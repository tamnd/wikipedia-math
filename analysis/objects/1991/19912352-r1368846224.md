# Method of dominant balance

## o1 subject: Method of dominant balance

In mathematics, the method of dominant balance approximates the solution to an equation
by solving a simplified form of the equation containing 2 or more of the equation's terms that most influence (dominate) the solution and excluding terms contributing only small modifications to this approximate solution. Following an initial solution, iteration of the procedure may generate additional terms of an asymptotic expansion providing a more accurate solution.

## o25 section: Algorithm

## o26 definition/construction: Algorithm

## Algorithm
The input is the set of equation terms and the limit L. The output is the set of approximate solutions. For each pair of distinct equation terms $T_{i}(s),T_{j}(s)$ the algorithm applies a scale transformation if needed, balances the selected terms by finding a function that solves the reduced equation and then determines if this function is consistent. If the function balances the terms and is consistent, the algorithm adds the function to the set of approximate solutions, otherwise the algorithm rejects the function. The process is repeated for each pair of distinct equation terms.
Inputs Set of equation terms $\{ T_{0}(s), T_{1}(s), \ldots, T_{n}(s)\}$ and limit $L$
Output Set of approximate solutions $\{ s_{0}(z), s_{1}(z), \dots \}$
For each pair of distinct equation terms $T_{i}(s),T_{j}(s)$ do:
Apply a scale transformation if needed.
Solve the reduced equation: $T_{i}(s)+T_{j}(s)=0$ with $T_{i}(s) \ne 0$ and $T_{j}(s) \ne 0$.
Verify consistency: $R_{ij}(s) \ll T_{i}(s) \ (z \to L)$ and $R_{ij}(s) \ll T_{j}(s) \ (z \to L).$
If function $s(z)$ is consistent and solves the reduced equation, add this function to the set of approximate solutions, otherwise reject the function.

## Examples
### Algebraic function
The dominant balance method will generate an approximate solution for variable $s$ in algebraic equation $1-16s+\epsilon s^{5}=0$ that depends on parameter $\epsilon$. This example computes asymptotic values as $\epsilon$ approaches zero because this example's goal is finding solutions for small $\epsilon$ parameter values. The function $s=s(\epsilon)$ denotes how the equation's solution depends on the equation's parameter $\epsilon$. The solution set is enumerated as $\{ s_{0}(\epsilon),s_{1}(\epsilon), s_{2}(\epsilon), s_{3}(\epsilon), s_{4}(\epsilon) \}$.
#### Input
The set of equation terms is $\{ 1, -16s, \epsilon s^{5} \}$ and asymptotic computations are as $\epsilon$ approaches zero.
#### First term pair
Select the terms $1$ and $-16s$.
Rewriting the selected terms as $\epsilon^{0} 1$ and $-\epsilon^{0} 16s$, the parameter's exponents are the same (0,0) for both terms so no scale transformation needed.
Solve the reduced equation: $1-16s=0, s(\epsilon)= \tfrac{1}{16}$.
Verify consistency: $\epsilon s^{5} \ll 1 \ (\epsilon \to 0), \ \epsilon s^{5} \ll 16s \ (\epsilon \to 0) \$ for $s(\epsilon)=\tfrac{1}{16}.$
Add this function to the set of approximate solutions: $s_{0}(\epsilon)=\tfrac{1}{16}$.
#### Second term pair
Select the terms $-16s$ and $\epsilon s^{5}$.
Rewriting the selected terms as $-\epsilon^{0} 16s$ and $\epsilon^{1} s^{5}$, the parameter's exponents are different (0,1) so a scale transformation is needed. Apply the scale transformation $s=\epsilon^{-1/4} \tilde{s}$. The parameter exponents of the transformed terms $- \epsilon^{-1/4} 16 \tilde{s}$ and $\epsilon^{-1/4} \tilde{s}^{5}=0$ are the same (-1/4,-1/4). The transformed equation becomes $\epsilon^{1/4}-16 \tilde{s}+\tilde{s}^{5}=0$.
Solve the reduced equation: $-16 \tilde{s}+\tilde{s}^{5}=0, \ \tilde{s}= 2, -2, 2i, -2i$.
Verify consistency: $\epsilon^{1/4} \ll 16 \tilde{s} \ (\epsilon \to 0), \ \epsilon^{1/4} \ll \tilde{s}^{5} \ (\epsilon \to 0) \$ for $\tilde{s}= 2, -2, 2i, -2i.$
Add these functions to the set of approximate solutions:
$$s_{1}(\epsilon)=\frac{2}{\epsilon^{1/4}},s_{2}(\epsilon)=\frac{-2}{\epsilon^{1/4}},s_{3}(\epsilon)=\frac{2i}{\epsilon^{1/4}},s_{4}(\epsilon)=\frac{-2i}{\epsilon^{1/4}}.$$
#### Third term pair
Select the terms $1$ and $\epsilon s^{5}$.
Rewriting the selected terms as $\epsilon^{0} 1$ and $\epsilon^{1} s^{5}$, the parameter's exponents are different (0,1) so a scale transformation is needed. Apply the scale transformation $s=\epsilon^{-1/5} \tilde{s}$. The parameter exponents of the transformed terms $\epsilon^{0} 1$ and $\epsilon^{0} \tilde{s}^{5}$ are the same (0,0). The transformed equation is $1-16 \epsilon^{-1/5} \tilde{s}+\tilde{s}^{5}=0.$
Solve the reduced equation: $1+\tilde{s}^{5}=0, \ \tilde{s}= (-1)^{1/5}.$
The function is not consistent: $-16 \epsilon^{-1/5}\tilde{s} \gg 1 \ (\epsilon \to 0), \ \epsilon^{-1/5}\tilde{s} \gg \tilde{s}^{5} \ (\epsilon \to 0) \$ for $\tilde{s}= (-1)^{1/5}.$
Reject this function: $s= \epsilon^{-1/5} (-1)^{1/5}.$
#### Output
The set of approximate solutions has 5 functions:
$$\left \{
\frac{1}{16},
\frac{2}{\epsilon^{1/4}},
\frac{-2}{\epsilon^{1/4}},
\frac{2i}{\epsilon^{1/4}},
\frac{-2i}{\epsilon^{1/4}}
\right \}.$$
#### Perturbation series solution
The approximate solutions are the first terms in the perturbation series solutions.
$$\begin{aligned}
& s_0(\epsilon)=\frac{1}{16}+\frac{1}{16777216} \epsilon^{1}+\frac{5}{17592186044416} \epsilon^{2}+\ldots, \\
& s_1(\epsilon)=\frac{2}{\epsilon^{1/4}}-\frac{1}{64} -\frac{5}{16384} \epsilon^{\frac{1}{4}}-\frac{5}{524288} \epsilon^{\frac{1}{2}}-\ldots, \\
& s_2(\epsilon)=-\frac{2}{\epsilon^{1/4}}-\frac{1}{64}+\frac{5}{16384} \epsilon^{\frac{1}{4}}-\frac{5}{524288} \epsilon^{\frac{1}{2}}+\ldots, \\
& s_3(\epsilon)=\frac{2i}{\epsilon^{1/4}}-\frac{1}{64} +\frac{5 i}{16384} \epsilon^{\frac{1}{4}}+\frac{5}{524288} \epsilon^{\frac{1}{2}}-\ldots \\
& s_4(\epsilon)=-\frac{2i}{\epsilon^{1/4}}-\frac{1}{64} -\frac{5 i}{16384} \epsilon^{\frac{1}{4}}+\frac{5}{524288} \epsilon^{\frac{1}{2}}+\ldots, \\
\end{aligned}$$
### Differential equation
The differential equation $z^{3}w^{\prime \prime}-w=0$ is known to have a solution with an exponential leading term. The transformation $w(z)=e^{s(z)}$ leads to the differential equation $1-z^{3}(s^{\prime})^{2}-z^{3}s^{\prime \prime}=0$. The dominant balance method will find an approximate solution as $z$ approaches zero because this example's focus is for solutions for small $z$ values. Scaled transformations will not be used because there are no equation parameters. Two consecutive applications of the dominant balance method will generate the 2 leading terms of an asymptotic series.
#### Input
The set of equation terms is $\{ 1,-z^{3}(s^{\prime})^{2},-z^{3}s^{\prime \prime} \}$ and the limit is zero.
##### First term pair
Select $1$ and $-z^{3}(s^{\prime})^{2}$.
The scale transformation is not required.
Solve the reduced equation: $1-z^{3}(s^{\prime})^{2}=0, \ s(z)=\pm 2z^{-1/2}$
Verify consistency: $z^{3}s^{\prime \prime} \ll 1 \ (z \to 0), \ z^{3}s^{\prime \prime} \ll z^{3}(s^{\prime})^{2} \ (z \to 0)$ for $s(z)=\pm 2z^{-1/2}.$
Add these 2 functions to the set of approximate solutions: $s_{+}(z)= +2z^{-1/2}, \ s_{-}(z)= -2z^{-1/2}.$
#### Second term pair
Select $1$ and $-z^{3}s^{\prime \prime}$
The scale transformation is not required.
Solve the reduced equation: $1-z^{3}s^{\prime \prime}=0, \ s(z)=\tfrac{1}{2}z^{-1}$
The function is not consistent: $z^{3}(s^{\prime})^{2} \gg 1 \ (z \to 0), \ z^{3}(s^{\prime})^{2} \gg z^{3}s^{\prime \prime} \ (z \to 0)$ for $s(z)=\tfrac{1}{2}z^{-1}.$
Reject this function: $s(z)=\tfrac{1}{2}z^{-1}.$.
#### Third term pair
Select $-z^{3}(s^{\prime})^{2}$ and $-z^{3}s^{\prime \prime}$.
The scale transformation is not required.
Solve the reduced equation: $z^{3}(s^{\prime})^{2}+z^{3}s^{\prime \prime}=0, \ s(z)=\ln z$.
The function is not consistent: $1 \gg z^{3}(s^{\prime})^{2} \ (z \to 0) \$ and $\ 1 \gg \ z^{3}s^{\prime \prime} \ (z \to 0)$ for $s(z)=\ln z.$
Reject this function: $s(z)=\ln z.$
#### Output
The set of approximate solutions has 2 functions:
$$\left \{ +2z^{-1/2}, -2z^{-1/2} \right \}.$$
#### Find 2-term solutions
Using the 1-term solution, a 2-term solution is
$$s_{2\pm}(z)=\pm 2z^{-1/2}+s(z).$$
Substitution of this 2-term solution into the original differential equation generates a new differential equation:
$$\begin{aligned}
1-z^{3}(s_{2\pm}^{\prime})^{2}-z^{3}s_{2\pm}^{\prime \prime}&=0 \\
\pm 1 \mp \frac{4}{3}zs^{\prime}+\frac{2}{3} z^{5/2}(s^{\prime})^{2}+\frac{2}{3}z^{5/2}s^{\prime\prime}&=0.
\end{aligned}$$
#### Input
The set of equation terms is $\{
\pm1, \mp \frac{4}{3}zs^{\prime}, \frac{2}{3} z^{5/2}(s^{\prime})^{2}, \frac{2}{3}z^{5/2}s^{\prime\prime} \}$ and the limit is zero.
##### First term pair
1. Select $1$ and $-\tfrac{4}{3}zs^{\prime}$.
2. The scale transformation is not required.
3. Solve the reduced equation: $1-\tfrac{4}{3}zs^{\prime}=0, \ s(z)=\tfrac{3}{4} \ln z$.
4. Verify consistency:
$\tfrac{2}{3} z^{5/2}(s^{\prime})^{2}+\tfrac{2}{3}z^{5/2}s^{\prime\prime} \ll 1 \ (z \to 0), \text{for} \ s(z)=\tfrac{3}{4} \ln z$
$\tfrac{2}{3} z^{5/2}(s^{\prime})^{2}+\tfrac{2}{3}z^{5/2}s^{\prime\prime} \ll \tfrac{4}{3}zs^{\prime} \ (z \to 0) \ \text{for} \ s(z)=\tfrac{3}{4} \ln z.$
5. Add these functions to the set of approximate solutions:
$s_{2+}(z)=+ 2z^{-1/2}+\tfrac{3}{4} \ln z$
$s_{2-}(z)=- 2z^{-1/2}+\tfrac{3}{4} \ln z$.
#### Other term pairs
For other term pairs, the functions that solve the reduced equations are not consistent.
#### Output
The set of approximate solutions has 2 functions:
$$\left \{ +2z^{-1/2}+\tfrac{3}{4} \ln z, -2z^{-1/2}+\tfrac{3}{4} \ln z \right \}.$$
#### Asymptotic expansion
The next iteration generates a 3-term solution $s_{3 \pm}(z)=\pm 2z^{-1/2}+\tfrac{3}{4} \operatorname{ln}(z)+h(z)$ with $h(z) \ll 1 \ (z \to 0)$ and this means that a power series expansion can represent the remainder of the solution.
The dominant balance method generates the leading term to this asymptotic expansion with constant $A$ and expansion coefficients determined by substitution into the full differential equation:
$w(z)=A z^{3/4}e^{\pm 2z^{-1/2}} \left( \sum^{m}_{n=0} \ a_{n} z^{n/2} \right)$
$a_{n+1}=\pm \frac{(n-1/2)(n+3/2)a_{n}}{4(n+1)}.$
A partial sum of this non-convergent series generates an approximate solution. The leading term corresponds to the Liouville-Green (LG) or Wentzel–Kramers–Brillouin (WKB) approximation.
