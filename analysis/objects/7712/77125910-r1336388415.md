# Mučnik reducibility

## o1 subject: Mučnik reducibility

In computability theory, a set $P$ of functions $\mathbb{N} \rightarrow \mathbb{N}$ is said to be Mučnik-reducible to another set $Q$ of functions $\mathbb{N} \rightarrow \mathbb{N}$ when for every function $g$ in $Q$, there exists a function $f$ in $P$ that is Turing-reducible to $g$.
