# Van der Waerden test

## o1 subject: Van der Waerden test

Named after the Dutch mathematician Bartel Leendert van der Waerden, the Van der Waerden test is a statistical test that k population distribution functions are equal. The Van der Waerden test converts the ranks from a standard Kruskal-Wallis test to quantiles of the standard normal distribution (details given below). These are called normal scores and the test is computed from these normal scores.
