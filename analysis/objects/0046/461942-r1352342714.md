# Poincaré half-plane model

## o1 subject: Poincaré half-plane model

In non-Euclidean geometry, the Poincaré half-plane model is a way of representing the hyperbolic plane using points in the familiar Euclidean plane. Specifically, each point in the hyperbolic plane is represented using a Euclidean point with coordinates $\langle x, y\rangle$ whose $y$ coordinate is greater than zero, the upper half-plane, and a metric tensor (definition of distance) called the Poincaré metric is adopted, in which the local scale is inversely proportional to the $y$ coordinate. Points on the $x$-axis, whose $y$ coordinate is equal to zero, represent ideal points (points at infinity), which are outside the hyperbolic plane proper.
