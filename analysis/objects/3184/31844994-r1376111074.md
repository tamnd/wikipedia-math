## o3 subject: StatCounter

StatCounter is an Irish web traffic analysis website started in 1999. Access to basic services is free to use and advanced services can cost between 5 and US$119 a month. StatCounter is based in Dublin, Ireland. The statistics from StatCounter are used to compute web usage share for example. , StatCounter is used on 0.9% of all websites.
