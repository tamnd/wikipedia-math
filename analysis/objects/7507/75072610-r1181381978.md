# Einstein–Weyl geometry

## o1 subject: Einstein–Weyl geometry

An Einstein–Weyl geometry is a smooth conformal manifold, together with a compatible Weyl connection that satisfies an appropriate version of the Einstein vacuum equations, first considered by and named after Albert Einstein and Hermann Weyl. Specifically, if $M$ is a manifold with a conformal metric $[g]$, then a Weyl connection is by definition a torsion-free affine connection $\nabla$ such that
$$\nabla g = \alpha\otimes g$$
where $\alpha$ is a one-form.
