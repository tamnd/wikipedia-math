## Chernavskii's theorem
Chernavskii's theorem (1964): If $M$ and $N$ are n-manifolds and $f$ is a discrete, open, continuous mapping of $M$ into $N$ then the branch set $B$$f$ = { x: x is an element of $M$ and $f$ fails to be a local homeomorphism at x} satisfies dimension ($B$$f$) ≤ n – 2.
