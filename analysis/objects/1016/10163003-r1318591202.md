# Bruhat order

## o1 subject: Bruhat order

In mathematics, the Bruhat order (also called the strong order, strong Bruhat order, Chevalley order, Bruhat–Chevalley order, or Chevalley–Bruhat order) is a partial order on the elements of a Coxeter group, that corresponds to the inclusion order on Schubert varieties.

## Definition
If $(W, S)$ is a Coxeter system with generators $S$, then the Bruhat order is a partial order on the group $W$. The definition of Bruhat order relies on several other definitions: first, reduced word for an element $w$ of $W$ is a minimum-length expression of $w$ as a product of elements of $S$, and the length $\ell(w)$ of $w$ is the length of its reduced words. Then the (strong) Bruhat order is defined by $u \le v$ if some substring of some (or every) reduced word for $v$ is a reduced word for $u$. (Here a substring is not necessarily a consecutive substring.)
There are two other related partial orders:
- the weak left (Bruhat) order is defined by $u \le_{L} v$ if some final substring of some reduced word for $v$ is a reduced word for $u$, and
- the weak right (Bruhat) order is defined by $u \le_{R} v$ if some initial substring of some reduced word for $v$ is a reduced word for $u$.
For more on the weak orders, see the article Weak order of permutations.
