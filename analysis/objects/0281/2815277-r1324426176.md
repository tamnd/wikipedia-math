# Gap theorem

## o1 subject: Gap theorem

In computational complexity theory, the gap theorem, also known as the Borodin–Trakhtenbrot gap theorem, is a major theorem about the complexity of computable functions.

## Statement
As an introductory example, suppose that we are considering time complexity of a certain specific Turing machine model. The set $\operatorname{TIME}(n^2)$ is the set of total computable functions, such that there exists some implementation of the function that computes it in time $\le n^2$ given an input size of $n$.
In general, any total computable function $t$ defines some $\operatorname{TIME}(t(n))$ time complexity class, and we expect that if $t'(n)$ is much larger than $t(n)$, for all $n$, then $\operatorname{TIME}(t'(n))$ should be larger than $\operatorname{TIME}(t(n))$. The gap theorem states that this is not necessarily so. Indeed, for any total computable $g$ such that $g(n) > n$ for all $n$, there exists some total computable function $t$, such that $\operatorname{TIME}(t(n)) = \operatorname{TIME}(g(t(n)))$. Intuitively, adding compute time might not allow us to compute more functions.
More generally, suppose $\Phi$ is an abstract (Blum) complexity measure, then for any total computable function $g$ for which $g(x) \geq x$ for every $x$, there is a total computable function $t$ such that with respect to $\Phi$, the complexity classes with boundary functions $t$ and $g \circ t$ are identical.
### Implications
For the special case of time complexity, this can be stated more simply as:
for any total computable function $g : \, \omega \,\to\, \omega$ such that $g(x) \geq x$ for all $x$, there exists a time bound $T(n)$ such that $\mathsf{DTIME}(g(T(n))) = \mathsf{DTIME}(T(n))$.
Similarly for the special case of space complexity.
Because the bound $T(n)$ may be very large (and often will be nonconstructible) the gap theorem does not imply anything interesting for complexity classes such as P or NP, and it does not contradict the time hierarchy theorem or space hierarchy theorem.
