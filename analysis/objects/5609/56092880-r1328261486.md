# Unigraph

## o1 subject: Unigraph

An unigraph or unigraphic graph is a graph that is up to isomorphism defined by its degree sequence. In other words, if any two graphs with the same given degree sequence are isomorphic to each other then they are (representations of) the same unigraph. The corresponding degree sequence is called unigraphical.
