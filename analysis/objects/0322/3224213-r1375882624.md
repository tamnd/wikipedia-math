# Symmetrically continuous function

## o1 subject: Symmetrically continuous function

In mathematics, a function $f: \mathbb{R} \to \mathbb{R}$ is symmetrically continuous at a point x if
$$\lim_{h\to 0} f(x+h)-f(x-h) = 0.$$
