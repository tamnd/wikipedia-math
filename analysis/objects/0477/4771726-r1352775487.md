# Simple extension

## o1 subject: Simple extension

In field theory, a simple extension is a field extension that is generated by the adjunction of a single element, called a primitive element. Simple extensions are well understood and can be completely classified.

## o2 section: Definition

## o3 definition: Definition

## Definition
A field extension $L/K$ is called a simple extension if there exists an element $\theta$ in L with
$L = K(\theta).$
This means that every element of $L$ can be expressed as a rational fraction in $\theta$, with coefficients in $K$; that is, it is produced from $\theta$ and elements of $K$ by the field operations +, −, •, / . Equivalently, $L$ is the smallest field that contains both $K$ and $\theta$.
There are two different kinds of simple extensions (see below):
- The element $\theta$ may be transcendental over $K$, which means that it is not a root of any polynomial with coefficients in $K$. In this case $K(\theta)$ is isomorphic to the field of rational functions $K(X).$
- Otherwise, $\theta$ is algebraic over $K$; that is, $\theta$ is a root of a polynomial over $K$. The monic polynomial $p(X)$ of minimal degree $n$, with $\theta$ as a root, is called the minimal polynomial of $\theta$. Its degree equals the degree of the field extension, that is, the dimension of $L$ viewed as a $K$-vector space. In this case, every element of $K(\theta)$ can be uniquely expressed as a polynomial in $\theta$ of degree less than $n$, and $K(\theta)$ is isomorphic to the quotient ring $K[X]/(p(X)).$
In both cases, the element $\theta$ is called a generating element or primitive element for the extension; one says also $L$ is generated over $K$ by $\theta$.
For example, every finite field is a simple extension of the prime field of the same characteristic. More precisely, if $p$ is a prime number and $q=p^n,$ the field $L=\mathbb{F}_{q}$ of $q$ elements is a simple extension of degree n of $K=\mathbb{F}_{p}.$ In fact, L is generated as a field by any element $\theta$ that is a root of an irreducible polynomial of degree n in $K[X]$.
However, in the case of finite fields, the term primitive element is usually reserved for a stronger notion, an element γ that generates $L^\times = L-\{0\}$ as a multiplicative group, so that every nonzero element of L is a power of γ, i.e. is produced from γ using only the group operation • . To distinguish these meanings, one uses the term "generator" or field primitive element for the weaker meaning, reserving "primitive element" or group primitive element for the stronger meaning. (See Finite field#Multiplicative structure and Primitive element (finite field)).

## o7 example: Examples

## Examples
- C / R generated by $\theta = i =\sqrt{-1}$.
- Q($\sqrt{2}$) / Q generated by $\theta=\sqrt{2}$.
- Any number field (i.e., a finite extension of Q) is a simple extension Q(θ) for some θ. For example, $\mathbf{Q}(\sqrt{3}, \sqrt{7})$ is generated by $\theta=\sqrt{3} + \sqrt{7}$.
- F(X) / F, a field of rational functions, is generated by the formal variable X.
