# Ω-automaton

## o1 subject: Ω-automaton

In automata theory, a branch of theoretical computer science, an ω-automaton (or stream automaton) is a variation of a finite automaton that runs on infinite, rather than finite, strings as input. Since ω-automata do not stop, they have a variety of acceptance conditions rather than simply a set of accepting states.

## Acceptance conditions
Acceptance conditions may be infinite sets of ω-words. However, people mostly study acceptance conditions that are finitely representable. The following lists a variety of popular acceptance conditions.
Before discussing the list, let's make the following observation. In the case of infinitely running systems, one is often interested in whether certain behavior is repeated infinitely often. For example, if a network card receives infinitely many ping requests, then it may fail to respond to some of the requests but should respond to an infinite subset of received ping requests. This motivates the following definition: For any run $\rho$, let $\text{Inf}(\rho)$ be the set of states that occur infinitely often in $\rho$. This notion of certain states being visited infinitely often will be helpful in defining the following acceptance conditions.
- A Büchi automaton is an ω-automaton $A$ that uses the following acceptance condition, for some subset $F$ of $Q$:
Büchi condition
$A$ accepts exactly those runs $\rho$ for which $\text{Inf}(\rho) \cap F \neq \emptyset$, i.e. there is an accepting state that occurs infinitely often in $\rho$.
- A Rabin automaton is an ω-automaton $A$ that uses the following acceptance condition, for some set $\Omega$ of pairs $(B_i, G_i)$ of sets of states:
Rabin condition
$A$ accepts exactly those runs $\rho$ for which there exists a pair $(B_i, G_i)$ in $\Omega$ such that $B_i \cap \text{Inf}(\rho) = \emptyset$ and $G_i \cap \text{Inf}(\rho) \neq \emptyset$.
- A Streett automaton is an ω-automaton $A$ that uses the following acceptance condition, for some set $\Omega$ of pairs $(B_i, G_i)$ of sets of states:
Streett condition
$A$ accepts exactly those runs $\rho$ such that for all pairs $(B_i, G_i)$ in $\Omega$, $B_i \cap \text{Inf}(\rho) \neq \emptyset$ or $G_i \cap \text{Inf}(\rho) = \emptyset$.
- A parity automaton is an automaton $A$ whose set of states is $Q = \{0, 1, 2, \ldots, k\}$ for some natural number $k$, and that has the following acceptance condition:
Parity condition
$A$ accepts $\rho$ if and only if the smallest number in $\text{Inf}(\rho)$ is even.
- A Muller automaton is an ω-automaton $A$ that uses the following acceptance condition, for a subset $\mathbf{F}$ of $\mathcal{P}(Q)$ (the power set of $Q$):
Muller condition
$A$ accepts exactly those runs $\rho$ for which $\text{Inf}(\rho) \in \mathbf{F}$.
Every Büchi automaton can be regarded as a Muller automaton. It suffices to replace $F$ by $\mathbf{F}'$ consisting of all subsets of $Q$ that contain at least one element of $F$.
Similarly every Rabin, Streett or parity automaton can also be regarded as a Muller automaton.

## Example
The following ω-language $L$ over the alphabet $\Sigma = \{0, 1\}$, which can be recognized by a nondeterministic Büchi automaton:
$L$ consists of all ω-words in $\Sigma^\omega$ in which 1 occurs only finitely many times.
A non-deterministic Büchi automaton recognizing $L$ needs only two states $q_0$ (the initial state) and $q_1$. $\Delta$ consists of the triples $(q_0, 0, q_0)$, $(q_0, 1, q_0)$, $(q_0, 0, q_1)$ and $(q_1, 0, q_1)$.
$F = \{q_1\}$. For any input $\alpha$ in which 1 occurs only finitely many times, there is a run that stays in state $q_0$ as long as there are 1s to read, and goes to state $q_1$ afterwards. This run is successful.
If there are infinitely many 1s, then there is only one possible run: the one that always stays in state $q_0$. (Once the machine has left $q_0$ and reached $q_1$, it cannot return. If another 1 is read, there is no successor state.)
Notice that above language cannot be recognized by a deterministic Büchi automaton, which is strictly less expressive than its non-deterministic counterpart.
