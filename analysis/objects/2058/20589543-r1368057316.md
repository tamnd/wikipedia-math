# Mixing length model

## o1 subject: Mixing length model

In fluid dynamics, the mixing length model is a method attempting to describe momentum transfer by turbulence Reynolds stresses within a Newtonian fluid boundary layer by means of an eddy viscosity. The model was developed by Ludwig Prandtl in the early 20th century. Prandtl himself had reservations about the model, describing it as, "only a rough approximation,"
but it has been used in numerous fields ever since, including atmospheric science, oceanography and stellar structure.
