# Recursive largest first algorithm

## o1 subject: Recursive largest first algorithm

The Recursive Largest First (RLF) algorithm is a heuristic for the NP-hard graph coloring problem. It was originally proposed by Frank Leighton in 1979.

## Example
Consider the graph $G=(V,E)$ shown on the right. This is a wheel graph and will therefore be optimally colored by RLF. Executing the algorithm results in the vertices being selected and colored in the following order:
- Vertex $g$ (color 1)
- Vertex $a$, $c$, and then $e$ (color 2)
- Vertex $b$, $d$, and then $f$ (color 3)
This gives the final three-colored solution $\mathcal{S} = \{\{g\}, \{a, c, e\}, \{b, d, f\}\}$.
