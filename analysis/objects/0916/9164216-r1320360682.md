# Neyman construction

## o1 subject: Neyman construction

Neyman construction, named after Jerzy Spława-Neyman, is a frequentist method to construct an interval at a confidence level $C, \,$ such that if we repeat the experiment many times the interval will contain the true value of some parameter a fraction $C\,$ of the time.

## Implementation
A Neyman construction can be carried out by performing multiple experiments that construct data sets corresponding to a given value of the parameter. The experiments are fitted with conventional methods, and the space of fitted parameter values constitutes the band which the confidence interval can be selected from.
