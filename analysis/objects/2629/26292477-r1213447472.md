# Krichevsky–Trofimov estimator

## o1 subject: Krichevsky–Trofimov estimator

In information theory, given an unknown stationary source $\pi$ with alphabet A and a sample w from $\pi$, the Krichevsky–Trofimov (KT) estimator produces an estimate pi(w) of the probability of each symbol i ∈ A. This estimator is optimal in the sense that it minimizes the worst-case regret asymptotically.
