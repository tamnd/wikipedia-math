## o8 proof: Proof

Proof. By construction, it would mean that $\mathbf{x}_{k+1} = \mathbf{x}_k$, that is, taking a conjugate gradient step gets us exactly back to where we were. This is only possible if the local gradient is already zero.

## o10 statement/lemma: Lemma 1

Lemma 1. $\mathbf{p}_i^T \mathbf{r}_j = 0, \;\forall i < j$ and $\mathbf{r}_i^T \mathbf{r}_j = 0, \;\forall i < j$.

## o11 proof: Proof

Proof. By the geometric construction, the tangent plane to the ellipsoid at $\mathbf{x}_j$ contains each of the previous conjugate direction vectors $\mathbf{p}_0, \mathbf{p}_1, \dots,\mathbf{p}_{j-1}$. Further, $\mathbf{r}_j$ is perpendicular to the tangent, thus $\mathbf{p}_i^T \mathbf{r}_j = 0, \;\forall i < j$. The second equation is true since by construction, $\mathbf{r}_0, \mathbf{r}_1, \dots,\mathbf{r}_{j-1}$ is a linear transform of $\mathbf{p}_0, \mathbf{p}_1, \dots,\mathbf{p}_{j-1}$.

## o12 statement/lemma: Lemma 2

Lemma 2. $\mathbf{p}_k^T \mathbf{r}_k = \mathbf{r}_k^T\mathbf{r}_k$.

## o13 proof: Proof

Proof. By construction, $\mathbf{p}_{k} := \boldsymbol{r}_{k} - \sum_{i = 0}^{k-1}
\frac{\boldsymbol{p}_i^\mathrm{T}\boldsymbol{Ar}_{k-1}}{\boldsymbol{p}_i^\mathrm{T}\boldsymbol{Ap}_i}\boldsymbol{p}_{i}$, now apply lemma 1.

## o14 statement/lemma: Lemma 3

Lemma 3. $\boldsymbol{p}_i^\mathrm{T}\boldsymbol{Ar}_{k+1} = \begin{cases}
0, \; i < k \\
-\boldsymbol{r}_{k+1}^T \boldsymbol{r}_{k+1} /\alpha_{k}, \; i = k
\end{cases}$.

## o15 proof: Proof

Proof. By construction, we have $\mathbf{r}_{i+1} = \mathbf{r}_i - \alpha_i \mathbf{A p}_i$, thus
$$\boldsymbol r_{k+1}^T \boldsymbol A \boldsymbol p_i = \boldsymbol r_{k+1}^T \frac{\boldsymbol r_{i} -\boldsymbol r_{i+1}}{\alpha_i}$$
Now apply lemma 1.
Plugging lemmas 1-3 in, we have $\alpha_k=\frac{\mathbf{r}_k^{\top} \mathbf{r}_k}{\mathbf{p}_k^{\top} \mathbf{A} \mathbf{p}_k}$ and $\mathbf{p}_{k+1}:=\boldsymbol{r}_{k+1} + \frac{\mathbf{r}_{k+1}^{\top} \mathbf{r}_{k+1}}{\mathbf{r}_k^{\top} \mathbf{r}_k} \mathbf p_k$, which is the proper conjugate gradient algorithm.
