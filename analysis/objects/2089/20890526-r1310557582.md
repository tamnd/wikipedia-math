# Bootstrapping populations

## o1 subject: Bootstrapping populations

Bootstrapping populations in statistics and mathematics starts with a sample $\{x_1,\ldots,x_m\}$ observed from a random variable.

## o2 citation

## o3 section: Method

## o4 definition/construction: Method

## Method
Given a $\boldsymbol x=\{x_1,\ldots,x_m\}$ of a random variable X and a sampling mechanism $(g_{\boldsymbol\theta},Z)$ for X, the realization x is given by $\boldsymbol x=\{g_{\boldsymbol\theta}(z_1),\ldots,g_{\boldsymbol\theta}(z_m)\}$, with $\boldsymbol\theta=(\theta_1,\ldots,\theta_k)$. Focusing on well-behaved statistics,
{|
|-
| $s_1=h_1(x_1,\ldots,x_m),$
|-
| $\vdots\ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots$
|-
| $s_k=h_k(x_1,\ldots,x_m),$
|}
for their parameters, the master equations read
{| width=100%
|-
| $s_1= h_1(g_{\boldsymbol\theta} (z_1),\ldots, g_{\boldsymbol\theta} (z_m))= \rho_1(\boldsymbol\theta;z_1,\ldots,z_m)$
|-
| width=90% | $\vdots\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots$
| width=10% align="center" | (1)
|-
| $s_k= h_k(g_{\boldsymbol\theta} (z_1),\ldots, g_{\boldsymbol\theta} (z_m))= \rho_k(\boldsymbol\theta;z_1,\ldots,z_m).$
|}
For each sample seed $\{z_1,\ldots,z_m\}$ a vector of parameters $\boldsymbol\theta$ is obtained from the solution of the above system with $s_i$ fixed to the observed values.
Having computed a huge set of compatible vectors, say N, the empirical marginal distribution of $\Theta_j$ is obtained by:
{| width=100%
|-
| width=90% | $\widehat F_{\Theta_j}(\theta)=\sum_{i=1}^N\frac{1}{N}I_{(-\infty,\theta]}(\breve\theta_{j,i})$
| width=10% align="center" | (2)
|}
where $\breve\theta_{j,i}$ is the j-th component of the generic solution of (1) and where $I_{(-\infty,\theta]}(\breve\theta_{j,i})$ is the indicator function of $\breve\theta_{j,i}$ in the interval $(-\infty,\theta].$
Some indeterminacies remain if X is discrete and this we will be considered shortly.
The whole procedure may be summed up in the form of the following Algorithm, where the index $\boldsymbol\Theta$ of $\boldsymbol s_{\boldsymbol\Theta}$ denotes the parameter vector from which the statistics vector is derived.

## o5 section: Algorithm

## o6 definition/construction: Algorithm

## Algorithm
| Generating parameter populations through a bootstrap
|
Given a sample $\{x_1,\ldots,x_m\}$ from a random variable with parameter vector $\boldsymbol\theta$ unknown,
- Identify a vector of well-behaved statistics $\boldsymbol S$ for $\boldsymbol\Theta$;
- compute a specification $\boldsymbol s_{\boldsymbol\Theta}$ of $\boldsymbol S$ from the sample;
- repeat for a satisfactory number N of iterations:
draw a sample seed $\breve{\boldsymbol z}_i$ of size m from the seed random variable;
get $\breve{\boldsymbol\theta}_i=\mathrm{Inv}(\boldsymbol s,\boldsymbol z_i)$ as a solution of (1) in θ with $\boldsymbol s=\boldsymbol s_{\boldsymbol\Theta}$ and $\boldsymbol z_i = \{\breve z_1,\ldots,\breve z_m\}$;
add $\breve{\boldsymbol\theta}_i$ to $\boldsymbol\Theta$; population.
You may easily see from a table of sufficient statistics that we obtain the curve in the picture on the left by computing the empirical distribution (2) on the population obtained through the above algorithm when: i) X is an Exponential random variable, ii) $s_\Lambda= \sum_{j=1}^m x_j$, and
$\text{ iii) Inv}(s_\Lambda,\boldsymbol u_i) =\sum_{j=1}^m(-\log u_{ij})/s_\Lambda$,
and the curve in the picture on the right when: i) X is a Uniform random variable in $[0,a]$, ii) $s_A= \max_{j=1, \ldots, m} x_j$, and
$\text{iii) Inv}(s_A,\boldsymbol u_i) =s_A/\max_{j=1,\ldots,m}\{u_{ij}\}$.
### Remark
Note that the accuracy with which a parameter distribution law of
populations compatible with a sample is obtained is not a function of the sample size. Instead, it is a function of the number of seeds we draw. In turn, this number is purely a matter of computational time but does not require any extension of the observed data. With other bootstrapping methods focusing on a generation of sample replicas (like those proposed by ) the accuracy of the estimate distributions depends on the sample size.
### Example
For $\boldsymbol x$ expected to represent a Pareto distribution, whose specification requires values for the parameters $a$ and k, we have that the cumulative distribution function reads:
$F_X(x)=1-\left(\frac{k}{x}\right)^a$.
A sampling mechanism $(g_{(a,k)}, U)$ has $[0,1]$ uniform seed U and explaining function $g_{(a,k)}$ described by:
$x= g_{(a,k)}=(1 - u)^{-\frac{1}{a}} k$
A relevant statistic $\boldsymbol s_\boldsymbol\Theta$ is constituted by the pair of joint sufficient statistics for $A$ and K, respectively $s_1=\sum_{i=1}^m \log x_i, s_{2}=\min\{x_i\}$.
The master equations read
$s_1=\sum_{i=1}^m -\frac{1}{a}\log(1 - u_i)+m \log k$
$s_{2}=(1 - u_{\min})^{-\frac{1}{a}} k$
with $u_{\min}=\min\{u_i\}$.
