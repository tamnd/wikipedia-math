# Conjugate gradient squared method

## o1 subject: Conjugate gradient squared method

In numerical linear algebra, the conjugate gradient squared method (CGS) is an iterative algorithm for solving systems of linear equations of the form $A{\mathbf x} = {\mathbf b}$, particularly in cases where computing the transpose $A^T$ is impractical. The CGS method was developed as an improvement to the biconjugate gradient method.

## Algorithm
The algorithm is as follows:
- Choose an initial guess ${\mathbf x}^{(0)}$
- Compute the residual ${\mathbf r}^{(0)} = {\mathbf b} - A{\mathbf x}^{(0)}$
- Choose $\tilde {\mathbf r} = {\mathbf r}^{(0)}$
- For $i = 1, 2, 3, \dots$ do:
$\rho^{(i-1)} = \tilde {\mathbf r}^{T}{\mathbf r}^{(i-1)}$
If $\rho^{(i-1)} = 0$, the method fails.
If $i=1$:
${\mathbf p}^{(1)} = {\mathbf u}^{(1)} = {\mathbf r}^{(0)}$
Else:
$\beta^{(i-1)} = \rho^{(i-1)}/\rho^{(i-2)}$
${\mathbf u}^{(i)} = {\mathbf r}^{(i-1)} + \beta_{i-1}{\mathbf q}^{(i-1)}$
${\mathbf p}^{(i)} = {\mathbf u}^{(i)} + \beta^{(i-1)}({\mathbf q}^{(i-1)} + \beta^{(i-1)}{\mathbf p}^{(i-1)})$
Solve $M\hat {\mathbf p}={\mathbf p}^{(i)}$, where $M$ is a pre-conditioner.
$\hat {\mathbf v} = A\hat {\mathbf p}$
$\alpha^{(i)} = \rho^{(i-1)} / \tilde {\mathbf r}^T \hat {\mathbf v}$
${\mathbf q}^{(i)} = {\mathbf u}^{(i)} - \alpha^{(i)}\hat {\mathbf v}$
Solve $M\hat {\mathbf u} = {\mathbf u}^{(i)} + {\mathbf q}^{(i)}$
${\mathbf x}^{(i)} = {\mathbf x}^{(i-1)} + \alpha^{(i)} \hat {\mathbf u}$
$\hat {\mathbf q} = A\hat {\mathbf u}$
${\mathbf r}^{(i)} = {\mathbf r}^{(i-1)} - \alpha^{(i)}\hat {\mathbf q}$
Check for convergence: if there is convergence, end the loop and return the result
