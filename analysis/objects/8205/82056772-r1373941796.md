# Calcpad

## o2 subject: Calcpad

Calcpad is a free and open source mathematical software, created by PhD Eng. Nedelcho Ganchovski in 2014. It is primarily designed to perform engineering calculations and document the results into calculation notes/reports in HTML, PDF or Microsoft Word format. Calcpad employs its own programming language with simplified syntax, suitable for engineers with minimal programming experience.
