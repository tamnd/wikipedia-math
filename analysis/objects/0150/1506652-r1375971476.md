# Choropleth map

## o1 subject: Choropleth map

A choropleth map (grc) is a type of statistical thematic map that uses pseudocolour, meaning color corresponding with an aggregate summary of a geographic characteristic within spatial enumeration units, such as population density or per-capita income.
