# Datagram Transport Layer Security

## o1 subject: Datagram Transport Layer Security

Datagram Transport Layer Security (DTLS) is a communications protocol providing security to datagram-based applications by allowing them to communicate in a way designed434763479147 to prevent eavesdropping, tampering, or message forgery. The DTLS protocol is based on the stream-oriented Transport Layer Security (TLS) protocol and is intended to provide similar security guarantees. The DTLS protocol datagram preserves the semantics of the underlying transport—the application does not suffer from the delays associated with stream protocols, but because it uses User Datagram Protocol (UDP) or Stream Control Transmission Protocol (SCTP), the application has to deal with packet reordering, loss of datagram and data larger than the size of a datagram network packet. Because DTLS uses UDP or SCTP rather than TCP it avoids the TCP meltdown problem when being used to create a VPN tunnel.

## Definition
The following documents define DTLS:
- 5238 from May 20085238 for use with Datagram Congestion Control Protocol (DCCP)
- 5415 from March 20095415 for use with Control And Provisioning of Wireless Access Points (CAPWAP)
- 5764 from May 20105764 for use with Secure Real-time Transport Protocol (SRTP) subsequently called DTLS-SRTP in a draft with Secure Real-Time Transport Control Protocol (SRTCP)
- 6083 from January 20116083 for use with Stream Control Transmission Protocol (SCTP) encapsulation
- 6347 from January 20126347 defining DTLS 1.2
- 9147 from April 20229147 defining DTLS 1.3
DTLS 1.0 is based on TLS 1.1, DTLS 1.2 is based on TLS 1.2, and DTLS 1.3 is based on TLS 1.3. There is no DTLS 1.1 because this version-number was skipped in order to harmonize version numbers with TLS.6347 Like previous DTLS versions, DTLS 1.3 is intended to provide "equivalent security guarantees [to TLS 1.3] with the exception of order protection/non-replayability".

### Applications
- Cisco AnyConnect VPN Client uses TLS and invented DTLS-based VPN.
- OpenConnect is an open source AnyConnect-compatible client and ocserv server that supports (D)TLS.
- Cisco InterCloud Fabric uses DTLS to form a tunnel between private and public/provider compute environments.
- Cato Networks utilizes DTLS v1.2 for the underlay tunnel used by both the Cato Socket and Cato ZTNA (formerly SDP) client when forming tunnels to the Cato POPs and when forming off-cloud tunnels between Cato sockets.
- ZScaler tunnel 2.0 for ZScaler Internet Access (ZIA) uses DTLS for tunneling. ZScaler Private Access (ZPA) does not support DTLS
- F5 Networks Edge VPN Client uses TLS and DTLS.
- Fortinet's SSL VPN and Array Networks SSL VPN also use DTLS for VPN tunneling.
- Citrix Systems NetScaler uses DTLS to secure UDP.
- Web browsers: Google Chrome, Opera and Firefox support DTLS-SRTP for WebRTC. Firefox 86 and onward does not support DTLS 1.0.
- Remote Desktop Protocol 8.0 and onwards.
