# Simplicial vertex

## o1 subject: Simplicial vertex

In graph theory, a simplicial vertex $v$ is a vertex whose closed neighborhood $N_{G}[v]$ in a graph $G$ forms a clique, where every pair of neighbors is adjacent to each other.
