# ROCA vulnerability

## o1 infobox: infobox bug

## o2 subject: ROCA vulnerability

The ROCA vulnerability is a cryptographic weakness that allows the private key of a key pair to be recovered from the public key in keys generated by devices with the vulnerability. "ROCA" is an acronym for "Return of Coppersmith's attack". The vulnerability has been given the identifier 2017-15361.
