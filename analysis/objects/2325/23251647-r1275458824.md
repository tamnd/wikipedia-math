# Continuity set

## o1 subject: Continuity set

In measure theory, a branch of mathematics, a continuity set of a measure $\mu$ is any Borel set $B$ such that
$$\mu(\partial B) = 0,$$
where $\partial B$ is the (topological) boundary of $B$. For signed measures, one instead asks that
$$|\mu|(\partial B) = 0.$$
