# Markov constant

## o1 subject: Markov constant

In number theory, specifically in Diophantine approximation theory, the Markov constant $M(\alpha)$ of an irrational number $\alpha$ is the factor for which Dirichlet's approximation theorem can be improved for $\alpha$.

## o8 definition: Definition

## Definition
Mathematically, the Markov constant of irrational $\alpha$ is defined as $M(\alpha)=\sup \left\{\lambda\in\mathbb{R} : \left\vert \alpha - \frac{p}{q} \right\vert<\frac{1}{\lambda q^2} \text{ has infinitely many solutions for }p,q\in\mathbb{N} \right\}$. If the set does not have an upper bound we define $M(\alpha)=\infty$.
Alternatively, it can be defined as $\limsup_{k\to\infty}\frac{1}{k^2\left\vert \alpha-\frac{f(k)}{k} \right\vert}$ where $f(k)$ is defined as the closest integer to $\alpha k$.

## o18 example: Examples

## Examples
### Markov constant of two numbers
Since $\frac{\sqrt{10}}{2}=[1;\overline{1,1,2}]$,
$\begin{aligned} M\left ( \frac{\sqrt{10}}{2} \right )
& = \max([1;\overline{2,1,1}]+[0;\overline{1,2,1}],[1;\overline{1,2,1}]+[0;\overline{2,1,1}],[2;\overline{1,1,2}]+[0;\overline{1,1,2}]) \\
& = \max\left ( \frac{2\sqrt{10}}{3},\frac{2\sqrt{10}}{3},\sqrt{10} \right ) \\
& = \sqrt{10}. \end{aligned}$
As $e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, \ldots, 1, 2n, 1, \ldots], M(e)=\infty$ because the continued fraction representation of $e$ is unbounded.
### Numbers αn having Markov constant less than 3
Consider $n=6$; Then $m_n=34$. By trial and error it can be found that $u=13$. Then
$\begin{aligned} \alpha_6 & = \frac{2u-3m_6+\sqrt{9m_6^2-4}}{2m_6} \\[6pt]
& = \frac{-76+\sqrt{10400}}{68} \\[6pt]
&= \frac{-19+5\sqrt{26}}{17} \\[6pt]
&=[0;\overline{2,1,1,1,1,1,1,2}]. \end{aligned}$
