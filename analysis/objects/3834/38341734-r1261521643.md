# T-coloring

## o1 subject: T-coloring

In graph theory, a T-Coloring of a graph $G = (V, E)$, given the set T of nonnegative integers containing 0, is a function $c: V(G) \to \mathbb{N}$ that maps each vertex to a positive integer (color) such that if u and w are adjacent then $|c(u) - c(w)| \notin T$. In simple words, the absolute value of the difference between two colors of adjacent vertices must not belong to fixed set T. The concept was introduced by William K. Hale. If T = $\{0\}$ it reduces to common vertex coloring.

## o6 proof: Proof

Proof. Every T-coloring of G is also a vertex coloring of G, so $\chi_{T}(G)\geq \chi(G).$ Suppose that $\chi(G)=k$ and $r=\max(T).$ Given a common vertex k-coloring function $c: V(G) \to \mathbb{N}$ using the colors $\{1, \ldots,k\}.$ We define $d: V(G) \to \mathbb{N}$ as
$d(v)=(r+1)c(v)$
For every two adjacent vertices u and w of G,
$|d(u) - d(w)| =| (r+1)c(u) - (r+1)c(w)| =(r+1) | c(u)-c(w)| \geq r +1$
so $|d(u) - d(w)| \notin T.$ Therefore d is a T-coloring of G. Since d uses k colors, $\chi_{T}(G)\leq k =\chi(G).$ Consequently, $\chi_{T}(G)=\chi(G).$
