# Gauss–Kuzmin–Wirsing operator

## o1 subject: Gauss–Kuzmin–Wirsing operator

In mathematics, the Gauss–Kuzmin–Wirsing operator is the transfer operator of the Gauss map that takes a positive number to the fractional part of its reciprocal. (This is not the same as the Gauss map in differential geometry.) It is named after Carl Gauss, Rodion Kuzmin, and Eduard Wirsing. It occurs in the study of continued fractions; it is also related to the Riemann zeta function.

## o17 section: The Gauss map is ergodic

## o18 statement/lemma: Lemma

Lemma. For any open interval $(a, b) \subset (0, 1)$, we have
$$\mu(T^{-n}(a,b) \cap \Delta_n) = \mu((a,b)) \mu(\Delta_n) \underbrace{\left(\frac{q_n(q_n + q_{n-1})}{(q_n + q_{n-1}b)(q_n + q_{n-1}a) } \right)}_{\geq 1/2}$$
Proof. For any $t \in (0, 1)$ we have $[0;a_1, \dots, a_n + t] = \frac{q_n + q_{n-1}t}{p_n + p_{n-1}t}$ by standard continued fraction theory. By expanding the definition, $T^{-n}(a,b) \cap \Delta_n$ is an interval with end points $[0;a_1, \dots, a_n + a], [0;a_1, \dots, a_n+ b]$. Now compute directly. To show the fraction is $\geq 1/2$, use the fact that $q_n \geq q_{n-1}$.

## o19 statement/theorem: Theorem

Theorem. The Gauss map is ergodic.

## o20 proof: Proof

Proof. Consider the set of all open intervals in the form $([0;a_1, \dots, a_n], [0;a_1, \dots, a_n+1])$. Collect them into a single family $\mathcal C$. This $\mathcal C$ is a covering family, because any open interval $(a, b)\setminus \mathbb{Q}$ where $a, b$ are rational, is a disjoint union of finitely many sets in $\mathcal C$.
Suppose a set $B$ is $T$-invariant and has positive measure. Pick any $\Delta_n \in \mathcal C$. Since Lebesgue measure is outer regular, there exists an open set $B_0$ which differs from $B$ by only $\mu(B_0 \Delta B) < \epsilon$. Since $B$ is $T$-invariant, we also have $\mu(T^{-n}B_0 \Delta B) = \mu(B_0 \Delta B) < \epsilon$. Therefore,
$$\mu(T^{-n}B_0 \cap \Delta_n) \in \mu(B\cap \Delta_n) \pm \epsilon$$
By the previous lemma, we have
$$\mu(T^{-n}B_0 \cap \Delta_n) \geq \frac 12 \mu(B_0) \mu(\Delta_n) \in \frac 12 (\mu(B) \pm \epsilon) \mu(\Delta_n)$$
Take the $\epsilon \to 0$ limit, we have $\mu(B \cap \Delta_n) \geq \frac 12 \mu(B) \mu(\Delta_n)$. By Knopp's lemma, it has full measure.
