# Tamari lattice

## o1 subject: Tamari lattice

In mathematics, the Tamari lattice is an algebraic structure that concisely represents some of the important logical and geometric properties of associativity. More formally, the Tamari lattice of order n, introduced by and sometimes notated Tn or Yn, is a partially ordered set in which the elements consist of all ways of bracketing a sequence of n+1 letters using n pairs of parentheses, with the ordering induced by only rightward applications of the associative law ((xy)z) → (x(yz)). For instance, T3 contains five elements (((ab)c)d), ((ab)(cd)), ((a(bc))d), (a((bc)d)), and (a(b(cd))), with (((ab)c)d) < ((ab)(cd)) < (a(b(cd))) and (((ab)c)d) < ((a(bc))d) < (a((bc)d)) < (a(b(cd))). (The outermost pair of parentheses is redundant and often omitted when naming the elements of Tn, as in the depiction of T4 shown in the figure.)
