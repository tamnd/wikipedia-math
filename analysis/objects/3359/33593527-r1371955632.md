# Diagnostic odds ratio

## o1 subject: Diagnostic odds ratio

In medical testing with binary classification, the diagnostic odds ratio (DOR) is a measure of the effectiveness of a diagnostic test. It is defined as the ratio of positive likelihood ratio to negative likelihood ratio. There is also a multiclass version of the diagnostic odds ratio.

## o2 citation: Glas 2003

## o3 citation: Foulle2025

## o4 section: Definition

## o5 definition: Definition

## Definition
The diagnostic odds ratio is defined mathematically as:
$\text{Diagnostic odds ratio, DOR} = \frac{TP/FN}{FP/TN} = \frac{TP/FP}{FN/TN} = \frac{TP \cdot TN}{FP \cdot FN}$
where $TP$, $FN$, $FP$ and $TN$ are the number of true positives, false negatives, false positives and true negatives respectively.
### Confidence interval
As with the odds ratio, the logarithm of the diagnostic odds ratio is approximately normally distributed. The standard error of the log diagnostic odds ratio is approximately:
$\mathrm{SE}\left(\ln{\text{DOR}}\right) = \sqrt{\frac{1}{TP}+\frac{1}{FN}+\frac{1}{FP}+\frac{1}{TN}}$
From this an approximate 95% confidence interval can be calculated for the log diagnostic odds ratio:
$\ln{\text{DOR}} \pm 1.96 \times \mathrm{SE}\left(\ln{\text{DOR}}\right)$
Exponentiation of the approximate confidence interval for the log diagnostic odds ratio gives the approximate confidence interval for the diagnostic odds ratio.

## o12 application: Uses

## Uses
The log diagnostic odds ratio is sometimes used in meta-analyses of diagnostic test accuracy studies due to its simplicity (being approximately normally distributed).
Traditional meta-analytic techniques such as inverse-variance weighting can be used to combine log diagnostic odds ratios computed from a number of data sources to produce an overall diagnostic odds ratio for the test in question.
The log diagnostic odds ratio can also be used to study the trade-off between sensitivity and specificity by expressing the log diagnostic odds ratio in terms of the logit of the true positive rate (sensitivity) and false positive rate (1 − specificity), and by additionally constructing a measure, $S$:
$D = \log{\text{DOR}} = \log{\left[\frac{TPR}{(1-TPR)}\times\frac{(1-FPR)}{FPR}\right]} = \operatorname{logit}(TPR) - \operatorname{logit}(FPR)$
$S = \operatorname{logit}(TPR) + \operatorname{logit}(FPR)$
It is then possible to fit a straight line, $D = a + bS$. If b ≠ 0 then there is a trend in diagnostic performance with threshold beyond the simple trade-off of sensitivity and specificity. The value a can be used to plot a summary ROC (SROC) curve.

## Example
Consider a test with the following 2×2 confusion matrix:
| | Positive | Negative
| Positive | 26 | 3
| Negative | 12 | 48
We calculate the diagnostic odds ratio as:
$\text{DOR} = \frac{TP/FP}{FN/TN} = \frac{26/12}{3/48} = 34.666\ldots \approx 35$
This diagnostic odds ratio is greater than one, so we know that the test is discriminating correctly. We compute the confidence interval for the diagnostic odds ratio of this test as [9, 134].
