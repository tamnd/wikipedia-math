# Zeta distribution

## o1 subject: Zeta distribution

In probability theory and statistics, the zeta distribution is a discrete probability distribution. If X is a zeta-distributed random variable with parameter s, then the probability that X takes the positive integer value k is given by the probability mass function

## o3 definition: Definition

## Definition
The zeta distribution is defined for positive integers $k \geq 1$, and its probability mass function is given by
$$P(x=k) = \frac 1 {\zeta(s)} k^{-s},$$
where $s>1$ is the parameter, and $\zeta(s)$ is the Riemann zeta function.
The cumulative distribution function is given by
$$P(x \leq k) = \frac{H_{k,s}}{\zeta(s)},$$
where $H_{k,s}$ is the generalized harmonic number
$$H_{k,s} = \sum_{i=1}^k \frac 1 {i^s}.$$
