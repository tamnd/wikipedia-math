# Formation matrix

## o1 subject: Formation matrix

In statistics and information theory, the expected formation matrix and the observed formation matrix are concepts used to quantify the uncertainty associated with parameter estimates derived from a likelihood function $L(\theta)$. They are the matrix inverses of the Fisher information matrix and the observed information matrix, respectively.
