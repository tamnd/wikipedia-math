# Reye configuration

## o1 subject: Reye configuration

In geometry, the Reye configuration, introduced by , is a configuration of 12 points and 16 lines. Each point of the configuration belongs to four lines, and each line contains three points. Therefore, in the notation of configurations, the Reye configuration is written as $12_{4}16_{3}$. It is symmetric (both point and line transitive) and has 576 automorphisms.
