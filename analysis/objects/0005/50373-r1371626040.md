# Type B Cipher Machine

## o1 subject: Type B Cipher Machine

The "System 97 Typewriter for European Characters" (九七式欧文印字機 kyūnana-shiki ōbun injiki) or "Type B Cipher Machine", codenamed Purple by the United States, was an encryption machine used by the Japanese Foreign Office from February 1939 to the end of World War II. It replaced the Type A Red machine encrypt the most sensitive diplomatic traffic.
