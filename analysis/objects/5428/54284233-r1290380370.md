# Andrásfai graph

## o1 infobox: infobox graph

## o2 subject: Andrásfai graph

In graph theory, an Andrásfai graph is a triangle-free, circulant graph named after Béla Andrásfai.

## o3 section: Properties

## o4 statement/fact: Properties

## Properties
The Andrásfai graph $\operatorname{And}(n)$ for any natural number $n \ge 1$ is a circulant graph on $3n - 1$ vertices, in which vertex $k$ is connected by an edge to vertices $k \pm j$, for every $j$ that is congruent to 1 mod 3. For instance, the Wagner graph is an Andrásfai graph, the graph $\operatorname{And}(3)$.
The graph family is triangle-free, and $\operatorname{And}(n)$ has an independence number of $n$. From this the formula $R(3,n) \ge 3(n - 1)$ results, where $R(n,k)$ is the Ramsey number. The equality holds for $n = 3$ and $n = 4$ only.
The Andrásfai graphs were later generalized.
