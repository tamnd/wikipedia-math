# HP 30b

## o1 infobox: infobox calculator

## o2 subject: HP 30b

The HP 30b (NW238AA, variously codenamed "Big Euro", "Mid Euro" and "Fox") is a programmable financial calculator from HP which was released on 7 January 2010. The HP 30b is an advanced version of the HP's prior model HP&nbsp;20b. Featuring a two line alpha numeric display, ability to input data via Reverse Polish Notation, Algebraic and normal Chain algebraic methods, and twelve digit display.
