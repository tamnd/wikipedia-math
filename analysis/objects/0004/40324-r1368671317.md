# Quadratic programming

## o1 subject: Quadratic programming

Quadratic programming (QP) is the process of solving certain mathematical optimization problems involving quadratic functions. Specifically, one seeks to optimize (minimize or maximize) a multivariate quadratic function subject to linear constraints on the variables. Quadratic programming is a type of nonlinear programming.

### Generalizations
When minimizing a function $f$ in the neighborhood of some reference point $x_{0}$, $Q$ is set to its Hessian matrix $\mathbf{H}(f(\mathbf{x}_{0}))$ and $\mathbf{c}$ is set to its gradient $\nabla f(\mathbf{x}_{0})$. A related programming problem, quadratically constrained quadratic programming, can be posed by adding quadratic constraints on the variables.
