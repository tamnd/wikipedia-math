# Modified Richardson iteration

## o1 subject: Modified Richardson iteration

Modified Richardson iteration is an iterative method for solving a system of linear equations. Richardson iteration was proposed by Lewis Fry Richardson in work that was published in 1911. It is similar to the Jacobi and Gauss–Seidel method.
