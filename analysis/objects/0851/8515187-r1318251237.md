# Matrix-free methods

## o1 subject: Matrix-free methods

In computational mathematics, a matrix-free method is an algorithm for solving a linear system of equations or an eigenvalue problem that does not store the coefficient matrix explicitly, but accesses the matrix by evaluating matrix-vector products. Such methods can be preferable when the matrix is sufficiently large that storing and manipulating it would be prohibitively expensive with respect to memory or computation time, even with the use of methods for sparse matrices.
