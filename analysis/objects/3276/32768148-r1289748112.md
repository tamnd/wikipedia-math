# Bessel–Maitland function

## o1 subject: Bessel–Maitland function

In mathematics, the Bessel–Maitland function, or Wright generalized Bessel function, is a generalization of the Bessel function, introduced by . It allows to model more complex phenomena by providing solutions to a broader class of fractional-order differential equations than possible with standard Bessel functions.

## Definition
The function is given by
$J^{\mu,\nu}(z) = \sum_{k\ge 0} \frac{(-z)^k}{\Gamma(k\mu+\nu+1)k!}.$
