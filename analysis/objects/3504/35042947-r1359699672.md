# Trapezoidal rule (differential equations)

## o1 subject: Trapezoidal rule

In numerical analysis and scientific computing, the trapezoidal rule is a numerical method to solve ordinary differential equations derived from the trapezoidal rule for computing integrals. The trapezoidal rule is an implicit second-order method, which can be considered as both a Runge–Kutta method and a linear multistep method.

## o2 section: Method

## o3 definition/construction: Method

## Method
Suppose that we want to solve the differential equation
$$y' = f(t,y).$$
The trapezoidal rule is given by the formula
$$y_{n+1} = y_n + \tfrac 1 2 h \Big( f(t_n,y_n) + f(t_{n+1},y_{n+1}) \Big),$$
where $h = t_{n+1} - t_n$ is the step size.
This is an implicit method: the value $y_{n+1}$ appears on both sides of the equation, and to actually calculate it, we have to solve an equation which will usually be nonlinear. One possible method for solving this equation is Newton's method. We can use the Euler method to get a fairly good estimate for the solution, which can be used as the initial guess of Newton's method. Cutting short, using only the guess from Eulers method is equivalent to performing Heun's method.
