## o6 statement/theorem: Gross star theorem

## Gross star theorem
- Hypothesis: Let f be a meromorphic function which is the ratio of two entire functions. Suppose that z is a complex number which is not a singular point of f. Define w = f(z). Consider the germ Φz of the inverse of f, such that Φz(w) = z.
- Conclusion: Then the set { eiθ : 0 ≤ θ ≤ 2 π and Φz has an analytic continuation along the ray { w + r eiθ : 0 ≤ r < ∞ } } is equal to the unit circle, except for a set with Lebesgue measure zero.
