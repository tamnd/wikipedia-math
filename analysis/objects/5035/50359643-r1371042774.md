# Gijswijt's sequence

## o1 subject: Gijswijt's sequence

In mathematics, Gijswijt's sequence (named after Dion Gijswijt by Neil Sloane) is a self-describing sequence where each term counts the maximum number of repeated blocks of numbers in the sequence immediately preceding that term.

## o2 citation: OEIS

## o3 section: Definition

## o4 definition: Definition

## Definition
The process to generate terms in the sequence can be defined by looking at the sequence as a series of letters in the alphabet of natural numbers:
- $a(1) = 1$, and
- $a(n+1) = k$, where $k$ is the largest natural number such that the word $a(1)a(2)a(3)...a(n)$ can be written in the form $xy^k$ for some words $x$ and $y$, with $y$ having non-zero length.
The sequence is base-agnostic. That is, if a run of 10 repeated blocks is found, the next term in the sequence would be a single number 10, not a 1 followed by a 0.

## Properties
Only limited research has focused on Gijswijt's sequence. As such, very little has been proven about the sequence and many open questions remain unsolved.
### Average value
Though it is known that each natural number occurs at a finite position within the sequence, it has been shown that the sequence has a finite mean. To define this formally on an infinite sequence, where re-ordering of the terms may matter, it is known that
$\lim_{n \to \infty} \frac{1}{n} \sum_{i=1}^n a(i) \approx 1.904 < \infty$.
Likewise, it is known that any natural number has a positive density in the sequence.
### Rate of growth and first occurrences
In 2006 Gijswijt proved that the sequence contains every natural number. The sequence grows roughly super-logarithmically, with the first occurrence of any natural $n$ positioned at approximately $2^{2^{3^{4^{5^{.^{.^{.{n-1}}}}}}}}$. An expression for the earliest index at which a given positive integer $n$ appears was found by Levi van de Pol, in terms of a constant $\epsilon_1$ and a sequence of constants $\nu_k$.
For example, the position of the first 5 is given by
$\phi^{(1)}(5)=\lfloor 1-\epsilon_1+\epsilon_1\cdot 2^{418090195952691922788353} \rfloor$
where $\epsilon_1\approx 3.48669886438365597023$. Expanded out, this number is approximately
$3.2719044223289929745 \cdot 10^{125857689874791897769333} \approx 10^{10^{23.09987975598418}}$.
The first instance of two consecutive 4's starts at position
$255895648634818208370064452304769558261700170817472823398081655524438021806620809813295008281436789493636144 \approx 2.558956\cdot10^{107},$
as calculated by van de Pol.
### Recursive structure
The sequence can be broken into discrete "block" and "glue" sequences, which can be used to recursively build up the sequence. For example, at the base level, we can define $B_1=1$ and $S_1=2$ as the first block and glue sequences, respectively. Together, we can see how they form the beginning of the sequence:
$B_1B_1S_1 = 1, 1, 2$
The next step is to recursively build up the sequence. Define $B_2 = B_1B_1S_1$. Noting that the sequence starts with $B_1B_1$, we can define a glue string $S_2 = 2,2,3$ which gives:
$B_2B_2S_2 = 1, 1, 2, 1, 1, 2, 2, 2, 3$
We assigned $S_2$ to a particular sequence which gives the property that $B_2B_2S_2B_2B_2S_2$ also occurs at the top of the sequence.
This process can be continued indefinitely with $B_{n+1} = B_nB_nS_n$. It turns out that we can discover a glue string $S_n$ by noting that $S_n$ will never have a 1, and that it stops once it reaches the first 1 to follow $B_nB_n$. It has also been proven that Gijswijt's sequence can be built up in this fashion indefinitely ‒ that is, $B_n$ and $S_n$ are always finite in length for any $n$.
Clever manipulation of the glue sequences in this recursive structure can be used to demonstrate that Gijswijt's sequence contains all the natural numbers, among other properties of the sequence.
