# Cis (mathematics)

## o1 subject: Cis

Cisoidal oscillation
In mathematics, $\mathbf{cis}$ is a function defined by $\operatorname{cis} x = \cos x + i \sin x$, where $\cos$ is the cosine function, $i$ is the imaginary unit and $\sin$ is the sine function. $x$ is the argument of the complex number (angle between line to point and x-axis in polar form). It is mathematically equivalent to Euler's formula, $e^{ix}$, which offers an even shorter notation for $\cos x + i \sin x$, but cis(x) is widely used as a name for this function in software libraries.
