# Real projective line

## o1 subject: Real projective line

In geometry, a real projective line is a projective line over the real numbers. It is an extension of the usual concept of a line that has been historically introduced to solve a problem set by visual perspective: two parallel lines do not intersect but seem to intersect "at infinity". For solving this problem, points at infinity have been introduced, in such a way that in a real projective plane, two distinct projective lines meet in exactly one point. The set of these points at infinity, the "horizon" of the visual perspective in the plane, is a real projective line. It is the set of directions emanating from an observer situated at any point, with opposite directions identified.

## o2 section: Definition

## o3 definition: Definition

## Definition
The points of the real projective line are usually defined as equivalence classes of an equivalence relation. The starting point is a real vector space of dimension 2, $V$. Define on $V \setminus 0$ the binary relation $\mathbf{v} \sim \mathbf{w}$ to hold when there exists a nonzero real number $t$ such that $\mathbf{v} = t\mathbf{w}$. The definition of a vector space implies almost immediately that this is an equivalence relation. The equivalence classes are the vector lines from which the zero vector has been removed. The real projective line $\mathbf{P}(\mathbf{V})$ is the set of all equivalence classes. Each equivalence class is considered as a single point, or, in other words, a point is defined as being an equivalence class.
If one chooses a basis of $V$, this amounts (by identifying a vector with its coordinate vector) to identify $V$ with the direct product $\mathbf{R} \times \mathbf{R} = \mathbf{R}^{2}$, and the equivalence relation becomes $(x, y) \sim (w, z)$ if there exists a nonzero real number $t$ such that $(x, y) = (tw, tz)$. In this case, the projective line $\mathbf{P}(\mathbf{R}^{2})$ is preferably denoted $\mathbf{P}^{1}(\mathbf{R})$ or $\mathbb{R}\mathbb{P}^1$.
The equivalence class of the pair $(x, y)$ is traditionally denoted $[x: y]$, the colon in the notation recalling that, if $y \ne 0$, the ratio $x : y$ is the same for all elements of the equivalence class. If a point $P$ is the equivalence class $[x: y]$ one says that $(x, y)$ is a pair of projective coordinates of $P$.
As $\mathbf{P}(\mathbf{V})$ is defined through an equivalence relation, the canonical projection from $V$ to $\mathbf{P}(\mathbf{V})$ defines a topology (the quotient topology) and a differential structure on the projective line. However, the fact that equivalence classes are not finite induces some difficulties for defining the differential structure. These are solved by considering $\mathbf{V}$ as a Euclidean vector space. The circle of the unit vectors is, in the case of $\mathbf{R}^{2}$, the set of the vectors whose coordinates satisfy $x^{2} + y^{2} = 1$. This circle intersects each equivalence classes in exactly two opposite points. Therefore, the projective line may be considered as the quotient space of the circle by the equivalence relation such that $\mathbf{v} \sim \mathbf{w}$ if and only if either $\mathbf{v} = \mathbf{w}$ or $\mathbf{v} = -\mathbf{w}$.

## o17 statement/fact: Properties

### Properties
- Given two ordered triples of distinct points in $\mathbf{P}^{1}(\mathbf{R})$, there exists a unique element of $\operatorname{PGL}_{2}(\mathbf{R})$ mapping the first triple to the second; that is, the action is sharply 3-transitive. For example, the linear fractional transformation mapping $(0, 1, \infty)$ to $(-1, 0, 1)$ is the Cayley transform $x\mapsto \frac{x-1}{x+1}$.
- The stabilizer in $\operatorname{PGL}_{2}(\mathbf{R})$ of the point $\infty$ is the affine group of the real line, consisting of the transformations $x \mapsto ax+b$ for all $a \in \mathbf{R}^{*}$ and $b \in \mathbf{R}$.
