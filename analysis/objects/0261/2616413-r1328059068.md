# Erdős–Woods number

## o1 subject: Erdős–Woods number

In number theory, a positive integer $k$ is said to be an Erdős–Woods number if it has the following property:
there exists a positive integer $a$ such that in the sequence $(a, a + 1, \ldots, a + k)$ of consecutive integers, each of the elements has a non-trivial common factor with one of the endpoints. In other words, $k$ is an Erdős–Woods number if there exists a positive integer $a$ such that for each integer $i$ between $0$ and $k$, at least one of the greatest common divisors $\gcd(a, a + i)$ or $\gcd(a + i, a + k)$ is greater than $1$.
