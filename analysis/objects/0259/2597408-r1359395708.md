# Fekete's lemma

## o1 subject: Fekete's lemma

In mathematics, and in particular in calculus, Fekete's lemma (also called Fekete's subadditive lemma) is a lemma concerning the limit of subadditive sequences. The lemma provides an estimate for the linear growth rate of such sequences.

## o2 citation

## o3 section: Statement of the theorem

## o4 statement: Statement of the theorem

## Statement of the theorem
In this article, $\mathbb{N}$ denotes the natural numbers. This set does not include the number 0.
A sequence of real numbers $\{a_n\}_{n=1}^\infty$ is called a subadditive sequence if and only if for all $m,n\in\mathbb{N}$ one has
$a_{n+m}\le a_n+a_m.$
Fekete's lemma states that for every subadditive sequence,
$\lim_{n\to\infty}\frac{a_n}{n}=\inf_{n\in\mathbb{N}}\frac{a_n}{n}.$
That is, the sequence $\frac{a_n}{n}$ converges to its infimum. Note that this infimum may be $-\infty$.

## o5 section: Proof

## o6 proof: Proof

## Proof
To prove that the limit exists and equals the infimum, it suffices to show that
$\inf_{n\in\mathbb{N}}\frac{a_n}{n}\le \liminf_{n\to\infty}\frac{a_n}{n}\le \limsup_{n\to\infty}\frac{a_n}{n}\le \inf_{n\in\mathbb{N}}\frac{a_n}{n},$
where $\liminf$ and $\limsup$ denote the limit inferior and limit superior, respectively. The two left inequalities always hold, so it is enough to prove the rightmost inequality
$\limsup_{n\to\infty}\frac{a_n}{n}\le \inf_{n\in\mathbb{N}}\frac{a_n}{n}.$
Since the sequence is subadditive, one can prove by induction that for all $m,n,l,k\in\mathbb{N}$,
$a_{nl+mk}\le na_l+ma_k.$
Define $a_0=0$. Then this inequality also holds when one of the indices $m,n,l,k$ is 0.
Now fix some $q\in\mathbb{N}$. For every $n\in\mathbb{N}$ there exist $m\in\mathbb{N}$ and $0\le r\le q-1$ such that $n=mq+r$. Hence, by the inequality above,
$a_n\le ma_q+a_r.$
Define $C_q=\max(a_0,a_1,\dots,a_{q-1})$. Dividing the inequality above by $n$ yields
$\frac{a_n}{n}\le \frac{ma_q+a_r}{n}
= \frac{ma_q}{n}+\frac{a_r}{n}
\le \frac{ma_q}{mq}+\frac{C_q}{n}
= \frac{a_q}{q}+\frac{C_q}{n}.$
Taking the limit superior as $n\to\infty$, we obtain $\limsup_{n\to\infty}\frac{a_n}{n}\le \frac{a_q}{q}.$
Since $q$ was arbitrary, this holds for all $q$, and therefore
$\limsup_{n\to\infty}\frac{a_n}{n}\le \inf_{n\in\mathbb{N}}\frac{a_n}{n}.$
Combining the inequalities, we conclude that
$\lim_{n\to\infty}\frac{a_n}{n}=\inf_{n\in\mathbb{N}}\frac{a_n}{n}.$
∎

## o7 section: Examples

## o8 example: Examples

## Examples
### Square root
Define a sequence $\{a_n\}_{n=1}^\infty$ by, for all $n\in\mathbb{N}$,
$a_n:=n+\sqrt{n}.$
One can show that this sequence is subadditive, since for all $n,m\in\mathbb{N}$,
$a_{n+m}=n+m+\sqrt{n+m}
\le n+m+\sqrt{n}+\sqrt{m}
= a_n+a_m.$
Indeed,
$\lim_{n\to\infty}\frac{a_n}{n}
= \inf_{n\in\mathbb{N}}\frac{a_n}{n}
= \inf_{n\in\mathbb{N}}\frac{n+\sqrt{n}}{n}
= 1.$
### Integer value
Let $0<c\in\mathbb{R}$. Define a sequence $\{a_n\}_{n=1}^\infty$ by, for all $n\in\mathbb{N}$,
$a_n:=\lceil cn\rceil,$
where $\lceil\cdot\rceil$ denotes the ceiling function. The sequence is subadditive, since for all $n,m\in\mathbb{N}$,
$a_{n+m}
= \lceil c(n+m)\rceil
= \lceil cn+cm\rceil
\le \lceil cn\rceil+\lceil cm\rceil
= a_n+a_m.$
Indeed,
$\lim_{n\to\infty}\frac{a_n}{n}
= \inf_{n\in\mathbb{N}}\frac{a_n}{n}
= \inf_{n\in\mathbb{N}}\frac{\lceil cn\rceil}{n}
= c.$

## o17 proof: Proof

#### Proof
Define a new sequence $b_n:=a_n+C$. It is subadditive, since
$b_{n+m}
= a_{n+m}+C
\le a_n+a_m+C+C
= b_n+b_m.$
Therefore,
$\lim_{n\to\infty}\frac{b_n}{n}
= \inf_{n\in\mathbb{N}}\frac{b_n}{n}
= \inf_{n\in\mathbb{N}}\frac{a_n+C}{n}.$
On the other hand,
$\left|\frac{b_n}{n}-\frac{a_n}{n}\right|
= \frac{C}{n}\to 0,$
so the two sequences have the same limit. Hence,
$\lim_{n\to\infty}\frac{a_n}{n}
= \inf_{n\in\mathbb{N}}\frac{a_n+C}{n}.$
∎
