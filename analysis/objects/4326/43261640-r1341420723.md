# Atlantic City algorithm

## o1 subject: Atlantic City algorithm

In computing, an Atlantic City algorithm is a randomized algorithm that answers correctly at least 75% of the time. In some variant definitions, the correctness threshold may be any value greater than 50%. In either sense, Atlantic City algorithms are types of Monte Carlo algorithms.
