# Lehmer's totient problem

## o1 subject: Lehmer's totient problem

Can the totient function of a composite number $n$ divide $n-1$?
In mathematics, Lehmer's totient problem asks whether there is any composite number $n$ such that Euler's totient function $\varphi(n)$ divides $n - 1$. This is an unsolved problem.
