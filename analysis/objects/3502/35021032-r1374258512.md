## o5 statement/conjecture: Sum-product conjecture

## Sum-product conjecture
The sum-product conjecture informally says that one of the sum set or the product set of any set must be nearly as large as possible. It was originally conjectured by Erdős in 1974 to hold whether $A$ is a set of integers, reals, or complex numbers. More precisely, it proposes that, for any set $A\subset\mathbb{C}$, one has
$$\max(|A+A|,|A \cdot A|) \geq |A|^{2-o(1)}.$$
The asymptotic parameter in the $o(1)$ little o notation is $|A|$.
### Disproving the conjecture
This conjecture was disproved over the reals (and hence the complex numbers) in 2026 by Bloom, Sawin, Schildkraut, and Zhelezov, who constructed arbitrarily large sets $A\subset R$ of algebraic integers in number fields of degree proportional to $\log|A|$ such that
$$\max(|A+A|,|A \cdot A|) \leq |A|^{2-c}$$
for an absolute constant $c>0$. The same paper disproves the many sums and products conjecture and obtains analogous constructions over $p$-adic numbers, finite fields, and function fields in positive characteristic. The conjecture remains open over the integers.

## Examples
If $A=\{1,2,3,\dots,n\}$, then $|A+A|=2|A|-1\emptyset(|A|)$ using Big O notation, with $|A|$ the asymptotic parameter. Informally, this says that the sum set of $A$ grows only proportionally to $A$. On the other hand, the product set of $A$ satisfies a bound of the form $|A\cdot A|\ge|A|^{2-\varepsilon}$ for all $\varepsilon>0$ and all sufficiently large $n$. This is related to the Erdős multiplication table problem. The best lower bound on $|A\cdot A|$ for this set is due to Kevin Ford.
This example is an instance of the few sums, many products version of the sum-product problem of György Elekes and Imre Z. Ruzsa. A consequence of their result is that any set with a small sumset (such as an arithmetic progression) has the lower bound on the product set
$$|A\cdot A|=\Omega\left(|A|^2\log^{-1}|A|\right).$$
Xu and Zhou proved more strongly that
$$|A\cdot A|=\Omega\left(|A|^2\log^{1-2\log 2-o(1)}|A|\right)$$
for any dense subset $A$ of an arithmetic progression in integers, which is sharp up to the $o(1)$ in the exponent.
As an example for the corresponding few products, many sums version of the problem, the set $B=\{2,4,8,\dots,2^n\}$ satisfies $|B\cdot B=2|B|-1$ but has many sums: $|B+B| = \tbinom{|B|+1}{2}$. This bound comes from considering the binary representation of a number. The set $B$ is an example of a geometric progression.
For a random set of $n$ numbers, both the product set and the sumset have cardinality $\tbinom{n+1}{2}$; that is, with high probability, neither the sumset nor the product set generates repeated elements.
### Sharpness of the conjecture
Erdős and Szemerédi give an example of a sufficiently smooth set of integers $A$ with the bound
$$\max\{|A+A|,|A\cdot A|\} \leq |A|^{2} e^{-\frac{c \log|A|}{\log\log|A|} }.$$
This shows that the $o(1)$ term in the conjecture is necessary.
### Extremal cases
Often studied are the extreme cases of the hypothesis:
- few sums, many product (FSMP): if $|A+A\ll|A|$, then $|A\cdot A|\ge|A|^{2-o(1)}$, and
- few products, many sums (FPMS): if $|A\cdot A|\ll|A|$, then $|A+A|\ge|A|^{2-o(1)}$.

## o38 example: Example

Example: Let $\mathbb{F}$ be a finite field and take $A=\mathbb{F}$. Then since $\mathbb{F}$ is closed under addition and multiplication, $A+A=A\cdot A=\mathbb{F}$, and so $|A+A|=|A\cdot A|=|A|$. This pathological example extends to taking $A$ to be any sub-field of the field in question.
Qualitatively, the sum-product problem has been solved over finite fields:

## o39 statement/theorem: Theorem

Theorem (Bourgain, Katz, Tao (2004)): Let $p$ be prime and let $A\subset\mathbb{F}_p$ with $p^{\delta}<|A|<p^{1-\delta}$ for some $0<\delta<1$. Then $\max(|A+A|,|A\cdot A|)\ge c_\delta|A|^{1+\varepsilon}$ for some $\varepsilon=\varepsilon(\delta)>0$.
Bourgain, Katz, and Tao extended this theorem to arbitrary fields. Informally, the following theorem says that if a sufficiently large set does not grow under either addition or multiplication, then it is mostly contained in a dilate of a sub-field.

## o40 citation: :3

## o41 statement/theorem: Theorem

Theorem (Bourgain, Katz, Tao (2004)): Let $A$ be a subset of a finite field $\mathbb{F}$ so that $|A|>|\mathbb{F}|^{\delta}$ for some $0<\delta<1$, and suppose that $|A+A|,|A\cdot A|\le K|A|$. Then there exists a sub-field $G\subset \mathbb{F}$ with $|G|\le K^{C_\delta}|A|$, an element $x\in\mathbb{F}\setminus\{0\}$, and a set $X\subset \mathbb{F}$ with $|X|\le K^{C_\delta}$ so that $A\subseteq xG\cup X$.
They suggest that the constant $C_\delta$ may be independent of $\delta$.
Quantitative results towards the finite field sum-product problem in $\mathbb{F}$ typically fall into two categories: when $A\subset\mathbb{F}$ is small or large with respect to the characteristic of $\mathbb{F}$. This is because different types of techniques are used in each setting.

## o57 statement/theorem: Theorem

Theorem (Bourgain, Chang (2003)): Let $b\in\mathbb{N}$. Then there exists $k\in\mathbb{N}$ so that for all $A\subset\mathbb{Z}$, one has
$$\begin{aligned}\max\left(|kA|,|A^{(k)}|\right)
&=\max\left(|A+A+\cdots+A|,|A\cdot A\cdot\cdots\cdot A|\right)\\
&\ge|A|^b.
\end{aligned}$$
In many works, addition and multiplication are combined in one expression. With the motto addition and multiplication cannot coexist, one expects that any non-trivial combination of addition and multiplication of a set should guarantee growth. Note that in finite settings, or in fields with non-trivial subfields, such a statement requires further constraints.
Sets of interest include (results for $A\subset\mathbb{R}$):
- $A\cdot A+A$: Stevens and Warren show that
$$|A\cdot A+A|\gg|A|^{\tfrac{3}{2}+\tfrac{3}{170}-o(1)}.$$
- $A\cdot(A+A)$: Murphy, Roche-Newton and Shkredov show that
$$\left|A\cdot(A+A)\right|\gg|A|^{\tfrac{3}{2}+\tfrac{5}{242}-o(1)}.$$
- $A\cdot(A+1)$: Stevens and Warren show that
$$\left|A\cdot(A+1)\right|\gg|A|^{\tfrac{49}{38}-o(1)}.$$
- $(A\cdot A)+(A\cdot A)$: Stevens and Rudnev show that
$$\left|(A\cdot A)+(A\cdot A)\right|\gg|A|^{\tfrac{127}{80}-o(1)}.$$
