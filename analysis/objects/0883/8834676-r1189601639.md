# Truncated triheptagonal tiling

## o1 subject: Truncated triheptagonal tiling

In geometry, the truncated triheptagonal tiling is a semiregular tiling of the hyperbolic plane. There is one square, one hexagon, and one tetradecagon (14-sides) on each vertex. It has Schläfli symbol of $\operatorname{tr}\{7,3\}.$

## Symmetry
Each triangle in this dual tiling, order 3-7 kisrhombille, represent a fundamental domain of the Wythoff construction for the symmetry group [7,3].
