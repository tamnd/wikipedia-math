# Wolff algorithm

## o1 subject: Wolff algorithm

The Wolff algorithm (Modified Swendsen-Wang algorithm), is an algorithm for Monte Carlo simulation of the Ising model and Potts model in which the unit to be flipped is not a single spin (as in the heat bath or Metropolis algorithms) but a cluster of them. This cluster is defined as the set of connected spins sharing the same spin states, based on the Fortuin-Kasteleyn representation.
