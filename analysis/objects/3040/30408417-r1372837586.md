# Bivariate analysis

## o1 subject: Bivariate analysis

Bivariate analysis is one of the simplest forms of quantitative (statistical) analysis. It involves the analysis of two variables (often denoted as X, Y), for the purpose of determining the empirical relationship between them.

Pearson correlation coefficient
| Value | Correlation type | Interpretation | Example
| Between 0 and 1 | Positive | When one variable changes, the other variable changes in the same direction. | Time spent running and calories burnt
| 0 | No correlation | There is no relationship between the variables. | Amount of tea drank and the price of kiwis
