# Stacks Project

## o1 subject: Stacks Project

The Stacks Project is an open source collaborative mathematics textbook writing project with the aim to cover "algebraic stacks and the algebraic geometry needed to define them". , the book consists of 116 chapters (excluding the
license and index chapters) spreading over 7500 pages. The maintainer of the project, who reviews and accepts the changes, is Aise Johan de Jong.
