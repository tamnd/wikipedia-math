# Controllability Gramian

## o1 subject: Controllability Gramian

In control theory, we may need to find out whether or not a system such as
$$\begin{aligned}
\dot{\boldsymbol{x}}(t) &= \boldsymbol{Ax}(t) + \boldsymbol{Bu}(t) \\
\boldsymbol{y}(t) &= \boldsymbol{Cx}(t) +\boldsymbol{Du}(t)
\end{aligned}$$
is controllable, where $\boldsymbol{A}$, $\boldsymbol{B}$, $\boldsymbol{C}$ and $\boldsymbol{D}$ are, respectively, $n\times n$, $n\times p$, $q\times n$ and $q\times p$ matrices for a system with $p$ inputs, $n$ state variables and $q$ outputs.

## o5 statement/fact: Properties

### Properties
We can see that $\boldsymbol{BB^{T}}$ is a symmetric matrix, therefore, so is $\boldsymbol{W}_{c}$.
We can use again the fact that, if $\boldsymbol{A}$ is stable (all its eigenvalues have negative real part) to show that $\boldsymbol{W}_{c}$ is unique. In order to prove so, suppose we have two different solutions for
$$\boldsymbol{A} \boldsymbol{W}_{c} + \boldsymbol{W}_{c} \boldsymbol{A}^{T} = -\boldsymbol{BB}^{T}$$
and they are given by $\boldsymbol{W}_{c1}$ and $\boldsymbol{W}_{c2}$. Then we have:
$$\boldsymbol{A} (\boldsymbol{W}_{c1} - \boldsymbol{W}_{c2}) + (\boldsymbol{W}_{c1} - \boldsymbol{W}_{c2})\boldsymbol{A}^{T} = \boldsymbol{0}$$
Multiplying by $e^{\boldsymbol{A}t}$ by the left and by $e^{\boldsymbol{A}^{T}t}$ by the right, would lead us to
$$e^{\boldsymbol{A}t} \left[\boldsymbol{A}(\boldsymbol{W}_{c1}-\boldsymbol{W}_{c2}) + \boldsymbol{(W}_{c1}-\boldsymbol{W}_{c2})\boldsymbol{A}^{T}\right] e^{\boldsymbol{A}^{T}t}
= \frac{d}{dt} \left[e^{\boldsymbol{A}t} \left(\boldsymbol{W}_{c1}-\boldsymbol{W}_{c2}\right) e^{\boldsymbol{A^{T}}t}\right]
= \boldsymbol{0}$$
Integrating from $0$ to $\infty$:
$$\left[e^{\boldsymbol{A}t} \left(\boldsymbol{W}_{c1} - \boldsymbol{W}_{c2}\right) e^{\boldsymbol{A}^{T}t}\right]_{t=0}^{\infty} = \boldsymbol{0}$$
using the fact that $e^{\boldsymbol{A}t}\rightarrow0$ as $t\to\infty$:
$$\boldsymbol{0}-(\boldsymbol{W}_{c1}-\boldsymbol{W}_{c2})=\boldsymbol{0}$$
In other words, $\boldsymbol{W}_{c}$ has to be unique.
Also, we can see that
$$\boldsymbol{x}^{T}\boldsymbol{W}_{c}\boldsymbol{x}
= \int_{0}^{\infty} \boldsymbol{x}^{T}e^{\boldsymbol{A}t}\boldsymbol{BB}^{T}e^{\boldsymbol{A}^{T}t}\boldsymbol{x} \, dt
= \int_{0}^{\infty} \left\Vert \boldsymbol{B}^{T}e^{\boldsymbol{A}^{T}t}\boldsymbol{x}\right\Vert _{2}^{2}dt$$
is positive for any t (assuming the non-degenerate case where $\left\Vert \boldsymbol{B}^{T}e^{\boldsymbol{A}^{T}t} \boldsymbol{x}\right\Vert$ is not identically zero). This makes $\boldsymbol{W}_{c}$ a positive definite matrix.
More properties of controllable systems can be found in , as well as the proof for the other equivalent statements of “The pair $(\boldsymbol{A},\boldsymbol{B})$ is controllable” presented in section Controllability in LTI Systems.
