# Univariate (statistics)

## o1 subject: Univariate

Univariate is a term commonly used in statistics to describe a type of data which consists of observations on only a single characteristic or attribute. A simple example of univariate data would be the salaries of workers in industry. Similar to other data, univariate data can be visualized using graphs, images, or other analysis tools after the data is observed/collected, analyzed and reported with conclusions of the analysis.
