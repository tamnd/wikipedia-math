# Akelarre (cipher)

## o1 infobox: infobox block cipher

## o2 subject: Akelarre

Akelarre is a block cipher proposed in 1996, combining the basic design of IDEA with ideas from RC5. It was shown to be susceptible to a ciphertext-only attack in 1997.
