# Parameter space

## o1 subject: Parameter space

The parameter space is the space of all possible parameter values that define a particular mathematical model. It is also sometimes called weight space, and is often a subset of finite-dimensional Euclidean space.

## o4 example: Examples

## Examples
- A simple model of health deterioration after developing lung cancer could include the two parameters gender and smoker/non-smoker, in which case the parameter space is the following set of four possibilities: $\{(\operatorname{Male}, \operatorname{Smoker}), (\operatorname{Male}, \operatorname{Non}-\operatorname{smoker}), (\operatorname{Female}, \operatorname{Smoker}), (\operatorname{Female}, \operatorname{Non}-\operatorname{smoker})\}$.
- The logistic map $x_{n+1} = r x_n (1-x_n)$ has one parameter, r, which can take any positive value. The parameter space is therefore positive real numbers.
For some values of r, this function ends up cycling around a few values or becomes fixed on one value. These long-term values can be plotted against r in a bifurcation diagram to show the different behaviours of the function for different values of r.
- In a sine wave model $y(t) = A \cdot \sin(\omega t + \phi),$ the parameters are amplitude A > 0, angular frequency ω > 0, and phase φ ∈ S1. Thus the parameter space is $R^+ \times R^+ \times S^1 .$
- In complex dynamics, the parameter space is the complex plane C = { z = x + y i : x, y ∈ R }, where i2 = −1.
The famous Mandelbrot set is a subset of this parameter space, consisting of the points $c$ in the complex plane which give a bounded set of numbers when a iterated function $z_{n+1} = f_c(z_n) = z^2+c$ is repeatedly applied from that starting point $z_0 = 0$. The remaining points, which are not in the set, give an unbounded set of numbers (they tend to infinity) when this function is repeatedly applied from that $z_0$.
- In machine learning, hyperparameters are used to describe models. In deep learning, the parameters of a deep network are called weights. Due to the layered structure of deep networks, their weight space has a complex structure and geometry. For example, in multilayer perceptrons, the same function is preserved when permuting the nodes of a hidden layer, amounting to permuting weight matrices of the network. This property is known as equivariance to permutation of deep weight spaces. The study seeks hyperparameter optimization.
