# Parametric model

## o1 subject: Parametric model

In statistics, a parametric model or parametric family or finite-dimensional model is a particular class of statistical models. Specifically, a parametric model is a family of probability distributions that has a finite number of parameters.

## o2 section: Definition

## o3 definition: Definition

## Definition
A statistical model is a collection of probability distributions on some sample space. We assume that the collection, $\mathcal{P}$, is indexed by some set $\Theta$. The set $\Theta$ is called the parameter set or, more commonly, the parameter space. For each $\theta \in \Theta$, let $F_{\theta}$ denote the corresponding member of the collection; so $F_{\theta}$ is a cumulative distribution function. Then a statistical model can be written as
$\mathcal{P} = \big\{ F_\theta\ \big|\ \theta\in\Theta \big\}.$
The model is a parametric model if $\Theta \subseteq \mathbb{R}^{k}$ for some positive integer $k$.
When the model consists of absolutely continuous distributions, it is often specified in terms of corresponding probability density functions:
$\mathcal{P} = \big\{ f_\theta\ \big|\ \theta\in\Theta \big\}.$

## o4 section: Examples

## o5 example: Examples

## Examples
- The Poisson family of distributions is parametrized by a single number $\lambda > 0$:
$\mathcal{P} = \Big\{\ p_\lambda(j) = \tfrac{\lambda^j}{j!}e^{-\lambda},\ j=0,1,2,3,\dots \ \Big|\;\; \lambda>0 \ \Big\},$
where $p_{\lambda}$ is the probability mass function. This family is an exponential family.
- The normal family is parametrized by $\theta = (\mu, \sigma)$, where $\mu \in \mathbb{R}$ is a location parameter and $\sigma > 0$ is a scale parameter:
$\mathcal{P} = \Big\{\ f_\theta(x) = \tfrac{1}{\sqrt{2\pi}\sigma} \exp\left(-\tfrac{(x-\mu)^2}{2\sigma^2}\right)\ \Big|\;\; \mu\in\mathbb{R}, \sigma>0 \ \Big\}.$
This parametrized family is both an exponential family and a location-scale family.
- The Weibull translation model has a three-dimensional parameter $\theta = (\lambda, \beta, \mu)$:
$\mathcal{P} = \Big\{\
f_\theta(x) = \tfrac{\beta}{\lambda}
\left(\tfrac{x-\mu}{\lambda}\right)^{\beta-1}\!
\exp\!\big(\!-\!\big(\tfrac{x-\mu}{\lambda}\big)^\beta \big)\,
\mathbf{1}_{\{x>\mu\}}
\ \Big|\;\;
\lambda>0,\, \beta>0,\, \mu\in\mathbb{R}
\ \Big\},$
where $\beta$ is the shape parameter, $\lambda$ is the scale parameter and $\mu$ is the location parameter.
- The binomial model is parametrized by $\theta = (n, p)$, where $n$ is a non-negative integer and $p$ is a probability (i.e. $p \ge 0$ and $p \le 1$):
$\mathcal{P} = \Big\{\ p_\theta(k) = \tfrac{n!}{k!(n-k)!}\, p^k (1-p)^{n-k},\ k=0,1,2,\dots, n \ \Big|\;\; n\in\mathbb{Z}_{\ge 0},\, p \ge 0 \land p \le 1\Big\}.$
This example illustrates the definition for a model with some discrete parameters.
