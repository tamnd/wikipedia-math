# Fulton–MacPherson compactification

## o1 subject: Fulton–MacPherson compactification

In geometry, the Fulton–MacPherson compactification of the configuration space of n distinct labeled points in a compact complex manifold is a compact complex manifold that contains the configuration space as an open dense subset and is constructed in a canonical way.
