# Statistical data type

## o1 subject: Statistical data type

In statistics, data can have any of various types. Statistical data types include categorical (e.g. country), directional (angles or directions, e.g. wind measurements), count (a whole number of events), or real intervals (e.g. measures of temperature).

| binomial | 0, 1, ..., N | Number of successes (e.g. yes votes) out of N possible | rowspan=2 interval scale | binomial, beta-binomial | rowspan=2 additive | mean, median, mode, standard deviation, correlation | binomial regression (logistic, probit)
