# H-matrix (iterative method)

## o1 subject: H-matrix

In mathematics, an H-matrix is a matrix whose comparison matrix is an M-matrix. It is useful in iterative methods.

## o2 definition: Definition

Definition: Let $A = (a_{ij})$ be a $n \times n$ complex matrix. Then comparison matrix M(A) of complex matrix A is defined as $M(A) = \alpha_{ij}$ where $\alpha_{ij} = -|A_{ij}|$ for all $i \ne j, 1 \le i,j \le n$ and $\alpha_{ij} = |A_{ij}|$ for all $i = j, 1 \le i,j \le n$. If M(A) is a M-matrix, A is a H-matrix.
Invertible H-matrix guarantees convergence of Gauss–Seidel iterative methods.
