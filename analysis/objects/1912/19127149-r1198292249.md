# Primitive element (finite field)

## o1 subject: Primitive element

In field theory, a primitive element of a finite field $\operatorname{GF}(q)$ is a generator of the multiplicative group of the field. In other words, $\alpha \in \operatorname{GF}(q)$ is called a primitive element if it is a primitive $(q - 1)$th root of unity in $\operatorname{GF}(q)$; this means that each non-zero element of $\operatorname{GF}(q)$ can be written as $\alpha^{i}$ for some natural number $i$.

## o3 statement/fact: Properties

## Properties
### Number of primitive elements
The number of primitive elements in a finite field $\operatorname{GF}(q)$ is $\varphi(q - 1)$, where $\varphi$ is Euler's totient function, which counts the number of elements less than or equal to $m$ that are coprime to $m$. This can be proved by using the theorem that the multiplicative group of a finite field $\operatorname{GF}(q)$ is cyclic of order $q - 1$, and the fact that a finite cyclic group of order $m$ contains $\varphi(m)$ generators.
