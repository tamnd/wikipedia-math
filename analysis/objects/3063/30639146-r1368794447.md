# Wiener's attack

## o1 subject: Wiener's attack

The Wiener's attack, named after cryptologist Michael J. Wiener, is a type of cryptographic attack against RSA. The attack uses continued fraction representation to expose the private key d when d is small.

## o7 statement/theorem: Wiener's theorem

## Wiener's theorem
Let N = pq with q < p < 2q. Let d < $\tfrac{1}{3}$N1/4.
Given $\langle N, e\rangle$ with ed ≡ 1 (mod λ(N)), the attacker can efficiently recover d.

## Example
section
Suppose that the public keys are $\langle N, e\rangle$ = $\langle 90581, 17993\rangle$. The attack should determine d. By using Wiener's theorem and continued fractions to approximate d, first we try to find the continued fractions expansion of $\tfrac{e}{N}$. Note that this algorithm finds fractions in their lowest terms. We know that
$\frac{e}{N} = \frac{17993}{90581} = \cfrac{1}{5 + \cfrac{1}{29 +\dots + \cfrac{1}{3}}} = \left [0,5,29,4,1,3,2,4,3 \right ]$
According to the continued fractions expansion of $\tfrac{e}{N}$, all convergents $\tfrac{k}{d}$ are:
$\frac{k}{d} = 0, \frac{1}{5}, \frac{29}{146}, \frac{117}{589}, \frac{146}{735}, \frac{555}{2794}, \frac{1256}{6323}, \frac{5579}{28086}, \frac{17993}{90581}$
We can verify that the first convergent does not produce a factorization of N. However, the convergent $\tfrac{1}{5}$ yields
$\varphi (N) = \frac{ed - 1}{k} = \frac{17993\times5 - 1}{1} = 89964$
Now, if we solve the equation
$x^2 - \left ( \left (N - \varphi (N) \right ) + 1 \right )x + N = 0$
$x^2 - \left ( \left (90581 - 89964 \right ) + 1 \right )x + 90581 = 0$
$x^2 - 618x + 90581 = 0$
then we find the roots which are x = 379; 239. Therefore we have found the factorization
$N = 90581 = 379 \times 239 = p \times q$.
Notice that, for the modulus N = 90581, Wiener's theorem will work if
$d < \frac{N^{1/4}}{3} \approx 5.7828$.

## o13 proof: Proof of Wiener's theorem

## Proof of Wiener's theorem
The proof is based on approximations using continued fractions.
Since ed = 1 (mod λ(N)), there exists a k such that ed − kλ(N) = 1. Therefore
$\left | \frac {e}{\lambda (N)}- \frac {k}{d} \right \vert = \frac{1}{d \lambda (N)}$.
Let G = gcd(p − 1, q − 1); note that if φ(N) is used instead of λ(N), then the proof can be replaced with G = 1 and φ(N) replaced with λ(N).
Then multiplying by $\tfrac{1}{G}$,
$\left | \frac {e}{\varphi (N)}- \frac {k}{Gd} \right \vert = \frac{1}{d \varphi (N)}$
Hence, $\tfrac{k}{Gd}$ is an approximation of $\tfrac{e}{\varphi(N)}$. Although the attacker does not know φ(N), he may use N to approximate it. Indeed, since φ(N) = N − p − q + 1 and p + q − 1 < 3$\sqrt{N}$, we have:
$\left \vert p+q-1 \right \vert < 3 \sqrt{N}$
$\left \vert N-\varphi (N) \right \vert < 3 \sqrt{N}$
Using N in place of φ(N) we obtain:
$\begin{aligned}
\left \vert \frac{e}{N}- \frac{k}{Gd} \right \vert &= \left \vert \frac{edG-kN}{NGd} \right \vert \\
&= \left \vert \frac{edG-k \varphi (N)-kN+k \varphi (N)}{NGd} \right \vert \\
&= \left \vert \frac{1-k(N- \varphi (N))}{NGd} \right \vert \\
&< \left \vert \frac{-k(N- \varphi (N))}{NGd} \right \vert (\because 0 < |N-\varphi (N)|)\\
&< \left \vert \frac{3k \sqrt{N}}{NGd} \right \vert = \frac {3k \sqrt{N}}{\sqrt{N} \sqrt{N}Gd} \le \frac {3k}{d \sqrt{N}}
\end{aligned}$
Now, kλ(N) = ed − 1 < ed, so kλ(N) < ed. Since e < λ(N), so kλ(N) < ed < λ(N)d, then we obtain:
$k \lambda (N)<\lambda (N)d$
$k<d$
Since k < d and d < $\tfrac{1}{3}$N1/4.
Hence we obtain:
(1) $\left \vert \frac{e}{N}- \frac{k}{Gd} \right \vert < \frac{1}{dN^{\frac{1}{4}}}$
Since d < $\tfrac{1}{3}$N1/4, 2d < 3d, then 2d < 3d < N1/4, we obtain:
$2d<N^{1/4}$, so (2) $\frac{1}{2d} > \frac{1}{N^{1/4}}$
From (1) and (2), we can conclude that
$\left \vert \frac{e}{N}- \frac{k}{Gd} \right \vert < \frac{3k}{d \sqrt{N}}< \frac{1}{d \cdot 2d}= \frac{1}{2d^2}$
If $\lvert x - \tfrac{a}{b}\rvert$ < $\tfrac{1}{2b^{2}}$, then $\tfrac{a}{b}$ is a convergent of x, thus $\tfrac{k}{Gd}$ appears among the convergents of $\tfrac{e}{N}$. Therefore the algorithm will indeed eventually find $\tfrac{k}{Gd}$.
