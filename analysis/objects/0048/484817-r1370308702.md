# Nominal category

## o1 subject: Nominal category

In statistics, a nominal category (also nominal variable or nominal group) is a collection of objects or ideas grouped according to a particular qualitative property. Nominal categories do not have a natural order, which means that statistical analyses of these variables will always produce the same results, regardless of the order in which the data is presented.
