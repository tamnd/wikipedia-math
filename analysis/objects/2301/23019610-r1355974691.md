# Snellius–Pothenot problem

## o1 subject: Snellius–Pothenot problem

The Snellius–Pothenot problem is a trigonometry problem first described in the context of planar surveying where known points are used to solve an unknown one. Given three known points $A, B, C$, can the location of an observer at an unknown point $P$ be found?
Given these points, and that $C$ is between $A$ and $B$ as seen from $P$, an observer at P can resolve that the line segment $\overline{AC}$ subtends an angle $\alpha$ and the segment $\overline{CB}$ subtends an angle $\beta$; the solution to establishing the position of the point $P$ can be variously found through graphical geometry, rational trigonometry, and geometric algebra.
