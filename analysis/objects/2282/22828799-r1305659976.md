# Unknown key-share attack

## o1 subject: Unknown key-share attack

As defined by , an unknown key-share (UKS) attack on an authenticated key agreement (AK) or authenticated key agreement with key confirmation (AKC) protocol is an attack whereby an entity $A$ ends up believing she shares a key with $B$, and although this is in fact the case, $B$ mistakenly believes the key is instead shared with an entity $E \neq A$.
