# Alpha shape

## o1 subject: Alpha shape

In computational geometry, an alpha shape, or α-shape, is a family of piecewise linear simple curves in the Euclidean plane associated with the shape of a finite set of points. They were first defined by . The alpha-shape associated with a set of points is a generalization of the concept of the convex hull, i.e., every convex hull is an alpha-shape but not every alpha shape is a convex hull.

## o4 statement/fact: Characterization

## Characterization
For each real number $\alpha$, define the concept of a generalized disk of radius $1/\alpha$ as follows:
- If $\alpha=0$, it is a closed half-plane;
- If $\alpha>0$, it is a closed disk of radius $1/\alpha$;
- If $\alpha<0$, it is the closure of the complement of a disk of radius $-1/\alpha$.
Then, an edge of the alpha-shape is drawn between two members of the finite point set whenever there exists a generalized disk of radius $1/\alpha$ that has the two points on its boundary and that contains none of the point set in its interior.
If $\alpha=0$, then the alpha-shape associated with the finite point set is its ordinary convex hull.

## Examples
This technique can be employed to reconstruct a Fermi surface from the electronic Bloch spectral function evaluated at the Fermi level, as obtained from the Green's function in a generalised ab-initio study of the problem. The Fermi surface is then defined as the set of reciprocal space points within the first Brillouin zone, where the signal is highest.
The definition has the advantage of covering also cases of various forms of disorder.
