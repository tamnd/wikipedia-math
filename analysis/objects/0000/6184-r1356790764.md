# Co-NP

## o1 subject: Co-NP

In computational complexity theory, co-NP is a complexity class. A decision problem X is a member of co-NP if and only if its complement $\overline{X}$ is in the complexity class NP. The class can be defined as follows: a decision problem is in co-NP if and only if for every no-instance we have a polynomial-length "certificate" and there is a polynomial-time algorithm that can be used to verify any purported certificate.
