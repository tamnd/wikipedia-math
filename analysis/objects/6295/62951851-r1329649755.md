# Random recursive tree

## o1 subject: Random recursive tree

In probability theory, a random recursive tree is a rooted tree chosen uniformly at random from the recursive trees with a given number of vertices.

## o4 statement/fact: Properties

## Properties
With high probability, the longest path from the root to the leaf of an $n$-vertex random recursive tree has length $e\log n$.
The maximum number of children of any vertex, i.e., degree, in the tree is, with high probability, $(1\pm o(1))\log_2 n$.
The expected distance of the $k$th vertex from the root is the $k$th harmonic number, from which it follows by linearity of expectation that the sum of all root-to-vertex path lengths is, with high probability, $(1\pm o(1))n\log n$.
The expected number of leaves of the tree is $n/2$ with variance $n/12$, so with high probability the number of leaves is $(1\pm o(1))n/2$.
