# Lorenz curve

## o1 subject: Lorenz curve

In economics, the Lorenz curve is a graphical representation of the distribution of income or of wealth. It was developed by Max O. Lorenz in 1905 for representing inequality of the wealth distribution.

## o15 statement/fact: Properties

## Properties
A Lorenz curve always starts at (0,0) and ends at (1,1).
The Lorenz curve is not defined if the mean of the probability distribution is zero or infinite.
The Lorenz curve for a probability distribution is a continuous function. However, Lorenz curves representing discontinuous functions can be constructed as the limit of Lorenz curves of probability distributions, the line of perfect inequality being an example.
The information in a Lorenz curve may be summarized by the Gini coefficient and the Lorenz asymmetry coefficient.
The Lorenz curve cannot rise above the line of perfect equality.
A Lorenz curve that never falls beneath a second Lorenz curve and at least once runs above it, has Lorenz dominance over the second one.
If the variable being measured cannot take negative values, the Lorenz curve:
- cannot sink below the line of perfect inequality,
- is increasing.
Note however that a Lorenz curve for net worth would start out by going negative due to the fact that some people have a negative net worth because of debt.
The Lorenz curve is invariant under positive scaling. If $\boldsymbol{X}$ is a random variable, for any positive number $c$ the random variable $c\boldsymbol{X}$ has the same Lorenz curve as $\boldsymbol{X}$.
The Lorenz curve is flipped twice, once about $F = 0.5$ and once about $L = 0.5$, by negation. If $\boldsymbol{X}$ is a random variable with Lorenz curve $L_{\boldsymbol{X}}(F)$, then $-\boldsymbol{X}$ has the Lorenz curve:
$L_{-\boldsymbol{X}} = 1 - L_{\boldsymbol{X}}(1 - F)$
The Lorenz curve is changed by translations so that the equality gap $F - L(F)$ changes in proportion to the ratio of the original and translated means. If $\boldsymbol{X}$ is a random variable with a Lorenz curve $L_{\boldsymbol{X}}(F)$ and mean $\mu_{\boldsymbol{X}}$, then for any constant $c \ne -\mu_{\boldsymbol{X}}$, $\boldsymbol{X} + c$ has a Lorenz curve defined by:
$$F - L_{X+c}(F) = \frac{\mu_X}{\mu_X + c} ( F - L_X(F))$$
For a cumulative distribution function $F(x)$ with mean $\mu$ and (generalized) quantile function $x(F)$, then for any $F$ with 0 < $F < 1$ :
- If the Lorenz curve is differentiable:
$$\frac{d L(F)}{d F} = \frac{x(F)}{\mu}$$
- If the Lorenz curve is twice differentiable, then the probability density function $f(x)$ exists at that point and:
$$\frac{d^2 L(F)}{d F^2} = \frac{1}{\mu\,f(x(F))}\,$$
- If $L(F)$ is continuously differentiable, then the tangent of $L(F)$ is parallel to the line of perfect equality at the point $F(\mu)$. This is also the point at which the equality gap $F - L(F)$, the vertical distance between the Lorenz curve and the line of perfect equality, is greatest. The size of the gap is equal to half of the relative mean absolute deviation:
$$F(\mu) - L(F(\mu)) = \frac{\text{mean absolute deviation}}{2\,\mu}$$
