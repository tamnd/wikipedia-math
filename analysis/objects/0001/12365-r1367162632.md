# Googolplex

## o1 subject: Googolplex

A googolplex is the large number $10^{10^{100}}$, that is, $10$ raised to the power of a googol. If written out in ordinary decimal notation, it would be $1$ followed by a googol (10100) zeroes‌a physically impossible number to write explicitly.
