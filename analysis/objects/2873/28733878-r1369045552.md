# Spectrahedron

## o1 subject: Spectrahedron

In convex geometry, a spectrahedron is a shape that can be represented as a linear matrix inequality. Alternatively, the set of $n \times n$ positive semidefinite matrices forms a convex cone in $\mathbf{R}^{n \times n}$, and a spectrahedron is a shape that can be formed by intersecting this cone with an affine subspace.
