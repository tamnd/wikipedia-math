# Real point

## o1 subject: Real point

In geometry, a real point is a point in the complex projective plane with homogeneous coordinates $(x,y,z)$ for which there exists a nonzero complex number $\lambda$ such that $\lambda x$, $\lambda y$, and $\lambda z$ are all real numbers.
