# Descent direction

## o1 subject: Descent direction

In optimization, a descent direction is a vector $\mathbf{p}\in\mathbb R^n$ that points towards a local minimum $\mathbf{x}^*$ of an objective function $f:\mathbb R^n\to\mathbb R$.
