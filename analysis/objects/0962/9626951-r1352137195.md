# Exact couple

## o1 subject: Exact couple

In mathematics, an exact couple, due to , is a general source of spectral sequences. It is common especially in algebraic topology; for example, Serre spectral sequence can be constructed by first constructing an exact couple.

## o5 statement/lemma: Lemma

Let $A^r_p = \{ c \in F_p C \mid d(c) \in F_{p-r} C \}$, which inherits $\mathbb{Z}$-grading from $F_pC$. Then for each p
:$E^r_{p, *} \simeq {A^r_p \over d(A^{r-1}_{p+r-1}) + A^{r-1}_{p-1}}.$

## o8 statement/theorem: Theorem

If $C = \cup_p F_p C$ and for each n there is an integer $s(n)$ such that $F_{s(n)} C_n = 0$, then the spectral sequence Er converges to $H_*(C)$; that is, $E^\infty_{p, q} = F_p H_{p+q}(C)/F_{p-1} H_{p+q}(C)$.
