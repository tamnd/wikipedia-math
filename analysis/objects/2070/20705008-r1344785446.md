# Encrypted Title Key

## o1 subject: Encrypted Title Key

Encrypted Title Key is an encrypted key that belongs to the discs implementing Advanced Access Content System (AACS). This key is included in the Media Key Block system and is an important part of the content protection process of Blu-ray and HD-DVD contents.
