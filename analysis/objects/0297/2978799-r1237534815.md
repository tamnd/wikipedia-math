# Hartogs's theorem on separate holomorphicity

## o1 subject: Hartogs's theorem on separate holomorphicity

In mathematics, Hartogs's theorem is a fundamental result of Friedrich Hartogs in the theory of several complex variables. Roughly speaking, it states that a 'separately analytic' function is continuous. More precisely, if $F:{\textbf{C}}^n \to {\textbf{C}}$ is a function which is analytic in each variable zi, 1 ≤ i ≤ n, while the other variables are held constant, then F is a continuous function.
