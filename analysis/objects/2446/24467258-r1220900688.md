# Precision (statistics)

## o1 subject: Precision

In statistics, the precision matrix or concentration matrix is the matrix inverse of the covariance matrix or dispersion matrix, $P = \Sigma^{-1}$.
For univariate distributions, the precision matrix degenerates into a scalar precision, defined as the reciprocal of the variance, $p = \frac{1}{\sigma^2}$.
