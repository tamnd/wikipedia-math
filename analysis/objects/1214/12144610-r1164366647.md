# Increment theorem

## o1 subject: Increment theorem

In nonstandard analysis, a field of mathematics, the increment theorem states the following: Suppose a function $y = f(x)$ is differentiable at $x$ and that $\Delta x$ is infinitesimal. Then
$$\Delta y = f'(x)\,\Delta x + \varepsilon\, \Delta x$$
for some infinitesimal $\varepsilon$, where
$$\Delta y=f(x+\Delta x)-f(x).$$
