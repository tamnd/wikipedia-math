# Deontic logic

## o1 subject: Deontic logic

Deontic logic is the field of philosophical logic that is concerned with obligation, permission, and related concepts. Alternatively, a deontic logic is a formal system that attempts to capture the essential logical features of these concepts. It can be used to formalize imperative logic, or directive modality in natural languages. Typically, a deontic logic uses $\mathsf{O} A$ to mean it is obligatory that $A$, or it ought to be (the case) that $A$, and $\mathsf{P} A$ to mean it is permitted (or permissible) that $A$, which is defined as $\mathsf{P} A\equiv \neg \mathsf{O} \neg A$.
