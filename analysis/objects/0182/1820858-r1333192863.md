# Fundamental solution

## o1 subject: Fundamental solution

In mathematics, a fundamental solution for a linear partial differential operator $L$ is a formulation in the language of distribution theory of the older idea of a Green's function (although unlike Green's functions, fundamental solutions do not address boundary conditions).

## o3 section: Example

## o4 example: Example

## Example
Consider the following differential equation $Lf = \sin(x)$ with
$$L = \frac{d^2}{d x^2} .$$
The fundamental solutions can be obtained by solving $LF = \delta(x)$, explicitly,
$$\frac{d^2}{d x^2} F(x) = \delta(x) \,.$$
Since for the unit step function (also known as the Heaviside function) $H$ we have
$$\frac{d}{d x} H(x) = \delta(x) \,,$$
there is a solution
$$\frac{d}{d x} F(x) = H(x) + C \,.$$
Here $C$ is an arbitrary constant introduced by the integration. For convenience, set $C = -1/2$.
After integrating $\frac{dF}{dx}$ and choosing the new integration constant as zero, one has
$$F(x) = x H(x) - \frac{1}{2}x = \frac{1}{2} |x| ~.$$

## o9 proof: Proof that the convolution is a solution

### Proof that the convolution is a solution
Denote the convolution of functions $F$ and $g$ as $F \ast g$. Say we are trying to find the solution of $Lf = g(x)$. We want to prove that $F \ast g$ is a solution of the previous equation, i.e. we want to prove that $L(F \ast g) = g$. When applying the differential operator with constant coefficients, $L$, to the convolution, it is known that
$$L(F*g) = (LF)*g \,,$$
provided $L$ has constant coefficients.
If $F$ is the fundamental solution, the right side of the equation reduces to
$$\delta * g~.$$
But since the delta function is an identity element for convolution, this is simply $g(x)$. Summing up,
$$L(F*g) = (LF)*g = \delta(x)*g(x) = \int_{-\infty}^{\infty} \delta (x-y) g(y) \, dy = g(x) \,.$$
Therefore, if $F$ is the fundamental solution, the convolution $F \ast g$ is one solution of $Lf = g(x)$. This does not mean that it is the only solution. Several solutions for different initial conditions can be found.
