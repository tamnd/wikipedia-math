# Fundamental matrix (linear differential equation)

## o1 subject: Fundamental matrix

In mathematics, a fundamental matrix of a system of n homogeneous linear ordinary differential equations
$$\dot{\mathbf{x}}(t) = A(t) \mathbf{x}(t)$$
is a matrix-valued function $\Psi(t)$ whose columns are linearly independent solutions of the system.
Then every solution to the system can be written as $\mathbf{x}(t) = \Psi(t) \mathbf{c}$, for some constant vector $\mathbf{c}$ (written as a column vector of height $n$).
