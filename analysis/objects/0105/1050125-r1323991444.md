# Laver table

## o1 subject: Laver table

In mathematics, Laver tables (named after Richard Laver, who discovered them towards the end of the 1980s in connection with his works on set theory) are tables of numbers that have certain properties of algebraic and combinatorial interest. They occur in the study of racks and quandles.

## o2 section: Definition

## o3 definition: Definition

## Definition
For any nonnegative integer n, the n-th Laver table is the 2n × 2n table whose entry in the cell at row p and column q (1 ≤ p,q ≤ 2n) is defined as
$L_n(p, q) := p \star_n q$
where $\star_n$ is the unique binary operation on {1,...,2n} that satisfies the following two equations for all p, q:
:
$p \star_n 1 = p+1 \mod{2^n}$
and
:
$p \star_n (q \star_n r) = (p \star_n q) \star_n (p \star_n r).$
Note: Equation ((1)) uses the notation $x \bmod 2^n$ to mean the unique member of {1,...,2n} congruent to x modulo 2n.
Equation ((2)) is known as the (left) self-distributive law, and a set endowed with any binary operation satisfying this law is called a shelf. Thus, the n-th Laver table is just the multiplication table for the unique shelf ({1,...,2n}, $\star_n$) that satisfies Equation ((1)).

## o11 statement/fact: Properties

## Properties
- For all p, q in {1,...,2n}: $\ \ 2^n \star_n q = q;\ \ p \star_n 2^n = 2^n;\ \ (2^n-1)\star_n q = 2^n;\ \ p\star_n 2^{n-1}=2^n\text{ if }p\ne 2^n$.
- For all p in {1,...,2n}: $\ \ (p \star_n q)_{q=1,2,3,...}$ is periodic with period πn(p) equal to a power of two.
- For all p in {1,...,2n}: $\ \ (p \star_n q)_{q=1,2,3,...,\pi_n(p)}$ is strictly increasing from $p \star_n 1 = p+1\$ to $\ p \star_n \pi_n(p) = 2^n$.
- For all p,q: $\ p \star_n q = (p+1)^{(q)}, \text{ where } x^{(1)}=x,\ x^{(k+1)}=x^{(k)} \star_n x.$
