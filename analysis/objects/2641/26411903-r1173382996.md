# Circular uniform distribution

## o1 subject: Circular uniform distribution

In probability theory and directional statistics, a circular uniform distribution is a probability distribution on the unit circle whose density is uniform for all angles.

## o2 section: Description

## o3 section: Definition

## o4 definition: Definition

### Definition
The probability density function (pdf) of the circular uniform distribution, e.g. with $\theta\in[0,2\pi)$, is:
$f_{UC}(\theta)=\frac{1}{2\pi}.$
