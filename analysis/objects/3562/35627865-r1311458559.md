# Moderated mediation

## o1 subject: Moderated mediation

Moderated mediation, also known as conditional indirect effects, occurs when the treatment effect of an independent variable A on an outcome variable C via a mediator variable B differs depending on levels of a moderator variable D. Specifically, either the effect of A on B, and/or the effect of B on C depends on the level of D. In statistics, moderation and mediation can occur together in the same model.
