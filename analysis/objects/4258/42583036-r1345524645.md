# Monotone comparative statics

## o1 subject: Monotone comparative statics

Monotone comparative statics is a sub-field of comparative statics that focuses on the conditions under which endogenous variables undergo monotone changes (that is, either increasing or decreasing) when there is a change in the exogenous parameters. Traditionally, comparative results in economics are obtained using the Implicit Function Theorem, an approach that requires the concavity and differentiability of the objective function as well as the interiority and uniqueness of the optimal solution. The methods of monotone comparative statics typically dispense with these assumptions. It focuses on the main property underpinning monotone comparative statics, which is a form of complementarity between the endogenous variable and exogenous parameter. Roughly speaking, a maximization problem displays complementarity if a higher value of the exogenous parameter increases the marginal return of the endogenous variable. This guarantees that the set of solutions to the optimization problem is increasing with respect to the exogenous parameter.

## o5 definition: Definition (strong set order)

Definition (strong set order): Let $Y$ and $Y'$ be subsets of $\mathbb{R}$. Set $Y'$ dominates $Y$ in the strong set order ($Y'\geq_{SSO} Y$) if for any $x'$ in $Y'$ and $x$ in $Y$, we have $\max\{x',x\}$ in $Y'$ and $\min\{x',x\}$ in $Y$.
In particular, if $Y:=\{x\}$ and $Y':=\{x'\}$, then $Y' \geq_{SSO} Y$ if and only if $x' \geq x$. The correspondence $\arg\max_{x\in X}f(x;s)$ is said to be increasing if $\arg\max_{x\in X}f(x;s')\geq_{SSO} \arg\max_{x\in X}f(x;s)$ whenever $s'>_S s$.
The notion of complementarity between exogenous and endogenous variables is formally captured by single crossing differences.

Definition (single crossing function): Let $\phi:S\rightarrow \mathbb{R}$. Then $\phi$ is a single crossing function if for any $s' \geq_S s$ we have $\phi (s)\geq (>) \ 0 \ \Rightarrow \ \phi (s')\geq (>) \ 0$.

## o8 definition: Definition (single crossing differences)

Definition (single crossing differences): The family of functions $\{f(\cdot;s)\}_{s\in S}$, $f:X \times S\to \mathbb{R}$, obey single crossing differences (or satisfy the single crossing property) if for all $x' \geq x$, function $\Delta(s)= f(x' ;s)-f(x;s)$ is a single crossing function.
Obviously, an increasing function is a single crossing function and, if $\Delta (s)$ is increasing in $s$ (in the above definition, for any $x'>x$), we say that $\{f(\cdot;s)\}_{s\in S}$ obey increasing differences. Unlike increasing differences, single crossing differences is an ordinal property, i.e., if $\{f(\cdot;s)\}_{s\in S}$ obey single crossing differences, then so do $\{g(\cdot;s)\}_{s\in S}$, where $g(x;s)=H(f(x;s);s)$ for some function $H(\cdot;s)$ that is strictly increasing in $x$.

## o10 statement/theorem: Theorem 1

Theorem 1: Define $F_{Y}(s):=\arg\max_{x \in Y} f(x;s)$. The family $\{f(\cdot;s)\}_{s\in S}$ obey single crossing differences if and only if for all $Y\subseteq X$, we have $F_{ Y}( s ' ) \geq_{ SSO } F_{Y}( s )$ for any $s' \geq_S s$.
Proof: Assume $s' \geq_S s$ and $x \in F_{Y}(s)$, and $x' \in F_{Y}(s')$. We have to show that $\max\{ x' , x \}\in F_{Y}(s')$ and $\min\{ x ', x \} \in F_{Y}(s)$. We only need to consider the case where $x>x'$. Since $x \in F_{Y}(s)$, we obtain $f(x;s)\geq f(x';s)$, which guarantees that $x\in F_{Y'}(s')$. Furthermore, $f(x;s)=f(x';s)$ so that $x' \in F_Y(s)$. If not, $f(x;s)>f(x';s)$ which implies (by single crossing differences) that $f(x;s')>f(x';s')$, contradicting the optimality of $x'$ at $s'$. To show the necessity of single crossing differences, set $Y:=\{x,\bar{x}\}$, where $\bar{x} \geq x$. Then $F_{Y}(s') \geq_{SSO} F_{Y}(s)$ for any $s' \geq_S s$ guarantees that, if $f(\bar{x};s) \geq (>) \ f(x;s)$, then $f(\bar{x}; s') \geq (>) \ f(x;s')$. Q.E.D.
Application (monopoly output and changes in costs): A monopolist chooses $x \in X\subseteq \mathbb{R}_+$ to maximise its profit $\Pi(x;-c)=xP(x)-cx$, where $P:\mathbb{R}_+ \to \mathbb{R}_+$ is the inverse demand function and $c\geq 0$ is the constant marginal cost. Note that $\{\Pi(\cdot,-c)\}_{(-c) \in \mathbb{R}_{-}}$ obey single crossing differences. Indeed, take any $x' \geq x$ and assume that $x'P(x')-cx' \geq (>) \ xP(x)-cx$; for any $c'$ such that $(-c')\geq (-c)$, we obtain $x'P(x')-c'x' \geq (>) \ xP(x)-c'x$. By Theorem 1, the profit-maximizing output decreases as the marginal cost of output increases, i.e., as $(-c)$ decreases.

## o12 section: Interval dominance order

## o13 definition: Definition (Interval)

Definition (Interval): Let $X \subseteq \mathbb{R}$. A set $Y \subseteq X$ is an interval of $X$ if, whenever $x^*$ and $x^{**}$ are in $Y$, then any $x \in X$ such that $x^* \leq x \leq x^{**}$ is also in $Y$.
For example, if $X= \mathbb{N}$, then $\{1,2,3,4\}$ is an interval of $X$ but not $\{1,2,4\}$. Denote $[x^*,x^{**}]=\{x\in X \ | \ x^*\leq x\leq x^{**}\}$.

## o14 citation

## o15 definition: Definition (Interval Dominance Order)

Definition (Interval Dominance Order): The family $\{f(\cdot;s)\}_{s\in S}$ obey the interval dominance order (IDO) if for any $x''>x'$ and $s'\geq_S s$, such that $f(x'';s)\geq f(x;s)$, for all $x \in [x',x'']$, we have $f(x'';s) \geq (>) \ f(x';s) \ \Rightarrow \ f(x'';s')\geq (>) \ f(x';s')$.
Like single crossing differences, the interval dominance order (IDO) is an ordinal property. An example of an IDO family is a family of quasiconcave functions $\{f(\cdot;s)\}_{s\in S}$ where $\arg\max_{x\in X}f(x,s)$ increasing in $s$. Such a family need not obey single crossing differences.
A function $f:X\times S \to \mathbb{R}$ is regular if $\arg\max_{x \in [x^*, x^{**}]}f(x;s)$ is non-empty for any $x^{**}\geq x^*$, where $[x^*,x^{**}]$ denotes the interval $\{x\in X \ | \ x^*\leq x\leq x^{**}\}$.

## o16 citation

## o17 statement/theorem: Theorem 2

Theorem 2: Denote $F_Y(s):=\arg\max_{x\in Y} f(x;s)$. A family of regular functions $\{f(\cdot;s)\}_{s\in S}$ obeys the interval dominance order if and only if $F_Y(s)$ is increasing in $s$ for all intervals $Y \subseteq X$.
Proof: To show the sufficiency of IDO, take any two $s' \geq_S s$, and assume that $x' \in F_Y(s)$ and $x'' \in F_Y(s')$. We only need to consider the case where $x' > x''$. By definition $f(x';s) \geq f(x;s)$, for all $x \in [x'', x'] \subset Y$. Moreover, by IDO we have $f(x';s') \geq f(x'';s')$. Therefore, $x' \in F_Y(s')$. Furthermore, it must be that $f(x';s) = f(x'';s)$. Otherwise, i.e., if $f(x';s) > f(x'';s)$, then by IDO we have $f(x';s') > f(x'';s')$, which contradicts that $x'' \in F_Y(s')$. To show the necessity of IDO, assume that there is an interval $[x'',x']$ such that $f(x';s) \geq f(x;s)$ for all $x \in [x'',x']$. This means that $x' \in \arg\max_{x\in [x'',x']} f(x;s)$. There are two possible violations of IDO. One possibility is that $f(x'';s') > f(x'; s')$. In this case, by the regularity of $f(\cdot; s')$, the set $\arg\max_{x\in [x'',x']} f(x;s')$ is non-empty but does not contain $x'$ which is impossible since $\arg\max_{x\in [x'',x']} f(x;s)$ increases in $s$. Another possible violation of IDO occurs if $f(x'';s') = f(x';s')$ but $f(x'';s) < f(x';s)$. In this case, the set $\arg\max_{x\in [x'',x']} f(x;s')$ either contains $x''$, which is not possible since $\arg\max_{x\in [x'',x']} f(x;s)$ increases in $s$ (note that in this case $x'' \not \in \arg\max_{x\in [x'',x']} f(x;s')$) or it does not contain $x'$, which also violates monotonicity of $\arg\max_{x\in [x'',x']} f(x;s)$. Q.E.D.
The next result gives useful sufficient conditions for single crossing differences and IDO.

## o19 statement/proposition: Proposition 1

Proposition 1: Let $X$ be an interval of $\mathbb{R}$ and $\{f(\cdot;s)\}_{s\in S}$ be a family of continuously differentiable functions. (i) If, for any $s'\geq_S s$, there exists a number $\alpha>0$ such that $f'(x;s')\geq \alpha f'(x;s)$ for all $x\in X$, then $\{f(\cdot;s)\}_{s\in S}$ obey single crossing differences. (ii) If, for any $s'\geq_S s$, there exists a nondecreasing, strictly positive function $\alpha: X\rightarrow \mathbb{R}$ such that $f'(x;s')\geq \alpha(x)f'(x;s)$ for all $x\in X$, then $\{f(\cdot;s)\}_{s\in S}$ obey IDO.
Application (Optimal stopping problem): At each moment in time, agent gains profit of $\pi (t)$, which can be positive or negative. If agent decides to stop at time $x$, the present value of his accumulated profit is
$V(x;-r )=\int_0^x e^{-r t}\pi (t) dt,$
where $r>0$ is the discount rate. Since $V'(x;-r)=e^{-r x}\pi (x)$, the function $V$ has many turning points and they do not vary with the discount rate. We claim that the optimal stopping time is decreasing in $r$, i.e., if $r' > r >0$ then $\arg\max_{x\geq 0}V(x;-r) \geq_{SSO} \arg\max_{x \geq 0}V(x;-r')$. Take any $r'< r$. Then, $V'(x;-r)=e^{-rx} \pi(x) = e^{(r'-r)x}V'(x;-r').$ Since $\alpha (x)=e^{(r'-r)x}$ is positive and increasing, Proposition 1 says that $\{V(\cdot;-r)\}_{(-r) <0}$ obey IDO and, by Theorem 2, the set of optimal stopping times is decreasing.

## o22 section: Multi-dimensional optimization problems

## o23 definition: Definition (Strong Set Order)

Definition (Strong Set Order): Let $(X,\geq_X)$ be a lattice and $Y$, $Y'$ be subsets of $X$. We say that $Y'$ dominates $Y$ in the strong set order ($Y'\geq_{SSO} Y$ ) if for any $x'$ in $Y'$ and $x$ in $Y$, we have $x\vee x'$ in $Y'$ and $x\wedge x'$ in $Y$.
Examples of the strong set order in higher dimensions.
- Let $X=\mathbb{R}$ and $Y:=[a,b]$, $Y':=[ a' , b' ]$ be some closed intervals in $X$. Clearly $(X, \geq)$, where $\geq$ is the standard ordering on $\mathbb{R}$, is a lattice. Therefore, as it was shown in the previous section $Y' \geq_{SSO} Y$ if and only if $a' \geq a$ and $b' \geq b$;
- Let $X = \mathbb{R}^n$ and $Y$, $Y' \subset X$ be some hyperrectangles. That is, there exist some vectors $a$, $b$, $a'$, $b'$ in $X$ such that $Y:=\{x \in X \ | \ a \leq x \leq b\}$ and $Y':=\{x \in X \ | \ a' \leq x \leq b'\}$, where $\geq$ is the natural, coordinate-wise ordering on $\mathbb{R}^n$. Note that $(X, \geq)$ is a lattice. Moreover, $Y' \geq_{SSO} Y$ if and only if $a' \geq a$ and $b' \geq b$;
- Let $(X, \geq_X)$ be a space of all probability distributions with support being a subset of $\mathbb{R}$, endowed with the first order stochastic dominance order $\geq_X$. Note that $(X, \geq_X)$ is a lattice. Let $Y:=\Delta([a,b])$, $Y':=\Delta([ a' , b' ])$ denote sets of probability distributions with support $[a,b]$ and $[ a' , b' ]$ respectively. Then, $Y' \geq_{SSO} Y$ with respect to $\geq_X$ if and only if $a'\geq a$ and $b' \geq b$.

## o25 definition: Definition (Quasisupermodular function)

Definition (Quasisupermodular function): Let $(X,\geq_X)$ be a lattice. The function $f:X \to \mathbb{R}$ is quasisupermodular (QSM) if
$f(x)\geq (>) \ f(x\wedge x') \ \Rightarrow \ f(x\vee x')\geq (>) \ f(x').$
The function $f$ is said to be a supermodular function if $f(x\vee x')- f(x')\geq f(x) - f(x\wedge x').$ Every supermodular function is quasisupermodular. As in the case of single crossing differences, and unlike supermodularity, quasisupermodularity is an ordinal property. That is, if function $f$ is quasisupermodular, then so is function $g:=H \circ f$, where $H$ is some strictly increasing function.

## o27 statement/theorem: Theorem 3

Theorem 3: Let $(X,\geq_X)$ is a lattice, $(S, \geq_S)$ a partially ordered set, and $Y$, $Y'$ subsets of $X$. Given $f:X \times S \to \mathbb{R}$, we denote $\arg\max_{x\in Y}f(x;s)$ by $F_Y(s)$. Then $F_{Y'}(s') \geq_{SSO} F_{Y}(s)$ for any $s' \geq_S s$ and $Y' \geq_{SSO} Y$
Proof: $( \Leftarrow )$. Let $Y' \geq_{SSO} Y$, $s' \geq_S s$, and $x' \in F_{Y'}(s')$, $x \in F_{Y}(s)$. Since $x \in F_Y(s)$ and $Y' \geq_{SSO} Y$, then $f(x;s) \geq f(x'\wedge x;s)$. By quasisupermodularity, $f(x'\vee x;s) \geq f(x';s)$, and by the single crossing differences, $f(x'\vee x;s') \geq f(x';s')$. Hence $x'\vee x \in F_{Y'}(s')$. Now assume that $x'\wedge x \not\in F_{Y}(s)$. Then $f(x;s)>f(x'\wedge x;s)$. By quasisupermodularity, $f(x'\vee x;s)>f(x';s)$, and by single crossing differences $f(x'\vee x;s')>f(x';s')$. But this contradicts that $x' \in F_{Y'}(s')$. Hence, $x'\wedge x \in F_{Y}(s)$.
$( \Rightarrow )$. Set $Y':=\{x', x'\vee x\}$ and $Y:=\{x, x'\wedge x\}$. Then, $Y' \geq_{SSO} Y$ and thus $F_{Y'}(s) \geq_{SSO} F_{Y}(s)$, which guarantees that, if $f(x;s) \geq (>) \ f(x'\wedge x;s)$, then $f(x'\vee x;s)\geq (>)\ f(x';s)$. To show that single crossing differences also hold, set $Y:=\{x,\bar{x}\}$, where $\bar{x}\geq x$. Then $F_{Y}(s') \geq_{SSO} F_{Y}(s)$ for any $s' \geq_S s$ guarantees that, if $f(\bar{x};s) \geq (>) \ f(x;s)$, then $f(\bar{x}; s') \geq (>) \ f(x;s')$. Q.E.D.
Application (Production with multiple goods): Let $x$ denote the vector of inputs (drawn from a sublattice $X$ of $\mathbb{R}^{l}_+$) of a profit-maximizing firm, $p \in \mathbb{R}^{l}_{++}$ be the vector of input prices, and $V$ the revenue function mapping input vector $x$ to revenue (in $\mathbb{R}$). The firm's profit is $\Pi (x; p)= V (x)-p\cdot x$. For any $x'$, $x\in X$, $x' \geq x$, $V(x') - V(x) + (-p)(x'-x)$ is increasing in $(-p)$. Hence, $\{\Pi (\cdot; p)\}_{p \in \mathbb{R}_{++}^l}$ has increasing differences (and so it obeys single crossing differences). Moreover, if $V$ is supermodular, then so is $\Pi(\cdot; p)$. Therefore, it is quasisupermodular and by Theorem 3, $\arg\max_{x\in X}\Pi (x;p) \geq_{SSO} \arg\max_{x\in X}\Pi (x;p')$ for $p'\geq p$.

## o31 statement/theorem: Theorem 4

Theorem 4: Suppose $u:\mathbb{R}_{++}^n\rightarrow\mathbb{R}$ is supermodular and concave. Then the demand correspondence is normal in the following sense: suppose $w''>w'$, $x''\in D(p,w'')$ and $x'\in D(p,w')$; then there is $z''\in D(p,w'')$ and $z'\in D(p,w')$ such that $z''\geq x'$ and $x''\geq z'$.
The supermodularity of $u$ alone guarantees that, for any $x$ and $y$, $u(x\wedge y)-u(y)\geq u(x)-u(x \vee y)$. Note that the four points $x$, $y$, $x\wedge y$, and $x\vee y$ form a rectangle in Euclidean space (in the sense that $x\wedge y-x=y-x\vee y$, $x-x\vee y=x\wedge y-y$, and $x\wedge y-x$ and $x-x\vee y$ are orthogonal). On the other hand, supermodularity and concavity together guarantee that
$u( x \vee y - \lambda v)-u(y)\geq u(x)- u( x \wedge y + \lambda v).$
for any $\lambda \in [0,1]$, where $v = y - x\wedge y= x\vee y - x$. In this case, crucially, the four points $x$, $y$, $x \vee y - \lambda v$, and $x \wedge y + \lambda v$ form a backward-leaning parallelogram in Euclidean space.

## o34 statement/theorem: Theorem 5

Theorem 5: Suppose $\{f(\cdot;s)\}_{s\in S}$ $(S\subseteq \mathbb{R})$ obeys increasing differences. If $\{\lambda (\cdot; t)\}_{t\in T}$ is ordered with respect to first order stochastic dominance, then $\{F(\cdot;t)\}_{t\in T}$ obeys increasing differences.
Proof: For any $x', x \in X$, define $\phi(s):= f(x';s) - f(x;s)$. Then, $F(x';t) - F(x;t) = \int_{S} [f(x';s) - f(x;s)]\lambda (s; t) ds$, or equivalently $F(x';t) - F(x;t) = \int_{S} \phi(s)\lambda (s; t)ds$. Since $\{f(\cdot;s)\}_{s\in S}$ obeys increasing differences, $\phi$ is increasing in $s$ and first order stochastic dominance guarantees $F(x';t) - F(x;t)$ is increasing in $t$. Q.E.D.

## o37 statement/proposition: Proposition 2

Proposition 2: Let $\lambda(\cdot;t')$ and $\lambda(\cdot;t)$ be two probability mass functions defined on $S := \{1, 2, \ldots, N\}$ and suppose $\lambda(\cdot;t'')$ does not dominate $\lambda(\cdot;t')$ with respect to the monotone likelihood ratio property. Then there is a family of functions $\{f(\cdot;s)\}_{s \in S}$, defined on $X\subset \mathbb{R}$, that obey single crossing differences, such that $\arg\max_{x\in X} F(x; t'') < \arg\max_{x\in X} F(x; t')$, where $F(x;t)=\sum_{s\in S}\lambda (s,t)f(x,s)$ (for $t=t',\, t''$).
Application (Optimal portfolio problem): An agent maximizes expected utility with the strictly increasing Bernoulli utility function $u:\mathbb{R}_+ \to \mathbb{R}$. (Concavity is not assumed, so we allow the agent to be risk loving.) The wealth of the agent, $w>0$, can be invested in a safe or risky asset. The prices of the two assets are normalized at 1. The safe asset gives a constant return $R\geq 0$, while the return of the risky asset $s$ is governed by the
probability distribution $\lambda(s; t)$. Let $x$ denote the agent's investment in the risky asset. Then the wealth of the agent in state $s$ is $(w-x)R+xs$. The agent chooses $x$ to maximize
$V(x;t):=\int_S u((w-x)R + xs)\lambda(s;t) \, ds.$
Note that $\{\hat u(\cdot; s)\}_{s\in S}$, where $\hat u(x;s) := u(wR + x(s-R))$, obeys single crossing (though
not necessarily increasing) differences. By Theorem 6, $\{V(\cdot;t)\}_{t\in T}$ obeys single crossing differences, and hence $\arg\max_{x\geq 0}V(x;t)$ is increasing in $t$, if $\lambda(\cdot;t)\}_{t\in T}$ is ordered with
respect to the monotone likelihood ratio property.

## o39 definition: Definition (monotone signed-ratio)

Definition (monotone signed-ratio): Let $(S,\geq_S)$ be a poset. Two functions $f,g: S \to \mathbb{R}$ obey signed{ -}ratio monotonicity if, for any $s' \geq s$, the following holds:
- if $f(s) > 0$ and $g(s) < 0$, then
$-\frac {g(s)}{f(s)} \geq -\frac{g(s')}{f(s')};$
- if $f(s) < 0$ and $g(s) > 0$, then
$-\frac {f(s)}{g(s)} \geq -\frac{f(s')}{g(s')}.$

## o41 statement/proposition: Proposition 3

Proposition 3: Let $f$ and $g$ be two single crossing functions. Then $\alpha f + \beta g$ is a single crossing function for any non{-}negative scalars $\alpha$ and $\beta$ if and only if $f$ and $g$ obey signed-ratio monotonicity.
Proof: Suppose that $f(s) > 0$ and $g(s) < 0$. Define $\alpha^* = - g(s)/f(s)$, so that $\alpha^* f(s) + g(s) = 0$. Since $\alpha^* f(s) + g(s)$ is a single crossing function, it must be that $\alpha^* f(s') + g(s') \geq 0$, for any $s' \geq s$. Moreover, recall that since $f$ is a single crossing function, then $f(s') > 0$. By rearranging the above inequality, we conclude that
$\alpha^* = -\frac{g(s)}{f(s)} \geq -\frac{g(s')}{f(s')}.$
To prove the converse, without loss of generality assume that $\beta=1$. Suppose that
$\alpha f(s) + g(s) \geq (>) 0.$
If both $f(s) \geq 0$ and $g(s)\geq 0$, then $f(s')\geq 0$ and $g(s')\geq 0$ since both functions are single crossing. Hence, $\alpha f(s') + g(s') \geq (>) 0$. Suppose that $g(s)<0$ and $f(s)>0$. Since $f$ and $g$ obey signed{-}ratio monotonicity it must be that
$\alpha \geq (>) -\frac{g(s)}{f(s)} \geq -\frac{g(s')}{f(s')}.$
Since $f$ is a single crossing function, $f(s')> 0$, and so $\alpha f(s') + g(s') \geq (>) \ 0.$ Q.E.D.

## o42 statement/theorem: Theorem 7

Theorem 7: Let $(T, \mathcal{T}, \mu)$ be a finite measure space and suppose that, for each $s \in S$, $f(s; t)$ is a bounded and measurable function of $t \in T$. Then $F(s) = \int_T f(s; t) d\mu(t)$ is a single crossing function if, for all $t$, $t' \in T$, the pair of functions $f(s; t)$ and $f(s; t')$ of $s \in S$ satisfy signed-ratio monotonicity. This condition is also necessary if $\mathcal{T}$ contains all singleton sets and $F$ is required to be a single crossing function for any finite measure $\mu$.
Application (Monopoly problem under uncertainty): A firm faces uncertainty over the demand for its output $x$ and the profit at state $t \in T \subset \mathbb{R}$ is given
by $\Pi(x; -c, t) = xP(x; t) - cx$, where $c$ is the marginal cost and $P(x,t)$ is the inverse demand function in state $t$. The firm maximizes
$V(x; -c) = \int_T u(\Pi(x; -c, t))d\lambda(t),$
where $\lambda$ is the probability of state $t$ and $u : \mathbb{R} \to \mathbb{R}$ is the Bernoulli utility function representing the firm’s attitude towards uncertainty. By Theorem 1, $\arg\max_{x\geq 0} V(x;-c)$ is increasing in $-c$ (i.e., output falls with marginal cost) if the family $\{V(x; -c)\}_{c \in \mathbb{R}_+}$ obeys single crossing differences. By definition, the latter says that, for any $x' \geq x$, the function
$\Delta(-c)=\int_T [u(\Pi(x'; -c, t)) - u(\Pi(x; -c, t))] \, d\lambda(t),$
is a single crossing function. For each $t$, $\delta(-c, t) = u(\Pi(x'; -c, t)) - u(\Pi(x; -c, t))$ is s single crossing function of $-c$. However, unless $u$ is linear, $\delta$ will not, in general, be increasing in $-c$. Applying Theorem 6, $\Delta$ is a single crossing function if, for any $t', t \in T$, the functions $\delta(-c, t)$ and $\delta(-c, t')$ (of $-c$) obey signed-ratio monotonicity. This is guaranteed when (i) $P$ is decreasing in $x$ and increasing in $t$ and $\{\log(P(\cdot,t))\}_{t \in T}$ obeys increasing differences; and (ii) $u : \mathbb{R} \to \mathbb{R}$ is twice differentiable, with $u' > 0$, and obeys decreasing absolute risk aversion (DARA).
