# Bessel process

## o1 subject: Bessel process

In mathematics, a Bessel process, named after Friedrich Bessel. The n-dimensional Bessel process is the solution to the stochastic differential equation (SDE)

## o2 section: Formal definition

## o3 definition: Formal definition

## Formal definition
The Bessel process of order n is the real-valued process X given (when n ≥ 2) by
$X_t = \| W_t \|,$
where ||·|| denotes the Euclidean norm in Rn and W is an n-dimensional Wiener process (Brownian motion). Note that this SDE makes sense for any real parameter $n$ (although the drift term is singular at zero).

## o5 definition/notation: Notation

## Notation
A notation for the Bessel process of dimension $n$ started at zero is $\operatorname{BES}_{0}(n)$.
