# Modal μ-calculus

## o1 subject: Modal μ-calculus

In theoretical computer science, the modal μ-calculus (Lμ, Lμ, or propositional mu-calculus, sometimes just μ-calculus, although this can have a more general meaning) is an extension of propositional modal logic (with many modalities) by adding the least fixed point operator μ and the greatest fixed point operator ν, thus a fixed-point logic.

### Examples
- $\nu Z.\phi \wedge [a]Z$ is interpreted as "$\phi$ is true along every a-path". The idea is that "$\phi$ is true along every a-path" can be defined axiomatically as that (weakest) sentence $Z$ which implies $\phi$ and which remains true after processing any a-label.
- $\mu Z.\phi \vee \langle a \rangle Z$ is interpreted as the existence of a path along a-transitions to a state where $\phi$ holds.
- The property of a state being deadlock-free, meaning no path from that state reaches a dead end, is expressed by the formula
$$\nu Z.\left (\bigvee_{a\in A}\langle a\rangle\top\wedge \bigwedge_{a\in A}[a]Z \right)$$
