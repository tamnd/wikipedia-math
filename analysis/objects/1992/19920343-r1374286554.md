# Simultaneous action selection

## o1 subject: Simultaneous action selection

Simultaneous action selection, or SAS, is a game mechanic that occurs when players of a game take action (such as moving their pieces) at the same time. Examples of games that use this type of movement include rock–paper–scissors and Diplomacy.
