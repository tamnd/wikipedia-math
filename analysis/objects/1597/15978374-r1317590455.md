# Martin's maximum

## o1 subject: Martin's maximum

In set theory, a branch of mathematical logic, Martin's maximum, introduced by and named after Donald Martin, is a stronger form of the proper forcing axiom, itself a stronger form of Martin's axiom. It represents the broadest class of forcings for which a forcing axiom is consistent.
