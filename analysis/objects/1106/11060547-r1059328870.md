# A12 Authentication

## o1 subject: A12 Authentication

A12 Authentication (Access Authentication for 1xEV-DO) is a CHAP-based mechanism used by a CDMA2000 Access Network (AN) to authenticate a 1xEV-DO Access Terminal (AT).
