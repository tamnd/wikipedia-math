# Shintani zeta function

## o1 subject: Shintani zeta function

In mathematics, a Shintani zeta function or Shintani L-function is a generalization of the Riemann zeta function. They were first studied by . They include Hurwitz zeta functions and Barnes zeta functions.

## Definition
Let $P(\mathbf{x})$ be a polynomial in the variables $\mathbf{x}=(x_1,\dots,x_r)$ with real coefficients such that $P(\mathbf{x})$ is a product of linear polynomials with positive coefficients, that is, $P(\mathbf{x})=P_1(\mathbf{x})P_2(\mathbf{x})\cdots P_k(\mathbf{x})$, where
$$P_i(\mathbf{x})= a_{i1} x_1 + a_{i2} x_2 +\cdots + a_{ir}x_r + b_i,$$
where $a_{ij}>0$, $b_i>0$ and $k=\deg P$. The Shintani zeta function in the variable $s$ is given by (the meromorphic continuation of)
$$\zeta(P;s)=\sum_{x_1,\dots,x_r=1}^{\infty}\frac{1}{P(\mathbf{x})^s}.$$
