# Lattice path

## o1 subject: Lattice path

In combinatorics, a lattice path $L$ in the $d$-dimensional integer lattice $\mathbb{Z}^d$ of length $k$ with steps in the set $S$, is a sequence of vectors $v_0, v_1, \ldots, v_k \in \mathbb{Z}^d$ such that each consecutive difference $v_i - v_{i-1}$ lies in $S$.
A lattice path may lie in any lattice in $\mathbb{R}^d$, but the integer lattice $\mathbb{Z}^d$ is most commonly used.
