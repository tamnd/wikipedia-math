## Notation
If $v$ is a valuation, that is, a mapping from the atoms to the set $\{ t, f \}$, then the double-bracket notation is commonly used to denote a valuation; that is, $[\![\phi]\!]_v = v(\phi)$ for a propositional formula $\phi$.
