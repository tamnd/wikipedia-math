# Parabolic cylinder function

## o1 subject: Parabolic cylinder function

In mathematics, the parabolic cylinder functions are special functions defined as solutions to the differential equation

## o2 equation: 1

$\frac{d^2f}{dz^2} + \left(\tilde{a}z^2+\tilde{b}z+\tilde{c}\right)f=0.$

## o3 equation: A

$\frac{d^2f}{dz^2} - \left(\tfrac14z^2+a\right)f=0$

## o4 equation: B

$\frac{d^2f}{dz^2} + \left(\tfrac14z^2-a\right)f=0.$
