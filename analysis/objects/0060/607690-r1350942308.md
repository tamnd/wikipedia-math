# Affine connection

## o1 subject: Affine connection

In differential geometry, an affine connection is a geometric object on a smooth manifold which connects nearby tangent spaces, so it permits tangent vector fields to be differentiated as if they were functions on the manifold with values in a fixed vector space. Connections are among the simplest methods of defining differentiation of the sections of vector bundles.

## o11 statement/fact: Elementary properties

### Elementary properties
- It follows from property 1 above that the value of $\nabla_{X}Y$ at a point $x \in M$ depends only on the value of $X$ at $x$ and not on the value of $X$ on $M - \{x\}$. It also follows from property 2 above that the value of $\nabla_{X}Y$ at a point $x \in M$ depends only on the value of $Y$ on a neighbourhood of $x$.
- If $\nabla^{1}, \nabla^{2}$ are affine connections then the value at $x$ of $\nabla^{1}_{X}Y - \nabla^{2}_{X}Y$ may be written $\Gamma_{x}(X_{x}, Y_{x})$ where
$$\Gamma_x : \mathrm{T}_xM \times \mathrm{T}_xM \to \mathrm{T}_xM$$
is bilinear and depends smoothly on $x$ (i.e., it defines a smooth bundle homomorphism). Conversely if $\nabla$ is an affine connection and $\Gamma$ is such a smooth bilinear bundle homomorphism (called a connection form on $M$) then $\nabla + \Gamma$ is an affine connection.
- If $M$ is an open subset of $\mathbf{R}^{n}$, then the tangent bundle of $M$ is the trivial bundle $M \times \mathbf{R}^{n}$. In this situation there is a canonical affine connection $d$ on $M$: any vector field $Y$ is given by a smooth function $V$ from $M$ to $\mathbf{R}^{n}$; then $d_{X}Y$ is the vector field corresponding to the smooth function $dV(X) = \partial_{X}Y$ from $M$ to $\mathbf{R}^{n}$. Any other affine connection $\nabla$ on $M$ may therefore be written $\nabla = d + \Gamma$, where $\Gamma$ is a connection form on $M$.
- More generally, a local trivialization of the tangent bundle is a bundle isomorphism between the restriction of $TM$ to an open subset $U$ of $M$, and $U \times \mathbf{R}^{n}$. The restriction of an affine connection $\nabla$ to $U$ may then be written in the form $d + \Gamma$ where $\Gamma$ is a connection form on $U$.
