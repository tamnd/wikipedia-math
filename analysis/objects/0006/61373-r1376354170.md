# Golden ratio base

## o1 subject: Golden ratio base

Golden ratio base is a non-integer positional numeral system that uses the golden ratio (the irrational number $\tfrac12\bigl(1+\sqrt{5}\bigr)$ $\approx 1.61803...$ symbolized by the Greek letter φ) as its base. It is sometimes referred to as base-φ, golden mean base, phi-base, or, colloquially, phinary. Any non-negative real number can be represented as a base-$\varphi$ numeral using only the digits $0$ and $1$, and avoiding the digit sequence "$11$" – this is called a standard form. A base-$\varphi$ numeral that includes the digit sequence "$11$" can always be rewritten in standard form, using the algebraic property of the base $\varphi$ that $\varphi^{n} + \varphi^{n - 1} = \varphi^{n + 1}$. For instance, $11_{\varphi} = 100_{\varphi}$.
