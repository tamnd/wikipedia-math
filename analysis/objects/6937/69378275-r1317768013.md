## o1 subject: Flag algebra

Flag algebras are an important computational tool in the field of graph theory which have a wide range of applications in homomorphism density and related topics. Roughly, they formalize the notion of adding and multiplying homomorphism densities and set up a framework to solve graph homomorphism inequalities with computers by reducing them to semidefinite programming problems. Originally introduced by Alexander Razborov in a 2007 paper, the method has since come to solve numerous difficult, previously unresolved graph theoretic questions. These include the $D_{2,3}$ question regarding the region of feasible edge density, triangle density pairs and the maximum number of pentagons in triangle free graphs.

## o8 definition: Definition

## Definition
Fix a collection of forbidden subgraphs $\mathcal{H}$ and consider the set of graphs $\mathcal{G}$ of $\mathcal{H}$-free graphs. Now, define a type of size $k$ to be a graph $\sigma\in\mathcal G$ with labeled vertices $V(\sigma)=[k]$. The type of size 0 is typically denoted as $\varnothing$.
First, we define a $\sigma$-flag, a partially labeled graph which will be crucial for the theory of flag algebras:
Definition: A $\sigma$-flag is a pair $(F,\theta)$ where $F\in\mathcal G$ is an underlying, unlabeled, $\mathcal H$-free graph, while $\theta:[k]\to V(F)$ defines a labeled graph embedding of $\sigma$ onto the vertices $F$. Denote the set of $\sigma$-flags to be $\mathcal F^\sigma$ and the set of $\sigma$-flags of size $n$ to be $\mathcal F^\sigma_n$. As an example, $P_3^b$ from the proof of Mantel's Theorem above is a $\sigma$-flag where $\sigma$ is a type of size 1 corresponding to a single vertex.
For $\sigma$-flags $F_1,F_2,\ldots,F_t,(G,\theta)$ satisfying $|G|-|\sigma|\ge \sum_{i=1}^t |F_i|-|\sigma|$, we can define the density of the $\sigma$-flags onto the underlying graph $G$ in the following way:
Definition: The density $p(F_1,F_2,\ldots,F_t;G)$ of the $\sigma$-flags $F_1,\ldots,F_t$ in $G$ is defined to be the probability of successfully randomly embedding $F_1,\ldots,F_t$ into $V(G)$ such that they are nonintersecting on $V(G)\setminus\mathrm{im}(\theta)$ and are all labeled in the exact same way as $G$ on $\mathrm{im}(\theta)$.
More precisely, choose pairwise disjoint $U_1,U_2,\ldots,U_t\subseteq V(G)\setminus\mathrm{im}(\theta)$ at random and define $p(F_1,\ldots,F_t;G)$ to be the probability that the $\sigma$-flag $(G[U_i\cup\mathrm{im}(\theta)],\theta)$ is isomorphic to $F_i$ for all $i\in[t]$.
Note that, when embedding $F$ into $G$, where $F,G$ are $\sigma$-flags, it can be done by first embedding $F$ into a $\sigma$-flag $F'$ of size $n\in[|F|,|G|]$ and then embedding $F'$ into $G$, which gives the formula: $p(F;G)=\sum_{F'\in \mathcal F^\sigma_n}p(F;F')p(F';G)$. Extending this to sets of $\sigma$-flags gives the Chain Rule:
Theorem (Chain Rule): If $F_1,F_2,\ldots,F_t,G$ are $\sigma$-flags, $s,n$ are naturals such that $F_1,\ldots,F_t$ fit in $G$, $F_1,\ldots,F_s$ fit in a $\sigma$-flag of size $n$, and a $\sigma$-flag of size $n$ combined with $F_{s+1},\ldots,F_t$ fit in $G$, then $p(F_1,F_2,\ldots,F_t;G)=\sum_{F\in\mathcal F^\sigma_n}p(F_1,\ldots,F_s;F)p(F,F_{s+1},\ldots,F_t;G)$.
Recall that the previous proof for Mantel's involved linear combinations of terms of the form $d(H,G)$. The relevant ideas were slightly imprecise with letting $|G|$ tend to infinity, but explicitly there is a sequence $G_1,G_2,\ldots$ such that $d(H,G_i)$ converges to some $\phi(H)$ for all $H$, where $\phi$ is called a limit functional. Thus, all references to $d(H,G)$ really refer to the limit functional. Now, graph homomorphism inequalities can be written as linear combinations of $\phi$ with different $H$s, but it would be convenient to express them as a single term. This motivates defining $\mathbb R\mathcal F^\sigma$, the set of formal linear combinations of $\sigma$-flags over $\mathbb R$, and now $\phi$ can be extended to a linear function over $\mathbb R\mathcal F^\sigma$.
However, using the full space $\mathbb R\mathcal F^\sigma$ is wasteful when investigating just limit functionals, since there exist nontrivial relations between densities of certain $\sigma$-flags. In particular, the Chain Rule shows that
$\phi(F)=\phi\left(\sum_{F'\in\mathcal F^\sigma_n}p(F;F')F'\right)\implies F-\sum_{F'\in\mathcal F^\sigma_n}p(F;F')F'\in\ker\phi$
is always true. Rather than dealing with all of these elements of the kernel, let the set of expressions of the above form (i.e. those obtained from Chain Rule with a single $\sigma$-flag) as $\mathcal K^\sigma$ and quotient them out in our final analysis. These ideas combine to form the definition for a flag algebra:
Definition (Flag Algebras): A flag algebra is defined on the space of linear combinations of $\sigma$-flags $\mathcal A^\sigma = \mathbb R\mathcal F^\sigma/\mathcal K^\sigma$ equipped with bilinear operator $F\cdot G=\sum_{H\in \mathcal F^\sigma_n}p(F,G;H)H$ for $F,G\in \mathcal F^\sigma$ and any natural $n$ such that $F,G$ fit in a $\sigma$-flag of size $n$, extending the operator linearly to $\mathbb R\mathcal F^\sigma$.
It remains to check that the choice of $n$ does not matter for a pair $F,G$ provided it is large enough (this can be proven with Chain Rule) as well as that if $f\in \mathcal K^\sigma$ then $f\cdot g\in\mathcal K^\sigma$, meaning that the operator respects the quotient and thus forms a well-defined algebra on the desired space.
One important result of this definition for the operator is that multiplication is respected on limit functionals. In particular, for a limit functional $\phi$, the identity $\phi(f\cdot g)=\phi(f)\cdot\phi(g)$ holds true. For example, it was shown that $\phi(P_3^b)=\phi(K_2^b)^2$ in our proof for Mantel's, and this result is just a corollary of this statement. More generally, the fact that $\phi$ is multiplicative means that all limit functionals are algebra homomorphisms between $\mathcal A^\sigma$ and $\mathbb R$.

## Generalizations
The method of flag algebras readily generalizes to numerous graph-like constructs. As Razborov wrote in his original paper, flags can be described with finite model theory instead. Instead of graphs, models of some nondegenerate universal first-order theory $T$ with equality in a finite relational signature $L$ with only predicate symbols can be used. A model $M$, which replaces our previous notion of a graph, has ground set $V(M)$, whose elements are called vertices.
Now, defining sub-models and model embeddings in an analogous way to subgraphs and graph embeddings, all of the definitions and theorems above can be nearly directly translated into the language of model theory. The fact that the theory of flag algebras generalizes well means that it can be used not only to solve problems in simple graphs, but also similar constructs such as, but not limited to, directed graphs and hypergraphs.
