# Logic redundancy

## o1 subject: Logic redundancy

Logic redundancy occurs in a logic gate network containing circuitry that does not affect the static logic function. There are several reasons why logic redundancy may exist. One reason is that it may have been added deliberately to suppress transient glitches (thus causing a race condition) in the output signals by having two or more product terms overlap with a third one.
