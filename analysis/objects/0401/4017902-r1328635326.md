# Reciprocal gamma function

## o1 subject: Reciprocal gamma function

In mathematics, the reciprocal gamma function is the function
$$f(z) = \frac{1}{\Gamma(z)},$$
where $\Gamma(z)$ denotes the gamma function. Since the gamma function is meromorphic and nonzero everywhere in the complex plane, its reciprocal is an entire function. As an entire function, it is of order 1 (meaning that $\log \log \lvert \tfrac{1}{\Gamma(z)}\rvert$ grows no faster than $\log \lvert z\rvert$), but of infinite type (meaning that $\log \lvert \tfrac{1}{\Gamma(z)}\rvert$ grows faster than any multiple of $\lvert z\rvert$, since its growth is approximately proportional to $\lvert z\rvert \log \lvert z\rvert$ in the left-half plane).
