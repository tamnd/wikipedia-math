# Ridgeline plot

## o1 subject: Ridgeline plot

A ridgeline plot (also known as a joyplot) is a series of line plots that are combined by vertical stacking to allow the easy visualization of changes through space or time. The plots are often overlapped slightly to allow the changes to be more clearly contrasted.
