# Schur class

## o1 subject: Schur class

In complex analysis, the Schur class is the set of holomorphic functions $f(z)$ defined on the open unit disk $\mathbb{D} = \{ z\in \mathbb{C} : |z|<1\}$ and satisfying $|f(z)| \leq 1$.
