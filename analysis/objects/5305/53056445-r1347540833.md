# Meissel–Lehmer algorithm

## o1 subject: Meissel–Lehmer algorithm

The Meissel–Lehmer algorithm (after Ernst Meissel and Derrick Henry Lehmer) is an algorithm that computes exact values of the prime-counting function.

## o5 statement: Formula for Pk(x, a)

### Formula for Pk(x, a)
For $k = 2$, we get the following formula for $P_{k}(x, a)$:
$\begin{aligned}
P_2(x, a) & =\left| \left\{ n : n \le x,~ n = p_b p_c, ~\text{with}~ a < b \le c \right\} \right| \\
& = \sum_{b = a+1}^{\pi(x^{1/2})} \left| \left\{ n : n \le x,~ n = p_b p_c, ~\text{with}~ b \le c \le \pi \left( \frac{x}{p_b} \right) \right\} \right| \\
& = \sum_{b = a+1}^{\pi(x^{1/2})} \left( \pi\left( \frac{x}{p_b} \right) - (b-1) \right) \\
& = \binom{a}{2} - \binom{\pi(x^{1/2})}{2} + \sum_{b = a+1}^{\pi(x^{1/2})} \pi\left( \frac{x}{p_b} \right).
\end{aligned}$
For $k \ge 3$, the identities for $P_{k}(x, a)$ can be derived similarly.
