# Ad nauseam

## o1 infobox: infobox phrase

## o2 subject: Ad nauseam

is a Latin term used to describe an argument or a discussion that has been extended to the figurative point of nausea. For example, "this has been discussed " indicates that the topic has been discussed extensively and those involved have grown sick of it.
