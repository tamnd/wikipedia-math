# Chord (geometry)

## o1 subject: Chord

In geometry, a chord (la) of a circle is a straight line segment whose endpoints both lie on a circular arc. If a chord were to be extended infinitely on both directions into a line, the object is a secant line. The perpendicular line passing through the chord's midpoint is called sagitta (Latin for "arrow").
