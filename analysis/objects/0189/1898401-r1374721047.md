# Arc length

## o1 subject: Arc length

Arc length is the length of a curve from beginning to end. Conceptually, if we imagined the curve as a string, the arc length is how long the string would be if we straightened it out.
It can be formalized mathematically for smooth curves using vector calculus and differential geometry, or for curves that might not necessarily be smooth as a least upper bound of lengths of polygonal chains. The curves for which this limit exists are called rectifiable curves, and the process of determining their arc length in this way is called curve rectification.

## o2 section: Definition

## o3 definition: Definition

## Definition
A curve in the plane can be approximated by connecting a finite number of points on the curve, in consecutive order, using (straight) line segments to create a polygonal chain. One may calculate the length of each linear segment using the Pythagorean theorem, and sum these lengths to obtain the total length of the chain; that approximation is known as the (cumulative) chordal distance.
If additional points are placed along the curve, the chordal distance will not decrease, but may increase. If chordal distance is bounded above, the least upper bound is called the length of the curve. A curve with the property that every arc between two points of the curve has finite length (even if the whole curve has infinite length) is called a rectifiable curve.
For a parametric curve (thought of as the trajectory of a particle, moving in the plane with position $(x(t),y(t))$ at time $t$) the arc length is the smallest quantity that is not exceeded by the length of any polygonal path along the curve. Suppose the curve is $\{\, (x(t), y(t)) : a \le t \le b\,\}$ for some numbers $a<b.$ Suppose $a = t_0 < t_1 < t_2 < \cdots < t_n = b.$ Then the sequence of points $\big( (x(t_i), y(t_i) \big)_{i=0}^n$ is a polygonal path, and its length is
$$\sum_{i=0}^{n-1} \text{distance from } (x(t_i), y(t_i)) \text{ to } (x_{t_{i+1}}, y_{t_{i+1}}).$$
The length of the curve is at least as much as the length of any polygonal path, but it is the smallest distance that is not exceeded by the length of any such polygonal path.

## o30 pointer-item: Non-rectifiable curve

## Curves with infinite length
As mentioned above, some curves are non-rectifiable. That is, there is no upper bound on the lengths of polygonal approximations; the length can be made arbitrarily large. Informally, such curves are said to have infinite length. There are continuous curves on which every arc (other than a single-point arc) has infinite length. An example of such a curve is the Koch curve. Another example of a curve with infinite length is the graph of the function defined by f(x) = x sin(1/x) for any open set with 0 as one of its delimiters and f(0) = 0. Sometimes the Hausdorff dimension and Hausdorff measure are used to quantify the size of such curves.
