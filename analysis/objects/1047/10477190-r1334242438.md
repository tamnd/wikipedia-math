# T-J model

## o1 subject: T-J model

In solid-state physics, the t-J model is a model first derived by Józef Spałek and Andrzej M. Oleś to explain antiferromagnetic properties of Mott insulators, taking into account experimental results about the strength of electron-electron repulsion in these materials.
