# Blichfeldt's theorem

## o1 subject: Blichfeldt's theorem

Blichfeldt's theorem is a mathematical theorem in the geometry of numbers, stating that whenever a bounded set in the Euclidean plane has area $A$, it can be translated so that it includes at least $\lceil A\rceil$ points of the integer lattice. Equivalently, every bounded set of area $A$ contains a set of $\lceil A\rceil$ points whose coordinates all differ by integers.

## Applications
### Minkowski's theorem
Minkowski's theorem, proved earlier than Blichfeldt's work by Hermann Minkowski, states that any convex set in the plane that is centrally symmetric around the origin, with area greater than four (or a compact symmetric set with area equal to four) contains a nonzero integer point. More generally, for a $d$-dimensional lattice $\Lambda$ whose fundamental parallelotopes have volume $L$, any set centrally symmetric around the origin with volume greater than $2^d L$ contains a nonzero lattice point.
Although Minkowski's original proof was different, Blichfeldt's theorem can be used in a simple proof of Minkowski's theorem. Let $X$ be any centrally symmetric set with volume greater than $2^d L$ (meeting the conditions of Minkowski's theorem), and scale it down by a factor of two to obtain a set $\tfrac{1}{2}X$ of volume greater than $L$. By Blichfeldt's theorem, $\tfrac{1}{2}X$ has two points $p$ and $q$ whose coordinatewise difference belongs to $L$. Reversing the shrinking operation, $2p$ and $2q$ belong to $X$. By symmetry $-2q$ also belongs to $X$, and by convexity the midpoint of $2p$ and $-2q$ belongs to $X$. But this midpoint is $p-q$, a nonzero point of $L$.
### Other applications
Many applications of Blichfeldt's theorem involve finding a nonzero lattice point in a large-enough set $X$, without imposing the assumption of convexity needed in Minkowski's theorem.
One method for doing this would be to find the largest centrally symmetric convex subset $K$ of $X$, and then to apply Minkowski's theorem to $K$, but this does not always give the strongest possible bounds on how big $X$ needs to be to ensure that it contains a lattice point.
In applying Minkowski's theorem, one uses a scaled copy $\tfrac{1}{2}K$ of $K$: any two lattice points in $\tfrac{1}{2}K$ have a nonzero lattice point difference in $K$ and therefore in $X$. It may be possible, instead, to find a subset $Y\subset X$, larger than $\tfrac{1}{2}K$, with the same property that its pairwise differences belong to $X$. When this is the case, the larger size of $Y$ relative to $\tfrac{1}{2}K$ leads to tighter bounds on how big $X$ needs to be sure of containing a lattice point.
For a centrally symmetric star domain, it is possible to use the calculus of variations to find the largest set $X'$ whose pairwise differences belong to $X$. Applications of this method include simultaneous Diophantine approximation, the problem of approximating a given set of irrational numbers by rational numbers that all have the same denominators.

## Generalizations
Analogues of Blichfeldt's theorem have been proven for other sets of points than lattices, showing that large enough regions contain many points from these sets. These include a theorem for Fuchsian groups, lattice-like subsets of $2\times 2$ matrices, and for the sets of vertices of Archimedean tilings.
Other generalizations replace the set $S$ by a measurable function, and prove that its sum over some set of translated lattice points is at least as large as its integral, or replace the single set $S$ with a family of sets.
