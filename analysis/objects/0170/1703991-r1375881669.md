# Muller's method

## o1 subject: Muller's method

Muller's method is a root-finding algorithm, a numerical method for solving equations of the form $f(x) = 0$. It was first presented by David E. Muller in 1956.

## o3 section: Algorithm

## o4 definition/construction: Algorithm

## Algorithm
The following pseudocode describes Muller's method for approximating a root of the equation $f(x) = 0$. It returns an estimate $x_{3}$ that satisfies $|x_{3} - x_{2}| < \varepsilon$, where $\varepsilon$ is a user-specified tolerance.
input: function $f$, initial approximations $x0$, $x1$, $x2$, tolerance $\varepsilon$, maximum iterations $Nmax$
for n = 0 to Nmax do
h0 ← x1 − x0
h1 ← x2 − x1
δ0 ← (f(x1) − f(x0)) / h0
δ1 ← (f(x2) − f(x1)) / h1
a ← (δ1 − δ0) / (h1 + h0)
b ← a·h1 + δ1
c ← f(x2)
if b ≥ 0 then
denominator ← b + sqrt(b² − 4·a·c)
else
denominator ← b − sqrt(b² − 4·a·c)
end if
x3 ← x2 − 2·c / denominator
if |x3 − x2| < ε then
return x3
end if
x0 ← x1
x1 ← x2
x2 ← x3
end for
return x3

## Example
Suppose we seek a solution of the polynomial
$$f(x) = -x^3 - x + 7 \,.$$
Applying Muller's method with initial guesses $x_{0}=1$, $x_{1}=2$ and $x_{2}=3$ and a tolerance of $10^{-9}$ gives the following approximations:

| $3$ | $-6.0$ | $-26.0$ | $-23$ | $-37.13552$ | $1.7612940604716703$ | $-2.2510 \times 10^{-1}$
| $4$ | $-6.76129$ | $-10.01078$ | $-0.22510$ | $-19.71273$ | $1.7384555878656442$ | $7.53555 \times 10^{-3}$
| $5$ | $-6.49974$ | $-10.03787$ | $7.53555 \times 10^{-3}$ | $-20.08549$ | $1.7392059353750402$ | $-2.08961 \times 10^{-5}$
| $6$ | $-5.23895$ | $-10.07452$ | $-2.08961 \times 10^{-5}$ | $-20.14903$ | $1.7392038612200968$ | $-3.42854 \times 10^{-11}$
