# Quasi-polynomial growth

## o1 subject: Quasi-polynomial growth

In theoretical computer science, a function $f(n)$ is said to exhibit quasi-polynomial growth when it has an upper bound of the form
$$f(n)=2^{O\bigl((\log n)^c\bigr)}$$
for some constant $c$, as expressed using big O notation. That is, it is bounded by an exponential function of a polylogarithmic function. This generalizes the polynomials and the functions of polynomial growth, for which one can take $c=1$. A function with quasi-polynomial growth is also said to be quasi-polynomially bounded.
