## Precise statement
For any fixed a < b,
$\lim_{x \rightarrow \infty} \left ( \frac {1}{x} \cdot \#\left\{ n \leq x : a \le \frac{\omega(n) - \log \log n}{\sqrt{\log \log n}} \le b \right\} \right ) = \Phi(a,b)$
where $\Phi(a,b)$ is the normal (or "Gaussian") distribution, defined as
$\Phi(a,b)= \frac{1}{\sqrt{2\pi}}\int_a^b e^{-t^2/2} \, dt.$
More generally, if f(n) is a strongly additive function ($\scriptstyle f(p_1^{a_1}\cdots p_k^{a_k})=f(p_1)+\cdots+f(p_k)$) with $\scriptstyle |f(p)|\le1$ for all prime p, then
$\lim_{x \rightarrow \infty} \left ( \frac {1}{x} \cdot \#\left\{ n \leq x : a \le \frac{f(n) - A(n)}{B(n)} \le b \right\} \right ) = \Phi(a,b)$
with
$A(n)=\sum_{p\le n}\frac{f(p)}{p},\qquad B(n)=\sqrt{\sum_{p\le n}\frac{f(p)^2}{p}}.$
