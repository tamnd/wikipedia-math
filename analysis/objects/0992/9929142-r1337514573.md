# 1 + 1 + 1 + 1 + ⋯

## o1 citation

## o2 subject: 1 + 1 + 1 + 1 + ⋯

In mathematics, 1 + 1 + 1 + 1 + ⋯, also written $\textstyle \sum_{n=1}^{\infty} n^0$, $\textstyle \sum_{n=1}^{\infty} 1^n$, or simply $\textstyle \sum_{n=1}^{\infty} 1$, is a divergent series. Nevertheless, it is sometimes imputed to have a value of $-\tfrac{1}{2}$, especially in physics. This value can be justified by certain mathematical methods for obtaining values from divergent series, including zeta function regularization.
