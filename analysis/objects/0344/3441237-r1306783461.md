# Pseudocircle

## o1 subject: Pseudocircle

The pseudocircle is the finite topological space X consisting of four distinct points {a,b,c,d} with the following non-Hausdorff topology:
$$\{\{a,b,c,d\}, \{a,b,c\}, \{a,b,d\}, \{a,b\}, \{a\}, \{b\}, \varnothing\}.$$
