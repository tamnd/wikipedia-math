# Separable extension

## o1 subject: Separable extension

In field theory, a branch of algebra, an algebraic field extension $E/F$ is called a separable extension if for every $\alpha\in E$, the minimal polynomial of $\alpha$ over $F$ is a separable polynomial (i.e., it is coprime to its formal derivative, or equivalently it has no repeated roots in any extension field). There is also a more general definition that applies when $E$ is not necessarily algebraic over $F$. An extension that is not separable is said to be inseparable.
