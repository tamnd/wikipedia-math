# 2.5D (visual perception)

## o1 subject: 2.5D

Two-and-a-half-dimensional (2.5D) perception is an effect in visual perception. It is the construction of an apparently three-dimensional environment from 2D retinal projections. While the result is technically 2D, it allows for the illusion of depth. It is easier for the eye to discern the distance between two items than the depth of a single object in the view field. Computers can use 2.5D to make images of human faces look lifelike.
