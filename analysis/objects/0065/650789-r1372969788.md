# Star (game theory)

## o1 subject: Star

In combinatorial game theory, star, written as $\ast$ or $\ast1$, is the value given to the game where both players have only the option of moving to the zero game. Star may also be denoted as the surreal form $\{0|0\}$. This game is an unconditional first-player win.
