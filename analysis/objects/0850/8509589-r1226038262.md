# Odd greedy expansion

## o1 subject: Odd greedy expansion

Does every rational number with an odd denominator have an odd greedy expansion?
In number theory, the odd greedy expansion problem asks whether a greedy algorithm for finding Egyptian fractions with odd denominators always succeeds. It is an open problem.

## o2 problem

Does every rational number with an odd denominator have an odd greedy expansion?

## Example
Let $x/y$ = 4/23.
23/4 = 5$\tfrac{3}{4}$; the next larger odd number is 7. So the first step expands
4/23 $=$ 1/7 + 5/161.
161/5 = 32$\tfrac{1}{5}$; the next larger odd number is 33. So the next step expands
4/23 $=$ 1/7 + 1/33 + 4/5313.
5313/4 = 1328$\tfrac{1}{4}$; the next larger odd number is 1329. So the third step expands
4/23 $=$ 1/7 + 1/33 + 1/1329 + 1/2353659.
Since the final term in this expansion is a unit fraction, the process terminates with this expansion as its result.
