# Non-measurable set

## o1 subject: Non-measurable set

In mathematics, a non-measurable set is a set which cannot be assigned a meaningful size, such as a length, area, or volume. The term is normally applied to Lebesgue measure, which assigns a length to a very large family of subsets of the real line but which cannot be extended to all subsets. In Zermelo–Fraenkel set theory with the axiom of choice, non-measurable subsets of $\mathbb{R}$ exist. The first example of one was constructed by Giuseppe Vitali in 1905. The existence of non-measurable sets marks a limit on how far the intuitive notion of size can be extended, and it is one of the best-known consequences of the axiom of choice.

## o19 definition/construction: Construction of a non-measurable set

## Construction of a non-measurable set
The following construction, which is essentially Vitali's, produces a set to which no notion of length can be assigned. Let $S$ be the unit circle in the complex plane, and let $G$ be the group of rotations through angles which are rational multiples of $\pi$. Then $G$ is countable, being isomorphic to $\mathbb{Q}/\mathbb{Z}$, while $S$ is uncountable. Hence $S$ splits into uncountably many orbits under $G$; the orbit of $s$ is the countable set $\{ s e^{i q \pi} : q \in \mathbb{Q} \}$. Using the axiom of choice, pick one point from each orbit to form a set $X$. Its rotated copies $gX$, one for each $g \in G$, are then pairwise disjoint, mutually congruent, countable, and together make up the whole circle. No rotation-invariant, countably additive probability measure on $S$ can give $X$ a value. The copies are congruent, so each would have to have the same measure as $X$; were that measure zero the circle would measure zero rather than one, and were it positive the circle would measure infinity (a countable sum of equal positive numbers diverges). No such measure can give $X$ a value; $X$ is therefore non-measurable.
The analogous construction on the line, grouping real numbers that differ by a rational number (the classes of $\mathbb{R}/\mathbb{Q}$) and picking one from each, yields the Vitali set.
