## o3 section: Definitions

## o4 definition: Definitions

## Definitions
A $\pi$-system is a non-empty collection of sets $P$ that is closed under non-empty finite intersections, which is equivalent to $P$ containing the intersection of any two of its elements.
If every set in this $\pi$-system is a subset of $\Omega$ then it is called a $\pi$-system on $\Omega.$
For any non-empty family $\Sigma$ of subsets of $\Omega,$ there exists a $\pi$-system $\mathcal{I}_{\Sigma},$ called the $\pi$-system generated by $\boldsymbol\varSigma$, that is the unique smallest $\pi$-system of $\Omega$ containing every element of $\Sigma.$
It is equal to the intersection of all $\pi$-systems containing $\Sigma,$ and can be explicitly described as the set of all possible non-empty finite intersections of elements of $\Sigma:$
$$\left\{E_1 \cap \cdots \cap E_n ~:~ 1 \leq n \in \mathbb{N} \text{ and } E_1, \ldots, E_n \in \Sigma\right\}.$$
A non-empty family of sets has the finite intersection property if and only if the $\pi$-system it generates does not contain the empty set as an element.

## o5 section: Examples

## o6 example: Examples

## Examples
- For any real numbers $a$ and $b,$ the intervals $(-\infty, a]$ form a $\pi$-system, and the intervals $(a, b]$ form a $\pi$-system if the empty set is also included.
- The topology (collection of open subsets) of any topological space is a $\pi$-system.
- Every filter is a $\pi$-system. Every $\pi$-system that doesn't contain the empty set is a prefilter (also known as a filter base).
- For any measurable function $f : \Omega \to \mathbb{R},$ the set $\mathcal{I}_f = \left\{f^{-1}((-\infty, x]) : x \in \mathbb{R}\right\}$ defines a $\pi$-system, and is called the $\pi$-system generated by $f.$ (Alternatively, $\left\{f^{-1}((a, b]) : a, b \in \mathbb{R}, a < b\right\} \cup \{\varnothing\}$ defines a $\pi$-system generated by $f.$)
- If $P_1$ and $P_2$ are $\pi$-systems for $\Omega_1$ and $\Omega_2,$ respectively, then $\{A_1 \times A_2 : A_1 \in P_1, A_2 \in P_2\}$ is a $\pi$-system for the Cartesian product $\Omega_1 \times \Omega_2.$
- Every -algebra is a $\pi$-system.

## o9 statement/theorem: The - theorem

### The $\pi$- theorem
Let $D$ be a -system, and let $\mathcal{I} \subseteq D$ be a $\pi$-system contained in $D.$ The $\pi$- theorem states that the -algebra $\sigma(\mathcal{I})$ generated by $\mathcal{I}$ is contained in $D ~:~$ $\sigma(\mathcal{I}) \subseteq D.$
The $\pi$- theorem can be used to prove many elementary measure theoretic results. For instance, it is used in proving the uniqueness claim of the Carathéodory extension theorem for -finite measures.
The $\pi$- theorem is closely related to the monotone class theorem, which provides a similar relationship between monotone classes and algebras, and can be used to derive many of the same results. Since $\pi$-systems are simpler classes than algebras, it can be easier to identify the sets that are in them while, on the other hand, checking whether the property under consideration determines a -system is often relatively easy. Despite the difference between the two theorems, the $\pi$- theorem is sometimes referred to as the monotone class theorem.
#### Example
Let $\mu_1, \mu_2 : F \to \mathbb{R}$ be two measures on the -algebra $F,$ and suppose that $F = \sigma(I)$ is generated by a $\pi$-system $I.$ If
- $\mu_1(A) = \mu_2(A)$ for all $A \in I,$ and
- $\mu_1(\Omega) = \mu_2(\Omega) < \infty,$
then $\mu_1 = \mu_2.$
This is the uniqueness statement of the Carathéodory extension theorem for finite measures. If this result does not seem very remarkable, consider the fact that it usually is very difficult or even impossible to fully describe every set in the -algebra, and so the problem of equating measures would be completely hopeless without such a tool.
Idea of the proof
Define the collection of sets
$$D = \left\{ A \in \sigma(I) \colon \mu_1(A) = \mu_2(A) \right\}.$$
By the first assumption, $\mu_1$ and $\mu_2$ agree on $I$ and thus $I \subseteq D.$ By the second assumption, $\Omega \in D,$ and it can further be shown that $D$ is a -system. It follows from the $\pi$- theorem that $\sigma(I) \subseteq D \subseteq \sigma(I),$ and so $D = \sigma(I).$ That is to say, the measures agree on $\sigma(I).$

#### Example
Let $Z = \left(Z_1, Z_2\right),$ where $Z_1, Z_2 \sim \mathcal{N}(0, 1)$ are iid standard normal random variables. Define the radius and argument (arctan) variables
$$R = \sqrt{Z_1^2 + Z_2^2}, \qquad \Theta = \tan^{-1}\left(Z_2 / Z_1\right).$$
Then $R$ and $\Theta$ are independent random variables.
To prove this, it is sufficient to show that the $\pi$-systems $\mathcal{I}_R, \mathcal{I}_\Theta$ are independent: that is, for all $\rho \in [0, \infty)$ and $\theta \in [0, 2 \pi],$
$$\operatorname{P}[R \leq \rho, \Theta \leq \theta] = \operatorname{P}[R \leq \rho] \operatorname{P}[\Theta \leq \theta].$$
Confirming that this is the case is an exercise in changing variables. Fix $\rho \in [0, \infty)$ and $\theta \in [0, 2 \pi],$ then the probability can be expressed as an integral of the probability density function of $Z.$
$$\begin{aligned}
\operatorname P [R \leq \rho, \Theta \leq \theta] &= \int_{R \leq \rho, \, \Theta \leq \theta} \frac{1}{2\pi}\exp\left({-\frac12(z_1^2 + z_2^2)}\right) dz_1 \, dz_2 \\[5pt]
& = \int_0^{\theta} \int_0^\rho \frac{1}{2 \pi}e^{-\frac{r^2}{2}} \; r \, dr \, d\tilde\theta \\[5pt]
& = \left(\int_0^\theta \frac{1}{2 \pi} \, d\tilde \theta\right) \; \left(\int_0^\rho e^{-\frac{r^2}{2}} \; r \, dr\right) \\[5pt]
& = \operatorname P[\Theta \leq \theta]\operatorname P[R \leq \rho].
\end{aligned}$$
