# Formal criteria for adjoint functors

## o1 subject: Formal criteria for adjoint functors

In category theory, a branch of mathematics, the formal criteria for adjoint functors are criteria for the existence of a left or right adjoint of a given functor.

## o2 citation

## o3 citation

## o4 statement/theorem: Freyd's adjoint functor theorem

Let $G: \mathcal{B} \to \mathcal{A}$ be a functor between categories such that $\mathcal{B}$ is complete. Then the following are equivalent (for simplicity ignoring the set-theoretic issues):
# G has a left adjoint.
# $G$ preserves all limits, and the following solution set condition is satisfied: for each object x in $\mathcal{A}$, there exist a set I and an I-indexed family of morphisms $f_i : x \to G y_i$ such that each morphism $x \to Gy$ is of the form $G(y_i \to y) \circ f_i$ for some morphism $y_i \to y$.

## o5 statement: Kan criterion for the existence of a left adjoint

Let $G: \mathcal{B} \to \mathcal{A}$ be a functor between categories. Then the following are equivalent.
# G has a left adjoint.
# G preserves limits and, for each object x in $\mathcal{A}$, the limit $\lim ({(x \downarrow G) \to \mathcal{B}})$ exists in $\mathcal{B}$.
# The right Kan extension $G_! 1_{\mathcal{B}}$ of the identity functor $1_{\mathcal{B}}$ along G exists and is preserved by G.
Moreover, when this is the case then a left adjoint of G can be computed using the right Kan extension.
