# Convergent matrix

## o1 subject: Convergent matrix

In linear algebra, a convergent matrix is a matrix that converges to the zero matrix under matrix exponentiation.

## o2 section: Background

## o3 section: Definition

## o4 definition: Definition

## Definition
We call an n × n matrix T a convergent matrix if
::
$\lim_{k \to \infty}( \mathbf T^k)_{ij} = 0,$
for each i = 1, 2, ..., n and j = 1, 2, ..., n.

## o5 equation: 1

$\lim_{k \to \infty}( \mathbf T^k)_{ij} = 0,$

## o9 section: Example

## o10 example: Example

## Example
Let
$\begin{aligned}
& \mathbf{T} = \begin{pmatrix}
\frac{1}{4} & \frac{1}{2} \\[4pt]
0 & \frac{1}{4}
\end{pmatrix}.
\end{aligned}$
Computing successive powers of T, we obtain
$\begin{aligned}
& \mathbf{T}^2 = \begin{pmatrix}
\frac{1}{16} & \frac{1}{4} \\[4pt]
0 & \frac{1}{16}
\end{pmatrix}, \quad \mathbf{T}^3 = \begin{pmatrix}
\frac{1}{64} & \frac{3}{32} \\[4pt]
0 & \frac{1}{64}
\end{pmatrix}, \quad \mathbf{T}^4 = \begin{pmatrix}
\frac{1}{256} & \frac{1}{32} \\[4pt]
0 & \frac{1}{256}
\end{pmatrix}, \quad \mathbf{T}^5 = \begin{pmatrix}
\frac{1}{1024} & \frac{5}{512} \\[4pt]
0 & \frac{1}{1024}
\end{pmatrix},
\end{aligned}$
$\begin{aligned}
\mathbf{T}^6 = \begin{pmatrix}
\frac{1}{4096} & \frac{3}{1024} \\[4pt]
0 & \frac{1}{4096}
\end{pmatrix},
\end{aligned}$
and, in general,
$\begin{aligned}
\mathbf{T}^k = \begin{pmatrix}
(\frac{1}{4})^k & \frac{k}{2^{2k - 1}} \\[4pt]
0 & (\frac{1}{4})^k
\end{pmatrix}.
\end{aligned}$
Since
$\lim_{k \to \infty} \left( \frac{1}{4} \right)^k = 0$
and
$\lim_{k \to \infty} \frac{k}{2^{2k - 1}} = 0,$
T is a convergent matrix. Note that ρ(T) = $\tfrac{1}{4}$, where ρ(T) represents the spectral radius of T, since $\tfrac{1}{4}$ is the only eigenvalue of T.

## o11 section: Characterizations

## o12 statement/fact: Characterizations

## Characterizations
Let T be an n × n matrix. The following properties are equivalent to T being a convergent matrix:
- $\lim_{k \to \infty} \| \mathbf T^k \| = 0,$ for some natural norm;
- $\lim_{k \to \infty} \| \mathbf T^k \| = 0,$ for all natural norms;
- $\rho( \mathbf T ) < 1$;
- $\lim_{k \to \infty} \mathbf T^k \mathbf x = \mathbf 0,$ for every x.
