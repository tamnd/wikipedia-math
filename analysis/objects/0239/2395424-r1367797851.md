# Mex (mathematics)

## o1 subject: Mex

In mathematics, the mex (minimum excluded value) of a subset of a well-ordered set is the smallest value from the whole set that does not belong to the subset. That is, it is the minimum value of the complement set.

## Examples
The following examples all assume that the given set is a subset of the class of ordinal numbers:
$$\begin{array}{lcl}
\operatorname{mex}(\emptyset) &=& 0 \\[2pt]
\operatorname{mex}(\{1, 2, 3\}) &=& 0 \\[2pt]
\operatorname{mex}(\{0, 2, 4, 6, \ldots\}) &=& 1 \\[2pt]
\operatorname{mex}(\{0, 1, 4, 7, 12\}) &=& 2 \\[2pt]
\operatorname{mex}(\{0, 1, 2, 3, \ldots\}) &=& \omega \\[2pt]
\operatorname{mex}(\{0, 1, 2, 3, \ldots, \omega\}) &=& \omega+1
\end{array}$$
where $\omega$ is the limit ordinal for the natural numbers.
