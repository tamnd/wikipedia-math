# Goldston–Pintz–Yıldırım sieve

## o1 subject: Goldston–Pintz–Yıldırım sieve

The Goldston–Pintz–Yıldırım sieve (also called GPY sieve or GPY method) is a sieve method and variant of the Selberg sieve with generalized, multidimensional sieve weights. The sieve led to a series of important breakthroughs in analytic number theory.

### Notation
Fix a $k\in \mathbb{N}$ and the following notation:
- $\mathbb{P}$ is the set of prime numbers and $1_{\mathbb{P}}(n)$ the characteristic function of that set,
- $\Lambda(n)$ is the von Mangoldt function,
- $\omega(n)$ is the small prime omega function (which counts the distinct prime factors of $n$)
- $\mathcal{H}=\{h_1,\dots,h_k\}$ is a set of distinct nonnegative integers $h_i\in\mathbb{Z}_+\cup \{0\}$.
- $\theta(n)$ is another characteristic function of the primes defined as
$\theta(n)=\begin{cases} \log(n) & \text{if }n\in \mathbb{P}\\ 0 & \text{else.}\end{cases}$
Notice that $\theta(n)=\log((n-1)1_{\mathbb{P}}(n)+1)$.
For an $\mathcal{H}$ we also define
- $\mathcal{H}(n):=(n+h_1,\dots,n+h_k)$,
- $P_{\mathcal{H}}(n):=(n+h_1)(n+h_2)\cdots (n+h_k)$
- $\nu_p(\mathcal{H})$ is the amount of distinct residue classes of $\mathcal{H}$ modulo $p$. For example $\nu_3(\{0,2,4\})=3$ and $\nu_3(\{0,2\})=2$ because $\{0,2,4\}\stackrel{\pmod{3}}{=}\{0,1,2\}$ and $\{0,2\}\stackrel{\pmod{3}}{=}\{0,2\}$.
If $\nu_p(\mathcal{H})<k$ for all $p\in \mathbb{P}$, then we call $\mathcal{H}$ admissible.

## o9 definition/construction: Construction

### Construction
Let $\mathcal{H}=\{h_1,\dots,h_k\}$ be admissible and consider the following sifting function
$\mathcal{S}(N,c;\mathcal{H}):=\sum\limits_{n=N+1}^{2N}\left(\sum\limits_{h_i\in \mathcal {H}}1_{\mathbb{P}}(n+h_i)-c\right)w(n)^2,\quad w(n)\in \mathbb{R},\quad c>0,$
where $w(n)$ is a weight function we derive later.
For each $n\in [N+1,2N]$ this sifting function counts the primes of the form $n+h_i$ minus some threshold $c$, so if $\mathcal{S}>0$ then there exist some $n$ such that at least $\lfloor c \rfloor +1$ are prime numbers in $\mathcal{H}(n)$.
Since $1_{\mathbb{P}}(n)$ has not so nice analytic properties one chooses rather the following sifting function
$\mathcal{S}(N;\mathcal{H}):=\sum\limits_{n=N+1}^{2N}\left(\sum\limits_{h_i\in \mathcal{H}}\theta(n+h_i)-\log(3N)\right)w(n)^2.$
Since $\log(N)<\theta(n+h_i)<\log(2N)$ and $c=\log(3n)$, we have $\mathcal{S}>0$ only if there are at least two prime numbers $n+h_i$ and $n+h_j$. Next we have to choose the weight function $w(n)$ so that we can detect prime k-tuples.
#### Derivation of the weights
A candidate for the weight function is the generalized von Mangoldt function
$\Lambda_k(n)=\sum\limits_{d\mid n}\mu(d)\left(\log\left(\frac{n}{d}\right)\right)^k,$
which has the following property: if $\omega(n)>k$, then $\Lambda_k(n)=0$. This functions also detects factors which are proper prime powers, but this can be removed in applications with a negligible error.
So if $\mathcal{H}(n)$ is a prime k-tuple, then the function
$\Lambda_k(n;\mathcal{H})=\frac{1}{k!}\Lambda_k(P_{\mathcal{H}}(n))$
will not vanish. The factor $1/k!$ is just for computational purposes. The (classical) von Mangoldt function can be approximated with the truncated von Mangoldt function
$\Lambda(n)\approx \Lambda_R(n):=\sum\limits_{\begin{array}{c} d\mid n\\ d\leq R \end{array}}\mu(d)\log\left(\frac{R}{d}\right),$
where $R$ now no longer stands for the length of $\mathcal{H}$ but for the truncation position. Analogously we approximate $\Lambda_k(n;\mathcal{H})$ with
$\Lambda_R(n;\mathcal{H})=\frac{1}{k!}\sum\limits_{\begin{array}{c} d\mid P_{\mathcal{H}}(n)\\ d\leq R \end{array}}\mu(d)\left(\log\left(\frac{R}{d}\right)\right)^k$
For technical purposes we rather want to approximate tuples with primes in multiple components than solely prime tuples and introduce another parameter $0\leq \ell \leq k$ so we can choose to have $k+\ell$ or less distinct prime factors. This leads to the final form
$\Lambda_R(n;\mathcal{H},\ell)=\frac{1}{(k+\ell)!}\sum\limits_{\begin{array}{c} d\mid P_{\mathcal{H}}(n)\\ d\leq R \end{array}}\mu(d)\left(\log\left(\frac{R}{d}\right)\right)^{k+\ell}$
Without this additional parameter $\ell$ one has for a distinct $d=d_1d_2\cdots d_k$ the restriction $d_1\leq R, d_2\leq R, \dots ,d_k\leq R$ but by introducing this parameter one gets the more looser restriction $d_1d_2\dots d_k\leq R$.
So one has a $k+\ell$-dimensional sieve for a $k$-dimensional sieve problem.

## o14 proof: Proof of the main theorem by Goldston, Pintz and Yıldırım

### Proof of the main theorem by Goldston, Pintz and Yıldırım
Consider $(\mathcal{H}_1,\ell_1, k_1)$ and $(\mathcal{H}_2,\ell_2, k_2)$ and $1\leq h_0\leq R$ and define $M:=k_1+k_2+\ell_1+\ell_2$. In their paper, Goldston, Pintz and Yıldırım proved in two propositions that under suitable conditions two asymptotic formulas of the form
$\sum\limits_{n\leq N}\Lambda_R(n;\mathcal{H}_1,\ell_1)\Lambda_R(n;\mathcal{H}_2,\ell_2) = C_1\left(\mathcal{S}(\mathcal{H}^{i})+o_M(1)\right)N$
and
$\sum\limits_{n\leq N}\Lambda_R(n;\mathcal{H}_1,\ell_1)\Lambda_R(n;\mathcal{H}_2,\ell_2)\theta(n+h_0)
= C_2\left(\mathcal{S}(\mathcal{H}^j)+o_M(1)\right)N$
hold, where $C_1,C_2$ are two constants, $\mathcal{S}(\mathcal{H}^{i})$ and $\mathcal{S}(\mathcal{H}^{j})$ are two singular series whose description we omit here.
Finally one can apply these results to $\mathcal{S}$ to derive the theorem by Goldston, Pintz and Yıldırım on infinitely many prime tuples whose distances are arbitrarily smaller than the average distance.
