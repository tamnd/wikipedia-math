# Confidence region

## o1 subject: Confidence region

In statistics, a confidence region is a multivariate generalization of a confidence interval. For a bivariate normal distribution, it is an ellipse, also known as the error ellipse. More generally, it is a set of points in an n-dimensional space, often represented as a hyperellipsoid around a point estimate which is a solution to a problem, although other shapes can occur depending on the distribution.
