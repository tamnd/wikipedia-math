# Ridge function

## o1 subject: Ridge function

In mathematics, a ridge function is any function $f:\mathbb{R}^d\rightarrow\mathbb{R}$ that can be written as the composition of an univariate function $g:\mathbb{R} \rightarrow\mathbb{R}$, that is called a profile function, with an affine transformation, given by a direction vector $a \in \mathbb{R}^d$ with shift $b \in \mathbb{R}$.
