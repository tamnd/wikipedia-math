## Facts
- Every number in a reduced residue system modulo n is a generator for the additive group of integers modulo n.
- A reduced residue system modulo n is a group under multiplication modulo n.
- If $\{r_{1}, r_{2}, ... , r_{\varphi(n)}\}$ is a reduced residue system modulo n with n > 2, then ∑i ri ≡ 0 (mod n).
- If $\{r_{1}, r_{2}, ... , r_{\varphi(n)}\}$ is a reduced residue system modulo n, and a is an integer such that gcd(a, n) = 1, then $\{ar_{1}, ar_{2}, ... , ar_{\varphi(n)}\}$ is also a reduced residue system modulo n.
