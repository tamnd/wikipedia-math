# Global dominating set

## o1 subject: Global dominating set

In graph theory, a global dominating set is a dominating set $S$ of a graph $G$ that is also a dominating set of the complement graph $\bar{G}$. The global domination number $\gamma_g(G)$ is the minimum cardinality of a global dominating set of $G$. The concept was introduced by E. Sampathkumar in 1989.

## o2 citation: sampathkumar1989

## o3 section: Definition

## o4 definition: Definition

## Definition
Let $G = (V, E)$ be a graph with vertex set $V$ and edge set $E$. A set $S \subseteq V$ is a dominating set of $G$ if every vertex in $V - S$ is adjacent to at least one vertex in $S$. A dominating set $S$ is called a global dominating set (or g.d. set) if $S$ is also a dominating set of the complement $\bar{G}$.
Equivalently, a dominating set $S$ of $G$ is a global dominating set if and only if for each vertex $v \in V - S$, there exists a vertex $u \in S$ such that $u$ is not adjacent to $v$ in $G$.

## o5 section: Properties

## o6 statement/fact: Properties

## Properties
The following properties hold for any graph $G$:
- $\gamma_g(G) = \gamma_g(\bar{G})$
- $\gamma(G) \leq \gamma_g(G)$, where $\gamma(G)$ is the domination number of $G$
- $\bar{\gamma}(G) \leq \gamma_g(G)$, where $\bar{\gamma}(G) = \gamma(\bar{G})$
- $\frac{\gamma(G) + \bar{\gamma}(G)}{2} \leq \gamma_g(G) \leq \gamma(G) + \bar{\gamma}(G)$
For a graph $G$ of order $p$ without isolated vertices:
- $\gamma(G) + \gamma_g(G) \leq p + 1$
- $\gamma_g(G) \leq \max\{\chi(G), \chi(\bar{G})\}$, where $\chi(G)$ is the chromatic number of $G$
The global domination number exhibits invariance under certain graph operations. For example, for cycles $C_n$ (with $n \neq 3, n \neq 5$), the global domination number remains unchanged under the operation of edge duplication, and similarly for wheels $W_n$.
### Bounds
For a connected graph $G$ of order $n$ with maximum degree $\Delta(G)$, diameter $d(G)$, radius $r(G)$, and the set of support vertices (vertices adjacent to vertices with degree $1$) $Supp(G)$, the following lower bound holds:
$L = \max\left\{\frac{n}{\Delta(G)+1}, \frac{2r(G)}{3}, \frac{d(G)+1}{3}, |Supp(G)|\right\} \leq \gamma_g(G)$
Upper bounds have also been established:
- $\gamma_g(G) \leq \min\{\Delta(G), \Delta(\bar{G})\} + 1$
- $\gamma_g(G) \leq \max\{\delta(G), \delta(\bar{G})\} + 1$ when $\delta(G) = \delta(\bar{G}) > 2$, where $\delta(G)$ is the minimum degree

## o15 definition/construction: Algorithms

## Algorithms
Both exact and heuristic algorithms have been developed for the global domination problem:
Exact algorithms:
- An integer linear programming (ILP) formulation using $2n$ constraints to ensure domination in both $G$ and $\bar{G}$
- An implicit enumeration algorithm using binary search over feasible solution sizes, guided by lower and upper bounds
Heuristic algorithms:
- Greedy algorithms that iteratively select vertices maximizing the number of newly dominated vertices in both the graph and its complement
- A purification procedure that reduces the size of a global dominating set by removing redundant vertices while maintaining the domination property

## o16 section: Applications

## o17 application: Applications

## Applications
Global dominating sets arise naturally in network reliability contexts. Consider a graph representing a network of roads connecting various locations, where some locations have supply stations. If the primary links (edges of $G$) may fail, maintaining supply requires that stations can reach all locations through alternative links (edges of $\bar{G}$). A global dominating set represents the minimum set of supply stations needed to maintain service regardless of which network (primary or backup) is operational.
In social network analysis, when modeling individuals with certain social behaviors, a standard dominating set identifies influential individuals, but does not account for potential changes in influence relationships. A global dominating set ensures coverage even if the influence network changes to its complement, providing resilience against dynamic network changes.
