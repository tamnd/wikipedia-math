# Simplex graph

## o1 subject: Simplex graph

In graph theory, a branch of mathematics, the simplex graph $\kappa(G)$ of an undirected graph $G$ is itself a graph, with one node for each clique (a set of mutually adjacent vertices) in $G$. Two nodes of $\kappa(G)$ are linked by an edge whenever the corresponding two cliques differ in the presence or absence of a single vertex.
