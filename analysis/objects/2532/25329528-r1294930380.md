# Wrapped distribution

## o1 subject: Wrapped distribution

In probability theory and directional statistics, a wrapped probability distribution is a continuous probability distribution that describes data points that lie on a unit n-sphere. In one dimension, a wrapped distribution consists of points on the unit circle. If $\phi$ is a random variate in the interval $(-\infty,\infty)$ with probability density function (PDF) $p(\phi)$, then $z = e^{i\phi}$ is a circular variable distributed according to the wrapped distribution $p_{wz}(\theta)$ and $\theta = \arg(z)$ is an angular variable in the interval $(-\pi,\pi]$ distributed according to the wrapped distribution $p_w(\theta)$.
