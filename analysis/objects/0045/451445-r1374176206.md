# Cube (algebra)

## o1 subject: Cube

In arithmetic and algebra, the cube of a number $n$ is its third power, that is, the result of multiplying three instances of $n$ together.
The cube of a number $n$ is denoted $n^{3}$, using a superscript 3, for example 23 $=$ 8. The cube operation can also be defined for any other mathematical expression, for example $(x + 1)^{3}$.

## o12 statement/theorem: Fermat's Last Theorem for cubes

### Fermat's Last Theorem for cubes
The equation $x^{3} + y^{3} = z^{3}$ has no non-trivial (i.e. $xyz \ne 0$) solutions in integers. In fact, it has none in Eisenstein integers.
Both of these statements are also true for the equation $x^{3} + y^{3} = 3z^{3}$.
