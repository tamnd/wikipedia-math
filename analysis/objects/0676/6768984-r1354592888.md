# Phase margin

## o1 subject: Phase margin

In electronic amplifiers, the phase margin (PM) is the difference between the phase lag $\varphi$ (< 0) and -180°, for an amplifier's output signal (relative to its input) at zero dB gain - i.e. unity gain, or that the output signal has the same amplitude as the input.
