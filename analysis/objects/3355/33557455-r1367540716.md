# Morris method

## o1 subject: Morris method

In applied statistics, the Morris method for global sensitivity analysis is a so-called one-factor-at-a-time method, meaning that in each run only one input parameter is given a new value. It facilitates a global sensitivity analysis by making a number $r$ of local changes at different points $x(1 \rightarrow r)$ of the possible range of input values.

## o6 statement/generalization: Variations

### Variations
In the original work of Morris the two sensitivity measures proposed were respectively the mean, $\mu$,
and the standard deviation, $\sigma$, of $F_i$. However, choosing Morris has the drawback that, if the distribution $F_i$ contains negative elements, which occurs when the model is non-monotonic, when computing the mean some effects may cancel each other out. Thus, the measure $\mu$ on its own is not reliable for ranking factors in order
of importance. It is necessary to consider at the same time the values of $\mu$ and $\sigma$, as a factor with elementary effects of different signs (that cancel each other out) would have a low value of $\mu$ but a
considerable value of $\sigma$ that avoids underestimating the factors.
