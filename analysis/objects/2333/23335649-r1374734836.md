# Canonical map

## o1 subject: Canonical map

In mathematics, a canonical map, also called a natural map, is a map or morphism between objects that arises naturally from the definition or the construction of the objects. Often, it is a map which preserves the widest amount of structure. A choice of a canonical map sometimes depends on a convention (e.g., a sign convention).

## o3 example: Examples

## Examples
- If $N$ is a normal subgroup of a group $G$, then there is a canonical surjective group homomorphism from $G$ to the quotient group $G / N$, that sends an element $g$ to the coset determined by $g$.
- If $I$ is an ideal of a ring $R$, then there is a canonical surjective ring homomorphism from $R$ onto the quotient ring $R / I$ that sends an element $r$ to its coset $I + r$.
- If $S$ is a multiplicative set in commutative ring $R$, then there is a canonical ring homomorphism from $R$ to the localization $S^{-1}R$ that sends element $r$ to $r/1$ in the localization.
- If $R_{f}$ is the localization of commutative ring $R$ by $S = \{1, f, f^{2}, f^{3}, ...\}$, and $R_{p}$ is the localization of $R$ by $S = R \backslash p$, where $p$ is a prime ideal such that $f \notin p$, there is a canonical ring homomorphism $\alpha : R_{f} \to R_{p}$ mapping $a/f^{n}$ as an element of $R_{f}$ to $a/f^{n}$ as an element of $R_{p}$. If φ is the canonical map $R \to R_{p}$ and ψ is the canonical map $R \to R_{f}$, then α is the unique map such that $\varphi = \alpha \circ \psi$.
- If $V$ is a finite-dimenstional vector space, then there is a canonical map from $V$ to the second dual space of $V$, that sends a vector $v$ to the linear functional $f_{v}$ defined by $f_{v}(\lambda) = \lambda(v)$.
- If $f: R \to S$ is a homomorphism between commutative rings, then $S$ can be viewed as an algebra over $R$. The ring homomorphism $f$ is then called the structure map (for the algebra structure). The corresponding map on the prime spectra $f^{*}: \operatorname{Spec}(S) \to \operatorname{Spec}(R)$ is also called the structure map. More generally, a scheme X over a scheme S is one equipped with a structure morphism $X \to S$; for a scheme over a field k (e.g., a variety), this is a morphism $X \to \operatorname{Spec}(k)$.
- If $E$ is a vector bundle over a topological space $X$, then the projection map from $E$ to $X$ is the structure map.
- In topology, a canonical map is a function $f$ mapping a set $X \to X / R$ ($X \bmod R$), where $R$ is an equivalence relation on $X$, that takes each $x$ in $X$ to the equivalence class $[x] \bmod R$.
