# Null (mathematics)

## o1 subject: Null

In mathematics, the word null (from meaning "zero", which is from meaning "none") is often associated with the concept of zero, or with the concept of nothing. It is used in varying contexts from "having zero members in a set" (e.g., null set) to "having a value of zero" (e.g., null vector).
