# Quotient graph

::: {#o1 .subject cue=lead name="Quotient graph"}

In [graph theory](wikipedia://en/12401), a **quotient graph** *Q* of a graph *G* is a graph whose vertices are blocks of a [partition](wikipedia://en/340240) of the vertices of *G* and where block *B* is adjacent to block *C* if some vertex in *B* is adjacent to some vertex in *C* with respect to the edge set of *G*.[^o2] In other words, if *G* has edge set *E* and vertex set *V* and *R* is the [equivalence relation](wikipedia://en/9259) induced by the partition, then the quotient graph has vertex set *V*/*R* and edge set {(\[*u*\]<sub>*R*</sub>, \[*v*\]<sub>*R*</sub>) | (*u*, *v*) ∈ *E*(*G*)}.

:::

More formally, a quotient graph is a [quotient object](https://en.wikipedia.org/wiki/Quotient_object) in the [category](wikipedia://en/53759) of graphs. The category of graphs is [concretizable](https://en.wikipedia.org/wiki/Concretizable) – mapping a graph to its set of vertices makes it a [concrete category](wikipedia://en/167001) – so its objects can be regarded as "sets with additional structure", and a quotient graph corresponds to the graph induced on the [quotient set](https://en.wikipedia.org/wiki/Quotient_set) *V*/*R* of its vertex set *V*. Further, there is a [graph homomorphism](wikipedia://en/676328) (a [quotient map](https://en.wikipedia.org/wiki/Quotient_map)) from a graph to a quotient graph, sending each vertex or edge to the equivalence class that it belongs to. Intuitively, this corresponds to "gluing together" (formally, "identifying") vertices and edges of the graph.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

A graph is trivially a quotient graph of itself (each block of the partition is a single vertex), and the graph consisting of a single point is the quotient graph of any non-empty graph (the partition consisting of a single block of all vertices). The simplest non-trivial quotient graph is one obtained by identifying two vertices ([vertex identification](https://en.wikipedia.org/wiki/Vertex_identification)); if the vertices are connected, this is called [edge contraction](wikipedia://en/3758115).

:::

## Special types of quotient {#Special_types_of_quotient}

*Image: Graph Condensation.svg.* A directed graph (blue and black) and its condensation (yellow). The strongly connected components (subsets of blue vertices within each yellow vertex) form the blocks of a partition giving rise to the quotient.

The [condensation](https://en.wikipedia.org/wiki/Condensation_%28graph_theory%29) of a directed graph is the quotient graph where the [strongly connected components](wikipedia://en/684680) form the blocks of the partition. This construction can be used to derive a [directed acyclic graph](wikipedia://en/204002) from any directed graph.[^o6]

The result of one or more [edge contractions](wikipedia://en/3758115) in an undirected graph *G* is a quotient of *G*, in which the blocks are the [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) of the subgraph of *G* formed by the contracted edges. However, for quotients more generally, the blocks of the partition giving rise to the quotient do not need to form connected subgraphs.

If *G* is a [covering graph](wikipedia://en/21123339) of another graph *H*, then *H* is a quotient graph of *G*. The blocks of the corresponding partition are the inverse images of the vertices of *H* under the covering map. However, covering maps have an additional requirement that is not true more generally of quotients, that the map be a local isomorphism.[^o7]

## Computational complexity {#Computational_complexity}

Given an $n$-vertex [cubic graph](wikipedia://en/980508) *G* and a parameter $k$, the computational complexity of determining whether *G* can be obtained as a quotient of a [planar graph](wikipedia://en/24314) with $n + k$ vertices is [NP-complete](https://en.wikipedia.org/wiki/NP-complete).[^o9]
