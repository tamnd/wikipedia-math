# Ky Fan inequality

::: {#o1 .subject cue=lead name="Ky Fan inequality"}

In [mathematics](wikipedia://en/18831), the term **Ky Fan inequality** refers to an inequality involving the [geometric mean](wikipedia://en/13046) and [arithmetic mean](wikipedia://en/612) of two sets of [real numbers](https://en.wikipedia.org/wiki/Real_numbers) within the [unit interval](wikipedia://en/49324). The result was published on page 5 of the book *Inequalities* by [Edwin F. Beckenbach](wikipedia://en/36442901) and [Richard E. Bellman](https://en.wikipedia.org/wiki/Richard_E._Bellman) (1961), who attribute it to an unpublished result by [Ky Fan](https://en.wikipedia.org/wiki/Ky_Fan). They discuss the inequality in connection with the [inequality of arithmetic and geometric means](https://en.wikipedia.org/wiki/Inequality_of_arithmetic_and_geometric_means) and [Augustin Louis Cauchy](https://en.wikipedia.org/wiki/Augustin_Louis_Cauchy)'s proof of that inequality via forward-backward induction—a method that can also be used to prove the Ky Fan inequality.

:::

This inequality is a special case of [Levinson's inequality](wikipedia://en/7473871) and serves as a foundation for several generalizations and refinements, some of which are referenced below.

## Statement of the classical version {#Statement_of_the_classical_version}

If with $0\le x_i\le \frac{1}{2}$ for *i* = 1, ..., *n*, then

$$\frac{ \bigl(\prod_{i=1}^n x_i\bigr)^{1/n} } { \bigl(\prod_{i=1}^n (1-x_i)\bigr)^{1/n} } \le \frac{ \frac1n \sum_{i=1}^n x_i } { \frac1n \sum_{i=1}^n (1-x_i) }$$

with equality [if and only if](wikipedia://en/14922) *x*<sub>1</sub> = *x*<sub>2</sub> = ⋅ ⋅ ⋅ = *x<sub>n</sub>*.

### Remark {#Remark}

Let

$$A_n:=\frac1n\sum_{i=1}^n x_i,\qquad G_n=\biggl(\prod_{i=1}^n x_i\biggr)^{1/n}$$

denote the arithmetic and geometric mean, respectively, of *x*<sub>1</sub>, . . ., *x<sub>n</sub>*, and let

$$A_n':=\frac1n\sum_{i=1}^n (1-x_i),\qquad G_n'=\biggl(\prod_{i=1}^n (1-x_i)\biggr)^{1/n}$$

denote the arithmetic and geometric mean, respectively, of 1 − *x*<sub>1</sub>, . . ., 1 − *x<sub>n</sub>*. Then the Ky Fan inequality can be written as

$$\frac{G_n}{G_n'}\le\frac{A_n}{A_n'},$$

which shows the similarity to the [inequality of arithmetic and geometric means](https://en.wikipedia.org/wiki/Inequality_of_arithmetic_and_geometric_means) given by *G<sub>n</sub>* ≤ *A<sub>n</sub>*.

## Generalization with weights {#Generalization_with_weights}

If *x<sub>i</sub>* ∈ \[0,$\tfrac{1}{2}$\] and *γ<sub>i</sub>* ∈ \[0,1\] for *i* = 1, . . ., *n* are real numbers satisfying *γ*<sub>1</sub> + . . . + *γ<sub>n</sub>* = 1, then

$$\frac{ \prod_{i=1}^n x_i^{\gamma_i} } { \prod_{i=1}^n (1-x_i)^{\gamma_i} } \le \frac{ \sum_{i=1}^n \gamma_i x_i } { \sum_{i=1}^n \gamma_i (1-x_i) }$$

with the convention 0<sup>0</sup> := 0. Equality holds if and only if either

- *γ<sub>i</sub>x<sub>i</sub>* = 0 for all *i* = 1, . . ., *n* or
- all *x<sub>i</sub>* > 0 and there exists *x* ∈ (0,$\tfrac{1}{2}$\] such that *x* = *x<sub>i</sub>* for all *i* = 1, . . ., *n* with *γ<sub>i</sub>* > 0.

The classical version corresponds to *γ<sub>i</sub>* = 1/*n* for all *i* = 1, . . ., *n*.

::: {#o6 .proof cue=heading name="Proof of the generalization"}

## Proof of the generalization {#Proof_of_the_generalization}

**Idea:** Apply [Jensen's inequality](wikipedia://en/297811) to the strictly [concave function](wikipedia://en/263321)

$$f(x):= \ln x-\ln(1-x) = \ln\frac x{1-x},\qquad x\in(0,\tfrac12].$$

**Detailed proof:** (a) If at least one *x<sub>i</sub>* is zero, then the left-hand side of the Ky Fan inequality is zero and the inequality is proved. Equality holds if and only if the right-hand side is also zero, which is the case when *γ<sub>i</sub>x<sub>i</sub>* = 0 for all *i* = 1, . . ., *n*.

(b) Assume now that all *x<sub>i</sub>* > 0. If there is an *i* with *γ<sub>i</sub>* = 0, then the corresponding *x<sub>i</sub>* > 0 has no effect on either side of the inequality, hence the *i*<sup>th</sup> term can be omitted. Therefore, we may assume that *γ<sub>i</sub>* > 0 for all *i* in the following. If *x*<sub>1</sub> = *x*<sub>2</sub> = . . . = *x<sub>n</sub>*, then equality holds. It remains to show strict inequality if not all *x<sub>i</sub>* are equal.

The function *f* is strictly concave on (0,$\tfrac{1}{2}$\], because we have for its second derivative

$$f''(x)=-\frac1{x^2}+\frac1{(1-x)^2}<0,\qquad x\in(0,\tfrac12).$$

Using the [functional equation](wikipedia://en/364377) for the [natural logarithm](wikipedia://en/21476) and Jensen's inequality for the strictly concave *f*, we obtain that

$$\begin{aligned} \ln\frac{ \prod_{i=1}^n x_i^{\gamma_i}} { \prod_{i=1}^n (1-x_i)^{\gamma_i} } &=\ln\prod_{i=1}^n\Bigl(\frac{x_i}{1-x_i}\Bigr)^{\gamma_i}\\ &=\sum_{i=1}^n \gamma_i f(x_i)\\ &<f\biggl(\sum_{i=1}^n \gamma_i x_i\biggr)\\ &=\ln\frac{ \sum_{i=1}^n \gamma_i x_i } { \sum_{i=1}^n \gamma_i (1-x_i) }, \end{aligned}$$

where we used in the last step that the *γ<sub>i</sub>* sum to one. Taking the exponential of both sides gives the Ky Fan inequality.

:::
