# Glossary of module theory

::: {#o1 .subject cue=lead name="Glossary of module theory"}

[Module theory](https://en.wikipedia.org/wiki/Module_theory) is the branch of mathematics in which [modules](wikipedia://en/276410) are studied. This is a glossary of some terms of the subject.

:::

See also: *[Glossary of linear algebra](wikipedia://en/70361989)*, *[Glossary of ring theory](wikipedia://en/251424)*, *[Glossary of representation theory](wikipedia://en/55799101)*.

## A {#A}

::: {#o3 .entry cue=term name="algebraically compact"}

**algebraically compact**

[algebraically compact module](wikipedia://en/478346) (also called [pure injective module](https://en.wikipedia.org/wiki/Pure_injective_module)) is a module in which all systems of equations can be decided by finitary means. Alternatively, those modules which leave pure-exact sequence exact after applying Hom.

:::

::: {#o4 .entry cue=term name="annihilator"}

**annihilator**

The [annihilator](wikipedia://en/328684) of a left $R$-module $M$ is the set $\textrm{Ann}(M) := \{ r \in R ~|~ rm = 0 \, \forall m \in M \}$ . It is a (two-sided) [ideal](wikipedia://en/25977) of $R$.

The annihilator of an element $m \in M$ is the set $\textrm{Ann}(m) := \{ r \in R ~|~ rm = 0 \}$. It is a left ideal.

:::

::: {#o5 .entry cue=term name="Artinian"}

**Artinian**

An [Artinian module](wikipedia://en/542336) is a module in which every decreasing chain of submodules becomes stationary after finitely many steps.

:::

::: {#o6 .entry cue=term name="associated prime"}

**associated prime**

[associated prime](wikipedia://en/17286442)

:::

::: {#o7 .entry cue=term name="automorphism"}

**automorphism**

An [automorphism](wikipedia://en/1160) is an [endomorphism](wikipedia://en/9569) that is also an isomorphism.

:::

::: {#o8 .entry cue=term name="Azumaya"}

**Azumaya**

[Azumaya's theorem](https://en.wikipedia.org/wiki/Azumaya's_theorem) says that two decompositions into modules with local endomorphism rings are equivalent.

:::

## D {#D}

::: {#o33 .entry cue=term name="D"}

**D**

A [D-module](wikipedia://en/3440755) is a module over a ring of differential operators.

:::

::: {#o34 .entry cue=term name="decomposition"}

**decomposition**

A [decomposition of a module](wikipedia://en/61406091) is a way to express a module as a direct sum of submodules.

::: {#o36 .entry cue=term name="determinant"}

**determinant**

The [determinant](https://en.wikipedia.org/wiki/Determinant_of_a_module) of a finite free module over a commutative ring is the *r*-th exterior power of the module when *r* is the rank of the module.

:::

::: {#o37 .entry cue=term name="differential"}

**differential**

A [differential graded module](wikipedia://en/46781249) or dg-module is a graded module with a differential.

:::

::: {#o38 .entry cue=term name="direct sum"}

**direct sum**

A [direct sum of modules](wikipedia://en/58899) is a module that is the direct sum of the underlying abelian group together with component-wise scalar multiplication.

:::

::: {#o39 .entry cue=term name="directing"}

**directing**

An indecomposable module *M* is directing if there is no cycle of module homomorphisms $f_0: M \to M_1, f_1: M_1 \to M_2, ..., f_{n-1}: M_{n-1} \to M$ such that for all *i*, $f_i$ is neither zero nor an isomorphism.

:::

::: {#o40 .entry cue=term name="dual module"}

**dual module**

The dual module of a module *M* over a commutative ring *R* is the module $\operatorname{Hom}_R(M, R)$.

::: {#o42 .entry cue=term name="Drinfeld"}

**Drinfeld**

## F {#F}

::: {#o53 .entry cue=term name="faithful"}

**faithful**

A [faithful module](https://en.wikipedia.org/wiki/Faithful_module) $M$ is one where the action of each nonzero $r \in R$ on $M$ is nontrivial (i.e. $rx \ne 0$ for some $x$ in $M$). Equivalently, $\textrm{Ann}(M)$ is the zero ideal.

:::

::: {#o54 .entry cue=term name="finite"}

**finite**

The term "[finite module](https://en.wikipedia.org/wiki/Finite_module)" is another name for a [finitely generated module](wikipedia://en/326430).

:::

::: {#o55 .entry cue=term name="finite length"}

**finite length**

A module of finite [length](wikipedia://en/816070) is a module that admits a (finite) composition series.

:::

::: {#o56 .entry cue=term name="finite presentation"}

**finite presentation**

A [finite free presentation](https://en.wikipedia.org/wiki/Finite_free_presentation) of a module *M* is an exact sequence $F_1 \to F_0 \to M$ where $F_i$ are finitely generated free modules.

A [finitely presented module](https://en.wikipedia.org/wiki/Finitely_presented_module) is a module that admits a [finite free presentation](https://en.wikipedia.org/wiki/Finite_free_presentation).

:::

::: {#o57 .entry cue=term name="finitely generated"}

**finitely generated**

A module $M$ is [finitely generated](wikipedia://en/326430) if there exist finitely many elements $x_1,...,x_n$ in $M$ such that every element of $M$ is a finite linear combination of those elements with coefficients from the scalar ring $R$.

::: {#o60 .entry cue=term name="flat"}

**flat**

A $R$-module $F$ is called a [flat module](wikipedia://en/492616) if the [tensor product](wikipedia://en/2993836) functor $- \otimes_R F$ is [exact](wikipedia://en/453945).In particular, every projective module is flat.

:::

::: {#o61 .entry cue=term name="free"}

**free**

A [free module](wikipedia://en/326454) is a module that has a basis, or equivalently, one that is isomorphic to a direct sum of copies of the scalar ring $R$.

## I {#I}

::: {#o75 .entry cue=term name="idempotent"}

**idempotent**

An [idempotent](https://en.wikipedia.org/wiki/Idempotent_endomorphism) is an endomorphism whose square is itself.

:::

::: {#o76 .entry cue=term name="indecomposable"}

**indecomposable**

An [indecomposable module](wikipedia://en/810549) is a non-zero module that cannot be written as a direct sum of two non-zero submodules. Every simple module is indecomposable (but not conversely).

:::

::: {#o77 .entry cue=term name="index"}

**index**

The [index of an endomorphism](https://en.wikipedia.org/wiki/Index_of_an_endomorphism) $f : M \to M$ is the difference $\operatorname{length}(\operatorname{coker}(f)) - \operatorname{length}(\operatorname{ker}(f))$, when the cokernel and kernel of $f$ have finite length.

:::

::: {#o78 .entry cue=term name="injective"}

**injective**

A $R$-module $Q$ is called an [injective module](wikipedia://en/473775) if given a $R$-module homomorphism $g: X \to Q$, and an [injective](https://en.wikipedia.org/wiki/Injective) $R$-module homomorphism $f: X \to Y$, there exists a $R$-module homomorphism $h : Y \to Q$ such that $f \circ h = g$.

*Image: Injective module.svg.* The module Q is injective if the diagram commutes

The following conditions are equivalent:

The contravariant functor $\textrm{Hom}_R( - , I)$ is [exact](wikipedia://en/453945).

$I$ is a injective module.

Every short exact sequence $0 \to I \to L \to L' \to 0$ is split.

An [injective envelope](https://en.wikipedia.org/wiki/Injective_envelope) (also called injective hull) is a maximal essential extension, or a minimal embedding in an injective module.

An [injective cogenerator](https://en.wikipedia.org/wiki/Injective_cogenerator) is an injective module such that every module has a nonzero homomorphism into it.

:::

::: {#o99 .entry cue=term name="module"}

**module**

A [left module](https://en.wikipedia.org/wiki/Left_module) $M$ over the [ring](wikipedia://en/48404) $R$ is an [abelian group](wikipedia://en/2974) $(M, +)$ with an operation $R \times M \to M$ (called scalar multipliction) satisfies the following condition:

$$\forall r,s \in R, \forall m,n \in M,$$

$$r (m + n) = rm + rn$$

$$r (s m) = (r s) m$$

$$1_R \, m = m$$

A [right module](https://en.wikipedia.org/wiki/Right_module) $M$ over the ring $R$ is an abelian group $(M, +)$ with an operation $M \times R \to M$ satisfies the following condition:

$$\forall r,s \in R, \forall m,n \in M,$$

$$(m + n) r = m r + n r$$

$$(m s) r = m (s r)$$

$$m 1_R = m$$

All the modules together with all the module homomorphisms between them form the [category of modules](wikipedia://en/11231812).

::: {#o109 .entry cue=term name="projective"}

**projective**

*Image: Projective module.png.* The characteristic property of projective modules is called **[lifting](wikipedia://en/10504570)**.

A $R$-module $P$ is called a [projective module](wikipedia://en/364488) if given a $R$-module homomorphism $g: P \to M$, and a [surjective](https://en.wikipedia.org/wiki/Surjective) $R$-module homomorphism $f: N \to M$, there exists a $R$-module homomorphism $h : P \to N$ such that $f \circ h = g$.

The following conditions are equivalent:

The covariant functor $\textrm{Hom}_R(P, - )$ is [exact](wikipedia://en/453945).

$M$ is a projective module.

Every short exact sequence $0 \to L \to L' \to P \to 0$ is split.

$M$ is a direct summand of free modules.

In particular, every free module is projective.

The [projective dimension](https://en.wikipedia.org/wiki/Projective_dimension) of a module is the minimal length of (if any) a finite projective resolution of the module; the dimension is infinite if there is no finite projective resolution.

A [projective cover](wikipedia://en/10273917) is a minimal surjection from a projective module.

A [simple module](wikipedia://en/29430) is a nonzero module whose only submodules are zero and itself.

::: {#o131 .entry cue=term name="structure theorem"}

**structure theorem**

The [structure theorem for finitely generated modules over a principal ideal domain](wikipedia://en/9902787) says that a finitely generated modules over PIDs are finite direct sums of primary cyclic modules.

:::

::: {#o132 .entry cue=term name="submodule"}

**submodule**

Given a $R$-module $M$, an additive subgroup $N$ of $M$ is a [submodule](https://en.wikipedia.org/wiki/Submodule) if $RN \subset N$.

:::

::: {#o133 .entry cue=term name="support"}

**support**

The [support of a module](wikipedia://en/16073360) over a commutative ring is the set of prime ideals at which the localizations of the module are nonzero.

:::

## U {#U}

::: {#o141 .entry cue=term name="uniform"}

**uniform**

A [uniform module](wikipedia://en/31553078) is a module in which every two non-zero submodules have a non-zero intersection.

## Z {#Z}

::: {#o145 .entry cue=term name="zero"}

**zero**

The [zero module](https://en.wikipedia.org/wiki/Zero_module) is a module consisting of only zero element.

The [zero module homomorphism](https://en.wikipedia.org/wiki/Zero_module_homomorphism) is a module homomorphism that maps every element to zero.
