# Breusch–Godfrey test

::: {#o1 .subject cue=lead name="Breusch–Godfrey test"}

In [statistics](wikipedia://en/26685), the **Breusch–Godfrey test** is used to assess the validity of some of the modelling assumptions inherent in applying [regression-like](wikipedia://en/826997) models to observed data series.[^o2][^o3] In particular, it [tests](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing) for the presence of [serial correlation](wikipedia://en/2724) that has not been included in a proposed model structure and which, if present, would mean that incorrect conclusions would be drawn from other tests or that sub-optimal estimates of model parameters would be obtained.

:::

The regression models to which the test can be applied include cases where lagged values of the [dependent variables](https://en.wikipedia.org/wiki/Independent_and_dependent_variables) are used as [independent variables](https://en.wikipedia.org/wiki/Independent_and_dependent_variables) in the model's representation for later observations. This type of structure is common in [econometric models](https://en.wikipedia.org/wiki/Econometric_models).

The test is named after [Trevor S. Breusch](https://en.wikipedia.org/wiki/Trevor_S._Breusch) and [Leslie G. Godfrey](https://en.wikipedia.org/wiki/Leslie_G._Godfrey).

## Background {#Background}

The Breusch–Godfrey test is a test for [autocorrelation](wikipedia://en/2724) in the [errors](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) in a regression model. It makes use of the [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) from the model being considered in a [regression analysis](wikipedia://en/826997), and a test statistic is derived from these. The [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) is that there is no [serial correlation](https://en.wikipedia.org/wiki/Serial_correlation) of any order up to *p*.

Because the test is based on the idea of [Lagrange multiplier testing](https://en.wikipedia.org/wiki/Lagrange_multiplier_test), it is sometimes referred to as an **LM test for serial correlation.**[^o5]

A similar assessment can be also carried out with the [Durbin–Watson test](wikipedia://en/4864529) and the [Ljung–Box test](wikipedia://en/6534294). However, the test is more general than that using the Durbin–Watson statistic (or Durbin's *h* statistic), which is only valid for nonstochastic regressors and for testing the possibility of a first-order autoregressive model (e.g. AR(1)) for the regression errors. The BG test has none of these restrictions, and is statistically more [powerful](https://en.wikipedia.org/wiki/Statistical_power) than Durbin's *h* statistic. The BG test is considered to be more general than the Ljung-Box test because the latter requires the assumption of strict exogeneity, but the BG test does not. However, the BG test requires the assumptions of stronger forms of predeterminedness and conditional [homoscedasticity](https://en.wikipedia.org/wiki/Homoscedasticity).

::: {#o7 .definition kind=definition/construction cue=heading name="Procedure"}

## Procedure {#Procedure}

Consider a [linear regression](wikipedia://en/48758386) of any form, for example

$$Y_t = \beta_1+ \beta_2 X_{t,1} + \beta_3 X_{t,2} + u_t \,$$

where the errors might follow an AR(*p*) autoregressive scheme, as follows:

$$u_t = \rho_1 u_{t-1} + \rho_2 u_{t-2} + \cdots + \rho_p u_{t-p} + \varepsilon_t. \,$$

The simple regression model is first fitted by [ordinary least squares](wikipedia://en/1651906) to obtain a set of sample residuals $\hat{u}_t$.

Breusch and Godfrey proved that, if the following auxiliary regression model is fitted

$$\hat{u}_t = \alpha_0 + \alpha_1 X_{t,1} + \alpha_2 X_{t,2} + \rho_1 \hat{u}_{t-1} + \rho_2 \hat{u}_{t-2} + \cdots + \rho_p \hat{u}_{t-p} + \varepsilon_t \,$$

Denote by $\tilde{u}_t$ the fitted value of $\hat{u}_t$ obtained from this auxiliary regression. If the usual [coefficient of determination](wikipedia://en/1500869) ($R^2$ statistic) is calculated for this model:

$$R^2 := 1 - \frac{\sum_{j=1}^{T-p} (\hat{u}_{T-j} - \tilde{u}_{T-j})^2}{\sum_{j=1}^{T-p} (\hat{u}_{T-j} - \bar{\hat{u}})^2},$$

where $\bar{\hat{u}}$ stands for the [arithmetic mean](wikipedia://en/612) of residuals. One may average residuals over the last $n=T-p$ observations, where $T$ is the number of observations in the original model and $p$ is the number of error lags used in the auxiliary regression. There is a version of the test where missing residuals $\hat{u}_{1-j}$ are replaced by zeros. In this version of the test the number of observations in the auxiliary regression $n$ is equal to the original number of observations $T$.

The following [asymptotic approximation](wikipedia://en/3001287) can be used for the distribution of the test statistic:

$$n R^2\,\sim\,\chi^2_p, \,$$

when the null hypothesis ${H_0: \lbrace \rho_i = 0 \text{ for all } i \rbrace }$ holds (that is, there is no serial correlation of any order up to *p*).

:::

## Software {#Software}

- In [R](wikipedia://en/376707), this test is performed by function **bgtest**, available in [package](wikipedia://en/376707#Packages) **lmtest**.[^o9][^o10]
- In [Stata](wikipedia://en/1809002), this test is performed by the command **estat bgodfrey**, and by **varlmar** for [vector autoregressions](wikipedia://en/2399016).[^o11][^o12][^o13]
- In [SAS](wikipedia://en/990677), the **GODFREY** option of the **MODEL** statement in **PROC AUTOREG** provides a version of this test.
- In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) Statsmodels, the acorr\_breusch\_godfrey function in the module statsmodels.stats.diagnostic [^o14]
- In [EViews](wikipedia://en/3933682), this test is already done after a regression, at "View" → "Residual Diagnostics" → "Serial Correlation LM Test".
- In [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), the *BreuschGodfreyTest* function is available in the *HypothesisTests* package.[^o15]
- In [gretl](wikipedia://en/1166251), this test can be obtained via the **modtest** command, or under the "Test" → "Autocorrelation" menu entry in the GUI client.
