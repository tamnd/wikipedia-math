# Indecomposability (intuitionistic logic)

::: {#o1 .subject cue=lead name="Indecomposability"}

definition In [intuitionistic analysis](https://en.wikipedia.org/wiki/Intuitionistic_analysis) and in [computable analysis](wikipedia://en/21535996), **indecomposability** or **indivisibility** (Unzerlegbarkeit, from the adjective *unzerlegbar*) is the principle that the [continuum](wikipedia://en/24758677) cannot be [partitioned](wikipedia://en/340240) into two nonempty pieces. This principle was established by [Brouwer](https://en.wikipedia.org/wiki/Luitzen_Egbertus_Jan_Brouwer) in 1928[^o2] using [intuitionistic principles](https://en.wikipedia.org/wiki/Constructivist_analysis), and can also be proven using [Church's thesis](wikipedia://en/15756448). The analogous property in classical [analysis](wikipedia://en/48396) is the fact that every [continuous function](wikipedia://en/6122) from the continuum to {0,1} is constant.

:::

It follows from the indecomposability principle that any property of real numbers that is *decided* (each real number either has or does not have that property) is in fact [trivial](https://en.wikipedia.org/wiki/Trivial_%28mathematics%29) (either all the real numbers have that property, or else none of them do). Conversely, if a property of real numbers is not trivial, then the property is not decided for all real numbers. This contradicts the [law of the excluded middle](https://en.wikipedia.org/wiki/Law_of_the_excluded_middle), according to which every property of the real numbers is decided; so, since there are many nontrivial properties, there are many nontrivial partitions of the continuum.

In [constructive set theory](wikipedia://en/5042360) (CZF), it is consistent to assume the universe of all sets is indecomposable—so that any class for which membership is decided (every set is either a member of the class, or else not a member of the class) is either empty or the entire universe.
