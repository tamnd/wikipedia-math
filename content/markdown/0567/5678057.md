# Godunov's theorem

::: {#o1 .subject cue=lead name="Godunov's theorem"}

In [numerical analysis](wikipedia://en/21506) and [computational fluid dynamics](wikipedia://en/305924), **Godunov's theorem** — also known as **Godunov's order barrier theorem** — is a mathematical [theorem](wikipedia://en/30977) important in the development of the theory of [high-resolution schemes](https://en.wikipedia.org/wiki/High-resolution_scheme) for the numerical solution of [partial differential equations](wikipedia://en/52564).

:::

The theorem states that:

Professor [Sergei Godunov](wikipedia://en/5665800) originally proved the theorem as a Ph.D. student at [Moscow State University](https://en.wikipedia.org/wiki/Moscow_State_University). It is his most influential work in the area of applied and numerical mathematics and has had a major impact on science and engineering, particularly in the development of methods used in [computational fluid dynamics](wikipedia://en/305924) (CFD) and other computational fields. One of his major contributions was to prove the theorem (Godunov, 1954; Godunov, 1959), that bears his name.

::: {#o3 .statement cue=heading name="The theorem"}

## The theorem {#The_theorem}

We generally follow Wesseling (2001).

**Aside**

Assume a continuum problem described by a [PDE](wikipedia://en/52564) is to be computed using a numerical scheme based upon a uniform computational grid and a one-step, constant step-size, *M* grid point, integration algorithm, either implicit or explicit. Then if $x_{j} = j\,\Delta x$ and $t^n = n\,\Delta t$, such a scheme can be described by

::: {#o4 .equation cue=numblk name="1"}

$$\sum_{m=1}^{M} {\beta _m } \varphi _{j + m}^{n + 1} = \sum_{m=1}^{M} {\alpha _m \varphi _{j + m}^n }. \tag{1}$$

:::

In other words, the solution $\varphi _j^{n + 1}$ at time $n + 1$ and location $j$ is a linear function of the solution at the previous time step $n$. We assume that $\beta _m$ determines $\varphi _j^{n + 1}$ uniquely. Now, since the above equation represents a linear relationship between $\varphi _j^{n }$ and $\varphi _j^{n + 1}$ we can perform a linear transformation to obtain the following equivalent form,

::: {#o5 .equation cue=numblk name="2"}

$$\varphi _j^{n + 1} = \sum\limits_m^{M} {\gamma _m \varphi _{j + m}^n }. \tag{2}$$

:::

::: {#o6 .statement kind=statement/theorem cue=inline-head name="Theorem 1"}

**Theorem 1:** *Monotonicity preserving*

The above scheme of equation (2) is monotonicity preserving if and only if

::: {#o7 .equation cue=numblk name="3"}

$$\gamma _m \ge 0,\quad \forall m . \tag{3}$$

:::

*Proof* - Godunov (1959)

**Case 1: (sufficient condition)**

Assume (3) applies and that $\varphi _j^n$ is monotonically increasing with $j$.

Then, because $\varphi _j^n \le \varphi _{j + 1}^n \le \cdots \le \varphi _{j + m}^n$ it therefore follows that $\varphi _j^{n + 1} \le \varphi _{j + 1}^{n + 1} \le \cdots \le \varphi _{j + m}^{n + 1}$ because

::: {#o8 .equation cue=numblk name="4"}

$$\varphi _j^{n + 1} - \varphi _{j - 1}^{n + 1} = \sum\limits_m^{M} {\gamma _m \left( {\varphi _{j + m}^n - \varphi _{j + m - 1}^n } \right)} \ge 0 . \tag{4}$$

:::

This means that monotonicity is preserved for this case.

**Case 2: (necessary condition)**

We prove the necessary condition by contradiction. Assume that $\gamma _p^{} < 0$ for some $p$ and choose the following monotonically increasing $\varphi_j^n \,$,

::: {#o9 .equation cue=numblk name="5"}

$$\varphi _i^n = 0, \quad i < k;\quad \varphi _i^n = 1, \quad i \ge k . \tag{5}$$

:::

Then from equation (2) we get

::: {#o10 .equation cue=numblk name="6"}

$$\varphi _j^{n + 1} - \varphi _{j-1}^{n+1} = \sum\limits_m^M {\gamma _m } \left( {\varphi _{j + m}^{n} - \varphi _{j + m - 1}^{n} } \right) = \begin{cases} 0, & j + m \ne k \\ \gamma _m , & j + m = k \\ \end{cases} \tag{6}$$

:::

Now choose $j = k - p$, to give

::: {#o11 .equation cue=numblk name="7"}

$$\varphi _{k-p}^{n + 1} - \varphi _{k-p-1}^{n + 1} = {\gamma _p \left( {\varphi _{k}^n - \varphi _{k - 1}^n } \right)} < 0 , \tag{7}$$

:::

which implies that $\varphi _j^{n + 1}$ is **NOT** increasing, and we have a contradiction. Thus, monotonicity is **NOT** preserved for $\gamma _p < 0$, which completes the proof.

:::

::: {#o12 .statement kind=statement/theorem cue=inline-head name="Theorem 2"}

**Theorem 2:** *Godunov’s Order Barrier Theorem*

Linear one-step second-order accurate numerical schemes for the convection equation

::: {#o13 .equation cue=numblk name="10"}

$${{\partial \varphi } \over {\partial t}} + c{ { \partial \varphi } \over {\partial x}} = 0 , \quad t > 0, \quad x \in \mathbb{R} \tag{10}$$

:::

cannot be monotonicity preserving unless

::: {#o14 .equation cue=numblk name="11"}

$$\sigma = \left| c \right|{{\Delta t} \over {\Delta x}} \in \mathbb{ N} , \tag{11}$$

:::

where $\sigma$ is the signed [Courant–Friedrichs–Lewy condition](wikipedia://en/2029932) (CFL) number.

*Proof* - Godunov (1959)

Assume a numerical scheme of the form described by equation (2) and choose

::: {#o15 .equation cue=numblk name="12"}

$$\varphi \left( {0,x} \right) = \left( {{x \over {\Delta x}} - {1 \over 2}} \right)^2 - {1 \over 4}, \quad \varphi _j^0 = \left( {j - {1 \over 2}} \right)^2 - {1 \over 4} . \tag{12}$$

:::

The exact solution is

::: {#o16 .equation cue=numblk name="13"}

$$\varphi \left( {t,x} \right) = \left( {{{x - ct} \over {\Delta x}} - {1 \over 2}} \right)^2 - {1 \over 4} . \tag{13}$$

:::

If we assume the scheme to be at least second-order accurate, it should produce the following solution exactly

::: {#o17 .equation cue=numblk name="14"}

$$\varphi _j^1 = \left( {j - \sigma - {1 \over 2}} \right)^2 - {1 \over 4}, \quad \varphi _j^0 = \left( {j - {1 \over 2}} \right)^2 - {1 \over 4}. \tag{14}$$

:::

Substituting into equation (2) gives:

::: {#o18 .equation cue=numblk name="15"}

$$\left( {j - \sigma - {1 \over 2}} \right)^2 - {1 \over 4} = \sum\limits_m^{M} {\gamma _m \left\{ {\left( {j + m - {1 \over 2}} \right)^2 - {1 \over 4}} \right\}}. \tag{15}$$

:::

Suppose that the scheme **IS** monotonicity preserving, then according to the theorem 1 above, $\gamma _m \ge 0$.

Now, it is clear from equation (15) that

::: {#o19 .equation cue=numblk name="16"}

$$\left( {j - \sigma - {1 \over 2}} \right)^2 - {1 \over 4} \ge 0, \quad \forall j . \tag{16}$$

:::

Assume $\sigma > 0, \quad \sigma \notin \mathbb{ N}$ and choose $j$ such that $j > \sigma > \left( j - 1 \right)$. This implies that $\left( {j - \sigma } \right) > 0$ and $\left( {j - \sigma - 1} \right) < 0$.

It therefore follows that,

::: {#o20 .equation cue=numblk name="17"}

$$\left( {j - \sigma - {1 \over 2}} \right)^2 - {1 \over 4} = \left( j - \sigma \right) \left(j - \sigma - 1 \right) < 0, \tag{17}$$

:::

which contradicts equation (16) and completes the proof.

The exceptional situation whereby $\sigma = \left| c \right|{{\Delta t} \over {\Delta x}} \in \mathbb{N}$ is only of theoretical interest, since this cannot be realised with variable coefficients. Also, integer [CFL](wikipedia://en/2029932) numbers greater than unity would not be feasible for practical problems.

:::
