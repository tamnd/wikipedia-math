# Zeldovich regularization

::: {#o1 .subject cue=lead name="Zeldovich regularization"}

**Zeldovich regularization** refers to a [regularization method](https://en.wikipedia.org/wiki/Regularization_%28physics%29) to calculate [divergent integrals](wikipedia://en/346030) and [divergent series](wikipedia://en/876428), that was first introduced by [Yakov Zeldovich](https://en.wikipedia.org/wiki/Yakov_Zeldovich) in 1961.[^o2] Zeldovich was originally interested in calculating the norm of the [Gamow wave function](wikipedia://en/14356889) which is divergent since there is an outgoing spherical wave. Zeldovich regularization uses a [Gaussian](wikipedia://en/245552) type-regularization and is defined, for divergent integrals, by[^o3]

:::

$$\int_0^\infty f(x) dx \equiv \lim_{\alpha\to 0^+}\int_0^\infty f(x) e^{-\alpha x^2} dx.$$

and, for divergent series, by[^o4][^o5][^o6]

$$\sum_n c_n \equiv \lim_{\alpha\to 0^+}\sum_n c_n e^{-\alpha n^2}.$$
