# Key transparency

::: {#o1 .subject cue=lead name="Key transparency"}

**Key transparency** allows communicating parties to verify [public keys](wikipedia://en/24222) used in [end-to-end encryption](wikipedia://en/1065362).[^o2] In many end-to-end encryption services, to initiate communication a user will reach out to a central server and request the public keys of the user with which they wish to communicate.[^o3] If the central server is malicious or becomes compromised, a [man-in-the-middle attack](wikipedia://en/144676) can be launched through the issuance of incorrect public keys. The communications can then be intercepted and manipulated.[^o4] Additionally, legal pressure could be applied by surveillance agencies to manipulate public keys and read messages.[^o3]

:::

With key transparency, public keys are posted to a public log that can be universally audited.[^o5] Communicating parties can verify public keys used are accurate.[^o5]
