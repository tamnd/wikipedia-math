# SSE5

::: {#o1 .subject cue=lead name="SSE5"}

The **SSE5** (short for **Streaming SIMD Extensions version 5**) was a [SIMD](https://en.wikipedia.org/wiki/SIMD) instruction set extension proposed by [AMD](https://en.wikipedia.org/wiki/Advanced_Micro_Devices) on August 30, 2007 as a supplement to the 128-bit [SSE](wikipedia://en/55365) core instructions in the [AMD64](https://en.wikipedia.org/wiki/AMD64) architecture.

:::

AMD chose not to implement SSE5 as originally proposed. In May 2009, AMD replaced SSE5 with three smaller instruction set extensions named as [XOP](wikipedia://en/22701763), [FMA4](wikipedia://en/23095212), and [F16C](wikipedia://en/40527379), which retain the proposed functionality of SSE5, but encode the instructions differently for better compatibility with Intel's proposed [AVX](wikipedia://en/16779711) instruction set.

The three SSE5-derived instruction sets were introduced in the [Bulldozer](https://en.wikipedia.org/wiki/Bulldozer_%28microarchitecture%29) processor core, released in October 2011 on a [32 nm](https://en.wikipedia.org/wiki/32_nanometer) process.[^o2]

## Compatibility {#Compatibility}

AMD's SSE5 extension bundle does not include the full set of [Intel](https://en.wikipedia.org/wiki/Intel)'s [SSE4](wikipedia://en/6821879) instructions, making it a competitor to SSE4 rather than a successor.

## SSE5 enhancements {#SSE5_enhancements}

The proposed SSE5 instruction set consisted of 170 instructions (including 46 base instructions), many of which are designed to improve single-threaded performance. Some SSE5 instructions are [3-operand instructions](https://en.wikipedia.org/wiki/Instruction_set#Code_density), the use of which will increase the average number of [instructions per cycle](https://en.wikipedia.org/wiki/Instructions_per_cycle) achievable by [x86](https://en.wikipedia.org/wiki/X86) code.[^o5] Selected new instructions include:[^o6]

- [Fused multiply–accumulate](https://en.wikipedia.org/wiki/Fused_multiply–accumulate) (FMACxx) instructions
- Integer [multiply–accumulate](https://en.wikipedia.org/wiki/Multiply–accumulate) (IMAC, IMADC) instructions
- Permutation (PPERM, PERMPx) and conditional move (PCMOV) instructions
- Precision control, rounding, and conversion instructions

AMD claimed SSE5 would provide dramatic performance improvements, particularly in [high-performance computing](https://en.wikipedia.org/wiki/High-performance_computing) (HPC), [multimedia](https://en.wikipedia.org/wiki/Multimedia), and [computer security](https://en.wikipedia.org/wiki/Computer_security) applications, including a 5x performance gain for [AES encryption](wikipedia://en/1260) and a 30% performance gain for the [discrete cosine transform](wikipedia://en/59962) (DCT) used for example in video processing.[^o5]

## 2009 revision {#2009_revision}

The SSE5 specification included a proposed extension to the general coding scheme of [x86](https://en.wikipedia.org/wiki/X86) instructions in order to allow instructions to have more than two operands. In 2008, [Intel](https://en.wikipedia.org/wiki/Intel) announced their planned [AVX](wikipedia://en/16779711) instruction set which proposed a different way of coding instructions with more than two operands. The two proposed coding schemes, SSE5 and AVX, are mutually incompatible, although the AVX scheme has certain advantages over the SSE5 scheme: most importantly, AVX has plenty of space for future extensions, including larger vector sizes.

In May 2009, AMD published a revised specification for the planned future instructions. This revision changes the coding scheme to make it compatible with the AVX scheme, but with a differing prefix byte in order to avoid overlap between instructions introduced by AMD and instructions introduced by Intel.

The revised instruction set no longer carries the name SSE5, which has been criticized for being misleading, but most of the instructions in the new revision are functionally identical to the original SSE5 specification—only the way the instructions are coded differs. The planned additions to the AMD instruction set consists of three subsets:

1. [XOP](wikipedia://en/22701763): Integer vector [multiply–accumulate](https://en.wikipedia.org/wiki/Multiply–accumulate) instructions, integer vector horizontal addition, integer vector compare, shift and rotate instructions, byte permutation and conditional move instructions, floating point fraction extraction.
1. [FMA4](wikipedia://en/23095212): Floating-point vector [multiply–accumulate](https://en.wikipedia.org/wiki/Multiply–accumulate).
1. [F16C](wikipedia://en/40527379): [Half-precision](https://en.wikipedia.org/wiki/Half-precision) floating-point conversion.

Both XOP and FMA4 are removed in newer AMD processors using the [Zen microarchitecture](https://en.wikipedia.org/wiki/Zen_%28microarchitecture%29).[^o8]
