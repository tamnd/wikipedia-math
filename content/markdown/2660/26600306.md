# Esakia space

::: {#o1 .subject cue=lead name="Esakia space"}

In [mathematics](wikipedia://en/18831), **Esakia spaces** are special [ordered](https://en.wikipedia.org/wiki/Partial_order) [topological spaces](wikipedia://en/30450) introduced and studied by [Leo Esakia](https://en.wikipedia.org/wiki/Leo_Esakia) in 1974.[^o2] Esakia spaces play a fundamental role in the study of [Heyting algebras](wikipedia://en/309343), primarily by virtue of the [Esakia duality](wikipedia://en/26600432)—the [dual equivalence](wikipedia://en/379051) between the [category](wikipedia://en/53759) of Heyting algebras and the category of Esakia spaces.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a [partially ordered](https://en.wikipedia.org/wiki/Partially_ordered) [set](wikipedia://en/26691) $(X, \le)$ and for $x\in X$, let $\downarrow x = \{y\in X : y\le x$} and let $\uparrow x = \{y\in X : x\le y$}. Also, for $A\subseteq X$, let $\downarrow A = \{y\in X : y \le x\text{ for }\text{ some } x\in A$} and $\uparrow A = \{y\in X : y\ge x\text{ for }\text{ some } x\in A$}.

An **Esakia space** is a [Priestley space](wikipedia://en/26599382) $(X,\tau,\le)$ such that for each [clopen](wikipedia://en/233398) subset $C$ of the topological space $(X,\tau)$, the set $\downarrow C$ is also clopen.

:::

::: {#o6 .definition cue=heading name="Equivalent definitions"}

## Equivalent definitions {#Equivalent_definitions}

There are several equivalent ways to define Esakia spaces.

Theorem:[^o7] Given that $(X,\tau)$ is a [Stone space](wikipedia://en/380219), the following conditions are equivalent:

(i) $(X,\tau,\le)$ is an Esakia space.

(ii) $\uparrow x$ is [closed](wikipedia://en/47279) for each $x\in X$ and $\downarrow C$ is clopen for each clopen $C\subseteq X$.

(iii) $\downarrow x$ is closed for each $x\in X$ and $\uparrow\operatorname{cl}(A) = \operatorname{cl}(\uparrow A)$ for each $A\subseteq X$ (where $\operatorname{cl}$ denotes the [closure](wikipedia://en/483120) in $X$).

(iv) $\downarrow x$ is closed for each $x\in X$, the least closed set containing an [up-set](https://en.wikipedia.org/wiki/Up-set) is an up-set, and the least up-set containing a closed set is closed.

Since Priestley spaces can be described in terms of [spectral spaces](https://en.wikipedia.org/wiki/Spectral_spaces), the Esakia property can be expressed in spectral space terminology as follows: The Priestley space corresponding to a spectral space $X$ is an Esakia space if and only if the closure of every constructible subset of $X$ is constructible.[^o8]

:::

## Esakia morphisms {#Esakia_morphisms}

Let $(X,\le)$ and $(Y,\le)$ be partially ordered sets and let $f : X \to Y$ be an [order-preserving](https://en.wikipedia.org/wiki/Order-preserving) map. The map $f$ is a [bounded morphism](https://en.wikipedia.org/wiki/P-morphism) (also known as [p-morphism](https://en.wikipedia.org/wiki/P-morphism)) if for each $x\in X$ and $y\in Y$, if $f(x)\le y$, then there exists $z\in X$ such that $x\le z$ and $f(z) = y$.

Theorem:[^o10] The following conditions are equivalent:

(1) $f$ is a bounded morphism.

(2) $f(\uparrow x) = \uparrow f(x)$ for each $x\in X$.

(3) $f^{-1}(\downarrow y) = \downarrow f^{-1}(y)$ for each $y\in Y$.

Let $(X, \tau, \le)$ and $(Y, \tau, \le)$ be Esakia spaces and let $f : X \to Y$ be a map. The map $f$ is called an *Esakia morphism* if $f$ is a [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) bounded morphism.
