# Sierpiński space

::: {#o1 .subject cue=lead name="Sierpiński space"}

In [mathematics](wikipedia://en/18831), the **Sierpiński space** is a [finite topological space](wikipedia://en/14682596) with two points, only one of which is [closed](wikipedia://en/47279). It is the smallest example of a [topological space](wikipedia://en/30450) which is neither [trivial](wikipedia://en/382447) nor [discrete](https://en.wikipedia.org/wiki/Discrete_topology). It is named after [Wacław Sierpiński](wikipedia://en/34122).

:::

The Sierpiński space has important relations to the [theory of computation](wikipedia://en/155414) and [semantics](wikipedia://en/29107),[^o3][^o4] because it is the [classifying space](wikipedia://en/923556) for [open sets](https://en.wikipedia.org/wiki/Open_sets) in the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology).

## Definition and fundamental properties {#Definition_and_fundamental_properties}

Explicitly, the Sierpiński space is a [topological space](wikipedia://en/30450) *S* whose underlying [point set](wikipedia://en/26691) is $\{0, 1\}$ and whose [open sets](wikipedia://en/39358) are

$$\{\varnothing,\{1\}, \{0,1\}\}.$$

The [closed sets](wikipedia://en/47279) are

$$\{\varnothing, \{0\}, \{0,1\}\}.$$

So the [singleton set](https://en.wikipedia.org/wiki/Singleton_set) $\{0\}$ is closed and the set $\{1\}$ is open ($\varnothing = \{ \, \}$ is the [empty set](wikipedia://en/9566)).

The [closure operator](wikipedia://en/331597) on *S* is determined by

$$\overline{\{0\}} = \{0\}, \qquad \overline{\{1\}} = \{0,1\}.$$

A finite topological space is also uniquely determined by its [specialization preorder](wikipedia://en/542347). For the Sierpiński space this [preorder](wikipedia://en/23582) is actually a [total order](wikipedia://en/30330) and given by

$$0 \leq 0, \qquad 0 \leq 1, \qquad 1 \leq 1.$$

## Topological properties {#Topological_properties}

The Sierpiński space $S$ is a special case of both the finite [particular point topology](wikipedia://en/5336200) (with particular point 1) and the finite [excluded point topology](wikipedia://en/5539197) (with excluded point 0). Therefore, $S$ has many properties in common with one or both of these families.

### Separation {#Separation}

- The points 0 and 1 are [topologically distinguishable](https://en.wikipedia.org/wiki/Topologically_distinguishable) in *S* since $\{1\}$ is an open set which contains only one of these points. Therefore, *S* is a [Kolmogorov (T<sub>0</sub>) space](wikipedia://en/68121).
- However, *S* is not [T<sub>1</sub>](wikipedia://en/148721) since the point 1 is not closed. It follows that *S* is not [Hausdorff](wikipedia://en/13637), or T<sub>*n*</sub> for any $n \geq 1.$
- *S* is not [regular](wikipedia://en/53058) (or [completely regular](https://en.wikipedia.org/wiki/Completely_regular)) since the point 1 and the disjoint closed set $\{0\}$ cannot be [separated by neighborhoods](https://en.wikipedia.org/wiki/Separated_set). (Also regularity in the presence of T<sub>0</sub> would imply Hausdorff.)
- *S* is [vacuously](wikipedia://en/51672) [normal](wikipedia://en/48629) and [completely normal](https://en.wikipedia.org/wiki/Completely_normal_space) since there are no nonempty [separated sets](https://en.wikipedia.org/wiki/Separated_set).
- *S* is not [perfectly normal](https://en.wikipedia.org/wiki/Perfectly_normal_space) since the disjoint closed sets $\varnothing$ and $\{0\}$ cannot be precisely separated by a function. Indeed, $\{0\}$ cannot be the [zero set](https://en.wikipedia.org/wiki/Zero_set) of any [continuous function](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) $S \to \mathbb{R}$ since every such function is [constant](wikipedia://en/320861).

### Connectedness {#Connectedness}

- The Sierpiński space *S* is both [hyperconnected](https://en.wikipedia.org/wiki/Hyperconnected) (since every nonempty open set contains 1) and [ultraconnected](https://en.wikipedia.org/wiki/Ultraconnected) (since every nonempty closed set contains 0).
- It follows that *S* is both [connected](wikipedia://en/6233) and [path connected](https://en.wikipedia.org/wiki/Path_connected_space).
- A [path](wikipedia://en/1189553) from 0 to 1 in *S* is given by the function: $f(0) = 0$ and $f(t) = 1$ for $t > 0.$ The function $f : I \to S$ is continuous since $f^{-1}(1) = (0, 1]$ which is open in *I*.
- Like all finite topological spaces, *S* is [locally path connected](https://en.wikipedia.org/wiki/Locally_path_connected).
- The Sierpiński space is [contractible](wikipedia://en/1752414), so the [fundamental group](wikipedia://en/11004) of *S* is [trivial](wikipedia://en/193059) (as are all the [higher homotopy groups](https://en.wikipedia.org/wiki/Higher_homotopy_groups)).

### Compactness {#Compactness}

- Like all finite topological spaces, the Sierpiński space is both [compact](wikipedia://en/6042) and [second-countable](https://en.wikipedia.org/wiki/Second-countable).
- The compact subset $\{1\}$ of *S* is not closed showing that compact subsets of T<sub>0</sub> spaces need not be closed.
- Every [open cover](https://en.wikipedia.org/wiki/Open_cover) of *S* must contain *S* itself since *S* is the only open neighborhood of 0. Therefore, every open cover of *S* has an open [subcover](https://en.wikipedia.org/wiki/Subcover) consisting of a single set: $\{S\}.$
- It follows that *S* is [fully normal](https://en.wikipedia.org/wiki/Fully_normal_space).[^o10]

### Convergence {#Convergence}

- Every [sequence](wikipedia://en/27838) in *S* [converges](wikipedia://en/285773) to the point 0. This is because the only neighborhood of 0 is *S* itself.
- A sequence in *S* converges to 1 if and only if the sequence contains only finitely many terms equal to 0 (i.e. the sequence is eventually just 1's).
- The point 1 is a [cluster point](https://en.wikipedia.org/wiki/Cluster_point) of a sequence in *S* if and only if the sequence contains infinitely many 1's.
- *Examples*:
  - 1 is not a cluster point of $(0,0,0,0,\ldots).$
  - 1 is a cluster point (but not a limit) of $(0,1,0,1,0,1,\ldots).$
  - The sequence $(1,1,1,1,\ldots)$ converges to both 0 and 1.

### Metrizability {#Metrizability}

- The Sierpiński space *S* is not [metrizable](wikipedia://en/19738) or even [pseudometrizable](https://en.wikipedia.org/wiki/Pseudometrizable_space) since every pseudometric space is [completely regular](wikipedia://en/30554) but the Sierpiński space is not even [regular](wikipedia://en/53058).
- *S* is generated by the [hemimetric](https://en.wikipedia.org/wiki/Hemimetric) (or [pseudo](wikipedia://en/68503)-[quasimetric](https://en.wikipedia.org/wiki/Quasimetric)) $d(0, 1) = 0$ and $d(1,0) = 1.$

### Other properties {#Other_properties}

- There are only three [continuous maps](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) from *S* to itself: the [identity map](wikipedia://en/15069) and the [constant maps](https://en.wikipedia.org/wiki/Constant_map) to 0 and 1.
- It follows that the [homeomorphism group](wikipedia://en/1531409) of *S* is [trivial](wikipedia://en/193059).

## Continuous functions to the Sierpiński space {#Continuous_functions_to_the_Sierpiński_space}

Let *X* be an arbitrary set. The [set of all functions](wikipedia://en/340630) from *X* to the set $\{0, 1\}$ is typically denoted $2^X.$ These functions are precisely the [characteristic functions](wikipedia://en/240790) of *X*. Each such function is of the form

$$\chi_U(x) = \begin{cases}1 & x \in U \\ 0 & x \not\in U\end{cases}$$

where *U* is a [subset](wikipedia://en/27631) of *X*. In other words, the set of functions $2^X$ is in [bijective](https://en.wikipedia.org/wiki/Bijective) correspondence with $P(X),$ the [power set](wikipedia://en/23799) of *X*. Every subset *U* of *X* has its characteristic function $\chi_U$ and every function from *X* to $\{0, 1\}$ is of this form.

Now suppose *X* is a topological space and let $\{0, 1\}$ have the Sierpiński topology. Then a function $\chi_U : X \to S$ is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) if and only if $\chi_U^{-1}(1)$ is open in *X*. But, by definition

$$\chi_U^{-1}(1) = U.$$

So $\chi_U$ is continuous if and only if *U* is open in *X*. Let $C(X, S)$ denote the set of all continuous maps from *X* to *S* and let $T(X)$ denote the topology of *X* (that is, the family of all open sets). Then we have a bijection from $T(X)$ to $C(X, S)$ which sends the open set $U$ to $\chi_U.$

$$C(X, S) \cong T(X)$$

That is, if we identify $2^X$ with $P(X)$ the subset of continuous maps $C(X, S) \subseteq 2^X$ is precisely the topology of $X:$ $T(X) \subseteq P(X).$

A particularly notable example of this is the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology) for [partially ordered sets](wikipedia://en/23572), in which the Sierpiński space becomes the [classifying space](wikipedia://en/923556) for open sets when the characteristic function preserves [directed joins](https://en.wikipedia.org/wiki/Directed_join).

### Categorical description {#Categorical_description}

The above construction can be described nicely using the language of [category theory](wikipedia://en/5869). There is a [contravariant functor](https://en.wikipedia.org/wiki/Contravariant_functor) $T : \mathbf{Top} \to \mathbf{Set}$ from the [category of topological spaces](wikipedia://en/435051) to the [category of sets](wikipedia://en/26829) which assigns each topological space $X$ its set of open sets $T(X)$ and each continuous function $f : X \to Y$ the [preimage](https://en.wikipedia.org/wiki/Preimage) map

$$f^{-1} : T(Y) \to T(X).$$

The statement then becomes: the functor $T$ is [represented](wikipedia://en/844461) by $(S, \{1\})$ where $S$ is the Sierpiński space. That is, $T$ is [naturally isomorphic](https://en.wikipedia.org/wiki/Naturally_isomorphic) to the [Hom functor](wikipedia://en/2741037) $\operatorname{Hom}(-, S)$ with the natural isomorphism determined by the [universal element](https://en.wikipedia.org/wiki/Universal_element) $\{1\} \in T(S).$ This is generalized by the notion of a [presheaf](wikipedia://en/4840944).[^o17]

### The initial topology {#The_initial_topology}

Any topological space *X* has the [initial topology](wikipedia://en/1197123) induced by the family $C(X, S)$ of continuous functions to Sierpiński space. Indeed, in order to [coarsen](https://en.wikipedia.org/wiki/Coarser_topology) the topology on *X* one must remove open sets. But removing the open set *U* would render $\chi_U$ discontinuous. So *X* has the coarsest topology for which each function in $C(X, S)$ is continuous.

The family of functions $C(X, S)$ [separates points](wikipedia://en/13972359) in *X* if and only if *X* is a [T<sub>0</sub> space](https://en.wikipedia.org/wiki/T0_space). Two points $x$ and $y$ will be separated by the function $\chi_U$ if and only if the open set *U* contains precisely one of the two points. This is exactly what it means for $x$ and $y$ to be [topologically distinguishable](https://en.wikipedia.org/wiki/Topologically_distinguishable).

Therefore, if *X* is T<sub>0</sub>, we can embed *X* as a [subspace](https://en.wikipedia.org/wiki/Subspace_%28topology%29) of a [product](wikipedia://en/24910) of Sierpiński spaces, where there is one copy of *S* for each open set *U* in *X*. The embedding map

$$e : X \to \prod_{U \in T(X)} S = S^{T(X)}$$

is given by

$$e(x)_U = \chi_U(x).\,$$

Since subspaces and products of T<sub>0</sub> spaces are T<sub>0</sub>, it follows that a topological space is T<sub>0</sub> if and only if it is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to a subspace of a power of *S*.

## In algebraic geometry {#In_algebraic_geometry}

In [algebraic geometry](wikipedia://en/1997) the Sierpiński space arises as the [spectrum](wikipedia://en/37291) $\operatorname{Spec}(R)$ of a [discrete valuation ring](wikipedia://en/848633) $R$ such as $\mathbb{Z}_{(p)}$ (the [localization](https://en.wikipedia.org/wiki/Localization_of_a_ring) of the [integers](wikipedia://en/14563) at the [prime ideal](wikipedia://en/24928) generated by the prime number $p$). The [generic point](wikipedia://en/3043978) of $\operatorname{Spec}(R),$ coming from the [zero ideal](https://en.wikipedia.org/wiki/Zero_ideal), corresponds to the open point 1, while the [special point](https://en.wikipedia.org/wiki/Special_point) of $\operatorname{Spec}(R),$ coming from the unique [maximal ideal](wikipedia://en/48164), corresponds to the [closed point](wikipedia://en/33086408) 0.
