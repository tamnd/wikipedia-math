# Singleton (mathematics)

::: {#o1 .subject cue=lead name="Singleton"}

In [mathematics](wikipedia://en/18831), a **singleton** (also known as a **unit set**[^o2] or **one-point set**) is a [set](wikipedia://en/26691) with [exactly one](wikipedia://en/276894) [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29). For example, the set $\{0\}$ is a singleton whose single element is $0$.

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Within the framework of [Zermelo–Fraenkel set theory](wikipedia://en/152214), the [axiom of regularity](wikipedia://en/2113) guarantees that no set is an element of itself. This implies that a singleton is necessarily distinct from the element it contains,[^o2] thus 1 and $\{1\}$ are not the same thing, and the [empty set](wikipedia://en/9566) is distinct from the set containing only the empty set. A set such as $\{\{1, 2, 3\}\}$ is a singleton as it contains a single element (which itself is a set, but not a singleton).

A set is a singleton [if and only if](wikipedia://en/14922) its [cardinality](wikipedia://en/6174) is 1. In [von Neumann's set-theoretic construction of the natural numbers](wikipedia://en/428484), the number 1 is *defined* as the singleton $\{0\}.$

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the existence of singletons is a consequence of the [axiom of pairing](wikipedia://en/52385): for any set *A*, the axiom applied to *A* and *A* asserts the existence of $\{A, A\},$ which is the same as the singleton $\{A\}$ (since it contains *A*, and no other set, as an element).

If *A* is any set and *S* is any singleton, then there exists precisely one [function](wikipedia://en/185427) from *A* to *S*, the function sending every element of *A* to the single element of *S*. Thus every singleton is a [terminal object](https://en.wikipedia.org/wiki/Terminal_object) in the [category of sets](wikipedia://en/26829).

A singleton has the property that every function from it to any arbitrary set is injective. The only non-singleton set with this property is the [empty set](wikipedia://en/9566).

Every singleton set is an [ultra prefilter](https://en.wikipedia.org/wiki/Ultra_prefilter). If $X$ is a set and $x \in X$ then the upward of $\{x\}$ in $X,$ which is the set $\{S \subseteq X : x \in S\},$ is a [principal](https://en.wikipedia.org/wiki/Ultrafilter_%28set_theory%29#principal) [ultrafilter](https://en.wikipedia.org/wiki/Ultrafilter_%28set_theory%29) on $X$. Moreover, every principal ultrafilter on $X$ is necessarily of this form.[^o5] The [ultrafilter lemma](https://en.wikipedia.org/wiki/Ultrafilter_lemma) implies that non-[principal](https://en.wikipedia.org/wiki/Ultrafilter_%28set_theory%29#principal) ultrafilters exist on every [infinite set](wikipedia://en/142679) (these are called [free ultrafilters](https://en.wikipedia.org/wiki/Free_ultrafilter_%28set_theory%29)). Every [net](wikipedia://en/22170) valued in a singleton subset $X$ of is an [ultranet](https://en.wikipedia.org/wiki/Ultranet_%28math%29) in $X.$

The [Bell number](wikipedia://en/201022) integer sequence counts the number of [partitions of a set](https://en.wikipedia.org/wiki/Partitions_of_a_set) (), if singletons are excluded then the numbers are smaller ().

:::

## In category theory {#In_category_theory}

Structures built on singletons often serve as [terminal objects](https://en.wikipedia.org/wiki/Terminal_object) or [zero objects](https://en.wikipedia.org/wiki/Zero_object) of various [categories](https://en.wikipedia.org/wiki/Category_%28category_theory%29):

- The statement above shows that the singleton sets are precisely the terminal objects in the category **[Set](wikipedia://en/26829)** of [sets](wikipedia://en/26691). No other sets are terminal.
- Any singleton admits a unique [topological space](wikipedia://en/30450) structure (both subsets are open). These singleton topological spaces are terminal objects in the category of topological spaces and [continuous functions](wikipedia://en/6122). No other spaces are terminal in that category.
- Any singleton admits a unique [group](wikipedia://en/19447) structure (the unique element serving as [identity element](wikipedia://en/14962)). These singleton groups are [zero objects](https://en.wikipedia.org/wiki/Initial_object) in the category of groups and [group homomorphisms](wikipedia://en/12396). No other groups are terminal in that category.

## Definition by indicator functions {#Definition_by_indicator_functions}

Let $S$ be a [class](wikipedia://en/20696) defined by an [indicator function](wikipedia://en/240790)

$$b : X \to \{0, 1\}.$$

Then $S$ is called a *singleton* if and only if there is some $y \in X$ such that for all $x \in X,$

$$b(x) = (x = y).$$

## Definition in *Principia Mathematica* {#Definition_in_Principia_Mathematica}

The following definition was introduced in [Principia Mathematica](wikipedia://en/24133) by [Whitehead](wikipedia://en/43395) and [Russell](wikipedia://en/4163):[^o9]

$\iota$**‘**$x = \hat{y}(y = x)$ **Df.**

The symbol $\iota$**‘**$x$ denotes the singleton $\{x\}$ and $\hat{y}(y = x)$ denotes the class of objects identical with $x$ i.e. $\{y : y=x\}$. This occurs as a definition in the introduction, which, in places, simplifies the argument in the main text, where it occurs as proposition 51.01 (p. 357 ibid.). The proposition is subsequently used to define the [cardinal number](wikipedia://en/6173) 1 as

$1=\hat{\alpha}((\exists x)\alpha=\iota$**‘**$x)$ **Df.**

That is, 1 is the class of singletons. This is definition 52.01 (p. 363 ibid.)
