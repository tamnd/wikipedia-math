# Crypto (book)

::: {#o2 .subject cue=lead name="Crypto"}

***Crypto: How the Code Rebels Beat the Government Saving Privacy in the Digital Age*** is a book about [cryptography](wikipedia://en/18934432) written by [Steven Levy](https://en.wikipedia.org/wiki/Steven_Levy), published in 2001. Levy details the emergence of [public key](https://en.wikipedia.org/wiki/Public_key) cryptography, [digital signatures](https://en.wikipedia.org/wiki/Digital_signatures) and the struggle between the [National Security Agency](wikipedia://en/21939) and *[cypherpunks](wikipedia://en/37314#Etymology_and_the_Cypherpunks_mailing_list)*. The book details the creation of [Data Encryption Standard](wikipedia://en/7978) (DES), [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) and the [Clipper chip](wikipedia://en/409665).[^o3]

:::
