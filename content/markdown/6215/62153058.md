# Polytopological space

::: {#o1 .subject cue=lead name="Polytopological space"}

In [general topology](wikipedia://en/178649), a **polytopological space** consists of a [set](wikipedia://en/26691) $X$ together with a [family](wikipedia://en/723043) $\{\tau_i\}_{i\in I}$ of [topologies](wikipedia://en/30450#Definition_via_open_sets) on $X$ that is [linearly ordered](wikipedia://en/30330) by the [inclusion relation](wikipedia://en/27631) where $I$ is an arbitrary [index set](wikipedia://en/393055). It is usually assumed that the topologies are in non-decreasing order.[^o2][^o3] However some authors prefer the associated [closure](wikipedia://en/42309) [operators](wikipedia://en/22213) $\{k_i\}_{i\in I}$ to be in non-decreasing order where $k_i\leq k_j$ if and only if $k_iA\subseteq k_jA$ for all $A\subseteq X$. This requires non-increasing topologies.[^o4]

:::

::: {#o6 .definition cue=heading name="Formal definitions"}

## Formal definitions {#Formal_definitions}

An $L$**\-topological space** $(X,\tau)$ is a set $X$ together with a [monotone map](wikipedia://en/48260) $\tau:L\to$ **Top**$(X)$ where $(L,\leq)$ is a [partially ordered set](wikipedia://en/23572) and **Top**$(X)$ is the set of all possible topologies on $X,$ ordered by inclusion. When the partial order $\leq$ is a linear order then $(X,\tau)$ is called a **polytopological space**. Taking $L$ to be the [ordinal number](wikipedia://en/26547932#Von_Neumann_definition_of_ordinals) $n=\{0,1,\dots,n-1\},$ an [$n$**\-topological space**](https://en.wikipedia.org/wiki/N-topological_space) $(X,\tau_0,\dots,\tau_{n-1})$ can be thought of as a set $X$ with topologies $\tau_0\subseteq\dots\subseteq\tau_{n-1}$ on it. More generally a **multitopological space** $(X,\tau)$ is a set $X$ together with an arbitrary family $\tau$ of topologies on it.[^o3]

:::

## History {#History}

Polytopological spaces were introduced in 2008 by the philosopher [Thomas Icard](https://en.wikipedia.org/wiki/Thomas_Icard) for the purpose of defining a topological [model](wikipedia://en/19858) of [Japaridze's polymodal logic (GLP)](wikipedia://en/46851461).[^o2] They were later used to generalize variants of [Kuratowski's closure-complement problem](wikipedia://en/10104622).[^o3][^o4] For example Taras Banakh et al. proved that under operator composition the $n$ closure operators and complement operator on an arbitrary $n$-topological space can together generate at most $2\cdot K(n)$ distinct operators[^o3] where

$$K(n)=\sum_{i,j=0}^n\tbinom{i+j}{i} \cdot \tbinom{i+j}{j}.$$

In 1965 the Finnish logician [Jaakko Hintikka](wikipedia://en/1710903) found this bound for the case $n=2$ and claimed[^o8] it "does not appear to obey any very simple law as a function of $n$".
