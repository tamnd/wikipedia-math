# Bangdiwala's B

::: {#o1 .subject cue=lead name="Bangdiwala's B"}

**Bangdiwala's B** statistic was created by [Shrikant Bangdiwala](https://en.wikipedia.org/wiki/Shrikant_Bangdiwala) in 1985 and is a measure of [inter-rater agreement](https://en.wikipedia.org/wiki/Inter-rater_agreement).[^o2][^o3] While not as commonly used as the [kappa statistic](https://en.wikipedia.org/wiki/Kappa_statistic) the B test has been used by various workers.[^o4][^o5][^o6][^o7] While it is principally used as a graphical aid to inter observer agreement, its [asymptotic distribution](wikipedia://en/3001287) is known.

:::

::: {#o9 .definition cue=heading name="Definition"}

## Definition {#Definition}

The test is applicable to testing the agreement between two observers. It is defined to be

$$B = \frac{ \sum_{i=1}^k n_{ ii }^2 }{ \sum_{i=1}^k n_{ i. } n_{ .i } }$$

where $n_{ii}$ are the values on the main diagonal, $n_{i.}$ is the $i$th row total, and $n_{.i}$ is the $i$th column total of the [contingency table](wikipedia://en/935515). The value of B varies in value between 0 (no agreement) and +1 (perfect agreement).

In large samples B has a [normal distribution](wikipedia://en/21462) whose variance has a complicated expression.[^o10] For small samples a permutation test is indicated.[^o10]

Guidance on its use and its extension to *n* x *n* tables have been provided by Munoz & Bangdiwala.[^o11] It may be more useful than the more commonly used Cohen's kappa in some circumstances.[^o12]

:::

## Tutorials and examples {#Tutorials_and_examples}

Worked examples of the use of Bangdiwala's B have been published.[^o14][^o15] The statistical programming language R has a set of functions that will compute the B test,[^o16] and a tutorial on the use of a test using these R functions is available.[^o17]
