# Measure algebra

::: {#o1 .subject cue=lead name="Measure algebra"}

In [mathematics](wikipedia://en/18831), a **measure algebra** is a [Boolean algebra](wikipedia://en/3959) with a countably additive positive [measure](wikipedia://en/19873). A [probability measure](wikipedia://en/45437) on a [measure space](wikipedia://en/45270) gives a measure algebra on the Boolean algebra of measurable sets modulo [null sets](wikipedia://en/21520).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A measure algebra is a Boolean algebra $B$ with a measure $m$, which is a real-valued function on $B$ such that[^n1]

- $$m(0)=0,\ m(1)=1,$$
- $m(x)>0$ if $x \neq 0$,
- $m(a)\leq m(b)$ for $a \leq b$,
- If $a_0, a_1, a_2, \dots$ are pairwise disjoint, then

$$m{\left(\sum_{n=0}^\infty a_n\right)} = \sum_{n=0}^\infty m(a_n).$$

:::
