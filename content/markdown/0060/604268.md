# Multi-index notation

::: {#o1 .subject cue=lead name="Multi-index notation"}

**Multi-index notation** is a [mathematical notation](wikipedia://en/277184) that simplifies formulas used in [multivariable calculus](wikipedia://en/615222), [partial differential equations](wikipedia://en/52564) and the theory of [distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29), by generalising the concept of an integer [index](wikipedia://en/320026) to an ordered [tuple](wikipedia://en/132729) of indices.

:::

## Definition and basic properties {#Definition_and_basic_properties}

An *n*-dimensional **multi-index** is an $n$-[tuple](wikipedia://en/132729)

$$\alpha = (\alpha_1, \alpha_2,\ldots,\alpha_n)$$

of [non-negative integers](https://en.wikipedia.org/wiki/Non-negative_integer) (i.e. an element of the *$n$*-[dimensional](wikipedia://en/8398) [set](wikipedia://en/26691) of [natural numbers](wikipedia://en/21474), denoted $\mathbb{N}^n_0$).

For multi-indices $\alpha, \beta \in \mathbb{N}^n_0$ and $x = (x_1, x_2, \ldots, x_n) \in \mathbb{R}^n$, one defines:

**Componentwise sum and difference**

$$\alpha \pm \beta= (\alpha_1 \pm \beta_1,\,\alpha_2 \pm \beta_2, \ldots, \,\alpha_n \pm \beta_n)$$

**[Partial order](https://en.wikipedia.org/wiki/Partial_order)**

$$\alpha \le \beta \quad \Leftrightarrow \quad \alpha_i \le \beta_i \quad \forall\,i\in\{1,\ldots,n\}$$

**Sum of components (absolute value)**

$$| \alpha | = \alpha_1 + \alpha_2 + \cdots + \alpha_n$$

**[Factorial](wikipedia://en/10606)**

$$\alpha ! = \alpha_1! \cdot \alpha_2! \cdots \alpha_n!$$

**[Binomial coefficient](wikipedia://en/4668)**

$$\binom{\alpha}{\beta} = \binom{\alpha_1}{\beta_1}\binom{\alpha_2}{\beta_2}\cdots\binom{\alpha_n}{\beta_n} = \frac{\alpha!}{\beta!(\alpha-\beta)!}$$

**[Multinomial coefficient](https://en.wikipedia.org/wiki/Multinomial_coefficient)**

$$\binom{k}{\alpha} = \frac{k!}{\alpha_1! \alpha_2! \cdots \alpha_n! } = \frac{k!}{\alpha!}$$

where $k:=|\alpha|\in\mathbb{N}_0$.

**[Power](https://en.wikipedia.org/wiki/Power_%28mathematics%29)**

$$x^\alpha = x_1^{\alpha_1} x_2^{\alpha_2} \ldots x_n^{\alpha_n}.$$

**Higher-order [partial derivative](wikipedia://en/52565)**

$$\partial^\alpha = \partial_1^{\alpha_1} \partial_2^{\alpha_2} \ldots \partial_n^{\alpha_n},$$

where $\partial_i^{\alpha_i}:=\partial^{\alpha_i} / \partial x_i^{\alpha_i}$ (see also [4-gradient](https://en.wikipedia.org/wiki/4-gradient)). Sometimes the notation $D^{\alpha} = \partial^{\alpha}$ is also used.[^o3]

## Some applications {#Some_applications}

The multi-index notation allows the extension of many formulae from elementary calculus to the corresponding multi-variable case. Below are some examples. In all the following, $x,y,h\in\mathbb{C}^n$ (or $\mathbb{R}^n$), and $\alpha,\beta, \nu\in\mathbb{N}_0^n$.

### Derivative of a monomial {#Derivative_of_a_monomial}

$$\partial^\alpha x^\beta = \begin{cases} \frac{\beta!}{(\beta-\alpha)!} x^{\beta-\alpha}, & \text{if}~ \alpha\le\beta,\\ 0, & \text{otherwise.} \end{cases}$$

::: {#o7 .statement kind=statement/theorem cue=named-heading name="Multinomial theorem"}

### Multinomial theorem {#Multinomial_theorem}

$$\left( \sum_{i=1}^n x_i\right)^k = \sum_{|\alpha|=k} \binom{k}{\alpha} \, x^\alpha.$$

:::

::: {#o9 .statement kind=statement/theorem cue=named-heading name="Multi-binomial theorem"}

### Multi-binomial theorem {#Multi-binomial_theorem}

$$(x+y)^\alpha = \sum_{\nu \le \alpha} \binom{\alpha}{\nu} \, x^\nu y^{\alpha - \nu}.$$

Note that, since $x + y$ is a vector and $\alpha$ is a multi-index, the expression on the left is short for $(x_{1} + y_{1})^{\alpha_{1}}\cdots(x_{n} + y_{n})^{\alpha_{n}}$.

:::

::: {#o11 .statement cue=named-heading name="Leibniz formula"}

### Leibniz formula {#Leibniz_formula}

For smooth functions $f$ and $g$,

$$\partial^\alpha(fg) = \sum_{\nu \le \alpha} \binom{\alpha}{\nu} \, \partial^{\nu}f\,\partial^{\alpha-\nu}g.$$

:::

### Taylor series {#Taylor_series}

For an [analytic function](wikipedia://en/61478) $f$ in *$n$* variables one has

$$f(x+h) = \sum_{\alpha\in\mathbb{N}^n_0} {\frac{\partial^{\alpha}f(x)}{\alpha !}h^\alpha}.$$

In fact, for a smooth enough function, we have the similar **Taylor expansion**

$$f(x+h) = \sum_{|\alpha| \le n}{\frac{\partial^{\alpha}f(x)}{\alpha !}h^\alpha}+R_{n}(x,h),$$

where the last term (the remainder) depends on the exact version of Taylor's formula. For instance, for the Cauchy formula (with integral remainder), one gets

$$R_n(x,h)= (n+1) \sum_{|\alpha| =n+1}\frac{h^\alpha}{\alpha !} \int_0^1(1-t)^n\partial^\alpha f(x+th) \, dt.$$

### Integration by parts {#Integration_by_parts}

For smooth functions $u$ and $v$ with [compact support](https://en.wikipedia.org/wiki/Compact_support) in $\mathbb{R}^n$,

$$\int_{\mathbb{R}^n} u(\partial^{\alpha}v) \, dx = (-1)^{|\alpha|} \int_{\mathbb{R}^n} {(\partial^{\alpha}u)v\,dx}.$$

This formula is used for the definition of [weak derivatives](wikipedia://en/1411087) of [distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29).
