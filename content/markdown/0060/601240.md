# Semantic theory of truth

::: {#o1 .subject cue=lead name="Semantic theory of truth"}

A **semantic theory of truth** is a [theory of truth](https://en.wikipedia.org/wiki/Theory_of_truth) in the [philosophy of language](https://en.wikipedia.org/wiki/Philosophy_of_language) which holds that truth is a property of sentences.[^o2]

:::

## Origin {#Origin}

The [semantic](https://en.wikipedia.org/wiki/Semantic) conception of truth, which is related in different ways to both the [correspondence](https://en.wikipedia.org/wiki/Correspondence_theory_of_truth) and [deflationary](wikipedia://en/601131) conceptions, is due to work by [Polish](https://en.wikipedia.org/wiki/Poland) [logician](wikipedia://en/46426065) [Alfred Tarski](wikipedia://en/59920). Tarski, in "On the Concept of Truth in Formal Languages" (1935), attempted to formulate a new theory of truth in order to resolve the [liar paradox](wikipedia://en/17967). In the course of this he made several metamathematical discoveries, most notably [Tarski's undefinability theorem](wikipedia://en/583785) using the same formal technique [Kurt Gödel](wikipedia://en/16736) used in his [incompleteness theorems](wikipedia://en/58863). Roughly, this states that a truth-predicate satisfying [Convention T](https://en.wikipedia.org/wiki/Convention_T) for the sentences of a given language cannot be defined *within* that language.

::: {#o5 .pointer-item cue=pointer name="Tarski's theory of truth"}

## Tarski's theory of truth {#Tarski's_theory_of_truth}

Tarski's theory of truth

To formulate linguistic theories[^o6] without semantic [paradoxes](wikipedia://en/24390) such as the [liar paradox](wikipedia://en/17967), it is generally necessary to distinguish the language that one is talking about (the *object language*) from the language that one is using to do the talking (the *[metalanguage](wikipedia://en/402929)*). In the following, quoted text is use of the object language, while unquoted text is use of the metalanguage; a quoted sentence (such as "*P*") is always the metalanguage's *name* for a sentence, such that this name is simply the sentence *P* rendered in the object language. In this way, the metalanguage can be used to talk about the object language; **Tarski's theory of truth** ([Alfred Tarski](wikipedia://en/59920) 1935) demanded that the object language be contained in the metalanguage.

Tarski's **material adequacy condition**, also known as **Convention T**, holds that any viable theory of truth must entail, for every sentence "*P*", a sentence of the following form (known as "form (T)"):

(1) "P" is true [if, and only if](https://en.wikipedia.org/wiki/If,_and_only_if), P.

For example,

(2) 'snow is white' is true if and only if snow is white.

These sentences (1 and 2, etc.) have come to be called the "T-sentences". The reason they look trivial is that the object language and the metalanguage are both English; here is an example where the object language is German and the metalanguage is English:

(3) 'Schnee ist weiß' is true if and only if snow is white.

As Tarski originally formulated it, this theory applies only to [formal languages](wikipedia://en/10939), cf. also [semantics of first-order logic](wikipedia://en/10983#Semantics). He gave a number of reasons for not extending his theory to [natural languages](wikipedia://en/21173), including the problem that there is no systematic way of deciding whether a given sentence of a natural language is well-formed, and that a natural language is *closed* (that is, it can describe the semantic characteristics of its own elements). But Tarski's approach was extended by [Davidson](https://en.wikipedia.org/wiki/Donald_Davidson_%28philosopher%29) into an approach to theories of *[meaning](https://en.wikipedia.org/wiki/Meaning_%28linguistics%29)* for natural languages, which involves treating "truth" as a primitive, rather than a defined, concept. (See [truth-conditional semantics](wikipedia://en/910058).)

Tarski developed the theory to give an [inductive definition](https://en.wikipedia.org/wiki/Inductive_definition) of truth as follows. (See [T-schema](wikipedia://en/1063436))

For a language *L* containing ¬ ("not"), ∧ ("and"), ∨ ("or"), ∀ ("for all"), and ∃ ("there exists"), Tarski's inductive definition of truth looks like this:

- (1) A primitive statement "*A*" is true if, and only if, *A*.
- (2) "¬*A*" is true if, and only if, "*A"* is not true.
- (3) "*A*∧*B*" is true if, and only if, "*A" is true* and "*B" is true*.
- (4) "*A*∨*B*" is true if, and only if, "*A" is true* or "*B" is true* or ("*A" is true* and "*B" is true*).
- (5) "∀*x*(*Fx*)" is true if, and only if, for all objects x, "Fx" is true.
- (6) "∃*x*(*Fx*)" is true if, and only if, there is an object *x* for which "Fx" is true.

These explain how the truth conditions of *complex* sentences (built up from [connectives](wikipedia://en/18153) and [quantifiers](wikipedia://en/43507260)) can be reduced to the truth conditions of their [constituents](https://en.wikipedia.org/wiki/Constituent_%28linguistics%29). The simplest constituents are [atomic sentences](wikipedia://en/943457). A contemporary semantic definition of truth would define truth for the atomic sentences as follows:

- An atomic sentence *F*(*x*<sub>1</sub>,...,*x*<sub>*n*</sub>) is true (relative to an [assignment](https://en.wikipedia.org/wiki/Assignment_%28mathematical_logic%29) of values to the variables *x*<sub>1</sub>, ..., *x*<sub>*n*</sub>)) if the corresponding [values](wikipedia://en/4095147) of [variables](wikipedia://en/3728109) bear the [relation](wikipedia://en/22517558) expressed by the [predicate](wikipedia://en/285109) *F*.

Tarski himself defined truth for atomic sentences in a variant way that does not use any technical terms from semantics, such as the "expressed by" above. This is because he wanted to define these semantic terms in the context of truth. Therefore it would be circular to use one of them in the definition of truth itself. Tarski's semantic conception of truth plays an important role in [modern logic](wikipedia://en/10983) and also in contemporary [philosophy of language](https://en.wikipedia.org/wiki/Philosophy_of_language). It is a rather controversial point whether Tarski's semantic theory should be counted either as a [correspondence theory](https://en.wikipedia.org/wiki/Correspondence_theory_of_truth) or as a [deflationary theory](wikipedia://en/601131).[^o7]

## Kripke's theory of truth {#Kripke's_theory_of_truth}

Kripke's theory of truth

**Kripke's theory of truth** ([Saul Kripke](wikipedia://en/48039) 1975) is an alternative to Tarski's hierarchy of object languages and metalanguages. Based on partial logic (a logic of partially defined [truth predicates](wikipedia://en/4807326) instead of Tarski's logic of totally defined truth predicates), Kripke allows a language to contain its own truth predicate and constructs an interpretation of that predicate in stages.[^o10]

In the most common construction of the theory, sentences are evaluated with the [strong Kleene evaluation scheme](wikipedia://en/249904#Kleene_and_Priest_logics).[^o11] In addition to true and false sentences, some sentences are also allowed to have no initial truth value. Then, iteratively, the interpretation of the truth predicate is expanded. At each stage, sentences whose truth values can be determined from earlier stages receive a truth value. For example, if a sentence $P$ is determined to be true, then at a later stage a sentence asserting "$P$ is true" can be assigned a true value.

This process can be continued through [transfinite induction](wikipedia://en/30461). Since the strong Kleene evaluation is monotonic, the sequence will eventually reach a fixed point where further applications of the procedure no longer change the extension or anti-extension of the truth predicate.[^o12] Kripke focuses on the least such fixed point, obtained by beginning with the minimal interpretation of the truth predicate and iterating the construction.[^o13]

A sentence that receives a truth value at the least fixed point is called grounded, while those that never receive one are ungrounded. A grounded sentence implies that it has a truth value that can be traced back through the stages of construction to non semantic facts. Sentences such as the [liar paradox](wikipedia://en/17967) may remain ungrounded; under the strong Kleene construction, the liar would have no truth value at the least fixed point. This allows Kripke's theory to accommodate semantic self reference without introducing Tarski's explicit hierarchy of languages.[^o14]
