# Duality (order theory)

::: {#o1 .subject cue=lead name="Duality"}

In the [mathematical](wikipedia://en/18831) area of [order theory](wikipedia://en/361924), every [partially ordered set](wikipedia://en/23572) *P* gives rise to a **dual** (or **opposite**) partially ordered set which is often denoted by *P*<sup>op</sup> or *P*<sup>*d*</sup>. This dual order *P*<sup>op</sup> is defined to be the same set, but with the **inverse order**, i.e. *x* ≤ *y* holds in *P*<sup>op</sup> [if and only if](wikipedia://en/14922) *y* ≤ *x* holds in *P*. It is easy to see that this construction, which can be depicted by flipping the [Hasse diagram](wikipedia://en/338199) for *P* upside down, will indeed yield a partially ordered set. In a broader sense, two partially ordered sets are also said to be duals if they are **dually isomorphic**, i.e. if one poset is [order isomorphic](wikipedia://en/23916899) to the dual of the other.

:::

The importance of this simple definition stems from the fact that every definition and theorem of order theory can readily be transferred to the dual order. Formally, this is captured by the **Duality Principle** for ordered sets:

If a given statement is valid for all partially ordered sets, then its dual statement, obtained by inverting the direction of all order relations and by dualizing all order theoretic definitions involved, is also valid for all partially ordered sets.

If a statement or definition is equivalent to its dual then it is said to be **self-dual**. Note that the consideration of dual orders is so fundamental that it often occurs implicitly when writing ≥ for the dual order of ≤ without giving any prior definition of this "new" symbol.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

*Image: Duale Verbaende.svg.* A bounded distributive lattice, and its dual

Naturally, there are a great number of examples for concepts that are dual:

- [Greatest elements and least elements](https://en.wikipedia.org/wiki/Greatest_element)
- [Maximal elements and minimal elements](https://en.wikipedia.org/wiki/Maximal_element)
- [Least upper bounds](https://en.wikipedia.org/wiki/Least_upper_bound) (suprema, ∨) and [greatest lower bounds](https://en.wikipedia.org/wiki/Greatest_lower_bound) (infima, ∧)
- [Upper sets and lower sets](https://en.wikipedia.org/wiki/Upper_set)
- [Ideals](wikipedia://en/530559) and [filters](wikipedia://en/19719)
- [Closure operators](wikipedia://en/483120) and [kernel operators](https://en.wikipedia.org/wiki/Kernel_operator).

Examples of notions which are self-dual include:

- Being a ([complete](wikipedia://en/44777)) [lattice](wikipedia://en/469304)
- [Monotonicity](wikipedia://en/48260) of functions
- [Distributivity of lattices](wikipedia://en/310883), i.e. the lattices for which ∀*x*,*y*,*z*: *x* ∧ (*y* ∨ *z*) = (*x* ∧ *y*) ∨ (*x* ∧ *z*) holds are exactly those for which the dual statement ∀*x*,*y*,*z*: *x* ∨ (*y* ∧ *z*) = (*x* ∨ *y*) ∧ (*x* ∨ *z*) holds[^o4]
- Being a [Boolean algebra](wikipedia://en/3959)
- Being an [order isomorphism](wikipedia://en/23916899).

Since partial orders are [antisymmetric](wikipedia://en/1176), the only ones that are self-dual are the [equivalence relations](https://en.wikipedia.org/wiki/Equivalence_relations) (but the notion of partial order **is** self-dual).
