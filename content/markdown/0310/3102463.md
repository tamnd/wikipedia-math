# Godeaux surface

::: {#o1 .subject cue=lead name="Godeaux surface"}

In mathematics, a **Godeaux surface** is one of the [surfaces of general type](https://en.wikipedia.org/wiki/Surfaces_of_general_type) introduced by [Lucien Godeaux](wikipedia://en/7285615) in 1931. Other surfaces constructed in a similar way with the same [Hodge numbers](https://en.wikipedia.org/wiki/Hodge_number) are also sometimes called Godeaux surfaces. Surfaces with the same Hodge numbers (such as [Barlow surfaces](wikipedia://en/3102370)) are called **numerical Godeaux surfaces**.

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

The cyclic group of order 5 acts freely on the [Fermat surface](https://en.wikipedia.org/wiki/Fermat_surface) of points (*w : x : y : z*) in *P*<sup>3</sup> satisfying *w*<sup>5</sup> + *x*<sup>5</sup> + *y*<sup>5</sup> + *z*<sup>5</sup> = 0 by mapping (*w* : *x* : *y* : *z*) to (*w:ρx:ρ<sup>2</sup>y:ρ<sup>3</sup>z*) where ρ is a fifth root of 1. The quotient by this action is the original **Godeaux surface**.

:::

## Invariants {#Invariants}

The fundamental group (of the original Godeaux surface) is cyclic of order 5. It has invariants $q = 0, p_g = 0$ like rational surfaces do, though it is not rational. The square of the first Chern class $c_1^2 = 1$ (and moreover the canonical class is ample).
