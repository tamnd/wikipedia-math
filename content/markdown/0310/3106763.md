# R (complexity)

::: {#o1 .subject cue=lead name="R"}

In [computational complexity theory](wikipedia://en/7543), **R** is the class of [decision problems](wikipedia://en/8336) solvable by a [Turing machine](wikipedia://en/30403), which is the set of all [recursive languages](wikipedia://en/23290990) (also called decidable languages).

:::

## Equivalent formulations {#Equivalent_formulations}

R is equivalent to the set of all total [computable functions](wikipedia://en/1139338) in the sense that:

- a decision problem is in R if and only if its [indicator function](wikipedia://en/240790) is computable,
- a total function is computable if and only if its [graph](wikipedia://en/87352) is in R.

## Relationship with other classes {#Relationship_with_other_classes}

Since we can decide any problem for which there exists a [recogniser](https://en.wikipedia.org/wiki/Recognizer) and also a co-recogniser by simply interleaving them until one obtains a result, the class is equal to [**RE**](wikipedia://en/3106703) ∩ **co-RE**.
