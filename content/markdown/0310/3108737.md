# Hermitian function

::: {#o1 .subject cue=lead name="Hermitian function"}

In [mathematical analysis](wikipedia://en/48396), a **Hermitian function** is a [complex function](https://en.wikipedia.org/wiki/Complex-valued_function) with the property that its [complex conjugate](wikipedia://en/173918) is equal to the original function with the variable changed in [sign](wikipedia://en/7951270):

:::

$$f^*(x) = f(-x)$$

(where the $^*$ indicates the complex conjugate) for all $x$ in the domain of $f$. In [physics](wikipedia://en/22939), this property is referred to as [PT symmetry](https://en.wikipedia.org/wiki/Non-Hermitian_quantum_mechanics).

This definition extends also to functions of two or more variables, e.g., in the case that $f$ is a function of two variables it is Hermitian if

$$f^*(x_1, x_2) = f(-x_1, -x_2)$$

for all pairs $(x_1, x_2)$ in the domain of $f$.

From this definition it follows immediately that: $f$ is a Hermitian function [if and only if](wikipedia://en/14922)

- the real part of $f$ is an [even function](https://en.wikipedia.org/wiki/Even_function),
- the imaginary part of $f$ is an [odd function](https://en.wikipedia.org/wiki/Odd_function).

## Motivation {#Motivation}

Hermitian functions appear frequently in mathematics, physics, and [signal processing](wikipedia://en/29324). For example, the following two statements follow from basic properties of the Fourier transform:

- The function $f$ is real-valued if and only if the [Fourier transform](wikipedia://en/52247) of $f$ is Hermitian.
- The function $f$ is Hermitian if and only if the [Fourier transform](wikipedia://en/52247) of $f$ is real-valued.

Since the Fourier transform of a real signal is guaranteed to be Hermitian, it can be compressed using the Hermitian even/odd symmetry. This, for example, allows the [discrete Fourier transform](wikipedia://en/8811) of a signal (which is in general complex) to be stored in the same space as the original real signal. Informally, only half of the fourier transform of a real signal is needed to lossessly represent it in frequency domain.

For the magnitude spectra (obtained from [DFT](wikipedia://en/8811)), the axis of symmetry is around the [Nyquist point](wikipedia://en/41435); one half is the mirror image of the other.

- If *f* is Hermitian, then $f \star g = f*g$.

Where the $\star$ is [cross-correlation](wikipedia://en/714163), and $*$ is [convolution](wikipedia://en/7519).

- If both *f* and *g* are Hermitian, then $f \star g = g \star f$.
