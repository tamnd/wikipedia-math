# GNOME Keyring

::: {#o2 .subject cue=lead name="GNOME Keyring"}

**GNOME Keyring** is a software application designed to store security credentials such as [usernames](https://en.wikipedia.org/wiki/User_%28computing%29),[^o10] [passwords](wikipedia://en/24304),[^o10] and [keys](wikipedia://en/24222), together with a small amount of relevant [metadata](https://en.wikipedia.org/wiki/Metadata). The sensitive data is [encrypted](https://en.wikipedia.org/wiki/Encrypt) and stored in a keyring [file](https://en.wikipedia.org/wiki/Computer_file) in the user's [home directory](https://en.wikipedia.org/wiki/Home_directory). The default keyring uses the login [password](wikipedia://en/24304) for encryption, so users don't need to remember another password.[^o3]

:::

As of 2009, GNOME Keyring was part of the desktop environment in the operating system [OpenSolaris](https://en.wikipedia.org/wiki/OpenSolaris).[^o10]

GNOME Keyring is implemented as a [daemon](https://en.wikipedia.org/wiki/Daemon_%28computer_software%29) and uses the [process](https://en.wikipedia.org/wiki/Process_%28computing%29) name *gnome-keyring-daemon*. Applications can store and request passwords by using the *libsecret* [library](https://en.wikipedia.org/wiki/Library_%28computing%29) which replaces the deprecated *libgnome-keyring* library.

GNOME Keyring is part of the [GNOME](https://en.wikipedia.org/wiki/GNOME) desktop. As of 2006, it integrated with [NetworkManager](https://en.wikipedia.org/wiki/NetworkManager) to store [WEP](wikipedia://en/422014) passwords.[^o4] [GNOME Web](https://en.wikipedia.org/wiki/GNOME_Web) and the email client [Geary](https://en.wikipedia.org/wiki/Geary_%28software%29) uses GNOME Keyring to store passwords.[^o5]

On systems where GNOME Keyring is present, software written in [Vala](https://en.wikipedia.org/wiki/Vala_%28programming_language%29) can use it to store and retrieve passwords.[^o6] The GNOME Keyring Manager (gnome-keyring-manager) was the first user interface for the GNOME Keyring. As of GNOME 2.22, it is deprecated and replaced entirely with [Seahorse](https://en.wikipedia.org/wiki/Seahorse_%28software%29).[^o7]
