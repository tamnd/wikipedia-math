# Compactly generated group

::: {#o1 .subject cue=lead name="Compactly generated group"}

In [mathematics](wikipedia://en/18831), a **compactly generated (topological) group** is a [topological group](wikipedia://en/42315) *G* which is [algebraically generated](wikipedia://en/99945) by one of its [compact](wikipedia://en/6042) subsets.[^o2] This should not be confused with the unrelated notion (widely used in [algebraic topology](wikipedia://en/38801)) of a [compactly generated space](wikipedia://en/899382) -- one whose [topology](wikipedia://en/29954) is generated (in a suitable sense) by its compact subspaces.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [topological group](wikipedia://en/42315) *G* is said to be **compactly generated** if there exists a compact subset *K* of *G* such that

$$\langle K\rangle = \bigcup_{n \in \mathbb{N}} (K \cup K^{-1})^n = G.$$

So if *K* is symmetric, i.e. *K* = *K*<sup>−1</sup>, then

$$G = \bigcup_{n \in \mathbb{N}} K^n.$$

:::

## Locally compact case {#Locally_compact_case}

This property is interesting in the case of [locally compact](wikipedia://en/48632) topological groups, since locally compact compactly generated topological groups can be approximated by locally compact, [separable](wikipedia://en/27855) [metric](wikipedia://en/20018) factor groups of *G*. More precisely, for a sequence

*U*<sub>*n*</sub>

of open identity neighborhoods, there exists a [normal subgroup](wikipedia://en/21918) *N* contained in the intersection of that sequence, such that

*G*/*N*

is locally compact metric separable (the [Kakutani-Kodaira-Montgomery-Zippin theorem](https://en.wikipedia.org/wiki/Kakutani-Kodaira-Montgomery-Zippin_theorem)).
