# GMR (cryptography)

::: {#o1 .subject cue=lead name="GMR"}

In [cryptography](wikipedia://en/18934432), **GMR** is a [digital signature](wikipedia://en/59644) [algorithm](wikipedia://en/775) named after its inventors [Shafi Goldwasser](wikipedia://en/842178), [Silvio Micali](https://en.wikipedia.org/wiki/Silvio_Micali) and [Ron Rivest](https://en.wikipedia.org/wiki/Ron_Rivest).

:::

As with [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) the security of the system is related to the difficulty of [factoring very large numbers](wikipedia://en/15491). But, in contrast to RSA, GMR is secure against *adaptive [chosen-message attacks](https://en.wikipedia.org/wiki/Chosen_plaintext_attack)*, which is the currently accepted security definition for signature schemes— even when an attacker receives signatures for messages of his choice, this does not allow them to forge a signature for a single additional message.
