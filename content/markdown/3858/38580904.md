# Halin's grid theorem

::: {#o1 .subject cue=lead name="Halin's grid theorem"}

In the mathematics of [infinite graphs](https://en.wikipedia.org/wiki/Infinite_graph), **Halin's grid theorem** states that the infinite graphs with *thick [ends](wikipedia://en/33989041)* are exactly the graphs containing [subdivisions](wikipedia://en/353021) of the [hexagonal tiling](wikipedia://en/2863719) of the plane. It was published by [Rudolf Halin](wikipedia://en/38581524) in 1965. It is a precursor to the work of [Neil Robertson](wikipedia://en/1575704) and [Paul Seymour](wikipedia://en/1575708) linking [treewidth](wikipedia://en/3987086) to large [grid](https://en.wikipedia.org/wiki/Grid_graph) [minors](wikipedia://en/353042) in finite graphs, which became an important component of the [algorithmic](wikipedia://en/775) theory of [bidimensionality](https://en.wikipedia.org/wiki/Bidimensionality).

:::

## Definitions and statement {#Definitions_and_statement}

A ray, in an infinite graph, is a semi-infinite [path](wikipedia://en/638889): a connected infinite subgraph in which one vertex has [degree](wikipedia://en/1374448) one and the rest have degree two. In a precursor to the paper proving his grid theorem, Halin defined two rays $r_0$ and $r_1$ to be equivalent if there exists a ray $r_2$ that includes infinitely many vertices from each of them. This is an [equivalence relation](wikipedia://en/9259), and its equivalence classes (sets of mutually equivalent rays) are called the [ends](wikipedia://en/33989041) of the graph. Halin defined a *thick end* of a graph to be an end that contains infinitely many rays that, despite being equivalent, are pairwise [disjoint](wikipedia://en/39359) from each other.

*Image: Tiling Regular 6-3 Hexagonal.svg.* The hexagonal tiling of the plane

An example of a graph with a thick end is provided by the [hexagonal tiling](wikipedia://en/2863719) of the [Euclidean plane](wikipedia://en/15575410). The subset of the hexagonal tiling within any fixed [angle](wikipedia://en/1196) also has infinitely many disjoint rays. [Reinhard Diestel](wikipedia://en/78071340) defines a partial hexagonal grid with this combinatorial structure consisting of the [integer points](https://en.wikipedia.org/wiki/Integer_point) $(x,y)$ with $0\le x\le y$ (a 45° angle), with vertical edges connecting each $(x,y)$ to $(x,y+1)$ but with horizontal edges from $(x,y)$ to $(x+1,y)$ only when $x+y$ is odd. For a partial hexagonal grid, defined in this way, the geometric rays extending vertically from each point $(x,x)$ provide infinitely many disjoint graph-theoretic rays, all of which belong to the same thick end.

Halin's theorem states that this example is universal: every graph with a thick end contains as a subgraph either this partial hexagonal grid itself, or a graph formed from it by modifying it in simple ways, by subdividing some of its edges into finite paths. The subgraph of this form can be chosen so that its rays belong to the given thick end. Conversely, whenever an infinite graph contains a subdivision of the hexagonal tiling, it must have a thick end, namely the end that contains all of the rays that are subgraphs of this subdivision.

## Analogues for finite graphs {#Analogues_for_finite_graphs}

As part of their work on [graph minors](wikipedia://en/353042) leading to the [Robertson–Seymour theorem](wikipedia://en/351769) and the [graph structure theorem](wikipedia://en/21318521), [Neil Robertson](wikipedia://en/1575704) and [Paul Seymour](wikipedia://en/1575708) proved that a family $\mathcal{F}$ of finite graphs has unbounded [treewidth](wikipedia://en/3987086) if and only if the minors of graphs in $\mathcal{F}$ include arbitrarily large square [grid graphs](https://en.wikipedia.org/wiki/Grid_graph), or equivalently subgraphs of the hexagonal tiling formed by intersecting it with arbitrarily large disks. Although the precise relation between treewidth and grid minor size remains elusive, this result became a cornerstone in the theory of [bidimensionality](https://en.wikipedia.org/wiki/Bidimensionality), a characterization of certain graph parameters that have particularly efficient [fixed-parameter tractable](wikipedia://en/603026) algorithms and [polynomial-time approximation schemes](wikipedia://en/666431).

For finite graphs, the treewidth is always one less than the maximum order of a [haven](wikipedia://en/5133456), where a haven describes a certain type of strategy for a robber to escape the police in a [pursuit–evasion](wikipedia://en/3857398) game played on the graph, and the order of the haven gives the number of police needed to catch a robber using this strategy. Thus, the relation between treewidth and grid minors can be restated: in a family of finite graphs, the order of the havens is unbounded if and only if the size of the grid minors is unbounded. For infinite graphs, the equivalence between treewidth and haven order is no longer true, but instead havens are intimately connected to ends: the ends of a graph are in one-to-one correspondence with the havens whose order is the [aleph number](wikipedia://en/293961) $\aleph_0$. It is not always the case that an infinite graph has a haven of infinite order if and only if it has a grid minor of infinite size, but Halin's theorem provides an extra condition (the thickness of the end corresponding to the haven) under which it becomes true.
