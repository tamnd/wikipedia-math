# Spinc structure

::: {#o1 .subject cue=lead name="Spinc structure"}

In [spin geometry](wikipedia://en/32013990), a **spin<sup>c</sup> structure** (or **complex spin structure**) is a generalization of a [spin structure](wikipedia://en/2844303). In mathematics, these are used to describe [spinor bundles](wikipedia://en/348085) and [spinors](wikipedia://en/29276), which in physics are used to describe [spin](wikipedia://en/19593829), an intrinsic [angular momentum](wikipedia://en/2839) of [particles](https://en.wikipedia.org/wiki/Particle) after which they have been named. Since spin<sup>c</sup> structures also exist under weakened conditions, which might not allow spin structures, they provide a suitable alternative for such situations. [Orientable](wikipedia://en/187446) manifolds with a spin<sup>c</sup> structure are called **spin<sup>c</sup> manifolds**.[^o2] C stands for the [complex numbers](wikipedia://en/5826), which are denoted $\mathbb{C}$ and appear in the definition of the underlying [spin<sup>c</sup> group](wikipedia://en/79367876).

:::

In four dimensions, a spin<sup>c</sup> structure defines two complex plane bundles, which can be used to describe negative and positive [chirality](https://en.wikipedia.org/wiki/Chirality_%28physics%29) of [spinors](wikipedia://en/29276), for example in the [Dirac equation](wikipedia://en/39407) of [relativistic quantum field theory](https://en.wikipedia.org/wiki/Relativistic_quantum_field_theory). Another central application is [Seiberg–Witten theory](wikipedia://en/3526032), which uses them to study [4-manifolds](wikipedia://en/1362795).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $M$ be a $n$-dimensional [orientable manifold](https://en.wikipedia.org/wiki/Orientable_manifold). Its [tangent bundle](wikipedia://en/211794) $TM$ is described by a classifying map $M\rightarrow\operatorname{BSO}(n)$ into the [classifying space](wikipedia://en/76359810) $\operatorname{BSO}(n)$ of the [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group) $\operatorname{SO}(n)$. It can factor over the map $\operatorname{BSpin}^\mathrm{c}(n)\rightarrow\operatorname{BSO}(n)$ induced by the canonical projection $\operatorname{Spin}^\mathrm{c}(n)\twoheadrightarrow\operatorname{SO}(n)$ on [classifying spaces](wikipedia://en/923556). In this case, the classifying map lifts to a continuous map $M\rightarrow\operatorname{BSpin}^\mathrm{c}(n)$ into the classifying space $\operatorname{BSpin}^\mathrm{c}(n)$ of the [spin<sup>c</sup> group](wikipedia://en/79367876) $\operatorname{Spin}^\mathrm{c}(n)$. Its [homotopy](wikipedia://en/212250) class is called *spin<sup>c</sup> structure*.[^o5][^o6]

Assume $M$ has a spin<sup>c</sup> structure. Let then $\operatorname{Spin}^\mathrm{c}(M)$ denote the set of spin<sup>c</sup> structures on $M$. The first [unitary group](wikipedia://en/173993) [$\operatorname{U}(1)$](wikipedia://en/80364893) is the second factor of the spin<sup>c</sup> group and using its [classifying space](wikipedia://en/2819900) [$\operatorname{BU}(1) \cong\operatorname{BSO}(2)$](wikipedia://en/80364893), which is the infinite [complex projective space](wikipedia://en/762977) [$\mathbb{C}P^\infty$](wikipedia://en/80364893) and a model of the [Eilenberg–MacLane space](wikipedia://en/1073230) $K(\mathbb{Z},2)$, there is a [bijection](wikipedia://en/3942):[^o7]

$$\operatorname{Spin}^\mathrm{c}(M) \cong[M,\operatorname{BU}(1)] \cong[M,\mathbb{C}P^\infty] \cong[M,K(\mathbb{Z},2)] \cong H^2(M,\mathbb{Z}).$$

The former isomorphism follows from the [Puppe sequence](wikipedia://en/4734210) for the fibration $\mathbb{C}P^\infty\hookrightarrow\operatorname{BSpin}^\mathrm{c}(n)\twoheadrightarrow\operatorname{BSO}(n)$ (when applying [$[M,-]$](wikipedia://en/80364893)).[^o8]

Due to the canonical projection $\operatorname{BSpin}^\mathrm{c}(n)\rightarrow\operatorname{U}(1)/\mathbb{Z}_2 \cong\operatorname{U}(1)$, every spin<sup>c</sup> structure induces a [principal $\operatorname{U}(1)$-bundle](wikipedia://en/80364893) or equivalently a complex [line bundle](wikipedia://en/361366).

:::

## Properties {#Properties}

- Every spin structure induces a canonical spin<sup>c</sup> structure.[^o11][^o12] The reverse implication doesn't hold as the [complex projective plane](wikipedia://en/737155) $\mathbb{C}P^2$ shows.
- Every spin<sup>c</sup> structure induces a canonical spin<sup>h</sup> structure. The reverse implication doesn't hold as the [Wu manifold](wikipedia://en/77123741) $\operatorname{SU}(3)/\operatorname{SO}(3)$ shows.
- An orientable manifold $M$ has a spin<sup>c</sup> structure iff its third integral Stiefel–Whitney class $W_3(M) \in H^3(M,\mathbb{Z})$ vanishes. This class $W_3(M)$ is the image of the second ordinary Stiefel–Whitney class $w_2(M) \in H^2(M,\mathbb{Z}_2)$ under the Bockstein homomorphism $H^2(M,\mathbb{Z}_2)\rightarrow H^3(M,\mathbb{Z})$.[^o13][^o14]
- Every orientable smooth manifold with four or less dimensions has a spin<sup>c</sup> structure.[^o12]
- Every [almost complex manifold](wikipedia://en/514258) has a spin<sup>c</sup> structure.[^o15][^o12]
- For a [compact](wikipedia://en/6042) spin<sup>c</sup> manifold $M$, for which a torsion class $c\in H^2(M,\mathbb{Z})$ with $w_2(M)=c\operatorname{mod}2$ exists and which has a Riemannian metric of overall positive scalar curvature, its [Â genus](https://en.wikipedia.org/wiki/Â_genus) vanishes, hence $\widehat{A}(M)=0$.[^o16]

The following properties hold more generally for the lift on the Lie group $\operatorname{Spin}^k(n) :=\left( \operatorname{Spin}(n)\times\operatorname{Spin}(k) \right)/\mathbb{Z}_2$, with the particular case $k=2$ giving:

- If $M\times N$ is a spin<sup>c</sup> manifold, then $M$ and $N$ are spin<sup>c</sup> manifolds.[^o17]
- If $M$ is a spin manifold, then $M\times N$ is a spin<sup>c</sup> manifold iff $N$ is a spin<sup>c</sup> manifold.[^o17]
- If $M$ and $N$ are spin<sup>c</sup> manifolds of same dimension, then their [connected sum](wikipedia://en/490134) $M\# N$ is a spin<sup>c</sup> manifold.[^o18]
- The following conditions are equivalent:[^o19]
  - $M$ is a spin<sup>c</sup> manifold.
  - There is a real plane bundle $E\twoheadrightarrow M$, so that $TM\oplus E$ has a spin structure or equivalently $w_2(TM\oplus E) =0$.
  - $M$ can be immersed in a spin manifold with two dimensions more.
  - $M$ can be embedded in a spin manifold with two dimensions more.

:::

## Cohomology of infinite classifying space {#Cohomology_of_infinite_classifying_space}

The [cohomology ring](wikipedia://en/1069723) of the infinite classifying space $\operatorname{BSpin}^\mathrm{c} :=\lim_{n\rightarrow\infty}\operatorname{BSpin}^\mathrm{c}(n)$ with coefficients in $\mathbb{Z}_2$ can be expressed using [Steenrod squares](https://en.wikipedia.org/wiki/Steenrod_square) and [Wu classes](https://en.wikipedia.org/wiki/Wu_class):[^o21][^o22]

$$H^*(\operatorname{BSpin}^\mathrm{c},\mathbb{Z}_2) \cong H^*(\operatorname{BSO},\mathbb{Z}_2)/(\operatorname{Sq}^1\nu_{2^r},r\geq 1).$$
