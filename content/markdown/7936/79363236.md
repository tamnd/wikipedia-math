# Burgess inequality

::: {#o1 .subject cue=lead name="Burgess inequality"}

In [analytic number theory](wikipedia://en/251513), the **Burgess inequality** (also called the **Burgess bound**) is an [inequality](wikipedia://en/89489) that provides an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) for [character sums](wikipedia://en/2986034)

:::

$$S_{\chi}(N,H):=\sum\limits_{N+1\leq n\leq N+H} \chi(n)$$

where $\chi$ is a [Dirichlet character](wikipedia://en/174515) modulo a cube free $q\in\mathbb{N}$ that is not the [principal character](wikipedia://en/174515) $\chi_0$.

The inequality was proven in 1963 along with a series of related inequalities, by the [British](https://en.wikipedia.org/wiki/United_Kingdom) mathematician [David Allan Burgess](https://en.wikipedia.org/wiki/David_Allan_Burgess).[^o2] It provides a better estimate for small character sums than the [Pólya–Vinogradov inequality](https://en.wikipedia.org/wiki/Pólya–Vinogradov_inequality) from 1918. More recent results have led to refinements and generalizations of the Burgess bound.[^o3]

::: {#o5 .statement cue=named-heading name="Burgess inequality"}

## Burgess inequality {#Burgess_inequality}

A number is called *cube free* if it is not divisible by any cubic number $x^3$ except $\pm 1$. Define $r\in \mathbb{N}$ with $r\geq 2$ and $\varepsilon>0$.

Let $\chi$ be a Dirichlet character modulo $q\in\mathbb{N}$ that is not a principal character. For two $N,H\in\mathbb{N}$, define the character sum

$$S_{\chi}(N,H):=\sum\limits_{N+1\leq n\leq N+H} \chi(n).$$

If either $q$ is cube free or $r\leq 3$, then the **Burgess inequality** holds[^o2][^o6]

$$|S_{\chi}(N,H)|\leq C_{r,\varepsilon} H^{1-1/r}q^{(r+1)/(4r^2)+\varepsilon}$$

for some constant $C_{r,\varepsilon}$.

:::
