# Spinc group

::: {#o1 .subject cue=lead name="Spinc group"}

In [spin geometry](wikipedia://en/32013990), a **spin<sup>c</sup> group** (or **complex spin group**) is a [Lie group](wikipedia://en/17945) obtained by the [spin group](wikipedia://en/411231) through twisting with the first [unitary group](wikipedia://en/173993). C stands for the [complex numbers](wikipedia://en/5826), which are denoted $\mathbb{C}$. An important application of spin<sup>c</sup> groups is for [spin<sup>c</sup> structures](wikipedia://en/79367906), which are central for [Seiberg–Witten theory](wikipedia://en/3526032).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [spin group](wikipedia://en/411231) $\operatorname{Spin}(n)$ is a [double cover](https://en.wikipedia.org/wiki/Double_cover_%28topology%29) of the [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group) $\operatorname{SO}(n)$, hence $\mathbb{Z}_2$ acts on it with $\operatorname{Spin}(n)/\mathbb{Z}_2\cong\operatorname{SO}(n)$. Furthermore, $\mathbb{Z}_2$ also acts on the first unitary group $\operatorname{U}(1)$ through the [antipodal](wikipedia://en/367577) identification $y\sim -y$. The *spin<sup>c</sup> group* is then:[^o4][^o5][^o6][^o7]

$$\operatorname{Spin}^\mathrm{c}(n) :=\left( \operatorname{Spin}(n)\times\operatorname{U}(1) \right)/\mathbb{Z}_2$$

with $(x,y)\sim(-x,-y)$. It is also denoted $\operatorname{Spin}^\mathbb{C}(n)$. Using the exceptional isomorphism $\operatorname{Spin}(2) \cong\operatorname{U}(1)$, one also has $\operatorname{Spin}^\mathrm{c}(n) =\operatorname{Spin}^2(n)$ with:

$$\operatorname{Spin}^k(n) :=\left( \operatorname{Spin}(n)\times\operatorname{Spin}(k) \right)/\mathbb{Z}_2.$$

:::

## Low-dimensional examples {#Low-dimensional_examples}

- $\operatorname{Spin}^\mathrm{c}(1) \cong\operatorname{U}(1) \cong\operatorname{SO}(2)$, induced by the isomorphism $\operatorname{Spin}(1) \cong\operatorname{O}(1) \cong\mathbb{Z}_2$
- $\operatorname{Spin}^\mathrm{c}(3) \cong\operatorname{U}(2)$,[^o9] induced by the [exceptional isomorphism](wikipedia://en/25262819) $\operatorname{Spin}(3) \cong\operatorname{Sp}(1) \cong\operatorname{SU}(2)$. Since furthermore $\operatorname{Spin}(2) \cong\operatorname{U}(1) \cong\operatorname{SO}(2)$, one also has $\operatorname{Spin}^\mathrm{c}(3) \cong\operatorname{Spin}^\mathrm{h}(2)$.
- $\operatorname{Spin}^\mathrm{c}(4) \cong\operatorname{U}(2)\times_{\operatorname{U}(1)}\operatorname{U}(2)$, induced by the exceptional isomorphism $\operatorname{Spin}(4) \cong\operatorname{SU}(2)\times\operatorname{SU}(2)$
- $\operatorname{Spin}^\mathrm{c}(6) \rightarrow\operatorname{U}(4)$ is a double cover, induced by the exceptional isomorphism $\operatorname{Spin}(6) \cong\operatorname{SU}(4)$

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

For all higher abelian [homotopy groups](wikipedia://en/297506), one has:

$$\pi_k\operatorname{Spin}^\mathrm{c}(n) \cong\pi_k\operatorname{Spin}(n)\times\pi_k\operatorname{U}(1) \cong\pi_k\operatorname{SO}(n)$$

for $k\geq 2$.

:::
