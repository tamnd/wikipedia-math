# Spinh group

::: {#o1 .subject cue=lead name="Spinh group"}

In [spin geometry](wikipedia://en/32013990), a **spin<sup>h</sup> group** (or **quaternionic spin group**) is a [Lie group](wikipedia://en/17945) obtained by the [spin group](wikipedia://en/411231) through twisting with the first [symplectic group](wikipedia://en/173977). H stands for the [quaternions](wikipedia://en/51440), which are denoted $\mathbb{H}$. An important application of spin<sup>h</sup> groups is for [spin<sup>h</sup> structures](wikipedia://en/79367918).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [spin group](wikipedia://en/411231) $\operatorname{Spin}(n)$ is a [double cover](https://en.wikipedia.org/wiki/Double_cover_%28topology%29) of the [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group) $\operatorname{SO}(n)$, hence $\mathbb{Z}_2$ acts on it with $\operatorname{Spin}(n)/\mathbb{Z}_2\cong\operatorname{SO}(n)$. Furthermore, $\mathbb{Z}_2$ also acts on the first symplectic group $\operatorname{Sp}(1)$ through the [antipodal](wikipedia://en/367577) identification $y\sim -y$. The *spin<sup>h</sup> group* is then:[^o4]

$$\operatorname{Spin}^\mathrm{h}(n) :=\left( \operatorname{Spin}(n)\times\operatorname{Sp}(1) \right)/\mathbb{Z}_2$$

mit $(x,y)\sim(-x,-y)$. It is also denoted $\operatorname{Spin}^\mathbb{H}(n)$. Using the exceptional isomorphism $\operatorname{Spin}(3) \cong\operatorname{Sp}(1)$, one also has $\operatorname{Spin}^\mathrm{h}(n) =\operatorname{Spin}^3(n)$ with:

$$\operatorname{Spin}^k(n) :=\left( \operatorname{Spin}(n)\times\operatorname{Spin}(k) \right)/\mathbb{Z}_2.$$

:::

## Low-dimensional examples {#Low-dimensional_examples}

- $\operatorname{Spin}^\mathrm{h}(1) \cong\operatorname{Sp}(1) \cong\operatorname{SU}(2)$, induced by the isomorphism $\operatorname{Spin}(1) \cong\operatorname{O}(1) \cong\mathbb{Z}_2$
- $\operatorname{Spin}^\mathrm{h}(2) \cong\operatorname{U}(2)$, induced by the [exceptional isomorphism](wikipedia://en/25262819) $\operatorname{Spin}(2) \cong\operatorname{U}(1) \cong\operatorname{SO}(2)$- Since furthermore $\operatorname{Spin}(3) \cong\operatorname{Sp}(1) \cong\operatorname{SU}(2)$, one also has $\operatorname{Spin}^\mathrm{h}(2) \cong\operatorname{Spin}^\mathrm{c}(3)$.

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

For all higher abelian [homotopy groups](wikipedia://en/297506), one has:

$$\pi_k\operatorname{Spin}^\mathrm{h}(n) \cong\pi_k\operatorname{Spin}(n)\times\pi_k\operatorname{Sp}(1) \cong\pi_k\operatorname{SO}(n)\times\pi_k(S^3)$$

for $k\geq 2$.

:::
