# Conjugate gradient squared method

::: {#o1 .subject cue=lead name="Conjugate gradient squared method"}

In [numerical linear algebra](wikipedia://en/7330660), the **conjugate gradient squared method (CGS)** is an [iterative](wikipedia://en/15237) algorithm for solving [systems of linear equations](https://en.wikipedia.org/wiki/Systems_of_linear_equations) of the form $A{\mathbf x} = {\mathbf b}$, particularly in cases where computing the [transpose](wikipedia://en/173844) $A^T$ is impractical.[^o2] The CGS method was developed as an improvement to the [biconjugate gradient method](wikipedia://en/4289501).[^o3][^o4][^o5]

:::

## Background {#Background}

A [system of linear equations](wikipedia://en/113087) $A{\mathbf x} = {\mathbf b}$ consists of a known [matrix](wikipedia://en/20556859) $A$ and a known [vector](https://en.wikipedia.org/wiki/Vector_%28mathematics%29) ${\mathbf b}$. To solve the system is to find the value of the unknown vector ${\mathbf x}$.[^o4][^o7] A direct method for solving a system of linear equations is to take the inverse of the matrix $A$, then calculate $\mathbf x = A^{-1}\mathbf b$. However, computing the inverse is computationally expensive. Hence, iterative methods are commonly used. Iterative methods begin with a guess $\mathbf x^{(0)}$, and on each iteration the guess is improved. Once the difference between successive guesses is sufficiently small, the method has converged to a solution.[^o8][^o9]

As with the [conjugate gradient method](wikipedia://en/1448821), [biconjugate gradient method](wikipedia://en/4289501), and similar iterative methods for solving systems of linear equations, the CGS method can be used to find solutions to multi-variable [optimisation problems](https://en.wikipedia.org/wiki/Optimisation_problems), such as [power-flow analysis](https://en.wikipedia.org/wiki/Power-flow_study), [hyperparameter optimisation](https://en.wikipedia.org/wiki/Hyperparameter_optimisation), and [facial recognition](https://en.wikipedia.org/wiki/Facial_recognition_system).[^o10]

::: {#o12 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

The algorithm is as follows:[^o13]

1. Choose an initial guess ${\mathbf x}^{(0)}$
1. Compute the residual ${\mathbf r}^{(0)} = {\mathbf b} - A{\mathbf x}^{(0)}$
1. Choose $\tilde {\mathbf r} = {\mathbf r}^{(0)}$
1. For $i = 1, 2, 3, \dots$ do:
   1. $$\rho^{(i-1)} = \tilde {\mathbf r}^{T}{\mathbf r}^{(i-1)}$$
   1. If $\rho^{(i-1)} = 0$, the method fails.
   1. If $i=1$:
      1. $${\mathbf p}^{(1)} = {\mathbf u}^{(1)} = {\mathbf r}^{(0)}$$
   1. Else:
      1. $$\beta^{(i-1)} = \rho^{(i-1)}/\rho^{(i-2)}$$
      1. $${\mathbf u}^{(i)} = {\mathbf r}^{(i-1)} + \beta_{i-1}{\mathbf q}^{(i-1)}$$
      1. $${\mathbf p}^{(i)} = {\mathbf u}^{(i)} + \beta^{(i-1)}({\mathbf q}^{(i-1)} + \beta^{(i-1)}{\mathbf p}^{(i-1)})$$
   1. Solve $M\hat {\mathbf p}={\mathbf p}^{(i)}$, where $M$ is a pre-conditioner.
   1. $$\hat {\mathbf v} = A\hat {\mathbf p}$$
   1. $$\alpha^{(i)} = \rho^{(i-1)} / \tilde {\mathbf r}^T \hat {\mathbf v}$$
   1. $${\mathbf q}^{(i)} = {\mathbf u}^{(i)} - \alpha^{(i)}\hat {\mathbf v}$$
   1. Solve $M\hat {\mathbf u} = {\mathbf u}^{(i)} + {\mathbf q}^{(i)}$
   1. $${\mathbf x}^{(i)} = {\mathbf x}^{(i-1)} + \alpha^{(i)} \hat {\mathbf u}$$
   1. $$\hat {\mathbf q} = A\hat {\mathbf u}$$
   1. $${\mathbf r}^{(i)} = {\mathbf r}^{(i-1)} - \alpha^{(i)}\hat {\mathbf q}$$
   1. Check for convergence: if there is convergence, end the loop and return the result

:::
