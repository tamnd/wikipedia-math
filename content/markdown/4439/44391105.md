# Pisier–Ringrose inequality

::: {#o1 .subject cue=lead name="Pisier–Ringrose inequality"}

In [mathematics](wikipedia://en/18831), **Pisier–Ringrose inequality** is an inequality in the theory of C\*-algebras which was proved by [Gilles Pisier](wikipedia://en/26438577) in 1978 affirming a conjecture of [John Ringrose](https://en.wikipedia.org/wiki/John_Ringrose). It is an extension of the [Grothendieck inequality](wikipedia://en/9395279).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

::: {#o4 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem**.[^o5][^o6] If $\gamma$ is a bounded, linear mapping of one C\*-algebra $\mathfrak{A}$ into another C\*-algebra $\mathfrak{B}$, then

$$\left\|\sum_{j=1}^n \gamma(A_j)^* \gamma(A_j) + \gamma(A_j) \gamma(A_j)^*\right\| \le 4 \|\gamma \|^2 \left\| \sum_{j=1}^n A_j^*A_j + A_j A_j^* \right\|$$

for each finite set $\{ A_1, A_2, \ldots, A_n \}$ of elements $A_j$ of $\mathfrak{A}$.

:::
