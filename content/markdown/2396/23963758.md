# Shrewd cardinal

::: {#o1 .subject cue=lead name="Shrewd cardinal"}

In [mathematics](wikipedia://en/18831), a **shrewd cardinal** is a certain kind of [large cardinal](wikipedia://en/383644) number introduced by (Rathjen 1995), extending the definition of [indescribable cardinals](wikipedia://en/248097).

:::

For an [ordinal](wikipedia://en/26547932) λ, a [cardinal number](wikipedia://en/6173) κ is called λ-shrewd if for every [proposition](https://en.wikipedia.org/wiki/Proposition_%28mathematics%29) φ using a predicate symbol and with one free variable, and set A ⊆ V<sub>κ</sub> with (V<sub>κ+λ</sub>, ∈, A) ⊧ φ(κ) there exists an α, λ' \< κ with (V<sub>α+λ'</sub>, ∈, A ∩ V<sub>α</sub>) ⊧ φ(α). It is called shrewd if it is λ-shrewd for every λ[^o3]<sup>(Definition 4.1)</sup> (including λ > κ).

This definition extends the concept of [indescribability](https://en.wikipedia.org/wiki/Totally_indescribable_cardinal) to transfinite levels. A λ-shrewd cardinal is also μ-shrewd for any ordinal μ \< λ.[^o3]<sup>(Corollary 4.3)</sup> Shrewdness was developed by [Michael Rathjen](https://en.wikipedia.org/wiki/Michael_Rathjen) as part of his [ordinal analysis](wikipedia://en/16084282) of [Π<sup>1</sup><sub>2</sub>-comprehension](wikipedia://en/3542454). It is essentially the nonrecursive analog to the [stability](https://en.wikipedia.org/wiki/Stable_ordinal) property for [admissible ordinals](wikipedia://en/4635859).

More generally, a cardinal number κ is called λ-Π<sub>m</sub>-shrewd if for every Π<sub>m</sub> proposition φ, and set A ⊆ V<sub>κ</sub> with (V<sub>κ+λ</sub>, ∈, A) ⊧ φ(κ) there exists an α, λ' \< κ with (V<sub>α+λ'</sub>, ∈, A ∩ V<sub>α</sub>) ⊧ φ(α).[^o3]<sup>(Definition 4.1)</sup> Π<sub>m</sub> is one of the levels of the [Lévy hierarchy](wikipedia://en/25129404), in short one looks at formulas with m-1 alternations of [quantifiers](wikipedia://en/43507282) with the outermost quantifier being universal.

For finite *n*, an *n*-Π<sub>m</sub>-shrewd cardinals is the same thing as a Π<sub>m</sub><sup>n</sup>-indescribable cardinal.

If κ is a [subtle cardinal](wikipedia://en/326550), then the set of κ-shrewd cardinals is [stationary](wikipedia://en/1679067) in κ.[^o3]<sup>(Lemma 4.6)</sup> A cardinal is [strongly unfoldable](wikipedia://en/853783) iff it is shrewd.[^o4]

λ-shrewdness is an improved version of λ-indescribability, as defined in Drake; this cardinal property differs in that the reflected substructure must be (V<sub>α+λ</sub>, ∈, A ∩ V<sub>α</sub>), making it impossible for a cardinal κ to be κ-indescribable. Also, the monotonicity property is lost: a λ-indescribable cardinal may fail to be α-indescribable for some ordinal α \< λ.
