# Saturated set (intersection of open sets)

::: {#o1 .subject cue=lead name="Saturated set"}

In [general topology](wikipedia://en/178649), a **saturated set** is a subset of a [topological space](wikipedia://en/30450) equal to an [intersection](wikipedia://en/23476429) of (an arbitrary number of) [open sets](wikipedia://en/39358).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $S$ be a subset of a [topological space](wikipedia://en/30450) $X$. The **saturation** $\operatorname{sat}(S)$ of $S$ is the intersection of all the [neighborhoods](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of $S$.[^o12]

$$\operatorname{sat}(S)=\bigcap\mathcal N_S$$

Here $\mathcal N_S$ denotes the [neighborhood filter](https://en.wikipedia.org/wiki/Neighborhood_filter) of $S$. The neighborhood filter $\mathcal N_S$ can be replaced by any [local basis](https://en.wikipedia.org/wiki/Local_basis) of $S$. In particular, $\operatorname{sat}(S)$ is the intersection of all open sets containing $S$.

Let $S$ be a subset of a [topological space](wikipedia://en/30450) $X$. Then the following conditions are equivalent.

- $S$ is the intersection of a set of open sets of $X$.
- $S$ equals its own saturation.

We say that $S$ is **saturated** if it satisfies the above equivalent conditions.[^o12][^o4] We say that $S$ is **recurrent** if it intersects every non-empty saturated set of $X$.[^o12]

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Implications {#Implications}

Every [G<sub>δ</sub> set](wikipedia://en/252076) is saturated, obvious by definition. Every recurrent set is [dense](wikipedia://en/23523594), also obvious by definition.

### In relation to compactness {#In_relation_to_compactness}

A subset of a [topological space](wikipedia://en/30450) is [compact](https://en.wikipedia.org/wiki/Compact_set) if and only if its saturation is compact.

For a topological space $X$, the following are equivalent.

- Every point $x\in X$ has a compact [local basis](https://en.wikipedia.org/wiki/Local_basis). (This is one of several definitions of [locally compact spaces](wikipedia://en/48632).)
- Every point $x\in X$ has a compact saturated local basis.

In a [sober space](wikipedia://en/602490), the intersection of a [downward-directed set](https://en.wikipedia.org/wiki/Downward-directed_set) of compact saturated sets is again compact and saturated.[^o12] This is a sober variant of the [Cantor intersection theorem](https://en.wikipedia.org/wiki/Cantor_intersection_theorem).

### In relation to Baire spaces {#In_relation_to_Baire_spaces}

For a [topological space](wikipedia://en/30450) $X$, the following are equivalent.

- $X$ is a [Baire space](wikipedia://en/200550).
- Every recurrent set of $X$ is Baire.
- $X$ has a Baire recurrent set.

:::

## Examples {#Examples}

For a [topological space](wikipedia://en/30450) $X$, the following are equivalent.

- Every subset of $X$ is saturated.
- The only recurrent set of $X$ is $X$ itself.
- $X$ is a [T<sub>1</sub> space](wikipedia://en/148721).

A subset $S$ of a [preordered set](https://en.wikipedia.org/wiki/Preordered_set) $(X,\lesssim)$ is saturated with respect to the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology) if and only if it is [upward-closed](https://en.wikipedia.org/wiki/Upward-closed_set).[^o12]

Let $(X,\lesssim)$ be a [closed preordered set](wikipedia://en/80469624) (one in which every [chain](https://en.wikipedia.org/wiki/Chain_%28order_theory%29) has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound)). Let $\max X$ be the set of [maximal elements](https://en.wikipedia.org/wiki/Maximal_element) of $X$. By the [Zorn lemma](https://en.wikipedia.org/wiki/Zorn_lemma), $\max X$ is a recurrent set of $X$ with the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology).[^o12]
