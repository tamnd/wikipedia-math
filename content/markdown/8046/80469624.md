# Closed preordered set

::: {#o1 .subject cue=lead name="Closed preordered set"}

In [mathematics](wikipedia://en/18831), a **closed preordered set** is one whose anti-[well-ordered](wikipedia://en/33456) subsets have [lower bounds](https://en.wikipedia.org/wiki/Lower_bound).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\kappa$ be a cardinal. A [preordered set](https://en.wikipedia.org/wiki/Preordered_set) $(P,\lesssim)$ is called **$\kappa$-closed** if every subset of $P$ whose [opposite](wikipedia://en/3941020) is well-ordered with order-type less than $\kappa$ has a lower bound.[^o9][^o4][^o5]

A preordered set is **${<}\kappa$-closed** if it is $\lambda$-closed for every $\lambda<\kappa$. A preordered set is called **closed** or **${<}{\operatorname{Ord}}$-closed** if it is $\kappa$-closed for every $\kappa$.[^o6]

A preordered set is **inductive** if every [chain](https://en.wikipedia.org/wiki/Chain_%28order_theory%29) has an upper bound. Since every totally ordered set has a well-ordered [cofinal subset](https://en.wikipedia.org/wiki/Cofinal_subset), this is equivalent to saying that the preordered set is the opposite of a closed preordered set.

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Inductive preordered sets satisfy [Zorn's lemma](wikipedia://en/51442) and the [Bourbaki–Witt theorem](wikipedia://en/1011270).

A $\kappa$-closed [forcing](wikipedia://en/152205) preserves cofinalities less than or equal to $\kappa$, hence cardinals less than or equal to $\kappa$.[^o9]

:::
