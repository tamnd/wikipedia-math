# Embedding problem

::: {#o1 .subject cue=lead name="Embedding problem"}

In [Galois theory](wikipedia://en/61316), a branch of [mathematics](wikipedia://en/18831), the **embedding problem** is a generalization of the [inverse Galois problem](wikipedia://en/739166). Roughly speaking, it asks whether a given [Galois extension](wikipedia://en/457064) can be embedded into a Galois extension in such a way that the [restriction map](wikipedia://en/1589032) between the corresponding [Galois groups](wikipedia://en/12673) is given.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a [field](wikipedia://en/10603) *K* and a finite [group](wikipedia://en/19447) *H*, one may pose the following question (the so called [inverse Galois problem](wikipedia://en/739166)). Is there a Galois extension *F/K* with Galois group isomorphic to *H*. The embedding problem is a generalization of this problem:

Let *L/K* be a Galois extension with Galois group *G* and let *f* : *H* → *G* be an epimorphism. Is there a Galois extension *F/K* with Galois group *H* and an embedding *α* : *L* → *F* fixing *K* under which the restriction map from the Galois group of *F/K* to the Galois group of *L/K* coincides with *f*?

Analogously, an embedding problem for a [profinite group](wikipedia://en/24266) *F* consists of the following data: Two profinite groups *H* and *G* and two continuous epimorphisms *φ* : *F* → *G* and *f* : *H* → *G*. The embedding problem is said to be **finite** if the group *H* is. A **solution** (sometimes also called weak solution) of such an embedding problem is a continuous homomorphism *γ* : *F* → *H* such that *φ* = *f* *γ*. If the solution is surjective, it is called a **proper solution**.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Finite embedding problems characterize profinite groups. The following theorem gives an illustration for this principle.

::: {#o6 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Let *F* be a [countably](https://en.wikipedia.org/wiki/Countably) (topologically) generated profinite group. Then

1. *F* is [projective](https://en.wikipedia.org/wiki/Projective_profinite_group) if and only if any finite embedding problem for *F* is solvable.
1. *F* is free of countable rank if and only if any finite embedding problem for *F* is properly solvable.

:::
