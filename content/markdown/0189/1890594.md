# Simple function

::: {#o1 .subject cue=lead name="Simple function"}

In the [mathematical](wikipedia://en/18831) field of [real analysis](wikipedia://en/26478), a **simple function** is a [real](wikipedia://en/20646438) (or [complex](wikipedia://en/5826))-valued function over a subset of the [real line](https://en.wikipedia.org/wiki/Real_line), similar to a [step function](wikipedia://en/170939). Simple functions are sufficiently "nice" that using them makes mathematical reasoning, theory, and proof easier. For example, simple functions attain only a finite number of values. Some authors also require simple functions to be [measurable](wikipedia://en/44055), as used in practice.

:::

A basic example of a simple function is the [floor function](https://en.wikipedia.org/wiki/Floor_function) over the half-open interval \[1, 9), whose only values are {1, 2, 3, 4, 5, 6, 7, 8}. A more advanced example is the [Dirichlet function](wikipedia://en/630005) over the real line, which takes the value 1 if *x* is rational and 0 otherwise. (Thus the "simple" of "simple function" has a technical meaning somewhat at odds with common language.) All [step functions](wikipedia://en/170939) are simple.

Simple functions are used as a first stage in the development of theories of [integration](wikipedia://en/15532), such as the [Lebesgue integral](wikipedia://en/26064288), because it is easy to define integration for a simple function and also it is straightforward to approximate more general functions by sequences of simple functions.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, a simple function is a finite [linear combination](wikipedia://en/55632) of [indicator functions](wikipedia://en/240790) of [measurable sets](https://en.wikipedia.org/wiki/Measurable_set). More precisely, let (*X*, Σ) be a [measurable space](https://en.wikipedia.org/wiki/Sigma-algebra). Let *A*<sub>1</sub>, ..., *A*<sub>*n*</sub> ∈ Σ be a [sequence](wikipedia://en/27838) of disjoint measurable sets, and let *a*<sub>1</sub>, ..., *a*<sub>*n*</sub> be a sequence of [real](wikipedia://en/20646438) or [complex numbers](wikipedia://en/5826). A *simple function* is a function $f\colon X \to \mathbb{C}$ of the form

$$f(x)=\sum_{k=1}^n a_k {\mathbf 1}_{A_k}(x),$$

where ${\mathbf 1}_A$ is the [indicator function](wikipedia://en/240790) of the set *A*.

:::

## Properties of simple functions {#Properties_of_simple_functions}

The sum, difference, and product of two simple functions are again simple functions, and multiplication by constant keeps a simple function simple; hence it follows that the collection of all simple functions on a given measurable space forms a [commutative algebra](wikipedia://en/191788) over $\mathbb{C}$.

## Integration of simple functions {#Integration_of_simple_functions}

If a [measure](wikipedia://en/19873) $\mu$ is defined on the space $(X, \Sigma)$, the [integral](wikipedia://en/26064288) of a simple function $f\colon X \to \mathbb R$ with respect to $\mu$ is defined to be

$$\int_X f d \mu = \sum_{k=1}^na_k\mu(A_k),$$

if all summands are finite.

## Relation to Lebesgue integration {#Relation_to_Lebesgue_integration}

The above integral of simple functions can be extended to a more general class of functions, which is how the [Lebesgue integral](wikipedia://en/26064288) is defined. This extension is based on the following fact.

**Theorem**. Any non-negative [measurable function](wikipedia://en/44055) $f\colon X \to\mathbb{R}^{+}$ is the [pointwise](wikipedia://en/4786797) limit of a monotonic increasing sequence of non-negative simple functions.

It is implied in the statement that the sigma-algebra in the co-domain $\mathbb{R}^{+}$ is the restriction of the [Borel σ-algebra](https://en.wikipedia.org/wiki/Borel_σ-algebra) $\mathfrak{B}(\mathbb{R})$ to $\mathbb{R}^{+}$. The proof proceeds as follows. Let $f$ be a non-negative measurable function defined over the measure space $(X, \Sigma,\mu)$. For each $n\in\mathbb N$, subdivide the co-domain of $f$ into $2^{2n}+1$ intervals, $2^{2n}$ of which have length $2^{-n}$. That is, for each $n$, define

$I_{n,k}=\left[\frac{k-1}{2^n},\frac{k}{2^n}\right)$ for $k=1,2,\ldots,2^{2n}$, and $I_{n,2^{2n}+1}=[2^n,\infty)$,

which are disjoint and cover the non-negative real line ($\mathbb{R}^{+} \subseteq \cup_{k}I_{n,k}, \forall n \in \mathbb{N}$).

Now define the sets

$A_{n,k}=f^{-1}(I_{n,k}) \,$ for $k=1,2,\ldots,2^{2n}+1,$

which are measurable ($A_{n,k}\in \Sigma$) because $f$ is assumed to be measurable.

Then the increasing sequence of simple functions

$$f_n=\sum_{k=1}^{2^{2n}+1}\frac{k-1}{2^n}{\mathbf 1}_{A_{n,k}}$$

converges pointwise to $f$ as $n\to\infty$. Note that, when $f$ is bounded, the convergence is uniform.
