# Sperner property of a partially ordered set

::: {#o1 .subject cue=lead name="Sperner property of a partially ordered set"}

In [order-theoretic mathematics](wikipedia://en/361924), a [graded](wikipedia://en/2514970) [partially ordered set](wikipedia://en/23572) is said to have the **Sperner property** (and hence is called a **Sperner poset**), if no [antichain](wikipedia://en/348973) within it is larger than the largest rank level (one of the sets of elements of the same rank) in the poset.[^o2] Since every rank level is itself an antichain, the Sperner property is equivalently the property that some rank level is a maximum antichain.[^o3] The Sperner property and Sperner posets are named after [Emanuel Sperner](wikipedia://en/374404), who proved [Sperner's theorem](wikipedia://en/748844) stating that the [family of all subsets](https://en.wikipedia.org/wiki/Powerset) of a finite set (partially ordered by set inclusion) has this property. The lattice of partitions of a finite set typically lacks the Sperner property.[^o4]

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

The Boolean lattice formed by all subsets of an n-element set, ordered by inclusion, satisfies the Sperner property, as shown by Sperner's theorem.

:::

::: {#o8 .statement kind=statement/generalization cue=heading name="Variations"}

## Variations {#Variations}

A ***k*-Sperner poset** is a graded poset in which no union of *k* antichains is larger than the union of the *k* largest rank levels,[^o2] or, equivalently, the poset has a maximum [k-family](https://en.wikipedia.org/wiki/K-family) consisting of *k* rank levels.[^o3]

A **strict Sperner poset** is a graded poset in which all maximum antichains are rank levels.[^o3]

A **strongly Sperner poset** is a graded poset which is *k-Sperner* for all values of *k* up to the largest rank value.[^o3]

:::
