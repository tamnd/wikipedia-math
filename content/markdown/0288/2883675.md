# Chow test

::: {#o1 .subject cue=lead name="Chow test"}

The **Chow test** (), proposed by [econometrician](wikipedia://en/10390) [Gregory Chow](https://en.wikipedia.org/wiki/Gregory_Chow) in 1960, is a [statistical test](https://en.wikipedia.org/wiki/Statistical_test) of whether the true coefficients in two [linear regressions](wikipedia://en/48758386) on different data sets are equal. In econometrics, it is most commonly used in [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis) to test for the presence of a [structural break](wikipedia://en/14528980) at a period which can be assumed to be known *a priori* (for instance, a major historical event such as a war). In [program evaluation](https://en.wikipedia.org/wiki/Program_evaluation), the Chow test is often used to determine whether the independent variables have different impacts on different subgroups of the population.

:::

## First Chow Test {#First_Chow_Test}

Suppose that we model our data as

$$y_t=a+bx_{1t} + cx_{2t} + \varepsilon.\,$$

If we split our data into two groups, then we have

$$y_t=a_1+b_1x_{1t} + c_1x_{2t} + \varepsilon \,$$

and

$$y_t=a_2+b_2x_{1t} + c_2x_{2t} + \varepsilon. \,$$

The [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) of the Chow test asserts that $a_1=a_2$, $b_1=b_2$, and $c_1=c_2$, and there is the assumption that the [model errors](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) $\varepsilon$ are [independent and identically distributed](https://en.wikipedia.org/wiki/Independent_and_identically_distributed) from a [normal distribution](wikipedia://en/21462) with unknown [variance](wikipedia://en/32344).

Let $S_C$ be the sum of squared [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) from the combined data, $S_1$ be the sum of squared residuals from the first group, and $S_2$ be the sum of squared residuals from the second group. $N_1$ and $N_2$ are the number of observations in each group and $k$ is the total number of parameters (in this case 3, i.e. 2 independent variables coefficients + intercept). Then the Chow [test statistic](wikipedia://en/1416975) is

$$\frac{(S_C -(S_1+S_2))/k}{(S_1+S_2)/(N_1+N_2-2k)}.$$

The test statistic follows the [*F*-distribution](wikipedia://en/332116) with $k$ and $N_1+N_2-2k$ [degrees of freedom](wikipedia://en/2321606).

The same result can be achieved via dummy variables.

Consider the two data sets which are being compared. Firstly there is the 'primary' [data set](wikipedia://en/8495) i={1,...,$n_1$} and the 'secondary' data set i={$n_1$+1,...,n}. Then there is the union of these two sets: i={1,...,n}. If there is no structural change between the primary and secondary data sets a regression can be run over the union without the issue of biased estimators arising.

Consider the regression:

$$y_t=\beta_0+\beta_1x_{1t} + \beta_2x_{2t} + ... + \beta_kx_{kt} + \gamma_0D_t + \sum_{i=1}^k\gamma_ix_{it}D_t + \varepsilon_t.\,$$

Which is run over i={1,...,n}.

D is a dummy variable taking a value of 1 for i={$n_1$+1,...,n} and 0 otherwise.

If both data sets can be explained fully by $(\beta_0,\beta_1,...,\beta_k)$ then there is no use in the dummy variable as the data set is explained fully by the restricted equation. That is, under the assumption of no structural change we have a null and alternative hypothesis of:

$$H_0: \gamma_0=0,\gamma_1=0,...,\gamma_k=0$$

$$H_1: \text{otherwise}$$

The null hypothesis of joint insignificance of D can be run as an [F-test](wikipedia://en/318976) with $n-2(k+1)$ degrees of freedom (DoF). That is: $F=\frac{(RSS^R-RSS^U)/(k+1)}{RSS^U/DoF}$.

**Remarks**

- The global sum of squares (SSE) is often called the Restricted Sum of Squares (RSSM) as we basically test a constrained model where we have $2k$ assumptions (with $k$ the number of regressors).
- Some software like SAS will use a predictive Chow test when the size of a subsample is less than the number of regressors.
