# Parametric model

::: {#o1 .subject cue=lead name="Parametric model"}

In [statistics](wikipedia://en/26685), a **parametric model** or **parametric family** or **finite-dimensional model** is a particular class of [statistical models](wikipedia://en/27576). Specifically, a parametric model is a family of [probability distributions](wikipedia://en/23543) that has a finite number of [parameters](https://en.wikipedia.org/wiki/Parameter_%28statistics%29).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [statistical model](wikipedia://en/27576) is a collection of [probability distributions](wikipedia://en/23543) on some [sample space](wikipedia://en/22958). We assume that the collection, $\mathcal{P}$, is indexed by some set $\Theta$. The set $\Theta$ is called the **parameter set** or, more commonly, the **[parameter space](wikipedia://en/2882813)**. For each $\theta \in \Theta$, let $F_{\theta}$ denote the corresponding member of the collection; so $F_{\theta}$ is a [cumulative distribution function](wikipedia://en/5793). Then a statistical model can be written as

$$\mathcal{P} = \big\{ F_\theta\ \big|\ \theta\in\Theta \big\}.$$

The model is a **parametric model** if $\Theta \subseteq \mathbb{R}^{k}$ for some positive integer $k$.

When the model consists of absolutely continuous distributions, it is often specified in terms of corresponding [probability density functions](wikipedia://en/43487):

$$\mathcal{P} = \big\{ f_\theta\ \big|\ \theta\in\Theta \big\}.$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [Poisson family](wikipedia://en/23009144) of distributions is parametrized by a single number $\lambda > 0$:

$$\mathcal{P} = \Big\{\ p_\lambda(j) = \tfrac{\lambda^j}{j!}e^{-\lambda},\ j=0,1,2,3,\dots \ \Big|\;\; \lambda>0 \ \Big\},$$

where $p_{\lambda}$ is the [probability mass function](wikipedia://en/154725). This family is an [exponential family](wikipedia://en/339174).

- The [normal family](wikipedia://en/21462) is parametrized by $\theta = (\mu, \sigma)$, where $\mu \in \mathbb{R}$ is a location parameter and $\sigma > 0$ is a scale parameter:

$$\mathcal{P} = \Big\{\ f_\theta(x) = \tfrac{1}{\sqrt{2\pi}\sigma} \exp\left(-\tfrac{(x-\mu)^2}{2\sigma^2}\right)\ \Big|\;\; \mu\in\mathbb{R}, \sigma>0 \ \Big\}.$$

This [parametrized family](wikipedia://en/19653337) is both an [exponential family](wikipedia://en/339174) and a [location-scale family](https://en.wikipedia.org/wiki/Location-scale_family).

- The [Weibull translation model](wikipedia://en/206948) has a three-dimensional parameter $\theta = (\lambda, \beta, \mu)$:

$$\mathcal{P} = \Big\{\ f_\theta(x) = \tfrac{\beta}{\lambda} \left(\tfrac{x-\mu}{\lambda}\right)^{\beta-1}\! \exp\!\big(\!-\!\big(\tfrac{x-\mu}{\lambda}\big)^\beta \big)\, \mathbf{1}_{\{x>\mu\}} \ \Big|\;\; \lambda>0,\, \beta>0,\, \mu\in\mathbb{R} \ \Big\},$$

where $\beta$ is the [shape parameter](wikipedia://en/9210865), $\lambda$ is the [scale parameter](wikipedia://en/769503) and $\mu$ is the [location parameter](wikipedia://en/17516).

- The [binomial model](wikipedia://en/3876) is parametrized by $\theta = (n, p)$, where $n$ is a non-negative integer and $p$ is a probability (i.e. $p \ge 0$ and $p \le 1$):

$$\mathcal{P} = \Big\{\ p_\theta(k) = \tfrac{n!}{k!(n-k)!}\, p^k (1-p)^{n-k},\ k=0,1,2,\dots, n \ \Big|\;\; n\in\mathbb{Z}_{\ge 0},\, p \ge 0 \land p \le 1\Big\}.$$

This example illustrates the definition for a model with some discrete parameters.

:::

## General remarks {#General_remarks}

A parametric model is called [identifiable](https://en.wikipedia.org/wiki/Identifiable) if the mapping $\theta \mapsto P_{\theta}$ is invertible, i.e. there are no two different parameter values $\theta_{1}$ and $\theta_{2}$ such that $P_{\theta_{1}} = P_{\theta_{2}}$.

## Comparisons with other classes of models {#Comparisons_with_other_classes_of_models}

[Parametric models](wikipedia://en/223366) are contrasted with the [semi-parametric](wikipedia://en/4415208), [semi-nonparametric](https://en.wikipedia.org/wiki/Semi-nonparametric_model), and [non-parametric models](https://en.wikipedia.org/wiki/Non-parametric_model), all of which consist of an infinite set of "parameters" for description. The distinction between these four classes is as follows:

- in a "*[parametric](wikipedia://en/223366)*" model all the parameters are in finite-dimensional parameter spaces;
- a model is "*[non-parametric](wikipedia://en/223369)*" if all the parameters are in infinite-dimensional parameter spaces;
- a "*semi-parametric*" model contains finite-dimensional parameters of interest and infinite-dimensional [nuisance parameters](wikipedia://en/979528);
- a "*semi-nonparametric*" model has both finite-dimensional and infinite-dimensional unknown parameters of interest.

Some statisticians believe that the concepts "parametric", "non-parametric", and "semi-parametric" are ambiguous.[^o8] It can also be noted that the set of all probability measures has a [cardinality](wikipedia://en/6174) of the [continuum](wikipedia://en/24758677), and therefore it is possible to parametrize any model at all by a single number in the (0,1) interval.[^o9] This difficulty can be avoided by considering only "smooth" parametric models.
