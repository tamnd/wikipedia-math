# Aperiodic set of prototiles

*Image: Fund un prim cell.svg.* Click "show" for description.

*Image: Penrose Rhombi BR.svg.* The [Penrose tiles](https://en.wikipedia.org/wiki/Penrose_tiles) are an aperiodic set of tiles, since they admit only *non-periodic* tilings of the plane (see next image).

*Image: Penrose tiling.svg.* All of the infinitely many tilings by the Penrose tiles are [aperiodic](wikipedia://en/868145). That is, the Penrose tiles are an aperiodic set of prototiles.

::: {#o1 .subject cue=lead name="Aperiodic set of prototiles"}

A set of [prototiles](wikipedia://en/39372) is [aperiodic](wikipedia://en/868145) if copies of the prototiles can be assembled to create [tilings](wikipedia://en/321671), such that all possible tessellation patterns are non-[periodic](https://en.wikipedia.org/wiki/Periodic_tiling). The *aperiodicity* referred to is a property of the particular set of prototiles; the various resulting tilings themselves are just non-periodic.

:::

A given set of tiles, in the [Euclidean plane](wikipedia://en/15575410) or some other geometric setting, *admits a tiling* if non-overlapping copies of the tiles in the set can be fitted together to cover the entire space. A given set of tiles might admit periodic tilings — that is, tilings that remain invariant after being shifted by a [translation](wikipedia://en/204682) (for example, a lattice of square tiles is periodic). It is not difficult to design a set of tiles that admits non-periodic tilings as well as periodic tilings. (For example, randomly arranged tilings using a 2×2 square and 2×1 rectangle are typically non-periodic.)

However, an **aperiodic set of tiles** can *only* produce non-periodic tilings.[^o2][^o3] Infinitely many distinct tilings may be obtained from a single aperiodic set of tiles.[^o4]

The best-known examples of an aperiodic set of tiles are the various [Penrose tiles](https://en.wikipedia.org/wiki/Penrose_tiles).[^o5][^o6] The known aperiodic sets of prototiles are seen on the [list of aperiodic sets of tiles](wikipedia://en/28157642). The underlying [undecidability](wikipedia://en/15631055) of the [domino problem](https://en.wikipedia.org/wiki/Domino_problem) implies that there exists no systematic [procedure](https://en.wikipedia.org/wiki/Effective_procedure) for deciding whether a given set of tiles can tile the plane.

## History {#History}

[Polygons](wikipedia://en/23621) are [plane](wikipedia://en/19469852) [figures](wikipedia://en/169191) bounded by straight [line segments](wikipedia://en/22634860). [Regular polygons](wikipedia://en/333306) have [all sides of equal length](wikipedia://en/214547) as well as [all angles of equal measure](wikipedia://en/2476494). As early as AD 325, [Pappus of Alexandria](wikipedia://en/509300) knew that only 3 types of regular polygons (the square, equilateral triangle, and hexagon) can fit perfectly together in repeating [tessellations](wikipedia://en/321671) on a [Euclidean plane](wikipedia://en/15575410). Within that plane, every triangle, irrespective of regularity, will tessellate. In contrast, regular pentagons do not tessellate. However, irregular pentagons, with different sides and angles can tessellate. There are 15 irregular convex pentagons that tile the plane.[^o8]

[Polyhedra](https://en.wikipedia.org/wiki/Polyhedra) are the [three dimensional](wikipedia://en/3054853) correlates of polygons. They are built from [flat faces](wikipedia://en/149926) and [straight edges](wikipedia://en/12158034) and have sharp corner turns at the [vertices](wikipedia://en/11308417). Although a cube is the only regular polyhedron that admits of tessellation, many non-regular 3-dimensional shapes can tessellate, such as the [truncated octahedron](wikipedia://en/279654).

The second part of [Hilbert's eighteenth problem](wikipedia://en/2336224) asked for a single polyhedron tiling [Euclidean 3-space](wikipedia://en/3054853), such that no tiling by it is [isohedral](https://en.wikipedia.org/wiki/Isohedral) (an [anisohedral](wikipedia://en/13180391) tile). The problem as stated was solved by [Karl Reinhardt](wikipedia://en/35727144) in 1928, but sets of aperiodic tiles have been considered as a natural extension.[^o9] The specific question of aperiodic sets of tiles first arose in 1961, when logician [Hao Wang](wikipedia://en/1056047) tried to determine whether the [Domino Problem](https://en.wikipedia.org/wiki/Domino_Problem) is decidable — that is, whether there exists an algorithm for deciding if a given finite set of prototiles admits a tiling of the plane. Wang found algorithms to enumerate the tilesets that cannot tile the plane, and the tilesets that tile it periodically; by this he showed that such a decision algorithm exists if every finite set of prototiles that admits a tiling of the plane also admits a periodic tiling.

*Image: Wang tiles.svg.* These [Wang tiles](wikipedia://en/65798) yield only non-periodic tilings of the plane, and so are aperiodic.

Hence, when in 1966 [Robert Berger](wikipedia://en/2012183) found an aperiodic set of prototiles this demonstrated that the tiling problem is in fact not decidable.[^o10] (Thus Wang's procedures do not work on all tile sets, although that does not render them useless for practical purposes.) This first such set, used by Berger in his proof of undecidability, required 20,426 Wang tiles. Berger later reduced his set to 104, and [Hans Läuchli](https://en.wikipedia.org/wiki/Hans_Läuchli) subsequently found an aperiodic set requiring only 40 Wang tiles.[^o11] The set of 13 tiles given in the illustration on the right is an aperiodic set published by [Karel Culik](https://en.wikipedia.org/wiki/Karel_Culik), II, in 1996.

However, a smaller aperiodic set, of six non-Wang tiles, was discovered by [Raphael M. Robinson](wikipedia://en/693495) in 1971.[^o12] [Roger Penrose](wikipedia://en/26193) discovered three more sets in 1973 and 1974, reducing the number of tiles needed to two, and [Robert Ammann](wikipedia://en/1505379) discovered several new sets in 1977. The question of whether an aperiodic set exists with only a single prototile is known as the [einstein problem](wikipedia://en/43542926), and was solved by amateur mathematician [David Smith](https://en.wikipedia.org/wiki/David_Smith_%28amateur_mathematician%29) in 2022.

## Constructions {#Constructions}

There are few constructions of aperiodic tilings known, even forty years after Berger's groundbreaking construction. Some constructions are of infinite families of aperiodic sets of tiles.[^o15][^o16] Those constructions that have been found are mostly constructed in one of a few ways—primarily by forcing some sort of non-periodic hierarchical structure. Despite this, the [undecidability](wikipedia://en/15631055) of the [Domino Problem](https://en.wikipedia.org/wiki/Domino_Problem) ensures that there must be infinitely many distinct principles of construction, and that in fact, there exist aperiodic sets of tiles for which there can be no proof of their aperiodicity.

There can be no aperiodic set of tiles in one dimension: it is a simple exercise to show that any set of tiles in the line either cannot be used to form a complete tiling, or can be used to form a periodic tiling. Aperiodicity of prototiles requires two or more dimensions.
