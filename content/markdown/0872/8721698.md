# Resolvent set

::: {#o1 .subject cue=lead name="Resolvent set"}

In [linear algebra](wikipedia://en/18422) and [operator theory](wikipedia://en/712675), the **resolvent set** of a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) is a [set](wikipedia://en/26691) of [complex numbers](wikipedia://en/5826) for which the operator is in some sense "[well-behaved](wikipedia://en/372742#Well-behaved)". The resolvent set plays an important role in the [resolvent formalism](wikipedia://en/3378540).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let *X* be a [Banach space](wikipedia://en/3989) and let $L\colon D(L)\rightarrow X$ be a linear operator with [domain](wikipedia://en/50263) $D(L) \subseteq X$. Let id denote the [identity operator](wikipedia://en/15069) on *X*. For any $\lambda \in \mathbb{C}$, let

$$L_{\lambda} = L - \lambda\,\mathrm{id}.$$

A complex number $\lambda$ is said to be a **regular value** if the following three statements are true:

1. $L_\lambda$ is [injective](https://en.wikipedia.org/wiki/Injective), that is, the corestriction of $L_\lambda$ to its image has an [inverse](wikipedia://en/14907) $R(\lambda, L)=(L-\lambda \,\mathrm{id})^{-1}$ called the **resolvent**;[^n1]
1. $R(\lambda,L)$ is a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator);
1. $R(\lambda,L)$ is defined on a [dense](wikipedia://en/23523594) [subspace](wikipedia://en/56357) of *X*, that is, $L_\lambda$ has dense range.

The **resolvent set** of *L* is the set of all regular values of *L*:

$$\rho(L) = \{ \lambda \in \mathbb{C} \mid \lambda \mbox{ is a regular value of } L \}.$$

The [spectrum](wikipedia://en/206137) is the [complement](wikipedia://en/54347) of the resolvent set

$$\sigma (L) = \mathbb{C} \setminus \rho (L),$$

and subject to a mutually singular [spectral decomposition](wikipedia://en/976834) into the [point spectrum](wikipedia://en/206137#Point_spectrum) (when condition 1 fails), the [continuous spectrum](wikipedia://en/206137#Continuous_spectrum) (when condition 2 fails) and the [residual spectrum](wikipedia://en/206137#Residual_spectrum) (when condition 3 fails).

If $L$ is a [closed operator](https://en.wikipedia.org/wiki/Closed_operator), then so is each $L_\lambda$, and condition 3 may be replaced by requiring that $L_\lambda$ be [surjective](https://en.wikipedia.org/wiki/Surjective).

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The resolvent set $\rho(L) \subseteq \mathbb{C}$ of a bounded linear operator *L* is an [open set](wikipedia://en/39358).
- More generally, the resolvent set of a densely defined closed unbounded operator is an open set.

:::
