# Laplacian smoothing

::: {#o1 .subject cue=lead name="Laplacian smoothing"}

**Laplacian smoothing** is an algorithm to [smooth](wikipedia://en/4155662) a [polygonal mesh](https://en.wikipedia.org/wiki/Polygon_mesh).[^o2][^o3] For each vertex in a mesh, a new position is chosen based on local information (such as the position of neighbours) and the vertex is moved there. In the case that a mesh is topologically a rectangular grid (that is, each internal vertex is connected to four neighbours) then this operation produces the [Laplacian](https://en.wikipedia.org/wiki/Laplacian) of the mesh.

:::

More formally, the smoothing operation may be described per-vertex as:

$$\bar{x}_{i}= \frac{1}{N} \sum_{j=1}^{N}\bar{x}_j$$

Where $N$ is the number of adjacent vertices to node $i$, $\bar{x}_{j}$ is the position of the $j$-th adjacent vertex and $\bar{x}_{i}$ is the new position for node $i$.[^o4]
