# Luzin N property

::: {#o1 .subject cue=lead name="Luzin N property"}

In [mathematics](wikipedia://en/18831), a function *f* on the interval \[*a*, *b*\] has the **Luzin N property**, named after [Nikolai Luzin](wikipedia://en/576228) (also called Luzin property or N property) if for all $N\subset[a,b]$ such that $\lambda(N)=0$, there holds: $\lambda(f(N))=0$, where $\lambda$ stands for the [Lebesgue measure](wikipedia://en/18198).

:::

Note that the image of such a set *N* is not necessarily [measurable](https://en.wikipedia.org/wiki/Measurable_set), but since the Lebesgue measure is [complete](wikipedia://en/44775), it follows that if the Lebesgue [outer measure](wikipedia://en/488605) of that set is zero, then it is measurable and its Lebesgue measure is zero as well.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Any differentiable function has the Luzin N property.[^o4][^o5] This extends to functions that are differentiable on a [cocountable set](https://en.wikipedia.org/wiki/Cocountable_set), as the image of a countable set is countable and thus a null set, but not to functions differentiable on a [conull set](wikipedia://en/735067): The [Cantor function](wikipedia://en/320819) does not have the Luzin N property, as the Lebesgue measure of the [Cantor set](wikipedia://en/6172) is zero, but its image is the complete \[0,1\] interval.

A function *f* on the interval \[*a*,*b*\] is [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) if and only if it is [continuous](wikipedia://en/6122), is of [bounded variation](wikipedia://en/330673) and has the Luzin N property.

:::
