# Kunstweg

::: {#o1 .subject cue=lead name="Kunstweg"}

*Image: Kunstweg (Jost Bürgi).png.* The *Kunstweg* by Jost Bürgi in his *Fundamentum Astronomiae*.

Bürgi's **Kunstweg** is a set of [algorithms](wikipedia://en/775) developed by [Jost Bürgi](https://en.wikipedia.org/wiki/Jost_Bürgi) in the late 16th century.[^o2] They are used to calculate [sines](https://en.wikipedia.org/wiki/Sines) to arbitrary precision.. Bürgi used these algorithms to calculate a [Canon Sinuum](wikipedia://en/49590020), a sine table in increments of 2 [arc seconds](https://en.wikipedia.org/wiki/Arc_seconds). It is believed that the table featured values accurate to eight sexagesimal places. Some authors have speculated that the table only covered the range from 0° to 45°, although there is no evidence supporting this claim. Such tables were crucial for maritime [navigation](https://en.wikipedia.org/wiki/Navigation). [Johannes Kepler](wikipedia://en/15736) described the Canon Sinuum as the most precise sine table known at the time.[^o3] Bürgi explained his algorithms in his work *[Fundamentum Astronomiae](wikipedia://en/49672578)*, which he presented to [Emperor Rudolf II](https://en.wikipedia.org/wiki/Emperor_Rudolf_II) in 1592.

:::

The Kunstweg algorithm calculates sine values iteratively. In each step, the value of a cell is the sum of the two preceding cells in the same [column](https://en.wikipedia.org/wiki/Column). The final cell's value is halved before beginning the next iteration. Ultimately, the values in the last column are normalized. Accurate sine [approximations](https://en.wikipedia.org/wiki/Approximations) are achieved after only a few iterations.

In 2015, [Menso Folkerts](https://en.wikipedia.org/wiki/Menso_Folkerts) and coworkers demonstrated that this iterative process does indeed converge toward the true sine values.[^o4] According to them this was the first step towards [differential calculus](https://en.wikipedia.org/wiki/Difference_calculus).
