# Order type

::: {#o1 .subject cue=lead name="Order type"}

In [mathematics](wikipedia://en/18831), especially in [set theory](wikipedia://en/27553) and [order theory](wikipedia://en/361924), two [ordered sets](https://en.wikipedia.org/wiki/Ordered_set) $X$ and $Y$ are said to have the same **order type** if they are [order isomorphic](https://en.wikipedia.org/wiki/Order_isomorphic), that is, if there exists a [bijection](wikipedia://en/3942) (each element pairs with exactly one in the other set) $f\colon X \to Y$ such that both $f$ and its [inverse](wikipedia://en/14907) are [monotonic](https://en.wikipedia.org/wiki/Monotonic#Monotonicity_in_order_theory) (preserving orders of elements).

:::

In the special case when $X$ is [totally ordered](https://en.wikipedia.org/wiki/Totally_ordered), monotonicity of $f$ already implies monotonicity of its inverse.

One and the same set may be equipped with different orders. Since order-equivalence is an [equivalence relation](wikipedia://en/9259), it [partitions](wikipedia://en/340240) the [class](wikipedia://en/20696) of all ordered sets into [equivalence classes](wikipedia://en/9260).

::: {#o3 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

If a set $X$ has order type denoted $\sigma$, the order type of the reversed order, the [dual](wikipedia://en/600618) of $X$, is denoted $\sigma^{*}$.

The order type of a well-ordered set $X$ is sometimes expressed as $\operatorname{ord}(X)$.[^o4]

:::

## Examples of ordering {#Examples_of_ordering}

The order type of the [integers](https://en.wikipedia.org/wiki/Integer_number) and [rationals](wikipedia://en/19727024) is usually denoted $\pi$ and $\eta$, respectively. The [set](wikipedia://en/26691) of integers and the set of [even](wikipedia://en/143135) integers have the same order type, because the mapping $n\mapsto 2n$ is a bijection that preserves the order. But the set of integers and the set of rational numbers (with the standard ordering) do not have the same order type, because even though the sets are of the same [size](wikipedia://en/6174) (they are both [countably infinite](wikipedia://en/6026)), there is no order-preserving bijective mapping between them. The open interval $(0, 1)$ of rationals is order isomorphic to the rationals, since, for example, $f(x) = \tfrac{2x - 1}{1 - \vert {2x - 1} \vert}$ is a strictly increasing bijection from the former to the latter. Relevant theorems of this sort are expanded upon below.

More examples can be given now: The set of positive integers (which has a least element), and that of negative integers (which has a greatest element). The [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) have order type denoted by ω, as explained below.

The rationals contained in the half-closed intervals \[0,1) and (0,1\], and the closed interval \[0,1\], are three additional order type examples.

## Order type of well-orderings {#Order_type_of_well-orderings}

*Image: OrderTypeExamples svg.svg.* Three well-orderings on the set of natural numbers with distinct order types (*top to bottom*): $\omega$, $\omega+5$, and $\omega+\omega$.

Every [well-ordered set](https://en.wikipedia.org/wiki/Well-ordered_set) is order-equivalent to exactly one [ordinal number](https://en.wikipedia.org/wiki/Ordinal_number_%28mathematics%29). The ordinal numbers are taken to be the [canonical representatives](wikipedia://en/515096) of their classes, and so the order type of a well-ordered set is usually identified with the corresponding ordinal. Order types thus often take the form of arithmetic expressions of ordinals.

### Examples of well-ordering {#Examples_of_well-ordering}

Firstly, the order type of the set of natural numbers is $\omega$. Any other model of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), that is any [non-standard model](wikipedia://en/6251420#Structure_of_countable_non-standard_models), starts with a segment isomorphic to ω but then adds extra numbers. For example, any countable such model has order type ω + (ω\* + ω) ⋅ η.

Secondly, consider the set $V$ of [even ordinals](https://en.wikipedia.org/wiki/Even_ordinal) less than $\omega \cdot 2 + 7$:

$$V = \{0,2,4,\ldots;\omega,\omega + 2,\omega + 4,\ldots;\omega\cdot 2,\omega\cdot 2 + 2, \omega\cdot 2 + 4, \omega\cdot 2 + 6\}.$$

As this comprises two separate counting sequences followed by four elements at the end, the order type is

$$\operatorname{ord}(V) = \omega\cdot 2 + 4 = \{0, 1, 2, \ldots; \omega, \omega+1, \omega+2, \ldots; \omega\cdot 2, \omega\cdot 2 + 1, \omega\cdot 2 + 2, \omega\cdot 2 + 3\},$$

## Rational numbers {#Rational_numbers}

With respect to their standard ordering as numbers, the set of rationals is not well-ordered. Neither is the [completed](wikipedia://en/29322627) set of reals, for that matter.

Any countable [toset](https://en.wikipedia.org/wiki/Toset) can be mapped injectively into the rational numbers in an order-preserving way. Moreover, when the order is [dense](wikipedia://en/6320997) and has no highest nor lowest element, there even exists an order-preserving *bijection* into $\mathbb{Q}$ — which, since the order is total, is then necessarily an *order isomorphism.* Hence, the order type of any such toset is precisely that of the rationals.
