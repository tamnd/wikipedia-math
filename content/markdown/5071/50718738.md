# Generating set of a module

::: {#o1 .subject cue=lead name="Generating set of a module"}

In [mathematics](wikipedia://en/18831), a **generating set** Γ of a [module](wikipedia://en/276410) *M* over a [ring](wikipedia://en/48404) *R* is a [subset](wikipedia://en/27631) of *M* such that the smallest [submodule](https://en.wikipedia.org/wiki/Submodule) of *M* containing Γ is *M* itself (the smallest submodule containing a subset is the [intersection](wikipedia://en/23476429) of all submodules containing the set). The set Γ is then said to generate *M*. For example, the ring *R* is generated by the identity element 1 as a left *R*-module over itself. If there is a [finite](wikipedia://en/11742) generating set, then a module is said to be [finitely generated](wikipedia://en/326430).

:::

This applies to [ideals](wikipedia://en/25977), which are the submodules of the ring itself. In particular, a [principal ideal](wikipedia://en/145126) is an ideal that has a generating set consisting of a single element.

Explicitly, if Γ is a generating set of a module *M*, then every element of *M* is a (finite) *R*-linear combination of some elements of Γ; i.e., for each *x* in *M*, there are *r*<sub>1</sub>, ..., *r*<sub>*m*</sub> in *R* and *g*<sub>1</sub>, ..., *g*<sub>*m*</sub> in Γ such that

$$x = r_1 g_1 + \cdots + r_m g_m.$$

Put in another way, there is a [surjection](https://en.wikipedia.org/wiki/Surjection)

$$\bigoplus_{g \in \Gamma} R \to M, \, r_g \mapsto r_g g,$$

where we wrote *r*<sub>*g*</sub> for an element in the *g*-th component of the direct sum. (Coincidentally, since a generating set always exists, e.g. *M* itself, this shows that a module is a [quotient](wikipedia://en/364820) of a [free module](wikipedia://en/326454), a useful fact.)

A generating set of a module is said to be **minimal** if no [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of the set generates the module. If *R* is a [field](wikipedia://en/10603), then a minimal generating set is the same thing as a [basis](wikipedia://en/18420). Unless the module is [finitely generated](wikipedia://en/326430), there may exist no minimal generating set.[^o2]

The [cardinality](wikipedia://en/6174) of a minimal generating set need not be an invariant of the module; **Z** is generated as a principal ideal by 1, but it is also generated by, say, a minimal generating set {2, 3}. What *is* uniquely determined by a module is the [infimum](https://en.wikipedia.org/wiki/Infimum) of the numbers of the generators of the module.

Let *R* be a [local ring](wikipedia://en/153391) with [maximal ideal](wikipedia://en/48164) *m* and [residue field](wikipedia://en/10789680) *k* and *M* finitely generated module. Then [Nakayama's lemma](wikipedia://en/1835001) says that *M* has a minimal generating set whose cardinality is $\dim_k M / mM = \dim_k M \otimes_R k$. If *M* is [flat](wikipedia://en/492616), then this minimal generating set is [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) (so *M* is free). See also: [Minimal resolution](https://en.wikipedia.org/wiki/Minimal_resolution_%28algebra%29).

A more refined information is obtained if one considers the relations between the generators; see [Free presentation of a module](https://en.wikipedia.org/wiki/Free_presentation_of_a_module).
