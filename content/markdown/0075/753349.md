# Boolean function

*Image: BinaryDecisionTree.svg.* A [binary decision diagram](wikipedia://en/576855) and [truth table](wikipedia://en/25512250) of a ternary Boolean function

::: {#o1 .subject cue=lead name="Boolean function"}

In [mathematics](wikipedia://en/18831), a **Boolean function** is a [function](wikipedia://en/185427) whose [arguments](wikipedia://en/32842052) and result assume values from a two-element set (usually {true, false}, {0,1} or {−1,1}).[^o2][^o3] Alternative names are **switching function**, used especially in older [computer science](https://en.wikipedia.org/wiki/Computer_science) literature,[^o4][^o5] and **[truth function](wikipedia://en/604707)** (or **logical function)**, used in [logic](wikipedia://en/46426065). Boolean functions are the subject of [Boolean algebra](wikipedia://en/54476844) and [switching theory](https://en.wikipedia.org/wiki/Switching_theory).[^o6]

:::

A Boolean function takes the form $f:\{0,1\}^k \to \{0,1\}$, where $\{0,1\}$ is known as the [Boolean domain](wikipedia://en/3954077) and $k$ is a non-negative integer called the [arity](wikipedia://en/42301) of the function. In the case where $k=0$, the function is a constant element of $\{0,1\}$. A Boolean function with multiple outputs, $f:\{0,1\}^k \to \{0,1\}^m$ with $m>1$ is a **vectorial** or *vector-valued* Boolean function (an [S-box](wikipedia://en/240991) in symmetric [cryptography](wikipedia://en/18934432)).[^o24]

There are $2^{2^k}$ different Boolean functions with $k$ arguments; equal to the number of different [truth tables](wikipedia://en/25512250) with $2^k$ entries.

Every $k$-ary Boolean function can be expressed as a [propositional formula](wikipedia://en/1557634) in $k$ variables $x_1,...,x_k$, and two propositional formulas are [logically equivalent](wikipedia://en/169324) if and only if they express the same Boolean function.

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

*Image: Logical connectives Hasse diagram.svg.* The sixteen binary Boolean functions

The rudimentary symmetric Boolean functions ([logical connectives](wikipedia://en/18153) or [logic gates](https://en.wikipedia.org/wiki/Logic_gate)) are:

- [NOT](wikipedia://en/100625), [negation](wikipedia://en/161019) or [complement](https://en.wikipedia.org/wiki/Logical_complement) - which receives one input and returns true when that input is false ("not")
- [AND](https://en.wikipedia.org/wiki/AND_gate) or [conjunction](wikipedia://en/18152) - true when all inputs are true ("both")
- [OR](https://en.wikipedia.org/wiki/OR_gate) or [disjunction](wikipedia://en/7962) - true when any input is true ("either")
- [XOR](https://en.wikipedia.org/wiki/XOR_gate) or [exclusive disjunction](wikipedia://en/105979) - true when one of its inputs is true and the other is false ("not equal")
- [NAND](https://en.wikipedia.org/wiki/NAND_gate) or [Sheffer stroke](wikipedia://en/29388) - true when it is not the case that all inputs are true ("not both")
- [NOR](https://en.wikipedia.org/wiki/NOR_gate) or [logical nor](wikipedia://en/209154) - true when none of the inputs are true ("neither")
- [XNOR](https://en.wikipedia.org/wiki/XNOR_gate) or [logical equality](wikipedia://en/3092370) - true when both inputs are the same ("equal")

An example of a more complicated function is the [majority function](wikipedia://en/20823) (of an odd number of inputs).

:::

## Representation {#Representation}

*Image: Three input boolean circuit.svg.* A Boolean function represented as a [Boolean circuit](wikipedia://en/7087423)

A Boolean function may be specified in a variety of ways:

- [Truth table](wikipedia://en/25512250): explicitly listing its value for all possible values of the arguments
  - Marquand diagram: truth table values arranged in a two-dimensional grid (used in a [Karnaugh map](wikipedia://en/10854684))
  - [Binary decision diagram](wikipedia://en/576855), listing the truth table values at the bottom of a binary tree
  - [Venn diagram](wikipedia://en/61701), depicting the truth table values as a colouring of regions of the plane

Algebraically, as a [propositional formula](wikipedia://en/1557634) using rudimentary Boolean functions:

- [Negation normal form](wikipedia://en/554622), an arbitrary mix of AND and ORs of the arguments and their complements
- [Disjunctive normal form](wikipedia://en/73341), as an OR of ANDs of the arguments and their complements
- [Conjunctive normal form](wikipedia://en/73342), as an AND of ORs of the arguments and their complements
- [Canonical normal form](wikipedia://en/794841), a standardized formula which uniquely identifies the function:
  - [Algebraic normal form](wikipedia://en/1048680) or [Zhegalkin polynomial](https://en.wikipedia.org/wiki/Zhegalkin_polynomial), as a XOR of ANDs of the arguments (no complements allowed)
  - *Full* (canonical) [disjunctive normal form](wikipedia://en/73341), an OR of ANDs each containing every argument or complement ([minterms](https://en.wikipedia.org/wiki/Minterms))
  - *Full* (canonical) [conjunctive normal form](wikipedia://en/73342), an AND of ORs each containing every argument or complement ([maxterms](https://en.wikipedia.org/wiki/Maxterms))
  - [Blake canonical form](wikipedia://en/39986184), the OR of all the [prime implicants](https://en.wikipedia.org/wiki/Prime_implicant) of the function

Boolean formulas can also be displayed as a graph:

- [Propositional directed acyclic graph](https://en.wikipedia.org/wiki/Propositional_directed_acyclic_graph)
  - [Digital circuit](https://en.wikipedia.org/wiki/Circuit_%28computer_science%29) diagram of [logic gates](https://en.wikipedia.org/wiki/Logic_gate), a [Boolean circuit](wikipedia://en/7087423)
  - [And-inverter graph](https://en.wikipedia.org/wiki/And-inverter_graph), using only AND and NOT

In order to optimize electronic circuits, Boolean formulas can be [minimized](https://en.wikipedia.org/wiki/Minimization_of_Boolean_functions) using the [Quine–McCluskey algorithm](wikipedia://en/317263) or [Karnaugh map](wikipedia://en/10854684).

## Analysis {#Analysis}

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

A Boolean function can have a variety of properties:[^o14]

- [Constant](wikipedia://en/320861): Is always true or always false regardless of its arguments.
- [Monotone](wikipedia://en/48260#In_Boolean_functions): for every combination of argument values, changing an argument from false to true can only cause the output to switch from false to true and not from true to false. A function is said to be [unate](https://en.wikipedia.org/wiki/Unate_function) in a certain variable if it is monotone with respect to changes in that variable.
- [Linear](wikipedia://en/91591#Boolean_functions): for each variable, flipping the value of the variable either always makes a difference in the truth value or never makes a difference (a [parity function](wikipedia://en/22399369)).
- [Symmetric](wikipedia://en/22399366): the value does not depend on the order of its arguments.
- [Read-once](https://en.wikipedia.org/wiki/Read-once_function): Can be expressed with [conjunction](wikipedia://en/18152), [disjunction](wikipedia://en/7962), and [negation](wikipedia://en/161019) with a single instance of each variable.
- [Balanced](wikipedia://en/24635433): if its [truth table](wikipedia://en/25512250) contains an equal number of zeros and ones. The [Hamming weight](wikipedia://en/1127884) of the function is the number of ones in the truth table.
- [Bent](wikipedia://en/24465207): its derivatives are all balanced (the autocorrelation spectrum is zero)
- [Correlation immune](wikipedia://en/4279403) to *m*th order: if the output is uncorrelated with all (linear) combinations of at most *m* arguments
- [Evasive](wikipedia://en/26006899): if evaluation of the function always requires the value of all arguments
- A Boolean function is a *Sheffer function* if it can be used to create (by composition) any arbitrary Boolean function (see [functional completeness](wikipedia://en/5279259))
- The *algebraic degree* of a function is the order of the highest order monomial in its [algebraic normal form](wikipedia://en/1048680)

[Circuit complexity](wikipedia://en/7641969) attempts to classify Boolean functions with respect to the size or depth of circuits that can compute them.

:::

### Derived functions {#Derived_functions}

A Boolean function may be decomposed using [Boole's expansion theorem](wikipedia://en/2733707) in positive and negative *Shannon* *cofactors* ([Shannon expansion](https://en.wikipedia.org/wiki/Shannon_expansion)), which are the (*k*−1)-ary functions resulting from fixing one of the arguments (to 0 or 1). The general *k*-ary functions obtained by imposing a linear constraint on a set of inputs (a linear subspace) are known as *subfunctions*.[^o16]

The *[Boolean derivative](https://en.wikipedia.org/wiki/Boolean_derivative)* of the function to one of the arguments is a (*k*−1)-ary function that is true when the output of the function is sensitive to the chosen input variable; it is the XOR of the two corresponding cofactors. A derivative and a cofactor are used in a [Reed–Muller expansion](https://en.wikipedia.org/wiki/Reed–Muller_expansion). The concept can be generalized as a *k*-ary derivative in the direction dx, obtained as the difference (XOR) of the function at x and x + dx.[^o16]

The *[Möbius transform](https://en.wikipedia.org/wiki/Zhegalkin_polynomial#Möbius_transformation)* (or *Boole–Möbius transform*) of a Boolean function is the set of coefficients of its [polynomial](https://en.wikipedia.org/wiki/Zhegalkin_polynomial) ([algebraic normal form](wikipedia://en/1048680)), as a function of the monomial exponent vectors. It is a [self-inverse](wikipedia://en/293450) transform. It can be calculated efficiently using a [butterfly algorithm](wikipedia://en/2707212) ("*Fast Möbius Transform*"), analogous to the [fast Fourier transform](wikipedia://en/11512).[^o17] *Coincident* Boolean functions are equal to their Möbius transform, i.e. their truth table (minterm) values equal their algebraic (monomial) coefficients.[^o18] There are 2^2^(*k*−1) coincident functions of *k* arguments.[^o19]

::: {#o21 .pointer-item cue=pointer name="Linear approximation table"}

### Cryptographic analysis {#Cryptographic_analysis}

The *[Walsh transform](https://en.wikipedia.org/wiki/Walsh_transform)* of a Boolean function is a k-ary integer-valued function giving the coefficients of a decomposition into [linear functions](wikipedia://en/22399369) ([Walsh functions](wikipedia://en/380839)), analogous to the decomposition of real-valued functions into [harmonics](https://en.wikipedia.org/wiki/Harmonic) by the [Fourier transform](wikipedia://en/52247). Its square is the *power spectrum* or *Walsh spectrum*. The Walsh coefficient of a single bit vector is a measure for the correlation of that bit with the output of the Boolean function. The maximum (in absolute value) Walsh coefficient is known as the *linearity* of the function.[^o16] The highest number of bits (order) for which all Walsh coefficients are 0 (i.e. the subfunctions are balanced) is known as *resiliency*, and the function is said to be [correlation immune](wikipedia://en/4279403) to that order.[^o16] The Walsh coefficients play a key role in [linear cryptanalysis](wikipedia://en/59469).

The *[autocorrelation](wikipedia://en/2724)* of a Boolean function is a k-ary integer-valued function giving the correlation between a certain set of changes in the inputs and the function output. For a given bit vector it is related to the Hamming weight of the derivative in that direction. The maximal autocorrelation coefficient (in absolute value) is known as the *absolute indicator*.[^o14][^o16] If all autocorrelation coefficients are 0 (i.e. the derivatives are balanced) for a certain number of bits then the function is said to satisfy the *propagation criterion* to that order; if they are all zero then the function is a [bent function](wikipedia://en/24465207).[^o22] The autocorrelation coefficients play a key role in [differential cryptanalysis](wikipedia://en/8536).

The Walsh coefficients of a Boolean function and its autocorrelation coefficients are related by the equivalent of the [Wiener–Khinchin theorem](wikipedia://en/3350111), which states that the autocorrelation and the power spectrum are a Walsh transform pair.[^o16]

#### Linear approximation table {#Linear_approximation_table}

These concepts can be extended naturally to *vectorial* Boolean functions by considering their output bits (*coordinates*) individually, or more thoroughly, by looking at the set of all linear functions of output bits, known as its *components*.[^o24] The set of Walsh transforms of the components is known as a **linear approximation table** (LAT)[^o25][^o26] or *correlation matrix*;[^o27][^o28] it describes the correlation between different linear combinations of input and output bits. The set of autocorrelation coefficients of the components is the *autocorrelation table*,[^o26] related by a Walsh transform of the components[^o29] to the more widely used *difference distribution table* (DDT)[^o25][^o26] which lists the correlations between differences in input and output bits (see also: [S-box](wikipedia://en/240991)).

:::

## Real polynomial form {#Real_polynomial_form}

### On the unit hypercube {#On_the_unit_hypercube}

Any Boolean function $f(x): \{0,1\}^n \rightarrow \{0,1\}$ can be uniquely extended (interpolated) to the [real domain](wikipedia://en/20646438) by a [multilinear polynomial](wikipedia://en/21890097) in $\mathbb{R}^n$, constructed by summing the truth table values multiplied by [indicator polynomials](wikipedia://en/217523):

$$f^*(x) = \sum_{a \in {\{0,1\}}^n} f(a) \prod_{i:a_i=1} x_i \prod_{i:a_i=0} (1-x_i)$$

For example, the extension of the binary XOR function $x \oplus y$ is

$$0(1-x)(1-y) + 1x(1-y) + 1(1-x)y + 0xy$$

which equals

$$x + y -2xy$$

Some other examples are negation ($1-x$), AND ($xy$) and OR ($x + y - xy$). When all operands are independent (share no variables) a function's polynomial form can be found by repeatedly applying the polynomials of the operators in a Boolean formula. When the coefficients are calculated [modulo 2](wikipedia://en/20087) one obtains the [algebraic normal form](wikipedia://en/1048680) ([Zhegalkin polynomial](https://en.wikipedia.org/wiki/Zhegalkin_polynomial)).

Direct expressions for the coefficients of the polynomial can be derived by taking an appropriate derivative:

$$\begin{array}{lcl} f^*(00) & = & (f^*)(00) & = & f(00) \\ f^*(01) & = & (\partial_1f^*)(00) & = & -f(00) + f(01) \\ f^*(10) & = & (\partial_2f^*)(00) & = & -f(00) + f(10) \\ f^*(11) & = & (\partial_1\partial_2f^*)(00) & = & f(00) -f(01)-f(10)+f(11) \\ \end{array}$$

this generalizes as the [Möbius inversion](https://en.wikipedia.org/wiki/Möbius_transform) of the [partially ordered set](wikipedia://en/23572) of bit vectors:

$$f^*(m) = \sum_{a \subseteq m} (-1)^{|a|+|m|} f(a)$$

where $|a|$ denotes the weight of the bit vector $a$. Taken modulo 2, this is the [Boolean *Möbius transform*](https://en.wikipedia.org/wiki/Zhegalkin_polynomial), giving the [algebraic normal form](wikipedia://en/1048680) coefficients:

$$\hat f(m) = \bigoplus_{a \subseteq m} f(a)$$

In both cases, the sum is taken over all bit-vectors *a* covered by *m*, i.e. the "one" bits of *a* form a subset of the one bits of *m*.

When the domain is restricted to the n-dimensional [hypercube](wikipedia://en/39783) $[0,1]^n$, the polynomial $f^*(x): [0,1]^n \rightarrow [0,1]$ gives the probability of a positive outcome when the Boolean function *f* is applied to *n* independent random ([Bernoulli](wikipedia://en/199189)) variables, with individual probabilities *x*. A special case of this fact is the [piling-up lemma](wikipedia://en/715186) for [parity functions](wikipedia://en/22399369). The polynomial form of a Boolean function can also be used as its natural extension to [fuzzy logic](wikipedia://en/49180).

### On the symmetric hypercube {#On_the_symmetric_hypercube}

Often, the Boolean domain is taken as $\{-1, 1\}$, with false ("0") mapping to 1 and true ("1") to −1 (see [Analysis of Boolean functions](wikipedia://en/54171755)). The polynomial corresponding to $g(x): \{-1,1\}^n \rightarrow \{-1,1\}$ is then given by:

$$g^*(x) = \sum_{a \in {\{-1,1\}}^n} g(a) \prod_{i:a_i=-1} \frac{1-x_i}{2} \prod_{i:a_i=1} \frac{1+x_i}{2}$$

Using the symmetric Boolean domain simplifies certain aspects of the [analysis](wikipedia://en/54171755), since negation corresponds to multiplying by −1 and [linear functions](wikipedia://en/22399369) are [monomials](wikipedia://en/357416) (XOR is multiplication). This polynomial form thus corresponds to the *Walsh transform* (in this context also known as *Fourier transform*) of the function (see above). The polynomial also has the same statistical interpretation as the one in the standard Boolean domain, except that it now deals with the expected values $E(X) = P(X=1) - P(X=-1) \in [-1, 1]$ (see [piling-up lemma](wikipedia://en/715186) for an example).

## Applications {#Applications}

Boolean functions play a basic role in questions of [complexity theory](wikipedia://en/7543) as well as the design of processors for [digital computers](https://en.wikipedia.org/wiki/Digital_computer), where they are implemented in electronic circuits using [logic gates](https://en.wikipedia.org/wiki/Logic_gate).

The properties of Boolean functions are critical in [cryptography](wikipedia://en/18934432), particularly in the design of [symmetric key algorithms](https://en.wikipedia.org/wiki/Symmetric_key_algorithm) (see [substitution box](https://en.wikipedia.org/wiki/Substitution_box)).

In [cooperative game](wikipedia://en/657958) theory, monotone Boolean functions are called **simple games** (voting games); this notion is applied to solve problems in [social choice theory](wikipedia://en/1745670).
