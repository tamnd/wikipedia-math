# Prime (order theory)

::: {#o1 .subject cue=lead name="Prime"}

In [mathematics](wikipedia://en/18831), an element *p* of a [partial order](https://en.wikipedia.org/wiki/Partial_order) (P, ≤) is a **meet prime** element when *p* is the principal element of a [principal](wikipedia://en/145126) [prime ideal](wikipedia://en/530559#Prime_ideals). Equivalently, if *P* is a [lattice](wikipedia://en/469304), *p* ≠ *top*, and for all *a*, *b* in *P*,

:::

*a*∧*b* ≤ *p* implies *a* ≤ *p* or *b* ≤ *p*.
