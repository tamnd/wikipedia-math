# Periodic point

::: {#o1 .subject cue=lead name="Periodic point"}

In [mathematics](wikipedia://en/18831), in the study of [iterated functions](wikipedia://en/1448702) and [dynamical systems](wikipedia://en/9087), a **periodic point** of a [function](wikipedia://en/185427) is a point which the system returns to after a certain number of function iterations or a certain amount of time.

:::

## Iterated functions {#Iterated_functions}

Given a [mapping](https://en.wikipedia.org/wiki/Mapping_%28mathematics%29) $f$ from a [set](wikipedia://en/26691) $X$ into itself,

$$f: X \to X,$$

a point $x$ in $X$ is called periodic point if there exists an $n$>0 so that

$$\ f_n(x) = x$$

where $f_{n}$ is the $n$th [iterate](wikipedia://en/1448702) of $f$. The smallest positive [integer](wikipedia://en/14563) $n$ satisfying the above is called the *prime period* or *least period* of the point $x$. If every point in $X$ is a periodic point with the same period $n$, then $f$ is called *periodic* with period $n$ (this is not to be confused with the notion of a [periodic function](wikipedia://en/76848)).

If there exist distinct $n$ and $m$ such that

$$f_n(x) = f_m(x)$$

then $x$ is called a **preperiodic point**. All periodic points are preperiodic.

If $f$ is a [diffeomorphism](wikipedia://en/8564) of a [differentiable manifold](wikipedia://en/2119219), so that the [derivative](wikipedia://en/7921) $f_n^\prime$ is defined, then one says that a periodic point is *hyperbolic* if

$$|f_n^\prime|\ne 1,$$

that it is *[attractive](wikipedia://en/191094)* if

$$|f_n^\prime|< 1,$$

and it is *repelling* if

$$|f_n^\prime|> 1.$$

If the [dimension](wikipedia://en/8398) of the [stable manifold](wikipedia://en/5466649) of a periodic point or fixed point is zero, the point is called a *source*; if the dimension of its [unstable manifold](https://en.wikipedia.org/wiki/Unstable_manifold) is zero, it is called a *sink*; and if both the stable and unstable manifold have nonzero dimension, it is called a *saddle* or [saddle point](wikipedia://en/640249).

::: {#o4 .example cue=heading name="Examples"}

### Examples {#Examples}

A period-one point is called a [fixed point](wikipedia://en/449738).

The [logistic map](wikipedia://en/18137)

$$x_{t+1}=rx_t(1-x_t), \qquad 0 \leq x_t \leq 1, \qquad 0 \leq r \leq 4$$

exhibits periodicity for various values of the parameter $r$. For $r$ between 0 and 1, 0 is the sole periodic point, with period 1 (giving the sequence $0, 0, 0, \ldots,$ which [attracts](wikipedia://en/191094) all orbits). For $r$ between 1 and 3, the value 0 is still periodic but is not attracting, while the value $\tfrac{r-1}{r}$ is an attracting periodic point of period 1. With $r$ greater than 3 but less than $1 + \sqrt 6,$ there are a pair of period-2 points which together form an attracting sequence, as well as the non-attracting period-1 points 0 and $\tfrac{r-1}{r}.$ As the value of parameter $r$ rises toward 4, there arise groups of periodic points with any positive integer for the period; for some values of $r$ one of these repeating sequences is attracting while for others none of them are (with almost all orbits being chaotic).

:::

## Dynamical system {#Dynamical_system}

Given a [real global dynamical system](https://en.wikipedia.org/wiki/Real_global_dynamical_system) $(\mathbb{R}, X, \Phi),$ with $X$ the [phase space](https://en.wikipedia.org/wiki/Phase_space_%28dynamical_system%29) and $\Phi$ the [evolution function](https://en.wikipedia.org/wiki/Evolution_function),

$$\Phi: \mathbb{R} \times X \to X$$

a point $x$ in $X$ is called *periodic* with *period* $T$ if

$$\Phi(T, x) = x\,$$

The smallest positive $T$ with this property is called *prime period* of the point $x$.

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- Given a periodic point $x$ with period $T$, then $\Phi(t,x) = \Phi(t+T,x)$ for all $t$ in $\mathbb{R}.$
- Given a periodic point $x$ then all points on the [orbit](wikipedia://en/252250) $\gamma_{x}$ through $x$ are periodic with the same prime period.

:::
