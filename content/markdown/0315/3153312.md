# Reflector (cipher machine)

::: {#o1 .subject cue=lead name="Reflector"}

A **reflector**, in [cryptology](https://en.wikipedia.org/wiki/Cryptology), is a component of some [rotor cipher machines](wikipedia://en/196223), such as the [Enigma machine](wikipedia://en/9256), that sends electrical impulses that have reached it from the machine's [rotors](wikipedia://en/196223), back in reverse order through those rotors. The reflector simplified using the same machine setup for encryption and decryption, but it creates a weakness in the encryption: with a reflector the encrypted version of a given letter can never be that letter itself. That limitation aided World War II code breakers in [cracking Enigma encryption](wikipedia://en/872175). The comparable WWII U.S. cipher machine, [SIGABA](wikipedia://en/145035), did not include a reflector.

:::

*Image: Enigma-action.svg.* The scrambling action of the Enigma rotors shown for two consecutive letters — current is passed into set of rotors, around the reflector, and back out through the rotors again. Note: The greyed-out lines represent other possible circuits within each rotor, which are hard-wired to contacts on each rotor. Letter A encrypts differently with consecutive key presses, first to G, and then to C. This is because the right hand rotor has stepped, sending the signal on a completely different route.

## Other names {#Other_names}

The reflector is also known as the **reversing drum** or, from the German, the ***Umkehrwalze*** or ***UKW***.

## History and development {#History_and_development}

The reflector was invented by Willi Korn, an engineer working at Arthur Scherbius's firm, Chiffriermaschinen Aktiengesellschaft (ChiMaAG). It was first integrated into the commercial Enigma "Glow Lamp" model (Enigma A). The component was adopted to replace the heavy printing mechanisms used in earlier rotor designs, which allowed the machine to be lighter and more compact for military field operations.[^o4]
