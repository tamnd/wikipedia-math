# Large set (combinatorics)

::: {#o1 .subject cue=lead name="Large set"}

In [combinatorial](wikipedia://en/5170) mathematics, a **large set** of [positive integers](https://en.wikipedia.org/wiki/Positive_integer)

:::

$$S = \{s_0,s_1,s_2,s_3,\dots\}$$

is one such that the [infinite sum](https://en.wikipedia.org/wiki/Infinite_sum) of the reciprocals

$$\frac{1}{s_0}+\frac{1}{s_1}+\frac{1}{s_2}+\frac{1}{s_3}+\cdots$$

[diverges](wikipedia://en/876428). A **small set** is any subset of the positive integers that is not large; that is, one whose sum of reciprocals converges.

Large sets appear in the [Müntz–Szász theorem](wikipedia://en/3204608) and in the [Erdős conjecture on arithmetic progressions](wikipedia://en/4312009).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every finite subset of the positive integers is small.
- The set $\{1,2,3,4,5,\dots\}$ of all positive integers is a large set; this statement is equivalent to the divergence of the [harmonic series](wikipedia://en/142488). More generally, any [arithmetic progression](wikipedia://en/168389) (i.e., a set of all integers of the form *an* + *b* with *a* ≥ 1, *b* ≥ 1 and *n* = 0, 1, 2, 3, ...) is a large set.
- The set of [square numbers](wikipedia://en/213919) is small (see *Basel problem#The Riemann zeta function*). So is the set of [cube numbers](https://en.wikipedia.org/wiki/Cube_number), the set of 4th powers, and so on. More generally, the set of positive integer values of any [polynomial](wikipedia://en/23000) of degree 2 or larger forms a small set.
- The set {1, 2, 4, 8, ...} of [powers of 2](wikipedia://en/376948) is a small set, and so is any [geometric progression](wikipedia://en/23474670) (i.e., a set of numbers of the form of the form *ab*<sup>*n*</sup> with *a* ≥ 1, *b* ≥ 2 and *n* = 0, 1, 2, 3, ...).
- The set of [prime numbers](wikipedia://en/23666) [is large](https://en.wikipedia.org/wiki/Proof_that_the_sum_of_the_reciprocals_of_the_primes_diverges). The set of [twin primes](wikipedia://en/41997) is small (see *[Brun's constant](https://en.wikipedia.org/wiki/Brun's_constant)*).
- The set of [prime powers](wikipedia://en/1630483) which are not prime (i.e., all numbers of the form *p*<sup>*n*</sup> with *n* ≥ 2 and *p* prime) is small although the primes are large. This property is frequently used in [analytic number theory](wikipedia://en/251513). More generally, the set of [perfect powers](wikipedia://en/4023591) is small; even the set of [powerful numbers](wikipedia://en/462499) is small.
- The set of numbers whose expansions in a given [base](wikipedia://en/21170#Positional_systems_in_detail) exclude a given digit is small. For example, the set $$\{1, 2, \dots, 5, 6, 8, 9, \dots, 15, 16, 18, 19, \dots, 65, 66, 68, 69, 80, 81, \dots \}$$ of integers whose [decimal](wikipedia://en/8214) expansion does not include the digit 7 is small. Such series are called [Kempner series](wikipedia://en/17961670).
- Any set whose upper [asymptotic density](https://en.wikipedia.org/wiki/Asymptotic_density) is nonzero, is large.
- The set of all primes in an arithmetic progression *an* + *b*, where *a* and *b* are coprime is large (see *[Dirichlet's theorem on arithmetic progressions](wikipedia://en/101453)*).

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every [subset](wikipedia://en/27631) of a small set is small.
- The [union](wikipedia://en/47949) of finitely many small sets is small, because the sum of two [convergent series](wikipedia://en/1743431) is a convergent series. (Hence, the small sets form an [ideal](wikipedia://en/12633368) on the set of positive integers.)
- The complement of every small set is large.
- The [Müntz–Szász theorem](wikipedia://en/3204608) states that a set $S=\{s_1,s_2,s_3,\dots\}$ is large if and only if the set of polynomials spanned by $$\{1,x^{s_1},x^{s_2},x^{s_3},\dots\}$$ is [dense](wikipedia://en/23523594) in the [uniform norm](wikipedia://en/349755) topology of [continuous functions](wikipedia://en/6122) on a closed interval in the positive real numbers. This is a generalization of the [Stone–Weierstrass theorem](wikipedia://en/28858).

:::

## Open problems involving large sets {#Open_problems_involving_large_sets}

[Paul Erdős](wikipedia://en/601284) [conjectured](wikipedia://en/4312009) that all large sets contain arbitrarily long [arithmetic progressions](wikipedia://en/168389). He offered a prize of \$3000 for a proof, more than for any of his [other conjectures](https://en.wikipedia.org/wiki/Erdős_conjectures), and joked that this prize offer violated the minimum wage law.[^o7] The question is still open.

It is not known how to identify whether a given set is large or small in general. As a result, there are many sets which are not known to be either large or small.
