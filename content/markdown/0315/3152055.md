# Frank–Wolfe algorithm

::: {#o1 .subject cue=lead name="Frank–Wolfe algorithm"}

The **Frank–Wolfe algorithm** is an [iterative](wikipedia://en/15237) [first-order](https://en.wikipedia.org/wiki/First-order_approximation) [optimization](wikipedia://en/52033) [algorithm](wikipedia://en/775) for [constrained](wikipedia://en/4171950) [convex optimization](wikipedia://en/1674411). Also known as the **conditional gradient method**,[^o2] **reduced gradient algorithm** and the **convex combination algorithm**, the method was originally proposed by [Marguerite Frank](wikipedia://en/42133630) and [Philip Wolfe](wikipedia://en/41154952) in 1956.[^o3] In each iteration, the Frank–Wolfe algorithm considers a [linear approximation](wikipedia://en/1107596) of the objective function, and moves towards a minimizer of this linear function (taken over the same domain).

:::

## Problem statement {#Problem_statement}

Suppose $\mathcal{D}$ is a [compact](wikipedia://en/6042) [convex set](wikipedia://en/6292) in a [vector space](wikipedia://en/32370) and $f \colon \mathcal{D} \to \mathbb{R}$ is a [convex](wikipedia://en/245568), [differentiable](wikipedia://en/330206) [real-valued function](wikipedia://en/22284647). The Frank–Wolfe algorithm solves the [optimization problem](wikipedia://en/1126536)

Minimize $f(\mathbf{x})$

subject to $\mathbf{x} \in \mathcal{D}$.

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

*Image: Franke wolfe animation for wiki.gif.* Animation of Franke-Wolfe algorithm.[^o7]

*Initialization:* Let $k \leftarrow 0$, and let $\mathbf{x}_0 \!$ be any point in $\mathcal{D}$.

**Step 1.** *Direction-finding subproblem:* Find $\mathbf{s}_k$ solving

Minimize $\mathbf{s}^T \nabla f(\mathbf{x}_k)$

Subject to $\mathbf{s} \in \mathcal{D}$

*(Interpretation: Minimize the linear approximation of the problem given by the first-order [Taylor approximation](wikipedia://en/30448) of $f$ around $\mathbf{x}_k \!$ constrained to stay within $\mathcal{D}$.)*

**Step 2.** *Step size determination:* Set $\alpha \leftarrow \frac{2}{k+2}$, or alternatively find $\alpha$ that minimizes $f(\mathbf{x}_k+\alpha(\mathbf{s}_k -\mathbf{x}_k))$ subject to $0 \le \alpha \le 1$ .

**Step 3.** *Update:* Let $\mathbf{x}_{k+1}\leftarrow \mathbf{x}_k+\alpha(\mathbf{s}_k-\mathbf{x}_k)$, let $k \leftarrow k+1$ and go to Step 1.

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

While competing methods such as [gradient descent](wikipedia://en/201489) for constrained optimization require a [projection step](wikipedia://en/3909097) back to the feasible set in each iteration, the Frank–Wolfe algorithm only needs the solution of a convex problem over the same set in each iteration, and automatically stays in the feasible set.

The convergence of the Frank–Wolfe algorithm is sublinear in general: the error in the objective function to the optimum is $O(1/k)$ after *k* iterations, so long as the gradient is [Lipschitz continuous](wikipedia://en/51731) with respect to some norm. The same convergence rate can also be shown if the sub-problems are only solved approximately.[^o10]

The iterations of the algorithm can always be represented as a sparse convex combination of the extreme points of the feasible set, which has helped to the popularity of the algorithm for sparse greedy optimization in [machine learning](wikipedia://en/233488) and [signal processing](wikipedia://en/29324) problems,[^o11] as well as for example the optimization of [minimum–cost flows](wikipedia://en/645676) in [transportation networks](https://en.wikipedia.org/wiki/Transport_network).[^o12]

If the feasible set is given by a set of linear constraints, then the subproblem to be solved in each iteration becomes a [linear program](wikipedia://en/43730).

While the worst-case convergence rate with $O(1/k)$ can not be improved in general, faster convergence can be obtained for special problem classes, such as some strongly convex problems.[^o13]

:::

## Lower bounds on the solution value, and primal-dual analysis {#Lower_bounds_on_the_solution_value,_and_primal-dual_analysis}

Since $f$ is [convex](wikipedia://en/245568), for any two points $\mathbf{x}, \mathbf{y} \in \mathcal{D}$ we have:

$$f(\mathbf{y}) \geq f(\mathbf{x}) + (\mathbf{y} - \mathbf{x})^T \nabla f(\mathbf{x})$$

This also holds for the (unknown) optimal solution $\mathbf{x}^*$. That is, $f(\mathbf{x}^*) \ge f(\mathbf{x}) + (\mathbf{x}^* - \mathbf{x})^T \nabla f(\mathbf{x})$. The best lower bound with respect to a given point $\mathbf{x}$ is given by

$$\begin{aligned} f(\mathbf{x}^*) & \ge f(\mathbf{x}) + (\mathbf{x}^* - \mathbf{x})^T \nabla f(\mathbf{x}) \\ &\geq \min_{\mathbf{y} \in D} \left\{ f(\mathbf{x}) + (\mathbf{y} - \mathbf{x})^T \nabla f(\mathbf{x}) \right\} \\ &= f(\mathbf{x}) - \mathbf{x}^T \nabla f(\mathbf{x}) + \min_{\mathbf{y} \in D} \mathbf{y}^T \nabla f(\mathbf{x}) \end{aligned}$$

The latter optimization problem is solved in every iteration of the Frank–Wolfe algorithm, therefore the solution $\mathbf{s}_k$ of the direction-finding subproblem of the $k$-th iteration can be used to determine increasing lower bounds $l_k$ during each iteration by setting $l_0 = - \infty$ and

$$l_k := \max (l_{k - 1}, f(\mathbf{x}_k) + (\mathbf{s}_k - \mathbf{x}_k)^T \nabla f(\mathbf{x}_k))$$

Such lower bounds on the unknown optimal value are important in practice because they can be used as a stopping criterion, and give an efficient certificate of the approximation quality in every iteration, since always $l_k \leq f(\mathbf{x}^*) \leq f(\mathbf{x}_k)$.

It has been shown that this corresponding [duality gap](wikipedia://en/33328430), that is the difference between $f(\mathbf{x}_k)$ and the lower bound $l_k$, decreases with the same convergence rate, i.e. $f(\mathbf{x}_k) - l_k = O(1/k) .$

## Applications {#Applications}

The Frank-Wolfe algorithm can be used to compute a [Wardrop equilibrium](wikipedia://en/81990926).
