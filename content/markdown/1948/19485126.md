# Harris chain

::: {#o1 .subject cue=lead name="Harris chain"}

In the mathematical study of [stochastic processes](wikipedia://en/47895), a **Harris chain** is a [Markov chain](wikipedia://en/60876) where the chain returns to a particular part of the state space an unbounded number of times.[^o2] Harris chains are [regenerative processes](wikipedia://en/29154766) and are named after [Theodore Harris](wikipedia://en/14786020). The theory of Harris chains and Harris recurrence is useful for treating Markov chains on general (possibly uncountably infinite) state spaces.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\{X_n\}$ be a [Markov chain](wikipedia://en/60876) on a general state space $\Omega$ with [stochastic kernel](https://en.wikipedia.org/wiki/Stochastic_kernel) $K$. The kernel represents a generalized one-step transition probability law, so that $P(X_{n+1}\in C\mid X_n=x)=K(x,C)$ for all states $x$ in $\Omega$ and all measurable sets $C\subseteq \Omega$. The chain $\{X_n\}$ is a *Harris chain*[^o5] if there exists $A\subseteq\Omega,\varepsilon>0$, and [probability measure](wikipedia://en/45437) $\rho$ with $\rho(\Omega)=1$ such that

1. If $\tau_A:=\inf \{n\geq 0:X_n\in A\}$, then $P(\tau_A<\infty\mid X_0=x)=1$ for all $x\in\Omega$.
1. If $x\in A$ and $C\subseteq\Omega$ (where $C$ is measurable), then $K(x, C)\geq \varepsilon\rho(C)$.

The first part of the definition ensures that the chain returns to some state within $A$ with probability 1, regardless of where it starts. It follows that it visits state $A$ infinitely often (with probability 1). The second part implies that once the Markov chain is in state $A$, its next-state can be generated with the help of an independent Bernoulli coin flip. To see this, first note that the parameter $\varepsilon$ must be between 0 and 1 (this can be shown by applying the second part of the definition to the set $C=\Omega$). Now let $x$ be a point in $A$ and suppose $X_n=x$. To choose the next state $X_{n+1}$, independently flip a biased coin with success probability $\varepsilon$. If the coin flip is successful, choose the next state $X_{n+1}\in\Omega$ according to the probability measure $\rho$. Else (and if $\varepsilon<1$), choose the next state $X_{n+1}$ according to the measure $P(X_{n+1}\in C\mid X_n=x)=(K(x,C)-\varepsilon\rho(C))/(1-\varepsilon)$ (defined for all measurable subsets $C\subseteq \Omega$).

Two random processes $\{X_n\}$ and $\{Y_n\}$ that have the same probability law and are Harris chains according to the above definition can be coupled as follows: Suppose that $X_n=x$ and $Y_n=y$, where $x$ and $y$ are points in $A$. Using the same coin flip to decide the next-state of both processes, it follows that the next states are the same with probability at least $\varepsilon$.

:::

## Examples {#Examples}

### Example 1: Countable state space {#Example_1:_Countable_state_space}

Let Ω be a countable state space. The kernel *K* is defined by the one-step conditional transition probabilities P\[*X*<sub>*n*+1</sub> = *y* | *X*<sub>*n*</sub> = *x*\] for *x*,*y* ∈ Ω. The measure ρ is a [probability mass function](wikipedia://en/154725) on the states, so that *ρ*(*x*) ≥ 0 for all *x* ∈ Ω, and the sum of the *ρ*(x) probabilities is equal to one. Suppose the above definition is satisfied for a given set *A* ⊆ Ω and a given parameter ε > 0. Then P\[*X*<sub>*n*+1</sub> = *c* | *X*<sub>*n*</sub> = *x*\] ≥ *ερ*(*c*) for all *x* ∈ *A* and all *c* ∈ Ω.

### Example 2: Chains with continuous densities {#Example_2:_Chains_with_continuous_densities}

Let {*X*<sub>*n*</sub>}, *X*<sub>*n*</sub> ∈ **R**<sup>*d*</sup> be a [Markov chain](wikipedia://en/60876) with a [kernel](https://en.wikipedia.org/wiki/Integral_kernel) that is [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) with respect to [Lebesgue measure](wikipedia://en/18198):

*K*(*x*, *dy*) = *K*(*x*, *y*) *dy*

such that *K*(*x*, *y*) is a [continuous function](wikipedia://en/6122).

Pick (*x*<sub>0</sub>, *y*<sub>0</sub>) such that *K*(*x*<sub>0</sub>, *y*<sub>0</sub> ) > 0, and let *A* and Ω be [open sets](https://en.wikipedia.org/wiki/Open_sets) containing *x*<sub>0</sub> and *y*<sub>0</sub> respectively that are sufficiently small so that *K*(*x*, *y*) ≥ *ε* > 0 on *A* × Ω. Letting *ρ*(*C*) = |Ω ∩ *C*|/|Ω| where |Ω| is the [Lebesgue measure](wikipedia://en/18198) of Ω, we have that (2) in the above definition holds. If (1) holds, then {*X*<sub>*n*</sub>} is a Harris chain.

:::

## Reducibility and periodicity {#Reducibility_and_periodicity}

In the following $R:=\inf\{n\ge1:X_n\in A\}$; i.e. $R$ is the first time after time 0 that the process enters region $A$. Let $\mu$ denote the initial distribution of the Markov chain, i.e. $X_0\sim\mu$.

::: {#o11 .definition cue=inline-head name="Definition"}

**Definition:** If for all $\mu$, $P [ R<\infty | X_0 \in A ]=1$, then the Harris chain is called *recurrent.*

:::

::: {#o12 .definition cue=inline-head name="Definition"}

**Definition:** A recurrent Harris chain $X_n$ is *aperiodic* if $\exists N$, such that $\forall n\ge N$, $\forall \mu, P[X_n\in A | X_0 \in A]>0$

:::

::: {#o13 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** Let $X_n$ be an aperiodic recurrent Harris chain with stationary distribution $\pi$. If $P [ R<\infty | X_0 \in A ]=1$ then as $n\rightarrow\infty$, $||\mathcal{L}(X_n|X_0)-\pi||_{TV}\rightarrow 0$ where $||\cdot||_{TV}$ denotes the [total variation](wikipedia://en/683561) for signed measures defined on the same [measurable space](wikipedia://en/43333).

:::
