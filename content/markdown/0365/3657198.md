# Phylogenetic network

::: {#o1 .subject cue=lead name="Phylogenetic network"}

A **phylogenetic network** is any [graph](wikipedia://en/325806) used to visualize evolutionary relationships (either [abstractly](https://en.wikipedia.org/wiki/Abstract_object) or explicitly)[^o2] between [nucleotide sequences](https://en.wikipedia.org/wiki/Nucleotide_sequence), [genes](https://en.wikipedia.org/wiki/Gene), [chromosomes](https://en.wikipedia.org/wiki/Chromosome), [genomes](https://en.wikipedia.org/wiki/Genome), or [species](https://en.wikipedia.org/wiki/Species).[^o3] They are employed when reticulation events such as [hybridization](https://en.wikipedia.org/wiki/Hybrid_%28biology%29), [horizontal gene transfer](https://en.wikipedia.org/wiki/Horizontal_gene_transfer), [recombination](https://en.wikipedia.org/wiki/Genetic_recombination), or [gene duplication](https://en.wikipedia.org/wiki/Gene_duplication) and loss are believed to be involved. They differ from [phylogenetic trees](https://en.wikipedia.org/wiki/Phylogenetic_trees) by the explicit modeling of richly linked networks, by means of the addition of hybrid nodes (nodes with two parents) instead of only tree nodes (a hierarchy of nodes, each with only one parent).[^o4] [Phylogenetic trees](wikipedia://en/149326) are a subset of [phylogenetic](https://en.wikipedia.org/wiki/Phylogenetic) networks. Phylogenetic networks can be inferred and visualised with software such as [SplitsTree](https://en.wikipedia.org/wiki/SplitsTree),[^o5] the R-package, phangorn,[^o6][^o7] and, more recently, [Dendroscope](https://en.wikipedia.org/wiki/Dendroscope). A standard format for representing phylogenetic networks is a variant of [Newick format](https://en.wikipedia.org/wiki/Newick_format) which is extended to support networks as well as trees.[^o8]

:::

Many kinds and subclasses of phylogenetic networks have been defined based on the biological phenomenon they represent or which data they are built from (hybridization networks, usually built from rooted trees, ancestral recombination graphs (ARGs) from binary sequences, [median networks](wikipedia://en/16970848) from a set of [splits](https://en.wikipedia.org/wiki/Split_%28phylogenetics%29), optimal realizations and reticulograms from a [distance matrix](wikipedia://en/831350)), or restrictions to get computationally tractable problems (galled trees, and their generalizations level-k phylogenetic networks, tree-child or tree-sibling phylogenetic networks).

## Microevolution {#Microevolution}

Phylogenetic trees also have trouble depicting [microevolutionary](https://en.wikipedia.org/wiki/Microevolution) events, for example the geographical distribution of muskrat or fish populations of a given species among river networks, because there is no [species](https://en.wikipedia.org/wiki/Species) boundary to prevent gene flow between populations. Therefore, a more general phylogenetic network better depicts these situations.[^o10]

## Rooted vs unrooted {#Rooted_vs_unrooted}

**Unrooted phylogenetic network**

Let X be a set of [taxa](https://en.wikipedia.org/wiki/Taxon). An unrooted phylogenetic network N on X is any undirected graph whose leaves are [bijectively](https://en.wikipedia.org/wiki/Bijective) labeled by the taxa in X.

A number of different types of unrooted phylogenetic networks are in use like [split networks](https://en.wikipedia.org/wiki/Split_networks) and [quasi-median networks](https://en.wikipedia.org/wiki/Quasi-median_networks). In most cases, such networks only depict relations between taxa, without giving information about the evolutionary history. Although some methods produce unrooted networks that can be interpreted as undirected versions of rooted networks, which do represent a phylogeny.

**Rooted phylogenetic network**

Let X be a set of taxa. A rooted phylogenetic network N on X is a rooted [directed acyclic graph](wikipedia://en/204002) where the set of leaves is bijectively labeled by the taxa in X.

Rooted phylogenetic networks, like rooted phylogenetic trees, give explicit representations of evolutionary history. This means that they visualize the order in which the species diverged (speciated), converged (hybridized), and transferred genetic material (horizontal gene transfer).

## Classes of networks {#Classes_of_networks}

section For computational purposes, studies often restrict their attention to classes of networks: subsets of all networks with certain properties. Although computational simplicity is the main goal, most of these classes have a biological justification as well. Some prominent classes currently used in the mathematical phylogenetics literature are tree-child networks,[^o13] tree-based networks,[^o14] and level-k networks[^o15][^o16]

## Software to compute phylogenetic networks {#Software_to_compute_phylogenetic_networks}

- [PhyloNet](http://bioinfo.cs.rice.edu/PhyloNet), A Java-based software package that builds phylogenetic networks taking ILS, HGT etc. into consideration.
- [PhyloNetworks](http://crsl4.github.io/PhyloNetworks.jl/latest/), a [Julia](https://julialang.org) package for the manipulation, visualization, inference of phylogenetic networks, and their use for trait evolution.
- [Network](http://www.fluxus-engineering.com/sharenet.htm), Free Phylogenetic Network Software. Network generates evolutionary trees and networks from genetic, linguistic, and other data.
- [Phylogeny programs](http://evolution.genetics.washington.edu/phylip/software.html), some of which compute phylogenetic networks
- [List of programs for phylogenetic network reconstruction, evaluation, visualization, etc.](https://web.archive.org/web/20141125081801/http://www.lirmm.fr/~gambette/PhylogeneticNetworks/show.php?keyword=programs)
- [SplitsTree](https://en.wikipedia.org/wiki/SplitsTree)
- [Dendroscope](https://en.wikipedia.org/wiki/Dendroscope)
- [Network inferring on the T-REX server](http://www.trex.uqam.ca/index.php?action=hgt&project=trex)
- [TCS](http://darwin.uvigo.es), Phylogenetic networks from DNA sequences or nucleotide distances using statistical parsimony.
- [NetTest](http://darwin.uvigo.es), Characterization of phylogenetic networks.[^o18]
- [phangorn: Phylogenetic Reconstruction and Analysis](https://cran.r-project.org/web/packages/phangorn/index.html)
- [SimPlot++](https://github.com/Stephane-S/Simplot_PlusPlus) Sequence similarity network analysis.[^o19]
