# Volterra operator

::: {#o1 .subject cue=lead name="Volterra operator"}

In [mathematics](wikipedia://en/18831), in the area of [functional analysis](wikipedia://en/11180) and [operator theory](wikipedia://en/712675), the **Volterra operator**, named after [Vito Volterra](https://en.wikipedia.org/wiki/Vito_Volterra), is a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) on the space *L*<sup>2</sup>\[0,1\] of complex-valued [square-integrable functions](wikipedia://en/28680558) on the interval \[0,1\]. On the subspace *C*\[0,1\] of [continuous functions](wikipedia://en/6122) it represents [indefinite integration](https://en.wikipedia.org/wiki/Indefinite_integration). It is the operator corresponding to the [Volterra integral equations](wikipedia://en/2091691).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Volterra operator, *V*, may be defined for a function *f* ∈ *L*<sup>2</sup>\[0,1\] and a value *t* ∈ \[0,1\], as[^o4]

$$V(f)(t) = \int_{0}^{t} f(s)\, ds.$$

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- *V* is a bounded linear operator between [Hilbert spaces](wikipedia://en/20598932), with kernel form $$Vf(x) = \int_0^1 1_{y \leq x} f(y) dy$$ proven by [exchanging the integral sign](wikipedia://en/255245).
- *V* is a [Hilbert–Schmidt operator](wikipedia://en/976673) with norm $\|V\|_{HS}^2 = 1/2$, hence in particular is [compact](wikipedia://en/577441).
- Its [Hermitian adjoint](wikipedia://en/667175) has kernel form $$V^*(f)(x) = \int_{x}^{1} f(y)dy = \int_0^1 1_{y \geq x} f(y)dy$$
- The positive-definite integral operator $K := V^* V$ has kernel form $$Kf(x) = \int_0^1 \min(1-x, 1-y) f(y) dy$$ proven by exchanging the integral sign. Similarly, $VV^*$ has kernel $\min(x, y)$. They are [unitarily equivalent](wikipedia://en/187408) via $Uf(x) = f(1-x)$, so both have the same spectrum.
- The eigenfunctions of $VV^*$ satisfy $\begin{cases} f(1) &= 0 \\ f'(0) &= 0 \\ f''(x) &= -\lambda^{-1} f \end{cases}$ with solution $$f(x) = \sin((k+1/2) \pi x), \lambda = \left(\frac{1}{(k+ 1/2) \pi}\right)^2$$ with $k = 0, 1, 2, \dots$.
- The [singular values](wikipedia://en/709116) of *V* are $((k + 1/2) \pi)^{-1}$ with $k = 0, 1, 2, \dots$.
- The [operator norm](wikipedia://en/246722) of *V* is $2/\pi$.
- *V* is not [trace class](wikipedia://en/192266).
- *V* has no [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) and therefore, by the [spectral theory of compact operators](wikipedia://en/4597914), its [spectrum](wikipedia://en/206137) *σ*(*V*) = {0}.[^o7][^o8]
- *V* is a [quasinilpotent operator](https://en.wikipedia.org/wiki/Quasinilpotent_operator) (that is, the [spectral radius](wikipedia://en/386169), *ρ*(*V*), is zero), but it is not [nilpotent operator](wikipedia://en/671772).

:::
