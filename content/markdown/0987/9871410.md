# Boolean operations on polygons

::: {#o1 .subject cue=lead name="Boolean operations on polygons"}

**Boolean operations on polygons** are a set of [Boolean operations](https://en.wikipedia.org/wiki/Boolean_operation_%28Boolean_algebra%29) (AND, OR, NOT, XOR, ...) operating on one or more sets of [polygons](wikipedia://en/23621) in computer graphics. These sets of operations are widely used in [computer graphics](https://en.wikipedia.org/wiki/Computer_graphics), [CAD](https://en.wikipedia.org/wiki/Computer-aided_design), and in [EDA](https://en.wikipedia.org/wiki/Electronic_design_automation) (in [integrated circuit](https://en.wikipedia.org/wiki/Integrated_circuit) physical design and verification software). These are also used for activities like rapid [prototyping](https://en.wikipedia.org/wiki/Prototyping) in product design, medical device development, or even the creation of elaborate artworks.

## Uses in software {#Uses_in_software}

Early algorithms for Boolean operations on polygons were based on the use of [bitmaps](https://en.wikipedia.org/wiki/Bitmaps). Using bitmaps in modeling polygon shapes has many drawbacks. One of the drawbacks is that the memory usage can be very large, since the resolution of polygons is proportional to the number of bits used to represent polygons. The higher the resolution is desired, the more the number of bits is required.

Modern implementations for Boolean operations on polygons tend to use plane sweep algorithms (or [Sweep line algorithms](wikipedia://en/8700856)). A list of papers using plane sweep algorithms for Boolean operations on polygons can be found in References below.

Boolean operations on [convex polygons](wikipedia://en/660019) and [monotone polygons](wikipedia://en/12003237) of the same direction may be performed in [linear time](https://en.wikipedia.org/wiki/Linear_time).[^o5]
