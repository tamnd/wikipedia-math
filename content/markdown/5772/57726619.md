# H-matrix (iterative method)

::: {#o1 .subject cue=lead name="H-matrix"}

In mathematics, an ***H*-matrix** is a [matrix](wikipedia://en/20556859) whose [comparison matrix](wikipedia://en/57726601) is an [M-matrix](wikipedia://en/7939066). It is useful in [iterative methods](wikipedia://en/15237).

:::

::: {#o2 .definition cue=inline-head name="Definition"}

**Definition:** Let $A = (a_{ij})$ be a $n \times n$ complex matrix. Then [comparison matrix](wikipedia://en/57726601) *M*(*A*) of complex matrix *A* is defined as $M(A) = \alpha_{ij}$ where $\alpha_{ij} = -|A_{ij}|$ for all $i \ne j, 1 \le i,j \le n$ and $\alpha_{ij} = |A_{ij}|$ for all $i = j, 1 \le i,j \le n$. If *M*(*A*) is a [M-matrix](wikipedia://en/7939066), *A* is a *H*-matrix.

[Invertible](wikipedia://en/217122) H-matrix guarantees convergence of [Gauss–Seidel iterative methods](wikipedia://en/4046824).[^o3]

:::
