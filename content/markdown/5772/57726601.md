# Comparison matrix

::: {#o1 .subject cue=lead name="Comparison matrix"}

In [linear algebra](wikipedia://en/18422), let $A = (a_{ij})$ be a $n \times n$ complex [matrix](wikipedia://en/20556859). The **comparison matrix** $M(A) = (\alpha_{ij})$ of complex matrix *A* is defined as

:::

$\alpha_{ij} = \begin{cases} -|a_{ij}| &\text{if } i \neq j, \\ |a_{ij}| &\text{if } i=j. \end{cases}$[^o2]
