# Norm (abelian group)

::: {#o1 .subject cue=lead name="Norm"}

In [mathematics](wikipedia://en/18831), specifically [abstract algebra](wikipedia://en/19616384), if $(G, +)$ is an ([abelian](wikipedia://en/2974)) [group](wikipedia://en/19447) with identity element $e$ then $\nu\colon G \to \mathbb{R}$ is said to be a **norm** on $(G, +)$ if:

:::

1. [Positive definiteness](wikipedia://en/3142115): $\nu(g) > 0 \text{ for all } g \ne e \text{ and } \nu(e) = 0$,
1. [Subadditivity](wikipedia://en/745789): $\nu(g+h) \le \nu(g) + \nu(h)$,
1. Inversion (Symmetry): $\nu(-g) = \nu(g) \text{ for all } g \in G$.[^o2][^o3]

An alternative, stronger definition of a norm on $(G, +)$ requires

1. $$\nu(g) > 0 \text{ for all } g \ne e,$$
1. $$\nu(g+h) \le \nu(g) + \nu(h),$$
1. $\nu(mg) = |m| \, \nu(g) \text{ for all } m \in \mathbb{Z}$.[^o4][^o5]

The norm $\nu$ is **discrete** if there is some [real number](wikipedia://en/20646438) $\rho > 0$ such that $\nu(g) > \rho$ whenever $g \ne 0$.

## Free abelian groups {#Free_abelian_groups}

An abelian group is a [free abelian group](wikipedia://en/247296) [if and only if](wikipedia://en/14922) it has a discrete norm.[^o4][^o5]
