# Carathéodory kernel theorem

::: {#o1 .subject cue=lead name="Carathéodory kernel theorem"}

In [mathematics](wikipedia://en/18831), the **Carathéodory kernel theorem** is a result in [complex analysis](wikipedia://en/5759) and [geometric function theory](wikipedia://en/5458932) established by the Greek mathematician [Constantin Carathéodory](wikipedia://en/470625) in 1912. The [uniform convergence](wikipedia://en/50652) on compact sets of a sequence of [holomorphic](wikipedia://en/14110) [univalent functions](https://en.wikipedia.org/wiki/Univalent_functions), defined on the [unit disk](wikipedia://en/252738) in the [complex plane](wikipedia://en/217628) and fixing 0, can be formulated purely geometrically in terms of the limiting behaviour of the images of the functions. The kernel theorem has wide application in the theory of univalent functions and in particular provides the geometric basis for the [Loewner differential equation](wikipedia://en/34134544).

:::

## Kernel of a sequence of open sets {#Kernel_of_a_sequence_of_open_sets}

Let *U*<sub>*n*</sub> be a sequence of open sets in **C** containing 0. Let *V*<sub>*n*</sub> be the connected component of the interior of $U_{n} \cap U_{n + 1} \cap ...$ containing 0. The **kernel** of the sequence is defined to be the union of the *V*<sub>*n*</sub>'s, provided it is non-empty; otherwise it is defined to be $\{0\}$. Thus the kernel is either a connected open set containing 0 or the one point set $\{0\}$. The sequence is said to converge to a kernel if each subsequence has the same kernel.

**Examples**

- If *U*<sub>*n*</sub> is an increasing sequence of connected open sets containing 0, then the kernel is just the union.
- If *U*<sub>*n*</sub> is a decreasing sequence of connected open sets containing 0, then, if 0 is an interior point of *U*<sub>1</sub> ∩ *U*<sub>2</sub> ∩ ..., the sequence converges to the component of the interior containing 0. Otherwise, if 0 is not an interior point, the sequence converges to $\{0\}$.

::: {#o4 .statement kind=statement/theorem cue=named-heading name="Kernel theorem"}

## Kernel theorem {#Kernel_theorem}

Let *f*<sub>*n*</sub>(*z*) be a sequence of [holomorphic](wikipedia://en/14110) [univalent functions](wikipedia://en/1534382) on the unit disk *D*, normalised so that *f*<sub>*n*</sub>(0) = 0 and *f* '<sub>*n*</sub> (0) > 0. Then *f*<sub>*n*</sub> converges uniformly on compacts in *D* to a function *f* if and only if *U*<sub>*n*</sub> = *f*<sub>*n*</sub>(*D*) converges to its kernel and this kernel is not **C**. If the kernel is $\{0\}$, then *f* = 0. Otherwise the kernel is a connected open set *U*, *f* is univalent on *D* and *f*(*D*) = *U*.

:::

::: {#o6 .proof cue=heading name="Proof"}

## Proof {#Proof}

Using [Hurwitz's theorem](wikipedia://en/23190553) and [Montel's theorem](wikipedia://en/1484228), it is straightforward to check that if *f*<sub>*n*</sub> tends uniformly on compacts to *f,* then each subsequence of *U*<sub>*n*</sub> has kernel *U* = *f*(*D*).

Conversely if *U*<sub>*n*</sub> converges to a kernel not equal to **C**, then by the [Koebe quarter theorem](wikipedia://en/16758771) *U*<sub>*n*</sub> contains the disk of radius *f* '<sub>*n*</sub>(0) / 4 with centre 0. The assumption that *U* ≠ **C** implies that these radii are uniformly bounded. By the [Koebe distortion theorem](https://en.wikipedia.org/wiki/Koebe_distortion_theorem)

$$|f_n(z)| \le f_n^\prime(0) {|z|\over (1-|z|)^2}.$$

Hence the sequence *f*<sub>*n*</sub> is uniformly bounded on compact sets. If two subsequences converge to holomorphic limits *f* and *g*, then *f*(0) = *g*(0) and with *f*'(0), *g**(0) ≥ 0. By the first part and the assumptions it follows that*****f*(*D*) =*g*(*D*). Uniqueness in the [Riemann mapping theorem](wikipedia://en/26215) forces*f*\=*g*, so the original sequence*f*<sub>*n*</sub> is uniformly convergent on compact sets.***

:::
