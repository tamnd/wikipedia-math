# Generalized semi-infinite programming

::: {#o1 .subject cue=lead name="Generalized semi-infinite programming"}

In [mathematics](wikipedia://en/18831), a [semi-infinite programming (SIP)](https://en.wikipedia.org/wiki/Semi-Infinite_Programming) problem is an optimization problem with a finite number of variables and an infinite number of constraints. The constraints are typically parameterized. In a **generalized semi-infinite programming** (**GSIP**) problem, the feasible set of the parameters depends on the variables.[^o2]

:::

## Mathematical formulation of the problem {#Mathematical_formulation_of_the_problem}

The problem can be stated simply as:

$$\min\limits_{x \in X}\;\; f(x)$$

$$\mbox{subject to: }\$$

$$g(x,y) \le 0, \;\; \forall y \in Y(x)$$

where

$$f: R^n \to R$$

$$g: R^n \times R^m \to R$$

$$X \subseteq R^n$$

$$Y \subseteq R^m.$$

In the special case that the set :$Y(x)$ is nonempty for all $x \in X$ GSIP can be cast as [bilevel programs](wikipedia://en/17702796) ([Multilevel programming](https://en.wikipedia.org/wiki/Multilevel_programming)).
