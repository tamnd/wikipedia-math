# F16C

::: {#o1 .subject cue=lead name="F16C"}

The **F16C**[^o2] (previously/informally known as **CVT16**) instruction set is an [x86](https://en.wikipedia.org/wiki/X86) [instruction set architecture](https://en.wikipedia.org/wiki/Instruction_set_architecture) extension which provides support for converting between [half-precision](https://en.wikipedia.org/wiki/Half-precision) and standard IEEE [single-precision floating-point formats](https://en.wikipedia.org/wiki/Single-precision_floating-point_format).

:::

## History {#History}

The CVT16 instruction set, announced by [AMD](https://en.wikipedia.org/wiki/Advanced_Micro_Devices) on May 1, 2009,[^o4] is an extension to the 128-bit [SSE](wikipedia://en/55365) core instructions in the [x86](https://en.wikipedia.org/wiki/X86) and [AMD64](https://en.wikipedia.org/wiki/AMD64) instruction sets.

CVT16 is a revision of part of the [SSE5](wikipedia://en/13016550) instruction set proposal announced on August 30, 2007, which is supplemented by the [XOP](wikipedia://en/22701763) and [FMA4](wikipedia://en/23095212) instruction sets. This revision makes the binary coding of the proposed new instructions more compatible with [Intel](https://en.wikipedia.org/wiki/Intel)'s [AVX](wikipedia://en/16779711) instruction extensions, while the functionality of the instructions is unchanged.

In recent documents, the name F16C is formally used in both [Intel](https://en.wikipedia.org/wiki/Intel) and [AMD](https://en.wikipedia.org/wiki/AMD) [x86-64](https://en.wikipedia.org/wiki/X86-64) architecture specifications.

## Technical information {#Technical_information}

There are variants that convert four floating-point values in an [XMM register](wikipedia://en/55365#Registers) or 8 floating-point values in a [YMM register](wikipedia://en/16779711).

The instructions are abbreviations for "vector convert packed half to packed single" and vice versa:

- `VCVTPH2PS xmmreg,xmmrm64` – convert four half-precision floating point values in memory or the bottom half of an XMM register to four single-precision floating-point values in an XMM register.
- `VCVTPH2PS ymmreg,xmmrm128` – convert eight half-precision floating point values in memory or an XMM register (the bottom half of a YMM register) to eight single-precision floating-point values in a YMM register.
- `VCVTPS2PH xmmrm64,xmmreg,imm8` – convert four single-precision floating point values in an XMM register to half-precision floating-point values in memory or the bottom half an XMM register.
- `VCVTPS2PH xmmrm128,ymmreg,imm8` – convert eight single-precision floating point values in a YMM register to half-precision floating-point values in memory or an XMM register.

The 8-bit immediate argument to `VCVTPS2PH` selects the [rounding](wikipedia://en/169945) mode. Values 0–4 select nearest, down, up, truncate, and the mode set in `MXCSR.RC`.

Support for these instructions is indicated by bit 29 of ECX after [CPUID with EAX=1](https://en.wikipedia.org/wiki/CPUID#EAX=1:_Processor_Info_and_Feature_Bits).

## CPUs with F16C {#CPUs_with_F16C}

- [AMD](https://en.wikipedia.org/wiki/Advanced_Micro_Devices):
  - [Jaguar-based](https://en.wikipedia.org/wiki/Jaguar_%28microarchitecture%29) processors
  - [Puma-based](https://en.wikipedia.org/wiki/Puma_%28microarchitecture%29) processors
  - "Heavy Equipment" processors
    - [Piledriver-based](https://en.wikipedia.org/wiki/Piledriver_%28microarchitecture%29) processors, Q4 2012[^o7]
    - [Steamroller-based](https://en.wikipedia.org/wiki/Steamroller_%28microarchitecture%29) processors, Q1 2014
    - [Excavator-based](https://en.wikipedia.org/wiki/Excavator_%28microarchitecture%29) processors, Q2 2015
  - [Zen-based](https://en.wikipedia.org/wiki/Zen_%28microarchitecture%29) processors, Q1 2017, and newer
- [Intel](https://en.wikipedia.org/wiki/Intel_Corporation):
  - [Ivy Bridge](https://en.wikipedia.org/wiki/Ivy_Bridge_%28microarchitecture%29) processors and newer
