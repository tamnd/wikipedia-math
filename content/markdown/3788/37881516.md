# Excursion probability

::: {#o1 .subject cue=lead name="Excursion probability"}

In [probability theory](wikipedia://en/23542), an **excursion probability** is the probability that a [stochastic process](wikipedia://en/47895) surpasses a given value in a fixed time period. It is the probability[^o2]

:::

$$\mathbb P \left\{ \sup_{t \in T} f(t) \geq u \right\}.$$

Numerous approximation methods for the situation where *u* is large and f(*t*) is a [Gaussian process](wikipedia://en/302944) have been proposed such as [Rice's formula](wikipedia://en/37862118).[^o2][^o3] First-excursion probabilities can be used to describe deflection to a critical point experienced by structures during "random loadings, such as earthquakes, strong gusts, hurricanes, etc."[^o4]
