# Finite model property

::: {#o1 .subject cue=lead name="Finite model property"}

In [mathematical logic](wikipedia://en/19636), a logic **L** has the **finite model property** (fmp for short) if any non-[theorem](wikipedia://en/30977#Theorems_in_logic) of **L** is falsified by some *finite* [model](https://en.wikipedia.org/wiki/Model_%28mathematical_logic%29) of **L**. Another way of putting this is to say that **L** has the fmp if for every [formula](wikipedia://en/404582) *A* of **L**, *A* is an **L**-theorem [if and only if](wikipedia://en/14922) *A* is a theorem of the theory of finite models of **L**.

:::

If **L** is finitely axiomatizable (and has a [recursive](https://en.wikipedia.org/wiki/Recursive) set of [inference rules](https://en.wikipedia.org/wiki/Inference_rule)) and has the fmp, then it is [decidable](wikipedia://en/913118). However, the result does not hold if **L** is merely recursively axiomatizable. Even if there are only finitely many finite models to choose from (up to [isomorphism](wikipedia://en/14828)) there is still the problem of checking whether the underlying frames of such models validate the logic, and this may not be decidable when the logic is not finitely axiomatizable, even when it is recursively axiomatizable. (Note that a logic is recursively enumerable if and only if it is recursively axiomatizable, a result known as [Craig's theorem](wikipedia://en/8465779).)

::: {#o3 .example cue=heading name="Example"}

## Example {#Example}

A [first-order](wikipedia://en/10983) formula with one [universal quantification](wikipedia://en/76174) has the fmp. A first-order formula without [function symbols](wikipedia://en/7788156#Definition), where all [existential quantifications](wikipedia://en/91420) appear first in the formula, also has the fmp.[^o4]

:::
