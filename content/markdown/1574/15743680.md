# Negacyclic convolution

::: {#o1 .subject cue=lead name="Negacyclic convolution"}

In mathematics, **negacyclic convolution**[^o2] is a [convolution](wikipedia://en/7519) between two vectors $\mathbf x =(x_1, \dots, x_n)$ and $\mathbf y= (y_1, ..., y_n)$, giving the vector $\mathbf z$ whose components are defined as

:::

$$z_k = x_0 y_k + \cdots + x_k y_0 - (x_{k+1}y_{n-1} + \cdots + x_n y_{k+1}).$$

It is also called skew [circular convolution](wikipedia://en/3367262) or wrapped convolution. It results from multiplication of a skew circulant matrix, generated by vector *a*, with vector *b*.
