# Hermite's cotangent identity

::: {#o1 .subject cue=lead name="Hermite's cotangent identity"}

In [mathematics](wikipedia://en/18831), **Hermite's cotangent identity** is a [trigonometric identity](https://en.wikipedia.org/wiki/Trigonometric_identity) discovered by [Charles Hermite](wikipedia://en/22870422).[^o2] Suppose *a*<sub>1</sub>, ..., *a*<sub>*n*</sub> are [complex numbers](wikipedia://en/5826), no two of which differ by an integer multiple of $\pi$. Let

:::

$$A_{n,k} = \prod_{\begin{smallmatrix} 1 \le j \le n \\ j \neq k \end{smallmatrix}} \cot(a_k - a_j)$$

(in particular, *A*<sub>1,1</sub>, being an [empty product](wikipedia://en/181289), is 1). Then

$$\cot(z - a_1)\cdots\cot(z - a_n) = \cos\frac{n\pi}{2} + \sum_{k=1}^n A_{n,k} \cot(z - a_k).$$

The simplest non-trivial example is the case *n* = 2:

$$\cot(z - a_1)\cot(z - a_2) = -1 + \cot(a_1 - a_2)\cot(z - a_1) + \cot(a_2 - a_1)\cot(z - a_2). \,$$
