# Noisy-storage model

::: {#o1 .subject cue=lead name="Noisy-storage model"}

The **noisy-storage model**[^o2] refers to a cryptographic model employed in [quantum cryptography](wikipedia://en/28676005). It assumes that the [quantum memory](https://en.wikipedia.org/wiki/Quantum_memory) device of an attacker ([adversary](wikipedia://en/789126)) trying to break the protocol is imperfect (noisy). The main goal of this model is to enable the secure implementation of two-party cryptographic primitives, such as [bit commitment](https://en.wikipedia.org/wiki/Bit_commitment), [oblivious transfer](wikipedia://en/554716) and [secure identification](https://en.wikipedia.org/wiki/Smart_Card#Applications).

:::

## Motivation {#Motivation}

Quantum communication has proven to be extremely useful when it comes to distributing encryption keys. It allows two distant parties [Alice and Bob](wikipedia://en/679079) to expand a small initial [secret key](https://en.wikipedia.org/wiki/Secret_key) into an arbitrarily long secret key by sending [qubits](https://en.wikipedia.org/wiki/Qubits) (quantum bits) to each other. Most importantly, it can be shown that any [eavesdropper](https://en.wikipedia.org/wiki/Eavesdropper) trying to listen into their communication cannot intercept any information about the long key. This is known as [quantum key distribution](wikipedia://en/51910) (QKD).

Yet, it has been shown that even quantum communication does not allow the secure implementation of many other two-party cryptographic tasks.[^o4][^o5][^o6][^o7] These all form instances of [secure function evaluation](https://en.wikipedia.org/wiki/Secure_function_evaluation). An example is [oblivious transfer](wikipedia://en/554716). What sets these tasks apart from key distribution is that they aim to solve problems between two parties, Alice and Bob, who do *not* trust each other. That is, there is no outside party like an [eavesdropper](https://en.wikipedia.org/wiki/Eavesdropper), only Alice and Bob. Intuitively, it is this lack of trust that makes the problem hard. Unlike in [quantum key distribution](wikipedia://en/51910), Alice and Bob cannot collaborate to try and detect any eavesdropping activity. Instead, each party has to fend for himself.

Since tasks like [secure identification](https://en.wikipedia.org/wiki/Smart_Card#Applications) are of practical interest, one is willing to make assumptions on how powerful the [adversary](wikipedia://en/789126) can be. Security then holds as long as these assumptions are satisfied. In classical cryptography, i.e., without the use of quantum tools, most of these are [computational assumptions](wikipedia://en/6158383). Such assumptions consists of two parts. First, one assumes that a particular problem is difficult to solve. For example, one might assume that it is hard to [factor](wikipedia://en/15491) a large [integer](wikipedia://en/14563) into its [prime](wikipedia://en/23666) factors (e.g. 15=5x3). Second, one assumes that the adversary has a limited amount of computing power, namely less than what is (thought to be) required to solve the chosen problem.

### Bounded storage {#Bounded_storage}

In [information theoretic cryptography](https://en.wikipedia.org/wiki/Information_theoretic_security) physical assumptions appear, which do not rely on any hardness assumptions, but merely assume a limit on some other resource. In classical cryptography, the **bounded-storage model** introduced by [Ueli Maurer](wikipedia://en/33842913) assumes that the [adversary](wikipedia://en/789126) can only store a certain number of classical bits.[^o9][^o10] Protocols are known that do (in principle) allow the secure implementation of any cryptographic task as long as the adversary's storage is small. Very intuitively, security becomes possible under this assumption since the adversary has to make a choice which information to keep. That is, the protocol effectively overflows his memory device leading to an inevitable lack on information for the adversary. It was later discovered that any classical [protocol](https://en.wikipedia.org/wiki/Protocol_%28object-oriented_programming%29) which requires the honest parties to store $n$ bits in order to execute it successfully can be broken by an adversary that can store more than about $O(n^2)$ bits.[^o11] That is, the gap between what is required to execute the protocol, and what is required to break the security is relatively small.

### Bounded quantum storage {#Bounded_quantum_storage}

This gap changes dramatically when using [quantum communication](https://en.wikipedia.org/wiki/Quantum_communication)[^o13] . That is, Alice and Bob can send [qubits](wikipedia://en/25284) to each other as part of the protocol. Likewise, one now assumes that the adversary's quantum storage is limited to a certain number of qubits. There is no restriction on how many classical bits the adversary can store. This is known as the **bounded-*quantum*-storage model**.[^o13][^o14] It was shown that there exist quantum protocols in which the honest parties need *no* quantum storage at all to execute them, but are nevertheless secure as long as Alice transmits more than twice the number of qubits than the adversary can store.

### Noisy storage {#Noisy_storage}

More generally, security is possible as long as the amount of information that the adversary can store in his memory device is limited. This intuition is captured by the **noisy-storage model**,[^o2] which includes the bounded-quantum-storage model as a special case.[^o16] Such a limitation can, for example, come about if the memory device is extremely large, but very imperfect. In [information theory](wikipedia://en/14773) such an imperfect memory device is also called a [noisy channel](https://en.wikipedia.org/wiki/Noisy_channel). The motivation for this more general model is threefold. First, it allows one to make statements about much more general memory devices that the adversary may have available. Second, security statements could be made when the signals transmitted, or the storage device itself, uses [continuous variables](wikipedia://en/51910) whose dimension is infinite and thus cannot be captured by a bounded storage assumption without additional constraints. Third, even if the dimension of the signals itself is small, the noisy-storage analysis allows security beyond the regime where bounded-storage itself can make any security statement. For example, if the storage channel is entanglement breaking, security is possible even if the storage device is arbitrarily large (i.e., not bounded in any way).

## Assumption {#Assumption}

The assumption of the noisy-storage model is that during waiting times $\Delta t$ introduced into the protocol, the [adversary](wikipedia://en/789126) can only store [quantum information](wikipedia://en/25274) in his noisy memory device.[^o16] Such a device is simply a [quantum channel](wikipedia://en/1013550) $\mathcal{F}:\mathcal{S}(\mathcal{H}_{\rm in}) \rightarrow \mathcal{S}(\mathcal{H}_{\rm out})$ that takes input [states](wikipedia://en/30876419) $\rho_{\rm in} \in \mathcal{S}(\mathcal{H}_{\rm in})$ to some noisy output states $\rho_{\rm out} \in \mathcal{S}(\mathcal{H}_{\rm out})$. Otherwise, the adversary is all powerful. For example, he can store an unlimited amount of classical information and perform any computation instantaneously.

*Image: NoisyStorageModel.png.* During waiting times $\Delta t$ the storage device has to be used.

The latter assumption also implies that he can perform any form of [error correcting encoding](https://en.wikipedia.org/wiki/Error-correcting) before and after using the noisy memory device, even if it is computationally very difficult to do (i.e., it requires a long time). In this context, this is generally referred to as an encoding attack $\mathcal{E}$ and a decoding attack $\mathcal{D}$. Since the adversary's classical memory can be arbitrarily large, the encoding $\mathcal{E}$ may not only generate some [quantum state](wikipedia://en/30876419) as input to the storage device $\mathcal{F}$ but also output classical information. The adversary's decoding attack $\mathcal{D}$ can make use of this extra classical information, as well as any additional information that the adversary may gain after the waiting time has passed.

In practise, one often considers storage devices that consist of $N$ memory cells, each of which is subject to noise. In information-theoretic terms, this means that the device has the form $\mathcal{F} = \mathcal{N}^{\otimes N}$, where $\mathcal{N}: S(\mathbb{C}^d) \rightarrow S(\mathbb{C}^d)$ is a noisy [quantum channel](wikipedia://en/1013550) acting on a memory cell of dimension $d$.

::: {#o19 .example cue=heading name="Examples"}

### Examples {#Examples}

- The storage device consists of $N$ [qubits](wikipedia://en/25284), each of which is subject to [depolarizing noise](https://en.wikipedia.org/wiki/Quantum_depolarizing_channel). That is, $\mathcal{F} = \mathcal{N}^{\otimes N}$, where $\mathcal{N}(\rho) = \lambda \rho + (1-\lambda) \mathsf{id}/2$ is the 2-dimensional [depolarizing channel](https://en.wikipedia.org/wiki/Quantum_depolarizing_channel).
- The storage device consists of $N$ [qubits](wikipedia://en/25284), which are noise-free. This corresponds to the special case of **bounded-quantum-storage**. That is, $\mathcal{F} = \mathsf{id}^{\otimes N}$, where $\mathsf{id}$ is the [identity channel](wikipedia://en/33849734).

:::

## Protocols {#Protocols}

Most protocols proceed in two steps. First, Alice and Bob exchange $n$ [qubits](wikipedia://en/25284) encoded in two or three [mutually unbiased bases](wikipedia://en/20191641). These are the same encodings which are used in the [BB84](wikipedia://en/6178477) or [six-state protocols](https://en.wikipedia.org/wiki/Six-State_Protocol) of [quantum key distribution](wikipedia://en/51910). Typically, this takes the form of Alice sending such qubits to Bob, and Bob measuring them immediately on arrival. This has the advantage that Alice and Bob need no quantum storage to execute the protocol. It is furthermore experimentally relatively easy to create such [qubits](https://en.wikipedia.org/wiki/Qubits), making it possible to implement such protocols using currently available technology.[^o21]

The second step is to perform classical post-processing of the measurement data obtained in step one. Techniques used depend on the protocol in question and include [privacy amplification](https://en.wikipedia.org/wiki/Privacy_amplification), [error-correcting codes](https://en.wikipedia.org/wiki/Error-correcting_codes), min-entropy sampling, and interactive hashing.

### General {#General}

To demonstrate that all [two-party cryptographic tasks](https://en.wikipedia.org/wiki/Secure_function_evaluation) can be implemented securely, a common approach is to show that a simple [cryptographic primitive](wikipedia://en/4928985) can be implemented that is known to be *universal* for [secure function evaluation](https://en.wikipedia.org/wiki/Secure_function_evaluation). That is, once one manages to build a protocol for such a cryptographic primitive all other tasks can be implemented by using this primitive as a basic building block. One such primitive is [oblivious transfer](wikipedia://en/554716). In turn, [oblivious transfer](wikipedia://en/554716) can be constructed from an even simpler building block known as [weak string erasure](https://en.wikipedia.org/wiki/Weak_string_erasure) in combination with cryptographic techniques such as [privacy amplification](https://en.wikipedia.org/wiki/Privacy_amplification).

All protocols proposed to date allow one of the parties (Alice) to have even an unlimited amount of noise-free quantum memory. I.e., the noisy-storage assumption is applied to only one of the parties (Bob). For storage devices of the form $\mathcal{F} = \mathcal{N}^{\otimes N}$ it is known that any [two-party cryptographic task](https://en.wikipedia.org/wiki/Secure_function_evaluation) can be implemented securely by means of [weak string erasure](https://en.wikipedia.org/wiki/Weak_string_erasure) and [oblivious transfer](wikipedia://en/554716) whenever any of the following conditions hold.

- For bounded-quantum-storage (i.e., $\mathcal{N} = \mathsf{id}$), security can be achieved using a protocol in which Alice sends $n > 2N$ [BB84](wikipedia://en/6178477) encoded [qubits](wikipedia://en/25284).[^o16] That is, security can be achieved when Alice sends more than twice the number of qubits than Bob can store. One can also look at this from Bob's perspective and say that security can be achieved when Bob can store strictly less than half of the qubits that Alice sent, i.e., $N < n/2$.
- For bounded-quantum-storage using higher-dimensional memory cells (i.e., each cell is not a [qubit](wikipedia://en/25284), but a [qudit](https://en.wikipedia.org/wiki/Qudit#Variations_of_the_qubit)), security can be achieved in a protocol in which Alice sends $n$ higher-dimensional qudits encoded one of the possible [mutually unbiased bases](wikipedia://en/20191641). In the limit of large dimensions, security can be achieved whenever $n \gtrapprox N$. That is, security can always be achieved as long as Bob cannot store any constant fraction of the transmitted signals.[^o23] This is optimal for the protocols considered since for $n = N$ a dishonest Bob can store all qudits sent by Alice. It is not known whether the same is possible using merely [BB84](wikipedia://en/6178477) encoded qubits.
- For noisy-storage and devices of the form $\mathcal{F} = \mathcal{N}^{\otimes N}$ security can be achieved using a protocol in which Alice sends $n$ [BB84](wikipedia://en/6178477) encoded [qubits](https://en.wikipedia.org/wiki/Qubits) if
- $n > 2 \cdot N \cdot C(\mathcal{N})$,[^o16] where $C(\mathcal{N})$ is the [classical capacity](https://en.wikipedia.org/wiki/Classical_capacity) of the [quantum channel](wikipedia://en/1013550) $\mathcal{N}$, and $\mathcal{N}$ obeys the so-called *strong converse property*,[^o24] or, if
- $n > 2 \cdot N \cdot E_C(\mathcal{N})$,[^o25] where $E_C(\mathcal{N})$ is the [entanglement cost](https://en.wikipedia.org/wiki/Entanglement_cost) of the [quantum channel](wikipedia://en/1013550) $\mathcal{N}$. This is generally much better than the condition on the [classical capacity](https://en.wikipedia.org/wiki/Classical_capacity), however it is harder to evaluate $E_C(\mathcal{N})$.
- For noisy-storage and devices of the form $\mathcal{F} = \mathcal{N}^{\otimes N}$ security can be achieved using a protocol in which Alice sends $n$ [qubits](wikipedia://en/25284) encoded in one of the three [mutually unbiased bases](wikipedia://en/20191641) per qubit, if
- $n > Q(\mathcal{N}) N$,[^o26] where $Q$ is the [quantum capacity](wikipedia://en/31477756) of $\mathcal{N}$, and the strong converse parameter of $\mathcal{N}$ is not too small.

The three [mutually unbiased bases](wikipedia://en/20191641) are the same encodings as in the [six-state protocol](https://en.wikipedia.org/wiki/Six-State_Protocol) of [quantum key distribution](wikipedia://en/51910). The last condition does form the best known condition for most channels, yet the [quantum capacity](wikipedia://en/31477756) as well as the strong converse parameter are generally not easy to determine.

### Specific tasks {#Specific_tasks}

Using such basic primitives as building blocks is not always the most efficient way to solve a cryptographic task. Specialized protocols targeted to solve specific problems are generally more efficient. Examples of known protocols are

- [Bit commitment](https://en.wikipedia.org/wiki/Bit_commitment) in the noisy-storage model,[^o16][^o23] and in the case of bounded-quantum-storage[^o14]
- [Oblivious transfer](wikipedia://en/554716) in the noisy-storage model,[^o16] and in the case of bounded-quantum-storage[^o13][^o14]
- [Secure identification](https://en.wikipedia.org/wiki/Smart_Card#Applications) in the bounded-quantum-storage model[^o28][^o29]

## Noisy-storage and QKD {#Noisy-storage_and_QKD}

The assumption of bounded-quantum-storage has also been applied outside the realm of [secure function evaluation](https://en.wikipedia.org/wiki/Secure_function_evaluation). In particular, it has been shown that if the eavesdropper in [quantum key distribution](wikipedia://en/51910) is memory bounded, higher bit error rates can be tolerated in an experimental implementation.[^o14]
