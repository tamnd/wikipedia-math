# Inverse matrix gamma distribution

::: {#o1 .subject cue=lead name="Inverse matrix gamma distribution"}

In [statistics](wikipedia://en/26685), the **inverse matrix gamma distribution** is a generalization of the [inverse gamma distribution](https://en.wikipedia.org/wiki/Inverse_gamma_distribution) to [positive-definite matrices](https://en.wikipedia.org/wiki/Positive-definite_matrix).[^o2] It is a more general version of the [inverse Wishart distribution](https://en.wikipedia.org/wiki/Inverse_Wishart_distribution), and is used similarly, e.g. as the [conjugate prior](wikipedia://en/846412) of the [covariance matrix](wikipedia://en/191752) of a [multivariate normal distribution](wikipedia://en/50347) or [matrix normal distribution](wikipedia://en/437758). The [compound distribution](https://en.wikipedia.org/wiki/Compound_distribution) resulting from compounding a matrix normal with an inverse matrix gamma prior over the covariance matrix is a [generalized matrix t-distribution](https://en.wikipedia.org/wiki/Generalized_matrix_t-distribution).

:::

This reduces to the [inverse Wishart distribution](https://en.wikipedia.org/wiki/Inverse_Wishart_distribution) with $\nu$ degrees of freedom when $\beta=2, \alpha=\frac{\nu}{2}$.
