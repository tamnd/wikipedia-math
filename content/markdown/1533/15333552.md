# C-minimal theory

::: {#o1 .subject cue=lead name="C-minimal theory"}

In [model theory](wikipedia://en/19858), a branch of [mathematical logic](wikipedia://en/19636), a **C-minimal theory** is a theory that is "minimal" with respect to a [ternary relation](https://en.wikipedia.org/wiki/Triadic_relation) *C* with certain properties. [Algebraically closed fields](wikipedia://en/1018) with a (Krull) [valuation](wikipedia://en/347049) are perhaps the most important example.

:::

This notion was defined in analogy to the [o-minimal theories](wikipedia://en/30865852), which are "minimal" (in the same sense) with respect to a linear order.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A *C*-relation is a ternary relation *C*(*x*; *y*, *z*) that satisfies the following axioms.

1. $$\forall xyz\, [ C(x;y,z)\rightarrow C(x;z,y) ],$$
1. $$\forall xyz\, [ C(x;y,z)\rightarrow\neg C(y;x,z) ],$$
1. $$\forall xyzw\, [ C(x;y,z)\rightarrow (C(w;y,z)\vee C(x;w,z)) ],$$
1. $$\forall xy\, [ x\neq y \rightarrow \exists z\neq y\, C(x;y,z) ].$$

A **C-minimal structure** is a [structure](wikipedia://en/4055928) *M*, in a [signature](wikipedia://en/7788156) containing the symbol *C*, such that *C* satisfies the above axioms and every set of elements of *M* that is definable with parameters in *M* is a Boolean combination of instances of *C*, i.e. of formulas of the form *C*(*x*; *b*, *c*), where *b* and *c* are elements of *M*.

A theory is called **C-minimal** if all of its models are C-minimal. A structure is called **strongly C-minimal** if its theory is C-minimal. One can construct C-minimal structures which are not strongly C-minimal.

:::

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

For a [prime number](wikipedia://en/23666) *p* and a [*p*-adic number](wikipedia://en/51423) *a*, let $\lvert a\rvert$<sub>*p*</sub> denote its *p*-adic absolute value. Then the relation defined by $C(a; b, c) \iff |b-c|_p < |a-c|_p$ is a *C*-relation, and the theory of **Q**<sub>*p*</sub> with addition and this relation is C-minimal. The theory of **Q**<sub>*p*</sub> as a field, however, is not C-minimal.

:::
