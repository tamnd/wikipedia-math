# Ternary numeral system

::: {#o1 .subject cue=lead name="Ternary numeral system"}

A **ternary** [numeral system](wikipedia://en/21170) (also called **base 3** or **trinary**[^o2]) has [three](https://en.wikipedia.org/wiki/3_%28number%29) as its [base](wikipedia://en/701207).

:::

Although *ternary* most often refers to a system in which the three digits are all non-negative numbers (specifically 0, 1, and 2), the adjective also lends its name to the [balanced ternary](wikipedia://en/376757) system. Comprising the digits −1, 0 and +1, balanced ternary is widely used in comparison logic and [ternary computers](https://en.wikipedia.org/wiki/Ternary_computer).

## Information units {#Information_units}

::: {#o5 .pointer-item cue=pointer name="Ternary digit"}

### Trit {#Trit}

A ternary [digit](wikipedia://en/280582) is a **trit** (**tr**inary dig**it**), analogously to a [bit](https://en.wikipedia.org/wiki/Bit). One trit is equivalent to [log<sub>2</sub>](wikipedia://en/249992) 3 (about 1.58496) bits of [information](wikipedia://en/18075548).[^o6] Under classical hardware assumptions, base-3 is theoretically more efficient than binary in terms of [radix economy](https://en.wikipedia.org/wiki/Radix_economy), as 3 is the closest integer to [Euler's number](wikipedia://en/9633) (*e*).[^o7]

:::

### Tribble {#Tribble}

Analogous to the binary [nibble](https://en.wikipedia.org/wiki/Nibble), a **tribble** consists of 3 trits. It can hold 27 distinct states ($3^{3} = 27$), which is roughly equivalent to 4.75 bits of information. Because it has exactly 27 states, a tribble is conveniently represented by a single character in a [septemvigesimal](https://en.wikipedia.org/wiki/Septemvigesimal) (base-27) alphanumeric notation.

::: {#o10 .pointer-item cue=pointer name="Tryte"}

### Tryte {#Tryte}

Analogous to a binary [byte](https://en.wikipedia.org/wiki/Byte), a **tryte** is typically defined as 6 or 9 trits. Early [ternary computers](https://en.wikipedia.org/wiki/Ternary_computer), such as the Soviet [Setun](https://en.wikipedia.org/wiki/Setun), defined a tryte to be six trits.[^o35] A six-trit tryte holds $3^{6} = 729$ states, carrying approximately 9.5 [bits](https://en.wikipedia.org/wiki/Bit) of information—significantly more than the standard 8-bit binary byte (256 states).[^o36] Modern theoretical architectures often favor a 9-trit tryte ($3^{9} = 19,683$ states), as it cleanly divides into three tribbles.

:::

### Word {#Word}

A ternary **word** represents the standard register width for a given ternary architecture. The Setun computer, for instance, operated using an 18-trit word with 9-trit command and memory architectures.[^o36]

### Macro units {#Macro_units}

When scaling to larger data storage capacities, ternary computing nomenclature splits into two distinct conventions depending on the hardware architecture:

- **Native ternary scaling:** In a pure ternary system, macro-units scale by powers of 3 rather than the powers of 2 (1,024) or 10 (1,000) used in binary and decimal systems. A **kilotryte** (KT) in this system is exactly $3^{10}$ (59,049) trytes. Following this pattern, a **megatryte** (MT) is $3^{20}$ trytes, and a **gigatryte** (GT) is $3^{30}$ trytes.
- **Binary-compatible scaling:** In hybrid systems designed to interface directly with existing binary infrastructure, engineers often map ternary groupings to standard binary sizes. Because 5 trits (243 states) fit efficiently within an 8-bit byte (256 states), traditional binary [SI prefixes](https://en.wikipedia.org/wiki/SI_prefixes) are sometimes applied directly to tryte blocks, making a kilotryte equal to 1,024 trytes, and a megatryte equal to 1,048,576 trytes.

## Comparison to other bases {#Comparison_to_other_bases}

Representations of [integer numbers](https://en.wikipedia.org/wiki/Integer_number) in ternary do not get uncomfortably lengthy as quickly as in [binary](https://en.wikipedia.org/wiki/Binary_numeral_system). For example, [decimal](wikipedia://en/8214) 365${}_{10}$ or [senary](wikipedia://en/29652) 1${}_{6}$ corresponds to binary 1${}_{2}$ (nine [bits](https://en.wikipedia.org/wiki/Bit)) and to ternary 111${}_{3}$ (six trits). However, they are still far less compact than the corresponding representations in bases such as decimal – see below for a compact way to codify ternary using nonary (base 9) and [septemvigesimal](https://en.wikipedia.org/wiki/Septemvigesimal) (base 27).

As for [rational numbers](wikipedia://en/19727024), ternary offers a convenient way to represent $\tfrac{1}{3}$ similar to senary (as opposed to its cumbersome representation as an infinite string of [recurring digits](https://en.wikipedia.org/wiki/Recurring_decimal) in decimal); but a major drawback is that, in turn, ternary does not offer a finite representation for $\tfrac{1}{2}$ (nor for $\tfrac{1}{4}$, $\tfrac{1}{8}$, etc.), because [2](https://en.wikipedia.org/wiki/2_%28number%29) has a [prime factor](https://en.wikipedia.org/wiki/Prime_factor) that is not a [factor](wikipedia://en/82341) of the base; as with base two, one-tenth (decimal $\tfrac{1}{10}$, senary $\tfrac{1}{14}$) is not representable exactly (that would need e.g. decimal); nor is one-sixth (senary $\tfrac{1}{10}$, decimal $\tfrac{1}{6}$).

### Sum of the digits in ternary as opposed to binary {#Sum_of_the_digits_in_ternary_as_opposed_to_binary}

The value of a binary number with $n$ bits that are all 1 is $2^{n} - 1$.

Similarly, for a number $N(b, d)$ with base $b$ and $d$ digits, all of which are the maximal digit value $b - 1$, we can write the geometric progression:

$$\begin{aligned} N(b, d) &= (b - 1)b^{d-1} + (b - 1)b^{d-2} + \dots + (b - 1)b^0 \\ &= (b - 1)(b^{d-1} + b^{d-2} + \dots + 1) \\ &= (b - 1)M. \end{aligned}$$

Multiplying $M$ by $b$ yields:

$$bM = b^d + b^{d-1} + \dots + b^1$$

Subtracting $M$ from $bM$ isolates the boundary values:

$$bM - M = b^d - 1$$

$$M = \frac{b^d - 1}{b - 1}$$

Substituting this back into the original equation for $N(b, d)$ demonstrates that the maximum value for any base matches the boundary behavior of binary:

$$N(b, d) = (b - 1)\left(\frac{b^d - 1}{b - 1}\right) = b^d - 1.$$

For a three-digit ternary number, $N(3, 3) = 3^3 - 1 = 26 = (2 \times 3^2) + (2 \times 3^1) + (2 \times 3^0) = 18 + 6 + 2$.

## Practical use {#Practical_use}

*Image: fewest\_weights\_balance\_puzzle.svg.* Use of ternary numbers to balance an unknown integer weight from 1 to 40 kg with weights of 1, 3, 9 and 27 kg (4 ternary digits actually gives $3^{4} = 81$ possible combinations: −40 to +40, but only the positive values are useful)

In certain analog logic, the state of the circuit is often expressed ternary. This is most commonly seen in [CMOS](https://en.wikipedia.org/wiki/CMOS) circuits, and also in [transistor–transistor logic](https://en.wikipedia.org/wiki/Transistor–transistor_logic) with [totem-pole output](https://en.wikipedia.org/wiki/Push–pull_output). The output is said to either be low ([grounded](https://en.wikipedia.org/wiki/Ground_%28electricity%29)), high, or open ([high-*Z*](https://en.wikipedia.org/wiki/High_impedance)). In this configuration the output of the circuit is actually not connected to any [voltage](https://en.wikipedia.org/wiki/Voltage) reference at all. Where the signal is usually grounded to a certain reference, or at a certain voltage level, the state is said to be high [impedance](https://en.wikipedia.org/wiki/Electrical_impedance) because it is open and serves its own reference. Thus, the actual voltage level is sometimes unpredictable.

A rare "ternary point" in common use occurs in defensive statistics in American [baseball](https://en.wikipedia.org/wiki/Baseball) (specifically for [pitchers](https://en.wikipedia.org/wiki/Pitcher)) to denote fractional parts of an inning. Because an offensive team is allowed three [outs](https://en.wikipedia.org/wiki/Out_%28baseball%29) per half-inning, each out represents exactly one-third of a defensive inning and is colloquially written as a decimal point followed by the number of outs.

For example, if a player pitches all of the 4th, 5th, and 6th innings, and records exactly 2 outs in the 7th inning, their [innings pitched](https://en.wikipedia.org/wiki/Innings_pitched) (IP) statistic would be listed as **\3.2**. This represents $3\tfrac{2}{3}$ innings pitched (a notation sometimes preferred by traditional record keepers). In this specific sport context, only the fractional part of the number is structurally calculated in base 3.[^o23]

Ternary numbers can be used to convey self-similar structures like the [Sierpinski triangle](wikipedia://en/29638) or the [Cantor set](wikipedia://en/6172) conveniently. Additionally, it turns out that the ternary representation is useful for defining the Cantor set and related point sets, because of the way the Cantor set is constructed. The Cantor set consists of the points from 0 to 1 that have a ternary expression that does not contain any instance of the digit 1. Any terminating expansion in the ternary system is equivalent to the expression that is identical up to the term preceding the last non-zero term followed by the term one less than the last non-zero term of the first expression, followed by an infinite tail of twos. For example: 0.1020 is equivalent to 0.1012222... because the expansions are the same until the "two" of the first expression, the two was decremented in the second expansion, and trailing zeros were replaced with trailing twos in the second expression.

Ternary is the integer base with the lowest [radix economy](https://en.wikipedia.org/wiki/Radix_economy), followed closely by [binary](https://en.wikipedia.org/wiki/Binary_numeral_system) and [quaternary](wikipedia://en/357685). This is due to its proximity to the [mathematical constant](wikipedia://en/48779551) [*e*](wikipedia://en/9633). It has been used for some computing systems because of this efficiency. It is also used to represent three-option *trees*, such as phone menu systems, which allow a simple path to any branch.

### Balanced ternary advantages {#Balanced_ternary_advantages}

When implemented as [balanced ternary](wikipedia://en/376757) (comprising the digits −1, 0, and +1), the numeral system offers distinct computational advantages over binary. Most notably, balanced ternary eliminates the need for an explicit [sign bit](https://en.wikipedia.org/wiki/Sign_bit), as the sign of a number is inherently determined by its most significant non-zero digit. Furthermore, mathematical negation is highly efficient, requiring only a simple entrywise inversion of symbols (swapping +1s and −1s) rather than the complex two's complement operations required by binary hardware.[^o25]

A form of [redundant binary representation](https://en.wikipedia.org/wiki/Redundant_binary_representation) called a binary signed-digit number system, a form of [signed-digit representation](wikipedia://en/1181818), is sometimes used in low-level software and hardware to accomplish fast addition of integers because it can eliminate [carries](wikipedia://en/1629687).[^o30]

::: {#o27 .pointer-item cue=pointer name="Binary-coded ternary"}

### Binary-coded ternary {#Binary-coded_ternary}

Simulation of ternary computers using binary computers, or interfacing between ternary and binary computers, can involve use of binary-coded ternary (BCT) numbers, with two or three bits used to encode each trit.[^o31][^o32] BCT encoding is analogous to [binary-coded decimal](https://en.wikipedia.org/wiki/Binary-coded_decimal) (BCD) encoding. If the trit values 0, 1 and 2 are encoded 00, 01 and 10, conversion in either direction between binary-coded ternary and binary can be done in [logarithmic time](wikipedia://en/405944#Logarithmic_time).[^o33] A library of [C code](https://en.wikipedia.org/wiki/C_%28programming_language%29) supporting BCT arithmetic is available.[^o34]

:::
