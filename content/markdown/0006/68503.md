# Pseudometric space

::: {#o1 .subject cue=lead name="Pseudometric space"}

In [mathematics](wikipedia://en/18831), a **pseudometric space** is a [generalization](wikipedia://en/12746) of a [metric space](wikipedia://en/20018) in which the distance between two distinct points can be zero. Pseudometric spaces were introduced by [Đuro Kurepa](wikipedia://en/3130558)[^o2][^o3] in 1934. In the same way as every [normed space](https://en.wikipedia.org/wiki/Normed_space) is a [metric space](wikipedia://en/20018), every [seminormed space](https://en.wikipedia.org/wiki/Seminormed_space) is a pseudometric space. Because of this analogy, the term [semimetric space](https://en.wikipedia.org/wiki/Semimetric_space) (which has a different meaning in [topology](wikipedia://en/29954)) is sometimes used as a synonym, especially in [functional analysis](wikipedia://en/11180).

:::

When a topology is generated using a family of pseudometrics, the space is called a [gauge space](https://en.wikipedia.org/wiki/Gauge_space).

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

A pseudometric space $(X,d)$ is a set $X$ together with a non-negative [real-valued function](wikipedia://en/22284647) $d : X \times X \longrightarrow \mathbb{R}_{\geq 0},$ called a **pseudometric**, such that for every $x, y, z \in X,$

1. $$d(x,x) = 0.$$
1. *Symmetry*: $d(x,y) = d(y,x)$
1. *[Subadditivity](wikipedia://en/745789)*/*[Triangle inequality](wikipedia://en/53941)*: $d(x,z) \leq d(x,y) + d(y,z)$

Unlike a metric space, points in a pseudometric space need not be [distinguishable](wikipedia://en/630398); that is, one may have $d(x, y) = 0$ for distinct values $x \neq y.$

It is worth noting that Symmetry and classical Triangle inequality can be replaced with single modified Triangle one: $d(x,y) \leq d(x,z) + d(y,z)$. This inequality combines symmetry and classical Triangle inequality.

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

Any metric space is a pseudometric space. Pseudometrics arise naturally in [functional analysis](wikipedia://en/11180). Consider the space $\mathcal{F}(X)$ of real-valued functions $f : X \to \mathbb{R}$ together with a special point $x_0 \in X.$ This point then induces a pseudometric on the space of functions, given by

$$d(f,g) = \left|f(x_0) - g(x_0)\right|$$

for $f, g \in \mathcal{F}(X)$

A [seminorm](wikipedia://en/292067) $p$ induces the pseudometric $d(x, y) = p(x - y)$. This is a [convex function](wikipedia://en/245568) of an [affine function](https://en.wikipedia.org/wiki/Affine_function) of $x$ (in particular, a [translation](wikipedia://en/204682)), and therefore convex in $x$. (Likewise for $y$.)

Conversely, a homogeneous, translation-invariant pseudometric induces a seminorm.

Pseudometrics also arise in the theory of [hyperbolic](wikipedia://en/1589135) [complex manifolds](wikipedia://en/509742): see [Kobayashi metric](wikipedia://en/31025902).

Every [measure space](wikipedia://en/45270) $(\Omega,\mathcal{A},\mu)$ can be viewed as a complete pseudometric space by defining

$$d(A,B) := \mu(A \vartriangle B)$$

for all $A, B \in \mathcal{A},$ where the triangle denotes [symmetric difference](wikipedia://en/262288).

If $f : X_1 \to X_2$ is a function and *d*<sub>2</sub> is a pseudometric on *X*<sub>2</sub>, then $d_1(x, y) := d_2(f(x), f(y))$ gives a pseudometric on *X*<sub>1</sub>. If *d*<sub>2</sub> is a metric and *f* is [injective](wikipedia://en/45196), then *d*<sub>1</sub> is a metric.

:::

::: {#o9 .pointer-item cue=pointer name="Pseudometrisable space"}

## Topology {#Topology}

The **pseudometric topology** is the [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29) generated by the [open balls](https://en.wikipedia.org/wiki/Open_balls)

$$B_r(p) = \{x \in X : d(p, x) < r\},$$

which form a [basis](https://en.wikipedia.org/wiki/Basis_%28topology%29) for the topology. A topological space is said to be a **pseudometrizable space**[^o11] if the space can be given a pseudometric such that the pseudometric topology coincides with the given topology on the space.

The difference between pseudometrics and metrics is entirely topological. That is, a pseudometric is a metric if and only if the topology it generates is [T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space) (that is, distinct points are [topologically distinguishable](https://en.wikipedia.org/wiki/Topologically_distinguishable)).

The definitions of [Cauchy sequences](wikipedia://en/6085) and [metric completion](https://en.wikipedia.org/wiki/Completion_%28metric_space%29) for metric spaces carry over to pseudometric spaces unchanged.[^o12] The notion of a [continuous function](wikipedia://en/6122) is also largely unchanged when applied to a pseudometric space.

:::

## Metric identification {#Metric_identification}

The vanishing of the pseudometric induces an [equivalence relation](wikipedia://en/9259), called the **metric identification**, that converts the pseudometric space into a full-fledged [metric space](wikipedia://en/20018). This is done by defining $x\sim y$ if $d(x,y)=0$. Let $X^* = X/{\sim}$ be the [quotient space](wikipedia://en/237213) of $X$ by this equivalence relation and define

$$\begin{aligned} d^*:(X/\sim)&\times (X/\sim) \longrightarrow \mathbb{R}_{\geq 0} \\ d^*([x],[y])&=d(x,y) \end{aligned}$$

This is well defined because for any $x' \in [x]$ we have that $d(x, x') = 0$ and so $d(x', y) \leq d(x, x') + d(x, y) = d(x, y)$ and vice versa. Then $d^*$ is a metric on $X^*$ and $(X^*,d^*)$ is a well-defined metric space, called the **metric space induced by the pseudometric space** $(X, d)$.[^o14][^o15]

The metric identification preserves the induced topologies. That is, a subset $A \subseteq X$ is open (or closed) in $(X, d)$ if and only if $\pi(A) = [A]$ is open (or closed) in $\left(X^*, d^*\right)$ and $A$ is [saturated](wikipedia://en/26592789). The topological identification is the [Kolmogorov quotient](https://en.wikipedia.org/wiki/Kolmogorov_quotient).

An example of this construction is the [completion of a metric space](wikipedia://en/7832#Completion) by its [Cauchy sequences](https://en.wikipedia.org/wiki/Cauchy_sequences).

::: {#o17 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- In a pseudometric space, the set of all points (say, X) which are of distance 0 relative to another set Y in the space is the closure of Y, or cl(Y) = X.[^o18]
