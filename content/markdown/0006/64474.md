# Concatenation

::: {#o1 .subject cue=lead name="Concatenation"}

Z10000

*Image: 20241229 Using concatenate function in spreadsheet to create SVG code - demo.svg.* A spreadsheet's concatenate ("&") function is used to assemble a complex text string—in this example, [XML](https://en.wikipedia.org/wiki/XML) code for an [SVG](https://en.wikipedia.org/wiki/SVG) "circle" element.

In [formal language theory](wikipedia://en/10939) and [computer programming](https://en.wikipedia.org/wiki/Computer_programming), **concatenation** is the operation of joining sequential objects, such as [character strings](https://en.wikipedia.org/wiki/Character_string_%28computer_science%29), [files](https://en.wikipedia.org/wiki/Computer_file), [lists](https://en.wikipedia.org/wiki/List_%28abstract_data_type%29) or pieces of [audio](https://en.wikipedia.org/wiki/Recorded_sound) or [video](https://en.wikipedia.org/wiki/Video), end-to-end. For example, the concatenation of "snow" and "ball" is "snowball". In certain formalizations of [concatenation theory](wikipedia://en/40965300), also called string theory, string concatenation is a [primitive notion](wikipedia://en/23706).

:::

::: {#o3 .definition kind=definition/notation cue=heading name="Terminology"}

## Terminology {#Terminology}

To *concatenate* is to join two or more sequential objects together to create a new object, generally without modifying any of the original objects.

To *append* is to modify a sequential object by adding material at the end. Thus to append *a* to *b* is to modify *b* to be equal to the concatenation of the original value of *b* and *a*. Despite this, in some [high-level programming languages](https://en.wikipedia.org/wiki/High-level_programming_language), especially functional and logical ones, **`append`** is the operation for concatenating lists or [arrays](https://en.wikipedia.org/wiki/Array_data_type) without modifying the originals.

To *prepend* is to modify a sequential object by adding material at the beginning. Thus to prepend *a* to *b* is to modify *b* to be equal to the concatenation of *a* and the original value of *b*.

:::

## Syntax {#Syntax}

In many [programming languages](wikipedia://en/23015), string concatenation is a [binary](wikipedia://en/3948) [infix operator](https://en.wikipedia.org/wiki/Infix_operator), and in some it is written without an operator. Furthermore, the notation may be specific to string concatenation or support concatenation of various sequential data types depending on the language. Examples include:

- [Overloading](https://en.wikipedia.org/wiki/Operator_overloading) the plus sign `+`, such as most [BASICs](https://en.wikipedia.org/wiki/BASIC) and C#: `"Hello, " + "World"` has the value `"Hello, World"`.
- Dedicated operator, such as `.` in [PHP](https://en.wikipedia.org/wiki/PHP), `&` in [Visual Basic](https://en.wikipedia.org/wiki/Visual_Basic),[^o5] `||` in [SQL](wikipedia://en/29004)[^o6][^o7] and `~` in [D](https://en.wikipedia.org/wiki/D_%28programming_language%29).[^o8] Advantages over reusing `+` may include supporting implicit [type conversion](https://en.wikipedia.org/wiki/Type_conversion) to strings and distinguishing numeric array/list concatenation from [vector addition](https://en.wikipedia.org/wiki/Vector_addition), depending on the language.
- [String literal concatenation](https://en.wikipedia.org/wiki/String_literal_concatenation), in which adjacent strings are concatenated without any operator. Example from C: `"Hello, " "World"` has the value `"Hello, World"`.
- [Interpolation](https://en.wikipedia.org/wiki/String_interpolation), using a special syntax to embed variables or expressions within strings. Example from C#: `$"{hello}{world}"`, where `string hello = "Hello, ";` and `string world = "World";`
- Formatting, using a string formatter to concatenate. Example from Java: `String.format("%s%s", "Hello, ", "World")`

In many scientific publications or standards the concatenation operator notation used is `||`.[^o9]

### Lisp {#Lisp}

The `append` procedure takes zero or more [(linked) lists](https://en.wikipedia.org/wiki/Linked_list) as arguments, and returns the concatenation of these lists.

```lisp
(append '(1 2 3) '(a b) '() '(6))
;Output: (1 2 3 a b 6)
```

Since the `append` procedure must completely copy all of its arguments except the last, both its [time and space complexity](wikipedia://en/7543) are [O(*n*)](wikipedia://en/44578) for a list of $n$ elements. It may thus be a source of inefficiency if used injudiciously in code.

The `nconc` procedure (called `append!` in [Scheme](https://en.wikipedia.org/wiki/Scheme_%28programming_language%29)) performs the same function as `append`, but [destructively](https://en.wikipedia.org/wiki/In-place_algorithm): it alters the [cdr](https://en.wikipedia.org/wiki/Car_and_cdr) of each argument (save the last), pointing it to the next list.

::: {#o12 .definition kind=definition/construction cue=heading name="Implementation"}

#### Implementation {#Implementation}

`Append` can easily be defined [recursively](wikipedia://en/25407) in terms of `[[cons]]`. The following is a simple implementation in Scheme, for two arguments only:

```scheme
(define append
  (lambda (ls1 ls2)
    (if (null? ls1)
      ls2
      (cons (car ls1) (append (cdr ls1) ls2)))))
```

Append can also be implemented using fold-right:

```scheme
(define append
   (lambda (a b)
      (fold-right cons b a)))
```

:::

### Prolog {#Prolog}

The [logic programming](https://en.wikipedia.org/wiki/Logic_programming) language [Prolog](wikipedia://en/23485) features a built-in `append` predicate, which can be implemented as follows:

```prolog
append([],Ys,Ys).
append([X|Xs],Ys,[X|Zs]) :-
    append(Xs,Ys,Zs).
```

This predicate can be used for appending, but also for picking lists apart. Calling

```prolog
 ?- append(L,R,[1,2,3]).
```

yields the solutions:

L = \[\], R = \[1, 2, 3\] ; L = \[1\], R = \[2, 3\] ; L = \[1, 2\], R = \[3\] ; L = \[1, 2, 3\], R = \[\]

### Miranda {#Miranda}

In [Miranda](https://en.wikipedia.org/wiki/Miranda_%28programming_language%29), this right-[fold](https://en.wikipedia.org/wiki/Fold_%28higher-order_function%29), from Hughes (1989:5-6), has the same semantics (by example) as the Scheme implementation above, for two arguments.

append a b = reduce cons b a

Where reduce is Miranda's name for [fold](https://en.wikipedia.org/wiki/Fold_%28higher-order_function%29), and [cons](https://en.wikipedia.org/wiki/Cons) constructs a list from two values or lists.

For example,

append \[1,2\] \[3,4\] = reduce cons \[3,4\] \[1,2\] = (reduce cons \[3,4\]) (cons 1 (cons 2 nil)) = cons 1 (cons 2 \[3,4\])) (replacing cons by cons and nil by \[3,4\]) = \[1,2,3,4\]

### Haskell {#Haskell}

In [Haskell](https://en.wikipedia.org/wiki/Haskell), this right-[fold](https://en.wikipedia.org/wiki/Fold_%28higher-order_function%29) has the same effect as the Scheme implementation above:

```haskell
append :: [a] -> [a] -> [a]
append xs ys = foldr (:) ys xs
```

This is essentially a reimplementation of Haskell's `++` operator.

### Perl {#Perl}

In [Perl](https://en.wikipedia.org/wiki/Perl), the push function is equivalent to the append method, and can be used in the following way.

```perl
my @list;
push @list, 1;
push @list, 2, 3;
```

The end result is a list containing \[1, 2, 3\]

The unshift function appends to the front of a list, rather than the end

```perl
my @list;
unshift @list, 1;
unshift @list, 2, 3;
```

The end result is a list containing \[2, 3, 1\]

When opening a file, use the ">>" mode to append rather than over write.

```perl
open(my $fh, '>>', "/some/file.txt");
print $fh "Some new text\n";
close $fh;
```

Note that when opening and closing file handles, one should always check the return value.

### Python {#Python}

In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), use the list method extend or the infix operators + and += to append lists.

```pycon
>>> l = [1, 2]
>>> l.extend([3, 4, 5])
>>> l
[1, 2, 3, 4, 5]
>>> l + [6, 7]
[1, 2, 3, 4, 5, 6, 7]
```

Do not confuse with the list method append, which adds a **single** element to a list:

```pycon
>>> l = [1, 2]
>>> l.append(3)
>>> l
[1, 2, 3]
```

### Bash {#Bash}

In [Bash](https://en.wikipedia.org/wiki/Bash_%28Unix_shell%29) the append redirect is the usage of ">>" for adding a stream to something, like in the following series of shell commands:

```bash
echo Hello world! >text; echo Goodbye world! >>text; cat text
```

The stream "Goodbye world!" is added to the text file written in the first command. The ";" implies the execution of the given commands in order, not simultaneously. So, the final content of the text file is:

Hello world! Goodbye world!

### Other languages {#Other_languages}

Other [high-level programming languages](https://en.wikipedia.org/wiki/High-level_programming_language) which feature [linked lists](https://en.wikipedia.org/wiki/Linked_list) as primitive [data structures](wikipedia://en/8519) have adopted an `append`. To append lists, as an [operator](https://en.wikipedia.org/wiki/Operator_%28computer_programming%29), [Haskell](https://en.wikipedia.org/wiki/Haskell) uses `++`, [OCaml](https://en.wikipedia.org/wiki/OCaml) uses `@`. Other languages use the `+` or `++` symbols to nondestructively concatenate a [string](wikipedia://en/27701), list, or array.

## Implementation {#Implementation}

In programming, string concatenation generally occurs at run time, as string values are typically not known until run time. However, in the case of string literals, the values are known at compile time, and thus string concatenation can be done at compile time either via [string literal concatenation](https://en.wikipedia.org/wiki/String_literal_concatenation) or via [constant folding](https://en.wikipedia.org/wiki/Constant_folding), a potential run-time optimization.

:::

## Concatenation of sets of strings {#Concatenation_of_sets_of_strings}

In [formal language theory](wikipedia://en/10939) and [pattern matching](https://en.wikipedia.org/wiki/Pattern_matching) (including [regular expressions](https://en.wikipedia.org/wiki/Regular_expressions)), the concatenation operation on strings is generalised to an operation on sets of strings as follows:

For two sets of strings *S*<sub>1</sub> and *S*<sub>2</sub>, the *concatenation* *S*<sub>1</sub>*S*<sub>2</sub> consists of all strings of the form *vw* where *v* is a string from *S*<sub>1</sub> and *w* is a string from *S*<sub>2</sub>, or formally $S_{1}S_{2} = \{vw : v \in S_{1}, w \in S_{2}\}$. Many authors also use concatenation of a string set and a single string, and vice versa, which are defined similarly by $S_{1}w = \{vw : v \in S_{1}\}$ and $vS_{2} = \{vw : w \in S_{2}\}$. In these definitions, the string *vw* is the ordinary concatenation of strings *v* and *w* as defined in the introductory section.

For example, if $F = \{a, b, c, d, e, f, g, h\}$, and $R = \{1, 2, 3, 4, 5, 6, 7, 8\}$, then *FR* denotes the set of all [chess board](https://en.wikipedia.org/wiki/Chess_board) coordinates in [algebraic notation](https://en.wikipedia.org/wiki/Algebraic_notation_%28chess%29), while e*R* denotes the set of all coordinates of the kings' [file](https://en.wikipedia.org/wiki/File_%28chess%29).

In this context, sets of strings are often referred to as formal languages. The concatenation operator is usually expressed as simple juxtaposition (as with [multiplication](wikipedia://en/20845)).

::: {#o24 .statement kind=statement/fact cue=heading name="Algebraic properties"}

## Algebraic properties {#Algebraic_properties}

The strings over an alphabet, with the concatenation operation, form an [associative](wikipedia://en/1335) algebraic structure called a [free monoid](wikipedia://en/523166). The [identity element](wikipedia://en/14962) is the [null string](https://en.wikipedia.org/wiki/Null_string).

Sets of strings with concatenation and [alternation](https://en.wikipedia.org/wiki/Alternation_%28formal_language_theory%29) form a [semiring](wikipedia://en/371468), with concatenation [distributing](wikipedia://en/103118) over alternation. The identity for alternation (the 0 element) is the [empty set](wikipedia://en/9566) and identity for concatenation (the 1 element) is the set containing just the null string.

:::

## Applications {#Applications}

### Audio and telephony {#Audio_and_telephony}

In programming for telephony, concatenation is used to provide dynamic audio feedback to a user. For example, in a "time of day" [speaking clock](https://en.wikipedia.org/wiki/Speaking_clock), concatenation is used to give the correct time by playing the appropriate recordings concatenated together. For example: "at the tone, the time will be", "eight", "thirty", "five", "and", "twenty", "five", "seconds".

The recordings themselves exist separately, but playing them one after the other provides a grammatically correct sentence to the listener.

This technique is also used in number change announcements, [voice mail](https://en.wikipedia.org/wiki/Voice_mail) systems, or most telephony applications that provide dynamic feedback to the caller (e.g. [moviefone](https://en.wikipedia.org/wiki/Moviefone), [tellme](https://en.wikipedia.org/wiki/Tellme), and others).

Programming for any kind of computerised public address system can also employ concatenation for dynamic public announcements (for example, flights in an airport). The system would archive recorded speech of numbers, routes or airlines, destinations, times, etc. and play them back in a specific sequence to produce a grammatically correct sentence that is announced throughout the facility.

### Database theory {#Database_theory}

One of the principles of [relational database](https://en.wikipedia.org/wiki/Relational_database) design is that the fields of data tables should reflect a single characteristic of the table's subject, which means that they should not contain concatenated strings. When concatenation is desired in a report, it should be provided at the time of running the report. For example, to display the physical address of a certain customer, the data might include building number, street name, building sub-unit number, city name, state/province name, postal code, and country name, e.g., "123 Fake St Apt 4, Boulder, CO 80302, USA", which combines seven fields. However, the customers data table should not use one field to store that concatenated string; rather, the concatenation of the seven fields should happen upon running the report. The reason for such principles is that without them, the entry and updating of large volumes of data becomes error-prone and labor-intensive. Separately entering the city, state, ZIP code, and nation allows data-entry validation (such as detecting an invalid state abbreviation). Then those separate items can be used for sorting or indexing the records, such as all with "Boulder" as the city name.

### Recreational mathematics {#Recreational_mathematics}

In [recreational mathematics](wikipedia://en/26446), many problems concern the properties of numbers under concatenation of their numerals in some [base](wikipedia://en/701207). Examples include [home primes](wikipedia://en/30033327) (primes obtained by repeatedly factoring the increasing concatenation of prime factors of a given number), [Smarandache–Wellin numbers](wikipedia://en/439984) (the concatenations of the first [prime numbers](wikipedia://en/23666)), and the [Champernowne](wikipedia://en/541351) and [Copeland–Erdős constants](wikipedia://en/3904191) (the real numbers formed by the decimal representations of the [positive integers](https://en.wikipedia.org/wiki/Positive_integers) and the prime numbers, respectively).
