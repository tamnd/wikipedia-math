# Andrews plot

*Image: Andrews curve for Iris data set.png.* An Andrews curve for the Iris data set

::: {#o1 .subject cue=lead name="Andrews plot"}

In [data visualization](https://en.wikipedia.org/wiki/Data_visualization), an **Andrews plot** or **Andrews curve** is a way to visualize structure in high-dimensional data. It is basically a rolled-down, non-integer version of the Kent–Kiviat [radar m chart](wikipedia://en/8432961), or a smoothed version of a [parallel coordinate plot](wikipedia://en/1254148). It is named after the statistician David F. Andrews.[^o2][^o3][^o4][^o5]

:::

A value $x$ is a [high-dimensional datapoint](wikipedia://en/1482083) if it is an element of $\mathbb R ^d$. We can represent high-dimensional data with a number for each of their dimensions, $x = \left \{ x_1, x_2, \ldots, x_d \right \}$. To visualize them, the Andrews plot defines a finite [Fourier series](wikipedia://en/59038):

$$f_x(t) = \frac{x_1}{\sqrt 2} + x_2 \sin(t) + x_3 \cos(t) + x_4 \sin(2t) + x_5 \cos(2t) + \cdots$$

This function is then plotted for $-\pi < t < \pi$. Thus each data point may be viewed as a line between $-\pi$ and $\pi$. This formula can be thought of as the projection of the data point onto the vector:

$$\left ( \frac 1 {\sqrt 2}, \sin(t), \cos(t), \sin(2t), \cos(2t), \ldots \right )$$

If there is structure in the data, it may be visible in the Andrews curves of the data.

These curves have been utilized in fields as different as [biology](https://en.wikipedia.org/wiki/Biology), [neurology](https://en.wikipedia.org/wiki/Neurology), [sociology](https://en.wikipedia.org/wiki/Sociology) and [semiconductor](https://en.wikipedia.org/wiki/Semiconductor) manufacturing. Some of their uses include the [quality control](wikipedia://en/41613) of products, the detection of period and [outliers](wikipedia://en/160951) in [time series](wikipedia://en/406624), the visualization of learning in [artificial neural networks](https://en.wikipedia.org/wiki/Artificial_neural_network), and correspondence analysis.

Theoretically, it is possible to project them onto an [*n*-sphere](wikipedia://en/39782). The projection onto the circle results in the aforementioned [radar chart](wikipedia://en/8432961).
