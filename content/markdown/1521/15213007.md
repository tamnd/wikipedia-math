# MLwiN

::: {#o2 .subject cue=lead name="MLwiN"}

**MLwiN** is a [statistical software](https://en.wikipedia.org/wiki/Statistical_software) package for fitting [multilevel models](wikipedia://en/4521038). It uses both [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimation and [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC) methods. MLwiN is based on an earlier package, [MLn](https://en.wikipedia.org/wiki/MLn), but with a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) (as well as other additional features).[^o3] MLwiN represents multilevel models using [mathematical notation](wikipedia://en/277184) including Greek letters and multiple [subscripts](https://en.wikipedia.org/wiki/Subscript), so the user needs to be (or become) familiar with such notation.

:::

For a tutorial introduction to multilevel models and their applications in [medical statistics](wikipedia://en/11082896) illustrated using MLwiN, see Goldstein *et al.*[^o4]
