# Restricted maximum likelihood

::: {#o1 .subject cue=lead name="Restricted maximum likelihood"}

In [statistics](wikipedia://en/26685), the **restricted** (or **residual**, or **reduced**) **maximum likelihood** (**REML**) approach is a particular form of [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimation that does not base estimates on a maximum likelihood fit of all the information, but instead uses a [likelihood function](wikipedia://en/44968) calculated from a transformed set of data, so that [nuisance parameters](wikipedia://en/979528) have no effect.[^o2]

:::

In the case of [variance component](https://en.wikipedia.org/wiki/Variance_component) estimation, the original data set is replaced by a set of [contrasts](wikipedia://en/5611564) calculated from the data, and the likelihood function is calculated from the probability distribution of these contrasts, according to the model for the complete data set. In particular, REML is used as a method for fitting linear [mixed models](wikipedia://en/5431921). In contrast to the earlier [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimation, REML can produce [unbiased](wikipedia://en/184099) estimates of variance and covariance parameters.[^o3]

The idea underlying REML estimation was put forward by [M. S. Bartlett](wikipedia://en/865429) in 1937.[^o2][^o4] The first description of the approach applied to estimating components of variance in unbalanced data was by [Desmond Patterson](https://en.wikipedia.org/wiki/Desmond_Patterson) and [Robin Thompson](https://en.wikipedia.org/wiki/Robin_Thompson_%28statistician%29)[^o2][^o5] of the [University of Edinburgh](https://en.wikipedia.org/wiki/University_of_Edinburgh) in 1971, although they did not use the term REML. A review of the early literature was given by Harville.[^o6]

REML estimation is available in a number of general-purpose [statistical software](https://en.wikipedia.org/wiki/Statistical_software) packages, including [Genstat](wikipedia://en/3829976) (the REML directive), [SAS](wikipedia://en/990677) (the MIXED procedure), [SPSS](wikipedia://en/179088) (the MIXED command), [Stata](wikipedia://en/1809002) (the mixed command), [JMP (statistical software)](wikipedia://en/1979375), and [R](wikipedia://en/376707) (especially the [lme4](https://cran.r-project.org/web/packages/lme4/index.html) and older [nlme](https://cran.r-project.org/web/packages/nlme/index.html) packages), as well as in more specialist packages such as [MLwiN](wikipedia://en/15213007), [HLM](http://www.ssicentral.com/hlm/), [ASReml](wikipedia://en/15092456), [BLUPF90](https://en.wikipedia.org/wiki/BLUPF90), [wombat](http://didgeridoo.une.edu.au/km/wombat.php), [Statistical Parametric Mapping](https://en.wikipedia.org/wiki/Statistical_Parametric_Mapping) and [CropStat](http://archive.irri.org/science/software/cropstat.asp).

REML estimation is implemented in [Surfstat](http://www.math.mcgill.ca/keith/surfstat/), a [Matlab](https://en.wikipedia.org/wiki/Matlab) toolbox for the statistical analysis of univariate and multivariate surface and volumetric neuroimaging data using linear mixed effects models and random field theory,[^o7][^o8] but more generally in the fitlme package for modeling linear mixed effects models in a domain-general way.[^o9]
