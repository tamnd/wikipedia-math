# MPIR (mathematics software)

::: {#o3 .subject cue=lead name="MPIR"}

**Multiple Precision Integers and Rationals** (**MPIR**) is an [open-source software](https://en.wikipedia.org/wiki/Open-source_software) [multiprecision integer](wikipedia://en/600892) [library](https://en.wikipedia.org/wiki/Library_%28computing%29) [forked](https://en.wikipedia.org/wiki/Fork_%28software_development%29) from the [GNU Multiple Precision Arithmetic Library](https://en.wikipedia.org/wiki/GNU_Multiple_Precision_Arithmetic_Library) (GMP) project. It consists of much code from past GMP releases, and some original contributed code.

:::

According to the MPIR-devel mailing list, "MPIR is no longer maintained",[^o4] except for building the old code on Windows using new versions of Microsoft Visual Studio.

According to the MPIR developers, some of the main goals of the MPIR project were:

- Maintaining [compatibility](https://en.wikipedia.org/wiki/Computer_compatibility#Software_compatibility) with GMP – so that MPIR can be used as a replacement for GMP.
- Providing [build](https://en.wikipedia.org/wiki/Software_build) support for [Linux](https://en.wikipedia.org/wiki/Linux), [Mac OS](https://en.wikipedia.org/wiki/Mac_OS), [Solaris](https://en.wikipedia.org/wiki/Solaris_%28operating_system%29) and [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) systems.
- Supporting [building](https://en.wikipedia.org/wiki/Software_build) MPIR using Microsoft based build tools for use in 32- and 64-bit versions of Windows.

MPIR is optimized for many processors (CPUs). [Assembly language](https://en.wikipedia.org/wiki/Assembly_language) code exists for these : ARM, DEC Alpha 21064, 21164, and 21264, AMD K6, K6-2, Athlon, K8 and K10, Intel Pentium, Pentium Pro-II-III, Pentium 4, generic x86, Intel IA-64, Core 2, i7, Atom, Motorola-IBM PowerPC 32 and 64, MIPS R3000, R4000, SPARCv7, SuperSPARC, generic SPARCv8, UltraSPARC.
