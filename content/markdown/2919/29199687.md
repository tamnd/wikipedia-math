# Dendroidal set

::: {#o1 .subject cue=lead name="Dendroidal set"}

In mathematics, a **dendroidal set** is a generalization of [simplicial sets](wikipedia://en/1027784) introduced by (Moerdijk Weiss 2007). They have the same relation to (colored symmetric) [operads](wikipedia://en/3126358), also called [symmetric multicategories](https://en.wikipedia.org/wiki/Symmetric_multicategory), that simplicial sets have to [categories](wikipedia://en/5869).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A dendroidal set is a [contravariant functor](https://en.wikipedia.org/wiki/Contravariant_functor) from Ω to [sets](https://en.wikipedia.org/wiki/Set_%28category_theory%29), where Ω is the **tree category** consisting of finite rooted trees considered as operads, whose morphisms are operad morphisms. The trees are allowed to have some edges with a vertex on only one side; these are called outer edges, and the root is one of the outer edges.

:::
