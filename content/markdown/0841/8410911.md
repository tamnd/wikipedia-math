# Mian–Chowla sequence

::: {#o1 .subject cue=lead name="Mian–Chowla sequence"}

In [mathematics](wikipedia://en/18831), the **Mian–Chowla sequence** is an [integer sequence](wikipedia://en/51421) defined [recursively](wikipedia://en/25407) in the following way. The sequence starts with

:::

$$a_1 = 1.$$

Then for $n>1$, $a_n$ is the smallest integer such that every pairwise sum

$$a_i + a_j$$

is distinct, for all $i$ and $j$ less than or equal to $n$.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Initially, with $a_1$, there is only one pairwise sum, 1 + 1 = 2. The next term in the sequence, $a_2$, is 2 since the pairwise sums then are 2, 3 and 4, i.e., they are distinct. Then, $a_3$ can't be 3 because there would be the non-distinct pairwise sums 1 + 3 = 2 + 2 = 4. We find then that $a_3 = 4$, with the pairwise sums being 2, 3, 4, 5, 6 and 8. The sequence thus begins

[1](https://en.wikipedia.org/wiki/1_%28number%29), [2](https://en.wikipedia.org/wiki/2_%28number%29), [4](https://en.wikipedia.org/wiki/4_%28number%29), [8](https://en.wikipedia.org/wiki/8_%28number%29), [13](wikipedia://en/37231), [21](wikipedia://en/209248), [31](https://en.wikipedia.org/wiki/31_%28number%29), [45](https://en.wikipedia.org/wiki/45_%28number%29), [66](https://en.wikipedia.org/wiki/66_%28number%29), [81](https://en.wikipedia.org/wiki/81_%28number%29), [97](https://en.wikipedia.org/wiki/97_%28number%29), [123](https://en.wikipedia.org/wiki/123_%28number%29), [148](https://en.wikipedia.org/wiki/148_%28number%29), [182](https://en.wikipedia.org/wiki/182_%28number%29), [204](https://en.wikipedia.org/wiki/204_%28number%29), [252](https://en.wikipedia.org/wiki/252_%28number%29), [290](https://en.wikipedia.org/wiki/290_%28number%29), 361, 401, 475, ... .

:::

## Similar sequences {#Similar_sequences}

If we define $a_1 = 0$, the resulting sequence is the same except each term is one less (that is, 0, 1, 3, 7, 12, 20, 30, 44, 65, 80, 96, ... ).

## History {#History}

The sequence was invented by Abdul Majid Mian and [Sarvadaman Chowla](wikipedia://en/292142).
