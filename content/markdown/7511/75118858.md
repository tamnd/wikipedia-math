# Graphs with few cliques

::: {#o1 .subject cue=lead name="Graphs with few cliques"}

In [graph theory](wikipedia://en/12401), a [class](https://en.wikipedia.org/wiki/Class_%28mathematics%29) of [graphs](wikipedia://en/325806) is said to have **few cliques** if every member of the class has a [polynomial number](wikipedia://en/405944) of [maximal cliques.](https://en.wikipedia.org/wiki/Maximal_clique)[^o2] Certain generally [NP-hard](wikipedia://en/54681) computational problems are solvable in polynomial time on such classes of graphs,[^o2][^o3] making graphs with few cliques of interest in computational [graph theory](wikipedia://en/12401), [network analysis](wikipedia://en/325726), and other branches of [applied mathematics](wikipedia://en/24295969).[^o4] Informally, a family of graphs has few cliques if the graphs do not have a large number of large [clusters.](https://en.wikipedia.org/wiki/Cluster_%28statistics%29)

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

A *clique* of a graph is a complete [subgraph](https://en.wikipedia.org/wiki/Subgraph_%28graph_theory%29), while a *maximal clique* is a clique that is not properly contained in another clique. One can regard a clique as a cluster of vertices, since they are by definition all connected to each other by an edge. The concept of clusters is ubiquitous in [data analysis](wikipedia://en/2720954), such as on the analysis of [social networks](https://en.wikipedia.org/wiki/Social_network). For that reason, limiting the number of possible maximal cliques has computational ramifications for [algorithms](wikipedia://en/775) on graphs or networks.

Formally, let $X$ be a class of graphs. If for every $n$-[vertex](wikipedia://en/638899) graph $G$ in $X$, there exists a polynomial $f(n)$ such that $G$ has $O(f(n))$ maximal cliques, then $X$ is said to be a *class of graphs with few cliques.*[^o2]

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [Turán graph](wikipedia://en/360581) $T(n, \lceil n/3 \rceil)$ has an [exponential number](wikipedia://en/191933) of maximal cliques. In particular, this graph has exactly $3^{n/3}$maximal cliques when $n \equiv 0 \mod 3$, which is [asymptotically greater](wikipedia://en/641995) than any polynomial function.[^o9] This graph is sometimes called the *Moon-Moser graph*, after Moon & Moser showed in 1965 that this graph has the largest number of maximal cliques among all graphs on $n$ vertices.[^o10] So the class of Turán graphs does *not* have few cliques.
- A [tree](wikipedia://en/48560) $T$ on $n$ vertices has as many maximal cliques as edges, since it contains no triangles by definition. Any tree has exactly $n-1$ edges,[^o11] and therefore that number of maximal cliques. So the class of trees has few cliques.
- A [chordal graph](wikipedia://en/744165) on $n$ vertices has at most $n$ maximal cliques,[^o12] so chordal graphs have few cliques.
- Any [planar graph](wikipedia://en/24314) on $n$ vertices has at most $8n-16$ maximal cliques,[^o13] so the class of planar graphs has few cliques.
- Any $n$-vertex graph with [boxicity](wikipedia://en/11167471) $b$ has $O(n^b)$ maximal cliques,[^o14] so the class of graphs with bounded boxicity has few cliques.
- Any $n$-vertex graph with [degeneracy](wikipedia://en/27545816) $d$ has at most $(n-d)3^{d/3}$ maximal cliques whenever $d \equiv 0 \mod 3$ and $n \geq d+3$,[^o15] so the class of graphs with bounded degeneracy has few cliques.
- Let $G$ be an [intersection graph](wikipedia://en/7726759) of $n$ [convex polytopes](wikipedia://en/1817885) in $d$-dimensional [Euclidean space](wikipedia://en/9697) whose [facets](wikipedia://en/149926) are parallel to $k$ [hyperplanes](wikipedia://en/99862). Then the number of maximal cliques of $G$ is $O\left(n^{dk^{d+1}} \right)$,[^o16] which is polynomial in $n$ for fixed $d$ and $k$. Therefore, the class of intersection graphs of convex polytopes in fixed-dimensional Euclidean space with a bounded number of facets has few cliques.

:::
