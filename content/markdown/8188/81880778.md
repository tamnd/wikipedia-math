# Rådström's embedding theorem

::: {#o1 .subject cue=lead name="Rådström's embedding theorem"}

In [functional analysis](wikipedia://en/11180), **Rådström's embedding theorem** is a result related to the set of [compact](wikipedia://en/6042) and [convex](wikipedia://en/6292) subsets of a [normed vector space](wikipedia://en/21538). It states that such sets can be [isometrically](wikipedia://en/254777) [embededded](wikipedia://en/52119) into a [convex cone](wikipedia://en/3558266) in another normed vector space.

:::

The theorem is an important result in that it shows that this family of sets has natural [linear](wikipedia://en/18422) and [metric](wikipedia://en/20018) structures, which allows for simpler algebraic manipulations via the embedding. It was first proven by [Hans Rådström](wikipedia://en/34034780) in 1952.[^o2]

An extension of Rådström's result to [locally convex topological vector spaces](wikipedia://en/518844), known as the **Hörmander embedding theorem**, was proven by [Lars Hörmander](wikipedia://en/500958) in 1954.[^o3]

## Preliminaries {#Preliminaries}

### $CK(X)$ and the Hausdorff metric {#CK(X)_and_the_Hausdorff_metric}

For any [normed vector space](wikipedia://en/21538) $(X, || \cdot ||)$, let $CK(X)$ be the set of all its convex and compact subsets. We can endow $CK(X)$ with a metric structure given by the [Hausdorff metric](https://en.wikipedia.org/wiki/Hausdorff_metric)

$$d_H(A, B) = \sup_{x \in X} |d(x, A) - d(x, B)|,$$

where $d$ is the metric over $X$ induced by the norm $|| \cdot ||$, and $d(x, Y) = \inf_{y \in Y} d(x, y)$ is the distance from $x$ to a set $Y \subseteq X$. It is well known that $(CK(X), d_H)$ forms a [metric space](wikipedia://en/20018) of its own right.[^o6]

::: {#o8 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

### Main version {#Main_version}

The main version of Rådström's theorem reads as follows:[^o2][^o10]

::: {#o11 .statement kind=statement/theorem cue=inline-head name="Theorem (Rådström, 1952)"}

**Theorem (Rådström, 1952):** Let $(X, || \cdot||)$ be a normed space. Then there exists a normed space $(Y, ||\cdot||_Y)$ such that the space $(CK(X), d_H)$ can be isometrically embedded into a convex cone $C \subseteq Y$. Furthermore, it is possible to construct a "minimal" $Y$ for which this holds.

:::

::: {#o13 .statement kind=statement/generalization cue=heading name="Extensions"}

### Extensions {#Extensions}

It is possible to generalize Rådström's theorem to [locally convex topological vector spaces](wikipedia://en/518844) (LCTVS). This is done via Hörmander's embedding theorem, proven by [Lars Hörmander](wikipedia://en/500958) in 1954.[^o3] Hörmander's theorem explicitly constructs an embedding via [support functions](wikipedia://en/9377661) of closed, convex, [(strongly) bounded](wikipedia://en/1789812) sets.

::: {#o14 .statement kind=statement/theorem cue=inline-head name="Theorem (Hörmander, 1954)"}

**Theorem (Hörmander, 1954):** let $X$ be a real [LCTVS](https://en.wikipedia.org/wiki/LCTVS), and $CB(X)$ the set of all its closed, convex, [(strongly) bounded](wikipedia://en/1789812) subsets. Denoting by $X^*$ the [dual space](wikipedia://en/7988) of $X$, consider the closed unit ball $\mathcal B^* \subseteq X^*$, and the [Banach space](wikipedia://en/3989) $\mathcal C_b (\mathcal B^*)$ of all continuous, bounded functions $h :B^* \to \mathbb R$. For each $A \in CB(X)$, let $s_A \in \mathcal C_b (\mathcal B^*)$ defined by

$$s_A(x) = \sup_{y \in A} \langle x, y\rangle$$

be its [support function](wikipedia://en/9377661). Then the mapping $H: CB(X) \to \mathcal C_b(\mathcal B^*)$ given by

$$A \mapsto s_A$$

is an isometric embedding into a convex cone in $\mathcal C_b(\mathcal B^*)$. Moreover, by the [properties of support functions](wikipedia://en/9377661#Properties) such embedding is also [linear](wikipedia://en/18102) when $CB(X)$ is endowed with a [vector-space structure](wikipedia://en/32370) given by the [Minkowski sum](https://en.wikipedia.org/wiki/Minkowski_sum) and scalar multiplication.[^o10]

:::

## Applications {#Applications}

### Integration of set-valued functions {#Integration_of_set-valued_functions}

The theorem can be used to define the [integral of a set-valued function](wikipedia://en/78164251) (or [correspondence](wikipedia://en/12506030)) via [Debreu's integral](wikipedia://en/78164251#The_Debreu_integral).[^o18][^o19] This has applications, for example, in the theory of [random compact sets](wikipedia://en/5308916).[^o20][^o21]

:::
