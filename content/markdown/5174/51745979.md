# Parity graph

*Image: Cubic matchstick graph.svg.* A parity graph (the unique smallest [cubic](wikipedia://en/980508), [matchstick graph](wikipedia://en/25730128)) that is neither [distance-hereditary](wikipedia://en/17315337) nor [bipartite](wikipedia://en/244431)

::: {#o1 .subject cue=lead name="Parity graph"}

In [graph theory](wikipedia://en/12401), a **parity graph** is a [graph](wikipedia://en/325806) in which all [induced paths](wikipedia://en/7714430) between the same two [vertices](wikipedia://en/638899) have the same [parity](wikipedia://en/143135): either all paths have odd length, or all have even length.[^o2] This class of graphs was named and first studied by (Burlet Uhry 1984).[^o4]

:::

## Related classes of graphs {#Related_classes_of_graphs}

Parity graphs include the [distance-hereditary graphs](wikipedia://en/17315337), in which every two induced paths between the same two vertices have the same length. They also include the [bipartite graphs](wikipedia://en/244431), which may be characterized analogously as the graphs in which every two paths (not necessarily induced paths) between the same two vertices have the same parity, and the [line perfect graphs](wikipedia://en/54306580), a generalization of the bipartite graphs. Every parity graph is a [Meyniel graph](wikipedia://en/744167), a graph in which every odd cycle of length five or more has two chords. For, in a parity graph, any long odd cycle can be partitioned into two paths of different parities, neither of which is a single edge, and at least one chord is needed to prevent these from both being induced paths. Then, partitioning the cycle into two paths between the endpoints of this first chord, a second chord is needed to prevent the two paths of this second partition from being induced. Because Meyniel graphs are [perfect graphs](wikipedia://en/670531), parity graphs are also perfect.[^o2] They are exactly the graphs whose [Cartesian product](wikipedia://en/2856852) with a single edge remains perfect.[^o6]

::: {#o8 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

A graph is a parity graph if and only if every component of its [split decomposition](https://en.wikipedia.org/wiki/Split_decomposition) is either a [complete graph](wikipedia://en/85816) or a [bipartite graph](wikipedia://en/244431).[^o9] Based on this characterization, it is possible to test whether a given graph is a parity graph in [linear time](https://en.wikipedia.org/wiki/Linear_time). The same characterization also leads to generalizations of some graph optimization algorithms from bipartite graphs to parity graphs. For instance, using the split decomposition, it is possible to find the weighted [maximum independent set](https://en.wikipedia.org/wiki/Maximum_independent_set) of a parity graph in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).[^o10]
