# Late acceptance hill climbing

::: {#o1 .subject cue=lead name="Late acceptance hill climbing"}

**Late acceptance hill climbing**, created by Yuri Bykov in 2008[^o2] is a [metaheuristic](https://en.wikipedia.org/wiki/Metaheuristic) search method employing [local search](https://en.wikipedia.org/wiki/Local_search_%28optimization%29) methods used for [mathematical optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29).

:::
