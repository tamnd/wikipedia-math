# DPLL(T)

::: {#o1 .subject cue=lead name="DPLL(T)"}

In computer science, **DPLL(T)** is a framework for determining the satisfiability of [SMT](https://en.wikipedia.org/wiki/Satisfiability_modulo_theories) problems. The algorithm extends the original [SAT](wikipedia://en/4715)-solving [DPLL algorithm](wikipedia://en/2745094) with the ability to reason about an arbitrary [theory](https://en.wikipedia.org/wiki/Logical_theory) *T*.[^o2][^o3][^o4] At a high level, the algorithm works by transforming an SMT problem into a SAT formula where atoms are replaced with Boolean variables. The algorithm repeatedly finds a satisfying valuation for the SAT problem, consults a [theory solver](https://en.wikipedia.org/wiki/Solver) to check consistency under the domain-specific theory, and then (if a contradiction is found) refines the SAT formula with this information.[^o5]

:::

Many modern SMT solvers, such as [Microsoft](https://en.wikipedia.org/wiki/Microsoft)'s [Z3 Theorem Prover](https://en.wikipedia.org/wiki/Z3_Theorem_Prover) and [CVC4](https://en.wikipedia.org/wiki/CVC4), use DPLL(T) to power their core solving capabilities.[^o6][^o7][^o8]
