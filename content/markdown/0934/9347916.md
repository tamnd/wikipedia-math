# New Data Seal

::: {#o2 .subject cue=lead name="New Data Seal"}

In [cryptography](wikipedia://en/18934432), **New Data Seal (NDS)** is a [block cipher](wikipedia://en/4594) that was designed at [IBM](https://en.wikipedia.org/wiki/IBM) in 1975, based on the [Lucifer](wikipedia://en/364242) algorithm that became [DES](wikipedia://en/7978).

:::

The cipher uses a [block size](wikipedia://en/294065) of 128 bits, and a very large [key size](wikipedia://en/5749) of 2048 bits. Like DES it has a 16-round [Feistel network](wikipedia://en/352709) structure. The round function uses two fixed 4×4-bit [S-boxes](https://en.wikipedia.org/wiki/Substitution_box), chosen to be non-[affine](wikipedia://en/38449). The [key](wikipedia://en/53039) is also treated as an 8×8-bit lookup table, using the first bit of each of the 8 bytes of the half-block as input. The nth bit of the output of this table determines whether or not the two [nibbles](https://en.wikipedia.org/wiki/Nibble) of the nth byte are swapped after S-box substitution. All rounds use the same table. Each round function ends with a fixed [permutation](wikipedia://en/44027) of all 64 bits, preventing the cipher from being broken down and analyzed as a system of simpler independent subciphers.

In 1977, [Edna Grossman](wikipedia://en/6643135) and [Bryant Tuckerman](wikipedia://en/1211923) cryptanalyzed NDS using the first known [slide attack](wikipedia://en/1821327). This method uses no more than 4096 [chosen plaintexts](wikipedia://en/63852); in their best trial they recovered the key with only 556 chosen plaintexts.
