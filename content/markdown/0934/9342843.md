# Fujiki class C

::: {#o1 .subject cue=lead name="Fujiki class C"}

In [algebraic geometry](wikipedia://en/1997), a [complex manifold](wikipedia://en/509742) is called **Fujiki class $\mathcal{C}$** if it is [bimeromorphic](https://en.wikipedia.org/wiki/Bimeromorphic) to a compact [Kähler manifold](wikipedia://en/390538). This notion was defined by [Akira Fujiki](https://en.wikipedia.org/wiki/Akira_Fujiki).[^o2]

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let *M* be a compact manifold of Fujiki class $\mathcal{C}$, and $X\subset M$ its complex subvariety. Then *X* is also in Fujiki class $\mathcal{C}$ (,[^o5] Lemma 4.6). Moreover, the [Douady space](https://en.wikipedia.org/wiki/Douady_space) of *X* (that is, the [moduli of deformations](wikipedia://en/361609) of a subvariety $X\subset M$, *M* fixed) is compact and in Fujiki class $\mathcal{C}$.[^o6]

Fujiki class $\mathcal{C}$ manifolds are examples of compact complex manifolds which are not necessarily Kähler, but for which the [$\partial \bar \partial$-lemma](wikipedia://en/72112048) holds.[^o7]

:::

::: {#o9 .statement kind=statement/conjecture cue=heading name="Conjectures"}

## Conjectures {#Conjectures}

[J.-P. Demailly](wikipedia://en/53350424) and M. Pǎun have shown that a manifold is in Fujiki class $\mathcal{C}$ if and only if it supports a [Kähler current](https://en.wikipedia.org/wiki/Kähler_current).[^o10] They also conjectured that a manifold *M* is in Fujiki class $\mathcal{C}$ if it admits a [nef current](https://en.wikipedia.org/wiki/Nef_current) which is *big*, that is, satisfies

$$\int_M \omega^{{dim_{\mathbb C} M}}>0.$$

For a cohomology class $[\omega]\in H^2(M)$ which is rational, this statement is known: by [Grauert-Riemenschneider conjecture](https://en.wikipedia.org/wiki/Grauert-Riemenschneider_conjecture), a holomorphic line bundle *L* with first [Chern class](wikipedia://en/294349)

$$c_1(L)=[\omega]$$

[nef](https://en.wikipedia.org/wiki/Numerically_effective) and big has maximal [Kodaira dimension](wikipedia://en/1866873), hence the corresponding rational map to

$${\mathbb P} H^0(L^N)$$

is [generically finite](https://en.wikipedia.org/wiki/Generically_finite) onto its image, which is algebraic, and therefore Kähler.

Fujiki[^o11] and Ueno[^o12] asked whether the property $\mathcal{C}$ is stable under deformations. This conjecture was disproven in 1992 by Y.-S. Poon and [Claude LeBrun](wikipedia://en/38381127)[^o13]

:::
