# Prime k-tuple

::: {#o1 .subject cue=lead name="Prime k-tuple"}

In [number theory](wikipedia://en/21527), a **prime $k$-tuple** is a finite collection of values representing a repeatable pattern of differences between [prime numbers](https://en.wikipedia.org/wiki/Prime_numbers). For a $k$-[tuple](wikipedia://en/132729) $(a, b, \ldots)$, the positions where the $k$-tuple matches a pattern in the prime numbers are given by the set of [integers](https://en.wikipedia.org/wiki/Integers) $n$ for which all of the values $(n + a, n + b, \ldots)$ are prime. Typically the first value in the $k$-tuple is 0 and the rest are distinct positive [even numbers](https://en.wikipedia.org/wiki/Even_numbers).[^o2]

:::

## Admissibility {#Admissibility}

In order for a $k$-tuple to have infinitely many positions at which all of its values are prime, there cannot exist a prime $p$ such that the tuple includes every different possible value [modulo](wikipedia://en/20087) $p$. If such a prime $p$ existed, then no matter which value of $n$ was chosen, one of the values formed by adding $n$ to the tuple would be divisible by $p$, so the only possible placements would have to include $p$ itself, and there are at most $k$ of those. For example, the numbers in a $k$-tuple cannot take on all three values 0, 1, and 2 modulo 3; otherwise the resulting numbers would always include a multiple of 3 and therefore could not all be prime unless one of the numbers is 3 itself.

A $k$-tuple that includes every possible residue modulo $p$ is said to be **inadmissible modulo $p$**. It should be obvious that this is only possible when $k \ge p$. A tuple which is not inadmissible modulo $p$ is called **admissible**.

It is [conjectured](https://en.wikipedia.org/wiki/Conjectured) that every admissible $k$-tuple matches infinitely many positions in the sequence of prime numbers. However, there is no tuple for which this has been [proven](wikipedia://en/82285) except the trivial 1-tuple (0). In that case, the conjecture is equivalent to the statement that there are [infinitely many primes](wikipedia://en/3143591). Nevertheless, [Yitang Zhang](wikipedia://en/39441844) proved in 2013 that there exists at least one 2-tuple which matches infinitely many positions; subsequent work showed that such a 2-tuple exists with values differing by 246 or less that matches infinitely many positions.[^o6]

### Positions matched by inadmissible patterns {#Positions_matched_by_inadmissible_patterns}

Although (0, 2, 4) is inadmissible modulo 3, it does produce a single set of primes: (3, 5, 7).

Because 3 is the first odd prime, a non-trivial ($k \ge 1$) $k$-tuple matching the prime 3 can only match in one position. If the tuple begins (0, 1, ...) (i.e. is inadmissible modulo 2) then it can only match (2, 3, ...); if the tuple contains only even numbers, it can only match (3, ...).

Inadmissible $k$-tuples can have more than one all-prime solution if they are admissible modulo 2 and 3, and inadmissible modulo $p \ge 5$. This of course implies that there must be at least five numbers in the tuple. The shortest inadmissible tuple with more than one solution is the 5-tuple (0, 2, 8, 14, 26), which has two solutions: (3, 5, 11, 17, 29) and (5, 7, 13, 19, 31), where all values modulo 5 are included in both cases. Examples with three or more solutions also exist.[^o8]

## Prime constellations {#Prime_constellations}

The **diameter** of a $k$-tuple is the difference of its largest and smallest elements. An admissible prime $k$-tuple with the smallest possible diameter $d$ (among all admissible $k$-tuples) is a **prime constellation**. For all $n \ge k$ this will always produce consecutive primes. (Recall that all $n$ are integers for which the values $(n + a, n + b, \ldots)$ are prime.)

This means that, for large $n$:

$$p_{n+k-1} - p_n \geq d$$

where $p_{n}$ is the $n$th prime number.

The first few prime constellations are:

| 5 | 12 | (0, 2, 6, 8, 12) (0, 4, 6, 10, 12) | (5, 7, 11, 13, 17) (7, 11, 13, 17, 19) |
| 6 | 16 | (0, 4, 6, 10, 12, 16) | (7, 11, 13, 17, 19, 23) |
| 7 | 20 | (0, 2, 6, 8, 12, 18, 20) (0, 2, 8, 12, 14, 18, 20) | (11, 13, 17, 19, 23, 29, 31) (5639, 5641, 5647, 5651, 5653, 5657, 5659) |
| 8 | 26 | (0, 2, 6, 8, 12, 18, 20, 26) (0, 2, 6, 12, 14, 20, 24, 26) (0, 6, 8, 14, 18, 20, 24, 26) | (11, 13, 17, 19, 23, 29, 31, 37) (17, 19, 23, 29, 31, 37, 41, 43) (88793, 88799, 88801, 88807, 88811, 88813, 88817, 88819) |

:::

The diameter $d$ as a function of $k$ is [sequence A008407](https://en.wikipedia.org/wiki/Oeis:A008407) in the [OEIS](https://en.wikipedia.org/wiki/OEIS).

A prime constellation is sometimes referred to as a **prime $k$-tuplet**, but some authors reserve that term for instances that are not part of longer $k$-tuplets.

The [first Hardy–Littlewood conjecture](wikipedia://en/22947746) predicts that the asymptotic frequency of any prime constellation can be calculated. While the conjecture is unproven it is considered likely to be true. If that is the case, it implies that the [second Hardy–Littlewood conjecture](wikipedia://en/361598), in contrast, is false.

:::

## Prime arithmetic progressions {#Prime_arithmetic_progressions}

A prime $k$-tuple of the form $(0, n, 2n, 3n, \ldots, (k - 1)n)$ is said to be a **prime arithmetic progression**. In order for such a $k$-tuple to meet the admissibility test, $n$ must be a multiple of the [primorial](wikipedia://en/422786) of $k$.

## Skewes numbers {#Skewes_numbers}

The [Skewes numbers for prime *k*-tuples](wikipedia://en/250178#Equivalent_for_prime_k-tuples) are an extension of the definition of [Skewes's number](wikipedia://en/250178) to prime *k*-tuples based on the [first Hardy–Littlewood conjecture](wikipedia://en/22947746) ((Tóth 2019)). Let $P = (p,\ p+i_1,\ p+i_2,\ \dots\ ,\ p+i_k)$ denote a prime $k$-tuple, $\pi_P(x)$ the number of primes $p$ below $x$ such that $p,\ p+i_1,\ p+i_2,\ \dots\ ,\ p+i_k$ are all prime, let $\operatorname{li}_P(x) = \int_2^x \frac{dt}{(\ln t)^{k + 1}}$ and let $C_P$ denote its Hardy–Littlewood constant (see [first Hardy–Littlewood conjecture](wikipedia://en/22947746)). Then the first prime $p$ that violates the Hardy–Littlewood inequality for the $k$-tuple $P$, i.e., such that

$$\pi_P(p) > C_P \operatorname{li}_P(p),$$

(if such a prime exists) is the *Skewes number for $P$*.
