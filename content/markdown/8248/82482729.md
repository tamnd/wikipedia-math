# Skein (graph theory)

::: {#o1 .subject cue=lead name="Skein"}

A **skein** in a [graph](wikipedia://en/325806) $G$ is a subgraph of $G$ that is the union of a collection of [paths](wikipedia://en/638889) between two distinct vertices that have only these two vertices in common.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G$ be a graph, and $a$ and $b$ be two distinct vertices of $G$. An $(a,b)$-skein of strength $k$, where $k$ is a [cardinal number](wikipedia://en/6173), is then the union of a set of $k$ paths joining $a$ and $b$ such that any two of these paths have only $a$ and $b$ in common. The skein is then also called a $k$-skein.

For a $k$-skein in a [finite graph](https://en.wikipedia.org/wiki/Finite_graph), $k$ is a [natural number](wikipedia://en/21474).

:::

:::

::: {#o7 .application cue=heading name="Application"}

## Application {#Application}

Using the notion of a *skein*, [Menger's theorem](wikipedia://en/1155738) can be formulated as follows:

The size of any [minimum cut](wikipedia://en/3562453) of a given [finite graph](https://en.wikipedia.org/wiki/Finite_graph) is equal to the maximal value of $k$ for which the graph contains a $k$-skein.

:::
