# Abel equation

::: {#o1 .subject cue=lead name="Abel equation"}

The **Abel equation**, named after [Niels Henrik Abel](wikipedia://en/21573), is a type of [functional equation](wikipedia://en/364377) of the form

:::

$$f(h(x)) = h(x + 1)$$

or

$$\alpha(f(x)) = \alpha(x)+1.$$

The forms are equivalent when $\alpha$ is [invertible](https://en.wikipedia.org/wiki/Invertible_function). $h$ or $\alpha$ control the [iteration](wikipedia://en/1448702) of $f$.

## Equivalence {#Equivalence}

The second equation can be written

$$\alpha^{-1}(\alpha(f(x))) = \alpha^{-1}(\alpha(x)+1)\, .$$

Taking $x = \alpha^{-1}(y)$, the equation can be written

$$f(\alpha^{-1}(y)) = \alpha^{-1}(y+1)\, .$$

For a known function $f(x)$ , a problem is to solve the functional equation for the function $\alpha^{-1} \equiv h$, possibly satisfying additional requirements, such as $\alpha^{-1}(0) = 1$.

The change of variables $s^{\alpha(x)} = \Psi(x)$, for a [real](wikipedia://en/20646438) parameter $s$, brings Abel's equation into the celebrated [Schröder's equation](wikipedia://en/5834541), $\Psi(f(x)) = s \Psi(x)$ .

The further change $F(x) = \exp(s^{\alpha(x)})$ into [Böttcher's equation](wikipedia://en/34458555), $F(f(x)) = F(x)^{s}$.

The Abel equation is a special case of (and easily generalizes to) the **translation equation**,[^o3]

$$\omega( \omega(x,u),v)=\omega(x,u+v) ~,$$

e.g., for $\omega(x,1) = f(x)$,

$\omega(x,u) = \alpha^{-1}(\alpha(x)+u)$. (Observe $\omega(x,0) = x$.)

The Abel function $\alpha(x)$ further provides the canonical coordinate for [Lie advective flows](wikipedia://en/467384) (one parameter [Lie groups](wikipedia://en/17945)).

## History {#History}

Initially, the equation in the more general form [^o5] [^o6] was reported. Even in the case of a single variable, the equation is non-trivial, and admits special analysis.[^o7][^o8][^o9]

In the case of a linear transfer function, the solution is expressible compactly.[^o10]

::: {#o12 .statement kind=statement/generalization cue=heading name="Special cases"}

## Special cases {#Special_cases}

The equation of [tetration](wikipedia://en/482379) is a special case of Abel's equation, with $f = \exp$.

In the case of an integer argument, the equation encodes a recurrent procedure, e.g.,

$$\alpha(f(f(x)))=\alpha(x)+2 ~,$$

and so on,

$$\alpha(f_n(x))=\alpha(x)+n ~.$$

:::

## Solutions {#Solutions}

The Abel equation has at least one solution on $E$ [if and only if](wikipedia://en/14922) for all $x \in E$ and all $n \in \mathbb{N}^*$, $f^{n}(x) \neq x$, where $f^{n} = f \circ f \circ ... \circ f$, is the function $f$ [iterated](wikipedia://en/1448702) $n$ times.[^o14]

We have the following existence and uniqueness theorem[^o15]

Let $h: \mathbb{R} \to \mathbb{R}$ be [analytic](wikipedia://en/61478), meaning it has a Taylor expansion. To find: real analytic solutions $\alpha: \mathbb{R} \to \mathbb{C}$ of the Abel equation $\alpha \circ h = \alpha + 1$.

### Existence {#Existence}

A real analytic solution $\alpha$ exists if and only if both of the following conditions hold:

- $h$ has no [fixed points](wikipedia://en/449738), meaning there is no $y \in \mathbb{R}$ such that $h(y) = y$.
- The set of [critical points](wikipedia://en/1951424) of $h$, where $h'(y) = 0$, is bounded above if $h(y) > y$ for all $y$, or bounded below if $h(y) < y$ for all $y$.

### Uniqueness {#Uniqueness}

The solution is essentially unique in the sense that there exists a canonical solution $\alpha_0$ with the following properties:

- The set of critical points of $\alpha_0$ is bounded above if $h(y) > y$ for all $y$, or bounded below if $h(y) < y$ for all $y$.
- This canonical solution generates all other solutions. Specifically, the set of all real analytic solutions is given by

$$\{\alpha_0 + \beta\circ \alpha_0 | \beta : \mathbb{R} \to \mathbb{R} \text{ is analytic, with period 1}\}.$$

### Approximate solution {#Approximate_solution}

Analytic solutions (Fatou coordinates) can be approximated by [asymptotic expansion](wikipedia://en/642090) of a function defined by [power series](wikipedia://en/59958) in the sectors around a [parabolic fixed point](wikipedia://en/10422205).[^o19] The analytic solution is unique up to a constant.[^o20]
