# Friedberg numbering

::: {#o1 .subject cue=lead name="Friedberg numbering"}

In [computability theory](wikipedia://en/155414), a **Friedberg numbering** is a [computable](wikipedia://en/2399097#Computable_numberings) [numbering](wikipedia://en/2399097) (enumeration) of the set of all [computably enumerable sets](wikipedia://en/332090) that has no repetitions: each computably enumerable set appears exactly once in the enumeration (Vereščagin and Shen 2003:30).

:::

The existence of such numberings was established by [Richard M. Friedberg](https://en.wikipedia.org/wiki/Richard_M._Friedberg) in 1958 (Cutland 1980:78).
