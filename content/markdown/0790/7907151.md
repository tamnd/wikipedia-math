# Rellich–Kondrachov theorem

::: {#o1 .subject cue=lead name="Rellich–Kondrachov theorem"}

In [mathematics](wikipedia://en/18831), the **Rellich–Kondrachov theorem** is a [compact embedding](https://en.wikipedia.org/wiki/Compactly_embedded) [theorem](wikipedia://en/30977) concerning [Sobolev spaces](wikipedia://en/611964). It is named after the Austrian-German mathematician [Franz Rellich](wikipedia://en/4172897) and the Russian mathematician [Vladimir Iosifovich Kondrashov](https://en.wikipedia.org/wiki/Vladimir_Iosifovich_Kondrashov). Rellich proved the *L*<sup>2</sup> theorem and Kondrashov the *L*<sup>*p*</sup> theorem.

:::

::: {#o3 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let Ω ⊆ **R**<sup>*n*</sup> be an [open](wikipedia://en/39358), [bounded](wikipedia://en/48258) [Lipschitz domain](wikipedia://en/7820612), and let 1 ≤ *p* \< *n*. Set

$$p^{*} := \frac{n p}{n - p}.$$

Then the Sobolev space $W^{1, p} (\Omega)$ is [continuously embedded](https://en.wikipedia.org/wiki/Continuously_embedded) in the [*L*<sup>*p*</sup> space](wikipedia://en/45194) $L^{p^*}(\Omega;\mathbb{R})$ and is [compactly embedded](https://en.wikipedia.org/wiki/Compactly_embedded) in $L^q(\Omega;\mathbb{R})$ for every $1 \leq q < p^*$. In symbols,

$$W^{1, p} (\Omega) \hookrightarrow L^{p^{*}} (\Omega)$$

and

$$W^{1, p} (\Omega) \subset \subset L^{q} (\Omega) \text{ for } 1 \leq q < p^{*}.$$

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Kondrachov embedding theorem"}

### Kondrachov embedding theorem {#Kondrachov_embedding_theorem}

On a compact manifold with $C^{1}$ boundary, the **Kondrachov embedding theorem** states that if $k > \ell$ and $k - n/p > \ell - n/q$ then the Sobolev embedding

$$W^{k,p}(M)\subset W^{\ell,q}(M)$$

is [completely continuous](https://en.wikipedia.org/wiki/Completely_continuous) (compact).[^o6]

:::

:::

## Consequences {#Consequences}

Since an embedding is compact if and only if the inclusion (identity) operator is a [compact operator](wikipedia://en/577441), the Rellich–Kondrachov theorem implies that any uniformly bounded sequence in *W*<sup>1,*p*</sup>(Ω; **R**) has a subsequence that converges in *L*<sup>*q*</sup>(Ω; **R**). Stated in this form, in the past the result was sometimes referred to as the **Rellich–Kondrachov selection theorem**, since one "selects" a convergent subsequence. (However, today the customary name is "compactness theorem", whereas "selection theorem" has a precise and quite different meaning, referring to [set-valued functions](wikipedia://en/12506030).)

The Rellich–Kondrachov theorem may be used to prove the [Poincaré inequality](wikipedia://en/4722074),[^o8] which states that for *u* ∈ *W*<sup>1,*p*</sup>(Ω; **R**) (where Ω satisfies the same hypotheses as above),

$$\| u - u_\Omega \|_{L^p (\Omega)} \leq C \| \nabla u \|_{L^p (\Omega)}$$

for some constant *C* depending only on *p* and the geometry of the domain Ω, where

$$u_\Omega := \frac{1}{\operatorname{meas} (\Omega)} \int_\Omega u(x) \, \mathrm{d} x$$

denotes the mean value of *u* over Ω.
