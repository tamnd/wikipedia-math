# Fisher kernel

::: {#o1 .subject cue=lead name="Fisher kernel"}

In [statistical classification](wikipedia://en/1579244), the **Fisher kernel**, named after [Ronald Fisher](wikipedia://en/140824), is a function that [measures the similarity](wikipedia://en/1004743) of two objects on the basis of sets of measurements for each object and a statistical model. In a classification procedure, the class for a new object (whose real class is unknown) can be estimated by minimising, across classes, an average of the Fisher kernel distance from the new object to each known member of the given class.

:::

The Fisher kernel was introduced in 1998.[^o2] It combines the advantages of [generative statistical models](wikipedia://en/1222578) (like the [hidden Markov model](wikipedia://en/98770)) and those of [discriminative methods](wikipedia://en/1579244) (like [support vector machines](wikipedia://en/65309)):

- generative models can process data of variable length (adding or removing data is well-supported)
- discriminative methods can have flexible criteria and yield better results.

## Derivation {#Derivation}

### Fisher score {#Fisher_score}

The Fisher kernel makes use of the **Fisher [score](https://en.wikipedia.org/wiki/Score_%28statistics%29)**, defined as

$$U_X = \nabla_{\theta} \log P(X|\theta)$$

with *θ* being a set (vector) of parameters. The function taking *θ* to log P(*X*|*θ*) is the [log-likelihood](https://en.wikipedia.org/wiki/Log-likelihood) of the probabilistic model.

### Fisher kernel {#Fisher_kernel}

The **Fisher kernel** is defined as

$$K(X_i, X_j) = U_{X_i}^T \mathcal{I}^{-1} U_{X_j}$$

with *$\mathcal{I}$* being the [Fisher information](wikipedia://en/598971) matrix.

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

### Information retrieval {#Information_retrieval}

The Fisher kernel is the kernel for a generative probabilistic model. As such, it constitutes a bridge between generative and probabilistic models of documents.[^o9] Fisher kernels exist for numerous models, notably [tf–idf](https://en.wikipedia.org/wiki/Tf–idf),[^o10] [Naive Bayes](https://en.wikipedia.org/wiki/Naive_Bayes) and [probabilistic latent semantic analysis](wikipedia://en/2088675).

### Image classification and retrieval {#Image_classification_and_retrieval}

The Fisher kernel can also be applied to image representation for classification or retrieval problems. Currently, the most popular [bag-of-visual-words](https://en.wikipedia.org/wiki/Bag_of_words_model_in_computer_vision) representation suffers from sparsity and high dimensionality. The Fisher kernel can result in a compact and dense representation, which is more desirable for image classification[^o12][^o13] and retrieval[^o14][^o15] problems.

The Fisher Vector (FV), a special, approximate, and improved case of the general Fisher kernel,[^o16] is an image representation obtained by pooling local image [features](https://en.wikipedia.org/wiki/Feature_%28computer_vision%29). The FV encoding stores the mean and the covariance deviation vectors per component k of the Gaussian-Mixture-Model (GMM) and each element of the local feature descriptors together. In a systematic comparison, FV outperformed all compared encoding methods ([Bag of Visual Words (BoW)](https://en.wikipedia.org/wiki/Bag-of-words_model_in_computer_vision), Kernel Codebook encoding (KCB), Locality Constrained Linear Coding (LLC), Vector of Locally Aggregated Descriptors (VLAD)) showing that the encoding of second order information (aka codeword covariances) indeed benefits classification performance.[^o17]
