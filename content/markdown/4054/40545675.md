# Tau-leaping

::: {#o1 .subject cue=lead name="Tau-leaping"}

In [probability theory](wikipedia://en/23542), **tau-leaping**, or **τ-leaping**, is an approximate method for the [simulation](https://en.wikipedia.org/wiki/Computer_simulation) of a [stochastic system](https://en.wikipedia.org/wiki/Stochastic_system).[^o2] It is based on the [Gillespie algorithm](wikipedia://en/4438763), performing all reactions for an interval of length tau before updating the propensity functions.[^o3] By updating the rates less often this sometimes allows for more efficient simulation and thus the consideration of larger systems.

:::

Many variants of the basic algorithm have been considered.[^o4][^o5][^o6][^o7][^o8]

::: {#o10 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

The algorithm is analogous to the [Euler method](wikipedia://en/3011098) for deterministic systems, but instead of making a fixed change

$$x(t+\tau)=x(t)+\tau x'(t)$$

the change is

$$x(t+\tau)=x(t)+P(\tau x'(t))$$

where $P(\tau x'(t))$ is a [Poisson](wikipedia://en/23009144) distributed [random variable](wikipedia://en/25685) with mean $\tau x'(t)$.

Given a state $\mathbf{x}(t)=\{X_i(t)\}$ with events $E_j$ occurring at rate $R_j(\mathbf{x}(t))$ and with state change vectors $\mathbf{v}_{ij}$ (where $i$ indexes the state variables, and $j$ indexes the events), the method is as follows:

1. Initialise the model with initial conditions $\mathbf{x}(t_0)=\{X_i(t_0)\}$.
1. Calculate the event rates $R_j(\mathbf{x}(t))$.
1. Choose a time step $\tau$. This may be fixed, or by some algorithm dependent on the various event rates.
1. For each event $E_j$ generate $K_j \sim \text{Poisson}(R_j\tau)$, which is the number of times each event occurs during the time interval $[t,t+\tau)$.
1. Update the state by

$$\mathbf{x}(t+\tau)=\mathbf{x}(t)+\sum_j K_jv_{ij}$$

where $v_{ij}$ is the change on state variable $X_i$ due to event $E_j$. At this point it may be necessary to check that no populations have reached unrealistic values (such as a population becoming negative due to the unbounded nature of the Poisson variable $K_j$).

1. Repeat from Step 2 onwards until some desired condition is met (e.g. a particular [state variable](https://en.wikipedia.org/wiki/State_variable) reaches 0, or time $t_1$ is reached).

:::

## Algorithm for efficient step size selection {#Algorithm_for_efficient_step_size_selection}

This algorithm is described by Cao et al.[^o5] The idea is to bound the relative change in each event rate $R_j$ by a specified tolerance $\epsilon$ (Cao et al. recommend $\epsilon=0.03$, although it may depend on model specifics). This is achieved by bounding the relative change in each state variable $X_i$ by $\epsilon/g_i$, where $g_i$ depends on the rate that changes the most for a given change in $X_i$. Typically $g_i$ is equal the highest order event rate, but this may be more complex in different situations (especially epidemiological models with non-linear event rates).

This algorithm typically requires computing $2N$ *auxiliary values* (where $N$ is the number of state variables $X_i$), and should only require reusing previously calculated values $R_j(\mathbf{x})$. An important factor in this is that since $X_i$ is an [integer](wikipedia://en/14563) value, there is a minimum value by which it can change, preventing the relative change in $R_j$ being bounded by 0, which would result in $\tau$ also tending to 0.

1. For each state variable $X_i$, calculate the auxiliary values

$$\mu_i(\mathbf{x}) = \sum_j v_{ij} R_j(\mathbf{x})$$

$$\sigma_i^2(\mathbf{x}) = \sum_j v_{ij}^2 R_j(\mathbf{x})$$

1. For each state variable $X_i$, determine the highest order event in which it is involved, and obtain $g_i$
1. Calculate time step $\tau$ as

$$\tau = \min_i {\left\{ \frac{\max{\{\epsilon X_i / g_i, 1\}}}{|\mu_i(\mathbf{x})|}, \frac{\max{\{\epsilon X_i / g_i, 1\}}^2}{\sigma_i^2(\mathbf{x})} \right\}}$$

This computed $\tau$ is then used in Step 3 of the $\tau$ leaping algorithm.
