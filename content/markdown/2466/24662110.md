# Effective Polish space

::: {#o1 .subject cue=lead name="Effective Polish space"}

In [mathematical logic](wikipedia://en/19636), an **effective Polish space** is a [complete](wikipedia://en/7832) [separable](wikipedia://en/27855) [metric space](wikipedia://en/20018) that has a [computable presentation](https://en.wikipedia.org/wiki/Computable_presentation). Such spaces are studied in [effective descriptive set theory](wikipedia://en/3244136) and in [constructive analysis](wikipedia://en/239851). In particular, standard examples of [Polish spaces](wikipedia://en/396622) such as the [real line](https://en.wikipedia.org/wiki/Real_line), the [Cantor set](wikipedia://en/6172) and the [Baire space](wikipedia://en/2078245) are all effective Polish spaces.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An effective Polish space is a complete separable metric space *X* with metric *d* such that there is a countable dense set *C* = (*c*<sub>0</sub>, *c*<sub>1</sub>,...) that makes the following two [relations](https://en.wikipedia.org/wiki/Relation_%28logic%29) on $\mathbb{N}^4$ computable (Moschovakis 2009:96-7):

$$P(i,j,k,m) \equiv \left\{ d(c_i,c_j) \leq \frac{m}{k+1} \right\}$$

$$Q(i,j,k,m) \equiv \left\{ d(c_i,c_j) < \frac{m}{k+1} \right\}$$

:::
