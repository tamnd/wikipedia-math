# Column groups and row groups

::: {#o1 .subject cue=lead name="Column groups and row groups"}

*Image: Simple Periodic Table Chart-blocks.svg.* Colored column groups and row groups in the [periodic table](https://en.wikipedia.org/wiki/Periodic_table) of the chemical elements.

In [tables](https://en.wikipedia.org/wiki/Table_%28information%29) and [matrices](wikipedia://en/20556859), a **column group** or **row group** usually refers to a [subset](wikipedia://en/27631) of columns or rows, respectively. Short names or notational names include **col group** or **colgroup**, and **row group** or **rowgroup**. They can have varying uses depending on context:

:::

- In mathematics, a [partitioned matrix](https://en.wikipedia.org/wiki/Partitioned_matrix) is an interpretation of a matrix as being broken down into submatrices which may be more precisely referred to as a collection of row groups and column groups
- In web development, colgroup is a [standard HTML attribute](https://en.wikipedia.org/wiki/HTML_attribute#Standard_attributes) and an [HTML event attribute](https://en.wikipedia.org/wiki/HTML_attribute#Event_attributes), for example used for color formatting of entire columns in HTML tables.[^o2] The colgroup tag acts as a "parent container of one or more `<col>` elements".[^o3] [Rowgroup](https://en.wikipedia.org/wiki/Rowgroup) is another HTML attribute.[^o4]
- In [reporting](https://en.wikipedia.org/wiki/Report)[^o5] (including [business reporting](https://en.wikipedia.org/wiki/Financial_reporting), [data reporting](https://en.wikipedia.org/wiki/Data_reporting) and [financial reporting](https://en.wikipedia.org/wiki/Financial_reporting)), colgroups and rowgroups can be used for constructing tables and matrices which dynamically adjusts the size of their columns and rows, respectively, by displaying the set of columns in the colgroup set (which again is a subset of the underlying data).
- In reporting, colgroups and rowgroups can also be used for grouping of collapsible categories in the presentation of a table[^o6] (with or without aggregation for the groups[^o7]). One example of a use case may be if a table contains a lot of detailed information, but there is a want to display summarizing information of groups in the same table.[^o6]
