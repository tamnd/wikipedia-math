# Polystick

::: {#o1 .subject cue=lead name="Polystick"}

In [recreational mathematics](wikipedia://en/26446), a **polystick** (or **polyedge**) is a [polyform](wikipedia://en/691765) with a [line segment](wikipedia://en/22634860) (a 'stick') as the basic shape. A polystick is a connected set of segments in a [regular grid](wikipedia://en/3771917). A square polystick is a connected subset of a regular square grid. A triangular polystick is a connected subset of a regular triangular grid. Polysticks are classified according to how many line segments they contain.

:::

The name **"polystick"** seems to have been coined by Brian R. Barwell.[^o3]

The names **"polytrig"**[^o4] and **"polytwigs"**[^o5] has been proposed by David Goodger to simplify the phrases "triangular-grid polysticks" and "hexagonal-grid polysticks," respectively. Colin F. Brown has used an earlier term **"polycules"** for the hexagonal-grid polysticks due to their appearance resembling the [spicules](https://en.wikipedia.org/wiki/Sponge_spicule) of [sea sponges](https://en.wikipedia.org/wiki/Sea_sponges).[^o5]

There is no standard term for line segments built on other [regular tilings](https://en.wikipedia.org/wiki/List_of_uniform_tilings), an [unstructured grid](wikipedia://en/3772072), or a simple [connected graph](https://en.wikipedia.org/wiki/Connected_graph), but both **"polynema"** and **"polyedge"** have been proposed.

When reflections are considered distinct we have the *one-sided* polysticks. When rotations and reflections are not considered to be distinct shapes, we have the *free* polysticks. Thus, for example, there are 7 one-sided square tristicks because two of the five shapes have left and right versions.[^o2][^o7]

The set of *n*-sticks that contain no closed loops is equivalent, with some duplications, to the set of [(*n*+1)-ominos](wikipedia://en/72634), as each [vertex](wikipedia://en/638899) at the end of every line segment can be replaced with a single square of a polyomino. For example, the set of tristicks is equivalent to the set of [Tetrominos](https://en.wikipedia.org/wiki/Tetrominos). In general, an *n*-stick with *m* loops is equivalent to a (*n*−*m*+1)-omino (as each loop means that one line segment does not add a vertex to the figure).
