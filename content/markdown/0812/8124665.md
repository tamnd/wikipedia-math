# Igusa zeta function

::: {#o1 .subject cue=lead name="Igusa zeta function"}

In [mathematics](wikipedia://en/18831), an **Igusa zeta function** is a type of [generating function](wikipedia://en/160993), counting the number of solutions of an equation, *modulo* *p*, *p*<sup>2</sup>, *p*<sup>3</sup>, and so on.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a [prime number](wikipedia://en/23666) *p* let *K* be a [p-adic field](https://en.wikipedia.org/wiki/P-adic_field), i.e. $[K: \mathbb{Q}_p]<\infty$, *R* the [valuation ring](wikipedia://en/966856) and *P* the maximal [ideal](wikipedia://en/25977). For $z \in K$ we denote by $\operatorname{ord}(z)$ the [valuation](wikipedia://en/347049) of *z*, $\mid z \mid = q^{-\operatorname{ord}(z)}$, and $ac(z)=z \pi^{-\operatorname{ord}(z)}$ for a uniformizing parameter π of *R*.

Furthermore let $\phi : K^n \to \mathbb{C}$ be a [Schwartz–Bruhat function](wikipedia://en/5878203), i.e. a locally constant function with [compact support](https://en.wikipedia.org/wiki/Compact_support) and let $\chi$ be a [character](wikipedia://en/293418) of $R^\times$.

In this situation one associates to a non-constant [polynomial](wikipedia://en/23000) $f(x_1, \ldots, x_n) \in K[x_1,\ldots,x_n]$ the Igusa zeta function

$$Z_\phi(s,\chi) = \int_{K^n} \phi(x_1,\ldots,x_n) \chi(ac(f(x_1,\ldots,x_n))) |f(x_1,\ldots,x_n)|^s \, dx$$

where $s \in \mathbb{C}, \operatorname{Re}(s)>0,$ and *dx* is [Haar measure](wikipedia://en/40645) so normalized that $R^n$ has measure 1.

:::

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Igusa's theorem"}

## Igusa's theorem {#Igusa's_theorem}

(txt) showed that $Z_\phi (s,\chi)$ is a rational function in $t=q^{-s}$. The proof uses [Heisuke Hironaka](wikipedia://en/13822)'s theorem about the [resolution of singularities](wikipedia://en/9914115). Later, an entirely different proof was given by [Jan Denef](wikipedia://en/6837784) using p-adic cell decomposition. Little is known, however, about explicit formulas. (There are some results about Igusa zeta functions of [Fermat varieties](https://en.wikipedia.org/wiki/Fermat_varieties).)

:::

## Congruences modulo powers of *P* {#Congruences_modulo_powers_of_P}

Henceforth we take $\phi$ to be the [characteristic function](wikipedia://en/240790) of $R^n$ and $\chi$ to be the trivial character. Let $N_i$ denote the number of solutions of the [congruence](wikipedia://en/48167)

$$f(x_1,\ldots,x_n) \equiv 0 \mod P^i.$$

Then the Igusa zeta function

$$Z(t)= \int_{R^n} |f(x_1,\ldots,x_n)|^t \, dx$$

is closely related to the Poincaré series

$$P(t)= \sum_{i=0}^{\infty} q^{-in}N_i t^i$$

by

$$P(t)= \frac{1-t Z(t)}{1-t}.$$
