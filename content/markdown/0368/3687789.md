# Split link

::: {#o1 .subject cue=lead name="Split link"}

In the [mathematical](wikipedia://en/18831) field of [knot theory](wikipedia://en/153008), a **split link** is a [link](wikipedia://en/1161784) that has a (topological) 2-sphere in its complement separating one or more link components from the others.[^o2] A split link is said to be **splittable**, and a link that is not split is called a **non-split link** or not splittable. Whether a link is split or non-split corresponds to whether the [link complement](https://en.wikipedia.org/wiki/Link_complement) is reducible or irreducible as a [3-manifold](wikipedia://en/1018257).

:::

A link with an alternating diagram, i.e. an [alternating link](https://en.wikipedia.org/wiki/Alternating_link), will be non-split if and only if this diagram is connected. This is a result of the work of [William Menasco](wikipedia://en/16854432).[^o3] A split link has many connected, non-alternating link diagrams.
