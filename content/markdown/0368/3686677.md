# Unit disk graph

*Image: Unit disk graph.svg.* A collection of unit circles and the corresponding unit disk graph.

::: {#o1 .subject cue=lead name="Unit disk graph"}

In [geometric graph theory](wikipedia://en/3313527), a **unit disk graph** is the [intersection graph](wikipedia://en/7726759) of a family of [unit disks](wikipedia://en/252738) in the [Euclidean plane](wikipedia://en/15575410). That is, it is a graph with one vertex for each disk in the family, and with an edge between two vertices whenever the corresponding vertices lie within a unit distance of each other.

:::

They are commonly formed from a [Poisson point process](wikipedia://en/41597450), making them a simple example of a random structure.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There are several possible definitions of the unit disk graph, equivalent to each other up to a choice of scale factor:

- Unit disk graphs are the graphs formed from a collection of points in the Euclidean plane, with a vertex for each point and an edge connecting each pair of points whose distance is below a fixed threshold.
- Unit disk graphs are the [intersection graphs](wikipedia://en/7726759) of equal-radius circles, or of equal-radius disks. These graphs have a vertex for each circle or disk, and an edge connecting each pair of circles or disks that have a nonempty intersection.
- Unit disk graphs may be formed in a different way from a collection of equal-radius circles, by connecting two circles with an edge whenever one circle contains the center of the other circle.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every [induced subgraph](wikipedia://en/1655188) of a unit disk graph is also a unit disk graph. An example of a graph that is not a unit disk graph is the [star](wikipedia://en/19310129) $K_{1,6}$ with one central node connected to six leaves: if each of six unit disks touches a common unit disk, some two of the six disks must touch each other. Therefore, unit disk graphs cannot contain an induced $K_{1,6}$ subgraph.[^n1] Infinitely many other forbidden induced subgraphs are known.[^n2]

The number of unit disk graphs on $n$ labeled vertices is within an exponential factor of $n^{2n}$.[^n3] This rapid growth implies that unit disk graphs do not have bounded [twin-width](wikipedia://en/71380095).[^n4]

:::

::: {#o11 .application cue=heading name="Applications"}

## Applications {#Applications}

Beginning with the work of (Huson Sen 1995), unit disk graphs have been used in [computer science](https://en.wikipedia.org/wiki/Computer_science) to model the topology of [ad hoc wireless communication networks](https://en.wikipedia.org/wiki/Mobile_ad_hoc_network). In this application, nodes are connected through a direct wireless connection without a [base station](https://en.wikipedia.org/wiki/Base_station). It is assumed that all nodes are homogeneous and equipped with [omnidirectional antennas](https://en.wikipedia.org/wiki/Omnidirectional_antenna). Node locations are modelled as Euclidean points, and the area within which a signal from one node can be received by another node is modelled as a circle. If all nodes have transmitters of equal power, these circles are all equal. Random geometric graphs, formed as unit disk graphs with randomly generated disk centres, have also been used as a model of [percolation](wikipedia://en/187805) and various other phenomena.[^o13]

:::

## Computational complexity {#Computational_complexity}

If one is given a collection of unit disks (or their centres) in a space of any fixed dimension, it is possible to construct the corresponding unit disk graph in [linear time](https://en.wikipedia.org/wiki/Linear_time), by rounding the centres to nearby [integer grid](wikipedia://en/3333402) points, using a [hash table](wikipedia://en/13833) to find all pairs of centres within constant distance of each other, and filtering the resulting list of pairs for the ones whose circles intersect. The ratio of the number of pairs considered by this algorithm to the number of edges in the eventual graph is a constant, giving the linear time bound. However, this constant [grows exponentially](wikipedia://en/191933) as a function of the dimension.[^n5]

It is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) (more specifically, complete for the [existential theory of the reals](https://en.wikipedia.org/wiki/Existential_theory_of_the_reals)) to determine whether a graph, given without geometry, can be represented as a unit disk graph.[^o16] Additionally, it is provably impossible in polynomial time to output explicit coordinates of a unit disk graph representation: there exist unit disk graphs that require exponentially many bits of precision in any such representation.[^o17]

However, many important and difficult graph optimization problems such as [maximum independent set](https://en.wikipedia.org/wiki/Maximum_independent_set), [graph coloring](wikipedia://en/426743), and minimum [dominating set](wikipedia://en/1747972) can be [approximated](wikipedia://en/563105) efficiently by using the geometric structure of these graphs,[^o18] and the [maximum clique problem](https://en.wikipedia.org/wiki/Maximum_clique_problem) can be solved exactly for these graphs in polynomial time, given a disk representation.[^o19] Even if a disk representation is not known, and an abstract graph is given as input, it is possible in polynomial time to produce either a maximum clique or a proof that the graph is not a unit disk graph,[^n6] and to 3-approximate the optimum coloring by using a [greedy coloring](wikipedia://en/21051195) algorithm.[^n7]

## See also {#See_also}

- [Barrier resilience](https://en.wikipedia.org/wiki/Barrier_resilience), an algorithmic problem of breaking cycles in unit disk graphs
- [Indifference graph](wikipedia://en/42535190), a one-dimensional analogue of the unit disk graphs
- [Penny graph](wikipedia://en/53242630), the unit disk graphs for which the disks can be tangent but not overlap ([contact graph](wikipedia://en/51513238))
- [Coin graph](https://en.wikipedia.org/wiki/Coin_graph), the contact graph of (not necessarily unit-sized) disks
- [Vietoris–Rips complex](wikipedia://en/13056778), a generalization of the unit disk graph that constructs higher-order topological spaces from unit distances in a metric space
- [Unit distance graph](wikipedia://en/7158665), a graph formed by connecting points that are at distance exactly one rather than (as here) at most a given threshold
