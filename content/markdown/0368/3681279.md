# Non-negative matrix factorization

Dimensionality reduction

*Image: NMF.png.* Illustration of approximate non-negative matrix factorization: the matrix $\mathbf{V}$ is represented by the two smaller matrices $\mathbf{W}$ and $\mathbf{H}$, which, when multiplied, approximately reconstruct $\mathbf{V}$.

::: {#o1 .subject cue=lead name="Non-negative matrix factorization"}

**Non-negative matrix factorization** (**NMF** or **NNMF**), also **non-negative matrix approximation**[^o27][^o2] is a group of [algorithms](wikipedia://en/775) in [multivariate analysis](https://en.wikipedia.org/wiki/Multivariate_analysis) and [linear algebra](wikipedia://en/18422) where a [matrix](wikipedia://en/20556859) $\mathbf{V}$ is [factorized](wikipedia://en/253873) into (usually) two matrices $\mathbf{W}$ and $\mathbf{H}$, with the property that all three matrices have no negative elements. This non-negativity makes the resulting matrices easier to inspect. Also, in applications such as processing of audio spectrograms or muscular activity, non-negativity is inherent to the data being considered. Since the problem is not exactly solvable in general, it is commonly approximated numerically.

:::

NMF finds applications in such fields as [astronomy](https://en.wikipedia.org/wiki/Astronomy),[^o75][^o76] [computer vision](https://en.wikipedia.org/wiki/Computer_vision), [document clustering](https://en.wikipedia.org/wiki/Document_clustering),[^o27] [missing data imputation](wikipedia://en/1309220),[^o3] [chemometrics](wikipedia://en/314204), [audio signal processing](https://en.wikipedia.org/wiki/Audio_signal_processing), [recommender systems](wikipedia://en/596646),[^o4][^o5] and [bioinformatics](wikipedia://en/4214).[^o6]

## History {#History}

In [chemometrics](wikipedia://en/314204) non-negative matrix factorization has a long history under the name "self modeling curve resolution".[^o8] In this framework the vectors in the right matrix are continuous curves rather than discrete vectors. Also early work on non-negative matrix factorizations was performed by a Finnish group of researchers in the 1990s under the name *positive matrix factorization*.[^o11] It became more widely known as *non-negative matrix factorization* after Lee and [Seung](https://en.wikipedia.org/wiki/Sebastian_Seung) investigated the properties of the algorithm and published some simple and useful algorithms for two types of factorizations.[^o12][^o13]

## Background {#Background}

Let matrix $\mathbf{V}$ be the product of the matrices $\mathbf{W}$ and $\mathbf{H}$,

$$\mathbf{V} = \mathbf{W} \mathbf{H} \,.$$

Matrix multiplication can be implemented as computing the column vectors of $\mathbf{V}$ as linear combinations of the column vectors in $\mathbf{W}$ using coefficients supplied by columns of $\mathbf{H}$. That is, each column of $\mathbf{V}$ can be computed as follows:

$$\mathbf{v}_i = \mathbf{W} \mathbf{h}_{i} \,,$$

where $\mathbf{v}_{i}$ is the $i$-th column vector of the product matrix $\mathbf{V}$ and $\mathbf{h}_{i}$ is the $i$-th column vector of the matrix $\mathbf{H}$.

When multiplying matrices, the dimensions of the factor matrices may be significantly lower than those of the product matrix and it is this property that forms the basis of NMF. NMF generates factors with significantly reduced dimensions compared to the original matrix. For example, if $\mathbf{V}$ is an $m \times n$ matrix, $\mathbf{W}$ is an $m \times p$ matrix, and $\mathbf{H}$ is a $p \times n$ matrix then $p$ can be significantly less than both $m$ and $n$.

Here is an example based on a text-mining application:

- Let the input matrix (the matrix to be factored) be $\mathbf{V}$ with 10000 rows and 500 columns where words are in rows and documents are in columns. That is, we have 500 documents indexed by 10000 words. It follows that a column vector $\mathbf{v}$ in $\mathbf{V}$ represents a document.
- Assume we ask the algorithm to find 10 features in order to generate a *features matrix* $\mathbf{W}$ with 10000 rows and 10 columns and a *coefficients matrix* $\mathbf{H}$ with 10 rows and 500 columns.
- The product of $\mathbf{W}$ and $\mathbf{H}$ is a matrix with 10000 rows and 500 columns, the same shape as the input matrix $\mathbf{V}$ and, if the factorization worked, it is a reasonable approximation to the input matrix $\mathbf{V}$.
- From the treatment of matrix multiplication above it follows that each column in the product matrix $\mathbf{WH}$ is a linear combination of the 10 column vectors in the features matrix $\mathbf{W}$ with coefficients supplied by the coefficients matrix $\mathbf{H}$.

This last point is the basis of NMF because we can consider each original document in our example as being built from a small set of hidden features. NMF generates these features.

It is useful to think of each feature (column vector) in the features matrix $\mathbf{W}$ as a document archetype comprising a set of words where each word's cell value defines the word's rank in the feature: The higher a word's cell value the higher the word's rank in the feature. A column in the coefficients matrix $\mathbf{H}$ represents an original document with a cell value defining the document's rank for a feature. We can now reconstruct a document (column vector) from our input matrix by a linear combination of our features (column vectors in $\mathbf{W}$) where each feature is weighted by the feature's cell value from the document's column in $\mathbf{H}$.

## Clustering property {#Clustering_property}

NMF has an inherent clustering property,[^o60] i.e., it automatically clusters the columns of input data $\mathbf{V} = (v_1, \dots, v_n)$.

More specifically, the approximation of $\mathbf{V}$ by $\mathbf{V} \simeq \mathbf{W}\mathbf{H}$ is achieved by finding $W$ and $H$ that minimize the error function (using the [Frobenius norm](wikipedia://en/1543735#Frobenius_norm))

$\left\| V - WH \right\|_F,$ subject to $W \geq 0, H \geq 0.$,

If we furthermore impose an orthogonality constraint on $\mathbf{H}$, i.e. $\mathbf{H}\mathbf{H}^T = I$, then the above minimization is mathematically equivalent to the minimization of [K-means clustering](wikipedia://en/1860407).[^o60]

Furthermore, the computed $H$ gives the cluster membership, i.e., if $\mathbf{H}_{kj} > \mathbf{H}_{ij}$ for all *i* ≠ *k*, this suggests that the input data $v_j$ belongs to $k$-th cluster. The computed $W$ gives the cluster centroids, i.e., the $k$-th column gives the cluster centroid of $k$-th cluster. This centroid's representation can be significantly enhanced by convex NMF.

When the orthogonality constraint $\mathbf{H}\mathbf{H}^T = I$ is not explicitly imposed, the orthogonality holds to a large extent, and the clustering property holds too.

When the error function to be used is [Kullback–Leibler divergence](wikipedia://en/1115052), NMF is identical to the [probabilistic latent semantic analysis](wikipedia://en/2088675) (PLSA), a popular document clustering method.[^o16]

## Types {#Types}

### Approximate non-negative matrix factorization {#Approximate_non-negative_matrix_factorization}

Usually the number of columns of $\mathbf{W}$ and the number of rows of $\mathbf{H}$ in NMF are selected so the product $\mathbf{WH}$ will become an approximation to $\mathbf{V}$. The full decomposition of $\mathbf{V}$ then amounts to the two non-negative matrices $\mathbf{W}$ and $\mathbf{H}$ as well as a residual $\mathbf{U}$, such that: $\mathbf{V} = \mathbf{WH} + \mathbf{U}$. The elements of the residual matrix can either be negative or positive.

When $\mathbf{W}$ and $\mathbf{H}$ are smaller than $\mathbf{V}$ they become easier to store and manipulate. Another reason for factorizing $\mathbf{V}$ into smaller matrices $\mathbf{W}$ and $\mathbf{H}$, is that if one's goal is to approximately represent the elements of $\mathbf{V}$ by significantly less data, then one has to infer some latent structure in the data.

### Convex non-negative matrix factorization {#Convex_non-negative_matrix_factorization}

In standard NMF, matrix factor $\mathbf{W} \in \mathbf{R}_{+}^{m \times k}$， i.e., $\mathbf{W}$ can be anything in that space. Convex NMF[^o20] restricts the columns of $\mathbf{W}$ to [convex combinations](wikipedia://en/794534) of the input data vectors $(v_1, \dots, v_n)$. This greatly improves the quality of data representation of $\mathbf{W}$. Furthermore, the resulting matrix factor $\mathbf{H}$ becomes more sparse and orthogonal.

### Nonnegative rank factorization {#Nonnegative_rank_factorization}

In case the [nonnegative rank](wikipedia://en/13835110) of $\mathbf{V}$ is equal to its actual rank, $\mathbf{V} = \mathbf{WH}$ is called a nonnegative rank factorization (NRF).[^o22][^o23][^o24] The problem of finding the NRF of $\mathbf{V}$, if it exists, is known to be NP-hard.[^o25]

### Different cost functions and regularizations {#Different_cost_functions_and_regularizations}

There are different types of non-negative matrix factorizations. The different types arise from using different [cost functions](wikipedia://en/442137) for measuring the divergence between $\mathbf{V}$ and $\mathbf{WH}$ and possibly by [regularization](wikipedia://en/2009061) of the $\mathbf{W}$ and/or $\mathbf{H}$ matrices.[^o27]

Two simple divergence functions studied by Lee and Seung are the squared error (or [Frobenius norm](https://en.wikipedia.org/wiki/Frobenius_norm)) and an extension of the Kullback–Leibler divergence to positive matrices (the original [Kullback–Leibler divergence](wikipedia://en/1115052) is defined on probability distributions). Each divergence leads to a different NMF algorithm, usually minimizing the divergence using iterative update rules.

The factorization problem in the squared error version of NMF may be stated as: Given a matrix $\mathbf{V}$ find nonnegative matrices W and H that minimize the function

$$F(\mathbf{W},\mathbf{H}) = \left\|\mathbf{V} - \mathbf{WH} \right\|^2_F$$

Another type of NMF for images is based on the [total variation norm](https://en.wikipedia.org/wiki/Total_variation_norm).[^o28]

When [L1 regularization](https://en.wikipedia.org/wiki/Tikhnov_regularization) (akin to [Lasso](wikipedia://en/22349350)) is added to NMF with the mean squared error cost function, the resulting problem may be called **non-negative sparse coding** due to the similarity to the [sparse coding](https://en.wikipedia.org/wiki/Sparse_coding) problem,[^o29][^o30] although it may also still be referred to as NMF.[^o31]

### Online NMF {#Online_NMF}

Many standard NMF algorithms analyze all the data together; i.e., the whole matrix is available from the start. This may be unsatisfactory in applications where there are too many data to fit into memory or where the data are provided in [streaming](https://en.wikipedia.org/wiki/Data_stream) fashion. One such use is for [collaborative filtering](https://en.wikipedia.org/wiki/Collaborative_filtering) in [recommendation systems](wikipedia://en/596646), where there may be many users and many items to recommend, and it would be inefficient to recalculate everything when one user or one item is added to the system. The cost function for optimization in these cases may or may not be the same as for standard NMF, but the algorithms need to be rather different.[^o33][^o34]

### Convolutional NMF {#Convolutional_NMF}

If the columns of $\mathbf{V}$ represent data sampled over spatial or temporal dimensions, e.g. time signals, images, or video, features that are equivariant w.r.t. shifts along these dimensions can be learned by Convolutional NMF. In this case, $\mathbf{W}$ is sparse with columns having local non-zero weight windows that are shared across shifts along the spatio-temporal dimensions of $\mathbf{V}$, representing [convolution kernels](https://en.wikipedia.org/wiki/Kernel_%28image_processing%29). By spatio-temporal pooling of $\mathbf{H}$ and repeatedly using the resulting representation as input to convolutional NMF, deep feature hierarchies can be learned.[^o36]

## Algorithms {#Algorithms}

There are several ways in which the $\mathbf{W}$ and $\mathbf{H}$ may be found: Lee and Seung's [multiplicative update rule](https://en.wikipedia.org/wiki/Multiplicative_Weight_Update_Method)[^o13] has been a popular method due to the simplicity of implementation. This algorithm is:

initialize: $\mathbf{W}$ and $\mathbf{H}$ non negative.

Then update the values in $\mathbf{W}$ and $\mathbf{H}$ by computing the following, with $n$ as an index of the iteration.

$$\mathbf{H}_{[i,j]}^{n+1} \leftarrow \mathbf{H}_{[i,j]}^n \frac{((\mathbf{W}^n)^T\mathbf{V})_{[i,j]}}{((\mathbf{W}^n)^T\mathbf{W}^n\mathbf{H}^n)_{[i,j]}}$$

and

$$\mathbf{W}_{[i,j]}^{n+1} \leftarrow \mathbf{W}_{[i,j]}^n \frac{(\mathbf{V}(\mathbf{H}^{n+1})^T)_{[i,j]}}{(\mathbf{W}^n\mathbf{H}^{n+1}(\mathbf{H}^{n+1})^T)_{[i,j]}}$$

Until $\mathbf{W}$ and $\mathbf{H}$ are stable.

Note that the updates are done on an element by element basis not matrix multiplication.

We note that the multiplicative factors for $\mathbf{W}$ and $\mathbf{H}$, i.e. the $\frac{\mathbf{W}^\mathsf{T} \mathbf{V}}{\mathbf{W}^\mathsf{T} \mathbf{W} \mathbf{H}}$ and ${\textstyle {\frac {\mathbf {V} \mathbf {H} ^{\mathsf {T}} }{\mathbf {W} \mathbf {H} \mathbf {H} ^{\mathsf {T}}}}}$ terms, are [matrices of ones](wikipedia://en/690246) when $\mathbf{V} = \mathbf{W} \mathbf{H}$.

More recently other algorithms have been developed. Some approaches are based on alternating [non-negative least squares](wikipedia://en/41740999): in each step of such an algorithm, first $\mathbf{H}$ is fixed and $\mathbf{W}$ found by a non-negative least squares solver, then $\mathbf{W}$ is fixed and $\mathbf{H}$ is found analogously. The procedures used to solve for $\mathbf{W}$ and $\mathbf{H}$ may be the same[^o39] or different, as some NMF variants regularize one of $\mathbf{W}$ and $\mathbf{H}$.[^o29] Specific approaches include the projected [gradient descent](wikipedia://en/201489) methods,[^o39][^o40] the [active set](https://en.wikipedia.org/wiki/Active_set) method,[^o4][^o41] the optimal gradient method,[^o42] coordinate descent,[^o43] and the block principal pivoting method[^o44] among several others.[^o45]

Current algorithms are sub-optimal in that they only guarantee finding a local minimum, rather than a global minimum of the cost function. A provably optimal algorithm is unlikely in the near future as the problem has been shown to generalize the k-means clustering problem which is known to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete).[^o46] However, as in many other data mining applications, a local minimum may still prove to be useful.

In addition to the optimization step, initialization has a significant effect on NMF. The initial values chosen for $\mathbf{W}$ and $\mathbf{H}$ may affect not only the rate of convergence, but also the overall error at convergence. Some options for initialization include complete randomization, [SVD](wikipedia://en/142207), k-means clustering, and more advanced strategies based on these and other paradigms.[^o47]

*Image: Fractional\_Residual\_Variances\_comparison,\_PCA\_and\_NMF.pdf.* Fractional residual variance (FRV) plots for PCA and sequential NMF;[^o76] for PCA, the theoretical values are the contribution from the residual eigenvalues. In comparison, the FRV curves for PCA reaches a flat plateau where no signal are captured effectively; while the NMF FRV curves are declining continuously, indicating a better ability to capture signal. The FRV curves for NMF also converges to higher levels than PCA, indicating the less-overfitting property of NMF.

### Variable rank methods {#Variable_rank_methods}

Between any two local minima of rank $p$, there is a "mostly downhill" path between them in the space of rank $2p$ solutions.[^o49] This motivates the idea of rank expansion and contraction as tools to escape poor local minima. To increase the rank, new components can be discovered using the generalized singular value decomposition.[^o50] To decrease the rank, pairs of components may be greedily merged by a least-loss criterion.[^o49] These techniques can be used in conjunction with a variety of NMF algorithms. Rank-modification does not necessarily increase computation time, largely because NMF algorithms frequently slow at one or more "plateaus" and empirically one finds that higher-rank solutions are less likely to plateau.[^o49]

### Sequential NMF {#Sequential_NMF}

The sequential construction of NMF components ($\mathbf{W}$ and $\mathbf{H}$) was firstly used to relate NMF with [Principal Component Analysis](https://en.wikipedia.org/wiki/Principal_Component_Analysis) (PCA) in astronomy.[^o77] The contribution from the PCA components are ranked by the magnitude of their corresponding eigenvalues; for NMF, its components can be ranked empirically when they are constructed one by one (sequentially), i.e., learn the $(n+1)$-th component with the first $n$ components constructed.

The contribution of the sequential NMF components can be compared with the [Karhunen–Loève theorem](https://en.wikipedia.org/wiki/Karhunen–Loève_theorem), an application of PCA, using the plot of eigenvalues. A typical choice of the number of components with PCA is based on the "elbow" point, then the existence of the flat plateau is indicating that PCA is not capturing the data efficiently, and at last there exists a sudden drop reflecting the capture of random noise and falls into the regime of overfitting.[^o80][^o82] For sequential NMF, the plot of eigenvalues is approximated by the plot of the fractional residual variance curves, where the curves decreases continuously, and converge to a higher level than PCA,[^o76] which is the indication of less over-fitting of sequential NMF.

### Exact NMF {#Exact_NMF}

Exact solutions for the variants of NMF can be expected (in polynomial time) when additional constraints hold for matrix $\mathbf{V}$. A polynomial time algorithm for solving nonnegative rank factorization if $\mathbf{V}$ contains a monomial sub matrix of rank equal to its rank was given by Campbell and Poole in 1981.[^o53] Kalofolias and Gallopoulos (2012)[^o54] solved the symmetric counterpart of this problem, where $\mathbf{V}$ is symmetric and contains a diagonal principal sub matrix of rank r. Their algorithm runs in $O(\operatorname{rm}^{2})$ time in the dense case. Arora, Ge, Halpern, Mimno, Moitra, Sontag, Wu, & Zhu (2013) give a polynomial time algorithm for exact NMF that works for the case where one of the factors W satisfies a separability condition.[^o55]

## Relation to other techniques {#Relation_to_other_techniques}

In *Learning the parts of objects by non-negative matrix factorization* Lee and Seung[^o57] proposed NMF mainly for parts-based decomposition of images. It compares NMF to [vector quantization](wikipedia://en/47805) and [principal component analysis](wikipedia://en/76340), and shows that although the three techniques may be written as factorizations, they implement different constraints and therefore produce different results.

*Image: Restricted Boltzmann machine.svg.* NMF as a probabilistic graphical model: visible units ($\mathbf{V}$) are connected to hidden units ($\mathbf{H}$) through weights $\mathbf{W}$, so that $\mathbf{V}$ is [generated](wikipedia://en/1222578) from a probability distribution with mean $\sum_a W_{ia}h_a$.[^o12]

It was later shown that some types of NMF are an instance of a more general probabilistic model called "multinomial PCA".[^o58] When NMF is obtained by minimizing the [Kullback–Leibler divergence](wikipedia://en/1115052), it is in fact equivalent to another instance of multinomial PCA, [probabilistic latent semantic analysis](wikipedia://en/2088675),[^o59] trained by [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimation. That method is commonly used for analyzing and clustering textual data and is also related to the [latent class model](wikipedia://en/4094720).

NMF with the least-squares objective is equivalent to a relaxed form of [K-means clustering](wikipedia://en/1860407): the matrix factor $\mathbf{W}$ contains cluster centroids and $\mathbf{H}$ contains cluster membership indicators.[^o60][^o61] This provides a theoretical foundation for using NMF for data clustering. However, k-means does not enforce non-negativity on its centroids, so the closest analogy is in fact with "semi-NMF".

NMF can be seen as a two-layer [directed graphical](wikipedia://en/203996) model with one layer of observed random variables and one layer of hidden random variables.[^o62]

NMF extends beyond matrices to tensors of arbitrary order.[^o63][^o64][^o65] This extension may be viewed as a non-negative counterpart to, e.g., the [PARAFAC](https://en.wikipedia.org/wiki/PARAFAC) model.

Other extensions of NMF include joint factorization of several data matrices and tensors where some factors are shared. Such models are useful for sensor fusion and relational learning.[^o66]

NMF is an instance of nonnegative [quadratic programming](wikipedia://en/40324), just like the [support vector machine](wikipedia://en/65309) (SVM). However, SVM and NMF are related at a more intimate level than that of NQP, which allows direct application of the solution algorithms developed for either of the two methods to problems in both domains.[^o67]

## Uniqueness {#Uniqueness}

The factorization is not unique: A matrix and its [inverse](https://en.wikipedia.org/wiki/Inverse_matrix) can be used to transform the two factorization matrices by, e.g.,[^o69]

$$\mathbf{WH} = \mathbf{WBB}^{-1}\mathbf{H}$$

If the two new matrices $\mathbf{\tilde{W} = WB}$ and $\mathbf{\tilde{H}}=\mathbf{B}^{-1}\mathbf{H}$ are [non-negative](https://en.wikipedia.org/wiki/Non-negative_matrix) they form another parametrization of the factorization.

The non-negativity of $\mathbf{\tilde{W}}$ and $\mathbf{\tilde{H}}$ applies at least if $\mathbf{B}$ is a non-negative [monomial matrix](https://en.wikipedia.org/wiki/Monomial_matrix). In this simple case it will just correspond to a scaling and a [permutation](wikipedia://en/44027).

More control over the non-uniqueness of NMF is obtained with sparsity constraints.[^o70]

## Applications {#Applications}

### Astronomy {#Astronomy}

In astronomy, NMF is a promising method for [dimension reduction](https://en.wikipedia.org/wiki/Dimension_reduction) in the sense that astrophysical signals are non-negative. NMF has been applied to the spectroscopic observations[^o74][^o75] and the direct imaging observations[^o76] as a method to study the common properties of astronomical objects and post-process the astronomical observations. The advances in the spectroscopic observations by Blanton & Roweis (2007)[^o75] takes into account of the uncertainties of astronomical observations, which is later improved by Zhu (2016)[^o77] where missing data are also considered and [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing) is enabled. Their method is then adopted by Ren et al. (2018)[^o76] to the direct imaging field as one of the [methods of detecting exoplanets](wikipedia://en/7290120), especially for the direct imaging of [circumstellar disks](https://en.wikipedia.org/wiki/Circumstellar_disks).

Ren et al. (2018)[^o76] are able to prove the stability of NMF components when they are constructed sequentially (i.e., one by one), which enables the [linearity](wikipedia://en/91591) of the NMF modeling process; the [linearity](wikipedia://en/91591) property is used to separate the stellar light and the light scattered from the [exoplanets](https://en.wikipedia.org/wiki/Exoplanets) and [circumstellar disks](https://en.wikipedia.org/wiki/Circumstellar_disks).

In direct imaging, to reveal the faint exoplanets and circumstellar disks from bright the surrounding stellar lights, which has a typical contrast from 10⁵ to 10¹⁰, various statistical methods have been adopted,[^o78][^o79][^o80] however the light from the exoplanets or circumstellar disks are usually over-fitted, where forward modeling have to be adopted to recover the true flux.[^o81][^o82] Forward modeling is currently optimized for point sources,[^o82] however not for extended sources, especially for irregularly shaped structures such as circumstellar disks. In this situation, NMF has been an excellent method, being less over-fitting in the sense of the non-negativity and [sparsity](https://en.wikipedia.org/wiki/Sparsity) of the NMF modeling coefficients, therefore forward modeling can be performed with a few scaling factors,[^o76] rather than a computationally intensive data re-reduction on generated models.

### Data imputation {#Data_imputation}

To impute missing data in statistics, NMF can take missing data while minimizing its cost function, rather than treating these missing data as zeros.[^o3] This makes it a mathematically proven method for [data imputation](wikipedia://en/1309220) in statistics.[^o3] By first proving that the missing data are ignored in the cost function, then proving that the impact from missing data can be as small as a second order effect, Ren et al. (2020)[^o3] studied and applied such an approach for the field of astronomy. Their work focuses on two-dimensional matrices, specifically, it includes mathematical derivation, simulated data imputation, and application to on-sky data.

The data imputation procedure with NMF can be composed of two steps. First, when the NMF components are known, Ren et al. (2020) proved that impact from missing data during data imputation ("target modeling" in their study) is a second order effect. Second, when the NMF components are unknown, the authors proved that the impact from missing data during component construction is a first-to-second order effect.

Depending on the way that the NMF components are obtained, the former step above can be either independent or dependent from the latter. In addition, the imputation quality can be increased when the more NMF components are used, see Figure 4 of Ren et al. (2020) for their illustration.[^o3]

### Text mining {#Text_mining}

NMF can be used for [text mining](wikipedia://en/318439) applications. In this process, a [*document-term* matrix](https://en.wikipedia.org/wiki/Document-term_matrix) is constructed with the weights of various terms (typically weighted word frequency information) from a set of documents. This matrix is factored into a *term-feature* and a *feature-document* matrix. The features are derived from the contents of the documents, and the feature-document matrix describes [data clusters](https://en.wikipedia.org/wiki/Data_cluster) of related documents.

One specific application used hierarchical NMF on a small subset of scientific abstracts from [PubMed](https://en.wikipedia.org/wiki/PubMed).[^o85] Another research group clustered parts of the [Enron](https://en.wikipedia.org/wiki/Enron) email dataset[^o86] with 65,033 messages and 91,133 terms into 50 clusters.[^o87] NMF has also been applied to citations data, with one example clustering [English Wikipedia](https://en.wikipedia.org/wiki/English_Wikipedia) articles and [scientific journals](https://en.wikipedia.org/wiki/Scientific_journal) based on the outbound scientific citations in English Wikipedia.[^o88]

Arora, Ge, Halpern, Mimno, Moitra, Sontag, Wu, & Zhu (2013) have given polynomial-time algorithms to learn topic models using NMF. The algorithm assumes that the topic matrix satisfies a separability condition that is often found to hold in these settings.[^o55]

Hassani, Iranmanesh and Mansouri (2019) proposed a feature agglomeration method for term-document matrices which operates using NMF. The algorithm reduces the term-document matrix into a smaller matrix more suitable for text clustering.[^o89]

### Spectral data analysis {#Spectral_data_analysis}

NMF is also used to analyze spectral data; one such use is in the classification of space objects and debris.[^o91]

### Scalable Internet distance prediction {#Scalable_Internet_distance_prediction}

NMF is applied in scalable Internet distance (round-trip time) prediction. For a network with $N$ hosts, with the help of NMF, the distances of all the $N^2$ end-to-end links can be predicted after conducting only $O(N)$ measurements. This kind of method was firstly introduced in Internet Distance Estimation Service (IDES).[^o93] Afterwards, as a fully decentralized approach, Phoenix network coordinate system[^o94] is proposed. It achieves better overall prediction accuracy by introducing the concept of weight.

### Non-stationary speech denoising {#Non-stationary_speech_denoising}

Speech denoising has been a long lasting problem in [audio signal processing](https://en.wikipedia.org/wiki/Audio_signal_processing). There are many algorithms for denoising if the noise is stationary. For example, the [Wiener filter](wikipedia://en/1216721) is suitable for additive [Gaussian noise](wikipedia://en/1387827). However, if the noise is non-stationary, the classical denoising algorithms usually have poor performance because the statistical information of the non-stationary noise is difficult to estimate. Schmidt et al.[^o96] use NMF to do speech denoising under non-stationary noise, which is completely different from classical statistical approaches. The key idea is that clean speech signal can be sparsely represented by a speech dictionary, but non-stationary noise cannot. Similarly, non-stationary noise can also be sparsely represented by a noise dictionary, but speech cannot.

The algorithm for NMF denoising goes as follows. Two dictionaries, one for speech and one for noise, need to be trained offline. Once a noisy speech is given, we first calculate the magnitude of the Short-Time-Fourier-Transform. Second, separate it into two parts via NMF, one can be sparsely represented by the speech dictionary, and the other part can be sparsely represented by the noise dictionary. Third, the part that is represented by the speech dictionary will be the estimated clean speech.

### Population genetics {#Population_genetics}

Sparse NMF is used in [Population genetics](wikipedia://en/219268) for estimating individual admixture coefficients, detecting genetic clusters of individuals in a population sample or evaluating [genetic admixture](https://en.wikipedia.org/wiki/Genetic_admixture) in sampled genomes. In human genetic clustering, NMF algorithms provide estimates similar to those of the computer program STRUCTURE, but the algorithms are more efficient computationally and allow analysis of large population genomic data sets.[^o98]

### Bioinformatics {#Bioinformatics}

NMF has been successfully applied in [bioinformatics](wikipedia://en/4214) for clustering [gene expression](https://en.wikipedia.org/wiki/Gene_expression) and [DNA methylation](https://en.wikipedia.org/wiki/DNA_methylation) data and finding the genes most representative of the clusters.[^o30][^o100][^o101][^o102] In the analysis of cancer mutations it has been used to identify common patterns of mutations that occur in many cancers and that probably have distinct causes.[^o103] NMF techniques can identify sources of variation such as cell types, disease subtypes, population stratification, tissue composition, and tumor clonality.[^o104]

A particular variant of NMF, namely Non-Negative Matrix Tri-Factorization (NMTF),[^o105] has been use for [drug repurposing](https://en.wikipedia.org/wiki/Drug_repositioning) tasks in order to predict novel protein targets and therapeutic indications for approved drugs[^o106] and to infer pair of synergic anticancer drugs.[^o107]

### Nuclear imaging {#Nuclear_imaging}

NMF, also referred in this field as factor analysis, has been used since the 1980s[^o109] to analyze sequences of images in [SPECT](https://en.wikipedia.org/wiki/SPECT) and [PET](https://en.wikipedia.org/wiki/Positron_emission_tomography) dynamic medical imaging. Non-uniqueness of NMF was addressed using sparsity constraints.[^o110] [^o111] [^o112]

:::

## Current research {#Current_research}

Current research (since 2010) in nonnegative matrix factorization includes, but is not limited to,

1. Algorithmic: searching for global minima of the factors and factor initialization.[^o114]
1. Scalability: how to factorize million-by-billion matrices, which are commonplace in Web-scale data mining, e.g., see Distributed Nonnegative Matrix Factorization (DNMF),[^o115] Scalable Nonnegative Matrix Factorization (ScalableNMF),[^o116] Distributed Stochastic Singular Value Decomposition.[^o117]
1. Online: how to update the factorization when new data comes in without recomputing from scratch, e.g., see online CNSC[^o118]
1. Collective (joint) factorization: factorizing multiple interrelated matrices for multiple-view learning, e.g. multi-view clustering, see CoNMF[^o119] and MultiNMF[^o120]
1. Cohen and Rothblum 1993 problem: whether a rational matrix always has an NMF of minimal inner dimension whose factors are also rational. Recently, this problem has been answered negatively.[^o121]
