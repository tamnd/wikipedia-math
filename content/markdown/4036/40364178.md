# PS Power and Sample Size

::: {#o3 .subject cue=lead name="PS Power and Sample Size"}

**PS** is an interactive [computer program](https://en.wikipedia.org/wiki/Computer_program) for performing [statistical power](https://en.wikipedia.org/wiki/Statistical_power) and [sample size calculations](wikipedia://en/1776839).[^o4][^o5][^o6]

:::

## Program description {#Program_description}

The P program can be used for studies with dichotomous, continuous, or survival response measures. The user specifies the [alternative hypothesis](https://en.wikipedia.org/wiki/Alternative_hypothesis) in terms of differing response rates, means, survival times, [relative risks](wikipedia://en/2622159), or [odds ratios](wikipedia://en/406880). Matched or independent study designs may be used. Power, sample size, and the detectable alternative hypothesis are interrelated. The user specifies any two of these three quantities and the program derives the third. A description of each calculation, written in English, is generated and may be copied into the user's documents. Interactive help is available. The program provides methods that are appropriate for matched and independent t-tests,[^o4] survival analysis,[^o8] matched[^o9] and unmatched[^o10][^o11] studies of dichotomous events, the Mantel-Haenszel test,[^o12] and linear regression.[^o5] The program can generate graphs of the relationships between power, sample size and the detectable alternative hypothesis. It can plot graphs of any two of these variables while holding the third constant. Linear or logarithmic axes may be used and multiple curves can be plotted on each graph. Graphs may be copied and pasted into other documents or programs for further editing.

## Reviews {#Reviews}

Reviews of this program have been published by McCrum-Gardner,[^o14] Thomas and Krebs,[^o15] Stawicki[^o16] and Pezzullo.[^o17]

## Web version {#Web_version}

A web-based version of the program is also available at [https://cqsclinical.app.vumc.org/ps/](https://cqsclinical.app.vumc.org/ps/).
