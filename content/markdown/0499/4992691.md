# Petersen

::: {#o1 .subject cue=lead name="Petersen"}

**Petersen** is a common [Danish](https://en.wikipedia.org/wiki/Danish_language) [patronymic](https://en.wikipedia.org/wiki/Patronymic) [surname](https://en.wikipedia.org/wiki/Surname), meaning *"son of [Peter](https://en.wikipedia.org/wiki/Peter_%28name%29)"*.[^o3] **Petersén** is a Swedish orthographic variant.

:::
