# Logical cube

::: {#o1 .subject cue=lead name="Logical cube"}

In the system of [Aristotelian logic](wikipedia://en/321652), the **logical cube** is a [diagram](https://en.wikipedia.org/wiki/Diagram) representing the different ways in which each of the eight [propositions](wikipedia://en/81094) of the [system](wikipedia://en/396102) is logically related ('opposed') to each of the others.[^o2] The system is also useful in the analysis of [syllogistic logic](wikipedia://en/321652), serving to identify the allowed logical conversions from one type to another.[^o3]

:::
