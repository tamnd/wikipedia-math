# Biweight midcorrelation

::: {#o1 .subject cue=lead name="Biweight midcorrelation"}

In statistics, **biweight midcorrelation** (also called **bicor**) is a [measure of similarity](wikipedia://en/1004743) between samples. It is [median](wikipedia://en/18837)-based, rather than [mean](https://en.wikipedia.org/wiki/Mean)-based, thus is less sensitive to outliers, and can be a robust alternative to other similarity metrics, such as [Pearson correlation](https://en.wikipedia.org/wiki/Pearson_product-moment_correlation_coefficient) or [mutual information](wikipedia://en/427282).[^o2]

:::

## Derivation {#Derivation}

Here we find the biweight midcorrelation of two vectors $x$ and $y$, with $i=1,2, \ldots,m$ items, representing each item in the vector as $x_1, x_2, \ldots, x_m$ and $y_1, y_2, \ldots, y_m$. First, we define $\operatorname{med}(x)$ as the [median](wikipedia://en/18837) of a vector $x$ and $\operatorname{mad}(x)$ as the [median absolute deviation](wikipedia://en/10050999) (MAD), then define $u_i$ and $v_i$ as,

$$\begin{aligned} u_i &= \frac{x_i - \operatorname{med}(x)}{9 \operatorname{mad}(x)},\\ v_i &= \frac{y_i - \operatorname{med}(y)}{9 \operatorname{mad}(y)}. \end{aligned}$$

Now we define the *weights* $w_i^{(x)}$ and $w_i^{(y)}$ as,

$$\begin{aligned} w_i^{(x)} &= \left(1-u_i^2\right)^2 I\left(1-|u_i|\right)\\ w_i^{(y)} &= \left(1-v_i^2\right)^2 I\left(1-|v_i|\right) \end{aligned}$$

where $I$ is the identity function where,

$$I(x) = \begin{cases}1, & \text{if } x >0\\ 0, & \text{otherwise}\end{cases}$$

Then we normalize so that the sum of the weights is 1:

$$\begin{aligned} \tilde{x}_i &= \frac{\left(x_i - \operatorname{med}(x)\right) w_i^{(x)}}{\sqrt{\sum_{j=1}^m \left[(x_j -\operatorname{med}(x)) w_j^{(x)}\right]^2}}\\ \tilde{y}_i &= \frac{\left(y_i - \operatorname{med}(y)\right) w_i^{(y)}}{\sqrt{\sum_{j=1}^m \left[(y_j -\operatorname{med}(y)) w_j^{(y)}\right]^2}}. \end{aligned}$$

Finally, we define biweight midcorrelation as,

$$\mathrm{bicor}\left(x, y\right) = \sum_{i=1}^m \tilde{x}_i \tilde{y}_i$$

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

Biweight midcorrelation has been shown to be more robust in evaluating similarity in gene expression networks,[^o6] and is often used for [weighted correlation network analysis](wikipedia://en/41224221).

:::

## Implementations {#Implementations}

Biweight midcorrelation has been implemented in the [R statistical programming language](wikipedia://en/376707) as the function `bicor` as part of the WGCNA package[^o9]

Also implemented in the [Raku programming language](https://en.wikipedia.org/wiki/Raku_%28programming_language%29) as the function `bi_cor_coef` as part of the Statistics module.[^o10]
