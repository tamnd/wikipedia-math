# 80,000

::: {#o1 .subject cue=lead name="80,000"}

**80,000** (**eighty thousand**) is the [natural number](wikipedia://en/21474) after [79,999](wikipedia://en/13280227#79000_to_79999) and before 80,001.

:::

## Selected numbers in the range 80,000–89,999 {#Selected_numbers_in_the_range_80,000–89,999}

- **80,000** = Since January 2024, the daily URL save limit for [YouTube](https://en.wikipedia.org/wiki/YouTube) for the [Wayback Machine](https://en.wikipedia.org/wiki/Wayback_Machine)
- **80,782** = [Pell number](wikipedia://en/1355482) *P*<sub>14</sub>
- **81,081** = smallest [abundant number](wikipedia://en/321831) ending in 1, 3, 7, or 9
- **81,181** = number of reduced trees with 25 nodes
- **82,000** = the only currently known number greater than 1 that can be written in bases from 2 through 5 using only 0s and 1s.[^o6][^o7]
- **82,025** = number of primes $\leq 2^{20}$.
- **82,467** = number of square (0,1)-matrices without zero rows and with exactly 6 entries equal to 1
- **82,656** = [Kaprekar number](wikipedia://en/472129): 82656<sup>2</sup> = 6832014336; 68320 + 14336 = 82656
- **82,944** = 3-[smooth number](wikipedia://en/1035039): 2<sup>10</sup> × 3<sup>4</sup>
- **83,097** = [Riordan number](https://en.wikipedia.org/wiki/Oeis:A005043)
- **83,160** = the 29th [highly composite number](wikipedia://en/208732)
- **83,357** = [Friedman prime](https://en.wikipedia.org/wiki/Friedman_prime)
- **84,672** = number of primitive polynomials of degree 21 over GF(2)
- **85,085** = product of five consecutive primes: 5 × 7 × 11 × 13 × 17
- **87,360** = [unitary perfect number](wikipedia://en/553027)
- **88,789** = the start of a [prime 9-tuple](wikipedia://en/11421646), along with 88793, 88799, 88801, 88807, 88811, 88813, 88817, and 88819.
- **89,134** = number of partitions of 45
