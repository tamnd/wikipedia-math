# Wu's method of characteristic set

::: {#o1 .subject cue=lead name="Wu's method of characteristic set"}

**[Wenjun Wu](https://en.wikipedia.org/wiki/Wu_Wenjun)'s method** is an algorithm for solving [multivariate polynomial equations](https://en.wikipedia.org/wiki/Systems_of_polynomial_equations) introduced in the late 1970s by the Chinese [mathematician](wikipedia://en/18902) [Wen-Tsun Wu](https://en.wikipedia.org/wiki/Wu_Wenjun). This method is based on the mathematical concept of **characteristic set** introduced in the late 1940s by [J.F. Ritt](https://en.wikipedia.org/wiki/Joseph_Ritt). It is fully independent of the [Gröbner basis](wikipedia://en/357328) method, introduced by [Bruno Buchberger](wikipedia://en/1924233) (1965), even if Gröbner bases may be used to compute characteristic sets.[^o2][^o3]

:::

Wu's method is powerful for [mechanical theorem proving](https://en.wikipedia.org/wiki/Automatic_theorem_proving) in [elementary geometry](https://en.wikipedia.org/wiki/Elementary_geometry), and provides a complete decision process for certain classes of problem. It has been used in research in his laboratory (KLMM, Key Laboratory of Mathematics Mechanization in Chinese Academy of Science) and around the world. The main trends of research on Wu's method concern [systems of polynomial equations](https://en.wikipedia.org/wiki/Systems_of_polynomial_equations) of positive dimension and [differential algebra](wikipedia://en/1816587) where [Ritt](https://en.wikipedia.org/wiki/Joseph_Ritt)'s results have been made effective.[^o4][^o5] Wu's method has been applied in various scientific fields, like biology, [computer vision](https://en.wikipedia.org/wiki/Computer_vision), [robot kinematics](https://en.wikipedia.org/wiki/Robot_kinematics) and especially [automatic proofs](wikipedia://en/2546) in geometry.[^o6]

## Informal description {#Informal_description}

**Wu's method** uses [polynomial](wikipedia://en/23000) division to solve problems of the form:

$$\forall x, y, z, \dots I(x, y, z, \dots) \implies f(x, y, z, \dots) \,$$

where *f* is a [polynomial equation](https://en.wikipedia.org/wiki/Polynomial_equation) and *I* is a [conjunction](wikipedia://en/18152) of [polynomial equations](https://en.wikipedia.org/wiki/Polynomial_equation). The algorithm is complete for such problems over the [complex domain](https://en.wikipedia.org/wiki/Complex_domain).

The core idea of the algorithm is that you can divide one polynomial by another to give a remainder. Repeated division results in either the remainder vanishing (in which case the *I* implies *f* statement is true), or an irreducible remainder is left behind (in which case the statement is false).

More specifically, for an [ideal](wikipedia://en/25977) *I* in the [ring](wikipedia://en/48404) *k*\[*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>\] over a field *k*, a (Ritt) characteristic set *C* of *I* is composed of a set of polynomials in *I*, which is in triangular shape: polynomials in *C* have distinct main variables (see the formal definition below). Given a characteristic set *C* of *I*, one can decide if a polynomial *f* is zero modulo *I*. That is, the membership test is checkable for *I*, provided a characteristic set of *I*.

## Ritt characteristic set {#Ritt_characteristic_set}

A Ritt characteristic set is a [finite set](wikipedia://en/11742) of polynomials in [triangular form](wikipedia://en/27420015#Regular_chains) of an ideal. This triangular set satisfies certain minimal condition with respect to the Ritt ordering, and it preserves many interesting geometrical properties of the ideal. However it may not be its system of generators.

::: {#o10 .definition kind=definition/notation cue=heading name="Notation"}

### Notation {#Notation}

Let R be the multivariate [polynomial ring](wikipedia://en/373065) *k*\[*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>\] over a field *k*. The variables are ordered linearly according to their subscript: *x*<sub>1</sub> \< ... \< *x*<sub>*n*</sub>. For a non-constant polynomial *p* in R, the greatest variable effectively presenting in *p*, called **main variable** or **class**, plays a particular role: *p* can be naturally regarded as a univariate polynomial in its main variable *x*<sub>*k*</sub> with coefficients in *k*\[*x*<sub>1</sub>, ..., *x*<sub>*k*−1</sub>\]. The degree of p as a univariate polynomial in its main variable is also called its main degree.

:::

### Triangular set {#Triangular_set}

A set *T* of non-constant polynomials is called a **triangular set** if all polynomials in *T* have distinct main variables. This generalizes triangular [systems of linear equations](https://en.wikipedia.org/wiki/Systems_of_linear_equations) in a natural way.

### Ritt ordering {#Ritt_ordering}

For two non-constant polynomials *p* and *q*, we say *p* is smaller than *q* with respect to **Ritt ordering** and written as *p* \<<sub>*r*</sub> *q*, if one of the following assertions holds:

(1) the main variable of *p* is smaller than the main variable of *q*, that is, mvar(*p*) \< mvar(*q*),

(2) *p* and *q* have the same main variable, and the main degree of *p* is less than the **main degree** of *q*, that is, mvar(*p*) = mvar(*q*) and mdeg(*p*) \< mdeg(*q*).

In this way, (*k*\[*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>\],\<<sub>*r*</sub>) forms a [well partial order](https://en.wikipedia.org/wiki/Well_partial_order). However, the Ritt ordering is not a [total order](wikipedia://en/30330): there exist polynomials p and q such that neither *p* \<<sub>*r*</sub> *q* nor *p* ><sub>*r*</sub> *q*. In this case, we say that *p* and *q* are not comparable. The Ritt ordering is comparing the **rank** of *p* and *q*. The rank, denoted by rank(*p*), of a non-constant polynomial *p* is defined to be a power of its main variable: mvar(*p*)<sup>mdeg(*p*)</sup> and ranks are compared by comparing first the variables and then, in case of equality of the variables, the degrees.

### Ritt ordering on triangular sets {#Ritt_ordering_on_triangular_sets}

A crucial generalization on Ritt ordering is to compare triangular sets. Let *T* = { *t*<sub>1</sub>, ..., *t*<sub>*u*</sub>} and *S* = { *s*<sub>1</sub>, ..., *s*<sub>*v*</sub>} be two triangular sets such that polynomials in *T* and *S* are sorted increasingly according to their main variables. We say *T* is smaller than S w.r.t. Ritt ordering if one of the following assertions holds

1. there exists *k* ≤ min(*u*, *v*) such that rank(*t*<sub>*i*</sub>) = rank(*s*<sub>*i*</sub>) for 1 ≤ *i* \< *k* and *t*<sub>*k*</sub> \<<sub>*r*</sub> *s*<sub>*k*</sub>,
1. *u* > *v* and rank(*t*<sub>*i*</sub>) = rank(*s*<sub>*i*</sub>) for 1 ≤ *i* ≤ *v*.

Also, there exists incomparable triangular sets w.r.t Ritt ordering.

### Ritt characteristic set {#Ritt_characteristic_set}

Let I be a non-zero ideal of k\[x<sub>1</sub>, ..., x<sub>n</sub>\]. A subset T of I is a **Ritt characteristic set** of I if one of the following conditions holds:

1. T consists of a single nonzero constant of k,
1. T is a triangular set and T is minimal w.r.t Ritt ordering in the set of all triangular sets contained in I.

A polynomial ideal may possess (infinitely) many characteristic sets, since Ritt ordering is a partial order.

## Wu characteristic set {#Wu_characteristic_set}

The Ritt–Wu process, first devised by Ritt, subsequently modified by Wu, computes not a Ritt characteristic but an extended one, called Wu characteristic set or ascending chain.

A non-empty subset T of the ideal $\langle F\rangle$ generated by F is a **Wu characteristic set** of F if one of the following condition holds

1. T = {a} with a being a nonzero constant,
1. T is a triangular set and there exists a subset G of $\langle F\rangle$ such that $\langle F\rangle$ = $\langle G\rangle$ and every polynomial in G is [pseudo-reduced](wikipedia://en/18814716) to zero with respect to T.

Wu characteristic set is defined to the set F of polynomials, rather to the ideal $\langle F\rangle$ generated by F. Also it can be shown that a Ritt characteristic set T of $\langle F\rangle$ is a Wu characteristic set of F. Wu characteristic sets can be computed by Wu's algorithm CHRST-REM, which only requires pseudo-remainder computations and no factorizations are needed.

Wu's characteristic set method has exponential complexity; improvements in computing efficiency by weak chains, [regular chains](wikipedia://en/18814716), saturated chain were introduced[^o16]

## Decomposing algebraic varieties {#Decomposing_algebraic_varieties}

An application is an algorithm for solving systems of algebraic equations by means of characteristic sets. More precisely, given a finite subset F of polynomials, there is an algorithm to compute characteristic sets *T*<sub>1</sub>, ..., *T*<sub>*e*</sub> such that:

$$V(F) = W(T_1)\cup \cdots \cup W(T_e),$$

where *W*(*T*<sub>*i*</sub>) is the difference of *V*(*T*<sub>*i*</sub>) and *V*(*h*<sub>*i*</sub>), here *h*<sub>*i*</sub> is the product of initials of the polynomials in *T*<sub>*i*</sub>.
