# Linux kernel crypto API

::: {#o1 .subject cue=lead name="Linux kernel crypto API"}

**Crypto API** is a [cryptography](wikipedia://en/18934432) [framework](https://en.wikipedia.org/wiki/Framework_%28software%29) in the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel), for various parts of the kernel that deal with cryptography, such as [IPsec](https://en.wikipedia.org/wiki/IPsec) and [dm-crypt](wikipedia://en/10782256). It was introduced in kernel version 2.5.45[^o2] and has since expanded to include essentially all popular [block ciphers](wikipedia://en/4594) and [hash functions](https://en.wikipedia.org/wiki/Hash_function).

:::

## Userspace interfaces {#Userspace_interfaces}

Many platforms that provide hardware acceleration of [AES encryption](https://en.wikipedia.org/wiki/AES_encryption) expose this to programs through an extension of the [instruction set architecture](https://en.wikipedia.org/wiki/Instruction_set_architecture) (ISA) of the various chipsets (e.g. [AES instruction set](wikipedia://en/23095336) for [x86](https://en.wikipedia.org/wiki/X86)). With this sort of implementation, any program ([kernel-mode](https://en.wikipedia.org/wiki/Kernel-mode) or [user-space](https://en.wikipedia.org/wiki/User-space)) may utilize these features directly. [^o4] Some platforms, such as the ARM Kirkwood [SheevaPlug](https://en.wikipedia.org/wiki/SheevaPlug) and [AMD Geode](https://en.wikipedia.org/wiki/AMD_Geode) processors, however, are not implemented as ISA extensions, and are only accessible through kernel-mode drivers. In order for user-mode applications that utilize encryption, such as [wolfSSL](https://en.wikipedia.org/wiki/WolfSSL), [OpenSSL](wikipedia://en/438819) or [GnuTLS](wikipedia://en/949758), to take advantage of such acceleration, they must interface with the kernel.[^o5]

**AF\_ALG**

A [netlink](https://en.wikipedia.org/wiki/Netlink)-based interface that adds an `AF_ALG` address family;[^o6] it was merged into version 2.6.38 of the [Linux kernel mainline](https://en.wikipedia.org/wiki/Linux_kernel_mainline).[^o7][^o8] There was once a plugin to [OpenSSL](wikipedia://en/438819) to support AF\_ALG,[^o9] which has been submitted for merging.[^o10] In version 1.1.0, OpenSSL landed another patch for AF\_ALG contributed by Intel.[^o11] [wolfSSL](https://en.wikipedia.org/wiki/WolfSSL) can make use of AF\_ALG and cryptodev[^o12]

**cryptodev**

The [OpenBSD Cryptographic Framework](wikipedia://en/36097799) `/dev/crypto` interface of [OpenBSD](https://en.wikipedia.org/wiki/OpenBSD) was ported to Linux,[^o13][^o14][^o15] but never merged.
