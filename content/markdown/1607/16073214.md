# Tarski's exponential function problem

::: {#o1 .subject cue=lead name="Tarski's exponential function problem"}

In [model theory](wikipedia://en/19858), **Tarski's exponential function problem** asks whether the [theory](wikipedia://en/3512103) of the [real numbers](wikipedia://en/20646438) together with the [exponential function](wikipedia://en/9678) is [decidable](wikipedia://en/913118#Decidability_of_a_theory). [Alfred Tarski](wikipedia://en/59920) had previously shown that the [theory of the real numbers (without the exponential function) is decidable](wikipedia://en/43578228).[^o2]

:::

## The problem {#The_problem}

The ordered real field $\mathbb{R}$ is a structure over the language of [ordered rings](wikipedia://en/525697) $L_{\text{or}}=(+,-,<,0,1)$, with the usual interpretation given to each symbol. It was proved by Tarski that the theory of the [real field](wikipedia://en/1066093), $\operatorname{Th}(\mathbb{R})$, is decidable. That is, given any $L_{\text{or}}$-sentence $\varphi$ there is an effective procedure for determining whether

$$\mathbb{R}\models\varphi.$$

He then asked whether this was still the case if one added a unary function $\exp$ to the language that was interpreted as the [exponential function](wikipedia://en/9678) on $\mathbb{R}$, to get the structure $\mathbb{R}_{\exp}$.

## Conditional and equivalent results {#Conditional_and_equivalent_results}

The problem can be reduced to finding an effective procedure for determining whether any given [exponential polynomial](wikipedia://en/9023027) in $n$ variables and with coefficients in $\mathbb{Z}$ has a solution in $\mathbb{R}^n$. (Macintyre Wilkie 1996) showed that [Schanuel's conjecture](wikipedia://en/2031353) implies such a procedure exists, and hence gave a conditional solution to Tarski's problem.[^o6] Schanuel's conjecture deals with all complex numbers so would be expected to be a stronger result than the decidability of $\mathbb{R}_{\exp}$, and indeed, Macintyre and Wilkie proved that only a real version of Schanuel's conjecture is required to imply the decidability of this theory.

Even the real version of Schanuel's conjecture is not a [necessary condition](https://en.wikipedia.org/wiki/Necessary_and_sufficient_condition) for the decidability of the theory. In their paper, Macintyre and Wilkie showed that an equivalent result to the decidability of $\operatorname{Th}(\mathbb{R}_{\exp})$ is what they dubbed the weak Schanuel's conjecture. This conjecture states that there is an effective procedure that, given $n\ge 1$ and exponential polynomials in $n$ variables with integer coefficients $f_1,\dots, f_n, g$, produces an integer $\eta\ge 1$ that depends on $n, f_1,\dots, f_n, g$, and such that if $\alpha\in\mathbb{R}^n$ is a [non-singular](wikipedia://en/4230456) solution of the system

$$f_1(x_1,\ldots,x_n,e^{x_1},\ldots,e^{x_n})=\ldots=f_n(x_1,\ldots,x_n,e^{x_1},\ldots,e^{x_n})=0$$

then either $g(\alpha)=0$ or $|g(\alpha)|>\tfrac{1}{\eta}$.
