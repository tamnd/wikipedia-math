# Transformation (function)

Function (mathematics)

*Image: A code snippet for a rhombic repetitive pattern.svg.* A [composition](wikipedia://en/195947) of four [mappings](wikipedia://en/516931) coded [in SVG](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics),which **transforms** a [rectangular](wikipedia://en/70048) repetitive [pattern](https://en.wikipedia.org/wiki/Pattern)into a [rhombic](wikipedia://en/183884) pattern. The four transformations are [linear](wikipedia://en/18102).

::: {#o1 .subject cue=lead name="Transformation"}

In [mathematics](wikipedia://en/18831), a **transformation**, **transform**, or **self-map**[^o2] is a [function](wikipedia://en/185427) *f*, usually with some [geometrical](wikipedia://en/18973446) underpinning, that maps a [set](wikipedia://en/26691) *X* to itself, i.e. *f*: *X* → *X*.[^o3][^o4][^o5] Examples include [linear transformations](https://en.wikipedia.org/wiki/Linear_transformation) of [vector spaces](https://en.wikipedia.org/wiki/Vector_spaces) and [geometric transformations](wikipedia://en/43194879), which include [projective transformations](https://en.wikipedia.org/wiki/Projective_transformation), [affine transformations](wikipedia://en/38449), and specific affine transformations, such as [rotations](wikipedia://en/39789#Mathematics), [reflections](wikipedia://en/295829) and [translations](wikipedia://en/204682).[^o6][^o7]

:::

## Partial transformations {#Partial_transformations}

While it is common to use the term **transformation** for any function of a set into itself (especially in terms like "[transformation semigroup](wikipedia://en/19313303)" and similar), there exists an alternative form of terminological convention in which the term "transformation" is reserved only for bijections. When such a narrow notion of transformation is generalized to [partial functions](https://en.wikipedia.org/wiki/Partial_functions), then a **partial transformation** is a function *f*: *A* → *B*, where both *A* and *B* are [subsets](wikipedia://en/27631) of some set *X*.[^o9]

## Algebraic structures {#Algebraic_structures}

The set of all transformations on a given base set, together with [function composition](wikipedia://en/195947), forms a [regular semigroup](wikipedia://en/6797677).

## Combinatorics {#Combinatorics}

For a finite set of [cardinality](wikipedia://en/6174) *n*, there are *n*<sup>*n*</sup> transformations and (*n*+1)<sup>*n*</sup> partial transformations.[^o12]
