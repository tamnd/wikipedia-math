# Chi distribution

::: {#o1 .subject cue=lead name="Chi distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **chi distribution** is a continuous [probability distribution](wikipedia://en/23543) over the non-negative real line. It is the distribution of the positive square root of a sum of squared independent [Gaussian random variables](wikipedia://en/21462). Equivalently, it is the distribution of the [Euclidean distance](wikipedia://en/53932) between a multivariate Gaussian random variable and the origin. The chi distribution describes the positive square roots of a variable obeying a [chi-squared distribution](wikipedia://en/113424).

:::

If $Z_1, \ldots, Z_k$ are $k$ independent, [normally distributed](wikipedia://en/21462) random variables with mean 0 and [standard deviation](wikipedia://en/27590) 1, then the statistic

$$Y = \sqrt{\sum_{i=1}^k Z_i^2}$$

is distributed according to the chi distribution. The chi distribution has one positive integer parameter $k$, which specifies the [degrees of freedom](wikipedia://en/2321606) (i.e. the number of random variables $Z_i$).

The most familiar examples are the [Rayleigh distribution](wikipedia://en/262296) (chi distribution with two [degrees of freedom](wikipedia://en/176622)) and the [Maxwell–Boltzmann distribution](wikipedia://en/19830) of the molecular speeds in an [ideal gas](wikipedia://en/65905) (chi distribution with three degrees of freedom).

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

### Probability density function {#Probability_density_function}

The [probability density function](wikipedia://en/43487) (pdf) of the chi-distribution is

$$f(x;k) = \begin{cases} \dfrac{x^{k-1}e^{-x^2/2}}{2^{k/2-1}\Gamma\left(\frac{k}{2}\right)}, & x\geq 0; \\ 0, & \text{otherwise}. \end{cases}$$

where $\Gamma(z)$ is the [gamma function](wikipedia://en/12316).

### Cumulative distribution function {#Cumulative_distribution_function}

The cumulative distribution function is given by:

$$F(x;k)=P(k/2,x^2/2)\,$$

where $P(k,x)$ is the [regularized gamma function](wikipedia://en/456050#Regularized_gamma_functions_and_Poisson_random_variables).

### Generating functions {#Generating_functions}

The [moment-generating function](https://en.wikipedia.org/wiki/Moment-generating_function) is given by:

$$M(t)=M\left(\frac{k}{2},\frac{1}{2},\frac{t^2}{2}\right)+t\sqrt{2}\,\frac{\Gamma((k+1)/2)}{\Gamma(k/2)} M\left(\frac{k+1}{2},\frac{3}{2},\frac{t^2}{2}\right),$$

where $M(a,b,z)$ is Kummer's [confluent hypergeometric function](wikipedia://en/1516095). The [characteristic function](wikipedia://en/3229401) is given by:

$$\varphi(t;k)=M\left(\frac{k}{2},\frac{1}{2},\frac{-t^2}{2}\right) + it\sqrt{2}\,\frac{\Gamma((k+1)/2)}{\Gamma(k/2)} M\left(\frac{k+1}{2},\frac{3}{2},\frac{-t^2}{2}\right).$$

:::

## Properties {#Properties}

### Moments {#Moments}

The raw [moments](wikipedia://en/368684) are then given by:

$$\mu_j = \int_0^\infty f(x;k) x^j \mathrm{d} x = 2^{j/2}\ \frac{\ \Gamma\left( \tfrac{1}{2}(k+j) \right)\ }{\Gamma\left( \tfrac{1}{2}k \right)}$$

where $\ \Gamma(z)\$ is the [gamma function](wikipedia://en/12316). Thus the first few raw moments are:

$$\mu_1 = \sqrt{2\ }\ \frac{\ \Gamma\left( \tfrac{1}{2}(k + 1) \right)\ }{\Gamma\left( \tfrac{1}{2}k \right)}$$

$$\mu_2 = k\ ,$$

$$\mu_3=2\sqrt{2\ }\ \frac{\ \Gamma\left( \tfrac{1}{2}(k + 3) \right)\ }{\Gamma\left( \tfrac{1}{2}k \right)} = (k+1)\ \mu_1\ ,$$

$$\mu_4 = (k)(k+2)\ ,$$

$$\mu_5 = 4\sqrt{2\ }\ \frac{\ \Gamma\left( \tfrac{1}{2}(k\!+\!5) \right)\ }{\Gamma\left( \tfrac{1}{2}k \right)} = (k+1)(k+3)\ \mu_1\ ,$$

$$\mu_6 = (k)(k+2)(k+4)\ ,$$

where the rightmost expressions are derived using the recurrence relationship for the gamma function:

$$\Gamma(x+1) = x\ \Gamma(x) ~.$$

From these expressions we may derive the following relationships:

Mean: $\mu = \sqrt{2\ }\ \frac{\ \Gamma\left( \tfrac{1}{2}(k+1) \right)\ }{\Gamma\left( \tfrac{1}{2} k \right)}\ ,$ which is close to $\sqrt{k - \tfrac{1}{2}\ }\$ for large $k$.

Variance: $V = k - \mu^2\ ,$ which approaches $\ \tfrac{1}{2}\$ as $k$ increases.

Skewness: $\gamma_1 = \frac{\mu}{\ \sigma^3\ } \left(1 - 2 \sigma^2 \right) ~.$

Kurtosis excess: $\gamma_2 = \frac{2}{\ \sigma^2\ } \left(1 - \mu\ \sigma\ \gamma_1 - \sigma^2 \right) ~.$

### Entropy {#Entropy}

The entropy is given by:

$$S=\ln(\Gamma(k/2))+\frac{1}{2}(k\!-\!\ln(2)\!-\!(k\!-\!1)\psi^0(k/2))$$

where $\psi^0(z)$ is the [polygamma function](wikipedia://en/406932).

### Large n approximation {#Large_n_approximation}

We find the large n=k+1 approximation of the mean and variance of chi distribution. This has application e.g. in finding the distribution of standard deviation of a sample of normally distributed population, where n is the sample size.

The mean is then:

$$\mu = \sqrt{2}\,\,\frac{\Gamma(n/2)}{\Gamma((n-1)/2)}$$

We use the [Legendre duplication formula](wikipedia://en/8720712#Gamma_function–Legendre_formula) to write:

$$2^{n-2} \,\Gamma((n-1)/2)\cdot \Gamma(n/2) = \sqrt{\pi} \Gamma (n-1),$$

so that:

$$\mu = \sqrt{2/\pi}\,2^{n-2}\,\frac{(\Gamma(n/2))^2}{\Gamma(n-1)}$$

Using [Stirling's approximation](wikipedia://en/151783) for Gamma function, we get the following expression for the mean:

$$\mu = \sqrt{2/\pi}\,2^{n-2}\,\frac{\left(\sqrt{2\pi}(n/2-1)^{n/2-1+1/2}e^{-(n/2-1)}\cdot[1+\frac{1}{12(n/2-1)}+O(\frac{1}{n^2})]\right)^2}{\sqrt{2\pi}(n-2)^{n-2+1/2}e^{-(n-2)}\cdot [1+\frac{1}{12(n-2)}+O(\frac{1}{n^2})]}$$

$$= (n-2)^{1/2}\,\cdot \left[1+\frac{1}{4n}+O(\frac{1}{n^2})\right] = \sqrt{n-1}\,(1-\frac{1}{n-1})^{1/2}\cdot \left[1+\frac{1}{4n}+O(\frac{1}{n^2})\right]$$

$$= \sqrt{n-1}\,\cdot \left[1-\frac{1}{2n}+O(\frac{1}{n^2})\right]\,\cdot \left[1+\frac{1}{4n}+O(\frac{1}{n^2})\right]$$

$$= \sqrt{n-1}\,\cdot \left[1-\frac{1}{4n}+O(\frac{1}{n^2})\right]$$

And thus the variance is:

$$V=(n-1)-\mu^2\, = (n-1)\cdot \frac{1}{2n}\,\cdot \left[1+O(\frac{1}{n})\right] = \frac12 + O(\frac1n)$$

:::

## Related distributions {#Related_distributions}

- If $X \sim \chi_k$ then $X^2 \sim \chi^2_k$ ([chi-squared distribution](wikipedia://en/113424))
- $\chi_1 \sim \mathrm{HN}(1)\,$ ([half-normal distribution](wikipedia://en/15906455)), i.e. if $X \sim N(0,1)\,$ then $| X | \sim \chi_1 \,$, and if $Y \sim \mathrm{HN}(\sigma)\,$ for any $\sigma > 0 \,$ then $\tfrac{Y}{\sigma} \sim \chi_1\,$
- $\chi_2 \sim \mathrm{Rayleigh}(1)\,$ ([Rayleigh distribution](wikipedia://en/262296)) and if $Y \sim \mathrm{Rayleigh}(\sigma)\,$ for any $\sigma > 0 \,$ then $\tfrac{Y}{\sigma} \sim \chi_2\,$
- $\chi_3 \sim \mathrm{Maxwell}(1)\,$ ([Maxwell distribution](https://en.wikipedia.org/wiki/Maxwell_distribution)) and if $Y \sim \mathrm{Maxwell}(a)\,$ for any $a > 0 \,$ then $\tfrac{Y}{a} \sim \chi_3\,$
- $\|\boldsymbol{N}_{i=1,\ldots,k}{(0,1)}\|_2 \sim \chi_k$, the [Euclidean norm](wikipedia://en/990534#Euclidean_norm) of a [standard normal random vector](wikipedia://en/50347#Standard_normal_random_vector) of with $k$ dimensions, is distributed according to a chi distribution with $k$ [degrees of freedom](wikipedia://en/2321606)
- chi distribution is a special case of various distributions: [generalized gamma](wikipedia://en/24553589), [Nakagami](wikipedia://en/9492642), [noncentral chi](wikipedia://en/2858062), etc.
- $\lim_{k \to \infty}\tfrac{\chi_k-\mu_k}{\sigma_k} \xrightarrow{d}\ N(0,1) \,$ ([Normal distribution](wikipedia://en/21462))
- The mean of the chi distribution (scaled by the square root of $n-1$) yields the correction factor in the [unbiased estimation of the standard deviation of the normal distribution](wikipedia://en/10240807#Results_for_the_normal_distribution).

*Various chi and chi-squared distributions*

| Name | Statistic |
