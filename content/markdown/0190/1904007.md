# Wave front set

::: {#o1 .subject cue=lead name="Wave front set"}

In [mathematical analysis](wikipedia://en/48396), more precisely in [microlocal analysis](wikipedia://en/6108841), the **wave front (set)** WF(*f*) characterizes the [singularities](https://en.wikipedia.org/wiki/Mathematical_singularity) of a [generalized function](wikipedia://en/1580246) *f*, not only in [space](wikipedia://en/27667), but also with respect to its [Fourier transform](wikipedia://en/52247) at each point. The term "wave front" was coined by [Lars Hörmander](wikipedia://en/500958) around 1970.

:::

## Introduction {#Introduction}

In more familiar terms, WF(*f*) tells not only *where* the function *f* is singular (which is already described by its [singular support](https://en.wikipedia.org/wiki/Singular_support)), but also *how* or *why* it is singular, by being more exact about the direction in which the singularity occurs. This concept is mostly useful in dimensions at least two, since in one dimension there are only two possible directions. The complementary notion of a function being non-singular in a direction is *microlocal smoothness*.

Intuitively, as an example, consider a function ƒ whose singular support is concentrated on a smooth curve in the plane at which the function has a jump discontinuity. In the direction tangent to the curve, the function remains smooth. By contrast, in the direction normal to the curve, the function has a singularity. To decide on whether the function is smooth in another direction *v*, one can try to smooth the function out by averaging in directions perpendicular to *v*. If the resulting function is smooth, then we regard ƒ to be smooth in the direction of *v*. Otherwise, *v* is in the wavefront set.

Formally, in [Euclidean space](wikipedia://en/9697), the **wave front set** of ƒ is defined as the [complement](wikipedia://en/54347) of the set of all pairs (*x*<sub>0</sub>,*v*) such that there exists a test function $\phi\in C_c^\infty$ with $\phi$(*x*<sub>0</sub>) ≠ 0 and an open [cone](https://en.wikipedia.org/wiki/Cone_%28linear_algebra%29) Γ containing *v* such that the estimate

$$|(\phi f)^\wedge(\xi)| \le C_N(1+|\xi|)^{-N}\quad\mbox{for all }\ \xi\in\Gamma$$

holds for all positive integers *N*. Here $(\phi f)^\wedge$ denotes the Fourier transform. Observe that the wavefront set is [conical](https://en.wikipedia.org/wiki/Cone_%28linear_algebra%29) in the sense that if (*x*,*v*) ∈ Wf(ƒ), then (*x*,λ*v*) ∈ Wf(ƒ) for all λ > 0. In the example discussed in the previous paragraph, the wavefront set is the set-theoretic complement of the image of the tangent bundle of the curve inside the tangent bundle of the plane.

Because the definition involves cutoff by a compactly supported function, the notion of a wave front set can be transported to any [differentiable manifold](wikipedia://en/2119219) *X*. In this more general situation, the wave front set is a closed conical subset of the [cotangent bundle](wikipedia://en/221600) *T*<sup>\*</sup>(*X*), since the ξ variable naturally localizes to a [covector](https://en.wikipedia.org/wiki/Covector) rather than a vector. The wave front set is defined such that its projection on *X* is equal to the [singular support](https://en.wikipedia.org/wiki/Singular_support) of the function.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

In Euclidean space, the wave front set of a [distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) ƒ is defined as

$${\rm WF}(f) = \{ (x,\xi)\in \mathbb{R}^n\times\mathbb{R}^n \mid \xi\in\Sigma_x(f)\}$$

where $\Sigma_x(f)$ is the singular fibre of ƒ at *x*. The singular fibre is defined to be the [complement](wikipedia://en/54347) of all directions $\xi$ such that the Fourier transform of *f*, localized at *x*, is sufficiently regular when restricted to an open cone containing $\xi$. More precisely, a direction *v* is in the complement of $\Sigma_x(f)$ if there is a compactly supported smooth function $\phi$ with $\phi$(*x*)$\not= 0$ and an open cone $\Gamma$ containing *v* such that the following estimate holds for each positive integer *N*:

$$|(\phi f)^\wedge(\xi)| < c_N(1+|\xi|)^{-N}\quad{\rm for~all}\ \xi\in\Gamma.$$

Once such an estimate holds for a particular cutoff function $\phi$ at *x*, it also holds for all cutoff functions with smaller support, possibly for a different open cone containing *v*.

On a [differentiable manifold](wikipedia://en/2119219) *M*, using local coordinates $x,\xi$ on the [cotangent bundle](wikipedia://en/221600), the wave front set WF(*f*) of a distribution ƒ can be defined in the following general way:

$${\rm WF}(f) = \{ (x,\xi)\in T^*(X) \mid \xi\in\Sigma_x(f) \}$$

where the singular fibre $\Sigma_x(f)$ is again the complement of all directions $\xi$ such that the Fourier transform of *f*, localized at *x*, is sufficiently regular when restricted to a conical neighbourhood of $\xi$. The problem of regularity is local, so it can be checked in the local coordinate system, using the Fourier transform on the *x* variables. The required regularity estimate transforms well under [diffeomorphism](wikipedia://en/8564), and so the notion of regularity is independent of the choice of local coordinates.

::: {#o6 .statement kind=statement/generalization cue=heading name="Generalizations"}

### Generalizations {#Generalizations}

The notion of a wave front set can be adapted to accommodate other notions of regularity of a function. Localized can here be expressed by saying that *f* is truncated by some [smooth](https://en.wikipedia.org/wiki/Smooth_function#Smoothness) [cutoff function](https://en.wikipedia.org/wiki/Cutoff_function) not vanishing at *x*. (The localization process could be done in a more elegant fashion, using [germs](wikipedia://en/352714).)

More concretely, this can be expressed as

$$\xi\notin\Sigma_x(f) \iff \xi=0 \text{ or }\exists\phi\in\mathcal D_x,\ \exists V\in\mathcal V_\xi: \widehat{\phi f}|_V\in O(V)$$

where

- $\mathcal D_x$ are [compactly supported](https://en.wikipedia.org/wiki/Compactly_supported) [smooth functions](https://en.wikipedia.org/wiki/Smooth_function) not vanishing at *x*,
- $\mathcal V_\xi$ are *conical neighbourhoods* of $\xi$, i.e. [neighbourhoods](wikipedia://en/1529485) *V* such that $c\cdot V\subset V$ for all $c > 0$,
- $\widehat u|_V$ denotes the [Fourier transform](wikipedia://en/52247) of the (compactly supported generalized) function *u*, restricted to *V*,
- $O: \Omega\to O(\Omega)$ is a fixed [presheaf](https://en.wikipedia.org/wiki/Presheaf#Presheaves) of functions (or distributions) whose choice enforces the desired regularity of the Fourier transform.

Typically, sections of *O* are required to satisfy some growth (or decrease) condition at infinity, e.g. such that $(1+|\xi|)^s v(\xi)$ belong to some [L<sup>p</sup> space](wikipedia://en/45194). This definition makes sense, because the Fourier transform becomes more regular (in terms of growth at infinity) when *f* is truncated with the smooth cutoff $\phi$.

The most difficult "problem", from a theoretical point of view, is finding the adequate sheaf *O* characterizing functions belonging to a given subsheaf *E* of the space *G* of generalized functions.

:::

::: {#o8 .example cue=heading name="Example"}

### Example {#Example}

If we take *G* = *D*′ the space of [Schwartz distributions](https://en.wikipedia.org/wiki/Schwartz_distribution) and want to characterize distributions which are locally $C^\infty$ functions, we must take for *O*(Ω) the classical function spaces called *O*′<sub>*M*</sub>(Ω) in the literature.

Then the projection on the first component of a distribution's wave front set is nothing else than its classical [singular support](https://en.wikipedia.org/wiki/Singular_support), i.e. the complement of the set on which its restriction would be a [smooth function](https://en.wikipedia.org/wiki/Smooth_function).

:::

::: {#o10 .application cue=heading name="Applications"}

### Applications {#Applications}

The wave front set is useful, among others, when studying [propagation](https://en.wikipedia.org/wiki/Wave_propagation) of [singularities](https://en.wikipedia.org/wiki/Mathematical_singularity) by [pseudodifferential operators](https://en.wikipedia.org/wiki/Pseudodifferential_operator). The [propagation of singularities theorem](https://en.wikipedia.org/wiki/Propagation_of_singularities_theorem) characterizes the wave front set.
