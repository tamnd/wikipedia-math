# Verus (proof system)

::: {#o1 .subject cue=lead name="Verus"}

**Verus** is a [formal verification](https://en.wikipedia.org/wiki/Formal_verification) tool for the [Rust programming language](https://en.wikipedia.org/wiki/Rust_programming_language) that uses [SMT solvers](https://en.wikipedia.org/wiki/SMT_solver) in its implementation.[^o2]

:::

Verus has been used by [Amazon Web Services](https://en.wikipedia.org/wiki/Amazon_Web_Services) and [Microsoft](https://en.wikipedia.org/wiki/Microsoft) for provably correct software development.[^o3][^o4] The AutoVerus system uses [large language models](https://en.wikipedia.org/wiki/Large_language_model) to construct Verus proofs for Rust programs.[^o5]
