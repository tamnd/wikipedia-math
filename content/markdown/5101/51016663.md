# Differential forms on a Riemann surface

::: {#o1 .subject cue=lead name="Differential forms on a Riemann surface"}

article In [mathematics](wikipedia://en/18831), **differential forms on a Riemann surface** are an important special case of the general theory of [differential forms](https://en.wikipedia.org/wiki/Differential_forms) on [smooth manifolds](https://en.wikipedia.org/wiki/Smooth_manifold), distinguished by the fact that the [conformal structure](https://en.wikipedia.org/wiki/Conformal_structure) on the [Riemann surface](wikipedia://en/173181) intrinsically defines a [Hodge star operator](wikipedia://en/310914) on [1-forms](wikipedia://en/314692) (or differentials) without specifying a [Riemannian metric](https://en.wikipedia.org/wiki/Riemannian_metric). This allows the use of [Hilbert space](wikipedia://en/20598932) techniques for studying function theory on the Riemann surface and in particular for the construction of harmonic and holomorphic differentials with prescribed singularities. These methods were first used by (Hilbert 1909) in his variational approach to the Dirichlet principle, making rigorous the arguments proposed by [Riemann](wikipedia://en/41980). Later (Weyl 1940) found a direct approach using his method of orthogonal projection, a precursor of the modern theory of [elliptic differential operators](https://en.wikipedia.org/wiki/Elliptic_differential_operator) and [Sobolev spaces](wikipedia://en/611964). These techniques were originally applied to prove the [uniformization theorem](wikipedia://en/288270) and its generalization to [planar Riemann surfaces](wikipedia://en/50964981). Later they supplied the analytic foundations for the [harmonic integrals](wikipedia://en/501590) of (Hodge 1941). This article covers general results on differential forms on a Riemann surface that do not rely on any choice of [Riemannian structure](wikipedia://en/144652).

:::

## Hodge star on 1-forms {#Hodge_star_on_1-forms}

On a Riemann surface the [Hodge star](https://en.wikipedia.org/wiki/Hodge_star) is defined on 1-forms by the local formula

$$\displaystyle{ \star(p\,dx + q\, dy) = -q\,dx + p\, dy.}$$

It is well-defined because it is invariant under [holomorphic](https://en.wikipedia.org/wiki/Holomorphic) changes of coordinate.

Indeed, if *z* = *x* + *iy* is holomorphic as a function of *w* = *u* + *iv*, then by the [Cauchy–Riemann equations](wikipedia://en/7583) *x*<sub>*u*</sub> = *y*<sub>*v*</sub> and *y*<sub>*u*</sub> = −*x*<sub>*v*</sub>. In the new coordinates

$$\displaystyle{p\,dx + q\, dy = (px_u + q y_u)du + (px_v+qy_v)dv=p_1 du + q_1 dv,}$$

so that

$$-q_1 \,du + p_1 \,dv= -(px_v+qy_v)du + (px_u + q y_u)dv = -q(x_u du + x_v dv) + p(y_u du + y_vdv) = -q\,dx + p\, dy,$$

proving the claimed invariance.[^o6]

Note that for 1-forms *ω*<sub>1</sub> = *p*<sub>1</sub> *dx* + *q*<sub>1</sub> *dy* and *ω*<sub>2</sub> = *p*<sub>2</sub> *dx* + *q*<sub>2</sub> *dy*

$$\displaystyle{\omega_1 \wedge \star \omega_2 = (p_1p_2 + q_1q_2)\, dx\wedge dy = \omega_2 \wedge \star \omega_1.}$$

In particular if *ω* = *p* *dx* + *q* *dy* then

$$\displaystyle{\omega \wedge \star \omega =(p^2+q^2) \, dx\wedge dy.}$$

Note that in standard coordinates

$$\star dz = -i dz,\,\, \star d\overline{z} = i d\overline{z}.$$

Recall also that

$${\partial\over \partial z} = {1\over 2}\left({\partial \over \partial x} - i {\partial \over \partial y}\right),\,\,\, {\partial \over\partial \overline{z}} = {1\over 2} \left({\partial \over\partial x} +i {\partial \over\partial y}\right),$$

so that

$$df= f_z \, dz + f_{\overline{z}}\, d\overline{z} = \partial f + \bar{\partial}f.$$

The decomposition $d = \partial + \bar{\partial}$ is independent of the choice of local coordinate. The 1-forms with only a $dz$ component are called (1,0) forms; those with only a $d\overline{z}$ component are called (0,1) forms. The operators $\partial$ and $\overline{\partial}$ are called the [Dolbeault operators](wikipedia://en/2497815#Dolbeault_operators).

It follows that

$$\star df= -i\partial f + i\bar{\partial}f.$$

The Dolbeault operators can similarly be defined on 1-forms and as zero on 2-forms. They have the properties

$$d=\partial+\bar{\partial}$$

$$\partial^2=\bar{\partial}^2=\partial\bar{\partial}+\bar{\partial}\partial=0.$$

## Poincaré lemma {#Poincaré_lemma}

On a Riemann surface the [Poincaré lemma](wikipedia://en/600030) states that every closed 1-form or 2-form is locally exact.[^o9] Thus if *ω* is a smooth 1-form with *dω* = 0 then in some open neighbourhood of a given point there is a smooth function *f* such that *ω* = *df* in that neighbourhood; and for any smooth 2-form Ω there is a smooth 1-form *ω* defined in some open neighbourhood of a given point such that Ω = *dω* in that neighbourhood.

If *ω* = *p* *dx* + *q* *dy* is a closed 1-form on (*a*,*b*) × (*c*,*d*), then *p*<sub>*y*</sub> = *q*<sub>*x*</sub>. If *ω* = *df* then *p* = *f*<sub>*x*</sub> and *q* = *f*<sub>*y*</sub>. Set

$$\displaystyle{g(x,y)=\int_a^x p(t,y)\, dt,}$$

so that *g*<sub>*x*</sub> = *p*. Then *h* = *f* − *g* must satisfy *h*<sub>*x*</sub> = 0 and *h*<sub>*y*</sub> = *q* − *g*<sub>*y*</sub>. The right hand side here is independent of *x* since its [partial derivative](wikipedia://en/52565) with respect to *x* is 0. So

$$\displaystyle{h(x,y)=\int_c^y q(a,s)\, ds - g(a,y)=\int_c^y q(a,s)\, ds,}$$

and hence

$$\displaystyle{f(x,y)=\int_a^x p(t,y)\, dt + \int_c^y q(a,s)\, ds.}$$

Similarly, if Ω = *r* *dx* ∧ *dy* then Ω = *d*(*f* *dx* + *g* *dy*) with *g*<sub>*x*</sub> − *f*<sub>*y*</sub> = *r*. Thus a solution is given by *f* = 0 and

$$\displaystyle{g(x,y)=\int_a^x r(t,y) \, dt.}$$

**Comment on differential forms with compact support.** Note that if *ω* has compact support, so vanishes outside some smaller rectangle (*a*<sub>1</sub>,*b*<sub>1</sub>) × (*c*<sub>1</sub>,*d*<sub>1</sub>) with *a* \< *a*<sub>1</sub> \< *b*<sub>1</sub> \<*b* and *c* \< *c*<sub>1</sub> \< *d*<sub>1</sub> \< *d*, then the same is true for the solution *f*(*x*,*y*). So the Poincaré lemma for 1-forms holds with this additional conditions of compact support.

A similar statement is true for 2-forms; but, since there is some choices for the solution, a little more care has to be taken in making those choices.[^o10]

In fact if Ω has compact support on (*a*,*b*) × (*c*,*d*) and if furthermore ∬ Ω = 0, then Ω = *dω* with *ω* a 1-form of compact support on (*a*,*b*) × (*c*,*d*). Indeed, Ω must have support in some smaller rectangle (*a*<sub>1</sub>,*b*<sub>1</sub>) × (*c*<sub>1</sub>,*d*<sub>1</sub>) with *a* \< *a*<sub>1</sub> \< *b*<sub>1</sub> \<*b* and *c* \< *c*<sub>1</sub> \< *d*<sub>1</sub> \< *d*. So *r*(*x*, *y*) vanishes for *x* ≤ *a*<sub>1</sub> or *x* ≥ *b*<sub>1</sub> and for *y* ≤ *c*<sub>1</sub> or *y* ≥ *d*<sub>1</sub>. Let *h*(*y*) be a smooth function supported in (*c*<sub>1</sub>,*d*<sub>1</sub>) with $\int^{d}_{c} h(t) dt = 1$. Set $k(x) = \int^{d}_{c} r(x,y) dy$: it is a smooth function supported in (*a*<sub>1</sub>,*b*<sub>1</sub>). Hence *R*(*x*,*y*) = *r*(*x*,*y*) − *k*(*x*)*h*(*y*) is smooth and supported in (*a*<sub>1</sub>,*b*<sub>1</sub>) × (*c*<sub>1</sub>,*d*<sub>1</sub>). It now satisfies $\int^{d}_{c} R(x,y) dy \equiv 0$. Finally set

$$P(x,y)=\int_c^y R(x,y) dy,\,\,\, Q(x,y)=h(y)\int_a^x k(s) \, ds.$$

Both *P* and *Q* are smooth and supported in (*a*<sub>1</sub>,*b*<sub>1</sub>) × (*c*<sub>1</sub>,*d*<sub>1</sub>) with *P*<sub>*y*</sub> = *R* and *Q*<sub>*x*</sub>(*x*,*y*) = *k*(*x*)*h*(*y*). Hence *ω* = −*P* *dx* + *Q* *dy* is a smooth 1-form supported in (*a*<sub>1</sub>,*b*<sub>1</sub>) × (*c*<sub>1</sub>,*d*<sub>1</sub>) with

$$d\omega = (Q_x + P_y)\,dx \wedge dy = r \,dx \wedge dy =\Omega.$$

:::

## Integration of 2-forms {#Integration_of_2-forms}

If Ω is a continuous 2-form of compact support on a Riemann surface *X*, its support *K* can be covered by finitely many coordinate charts *U*<sub>*i*</sub> and there is a partition of unity χ<sub>*i*</sub> of smooth non-negative functions with compact support such that Σ χ<sub>*i*</sub> = 1 on a neighbourhood of *K*. Then the integral of Ω is defined by

$$\displaystyle{\int_X \Omega = \sum \int_{X} \chi_i\Omega= \sum \int_{U_i} \chi_i \Omega,}$$

where the integral over *U*<sub>*i*</sub> has its usual definition in local coordinates. The integral is independent of the choices here.

If Ω has the local representation *f*(*x*,*y*) *dx* ∧ *dy*, then |Ω| is the density |*f*(*x*,*y*)| *dx* ∧ *dy*, which is well defined and satisfies |∫<sub>*X*</sub> Ω| ≤ ∫<sub>*X*</sub> |Ω|. If Ω is a non-negative continuous density, not necessarily of compact support, its integral is defined by

$$\displaystyle{\int_X \Omega =\sup_{0\le \psi \le 1,\, \psi\in C_c(X)} \int_X \psi \Omega.}$$

If Ω is any continuous 2-form it is integrable if ∫<sub>*X*</sub> |Ω| \< ∞. In this case, if ∫<sub>*X*</sub> |Ω| = lim ∫<sub>*X*</sub> ψ<sub>*n*</sub> |Ω|, then ∫<sub>*X*</sub> Ω can be defined as lim ∫<sub>*X*</sub> ψ<sub>*n*</sub> Ω. The integrable continuous 2-forms form a complex normed space with norm ||Ω||<sub>1</sub> = ∫<sub>*X*</sub> |Ω|.

## Integration of 1-forms along paths {#Integration_of_1-forms_along_paths}

If *ω* is a 1-form on a Riemann surface *X* and *γ*(*t*) for *a* ≤ *t* ≤ *b* is a smooth path in *X*, then the mapping *γ* induces a 1-form *γ*∗*ω* on \[*a*,*b*\]. The integral of *ω* along *γ* is defined by

$$\displaystyle{\int_\gamma \omega = \int_a^b \gamma^{*} \omega.}$$

This definition extends to piecewise smooth paths *γ* by dividing the path up into the finitely many segments on which it is smooth. In local coordinates if *ω* = *p* *dx* + *q* *dy* and *γ*(*t*) = (*x*(*t*),*y*(*t*)) then

$$\displaystyle{\gamma^* \omega= p(\gamma(t)) \dot{x}(t) \, dt + q(\gamma(t))\dot{y}(t)\, dt,}$$

so that

$$\displaystyle{\int_\gamma \omega= \int_a^b p(\gamma(t)) \dot{x}(t) \, dt + q(\gamma(t))\dot{y}(t)\, dt.}$$

Note that if the 1-form *ω* is exact on some connected [open set](wikipedia://en/39358) *U*, so that *ω* = *df* for some smooth function *f* on *U* (unique up to a constant), and *γ*(*t*), *a* ≤ *t* ≤ *b*, is a smooth path in *U*, then

$$\displaystyle{\int_\gamma \omega =\int_a^b d(f(\gamma(t)) = f(\gamma(b)) - f(\gamma(a)).}$$

This depends only on the difference of the values of *f* at the endpoints of the curve, so is independent of the choice of *f*. By the Poincaré lemma, every closed 1-form is locally exact, so this allows ∫<sub>γ</sub> ω to be computed as a sum of differences of this kind and for the integral of closed 1-forms to be extended to continuous paths:

**Monodromy theorem.** If *ω* is a closed 1-form, the integral ∫<sub>*γ*</sub> *ω* can be extended to any continuous path *γ*(*t*), *a* ≤ t ≤ *b* so that it is invariant under any [homotopy](wikipedia://en/212250) of paths keeping the end points fixed.[^o13]

In fact, the image of *γ* is compact, so can be covered by finitely many connected open sets *U*<sub>*i*</sub> on each of which ω can be written *df*<sub>*i*</sub> for some smooth function *f*<sub>*i*</sub> on *U*<sub>*i*</sub>, unique up to a constant.[^o14] It may be assumed that \[*a*,*b*\] is broken up into finitely many closed intervals *K*<sub>*i*</sub> = \[*t*<sub>*i*−1</sub>,*t*<sub>*i*</sub>\] with *t*<sub>0</sub> = *a* and *t*<sub>*n*</sub> = *b* so that *γ*(*K*<sub>*i*</sub>) ⊂ *U*<sub>*i*</sub>. From the above if *γ* is piecewise smooth,

$$\displaystyle{\int_\gamma \omega = \sum \int_{\gamma|_{K_i}} \omega= \sum \int_{K_i} d(f_i\circ \gamma) =\sum_{i=1}^n f_i(\gamma(t_i)) - f_i(\gamma(t_{i-1}))= f_n(\gamma(b)) - f_1(\gamma(b)) + \sum_{i=1}^{n-1} [f_i(\gamma(t_i)) - f_{i+1}(\gamma(t_i))].}$$

Now *γ*(*t*<sub>*i*</sub>) lies in the open set *U*<sub>*i*</sub> ∩ *U*<sub>*i*+1</sub>, hence in a connected open component *V*<sub>*i*</sub>. The difference *g*<sub>*i*</sub> = *f*<sub>*i*</sub> − *f*<sub>*i*−1</sub> satisfies *dg*<sub>*i*</sub> = 0, so is a constant *c*<sub>*i*</sub> independent of *γ*. Hence

$$\displaystyle{\int_\gamma \omega = f_n(\gamma(b)) - f_1(\gamma(a)) + \sum_{i=1}^{n-1} c_i.}$$

The formula on the right hand side also makes sense if *γ* is just continuous on \[*a*,*b*\] and can be used to define ∫<sub>*γ*</sub> *ω*. The definition is independent of choices: for the curve *γ* can be uniformly approximated by piecewise smooth curves *δ* so close that *δ*(*K*<sub>*i*</sub>) ⊂ *U*<sub>*i*</sub> for all *i*; the formula above then equals ∫<sub>*δ*</sub> *ω* and shows the integral is independent of the choice of *δ*. The same argument shows that the definition is also invariant under small homotopies fixing endpoints; by compactness, it is therefore invariant under any homotopy fixing endpoints.

The same argument shows that a homotopy between closed continuous loops does not change their integrals over closed 1-forms. Since ∫<sub>*γ*</sub> *df* = *f*(*γ*(*b*)) − *f*(*γ*(*a*)), the integral of an exact form over a closed loop vanishes. Conversely if the integral of a closed 1-form *ω* over any closed loop vanishes, then the 1-form must be exact.

Indeed a function *f*(*z*) can be defined on *X* by fixing a point *w*, taking any path *δ* from *w* to *z* and setting *f*(*z*) = ∫<sub>*δ*</sub> *ω*. The assumption implies that *f* is independent of the path. To check that *df* = *ω*, it suffices to check this locally. Fix *z*<sub>0</sub> and take a path *δ*<sub>1</sub> from *w* to *z*<sub>0</sub>. Near *z*<sub>0</sub> the Poincaré lemma implies that *ω* = *dg* for some smooth function *g* defined in a neighbourhood of *z*<sub>0</sub>. If *δ*<sub>2</sub> is a path from *z*<sub>0</sub> to *z*, then *f*(*z*) = ∫<sub>*δ*<sub>1</sub></sub> *ω* + ∫<sub>*δ*<sub>2</sub></sub> *ω* = ∫<sub>*δ*<sub>1</sub></sub> *ω* + *g*(*z*) − *g*(*z*<sub>0</sub>), so *f* differs from *g* by a constant near *z*<sub>0</sub>. Hence *df* = *dg* = *ω* near *z*<sub>0</sub>.

A closed 1-form is exact [if and only if](wikipedia://en/14922) its integral around any piecewise smooth or continuous Jordan curve vanishes.[^o15]

In fact the integral is already known to vanish for an exact form, so it suffices to show that if ∫<sub><sub>*γ*</sub></sub> *ω* = 0 for all piecewise smooth closed Jordan curves *γ* then ∫<sub><sub>*γ*</sub></sub> *ω* = 0 for all closed continuous curves *γ*. Let *γ* be a closed continuous curve. The image of *γ* can be covered by finitely many opens on which *ω* is exact and this data can be used to define the integral on *γ*. Now recursively replace *γ* by smooth segments between successive division points on the curve so that the resulting curve *δ* has only finitely many intersection points and passes through each of these only twice. This curve can be broken up as a superposition of finitely many piecewise smooth Jordan curves. The integral over each of these is zero, so their sum, the integral over *δ*, is also zero. By construction the integral over *δ* equals the integral over *γ*, which therefore vanishes.

The above argument also shows that given a continuous Jordan curve *γ*(*t*), there is a [finite set](wikipedia://en/11742) of simple smooth Jordan curves *γ*<sub>*i*</sub>(*t*) with nowhere zero derivatives such that

$$\int_\gamma \omega = \sum_i \int_{\gamma_i} \omega$$

for any closed 1-form *ω*.[^o16] Thus to check exactness of a closed form it suffices to show that the vanishing of the integral around any regular closed curve, i.e. a simple smooth Jordan curve with nowhere vanishing derivative.

The same methods show that any continuous loop on a Riemann surface is homotopic to a smooth loop with nowhere zero derivative.

::: {#o18 .statement cue=named-heading name="Green–Stokes formula"}

## Green–Stokes formula {#Green–Stokes_formula}

If *U* is a bounded region in the complex plane with boundary consisting of piecewise smooth curves and *ω* is a 1-form defined on a neighbourhood of the closure of *U*, then the [Green–Stokes formula](wikipedia://en/243334) states that

$$\int_{\partial U} \omega = \int_U d\omega .$$

In particular if *ω* is a 1-form of compact support on **C** then

$$\int_{\bf C} d\omega = 0 ,$$

since the formula may be applied to a large disk containing the support of ω.[^o19]

Similar formulas hold on a Riemann surface *X* and can be deduced from the classical formulas using [partitions of unity](wikipedia://en/48636).[^o20] Thus if *U* ⊂ *X* is a connected region with compact closure and piecewise smooth boundary ∂*U* and *ω* is a 1-form defined on a neighbourhood of the closure of *U*, then the **Green–Stokes formula** states that

$$\displaystyle{\int_{\partial U} \omega = \int_U d\omega.}$$

Moreover, if *ω* is a 1-form of compact support on *X* then

$$\int_{X} d\omega = 0 .$$

To prove the second formula take a partition of unity *ψ*<sub>*i*</sub> supported in coordinate charts covering the support of *ω*. Then ∫<sub>*X*</sub> *dω* = Σ ∫<sub>*X*</sub> *d*(*ψ*<sub>*i*</sub> *ω*) = 0, by the planar result. Similarly to prove the first formula it suffices to show that

$$\displaystyle{\int_{\partial U} \psi\omega = \int_U d(\psi\omega)}$$

when *ψ* is a smooth function compactly supported in some coordinate patch. If the coordinate patch avoids the boundary curves, both sides vanish by the second formula above. Otherwise it can be assumed that the coordinate patch is a disk, the boundary of which cuts the curve transversely at two points. The same will be true for a slightly smaller disk containing the support of *ψ*. Completing the curve to a Jordan curve by adding part of the boundary of the smaller disk, the formula reduces to the planar Green-Stokes formula.

The Green–Stokes formula implies an adjoint relation for the Laplacian on functions defined as Δ*f* = −*d*∗*df*. This gives a 2-form, given in local coordinates by the formula

$$\Delta f =\left( -{\partial^2 f \over \partial x^2} - {\partial^2 f \over \partial y^2}\right) \, dx \wedge dy .$$

Then if *f* and *g* are smooth and the closure of *U* is compact

$$\int_U f\Delta g - g \Delta f = \int_{\partial U} g {\star d f} - f{\star d g} .$$

Moreover, if *f* or *g* has compact support then

$$\int_X f \Delta g = \int_X g \Delta f .$$

:::

## Duality between 1-forms and closed curves {#Duality_between_1-forms_and_closed_curves}

::: {#o22 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** If *γ* is a continuous Jordan curve on a Riemann surface *X*, there is a smooth closed 1-form *α* of compact support such that ∫<sub>*γ*</sub> *ω* = ∫<sub>*X*</sub> *ω* ∧ *α* for any closed smooth 1-form *ω* on *X*.[^o23][^o24]

It suffices to prove this when *γ* is a regular closed curve. By the [inverse function theorem](wikipedia://en/287229), there is a [tubular neighbourhood](wikipedia://en/3192042) of the image of *γ*, i.e. a smooth diffeomorphism $\Gamma(t, s)$ of the annulus $S^{1} \times (-1, 1)$ into *X* such that $\Gamma(t, 0) = \gamma(t)$. Using a [bump function](wikipedia://en/815799) on the second factor, a non-negative function *g* with compact support can be constructed such that *g* is smooth off *γ*, has support in a small neighbourhood of *γ*, and in a sufficiently small neighbourhood of *γ* is equal to 0 for *s* \< 0 and 1 for *s* ≥ 0. Thus *g* has a jump discontinuity across *γ*, although its differential *dg* is smooth with compact support. But then, setting *α* = −*dg*, it follows from Green's formula applied to the annulus $\gamma \times [0, \varepsilon]$ that

$$\int_X \omega \wedge \alpha = \int_X dg \wedge \omega = \int_{\gamma\times (0,\varepsilon)} dg \wedge \omega = \int_{\gamma\times (0,\varepsilon)}d(g\omega) = \int_\gamma \omega.$$

:::

::: {#o25 .statement kind=statement/corollary cue=inline-head name="Corollary 1"}

**Corollary 1.** A closed smooth 1-form *ω* is exact if and only if ∫<sub>*X*</sub> *ω* ∧ *α* = 0 for all smooth 1-forms *α* of compact support.[^o26]

In fact if *ω* is exact, it has the form *df* for *f* smooth, so that ∫<sub>*X*</sub> *ω* ∧ *α* = ∫<sub>*X*</sub> *df* ∧ *α* = ∫<sub>*X*</sub> *d*(*f* *α*) = 0 by Green's theorem. Conversely, if ∫<sub>*X*</sub> *ω* ∧ *α* = 0 for all smooth 1-forms *α* of compact support, the duality between Jordan curves and 1-forms implies that the integral of *ω* around any closed Jordan curve is zero and hence that *ω* is exact.

:::

::: {#o27 .statement kind=statement/corollary cue=inline-head name="Corollary 2"}

**Corollary 2.** If *γ* is a continuous closed curve on a Riemann surface *X*, there is a smooth closed 1-form *α* of compact support such that ∫<sub>*γ*</sub> *ω* = ∫<sub>*X*</sub> *ω* ∧ *α* for any closed smooth 1-form *ω* on *X*. The form *α* is unique up to adding an exact form and can be taken to have support in any open neighbourhood of the image of *γ*.

In fact *γ* is homotopic to a piecewise smooth closed curve *δ*, so that ∫<sub>*γ*</sub> *ω* = ∫<sub>*δ*</sub> *ω*. On the other hand there are finitely many piecewise smooth Jordan curves *δ*<sub>*i*</sub> such that $\int_{\delta} \omega = \Sigma \int_{\delta_{i}} \omega$. The result for *δ*<sub>*i*</sub> thus implies the result for *γ*. If *β* is another form with the same property, the difference *α* − *β* satisfies ∫<sub>*X*</sub> *ω* ∧ (*α* − *β*) = 0 for all closed smooth 1-forms *ω*. So the difference is exact by Corollary 1. Finally, if *U* is any neighbourhood of the image of *γ*, then the last result follows by applying first assertion to *γ* and *U* in place of *γ* and *X*.

:::

## Intersection number of closed curves {#Intersection_number_of_closed_curves}

The **[intersection number](wikipedia://en/384327)** of two closed curves *γ*<sub>1</sub>, *γ*<sub>2</sub> in a Riemann surface *X* can be defined analytically by the formula[^o29][^o30]

$$I(\gamma_1 , \gamma_2) = \int_X \alpha_1 \wedge \alpha_2,$$

where *α*<sub>1</sub> and *α*<sub>2</sub> are smooth 1-forms of compact support corresponding to *γ*<sub>1</sub> and *γ*<sub>2</sub>. From the definition it follows that $I(\gamma_{1}, \gamma_{2}) = -I(\gamma_{2}, \gamma_{1})$. Since *α<sub>i</sub>* can be taken to have its support in a neighbourhood of the image of γ<sub>*i*</sub>, it follows that $I(\gamma_{1} , \gamma_{2}) = 0$ if *γ*<sub>1</sub> and *γ*<sub>2</sub> are disjoint. By definition it depends only on the homotopy classes of *γ*<sub>1</sub> and *γ*<sub>2</sub>.

More generally the intersection number is always an integer and counts the number of times *with signs* that the two curves intersect. A crossing at a point is a positive or negative crossing according to whether *d*γ<sub>1</sub> ∧ *d*γ<sub>2</sub> has the same or opposite sign to $dx \land dy = -i/2 dz \land d\overline{z}$, for a local holomorphic parameter *z* = *x* + *iy*.[^o31]

Indeed, by homotopy invariance, it suffices to check this for smooth Jordan curves with nowhere vanishing derivatives. The *α*<sub>1</sub> can be defined by taking α<sub>1</sub>*df* with *f* of compact support in a neighbourhood of the image of γ<sub>1</sub> equal to 0 near the left hand side of *γ*<sub>1</sub>, 1 near the right hand side of *γ*<sub>1</sub> and smooth off the image of *γ*<sub>1</sub>. Then if the points of intersection of *γ*<sub>2</sub>(*t*) with γ<sub>1</sub> occur at *t* = *t*<sub>1</sub>, ..., *t*<sub>*m*</sub>, then

$$I(\gamma_1,\gamma_2) = \int_{\gamma_2} \alpha_1 = \int_{\gamma_2} df = \sum f\circ \gamma_2(t_i+) - f\circ\gamma_2(t_i-).$$

This gives the required result since the jump $f\circ\gamma_{2}(t_{i}+) - f\circ\gamma_{2}(t_{i}-)$ is + 1 for a positive crossing and −1 for a negative crossing.

## Holomorphic and harmonic 1-forms {#Holomorphic_and_harmonic_1-forms}

A **holomorphic 1-form** ω is one that in local coordinates is given by an expression *f*(*z*) *dz* with *f* [holomorphic](https://en.wikipedia.org/wiki/Holomorphic). Since $dg=\partial_z g \, dz + \partial_{\overline{z}} g\, d\overline{z},$ it follows that *dω* = 0, so any holomorphic 1-form is closed. Moreover, since ∗*dz* = −*i* *dz*, ω must satisfy ∗*ω* = −*iω*. These two conditions characterize holomorphic 1-forms. For if ω is closed, locally it can be written as *dg* for some *g*, The condition ∗*dg* = *i* *dg* forces $\partial_{\overline{z}} g = 0$, so that *g* is holomorphic and *dg* = *g* '(*z*) *dz*, so that ω is holomorphic.

Let *ω* = *f* *dz* be a holomorphic 1-form. Write *ω* = *ω*<sub>1</sub> + *iω*<sub>2</sub> with *ω*<sub>1</sub> and *ω*<sub>2</sub> real. Then *dω*<sub>1</sub> = 0 and *dω*<sub>2</sub> = 0; and since ∗*ω* = −*iω*, ∗*ω*<sub>1</sub> = *ω*<sub>2</sub>. Hence *d*∗*ω*<sub>1</sub> = 0. This process can clearly be reversed, so that there is a one-one correspondence between holomorphic 1-forms and real 1-forms ω<sub>1</sub> satisfying *d*ω<sub>1</sub> = 0 and *d*∗ω<sub>1</sub> = 0. Under this correspondence, *ω*<sub>1</sub> is the real part of *ω* while *ω* is given by *ω* = *ω*<sub>1</sub> + *i*∗*ω*<sub>1</sub>. Such forms ω<sub>1</sub> are called **harmonic 1-forms**. By definition ω<sub>1</sub> is harmonic if and only if ∗*ω*<sub>1</sub> is harmonic.

Since holomorphic 1-forms locally have the form *df* with *f* a holomorphic function and since the real part of a holomorphic function is harmonic, harmonic 1-forms locally have the form *dh* with *h* a [harmonic function](wikipedia://en/55762). Conversely if *ω*<sub>1</sub> can be written in this way locally, *d*∗ω<sub>1</sub> = *d*∗*dh* = (*h*<sub>*xx*</sub> + *h*<sub>*yy*</sub>) *dx*∧*dy* so that *h* is harmonic.[^o33]

::: {#o34 .remark cue=inline-head name="Remark"}

**Remark.** The definition of harmonic functions and 1-forms is intrinsic and only relies on the underlying Riemann surface structure. If, however, a conformal metric is chosen on the Riemann surface, the adjoint *d*\* of *d* can be defined and the Hodge star operation extended to functions and 2-forms. The Hodge Laplacian can be defined on *k*-forms as ∆<sub>*k*</sub> = *dd*\* +*d*\**d* and then a function *f* or a 1-form *ω* is harmonic if and only if it is annihilated by the Hodge Laplacian, i.e. ∆<sub>0</sub>*f* = 0 or ∆<sub>1</sub>*ω* = 0. The metric structure, however, is not required for the application to the uniformization of simply connected or planar Riemann surfaces.

:::

## Sobolev spaces on T<sup>2</sup> {#Sobolev_spaces_on_T2}

The theory of Sobolev spaces on $\mathbf{T}^{2}$ can be found in (Bers John Schechter 1979), an account which is followed in several later textbooks such as (Warner 1983) and (Griffiths Harris 1994). It provides an analytic framework for studying function theory on the torus **C**/**Z**+*i* **Z** = **R**<sup>2</sup> / **Z**<sup>2</sup> using [Fourier series](wikipedia://en/59038), which are just eigenfunction expansions for the Laplacian $-\partial^{2}/\partial x^{2} -\partial^{2}/\partial y^{2}$. The theory developed here essentially covers tori **C** / Λ where Λ is a [lattice](wikipedia://en/15782871) in **C**. Although there is a corresponding theory of Sobolev spaces on any compact Riemann surface, it is elementary in this case, because it reduces to [harmonic analysis](wikipedia://en/14147) on the compact Abelian group $\mathbf{T}^{2}$. Classical approaches to Weyl's lemma use harmonic analysis on the non-compact Abelian group **C** = **R**<sup>2</sup>, i.e. the methods of [Fourier analysis](wikipedia://en/11659), in particular [convolution operators](https://en.wikipedia.org/wiki/Convolution_operator) and the [fundamental solution](wikipedia://en/1820858) of the Laplacian.[^o39][^o40]

Let **T**<sup>2</sup> = {(*e*<sup>*ix*</sup>,*e*<sup>*iy*</sup>: *x*, *y* ∊ \[0,2*π*)} = **R**<sup>2</sup>/**Z**<sup>2</sup> = **C**/Λ where Λ = **Z** + *i* **Z**. For λ = *m* + *i* *n* ≅ (*m*,*n*) in Λ, set $e_{\lambda} (x,y) = e^{i(mx + ny)}$. Furthermore, set *D*<sub>*x*</sub> = −*i*∂/∂*x* and *D*<sub>*y*</sub> = −*i*∂/∂*y*. For α = (*p*,*q*) set *D*<sup>α</sup> =(*D*<sub>*x*</sub>)<sup>*p*</sup> (*D*<sub>*y*</sub>)<sup>*q*</sup>, a differential operator of total degree |*α*| = *p* + *q*. Thus $D^{\alpha}e_{\lambda} = \lambda^{\alpha} e_{\lambda}$, where $\lambda^{\alpha} =m^{p}n^{q}$. The (*e*<sub>λ</sub>) form an [orthonormal basis](wikipedia://en/195063) in C(**T**<sup>2</sup>) for the inner product $(f,g) = (2\pi)^{-2}\iint f(x,y) \overline{g(x,y)} dx dy$, so that $(\Sigma a_{\lambda} e_{\lambda}, \Sigma b_{\mu} e_{\mu}) = \Sigma a_{\lambda}\overline{b_{\lambda}}$.

For *f* in C<sup>∞</sup>(*T**<sup>2</sup>) and*****k*an integer, define the*k*th Sobolev norm by***

$$\|f\|_{(k)} = \left(\sum |\widehat{f}(\lambda)|^2 (1 + |\lambda|^2)^k\right)^{1/2}.$$

The associated inner product

$$\displaystyle{(f,g)_{(k)} = \sum \widehat{f}(\lambda)\overline{\widehat{g}(\lambda)} (1 +|\lambda|^2)^k}$$

makes C<sup>∞</sup>(**T**<sup>2</sup>) into an inner product space. Let *H*<sub>*k*</sub>(**T**<sup>2</sup>) be its Hilbert space completion. It can be described equivalently as the Hilbert space completion of the space of [trigonometric polynomials](wikipedia://en/591568)—that is finite sums $(\Sigma a_{\lambda} e_{\lambda}$—with respect to the *k*th Sobolev norm, so that *H*<sub>*k*</sub>(**T**<sup>2</sup>) = {Σ *a*<sub>λ</sub> *e*<sub>λ</sub> : Σ |*a*<sub>λ</sub>|<sup>2</sup>(1 + |λ|<sup>2</sup>)<sup>*k*</sup> \< ∞} with inner product

(Σ *a*<sub>λ</sub> *e*<sub>λ</sub>, Σ *b*<sub>μ</sub> *e*<sub>μ</sub>)<sub>(*k*)</sub> = Σ *a*<sub>λ</sub>$\overline{b_{\lambda}}$ (1 + |λ|<sup>2</sup>)<sup>*k*</sup>.

As explained below, the elements in the intersection *H*<sub>∞</sub>(**T**<sup>2</sup>) = $\cap$ *H*<sub>*k*</sub>(**T**<sup>2</sup>) are exactly the smooth functions on **T**<sup>2</sup>; elements in the union *H*<sub>−∞</sub>(**T**<sup>2</sup>) = $\cup$ *H*<sub>*k*</sub>(**T**<sup>2</sup>) are just [distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) on **T**<sup>2</sup> (sometimes referred to as "periodic distributions" on **R**<sup>2</sup>).[^o41]

The following is a (non-exhaustive) list of properties of the Sobolev spaces.

- **Differentiability and Sobolev spaces.** $C^{k}(\mathbf{T}^{2}) \subset H_{k}(\mathbf{T}^{2})$ for *k* ≥ 0 since, using the [binomial theorem](wikipedia://en/4677) to expand (1 + |λ|<sup>2</sup>)<sup>*k*</sup>,

$$\displaystyle{\|f\|_{(k)}^2 = \sum_{|\alpha|\le k} {k\choose \alpha} \|D^\alpha f\|^2 \le C \cdot \sup_{|\alpha|\le k} |D^\alpha f|^2.}$$

- **Differential operators.** *D*<sup>α</sup> *H*<sub>*k*</sub>(**T**<sup>2</sup>) ⊂ *H*<sub>*k*−|α|</sub>(**T**<sup>2</sup>) and *D*<sup>α</sup> defines a bounded linear map from *H*<sub>*k*</sub>(**T**<sup>2</sup>) to *H*<sub>*k*−|α|</sub>(**T**<sup>2</sup>). The operator *I* + Δ defines a unitary map of *H*<sub>*k*+2</sub>(**T**<sup>2</sup>) onto *H*<sub>*k*</sub>(**T**<sup>2</sup>); in particular (*I* + Δ)<sup>*k*</sup> defines a unitary map of *H*<sub>*k*</sub>(**T**<sup>2</sup>) onto *H*<sub>−*k*</sub>(**T**<sup>2</sup>) for *k* ≥ 0.

The first assertions follow because *D*<sup>α</sup> *e*<sub>λ</sub> = λ<sup>α</sup> *e*<sub>λ</sub> and |λ<sup>α</sup>| ≤ |λ|<sup>\|α|</sup> ≤ (1 + |λ|<sup>2</sup>)<sup>\|α|/2</sup>. The second assertions follow because *I* + Δ acts as multiplication by 1 + |λ|<sup>2</sup> on *e*<sub>λ</sub>.

- **Duality.** For *k* ≥ 0, the pairing sending *f*, *g* to (*f*,*g*) establishes a duality between *H*<sub>*k*</sub>(**T**<sup>2</sup>) and *H*<sub>−*k*</sub>(**T**<sup>2</sup>).

This is a restatement of the fact that (*I* + Δ)<sup>*k*</sup> establishes a unitary map between these two spaces, because $(f,g) = ((I + \Delta)^{k}f,g)_{(-k)}$.

- **Multiplication operators.** If *h* is a smooth function then multiplication by *h* defines a continuous operator on *H*<sub>*k*</sub>(**T**<sup>2</sup>).

For *k* ≥ 0, this follows from the formula for ||*f*||${}^{2}_{(k)}$ above and the [Leibniz rule](wikipedia://en/248988). Continuity for *H*<sub>−*k*</sub>(**T**<sup>2</sup>) follows by duality, since $(f,hg) = (\overline{h}f,g)$.

- **Sobolev spaces and differentiability (Sobolev's embedding theorem).** For *k* ≥ 0, $H_{k+2}(\mathbf{T}^{2}) \subset C^{k}(\mathbf{T}^{2})$ and sup<sub>\|α|≤*k*</sub> |*D*<sup>α</sup>*f*| ≤ *C*<sub>*k*</sub> ⋅ ||*f*||<sub>(*k*+2)</sub>.

The inequalities for trigonometric polynomials imply the containments. The inequality for *k* = 0 follows from

$$\sup \left|\sum a_\lambda e_\lambda\right| \le \left(\sum (1+|\lambda|^2)^{-2}\right)^{1/2} \cdot \sum |a_\lambda| \le \left(\sum |a_\lambda|^2 (1+|\lambda|^2)^2\right)^{1/2} = \left(\sum (1+|\lambda|^2)^{-2}\right)^{1/2} \cdot \left\|\sum a_\lambda e_\lambda \right\|_{(2)},$$

by the [Cauchy–Schwarz inequality](wikipedia://en/38128). The first term is finite by the [integral test](https://en.wikipedia.org/wiki/Integral_test), since ∬<sub>**C**</sub> (1 + |*z*|<sup>2</sup>)<sup>−2</sup> *dx* *dy* = $2\pi \int^{\infty}_{0} (1 + r^{2})^{-2} r dr$ \< ∞ using [polar coordinates](https://en.wikipedia.org/wiki/Polar_coordinates). In general if |α| ≤ k, then |sup *D*<sup>α</sup>*f*| ≤ *C*<sub>0</sub> ||*D*<sup>α</sup>*f*||<sub>2</sub> ≤ *C*<sub>0</sub> ⋅ *C*<sub>α</sub> ⋅ ||*f*||<sub>*k*+2</sub> by the continuity properties of *D*<sup>α</sup>.

- **Smooth functions.** *C*<sup>∞</sup>(**T**<sup>2</sup>) = $\cap$ *H*<sub>*k*</sub>(**T**<sup>2</sup>) consists of Fourier series Σ *a*<sub>λ</sub> *e*<sub>λ</sub> such that for all *k* > 0, (1 + |λ|<sup>2</sup>)<sup>*k*</sup> |*a*<sub>λ</sub>| tends to 0 as |λ| tends to ∞, i.e. the Fourier coefficients *a*<sub>λ</sub> are of "rapid decay".

This is an immediate consequence of the Sobolev embedding theorem.

- **Inclusion maps (Rellich's compactness theorem).** If *k* > *j*, the space *H*<sub>*k*</sub>(**T**<sup>2</sup>) is a subspace of *H*<sub>*j*</sub>(**T**<sup>2</sup>) and the inclusion *H*<sub>*k*</sub>(**T**<sup>2</sup>) $\rightarrow$ *H*<sub>*j*</sub>(**T**<sup>2</sup>) is [compact](wikipedia://en/577441).

With respect to the natural orthonormal bases, the inclusion map becomes multiplication by (1 + |λ|<sup>2</sup>)<sup>−(*k*−*j*)/2</sup>. It is therefore compact because it is given by a diagonal matrix with diagonal entries tending to zero.

- **Elliptic regularity (Weyl's lemma).** Suppose that *f* and *u* in *H*<sub>−∞</sub>(**T**<sup>2</sup>) = $\cup$ *H*<sub>*k*</sub>(**T**<sup>2</sup>) satisfy ∆*u* = *f*. Suppose also that ψ *f* is a smooth function for every smooth function ψ vanishing off a fixed open set *U* in **T**<sup>2</sup>; then the same is true for *u*. (Thus if *f* is smooth off *U*, so is *u*.)

By the Leibniz rule $\Delta(\psi u) = (\Delta\psi) u + 2(\psi_{x}u_{x} + \psi_{y}u_{y}) + \psi \Delta u$, so $\psi u = (I + \Delta)^{-1}[\psi u + (\Delta\psi) u + 2(\psi_{x}u_{x} + \psi_{y}u_{y}) + \psi f]$. If it is known that *φu* lies in *H*<sub>*k*</sub>(**T**<sup>2</sup>) for some *k* and all *φ* vanishing off *U*, then differentiating shows that φ*u*<sub>*x*</sub> and φ*u*<sub>*y*</sub> lie in *H*<sub>*k*−1</sub>(**T**<sup>2</sup>). The square-bracketed expression therefore also lies in *H*<sub>*k*−1</sub>(**T**<sup>2</sup>). The operator (*I* + Δ)<sup>−1</sup> carries this space onto *H*<sub>*k*+1</sub>(**T**<sup>2</sup>), so that ψ*u* must lie in *H*<sub>*k*+1</sub>(**T**<sup>2</sup>). Continuing in this way, it follows that ψ*u* lies in $\cap$ *H*<sub>*k*</sub>(**T**<sup>2</sup>) = *C*<sup>∞</sup>(**T**<sup>2</sup>).

- **Hodge decomposition on functions.** *H*<sub>0</sub>(**T**<sup>2</sup>) = ∆ *H*<sub>2</sub>(**T**<sup>2</sup>) $\oplus$ ker ∆ and *C*<sup>∞</sup>(**T**<sup>2</sup>) = ∆ *C*<sup>∞</sup>(**T**<sup>2</sup>) $\oplus$ ker ∆.

Identifying *H*<sub>2</sub>(**T**<sup>2</sup>) with *L*<sup>2</sup>(**T**<sup>2</sup>) = *H*<sub>0</sub>(**T**<sup>2</sup>) using the unitary operator *I* + Δ, the first statement reduces to proving that the operator *T* = ∆(*I* + Δ)<sup>−1</sup> satisfies *L*<sup>2</sup>(**T**<sup>2</sup>) = im *T* $\oplus$ ker *T*. This operator is bounded, self-adjoint and diagonalized by the orthonormal basis *e*<sub>λ</sub> with eigenvalue |λ|<sup>2</sup>(1 + |λ|<sup>2</sup>)<sup>−1</sup>. The operator *T* has kernel **C** *e*<sub>0</sub> (the constant functions) and on (ker *T*)<sup>⊥</sup> = $\overline{\operatorname{im} T}$ it has a bounded inverse given by *S* *e*<sub>λ</sub> = |λ|<sup>−2</sup>(1 + |λ|<sup>2</sup>) *e*<sub>λ</sub> for λ ≠ 0. So im *T* must be closed and hence *L*<sup>2</sup>(**T**<sup>2</sup>) = (ker *T*)<sup>⊥</sup> $\oplus$ ker *T* = im *T* $\oplus$ ker *T*. Finally if *f* = ∆*g* + *h* with *f* in *C*<sup>∞</sup>(**T**<sup>2</sup>), *g* in *H*<sub>2</sub>(**T**<sup>2</sup>) and *h* constant, *g* must be smooth by Weyl's lemma.[^o42]

- **Hodge theory on T<sup>2</sup>.** Let Ω<sup>*k*</sup>(**T**<sup>2</sup>) be the space of smooth *k*-forms for 0 ≤ *k* ≤ 2. Thus Ω<sup>0</sup>(**T**<sup>2</sup>) = *C*<sup>∞</sup>(**T**<sup>2</sup>), Ω<sup>1</sup>(**T**<sup>2</sup>) = *C*<sup>∞</sup>(**T**<sup>2</sup>) *dx* $\oplus$ *C*<sup>∞</sup>(**T**<sup>2</sup>) *dy* and Ω<sup>2</sup>(**T**<sup>2</sup>) = *C*<sup>∞</sup>(**T**<sup>2</sup>) *dx* ∧ *dy*. The Hodge star operation is defined on 1-forms by ∗(*p* dx + *q* *dy*) = −*q* *dx* + *p* *dy*. This definition is extended to 0-forms and 2-forms by \**f* = *f* *dx* ∧ *dy* and \*(*g* *dx* ∧ *dy*) = *g*. Thus \*\* = (−1)<sup>*k*</sup> on *k*-forms. There is a natural complex inner product on Ω<sup>*k*</sup>(**T**<sup>2</sup>) defined by

$$\displaystyle{(\alpha,\beta) = \int_{{\mathbf T}^2} \alpha \wedge \star \overline{\beta}.}$$

Define $\delta = -\ast d\ast$. Thus δ takes Ω<sup>*k*</sup>(**T**<sup>2</sup>) to Ω<sup>*k*−1</sup>(**T**<sup>2</sup>), annihilating functions; it is the adjoint of *d* for the above inner products, so that $\delta = d*$. Indeed by the Green-Stokes formula[^o43]

$$\displaystyle{(d\alpha,\beta) = \int d\alpha \wedge \star \overline{\beta} = \int d\alpha \wedge \star \overline{\beta} -\int d(\alpha\wedge \star\overline{\beta}) = (-1)^{\partial\alpha} \int \alpha\wedge d\star\overline{\beta} = \int\alpha \wedge \star\overline{\delta\beta} = (\alpha,\delta\beta).}$$

The operators *d* and δ = *d*\* satisfy *d*<sup>2</sup> = 0 and *δ*<sup>2</sup> = 0. The Hodge Laplacian on *k*-forms is defined by $\text{∆}_{k} = (d + d*)^{2} = dd* + d*d$. From the definition $\text{∆}_{0} f = \text{∆}f$. Moreover $\text{∆}_{1}(p dx+ q dy) = (\text{∆}p)\,dx + (\text{∆}q)\,dy$ and $\text{∆}_{2}(f dx\land dy) = (\text{∆}f)dx\land dy$. This allows the Hodge decomposition to be generalised to include 1-forms and 2-forms:

- **Hodge theorem.** Ω<sup>*k*</sup>(**T**<sup>2</sup>) = ker *d* $\cap$ ker *d*∗ $\oplus$ im *d* $\oplus$ im ∗*d* = ker *d* $\cap$ ker *d*\* $\oplus$ im *d* $\oplus$ im *d*\*. In the Hilbert space completion of Ω<sup>*k*</sup>(**T**<sup>2</sup>) the orthogonal complement of $\operatorname{im} d \oplus \operatorname{im} \ast d$ is $\ker d \cap \ker d\ast$, the finite-dimensional space of harmonic *k*-forms, i.e. the constant *k*-forms. In particular in $\Omega^{k}(\mathbf{T}^{2})$ , $\ker d / \operatorname{im} d = \ker d \cap \ker d*$, the space of harmonic *k*-forms. Thus the [de Rham cohomology](wikipedia://en/221530) of **T**<sup>2</sup> is given by harmonic (i.e. constant) *k*-forms.

From the Hodge decomposition on functions, Ω<sup>*k*</sup>(**T**<sup>2</sup>) = ker ∆<sub>*k*</sub> $\oplus$ im ∆<sub>*k*</sub>. Since ∆<sub>*k*</sub> = *dd*\* + *d*\**d*, ker ∆<sub>*k*</sub> = ker *d* $\cap$ ker *d*\*. Moreover im (*dd*\* + *d*\**d*) ⊊ im *d* $\oplus$ im *d*\*. Since ker *d* $\cap$ ker *d*\* is orthogonal to this direct sum, it follows that Ω<sup>*k*</sup>(**T**<sup>2</sup>) = ker *d* $\cap$ ker *d*\* $\oplus$ im *d* $\oplus$ im *d*\*. The last assertion follows because ker *d* contains $\ker d \cap \ker d* \oplus \operatorname{im} d$ and is orthogonal to im *d*\* = im ∗*d*.

## Hilbert space of 1-forms {#Hilbert_space_of_1-forms}

In the case of the compact Riemann surface **C** / Λ, the theory of Sobolev spaces shows that the Hilbert space completion of smooth 1-forms can be decomposed as the sum of three pairwise orthogonal spaces, the closure of exact 1-forms *df*, the closure of coexact 1-forms ∗*df* and the harmonic 1-forms (the 2-dimensional space of constant 1-forms). The **method of orthogonal projection** of (Weyl 1940) puts Riemann's approach to the Dirichlet principle on sound footing by generalizing this decomposition to arbitrary Riemann surfaces.

If *X* is a Riemann surface Ω${}^{1}_{c}$(*X*) denote the space of continuous 1-forms with compact support. It admits the complex inner product

$$\displaystyle{(\alpha,\beta) = \int_{X} \alpha \wedge \star\overline{\beta},}$$

for *α* and *β* in Ω${}^{1}_{c}$(*X*). Let *H* denote the Hilbert space completion of Ω${}^{1}_{c}$(*X*). Although *H* can be interpreted in terms of measurable functions, like Sobolev spaces on tori it can be studied directly using only elementary [functional analytic](wikipedia://en/11180) techniques involving Hilbert spaces and bounded linear operators.

Let *H*<sub>1</sub> denote the closure of *d* *C*${}^{\infty}_{c}$(*X*) and *H*<sub>2</sub> denote the closure of ∗*d* *C*${}^{\infty}_{c}$(*X*). Since $(df,\ast dg) = \int_{X} df \land d\overline{g} = \int_{X} d (f d\overline{g}) = 0$, these are orthogonal subspaces. Let *H*<sub>0</sub> denote the orthogonal complement (*H*<sub>1</sub> $\oplus$ *H*<sub>2</sub>)<sup>⊥</sup> = *H*${}^{\perp}_{1}$ $\cap$ *H*${}^{\perp}_{2}$.[^o46]

::: {#o47 .statement kind=statement/theorem cue=inline-head name="Theorem (Hodge−Weyl decomposition)"}

**Theorem (Hodge−Weyl decomposition).** *H* = *H*<sub>0</sub> $\oplus$ *H*<sub>1</sub> $\oplus$ *H*<sub>2</sub>. The subspace *H*<sub>0</sub> consists of square integrable harmonic 1-forms on *X*, i.e. 1-forms *ω* such that *dω* = 0, *d*∗*ω* = 0 and ||*ω*||<sup>2</sup> = ∫<sub>*X*</sub> *ω* ∧ ∗$\overline{\omega}$ \< ∞.

- Every square integrable continuous 1-form lies in *H*.

The space of continuous 1-forms of compact support is contained in the space of square integrable continuous 1-forms. They are both inner product spaces for the above inner product. So it suffices to show that any square integrable continuous 1-form can be approximated by continuous 1-forms of compact support. Let *ω* be a continuous square integrable 1-form, Thus the positive density Ω = *ω* ∧ ∗$\overline{\omega}$ is integrable and there are continuous functions of compact support *ψ<sub>n</sub>* with 0 ≤ *ψ<sub>n</sub>* ≤ 1 such that ∫<sub>*X*</sub> *ψ<sub>n</sub>* Ω tends to ∫<sub>*X*</sub> Ω = ||*ω*||<sup>2</sup>. Let $\varphi_{n} = 1 - (1 - \psi_{n})^{1/2}$, a continuous function of compact support with $0 \le \varphi_{n} \le 1$. Then *ω<sub>n</sub>* = *φ<sub>n</sub>* ⋅ ω tends to ω in *H*, since ||*ω* − *ω<sub>n</sub>*||<sup>2</sup> = ∫<sub>*X*</sub> (1 − *ψ<sub>n</sub>*) Ω tends to 0.

- If ω in *H* is such that *ψ* ⋅ *ω* is continuous for every *ψ* in *C*<sub>*c*</sub>(*X*), then *ω* is a square integrable continuous 1-form.

Note that the multiplication operator *m*(*φ*) given by *m*(*φ*)*α* = *φ* ⋅ *α* for φ in *C*<sub>*c*</sub>(*X*) and α in Ω${}^{1}_{c}$(*X*) satisfies ||*m*(φ)α|| ≤ ||φ||<sub>∞</sub> ||α||, where ||φ||<sub>∞</sub> = sup |φ|. Thus *m*(φ) defines a bounded linear operator with operator norm ||*m*(φ)|| ≤ ||φ||<sub>∞</sub>. It extends continuously to a bounded linear operator on *H* with the same operator norm. For every open set *U* with compact closure, there is a continuous function φ of compact support with 0 ≤ φ ≤ 1 with φ ≅ 1 on *U*. Then φ ⋅ ω is continuous on *U* so defines a unique continuous form ω<sub>*U*</sub> on *U*. If *V* is another open set intersecting *U*, then ω<sub>*U*</sub> = ω<sub>*V*</sub> on *U* $\cap$ *V*: in fact if *z* lies in *U* $\cap$ *V* and ψ in *C*<sub>*c*</sub>(*U* $\cap$ *V*) ⊂ *C*<sub>*c*</sub>(*X*) with *ψ* = 1 near *z*, then *ψ* ⋅ *ω<sub>U</sub>* = *ψ* ⋅ *ω* = *ψ* ⋅ *ω<sub>V</sub>*, so that *ω<sub>U</sub>* = *ω<sub>V</sub>* near *z*. Thus the ω<sub>*U*</sub>'s patch together to give a continuous 1-form ω<sub>0</sub> on *X*. By construction, *ψ* ⋅ *ω* = *ψ* ⋅ *ω*<sub>0</sub> for every *ψ* in *C*<sub>*c*</sub>(*X*). In particular for *φ* in *C*<sub>*c*</sub>(*X*) with $0 \le \varphi \le 1$, ∫ *φ* ⋅ *ω*<sub>0</sub> ∧ ∗$\overline{\omega_{0}}$ = ||*φ*<sup>1/2</sup> ⋅ *ω*<sub>0</sub>||<sup>2</sup> = ||*φ*<sup>1/2</sup> ⋅ *ω*||<sup>2</sup> ≤ ||ω||<sup>2</sup>. So ω<sub>0</sub> ∧ ∗$\overline{\omega_{0}}$ is integrable and hence ω<sub>0</sub> is square integrable, so an element of *H*. On the other hand ω can be approximated by *ω<sub>n</sub>* in Ω${}^{1}_{c}$(*X*). Take ψ<sub>*n*</sub> in *C*<sub>*c*</sub>(*X*) with 0 ≤ ψ<sub>*n*</sub> ≤ 1 with $\psi_{n} \cdot \omega_{n} = \omega_{n}$. Since real-valued continuous functions are closed under [lattice operations](wikipedia://en/469304). it can further be assumed that ∫ *ψ*${}^{2}_{n}$ *ω*<sub>0</sub> ∧ ∗$\overline{\omega_{0}}$, and hence ∫ *ψ<sub>n</sub>* *ω*<sub>0</sub> ∧ ∗$\overline{\omega_{0}}$, increase to ||*ω*<sub>0</sub>||<sup>2</sup>. But then ||ψ<sub>*n*</sub> ⋅ ω − ω|| and ||ψ<sub>*n*</sub> ⋅ ω<sub>0</sub> − ω<sub>0</sub>|| tend to 0. Since $\psi_{n} \cdot \omega = \psi_{n} \cdot \omega_{0}$, this shows that $\omega = \omega_{0}$.

- Every square integrable harmonic 1-form ω lies in *H*<sub>0</sub>.

This is immediate because ω lies in *H* and, for *f* a smooth function of compact support, $(df,\omega) = \int_{X} df \land \ast\omega = -\int_{X} f d\ast\omega = 0$ and $(\ast df,\omega) = \int_{X} df \land \omega = - \int_{X} f d\omega = 0$.

- Every element of *H*<sub>0</sub> is given by a square integrable harmonic 1-form.

Let ω be an element of *H*<sub>0</sub> and for fixed *p* in *X* fix a chart *U* in *X* containing *p* which is conformally equivalent by a map *f* to a disc *D* ⊂ **T**<sup>2</sup> with *f*(0) = *p*. The identification map from Ω${}^{1}_{c}$(*U*) onto Ω${}^{1}_{c}$(*D*) and hence into Ω<sup>1</sup>(**T**<sup>2</sup>) preserves norms (up to a constant factor). Let *K* be the closure of Ω${}^{1}_{c}$(*U*) in *H*. Then the above map extends uniquely to an isometry *T* of *K* into *H*<sub>0</sub>(**T**<sup>2</sup>)*dx* $\oplus$ *H*<sub>0</sub>(**T**<sup>2</sup>)*dy*. Moreover if *ψ* is in *C*${}^{\infty}_{c}$(*U*) then $T m(\psi) = m(\psi \circ f) T$. The identification map *T* is also compatible with *d* and the Hodge star operator. Let *D*<sub>1</sub> be a smaller concentric disk in **T**<sup>2</sup> and set *V* = *f*(*V*). Take *φ* in *C*${}^{\infty}_{c}$(*U*) with *φ* ≡ 1 on *V*. Then (*m*(*φ*) *ω*,*dh*) = 0 = (*m*(*φ*) *ω*,∗*dh*) for *h* in *C*${}^{\infty}_{c}$(*V*). Hence, if *ω*<sub>1</sub> = *m*(*φ*)*ω* and *ω*<sub>2</sub> = *T*(*ω*<sub>1</sub>), then (*ω*<sub>2</sub>, *dg*) = 0 = (*ω*<sub>2</sub>, ∗*dg*) for *g* in $C^{\infty}_{c}(D_{1})$.

Write *ω*<sub>2</sub> = *a* *dx* + *b* *dy* with *a* and *b* in *H*<sub>0</sub>(**T**<sup>2</sup>). The conditions above imply (*dω*<sub>1</sub>, ∗*g*) = 0 = (*d*∗ *ω*<sub>1</sub>, ∗*g*). Replacing ∗*g* by *dω*<sub>3</sub> with *ω*<sub>3</sub> a smooth 1-form supported in *D*<sub>1</sub>, it follows that ∆<sub>1</sub> *ω*<sub>2</sub> = 0 on *D*<sub>1</sub>. Thus ∆*a* = 0 = ∆*b* on *D*<sub>1</sub>. Hence by Weyl's lemma, *a* and *b* are harmonic on *D*<sub>1</sub>. In particular both of them, and hence ω<sub>2</sub>, are smooth on *D*<sub>1</sub>; and *dω*<sub>2</sub> = 0 = *d*∗*ω*<sub>2</sub> on *D*<sub>1</sub>. Transporting these equations back to *X*, it follows that *ω*<sub>1</sub> is smooth on *V* and *dω*<sub>1</sub> = 0 = *d*∗*ω*<sub>1</sub> on *V*. Since *ω*<sub>1</sub> = *m*(*φ*)*ω* and *p* was an arbitrary point, this implies in particular that *m*(*ψ*)*ω* is continuous for every *ψ* in *C*<sub>*c*</sub>(*X*). So *ω* is continuous and square integrable.

But then ω is smooth on *V* and *d*ω = 0 = *d*∗ω on *V*. Again since *p* was arbitrary, this implies ω is smooth on *X* and *d*ω = 0 = *d*∗ω on *X*, so that ω is a harmonic 1-form on *X*.

From the formulas for the Dolbeault operators $\partial$ and $\bar{\partial}$, it follows that

$$\displaystyle{d C^\infty_c(X) \oplus * d C^\infty_c(X) = \partial C^\infty_c(X) \oplus \overline{\partial}C^\infty_c(X),}$$

where both sums are orthogonal. The two subspaces in the second sum correspond to the ±*i* eigenspaces of the Hodge ∗ operator. Denoting their closures by *H*<sub>3</sub> and *H*<sub>4</sub>, it follows that *H*${}^{\perp}_{0}$ = *H*<sub>3</sub> ⊕ *H*<sub>4</sub> and that these subspaces are interchanged by complex conjugation. The smooth 1-forms in *H*<sub>1</sub>, *H*<sub>2</sub>, *H*<sub>3</sub> or *H*<sub>4</sub> have a simple description.[^o48]

- A smooth 1-form in *H*<sub>1</sub> has the form *df* for *f* smooth.
- A smooth 1-form in *H*<sub>2</sub> has the form ∗*df* for *f* smooth.
- A smooth 1-form in *H*<sub>3</sub> has the form $\partial$*f* for *f* smooth.
- A smooth 1-form in *H*<sub>3</sub> has the form $\bar{\partial}$*f* for *f* smooth.

In fact, in view of the decompositions of *H*${}^{\perp}_{0}$ and its invariance under the Hodge star operation, it suffices to prove the first of these assertions. Since *H*<sub>1</sub> is invariant under complex conjugation, it may be assumed that α is a smooth real 1-form in *H*<sub>1</sub>. It is therefore a limit in *H*<sub>1</sub> of forms *df*<sub>*n*</sub> with *f*<sub>*n*</sub> smooth of compact support. The 1-form α must be closed since, for any real-valued *f* in *C*${}^{\infty}_{c}$(*X*),

$$\int_X f \, d\alpha = -\int_X df \wedge \alpha= (\alpha,*df)=0,$$

so that *d*α = 0. To prove that α is exact it suffices to prove that ∫<sub>*X*</sub> α ∧ ∗β = 0 for any smooth closed real 1-form β of compact support. But by Green's formula

$$\int_X \alpha \wedge \star \beta = (\alpha,\beta) = \lim (df_n,\beta)= \lim \int_X df_n \wedge \beta=\lim \int_X d(f_n\beta)=0.$$

The above characterisations have an immediate corollary:

- A smooth 1-form α in *H*${}^{\perp}_{0}$ can be decomposed uniquely as *α* = *da* + ∗*db* = *∂f* + *∂g*, with *a*, *b*, *f* and *g* smooth and all the summands square integrable.

Combined with the previous Hodge–Weyl decomposition and the fact that an element of *H*<sub>0</sub> is automatically smooth, this immediately implies:

:::

::: {#o49 .statement kind=statement/theorem cue=inline-head name="Theorem (smooth Hodge–Weyl decomposition)"}

**Theorem (smooth Hodge–Weyl decomposition).** If α is a smooth square integrable 1-form then α can be written uniquely as $\alpha = \omega + da + *db = \omega + \partial f + \overline{\partial}g$ with *ω* harmonic, square integrable and $a, b, f, g$ smooth with square integrable differentials.[^o50]

:::

## Holomorphic 1-forms with a double pole {#Holomorphic_1-forms_with_a_double_pole}

The following result—reinterpreted in the next section in terms of harmonic functions and the Dirichlet principle—is the key tool for proving the [uniformization theorem](wikipedia://en/288270) for simply connected, or more generally planar, Riemann surfaces.

::: {#o52 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** If *X* is a Riemann surface and *P* is a point on *X* with local coordinate *z*, there is a unique holomorphic differential 1-form *ω* with a double pole at *P*, so that the singular part of *ω* is *z*<sup>−2</sup>*dz* near *P*, and regular everywhere else, such that *ω* is square integrable on the complement of a neighbourhood of *P* and the real part of *ω* is exact on *X* \\ {P}.[^o53]

The double pole condition is invariant under holomorphic coordinate change *z* $\mapsto$ *z* + *az*<sup>2</sup> + ⋯. There is an analogous result for poles of order greater than 2 where the singular part of *ω* has the form *z*<sup>–*k*</sup>*dz* with *k* > 2, although this condition is not invariant under holomorphic coordinate change.

To prove uniqueness, note that if *ω*<sub>1</sub> and *ω*<sub>2</sub> are two solutions then their difference *ω* = *ω*<sub>1</sub> − *ω*<sub>2</sub> is a square integrable holomorphic 1-form which is exact on *X* \\ {P}. Thus near *P*, $\omega = f(z) dz$ with *f* holomorphic near *z* = 0. There is a holomorphic function *g* on *X* \\ {P} such that *ω* = *dg* there. But then *g* must coincide with a [primitive](https://en.wikipedia.org/wiki/Primitive_function) of *f* near *z* = 0, so that *ω* = *dg* everywhere. But then *ω* lies in *H*<sub>0</sub> ∩ *H*<sub>1</sub> = (0), i.e. *ω* = 0.

To prove existence, take a bump function 0 ≤ *ψ* ≤ 1 in *C*${}^{\infty}_{c}$(*X*) with support in a neighbourhood of *P* of the form |*z*| \< *ε* and such that *ψ* ≡ 1 near *P*. Set

$$\alpha =-d \left({\psi(z)\over z}\right),$$

so that *α* equals *z*<sup>–2</sup>*dz* near *P*, vanishes off a neighbourhood of *P* and is exact on *X* \\ {P}. Let *β* = *α* − *i*∗*α*, a smooth (0,1) form on *X*, vanishing near *z* = 0, since it is a (1,0) form there, and vanishing off a larger neighbourhood of *P*. By the smooth Hodge−Weyl decomposition, *β* can be decomposed as *β* = *ω*<sub>0</sub> + *da* – *i*∗*da* with *ω*<sub>0</sub> a harmonic and square integrable (0,1) form and *a* smooth with square integrable differential. Now set *γ* = *α* – *da* = *ω*<sub>0</sub> + *i*∗*α* − *i*∗*da* and *ω* = Re *γ* + *i*∗ Re *γ*. Then α is exact on *X* \\ {P}; hence so is γ, as well as its real part, which is also the real part of ω. Near *P*, the 1-form ω differs from *z*<sup>–2</sup>*dz* by a smooth (1,0) form. It remains to prove that $\bar{\partial}$ω = 0 on *X* \\ {P}; or equivalently that Re γ is harmonic on *X* \\ {P}. In fact γ is harmonic on *X* \\ {P}; for *d*γ = *d*α − *d*(*da*) = 0 on *X* \\ {P} because α is exact there; and similarly *d*∗*γ* = 0 using the formula *γ* = *ω*<sub>0</sub> + *i*∗*α* − *i*∗*da* and the fact that *ω*<sub>0</sub> is harmonic.

:::

::: {#o54 .proof cue=inline-head name="Corollary of proof"}

**Corollary of proof.** [^o55] If *X* is a Riemann surface and *P* is a point on *X* with local coordinate *z*, there is a unique real-valued 1-form *δ* which is harmonic on *X* \\ {*P*} such that *δ* – Re *z*<sup>−2</sup>*dz* is harmonic near *z* = 0 (the point *P*) such that δ is square integrable on the complement of a neighbourhood of *P*. Moreover, if *h* is any real-valued smooth function on *X* with *dh* square integrable and *h* vanishing near *P*, then (*δ*,*dh*) = 0.

Existence follows by taking *δ* = Re *γ* = Re *ω* above. Since *ω* = *δ* + *i*∗δ, the uniqueness of ω implies the uniqueness of δ. Alternatively if δ<sub>1</sub> and δ<sub>2</sub> are two solutions, their difference η = δ<sub>1</sub> – δ<sub>2</sub> has no singularity at *P* and is harmonic on *X* \\ {*P*}. It is therefore harmonic in a neighbourhood of *P* and therefore everywhere. So η lies in *H*<sub>0</sub>. But also η is exact on *X* \\ *P* and hence on the whole of *X*, so it also lies in *H*<sub>1</sub>. But then it must lie in *H*<sub>0</sub> ∩ *H*<sub>1</sub> = (0), so that η = 0. Finally, if *N* is the closure of a neighbourhood of *P* disjoint from the support of *h* and *Y* = *X* \\ *N*, then δ|<sub>*Y*</sub> lies in *H*<sub>0</sub>(*Y*) and *dh* lies in the space *H*<sub>1</sub>(*Y*) so that

$$(\delta,dh) =\int_X \delta \wedge \star dh = \int_Y \delta \wedge \star dh = (\delta|_Y,dh)_Y = 0.$$

:::

::: {#o57 .statement cue=named-heading name="Dirichlet's principle on a Riemann surface"}

## Dirichlet's principle on a Riemann surface {#Dirichlet's_principle_on_a_Riemann_surface}

**Theorem.**[^o58] If *X* is a Riemann surface and *P* is a point on *X* with local coordinate *z*, there is a unique real-valued harmonic function *u* on *X* \\ {*P*} such that *u*(*z*) – Re *z*<sup>−1</sup> is harmonic near *z* = 0 (the point *P*) such that *du* is square integrable on the complement of a neighbourhood of *P*. Moreover, if *h* is any real-valued smooth function on *X* with *dh* square integrable and *h* vanishing near *P*, then (*du*,*dh*)=0.

In fact this result is immediate from the theorem and corollary in the previous section. The harmonic form δ constructed there is the real part of a holomorphic form ω = *dg* where *g* is holomorphic function on *X* with a simple pole at *P* with residue -1, i.e. *g*(*z*) = –*z*<sup>−1</sup> + *a*<sub>0</sub> + *a*<sub>1</sub>*z* + *a*<sub>2</sub> *z*<sup>2</sup> + ⋯ near *z* = 0. So *u* = - Re *g* gives a solution with the claimed properties since δ = −*du* and hence (*du*,*dh*) = −(δ,*dh*) = 0.

This result can be interpreted in terms of [Dirichlet's principle](wikipedia://en/1240011).[^o59][^o60][^o61] Let *D*<sub>*R*</sub> be a parametric disk |*z*| \< *R* about *P* (the point *z* = 0) with *R* > 1. Let *α* = −*d*(*ψz*<sup>−1</sup>), where 0 ≤ ψ ≤ 1 is a bump function supported in *D* = *D*<sub>1</sub>, identically 1 near *z* = 0. Let α<sub>1</sub> = −χ<sub>*D*</sub>(*z*) Re *d*(*z*<sup>−1</sup>) where χ<sub>*D*</sub> is the [characteristic function](wikipedia://en/240790) of *D*. Let γ= Re α and *γ*<sub>1</sub> = Re *α*<sub>1</sub>. Since χ<sub>*D*</sub> can be approximated by bump functions in L<sup>2</sup>, *γ*<sub>1</sub> − *γ* lies in the real Hilbert space of 1-forms Re *H*; similarly α<sub>1</sub> − α lies in *H*. Dirichlet's principle states that the distance function

*F*(*ξ*) = ||*γ*<sub>1</sub> − *γ* – *ξ*||

on Re *H*<sub>1</sub> is minimised by a smooth 1-form ξ<sub>0</sub> in Re *H*<sub>1</sub>. In fact −*du* coincides with the minimising 1-form: *γ* + *ξ*<sub>0</sub> = −*du*.

This version of Dirichlet's principle is easy to deduce from the previous construction of *du*. By definition *ξ*<sub>0</sub> is the orthogonal projection of *γ*<sub>1</sub> – *γ* onto Re *H*<sub>1</sub> for the real inner product Re (*η*<sub>1</sub>,*η*<sub>2</sub>) on *H*, regarded as a real inner product space. It coincides with the real part of the orthogonal projection ω<sub>1</sub> of α<sub>1</sub> – α onto *H*<sub>1</sub> for the complex inner product on *H*. Since the Hodge star operator is a unitary map on *H* swapping *H*<sub>1</sub> and *H*<sub>2</sub>, *ω*<sub>2</sub> = ∗*ω*<sub>1</sub> is the orthogonal projection of ∗(*α*<sub>1</sub> – *α*) onto *H*<sub>2</sub>. On the other hand, ∗*α*<sub>1</sub> = −*i* *α*<sub>1</sub>, since *α* is a (1,0) form. Hence

(*α*<sub>1</sub> – *α*) − *i*∗(*α*<sub>1</sub> – *α*) = *ω*<sub>0</sub> + *ω*<sub>1</sub> + *ω*<sub>2</sub>,

with *ω<sub>k</sub>* in *H*<sub>*k*</sub>. But the left hand side equals –*α* + *i*∗*α* = −*β*, with *β* defined exactly as in the preceding section, so this coincides with the previous construction.

Further discussion of Dirichlet's principle on a Riemann surface can be found in (Hurwitz Courant 1929), (Ahlfors 1947), (Courant 1950), (Schiffer Spencer 1954), (Pfluger 1957) and (Ahlfors Sario 1960).

**Historical note.** (Weyl 1913) proved the existence of the harmonic function *u* by giving a direct proof of Dirichlet's principle. In (Weyl 1940), he presented his method of orthogonal projection which has been adopted in the presentation above, following (Springer 1957), but with the theory of Sobolev spaces on **T**<sup>2</sup> used to prove elliptic regularity without using measure theory. In the expository texts (Weyl 1955) and (Kodaira 2007), both authors avoid invoking results on measure theory: they follow Weyl's original approach for constructing harmonic functions with singularities via Dirichlet's principle. In Weyl's method of orthogonal projection, Lebesgue's theory of integration had been used to realise Hilbert spaces of 1-forms in terms of measurable 1-forms, although the 1-forms to be constructed were smooth or even analytic away from their singularity. In the preface to (Weyl 1955), referring to the extension of his method of orthogonal projection to higher dimensions by (Kodaira 1949), Weyl writes:

"Influenced by Kodaira's work, I have hesitated a moment as to whether I should not replace the Dirichlet principle by the essentially equivalent "method of orthogonal projection" which is treated in a paper of mine. But for reasons the explication of which would lead too far afield here, I have stuck to the old approach."

In (Kodaira 2007), after giving a brief exposition of the method of orthogonal projection and making reference to Weyl's writings,[^o76] Kodaira explains:

"I first planned to prove Dirichlet's Principle using the method of orthogonal projection in this book. However, I did not like to have to use the concept of Lebesgue measurability only for the proof of Dirichlet's Principle and therefore I rewrote it in such a way that I did not have to."

The methods of Hilbert spaces, *L*<sup>*p*</sup> spaces and measure theory appear in the non-classical theory of Riemann surfaces (the study of [moduli spaces](wikipedia://en/361609) of Riemann surfaces) through the [Beltrami equation](wikipedia://en/31356616) and [Teichmüller theory](https://en.wikipedia.org/wiki/Teichmüller_theory).

:::

## Holomorphic 1-forms with two single poles {#Holomorphic_1-forms_with_two_single_poles}

::: {#o78 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Given a Riemann surface *X* and two distinct points *A* and *B* on *X*, there is a holomorphic 1-form on *X* with simple poles at the two points with non-zero residues having sum zero such that the 1-form is square integrable on the complement of any open neighbourhoods of the two points.[^o79]

The proof is similar to the proof of the result on holomorphic 1-forms with a single double pole. The result is first proved when *A* and *B* are close and lie in a parametric disk. Indeed, once this is proved, a sum of 1-forms for a chain of sufficiently close points between *A* and *B* will provide the required 1-form, since the intermediate singular terms will cancel. To construct the 1-form for points corresponding to *a* and *b* in a parametric disk, the previous construction can be used starting with the 1-form

$$\alpha = d\left (\psi(z) \log{z-a\over z-b}\right),$$

which locally has the form

$${dz\over z-a} - {dz\over z-b}.$$

:::

## Poisson equation {#Poisson_equation}

**Theorem (Poisson equation).** If Ω is a smooth 2-form of compact support on a Riemann surface *X*, then Ω can be written as Ω = ∆*f* where *f* is a smooth function with *df* square integrable if and only if ∫<sub>*X*</sub> Ω = 0.

In fact, Ω can be written as Ω = *d*α with α a smooth 1-form of compact support: indeed, using partitions of unity, this reduces to the case of a smooth 2-form of compact support on a rectangle. Indeed Ω can be written as a finite sum of 2-forms each supported in a parametric rectangle and having integral zero. For each of these 2-forms the result follows from Poincaré's lemma with compact support. Writing *α* = *ω* + *da* + \**db*, it follows that Ω = *d*\**db* = ∆*b*.

In the case of the simply connected Riemann surfaces **C**, *D* and *S*= **C** ∪ ∞, the Riemann surfaces are [symmetric spaces](wikipedia://en/1642877) *G* / *K* for the groups *G* = **R**<sup>2</sup>, SL(2,**R**) and SU(2). The methods of group representation theory imply the operator ∆ is *G*-invariant, so that its fundamental solution is given by right convolution by a function on *K* \\ *G* / *K*.[^o81][^o82] Thus in these cases Poisson's equation can be solved by an explicit integral formula. It is easy to verify that this explicit solution tends to 0 at ∞, so that in the case of these surfaces there is a solution *f* tending to 0 at ∞. (Donaldson 2011) proves this directly for simply connected surfaces and uses it to deduce the [uniformization theorem](wikipedia://en/288270).[^o84]
