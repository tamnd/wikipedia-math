# DONE

::: {#o1 .subject cue=lead name="DONE"}

The **Data-based Online Nonlinear Extremumseeker** (**DONE**) algorithm is a black-box [optimization](https://en.wikipedia.org/wiki/Optimization) algorithm. DONE models the unknown cost function and attempts to find an optimum of the underlying function. The DONE algorithm is suitable for optimizing costly and noisy functions and does not require derivatives. An advantage of DONE over similar algorithms, such as [Bayesian optimization](wikipedia://en/40973765), is that the [computational cost](https://en.wikipedia.org/wiki/Computational_cost) per iteration is independent of the number of function evaluations.

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Methods"}

## Methods {#Methods}

The DONE algorithm was first proposed by Hans Verstraete and Sander Wahls in 2015.[^o4] The algorithm fits a [surrogate model](wikipedia://en/6500531) based on random Fourier features[^o5] and then uses a well-known [L-BFGS](https://en.wikipedia.org/wiki/L-BFGS) algorithm to find an optimum of the surrogate model.

:::

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

DONE was first demonstrated for maximizing the signal in [optical coherence tomography](https://en.wikipedia.org/wiki/Optical_coherence_tomography) measurements, but has since then been applied to various other applications. For example, it was used to help extending the field of view in [light sheet fluorescence microscopy](https://en.wikipedia.org/wiki/Light_sheet_fluorescence_microscopy).[^o8]

:::
