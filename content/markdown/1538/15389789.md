# Zigzag code

::: {#o1 .subject cue=lead name="Zigzag code"}

In [coding theory](wikipedia://en/321869), a **zigzag code** is a type of [linear](wikipedia://en/1866743) [error-correcting code](https://en.wikipedia.org/wiki/Error-correcting_code) introduced by (Ping Huang Phamdo 2001).[^o3] They are defined by partitioning the input data into segments of fixed size, and adding sequence of check bits to the data, where each check bit is the [exclusive or](wikipedia://en/105979) of the bits in a single segment and of the previous check bit in the sequence.

:::

The [code rate](https://en.wikipedia.org/wiki/Code_rate) is high: $J/(J + 1)$ where $J$ is the number of bits per segment. Its worst-case ability to correct transmission errors is very limited: in the worst case it can only detect a single bit error and cannot correct any errors. However, it works better in the [soft-decision model of decoding](https://en.wikipedia.org/wiki/Soft-decision_decoder): its regular structure allows the task of finding a [maximum-likelihood decoding](wikipedia://en/1940782#Maximum_likelihood_decoding) or a posteriori probability decoding to be performed in constant time per input bit.
