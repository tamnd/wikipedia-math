# Doctrine (mathematics)

::: {#o1 .subject cue=lead name="Doctrine"}

In [mathematics](wikipedia://en/18831), specifically [category theory](wikipedia://en/5869), a **doctrine** is roughly a system of theories ("categorical analogues of fragments of [logical theories](https://en.wikipedia.org/wiki/Logical_theory) which have sufficient category-theoretic structure for their [models](wikipedia://en/2895304) to be described as [functors](https://en.wikipedia.org/wiki/Functors)"[^o2]). For example, an [algebraic theory](wikipedia://en/24497685), as invented by [William Lawvere](wikipedia://en/872760), is an example of a doctrine.[^o2] The concept of doctrines was invented by Lawvere as part of his work on algebraic theories.[^o3][^o4] The name is based on a suggestion by [Jon Beck](wikipedia://en/37065609).[^o4][^o5]

:::

A doctrine can be defined in several ways:[^o6]

- as a 2-[monad](wikipedia://en/355140). This was Lawvere's original approach.
- as a [2-category](wikipedia://en/2740708); the idea is that each object there amounts to a "theory".[^o6]
- As cartesian double theories, as logics, or as a class of limits.
