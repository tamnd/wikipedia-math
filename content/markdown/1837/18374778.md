# Minimal model (set theory)

::: {#o1 .subject cue=lead name="Minimal model"}

In [set theory](wikipedia://en/27553), a branch of [mathematics](wikipedia://en/18831), the **minimal model** is the minimal [standard model](wikipedia://en/18391755) of [ZFC](https://en.wikipedia.org/wiki/ZFC). The minimal model was introduced by (txt) and rediscovered by (Cohen 1963).

:::

The existence of a minimal model cannot be proved in [ZFC](https://en.wikipedia.org/wiki/ZFC), even assuming that ZFC is [consistent](https://en.wikipedia.org/wiki/Consistent), but follows from the existence of a standard model as follows. If there is a *set* *W* in the [von Neumann universe](wikipedia://en/445980) V that is a standard model of ZF, and the [ordinal](wikipedia://en/26547932) *κ* is the set of ordinals that occur in *W*, then L<sub>*κ*</sub> is the [class](wikipedia://en/20696) of [constructible sets](wikipedia://en/343335) of *W* (and so L<sub>*κ*</sub> is itself a standard model). If there is a set that is a standard model of ZF, then the smallest such set is such an L<sub>*κ*</sub>. This set is called the **minimal model** of ZFC, and also satisfies the [axiom of constructibility](wikipedia://en/696472) V=L. The downward [Löwenheim–Skolem theorem](wikipedia://en/341482) implies that the minimal model (if it exists as a set) is a [countable](https://en.wikipedia.org/wiki/Countable) set. More precisely, every element *s* of the minimal model can be named; in other words, for every element *s* of the minimal model, there is a [first-order sentence](https://en.wikipedia.org/wiki/First-order_sentence) *φ*(*x*) such that *s* is the unique element for which *φ*(*s*) is true.

(Cohen 1963) gave another construction of the minimal model as the strongly constructible sets, using a modified form of Gödel's constructible universe.

Of course, any consistent theory must have a model, so even within the minimal model of set theory there are sets that are models of ZFC (assuming ZFC is consistent in the model). However, these set models are non-standard. In particular, they do not use the normal membership relation and they are not well-founded.

If there is no standard model then the minimal model cannot exist as a set. However in this case the class of all constructible sets plays the same role as the minimal model and has similar properties (though it is now a proper class rather than a countable set).

The minimal model of set theory has no [inner models](wikipedia://en/1118686) other than itself. In particular it is not possible to use the method of inner models to prove that any given statement true in the minimal model (such as the [continuum hypothesis](wikipedia://en/5705)) is not provable in ZFC.
