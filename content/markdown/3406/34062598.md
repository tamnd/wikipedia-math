# Proto-value function

::: {#o1 .subject cue=lead name="Proto-value function"}

In [applied mathematics](wikipedia://en/24295969), **proto-value functions (PVFs)** are automatically learned [basis functions](wikipedia://en/50909) that are useful in approximating task-specific value functions, providing a compact representation of the powers of transition matrices. They provide a novel framework for solving the [credit assignment problem](https://en.wikipedia.org/wiki/Credit_assignment_problem). The framework introduces a novel approach to solving [Markov decision processes](wikipedia://en/1125883) (MDP) and [reinforcement learning](wikipedia://en/66294) problems, using multiscale spectral and [manifold learning](https://en.wikipedia.org/wiki/Manifold_learning) methods. Proto-value functions are generated by [spectral analysis](wikipedia://en/534914) of a graph, using the [graph Laplacian](wikipedia://en/1448472).

:::

Proto-value functions were first introduced in the context of reinforcement learning by Sridhar Mahadevan in his paper, *Proto-Value Functions: Developmental Reinforcement Learning* at [ICML](https://en.wikipedia.org/wiki/ICML) 2005.[^o2]

## Motivation {#Motivation}

Value function [approximation](wikipedia://en/336897) is a critical component to solving [Markov decision processes](wikipedia://en/1125883) (MDPs) defined over a continuous state space. A good function approximator allows a [reinforcement learning](wikipedia://en/66294) (RL) agent to accurately represent the value of any state it has experienced, without explicitly storing its value. Linear function approximation using [basis functions](wikipedia://en/50909) is a common way of constructing a value function approximation, like [radial basis functions](https://en.wikipedia.org/wiki/Radial_basis_functions), polynomial state encodings, and [CMACs](https://en.wikipedia.org/wiki/Cerebellar_Model_Articulation_Controller). However, parameters associated with these basis functions often require significant domain-specific hand-engineering.[^o4] Proto-value functions attempts to solve this required hand-engineering by accounting for the underlying manifold structure of the problem domain.[^o2]

## Overview {#Overview}

Proto-value functions are task-independent global basis functions that collectively span the entire space of possible value functions for a given state space.[^o2] They incorporate geometric constraints intrinsic to the environment. For example, states close in Euclidean distance (such as states on opposite sides of a wall) may be far apart in manifold space. Previous approaches to this nonlinearity problem lacked a broad theoretical framework, and consequently have only been explored in the context of discrete [MDPs](wikipedia://en/1125883).

Proto-value functions arise from reformulating the problem of value function approximation as real-valued function approximation on a graph or manifold. This results in broader applicability of the learned bases and enables a new class of learning algorithms, which learn representations and policies at the same time.[^o6]

## Basis functions from graph Laplacian {#Basis_functions_from_graph_Laplacian}

This approach constructs the [basis functions](wikipedia://en/50909) by spectral analysis of the graph Laplacian, a [self-adjoint](wikipedia://en/187408) (or symmetric) operator on the space of functions on the graph, closely related to the [random walk](wikipedia://en/235451) operator.

For the sake of simplicity, assume that the underlying state space can be represented as an undirected unweighted graph $G=(V,E)$ The [combinatorial Laplacian](wikipedia://en/1448472) $L$ is defined as the operator $L = D - A$, where $D$ is a diagonal matrix called the [degree matrix](wikipedia://en/1449175) and $A$ is the [adjacency matrix](wikipedia://en/244463).[^o2]

The spectral analysis of the Laplace operator on a graph consists of finding the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) and eigenfunctions which solve the equation

$$L\varphi_\lambda = \lambda\varphi_\lambda,$$

where $L$ is the combinatorial Laplacian, $\varphi_\lambda$ is an eigenfunction associated with the eigenvalue $\lambda$. Here the term "eigenfunction" is used to denote what is traditionally referred to as [eigenvector](https://en.wikipedia.org/wiki/Eigenvector) in linear algebra, because the Laplacian [eigenvectors](https://en.wikipedia.org/wiki/Eigenvector) can naturally be viewed as functions that map each vertex to a real number.[^o6]

The combinatorial Laplacian is not the only operator on graphs to select from. Other possible graph operators include:

- Normalized Laplacian $L_\text{normalized} = I - D^{-1/2}AD^{-1/2}$ [^o8]
- Random Walk $P = D^{-1}A$ [^o8]

### Graph construction on discrete state space {#Graph_construction_on_discrete_state_space}

For a finite state space the graph $G$ mentioned above can be simply constructed by examining the connections between states. Let $S_i$ and $S_j$ be any two states. Then

$$G_{i,j}=\begin{cases} 1 & \text{if } S_i\leftrightarrow S_j \\ 0 & \text{otherwise} \end{cases}$$

This can only be done when the state space is finite and of reasonable size.

### Graph construction on continuous or large state space {#Graph_construction_on_continuous_or_large_state_space}

For a continuous state space or simply a very large discrete state space, it is necessary to sample from the manifold in state space. Then constructing the Graph $G$ based on the samples. There are a few issues to consider here:[^o8]

- How to sample the manifold
  - Random walk or guided exploration
- How to determine if two sample should be connected

## Application {#Application}

Once the PVFs are generated, they can be plugged into a traditional function approximation framework. One such method is least-squares approximation.

### Least-squares approximation using proto-value functions {#Least-squares_approximation_using_proto-value_functions}

Let $\Phi_G=\left\{ V_1^G,\dots,V_k^G\right\}$ be the basis set of PVFs, where each $V_i^G$ is the eigenfunction defined over all states in the graph $G$. Let $\widehat{V}^\pi$ be the target value function that is only known for a subset of states $S_M^G =\left\{ s_1,\dots,s_m\right\}$.

Define the [gram matrix](https://en.wikipedia.org/wiki/Gramian_matrix)

$$K_G =\left(\Phi_m^G \right)^T \Phi_m^G.$$

Here $S_m^G$ is the component wise projection of the PVFs onto the states in $S_G^m$. Hence, each entry of the gram matrix is

$$K_G(i,j) = \sum_k V_i^G(k) V_j^G (k).$$

The coefficients that minimize the least squares error are then described by the equation

$$\alpha=K_G^{-1}\left(\Phi_M^G \right)^T \widehat{V}^\pi.$$

A nonlinear least-squares approach is possible by using the *k* PVFs with the largest absolute coefficients to compute the approximation.[^o2]
