# Scott's rule

::: {#o1 .subject cue=lead name="Scott's rule"}

**Scott's rule** is a method to select the number of bins in a [histogram](wikipedia://en/13266).[^o2] Scott's rule is widely employed in [data analysis](wikipedia://en/2720954) software including [R](wikipedia://en/376707),[^o3] [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29)[^o4] and [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel) where it is the default bin selection method.[^o5]

:::

For a set of $n$ observations $x_i$ let $\hat{f}(x)$ be the histogram approximation of some function $f(x)$. The integrated [mean squared error](wikipedia://en/201816) (IMSE) is

$$\text{IMSE} = E\left[ \int_{-\infty}^{\infty} dx (\hat{f}(x) - f(x))^2\right]$$

Where $E[\cdot]$ denotes the [expectation](wikipedia://en/9653) across many independent draws of $n$ data points. By [Taylor expanding](wikipedia://en/30448) to first order in $h$, the bin width, Scott showed that the optimal width is

$$h^* = \left( 6 / \int_{-\infty}^{\infty} f'(x)^2 dx \right)^{1/3}n^{-1/3}$$

This formula is also the basis for the [Freedman–Diaconis rule](wikipedia://en/1851103).

By taking a *normal reference* i.e. assuming that $f(x)$ is a [normal distribution](wikipedia://en/21462), the equation for $h^*$ becomes

$$h^* = \left( 24 \sqrt{\pi} \right)^{1/3} \sigma n^{-1/3} \sim 3.5 \sigma n^{-1/3}$$

where $\sigma$ is the [standard deviation](wikipedia://en/27590) of the normal distribution and is estimated from the data. With this value of bin width Scott demonstrates that[^o6]

$$\text{IMSE} \propto n^{-2/3}$$

showing how quickly the histogram approximation approaches the true distribution as the number of samples increases.

## Terrell–Scott rule {#Terrell–Scott_rule}

Another approach developed by Terrell and Scott[^o8] is based on the observation that, among all densities $g(x)$ defined on a [compact interval](wikipedia://en/381013#Compact_support), say $|x| < 1/2$, with derivatives which are [absolutely continuous](wikipedia://en/252670), the density which minimises $\int_{\infty}^{\infty} dx (g^{(k)}(x))^2$ is

$$f_k(x) = \begin{cases} \frac{(2k+1)!}{2^{2k}(k!)^2}(1-4x^2)^k, \quad &|x|\leq1/2\\ 0 &|x|>1/2 \end{cases}$$

Using this with $k=1$ in the expression for $h^*$ gives an [upper bound](wikipedia://en/42693) on the value of bin width which is

$$h^*_{TS} = \left( \frac{4}{n} \right)^{1/3}.$$

So, for functions satisfying the continuity conditions, at least

$$k_{TS} = \frac{b-a}{h^*} = \left( 2n \right)^{1/3}$$

bins should be used.[^o9]

*Image: Histogram rules.png.* 10000 samples from a normal distribution binned using different rules. The Scott rule uses 48 bins, the Terrell-Scott rule uses 28 and [Sturges's rule](wikipedia://en/76658532) 15.

This rule is also called the *oversmoothed rule*[^o9] or the *Rice rule*,[^o10] so called because both authors worked at [Rice University](https://en.wikipedia.org/wiki/Rice_University). The Rice rule is often reported with the factor of 2 outside the [cube root](wikipedia://en/292506), $2\left(n \right)^{1/3}$, and may be considered a different rule. The key difference from Scott's rule is that this rule does not assume the data is normally distributed and the bin width only depends on the number of samples, not on any properties of the data.

In general $\left( 2n \right)^{1/3}$ is not an [integer](wikipedia://en/14563) so $\lceil \left( 2n \right)^{1/3} \rceil$ is used where $\lceil \cdot \rceil$ denotes the [ceiling function](wikipedia://en/54267).
