# Semi-invariant of a quiver

::: {#o1 .subject cue=lead name="Semi-invariant of a quiver"}

In [mathematics](wikipedia://en/18831), the ring of **semi-invariants** is a subring of the coordinate ring of a quiver that containing those functions which are [invariant](wikipedia://en/363762) under the action of a certain [algebraic group](wikipedia://en/247924), up to a [character](wikipedia://en/691741) of that group. Specifically, given a [representation of a quiver](wikipedia://en/355100#Representations_of_quivers) with vertices *Q*<sub>0</sub>, there is a natural action of the algebraic group Π<sub>*i*∈*Q*<sub>0</sub></sub> GL(**d**(*i*)) by simultaneous base change. Such an action induces an action on the ring of functions. The functions which are invariant up to a character of the group are called **semi-invariants**. They form a ring whose structure reflects [representation-theoretical](wikipedia://en/19378200) properties of the quiver.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let *Q* = (*Q*<sub>0</sub>,*Q*<sub>1</sub>,*s*,*t*) be a [quiver](wikipedia://en/355100). Consider a dimension vector **d**, that is an element in $\mathbb{N}$<sup>*Q*<sub>0</sub></sup>. The set of **d**-dimensional representations is given by

$$\operatorname{Rep}(Q,\mathbf{d}):=\{V\in \operatorname{Rep}(Q) : V_i = \mathbf{d}(i)\}$$

Once fixed bases for each vector space *V*<sub>*i*</sub> this can be identified with the vector space

$$\bigoplus_{\alpha\in Q_1} \operatorname{Hom}_k(k^{\mathbf{d}(s(\alpha))}, k^{\mathbf{d}(t(\alpha))})$$

Such affine variety is endowed with an action of the algebraic group GL(**d**) := Π<sub>*i*∈*Q*<sub>0</sub></sub> GL(**d**(*i*)) by simultaneous base change on each vertex:

$$\begin{array}{ccc} GL(\mathbf{d}) \times \operatorname{Rep}(Q,\mathbf{d}) & \longrightarrow & \operatorname{Rep}(Q,\mathbf{d})\\ \Big((g_i), (V_i, V(\alpha))\Big) & \longmapsto & (V_i,g_{t(\alpha)}\cdot V(\alpha)\cdot g_{s(\alpha)}^{-1} ) \end{array}$$

By definition two modules *M*,*N* ∈ Rep(*Q*,**d**) are [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) if and only if their GL(**d**)-orbits coincide.

We have an induced action on the coordinate ring *k*\[Rep(*Q*,**d**)\] by defining:

$$\begin{array}{ccc} GL(\mathbf{d}) \times k[\operatorname{Rep}(Q,\mathbf{d})] & \longrightarrow & k[\operatorname{Rep}(Q,\mathbf{d})]\\ (g, f) & \longmapsto & g\cdot f(-):=f(g^{-1}. -) \end{array}$$

### Polynomial invariants {#Polynomial_invariants}

An element *f* ∈ *k*\[Rep(Q,**d**)\] is called an invariant (with respect to GL(**d**)) if *g*⋅*f* = *f* for any *g* ∈ GL(**d**). The set of invariants

$$I(Q,\mathbf{d}):=k[\operatorname{Rep}(Q,\mathbf{d})]^{GL(\mathbf{d})}$$

is in general a subalgebra of *k*\[Rep(*Q*,**d**)\].

::: {#o6 .example cue=heading name="Example"}

#### Example {#Example}

Consider the 1-loop quiver *Q*:

*Image: 1-loop quiver.svg.* 1-loop quiver

For **d** = (*n*) the representation space is End(*k*<sup>*n*</sup>) and the action of GL(*n*) is given by usual conjugation. The invariant ring is

$$I(Q,\mathbf{d})=k[c_1,\ldots,c_n]$$

where the *c*<sub>*i*</sub>s are defined, for any *A* ∈ End(*k*<sup>*n*</sup>), as the coefficients of the characteristic polynomial

$$\det(A-t \mathbb{I})=t^n-c_1(A)t^{n-1}+\cdots+(-1)^n c_n(A)$$

:::

### Semi-invariants {#Semi-invariants}

In case *Q* has neither loops nor cycles, the variety *k*\[Rep(*Q*,**d**)\] has a unique closed orbit corresponding to the unique **d**-dimensional semi-simple representation, therefore any invariant function is constant.

Elements which are invariants with respect to the [subgroup](wikipedia://en/28011) SL(**d**) := Π<sub>*i*∈*Q*<sub>0</sub></sub> SL(**d**(*i*)) form a ring, SI(*Q*,**d**), with a richer structure called ring of semi-invariants. It decomposes as

$$SI(Q,\mathbf{d})=\bigoplus_{\sigma\in \mathbb{Z}^{Q_0}} SI(Q,\mathbf{d})_{\sigma}$$

where

$$SI(Q,\mathbf{d})_{\sigma}:= \{f\in k[\operatorname{Rep}(Q,\mathbf{d})] : g\cdot f = \prod_{i\in Q_0}\det(g_i)^{\sigma_i} f, \forall g\in GL(\mathbf{d})\}.$$

A function belonging to SI(*Q*,**d**)<sub>*σ*</sub> is called semi-invariant of weight *σ*.

::: {#o9 .example cue=heading name="Example"}

#### Example {#Example}

Consider the quiver *Q*:

$$1 \xrightarrow{\ \ \alpha\ } 2$$

Fix **d** = (*n*,*n*). In this case *k*\[Rep(*Q*,(*n*,*n*))\] is congruent to the set of *n*-by-*n* [matrices](wikipedia://en/20556859): *M*(*n*). The function defined, for any *B* ∈ *M*(*n*), as det<sup>*u*</sup>(*B*(*α*)) is a semi-invariant of weight (*u*,−*u*) in fact

$$(g_1,g_2)\cdot {\det}^u (B) = {\det}^u(g_2^{-1}B g_1)= {\det}^u(g_1) {\det}^{-u}(g_2) {\det}^u(B)$$

The ring of semi-invariants equals the polynomial ring generated by det, i.e.

$$\mathsf{SI}(Q,\mathbf{d})=k[\det]$$

:::

:::

## Characterization of representation type through semi-invariant theory {#Characterization_of_representation_type_through_semi-invariant_theory}

For quivers of finite representation-type, that is to say [Dynkin quivers](wikipedia://en/277109#Finite_Dynkin_diagrams), the vector space *k*\[Rep(*Q*,**d**)\] admits an open dense orbit. In other words, it is a [prehomogenous vector space](wikipedia://en/13760785). Sato and Kimura described the ring of semi-invariants in such case.

::: {#o12 .statement kind=statement/theorem cue=named-heading name="Sato–Kimura theorem"}

### Sato–Kimura theorem {#Sato–Kimura_theorem}

Let *Q* be a [Dynkin quiver](wikipedia://en/277109#Finite_Dynkin_diagrams), **d** a dimension vector. Let Σ be the set of weights σ such that there exists *f*<sub>*σ*</sub> ∈ SI(*Q*,**d**)<sub>σ</sub> non-zero and irreducible. Then the following properties hold:

1. For every weight σ we have dim<sub>*k*</sub> SI(*Q*,**d**)<sub>*σ*</sub> ≤ 1.
1. All weights in Σ are [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) over $\mathbb{Q}$.
1. SI(*Q*,**d**) is the polynomial ring generated by the *f*<sub>*σ*</sub>'s, *σ* ∈ Σ.

Furthermore, we have an interpretation for the generators of this polynomial algebra. Let *O* be the open orbit, then *k*\[Rep(*Q*,**d**)\] \\ *O* = *Z*<sub>1</sub> ∪ ... ∪ *Z*<sub>*t*</sub> where each *Z*<sub>*i*</sub> is closed and irreducible. We can assume that the *Z*<sub>*i*</sub>s are arranged in increasing order with respect to the codimension so that the first *l* have codimension one and Z<sub>i</sub> is the zero-set of the irreducible polynomial *f*<sub>1</sub>, then SI(*Q*,**d**) = *k*\[*f*<sub>1</sub>, ..., *f*<sub>l</sub>\].

::: {#o14 .example cue=heading name="Example"}

#### Example {#Example}

In the example above the action of GL(*n*,*n*) has an open orbit on *M*(*n*) consisting of [invertible matrices](wikipedia://en/217122). Then we immediately recover SI(*Q*,(*n*,*n*)) = *k*\[det\].

Skowronski–Weyman provided a geometric characterization of the class of tame quivers (i.e. [Dynkin](wikipedia://en/277109#Finite_Dynkin_diagrams) and [Euclidean quivers](wikipedia://en/277109#Affine_Dynkin_diagrams)) in terms of semi-invariants.

:::

:::

::: {#o16 .statement kind=statement/theorem cue=named-heading name="Skowronski–Weyman theorem"}

### Skowronski–Weyman theorem {#Skowronski–Weyman_theorem}

Let *Q* be a finite connected quiver. The following are equivalent:

1. *Q* is either a [Dynkin quiver](wikipedia://en/277109#Finite_Dynkin_diagrams) or a [Euclidean quiver](wikipedia://en/277109#Affine_Dynkin_diagrams).
1. For each dimension vector **d**, the algebra SI(*Q*,**d**) is complete intersection.
1. For each dimension vector **d**, the algebra SI(*Q*,**d**) is either a polynomial algebra or a hypersurface.

::: {#o18 .example cue=heading name="Example"}

#### Example {#Example}

Consider the [Euclidean quiver](wikipedia://en/277109#Affine_Dynkin_diagrams) *Q*:

*Image: 4-subspace quiver.svg.* 4-subspace quiver

Pick the dimension vector **d** = (1,1,1,1,2). An element *V* ∈ *k*\[Rep(*Q*,**d**)\] can be identified with a quadruple (*A*<sub>1</sub>, *A*<sub>2</sub>, *A*<sub>3</sub>, *A*<sub>4</sub>) of matrices in *M*(1,2). Call *D*<sub>*i*,*j*</sub> the function defined on each *V* as det(*A*<sub>*i*</sub>,*A*<sub>*j*</sub>). Such functions generate the ring of semi-invariants:

$$SI(Q,\mathbf{d})=\frac{k[D_{1,2},D_{3,4},D_{1,4},D_{2,3},D_{1,3},D_{2,4}]}{D_{1,2}D_{3,4}+D_{1,4}D_{2,3}-D_{1,3}D_{2,4}}$$

:::
