# Rayo's number

::: {#o1 .subject cue=lead name="Rayo's number"}

**Rayo's number** is a [large number](https://en.wikipedia.org/wiki/Large_number) named after Mexican philosophy professor [Agustín Rayo](wikipedia://en/69832551), who defined it during a "Big Number Duel" at the [Massachusetts Institute of Technology](https://en.wikipedia.org/wiki/Massachusetts_Institute_of_Technology) (MIT) on 26 January 2007.[^o2][^o3] At the time, it was claimed to be the largest named number, as its size vastly exceeds even other notable large numbers such as [Graham's number](wikipedia://en/234232) and [TREE(3)](wikipedia://en/3606300).[^o4][^o5]

:::

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

The definition of Rayo's number is a variation on the definition:[^o8]

> The smallest number bigger than any finite number named by an expression in any language of [first-order set theory](wikipedia://en/27553) in which the language uses only a [googol](wikipedia://en/18994679) symbols or less.

Specifically, an initial version of the definition, which was later clarified, read "The smallest number bigger than any number that can be named by an expression in the language of first-order set-theory with less than a googol (100) symbols".[^o3]

The formal definition of the number defines a predicate $\mbox{Sat}$ according to the following [second-order](wikipedia://en/341428) formula, where $[\phi]$ is a [Gödel-coded](wikipedia://en/207790) formula and $s$ is a variable assignment:[^o8]

$$\begin{aligned} \mbox{Sat}([\phi],s):= & \mbox{For all }R \ \{ \\ & \{ \mbox{for any (coded) formula } [\psi] \mbox{ and any variable assignment } t \\ & (R([\psi],t) \leftrightarrow \\ & (( [\psi] = \mbox{''}x_i \in x_j\mbox{''} \land t(x_i) \in t(x_j)) \ \lor \\ & ( [\psi] = \mbox{''}x_i = x_j\mbox{''} \land t(x_i) = t(x_j)) \ \lor \\ & ( [\psi] = \mbox{''}(\neg \theta)\mbox{''} \land \neg R([\theta],t)) \ \lor \\ & ( [\psi] = \mbox{''}(\theta \land \xi)\mbox{''} \land R([\theta],t) \land R([\xi],t)) \ \lor \\ & ( [\psi] = \mbox{''}\exists x_i \ (\theta)\mbox{'' and, for some an } x_i \mbox{-variant } t' \mbox{ of } t, R([\theta],t')) \\ & )\} \rightarrow \\ & R([\phi],s)\} \end{aligned}$$

Given this formula, Rayo's number is defined as:[^o8]

> The smallest number bigger than every finite number $m$ with the following property: there is a formula $\phi(x_1)$ in the language of first-order set-theory (as presented in the definition of $\mbox{Sat}$) with less than a googol symbols and $x_1$ as its only free variable such that: (a) there is a variable assignment $s$ assigning $m$ to $x_1$ such that $\mbox{Sat}([\phi(x_1)],s)$, and (b) for any variable assignment $t$, if $\mbox{Sat}([\phi(x_1)],t)$, then $t$ assigns $m$ to $x_1$.

:::

## Explanation {#Explanation}

Intuitively, Rayo's number is defined in a [formal language](wikipedia://en/10939), such that:

- $x_i \in x_j$ and $x_i = x_j$ are [atomic formulas](https://en.wikipedia.org/wiki/Atomic_formulas).
- If $\theta$ is a formula, then $(\neg\theta)$ is a formula (the [negation](wikipedia://en/161019) of $\theta$).
- If $\theta$ and $\xi$ are formulas, then $(\theta \land \xi)$ is a formula (the [conjunction](wikipedia://en/18152) of $\theta$ and $\xi$).
- If $\theta$ is a formula, then $\exists x_i(\theta)$ is a formula ([existential quantification](wikipedia://en/91420)).

It is not allowed to eliminate parentheses. For instance, one must write $\exists x_i((\neg \theta))$ instead of $\exists x_i(\neg \theta)$.

It is possible to express the missing [logical connectives](https://en.wikipedia.org/wiki/Logical_connectives) in this language. For instance:

- [Disjunction](wikipedia://en/7962): $(\theta \lor \xi)$ as $(\neg((\neg \theta)\land(\neg \xi)))$.
- [Implication](wikipedia://en/658808): $(\theta \Rightarrow \xi)$ as $(\neg(\theta \land(\neg \xi)))$.
- [Biconditional](https://en.wikipedia.org/wiki/Biconditional): $(\theta \Leftrightarrow \xi)$ as $(\neg((\neg(\theta \land \xi))\land(\neg((\neg \theta) \land (\neg \xi)))))$.
- [Universal quantification](wikipedia://en/76174): $\forall x_i(\theta)$ as $(\neg \exists x_i((\neg \theta)))$.

The definition concerns formulas in this language that have only one [free variable](https://en.wikipedia.org/wiki/Free_variable), specifically $x_1$. If a formula with length $n$ is satisfied [iff](https://en.wikipedia.org/wiki/Iff) $x_1$ is equal to the finite [von Neumann ordinal](https://en.wikipedia.org/wiki/Von_Neumann_ordinal) $k$, we say such a formula is a "Rayo string" for $k$, and that $k$ is "Rayo-nameable" in $n$ symbols. Then, $\mbox{Rayo}(10^{100})$ is defined as the smallest $k$ greater than all numbers Rayo-nameable in at most $(10^{100})$ symbols.

Rayo notes that mathematicians working with a nonrealist philosophy of math may reject Rayo's number as being well-defined, because any [computably enumerable](wikipedia://en/332090) axiomatization of the language of second-order logic will have non-isomorphic [models](wikipedia://en/4055928), under which Rayo's number could correspond to different values.[^o8]
