# World Programming System

::: {#o2 .subject cue=lead name="World Programming System"}

The **World Programming System**, also known as **WPS Analytics** or **WPS**, is a software product developed by a company called [World Programming](https://en.wikipedia.org/wiki/World_Programming) (acquired by [Altair Engineering](https://en.wikipedia.org/wiki/Altair_Engineering)).

:::

WPS Analytics supports users of mixed ability to access and process data and to perform [data science](wikipedia://en/35458904) tasks. It has interactive [visual programming](https://en.wikipedia.org/wiki/Visual_programming) tools using data workflows, and it has [coding](https://en.wikipedia.org/wiki/Computer_programming) tools supporting the use of the [SAS language](wikipedia://en/19060492) mixed with [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [R](wikipedia://en/376707) and [SQL](wikipedia://en/29004).[^o3]

## About {#About}

WPS can use programs written in the [language of SAS](wikipedia://en/19060492) without the need for translating them into any other language. In this regard WPS is compatible with the SAS system. WPS has a built-in language interpreter able to process the language of SAS and produce similar results.[^o5]

WPS is available to run on [z/OS](https://en.wikipedia.org/wiki/Z/OS), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), [Linux](https://en.wikipedia.org/wiki/Linux) ([x86](https://en.wikipedia.org/wiki/X86), [Armv8 64-bit](https://en.wikipedia.org/wiki/AArch64), [IBM Power LE](https://en.wikipedia.org/wiki/PowerLinux), [IBM Z](https://en.wikipedia.org/wiki/Linux_on_IBM_Z)), and [AIX](https://en.wikipedia.org/wiki/IBM_AIX).[^o6]

On all supported platforms, programs written in the language of SAS can be executed from a WPS command line interface, often referred to as running in batch mode.[^o7]

WPS can also be used from a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) known as the **WPS Workbench** for managing, editing and running programs written in the language of SAS. The WPS Workbench user interface is based on [Eclipse](https://en.wikipedia.org/wiki/Eclipse_%28software%29).[^o8]

WPS version 4 (released in March 2018) introduced a drag-and-drop workflow canvas providing interactive blocks for data retrieval, blending and preparation, data discovery and profiling, predictive modelling powered by machine learning algorithms, model performance validation and scorecards.

WPS version 3 (released in February 2012) provided a new client/server architecture that allows the WPS Workbench GUI to execute SAS programs on remote server installations of WPS in a network or cloud. The resulting output, data sets, logs, etc., can then all be viewed and manipulated from inside the Workbench as if the workloads had been executed locally. SAS programs do not require any special language statements to use this feature.[^o9]

## Summary of main features {#Summary_of_main_features}

- Runs on [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), [z/OS](https://en.wikipedia.org/wiki/Z/OS), [Linux](https://en.wikipedia.org/wiki/Linux) ([x86](https://en.wikipedia.org/wiki/X86), [Armv8 64-bit](https://en.wikipedia.org/wiki/AArch64), [IBM Power LE](https://en.wikipedia.org/wiki/PowerLinux), [IBM Z](https://en.wikipedia.org/wiki/Linux_on_IBM_Z)), and [AIX](https://en.wikipedia.org/wiki/IBM_AIX)[^o6]
- An [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) based on [Eclipse](https://en.wikipedia.org/wiki/Eclipse_%28software%29) for Linux, macOS and Windows.[^o8]
- Support for language of SAS elements.[^o11]
- Support for the language of SAS Macros.[^o12]
- Matrix Programming support using PROC IML.[^o13]
- Support for generating band plots, bar charts, box plots, bubble plots, contour plots, dendrogram plots, ellipse plots, fringe plots, heat maps, high-low plots, histograms, loess plots, needle plots, pie charts, penalised b-spline, radar charts, reference lines, scatter plots, series plots, step plots, regression plots and vector plots.[^o14]
- Support for statistical procedures ACECLUS, ASSOCRULES, ANOVA, BIN, BOXPLOT, CANCORR, CANDISC, CLUSTER, CORRESP, DISCRIM, DISTANCE, FACTOR, FASTCLUS, FREQ, GAM, GANNO, GENMOD, GLIMMIX, GLM, GLMMOD, GLMSELECT, ICLIFETEST, KDE, LIFEREG, LIFETEST, LOESS, LOGISTIC, MDS, MEANS, MI, MIANALYSE, MIXED, MODECLUS, NESTED, NLIN, NPAR1WAY, PHREG, PLAN, PLS, POWER, PRINCOMP, PROBIT, QUANTREG, RBF, REG, ROBUSTREG, RSREG, SCORE, SEGMENT, SIMNORMAL, STANDARD, STDSIZE, STDRATE, STEPDISC, SUMMARY, SURVEYMEANS, SURVEYSELECT, TPSPLINE, TRANSREG, TREE, TTEST, UNIVARIATE, VARCLUS, VARCOMP[^o15]
- Support for time series procedures ARIMA, AUTOREG, ESM, EXPAND, FORECAST, LOAN, SEVERITY, SPECTRA, TIMESERIES, X12[^o16]
- Support for machine learning procedures DECISIONFOREST, DECISIONTREE, GMM, MLP, OPTIMALBIN, SEGMENT, SVM[^o17]
- Support for ODS.[^o12]
- Reads and writes SAS datasets ([compressed](wikipedia://en/8013) or uncompressed).[^o12]
- Access: Actian Matrix (previously known as [ParAccel](https://en.wikipedia.org/wiki/ParAccel)), [DASD](https://en.wikipedia.org/wiki/Direct_access_storage_device), [DB2](https://en.wikipedia.org/wiki/IBM_DB2), [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [Greenplum](https://en.wikipedia.org/wiki/Greenplum), [Hadoop](https://en.wikipedia.org/wiki/Apache_Hadoop), [Informix](https://en.wikipedia.org/wiki/IBM_Informix), [Kognitio](http://www.kognitio.com/analyticalplatform) (2012-08-24). <https://web.archive.org/web/20120824044739/http://www.kognitio.com/analyticalplatform>, [MariaDB](https://en.wikipedia.org/wiki/MariaDB), [MySQL](https://en.wikipedia.org/wiki/MySQL), [Netezza](https://en.wikipedia.org/wiki/Netezza), [ODBC](https://en.wikipedia.org/wiki/Open_Database_Connectivity), [OLEDB](https://en.wikipedia.org/wiki/OLE_DB), [Oracle](https://en.wikipedia.org/wiki/Oracle_Database), [PostgreSQL](https://en.wikipedia.org/wiki/PostgreSQL), [SAND](https://en.wikipedia.org/wiki/SAND_CDBMS), [Snowflake](https://en.wikipedia.org/wiki/Snowflake_Inc), [SPSS](wikipedia://en/179088)/[PSPP](wikipedia://en/16653967), [SQL Server](https://en.wikipedia.org/wiki/Microsoft_SQL_Server), [Sybase](https://en.wikipedia.org/wiki/Sybase), [Sybase IQ](https://en.wikipedia.org/wiki/Sybase_IQ), [Teradata](wikipedia://en/168680), [VSAM](https://en.wikipedia.org/wiki/Virtual_storage_access_method), [Vertica](https://en.wikipedia.org/wiki/Vertica) and [XML](https://en.wikipedia.org/wiki/XML).[^o18]
- Support for SAS Tape Format.[^o12]
- Direct output of reports to [CSV](https://en.wikipedia.org/wiki/Comma-separated_values), [PDF](https://en.wikipedia.org/wiki/PDF) and [HTML](https://en.wikipedia.org/wiki/HTML).[^o12]
- Support to connect WPS systems programmatically, remote submit parts of a program to execute on connected remote servers, upload and download data between the connected systems.[^o19]
- Support for [Hadoop](https://en.wikipedia.org/wiki/Apache_Hadoop)[^o20]
- Support for [R](wikipedia://en/376707)[^o21]
- Support for [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29)[^o22]

## Lawsuit {#Lawsuit}

In 2010 World Programming defended its use of the language of SAS in the High Court of England and Wales in *[SAS Institute Inc. v World Programming Ltd](https://en.wikipedia.org/wiki/SAS_Institute_Inc._v_World_Programming_Ltd)*.[^o26]

The software was the subject of [a lawsuit by SAS Institute](https://en.wikipedia.org/wiki/SAS_Institute_Inc_v_World_Programming_Ltd). The [EU Court of Justice](https://en.wikipedia.org/wiki/European_Court_of_Justice) ruled in favor of World Programming, stating that the copyright protection does not extend to the software functionality, the programming language used and the format of the data files used by the program. It stated that there is no copyright infringement when a company which does not have access to the source code of a program studies, observes and tests that program to create another program with the same functionality.[^o27]
