# Analyse-it

::: {#o2 .subject cue=lead name="Analyse-it"}

**Analyse-it** is a statistical analysis add-in for [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel). Analyse-it is the successor to Astute, developed in 1992 for Excel 4 and the first statistical analysis add-in for Microsoft Excel. Analyse-it provides a range of standard parametric and [non-parametric](https://en.wikipedia.org/wiki/Non-parametric) procedures, including [Descriptive statistics](wikipedia://en/8187), [ANOVA](https://en.wikipedia.org/wiki/ANOVA), [ANCOVA](https://en.wikipedia.org/wiki/ANCOVA), [Mann–Whitney](https://en.wikipedia.org/wiki/Mann–Whitney), [Wilcoxon](https://en.wikipedia.org/wiki/Wilcoxon), [chi-square](wikipedia://en/113424), [correlation](wikipedia://en/157057), [linear regression](wikipedia://en/48758386), [logistic regression](wikipedia://en/226631), [polynomial regression](wikipedia://en/21893202) and advanced model fitting, [principal component analysis](wikipedia://en/76340), and [factor analysis](wikipedia://en/253492).

:::

**Analyse-it Method Validation edition** provides the standard Analyse-it statistical analyses above, plus procedures for method evaluation, validation and demonstration, including [Bland–Altman bias plots](wikipedia://en/3146632), [Linear regression](wikipedia://en/48758386), Weighted Linear regression, [Deming regression](wikipedia://en/251549), Weighted Deming regression and [Passing Bablok](https://en.wikipedia.org/wiki/Passing_Bablok) for method comparison, Precision, Linearity, Detection limits, Reference intervals and [Receiver operating characteristic](wikipedia://en/922505) analysis supporting Delong, Delong Clarke-Pearson comparisons.(see references below). Version 4.00 added support for [CLSI](https://en.wikipedia.org/wiki/Clinical_and_Laboratory_Standards_Institute) guidelines EP05, EP06, EP09, EP10, EP12, EP15, EP17, EP21, EP24 (formerly GP10-A), and EP28 (formerly C28-A3C).

**Analyse-it Medical edition** provides the standard Analyse-it statistical analyses above, plus [Bland–Altman bias plots](wikipedia://en/3146632), Reference intervals and [Receiver operating characteristic](wikipedia://en/922505) analysis supporting Delong, Delong Clarke-Pearson comparisons.(see references below).

**Analyse-it Quality Control & Improvement edition** provides the standard Analyse-it statistical analyses above, plus procedures for [statistical process control](wikipedia://en/593680), including Shewhart, Levey-Jennings, CUSUM, and EWMA [control charts](wikipedia://en/435754), [process capability analysis](wikipedia://en/2731314), and [pareto analysis](wikipedia://en/4060171).

Analyse-it is compatible with Microsoft Excel 365 and 2013 onwards (both 32- and 64-bit versions).
