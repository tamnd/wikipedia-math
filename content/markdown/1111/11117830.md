# Quasi-bipartite graph

::: {#o1 .subject cue=lead name="Quasi-bipartite graph"}

In the [mathematical](wikipedia://en/18831) field of [graph theory](wikipedia://en/12401), an instance of the [Steiner tree problem](wikipedia://en/498304) (consisting of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) *G* and a set *R* of terminal vertices that must be connected to each other) is said to be **quasi-bipartite** if the non-terminal vertices in *G* form an [independent set](wikipedia://en/524501), i.e. if every edge is incident on at least one terminal. This generalizes the concept of a [bipartite graph](wikipedia://en/244431): if *G* is bipartite, and *R* is the set of vertices on one side of the bipartition, the set *R* is automatically independent.

:::

*Image: Quasi-bipartite.png.* The first graph has non-terminal points which are directly connected, and is therefore non-quasi-bipartite. The second has no non-terminal points which are directly connected, and is therefore quasi-bipartite.

This concept was introduced by Rajagopalan and Vazirani [^o2] who used it to provide a (3/2 + ε) [approximation algorithm](wikipedia://en/563105) for the Steiner tree problem on such instances. Subsequently, the ε factor was removed by Rizzi[^o3] and a 4/3 [approximation algorithm](wikipedia://en/563105) was obtained by Chakrabarty et al.[^o4] The same concept has been used by subsequent authors on the Steiner tree problem, e.g.[^o5] Robins and Zelikovsky[^o6] proposed an [approximation algorithm](wikipedia://en/563105) for Steiner tree problem which on quasi-bipartite graphs has [approximation ratio](https://en.wikipedia.org/wiki/Approximation_ratio) 1.28. The complexity of Robins and Zelikovsky's algorithm is *O(*mn<sup>2</sup>*)*, where *m* and *n* are the numbers of terminals and non-terminals in the graph, respectively. In 2012, Goemans et al.[^o7] gave a 73/60 ≈ 1.217-approximation algorithm for the Steiner tree problem on quasi-bipartite graphs; an algorithm achieving the same approximation factor was previously known for the special case of quasi-bipartite graphs with unit cost edges.[^o8]
