# Primary extension

::: {#o1 .subject cue=lead name="Primary extension"}

In [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29), a branch of algebra, a **primary extension** *L* of *K* is a [field extension](wikipedia://en/11634) such that the algebraic closure of *K* in *L* is [purely inseparable](https://en.wikipedia.org/wiki/Purely_inseparable) over *K*.[^o2]

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- An extension *L*/*K* is primary if and only if it is [linearly disjoint](https://en.wikipedia.org/wiki/Linearly_disjoint) from the [separable closure](https://en.wikipedia.org/wiki/Separable_closure) of *K* over *K*.[^o2]
- A subextension of a primary extension is primary.[^o2]
- A primary extension of a primary extension is primary (transitivity).[^o2]
- Any extension of a [separably closed field](https://en.wikipedia.org/wiki/Separably_closed_field) is primary.[^o2]
- An extension is [regular](wikipedia://en/26047190) if and only if it is separable and primary.[^o2]
- A primary extension of a [perfect field](wikipedia://en/505088) is [regular](wikipedia://en/26047190).

:::
