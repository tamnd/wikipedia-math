# OMEMO

*Image: OMEMO logo.svg.* Logo of OMEMO

::: {#o1 .subject cue=lead name="OMEMO"}

**OMEMO** is an extension to the Extensible Messaging and Presence Protocol ([XMPP](https://en.wikipedia.org/wiki/XMPP)) for multi-client [end-to-end encryption](wikipedia://en/1065362) developed by [Andreas Straub](https://en.wikipedia.org/wiki/Andreas_Straub). According to Straub, OMEMO uses the [Double Ratchet Algorithm](wikipedia://en/49111333) "to provide multi-end to multi-end encryption, allowing messages to be synchronized securely across multiple clients, even if some of them are offline".[^o28] The name "OMEMO" is a [recursive acronym](https://en.wikipedia.org/wiki/Recursive_acronym) for "OMEMO Multi-End Message and Object Encryption". It is an open standard based on the Double Ratchet Algorithm and the [Personal Eventing Protocol](https://en.wikipedia.org/wiki/Personal_Eventing_Protocol) (PEP, XEP-0163).[^o24] OMEMO offers future and [forward secrecy](wikipedia://en/2191130) and deniability with message synchronization and offline delivery.

:::

## Features {#Features}

In comparison with [OTR](https://en.wikipedia.org/wiki/Off-the-Record_Messaging), the OMEMO protocol offers many-to-many encrypted chat, offline messages queuing, forward secrecy, file transfer, verifiability and deniability at the cost of slightly larger message size overhead.[^o3]

## History {#History}

The protocol was developed and first implemented by Andreas Straub as a [Google Summer of Code](https://en.wikipedia.org/wiki/Google_Summer_of_Code) project in 2015. The project's goal was to implement a double-ratchet-based multi-end to multi-end encryption scheme into an Android XMPP-based instant messaging client called [Conversations](https://en.wikipedia.org/wiki/Conversations_%28software%29). It was introduced in Conversations and submitted to the [XMPP Standards Foundation](https://en.wikipedia.org/wiki/XMPP_Standards_Foundation) (XSF) as a proposed [XMPP Extension Protocol](https://en.wikipedia.org/wiki/XMPP_Extension_Protocol) (XEP) in the autumn of 2015 and got accepted as [XEP-0384](https://xmpp.org/extensions/xep-0384.html) in December 2016.[^o28]

In July 2016, the [ChatSecure](wikipedia://en/41518933) project announced that they would implement OMEMO in the next releases. ChatSecure v4.0 supports OMEMO and was released on January 17, 2017.[^o5][^o6]

A first experimental release of an OMEMO plugin for the cross-platform XMPP client [Gajim](https://en.wikipedia.org/wiki/Gajim) was made available on December 26, 2015.[^o25]

In June 2016, the non-profit computer security consultancy firm Radically Open Security published an analysis of the OMEMO protocol.[^o7]

## Client support {#Client_support}

Selected clients supporting OMEMO (full list of clients also exists[^o9]):

- [BeagleIM](https://beagle.im/) ([macOS](https://en.wikipedia.org/wiki/MacOS))[^o10]
- [ChatSecure](wikipedia://en/41518933) ([iOS](https://en.wikipedia.org/wiki/IOS))[^o11]
- [Conversations](https://en.wikipedia.org/wiki/Conversations_%28software%29) ([Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29))
- [Converse.js](https://conversejs.org/) ([Browser](https://en.wikipedia.org/wiki/Web_browser)-based)[^o12]
- [Dino](https://dino.im/) ([Linux](https://en.wikipedia.org/wiki/Linux), [macOS](https://en.wikipedia.org/wiki/MacOS))[^o13]
- [Gajim](https://en.wikipedia.org/wiki/Gajim) ([Linux](https://en.wikipedia.org/wiki/Linux), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [BSD](https://en.wikipedia.org/wiki/Berkeley_Software_Distribution))[^o26][^o14]
- [Kaidan](https://kaidan.im/) ([Linux](https://en.wikipedia.org/wiki/Linux))[^o15]
- [Movim](https://en.wikipedia.org/wiki/Movim) ([Browser](https://en.wikipedia.org/wiki/Web_browser)-based)[^o16]
- [Psi/Psi+](https://en.wikipedia.org/wiki/Psi_%28instant_messaging_client%29) via official plugin ([Linux](https://en.wikipedia.org/wiki/Linux), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), [Haiku](https://en.wikipedia.org/wiki/Haiku_%28operating_system%29), [FreeBSD](https://en.wikipedia.org/wiki/FreeBSD))[^o27]
- [libpurple](https://en.wikipedia.org/wiki/Libpurple) clients such as [Pidgin](wikipedia://en/188211) or Finch via experimental plugin [^o30]
- [Adium](https://en.wikipedia.org/wiki/Adium) via an Xtra based on the libpurple plugin[^o31]
- [Profanity](https://en.wikipedia.org/wiki/Profanity_%28instant_messaging_client%29) via experimental plugin ([BSD](https://en.wikipedia.org/wiki/Berkeley_Software_Distribution), [Linux](https://en.wikipedia.org/wiki/Linux), [macOS](https://en.wikipedia.org/wiki/MacOS), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows))[^o29]
- [SiskinIM](https://siskin.im/) ([iOS](https://en.wikipedia.org/wiki/IOS))[^o17]

## Library support {#Library_support}

- Smack supports OMEMO using the two modules smack-omemo and smack-omemo-signal[^o19]
- XMPPFramework ([macOS](https://en.wikipedia.org/wiki/MacOS), [iOS](https://en.wikipedia.org/wiki/IOS), [tvOS](https://en.wikipedia.org/wiki/TvOS)) [^o20] supports OMEMO via the OMEMOModule extension [^o21] when used in conjunction with the SignalProtocol-ObjC library.[^o22]
