# Van der Waerden number

::: {#o1 .subject cue=lead name="Van der Waerden number"}

[Van der Waerden's theorem](wikipedia://en/157178) states that for any [positive integers](https://en.wikipedia.org/wiki/Positive_integer) *r* and *k* there exists a positive integer *N* such that if the integers {1, 2, ..., *N*} are colored, each with one of *r* different colors, then there are at least *k* integers in [arithmetic progression](wikipedia://en/168389) all of the same color. The smallest such *N* is the **van der Waerden number** *W*(*r*, *k*).

:::

## Tables of Van der Waerden numbers {#Tables_of_Van_der_Waerden_numbers}

There are two cases in which the van der Waerden number *W*(*r*, *k*) is easy to compute: first, when the number of colors *r* is equal to 1, one has *W*(1, *k*) = *k* for any integer *k*, since one color produces only trivial colorings RRRRR...RRR (for the single color denoted R). Second, when the length *k* of the forced arithmetic progression is 2, one has *W*(*r*, 2) = *r* + 1, since one may construct a coloring that avoids arithmetic progressions of length 2 by using each color at most once, but using any color twice creates a length-2 arithmetic progression. (For example, for *r* = 3, the longest coloring that avoids an arithmetic progression of length 2 is RGB.) There are only seven other van der Waerden numbers that are known exactly. Some lower bound colorings computed using SAT approach by Marijn J.H. Heule [^o4] can be found on [github project page](https://github.com/marijnheule/vdWaerden).

Van der Waerden numbers with *r* ≥ 2 are bounded above by

$$W(r,k)\le 2^{2^{r^{2^{2^{k+9}}}}}$$

as proved by [Gowers](wikipedia://en/365715).[^o6]

For a [prime number](wikipedia://en/23666) *p*, the 2-color van der Waerden number is bounded below by

$$p\cdot2^p\le W(2,p+1),$$

as proved by [Berlekamp](wikipedia://en/655893).[^o7]

One sometimes also writes *w*(r; *k*<sub>1</sub>, *k*<sub>2</sub>, ..., *k*<sub>*r*</sub>) to mean the smallest number *w* such that any coloring of the integers {1, 2, ..., *w*} with *r* colors contains a progression of length *k*<sub>*i*</sub> of color *i*, for some *i*. Van der Waerden numbers are [primitive recursive](https://en.wikipedia.org/wiki/Primitive_recursive), as proved by [Shelah](wikipedia://en/331211);[^o26] in fact he proved that they are (at most) on the fifth level $\mathcal{E}^5$ of the [Grzegorczyk hierarchy](wikipedia://en/14334415).
