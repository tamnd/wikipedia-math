# E2 (cipher)

::: {#o2 .subject cue=lead name="E2"}

In [cryptography](wikipedia://en/18934432), **E2** is a [symmetric](wikipedia://en/53042) [block cipher](wikipedia://en/4594) which was created in 1998 by [NTT](https://en.wikipedia.org/wiki/Nippon_Telegraph_and_Telephone) and submitted to the [AES competition](https://en.wikipedia.org/wiki/AES_competition).

:::

Like other AES candidates, E2 operates on blocks of 128 bits, using a key of 128, 192, or 256 bits. It uses a 12-round [Feistel network](wikipedia://en/352709). E2 has an input transformation and output transformation that both use [modular multiplication](wikipedia://en/20087), but the round function itself consists only of [XORs](https://en.wikipedia.org/wiki/XOR) and [S-box](https://en.wikipedia.org/wiki/Substitution_box) lookups. The single 8×8-bit S-box is constructed from the composition of an [affine transformation](wikipedia://en/38449) with the discrete [exponentiation](wikipedia://en/99491) x<sup>127</sup> over the [finite field](wikipedia://en/11615) GF(2<sup>8</sup>). NTT adopted many of E2's special characteristics in [Camellia](wikipedia://en/532475), which has essentially replaced E2.
