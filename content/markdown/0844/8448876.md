# Cash–Karp method

::: {#o1 .subject cue=lead name="Cash–Karp method"}

In [numerical analysis](wikipedia://en/21506), the **Cash–Karp method** is a method for solving [ordinary differential equations](https://en.wikipedia.org/wiki/Ordinary_differential_equations) (ODEs). It was proposed by Professor Jeff R. Cash [^o2] from [Imperial College London](https://en.wikipedia.org/wiki/Imperial_College_London) and Alan H. Karp from [IBM](https://en.wikipedia.org/wiki/IBM) Scientific Center. The method is a member of the [Runge–Kutta](https://en.wikipedia.org/wiki/Runge–Kutta) family of ODE solvers. More specifically, it uses six function evaluations to calculate fourth- and fifth-order accurate solutions. The difference between these solutions is then taken to be the error of the (fourth order) solution. This error estimate is very convenient for [adaptive stepsize](https://en.wikipedia.org/wiki/Adaptive_stepsize) integration algorithms. Other similar integration methods are [Fehlberg](https://en.wikipedia.org/wiki/Fehlberg) (RKF) and [Dormand–Prince](wikipedia://en/8452422) (RKDP).

:::
