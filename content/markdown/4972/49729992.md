# Hybrid argument (cryptography)

::: {#o1 .subject cue=lead name="Hybrid argument"}

In [cryptography](wikipedia://en/18934432), the **hybrid argument** is a proof technique used to show that two distributions are [computationally indistinguishable](wikipedia://en/1467815).

:::

## History {#History}

Hybrid arguments had their origin in the papers by [Andrew Yao](https://en.wikipedia.org/wiki/Andrew_Yao) in 1982 and [Shafi Goldwasser](wikipedia://en/842178) and [Silvio Micali](https://en.wikipedia.org/wiki/Silvio_Micali) in 1983.[^o3]

## Formal description {#Formal_description}

Formally, to show two distributions *D*<sub>1</sub> and *D*<sub>2</sub> are computationally indistinguishable, we can define a sequence of *hybrid distributions* *D*<sub>1</sub> := *H*<sub>0</sub>, *H*<sub>1</sub>, ..., *H*<sub>*t*</sub> =: *D*<sub>2</sub> where *t* is polynomial in the security parameter *n*. Define the advantage of any probabilistic efficient (polynomial-bounded time) algorithm **A** as

$\mathsf{Adv}_{H_i, H_{i+1}}^{\mathsf{dist}}(\mathbf{A}) := \left|\Pr[x \stackrel{\$}{\gets} H_i : \mathbf{A}(x)=1] - \Pr[x \stackrel{\$}{\gets} H_{i+1} : \mathbf{A}(x)=1] \right|,$

where the dollar symbol (\$) denotes that we sample an element from the distribution at random.

By [triangle inequality](wikipedia://en/53941), it is clear that for any probabilistic polynomial time algorithm **A**,

$$\mathsf{Adv}_{D_1, D_2}^{\mathsf{dist}}(\mathbf{A}) \leq \sum_{i=0}^{t-1}\mathsf{Adv}_{H_i, H_{i+1}}^{\mathsf{dist}}(\mathbf{A}).$$

Thus there must exist some *k* s.t. 0 ≤ *k* \< *t(n)* and

$$\mathsf{Adv}_{H_k, H_{k+1}}^{\mathsf{dist}}(\mathbf{A}) \geq \mathsf{Adv}_{D_1, D_2}^{\mathsf{dist}}(\mathbf{A})/t(n).$$

Since *t* is polynomial-bounded, for any such algorithm **A**, if we can show that it has a fixed negligible advantage function *ε(n)* between distributions *H*<sub>*i*</sub> and *H*<sub>*i*+1</sub> for every *i*, so in particular,

$$\epsilon(n) \ge \mathsf{Adv}_{H_k, H_{k+1}}^{\mathsf{dist}}(\mathbf{A}) \geq \mathsf{Adv}_{D_1, D_2}^{\mathsf{dist}}(\mathbf{A})/t(n),$$

then it immediately follows that its advantage to distinguish the distributions *D*<sub>*1*</sub> = *H*<sub>0</sub> and *D*<sub>*2*</sub> = *H*<sub>*t*</sub> must also be negligible.

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

The hybrid argument is extensively used in cryptography. Some simple proofs using hybrid arguments are:

- If one cannot efficiently predict the next bit of the output of some number generator, then this generator is a [pseudorandom number generator](wikipedia://en/45524) (PRG).[^o7]
- We can securely expand a PRG with 1-bit output into a PRG with *n*-bit output.[^o8]
