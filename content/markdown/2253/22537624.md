# I-bundle

*Image: MobiusF.PNG.* A Möbius band is a non-orientable I-bundle. The dark line is the base for a set of transversal lines that are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to the fiber and that each touch the edge of the band twice.

*Image: Hopf\_band\_wikipedia.png.* An annulus is an orientable I-bundle. This example is embedded in 3-space with an even number of twists

*Image: MxS1.PNG.* This image represents the twisted I-bundle over the 2-torus, which is also fibered as a Möbius strip times the circle. So, this space is also a [circle bundle](wikipedia://en/2794417)

::: {#o1 .subject cue=lead name="I-bundle"}

In mathematics, an **I-bundle** is a [fiber bundle](wikipedia://en/276526) whose fiber is an [interval](wikipedia://en/49172) and whose base is a [manifold](wikipedia://en/2073470). Any kind of interval, open, closed, semi-open, semi-closed, open-bounded, compact, even [rays](https://en.wikipedia.org/wiki/Line_%28mathematics%29#Ray), can be the fiber. An I-bundle is said to be twisted if it is not trivial.

:::

Two simple examples of I-bundles are the [annulus](wikipedia://en/356158) and the [Möbius band](https://en.wikipedia.org/wiki/Möbius_band), the only two possible I-bundles over the circle $S^1$. The annulus is a trivial or untwisted bundle because it corresponds to the [Cartesian product](wikipedia://en/24104095) $S^1\times I$, and the Möbius band is a non-trivial or twisted bundle. Both bundles are [2-manifolds](https://en.wikipedia.org/wiki/2-manifold), but the annulus is an [orientable manifold](https://en.wikipedia.org/wiki/Orientable_manifold) while the Möbius band is a [non-orientable manifold](https://en.wikipedia.org/wiki/Non-orientable_manifold).

There are only two kinds of I-bundles when the base manifold is any [surface](wikipedia://en/27865) but the [Klein bottle](wikipedia://en/17412) $K$. That surface has three I-bundles: the trivial bundle $K\times I$ and two twisted bundles.

Together with the [Seifert fiber spaces](wikipedia://en/1631931), I-bundles are fundamental elementary building blocks for the description of three-dimensional spaces. These observations are simple well known facts on elementary [3-manifolds](wikipedia://en/1018257).

[Line bundles](wikipedia://en/361366) are both I-bundles and [vector bundles](wikipedia://en/276524) of rank one. When considering I-bundles, one is interested mostly in their [topological properties](wikipedia://en/1337282) and not their possible vector properties, as one might be for [line bundles](wikipedia://en/361366).
