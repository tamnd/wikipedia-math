# Loeb space

::: {#o1 .subject cue=lead name="Loeb space"}

In mathematics, a **Loeb space** is a type of [measure space](wikipedia://en/45270) introduced by (txt) using [nonstandard analysis](wikipedia://en/21708).

:::

::: {#o4 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

Loeb's construction starts with a [finitely additive](https://en.wikipedia.org/wiki/Finitely_additive) map $\nu$ from an [internal](wikipedia://en/2190765) algebra $\mathcal A$ of sets to the [nonstandard reals](wikipedia://en/51429). Define $\mu$ to be given by the standard part of $\nu$, so that $\mu$ is a finitely additive map from $\mathcal A$ to the [extended reals](wikipedia://en/51698) $\overline\mathbb R$. Even if $\mathcal A$ is a nonstandard $\sigma$[\-algebra](wikipedia://en/29586), the algebra $\mathcal A$ need not be an ordinary $\sigma$-algebra as it is not usually closed under countable unions. Instead the algebra $\mathcal A$ has the property that if a set in it is the union of a countable family of elements of $\mathcal A$, then the set is the union of a finite number of elements of the family, so in particular any finitely additive map (such as $\mu$) from $\mathcal A$ to the extended reals is automatically countably additive. Define $\mathcal M$ to be the $\sigma$-algebra generated by $\mathcal A$. Then by [Carathéodory's extension theorem](wikipedia://en/4026968) the measure $\mu$ on *$\mathcal A$* extends to a countably additive measure on $\mathcal M$, called a Loeb measure.

:::
