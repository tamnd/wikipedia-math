# 3x + 1 semigroup

::: {#o1 .subject cue=lead name="3x + 1 semigroup"}

In [algebra](wikipedia://en/18716923), the **$3x + 1$ semigroup** is a special [subsemigroup](https://en.wikipedia.org/wiki/Subsemigroup) of the multiplicative [semigroup](wikipedia://en/27799) of all positive [rational numbers](wikipedia://en/19727024).[^o2] The elements of a generating set of this semigroup are related to the sequence of numbers involved in the still open [Collatz conjecture](wikipedia://en/37895) or the "3*x* + 1 problem". The 3*x* + 1 semigroup has been used to prove a weaker form of the Collatz conjecture. In fact, it was in such context the concept of the 3*x* + 1 semigroup was introduced by H. Farkas in 2005.[^o3] Various generalizations of the 3*x* + 1 semigroup have been constructed and their properties have been investigated.[^o4]

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

The 3*x* + 1 semigroup is the multiplicative semigroup of positive rational numbers [generated](wikipedia://en/3171371) by the set

$$\{2\}\cup \left\{\frac{2k+1}{3k+2} : k\geq 0\right\}=\left\{ 2, \frac{1}{2}, \frac{3}{5}, \frac{5}{8}, \frac{7}{11},\ldots \right\}.$$

The function $T : \mathbb{Z} \to \mathbb{Z}$ as defined below is used in the "shortcut" definition of the [Collatz conjecture](wikipedia://en/37895#As_a_parity_sequence):

$$T(n)=\begin{cases} \frac{n}{2} & \text{if } n \text{ is even}\\[4px] \frac{3n+1}{2} & \text{if } n \text{ is odd}\end{cases}$$

The Collatz conjecture asserts that for each positive integer $n$, there is some iterate of $T$ with itself which maps $n$ to 1, that is, there is some integer $k$ such that $T^{(k)}(n)=1$. For example if $n=7$ then the values of $T^{(k)}(n)$ for $k = 1, 2, 3,...$ are 11, 17, 26, 13, 20, 10, 5, 8, 4, 2, 1 and $T^{(11)}(7)=1$.

The relation between the 3*x* + 1 semigroup and the Collatz conjecture is that the 3*x* + 1 semigroup is also generated by the set

$$\left\{ \dfrac{n}{T(n)} : n>0 \right\}.$$

:::

::: {#o8 .statement kind=statement/conjecture cue=named-heading name="The weak Collatz conjecture"}

## The weak Collatz conjecture {#The_weak_Collatz_conjecture}

The weak Collatz conjecture asserts the following: "The 3*x* + 1 semigroup contains every positive integer." This was formulated by Farkas and it has been proven to be true as a consequence of the following property of the 3*x* + 1 semigroup:[^o2]

The 3*x* + 1 semigroup *S* equals the set of all positive rationals $\tfrac{a}{b}$ in lowest terms having the property that *b* ≢ 0 (mod 3). In particular, *S* contains every positive integer.

:::

## The wild semigroup {#The_wild_semigroup}

The semigroup generated by the set

$$\left\{\frac{1}{2}\right\}\cup \left\{\frac{3k+2}{2k+1}:k\geq 0\right\},$$

which is also generated by the set

$$\left\{\frac{T(n)}{n}: n>0\right\},$$

is called the wild semigroup. The integers in the wild semigroup consist of all integers *m* such that *m* ≢ 0 (mod 3).[^o10]
