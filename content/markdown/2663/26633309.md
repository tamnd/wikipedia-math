# Barnes zeta function

::: {#o1 .subject cue=lead name="Barnes zeta function"}

In [mathematics](wikipedia://en/18831), a **Barnes zeta function** is a generalization of the [Riemann zeta function](wikipedia://en/25809) introduced by (txt). It is further generalized by the [Shintani zeta function](wikipedia://en/26628999).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Barnes zeta function is defined by

$$\zeta_N(s,w\mid a_1,\ldots,a_N)=\sum_{n_1,\dots,n_N\ge 0}\frac{1}{(w+n_1a_1+\cdots+n_Na_N)^s}$$

where *w* and *a*<sub>*j*</sub> have positive real part and *s* has real part greater than *N*.

It has a [meromorphic continuation](https://en.wikipedia.org/wiki/Meromorphic_continuation) to all complex *s*, whose only [singularities](https://en.wikipedia.org/wiki/Mathematical_singularity) are simple poles at *s* = 1, 2, ..., *N*. For *N* = *w* = *a*<sub>1</sub> = 1 it is the Riemann zeta function.

:::
