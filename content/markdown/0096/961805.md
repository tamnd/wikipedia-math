# Algebra of sets

::: {#o1 .subject cue=lead name="Algebra of sets"}

In [mathematics](wikipedia://en/18831), particularly in the study of [set theory](wikipedia://en/27553), **the algebra of sets** defines the properties and laws of [sets](wikipedia://en/26691), the set-theoretic [operations](wikipedia://en/4140245) of [union](wikipedia://en/47949), [intersection](wikipedia://en/23476429), and [complementation](wikipedia://en/54347) and the [relations](wikipedia://en/3931) of set [equality](wikipedia://en/90446) and set [inclusion](wikipedia://en/27631). It also provides systematic procedures for evaluating expressions and performing calculations involving these operations and relations.

:::

Any set of sets closed under the set-theoretic operations forms a [Boolean algebra](wikipedia://en/3959) with the [join](wikipedia://en/3956618) operator being union, the [meet](wikipedia://en/3956618) operator being intersection, the complement operator being set complement,[^n1] the bottom being $\varnothing$ and the top being the [universe](wikipedia://en/296838) set under consideration.

## Fundamentals {#Fundamentals}

A [set](wikipedia://en/26691) is a collection of many [mathematical objects](https://en.wikipedia.org/wiki/Mathematical_objects). Examples of such objects are [numbers](wikipedia://en/21690), symbols, [points in space](wikipedia://en/593693), [lines](wikipedia://en/946975), other [geometric shapes](https://en.wikipedia.org/wiki/Geometric_shape), [variables](wikipedia://en/3728109), [functions](wikipedia://en/185427), or even other sets.[^n2] A set is usually denote a upper-case letter and [curly braces](https://en.wikipedia.org/wiki/Curly_braces), as in $A = \{1,2,3,4\}$ and $B = \{a,b,c,x,y,z\}$.

### Union and intersection {#Union_and_intersection}

The algebra of sets studies the properties and laws of sets algebraically. Foundationally, there are two set-theoretic operations: [union](wikipedia://en/47949) ($\cup$) and [intersection](wikipedia://en/23476429) ($\cap$). A union is a set-theoretic operation that collects all members of two or more sets into a single set. An intersection collects the common elements of two or more sets. For instance, let $A = \{1,2,3,5\}$ and $B = \{2,4,6\}$. Then $A \cup B = \{1,2,3,4,5,6\}$, $A \cap B = \{2\}$. Analogically, the algebra of sets can be interpreted as the algebra of numbers. Just as arithmetic [addition](wikipedia://en/61338) and [multiplication](wikipedia://en/20845) are [associative](https://en.wikipedia.org/wiki/Associativity) and [commutative](https://en.wikipedia.org/wiki/Commutativity), so are set union and intersection.[^n3] Similarly for the arithmetic relation "less than or equal" is [reflexive](wikipedia://en/200458), [antisymmetric](wikipedia://en/1176) and [transitive](wikipedia://en/200463), so is the set relation of "subset".[^n4] Several of these identities or "laws" are the following.[^n5]

**[Commutative property](wikipedia://en/294390)**

- $$A \cup B = B \cup A$$
- $$A \cap B = B \cap A$$

**[Associative property](wikipedia://en/1335)**

- $$(A \cup B) \cup C = A \cup (B \cup C)$$
- $$(A \cap B) \cap C = A \cap (B \cap C)$$

**[Distributive property](wikipedia://en/103118)**

- $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
- $$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

The union and intersection of sets may be seen as analogous to the addition and multiplication of numbers. Like addition and multiplication, the operations of union and intersection are commutative and associative, and intersection *distributes* over union.[^n3] However, unlike addition and multiplication, union also distributes over intersection.

### Empty set, universe set, and the complement of a set {#Empty_set,_universe_set,_and_the_complement_of_a_set}

Two additional pairs of properties involve the special sets called the [empty set](wikipedia://en/9566) $\varnothing$ and the [universe set](wikipedia://en/296838) $\boldsymbol{U}$. These sets have no members, and the universe set has all possible members (in a particular context), respectively. A set where the members are not in a set $A$ is the [complement](wikipedia://en/54347); the operator denotes $A^\complement$ or $A'$ (read as "A prime"). Equivalently, the complement of a set $A^\complement$ is a set that is included in a universe set $\boldsymbol{U}$ and not in $A$; i.e., $A^\complement = \boldsymbol{U} \setminus A$.[^n6]

**Identity**

- $$A \cup \varnothing = A$$
- $$A \cap \boldsymbol{U} = A$$

**Complement**

- $$A \cup A^\complement = \boldsymbol{U}$$
- $$A \cap A^\complement = \varnothing$$

The identity expressions (together with the commutative expressions) say that, just like 0 and 1 for addition and multiplication,[^n7] $\varnothing$ and $\boldsymbol{U}$ are the [identity elements](wikipedia://en/14962) for union and intersection, respectively.

Unlike addition and multiplication, union and intersection do not have [inverse elements](wikipedia://en/45199). However, the complement laws give the fundamental properties of the somewhat inverse-like [unary operation](wikipedia://en/161006) of set complementation.

The preceding five pairs of formulae—the commutative, associative, distributive, identity, and complement formulae—encompass all of set algebra, in the sense that every valid proposition in the algebra of sets can be derived from them.

If the complement formulae are weakened to the rule $(A^\complement)^\complement = A$, then this is exactly the algebra of propositional [linear logic](wikipedia://en/579675).

::: {#o14 .statement cue=named-heading name="Principle of duality"}

## Principle of duality {#Principle_of_duality}

Each of the identities stated above is one of a pair of identities such that each can be transformed into the other by interchanging $\cup$ and $\cap$, while also interchanging $\varnothing$ and $\boldsymbol{U}$.

These are examples of an extremely important and powerful property of set algebra, namely, the **principle of duality** for sets, which asserts that for any true statement about sets, the **dual** statement obtained by interchanging unions and intersections, interchanging $\boldsymbol{U}$ and $\varnothing$ and reversing inclusions is also true. A statement is said to be **self-dual** if it is equal to its own dual.

:::

::: {#o16 .statement cue=named-heading name="Some additional laws for unions and intersections"}

## Some additional laws for unions and intersections {#Some_additional_laws_for_unions_and_intersections}

For any [subsets](wikipedia://en/27631) $A$ and $B$ of a universe set $\boldsymbol{U}$, the following identities hold:

**[idempotent](https://en.wikipedia.org/wiki/Idempotent) laws**

- $$A \cup A = A$$
- $$A \cap A = A$$

**domination laws**

- $$A \cup \boldsymbol{U} = \boldsymbol{U}$$
- $$A \cap \varnothing = \varnothing$$

**[absorption laws](wikipedia://en/286172)**

- $$A \cup (A \cap B) = A$$
- $$A \cap (A \cup B) = A$$

Intersection can be expressed in terms of set difference:

$$A \cap B = A \setminus (A \setminus B)$$

:::

::: {#o18 .statement cue=named-heading name="Some additional laws for complements"}

## Some additional laws for complements {#Some_additional_laws_for_complements}

Let $A$ and $B$ be [subsets](wikipedia://en/27631) of a universe $\boldsymbol{U}$, then:

**[de Morgan's laws](wikipedia://en/64669)**

- $$(A \cup B)^\complement = A^\complement \cap B^\complement$$
- $$(A \cap B)^\complement = A^\complement \cup B^\complement$$

**double complement or [involution](wikipedia://en/293450) law**

- $$(A^\complement)^\complement = A$$

**complement laws for the universe set and the empty set**

- $$\varnothing^\complement = \boldsymbol{U}$$
- $$\boldsymbol{U}^\complement = \varnothing$$

Notice that the double complement law is self-dual. The following is also self-dual, saying that the complement of a set is the only set that satisfies the complement laws. In other words, complementation is characterized by the complement laws: Let $A$ and $B$ be subsets of a universe $\boldsymbol{U}$,

**uniqueness of complements**

- If $A \cup B = \boldsymbol{U}$, and $A \cap B = \varnothing$, then $B = A^\complement$

:::

## Algebra of inclusion {#Algebra_of_inclusion}

The algebra of sets include the [inclusion](wikipedia://en/27631) of sets. That is, the [binary relation](wikipedia://en/3931) of one set being a subset of another, which is a [partial order](https://en.wikipedia.org/wiki/Partial_order). If $A$, $B$ and $C$ are sets then the following hold:

**[reflexivity](wikipedia://en/200458)**

- $$A \subseteq A$$

**[antisymmetry](wikipedia://en/1176)**

- $A \subseteq B$ and $B \subseteq A$ if and only if $A = B$

**[transitivity](wikipedia://en/200463)**

- If $A \subseteq B$ and $B \subseteq C$, then $A \subseteq C$

For any set $S$, the [power set](wikipedia://en/23799) of $S$, ordered by inclusion, is a [bounded lattice](wikipedia://en/469304), and hence together with the distributive and complement laws above, shows that it is a [Boolean algebra](wikipedia://en/3959). That is, if $A$, $B$ and $C$ are subsets of a set $S$ then the following hold:

**existence of a [least element](https://en.wikipedia.org/wiki/Greatest_element) and a [greatest element](https://en.wikipedia.org/wiki/Greatest_element)**

- $$\varnothing \subseteq A \subseteq S$$

**existence of [joins](wikipedia://en/469304)**

- $$A \subseteq A \cup B$$
  - If $A \subseteq C$ and $B \subseteq C$, then $A \cup B \subseteq C$

**existence of [meets](wikipedia://en/469304)**

- $$A \cap B \subseteq A$$
- If $C \subseteq A$ and $C \subseteq B$, then $C \subseteq A \cap B$

The inclusion set $A \subseteq B$ is equivalent to various other statements involving unions, intersections, and complements. That is, for any two sets $A$ and $B$, the following are equivalent:

- $$A \subseteq B$$
- $$A \cap B = A$$
- $$A \cup B = B$$
- $$A \setminus B = \varnothing$$
- $$B^\complement \subseteq A^\complement$$

This shows that the relation of set inclusion can be characterized by either of the operations of set union or set intersection, meaning that the notion of set inclusion is axiomatically superfluous.

## Algebra of relative complements {#Algebra_of_relative_complements}

The following proposition lists several identities concerning [relative complements](wikipedia://en/54347) and set-theoretic differences.

::: {#o21 .statement kind=statement/proposition cue=inline-head name="PROPOSITION 9"}

**PROPOSITION 9**: For any universe $\boldsymbol{U}$ and subsets $A$, $B$ and $C$ of $\boldsymbol{U}$, the following identities hold:

- $$C \setminus (A \cap B) = (C \setminus A) \cup (C \setminus B)$$
- $$C \setminus (A \cup B) = (C \setminus A) \cap (C \setminus B)$$
- $$C \setminus (B \setminus A) = (A \cap C)\cup(C \setminus B)$$
- $$(B \setminus A) \cap C = (B \cap C) \setminus (A \cap C) = (B \cap C) \setminus A = B \cap (C \setminus A)$$
- $$(B \setminus A) \cup C = (B \cup C) \setminus (A \setminus C)$$
- $$(B \setminus A) \setminus C = B \setminus (A \cup C)$$
- $$A \setminus A = \varnothing$$
- $$\varnothing \setminus A = \varnothing$$
- $$A \setminus \varnothing = A$$
- $$B \setminus A = A^\complement \cap B$$
- $$(B \setminus A)^\complement = A \cup B^\complement$$
- $$\boldsymbol{U} \setminus A = A^\complement$$
- $$A \setminus \boldsymbol{U} = \varnothing$$

:::
