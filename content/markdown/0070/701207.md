# Radix

::: {#o1 .subject cue=lead name="Radix"}

In a [positional numeral system](https://en.wikipedia.org/wiki/Positional_numeral_system), the **radix** (**radices**) or **base** is the number of unique [digits](wikipedia://en/280582), including the digit zero, used to represent numbers. For example, in [decimal systems](wikipedia://en/8214) (the most common systems in use today) the radix is [ten](wikipedia://en/208151).

:::

In any standard positional numeral system, a number is conventionally written as (*x*)<sub>*y*</sub> with *x* as the [string](wikipedia://en/27701) of digits and *y* as its base. For base ten, the subscript is usually assumed and omitted (together with the enclosing [parentheses](https://en.wikipedia.org/wiki/Parentheses)), as it is the most common way to express [value](wikipedia://en/4095147). For example, (100)<sub>10</sub> is equivalent to 100 (the decimal system is implied in the latter) and represents the number one hundred, while (100)<sub>2</sub> (in the [binary system](https://en.wikipedia.org/wiki/Binary_system_%28numeral%29) with base 2) represents the number four.[^o4]

Electronic [computers](https://en.wikipedia.org/wiki/Computer) process and store information in the simplest way, as [bits](https://en.wikipedia.org/wiki/Bit) of [binary](wikipedia://en/238686) code, which have a radix of 2.

## Etymology {#Etymology}

*Radix* is a Latin word for "root". *Root* can be considered a synonym for *base,* in the arithmetical sense.

## In numeral systems {#In_numeral_systems}

Generally, in a system with radix *b* (*b* > 1), a string of digits *d*<sub>1</sub> ... *d<sub>n</sub>* denotes the number *d*<sub>1</sub>*b*<sup>*n*−1</sup> + *d*<sub>2</sub>*b*<sup>*n*−2</sup> + ... + *d<sub>n</sub>b*<sup>0</sup>, where 0 ≤ *d<sub>i</sub>* \< *b*.[^o4] In contrast to decimal, or radix 10, which has a ones' place, tens' place, hundreds' place, and so on, radix *b* would have a ones' place, then a *b*<sup>1</sup>s' place, a *b*<sup>2</sup>s' place, etc.[^o5]

For example, if *b* = 12, a string of digits such as 59A (where the letter "A" represents the value of ten) would represent the value *5* × *12*<sup>*2*</sup> + *9* × *12*<sup>*1*</sup> + *10* × *12*<sup>*0*</sup> = 838 in base 10.

The octal and hexadecimal systems are often used in computing because of their ease as shorthand for binary. Every hexadecimal digit corresponds to a sequence of four binary digits, since sixteen is the fourth power of two; for example, hexadecimal 78<sub>16</sub> is binary 111<sub>2</sub>. Similarly, every octal digit corresponds to a unique sequence of three binary digits, since eight is the cube of two.

This representation is unique. Let *b* be a positive integer greater than 1. Then every positive integer *a* can be expressed uniquely in the form

$$a = r_m b^m + r_{m-1} b^{m-1} + \dotsb + r_1 b + r_0,$$

where *m* is a nonnegative integer and the *r**s are integers such that***

0 \< *r*<sub>*m*</sub> \< *b* and 0 ≤ *r*<sub>*i*</sub> \< *b* for *i* = 0, 1, ... , *m* − 1.[^o8]

Radices are usually [natural numbers](wikipedia://en/21474). However, other positional systems are possible, for example, [golden ratio base](wikipedia://en/61373) (whose [radix is a non-integer](wikipedia://en/6832938) [algebraic number](wikipedia://en/1158)),[^o9] and [negative base](wikipedia://en/10784136) (whose radix is negative).[^o10] A negative base allows the representation of negative numbers without the use of a minus sign. For example, let *b* = −10. Then a string of digits such as 19 denotes the (decimal) number 1 × (−10)<sup>1</sup> + 9 × (−10)<sup>0</sup> = −1.

## Table of bases {#Table_of_bases}

Different bases are especially used in connection with computers. The commonly used bases are 10 ([decimal](wikipedia://en/8214)), 2 ([binary](wikipedia://en/238686)), 8 ([octal](wikipedia://en/22330)), and 16 ([hexadecimal](wikipedia://en/13263)). A [byte](https://en.wikipedia.org/wiki/Byte) with 8 [bits](https://en.wikipedia.org/wiki/Bit) can represent values from 0 to 255, often expressed with [leading zeros](https://en.wikipedia.org/wiki/Leading_zero) in base 2, 8 or 16 to give the same length.[^o13]
