# Illicit minor

*Image: Venn-diagram-association-fallacy-01.svg.* An [Euler diagram](wikipedia://en/2427526) showing an illicit minor, where the set *A* is a [subset](wikipedia://en/27631) of both *B* and *C*, but *B* is not a subset of *C*.

::: {#o1 .subject cue=lead name="Illicit minor"}

**Illicit minor** is a [formal fallacy](wikipedia://en/3637937) committed in a [categorical syllogism](https://en.wikipedia.org/wiki/Categorical_syllogism) that is [invalid](wikipedia://en/21304742) because its [minor term](https://en.wikipedia.org/wiki/Minor_term) is [undistributed](https://en.wikipedia.org/wiki/Distribution_of_terms) in the [minor premise](https://en.wikipedia.org/wiki/Minor_premise).

:::

This fallacy has the following [argument form](https://en.wikipedia.org/wiki/Argument_form):

All A are B.

All A are C.

Therefore, all C are B.

*Example:*

All cats are felines.

All cats are mammals.

Therefore, all mammals are felines.

The minor term here is [mammal](https://en.wikipedia.org/wiki/Mammal), which is not distributed in the [minor premise](https://en.wikipedia.org/wiki/Minor_premise) "All cats are mammals", because this premise is only defining a property of **possibly some** mammals (i.e., that they're [cats](https://en.wikipedia.org/wiki/Cat).) However, in the conclusion "All mammals are felines", mammal *is* distributed (it is talking about **all** mammals being felines). It is shown to be false by any [mammal](https://en.wikipedia.org/wiki/Mammal) that is not a [feline](https://en.wikipedia.org/wiki/Felidae); for example, a [dog](https://en.wikipedia.org/wiki/Dog).

*Example:*

Pie is good.

Pie is unhealthy.

Thus, all good things are unhealthy.
