# Colour refinement algorithm

::: {#o1 .subject cue=lead name="Colour refinement algorithm"}

In [graph theory](wikipedia://en/12401) and [theoretical computer science](wikipedia://en/323392), the **colour refinement algorithm** also known as the **naive vertex classification**, or the **1-dimensional version of the [Weisfeiler-Leman algorithm](https://en.wikipedia.org/wiki/Weisfeiler_Leman_graph_isomorphism_test)**, is a routine used for testing whether two graphs are [isomorphic](https://en.wikipedia.org/wiki/Isomorphic_graph).[^o2] While it solves graph isomorphism on almost all graphs, there are graphs such as all regular graphs that cannot be distinguished using colour refinement.

:::

## History {#History}

The first appearance of color refinement is in Stephen H. Unger's program GIT for graph isomorphism, where it is called the Extend method.[^o4] It was described again, immediately after, in a chemistry paper.[^o5]

## Description {#Description}

The algorithm takes as an input a graph $G$ with $n$ vertices. It proceeds in iterations and in each iteration produces a new colouring of the vertices. Formally a "[colouring](wikipedia://en/426743)" is a function from the vertices of this graph into some set (of "colours"). In each iteration, we define a sequence of vertex colourings $\lambda_i$ as follows:

- $\lambda_0$ is the initial colouring. If the graph is unlabelled, the initial colouring assigns a trivial colour $\lambda_0(v)$ to each vertex $v$. If the graph is labelled, $\lambda_0$ is the label of vertex $v$.
- For all vertices $v$, we set $\lambda_{i+1}(v) = \left(\lambda_i(v), \{\{ \lambda_i(w) \mid w \text{ is a neighbor of } v\}\}\right)$.

In other words, the new colour of the vertex $v$ is the pair formed from the previous colour and the [multiset](wikipedia://en/305303) of the colours of its neighbours. This algorithm keeps refining the current colouring. At some point it stabilises, i.e., $\lambda_{i+1}(u)=\lambda_{i+1}(v)$ if and only if $\lambda_i(u)=\lambda_i(v)$. This final colouring is called the *stable colouring*.

## Graph Isomorphism {#Graph_Isomorphism}

Colour refinement can be used as a subroutine for an important [computational problem](https://en.wikipedia.org/wiki/Computational_problem): [graph isomorphism](wikipedia://en/1950766). In this problem we have as input two graphs $G, H$ and our task is to determine whether they are [isomorphic](wikipedia://en/247577). Informally, this means that the two graphs are the same up to relabelling of vertices.

To test if $G$ and $H$ are isomorphic we could try the following. Run colour refinement on both graphs. If the stable colourings produced are different we know that the two graphs are not isomorphic. However, it could be that the same stable colouring is produced despite the two graphs not being isomorphic; see below.

## Complexity {#Complexity}

It is easy to see that if colour refinement is given a $n$ vertex graph as input, a stable colouring is produced after at most $n-1$ iterations. Conversely, there exist graphs where this bound is realised.[^o9] This leads to a $O((n+m)\log n)$ implementation where $n$ is the number of vertices and $m$ the number of edges.[^o10] This complexity has been proven to be optimal under reasonable assumptions.[^o11]

## Expressivity {#Expressivity}

We say that two graphs $G$ and $H$ are *distinguished* by colour refinement if the algorithm yields a different output on $G$ as on $H$. There are simple examples of graphs that are not distinguished by colour refinement. For example, it does not distinguish a cycle of length 6 from a pair of triangles (example V.1 in [^o13]). Despite this, the algorithm is very powerful in that a [random graph](wikipedia://en/358477) will be identified by the algorithm asymptotically [almost surely](wikipedia://en/351908).[^o14] Even stronger, it has been shown that as $n$ increases, the proportion of graphs that are *not* identified by colour refinement decreases exponentially in order $n$.[^o15]

## Equivalent Characterizations {#Equivalent_Characterizations}

For two graphs $G$ and $H$ with the same number of vertices, the following conditions are equivalent:

- $G$ and $H$ are indistinguishable by colour refinement.
- The [minimum fibration bases](wikipedia://en/82556267) of $G$ and $H$ are isomorphic.
- $G$ and $H$ are [fractionally isomorphic](wikipedia://en/45170672).[^o17][^o18]
- $G$ and $H$ have a common coarsest [equitable partition](wikipedia://en/45170672#Equivalence_to_coarsest_equitable_partition).
- $G$ and $H$ have the same [universal cover](wikipedia://en/21123339#Universal_cover).[^o19]
- For all [trees](wikipedia://en/48560) $T$, there are an equal number of [homomorphisms](wikipedia://en/676328) from $T$ to $G$ as there are from $T$ to $H$.[^o20]
- $G$ and $H$ cannot be distinguished by the [two variable fragment of first order logic](wikipedia://en/43571383) with [counting](wikipedia://en/2150531).[^o21]
- Any [message passing graph neural network](https://en.wikipedia.org/wiki/Graph_neural_network#Message_passing_layers) will map $G$ and $H$ to the same output, if the input node features are the initial colours $\lambda_0$.[^o22][^o23]
- Any synchronous anonymous algorithm with broadcast/mailbox message passing in which the input depends on the color only will generate an output that depends, again, on the initial color only.[^o24]
