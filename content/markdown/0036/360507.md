# Gimel function

::: {#o1 .subject cue=lead name="Gimel function"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **gimel function** is the following function mapping [cardinal numbers](wikipedia://en/6173) to cardinal numbers:

:::

$$\gimel\colon\kappa\mapsto\kappa^{\mathrm{cf}(\kappa)}$$

where cf denotes the [cofinality](wikipedia://en/6693) function; the gimel function is used for studying the [continuum function](wikipedia://en/5488499) and the [cardinal exponentiation](wikipedia://en/6173#Cardinal_exponentiation) function. The symbol $\gimel$ is a serif form of the Hebrew letter [gimel](https://en.wikipedia.org/wiki/Gimel).

## Values of the gimel function {#Values_of_the_gimel_function}

The gimel function has the property $\gimel(\kappa)>\kappa$ for all infinite cardinals $\kappa$ by [König's theorem](https://en.wikipedia.org/wiki/König's_theorem_%28set_theory%29).

For regular cardinals $\kappa$, $\gimel(\kappa)= 2^\kappa$, and [Easton's theorem](wikipedia://en/4691250) says that very little about this function can be determined in ZFC without additional axioms. For singular $\kappa$, upper bounds for $\gimel(\kappa)$ can be found from [Shelah](wikipedia://en/331211)'s [PCF theory](https://en.wikipedia.org/wiki/PCF_theory).

::: {#o4 .statement kind=statement/conjecture cue=named-heading name="The gimel hypothesis"}

## The gimel hypothesis {#The_gimel_hypothesis}

The **gimel hypothesis** states that $\gimel(\kappa)=\max(2^{\text{cf}(\kappa)},\kappa^+)$. In essence, this means that $\gimel(\kappa)$ for singular $\kappa$ is the smallest value allowed by the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (assuming consistency).

Under this hypothesis cardinal exponentiation is simplified, though not to the extent of the [generalized continuum hypothesis](https://en.wikipedia.org/wiki/Generalized_continuum_hypothesis) (which implies the gimel hypothesis).

:::

## Reducing the exponentiation function to the gimel function {#Reducing_the_exponentiation_function_to_the_gimel_function}

(Bukovský 1965) showed that all cardinal exponentiation is determined (recursively) by the gimel function as follows.

- If $\kappa$ is an infinite regular cardinal (in particular any infinite successor) then $2^\kappa = \gimel(\kappa)$
- If $\kappa$ is infinite and singular and the continuum function is eventually constant below $\kappa$ then $2^\kappa=2^{<\kappa}$
- If $\kappa$ is a limit and the continuum function is not eventually constant below $\kappa$ then $2^\kappa=\gimel(2^{<\kappa})$

The remaining rules hold whenever $\kappa$ and $\lambda$ are both infinite:

- If $\aleph_{0} \le \kappa \le \lambda$ then $\kappa^{\lambda} = 2^{\lambda}$
- If $\mu^{\lambda} \ge \kappa$ for some $\mu < \kappa$ then $\kappa^{\lambda} = \mu^{\lambda}$
- If $\kappa > \lambda$ and $\mu^{\lambda} < \kappa$ for all $\mu < \kappa$ and $\operatorname{cf}(\kappa) \le \lambda$ then $\kappa^{\lambda} = \kappa^{\operatorname{cf}(\kappa)}$
- If $\kappa > \lambda$ and $\mu^{\lambda} < \kappa$ for all $\mu < \kappa$ and $\operatorname{cf}(\kappa) > \lambda$ then $\kappa^{\lambda} = \kappa$
