# Interval graph

::: {#o1 .subject cue=lead name="Interval graph"}

*Image: Interval graph.svg.* Seven intervals on the real line and the corresponding seven-vertex interval graph.

In [graph theory](wikipedia://en/12401), an **interval graph** is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) formed from a set of [intervals](wikipedia://en/49172) on the [real line](https://en.wikipedia.org/wiki/Real_line), with a vertex for each interval and an edge between vertices whose intervals intersect. It is the [intersection graph](wikipedia://en/7726759) of the intervals.

:::

Interval graphs are [chordal graphs](wikipedia://en/744165) and [perfect graphs](wikipedia://en/670531). They can be recognized in [linear time](https://en.wikipedia.org/wiki/Linear_time), and an optimal [graph coloring](wikipedia://en/426743) or [maximum clique](https://en.wikipedia.org/wiki/Maximum_clique) in these graphs can be found in linear time. The interval graphs include all [proper interval graphs](https://en.wikipedia.org/wiki/Proper_interval_graph), graphs defined in the same way from a set of [unit intervals](wikipedia://en/49324).

These graphs have been used to model [food webs](wikipedia://en/145772), and to study [scheduling](https://en.wikipedia.org/wiki/Scheduling) problems in which one must select a subset of tasks to be performed at non-overlapping times. Other applications include assembling contiguous subsequences in [DNA](https://en.wikipedia.org/wiki/DNA) mapping, and temporal reasoning.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An interval graph is an undirected graph $G$ formed from a family of intervals

$$S_i,\quad i=0,1,2,\dots$$

by creating one vertex $v_{i}$ for each interval $S_{i}$, and connecting two vertices $v_{i}$ and $v_{j}$ by an edge whenever the corresponding two sets have a nonempty intersection. That is, the edge set of $G$ is

$$E(G)=\{(v_i,v_j)\mid S_i\cap S_j\ne\emptyset\}.$$

It is the [intersection graph](wikipedia://en/7726759) of the intervals.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

Three independent vertices form an [asteroidal triple](https://en.wikipedia.org/wiki/AT-free_graph) (AT) in a graph if, for each two, there exists a path containing those two but no neighbor of the third. A graph is [AT-free](https://en.wikipedia.org/wiki/AT-free_graph) if it has no asteroidal triple. The earliest characterization of interval graphs seems to be the following:

- A graph is an interval graph if and only if it is [chordal](https://en.wikipedia.org/wiki/Chordal) and AT-free.[^n1]

Other characterizations:

- A graph is an interval graph if and only if its maximal [cliques](wikipedia://en/524466) can be ordered $M_1,M_2,\dots,M_k$ such that each vertex that belongs to two of these cliques also belongs to all cliques between them in the ordering. That is, for every $v\in M_i\cap M_k$ with $i<k$, it is also the case that $v\in M_j$ whenever $i<j<k$.[^o7]
- A graph is an interval graph if and only if it does not contain the [cycle graph](wikipedia://en/878962) $C_4$ as an [induced subgraph](wikipedia://en/1655188) and is the complement of a [comparability graph](wikipedia://en/6978672).[^n2]

Various other characterizations of interval graphs and variants have been described.[^o9]

:::

## Efficient recognition algorithm {#Efficient_recognition_algorithm}

Determining whether a given graph $G=(V,E)$ is an interval graph can be done in $O(|V|+|E|)$ time by seeking an ordering of the maximal cliques of $G$ that is consecutive with respect to vertex inclusion. Many of the known algorithms for this problem work in this way, although it is also possible to recognize interval graphs in linear time without using their cliques.[^n3]

The original linear time recognition algorithm of (Booth Lueker 1976) is based on their complex [PQ tree](wikipedia://en/597568) data structure, but (Habib McConnell Paul Viennot 2000) showed how to solve the problem more simply using [lexicographic breadth-first search](https://en.wikipedia.org/wiki/Lexicographic_breadth-first_search), based on the fact that a graph is an interval graph if and only if it is [chordal](wikipedia://en/744165) and its [complement](https://en.wikipedia.org/wiki/Complement_%28graph_theory%29) is a [comparability graph](wikipedia://en/6978672).[^o14] A similar approach using a 6-sweep LexBFS algorithm is described in (Corneil Olariu Stewart 2009).

## Related families of graphs {#Related_families_of_graphs}

By the characterization of interval graphs as AT-free chordal graphs,[^n1] interval graphs are [strongly chordal graphs](wikipedia://en/24809733) and hence [perfect graphs](wikipedia://en/670531). Their [complements](wikipedia://en/1175649) belong to the class of [comparability graphs](wikipedia://en/6978672),[^n2] and the comparability relations are precisely the [interval orders](wikipedia://en/11680645).[^n4]

From the fact that a graph is an interval graph if and only if it is [chordal](wikipedia://en/744165) and its [complement](https://en.wikipedia.org/wiki/Complement_%28graph_theory%29) is a [comparability graph](wikipedia://en/6978672), it follows that a graph and its complement are both interval graphs if and only if the graph is both a [split graph](wikipedia://en/9928681) and a [permutation graph](wikipedia://en/17625375).

The interval graphs that have an interval representation in which every two intervals are either disjoint or nested are the [trivially perfect graphs](wikipedia://en/18033364).

A graph has [boxicity](wikipedia://en/11167471) at most one if and only if it is an interval graph; the boxicity of an arbitrary graph $G$ is the minimum number of interval graphs on the same set of vertices such that the intersection of the edges sets of the interval graphs is $G$.

The intersection graphs of [arcs](https://en.wikipedia.org/wiki/Arc_%28geometry%29) of a [circle](wikipedia://en/6220) form [circular-arc graphs](https://en.wikipedia.org/wiki/Circular-arc_graph), a class of graphs that contains the interval graphs. The [trapezoid graphs](wikipedia://en/31675608), intersections of trapezoids whose parallel sides all lie on the same two parallel lines, are also a generalization of the interval graphs.

The connected [triangle-free](wikipedia://en/7667996) interval graphs are exactly the [caterpillar trees](wikipedia://en/27258886).[^n5]

### Proper interval graphs {#Proper_interval_graphs}

[Proper interval graphs](https://en.wikipedia.org/wiki/Proper_interval_graph) are interval graphs that have an interval representation in which no interval [properly contains](wikipedia://en/27631) any other interval; [unit interval graphs](https://en.wikipedia.org/wiki/Unit_interval_graph) are the interval graphs that have an interval representation in which each interval has unit length. A unit interval representation without repeated intervals is necessarily a proper interval representation. Not every proper interval representation is a unit interval representation, but every proper interval graph is a unit interval graph, and vice versa.[^o22] Every proper interval graph is a [claw-free graph](wikipedia://en/12415907); conversely, the proper interval graphs are exactly the claw-free interval graphs. However, there exist claw-free graphs that are not interval graphs.[^n6]

An interval graph is called $q$-proper if there is a representation in which no interval is contained by more than $q$ others. This notion extends the idea of proper interval graphs such that a 0-proper interval graph is a proper interval graph.[^n7] An interval graph is called $p$-improper if there is a representation in which no interval contains more than $p$ others. This notion extends the idea of proper interval graphs such that a 0-improper interval graph is a proper interval graph.[^n8] An interval graph is $k$-nested if there is no chain of length $k+1$ of intervals nested in each other. This is a generalization of proper interval graphs as 1-nested interval graphs are exactly proper interval graphs.[^n9]

## Applications {#Applications}

The mathematical theory of interval graphs was developed with a view towards applications by researchers at the [RAND Corporation](https://en.wikipedia.org/wiki/RAND_Corporation)'s mathematics department, which included young researchers—such as [Peter C. Fishburn](wikipedia://en/1787186) and students like [Alan C. Tucker](https://en.wikipedia.org/wiki/Alan_C._Tucker) and [Joel E. Cohen](https://en.wikipedia.org/wiki/Joel_E._Cohen)—besides leaders—such as [Delbert Fulkerson](wikipedia://en/239238) and (recurring visitor) [Victor Klee](https://en.wikipedia.org/wiki/Victor_Klee).[^n10] Cohen applied interval graphs to [mathematical models](https://en.wikipedia.org/wiki/Mathematical_biology) of [population biology](https://en.wikipedia.org/wiki/Population_biology), specifically [food webs](wikipedia://en/145772).[^n11]

Interval graphs are used to represent [resource allocation](https://en.wikipedia.org/wiki/Resource_allocation) problems in [operations research](wikipedia://en/43476) and [scheduling theory](https://en.wikipedia.org/wiki/Scheduling_%28computing%29). In these applications, each interval represents a request for a resource (such as a processing unit of a distributed computing system or a room for a class) for a specific period of time. The maximum weight [independent set problem](wikipedia://en/524501) for the graph represents the problem of finding the best subset of requests that can be satisfied without conflicts.[^n12] See [interval scheduling](https://en.wikipedia.org/wiki/Interval_scheduling) for more information.

An optimal [graph coloring](wikipedia://en/426743) of the interval graph represents an assignment of resources that covers all of the requests with as few resources as possible; it can be found in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) by a [greedy coloring](wikipedia://en/21051195) algorithm that colors the intervals in sorted order by their left endpoints.[^n13]

Other applications include genetics, [bioinformatics](wikipedia://en/4214), and computer science. Finding a set of intervals that represent an interval graph can also be used as a way of assembling contiguous subsequences in [DNA](https://en.wikipedia.org/wiki/DNA) mapping.[^n14] Interval graphs also play an important role in temporal reasoning.[^n15]

:::

## Interval completions and pathwidth {#Interval_completions_and_pathwidth}

If $G$ is an arbitrary graph, an **interval completion** of $G$ is an interval graph on the same vertex set that contains $G$ as a subgraph. The parameterized version of interval completion (find an interval supergraph with $k$ additional edges) is [fixed parameter tractable](wikipedia://en/603026), and moreover, is solvable in parameterized subexponential time.[^n16][^n17]

The [pathwidth](wikipedia://en/5133142) of an interval graph is one less than the size of its maximum clique (or equivalently, one less than its chromatic number), and the pathwidth of any graph $G$ is the same as the smallest pathwidth of an interval graph that contains $G$ as a subgraph.[^n18]

## Combinatorial enumeration {#Combinatorial_enumeration}

The number of connected interval graphs on $n$ unlabeled vertices, for $n=1, 2, 3, \dots$, is:[^n19]

1, 1, 2, 5, 15, 56, 250, 1328, 8069, 54962, 410330, 3317302, ...

Without the assumption of connectivity, the numbers are larger. The number of interval graphs on $n$ unlabeled vertices, not necessarily connected, is:[^n20]

1, 2, 4, 10, 27, 92, 369, 1807, 10344, 67659, 491347, 3894446, ...

These numbers exhibit faster than [exponential growth](wikipedia://en/191933): the number of interval graphs on $3n$ unlabeled vertices is at least $n!/3^{3n}$.[^n21] Because of this fast growth rate, the interval graphs do not have bounded [twin-width](wikipedia://en/71380095).[^n22]
