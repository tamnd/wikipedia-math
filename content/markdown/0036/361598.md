# Second Hardy–Littlewood conjecture

::: {#o1 .subject cue=lead name="Second Hardy–Littlewood conjecture"}

::: {#o2 .statement cue=infobox-mathematical-statement name="Second Hardy–Littlewood conjecture"}

**Second Hardy–Littlewood conjecture.**

:::

In [number theory](wikipedia://en/21527), the **second Hardy–Littlewood conjecture** concerns the number of [primes](wikipedia://en/23666) in [intervals](wikipedia://en/49172). Along with the [first Hardy–Littlewood conjecture](wikipedia://en/22947746), the second Hardy–Littlewood conjecture was proposed by [G. H. Hardy](wikipedia://en/87599) and [John Edensor Littlewood](wikipedia://en/158371) in 1923.[^o3]

:::

::: {#o5 .statement cue=heading name="Statement"}

## Statement {#Statement}

The conjecture states that

$$\pi(x+y) \leq \pi(x) + \pi(y)$$

for integers $x, y \ge 2$, where $\pi(z)$ denotes the [prime-counting function](wikipedia://en/331826), giving the number of prime numbers up to and including $z$.

:::

::: {#o7 .statement kind=statement/conjecture cue=named-heading name="Connection to the first Hardy–Littlewood conjecture"}

## Connection to the first Hardy–Littlewood conjecture {#Connection_to_the_first_Hardy–Littlewood_conjecture}

The statement of the second Hardy–Littlewood conjecture is equivalent to the statement that the number of primes from $x + 1$ to $x + y$ is always less than or equal to the number of primes from 1 to $y$. This was proved to be inconsistent with the first Hardy–Littlewood conjecture on prime $k$-tuples, and the first violation is expected to likely occur for very large values of $x$.[^o8][^o9] For example, an [admissible *k*-tuple](wikipedia://en/11421646#Admissibility) (or [prime constellation](https://en.wikipedia.org/wiki/Prime_constellation)) of 447 primes can be found in an interval of $y = 3159$ integers, while $\pi(3159) = 446$. If the first Hardy–Littlewood conjecture holds, then the first such $k$-tuple is expected for *$x$* greater than $1.5 \times 10^{174}$ but less than $2.2 \times 10^{1198}$.[^o10]

:::
