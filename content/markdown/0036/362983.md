# Many-one reduction

::: {#o1 .subject cue=lead name="Many-one reduction"}

In [computability theory](wikipedia://en/155414) and [computational complexity theory](wikipedia://en/7543), a **many-one reduction** (also called **mapping reduction**[^o2]) is a [reduction](wikipedia://en/848067) that converts instances of one [decision problem](wikipedia://en/8336) (whether an instance is in $L_1$) to another decision problem (whether an instance is in $L_2$) using a [computable function](wikipedia://en/1139338). The reduced instance is in the language $L_2$ if and only if the initial instance is in its language $L_1$. Thus if we can decide whether $L_2$ instances are in the language $L_2$, we can decide whether $L_1$ instances are in the language $L_1$ by applying the reduction and solving for $L_2$. Thus, reductions can be used to measure the relative computational difficulty of two problems. It is said that $L_1$ reduces to $L_2$ if, in layman's terms $L_2$ is at least as hard to solve as $L_1$. This means that any algorithm that solves $L_2$ can also be used as part of a (otherwise relatively simple) program that solves $L_1$.

:::

Many-one reductions are a special case and stronger form of [Turing reductions](wikipedia://en/1188375).[^o2] With many-one reductions, the oracle (that is, our solution for $L_2$) can be invoked only once at the end, and the answer cannot be modified. This means that if we want to show that problem $L_1$ can be reduced to problem $L_2$, we can use our solution for $L_2$ only once in our solution for $L_1$, unlike in Turing reductions, where we can use our solution for $L_2$ as many times as needed in order to solve the membership problem for the given instance of $L_1$.

Many-one reductions were first used by [Emil Post](https://en.wikipedia.org/wiki/Emil_Post) in a paper published in 1944.[^o3] Later [Norman Shapiro](https://en.wikipedia.org/wiki/Norman_Shapiro) used the same concept in 1956 under the name *strong reducibility*.[^o4]

## Definitions {#Definitions}

### Formal languages {#Formal_languages}

Suppose $A$ and $B$ are [formal languages](wikipedia://en/10939) over the [alphabets](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29) $\Sigma$ and $\Gamma$, respectively. A **many-one reduction** from $A$ to $B$ is a [total computable function](https://en.wikipedia.org/wiki/Total_computable_function) $f: \Sigma^{*}\rightarrow\Gamma^{*}$ that has the property that each word $w$ is in $A$ if and only if $f(w)$ is in $B$.

If such a function $f$ exists, one says that $A$ is **many-one reducible** or **m-reducible** to $B$ and writes

$$A \leq_{\mathrm{m}} B.$$

### Subsets of natural numbers {#Subsets_of_natural_numbers}

Given two sets $A,B \subseteq \mathbb{N}$ one says $A$ is **many-one reducible** to $B$ and writes

$$A \leq_{\mathrm{m}} B$$

if there exists a [total computable function](https://en.wikipedia.org/wiki/Total_computable_function) $f$ with $x\in A$ iff $f(x)\in B$.

If the many-one reduction $f$ is [injective](wikipedia://en/45196), one speaks of a one-one reduction and writes $A \leq_1 B$.

If the one-one reduction $f$ is [surjective](wikipedia://en/27873), one says $A$ is **[recursively isomorphic](wikipedia://en/2611685)** to $B$ and writes[^o9]<sup>p.324</sup>

$$A\equiv B$$

### Many-one equivalence {#Many-one_equivalence}

If both $A \leq_{\mathrm{m}} B$ and $B \leq_{\mathrm{m}} A$, one says $A$ is **many-one equivalent** or **m-equivalent** to $B$ and writes

$$A \equiv_{\mathrm{m}} B.$$

### Many-one completeness (m-completeness) {#Many-one_completeness_(m-completeness)}

A set $B$ is called *many-one complete*, or simply **m-complete**, [iff](https://en.wikipedia.org/wiki/Iff) $B$ is recursively enumerable and every recursively enumerable set $A$ is m-reducible to $B$.

:::

## Degrees {#Degrees}

The relation $\equiv_m$ indeed is an [equivalence](wikipedia://en/9259), its [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes) are called m-degrees and form a poset $\mathcal D_m$ with the order induced by $\leq_m$.[^o9]<sup>p.257</sup>

Some properties of the m-degrees, some of which differ from analogous properties of [Turing degrees](wikipedia://en/764405):[^o9]<sup>pp.555--581</sup>

- There is a well-defined jump operator on the m-degrees.
- The only m-degree with jump **0**<sub>m</sub>′ is **0**<sub>m</sub>.
- There are m-degrees $\mathbf a>_m\boldsymbol 0_m'$ where there does not exist $\mathbf b$ where $\mathbf b'=\mathbf a$.
- Every countable linear order with a least element embeds into $\mathcal D_m$.
- The first order theory of $\mathcal D_m$ is isomorphic to the theory of second-order arithmetic.

There is a characterization of $\mathcal D_m$ as the unique poset satisfying several explicit properties of its [ideals](wikipedia://en/12633368), a similar characterization has eluded the Turing degrees.[^o9]<sup>pp.574--575</sup>

[Myhill's isomorphism theorem](wikipedia://en/2611629) can be stated as follows: "For all sets $A,B$ of natural numbers, $A\equiv B\iff A\equiv_1 B$." As a corollary, $\equiv$ and $\equiv_1$ have the same equivalence classes.[^o9]<sup>p.325</sup> The equivalences classes of $\equiv_1$ are called the *1-degrees*.

## Many-one reductions with resource limitations {#Many-one_reductions_with_resource_limitations}

Many-one reductions are often subjected to resource restrictions, for example that the reduction function is computable in polynomial time, logarithmic space, by $AC_0$ or $NC_0$ circuits, or polylogarithmic projections where each subsequent reduction notion is weaker than the prior; see [polynomial-time reduction](wikipedia://en/159695) and [log-space reduction](wikipedia://en/1174850) for details.

Given decision problems $A$ and $B$ and an [algorithm](wikipedia://en/775) *N* that solves instances of $B$, we can use a many-one reduction from $A$ to $B$ to solve instances of $A$ in:

- the time needed for *N* plus the time needed for the reduction
- the maximum of the space needed for *N* and the space needed for the reduction

We say that a class **C** of languages (or a subset of the [power set](wikipedia://en/23799) of the natural numbers) is *closed under many-one reducibility* if there exists no reduction from a language outside **C** to a language in **C**. If a class is closed under many-one reducibility, then many-one reduction can be used to show that a problem is in **C** by reducing it to a problem in **C**. Many-one reductions are valuable because most well-studied complexity classes are closed under some type of many-one reducibility, including [P](wikipedia://en/658550), [NP](wikipedia://en/21562), [L](wikipedia://en/1149999), [NL](wikipedia://en/1145955), [co-NP](wikipedia://en/6184), [PSPACE](wikipedia://en/39351), [EXP](https://en.wikipedia.org/wiki/EXP), and many others. It is known for example that the first four listed are closed up to the very weak reduction notion of polylogarithmic time projections. These classes are not closed under arbitrary many-one reductions, however.

## Many-one reductions extended {#Many-one_reductions_extended}

One may also ask about generalized cases of many-one reduction. One such example is *e-reduction*, where we consider $f:A\to B$ that are recursively enumerable instead of restricting to recursive $f$. The resulting reducibility relation is denoted $\leq_e$, and its poset has been studied in a similar vein to that of the Turing degrees. For example, there is a jump set $\boldsymbol 0^'_e$ for *e*-degrees. The *e*-degrees do admit some properties differing from those of the poset of Turing degrees, e.g. an embedding of the diamond graph into the degrees below $\boldsymbol'_e$.[^o15]

## Properties {#Properties}

- The [relations](wikipedia://en/22517558) of many-one reducibility and 1-reducibility are [transitive](wikipedia://en/200463) and [reflexive](wikipedia://en/200458) and thus induce a [preorder](wikipedia://en/23582) on the [powerset](https://en.wikipedia.org/wiki/Powerset) of the natural numbers.
- $A \leq_{\mathrm{m}} B$ [if and only if](wikipedia://en/14922) $\mathbb{N} \setminus A \leq_{\mathrm{m}} \mathbb{N} \setminus B.$
- A set is many-one reducible to the [halting problem](wikipedia://en/21391870) [if and only if](wikipedia://en/14922) it is [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable). This says that with regards to many-one reducibility, the halting problem is the most complicated of all recursively enumerable problems. Thus the halting problem is r.e. complete. Note that it is not the only r.e. complete problem.
- The specialized halting problem for an *individual* Turing machine *T* (i.e., the set of inputs for which *T* eventually halts) is many-one complete iff *T* is a [universal Turing machine](wikipedia://en/71435). Emil Post showed that there exist recursively enumerable sets that are neither [decidable](wikipedia://en/913118) nor m-complete, and hence that *there exist nonuniversal Turing machines whose individual halting problems are nevertheless undecidable*.

:::

## Karp reductions {#Karp_reductions}

A [polynomial-time](wikipedia://en/159695) many-one reduction from a problem *A* to a problem *B* (both of which are usually required to be [decision problems](wikipedia://en/8336)) is a polynomial-time algorithm for transforming inputs to problem *A* into inputs to problem *B*, such that the transformed problem has the same output as the original problem. An instance *x* of problem *A* can be solved by applying this transformation to produce an instance *y* of problem *B*, giving *y* as the input to an algorithm for problem *B*, and returning its output. Polynomial-time many-one reductions may also be known as **polynomial transformations** or **Karp reductions**, named after [Richard Karp](https://en.wikipedia.org/wiki/Richard_Karp). A reduction of this type is denoted by $A \le_m^P B$ or $A \le_p B$.[^o19][^o20]
