# Snake-in-the-box

::: {#o1 .subject cue=lead name="Snake-in-the-box"}

*Image: Snake in the box.svg.* Drawing of a snake in a [cube](wikipedia://en/6285) (which is a three-dimensional [hypercube](wikipedia://en/39783))

::: {#o2 .problem cue=unsolved}

What is the maximum length of a snake for each $n$-dimensional hypercube graph?

:::

The **snake-in-the-box** problem in [graph theory](wikipedia://en/12401) and [coding theory](wikipedia://en/321869) deals with finding a certain kind of path along the edges of a [hypercube](wikipedia://en/39783). This path starts at one corner and travels along the edges to as many corners as it can reach. After it gets to a new corner, the previous corner and all of its neighbors must be marked as unusable. The path must never travel to a corner which has been marked unusable.

:::

In other words, a *snake* is a connected open path in the hypercube where each node has exactly two neighbors that are also in the path, with the exception of the first and last nodes, which each has only one neighbor in the path. The rule for generating a snake is that a node in the hypercube may be visited if it is connected to the current node and it is not a neighbor of any previously visited node in the snake, other than the current node.

In graph theory terminology, this is called finding the longest possible [induced path](wikipedia://en/7714430) in a [hypercube](wikipedia://en/6706815); it can be viewed as a special case of the [induced subgraph isomorphism problem](wikipedia://en/6892618). There is a similar problem of finding long induced [cycles](wikipedia://en/878962) in hypercubes, called the **coil-in-the-box** problem.

The snake-in-the-box problem was first described by (Kautz 1958), motivated by the theory of [error-correcting codes](https://en.wikipedia.org/wiki/Error-correcting_code). The vertices of a solution to the snake or coil in the box problems can be used as a [Gray code](wikipedia://en/50564) that can detect single-bit errors. Such codes have applications in [electrical engineering](https://en.wikipedia.org/wiki/Electrical_engineering), [coding theory](wikipedia://en/321869), and computer [network topologies](https://en.wikipedia.org/wiki/Network_topology). In these applications, it is important to devise as long a code as is possible for a given dimension of [hypercube](wikipedia://en/39783). Often, the longer the code, the more effective are its capabilities.

Finding the longest snake or coil becomes notoriously difficult as the dimension number increases and the search space suffers a serious [combinatorial explosion](wikipedia://en/7835738). Some techniques for determining the upper and lower bounds for the snake-in-the-box problem include proofs using [discrete mathematics](wikipedia://en/8492) and [graph theory](wikipedia://en/12401), [exhaustive search](https://en.wikipedia.org/wiki/Exhaustive_search) of the search space, and [heuristic](https://en.wikipedia.org/wiki/Heuristic) search utilizing evolutionary techniques.

## Known lengths and bounds {#Known_lengths_and_bounds}

The maximum length for the snake-in-the-box problem is known for dimensions one through eight; it is

1, 2, 4, 7, 13, 26, 50, 98 .

Beyond that length, the exact length of the longest snake is not known; the best lengths found so far for dimensions nine through thirteen are

191, 379, 746, 1476, 2932.[^o5]

For cycles (the coil-in-the-box problem), a cycle cannot exist in a hypercube of dimension less than two. The maximum lengths of the longest possible cycles are

0, 4, 6, 8, 14, 26, 48, 96 .

Beyond that length, the exact length of the longest cycle is not known; the best lengths found so far for dimensions nine through thirteen are

192, 374, 738, 1468, 2840.[^o5]

*Doubled coils* are a special case: cycles whose second half repeats the structure of their first half, also known as *symmetric coils*. For dimensions two through seven the lengths of the longest possible doubled coils are

4, 6, 8, 14, 26, 46.

Beyond that, the best lengths found so far for dimensions eight through thirteen are

94, 186, 370, 726, 1430, 2810.[^o5]

For both the snake and the coil in the box problems, it is known that the maximum length is proportional to 2<sup>*n*</sup> for an *n*-dimensional box, asymptotically as *n* grows large, and bounded above by 2<sup>*n* − 1</sup>. The [constant of proportionality](https://en.wikipedia.org/wiki/Constant_of_proportionality) is not known, the best known lower bound being 77/256 ≈ 0.30 (see (Abbot Katchalski 1991)).[^o7]
