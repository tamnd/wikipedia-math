# Hyponormal operator

::: {#o1 .subject cue=lead name="Hyponormal operator"}

articlearticleIn [mathematics](wikipedia://en/18831), especially [operator theory](wikipedia://en/712675), a **hyponormal operator** is a generalization of a [normal operator](wikipedia://en/190167). In general, a bounded [linear operator](https://en.wikipedia.org/wiki/Linear_operator) *T* on a complex [Hilbert space](wikipedia://en/20598932) *H* is said to be ***p*-hyponormal** ($0 < p \le 1$) if:

:::

$$(T^*T)^p \ge (TT^*)^p$$

(That is to say, $(T^*T)^p - (TT^*)^p$ is a positive operator.) If $p = 1$, then *T* is called a hyponormal operator. If $p = 1/2$, then *T* is called a semi-hyponormal operator. Moreover, *T* is said to be **log-hyponormal** if it is invertible and

$$\log (T^*T) \ge \log (TT^*).$$

An invertible *p*-hyponormal operator is log-hyponormal. On the other hand, not every log-hyponormal is *p*-hyponormal.

The class of semi-hyponormal operators was introduced by Xia, and the class of p-hyponormal operators was studied by Aluthge, who used what is today called the [Aluthge transformation](https://en.wikipedia.org/wiki/Aluthge_transformation).

Every [subnormal operator](wikipedia://en/7930037) (in particular, a normal operator) is hyponormal, and every hyponormal operator is a [paranormal](wikipedia://en/21455723) [convexoid operator](wikipedia://en/21498815). Not every paranormal operator is, however, hyponormal.
