# Graph algebra (social sciences)

::: {#o1 .subject cue=lead name="Graph algebra"}

**Graph algebra** is [systems-centric](https://en.wikipedia.org/wiki/Systems-centric) modeling tool for the [social sciences](https://en.wikipedia.org/wiki/Social_sciences).[^o2] It was first developed by Sprague, Pzeworski, and Cortes[^o3] as a hybridized version of engineering plots to describe social phenomena.

:::
