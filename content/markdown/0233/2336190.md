# Hilbert's thirteenth problem

::: {#o1 .subject cue=lead name="Hilbert's thirteenth problem"}

**Hilbert's thirteenth problem** is one of the 23 [Hilbert problems](https://en.wikipedia.org/wiki/Hilbert_problems) set out in a celebrated list compiled in 1900 by [David Hilbert](wikipedia://en/8302). It entails proving whether a solution exists for all [7th-degree equations](wikipedia://en/25451646) using [algebraic](wikipedia://en/974169) (variant: [continuous](wikipedia://en/6122)) [functions](wikipedia://en/185427) of two [arguments](wikipedia://en/32842052). It was first presented in the context of [nomography](https://en.wikipedia.org/wiki/Nomograph), and in particular "nomographic construction" — a process whereby a function of several variables is constructed using functions of two variables. The variant for continuous functions was resolved affirmatively in 1957 by [Vladimir Arnold](wikipedia://en/32490) when he proved the [Kolmogorov–Arnold representation theorem](wikipedia://en/47321473), but the variant for algebraic functions remains unresolved.

:::

## Introduction {#Introduction}

Using the methods pioneered by [Ehrenfried Walther von Tschirnhaus](wikipedia://en/26456397) (1683), [Erland Samuel Bring](https://en.wikipedia.org/wiki/Erland_Samuel_Bring) (1786), and [George Jerrard](https://en.wikipedia.org/wiki/George_Jerrard) (1834),[^o3] [William Rowan Hamilton](wikipedia://en/39817) showed in 1836 that every [seventh-degree](wikipedia://en/25451646) equation can be reduced via radicals to the form $x^7 + ax^3 + bx^2 + cx + 1 = 0$.[^o4][^o5]

Regarding this equation, Hilbert asked whether its solution, *x*, considered as a function of the three variables *a*, *b* and *c*, can be expressed as the [composition](wikipedia://en/195947) of a finite number of two-variable functions.

## History {#History}

Hilbert originally posed his problem for [algebraic functions](wikipedia://en/974169)[^o7] ("...Existenz von algebraischen Funktionen...", i.e., "...existence of algebraic functions..."; also see Abhyankar 1997,[^o8] Vitushkin 2004[^o9]). However, later in that article, Hilbert also conjectured there isn't a solution to a seventh-degree equation, even using arbitrary [continuous functions](wikipedia://en/6122) in two variables.[^o10]

A generalization of the second ("continuous") variant of the problem is the following question: can every continuous function of three variables be expressed as a [composition](wikipedia://en/195947) of finitely many continuous functions of two variables? The affirmative answer to this general question was given in 1957 by [Vladimir Arnold](wikipedia://en/32490), then only nineteen years old and a student of [Andrey Kolmogorov](wikipedia://en/91161). Kolmogorov had shown in the previous year that any function of several variables can be constructed with a finite number of three-variable functions. Arnold then expanded on this work to show that only two-variable functions were in fact required, thus answering Hilbert's question when posed for the class of continuous functions.[^o12] Later, Kolmogorov slightly simplified Arnold's result.[^o13]

Arnold later returned to the algebraic version of the problem, jointly with [Goro Shimura](wikipedia://en/174724) (Arnold and Shimura 1976).[^o14]
