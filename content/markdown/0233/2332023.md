# Java Secure Socket Extension

::: {#o1 .subject cue=lead name="Java Secure Socket Extension"}

In [computing](https://en.wikipedia.org/wiki/Computing), the **Java Secure Socket Extension** (**JSSE**) is a Java API and a provider implementation named SunJSSE that enable secure [Internet](https://en.wikipedia.org/wiki/Internet) communications in the [Java Runtime Environment](https://en.wikipedia.org/wiki/Java_Runtime_Environment). It implements a [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) technology version of the [Secure Sockets Layer](https://en.wikipedia.org/wiki/Secure_Sockets_Layer) (SSL) and the [Transport Layer Security](wikipedia://en/187813) (TLS) [protocols](https://en.wikipedia.org/wiki/Communications_protocol). It includes functionality for data [encryption](wikipedia://en/10294),[^o2] server [authentication](wikipedia://en/47967), [message integrity](https://en.wikipedia.org/wiki/Message_integrity), and optional client-authentication.

:::

JSSE was originally developed as an optional package for Java versions 1.2 and 1.3, but was added as a standard API and implementation into JDK 1.4.
