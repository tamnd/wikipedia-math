# Computational topology

::: {#o1 .subject cue=lead name="Computational topology"}

**Algorithmic topology**, or **computational topology**, is a subfield of [topology](wikipedia://en/29954) with an overlap with areas of [computer science](https://en.wikipedia.org/wiki/Computer_science), in particular, [computational geometry](wikipedia://en/176927) and [computational complexity theory](wikipedia://en/7543).

:::

A primary concern of algorithmic topology, as its name suggests, is to develop efficient [algorithms](wikipedia://en/775) for solving problems that arise naturally in fields such as [computational geometry](wikipedia://en/176927), [graphics](https://en.wikipedia.org/wiki/Graphics), [robotics](https://en.wikipedia.org/wiki/Robotics), [social science](https://en.wikipedia.org/wiki/Social_science), [structural biology](https://en.wikipedia.org/wiki/Structural_biology), and [chemistry](https://en.wikipedia.org/wiki/Chemistry), using methods from [computable topology](wikipedia://en/36075414).[^o2][^o3][^o4]

## Major algorithms by subject area {#Major_algorithms_by_subject_area}

### Algorithmic 3-manifold theory {#Algorithmic_3-manifold_theory}

A large family of algorithms concerning [3-manifolds](wikipedia://en/1018257) revolve around [normal surface](wikipedia://en/3141418) theory, which is a phrase that encompasses several techniques to turn problems in 3-manifold theory into integer linear programming problems.

- *Rubinstein and Thompson's 3-sphere recognition algorithm*. This is an algorithm that takes as input a [triangulated](wikipedia://en/1440976) [3-manifold](wikipedia://en/1018257) and determines whether or not the manifold is [homeomorphic](wikipedia://en/13660) to the [3-sphere](wikipedia://en/39792). It has exponential run-time in the number of tetrahedral simplexes in the initial 3-manifold, and also an exponential memory profile. Saul Schleimer went on to show the problem lies in the complexity class [NP](wikipedia://en/21562).[^o7] Furthermore, Raphael Zentner showed that the problem lies in the complexity class coNP,[^o8] provided that the [Generalized Riemann hypothesis](wikipedia://en/152567) holds. He uses instanton gauge theory, the geometrization theorem of 3-manifolds, and subsequent work of Greg Kuperberg [^o9] on the complexity of knottedness detection.
- The [connect-sum](wikipedia://en/490134) decomposition of 3-manifolds is also implemented in [Regina](wikipedia://en/4781110), has exponential run-time and is based on a similar algorithm to the 3-sphere recognition algorithm.
- Determining that the Seifert-Weber 3-manifold contains no incompressible surface has been algorithmically implemented by Burton, Rubinstein and Tillmann[^o10] and based on normal surface theory.
- The *Manning algorithm* is an algorithm to find hyperbolic structures on 3-manifolds whose [fundamental group](wikipedia://en/11004) have a solution to the [word problem](wikipedia://en/33563).[^o11]

At present the [JSJ decomposition](wikipedia://en/228599) has not been implemented algorithmically in computer software. Neither has the compression-body decomposition. There are some very popular and successful heuristics, such as [SnapPea](wikipedia://en/3025251) which has much success computing approximate hyperbolic structures on triangulated 3-manifolds. It is known that the full classification of 3-manifolds can be done algorithmically,[^o12] in fact, it is known that deciding whether two closed, oriented 3-manifolds given by [triangulations](wikipedia://en/1440976) (simplicial complexes) are equivalent (homeomorphic) is [elementary recursive](https://en.wikipedia.org/wiki/Elementary_recursive).[^o13] This generalizes the result on 3-sphere recognition.

#### Conversion algorithms {#Conversion_algorithms}

- [SnapPea](wikipedia://en/3025251) implements an algorithm to convert a planar [knot](wikipedia://en/366808) or [link diagram](wikipedia://en/366808#knot_diagram) into a cusped triangulation. This algorithm has a roughly linear run-time in the number of crossings in the diagram, and low memory profile. The algorithm is similar to the Wirthinger algorithm for constructing presentations of the [fundamental group](wikipedia://en/11004) of link complements given by planar diagrams. Similarly, SnapPea can convert [surgery](wikipedia://en/5961115) presentations of 3-manifolds into triangulations of the presented 3-manifold.
- D. Thurston and F. Costantino have a procedure to construct a triangulated 4-manifold from a triangulated 3-manifold. Similarly, it can be used to construct surgery presentations of triangulated 3-manifolds, although the procedure is not explicitly written as an algorithm in principle it should have polynomial run-time in the number of tetrahedra of the given 3-manifold triangulation.[^o15]
- S. Schleimer has an algorithm which produces a triangulated 3-manifold, given input a word (in [Dehn twist](wikipedia://en/765970) generators) for the [mapping class group](wikipedia://en/793295) of a surface. The 3-manifold is the one that uses the word as the attaching map for a [Heegaard splitting](wikipedia://en/864418) of the 3-manifold. The algorithm is based on the concept of a *layered triangulation*.

### Algorithmic knot theory {#Algorithmic_knot_theory}

[Determining whether or not a knot is trivial](wikipedia://en/4956355) is known to be in the complexity classes [NP](wikipedia://en/21562)[^o17] as well as [co-NP](wikipedia://en/6184).[^o18] The problem of determining the [genus of a knot in a 3-manifold](https://en.wikipedia.org/wiki/Knot_genus) is [NP-complete](https://en.wikipedia.org/wiki/NP-complete);[^o19] however, while [NP](wikipedia://en/21562) remains an upper bound on the complexity of determining the genus of a knot in R<sup>3</sup> or S<sup>3</sup>, as of 2006 it was unknown whether the algorithmic problem of determining the genus of a knot in those particular 3-manifolds was still [NP-hard](https://en.wikipedia.org/wiki/NP-hard).[^o19]

### Computational homotopy {#Computational_homotopy}

- Computational methods for [homotopy groups of spheres](wikipedia://en/1104697#Computational_methods).
- Computational methods for solving [systems of polynomial equations](https://en.wikipedia.org/wiki/Systems_of_polynomial_equations#Homotopy_continuation_method).
- Brown has an algorithm to compute the homotopy groups of spaces that are finite [Postnikov complexes](wikipedia://en/15708202),[^o21] although it is not widely considered implementable.

### Computational homology {#Computational_homology}

Computation of [homology groups](https://en.wikipedia.org/wiki/Homology_group) of [cell complexes](wikipedia://en/353022) reduces to bringing the boundary matrices into [Smith normal form](wikipedia://en/1106564). Although this is a completely solved problem algorithmically, there are various technical obstacles to efficient computation for large complexes. There are two central obstacles. Firstly, the basic Smith form algorithm has cubic complexity in the size of the matrix involved since it uses row and column operations which makes it unsuitable for large cell complexes. Secondly, the intermediate matrices which result from the application of the Smith form algorithm get filled-in even if one starts and ends with sparse matrices.

- Efficient and probabilistic Smith normal form algorithms, as found in the [LinBox](http://www.linalg.org) library.
- Simple homotopic reductions for pre-processing homology computations, as in the [Perseus](http://www.sas.upenn.edu/~vnanda/perseus/index.html) software package.
- Algorithms to compute [persistent homology](wikipedia://en/31069689) of [filtered](wikipedia://en/726014) complexes, as in the [TDAstats](https://CRAN.R-project.org/package=TDAstats) R package.[^o23]
- In some applications, such as in [Topological Data Analysis](wikipedia://en/17740009) (TDA), it is useful to have representatives of (co)homology classes that are as "small" as possible. This is known as the problem of (co)homology localization. On triangulated manifolds, given a chain representing a homology class, it is in general NP-hard to approximate the minimum-support homologous chain.[^o24] However, the particular setting of approximating 1-cohomology localization on triangulated 2-manifolds is one of only three known problems whose hardness is equivalent to the [Unique Games Conjecture](https://en.wikipedia.org/wiki/Unique_Games_Conjecture).[^o25]
