# Conditional-access module

*Image: AstonCam.jpg.* Conditional Access Module

*Image: CAS.svg.* Various types of CAM

::: {#o1 .subject cue=lead name="Conditional-access module"}

A **conditional access module** (**CAM**) is an electronic device, usually incorporating a slot for a [smart card](https://en.wikipedia.org/wiki/Smart_card), which equips an [integrated digital television](https://en.wikipedia.org/wiki/Integrated_digital_television) or [set-top box](https://en.wikipedia.org/wiki/Set-top_box) with the appropriate hardware facility to view [conditional access](wikipedia://en/2183934) content that has been [encrypted](wikipedia://en/10294) using a conditional access system.[^o2] They are normally used with [direct-broadcast satellite](https://en.wikipedia.org/wiki/Direct-broadcast_satellite) (DBS) services, although [digital terrestrial](https://en.wikipedia.org/wiki/Digital_terrestrial_television) pay TV suppliers also use CAMs. [PC Card](https://en.wikipedia.org/wiki/PC_Card) [form factor](https://en.wikipedia.org/wiki/Computer_form_factor) is used as the [Common Interface](https://en.wikipedia.org/wiki/Common_Interface) form of Conditional Access Modules for [DVB](https://en.wikipedia.org/wiki/Digital_Video_Broadcasting) broadcasts. Major CAM manufacturers are Airmod.tech and SMIT. Airmod, created in 2022, regroup CAM formerly managed by Neotion and SmarDTV.

:::

Some encryption systems for which CAMs are available are [Logiways](https://en.wikipedia.org/wiki/Logiways), [Nagravision](https://en.wikipedia.org/wiki/Nagravision), [Viaccess](https://en.wikipedia.org/wiki/Viaccess), [Mediaguard](https://en.wikipedia.org/wiki/Mediaguard), Irdeto, [KeyFly](https://en.wikipedia.org/wiki/KeyFly), [Verimatrix](https://en.wikipedia.org/wiki/Verimatrix), [Cryptoworks](https://en.wikipedia.org/wiki/Cryptoworks), [Mascom](https://en.wikipedia.org/wiki/Mascom), Safeview, [Diablo CAM](https://en.wikipedia.org/wiki/Diablo_CAM) and [Conax](https://en.wikipedia.org/wiki/Conax). [NDS](https://en.wikipedia.org/wiki/News_Datacom) [VideoGuard](wikipedia://en/1523933) encryption, the preferred choice of [Sky Digital](https://en.wikipedia.org/wiki/Sky_Digital_%28UK_&_Ireland%29) can only be externally emulated by a Dragon brand CAM. The NDS CAM that the Sky viewing card ordinarily uses is built into the Sky Digibox and thus not visible. Dragon and Matrix, two popular cams with satellite television enthusiasts are mis meaning each is capable of handling more than one encryption system. Matrix CAMs can be upgraded via the [PC Card](https://en.wikipedia.org/wiki/PC_Card) port in a [laptop](https://en.wikipedia.org/wiki/Laptop) personal computer whereas a Dragon cam update is done via separate programmer hardware. Although not officially supported or acknowledged, mis and programmable modules are a [grey market](https://en.wikipedia.org/wiki/Grey_market) in the pay-TV industry.

The primary purpose of the CAM is to derive control words, which are short-term decryption keys for video. The effectiveness of a CAM depends on the [tamper](https://en.wikipedia.org/wiki/Tamper-evident) resistance of the hardware; if the hardware is broken, the functionality of the CAM can be emulated, enabling the content to be decrypted by non-subscribers. CAMs are normally removable so that they can be replaced after the hardware security is breached. Replacement of the CAMs in a system is called a card swap-out.

CAM Modules come in two types: *standard*, intended for a single TV consumer, and *professional*, made for an array of televisions connected to a rack of CAMs, like in a hospital or a hotel.

The standard format for a CAM is a [PC card](https://en.wikipedia.org/wiki/PC_card) which takes a [smart card](https://en.wikipedia.org/wiki/Smart_card) to authenticate, although CAMs with the 'smart card' burnt into memory, known as Cardless CAM, can be found. With the CI+ 2.0 certification came a new [USB dongle](https://en.wikipedia.org/wiki/USB_dongle) form factor. In addition, CAM emulators exist for many systems, either providing an interface to allow the use of more than one type of card, or a card not designed for that receiver.
