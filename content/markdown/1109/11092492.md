# Amalgamation property

::: {#o1 .subject cue=lead name="Amalgamation property"}

*Image: Amalgamation property.svg.* A [commutative diagram](wikipedia://en/138484) of the amalgamation property.

In the mathematical field of [model theory](wikipedia://en/19858), the **amalgamation property** is a property of collections of [structures](wikipedia://en/4055928) that guarantees, under certain conditions, that two structures in the collection can be regarded as substructures of a larger one.

:::

This property plays a crucial role in [Fraïssé's theorem](https://en.wikipedia.org/wiki/Fraïssé's_theorem), which characterises classes of finite structures that arise as [ages](https://en.wikipedia.org/wiki/Age_%28model_theory%29) of countable homogeneous structures.

The [diagram](wikipedia://en/7651625) of the amalgamation property appears in many areas of [mathematical logic](wikipedia://en/19636). Examples include in [modal logic](wikipedia://en/333365) as an incestual accessibility relation, and in [lambda calculus](wikipedia://en/18203) as a manner of [reduction](wikipedia://en/18203#Reduction) having the [Church–Rosser property](https://en.wikipedia.org/wiki/Church–Rosser_property).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An *amalgam* can be formally defined as a 5-tuple (*A,f,B,g,C*) such that *A,B,C* are structures having the same [signature](wikipedia://en/7788156), and *f: A* → *B, g*: *A* → *C* are *embeddings*. Recall that *f: A* → *B* is an *embedding* if *f* is an injective morphism which induces an isomorphism from *A* to the substructure *f(A)* of *B*.[^o4]

A class *K* of structures has the amalgamation property if for every amalgam with *A,B,C* ∈ *K* and *A* ≠ Ø, there exist both a structure *D* ∈ *K* and embeddings *f':* *B* → *D, g':* *C* → *D* such that

$$f'\circ f = g' \circ g. \,$$

A first-order theory $T$ has the amalgamation property if the class of models of $T$ has the amalgamation property. The amalgamation property has certain connections to [quantifier elimination](wikipedia://en/2150441).

In general, the amalgamation property can be considered for a [category](wikipedia://en/5869) with a specified choice of the class of morphisms (in place of embeddings). This notion is related to the categorical notion of a [pushout](wikipedia://en/582024), where *D* is supposed to be minimal in a suitable sense.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- The class of sets, where the embeddings are injective functions, and if they are assumed to be inclusions then an amalgam is simply the union of the two sets.
- The class of [free groups](wikipedia://en/59735) where the embeddings are injective homomorphisms, and (assuming they are inclusions) an amalgam is the [quotient group](wikipedia://en/11526) $B*C/A$, where \* is the [free product](wikipedia://en/360036).
- The class of finite [linear orderings](https://en.wikipedia.org/wiki/Linear_order). This is due to the fact that any [homogeneous structure](wikipedia://en/19858#homogeneous) from an amalgamation class of finite structure. [^o7]

A similar but different notion to the amalgamation property is the [joint embedding property](wikipedia://en/17232866). To see the difference, first consider the class *K* (or simply the set) containing three models with linear orders, *L*<sub>1</sub> of size one, *L*<sub>2</sub> of size two, and *L*<sub>3</sub> of size three. This class *K* has the joint embedding property because all three models can be embedded into *L*<sub>3</sub>. However, *K* does not have the amalgamation property. The counterexample for this starts with *L*<sub>1</sub> containing a single element *e* and extends in two different ways to *L*<sub>3</sub>, one in which *e* is the smallest and the other in which *e* is the largest. Now any common model with an embedding from these two extensions must be at least of size five so that there are two elements on either side of *e*.

Now consider the class of [algebraically closed fields](wikipedia://en/1018). This class has the amalgamation property since any two field extensions of a prime field can be embedded into a common field. However, two arbitrary fields cannot be embedded into a common field when the [characteristic](wikipedia://en/1066621) of the fields differ.

:::

::: {#o9 .pointer-item cue=pointer name="Disjoint amalgamation property"}

## Strong amalgamation property {#Strong_amalgamation_property}

A class *K* of structures has the *strong amalgamation property* (SAP), also called the *disjoint amalgamation property* (DAP), if for every amalgam with *A,B,C* ∈ *K* there exist both a structure *D* ∈ *K* and embeddings *f':* *B* → *D, g': C* → *D* such that

$$f' \circ f = g' \circ g \,$$

and

$$f '[B] \cap g '[C] = (f ' \circ f)[A] = (g ' \circ g)[A] \,$$

where for any set *X* and function *h* on *X,*

$$h \lbrack X \rbrack = \lbrace h(x) \mid x \in X \rbrace. \,$$

This property is related to the notion of a [pullback](wikipedia://en/841689)[^o10].
