# Card Verifiable Certificate

::: {#o1 .subject cue=lead name="Card Verifiable Certificate"}

**Card Verifiable Certificates** (**CVC**) are [digital certificates](https://en.wikipedia.org/wiki/Digital_certificate) that are designed to be processed by devices with limited computing power such as [smart cards](https://en.wikipedia.org/wiki/Smart_cards). This is achieved by using simple [type–length–value](https://en.wikipedia.org/wiki/Type–length–value) (TLV) encoding with fixed fields. Fixed fields means that each field in the certificate is of fixed, or maximum, length and each field comes in a well defined order. This makes parsing easy, in contrast to [asn.1](https://en.wikipedia.org/wiki/Asn.1) parsing which requires more processing and has to keep fields in memory while parsing nested content.

:::

CVC is used by the third generation ePassports implementing [Extended Access Control](https://en.wikipedia.org/wiki/Extended_Access_Control) (EAC).

There are [open source](https://en.wikipedia.org/wiki/Open_source) implementations for processing EAC/CVC certificates:

- [EJBCA](https://en.wikipedia.org/wiki/EJBCA)
- JMRTD[^o2]
