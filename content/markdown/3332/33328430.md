# Duality gap

::: {#o1 .subject cue=lead name="Duality gap"}

In [optimization problems](wikipedia://en/1126536) in [applied mathematics](wikipedia://en/24295969), the **duality gap** is the difference between the [primal and dual solutions](https://en.wikipedia.org/wiki/Dual_problem). If $d^*$ is the optimal dual value and $p^*$ is the optimal primal value then the duality gap is equal to $p^* - d^*$. This value is always greater than or equal to 0 (for minimization problems). The duality gap is zero if and only if [strong duality](wikipedia://en/34390810) holds. Otherwise the gap is strictly positive and [weak duality](wikipedia://en/34390896) holds.[^o2]

:::

In general given two [dual pairs](https://en.wikipedia.org/wiki/Dual_pair) [separated](https://en.wikipedia.org/wiki/Separated_space) [locally convex spaces](https://en.wikipedia.org/wiki/Locally_convex_space) $\left(X,X^*\right)$ and $\left(Y,Y^*\right)$. Then given the function $f: X \to \mathbb{R} \cup \{+\infty\}$, we can define the primal problem by

$$\inf_{x \in X} f(x). \,$$

If there are constraint conditions, these can be built into the function $f$ by letting $f = f + I_\text{constraints}$ where $I$ is the [indicator function](https://en.wikipedia.org/wiki/Characteristic_function_%28convex_analysis%29). Then let $F: X \times Y \to \mathbb{R} \cup \{+\infty\}$ be a [perturbation function](wikipedia://en/33430345) such that $F(x,0) = f(x)$. The *duality gap* is the difference given by

$$\inf_{x \in X} [F(x,0)] - \sup_{y^* \in Y^*} [-F^*(0,y^*)]$$

where $F^*$ is the [convex conjugate](wikipedia://en/1001490) in both variables.[^o3][^o4][^o5]

In computational [optimization](https://en.wikipedia.org/wiki/Optimization), another "duality gap" is often reported, which is the difference in value between any dual solution and the value of a feasible but suboptimal iterate for the primal problem. This alternative "duality gap" quantifies the discrepancy between the value of a current feasible but suboptimal iterate for the primal problem and the value of the dual problem; the value of the dual problem is, under regularity conditions, equal to the value of the *[convex relaxation](https://en.wikipedia.org/wiki/Convex_relaxation)* of the primal problem: The convex relaxation is the problem arising replacing a non-convex feasible set with its closed [convex hull](wikipedia://en/40634) and with replacing a non-convex function with its convex [closure](https://en.wikipedia.org/wiki/Lower_semi-continuous), that is the function that has the [epigraph](wikipedia://en/5744061) that is the closed convex hull of the original primal objective function.[^o6][^o7][^o8][^o9][^o10][^o11][^o12][^o13][^o14]
