# Cyclic graph

::: {#o1 .subject cue=lead name="Cyclic graph"}

In mathematics, a **cyclic graph** may mean a graph that contains a cycle, or a graph that is a cycle, with varying definitions of cycles. See:

:::

- [Cycle (graph theory)](wikipedia://en/168609), a cycle in a graph
- [Forest (graph theory)](https://en.wikipedia.org/wiki/Forest_%28graph_theory%29), an undirected graph with no cycles
- [Biconnected graph](wikipedia://en/4989397), an undirected graph in which every edge belongs to a cycle
- [Directed acyclic graph](wikipedia://en/204002), a directed graph with no cycles
- [Strongly connected graph](https://en.wikipedia.org/wiki/Strongly_connected_graph), a directed graph in which every edge belongs to a cycle
- [Aperiodic graph](wikipedia://en/7220840), a directed graph in which the cycle lengths have no nontrivial common divisor
- [Pseudoforest](wikipedia://en/13511542), a directed or undirected graph in which every connected component includes at most one cycle
- [Cycle graph](wikipedia://en/878962), a graph that has the structure of a single cycle
- [Pancyclic graph](wikipedia://en/28691490), a graph that has cycles of all possible lengths
- [Cycle detection (graph theory)](https://en.wikipedia.org/wiki/Cycle_detection_%28graph_theory%29), the algorithmic problem of finding cycles in graphs

Other similarly-named concepts include

- [Cycle graph (algebra)](wikipedia://en/1681010), a graph that illustrates the cyclic subgroups of a group
- [Circulant graph](wikipedia://en/3498787), a graph with an [automorphism](wikipedia://en/15094186) which permutes its vertices cyclically.
