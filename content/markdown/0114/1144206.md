# Garden of Eden (cellular automaton)

*Image: Garden of Eden pattern.png.* A Garden of Eden in [Conway's Game of Life](wikipedia://en/37035), discovered by R. Banks in 1971.[^o14] The cells outside the image are all dead (white).

*Image: Garden of Eden 4.png.* An orphan in Life found by Achim Flammenkamp. Black squares are required live cells; blue x's are required dead cells.

::: {#o1 .subject cue=lead name="Garden of Eden"}

In a [cellular automaton](wikipedia://en/54342), a **Garden of Eden** is a configuration that has no predecessor. It can be the [initial configuration](wikipedia://en/1186804) of the automaton but cannot arise in any other way. [John Tukey](wikipedia://en/415974) named these configurations after the [Garden of Eden](https://en.wikipedia.org/wiki/Garden_of_Eden) in [Abrahamic religions](https://en.wikipedia.org/wiki/Abrahamic_religions), which was created out of nowhere.[^n1]

:::

A Garden of Eden is determined by the state of every cell in the automaton (usually a one- or two-dimensional infinite [square lattice](wikipedia://en/2874853) of cells). However, for any Garden of Eden there is at least one finite pattern (a subset of cells and their states, called an *orphan*) with the same property of having no predecessor, no matter how the remaining cells are filled in. A configuration of the whole automaton is a Garden of Eden [if and only if](wikipedia://en/14922) it contains an orphan. For one-dimensional cellular automata, orphans and Gardens of Eden can be found by an efficient algorithm, but for higher [dimensions](wikipedia://en/8398) this is an [undecidable problem](wikipedia://en/15631055). Nevertheless, computer searches have succeeded in finding these patterns in [Conway's Game of Life](wikipedia://en/37035).

The Garden of Eden theorem of [Moore](https://en.wikipedia.org/wiki/Edward_F._Moore) and [Myhill](wikipedia://en/2611636) asserts that a cellular automaton on the square grid, or on a tiling of any higher dimensional [Euclidean space](wikipedia://en/9697), has a Garden of Eden if and only if it has *twins*, two finite patterns that have the same successors whenever one is substituted for the other.

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A [cellular automaton](wikipedia://en/54342) is defined by a grid of cells, a finite set of states that can be assigned to each cell, and an update rule. Often, the grid of cells is the one- or two-dimensional infinite [square lattice](wikipedia://en/2874853). The update rule determines the next state of each cell as a function of its current state and of the current states of certain other nearby cells (the *neighborhood* of the cell). The neighborhood can be an arbitrary finite set of cells, but each two cells should have neighbors in the same relative positions and all cells must use the same update rule. A *configuration* of the automaton is an assignment of a state to every cell.[^o5]

The *successor* of a configuration is another configuration, formed by applying the update rule simultaneously to every cell.[^o6] The *transition function* of the automaton is the function that maps each configuration to its successor.[^o5] If the successor of configuration *X* is configuration *Y*, then *X* is a *predecessor* of *Y*. A configuration may have zero, one, or more predecessors, but it always has exactly one successor.[^o6] A Garden of Eden is defined to be a configuration with zero predecessors.[^o7]

A *pattern*, for a given cellular automaton, consists of a finite set of cells together with a state for each of those cells.[^o8] A configuration contains a pattern when the states of the cells in the pattern are the same as the states of the same cells in the configuration (without translating the cells before matching them). The definition of predecessors of configurations can be extended to predecessors of patterns: a predecessor of a pattern is just a configuration whose successor contains the pattern. An orphan, then, is a pattern with no predecessor.[^o8]

:::

## Searching for the Garden of Eden {#Searching_for_the_Garden_of_Eden}

For one-dimensional cellular automata, Gardens of Eden can be found by an efficient [algorithm](wikipedia://en/775) whose running time is polynomial in the size of the rule table of the automaton. For higher dimensions, determining whether a Garden of Eden exists is an [undecidable problem](wikipedia://en/15631055), meaning that there is no algorithm that can be guaranteed to terminate and produce the correct answer.[^o10] Nevertheless, in many cases it is possible to use the Garden of Eden theorem (below) to infer that a solution exists and then use a search algorithm to find one.

It would be possible for a computer program to search for orphan patterns by systematically examining all finite patterns, in order by increasing size, and by testing all possible predecessors for each pattern to determine whether it is in fact an orphan. However, the number of patterns that would need to be generated to find a Garden of Eden in this way is exponential in the area of the pattern. This enormous number of patterns would make this type of [brute-force search](https://en.wikipedia.org/wiki/Brute-force_search) prohibitively expensive, even for relatively small sizes of patterns.[^o11]

(txt) pioneered a more efficient computational approach for finding orphan patterns. His method is based on the theory of [formal languages](wikipedia://en/10939), and takes an amount of time that is exponential in the width of the pattern rather than its area. The key idea is that, for any fixed width, it is possible to construct a [nondeterministic finite automaton](wikipedia://en/653406) that recognizes patterns of a given width that have a predecessor. The input symbols to this machine describe each row of the pattern, and the states of the machine describe the nearby rows of possible predecessors for the part of the pattern that has been input so far. One can construct from this machine another finite state machine that recognizes the [complementary set](wikipedia://en/54347), the patterns that do not have predecessors, by converting the nondeterministic finite state machine to a [deterministic finite automaton](wikipedia://en/653404) by using the [powerset construction](wikipedia://en/1163167), and then complementing its set of accepting states. Once a machine recognizing the complementary set has been constructed, one may test whether the language it recognizes is empty, by searching for a path from the start state to an accepting state. This path, if it exists, gives a row-by-row description of an orphan pattern.[^n2]

[Martin Gardner](wikipedia://en/20435) credits [Alvy Ray Smith](https://en.wikipedia.org/wiki/Alvy_Ray_Smith) with the observation that the Garden of Eden theorem applies to [Conway's Game of Life](wikipedia://en/37035), and proves the existence of Gardens of Eden for this rule. The first explicit Garden of Eden in Life, with its live cells fitting in a $9 \times 33$ rectangle, was identified as a candidate to be a Garden of Eden by Roger Banks in 1971, and then verified by an exhaustive [backtracking search](https://en.wikipedia.org/wiki/Backtracking_search) for predecessors.[^o14] Subsequently, Hardouin-Duparc used his formal language approach to find the narrowest possible Gardens of Eden in Conway's Game of Life, with the [bounding box](https://en.wikipedia.org/wiki/Bounding_box) for their live cells being only six cells wide.[^n3]

The smallest known orphan pattern in Conway's Game of Life (by area of its bounding box) was found by Steven Eker in April 2016. It has 57 living cells and fits in an 8×12 rectangle.[^n4]

## Existence of orphans {#Existence_of_orphans}

By definition, every orphan belongs to a Garden of Eden: extending an orphan to a configuration of the whole automaton, by choosing a state for each remaining cell arbitrarily, will always produce a Garden of Eden. But the reverse is also true: every Garden of Eden contains at least one orphan.[^o19][^o18] To prove this, Kari[^o19] uses a topological argument, based on the [Curtis–Hedlund–Lyndon theorem](wikipedia://en/18903091) according to which the transition functions of cellular automata are exactly the translation-invariant [continuous functions](wikipedia://en/6122) on the space of configurations.[^o20] Here, continuity is defined by assigning a [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) to the finite set of states of the automaton, and then using a [product topology](wikipedia://en/24910) with one term in the product for each cell in the automaton to construct a [topological space](wikipedia://en/30450) whose points are the automaton's configurations. By [Tychonoff's theorem](wikipedia://en/82739) it is a [compact space](wikipedia://en/6042).[^o19]

For each finite pattern, the set of configurations that contain the pattern is an [open set](wikipedia://en/39358) in this topology, called a *cylinder*.[^o8] The cylinders form a [basis](wikipedia://en/59220) for the topology. As Kari observes, the collection of configurations that are not Gardens of Eden is just the image of the transition function, so by the [closed map lemma](https://en.wikipedia.org/wiki/Closed_map_lemma) for compact spaces it is a [closed set](wikipedia://en/47279). The set of Gardens of Eden, correspondingly, is an open set. Because it is open and the cylinders form a basis, the set of Gardens of Eden can be represented as a union of cylinders. Each of the cylinders in this union consists only of Gardens of Eden, so the pattern that determines each cylinder must be an orphan. If the set of Gardens of Eden is non-empty, there must be at least one cylinder in this union, so there must be at least one orphan. And any particular Garden of Eden must belong to one of these cylinders, and therefore must contain the orphan for that cylinder.[^o19]

::: {#o22 .statement cue=heading name="The Garden of Eden theorem"}

## The Garden of Eden theorem {#The_Garden_of_Eden_theorem}

In a cellular automaton, two finite patterns are *twins* if one can be substituted for the other wherever it appears, without changing future configurations. A cellular automaton is [injective](wikipedia://en/45196) if every pair of distinct configurations of the automaton remain different after a step of the automaton, and locally injective if it has no twins. It is [surjective](wikipedia://en/27873) if and only if every configuration has a predecessor; that is, if and only if it has no Garden of Eden configuration. An automaton that is both injective and surjective is called a [reversible cellular automaton](wikipedia://en/30766907).[^o5]

The **Garden of Eden theorem**, due to (txt) and (txt), asserts that a cellular automaton in a [Euclidean space](wikipedia://en/9697) is locally injective if and only if it is surjective. In other words, it asserts that a cellular automaton has a Garden of Eden, if and only if it has twins. More strongly, every non-locally-injective cellular automaton has an orphan pattern. An immediate corollary is that an injective cellular automaton must be surjective. Moore proved one direction of the theorem, that automata with twins have orphans;[^n1] Myhill proved the converse, that an automaton with an orphan also has twins.[^n5]

In the case of Conway's Game of Life, twins are much easier to find than orphans. For instance, a five-by-five block of dead cells and a five-by-five block with its center cell live and the remaining cells dead are twins: the state of the center cell cannot affect later configurations of the pattern. Thus, in this case, the Garden of Eden theorem allows the existence of a Garden of Eden to be demonstrated much more easily than by finding an explicit orphan pattern.[^n6]

::: {#o29 .proof cue=heading name="Proof sketch"}

### Proof sketch {#Proof_sketch}

The main idea of the proof of the theorem is to use a [counting argument](wikipedia://en/741875), to show that any failure of local injectivity (twin patterns) leads to an orphan pattern, and vice versa. In more detail, suppose for concreteness that the underlying lattice of the automaton is a two-dimensional square grid, that it has $s$ different cell states, that the twin patterns $P$ and $Q$ both fit into an $n \times n$ square, and that the radius of any cell's neighborhood is at most $n$. Then, in order to determine whether a pattern that fits within an $mn \times mn$ square is an orphan, one need only look at the parts of potential predecessors that fit within an $(m + 2)n \times (m + 2)n$ square and that do not contain pattern $Q$. But there are only $(s^{n \times n} - 1)^{(m + 2) \times (m + 2)}$ of these potential predecessors. For sufficiently large values of $m$ this number is smaller than the number $s^{mn \times mn}$ of potential orphans. Therefore, one of the potential orphans has no predecessor and is really an orphan; that is, non-injectivity implies non-surjectivity. Conversely (letting $n$ be the size of a [bounding box](https://en.wikipedia.org/wiki/Bounding_box) of an orphan) a very similar counting argument shows that the number of patterns that fit within an $(m + 2)n \times (m + 2)n$ square and do not contain an orphan is too small to provide a distinct successor to every starting pattern within an $mn \times mn$ square, overlayed over some arbitrary-but-unchanging background. From this it follows that two background-framed $(m + 2)n \times (m + 2)n$ patterns are twins, so non-surjectivity implies local non-injectivity.[^n5]

:::

### Injectivity versus local injectivity {#Injectivity_versus_local_injectivity}

*Image: Rule90rand-expanded.png.* Time-space diagram of [Rule 90](wikipedia://en/16572515), which has no Garden of Eden despite being non-injective. Each row depicts a configuration, with time progressing downwards.

The distinction between injectivity and local injectivity in the theorem is necessary, as there exist cellular automata that are locally injective but not injective. One example is [Rule 90](wikipedia://en/16572515), the one-dimensional binary automaton whose update rule replaces each cell's state with the [exclusive or](wikipedia://en/105979) of its two neighbors. In this automaton, every configuration has two predecessors, so it is not injective but also has no Garden of Eden.[^n7]

### With quiescent states {#With_quiescent_states}

In automata such as [Conway's Game of Life](wikipedia://en/37035), there is a special "quiescent" state such that a quiescent cell whose neighborhood is entirely quiescent remains quiescent. In this case one may define a "finite configuration" to be a configuration with only finitely many non-quiescent cells. Any non-locally-injective cellular automaton with a quiescent state has Gardens of Eden that are themselves finite configurations, for instance any finite configuration that contains an orphan. It may also be possible for an automaton to have a finite configuration whose only predecessors are not finite (for instance, in Rule 90, a configuration with a single live cell has this property). However, the Garden of Eden theorem does not characterize the existence of such patterns.[^o34]

### In non-Euclidean geometries {#In_non-Euclidean_geometries}

In cellular automata defined over tessellations of the [hyperbolic plane](wikipedia://en/318742), or of higher-dimensional hyperbolic spaces, the counting argument in the proof of the Garden of Eden theorem does not work, because it depends implicitly on the property of Euclidean spaces that the boundary of a region grows less quickly than its volume as a function of the radius. There exist hyperbolic cellular automata that have twins but that do not have a Garden of Eden, and other hyperbolic cellular automata that have a Garden of Eden but do not have twins; these automata can be defined, for instance, in a rotation-invariant way on the [uniform hyperbolic tilings](wikipedia://en/18640974) in which three [heptagons](wikipedia://en/365349) meet at each vertex, or in which four [pentagons](wikipedia://en/20741014) meet at each vertex.[^o36]

However, the Garden of Eden theorem can be generalized beyond Euclidean spaces, to cellular automata defined on the elements of an [amenable group](wikipedia://en/657430).[^o37] A weaker form of the Garden of Eden theorem asserts that every injective cellular automaton is surjective. It can be proven for [sofic groups](wikipedia://en/37690209) using the [Ax–Grothendieck theorem](wikipedia://en/21867395), an analogous relation between injectivity and bijectivity in algebraic geometry.[^n8] More generally, the groups for which this weaker form holds are called [surjunctive groups](wikipedia://en/37698505).[^n9] There are no known examples of groups that are not surjunctive.[^n10]

:::

## In fiction {#In_fiction}

In [Greg Egan](https://en.wikipedia.org/wiki/Greg_Egan)'s novel *[Permutation City](https://en.wikipedia.org/wiki/Permutation_City)*, the protagonist uses a Garden of Eden configuration to create a situation in which a copy of himself can prove that he is living within a simulation. Previously all his simulated copies had found themselves in some variant of the "real world"; although they had memories of being simulated copies living in a simulation, there was always a simpler explanation for how those memories came to be. The Garden of Eden configuration, however, cannot occur except in an intelligently designed simulation. The religious parallels are intentional.[^o42]
