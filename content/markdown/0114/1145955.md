# NL (complexity)

::: {#o1 .subject cue=lead name="NL"}

::: {#o2 .problem cue=unsolved}

$$\mathsf{L \overset?= NL}$$

:::

In [computational complexity theory](wikipedia://en/7543), **NL** (**N**ondeterministic **L**ogarithmic-space) is the [complexity class](wikipedia://en/502426) containing [decision problems](wikipedia://en/8336) that can be solved by a [nondeterministic Turing machine](wikipedia://en/21935) using a [logarithmic](wikipedia://en/17860) amount of [memory space](https://en.wikipedia.org/wiki/Memory_space_%28computational_resource%29).

:::

**NL** is a generalization of **[L](wikipedia://en/1149999)**, the class for logspace problems on a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine). Since any deterministic Turing machine is also a [nondeterministic Turing machine](wikipedia://en/21935), we have that **L** is contained in **NL**.

**NL** can be formally defined in terms of the computational resource [nondeterministic space](https://en.wikipedia.org/wiki/Nondeterministic_space) (or NSPACE) as **NL** = **NSPACE**(log *n*).

Important results in complexity theory allow us to relate this complexity class with other classes, telling us about the relative power of the resources involved. Results in the field of [algorithms](wikipedia://en/775), on the other hand, tell us which problems can be solved with this resource. Like much of complexity theory, many important questions about **NL** are still [open](wikipedia://en/1333335) (see [Unsolved problems in computer science](https://en.wikipedia.org/wiki/Unsolved_problems_in_computer_science)).

Occasionally **NL** is referred to as **RL** due to its probabilistic definition below; however, this name is more frequently used to refer to [randomized logarithmic space](wikipedia://en/1176581), which is not known to equal **NL**.

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There are several equivalent definitions of the **NL** class.

### Standard definition {#Standard_definition}

**NL** is the complexity class of decision problems that can be solved by a nondeterministic Turing machine (NTM) using a logarithmic amount of memory space.

In more detail, a language $L$ is NL iff there exists a NTM $M$ such that

- $M$ runs on logspace.
- $M$ always halts.
- If $x \in L$, then there exists at least one computational trace of $M(x)$ that results in the machine halting in an accepting state.
- If $x \not\in L$, then all computational traces of $M(x)$ results in the machine halting in an unaccepting state.

::: {#o7 .pointer-item cue=pointer name="ZPL (complexity)"}

### Probabilistic definition {#Probabilistic_definition}

Suppose *C* is the [complexity class](wikipedia://en/502426) of [decision problems](https://en.wikipedia.org/wiki/Decision_problems) solvable in logarithmithic space with [probabilistic Turing machines](wikipedia://en/197812) that never accept incorrectly but are allowed to reject incorrectly less than 1/3 of the time; this is called *one-sided error*. The constant 1/3 is arbitrary; any *x* with 0 ≤ *x* \< 1/2 would suffice.

It turns out that *C* = **NL**. Notice that *C*, unlike its deterministic counterpart **[L](wikipedia://en/1149999)**, is not limited to polynomial time, because although it has a polynomial number of configurations it can use randomness to escape an infinite loop. If we do limit it to polynomial time, we get the class **[RL](wikipedia://en/1176581)**, which is contained in but not known or believed to equal **NL**.

There is a simple algorithm that establishes that *C* = **NL**. Clearly *C* is contained in **NL**, since:

- If the string is not in the language, both reject along all computation paths.
- If the string is in the language, an **NL** algorithm accepts along at least one computation path and a *C* algorithm accepts along at least two-thirds of its computation paths.

To show that **NL** is contained in *C*, we simply take an **NL** algorithm and choose a random computation path of length *n*, and execute this 2<sup>*n*</sup> times. Because no computation path exceeds length *n*, and because there are 2<sup>*n*</sup> computation paths in all, we have a good chance of hitting the accepting one (bounded below by a constant).

The only problem is that we don't have room in log space for a binary counter that goes up to 2<sup>*n*</sup>. To get around this we replace it with a *randomized* counter, which simply flips *n* coins and stops and rejects if they all land on heads. Since this event has probability 2<sup>−*n*</sup>, we [expect](wikipedia://en/9653) to take 2<sup>*n*</sup> steps on average before stopping. It only needs to keep a running total of the number of heads in a row it sees, which it can count in log space.

Because of the [Immerman–Szelepcsényi theorem](wikipedia://en/2827371), according to which NL is closed under complements, the one-sided error in these probabilistic computations can be replaced by zero-sided error. That is, these problems can be solved by probabilistic Turing machines that use logarithmic space and never make errors. The corresponding complexity class that also requires the machine to use only polynomial time is called [ZPLP](https://en.wikipedia.org/wiki/ZPLP_%28complexity%29).

Thus, when we only look at space, it seems that randomization and nondeterminism are equally powerful.

:::

### Certificate definition {#Certificate_definition}

**NL** can equivalently be characterised by [certificates](wikipedia://en/14933760), analogous to classes such as **[NP](wikipedia://en/21562)**. Let a *verifier* be a deterministic logarithmic-space bounded deterministic Turing machine that has an additional read-only read-once input tape (that is, the verifier may only move the read-head forwards, never backwards).

A language $L$ is in **NL** if and only if[^o9]

- There exists a polynomial function $p$.
- There exists a verifier $TM$.
- For any $x$, $x \in L$ iff there exists a certificate $u$ with length $|u| \leq p(|x|)$, such that $TM(x, u) = 1$.

In words, it means that if a sentence is in the language, then there exists a polynomial-length proof that it is in the language. It does not say anything about the case where the sentence is *not* in the language, though by the Immerman–Szelepcsényi theorem, it is clear that there exists some verifier that can verify both $x \in L$ and $x \not\in L$.

Note that the read-once condition is necessary. If the verifier can read forwards and backwards, this extends the class to the **NP** class.[^o9]

[Cem Say](https://en.wikipedia.org/wiki/Cem_Say) and Abuzer Yakaryılmaz have proven that the deterministic logarithmic-space Turing machine in the statement above can be replaced by a bounded-error probabilistic constant-space Turing machine that is allowed to use only a constant number of random bits.[^o10]

### Descriptive definition {#Descriptive_definition}

In [descriptive complexity theory](wikipedia://en/1212009), **NL** is defined as those languages expressible in [first-order logic](wikipedia://en/10983) with an added [transitive closure](wikipedia://en/292239) operator.

:::

## Closure properties {#Closure_properties}

The class NL is closed under the operations complementation, union, and therefore intersection, [concatenation](wikipedia://en/64474#Concatenation_of_sets_of_strings), and [Kleene star](wikipedia://en/16750).

## NL-completeness {#NL-completeness}

A problem is **[NL-complete](wikipedia://en/4595166)** if it is **NL**, and any problem in **NL** is [log-space reducible](wikipedia://en/1174850) to it.

Problems that are known to be **NL**-complete including [ST-connectivity](https://en.wikipedia.org/wiki/ST-connectivity) and [2-satisfiability](https://en.wikipedia.org/wiki/2-satisfiability).

[ST-connectivity](https://en.wikipedia.org/wiki/ST-connectivity) asks, for nodes *S* and *T* in a [directed graph](wikipedia://en/19721986), whether *T* is [reachable](wikipedia://en/2833097) from *S*.

[2-satisfiability](https://en.wikipedia.org/wiki/2-satisfiability) asks, given a [propositional](wikipedia://en/18154) formula of which each clause is the [disjunction](https://en.wikipedia.org/wiki/Disjunction) of two literals, if there is a variable assignment that makes the formula true. An example instance, where $\neg$ indicates *not*, might be:

$$(x_1 \vee \neg x_3) \wedge (\neg x_2 \vee x_3) \wedge (\neg x_1 \vee \neg x_2)$$

## Containments {#Containments}

It is known that NL is contained in [P](wikipedia://en/658550), since there is a [polynomial-time algorithm](https://en.wikipedia.org/wiki/Polynomial-time_algorithm) for [2-satisfiability](https://en.wikipedia.org/wiki/2-satisfiability), but it is not known whether NL = P or whether L = NL. It is known that NL = co-NL, where co-NL is the class of languages whose [complements](wikipedia://en/1929955) are in NL. This result (the [Immerman–Szelepcsényi theorem](wikipedia://en/2827371)) was independently discovered by [Neil Immerman](https://en.wikipedia.org/wiki/Neil_Immerman) and [Róbert Szelepcsényi](https://en.wikipedia.org/wiki/Róbert_Szelepcsényi) in 1987; they received the 1995 [Gödel Prize](https://en.wikipedia.org/wiki/Gödel_Prize) for this work.

In [circuit complexity](wikipedia://en/7641969), NL can be placed within the [NC](wikipedia://en/22073) hierarchy. In Papadimitriou 1994, Theorem 16.1, we have:

$$\mathsf{NC_1 \subseteq L \subseteq NL \subseteq NC_2}.$$

More precisely, NL is contained in [AC<sup>1</sup>](wikipedia://en/7401755). It is known that NL is equal to [ZPL](https://en.wikipedia.org/wiki/ZPL_%28complexity%29), the class of problems solvable by randomized algorithms in logarithmic space and unbounded time, with no error. It is not, however, known or believed to be equal to [RLP](https://en.wikipedia.org/wiki/RLP_%28complexity%29) or [ZPLP](https://en.wikipedia.org/wiki/ZPLP_%28complexity%29), the polynomial-time restrictions of RL and ZPL, which some authors refer to as RL and ZPL.

We can relate NL to deterministic space using [Savitch's theorem](wikipedia://en/658501), which tells us that any nondeterministic algorithm can be simulated by a deterministic machine in at most quadratically more space. From Savitch's theorem, we have directly that:

$$\mathsf{NL \subseteq SPACE}(\log^2 n) \ \ \ \ \text{equivalently, } \mathsf{NL \subseteq L}^2.$$

This was the strongest deterministic-space inclusion known in 1994 (Papadimitriou 1994 Problem 16.4.10, "Symmetric space"). Since larger space classes are not affected by quadratic increases, the nondeterministic and deterministic classes are known to be equal, so that for example we have [PSPACE](wikipedia://en/39351) = [NPSPACE](https://en.wikipedia.org/wiki/NPSPACE).
