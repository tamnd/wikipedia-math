# Hilbert's irreducibility theorem

::: {#o1 .subject cue=lead name="Hilbert's irreducibility theorem"}

In [number theory](wikipedia://en/21527), **Hilbert's irreducibility theorem**, conceived by [David Hilbert](wikipedia://en/8302) in 1892, states that every finite set of [irreducible polynomials](wikipedia://en/188725) in a finite number of variables and having [rational number](wikipedia://en/19727024) coefficients admit a common specialization of a proper subset of the variables to rational numbers such that all the polynomials remain irreducible. This theorem is a prominent theorem in number theory.

:::

::: {#o3 .statement kind=statement/theorem cue=named-heading name="Formulation of the theorem"}

## Formulation of the theorem {#Formulation_of_the_theorem}

**Hilbert's irreducibility theorem.** Let

$$f_1(X_1, \ldots, X_r, Y_1, \ldots, Y_s), \ldots, f_n(X_1, \ldots, X_r, Y_1, \ldots, Y_s)$$

be irreducible polynomials in the ring

$$\mathbb{Q}(X_1, \ldots, X_r)[Y_1, \ldots, Y_s].$$

Then there exists an *r*-tuple of rational numbers (*a*<sub>1</sub>, ..., *a<sub>r</sub>*) such that

$$f_1(a_1, \ldots, a_r, Y_1,\ldots, Y_s), \ldots, f_n(a_1, \ldots, a_r, Y_1,\ldots, Y_s)$$

are irreducible in the ring

$$\mathbb{Q}[Y_1,\ldots, Y_s].$$

**Remarks.**

- It follows from the theorem that there are infinitely many *r*-tuples. In fact the set of all irreducible specializations, called Hilbert set, is large in many senses. For example, this set is [Zariski dense](wikipedia://en/241744) in $\mathbb{Q}^r.$
- There are always (infinitely many) integer specializations, i.e., the assertion of the theorem holds even if we demand (*a*<sub>1</sub>, ..., *a<sub>r</sub>*) to be integers.
- There are many [Hilbertian fields](https://en.wikipedia.org/wiki/Hilbertian_field), i.e., fields satisfying Hilbert's irreducibility theorem. For example, [number fields](https://en.wikipedia.org/wiki/Number_field) are Hilbertian.[^o4]
- The irreducible specialization property stated in the theorem is the most general. There are many reductions, e.g., it suffices to take $n=r=s=1$ in the definition. A result of Bary-Soroker shows that for a field *K* to be Hilbertian it suffices to consider the case of $n=r=s=1$ and $f=f_1$ [absolutely irreducible](https://en.wikipedia.org/wiki/Absolutely_irreducible), that is, irreducible in the ring *K*<sup>alg</sup>\[*X*,*Y*\], where *K*<sup>alg</sup> is the algebraic closure of *K*.

:::

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

Hilbert's irreducibility theorem has numerous applications in [number theory](wikipedia://en/21527) and [algebra](wikipedia://en/18716923). For example:

- The [inverse Galois problem](wikipedia://en/739166), Hilbert's original motivation. The theorem almost immediately implies that if a finite group *G* can be realized as the Galois group of a Galois extension *N* of

$$E=\mathbb{Q}(X_1, \ldots, X_r),$$

then it can be specialized to a Galois extension *N*<sub>0</sub> of the rational numbers with *G* as its Galois group.[^o7] (To see this, choose a monic irreducible polynomial *f*(*X*<sub>1</sub>, ..., *X<sub>n</sub>*, *Y*) whose root generates *N* over *E*. If *f*(*a*<sub>1</sub>, ..., *a<sub>n</sub>*, *Y*) is irreducible for some *a<sub>i</sub>*, then a root of it will generate the asserted *N*<sub>0</sub>.)

- Construction of elliptic curves with large rank.[^o7]
- Hilbert's irreducibility theorem is used as a step in the [Andrew Wiles](wikipedia://en/2027) proof of [Fermat's Last Theorem](wikipedia://en/19021953).
- If a polynomial $g(x) \in \mathbb{Z}[x]$ is a perfect square for all large integer values of *x*, then *g(x)* is the square of a polynomial in $\mathbb{Z}[x].$ This follows from Hilbert's irreducibility theorem with $n=r=s=1$ and

$$f_1(X, Y) = Y^2 - g(X).$$

(More elementary proofs exist.) The same result is true when "square" is replaced by "cube", "fourth power", etc.

:::

## Generalizations {#Generalizations}

It has been reformulated and generalized extensively, by using the language of [algebraic geometry](wikipedia://en/1997). See [thin set (Serre)](wikipedia://en/3143411).
