# FreeOTP

::: {#o3 .subject cue=lead name="FreeOTP"}

**FreeOTP** is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source) [authenticator](wikipedia://en/40745) by [Red Hat](https://en.wikipedia.org/wiki/Red_Hat). It implements [multi-factor authentication](https://en.wikipedia.org/wiki/Multi-factor_authentication) using [HOTP](https://en.wikipedia.org/wiki/HOTP) and [TOTP](https://en.wikipedia.org/wiki/Time-based_One-time_Password_Algorithm). [Tokens](https://en.wikipedia.org/wiki/Tokenization_%28data_security%29) can be added by scanning a [QR code](https://en.wikipedia.org/wiki/QR_code) or by manually entering the token configuration. It is licensed under the [Apache 2.0 license](https://en.wikipedia.org/wiki/Apache_License), and supports [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29) and [iOS](https://en.wikipedia.org/wiki/IOS).[^o4][^o5][^o6]

:::
