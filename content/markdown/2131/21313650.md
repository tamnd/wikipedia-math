# Exponential field

::: {#o1 .subject cue=lead name="Exponential field"}

In [mathematics](wikipedia://en/18831), an **exponential field** is a [field](wikipedia://en/10603) with a further [unary operation](wikipedia://en/161006) that is a [homomorphism](wikipedia://en/13564) from the field's additive group to its multiplicative group. This generalizes the usual idea of [exponentiation](wikipedia://en/99491) on the [real numbers](wikipedia://en/20646438), where the base is a chosen positive real number.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A field is an [algebraic structure](wikipedia://en/106364) composed of a set of elements $F$ and two [binary operations](wikipedia://en/3948), addition ($+$) and multiplication ($\cdot$), such that $F$ forms an [abelian group](wikipedia://en/2974) under addition with identity $0_F$ and $F$ excluding $0_F$ forms an abelian group under multiplication with identity $1_F$. Moreover, multiplication is distributive over addition; that is, for any elements $a,b,c$ in $F$, one has

$$a\cdot(b+c)=a\cdot b+a\cdot c.$$

If there is also a [function](wikipedia://en/185427) $E$ that maps $F$ into $F$, and such that for every $a$ and $b$ in $F$ one has

$$\begin{aligned}&E(a+b)=E(a)\cdot E(b),\\&E(0_F)=1_F, \end{aligned}$$

then $F$ is called an exponential field, and the function $E$ is called an exponential function on $F$.[^n1] Thus an exponential function on a field is a [homomorphism](wikipedia://en/13564) between the additive group of $F$ and its multiplicative group.

:::

## Trivial exponential function {#Trivial_exponential_function}

There is a trivial exponential function on any field, namely, the map that sends every element to the identity element of the field under multiplication. Thus, every field is trivially an exponential field, so the cases of interest to mathematicians occur when the exponential function is non-trivial.

Exponential fields are sometimes required to have [characteristic](wikipedia://en/1066621) zero as the only exponential function on a field with nonzero characteristic is the trivial one.[^n2] To see this, first note that for any element $x$ in a field $F$ with characteristic $p>0$,

$$1=E(0)=E(\underbrace{x+x+\cdots+x}_{p\text{ times}})=E(x)E(x)\cdots E(x)=E(x)^p.$$

Hence

$$E(x)^p-1=E(x)^p-1^p=(E(x)-1)^p=0$$

and so $E(x)=1$ for all $x$ in $F$.[^n3]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- The field of real numbers $\mathbb{R}$, formally $(\mathbb{R},+,\cdot,0,1)$, has infinitely many exponential functions. One such function is the usual [exponential function](wikipedia://en/9678) $E(x)=e^x$, since we have $e^{x+y}=e^xe^y$ and $e^0=1$ as required. Considering the [ordered field](wikipedia://en/22430) $\mathbb{R}$ equipped with this function gives the ordered real exponential field, denoted $\mathbb{R}_{\text{exp}}=(\mathbb{R},+,\cdot,<,0,1,\operatorname{exp})$.
- Any real number $a>0$ gives an exponential function on $\mathbb{R}$, where the map $E(x)=a^x$ satisfies the required properties.
- Analogously to the real exponential field, there is the [complex](wikipedia://en/5826) exponential field, $\mathbb{C}_{\text{exp}}=(\mathbb{C},+,\cdot,0,1,\operatorname{exp})$. However, this field is not ordered.
- Boris Zilber constructed an exponential field that, crucially, satisfies the equivalent formulation of [Schanuel's conjecture](wikipedia://en/2031353) with the field's exponential function.[^n4] It is conjectured that this exponential field is actually $\mathbb{C}_{\text{exp}}$, and a proof of this fact would thus prove Schanuel's conjecture.

:::

## Exponential rings {#Exponential_rings}

The underlying set $F$ may not be required to be a field but instead allowed to simply be a [ring](wikipedia://en/48404), $R$, and concurrently the exponential function is relaxed to be a homomorphism from the additive group in $R$ to the multiplicative group of [units](wikipedia://en/289666) $R^\times$. The resulting object is called an **exponential ring**.[^n2]

An example of an exponential ring with a non-trivial exponential function is the ring of integers $\mathbb{Z}$ equipped with the function $E$ which takes the value $1$ at even integers and $-1$ at odd integers, i.e., the function $n \mapsto (-1)^n$. This exponential function, and the trivial one, are the only two functions on $\mathbb{Z}$ that satisfy the conditions.[^n5]

::: {#o15 .statement kind=statement/conjecture cue=heading name="Open problems"}

## Open problems {#Open_problems}

Exponential fields are much-studied objects in [model theory](wikipedia://en/19858), occasionally providing a link between it and [number theory](wikipedia://en/21527) as in the case of [Zilber](wikipedia://en/47992829)'s work on [Schanuel's conjecture](wikipedia://en/2031353). It was proved in the 1990s that $\mathbb{R}_{\text{exp}}$ is [model complete](wikipedia://en/15931153), a result known as [Wilkie's theorem](wikipedia://en/22304328). This result, when combined with [Khovanskii](wikipedia://en/43849047)'s theorem on [Pfaffian functions](wikipedia://en/14644287), proves that $\mathbb{R}_{\text{exp}}$ is also [o-minimal](https://en.wikipedia.org/wiki/O-minimal).[^n6] On the other hand, it is known that $\mathbb{C}_{\text{exp}}$ is not model complete.[^n7] The question of [decidability](wikipedia://en/913118) is still unresolved. [Alfred Tarski](wikipedia://en/59920) posed the question of the decidability of $\mathbb{R}_{\text{exp}}$ and hence it is now known as [Tarski's exponential function problem](wikipedia://en/16073214). It is known that if the real version of Schanuel's conjecture is true then $\mathbb{R}_{\text{exp}}$ is decidable.[^o18]

:::
