# Point-finite collection

::: {#o1 .subject cue=lead name="Point-finite collection"}

In [mathematics](wikipedia://en/18831), a collection or [family](wikipedia://en/723043) $\mathcal{U}$ of subsets of a [topological space](wikipedia://en/30450) $X$ is said to be **point-finite** if every point of $X$ lies in only finitely many members of $\mathcal{U}.$[^n1][^o3]

:::

A [metacompact space](wikipedia://en/5074872) is a topological space in which every [open cover](https://en.wikipedia.org/wiki/Open_cover) admits a point-finite open [refinement](https://en.wikipedia.org/wiki/Refinement_%28topology%29). Every [locally finite collection](wikipedia://en/11611098) of subsets of a topological space is also point-finite. A topological space in which every open cover admits a locally finite open refinement is called a [paracompact space](wikipedia://en/48631). Every paracompact space is therefore metacompact.[^o3]

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Dieudonné's theorem"}

## Dieudonné's theorem {#Dieudonné's_theorem}

::: {#o6 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

[^o7][^n2] A topological space $X$ is [normal](wikipedia://en/48629) if and only if each point-finite open cover of $X$ has a [shrinking](https://en.wikipedia.org/wiki/Shrinking_%28topology%29); that is, if $\{ U_i \mid i \in I \}$ is an open cover indexed by a set $I$, there is an open cover $\{ V_i \mid i \in I \}$ indexed by the same set $I$ such that $\overline{V_i} \subset U_i$ for each $i \in I$.

:::

The original proof uses [Zorn's lemma](wikipedia://en/51442), while Willard uses [transfinite recursion](https://en.wikipedia.org/wiki/Transfinite_recursion).

:::
