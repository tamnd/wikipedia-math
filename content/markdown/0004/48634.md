# Nowhere dense set

::: {#o1 .subject cue=lead name="Nowhere dense set"}

In [mathematics](wikipedia://en/18831), a [subset](wikipedia://en/26691) of a [topological space](wikipedia://en/30450) is called **nowhere dense**[^n1][^n2] or **rare**[^n3] if its [closure](wikipedia://en/42309) has [empty](wikipedia://en/9566) [interior](wikipedia://en/55610). In a very loose sense, it is a set whose elements are not tightly clustered (as defined by the [topology](wikipedia://en/30450#Definitions) on the space) anywhere. For example, the [integers](wikipedia://en/14563) are nowhere dense among the [reals](wikipedia://en/20646438), whereas the [interval](wikipedia://en/49172) (0, 1) is not nowhere dense.

:::

A countable union of nowhere dense sets is called a [meagre set](wikipedia://en/226975). Meagre sets play an important role in the formulation of the [Baire category theorem](wikipedia://en/55227), which is used in the proof of several fundamental results of [functional analysis](wikipedia://en/11180).

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Density nowhere can be characterized in different (but equivalent) ways. The simplest definition is the one from density:

> A subset $S$ of a [topological space](wikipedia://en/30450) $X$ is said to be ***dense*** in another set $U$ if the intersection $S \cap U$ is a [dense subset](wikipedia://en/23523594) of $U.$ The set $S$ is **nowhere dense** or **rare** in $X$ if $S$ is not dense in any nonempty open subset $U$ of $X.$

Expanding out the negation of density, it is equivalent that each nonempty [open set](wikipedia://en/39358) $U$ contains a nonempty open subset disjoint from $S.$[^n4] It suffices to check either condition on a [base](wikipedia://en/59220) for the topology on $X.$ In particular, density nowhere in $\mathbb{R}$ is often described as being dense in no [open interval](https://en.wikipedia.org/wiki/Open_Interval).[^o8][^o9]

### Definition by closure {#Definition_by_closure}

The second definition above is equivalent to requiring that the closure, $\operatorname{cl}_X S,$ cannot contain any nonempty open set.[^o11] This is the same as saying that the [interior](wikipedia://en/55610) of the [closure](wikipedia://en/42309) of $S$ is empty; that is,

> $\operatorname{int}_X \left(\operatorname{cl}_X S\right) = \varnothing.$[^o12][^n5]

Alternatively, the complement of the closure $X \setminus \left(\operatorname{cl}_X S\right)$ must be a dense subset of $X;$[^n4][^o12] in other words, the [exterior](https://en.wikipedia.org/wiki/Exterior_%28topology%29) of $S$ is dense in $X.$

:::

::: {#o16 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The notion of *nowhere dense set* is always relative to a given surrounding space. Suppose $A\subseteq Y\subseteq X,$ where $Y$ has the [subspace topology](wikipedia://en/910926) induced from $X.$ The set $A$ may be nowhere dense in $X,$ but not nowhere dense in $Y.$ Notably, a set is always dense in its own subspace topology. So if $A$ is nonempty, it will not be nowhere dense as a subset of itself. However the following results hold:[^n6][^n7]

- If $A$ is nowhere dense in $Y,$ then $A$ is nowhere dense in $X.$
- If $Y$ is open in $X$, then $A$ is nowhere dense in $Y$ if and only if $A$ is nowhere dense in $X.$
- If $Y$ is dense in $X$, then $A$ is nowhere dense in $Y$ if and only if $A$ is nowhere dense in $X.$

A set is nowhere dense if and only if its closure is.[^n1]

Every subset of a nowhere dense set is nowhere dense, and a finite [union](wikipedia://en/47949) of nowhere dense sets is nowhere dense.[^n8][^n9] Thus the nowhere dense sets form an [ideal of sets](https://en.wikipedia.org/wiki/Ideal_of_sets), a suitable notion of [negligible set](wikipedia://en/195132). In general they do not form a [𝜎-ideal](wikipedia://en/1567410), as [meager sets](https://en.wikipedia.org/wiki/Meager_set), which are the countable unions of nowhere dense sets, need not be nowhere dense. For example, the set $\mathbb{Q}$ is not nowhere dense in $\mathbb{R}.$

The [boundary](wikipedia://en/72824) of every open set and of every closed set is closed and nowhere dense.[^n10][^n2] A closed set is nowhere dense if and only if it is equal to its boundary,[^n10] if and only if it is equal to the boundary of some open set[^n2] (for example the open set can be taken as the complement of the set). An arbitrary set $A\subseteq X$ is nowhere dense if and only if it is a subset of the boundary of some open set (for example the open set can be taken as the [exterior](https://en.wikipedia.org/wiki/Exterior_%28topology%29) of $A$).

:::

## Examples {#Examples}

- The set $S=\{1/n:n=1,2,...\}$ and its closure $S\cup\{0\}$ are nowhere dense in $\mathbb{R},$ since the closure has empty interior.
- The [Cantor set](wikipedia://en/6172) is an uncountable nowhere dense set in $\mathbb{R}.$
- $\mathbb{R}$ viewed as the horizontal axis in the Euclidean plane is nowhere dense in $\mathbb{R}^2.$
- $\mathbb{Z}$ is nowhere dense in $\mathbb{R}$ but the rationals $\mathbb{Q}$ are not (they are dense everywhere).
- $\mathbb{Z} \cup [(a, b) \cap \mathbb{Q}]$ is **not** nowhere dense in $\mathbb{R}$: it is dense in the open interval $(a,b),$ and in particular the interior of its closure is $(a,b).$
- The empty set is nowhere dense. In a [discrete space](wikipedia://en/56061), the empty set is the only nowhere dense set.[^n11]
- In a [T<sub>1</sub> space](wikipedia://en/148721), any singleton set that is not an [isolated point](wikipedia://en/390557) is nowhere dense.
- A [vector subspace](https://en.wikipedia.org/wiki/Vector_subspace) of a [topological vector space](wikipedia://en/45752) is either dense or nowhere dense.[^n12]

:::

## Nowhere dense sets with positive measure {#Nowhere_dense_sets_with_positive_measure}

A nowhere dense set is not necessarily negligible in every sense. For example, if $X$ is the [unit interval](wikipedia://en/49324) $[0, 1],$ not only is it possible to have a dense set of [Lebesgue measure](wikipedia://en/18198) zero (such as the set of rationals), but it is also possible to have a nowhere dense set with positive measure. One such example is the [Smith–Volterra–Cantor set](wikipedia://en/922382).

For another example (a variant of the [Cantor set](wikipedia://en/6172)), remove from $[0, 1]$ all [dyadic fractions](https://en.wikipedia.org/wiki/Dyadic_fraction), i.e. fractions of the form $a/2^n$ where $a, n \in \mathbb{N}^*$ such that $1\leq a < 2^n$ is odd, and the intervals around them: $\left(a/2^n - 1/2^{2n+1}, a/2^n + 1/2^{2n+1}\right).$ Since for each $n$ this removes intervals adding up to at most $1/2^{n+1},$ the nowhere dense set remaining after all such intervals have been removed has measure of at least $1/2$ (in fact just over $0.535\ldots$ because of overlaps[^o31]) and so in a sense represents the majority of the ambient space $[0, 1].$ This set is nowhere dense, as it is closed and has an empty interior: any interval $(a, b)$ is not contained in the set since the dyadic fractions in $(a, b)$ have been removed.

Generalizing this method, one can construct in the unit interval nowhere dense sets of any measure less than $1,$ although the measure cannot be exactly 1 (because otherwise the complement of its closure would be a nonempty open set with measure zero, which is impossible).[^o32]

For another simpler example, if $U$ is any dense open subset of $\mathbb{R}$ having finite [Lebesgue measure](wikipedia://en/18198) then $\mathbb{R} \setminus U$ is necessarily a closed subset of $\mathbb{R}$ having infinite Lebesgue measure that is also nowhere dense in $\mathbb{R}$ (because its topological interior is empty). Such a dense open subset $U$ of finite Lebesgue measure is commonly constructed when proving that the Lebesgue measure of the rational numbers $\mathbb{Q}$ is $0.$ This may be done by choosing any [bijection](wikipedia://en/3942) $f : \mathbb{N} \to \mathbb{Q}$ (it actually suffices for $f : \mathbb{N} \to \mathbb{Q}$ to merely be a [surjection](https://en.wikipedia.org/wiki/Surjection)) and for every $r > 0,$ letting

$$U_r ~:=~ \bigcup_{n \in \mathbb{N}} \left(f(n) - r/2^n, f(n) + r/2^n\right) ~=~ \bigcup_{n \in \mathbb{N}} f(n) + \left(- r/2^n, r/2^n\right)$$

(here, the [Minkowski sum](https://en.wikipedia.org/wiki/Minkowski_sum) notation $f(n) + \left(- r/2^n, r/2^n\right) := \left(f(n) - r/2^n, f(n) + r/2^n\right)$ was used to simplify the description of the intervals). The open subset $U_r$ is dense in $\mathbb{R}$ because this is true of its subset $\mathbb{Q}$ and its Lebesgue measure is no greater than $\sum_{n \in \mathbb{N}} 2 r / 2^n = 2 r.$ Taking the union of closed, rather than open, intervals produces the [F-subset](wikipedia://en/396575)

$$S_r ~:=~ \bigcup_{n \in \mathbb{N}} f(n) + \left[- r/2^n, r/2^n\right]$$

that satisfies $S_{r/2} \subseteq U_r \subseteq S_r \subseteq U_{2r}.$ Because $\mathbb{R} \setminus S_r$ is a subset of the nowhere dense set $\mathbb{R} \setminus U_r,$ it is also nowhere dense in $\mathbb{R}.$ Because $\mathbb{R}$ is a [Baire space](wikipedia://en/200550), the set

$$D := \bigcap_{m=1}^{\infty} U_{1/m} = \bigcap_{m=1}^{\infty} S_{1/m}$$

is a dense subset of $\mathbb{R}$ (which means that like its subset $\mathbb{Q},$ $D$ cannot possibly be nowhere dense in $\mathbb{R}$) with $0$ Lebesgue measure that is also a [nonmeager subset](https://en.wikipedia.org/wiki/Nonmeager_set) of $\mathbb{R}$ (that is, $D$ is of the [second category](https://en.wikipedia.org/wiki/Second_category) in $\mathbb{R}$), which makes $\mathbb{R} \setminus D$ a [comeager subset](https://en.wikipedia.org/wiki/Comeager_set) of $\mathbb{R}$ whose interior in $\mathbb{R}$ is also empty; however, $\mathbb{R} \setminus D$ is nowhere dense in $\mathbb{R}$ if and only if its closure in $\mathbb{R}$ has empty interior. The subset $\mathbb{Q}$ in this example can be replaced by any countable dense subset of $\mathbb{R}$ and furthermore, even the set $\mathbb{R}$ can be replaced by $\mathbb{R}^n$ for any integer $n > 0.$
