# GNU Octave

::: {#o1 .subject cue=lead name="GNU Octave"}

**GNU Octave** is a [scientific programming language](https://en.wikipedia.org/wiki/Scientific_programming_language) for [scientific computing](https://en.wikipedia.org/wiki/Scientific_computing) and [numerical computation](https://en.wikipedia.org/wiki/Numerical_computation). Among other things, Octave can be used to solve linear and nonlinear problems numerically and to perform other numerical experiments using a language that is mostly compatible with [MATLAB](wikipedia://en/20412). It may also be used as a [batch-oriented](https://en.wikipedia.org/wiki/Batch_processing) language. As part of the [GNU Project](https://en.wikipedia.org/wiki/GNU_Project), it is [free software](https://en.wikipedia.org/wiki/Free_software) under the terms of the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License).

:::

## History {#History}

The project was conceived around 1988.[^o8] At first it was intended to be a companion to a chemical reactor design course. Full development was started by John W. Eaton in 1992. The first alpha release dates back to 4 January 1993 and on 17 February 1994 version 1.0 was released. Version 9.2.0 was released on 7 June 2024.[^o9]

The program is named after [Octave Levenspiel](https://en.wikipedia.org/wiki/Octave_Levenspiel), a former professor of the principal author. Levenspiel was known for his ability to perform quick [back-of-the-envelope calculations](wikipedia://en/550392).[^o10]

## Developments {#Developments}

In addition to use on desktops for personal scientific computing, Octave is used in academia and industry. For example, Octave was used on a massive [parallel](https://en.wikipedia.org/wiki/Parallel_computing) computer at [Pittsburgh Supercomputing Center](https://en.wikipedia.org/wiki/Pittsburgh_Supercomputing_Center) to find vulnerabilities related to guessing social security numbers.[^o28]

Acceleration with [OpenCL](https://en.wikipedia.org/wiki/OpenCL) or [CUDA](https://en.wikipedia.org/wiki/CUDA) is also possible with use of GPUs.[^o29]

## Technical details {#Technical_details}

- Octave is written in [C++](https://en.wikipedia.org/wiki/C++) using the [C++ standard library](https://en.wikipedia.org/wiki/C++_standard_library).
- Octave uses an [interpreter](https://en.wikipedia.org/wiki/Interpreter_%28computing%29) to execute the Octave scripting language.
- Octave is extensible using dynamically loadable modules.
- Octave interpreter has an [OpenGL](https://en.wikipedia.org/wiki/OpenGL)-based graphics engine to create plots, graphs and charts and to save or print them. Alternatively, [gnuplot](https://en.wikipedia.org/wiki/Gnuplot) can be used for the same purpose.
- Octave includes a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) (GUI) in addition to the traditional [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface) (CLI); see user interfaces below for details.

## Octave, the language {#Octave,_the_language}

The Octave language is an interpreted programming language. It is a [structured programming](https://en.wikipedia.org/wiki/Structured_programming) language (similar to [C](https://en.wikipedia.org/wiki/C_%28programming_language%29)) and supports many common [C standard library](https://en.wikipedia.org/wiki/C_standard_library) functions, and also certain [UNIX](https://en.wikipedia.org/wiki/POSIX) system calls and functions.[^o32] However, it does not support passing arguments by reference[^o33] although function arguments are [copy-on-write](https://en.wikipedia.org/wiki/Copy-on-write) to avoid unnecessary duplication.

Octave programs consist of a list of function calls or a [script](https://en.wikipedia.org/wiki/Script_%28computer_programming%29). The syntax is [matrix](https://en.wikipedia.org/wiki/Array_programming)-based and provides various functions for matrix operations. It supports various [data structures](wikipedia://en/8519) and allows [object-oriented programming](https://en.wikipedia.org/wiki/Object-oriented_programming).[^o34]

Its syntax is very similar to MATLAB, and careful programming of a script will allow it to run on both Octave and MATLAB.[^o35]

Because Octave is made available under the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License), it may be freely changed, copied and used.[^o10] The program runs on [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) and most [Unix](https://en.wikipedia.org/wiki/Unix) and [Unix-like](https://en.wikipedia.org/wiki/Unix-like) [operating systems](https://en.wikipedia.org/wiki/Operating_system), including [Linux](https://en.wikipedia.org/wiki/Linux), [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29), and [macOS](https://en.wikipedia.org/wiki/MacOS).[^o36][^o37][^o38]

## Notable features {#Notable_features}

### Command and variable name completion {#Command_and_variable_name_completion}

Typing a TAB character on the command line causes Octave to attempt to complete variable, function, and file names (similar to [Bash](https://en.wikipedia.org/wiki/Bash_%28Unix_shell%29)'s [tab completion](https://en.wikipedia.org/wiki/Tab_completion)). Octave uses the text before the cursor as the initial portion of the name to complete.[^o41]

### Command history {#Command_history}

When running interactively, Octave saves the commands typed in an internal buffer so that they can be recalled and edited.

### Data structures {#Data_structures}

Octave includes a limited amount of support for organizing data in structures. In this example, we see a structure x with elements a, b, and c, (an integer, an array, and a string, respectively):

```octave
octave:1> x.a = 1; x.b = [1, 2; 3, 4]; x.c = "string";
octave:2> x.a
ans =  1
octave:3> x.b
ans =

   1   2
   3   4

octave:4> x.c
ans = string
octave:5> x
x =

  scalar structure containing the fields:

    a = 1
    b =

       1   2
       3   4

    c = string
```

### Short-circuit Boolean operators {#Short-circuit_Boolean_operators}

Octave's `&&` and `||` logical [operators](https://en.wikipedia.org/wiki/Operator_%28programming%29) are evaluated in a [short-circuit](https://en.wikipedia.org/wiki/Short-circuit_evaluation) fashion (like the corresponding operators in the [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) language), in contrast to the element-by-element operators `&` and `|`.

### Increment and decrement operators {#Increment_and_decrement_operators}

Octave includes the C-like [increment and decrement operators](https://en.wikipedia.org/wiki/Increment_and_decrement_operators) `++` and `--` in both their prefix and postfix forms. Octave also does [augmented assignment](https://en.wikipedia.org/wiki/Augmented_assignment), e.g. `x += 5`.

### Unwind-protect {#Unwind-protect}

Octave supports a limited form of [exception handling](https://en.wikipedia.org/wiki/Exception_handling) modelled after the [`unwind_protect`](http://www.lispworks.com/documentation/HyperSpec/Body/s_unwind.htm) of [Lisp](https://en.wikipedia.org/wiki/Lisp_%28programming_language%29). The general form of an unwind\_protect block looks like this:

```octave
unwind_protect
   body
unwind_protect_cleanup
   cleanup
end_unwind_protect
```

As a general rule, GNU Octave recognizes as termination of a given `''block''` either the keyword `end` (which is compatible with the MATLAB language) or a more specific keyword `end''block''` or, in some cases, `end_''block''`. As a consequence, an `unwind_protect` block can be terminated either with the keyword `end_unwind_protect` as in the example, or with the more portable keyword `end`.

The *cleanup* part of the block is always executed. In case an exception is raised by the *body* part, *cleanup* is executed immediately before propagating the exception outside the block `unwind_protect`.

GNU Octave also supports another form of exception handling (compatible with the MATLAB language):

```matlab
try
   body
catch
   exception_handling
end
```

This latter form differs from an `unwind_protect` block in two ways. First, *exception\_handling* is only executed when an exception is raised by *body*. Second, after the execution of *exception\_handling* the exception is not propagated outside the block (unless a `rethrow( lasterror )` statement is explicitly inserted within the *exception\_handling* code).

### Variable-length argument lists {#Variable-length_argument_lists}

Octave has a mechanism for handling functions that take an unspecified number of arguments without explicit upper limit. To specify a list of zero or more arguments, use the special argument `varargin` as the last (or only) argument in the list. `varargin` is a cell array containing all the input arguments.

```octave
function s = plus (varargin)
   if (nargin==0)
      s = 0;
   else
      s = varargin{1} + plus (varargin{2:nargin});
   end
end
```

### Variable-length return lists {#Variable-length_return_lists}

A function can be set up to return any number of values by using the special return value `varargout`. For example:

```octave
function varargout = multiassign (data)
   for k=1:nargout
      varargout{k} = data(:,k);
   end
end
```

### C++ integration {#C++_integration}

It is also possible to execute Octave code directly in a C++ program. For example, here is a code snippet for calling `rand([10,1])`:

```cpp
#include <octave/oct.h>
...
ColumnVector NumRands(2);
NumRands(0) = 10;
NumRands(1) = 1;
octave_value_list f_arg, f_ret;
f_arg(0) = octave_value(NumRands);
f_ret = feval("rand", f_arg, 1);
Matrix unis(f_ret(0).matrix_value());
```

C and C++ code can be integrated into GNU Octave by creating oct files, or using the MATLAB compatible [MEX files](https://en.wikipedia.org/wiki/MEX_file).

## MATLAB compatibility {#MATLAB_compatibility}

Octave has been built with MATLAB compatibility in mind, and shares many features with MATLAB:

```octave
% Script: myscript.m
a = 5;
b = a * 2

% Function: myfunc.m
function result = myfunc(x)
    result = x^2 + 3;
end
```

1. Matrices as fundamental data type.
1. Built-in support for complex numbers.
1. Powerful built-in math functions and extensive function libraries.
1. Extensibility in the form of user-defined functions.

Octave treats incompatibility with MATLAB as a [bug](https://en.wikipedia.org/wiki/Bug_%28software%29); therefore, it could be considered a [software clone](https://en.wikipedia.org/wiki/Software_clone), which does not infringe [software copyright](https://en.wikipedia.org/wiki/Software_copyright) as per *[Lotus v. Borland](https://en.wikipedia.org/wiki/Lotus_v._Borland)* court case.

MATLAB scripts from the [MathWorks](https://en.wikipedia.org/wiki/MathWorks)' FileExchange repository in principle are compatible with Octave. However, while they are often provided and uploaded by users under an Octave [compatible](https://en.wikipedia.org/wiki/License_compatibility) and proper [open source](https://en.wikipedia.org/wiki/Open-source_license) [BSD license](https://en.wikipedia.org/wiki/BSD_license), the FileExchange [Terms of use](https://en.wikipedia.org/wiki/EULA) prohibit any usage beside MathWorks' [proprietary](https://en.wikipedia.org/wiki/Proprietary_software) MATLAB.[^o51][^o52][^o53]

### Syntax compatibility {#Syntax_compatibility}

There are a few purposeful, albeit minor, [syntax additions](http://octave.org/wiki/index.php?title=FAQ#Porting_programs_from_Matlab_to_Octave) (2012-04-26). <https://web.archive.org/web/20120426060857/http://octave.org/wiki/index.php?title=FAQ#Porting_programs_from_Matlab_to_Octave>:

1. [Comment](https://en.wikipedia.org/wiki/Comment_%28computer_programming%29) lines can be prefixed with the # character as well as the % character;
1. Various [C-based](https://en.wikipedia.org/wiki/C_%28programming_language%29) operators [\++](https://en.wikipedia.org/wiki/Increment_operator), [\--](https://en.wikipedia.org/wiki/Decrement_operator), [\+=](https://en.wikipedia.org/wiki/Augmented_assignment), \*=, /= are supported;
1. Elements can be referenced without creating a new variable by cascaded indexing, e.g. \[1:10\](3);
1. [Strings](wikipedia://en/27701) can be defined with the double-quote " character as well as the single-quote ' character;
1. When the variable type is [single](https://en.wikipedia.org/wiki/Single-precision_floating-point_format) (a single-precision floating-point number), Octave calculates the "[mean](https://en.wikipedia.org/wiki/Mean)" in the single-domain (MATLAB in [double-domain](https://en.wikipedia.org/wiki/Double-precision_floating-point_format)) which is faster but gives less accurate results;
1. Blocks can also be terminated with more specific [Control structure](https://en.wikipedia.org/wiki/Control_structure) keywords, i.e., endif, endfor, endwhile, etc.;
1. Functions can be defined within scripts and at the Octave prompt;
1. Presence of a do-until loop (similar to [do-while](https://en.wikipedia.org/wiki/Do_while_loop) in C).

### Function compatibility {#Function_compatibility}

Many, but not all, of the numerous MATLAB functions are available in GNU Octave, some of them accessible through packages in [Octave Forge](https://octave.sourceforge.io). The functions available as part of either core Octave or Forge packages are listed [online](https://octave.sourceforge.io/list_functions.php?q=&sort=alphabetic) (2024-03-14). <https://web.archive.org/web/20240314051049/https://octave.sourceforge.io/list_functions.php?q=&sort=alphabetic>.

A list of unavailable functions is included in the Octave function [`__unimplemented.m__`](http://hg.savannah.gnu.org/hgweb/octave/file/tip/scripts/help/__unimplemented__.m). Unimplemented functions are also listed under many Octave Forge packages in the [Octave Wiki](https://wiki.octave.org/Category:Octave_Forge).

When an unimplemented function is called the following error message is shown:

```octave
  octave:1> guide
  warning: the 'guide' function is not yet implemented in Octave

  Please read <http://www.octave.org/missing.html> to learn how you can contribute missing functionality.
  error: 'guide' undefined near line 1 column 1
```

## User interfaces {#User_interfaces}

Octave comes with an official [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) (GUI) and an [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) (IDE) based on [Qt](https://en.wikipedia.org/wiki/Qt_%28software%29). It has been available since Octave 3.8,[^o57] and has become the default interface (over the [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface)) with the release of Octave 4.0.[^o16] It was well-received by an EDN contributor, who wrote "\[Octave\] now has a very workable GUI" in reviewing the then-new GUI in 2014.[^o58]

Several 3rd-party graphical front-ends have also been developed, like [ToolboX](https://en.wikipedia.org/wiki/Toolbox_%28software%29) for coding education.

## GUI applications {#GUI_applications}

With Octave code, the user can create GUI applications. See [GUI Development (GNU Octave (version 7.1.0))](https://octave.org/doc/v7.1.0/GUI-Development.html). Below are some examples:

Button, edit control, checkbox

```octave
# create figure and panel on it
f = figure;
# create a button (default style)
b1 = uicontrol (f, "string", "A Button", "position",[10 10 150 40]);
# create an edit control
e1 = uicontrol (f, "style", "edit", "string", "editable text", "position",[10 60 300 40]);
# create a checkbox
c1 = uicontrol (f, "style", "checkbox", "string", "a checkbox", "position",[10 120 150 40]);
```

Textbox

```octave
prompt = {"Width", "Height", "Depth"};
defaults = {"1.10", "2.20", "3.30"};
rowscols = [1,10; 2,20; 3,30];
dims = inputdlg (prompt, "Enter Box Dimensions", rowscols, defaults);
```

Listbox with message boxes.

```octave
my_options = {"An item", "another", "yet another"};
[sel, ok] = listdlg ("ListString", my_options, "SelectionMode", "Multiple");
if (ok == 1)
  msgbox ("You selected:");
  for i = 1:numel (sel)
    msgbox (sprintf ("\t%s", my_options{sel(i)}));
  endfor
else
  msgbox ("You cancelled.");
endif
```

Radiobuttons

```octave
# create figure and panel on it
f = figure;
# create a button group
gp = uibuttongroup (f, "Position", [ 0 0.5 1 1])
# create a buttons in the group
b1 = uicontrol (gp, "style", "radiobutton", "string", "Choice 1", "Position", [ 10 150 100 50 ]);
b2 = uicontrol (gp, "style", "radiobutton", "string", "Choice 2", "Position", [ 10 50 100 30 ]);
# create a button not in the group
b3 = uicontrol (f, "style", "radiobutton","string", "Not in the group","Position", [ 10 50 100 50 ]);
```

## Packages {#Packages}

Octave also has many packages available. Those packages are located at Octave-Forge [Octave Forge - Packages](https://octave.sourceforge.io/packages.php), or [GitHub Octave Packages](https://gnu-octave.github.io/packages/symbolic). It is also possible for anyone to create and maintain packages.

## Comparison with similar software {#Comparison_with_similar_software}

Alternatives to GNU Octave under an [open source](https://en.wikipedia.org/wiki/Free_software) license, other than the aforementioned MATLAB, include [Scilab](https://en.wikipedia.org/wiki/Scilab) and [FreeMat](https://en.wikipedia.org/wiki/FreeMat).[^o62][^o63][^o64][^o65] Octave is more compatible with MATLAB than Scilab is,[^o62][^o66][^o67] and FreeMat has not been updated since June 2013.[^o68]

Also the [Julia programming language](https://en.wikipedia.org/wiki/Julia_%28programming_language%29) and its plotting capabilities has similarities with GNU Octave.
