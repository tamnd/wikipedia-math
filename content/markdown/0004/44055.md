# Measurable function

::: {#o1 .subject cue=lead name="Measurable function"}

In [mathematics](wikipedia://en/18831), and in particular [measure theory](wikipedia://en/48396#Measure_theory), a **measurable function** is a function between the underlying sets of two [measurable spaces](wikipedia://en/43333) that preserves the structure of the spaces: the [preimage](https://en.wikipedia.org/wiki/Preimage) of any [measurable](wikipedia://en/19873) set is measurable. This is in direct analogy to the definition that a [continuous](wikipedia://en/6122) function between [topological spaces](wikipedia://en/30450) [preserves](wikipedia://en/27716891) the topological structure: the preimage of any [open set](wikipedia://en/39358) is open. In [real analysis](wikipedia://en/26478), measurable functions are used in the definition of the [Lebesgue integral](https://en.wikipedia.org/wiki/Lebesgue_integration). In [probability theory](wikipedia://en/23542), a measurable function on a [probability space](wikipedia://en/43325) is known as a [random variable](wikipedia://en/25685).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let $(X,\Sigma)$ and $(Y,\mathrm{T})$ be measurable spaces, meaning that $X$ and $Y$ are sets equipped with respective [σ-algebras](wikipedia://en/29586) $\Sigma$ and $\mathrm{T}.$ A function $f:X\to Y$ is said to be measurable if for every $E\in \mathrm{T}$ the pre-image of $E$ under $f$ is in $\Sigma$; that is, for all $E \in \mathrm{T}$

$$f^{-1}(E) := \{ x\in X \mid f(x) \in E \} \in \Sigma.$$

That is, $\sigma (f)\subseteq\Sigma,$ where $\sigma (f)$ is the [σ-algebra generated by f](wikipedia://en/29586#σ-algebra_generated_by_a_function). If $f:X\to Y$ is a measurable function, one writes

$$f \colon (X, \Sigma) \rightarrow (Y, \mathrm{T}).$$

to emphasize the dependency on the $\sigma$-algebras $\Sigma$ and $\mathrm{T}.$

:::

## Term usage variations {#Term_usage_variations}

The choice of $\sigma$-algebras in the definition above is sometimes implicit and left up to the context. For example, for $\mathbb{R},$ $\mathbb{C},$ or other topological spaces, the [Borel algebra](https://en.wikipedia.org/wiki/Borel_algebra) (generated by all the open sets) is a common choice. Some authors define **measurable functions** as exclusively real-valued ones with respect to the Borel algebra.[^o5]

If the values of the function lie in an [infinite-dimensional vector space](https://en.wikipedia.org/wiki/Infinite-dimensional_vector_space), other non-equivalent definitions of measurability, such as [weak measurability](https://en.wikipedia.org/wiki/Weak_measurability) and [Bochner measurability](https://en.wikipedia.org/wiki/Bochner_measurability), exist.

::: {#o7 .pointer-item cue=pointer name="Borel function"}

## Notable classes of measurable functions {#Notable_classes_of_measurable_functions}

- Random variables are by definition measurable functions defined on probability spaces.
- If $(X, \Sigma)$ and $(Y, T)$ are [Borel spaces](wikipedia://en/43327#Standard_Borel_spaces_and_Kuratowski_theorems), a measurable function $f:(X, \Sigma) \to (Y, T)$ is also called a **Borel function**. Continuous functions are Borel functions but not all Borel functions are continuous. However, a measurable function is nearly a continuous function; see [Luzin's theorem](https://en.wikipedia.org/wiki/Luzin's_theorem). If a Borel function happens to be a section of a map $Y\xrightarrow{~\pi~}X,$ it is called a **Borel section**.
- A [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable) function is a measurable function $f : (\mathbb{R}, \mathcal{L}) \to (\mathbb{C}, \mathcal{B}_\mathbb{C}),$ where $\mathcal{L}$ is the $\sigma$-algebra of Lebesgue measurable sets, and $\mathcal{B}_\mathbb{C}$ is the [Borel algebra](https://en.wikipedia.org/wiki/Borel_algebra) on the [complex numbers](wikipedia://en/5826) $\mathbb{C}.$ Lebesgue measurable functions are of interest in [mathematical analysis](wikipedia://en/48396) because they can be integrated. In the case $f : X \to \mathbb{R},$ $f$ is Lebesgue measurable if and only if $\{f > \alpha\} = \{ x\in X : f(x) > \alpha\}$ is measurable for all $\alpha\in\mathbb{R}.$ This is also equivalent to any of $\{f \geq \alpha\},\{f<\alpha\},\{f\le\alpha\}$ being measurable for all $\alpha,$ or the preimage of any open set being measurable. Continuous functions, monotone functions, step functions, semicontinuous functions, Riemann-integrable functions, and functions of bounded variation are all Lebesgue measurable.[^o8] A function $f:X\to\mathbb{C}$ is measurable if and only if the real and imaginary parts are measurable.

:::

## Properties of measurable functions {#Properties_of_measurable_functions}

- The sum and product of two complex-valued measurable functions are measurable.[^o10] So is the quotient, so long as there is no division by zero.[^o5]
- If $f : (X,\Sigma_1) \to (Y,\Sigma_2)$ and $g:(Y,\Sigma_2) \to (Z,\Sigma_3)$ are measurable functions, then so is their composition $g\circ f:(X,\Sigma_1) \to (Z,\Sigma_3).$[^o5]
- If $f : (X,\Sigma_1) \to (Y,\Sigma_2)$ and $g:(Y,\Sigma_3) \to (Z,\Sigma_4)$ are measurable functions, their composition $g\circ f: X\to Z$ need not be $(\Sigma_1,\Sigma_4)$-measurable unless $\Sigma_3 \subseteq \Sigma_2.$ Indeed, two Lebesgue-measurable functions may be constructed in such a way as to make their composition non-Lebesgue-measurable.
- The (pointwise) [supremum](https://en.wikipedia.org/wiki/Supremum), [infimum](https://en.wikipedia.org/wiki/Infimum), [limit superior](https://en.wikipedia.org/wiki/Limit_superior), and [limit inferior](https://en.wikipedia.org/wiki/Limit_inferior) of a sequence (viz., countably many) of real-valued measurable functions are all measurable as well.[^o5][^o11]
- The [pointwise](wikipedia://en/4786797) limit of a sequence of measurable functions $f_n: X \to Y$ is measurable, where $Y$ is a metric space (endowed with the Borel algebra). This is not true in general if $Y$ is non-metrizable. The corresponding statement for continuous functions requires stronger conditions than pointwise convergence, such as uniform convergence.[^o12][^o13]

## Non-measurable functions {#Non-measurable_functions}

Real-valued functions encountered in applications tend to be measurable; however, it is not difficult to prove the existence of non-measurable functions. Such proofs rely on the [axiom of choice](wikipedia://en/840) in an essential way, in the sense that [Zermelo–Fraenkel set theory](wikipedia://en/152214) without the axiom of choice does not prove the existence of such functions.

In any measure space *$(X, \Sigma)$* with a [non-measurable set](wikipedia://en/620134) $A \subset X,$ $A \notin \Sigma,$ one can construct a non-measurable [indicator function](wikipedia://en/240790):

$$\mathbf{1}_A:(X,\Sigma) \to \mathbb{R}, \quad \mathbf{1}_A(x) = \begin{cases} 1 & \text{ if } x \in A \\ 0 & \text{ otherwise}, \end{cases}$$

where $\mathbb{R}$ is equipped with the usual [Borel algebra](https://en.wikipedia.org/wiki/Borel_algebra). This is a non-measurable function since the preimage of the measurable set $\{1\}$ is the non-measurable $A.$

As another example, any non-constant function $f : X \to \mathbb{R}$ is non-measurable with respect to the trivial $\sigma$-algebra $\Sigma = \{\varnothing, X\},$ since the preimage of any point in the range is some proper, nonempty subset of $X,$ which is not an element of the trivial $\Sigma.$
