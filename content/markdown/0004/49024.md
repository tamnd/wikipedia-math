# Wolfram Mathematica

::: {#o1 .subject cue=lead name="Wolfram Mathematica"}

Mathematica

**Wolfram Mathematica** (also known as **Mathematica**) is a software system with built-in libraries for several areas of technical computing that allows [machine learning](wikipedia://en/233488), [statistics](wikipedia://en/26685), [symbolic computation](wikipedia://en/23659805), data manipulation, network analysis, time series analysis, quantum computation framework, [NLP](https://en.wikipedia.org/wiki/Natural_language_processing), [optimization](https://en.wikipedia.org/wiki/Optimization), plotting [functions](wikipedia://en/185427) and various types of data, implementation of [algorithms](wikipedia://en/775), creation of [user interfaces](https://en.wikipedia.org/wiki/User_interface), and interfacing with programs written in other [programming languages](wikipedia://en/23015). It was conceived by [Stephen Wolfram](wikipedia://en/52469), and is developed by [Wolfram Research](wikipedia://en/594109) of Champaign, Illinois.[^o9][^o10] The [Wolfram Language](https://en.wikipedia.org/wiki/Wolfram_Language) is the programming language used in *Mathematica*.[^o11] Mathematica 1.0 was released on June 23, 1988 in [Champaign, Illinois](https://en.wikipedia.org/wiki/Champaign,_Illinois) and [Santa Clara, California](https://en.wikipedia.org/wiki/Santa_Clara,_California).[^o12][^o13][^o14] Mathematica's Wolfram Language is fundamentally based on [Lisp](https://en.wikipedia.org/wiki/Lisp_%28programming_language%29).

:::

## Notebook interface {#Notebook_interface}

Mathematica is split into two parts: the kernel and the [front end](https://en.wikipedia.org/wiki/Front_and_back_ends). The kernel interprets expressions (Wolfram Language code) and returns result expressions, which can then be displayed by the front end.

The original front end, designed by [Theodore Gray](https://en.wikipedia.org/wiki/Theodore_Gray)[^o16] in 1988, consists of a [notebook interface](https://en.wikipedia.org/wiki/Notebook_interface) and allows the creation and editing of [notebook documents](https://en.wikipedia.org/wiki/Notebook_interface) that can contain code, plaintext, images, and graphics.[^o17]

Code development is also supported in a range of standard [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) (IDE) including [Eclipse](https://en.wikipedia.org/wiki/Eclipse_%28software%29),[^o18] [IntelliJ IDEA](https://en.wikipedia.org/wiki/IntelliJ_IDEA),[^o19] [Atom](https://en.wikipedia.org/wiki/Atom_%28text_editor%29), [Vim](https://en.wikipedia.org/wiki/Vim_%28text_editor%29), [Visual Studio Code](https://en.wikipedia.org/wiki/Visual_Studio_Code) and [Git](https://en.wikipedia.org/wiki/Git). The Mathematica Kernel also includes a command line front end.[^o20]

Other interfaces include JMath,[^o21] based on [GNU Readline](https://en.wikipedia.org/wiki/GNU_Readline) and WolframScript[^o22] which runs self-contained Mathematica programs (with arguments) from the UNIX command line.

## High-performance computing {#High-performance_computing}

Capabilities for [high-performance computing](https://en.wikipedia.org/wiki/High-performance_computing) were extended with the introduction of [packed arrays](https://en.wikipedia.org/wiki/Packed_array) in version 4 (1999)[^o24] and [sparse matrices](wikipedia://en/341015) (version 5, 2003),[^o25] and by adopting the [GNU Multiple Precision Arithmetic Library](https://en.wikipedia.org/wiki/GNU_Multiple_Precision_Arithmetic_Library) to evaluate high-precision arithmetic.

Version 5.2 (2005) added automatic [multi-threading](https://en.wikipedia.org/wiki/Thread_%28computer_science%29) when computations are performed on [multi-core](https://en.wikipedia.org/wiki/Multi-core) computers.[^o26] This release included CPU-specific optimized libraries.[^o27] In addition Mathematica is supported by third party specialist acceleration hardware such as [ClearSpeed](https://en.wikipedia.org/wiki/ClearSpeed).[^o28]

In 2002, [gridMathematica](https://en.wikipedia.org/wiki/GridMathematica) was introduced to allow user level [parallel programming](https://en.wikipedia.org/wiki/Parallel_computing) on heterogeneous clusters and multiprocessor systems[^o29] and in 2008 parallel computing technology was included in all Mathematica licenses including support for grid technology such as [Windows HPC Server 2008](https://en.wikipedia.org/wiki/Windows_HPC_Server_2008), [Microsoft Compute Cluster Server](https://en.wikipedia.org/wiki/Windows_Server_2003) and [Sun Grid](https://en.wikipedia.org/wiki/Sun_Grid).

Support for [CUDA](https://en.wikipedia.org/wiki/CUDA) and [OpenCL](https://en.wikipedia.org/wiki/OpenCL) [GPU](https://en.wikipedia.org/wiki/GPU) hardware was added in 2010.[^o30]

## Extensions {#Extensions}

As of Version 14, there are 6,602 built-in functions and symbols in the Wolfram Language.[^o33] Stephen Wolfram announced the launch of the Wolfram Function Repository in June 2019 as a way for the public Wolfram community to contribute functionality to the Wolfram Language.[^o34] There are currently more than 3000 functions contributed as Resource Functions.[^o35] In addition to the Wolfram Function Repository, there is a Wolfram Data Repository with computable data and the Wolfram Neural Net Repository for machine learning.[^o36]

Wolfram Mathematica is the basis of the Combinatorica package, which adds discrete mathematics functionality in combinatorics and graph theory to the program.[^o37]

## Connections to other applications, programming languages, and services {#Connections_to_other_applications,_programming_languages,_and_services}

Communication with other applications can be done using a protocol called Wolfram Symbolic Transfer Protocol (WSTP). It allows communication between the Wolfram Mathematica kernel and the front end and provides a general interface between the kernel and other applications.[^o40]

Wolfram Research freely distributes a developer kit for linking applications written in the programming language [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) to the Mathematica kernel through WSTP using J/Link.,[^o41] a [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) program that can ask Mathematica to perform computations. Similar functionality is achieved with .NET /Link,[^o42] but with [.NET](https://en.wikipedia.org/wiki/.NET_Framework) programs instead of Java programs.

Other languages that connect to Mathematica include [Haskell](https://en.wikipedia.org/wiki/Haskell),[^o43] [AppleScript](https://en.wikipedia.org/wiki/AppleScript),[^o44] [Racket](https://en.wikipedia.org/wiki/Racket_%28programming_language%29),[^o45] [Visual Basic](https://en.wikipedia.org/wiki/Visual_Basic),[^o46] [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29),[^o47][^o48] and [Clojure](https://en.wikipedia.org/wiki/Clojure).[^o49]

Mathematica supports the generation and execution of [Modelica](https://en.wikipedia.org/wiki/Modelica) models for [systems modeling](https://en.wikipedia.org/wiki/Systems_modeling) and connects with [Wolfram System Modeler](https://en.wikipedia.org/wiki/Wolfram_SystemModeler).

Links are also available to many third-party software packages and APIs.[^o50]

Mathematica can also capture real-time data from a variety of sources[^o51] and can read and write to public blockchains ([Bitcoin](wikipedia://en/28249265), [Ethereum](https://en.wikipedia.org/wiki/Ethereum), and ARK).[^o52]

It supports import and export of over 220 data, image, video, sound, [computer-aided design](https://en.wikipedia.org/wiki/Computer-aided_design) (CAD), [geographic information systems](https://en.wikipedia.org/wiki/Geographic_information_system) (GIS),[^o53] document, and biomedical formats.

In 2019, support was added for compiling Wolfram Language code to [LLVM](https://en.wikipedia.org/wiki/LLVM).[^o54]

Version 12.3 of the Wolfram Language added support for [Arduino](https://en.wikipedia.org/wiki/Arduino).[^o55]

:::

## Computable data {#Computable_data}

Mathematica is also integrated with [Wolfram Alpha](https://en.wikipedia.org/wiki/Wolfram_Alpha), an online [answer engine](https://en.wikipedia.org/wiki/Answer_engine) that provides additional data, some of which is kept updated in real time, for users who use Mathematica with an internet connection. Some of the data sets include astronomical, chemical, geopolitical, language, biomedical, airplane, and weather data, in addition to mathematical data (such as knots and polyhedra).[^o57]

## Reception {#Reception}

*[BYTE](https://en.wikipedia.org/wiki/BYTE)* in 1989 listed Mathematica as among the "Distinction" winners of the BYTE Awards, stating that it "is another breakthrough Macintosh application ... it could enable you to absorb the algebra and calculus that seemed impossible to comprehend from a textbook".[^o59]

Mathematica has been criticized for being closed source.[^o60] Wolfram Research claims keeping Mathematica closed source is central to its business model and the continuity of the software.[^o61][^o62]
