# Injective function

::: {#o1 .subject cue=lead name="Injective function"}

In [mathematics](wikipedia://en/18831), an **injective function** (also known as **injection**, or **one-to-one function**[^o2]) is a [function](wikipedia://en/185427) $f$ that maps [distinct](https://en.wikipedia.org/wiki/Distinct_%28mathematics%29) elements of its domain to distinct elements of its codomain; that is, $x_{1} \ne x_{2}$ implies $f(x_{1}) f(x_{2})$ (equivalently by [contraposition](wikipedia://en/8556497), $f(x_{1}) = f(x_{2})$ implies $x_{1} = x_{2}$). In other words, every element of the function's [codomain](wikipedia://en/50264) is the [image](wikipedia://en/579311) of at most one element of its [domain](wikipedia://en/50263).[^o3] The term one-to-one function must not be confused with one-to-one correspondence that refers to [bijective functions](https://en.wikipedia.org/wiki/Bijective_function), which are functions such that each element in the codomain is an image of *exactly one* element in the domain.

:::

A [homomorphism](wikipedia://en/13564) between [algebraic structures](wikipedia://en/106364) is a function that is compatible with the operations of the structures. For all common algebraic structures, and, in particular for [vector spaces](wikipedia://en/32370), an injective homomorphism is also called a [monomorphism](wikipedia://en/59538). However, in the more general context of [category theory](wikipedia://en/5869), the definition of a monomorphism differs from that of an injective homomorphism.[^o4] This is thus a theorem that they are equivalent for algebraic structures; see *Homomorphism* for more details.

A function $f$ that is not injective is sometimes called many-to-one.[^o3]

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Injection.svg.* An injective function, which is not also [surjective](wikipedia://en/27873)

Let $f$ be a function whose domain is a set $X$. The function $f$ is said to be **injective** provided that for all $a$ and $b$ in $X,$ if $f(a) = f(b)$, then $a = b$; that is, $f(a) = f(b)$ implies $a = b$. Equivalently, if $a \neq b$, then $f(a) \neq f(b)$ in the [contrapositive](wikipedia://en/8556497) statement.

Symbolically,

$$\forall a,b \in X, \;\; f(a)=f(b) \Rightarrow a=b,$$

which is logically equivalent to the [contrapositive](wikipedia://en/8556497),[^o7]

$$\forall a, b \in X, \;\; a \neq b \Rightarrow f(a) \neq f(b).$$

An injective function (or, more generally, a monomorphism) is often denoted by using the specialized arrows ↣ or ↪ (for example, $f:A\rightarrowtail B$ or $f:A\hookrightarrow B$), although some authors specifically reserve ↪ for an [inclusion map](wikipedia://en/492516).[^o8]

:::

## Examples {#Examples}

*For visual examples, readers are directed to the gallery section.*

- For any set $X$ and any subset $S \subseteq X$, the [inclusion map](wikipedia://en/492516) $S \to X$ (which sends any element $s \in S$ to itself) is injective. In particular, the [identity function](wikipedia://en/15069) $X \to X$ is always injective (and in fact bijective).
- If the domain of a function is the [empty set](wikipedia://en/9566), then the function is the [empty function](https://en.wikipedia.org/wiki/Empty_function), which is injective.
- If the domain of a function has one element (that is, it is a [singleton set](https://en.wikipedia.org/wiki/Singleton_set)), then the function is always injective.
- The function $f : \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 2 x + 1$ is injective.
- The function $g : \mathbb{R} \to \mathbb{R}$ defined by $g(x) = x^2$ is not injective, because (for example) $g(1) = 1 = g(-1).$ However, if $g$ is redefined so that its domain is the non-negative real numbers $[0, +\infty)$, then $g$ is injective.
- The [exponential function](wikipedia://en/9678) $\exp : \mathbb{R} \to \mathbb{R}$ defined by $\exp(x) = e^x$ is injective (but not [surjective](wikipedia://en/27873), as no real value maps to a negative number).
- The [natural logarithm](wikipedia://en/21476) function $\ln : (0, \infty) \to \mathbb{R}$ defined by $x \mapsto \ln x$ is injective.
- The function $g : \mathbb{R} \to \mathbb{R}$ defined by $g(x) = x^n - x$ is not injective, since, for example, $g(0) = g(1) = 0$.

More generally, when $X$ and $Y$ are both the [real line](https://en.wikipedia.org/wiki/Real_line) $\mathbb{R}$, then an injective function $f : \mathbb{R} \to \mathbb{R}$ is one whose graph is never intersected by any horizontal line more than once. This principle is referred to as the [horizontal line test](wikipedia://en/56874).[^o3]

:::

## Injections can be undone {#Injections_can_be_undone}

Functions with [left inverses](wikipedia://en/14907#Left_and_right_inverses) are always injections. That is, given $f : X \to Y$, if there is a function $g : Y \to X$ such that for every $x \in X$, $g(f(x)) = x$, then $f$ is injective. The proof is that

$$f(a) = f(b) \rightarrow g(f(a))=g(f(b)) \rightarrow a = b.$$

In this case, $g$ is called a [retraction](https://en.wikipedia.org/wiki/Retract_%28category_theory%29) of $f$. Conversely, $f$ is called a [section](https://en.wikipedia.org/wiki/Retract_%28category_theory%29) of $g$. For example: $f:\mathbb{R}\rightarrow\mathbb{R}^2,x\mapsto(1,m)^\intercal x$ is retracted by $g:y\mapsto\frac{(1,m)}{1+m^2}y$.

Conversely, every injection $f$ with a non-empty domain has a left inverse $g$. It can be defined by choosing an element $a$ in the domain of $f$ and setting $g(y)$ to the unique element of the pre-image $f^{-1}[y]$ (if it is non-empty) or to $a$ (otherwise).

The left inverse $g$ is not necessarily an [inverse](wikipedia://en/14907) of $f,$ because the composition in the other order, $f \circ g$, may differ from the identity on $Y$. In other words, an injective function can be "reversed" by a left inverse, but is not necessarily [invertible](wikipedia://en/14907), which requires that the function is bijective.

## Injections may be made invertible {#Injections_may_be_made_invertible}

In fact, to turn an injective function $f : X \to Y$ into a bijective (hence invertible) function, it suffices to replace its codomain $Y$ by its actual image $J = f(X).$ That is, let $g : X \to J$ such that $g(x) = f(x)$ for all $x \in X$; then $g$ is bijective. Indeed, $f$ can be factored as $\operatorname{In}_{J,Y} \circ g$, where $\operatorname{In}_{J,Y}$ is the [inclusion function](https://en.wikipedia.org/wiki/Inclusion_function) from $J$ into $Y$.

More generally, injective [partial functions](wikipedia://en/23577) are called [partial bijections](https://en.wikipedia.org/wiki/Partial_bijection).

## Other properties {#Other_properties}

*Image: Injective composition2.svg.* The composition of two injective functions is injective.

- If $f$ and $g$ are both injective then $f \circ g$ is injective.
- If $g \circ f$ is injective, then $f$ is injective (but $g$ need not be).
- $f : X \to Y$ is injective if and only if, given any functions $g$, $h : W \to X$ whenever $f \circ g = f \circ h$, then $g = h$. In other words, injective functions are precisely the [monomorphisms](wikipedia://en/59538) in the [category](wikipedia://en/5869) **[Set](wikipedia://en/26829)** of sets.
- If $f : X \to Y$ is injective and $A$ is a [subset](wikipedia://en/27631) of $X$, then $f^{-1}(f(A)) = A$. Thus, $A$ can be recovered from its [image](https://en.wikipedia.org/wiki/Image_%28function%29) $f(A)$.
- If $f : X \to Y$ is injective and $A$ and $B$ are both subsets of $X$, then $f(A \cap B) = f(A) \cap f(B)$.
- Every function $h : W \to Y$ can be decomposed as $h = f \circ g$ for a suitable injection $f$ and surjection $g$. This decomposition is unique [up to isomorphism](https://en.wikipedia.org/wiki/Up_to_isomorphism), and $f$ may be thought of as the [inclusion function](https://en.wikipedia.org/wiki/Inclusion_function) of the range $h(W)$ of $h$ as a subset of the codomain $Y$ of $h$.
- If $f : X \to Y$ is an injective function, then $Y$ has at least as many elements as $X,$ in the sense of [cardinal numbers](wikipedia://en/6173). In particular, if, in addition, there is an injection from $Y$ to $X$, then $X$ and $Y$ have the same cardinal number. (This is known as the [Cantor–Bernstein–Schroeder theorem](https://en.wikipedia.org/wiki/Cantor–Bernstein–Schroeder_theorem).)
- If both $X$ and $Y$ are [finite](wikipedia://en/11742) with the same number of elements, then $f : X \to Y$ is injective if and only if $f$ is surjective (in which case $f$ is bijective).
- An injective function which is a homomorphism between two algebraic structures is an [embedding](wikipedia://en/52119).
- Unlike surjectivity, which is a relation between the graph of a function and its codomain, injectivity is a property of the graph of the function alone; that is, whether a function $f$ is injective can be decided by only considering the graph (and not the codomain) of $f$.

## Proving that functions are injective {#Proving_that_functions_are_injective}

A proof that a function $f$ is injective depends on how the function is presented and what properties the function holds. For functions that are given by some formula there is a basic idea. We use the definition of injectivity, namely that if $f(x) = f(y)$, then $x = y$.[^o15]

Here is an example:

$$f(x) = 2 x + 3$$

Proof: Let $f : X \to Y$. Suppose $f(x) = f(y)$. So $2 x + 3 = 2 y + 3$ implies $2 x = 2 y$, which implies $x = y$. Therefore, it follows from the definition that $f$ is injective.

There are multiple other methods of proving that a function is injective. For example, in calculus if $f$ is a differentiable function defined on some interval, then it is sufficient to show that the derivative is always positive or always negative on that interval. In linear algebra, if $f$ is a linear transformation it is sufficient to show that the kernel of $f$ contains only the zero vector. If $f$ is a function with finite domain it is sufficient to look through the list of images of each domain element and check that no image occurs twice on the list.

A graphical approach for a real-valued function $f$ of a real variable $x$ is the [horizontal line test](wikipedia://en/56874). If every horizontal line intersects the curve of $f(x)$ in at most one point, then $f$ is injective or one-to-one.
