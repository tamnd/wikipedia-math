# Complete measure

::: {#o1 .subject cue=lead name="Complete measure"}

In [mathematics](wikipedia://en/18831), a **complete measure** (or, more precisely, a **complete measure space**) is a [measure space](wikipedia://en/19873) in which every [subset](wikipedia://en/27631) of every [null set](wikipedia://en/21520) is measurable (having [measure zero](https://en.wikipedia.org/wiki/Measure_zero)). More formally, a measure space (*X*, Σ, *μ*) is complete if and only if[^o2][^o3]

:::

$$S \subseteq N \in \Sigma \mbox{ and } \mu(N) = 0\ \Rightarrow\ S \in \Sigma.$$

## Motivation {#Motivation}

The need to consider questions of completeness can be illustrated by considering the problem of product spaces.

Suppose that we have already constructed [Lebesgue measure](wikipedia://en/18198) on the [real line](https://en.wikipedia.org/wiki/Real_line): denote this measure space by $(\mathbb{R}, B, \lambda).$ We now wish to construct some two-dimensional Lebesgue measure $\lambda^2$ on the plane $\mathbb{R}^2$ as a [product measure](wikipedia://en/2986564). Naively, we would take the [\-algebra](https://en.wikipedia.org/wiki/Sigma_algebra) on $\mathbb{R}^2$ to be $B \otimes B,$ the smallest -algebra containing all measurable "rectangles" $A_1 \times A_2$ for $A_1, A_2 \in B.$

While this approach does define a [measure space](wikipedia://en/45270), it has a flaw. Since every [singleton](wikipedia://en/381798) set has one-dimensional Lebesgue measure zero,

$$\lambda^2(\{0\} \times A) \leq \lambda(\{0\}) = 0$$

for any subset $A$ of $\mathbb{R}.$ However, suppose that $A$ is a [non-measurable subset](wikipedia://en/620134) of the real line, such as the [Vitali set](wikipedia://en/424189). Then the $\lambda^2$-measure of $\{0\} \times A$ is not defined but

$$\{0\} \times A \subseteq \{0\} \times \mathbb{R},$$

and this larger set does have $\lambda^2$-measure zero. So this "two-dimensional Lebesgue measure" as just defined is not complete, and some kind of completion procedure is required.

::: {#o6 .definition kind=definition/construction cue=heading name="Construction of a complete measure"}

## Construction of a complete measure {#Construction_of_a_complete_measure}

Given a (possibly incomplete) measure space (*X*, Σ, *μ*), there is an extension (*X*, Σ<sub>0</sub>, *μ*<sub>0</sub>) of this measure space that is complete.[^o7] The smallest such extension (i.e. the smallest *σ*-algebra Σ<sub>0</sub>) is called the **completion** of the measure space.

The completion can be constructed as follows:

- let *Z* be the set of all the subsets of the zero-*μ*-measure subsets of *X* (intuitively, those elements of *Z* that are not already in Σ are the ones preventing completeness from holding true);
- let Σ<sub>0</sub> be the *σ*-algebra generated by Σ and *Z* (i.e. the smallest *σ*-algebra that contains every element of Σ and of *Z*);
- *μ* has an extension *μ*<sub>0</sub> to Σ<sub>0</sub> (which is unique if *μ* is [*σ*-finite](wikipedia://en/4316174)), called the [outer measure](wikipedia://en/488605) of *μ*, given by the [infimum](https://en.wikipedia.org/wiki/Infimum)

$$\mu_{0} (C) := \inf \{ \mu (D) \mid C \subseteq D \in \Sigma \}.$$

Then (*X*, Σ<sub>0</sub>, *μ*<sub>0</sub>) is a complete measure space, and is the completion of (*X*, Σ, *μ*).

In the above construction it can be shown that every member of Σ<sub>0</sub> is of the form *A* ∪ *B* for some *A* ∈ Σ and some *B* ∈ *Z*, and

$$\mu_{0} (A \cup B) = \mu (A).$$

:::

## Examples {#Examples}

- [Borel measure](wikipedia://en/4322) as defined on the Borel *σ*-algebra generated by the [open](wikipedia://en/39358) [intervals](wikipedia://en/49172) of the real line is not complete, and so the above completion procedure must be used to define the complete Lebesgue measure. This is illustrated by the fact that the set of all Borel sets over the reals has the same cardinality as the reals. While the [Cantor set](wikipedia://en/6172) is a Borel set, has measure zero, and its power set has cardinality strictly greater than that of the reals. Thus there is a subset of the Cantor set that is not contained in the Borel sets. Hence, the Borel measure is not complete.
- *n*-dimensional Lebesgue measure is the completion of the *n*-fold product of the one-dimensional Lebesgue space with itself. It is also the completion of the Borel measure, as in the one-dimensional case.

:::

## Properties {#Properties}

[Maharam's theorem](wikipedia://en/18759825) states that every complete measure space is decomposable into measures on [continua](wikipedia://en/24758677), and a finite or countable [counting measure](wikipedia://en/191786).
