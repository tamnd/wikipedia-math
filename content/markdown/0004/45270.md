# Measure space

Measurable space

::: {#o1 .subject cue=lead name="Measure space"}

A **measure space** is a basic object of [measure theory](https://en.wikipedia.org/wiki/Measure_theory), a branch of [mathematics](wikipedia://en/18831) that studies generalized notions of [volumes](wikipedia://en/32498). It contains an underlying set, the [subsets](wikipedia://en/27631) of this set that are feasible for measuring (the [$\sigma$-algebra](wikipedia://en/29586)), and the method that is used for measuring (the [measure](wikipedia://en/19873)). One important example of a measure space is a [probability space](wikipedia://en/43325).

:::

A [measurable space](wikipedia://en/43333) consists of the first two components without a specific measure.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A measure space is a triple $(X, \mathcal A, \mu),$ where[^o8][^o9]

- $X$ is a set
- $\mathcal A$ is a [$\sigma$-algebra](wikipedia://en/29586) on the set $X$
- $\mu$ is a [measure](wikipedia://en/19873) on $(X, \mathcal{A})$

In other words, a measure space consists of a [measurable space](wikipedia://en/43333) $(X, \mathcal{A})$ together with a [measure](wikipedia://en/19873) on it.

:::

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

Set $X = \{0, 1\}$. The $\sigma$-algebra on finite sets such as the one above is usually the [power set](wikipedia://en/23799), which is the set of all subsets (of a given set) and is denoted by $\wp(\cdot).$ Sticking with this convention, we set

$$\mathcal{A} = \wp(X)$$

In this simple case, the power set can be written down explicitly:

$$\wp(X) = \{\varnothing, \{0\}, \{1\}, \{0, 1\}\}.$$

As the measure, define $\mu$ by

$$\mu(\{0\}) = \mu(\{1\}) = \frac{1}{2},$$

so $\mu(X) = 1$ (by additivity of measures) and $\mu(\varnothing) = 0$ (by definition of measures).

This leads to the measure space $(X, \wp(X), \mu).$ It is a [probability space](wikipedia://en/43325), since $\mu(X) = 1.$ The measure $\mu$ corresponds to the [Bernoulli distribution](wikipedia://en/199189) with $p = \frac{1}{2},$ which is for example used to model a fair coin flip.

:::

## Important classes of measure spaces {#Important_classes_of_measure_spaces}

Most important classes of measure spaces are defined by the properties of their associated measures. This includes, in order of increasing generality:

- [Probability spaces](wikipedia://en/43325), a measure space where the measure is a [probability measure](wikipedia://en/45437)[^o8]
- Finite measure spaces, where the measure is a [finite measure](wikipedia://en/4316185)[^o11]
- $\sigma$-finite measure spaces, where the measure is a [$\sigma$-finite measure](https://en.wikipedia.org/wiki/Sigma-finite_measure)[^o11]

Another class of measure spaces are the [complete measure spaces](https://en.wikipedia.org/wiki/Complete_measure_space).[^o10]
