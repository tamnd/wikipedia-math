# Perfect matching

::: {#o1 .subject cue=lead name="Perfect matching"}

In [graph theory](wikipedia://en/12401), a **perfect matching** in a [graph](wikipedia://en/325806) is a [matching](wikipedia://en/581797) that covers every [vertex](wikipedia://en/638899) of the graph. More formally, given a graph $G$ with edges $E$ and vertices $V$, a perfect matching in $G$ is a [subset](wikipedia://en/27631) $M$ of $E$, such that every vertex in $V$ is adjacent to exactly one edge in $M$. The [adjacency matrix](wikipedia://en/244463) of a perfect matching is a symmetric [permutation matrix](wikipedia://en/238849).

:::

A perfect matching is also called a **1-factor**; see [Graph factorization](wikipedia://en/3298854) for an explanation of this term. In some literature, the term **complete matching** is used.

Every perfect matching is a [maximum-cardinality matching](https://en.wikipedia.org/wiki/Maximum_cardinality_matching), but the opposite is not true. For example, consider the following graphs:[^o2]

*Image: Maximum-matching-labels.svg.*

In graph (b) there is a perfect matching (of size 3) since all 6 vertices are matched; in graphs (a) and (c) there is a maximum-cardinality matching (of size 2) which is not perfect, since some vertices are unmatched.

A perfect matching is also a minimum-size [edge cover](wikipedia://en/4577392). If there is a perfect matching, then both the matching number and the edge cover number equal $\lvert V\rvert / 2$.

A perfect matching can only occur when the graph has an even number of vertices. A **near-perfect matching** is one in which exactly one vertex is unmatched. This can only occur when the graph has an [odd number](https://en.wikipedia.org/wiki/Odd_number) of vertices, and such a matching must be maximum. In the above figure, part (c) shows a near-perfect matching. If, for every vertex in a graph, there is a near-perfect matching that omits only that vertex, the graph is also called [factor-critical](wikipedia://en/7684634).

## Characterizations {#Characterizations}

[Hall's marriage theorem](wikipedia://en/186969) provides a characterization of bipartite graphs which have a perfect matching.

[Tutte's theorem on perfect matchings](wikipedia://en/1655060) provides a characterization for arbitrary graphs.

A perfect matching is a spanning [1-regular](wikipedia://en/85821) subgraph, a.k.a. a [1-factor](https://en.wikipedia.org/wiki/1-factor). In general, a spanning *k*-regular subgraph is a [*k*-factor](https://en.wikipedia.org/wiki/Factor_%28graph_theory%29).

A spectral characterization for a graph to have a perfect matching is given by Hassani Monfared and Mallik as follows: Let $G$ be a [graph](wikipedia://en/325806) on even $n$ vertices and $\lambda_1 > \lambda_2 > \ldots > \lambda_{\frac{n}{2}}>0$ be $\frac{n}{2}$ distinct nonzero [purely imaginary numbers](wikipedia://en/14554). Then $G$ has a perfect matching if and only if there is a real [skew-symmetric matrix](wikipedia://en/174055) $A$ with graph $G$ and [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) $\pm \lambda_1, \pm\lambda_2,\ldots,\pm\lambda_{\frac{n}{2}}$.[^o5] Note that the (simple) graph of a real symmetric or skew-symmetric matrix $A$ of order $n$ has $n$ vertices and edges given by the nonzero off-diagonal entries of $A$.

:::

## Computation {#Computation}

Deciding whether a graph admits a perfect matching can be done in [polynomial time](https://en.wikipedia.org/wiki/Polynomial-time), using any algorithm for finding a [maximum cardinality matching](https://en.wikipedia.org/wiki/Maximum_cardinality_matching).

However, counting the number of perfect matchings, even in [bipartite graphs](wikipedia://en/244431), is [\#P-complete](wikipedia://en/27925). This is because computing the [permanent](wikipedia://en/215889) of an arbitrary 0–1 matrix (another #P-complete problem) is the same as computing the number of perfect matchings in the bipartite graph having the given matrix as its [biadjacency matrix](https://en.wikipedia.org/wiki/Biadjacency_matrix).

A theorem of [Pieter Kasteleyn](https://en.wikipedia.org/wiki/Pieter_Kasteleyn) states that the number of perfect matchings in a [planar graph](wikipedia://en/24314) can be computed exactly in polynomial time via the [FKT algorithm](wikipedia://en/30159370).

The number of perfect matchings in a [complete graph](wikipedia://en/85816) *K<sub>n</sub>* (with *n* even) is given by the [double factorial](wikipedia://en/507208): $(n-1)!!$[^o8]

:::

## Connection to Graph Coloring {#Connection_to_Graph_Coloring}

An [edge-colored graph](wikipedia://en/690647) can induce a number of (not necessarily proper) [vertex colorings](wikipedia://en/426743) equal to the number of perfect matchings, as every vertex is covered exactly once in each matching. This property has been investigated in [quantum physics](https://en.wikipedia.org/wiki/Quantum_physics)[^o10] and [computational complexity theory](wikipedia://en/7543).[^o11]

## Perfect matching polytope {#Perfect_matching_polytope}

The **perfect matching polytope** of a graph is a polytope in **R**<sup>\|E|</sup> in which each corner is an incidence vector of a perfect matching.
