# Vector quantization

::: {#o1 .subject cue=lead name="Vector quantization"}

**Vector quantization** (**VQ**) is a classical [quantization](wikipedia://en/317018) technique from [signal processing](wikipedia://en/29324) that allows the modeling of [probability density functions](https://en.wikipedia.org/wiki/Probability_density_functions) by the distribution of prototype vectors. Developed in the early 1980s by [Robert M. Gray](https://en.wikipedia.org/wiki/Robert_M._Gray), it was originally used for [data compression](wikipedia://en/8013). It works by dividing a large set of points ([vectors](wikipedia://en/879358)) into groups having approximately the same number of points closest to them. Each group is represented by its [centroid](wikipedia://en/187926) point, as in [k-means](https://en.wikipedia.org/wiki/K-means) and some other [clustering](wikipedia://en/669675) algorithms. In simpler terms, vector quantization chooses a set of points to represent a larger set of points.

:::

The density matching property of vector quantization is powerful, especially for identifying the density of large and high-dimensional data. Since data points are represented by the index of their closest centroid, commonly occurring data have low error, and rare data high error. This is why VQ is suitable for [lossy data compression](https://en.wikipedia.org/wiki/Lossy_data_compression). It can also be used for lossy data correction and [density estimation](wikipedia://en/554671).

Vector quantization is based on the [competitive learning](https://en.wikipedia.org/wiki/Competitive_learning) paradigm, so it is closely related to the [self-organizing map](wikipedia://en/76996) model and to [sparse coding](https://en.wikipedia.org/wiki/Sparse_coding) models used in [deep learning](https://en.wikipedia.org/wiki/Deep_learning) algorithms such as [autoencoder](https://en.wikipedia.org/wiki/Autoencoder).

## Training {#Training}

One simple training algorithm for vector quantization is:[^o3]

1. Pick a sample point at random
1. Move the nearest quantization vector centroid towards this sample point, by a small fraction of the distance
1. Repeat

A more sophisticated algorithm reduces the bias in the density matching estimation and ensures that all points are used, by including an extra sensitivity parameter:

1. Increase each centroid's sensitivity $s_i$ by a small amount
1. Pick a sample point $P$ at random
1. For each quantization vector centroid $c_i$, let $d(P, c_i)$ denote the distance of $P$ and $c_i$
1. Find the centroid $c_i$ for which $d(P, c_i) - s_i$ is the smallest
1. Move $c_i$ towards $P$ by a small fraction of the distance
1. Set $s_i$ to zero
1. Repeat

It is desirable to use a cooling schedule to produce convergence: see [Simulated annealing](wikipedia://en/172244). Another simple method is [LBG](https://en.wikipedia.org/wiki/Linde–Buzo–Gray_algorithm), which is based on [k-means](wikipedia://en/1860407).

The algorithm can be iteratively updated with "live" data, rather than by picking random points from a data set, but this will introduce some bias if the data are temporally correlated over many samples.

## Applications {#Applications}

Vector quantization is used for lossy data compression, lossy data correction, pattern recognition, density estimation and clustering.

Lossy data correction, or prediction, is used to recover data missing from some dimensions. It is done by finding the nearest group with the data dimensions available, then predicting the result based on the values for the missing dimensions, assuming that they will have the same value as the group's centroid.

For [density estimation](wikipedia://en/554671), the area/volume that is closer to a particular centroid than to any other is inversely proportional to the density (due to the density matching property of the algorithm).

### Use in data compression {#Use_in_data_compression}

Vector quantization, also called "block quantization" or "pattern matching quantization" is often used in [lossy data compression](https://en.wikipedia.org/wiki/Lossy_data_compression). It works by encoding values from a multidimensional [vector space](wikipedia://en/32370) into a finite set of values from a discrete [subspace](wikipedia://en/56357) of lower dimension. A lower-space vector requires less storage space, so the data is compressed. Due to the density matching property of vector quantization, the compressed data has errors that are inversely proportional to density.

The transformation is usually done by [projection](wikipedia://en/3909097) or by using a [codebook](wikipedia://en/530786). In some cases, a codebook can be also used to [entropy code](https://en.wikipedia.org/wiki/Entropy_code) the discrete value in the same step, by generating a [prefix coded](wikipedia://en/66193) variable-length encoded value as its output.

The set of discrete amplitude levels is quantized jointly rather than each sample being quantized separately. Consider a *k*-dimensional vector $[x_1,x_2,...,x_k]$ of amplitude levels. It is compressed by choosing the nearest matching vector from a set of *n*-dimensional vectors $[y_1,y_2,...,y_n]$, with *n* \< *k*.

All possible combinations of the *n*-dimensional vector $[y_1,y_2,...,y_n]$ form the [vector space](wikipedia://en/32370) to which all the quantized vectors belong.

Only the index of the codeword in the codebook is sent instead of the quantized values. This conserves space and achieves more compression.

[Twin vector quantization](https://en.wikipedia.org/wiki/TwinVQ#TwinVQ_in_MPEG-4) (VQF) is part of the [MPEG-4](https://en.wikipedia.org/wiki/MPEG-4) standard dealing with time domain weighted interleaved vector quantization.

### Use in pattern recognition {#Use_in_pattern_recognition}

VQ was also used in the eighties for speech[^o13] and [speaker recognition](https://en.wikipedia.org/wiki/Speaker_recognition).[^o14] Recently it has also been used for efficient [nearest neighbor search](https://en.wikipedia.org/wiki/Nearest_neighbor_search) [^o15] and on-line signature recognition.[^o16] In [pattern recognition](wikipedia://en/126706) applications, one codebook is constructed for each class (each class being a user in biometric applications) using acoustic vectors of this user. In the testing phase the quantization distortion of a testing signal is worked out with the whole set of codebooks obtained in the training phase. The codebook that provides the smallest vector quantization distortion indicates the identified user.

The main advantage of VQ in [pattern recognition](wikipedia://en/126706) is its low computational burden when compared with other techniques such as [dynamic time warping](wikipedia://en/342855) (DTW) and [hidden Markov model](wikipedia://en/98770) (HMM). The main drawback when compared to DTW and HMM is that it does not take into account the temporal evolution of the signals (speech, signature, etc.) because all the vectors are mixed up. In order to overcome this problem a multi-section codebook approach has been proposed.[^o17] The multi-section approach consists of modelling the signal with several sections (for instance, one codebook for the initial part, another one for the center and a last codebook for the ending part).

### Use as clustering algorithm {#Use_as_clustering_algorithm}

As VQ is seeking for centroids as density points of nearby lying samples, it can be also directly used as a prototype-based clustering method: each centroid is then associated with one prototype. By aiming to minimize the expected squared quantization error[^o19] and introducing a decreasing learning gain fulfilling the Robbins-Monro conditions, multiple iterations over the whole data set with a concrete but fixed number of prototypes converges to the solution of [k-means](https://en.wikipedia.org/wiki/K-means) clustering algorithm in an incremental manner.

### Generative adversarial networks (GAN) {#Generative_adversarial_networks_(GAN)}

VQ has been used to quantize a feature representation layer in the discriminator of [generative adversarial networks](https://en.wikipedia.org/wiki/Generative_adversarial_network). The feature quantization (FQ) technique performs implicit feature matching.[^o21] It improves the GAN training, and yields an improved performance on a variety of popular GAN models: BigGAN for image generation, StyleGAN for face synthesis, and U-GAT-IT for unsupervised image-to-image translation.
