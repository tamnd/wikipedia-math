# Monotonic function

*Image: Monotonicity example1.svg.* Figure 1. A monotonically non-decreasing function

*Image: Monotonicity example2.svg.* Figure 2. A monotonically non-increasing function

*Image: Monotonicity example3.svg.* Figure 3. A function that is *not* monotonic

::: {#o1 .subject cue=lead name="Monotonic function"}

In [mathematics](wikipedia://en/18831), a **monotonic function** (or **monotone function**) is a [function](wikipedia://en/185427) between [ordered sets](wikipedia://en/203204) that preserves or reverses the given [order](https://en.wikipedia.org/wiki/Order_relation).[^o2][^o3][^o4] This concept first arose in [calculus](wikipedia://en/5176), and was later generalized to the more abstract setting of [order theory](wikipedia://en/361924).

:::

## In calculus and analysis {#In_calculus_and_analysis}

In [calculus](wikipedia://en/5176), a function $f$ defined on a [subset](wikipedia://en/27631) of the [real numbers](https://en.wikipedia.org/wiki/Real_numbers) with real values is called *monotonic* if it is either entirely non-decreasing, or entirely non-increasing.[^o3] That is, as per Fig. 1, a function that increases monotonically does not exclusively have to increase, it simply must not decrease.

A function is termed *monotonically increasing* (also *increasing* or *non-decreasing*)[^o4] if for all $x$ and $y$ such that $x \leq y$ one has $f\!\left(x\right) \leq f\!\left(y\right)$, so $f$ preserves the order (see Figure 1). Likewise, a function is called *monotonically decreasing* (also *decreasing* or *non-increasing*)[^o4] if, whenever $x \leq y$, then $f\!\left(x\right) \geq f\!\left(y\right)$, so it *reverses* the order (see Figure 2).

If the order $\leq$ in the definition of monotonicity is replaced by the strict order $<$, one obtains a stronger requirement. A function with this property is called *strictly increasing* (also *increasing*).[^o4][^o6] Again, by inverting the order symbol, one finds a corresponding concept called *strictly decreasing* (also *decreasing*).[^o4][^o6] A function with either property is called *strictly monotone*. Functions that are strictly monotone are [one-to-one](https://en.wikipedia.org/wiki/One-to-one_function) (because for $x$ not equal to $y$, either $x < y$ or $x > y$ and so, by monotonicity, either $f\!\left(x\right) < f\!\left(y\right)$ or $f\!\left(x\right) > f\!\left(y\right)$, thus $f\!\left(x\right) \neq f\!\left(y\right)$.

To avoid ambiguity, the terms *weakly monotone*, *weakly increasing* and *weakly decreasing* are often used to refer to non-strict monotonicity.

The terms "non-decreasing" and "non-increasing" should not be confused with the (much weaker) negative qualifications "not decreasing" and "not increasing". For example, the non-monotonic function shown in figure 3 first falls, then rises, then falls again. It is therefore not decreasing and not increasing, but it is neither non-decreasing nor non-increasing.

A function $f$ is said to be *absolutely monotonic* over an interval $\left(a, b\right)$ if the [derivatives](wikipedia://en/7921) of all orders of $f$ are [nonnegative](https://en.wikipedia.org/wiki/Nonnegative) or all [nonpositive](https://en.wikipedia.org/wiki/Nonpositive) at all points on the interval.

### Inverse of function {#Inverse_of_function}

All strictly monotonic functions are [invertible](wikipedia://en/14907) because they are guaranteed to have a one-to-one mapping from their range to their domain.

However, functions that are only weakly monotone need not be invertible; they may be constant on some interval (and therefore not one-to-one).

A function may be strictly monotonic over a limited a range of values and thus have an inverse on that range even though it is not strictly monotonic everywhere. For example, if $y = g(x)$ is strictly increasing on the range $[a, b]$, then it has an inverse $x = h(y)$ on the range $[g(a), g(b)]$.

The term *monotonic* is sometimes used in place of *strictly monotonic*, so a source may state that all monotonic functions are invertible when they really mean that all strictly monotonic functions are invertible.

### Monotonic transformation {#Monotonic_transformation}

The term *monotonic transformation* (or *monotone transformation*) may also cause confusion because it refers to a transformation by a strictly increasing function. This is the case in economics with respect to the ordinal properties of a [utility function](https://en.wikipedia.org/wiki/Utility_function) being preserved across a monotonic transform (see also [monotone preferences](https://en.wikipedia.org/wiki/Monotone_preferences)).[^o10] In this context, the term "monotonic transformation" refers to a positive monotonic transformation and is intended to distinguish it from a "negative monotonic transformation," which reverses the order of the numbers.[^o11]

:::

### Some basic applications and results {#Some_basic_applications_and_results}

*Image: Monotonic dense jumps svg.svg.* Monotonic function with a dense set of jump discontinuities (several sections shown)

*Image: Growth equations.png.* Plots of 6 monotonic growth functions

The following properties are true for a monotonic function $f\colon \mathbb{R} \to \mathbb{R}$:

- $f$ has [limits](wikipedia://en/285759) from the right and from the left at every point of its [domain](wikipedia://en/50263);
- $f$ has a limit at positive or negative infinity ($\pm\infty$) of either a real number, $\infty$, or $-\infty$.
- $f$ can only have [jump](https://en.wikipedia.org/wiki/Jump_discontinuities) and [removable discontinuities](https://en.wikipedia.org/wiki/Removable_discontinuity).
- $f$ can only have [countably](https://en.wikipedia.org/wiki/Countably) many [discontinuities](wikipedia://en/22278053) in its domain. The discontinuities, however, do not necessarily consist of isolated points and may even be [dense](wikipedia://en/23523594) in an interval (*a*, *b*). For example, for any [summable sequence](https://en.wikipedia.org/wiki/Summable_sequence) $(a_i)$ of positive numbers and any enumeration $(q_i)$ of the [rational numbers](wikipedia://en/19727024), the monotonically increasing function $$f(x)=\sum_{q_i\leq x} a_i$$ is continuous exactly at every irrational number (cf. picture). It is the [cumulative distribution function](wikipedia://en/5793) of the [discrete measure](wikipedia://en/8912350) on the rational numbers, where $a_i$ is the weight of $q_i$.
- If $f$ is [differentiable](https://en.wikipedia.org/wiki/Differentiable) at $x^*\in\mathbb R$ and $f'(x^*)>0$, then there is a non-degenerate [interval](wikipedia://en/49172) *I* such that $x^*\in I$ and $f$ is increasing on *I*.
- As a partial converse, if $f$ is differentiable and increasing on an interval, $I$, then its derivative is nonnegative at every point in $I$. Furthermore, the set $A = \{x\in I: f'(x) > 0\}$ is dense with positive [Lebesgue measure](wikipedia://en/18198). Not much more can be said about $A$; for instance, $A$ may be [meagre](wikipedia://en/226975), as in the case of a [Pompeiu derivative](wikipedia://en/26580514), and for fixed $I$, the Lebesgue measure of $A$ can be made arbitrarily close to $0$ via a suitable choice of $f$.

These properties are the reason why monotonic functions are useful in technical work in [analysis](wikipedia://en/48396). Other important properties of these functions include:

- if $f$ is a monotonic function defined on an [interval](wikipedia://en/49172) $I$, then $f$ is [differentiable](wikipedia://en/7921) [almost everywhere](wikipedia://en/44688) on $I$; i.e. the set of numbers $x$ in $I$ such that $f$ is not differentiable in $x$ has [Lebesgue](wikipedia://en/18198) [measure zero](https://en.wikipedia.org/wiki/Measure_zero). In addition, this result cannot be improved to countable: see [Cantor function](wikipedia://en/320819).
- if this set is countable, then $f$ is absolutely continuous
- if $f$ is a monotonic function defined on an interval $\left[a, b\right]$, then $f$ is [Riemann integrable](wikipedia://en/26390).

An important application of monotonic functions is in [probability theory](wikipedia://en/23542). If $X$ is a [random variable](wikipedia://en/25685), its [cumulative distribution function](wikipedia://en/5793) $F_X\!\left(x\right) = \text{Prob}\!\left(X \leq x\right)$ is a monotonically increasing function.

A function is *[unimodal](https://en.wikipedia.org/wiki/Unimodal_function)* if it is monotonically increasing up to some point (the *[mode](wikipedia://en/298420)*) and then monotonically decreasing.

When $f$ is a *strictly monotonic* function, then $f$ is [injective](https://en.wikipedia.org/wiki/Injective) on its domain, and if $T$ is the [range](wikipedia://en/275991) of $f$, then there is an [inverse function](wikipedia://en/14907) on $T$ for $f$. In contrast, each constant function is monotonic, but not injective,[^o13] and hence cannot have an inverse.

## In topology {#In_topology}

A map $f: X \to Y$ is said to be *monotone* if each of its [fibers](wikipedia://en/6603892#Fiber_in_naive_set_theory) is [connected](https://en.wikipedia.org/wiki/Connected_%28topology%29); that is, for each element $y \in Y,$ the (possibly empty) set $f^{-1}(y)$ is a connected [subspace](wikipedia://en/910926) of $X.$

:::

## In functional analysis {#In_functional_analysis}

In [functional analysis](wikipedia://en/11180) on a [topological vector space](wikipedia://en/45752) $X$, a (possibly non-linear) operator $T: X \rightarrow X^*$ is said to be a *monotone operator* if

$$(Tu - Tv, u - v) \geq 0 \quad \forall u,v \in X.$$

[Kachurovskii's theorem](wikipedia://en/13213280) shows that [convex functions](wikipedia://en/245568) on [Banach spaces](wikipedia://en/3989) have monotonic operators as their derivatives.

A subset $G$ of $X \times X^*$ is said to be a *monotone set* if for every pair $[u_1, w_1]$ and $[u_2, w_2]$ in $G$,

$$(w_1 - w_2, u_1 - u_2) \geq 0.$$

$G$ is said to be *maximal monotone* if it is maximal among all monotone sets in the sense of set inclusion. The graph of a monotone operator $G(T)$ is a monotone set. A monotone operator is said to be *maximal monotone* if its graph is a *maximal monotone set*.

:::

## In order theory {#In_order_theory}

Order theory deals with arbitrary [partially ordered sets](wikipedia://en/23572) and [preordered sets](wikipedia://en/23582) as a generalization of real numbers. The above definition of monotonicity is relevant in these cases as well. However, the terms "increasing" and "decreasing" are avoided, since their conventional pictorial representation does not apply to orders that are not [total](wikipedia://en/30330). Furthermore, the [strict](https://en.wikipedia.org/wiki/Strict_order) relations $<$ and $>$ are of little use in many non-total orders and hence no additional terminology is introduced for them.

Letting $\leq$ denote the partial order relation of any partially ordered set, a *monotone* function, also called *isotone*, or *order-preserving*, satisfies the property

$$x \leq y \implies f(x) \leq f(y)$$

for all $x$ and $y$ in its domain. The composite of two monotone mappings is also monotone.

The [dual](wikipedia://en/600618) notion is often called *antitone*, *anti-monotone*, or *order-reversing*. Hence, an antitone function $f$ satisfies the property

$$x \leq y \implies f(y) \leq f(x),$$

for all $x$ and $y$ in its domain.

A [constant function](wikipedia://en/320861) is both monotone and antitone; conversely, if $f$ is both monotone and antitone, and if the domain of $f$ is a [lattice](wikipedia://en/469304), then $f$ must be constant.

Monotone functions are central in order theory. They appear in most articles on the subject and examples from special applications are found in these places. Some notable special monotone functions are [order embeddings](wikipedia://en/762203) (functions for which $x \leq y$ [if and only if](wikipedia://en/14922) $f(x) \leq f(y))$ and [order isomorphisms](wikipedia://en/23916899) ([surjective](https://en.wikipedia.org/wiki/Surjective) order embeddings).

## In the context of search algorithms {#In_the_context_of_search_algorithms}

In the context of [search algorithms](https://en.wikipedia.org/wiki/Search_algorithm) monotonicity (also called consistency) is a condition applied to [heuristic functions](https://en.wikipedia.org/wiki/Heuristic_function). A heuristic $h(n)$ is monotonic if, for every node $n$ and every successor $n'$ of $n$ generated by any action $a$, the estimated cost of reaching the goal from $n$ is no greater than the step cost of getting to $n'$ plus the estimated cost of reaching the goal from $n'$,

$$h(n) \leq c\left(n, a, n'\right) + h\left(n'\right) .$$

This is a form of [triangle inequality](wikipedia://en/53941), with $n$, $n'$, and the goal $G_{n}$ closest to $n$. Because every monotonic heuristic is also [admissible](https://en.wikipedia.org/wiki/Admissible_heuristic), monotonicity is a stricter requirement than admissibility. Some [heuristic algorithms](https://en.wikipedia.org/wiki/Heuristic_algorithm) such as [A\*](wikipedia://en/100558) can be proven [optimal](https://en.wikipedia.org/wiki/Asymptotically_optimal_algorithm) provided that the heuristic they use is monotonic.[^o20]

## In Boolean functions {#In_Boolean_functions}

| *Image: Hasse3 ge2.svg.* Hasse diagram of the monotonic function "at least two of $a$, $b$, $c$ hold". Colors indicate function output values. |
|---|

In [Boolean algebra](wikipedia://en/54476844), a monotonic function is one such that for all $a_{i}$ and $b_{i}$ in $\{0,1\}$, if $a_{1} \le b_{1}$, $a_{2} \le b_{2}$, ..., $a_{n} \le b_{n}$ (i.e. the Cartesian product $\{0, 1\}^{n}$ is ordered [coordinatewise](https://en.wikipedia.org/wiki/Coordinatewise_order)), then $f(a_{1}, ..., a_{n}) \le f(b_{1}, ..., b_{n})$. In other words, a Boolean function is monotonic if, for every combination of inputs, switching one of the inputs from false to true can only cause the output to switch from false to true and not from true to false. Graphically, this means that an $n$-ary Boolean function is monotonic when its representation as an [$n$-cube](wikipedia://en/39783) labelled with truth values has no upward edge from *true* to *false*. (This labelled [Hasse diagram](wikipedia://en/338199) is the [dual](wikipedia://en/609737#Dimension-reversing_dualities) of the function's labelled [Venn diagram](wikipedia://en/61701), which is the more common representation for $n \le 3$.)

The monotonic Boolean functions are precisely those that can be defined by an expression combining the inputs (which may appear more than once) using only the operators *[and](wikipedia://en/18152)* and *[or](wikipedia://en/7962)* (in particular *[not](wikipedia://en/161019)* is forbidden). For instance "at least two of $a$, $b$, $c$ hold" (the ternary [majority function](wikipedia://en/20823)) is a monotonic function of $a$, $b$, $c$, since it can be written for instance as (($a$ and $b$) or ($a$ and $c$) or ($b$ and $c$)).

The number of such functions on $n$ variables is known as the [Dedekind number](wikipedia://en/21452705) of $n$.

[SAT solving](https://en.wikipedia.org/wiki/SAT_solving), generally an [NP-hard](https://en.wikipedia.org/wiki/NP-hard) task, can be achieved efficiently when all involved functions and predicates are monotonic and Boolean.[^o23]
