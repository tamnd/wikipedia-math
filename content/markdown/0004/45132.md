# Truth condition

::: {#o1 .subject cue=lead name="Truth condition"}

In [semantics](wikipedia://en/29107) and [pragmatics](https://en.wikipedia.org/wiki/Pragmatics), a **truth condition** is the condition under which a [sentence](https://en.wikipedia.org/wiki/Sentence_%28linguistics%29) is [true](wikipedia://en/29920). For example, "It is snowing in [Nebraska](https://en.wikipedia.org/wiki/Nebraska)" is true precisely when it is snowing in Nebraska. Truth conditions of a sentence do not necessarily reflect current reality. They are merely the conditions under which the statement would be true.[^o2]

:::

More formally, a truth condition makes a sentence true for a given [inductive definition of truth](wikipedia://en/601240#Tarski's_theory_of_truth). Understood this way, truth conditions are [theoretical entities](https://en.wikipedia.org/wiki/Theoretical_entities). To illustrate with an example: suppose that, in a particular truth theory[^o3] which is a theory of truth where truth is somehow made acceptable despite semantic terms as close as possible, the word "Nixon" [refers](wikipedia://en/20110874) to [Richard M. Nixon](https://en.wikipedia.org/wiki/Richard_M._Nixon), and "is alive" is associated with the [set](wikipedia://en/26691) of currently living things. Then one way of representing the truth condition of "Nixon is alive" is as the [ordered pair](wikipedia://en/22362) \<Nixon, {x: x is alive}>. And we say that "Nixon is alive" is true if and only if the referent (or referent of) "Nixon" belongs to the set associated with "is alive", that is, if and only if Nixon is alive.

In semantics, the truth condition of a sentence is almost universally considered distinct from its [meaning](https://en.wikipedia.org/wiki/Meaning_%28linguistics%29). The meaning of a sentence is conveyed if the truth conditions for the sentence are understood. Additionally, there are many sentences that are understood although their truth condition is [uncertain](wikipedia://en/63778). One popular argument for this view is that some sentences are [necessarily true](wikipedia://en/3986852)—that is, they are true whatever happens to obtain. All such sentences have the same truth conditions, but arguably do not thereby have the same meaning. Likewise, the sets {x: x is alive} and {x: x is alive and x is not a rock} are identical—they have precisely the same members—but presumably the sentences "Nixon is alive" and "Nixon is alive and is not a rock" have different meanings.
