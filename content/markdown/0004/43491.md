# Heuristic argument

::: {#o1 .subject cue=lead name="Heuristic argument"}

A **heuristic argument** is an [argument](wikipedia://en/13018310) that reasons from the value of a method or principle that has been shown experimentally (especially through [trial-and-error](https://en.wikipedia.org/wiki/Trial-and-error)) to be useful or convincing in learning, discovery and [problem-solving](https://en.wikipedia.org/wiki/Problem-solving), but whose line of reasoning involves key oversimplifications that make it not entirely rigorous.[^o2] A widely used and important example of a [heuristic](https://en.wikipedia.org/wiki/Heuristic) argument is [Occam's razor](wikipedia://en/36797).

:::

It is a speculative, non-rigorous argument that relies on analogy or intuition, and that allows one to achieve a result or an approximation that is to be checked later with more rigor. Otherwise, the results are generally to be doubted. It is used as a hypothesis or a conjecture in an investigation, though it can also be used as a mnemonic as well.[^o3]
