# Turing tarpit

::: {#o1 .subject cue=lead name="Turing tarpit"}

A **Turing tarpit** (or **Turing tar-pit**) is any [programming language](wikipedia://en/23015) or [computer interface](https://en.wikipedia.org/wiki/Computer_interface) that allows for flexibility in function but is difficult to learn and use because it offers little or no support for common tasks.[^o2] The phrase was coined in 1982 by [Alan Perlis](https://en.wikipedia.org/wiki/Alan_Perlis) in the *[Epigrams on Programming](https://en.wikipedia.org/wiki/Epigrams_on_Programming)*:[^o3]

:::

\54. Beware of the Turing tar-pit in which everything is possible but nothing of interest is easy.

Perlis did not further explain the term or offer examples, leaving his meaning open to interpretation. "Turing" has generally been understood to refer to the [Church–Turing thesis](wikipedia://en/6854), which holds that certain simple models of computation are sufficient to express any numerical calculation procedure, even though doing so in practice might be a daunting task.

As a pioneer in programming language technology, Perlis participated in the specification of [ALGOL](https://en.wikipedia.org/wiki/ALGOL), a language that provided a rich procedural syntax but no standard [input/output](https://en.wikipedia.org/wiki/Input/output) facilities. Accordingly, [Peter Wegner](https://en.wikipedia.org/wiki/Peter_Wegner_%28computer_scientist%29) identified real-time interaction with an environment as an aspect of practical computing that models like the [Turing machine](wikipedia://en/30403) failed to address.[^o4]

The term has since become associated with [esoteric programming languages](https://en.wikipedia.org/wiki/Esoteric_programming_language) that are intentionally designed to be universal but impractical.[^o5] Using such languages is a form of [mathematical recreation](https://en.wikipedia.org/wiki/Mathematical_recreation): programmers can work out how to achieve basic programming constructs in an extremely difficult but mathematically [Turing-equivalent](wikipedia://en/30621) language.[^o6]
