# Bounded set

*Image: Bounded unbounded.svg.* An [artist's impression](https://en.wikipedia.org/wiki/Artist's_impression) of a bounded set (top) and of an unbounded set (bottom). The set at the bottom continues forever towards the right.

::: {#o1 .subject cue=lead name="Bounded set"}

In [mathematical analysis](wikipedia://en/48396) and related areas of [mathematics](wikipedia://en/18831), a [set](wikipedia://en/26691) is called **bounded** if all of its points are within a certain distance of each other. Conversely, a set which is not bounded is called **unbounded**. The word "bounded" makes no sense in a general topological space without a corresponding [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29).

:::

*[Boundary](wikipedia://en/72824)* is a distinct concept; for example, a [circle](wikipedia://en/6220) (not to be confused with a [disk](wikipedia://en/329542)) in isolation is a boundaryless bounded set, while the [half plane](https://en.wikipedia.org/wiki/Half_plane) is unbounded yet has a boundary.

A bounded set is not necessarily a [closed set](wikipedia://en/47279) and vice versa. For example, a subset $S$ of a 2-dimensional real space $\mathbf{R}^{2}$ constrained by two parabolic curves $x^{2} + 1$ and $x^{2} - 1$ defined in a [Cartesian coordinate system](wikipedia://en/7706) is closed by the curves but not bounded (so unbounded).

## Definition in the real numbers {#Definition_in_the_real_numbers}

*Image: Illustration of supremum.svg.* A real set with upper bounds and its [supremum](https://en.wikipedia.org/wiki/Supremum).

A set $S$ of [real numbers](wikipedia://en/20646438) is called *bounded from above* if there exists some real number $k$ (not necessarily in $S$) such that $k \ge s$ for all $s$ in $S$. The number $k$ is called an **upper bound** of $S$. The terms *bounded from below* and **lower bound** are similarly defined.

A set $S$ is **bounded** if it has both upper and lower bounds. Therefore, a set of real numbers is bounded if it is contained in a [finite interval](wikipedia://en/49172).

## Definition in a metric space {#Definition_in_a_metric_space}

A [subset](wikipedia://en/27631) $S$ of a [metric space](wikipedia://en/20018) $(M, d)$ is **bounded** if there exists $r > 0$ such that for all $s$ and $t$ in $S$, we have $d(s, t) < r$. The metric space $(M, d)$ is a *bounded* metric space (or $d$ is a *bounded* metric) if $M$ is bounded as a subset of itself.

- [Total boundedness](https://en.wikipedia.org/wiki/Total_boundedness) implies boundedness. For subsets of $\mathbf{R}^{n}$ the two are equivalent.
- A metric space is [compact](wikipedia://en/6042) if and only if it is [complete](wikipedia://en/7832) and totally bounded.
- A subset of [Euclidean space](wikipedia://en/9697) $\mathbf{R}^{n}$ is compact if and only if it is [closed](wikipedia://en/47279) and bounded. This is also called the [Heine-Borel theorem](https://en.wikipedia.org/wiki/Heine-Borel_theorem).

## Boundedness in topological vector spaces {#Boundedness_in_topological_vector_spaces}

In [topological vector spaces](wikipedia://en/45752), a different definition for bounded sets exists which is sometimes called [von Neumann boundedness](https://en.wikipedia.org/wiki/Von_Neumann_bounded). If the topology of the topological vector space is induced by a [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) which is [homogeneous](https://en.wikipedia.org/wiki/Homogeneous_metric), as in the case of a metric induced by the [norm](wikipedia://en/990534) of [normed vector spaces](https://en.wikipedia.org/wiki/Normed_vector_spaces), then the two definitions coincide.

## Boundedness in order theory {#Boundedness_in_order_theory}

A set of real numbers is bounded if and only if it has an upper and lower bound. This definition is extendable to subsets of any [partially ordered set](wikipedia://en/23572). Note that this more general concept of boundedness does not correspond to a notion of "size".

A subset $S$ of a partially ordered set $P$ is called **bounded above** if there is an element $k$ in $P$ such that $k \ge s$ for all $s$ in $S$. The element $k$ is called an **upper bound** of $S$. The concepts of **bounded below** and **lower bound** are defined similarly. (See also [upper and lower bounds](wikipedia://en/42693).)

A subset $S$ of a partially ordered set $P$ is called **bounded** if it has both an upper and a lower bound, or equivalently, if it is contained in an [interval](wikipedia://en/49172#Intervals_in_order_theory). Note that this is not just a property of the set $S$ but also one of the set $S$ as subset of $P$.

A **bounded poset** $P$ (that is, by itself, not as subset) is one that has a least element and a [greatest element](https://en.wikipedia.org/wiki/Greatest_element). Note that this concept of boundedness has nothing to do with finite size, and that a subset $S$ of a bounded poset $P$ with as order the [restriction](wikipedia://en/3931#Restriction) of the order on $P$ is not necessarily a bounded poset.

A subset $S$ of $\mathbf{R}^{n}$ is bounded with respect to the [Euclidean distance](wikipedia://en/53932) if and only if it bounded as subset of $\mathbf{R}^{n}$ with the [product order](wikipedia://en/1956306). However, $S$ may be bounded as subset of $\mathbf{R}^{n}$ with the [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order), but not with respect to the Euclidean distance.

A class of [ordinal numbers](wikipedia://en/26547932) is said to be unbounded, or [cofinal](wikipedia://en/1633290), when given any ordinal, there is always some element of the class greater than it. Thus in this case "unbounded" does not mean unbounded by itself but unbounded as a subclass of the class of all ordinal numbers.
