# Almost everywhere

*Image: Function-1 x.svg.* The function [1/x](https://en.wikipedia.org/wiki/1/x) is [differentiable](https://en.wikipedia.org/wiki/Differentiable) and [continuous](wikipedia://en/6122) almost everywhere; more precisely, everywhere except at x = 0.

::: {#o1 .subject cue=lead name="Almost everywhere"}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory) (a branch of [mathematical analysis](wikipedia://en/48396)), a property holds **almost everywhere** (sometimes abbreviated as **a.e.**) if the set for which the property does not hold is negligible in a technical sense. The notion of "almost everywhere" is a companion notion to the concept of [measure zero](https://en.wikipedia.org/wiki/Measure_zero), and is analogous to the notion of *[almost surely](wikipedia://en/351908)* in [probability theory](wikipedia://en/23542).

:::

More specifically, a property holds almost everywhere if it holds for all elements in a set except a subset of measure zero,[^o2][^o3] or equivalently, if the set of elements for which the property holds is [conull](wikipedia://en/735067). In cases where the measure is not [complete](wikipedia://en/44775), it is sufficient that the set be contained within a set of measure zero. When discussing sets of [real numbers](wikipedia://en/20646438), the [Lebesgue measure](wikipedia://en/18198) is usually assumed unless otherwise stated.

The term *almost everywhere* is abbreviated *a.e.*;[^o4] in older literature *p.p.* is used, to stand for the equivalent [French](https://en.wikipedia.org/wiki/French_language) phrase presque partout.[^o5]

A set with **full measure** is one whose complement is of measure zero. In probability theory, the terms *almost surely*, *almost certain* and *almost always* refer to [events](wikipedia://en/22961) with [probability](wikipedia://en/22934) 1 not necessarily including all of the outcomes. These are exactly the sets of full measure in a probability space.

Occasionally, instead of saying that a property holds almost everywhere, it is said that the property holds for **almost all** elements (though the term [almost all](wikipedia://en/1309) can also have other meanings).

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $(X,\Sigma,\mu)$ is a [measure space](wikipedia://en/45270), a property $P$ is said to hold almost everywhere in $X$ if there exists a measurable set $N \in \Sigma$ with $\mu(N) = 0$, and all $x\in X\setminus N$ have the property $P$.[^o8] Another common way of expressing the same thing is to say that "almost every point satisfies $P\,$", or that "for almost every $x$, $P(x)$ holds".

It is *not* required that the set $\{x\in X: \neg P(x)\}$ has measure zero; it may not be measurable. By the above definition, it is sufficient that $\{x\in X: \neg P(x)\}$ be contained in some set $N$ that is measurable and has measure zero. However, this technicality vanishes when considering a [complete measure space](https://en.wikipedia.org/wiki/Complete_measure_space): if $X$ is complete then $N$ exists with measure zero if and only if $\{x\in X: \neg P(x)\}$ is measurable with measure zero.

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If property $P$ holds almost everywhere and implies property *$Q$*, then property *$Q$* holds almost everywhere. This follows from the [monotonicity](wikipedia://en/19873#Monotonicity) of measures.
- If $(P_n)$ is a finite or a countable sequence of properties, each of which holds almost everywhere, then their conjunction $\forall n P_n$ holds almost everywhere. This follows from the [countable sub-additivity](wikipedia://en/19873#Measures_of_infinite_unions_of_measurable_sets) of measures.
- By contrast, if $(P_x)_{x\in \mathbf R}$ is an uncountable family of properties, each of which holds almost everywhere, then their conjunction $\forall x P_x$ does not necessarily hold almost everywhere. For example, if $\mu$ is Lebesgue measure on $X = \mathbf R$ and $P_x$ is the property of not being equal to $x$ (i.e. $P_x(y)$ is true if and only if $y \neq x$), then each $P_x$ holds almost everywhere, but the conjunction $\forall x P_x$ does not hold anywhere.

As a consequence of the first two properties, it is often possible to reason about "almost every point" of a measure space as though it were an ordinary point rather than an abstraction. This is often done implicitly in informal mathematical arguments. However, one must be careful with this mode of reasoning because of the third bullet above: universal quantification over uncountable families of statements is valid for ordinary points but not for "almost every point".

:::

::: {#o12 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *f* : **R** → **R** is a [Lebesgue integrable](wikipedia://en/26064288) function and $f(x) \ge 0$ almost everywhere, then $$\int_a^b f(x) \, dx \geq 0$$ for all real numbers $a < b$ with equality [if and only if](wikipedia://en/14922) $f(x) = 0$ almost everywhere.
- If *f* : \[*a*, *b*\] → **R** is a [monotonic function](wikipedia://en/48260), then *f* is [differentiable](wikipedia://en/7921) almost everywhere.
- If *f* : **R** → **R** is [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable) and $$\int_a^b |f(x)| \, dx < \infty$$ for all real numbers $a < b$, then there exists a set *E* (depending on *f*) such that, if *x* is in *E*, the Lebesgue mean $$\frac{1}{2\varepsilon} \int_{x-\varepsilon}^{x+\varepsilon} f(t)\,dt$$ converges to $f(x)$ as $\epsilon$ decreases to zero. The set *E* is called the Lebesgue set of *f*. Its complement can be proved to have measure zero. In other words, the Lebesgue mean of *f* converges to *f* almost everywhere.
- A bounded [function](wikipedia://en/185427) $f : [a, b] \to \mathbf{R}$ is [Riemann integrable](wikipedia://en/26390) if and only if it is [continuous](wikipedia://en/6122) almost everywhere.
- As a curiosity, the decimal expansion of almost every real number in the interval \[0, 1\] contains the complete text of [Shakespeare's plays](https://en.wikipedia.org/wiki/Shakespeare's_plays), encoded in [ASCII](https://en.wikipedia.org/wiki/ASCII); similarly for every other finite digit sequence, see [Normal number](wikipedia://en/204277).

:::

## Definition using ultrafilters {#Definition_using_ultrafilters}

Outside of the context of real analysis, the notion of a property true almost everywhere is sometimes defined in terms of an [ultrafilter](wikipedia://en/31911). An ultrafilter on a set *X* is a maximal collection *F* of subsets of *X* such that:

1. If *U* ∈ *F* and *U* ⊆ *V* then *V* ∈ *F*
1. The intersection of any two sets in *F* is in *F*
1. The empty set is not in *F*

A property *P* of points in *X* holds almost everywhere, relative to an ultrafilter *F*, if the set of points for which *P* holds is in *F*.

For example, one construction of the [hyperreal number](wikipedia://en/51429) system defines a hyperreal number as an equivalence class of sequences that are equal almost everywhere as defined by an ultrafilter.

The definition of *almost everywhere* in terms of ultrafilters is closely related to the definition in terms of measures, because each ultrafilter defines a finitely-additive measure taking only the values 0 and 1, where a set has measure 1 if and only if it is included in the ultrafilter.

With this notion of "almost everywhere" [Łoś's theorem](https://en.wikipedia.org/wiki/Łoś's_theorem) can be understood as saying that a [first-order formula](https://en.wikipedia.org/wiki/First-order_formula) is true in an [ultraproduct](wikipedia://en/273642) if and only if it's true in almost all of the factors.
