# Datagram Transport Layer Security

::: {#o1 .subject cue=lead name="Datagram Transport Layer Security"}

**Datagram Transport Layer Security** (**DTLS**) is a [communications protocol](https://en.wikipedia.org/wiki/Communications_protocol) providing [security](wikipedia://en/40922) to [datagram](https://en.wikipedia.org/wiki/Datagram)-based applications by allowing them to communicate in a way designed434763479147 to prevent [eavesdropping](https://en.wikipedia.org/wiki/Eavesdropping), [tampering](https://en.wikipedia.org/wiki/Man_in_the_middle_attack), or [message forgery](wikipedia://en/603812). The DTLS protocol is based on the [stream](https://en.wikipedia.org/wiki/Stream_%28computing%29)-oriented [Transport Layer Security](wikipedia://en/187813) (TLS) protocol and is intended to provide similar security guarantees. The DTLS protocol datagram preserves the semantics of the underlying transport—the application does not suffer from the delays associated with stream protocols, but because it uses [User Datagram Protocol](https://en.wikipedia.org/wiki/User_Datagram_Protocol) (UDP) or [Stream Control Transmission Protocol](https://en.wikipedia.org/wiki/Stream_Control_Transmission_Protocol) (SCTP), the application has to deal with [packet reordering](https://en.wikipedia.org/wiki/Packet_reordering), loss of datagram and data larger than the size of a datagram [network packet](https://en.wikipedia.org/wiki/Network_packet). Because DTLS uses UDP or SCTP rather than TCP it avoids the [TCP meltdown problem](https://en.wikipedia.org/wiki/TCP_meltdown_problem)[^o2][^o3] when being used to create a VPN tunnel.

:::

## Definition {#Definition}

The following documents define DTLS:

- 5238 from May 20085238 for use with [Datagram Congestion Control Protocol](https://en.wikipedia.org/wiki/Datagram_Congestion_Control_Protocol) (DCCP)
- 5415 from March 20095415 for use with [Control And Provisioning of Wireless Access Points](https://en.wikipedia.org/wiki/CAPWAP) (CAPWAP)
- 5764 from May 20105764 for use with [Secure Real-time Transport Protocol](https://en.wikipedia.org/wiki/Secure_Real-time_Transport_Protocol) (SRTP) subsequently called **DTLS-SRTP** in a draft with [Secure Real-Time Transport Control Protocol](https://en.wikipedia.org/wiki/Secure_Real-Time_Transport_Control_Protocol) (SRTCP)[^o6]
- 6083 from January 20116083 for use with [Stream Control Transmission Protocol](https://en.wikipedia.org/wiki/Stream_Control_Transmission_Protocol) (SCTP) encapsulation
- 6347 from January 20126347 defining DTLS 1.2
- 9147 from April 20229147 defining DTLS 1.3

DTLS 1.0 is based on TLS 1.1, DTLS 1.2 is based on TLS 1.2, and DTLS 1.3 is based on TLS 1.3. There is no DTLS 1.1 because this version-number was skipped in order to harmonize version numbers with TLS.6347 Like previous DTLS versions, DTLS 1.3 is intended to provide "equivalent security guarantees \[to TLS 1.3\] with the exception of order protection/non-replayability".[^o7]

::: {#o50 .application cue=heading name="Applications"}

### Applications {#Applications}

- [Cisco](https://en.wikipedia.org/wiki/Cisco_Systems) [AnyConnect](https://en.wikipedia.org/wiki/AnyConnect) VPN Client uses TLS and invented DTLS-based VPN.[^o51]
- [OpenConnect](https://en.wikipedia.org/wiki/OpenConnect) is an open source AnyConnect-compatible client and [ocserv](https://en.wikipedia.org/wiki/Ocserv) server that supports (D)TLS.[^o52]
- Cisco InterCloud Fabric uses DTLS to form a tunnel between private and public/provider compute environments.[^o53]
- [Cato Networks](https://en.wikipedia.org/wiki/Cato_Networks) utilizes DTLS v1.2 for the underlay tunnel used by both the Cato Socket and Cato ZTNA (formerly SDP) client when forming tunnels to the Cato POPs [^o54] and when forming off-cloud tunnels between Cato sockets.[^o55]
- [ZScaler](https://en.wikipedia.org/wiki/Zscaler) tunnel 2.0 for ZScaler Internet Access (ZIA) uses DTLS for tunneling. ZScaler Private Access (ZPA) does not support DTLS [^o56]
- F5 Networks [Edge VPN Client](https://en.wikipedia.org/wiki/F5_Networks#BIG-IP_product_modules) uses TLS and DTLS.[^o57]
- Fortinet's SSL VPN[^o58] and Array Networks SSL VPN[^o59] also use DTLS for VPN tunneling.
- Citrix Systems [NetScaler](https://en.wikipedia.org/wiki/Citrix_Systems#Networking_and_cloud) uses DTLS to secure UDP.[^o60]
- Web browsers: [Google Chrome](https://en.wikipedia.org/wiki/Google_Chrome), [Opera](https://en.wikipedia.org/wiki/Opera_%28web_browser%29) and [Firefox](https://en.wikipedia.org/wiki/Firefox) support DTLS-SRTP[^o61] for [WebRTC](https://en.wikipedia.org/wiki/WebRTC). Firefox 86 and onward does not support DTLS 1.0.[^o62]
- [Remote Desktop Protocol](https://en.wikipedia.org/wiki/Remote_Desktop_Protocol) 8.0 and onwards.

## Vulnerabilities {#Vulnerabilities}

In February 2013 two researchers from Royal Holloway, University of London discovered a timing attack[^o64] which allowed them to recover (parts of the) plaintext from a DTLS connection using the OpenSSL or GnuTLS implementation of DTLS when [Cipher Block Chaining](https://en.wikipedia.org/wiki/Cipher_Block_Chaining) mode encryption was used.
