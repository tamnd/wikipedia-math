# Nimbus (cipher)

::: {#o1 .subject cue=lead name="Nimbus"}

In [cryptography](wikipedia://en/18934432), **Nimbus** is a [block cipher](wikipedia://en/4594) invented by [Alexis Machado](https://en.wikipedia.org/wiki/Alexis_Machado) in 2000. It was submitted to the [NESSIE](wikipedia://en/497430) project, but was not selected.

:::

The algorithm uses a 128-bit key. It operates on blocks of 64 bits and consists of 5 rounds of encryption. The round function is exceedingly simple. In each round the block is [XORed](https://en.wikipedia.org/wiki/XOR) with a subkey, the order of its bits is reversed, and then it is multiplied mod 2<sup>64</sup> by another subkey, which is forced to be odd.[^o3]

Nimbus was broken by [Vladimir Furman](https://en.wikipedia.org/wiki/Vladimir_Furman); he found a [differential attack](wikipedia://en/8536) using only 256 chosen plaintexts.[^o4]
