# CryptoBuddy

::: {#o1 .subject cue=lead name="CryptoBuddy"}

**CryptoBuddy** is a simple [software](https://en.wikipedia.org/wiki/Software) application for the [encryption](wikipedia://en/10294) and [compression](wikipedia://en/8013) of computer files to make them safe and secure.[^o2][^o3]

:::

## Overview {#Overview}

The application uses a 64-bit [block cipher](wikipedia://en/4594) algorithm for encryption and a proprietary compression algorithm. The CryptoBuddy software is also used as part of the CryptoStick encryption device from Research Triangle Software, Inc.

## Release {#Release}

The software was released for public use on June 12, 2002.[^o6]
