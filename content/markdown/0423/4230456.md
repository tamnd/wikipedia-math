# Singular point of a curve

::: {#o1 .subject cue=lead name="Singular point of a curve"}

In [geometry](wikipedia://en/18973446), a **singular point** on a [curve](wikipedia://en/89246) is one where the curve is not given by a [smooth](https://en.wikipedia.org/wiki/Smooth_function) embedding of a [parameter](wikipedia://en/453198). The precise definition of a singular point depends on the type of curve being studied.

:::

## Algebraic curves in the plane {#Algebraic_curves_in_the_plane}

[Algebraic curves in the plane](https://en.wikipedia.org/wiki/Plane_algebraic_curve) may be defined as the set of points $(x, y)$ satisfying an equation of the form $f(x,y) = 0,$ where $f$ is a [polynomial](wikipedia://en/23000) function $f: \mathbb{R}^2 \to \mathbb{R}.$ If $f$ is expanded as

$$f = a_0 + b_0 x + b_1 y + c_0 x^2 + 2c_1 xy + c_2 y^2 + \cdots$$

If the origin $(0, 0)$ is on the curve then $a_{0} = 0$. If $b_{1} \ne 0$ then the [implicit function theorem](wikipedia://en/581005) guarantees there is a smooth function $h$ so that the curve has the form $y = h(x)$ near the origin. Similarly, if $b_{0} \ne 0$ then there is a smooth function $k$ so that the curve has the form $x = k(y)$ near the origin. In either case, there is a smooth map from $\mathbb{R}$ to the plane which defines the curve in the neighborhood of the origin. Note that at the origin

$$b_0 = \frac{\partial f}{\partial x}, \; b_1 = \frac{\partial f}{\partial y},$$

so the curve is non-singular or *regular* at the origin if at least one of the [partial derivatives](wikipedia://en/52565) of $f$ is non-zero. The singular points are those points on the curve where both partial derivatives vanish,

$$f(x,y) = \frac{\partial f}{\partial x} = \frac{\partial f}{\partial y} = 0.$$

### Regular points {#Regular_points}

Assume the curve passes through the origin and write $y = mx.$ Then $f$ can be written

$$f= (b_0 + m b_1) x + (c_0 + 2m c_1 + c_2 m^2)x^2 + \cdots.$$

If $b_0 + mb_1$ is not 0 then $f = 0$ has a solution of multiplicity 1 at $x = 0$ and the origin is a point of single contact with line $y = mx.$ If $b_0 + mb_1 = 0$ then $f = 0$ has a solution of multiplicity 2 or higher and the line $y = mx,$ or $b_0x + b_1y = 0,$ is tangent to the curve. In this case, if $c_0 + 2mc_1 + c_2m^2$ is not 0 then the curve has a point of double contact with $y = mx.$ If the coefficient of $x^{2}$, $c_0 + 2mc_1 + c_2m^2,$ is 0 but the coefficient of $x^{3}$ is not then the origin is a [point of inflection](wikipedia://en/379845) of the curve. If the coefficients of $x^{2}$ and $x^{3}$ are both 0 then the origin is called *point of undulation* of the curve. This analysis can be applied to any point on the curve by translating the coordinate axes so that the origin is at the given point.[^o4]

::: {#o6 .pointer-item cue=pointer name="Double point"}

### Double points {#Double_points}

*Image: Limacons.svg.* Three [limaçons](wikipedia://en/641715) illustrating the types of double point. When converted to [Cartesian coordinates](https://en.wikipedia.org/wiki/Cartesian_coordinates) as $(x^2 + y^2 - x)^2 = (1.5)^2 (x^2 + y^2),$ the left curve acquires an acnode at the origin, which is an isolated point in the plane. The central curve, the [cardioid](wikipedia://en/642101), has a cusp at the origin. The right curve has a crunode at the origin and the curve crosses itself to form a loop.

If $b_{0}$ and $b_{1}$ are both $0$ in the above expansion, but at least one of $c_{0}$, $c_{1}$, $c_{2}$ is not 0 then the origin is called a ***double point*** of the curve. Again putting $y = mx,$ $f$ can be written

$$f = (c_0 + 2m c_1 + c_2 m^2)x^2 + (d_0 + 3md_1 + 3 m^2 d_2 + d_3 m^3) x^3 + \cdots.$$

Double points can be classified according to the solutions of $c_0 + 2mc_1 + m^2c_2 = 0.$

#### Crunodes {#Crunodes}

If $c_0 + 2mc_1 + m^2c_2 = 0$ has two real solutions for $m$, that is if $c_0c_2 - c_1^2 < 0,$ then the origin is called a *[crunode](wikipedia://en/3090324)*. The curve in this case crosses itself at the origin and has two distinct tangents corresponding to the two solutions of $c_0 + 2mc_1 + m^2c_2 = 0.$ The function $f$ has a [saddle point](wikipedia://en/640249) at the origin in this case.

#### Acnodes {#Acnodes}

If $c_0 + 2mc_1 + m^2c_2 = 0$ has no real solutions for $m$, that is if $c_0c_2 - c_1^2 > 0,$ then the origin is called an *[acnode](wikipedia://en/3090256)*. In the real plane the origin is an [isolated point](wikipedia://en/390557) on the curve; however when considered as a complex curve the origin is not isolated and has two imaginary tangents corresponding to the two complex solutions of $c_0 + 2mc_1 + m^2c_2 = 0.$ The function $f$ has a [local extremum](https://en.wikipedia.org/wiki/Maxima_and_minima) at the origin in this case.

#### Cusps {#Cusps}

If $c_0 + 2mc_1 + m^2c_2 = 0$ has a single solution of multiplicity 2 for $m$, that is if $c_0c_2 - c_1^2 = 0,$ then the origin is called a [*cusp*](wikipedia://en/6851758). The curve in this case changes direction at the origin creating a sharp point. The curve has a single tangent at the origin which may be considered as two coincident tangents.

#### Further classification {#Further_classification}

The term *node* is used to indicate either a crunode or an acnode, in other words a double point which is not a cusp. The number of nodes and the number of cusps on a curve are two of the invariants used in the [Plücker formulas](wikipedia://en/3127299).

If one of the solutions of $c_0 + 2mc_1 + m^2c_2 = 0$ is also a solution of $d_0 + 3md_1 + 3m^2d_2 + m^3d_3 = 0,$ then the corresponding branch of the curve has a point of inflection at the origin. In this case the origin is called a *flecnode*. If both tangents have this property, so $c_0 + 2mc_1 + m^2c_2$ is a factor of $d_0 + 3md_1 + 3m^2d_2 + m^3d_3,$ then the origin is called a *biflecnode*.[^o11]

:::

::: {#o13 .pointer-item cue=pointer name="Multiple point"}

### Multiple points {#Multiple_points}

*Image: 3 Petal rose.svg.* A curve with a triple point at the origin: $x(t) = \sin(2t) + \cos(t)$, $y(t) = \sin(t) + \cos(2t)$

In general, if all the terms of degree less than $k$ are 0, and at least one term of degree $k$ is not 0 in $f$, then curve is said to have a *multiple point* of order $k$ or a *k-ple point*. The curve will have, in general, $k$ tangents at the origin though some of these tangents may be imaginary.[^o14]

:::

## Parametric curves {#Parametric_curves}

A [parameterized](wikipedia://en/576108) curve in $\mathbb{R}^2$ is defined as the image of a function $g: \mathbb{R} \to \mathbb{R}^2,$ $g(t) = (g_1(t),g_2(t)).$ The singular points are those points where

$$\frac{dg_1}{dt} = \frac{dg_2}{dt} = 0.$$

*Image: cusp.svg.* A cusp in the [semicubical parabola](wikipedia://en/2669305) $y^2=x^3$

Many curves can be defined in either fashion, but the two definitions may not agree. For example, the [cusp](wikipedia://en/6851758) can be defined on an [algebraic curve](wikipedia://en/253260), $x^3 - y^2 = 0,$ or on a parametrised curve, $g(t) = (t^2, t^3).$ Both definitions give a singular point at the origin. However, a [node](wikipedia://en/3090324) such as that of $y^2 - x^3 - x^2 = 0$ at the origin is a singularity of the curve considered as an algebraic curve, but if we parameterize it as $g(t) = (t^2 - 1, t(t^2 - 1)),$ then $g'(t)$ never vanishes, and hence the node is *not* a singularity of the parameterized curve as defined above.

Care needs to be taken when choosing a parameterization. For instance the straight line $y = 0$ can be parameterised by $g(t) = (t^3, 0),$ which has a singularity at the origin. When parametrised by $g(t) = (t, 0),$ it is nonsingular. Hence, it is technically more correct to discuss *singular points of a smooth mapping* here rather than a singular point of a curve.

The above definitions can be extended to cover *[implicit](wikipedia://en/250896) curves* which are defined as the zero set $f^{-1}(0)$ of a [smooth function](https://en.wikipedia.org/wiki/Smooth_function), and it is not necessary just to consider algebraic varieties. The definitions can be extended to cover curves in higher dimensions.

A theorem of [Hassler Whitney](wikipedia://en/391794)[^o16][^o17] states

::: {#o18 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

Any closed set in $\mathbb{R}^n$ occurs as the solution set of $f^{-1}(0)$ for some **smooth** function $f: \mathbb{R}^n \to \mathbb{R}.$

:::

Any parameterized curve can also be defined as an implicit curve, and the classification of singular points of curves can be studied as a classification of [singular points of an algebraic variety](wikipedia://en/981915).

## Types of singular points {#Types_of_singular_points}

Some of the possible singularities are:

- An isolated point: $x^2 + y^2 = 0,$ an [acnode](wikipedia://en/3090256)
- Two lines crossing: $x^2 - y^2 = 0,$ a [crunode](wikipedia://en/3090324)
- A [cusp](wikipedia://en/6851758): $x^3 - y^2 = 0,$ also called a *spinode*
- A [tacnode](wikipedia://en/7537723): $x^4 - y^2 = 0$
- A [rhamphoid cusp](https://en.wikipedia.org/wiki/Rhamphoid_cusp): $x^5 - y^2 = 0.$
