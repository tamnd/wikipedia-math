# Latent variable model

::: {#o1 .subject cue=lead name="Latent variable model"}

A **latent variable model** is a [statistical model](wikipedia://en/27576) that relates a set of [observable variables](https://en.wikipedia.org/wiki/Observable_variable) (also called *manifest variables* or *indicators*)[^o2] to a set of [latent variables](https://en.wikipedia.org/wiki/Latent_variable). Latent variable models are applied across a wide range of fields such as biology, computer science, and social science.[^o3] Common use cases for latent variable models include applications in [psychometrics](wikipedia://en/24982) (e.g., summarizing responses to a set of survey questions with a [factor analysis](wikipedia://en/253492) model positing a smaller number of psychological attributes, such as the trait [extraversion](https://en.wikipedia.org/wiki/Extraversion_and_introversion), that are presumed to cause the survey question responses),[^o4] and [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing) (e.g., a [topic model](wikipedia://en/28934119) summarizing a corpus of texts with a number of "topics").[^o5]

:::

It is assumed that the responses on the indicators or manifest variables are the result of an individual's position on the latent variable(s), and that the manifest variables have nothing in common after controlling for the latent variable ([local independence](wikipedia://en/9269164)).

Different types of latent variable models can be grouped according to whether the manifest and latent variables are categorical or continuous:[^o6]

::: {#o7 .table cue=table}

|  | Manifest variables |  |
|---|---|---|
| Latent variables | Continuous | Categorical |
| Continuous | [Factor analysis](wikipedia://en/253492) | [Item response theory](wikipedia://en/420159) |
| Categorical | [Latent profile analysis](https://en.wikipedia.org/wiki/Latent_profile_analysis) | [Latent class analysis](https://en.wikipedia.org/wiki/Latent_class_analysis) |

:::

The [Rasch model](wikipedia://en/2161615) represents the simplest form of item response theory. [Mixture models](https://en.wikipedia.org/wiki/Mixture_models) are central to latent profile analysis.

In [factor analysis](wikipedia://en/253492) and [latent trait analysis](https://en.wikipedia.org/wiki/Latent_trait_analysis) the latent variables are treated as continuous [normally distributed](wikipedia://en/21462) variables, and in latent profile analysis and latent class analysis as from a [multinomial distribution](wikipedia://en/1045553).[^o8] The manifest variables in factor analysis and latent profile analysis are continuous and in most cases, their conditional distribution given the latent variables is assumed to be normal. In latent trait analysis and latent class analysis, the manifest variables are discrete. These variables could be dichotomous, ordinal or nominal variables. Their conditional distributions are assumed to be binomial or multinomial.
