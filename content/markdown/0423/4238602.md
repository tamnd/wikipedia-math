# Urchin (software)

::: {#o1 .subject cue=lead name="Urchin"}

**Urchin** was a [web statistics analysis](wikipedia://en/2475872) program that was developed by [Urchin Software Corporation](https://en.wikipedia.org/wiki/Urchin_Software_Corporation). Urchin analyzed [web server](https://en.wikipedia.org/wiki/Web_server) [log file](https://en.wikipedia.org/wiki/Data_logging) content and displayed the [traffic](https://en.wikipedia.org/wiki/Internet_traffic) information on that [website](https://en.wikipedia.org/wiki/Website) based upon the log data. Sales of Urchin products ended on March 28, 2012.[^o3]

:::

Urchin software could be run in two different data collection modes: log file analyzer or hybrid. As a log file analyzer, Urchin processed web server log files in a variety of log file formats. Custom file formats could also be defined. As a hybrid, Urchin combined page tags with log file data to eradicate the limitations of each data collection method in isolation.[^o4] The result was more accurate web visitor data.[^o5]

Urchin became one of the more popular tools for website [traffic analysis](https://en.wikipedia.org/wiki/Traffic_analysis), particularly with ISPs and web hosting providers. This was largely due to its scalability in performance and its pricing model.[^o6] Logo of Urchin Software Corporation.svg Logo of Urchin (software).svg Urchin Software Corp. was acquired by [Google](https://en.wikipedia.org/wiki/Google) in April 2005, forming [Google Analytics](https://en.wikipedia.org/wiki/Google_Analytics).[^o7] In April 2008, Google released Urchin 6.[^o8][^o9] In February 2009, Google released Urchin 6.5, integrating [AdWords](https://en.wikipedia.org/wiki/AdWords).[^o10] Urchin 7 was released in September 2010 and included 64-bit support, a new UI, and event tracking, among other features.[^o11][^o12]
