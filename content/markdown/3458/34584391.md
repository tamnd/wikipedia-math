# Petrov–Galerkin method

::: {#o1 .subject cue=lead name="Petrov–Galerkin method"}

The **Petrov–Galerkin method** is a mathematical method used to approximate solutions of [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations) which contain terms with [odd](https://en.wikipedia.org/wiki/Even_and_odd_numbers) order and where the test function and solution function belong to different function spaces.[^o2] It can be viewed as an extension of [Bubnov-Galerkin method](wikipedia://en/2664839) where the bases of test functions and solution functions are the same. In an operator formulation of the differential equation, Petrov–Galerkin method can be viewed as applying a projection that is not necessarily orthogonal, in contrast to [Bubnov-Galerkin method](wikipedia://en/2664839).

:::

It is named after the Soviet scientists [Georgy I. Petrov](https://en.wikipedia.org/wiki/Georgy_Petrov) and [Boris G. Galerkin](wikipedia://en/2370583).[^o3]

## Introduction with an abstract problem {#Introduction_with_an_abstract_problem}

Petrov-Galerkin's method is a natural extension of [Galerkin method](wikipedia://en/2664839) and can be similarly introduced as follows.

### A problem in weak formulation {#A_problem_in_weak_formulation}

Let us consider an abstract problem posed as a [weak formulation](wikipedia://en/3368981) on a pair of [Hilbert spaces](https://en.wikipedia.org/wiki/Hilbert_spaces) $V$ and $W$, namely,

find $u\in V$ such that $a(u,w) = f(w)$ for all $w\in W$.

Here, $a(\cdot,\cdot)$ is a [bilinear map](wikipedia://en/4365) and $f$ is a bounded linear functional on $W$.

### Petrov-Galerkin dimension reduction {#Petrov-Galerkin_dimension_reduction}

Choose subspaces $V_n \subset V$ of dimension *n* and $W_m \subset W$ of dimension *m* and solve the projected problem:

Find $v_n\in V_n$ such that $a(v_n,w_m) = f(w_m)$ for all $w_m\in W_m$.

We notice that the equation has remained unchanged and only the spaces have changed. Reducing the problem to a finite-dimensional vector subspace allows us to numerically compute $v_n$ as a finite [linear combination](wikipedia://en/55632) of the basis vectors in $V_n$.

### Petrov-Galerkin generalized orthogonality {#Petrov-Galerkin_generalized_orthogonality}

The key property of the Petrov-Galerkin approach is that the error is in some sense "orthogonal" to the chosen subspaces. Since $W_m \subset W$, we can use $w_m$ as a [test vector](https://en.wikipedia.org/wiki/Test_vector) in the original equation. Subtracting the two, we get the relation for the error, $\epsilon_n = v-v_n$ which is the error between the solution of the original problem, $v$, and the solution of the Galerkin equation, $v_n$, as follows

$a(\epsilon_n, w_m) = a(v,w_m) - a(v_n, w_m) = f(w_m) - f(w_m) = 0$ for all $w_m\in W_m$.

### Matrix form {#Matrix_form}

Since the aim of the approximation is producing a [linear system of equations](wikipedia://en/113087), we build its matrix form, which can be used to compute the solution algorithmically.

Let $v^1, v^2,\ldots, v^n$ be a [basis](wikipedia://en/18420) for $V_n$ and $w^1, w^2,\ldots, w^m$ be a [basis](wikipedia://en/18420) for $W_m$. Then, it is sufficient to use these in turn for testing the Galerkin equation, i.e.: find $v_n \in V_n$ such that

$$a(v_n, w^j) = f(w^j) \quad j=1,\ldots, m.$$

We expand $v_n$ with respect to the solution basis, $v_n = \sum_{i=1}^n x^i v^i$ and insert it into the equation above, to obtain

$$a\left(\sum_{i=1}^n x^i v^i,\, w^j\right) = \sum_{i=1}^n x^i a(v^i, w^j) = f(w^j) \quad j=1,\ldots,m.$$

This previous equation is actually a linear system of equations $A^Tx=b$, where

$$A_{ij} \stackrel{\mathrm{def}}{=} a(v^i, w^j), \qquad\text{and}\qquad b_j \stackrel{\mathrm{def}}{=} f(w^j).$$

#### Symmetry of the matrix {#Symmetry_of_the_matrix}

Due to the definition of the matrix entries, the matrix $A$ is [symmetric](wikipedia://en/126474) if $V=W$, the bilinear form $a(\cdot,\cdot)$ is symmetric, $n=m$, $V_n=W_m$, and $v^i=w^j$ for all $i=j=1,\ldots, n=m.$ In contrast to the case of [Bubnov-Galerkin](wikipedia://en/2664839) method, the system matrix $A$ is not even square, if $n\neq m.$
