# Tunnell's theorem

::: {#o1 .subject cue=lead name="Tunnell's theorem"}

In [number theory](wikipedia://en/21527), **Tunnell's theorem** gives a partial resolution to the [congruent number problem](https://en.wikipedia.org/wiki/Congruent_number_problem), and under the [Birch and Swinnerton-Dyer conjecture](wikipedia://en/435161), a full resolution.

:::

## Congruent number problem {#Congruent_number_problem}

The congruent number problem asks which positive [integers](wikipedia://en/14563) can be the [area](wikipedia://en/1209) of a [right triangle](wikipedia://en/39420) with all three sides [rational](wikipedia://en/19727024). Tunnell's theorem relates this to the number of integral solutions of a few fairly simple [Diophantine equations](wikipedia://en/9109).

::: {#o4 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

For a given [square-free integer](wikipedia://en/29525) *n*, define

$$\begin{aligned} A_n & = \#\{ (x,y,z) \in \mathbb{Z}^3 \mid n = 2x^2 + y^2 + 32z^2 \}, \\ B_n & = \#\{ (x,y,z) \in \mathbb{Z}^3 \mid n = 2x^2 + y^2 + 8z^2 \}, \\ C_n & = \#\{ (x,y,z) \in \mathbb{Z}^3 \mid n = 8x^2 + 2y^2 + 64z^2 \}, \\ D_n & = \#\{ (x,y,z) \in \mathbb{Z}^3 \mid n = 8x^2 + 2y^2 + 16z^2 \}. \end{aligned}$$

Tunnell's theorem states that supposing *n* is a congruent number, if *n* is odd then 2*A<sub>n</sub>* = *B<sub>n</sub>* and if *n* is even then 2*C<sub>n</sub>* = *D<sub>n</sub>*. [Conversely](wikipedia://en/155941), if the [Birch and Swinnerton-Dyer conjecture](wikipedia://en/435161) holds true for [elliptic curves](wikipedia://en/10225) of the form $y^2 = x^3 - n^2x$, these equalities are sufficient to conclude that *n* is a congruent number.

:::

## History {#History}

The theorem is named for [Jerrold B. Tunnell](wikipedia://en/41107257), a number theorist at [Rutgers University](https://en.wikipedia.org/wiki/Rutgers_University), who [proved](wikipedia://en/82285) it in (Tunnell 1983).

## Importance {#Importance}

The importance of Tunnell's theorem is that the criterion it gives is testable by a finite calculation. For instance, for a given $n$, the numbers $A_n,B_n,C_n,D_n$ can be calculated by exhaustively searching through $x,y,z$ in the range $-\sqrt{n},\ldots,\sqrt{n}$.
