# Naccache–Stern cryptosystem

::: {#o1 .subject cue=lead name="Naccache–Stern cryptosystem"}

The **Naccache–Stern cryptosystem** is a [homomorphic](wikipedia://en/4939073) [public-key cryptosystem](https://en.wikipedia.org/wiki/Public-key_cryptosystem) whose security rests on the [higher residuosity problem](https://en.wikipedia.org/wiki/Higher_residuosity_problem). The Naccache–Stern cryptosystem was discovered by [David Naccache](wikipedia://en/9488704) and [Jacques Stern](https://en.wikipedia.org/wiki/Jacques_Stern_%28cryptographer%29) in 1998.

:::

## Scheme Definition {#Scheme_Definition}

Like many [public key cryptosystems](https://en.wikipedia.org/wiki/Public_key_cryptography), this scheme works in the group $(\mathbb{Z}/n\mathbb{Z})^*$ where *n* is a product of two large [primes](wikipedia://en/23666). This scheme is [homomorphic](wikipedia://en/4939073) and hence [malleable](wikipedia://en/87027).

### Key Generation {#Key_Generation}

- Pick a family of *k* small distinct [primes](wikipedia://en/23666) *p*<sub>1</sub>,...,*p*<sub>k</sub>.
- Divide the set in half and set $u = \prod_{i=1}^{k/2} p_i$ and $v = \prod_{k/2+1}^k p_i$.
- Set $\sigma = uv = \prod_{i=1}^k p_i$
- Choose large primes *a* and *b* such that both *p* = 2*au*+1 and *q*=2*bv*+1 are prime.
- Set *n*=*pq*.
- Choose a random *g* mod *n* such that *g* has order φ(*n*)/4.

The public key is the numbers (σ,*n*,*g*) and the private key is the pair (*p*,*q*).

The primes (p<sub>1</sub>, ..., p<sub>k</sub>) are also effectively public, since they can be efficiently recovered from the public value σ = Π pi, given that they are small. These primes are required during decryption, where computations are performed modulo each p<sub>i</sub> in order to recover the message.

When *k*=1 this is essentially the [Benaloh cryptosystem](wikipedia://en/6144390).

### Message Encryption {#Message_Encryption}

This system allows encryption of a message *m* in the group $\mathbb{Z}/\sigma\mathbb{Z}$.

- Pick a random $x \in \mathbb{Z}/n\mathbb{Z}$.
- Calculate $E(m) = x^\sigma g^m \mod n$

Then *E(m)* is an encryption of the message *m*.

### Message Decryption {#Message_Decryption}

To decrypt, we first find *m* mod *p*<sub>*i*</sub> for each *i*, and then we apply the [Chinese remainder theorem](wikipedia://en/7713) to calculate *m* mod $\sigma$.

Given a ciphertext *c*, to decrypt, we calculate

- $c_i \equiv c^{\phi(n)/p_i} \mod n$. Thus

$$\begin{matrix} c^{\phi(n)/p_i} &\equiv& x^{\sigma \phi(n)/p_i} g^{m\phi(n)/p_i} \mod n\\ &\equiv& g^{(m_i + y_ip_i)\phi(n)/p_i} \mod n \\ &\equiv& g^{m_i\phi(n)/p_i} \mod n \end{matrix}$$

where $m_i \equiv m \mod p_i$.

- Since *p*<sub>*i*</sub> is chosen to be small, *m*<sub>*i*</sub> can be recovered by exhaustive search, i.e. by comparing $c_i$ to $g^{j\phi(n)/p_i}$ for *j* from 1 to *p*<sub>*i*</sub>-1.
- Once *m*<sub>*i*</sub> is known for each *i*, *m* can be recovered by a direct application of the Chinese remainder theorem.

## Security {#Security}

The [semantic security](wikipedia://en/960585) of the Naccache–Stern cryptosystem rests on an extension of the [quadratic residuosity problem](wikipedia://en/1183041) known as the [higher residuosity problem](https://en.wikipedia.org/wiki/Higher_residuosity_problem).
