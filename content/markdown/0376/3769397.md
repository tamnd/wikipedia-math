# Block (permutation group theory)

::: {#o1 .subject cue=lead name="Block"}

In [mathematics](wikipedia://en/18831) and [group theory](wikipedia://en/41890), a **block** for the [action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) of a [group](wikipedia://en/19447) $G$ on a [set](wikipedia://en/26691) $X$ is a subset $Y$ of $X$ whose images under $G$ either coincide with $Y$ or are disjoint from $Y$. These images form a **block system**, a [partition](https://en.wikipedia.org/wiki/Partition_%28set_theory%29) of $X$ that is $G$-invariant. In terms of the associated [equivalence relation](wikipedia://en/9259) on $X$, $G$-invariance means that

:::

for all $g\in G$ and all $x,y\in X$. The action of $G$ on $X$ induces a natural action of $G$ on any block system for $X$.[^o2]

The set of [orbits](https://en.wikipedia.org/wiki/Orbit_%28group_theory%29) of the $G$-set $X$ is an example of a block system. The corresponding equivalence relation is the smallest $G$-invariant equivalence on $X$ such that the induced action on the block system is trivial.

The partition into [singleton sets](https://en.wikipedia.org/wiki/Singleton_set) is a block system and if $X$ is non-empty then the partition into one set $X$ itself is a block system as well (if $X$ is a singleton set then these two partitions are identical). A [transitive](https://en.wikipedia.org/wiki/Transitive_action) (and thus non-empty) $G$-set $X$ is said to be [primitive](wikipedia://en/2739252) if it has no other block systems.[^o3] For a non-empty $G$-set $X$ the transitivity requirement in the previous definition is only necessary in the case when $|X|=2$ and the group action is trivial.

## Stabilizers of blocks {#Stabilizers_of_blocks}

If *B* is a block, the [stabilizer](https://en.wikipedia.org/wiki/Stabilizer_subgroup) of *B* is the [subgroup](wikipedia://en/28011)

*G*<sub>*B*</sub> = { *g* ∈ *G* | *gB* = *B* }.

The stabilizer of a block contains the stabilizer *G*<sub>*x*</sub> of each of its elements. Conversely, if *x* ∈ *X* and *H* is a subgroup of *G* containing *G*<sub>*x*</sub>, then the orbit *H*.*x* of *x* under *H* is a block contained in the orbit *G*.*x* and containing *x*.

For any *x* ∈ *X*, block *B* containing *x* and subgroup *H* ⊆ *G* containing *G*<sub>*x*</sub> it's *G*<sub>*B*</sub>.*x* = *B* ∩ *G*.*x* and *G*<sub>*H*.*x*</sub> = *H*.

It follows that the blocks containing *x* and contained in *G*.*x* are in [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence) with the subgroups of *G* containing *G*<sub>*x*</sub>. In particular, if the *G*-set *X* is transitive then the blocks containing *x* are in one-to-one correspondence with the subgroups of *G* containing *G*<sub>*x*</sub>. In this case the *G*-set *X* is primitive if and only if either the group action is trivial (then *X* = {*x*}) or the stabilizer *G*<sub>*x*</sub> is a [maximal subgroup](wikipedia://en/1472649) of *G* (then the stabilizers of all elements of *X* are the maximal subgroups of *G* [conjugate](wikipedia://en/49176) to *G*<sub>*x*</sub> because *G*<sub>*gx*</sub> = *g* ⋅ *G*<sub>*x*</sub> ⋅ *g*<sup>−*1*</sup>).
