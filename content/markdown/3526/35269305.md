# Ordinal regression

::: {#o1 .subject cue=lead name="Ordinal regression"}

In [statistics](wikipedia://en/26685), **ordinal regression**, also called **ordinal classification**, is a type of [regression analysis](wikipedia://en/826997) used for predicting an [ordinal variable](https://en.wikipedia.org/wiki/Ordinal_variable), i.e. a variable whose value exists on an arbitrary scale where only the relative ordering between different values is significant. It can be considered an intermediate problem between regression and [classification](wikipedia://en/1579244).[^o2][^o3] Examples of ordinal regression are [ordered logit](wikipedia://en/3768065) and [ordered probit](https://en.wikipedia.org/wiki/Ordered_probit). Ordinal regression turns up often in the [social sciences](https://en.wikipedia.org/wiki/Social_sciences), for example in the modeling of human levels of preference (on a scale from, say, 1–5 for "very poor" through "excellent"), as well as in [information retrieval](https://en.wikipedia.org/wiki/Information_retrieval). In [machine learning](wikipedia://en/233488), ordinal regression may also be called **ranking learning**.[^o4]

:::

## Linear models for ordinal regression {#Linear_models_for_ordinal_regression}

Ordinal regression can be performed using a [generalized linear model](wikipedia://en/747122) (GLM) that fits both a coefficient vector and a set of *thresholds* to a dataset. Suppose one has a set of observations, represented by length-$p$ vectors $\mathbf{x}_{1}$ through $\mathbf{x}_{n}$, with associated [responses](https://en.wikipedia.org/wiki/Response_variable) $y_{1}$ through $y_{n}$, where each $y_{i}$ is an [ordinal variable](https://en.wikipedia.org/wiki/Ordinal_variable) on a scale $1, ..., K$. For simplicity, and without loss of generality, we assume $y$ is a non-decreasing vector, that is, $y_{i} \le y_{i+1}$. To this data, one fits a length-$p$ coefficient vector $\mathbf{w}$ and a set of thresholds $\theta_{1}, ..., \theta_{K-1}$ with the property that $\theta_{1} < \theta_{2} < ... < \theta_{K-1}$. This set of thresholds divides the real number line into $K$ disjoint segments, corresponding to the $K$ response levels.

The model can now be formulated as

$$\Pr(y \le i \mid \mathbf{x}) = \sigma(\theta_i - \mathbf{w} \cdot \mathbf{x})$$

or, the cumulative probability of the response $y$ being at most $i$ is given by a function $\sigma$ (the inverse [link function](https://en.wikipedia.org/wiki/Link_function)) applied to a linear function of $\mathbf{x}$. Several choices exist for $\sigma$; the [logistic function](wikipedia://en/84563)

$$\sigma(\theta_i - \mathbf{w} \cdot \mathbf{x}) = \frac{1}{1 + e^{-(\theta_i - \mathbf{w} \cdot \mathbf{x})}}$$

gives the [ordered logit](wikipedia://en/3768065) model, while using the [CDF](wikipedia://en/5793) of the standard [normal distribution](wikipedia://en/21462) gives the [ordered probit](https://en.wikipedia.org/wiki/Ordered_probit) model. A third option is to use an exponential function

$$\sigma(\theta_i - \mathbf{w} \cdot \mathbf{x}) = 1 - \exp(-\exp(\theta_i - \mathbf{w} \cdot \mathbf{x}))$$

which gives the [proportional hazards model](wikipedia://en/5352267).[^o6]

### Latent variable model {#Latent_variable_model}

The probit version of the above model can be justified by assuming the existence of a real-valued [latent variable](https://en.wikipedia.org/wiki/Latent_variable) (unobserved quantity) $y*$, determined by[^o8]

$$y^* = \mathbf{w} \cdot \mathbf{x} + \varepsilon$$

where $\varepsilon$ is [normally distributed](wikipedia://en/21462) with zero mean and unit variance, [conditioned](https://en.wikipedia.org/wiki/Conditional_distribution) on $\mathbf{x}$. The response variable $y$ results from an "incomplete measurement" of $y*$, where one only determines the interval into which $y*$ falls:

$$y = \begin{cases} 1 & \text{if} ~~ y^* \le \theta_1, \\ 2 & \text{if} ~~ \theta_1 < y^* \le \theta_2, \\ 3 & \text{if} ~~ \theta_2 < y^* \le \theta_3 \\ \vdots \\ K & \text{if}~~ \theta_{K-1} < y^*. \end{cases}$$

Defining $\theta_{0} = -\infty$ and $\theta_{K} = \infty$, the above can be summarized as $y = k$ [if and only if](wikipedia://en/14922) $\theta_{k-1} < y* \le \theta_{k}$.

From these assumptions, one can derive the conditional distribution of $y$ as

$$\begin{aligned} P(y = k \mid \mathbf{x}) & = P(\theta_{k-1} < y^* \le \theta_k \mid \mathbf{x}) \\ & = P(\theta_{k-1} < \mathbf{w} \cdot \mathbf{x} + \varepsilon \le \theta_k) \\ & = \Phi(\theta_k - \mathbf{w} \cdot \mathbf{x}) - \Phi(\theta_{k-1} - \mathbf{w} \cdot \mathbf{x}) \end{aligned}$$

where $\Phi$ is the [cumulative distribution function](wikipedia://en/5793) of the standard normal distribution, and takes on the role of the inverse link function $\sigma$. The [log-likelihood](https://en.wikipedia.org/wiki/Log-likelihood) of the model for a single training example $\mathbf{x}_{i}$, $y_{i}$ can now be stated as

$$\log\mathcal{L}(\mathbf{w}, \mathbf{\theta} \mid \mathbf{x}_i, y_i) = \sum_{k=1}^K [y_i = k] \log [\Phi(\theta_k - \mathbf{w} \cdot \mathbf{x}_i) - \Phi(\theta_{k-1} - \mathbf{w} \cdot \mathbf{x}_i)]$$

(using the [Iverson bracket](wikipedia://en/1721092) $[y_{i} = k]$.) The log-likelihood of the ordered logit model is analogous, using the logistic function instead of $\Phi$.[^o9]

## Alternative models {#Alternative_models}

In machine learning, alternatives to the latent-variable models of ordinal regression have been proposed. An early result was PRank, a variant of the [perceptron](wikipedia://en/172777) algorithm that found multiple parallel hyperplanes separating the various ranks; its output is a weight vector $\mathbf{w}$ and a sorted vector of $K-1$ thresholds $\mathbf{\theta}$, as in the ordered logit/probit models. The prediction rule for this model is to output the smallest rank $k$ such that $\mathbf{wx} < \theta_{k}$.[^o11]

Other methods rely on the principle of large-margin learning that also underlies [support vector machines](wikipedia://en/65309).[^o12][^o13]

Another approach is given by Rennie and Srebro, who, realizing that "even just evaluating the likelihood of a predictor is not straight-forward" in the ordered logit and ordered probit models, propose fitting ordinal regression models by adapting common [loss functions](wikipedia://en/442137) from classification (such as the [hinge loss](wikipedia://en/33100241) and [log loss](https://en.wikipedia.org/wiki/Log_loss)) to the ordinal case.[^o14]

## Software {#Software}

ORCA (Ordinal Regression and Classification Algorithms) is an Octave/MATLAB framework including a wide set of ordinal regression methods.[^o16]

R packages that provide ordinal regression methods include MASS[^o17], Rstan, brms and Ordinal.[^o18]
