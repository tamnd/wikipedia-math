# Split interval

::: {#o1 .subject cue=lead name="Split interval"}

In [topology](wikipedia://en/29954), the **split interval**, or **double arrow space**, is a [topological space](wikipedia://en/30450) that results from splitting each point in a [closed interval](https://en.wikipedia.org/wiki/Closed_interval) into two adjacent points and giving the resulting ordered set the [order topology](wikipedia://en/213650). It satisfies various interesting properties and serves as a useful counterexample in [general topology](wikipedia://en/178649).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The **split interval** can be defined as the [lexicographic product](https://en.wikipedia.org/wiki/Lexicographical_order) $[0, 1] \times\{0, 1\}$ equipped with the [order topology](wikipedia://en/213650).[^o4] Equivalently, the space can be constructed by taking the closed interval $[0,1]$ with its usual order, splitting each point $a$ into two adjacent points $a^-<a^+$, and giving the resulting linearly ordered set the order topology.[^o5] The space is also known as the **double arrow space**,[^o6][^o7] **Alexandrov double arrow space** or **two arrows space**.

The space above is a [linearly ordered topological space](https://en.wikipedia.org/wiki/Linearly_ordered_topological_space) with two isolated points, $(0,0)$ and $(1,1)$ in the lexicographic product. Some authors[^o8][^o9] take as definition the same space without the two isolated points. (In the point splitting description this corresponds to not splitting the endpoints $0$ and $1$ of the interval.) The resulting space has essentially the same properties.

The double arrow space is a subspace of the [lexicographically ordered unit square](wikipedia://en/29044559). If we ignore the isolated points, a [base](wikipedia://en/59220) for the double arrow space topology consists of all sets of the form $((a,b]\times\{0\}) \cup ([a,b)\times\{1\})$ with $a<b$. (In the point splitting description these are the [clopen](https://en.wikipedia.org/wiki/Clopen) intervals of the form $[a^+,b^-]=(a^-,b^+)$, which are simultaneously closed intervals and open intervals.) The lower subspace $(0,1]\times\{0\}$ is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to the [Sorgenfrey line](https://en.wikipedia.org/wiki/Sorgenfrey_line) with half-open intervals to the left as a base for the topology, and the upper subspace $[0,1)\times\{1\}$ is homeomorphic to the Sorgenfrey line with half-open intervals to the right as a base, like two parallel arrows going in opposite directions, hence the name.

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The split interval $X$ is a [zero-dimensional](https://en.wikipedia.org/wiki/Zero-dimensional) [compact](https://en.wikipedia.org/wiki/Compact_%28topology%29) [Hausdorff space](wikipedia://en/13637). It is a [linearly ordered topological space](https://en.wikipedia.org/wiki/Linearly_ordered_topological_space) that is [separable](https://en.wikipedia.org/wiki/Separable_%28topology%29) but not [second countable](https://en.wikipedia.org/wiki/Second_countable), hence not [metrizable](https://en.wikipedia.org/wiki/Metrizable); its metrizable subspaces are all countable.

It is [hereditarily Lindelöf](https://en.wikipedia.org/wiki/Hereditarily_Lindelöf), hereditarily separable, and [perfectly normal](https://en.wikipedia.org/wiki/Perfectly_normal_space) (T<sub>6</sub>). But the product $X\times X$ of the space with itself is not even [hereditarily normal](https://en.wikipedia.org/wiki/Hereditarily_normal_space) (T<sub>5</sub>), as it contains a copy of the [Sorgenfrey plane](wikipedia://en/682853), which is not [normal](wikipedia://en/48629).

All [compact](https://en.wikipedia.org/wiki/Compactness), separable ordered spaces are order-isomorphic to a subset of the split interval.[^o12]
