# Supnick matrix

::: {#o1 .subject cue=lead name="Supnick matrix"}

A **Supnick matrix** or **Supnick array** – named after Fred Supnick of the [City College of New York](https://en.wikipedia.org/wiki/City_College_of_New_York), who introduced the notion in 1957 – is a [Monge array](https://en.wikipedia.org/wiki/Monge_array) which is also a [symmetric matrix](wikipedia://en/126474).

:::

## Mathematical definition {#Mathematical_definition}

A Supnick matrix is a square [Monge array](https://en.wikipedia.org/wiki/Monge_array) that is symmetric around the [main diagonal](wikipedia://en/194990).

An *n*-by-*n* [matrix](wikipedia://en/20556859) is a Supnick matrix if, for all *i*, *j*, *k*, *l* such that if

$1\le i < k\le n$ and $1\le j < l\le n$

then

$$a_{ij} + a_{kl} \le a_{il} + a_{kj}\,$$

and also

$$a_{ij} = a_{ji}. \,$$

A logically equivalent definition is given by Rudolf & Woeginger who in 1995 proved that

*A matrix is a Supnick matrix [iff](https://en.wikipedia.org/wiki/Iff) it can be written as the sum of a sum matrix*S*and a non-negative linear combination of LL-UR block matrices.*

The *sum matrix* is defined in terms of a sequence of *n* real numbers {α<sub>*i*</sub>}:

$$S = [s_{ij}] = [\alpha_i + \alpha_j]; \,$$

and an *LL-UR block matrix* consists of two symmetrically placed rectangles in the lower-left and upper right corners for which *a<sub>ij</sub>* = 1, with all the rest of the matrix elements equal to zero.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Adding two Supnick matrices together will result in a new Supnick matrix (Deineko and Woeginger 2006).

Multiplying a Supnick matrix by a non-negative [real number](wikipedia://en/20646438) produces a new Supnick matrix (Deineko and Woeginger 2006).

If the [distance matrix](wikipedia://en/831350) in a [traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem) can be written as a Supnick matrix, that particular instance of the problem admits an easy solution (even though the problem is, in general, [NP hard](https://en.wikipedia.org/wiki/NP_hard)).

:::
