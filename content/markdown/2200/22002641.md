# RV coefficient

::: {#o1 .subject cue=lead name="RV coefficient"}

In statistics, the **RV coefficient**[^o2] is a [multivariate](wikipedia://en/19384) generalization of the *squared* [Pearson correlation coefficient](wikipedia://en/221708) (because the RV coefficient takes values between 0 and 1).[^o3] It measures the closeness of two set of points that may each be represented in a [matrix](wikipedia://en/20556859).

:::

The major approaches within [statistical multivariate data analysis](wikipedia://en/19384) can all be brought into a common framework in which the RV coefficient is maximised subject to relevant constraints. Specifically, these statistical methodologies include:[^o2]

- [principal component analysis](wikipedia://en/76340)
- [canonical correlation analysis](https://en.wikipedia.org/wiki/Canonical_correlation_analysis)
- multivariate [regression](wikipedia://en/826997)
- [statistical classification](wikipedia://en/1579244) ([linear discrimination](wikipedia://en/1470657)).

One application of the RV coefficient is in [functional neuroimaging](https://en.wikipedia.org/wiki/Functional_neuroimaging) where it can measure the similarity between two subjects' series of brain scans[^o4] or between different scans of a same subject.[^o5]

::: {#o7 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

The definition of the RV-coefficient makes use of ideas[^o8] concerning the definition of scalar-valued quantities which are called the "variance" and "covariance" of vector-valued [random variables](https://en.wikipedia.org/wiki/Random_variables). Note that standard usage is to have matrices for the variances and covariances of vector random variables. Given these innovative definitions, the RV-coefficient is then just the correlation coefficient defined in the usual way.

Suppose that *X* and *Y* are matrices of centered random vectors (column vectors) with [covariance matrix](wikipedia://en/191752) given by

$$\Sigma_{XY}=\operatorname{E}( XY^\top) \,,$$

then the scalar-valued covariance (denoted by COVV) is defined by[^o8]

$$\operatorname{COVV}(X,Y)= \operatorname{Tr}(\Sigma_{XY}\Sigma_{YX}) \, .$$

The scalar-valued variance is defined correspondingly:

$$\operatorname{VAV}(X)= \operatorname{Tr}(\Sigma_{XX}^2) \, .$$

With these definitions, the variance and covariance have certain additive properties in relation to the formation of new vector quantities by extending an existing vector with the elements of another.[^o8]

Then the RV-coefficient is defined by[^o8]

$$\mathrm{RV}(X,Y) = \frac { \operatorname{COVV}(X,Y) } { \sqrt{ \operatorname{VAV}(X) \operatorname{VAV}(Y) } } \, .$$

:::

## Shortcoming of the coefficient and adjusted version {#Shortcoming_of_the_coefficient_and_adjusted_version}

Even though the coefficient takes values between 0 and 1 by construction, it seldom attains values close to 1 as the denominator is often too large with respect to the maximal attainable value of the denominator.[^o10]

Given known diagonal blocks $\Sigma_{XX}$ and $\Sigma_{YY}$ of dimensions $p\times p$ and $q\times q$ respectively, assuming that $p \le q$ [without loss of generality](wikipedia://en/296000), it has been proved[^o11] that the maximal attainable numerator is $\operatorname{Tr}(\Lambda_X \Pi \Lambda_Y),$ where $\Lambda_X$ (resp. $\Lambda_Y$) denotes the [diagonal matrix](wikipedia://en/174080) of the eigenvalues of $\Sigma_{XX}$(resp. $\Sigma_{YY}$) sorted decreasingly from the upper leftmost corner to the lower rightmost corner and $\Pi$ is the $p \times q$ matrix $(I_p \ 0_{p\times (q-p)} )$.

In light of this, Mordant and Segers[^o11] proposed an adjusted version of the RV coefficient in which the denominator is the maximal value attainable by the numerator. It reads

$$\bar{\operatorname{RV}}(X,Y) = \frac{\operatorname{Tr}(\Sigma_{XY}\Sigma_{YX})}{\operatorname{Tr}(\Lambda_X \Pi \Lambda_Y)} = \frac{\operatorname{Tr}(\Sigma_{XY}\Sigma_{YX})}{\sum_{j=1}^{min(p,q)} (\Lambda_X)_{j,j} (\Lambda_Y)_{j,j}}.$$

The impact of this adjustment is clearly visible in practice.[^o11]
