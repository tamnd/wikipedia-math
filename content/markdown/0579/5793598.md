# Chebyshev function

*Image: ChebyshevPsi.png.* The Chebyshev function $\psi(x)$, with $x < 50$

*Image: Chebyshev.svg.* The function $\psi(x)-x$, for $x < 10^{4}$

*Image: Chebyshev-big.svg.* The function $\psi(x)-x$, for $x < 10^{7}$

::: {#o1 .subject cue=lead name="Chebyshev function"}

In [mathematics](wikipedia://en/18831), the **Chebyshev function** is either a scalarising function (**Tchebycheff function**) or one of two related functions. The **first Chebyshev function** $\vartheta(x)$ or $\theta(x)$ is given by

:::

$$\vartheta(x) = \sum_{p \le x} \log p$$

where $\log$ denotes the [natural logarithm](wikipedia://en/21476), with the sum extending over all [prime numbers](wikipedia://en/23666) $p$ that are less than or equal to $x$.

The **second Chebyshev function** $\psi(x)$ is defined similarly, with the sum extending over all [prime powers](wikipedia://en/1630483) not exceeding $x$

$$\psi(x) = \sum_{k \in \mathbb{N}}\sum_{p^k \le x}\log p = \sum_{n \leq x} \Lambda(n) = \sum_{p \le x}\left\lfloor\log_p x\right\rfloor\log p,$$

where $\Lambda$ is the [von Mangoldt function](wikipedia://en/1928862). The Chebyshev functions, especially the second one $\psi(x)$, are often used in [proofs](wikipedia://en/82285) related to [prime numbers](wikipedia://en/23666), because it is typically simpler to work with them than with the [prime-counting function](wikipedia://en/331826), $\pi(x)$ (see the exact formula below.) Both Chebyshev functions are asymptotic to $x$, a statement equivalent to the [prime number theorem](wikipedia://en/23692).

**Tchebycheff function**, **Chebyshev utility function**, or **weighted Tchebycheff scalarizing function** is used when one has several functions to be minimized and one wants to "scalarize" them to a single function:

$f_{Tchb}(x,w) = \max_i w_i f_i(x).$[^o2]

By minimizing this function for different values of $w$, one obtains every point on a [Pareto front](https://en.wikipedia.org/wiki/Pareto_front), even in the nonconvex parts.[^o2] Often the functions to be minimized are not $f_i$ but $|f_i-z_i^*|$ for some scalars $z_i^*$. Then $f_{Tchb}(x,w) = \max_i w_i |f_i(x)-z_i^*|.$[^o3]

All three functions are named in honour of [Pafnuty Chebyshev](wikipedia://en/149568).

## Relationships {#Relationships}

The second Chebyshev function can be seen to be related to the first by writing it as

$$\psi(x) = \sum_{p \le x}k \log p$$

where $k$ is the unique [integer](wikipedia://en/14563) such that $p^{k} \le x$ and $x < p^{k+1}$. The values of $k$ are given in . A more direct relationship is given by

$$\psi(x) = \sum_{n=1}^\infty \vartheta\big(x^{\frac{1}{n}}\big).$$

This last sum has only a finite number of non-vanishing terms, as

$$\vartheta\big(x^{\frac{1}{n}}\big) = 0\quad \text{for}\quad n>\log_2 x = \frac{\log x}{\log 2}.$$

The second Chebyshev function is the logarithm of the [least common multiple](wikipedia://en/17961) of the integers from 1 to $n$.

$$\operatorname{lcm}(1,2,\dots,n) = e^{\psi(n)}.$$

Values of $\operatorname{lcm}(1, 2, ..., n)$ for the integer variable $n$ are given at .

## Relationships between *ψ*(*x*)/*x* and *ϑ*(*x*)/*x* {#Relationships_between_&psi;(x)/x_and_&vartheta;(x)/x}

The following [theorem](wikipedia://en/30977) relates the two quotients $\frac{\psi(x)}{x}$ and $\frac{\vartheta(x)}{x}$ .[^o6]

::: {#o7 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** For $x>0$, we have

$$0 \leq \frac{\psi(x)}{x}-\frac{\vartheta(x)}{x}\leq \frac{(\log x)^2}{2\sqrt{x}\log 2}.$$

This [inequality](wikipedia://en/89489) implies that

$$\lim_{x\to\infty}\!\left(\frac{\psi(x)}{x}-\frac{\vartheta(x)}{x}\right)\! = 0.$$

In other words, if one of the $\psi(x)/x$ or $\vartheta(x)/x$ tends to a [limit](wikipedia://en/285759) then so does the other, and the two limits are equal.

:::

::: {#o8 .proof cue=inline-head name="Proof"}

**Proof:** Since $\psi(x)=\sum_{n \leq \log_2 x}\vartheta(x^{1/n})$, we find that

$$0 \leq \psi(x)-\vartheta(x)=\sum_{2\leq n \leq \log_2 x}\vartheta(x^{1/n}).$$

But from the definition of $\vartheta(x)$ we have the trivial inequality

$$\vartheta(x)\leq \sum_{p\leq x}\log x\leq x\log x$$

so

$$\begin{aligned} 0\leq\psi(x)-\vartheta(x)&\leq \sum_{2\leq n\leq \log_2 x}x^{1/n}\log(x^{1/n})\\ &\leq(\log_2 x)\sqrt{x}\log\sqrt{x}\\ &=\frac{\log x}{\log 2}\frac{\sqrt{x}}{2}\log x\\ &=\frac{\sqrt{x}\,(\log x)^2}{2\log 2}. \end{aligned}$$

Lastly, divide by $x$ to obtain the inequality in the theorem.

:::

## Asymptotics and bounds {#Asymptotics_and_bounds}

The following bounds are known for the Chebyshev functions: (in these formulas $p_{k}$ is the $k$th prime number; $p_{1} = 2$, $p_{2} = 3$, etc.)

$$\begin{aligned} \vartheta(p_k) &\ge k\left( \log k+\log\log k-1+\frac{\log\log k-2.050735}{\log k}\right)&& \text{for }k\ge10^{11}, \\[8px] \vartheta(p_k) &\le k\left( \log k+\log\log k-1+\frac{\log\log k-2}{\log k}\right)&& \text{for }k \ge 198, \\[8px] |\vartheta(x)-x| &\le 0.006788\,\frac{x}{\log x}&& \text{for }x \ge 10\,544\,111, \\[8px] |\psi(x)-x|&\le0.006409\,\frac{x}{\log x}&& \text{for } x \ge e^{22},\\[8px] 0.9999\sqrt{x} &< \psi(x)-\vartheta(x)<1.00007\sqrt{x}+1.78\sqrt[3]{x}&& \text{for }x\ge121. \end{aligned}$$

Furthermore, under the [Riemann hypothesis](wikipedia://en/19344125),

$$\begin{aligned} |\vartheta(x)-x| &= O\Big(x^{\frac12+\varepsilon}\Big) \\ |\psi(x)-x| &= O\Big(x^{\frac12+\varepsilon}\Big) \end{aligned}$$

for any $\varepsilon > 0$.

Upper bounds exist for both $\vartheta(x)$ and $\psi(x)$ such that[^o10]

$$\begin{aligned} \vartheta(x)&<1.000028x \\ \psi(x)&<1.03883x \end{aligned}$$

for any $x > 0$.

## The exact formula {#The_exact_formula}

In 1895, [Hans Carl Friedrich von Mangoldt](wikipedia://en/1928734) proved an [explicit expression](https://en.wikipedia.org/wiki/Explicit_formulae_%28L-function%29) for $\psi(x)$ as a sum over the nontrivial [zeros](wikipedia://en/264210) of the [Riemann zeta function](wikipedia://en/25809):

$$\psi_0(x) = x - \sum_{\rho} \frac{x^{\rho}}{\rho} - \frac{\zeta'(0)}{\zeta(0)} - \tfrac{1}{2} \log (1-x^{-2}).$$

(The numerical value of $\tfrac{\zeta(0)}{\zeta(0)}$ is $\log(2\pi)$.) Here $\rho$ runs over the nontrivial zeros of the zeta function, and $\psi_{0}$ is the same as $\psi$, except that at its [jump discontinuities](https://en.wikipedia.org/wiki/Jump_discontinuity) (the prime powers) it takes the value halfway between the values to the left and the right:

$$\psi_0(x) = \frac{1}{2}\!\left( \sum_{n \leq x} \Lambda(n)+\sum_{n < x} \Lambda(n)\right) =\begin{cases} \psi(x) - \tfrac{1}{2} \Lambda(x) & x = 2,3,4,5,7,8,9,11,13,16,\dots \\ \, \psi(x) & \mbox{otherwise.} \end{cases}$$

From the [Taylor series](wikipedia://en/30448) for the [logarithm](wikipedia://en/21476), the last term in the explicit formula can be understood as a summation of $\tfrac{x^{\omega}}{\omega}$ over the trivial zeros of the zeta function, $\omega = -2, -4, -6, ...$, i.e.

$$\sum_{k=1}^{\infty} \frac{x^{-2k}}{-2k} = \tfrac{1}{2} \log \left( 1 - x^{-2} \right).$$

Similarly, the first term, $x = \tfrac{x^{1}}{1}$, corresponds to the simple [pole](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) of the zeta function at 1. It being a pole rather than a zero accounts for the opposite sign of the term.

:::

## Properties {#Properties}

A theorem due to [Erhard Schmidt](wikipedia://en/672191) states that, for some explicit positive constant $K$, there are infinitely many [natural numbers](wikipedia://en/21474) $x$ such that

$$\psi(x)-x < -K\sqrt{x}$$

and infinitely many natural numbers $x$ such that

$$\psi(x)-x > K\sqrt{x}.$$

In [little-$o$ notation](https://en.wikipedia.org/wiki/Big-O_notation), one may write the above as

$$\psi(x)-x \ne o\left(\sqrt{x}\,\right).$$

[Hardy](wikipedia://en/87599) and [Littlewood](https://en.wikipedia.org/wiki/J._E._Littlewood) prove the stronger result, that

$$\psi(x)-x \ne o\left(\sqrt{x}\,\log\log\log x\right).$$

:::

## Relation to primorials {#Relation_to_primorials}

The first Chebyshev function is the logarithm of the [primorial](wikipedia://en/422786) of $x$, denoted $x\#$, as we have

$$\vartheta(x) = \sum_{p \le x} \log p = \log \prod_{p\le x} p = \log\left(x\#\right).$$

The [prime number theorem](wikipedia://en/23692) is equivalent to $\lim_{x\to\infty}({\vartheta (x)}/x) = 1$. From the equivalent form $\vartheta(x)=x(1+o(1))$ as $x\rightarrow\infty$, where $o$ is the [little-$o$ notation](https://en.wikipedia.org/wiki/Little-o_notation), it thus immediately follows that we have

$$x\#=e^{(1+o(1))x}.$$

## Relation to the prime-counting function {#Relation_to_the_prime-counting_function}

The Chebyshev function can be related to the prime-counting function as follows. Define

$$\Pi(x) = \sum_{n \leq x} \frac{\Lambda(n)}{\log n}.$$

Then

$$\Pi(x) = \sum_{n \leq x} \Lambda(n) \int_n^x \frac{dt}{t \log^2 t} + \frac{1}{\log x} \sum_{n \leq x} \Lambda(n) = \int_2^x \frac{\psi(t)\, dt}{t \log^2 t} + \frac{\psi(x)}{\log x}.$$

The transition from $\Pi$ to the [prime-counting function](wikipedia://en/331826), $\pi$, is made through the equation

$$\Pi(x) = \pi(x) + \tfrac{1}{2} \pi\left(\sqrt{x}\,\right) + \tfrac{1}{3} \pi\left(\sqrt[3]{x}\,\right) + \cdots$$

Certainly $\pi(x) \le x$, so for the sake of approximation, this last relation can be recast in the form

$$\pi(x) = \Pi(x) + O\left(\sqrt{x}\,\right).$$

::: {#o18 .statement kind=statement/conjecture cue=named-heading name="The Riemann hypothesis"}

## The Riemann hypothesis {#The_Riemann_hypothesis}

The [Riemann hypothesis](wikipedia://en/19344125) states that all nontrivial [zeros](wikipedia://en/264210) of the zeta function have [real part](https://en.wikipedia.org/wiki/Real_part) $\tfrac{1}{2}$. In this case, $\lvert x^{\rho}\rvert = \sqrt{x}$, and it can be shown that

$$\sum_{\rho} \frac{x^{\rho}}{\rho} = O\!\left(\sqrt{x}\, \log^2 x\right).$$

By the above, this implies

$$\pi(x) = \operatorname{li}(x) + O\!\left(\sqrt{x}\, \log x\right).$$

:::

## Smoothing function {#Smoothing_function}

*Image: Chebyshev-smooth.svg.* The difference of the smoothed Chebyshev function and $\tfrac{x^{2}}{2}$ for $x < 10^{6}$

The **smoothing function** is defined as

$$\psi_1(x) = \int_0^x \psi(t)\,dt.$$

It can trivially be shown that $\psi_1(x) \sim \frac{x^2}{2}.$
