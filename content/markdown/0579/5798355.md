# Inner measure

::: {#o1 .subject cue=lead name="Inner measure"}

In [mathematics](wikipedia://en/18831), in particular in [measure theory](https://en.wikipedia.org/wiki/Measure_theory), an **inner measure** is a [function](wikipedia://en/185427) on the [power set](wikipedia://en/23799) of a given [set](wikipedia://en/26691), with values in the [extended real numbers](https://en.wikipedia.org/wiki/Extended_real_line), satisfying some technical conditions. Intuitively, the inner measure of a set is a lower bound of the size of that set.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An inner measure is a [set function](wikipedia://en/25911217)

$$\varphi : 2^X \to [0, \infty],$$

defined on all [subsets](wikipedia://en/27631) of a set $X,$ that satisfies the following conditions:

- Null empty set: The [empty set](wikipedia://en/9566) has zero inner measure (*see also: [measure zero](https://en.wikipedia.org/wiki/Measure_zero)*); that is, $$\varphi(\varnothing) = 0$$
- [Superadditive](wikipedia://en/1464384): For any [disjoint](wikipedia://en/39359) sets $A$ and $B,$ $$\varphi(A \cup B) \geq \varphi(A) + \varphi(B).$$
- Limits of decreasing towers: For any [sequence](wikipedia://en/27838) $A_1, A_2, \ldots$ of sets such that $A_j \supseteq A_{j+1}$ for each $j$ and $\varphi(A_1) < \infty$ $$\varphi \left(\bigcap_{j=1}^\infty A_j\right) = \lim_{j \to \infty} \varphi(A_j)$$
- If the measure is not finite, that is, if there exist sets $A$ with $\varphi(A) = \infty$, then this infinity must be approached. More precisely, if $\varphi(A) = \infty$ for a set $A$ then for every positive [real number](wikipedia://en/20646438) $r,$ there exists some $B \subseteq A$ such that $$r \leq \varphi(B) < \infty.$$

:::

## The inner measure induced by a measure {#The_inner_measure_induced_by_a_measure}

Let $\Sigma$ be a [σ-algebra](wikipedia://en/29586) over a set $X$ and $\mu$ be a [measure](wikipedia://en/19873) on $\Sigma.$ Then the inner measure $\mu_*$ induced by $\mu$ is defined by

$$\mu_*(T) = \sup\{\mu(S) : S \in \Sigma \text{ and } S \subseteq T\}.$$

Essentially $\mu_*$ gives a lower bound of the size of any set by ensuring it is at least as big as the $\mu$-measure of any of its $\Sigma$-measurable subsets. Even though the set function $\mu_*$ is usually not a measure, $\mu_*$ shares the following properties with measures:

1. $$\mu_*(\varnothing) = 0,$$
1. $\mu_*$ is non-negative,
1. If $E \subseteq F$ then $\mu_*(E) \leq \mu_*(F).$

## Measure completion {#Measure_completion}

Induced inner measures are often used in combination with [outer measures](wikipedia://en/488605) to extend a measure to a larger σ-algebra. If $\mu$ is a finite measure defined on a [σ-algebra](wikipedia://en/29586) $\Sigma$ over $X$ and $\mu^*$ and $\mu_*$ are corresponding induced outer and inner measures, then the sets $T \in 2^X$ such that $\mu_*(T) = \mu^*(T)$ form a σ-algebra $\hat \Sigma$ with $\Sigma\subseteq\hat\Sigma$.[^o6] The set function $\hat\mu$ defined by

$$\hat\mu(T) = \mu^*(T) = \mu_*(T)$$

for all $T \in \hat \Sigma$ is a measure on $\hat \Sigma$ known as the completion of $\mu.$
