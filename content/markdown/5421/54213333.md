# Hardware security

::: {#o1 .subject cue=lead name="Hardware security"}

**Hardware security** is a discipline originated from the cryptographic engineering and involves [hardware design](https://en.wikipedia.org/wiki/Hardware_design), [access control](https://en.wikipedia.org/wiki/Access_control), [secure multi-party computation](wikipedia://en/646233), secure key storage, ensuring code authenticity, measures to ensure that the supply chain that built the product is secure among other things.[^o2][^o3][^o4][^o5]

:::

A [hardware security module](https://en.wikipedia.org/wiki/Hardware_security_module) (HSM) is a physical computing device that safeguards and manages [digital keys](https://en.wikipedia.org/wiki/Digital_keys) for strong authentication and provides [cryptoprocessing](wikipedia://en/59865). These modules traditionally come in the form of a plug-in card or an external device that attaches directly to a [computer](https://en.wikipedia.org/wiki/Computer) or [network server](https://en.wikipedia.org/wiki/Server_%28computing%29).

Some providers in this discipline consider that the key difference between hardware security and [software security](https://en.wikipedia.org/wiki/Computer_security) is that hardware security is implemented using "non-[Turing-machine](wikipedia://en/30403)" logic (raw [combinatorial logic](wikipedia://en/89371) or [simple state machines](wikipedia://en/10931)). One approach, referred to as "hardsec", uses [FPGAs](https://en.wikipedia.org/wiki/Field-programmable_gate_array) to implement non-Turing-machine security controls as a way of combining the security of hardware with the flexibility of software.[^o6]

[Hardware backdoors](https://en.wikipedia.org/wiki/Hardware_backdoor) are [backdoors](https://en.wikipedia.org/wiki/Backdoor_%28computing%29) in [hardware](https://en.wikipedia.org/wiki/Computer_hardware). Conceptionally related, a [hardware Trojan](https://en.wikipedia.org/wiki/Hardware_Trojan) (HT) is a malicious modification of [electronic system](https://en.wikipedia.org/wiki/Electronic_system), particularly in the context of [integrated circuit](https://en.wikipedia.org/wiki/Integrated_circuit).[^o2][^o4]

A [physical unclonable function](wikipedia://en/13578949) (PUF)[^o7][^o8] is a physical entity that is embodied in a physical structure and is easy to evaluate but hard to predict. Further, an individual PUF device must be easy to make but practically impossible to duplicate, even given the exact manufacturing process that produced it. In this respect it is the hardware analog of a [one-way function](wikipedia://en/363890). The name "physical unclonable function" might be a little misleading as some PUFs are clonable, and most PUFs are noisy and therefore do not achieve the requirements for a [function](wikipedia://en/185427). Today, PUFs are usually implemented in [integrated circuits](https://en.wikipedia.org/wiki/Integrated_circuits) and are typically used in applications with high security requirements.

Many attacks on sensitive data and resources reported by organizations occur from within the organization itself.[^o9]
