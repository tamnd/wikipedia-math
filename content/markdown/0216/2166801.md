# Empty domain

*Image: Square of opposition, set diagrams.svg.* In modern logic only the contradictories in the [square of opposition](wikipedia://en/246976) apply, because domains may be empty.(Black areas are empty,red areas are nonempty.)

::: {#o1 .subject cue=lead name="Empty domain"}

In [first-order logic](wikipedia://en/10983), the **empty [domain](wikipedia://en/229180)** is the [empty set](wikipedia://en/9566), having no members. In traditional and classical logic, domains are restrictedly non-empty in order that certain theorems be valid. Interpretations with an empty domain are shown to be a trivial case by a convention originating at least in 1927 with [Bernays](wikipedia://en/2556580) and [Schönfinkel](wikipedia://en/767234) (though possibly earlier) but oft-attributed to [Quine's](wikipedia://en/33833) 1951 *Mathematical Logic*.[^o2]

:::

## Existential import {#Existential_import}

The convention is to assign any formula beginning with a universal quantifier the value *truth,* while any formula beginning with an existential quantifier is assigned the value *falsehood*. This follows from the idea that existentially quantified statements have **existential import** (i.e. they imply the existence of something) while universally quantified statements do not.

With ancient logic such as [Aristotelian logic](https://en.wikipedia.org/wiki/Aristotelian_logic), the universally quantified statement has existential import, i. e. "All As are B" implies "Some As are B". In contemporary logic, this implication is rejected. "All As are B" might be true even if there are no As, and so does not have existential import, while "Some As are B" implies the existence of at least one A, so it does.[^o4]

This interpretation stems from the likes of [Franz Brentano](https://en.wikipedia.org/wiki/Franz_Brentano), [Charles Sanders Peirce](wikipedia://en/6117), [Gottlob Frege](wikipedia://en/48416), and [George Boole](wikipedia://en/38298).[^o5] In modern [model theory](wikipedia://en/19858), it follows immediately for the truth conditions for quantified sentences:

- $$A\models\exists x\phi(x) \text{ if and only if there is an } a\in A\text{ such that }A\models\phi[a]$$
- $$A\models\forall x\phi(x) \text{ if and only if every } a\in A\text{ is such that }A\models\phi[a]$$

In other words, an existential quantification of the open formula *φ* is true in a model if and only if there is some element in the domain (of the model) that satisfies the formula; i.e. if and only if that element has the property denoted by the open formula. A universal quantification of an open formula *φ* is true in a model if and only if every element in the domain satisfies that formula. (Note that in the metalanguage, "everything that is such that X is such that Y" is interpreted as a [universal generalization](wikipedia://en/939333) of the [material conditional](wikipedia://en/658808) "if anything is such that X then it is such that Y". Also, the quantifiers are given their usual objectual readings, so that a positive existential statement has existential import, while a universal one does not.) An analogous case concerns the empty conjunction and the empty disjunction. The semantic clauses for, respectively, conjunctions and disjunctions are given by

- $$A\models \phi_1\land\dots\land\phi_n \iff \forall\phi_i (1\leq i\leq n), A\models \phi_i$$
- $$A\models \phi_1\lor\dots\lor\phi_n \iff \exists\phi_i (1\leq i\leq n), A\models \phi_i.$$

It is easy to see that the empty conjunction is trivially true, and the empty disjunction trivially false.

Logics whose theorems are valid in every, including the empty, domain were first considered by Jaskowski 1934, [Mostowski](wikipedia://en/1029314) 1951, Hailperin 1953, Quine 1954, Leonard 1956, and [Hintikka](https://en.wikipedia.org/wiki/Hintikka) 1959. While Quine called such logics "inclusive" logic they are now referred to as [free logic](wikipedia://en/1635110).
