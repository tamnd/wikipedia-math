# Farkas

::: {#o1 .subject cue=lead name="Farkas"}

**Farkas** ("Wolf" in Hungarian) is a [Hungarian](https://en.wikipedia.org/wiki/Hungary) surname and a given name. In Czech and Slovak languages it is rendered as [Farkaš](https://en.wikipedia.org/wiki/Farkaš).

:::
