# Truth-value semantics

::: {#o1 .subject cue=lead name="Truth-value semantics"}

In [formal semantics](https://en.wikipedia.org/wiki/Formal_semantics_%28logic%29), **truth-value semantics** is an alternative to [Tarskian semantics](wikipedia://en/601240). It has been primarily championed by [Ruth Barcan Marcus](wikipedia://en/369743),[^o2] H. Leblanc, and [J. Michael Dunn](https://en.wikipedia.org/wiki/J._Michael_Dunn) and [Nuel Belnap](wikipedia://en/1251311).[^o3] It is also called the *substitution interpretation* (of the quantifiers) or substitutional quantification.

:::

The idea of these semantics is that a [universal](https://en.wikipedia.org/wiki/Universal_quantifier) (respectively, [existential](https://en.wikipedia.org/wiki/Existential_quantifier)) [quantifier](wikipedia://en/43507260) may be read as a [conjunction](wikipedia://en/18152) (respectively, [disjunction](wikipedia://en/7962)) of formulas in which constants replace the variables in the scope of the quantifier. For example, $\forall xPx$ may be read ($Pa \land Pb \land Pc \land\dots$) where $a, b, c$ are individual constants replacing all occurrences of $x$ in $Px$.

The main difference between truth-value semantics and the [standard semantics](https://en.wikipedia.org/wiki/Tarskian_semantics) for [predicate logic](https://en.wikipedia.org/wiki/Predicate_logic) is that there are no domains for truth-value semantics. Only the [truth clauses](https://en.wikipedia.org/wiki/Truth_clause) for atomic and for quantificational formulas differ from those of the standard semantics. Whereas in standard semantics [atomic formulas](wikipedia://en/4472066) like $Pb$ or $Rca$ are true if and only if (the referent of) $b$ is a member of the extension of the predicate $P$, respectively, if and only if the pair $(c, a)$ is a member of the extension of $R$, in truth-value semantics the truth-values of atomic formulas are basic. A universal (existential) formula is true if and only if all (some) [ground](https://en.wikipedia.org/wiki/Ground_formula) substitution instances of the unquantified subformula are true. Compare this with the standard semantics, which says that a universal (existential) formula is true if and only if for all (some) members of the domain, the formula holds for all (some) of them; for example, $\forall x A$ is true (under an interpretation) if and only if for all $k$ in the domain $D$, $A(k/x)$ is true (where $A(k/x)$ is the result of substituting $k$ for all occurrences of $x$ in $A$). (Here we are assuming that constants are names for themselves—i.e. they are also members of the domain.)

Truth-value semantics is not without its problems. First, the [strong completeness theorem](wikipedia://en/31271451#Forms_of_completeness) and [compactness](wikipedia://en/152207) fail. To see this consider the set $\{F(1), F(2),\dots\}$. Clearly the formula $\forall x F(x)$ is a [logical consequence](wikipedia://en/37531624) of the set, but it is not a consequence of any finite subset of it (and hence it is not deducible from it). It follows immediately that both compactness and the strong completeness theorem fail for truth-value semantics. This is rectified by a modified definition of logical consequence as given in Dunn and Belnap 1968.[^o3]

Another problem occurs in [free logic](wikipedia://en/1635110). Consider a language with one individual constant $c$ that is nondesignating and a predicate $F$ standing for 'does not exist'. Then $\exists x F x$ is false even though a substitution instance (in fact *every* such instance under this interpretation) of it is true. To solve this problem we simply add the proviso that an existentially quantified statement is true under an interpretation for at least one substitution instance in which the constant designates something that exists.
