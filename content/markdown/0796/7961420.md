# Streamline diffusion

::: {#o1 .subject cue=lead name="Streamline diffusion"}

**Streamline diffusion**, given an [advection](https://en.wikipedia.org/wiki/Advection_equation)-[diffusion equation](wikipedia://en/645335), refers to all [diffusion](https://en.wikipedia.org/wiki/Diffusion) going on along the advection direction.[^o2]

:::
