# Convex combination

In [convex geometry](wikipedia://en/4165882) and [vector algebra](wikipedia://en/32370), a **convex combination** is a [linear combination](wikipedia://en/55632) of [points](wikipedia://en/593693) (which can be [vectors](https://en.wikipedia.org/wiki/Vector_%28geometric%29), [scalars](wikipedia://en/3588331), or more generally points in an [affine space](wikipedia://en/298834)) where all [coefficients](https://en.wikipedia.org/wiki/Coefficients) are [non-negative](https://en.wikipedia.org/wiki/Non-negative) and sum to 1.[^o2] In other words, the operation is equivalent to a standard [weighted average](wikipedia://en/189822), but whose weights are expressed as a percent of the total weight, instead of as a fraction of the *count* of the weights as in a standard weighted average.

:::

## Formal definition {#Formal_definition}

More formally, given a finite number of points $x_1, x_2, \dots, x_n$ in a [real vector space](https://en.wikipedia.org/wiki/Real_vector_space) or [affine space](wikipedia://en/298834), a convex combination of these points is a point of the form

$$\alpha_1x_1+\alpha_2x_2+\cdots+\alpha_nx_n$$

where the real numbers $\alpha_i$ satisfy $\alpha_i\ge 0$ and $\alpha_1+\alpha_2+\cdots+\alpha_n=1.$[^o2]

As a particular example, every convex combination of two points lies on the [line segment](wikipedia://en/22634860) between the points.[^o2]

A set is [convex](wikipedia://en/6292) if it contains all convex combinations of its points. The [convex hull](wikipedia://en/40634) of a given set of points is identical to the set of all their convex combinations.[^o2]

There exist subsets of a vector space that are not closed under linear combinations but are closed under convex combinations. For example, the interval $[0,1]$ is convex but generates the real-number line under linear combinations. Another example is the convex set of [probability distributions](wikipedia://en/23543), as linear combinations preserve neither nonnegativity nor affinity (i.e., having total integral one).

:::

## Other objects {#Other_objects}

- A [random variable](wikipedia://en/25685) $X$ is said to have an $n$-component [finite mixture distribution](wikipedia://en/708242#Finite_and_countable_mixtures) if its [probability density function](wikipedia://en/43487) is a convex combination of $n$ so-called component densities.

## Related constructions {#Related_constructions}

- A [conical combination](wikipedia://en/19634578) is a linear combination with nonnegative coefficients. When a point $x$ is to be used as the reference origin for defining [displacement vectors](https://en.wikipedia.org/wiki/Displacement_%28vector%29), then $x$ is a convex combination of $n$ points $x_1, x_2, \dots, x_n$ if and only if the zero displacement is a non-trivial [conical combination](wikipedia://en/19634578) of their $n$ respective displacement vectors relative to $x$.
- [Weighted means](https://en.wikipedia.org/wiki/Weighted_mean) are functionally the same as convex combinations, but they use a different notation. The coefficients ([weights](wikipedia://en/245523)) in a weighted mean are not required to sum to 1; instead the weighted linear combination is explicitly divided by the sum of the weights.
- [Affine combinations](wikipedia://en/298835) are like convex combinations, but the coefficients are not required to be non-negative. Hence, affine combinations are defined in vector spaces over any [field](wikipedia://en/10603).
