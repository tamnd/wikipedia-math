# Conformable matrix

::: {#o1 .subject cue=lead name="Conformable matrix"}

In [mathematics](wikipedia://en/18831), a [matrix](wikipedia://en/20556859) is **conformable** if its dimensions are suitable for defining some operation (*e.g.* addition, multiplication, etc.).[^o2]

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- If two matrices have the same dimensions (number of rows and number of columns), they are *conformable for addition*.
- Multiplication of two matrices is defined if and only if the number of columns of the left matrix is the same as the number of rows of the right matrix. That is, if $\mathbf{A}$ is an $m \times n$ matrix and $\mathbf{B}$ is an $s \times p$ matrix, then $n$ needs to be equal to $s$ for the matrix product $\mathbf{AB}$ to be defined. In this case, we say that $\mathbf{A}$ and $\mathbf{B}$ are *conformable for multiplication* (in that sequence).
- Since squaring a matrix involves multiplying it by itself ($\mathbf{A}^{\mathbf{2}} = \mathbf{AA}$) a matrix must be $m \times m$ (that is, it must be a [square matrix](wikipedia://en/166022)) to be *conformable for squaring*. Thus for example only a square matrix can be [idempotent](wikipedia://en/2974863).
- Only a square matrix is *conformable for [matrix inversion](https://en.wikipedia.org/wiki/Matrix_inversion)*. However, the [Moore–Penrose pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse) and other [generalized inverses](wikipedia://en/7043631) do not have this requirement.
- Only a square matrix is *conformable for [matrix exponentiation](https://en.wikipedia.org/wiki/Matrix_exponentiation)*.

:::
