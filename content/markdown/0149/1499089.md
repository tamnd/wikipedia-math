# Hardy's theorem

::: {#o1 .subject cue=lead name="Hardy's theorem"}

In [mathematics](wikipedia://en/18831), **Hardy's theorem** is a result in [complex analysis](wikipedia://en/5759) describing the behavior of [holomorphic functions](wikipedia://en/14110).

:::

Let $f$ be a holomorphic function on the [open ball](https://en.wikipedia.org/wiki/Open_ball) centered at zero and radius $R$ in the [complex plane](wikipedia://en/217628), and assume that $f$ is not a [constant function](wikipedia://en/320861). If one defines

$$I(r) = \frac{1}{2\pi} \int_0^{2\pi}\! \left| f(r e^{i\theta}) \right| \,d\theta$$

for $0< r < R,$ then this function is strictly [increasing](wikipedia://en/48260) and is a convex function of $\log r$.
