# Minkowski inequality

::: {#o1 .subject cue=lead name="Minkowski inequality"}

In [mathematical analysis](wikipedia://en/48396), the **Minkowski inequality** establishes that the [$L^p$ spaces](wikipedia://en/45194) satisfy the [triangle inequality](wikipedia://en/53941) in the definition of [normed vector spaces](wikipedia://en/21538). The inequality is named after the German mathematician [Hermann Minkowski](wikipedia://en/193537).

:::

Let $S$ be a [measure space](wikipedia://en/45270), let $1 \leq p \leq \infty$ and let $f$ and $g$ be elements of $L^p(S).$ Then $f + g$ is in $L^p(S),$ and we have the triangle inequality

$$\|f+g\|_p \leq \|f\|_p + \|g\|_p$$

with equality for $1 < p < \infty$ if and only if $f$ and $g$ are positively [linearly dependent](https://en.wikipedia.org/wiki/Linearly_dependent); that is, $f = \lambda g$ for some $\lambda \geq 0$ or $g = 0.$ Here, the norm is given by:

$$\|f\|_p = \left(\int |f|^p d\mu\right)^{\frac{1}{p}}$$

if $p < \infty,$ or in the case $p = \infty$ by the [essential supremum](https://en.wikipedia.org/wiki/Essential_supremum)

$$\|f\|_\infty = \operatorname{ess\ sup}_{x\in S}|f(x)|.$$

The Minkowski inequality is the triangle inequality in $L^p(S).$ In fact, it is a special case of the more general fact

$$\|f\|_p = \sup_{\|g\|_q = 1} \int |fg| d\mu, \qquad \tfrac{1}{p} + \tfrac{1}{q} = 1$$

where it is easy to see that the right-hand side satisfies the triangular inequality.

Like [Hölder's inequality](wikipedia://en/191538), the Minkowski inequality can be specialized to sequences and vectors by using the [counting measure](wikipedia://en/191786):

$$\left(\sum_{k=1}^n |x_k + y_k|^p\right)^{1/p} \leq \left(\sum_{k=1}^n |x_k|^p\right)^{1/p} + \left(\sum_{k=1}^n |y_k|^p\right)^{1/p}$$

for all [real](wikipedia://en/20646438) (or [complex](wikipedia://en/5826)) numbers $x_1, \dots, x_n, y_1, \dots, y_n$ and where $n$ is the [cardinality](wikipedia://en/6174) of $S$ (the number of elements in $S$).

In probabilistic terms, given the [probability space](wikipedia://en/43325) $(\Omega, \mathcal{F}, \mathbb{P}),$ and $\mathbb{E}$ denote the [expectation operator](wikipedia://en/9653) for every real- or complex-valued [random variables](wikipedia://en/25685) $X$ and $Y$ on $\Omega,$ Minkowski's inequality reads

$$\left(\mathbb{E}[|X + Y|^p]\right)^{\frac{1}{p}} \leqslant \left(\mathbb{E}[ |X|^p]\right)^{\frac{1}{p}} + \left(\mathbb{E}[|Y|^p]\right)^{\frac{1}{p}}.$$

::: {#o3 .proof cue=heading name="Proof"}

## Proof {#Proof}

::: {#o5 .proof cue=heading name="Proof by Hölder's inequality"}

### Proof by Hölder's inequality {#Proof_by_Hölder's_inequality}

First, we prove that $f + g$ has finite $p$-norm if $f$ and $g$ both do, which follows by

$$|f + g|^p \leq 2^{p-1}(|f|^p + |g|^p).$$

Indeed, here we use the fact that $h(x) = |x|^p$ is [convex](wikipedia://en/245568) over $\mathbb{R}^+$ (for $p > 1$) and so, by the definition of convexity,

$$\left|\tfrac{1}{2} f + \tfrac{1}{2} g\right|^p \leq \left|\tfrac{1}{2} |f| + \tfrac{1}{2} |g|\right|^p \leq \tfrac{1}{2}|f|^p + \tfrac{1}{2} |g|^p.$$

This means that

$$|f+g|^p \leq \tfrac{1}{2}|2f|^p + \tfrac{1}{2}|2g|^p = 2^{p-1}|f|^p + 2^{p-1}|g|^p.$$

Now, we can legitimately talk about $\|f + g\|_p$. If it is zero, then Minkowski's inequality holds. We now assume that $\|f + g\|_p$ is not zero. Using the triangle inequality and then [Hölder's inequality](wikipedia://en/191538), we find that

$$\begin{aligned} \|f + g\|_p^p &= \int |f + g|^p \, \mathrm{d}\mu \\ &= \int |f + g| \cdot |f + g|^{p-1} \, \mathrm{d}\mu \\ &\leq \int (|f| + |g|)|f + g|^{p-1} \, \mathrm{d}\mu \\ &=\int |f||f + g|^{p-1} \, \mathrm{d}\mu+\int |g||f + g|^{p-1} \, \mathrm{d}\mu \\ &\leq \left(\left(\int |f|^p \, \mathrm{d}\mu\right)^{\frac{1}{p}} + \left(\int |g|^p \,\mathrm{d}\mu\right)^{\frac{1}{p}}\right)\left(\int |f + g|^{(p-1)\left(\frac{p}{p-1}\right)} \, \mathrm{d}\mu\right)^{1-\frac{1}{p}} && \text{ Hölder's inequality} \\ &= \left(\|f\|_p + \|g\|_p \right )\frac{\|f + g\|_p^p}{\|f + g\|_p} \end{aligned}$$

We obtain Minkowski's inequality by multiplying both sides by

$$\frac{\|f + g\|_p}{\|f + g\|_p^p}.$$

:::

::: {#o7 .proof cue=heading name="Proof by a direct convexity argument"}

### Proof by a direct convexity argument {#Proof_by_a_direct_convexity_argument}

Given $t \in (0, 1)$, one has, by convexity ([Jensen's inequality](wikipedia://en/297811)), for every $x \in S$

$$|f (x) + g (x)|^p = \Bigl|(1-t) \frac{f(x)}{1 -t} + t \frac{g(x)}{t} \Bigr|^p \le (1-t) \Bigl|\frac{f(x)}{1 -t}\Bigr|^p + t \Bigl|\frac{g(x)}{t} \Bigr|^p = \frac{|f(x)|^p}{(1-t)^{p - 1}} + \frac{|g(x)|^p}{t^{p-1}}.$$

By integration this leads to

$$\int_{S} |f + g|^p\, \mathrm{d}\mu \le \frac{1}{(1-t)^{p-1}}\int_{S} |f|^p\, \mathrm{d}\mu + \frac{1}{t^{p-1}} \int_{S} |g|^p\, \mathrm{d}\mu.$$

One takes then

$$t = \frac{\Vert g \Vert_{p}}{\Vert f \Vert_{p} + \Vert g \Vert_{p}}$$

to reach the conclusion.

:::

:::

::: {#o9 .statement cue=named-heading name="Minkowski's integral inequality"}

## Minkowski's integral inequality {#Minkowski's_integral_inequality}

Suppose that $(S_1, \mu_1)$ and $(S_2, \mu_2)$ are two -finite measure spaces and $F : S_1 \times S_2 \to \mathbb{R}$ is measurable. Then Minkowski's integral inequality is:[^n1][^n2]

$$\left[\int_{S_2}\left|\int_{S_1}F(x,y)\, \mu_1(\mathrm{d}x)\right|^p \mu_2(\mathrm{d}y)\right]^{\frac{1}{p}} ~\leq~ \int_{S_1}\left(\int_{S_2}|F(x,y)|^p\,\mu_2(\mathrm{d}y)\right)^{\frac{1}{p}}\mu_1(\mathrm{d}x),\quad p\in[1,\infty)$$

with obvious modifications in the case $p = \infty.$ If $p > 1,$ and both sides are finite, then equality holds only if $|F(x, y)| = \varphi(x) \, \psi(y)$ a.e. for some non-negative measurable functions $\varphi$ and $\psi$.

If $\mu_1$ is the counting measure on a two-point set $S_1 = \{1, 2\},$ then Minkowski's integral inequality gives the usual Minkowski inequality as a special case: for putting $f_i(y) = F(i, y)$ for $i = 1, 2,$ the integral inequality gives

$$\|f_1 + f_2\|_p = \left(\int_{S_2}\left|\int_{S_1}F(x,y)\,\mu_1(\mathrm{d}x)\right|^p \mu_2(\mathrm{d}y)\right)^{\frac{1}{p}} \leq \int_{S_1}\left(\int_{S_2}|F(x,y)|^p\,\mu_2(\mathrm{d}y)\right)^{\frac{1}{p}} \mu_1(\mathrm{d}x) = \|f_1\|_p + \|f_2\|_p.$$

If the measurable function $F : S_1 \times S_2 \to \mathbb{R}$ is non-negative then for all $1 \leq p \leq q \leq \infty,$[^n3]

$$\left\|\left\|F(\,\cdot, s_2)\right\|_{L^p(S_1, \mu_1)}\right\|_{L^q(S_2, \mu_2)} ~\leq~ \left\|\left\|F(s_1, \cdot)\right\|_{L^q(S_2, \mu_2)}\right\|_{L^p(S_1, \mu_1)} \ .$$

This notation has been generalized to

$$\|f\|_{p,q} = \left(\int_{\mathbb{R}^m} \left[\int_{\mathbb{R}^n}|f(x,y)|^q\mathrm{d}y\right]^{\frac{p}{q}} \mathrm{d}x\right)^{\frac{1}{p}}$$

for $f : \mathbb{R}^{m+n} \to E,$ with $\mathcal{L}_{p,q}(\mathbb{R}^{m+n},E) = \{f \in E^{\mathbb{R}^{m+n}} : \|f\|_{p,q} < \infty\}.$ Using this notation, manipulation of the exponents reveals that, if $p < q,$ then $\|f\|_{q,p} \leq \|f\|_{p,q}$.

:::

::: {#o14 .statement cue=named-heading name="Reverse inequality"}

## Reverse inequality {#Reverse_inequality}

When $p < 1$ the reverse inequality holds:

$$\|f+g\|_p \ge \|f\|_p + \|g\|_p.$$

We further need the restriction that both $f$ and $g$ are non-negative, as we can see from the example $f=-1, g=1$ and $p = 1$

$$\|f+g\|_1 = 0 < 2 = \|f\|_1 + \|g\|_1.$$

The reverse inequality follows from the same argument as the standard Minkowski, but uses that Hölder's inequality is also reversed in this range.

Using the Reverse Minkowski, we may prove that power means with $p \leq 1,$ such as the [harmonic mean](wikipedia://en/14463) and the [geometric mean](wikipedia://en/13046) are concave.

:::

## Generalizations to other functions {#Generalizations_to_other_functions}

The Minkowski inequality can be generalized to other functions $\phi(x)$ beyond the power function $x^p$. The generalized inequality has the form

$$\phi^{-1}\left(\textstyle\sum\limits_{i=1}^n \phi(x_i + y_i)\right) \leq \phi^{-1}\left(\textstyle\sum\limits_{i=1}^n \phi(x_i)\right) + \phi^{-1}\left(\textstyle\sum\limits_{i=1}^n \phi(y_i)\right).$$

Various sufficient conditions on $\phi$ have been found by Mulholland[^o16] and others. For example, for $x \geq 0$ one set of sufficient conditions from Mulholland is

1. $\phi(x)$ is continuous and strictly increasing with $\phi(0) = 0.$
1. $\phi(x)$ is a convex function of $x.$
1. $\log\phi(x)$ is a convex function of $\log(x).$
