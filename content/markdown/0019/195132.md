# Negligible set

::: {#o1 .subject cue=lead name="Negligible set"}

In [mathematics](wikipedia://en/18831), a **negligible set** is a [set](wikipedia://en/26691) that is small enough that it can be ignored for some purpose. As common examples, [finite sets](wikipedia://en/11742) can be ignored when studying the [limit of a sequence](wikipedia://en/285773), and [null sets](wikipedia://en/21520) can be ignored when studying the [integral](https://en.wikipedia.org/wiki/Integral_%28measure_theory%29) of a [measurable function](wikipedia://en/44055).

:::

Negligible sets define several useful concepts that can be applied in various situations, such as truth [almost everywhere](wikipedia://en/44688). In order for these to work, it is generally only necessary that the negligible sets form an [ideal](wikipedia://en/12633368); that is, that the [empty set](wikipedia://en/9566) be negligible, the [union](wikipedia://en/47949) of two negligible sets be negligible, and any [subset](wikipedia://en/27631) of a negligible set be negligible. For some purposes, we also need this ideal to be a [sigma-ideal](wikipedia://en/1567410), so that [countable](https://en.wikipedia.org/wiki/Countable) unions of negligible sets are also negligible. If $I$ and $J$ are both ideals of [subsets](wikipedia://en/27631) of the same [set](wikipedia://en/26691) $X$, then one may speak of $I$*\-negligible* and $J$*\-negligible* subsets.

The opposite of a negligible set is a [generic property](wikipedia://en/12886758), which has various forms.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Let *X* be the set **N** of [natural numbers](wikipedia://en/21474), and let a subset of **N** be negligible if it is [finite](wikipedia://en/11742). Then the negligible sets form an ideal. This idea can be applied to any [infinite set](wikipedia://en/142679); but if applied to a finite set, every subset will be negligible, which is not a very useful notion.

Or let *X* be an [uncountable set](wikipedia://en/32248), and let a subset of *X* be negligible if it is [countable](wikipedia://en/6026). Then the negligible sets form a sigma-ideal.

Let *X* be a [measurable space](wikipedia://en/43333) equipped with a [measure](wikipedia://en/19873) *m,* and let a subset of *X* be negligible if it is *m*-[null](wikipedia://en/21520). Then the negligible sets form a sigma-ideal. Every sigma-ideal on *X* can be recovered in this way by placing a suitable measure on *X*, although the measure may be rather pathological.

Let *X* be the set **R** of [real numbers](wikipedia://en/20646438), and let a subset *A* of **R** be negligible if for each ε > 0,[^o4] there exists a finite or countable collection *I*<sub>1</sub>, *I*<sub>2</sub>, … of (possibly overlapping) intervals satisfying:

$$A \subset \bigcup_{k} I_k$$

and

$$\sum_{k} |I_k| < \epsilon .$$

This is a special case of the preceding example, using [Lebesgue measure](wikipedia://en/18198), but described in elementary terms.

Let *X* be a [topological space](wikipedia://en/30450), and let a subset be negligible if it is of [first category](https://en.wikipedia.org/wiki/First_category), that is, if it is a countable union of [nowhere-dense sets](https://en.wikipedia.org/wiki/Nowhere-dense_set) (where a set is nowhere-dense if it is not [dense](wikipedia://en/23523594) in any [open set](wikipedia://en/39358)). Then the negligible sets form a sigma-ideal.

Let *X* be a [directed set](wikipedia://en/9165), and let a subset of *X* be negligible if it has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound). Then the negligible sets form an ideal. The first example is a special case of this using the usual ordering of *N*.

In a [coarse structure](wikipedia://en/4960605), the controlled sets are negligible.

:::

## Derived concepts {#Derived_concepts}

Let *X* be a [set](wikipedia://en/26691), and let *I* be an ideal of negligible [subsets](wikipedia://en/27631) of *X*. If *p* is a proposition about the elements of *X*, then *p* is true *[almost everywhere](wikipedia://en/44688)* if the set of points where *p* is true is the [complement](wikipedia://en/54347) of a negligible set. That is, *p* may not always be true, but it's false so rarely that this can be ignored for the purposes at hand.

If *f* and *g* are functions from *X* to the same space *Y*, then *f* and *g* are *equivalent* if they are equal almost everywhere. To make the introductory paragraph precise, then, let *X* be **N**, and let the negligible sets be the finite sets. Then *f* and *g* are sequences. If *Y* is a [topological space](wikipedia://en/30450), then *f* and *g* have the same limit, or both have none. (When you generalise this to a directed sets, you get the same result, but for [nets](wikipedia://en/22170).) Or, let *X* be a measure space, and let negligible sets be the null sets. If *Y* is the [real line](https://en.wikipedia.org/wiki/Real_line) **R**, then either *f* and *g* have the same integral, or neither integral is defined.
