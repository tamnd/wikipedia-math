# Completeness (statistics)

::: {#o1 .subject cue=lead name="Completeness"}

In [statistics](wikipedia://en/26685), **completeness** is a property of a [statistic](wikipedia://en/26703) computed on a [sample dataset](https://en.wikipedia.org/wiki/Sample_%28statistics%29) in relation to a parametric model of the dataset. It is opposed to the concept of an [ancillary statistic](wikipedia://en/670398). While an ancillary statistic contains no information about the model parameters, a complete statistic contains only information about the parameters, and no ancillary information. It is closely related to the concept of a [sufficient statistic](wikipedia://en/140841) which contains all of the information that the dataset provides about the parameters.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Consider a [random variable](wikipedia://en/25685) *X* whose probability distribution belongs to a [parametric model](wikipedia://en/2883137) ***P***<sub>*θ*</sub> parametrized by *θ*.

Say *T* is a [statistic](wikipedia://en/26703); that is, the composition of a [measurable function](wikipedia://en/44055) with a random sample *X*<sub>1</sub>,...,*X*<sub>n</sub>.

The statistic *T* is said to be **complete** for the distribution of *X* if, for every measurable function *g,*[^o2]

$$\text{if }\operatorname{E}_\theta(g(T))=0\text{ for all }\theta\text{ then }\mathbf{P}_\theta(g(T)=0)=1\text{ for all }\theta.$$

The statistic *T* is said to be **boundedly complete** for the distribution of *X* if this implication holds for every measurable function *g* that is also bounded.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

### Bernoulli model {#Bernoulli_model}

The Bernoulli model admits a complete statistic.[^o2] Let *X* be a [random sample](https://en.wikipedia.org/wiki/Random_sample) of size *n* such that each *X*<sub>*i*</sub> has the same [Bernoulli distribution](wikipedia://en/199189) with parameter *p*. Let *T* be the number of 1s observed in the sample, i.e. $\textstyle T = \sum_{i=1}^n X_i$. *T* is a statistic of *X* which has a [binomial distribution](wikipedia://en/3876) with parameters (*n*,*p*). If the parameter space for *p* is (0,1), then *T* is a complete statistic. To see this, note that

$$\operatorname{E}_p(g(T)) = \sum_{t=0}^n {g(t){n \choose t}p^{t}(1-p)^{n-t}} = (1-p)^n \sum_{t=0}^n {g(t){n \choose t}\left(\frac{p}{1-p}\right)^t} .$$

Observe also that neither *p* nor 1 − *p* can be 0. Hence $E_p(g(T)) = 0$ if and only if:

$$\sum_{t=0}^n g(t){n \choose t}\left(\frac{p}{1-p}\right)^t = 0.$$

On denoting *p*/(1 − *p*) by *r*, one gets:

$$\sum_{t=0}^n g(t){n \choose t}r^t = 0 .$$

First, observe that the range of *r* is the [positive reals](https://en.wikipedia.org/wiki/Positive_reals). Also, E(*g*(*T*)) is a [polynomial](wikipedia://en/23000) in *r* and, therefore, can only be identical to 0 if all coefficients are 0, that is, *g*(*t*) = 0 for all *t*.

It is important to notice that the result that all coefficients must be 0 was obtained because of the range of *r*. Had the parameter space been finite and with a number of elements less than or equal to *n*, it might be possible to solve the linear equations in *g*(*t*) obtained by substituting the values of *r* and get solutions different from 0. For example, if *n* = 1 and the parameter space is {0.5}, a single observation and a single parameter value, *T* is not complete. Observe that, with the definition:

$$g(t) = 2(t-0.5), \,$$

then, E(*g*(*T*)) = 0 although *g*(*t*) is not 0 for *t* = 0 nor for *t* = 1.

### Gaussian model with fixed variance {#Gaussian_model_with_fixed_variance}

This example will show that, in a sample *X*<sub>1</sub>, *X*<sub>2</sub> of size 2 from a [normal distribution](wikipedia://en/21462) with known variance, the statistic *X*<sub>1</sub> + *X*<sub>2</sub> is complete and sufficient. Suppose *X*<sub>1</sub>, *X*<sub>2</sub> are [independent](https://en.wikipedia.org/wiki/Statistical_independence), identically distributed random variables, [normally distributed](wikipedia://en/21462) with expectation *θ* and variance 1. The sum

$$s((X_1, X_2)) = X_1 + X_2$$

is a **complete statistic** for *θ*.

To show this, it is sufficient to demonstrate that there is no non-zero function $g$ such that the expectation of

$$g(s(X_1, X_2)) = g(X_1+X_2)$$

remains zero regardless of the value of *θ*.

That fact may be seen as follows. The probability distribution of *X*<sub>1</sub> + *X*<sub>2</sub> is normal with expectation 2*θ* and variance 2. Its probability density function in $x$ is therefore proportional to

$$\exp\left(-(x-2\theta)^2/4\right).$$

The expectation of *g* above would therefore be a constant times

$$\int_{-\infty}^\infty g(x)\exp\left(-(x-2\theta)^2/4\right)\,dx.$$

A bit of algebra reduces this to

$$k(\theta) \int_{-\infty}^\infty h(x)e^{x\theta}\,dx,$$

where *k*(*θ*) is nowhere zero and

$$h(x)=g(x)e^{-x^2/4}.$$

As a function of *θ* this is a two-sided [Laplace transform](wikipedia://en/18610) of *h*, and cannot be identically zero unless *h* is zero almost everywhere.[^o9] The exponential is not zero, so this can only happen if *g* is zero almost everywhere.

By contrast, the statistic $(X_1,X_2)$ is sufficient but not complete. It admits a non-zero unbiased estimator of zero, namely $X_1-X_2$.

### Sufficiency does not imply completeness {#Sufficiency_does_not_imply_completeness}

Most parametric models have a [sufficient statistic](wikipedia://en/140841) which is not complete. This is important because the [Lehmann–Scheffé theorem](wikipedia://en/342602) cannot be applied to such models. Galili and Meilijson 2016 [^o11] propose the following didactic example.

Consider $n$ independent samples from the uniform distribution:

$$X_i \sim U \big( (1-k) \theta , (1+k)\theta \big) \qquad\qquad 0 < k < 1$$

$k$ is a known design parameter. This model is a *scale family* (a specific case of [a location-scale family](https://en.wikipedia.org/wiki/Location-scale_family)) model: scaling the samples by a multiplier $c$ multiplies the parameter $\theta$.

Galili and Meilijson show that the minimum and maximum of the samples are together a sufficient statistic: $X_{(1)}, X_{(n)}$ (using the usual notation for [order statistics](wikipedia://en/160986)). Indeed, conditional on these two values, the distribution of the rest of the sample is simply uniform on the range they define: $\left[X_{(1)}, X_{(n)}\right]$.

However, their ratio has a distribution which does not depend on $\theta$. This follows from the fact that this is a scale family: any change of scale impacts both variables identically. Subtracting the mean $m$ from that distribution, we obtain:

$$\mathbb E \left[ \frac {X_{(n)}} {X_{(1)} } \right] - m = 0$$

We have thus shown that there exists a function $g\left(X_{(1)}, X_{(n)}\right)$ which is not $0$ everywhere but which has expectation $0$. The pair is thus not complete.

:::

## Importance of completeness {#Importance_of_completeness}

The notion of completeness has many applications in statistics, particularly in the following theorems of mathematical statistics.

::: {#o14 .statement kind=statement/theorem cue=named-heading name="Lehmann–Scheffé theorem"}

### Lehmann–Scheffé theorem {#Lehmann–Scheffé_theorem}

**Completeness** occurs in the [Lehmann–Scheffé theorem](wikipedia://en/342602),[^o2] which states that given a **complete** and [sufficient](https://en.wikipedia.org/wiki/Sufficiency_%28statistics%29) statistic $T$, an unbiased estimator for the parameter *θ* of the form $g(T)$, for some measurable function $g$, is the best mean-unbiased estimator for *θ*. In other words, the estimator $g(T)$ has the smallest expected loss for any [convex](wikipedia://en/245568) loss function; in many practical applications with the squared loss-function, it has a smaller mean squared error among any estimators with the same [expected value](wikipedia://en/9653).

There are examples where the minimal sufficient statistic is **not complete** and where several alternative statistics for unbiased estimation of *θ* exist, while some of them have lower variance than others.[^o11]

See also [minimum-variance unbiased estimator](wikipedia://en/1583470).

:::

::: {#o16 .statement kind=statement/theorem cue=named-heading name="Basu's theorem"}

### Basu's theorem {#Basu's_theorem}

**Bounded completeness** occurs in [Basu's theorem](wikipedia://en/7807871),[^o2] which states that a statistic that is both **boundedly complete** and [sufficient](wikipedia://en/140841) is [independent](https://en.wikipedia.org/wiki/Statistical_independence) of any [ancillary statistic](wikipedia://en/670398).

:::

::: {#o18 .statement kind=statement/theorem cue=named-heading name="Bahadur's theorem"}

### Bahadur's theorem {#Bahadur's_theorem}

**Bounded completeness** also occurs in Bahadur's theorem. In the case where there exists at least one [minimal sufficient](https://en.wikipedia.org/wiki/Minimal_sufficient) statistic, a statistic which is [sufficient](https://en.wikipedia.org/wiki/Sufficient) and boundedly complete, is necessarily minimal sufficient.[^o19]

:::
