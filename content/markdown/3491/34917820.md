# Berman–Hartmanis conjecture

::: {#o1 .subject cue=lead name="Berman–Hartmanis conjecture"}

::: {#o2 .problem cue=unsolved}

Is there a polynomial time isomorphism between every two NP-complete languages?

:::

In [structural complexity theory](https://en.wikipedia.org/wiki/Structural_complexity_theory), the **Berman–Hartmanis conjecture** is an unsolved [conjecture](wikipedia://en/6138) named after Leonard C. Berman and [Juris Hartmanis](https://en.wikipedia.org/wiki/Juris_Hartmanis).[^o3] Informally, it states that all [NP-complete](https://en.wikipedia.org/wiki/NP-complete) languages look alike, in the sense that they can be related to each other by [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) [isomorphisms](wikipedia://en/14828).[^o4][^o5][^o6][^o7]

:::

::: {#o9 .statement cue=heading name="Statements"}

## Statements {#Statements}

### Statement using p-isomorphism {#Statement_using_p-isomorphism}

An **isomorphism** between [formal languages](wikipedia://en/10939) *L*<sub>1</sub> and *L*<sub>2</sub> is a [bijective](wikipedia://en/3942) map *f* from [strings](wikipedia://en/27701) in the alphabet of *L*<sub>1</sub> to strings in the alphabet of *L*<sub>2</sub>, with the property that a string *x* belongs to *L*<sub>1</sub> if and only if *f*(*x*) belongs to *L*<sub>2</sub>.

A polynomial-time isomorphism, or ***p*-isomorphism** for short, is an isomorphism *f* where both *f* and its [inverse function](wikipedia://en/14907) can be computed in an amount of time polynomial in the lengths of their arguments.

Berman and Hartmanis conjectured that all NP-complete languages are p-isomorphic to each other.[^o3]

### Statement using paddable languages {#Statement_using_paddable_languages}

A formal language *L* is **paddable** if there is a polynomial time function *f*(*x*,*y*), with a polynomial time inverse, such that for every *x* and every *y*, the string *x* belongs to *L* if and only if *f*(*x*,*y*) belongs to *L*. That is, it is possible to [pad](https://en.wikipedia.org/wiki/Padding_argument) the input *x* with irrelevant information *y*, in an invertible way, without changing its membership in the language. Berman and Hartmanis *proved* that all pairs of paddable NP-complete languages are p-isomorphic.[^o3]

Since *p*-isomorphism preserves paddability, and there exist paddable NP-complete languages, an equivalent way of stating the Berman–Hartmanis conjecture is that all NP-complete languages are paddable.

### Statement using equivalence relations {#Statement_using_equivalence_relations}

Polynomial time isomorphism is an [equivalence relation](wikipedia://en/9259), and it can be used to partition the formal languages into [equivalence classes](wikipedia://en/9260), so another way of stating the Berman–Hartmanis conjecture is that the NP-complete languages form a single equivalence class for this relation.

:::

## Implications {#Implications}

### Non-existence of sparse NP-complete languages {#Non-existence_of_sparse_NP-complete_languages}

A formal language is called [**sparse**](wikipedia://en/12769596) if the number of yes-instances of length *n* grows only polynomially as a function of *n*. The known NP-complete languages have a number of yes-instances that grows exponentially, and if *L* is a language with exponentially many yes-instances then it cannot be *p*-isomorphic to a sparse language, because its yes-instances would have to be mapped to strings that are more than polynomially long in order for the mapping to be one-to-one. Therefore, if the Berman–Hartmanis conjecture is true, an immediate consequence would be the nonexistence of sparse NP-complete languages.

### P vs. NP {#P_vs._NP}

The nonexistence of sparse NP-complete languages in turn implies that [P ≠ NP](wikipedia://en/6115), because if P = NP then every nontrivial language in P (including some sparse ones, such as the language of binary strings all of whose bits are zero) would be NP-complete. In 1982, Steve Mahaney published his proof that the nonexistence of sparse NP-complete languages (with NP-completeness defined in the standard way using [many-one reductions](wikipedia://en/362983)) is in fact equivalent to the statement that P ≠ NP; this is [Mahaney's theorem](wikipedia://en/47241003). Even for a relaxed definition of NP-completeness using [Turing reductions](wikipedia://en/1188375), the existence of a sparse NP-complete language would imply an unexpected collapse of the [polynomial hierarchy](wikipedia://en/658651).[^o16]

## Evidence {#Evidence}

As evidence towards the conjecture, (Agrawal Allender Impagliazzo Pitassi 1997) showed that an analogous conjecture with a restricted type of reduction is true: every two languages that are complete for NP under [AC<sup>0</sup>](wikipedia://en/7400698) many-one reductions have an AC<sup>0</sup> isomorphism.[^o19] (Agrawal Watanabe 2009) showed that, if there exist [one-way functions](wikipedia://en/363890) that cannot be inverted in polynomial time on all inputs, but if every such function has a small but dense subset of inputs on which it can be inverted in [P/poly](wikipedia://en/2052415) (as is true for known functions of this type) then every two NP-complete languages have a P/poly isomorphism.[^o21] And (Fenner Fortnow Kurtz 1992) found an [oracle machine](wikipedia://en/22431) model in which the analogue to the isomorphism conjecture is true.[^o23]

Evidence against the conjecture was provided by (Joseph Young 1985) and (Kurtz Mahaney Royer 1995). Joseph and Young introduced a class of NP-complete problems, the [*k*-creative sets](https://en.wikipedia.org/wiki/Polynomial_creativity), for which no *p*-isomorphism to the standard NP-complete problems is known.[^o26] Kurtz et al. showed that in oracle machine models given access to a [random oracle](wikipedia://en/451286), the analogue of the conjecture is not true: if *A* is a random oracle, then not all sets complete for NP<sup>*A*</sup> have isomorphisms in P<sup>*A*</sup>.[^o27] Random oracles are commonly used in the theory of cryptography to model [cryptographic hash functions](wikipedia://en/439526) that are computationally indistinguishable from random, and the construction of Kurtz et al. can be carried out with such a function in place of the oracle. For this reason, among others, the Berman–Hartmanis isomorphism conjecture is believed false by many complexity theorists.[^o28]
