# Bilinear quadrilateral element

::: {#o1 .subject cue=lead name="Bilinear quadrilateral element"}

The **bilinear quadrilateral element**, also known as the **Q4 element**,[^o3] is a type of element used in [finite element analysis](https://en.wikipedia.org/wiki/Finite_element_analysis) which is used to approximate in a 2D domain the exact solution to a given [differential equation](wikipedia://en/1424309).

:::

The element consists of a combination of two sets of [Lagrange polynomials](wikipedia://en/217523), each one used to define the variation of a field in each orthogonal direction of the local referential.
