# OpenBUGS

::: {#o1 .subject cue=lead name="OpenBUGS"}

**OpenBUGS** is a [software application](https://en.wikipedia.org/wiki/Software_application) for the [Bayesian analysis](https://en.wikipedia.org/wiki/Bayesian_analysis) of [complex](https://en.wikipedia.org/wiki/Complex_system) [statistical models](wikipedia://en/27576) using [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC) methods. OpenBUGS is the open source variant of [WinBUGS](wikipedia://en/10794084) ([Bayesian inference](wikipedia://en/49571) Using [Gibbs Sampling](wikipedia://en/509709)). It runs under [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) and [Linux](https://en.wikipedia.org/wiki/Linux), as well as from inside the [R statistical package](https://en.wikipedia.org/wiki/R_programming_language). [Versions](https://en.wikipedia.org/wiki/Software_versioning) from v3.0.7 onwards have been designed to be at least as efficient and reliable as WinBUGS over a range of test applications.[^o4]

:::

## Differences from WinBUGS {#Differences_from_WinBUGS}

In addition to the different licence and greater range of operating systems, a fundamental difference between OpenBUGS and WinBUGS is the way in which the expert system selects the updating algorithm to use for the class of full [conditional distribution](https://en.wikipedia.org/wiki/Conditional_distribution) of each node. While WinBUGS defines one algorithm for each possible class, there is no limit to the number of algorithms that OpenBUGS can use, allowing greater flexibility and extensibility.[^o4][^o5] The user can select the updater to be used for each node after compilation. Further differences are detailed on the OpenBUGS website.[^o6]

## Programming language {#Programming_language}

The [source code](https://en.wikipedia.org/wiki/Source_code) of OpenBUGS is written in the [Component Pascal](https://en.wikipedia.org/wiki/Component_Pascal) [programming language](wikipedia://en/23015) and is dependent on the Component Pascal [libraries](https://en.wikipedia.org/wiki/Library_%28computer_science%29) provided by Oberon Microsystems as part of the [Blackbox Component Framework](https://en.wikipedia.org/wiki/BlackBox_Component_Builder). The development tools are available as open source. Binaries of the current version of OpenBUGS are available for Microsoft Windows, and the previous version for [Linux](https://en.wikipedia.org/wiki/Linux), it can also run under WINE for Linux. Installation problems, development and usage questions are discussed at the OpenBUGS Bulletin Board.

Attempts to port OpenBUGS to [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) with the [Gardens Point Component Pascal](https://en.wikipedia.org/wiki/Gardens_Point_Component_Pascal) were given up in favor of a new portable implementation called [JAGS](wikipedia://en/21845564).

The [BUGS language](https://en.wikipedia.org/wiki/BUGS_language) is the language that specifies the model code. It is [parsed](https://en.wikipedia.org/wiki/Parsing) by OpenBUGS, which then creates an [executable](https://en.wikipedia.org/wiki/Executable) (compiled code) that generates a [sample](https://en.wikipedia.org/wiki/Sample_%28statistics%29) from the [posterior distribution](wikipedia://en/357672) when run.

OpenBUGS was designed to run together with [S-Plus](https://en.wikipedia.org/wiki/S-Plus)[^o8] and the BUGS language is similar to the [S programming language](https://en.wikipedia.org/wiki/S_programming_language). OpenBUGS works well together with [R](https://en.wikipedia.org/wiki/R_programming_language); the R2OpenBUGS or BRugs packages provides some interoperability, and R modules help further analyses.
