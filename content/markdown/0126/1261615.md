# Rectangular function

*Image: Rectangular function.svg.* Rectangular function with $T = 1$

::: {#o1 .subject cue=lead name="Rectangular function"}

The **rectangular function** (also known as the **rectangle function**, **rect function**, **Pi function**, **Heaviside Pi function**,[^o2] **gate function**, **unit pulse**, or the **normalized [boxcar function](wikipedia://en/1454542)**) is defined as

:::

$$\operatorname{rect}\left(\frac{t}{T}\right) = \Pi\left(\frac{t}{T}\right) = \left\{\begin{array}{rl} 0, & \text{if } |t| > \frac{T}{2} \\ \frac{1}{2}, & \text{if } |t| = \frac{T}{2} \\ 1, & \text{if } |t| < \frac{T}{2}. \end{array}\right.$$

Alternative definitions of the function define $\operatorname{rect}\left(t=\pm\frac{T}{2}\right)$ to be 0,[^o4] 1,[^o5][^o6] or undefined. The area under the curve does not change for the different definitions of the functions at $t=\pm\frac{T}{2}$.

The rectangular function can be used as the basis for a *[rectangular wave](https://en.wikipedia.org/wiki/Rectangular_wave)*.

## History {#History}

The *rect* function has been introduced 1953 by [Woodward](wikipedia://en/9986270)[^o8] in "Probability and Information Theory, with Applications to Radar"[^o9] as an ideal [cutout operator](wikipedia://en/244097#Rectangular_window), together with the [*sinc* function](wikipedia://en/610583)[^o10][^o11] as an ideal [interpolation operator](wikipedia://en/105499), and their counter operations which are [sampling](https://en.wikipedia.org/wiki/Sampling_%28signal_processing%29) ([*comb* operator](wikipedia://en/1314272#Dirac-comb_identity)) and [replicating](wikipedia://en/29262224) ([*rep* operator](wikipedia://en/1314272#Dirac-comb_identity)), respectively.

## Relation to the boxcar function {#Relation_to_the_boxcar_function}

The rectangular function is a special case of the more general [boxcar function](wikipedia://en/1454542):

$$\operatorname{rect}\left(\frac{t-X}{Y} \right) = H(t - (X - Y/2)) - H(t - (X + Y/2)) = H(t - X + Y/2) - H(t - X - Y/2)$$

where $H(x)$ is the [Heaviside step function](wikipedia://en/87299); the function is centered at $X$ and has duration $Y$, from $X-Y/2$ to $X+Y/2.$

## Fourier transform of the rectangular function {#Fourier_transform_of_the_rectangular_function}

*Image: Sinc\_function\_(normalized).svg.* Plot of normalized $\operatorname{sinc}(x)$ function (i.e. $\operatorname{sinc}(\pi x)$) with its spectral frequency components.

The [unitary Fourier transforms](wikipedia://en/52247#Tables_of_important_Fourier_transforms) of the rectangular function are[^o3]

$$\int_{-\infty}^\infty \operatorname{rect}(t)\cdot e^{-i 2\pi f t} \, dt =\frac{\sin(\pi f)}{\pi f} = \operatorname{sinc}(\pi f) =\operatorname{sinc}_\pi(f),$$

using ordinary frequency $f$, where [$\operatorname{sinc}_\pi$](wikipedia://en/610583) is the normalized form[^o14] of the [sinc function](wikipedia://en/610583) and

$$\frac{1}{\sqrt{2\pi}}\int_{-\infty}^\infty \operatorname{rect}(t)\cdot e^{-i \omega t} \, dt =\frac{1}{\sqrt{2\pi}}\cdot \frac{\sin\left(\omega/2 \right)}{\omega/2} =\frac{1}{\sqrt{2\pi}} \cdot \operatorname{sinc}\left(\omega/2 \right),$$

using angular frequency $\omega$, where [$\operatorname{sinc}$](wikipedia://en/610583) is the unnormalized form of the [sinc function](wikipedia://en/610583).

For $\operatorname{rect} (x/a)$, its Fourier transform is

$$\int_{-\infty}^\infty \operatorname{rect}\left(\frac{t}{a}\right)\cdot e^{-i 2\pi f t} \, dt =a \frac{\sin(\pi af)}{\pi af} = a\ \operatorname{sinc}_\pi{(a f)}.$$

## Self convolution of the Rectangular function {#Self_convolution_of_the_Rectangular_function}

*Image: Splines resulting from successive convolution of the unit Rect function.png.* The unit Rectangular function (in which $T=1$) along with the [piecewise defined](wikipedia://en/404130) [splines](wikipedia://en/457680) that result from successive convolutions of the Rectangular function with itself.

The [self convolution](https://en.wikipedia.org/wiki/Self_convolution) of the dis-[continuous](wikipedia://en/6122) rectangular function results in the [triangular function](wikipedia://en/3524992), a [piecewise defined](wikipedia://en/404130) [spline](wikipedia://en/457680) that is continuous, but not continuously [differentiable](wikipedia://en/330206). Successive convolutions of the rectangular function result in piecewise defined pulses with lower maximums which are wider and smoother, with "smoother" meaning [higher-order derivatives](https://en.wikipedia.org/wiki/Higher-order_derivative) are continuous.[^o16]

A [convolution](wikipedia://en/7519) of the discontinuous rectangular function with itself results in the triangular function, which is a continuous function:

$$\begin{aligned} \operatorname{rect(2t/T)} * \operatorname{rect(2t/T)} = \operatorname{tri(t/T)} = \begin{cases} 1 + t, & -T < t < 0 \\ 1 - t, & \,\,\,\,\, 0 < t < T \\ 0 & \,\,\,\,\,\text{otherwise} \\ \end{cases} \end{aligned}$$

Self convolution of the rectangular function applied twice yields a continuous and differentiably continuous parabolic spline:

$$\begin{aligned} \operatorname{rect(2t/T)} * \operatorname{rect(2t/T)} * \operatorname{rect(2t/T)} = \operatorname{tri(t/T)} * \operatorname{rect(2t/T)} = \begin{cases} \frac{9}{8} + \frac{3}{2}t + \frac{1}{2}t^2, & -\frac{3}{2}T < t < -\frac{1}{2}T \\ \frac{3}{4} - t^2, & -\frac{1}{2}T < t < \frac{1}{2}T \\ \frac{9}{8} - \frac{3}{2}t + \frac{1}{2}t^2, & \,\,\,\,\, \frac{1}{2}T < t < \frac{3}{2}T \\ 0 & \,\,\,\,\,\text{otherwise} \\ \end{cases} \end{aligned}$$

A self convolution of the rectangular function applied three times yields a continuous, and a second order differentiably continuous cubic spline:

$$\begin{aligned} \operatorname{tri(t/T)} * \operatorname{tri(t/T)} = \begin{cases} \frac{4}{3} + {2}t + t^2 +\frac{1}{6}t^3 , & -2T < t < -T \\ \frac{2}{3} - t^2 - \frac{1}{2}t^3, & -T < t < 0 \\ \frac{2}{3} - t^2 + \frac{1}{2}t^3, & \,\,\,\,\,0 < t < T \\ \frac{4}{3} - {2}t + t^2 -\frac{1}{6}t^3 , & \,\,\,\,\,T < t < 2T \\ 0 & \,\,\,\,\,\text{otherwise} \\ \end{cases} \end{aligned}$$

A self convolution of the rectangular function applied four times yields a continuous, and a third order differentiably continuous 4th order spline:

$$\begin{aligned} 4^{th}\,\text{order spline} = \begin{cases} \frac{625}{384} + \frac{125}{48}t + \frac{25}{16}t^2 +\frac{5}{12}t^3 + \frac{1}{24}t^4, & -\frac{5}{2}T < t < -\frac{3}{2}T \\ \frac{55}{96} - \frac{5}{24}t - \frac{5}{4} t^2 - \frac{5}{6}t^3 -\frac{1}{6}t^4, & -\frac{3}{2}T < t < -\frac{1}{2}T \\ \frac{115}{192} - \frac{5}{8}t^2 + \frac{1}{4}t^4, & -\frac{1}{2}T < t < \frac{1}{2}T \\ \frac{55}{96} + \frac{5}{24}t - \frac{5}{4} t^2 + \frac{5}{6}t^3 -\frac{1}{6}t^4, & \,\,\,\,\,\frac{1}{2}T < t < \frac{3}{2}T \\ \frac{625}{384} - \frac{125}{48}t + \frac{25}{16}t^2 -\frac{5}{12}t^3 + \frac{1}{24}t^4, & \,\,\,\,\,\frac{3}{2}T < t < \frac{5}{2}T \\ 0 & \,\,\,\,\,\text{otherwise} \\ \end{cases} \end{aligned}$$

Since the [Fourier transform](wikipedia://en/52247) of the rectangular function is the [Sinc function](wikipedia://en/610583), the [convolution theorem](wikipedia://en/53268) implies that the Fourier transform of pulses resulting from successive convolutions of the rectangular function with itself is simply the Sinc function to the order of the number of times that the convolution function was applied + 1 (i.e., the Fourier transform of the triangular function is Sinc<sup>2</sup>, the Fourier transform of the parabolic spline resulting from two successive convolutions of the rectangular function with itself is Sinc<sup>3</sup>, etc.)

## Use in probability {#Use_in_probability}

Viewing the rectangular function as a [probability density function](wikipedia://en/43487), it is a special case of the [continuous uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) with $a = -1/2, b = 1/2.$ The [characteristic function](wikipedia://en/3229401) is

$$\varphi(k) = \frac{\sin(k/2)}{k/2},$$

and its [moment-generating function](https://en.wikipedia.org/wiki/Moment-generating_function) is

$$M(k) = \frac{\sinh(k/2)}{k/2},$$

where $\sinh(t)$ is the [hyperbolic sine](https://en.wikipedia.org/wiki/Hyperbolic_sine) function.

## Rational approximation {#Rational_approximation}

The pulse function may also be expressed as a limit of a [rational function](wikipedia://en/361210):

$$\Pi(t) = \lim_{n\rightarrow \infty, n\in \mathbb(Z)} \frac{1}{(2t)^{2n}+1}.$$

## Dirac delta function {#Dirac_delta_function}

The rectangle function can be used to represent the [Dirac delta function](wikipedia://en/37021) $\delta (x)$.[^o20] Specifically,

$$\delta (x) = \lim_{a \to 0} \frac{1}{a}\operatorname{rect}\left(\frac{x}{a}\right).$$

For a function $g(x)$, its average over the width *$a$* around 0 in the function domain is calculated as,

$$g_{avg}(0) = \frac{1}{a} \int\limits_{- \infty}^{\infty} dx\ g(x) \operatorname{rect}\left(\frac{x}{a}\right).$$

To obtain $g(0)$, the following limit is applied,

$$g(0) = \lim_{a \to 0} \frac{1}{a} \int\limits_{- \infty}^{\infty} dx\ g(x) \operatorname{rect}\left(\frac{x}{a}\right)$$

and this can be written in terms of the Dirac delta function as,

$$g(0) = \int\limits_{- \infty}^{\infty} dx\ g(x) \delta (x).$$

The Fourier transform of the Dirac delta function $\delta (t)$ is

$$\delta (f) = \int_{-\infty}^\infty \delta (t) \cdot e^{-i 2\pi f t} \, dt = \lim_{a \to 0} \frac{1}{a} \int_{-\infty}^\infty \operatorname{rect}\left(\frac{t}{a}\right)\cdot e^{-i 2\pi f t} \, dt = \lim_{a \to 0} \operatorname{sinc}{(a f)}.$$

where the [sinc function](wikipedia://en/610583) here is the normalized sinc function. Because the first zero of the sinc function is at $f = 1 / a$ and $a$ goes to infinity, the Fourier transform of $\delta (t)$ is

$$\delta (f) = 1,$$

means that the frequency spectrum of the Dirac delta function is infinitely broad. As a pulse is shorten in time, it is larger in spectrum.
