# Free Boolean algebra

::: {#o1 .subject cue=lead name="Free Boolean algebra"}

In [mathematics](wikipedia://en/18831), a **free Boolean algebra** is a [Boolean algebra](wikipedia://en/3959) with a distinguished set of elements, called ***generators***, such that:

:::

1. Each element of the Boolean algebra can be expressed as a finite combination of generators, using the Boolean operations, and
1. The generators are as *independent* as possible, in the sense that there are no relationships among them (again in terms of finite expressions using the Boolean operations) that do not hold in *every* Boolean algebra no matter *which* elements are chosen.

::: {#o3 .example cue=heading name="A simple example"}

## A simple example {#A_simple_example}

*Image: Free-boolean-algebra-hasse-diagram.svg.* The [Hasse diagram](wikipedia://en/338199) of the free Boolean algebra on two generators, *p* and *q*. Take *p (left circle)* to be "John is tall" and *q (right circle)*to be "Mary is rich". The atoms are the four elements in the row just above FALSE.

The [generators](https://en.wikipedia.org/wiki/Generating_set) of a free Boolean algebra can represent independent [propositions](wikipedia://en/81094). Consider, for example, the propositions "John is tall" and "Mary is rich". These generate a Boolean algebra with four [atoms](https://en.wikipedia.org/wiki/Atomic_%28order_theory%29), namely:

- John is tall, and Mary is rich;
- John is tall, and Mary is not rich;
- John is not tall, and Mary is rich;
- John is not tall, and Mary is not rich.

Other elements of the Boolean algebra are then [logical disjunctions](wikipedia://en/7962) of the atoms, such as "John is tall and Mary is not rich, or John is not tall and Mary is rich". In addition there is one more element, FALSE, which can be thought of as the empty disjunction; that is, the disjunction of no atoms.

This example yields a Boolean algebra with 16 elements; in general, for finite *n*, the free Boolean algebra with *n* generators has 2<sup>*n*</sup> [atoms](https://en.wikipedia.org/wiki/Atomic_%28order_theory%29), and therefore $2^{2^n}$ elements.

If there are [infinitely](wikipedia://en/142679) many [generators](https://en.wikipedia.org/wiki/Generating_set), a similar situation prevails except that now there are no [atoms](https://en.wikipedia.org/wiki/Atomic_%28order_theory%29). Each element of the Boolean algebra is a combination of finitely many of the generating propositions, with two such elements deemed identical if they are [logically equivalent](wikipedia://en/169324).

Another way to see why the free Boolean algebra on an n-element set has $2^{2^n}$ elements is to note that each element is a function from n bits to one. There are $2^n$ possible inputs to such a function and the function will choose 0 or 1 to output for each input, so there are $2^{2^n}$ possible functions.

:::

## Category-theoretic definition {#Category-theoretic_definition}

In the language of [category theory](wikipedia://en/5869), free Boolean algebras can be defined simply in terms of an [adjunction](wikipedia://en/53991) between the category of sets and functions, **Set**, and the category of Boolean algebras and Boolean algebra homomorphisms, **BA**. In fact, this approach generalizes to any [algebraic structure](wikipedia://en/106364) definable in the framework of [universal algebra](wikipedia://en/45200) (see [free object](wikipedia://en/333835)).

Above, we said that a free Boolean algebra is a Boolean algebra with a set of generators that behave a certain way; alternatively, one might start with a set and ask which algebra it generates. Every set *X* generates a free Boolean algebra *FX* defined as the algebra such that for every algebra *B* and function *f* : *X* → *B*, there is a unique Boolean algebra homomorphism *f*′ : *FX* → *B* that extends *f*. [Diagrammatically](wikipedia://en/138484),

*Image: Free-Boolean-algebra-unit-sloppy.png.*

where *i*<sub>*X*</sub> is the inclusion, and the dashed arrow denotes uniqueness. The idea is that once one chooses where to send the elements of *X*, the [laws for Boolean algebra homomorphisms](wikipedia://en/3959#Homomorphisms_and_isomorphisms) determine where to send everything else in the free algebra *FX*. If *FX* contained elements inexpressible as combinations of elements of *X*, then *f*′ wouldn't be unique, and if the elements of *X* weren't sufficiently independent, then *f*′ wouldn't be well defined! It is easily shown that *FX* is unique (up to isomorphism), so this definition makes sense. It is also easily shown that a free Boolean algebra with generating set X, as defined originally, is isomorphic to *FX*, so the two definitions agree.

One shortcoming of the above definition is that the diagram doesn't capture that *f*′ is a homomorphism; since it is a diagram in **Set** each arrow denotes a mere function. We can fix this by separating it into two diagrams, one in **BA** and one in **Set**. To relate the two, we introduce a [functor](wikipedia://en/10987) *U* : **BA** → **Set** that "[forgets](wikipedia://en/844783)" the algebraic structure, mapping algebras and homomorphisms to their underlying sets and functions.

*Image: Free-Boolean-algebra-unit.png.*

If we interpret the top arrow as a diagram in **BA** and the bottom triangle as a diagram in **Set**, then this diagram properly expresses that every function *f* : *X* → *UB* extends to a unique Boolean algebra homomorphism *f*′ : *FX* → *B*. The functor *U* can be thought of as a device to pull the homomorphism *f*′ back into **Set** so it can be related to *f*.

The remarkable aspect of this is that the latter diagram is one of the various (equivalent) definitions of when two functors are [adjoint](wikipedia://en/53991). Our *F* easily extends to a functor **Set** → **BA**, and our definition of *X* generating a free Boolean algebra *FX* is precisely that *U* has a [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint) *F*.

## Topological realization {#Topological_realization}

The free Boolean algebra with κ [generators](https://en.wikipedia.org/wiki/Generating_set), where κ is a finite or infinite [cardinal number](wikipedia://en/6173), may be realized as the collection of all [clopen](wikipedia://en/233398) [subsets](wikipedia://en/27631) of {0,1}<sup>κ</sup>, given the [product topology](wikipedia://en/24910) assuming that {0,1} has the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology). For each α\<κ, the α*th* generator is the set of all elements of {0,1}<sup>κ</sup> whose α*th* coordinate is 1. In particular, the free Boolean algebra with $\aleph_0$ generators is the collection of all clopen subsets of a [Cantor space](wikipedia://en/352376), sometimes called the [Cantor algebra](wikipedia://en/43215632). This collection is [countable](wikipedia://en/6026). In fact, while the free Boolean algebra with *n* generators, *n* finite, has [cardinality](wikipedia://en/6174) $2^{2^n}$, the free Boolean algebra with $\aleph_0$ generators, as for any free algebra with $\aleph_0$ generators and countably many finitary operations, has cardinality $\aleph_0$.

For more on this [topological](wikipedia://en/29954) approach to free Boolean algebra, see [Stone's representation theorem for Boolean algebras](wikipedia://en/604111).
