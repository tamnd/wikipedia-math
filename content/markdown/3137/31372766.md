# RRQR factorization

::: {#o1 .subject cue=lead name="RRQR factorization"}

An **RRQR factorization** or **rank-revealing QR factorization** is a [matrix decomposition](wikipedia://en/253873) algorithm based on the [QR factorization](wikipedia://en/305223) which can be used to determine the [rank](wikipedia://en/26561) of a matrix.[^o2] The [singular value decomposition](wikipedia://en/142207) can be used to generate an RRQR, but it is not an efficient method to do so.[^o3] An RRQR implementation is available in MATLAB.[^o4]

:::
