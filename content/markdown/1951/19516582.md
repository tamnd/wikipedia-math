# Bailey pair

::: {#o1 .subject cue=lead name="Bailey pair"}

In mathematics, a **Bailey pair** is a pair of sequences satisfying certain relations, and a **Bailey chain** is a sequence of Bailey pairs. Bailey pairs were introduced by (txt) while studying the second proof Rogers 1917 of the [Rogers–Ramanujan identities](wikipedia://en/2324711), and Bailey chains were introduced by (Andrews 1984).

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [q-Pochhammer symbols](wikipedia://en/11149717) $(a;q)_n$ are defined as:

$$(a;q)_n = \prod_{0\le j<n}(1-aq^j) = (1-a)(1-aq)\cdots(1-aq^{n-1}).$$

A pair of sequences (α<sub>*n*</sub>,β<sub>*n*</sub>) is called a Bailey pair if they are related by

$$\beta_n=\sum_{r=0}^n\frac{\alpha_r}{(q;q)_{n-r}(aq;q)_{n+r}}$$

or equivalently

$$\alpha_n = (1-aq^{2n})\sum_{j=0}^n\frac{(aq;q)_{n+j-1}(-1)^{n-j}q^{n-j\choose 2}\beta_j}{(q;q)_{n-j}}.$$

:::

::: {#o7 .statement kind=statement/lemma cue=named-heading name="Bailey's lemma"}

## Bailey's lemma {#Bailey's_lemma}

Bailey's lemma states that if (α<sub>*n*</sub>,β<sub>*n*</sub>) is a Bailey pair, then so is (α'<sub>*n*</sub>,β'<sub>*n*</sub>) where

$$\alpha^\prime_n= \frac{(\rho_1;q)_n(\rho_2;q)_n(aq/\rho_1\rho_2)^n\alpha_n}{(aq/\rho_1;q)_n(aq/\rho_2;q)_n}$$

$$\beta^\prime_n = \sum_{j\ge0}\frac{(\rho_1;q)_j(\rho_2;q)_j(aq/\rho_1\rho_2;q)_{n-j}(aq/\rho_1\rho_2)^j\beta_j}{(q;q)_{n-j}(aq/\rho_1;q)_n(aq/\rho_2;q)_n}.$$

In other words, given one Bailey pair, one can construct a second using the formulas above. This process can be iterated to produce an infinite sequence of Bailey pairs, called a **Bailey chain**.

:::

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

An example of a Bailey pair is given by (Andrews Askey Roy 1999, p. 590)

$$\alpha_n = q^{n^2+n}\sum_{j=-n}^n(-1)^jq^{-j^2}, \quad \beta_n = \frac{(-q)^n}{(q^2;q^2)_n}.$$

(txt) gave a list of 130 examples related to Bailey pairs.
