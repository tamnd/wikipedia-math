# Relationships among probability distributions

*Image: Relationships among some of univariate probability distributions.jpg.* Relationships among some of univariate probability distributions are illustrated with connected lines. dashed lines means approximate relationship. more info:[^o1]

*Image: ProbOnto2.5.jpg.* Relationships between univariate probability distributions in [ProbOnto](https://en.wikipedia.org/wiki/ProbOnto).[^o2]

::: {#o3 .subject cue=lead name="Relationships among probability distributions"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), there are several relationships among [probability distributions](https://en.wikipedia.org/wiki/Probability_distributions). These relations can be categorized in the following groups:

:::

- One distribution is a special case of another with a broader parameter space
- Transforms (function of a random variable);
- Combinations (function of several variables);
- Approximation (limit) relationships;
- Compound relationships (useful for Bayesian inference);
- [Duality](wikipedia://en/609737);
- [Conjugate priors](wikipedia://en/846412).

## Special case of distribution parametrization {#Special_case_of_distribution_parametrization}

- A [binomial distribution](wikipedia://en/3876) with parameters *n* = 1 and *p* is a [Bernoulli distribution](wikipedia://en/199189) with parameter *p*.
- A [negative binomial distribution](wikipedia://en/45177) with parameters *n* = 1 and *p* is a [geometric distribution](wikipedia://en/45922) with parameter *p*.
- A [gamma distribution](wikipedia://en/207079) with shape parameter *α* = 1 and rate parameter *β* is an [exponential distribution](wikipedia://en/45906) with rate parameter *β*.
- A [gamma distribution](wikipedia://en/207079) with shape parameter *α* = *v*/2 and rate parameter *β* = 1/2 is a [chi-squared distribution](wikipedia://en/113424) with *ν* [degrees of freedom](wikipedia://en/2321606).
- A [chi-squared distribution](wikipedia://en/113424) with 2 degrees of freedom (*k* = 2) is an [exponential distribution](wikipedia://en/45906) with a mean value of 2 (rate *λ* = 1/2 .)
- A [Weibull distribution](wikipedia://en/206948) with shape parameter *k* = 1 and rate parameter *β* is an [exponential distribution](wikipedia://en/45906) with rate parameter *β*.
- A [beta distribution](wikipedia://en/207074) with shape parameters *α* = *β* = 1 is a [continuous uniform distribution](wikipedia://en/1699223) over the real numbers 0 to 1.
- A [beta-binomial distribution](wikipedia://en/7377730) with parameter *n* and shape parameters *α* = *β* = 1 is a [discrete uniform distribution](wikipedia://en/1699214) over the integers 0 to *n*.
- A [Student's t-distribution](wikipedia://en/105375) with one degree of freedom (*v* = 1) is a [Cauchy distribution](wikipedia://en/7003) with location parameter *x* = 0 and scale parameter *γ* = 1.
- A [Burr distribution](wikipedia://en/12618582) with parameters *c* = 1 and *k* (and scale *λ*) is a [Lomax distribution](wikipedia://en/32253318) with shape *k* (and scale *λ*.)

## Transform of a variable {#Transform_of_a_variable}

### Multiple of a random variable {#Multiple_of_a_random_variable}

Multiplying the variable by any positive real constant yields a **scaling** of the original distribution. Some are self-replicating, meaning that the scaling yields the same family of distributions, albeit with a different parameter: [normal distribution](wikipedia://en/21462), [gamma distribution](wikipedia://en/207079), [Cauchy distribution](wikipedia://en/7003), [exponential distribution](wikipedia://en/45906), [Erlang distribution](wikipedia://en/199028), [Weibull distribution](wikipedia://en/206948), [logistic distribution](wikipedia://en/542666), [error distribution](https://en.wikipedia.org/wiki/Error_distribution), [power-law distribution](wikipedia://en/24522#Power-law_probability_distributions), [Rayleigh distribution](wikipedia://en/262296).

::: {#o7 .example cue=inline-head name="Example"}

**Example:**

- If *X* is a gamma random variable with shape and rate parameters (*α*, *β*), then *Y* = *aX* is a gamma random variable with parameters (*α*,*β*/*a*).
- If *X* is a gamma random variable with shape and scale parameters (*α*, *θ*), then *Y* = *aX* is a gamma random variable with parameters (*α*,*aθ*).

:::

### Linear function of a random variable {#Linear_function_of_a_random_variable}

The affine transform *ax* + *b* yields a **relocation and scaling** of the original distribution. The following are self-replicating: [Normal distribution](wikipedia://en/21462), [Cauchy distribution](wikipedia://en/7003), [Logistic distribution](wikipedia://en/542666), [Error distribution](https://en.wikipedia.org/wiki/Error_distribution), [Power distribution](wikipedia://en/24522#Power-law_probability_distributions), [Rayleigh distribution](wikipedia://en/262296).

::: {#o9 .example cue=inline-head name="Example"}

**Example:**

- If *Z* is a normal random variable with parameters (*μ* = *m*, *σ*<sup>2</sup> = *s*<sup>2</sup>), then *X* = *aZ* + *b* is a normal random variable with parameters (*μ* = *am* + *b*, *σ*<sup>2</sup> = *a*<sup>2</sup>*s*<sup>2</sup>).

:::

### Reciprocal of a random variable {#Reciprocal_of_a_random_variable}

The reciprocal 1/*X* of a random variable *X*, is a member of the same family of distribution as *X*, in the following cases: [Cauchy distribution](wikipedia://en/7003), [F distribution](https://en.wikipedia.org/wiki/F_distribution), [log logistic distribution](https://en.wikipedia.org/wiki/Log_logistic_distribution).

**Examples:**

- If X is a Cauchy (*μ*, *σ*) random variable, then 1/*X* is a Cauchy (*μ*/*C*, *σ*/*C*) random variable where *C* = *μ*<sup>2</sup> + *σ*<sup>2</sup>.
- If *X* is an *F*(*ν*<sub>1</sub>, *ν*<sub>2</sub>) random variable then 1/*X* is an *F*(*ν*<sub>2</sub>, *ν*<sub>1</sub>) random variable.

### Other cases {#Other_cases}

**Some distributions are invariant under a specific transformation.**

::: {#o12 .example cue=inline-head name="Example"}

**Example:**

- If *X* is a **beta** (*α*, *β*) random variable then (1 − *X*) is a **beta** (*β*, *α*) random variable.
- If *X* is a **binomial** (*n*, *p*) random variable then (*n* − *X*) is a **binomial** (*n*, 1 − *p*) random variable.
- If X follows a continuous **uniform distribution** on \[0,1\], and F<sub>X</sub>(X) is its cumulative distribution function (CDF), then the random variable U=F<sub>X</sub>(X) follows a standard **uniform distribution** on \[0,1\].

**Some distributions are variant under a specific transformation.**

- If *X* is a **normal** (*μ*, *σ*<sup>2</sup>) random variable then *e*<sup>*X*</sup> is a **lognormal** (*μ*, *σ*<sup>2</sup>) random variable.

Conversely, if *X* is a lognormal (*μ*, *σ*<sup>2</sup>) random variable then log *X* is a normal (*μ*, *σ*<sup>2</sup>) random variable.

- If *X* is an **exponential** random variable with mean *β*, then *X*<sup>1/*γ*</sup> is a **Weibull** (*γ*, *β*) random variable.
- The square of a **standard normal** random variable has a **chi-squared** distribution with one degree of freedom.
- If *X* is a **[Student’s t](https://en.wikipedia.org/wiki/Student’s_t-distribution)** random variable with *ν* degree of freedom, then *X*<sup>2</sup> is an ***F*** (1,*ν*) random variable.
- If *X* is a **double exponential** random variable with mean 0 and scale *λ*, then |*X*| is an **exponential** random variable with mean *λ*.
- A **geometric** random variable is the [floor](wikipedia://en/54267) of an **exponential** random variable.
- A **[rectangular](https://en.wikipedia.org/wiki/Rectangular_distribution)** random variable is the floor of a **uniform** random variable.
- A **[reciprocal](wikipedia://en/39127799)** random variable is the exponential of a **uniform** random variable.

:::

## Functions of several variables {#Functions_of_several_variables}

::: {#o15 .pointer-item cue=pointer name="Sum of independent random variables"}

### Sum of variables {#Sum_of_variables}

The distribution of the sum of [independent random variables](https://en.wikipedia.org/wiki/Independent_random_variables) is the [convolution](wikipedia://en/32251002) of their distributions. Suppose $Z$ is the sum of $n$ independent random variables $X_1, \dots, X_n$ each with [probability mass functions](wikipedia://en/154725) $f_{X_i}(x)$. Then

$$Z = \sum_{i = 1}^{n} {X_i}.$$

If it has a distribution from the same family of distributions as the original variables, that family of distributions is said to be *closed under convolution*. Often (always?) these distributions are also [stable distributions](wikipedia://en/1117869) (see also [Discrete-stable distribution](wikipedia://en/42532877)).

Examples of such [univariate distributions](wikipedia://en/9253219) are: [normal distributions](wikipedia://en/21462), [Poisson distributions](wikipedia://en/23009144), [binomial distributions](wikipedia://en/3876) (with common success probability), [negative binomial distributions](wikipedia://en/45177) (with common success probability), [gamma distributions](wikipedia://en/207079) (with common [rate parameter](https://en.wikipedia.org/wiki/Rate_parameter)), [chi-squared distributions](wikipedia://en/113424), [Cauchy distributions](wikipedia://en/7003), [hyperexponential distributions](wikipedia://en/3520536).

**Examples:**[^o16][^o17]

- If *X*<sub>1</sub> and *X*<sub>2</sub> are **Poisson** random variables with means *μ*<sub>1</sub> and *μ*<sub>2</sub> respectively, then *X*<sub>1</sub> + *X*<sub>2</sub> is a **Poisson** random variable with mean *μ*<sub>1</sub> + *μ*<sub>2</sub>.
- The sum of **gamma** (*α*<sub>*i*</sub>, *β*) random variables has a **gamma**(Σ*α*<sub>*i*</sub>, *β*) distribution.
- If *X*<sub>1</sub> is a **Cauchy** (*μ*<sub>1</sub>, *σ*<sub>1</sub>) random variable and *X*<sub>2</sub> is a Cauchy (*μ*<sub>2</sub>, *σ*<sub>2</sub>), then *X*<sub>1</sub> + *X*<sub>2</sub> is a **Cauchy** (*μ*<sub>1</sub> + *μ*<sub>2</sub>, *σ*<sub>1</sub> + *σ*<sub>2</sub>) random variable.
- If X<sub>1</sub> and X<sub>2</sub> are **chi-squared** random variables with ν<sub>1</sub> and ν<sub>2</sub> degrees of freedom respectively, then X<sub>1</sub> + X<sub>2</sub> is a **chi-squared** random variable with ν<sub>1</sub> + ν<sub>2</sub> degrees of freedom.
- If *X*<sub>1</sub> is a **normal** (*μ*<sub>1</sub>, *σ*${}^{2}_{1}$) random variable and *X*<sub>2</sub> is a normal (*μ*<sub>2</sub>, *σ*${}^{2}_{2}$) random variable, then X<sub>1</sub> + *X*<sub>2</sub> is a **normal** (*μ*<sub>1</sub> + *μ*<sub>2</sub>, *σ*${}^{2}_{1}$ + *σ*${}^{2}_{2}$) random variable.
- The sum of *N* chi-squared (1) random variables has a chi-squared distribution with *N* degrees of freedom.

Other distributions are not closed under convolution, but their sum has a known distribution:

- The sum of *n* **Bernoulli** (p) random variables is a **binomial** (*n*, *p*) random variable.
- The sum of *n* **geometric** random variables with probability of success *p* is a **negative binomial** random variable with parameters *n* and *p*.
- The sum of *n* **exponential** (*β*) random variables is a **gamma** (*n*, *β*) random variable. Since n is an integer, the gamma distribution is also a **[Erlang distribution](wikipedia://en/199028).**
- The sum of the squares of *N* **standard normal** random variables has a **chi-squared** distribution with N degrees of freedom.

:::

### Product of variables {#Product_of_variables}

The product of independent random variables *X* and *Y* may belong to the same family of distribution as *X* and *Y*: [Bernoulli distribution](wikipedia://en/199189) and [log-normal distribution](wikipedia://en/102476).

::: {#o19 .example cue=inline-head name="Example"}

**Example:**

- If *X*<sub>1</sub> and *X*<sub>2</sub> are independent **log-normal** random variables with parameters (*μ*<sub>1</sub>, *σ*${}^{2}_{1}$) and (*μ*<sub>2</sub>, *σ*${}^{2}_{2}$) respectively, then *X*<sub>1</sub> *X*<sub>2</sub> is a **log-normal** random variable with parameters (*μ*<sub>1</sub> + *μ*<sub>2</sub>, *σ*${}^{2}_{1}$ + *σ*${}^{2}_{2}$).

(See also [Product distribution](https://en.wikipedia.org/wiki/Product_distribution).)

:::

### Minimum and maximum of independent random variables {#Minimum_and_maximum_of_independent_random_variables}

For some distributions, the **minimum** value of several independent random variables is a member of the same family, with different parameters: [Bernoulli distribution](wikipedia://en/199189), [Geometric distribution](wikipedia://en/45922), [Exponential distribution](wikipedia://en/45906), [Extreme value distribution](https://en.wikipedia.org/wiki/Extreme_value_distribution), [Pareto distribution](wikipedia://en/53057), [Rayleigh distribution](wikipedia://en/262296), [Weibull distribution](wikipedia://en/206948).

**Examples:**

- If *X*<sub>1</sub> and *X*<sub>2</sub> are independent **geometric** random variables with probability of success *p*<sub>1</sub> and *p*<sub>2</sub> respectively, then min(*X*<sub>1</sub>, *X*<sub>2</sub>) is a geometric random variable with probability of success *p* = *p*<sub>1</sub> + *p*<sub>2</sub> − *p*<sub>1</sub> *p*<sub>2</sub>. The relationship is simpler if expressed in terms probability of failure: *q* = *q*<sub>1</sub> *q*<sub>2</sub>.
- If *X*<sub>1</sub> and *X*<sub>2</sub> are independent **exponential** random variables with rate *μ*<sub>1</sub> and *μ*<sub>2</sub> respectively, then min(*X*<sub>1</sub>, *X*<sub>2</sub>) is an exponential random variable with rate *μ* = *μ*<sub>1</sub> + *μ*<sub>2</sub>.

Similarly, distributions for which the **maximum** value of several independent random variables is a member of the same family of distribution include: [Bernoulli distribution](wikipedia://en/199189), [Power law](wikipedia://en/24522) distribution.

### Other {#Other}

- If *X* and *Y* are independent **standard normal** random variables, *X*/*Y* is a **Cauchy** (0,1) random variable.
- If *X*<sub>1</sub> and *X*<sub>2</sub> are independent **chi-squared** random variables with *ν*<sub>1</sub> and *ν*<sub>2</sub> degrees of freedom respectively, then (*X*<sub>1</sub>/*ν*<sub>1</sub>)/(*X*<sub>2</sub>/*ν*<sub>2</sub>) is an ***F***(*ν*<sub>1</sub>, *ν*<sub>2</sub>) random variable.
- If *X* is a **standard normal** random variable and U is an independent **chi-squared** random variable with *ν* degrees of freedom, then $\frac{X}{\sqrt{(U/\nu)}}$ is a **Student's *t***(*ν*) random variable.
- If *X*<sub>1</sub> is a **gamma** (*α*<sub>1</sub>, 1) random variable and *X*<sub>2</sub> is an independent **gamma** (α<sub>2</sub>, 1) random variable then *X*<sub>1</sub>/(*X*<sub>1</sub> + *X*<sub>2</sub>) is a **beta**(*α*<sub>1</sub>, *α*<sub>2</sub>) random variable. More generally, if *X*<sub>1</sub> is a gamma(*α*<sub>1</sub>, *β*<sub>1</sub>) random variable and *X*<sub>2</sub> is an independent gamma(*α*<sub>2</sub>, *β*<sub>2</sub>) random variable then β<sub>2</sub> X<sub>1</sub>/(*β*<sub>2</sub> *X*<sub>1</sub> + *β*<sub>1</sub> *X*<sub>2</sub>) is a beta(*α*<sub>1</sub>, *α*<sub>2</sub>) random variable.
- If *X* and *Y* are independent **exponential** random variables with mean μ, then *X* − *Y* is a **[double exponential](wikipedia://en/1106213)** random variable with mean 0 and scale μ.
- If X<sub>i</sub> are independent **Bernoulli** random variables then their [parity](wikipedia://en/22399369) (XOR) is a **Bernoulli** variable described by the [piling-up lemma](wikipedia://en/715186).

(See also [ratio distribution](wikipedia://en/9519371).)

## Approximate (limit) relationships {#Approximate_(limit)_relationships}

Approximate or limit relationship means

- either that the combination of an infinite number of *iid* random variables tends to some distribution,
- or that the limit when a parameter tends to some value approaches to a different distribution.

**Combination of *iid* random variables:**

- Given certain conditions, the sum (hence the average) of a sufficiently large number of iid random variables, each with finite mean and variance, will be approximately normally distributed. This is the [central limit theorem](wikipedia://en/39406) (CLT).

**Special case of distribution parametrization:**

- *X* is a **hypergeometric** (*m*, *N*, *n*) random variable. If *n* and *m* are large compared to *N*, and *p* = *m*/*N* is not close to 0 or 1, then *X* approximately has a **Binomial**(*n*, *p*) distribution.
- *X* is a **beta-binomial** random variable with parameters (*n*, *α*, *β*). Let *p* = *α*/(*α* + *β*) and suppose *α* + *β* is large, then *X* approximately has a **binomial**(*n*, *p*) distribution.
- If *X* is a **binomial** (*n*, *p*) random variable and if *n* is large and *np* is small then *X* approximately has a **Poisson**(*np*) distribution.
- If *X* is a **negative binomial** random variable with *r* large, *P* near 1, and *r*(1 − *P*) = *λ*, then *X* approximately has a **Poisson** distribution with mean *λ*.

Consequences of the CLT:

- If *X* is a **Poisson** random variable with large mean, then for integers *j* and *k*, P(*j* ≤ *X* ≤ *k*) approximately equals to *P*(*j* − 1/2 ≤ *Y* ≤ *k* + 1/2) where *Y* is a **normal** distribution with the same mean and variance as *X*.
- If *X* is a **binomial**(*n*, *p*) random variable with large *np* and *n*(1 − *p*), then for integers *j* and *k*, P(*j* ≤ *X* ≤ *k*) approximately equals to P(*j* − 1/2 ≤ *Y* ≤ *k* + 1/2) where *Y* is a **normal** random variable with the same mean and variance as *X*, i.e. *np* and *np*(1 − *p*).
- If *X* is a **beta** random variable with parameters *α* and *β* equal and large, then *X* approximately has a **normal** distribution with the same mean and variance, i. e. mean *α*/(*α* + *β*) and variance *αβ*/((*α* + *β*)<sup>2</sup>(*α* + *β* + 1)).
- If *X* is a **gamma**(*α*, *β*) random variable and the shape parameter *α* is large relative to the scale parameter *β*, then *X* approximately has a **normal** random variable with the same mean and variance.
- If *X* is a **Student's *t*** random variable with a large number of degrees of freedom *ν* then *X* approximately has a **standard normal** distribution.
- If *X* is an ***F***(*ν*, *ω*) random variable with *ω* large, then *νX* is approximately distributed as a **chi-squared** random variable with *ν* degrees of freedom.

## Compound (or Bayesian) relationships {#Compound_(or_Bayesian)_relationships}

When one or more parameter(s) of a distribution are random variables, the [compound](wikipedia://en/28897820) distribution is the [marginal distribution](wikipedia://en/506077) of the variable.

**Examples:**

- If *X* | *N* is a **binomial** (*N*,*p*) random variable, where parameter *N* is a random variable with negative-binomial (*m*, *r*) distribution, then *X* is distributed as a **negative-binomial** (*m*, *r*/(*p* + *qr*)).
- If *X* | *N* is a **binomial** (*N*,*p*) random variable, where parameter *N* is a random variable with Poisson(*μ*) distribution, then *X* is distributed as a **Poisson** (*μp*).
- If *X* | *μ* is a **Poisson**(*μ*) random variable and parameter *μ* is random variable with gamma(*m*, *θ*) distribution (where *θ* is the scale parameter), then *X* is distributed as a **negative-binomial** (*m*, *θ*/(1 + *θ*)), sometimes called [gamma-Poisson distribution](https://en.wikipedia.org/wiki/Gamma-Poisson_distribution).

Some distributions have been specially named as compounds: [beta-binomial distribution](wikipedia://en/7377730), [Beta negative binomial distribution](wikipedia://en/31118503), [gamma-normal distribution](https://en.wikipedia.org/wiki/Gamma-normal_distribution).

**Examples:**

- If *X* is a Binomial(*n*,*p*) random variable, and parameter p is a random variable with beta(*α*, *β*) distribution, then *X* is distributed as a Beta-Binomial(*α*,*β*,*n*).
- If *X* is a negative-binomial(*r*,*p*) random variable, and parameter *p* is a random variable with beta(*α*,*β*) distribution, then *X* is distributed as a [Beta negative binomial distribution](wikipedia://en/31118503)(*r*,*α*,*β*).
