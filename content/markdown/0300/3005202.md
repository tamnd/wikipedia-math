# Atomic model (mathematical logic)

::: {#o1 .subject cue=lead name="Atomic model"}

In [model theory](wikipedia://en/19858), a subfield of [mathematical logic](wikipedia://en/19636), an **atomic model** is a model such that the complete [type](wikipedia://en/3741564) of every [tuple](wikipedia://en/132729) is axiomatized by a single [formula](https://en.wikipedia.org/wiki/Formula_%28logic%29). Such types are called **principal types**, and the formulas that axiomatize them are called **complete formulas**.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let *T* be a [theory](wikipedia://en/3512103). A complete type *p*(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>) is called **principal** or **atomic** (relative to *T*) if it is axiomatized relative to *T* by a single formula *φ*(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>) ∈ *p*(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>).

A formula *φ* is called **complete** in *T* if for every formula *ψ*(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>), the theory *T* ∪ {*φ*} entails exactly one of *ψ* and ¬*ψ*.[^o4] It follows that a complete type is principal if and only if it contains a complete formula.

A model *M* is called **atomic** if every *n*-tuple of elements of *M* satisfies a formula that is complete in Th(*M*)—the theory of *M*.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [ordered field](wikipedia://en/22430) of [real](wikipedia://en/20646438) [algebraic numbers](wikipedia://en/1158) is the unique atomic model of the theory of [real closed fields](wikipedia://en/1066093).
- Any finite model is atomic.
- A dense [linear ordering](https://en.wikipedia.org/wiki/Linear_ordering) without endpoints is atomic.
- Any [prime model](wikipedia://en/1663421) of a [countable](https://en.wikipedia.org/wiki/Countable) theory is atomic by the [omitting types theorem](wikipedia://en/3741564#Omitting_types_theorem).
- Any countable atomic model is prime, but there are plenty of atomic models that are not prime, such as an uncountable dense linear order without endpoints.
- The theory of a countable number of independent unary relations is complete but has no completable formulas and no atomic models.

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The [back-and-forth method](wikipedia://en/2033586) can be used to show that any two countable atomic models of a theory that are [elementarily equivalent](https://en.wikipedia.org/wiki/Elementarily_equivalent) are [isomorphic](https://en.wikipedia.org/wiki/Isomorphic).

:::
