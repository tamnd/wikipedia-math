# Valiant–Vazirani theorem

::: {#o1 .subject cue=lead name="Valiant–Vazirani theorem"}

The **Valiant–Vazirani theorem** is a theorem in [computational complexity theory](wikipedia://en/7543) stating that if there is a [polynomial time algorithm](wikipedia://en/658550) for [Unambiguous-SAT](wikipedia://en/4715#Extensions_of_SAT), then [NP](wikipedia://en/21562) = [RP](wikipedia://en/54771). It was proven by [Leslie Valiant](https://en.wikipedia.org/wiki/Leslie_Valiant) and [Vijay Vazirani](https://en.wikipedia.org/wiki/Vijay_Vazirani) in their paper titled *NP is as easy as detecting unique solutions* published in 1986.[^o2]

:::

The Valiant–Vazirani theorem implies that the [Boolean satisfiability problem](wikipedia://en/4715), which is [NP-complete](https://en.wikipedia.org/wiki/NP-complete), remains a computationally hard problem even if the input instances are promised to have at most one satisfying assignment.

::: {#o4 .proof cue=heading name="Proof outline"}

## Proof outline {#Proof_outline}

[Unambiguous-SAT](wikipedia://en/4715#Extensions_of_SAT) is the [promise problem](wikipedia://en/1471429) of deciding whether a given Boolean formula that has at most one satisfying assignment is unsatisfiable or has exactly one satisfying assignment. In the first case, an algorithm for Unambiguous-SAT should reject, and in the second it should accept the formula. If the formula has more than one satisfying assignment, then there is no condition on the behavior of the algorithm. The promise problem Unambiguous-SAT can be decided by a [nondeterministic Turing machine](wikipedia://en/21935) that has at most one accepting computation path, thus it belongs to the promise version of the complexity class [UP](wikipedia://en/312240) (the class UP as such is only defined for languages).

The proof of the Valiant–Vazirani theorem consists of a probabilistic reduction that given a formula *F* in *n* variables, outputs a sequence of formulas *G*<sub>0</sub>,...,*G<sub>n</sub>* such that:

- Every satisfying assignment of any *G<sub>i</sub>* also satisfies *F*. Thus, if *F* is unsatisfiable, then all *G<sub>i</sub>*, *i* ≤ *n*, are unsatisfiable.
- If *F* is satisfiable, then with probability at least 1/4, some *G<sub>i</sub>* has a unique satisfying assignment.

The idea of the reduction is to successively intersect the solution space of the formula *F* with *n* random linear hyperplanes in $\mathbb F_2^n$.

As a consequence (not needed for the **NP** = **RP** argument, but of independent interest), if we choose one of the *G<sub>i</sub>* at random, we obtain a randomized reduction with one-sided error from SAT to Unambiguous-SAT that succeeds with probability at least Ω(1/*n*). That is, if *F* is unsatisfiable, the output formula is always unsatisfiable, and if *F* is satisfiable, then the output formula has a unique satisfying assignment with probability Ω(1/*n*).

Now, assuming Unambiguous-SAT is solvable by a polynomial time algorithm *A*, we obtain an **RP** algorithm for SAT by running *A* on *G<sub>i</sub>* for each *i* ≤ *n*. If *F* is unsatisfiable, then *A* rejects all *G<sub>i</sub>* as they are unsatisfiable, whereas if *F* is satisfiable, then *A* accepts some *G<sub>i</sub>* with probability at least 1/4. (We can improve the acceptance probability by repeating the reduction several times.)

More generally, this argument shows unconditionally that **NP** is included in **RP<sup>promiseUP</sup>**.

An alternative proof is based on the [isolation lemma](wikipedia://en/27295601) by Mulmuley, Vazirani, and Vazirani. They consider a more general setting, and applied to the setting here this gives an isolation probability of only $\Omega(1/n^8)$.
