# Null (mathematics)

::: {#o1 .subject cue=lead name="Null"}

In [mathematics](wikipedia://en/18831), the word **null** (from null meaning "zero", which is from nullus meaning "none") is often associated with the concept of zero, or with the concept of nothing.[^o2][^o3] It is used in varying contexts from "having [zero members in a set](wikipedia://en/9566)" (e.g., null set)[^o4] to "having a value of [zero](https://en.wikipedia.org/wiki/Zero)" (e.g., null vector).[^o5]

:::

In a [vector space](wikipedia://en/32370), the null vector is the [neutral element](https://en.wikipedia.org/wiki/Neutral_element) of vector addition; depending on the context, a null vector may also be a vector mapped to some *null* by a function under consideration (such as a [quadratic form](wikipedia://en/251478) coming with the vector space, see [null vector](wikipedia://en/1453977), a linear mapping given as [matrix product](https://en.wikipedia.org/wiki/Matrix_product) or [dot product](wikipedia://en/157093),[^o5] a [seminorm](wikipedia://en/990534) in a [Minkowski space](https://en.wikipedia.org/wiki/Minkowski_space#Causal_structure), etc.). In [set theory](wikipedia://en/27553), the [empty set](wikipedia://en/9566), that is, the set with zero elements, denoted "{}" or "∅", may also be called null set.[^o4][^o6] In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), a [null set](wikipedia://en/21520) is a (possibly nonempty) set with zero measure.

A [null space](https://en.wikipedia.org/wiki/Null_space) of a mapping is the part of the domain that is mapped into the null element of the image (the inverse image of the null element). For example, in linear algebra, the null space of a linear mapping, also known as [kernel](wikipedia://en/1072915), is the set of vectors which map to the null vector under that mapping.

In [statistics](wikipedia://en/26685), a [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) is a proposition that no effect or relationship exists between populations and phenomena. It is the hypothesis which is presumed true—unless statistical evidence indicates otherwise.[^o7]
