# Stable module category

::: {#o1 .subject cue=lead name="Stable module category"}

In mathematics, especially [representation theory](wikipedia://en/19378200), the **stable module category** is a quotient of a module [category](wikipedia://en/53759) in which projectives are "factored out."

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *R* be a [ring](wikipedia://en/48404). For two [modules](wikipedia://en/276410) *M* and *N* over *R*, define $\underline{\mathrm{Hom}}(M,N)$ to be the set of *R*-[linear maps](wikipedia://en/18102) from *M* to *N* modulo the relation that *f* ~ *g* if *f* − *g* factors through a [projective module](wikipedia://en/364488). The stable module category is defined by setting the [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) to be the *R*-modules, and the [morphisms](wikipedia://en/27716891) are the [equivalence classes](wikipedia://en/9260) $\underline{\mathrm{Hom}}(M,N)$.

Given a module *M*, let *P* be a projective module with a [surjection](https://en.wikipedia.org/wiki/Surjection) $p \colon P \to M$. Then set $\Omega(M)$ to be the [kernel](wikipedia://en/45240) of *p*. Suppose we are given a morphism $f \colon M \to N$ and a surjection $q \colon Q \to N$ where *Q* is projective. Then one can lift *f* to a map $P \to Q$ which maps $\Omega(M)$ into $\Omega(N)$. This gives a well-defined [functor](wikipedia://en/10987) $\Omega$ from the stable module category to itself.

For certain rings, such as [Frobenius algebras](wikipedia://en/1814652), $\Omega$ is an [equivalence of categories](wikipedia://en/379051). In this case, the inverse $\Omega^{-1}$ can be defined as follows. Given *M*, find an [injective module](wikipedia://en/473775) *I* with an inclusion $i \colon M \to I$. Then $\Omega^{-1}(M)$ is defined to be the [cokernel](wikipedia://en/279715) of *i*. A case of particular interest is when the ring *R* is a [group algebra](wikipedia://en/349223).

The functor Ω<sup>−1</sup> can even be defined on the [module category](https://en.wikipedia.org/wiki/Module_category) of a general ring (without factoring out projectives), as the cokernel of the [injective envelope](https://en.wikipedia.org/wiki/Injective_envelope). It need not be true in this case that the functor Ω<sup>−1</sup> is actually an inverse to Ω. One important property of the stable module category is it allows defining the Ω functor for general rings. When *R* is [perfect](wikipedia://en/22658615) (or *M* is [finitely generated](wikipedia://en/326430) and *R* is [semiperfect](https://en.wikipedia.org/wiki/Semiperfect_ring)), then Ω(*M*) can be defined as the kernel of the [projective cover](wikipedia://en/10273917), giving a functor on the module category. However, in general projective covers need not exist, and so passing to the stable module category is necessary.

:::

## Connections with cohomology {#Connections_with_cohomology}

Now we suppose that *R = kG* is a group algebra for some [field](wikipedia://en/10603) *k* and some [group](wikipedia://en/19447) *G*. One can show that there exist [isomorphisms](wikipedia://en/14828)

$$\underline{\mathrm{Hom}}(\Omega^n(M), N) \cong \mathrm{Ext}^n_{kG}(M,N) \cong \underline{\mathrm{Hom}}(M, \Omega^{-n}(N))$$

for every positive [integer](wikipedia://en/14563) *n*. The [group cohomology](wikipedia://en/248635) of a representation *M* is given by $\mathrm{H}^n(G; M) = \mathrm{Ext}^n_{kG}(k, M)$ where *k* has a trivial *G*-action, so in this way the stable module category gives a natural setting in which group cohomology lives.

Furthermore, the above isomorphism suggests defining cohomology groups for negative values of *n*, and in this way one recovers [Tate cohomology](https://en.wikipedia.org/wiki/Tate_cohomology).

## Triangulated structure {#Triangulated_structure}

An [exact sequence](wikipedia://en/138215)

$$0 \to X \to E \to Y \to 0$$

in the usual module category defines an element of $\mathrm{Ext}^1_{kG}(Y,X)$, and hence an element of $\underline{\mathrm{Hom}}(Y, \Omega^{-1}(X))$, so that we get a sequence

$$X \to E \to Y \to \Omega^{-1}(X).$$

Taking $\Omega^{-1}$ to be the translation functor and such sequences as above to be exact triangles, the stable module category becomes a [triangulated category](wikipedia://en/1679700).
