# Combinatorial map

::: {#o1 .subject cue=lead name="Combinatorial map"}

A **combinatorial map** is a [combinatorial](wikipedia://en/5170) representation of a graph on an [orientable surface](https://en.wikipedia.org/wiki/Orientable_surface). A combinatorial map may also be called a [combinatorial embedding](wikipedia://en/8149170#Combinatorial_embedding), a [rotation system](https://en.wikipedia.org/wiki/Rotation_system), an orientable [ribbon graph](wikipedia://en/56039802), a fat graph, or a cyclic graph.[^o25] More generally, an $n$-dimensional combinatorial map is a combinatorial representation of a graph on an $n$-dimensional orientable manifold.

:::

Combinatorial maps are used as efficient data structures in image representation and [processing](https://en.wikipedia.org/wiki/Image_processing), in geometrical modeling. This model is related to [simplicial complexes](wikipedia://en/252686) and to [combinatorial topology](wikipedia://en/363400). A combinatorial map is a [boundary representation](https://en.wikipedia.org/wiki/Boundary_representation) model; it represents object by its boundaries.

## History {#History}

The concept of a combinatorial map was introduced informally by [J. Edmonds](wikipedia://en/3625459) for [polyhedral surfaces](https://en.wikipedia.org/wiki/Polyhedral_surface)[^o3] which are [planar graphs](wikipedia://en/24314). It was given its first definite formal expression under the name "Constellations" by A. Jacques[^o4][^o5] but the concept was already extensively used under the name "rotation" by [Gerhard Ringel](wikipedia://en/1571968)[^o6] and J.W.T. Youngs in their famous solution of the Heawood map-coloring problem. The term "constellation" was not retained and instead "combinatorial map" was favored.[^o7]

Combinatorial maps were later generalized to represent higher-dimensional orientable subdivided objects.

## Motivation {#Motivation}

Several applications require a data structure to represent the subdivision of an object. For example, a 2D object can be decomposed into vertices (0-cells), edges (1-cells), and faces (2-cells). More generally, an n-dimensional object is composed with cells of dimension 0 to n. Moreover, it is also often necessary to represent neighboring relations between these cells.

Thus, we want to describe all the cells of the subdivision, plus all the incidence and adjacency relations between these cells. When all the represented cells are simplexes, a [simplicial complex](wikipedia://en/252686) may be used, but when we want to represent any type of cells, we need to use cellular topological models like combinatorial maps or generalized maps.

## Definition {#Definition}

A combinatorial map is a triplet $M = (D, \sigma, \alpha)$ such that:

- $D$ is a finite set of darts;
- $\sigma$ is a [permutation](wikipedia://en/44027#Permutations_in_group_theory) on $D$;
- $\alpha$ is an [involution](wikipedia://en/293450) on $D$ with no fixed point.

Intuitively, a combinatorial map corresponds to a graph where each edge is subdivided into two darts (sometimes also called half-edges). The permutation $\sigma$ gives, for each dart, the next dart by turning around the vertex in the positive orientation; the other permutation $\alpha$ gives, for each dart, the other dart of the same edge.

$\alpha$ allows one to retrieve edges (**a**lpha for **a**rête in French), and $\sigma$ allows one to retrieve vertices (**s**igma for **s**ommet in French). We define $\varphi = \sigma \circ \alpha$ which gives, for each dart, the next dart of the same face (**p**hi for **f**ace also in French).

So, there are two ways to represent a combinatorial map depending if the permutation is $\sigma$ or $\varphi$ (see example below). These two representations are dual to each other: vertices and faces are exchanged.

## Higher-dimensional generalization {#Higher-dimensional_generalization}

An *n*-dimensional combinatorial map (or *n*-map) is a (*n* + 1)-tuple $M = (D, \beta_{1}, ..., \beta_{n})$ such that:[^o12][^o13]

- $D$ is a finite set of darts;
- $\beta_{1}$ is a [permutation](wikipedia://en/44027#Permutations_in_group_theory) on $D$;
- $\beta_{2}, ..., \beta_{n}$ are [involutions](wikipedia://en/293450) on $D$;
- $\beta_{i} \circ \beta_{j}$ is an involution if $i + 2 \le j (i, j \in \{ 1, ,..., n \})$.

An *n*-dimensional combinatorial map represents the subdivision of a closed orientable *n*-dimensional space. The constraint on $\beta_{i} \circ \beta_{j}$ guarantees the topological validity of the map as a quasi-manifold subdivision. Two-dimensional combinatorial maps can be retrieved by fixing $n = 2$ and renaming $\sigma$ by $\beta_{1}$ and $\alpha$ by $\beta_{2}$.

Spaces that are not necessarily closed or [orientable](https://en.wikipedia.org/wiki/Orientable) may be represented using (*n*-dimensional) [generalized maps](https://en.wikipedia.org/wiki/Generalized_maps).

## Rotation systems {#Rotation_systems}

In [combinatorial](wikipedia://en/5170) [mathematics](wikipedia://en/18831), **rotation systems** (also called **combinatorial embeddings** or [combinatorial maps](https://en.wikipedia.org/wiki/Combinatorial_maps)) encode [embeddings of graphs](wikipedia://en/8149170) onto [orientable](wikipedia://en/187446) [surfaces](wikipedia://en/27865) by describing the [circular ordering](https://en.wikipedia.org/wiki/Circular_ordering) of a [graph](wikipedia://en/325806)'s edges around each vertex. A more formal definition of a rotation system involves pairs of [permutations](wikipedia://en/44027); such a pair is sufficient to determine a [multigraph](wikipedia://en/1774970), a surface, and a [2-cell embedding](wikipedia://en/8149170) of the multigraph onto the surface.

Every rotation scheme defines a unique 2-cell embedding of a [connected](wikipedia://en/1614492) multigraph on a closed oriented surface (up to orientation-preserving topological equivalence). Conversely, any embedding of a connected multigraph *G* on an oriented closed surface defines a unique rotation system having *G* as its underlying multigraph. This fundamental equivalence between rotation systems and 2-cell-embeddings was first settled in a dual form by Lothar Heffter in the 1890s[^o16] and extensively used by [Ringel](wikipedia://en/1571968) during the 1950s.[^o17] Independently, [Edmonds](wikipedia://en/3625459) gave the primal form of the theorem[^o18] and the details of his study have been popularized by Youngs.[^o19] The generalization to multigraphs was presented by Gross and Alpert.[^o20]

Rotation systems are related to, but not the same as, the *[rotation maps](https://en.wikipedia.org/wiki/Rotation_map)* used by Reingold et al. (2002) to define the [zig-zag product](wikipedia://en/24387478) of graphs. A rotation system specifies a circular ordering of the edges around each vertex, while a rotation map specifies a (non-circular) permutation of the edges at each vertex. In addition, rotation systems can be defined for any graph, while as Reingold et al. define them rotation maps are restricted to [regular graphs](wikipedia://en/85821).

### Characterizing the surface of the embedding {#Characterizing_the_surface_of_the_embedding}

According to the [Euler formula](wikipedia://en/148420) we can deduce the [genus](wikipedia://en/61891) *g* of the closed orientable surface defined by the rotation system $(\sigma,\theta)$ (that is, the surface on which the underlying multigraph is 2-cell embedded).[^o22] Notice that $V=|Z(\sigma)|$, $E=|Z(\theta)|$ and $F=|Z(\sigma\theta)|$. We find that

$$g=1-\frac{1}{2}(V-E+F)=1-\frac{1}{2}(|Z(\sigma)|-|Z(\theta)|+|Z(\sigma\theta)|)$$

where $Z(\phi)$ denotes the set of the orbits of permutation $\phi$.
