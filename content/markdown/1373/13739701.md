# Panjer recursion

::: {#o1 .subject cue=lead name="Panjer recursion"}

The **Panjer recursion** is an [algorithm](wikipedia://en/775) to compute the [probability distribution](wikipedia://en/23543) approximation of a compound [random variable](wikipedia://en/25685) $S = \sum_{i=1}^N X_i\,$ where both $N\,$ and $X_i\,$ are [random variables](wikipedia://en/25685) and of special types. In more general cases the distribution of *S* is a [compound distribution](https://en.wikipedia.org/wiki/Compound_distribution). The recursion for the special cases considered was introduced in a paper [^o2] by [Harry Panjer](https://en.wikipedia.org/wiki/Harry_Panjer) (Distinguished Emeritus Professor, [University of Waterloo](https://en.wikipedia.org/wiki/University_of_Waterloo)[^o3]). It is heavily used in [actuarial science](wikipedia://en/189373) (see also [systemic risk](https://en.wikipedia.org/wiki/Systemic_risk)).

:::

## Preliminaries {#Preliminaries}

We are interested in the compound random variable $S = \sum_{i=1}^N X_i\,$ where $N\,$ and $X_i\,$ fulfill the following preconditions.

### Claim size distribution {#Claim_size_distribution}

We assume the $X_i\,$ to be [i.i.d.](https://en.wikipedia.org/wiki/I.i.d.) and independent of $N\,$. Furthermore the $X_i\,$ have to be distributed on a lattice $h \mathbb{N}_0\,$ with latticewidth $h>0\,$.

$$f_k = P[X_i = hk].\,$$

In actuarial practice, $X_i\,$ is obtained by discretisation of the claim density function (upper, lower...).

::: {#o7 .pointer-item cue=pointer name="Panjer class"}

### Claim number distribution {#Claim_number_distribution}

The number of claims *N* is a [random variable](wikipedia://en/25685), which is said to have a "claim number distribution", and which can take values 0, 1, 2, .... etc.. For the "Panjer recursion", the [probability distribution](wikipedia://en/23543) of *N* has to be a member of the **Panjer class**, otherwise known as the [(a,b,0) class of distributions](wikipedia://en/14204502). This class consists of all counting random variables which fulfill the following relation:

$$P[N=k] = p_k= \left(a + \frac{b}{k} \right) \cdot p_{k-1},~~k \ge 1.\,$$

for some $a$ and $b$ which fulfill $a+b \ge 0\,$. The initial value $p_0\,$ is determined such that $\sum_{k=0}^\infty p_k = 1.\,$

The Panjer recursion makes use of this iterative relationship to specify a recursive way of constructing the probability distribution of *S*. In the following $W_N(x)\,$ denotes the [probability generating function](wikipedia://en/236841) of *N*: for this see the table in [(a,b,0) class of distributions](wikipedia://en/14204502).

In the case of claim number is known, please note the *De Pril* algorithm.[^o8] This algorithm is suitable to compute the sum distribution of $n$ discrete [random variables](https://en.wikipedia.org/wiki/Random_variables).[^o9]

:::

## Recursion {#Recursion}

The algorithm now gives a recursion to compute the $g_k =P[S = hk] \,$.

The starting value is $g_0 = W_N(f_0)\,$ with the special cases

$$g_0=p_0\cdot \exp(f_0 b) \quad \text{ if } \quad a = 0,\,$$

and

$$g_0=\frac{p_0}{(1-f_0a)^{1+b/a}} \quad \text{ for } \quad a \ne 0,\,$$

and proceed with

$$g_k=\frac{1}{1-f_0a}\sum_{j=1}^k \left( a+\frac{b\cdot j}{k} \right) \cdot f_j \cdot g_{k-j}.\,$$
