# Five-number summary

::: {#o1 .subject cue=lead name="Five-number summary"}

The **five-number summary** is a set of [descriptive statistics](wikipedia://en/8187) that provides information about a dataset. It consists of the five most important sample [percentiles](wikipedia://en/354907):

:::

1. the [sample minimum](https://en.wikipedia.org/wiki/Sample_minimum) *(smallest observation)*
1. the [lower quartile](wikipedia://en/25170) or *first quartile*
1. the [median](wikipedia://en/18837) (the middle value)
1. the [upper quartile](wikipedia://en/25170) or *third quartile*
1. the [sample maximum](https://en.wikipedia.org/wiki/Sample_maximum) (largest observation)

In addition to the median of a single set of data there are two related statistics called the upper and lower quartiles. If data are placed in order, then the lower quartile is central to the lower half of the data and the upper quartile is central to the upper half of the data. These quartiles are used to calculate the interquartile range, which helps to describe the spread of the data, and determine whether or not any data points are outliers.

In order for these statistics to exist, the observations must be from a [univariate](wikipedia://en/2398982) variable that can be measured on an ordinal, interval or ratio [scale](wikipedia://en/821148).

## Use and representation {#Use_and_representation}

The five-number summary provides a concise summary of the [distribution](wikipedia://en/23543) of the observations. Reporting five numbers avoids the need to decide on the most appropriate summary statistic. The five-number summary gives information about the location (from the median), spread (from the quartiles) and range (from the sample minimum and maximum) of the observations. Since it reports [order statistics](wikipedia://en/160986) (rather than, say, the mean) the five-number summary is appropriate for [ordinal measurements](wikipedia://en/821148#Ordinal_scale), as well as interval and ratio measurements.

It is possible to quickly compare several sets of observations by comparing their five-number summaries, which can be represented graphically using a [boxplot](https://en.wikipedia.org/wiki/Boxplot).

In addition to the points themselves, many [L-estimators](wikipedia://en/17398955) can be computed from the five-number summary, including [interquartile range](wikipedia://en/14812), [midhinge](wikipedia://en/12559595), [range](wikipedia://en/27588), [mid-range](wikipedia://en/2814021), and [trimean](wikipedia://en/9888821).

The five-number summary is sometimes represented as in the following table:

::: {#o3 .table cue=table}

| median |  |
|---|---|
| 1st quartile | 3rd quartile |
| Minimum | Maximum |

:::

## Example {#Example}

This example calculates the five-number summary for the following set of observations: 0, 0, 1, 2, 63, 61, 27, 13. These are the number of known moons of each planet in the [Solar System](https://en.wikipedia.org/wiki/Solar_System) January 2010.

It helps to put the observations in ascending order: 0, 0, 1, 2, 13, 27, 61, 63. There are eight observations, so the median is the mean of the two middle numbers, (2 + 13)/2 = 7.5. Splitting the observations either side of the median gives two groups of four observations. The median of the first group is the lower or first quartile, and is equal to (0 + 1)/2 = 0.5. The median of the second group is the upper or third quartile, and is equal to (27 + 61)/2 = 44. The smallest and largest observations are 0 and 63.

So the five-number summary would be 0, 0.5, 7.5, 44, 63.

### Example in R {#Example_in_R}

It is possible to calculate the five-number summary in the [R programming language](https://en.wikipedia.org/wiki/R_programming_language) using the `fivenum` function. The `summary` function, when applied to a vector, displays the five-number summary together with the mean (which is not itself a part of the five-number summary). The `fivenum` uses a different method to calculate percentiles than the `summary` function.

\> moons \<- c(0, 0, 1, 2, 63, 61, 27, 13) > fivenum(moons) \[1\] 0.0 0.5 7.5 44.0 63.0 > summary(moons) Min. 1st Qu. Median Mean 3rd Qu. Max. 0.00 0.75 7.50 20.88 35.50 63.00

### Example in Python {#Example_in_Python}

This python example uses the `percentile` function from the numerical library `numpy` and works in Python 2 and 3.

```numpy
import numpy as np

def fivenum(data):
    """Five-number summary."""
    return np.percentile(data, [0, 25, 50, 75, 100], method="midpoint")
```

```pycon
>>> moons = [0, 0, 1, 2, 63, 61, 27, 13]
>>> print(fivenum(moons))
[  0.    0.5   7.5  44.   63. ]
```

### Example in SAS {#Example_in_SAS}

You can use `PROC UNIVARIATE` in [SAS](wikipedia://en/990677) to get the five number summary:

```sas
data fivenum;
input x @@;
datalines;
1 2 3 4 20 202 392 4 38 20
;
run;

ods select Quantiles;
proc univariate data = fivenum;
 output out = fivenums min = min Q1 = Q1 Q2 = median Q3 = Q3 max = max;
run;

proc print data = fivenums;
run;
```
