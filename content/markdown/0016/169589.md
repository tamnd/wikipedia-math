::: {#o6 .entry cue=list-entry name="Continuous probability distribution"}

- [Continuous probability distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution): Sometimes this term is used to mean a probability distribution whose [cumulative distribution function](wikipedia://en/5793) (c.d.f.) is (simply) continuous. Sometimes it has a less inclusive meaning: a distribution whose c.d.f. is [absolutely continuous](wikipedia://en/252670) with respect to [Lebesgue measure](wikipedia://en/18198). This less inclusive sense is equivalent to the condition that every set whose Lebesgue measure is 0 has probability 0.

## Continuum {#Continuum}

::: {#o11 .entry cue=list-entry name="Continuum (set theory)"}

- [Continuum (set theory)](wikipedia://en/24758677), the [real line](https://en.wikipedia.org/wiki/Real_line) or the corresponding cardinal number

:::

::: {#o12 .entry cue=list-entry name="Linear continuum"}

- [Linear continuum](wikipedia://en/17368856), any ordered set that shares certain properties of the real line

:::

::: {#o13 .entry cue=list-entry name="Continuum (topology)"}

- [Continuum (topology)](wikipedia://en/24758520), a nonempty compact connected [metric space](wikipedia://en/20018) (sometimes a [Hausdorff space](wikipedia://en/13637))

:::

::: {#o14 .entry cue=list-entry name="Continuum hypothesis"}

- [Continuum hypothesis](wikipedia://en/5705), a conjecture of Georg Cantor that there is no cardinal number between that of countably infinite sets and the cardinality of the set of all real numbers. The latter cardinality is equal to the cardinality of the set of all subsets of a countably infinite set.

:::

::: {#o15 .entry cue=list-entry name="Cardinality of the continuum"}

- [Cardinality of the continuum](wikipedia://en/1574901), a cardinal number that represents the size of the set of real numbers

:::
