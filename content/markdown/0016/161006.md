# Unary operation

::: {#o1 .subject cue=lead name="Unary operation"}

In [mathematics](wikipedia://en/18831), a **unary operation** is an [operation](wikipedia://en/4140245) with only one [operand](wikipedia://en/22656), i.e. a single input.[^o2] This is in contrast to *[binary operations](wikipedia://en/3948)*, which use two operands.[^o3] An example is any [function](wikipedia://en/185427) $f : A \rightarrow A$, where $A$ is a [set](wikipedia://en/26691); the function $f$ is a unary operation on $A$.

:::

Common notations are [prefix notation](https://en.wikipedia.org/wiki/Prefix_notation) (e.g. [negation](wikipedia://en/161019) $\neg$, [additive inverse](wikipedia://en/228312) $-$), [postfix notation](https://en.wikipedia.org/wiki/Postfix_notation) (e.g. [factorial](wikipedia://en/10606) $n!$), functional notation (e.g. $\sin\,x$ or $\sin(x)$), and [superscripts](https://en.wikipedia.org/wiki/Superscript) (e.g. [transpose](wikipedia://en/173844) $A^{T}$). Other notations exist as well, for example, in the case of the [square root](wikipedia://en/29208), a [horizontal bar](wikipedia://en/673457) extending the square root sign over the argument can indicate the extent of the argument.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

### Absolute value {#Absolute_value}

Obtaining the [absolute value](wikipedia://en/991) of a number is a unary operation. This function is defined as $|n| = \begin{cases} n, & \mbox{if } n\geq0 \\ -n, & \mbox{if } n<0 \end{cases}$ where $|n|$ is the absolute value of $n$.

### Negation {#Negation}

[Negation](https://en.wikipedia.org/wiki/Negation_%28arithmetic%29) is used to find the negative value of a single number. Here are some examples:

$$-(3) = -3$$

$$-( -3) = 3$$

### Factorial {#Factorial}

For any positive integer *n*, the product of the integers less than or equal to *n* is a unary operation called [factorial](wikipedia://en/10606). In the context of [complex numbers](wikipedia://en/5826), the [gamma function](wikipedia://en/12316) is a unary operation extension of factorial.

### Trigonometry {#Trigonometry}

In [trigonometry](wikipedia://en/18717261), the [trigonometric functions](wikipedia://en/30367), such as $\sin$, $\cos$, and $\tan$, can be seen as unary operations. This is because it is possible to provide only one term as input for these functions and retrieve a result. By contrast, binary operations, such as [addition](wikipedia://en/61338), require two different terms to compute a result.

### Examples from programming languages {#Examples_from_programming_languages}

Below is a table summarizing common unary operators along with their symbols, description, and examples:[^o11]

::: {#o12 .table cue=table}

| Operator | Symbol | Description | Example |
|---|---|---|---|
| Increment | `++` | Increases the value of a variable by 1 | `x = 2; ++x; // x is now 3` |
| Decrement | `--` | Decreases the value of a variable by 1 | `y = 10; --y; // y is now 9` |
| Unary Plus | `+` | Indicates a positive value | `a = -5; b = +a; // b is -5` |
| Unary Minus | `-` | Indicates a negative value | `c = 4; d = -c; // d is -4` |
| [Logical NOT](https://en.wikipedia.org/wiki/Logical_NOT) | `!` | Negates the truth value of a Boolean expression | `flag = true; result = !flag; // result is false` |
| [Bitwise NOT](https://en.wikipedia.org/wiki/Bitwise) | `~` | Bitwise negation, flips the bits of an integer | `num = 5; result = ~num; // result is -6` |

:::

#### JavaScript {#JavaScript}

In [JavaScript](https://en.wikipedia.org/wiki/JavaScript), these operators are unary:[^o16]

- [Increment](https://en.wikipedia.org/wiki/Increment_and_decrement_operators): `++<span style="color:gray;">x</span>`, `<span style="color:gray;">x</span>++`
- [Decrement](https://en.wikipedia.org/wiki/Increment_and_decrement_operators): `--<span style="color:gray;">x</span>`, `<span style="color:gray;">x</span>--`
- Positive: `+<span style="color:gray;">x</span>`
- Negative: `-<span style="color:gray;">x</span>`
- [Ones' complement](wikipedia://en/30670886): `~<span style="color:gray;">x</span>`
- [Logical negation](wikipedia://en/161019): `!<span style="color:gray;">x</span>`

#### Python {#Python}

In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), there are no [increment or decrement operators](https://en.wikipedia.org/wiki/Increment_and_decrement_operators), but the following unary operators are available:[^o11]

- Positive: `+<span style="color:gray;">x</span>`
- Negative: `-<span style="color:gray;">x</span>`
- [Ones' complement](wikipedia://en/30670886): `~<span style="color:gray;">x</span>`
- [Logical negation](wikipedia://en/161019): `not <span style="color:gray;">x</span>`

#### C family of languages {#C_family_of_languages}

In the [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) family of languages, the following operators are unary:[^o19][^o20]

- [Increment](https://en.wikipedia.org/wiki/Increment_and_decrement_operators): `++<span style="color:gray;">x</span>`, `<span style="color:gray;">x</span>++`
- [Decrement](https://en.wikipedia.org/wiki/Increment_and_decrement_operators): `--<span style="color:gray;">x</span>`, `<span style="color:gray;">x</span>--`
- [Address](https://en.wikipedia.org/wiki/Reference_%28computer_science%29): `&<span style="color:gray;">x</span>`
- [Indirection](https://en.wikipedia.org/wiki/Indirection): `*<span style="color:gray;">x</span>`
- Positive: `+<span style="color:gray;">x</span>`
- Negative: `-<span style="color:gray;">x</span>`
- [Ones' complement](wikipedia://en/30670886): `~<span style="color:gray;">x</span>`
- [Logical negation](wikipedia://en/161019): `!<span style="color:gray;">x</span>`
- [Sizeof](https://en.wikipedia.org/wiki/Sizeof): `sizeof <span style="color:gray;">x</span>, sizeof(<span style="color:gray;">type-name</span>)`
- [Cast](https://en.wikipedia.org/wiki/Type_conversion): `(''type-name'') ''<span style="color:gray;">cast-expression</span>''`

#### Unix shell (Bash) {#Unix_shell_(Bash)}

In the [Unix shell](https://en.wikipedia.org/wiki/Unix_shell) ([Bash](https://en.wikipedia.org/wiki/Bash_%28Unix_shell%29)/[Bourne Shell](https://en.wikipedia.org/wiki/Bourne_shell)), e.g., the following operators are unary:[^o22][^o23]

- Pre and Post-Increment: `++<span style="color:gray;">$x</span>`, `<span style="color:gray;">$x</span>++`
- Pre and Post-Decrement: `--<span style="color:gray;">$x</span>`, `<span style="color:gray;">$x</span>--`
- Positive: `+<span style="color:gray;">$x</span>`
- Negative: `-<span style="color:gray;">$x</span>`
- Logical negation: `!<span style="color:gray;">$x</span>`
- Simple expansion: `$<span style="color:gray;">x</span>`
- Complex expansion: `${#<span style="color:gray;">x</span>}`

#### PowerShell {#PowerShell}

In the [PowerShell](https://en.wikipedia.org/wiki/PowerShell), the following operators are unary:[^o25]

- Increment: `++<span style="color:gray;">$x</span>`, `<span style="color:gray;">$x</span>++`
- Decrement: `--<span style="color:gray;">$x</span>`, `<span style="color:gray;">$x</span>--`
- Positive: `+<span style="color:gray;">$x</span>`
- Negative: `-<span style="color:gray;">$x</span>`
- Logical negation: `!<span style="color:gray;">$x</span>`
- [Invoke](https://en.wikipedia.org/wiki/Execution_%28computing%29) in current [scope](https://en.wikipedia.org/wiki/Scope_%28programming%29): `.<span style="color:gray;">$x</span>`
- Invoke in new scope: `&<span style="color:gray;">$x</span>`
- Cast: `[''type-name''] ''<span style="color:gray;">cast-expression</span>''`
- Cast: `+<span style="color:gray;">$x</span>`
- Array: `,<span style="color:gray;">$array</span>`
