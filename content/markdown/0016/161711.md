# Truth value

::: {#o1 .subject cue=lead name="Truth value"}

In [logic](wikipedia://en/46426065) and [mathematics](wikipedia://en/18831), a **truth value**, sometimes called a **logical value**, is a value indicating the relation of a [proposition](wikipedia://en/81094) to [truth](wikipedia://en/29920), which in [classical logic](wikipedia://en/55868) has only two possible values (*[true](wikipedia://en/3986852)* or *[false](wikipedia://en/229823)*).[^o2][^o3] Truth values are used in [computing](https://en.wikipedia.org/wiki/Computing) as well as various types of [logic](wikipedia://en/46426065).

:::

::: {#o5 .pointer-item cue=pointer name="Falsy"}

## Computing {#Computing}

In some programming languages, any [expression](https://en.wikipedia.org/wiki/Expression_%28computer_science%29) can be evaluated in a context that expects a [Boolean data type](https://en.wikipedia.org/wiki/Boolean_data_type). Typically (though this varies by programming language) expressions like the number [zero](https://en.wikipedia.org/wiki/Zero), the [empty string](wikipedia://en/835827), empty lists, and [null](https://en.wikipedia.org/wiki/Null_pointer) are treated as false, and strings with content (like "abc"), other numbers, and objects evaluate to true. Sometimes these classes of expressions are called **falsy** and **truthy**. For example, in [Lisp](https://en.wikipedia.org/wiki/Lisp_%28programming_language%29), [nil](https://en.wikipedia.org/wiki/Null_pointer), the empty list, is treated as false, and all other values are treated as true. In [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), the number 0 or 0.0 is false, and all other values are treated as true.

In [JavaScript](https://en.wikipedia.org/wiki/JavaScript), the empty string (`""`), `null`, `undefined`, [`NaN`](https://en.wikipedia.org/wiki/NaN), `+0`, `[[−0]]` and `false`[^o6] are sometimes called *falsy* (of which the [complement](wikipedia://en/54347) is *truthy*) to distinguish between strictly [type-checked](wikipedia://en/602650) and [coerced](https://en.wikipedia.org/wiki/Type_conversion) Booleans (see also: [JavaScript syntax#Type conversion](https://en.wikipedia.org/wiki/JavaScript_syntax#Type_conversion)).[^o7] As opposed to Python, empty containers (arrays, maps, sets) are considered truthy. Languages such as [PHP](https://en.wikipedia.org/wiki/PHP) also use this approach.

:::

## Classical logic {#Classical_logic}

|  | ⊤ |  | ·**∧**· |
|---|---|---|---|
|  | true |  | [conjunction](wikipedia://en/18152) |
| ¬ | ↕ |  | ↕ |
|  | ⊥ |  | ·**∨**· |
|  | false |  | [disjunction](wikipedia://en/7962) |
| Negation interchanges true with false and conjunction with disjunction. |  |  |  |

In [classical logic](wikipedia://en/55868), with its intended semantics, the truth values are *[true](wikipedia://en/3986852)* (denoted by $1$ or the [verum](https://en.wikipedia.org/wiki/Verum) $\top$), and *[untrue](wikipedia://en/229823)* or *[false](wikipedia://en/229823)* (denoted by $0$ or the [falsum](https://en.wikipedia.org/wiki/Falsum) $\perp$); that is, classical logic is a [two-valued logic](https://en.wikipedia.org/wiki/Two-valued_logic). This set of two values is also called the [Boolean domain](wikipedia://en/3954077). Corresponding semantics of [logical connectives](wikipedia://en/18153) are [truth functions](wikipedia://en/604707), whose values are expressed in the form of [truth tables](wikipedia://en/25512250). [Logical biconditional](wikipedia://en/228783) becomes the [equality](wikipedia://en/90446) binary relation, and [negation](wikipedia://en/161019) becomes a [bijection](wikipedia://en/3942) which [permutes](wikipedia://en/44027) true and false. Conjunction and disjunction are [dual](https://en.wikipedia.org/wiki/Dual_%28mathematics%29#Duality_in_logic_and_set_theory) with respect to negation, which is expressed by [De Morgan's laws](wikipedia://en/64669):

$$\neg(p \land q) \Leftrightarrow \neg p\,\lor\,\neg q$$

$$\neg(p \lor q) \Leftrightarrow \neg p\,\land\,\neg q$$

[Propositional variables](wikipedia://en/1557562) become [variables](https://en.wikipedia.org/wiki/Variable_%28computer_science%29) in the Boolean domain. Assigning values for propositional variables is referred to as [valuation](wikipedia://en/17456938).

|---|---|---|
| \1. | true | true |
| \2. | true | false |
| \3. | false | true |

## Intuitionistic and constructive logic {#Intuitionistic_and_constructive_logic}

Whereas in classical logic truth values form a [Boolean algebra](wikipedia://en/54476844), in [intuitionistic logic](wikipedia://en/169262), and more generally, [constructive mathematics](https://en.wikipedia.org/wiki/Constructivism_%28mathematics%29), the truth values form a [Heyting algebra](wikipedia://en/309343). Such truth values may express various aspects of validity, including locality, temporality, or computational content.

For example, one may use the [open sets](wikipedia://en/39358) of a topological space as intuitionistic truth values, in which case the truth value of a formula expresses *where* the formula holds, not whether it holds.

In [realizability](wikipedia://en/11009758) truth values are sets of programs, which can be understood as computational evidence of validity of a formula. For example, the truth value of the statement "for every number there is a prime larger than it" is the set of all programs that take as input a number $n$, and output a prime larger than $n$.

In [category theory](wikipedia://en/5869), truth values appear as the elements of the [subobject classifier](wikipedia://en/366909). In particular, in an [elementary topos](wikipedia://en/815802) every formula of [higher-order logic](wikipedia://en/562883) may be assigned a truth value in the subobject classifier.

Even though a Heyting algebra may have many elements, this should not be understood as there being truth values that are neither true nor false, because intuitionistic logic proves $\neg(p \ne \top \land p \ne \neg\perp)$ ("it is not the case that $p$ is neither true nor false").[^o12]

In [intuitionistic type theory](wikipedia://en/345023), the [Curry–Howard correspondence](wikipedia://en/40282#Curry–Howard_correspondence) exhibits an equivalence of propositions and types, according to which validity is equivalent to inhabitation of a type.

For other notions of intuitionistic truth values, see *[Brouwer–Heyting–Kolmogorov interpretation](wikipedia://en/1925846)* and *Intuitionistic logic*.

## Multi-valued logic {#Multi-valued_logic}

[Multi-valued logics](https://en.wikipedia.org/wiki/Multi-valued_logic) (such as [fuzzy logic](wikipedia://en/49180) and [relevance logic](wikipedia://en/185076)) allow for more than two truth values, possibly containing some internal structure. For example, on the [unit interval](wikipedia://en/49324) 0, 1 such structure is a [total order](wikipedia://en/30330); this may be expressed as the existence of various [degrees of truth](https://en.wikipedia.org/wiki/Degrees_of_truth).

## Algebraic semantics {#Algebraic_semantics}

Not all [logical systems](https://en.wikipedia.org/wiki/Logical_system) are truth-valuational in the sense that logical connectives may be interpreted as truth functions. For example, [intuitionistic logic](wikipedia://en/169262) lacks a complete set of truth values because its semantics, the [Brouwer–Heyting–Kolmogorov interpretation](wikipedia://en/1925846), is specified in terms of [provability](wikipedia://en/183478) conditions, and not directly in terms of the [necessary truth](https://en.wikipedia.org/wiki/Necessarily_true) of formulae.

But even non-truth-valuational logics can associate values with logical formulae, as is done in [algebraic semantics](wikipedia://en/2848519). The algebraic semantics of intuitionistic logic is given in terms of [Heyting algebras](wikipedia://en/309343), compared to [Boolean algebra](wikipedia://en/3959) semantics of classical propositional calculus.
