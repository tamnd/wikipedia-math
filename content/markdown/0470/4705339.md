# Information dimension

::: {#o1 .subject cue=lead name="Information dimension"}

In [information theory](wikipedia://en/14773), **information dimension** is an information measure for random [vectors](wikipedia://en/32533) in [Euclidean space](wikipedia://en/9697), based on the normalized [entropy](wikipedia://en/15445) of finely quantized versions of the [random vectors](https://en.wikipedia.org/wiki/Random_vector). This concept was first introduced by [Alfréd Rényi](wikipedia://en/614988) in 1959.[^o2]

:::

Simply speaking, it is a measure of the [fractal dimension](wikipedia://en/285907) of a [probability distribution](wikipedia://en/23543). It characterizes the growth rate of the [Shannon entropy](https://en.wikipedia.org/wiki/Shannon_entropy) given by successively finer discretizations of the space.

In 2010, Wu and Verdú gave an operational characterization of [Rényi information dimension](https://en.wikipedia.org/wiki/Rényi_information) as the fundamental limit of almost [lossless data compression](https://en.wikipedia.org/wiki/Lossless_data_compression) for analog sources under various regularity constraints of the encoder/decoder.

::: {#o4 .definition cue=heading name="Definition and Properties"}

## Definition and Properties {#Definition_and_Properties}

The entropy of a [discrete random variable](https://en.wikipedia.org/wiki/Discrete_random_variable) $Z$ is

$$\mathbb{H}_0(Z)=\sum_{z \in supp(P_Z)}P_Z(z)\log_2\frac{1}{P_Z(z)}$$

where $P_Z(z)$ is the [probability measure](wikipedia://en/45437) of $Z$ when $Z=z$, and the $supp(P_Z)$ denotes a set $\{z|z \in\mathcal{Z},P_Z(z)>0\}$.

Let $X$ be an arbitrary real-valued random variable. Given a [positive integer](https://en.wikipedia.org/wiki/Positive_integer) $m$, we create a new discrete random variable

$$\langle X\rangle_m=\frac{\lfloor mX\rfloor}{m}$$

where the $\lfloor \cdot \rfloor$ is the floor operator which converts a [real number](wikipedia://en/20646438) to the greatest integer less than it. Then

$$\underline{d}(X)=\liminf_{m \rightarrow \infty}\frac{\mathbb{H}_0(\langle X \rangle_m)}{\log_2m}$$

and

$$\bar{d}(X)=\limsup_{m \rightarrow \infty}\frac{\mathbb{H}_0(\langle X \rangle_m)}{\log_2m}$$

are called lower and upper information dimensions of $X$ respectively. When $\underline{d}(X)=\bar{d}(X)$, we call this value information dimension of $X$,

$$d(X)=\lim_{m \rightarrow \infty}\frac{\mathbb{H}_0(\langle X \rangle_m)}{\log_2m}$$

Some important properties of information dimension $d(X)$:

- If the mild condition $\mathbb{H}(\lfloor X\rfloor)<\infty$ is fulfilled, we have $0\leq\underline{d}(X)\leq\bar{d}(X)\leq1$.
- For an $n$-dimensional random vector $\vec{X}$, the first property can be generalized to $0\leq\underline{d}(\vec{X})\leq \bar{d}(\vec{X})\leq n$.
- It is sufficient to calculate the upper and lower information dimensions when restricting to the [exponential](wikipedia://en/9678) subsequence $m=2^l$.
- $\underline{d}(X)$ and $\bar{d}(X)$ are kept unchanged if rounding or ceiling functions are used in quantization.

:::

## *d*-Dimensional Entropy {#d-Dimensional_Entropy}

If the information dimension $d$ exists, one can define the $d$-dimensional entropy of this distribution by

$$\mathbb{H}_{d(X)}(X)=\lim_{n \rightarrow + \infty}(\mathbb{H}_0(\langle X \rangle_n)-d(X)\log_2n)$$

provided the limit exists. If $d=0$, the zero-dimensional entropy equals the standard [Shannon entropy](https://en.wikipedia.org/wiki/Shannon_entropy) $\mathbb{H}_0(X)$. For integer dimension $d=n\ge 1$, the $n$-dimensional entropy is the $n$-fold integral defining the respective [differential entropy](wikipedia://en/3504168).

::: {#o7 .definition cue=heading name="An equivalent definition of Information Dimension"}

## An equivalent definition of Information Dimension {#An_equivalent_definition_of_Information_Dimension}

In 1994, Kawabata and Dembo in (Kawabata Dembo 1994) proposed a new way of measuring information based on [rate distortion](https://en.wikipedia.org/wiki/Rate_distortion) value of a random variable. The measure is defined as

$$d_R(X)=-2\frac{R(X, D)}{\log D},$$

where $R(X, D)$ is the rate-distortion function that is defined as

$$R(X, D) = \min_{\|X-\hat{X}\|_2\leq D} I(X, \hat{X}),$$

or equivalently, minimum information that could lead to a $D$-close approximation of $X$.

They further, proved that such definition is equivalent to the definition of information dimension. Formally,

$$d_R(X) = d(X).$$

:::

## Dimensional-Rate Bias {#Dimensional-Rate_Bias}

Using the above definition of Rényi information dimension, a similar measure to *d*-dimensional entropy is defined in (Charusaie Amini Rini 2022) . This value $b(X)$ that is named dimensional-rate bias is defined in a way to capture the finite term of rate-distortion function. Formally,

$$R(X, D)=-\frac{d(X)}{2}\log \frac{2\pi e D}{d(X)}+b(X).$$

The dimensional-rate bias is equal to *d*-dimensional rate for [continuous](https://en.wikipedia.org/wiki/Continuous_probability_distribution), [discrete](https://en.wikipedia.org/wiki/Discrete_probability_distribution), and discrete-continuous mixed distribution. Furthermore, it is calculable for a set of [singular random variables](wikipedia://en/4304500), while *d*-dimensional entropy does not necessarily exist there.

Finally, dimensional-rate bias generalizes the [Shannon's entropy](https://en.wikipedia.org/wiki/Shannon's_entropy) and [differential entropy](wikipedia://en/3504168), as one could find the mutual information $I(X; Y)$ using the following formula:

$$I(X;Y) = b(X)+b(Y)-b(X, Y).$$

## Discrete-Continuous Mixture Distributions {#Discrete-Continuous_Mixture_Distributions}

According to [Lebesgue decomposition theorem](wikipedia://en/4316238),[^o12] a [probability distribution](wikipedia://en/23543) can be uniquely represented by the mixture

> $$v=pP_{Xd}+qP_{Xc}+rP_{Xs}$$

where $p+q+r=1$ and $p,q,r\geq0$; $P_{Xd}$ is a purely atomic probability measure (discrete part), $P_{Xc}$ is the absolutely continuous probability measure, and $P_{Xs}$ is a probability measure singular with respect to [Lebesgue measure](wikipedia://en/18198) but with no atoms (singular part).

Let $X$ be a [random variable](wikipedia://en/25685) such that $\mathbb{H}(\lfloor X \rfloor) < \infty$. Assume the distribution of $X$ can be represented as

> $$v=(1-\rho)P_{Xd}+\rho P_{Xc}$$

where $P_{Xd}$ is a [discrete measure](wikipedia://en/8912350) and $P_{Xc}$ is the absolutely continuous probability measure with $0\leq\rho\leq1$. Then

> $$d(X)=\rho$$

Moreover, given $\mathbb{H}_0(P_{Xd})$ and differential entropy $h(P_{Xc})$, the $d$-Dimensional Entropy is simply given by

> $$\mathbb{H}_\rho(X)=(1-\rho)\mathbb{H}_0(P_{Xd})+\rho h(P_{Xc})+\mathbb{H}_0(\rho)$$

where $\mathbb{H}_0(\rho)$ is the Shannon entropy of a discrete random variable $Z$ with $P_Z(1)=\rho$ and $P_Z(0)=1-\rho$ and given by

> $$\mathbb{H}_0(\rho)=\rho\log_2\frac{1}{\rho}+(1-\rho)\log_2\frac{1}{1-\rho}$$

::: {#o14 .example cue=heading name="Example"}

### Example {#Example}

*Image: A standard Gaussian distribution for illustration an example.png.*

Consider a signal which has a [Gaussian probability distribution](https://en.wikipedia.org/wiki/Gaussian_probability_distribution).

We pass the signal through a half-wave [rectifier](https://en.wikipedia.org/wiki/Rectifier#Half-wave_rectification) which converts all negative value to 0, and maintains all other values. The half-wave rectifier can be characterized by the function

> $$f(x)= \begin{cases} x,& \text{if } x\geq 0\\ 0,&x<0 \end{cases}$$

*Image: Rectified gaussian distribution.png.*

Then, at the output of the rectifier, the signal has a [rectified Gaussian distribution](wikipedia://en/31441193). It is characterized by an atomic mass of weight 0.5 and has a Gaussian PDF for all $x>0$.

With this mixture distribution, we apply the formula above and get the information dimension $d$ of the distribution and calculate the $d$-dimensional entropy.

> $$d(X)=\rho=0.5$$

The normalized right part of the zero-mean Gaussian distribution has entropy $h(P_{Xc})=\frac{1}{2}\log_2(2\pi e\sigma^2)-1$, hence

> $$\begin{aligned} \mathbb{H}_{0.5}(X)&=(1-0.5)(1\log_21)+0.5h(P_{Xc})+\mathbb{H}_0(0.5)\\ &=0+\frac{1}{2}(\frac{1}{2}\log_2(2\pi e\sigma^2)-1)+1\\ &=\frac{1}{4}\log_2(2\pi e\sigma^2)+\frac{1}{2}\,\text{ bit(s)} \end{aligned}$$

:::

## Connection to Differential Entropy {#Connection_to_Differential_Entropy}

It is shown [^o16] that information dimension and [differential entropy](wikipedia://en/3504168) are tightly connected.

Let $X$ be a random variable with continuous density $f(x)$.

*Image: A simple continuous function which are used to be quantized.png.*

Suppose we divide the range of $X$ into bins of length $\Delta$. By the [mean value theorem](wikipedia://en/19662), there exists a value $x_i$ within each bin such that

$$f(x_i)\Delta=\int_{i\Delta}^{(i+1)\Delta}f(x)\;\mathrm{d}x$$

Consider the discretized random variable $X^\Delta=x_i$ if $i\Delta\leq X< (i+1)\Delta$.

*Image: F(x) which has already been quantized to several dirac function.png.*

The probability of each support point $X^\Delta=x_i$ is

$$P_{X^\Delta}(x_i)=\int_{i\Delta}^{(i+1)\Delta}f(x)\;\mathrm{d}x=f(x_i)\Delta$$

Let $S = \operatorname{supp}(P_{X^\Delta})$. The entropy of $X^\Delta$ is

$$\begin{aligned} \mathbb{H}_0(X^\Delta)&=-\sum_{x_i \in S} P_{X^\Delta}\log_2P_{X^\Delta}\\ &=-\sum_{x_i \in S} f(x_i)\Delta\log_2(f(x_i)\Delta)\\ &=-\sum_{x_i \in S} \Delta f(x_i)\log_2f(x_i)-\sum_{x_i \in S} f(x_i)\Delta \log_2\Delta\\ &=-\sum_{x_i \in S} \Delta f(x_i)\log_2f(x_i)-\log_2\Delta\\ \end{aligned}$$

If we set $\Delta=1/m$ and $x_i=i/m$ then we are doing exactly the same quantization as the definition of information dimension. Since relabeling the events of a discrete random variable does not change its entropy, we have

$$\mathbb{H}_0(X^{1/m})=\mathbb{H}_0(\langle X\rangle_m).$$

This yields

$$\mathbb{H}_0(\langle X\rangle_m)=-\sum \frac{1}{m} f(x_i)\log_2f(x_i)+\log_2m$$

and when $m$ is sufficiently large,

$$-\sum \Delta f(x_i)\log_2f(x_i) \approx \int f(x)\log_2 \frac{1}{f(x)}\mathrm{d}x$$

which is the differential entropy $h(x)$ of the continuous random variable. In particular, if $f(x)$ is Riemann integrable, then

$$h(X)=\lim_{m\rightarrow \infty}\mathbb{H}_0(\langle X\rangle_m)-\log_2(m).$$

Comparing this with the $d$-dimensional entropy shows that the differential entropy is exactly the one-dimensional entropy

$$h(X)=\mathbb{H}_1(X).$$

In fact, this can be generalized to higher dimensions. Rényi shows that, if $\vec{X}$ is a random vector in a $n$-dimensional Euclidean space $\Re^n$ with an absolutely continuous distribution with a probability density function $f_{\vec{X}}(\vec{x})$ and finite entropy of the integer part ($H_0(\langle \vec{X} \rangle_m)<\infty$), we have $d(\vec{X})=n$

and

$$\mathbb{H}_n(\vec{X})=\int\cdots\int f_{\vec{X}}(\vec{x})\log_2\frac{1}{f_{\vec{X}}(\vec{x})}\mathrm{d}\vec{x},$$

if the integral exists.

## Lossless data compression {#Lossless_data_compression}

The information dimension of a distribution gives a theoretical upper bound on the compression rate, if one wants to compress a variable coming from this distribution. In the context of lossless data compression, we try to compress real number with less real number which both have infinite precision.

The main objective of the lossless data compression is to find efficient representations for source realizations $x^n\in \mathcal{X}^n$ by $y^n\in\mathcal{Y}^n$. A $(n,k)-$code for $\{X_i:i\in\mathcal{N}\}$ is a pair of mappings:

- encoder: $f_n:\mathcal{X}^n\rightarrow \mathcal{Y}^k$ which converts information from a source into symbols for communication or storage;
- decoder: $g_n:\mathcal{Y}^k\rightarrow\mathcal{X}^n$ is the reverse process, converting code symbols back into a form that the recipient understands.

The block error probability is $\mathcal{P}\{g_n(f_n(X^n))\neq X^n\}$.

Define $r(\epsilon)$ to be the [infimum](wikipedia://en/39382) of $r\geq0$ such that there exists a sequence of $(n,\lfloor rn\rfloor)-$codes such that $\mathcal{P}\{g_n(f_n(X^n))\neq X^n\}\leq\epsilon$ for all sufficiently large $n$.

So $r(\epsilon)$ basically gives the ratio between the code length and the source length, it shows how good a specific encoder decoder pair is. The fundamental limits in lossless source coding are as follows.[^o18]

Consider a continuous encoder function $f(x):{\mathbb{R}}^n\rightarrow {\mathbb{R}}^{\lfloor Rn\rfloor}$ with its continuous decoder function $g(x):{\mathbb{R}}^{\lfloor Rn\rfloor}\rightarrow {\mathbb{R}}^n$. If we impose no regularity on $f(x)$ and $g(x)$, due to the rich structure of $\Re$, we have the minimum $\epsilon$-achievable rate $R_0(\epsilon)=0$ for all $0<\epsilon\leq1$. It means that one can build an encoder-decoder pair with infinity compression rate.

In order to get some nontrivial and meaningful conclusions, let $R^*(\epsilon )$ the minimum $\epsilon-$achievable rate for linear encoder and Borel decoder. If random variable $X$ has a distribution which is a mixture of discrete and continuous part. Then $R^*(\epsilon)=d(X)$ for all $0<\epsilon\leq1$ Suppose we restrict the decoder to be a [Lipschitz continuous function](https://en.wikipedia.org/wiki/Lipschitz_continuous_function) and $\bar{d}(X)<\infty$ holds, then the minimum $\epsilon-$achievable rate $R(\epsilon)\geq \bar{d}(X)$ for all $0<\epsilon\leq1$.

The fundamental role of information dimension in lossless data compression further extends beyond the i.i.d. data. It is shown that for specified processes (e.g., moving-average processes) the ratio of lossless compression is also equal to the information dimension rate.[^o19] This result allows for further compression that was not possible by considering only [marginal distribution](wikipedia://en/506077) of the process.
