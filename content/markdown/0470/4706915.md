# Even code

::: {#o1 .subject cue=lead name="Even code"}

A binary [linear code](wikipedia://en/1866743) is called an **even code** if the [Hamming weight](wikipedia://en/1127884) of each of its codewords is even. An even code should have a generator polynomial that includes the (*x*+1) minimal polynomial as a product. Furthermore, a binary code is called **doubly even** if the Hamming weight of all its codewords is [divisible by 4](https://en.wikipedia.org/wiki/Divisible_by_4). An even code which is not doubly even is said to be strictly even.

:::

Examples of doubly even codes are the extended binary [Hamming code](wikipedia://en/41226) of block length 8 and the extended [binary Golay code](wikipedia://en/344971) of block length 24. These two codes are, in addition, [self-dual](https://en.wikipedia.org/wiki/Self-dual_code).
