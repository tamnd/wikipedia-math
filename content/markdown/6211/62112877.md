# Dependent random choice

::: {#o1 .subject cue=lead name="Dependent random choice"}

In mathematics, **dependent random choice** is a [probabilistic](https://en.wikipedia.org/wiki/Probabilistic) technique that shows how to find a large set of [vertices](wikipedia://en/11308417) in a dense [graph](wikipedia://en/12401) such that every small subset of vertices has many common neighbors. It is a useful tool to embed a graph into another graph with many edges. Thus it has its application in [extremal graph theory](wikipedia://en/529568), [additive combinatorics](wikipedia://en/18243392) and [Ramsey theory](wikipedia://en/157175).

:::

::: {#o3 .statement kind=statement/theorem cue=named-heading name="Statement of theorem"}

## Statement of theorem {#Statement_of_theorem}

Let $u,n,r,m,t \in \mathbb{N}$, $\alpha>0$ and suppose:[^o4][^o5][^o6][^o7][^o8]

$$n\alpha^t - {n \choose r} \left(\frac{m}{n}\right)^t \geq u.$$

Every graph on $n$ vertices with at least $\frac{\alpha n^2}{2}$ edges contains a subset $U$ of vertices with $|U|\geq u$ such that for all $S\subset U$ with $|S| = r$, $S$ has at least $m$ common neighbors.

:::

::: {#o10 .proof cue=heading name="Proof"}

## Proof {#Proof}

The basic idea is to choose the set of vertices randomly. However, instead of choosing each vertex uniformly at random, the procedure randomly chooses a list of $t$ vertices first and then chooses common neighbors as the set of vertices. The hope is that in this way, the chosen set would be more likely to have more common neighbors.

Formally, let $T$ be a list of $t$ vertices chosen uniformly at random from $V(G)$ with replacement (allowing repetition). Let $A$ be the common neighborhood of $T$. The [expected value](wikipedia://en/9653) of $|A|$ is

$$\begin{aligned} \mathbb{E}|A| &= \sum_{v\in V}\mathbb{P}(v\in A)= \sum_{v\in V}\mathbb{P}(T\subseteq N(v))= \sum_{v\in V}\left(\frac{d(v)}{n}\right)^t\\ &\geq n\left(\frac{1}{n}\sum_{v\in V}\frac{d(v)}{n}\right)^t \quad\text{(convexity)}\\ &\geq n\alpha^t. \end{aligned}$$

For every $r$-element subset $S$ of $V$, $A$ contains $S$ if and only if $T$ is contained in the common neighborhood of $S$, which occurs with probability $\left(\frac{\#\text{common neighbors of }S}{n}\right)^t.$ An $S$ is *bad* if it has less than $m$ common neighbors. Then for each fixed $r$-element subset $S$ of $V$, it is contained in $A$ with probability less than $(m/n)^t$. Therefore by linearity of expectation,

$$\mathbb{E}[\#\text{bad }r\text{-element subset of }A]<\binom{n}{r}\left(\frac{m}{n}\right)^t.$$

To eliminate bad subsets, we exclude one element in each bad subset. The number of remaining elements is at least $|A|-(\#\text{bad }r\text{-element subset of }A)$, whose expected value is at least $n\alpha^t-\binom{n}{r}\left(\frac{m}{n}\right)^t\geq u.$ Consequently, there exists a $T$ such that there are at least $u$ elements in $A$ remaining after getting rid of all bad $r$-element subsets. The set $U$ of the remaining $u$ elements expresses the desired properties.

:::

::: {#o12 .application cue=heading name="Applications"}

## Applications {#Applications}

### Turán numbers of a bipartite graph {#Turán_numbers_of_a_bipartite_graph}

Dependent random choice can help find the [Turán number](wikipedia://en/14982946). Using appropriate parameters, if $H = A\cup B$ is a [bipartite graph](wikipedia://en/244431) in which all vertices in $B$ have degree at most $r$, then the extremal number $\text{ex}(n, H)\leq c n^{2-1/r}$ where $c = c(H)$ only depends on $H$.[^o4][^o8]

Formally, with $a=|A|, b=|B|$, let $c$ be a sufficiently large constant such that $(2c)^r - (a+b)^r \geq a.$ If $\alpha = 2cn^{-1/r}, m = a+b, t = r, u = a$ then

$$n\alpha^t - \binom{n}{r}\left(\frac{m}{n}\right)^t = (2c)^r - \binom{n}{r}\left(\frac{a+b}{n}\right)^r\geq (2c)^r - (a+b)^r\geq a=u,$$

and so the assumption of dependent random choice holds. Hence, for each graph $G$ with at least $cn^{2-1/r}$ edges, there exists a vertex subset $U$ of size $a$ satisfying that every $r$-subset of $U$ has at least $a+b$ common neighbors. By embedding $H$ into $G$ by embedding $A$ into $U$ arbitrarily and then embedding the vertices in $B$ one by one, then for each vertex $v$ in $B$, it has at most $r$ neighbors in $A$, which shows that their images in $U$ have at least $a+b$ common neighbors. Thus $v$ can be embedded into one of the common neighbors while avoiding collisions.

This can be generalized to [degenerate](wikipedia://en/27545816) graphs using a variation of dependent random choice.

### Embedding a 1-subdivision of a complete graph {#Embedding_a_1-subdivision_of_a_complete_graph}

DRC can be applied directly to show that if $G$ is a graph on $n$ vertices and $\epsilon n^2$ edges, then $G$ contains a [1-subdivision](wikipedia://en/353021#Subdivision_and_smoothing) of a [complete graph](wikipedia://en/85816) with $\epsilon^{3/2}n^{1/2}$ vertices. This can be shown in a similar way to the above proof of the bound on [Turán number](wikipedia://en/14982946) of a bipartite graph.[^o4]

Indeed, if we set $\alpha = 2\epsilon, m = a^2, t=\frac{\log n}{2\log 1/\epsilon}, u=a$, we have (since $2\epsilon = \alpha \leq 1$)

$$n\alpha^t - \binom{n}{r}\left(\frac{m}{n}\right)^t \geq (2\epsilon)^tn - \binom{n}{2}\epsilon^{3t}\geq n^{1/2}\geq a=u,$$

and so the DRC assumption holds. Since a 1-subdivision of the complete graph on $a$ vertices is a bipartite graph with parts of size $a$ and $b = \binom{a}{2}$ where every vertex in the second part has degree two, the embedding argument in the proof of the bound on Turán number of a bipartite graph produces the desired result.

:::

::: {#o16 .statement kind=statement/generalization cue=heading name="Variation"}

## Variation {#Variation}

A stronger version finds two subsets of vertices $U_1, U_2$ in a [dense graph](wikipedia://en/2777098) $G$ so that every small subset of vertices in $U_i$ has a lot of common neighbors in $U_{3-i}$.

Formally, let $u,n,r,m,t,q$ be some positive integers with $q>r$, and let $\alpha>0$ be some [real number](wikipedia://en/20646438). Suppose that the following constraints hold:

$$\begin{aligned} n\alpha^t-\binom{n}{q}\left(\frac{m}{n}\right)^t & \geq u\\ \binom{n}{r}\left(\frac{m}{u}\right)^{q-r} & <1. \end{aligned}$$

Then every graph $G$ on $n$ vertices with at least $\alpha n^2/2$ edges contains two subsets $U_1, U_2$ of vertices so that any $r$ vertices in $U_i$ have at least $m$ common neighbors in $U_{3-i}$.[^o4]

### Extremal number of a degenerate bipartite graph {#Extremal_number_of_a_degenerate_bipartite_graph}

Using this stronger statement, one can upper bound the [extremal number](wikipedia://en/529568) of $r$-degenerate bipartite graphs: for each $r$-degenerate bipartite graph $H$ with at most $N^{1-1.8/s}$ vertices, the extremal number $\text{ex}(N, H)$ is at most $N^{2-1/(s^3r)}.$[^o4]

### Ramsey number of a degenerate bipartite graph {#Ramsey_number_of_a_degenerate_bipartite_graph}

This statement can be also applied to obtain an upper bound of the [Ramsey number](wikipedia://en/184898) of a degenerate bipartite graphs. If $r$ is a fixed [integer](wikipedia://en/14563), then for every bipartite $r$-degenerate bipartite graph $G$ on $n$ vertices, the Ramsey number $r(G)$ is of the order $n^{1+o(1)}.$[^o4]

:::
