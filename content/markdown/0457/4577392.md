# Edge cover

::: {#o1 .subject cue=lead name="Edge cover"}

In [graph theory](wikipedia://en/12401), an **edge cover** of a [graph](wikipedia://en/325806) is a set of [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) such that every [vertex](wikipedia://en/638899) of the graph is an endpoint of at least one edge of the set. In [computer science](https://en.wikipedia.org/wiki/Computer_science), the **minimum edge cover problem** is the problem of finding an edge cover of minimum size. It is an [optimization problem](wikipedia://en/1126536) that belongs to the class of [covering problems](https://en.wikipedia.org/wiki/Covering_problem) and can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, an edge cover of a graph $G$ is a set of edges $C$ such that each vertex in $G$ is incident with at least one edge in $C$. The set $C$ is said to *cover* the vertices of $G$. The following figure shows examples of edge coverings in two graphs (the set $C$ is marked with red).

*Image: Edge-cover.svg.*

A **minimum edge covering** is an edge covering of smallest possible size. The **edge covering number** $\rho(G)$ is the size of a minimum edge covering. The following figure shows examples of minimum edge coverings (again, the set $C$ is marked with red).

*Image: Minimum-edge-cover.svg.*

Note that the figure on the right is not only an edge cover but also a [matching](wikipedia://en/581797). In particular, it is a [perfect matching](wikipedia://en/44031): a matching $M$ in which every vertex is incident with exactly one edge in $M$. A perfect matching (if it exists) is always a minimum edge covering.

::: {#o5 .example cue=heading name="Examples"}

### Examples {#Examples}

- The set of all edges is an edge cover, assuming that there are no degree-0 vertices.
- The [complete bipartite graph](wikipedia://en/525320) $K_{m,n}$ has edge covering number $\max(m, n)$.

## Algorithms {#Algorithms}

A smallest edge cover can be found in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) by finding a [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching) and extending it greedily so that all vertices are covered.[^o9][^o8] In the following figure, a maximum matching is marked with red; the extra edges that were added to cover unmatched nodes are marked with blue. (The figure on the right shows a graph in which a maximum matching is a [perfect matching](wikipedia://en/44031); hence it already covers all vertices and no extra edges were needed.)

*Image: Minimum-edge-cover-from-maximum-matching.svg.*

On the other hand, the related problem of finding a smallest [vertex cover](wikipedia://en/562782) is an [NP-hard](https://en.wikipedia.org/wiki/NP-hard) problem.[^o9]

Looking at the image it already becomes obvious why, for a given minimum edge cover $C$ and [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching) $M$, letting $c$ and $m$ be the number of edges in $C$ and $M$ respectively, we have:[^o10] $|V| = c + m$. Indeed, $C$ contains a maximum matching, so the edges of $C$ can be decomposed between the $m$ edges of a maximum matching, covering $2m$ vertices, and the $c-m$ other edges that each cover one other vertex. Thus, as $C$ covers all of the $|V|$ vertices, we have $|V| = 2m + (c-m)$ giving the desired equality.
