# Post hoc analysis

::: {#o1 .subject cue=lead name="Post hoc analysis"}

In a scientific study, **post hoc analysis** (from [Latin](https://en.wikipedia.org/wiki/Latin_language) *[post hoc](https://en.wikipedia.org/wiki/Post_hoc_%28disambiguation%29)*, "after this") consists of [statistical analyses](wikipedia://en/26685) that were specified after the data were seen.[^o2][^o3][^o4] A post hoc analysis is usually used to explore specific, statistically significant differences between the means of three or more independent groups-- differences detected with an [analysis of variance](wikipedia://en/634) (ANOVA).[^o5] An ANOVA does not identify the group(s); for that, a post hoc analysis is required.[^o6]

:::

Because each post hoc analysis is effectively a [statistical test](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing), conducting multiple post hoc comparisons introduces a [family-wise error rate problem](wikipedia://en/4621448), which is a type of [multiple testing](https://en.wikipedia.org/wiki/Multiple_testing) problem. This increases the likelihood of false positives unless corrected.

Post hoc tests are follow-up tests performed after a significant ANOVA result[^o7] to identify where the differences lie (which specific groups differ). To compensate, multiple post hoc testing procedures are sometimes used, but that is often difficult or impossible to do precisely. Post hoc analysis that is conducted and interpreted without adequate consideration of this problem is sometimes called *[data dredging](wikipedia://en/1311951)* (*p*-hacking) by critics because the statistical associations that it finds are often spurious.[^o8] In other words, findings from data dredging are invalid or not trustworthy.

Post hoc analyses are acceptable when transparently reported as exploratory. In other words, post hoc analyses are not inherently unethical.[^o9] The main requirement for their [ethical use](wikipedia://en/3609425) is simply that their results not be [mispresented](wikipedia://en/29537) as the original hypothesis.[^o9] Modern editions of scientific manuals have clarified this point; for example, [APA style](https://en.wikipedia.org/wiki/APA_style) now specifies that "hypotheses should now be stated in three groupings: preplanned–primary, preplanned–secondary, and exploratory (post hoc). Exploratory hypotheses are allowable, and there should be no pressure to disguise them as if they were preplanned."[^o9]

## Types of post hoc analysis {#Types_of_post_hoc_analysis}

Types or categories of post hoc analyses include:[^o11]

- **Pairwise comparisons:** Tests all possible pairs
- **Trend analysis:** Tests for linear or quadratic trends across ordered groups
- **Simple effects analysis:** Examines effects within factorial ANOVA
- **Interaction probing:** Analyzes interaction constraints within factorial ANOVA
- **Restricted Sets of Contrasts:** Testing smaller families of comparisons

In addition, a **subgroup analysis**[^o12] examines whether findings differ between discrete categories of subjects in the sample. This approach is common in clinical and observational studies.

## Common post hoc tests {#Common_post_hoc_tests}

Common post hoc tests include:[^o14][^o15]

- [Fisher's least significant difference](wikipedia://en/82078214)
- [Holm-Bonferroni Procedure](wikipedia://en/10726541)
- [Newman-Keuls](wikipedia://en/23857094)
- [Rodger's Method](wikipedia://en/37994723)
- [Scheffé's Method](wikipedia://en/14913760)
- [Tukey's Test](wikipedia://en/14653762) and Honestly Significance Difference (HSD) (see also: [Studentized Range Distribution](wikipedia://en/14261888))

However, with the exception of Scheffès Method, these tests should be specified "a priori" despite being called "post-hoc" in conventional usage. For example, a difference between means could be significant with the Holm-Bonferroni method but not with the Tukey Test and vice versa. It would be poor practice for a data analyst to choose which of these tests to report based on which gave the desired result.

## Causes {#Causes}

Sometimes the temptation to engage in post hoc analysis is motivated by a desire to produce positive results or see a project as successful. In the case of pharmaceutical research, there may be significant financial consequences to a failed trial.
