# Rank ring

::: {#o1 .subject cue=lead name="Rank ring"}

In [mathematics](wikipedia://en/18831), a **rank ring** is a [ring](wikipedia://en/48404) with a [real](wikipedia://en/20646438)-valued rank function behaving like the rank of an [endomorphism](wikipedia://en/9569). () introduced rank rings in his work on [continuous geometry](wikipedia://en/32590824), and showed that the ring associated to a continuous geometry is a rank ring.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

(txt, p.231) defined a ring to be a rank ring if it is [regular](wikipedia://en/907524) and has a real-valued rank function *R* with the following properties:

- 0 ≤ *R*(*a*) ≤ 1 for all *a*
- *R*(*a*) = 0 if and only if *a* = 0
- *R*(1) = 1
- *R*(*ab*) ≤ *R*(*a*), *R*(*ab*) ≤ *R*(*b*)
- If *e*<sup>2</sup> = *e*, *f*<sup>2</sup> = *f*, *ef* = *fe* = 0 then *R*(*e* + *f* ) = *R*(*e*) + *R*(*f* ).

:::
