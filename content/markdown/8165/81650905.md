# Efficient dominating set

*Image: Efficient dominating set.svg.* The two darker vertices at the top form an **efficient dominating set** of the graph. Each vertex of the graph is [dominated](wikipedia://en/1747972) by **exactly one** vertex in this set (colored by which one dominates it), including the vertices of the set, each of which dominates itself.

::: {#o1 .subject cue=lead name="Efficient dominating set"}

In [graph theory](wikipedia://en/12401), an **efficient dominating set** (also called an **e.d. set** or **independent perfect dominating set**[^o2]) is a [dominating set](wikipedia://en/1747972) with the additional property that every [vertex](wikipedia://en/638899) in the [graph](wikipedia://en/325806) is dominated by exactly one vertex in the set.[^o3]

:::

The **efficient domination problem** (ED problem) asks whether a given graph contains an efficient dominating set. The problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) for general graphs[^o3] and remains NP-complete even when restricted to [3-regular planar graphs](wikipedia://en/24314).[^o4]

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

A vertex $v$ in a graph **dominates** itself and all its neighbors, that is, every vertex $u$ such that $u = v$ or $uv \in E$. A [dominating set](wikipedia://en/1747972) $D$ is a set of vertices such that every vertex in the graph is dominated by at least one vertex in $D$. An *efficient* dominating set strengthens this condition by requiring that every vertex is dominated by **exactly one** vertex in $D$.[^o3]

More formally, a vertex set $D \subseteq V$ in a graph $G = (V,E)$ is an efficient dominating set if for every vertex $v \in V$, there is exactly one $d \in D$ such that $v$ is in the [closed neighborhood](wikipedia://en/7309251) $N_G[d]$ of $d$.[^o3]

An equivalent characterization is that the closed neighborhoods ${N_G[d] : d \in D}$ form a [partition](wikipedia://en/340240) of the vertex set $V$.[^o4]

Every efficient dominating set is necessarily a [minimum dominating set](https://en.wikipedia.org/wiki/Minimum_dominating_set), since the closed neighborhoods partition the vertex set.[^o4] However, not every minimum dominating set is efficient.

:::

## Complexity {#Complexity}

The efficient domination problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) for several graph classes, including [bipartite graphs](wikipedia://en/244431), [chordal graphs](wikipedia://en/744165), and [chordal bipartite graphs](wikipedia://en/44355462)[^o3]. The problem remains NP-complete even when restricted to 3-regular planar graphs.[^o4]

However, the problem can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) for certain restricted graph classes:[^o3][^o4]

- [Dually chordal graphs](https://en.wikipedia.org/wiki/Dually_chordal_graph) can be solved in [linear time](https://en.wikipedia.org/wiki/Linear_time)
- [AT-free graphs](https://en.wikipedia.org/wiki/AT-free_graph) can be solved in polynomial time
- [Interval bigraphs](wikipedia://en/363423) can be solved in polynomial time
- [Trees](wikipedia://en/48560) can be solved in linear time

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

[Sierpiński graphs](https://en.wikipedia.org/wiki/Sierpiński_graph) $S(n,k)$ provide notable examples of graphs with efficient dominating sets. These graphs possess essentially unique efficient dominating sets for all parameters $n$ and $k$.[^o10][^o11]

The closely related [Sierpiński gasket graphs](wikipedia://en/58619302) $S_n$, which arise from iterations leading to the [Sierpiński gasket](wikipedia://en/29638), have a much more restrictive structure: they contain an efficient dominating set if and only if $n = 1$ or $n = 3$.[^o11]

[Circulant graphs](wikipedia://en/3498787) provide another well-studied class for efficient dominating sets. A circulant graph $\text{Cay}(\mathbb{Z}_n, S)$ is a [Cayley graph](wikipedia://en/358277) on the [cyclic group](wikipedia://en/52327) $\mathbb{Z}_n$ with connection set $S$, where $S = -S$ and $0 \notin S$. Such a graph has vertices $\{0, 1, \ldots, n-1\}$ with edges connecting vertices whose difference lies in $S$.[^o12]

For a circulant graph $\text{Cay}(\mathbb{Z}_n, S)$ to admit an efficient dominating set $D$, a necessary condition is $n = |S_0| \cdot |D|$, where $S_0 = S \cup \{0\}$.[^o12]

For connected non-complete circulant graphs of degree $|S| = p - 1$ where $p$ is prime, an efficient dominating set exists if and only if $s - s' \not\equiv 0 \pmod{p}$ for any distinct $s, s' \in S_0$. When this condition holds, all efficient dominating sets are precisely the cosets $g + p\mathbb{Z}_n$ for $g \in \mathbb{Z}_n$.[^o12]

Similar characterizations exist for circulant graphs of degree $|S| = pq - 1$ and $|S| = p^m - 1$, where $p, q$ are primes and $m$ is a positive integer, provided that $|S| + 1$ is relatively prime to $\frac{n}{|S|+1}$.[^o12]

:::

## History and applications {#History_and_applications}

The concept of efficient dominating sets was introduced independently by two groups of researchers. [Norman Biggs](wikipedia://en/26991095) first studied these structures in 1973 under the name **perfect codes** in the context of [coding theory](wikipedia://en/321869) and [distance-transitive graphs](wikipedia://en/7768222).[^o14] Later, apparently unaware of Biggs's work, Bange, Barkauskas, and Slater independently defined the concept as **efficient dominating sets** and developed [linear time](https://en.wikipedia.org/wiki/Linear_time) algorithms for finding them in [trees](wikipedia://en/48560).[^o2][^o4]

Efficient dominating sets have applications in [resource allocation](https://en.wikipedia.org/wiki/Resource_allocation) problems for [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing). When modeling a parallel computer's processors and interconnection network as a graph, an efficient dominating set represents an optimal placement of limited resources (such as disk drives, I/O connections, or software modules) such that every processor is within distance $d$ of exactly one resource unit, with neither duplication nor overlap.[^o4]

The concept has been extended to [fuzzy graphs](https://en.wikipedia.org/wiki/Fuzzy_graph) and intuitionistic fuzzy graphs, where efficient domination has been applied to [encryption](wikipedia://en/10294) and [decryption](https://en.wikipedia.org/wiki/Decryption) problems. In these applications, efficient dominating nodes serve as centers of subnetworks in the encryption scheme, and identifying the efficiently dominating set becomes the secret key for decryption.[^o15]

For [hypercube graphs](wikipedia://en/6706815), a distance d efficient dominating set corresponds precisely to a **perfect binary d-error-correcting code**.[^o4][^o14] This connection links the graph-theoretic concept to [coding theory](wikipedia://en/321869).

## Related problems {#Related_problems}

The **efficient edge domination problem** (EED problem) is the edge-analogue of the efficient domination problem. An **efficient edge dominating set** $M \subseteq E$ is a set of edges such that every edge $e \in E$ is intersected by exactly one edge $e' \in M$. The EED problem can be solved in linear time for [chordal graphs](wikipedia://en/744165) and [dually chordal graphs](https://en.wikipedia.org/wiki/Dually_chordal_graph).[^o3]

A **strong efficient dominating set** is a variant where domination is restricted to neighbors of equal or higher degree. Formally, a set $S \subseteq V$ is a strong efficient dominating set if for every $v \in V$, there is exactly one vertex in $S$ that either equals $v$ or is adjacent to $v$ with degree at least $\deg(v)$. Unlike standard efficient dominating sets, which all have the same cardinality in a given graph, strong efficient dominating sets of the same graph may have different cardinalities.[^o17]

The concept extends naturally to **distance d perfect dominating sets** (or **distance d PDS**). A vertex $v$ **d-dominates** a vertex $u$ if the distance between them is at most $d$. A set $D$ is a distance d perfect dominating set if every vertex in the graph is d-dominated by exactly one vertex in $D$.[^o4]

The concept also extends to [hypergraphs](wikipedia://en/232535), where similar complexity results have been established.[^o3]
