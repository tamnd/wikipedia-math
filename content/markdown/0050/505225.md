# Iterated function system

::: {#o1 .subject cue=lead name="Iterated function system"}

*Image: Sierpinski1.png.* [Sierpiński triangle](wikipedia://en/29638) created using IFS (colored to illustrate self-similar structure)

*Image: Chris Ursitti fractal 0000.png.* Colored IFS designed using [Apophysis](https://en.wikipedia.org/wiki/Apophysis_%28software%29) software and rendered by the [Electric Sheep](https://en.wikipedia.org/wiki/Electric_Sheep)

In [mathematics](wikipedia://en/18831), **iterated function systems** (**IFSs**) are a method of constructing [fractals](wikipedia://en/10913); the resulting fractals are often [self-similar](https://en.wikipedia.org/wiki/Self-similar). IFS fractals are more related to [set theory](wikipedia://en/27553) than fractal geometry.[^o2] They were introduced in 1981.

:::

**IFS** fractals, as they are normally called, can be of any number of dimensions, but are commonly computed and drawn in 2D. The fractal is made up of the union of several copies of itself, each copy being transformed by a function (hence "function system"). The canonical example is the [Sierpiński triangle](wikipedia://en/29638). The functions are normally [contractive](wikipedia://en/6239), which means they bring points closer together and make shapes smaller. Hence, the shape of an IFS fractal is made up of several possibly-overlapping smaller copies of itself, each of which is also made up of copies of itself, [ad infinitum](https://en.wikipedia.org/wiki/Ad_infinitum). This is the source of its self-similar fractal nature.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, an [iterated function](wikipedia://en/1448702) system is a finite set of [contraction mappings](wikipedia://en/6239) on a [complete metric space](wikipedia://en/7832).[^o5] Symbolically,

$$\{f_i:X\to X\mid i=1,2,\dots,N\},\ N\in\mathbb{N}$$

is an iterated function system if each $f_{i}$ is a contraction on the complete metric space $X$.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

*Image: Chaosgame.gif.* Construction of an IFS by the [chaos game](https://en.wikipedia.org/wiki/Chaos_game) (animated)

*Image: Ifs-construction.png.* IFS being made with two functions

Hutchinson showed that, for the metric space $\mathbb{R}^{n}$, or more generally, for a complete metric space $X$, such a system of functions has a unique nonempty [compact](wikipedia://en/6042) (closed and bounded) fixed set $S$.[^o8] One way of constructing a fixed set is to start with an initial nonempty closed and bounded set $S_{0}$ and iterate the actions of the $f_{i}$, taking $S_{n+1}$ to be the union of the images of $S_{n}$ under the $f_{i}$; then taking $S$ to be the [closure](wikipedia://en/42309) of the limit $n\to\infty S_{n}$. Symbolically, the unique fixed (nonempty compact) set $S \subseteq X$ has the property

$$S = \overline{\bigcup_{i=1}^N f_i(S)}.$$

The set $S$ is thus the fixed set of the [Hutchinson operator](wikipedia://en/18502646) $F : 2^{X} \to 2^{X}$ defined for $A \subseteq X$ via

$$F(A)=\overline{\bigcup_{i=1}^N f_i(A)}.$$

The existence and uniqueness of $S$ is a consequence of the [contraction mapping principle](https://en.wikipedia.org/wiki/Contraction_mapping_principle), as is the fact that

$$\lim_{n\to\infty}F^{n}(A)=S$$

for any nonempty compact set $A$ in $X$. (For contractive IFS this convergence takes place even for any nonempty closed bounded set $A$). Random elements arbitrarily close to $S$ may be obtained by the "chaos game", described below.

Recently it was shown that the IFSs of non-contractive type (i.e. composed of maps that are not contractions with respect to any topologically equivalent metric in $X$) can yield attractors. These arise naturally in projective spaces, though classical irrational rotation on the circle can be adapted too.[^o9]

The collection of functions $f_{i}$ [generates](https://en.wikipedia.org/wiki/Generating_set) a [monoid](wikipedia://en/19652) under [composition](wikipedia://en/195947). If there are only two such functions, the monoid can be visualized as a [binary tree](wikipedia://en/4321), where, at each node of the tree, one may compose with the one or the other function (*i.e.* take the left or the right branch). In general, if there are $k$ functions, then one may visualize the monoid as a full [$k$-ary tree](https://en.wikipedia.org/wiki/K-ary_tree), also known as a [Cayley tree](https://en.wikipedia.org/wiki/Cayley_tree).

Sometimes each function $f_{i}$ is required to be a [linear](https://en.wikipedia.org/wiki/Linear_transformation), or more generally an [affine transformation](wikipedia://en/38449), and hence represented by a [matrix](wikipedia://en/20556859). However, IFSs may also be built from non-linear functions, including [projective transformations](https://en.wikipedia.org/wiki/Projective_transformation) and [Möbius transformations](wikipedia://en/314493). The [Fractal flame](wikipedia://en/505238) is an example of an IFS with nonlinear functions.

The most common algorithm to compute IFS fractals is called the "[chaos game](https://en.wikipedia.org/wiki/Chaos_game)". It consists of picking a random point in the plane, then iteratively applying one of the functions chosen at random from the function system to transform the point to get a next point. An alternative algorithm is to generate each possible sequence of functions up to a given maximum length, and then to plot the results of applying each of these sequences of functions to an initial point or shape.

Each of these algorithms provides a global construction which generates points distributed across the whole fractal. If a small area of the fractal is being drawn, many of these points will fall outside of the screen boundaries. This makes zooming into an IFS construction drawn in this manner impractical.

Although the theory of IFS requires each function to be contractive, in practice software that implements IFS only require that the whole system be contractive on average.[^o12]

:::

## Partitioned iterated function systems {#Partitioned_iterated_function_systems}

PIFS (partitioned iterated function systems), also called local iterated function systems,[^o16] give surprisingly good image compression, even for photographs that do not seem to have the kinds of self-similar structure shown by simple IFS fractals.[^o14]

## The inverse problem {#The_inverse_problem}

Very fast algorithms exist to generate an image from a set of IFS or PIFS parameters. It is faster and requires much less storage space to store a description of how it was created, transmit that description to a destination device, and regenerate that image anew on the destination device, than to store and transmit the color of each pixel in the image.[^o16]

The [inverse problem](wikipedia://en/203956) is more difficult: given some original arbitrary digital image such as a digital photograph, try to find a set of IFS parameters which, when evaluated by iteration, produces another image visually similar to the original. In 1989, Arnaud Jacquin presented a solution to a restricted form of the inverse problem using only PIFS; the general form of the inverse problem remains unsolved.[^o17][^o18][^o16]

By 1995, all [fractal compression](wikipedia://en/60022) software was based on Jacquin's approach.[^o18]

## History {#History}

IFSs were conceived in their present form by [John E. Hutchinson](https://en.wikipedia.org/wiki/John_E._Hutchinson) in 1981[^o8] and popularized by [Michael Barnsley](wikipedia://en/1014175)'s book *Fractals Everywhere*.

IFSs provide models for certain plants, leaves, and ferns, by virtue of the self-similarity which often occurs in branching structures in nature.
