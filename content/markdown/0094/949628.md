# Approximate identity

::: {#o1 .subject cue=lead name="Approximate identity"}

In [mathematics](wikipedia://en/18831), particularly in [functional analysis](wikipedia://en/11180) and [ring theory](wikipedia://en/250424), an approximate identity is a [net](wikipedia://en/22170) in a [Banach algebra](wikipedia://en/4665) or [ring](wikipedia://en/48404) (generally without an identity) that acts as a substitute for an [identity element](wikipedia://en/14962).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **right approximate identity** in a Banach algebra *A* is a net $\{e_\lambda : \lambda \in \Lambda\}$ such that for every element *a* of *A*, $\lim_{\lambda\in\Lambda}\lVert ae_\lambda - a \rVert = 0.$ Similarly, a **left approximate identity** in a Banach algebra *A* is a net $\{e_\lambda : \lambda \in \Lambda\}$ such that for every element *a* of *A*, $\lim_{\lambda\in\Lambda}\lVert e_\lambda a - a \rVert = 0.$ An **approximate identity** is a net which is both a right approximate identity and a left approximate identity. [^o4]

:::

## C\*-algebras {#C*-algebras}

For [C\*-algebras](wikipedia://en/7184), a right (or left) approximate identity consisting of [self-adjoint](https://en.wikipedia.org/wiki/Self-adjoint) elements is the same as an approximate identity. The net of all positive elements in *A* of norm ≤ 1 with its natural order is an approximate identity for any C\*-algebra. This is called the **canonical approximate identity** of a C\*-algebra. Approximate identities are not unique. For example, for [compact operators](wikipedia://en/577441) acting on a [Hilbert space](wikipedia://en/20598932), the net consisting of finite rank projections would be another approximate identity.

If an approximate identity is a [sequence](https://en.wikipedia.org/wiki/Sequence_%28mathematics%29), we call it a **sequential approximate identity** and a C\*-algebra with a sequential approximate identity is called **σ-unital**. Every [separable](wikipedia://en/27855) C\*-algebra is σ-unital, though the [converse](wikipedia://en/155941) is false. A commutative C\*-algebra is σ-unital [if and only if](wikipedia://en/14922) its [spectrum](wikipedia://en/918414) is [&sigma;-compact](https://en.wikipedia.org/wiki/&sigma;-compact). In general, a C\*-algebra *A* is σ-unital if and only if *A* contains a strictly positive element, i.e. there exists *h* in *A*<sub>\+</sub> such that the [hereditary C\*-subalgebra](wikipedia://en/13437009) generated by *h* is *A*.

One sometimes considers approximate identities consisting of specific types of elements. For example, a C\*-algebra has [real rank zero](wikipedia://en/48465743#Real_rank_zero) if and only if every hereditary C\*-subalgebra has an approximate identity consisting of projections. This was known as property (HP) in earlier literature.[^o6] [^o7]

## Convolution algebras {#Convolution_algebras}

An approximate identity in a [convolution](wikipedia://en/7519) algebra plays the same role as a sequence of function approximations to the [Dirac delta function](wikipedia://en/37021) (which is the identity element for convolution). For example, the [Fejér kernels](wikipedia://en/693816) of [Fourier series](wikipedia://en/59038) theory give rise to an approximate identity.

## Rings {#Rings}

In ring theory, an approximate identity is defined in a similar way, except that the ring is given the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) so that *a* = *ae*<sub>λ</sub> for some λ.

A [module](wikipedia://en/276410) over a ring with approximate identity is called **non-degenerate** if for every *m* in the module there is some λ with *m* = *me*<sub>λ</sub>.
