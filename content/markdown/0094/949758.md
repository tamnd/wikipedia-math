# GnuTLS

::: {#o4 .subject cue=lead name="GnuTLS"}

**GnuTLS** (, the **GNU Transport Layer Security Library**) is a [free software](https://en.wikipedia.org/wiki/Free_software) implementation of the [TLS, SSL](wikipedia://en/187813) and [DTLS](https://en.wikipedia.org/wiki/DTLS) protocols. It offers an [application programming interface](https://en.wikipedia.org/wiki/Application_programming_interface) (API) for applications to enable secure communication over the network [transport layer](https://en.wikipedia.org/wiki/Transport_layer), as well as interfaces to access [X.509](https://en.wikipedia.org/wiki/X.509), [PKCS #12](wikipedia://en/12545362), [OpenPGP](https://en.wikipedia.org/wiki/OpenPGP) and other structures.

:::

## Features {#Features}

GnuTLS consists of a library that allows client applications to start secure sessions using the available protocols. It also provides command-line tools, including an X.509 certificate manager, a test client and server, and random key and password generators.

GnuTLS has the following features:

- [TLS](wikipedia://en/187813) 1.3, TLS 1.2, TLS 1.1, TLS 1.0, and SSL 3.0 protocols
- [Datagram TLS](wikipedia://en/1500599) (DTLS) 1.2, and DTLS 1.0, protocols
- [TLS-SRP](wikipedia://en/31681249): [Secure remote password protocol](https://en.wikipedia.org/wiki/Secure_remote_password_protocol) (SRP) for TLS authentication
- [TLS-PSK](wikipedia://en/14453017): [Pre-shared key](wikipedia://en/4934057) (PSK) for TLS authentication
- [X.509](https://en.wikipedia.org/wiki/X.509) and [OpenPGP](https://en.wikipedia.org/wiki/OpenPGP) [certificate](wikipedia://en/223796)[^o6] handling
- CPU assisted cryptography and cryptographic accelerator support ([/dev/crypto](https://en.wikipedia.org/wiki//dev/crypto)), [VIA PadLock](https://en.wikipedia.org/wiki/VIA_PadLock) and [AES-NI](https://en.wikipedia.org/wiki/AES-NI) instruction sets[^o7]
- Support for [smart cards](https://en.wikipedia.org/wiki/Smart_card) and for hardware security modules
- Storage of cryptographic keys in the system's [Trusted Platform Module](wikipedia://en/2936835) (TPM)

## History {#History}

### Origin {#Origin}

GnuTLS was initially created around March[^o10] to November[^o11] 2000, by Nikos Mavrogiannopoulos to allow applications of the [GNU Project](https://en.wikipedia.org/wiki/GNU_Project) to use secure protocols such as [TLS](wikipedia://en/187813). Although [OpenSSL](wikipedia://en/438819) already existed, OpenSSL's license is not [compatible](https://en.wikipedia.org/wiki/License_compatibility) with the GPL;[^o12] thus software under the GPL, such as GNU software, could not use OpenSSL without making a [GPL linking exception](https://en.wikipedia.org/wiki/GPL_linking_exception).

### License {#License}

The GnuTLS library was [licensed](https://en.wikipedia.org/wiki/Software_license) originally under the [GNU Lesser General Public License](https://en.wikipedia.org/wiki/GNU_Lesser_General_Public_License) v2, while included applications to use the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License).

In August 2011 the library was updated to the [LGPLv3](https://en.wikipedia.org/wiki/LGPLv3).[^o14] After it was noticed[^o15] that there were new [license compatibility](https://en.wikipedia.org/wiki/License_compatibility) problems introduced, especially with other [free software](https://en.wikipedia.org/wiki/Free_software) with the license change, after discussions the [license was downgraded](https://en.wikipedia.org/wiki/Relicensing) again to LGPLv2.1 in March 2013.[^o16]

### Split from GNU {#Split_from_GNU}

GnuTLS was created for the [GNU Project](https://en.wikipedia.org/wiki/GNU_Project),[^o18][^o19] but in December 2012 its maintainer, Nikos Mavrogiannopoulos, dissociated the project from GNU after policy disputes with the [Free Software Foundation](https://en.wikipedia.org/wiki/Free_Software_Foundation).[^o18][^o19] [Richard Stallman](https://en.wikipedia.org/wiki/Richard_Stallman) opposed this move and suggested [forking](https://en.wikipedia.org/wiki/Fork_%28software%29) the project instead.[^o20] Soon afterward, developer Paolo Bonzini ended his maintainership of GNU [Sed](https://en.wikipedia.org/wiki/Sed) and [Grep](https://en.wikipedia.org/wiki/Grep), expressing concerns similar to those of GnuTLS maintainer Mavrogiannopoulos.[^o21]
