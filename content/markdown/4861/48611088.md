# Conglomerate (mathematics)

::: {#o1 .subject cue=lead name="Conglomerate"}

In [mathematics](wikipedia://en/18831), in the framework of a one-universe foundation for [category theory](wikipedia://en/5869),[^o10][^o11] the term **conglomerate** is applied to arbitrary [sets](wikipedia://en/26691) as a contraposition to the distinguished sets that are elements of a [Grothendieck universe](wikipedia://en/1072144).[^o12][^o13][^o17][^o18][^o15][^o19]

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The most popular axiomatic set theories, [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC), [von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) (NBG), and [Morse–Kelley set theory](wikipedia://en/2693655) (MK), admit [non-conservative extensions](https://en.wikipedia.org/wiki/Non-conservative_extension) that arise after adding a supplementary axiom of existence of a [Grothendieck universe](wikipedia://en/1072144) $U$. An example of such an extension is the [Tarski–Grothendieck set theory](wikipedia://en/6105873), where an infinite hierarchy of Grothendieck universes is postulated.

The concept of conglomerate was created to deal with *"collections"* of [classes](wikipedia://en/20696), which is desirable in category theory so that each class can be considered as an element of a "more general collection", a conglomerate. Technically this is organized by changes in terminology: when a [Grothendieck universe](wikipedia://en/1072144) $U$ is added to the chosen axiomatic set theory ([ZFC](wikipedia://en/152214)/[NBG](wikipedia://en/528491)/[MK](wikipedia://en/2693655)) it is considered convenient[^o14][^o16]

- to apply the term "set" only to elements of $U$,
- to apply the term "class" only to subsets of $U$,
- to apply the term "conglomerate" to all sets (not necessary elements or subsets of $U$).

As a result, in this terminology, each set is a class, and each class is a conglomerate.

:::

## Corollaries {#Corollaries}

Formally this construction describes a model of the initial axiomatic set theory ([ZFC](https://en.wikipedia.org/wiki/ZFC)/[NBG](wikipedia://en/528491)/[MK](wikipedia://en/2693655)) in the extension of this theory ("ZFC/NBG/MK+[Grothendieck universe](wikipedia://en/1072144)") with $U$ as the universe.[^o10][^o11]

If the initial axiomatic set theory admits the idea of a [proper class](https://en.wikipedia.org/wiki/Proper_class) (i.e. an object that can't be an element of any other object, like the class $Set$ of all sets in NBG and in MK), then these objects (proper classes) are discarded from the consideration in the new theory ("NBG/MK+Grothendieck universe"). However, (not counting the possible problems caused by the supplementary axiom of existence of $U$) this in some sense does not lead to a loss of information about objects of the old theory (NBG or MK) since its representation as a model in the new theory ("NBG/MK+Grothendieck universe") means that what can be proved in NBG/MK about its usual objects called classes (including proper classes) can be proved as well in "NBG/MK+Grothendieck universe" about its classes (i.e. about subsets of $U$, including subsets that are not elements of $U$, which are analogs of proper classes from NBG/MK). At the same time, the new theory is not equivalent to the initial one, since some extra propositions about classes can be proved in "NBG/MK+Grothendieck universe" but not in NBG/MK.

::: {#o6 .definition kind=definition/notation cue=heading name="Terminology"}

## Terminology {#Terminology}

The change in terminology is sometimes called "conglomerate convention".[^o15] The first step, made by [Mac Lane](https://en.wikipedia.org/wiki/Mac_Lane),[^o10][^o11] is to apply the term "class" only to subsets of $U.$ Mac Lane does not redefine existing set-theoretic terms; rather, he works in a set theory without classes (ZFC, not NBG/MK), calls members of $U$ "small sets", and states that the small sets and the classes satisfy the axioms of NBG. He does not need "conglomerates", since sets need not be small.

The term "conglomerate" lurks in reviews of the 1970s and 1980s on [Mathematical Reviews](wikipedia://en/1485646)[^o7] without definition, explanation or reference, and sometimes in papers.[^o8]

While the conglomerate convention is in force, it must be used exclusively in order to avoid ambiguity; that is, conglomerates should not be called “sets” in the usual fashion of ZFC.[^o15]
