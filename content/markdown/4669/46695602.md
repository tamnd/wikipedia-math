# Asano contraction

::: {#o1 .subject cue=lead name="Asano contraction"}

In [complex analysis](wikipedia://en/5759), a discipline in mathematics, and in [statistical physics](https://en.wikipedia.org/wiki/Statistical_physics), the **Asano contraction** or **Asano–Ruelle contraction** is a transformation on a separately affine [multivariate polynomial](https://en.wikipedia.org/wiki/Multivariate_polynomial). It was first presented in 1970 by Taro Asano to prove the [Lee–Yang theorem](wikipedia://en/19661214) in the [Heisenberg spin model](https://en.wikipedia.org/wiki/Heisenberg_model_%28quantum%29) case. This also yielded a simple proof of the Lee–Yang theorem in the [Ising model](wikipedia://en/292744). [David Ruelle](https://en.wikipedia.org/wiki/David_Ruelle) proved a general theorem relating the location of the roots of a contracted polynomial to that of the original. Asano contractions have also been used to study polynomials in [graph theory](wikipedia://en/12401).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\Phi(z_1,z_2,\ldots,z_n)$ be a polynomial which, when viewed as a function of only one of these variables is an [affine function](wikipedia://en/17570). Such functions are called separately affine. For example, $a+bz_1+cz_2+dz_1z_2$ is the general form of a separately affine function in two variables. Any separately affine function can be written in terms of any two of its variables as $\Phi(z_i,z_j)=a+bz_i+cz_j+dz_iz_j$. The Asano contraction $(z_i,z_j)\mapsto z$ sends $\Phi$ to $\tilde{\Phi}=a+dz$.[^o4]

:::

## Location of zeroes {#Location_of_zeroes}

Asano contractions are often used in the context of theorems about the location of roots. Asano originally used them because they preserve the property of having no roots when all the variables have magnitude greater than 1.[^o6] Ruelle provided a more general relationship which allowed the contractions to be used in more applications.[^o7] He showed that if there are [closed sets](wikipedia://en/47279) $M_1,M_2,\ldots,M_n$ not containing 0 such that $\Phi$ cannot vanish unless $z_i\in M_i$ for some index $i$, then $\tilde{\Phi}=((z_j,z_k)\mapsto z)(\Phi)$ can only vanish if $z_i\in M_i$ for some index $i\neq k,j$ or $z\in -M_jM_k$ where $-M_jM_k=\{-ab;a\in M_j,b\in M_k\}$.[^o8] Ruelle and others have used this theorem to relate the zeroes of the partition function to zeroes of the partition function of its subsystems.

::: {#o10 .application cue=heading name="Use"}

## Use {#Use}

Asano contractions can be used in statistical physics to gain information about a system from its subsystems. For example, suppose we have a system with a finite set $\Lambda$ of particles with [magnetic spin](wikipedia://en/19593829) either 1 or −1. For each site, we have a complex variable $z_x$ Then we can define a separately affine polynomial $P(z_\Lambda)=\sum_{X\subseteq \Lambda}c_X z^{X}$ where $z^X=\prod_{x\in X}z_x$, $c_X=e^{-\beta U(X)}$ and $U(X)$ is the energy of the state where only the sites in $X$ have positive spin. If all the variables are the same, this is the [partition function](wikipedia://en/312252). Now if $\Lambda=\Lambda_1\cap\Lambda_2$, then $P(z_\Lambda)$ is obtained from $P(z_{\Lambda_1})P(z_{\Lambda_2})$ by contracting the variable attached to identical sites.[^o8] This is because the Asano contraction essentially eliminates all terms where the spins at a site are distinct in the $P(z_{\Lambda_1})$ and $P(z_{\Lambda_2})$.

Ruelle has also used Asano contractions to find information about the location of roots of a generalization of [matching polynomials](wikipedia://en/24956783) which he calls graph-counting polynomials. He assigns a variable to each edge. For each vertex, he computes a [symmetric polynomial](wikipedia://en/1440207) in the variables corresponding to the edges incident on that vertex. The symmetric polynomial contains the terms of degree equal to the allowed degree for that node. He then multiplies these symmetric polynomials together and uses Asano contractions to only keep terms where the edge is present at both its endpoints. By using the [Grace–Walsh–Szegő theorem](wikipedia://en/40334623) and intersecting all the sets that can be obtained, Ruelle gives sets containing the roots of several types of these symmetric polynomials. Since the graph-counting polynomial was obtained from these by Asano contractions, most of the remaining work is computing products of these sets.[^o11]
