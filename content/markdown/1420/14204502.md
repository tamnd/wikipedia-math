# (a,b,0) class of distributions

::: {#o1 .subject cue=lead name="(a,b,0) class of distributions"}

In [probability theory](wikipedia://en/23542), a member of the **(*a*, *b*, 0) class of distributions** is any distribution of a [discrete random variable](https://en.wikipedia.org/wiki/Discrete_random_variable) *N* whose values are nonnegative integers whose probability mass function satisfies the recurrence formula (the [Panjer recursion](wikipedia://en/13739701))

:::

$$\frac{p_k}{p_{k-1}} = a + \frac{b}{k}, \qquad k = 1, 2, 3, \dots$$

for some real numbers *a* and *b*, where $p_k = P(N = k)$.

The (a,b,0) class of distributions is also known as the Panjer,[^o16][^o14] the [Poisson-type](https://en.wikipedia.org/wiki/Poisson-type_random_measures) or the Katz family of distributions,[^o15][^o17] and may be retrieved through the [Conway–Maxwell–Poisson distribution](wikipedia://en/15845763).

Only the [Poisson](wikipedia://en/23009144), [binomial](wikipedia://en/3876) and [negative binomial](wikipedia://en/45177) distributions satisfy the full form of this relationship. These are also the three discrete distributions among the six members of the [natural exponential family with quadratic variance functions](wikipedia://en/9413032#Quadratic_variance_functions) (NEF–QVF).

More general distributions can be defined by fixing some initial values of *p<sub>j</sub>* and applying the recursion to define subsequent values. This can be of use in fitting distributions to empirical data. However, some further well-known distributions are available if the recursion above need only hold for a restricted range of values of *k*:[^o11] for example the [logarithmic distribution](wikipedia://en/1119231) and the discrete [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29).

The (*a*, *b*, 0) class of distributions has important applications in [actuarial science](wikipedia://en/189373) in the context of loss models.[^o12]

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Sundt[^o13] proved that only the [binomial distribution](wikipedia://en/3876), the [Poisson distribution](wikipedia://en/23009144) and the [negative binomial distribution](wikipedia://en/45177) belong to this class of distributions, with each distribution being represented by a different sign of *a*. Furthermore, it was shown by Fackler[^o14] that there is a universal formula for all three distributions, called the **(united) Panjer distribution**.

The more usual parameters of these distributions are determined by both *a* and *b*. The properties of these distributions in relation to the present class of distributions are summarised in the following table. Note that $W_N(x)\,$ denotes the [probability generating function](wikipedia://en/236841).

::: {#o4 .table cue=table}

| Distribution | $P[N=k]\,$ | $a\,$ | $b \,$ | $p_0\,$ | $W_N(x)\,$ | $\operatorname E[N]\,$ | $\operatorname{Var}(N)\,$ |
|---|---|---|---|---|---|---|---|
| [Binomial](wikipedia://en/3876) | $\binom{n}{k} p^k (1-p)^{n-k}$ | $\frac{-p}{1-p}$ | $\frac{p(n+1)}{1-p}$ | $(1-p)^n\,$ | $(px+(1-p))^{n} \,$ | $np\,$ | $np(1-p) \,$ |
| [Poisson](wikipedia://en/23009144) | $e^{-\lambda}\frac{ \lambda^k}{k!}\,$ | $0\,$ | $\lambda \,$ | $e^{- \lambda}\,$ | $e^{\lambda(x-1)} \,$ | $\lambda\,$ | $\lambda \,$ |
| [Negative binomial](wikipedia://en/45177) | $\frac{\Gamma(r+k)}{k!\,\Gamma(r)}\,p^r\,(1-p)^k \,$ | $1-p\,$ | $(1-p)(r-1)\,$ | $p^r \,$ | $\left( \frac{p}{1 - x(1-p)}\right) ^r \,$ | $\frac{r(1-p)}{p} \,$ | $\frac{r(1-p)}{p^2} \,$ |
| Panjer distribution | $\left( 1+\frac{\lambda}{\alpha} \right)^{-\alpha} \frac{\lambda^k}{k!} \prod_{i=0}^{k-1}\frac{\alpha+i}{\alpha+\lambda} \,$ | $\frac{\lambda}{\alpha+\lambda}\,$ | $\frac{(\alpha-1)\lambda}{\alpha+\lambda}\,$ | $\left( 1+\frac{\lambda}{\alpha} \right)^{-\alpha} \,$ | $\left( 1-\frac{\lambda}{\alpha}(x-1)\right)^{-\alpha} \,$ | $\lambda \,$ | $\lambda \left( 1 + \frac{\lambda}{\alpha} \right) \,$ |

:::

Note that the Panjer distribution reduces to the Poisson distribution in the limit case $\alpha \rightarrow \pm\infty$; it coincides with the negative binomial distribution for positive, finite real numbers $\alpha\in \mathbb{R}_{>0}$, and it equals the binomial distribution for negative integers $-\alpha \in \mathbb{N}$.

:::

## Plotting {#Plotting}

An easy way to quickly determine whether a given sample was taken from a distribution from the (*a*,*b*,0) class is by graphing the ratio of two consecutive observed data (multiplied by a constant) against the *x*-axis.

By multiplying both sides of the recursive formula by $k$, you get

$$k \, \frac{p_k}{p_{k-1}} = ak + b,$$

which shows that the left side is obviously a linear function of $k$. When using a sample of $n$ data, an approximation of the $p_k$'s need to be done. If $n_k$ represents the number of observations having the value $k$, then $\hat{p}_k = \frac{n_k}{n}$ is an [unbiased](https://en.wikipedia.org/wiki/Estimator_bias) estimator of the true $p_k$.

Therefore, if a linear trend is seen, then it can be assumed that the data is taken from an (*a*,*b*,0) distribution. Moreover, the [slope](wikipedia://en/29368) of the function would be the parameter $a$, while the ordinate at the origin would be $b$.
