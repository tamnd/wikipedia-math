# Absorbing element

::: {#o1 .subject cue=lead name="Absorbing element"}

In [mathematics](wikipedia://en/18831), an **absorbing element** (or **annihilating element**) is a special type of element of a [set](wikipedia://en/26691) with respect to a [binary operation](wikipedia://en/3948) on that set. The result of combining an absorbing element with any element of the set is the absorbing element itself. In [semigroup](wikipedia://en/27799) theory, the absorbing element is called a **[zero element](wikipedia://en/27799#Identity_and_zero)**[^n1][^n2] because there is no risk of confusion with [other notions of zero](wikipedia://en/3476379), with the notable exception: under additive notation *zero* may, quite naturally, denote the neutral element of a monoid. In this article "zero element" and "absorbing element" are synonymous.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, let $(S,*)$ be a set $S$ with a closed binary operation $*$ on it (known as a [magma](wikipedia://en/141916)). A **zero element** (or an **absorbing**/**annihilating element**) is an element $z$ such that for all $s$ in $S$, $z*s=s*z=z$. This notion can be refined to the notions of **left zero**, where one requires only that $z*s=z$, and **right zero**, where $s*z=z$.[^n2]

Absorbing elements are particularly interesting for [semigroups](wikipedia://en/27799), especially the multiplicative semigroup of a [semiring](wikipedia://en/371468). In the case of a semiring with $0$, the definition of an absorbing element is sometimes relaxed so that it is not required to absorb $0$; otherwise, $0$ would be the only absorbing element.[^n3]

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If a magma has both a left zero $z$ and a right zero $z'$, then it has a zero, since $z=z*z'=z'$.
- A magma can have at most one zero element.

:::

::: {#o11 .example cue=heading name="Examples"}

## Examples {#Examples}

- The most well known example of an absorbing element comes from elementary algebra, where any number multiplied by zero equals zero. Zero is thus an absorbing element.
- The zero of any [ring](wikipedia://en/48404) is also an absorbing element. For an element $r$ of a ring $R$, $r0=r(0+0)=r0+r0$, so $0=r0$, as zero is the unique element $a$ for which $r-r=a$ for any $r$ in the ring $R$. This property holds true also in a [rng](https://en.wikipedia.org/wiki/Rng_%28mathematics%29) since multiplicative identity isn't required.
- [Floating point](https://en.wikipedia.org/wiki/Floating_point) arithmetics as defined in IEEE-754 standard contains a special value called Not-a-Number ($\mathrm{NaN}$). It is an absorbing element for every operation; i.e., $x+\mathrm{NaN}=\mathrm{NaN}+x=\mathrm{NaN}$, $x-\mathrm{NaN}=\mathrm{NaN}-x=\mathrm{NaN}$, etc.
- The set of [binary relations](https://en.wikipedia.org/wiki/Binary_relations) over a set $X$, together with the [composition of relations](wikipedia://en/7472170) forms a [monoid](wikipedia://en/19652) with zero, where the zero element is the [empty relation](https://en.wikipedia.org/wiki/Empty_relation) ([empty set](wikipedia://en/9566)).
- The closed interval $H=[0,1]$ with $x*y=\min(x,y)$ is also a monoid with zero, and the zero element is $0$.
