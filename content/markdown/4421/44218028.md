# Schröder–Bernstein theorem

::: {#o1 .subject cue=lead name="Schröder–Bernstein theorem"}

In [set theory](wikipedia://en/27553), the **Schröder–Bernstein theorem** states that, if there exist [injective functions](wikipedia://en/45196) $f : A \to B$ and $g : B \to A$ between the [sets](wikipedia://en/26691) $A$ and $B$, then there exists a [bijective](wikipedia://en/3942) function $h : A \to B$.

:::

In terms of the [cardinality](wikipedia://en/6174) of the two sets, this classically implies that if $\lvert A\rvert \le \lvert B\rvert$ and $\lvert B\rvert \le \lvert A\rvert$, then $\lvert A\rvert = \lvert B\rvert$; that is, $A$ and $B$ are [equipotent](https://en.wikipedia.org/wiki/Equipotent). This is a useful feature in the ordering of [cardinal numbers](wikipedia://en/6173).

The theorem is named after [Ernst Schröder](wikipedia://en/448015) and [Felix Bernstein](wikipedia://en/2597142). It is also known as the **Cantor–Bernstein theorem** or **Cantor–Schröder–Bernstein theorem**, after [Georg Cantor](wikipedia://en/12216), who first published it (albeit without proof).

::: {#o3 .proof cue=heading name="Proof"}

## Proof {#Proof}

*Image: Cantor-Bernstein.png.* König's definition of a bijection \#00c000:*A* → *B* from given example injections \#c00000:*A* → *B* and \#0000c0:*B* → *A*. An element in *A* and *B* is denoted by a number and a letter, respectively. The sequence 3 → e → 6 → ... is an *A*-stopper, leading to the definitions \#00c000(3) = \#c00000(3) = *e*, \#00c000(6) = \#c00000(6), .... The sequence *d* → 5 → *f* → ... is a *B*-stopper, leading to \#00c000(5) = \#0000c0<sup>−1</sup>(5) = *d*, .... The sequence ... → *a* → 1 → *c* → 4 → ... is doubly infinite, leading to \#00c000(1) = \#0000c0<sup>−1</sup>(1) = *a*, \#00c000(4) = \#0000c0<sup>−1</sup>(4) = *c*, .... The sequence *b* → 2 → *b* is cyclic, leading to \#00c000(2) = \#0000c0<sup>−1</sup>(2) = *b*.

The following proof is attributed to [Julius König](https://en.wikipedia.org/wiki/Julius_König).[^o4]

Assume without loss of generality that *A* and *B* are [disjoint](https://en.wikipedia.org/wiki/Disjoint_set). For any *a* in *A* or *b* in *B* we can form a unique two-sided sequence of elements that are alternately in *A* and *B*, by repeatedly applying $f$ and $g^{-1}$ to go from *A* to *B* and $g$ and $f^{-1}$ to go from *B* to *A* (where defined; the inverses $f^{-1}$ and $g^{-1}$ are understood as [partial functions](wikipedia://en/23577).)

$$\cdots \rightarrow f^{-1}(g^{-1}(a)) \rightarrow g^{-1}(a) \rightarrow a \rightarrow f(a) \rightarrow g(f(a)) \rightarrow \cdots$$

For any particular *a*, this sequence may terminate to the left or not, at a point where $f^{-1}$ or $g^{-1}$ is not defined.

By the fact that $f$ and $g$ are injective functions, each *a* in *A* and *b* in *B* is in exactly one such sequence to within identity: if an element occurs in two sequences, all elements to the left and to the right must be the same in both, by the definition of the sequences. Therefore, the sequences form a [partition](wikipedia://en/340240) of the (disjoint) union of *A* and *B*. Hence it suffices to produce a bijection between the elements of *A* and *B* in each of the sequences separately, as follows:

Call a sequence an *A-stopper* if it stops at an element of *A*, or a *B-stopper* if it stops at an element of *B*. Otherwise, call it *[doubly infinite](https://en.wikipedia.org/wiki/Doubly_infinite)* if all the elements are distinct or *cyclic* if it repeats. See the picture for examples.

- For an *A-stopper*, the function $f$ is a bijection between its elements in *A* and its elements in *B*.
- For a *B-stopper*, the function $g$ is a bijection between its elements in *B* and its elements in *A*.
- For a *doubly infinite* sequence or a *cyclic* sequence, either $f$ or $g$ will do ($g$ is used in the picture).

::: {#o6 .statement kind=statement/corollary cue=named-heading name="Corollary for surjective pair"}

### Corollary for surjective pair {#Corollary_for_surjective_pair}

If we assume the axiom of choice, then a pair of surjective functions $f$ and $g$ also implies the existence of a bijection. We construct an injective function $h : B \to A$ from $f^{-1}$ by picking a single element from the inverse image of each point in $B.$ The surjectivity of $f$ guarantees the existence of at least one element in each such inverse image. We do the same to obtain an injective function $k : A \to B$ from $g^{-1}.$ The Schröder–Bernstein theorem then can be applied to the injections *h* and *k*.

:::

::: {#o8 .example cue=heading name="Examples"}

### Examples {#Examples}

**Bijective function from $[0,1]\to[0,1)$**

*Note: $[0,1)$ is the half open set from 0 to 1, including the boundary 0 and excluding the boundary 1.*

Let $f:[0,1]\to[0,1)$ with $f(x)=x/2$; and $g:[0,1)\to[0,1]$ with $g(x)=x$; the two injective functions.

In line with that procedure $C_0=\{1\}, \; C_k=\{2^{-k}\}, \; C = \bigcup_{k=0}^\infty C_k = \{1, \tfrac{1}{2}, \tfrac{1}{4}, \tfrac{1}{8}, ... \}$

Then $h(x) = \begin{cases} \frac{x}{2} , & \mathrm{for}\ x \in C \\x , & \mathrm{for}\ x \in [0, 1] \smallsetminus C\end{cases}$ is a bijective function from $[0,1]\to[0,1)$.

**Bijective function from $[0,2)\to[0,1)^2$**

Let $f:[0,2)\to[0,1)^2$ with $f(x)=(x/2;0)$;

Then for $(x;y)\in[0,1)^2$ one can use the expansions $x= \sum_{k=1}^\infty a_k\cdot 10^{-k}$ and $y= \sum_{k=1}^\infty b_k\cdot 10^{-k}$ with $a_k, b_k \in \{0, 1, ..., 9\}$

and now one can set $g(x;y) = \sum_{k=1}^\infty (10\cdot a_k+ b_k)\cdot 10^{-2k}$ which defines an injective function $[0,1)^2 \to [0,2)$. (Example: $g(\tfrac{1}{3}; \tfrac{2}{3}) = 0.363636...= \tfrac{4}{11}$)

And therefore a bijective function $h$ can be constructed with the use of $f(x)$ and $g^{-1}(x)$.

In this case $C_0=[1,2)$ is still easy but already $C_1=g(f(C_0)) = g(\{ (x;0)|x\in [\tfrac{1}{2}, 1)\,\})$ gets quite complicated.

Note: Of course there's a more simple way by using the (already bijective) function definition $g_2(x;y) = 2\cdot \sum_{k=1}^\infty (10\cdot a_k+ b_k)\cdot 10^{-2k}$. Then $C$ would be the empty set and $h(x)=g_2^{-1}(x)$ for all x.

:::

## History {#History}

The traditional name "Schröder–Bernstein" is based on two proofs published independently in 1898. Cantor is often added because he first stated the theorem in 1887, while Schröder's name is often omitted because his proof turned out to be flawed while the name of [Richard Dedekind](wikipedia://en/23475106), who first proved it, is not connected with the theorem. According to Bernstein, Cantor had suggested the name *equivalence theorem* (Äquivalenzsatz).[^o10]

*Image: CantorEquivalenceTheorem1887b.gif.* Cantor's first statement of the theorem (1887)[^o11]

- **1887** **Cantor** publishes the theorem, however without proof.[^o11][^o10]
- **1887** On July 11, **Dedekind** proves the theorem (not relying on the [axiom of choice](wikipedia://en/840))[^o12] but neither publishes his proof nor tells Cantor about it. [Ernst Zermelo](wikipedia://en/178655) discovered Dedekind's proof and in 1908[^o13] he publishes his own proof based on the *chain theory* from Dedekind's paper *Was sind und was sollen die Zahlen?*[^o10][^o14]
- **1895** **Cantor** states the theorem in his first paper on set theory and transfinite numbers. He obtains it as an easy consequence of the linear order of cardinal numbers.[^o15][^o16][^o17] However, he could not prove the latter theorem, which is shown in 1915 to be equivalent to the [axiom of choice](wikipedia://en/840) by [Friedrich Moritz Hartogs](https://en.wikipedia.org/wiki/Friedrich_Moritz_Hartogs).[^o10][^o18]
- **1896** **Schröder** announces a proof (as a corollary of a theorem by [Jevons](wikipedia://en/207021)).[^o19]
- **1897** **Bernstein**, a 19-year-old student in Cantor's Seminar, presents his proof.[^o20][^o21]
- **1897** Almost simultaneously, but independently, **Schröder** finds a proof, subsequently shown to be flawed (see below).[^o20]
- **1897** After a visit by Bernstein, **Dedekind** independently proves the theorem a second time.
- **1898** **Bernstein'**s proof (not relying on the axiom of choice) is published by [Émile Borel](wikipedia://en/356161) in his book on functions.[^o22] (Communicated by Cantor at the 1897 [International Congress of Mathematicians](wikipedia://en/627842) in Zürich.) In the same year, the proof also appears in **Bernstein'**s dissertation.[^o23][^o10]
- **1898** **Schröder** publishes his proof[^o24] which, however, is shown to be faulty by [Alwin Reinhold Korselt](https://en.wikipedia.org/wiki/Alwin_Reinhold_Korselt) in 1902 (just before Schröder's death),[^o25] (confirmed by Schröder),[^o10][^o26] but Korselt's paper is published only in 1911.

Both proofs of Dedekind are based on his famous 1888 memoir *Was sind und was sollen die Zahlen?* and derive it as a corollary of a proposition equivalent to statement C in Cantor's paper,[^o15] which reads *A* ⊆ *B* ⊆ *C* and $\lvert A\rvert$ = $\lvert C\rvert$ implies $\lvert A\rvert$ = $\lvert B\rvert$ = $\lvert C\rvert$. Cantor observed this property as early as 1882/83 during his studies in set theory and transfinite numbers and was therefore (implicitly) relying on the [axiom of choice](wikipedia://en/840).

## Prerequisites {#Prerequisites}

The 1895 proof by [Cantor](wikipedia://en/12216) relied, in effect, on the [axiom of choice](wikipedia://en/840) by inferring the result as a [corollary](wikipedia://en/168865) of the [well-ordering theorem](wikipedia://en/33458).[^o16][^o17] However, König's proof given above shows that the result can also be proved without using the axiom of choice.

On the other hand, König's proof uses the principle of [excluded middle](https://en.wikipedia.org/wiki/Excluded_middle) to draw a conclusion through case analysis. As such, the above proof is not a constructive one. In fact, in a [constructive set theory](wikipedia://en/5042360) such as [intuitionistic](wikipedia://en/19513) set theory ${\mathsf{IZF}}$, which adopts the full [axiom of separation](https://en.wikipedia.org/wiki/Axiom_of_separation) but dispenses with the principle of excluded middle, assuming the Schröder–Bernstein theorem implies the latter.[^o28] In turn, there is no proof of König's conclusion in this or weaker constructive theories. Thus, the theorem is not provable in intuitionistic set theory and is generally not accepted as constructively valid.[^o29]

There is also a proof which uses [Tarski's fixed point theorem](wikipedia://en/181417).[^o30]
