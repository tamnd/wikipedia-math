# Unicoherent space

::: {#o1 .subject cue=lead name="Unicoherent space"}

In mathematics, a **unicoherent space** is a [topological space](wikipedia://en/30450) $X$ that is [connected](wikipedia://en/6233) and in which the following property holds:

:::

For any closed, connected $A, B \subset X$ with $X=A \cup B$, the intersection $A \cap B$ is connected.

For example, any closed interval on the real line is unicoherent, but a circle is not.

If a unicoherent space is more strongly hereditarily unicoherent (meaning that every subcontinuum is unicoherent) and [arcwise connected](wikipedia://en/6233#Path_connectedness), then it is called a [dendroid](wikipedia://en/8248350). If in addition it is [locally connected](wikipedia://en/6959754) then it is called a [dendrite](wikipedia://en/8248391). The [Phragmen–Brouwer theorem](wikipedia://en/34790475) states that, for locally connected spaces, unicoherence is equivalent to a separation property of the closed sets of the space.
