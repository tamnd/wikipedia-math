# List of computability and complexity topics

::: {#o1 .subject cue=lead name="List of computability and complexity topics"}

This is a list of **computability and complexity topics**, by Wikipedia page.

:::

[Computability theory](wikipedia://en/155414) is the part of the theory of [computation](wikipedia://en/5926) that deals with what can be computed, in principle. [Computational complexity theory](wikipedia://en/7543) deals with how hard computations are, in quantitative terms, both with upper bounds ([algorithms](wikipedia://en/775) whose complexity in the worst cases, as use of computing resources, can be estimated), and from below (proofs that no procedure to carry out some task can be very fast).
