# Waldegrave problem

::: {#o1 .subject cue=lead name="Waldegrave problem"}

In [game theory](wikipedia://en/11924), the **Waldegrave problem** is a problem first described in the second edition of [Pierre Raymond de Montmort](https://en.wikipedia.org/wiki/Pierre_Raymond_de_Montmort)\`s *[Essay d'analyse sur les jeux de hazard](wikipedia://en/48314912)*, which is the first discussion of a [mixed strategy](https://en.wikipedia.org/wiki/Mixed_strategy) to derive a [solution](wikipedia://en/1601457) in game theory. Montmort originally called Waldegrave's Problem the *Problème de la Poulle* or the Problem of the Pool. He provides a [minimax](wikipedia://en/19589) mixed strategy solution to a two-person version of the card game [le her](https://en.wikipedia.org/wiki/Le_her).

:::

The general description of the problem is as follows: Suppose there are n+1 players with each player putting one unit into the pot or pool. The first two players play each other and the winner plays the third player. The loser of each game puts one unit into the pot. Play continues in like fashion through all the players until one of the players has beaten all the others in succession. The original problem, stated in a letter dated 10 April 1711, from Montmort to [Nicholas Bernoulli](wikipedia://en/1151030) is for n = 2 and is attributed to *M. de Waldegrave*. The problem, according to Montmort, is to find the expectation of each player and the probability that the pool will be won within a specified number of games.[^n1]
