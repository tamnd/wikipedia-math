# Killed process

::: {#o1 .subject cue=lead name="Killed process"}

In [probability theory](wikipedia://en/23542) — specifically, in [stochastic analysis](https://en.wikipedia.org/wiki/Stochastic_processes) — a **killed process** is a stochastic process that is forced to assume an undefined or "killed" state at some (possibly random) time.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* : *T* × Ω → *S* be a stochastic process defined for "times" *t* in some [ordered](https://en.wikipedia.org/wiki/Ordered_set) [index set](wikipedia://en/393055) *T*, on a [probability space](wikipedia://en/43325) (Ω, Σ, **P**), and taking values in a [measurable space](wikipedia://en/43333) *S*. Let *ζ* : Ω → *T* be a random time, referred to as the **killing time**. Then the **killed process** *Y* associated to *X* is defined by

$$Y_{t} = X_{t} \mbox{ for } t < \zeta,$$

and *Y*<sub>*t*</sub> is left undefined for *t* ≥ *ζ*. Alternatively, one may set *Y*<sub>*t*</sub> = *c* for *t* ≥ *ζ*, where *c* is a "coffin state" not in *S*.

:::
