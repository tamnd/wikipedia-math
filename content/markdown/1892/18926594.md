# Hrushovski construction

::: {#o1 .subject cue=lead name="Hrushovski construction"}

In [model theory](wikipedia://en/19858), a branch of [mathematical logic](wikipedia://en/19636), the **Hrushovski construction** generalizes the [Fraïssé limit](https://en.wikipedia.org/wiki/Age_%28model_theory%29) by working with a notion of *strong substructure* $\leq$ rather than $\subseteq$. It can be thought of as a kind of "model-theoretic forcing", where a (usually) stable structure is created, called the *generic* or *rich* [^o2] model. The specifics of $\leq$ determine various properties of the generic, with its geometric properties being of particular interest. It was initially used by [Ehud Hrushovski](wikipedia://en/3132981) to generate a stable structure with an "exotic" geometry, thereby refuting Zil'ber's Conjecture.

:::

::: {#o4 .statement kind=statement/conjecture cue=named-heading name="Three conjectures"}

## Three conjectures {#Three_conjectures}

The initial applications of the Hrushovski construction refuted two conjectures and answered a third question in the negative. Specifically, we have:

- **Lachlan's Conjecture.** Any stable $\aleph_0$-categorical theory is totally transcendental.[^o5]
- **Zil'ber's Conjecture.** Any uncountably [categorical theory](wikipedia://en/1096396) is either locally modular or interprets an [algebraically closed field](wikipedia://en/1018).[^o6]
- **Cherlin's Question.** Is there a maximal (with respect to expansions) strongly minimal set?

:::

::: {#o8 .definition kind=definition/construction cue=heading name="The construction"}

## The construction {#The_construction}

Let *L* be a finite relational language. Fix **C** a class of *finite* *L*-structures which are closed under isomorphisms and substructures. We want to strengthen the notion of substructure; let $\leq$ be a relation on pairs from **C** satisfying:

- $A \leq B$ implies $A \subseteq B.$
- $A \subseteq B \subseteq C$ and $A \leq C$ implies $A \leq B$
- $\varnothing \leq A$ for all $A \in \mathbf{C}.$
- $A \leq B$ implies $A \cap C \leq B \cap C$ for all $C \in \mathbf{C}.$
- If $f\colon A \to A'$ is an isomorphism and $A \leq B$, then $f$ extends to an isomorphism $B \to B'$ for some superset of $A'$ with $A' \leq B'.$

::: {#o9 .definition cue=inline-head name="Definition"}

**Definition.** An embedding $f: A \hookrightarrow D$ is *strong* if $f(A) \leq D.$

:::

::: {#o10 .definition cue=inline-head name="Definition"}

**Definition.** The pair $(\mathbf{C}, \leq)$ has the *amalgamation property* if $A \leq B_1, B_2$ then there is a $D \in \mathbf{C}$ so that each $B_i$ embeds strongly into $D$ with the same image for $A.$

:::

::: {#o11 .definition cue=inline-head name="Definition"}

**Definition.** For infinite $D$ and $A \in \mathbf{C},$ we say $A \leq D$ iff $A \leq X$ for $A \subseteq X \subseteq D, X \in \mathbf{C}.$

:::

::: {#o12 .definition cue=inline-head name="Definition"}

**Definition.** For any $A \subseteq D,$ the *closure* of $A$ in $D,$ denoted by $\operatorname{cl}_D(A),$ is the smallest superset of $A$ satisfying $\operatorname{cl}(A) \leq D.$

:::

::: {#o13 .definition cue=inline-head name="Definition"}

**Definition.** A countable structure $G$ is *$(\mathbf{C}, \leq)$-generic* if:

- For $A \subseteq_\omega G, A \in \mathbf{C}.$
- For $A \leq G,$ if $A \leq B$ then there is a strong embedding of $B$ into $G$ over $A.$
- $G$ has finite closures: for every $A \subseteq_\omega G, \operatorname{cl}_G(A)$ is finite.

:::

::: {#o14 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** If $(\mathbf{C},\leq)$ has the [amalgamation property](wikipedia://en/11092492), then there is a unique $(\mathbf{C},\leq)$-generic.

The existence proof proceeds in imitation of the existence proof for Fraïssé limits. The uniqueness proof comes from an easy back and forth argument.

:::
