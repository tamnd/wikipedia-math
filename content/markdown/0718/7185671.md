# Uniformly Cauchy sequence

::: {#o1 .subject cue=lead name="Uniformly Cauchy sequence"}

In [mathematics](wikipedia://en/18831), a [sequence](wikipedia://en/27838) of [functions](wikipedia://en/185427) $\{f_{n}\}$ from a set *S* to a metric space *M* is said to be **uniformly Cauchy**[^o2] if:

:::

- For all $\varepsilon > 0$, there exists $N>0$ such that for all $x\in S$: $d(f_{n}(x), f_{m}(x)) < \varepsilon$ whenever $m, n > N$.

Another way of saying this is that $d_u (f_{n}, f_{m}) \to 0$ as $m, n \to \infty$, where the uniform distance $d_u$ between two functions is defined by

$$d_{u} (f, g) := \sup_{x \in S} d (f(x), g(x)).$$

## Convergence criteria {#Convergence_criteria}

A sequence of functions {*f*<sub>n</sub>} from *S* to *M* is **pointwise** Cauchy if, for each *x* ∈ *S*, the sequence {*f*<sub>n</sub>(*x*)} is a [Cauchy sequence](wikipedia://en/6085) in *M*. This is a weaker condition than being uniformly Cauchy.

In general a sequence can be pointwise Cauchy and not pointwise convergent, or it can be uniformly Cauchy and not uniformly convergent. Nevertheless, if the metric space *M* is [complete](wikipedia://en/7832), then any pointwise Cauchy sequence converges pointwise to a function from *S* to *M*. Similarly, any uniformly Cauchy sequence will tend [uniformly](wikipedia://en/50652) to such a function.

The uniform Cauchy property is frequently used when the *S* is not just a set, but a [topological space](wikipedia://en/30450), and *M* is a complete metric space. The following theorem holds:

- Let *S* be a topological space and *M* a complete metric space. Then any uniformly Cauchy sequence of [continuous functions](wikipedia://en/6122) *f*<sub>n</sub> : *S* → *M* tends [uniformly](wikipedia://en/50652) to a unique continuous function *f* : *S* → *M*.

## Generalization to uniform spaces {#Generalization_to_uniform_spaces}

A [sequence](wikipedia://en/27838) of [functions](wikipedia://en/185427) $\{f_{n}\}$ from a set *S* to a [uniform space](wikipedia://en/32339) *U* is said to be **uniformly Cauchy** if:

- For any entourage *E* of *U*, there exists $N>0$ such that, for all $x\in S$, $(f_{n}(x), f_{m}(x))\in E$ whenever $m, n > N$.
