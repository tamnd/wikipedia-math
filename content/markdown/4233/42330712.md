# Subverted support

::: {#o1 .subject cue=lead name="Subverted support"}

**Subverted support** is a [logical fallacy](https://en.wikipedia.org/wiki/Logical_fallacy) of explanation which attempts to explain something that does not happen.[^o2]

:::

## Logical form {#Logical_form}

*X* happens because of *Y* (when *X* does not actually happen or exist)

## Exception {#Exception}

The fallacy is true if a preceding statement claims that whatever follows is true.
