# Ladder height process

::: {#o1 .subject cue=lead name="Ladder height process"}

In [probability theory](wikipedia://en/23542), the **ladder height process** is a record of the largest or smallest value a given [stochastic process](wikipedia://en/47895) has achieved up to the specified point in time.[^o2]

:::

The [Wiener-Hopf factorization](https://en.wikipedia.org/wiki/Wiener-Hopf_factorization) gives the transition probability kernel in the discrete time case.[^o3]
