# Naimark equivalence

::: {#o1 .subject cue=lead name="Naimark equivalence"}

In mathematical [representation theory](wikipedia://en/19378200), two [representations](wikipedia://en/12695) of a [group](wikipedia://en/19447) on [topological vector spaces](wikipedia://en/45752) are called **Naimark equivalent** (named after [Mark Naimark](https://en.wikipedia.org/wiki/Mark_Naimark)) if there is a closed bijective linear map between [dense subspaces](https://en.wikipedia.org/wiki/Dense_subspace) preserving the [group action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29).

:::
