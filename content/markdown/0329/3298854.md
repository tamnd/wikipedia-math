# Graph factorization

::: {#o1 .subject cue=lead name="Graph factorization"}

*Image: Desargues graph 3color edge.svg.* 1-factorization of the [Desargues graph](wikipedia://en/1578059): each color class is a 1-factor.

*Image: Petersen-graph-factors.svg.* The [Petersen graph](wikipedia://en/194926) can be partitioned into a 1-factor (red) and a 2-factor (blue). However, the graph is not 1-factorable.

::: {#o2 .problem cue=unsolved}

**Conjecture:** If *n* is odd and *k* ≥ *n*, then *G* is 1-factorable. If *n* is even and *k* ≥ *n* − 1 then *G* is 1-factorable.

:::

In [graph theory](wikipedia://en/12401), a **factor** of a [graph](wikipedia://en/325806) *G* is a [spanning subgraph](https://en.wikipedia.org/wiki/Spanning_subgraph), i.e., a subgraph that has the same vertex set as *G*. A ***k*-factor** of a graph is a spanning *k*-[regular](wikipedia://en/85821) subgraph, and a ***k*-factorization** partitions the edges of the graph into disjoint *k*-factors. A graph *G* is said to be ***k*-factorable** if it admits a *k*-factorization. In particular, a **1-factor** is a [perfect matching](wikipedia://en/44031), and a 1-factorization of a *k*-regular graph is a [proper edge coloring](wikipedia://en/690647) with *k* colors. A **2-factor** is a collection of disjoint [cycles](wikipedia://en/168609) that spans all vertices of the graph.

:::

## 1-factorization {#1-factorization}

If a graph is 1-factorable then it has to be a [regular graph](wikipedia://en/85821). However, not all regular graphs are 1-factorable. A *k*-regular graph is 1-factorable if it has [chromatic index](https://en.wikipedia.org/wiki/Chromatic_index) *k*; examples of such graphs include:

- Any regular [bipartite graph](wikipedia://en/244431).[^o4] [Hall's marriage theorem](wikipedia://en/186969) can be used to show that a *k*-regular bipartite graph contains a perfect matching. One can then remove the perfect matching to obtain a (*k* − 1)-regular bipartite graph, and apply the same reasoning repeatedly.
- Any [complete graph](wikipedia://en/85816) with an [even](wikipedia://en/143135) number of nodes (see below).[^o5]

However, there are also *k*-regular graphs that have chromatic index *k* + 1, and these graphs are not 1-factorable; examples of such graphs include:

- Any regular graph with an [odd](wikipedia://en/143135) number of nodes.
- The [Petersen graph](wikipedia://en/194926).

### Complete graphs {#Complete_graphs}

*Image: Complete-edge-coloring.svg.* 1-factorization of *K*<sub>8</sub> in which each 1-factor consists of an edge from the center to a vertex of a [heptagon](wikipedia://en/365349) together with all possible perpendicular edges

A 1-factorization of a [complete graph](wikipedia://en/85816) corresponds to pairings in a [round-robin tournament](https://en.wikipedia.org/wiki/Round-robin_tournament). The 1-factorization of complete graphs is a special case of [Baranyai's theorem](wikipedia://en/24011805) concerning the 1-factorization of complete [hypergraphs](wikipedia://en/232535).

One method for constructing a 1-factorization of a complete graph on an even number of vertices involves placing all but one of the vertices in a [regular polygon](wikipedia://en/333306), with the remaining vertex at the center. With this arrangement of vertices, one way of constructing a 1-factor of the graph is to choose an edge *e* from the center to a single polygon vertex together with all possible edges that lie on lines perpendicular to *e*. The 1-factors that can be constructed in this way form a 1-factorization of the graph.

The number of distinct 1-factorizations of *K*<sub>2</sub>, *K*<sub>4</sub>, *K*<sub>6</sub>, *K*<sub>8</sub>, ... is 1, 1, 6, 6240, 1225566720, 252282619805368320, 98758655816833727741338583040, ... .

::: {#o8 .statement kind=statement/conjecture cue=named-heading name="1-factorization conjecture"}

### 1-factorization conjecture {#1-factorization_conjecture}

Let *G* be a *k*-regular graph with 2*n* nodes. If *k* is sufficiently large, it is known that *G* has to be 1-factorable:

- If *k* = 2*n* − 1, then *G* is the complete graph *K*<sub>2*n*</sub>, and hence 1-factorable (see above).
- If *k* = 2*n* − 2, then *G* can be constructed by removing a perfect matching from *K*<sub>2*n*</sub>. Again, *G* is 1-factorable.
- (Chetwynd Hilton 1985) show that if *k* ≥ 12*n*/7, then *G* is 1-factorable.

The **1-factorization conjecture**[^o10] is a long-standing [conjecture](wikipedia://en/6138) that states that *k* ≈ *n* is sufficient. In precise terms, the conjecture is:

- If *n* is odd and *k* ≥ *n*, then *G* is 1-factorable. If *n* is even and *k* ≥ *n* − 1 then *G* is 1-factorable.

The [overfull conjecture](https://en.wikipedia.org/wiki/Overfull_conjecture) implies the 1-factorization conjecture. The conjecture was confirmed by Csaba, Kühn, Lo, Osthus and Treglown for sufficiently large *n*.[^o11]

:::

### Perfect 1-factorization {#Perfect_1-factorization}

A **perfect pair** from a 1-factorization is a pair of 1-factors whose union [induces](wikipedia://en/325802#Subgraphs) a [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle).

A **perfect 1-factorization** (P1F) of a graph is a 1-factorization having the property that every pair of 1-factors is a perfect pair. A perfect 1-factorization should not be confused with a perfect matching (also called a 1-factor).

In 1964, [Anton Kotzig](wikipedia://en/25648858) conjectured that every complete graph *K*<sub>2*n*</sub> where *n* ≥ 2 has a perfect 1-factorization. So far, it is known that the following graphs have a perfect 1-factorization:[^o13]

- the infinite family of complete graphs *K*<sub>2*p*</sub> where *p* is an odd [prime](wikipedia://en/23666) (by Anderson and also Nakamura, independently),
- the infinite family of complete graphs *K*<sub>*p*+1</sub> where *p* is an odd prime,
- and sporadic additional results, including *K*<sub>2*n*</sub> where 2*n* ∈ {16, 28, 36, 40, 50, 126, 170, 244, 344, 730, 1332, 1370, 1850, 2198, 3126, 6860, 12168, 16808, 29792}. Some newer results are collected [here](http://users.monash.edu.au/~iwanless/data/P1F/newP1F.html).

If the complete graph *K*<sub>*n*+1</sub> has a perfect 1-factorization, then the [complete bipartite graph](wikipedia://en/525320) *K*<sub>*n*,*n*</sub> also has a perfect 1-factorization.[^o14]

## 2-factorization {#2-factorization}

If a graph is 2-factorable, then it has to be 2*k*-regular for some integer *k*. [Julius Petersen](wikipedia://en/76861) showed in 1891 that this necessary condition is also sufficient: [any 2*k*-regular graph is 2-factorable](wikipedia://en/42617238).[^o16]

If a [connected graph](wikipedia://en/1614492) is 2*k*-regular and has an even number of edges it may also be *k*-factored, by choosing each of the two factors to be an alternating subset of the edges of an [Euler tour](https://en.wikipedia.org/wiki/Euler_tour).[^o17] This applies only to connected graphs; disconnected [counterexamples](wikipedia://en/143151) include disjoint unions of odd cycles, or of copies of *K*<sub>2*k*+1</sub>.

The [Oberwolfach problem](wikipedia://en/55972236) concerns the existence of 2-factorizations of complete graphs into [isomorphic](wikipedia://en/247577) subgraphs. It asks for which subgraphs this is possible. This is known when the subgraph is connected (in which case it is a [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle) and this special case is the problem of [Hamiltonian decomposition](wikipedia://en/24004195)) but the general case remains [open](wikipedia://en/1333335).
