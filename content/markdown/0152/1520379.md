# Nonelementary integral

::: {#o1 .subject cue=lead name="Nonelementary integral"}

Integral In [mathematics](wikipedia://en/18831), a **nonelementary antiderivative** of a given [elementary function](wikipedia://en/10412) is an [antiderivative](wikipedia://en/2823) (or indefinite integral) that is, itself, not an elementary function.[^o2] A [theorem by Liouville](wikipedia://en/9482601) in 1835 provided the first proof that nonelementary antiderivatives exist.[^o3] This theorem also provides a basis for the [Risch algorithm](wikipedia://en/289450) for determining (with difficulty) which elementary functions have elementary antiderivatives.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of functions with nonelementary antiderivatives include:

- $\sqrt{1 - x^4}$[^o2] ([elliptic integral](wikipedia://en/9960))
- $\frac{1}{\ln x}$[^o6] ([logarithmic integral](wikipedia://en/47137))
- $e^{-x^2}$[^o2] ([error function](wikipedia://en/177111), [Gaussian integral](wikipedia://en/567580))
- $\sin(x^2)$ and $\cos(x^2)$ ([Fresnel integral](wikipedia://en/271143))
- $\frac{\sin(x)}{x} = \operatorname{sinc}(x)$ ([sine integral](https://en.wikipedia.org/wiki/Sine_integral), [Dirichlet integral](wikipedia://en/1235977))
- $\frac{e^{-x}}{x}$ ([exponential integral](wikipedia://en/648614))
- $e^{e^x} \,$(in terms of the exponential integral)
- $\ln(\ln x) \,$(in terms of the logarithmic integral)
- ${x^{c-1}}e^{-x}$ ([incomplete gamma function](wikipedia://en/456050)); for $c = 0,$ the antiderivative can be written in terms of the exponential integral; for $c = \tfrac{1}{2},$ in terms of the error function; for $c =$ any positive integer, the antiderivative is elementary.

Some common non-elementary antiderivative functions are given names, defining so-called [special functions](wikipedia://en/23709110), and formulas involving these new functions can express a larger class of non-elementary antiderivatives. The examples above name the corresponding special functions in parentheses.

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Nonelementary antiderivatives can often be evaluated using [Taylor series](wikipedia://en/30448). Even if a function has no elementary antiderivative, its Taylor series can [always be integrated](wikipedia://en/61478) term-by-term like a [polynomial](wikipedia://en/23000), giving the antiderivative function as a Taylor series with the same [radius of convergence](wikipedia://en/61476). However, even if the integrand has a convergent Taylor series, its sequence of coefficients often has no elementary formula and must be evaluated term by term, with the same limitation for the integral Taylor series.

Even if it isn't always possible to evaluate the antiderivative in elementary terms, one can approximate a corresponding [definite integral](https://en.wikipedia.org/wiki/Definite_integral) by [numerical integration](wikipedia://en/170089). There are also cases where there is no elementary antiderivative, but specific definite integrals (often [improper integrals](wikipedia://en/346030) over [unbounded intervals](https://en.wikipedia.org/wiki/Bounded_interval)) can be evaluated in elementary terms: most famously the [Gaussian integral](wikipedia://en/567580) $\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt \pi.$[^o9]

The closure under integration of the set of the elementary functions is the set of the [Liouvillian functions](wikipedia://en/47147130).
