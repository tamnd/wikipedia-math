# Generalized canonical correlation

::: {#o1 .subject cue=lead name="Generalized canonical correlation"}

In [statistics](wikipedia://en/26685), the **generalized [canonical correlation](wikipedia://en/363900) analysis** (gCCA), is a way of making sense of [cross-correlation](wikipedia://en/714163) matrices between the sets of random variables when there are more than two sets. While a conventional CCA generalizes [principal component analysis](wikipedia://en/76340) (PCA) to two sets of random variables, a gCCA generalizes PCA to more than two sets of random variables. The **canonical variables** represent those **common factors** that can be found by a large PCA of all of the transformed random variables after each set underwent its own PCA.

:::

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

The [Helmert-Wolf blocking](https://en.wikipedia.org/wiki/Helmert-Wolf_blocking) (HWB) method of estimating [linear regression](wikipedia://en/48758386) parameters can find an optimal solution only if all cross-correlations between the data blocks are zero. They can always be made to vanish by introducing a new regression parameter for each common factor. The gCCA method can be used for finding those harmful common factors that create cross-correlation between the blocks. However, no optimal HWB solution exists if the random variables do not contain enough information on all of the new regression parameters.

:::
