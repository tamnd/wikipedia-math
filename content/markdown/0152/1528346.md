# Totally bounded space

::: {#o1 .subject cue=lead name="Totally bounded space"}

In [topology](wikipedia://en/29954) and related branches of [mathematics](wikipedia://en/18831), **total-boundedness** is a generalization of [compactness](wikipedia://en/6042) for circumstances in which a set is not necessarily [closed](https://en.wikipedia.org/wiki/Closed_%28topology%29). A totally bounded set can be [covered](wikipedia://en/317552) by [finitely](wikipedia://en/11742) many [subsets](wikipedia://en/27631) of every fixed “size” (where the meaning of “size” depends on the structure of the [ambient space](https://en.wikipedia.org/wiki/Ambient_space)).

:::

The term **precompact** (or **pre-compact**) is sometimes used with the same meaning, but precompact is also used to mean [relatively compact](https://en.wikipedia.org/wiki/Relatively_compact). These definitions coincide for subsets of a [complete metric space](wikipedia://en/7832), but not in general.

## In metric spaces {#In_metric_spaces}

*Image: Unit square totally bounded space.png.* \[0, 1\]<sup>2</sup> is a totally bounded space because for every *ε* > 0, the unit square can be covered by finitely many open discs of radius *ε*.

A [metric space](wikipedia://en/20018) $(M,d)$ is ***totally bounded*** if and only if for every real number $\varepsilon > 0$, there exists a finite collection of [open balls](https://en.wikipedia.org/wiki/Open_ball) of radius $\varepsilon$ whose centers lie in *M* and whose union contains $M$. Equivalently, the metric space *M* is totally bounded if and only if for every $\varepsilon >0$, there exists a [finite cover](https://en.wikipedia.org/wiki/Finite_cover) such that the radius of each element of the cover is at most $\varepsilon$. This is equivalent to the existence of a finite [ε-net](https://en.wikipedia.org/wiki/Ε-net_%28metric_spaces%29).[^n1] A metric space is totally bounded iff every sequence admits a Cauchy [subsequence](wikipedia://en/236098); in complete metric spaces, a set is compact if and only if it is closed and totally bounded.[^o4]

Each totally bounded space is [bounded](wikipedia://en/48258) (as the union of finitely many bounded sets is bounded). The reverse is true for subsets of [Euclidean space](wikipedia://en/9697) (with the [subspace topology](wikipedia://en/910926)), but not in general. For example, an infinite set equipped with the [discrete metric](https://en.wikipedia.org/wiki/Discrete_metric) is bounded but not totally bounded:[^n2] every discrete ball of radius $\varepsilon = 1/2$ or less is a singleton, and no finite union of singletons can cover an infinite set.

### Uniform (topological) spaces {#Uniform_(topological)_spaces}

A metric appears in the definition of total boundedness only to ensure that each element of the finite cover is of comparable size, and can be weakened to that of a [uniform structure](https://en.wikipedia.org/wiki/Uniform_structure). A subset $S$ of a [uniform space](wikipedia://en/32339) $X$ is totally bounded if and only if, for any [entourage](https://en.wikipedia.org/wiki/Entourage_%28topology%29) $E$, there exists a finite cover of $S$ by subsets of $X$ each of whose [Cartesian squares](https://en.wikipedia.org/wiki/Cartesian_square) is a subset of $E$. (In other words, $E$ replaces the "size" $\varepsilon$, and a subset is of size $E$ if its Cartesian square is a subset of $E$.)[^o7]

The definition can be extended still further, to any category of spaces with a notion of [compactness](https://en.wikipedia.org/wiki/Compactness_%28topology%29) and [Cauchy completion](https://en.wikipedia.org/wiki/Cauchy_completion): a space is totally bounded if and only if its (Cauchy) completion is compact.

## Examples and elementary properties {#Examples_and_elementary_properties}

- In a metric space, every [compact set](https://en.wikipedia.org/wiki/Compact_set) is totally bounded.
- Every totally bounded set is bounded.[^o9][^n2]
- A subset of the [real line](https://en.wikipedia.org/wiki/Real_line), or more generally of finite-dimensional [Euclidean space](wikipedia://en/9697), is totally bounded if and only if it is [bounded](wikipedia://en/48258).
- More generally, if a metric space has the [Heine-Borel property](https://en.wikipedia.org/wiki/Heine-Borel_property), then a subset is bounded if and only if it is totally bounded.
- The [unit ball](https://en.wikipedia.org/wiki/Unit_ball) in a [Hilbert space](wikipedia://en/20598932), or more generally in a [Banach space](wikipedia://en/3989), is totally bounded (in the norm topology) if and only if the space has finite [dimension](https://en.wikipedia.org/wiki/Dimension_%28linear_algebra%29).
- Equicontinuous bounded functions on a compact set are precompact in the [uniform topology](wikipedia://en/50652); this is the [Arzelà–Ascoli theorem](wikipedia://en/596622).
- A [metric space](wikipedia://en/20018) is [separable](wikipedia://en/27855) if and only if it is [homeomorphic](wikipedia://en/13660) to a totally bounded metric space.[^n2]
- The closure of a totally bounded subset is again totally bounded.[^n3]

### Comparison with compact sets {#Comparison_with_compact_sets}

In metric spaces, a set is compact if and only if it is complete and totally bounded;[^o9] without the [axiom of choice](wikipedia://en/840), only the forward direction holds. Precompact sets share a number of properties with compact sets.

- Like compact sets, the union of finitely many totally bounded sets is totally bounded.
- Unlike compact sets, every subset of a totally bounded set is again totally bounded.
- The continuous image of a compact set is compact. The [*uniformly* continuous](wikipedia://en/32337) image of a precompact set is precompact.

## In topological groups {#In_topological_groups}

Although the notion of total boundedness is closely tied to metric spaces, the greater algebraic structure of topological groups allows one to trade away some [separation properties](wikipedia://en/40117302). For example, in metric spaces, a set is compact if and only if complete and totally bounded. Under the definition below, the same holds for any topological vector space (not necessarily Hausdorff nor complete).[^n3][^n4][^n5]

The general [logical](https://en.wikipedia.org/wiki/Logic_%28symbolic%29) form of the [definition](wikipedia://en/7964) is: a subset $S$ of a space $X$ is totally bounded if and only if, [given any](https://en.wikipedia.org/wiki/Given_any) size $E,$ [there exists](https://en.wikipedia.org/wiki/There_exist) a finite cover $\mathcal{O}$ of $S$ such that each element of $\mathcal{O}$ has size at most $E.$ $X$ is then totally bounded if and only if it is totally bounded when considered as a subset of itself.

We adopt the convention that, for any neighborhood $U \subseteq X$ of the identity, a subset $S \subseteq X$ is called (**left**) **$U$-small** if and only if $(- S) + S \subseteq U.$[^n3] A subset $S$ of a [topological group](wikipedia://en/42315) $X$ is (**left**) **totally bounded** if it satisfies any of the following equivalent conditions:

Definition: For any neighborhood $U$ of the identity $0,$ there exist finitely many $x_1, \ldots, x_n \in X$ such that $S \subseteq \bigcup_{j=1}^n \left(x_j + U\right).$ For any neighborhood $U$ of $0,$ there exists a finite subset $F \subseteq X$ such that $S \subseteq F + U$ (where the right hand side is the [Minkowski sum](https://en.wikipedia.org/wiki/Minkowski_sum) $F + U := \{ f + u : f \in F, u \in U \}$). For any neighborhood $U$ of $0,$ there exist finitely many subsets $B_1, \ldots, B_n$ of $X$ such that $S \subseteq B_1 \cup \cdots \cup B_n$ and each $B_j$ is $U$-small.[^n3] For any given [filter subbase](wikipedia://en/47516955) $\mathcal{B}$ of the identity element's [neighborhood filter](https://en.wikipedia.org/wiki/Neighborhood_filter) $\mathcal{N}$ (which consists of all neighborhoods of $0$ in $X$) and for every $B \in \mathcal{B},$ there exists a cover of $S$ by finitely many $B$-small subsets of $X.$[^n3] $S$ is **Cauchy bounded**: for every neighborhood $U$ of the identity and every [countably infinite](wikipedia://en/6026) subset $I$ of $S,$ there exist distinct $x, y \in I$ such that $x - y \in U.$[^n3] (If $S$ is finite then this condition is [satisfied vacuously](wikipedia://en/51672)). Any of the following three sets satisfies (any of the above definitions of) being (left) totally bounded:

The [closure](wikipedia://en/42309) $\overline{S} = \operatorname{cl}_X S$ of $S$ in $X.$[^n3]

This set being in the list means that the following characterization holds: $S$ is (left) totally bounded if and only if $\operatorname{cl}_X S$ is (left) totally bounded (according to any of the defining conditions mentioned above). The same characterization holds for the other sets listed below. The image of $S$ under the [canonical quotient](https://en.wikipedia.org/wiki/First_Isomorphism_Theorem) $X \to X / \overline{\{ 0 \}},$ which is defined by $x \mapsto x + \overline{\{ 0 \}}$ (where $0$ is the identity element). The sum $S + \operatorname{cl}_X \{ 0 \}.$[^n6]

The definition of **right totally bounded** is analogous: simply swap the order of the products.

### Topological vector spaces {#Topological_vector_spaces}

Any topological vector space is an abelian topological group under addition, so the above conditions apply. Historically, statement 6(a) was the first reformulation of total boundedness for [topological vector spaces](wikipedia://en/45752); it dates to a 1935 paper of [John von Neumann](wikipedia://en/15942).[^o31]

This definition has the appealing property that, in a [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space) endowed with the [weak topology](https://en.wikipedia.org/wiki/Weak_topology_%28polar_topology%29), the precompact sets are exactly the [bounded sets](wikipedia://en/1789812).

For separable Banach spaces, there is a nice characterization of the precompact sets (in the norm topology) in terms of weakly convergent sequences of functionals: if $X$ is a separable Banach space, then $S \subseteq X$ is precompact if and only if every [weakly convergent](wikipedia://en/33662) sequence of functionals converges [uniformly](wikipedia://en/50652) on $S.$[^o32]

#### Interaction with convexity {#Interaction_with_convexity}

The [balanced hull](wikipedia://en/1734238) of a totally bounded subset of a topological vector space is again totally bounded.[^n3][^n10] The [Minkowski sum](https://en.wikipedia.org/wiki/Minkowski_sum) of two compact (totally bounded) sets is compact (resp. totally bounded). In a locally convex (Hausdorff) space, the [convex hull](wikipedia://en/40634) and the [disked hull](https://en.wikipedia.org/wiki/Disked_hull) of a totally bounded set $K$ is totally bounded if and only if $K$ is complete.[^n11]
