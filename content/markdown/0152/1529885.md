# Uniform property

::: {#o1 .subject cue=lead name="Uniform property"}

In the [mathematical](wikipedia://en/18831) field of [topology](wikipedia://en/29954) a **uniform property** or **uniform invariant** is a property of a [uniform space](wikipedia://en/32339) that is [invariant](wikipedia://en/1126638) under [uniform isomorphisms](wikipedia://en/1344480).

:::

Since uniform spaces come as [topological spaces](wikipedia://en/30450) and uniform isomorphisms are [homeomorphisms](wikipedia://en/13660), every [topological property](wikipedia://en/1337282) of a uniform space is also a uniform property. This article is (mostly) concerned with uniform properties that are *not* topological properties.

## Uniform properties {#Uniform_properties}

- **Separated**. A uniform space *X* is [separated](https://en.wikipedia.org/wiki/Separated_space) if the intersection of all [entourages](https://en.wikipedia.org/wiki/Entourage_%28topology%29) is equal to the diagonal in *X* × *X*. This is actually just a topological property, and equivalent to the condition that the underlying topological space is [Hausdorff](wikipedia://en/13637) (or simply [*T*<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space) since every uniform space is [completely regular](https://en.wikipedia.org/wiki/Completely_regular)).
- **Complete**. A uniform space *X* is [complete](https://en.wikipedia.org/wiki/Complete_space) if every [Cauchy net](https://en.wikipedia.org/wiki/Cauchy_net) in *X* converges (i.e. has a [limit point](https://en.wikipedia.org/wiki/Limit_point) in *X*).
- **Totally bounded** (or **Precompact**). A uniform space *X* is [totally bounded](https://en.wikipedia.org/wiki/Totally_bounded) if for each entourage *E* ⊂ *X* × *X* there is a finite [cover](wikipedia://en/317552) {*U*<sub>*i*</sub>} of *X* such that *U*<sub>*i*</sub> × *U*<sub>*i*</sub> is contained in *E* for all *i*. Equivalently, *X* is totally bounded if for each entourage *E* there exists a finite subset {*x*<sub>*i*</sub>} of *X* such that *X* is the union of all *E*\[*x*<sub>*i*</sub>\]. In terms of uniform covers, *X* is totally bounded if every uniform cover has a finite subcover.
- **Compact**. A uniform space is [compact](wikipedia://en/6042) if it is complete and totally bounded. Despite the definition given here, compactness is a topological property and so admits a purely topological description (every open cover has a finite subcover).
- **Uniformly connected**. A uniform space *X* is [uniformly connected](wikipedia://en/1590868) if every [uniformly continuous function](https://en.wikipedia.org/wiki/Uniformly_continuous_function) from *X* to a [discrete uniform space](https://en.wikipedia.org/wiki/Discrete_uniform_space) is constant.
- **Uniformly disconnected**. A uniform space *X* is [uniformly disconnected](https://en.wikipedia.org/wiki/Uniformly_disconnected) if it is not uniformly connected.
