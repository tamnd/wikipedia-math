# Neighbourhood (mathematics)

*Image: Neighborhood illust1.svg.* A set $V$ in the [plane](https://en.wikipedia.org/wiki/Plane_%28geometry%29) is a neighbourhood of a point $p$ if a small disc around $p$ is contained in $V.$ The small disc around $p$ is an open set $U.$

::: {#o1 .subject cue=lead name="Neighbourhood"}

In [topology](wikipedia://en/29954) and [mathematical analysis](wikipedia://en/48396), a **neighbourhood** (or **neighborhood**) is one of the basic concepts in a [topological space](wikipedia://en/30450). It is closely related to the concepts of [open set](wikipedia://en/39358) and [interior](wikipedia://en/55610). Intuitively speaking, a neighbourhood of a point is a [set](wikipedia://en/26691) of points containing that point where one can move some amount in any direction away from that point without leaving the set.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

### Neighbourhood of a point {#Neighbourhood_of_a_point}

If $X$ is a [topological space](wikipedia://en/30450) and $p$ is a point in $X,$ then a **neighbourhood**[^n1] of $p$ is a subset $V$ of $X$ that includes an [open set](wikipedia://en/39358) $U$ containing $p$,[^o6]

$$p \in U \subseteq V \subseteq X.$$

This is equivalent to the point $p \in X$ belonging to the [topological interior](wikipedia://en/55610#Interior_point) of $V$ in $X.$

The neighbourhood $V$ need not be an open subset of $X.$ When $V$ is open (resp. closed, compact, etc.) in $X,$ it is called an **open neighbourhood**[^o7] (resp. closed neighbourhood, compact neighbourhood, etc.). Some authors[^n2] require neighbourhoods to be open.

*Image: Neighborhood illust2.svg.* A closed rectangle V is not a neighbourhood of any of its corners or its boundary since there is no open set in V containing any corner or edge point.

A set that is a neighbourhood of each of its points is open since it can be expressed as the union of open sets containing each of its points. A closed rectangle, as illustrated in the figure, is not a neighbourhood of all its points; points on the edges or corners of the rectangle are not contained in any open set that is contained within the rectangle.

The collection of all neighbourhoods of a point is called the [neighbourhood system](wikipedia://en/1714290) at the point.

::: {#o10 .pointer-item cue=pointer name="Neighborhood of a set"}

### Neighbourhood of a set {#Neighbourhood_of_a_set}

If $S$ is a [subset](wikipedia://en/27631) of a topological space $X$, then a **neighbourhood** of $S$ is a set $V$ that includes an open set $U$ containing $S$,

$$S \subseteq U \subseteq V \subseteq X.$$

It follows that a set $V$ is a neighbourhood of $S$ if and only if it is a neighbourhood of all the points in $S.$ Furthermore, $V$ is a neighbourhood of $S$ [if and only if](wikipedia://en/14922) $S$ is a subset of the [interior](wikipedia://en/55610) of $V.$ A neighbourhood of $S$ that is also an open subset of $X$ is called an **open neighbourhood** of $S.$ The neighbourhood of a point is just a special case of this definition.

:::

## In a metric space {#In_a_metric_space}

*Image: Neighborhood illust3.svg.* A set $S$ in the plane and a uniform neighbourhood $V$ of $S$. The open set that is depicted with the dashed line and contains $S$ is $S_r$, the r-neighbourhood of $S$.

*Image: Epsilon Umgebung.svg.* The epsilon (ε) neighbourhood of a number $a$ on the real number line.

In a [metric space](wikipedia://en/20018) $M = (X, d),$ a set $V$ is a **neighbourhood** of a point $p$ if there exists a positive real number $r$ such that the [open ball](https://en.wikipedia.org/wiki/Open_ball)

$$B(p; r) = \{ x \in X : d(x, p) < r \}$$

with center $p$ and radius $r$ is contained in $V.$

$V$ is a neighbourhood of a set $S$ if, for each element $p$ of $S,$ there exists a positive number $r$ such that $B(p; r)$ is contained in $V.$ $V$ is called a **uniform neighbourhood** of a set $S$ if there exists a positive number $r$ such that for all elements $p$ of $S,$ the open ball $B(p; r)$ is contained in $V.$

Under the same condition of the uniform neighbourhood with $r > 0,$ the **$r$-neighbourhood** $S_r$ of a set $S$ is the union of all the open balls of radius $r$ that are centered at each point in $S$:

$$S_r = \bigcup\limits_{p\in{}S} B_r(p).$$

It directly follows that an $r$-neighbourhood is a uniform neighbourhood, and that a set is a uniform neighbourhood if and only if it contains an $r$-neighbourhood for some value of $r.$

:::

## Examples {#Examples}

*Image: Set of real numbers with epsilon-neighbourhood.svg.* The set M is a neighbourhood of the number *a*, because there is an ε-neighbourhood of *a* which is a subset of M.

Given the set of [real numbers](wikipedia://en/20646438) $\mathbb{R}$ with the usual [Euclidean metric](https://en.wikipedia.org/wiki/Euclidean_metric), the subset $V$ defined as

$$V := \bigcup_{n \in \mathbb{N}} B\left(n\,;\,1/n \right),$$

is a neighbourhood for the set $\mathbb{N}$ of [natural numbers](wikipedia://en/21474), but is not a uniform neighbourhood of this set because for every positive real number $r$, $B\left(\left\lceil \frac{1}{r} \right\rceil + 1\,;\,r\right)$ is not a subset of $V$ (note that $\left\lceil \frac{1}{r} \right\rceil + 1$ is a natural number).

:::

## Topology from neighbourhoods {#Topology_from_neighbourhoods}

The above definition is useful if the notion of [open set](wikipedia://en/39358) is already defined. There is an alternative way to define a topology, by first defining the [neighbourhood system](wikipedia://en/1714290), and then open sets as those sets containing a neighbourhood of each of their points.

A neighbourhood system on $X$ is the assignment of a [filter](wikipedia://en/12646549) $N(x)$ of subsets of $X$ to each $x$ in $X,$ such that

1. the point $x$ is an element of each $U$ in $N(x)$
1. each $U$ in $N(x)$ contains some $V$ in $N(x)$ such that for each $y$ in $V,$ $U$ is in $N(y).$

One can show that both definitions are compatible, that is, the topology obtained from the neighbourhood system defined using open sets is the original one, and vice versa when starting out from a neighbourhood system.

## Uniform neighbourhoods {#Uniform_neighbourhoods}

In a [uniform space](wikipedia://en/32339) $S = (X, \Phi),$ $V$ is called a **uniform neighbourhood** of $P$ if there exists an [entourage](https://en.wikipedia.org/wiki/Entourage_%28topology%29) $U \in \Phi$ such that $V$ contains all points of $X$ that are $U$-close to some point of $P;$ that is, $U[x] \subseteq V$ for all $x \in P.$

::: {#o18 .pointer-item cue=pointer name="Deleted neighborhood"}

## Deleted neighbourhood {#Deleted_neighbourhood}

A **deleted neighbourhood** of a point $p$ (sometimes called a **punctured neighbourhood**) is a neighbourhood of $p,$ without $\{p\}.$ For instance, the [interval](wikipedia://en/49172) $(-1, 1) = \{y : -1 < y < 1\}$ is a neighbourhood of $p = 0$ in the [real line](https://en.wikipedia.org/wiki/Real_line), so the set $(-1, 0) \cup (0, 1) = (-1, 1) \setminus \{0\}$ is a deleted neighbourhood of $0.$ A deleted neighbourhood of a given point is not in fact a neighbourhood of the point. The concept of deleted neighbourhood occurs in the [definition of the limit of a function](wikipedia://en/285759#Functions_on_topological_spaces) and in the definition of limit points (among other things).[^o19]

:::
