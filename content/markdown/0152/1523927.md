# Matrix representation

::: {#o1 .subject cue=lead name="Matrix representation"}

*Image: Row\_and\_column\_major\_order.svg.* Illustration of [row- and column-major order](https://en.wikipedia.org/wiki/Row-_and_column-major_order)

**Matrix representation** is a method used by a [computer language](https://en.wikipedia.org/wiki/Computer_language) to store column-vector [matrices](wikipedia://en/20556859) of more than one dimension in [memory](https://en.wikipedia.org/wiki/Computer_storage). [Fortran](https://en.wikipedia.org/wiki/Fortran) and [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) use different schemes for their native arrays. [Fortran](https://en.wikipedia.org/wiki/Fortran) uses "Column Major", in which all the elements for a given column are stored contiguously in memory. [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) uses "Row Major", which stores all the elements for a given row contiguously in memory.

:::

[LAPACK](wikipedia://en/1013768) defines various matrix representations in memory. There is also [Sparse matrix representation](https://en.wikipedia.org/wiki/Sparse_matrix_representation) and [Morton-order matrix representation](https://en.wikipedia.org/wiki/Morton-order_matrix_representation). According to the documentation, in [LAPACK](wikipedia://en/1013768) the [unitary matrix](wikipedia://en/129222) representation is optimized.[^o2][^o3] Some languages such as [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) store matrices using [Iliffe vectors](https://en.wikipedia.org/wiki/Iliffe_vector). These are particularly useful for storing [irregular matrices](wikipedia://en/3366265). Matrices are of primary importance in [linear algebra](wikipedia://en/18422).

## Basic mathematical operations {#Basic_mathematical_operations}

An m × n (read as m by n) order [matrix](wikipedia://en/20556859) is a set of numbers arranged in m rows and n columns. Matrices of the same order can be added by adding the corresponding elements. Two matrices can be multiplied, the condition being that the number of columns of the first matrix is equal to the number of rows of the second matrix. Hence, if an m × n matrix is multiplied with an n × r matrix, then the resultant matrix will be of the order m × r.[^o5]

Operations like row operations or column operations can be performed on a matrix, using which we can obtain the inverse of a matrix. The inverse may be obtained by determining the adjoint as well.[^o5] rows and columns are the different classes of matrices

## In 3D graphics {#In_3D_graphics}

The choice of representation for 4×4 matrices commonly used in [3D graphics](https://en.wikipedia.org/wiki/3D_graphics) affects the implementation of matrix/vector operations in systems with packed [SIMD instructions](https://en.wikipedia.org/wiki/SIMD_instruction):

### Row major {#Row_major}

With row-major matrix order, it is easy to transform vectors using [dot product](wikipedia://en/157093) operations, since the coefficients of each component are sequential in memory. Consequently, this layout may be desirable if a processor supports dot product operations natively. It is also possible to efficiently use a '3×4' affine transformation matrix without padding or awkward permutes.

### Column major {#Column_major}

With column-major order, a "matrix × vector" multiply can be implemented with vectorized [multiply–add operations](https://en.wikipedia.org/wiki/Multiply–add_operation), if the vector's components are broadcast to each [SIMD lane](https://en.wikipedia.org/wiki/SIMD_lane). It is also easy to access the [basis vectors](https://en.wikipedia.org/wiki/Basis_vector) represented by a [transformation matrix](wikipedia://en/692458) as individual column vectors, as these are contiguous in memory.
