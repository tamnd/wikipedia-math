# Optimal instruments

::: {#o1 .subject cue=lead name="Optimal instruments"}

In [statistics](wikipedia://en/26685) and [econometrics](wikipedia://en/10390), **optimal instruments** are a technique for improving the [efficiency](wikipedia://en/27250866) of [estimators](wikipedia://en/10043) in *conditional moment models*, a class of [semiparametric models](wikipedia://en/4415208) that generate [conditional expectation](wikipedia://en/435099) functions. To estimate parameters of a conditional moment model, the statistician can derive an [expectation](wikipedia://en/9653) function (defining "moment conditions") and use the [generalized method of moments](wikipedia://en/1975550) (GMM). However, there are infinitely many moment conditions that can be generated from a single model; optimal instruments provide the most efficient moment conditions.

:::

As an example, consider the [nonlinear regression](wikipedia://en/1045012) model

$$y = f(x, \theta) + u$$

$$E[u\mid x]=0$$

where $y$ is a [scalar](wikipedia://en/3588331) (one-dimensional) [random variable](wikipedia://en/25685), $x$ is a [random vector](https://en.wikipedia.org/wiki/Random_vector) with dimension $k$, and $\theta$ is a $k$-dimensional [parameter](wikipedia://en/413291). The conditional moment restriction $E[u\mid x]=0$ is consistent with infinitely many moment conditions. For example:

$$E[ux] = E[u x^2] = E[u x^3] = \dots = 0$$

More generally, for any vector-valued [function](wikipedia://en/185427) $z$ of $x$, it will be the case that

$$E[z(x) (y - f(x, \theta))] = 0.$$

That is, $z$ defines a finite set of [orthogonality](wikipedia://en/102221#Statistics,_econometrics,_and_economics) conditions.

A natural question to ask, then, is whether an [asymptotically efficient](wikipedia://en/27250866#Asymptotic_efficiency) set of conditions is available, in the sense that no other set of conditions achieves lower [asymptotic variance](https://en.wikipedia.org/wiki/Asymptotic_variance).[^o2] Both econometricians[^o3][^o4] and statisticians[^o5] have extensively studied this subject.

The answer to this question is generally that this finite set exists and have been proven for a wide range of estimators. [Takeshi Amemiya](https://en.wikipedia.org/wiki/Takeshi_Amemiya) was one of the first to work on this problem and show the optimal number of instruments for nonlinear [simultaneous equation models](https://en.wikipedia.org/wiki/Simultaneous_equation_models) with homoskedastic and serially uncorrelated errors.[^o6] The form of the optimal instruments was characterized by [Lars Peter Hansen](https://en.wikipedia.org/wiki/Lars_Peter_Hansen),[^o7] and results for nonparametric estimation of optimal instruments are provided by Newey.[^o8] A result for nearest neighbor estimators was provided by Robinson.[^o9]

## In linear regression {#In_linear_regression}

The technique of optimal instruments can be used to show that, in a conditional moment [linear regression](wikipedia://en/48758386) model with *[iid](https://en.wikipedia.org/wiki/Iid)* data, the optimal GMM estimator is [generalized least squares](wikipedia://en/4504135). Consider the model

$$y = x^\mathrm T \theta + u$$

$$E[u \mid x] = 0$$

where $y$ is a scalar random variable, $x$ is a $k$-dimensional random vector, and $\theta$ is a $k$-dimensional parameter vector. As above, the moment conditions are

$$E[z(x) (y - x^\mathrm T \theta)] = 0$$

where $z = z(x)$ is an instrument set of dimension $p$ ($p \ge k$). The task is to choose $z$ to minimize the asymptotic variance of the resulting GMM estimator. If the data are *iid*, the asymptotic variance of the GMM estimator is

$$(E[x z^\mathrm T]^\mathrm T E[\sigma^2(x) z z^\mathrm T]^{-1} E[z x^\mathrm T])^{-1}$$

where $\sigma^2(x) \equiv E[u^2 \mid x]$.

The optimal instruments are given by

$$z^*(x) = \frac{x}{\sigma^2(x)}$$

which produces the asymptotic variance matrix

$$\left( E \left[ \frac{x x^\mathrm T}{\sigma^2(x)} \right] \right)^{-1}.$$

These are the optimal instruments because for any other $z$, the matrix

$$\left( E \left[ \frac{x x^\mathrm T}{\sigma^2(x)} \right] \right)^{-1} - (E[x z^\mathrm T]^\mathrm T E[\sigma^2(x) z z^\mathrm T]^{-1} E[z x^\mathrm T])^{-1}$$

is [positive semidefinite](https://en.wikipedia.org/wiki/Positive_semidefinite_matrix).

Given *iid* data $(y_1, x_1), \dots, (y_N, x_N)$, the GMM estimator corresponding to $z^*(x)$ is

$$\widetilde\theta = \left( \sum_{i=1}^N \frac{x_i x_i^\mathrm T}{\sigma^2(x_i)} \right)^{-1} \sum_{i=1}^N \frac{x_i y_i}{\sigma^2(x_i)}$$

which is the generalized least squares estimator. (It is unfeasible because $\sigma^{2}(\cdot)$ is unknown.)[^o2]
