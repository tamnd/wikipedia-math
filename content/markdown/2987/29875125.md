# Divisibility sequence

::: {#o1 .subject cue=lead name="Divisibility sequence"}

In mathematics, a **divisibility sequence** is an [integer sequence](wikipedia://en/51421) $(a_n)$ indexed by [positive integers](https://en.wikipedia.org/wiki/Positive_integer) $n$ such that

:::

$$\text{if }m\mid n\text{ then }a_m\mid a_n$$

for all $m$ and $n$. That is, whenever one index is a multiple of another one, then the corresponding term also is a multiple of the other term. The concept can be generalized to sequences with values in any [ring](wikipedia://en/48404) where the concept of [divisibility](https://en.wikipedia.org/wiki/Divisibility) is defined.

A **strong divisibility sequence** is an integer sequence $(a_n)$ such that for all positive integers $m$ and $n$,

$$\gcd(a_m,a_n) = a_{\gcd(m,n)},$$

where $\gcd$ is the [greatest common divisor](wikipedia://en/12354) function.

Every strong divisibility sequence is a divisibility sequence: $\gcd(m,n) = m$ if and only if $m\mid n$. Therefore, by the strong divisibility property, $\gcd(a_m,a_n) = a_m$ and therefore $a_m\mid a_n$.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Any [Lucas sequence](wikipedia://en/734635) of the first kind $U_{n}(P, Q)$ is a divisibility sequence. Moreover, it is a strong divisibility sequence when $\gcd(P, Q) = 1$. Specific examples include:

- Any constant sequence $a_n = k$ is a strong divisibility sequence, which is $kU_{n}(1, 0)$ for $n \ge 1$.
- Every sequence of the form $a_n = kn$, for some nonzero integer $k$, is a divisibility sequence. It is equal to $kU_{n}(2, 1)$.
- The [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_numbers) $F_{n}$ form a strong divisibility sequence, which is $U_{n}(1, -1)$.
- The [Mersenne numbers](https://en.wikipedia.org/wiki/Mersenne_number) $a_n = 2^n-1$ form a strong divisibility sequence, which is $U_{n}(3, 2)$.
- The [repunit](wikipedia://en/215056) numbers $R(b)$ for $n = 1, 2, ...$ in any base $b$ form a strong divisibility sequence, which is $U_{n}(b + 1, b)$.
- Any sequence of the form $a_n = A^n - B^n$ for integers $A>B>0$ is a divisibility sequence, which is $(A - B)U_{n}(A + B, AB)$. If $A$ and $B$ are coprime then this is a strong divisibility sequence.

[Elliptic divisibility sequences](wikipedia://en/21298611) are another class of divisibility sequences.
