# Stepwise irregular graph

*Image: A stepwise irregular graph.svg.* A stepwise irregular graph. The number on each vertex represents the [degree](wikipedia://en/1374448) of the vertex.

::: {#o1 .subject cue=lead name="Stepwise irregular graph"}

In [graph theory](wikipedia://en/12401), a **stepwise irregular graph** (or **SI graph**) is a [graph](wikipedia://en/325806) in which the [degrees](wikipedia://en/1374448) of any two [adjacent](https://en.wikipedia.org/wiki/Adjacent_%28graph_theory%29) vertices differ by exactly one. This concept was introduced by [Ivan Gutman](https://en.wikipedia.org/wiki/Ivan_Gutman) in 2018 as a way to study graphs with minimal irregularity among those with non-zero edge imbalance.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A graph $G = (V, E)$ is called **stepwise irregular** if for every edge $uv \in E(G)$, we have $|d(u) - d(v)| = 1$, where $d(x)$ denotes the [degree](wikipedia://en/1374448) of vertex $x$.

More generally, a graph $G$ is called a $k$-stepwise irregular graph (or $k$-SI graph) for a positive integer $k \ge 1$ if $|d(u) - d(v)| = k$ for every edge $uv \in E(G)$.[^o5] The original stepwise irregular graphs correspond to the case $k = 1$.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

Stepwise irregular graphs have several fundamental structural properties. Every stepwise irregular graph is [bipartite](wikipedia://en/244431). This follows from the fact that SI graphs cannot contain [odd cycles](https://en.wikipedia.org/wiki/Odd_cycle). In any [cycle](wikipedia://en/168609), moving along consecutive vertices requires the degrees to alternately increase and decrease by one, which is only possible if the cycle has even length.[^o2]

Every stepwise irregular graph has an even number of edges. This is a direct consequence of the [Albertson index](wikipedia://en/81286122) property and the fact that for SI graphs, the Albertson index equals the number of edges.[^o2]

In a stepwise irregular graph, every integer between the minimum degree $\delta(G)$ and maximum degree $\Delta(G)$ must appear as the degree of some vertex.[^o8] The graph is naturally bipartitioned into vertices of even degree and vertices of odd degree.

:::

## Structural results {#Structural_results}

### Order constraints {#Order_constraints}

The possible [orders](https://en.wikipedia.org/wiki/Order_%28graph_theory%29) (number of vertices) of stepwise irregular graphs depend on their [cyclomatic number](wikipedia://en/1483049) $\gamma = m - n + 1$:

- [Trees](wikipedia://en/48560) ($\gamma = 0$): The order is always odd. SI trees exist for all odd orders except 1, 5, 8, 13, and 17.[^o2]
- [Unicyclic graphs](https://en.wikipedia.org/wiki/Unicyclic_graph) ($\gamma = 1$): The order is always even. SI unicyclic graphs exist for all even orders except 2, 4, 6, 10, and 14.[^o2]
- Bicyclic graphs ($\gamma = 2$): The order is always odd. SI bicyclic graphs exist for all odd orders except 1, 3, 7, and 11.[^o2][^o8]
- Tricyclic graphs ($\gamma = 3$): The order is always even. SI tricyclic graphs exist for all even orders except 2, 4, 6, and 8.[^o8]

Connected stepwise irregular graphs exist for all orders except 1, 2, 4, and 6.[^o2][^o8]

For stepwise irregular trees with at least 1 vertex of degree $n$, the minimum order for $n$ = 0, 1, 2, 3...:[^o2]

1, 2, 3, 7, 21, 81, 391, 2283, 15657, 123301, 1096011, 10850511, 118369213...

### Diameter results {#Diameter_results}

For $k$-stepwise irregular graphs, it has been proven that for any $k \ge 1$ and any [diameter](wikipedia://en/1020021) $d \ge 2$, there exists a $k$-SI graph with diameter $d$. This can be achieved using [graph products](wikipedia://en/11492935) such as the [Cartesian](wikipedia://en/2856852) and [lexicographic products](wikipedia://en/6026731).[^o5]

## Extremal results {#Extremal_results}

For a $k$-stepwise irregular graph $G$ of order $n$:

$$\Delta(G) \le \lfloor\frac{n+k}{2}\rfloor$$

Where $\Delta(G)$ is the maximum degree of $G$. The equality holds if and only if $G$ is [isomorphic](wikipedia://en/14828) to the [complete bipartite graph](wikipedia://en/525320) $K_{(n+k)/2, (n-k)/2}$.[^o5]

The number of edges $m$ in a $k$-SI graph $G$ satisfies:

$$m(G) \le \frac{n\Delta(G)(\Delta(G) - k)}{2\Delta(G) - k}$$

with equality if and only if the degree complexity $C_d(G) = 2$ (i.e., the graph has exactly two distinct degree values).[^o5]

## Graph operations {#Graph_operations}

Stepwise irregular graphs are not [closed](wikipedia://en/47279) under common [graph operations](wikipedia://en/4140245).[^o8] Removing any edge or vertex from an SI graph results in a non-SI graph. The [complement](wikipedia://en/1175649) of a [connected](https://en.wikipedia.org/wiki/Connected_graph) SI graph is never SI. The subdivision graph of an SI graph is generally not SI, except for specific cases ($K_2$, $K_{1,3}$, and [3-regular graphs](wikipedia://en/85821)). The [line graph](wikipedia://en/675231) of an SI graph is not SI, except when the original graph is [$P_4$](wikipedia://en/4587190).

## Connection to graph irregularity {#Connection_to_graph_irregularity}

Stepwise irregular graphs are closely related to the [Albertson index](wikipedia://en/81286122), a measure of graph irregularity defined as:

$$\operatorname{Alb}(G) = \sum_{uv \in E(G)} |d(u)-d(v)|$$

This is sometimes denoted by $I(G)$ and simply called the irregularity of a graph in the literature.[^o15] For stepwise irregular graphs, $\operatorname{Alb}(G) = m$, making them the least irregular graphs among those with non-zero edge imbalance.[^o2]

## Topological indices {#Topological_indices}

The [Wiener index](wikipedia://en/14223173) $W(G)$, degree distance $DD(G)$, and Gutman index $ZZ(G)$ of SI graphs are all even integers, as well as the first and second [Zagreb indices](https://en.wikipedia.org/wiki/Zagreb_index) $M_1(G)$ and $M_2(G)$, and the multiplicative Zagreb indices $\Pi_1(G)$ and $\Pi_2(G)$.[^o2]
