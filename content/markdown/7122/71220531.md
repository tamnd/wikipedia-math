# Maximum inner-product search

::: {#o1 .subject cue=lead name="Maximum inner-product search"}

**Maximum inner-product search** (**MIPS**) is a [search problem](wikipedia://en/1471816), with a corresponding class of [search algorithms](https://en.wikipedia.org/wiki/Search_algorithm) which attempt to maximise the [inner product](wikipedia://en/14856) between a query and the data items to be retrieved. MIPS algorithms are used in a wide variety of big data applications, including [recommendation algorithms](https://en.wikipedia.org/wiki/Recommendation_algorithm) and [machine learning](wikipedia://en/233488).[^o2]

:::

Formally, for a database of vectors $x_i$ defined over a set of labels $S$ in an [inner product space](wikipedia://en/14856) with an inner product $\langle \cdot, \cdot \rangle$ defined on it, MIPS search can be defined as the problem of determining

$$\underset{i \in S}{\operatorname{arg\,max}}\ \langle x_i, q \rangle$$

for a given query $q$.

Although there is an obvious [linear-time](https://en.wikipedia.org/wiki/Linear-time) implementation, it is generally too slow to be used on practical problems. However, efficient algorithms exist to speed up MIPS search.[^o2][^o3]

Under the assumption of all vectors in the set having constant norm, MIPS can be viewed as equivalent to a [nearest neighbor search](https://en.wikipedia.org/wiki/Nearest_neighbor_search) (NNS) problem in which maximizing the inner product is equivalent to minimizing the corresponding [distance metric](https://en.wikipedia.org/wiki/Distance_metric) in the NNS problem.[^o4] Like other forms of NNS, MIPS algorithms may be approximate or exact.[^o5]

MIPS search is used as part of [DeepMind](https://en.wikipedia.org/wiki/DeepMind)'s [RETRO](https://en.wikipedia.org/wiki/RETRO_%28algorithm%29) algorithm.[^o6]
