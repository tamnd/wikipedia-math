# Shift rule

::: {#o1 .subject cue=lead name="Shift rule"}

The **shift rule** is a mathematical rule for [sequences](wikipedia://en/27838) and [series](wikipedia://en/15287).

:::

Here $n$ and $N$ are [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers).

For sequences, the rule states that if $(a_{n})$ is a sequence, then it [converges](wikipedia://en/1743431) [if and only if](wikipedia://en/14922) $(a_{n+N})$ also converges, and in this case both sequences always converge to the same number.[^o2]

For series, the rule states that the series $\sum\limits_{n=1}^\infty a_{n}$ converges to a number if and only if $\sum\limits_{n=1}^\infty a_{n+N}$ converges.[^o3]
