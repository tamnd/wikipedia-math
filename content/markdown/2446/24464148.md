# Simultaneous perturbation stochastic approximation

::: {#o1 .subject cue=lead name="Simultaneous perturbation stochastic approximation"}

**Simultaneous perturbation stochastic approximation** (SPSA) is an [algorithmic](wikipedia://en/775) method for optimizing systems with multiple unknown [parameters](https://en.wikipedia.org/wiki/Parameters). It is a type of [stochastic approximation](wikipedia://en/8979437) algorithm. As an optimization method, it is appropriately suited to large-scale population models, adaptive modeling, simulation [optimization](https://en.wikipedia.org/wiki/Optimization), and [atmospheric modeling](https://en.wikipedia.org/wiki/Atmospheric_model). Many examples are presented at the SPSA website http://www.jhuapl.edu/SPSA. A comprehensive book on the subject is Bhatnagar et al. (2013). An early paper on the subject is Spall (1987) and the foundational paper providing the key theory and justification is Spall (1992).

:::

SPSA is a descent method capable of finding global minima, sharing this property with other methods such as [simulated annealing](wikipedia://en/172244). Its main feature is the gradient approximation that requires only two measurements of the objective function, regardless of the dimension of the optimization problem. Recall that we want to find the [optimal control](wikipedia://en/362565) $u^*$ with loss function $J(u)$:

$$u^* = \arg \min_{u \in U} J(u).$$

Both Finite Differences Stochastic Approximation (FDSA) and SPSA use the same iterative process:

$$u_{n+1} = u_n - a_n\hat{g}_n(u_n),$$

where $u_n=((u_n)_1,(u_n)_2,\ldots,(u_n)_p)^T$ represents the $n^{th}$ iterate, $\hat{g}_n(u_n)$ is the estimate of the gradient of the objective function $g(u)= \frac{\partial}{\partial u}J(u)$ evaluated at ${u_n}$, and $\{a_n\}$ is a positive number sequence converging to 0. If $u_n$ is a *p*-dimensional vector, the $i^{th}$ component of the [symmetric](https://en.wikipedia.org/wiki/Symmetric) finite difference gradient estimator is:

**FD:** $(\hat{g_n}(u_n))_i = \frac{J(u_n+c_ne_i)-J(u_n-c_ne_i)}{2c_n},$

$1 \leq i \leq p$, where $e_i$ is the [unit vector](wikipedia://en/167053) with a 1 in the $i^{th}$ place, and $c_n$ is a small positive number that decreases with *n*. With this method, *2p* evaluations of *J* for each $g_n$ are needed. When *p* is large, this estimator loses efficiency.

Let now $\Delta_n$ be a random perturbation vector. The $i^{th}$ component of the stochastic perturbation gradient estimator is:

**SP:** $(\hat{g_n}(u_n))_i = \frac{J(u_n+c_n\Delta_n)-J(u_n-c_n\Delta_n)}{2c_n(\Delta_n)_i}.$

Remark that FD perturbs only one direction at a time, while the SP estimator disturbs all directions at the same time (the numerator is identical in all *p* components). The number of loss function measurements needed in the SPSA method for each $g_n$ is always 2, independent of the [dimension](wikipedia://en/8398) *p*. Thus, SPSA uses *p* times fewer function evaluations than FDSA, which makes it a lot more efficient.

Simple experiments with *p=2* showed that SPSA converges in the same number of iterations as FDSA. The latter follows [approximately](wikipedia://en/336271) the [steepest](https://en.wikipedia.org/wiki/Steepest) descent direction, behaving like the gradient method. On the other hand, SPSA, with the [random search](wikipedia://en/27340816) direction, does not follow exactly the gradient path. In average though, it tracks it nearly because the gradient approximation is an almost [unbiased](https://en.wikipedia.org/wiki/Unbiased) estimator of the gradient, as shown in the following lemma.

::: {#o3 .statement kind=statement/lemma cue=named-heading name="Convergence lemma"}

## Convergence lemma {#Convergence_lemma}

Denote by

$$b_n = E[\hat{g}_n|u_n] -\nabla J(u_n)$$

the bias in the estimator $\hat{g}_n$. Assume that $\{(\Delta_n)_i\}$ are all mutually independent with zero-mean, bounded second moments, and $E(|(\Delta_n)_i|^{-1})$ uniformly bounded. Then $b_n$→0 w.p. 1.

:::

## Sketch of the proof {#Sketch_of_the_proof}

The main [idea](https://en.wikipedia.org/wiki/Idea) is to use conditioning on $\Delta_n$ to express $E[(\hat{g}_n)_i]$ and then to use a second order Taylor expansion of $J(u_n+c_n\Delta_n)_i$ and $J(u_n-c_n\Delta_n)_i$. After algebraic manipulations using the zero mean and the independence of $\{(\Delta_n)_i\}$, we get

$$E[(\hat{g}_n)_i]=(g_n)_i + O(c_n^2)$$

The result follows from the [hypothesis](https://en.wikipedia.org/wiki/Hypothesis) that $c_n$→0.

Next we resume some of the hypotheses under which $u_t$ converges in [probability](wikipedia://en/22934) to the set of global minima of $J(u)$. The efficiency of the method depends on the shape of $J(u)$, the values of the parameters $a_n$ and $c_n$ and the distribution of the perturbation terms $\Delta_{ni}$. First, the algorithm parameters must satisfy the following conditions:

- $a_n$ >0, $a_n$→0 when n→∝ and $\sum_{n=1}^{\infty} a_n = \infty$. A good choice would be $a_n=\frac{a}{n};$ a>0;
- $c_n=\frac{c}{n^\gamma}$, where c>0, $\gamma \in \left[\frac{1}{6},\frac{1}{2}\right]$;
- $$\sum_{n=1}^{\infty} (\frac {a_n}{c_n})^2 < \infty$$
- $\Delta_{ni}$ must be mutually independent zero-mean random variables, symmetrically distributed about zero, with $\Delta_{ni} < a_1 < \infty$. The inverse first and second moments of the $\Delta_{ni}$ must be finite.

A good choice for $\Delta_{ni}$ is the [Rademacher distribution](wikipedia://en/1856890), i.e. Bernoulli +-1 with probability 0.5. Other choices are possible too, but note that the uniform and normal distributions cannot be used because they do not satisfy the finite inverse moment conditions.

The loss function *J(u)* must be thrice continuously [differentiable](wikipedia://en/330206) and the individual elements of the [third derivative](wikipedia://en/9092737) must be bounded: $|J^{(3)}(u)| < a_3 < \infty$. Also, $|J(u)|\rightarrow\infty$ as $u\rightarrow\infty$.

In addition, $\nabla J$ must be Lipschitz continuous, bounded and the ODE $\dot{u}=g(u)$ must have a unique solution for each [initial condition](wikipedia://en/1186804). Under these conditions and a few others, $u_k$ [converges](wikipedia://en/50723) in probability to the set of global minima of J(u) (see Maryak and Chin, 2008).

It has been shown that differentiability is not required: continuity and convexity are sufficient for convergence.[^o5]

## Extension to second-order (Newton) methods {#Extension_to_second-order_(Newton)_methods}

It is known that a stochastic version of the standard (deterministic) Newton-Raphson algorithm (a “second-order” method) provides an asymptotically optimal or near-optimal form of stochastic approximation. SPSA can also be used to efficiently estimate the [Hessian matrix](wikipedia://en/412108) of the loss function based on either noisy loss measurements or noisy gradient measurements (stochastic gradients). As with the basic SPSA method, only a small fixed number of loss measurements or gradient measurements are needed at each iteration, regardless of the problem dimension *p*. See the brief discussion in [Stochastic gradient descent](wikipedia://en/1180641).
