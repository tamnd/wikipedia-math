# Bent function

::: {#o1 .definition cue=defn}

*Image: Boolean functions like 1000 nonlinearity.svg.* The four 2-ary Boolean functions with [Hamming weight](wikipedia://en/1127884) 1 are bent; i.e., their nonlinearity is 1 (these Hadamard matrices show the Hamming distance to each of the eight linear and affine functions). The following formula shows that a 2-ary function is bent when its nonlinearity is 1: $$2^{2-1} - 2^{\frac{2}{2}-1} = 2 - 1 = 1$$

:::

::: {#o2 .definition cue=defn}

*Image: 0001 0001 0001 1110 nonlinearity.svg.* The Boolean function $x_1 x_2 \oplus x_3 x_4$ is bent; i.e., its nonlinearity is 6 (which is what these Hadamard Matrices show). The following formula shows that a 4-ary function is bent when its nonlinearity is 6: $$2^{4-1} - 2^{\frac{4}{2}-1} = 8-2 = 6$$

:::

::: {#o3 .subject cue=lead name="Bent function"}

In the [mathematical](wikipedia://en/18831) field of [combinatorics](wikipedia://en/5170), a **bent function** is a [Boolean function](wikipedia://en/753349) that is maximally non-linear; it is as different as possible from the set of all [linear](wikipedia://en/18102) and [affine functions](https://en.wikipedia.org/wiki/Affine_function) when measured by [Hamming distance](wikipedia://en/41227) between [truth tables](wikipedia://en/25512250). Concretely, this means the maximum [correlation](wikipedia://en/29018709) between the output of the function and a linear function is minimal. In addition, the [derivatives](https://en.wikipedia.org/wiki/Boolean_derivative) of a bent function are [balanced](wikipedia://en/24635433) Boolean functions, so for any change in the input variables there is a 50 percent chance that the output value will change.

:::

The maximal nonlinearity means approximating a bent function by an affine (linear) function is hard, a useful property in the defence against [linear cryptanalysis](wikipedia://en/59469). In addition, detecting a change in the output of the function yields no information about what change occurred in the inputs, making the function immune to [differential cryptanalysis](wikipedia://en/8536).

Bent functions were defined and named in the 1960s by [Oscar Rothaus](https://en.wikipedia.org/wiki/Oscar_Rothaus) in research not published until 1976.[^o16] They have been extensively studied for their applications in [cryptography](wikipedia://en/18934432), but have also been applied to [spread spectrum](https://en.wikipedia.org/wiki/Spread_spectrum), [coding theory](wikipedia://en/321869), and [combinatorial design](wikipedia://en/2761968). The definition can be extended in several ways, leading to different classes of generalized bent functions that share many of the useful properties of the original.

It is known that V. A. Eliseev and O. P. Stepchenkov studied bent functions, which they called *minimal functions*, in the USSR in 1962.[^o17] However, their results have still not been declassified.

Bent functions are also known as **perfectly nonlinear** (**PN**) Boolean functions. Certain functions that are as close as possible to perfect nonlinearity (e.g. for functions of an odd number of bits, or vectorial functions) are known as **almost perfectly nonlinear** (**APN**).[^o4]

## Walsh transform {#Walsh_transform}

Bent functions are defined in terms of the [Walsh transform](https://en.wikipedia.org/wiki/Walsh_transform). The Walsh transform of a Boolean function $f:\mathbb{Z}_2^n \to \mathbb{Z}_2$ is the function $\hat{f}:\mathbb{Z}_2^n \to \mathbb{Z}$ given by

$$\hat{f}(a) = \sum_{\scriptstyle{x \in \mathbb{Z}_2^n}} (-1)^{f(x) + a \cdot x},$$

where *a* · *x* = *a*<sub>1</sub>*x*<sub>1</sub> + *a*<sub>2</sub>*x*<sub>2</sub> + … + *a*<sub>*n*</sub>*x*<sub>*n*</sub> (mod 2) is the [dot product](wikipedia://en/157093) in **Z***n*.[^o18] Alternatively, let *S*<sub>0</sub>(*a*) = { *x* ∈ **Z***n* : *f*(*x*) = *a* · *x* } and *S*<sub>1</sub>(*a*) = { *x* ∈ **Z***n* : *f*(*x*) ≠ *a* · *x* } . Then $\lvert S_{0}(a)\rvert$ + $\lvert S_{1}(a)\rvert$ = 2<sup>*n*</sup> and hence

$$\hat{f}(a) = \left|S_0(a)\right| - \left|S_1(a)\right| = 2 \left|S_0(a)\right| - 2^n.$$

For any Boolean function *f* and *a* ∈ **Z***n*, the transform lies in the range

$$-2^n \leq \hat{f}(a) \leq 2^n.$$

Moreover, the linear function *f*<sub>0</sub>(*x*) = *a* · *x* and the affine function *f*<sub>1</sub>(*x*) = *a* · *x* + 1 correspond to the two extreme cases, since

$$\hat{f}_0(a) = 2^n,~ \hat{f}_1(a) = -2^n.$$

Thus, for each *a* ∈ **Z***n* the value of $\hat{f}(a)$ characterizes where the function *f*(*x*) lies in the range from *f*<sub>0</sub>(*x*) to *f*<sub>1</sub>(*x*).

::: {#o7 .definition cue=heading name="Definition and properties"}

## Definition and properties {#Definition_and_properties}

Rothaus defined a **bent function** as a Boolean function $f:\mathbb{Z}_2^n \to \mathbb{Z}_2$ whose [Walsh transform](https://en.wikipedia.org/wiki/Walsh_transform) has constant [absolute value](wikipedia://en/991). Bent functions are in a sense equidistant from all the affine functions, so they are equally hard to approximate with any affine function.

The simplest examples of bent functions, written in [algebraic normal form](wikipedia://en/1048680), are *F*(*x*<sub>1</sub>, *x*<sub>2</sub>) = *x*<sub>1</sub>*x*<sub>2</sub> and *G*(*x*<sub>1</sub>, *x*<sub>2</sub>, *x*<sub>3</sub>, *x*<sub>4</sub>) = *x*<sub>1</sub>*x*<sub>2</sub> ⊕ *x*<sub>3</sub>*x*<sub>4</sub>. This pattern continues: *x*<sub>1</sub>*x*<sub>2</sub> ⊕ *x*<sub>3</sub>*x*<sub>4</sub> ⊕ … ⊕ *x*<sub>*n*−1</sub>*x*<sub>*n*</sub> is a bent function $\mathbb{Z}_2^n \to \mathbb{Z}_2$ for every even *n*, but there is a wide variety of other bent functions as *n* increases.[^o19] The sequence of values (−1)<sup>*f*(*x*)</sup>, with *x* ∈ **Z***n* taken in [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order), is called a **bent sequence**; bent functions and bent sequences have equivalent properties. In this ±1 form, the Walsh transform is easily computed as

$$\hat{f}(a) = W\left(2^n\right) (-1)^{f(a)},$$

where *W*(2<sup>*n*</sup>) is the natural-ordered [Walsh matrix](wikipedia://en/1291534) and the sequence is treated as a [column vector](https://en.wikipedia.org/wiki/Column_vector).[^o20]

Rothaus proved that bent functions exist only for even *n*, and that for a bent function *f*, $\left|\hat{f}(a)\right| = 2^{n/2}$ for all *a* ∈ **Z***n*.[^o18] In fact, $\hat{f}(a) = 2^{n/2}(-1)^{g(a)}$, where *g* is also bent. In this case, $\hat{g}(a) = 2^{n/2}(-1)^{f(a)}$, so *f* and *g* are considered [dual](wikipedia://en/609737) functions.[^o20]

Every bent function has a [Hamming weight](wikipedia://en/1127884) (number of times it takes the value 1) of 2<sup>*n*−1</sup> ± 2<sup>*n*/2−1</sup>, and in fact agrees with any affine function at one of those two numbers of points. So the *nonlinearity* of *f* (minimum number of times it equals any affine function) is 2<sup>*n*−1</sup> − 2<sup>*n*/2−1</sup>, the maximum possible. Conversely, any Boolean function with nonlinearity 2<sup>*n*−1</sup> − 2<sup>*n*/2−1</sup> is bent.[^o18] The [degree](wikipedia://en/5930652) of *f* in algebraic normal form (called the *nonlinear order* of *f*) is at most $\tfrac{n}{2}$ (for *n* > 2).[^o19]

Although bent functions are vanishingly rare among Boolean functions of many variables, they come in many different kinds. There has been detailed research into special classes of bent functions, such as the [homogeneous](wikipedia://en/1698977) ones[^o21] or those arising from a [monomial](wikipedia://en/357416) over a [finite field](wikipedia://en/11615),[^o22] but so far the bent functions have defied all attempts at a complete enumeration or classification.

If $f$ is a bent function on the elementary abelian group $V = \mathbf{F}_{2}^{2m}$, then $H_{f} = ((-1)^{f(x+y)})_{x,y \in V}$ is a [Hadamard matrix](wikipedia://en/507553), and the support of $f$ (or its complement) is a Hadamard difference set in $V$.[^o16] This construction gives a Hadamard matrix developed over a noncyclic group; whether a real circulant (cyclic) Hadamard matrix of order greater than 4 can exist at all is the subject of [Ryser's conjecture on circulant Hadamard matrices](wikipedia://en/82859189), a long-standing open problem in combinatorics.

## Constructions {#Constructions}

There are several types of constructions for bent functions.[^o17]

- Combinatorial constructions: iterative constructions, Maiorana–McFarland construction, partial spreads, Dillon's and Dobbertin's bent functions, minterm bent functions, bent iterative functions
- Algebraic constructions: monomial bent functions with exponents of Gold, Dillon, Kasami, Canteaut–Leander and Canteaut–Charpin–Kuyreghyan; Niho bent functions, etc.

:::

## Applications {#Applications}

As early as 1982 it was discovered that [maximum length sequences](https://en.wikipedia.org/wiki/Maximum_length_sequence) based on bent functions have [cross-correlation](wikipedia://en/714163) and [autocorrelation](wikipedia://en/2724) properties rivalling those of the [Gold codes](wikipedia://en/50567) and [Kasami codes](https://en.wikipedia.org/wiki/Kasami_code) for use in [CDMA](https://en.wikipedia.org/wiki/CDMA).[^o23] These sequences have several applications in [spread spectrum](https://en.wikipedia.org/wiki/Spread_spectrum) techniques.

The properties of bent functions are naturally of interest in modern digital [cryptography](wikipedia://en/18934432), which seeks to obscure relationships between input and output. By 1988 Forré recognized that the Walsh transform of a function can be used to show that it satisfies the [strict avalanche criterion](https://en.wikipedia.org/wiki/Strict_avalanche_criterion) (SAC) and higher-order generalizations, and recommended this tool to select candidates for good [S-boxes](wikipedia://en/240991) achieving near-perfect [diffusion](wikipedia://en/537555).[^o24] Indeed, the functions satisfying the SAC to the highest possible order are always bent.[^o25] Furthermore, the bent functions are as far as possible from having what are called *linear structures*, nonzero vectors a such that *f*(*x* + *a*) + *f*(*x*) is a constant. In the language of [differential cryptanalysis](wikipedia://en/8536) (introduced after this property was discovered) the *derivative* of a bent function *f* at every nonzero point *a* (that is, *f*<sub>*a*</sub>(*x*) = *f*(*x* + *a*) + *f*(*x*)) is a [*balanced* Boolean function](wikipedia://en/24635433), taking on each value exactly half of the time. This property is called *perfect nonlinearity*.[^o19]

Given such good diffusion properties, apparently perfect resistance to differential cryptanalysis, and resistance by definition to [linear cryptanalysis](wikipedia://en/59469), bent functions might at first seem the ideal choice for secure cryptographic functions such as S-boxes. Their fatal flaw is that they fail to be balanced. In particular, an invertible S-box cannot be constructed directly from bent functions, and a [stream cipher](wikipedia://en/49007) using a bent combining function is vulnerable to a [correlation attack](wikipedia://en/19798753). Instead, one might start with a bent function and randomly complement appropriate values until the result is balanced. The modified function still has high nonlinearity, and as such functions are very rare the process should be much faster than a brute-force search.[^o19] But functions produced in this way may lose other desirable properties, even failing to satisfy the SAC – so careful testing is necessary.[^o25] A number of cryptographers have worked on techniques for generating balanced functions that preserve as many of the good cryptographic qualities of bent functions as possible.[^o26][^o27][^o28]

Some of this theoretical research has been incorporated into real cryptographic algorithms. The *CAST* design procedure, used by [Carlisle Adams](wikipedia://en/9212118) and [Stafford Tavares](wikipedia://en/9546396) to construct the S-boxes for the [block ciphers](https://en.wikipedia.org/wiki/Block_ciphers) [CAST-128](wikipedia://en/240998) and [CAST-256](wikipedia://en/612143), makes use of bent functions.[^o28] The [cryptographic hash function](wikipedia://en/439526) [HAVAL](wikipedia://en/1018362) uses Boolean functions built from representatives of all four of the [equivalence classes](wikipedia://en/9260) of bent functions on six variables.[^o29] The stream cipher [Grain](wikipedia://en/2710390) uses an [NLFSR](https://en.wikipedia.org/wiki/NLFSR) whose nonlinear feedback polynomial is, by design, the sum of a bent function and a linear function.[^o30]

## Generalizations {#Generalizations}

More than 25 different generalizations of bent functions are described in Tokareva's 2015 monograph.[^o17] There are algebraic generalizations (*q*-valued bent functions, *p*-ary bent functions, bent functions over a finite field, generalized Boolean bent functions of Schmidt, bent functions from a finite Abelian group into the set of complex numbers on the unit circle, bent functions from a finite Abelian group into a finite Abelian group, non-Abelian bent functions, vectorial G-bent functions, multidimensional bent functions on a finite Abelian group), combinatorial generalizations (symmetric bent functions, homogeneous bent functions, rotation symmetric bent functions, normal bent functions, self-dual and anti-self-dual bent functions, partially defined bent functions, plateaued functions, Z-bent functions and quantum bent functions) and cryptographic generalizations (semi-bent functions, balanced bent functions, partially bent functions, hyper-bent functions, bent functions of higher order, *k*-bent functions).

The most common class of *generalized bent functions* is the [mod *m*](wikipedia://en/20087) type, $f:\mathbb{Z}_m^n \to \mathbb{Z}_m$ such that

$$\hat{f}(a) = \sum_{x \in \mathbb{Z}_m^n} e^{\frac{2\pi i}{m} (f(x) - a \cdot x)}$$

has constant absolute value *m*<sup>*n*/2</sup>. Perfectly nonlinear functions $f:\mathbb{Z}_m^n \to \mathbb{Z}_m$, those such that for all nonzero *a*, *f*(*x* + *a*) − *f*(*a*) takes on each value *m*<sup>*n*−1</sup> times, are generalized bent. If *m* is [prime](wikipedia://en/23666), the converse is true. In most cases only prime *m* are considered. For odd prime *m*, there are generalized bent functions for every positive *n*, even and odd. They have many of the same good cryptographic properties as the binary bent functions.[^o31][^o32]

**Semi-bent functions** are an odd-order counterpart to bent functions. A semi-bent function is $f:\mathbb{Z}_m^n \to \mathbb{Z}_m$ with *n* odd, such that $\left|\hat{f}\right|$ takes only the values 0 and *m*<sup>(*n*+1)/2</sup>. They also have good cryptographic characteristics, and some of them are balanced, taking on all possible values equally often.[^o33]

The **partially bent functions** form a large class defined by a condition on the Walsh transform and autocorrelation functions. All affine and bent functions are partially bent. This is in turn a proper subclass of the *plateaued functions*.[^o34]

The idea behind the **hyper-bent functions** is to maximize the minimum distance to *all* Boolean functions coming from [bijective](wikipedia://en/3942) monomials on the finite field GF(2<sup>*n*</sup>), not just the affine functions. For these functions this distance is constant, which may make them resistant to an [interpolation attack](wikipedia://en/3329538).

Other related names have been given to cryptographically important classes of functions $f:\mathbb{Z}_2^n \to \mathbb{Z}_2^n$, such as **almost bent functions** and **crooked functions**. While not bent functions themselves (these are not even Boolean functions), they are closely related to the bent functions and have good nonlinearity properties.

:::
