# Littlewood–Paley theory

::: {#o1 .subject cue=lead name="Littlewood–Paley theory"}

In [harmonic analysis](wikipedia://en/14147), a field within mathematics, **Littlewood–Paley theory** is a theoretical framework used to extend certain results about square-integrable [*L*<sup>2</sup> functions](https://en.wikipedia.org/wiki/L2_function) to [*L*<sup>*p*</sup> functions](https://en.wikipedia.org/wiki/Lp_function) for 1 \< *p* \< ∞. It is typically used as a substitute for orthogonality arguments which only apply to *L*<sup>*p*</sup> functions when *p* = 2. One implementation involves studying a function by decomposing it in terms of functions with localized frequencies, and using the Littlewood–Paley *g*-function to compare it with its [Poisson integral](https://en.wikipedia.org/wiki/Poisson_integral). The 1-variable case was originated by (txt) and developed further by Polish mathematicians [A. Zygmund](https://en.wikipedia.org/wiki/A._Zygmund) and [J. Marcinkiewicz](https://en.wikipedia.org/wiki/J._Marcinkiewicz) in the 1930s using complex function theory (Zygmund 2002, chapters XIV, XV). [E. M. Stein](https://en.wikipedia.org/wiki/E._M._Stein) later extended the theory to higher dimensions using real variable techniques.

:::

::: {#o5 .pointer-item cue=pointer name="Dyadic decomposition"}

## The dyadic decomposition of a function {#The_dyadic_decomposition_of_a_function}

Littlewood–Paley theory uses a decomposition of a function *f* into a sum of functions *f*<sub>*ρ*</sub> with localized frequencies. There are several ways to construct such a decomposition; a typical method is as follows.

If *f(x)* is a function on **R**, and *ρ* is a measurable set (in the frequency space) with [characteristic function](wikipedia://en/240790) $\chi_\rho(\xi)$, then *f*<sub>*ρ*</sub> is defined via its [Fourier transform](wikipedia://en/52247)

$$\hat f_\rho := \chi_\rho\hat f.$$

Informally, *f*<sub>ρ</sub> is the piece of *f* whose frequencies lie in *ρ*.

If Δ is a collection of measurable sets which (up to measure 0) are disjoint and have union on the real line, then a well behaved function *f* can be written as a sum of functions *f*<sub>*ρ*</sub> for *ρ* ∈ Δ.

When Δ consists of the sets of the form

$$\rho = [-2^{k+1},-2^k] \cup [2^k,2^{k+1}].$$

for *k* an [integer](wikipedia://en/14563), this gives a so-called "dyadic decomposition" of *f* : Σ<sub>*ρ*</sub> *f*<sub>*ρ*</sub>.

There are many variations of this construction; for example, the characteristic function of a set used in the definition of *f*<sub>*ρ*</sub> can be replaced by a smoother function.

A key estimate of Littlewood–Paley theory is the Littlewood–Paley theorem, which bounds the size of the functions *f*<sub>*ρ*</sub> in terms of the size of *f*. There are many versions of this theorem corresponding to the different ways of decomposing *f*. A typical estimate is to bound the *L*<sup>*p*</sup> norm of (Σ<sub>*ρ*</sub> |*f*<sub>*ρ*</sub>|<sup>2</sup>)<sup>1/2</sup> by a multiple of the *L*<sup>*p*</sup> norm of *f*.

In higher dimensions it is possible to generalize this construction by replacing intervals with rectangles with sides parallel to the coordinate axes. Unfortunately these are rather special sets, which limits the applications to higher dimensions.

:::

::: {#o7 .pointer-item cue=pointer name="Littlewood-Paley g-function"}

## The Littlewood–Paley *g* function {#The_Littlewood–Paley_g_function}

The *g* function is a non-linear operator on *L*<sup>*p*</sup>(**R**<sup>*n*</sup>) that can be used to control the *L*<sup>*p*</sup> norm of a function *f* in terms of its [Poisson integral](https://en.wikipedia.org/wiki/Poisson_integral). The Poisson integral *u*(*x*,*y*) of *f* is defined for *y* > 0 by

$$u(x,y) = \int_{\mathbb R^n} P_y(t)f(x-t) \, dt$$

where the [Poisson kernel](wikipedia://en/2214583) *P* on the upper half space $\{ (y;x)\in\mathbf{R}^{n+1} \mid y>0\}$ is given by

$$P_y(x) = \int_{\mathbb R^n} e^{-2\pi i t \cdot x - 2\pi |t|y} \, dt = \frac{\Gamma((n+1)/2)}{\pi^{(n+1)/2}}\frac{y}{(|x|^2+y^2)^{(n+1)/2}}.$$

The Littlewood–Paley *g* function *g*(*f*) is defined by

$$g(f)(x) = \left(\int_0^\infty|\nabla u(x,y)|^2y \, dy\right)^{1/2}$$

A basic property of *g* is that it approximately preserves norms. More precisely, for 1 \< *p* \< ∞, the ratio of the *L*<sup>*p*</sup> norms of *f* and *g*(*f*) is bounded above and below by fixed positive constants depending on *n* and *p* but not on *f*.

:::

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

One early application of Littlewood–Paley theory was the proof that if *S*<sub>*n*</sub> are the partial sums of the [Fourier series](wikipedia://en/59038) of a periodic *L*<sup>*p*</sup> function (*p* > 1) and *n*<sub>*j*</sub> is a sequence satisfying *n*<sub>*j*+1</sub>/*n*<sub>*j*</sub> > *q* for some fixed *q* > 1, then the sequence *S*<sub>*n*<sub>*j*</sub></sub> converges [almost everywhere](wikipedia://en/44688). This was later superseded by the [Carleson–Hunt theorem](wikipedia://en/24105681) showing that *S*<sub>*n*</sub> itself converges almost everywhere.

Littlewood–Paley theory can also be used to prove the [Marcinkiewicz multiplier theorem](https://en.wikipedia.org/wiki/Marcinkiewicz_multiplier_theorem).
