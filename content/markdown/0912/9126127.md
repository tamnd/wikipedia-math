# Fair computational tree logic

::: {#o1 .subject cue=lead name="Fair computational tree logic"}

**Fair computational tree logic** is conventional [computational tree logic](https://en.wikipedia.org/wiki/Computational_tree_logic) studied with explicit fairness constraints.

:::

## Weak fairness / justice {#Weak_fairness_/_justice}

This declares conditions such as all processes execute infinitely often. If you consider the processes to be P<sub>i</sub>, then the condition becomes:

$$\bigwedge GFP_{i}$$

## Strong fairness / compassion {#Strong_fairness_/_compassion}

Here, if a process is requesting a resource infinitely often (R), it should be allowed to get the resource (C) infinitely often:

$$\bigwedge( GFR \longrightarrow GFC)$$

## Model checking for fair CTL {#Model_checking_for_fair_CTL}

Consider a [Kripke model](https://en.wikipedia.org/wiki/Kripke_model) with set of states *F*. A path $\pi = s_o, s_1 \dots$ is considered a **fair path**, if and only if the path includes all members of *F* infinitely often. Fair CTL [model checking](wikipedia://en/321157) restricts the checks to only fair paths. There are two kinds of fair quantifiers:

\1. M<sub>f</sub>, s<sub>i</sub> |= A$\phi$ if and only if $\phi$ holds in *all* fair paths.

\2. M<sub>f</sub>, s<sub>i</sub> |= E$\phi$ if and only if $\phi$ holds in *one or more* fair paths.

A **fair state** is one from which at least one fair path originates. This translates to M<sub>f</sub>, s |= EGtrue.

## SCC-based approach {#SCC-based_approach}

A [strongly connected component](wikipedia://en/684680) (SCC) of a directed graph is a maximal strongly connected subgraph—all the nodes are reachable from each other. A fair SCC is one that has an edge into at least one node for each of the fair conditions.

To check for fair EG for any formula,

1. Compute what is called the *denotation* of the formula *φ*: the set of states such that M, s |= *φ*.
1. Restrict the model to the denotation.
1. Find the fair SCC.
1. Obtain the union of all 3 (above).
1. Compute the states that can reach the union.

## Emerson Lei algorithm {#Emerson_Lei_algorithm}

The fix point characterization of Exist Globally is given by: \[EGφ\] = νZ .(\[φ\] ∩ \[EXZ \]), which is basically the limit applied according to [Kleene's theorem](https://en.wikipedia.org/wiki/Kleene's_theorem). To fair paths, it becomes \[Ef Gφ\] = νZ .(\[φ\] ∩<sub>Fi ∈FT</sub> \[EX\[E(Z U(Z ∧ Fi ))\]), which means the formula holds in the current state and the next states and the next to next states until it meets all the members of the fair conditions. This means that, the condition is equivalent to a sort of accepting point where the accepting condition is the entire set of Fair conditions.
