# Spectr-H64

::: {#o2 .subject cue=lead name="Spectr-H64"}

In [cryptography](wikipedia://en/18934432), **Spectr-H64** is a [block cipher](wikipedia://en/4594) designed in 2001 by N. D. Goots, A. A. Moldovyan and N. A. Moldovyan. It relies heavily on the [permutation](wikipedia://en/44027) of individual bits, so is much better suited to implementation in hardware than in software.

:::

The algorithm has a [block size](wikipedia://en/294065) of 64 bits and [key size](wikipedia://en/5749) of 256 bits. It uses a 12-round structure in which half of the block determines the transformation of the other half in each round, similar to a [Feistel cipher](wikipedia://en/352709) or [RC5](wikipedia://en/102600). This same basic design was repeated in its successor, [CIKS-1](wikipedia://en/8745236).

## Cryptanalysis {#Cryptanalysis}

An analysis of Spectr-H64 was presented in 2002 by Selçuk Kavut and Melek D Yücel of the Middle East Technical University, showing a method of using a [differential attack](https://en.wikipedia.org/wiki/Differential_attack) to retrieve half of the key bits when a single round is used. Using this method, they then presented a [slide attack](wikipedia://en/1821327) that requires 2<sup>17</sup> chosen plaintexts to return all key bits on the full 12 rounds.
