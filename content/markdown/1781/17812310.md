# Geometric data analysis

::: {#o1 .subject cue=lead name="Geometric data analysis"}

**Geometric data analysis** comprises [geometric](wikipedia://en/18973446) aspects of [image analysis](https://en.wikipedia.org/wiki/Image_analysis), [pattern analysis](https://en.wikipedia.org/wiki/Pattern_analysis), and [shape analysis](wikipedia://en/16576796), and the approach of [multivariate statistics](wikipedia://en/19384), which treat arbitrary data sets as *clouds of points* in a space that is *n*-dimensional. This includes [topological data analysis](wikipedia://en/17740009), [cluster analysis](wikipedia://en/669675), inductive data analysis, [correspondence analysis](wikipedia://en/11594341), [multiple correspondence analysis](wikipedia://en/24688532), [principal components analysis](https://en.wikipedia.org/wiki/Principal_components_analysis) and [iconography of correlations](wikipedia://en/67646381).

:::
