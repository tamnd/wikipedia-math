# Structured data analysis (statistics)

::: {#o1 .subject cue=lead name="Structured data analysis"}

**Structured data analysis** is the [statistical data analysis](wikipedia://en/26685) of [structured data](https://en.wikipedia.org/wiki/Structured_data). This can arise either in the form of an *a priori* structure such as multiple-choice questionnaires or in situations with the need to search for [structure](https://en.wikipedia.org/wiki/Structure) that fits the given data, either exactly or approximately. This structure can then be used for making comparisons, predictions, manipulations etc.[^o2][^o3]

:::
