# Null sign

*Image: Atheism symbol syreeni.svg.* A null sign

::: {#o1 .subject cue=lead name="Null sign"}

The **null sign** (∅) is a symbol often used in [mathematics](wikipedia://en/18831) for denoting the [empty set](wikipedia://en/9566). The same letter in [linguistics](https://en.wikipedia.org/wiki/Linguistics) represents [zero](https://en.wikipedia.org/wiki/Zero_%28linguistics%29), the lack of an element. It is commonly used in [phonology](https://en.wikipedia.org/wiki/Phonology), [morphology](https://en.wikipedia.org/wiki/Morphology_%28linguistics%29), and [syntax](wikipedia://en/26860).

:::

## Encodings {#Encodings}

The symbol ∅ is available at [Unicode](https://en.wikipedia.org/wiki/Unicode) point U+2205.[^o3] It can be coded in [HTML](https://en.wikipedia.org/wiki/HTML) as ∅, ∅, or ∅. In [LaTeX](https://en.wikipedia.org/wiki/LaTeX), it can be encoded as \\varnothing ($\varnothing$) or \\emptyset ($\emptyset$).

## Use in mathematics {#Use_in_mathematics}

In mathematics, the **null sign** (∅) denotes the [empty set](wikipedia://en/9566).[^o6][^o7] Note that a [null set](wikipedia://en/21520) is not necessarily an [empty set](wikipedia://en/9566). Common notations for the empty set include "{}", "∅", and "$\emptyset$". The latter two symbols were introduced by the [Bourbaki group](https://en.wikipedia.org/wiki/Bourbaki_group) (specifically [André Weil](wikipedia://en/2019)) in 1939, inspired by the letter [Ø](https://en.wikipedia.org/wiki/Ø) in the [Danish](https://en.wikipedia.org/wiki/Danish_orthography) and [Norwegian](https://en.wikipedia.org/wiki/Norwegian_orthography) alphabets[^o6] (and not related in any way to the Greek letter [Φ](https://en.wikipedia.org/wiki/Phi_%28letter%29)).[^o8]

Empty sets are used in set operations. For example:

> $$A=\{2,3,5,7,11\}$$
>
> $$B=\{4,6,8,9\}$$
>
> $$A \cap B = ?$$

There are no common elements in the solution; so it should be denoted as:

> $A \cap B = \varnothing$ or $A \cap B = \{ \}$

## Use in linguistics {#Use_in_linguistics}

In [linguistics](https://en.wikipedia.org/wiki/Linguistics), the null sign is used to indicate the absence of an element, such as a [phoneme](https://en.wikipedia.org/wiki/Phoneme) or [morpheme](https://en.wikipedia.org/wiki/Morpheme).[^o10]

## Use in photography {#Use_in_photography}

In [photography](https://en.wikipedia.org/wiki/Photography) the null sign, Ø, found on [camera lenses](https://en.wikipedia.org/wiki/Camera_lenses) denotes the filter thread diameter, measured in millimeters. This marking indicates the size of [screw-in filters](https://en.wikipedia.org/wiki/Photographic_filter) that can be attached to the front of the lens. This diameter is separate from any optical specification of the lens, as it is a standardized measurement for photographers to select a compatible filter. Common filter thread sizes include 52 +, 72 mm. If a photographer owns multiple lenses with different filter thread diameters, stepping rings can be utilized to adapt larger filters to smaller lens threads, eliminating the need to purchase duplicate filters in various sizes.
