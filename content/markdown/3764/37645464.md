# Tarski's World

::: {#o1 .subject cue=lead name="Tarski's World"}

**Tarski's World** is a computer-based introduction to [first-order logic](wikipedia://en/10983) written by [Jon Barwise](wikipedia://en/912858) and [John Etchemendy](wikipedia://en/5503538). It is named after the mathematical logician [Alfred Tarski](wikipedia://en/59920). The package includes a book, which serves as a textbook and manual, and a computer program which together serve as an introduction to the semantics of logic through games in which simple, three-dimensional worlds are populated with various geometric figures and these are used to test the truth or falsehood of first-order logic sentences. The program is also included in [Language, Proof and Logic](wikipedia://en/31629330) package.[^o2][^o3][^o4][^o5][^o6]

:::

The programme was later extended into Hyperproof.[^o7]
