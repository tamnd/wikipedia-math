# Lawvere's fixed-point theorem

::: {#o1 .subject cue=lead name="Lawvere's fixed-point theorem"}

In [mathematics](wikipedia://en/18831), **Lawvere's fixed-point theorem** is an important result in [category theory](wikipedia://en/5869).[^o2] It is a broad abstract generalization of many diagonal arguments in mathematics and logic, such as [Cantor's diagonal argument](wikipedia://en/51426), [Cantor's theorem](wikipedia://en/341442), [Russell's paradox](wikipedia://en/46095), [Gödel's first incompleteness theorem](https://en.wikipedia.org/wiki/Gödel's_first_incompleteness_theorem), [Turing's solution to the Entscheidungsproblem](wikipedia://en/3739933), and [Tarski's undefinability theorem](wikipedia://en/583785).[^o3]

:::

It was first proven by [William Lawvere](wikipedia://en/872760) in 1969.[^o4][^o5]

::: {#o7 .statement cue=heading name="Statement"}

## Statement {#Statement}

Lawvere's theorem states that, for any [Cartesian closed category](wikipedia://en/237037) $\mathbf{C}$ and given an object $B$ in it, if there is a [weakly point-surjective](https://en.wikipedia.org/wiki/Point-surjective_morphism#Definition#Weak_point-surjectivity) [morphism](wikipedia://en/27716891) $f$ from some object $A$ to the [exponential object](wikipedia://en/2237858) $B^A$, then every [endomorphism](wikipedia://en/9569)$g: B \rightarrow B$ has a fixed point. That is, there exists a morphism $b : 1 \rightarrow B$ (where $1$ is a [terminal object](wikipedia://en/59405) in $\mathbf{C}$ ) such that $g \circ b = b$.

This can be further generalized to a much broader class of categories. Let $\mathbf{C}$ be a category equipped with a [functor](wikipedia://en/10987) $\sharp : \mathbf{C} \times \mathbf{C} \rightarrow \mathbf{C}$, a chosen object $t$, and [natural transformation](wikipedia://en/45022) $\delta : id_\mathbf{C} \Rightarrow \sharp \circ \Delta_C$. Let $F : A \sharp A \rightarrow C$ and $\sigma : C \rightarrow C$ be morphisms in $\mathbf{C}$ such that, $\exists a_0 : t \rightarrow A, \forall a : t \rightarrow A$, such that $\sigma \circ F \circ \delta_A \circ a = F \circ (a_0 \sharp a) \circ \delta_t$. Then the map $c := F \circ \delta \circ a_0 : t \rightarrow C$ satisfies $\sigma \circ c = c$. [^o8]

:::

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

The theorem's [contrapositive](https://en.wikipedia.org/wiki/Contrapositive) is particularly useful in proving many results. It states that if there is an object $B$ in the category such that there is an endomorphism $g: B \rightarrow B$ that has no fixed points, then there is no object $A$ with a weakly point-surjective map $f : A \rightarrow B^A$. Some important corollaries of this are:[^o3]

- [Cantor's theorem](wikipedia://en/341442)
- [Cantor's diagonal argument](wikipedia://en/51426)
- [Diagonal lemma](wikipedia://en/348969)
- [Russell's paradox](wikipedia://en/46095)
- [Gödel's first incompleteness theorem](https://en.wikipedia.org/wiki/Gödel's_first_incompleteness_theorem)
- [Tarski's undefinability theorem](wikipedia://en/583785)
- [Turing's proof](wikipedia://en/3739933)
- [Löb's paradox](https://en.wikipedia.org/wiki/Löb's_paradox)
- [Roger's fixed-point theorem](wikipedia://en/155407#Rogers's_fixed-point_theorem)
- [Rice's theorem](wikipedia://en/25852)
