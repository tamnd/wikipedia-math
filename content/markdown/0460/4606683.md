# Diagonal functor

::: {#o1 .subject cue=lead name="Diagonal functor"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), the **diagonal functor** $\mathcal{C} \rightarrow \mathcal{C} \times \mathcal{C}$ is given by $\Delta(a) = \langle a,a \rangle$, which maps [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) as well as [morphisms](wikipedia://en/27716891). This [functor](wikipedia://en/10987) can be employed to give a succinct alternate description of the product of objects *within* the [category](wikipedia://en/53759) $\mathcal{C}$: a product $a \times b$ is a universal arrow from $\Delta$ to $\langle a,b \rangle$. The arrow comprises the projection maps.

:::

More generally, given a [small](https://en.wikipedia.org/wiki/Small_category) [index category](https://en.wikipedia.org/wiki/Index_category) $\mathcal{J}$, one may construct the [functor category](wikipedia://en/407039) $\mathcal{C}^\mathcal{J}$, the objects of which are called [diagrams](wikipedia://en/7651625). For each object $a$ in $\mathcal{C}$, there is a [constant diagram](https://en.wikipedia.org/wiki/Constant_functor) $\Delta_a : \mathcal{J} \to \mathcal{C}$ that maps every object in $\mathcal{J}$ to $a$ and every morphism in $\mathcal{J}$ to $1_a$. The diagonal functor $\Delta : \mathcal{C} \rightarrow \mathcal{C}^\mathcal{J}$ assigns to each object $a$ of $\mathcal{C}$ the diagram $\Delta_a$, and to each morphism $f: a \rightarrow b$ in $\mathcal{C}$ the [natural transformation](wikipedia://en/45022) $\eta$ in $\mathcal{C}^\mathcal{J}$ (given for every object $j$ of $\mathcal{J}$ by $\eta_j = f$). Thus, for example, in the case that $\mathcal{J}$ is a [discrete category](wikipedia://en/808519) with two objects, the diagonal functor $\mathcal{C} \rightarrow \mathcal{C} \times \mathcal{C}$ is recovered.

Diagonal functors provide a way to define [limits](wikipedia://en/39248) and [colimits](https://en.wikipedia.org/wiki/Colimit) of diagrams. Given a [diagram](wikipedia://en/7651625) $\mathcal{F} : \mathcal{J} \rightarrow \mathcal{C}$, a natural transformation $\Delta_a \to \mathcal{F}$ (for some object $a$ of $\mathcal{C}$) is called a [cone](wikipedia://en/7533645) for $\mathcal{F}$. These cones and their factorizations correspond precisely to the objects and morphisms of the [comma category](wikipedia://en/840950) $(\Delta\downarrow\mathcal{F})$, and a limit of $\mathcal{F}$ is a terminal object in $(\Delta\downarrow\mathcal{F})$, i.e., a [universal arrow](https://en.wikipedia.org/wiki/Universal_arrow) $\Delta \rightarrow \mathcal{F}$. Dually, a [colimit](https://en.wikipedia.org/wiki/Colimit) of $\mathcal{F}$ is an initial object in the comma category $(\mathcal{F}\downarrow\Delta)$, i.e., a universal arrow $\mathcal{F} \rightarrow \Delta$.

If every functor from $\mathcal{J}$ to $\mathcal{C}$ has a limit (which will be the case if $\mathcal{C}$ is [complete](wikipedia://en/62781)), then the operation of taking limits is itself a functor from $\mathcal{C}^\mathcal{J}$ to $\mathcal{C}$. The limit functor is the [right-adjoint](wikipedia://en/53991) of the diagonal functor. Similarly, the colimit functor (which exists if the category is cocomplete) is the left-adjoint of the diagonal functor. For example, the diagonal functor $\mathcal{C} \rightarrow \mathcal{C} \times \mathcal{C}$ described above is the left-adjoint of the binary [product functor](wikipedia://en/237868) and the right-adjoint of the binary [coproduct functor](wikipedia://en/310889).
