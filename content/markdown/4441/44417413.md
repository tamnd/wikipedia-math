# Ind-scheme

::: {#o1 .subject cue=lead name="Ind-scheme"}

In [algebraic geometry](wikipedia://en/1997), an **ind-scheme** is a set-valued [functor](wikipedia://en/10987) that can be written (represented) as a [direct limit](wikipedia://en/211566) (i.e., inductive limit) of [closed embedding](wikipedia://en/1623986) of [schemes](wikipedia://en/364754).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- $\mathbb{C}P^{\infty} = \varinjlim \mathbb{C}P^N$ is an ind-scheme.
- Perhaps the most famous example of an ind-scheme is an [infinite grassmannian](https://en.wikipedia.org/wiki/Infinite_grassmannian) (which is a quotient of the [loop group](wikipedia://en/1390288) of an [algebraic group](wikipedia://en/247924) *G*.)

:::
