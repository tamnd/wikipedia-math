# Strömberg wavelet

::: {#o1 .subject cue=lead name="Strömberg wavelet"}

In [mathematics](wikipedia://en/18831), the **Strömberg wavelet** is a certain [orthonormal wavelet](https://en.wikipedia.org/wiki/Orthonormal_wavelet) discovered by Jan-Olov Strömberg and presented in a paper published in 1983.[^o2] Even though the [Haar wavelet](wikipedia://en/50905) was earlier known to be an orthonormal wavelet, Strömberg wavelet was the first smooth orthonormal wavelet to be discovered. The term *wavelet* had not been coined at the time of publishing the discovery of Strömberg wavelet and Strömberg's motivation was to find an orthonormal basis for the [Hardy spaces](wikipedia://en/314780).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *m* be any [non-negative integer](https://en.wikipedia.org/wiki/Non-negative_integer). Let *V* be any [discrete subset](https://en.wikipedia.org/wiki/Discrete_subset) of the set *R* of [real numbers](wikipedia://en/20646438). Then *V* splits *R* into non-overlapping [intervals](wikipedia://en/49172). For any *r* in *V*, let *I*<sub>*r*</sub> denote the interval determined by *V* with *r* as the left endpoint. Let *P*<sup>(*m*)</sup>(*V*) denote the set of all [functions](wikipedia://en/185427) *f*(*t*) over *R* satisfying the following conditions:

- *f*(*t*) is [square integrable](https://en.wikipedia.org/wiki/Square_integrable).
- *f*(*t*) has [continuous](https://en.wikipedia.org/wiki/Continuity_%28mathematics%29) [derivatives](wikipedia://en/7921) of all orders up to *m*.
- *f*(*t*) is a [polynomial](wikipedia://en/23000) of degree *m* + 1 in each of the intervals *I*<sub>*r*</sub>.

If *A*<sub>0</sub> = {. . . , -2, -3/2, -1, -1/2} ∪ {0} ∪ {1, 2, 3, . . .} and *A*<sub>1</sub> = *A*<sub>0</sub> ∪ { 1/2 } then the **Strömberg wavelet** of order *m* is a function *S*<sup>*m*</sup>(*t*) satisfying the following conditions:[^o2]

- $$S^m(t)\in P^{(m)} (A_1).$$
- $\Vert S^m(t)\Vert=1$, that is, $\int_R\vert S^m(t)\vert^2\, dt = 1.$
- $S^m(t)$ is [orthogonal](https://en.wikipedia.org/wiki/Orthogonal) to $P^{(m)}(A_0)$, that is, $\int_R S^m(t)\, f(t)\, dt=0$ for all $f(t)\in P^{(m)}(A_0).$

### Properties of the set *P*<sup>(*m*)</sup>(*V*) {#Properties_of_the_set_P(m)(V)}

The following are some of the properties of the set *P*<sup>(*m*)</sup>(*V*):

1. Let the number of distinct elements in *V* be two. Then *f*(*t*) ∈ *P*<sup>(*m*)</sup>(*V*) if and only if *f*(*t*) = 0 for all *t*.
1. If the number of elements in *V* is three or more than *P*<sup>(*m*)</sup>(*V*) contains nonzero functions.
1. If *V*<sub>1</sub> and *V*<sub>2</sub> are discrete subsets of *R* such that *V*<sub>1</sub> ⊂ *V*<sub>2</sub> then *P*<sup>(*m*)</sup>(*V*<sub>1</sub>) ⊂ *P*<sup>(*m*)</sup>(*V*<sub>2</sub>). In particular, *P*<sup>(*m*)</sup>(*A*<sub>0</sub>) ⊂ *P*<sup>(*m*)</sup>(*A*<sub>1</sub>).
1. If *f*(*t*) ∈ *P*<sup>(*m*)</sup>(*A*<sub>1</sub>) then *f*(*t*) = *g*(*t*) + α λ(*t*) where α is constant and *g*(*t*) ∈ *P*<sup>(*m*)</sup>(*A*<sub>0</sub>) is defined by *g*(*r*) = *f*(*r*) for *r* ∈ *A*<sub>0</sub>.

### Strömberg wavelet as an orthonormal wavelet {#Strömberg_wavelet_as_an_orthonormal_wavelet}

The following result establishes the Strömberg wavelet as an [orthonormal wavelet](https://en.wikipedia.org/wiki/Orthonormal_wavelet).[^o2]

::: {#o8 .statement cue=heading name="Theorem"}

### Theorem {#Theorem}

Let *S*<sup>*m*</sup> be the Strömberg wavelet of order *m*. Then the following set

$$\left\{2^{j/2}S^m(2^jt-k):j,k \text{ integers }\right\}$$

is a complete [orthonormal](https://en.wikipedia.org/wiki/Orthonormal) system in the space of square integrable functions over *R*.

:::

:::

## Strömberg wavelets of order 0 {#Strömberg_wavelets_of_order_0}

*Image: StrombergWaveletOfOrderZero.png.* The graph of the Strömberg wavelet of order 0. The graph is scaled such that the value of the wavelet function at 1 is 1.

In the special case of Strömberg wavelets of order 0, the following facts may be observed:

1. If *f*(*t*) ∈ *P*<sup>0</sup>(*V*) then *f*(*t*) is defined uniquely by the discrete subset {*f*(*r*) : *r* ∈ *V*} of *R*.
1. To each *s* ∈ *A*<sub>0</sub>, a special function λ<sub>*s*</sub> in *A*<sub>0</sub> is associated: It is defined by λ<sub>*s*</sub>(*r*) = 1 if *r* = *s* and λ<sub>*s*</sub>(*r*) = 0 if *s* ≠ *r* ∈ *A*<sub>0</sub>. These special elements in *P*(*A*<sub>0</sub>) are called *simple tents*. The special simple tent λ<sub>1/2</sub>(*t*) is denoted by λ(*t*)

### Computation of the Strömberg wavelet of order 0 {#Computation_of_the_Strömberg_wavelet_of_order_0}

As already observed, the Strömberg wavelet *S*<sup>0</sup>(*t*) is completely determined by the set { *S*<sup>0</sup>(*r*) : *r* ∈ *A*<sub>1</sub> }. Using the defining properties of the Strömbeg wavelet, exact expressions for elements of this set can be computed and they are given below.[^o11]

$S^0(k) = S^0(1)(\sqrt{3}-2)^{k-1}$ for $k=1,2,3, \ldots$

$$S^0(\tfrac{1}{2}) = -S^0(1)\left(\sqrt{3}+\tfrac{1}{2}\right)$$

$$S^0(0) = S^0(1)(2\sqrt{3}-2)$$

$S^0(-\tfrac{k}{2}) = S^0(1)(2\sqrt{3}-2)(\sqrt{3}-2)^k$ for $k=1,2,3, \ldots$

Here *S*<sup>0</sup>(1) is constant such that ||*S*<sup>0</sup>(*t*)|| = 1.

### Some additional information about Strömberg wavelet of order 0 {#Some_additional_information_about_Strömberg_wavelet_of_order_0}

The Strömberg wavelet of order 0 has the following properties.[^o11]

- The Strömberg wavelet *S*<sup>0</sup>(*t*) [oscillates](https://en.wikipedia.org/wiki/Oscillation) about *t*-axis.
- The Strömberg wavelet *S*<sup>0</sup>(*t*) has [exponential decay](wikipedia://en/330320).
- The values of *S*<sup>0</sup>(*t*) for positive integral values of *t* and for negative half-integral values of *t* are related as follows: $S^0(-k/2)=(10-6\sqrt{3})S^0(k)$ for $k=1,2,3,\ldots\,.$
