# Toronto function

::: {#o1 .subject cue=lead name="Toronto function"}

In [mathematics](wikipedia://en/18831), the **Toronto function** is a modification of the [confluent hypergeometric function](wikipedia://en/1516095) defined by A. H. Heatley as[^n1][^n2]

:::

$$T(m,n,r)=r^{2n-m+1}e^{-r^2}\frac{\Gamma\big(\frac 1{2}m+\frac 1{2}\big)}{\Gamma(n+1)}{}_1F_1\big({\textstyle\frac 1{2}}m+{\textstyle\frac 1{2}};n+1;r^2\big),$$

where $\Gamma$ is the [gamma function](wikipedia://en/12316) and $_1F_1$ is a confluent hypergeometric function [of the first kind](wikipedia://en/1516095#Kummer's_equation).

The Toronto function has appeared in a study on the theory of turbulence.[^n3]
