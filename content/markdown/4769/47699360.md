# Bernstein's theorem (polynomials)

::: {#o1 .subject cue=lead name="Bernstein's theorem"}

In [mathematics](wikipedia://en/18831), **Bernstein's theorem** is an [inequality](wikipedia://en/89489) relating the maximum [modulus](wikipedia://en/5826#Definition_and_basic_operations) of a [complex](wikipedia://en/5826) [polynomial function](https://en.wikipedia.org/wiki/Polynomial_function) on the [unit disk](wikipedia://en/252738) with the maximum modulus of its [derivative](wikipedia://en/7921) on the unit disk. It was [proven](wikipedia://en/82285) by [Sergei Bernstein](wikipedia://en/976516) while he was working on [approximation theory](wikipedia://en/1092713).[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $\max_{|z|=1} |f(z)|$ denote the maximum modulus of an arbitrary function $f(z)$ on $|z|=1$, and let $f'(z)$ denote its derivative. Then for every polynomial $P(z)$ of [degree](wikipedia://en/5930652) $n$ we have

$$\max_{|z|=1} |P'(z)| \le n \max_{|z|=1} |P(z)|$$

and equality holds if and only if $P(z) = \alpha z^n$.[^o5]

:::

## Similar results {#Similar_results}

[Paul Erdős](wikipedia://en/601284) conjectured that if $P(z)$ has no zeros in $|z|<1$, then $\max_{|z|=1} |P'(z)| \le \frac{n}{2} \max_{|z|=1} |P(z)|$. This was proved by [Peter Lax](wikipedia://en/486365).[^o7] More generally, if $P(z)$ has no zeros in $|z|<k,$ for $k \ge 1$, then $\max_{|z|=1} |P'(z)| \le \frac{n}{1+k} \max_{|z|=1} |P(z)|$.[^o8]
