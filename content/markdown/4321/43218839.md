# Maharam algebra

::: {#o1 .subject cue=lead name="Maharam algebra"}

In mathematics, a **Maharam algebra** is a [complete Boolean algebra](wikipedia://en/1839944) with a continuous submeasure (defined below). They were introduced by Dorothy Maharam in 1947.[^o2]

:::

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A **continuous submeasure** or **Maharam submeasure** on a [Boolean algebra](wikipedia://en/54476844) is a [real-valued function](wikipedia://en/22284647) *m* such that

- $m(0)=0, m(1)=1,$ and $m(x)>0$ if $x\ne 0$.
- If $x\le y$, then $m(x)\le m(y)$.
- $$m(x\vee y)\le m(x)+m(y)-m(x\wedge y).$$
- If $x_n$ is a [decreasing sequence](https://en.wikipedia.org/wiki/Decreasing_sequence) with greatest lower bound 0, then the sequence $m(x_n)$ has [limit](wikipedia://en/26551602) 0.

A **Maharam algebra** is a [complete Boolean algebra](wikipedia://en/1839944) with a continuous submeasure.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

Every [probability measure](wikipedia://en/45437) is a continuous submeasure, so as the corresponding Boolean algebra of [measurable sets](https://en.wikipedia.org/wiki/Measurable_set) modulo [measure zero sets](wikipedia://en/21520) is complete, it is a Maharam algebra.

Michel Talagrand solved a long-standing problem by constructing a Maharam algebra that is not a [measure algebra](wikipedia://en/25626903), *i.e.*, that does not admit any countably additive strictly positive finite measure.[^o7]

:::
