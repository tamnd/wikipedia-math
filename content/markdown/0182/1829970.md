# Beta-dual space

::: {#o1 .subject cue=lead name="Beta-dual space"}

In [functional analysis](wikipedia://en/11180) and related areas of [mathematics](wikipedia://en/18831), the **beta-dual** or **$\beta$-dual** is a certain linear subspace of the [algebraic dual](https://en.wikipedia.org/wiki/Algebraic_dual) of a [sequence space](wikipedia://en/1701075).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a sequence space $X$, the **$\beta$-dual** of $X$ is defined as

$$X^{\beta}:= \left \{ x \in\mathbb{K}^\mathbb{N}\ : \ \sum_{i=1}^{\infty} x_i y_i\text{ converges }\quad \forall y \in X \right \}.$$

Here, $\mathbb{K}\in\{\mathbb{R},\mathbb{C}\}$ so that $\mathbb{K}$ denotes either the real or complex scalar field.

If $X$ is an [FK-space](wikipedia://en/1725128) then each $y$ in $X^{\beta}$ defines a [continuous linear form](https://en.wikipedia.org/wiki/Continuous_linear_form) on $X$

$$f_y(x) := \sum_{i=1}^{\infty} x_i y_i \qquad x \in X.$$

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- $$c_0^\beta = \ell^1$$
- $$(\ell^1)^\beta = \ell^\infty$$
- $$\omega^\beta = \{0\}$$

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The beta-dual of an FK-space $E$ is a [linear subspace](wikipedia://en/56357) of the [continuous dual](https://en.wikipedia.org/wiki/Continuous_dual) of $E$. If $E$ is an [FK-AK space](wikipedia://en/1940948) then the beta dual is linear isomorphic to the continuous dual.

:::
