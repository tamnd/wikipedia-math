# Subclass (set theory)

::: {#o1 .subject cue=lead name="Subclass"}

In [set theory](wikipedia://en/27553) and its applications throughout [mathematics](wikipedia://en/18831), a **subclass** is a [class](wikipedia://en/20696) contained in some other class in the same way that a [subset](wikipedia://en/27631) is a [set](wikipedia://en/26691) contained in some other set. One may also call this "inclusion of classes".

:::

That is, given classes *A* and *B*, *A* is a subclass of *B* [if and only if](wikipedia://en/14922) every member of *A* is also a member of *B*.[^o2] In fact, when using a definition of classes that requires them to be first-order definable, it is enough that *B* be a set; the [axiom of specification](https://en.wikipedia.org/wiki/Axiom_of_specification) essentially says that *A* must then also be a set.

As with subsets, the [empty set](wikipedia://en/9566) is a subclass of every class, and any class is a subclass of itself. But additionally, every class is a subclass of the class of all sets. Accordingly, the subclass relation makes the collection of all classes into a [Boolean lattice](https://en.wikipedia.org/wiki/Boolean_lattice), which the subset relation does not do for the collection of all sets. Instead, the collection of all sets is an [ideal](https://en.wikipedia.org/wiki/Ideal_%28lattice_theory%29) in the collection of all classes. (Of course, the collection of all classes is something larger than even a class!)
