# Basic affine jump diffusion

::: {#o1 .subject cue=lead name="Basic affine jump diffusion"}

In [mathematics](wikipedia://en/18831) [probability theory](wikipedia://en/23542), a **basic affine jump diffusion (basic AJD)** is a [stochastic process](wikipedia://en/47895) Z of the form

:::

$$dZ_t=\kappa (\theta -Z_t)\,dt+\sigma \sqrt{Z_t}\,dB_t+dJ_t,\qquad t\geq 0, Z_{0}\geq 0,$$

where $B$ is a standard [Brownian motion](wikipedia://en/4436), and $J$ is an independent [compound Poisson process](wikipedia://en/1082294) with constant jump intensity $l$ and independent exponentially distributed jumps with mean $\mu$. For the process to be well defined, it is necessary that $\kappa \theta \geq 0$ and $\mu \geq 0$. A basic AJD is a special case of an [affine process](https://en.wikipedia.org/wiki/Affine_process) and of a [jump diffusion](wikipedia://en/13760259). On the other hand, the [Cox–Ingersoll–Ross](https://en.wikipedia.org/wiki/Cox–Ingersoll–Ross) (CIR) process is a special case of a basic AJD.

Basic AJDs are attractive for modeling default times in [credit risk](https://en.wikipedia.org/wiki/Credit_risk) applications,[^o3][^o4][^o5][^o6] since both the [moment generating function](wikipedia://en/194634)

$$m\left( q\right) =\operatorname{E} \left( e^{q\int_0^t Z_s \, ds}\right) ,\qquad q\in \mathbb{R},$$

and the [characteristic function](wikipedia://en/3229401)

$$\varphi \left( u\right) =\operatorname{E} \left( e^{iu\int_0^t Z_s \, ds}\right) ,\qquad u\in \mathbb{R},$$

are known in [closed form](wikipedia://en/585143).[^o5]

The characteristic function allows one to calculate the density of an integrated basic AJD

$$\int_0^t Z_s \, ds$$

by [Fourier inversion](https://en.wikipedia.org/wiki/Fourier_inversion), which can be done efficiently using the [FFT](wikipedia://en/11512).
