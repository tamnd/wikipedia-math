# Nearest neighbour distribution

::: {#o1 .subject cue=lead name="Nearest neighbour distribution"}

In probability and statistics, a **nearest neighbor function**, **nearest neighbor distance distribution**,[^o2] **nearest-neighbor distribution function**[^o3] or **nearest neighbor distribution**[^o4] is a [mathematical function](https://en.wikipedia.org/wiki/Mathematical_function) that is defined in relation to [mathematical objects](https://en.wikipedia.org/wiki/Mathematical_objects) known as [point processes](wikipedia://en/2147685), which are often used as [mathematical models](wikipedia://en/20590) of physical phenomena representable as [randomly](https://en.wikipedia.org/wiki/Random) positioned [points](wikipedia://en/593693) in time, space or both.[^o5][^o6] More specifically, nearest neighbor functions are defined with respect to some point in the point process as being the [probability distribution](wikipedia://en/23543) of the distance from this point to its nearest neighboring point in the same point process, hence they are used to describe the probability of another point existing within some distance of a point. A nearest neighbor function can be contrasted with a [spherical contact distribution function](wikipedia://en/41575363), which is not defined in reference to some initial point but rather as the probability distribution of the radius of a sphere when it first encounters or makes contact with a point of a point process.

:::

Nearest neighbor function are used in the study of point processes[^o2][^o6][^o7] as well as the related fields of [stochastic geometry](wikipedia://en/22037813)[^o5] and [spatial statistics](wikipedia://en/9467349),[^o2][^o8] which are applied in various [scientific](https://en.wikipedia.org/wiki/Scientific) and [engineering](https://en.wikipedia.org/wiki/Engineering) disciplines such as [biology](https://en.wikipedia.org/wiki/Biology), [geology](https://en.wikipedia.org/wiki/Geology), [physics](wikipedia://en/22939), and [telecommunications](https://en.wikipedia.org/wiki/Telecommunications).[^o5][^o6][^o9][^o10]

## Point process notation {#Point_process_notation}

Point processes are mathematical objects that are defined on some underlying [mathematical space](https://en.wikipedia.org/wiki/Mathematical_space). Since these processes are often used to represent collections of points randomly scattered in space, time or both, the underlying space is usually *d*-dimensional [Euclidean space](wikipedia://en/9697) denoted here by $\textstyle \textbf{R}^{ d}$, but they can be defined on more [abstract](wikipedia://en/454446) mathematical spaces.[^o7]

Point processes have a number of interpretations, which is reflected by the various types of [point process notation](wikipedia://en/40765261).[^o5][^o10] For example, if a point $\textstyle x$ belongs to or is a member of a point process, denoted by $\textstyle {N}$, then this can be written as:[^o5]

$$\textstyle x\in {N},$$

and represents the point process being interpreted as a random [set](wikipedia://en/26691). Alternatively, the number of points of $\textstyle {N}$ located in some [Borel set](wikipedia://en/43327) $\textstyle B$ is often written as:[^o9][^o5][^o8]

$$\textstyle {N}(B),$$

which reflects a [random measure](wikipedia://en/10040846) interpretation for point processes. These two notations are often used in parallel or interchangeably.[^o5][^o8][^o9]

## Definitions {#Definitions}

### Nearest neighbor function {#Nearest_neighbor_function}

The nearest neighbor function, as opposed to the [spherical contact distribution function](wikipedia://en/41575363), is defined in relation to some point of a point process already existing in some region of space. More precisely, for some point in the point process $\textstyle {N}$, the nearest neighbor function is the probability distribution of the distance from that point to the nearest or closest neighboring point.

To define this function for a point located in $\textstyle \textbf{R}^d$ at, for example, the [origin](wikipedia://en/1313432) $\textstyle o$, the $\textstyle d$-dimensional [ball](wikipedia://en/160556) $\textstyle b(o,r)$ of radius $\textstyle r$ centered at the [origin](wikipedia://en/1313432) *o* is considered. Given a point of $\textstyle {N}$ existing at $\textstyle o$, then the **nearest neighbor function** is defined as:[^o5]

$$D_o(r)=1-P({N}(b(o,r))=1\mid o).$$

where $\textstyle P({N}(b(o,r))=1\mid o)$ denotes the conditional probability that there is one point of $\textstyle {N}$ located in $\textstyle b(o,r)$ given there is a point of $\textstyle {N}$ located at $\textstyle o$.

The reference point need not be at the origin, and can be located at an arbitrary point $\textstyle x\in\textbf{R}^d$. Given a point of $\textstyle {N}$ existing at $\textstyle x$, then the **nearest neighbor function**, is defined as:

$$D_x(r)=1-P({N}(b(x,r))=1\mid x).$$

:::

## Examples {#Examples}

Mathematical expressions of the nearest neighbor distribution only exist for a few point processes.

### Poisson point process {#Poisson_point_process}

For a [Poisson point process](wikipedia://en/41597450) $\textstyle {N}$ on $\textstyle \textbf{R}^d$ with [intensity measure](wikipedia://en/40969212#First_moment_measure) $\textstyle \Lambda$ the nearest neighbor function is:

$$D_x(r)=1-e^{-\Lambda(b(x,r))},$$

which for the homogeneous case becomes

$$D_x(r)=1-e^{-\lambda |b(x,r)|},$$

where $\textstyle |b(x,r)|$ denotes the volume (or more specifically, the [Lebesgue measure](wikipedia://en/18198)) of the (hyper) ball of radius $\textstyle r$. In the plane $\textstyle \textbf{R}^2$ with the reference point located at the origin, this becomes

$$D_x(r)=1-e^{-\lambda \pi r^2}.$$

:::

## Relationship to other functions {#Relationship_to_other_functions}

### Spherical contact distribution function {#Spherical_contact_distribution_function}

In general, the [spherical contact distribution function](wikipedia://en/41575363) and the corresponding nearest neighbor function are not equal. However, these two functions are identical for Poisson point processes.[^o5] In fact, this characteristic is due to a unique property of Poisson processes and their Palm distributions, which forms part of the result known as the *Slivnyak–Mecke*[^o9] or *Slivnyak's theorem*.[^o2]

### $J$-function {#-function}

The fact that the spherical distribution function *H*<sub>*s*</sub>(*r*) and nearest neighbor function *D*<sub>*o*</sub>(*r*) are identical for the Poisson point process can be used to statistically test if point process data appears to be that of a Poisson point process. For example, in spatial statistics the $J$-function is defined for all $r$ ≥ 0 as:[^o5]

$$J(r)=\frac{1-D_o(r)}{1-H_s(r)}$$

For a Poisson point process, the $J$ function is simply $J(r)$ = 1, hence why it is used as a [non-parametric](https://en.wikipedia.org/wiki/Non-parametric_statistics) test for whether data behaves as though it were from a Poisson process. It is, however, thought possible to construct non-Poisson point processes for which $J(r)$ = 1,[^o21] but such counterexamples are viewed as somewhat 'artificial' by some and exist for other statistical tests.[^o22]

More generally, $J$-function serves as one way (others include using [factorial moment measures](wikipedia://en/40990955)[^o2]) to measure the interaction between points in a point process.[^o5]
