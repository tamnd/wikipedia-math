# Fractional model

::: {#o1 .subject cue=lead name="Fractional model"}

In applied statistics, **fractional models** are, to some extent, related to [binary response models](https://en.wikipedia.org/wiki/Binary_response_model). However, instead of estimating the probability of being in one bin of a [dichotomous variable](https://en.wikipedia.org/wiki/Dichotomous_variable), the fractional model typically deals with variables that take on all possible values in the [unit interval](wikipedia://en/49324). One can easily generalize this model to take on values on any other interval by appropriate transformations.[^o2] Examples range from participation rates in [401(k)](https://en.wikipedia.org/wiki/401%28k%29) plans[^o3] to television ratings of [NBA](https://en.wikipedia.org/wiki/NBA) games.[^o4]

:::

## Description {#Description}

There have been two approaches to modeling this problem. Even though they both rely on an [index](wikipedia://en/18102#Index) that is linear in $x_{i}$ combined with a [link function](https://en.wikipedia.org/wiki/Link_function),[^o6] this is not strictly necessary. The first approach uses a [log-odds](https://en.wikipedia.org/wiki/Log-odds) transformation of $y$ as a linear function of $x_{i}$, i.e., $\operatorname{logit} y = \log \frac {y}{1-y} = x\beta$. This approach is problematic for two distinct reasons. The $y$ variable can not take on boundary values 1 and 0, and the interpretation of the coefficients is not straightforward. The second approach circumvents these issues by using the logistic regression as a link function. More specifically,

$$\operatorname E[y \lor x] = \frac {\exp(x\beta)}{1+\exp(x\beta)}$$

It immediately becomes clear that this set up is very similar to the [binary logit model](https://en.wikipedia.org/wiki/Binary_logit_model), with that difference that the $y$ variable can actually take on values in the unit interval. Many of the [estimation](wikipedia://en/36687154) techniques for the binary logit model, such as [non-linear least squares](wikipedia://en/15652764) and [quasi-MLE](https://en.wikipedia.org/wiki/Quasi-MLE), carry over in a natural way, just like [heteroskedasticity](https://en.wikipedia.org/wiki/Heteroskedasticity) adjustments and [partial effects](https://en.wikipedia.org/wiki/Partial_effects) calculations.[^o7]

Extensions to this [cross-sectional](https://en.wikipedia.org/wiki/Cross-sectional) model have been provided that allow for taking into account important econometric issues, such as endogenous explanatory variables and unobserved heterogeneous effects. Under [strict exogeneity](https://en.wikipedia.org/wiki/Strict_exogeneity) assumptions, it is possible to difference out these unobserved effects using [panel data](wikipedia://en/2499813) techniques, although weaker exogeneity assumptions can also result in consistent estimators.[^o8] [Control function](wikipedia://en/48673823) techniques to deal with endogeneity concerns have also been proposed.[^o9]
