# Fixed-effect Poisson model

::: {#o1 .subject cue=lead name="Fixed-effect Poisson model"}

In [statistics](wikipedia://en/26685), a **fixed-effect Poisson model** is a [Poisson regression](wikipedia://en/2708102) model used for static [panel data](wikipedia://en/2499813) when the outcome variable is [count data](wikipedia://en/15690807). Hausman, Hall, and Griliches pioneered the method in the mid-1980s. Their outcome of interest was the number of patents filed by firms, where they wanted to develop methods to control for the firm [fixed effects](wikipedia://en/4434344).[^o2] Linear panel data models use the linear additivity of the fixed effects to difference them out and circumvent the [incidental parameter problem](https://en.wikipedia.org/wiki/Incidental_parameter_problem). Even though Poisson models are inherently nonlinear, the use of the linear index and the exponential link function lead to multiplicative [separability](wikipedia://en/387750), more specifically [^o3]

:::

E\[*y*<sub>*it*</sub> ∨ *x*<sub>*i*1</sub>... *x*<sub>*iT*</sub>, *c*<sub>*i*</sub> \] = *m*(*x*<sub>*it*</sub>, *c*<sub>*i*</sub>, *b*<sub>0</sub> ) = exp(*c*<sub>*i*</sub> + *x*<sub>*it*</sub> *b*<sub>0</sub> ) = *a*<sub>*i*</sub> exp(*x*<sub>*it*</sub> *b*<sub>0</sub> ) = *μ*<sub>*ti*</sub> (1)

This formula looks very similar to the standard Poisson premultiplied by the term *a<sub>i</sub>*. As the conditioning set includes the observables over all periods, we are in the static panel data world and are imposing [strict exogeneity](https://en.wikipedia.org/wiki/Strict_exogeneity).[^o4] Hausman, Hall, and Griliches then use Andersen's conditional Maximum Likelihood methodology to estimate *b<sub>0</sub>*. Using *n*<sub>*i*</sub> = Σ *y*<sub>*it*</sub> allows them to obtain the following nice distributional result of *y<sub>i</sub>*

*y*<sub>*i*</sub> ∨ *n*<sub>*i*</sub>, *x*<sub>*i*</sub>, *c*<sub>*i*</sub> ~ Multinomial (*n*<sub>*i*</sub>, *p*<sub>1</sub> (*x*<sub>*i*</sub>, *b*<sub>0</sub>), ..., *p*<sub>*T*</sub> (*x*<sub>*i*</sub>, *b*<sub>0</sub> )) (2) where

$p_t(x_i, b_0) = \frac{m(x_{it}, b_0)}{\sum m(x_{it}, b_0)}. \quad$[^o5]

At this point, the estimation of the fixed-effect Poisson model is transformed in a useful way and can be estimated by maximum-likelihood estimation techniques for [multinomial](wikipedia://en/1045553) log likelihoods. This is computationally not necessarily very restrictive, but the distributional assumptions up to this point are fairly stringent. Wooldridge provided evidence that these models have nice robustness properties as long as the conditional mean assumption (i.e. equation 1) holds.[^o6] Chamberlain also provided [semi-parametric efficiency bounds](https://en.wikipedia.org/wiki/Semi-parametric_efficiency_bounds) for these estimators under slightly weaker exogeneity assumptions. However, these bounds are practically difficult to attain, as the proposed methodology needs [high-dimensional](https://en.wikipedia.org/wiki/High-dimensional) [nonparametric regressions](wikipedia://en/4536068) for attaining these bounds.
