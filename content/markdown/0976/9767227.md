# Low basis theorem

::: {#o1 .subject cue=lead name="Low basis theorem"}

The **low basis theorem** is one of several [basis theorems](wikipedia://en/53605449) in [computability theory](wikipedia://en/155414), each of which show that, given an infinite subtree of the binary tree $2^{<\omega}$, it is possible to find an infinite path through the tree with particular computability properties. The low basis theorem, in particular, shows that there must be a path which is [low](wikipedia://en/9767106); that is, the [Turing jump](wikipedia://en/1681091) of the path is Turing equivalent to the [halting problem](wikipedia://en/21391870) $\emptyset'$.

:::

## Statement and proof {#Statement_and_proof}

The low basis theorem states that every nonempty [$\Pi^0_1$ class](wikipedia://en/26004695) in $2^\omega$ (see [arithmetical hierarchy](wikipedia://en/186475)) contains a set of [low degree](wikipedia://en/9767106) (Soare 1987:109). This is equivalent, by definition, to the statement that each infinite computable subtree of the binary tree $2^{<\omega}$ has an infinite path of low degree.

The proof uses the method of forcing with $\Pi^0_1$ classes (Cooper 2004:330). Hájek and Kučera (1989) showed that the low basis is provable in the formal system of arithmetic known as $\mathsf{I}\Sigma_1$.

The forcing argument can also be formulated explicitly as follows. For a set $X\subseteq\omega$, let $f(X) = \sum_{\{i\}(X)\downarrow} 2^{-i}$, where ${\{i\}(X)\downarrow}$ means that Turing machine $i$ halts on $X$ (with the sum being over all such $i$). Then, for every nonempty (lightface) $\Pi^0_1$ set $S\subseteq 2^\omega$, the (unique) $X\in S$ minimizing $f(X)$ has a low Turing degree. This is because $X$ satisfies ${\{i\}(X)\downarrow} \iff \forall Y\in S({\{i\}(Y)\downarrow} \lor \exists j < i ({\{j\}(Y)\downarrow} \land \lnot{\{j\}(X)\downarrow}))$, so the function $i \mapsto {\{i\}(X)\downarrow}$ can be computed from $\emptyset'$ by induction on $i$; note that $\forall Y\in S \phi(Y)$ is $\Sigma^0_1$ for any $\Sigma^0_1$ set $\phi$. In other words, whether a machine halts on $X$ is *forced* by a finite condition, which allows for $X' = \emptyset'$.

::: {#o4 .application cue=heading name="Application"}

## Application {#Application}

One application of the low basis theorem is to construct completions of effective theories so that the completions have low Turing degree. For example, the low basis theorem implies the existence of [PA degrees](wikipedia://en/22822116) strictly below $\emptyset'$.

:::
