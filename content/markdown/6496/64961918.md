# Quasitrace

::: {#o1 .subject cue=lead name="Quasitrace"}

In [mathematics](wikipedia://en/18831), especially [functional analysis](wikipedia://en/11180), a **quasitrace** is a not necessarily additive tracial functional on a [C\*-algebra](wikipedia://en/7184). An additive quasitrace is called a **trace**. It is a major open problem if every quasitrace is a trace.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **quasitrace** on a C\*-algebra *A* is a map $\tau\colon A_+\to[0,\infty]$ such that:

- $\tau$ is **homogeneous**:

$\tau(\lambda a)=\lambda\tau(a)$ for every $a\in A_+$ and $\lambda\in[0,\infty)$.

- $\tau$ is **tracial**:

$\tau(xx^*)=\tau(x^*x)$ for every $x\in A$.

- $\tau$ is **additive** on [commuting](wikipedia://en/294390) elements:

$\tau(a+b)=\tau(a)+\tau(b)$ for every $a,b\in A_+$ that satisfy $ab=ba$.

- and such that for each $n\geq 1$ the induced map

$$\tau_n\colon M_n(A)_+\to[0,\infty], (a_{j,k})_{j,k=1,...,n}\mapsto\tau(a_{11})+...\tau(a_{nn})$$

has the same properties.

A quasitrace $\tau$ is:

- **bounded** if

$$\sup\{\tau(a):a\in A_+, \|a\|\leq 1\} < \infty.$$

- **normalized** if

$$\sup\{\tau(a):a\in A_+, \|a\|\leq 1\} = 1.$$

- **lower semicontinuous** if

$\{a\in A_+ : \tau(a)\leq t\}$ is closed for each $t\in[0,\infty)$.

:::

::: {#o5 .statement kind=statement/generalization cue=heading name="Variants"}

## Variants {#Variants}

- A **1-quasitrace** is a map $A_+\to[0,\infty]$ that is just homogeneous, tracial and additive on commuting elements, but does not necessarily extend to such a map on matrix algebras over *A*. If a 1-quasitrace extends to the matrix algebra $M_n(A)$, then it is called a **n-quasitrace**. There are examples of 1-quasitraces that are not 2-quasitraces. One can show that every 2-quasitrace is automatically a n-quasitrace for every $n\geq 1$. Sometimes in the literature, a *quasitrace* means a *1-quasitrace* and a *2-quasitrace* means a *quasitrace*.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A quasitrace that is additive on all elements is called a **trace**.
- [Uffe Haagerup](wikipedia://en/46705302) showed that every quasitrace on a unital, [exact C\*-algebra](wikipedia://en/36732832) is additive and thus a trace. The article of Haagerup was circulated as handwritten notes in 1991 and remained unpublished until 2014. Blanchard and Kirchberg removed the assumption of unitality in Haagerup's result.[^o9] As of today (August 2020) it remains an open problem if every quasitrace is additive.
- [Joachim Cuntz](wikipedia://en/38543091) showed that a simple, unital C\*-algebra is stably finite [if and only if](wikipedia://en/14922) it admits a dimension function. A simple, unital C\*-algebra is stably finite if and only if it admits a normalized quasitrace. An important consequence is that every simple, unital, stably finite, exact C\*-algebra admits a tracial state.
- Every quasitrace on a [von Neumann algebra](wikipedia://en/294185) is a trace.

:::
