# Ruler function

::: {#o1 .subject cue=lead name="Ruler function"}

*Image: Measurement unit.jpg.* A ruler, marked in centimeters (top), and inches (bottom). The rising and falling pattern of vertical lines on the inch scale resembles the ruler function.

In [number theory](wikipedia://en/21527), the **ruler function** of an integer $n$ can be either of two closely related functions. One of these functions counts the number of times $n$ can be evenly divided by two, which for the numbers 1, 2, 3, ... is

Alternatively, the ruler function can be defined as the same numbers plus one, which for the numbers 1, 2, 3, ... produces the sequence

As well as being related by adding one, these two sequences are related in a different way: the second one can be formed from the first one by removing all the zeros, and the first one can be formed from the second one by adding zeros at the start and between every pair of numbers. For either definition of the ruler function, the rising and falling patterns of the values of this function resemble the lengths of marks on [rulers](wikipedia://en/65593) with traditional units such as [inches](https://en.wikipedia.org/wiki/Inch). These functions should be distinguished from [Thomae's function](wikipedia://en/3397404), a function on [real numbers](wikipedia://en/20646438) which behaves similarly to the ruler function when restricted to the [dyadic rational numbers](https://en.wikipedia.org/wiki/Dyadic_rational_number).

:::

The 0-based ruler function is also known as the [2-adic valuation](wikipedia://en/16047618) of its argument,[^o2] and gives the position of the bit that changes at a given step of the [Gray code](wikipedia://en/50564).[^o3] The sequence of values of the ruler function is the [lexicographically earliest](wikipedia://en/567667) infinite [square-free word](wikipedia://en/4088382) over the natural numbers.[^o4]

In the [Tower of Hanoi](wikipedia://en/56990) puzzle, with the disks of the puzzle numbered in order by their size, the 1-based ruler function gives the number of the disk to move at each step in an optimal solution to the puzzle.[^o5] A simulation of the puzzle, in conjunction with other methods for generating its optimal sequence of moves, can be used in an algorithm for generating the sequence of values of the ruler function in [constant time](https://en.wikipedia.org/wiki/Constant_time) per value.[^o3]
