# Accessibility relation

*Image: Simple kripke model.png.* A simple [Kripke model](https://en.wikipedia.org/wiki/Kripke_model) with only three [possible worlds](https://en.wikipedia.org/wiki/Possible_worlds), viz. $u$, $v$, $w$. Since the accessibility relation relates $w$ to $v$ and $P$ is true at $v$, the formula $\Diamond P$ is true at $w$. Since $u$ is not accessible from $w$, the fact that $Q$ is true at $u$ does not lead $\Diamond Q$ to be true at $w$.

::: {#o1 .subject cue=lead name="Accessibility relation"}

An **accessibility relation** is a [relation](https://en.wikipedia.org/wiki/Relation_%28math%29) which plays a key role in assigning truth values to sentences in the [relational semantics](wikipedia://en/911960) for [modal logic](wikipedia://en/333365). In relational semantics, a modal formula's [truth value](wikipedia://en/161711) at a *[possible world](wikipedia://en/780566)* $w$ can depend on what is true at another possible world $v$, but only if the accessibility relation $R$ relates $w$ to $v$. For instance, if $P$ holds at some world $v$ such that $wRv$, the formula $\Diamond P$ will be true at $w$. The fact $wRv$ is crucial. If $R$ did not relate $w$ to $v$, then $\Diamond P$ would be false at $w$ unless $P$ also held at some other world $u$ such that $wRu$.[^o2][^o3]

:::

Accessibility relations are motivated conceptually by the fact that [natural language](wikipedia://en/21173) [modal statements](https://en.wikipedia.org/wiki/Linguistic_modality) depend on some, but not all, alternative scenarios. For instance, the sentence "It might be raining" is not generally judged true simply because one can imagine a scenario where it is raining. Rather, its truth depends on whether such a scenario is ruled out by available information. This fact can be formalized in modal logic by choosing an accessibility relation such that $wRv$ if $v$ is compatible with the information that is available to the speaker in $w$.

This idea can be extended to various applications of modal logic. In [epistemic logic](https://en.wikipedia.org/wiki/Epistemic_logic), one can use an epistemic notion of accessibility where $wRv$ for an individual $I$ if $I$ does not know something which would rule out the hypothesis that $w'=v$. In [deontic logic](wikipedia://en/1343980), one can say that $wRv$ if $v$ is a morally ideal world given the moral standards of $w$. In the application of modal logic to [computer science](https://en.wikipedia.org/wiki/Computer_science), possible worlds can be understood as representing possible states of a system and the accessibility relation can be understood as representing state transitions (see [Kripke structure (model checking)](https://en.wikipedia.org/wiki/Kripke_structure_%28model_checking%29)). Then $wRv$ if the system can transition from state $w$ to state $v$.

Different applications of modal logic can suggest different restrictions on admissible accessibility relations, which can in turn lead to different validities. The mathematical study of how validities are tied to conditions on accessibility relations is known as *modal correspondence theory*.
