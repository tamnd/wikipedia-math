# Zero-truncated Poisson distribution

::: {#o1 .subject cue=lead name="Zero-truncated Poisson distribution"}

In [probability theory](wikipedia://en/23542), the **zero-truncated Poisson distribution** (**ZTP distribution**) is a certain [discrete probability distribution](https://en.wikipedia.org/wiki/Discrete_probability_distribution) whose support is the set of positive integers. This distribution is also known as the **conditional Poisson distribution**[^o2] or the **positive Poisson distribution**.[^o3] It is the conditional [probability distribution](wikipedia://en/23543) of a [Poisson-distributed](wikipedia://en/23009144) [random variable](wikipedia://en/25685), given that the value of the random variable is not zero. Thus it is impossible for a ZTP random variable to be zero. Consider for example the random variable of the number of items in a shopper's basket at a supermarket checkout line. Presumably a shopper does not stand in line with nothing to buy (i.e., the minimum purchase is 1 item), so this phenomenon may follow a ZTP distribution.[^o4]

:::

Since the ZTP is a [truncated distribution](wikipedia://en/7179738) with the truncation stipulated as $k > 0$, one can derive the [probability mass function](wikipedia://en/154725) $g(k;\lambda)$ from a standard Poisson distribution $f(k;\lambda$) as follows: [^o5]

$$g(k;\lambda) = P(X = k \mid X > 0) = \frac{f(k;\lambda)}{1-f(0;\lambda)} = \frac{\lambda ^ k e^{- \lambda} }{k ! \left ( 1 - e^{- \lambda} \right )} = \frac{\lambda^k}{(e^\lambda-1)k!}$$

The [mean](wikipedia://en/9653) is

$$\operatorname{E}[X]=\frac{\lambda}{1-e^{-\lambda}}=\frac{\lambda e^\lambda}{e^\lambda-1}$$

and the [variance](wikipedia://en/32344) is

$$\operatorname{Var}[X]=\frac{\lambda+\lambda^2}{1-e^{-\lambda}} - \frac{\lambda^2 }{(1-e^{-\lambda})^2} = \operatorname{E}[X](1+\lambda-\operatorname{E}[X])$$

## Parameter estimation {#Parameter_estimation}

The [method of moments](wikipedia://en/2175504) estimator $\widehat{\lambda}$ for the parameter $\lambda$ is obtained by solving

$$\frac{\widehat{\lambda}}{1-e^{-\widehat{\lambda}}} = \bar{x}$$

where $\bar{x}$ is the [sample mean](https://en.wikipedia.org/wiki/Sample_mean).[^o2]

This equation has a solution in terms of the [Lambert W function](wikipedia://en/92465). In practice, a solution may be found using numerical methods.

## Generating zero-truncated Poisson-distributed random variables {#Generating_zero-truncated_Poisson-distributed_random_variables}

Random variables sampled from the zero-truncated Poisson distribution may be achieved using algorithms derived from Poisson distribution sampling algorithms.[^o10]

**init**: **Let** k ← 1, t ← *e*<sup>−λ</sup> / (1 - *e*<sup>−λ</sup>) \* λ, s ← t. Generate uniform random number u in \[0,1\]. **while** s \< u **do**: k ← k + 1. t ← t \* λ / k. s ← s + t. **return** k.

The cost of the procedure above is linear in $k$, which may be large for large values of $\lambda$. Given access to an efficient sampler for non-truncated Poisson random variates, a non-iterative approach involves sampling from a truncated [exponential distribution](wikipedia://en/45906) representing the time of the first event in a [Poisson point process](wikipedia://en/41597450), conditional on such an event existing.[^o11] A simple [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) implementation with [NumPy](https://en.wikipedia.org/wiki/NumPy) is:

```python
def sample_zero_truncated_poisson(rate):
    u = np.random.uniform(np.exp(-rate), 1)
    t = -np.log(u)
    return 1 + np.random.poisson(rate - t)
```
