# List of algebras

::: {#o1 .subject cue=lead name="List of algebras"}

This is a list of possibly [nonassociative algebras](https://en.wikipedia.org/wiki/Nonassociative_algebra). An algebra is a [module](wikipedia://en/276410), wherein you can also [multiply](wikipedia://en/30844) two module elements. (The multiplication in the module is compatible with multiplication-by-scalars from the base [ring](wikipedia://en/48404)).
