# Mathematics Made Difficult

::: {#o1 .subject cue=lead name="Mathematics Made Difficult"}

***Mathematics Made Difficult*** is a book by Carl E. Linderholm that uses advanced mathematical methods to prove results normally shown using [elementary proofs](wikipedia://en/9318685). Although the aim is largely [satirical](https://en.wikipedia.org/wiki/Satirical),[^o3][^o4] it also shows the non-trivial mathematics behind operations normally considered obvious, such as [numbering](https://en.wikipedia.org/wiki/Numbering), [counting](wikipedia://en/275768), and [factoring integers](https://en.wikipedia.org/wiki/Factoring_integers). Linderholm discusses these seemingly obvious ideas using concepts like [categories](wikipedia://en/5869) and [monoids](wikipedia://en/19652).[^o5]

:::

As an example, the proof that 2 is a [prime number](wikipedia://en/23666) starts:

> It is easily seen that the only numbers between 0 and 2, including 0 but excluding 2, are 0 and 1. Thus the remainder left by any number on division by 2 is either 0 or 1. Hence the [quotient ring](wikipedia://en/184635) *Z*/2*Z*, where 2*Z* is the [ideal](wikipedia://en/25977) in Z generated by 2, has only the [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) \[0\] and \[1\], where these are the [images](wikipedia://en/579311) of 0 and 1 under the canonical [quotient map](wikipedia://en/237213). Since \[1\] must be the [unit](https://en.wikipedia.org/wiki/Unit_%28mathematics%29) of this ring, every element of this ring except \[0\] is a unit, and the ring is a [field](wikipedia://en/10603) ...[^o6]
