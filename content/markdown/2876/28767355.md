# Uniformization (probability theory)

::: {#o1 .subject cue=lead name="Uniformization"}

In [probability theory](wikipedia://en/23542), **uniformization** method, (also known as **Jensen's method**[^o7] or the **randomization method**[^o2]) is a method to compute transient solutions of finite state [continuous-time Markov chains](wikipedia://en/1125342), by approximating the process by a [discrete-time Markov chain](wikipedia://en/3383619).[^o2] The original chain is scaled by the fastest transition rate *γ*, so that transitions occur at the same rate in every state, hence the name. The method is simple to program and efficiently calculates an approximation to the transient distribution at a single point in time (near zero).[^o7] The method was first introduced by Winfried Grassmann in 1977.[^o3][^o4][^o5]

:::

## Method description {#Method_description}

For a continuous-time [Markov chain](wikipedia://en/60876) with [transition rate matrix](https://en.wikipedia.org/wiki/Transition_rate_matrix) *Q*, the uniformized discrete-time Markov chain has probability transition matrix $P:=(p_{ij})_{i,j}$, which is defined by[^o7][^o8][^o9]

$$p_{ij} = \begin{cases} q_{ij}/\gamma &\text{ if } i \neq j \\ 1 - \sum_{k \neq i} q_{ik}/\gamma &\text{ if } i=j \end{cases}$$

with *γ*, the uniform rate parameter, chosen such that

$$\gamma \geq \max_i |q_{ii}|.$$

In matrix notation:

$$P=I+\frac{1}{\gamma}Q.$$

For a starting distribution $\pi$(0), the distribution at time *t*, $\pi$(*t*) is computed by[^o7]

$$\pi(t) = \sum_{n=0}^\infty \pi(0) P^n \frac{(\gamma t)^n}{n!}e^{-\gamma t}.$$

This representation shows that a continuous-time Markov chain can be described by a discrete Markov chain with transition matrix *P* as defined above where jumps occur according to a Poisson process with intensity *γt*.

In practice this [series](wikipedia://en/15287) is terminated after finitely many terms.

## Implementation {#Implementation}

[Pseudocode](https://en.wikipedia.org/wiki/Pseudocode) for the algorithm is included in Appendix A of Reibman and Trivedi's 1988 paper.[^o12] Using a [parallel](https://en.wikipedia.org/wiki/Parallel_algorithm) version of the algorithm, chains with state spaces of larger than 10<sup>7</sup> have been analysed.[^o13]

:::

## Limitations {#Limitations}

Reibman and Trivedi state that "uniformization is the method of choice for typical problems," though they note that for [stiff](wikipedia://en/2091823) problems some tailored algorithms are likely to perform better.[^o12]
