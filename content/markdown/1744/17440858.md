# Lander–Green algorithm

::: {#o1 .subject cue=lead name="Lander–Green algorithm"}

The **Lander–Green algorithm** is an algorithm, due to [Eric Lander](wikipedia://en/610184) and [Philip Green](https://en.wikipedia.org/wiki/Philip_Green_%28geneticist%29) for computing the [likelihood](https://en.wikipedia.org/wiki/Likelihood) of observed genotype data given a [pedigree](https://en.wikipedia.org/wiki/Pedigree_chart). It is appropriate for relatively small pedigrees and a large number of markers. It is used in the analysis of [genetic linkage](https://en.wikipedia.org/wiki/Genetic_linkage).[^o2][^o3]

:::
