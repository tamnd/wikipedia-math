# Elston–Stewart algorithm

::: {#o1 .subject cue=lead name="Elston–Stewart algorithm"}

The **Elston–Stewart algorithm** is an algorithm for computing the [likelihood](https://en.wikipedia.org/wiki/Likelihood) of observed data on a [pedigree](https://en.wikipedia.org/wiki/Pedigree_chart) assuming a general model under which specific genetic segregation, linkage and association models can be tested.[^o2] It is due to [Robert Elston](https://en.wikipedia.org/wiki/Robert_Elston) and [John Stewart](https://en.wikipedia.org/wiki/John_Stewart_%28scientist%29). It can handle relatively large pedigrees providing they are (almost) outbred. When used for linkage analysis its computation time is exponential in the number of markers, in contrast to the [Lander-Green algorithm](wikipedia://en/17440858), which has computational time exponential in the number of pedigree members.[^o3]

:::
