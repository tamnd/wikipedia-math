# Delta-ring

::: {#o1 .subject cue=lead name="Delta-ring"}

In [mathematics](wikipedia://en/18831), a [non-empty](wikipedia://en/9566) [collection](wikipedia://en/723043) of [sets](wikipedia://en/26691) $\mathcal{R}$ is called a **\-ring** (pronounced "delta-ring") if it is [closed](wikipedia://en/293802) under [union](wikipedia://en/47949), [relative complementation](wikipedia://en/54347), and countable [intersection](wikipedia://en/23476429). The name "delta-ring" originates from the German word for intersection, "Durchschnitt", which is meant to highlight the ring's closure under countable intersection, in contrast to a [\-ring](wikipedia://en/6928351) which is closed under countable unions.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [family of sets](wikipedia://en/723043) $\mathcal{R}$ is called a **\-ring** if it has all of the following properties:

1. Closed under finite unions: $A \cup B \in \mathcal{R}$ for all $A, B \in \mathcal{R},$
1. Closed under relative complementation: $A - B \in \mathcal{R}$ for all $A, B \in \mathcal{R},$ and
1. Closed under countable intersections: $\bigcap_{n=1}^{\infty} A_n \in \mathcal{R}$ if $A_n \in \mathcal{R}$ for all $n \in \mathbb{N}.$

If only the first two properties are satisfied, then $\mathcal{R}$ is a [ring of sets](wikipedia://en/2686481) but not a -ring. Every [\-ring](wikipedia://en/6928351) is a -ring, but not every -ring is a [\-ring](wikipedia://en/6928351).

\-rings can be used instead of [σ-algebras](wikipedia://en/29586) in the development of [measure theory](https://en.wikipedia.org/wiki/Measure_theory) if one does not wish to allow sets of infinite measure.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

The family $\mathcal{K} = \{ S \subseteq \mathbb{R} : S \text{ is bounded} \}$ is a -ring but not a [\-ring](wikipedia://en/6928351) because $\bigcup_{n=1}^{\infty} [0, n]$ is not bounded.

:::
