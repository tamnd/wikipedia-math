# Constant-weight code

::: {#o1 .subject cue=lead name="Constant-weight code"}

In [coding theory](wikipedia://en/321869), a **constant-weight code**, also called an ***m*-of-*n* code** or ***m*-out-of-*n* code**, is an [error detection and correction](wikipedia://en/10375) code where all codewords share the same [Hamming weight](wikipedia://en/1127884). The [one-hot](https://en.wikipedia.org/wiki/One-hot) code and the **balanced code** are two widely used kinds of constant-weight code.

:::

The theory is closely connected to that of [designs](wikipedia://en/2761968) (such as [*t*-designs](wikipedia://en/1188184) and [Steiner systems](wikipedia://en/28016)). Most of the work on this field of [discrete mathematics](wikipedia://en/8492) is concerned with *binary* constant-weight codes.

Binary constant-weight codes have several applications, including [frequency hopping](https://en.wikipedia.org/wiki/Frequency-hopping_spread_spectrum) in [GSM](https://en.wikipedia.org/wiki/Global_System_for_Mobile_Communications) networks.[^o2] Most [barcodes](https://en.wikipedia.org/wiki/Barcode) use a binary constant-weight code to simplify automatically setting the brightness threshold that distinguishes black and white stripes. Most [line codes](https://en.wikipedia.org/wiki/Line_code) use either a constant-weight code, or a nearly-constant-weight [paired disparity code](https://en.wikipedia.org/wiki/Paired_disparity_code). In addition to use as error correction codes, the large space between code words can also be used in the design of [asynchronous circuits](https://en.wikipedia.org/wiki/Asynchronous_circuit) such as [delay insensitive circuits](https://en.wikipedia.org/wiki/Delay_insensitive_circuit).

Constant-weight codes, like [Berger codes](https://en.wikipedia.org/wiki/Berger_code), can detect all unidirectional errors.

## *A*(*n*, *d*, *w*) {#A(n,_d,_w)}

The central problem regarding constant-weight codes is the following: what is the maximum number of codewords in a binary constant-weight code with length $n$, [Hamming distance](wikipedia://en/41227) $d$, and weight $w$? This number is called $A(n,d,w)$.

Apart from some trivial observations, it is generally impossible to compute these numbers in a straightforward way. Upper bounds are given by several important theorems such as the [first](https://en.wikipedia.org/wiki/First_Johnson_bound) and [second Johnson bounds](https://en.wikipedia.org/wiki/Second_Johnson_bound),[^o4] and better upper bounds can sometimes be found in other ways. Lower bounds are most often found by exhibiting specific codes, either with use of a variety of methods from discrete mathematics, or through heavy computer searching. A large table of such record-breaking codes was published in 1990,[^o5] and an extension to longer codes (but only for those values of $d$ and $w$ which are relevant for the GSM application) was published in 2006.[^o2]

## 1-of-*N* codes {#1-of-N_codes}

A special case of constant weight codes are the one-of-*N* codes, that encode $\log_2 N$ bits in a code-word of $N$ bits. The one-of-two code uses the code words 01 and 10 to encode the bits '0' and '1'. A one-of-four code can use the words 0001, 0010, 0100, 1000 in order to encode two bits 00, 01, 10, and 11. An example is [dual rail encoding](https://en.wikipedia.org/wiki/Dual_rail_encoding), and chain link [^o7] used in delay insensitive circuits. For these codes, $n=N,~ d=2,~ w=1$ and $A(n, d, w) = n$.

Some of the more notable uses of one-hot codes include [biphase mark code](https://en.wikipedia.org/wiki/Biphase_mark_code) uses a 1-of-2 code; [pulse-position modulation](https://en.wikipedia.org/wiki/Pulse-position_modulation) uses a 1-of-*n* code; [address decoder](https://en.wikipedia.org/wiki/Address_decoder), etc.

## Balanced code {#Balanced_code}

In [coding theory](wikipedia://en/321869), a **balanced code** is a [binary](https://en.wikipedia.org/wiki/Binary_numeral_system) [forward error correction](https://en.wikipedia.org/wiki/Forward_error_correction) code for which each codeword contains an equal number of zero and one bits. Balanced codes have been introduced by [Donald Knuth](wikipedia://en/8095);[^o10] they are a subset of so-called unordered codes, which are codes having the property that the positions of ones in a codeword are never a subset of the positions of the ones in another codeword. Like all unordered codes, balanced codes are suitable for the detection of all [unidirectional errors](https://en.wikipedia.org/wiki/Unidirectional_error) in an encoded message. Balanced codes allow for particularly efficient decoding, which can be carried out in parallel.[^o10][^o11][^o12]

Some of the more notable uses of balanced-weight codes include [biphase mark code](https://en.wikipedia.org/wiki/Biphase_mark_code) uses a 1 of 2 code; [6b/8b encoding](https://en.wikipedia.org/wiki/6b/8b_encoding) uses a 4 of 8 code; the [Hadamard code](wikipedia://en/7428961) is a $2^{k-1}$ of $2^k$ code (except for the zero codeword), the [three-of-six](https://en.wikipedia.org/wiki/IEEE_1355#Slice:_TS-FO-02) code; etc.

The 3-wire lane encoding used in [MIPI](https://en.wikipedia.org/wiki/MIPI_Alliance) C-PHY can be considered a generalization of constant-weight code to ternary -- each wire transmits a [ternary signal](https://en.wikipedia.org/wiki/Ternary_signal), and at any one instant one of the 3 wires is transmitting a low, one is transmitting a middle, and one is transmitting a high signal.[^o13]

:::

## *m*-of-*n* codes {#m-of-n_codes}

An ***m*-of-*n* code** is a separable [error detection](https://en.wikipedia.org/wiki/Error_detection) code with a code word length of *n* bits, where each code word contains exactly *m* instances of a "one". A single bit error will cause the code word to have either *m* + 1 or *m* − 1 "ones". An example *m*-of-*n* code is the [2-of-5 code](https://en.wikipedia.org/wiki/Two-out-of-five_code) used by the [United States Postal Service](https://en.wikipedia.org/wiki/United_States_Postal_Service).

The simplest implementation is to append a string of ones to the original data until it contains *m* ones, then append zeros to create a code of length *n*.

Example:

*3-of-6 code*

::: {#o15 .table cue=table name="3-of-6 code"}

| Original 3 data bits | Appended bits |
|---|---|
| 000 | 111 |
| 001 | 110 |
| 010 | 110 |
| 011 | 100 |
| 100 | 110 |
| 101 | 100 |
| 110 | 100 |
| 111 | 000 |

:::

Some of the more notable uses of constant-weight codes, other than the one-hot and balanced-weight codes already mentioned above, include [Code 39](https://en.wikipedia.org/wiki/Code_39) uses a 3-of-9 code; [bi-quinary coded decimal](https://en.wikipedia.org/wiki/Bi-quinary_coded_decimal) code uses a 2-of-7 code, the [2-of-5 code](https://en.wikipedia.org/wiki/Two-out-of-five_code), etc.
