# Linear predictor function

::: {#o1 .subject cue=lead name="Linear predictor function"}

In [statistics](wikipedia://en/26685) and in [machine learning](wikipedia://en/233488), a **linear predictor function** is a [linear function](wikipedia://en/152111) ([linear combination](wikipedia://en/55632)) of a set of coefficients and explanatory variables ([independent variables](https://en.wikipedia.org/wiki/Independent_variable)), whose value is used to predict the outcome of a [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable).[^o2] This sort of function usually comes in [linear regression](wikipedia://en/48758386), where the coefficients are called [regression coefficients](https://en.wikipedia.org/wiki/Regression_coefficient). However, they also occur in various types of [linear classifiers](wikipedia://en/98974) (e.g. [logistic regression](wikipedia://en/226631),[^o3] [perceptrons](wikipedia://en/172777),[^o4] [support vector machines](wikipedia://en/65309),[^o5] and [linear discriminant analysis](wikipedia://en/1470657)[^o6]), as well as in various other models, such as [principal component analysis](wikipedia://en/76340)[^o7] and [factor analysis](wikipedia://en/253492). In many of these models, the coefficients are referred to as "weights".

:::

::: {#o9 .definition cue=heading name="Definition"}

## Definition {#Definition}

The basic form of a linear predictor function $f(i)$ for data point *i* (consisting of *p* [explanatory variables](wikipedia://en/437701)), for *i* = 1, ..., *n*, is

$$f(i) = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_p x_{ip},$$

where $x_{ik}$, for *k* = 1, ..., *p*, is the value of the *k*-th explanatory variable for data point *i*, and $\beta_0, \ldots, \beta_p$ are the *coefficients* (regression coefficients, weights, etc.) indicating the relative effect of a particular *explanatory variable* on the *outcome*.

::: {#o11 .definition kind=definition/notation cue=heading name="Notations"}

### Notations {#Notations}

It is common to write the predictor function in a more compact form as follows:

- The coefficients *β*<sub>0</sub>, *β*<sub>1</sub>, ..., *β*<sub>*p*</sub> are grouped into a single vector ***β*** of size *p* + 1.
- For each data point *i*, an additional explanatory pseudo-variable *x*<sub>*i*0</sub> is added, with a fixed value of 1, corresponding to the [intercept](wikipedia://en/464331) coefficient *β*<sub>0</sub>.
- The resulting explanatory variables *x*<sub>*i0*</sub>(= 1), *x*<sub>*i*1</sub>, ..., *x*<sub>*ip*</sub> are then grouped into a single vector ***x<sub>i</sub>*** of size *p* + 1.

#### Vector Notation {#Vector_Notation}

This makes it possible to write the linear predictor function as follows:

$$f(i)= \boldsymbol\beta \cdot \mathbf{x}_i$$

using the notation for a [dot product](wikipedia://en/157093) between two vectors.

#### Matrix Notation {#Matrix_Notation}

An equivalent form using matrix notation is as follows:

$$f(i)= \boldsymbol\beta^{\mathrm T} \mathbf{x}_i = \mathbf{x}^{\mathrm T}_i \boldsymbol\beta$$

where $\boldsymbol\beta$ and $\mathbf{x}_i$ are assumed to be a *(p+1)*-by-1 [column vectors](https://en.wikipedia.org/wiki/Column_vector), $\boldsymbol\beta^{\mathrm T}$ is the [matrix transpose](https://en.wikipedia.org/wiki/Matrix_transpose) of $\boldsymbol\beta$ (so $\boldsymbol\beta^{\mathrm T}$ is a 1-by-*(p+1)* [row vector](https://en.wikipedia.org/wiki/Row_vector)), and $\boldsymbol\beta^{\mathrm T} \mathbf{x}_i$ indicates [matrix multiplication](wikipedia://en/125280) between the 1-by-*(p+1)* row vector and the *(p+1)*-by-1 column vector, producing a 1-by-1 matrix that is taken to be a [scalar](wikipedia://en/3588331).

## Linear regression {#Linear_regression}

An example of the usage of a linear predictor function is in [linear regression](wikipedia://en/48758386), where each data point is associated with a [continuous](https://en.wikipedia.org/wiki/Continuous_variable) outcome *y*<sub>*i*</sub>, and the relationship written

$$y_i = f(i) + \varepsilon_i = \boldsymbol\beta^{\mathrm T}\mathbf{x}_i\ + \varepsilon_i,$$

where $\varepsilon_i$ is a *disturbance term* or *[error variable](https://en.wikipedia.org/wiki/Error_variable)* — an *unobserved* [random variable](wikipedia://en/25685) that adds noise to the linear relationship between the dependent variable and predictor function.

## Stacking {#Stacking}

In some models (standard linear regression, in particular), the equations for each of the data points *i* = 1, ..., *n* are stacked together and written in vector form as

$$\mathbf{y} = \mathbf{X}\boldsymbol\beta + \boldsymbol\varepsilon, \,$$

where

$$\mathbf{y} = \begin{pmatrix} y_1 \\ y_2 \\ \vdots \\ y_n \end{pmatrix}, \quad \mathbf{X} = \begin{pmatrix} \mathbf{x}'_1 \\ \mathbf{x}'_2 \\ \vdots \\ \mathbf{x}'_n \end{pmatrix} = \begin{pmatrix} x_{11} & \cdots & x_{1p} \\ x_{21} & \cdots & x_{2p} \\ \vdots & \ddots & \vdots \\ x_{n1} & \cdots & x_{np} \end{pmatrix}, \quad \boldsymbol\beta = \begin{pmatrix} \beta_1 \\ \vdots \\ \beta_p \end{pmatrix}, \quad \boldsymbol\varepsilon = \begin{pmatrix} \varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_n \end{pmatrix}.$$

The matrix *X* is known as the [design matrix](wikipedia://en/949189) and encodes all known information about the [independent variables](https://en.wikipedia.org/wiki/Independent_variables). The variables $\varepsilon_i$ are [random variables](wikipedia://en/25685), which in standard linear regression are distributed according to a [standard normal distribution](https://en.wikipedia.org/wiki/Standard_normal_distribution); they express the influence of any unknown factors on the outcome.

This makes it possible to find optimal coefficients through the [method of least squares](https://en.wikipedia.org/wiki/Method_of_least_squares) using simple matrix operations. In particular, the optimal coefficients $\boldsymbol{\hat\beta}$ as estimated by least squares can be written as follows:

$$\boldsymbol{\hat\beta} =( X^\mathrm T X)^{-1}X^{\mathrm T}\mathbf{y}.$$

The matrix $( X^\mathrm T X)^{-1}X^{\mathrm T}$ is known as the [Moore–Penrose pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse) of *X*. The use of the [matrix inverse](https://en.wikipedia.org/wiki/Matrix_inverse) in this formula requires that *X* is of [full rank](https://en.wikipedia.org/wiki/Full_rank), i.e. there is not perfect [multicollinearity](wikipedia://en/1486691) among different explanatory variables (i.e. no explanatory variable can be perfectly predicted from the others). In such cases, the [singular value decomposition](wikipedia://en/142207) can be used to compute the pseudoinverse.

## Preprocessing of explanatory variables {#Preprocessing_of_explanatory_variables}

When a fixed set of nonlinear functions are used to transform the value(s) of a data point, these functions are known as [basis functions](wikipedia://en/50909). An example is [polynomial regression](wikipedia://en/21893202), which uses a linear predictor function to fit an arbitrary degree [polynomial](wikipedia://en/23000) relationship (up to a given order) between two sets of data points (i.e. a single [real-valued](https://en.wikipedia.org/wiki/Real-valued) explanatory variable and a related real-valued dependent variable), by adding multiple explanatory variables corresponding to various powers of the existing explanatory variable. Mathematically, the form looks like this:

$$y_i = \beta_0 + \beta_1 x_i + \beta_2 x_i^2 + \cdots + \beta_p x_i^p.$$

In this case, for each data point *i*, a set of explanatory variables is created as follows:

$$(x_{i1} = x_i,\quad x_{i2} = x_i^2,\quad \ldots,\quad x_{ip} = x_i^p)$$

and then standard [linear regression](wikipedia://en/48758386) is run. The basis functions in this example would be

$$\boldsymbol\phi(x) = (\phi_1(x), \phi_2(x), \ldots, \phi_p(x)) = (x, x^2, \ldots, x^p).$$

This example shows that a linear predictor function can actually be much more powerful than it first appears: It only really needs to be linear in the *coefficients*. All sorts of non-linear functions of the explanatory variables can be fit by the model.

There is no particular need for the inputs to basis functions to be univariate or single-dimensional (or their outputs, for that matter, although in such a case, a *K*-dimensional output value is likely to be treated as *K* separate scalar-output basis functions). An example of this is [radial basis functions](wikipedia://en/2310753) (RBF's), which compute some transformed version of the distance to some fixed point:

$$\phi(\mathbf{x};\mathbf{c}) = \phi(||\mathbf{x} - \mathbf{c}||) = \phi(\sqrt{(x_1 - c_1)^2 + \ldots + (x_K - c_K)^2})$$

An example is the [Gaussian](wikipedia://en/245552) RBF, which has the same functional form as the [normal distribution](wikipedia://en/21462):

$$\phi(\mathbf{x};\mathbf{c}) = e^{-b||\mathbf{x} - \mathbf{c}||^2}$$

which drops off rapidly as the distance from ***c*** increases.

A possible usage of RBF's is to create one for every observed data point. This means that the result of an RBF applied to a new data point will be close to 0 unless the new point is near to the point around which the RBF was applied. That is, the application of the radial basis functions will pick out the nearest point, and its regression coefficient will dominate. The result will be a form of [nearest neighbor interpolation](https://en.wikipedia.org/wiki/Nearest_neighbor_interpolation), where predictions are made by simply using the prediction of the nearest observed data point, possibly interpolating between multiple nearby data points when they are all similar distances away. This type of [nearest neighbor method](https://en.wikipedia.org/wiki/K-nearest_neighbor_algorithm) for prediction is often considered diametrically opposed to the type of prediction used in standard linear regression: But in fact, the transformations that can be applied to the explanatory variables in a linear predictor function are so powerful that even the nearest neighbor method can be implemented as a type of linear regression.

It is even possible to fit some functions that appear non-linear in the coefficients by transforming the coefficients into new coefficients that do appear linear. For example, a function of the form $a + b^2x_{i1} + \sqrt{c}x_{i2}$ for coefficients $a,b,c$ could be transformed into the appropriate linear function by applying the substitutions $b' = b^2, c' = \sqrt{c},$ leading to $a + b'x_{i1} + c'x_{i2},$ which is linear. Linear regression and similar techniques could be applied and will often still find the optimal coefficients, but their error estimates and such will be wrong.

The explanatory variables may be of any [type](wikipedia://en/35269346): [real-valued](https://en.wikipedia.org/wiki/Real-valued), [binary](https://en.wikipedia.org/wiki/Binary_variable), [categorical](wikipedia://en/821165), etc. The main distinction is between [continuous variables](https://en.wikipedia.org/wiki/Continuous_variable) (e.g. income, age, [blood pressure](https://en.wikipedia.org/wiki/Blood_pressure), etc.) and [discrete variables](https://en.wikipedia.org/wiki/Discrete_variable) (e.g. sex, race, political party, etc.). Discrete variables referring to more than two possible choices are typically coded using [dummy variables](wikipedia://en/285156) (or [indicator variables](https://en.wikipedia.org/wiki/Indicator_variable)), i.e. separate explanatory variables taking the value 0 or 1 are created for each possible value of the discrete variable, with a 1 meaning "variable does have the given value" and a 0 meaning "variable does not have the given value". For example, a four-way discrete variable of [blood type](https://en.wikipedia.org/wiki/Blood_type) with the possible values "A, B, AB, O" would be converted to separate two-way dummy variables, "is-A, is-B, is-AB, is-O", where only one of them has the value 1 and all the rest have the value 0. This allows for separate regression coefficients to be matched for each possible value of the discrete variable.

Note that, for *K* categories, not all *K* dummy variables are independent of each other. For example, in the above blood type example, only three of the four dummy variables are independent, in the sense that once the values of three of the variables are known, the fourth is automatically determined. Thus, it's really only necessary to encode three of the four possibilities as dummy variables, and in fact if all four possibilities are encoded, the overall model becomes non-[identifiable](https://en.wikipedia.org/wiki/Identifiable). This causes problems for a number of methods, such as the simple closed-form solution used in linear regression. The solution is either to avoid such cases by eliminating one of the dummy variables, and/or introduce a [regularization](wikipedia://en/2009061) constraint (which necessitates a more powerful, typically iterative, method for finding the optimal coefficients).[^o17]
