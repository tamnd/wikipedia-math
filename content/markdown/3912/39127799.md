# Reciprocal distribution

::: {#o1 .subject cue=lead name="Reciprocal distribution"}

In [probability](wikipedia://en/22934) and [statistics](wikipedia://en/26685), the **reciprocal distribution**, also known as the **log-uniform distribution**, is a [continuous probability distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution). It is characterised by its [probability density function](wikipedia://en/43487), within the support of the distribution, being proportional to the [reciprocal](wikipedia://en/229940) of the variable.

:::

The reciprocal distribution is an example of an [inverse distribution](wikipedia://en/37560131), and the reciprocal (inverse) of a random variable with a reciprocal distribution itself has a reciprocal distribution.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [probability density function](wikipedia://en/43487) (pdf) of the reciprocal distribution is

$$f( x; a,b ) = \frac{ 1 }{ x [ \ln( b ) - \ln( a ) ]} \quad \text{ for } a \le x \le b \text{ and } a > 0.$$

Here, $a$ and $b$ are the parameters of the distribution, which are the lower and upper bounds of the [support](https://en.wikipedia.org/wiki/Support_of_a_distribution), and $\ln$ is the [natural log](https://en.wikipedia.org/wiki/Natural_log). The [cumulative distribution function](wikipedia://en/5793) is

$$F( x ; a,b) = \frac{ \ln( x ) - \ln( a ) }{ \ln( b ) - \ln( a ) } \quad \text{ for } a \le x \le b.$$

:::

## Characterization {#Characterization}

### Relationship between the log-uniform and the uniform distribution {#Relationship_between_the_log-uniform_and_the_uniform_distribution}

*Image: Reciprocal Histogram.svg.* Histogram and log-histogram of random deviates from the reciprocal distribution

A positive random variable *X* is log-uniformly distributed if the logarithm of *X* is uniform distributed,

$$\ln(X) \sim \mathcal U(\ln(a), \ln(b)).$$

This relationship is true regardless of the base of the logarithmic or exponential function. If $\log_a(Y)$ is uniform distributed, then so is $\log_b(Y)$, for any two positive numbers $a,b\neq 1$. Likewise, if $e^X$ is log-uniform distributed, then so is $a^X$, where $0 < a \neq 1$.

:::

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

The reciprocal distribution is of considerable importance in [numerical analysis](wikipedia://en/21506), because a [computer](https://en.wikipedia.org/wiki/Computer)’s arithmetic operations, in particular, repeated multiplications and/or divisions, transform [mantissas](wikipedia://en/419250) with initial arbitrary distributions into the reciprocal distribution as a limiting distribution.[^o9]

:::
