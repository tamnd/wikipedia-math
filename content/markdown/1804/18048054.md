# Hypograph (mathematics)

::: {#o1 .subject cue=lead name="Hypograph"}

*Image: Hypograph en.svg.* Hypograph of a function

In [mathematics](wikipedia://en/18831), the **hypograph** or **subgraph** of a [function](wikipedia://en/185427) $f:\mathbb{R}^{n}\rightarrow \mathbb{R}$ is the [set](wikipedia://en/26691) of points lying on or below its [graph](wikipedia://en/87352). A related definition is that of such a function's [epigraph](wikipedia://en/5744061), which is the set of points on or above the function's graph.

:::

The [domain](wikipedia://en/50263) (rather than the [codomain](wikipedia://en/50264)) of the function is not particularly important for this definition; it can be an arbitrary set[^o9] instead of $\mathbb{R}^n$.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The definition of the hypograph was inspired by that of the [graph of a function](wikipedia://en/87352), where the **graph** of $f : X \to Y$ is defined to be the set

$$\operatorname{graph} f := \left\{ (x, y) \in X \times Y ~:~ y = f(x) \right\}.$$

The **hypograph** or **subgraph** of a function $f : X \to [-\infty, \infty]$ valued in the [extended real numbers](wikipedia://en/51698) $[-\infty, \infty] = \mathbb{R} \cup \{ \pm \infty \}$ is the set[^n1]

$$\begin{alignedat}{4} \operatorname{hyp} f &= \left\{ (x, r) \in X \times \mathbb{R} ~:~ r \leq f(x) \right\} \\ &= \left[ f^{-1}(\infty) \times \mathbb{R} \right] \cup \bigcup_{x \in f^{-1}(\mathbb{R})} (\{ x \} \times (-\infty, f(x)]). \end{alignedat}$$

Similarly, the set of points on or above the function is its [epigraph](wikipedia://en/5744061).

The **strict hypograph** is the hypograph with the graph removed:

$$\begin{alignedat}{4} \operatorname{hyp}_S f &= \left\{ (x, r) \in X \times \mathbb{R} ~:~ r < f(x) \right\} \\ &= \operatorname{hyp} f \setminus \operatorname{graph} f \\ &= \bigcup_{x \in X} (\{ x \} \times (-\infty, f(x))). \end{alignedat}$$

Despite the fact that $f$ might take one (or both) of $\pm \infty$ as a value (in which case its graph would not be a subset of $X \times \mathbb{R}$), the hypograph of $f$ is nevertheless defined to be a subset of $X \times \mathbb{R}$ rather than of $X \times [-\infty, \infty].$

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The hypograph of a function $f$ is [empty](wikipedia://en/9566) if and only if $f$ is identically equal to negative infinity.

A function is [concave](wikipedia://en/263321) if and only if its hypograph is a [convex set](wikipedia://en/6292). The hypograph of a real [affine function](https://en.wikipedia.org/wiki/Affine_function) $g : \mathbb{R}^n \to \mathbb{R}$ is a [halfspace](wikipedia://en/647297) in $\mathbb{R}^{n+1}.$

A function is [upper semicontinuous](wikipedia://en/57824) if and only if its hypograph is [closed](wikipedia://en/47279).
