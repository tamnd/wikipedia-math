# ZUC stream cipher

::: {#o1 .subject cue=lead name="ZUC stream cipher"}

**ZUC** is a stream [cipher](wikipedia://en/5244) included in the [Long Term Evolution](https://en.wikipedia.org/wiki/Long_Term_Evolution) standards used in 3GPP specifications for confidentiality and integrity.[^o2][^o3] It is named after [Zu Chongzhi](wikipedia://en/151762), the fifth-century Chinese mathematician.[^o4]

:::

It uses a 16-stage [linear feedback shift register](https://en.wikipedia.org/wiki/Linear_feedback_shift_register) with each stage in ${\rm GF}(2^{31}-1)$ and produces a 32-bit word on each tick.
