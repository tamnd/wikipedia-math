# Supersingular isogeny graph

::: {#o1 .subject cue=lead name="Supersingular isogeny graph"}

In mathematics, the **supersingular isogeny graphs** are a class of [expander graphs](wikipedia://en/9313) that arise in [computational number theory](wikipedia://en/511466) and have been applied in [elliptic-curve cryptography](wikipedia://en/9966). Their vertices represent [supersingular elliptic curves](wikipedia://en/3028216) over [finite fields](wikipedia://en/11615) and their edges represent [isogenies](wikipedia://en/1085176) between curves.

:::

::: {#o3 .definition cue=heading name="Definition and properties"}

## Definition and properties {#Definition_and_properties}

A supersingular isogeny graph is determined by choosing a large [prime number](wikipedia://en/23666) $p$ and a small prime number $\ell$, and considering the class of all [supersingular elliptic curves](wikipedia://en/3028216) defined over the [finite field](wikipedia://en/11615) $\mathbb{F}_{p^2}$. There are approximately $(p+1)/12$ such curves, each two of which can be related by isogenies. The vertices in the supersingular isogeny graph represent these curves (or more concretely, their [$j$-invariants](wikipedia://en/451988), elements of $\mathbb{F}_{p^2}$) and the edges represent isogenies of degree $\ell$ between two curves.

The supersingular isogeny graphs are $\ell+1$-[regular graphs](wikipedia://en/85821), meaning that each vertex has exactly $\ell+1$ neighbors. They were proven by Pizer to be [Ramanujan graphs](wikipedia://en/849412), graphs with optimal [expansion properties](wikipedia://en/9313) for their degree. The proof is based on [Pierre Deligne](wikipedia://en/394544)'s proof of the [Ramanujan–Petersson conjecture](wikipedia://en/782173).

:::

## Cryptographic applications {#Cryptographic_applications}

One proposal for a [cryptographic hash function](wikipedia://en/439526) involves starting from a fixed vertex of a supersingular isogeny graph, using the bits of the binary representation of an input value to determine a sequence of edges to follow in a walk in the graph, and using the identity of the vertex reached at the end of the walk as the hash value for the input. The security of the proposed hashing scheme rests on the assumption that it is difficult to find paths in this graph that connect arbitrary pairs of vertices.

It has also been proposed to use walks in two supersingular isogeny graphs with the same vertex set but different edge sets (defined using different choices of the $\ell$ parameter) to develop a key exchange primitive analogous to [Diffie–Hellman key exchange](wikipedia://en/7903), called [supersingular isogeny key exchange](wikipedia://en/42674727), suggested as a form of [post-quantum cryptography](wikipedia://en/26605226). However, a leading variant of supersingular isogeny key exchange was broken in 2022 using non-quantum methods.
