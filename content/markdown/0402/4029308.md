# Homotopy extension property

::: {#o1 .subject cue=lead name="Homotopy extension property"}

In [mathematics](wikipedia://en/18831), in the area of [algebraic topology](wikipedia://en/38801), the **homotopy extension property** indicates which [homotopies](wikipedia://en/212250) defined on a [subspace](wikipedia://en/910926) can be extended to a homotopy defined on a larger space. The homotopy extension property of [cofibrations](wikipedia://en/1697216) is [dual to](wikipedia://en/23191477) the [homotopy lifting property](wikipedia://en/522786) that is used to define [fibrations](wikipedia://en/316826).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X\,\!$ be a [topological space](wikipedia://en/30450), and let $A \subset X$. We say that the pair $(X,A)\,\!$ has the **homotopy extension property** if, given a homotopy $f_\bullet\colon A \rightarrow Y^I$ and a map $\tilde{f}_0\colon X \rightarrow Y$ such that

$$\tilde{f}_0\circ \iota = \left.\tilde{f}_0\right|_A = f_0 = \pi_0 \circ f_\bullet,$$

then there exists an *extension* of $f_\bullet$ to a homotopy $\tilde{f}_\bullet\colon X \rightarrow Y^I$ such that $\tilde{f}_\bullet\circ \iota = \left.\tilde{f}_\bullet\right|_A = f_\bullet$.[^o4]

That is, the pair $(X,A)\,\!$ has the homotopy extension property if any map $G\colon ((X\times \{0\}) \cup (A\times I)) \rightarrow Y$ can be extended to a map $G'\colon X\times I \rightarrow Y$ (i.e. $G\,\!$ and $G'\,\!$ agree on their common domain).

If the pair has this property only for a certain [codomain](wikipedia://en/50264) $Y\,\!$, we say that $(X,A)\,\!$ has the homotopy extension property with respect to $Y\,\!$.

:::

If the above diagram (without the dashed map) commutes (this is equivalent to the conditions above), then pair (X,A) has the homotopy extension property if there exists a map $\tilde{f}_\bullet$ which makes the diagram commute. By [currying](wikipedia://en/6600), note that homotopies expressed as maps $\tilde{f}_\bullet \colon X \to Y^I$ are in [natural bijection](wikipedia://en/45022#Tensor-hom_adjunction) with expressions as maps $\tilde{f}_\bullet \colon X\times I \to Y$.

Note that this diagram is dual to (opposite to) that of the [homotopy lifting property](wikipedia://en/522786); this duality is loosely referred to as [Eckmann–Hilton duality](wikipedia://en/23191477).

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any CW pair $(X,A)\,\!$ (that is, $X\,\!$ is a [cell complex](https://en.wikipedia.org/wiki/Cell_complex) and $A\,\!$ is a subcomplex of $X\,\!$) has the homotopy extension property.[^o8]

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A pair $(X,A)\,\!$ has the homotopy extension property if and only if $(X\times \{0\} \cup A\times I)$ is a [retract](https://en.wikipedia.org/wiki/Deformation_retract) of $X\times I.$[^o11]

:::

## Other {#Other}

If $(X, A)$ has the homotopy extension property, then the simple inclusion map $\iota\colon A \to X$ is a [cofibration](wikipedia://en/1697216).

In fact, if $\iota\colon Y \to Z$ is a [cofibration](wikipedia://en/1697216), then $\mathbf{\mathit{Y}}$ is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to its image under $\iota$. This implies that any cofibration can be treated as an inclusion map, and therefore it can be treated as having the homotopy extension property.
