# Algebraic representation

::: {#o1 .subject cue=lead name="Algebraic representation"}

In mathematics, an **algebraic representation** of a [group](wikipedia://en/19447) *G* on a [*k*-algebra](wikipedia://en/191788) *A* is a [linear representation](https://en.wikipedia.org/wiki/Linear_representation) $\pi: G \to GL(A)$ such that, for each *g* in *G*, $\pi(g)$ is an [algebra automorphism](https://en.wikipedia.org/wiki/Algebra_automorphism). Equipped with such a representation, the algebra *A* is then called a ***G*-algebra**.

:::

For example, if *V* is a linear representation of a group *G*, then the [representation put on](wikipedia://en/43079145) the [tensor algebra](wikipedia://en/363628) $T(A)$ is an algebraic representation of *G*.

If *A* is a commutative *G*-algebra, then $\operatorname{Spec}(A)$ is an [affine](https://en.wikipedia.org/wiki/Affine_scheme) [*G*-scheme](wikipedia://en/56600253).
