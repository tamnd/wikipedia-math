# Transformation semigroup

::: {#o1 .subject cue=lead name="Transformation semigroup"}

In [algebra](wikipedia://en/18716923), a **transformation semigroup** (or **composition semigroup**) is a collection of [transformations](wikipedia://en/1904373) ([functions](wikipedia://en/185427) from a set to itself) that is [closed](wikipedia://en/293802) under [function composition](wikipedia://en/195947). If it includes the [identity function](wikipedia://en/15069), it is a [monoid](wikipedia://en/19652), called a **transformation** (or **composition**) **monoid**. This is the [semigroup](wikipedia://en/27799) analogue of a [permutation group](wikipedia://en/24634).

:::

A transformation semigroup of a set has a tautological [semigroup action](wikipedia://en/1058218) on that set. Such actions are characterized by being faithful, i.e., if two elements of the semigroup have the same action, then they are equal.

An analogue of [Cayley's theorem](wikipedia://en/105967) shows that any semigroup can be realized as a transformation semigroup of some set.

In [automata theory](wikipedia://en/103356), some authors use the term *transformation semigroup* to refer to a semigroup [acting faithfully](wikipedia://en/1058218) on a set of "states" different from the semigroup's base set.[^o2] There is [a correspondence between the two notions](wikipedia://en/1058218#Transformation_semigroups).

## Transformation semigroups and monoids {#Transformation_semigroups_and_monoids}

A **transformation semigroup** is a pair (*X*,*S*), where *X* is a set and *S* is a semigroup of transformations of *X*. Here a **transformation** of *X* is just a [function](wikipedia://en/185427) from a subset of *X* to *X*, not necessarily invertible, and therefore *S* is simply a set of transformations of *X* which is [closed](wikipedia://en/293802) under [composition of functions](https://en.wikipedia.org/wiki/Composition_of_functions). The set of all [partial functions](wikipedia://en/23577) on a given base set, *X*, forms a [regular semigroup](wikipedia://en/6797677) called the semigroup of all partial transformations (or the **partial transformation semigroup** on *X*), typically denoted by $\mathcal{PT}_X$.[^o4]

If *S* includes the identity transformation of *X*, then it is called a **transformation monoid**. Any transformation semigroup *S* determines a transformation monoid *M* by taking the union of *S* with the identity transformation. A transformation monoid whose elements are invertible is a [permutation group](wikipedia://en/24634).

The set of all transformations of *X* is a transformation monoid called the **full transformation monoid** (or **semigroup**) of *X*. It is also called the **symmetric semigroup** of *X* and is denoted by *T*<sub>*X*</sub>. Thus a transformation semigroup (or monoid) is just a [subsemigroup](https://en.wikipedia.org/wiki/Subsemigroup) (or [submonoid](https://en.wikipedia.org/wiki/Submonoid)) of the full transformation monoid of *X*.

If (*X*,*S*) is a transformation semigroup then *X* can be made into a [semigroup action](wikipedia://en/1058218) of *S* by evaluation:

$$s\cdot x = s(x)\text{ for }s\in S, x\in X.$$

This is a monoid action if *S* is a transformation monoid.

The characteristic feature of transformation semigroups, as actions, is that they are *faithful*, i.e., if

$$s\cdot x = t\cdot x\text{ for all }x\in X,$$

then *s* = *t*. Conversely if a semigroup *S* acts on a set *X* by *T*(*s*,*x*) = *s* • *x* then we can define, for *s* ∈ *S*, a transformation *T*<sub>*s*</sub> of *X* by

$$T_s (x) = T(s,x).\,$$

The map sending *s* to *T*<sub>*s*</sub> is injective if and only if (*X*, *T*) is faithful, in which case the image of this map is a transformation semigroup isomorphic to *S*.

## Cayley representation {#Cayley_representation}

In [group theory](wikipedia://en/41890), [Cayley's theorem](wikipedia://en/105967) asserts that any group *G* is isomorphic to a subgroup of the [symmetric group](wikipedia://en/28901) of *G* (regarded as a set), so that *G* is a [permutation group](wikipedia://en/24634). This theorem generalizes straightforwardly to monoids: any monoid *M* is a transformation monoid of its underlying set, via the action given by left (or right) multiplication. This action is faithful because if *ax* = *bx* for all *x* in *M*, then by taking *x* equal to the identity element, we have *a* = *b*.

For a semigroup *S* without a (left or right) identity element, we take *X* to be the underlying set of the [monoid corresponding to *S*](wikipedia://en/19652#Examples) to realise *S* as a transformation semigroup of *X*. In particular any finite semigroup can be represented as a [subsemigroup](https://en.wikipedia.org/wiki/Subsemigroup) of transformations of a set *X* with |*X*| ≤ |*S*| + 1, and if *S* is a monoid, we have the sharper bound |*X*| ≤ |*S*|, as in the case of [finite groups](wikipedia://en/323707).[^o6]

### In computer science {#In_computer_science}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), Cayley representations can be applied to improve the asymptotic efficiency of semigroups by reassociating multiple composed multiplications. The action given by left multiplication results in right-associated multiplication, and vice versa for the action given by right multiplication. Despite having the same results for any semigroup, the asymptotic efficiency will differ. Two examples of useful transformation monoids given by an action of left multiplication are the functional variation of the [difference list](https://en.wikipedia.org/wiki/Difference_list) data structure, and the monadic Codensity transformation (a Cayley representation of a [monad](wikipedia://en/355140), which is a monoid in a particular [monoidal](wikipedia://en/330604) [functor category](wikipedia://en/407039)).[^o8]

## Transformation monoid of an automaton {#Transformation_monoid_of_an_automaton}

Let *M* be a deterministic [automaton](https://en.wikipedia.org/wiki/Automaton) with state space *S* and alphabet *A*. The words in the [free monoid](wikipedia://en/523166) *A*<sup>∗</sup> induce transformations of *S* giving rise to a [monoid morphism](https://en.wikipedia.org/wiki/Monoid_morphism) from *A*<sup>∗</sup> to the full transformation monoid *T*<sub>*S*</sub>. The image of this morphism is the transformation semigroup of *M*.[^o6]

For a [regular language](wikipedia://en/25723), the [syntactic monoid](wikipedia://en/670026) is isomorphic to the transformation monoid of the [minimal automaton](https://en.wikipedia.org/wiki/Minimal_automaton) of the language.[^o6]
