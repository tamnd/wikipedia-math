# Dodecagonal prism

::: {#o1 .subject cue=lead name="Dodecagonal prism"}

Prism even polyhedron stat table

*Image: Dodecagonal prism.stl.* 3D model of a uniform dodecagonal prism

In [geometry](wikipedia://en/18973446), the **dodecagonal prism** is the tenth in an infinite set of [prisms](wikipedia://en/283007), formed by square sides and two regular [dodecagon](wikipedia://en/508486) caps.

:::

If faces are all regular, it is a [uniform polyhedron](wikipedia://en/2537223).

::: {#o3 .application cue=heading name="Use"}
