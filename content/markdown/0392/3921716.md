# Categorical set theory

::: {#o1 .subject cue=lead name="Categorical set theory"}

**Categorical set theory** is any one of several versions of [set theory](wikipedia://en/27553) developed from or treated in the context of mathematical [category theory](wikipedia://en/5869). Its basis originated with the development of [ETCS](wikipedia://en/78516937) by [William Lawvere](wikipedia://en/872760) in 1964.[^o2]

:::
