# Inverse tangent integral

::: {#o1 .subject cue=lead name="Inverse tangent integral"}

The **inverse tangent integral** is a [special function](https://en.wikipedia.org/wiki/Special_function), defined by:

:::

$$\operatorname{Ti}_2(x) = \int_0^x \frac{\arctan t}{t} \, dt$$

Equivalently, it can be defined by a [power series](wikipedia://en/59958), or in terms of the [dilogarithm](wikipedia://en/2398437), a closely related special function.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The inverse tangent integral is defined by:

$$\operatorname{Ti}_2(x) = \int_0^x \frac{\arctan t}{t} \, dt$$

The [arctangent](https://en.wikipedia.org/wiki/Arctangent) is taken to be the [principal branch](https://en.wikipedia.org/wiki/Principal_branch); that is, −$\pi$/2 \< arctan(*t*) \< $\pi$/2 for all real *t*.[^o4]

Its [power series](wikipedia://en/59958) representation is

$$\operatorname{Ti}_2(x) = x - \frac{x^3}{3^2} + \frac{x^5}{5^2} - \frac{x^7}{7^2} + \cdots$$

which is [absolutely convergent](https://en.wikipedia.org/wiki/Absolutely_convergent) for $|x| \le 1.$[^o5]

The inverse tangent integral is closely related to the [dilogarithm](wikipedia://en/2398437) $\operatorname{Li}_2(z) = \sum_{n=1}^\infty \frac{z^n}{n^2}$ and can be expressed simply in terms of it:

$$\operatorname{Ti}_2(z) = \frac{1}{2i} \left( \operatorname{Li}_2(iz) - \operatorname{Li}_2(-iz) \right)$$

That is,

$$\operatorname{Ti}_2(x) = \operatorname{Im}(\operatorname{Li}_2(ix))$$

for all real *x*.[^o5]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The inverse tangent integral is an [odd function](https://en.wikipedia.org/wiki/Odd_function):[^o5]

$$\operatorname{Ti}_2(-x) = -\operatorname{Ti}_2(x)$$

The values of Ti<sub>2</sub>(*x*) and Ti<sub>2</sub>(1/*x*) are related by the identity

$$\operatorname{Ti}_2(x) - \operatorname{Ti}_2 \left(\frac{1}{x} \right) = \frac{\pi}{2} \log x$$

valid for all *x* > 0 (or, more generally, for Re(*x*) > 0). This can be proven by differentiating and using the identity $\arctan(t) + \arctan(1/t) = \pi/2$.[^o17][^o8]

The special value Ti<sub>2</sub>(1) is [Catalan's constant](wikipedia://en/46860) $1 - \frac{1}{3^2} + \frac{1}{5^2} - \frac{1}{7^2} + \cdots \approx 0.915966$.[^o8]

:::

## Integral relations {#Integral_relations}

$$\int_0^{\pi/2}\operatorname{arcsinh}(r\sin\theta)\,\mathrm d\theta=\operatorname{Ti}_2(r),\quad |r|\le1$$

$$\int_0^{\pi/2}\operatorname{arctanh}(r\sin\theta)\,\mathrm d\theta=2\operatorname{Ti}_2\left(\frac{1-\sqrt{1-r^2}}{r}\right),\quad |r|\le1\setminus\{0\}$$

$$\int_0^{\pi/2}\operatorname{arctanh}(p\sin\theta)\arctan(q\sin\theta)\,\mathrm d\theta=\pi\operatorname{Ti}_2\left(\frac{1-\sqrt{1-p^2}}{p}\cdot\frac{\sqrt{1+q^2}-1}{q}\right),\quad |p|\le1\setminus\{0\},q\ne0$$

$$\int_0^{\alpha}\!\!\int_0^{\beta}\frac{\mathrm dx\,\mathrm dy}{1+x^2y^2}=\operatorname{Ti}_2(\alpha\beta),\quad |\alpha\beta|\le1$$

::: {#o11 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

Similar to the [polylogarithm](wikipedia://en/482471) $\operatorname{Li}_n(z) = \sum_{k=1}^\infty \frac{z^k}{k^n}$, the function

$$\operatorname{Ti}_{n}(x) = \sum\limits_{k=0}^{\infty}\frac{(-1)^{k}x^{2k+1}}{\left(2k+1\right)^{n}}=x - \frac{x^3}{3^n} + \frac{x^5}{5^n} - \frac{x^7}{7^n} + \cdots$$

is defined analogously. This satisfies the recurrence relation:[^o12]

$$\operatorname{Ti}_{n}(x) = \int_0^x \frac{\operatorname{Ti}_{n-1}(t)}{t} \, dt$$

By this series representation it can be seen that the special values $\operatorname{Ti}_{n}(1)=\beta(n)$, where $\beta(s)$ represents the [Dirichlet beta function](wikipedia://en/2216061).

:::

## Relation to other special functions {#Relation_to_other_special_functions}

The inverse tangent integral is related to the [Legendre chi function](wikipedia://en/1269900) $\chi_2(x) = x + \frac{x^3}{3^2} + \frac{x^5}{5^2} + \cdots$ by:[^o5]

$$\operatorname{Ti}_2(x) = -i \chi_2(ix)$$

Note that $\chi_2(x)$ can be expressed as $\int_0^x \frac{\operatorname{artanh} t}{t} \, dt$, similar to the inverse tangent integral but with the [inverse hyperbolic tangent](https://en.wikipedia.org/wiki/Inverse_hyperbolic_tangent) instead.

The inverse tangent integral can also be written in terms of the [Lerch transcendent](wikipedia://en/1342978) $\Phi(z,s,a) = \sum_{n=0}^\infty \frac{z^n}{(n+a)^s}:$

$$\operatorname{Ti}_2(x) = \frac{1}{4} x \Phi(-x^2, 2, 1/2)$$

## History {#History}

The notation Ti<sub>2</sub> and Ti<sub>*n*</sub> is due to Lewin. [Spence](wikipedia://en/71138035) (1809)[^o16] studied the function, using the notation $\overset{n}{\operatorname{C}}(x)$. The function was also studied by [Ramanujan](https://en.wikipedia.org/wiki/Ramanujan).[^o17]
