# Pluriharmonic function

::: {#o1 .subject cue=lead name="Pluriharmonic function"}

In [mathematics](wikipedia://en/18831), precisely in the [theory of functions of several complex variables](wikipedia://en/360243), a **pluriharmonic function** is a [real valued](wikipedia://en/20646438) [function](wikipedia://en/185427) which is [locally](wikipedia://en/1462457) the [real part](https://en.wikipedia.org/wiki/Real_part) of a holomorphic function of several complex variables. Sometimes such a function is referred to as ***n*-harmonic function**, where *n* ≥ 2 is the [dimension](https://en.wikipedia.org/wiki/Dimension_%28mathematics%29) of the [complex domain](wikipedia://en/16796643) where the function is defined.[^o2] However, in modern expositions of the theory of functions of several complex variables[^o3] it is preferred to give an equivalent formulation of the concept, by defining pluriharmonic function a [complex valued](wikipedia://en/5826) function whose restriction to every complex [line](wikipedia://en/946975) is a [harmonic function](wikipedia://en/55762) with respect to the [real](https://en.wikipedia.org/wiki/Real_part) and [imaginary part](https://en.wikipedia.org/wiki/Imaginary_part) of the complex line parameter.

:::

::: {#o5 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

(Definition 1). Let $G \subseteq \mathbf{C}^{n}$ be a [complex domain](wikipedia://en/16796643) and $f : G \to \mathbf{R}$ be a $C^{2}$ (twice [continuously differentiable](wikipedia://en/330206)) function. The function $f$ is called **pluriharmonic** if, for every [complex](wikipedia://en/5826) [line](wikipedia://en/946975)

$$\{ a + b z \mid z \in \mathbb{C} \} \subset \mathbb{C}^n$$

formed by using every couple of complex [tuples](wikipedia://en/132729) $a, b \in \mathbf{C}^{n}$, the function

$$z \mapsto f(a + bz)$$

is a [harmonic function](wikipedia://en/55762) on the set

$$\{ z \in \mathbb{C} \mid a + b z \in G \} \subset \mathbb{C} .$$

(Definition 2). Let $M$ be a [complex manifold](wikipedia://en/509742) and $f : M \to \mathbf{R}$ be a $C^{2}$ function. The function $f$ is called **pluriharmonic** if

$$dd^c f = 0.$$

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

Every pluriharmonic function is a [harmonic function](wikipedia://en/55762), but not the other way around. Further, it can be shown that for [holomorphic functions](wikipedia://en/14110) of several complex variables the real (and the imaginary) parts are locally pluriharmonic functions. However a function being harmonic in each variable separately does not imply that it is pluriharmonic.

:::
