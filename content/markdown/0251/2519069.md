# Pluripolar set

::: {#o1 .subject cue=lead name="Pluripolar set"}

In [mathematics](wikipedia://en/18831), in the area of [potential theory](wikipedia://en/1431342), a **pluripolar set** is the analog of a [polar set](wikipedia://en/5207129) for [plurisubharmonic functions](wikipedia://en/2519085).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G \subset {\mathbb{C}}^n$ and let $f \colon G \to {\mathbb{R}} \cup \{ - \infty \}$ be a [plurisubharmonic function](wikipedia://en/2519085) which is not identically $-\infty$. The set

$${\mathcal{P}} := \{ z \in G \mid f(z) = - \infty \}$$

is called a *complete pluripolar set*. A *pluripolar set* is any subset of a complete pluripolar set. Pluripolar sets are of [Hausdorff dimension](wikipedia://en/14294) at most $2n-2$ and have zero [Lebesgue measure](wikipedia://en/18198).[^o4]

If $f$ is a [holomorphic function](wikipedia://en/14110) then $\log | f |$ is a plurisubharmonic function. The zero set of $f$ is then a pluripolar set if $f$ is not the zero function.

:::
