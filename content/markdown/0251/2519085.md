# Plurisubharmonic function

::: {#o1 .subject cue=lead name="Plurisubharmonic function"}

In [mathematics](wikipedia://en/18831), **plurisubharmonic** functions (sometimes abbreviated as **psh**, **plsh**, or **plush** functions) form an important class of [functions](wikipedia://en/185427) used in [complex analysis](wikipedia://en/5759). On a [Kähler manifold](wikipedia://en/390538), plurisubharmonic functions form a subset of the [subharmonic functions](wikipedia://en/3237359). However, unlike subharmonic functions (which are defined on a [Riemannian manifold](wikipedia://en/144652)) plurisubharmonic functions can be defined in full generality on [complex analytic spaces](https://en.wikipedia.org/wiki/Complex_analytic_space).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A [function](wikipedia://en/185427) $f \colon G \to {\mathbb{R}}\cup\{-\infty\},$ with *domain* $G \subset {\mathbb{C}}^n$ is called **plurisubharmonic** if it is [upper semi-continuous](https://en.wikipedia.org/wiki/Semi-continuous_function), and for every [complex](wikipedia://en/5826) line

$\{ a + b z \mid z \in {\mathbb{C}} \}\subset {\mathbb{C}}^n,$ with $a, b \in {\mathbb{C}}^n,$

the function $z \mapsto f(a + bz)$ is a [subharmonic function](wikipedia://en/3237359) on the set

$$\{ z \in {\mathbb{C}} \mid a + b z \in G \}.$$

In full generality, the notion can be defined on an arbitrary [complex manifold](wikipedia://en/509742) or even a [complex analytic space](https://en.wikipedia.org/wiki/Complex_analytic_space) $X$ as follows. An [upper semi-continuous function](wikipedia://en/57824) $f \colon X \to {\mathbb{R}} \cup \{ - \infty \}$ is said to be plurisubharmonic if for any [holomorphic map](https://en.wikipedia.org/wiki/Holomorphic_map) $\varphi\colon\Delta\to X$ the function $f\circ\varphi \colon \Delta \to {\mathbb{R}} \cup \{ - \infty \}$ is [subharmonic](wikipedia://en/3237359), where $\Delta\subset{\mathbb{C}}$ denotes the [unit disk](wikipedia://en/252738).

### Differentiable plurisubharmonic functions {#Differentiable_plurisubharmonic_functions}

If $f$ is of (differentiability) class $C^2$, then $f$ is plurisubharmonic if and only if the hermitian matrix $L_f=(\lambda_{ij})$, called Levi matrix, with entries

$$\lambda_{ij}=\frac{\partial^2f}{\partial z_i\partial\bar z_j}$$

is [positive semidefinite](https://en.wikipedia.org/wiki/Definiteness_of_a_matrix#Definitions_for_complex_matrices).

Equivalently, a $C^2$-function *f* is plurisubharmonic if and only if $i\partial\bar\partial f$ is a [positive (1,1)-form](wikipedia://en/10592733).

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

**Relation to Kähler manifold:** On n-dimensional complex Euclidean space $\mathbb{C}^n$ , $f(z) = |z|^2$ is plurisubharmonic. In fact, $i\partial\overline{\partial}f$ is equal to the standard [Kähler form](https://en.wikipedia.org/wiki/Kähler_form) on $\mathbb{C}^n$ up to constant multiples. More generally, if $g$ satisfies

$$i\partial\overline{\partial}g=\omega$$

for some Kähler form $\omega$, then $g$ is plurisubharmonic, which is called Kähler potential. These can be readily generated by applying the [ddbar lemma](wikipedia://en/72112048) to Kähler forms on a Kähler manifold.

**Relation to Dirac Delta:** On 1-dimensional complex Euclidean space $\mathbb{C}^1$ , $u(z) = \log|z|$ is plurisubharmonic. If $f$ is a C<sup>∞</sup>-class function with [compact support](https://en.wikipedia.org/wiki/Compact_support), then [Cauchy integral formula](https://en.wikipedia.org/wiki/Cauchy_integral_formula) says

$$f(0)=\frac{1}{2\pi i}\int_D\frac{\partial f}{\partial\bar{z}}\frac{dzd\bar{z}}{z},$$

which can be modified to

$$\frac{i}{\pi}\partial\overline{\partial}\log|z|=dd^c\log|z|.$$

It is nothing but [Dirac measure](wikipedia://en/1019002) at the origin 0 .

**More Examples**

- If $f$ is an analytic function on an [open set](wikipedia://en/39358), then $\log|f|$ is plurisubharmonic on that open set.
- [Convex functions](wikipedia://en/245568) are plurisubharmonic.
- If $\Omega$ is a [domain of holomorphy](wikipedia://en/3236377) then $-\log (dist(z,\Omega^c))$ is plurisubharmonic.

:::

## History {#History}

Plurisubharmonic functions were defined in 1942 by [Kiyoshi Oka](wikipedia://en/381978)[^o8] and [Pierre Lelong](wikipedia://en/34789789).[^o9]

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The set of plurisubharmonic functions has the following properties like a [convex cone](wikipedia://en/3558266):
  - if $f$ is a plurisubharmonic function and $c>0$ a positive real number, then the function $c\cdot f$ is plurisubharmonic,
  - if $f_1$ and $f_2$ are plurisubharmonic functions, then the sum $f_1+f_2$ is a plurisubharmonic function.
- Plurisubharmonicity is a local property, i.e. a function is plurisubharmonic if and only if it is plurisubharmonic in a neighborhood of each point.
- If $f$ is plurisubharmonic and $\varphi:\mathbb{R}\to\mathbb{R}$ an increasing convex function then $\varphi \circ f$ is plurisubharmonic. ($\varphi(-\infty)$ is interpreted as $\lim_{x \rightarrow -\infty} \varphi(x)$.)
- If $f_1$ and $f_2$ are plurisubharmonic functions, then the function $\max(f_1,f_2)$ is plurisubharmonic.
- The pointwise limit of a decreasing sequence of plurisubharmonic functions is plurisubharmonic.
- Every continuous plurisubharmonic function can be obtained as the limit of a decreasing sequence of smooth plurisubharmonic functions. Moreover, this sequence can be chosen uniformly convergent.[^o12]
- The inequality in the usual [semi-continuity](wikipedia://en/57824) condition holds as equality, i.e. if $f$ is plurisubharmonic then $\limsup_{x\to x_0}f(x) =f(x_0)$.
- Plurisubharmonic functions are [subharmonic](wikipedia://en/3237359), for any [Kähler metric](wikipedia://en/390538).
- Therefore, plurisubharmonic functions satisfy the [maximum principle](wikipedia://en/1436104), i.e. if $f$ is plurisubharmonic on the [domain](wikipedia://en/16796643) $D$ and $\sup_{x\in D}f(x) =f(x_0)$ for some point $x_0\in D$ then $f$ is constant.

:::

::: {#o14 .application cue=heading name="Applications"}

## Applications {#Applications}

In [several complex variables](https://en.wikipedia.org/wiki/Several_complex_variables), plurisubharmonic functions are used to describe [pseudoconvex domains](wikipedia://en/3235998), [domains of holomorphy](wikipedia://en/3236377) and [Stein manifolds](wikipedia://en/1053909).

:::

::: {#o16 .statement kind=statement/theorem cue=named-heading name="Oka theorem"}

## Oka theorem {#Oka_theorem}

The main geometric application of the theory of plurisubharmonic functions is the famous theorem proven by [Kiyoshi Oka](wikipedia://en/381978) in 1942.[^o8]

A continuous function $f:\; M \mapsto {\mathbb R}$ is called *exhaustive* if the preimage $f^{-1}((-\infty, c])$ is compact for all $c\in {\mathbb R}$. A plurisubharmonic function *f* is called *strongly plurisubharmonic* if the form $i\partial\bar\partial f-\omega$ is [positive](wikipedia://en/10592733), for some [Kähler form](wikipedia://en/390538) $\omega$ on *M*.

::: {#o17 .statement kind=statement/theorem cue=inline-head name="Theorem of Oka"}

**Theorem of Oka:** Let *M* be a complex manifold, admitting a smooth, exhaustive, strongly plurisubharmonic function. Then *M* is a [Stein manifold](wikipedia://en/1053909). Conversely, any Stein manifold admits such a function.

:::
