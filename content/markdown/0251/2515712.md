# Perfect ruler

::: {#o1 .subject cue=lead name="Perfect ruler"}

A **perfect ruler** of length $\ell$ is a [ruler](wikipedia://en/65593) with [integer](wikipedia://en/14563) markings $a_1=0 < a_2 < \dots < a_n=\ell$, for which there exists an integer $m$ such that any [positive integer](https://en.wikipedia.org/wiki/Positive_integer) $k\leq m$ is uniquely expressed as the [difference](https://en.wikipedia.org/wiki/Difference_%28mathematics%29) $k=a_i-a_j$ for some $i,j$. This is referred to as an $m$-perfect ruler.

:::

An [optimal](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) perfect ruler is one of the shortest length for fixed values of $m$ and $n$.

::: {#o3 .example cue=heading name="Example"}

## Example {#Example}

A 4-perfect ruler of length $7$ is given by $(a_1,a_2,a_3,a_4)=(0,1,3,7)$. To verify this, we need to show that every positive integer $k\leq 4$ is uniquely expressed as the difference of two markings:

$$1=1-0$$

$$2=3-1$$

$$3=3-0$$

$$4=7-3$$

:::
