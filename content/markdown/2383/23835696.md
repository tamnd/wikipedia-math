# Gordan's lemma

::: {#o1 .subject cue=lead name="Gordan's lemma"}

**Gordan's lemma** is a lemma in [convex geometry](wikipedia://en/4165882) and [algebraic geometry](wikipedia://en/1997). It can be stated in several ways.

:::

- Let $A$ be a matrix of integers. Let $M$ be the set of non-negative [integer](wikipedia://en/14563) solutions of $A \cdot x = 0$. Then there exists a finite subset of vectors in $M$, such that every element of $M$ is a [linear combination](wikipedia://en/55632) of these vectors with non-negative integer coefficients.[^o2]
- The [semigroup](wikipedia://en/27799) of integral points in a rational convex [polyhedral cone](https://en.wikipedia.org/wiki/Polyhedral_cone) is finitely generated.[^o3]
- An [affine toric variety](https://en.wikipedia.org/wiki/Affine_toric_variety) is an [algebraic variety](wikipedia://en/248808) (this follows from the fact that the [prime spectrum](https://en.wikipedia.org/wiki/Prime_spectrum) of the [semigroup algebra](https://en.wikipedia.org/wiki/Semigroup_algebra) of such a semigroup is, by definition, an [affine toric variety](https://en.wikipedia.org/wiki/Affine_toric_variety)).

The lemma is named after the mathematician [Paul Gordan](wikipedia://en/1059850) (1837–1912). Some authors have misspelled it as "Gordon's lemma".

::: {#o5 .proof cue=heading name="Proofs"}

## Proofs {#Proofs}

There are topological and algebraic proofs.

### Topological proof {#Topological_proof}

Let $\sigma$ be the [dual cone](https://en.wikipedia.org/wiki/Dual_cone) of the given rational polyhedral cone. Let $u_1, \dots, u_r$ be integral vectors so that $\sigma = \{ x \mid \langle u_i, x \rangle \ge 0, 1 \le i \le r \}.$ Then the $u_i$'s generate the dual cone $\sigma^{\vee}$; indeed, writing *C* for the cone generated by $u_i$'s, we have: $\sigma \subset C^{\vee}$, which must be the equality. Now, if *x* is in the semigroup

$$S_\sigma = \sigma^\vee \cap \mathbb{Z}^d,$$

then it can be written as

$$x = \sum_i n_i u_i + \sum_i r_i u_i,$$

where $n_i$ are nonnegative integers and $0 \le r_i \le 1$. But since *x* and the first sum on the right-hand side are integral, the second sum is a lattice point in a bounded region, and so there are only finitely many possibilities for the second sum (the topological reason). Hence, $S_{\sigma}$ is finitely generated.

### Algebraic proof {#Algebraic_proof}

The proof[^o8] is based on a fact that a semigroup *S* is finitely generated [if and only if](wikipedia://en/14922) its semigroup algebra $\mathbb{C}[S]$ is a [finitely generated algebra](wikipedia://en/11985661) over $\mathbb{C}$. To prove Gordan's lemma, by induction (cf. the proof above), it is enough to prove the following statement: for any unital subsemigroup *S* of $\mathbb{Z}^d$,

If *S* is finitely generated, then $S^+ = S \cap \{ x \mid \langle x, v \rangle \ge 0 \}$, *v* an integral vector, is finitely generated.

Put $A = \mathbb{C}[S]$, which has a basis $\chi^a, \, a \in S$. It has $\mathbb{Z}$-grading given by

$$A_n = \operatorname{span} \{ \chi^a \mid a \in S, \langle a, v \rangle = n \}.$$

By assumption, *A* is finitely generated and thus is Noetherian. It follows from the algebraic lemma below that $\mathbb{C}[S^+] = \oplus_0^\infty A_n$ is a finitely generated algebra over $A_0$. Now, the semigroup $S_0 = S \cap \{ x \mid \langle x, v \rangle = 0 \}$ is the image of *S* under a linear projection, thus finitely generated and so $A_0 = \mathbb{C}[S_0]$ is finitely generated. Hence, $S^+$ is finitely generated then.

::: {#o9 .statement kind=statement/lemma cue=inline-head name="Lemma"}

**Lemma**: Let *A* be a $\mathbb{Z}$-[graded ring](wikipedia://en/103094). If *A* is a [Noetherian ring](wikipedia://en/56129), then $A^+ = \oplus_0^{\infty} A_n$ is a finitely generated $A_0$-algebra.

Proof: Let *I* be the ideal of *A* generated by all homogeneous elements of *A* of positive degree. Since *A* is Noetherian, *I* is actually generated by finitely many $f_i's$, homogeneous of positive degree. If *f* is homogeneous of positive degree, then we can write $f = \sum_i g_i f_i$ with $g_i$ homogeneous. If *f* has sufficiently large degree, then each $g_i$ has degree positive and strictly less than that of *f*. Also, each degree piece $A_n$ is a finitely generated $A_0$-module. (Proof: Let $N_i$ be an increasing chain of finitely generated submodules of $A_n$ with union $A_n$. Then the chain of the ideals $N_i A$ stabilizes in finite steps; so does the chain $N_i = N_i A \cap A_n.$) Thus, by induction on degree, we see $A^+$ is a finitely generated $A_0$-algebra.

:::

## Applications {#Applications}

A *multi-[hypergraph](wikipedia://en/232535)* over a certain set $V$ is a [multiset](wikipedia://en/305303) of subsets of *$V$* (it is called "multi-hypergraph" since each hyperedge may appear more than once). A multi-hypergraph is called [*regular*](wikipedia://en/85821) if all vertices have the same [degree](wikipedia://en/1374448). It is called *decomposable* if it has a proper nonempty subset that is regular too. For any integer *n*, let $D(n)$ be the maximum degree of an indecomposable multi-hypergraph on *n* vertices. Gordan's lemma implies that $D(n)$ is finite.[^o2] *Proof*: for each subset *S* of vertices, define a variable *x<sub>S</sub>* (a non-negative integer). Define another variable *d* (a non-negative integer). Consider the following set of *n* equations (one equation per vertex):

$$\sum_{S\ni v} x_S - d = 0 \text{ for all } v\in V$$

Every solution (**x**,*d*) denotes a regular multi-hypergraphs on $V$, where **x** defines the hyperedges and *d* is the degree. By Gordan's lemma, the set of solutions is generated by a [finite set](wikipedia://en/11742) of solutions, i.e., there is a finite set $M$ of multi-hypergraphs, such that each regular multi-hypergraph is a linear combination of some elements of $M$. Every non-decomposable multi-hypergraph must be in $M$ (since by definition, it cannot be generated by other multi-hypergraph). Hence, the set of non-decomposable multi-hypergraphs is finite.

:::

## See also {#See_also}

- [Birkhoff algorithm](wikipedia://en/64692455) is an algorithm that, given a bistochastic matrix (a matrix which solves a particular set of equations), finds a decomposition of it into integral matrices. It is related to Gordan's lemma in that it shows that the set of these matrices is generated by a finite set of integral matrices.
