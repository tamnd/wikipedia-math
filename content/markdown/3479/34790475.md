# Phragmen–Brouwer theorem

::: {#o1 .subject cue=lead name="Phragmen–Brouwer theorem"}

In topology, the **Phragmén–Brouwer theorem**, introduced by [Lars Edvard Phragmén](wikipedia://en/29769882) and [Luitzen Egbertus Jan Brouwer](https://en.wikipedia.org/wiki/Luitzen_Egbertus_Jan_Brouwer), states that if *X* is a [normal](https://en.wikipedia.org/wiki/Normal_topological_space) [connected](https://en.wikipedia.org/wiki/Connected_topological_space) [locally connected topological space](https://en.wikipedia.org/wiki/Locally_connected_topological_space), then the following two properties are equivalent:

:::

- If *A* and *B* are disjoint closed subsets whose union separates *X*, then either *A* or *B* separates *X*.
- *X* is [unicoherent](https://en.wikipedia.org/wiki/Unicoherent), meaning that if *X* is the union of two closed connected subsets, then their intersection is connected or empty.

The theorem remains true with the weaker condition that *A* and *B* be [separated](wikipedia://en/148911).
