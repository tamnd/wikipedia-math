# Sipser–Lautemann theorem

::: {#o1 .subject cue=lead name="Sipser–Lautemann theorem"}

In [computational complexity theory](wikipedia://en/7543), the **Sipser–Lautemann theorem** or **Sipser–Gács–Lautemann theorem** states that [bounded-error probabilistic polynomial](wikipedia://en/4079) (BPP) time is contained in the [polynomial time hierarchy](wikipedia://en/658651), and more specifically Σ<sub>2</sub> ∩ Π<sub>2</sub>.

:::

In 1983, [Michael Sipser](wikipedia://en/3644015) showed that BPP is contained in the [polynomial time hierarchy](wikipedia://en/658651).[^o2] [Péter Gács](https://en.wikipedia.org/wiki/Péter_Gács) showed that BPP is actually contained in Σ<sub>2</sub> ∩ Π<sub>2</sub>. [Clemens Lautemann](https://en.wikipedia.org/wiki/Clemens_Lautemann) contributed by giving a simple proof of BPP’s membership in Σ<sub>2</sub> ∩ Π<sub>2</sub>, also in 1983.[^o3] It is conjectured that in fact BPP=[P](wikipedia://en/658550), which is a much stronger statement than the Sipser–Lautemann theorem.

::: {#o5 .proof cue=heading name="Proof"}

## Proof {#Proof}

Here we present the proof by Lautemann.[^o3] [Without loss of generality](wikipedia://en/296000), a machine *M* ∈ BPP with error ≤ 2<sup>−|*x*|</sup> can be chosen. (All BPP problems can be amplified to reduce the error probability exponentially.) The basic idea of the proof is to define a Σ<sub>2</sub> sentence that is equivalent to stating that *x* is in the language, *L*, defined by *M* by using a set of transforms of the [random variable](wikipedia://en/25685) inputs.

Since the output of *M* depends on random input, as well as the input *x*, it is useful to define which random strings produce the correct output as *A*(*x*) = {*r* | *M*(*x*,*r*) accepts}. The key to the proof is to note that when *x* ∈ *L*, *A*(*x*) is very large and when *x* ∉ *L*, *A*(*x*) is very small. By using [bitwise parity](https://en.wikipedia.org/wiki/Exclusive_disjunction), ⊕, a set of transforms can be defined as *A*(*x*) ⊕ *t*={*r* ⊕ *t* | *r* ∈ *A*(*x*)}. The first main lemma of the proof shows that the union of a small finite number of these transforms will contain the entire space of random input strings. Using this fact, a Σ<sub>2</sub> sentence and a Π<sub>2</sub> sentence can be generated that is true if and only if *x* ∈ *L* (see conclusion).

::: {#o7 .statement kind=statement/lemma cue=named-heading name="Lemma 1"}

### Lemma 1 {#Lemma_1}

The general idea of lemma one is to prove that if *A*(*x*) covers a large part of the random space $R= \{ 1,0 \} ^ {|r|}$ then there exists a small set of translations that will cover the entire random space. In more mathematical language:

*If* $\frac{|A(x)|}{|R|} \ge 1 - \frac{1}{2^{|x|}}$, *then* $\exists t_1,t_2,\ldots,t_{|r|}$, *where* $t_i \in \{ 1,0 \} ^{|r|}$ *such that* $\bigcup_i A(x) \oplus t_i = R.$

::: {#o8 .proof cue=inline-head name="Proof"}

**Proof.** Randomly pick *t*<sub>1</sub>, *t*<sub>2</sub>, ..., *t*<sub>\|*r*|</sub>. Let $S=\bigcup_i A(x)\oplus t_i$ (the union of all transforms of *A*(*x*)).

So, for all *r* in *R*,

$$\Pr [r \notin S] = \Pr [r \notin A(x) \oplus t_1] \cdot \Pr [r \notin A(x) \oplus t_2] \cdots \Pr [r \notin A(x) \oplus t_{|r|}] \le { \frac{1}{2^{|x| \cdot |r|}} }.$$

The probability that there will exist at least one element in *R* not in *S* is

$$\Pr \Bigl[ \bigvee_i (r_i \notin S)\Bigr] \le \sum_i \frac{1}{2^{|x| \cdot |r|}} = \frac{2^{|r|}}{2^{|x| \cdot |r|}} < 1.$$

Therefore

$$\Pr [S = R] \ge 1 - \frac{2^{|r|}}{2^{|x| \cdot |r|}} > 0.$$

Thus there is a selection for each $t_1,t_2,\ldots,t_{|r|}$ such that

$$\bigcup_i A(x) \oplus t_i = R.$$

:::

:::

::: {#o10 .statement kind=statement/lemma cue=named-heading name="Lemma 2"}

### Lemma 2 {#Lemma_2}

The previous lemma shows that *A*(*x*) can cover every possible point in the space using a small set of translations. Complementary to this, for *x* ∉ *L* only a small fraction of the space is covered by $S=\bigcup_i A(x)\oplus t_i$. We have:

$$\frac{|S|}{|R|} \le |r| \cdot \frac{|A(x)|}{|R|} \le |r| \cdot 2^{-|x|} < 1$$

because $|r|$ is polynomial in $|x|$.

:::

### Conclusion {#Conclusion}

The lemmas show that language membership of a language in BPP can be expressed as a Σ<sub>2</sub> expression, as follows.

$$x \in L \iff \exists t_1,t_2,\dots,t_{|r|}\, \forall r \in R \bigvee_{ 1 \le i \le |r|} (M(x, r \oplus t_i) \text{ accepts}).$$

That is, *x* is in language *L* [if and only if](wikipedia://en/14922) there exist $|r|$ binary vectors, where for all random bit vectors *r*, TM *M* accepts at least one random vector ⊕ *t<sub>i</sub>*.

The above expression is in [Σ<sub>2</sub>](wikipedia://en/658651) in that it is first existentially then universally quantified. Therefore BPP ⊆ Σ<sub>2</sub>. Because BPP is closed under [complement](wikipedia://en/1929955), this proves BPP ⊆ Σ<sub>2</sub> ∩ Π<sub>2</sub>.

:::

## Stronger version {#Stronger_version}

The theorem can be strengthened to $\mathsf{BPP} \subseteq \mathsf{MA} \subseteq \mathsf{S}_2^P \subseteq \Sigma_2 \cap \Pi_2$ (see [MA](https://en.wikipedia.org/wiki/MA_%28complexity%29), [S${}^{P}_{2}$](https://en.wikipedia.org/wiki/S2P_%28complexity%29)).[^o13][^o14]
