# Separatrix (mathematics)

::: {#o1 .subject cue=lead name="Separatrix"}

In [mathematics](wikipedia://en/18831), a **separatrix** is the boundary separating two modes of behaviour in a [differential equation](wikipedia://en/32742753).[^o2]

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### Simple pendulum {#Simple_pendulum}

Consider the differential equation describing the motion of a simple [pendulum](https://en.wikipedia.org/wiki/Pendulum):

$${d^2\theta\over dt^2}+{g\over \ell} \sin\theta=0.$$

where $\ell$ denotes the length of the pendulum, $g$ the [gravitational acceleration](https://en.wikipedia.org/wiki/Gravitational_acceleration) and $\theta$ the angle between the pendulum and vertically downwards. In this system there is a conserved quantity H (the [Hamiltonian](wikipedia://en/198319)), which is given by

$$H = \frac{\dot{\theta}^2}{2} - \frac{g}{\ell}\cos\theta.$$

With this defined, one can plot a curve of constant *H* in the [phase space](wikipedia://en/191101) of system. The phase space is a graph with $\theta$ along the horizontal axis and $\dot{\theta}$ on the vertical axis – see the thumbnail to the right. The type of resulting curve depends upon the value of *H*.

*Image: Separatrix for a Simple Pendulum.png.* The phase space for the simple pendulum

If $H<-\frac{g}{\ell}$ then no curve exists (because $\dot{\theta}$ would then be [imaginary](wikipedia://en/5826)).

If $-\frac{g}{\ell}<H<\frac{g}{\ell}$ then the curve will be a simple closed [curve](wikipedia://en/89246) which is nearly circular for small H and becomes "eye" shaped when H approaches the upper bound. These curves correspond to the pendulum swinging periodically from side to side.

If $\frac{g}{\ell}<H$ then the curve is open, and this corresponds to the pendulum forever swinging through complete circles. Note that $\theta = \pm 180$ deg. corresponds to the pendulum reaching the top, after which it leaves the phase-space plot on one side and reappears again on the other.

In this system the **separatrix** is the curve that corresponds to $H=\frac{g}{\ell}$. It separates — hence the name — the phase space into two distinct areas, each with a distinct type of motion. The region inside the separatrix has all those phase space curves which correspond to the pendulum oscillating back and forth, whereas the region outside the separatrix has all the phase space curves which correspond to the pendulum continuously turning through vertical planar circles.

### FitzHugh–Nagumo model {#FitzHugh–Nagumo_model}

*Image: Fitzhugh-nagumo b = 2.0, separatrix.png.* When $b=2, I_{ext} = 3.5$, we can easily see the separatrix and the two basins of attraction by solving for the trajectories *backwards* in time.

In the [FitzHugh–Nagumo model](wikipedia://en/9105867), when the linear nullcline pierces the cubic nullcline at the left, middle, and right branch once each, the system has a separatrix. Trajectories to the left of the separatrix converge to the left stable equilibrium, and similarly for the right. The separatrix itself is the [stable manifold](wikipedia://en/5466649) for the saddle point in the middle. Details are found in the page.

The separatrix is clearly visible by numerically solving for trajectories *backwards in time*. Since when solving for the trajectories forwards in time, trajectories diverge from the separatrix, when solving backwards in time, trajectories converge to the separatrix.
