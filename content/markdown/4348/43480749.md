# Approximation property (ring theory)

::: {#o1 .subject cue=lead name="Approximation property"}

In [algebra](wikipedia://en/19616384), a commutative [Noetherian ring](wikipedia://en/56129) *A* is said to have the **approximation property** with respect to an [ideal](wikipedia://en/25977) *I* if each finite system of polynomial equations with coefficients in *A* has a solution in *A* if and only if it has a solution in the [*I*-adic completion](https://en.wikipedia.org/wiki/Completion_%28ring_theory%29) of *A*.[^o4][^o5] The notion of the approximation property is due to [Michael Artin](wikipedia://en/1519821).

:::
