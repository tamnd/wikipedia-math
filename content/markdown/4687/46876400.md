# Indiscrete category

::: {#o1 .subject cue=lead name="Indiscrete category"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), an **indiscrete category** is a [category](wikipedia://en/53759) in which there is exactly one [morphism](wikipedia://en/27716891) between any two objects.[^o2] Every [class](wikipedia://en/20696) *X* gives rise to an indiscrete category whose objects are the elements of *X* such that for any two objects *A* and *B*, there is only one morphism from *A* to *B*. Any two nonempty indiscrete categories are [equivalent](wikipedia://en/379051) to each other. The [functor](wikipedia://en/10987) from **Set** to **Cat** that sends a set to the corresponding indiscrete category is [right adjoint](wikipedia://en/53991) to the functor that sends a small category to its set of objects.[^o2]
