# Markus–Yamabe conjecture

::: {#o1 .subject cue=lead name="Markus–Yamabe conjecture"}

In [mathematics](wikipedia://en/18831), the **Markus–Yamabe conjecture** is a [conjecture](wikipedia://en/6138) on global [asymptotic stability](https://en.wikipedia.org/wiki/Asymptotic_stability). If the [Jacobian matrix](wikipedia://en/195351) of a dynamical system at a fixed point is [Hurwitz](wikipedia://en/78291990), then the fixed point is asymptotically stable. Markus-Yamabe conjecture asks if a similar result holds *globally*. Precisely, the conjecture states that if a [continuously differentiable](https://en.wikipedia.org/wiki/Smooth_function) map on an $n$-dimensional [real](wikipedia://en/20646438) [vector space](wikipedia://en/32370) has a [fixed point](wikipedia://en/449738), and its [Jacobian matrix](https://en.wikipedia.org/wiki/Jacobian_matrix) is everywhere Hurwitz, then the fixed point is globally stable.

:::

The conjecture is true for the two-dimensional case. However, counterexamples have been constructed in higher dimensions. Hence, in the two-dimensional case *only*, it can also be referred to as the **Markus–Yamabe theorem**.

Related mathematical results concerning global asymptotic stability, which *are* applicable in dimensions higher than two, include various [autonomous convergence theorems](wikipedia://en/14469299). Analog of the conjecture for nonlinear control system with scalar nonlinearity is known as [Kalman's conjecture](wikipedia://en/35474299).

::: {#o3 .statement kind=statement/conjecture cue=named-heading name="Mathematical statement of conjecture"}

## Mathematical statement of conjecture {#Mathematical_statement_of_conjecture}

Let $f:\mathbb{R}^n\rightarrow\mathbb{R}^n$ be a $C^1$ map with $f(0) = 0$ and Jacobian $Df(x)$ which is Hurwitz stable for every $x \in \mathbb{R}^n$.

Then $0$ is a global attractor of the dynamical system $\dot{x}= f(x)$.

The conjecture is true for $n=2$ and false in general for $n>2$.

:::
