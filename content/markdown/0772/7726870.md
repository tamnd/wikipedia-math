# Query (complexity)

::: {#o1 .subject cue=lead name="Query"}

In [descriptive complexity](https://en.wikipedia.org/wiki/Descriptive_complexity), a **query** is a mapping from structures of one [signature](wikipedia://en/7788156) to structures of another vocabulary. [Neil Immerman](https://en.wikipedia.org/wiki/Neil_Immerman), in his book Descriptive Complexity,[^o2] "use\[s\] the concept of query as the fundamental paradigm of computation" (p. 17).

:::

Given signatures $\sigma$ and $\tau$, we define the set of [structures](wikipedia://en/4055928) on each language, $\mbox{STRUC}[\sigma]$ and $\mbox{STRUC}[\tau]$. A query is then any mapping

> $$I : \mbox{STRUC}[\sigma] \to \mbox{STRUC}[\tau]$$

[Computational complexity theory](wikipedia://en/7543) can then be phrased in terms of the power of the mathematical logic necessary to express a given query.

## Order-independent queries {#Order-independent_queries}

A query is **order-independent** if the ordering of objects in the structure does not affect the results of the query. In databases, these queries correspond to [generic queries](https://en.wikipedia.org/wiki/Generic_query) (Immerman 1999, p. 18). A query is order-independent iff $I(\mathfrak{A}) \equiv I(\mathfrak{B})$ for any isomorphic structures $\mathfrak{A}$ and $\mathfrak{B}$.
