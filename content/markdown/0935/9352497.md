# Flag (geometry)

*Image: Pyramid flag.svg.* Face diagram of a [square pyramid](wikipedia://en/1128455) showing one of its flags

::: {#o1 .subject cue=lead name="Flag"}

In (polyhedral) [geometry](wikipedia://en/18973446), a **flag** is a sequence of [faces](wikipedia://en/149926) of a [polytope](wikipedia://en/1211056), each contained in the next, with exactly one face from each [dimension](wikipedia://en/8398).

:::

More formally, a **flag** $\psi$ of an $n$-polytope is a set $\{F_{-1}, F_{0}, ..., F_{n}\}$ such that $F_{i} \le F_{i+1}$ $(-1 \le i \le n - 1)$ and there is precisely one $F_{i}$ in $\psi$ for each $i$, $(-1 \le i \le n).$ Since, however, the minimal face $F_{-1}$ and the maximal face $F_{n}$ must be in every flag, they are often omitted from the list of faces, as a shorthand. These latter two are called **improper** faces.

For example, a flag of a [polyhedron](wikipedia://en/23470) comprises one [vertex](wikipedia://en/11308417), one [edge](wikipedia://en/12158034) incident to that vertex, and one [polygonal](wikipedia://en/23621) face incident to both, plus the two improper faces.

A polytope is [regular](wikipedia://en/518693) if, and only if, its [symmetry group](wikipedia://en/28186) is [transitive](https://en.wikipedia.org/wiki/Transitive_group_action) on its flags. This definition excludes [chiral polytopes](wikipedia://en/20861435).

Two flags are **$j$-adjacent** if they only differ by a face of rank $j$. They are **adjacent** if they are $j$-adjacent for some value of $j$. Each flag is $j$-adjacent to precisely one flag.[^o2]

## Incidence geometry {#Incidence_geometry}

In the more abstract setting of [incidence geometry](wikipedia://en/1576323), which is a set having a symmetric and reflexive [relation](wikipedia://en/22517558) called *incidence* defined on its elements, a **flag** is a set of elements that are mutually incident.[^o4] This level of abstraction generalizes both the polyhedral concept given above as well as the related [flag](wikipedia://en/390646) concept from linear algebra.

A flag is *maximal* if it is not contained in a larger flag. An incidence geometry (Ω, $I$) has **rank** $r$ if Ω can be partitioned into sets Ω<sub>1</sub>, Ω<sub>2</sub>, ..., Ω<sub>$r$</sub>, such that each maximal flag of the geometry intersects each of these sets in exactly one element. In this case, the elements of set Ω<sub>$j$</sub> are called elements of **type $j$**.

Consequently, in a geometry of rank $r$, each maximal flag has exactly $r$ elements.

An incidence geometry of rank 2 is commonly called an *incidence structure* with elements of type 1 called points and elements of type 2 called blocks (or lines in some situations).[^o5] More formally,

An incidence structure is a triple **D** = (*V*, *B*, $I$) where *V* and *B* are any two disjoint sets and $I$ is a binary relation between *V* and *B*, that is, $I$ ⊆ *V* × *B*. The elements of *V* will be called *points*, those of *B* blocks and those of $I$ *flags*.[^o6]
