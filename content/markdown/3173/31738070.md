# Omnitruncated simplicial honeycomb

::: {#o1 .subject cue=lead name="Omnitruncated simplicial honeycomb"}

In [geometry](wikipedia://en/18973446) an **omnitruncated simplicial honeycomb** or **omnitruncated n-simplex honeycomb** is an n-dimensional [uniform tessellation](https://en.wikipedia.org/wiki/Uniform_honeycomb), based on the symmetry of the ${\tilde{A}}_n$ affine [Coxeter group](wikipedia://en/297004). Each is composed of [omnitruncated](https://en.wikipedia.org/wiki/Omnitruncation_%28geometry%29) [simplex](wikipedia://en/39781) [facets](wikipedia://en/7186647). The [vertex figure](wikipedia://en/1005719) for each is an irregular n-simplex.

:::

The facets of an *omnitruncated simplicial honeycomb* are called [permutahedra](https://en.wikipedia.org/wiki/Permutahedron) and can be positioned in *n+1* space with integral coordinates, permutations of the whole numbers (0,1,...,n).

## Projection by folding {#Projection_by_folding}

The (2n−1)-simplex honeycombs can be projected into the n-dimensional [omnitruncated](wikipedia://en/7083690) [hypercubic honeycomb](wikipedia://en/12237982) by a [geometric folding](wikipedia://en/5358554#Geometric_folding) operation that maps two pairs of mirrors into each other, sharing the same [vertex arrangement](wikipedia://en/14308644):

::: {#o4 .table cue=table}

| ${\tilde{A}}_3$ |  | ${\tilde{A}}_5$ |  | ${\tilde{A}}_7$ |  | ${\tilde{A}}_9$ |  | ... |
|---|---|---|---|---|---|---|---|---|
| ${\tilde{C}}_2$ |  | ${\tilde{C}}_3$ |  | ${\tilde{C}}_4$ |  | ${\tilde{C}}_5$ |  | ... |

:::
