# Symmetric function

::: {#o1 .subject cue=lead name="Symmetric function"}

In [mathematics](wikipedia://en/18831), a [function](wikipedia://en/185427) of $n$ variables is **symmetric** if its value is the same no matter the order of its [arguments](wikipedia://en/32842052). For example, a function $f\left(x_1,x_2\right)$ of two arguments is a symmetric function if and only if $f\left(x_1,x_2\right) = f\left(x_2,x_1\right)$ for all $x_1$ and $x_2$ such that $\left(x_1,x_2\right)$ and $\left(x_2,x_1\right)$ are in the [domain](wikipedia://en/50263) of $f.$ The most commonly encountered symmetric functions are [polynomial functions](https://en.wikipedia.org/wiki/Polynomial_function), which are given by the [symmetric polynomials](wikipedia://en/1440207).

:::

A related notion is [alternating polynomials](wikipedia://en/20717382), which change sign under an interchange of variables. Aside from polynomial functions, [tensors](wikipedia://en/23087738) that act as functions of several vectors can be symmetric, and in fact the space of symmetric $k$-tensors on a [vector space](wikipedia://en/32370) $V$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the space of [homogeneous polynomials](https://en.wikipedia.org/wiki/Homogeneous_polynomials) of degree $k$ on $V.$ Symmetric functions should not be confused with [even and odd functions](wikipedia://en/592151), which have a different sort of symmetry.

## Symmetrization {#Symmetrization}

Given any function $f$ in $n$ variables with values in an [abelian group](wikipedia://en/2974), a symmetric function can be constructed by summing values of $f$ over all permutations of the arguments. Similarly, an anti-symmetric function can be constructed by summing over [even permutations](https://en.wikipedia.org/wiki/Even_permutation) and subtracting the sum over [odd permutations](https://en.wikipedia.org/wiki/Odd_permutation). These operations are of course not invertible, and could well result in a function that is identically zero for nontrivial functions $f.$ The only general case where $f$ can be recovered if both its symmetrization and antisymmetrization are known is when $n = 2$ and the abelian group admits a division by 2 (inverse of doubling); then $f$ is equal to half the sum of its symmetrization and its antisymmetrization.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Consider the [real](wikipedia://en/20646438) function

$$f(x_1,x_2,x_3) = (x-x_1)(x-x_2)(x-x_3).$$

By definition, a symmetric function with $n$ variables has the property that

$$f(x_1,x_2,\ldots,x_n) = f(x_2,x_1,\ldots,x_n) = f(x_3,x_1,\ldots,x_n,x_{n-1}), \quad \text{ etc.}$$

In general, the function remains the same for every [permutation](wikipedia://en/44027) of its variables. This means that, in this case,

$$(x-x_1)(x-x_2)(x-x_3) = (x-x_2)(x-x_1)(x-x_3) = (x-x_3)(x-x_1)(x-x_2)$$

and so on, for all permutations of $x_1, x_2, x_3.$

Consider the function

$$f(x,y) = x^2 + y^2 - r^2.$$

If $x$ and $y$ are interchanged the function becomes

$$f(y,x) = y^2 + x^2 - r^2,$$

which yields exactly the same results as the original $f(x, y).$

Consider now the function

$$f(x,y) = ax^2+by^2-r^2.$$

If $x$ and $y$ are interchanged, the function becomes

$$f(y,x) = ay^2 + bx^2 - r^2.$$

This function is not the same as the original if $a \neq b,$ which makes it non-symmetric.

:::

## Applications {#Applications}

### U-statistics {#U-statistics}

In [statistics](wikipedia://en/26685), an $n$-sample statistic (a function in $n$ variables) that is obtained by [bootstrapping](wikipedia://en/6885770) symmetrization of a $k$-sample statistic, yielding a symmetric function in $n$ variables, is called a [U-statistic](wikipedia://en/16811057). Examples include the [sample mean](https://en.wikipedia.org/wiki/Sample_mean) and [sample variance](https://en.wikipedia.org/wiki/Sample_variance).
