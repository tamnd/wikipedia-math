# Pseudo-determinant

::: {#o1 .subject cue=lead name="Pseudo-determinant"}

In [linear algebra](wikipedia://en/18422) and [statistics](wikipedia://en/26685), the **pseudo-determinant**[^o2] is the product of all non-zero [eigenvalues](https://en.wikipedia.org/wiki/Eigendecomposition_%28matrix%29) of a [square matrix](wikipedia://en/166022). It coincides with the regular [determinant](wikipedia://en/8468) when the matrix is [non-singular](wikipedia://en/217122).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The pseudo-determinant of a square *n*-by-*n* matrix **A** may be defined as:

$$|\mathbf{A}|_+ = \lim_{\alpha\to 0} \frac{|\mathbf{A} + \alpha \mathbf{I}|}{\alpha^{n-\operatorname{rank}(\mathbf{A})}}$$

where |**A**| denotes the usual [determinant](wikipedia://en/8468), **I** denotes the [identity matrix](wikipedia://en/59718) and rank(**A**) denotes the [matrix rank](wikipedia://en/26561) of **A**.[^o5]

:::

## Definition of pseudo-determinant using Vahlen matrix {#Definition_of_pseudo-determinant_using_Vahlen_matrix}

The Vahlen matrix of a conformal transformation, the [Möbius transformation](wikipedia://en/314493) (i.e. $(ax + b)(cx + d)^{-1}$ for $a, b, c, d \in \mathcal{G}(p, q)$), is defined as $[f] = \begin{bmatrix}a & b \\c & d \end{bmatrix}$. By the pseudo-determinant of the Vahlen matrix for the conformal transformation, we mean

$$\operatorname{pdet} \begin{bmatrix}a & b\\ c& d\end{bmatrix} = ad^\dagger - bc^\dagger.$$

If $\operatorname{pdet}[f] > 0$, the transformation is sense-preserving (rotation) whereas if the $\operatorname{pdet}[f] < 0$, the transformation is sense-preserving (reflection).

## Computation for positive semi-definite case {#Computation_for_positive_semi-definite_case}

If $A$ is [positive semi-definite](https://en.wikipedia.org/wiki/Positive-definite_matrix), then the [singular values](wikipedia://en/142207) and [eigenvalues](https://en.wikipedia.org/wiki/Eigendecomposition_%28matrix%29) of $A$ coincide. In this case, if the [singular value decomposition](wikipedia://en/142207) (SVD) is available, then $|\mathbf{A}|_+$ may be computed as the product of the non-zero singular values. If all singular values are zero, then the pseudo-determinant is 1.

Supposing $\operatorname{rank}(A) = k$, so that *k* is the number of non-zero singular values, we may write $A = PP^\dagger$ where $P$ is some *n*-by-*k* matrix and the dagger is the [conjugate transpose](wikipedia://en/217548). The singular values of $A$ are the squares of the singular values of $P$ and thus we have $|A|_+ = \left|P^\dagger P\right|$, where $\left|P^\dagger P\right|$ is the usual determinant in *k* dimensions. Further, if $P$ is written as the block column $P = \left(\begin{smallmatrix} C \\ D \end{smallmatrix}\right)$, then it holds, for any heights of the blocks $C$ and $D$, that $|A|_+ = \left|C^\dagger C + D^\dagger D\right|$.

## Application in statistics {#Application_in_statistics}

If a statistical procedure ordinarily compares distributions in terms of the determinants of variance-covariance matrices then, in the case of singular matrices, this comparison can be undertaken by using a combination of the ranks of the matrices and their pseudo-determinants, with the matrix of higher rank being counted as "largest" and the pseudo-determinants only being used if the ranks are equal.[^o9] Thus pseudo-determinants are sometime presented in the outputs of statistical programs in cases where covariance matrices are singular.[^o10] In particular, the normalization for a [multivariate normal distribution](wikipedia://en/50347) with a covariance matrix $\mathbf{\Sigma}$ that is not necessarily nonsingular can be written as

$$\frac{1}{\sqrt{(2\pi)^{\operatorname{rank}(\mathbf\Sigma)}|\mathbf\Sigma|_+}} = \frac{1}{\sqrt{|2\pi\mathbf\Sigma|_+}}\,.$$
