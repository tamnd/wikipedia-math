# Order dual (functional analysis)

::: {#o1 .subject cue=lead name="Order dual"}

In mathematics, specifically in [order theory](wikipedia://en/361924) and [functional analysis](wikipedia://en/11180), the **order dual** of an [ordered vector space](wikipedia://en/8099221) $X$ is the set $\operatorname{Pos}\left(X^*\right) - \operatorname{Pos}\left(X^*\right)$ where $\operatorname{Pos}\left(X^*\right)$ denotes the set of all positive [linear functionals](https://en.wikipedia.org/wiki/Linear_functional) on $X$, where a linear function $f$ on $X$ is called **positive** if for all $x \in X,$ $x \geq 0$ implies $f(x) \geq 0.$[^n1] The order dual of $X$ is denoted by $X^+$. Along with the related concept of the [order bound dual](wikipedia://en/63989481), this space plays an important role in the theory of [ordered topological vector spaces](wikipedia://en/63988132).

:::

## Canonical ordering {#Canonical_ordering}

An element $f$ of the order dual of $X$ is called **positive** if $x \geq 0$ implies $\operatorname{Re} f(x) \geq 0.$ The positive elements of the order dual form a cone that induces an ordering on $X^+$ called the **canonical ordering**. If $X$ is an [ordered vector space](wikipedia://en/8099221) whose positive cone $C$ is generating (that is, $X = C - C$) then the order dual with the canonical ordering is an ordered vector space.[^n1] The order dual is the span of the set of positive linear functionals on $X$.[^n1]

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The order dual is contained in the [order bound dual](wikipedia://en/63989481).[^n1] If the positive cone of an [ordered vector space](wikipedia://en/8099221) $X$ is generating and if $[0, x] + [0, y] = [0, x + y]$ holds for all positive $x$ and $y$, then the order dual is equal to the order bound dual, which is an order complete vector lattice under its canonical ordering.[^n1]

The order dual of a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) is an order complete vector lattice.[^n1] The order dual of a vector lattice $X$ can be finite dimension (possibly even $\{ 0 \}$) even if $X$ is infinite-dimensional.[^n1]

:::

## Order bidual {#Order_bidual}

Suppose that $X$ is an [ordered vector space](wikipedia://en/8099221) such that the canonical order on $X^+$ makes $X^+$ into an ordered vector space. Then the **order bidual** is defined to be the order dual of $X^+$ and is denoted by $X^{++}$. If the positive cone of an [ordered vector space](wikipedia://en/8099221) $X$ is generating and if $[0, x] + [0, y] = [0, x + y]$ holds for all positive $x$ and $y$, then $X^{++}$ is an order complete vector lattice and the evaluation map $X \to X^{++}$ is order preserving.[^n1] In particular, if $X$ is a vector lattice then $X^{++}$ is an order complete vector lattice.[^n1]

## Minimal vector lattice {#Minimal_vector_lattice}

If $X$ is a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) and if $G$ is a [solid](wikipedia://en/63989659) subspace of $X^+$ that separates points in $X$, then the evaluation map $X \to G^{+}$ defined by sending $x \in X$ to the map $E_x : G^{+} \to \mathbb{C}$ given by $E_x(f) := f(x)$, is a lattice isomorphism of $X$ onto a vector [sublattice](https://en.wikipedia.org/wiki/Sublattice) of $G^+$.[^n1] However, the image of this map is in general not order complete even if $X$ is order complete. Indeed, a regularly ordered, order complete vector lattice need not be mapped by the evaluation map onto a band in the order bidual. An order complete, regularly ordered vector lattice whose canonical image in its order bidual is order complete is called **minimal** and is said to be **of minimal type**.[^n1]

::: {#o19 .example cue=heading name="Examples"}

### Examples {#Examples}

For any $1 < p < \infty$, the Banach lattice $L^p(\mu)$ is order complete and of minimal type; in particular, the norm topology on this space is the finest locally convex topology for which every [order convergent](https://en.wikipedia.org/wiki/Order_convergent) filter converges.[^n2]

:::

::: {#o22 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

Let $X$ be an [order complete](wikipedia://en/63989777) vector lattice of minimal type. For any $x \in X$ such that $x > 0,$ the following are equivalent:[^n2]

1. $x$ is a [weak order unit](wikipedia://en/63990033).
1. For every non-0 positive linear functional $f$ on $X$, $f(x) > 0.$
1. For each topology $\tau$ on $X$ such that $(X, \tau)$ is a [locally convex vector lattice](wikipedia://en/63990620), $x$ is a [quasi-interior point](wikipedia://en/63990101) of its positive cone.

:::

## Related concepts {#Related_concepts}

An ordered vector space $X$ is called **regularly ordered** and its order is said to be **regular** if it is [Archimedean ordered](https://en.wikipedia.org/wiki/Archimedean_ordered) and $X^+$ distinguishes points in $X$.[^n1]
