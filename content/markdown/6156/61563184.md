# Nonlocal operator

::: {#o1 .subject cue=lead name="Nonlocal operator"}

In [mathematics](wikipedia://en/18831), a **nonlocal [operator](wikipedia://en/22213)** is a [mapping](https://en.wikipedia.org/wiki/Mapping_%28mathematics%29) that maps a space of functions on a topological space to another space of functions on some domain in such a way that the value of the function output at a given point cannot be determined solely from the values of the input function in an arbitrary neighbourhood of any point. An example of a nonlocal operator is the [Fourier transform](wikipedia://en/52247).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let $X$ be a [topological space](wikipedia://en/30450), $Y$ a [set](wikipedia://en/26691), $F(X)$ a [function space](wikipedia://en/340630) containing functions with [domain](wikipedia://en/50263) $X$, and $G(Y)$ a function space containing functions with domain $Y$. Two functions $u$ and $v$ in $F(X)$ are called equivalent at $x\in X$ if there exists a [neighbourhood](wikipedia://en/1529485) $N$ of $x$ such that $u(x')=v(x')$ for all $x'\in N$. An operator $A: F(X) \to G(Y)$ is said to be local if for every $y\in Y$ there exists an $x\in X$ such that $Au(y) = Av(y)$ for all functions $u$ and $v$ in $F(X)$ which are equivalent at $x$. A nonlocal operator is an operator which is not local.

For a local operator it is possible (in principle) to compute the value $Au(y)$ using only knowledge of the values of $u$ in an arbitrarily small neighbourhood of a point $x$. For a nonlocal operator this is not possible.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

[Differential operators](wikipedia://en/263886) are examples of local operators. A large class of (linear) nonlocal operators is given by the [integral transforms](wikipedia://en/430912), such as the Fourier transform and the [Laplace transform](wikipedia://en/18610). For an integral transform of the form

$$(Au)(y) = \int \limits_X u(x)\, K(x, y)\, dx,$$

where $K$ is some kernel function, it is necessary to know the values of $u$ almost everywhere on the [support](wikipedia://en/381013) of $K(\cdot, y)$ in order to compute the value of $Au$ at $y$.

An example of a [singular integral operator](https://en.wikipedia.org/wiki/Singular_integral_operator) is the [fractional Laplacian](wikipedia://en/54352245)

$$(-\Delta)^sf(x) = c_{d,s} \int\limits_{\mathbb{R}^d} \frac{f(x)-f(y)}{|x-y|^{d+2s}}\,dy.$$

The prefactor $c_{d,s} := \frac{4^s\Gamma(d/2+s)}{\pi^{d/2}|\Gamma(-s)|}$ involves the [Gamma function](wikipedia://en/12316) and serves as a normalizing factor. The fractional Laplacian plays a role in, for example, the study of nonlocal [minimal surfaces](https://en.wikipedia.org/wiki/Minimal_surfaces).[^o6]

:::

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

Some examples of applications of nonlocal operators are:

- [Time series](wikipedia://en/406624) analysis using Fourier transformations
- Analysis of [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems) using Laplace transformations
- [Image denoising](https://en.wikipedia.org/wiki/Image_denoising) using [non-local means](https://en.wikipedia.org/wiki/Non-local_means)[^o9]
- Modelling [Gaussian blur](https://en.wikipedia.org/wiki/Gaussian_blur) or [motion blur](https://en.wikipedia.org/wiki/Motion_blur) in images using [convolution](wikipedia://en/7519) with a [blurring kernel](https://en.wikipedia.org/wiki/Kernel_%28image_processing%29) or [point spread function](wikipedia://en/865348)
