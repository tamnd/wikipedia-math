# Dini criterion

::: {#o1 .subject cue=lead name="Dini criterion"}

In mathematics, **Dini's criterion** is a condition for the [pointwise convergence](wikipedia://en/340198) of [Fourier series](wikipedia://en/59038), introduced by (txt).

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Dini's criterion states that if a [periodic function](wikipedia://en/76848) $f$ has the property that $(f(t)+f(-t))/t$ is [locally integrable](wikipedia://en/4258398) near $0$, then the Fourier series of $f$ converges to $0$ at $t=0$.

Dini's criterion is in some sense as strong as possible: if $g(t)$ is a positive continuous function such that $g(t)/t$ is not locally integrable near $0$, there is a continuous function $f$ with $|f(t)|\leq g(t)$ whose Fourier series does not converge at $0$.

:::
