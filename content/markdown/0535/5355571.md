# Longest element of a Coxeter group

::: {#o1 .subject cue=lead name="Longest element of a Coxeter group"}

In [mathematics](wikipedia://en/18831), the **longest element of a Coxeter group** is the unique element of maximal [length](wikipedia://en/3021393) in a [finite Coxeter group](https://en.wikipedia.org/wiki/Finite_Coxeter_group) with respect to the chosen generating set consisting of simple reflections. It is often denoted by *w*<sub>0</sub>.[^o2][^o3]

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A Coxeter group has a longest element [if and only if](wikipedia://en/14922) it is finite; "only if" is because the size of the group is bounded by the number of words of length less than or equal to the maximum.
- The longest element of a Coxeter group is the unique [maximal element](wikipedia://en/303398) with respect to the [Bruhat order](wikipedia://en/10163003).
- The longest element is an [involution](wikipedia://en/293450) (has order 2: $w_0^{-1} = w_0$), by uniqueness of maximal length (the inverse of an element has the same length as the element).[^o6]
- For any $w \in W,$ the length satisfies $\ell(w_0w) = \ell(w_0) - \ell(w).$[^o6]
- A reduced expression for the longest element is not in general unique.
- In a reduced expression for the longest element, every simple reflection must occur at least once.[^o6]
- If the Coxeter group is finite then the length of *w*<sub>0</sub> is the number of the [positive roots](https://en.wikipedia.org/wiki/Positive_root).[^o6]
- The open cell *Bw*<sub>0</sub>*B* in the [Bruhat decomposition](wikipedia://en/1139142) of a [semisimple algebraic group](https://en.wikipedia.org/wiki/Semisimple_algebraic_group) *G* is dense in [Zariski topology](wikipedia://en/241744); topologically, it is the top dimensional cell of the decomposition, and represents the [fundamental class](wikipedia://en/669440).
- The longest element is the central element −1 except for $A_n$ ($n \geq 2$), $D_n$ for *n* odd, $E_6,$ and $I_2(p)$ for *p* odd, when it is −1 multiplied by the order 2 automorphism of the [Coxeter diagram](https://en.wikipedia.org/wiki/Coxeter_diagram).[^o7]

:::
