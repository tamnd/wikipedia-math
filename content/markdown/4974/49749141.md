# Conservative functor

::: {#o1 .subject cue=lead name="Conservative functor"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **conservative functor** is a [functor](wikipedia://en/10987) $F: C \to D$ such that for any [morphism](wikipedia://en/27716891) $f$ in $C$, $F(f)$ being an [isomorphism](wikipedia://en/14828) implies that $f$ is an isomorphism.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

The [forgetful functors](wikipedia://en/844783) in [algebra](wikipedia://en/19616384), such as from **Grp** to **Set**, are conservative. More generally, every [monadic functor](wikipedia://en/355140#Monads_and_adjunctions) is conservative.[^o4] In contrast, the forgetful functor from **Top** to **Set** is not conservative because not every [continuous bijection](wikipedia://en/6122) is a [homeomorphism](wikipedia://en/13660).

Every [faithful functor](https://en.wikipedia.org/wiki/Faithful_functor) from a [balanced category](wikipedia://en/77326358) is conservative.[^o5]

:::
