# Unstructured grid

*Image: Unstructured\_grid.svg.* Example of unstructured grid for a [finite element analysis](https://en.wikipedia.org/wiki/Finite_element_analysis) mesh

::: {#o1 .subject cue=lead name="Unstructured grid"}

An **unstructured grid** or **irregular grid** is a [tessellation](wikipedia://en/321671) of a part of the [Euclidean plane](wikipedia://en/15575410) or [Euclidean space](wikipedia://en/9697) by simple shapes, such as [triangles](wikipedia://en/30654) or [tetrahedra](wikipedia://en/30606), in an irregular pattern. Grids of this [type](wikipedia://en/37667343) may be used in [finite element analysis](https://en.wikipedia.org/wiki/Finite_element_analysis) when the input to be analyzed has an irregular shape.

:::

Unlike [structured grids](https://en.wikipedia.org/wiki/Structured_grid), unstructured grids require a list of the [connectivity](wikipedia://en/1614492) which specifies the way a given set of vertices make up individual elements (see [graph (data structure)](https://en.wikipedia.org/wiki/Graph_%28data_structure%29)).

[Ruppert's algorithm](https://en.wikipedia.org/wiki/Ruppert's_algorithm) is often used to convert an irregularly shaped polygon into an unstructured grid of triangles.

In addition to triangles and tetrahedra, other commonly used elements in finite element simulation include quadrilateral (4-noded) and hexahedral (8-noded) elements in 2D and 3D, respectively. One of the most commonly used algorithms to generate unstructured quadrilateral grid is "Paving".[^o2] However, there is no such commonly used algorithm for generating unstructured hexahedral grid on a general 3D solid model. "Plastering" is a 3D version of Paving,[^o3] but it has difficulty in forming hexahedral elements at the interior of a solid.
