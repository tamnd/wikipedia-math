# Cocurvature

::: {#o1 .subject cue=lead name="Cocurvature"}

In [mathematics](wikipedia://en/18831) in the branch of [differential geometry](wikipedia://en/8625), the **cocurvature** of a [connection](wikipedia://en/308815) on a [manifold](wikipedia://en/2073470) is the [obstruction](wikipedia://en/2179639) to the integrability of the [vertical bundle](https://en.wikipedia.org/wiki/Vertical_bundle).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If *M* is a manifold and *P* is a connection on *M*, that is a vector-valued 1-form on *M* which is a projection on T*M* such that *P<sub>a</sub><sup>b</sup>P<sub>b</sub><sup>c</sup>* = *P<sub>a</sub><sup>c</sup>*, then the cocurvature $\bar{R}_P$ is a vector-valued 2-form on *M* defined by

$$\bar{R}_P(X,Y) = (\operatorname{Id} - P)[PX,PY]$$

where *X* and *Y* are vector fields on *M*.

:::
