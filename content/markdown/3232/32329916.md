# Dual-flashlight plot

*Image: wiki.dualflashlight.png.* Dual-flashlight plot showing a high-throughput screening dataset.

::: {#o1 .subject cue=lead name="Dual-flashlight plot"}

In statistics, a **dual-flashlight plot** is a type of scatter-plot in which the standardized mean of a contrast variable ([SMCV](https://en.wikipedia.org/wiki/SMCV)) is plotted against the mean of a [contrast variable](https://en.wikipedia.org/wiki/Contrast_variable) representing a comparison of interest .[^o2] The commonly used dual-flashlight plot is for the difference between two groups in high-throughput experiments such as [microarrays](https://en.wikipedia.org/wiki/Microarray) and [high-throughput screening](https://en.wikipedia.org/wiki/High-throughput_screening) studies, in which we plot the [SSMD](https://en.wikipedia.org/wiki/SSMD) versus average log fold-change on the *y*- and *x*-axes, respectively, for all genes or compounds (such as [siRNAs](https://en.wikipedia.org/wiki/SiRNA) or [small molecules](https://en.wikipedia.org/wiki/Small_molecule)) investigated in an experiment.[^o2] As a whole, the points in a dual-flashlight plot look like the beams of a flashlight with two heads, hence the name dual-flashlight plot.[^o2]

:::

With the dual-flashlight plot, we can see how the genes or compounds are distributed into each category in effect sizes, as shown in the figure. Meanwhile, we can also see the average fold-change for each gene or compound. The dual-flashlight plot is similar to the [volcano plot](wikipedia://en/25668921). In a [volcano plot](wikipedia://en/25668921), the [p-value](wikipedia://en/554994) (or q-value), instead of SMCV or SSMD, is plotted against average fold-change [^o3] .[^o4] The advantage of using SMCV over p-value (or q-value) is that, if there exist any non-zero true effects for a gene or compound, the estimated SMCV goes to its population value whereas the p-value (or q-value) for testing no mean difference (or zero contrast mean) goes to zero when the sample size increases .[^o5] Hence, the value of SMCV is comparable whereas the value of p-value or q-value is not comparable in experiments with different sample size, especially when many investigated genes or compounds do not have exactly zero effects. The dual-flashlight plot bears the same advantage that the SMCV has, as compared to the [volcano plot](wikipedia://en/25668921).
