# Barrier cone

::: {#o1 .subject cue=lead name="Barrier cone"}

In [mathematics](wikipedia://en/18831), specifically [functional analysis](wikipedia://en/11180), the **barrier cone** is a [cone](https://en.wikipedia.org/wiki/Cone_%28linear_algebra%29) associated to any non-empty subset of a [Banach space](wikipedia://en/3989). It is closely related to the notions of [support functions](wikipedia://en/9377661) and [polar sets](wikipedia://en/1764022).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* be a Banach space and let *K* be a non-empty subset of *X*. The **barrier cone** of *K* is the subset *b*(*K*) of *X*<sup>∗</sup>, the [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) of *X*, defined by

$$b(K) := \left\{ \ell \in X^{\ast} \,\left|\, \sup_{x \in K} \langle \ell, x \rangle < + \infty \right. \right\}.$$

:::

## Related notions {#Related_notions}

The function

$$\sigma_{K} \colon \ell \mapsto \sup_{x \in K} \langle \ell, x \rangle,$$

defined for each [continuous linear functional](https://en.wikipedia.org/wiki/Continuous_linear_functional) *ℓ* on *X*, is known as the [support function](wikipedia://en/9377661) of the set *K*; thus, the barrier cone of *K* is precisely the set of continuous linear functionals *ℓ* for which *σ*<sub>*K*</sub>(*ℓ*) is finite.

The set of continuous linear functionals *ℓ* for which *σ*<sub>*K*</sub>(*ℓ*) ≤ 1 is known as the [polar set](wikipedia://en/1764022) of *K*. The set of continuous linear functionals *ℓ* for which *σ*<sub>*K*</sub>(*ℓ*) ≤ 0 is known as the (negative) [polar cone](https://en.wikipedia.org/wiki/Polar_cone) of *K*. Clearly, both the polar set and the negative polar cone are subsets of the barrier cone.
