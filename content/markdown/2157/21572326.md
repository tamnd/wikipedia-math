# GraphPad Software

::: {#o1 .subject cue=lead name="GraphPad Software"}

**GraphPad Software Inc.** was a privately held software development corporation until its acquisition by [Insight Partners](https://en.wikipedia.org/wiki/Insight_Partners) in 2017.[^o3] The company was named Insightful Science and merged with [Dotmatics](https://en.wikipedia.org/wiki/Dotmatics) in 2021.[^o4]

:::

## Overview {#Overview}

The original software was written by Harvey Motulsky in 1989 and the company was co-founded by Motulsky and Earl Beutler. The company operates in California[^o6] and its products include the 2D scientific graphing, [biostatistics](wikipedia://en/3878), curve fitting software GraphPad Prism and the free, web-based statistical calculation software, GraphPad QuickCalcs.

The company was acquired in 2017 by Insight Partners[^o3] and then later merged with Dotmatics in 2021.[^o7]

::: {#o9 .pointer-item cue=pointer name="GraphPad Prism"}

## GraphPad Prism {#GraphPad_Prism}

**GraphPad Prism** is a commercial scientific 2D graphing and [statistics software](https://en.wikipedia.org/wiki/Statistics_software) for Windows and Mac OS desktop computers. Software features include [nonlinear regression](wikipedia://en/1045012), with functionalities including the removal of outliers, comparisons of models, comparisons of curves, and interpolation of standard curves. The software allows the automatic updating of results and graphs, and has functionality for displaying error bars.[^o12][^o13] Features for usability include built in formulae, batch processing and standardisation features, along with automated analysis and data validation.[^o14]

:::
