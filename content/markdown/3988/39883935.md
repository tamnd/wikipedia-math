# Two-way indicator species analysis

::: {#o1 .subject cue=lead name="Two-way indicator species analysis"}

**Two-way indicator species analysis** (TWINSPAN) is a [Fortran](https://en.wikipedia.org/wiki/Fortran)-based [statistical analysis](https://en.wikipedia.org/wiki/Statistical_analysis) method described in 1979 by Mark O. Hill.[^o3] It is widely used in [ecological](https://en.wikipedia.org/wiki/Ecology) research.[^o2]

:::

As of 1997, it was the only widespread standardized method to identify indicator plants.[^o3]
