# Firefox Lockwise

::: {#o1 .subject cue=lead name="Firefox Lockwise"}

**Firefox Lockwise** (formerly **Lockbox**[^o5]) is a deprecated[^o6] [password manager](wikipedia://en/4696394) for the [Firefox](https://en.wikipedia.org/wiki/Firefox) web browser, as well as the mobile operating systems [iOS](https://en.wikipedia.org/wiki/IOS) and [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29).[^o7][^o8] On desktop, Lockwise was simply part of Firefox,[^o20] whereas on iOS and Android it was available as a standalone app. If [Firefox Sync](https://en.wikipedia.org/wiki/Firefox_Sync) was activated (with a Firefox account), then Lockwise synced passwords between Firefox installations across devices.[^o9] It also featured a built-in [random password generator](https://en.wikipedia.org/wiki/Random_password_generator).[^o10] The application and branding have since been "phased out."[^o11]

:::

## History {#History}

Developed by [Mozilla](https://en.wikipedia.org/wiki/Mozilla_Corporation), it was originally named Firefox **Lockbox** in 2018.[^o13] It was renamed "Lockwise" in May 2019.[^o14][^o15] It was introduced for iOS on 10 July 2018 as part of the Test Pilot program.[^o16] On 26 March 2019, it was released for Android.[^o17]

On desktop, Lockwise started out as a browser addon. [Alphas](https://en.wikipedia.org/wiki/Alpha_release) were released between March and August 2019.[^o18] Since Firefox version 70, Lockwise has been integrated into the browser[^o19] (accessible at about:logins),[^o20] having replaced a basic password manager presented in a popup window.[^o21]

Mozilla ended support for Firefox Lockwise on December 13, 2021.[^o22][^o23]

As of January 2026, Lockwise is still fully functional on Android to this day.
