# Hamiltonian (control theory)

::: {#o1 .subject cue=lead name="Hamiltonian"}

The **Hamiltonian** is a [function](wikipedia://en/185427) used to solve a problem of [optimal control](wikipedia://en/362565) for a [dynamical system](wikipedia://en/9087). It can be understood as an instantaneous increment of the [Lagrangian expression](wikipedia://en/159974) of the problem that is to be optimized over a certain time period.[^o2] Inspired by—but distinct from—the [Hamiltonian of classical mechanics](wikipedia://en/198319), the Hamiltonian of optimal control theory was developed by [Lev Pontryagin](wikipedia://en/582075) as part of his [maximum principle](https://en.wikipedia.org/wiki/Pontryagin's_minimum_principle).[^o3] Pontryagin proved that a necessary condition for solving the optimal control problem is that the control should be chosen so as to optimize the Hamiltonian.[^o4]

:::

## Problem statement and definition of the Hamiltonian {#Problem_statement_and_definition_of_the_Hamiltonian}

Consider a [dynamical system](wikipedia://en/9087) of $n$ first-order [differential equations](wikipedia://en/1424309)

$$\dot{\mathbf{x}}(t) = \mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t)$$

where $\mathbf{x}(t) = \left[ x_{1}(t), x_{2}(t), \ldots, x_{n}(t) \right]^{\mathsf{T}}$ denotes a vector of state variables, and $\mathbf{u}(t) = \left[ u_{1}(t), u_{2}(t), \ldots, u_{r}(t) \right]^{\mathsf{T}}$ a vector of control variables. Once initial conditions $\mathbf{x}(t_{0}) = \mathbf{x}_{0}$ and controls $\mathbf{u}(t)$ are specified, a solution to the differential equations, called a *trajectory* $\mathbf{x}(t; \mathbf{x}_{0}, t_{0})$, can be found. The problem of optimal control is to choose $\mathbf{u}(t)$ (from some set $\mathcal{U} \subseteq \mathbb{R}^{r}$) so that $\mathbf{x}(t)$ maximizes or minimizes a certain [objective function](wikipedia://en/442137) between an initial time $t = t_{0}$ and a terminal time $t = t_{1}$ (where $t_{1}$ may be [infinity](wikipedia://en/20110824)). Specifically, the goal is to optimize over a performance index $I(\mathbf{x}(t),\mathbf{u}(t),t)$ defined at each point in time,

$\max_{\mathbf{u}(t)} J$, with $J = \int_{t_{0}}^{t_{1}} I[\mathbf{x}(t),\mathbf{u}(t),t] \, \mathrm{d}t$

subject to the above equations of motion of the state variables. The solution method involves defining an ancillary function known as the control Hamiltonian

which combines the objective function and the state equations much like a [Lagrangian](wikipedia://en/159974) in a static optimization problem, only that the multipliers $\mathbf{\lambda}(t)$—referred to as *costate variables*—are functions of time rather than constants.

The goal is to find an optimal control policy function $\mathbf{u}^\ast(t)$ and, with it, an optimal trajectory of the state variable $\mathbf{x}^\ast(t)$, which by [Pontryagin's maximum principle](wikipedia://en/831689) are the arguments that maximize the Hamiltonian,

$H(\mathbf{x}^\ast(t),\mathbf{u}^\ast(t),\mathbf{\lambda}(t),t) \geq H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)$ for all $\mathbf{u}(t) \in \mathcal{U}$

The first-order necessary conditions for a maximum are given by

$\frac{\partial H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)}{\partial \mathbf{u}} = 0 \quad$ which is the maximum principle,

$\frac{\partial H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)}{\partial \mathbf{\lambda}} = \dot{\mathbf{x}}(t) \quad$ which generates the state transition function $\, \mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t) = \dot{\mathbf{x}}(t)$,

$\frac{\partial H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)}{\partial \mathbf{x}} = - \dot{\mathbf{\lambda}}(t) \quad$ which generates the [costate equations](wikipedia://en/347128) $\, \dot{\mathbf{\lambda}}(t) = - \left[ I_{\mathbf{x}}(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}_{\mathbf{x}}(\mathbf{x}(t),\mathbf{u}(t),t) \right]$

Together, the state and costate equations describe the Hamiltonian dynamical system (again analogous to but distinct from the [Hamiltonian system](wikipedia://en/1197531) in physics), the solution of which involves a two-point [boundary value problem](wikipedia://en/436779), given that there are $2n$ boundary conditions involving two different points in time, the initial time (the $n$ differential equations for the state variables), and the terminal time (the $n$ differential equations for the costate variables; unless a final function is specified, the boundary conditions are $\mathbf{\lambda}(t_{1}) = 0$, or $\lim_{t_{1} \to \infty} \mathbf{\lambda}(t_{1}) = 0$ for infinite time horizons).[^o7]

A sufficient condition for a maximum is the concavity of the Hamiltonian evaluated at the solution, i.e.

$$H_{\mathbf{uu}}(\mathbf{x}^\ast(t),\mathbf{u}^\ast(t),\mathbf{\lambda}(t),t) \leq 0$$

where $\mathbf{u}^\ast(t)$ is the optimal control, and $\mathbf{x}^\ast(t)$ is resulting optimal trajectory for the [state variable](https://en.wikipedia.org/wiki/State_variable).[^o8] Alternatively, by a result due to [Olvi L. Mangasarian](wikipedia://en/46242822), the necessary conditions are sufficient if the functions $I(\mathbf{x}(t),\mathbf{u}(t),t)$ and $\mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t)$ are both concave in $\mathbf{x}(t)$ and $\mathbf{u}(t)$.[^o9]

### Derivation from the Lagrangian {#Derivation_from_the_Lagrangian}

A [constrained optimization](wikipedia://en/4171950) problem as the one stated above usually suggests a Lagrangian expression, specifically

$$L = \int_{t_{0}}^{t_{1}} I(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \left[ \mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t) - \dot{\mathbf{x}}(t) \right] \, \mathrm{d}t$$

where $\mathbf{\lambda}(t)$ compares to the [Lagrange multiplier](wikipedia://en/159974) in a static optimization problem but is now, as noted above, a function of time. In order to eliminate $\dot{\mathbf{x}}(t)$, the last term on the right-hand side can be rewritten using [integration by parts](wikipedia://en/147252), such that

$$- \int_{t_{0}}^{t_{1}} \mathbf{\lambda}^{\mathsf{T}}(t) \dot{\mathbf{x}}(t) \, \mathrm{d}t = -\mathbf{\lambda}^{\mathsf{T}}(t_{1}) \mathbf{x}(t_{1}) + \mathbf{\lambda}^{\mathsf{T}}(t_{0}) \mathbf{x}(t_{0}) + \int_{t_{0}}^{t_{1}} \dot{\mathbf{\lambda}}^{\mathsf{T}}(t) \mathbf{x}(t) \, \mathrm{d}t$$

which can be substituted back into the Lagrangian expression to give

$$L = \int_{t_{0}}^{t_{1}} \left[ I(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t) + \dot{\mathbf{\lambda}}^{\mathsf{T}}(t) \mathbf{x}(t) \right] \, \mathrm{d}t - \mathbf{\lambda}^{\mathsf{T}}(t_{1}) \mathbf{x}(t_{1}) + \mathbf{\lambda}^{\mathsf{T}}(t_{0}) \mathbf{x}(t_{0})$$

To derive the first-order conditions for an optimum, assume that the solution has been found and the Lagrangian is maximized. Then any perturbation to $\mathbf{x}(t)$ or $\mathbf{u}(t)$ must cause the value of the Lagrangian to decline. Specifically, the [total derivative](https://en.wikipedia.org/wiki/Total_derivative) of $L$ obeys

$$\mathrm{d}L = \int_{t_{0}}^{t_{1}} \left[ \left( I_{\mathbf{u}}(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}_{\mathbf{u}}(\mathbf{x}(t),\mathbf{u}(t),t) \right) \mathrm{d}\mathbf{u}(t) + \left( I_{\mathbf{x}}(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}_{\mathbf{x}}(\mathbf{x}(t),\mathbf{u}(t),t) + \dot{\mathbf{\lambda}}(t) \right) \mathrm{d}\mathbf{x}(t) \right] \mathrm{d}t - \mathbf{\lambda}^{\mathsf{T}}(t_{1}) \mathrm{d}\mathbf{x}(t_{1}) + \mathbf{\lambda}^{\mathsf{T}}(t_{0}) \mathrm{d}\mathbf{x}(t_{0}) \leq 0$$

For this expression to equal zero necessitates the following optimality conditions:

$$\begin{aligned} \underbrace{I_{\mathbf{u}}(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}_{\mathbf{u}}(\mathbf{x}(t),\mathbf{u}(t),t)}_{= \frac{\partial H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)}{\partial \mathbf{u}}} &= 0 \\ \underbrace{I_{\mathbf{x}}(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}_{\mathbf{x}}(\mathbf{x}(t),\mathbf{u}(t),t)}_{= \frac{\partial H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)}{\partial \mathbf{x}}} + \dot{\mathbf{\lambda}}(t) &= 0 \end{aligned}$$

If both the initial value $\mathbf{x}(t_{0})$ and terminal value $\mathbf{x}(t_{1})$ are fixed, i.e. $\mathrm{d}\mathbf{x}(t_{0}) = \mathrm{d}\mathbf{x}(t_{1}) = 0$, no conditions on $\mathbf{\lambda}(t_{0})$ and $\mathbf{\lambda}(t_{1})$ are needed. If the terminal value is free, as is often the case, the additional condition $\mathbf{\lambda}(t_{1}) = 0$ is necessary for optimality. The latter is called a transversality condition for a fixed horizon problem.[^o11]

It can be seen that the necessary conditions are identical to the ones stated above for the Hamiltonian. Thus the Hamiltonian can be understood as a device to generate the first-order necessary conditions.[^o12]

## The Hamiltonian in discrete time {#The_Hamiltonian_in_discrete_time}

When the problem is formulated in discrete time, the Hamiltonian is defined as:

$$H(x_{t},u_{t},\lambda_{t+1},t)=\lambda^\top_{t+1}f(x_{t},u_{t},t)+I(x_{t},u_{t},t) \,$$

and the [costate equations](https://en.wikipedia.org/wiki/Costate_equations) are

$$\lambda_{t} =\frac{\partial H}{\partial x_{t}}$$

(Note that the discrete time Hamiltonian at time $t$ involves the costate variable at time $t+1.$[^o14] This small detail is essential so that when we differentiate with respect to $x$ we get a term involving $\lambda_{t+1}$ on the right hand side of the costate equations. Using a wrong convention here can lead to incorrect results, i.e. a costate equation which is not a backwards difference equation).

## Behavior of the Hamiltonian over time {#Behavior_of_the_Hamiltonian_over_time}

From Pontryagin's maximum principle, special conditions for the Hamiltonian can be derived.[^o16] When the final time $t_1$ is fixed and the Hamiltonian does not depend explicitly on time $\left(\tfrac{\partial H}{\partial t} = 0\right)$, then:[^o17]

$$H(x^*(t),u^*(t),\lambda^*(t)) = \mathrm{constant}\,$$

or if the terminal time is free, then:

$$H(x^*(t),u^*(t),\lambda^*(t)) = 0.\,$$

Further, if the terminal time tends to [infinity](wikipedia://en/20110824), a [transversality condition](wikipedia://en/9900080) on the Hamiltonian applies.[^o18]

$$\lim_{t \to \infty} H(t) = 0$$

## The Hamiltonian of control compared to the Hamiltonian of mechanics {#The_Hamiltonian_of_control_compared_to_the_Hamiltonian_of_mechanics}

[William Rowan Hamilton](wikipedia://en/39817) defined the [Hamiltonian](wikipedia://en/198319) for describing the mechanics of a system. It is a function of three variables and related to the Lagrangian as

$$\mathcal{H}(p,q,t) = \langle p,\dot{q} \rangle -L(q,\dot{q},t)$$

where $L$ is the [Lagrangian](wikipedia://en/23371726), the extremizing of which determines the dynamics (*not* the Lagrangian defined above) and $q$ is the state variable. The Lagrangian is evaluated with $\dot{q}$ representing the [time derivative](wikipedia://en/1783069) of the state's evolution and $p$, the so-called "[conjugate momentum](https://en.wikipedia.org/wiki/Conjugate_momentum)", relates to it as

$$p = \frac{\partial L}{\partial \dot{q}}.$$

Hamilton then formulated his equations to describe the dynamics of the system as

$$\frac{ d}{ dt}p(t) = -\frac{\partial}{\partial q}\mathcal{H}$$

$$\frac{ d}{ dt}q(t) =~~\frac{\partial}{\partial p}\mathcal{H}$$

The Hamiltonian of control theory describes not the *dynamics* of a system but conditions for extremizing some scalar function thereof (the Lagrangian) with respect to a control variable $u$. As normally defined, it is a function of 4 variables

$$H(q,u,p,t)= \langle p,\dot{q} \rangle -L(q,u,t)$$

where $q$ is the state variable and $u$ is the control variable with respect to that which we are extremizing.

The associated conditions for a maximum are

$$\frac{dp}{dt} = -\frac{\partial H}{\partial q}$$

$$\frac{dq}{dt} = ~~\frac{\partial H}{\partial p}$$

$$\frac{\partial H}{\partial u} = 0$$

This definition agrees with that given by the article by Sussmann and Willems.[^o20] (see p. 39, equation 14). Sussmann and Willems show how the control Hamiltonian can be used in dynamics e.g. for the [brachistochrone problem](https://en.wikipedia.org/wiki/Brachistochrone_problem), but do not mention the prior work of [Carathéodory](https://en.wikipedia.org/wiki/Carathéodory) on this approach.[^o21]

## Current value and present value Hamiltonian {#Current_value_and_present_value_Hamiltonian}

In [economics](https://en.wikipedia.org/wiki/Economics), the objective function in dynamic optimization problems often depends directly on time only through [exponential discounting](https://en.wikipedia.org/wiki/Exponential_discounting), such that it takes the form

$$I(\mathbf{x}(t),\mathbf{u}(t),t) = e^{-\rho t} \nu(\mathbf{x}(t),\mathbf{u}(t))$$

where $\nu(\mathbf{x}(t),\mathbf{u}(t))$ is referred to as the instantaneous [utility function](https://en.wikipedia.org/wiki/Utility_function), or [felicity function](https://en.wikipedia.org/wiki/Felicity_function).[^o24] This allows a redefinition of the Hamiltonian as $H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t) = e^{-\rho t} \bar{H}(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t))$ where

$$\begin{aligned} \bar{H}(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t)) \equiv& \, e^{\rho t} \left[ I(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\lambda}^{\mathsf{T}}(t) \mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t) \right] \\ =& \, \nu(\mathbf{x}(t),\mathbf{u}(t),t) + \mathbf{\mu}^{\mathsf{T}}(t) \mathbf{f}(\mathbf{x}(t),\mathbf{u}(t),t) \end{aligned}$$

which is referred to as the current value Hamiltonian, in contrast to the present value Hamiltonian $H(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t),t)$ defined in the first section. Most notably the costate variables are redefined as $\mathbf{\mu}(t) = e^{\rho t} \mathbf{\lambda}(t)$, which leads to modified first-order conditions.

$$\frac{\partial \bar{H}(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t))}{\partial \mathbf{u}} = 0,$$

$$\frac{\partial \bar{H}(\mathbf{x}(t),\mathbf{u}(t),\mathbf{\lambda}(t))}{\partial \mathbf{x}} = - \dot{\mathbf{\mu}}(t) + \rho \mathbf{\mu}(t)$$

which follows immediately from the [product rule](wikipedia://en/248988). Economically, $\mathbf{\mu}(t)$ represent current-valued [shadow prices](https://en.wikipedia.org/wiki/Shadow_price) for the capital goods $\mathbf{x}(t)$.

:::

## Example: Ramsey–Cass–Koopmans model {#Example:_Ramsey–Cass–Koopmans_model}

In [economics](https://en.wikipedia.org/wiki/Economics), the [Ramsey–Cass–Koopmans model](wikipedia://en/4701722) is used to determine an optimal savings behavior for an economy. The objective function $J(c)$ is the [social welfare function](wikipedia://en/217104),

$$J(c) = \int^T_0 e^{-\rho t}u(c(t)) dt$$

to be maximized by choice of an optimal consumption path $c(t)$. The function $u(c(t))$ indicates the [utility](wikipedia://en/45479) the [representative agent](https://en.wikipedia.org/wiki/Representative_agent) of consuming $c$ at any given point in time. The factor $e^{-\rho t}$ represents [discounting](https://en.wikipedia.org/wiki/Discounting). The maximization problem is subject to the following differential equation for [capital intensity](https://en.wikipedia.org/wiki/Capital_intensity), describing the [time evolution](wikipedia://en/937739) of capital per effective worker:

$$\dot{k}=\frac{\partial k}{\partial t} =f(k(t)) - (n + \delta)k(t) - c(t)$$

where $c(t)$ is period t consumption, $k(t)$ is period t capital per worker (with $k(0) = k_{0} > 0$), $f(k(t))$ is period t production, $n$ is the population growth rate, $\delta$ is the capital depreciation rate, the agent discounts future utility at rate $\rho$, with $u'>0$ and $u''<0$.

Here, $k(t)$ is the state variable which evolves according to the above equation, and $c(t)$ is the control variable. The Hamiltonian becomes

$$H(k,c,\mu,t)=e^{-\rho t}u(c(t))+\mu(t)\dot{k}=e^{-\rho t}u(c(t))+\mu(t)[f(k(t)) - (n + \delta)k(t) - c(t)]$$

The optimality conditions are

$$\frac{\partial H}{\partial c}=0 \Rightarrow e^{-\rho t}u'(c)=\mu(t)$$

$$\frac{\partial H}{\partial k}=-\frac{\partial \mu}{\partial t}=-\dot{\mu} \Rightarrow \mu(t)[f'(k)-(n+\delta)]=-\dot{\mu}$$

in addition to the transversality condition $\mu(T)k(T)=0$. If we let $u(c)=\log(c)$, then [log-differentiating](wikipedia://en/21899466) the first optimality condition with respect to $t$ yields

$$-\rho-\frac{\dot{c}}{c(t)}=\frac{\dot{\mu}}{\mu(t)}$$

Inserting this equation into the second optimality condition yields

$$\rho+\frac{\dot{c}}{c(t)}=f'(k)-(n+\delta)$$

which is known as the [Keynes–Ramsey rule](https://en.wikipedia.org/wiki/Keynes–Ramsey_rule), which gives a condition for consumption in every period which, if followed, ensures maximum lifetime utility.
