# De Bruijn torus

*Image: de\_bruijn\_torus\_3x3.stl.* [STL](https://en.wikipedia.org/wiki/STL_%28file_format%29) model of de Bruijn torus $(16,32;3,3)_{2}$ with 1s as panels and 0s as holes in the mesh – with consistent orientation, every $3\times3$ matrix appears exactly once De\_bruijn\_torus\_3x3.stl

::: {#o1 .subject cue=lead name="De Bruijn torus"}

In [combinatorial](wikipedia://en/5170) mathematics, a **De Bruijn torus**, named after Dutch mathematician [Nicolaas Govert de Bruijn](wikipedia://en/3166399), is an [array](wikipedia://en/20556859) of symbols from an alphabet (often just 0 and 1) that contains every possible [matrix](wikipedia://en/20556859) of given dimensions $m \times n$ exactly once. It is a [torus](wikipedia://en/74800) because the edges are considered wraparound for the purpose of finding matrices. Its name comes from the [De Bruijn sequence](wikipedia://en/1565267), which can be considered a special case where $n = 1$ (one dimension).

:::

One of the main open questions regarding De Bruijn tori is whether a De Bruijn torus for a particular alphabet size can be constructed for a given $m$ and $n$. It is known that these always exist when $n = 1$, since then we simply get the De Bruijn sequences, which always exist. It is also known that "square" tori exist whenever $m = n$ and even (for the odd case the resulting tori cannot be square).[^o2][^o3][^o4]

The smallest possible binary "square" de Bruijn torus, depicted above right, denoted as $(4,4;2,2)_{2}$ de Bruijn torus (or simply as $B_{2}$), contains all $2\times2$ binary matrices.

## *B*<sub>2</sub> {#B2}

*Image: 2-2-4-4-de-Bruijn-torus.svg.* The (4,4;2,2) de Bruijn torus. Each 2-by-2 binary matrix can be found within it exactly once.

Apart from "translation", "inversion" (exchanging 0s and 1s) and "rotation" (by 90 degrees), no other $(4,4;2,2)_{2}$ de Bruijn tori are possible – this can be shown by complete inspection of all 2<sup>16</sup> binary matrices (or subset fulfilling constrains such as equal numbers of 0s and 1s).[^o6]

*Image: de\_bruijn\_torus\_3x2.svg.* De Bruijn torus (8,8;3,2) containing all 64 possible 3-row × 2-column matrices exactly once, with wrap­around – the bottom half is the negative of the top half

## Binary de Bruijn tori of greater size {#Binary_de_Bruijn_tori_of_greater_size}

The paper in which an example of the $(256,256;4,4)_{2}$ de Bruijn torus was constructed contained over 10 pages of binary, despite its reduced font size, requiring three lines per row of array.

The subsequent possible binary de Bruijn torus, containing all binary $6\times6$ matrices, would have $2^{36} = 68,719,476,736$ entries, yielding a square array of dimension $262,144\times262,144$, denoted a $(262144,262144;6,6)_{2}$ de Bruijn torus or simply *B*<sub>6</sub>. This could easily be stored on a computer—if printed with pixels of side 0.1 mm, such a matrix would require an area of approximately 26×26 [square metres](https://en.wikipedia.org/wiki/Square_metre).

The object *B*<sub>8</sub>, containing all binary $8\times8$ matrices and denoted $(4294967296,4294967296;8,8)_{2}$, has a total of 2<sup>64</sup> ≈ 18.447×10<sup>18</sup> entries: storing such a matrix would require 18.5 exabits, or 2.3 [exabytes](https://en.wikipedia.org/wiki/Exabyte) of storage. At the above scale, it would cover 429×429 [square kilometres](https://en.wikipedia.org/wiki/Square_kilometre).

## Applications {#Applications}

De Bruijn tori are used in the spatial coding context, e.g. for localization of a camera,[^o13] a robot[^o14] or a tangible[^o15] based on some optical ground pattern.

They are also used as basis of the PuzzleBoard,[^o16] an optical camera calibration target which adds position encoding to a chessboard calibration pattern.[^o17]

*Image: PuzzleBoard8x11.jpg.* An example of a PuzzleBoard pattern with 8x11 chessboard corners. Each 3x3 tile pattern is unique.

De Bruijn tori can be used to implement [digital paper](https://en.wikipedia.org/wiki/Digital_paper), similar to the [Anoto](https://en.wikipedia.org/wiki/Anoto) system. Each Anoto cell has four possible states and is thus based on a de Bruijn torus like structure with alphabet size 4. It uses a repeating 6-bit De Bruijn sequence with different offsets as columns.[^o18]
