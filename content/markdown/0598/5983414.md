# Star domain

*Image: Star domain.svg.* A star domain (equivalently, a star-convex or star-shaped set) is not necessarily [convex](wikipedia://en/6292) in the ordinary sense.

*Image: Not-star-shaped.svg.* An [annulus](wikipedia://en/356158) is not a star domain.

::: {#o1 .subject cue=lead name="Star domain"}

In [geometry](wikipedia://en/18973446), a [set](wikipedia://en/26691) $S$ in the [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$ is called a **star domain** (or **star-convex set**, **star-shaped set**[^o2] or **radially convex set**) if there exists an $s_0 \in S$ such that for all $s \in S,$ the [line segment](wikipedia://en/22634860) from $s_0$ to $s$ lies in $S.$ This definition is immediately generalizable to any [real](wikipedia://en/20646438), or [complex](wikipedia://en/5826), [vector space](wikipedia://en/32370).

:::

Intuitively, if one thinks of $S$ as a region surrounded by a wall, $S$ is a star domain if one can find a vantage point $s_0$ in $S$ from which any point $s$ in $S$ is within line-of-sight. A similar, but distinct, concept is that of a [radial set](wikipedia://en/33297737).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given two points $x$ and $y$ in a vector space $X$ (such as [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$), the [convex hull](wikipedia://en/40634) of $\{x, y\}$ is called the closed interval with endpoints $x$ and $y$ and it is denoted by

$$\left[x, y\right] ~:=~ \left\{t y + (1 - t) x : 0 \leq t \leq 1\right\} ~=~ x + (y - x) [0, 1],$$

where $z [0, 1] := \{z t : 0 \leq t \leq 1\}$ for every vector $z.$

A subset $S$ of a vector space $X$ is said to be star-shaped at $s_0 \in S$ if for every $s \in S,$ the closed interval $\left[s_0, s\right] \subseteq S.$ A set $S$ is star shaped and is called a star domain if there exists some point $s_0 \in S$ such that $S$ is star-shaped at $s_0.$

A set that is star-shaped at the origin is sometimes called a star set.[^n1] Such sets are closely related to [Minkowski functionals](wikipedia://en/3510908).

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any line or plane in $\mathbb{R}^n$ is a star domain.
- A line or a plane with a single point removed is not a star domain.
- If $A$ is a set in $\mathbb{R}^n,$ the set $B = \{t a : a \in A, t \in [0, 1]\}$ obtained by connecting all points in $A$ to the origin is a star domain.
- A [cross](https://en.wikipedia.org/wiki/Cross)-shaped figure is a star domain but is not convex.
- A [star-shaped polygon](wikipedia://en/12002655) is a star domain whose boundary is a sequence of connected line segments.

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- **Convexity**: any [non-empty](wikipedia://en/9566) [convex set](wikipedia://en/6292) is a star domain. A set is convex if and only if it is a star domain with respect to each point in that set.
- **Closure and interior:** The [closure](wikipedia://en/42309) of a star domain is a star domain, but the [interior](wikipedia://en/55610) of a star domain is not necessarily a star domain.
- **Contraction**: Every star domain is a [contractible](wikipedia://en/1752414) set, via a [straight-line homotopy](wikipedia://en/212250#Examples). In particular, any star domain is a [simply connected](https://en.wikipedia.org/wiki/Simply_connected) set.
- **Shrinking**: Every star domain, and only a star domain, can be "shrunken into itself"; that is, for every dilation ratio $r < 1,$ the star domain can be dilated by a ratio $r$ such that the dilated star domain is contained in the original star domain.[^o10]
- **Union and intersection**: The [union](wikipedia://en/47949) or [intersection](wikipedia://en/23476429) of two star domains is not necessarily a star domain.
- **Balance**: Given $W \subseteq X,$ the set $\bigcap_{|u|=1} u W$ (where $u$ ranges over all [unit length](https://en.wikipedia.org/wiki/Unit_length) scalars) is a [balanced set](wikipedia://en/1734238) whenever $W$ is a star shaped at the origin (meaning that $0 \in W$ and $r w \in W$ for all $0 \leq r \leq 1$ and $w \in W$).
- **Diffeomorphism**: A non-empty open star domain $S$ in $\mathbb{R}^n$ is [diffeomorphic](wikipedia://en/8564) to $\mathbb{R}^n.$
- **Binary operators:** If $A$ and $B$ are star domains, then so is the Cartesian product $A\times B$, and the sum $A + B$.[^o2]
- **Linear transformations**: If $A$ is a star domain, then so is every linear transformation of $A$.[^o2]

:::
