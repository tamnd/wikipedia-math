# Grunsky's theorem

::: {#o1 .subject cue=lead name="Grunsky's theorem"}

In [mathematics](wikipedia://en/18831), **Grunsky's theorem**, due to the German mathematician [Helmut Grunsky](wikipedia://en/33988516), is a result in [complex analysis](wikipedia://en/5759) concerning [holomorphic](wikipedia://en/14110) [univalent functions](wikipedia://en/1534382) defined on the [unit disk](wikipedia://en/252738) in the [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers). The theorem states that a univalent function defined on the unit disc, fixing the point 0, maps every disk *\|z|* \< *r* onto a [starlike domain](wikipedia://en/5983414) for *r* ≤ tanh π/4.

:::

The **radius of starlikeness** of an univalent function *f* satisfying *f*(0) = 0 is the largest radius *r* for which the function *f* maps the open disk *\|z|* \< *r* into a [starlike domain](wikipedia://en/5983414) with respect to the origin.

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let *f* be a univalent holomorphic function on the unit disc *D* such that *f*(0) = 0. Then for all *r* ≤ tanh π/4, the image of the disc *\|z|* \< *r* is [starlike](wikipedia://en/5983414) with respect to 0, i.e. it is [closed](wikipedia://en/293802) under multiplication by real numbers in (0,1).

:::

::: {#o5 .statement cue=named-heading name="An inequality of Grunsky"}

## An inequality of Grunsky {#An_inequality_of_Grunsky}

If *f*(z) is univalent on *D* with *f*(0) = 0, then

$$\left|\log {zf^\prime(z)\over f(z)}\right|\le \log {1+|z|\over 1-|z|}.$$

Taking the real and imaginary parts of the [logarithm](wikipedia://en/17860), this implies the two inequalities

$$\left|{zf^\prime(z)\over f(z)}\right|\le {1+|z|\over 1-|z|}$$

and

$$\left|\arg {zf^\prime(z)\over f(z)}\right| \le \log {1+|z|\over 1-|z|}.$$

For fixed *z*, both these equalities are attained by suitable [Koebe functions](https://en.wikipedia.org/wiki/Koebe_function)

$$g_w(\zeta)={\zeta\over (1-\overline{w}\zeta)^2},$$

where *\|w|* = 1.

::: {#o7 .proof cue=heading name="Proof"}

### Proof {#Proof}

(Grunsky 1932) originally proved these inequalities based on extremal techniques of [Ludwig Bieberbach](wikipedia://en/616186). Subsequent proofs, outlined in (Goluzin 1939), relied on the [Loewner equation](https://en.wikipedia.org/wiki/Loewner_equation). More [elementary proofs](wikipedia://en/9318685) were subsequently given based on [Goluzin's inequalities](https://en.wikipedia.org/wiki/Goluzin's_inequalities), an equivalent form of Grunsky's inequalities (1939) for the [Grunsky matrix](wikipedia://en/33994467).

For a univalent function *g* in *z* > 1 with an expansion

$$g(z) = z + b_1 z^{-1} + b_2 z^{-2} + \cdots.$$

Goluzin's inequalities state that

$$\left|\sum_{i=1}^n\sum_{j=1}^n\lambda_i\lambda_j \log {g(z_i)-g(z_j)\over z_i-z_j}\right| \le \sum_{i=1}^n\sum_{j=1}^n \lambda_i\overline{\lambda_j}\log {z_i\overline{z_j}\over z_i\overline{z_j}-1},$$

where the *z*<sub>*i*</sub> are distinct points with |*z*<sub>*i*</sub>| > 1 and λ<sub>*i*</sub> are arbitrary complex numbers.

Taking *n* = 2. with λ<sub>*1*</sub> = – λ<sub>*2*</sub> = λ, the inequality implies

$$\left| \log {g^\prime(\zeta)g^\prime(\eta) (\zeta-\eta)^2\over (g(\zeta)-g(\eta))^2}\right|\le \log {|1-\zeta\overline{\eta}|^2\over (|\zeta|^2 -1 )(|\eta|^2 -1)}.$$

If *g* is an [odd function](wikipedia://en/592151) and η = – ζ, this yields

$$\left| \log {\zeta g^\prime(\zeta) \over g(\zeta)}\right| \le {|\zeta|^2 + 1\over |\zeta|^2 -1}.$$

Finally if *f* is any normalized univalent function in *D*, the required inequality for *f* follows by taking

$$g(\zeta)=f(\zeta^{-2})^{-{1\over 2}}$$

with $z=\zeta^{-2}.$

:::

:::

::: {#o11 .proof cue=heading name="Proof of the theorem"}

## Proof of the theorem {#Proof_of_the_theorem}

Let *f* be a univalent function on *D* with *f*(0) = 0. By [Nevanlinna's criterion](wikipedia://en/34003154), *f* is starlike on *\|z|* \< *r* if and only if

$$\Re {zf^\prime(z)\over f(z)} \ge 0$$

for *\|z|* \< *r*. Equivalently

$$\left|\arg {zf^\prime(z)\over f(z)}\right| \le {\pi\over 2}.$$

On the other hand, by the inequality of Grunsky above,

$$\left|\arg {zf^\prime(z)\over f(z)}\right|\le \log {1+|z|\over 1-|z|}.$$

Thus if

$$\log {1+|z|\over 1-|z|} \le {\pi\over 2},$$

the inequality holds at *z*. This condition is equivalent to

$$|z|\le \tanh {\pi\over 4}$$

and hence *f* is starlike on any disk *\|z|* \< *r* with *r* ≤ tanh π/4.

:::
