# Yescrypt

::: {#o1 .subject cue=lead name="Yescrypt"}

**yescrypt** is a cryptographic [key derivation function](wikipedia://en/449781) used for [password hashing](https://en.wikipedia.org/wiki/Password_hashing) on [Fedora Linux](https://en.wikipedia.org/wiki/Fedora_Linux),[^o2] [Debian](https://en.wikipedia.org/wiki/Debian),[^o3] [Ubuntu](https://en.wikipedia.org/wiki/Ubuntu),[^o4] and [Arch Linux](https://en.wikipedia.org/wiki/Arch_Linux).[^o5] The function is more resistant to offline password-cracking attacks than [SHA-512](wikipedia://en/1638777).[^o6] It is based on [scrypt](https://en.wikipedia.org/wiki/Scrypt).[^o6]

:::

It was designed by [Alexander Peslyak](https://en.wikipedia.org/wiki/Alexander_Peslyak), also known as Solar Designer, to be highly resistant to hardware-accelerated brute-force attacks. It features enhanced memory-hardness and "strongly sequential" processing, which reduces the threat of large-scale cracking attempts using GPUs, FPGAs, and ASICs. Attacks that rely on [parallelization](https://en.wikipedia.org/wiki/Parallel_computing) are made more resource-intensive by yescrypt requiring a substantial amount of RAM to compute a single hash. These security benefits and its scalability have led to its adoption as the default password-hashing scheme for several major Linux distributions, where it is identifiable in the `/etc/shadow` file by the `$y$` prefix.
