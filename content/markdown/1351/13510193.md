# Densely defined operator

::: {#o1 .subject cue=lead name="Densely defined operator"}

In [mathematics](wikipedia://en/18831) – specifically, in [operator theory](wikipedia://en/712675) – a **densely defined operator** or **partially defined operator** is a type of partially defined [function](wikipedia://en/185427). In a [topological](wikipedia://en/29954) sense, it is a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) that is defined "almost everywhere". Densely defined operators often arise in [functional analysis](wikipedia://en/11180) as operations that one would like to apply to a larger class of objects than those for which they *[a priori](wikipedia://en/6679056)* "make sense".

:::

A [closed operator](https://en.wikipedia.org/wiki/Closed_operator) that is used in practice is often densely defined.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X,Y$ be [topological vector spaces](wikipedia://en/45752).

A **densely defined** linear operator $T$ from $X$ to $Y$ is a linear operator of type $T: D(T) \to Y$, such that $D(T)$ is a [dense subset](wikipedia://en/23523594) of $X$. In other words, $T$ is a [partial function](wikipedia://en/23577) whose [domain](wikipedia://en/50263) is dense in $X$.

Sometimes this is abbreviated as $T : X \to Y$ when the context makes it clear that $T$ might not be defined for all of $X$.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

::: {#o6 .statement kind=statement/theorem cue=math-theorem name="Closed Graph Theorem"}

**Closed Graph Theorem.**

If $X, Y$ are Hausdorff and metrizable, $T : D(T) \to Y$ is densely defined, with continuous inverse $S : Y \to D(T)$, then $T$ is closed. That is, the set $\{(x, T(x)): x \in D(T)\}$ is closed in the [product topology](wikipedia://en/24910) of $X \times Y$.

:::

::: {#o7 .proof cue=math-proof}

Take any [net](wikipedia://en/22170) $(x_\alpha)$ in $D(T)$ with $T x_\alpha\to y$ in $Y$. By continuity of $S$, $x_\alpha = S(Tx_\alpha)\to\ S(y)$. Hence there exists some $x \in D(T)$ such that $x_\alpha\to x$, and $T x = T(S(y)) = y$.

:::

The [Hausdorff property](wikipedia://en/13637) ensures sequential convergence is unique. The [metrizability property](wikipedia://en/19738) ensures that [sequentially closed](wikipedia://en/4668395) sets are closed. In functional analysis, these conditions typically hold, as most spaces under consideration are [Fréchet space](wikipedia://en/233801), or stronger than Fréchet. In particular, [Banach spaces](wikipedia://en/3989) are Fréchet.

:::

## Examples {#Examples}

### Sequence {#Sequence}

Let $X=\ell^{2}(\mathbb N)$ be the [Hilbert space](wikipedia://en/20598932) of [square-summable sequences](https://en.wikipedia.org/wiki/Square-summable_sequence), with orthonormal basis $(e_n)_{n\ge 1}$. Define the [diagonal operator](https://en.wikipedia.org/wiki/Diagonal_operator)

$$A : D(A)\to \ell^{2}, \qquad x_n \mapsto nx_n,$$

with domain

$$D(A):=\Big\{x=(x_n)_{n\ge 1}\in \ell^{2}:\sum_{n=1}^{\infty} n^{2} | x_n|^{2}<\infty\Big\}.$$

Then $D(A)$ is dense in $\ell^2$ because the [finitely supported sequences](https://en.wikipedia.org/wiki/Finite_support) $c_{00}\subset D(A)$, and $c_{00}$ is dense in $\ell^2$. The operator $A$ is closed and [unbounded](wikipedia://en/1422584), since $\|Ae_n\|_2=n$.

There exists a bounded inverse:

$$A^{-1}:\ell^{2}\to D(A),\qquad (A^{-1}y)_n:=\frac{y_n}{n},\qquad \|A^{-1}\|=\sup_{n\ge 1}\frac{1}{n}=1.$$

Hence $A:D(A)\to \ell^{2}$ is bijective with bounded inverse, so $0\in\rho(A)$ and, by the [Neumann series](wikipedia://en/2533545) argument, the [resolvent set](wikipedia://en/8721698) of $A$ contains the open unit disk $\{\,\lambda\in\mathbb C:\ |\lambda|<1\,\}$.

In fact, the spectrum of $A$ (that is, the complement of its resolvent set) is precisely the set of positive integers, since for any $\lambda \not\in \{1, 2, \dots\}$, the diagonal formula

$$(A-\lambda I)^{-1}y=\bigl(\tfrac{y_n}{n-\lambda}\bigr)_{n\ge 1}$$

defines a bounded operator $\ell^2\to D(A)$.

Thus, $A$ is a densely defined, closed, unbounded operator with bounded inverse and nontrivial, unbounded spectrum.

### Differentiation {#Differentiation}

Consider the space $C^0([0, 1]; \mathbb{R})$ of all [real-valued](wikipedia://en/20646438), [continuous functions](wikipedia://en/6122) defined on the unit interval; let $C^1([0, 1]; \mathbb{R})$ denote the subspace consisting of all [continuously differentiable functions](https://en.wikipedia.org/wiki/Smooth_function). Equip $C^0([0, 1]; \mathbb{R})$ with the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm) $\|\,\cdot\,\|_\infty$; this makes $C^0([0, 1]; \mathbb{R})$ into a real [Banach space](wikipedia://en/3989). The [differentiation operator](wikipedia://en/263886) $D$ given by

$$(\mathrm{D} u)(x) = u'(x)$$

is a linear operator defined on the dense linear subspace $C^1([0, 1]; \mathbb{R}) \subset C^0([0, 1]; \mathbb{R})$, therefore it is a operator densely defined on $C^0([0, 1]; \mathbb{R})$.

The operator $\mathrm{D}$ is an example of an [unbounded linear operator](https://en.wikipedia.org/wiki/Unbounded_linear_operator), since

$$u_n (x) = e^{- n x} \quad \text{ has } \quad \frac{\left\|\mathrm{D} u_n\right\|_{\infty}}{\left\|u_n\right\|_\infty} = n.$$

This unboundedness causes problems if one wishes to somehow continuously extend the differentiation operator $D$ to the whole of $C^0([0, 1]; \mathbb{R}).$

### Paley–Wiener {#Paley–Wiener}

The [Paley–Wiener integral](wikipedia://en/6583010) is a standard example of a [continuous extension](https://en.wikipedia.org/wiki/Continuous_extension) of a densely defined operator.

In any [abstract Wiener space](wikipedia://en/6592746) $i : H \to E$ with [adjoint](https://en.wikipedia.org/wiki/Adjoint_of_an_operator) $j := i^* : E^* \to H,$ there is a natural [continuous linear operator](wikipedia://en/1802169) (in fact it is the inclusion, and is an [isometry](wikipedia://en/254777)) from $j\left(E^*\right)$ to $L^2(E, \gamma; \mathbb{R}),$ under which $j(f) \in j\left(E^*\right) \subseteq H$ goes to the [equivalence class](wikipedia://en/9260) $[f]$ of $f$ in $L^2(E, \gamma; \mathbb{R}).$ It can be shown that $j\left(E^*\right)$ is dense in $H.$ Since the above inclusion is continuous, there is a unique continuous linear extension $I : H \to L^2(E, \gamma; \mathbb{R})$ of the inclusion $j\left(E^*\right) \to L^2(E, \gamma; \mathbb{R})$ to the whole of $H.$ This extension is the Paley–Wiener map.
