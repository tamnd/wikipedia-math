# Normal probability plot

::: {#o1 .subject cue=lead name="Normal probability plot"}

The **normal probability plot** is a [graphical technique](https://en.wikipedia.org/wiki/Graphical_technique) to identify substantive departures from [normality](wikipedia://en/21462). This includes identifying [outliers](wikipedia://en/160951), [skewness](wikipedia://en/28212), [kurtosis](wikipedia://en/16848), a need for transformations, and [mixtures](wikipedia://en/708242). Normal probability plots are made of raw data, [residuals from model fits](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics), and estimated parameters.

:::

*Image: normprob.png.* A normal probability plot

In a normal probability plot (also called a "normal plot"), the sorted data are plotted vs. values selected to make the resulting image look close to a straight line if the data are approximately normally distributed. Deviations from a straight line suggest departures from normality. The plotting can be manually performed by using a special [graph paper](wikipedia://en/293606), called *normal probability paper*. With modern computers normal plots are commonly made with software.

The normal probability plot is a special case of the [Q–Q](wikipedia://en/4031859) probability plot for a normal distribution. The theoretical [quantiles](wikipedia://en/25184) are generally chosen to approximate either the mean or the median of the corresponding [order statistics](wikipedia://en/160986).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The normal probability plot is formed by plotting the sorted data vs. an approximation to the means or medians of the corresponding [order statistics](wikipedia://en/160986); see [rankit](wikipedia://en/543116). Some plot the data on the vertical axis;[^o4] others plot the data on the horizontal axis.[^o5][^o6]

Different sources use slightly different approximations for [rankits](https://en.wikipedia.org/wiki/Rankits). The formula used by the "qqnorm" function in the basic "stats" package in [R (programming language)](wikipedia://en/376707) is as follows:

$$z_i = \Phi^{-1}\left( \frac{i-a}{n+1-2a} \right),$$

for $i = 1, 2, ..., n$, where

$a = 3/8$ if $n \le 10$ and

\0.5 for *n* > 10,

and $\Phi^{-1}$ is the standard normal [quantile function](wikipedia://en/10167616).

If the data are consistent with a sample from a normal distribution, the points should lie close to a straight line. As a reference, a straight line can be fit to the points. The further the points vary from this line, the greater the indication of departure from normality. If the sample has mean 0, standard deviation 1 then a line through 0 with slope 1 could be used.

With more points, random deviations from a line will be less pronounced. Normal plots are often used with as few as 7 points, e.g., with plotting the effects in a saturated model from a [2-level fractional factorial experiment](wikipedia://en/6994353). With fewer points, it becomes harder to distinguish between random variability and a substantive deviation from normality.

:::

## Other distributions {#Other_distributions}

Probability plots for distributions other than the normal are computed in exactly the same way. The normal quantile function $\Phi^{-1}$ is simply replaced by the quantile function of the desired distribution. In this way, a probability plot can easily be generated for any distribution for which one has the quantile function.

With a [location-scale family of distributions](https://en.wikipedia.org/wiki/Location-scale_family), the [location](wikipedia://en/17516) and [scale parameters](wikipedia://en/769503) of the distribution can be estimated from the [intercept](wikipedia://en/464331) and the [slope](wikipedia://en/29368) of the line. For other distributions the parameters must first be estimated before a probability plot can be made.
