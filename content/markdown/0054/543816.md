# A5/2

::: {#o1 .subject cue=lead name="A5/2"}

**A5/2** is a [stream cipher](wikipedia://en/49007) used to provide voice privacy in the [GSM](https://en.wikipedia.org/wiki/GSM) [cellular telephone](https://en.wikipedia.org/wiki/Cell_phone) protocol. It was designed in 1992-1993 (finished March 1993) as a replacement for the relatively stronger (but still weak) [A5/1](wikipedia://en/294149), to allow the GSM standard to be exported to countries "with restrictions on the import of products with cryptographic security features".[^o2]

:::

The cipher is based on a combination of four [linear-feedback shift registers](wikipedia://en/58992) with irregular clocking and a [non-linear](https://en.wikipedia.org/wiki/Non-linear) combiner.

In 1999, [Ian Goldberg](wikipedia://en/829135) and [David A. Wagner](wikipedia://en/298253) [cryptanalyzed](wikipedia://en/5715) A5/2 in the same month it was reverse engineered, and showed that it was extremely weak – so much so that low end equipment can probably break it in real time.[^o3]

In 2003, Elad Barkan, [Eli Biham](wikipedia://en/348920) and Nathan Keller presented a ciphertext-only attack based on the [error correcting codes](wikipedia://en/4237207) used in GSM communication. They also demonstrated a vulnerability in the GSM protocols that allows a [man-in-the-middle attack](wikipedia://en/144676) to work whenever the mobile phone supports A5/2, regardless of whether it was actually being used.[^o4]

Since July 1, 2006, the [GSMA](https://en.wikipedia.org/wiki/GSM_Association) (GSM Association) mandated that GSM Mobile Phones will not support the A5/2 Cipher any longer, due to its weakness, and the fact that [A5/1](wikipedia://en/294149) is deemed mandatory by the [3GPP](https://en.wikipedia.org/wiki/3GPP) association. In July 2007, the [3GPP](https://en.wikipedia.org/wiki/3GPP) has approved a change request to prohibit the implementation of A5/2 in any new mobile phones, stating: "It is mandatory for A5/1 and non encrypted mode to be implemented in mobile stations. It is prohibited to implement A5/2 in mobile stations."[^o5] If the network does not support A5/1 then an unencrypted connection can be used.
