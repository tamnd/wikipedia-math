# Random field

::: {#o1 .subject cue=lead name="Random field"}

In [physics](wikipedia://en/22939) and [mathematics](wikipedia://en/18831), a **random field** is a random function over an arbitrary domain (usually a multi-dimensional space such as $\mathbb{R}^n$). That is, it is a function $f(x)$ that takes on a random value at each point $x \in \mathbb{R}^n$(or some other domain). It is also sometimes thought of as a synonym for a [stochastic process](wikipedia://en/47895) with some restriction on its index set. That is, by modern definitions, a random field is a generalization of a [stochastic process](wikipedia://en/47895) where the underlying parameter need no longer be [real](wikipedia://en/1482083) or [integer](wikipedia://en/14563) valued "time" but can instead take values that are multidimensional [vectors](wikipedia://en/32370) or points on some [manifold](wikipedia://en/2073470).[^o2]

:::

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Given a [probability space](wikipedia://en/43325) $(\Omega, \mathcal{F}, P)$, an *X*-valued random field is a collection of *X*-valued [random variables](wikipedia://en/25685) indexed by elements in a [topological space](wikipedia://en/30450) *T*. That is, a random field *F* is a collection

$$\{ F_t : t \in T \}$$

where each $F_t$ is an *X*-valued random variable.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

In its discrete version, a random field is a list of random numbers whose indices are identified with a discrete set of points in a space (for example, *n*-[dimensional](https://en.wikipedia.org/wiki/Dimensional) [Euclidean space](wikipedia://en/9697)). Suppose there are four random variables, $X_1$, $X_2$, $X_3$, and $X_4$, located in a 2D grid at (0,0), (0,2), (2,2), and (2,0), respectively. Suppose each random variable can take on the value of −1 or 1, and the probability of each random variable's value depends on its immediately adjacent neighbours. This is a simple example of a discrete random field.

More generally, the values each $X_i$ can take on might be defined over a continuous domain. In larger grids, it can also be useful to think of the random field as a "function valued" random variable as described above. In [quantum field theory](wikipedia://en/25267) the notion is generalized to a random [functional](wikipedia://en/1374948), one that takes on random values over a [space of functions](wikipedia://en/340630) (see [Feynman integral](https://en.wikipedia.org/wiki/Feynman_integral)).

Several kinds of random fields exist, among them the [Markov random field](wikipedia://en/1323985) (MRF), [Gibbs random field](https://en.wikipedia.org/wiki/Gibbs_random_field), [conditional random field](wikipedia://en/4118276) (CRF), and [Gaussian random field](wikipedia://en/1803858). In 1974, [Julian Besag](wikipedia://en/28095997) proposed an approximation method relying on the relation between MRFs and Gibbs RFs.

### Example properties {#Example_properties}

An MRF exhibits the [Markov property](wikipedia://en/306422)

$$P(X_i=x_i|X_j=x_j, i\neq j) =P(X_i=x_i|X_j=x_j,j\in\partial_i), \,$$

for each choice of values $(x_j)_j$. Here each $\partial_i$ is the set of neighbors of $i$. In other words, the probability that a random variable assumes a value depends on its immediate neighboring random variables. The probability of a random variable in an MRF is given by

$$P(X_i=x_i|\partial_i) = \frac{P(X_i=x_i, \partial_i)}{\sum_k P(X_i=k, \partial_i)},$$

where the sum (can be an integral) is over the possible values of *k*. It is sometimes difficult to compute this quantity exactly.

:::

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

When used in the [natural sciences](https://en.wikipedia.org/wiki/Natural_sciences), values in a random field are often spatially correlated. For example, adjacent values (i.e. values with adjacent indices) do not differ as much as values that are further apart. This is an example of a [covariance](wikipedia://en/157059) structure, many different types of which may be modeled in a random field. One example is the [Ising model](wikipedia://en/292744) where sometimes nearest neighbor interactions are only included as a simplification to better understand the model.

A common use of random fields is in the generation of computer graphics, particularly those that mimic natural surfaces such as [water](https://en.wikipedia.org/wiki/Fluid_simulation) and [earth](https://en.wikipedia.org/wiki/Digital_terrain_model). Random fields have been also used in subsurface ground models as in [^o10]

In [neuroscience](https://en.wikipedia.org/wiki/Neuroscience), particularly in [task-related functional brain imaging](https://en.wikipedia.org/wiki/Functional_neuroimaging) studies using [PET](https://en.wikipedia.org/wiki/Positron_emission_tomography) or [fMRI](https://en.wikipedia.org/wiki/Functional_magnetic_resonance_imaging), statistical analysis of random fields are one common alternative to [correction for multiple comparisons](wikipedia://en/9444220) to find regions with *truly* significant activation.[^o11] More generally, random fields can be used to correct for the [look-elsewhere effect](wikipedia://en/34059413) in statistical testing, where the domain is the [parameter space](wikipedia://en/2882813) being searched.[^o12]

They are also used in [machine learning](wikipedia://en/233488) applications (see [Graphical model](wikipedia://en/447298)).

## Tensor-valued random fields {#Tensor-valued_random_fields}

Random fields are of great use in studying natural processes by the [Monte Carlo method](wikipedia://en/56098) in which the random fields correspond to naturally spatially varying properties. This leads to tensor-valued random fields in which the key role is played by a **statistical volume element** (**SVE**), which is a spatial box over which properties can be averaged; when the SVE becomes sufficiently large, its properties become deterministic and one recovers the [representative volume element](https://en.wikipedia.org/wiki/Representative_volume_element) (RVE) of deterministic continuum physics. The second type of random field that appears in continuum theories are those of dependent quantities (temperature, displacement, velocity, deformation, rotation, body and surface forces, stress, etc.).[^o14]
