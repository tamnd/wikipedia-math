# Category of preordered sets

::: {#o1 .subject cue=lead name="Category of preordered sets"}

In [mathematics](wikipedia://en/18831), the [category](wikipedia://en/5869) **PreOrd** has [preordered sets](wikipedia://en/23582) as [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) and [order-preserving functions](https://en.wikipedia.org/wiki/Order-preserving_function) as [morphisms](wikipedia://en/27716891).[^n1][^o3] This is a category because the [composition](wikipedia://en/195947) of two order-preserving functions is order preserving and the identity map is order preserving.

:::

The [monomorphisms](wikipedia://en/59538) in **PreOrd** are the [injective](https://en.wikipedia.org/wiki/Injective) order-preserving functions.

The [empty set](wikipedia://en/9566) (considered as a preordered set) is the [initial object](https://en.wikipedia.org/wiki/Initial_object) of **PreOrd**, and the [terminal objects](https://en.wikipedia.org/wiki/Terminal_objects) are precisely the [singleton](wikipedia://en/381798) preordered sets. There are thus no [zero objects](https://en.wikipedia.org/wiki/Zero_object) in **PreOrd**.

The categorical [product](wikipedia://en/237868) in **PreOrd** is given by the [product order](wikipedia://en/1956306) on the [cartesian product](wikipedia://en/24104095).

We have a [forgetful functor](wikipedia://en/844783) **PreOrd** → **[Set](wikipedia://en/26829)** that assigns to each preordered set the underlying [set](wikipedia://en/26691), and to each order-preserving function the underlying [function](wikipedia://en/185427). This functor is [faithful](https://en.wikipedia.org/wiki/Faithful_functor), and therefore **PreOrd** is a [concrete category](wikipedia://en/167001). This functor has a left [adjoint](wikipedia://en/53991) (sending every set to that set equipped with the equality relation) and a right adjoint (sending every set to that set equipped with the total relation).

While **PreOrd** is a category with different properties, the category of preordered groups, denoted **PreOrdGrp**, presents a more complex picture, nonetheless both imply preordered connections.[^o4]

## 2-category structure {#2-category_structure}

The set of morphisms (order-preserving functions) between two preorders actually has more structure than that of a set. It can be made into a preordered set itself by the pointwise relation:

(*f* ≤ *g*) ⇔ (∀*x* *f*(*x*) ≤ *g*(*x*))

This preordered set can in turn be considered as a category, which makes **PreOrd** a [2-category](wikipedia://en/2740708) (the additional axioms of a 2-category trivially hold because any equation of parallel morphisms is true in a [posetal category](https://en.wikipedia.org/wiki/Posetal_category)).

With this 2-category structure, a [pseudofunctor](https://en.wikipedia.org/wiki/Pseudofunctor) F from a category *C* to **PreOrd** is given by the same data as a 2-functor, but has the relaxed properties:

∀*x* ∈ F(*A*), F(*id*<sub>*A*</sub>)(*x*) ≃ *x*,

∀*x* ∈ F(*A*), F(*g*$\circ$*f*)(*x*) ≃ F(*g*)(F(*f*)(*x*)),

where *x* ≃ *y* means *x* ≤ *y* and *y* ≤ *x*.
