# Sparse graph code

::: {#o1 .subject cue=lead name="Sparse graph code"}

A **sparse graph code** is a [code](https://en.wikipedia.org/wiki/Code) which is represented by a [sparse graph](https://en.wikipedia.org/wiki/Sparse_graph).

:::

Any [linear code](wikipedia://en/1866743) can be represented as a graph, where there are two sets of nodes - a set representing the transmitted [bits](https://en.wikipedia.org/wiki/Bit) and another set representing the constraints that the transmitted bits have to satisfy. The state of the art classical [error-correcting codes](https://en.wikipedia.org/wiki/Error-correcting_code) are based on sparse graphs, achieving close to the [Shannon limit](https://en.wikipedia.org/wiki/Shannon_limit). The archetypal sparse-graph codes are [Gallager's](https://en.wikipedia.org/wiki/Robert_G._Gallager) [low-density parity-check codes](wikipedia://en/516393).
