# Function series

::: {#o1 .subject cue=lead name="Function series"}

In [calculus](wikipedia://en/5176), a **function series** is a [series](wikipedia://en/15287) where each of its [terms](wikipedia://en/61338#Notation_and_terminology) is a [function](wikipedia://en/185427), not just a [real](wikipedia://en/20646438) or [complex number](wikipedia://en/5826).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of function series include [ordinary power series](wikipedia://en/59958), [Laurent series](wikipedia://en/61213), [Fourier series](wikipedia://en/59038), [Liouville-Neumann series](wikipedia://en/203807), [formal power series](wikipedia://en/60012), and [Puiseux series](wikipedia://en/2604429).

:::

## Convergence {#Convergence}

There exist many types of [convergence](wikipedia://en/1743431) for a function series, such as [uniform convergence](wikipedia://en/50652), [pointwise convergence](wikipedia://en/340198), and convergence [almost everywhere](wikipedia://en/44688). Each type of convergence corresponds to a different [metric](wikipedia://en/20018) for the [space of functions](wikipedia://en/340630) that are added together in the series, and thus a different type of [limit](wikipedia://en/26551602).

The [Weierstrass M-test](wikipedia://en/444456) is a useful result in studying convergence of function series.
