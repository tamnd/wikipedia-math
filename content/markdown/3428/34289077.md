# Euclidean random matrix

::: {#o1 .subject cue=lead name="Euclidean random matrix"}

Within [mathematics](wikipedia://en/18831), an *N*×*N* **Euclidean random matrix** Â is defined with the help of an arbitrary deterministic function *f*(**r**, **r**′) and of *N* points {**r**<sub>i</sub>} randomly distributed in a region *V* of *d*-dimensional [Euclidean space](wikipedia://en/9697). The element A<sub>ij</sub> of the matrix is equal to *f*(**r**<sub>i</sub>, **r**<sub>j</sub>): A<sub>ij</sub> = *f*(**r**<sub>i</sub>, **r**<sub>j</sub>).

:::

## History {#History}

Euclidean [random matrices](wikipedia://en/1648765) were first introduced in 1999.[^o3] They studied a special case of functions *f* that depend only on the distances between the pairs of points: *f*(**r**, **r**′) = *f*(**r** - **r**′) and imposed an additional condition on the diagonal elements A<sub>ii</sub>,

A<sub>ij</sub> = *f*(**r**<sub>i</sub> - **r**<sub>j</sub>) - u δ<sub>ij</sub>Σ<sub>k</sub>*f*(**r**<sub>i</sub> - **r**<sub>k</sub>),

motivated by the physical context in which they studied the matrix. A [Euclidean distance matrix](wikipedia://en/8092698) is a particular example of Euclidean random matrix with either *f*(**r**<sub>i</sub> - **r**<sub>j</sub>) = |**r**<sub>i</sub> - **r**<sub>j</sub>|<sup>2</sup> or *f*(**r**<sub>i</sub> - **r**<sub>j</sub>) = |**r**<sub>i</sub> - **r**<sub>j</sub>|.[^o4]

For example, in many biological networks, the strength of interaction between two nodes depends on the physical proximity of those nodes. Spatial interactions between nodes can be modelled as a Euclidean random matrix, if nodes are placed randomly in space.[^o5][^o6]

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Because the positions of the points {**r**<sub>i</sub>} are random, the matrix elements A<sub>ij</sub> are random too. Moreover, because the *N*×*N* elements are completely determined by only *N* points and, typically, one is interested in *N*≫*d*, strong correlations exist between different elements.

### Hermitian Euclidean random matrices {#Hermitian_Euclidean_random_matrices}

[Hermitian](wikipedia://en/189682) Euclidean random matrices appear in various physical contexts, including supercooled liquids,[^o10] [phonons](wikipedia://en/85754) in disordered systems,[^o11] and waves in random media.[^o12]

*Example 1:* Consider the matrix Â generated by the function *f*(**r**, **r**′) = sin(*k*<sub>0</sub>|**r**-**r**′|)/(*k*<sub>0</sub>|**r**-**r**′|), with *k*<sub>0</sub> = 2π/λ<sub>0</sub>. This matrix is [Hermitian](wikipedia://en/189682) and its [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) Λ are [real](wikipedia://en/20646438). For *N* points distributed randomly in a cube of side *L* and volume *V* = *L*<sup>3</sup>, one can show[^o12] that the [probability distribution](wikipedia://en/23543) of Λ is approximately given by the [Marchenko-Pastur law](wikipedia://en/25115911), if the density of points ρ = *N*/*V* obeys ρλ<sub>0</sub><sup>3</sup> ≤ 1 and 2.8*N*/(*k*<sub>0</sub> *L*)<sup>2</sup> \< 1 (see figure).

*Image: Fig expc.png.* Example of the probability distribution of eigenvalues Λ of the Euclidean random matrix generated by the function *f*(**r**, **r**′) = exp(*ik*<sub>0</sub>ǀ**r**-**r**′ǀ)/(*k*<sub>0</sub>ǀ**r**-**r**′ǀ), with *k*<sub>0</sub> = 2π/λ<sub>0</sub> and *f*(**r**= **r**′) = 0.

### Non-Hermitian Euclidean random matrices {#Non-Hermitian_Euclidean_random_matrices}

A theory for the [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue) density of large (*N*≫1) non-Hermitian Euclidean random matrices has been developed[^o14] and has been applied to study the problem of [random laser](https://en.wikipedia.org/wiki/Random_laser).[^o15]

*Example 2:* Consider the matrix Â generated by the function *f*(**r**, **r**′) = exp(*ik*<sub>0</sub>|**r**-**r**′|)/(*k*<sub>0</sub>|**r**-**r**′|), with *k*<sub>0</sub> = 2π/λ<sub>0</sub> and *f*(**r**= **r**′) = 0. This matrix is not Hermitian and its eigenvalues Λ are [complex](wikipedia://en/5826). The probability distribution of Λ can be found analytically[^o14] if the density of point ρ = *N*/*V* obeys ρλ<sub>0</sub><sup>3</sup> ≤ 1 and 9*N*/(8*k*<sub>0</sub> *R*)<sup>2</sup> \< 1 (see figure).
