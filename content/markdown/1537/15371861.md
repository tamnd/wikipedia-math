# Lucas–Lehmer–Riesel test

::: {#o1 .subject cue=lead name="Lucas–Lehmer–Riesel test"}

In mathematics, the **Lucas–Lehmer–Riesel test** is a [primality test](wikipedia://en/183751) for numbers of the form $N = k \cdot 2^{n} - 1$ with odd $k < 2^{n}$. The test was developed by [Hans Riesel](https://en.wikipedia.org/wiki/Hans_Riesel) and it is based on the [Lucas–Lehmer primality test](wikipedia://en/325739). It is the fastest deterministic algorithm known for numbers of that form. For numbers of the form $N = k \cdot 2^{n} + 1$ ([Proth numbers](https://en.wikipedia.org/wiki/Proth_number)), either application of [Proth's theorem](wikipedia://en/3225985) (a [Las Vegas algorithm](wikipedia://en/537519)) or one of the deterministic proofs described in Brillhart–Lehmer–Selfridge 1975[^o2] (see [Pocklington primality test](https://en.wikipedia.org/wiki/Pocklington_primality_test)) are used.

:::

::: {#o4 .definition kind=definition/construction cue=heading name="The algorithm"}

## The algorithm {#The_algorithm}

The algorithm is very similar to the [Lucas–Lehmer test](wikipedia://en/325739), but with a variable starting point depending on the value of $k$.

Define a sequence $u_{i}$ for all $i > 0$ by:

$$u_i = u_{i-1}^2-2.$$

Then $N = k \cdot 2^{n} - 1$, with $k < 2^{n}$, is prime if and only if it divides $u_{n-2}$.

:::

## Finding the starting value {#Finding_the_starting_value}

The starting value $u_{0}$ is determined as follows.

- If $k \equiv 1\text{ or } 5\pmod{6}$: if $1\pmod{6}$ and $n$ is even, or $5\pmod{6}$ and $n$ is odd, then $3$ divides $N$, and there is no need to test. Otherwise, $N \equiv 7\pmod{24}$ and the [Lucas sequence](wikipedia://en/734635) $V(4,1)$ may be used: we take $u_0 = (2+\sqrt{3})^k+(2-\sqrt{3})^k$, which is the $k$th term of that sequence. This is a generalization of the ordinary [Lucas–Lehmer test](wikipedia://en/325739), and reduces to it when $k = 1$.
- Otherwise, we are in the case where $k$ is a multiple of $3$, and it is more difficult to select the right value of $u_{0}$. It is known that if $k = 3$ and $n \equiv 0\text{ or } 3\pmod{4}$, then we can take $u_{0} = 5778$.

An alternative method for finding the starting value $u_{0}$ is given in Rödseth 1994.[^o6] The selection method is much easier than that used by Riesel for the 3-divides-$k$ case: first, find a $P$-value that satisfies the following equalities of [Jacobi symbols](wikipedia://en/97313):

$$\left(\frac{P-2}{N}\right)=1 \quad\text{and}\quad \left(\frac{P+2}{N}\right)=-1.$$

In practice, only a few $P$-values need be checked before one is found (5, 8, 9, or 11 work in about 85% of trials).

To find the starting value $u_{0}$ from the $P$ value, we can use a Lucas $(P,1)$ sequence, as shown in Rödseth 1994[^o6] as well as page 124 of Riesel 1994.[^o7] The latter explains that when $3 \nmid k$, $P = 4$ may be used as above, and no further search is necessary.

The starting value $u_{0}$ will be the [Lucas sequence](wikipedia://en/734635) term $V_{k}(P,1)$ taken modulo $N$. This process of selection takes very little time compared to the main test.

## How the test works {#How_the_test_works}

The Lucas–Lehmer–Riesel test is a particular case of group-order primality testing; we demonstrate that some number is prime by showing that some group has the order that it would have were that number prime, and we do this by finding an element of that group of precisely the right order.

For Lucas-style tests on a number $N$, we work in the multiplicative group of a quadratic extension of the integers modulo $N$; if $N$ is prime, then the order of this multiplicative group is $N^{2} - 1$, it has a subgroup of order $N + 1$, and we try to find a generator for that subgroup.

We start off by trying to find a non-iterative expression for the $u_{i}$. Following the model of the Lucas–Lehmer test, put $u_{i} = a^{2^{i}} + a^{-2^{i}}$, and by induction we have $u_{i} = u^{2}_{i-1} - 2$.

So we can consider ourselves as looking at the $2^{i}$th term of the sequence $v(i) = a^{i} + a^{i}$. If $a$ satisfies a quadratic equation, then this is a Lucas sequence, and has an expression of the form $v(i) = \alpha v(i-1) + \beta v(i-2)$. Really, we are looking at the $k \cdot 2^{i}$th term of a different sequence, but since decimations (take every $k$th term starting with the zeroth) of a Lucas sequence are themselves Lucas sequences, we can deal with the factor $k$ by picking a different starting point.

## LLR software {#LLR_software}

*LLR* is a program that can run the LLR tests. The program was developed by Jean Penné. Vincent Penné has modified the program so that it can obtain tests via the Internet.[^o10] The software is used by both individual prime searchers and some [distributed computing](https://en.wikipedia.org/wiki/Distributed_computing) projects including [Riesel Sieve](https://en.wikipedia.org/wiki/Riesel_Sieve) and [PrimeGrid](wikipedia://en/3255603).

A version revised by Pavel Atnashev, *LLR2*, was deployed in 2020. This generates a [Gerbicz-Pietrzak](https://en.wikipedia.org/wiki/Gerbicz-Pietrzak) "proof of work" certificate for the [Fermat](wikipedia://en/157755) and [Proth](wikipedia://en/3225985) tests which allows the computation to be verified without needing a full double-check.[^o11] The cost is a 35% slowdown in computation and a lack of definiteness of any positive result as these verifiable tests are probabilistic.[^o12]

A further update from Atnashev, *PRST* of 2023[^o13] uses an alternate Gerbicz-Li certificate scheme[^o14] which takes about 2× longer to verify but has virtually no speed penalty for the main computation.[^o15] The new proof scheme also applies to the Morrison test, a generalization of the LLR test with Rödseth starting value. However, generating a proof-enabled LLR/Morrison is slower than running a plain LLR/Morrison, as the proof process requires both the U and V Lucas sequences (as opposed to the plain test only requiring the V-sequence after some modification: check that $V_{k\cdot (N+1)/2} \equiv 0 \pmod N$ for $Q = -1$).[^o16]
