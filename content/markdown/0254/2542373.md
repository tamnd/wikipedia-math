# Cross-sectional regression

::: {#o1 .subject cue=lead name="Cross-sectional regression"}

In [statistics](wikipedia://en/26685) and [econometrics](wikipedia://en/10390), a **cross-sectional regression** is a type of [regression](wikipedia://en/826997) in which the [explained and explanatory variables](wikipedia://en/437701) are all associated with the same single period or point in time. This type of [cross-sectional analysis](https://en.wikipedia.org/wiki/Cross-sectional_analysis) is in contrast to a [time-series regression](https://en.wikipedia.org/wiki/Time-series_regression) or [longitudinal regression](wikipedia://en/1557623) in which the variables are considered to be associated with a sequence of points in time.

:::

For example, in [economics](https://en.wikipedia.org/wiki/Economics) a regression to explain and predict [money demand](https://en.wikipedia.org/wiki/Money_demand) (how much people choose to hold in the form of the most liquid assets) could be conducted with either [cross-sectional](wikipedia://en/3297700) or [time series](wikipedia://en/406624) data. A cross-sectional regression would have as each data point an observation on a particular individual's money holdings, income, and perhaps other variables at a single point in time, and different data points would reflect different individuals at the same point in time. In contrast, a regression using time series would have as each data point an entire economy's money holdings, income, etc. at one point in time, and different data points would be drawn on the same economy but at different points in time.
