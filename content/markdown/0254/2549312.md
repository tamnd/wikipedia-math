# Provable prime

::: {#o1 .subject cue=lead name="Provable prime"}

In [number theory](wikipedia://en/21527), a **provable prime** is an [integer](wikipedia://en/14563) that has been calculated to be [prime](wikipedia://en/23666) using a primality-proving [algorithm](wikipedia://en/775). Boot-strapping techniques using [Pocklington primality test](https://en.wikipedia.org/wiki/Pocklington_primality_test) are the most common ways to generate provable primes for cryptography.[^o2][^o3] Contrast with [probable prime](wikipedia://en/160560), which is likely (but not certain) to be prime, based on the output of a [probabilistic](https://en.wikipedia.org/wiki/Probabilistic_algorithm) [primality test](wikipedia://en/183751).

:::

In principle, every prime number can be proved to be prime in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) by using the [AKS primality test](https://en.wikipedia.org/wiki/AKS_primality_test). Other methods which guarantee that their result is prime, but which do not work for all primes, are useful for the random generation of provable primes.[^o4]

Provable primes have also been generated on embedded devices.[^o5]
