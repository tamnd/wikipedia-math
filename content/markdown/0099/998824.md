# Atom (order theory)

::: {#o1 .subject cue=lead name="Atom"}

In the [mathematical](wikipedia://en/18831) field of [order theory](wikipedia://en/361924), an element *a* of a [partially ordered set](wikipedia://en/23572) with [least element](https://en.wikipedia.org/wiki/Least_element) **0** is an **atom** if **0** \< *a* and there is no *x* such that **0** \< *x* \< *a*.

:::

Equivalently, one may define an atom to be an element that is [minimal](https://en.wikipedia.org/wiki/Minimal_element) among the non-zero elements, or alternatively an element that [covers](wikipedia://en/14835049) the least element **0**.

Let \<: denote the [covering relation](wikipedia://en/14835049) in a partially ordered set.

A partially ordered set with a least element **0** is **atomic** if every element *b* > **0** has an atom *a* below it, that is, there is some *a* such that *b* ≥ *a* :> *0*. Every finite partially ordered set with **0** is atomic, but the set of nonnegative [real numbers](wikipedia://en/20646438) (ordered in the usual way) is not atomic (and in fact has no atoms).

A partially ordered set is **relatively atomic** (or *strongly atomic*) if for all *a* \< *b* there is an element *c* such that *a* \<: *c* ≤ *b* or, equivalently, if every interval \[*a*, *b*\] is atomic. Every relatively atomic partially ordered set with a least element is atomic. Every finite poset is relatively atomic.

A partially ordered set with least element **0** is called **atomistic** (not to be confused with **atomic**) if every element is the [least upper bound](wikipedia://en/39382#Suprema) of a set of atoms. The linear order with three elements is not atomistic (see Fig. 2).

Atoms in partially ordered sets are abstract generalizations of [singleton](wikipedia://en/381798) sets in [set theory](wikipedia://en/27553) (see Fig. 1). Atomicity (the property of being atomic) provides an abstract generalization in the context of [order theory](wikipedia://en/361924) of the ability to select an element from a non-empty set.

## Coatoms {#Coatoms}

The terms *coatom*, *coatomic*, and *coatomistic* are defined dually. Thus, in a partially ordered set with [greatest element](https://en.wikipedia.org/wiki/Greatest_element) **1**, one says that

- a **coatom** is an element covered by **1**,
- the set is **coatomic** if every *b* \< **1** has a coatom *c* above it, and
- the set is **coatomistic** if every element is the [greatest lower bound](https://en.wikipedia.org/wiki/Greatest_lower_bound) of a set of coatoms.

:::
