# Certificate (complexity)

::: {#o1 .subject cue=lead name="Certificate"}

In [computational complexity theory](wikipedia://en/7543), a **certificate** (also called a **witness**) is a [string](wikipedia://en/27701) that certifies the answer to a [computation](wikipedia://en/5926), or certifies the membership of some string in a [language](https://en.wikipedia.org/wiki/Language_%28computability%29). A certificate is often thought of as a solution path within a verification process, which is used to check whether a [problem](wikipedia://en/8336) gives the answer "Yes" or "No".

:::

In the [decision tree model](wikipedia://en/22684368) of computation, certificate complexity is the minimum number of the $n$ input variables of a [decision tree](wikipedia://en/232602) that need to be assigned a value in order to definitely establish the value of the [Boolean function](wikipedia://en/753349) $f$.

## Use in definitions {#Use_in_definitions}

The notion of certificate is used to define [semi-decidability](https://en.wikipedia.org/wiki/Semi-decidability):[^o3] a [formal language](wikipedia://en/10939) $L$ is semi-decidable if there is a two-place predicate [relation](wikipedia://en/22517558) $R \subseteq \Sigma^* \times \Sigma^*$ such that $R$ is [computable](https://en.wikipedia.org/wiki/Computability), and such that for all $x \in \Sigma^*$:

x ∈ L ⇔ there exists y such that R(x, y)

In this definition, y is the certificate, or witness, for the membership of x in L.

Certificates also give definitions for some complexity classes which can alternatively be characterised in terms of [nondeterministic Turing machines](wikipedia://en/21935). A language $L$ is in **[NP](wikipedia://en/21562)** if and only if there exists a polynomial $p$ and a [polynomial-time](https://en.wikipedia.org/wiki/Polynomial-time) bounded [Turing machine](wikipedia://en/30403) $M$ such that every word $x \in \Sigma^*$ is in the language $L$ precisely if there exists a certificate $c$ of length at most $p(|x|)$ such that $M$ accepts the pair $(x, c)$.[^o4] The class **[co-NP](wikipedia://en/6184)** has a similar definition, except that there are certificates for the words *not* in the language.

The class **[NL](wikipedia://en/1145955)** has a certificate definition: a problem in the language has a certificate of polynomial length, which can be verified by a deterministic logarithmic-space bounded Turing machine that can read each bit of the certificate once only.[^o5] Alternatively, the deterministic logarithmic-space Turing machine in the statement above can be replaced by a bounded-error probabilistic constant-space Turing machine that is allowed to use only a constant number of random bits.[^o6]

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

The problem of determining, for a given graph $G$ and number $k$, if the graph contains an [independent set](wikipedia://en/524501) of size $k$ is in **NP**. Given a pair $(G, k)$ in the language, a certificate is a set of $k$ vertices which are pairwise not adjacent (and hence are an independent set of size $k$).[^o9]

A more general example, for the problem of determining if a given Turing machine accepts an input in a certain number of steps, is as follows:

L = {\<\<M>, x, w> | does \<M> accept x in |w| steps?} Show L ∈ NP. **verifier:** gets string c = \<M>, x, w such that |c| \<= P(|w|) check if c is an accepting computation of M on x with at most |w| steps

\|c| \<= O(|w|<sup>3</sup>)

if we have a computation of a TM with k steps the total size of the computation string is k<sup>2</sup> Thus, \<\<M>, x, w> ∈ L ⇔ there exists c \<= a|w|<sup>3</sup> such that \<\<M>, x, w, c> ∈ V ∈ P

:::
