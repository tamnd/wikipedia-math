# Indicator function (complex analysis)

::: {#o1 .subject cue=lead name="Indicator function"}

In the field of [mathematics](wikipedia://en/18831) known as [complex analysis](wikipedia://en/5759), the **indicator function** of an [entire function](wikipedia://en/10372) indicates the rate of growth of the function in different directions.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let us consider an entire function $f : \mathbb{C} \to \mathbb{C}$. Supposing, that its [growth order](wikipedia://en/10372#Order_and_type) is $\rho$, the indicator function of $f$ is defined to be[^o4][^o5]

$$h_f(\theta)=\limsup_{r\to\infty}\frac{\log|f(re^{i\theta})|}{r^\rho}.$$

The indicator function can be also defined for functions which are not entire but analytic inside an angle $D = \{z=re^{i\theta}:\alpha<\theta<\beta\}$.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

By the very definition of the indicator function, we have that the indicator of the product of two functions does not exceed the sum of the indicators:[^o5]p. 51–52

$$h_{fg}(\theta)\le h_f(\theta)+h_g(\theta).$$

Similarly, the indicator of the sum of two functions does not exceed the larger of the two indicators:

$$h_{f+g}(\theta)\le \max\{h_f(\theta),h_g(\theta)\}.$$

:::

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

Elementary calculations show that, if $f(z)=e^{(A+iB)z^\rho}$, then $|f(re^{i\theta})|=e^{Ar^\rho\cos(\rho\theta)-Br^\rho\sin(\rho\theta)}$. Thus,[^o5]p. 52

$$h_f(\theta) = A\cos(\rho\theta)-B\sin(\rho\theta).$$

In particular,

$$h_{\exp}(\theta) = \cos(\theta).$$

Since the complex sine and cosine functions are [expressible](wikipedia://en/5010838#Complex_arguments) in terms of the exponential, it follows from the above result that

$$h_{\sin}(\theta)=h_{\cos}(\theta)= \left|\sin(\theta)\right|$$

Another easily deducible indicator function is that of the [reciprocal Gamma function](https://en.wikipedia.org/wiki/Reciprocal_Gamma_function). However, this function is of infinite type (and of order $\rho = 1$), therefore one needs to define the indicator function to be

$$h_{1/\Gamma}(\theta) = \limsup_{r\to\infty}\frac{\log|1/\Gamma(re^{i\theta})|}{r\log r}.$$

[Stirling's approximation](wikipedia://en/151783) of the Gamma function then yields, that

$$h_{1/\Gamma}(\theta)=-\cos(\theta).$$

Another example is that of the [Mittag-Leffler function](wikipedia://en/1603459) $E_\alpha$. This function is of order $\rho = 1/\alpha$, and[^o10]p. 50

$$h_{E_\alpha}(\theta)=\begin{cases}\cos\left(\frac{\theta}{\alpha}\right),&\text{for }|\theta|\le\frac 1 2 \alpha\pi;\\0,&\text{otherwise}.\end{cases}$$

The indicator of the [Barnes G-function](wikipedia://en/2060183) can be calculated easily from its asymptotic expression (which roughly [says](wikipedia://en/2060183#Asymptotic_expansion) that $\log G(z+1)\sim \frac{z^2}{2}\log z$):

$$h_G(\theta)=\frac{\log(G(re^{i\theta}))}{r^2\log(r)} = \frac12\cos(2\theta).$$

:::

## Further properties of the indicator {#Further_properties_of_the_indicator}

Those $h$ indicator functions which are of the form

$$h(\theta)=A\cos(\rho\theta)+B\sin(\rho\theta)$$

are called $\rho$-trigonometrically convex ($A$ and $B$ are real constants). If $\rho = 1$, we simply say, that $h$ is trigonometrically convex.

Such indicators have some special properties. For example, the following statements are all true for an indicator function that is trigonometrically convex at least on an interval $(\alpha,\beta)$:[^o4]p. 55–57[^o5]p. 54–61

- If $h(\theta_1)=-\infty$ for a $\theta_1\in(\alpha,\beta)$, then $h = -\infty$ everywhere in $(\alpha,\beta)$.
- If $h$ is bounded on $(\alpha,\beta)$, then it is continuous on this interval. Moreover, $h$ satisfies a [Lipschitz condition](https://en.wikipedia.org/wiki/Lipschitz_condition) on $(\alpha,\beta)$.
- If $h$ is bounded on $(\alpha,\beta)$, then it has both left-hand-side and right-hand-side derivative at every point in the interval $(\alpha,\beta)$. Moreover, the left-hand-side derivative is not greater than the right-hand-side derivative. It also holds true, that the right-hand-side derivative is continuous from the right, while the left-hand-side derivative is continuous from the left.
- If $h$ is bounded on $(\alpha,\beta)$, then it has a derivative at all points, except possibly on a [countable set](wikipedia://en/6026).
- If $h$ is $\rho$-trigonometrically convex on $[\alpha,\beta]$, then $h(\theta)+h(\theta+\pi/\rho) \ge 0$, whenever $\alpha \le \theta < \theta+\pi/\rho\le\beta$.
