# Division by infinity

::: {#o1 .subject cue=lead name="Division by infinity"}

*Image: Hyperbola\_one\_over\_x.svg.* The [hyperbola](wikipedia://en/14052) $y = 1/x$. As $x$ approaches ∞, $y$ approaches 0.

In [mathematics](wikipedia://en/18831), **division by infinity** is [division](wikipedia://en/53696) where the [divisor](wikipedia://en/49492) (denominator) is [infinity](wikipedia://en/20110824). In ordinary arithmetic, this does not have a [well-defined](https://en.wikipedia.org/wiki/Well-defined) meaning, since *∞* is a mathematical concept that does not correspond to a specific number, and moreover, there is no nonzero real number that, when added to itself an infinite number of times, gives a finite number, unless you address the concept of [indeterminate forms](wikipedia://en/366723). However, "dividing by ∞" can be given meaning as an informal way of expressing the [limit](wikipedia://en/26551602) of dividing a number by larger and larger divisors.[^o2]

:::

Using mathematical structures that go beyond the [real numbers](wikipedia://en/20646438), it is possible to define numbers that have infinite [magnitude](wikipedia://en/577301) yet can still be manipulated in ways much like ordinary arithmetic. For example, on the [extended real number line](wikipedia://en/51698), dividing any real number by infinity yields zero,[^o3] while in the [surreal number](wikipedia://en/51432) system, dividing 1 by the infinite number $\omega$ yields the [infinitesimal](wikipedia://en/160990) number $\epsilon$.[^o4][^o5] In [floating-point arithmetic](wikipedia://en/11376), any finite number divided by $\pm\infty$ is equal to [positive or negative zero](https://en.wikipedia.org/wiki/Signed_zero) if the numerator is finite. Otherwise, the result is [NaN](https://en.wikipedia.org/wiki/NaN).

The challenges of providing a rigorous meaning of "division by infinity" are analogous to those of defining [division by zero](wikipedia://en/185663).

## Use in technology {#Use_in_technology}

*Image: Ti 73 Graphing Calculator.jpg.* This calculator does not have an infinity button.

As infinity is difficult to deal with for most calculators and computers, many do not have a formal way of computing division by infinity.[^o7][^o8] Calculators such as the [TI-84](https://en.wikipedia.org/wiki/TI-84) and most household calculators do not have an infinity button so it is impossible to type into the calculator **x*divided by infinity' so instead users can type a large number such as "1e99" ($1 \times 10^{99}$) or "-1e99". By typing in some number divided by a sufficiently large number the output will be 0. In some cases this fails as there is either an overflow error or if the numerator is also a sufficiently large number then the output may be 1 or a real number. In the [Wolfram language](https://en.wikipedia.org/wiki/Wolfram_language), dividing an integer by infinity will result in the result 0.[^o9] Also, in some calculators such as the [TI-Nspire](https://en.wikipedia.org/wiki/TI-Nspire_series), 1 divided by infinity can be evaluated as 0.***

## Use in calculus {#Use_in_calculus}

### Integration {#Integration}

In [calculus](wikipedia://en/5176), taking the integral of a function is defined finding the area under a curve. This can be done simply by breaking up this area into rectangular sections and taking the sum of these sections. These are called [Riemann sums](wikipedia://en/176478). As the sections get narrower, the Riemann sum becomes an increasingly accurate approximation of the true area. Taking the limit of these Riemann sums, in which the sections can be heuristically regarded as "infinitely thin", gives the definite integral of the function over the prescribed interval. Conceptually this results in dividing the interval by infinity to result in infinitely small pieces.[^o2]p. 255–259

On a different note when taking an integral where one of the boundaries is infinity this is defined as an [improper integral](wikipedia://en/346030).[^o12] To determine this one would take the limit as a variable an approaches infinity substituting a in for the infinity sign. This would then allow the integral to be evaluated and then the limit would be taken. In many cases evaluating this would result in a term being divided by infinity. In this case in order to evaluate the integral one would assume this to be zero. This allows for the integral to be assumed to converge meaning a finite answer can be determined from the integral using this assumption.[^o12]

### L'Hôpital's rule {#L'Hôpital's_rule}

When given a ratio between two functions, the limit of this ratio can be evaluated by computing the limit of each function separately. Where the limit of the function in the denominator is infinity, and the numerator does not allow the ratio to be well determined, the limit of the ratio is said to be of indeterminate form.[^o14] An example of this is:

$$\frac{\infty}{\infty}$$

Using L'Hôpital's rule to evaluate limits of fractions where the denominator tends towards infinity can produce results other than 0.

If

$$\lim_{x\to c}\frac{f'(x)}{g'(x)}$$

then

$$\lim_{x\to c}\frac{f(x)}{g(x)} = \lim_{x\to c}\frac{f'(x)}{g'(x)}$$

So if

$$\lim_{x\to c}|f(x)| = \lim_{x\to c}|g(x)| = \infty,$$

then

$\lim_{x\to c}\frac{f(x)}{g(x)}=L$[^o15]

This means that, when using limits to give meaning to division by infinity, the result of "dividing by infinity" does not always equal 0.
