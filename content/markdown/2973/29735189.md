# Graph-tool

::: {#o1 .subject cue=lead name="Graph-tool"}

**graph-tool** is a [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) module for manipulation and statistical analysis of [graphs](wikipedia://en/325806) (AKA [networks](wikipedia://en/766409)). The core data structures and algorithms of graph-tool are implemented in [C++](https://en.wikipedia.org/wiki/C++), making extensive use of [metaprogramming](https://en.wikipedia.org/wiki/Metaprogramming), based heavily on the [Boost Graph Library](https://en.wikipedia.org/wiki/Boost_Graph_Library).[^o3] Many algorithms are implemented in parallel using [OpenMP](https://en.wikipedia.org/wiki/OpenMP), which provides increased performance on [multi-core](https://en.wikipedia.org/wiki/Multi-core_processor) architectures.

:::

## Features {#Features}

- Creation and manipulation of [directed](wikipedia://en/19721986) or [undirected graphs](wikipedia://en/325806).
- Association of arbitrary information to the vertices, edges or even the graph itself, by means of property maps.
- Filter vertices and/or edges "on the fly", such that they appear to have been removed.
- Support for [dot](https://en.wikipedia.org/wiki/DOT_language), [Graph Modelling Language](wikipedia://en/3428490) and [GraphML](wikipedia://en/3821625) formats.
- Convenient and powerful [graph drawing](wikipedia://en/325813) based on [cairo](https://en.wikipedia.org/wiki/Cairo_%28graphics%29) or [Graphviz](https://en.wikipedia.org/wiki/Graphviz).
- Support for typical statistical measurements: degree/property histogram, combined degree/property histogram, vertex-vertex correlations, [assortativity](https://en.wikipedia.org/wiki/Assortativity), average vertex-vertex [shortest path](https://en.wikipedia.org/wiki/Shortest_path), etc.
- Support for several graph-theoretical algorithms: such as [graph isomorphism](wikipedia://en/247577), [subgraph isomorphism](wikipedia://en/450062), [minimum spanning tree](wikipedia://en/41795), [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29), [dominator](wikipedia://en/396116) tree, [maximum flow](https://en.wikipedia.org/wiki/Maximum_flow), etc.
- Support for several [centrality](wikipedia://en/1462712) measures.
- Support for [clustering coefficients](wikipedia://en/1457636), as well as [network motif](https://en.wikipedia.org/wiki/Network_motif) statistics and [community structure](https://en.wikipedia.org/wiki/Community_structure) detection.
- Generation of [random graphs](https://en.wikipedia.org/wiki/Random_graphs), with arbitrary degree distribution and correlations.
- Support for well-established network models: [Price](wikipedia://en/7915003), [Barabási-Albert](wikipedia://en/8286726), Geometric Networks, Multidimensional [lattice graph](wikipedia://en/19635706), etc.

## Suitability {#Suitability}

Graph-tool can be used to work with very large graphs in a variety of contexts, including simulation of [cellular tissue](https://en.wikipedia.org/wiki/Epithelium),[^o6] [data mining](wikipedia://en/42253),[^o7][^o8] [analysis of social networks](wikipedia://en/325726),[^o9][^o10] analysis of [P2P](https://en.wikipedia.org/wiki/Peer-to-peer) systems,[^o11] large-scale modeling of [agent-based systems](https://en.wikipedia.org/wiki/Agent-based_model),[^o12] theoretical assessment and modeling of network [clustering](wikipedia://en/1457636),[^o13] large-scale [call graph](https://en.wikipedia.org/wiki/Call_graph) analysis,[^o14] and analysis of the brain's [Connectome](https://en.wikipedia.org/wiki/Connectome).[^o15]
