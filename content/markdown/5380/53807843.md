# K-synchronized sequence

::: {#o1 .subject cue=lead name="K-synchronized sequence"}

In [mathematics](wikipedia://en/18831) and [theoretical computer science](wikipedia://en/323392), a ***k*-synchronized sequence** is an infinite [sequence](wikipedia://en/27838) of terms *s*(*n*) characterized by a [finite automaton](wikipedia://en/10931) taking as input two strings *m* and *n*, each expressed in some fixed [base](wikipedia://en/701207) *k*, and accepting if *m* = *s*(*n*). The class of *k*-synchronized sequences lies between the classes of [*k*-automatic sequences](wikipedia://en/7740302) and [*k*-regular sequences](wikipedia://en/49645022).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

### As relations {#As_relations}

Let Σ be an alphabet of *k* symbols where *k* ≥ 2, and let \[*n*\]<sub>*k*</sub> denote the base-*k* representation of some number *n*. Given *r* ≥ 2, a subset *R* of $\mathbb{N}^{r}$ is *k*-synchronized if the relation {(\[*n*<sub>1</sub>\]<sub>*k*</sub>, ..., \[*n*<sub>*r*</sub>\]<sub>*k*</sub>)} is a right-synchronized[^o5] [rational relation](wikipedia://en/37532679#Rational_relations_and_rational_functions) over Σ<sup>∗</sup> × ... × Σ<sup>∗</sup>, where (*n*<sub>1</sub>, ..., *n*<sub>*r*</sub>) $\in$ *R*.[^o6]

### Language-theoretic {#Language-theoretic}

Let *n* ≥ 0 be a [natural number](wikipedia://en/21474) and let *f*: $\mathbb{N} \rightarrow \mathbb{N}$ be a map, where both *n* and *f*(*n*) are expressed in base *k*. The sequence *f*(*n*) is *k*-synchronized if the language of pairs $\{(n, f(n))\}$ is [regular](wikipedia://en/25723).

:::

## History {#History}

The class of *k*-synchronized sequences was introduced by Carpi and Maggi.[^o6]

::: {#o10 .example cue=heading name="Example"}

## Example {#Example}

### Subword complexity {#Subword_complexity}

Given a *k*-automatic sequence *s*(*n*) and an infinite string *S* = *s*(1)*s*(2)..., let ρ<sub>*S*</sub>(n) denote the subword complexity of *S*; that is, the number of distinct [subwords](https://en.wikipedia.org/wiki/Substring) of length *n* in *S*. Goč, Schaeffer, and Shallit[^o12] demonstrated that there exists a finite automaton accepting the language

$$\{(n, m)_k \mid n \geq 0 \text{ and } m = \rho_S(n)\}.$$

This automaton guesses the endpoints of every contiguous block of symbols in *S* and verifies that each subword of length *n* starting within a given block is novel while all other subwords are not. It then verifies that *m* is the sum of the sizes of the blocks. Since the pair (*n*, *m*)<sub>*k*</sub> is accepted by this automaton, the subword [complexity function](https://en.wikipedia.org/wiki/Complexity_function) of the *k*-automatic sequence *s*(*n*) is *k*-synchronized.

:::

::: {#o14 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

*k*-synchronized sequences exhibit a number of interesting properties. A non-exhaustive list of these properties is presented below.

- Every *k*-synchronized sequence is [*k*-regular](wikipedia://en/49645022).[^o15]
- Every [*k*-automatic sequence](wikipedia://en/7740302) is *k*-synchronized. To be precise, a sequence *s*(*n*) is *k*-automatic if and only if *s*(*n*) is *k*-synchronized and *s*(*n*) takes on finitely many terms.[^o16] This is an immediate consequence of both the above property and the fact that every *k*-regular sequence taking on finitely many terms is *k*-automatic.
- The class of *k*-synchronized sequences is closed under termwise sum and termwise composition.[^o17][^o18]
- The terms of any *k*-synchronized sequence have a linear growth rate.[^o19]
- If *s*(*n*) is a *k*-synchronized sequence, then both the subword complexity of *s*(*n*) and the palindromic complexity of *s*(*n*) (similar to subword complexity, but for distinct [palindromes](https://en.wikipedia.org/wiki/Palindrome)) are *k*-regular sequences.[^o20]

:::
