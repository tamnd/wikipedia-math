# Matrix decomposition

::: {#o1 .subject cue=lead name="Matrix decomposition"}

*Image: MatrixWorld.svg.* Diagram summarizing relationships between matrix classes and common matrix factorizations

In the [mathematical](wikipedia://en/18831) discipline of [linear algebra](wikipedia://en/18422), a **matrix decomposition** or **matrix factorization** is a [factorization](wikipedia://en/82341) of a [matrix](wikipedia://en/20556859) into a product of matrices. There are many different matrix decompositions; each finds use among a particular class of problems.

:::

::: {#o3 .example cue=heading name="Example"}

## Example {#Example}

In [numerical analysis](wikipedia://en/21506), different decompositions are used to implement efficient matrix [algorithms](wikipedia://en/775).

For example, when solving a [system of linear equations](wikipedia://en/113087) $A \mathbf{x} = \mathbf{b}$, the matrix *A* can be decomposed via the [LU decomposition](wikipedia://en/6243993). The LU decomposition factorizes a matrix into a [lower triangular matrix](https://en.wikipedia.org/wiki/Lower_triangular_matrix) *L* and an [upper triangular matrix](https://en.wikipedia.org/wiki/Upper_triangular_matrix) *U*. The systems $L(U \mathbf{x}) = \mathbf{b}$ and $U \mathbf{x} = L^{-1} \mathbf{b}$ require fewer additions and multiplications to solve, compared with the original system $A \mathbf{x} = \mathbf{b}$, though one might require significantly more digits in inexact arithmetic such as [floating point](https://en.wikipedia.org/wiki/Floating_point).

Similarly, the [QR decomposition](wikipedia://en/305223) expresses *A* as *QR* with *Q* an [orthogonal matrix](wikipedia://en/105620) and *R* an upper triangular matrix. The system *Q*(*R***x**) = **b** is solved by *R***x** = *Q*<sup>T</sup>**b** = **c**, and the system *R***x** = **c** is solved by '[back substitution](wikipedia://en/374222#Forward_and_back_substitution)'. The number of additions and multiplications required is about twice that of using the LU solver, but no more digits are required in inexact arithmetic because the QR decomposition is [numerically stable](https://en.wikipedia.org/wiki/Numerically_stable).

:::

## Decompositions related to solving systems of linear equations {#Decompositions_related_to_solving_systems_of_linear_equations}

### LU decomposition {#LU_decomposition}

- Traditionally applicable to: [square matrix](wikipedia://en/166022) *A*, although rectangular matrices can be applicable.[^o6][^o7]
- Decomposition: $A=LU$, where *L* is [lower triangular](wikipedia://en/374222) and *U* is [upper triangular](wikipedia://en/374222).
- Related: the [*LDU* decomposition](https://en.wikipedia.org/wiki/LDU_decomposition) is $A=LDU$, where *L* is [lower triangular](wikipedia://en/374222) with ones on the diagonal, *U* is [upper triangular](wikipedia://en/374222) with ones on the diagonal, and *D* is a [diagonal matrix](wikipedia://en/174080).
- Related: the [*LUP* decomposition](https://en.wikipedia.org/wiki/LUP_decomposition) is $PA=LU$, where *L* is [lower triangular](wikipedia://en/374222), *U* is [upper triangular](wikipedia://en/374222), and *P* is a [permutation matrix](wikipedia://en/238849).
- Existence: An LUP decomposition exists for any square matrix *A*. When *P* is an [identity matrix](wikipedia://en/59718), the LUP decomposition reduces to the LU decomposition.
- Comments: The LUP and LU decompositions are useful in solving an *n*-by-*n* system of linear equations $A \mathbf{x} = \mathbf{b}$. These decompositions summarize the process of [Gaussian elimination](wikipedia://en/13035) in matrix form. Matrix *P* represents any row interchanges carried out in the process of Gaussian elimination. If Gaussian elimination produces the [row echelon form](wikipedia://en/330215) without requiring any row interchanges, then *P* = *I*, so an LU decomposition exists.

### Rank factorization {#Rank_factorization}

- Applicable to: *m*-by-*n* matrix *A* of rank *r*
- Decomposition: $A=CF$ where *C* is an *m*-by-*r* full column rank matrix and *F* is an *r*-by-*n* full row rank matrix
- Comment: The rank factorization can be used to [compute the Moore–Penrose pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse#Rank_decomposition) of *A*,[^o11] which one can apply to [obtain all solutions of the linear system](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse#Obtaining_all_solutions_of_a_linear_system) $A \mathbf{x} = \mathbf{b}$.

### Cholesky decomposition {#Cholesky_decomposition}

- Applicable to: [square](wikipedia://en/166022), [hermitian](wikipedia://en/126474), [positive definite](https://en.wikipedia.org/wiki/Positive-definite_matrix) matrix $A$
- Decomposition: $A=U^*U$, where $U$ is upper triangular with real positive diagonal entries
- Comment: if the matrix $A$ is Hermitian and positive semi-definite, then it has a decomposition of the form $A=U^*U$ if the diagonal entries of $U$ are allowed to be zero
- Uniqueness: for positive definite matrices Cholesky decomposition is unique. However, it is not unique in the positive semi-definite case.
- Comment: if $A$ is real and symmetric, $U$ has all real elements
- Comment: An alternative is the [LDL decomposition](https://en.wikipedia.org/wiki/LDL_decomposition), which can avoid extracting square roots.

### QR decomposition {#QR_decomposition}

- Applicable to: *m*-by-*n* matrix *A* with linearly independent columns
- Decomposition: $A=QR$ where $Q$ is a [unitary matrix](wikipedia://en/129222) of size *m*-by-*m*, and $R$ is an [upper triangular](wikipedia://en/374222) matrix of size *m*-by-*n*
- Uniqueness: In general it is not unique, but if $A$ is of full [rank](https://en.wikipedia.org/wiki/Matrix_rank), then there exists a single $R$ that has all positive diagonal elements. If $A$ is square, also $Q$ is unique.
- Comment: The QR decomposition provides an effective way to solve the system of equations $A \mathbf{x} = \mathbf{b}$. The fact that $Q$ is [orthogonal](wikipedia://en/105620) means that $Q^{\mathrm{T}}Q=I$, so that $A \mathbf{x} = \mathbf{b}$ is equivalent to $R \mathbf{x} = Q^{\mathsf{T}} \mathbf{b}$, which is very easy to solve since $R$ is [triangular](wikipedia://en/374222).

## Decompositions based on eigenvalues and related concepts {#Decompositions_based_on_eigenvalues_and_related_concepts}

### Eigendecomposition {#Eigendecomposition}

- Also called *[spectral decomposition](https://en.wikipedia.org/wiki/Spectral_decomposition_%28Matrix%29)*.
- Applicable to: [square matrix](wikipedia://en/166022) *A* with linearly independent eigenvectors (not necessarily distinct eigenvalues).
- Decomposition: $A=VDV^{-1}$, where *D* is a [diagonal matrix](wikipedia://en/174080) formed from the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of *A*, and the columns of *V* are the corresponding [eigenvectors](https://en.wikipedia.org/wiki/Eigenvector) of *A*.
- Existence: An *n*-by-*n* matrix *A* always has *n* (complex) eigenvalues, which can be ordered (in more than one way) to form an *n*-by-*n* diagonal matrix *D* and a corresponding matrix of nonzero columns *V* that satisfies the [eigenvalue equation](https://en.wikipedia.org/wiki/Eigenvalue_equation) $AV=VD$. $V$ is invertible if and only if the *n* eigenvectors are [linearly independent](wikipedia://en/101863) (that is, each eigenvalue has [geometric multiplicity](https://en.wikipedia.org/wiki/Geometric_multiplicity) equal to its [algebraic multiplicity](https://en.wikipedia.org/wiki/Algebraic_multiplicity)). A sufficient (but not necessary) condition for this to happen is that all the eigenvalues are different (in this case geometric and algebraic multiplicity are equal to 1)
- Comment: One can always normalize the eigenvectors to have length one (see the definition of the eigenvalue equation)
- Comment: Every [normal matrix](wikipedia://en/170366) *A* (that is, matrix for which $AA^*=A^*A$, where $A^*$ is a [conjugate transpose](wikipedia://en/217548)) can be eigendecomposed. For a [normal matrix](wikipedia://en/170366) *A* (and only for a normal matrix), the eigenvectors can also be made orthonormal ($VV^*=I$) and the eigendecomposition reads as $A=VDV^*$. In particular all [unitary](wikipedia://en/129222), [Hermitian](wikipedia://en/189682), or [skew-Hermitian](wikipedia://en/509788) (in the real-valued case, all [orthogonal](wikipedia://en/105620), [symmetric](wikipedia://en/126474), or [skew-symmetric](wikipedia://en/174055), respectively) matrices are normal and therefore possess this property.
- Comment: For any real [symmetric matrix](wikipedia://en/126474) *A*, the eigendecomposition always exists and can be written as $A=VDV^\mathsf{T}$, where both *D* and *V* are real-valued.
- Comment: The eigendecomposition is useful for understanding the solution of a system of linear ordinary differential equations or linear difference equations. For example, the difference equation $x_{t+1}=Ax_t$ starting from the initial condition $x_0=c$ is solved by $x_t = A^tc$, which is equivalent to $x_t = VD^tV^{-1}c$, where *V* and *D* are the matrices formed from the eigenvectors and eigenvalues of *A*. Since *D* is diagonal, raising it to power $D^t$, just involves raising each element on the diagonal to the power *t*. This is much easier to do and understand than raising *A* to power *t*, since *A* is usually not diagonal.

### Jordan decomposition {#Jordan_decomposition}

The [Jordan normal form](wikipedia://en/312877) and the [Jordan–Chevalley decomposition](wikipedia://en/11578785)

- Applicable to: [square matrix](wikipedia://en/166022) *A*
- Comment: the Jordan normal form generalizes the eigendecomposition to cases where there are repeated eigenvalues and cannot be diagonalized, the Jordan–Chevalley decomposition does this without choosing a basis.

### Schur decomposition {#Schur_decomposition}

- Applicable to: [square matrix](wikipedia://en/166022) *A*
- Decomposition (complex version): $A=UTU^*$, where *U* is a [unitary matrix](wikipedia://en/129222), $U^*$ is the [conjugate transpose](wikipedia://en/217548) of *U*, and *T* is an [upper triangular](https://en.wikipedia.org/wiki/Upper_triangular) matrix called the complex [Schur form](https://en.wikipedia.org/wiki/Schur_form) which has the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of *A* along its diagonal.
- Comment: if *A* is a [normal matrix](wikipedia://en/170366), then *T* is diagonal and the Schur decomposition coincides with the spectral decomposition.

### Real Schur decomposition {#Real_Schur_decomposition}

- Applicable to: [square matrix](wikipedia://en/166022) *A*
- Decomposition: This is a version of Schur decomposition where $V$ and $S$ only contain real numbers. One can always write $A=VSV^\mathsf{T}$ where *V* is a real [orthogonal matrix](wikipedia://en/105620), $V^\mathsf{T}$ is the [transpose](https://en.wikipedia.org/wiki/Matrix_transpose) of *V*, and *S* is a [block upper triangular](wikipedia://en/457464) matrix called the real [Schur form](https://en.wikipedia.org/wiki/Schur_form). The blocks on the diagonal of *S* are of size 1×1 (in which case they represent real eigenvalues) or 2×2 (in which case they are derived from [complex conjugate](wikipedia://en/173918) eigenvalue pairs).

### QZ decomposition {#QZ_decomposition}

- Also called: *generalized Schur decomposition*
- Applicable to: [square matrices](wikipedia://en/166022) *A* and *B*
- Comment: there are two versions of this decomposition: complex and real.
- Decomposition (complex version): $A=QSZ^*$ and $B=QTZ^*$ where *Q* and *Z* are [unitary matrices](wikipedia://en/129222), the \* superscript represents [conjugate transpose](wikipedia://en/217548), and *S* and *T* are [upper triangular](https://en.wikipedia.org/wiki/Upper_triangular) matrices.
- Comment: in the complex QZ decomposition, the ratios of the diagonal elements of *S* to the corresponding diagonal elements of *T*, $\lambda_i = S_{ii}/T_{ii}$, are the generalized [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) that solve the [generalized eigenvalue problem](wikipedia://en/13576645#Additional_topics) $A \mathbf{v} = \lambda B \mathbf{v}$ (where $\lambda$ is an unknown scalar and **v** is an unknown nonzero vector).
- Decomposition (real version): $A=QSZ^\mathsf{T}$ and $B=QTZ^\mathsf{T}$ where *A*, *B*, *Q*, *Z*, *S*, and *T* are matrices containing real numbers only. In this case *Q* and *Z* are [orthogonal matrices](wikipedia://en/105620), the *T* superscript represents [transposition](https://en.wikipedia.org/wiki/Matrix_transpose), and *S* and *T* are [block upper triangular](wikipedia://en/457464) matrices. The blocks on the diagonal of *S* and *T* are of size 1×1 or 2×2.

### Takagi's factorization {#Takagi's_factorization}

- Applicable to: square, complex, symmetric matrix *A*.
- Decomposition: $A=VDV^\mathsf{T}$, where *D* is a real nonnegative [diagonal matrix](wikipedia://en/174080), and *V* is [unitary](wikipedia://en/129222). $V^\mathsf{T}$ denotes the [matrix transpose](https://en.wikipedia.org/wiki/Matrix_transpose) of *V*.
- Comment: The diagonal elements of *D* are the nonnegative square roots of the eigenvalues of $AA^*=VD^2V^{-1}$.
- Comment: *V* may be complex even if *A* is real.
- Comment: This is not a special case of the eigendecomposition (see above), which uses $V^{-1}$ instead of $V^\mathsf{T}$. Moreover, if *A* is not real, it is not Hermitian and the form using $V^*$ also does not apply.

### Singular value decomposition {#Singular_value_decomposition}

- Applicable to: *m*-by-*n* matrix *A*.
- Decomposition: $A=UDV^*$, where *D* is a nonnegative [diagonal matrix](wikipedia://en/174080), and *U* and *V* are [unitary](wikipedia://en/129222). Here $V^*$ is the [conjugate transpose](wikipedia://en/217548) of *V* (or simply the [transpose](https://en.wikipedia.org/wiki/Matrix_transpose), if *V* contains real numbers only).
- Comment: The diagonal elements of *D* are called the [singular values](wikipedia://en/709116) of *A*.
- Comment: Like the eigendecomposition above, the singular value decomposition involves finding basis directions along which matrix multiplication is equivalent to scalar multiplication, but it has greater generality since the matrix under consideration need not be square.
- Uniqueness: the singular values of $A$ are always uniquely determined. $U$ and $V$ need not to be unique in general.

### Scale-invariant decompositions {#Scale-invariant_decompositions}

Refers to variants of existing matrix decompositions, such as the SVD, that are invariant with respect to diagonal scaling.

- Applicable to: *m*-by-*n* matrix *A*.
- Unit-Scale-Invariant Singular-Value Decomposition: $A=DUSV^*E$, where *S* is a unique nonnegative [diagonal matrix](wikipedia://en/174080) of scale-invariant singular values, *U* and *V* are [unitary matrices](wikipedia://en/129222), $V^*$ is the [conjugate transpose](wikipedia://en/217548) of *V*, and positive diagonal matrices *D* and *E*.
- Comment: Is analogous to the SVD except that the diagonal elements of *S* are invariant with respect to left and/or right multiplication of *A* by arbitrary nonsingular diagonal matrices, as opposed to the standard SVD for which the singular values are invariant with respect to left and/or right multiplication of *A* by arbitrary unitary matrices.
- Comment: Is an alternative to the standard SVD when invariance is required with respect to diagonal rather than unitary transformations of *A*.
- Uniqueness: The scale-invariant singular values of $A$ (given by the diagonal elements of *S*) are always uniquely determined. Diagonal matrices *D* and *E*, and unitary *U* and *V*, are not necessarily unique in general.
- Comment: *U* and *V* matrices are not the same as those from the SVD.

Analogous scale-invariant decompositions can be derived from other matrix decompositions; for example, to obtain scale-invariant eigenvalues.[^o25][^o26]

### Hessenberg decomposition {#Hessenberg_decomposition}

- Applicable to: [square matrix](wikipedia://en/166022) A.
- Decomposition: $A=PHP^*$ where $H$ is the [Hessenberg matrix](wikipedia://en/519204) and $P$ is a [unitary matrix](wikipedia://en/129222).
- Comment: often the first step in the Schur decomposition.

### Complete orthogonal decomposition {#Complete_orthogonal_decomposition}

- Also known as: *UTV decomposition*, *ULV decomposition*, *URV decomposition*.
- Applicable to: *m*-by-*n* matrix *A*.
- Decomposition: $A=UTV^*$, where *T* is a [triangular matrix](wikipedia://en/374222), and *U* and *V* are [unitary matrices](wikipedia://en/129222).
- Comment: Similar to the singular value decomposition and to the Schur decomposition.

## Other decompositions {#Other_decompositions}

### Polar decomposition {#Polar_decomposition}

- Applicable to: any square complex matrix *A*.
- Decomposition: $A=UP$ (right polar decomposition) or $A=P'U$ (left polar decomposition), where *U* is a [unitary matrix](wikipedia://en/129222) and *P* and *P**are [positive semidefinite](https://en.wikipedia.org/wiki/Positive_semidefinite_matrix) [Hermitian matrices](https://en.wikipedia.org/wiki/Hermitian_matrices).***
- Uniqueness: $P$ is always unique and equal to $\sqrt{A^*A}$ (which is always hermitian and positive semidefinite). If $A$ is invertible, then $U$ is unique.
- Comment: Since any Hermitian matrix admits a spectral decomposition with a unitary matrix, $P$ can be written as $P=VDV^*$. Since $P$ is positive semidefinite, all elements in $D$ are non-negative. Since the product of two unitary matrices is unitary, taking $W=UV$one can write $A=U(VDV^*)=WDV^*$ which is the singular value decomposition. Hence, the existence of the polar decomposition is equivalent to the existence of the singular value decomposition.

### Algebraic polar decomposition {#Algebraic_polar_decomposition}

- Applicable to: square, complex, non-singular matrix *A*.[^o32]
- Decomposition: $A=QS$, where *Q* is a complex orthogonal matrix and *S* is complex symmetric matrix.
- Uniqueness: If $A^\mathsf{T}A$ has no negative real eigenvalues, then the decomposition is unique.[^o33]
- Comment: The existence of this decomposition is equivalent to $AA^\mathsf{T}$ being similar to $A^\mathsf{T}A$.[^o34]
- Comment: A variant of this decomposition is $A=RC$, where *R* is a real matrix and *C* is a [circular matrix](https://en.wikipedia.org/wiki/Circular_matrix).[^o33]

### Mostow's decomposition {#Mostow's_decomposition}

- Applicable to: square, complex, non-singular matrix *A*.[^o36][^o37]
- Decomposition: $A=Ue^{iM}e^{S}$, where *U* is unitary, *M* is real anti-symmetric and *S* is real symmetric.
- Comment: The matrix *A* can also be decomposed as $A=U_2e^{S_2}e^{iM_2}$, where *U*<sub>2</sub> is unitary, *M*<sub>2</sub> is real anti-symmetric and *S*<sub>2</sub> is real symmetric.[^o33]

### Sinkhorn normal form {#Sinkhorn_normal_form}

- Applicable to: square real matrix *A* with strictly positive elements.
- Decomposition: $A=D_{1}SD_{2}$, where *S* is [doubly stochastic](wikipedia://en/2906180) and *D*<sub>1</sub> and *D*<sub>2</sub> are real diagonal matrices with strictly positive elements.

### Sectoral decomposition {#Sectoral_decomposition}

- Applicable to: square, complex matrix *A* with [numerical range](wikipedia://en/15581094) contained in the sector $S_\alpha = \left\{r e^{i \theta} \in \mathbb{C} \mid r> 0, |\theta| \le \alpha < \frac{\pi}{2}\right\}$.
- Decomposition: $A = CZC^*$, where *C* is an invertible complex matrix and $Z = \operatorname{diag}\left(e^{i\theta_1},\ldots,e^{i\theta_n}\right)$ with all $\left|\theta_j\right| \le \alpha$.[^o40][^o41]

### Williamson's normal form {#Williamson's_normal_form}

- Applicable to: square, [positive-definite](https://en.wikipedia.org/wiki/Positive-definite_matrix) real matrix *A* with order 2*n*×2*n*.
- Decomposition: $A=S^\mathsf{T}\operatorname{diag}(D,D)S$, where $S \in \text{Sp}(2n)$ is a [symplectic matrix](wikipedia://en/173983) and *D* is a nonnegative *n*-by-*n* diagonal matrix.[^o43]

### Matrix square root {#Matrix_square_root}

- Decomposition: $A=BB$, not unique in general.
- In the case of positive semidefinite $A$, there is a unique positive semidefinite $B$ such that $A=B^*B=BB$.

## Generalizations {#Generalizations}

There exist analogues of the SVD, QR, LU and Cholesky factorizations for **quasimatrices** and **cmatrices** or **continuous matrices**.[^o47] A "quasimatrix" is, like a matrix, a rectangular scheme whose elements are indexed, but one discrete index is replaced by a continuous index. Likewise, a "cmatrix", is continuous in both indices. As an example of a cmatrix, one can think of the kernel of an [integral operator](wikipedia://en/2649421).

These factorizations are based on early work by (Fredholm 1903), (Hilbert 1904), and (Schmidt 1907). For an account and a translation to English of the seminal papers, see (Stewart 2011).
