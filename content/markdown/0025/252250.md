# Orbit (dynamics)

::: {#o1 .subject cue=lead name="Orbit"}

In [mathematics](wikipedia://en/18831), specifically in the study of [dynamical systems](wikipedia://en/9087), an **orbit** is a collection of points related by the [evolution function](https://en.wikipedia.org/wiki/Evolution_function) of the dynamical system. It can be understood as the subset of [phase space](https://en.wikipedia.org/wiki/Phase_space_%28dynamical_system%29) covered by the trajectory of the dynamical system under a particular set of [initial conditions](wikipedia://en/1186804), as the system evolves. As a phase space trajectory is uniquely determined for any given set of phase space coordinates, it is not possible for different orbits to intersect in phase space, therefore the set of all orbits of a dynamical system is a [partition](https://en.wikipedia.org/wiki/Partition_%28set_theory%29) of the phase space. Understanding the properties of orbits by using [topological methods](wikipedia://en/16379713) is one of the objectives of the modern theory of dynamical systems.

:::

For [discrete-time dynamical systems](https://en.wikipedia.org/wiki/Discrete-time_dynamical_system), the orbits are [sequences](wikipedia://en/27838); for [real dynamical systems](https://en.wikipedia.org/wiki/Real_dynamical_system), the orbits are [curves](wikipedia://en/89246); and for [holomorphic](wikipedia://en/14110) dynamical systems, the orbits are [Riemann surfaces](wikipedia://en/173181).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Simple Harmonic Motion Orbit.gif.* Diagram showing the periodic orbit of a mass-spring system in [simple harmonic motion](wikipedia://en/28437). (Here the velocity and position axes have been reversed from the standard convention in order to align the two diagrams)

Given a dynamical system (*T*, *M*, Φ) with *T* a [group](wikipedia://en/19447), *M* a [set](wikipedia://en/26691) and Φ the evolution function

$\Phi: U \to M$ where $U \subset T \times M$ with $\Phi(0,x)=x$

we define

$$I(x):=\{t \in T : (t,x) \in U \},$$

then the set

$$\gamma_x:=\{\Phi(t,x) : t \in I(x)\} \subset M$$

is called the **orbit** through *x*. An orbit which consists of a single point is called **constant orbit**. A non-constant orbit is called **closed** or **periodic** if there exists a $t\neq 0$ in $I(x)$ such that

$$\Phi(t, x) = x.$$

::: {#o5 .pointer-item cue=pointer name="Positive semi-orbit"}

### Real dynamical system {#Real_dynamical_system}

Given a real dynamical system (*R*, *M*, Φ), *I*(*x*) is an open interval in the [real numbers](wikipedia://en/20646438), that is $I(x) = (t_x^- , t_x^+)$. For any *x* in *M*

$$\gamma_{x}^{+} := \{\Phi(t,x) : t \in (0,t_x^+)\}$$

is called **positive semi-orbit** through *x* and

$$\gamma_{x}^{-} := \{\Phi(t,x) : t \in (t_x^-,0)\}$$

is called **negative semi-orbit** through *x*.

:::

### Discrete time dynamical system {#Discrete_time_dynamical_system}

For a discrete time dynamical system with a time-invariant evolution function $f$:

The **forward** orbit of x is the set :

$$\gamma_{x}^{+} \ \overset{\underset{\mathrm{def}}{}}{=} \ \{ f^{t}(x) : t \ge 0 \}$$

If the function is invertible, the **backward** orbit of x is the set :

$$\gamma_{x}^{-} \ \overset{\underset{\mathrm{def}}{}}{=} \ \{f^{t}(x) : t \le 0 \}$$

and **orbit** of x is the set :

$$\gamma_{x} \ \overset{\underset{\mathrm{def}}{}}{=} \ \gamma_{x}^{-} \cup \gamma_{x}^{+}$$

where :

- $f$ is the evolution function $f : X \to X$
- set $X$ is the **dynamical space**,
- $t$ is number of iteration, which is [natural number](wikipedia://en/21474) and $t \in T$
- $x$ is initial state of system and $x \in X$

### General dynamical system {#General_dynamical_system}

For a general dynamical system, especially in homogeneous dynamics, when one has a "nice" group $G$ acting on a probability space $X$ in a measure-preserving way, an orbit $G.x \subset X$ will be called periodic (or equivalently, closed) if the stabilizer $Stab_{G}(x)$ is a lattice inside $G$.

In addition, a related term is a bounded orbit, when the set $G.x$ is pre-compact inside $X$.

The classification of orbits can lead to interesting questions with relations to other mathematical areas, for example the Oppenheim conjecture (proved by Margulis) and the Littlewood conjecture (partially proved by Lindenstrauss) are dealing with the question whether every bounded orbit of some natural action on the homogeneous space $SL_{3}(\mathbb{R})\backslash SL_{3}(\mathbb{Z})$ is indeed periodic one, this observation is due to Raghunathan and in different language due to Cassels and Swinnerton-Dyer . Such questions are intimately related to deep measure-classification theorems.

### Notes {#Notes}

It is often the case that the evolution function can be understood to compose the elements of a [group](wikipedia://en/19447), in which case the [group-theoretic orbits](https://en.wikipedia.org/wiki/Orbit_%28group_theory%29) of the [group action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) are the same thing as the dynamical orbits.

## Stability of orbits {#Stability_of_orbits}

A basic classification of orbits is

- constant orbits or fixed points
- periodic orbits
- non-constant and non-periodic orbits

An orbit can fail to be closed in two ways. It could be an **asymptotically periodic** orbit if it [converges](wikipedia://en/26551602) to a periodic orbit. Such orbits are not closed because they never truly repeat, but they become arbitrarily close to a repeating orbit. An orbit can also be [chaotic](wikipedia://en/6295). These orbits come arbitrarily close to the initial point, but fail to ever converge to a periodic orbit. They exhibit [sensitive dependence on initial conditions](https://en.wikipedia.org/wiki/Sensitive_dependence_on_initial_conditions), meaning that small differences in the initial value will cause large differences in future points of the orbit.

There are other properties of orbits that allow for different classifications. An orbit can be [hyperbolic](wikipedia://en/3948604) if nearby points approach or diverge from the orbit exponentially fast.
