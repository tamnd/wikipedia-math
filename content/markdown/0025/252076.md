# Gδ set

::: {#o1 .subject cue=lead name="Gδ set"}

In [general topology](wikipedia://en/178649), a **G<sub>δ</sub> set** is a [subset](wikipedia://en/27631) of a [topological space](wikipedia://en/30450) that is a [countable](https://en.wikipedia.org/wiki/Countable) [intersection](wikipedia://en/23476429) of [open sets](wikipedia://en/39358). The notation originated from the [German](https://en.wikipedia.org/wiki/German_language) nouns de open set and de intersection.[^o2] Historically G<sub>δ</sub> sets were also called **inner limiting sets**,[^o3] but that terminology is not in use anymore. G<sub>δ</sub> sets, and their dual, [F<sub>σ</sub> sets](wikipedia://en/396575), are the second level of the [Borel hierarchy](wikipedia://en/5539282).

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

In a topological space a **G<sub>δ</sub> set** is a [countable](https://en.wikipedia.org/wiki/Countable) [intersection](wikipedia://en/23476429) of [open sets](wikipedia://en/39358). The G<sub>δ</sub> sets are exactly the level **Π**${}^{0}_{2}$ sets of the [Borel hierarchy](wikipedia://en/5539282).

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any open set is trivially a G<sub>δ</sub> set.
- The [irrational numbers](https://en.wikipedia.org/wiki/Irrational_numbers) are a G<sub>δ</sub> set in the real numbers $\mathbb{R}$. They can be written as the countable intersection of the open sets $\{ q \}^{c}$ (the superscript denoting the [complement](wikipedia://en/54347)) where $q$ is [rational](wikipedia://en/19727024).
- The set of rational numbers $\mathbb{Q}$ is not a G<sub>δ</sub> set in $\mathbb{R}$. If $\mathbb{Q}$ were the intersection of open sets $A_n$ each $A_n$ would be [dense](wikipedia://en/23523594) in $\mathbb{R}$ because $\mathbb{Q}$ is dense in $\mathbb{R}$. However, the construction above gave the irrational numbers as a countable intersection of open dense subsets. Taking the intersection of both of these sets gives the [empty set](wikipedia://en/9566) as a countable intersection of open dense sets in $\mathbb{R}$, a violation of the [Baire category theorem](wikipedia://en/55227).
- The [continuity set](wikipedia://en/23251647#Continuity_set_of_a_function) of any real valued function is a G<sub>δ</sub> subset of its domain (see the "Properties" section for a more general statement).
- The zero-set of a [derivative](https://en.wikipedia.org/wiki/Derivative_%28mathematics%29) of an everywhere differentiable real-valued function on $\mathbb{R}$ is a G<sub>δ</sub> set; it can be a dense set with empty interior, as shown by [Pompeiu's construction](wikipedia://en/26580514#Pompeiu's_construction).
- The set of functions in $C([0,1])$ not differentiable at any point within 0, 1 contains a dense G<sub>δ</sub> subset of the metric space $C([0,1])$. (See Weierstrass function.)

:::

## Properties {#Properties}

The notion of G<sub>δ</sub> sets in [metric](wikipedia://en/20018) (and [topological](wikipedia://en/30450)) spaces is related to the notion of [completeness](wikipedia://en/7832) of the metric space as well as to the [Baire category theorem](wikipedia://en/55227). See the result about completely metrizable spaces in the list of properties below. G<sub>δ</sub> sets and their complements are also of importance in [real analysis](wikipedia://en/26478), especially [measure theory](https://en.wikipedia.org/wiki/Measure_theory).

::: {#o11 .statement kind=statement/fact cue=heading name="Basic properties"}

### Basic properties {#Basic_properties}

- The [complement](wikipedia://en/54347) of a G<sub>δ</sub> set is an [F<sub>σ</sub>](wikipedia://en/396575) set, and vice versa.
- The intersection of countably many G<sub>δ</sub> sets is a G<sub>δ</sub> set.
- The union of finitely many G<sub>δ</sub> sets is a G<sub>δ</sub> set.
- A countable union of G<sub>δ</sub> sets (which would be called a G<sub>δσ</sub> set) is not a G<sub>δ</sub> set in general. For example, the rational numbers $\mathbb{Q}$ do not form a G<sub>δ</sub> set in $\mathbb{R}$.
- In a topological space, the [zero set](https://en.wikipedia.org/wiki/Zero_set) of every real valued continuous function $f$ is a (closed) G<sub>δ</sub> set, since $f^{-1}(0)$ is the intersection of the open sets $\{x \in X : -1/n < f(x) < 1/n\}$, $(n = 1, 2, \ldots)$.
- In a [metrizable](https://en.wikipedia.org/wiki/Metrizable) space, every [closed set](wikipedia://en/47279) is a G<sub>δ</sub> set and, dually, every open set is an F<sub>σ</sub> set.[^o12] Indeed, a closed set $F \subseteq X$ is the zero set of the continuous function $f(x) = d(x, F)$, where $d$ indicates the [distance from a point to a set](https://en.wikipedia.org/wiki/Distance_to_a_set). The same holds in [pseudometrizable](https://en.wikipedia.org/wiki/Pseudometrizable) spaces.
- In a [first countable](https://en.wikipedia.org/wiki/First_countable) [T<sub>1</sub> space](wikipedia://en/148721), every [singleton](wikipedia://en/381798) is a G<sub>δ</sub> set.[^n1]
- A [subspace](https://en.wikipedia.org/wiki/Topological_subspace) of a [completely metrizable](https://en.wikipedia.org/wiki/Completely_metrizable) space $X$ is itself completely metrizable if and only if it is a G<sub>δ</sub> set in $X$.[^o14][^o15]
- A subspace of a [Polish space](wikipedia://en/396622) $X$ is itself Polish if and only if it is a G<sub>δ</sub> set in $X$. This follows from the previous result about completely metrizable subspaces and the fact that every subspace of a separable metric space is separable.
- A topological space $X$ is Polish if and only if it is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to a G<sub>δ</sub> subset of a [compact](wikipedia://en/6042) [metric space](wikipedia://en/20018).[^o16][^o17]
- A topological space $X$ is perfectly normal if and only if it is both normal and has each closed set of $X$ being G<sub>δ.</sub>[^o18]

:::

### Continuity set of real valued functions {#Continuity_set_of_real_valued_functions}

The set of points where a function $f$ from a topological space to a metric space is [continuous](wikipedia://en/6122) is a G<sub>δ</sub> set. This is because continuity at a point $p$ can be defined by a $\Pi^0_2$ formula, namely: For all positive integers $n,$ there is an open set $U$ containing $p$ such that $d(f(x), f(y)) < 1/n$ for all $x, y$ in $U$. If a value of $n$ is fixed, the set of $p$ for which there is such a corresponding open $U$ is itself an open set (being a union of open sets), and the [universal quantifier](https://en.wikipedia.org/wiki/Universal_quantifier) on $n$ corresponds to the (countable) intersection of these sets. As a consequence, while it is possible for the irrationals to be the set of continuity points of a function (see the [popcorn function](https://en.wikipedia.org/wiki/Popcorn_function)), it is impossible to construct a function that is continuous only on the rational numbers.

In the real line, the converse holds as well; for any G<sub>δ</sub> subset $A$ of the real line, there is a function $f : \mathbb{R} \to \mathbb{R}$ that is continuous exactly at the points in $A$.[^o20]

:::

## G<sub>δ</sub> space {#Gδ_space}

A **[G<sub>δ</sub> space](wikipedia://en/17993945)**[^o22] is a topological space in which every [closed set](wikipedia://en/47279) is a G<sub>δ</sub> set.[^n2] A [normal space](wikipedia://en/48629) that is also a G<sub>δ</sub> space is called [perfectly normal](https://en.wikipedia.org/wiki/Perfectly_normal_space). For example, every metrizable space is perfectly normal.

- [*P*-space](wikipedia://en/41775284), any space having the property that every G<sub>δ</sub> set is open
