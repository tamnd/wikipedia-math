# Implicit function

Differential

::: {#o1 .subject cue=lead name="Implicit function"}

In [mathematics](wikipedia://en/18831), an **implicit equation** is a [relation](wikipedia://en/22517558) of the form $R(x_1, \dots, x_n) = 0,$ where $R$ is a [function](wikipedia://en/185427) of several variables (often a [polynomial](wikipedia://en/23000)). For example, the implicit equation of the [unit circle](wikipedia://en/27072071) is $x^2 + y^2 - 1 = 0.$

:::

An **implicit function** is a [function](wikipedia://en/185427) that is defined by an implicit equation, that relates one of the variables, considered as the [value](wikipedia://en/4095147) of the function, with the others considered as the [arguments](wikipedia://en/32842052).[^o2] For example, the equation $x^2 + y^2 - 1 = 0$ of the [unit circle](wikipedia://en/27072071) defines $y$ as an implicit function of $x$, $y = \sqrt{1-x^2}$, assuming $-1 \le x \le 1$ and $y$ is restricted to nonnegative values. Some equations do not admit an [explicit solution](https://en.wikipedia.org/wiki/Explicit_solution).

The [implicit function theorem](wikipedia://en/581005) provides conditions under which some kinds of implicit equations define implicit functions, namely those that are obtained by equating to zero [multivariable functions](https://en.wikipedia.org/wiki/Multivariable_function) that are [continuously differentiable](https://en.wikipedia.org/wiki/Continuously_differentiable).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### Inverse functions {#Inverse_functions}

A common type of implicit function is an [inverse function](wikipedia://en/14907). Not all functions have a unique inverse function. If $g$ is a function of $x$ that has a unique inverse, then the inverse function of $g$, called $g^{-1}$, is the unique function giving a [solution](https://en.wikipedia.org/wiki/Solution_%28mathematics%29) of the equation

$$y=g(x)$$

for $x$ in terms of $y$. This solution can then be written as

$$x = g^{-1}(y) \,.$$

Defining $g^{-1}$ as the inverse of $g$ is an implicit definition. For some functions $g$, $g^{-1}(y)$ can be written out explicitly as a [closed-form expression](wikipedia://en/585143) — for instance, if $g(x) = 2x - 1$, then $g^{-1}(y) = \tfrac{1}{2}(y + 1)$. However, this is often not possible, or only by introducing a new notation (as in the [product log](https://en.wikipedia.org/wiki/Product_log) example below).

Intuitively, an inverse function is obtained from $g$ by interchanging the roles of the dependent and independent variables.

::: {#o6 .example cue=inline-head name="Example"}

**Example:** The [product log](https://en.wikipedia.org/wiki/Product_log) is an implicit function giving the solution for $x$ of the equation $y - xe^{x} = 0$.

:::

### Algebraic functions {#Algebraic_functions}

An **algebraic function** is a function that satisfies a polynomial equation whose coefficients are themselves polynomials. For example, an algebraic function in one variable $x$ gives a solution for $y$ of an equation

$$a_n(x)y^n+a_{n-1}(x)y^{n-1}+\cdots+a_0(x)=0 \,,$$

where the coefficients $a_{i}(x)$ are polynomial functions of $x$. This algebraic function can be written as the right side of the solution equation $y = f(x)$. Written like this, $f$ is a [multi-valued](https://en.wikipedia.org/wiki/Multi-valued_function) implicit function.

Algebraic functions play an important role in [mathematical analysis](wikipedia://en/48396) and [algebraic geometry](wikipedia://en/1997). A simple example of an algebraic function is given by the left side of the unit circle equation:

$$x^2+y^2-1=0 \,.$$

Solving for $y$ gives an explicit solution:

$$y=\pm\sqrt{1-x^2} \,.$$

But even without specifying this explicit solution, it is possible to refer to the implicit solution of the unit circle equation as $y = f(x)$, where $f$ is the multi-valued implicit function.

While explicit solutions can be found for equations that are [quadratic](https://en.wikipedia.org/wiki/Quadratic_equations), [cubic](wikipedia://en/180787), and [quartic](wikipedia://en/251591) in $y$, the same is not in general true for [quintic](wikipedia://en/303368) and higher degree equations, such as

$$y^5 + 2y^4 -7y^3 + 3y^2 -6y - x = 0 \,.$$

Nevertheless, one can still refer to the implicit solution $y = f(x)$ involving the multi-valued implicit function $f$.

:::

## Caveats {#Caveats}

Not every equation $R(x, y) = 0$ implies a graph of a single-valued function, the circle equation being one prominent example. Another example is an implicit function given by $x - C(y) = 0$ where $C$ is a [cubic polynomial](https://en.wikipedia.org/wiki/Cubic_polynomial) having a "hump" in its graph. Thus, for an implicit function to be a *true* (single-valued) function it might be necessary to use just part of the graph. An implicit function can sometimes be successfully defined as a true function only after "zooming in" on some part of the $x$-axis and "cutting away" some unwanted function branches. Then an equation expressing $y$ as an implicit function of the other variables can be written.

The defining equation $R(x, y) = 0$ can also have other pathologies. For example, the equation $x = 0$ does not imply a function $f(x)$ giving solutions for $y$ at all; it is a vertical line. In order to avoid a problem like this, various constraints are frequently imposed on the allowable sorts of equations or on the [domain](https://en.wikipedia.org/wiki/Function_domain). The [implicit function theorem](wikipedia://en/581005) provides a uniform way of handling these sorts of pathologies.

## Implicit function theorem {#Implicit_function_theorem}

*Image: Implicit circle.svg.* The unit circle can be defined implicitly as the set of points $(x, y)$ satisfying $x^{2} + y^{2} = 1$. Around point $A$, $y$ can be expressed as an implicit function $y(x)$. (Unlike in many cases, here this function can be made explicit as $g_{1}(x) = \sqrt{1 - x^{2}}$.) No such function exists around point $B$, where the [tangent space](wikipedia://en/30807) is vertical.

Let $R(x, y)$ be a [differentiable function](wikipedia://en/330206) of two variables, and $(a, b)$ be a pair of [real numbers](wikipedia://en/20646438) such that $R(a, b) = 0$. If $\tfrac{\partial R}{\partial y} \ne 0$, then $R(x, y) = 0$ defines an implicit function that is differentiable in some small enough [neighbourhood](wikipedia://en/1529485) of *a*, *b*; in other words, there is a differentiable function $f$ that is defined and differentiable in some neighbourhood of $a$, such that $R(x, f(x)) = 0$ for $x$ in this neighbourhood.

The condition $\tfrac{\partial R}{\partial y} \ne 0$ means that $(a, b)$ is a [regular point](wikipedia://en/4230456) of the [implicit curve](wikipedia://en/11286809) of implicit equation $R(x, y) = 0$ where the [tangent](wikipedia://en/31482) is not vertical.

In a less technical language, implicit functions exist and can be differentiated, if the curve has a non-vertical tangent.[^o13]

:::

## In algebraic geometry {#In_algebraic_geometry}

Consider a [relation](wikipedia://en/22517558) of the form $R(x_{1}, \ldots, x_{n}) = 0$, where $R$ is a multivariable polynomial. The set of the values of the variables that satisfy this relation is called an [implicit curve](wikipedia://en/11286809) if $n = 2$ and an **[implicit surface](wikipedia://en/1527655)** if $n = 3$. The implicit equations are the basis of [algebraic geometry](wikipedia://en/1997), whose basic subjects of study are the simultaneous solutions of several implicit equations whose left-hand sides are polynomials. These sets of simultaneous solutions are called [affine algebraic sets](https://en.wikipedia.org/wiki/Affine_algebraic_set).

## In differential equations {#In_differential_equations}

The solutions of differential equations generally appear expressed by an implicit function.[^o16]

## Applications in economics {#Applications_in_economics}

### Marginal rate of substitution {#Marginal_rate_of_substitution}

In [economics](https://en.wikipedia.org/wiki/Economics), when the level set $R(x, y) = 0$ is an [indifference curve](https://en.wikipedia.org/wiki/Indifference_curve) for the quantities $x$ and $y$ consumed of two goods, the absolute value of the implicit derivative $\tfrac{dy}{dx}$ is interpreted as the [marginal rate of substitution](https://en.wikipedia.org/wiki/Marginal_rate_of_substitution) of the two goods: how much more of $y$ one must receive in order to be indifferent to a loss of one unit of $x$.

### Marginal rate of technical substitution {#Marginal_rate_of_technical_substitution}

Similarly, sometimes the level set $R(L, K)$ is an [isoquant](https://en.wikipedia.org/wiki/Isoquant) showing various combinations of utilized quantities $L$ of labor and $K$ of [physical capital](https://en.wikipedia.org/wiki/Physical_capital) each of which would result in the production of the same given quantity of output of some good. In this case the absolute value of the implicit derivative $\tfrac{dK}{dL}$ is interpreted as the [marginal rate of technical substitution](https://en.wikipedia.org/wiki/Marginal_rate_of_technical_substitution) between the two factors of production: how much more capital the firm must use to produce the same amount of output with one less unit of labor.

### Optimization {#Optimization}

Often in [economic theory](https://en.wikipedia.org/wiki/Economic_theory), some function such as a [utility function](https://en.wikipedia.org/wiki/Utility_function) or a [profit](https://en.wikipedia.org/wiki/Profit_%28economics%29) function is to be maximized with respect to a choice vector $x$ even though the objective function has not been restricted to any specific functional form. The [implicit function theorem](wikipedia://en/581005) guarantees that the [first-order conditions](https://en.wikipedia.org/wiki/First-order_condition) of the optimization define an implicit function for each element of the optimal vector $x*$ of the choice vector $x$. When profit is being maximized, typically the resulting implicit functions are the [labor demand](https://en.wikipedia.org/wiki/Labor_demand) function and the [supply functions](https://en.wikipedia.org/wiki/Supply_function) of various goods. When utility is being maximized, typically the resulting implicit functions are the [labor supply](https://en.wikipedia.org/wiki/Labor_supply) function and the [demand functions](https://en.wikipedia.org/wiki/Demand_function) for various goods.

Moreover, the influence of the problem's [parameters](wikipedia://en/25065#Mathematical_functions) on $x*$ — the partial derivatives of the implicit function — can be expressed as [total derivatives](https://en.wikipedia.org/wiki/Total_derivative) of the system of first-order conditions found using [total differentiation](wikipedia://en/23997203#Differentials_in_several_variables).
