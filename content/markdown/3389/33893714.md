# Esscher transform

::: {#o1 .subject cue=lead name="Esscher transform"}

In [actuarial science](wikipedia://en/189373), the **Esscher transform** (Gerber Shiu 1994) is a transform that takes a [probability density](wikipedia://en/43487) *f*(*x*) and transforms it to a new probability density *f*(*x*; *h*) with a parameter *h*. It was introduced by F. Esscher in 1932 (Esscher 1932).

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *f*(*x*) be a probability density. Its Esscher transform is defined as

$$f(x;h)=\frac{e^{hx}f(x)}{\int_{-\infty}^\infty e^{hx} f(x) \, dx}.\,$$

More generally, if *μ* is a [probability measure](wikipedia://en/45437), the Esscher transform of *μ* is a new probability measure *E<sub>h</sub>*(*μ*) which has [density](https://en.wikipedia.org/wiki/Radon–Nikodym_derivative)

$$\frac{e^{hx}}{\int_{-\infty}^\infty e^{hx} \, d\mu(x)}$$

with respect to *μ*.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

**Combination**

The Esscher transform of an Esscher transform is again an Esscher transform: *E<sub>h</sub>*<sub><sub>1</sub></sub> *E<sub>h</sub>*<sub><sub>2</sub></sub> = *E<sub>h</sub>*<sub><sub>1</sub> + *h*<sub>2</sub></sub>.

**Inverse**

The inverse of the Esscher transform is the Esscher transform with negative parameter: *E*${}^{-1}_{h}$ = *E*<sub>−*h*</sub>

**Mean move**

The effect of the Esscher transform on the [normal distribution](wikipedia://en/21462) is moving the mean:

$$E_h(\mathcal{N}(\mu,\,\sigma^2)) =\mathcal{N}(\mu + h\sigma^2,\,\sigma^2).\,$$

:::

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

::: {#o10 .table cue=table}

| Distribution | Esscher transform |
|---|---|
| [Bernoulli](wikipedia://en/199189) Bernoulli(*p*) | $k\mapsto\frac{e^{hk}p^k(1-p)^{1-k}}{1-p+pe^h} \text{ for } k = 0,1.$ |
| [Binomial](wikipedia://en/3876) B(*n*, *p*) | $k\mapsto\frac{{n\choose k}e^{hk}p^k(1-p)^{n-k}}{(1-p+pe^h)^n} \text{ for } k = 0,1,\ldots,n.$ |
| [Normal](wikipedia://en/21462) *N*(*μ*, *σ*<sup>2</sup>) | $x\mapsto\frac{1}{\sqrt{2 \pi \sigma^2}}e^{-\frac{(x-\mu-\sigma^2 h)^2}{2\sigma ^2}} \text{ for } x \text{ real.}$ |
| [Poisson](wikipedia://en/23009144) Pois(*λ*) | $k\mapsto\frac{e^{hk-\lambda e^h}\lambda^k}{k!} \text{ for } k=0,1,2,\ldots\,.$ |

:::

:::

::: {#o16 .statement cue=named-heading name="Esscher principle"}

## Esscher principle {#Esscher_principle}

The *Esscher principle* is an [insurance premium principle](https://en.wikipedia.org/wiki/Insurance_premium_principle) used in actuarial sciences that derives from the Esscher transform. It is given by $\pi[X,h]=E[Xe^{hX}]/E[e^{hX}]$, where $h$ is a strictly positive parameter. This premium is the [net premium](https://en.wikipedia.org/wiki/Net_premium) for a risk $Y=Xe^{hX}/m_X(h)$, where $m_X(h)$ denotes the [moment generating function](wikipedia://en/194634). This risk measure does not respect the positive homogeneity property of [coherent risk measure](wikipedia://en/5235067) for $h>0$.
