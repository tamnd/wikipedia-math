# Baer–Suzuki theorem

::: {#o1 .subject cue=lead name="Baer–Suzuki theorem"}

In [mathematics](wikipedia://en/18831), namely [finite group theory](wikipedia://en/41890#Finite_group_theory), the **Baer–Suzuki theorem**, [proved](wikipedia://en/82285) by (Baer 1957) and (Suzuki 1965), states that if any two elements of a [conjugacy class](wikipedia://en/49176) *C* of a finite [group](wikipedia://en/19447) generate a [nilpotent](wikipedia://en/144569) [subgroup](wikipedia://en/28011), then all elements of the conjugacy class *C* are contained in a nilpotent subgroup. (Alperin Lyons 1971) gave a short elementary proof.

:::
