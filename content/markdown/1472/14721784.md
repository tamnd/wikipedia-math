# Coupon collector's problem

::: {#o1 .subject cue=lead name="Coupon collector's problem"}

*Image: Coupon collector problem.svg.* Graph of number of coupons, $n$ vs the expected number of trials (i.e., time) needed to collect them all $E(T)$

In [probability theory](wikipedia://en/23542), the **coupon collector's problem** refers to mathematical analysis of "collect all [coupons](https://en.wikipedia.org/wiki/Coupon) and win" contests. It asks the following question: if each box of a given product (e.g., breakfast cereals) contains a coupon, and there are $n$ different types of coupons, what is the probability that more than $t$ boxes need to be bought to collect all $n$ coupons? An alternative statement is: given $n$ coupons, how many coupons do you [expect](wikipedia://en/9653) you need to draw with [replacement](wikipedia://en/160361#Replacement_of_selected_units) before having drawn each coupon at least once? The mathematical analysis of the problem reveals that the [expected number](wikipedia://en/9653) of trials needed grows as $\Theta(n\log(n))$. For example, when $n = 50$ it takes about 225[^o2] trials on average to collect all 50 coupons. Sometimes the problem is instead expressed in terms of an $n$-sided die.

:::

## Solution {#Solution}

### Calculating the expectation {#Calculating_the_expectation}

Let time $T$ be the number of draws needed to collect all $n$ coupons, and let $t_{i}$ be the time to collect the $i$-th coupon after $i - 1$ coupons have been collected. Then $T=t_1 + \cdots + t_n$. Think of $T$ and $t_{i}$ as [random variables](wikipedia://en/25685). Observe that the probability of collecting the $i$-th new coupon is $p_i = \frac{n - (i - 1)}{n} = \frac{n - i + 1}n$. Therefore, $t_i$ has [geometric distribution](wikipedia://en/45922) with expectation $\frac{1}{p_i} = \frac n{n - i + 1}$. By the [linearity of expectations](wikipedia://en/9653#Properties) we have:

$$\begin{aligned} \operatorname{E}(T) & {}= \operatorname{E}(t_1 + t_2 + \cdots + t_n) \\ & {}= \operatorname{E}(t_1) + \operatorname{E}(t_2) + \cdots + \operatorname{E}(t_n) \\ & {}= \frac{1}{p_1} + \frac{1}{p_2} + \cdots + \frac{1}{p_n} \\ & {}= \frac{n}{n} + \frac{n}{n-1} + \cdots + \frac{n}{1} \\ & {}= n \cdot \left(\frac{1}{1} + \frac{1}{2} + \cdots + \frac{1}{n}\right) \\ & {}= n \cdot H_n. \end{aligned}$$

Here $H_{n}$ is the $n$-th [harmonic number](wikipedia://en/214729). Using the [asymptotics](https://en.wikipedia.org/wiki/Asymptotics) of the harmonic numbers, we obtain:

$$\operatorname{E}(T) = n \cdot H_n = n \log n + \gamma n + \frac{1}{2} + O(1/n),$$

where $\gamma \approx 0.5772156649$ is the [Euler–Mascheroni constant](https://en.wikipedia.org/wiki/Euler–Mascheroni_constant).

Using the [Markov inequality](https://en.wikipedia.org/wiki/Markov_inequality) to bound the desired probability:

$$\operatorname{P}(T \geq cn H_n) \le \frac{1}{c}.$$

The above can be modified slightly to handle the case when we've already collected some of the coupons. Let $k$ be the number of coupons already collected, then:

$$\begin{aligned} \operatorname{E}(T_k) & {}= \operatorname{E}(t_{k+1} + t_{k+2} + \cdots + t_n) \\ & {}= n \cdot \left(\frac{1}{1} + \frac{1}{2} + \cdots + \frac{1}{n-k}\right) \\ & {}= n \cdot H_{n-k} \end{aligned}$$

And when $k=0$ then we get the original result.

### Calculating the variance {#Calculating_the_variance}

Using the independence of random variables $t_{i}$, we obtain:

$$\begin{aligned} \operatorname{Var}(T)& {}= \operatorname{Var}(t_1 + \cdots + t_n) \\ & {} = \operatorname{Var}(t_1) + \operatorname{Var}(t_2) + \cdots + \operatorname{Var}(t_n) \\ & {} = \frac{1-p_1}{p_1^2} + \frac{1-p_2}{p_2^2} + \cdots + \frac{1-p_n}{p_n^2} \\ & {} = \left(\frac{n^2}{n^2} + \frac{n^2}{(n-1)^2} + \cdots + \frac{n^2}{1^2}\right) - \left(\frac{n}{n} + \frac{n}{n-1} + \cdots + \frac{n}{1}\right) \\ & {} = n^2 \cdot \left(\frac{1}{1^2} + \frac{1}{2^2} + \cdots + \frac{1}{n^2} \right) - n \cdot \left(\frac{1}{1} + \frac{1}{2} + \cdots + \frac{1}{n} \right)\\ & {} < \frac{\pi^2}{6} n^2 \end{aligned}$$

since $\frac{\pi^2}6=\frac{1}{1^2}+\frac{1}{2^2}+\cdots+\frac{1}{n^2}+\cdots$ (see [Basel problem](wikipedia://en/490303)).

Bound the desired probability using the [Chebyshev inequality](https://en.wikipedia.org/wiki/Chebyshev_inequality):

$$\operatorname{P}\left(|T- n H_n| \geq cn\right) \le \frac{\pi^2}{6c^2}.$$

## Stirling numbers {#Stirling_numbers}

Let the random variable $X$ be the number of dice rolls performed before all faces have occurred.

The subpower is defined $a^{\{b\}}=a!\left\{{b\atop a}\right\}$, where $\left\{{b\atop a}\right\}$ is a [Stirling number of the second kind](https://en.wikipedia.org/wiki/Stirling_number_of_the_second_kind).[^o7]

Sequences of $k$ die rolls are functions $k\rightarrow n$ counted by $n^k$, while surjections (that land on each face at least once) are counted by $n^{\{k\}}$, so the probability that all faces were landed on within the $k$-th throw is $P(X\le k)=\frac{n^{\{k\}}}{n^k}$. By the recurrence relation of the Stirling numbers, the probability that exactly $k$ rolls are needed is $P(X=k)=\frac{n^{\{k\}}}{n^k}-\frac{n^{\{k-1\}}}{n^{k-1}}=\frac{(n-1)^{\{k-1\}}}{n^{k-1}}$

### Generating functions {#Generating_functions}

Replacing $z$ with $1+z$ in the [probability generating function](wikipedia://en/236841) produces the o.g.f. for $E\left[{X\choose k}\right]$. Using the partial fraction decomposition ${\frac1x-1\choose n}^{-1}=\sum_{k=0}^n{n\choose k}\frac{(-1)^{n-k}}{1-kx}$, we can take the expansion

$$\begin{aligned}&{\frac n{x+1}\choose n}^{-1}\\ =&\sum_{i=0}^n{n\choose i}\frac{(-1)^{n-i}}{1-i(1-\frac n{x+1+n})}\\ =&\sum_{i=0}^n{n\choose i}(-1)^{n-i}\left(\frac{1+n}{1+n-i}+in\sum_{k=1}^\infty\frac{(i-1)^{k-1}}{(n+1-i)^{k+1}}x^k\right)\end{aligned}$$

revealing that for $k>0$,

$$E\left[{X\choose k}\right]=n\sum_{i=0}^n{n\choose i}(-1)^{n-i}i\frac{(i-1)^{k-1}}{(n+1-i)^{k+1}}$$

Given an o.g.f. $f$, since $\left(\frac x{1-x}\right)^i=\sum_{n=0}^\infty{k-1\choose i-1}x^k$, a variation of the [binomial transform](wikipedia://en/3877474) is $[x^k]f\left(\frac x{1+x}\right)=\sum_{i=0}^k{k-1\choose i-1}(-1)^{k-i}[x^i]f(x)$. (Specifically, if ${\frac n{x+1}\choose n}^{-1}=f\left(\frac x{1+x}\right)$, $f(x)={n-nx\choose n}^{-1}$.)

Rewriting the binomial coefficient via the [gamma function](wikipedia://en/12316) and expanding as the $\exp$ of the [polygamma](wikipedia://en/406932) series (in terms of [generalised harmonic numbers](https://en.wikipedia.org/wiki/Generalized_harmonic_number)), we find $\left[\frac{x^i}{i!}\right]{n-x\choose n}^{-1}=\sum_{P\in\mathrm{perms}(i)}\prod_{c\in P}H^{(|c|)}_n$, so

$$E\left[{X\choose k}\right]=\sum_{i=0}^k{k-1\choose i-1}(-1)^{k-i}\frac{n^i}{i!}\sum_{P\in\mathrm{perms}(i)}\prod_{c\in P}H^{(|c|)}_n$$

which can also be written with the [falling factorial](https://en.wikipedia.org/wiki/Falling_factorial) and [Lah numbers](https://en.wikipedia.org/wiki/Lah_numbers) as

$$E[x^\underline k]=\sum_{i=0}^kL(k,i)(-1)^{k-i}n^i\sum_{P\in\mathrm{perms}(i)}\prod_{c\in P}H^{(|c|)}_n$$

The [raw moments](https://en.wikipedia.org/wiki/Raw_moments) of the distribution can be obtained from the falling moments via a [Stirling transform](wikipedia://en/1782555); due to the identity $\left\{{K\atop i}\right\}(-1)^K=\sum_{k=0}^K\left\{{K\atop k}\right\}L(k,i)(-1)^k$, this provides

$$E[x^k]=\sum_{i=0}^k\left\{{k\atop i}\right\}(-1)^{k-i}n^i\!\!\sum_{P\in\mathrm{perms}(i)}\prod_{c\in P}H^{(|c|)}_n$$

## Tail estimates {#Tail_estimates}

A stronger tail estimate for the upper tail can be obtained as follows. Let ${Z}_i^r$ denote the event that the $i$-th coupon was not picked in the first $r$ trials. Then

$$\begin{aligned} P\left [ {Z}_i^r \right ] = \left(1-\frac{1}{n}\right)^r \le e^{-r / n}. \end{aligned}$$

Thus, for $r = \beta n \log n$, we have $P\left [ {Z}_i^r \right ] \le e^{(-\beta n \log n ) / n} = n^{-\beta}$. Via a union bound over the $n$ coupons, we obtain

$$\begin{aligned} P\left [ T > \beta n \log n \right ] = P \left [ \bigcup_i {Z}_i^{\beta n \log n} \right ] \le n \cdot P [ {Z}_1^{\beta n \log n} ] \le n^{-\beta + 1}. \end{aligned}$$

## Extensions and generalizations {#Extensions_and_generalizations}

- [Pierre-Simon Laplace](wikipedia://en/344783), but also [Paul Erdős](wikipedia://en/601284) and [Alfréd Rényi](wikipedia://en/614988), proved the limit theorem for the distribution of $T$. This result is a further extension of previous bounds. A proof is found in.[^o11]

$\operatorname{P}(T < n\log n + cn) \to e^{-e^{-c}}, \text{ as } n \to \infty.$ which is a [Gumbel distribution](wikipedia://en/270827). A simple proof by martingales is in .[^o12]

.

- [Donald J. Newman](wikipedia://en/10419510) and [Lawrence Shepp](https://en.wikipedia.org/wiki/Lawrence_Shepp) gave a generalization of the coupon collector's problem when $m$ copies of each coupon need to be collected. Let $T_{m}$ be the first time $m$ copies of each coupon are collected. They showed that the expectation in this case satisfies:

$$\operatorname{E}(T_m) = n \log n + (m-1) n \log\log n + O(n), \text{ as } n \to \infty.$$

Here $m$ is fixed. When $m = 1$ we get the earlier formula for the expectation.

- Common generalization, also due to Erdős and Rényi:

$$\operatorname{P}\left(T_m < n\log n + (m-1) n \log\log n + cn\right) \to e^{-e^{-c}/(m-1)!}, \text{ as } n \to \infty.$$

- In the general case of a nonuniform probability distribution, according to [Philippe Flajolet](https://en.wikipedia.org/wiki/Philippe_Flajolet) et al.[^o13]

$$\operatorname{E}(T)=\int_0^\infty \left(1 - \prod_{i=1}^m \left(1-e^{-p_it}\right)\right)dt.$$

This is equal to

$$\operatorname{E}(T)=\sum_{q=0}^{m-1} (-1)^{m-1-q} \sum_{|J|=q} \frac{1}{1-P_J},$$

where $m$ denotes the number of coupons to be collected and $P_{J}$ denotes the probability of getting any coupon in the set of coupons $J$.
