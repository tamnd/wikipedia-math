# McNaughton's theorem

::: {#o1 .subject cue=lead name="McNaughton's theorem"}

In [automata theory](wikipedia://en/103356), **McNaughton's theorem** refers to a theorem that asserts that the set of [ω-regular languages](wikipedia://en/3262889) is identical to the set of languages recognizable by deterministic [Muller automata](https://en.wikipedia.org/wiki/Muller_automaton).[^o2] This theorem is proven by supplying an algorithm to construct a deterministic Muller automaton for any ω-regular language and vice versa.

:::

This theorem has many important consequences. Since (non-deterministic) [Büchi automata](wikipedia://en/344912) and ω-regular languages are [equally expressive](wikipedia://en/3262889#Equivalence_to_B.C3.BCchi_automaton), the theorem implies that Büchi automata and deterministic Muller automata are equally expressive. Since complementation of deterministic Muller automata is trivial, the theorem implies that Büchi automata/ω-regular languages are closed under complementation.

## Original statement {#Original_statement}

In McNaughton's original paper, the theorem was stated as:

> "An ω-event is regular if and only if it is finite-state."

In modern terminology, *ω-events* are commonly referred to as [ω-languages](https://en.wikipedia.org/wiki/Ω-language). Following McNaughton's definition, an ω-event is a *finite-state event* if there exists a deterministic Muller automaton that recognizes it.

## Constructing an ω-regular language from a deterministic Muller automaton {#Constructing_an_ω-regular_language_from_a_deterministic_Muller_automaton}

One direction of the theorem can be proven by showing that any given Muller automaton recognizes an ω-regular language.

Suppose *A* = (*Q*,Σ,δ,*q*<sub>0</sub>,**F**) is a deterministic [Muller automaton](https://en.wikipedia.org/wiki/Muller_automaton). The union of finitely many ω-regular languages produces an ω-regular language; therefore it can be assumed *[without loss of generality](wikipedia://en/296000)* that the Muller acceptance condition **F** contains exactly one set of states {*q*<sub>1</sub>, ... ,*q*<sub>*n*</sub>}. Let α be the [regular language](wikipedia://en/25723) whose elements will take *A* from *q*<sub>0</sub> to *q*<sub>1</sub>. For 1≤*i*≤*n*, let β<sub>*i*</sub> be a regular language whose elements take *A* from *q*<sub>*i*</sub> to *q*<sub>(*i* mod *n*)+1</sub> without passing through any state outside of {*q*<sub>1</sub>, ... ,*q*<sub>n</sub>}. It is claimed that **α(β<sub>1</sub> ... β<sub>n</sub>)<sup>ω</sup>** is the ω-regular language recognized by the Muller automaton *A*. It is proved as follows.

Suppose *w* is a word accepted by *A*. Let ρ be the run that led to the acceptance of *w*. For a time instant *t*, let ρ(*t*) be the state visited by ρ at time t. We create an infinite and strictly increasing sequence of time instants *t*<sub>1</sub>, *t*<sub>2</sub>, ... such that only states in {*q*<sub>1</sub>, ... ,*q*<sub>*n*</sub>'} appear after time *t*<sub>1</sub>, and for each *a* and *b*, ρ(*t*<sub>*na*+*b*</sub>) = *q*<sub>*b*</sub>. Such a sequence exists because all and only the states of {*q*<sub>1</sub>, ... ,*q*<sub>*n*</sub>} appear in ρ infinitely often. By the above definitions of α and β's, it can be easily shown that the existence of such a sequence implies that *w* is an element of α(β<sub>1</sub> ... β<sub>*n*</sub>)<sup>ω</sup>.

Conversely, suppose *w* ∈ α(β<sub>1</sub> ... β<sub>*n*</sub>)<sup>ω</sup>. Due to definition of α, there is an initial segment of *w* that is an element of α and thus leads *A* to the state *q*<sub>1</sub>. From there on, the run never assumes a state outside of {*q*<sub>1</sub>, ... ,*q*<sub>*n*</sub>}, due to the definitions of the β's, and all the states in the set are repeated infinitely often. Therefore, *A* accepts the word *w*.

## Constructing a deterministic Muller automaton from a given ω-regular language {#Constructing_a_deterministic_Muller_automaton_from_a_given_ω-regular_language}

The other direction of the theorem can be proven by showing that there exists a deterministic Muller automaton that recognizes a given ω-regular language.

The union of finitely many deterministic Muller automata can be easily constructed; therefore without loss of generality we assume that the given [ω-regular language](https://en.wikipedia.org/wiki/Ω-regular_language) is of the form αβ<sup>ω</sup>. Consider an ω-word *w*=*a*<sub>1</sub>*a*<sub>2</sub>... ∈ αβ<sup>ω</sup>. Let *w*(*i*,*j*) be the finite segment *a*<sub>*i*+1</sub>,...,*a*<sub>*j*-1</sub>*a*<sub>*j*</sub> of *w*. For building a Muller automaton for αβ<sup>ω</sup>, we introduce the following two concepts with respect to *w*.

**Favor**

A time *j* *favors* time *i* if *j* > *i*, *w*(0,*i*) ∈ αβ\*, and *w*(*i*,*j*) ∈ β\*.

**Equivalence**

*E*(*i*,*j*,*k*), or *i* is *equivalent* to *j* as *judged* at time *k*, if *i*,*j* ≤ *k*, *w*(0,i) ∈ αβ\*,*w*(0,j) ∈ αβ\*, and for every word x in Σ\*, *w*(i,k)x ∈ β\* if and only if *w*(j,k)x ∈ β\*. It is easy to note that if E(i,j,k) then for all k \< l, E(i,j,l). In other words, if i and j are ever judged to be equivalent then they will stay equivalent thereafter. And also for the same l, l favors i if and only if l favors j. Let *E(i,j)* if there exists a k such that E(i,j,k).

Let p be the number of states in the minimum [deterministic finite automaton](wikipedia://en/653404) A<sup>β\*</sup> to recognize language β\*. Now we prove two lemmas about the above two concepts.

::: {#o6 .statement kind=statement/lemma cue=inline-head name="Lemma 1"}

**Lemma 1**

*For any time k, among the times i,j \< k such that w(0,i) and w(0,j) ∈ αβ\*, the number of equivalence classes induced by E(i,j,k) is bounded by p. Also the number of equivalence classes induced by E(i,j) is bounded by p.*

**Proof:** The finite automaton A<sup>β\*</sup> is minimum; therefore it does not contain [equivalent states](wikipedia://en/17447039). Let i and j be such that *w*(0,i) and *w*(0,j) ∈ αβ\* and E(i,j,k). Then, words *w*(i,k) and *w*(j,k) will have to take A<sup>β\*</sup> to the same state starting from the initial state. Hence, first part of lemma is true. The second part is proved by contradiction. Let's suppose there are p+1 times i<sub>1</sub>,...,i<sub>p+1</sub> such that no two of them are equivalent. For l > max(i<sub>1</sub>,...,i<sub>p+1</sub>), we would have, for each m and n, not E(i<sub>m</sub>,i<sub>n</sub>,l). Therefore there would be p+1 equivalence classes, as judged at l, contradicting the first part of the lemma.

:::

::: {#o7 .statement kind=statement/lemma cue=inline-head name="Lemma 2"}

**Lemma 2**

*w ∈ αβ<sup>ω</sup> if and only if there exists a time i such that there are infinitely many times equivalent to i and favoring i.*

**Proof:** Let's suppose w ∈ αβ<sup>ω</sup> then there exists a strictly increasing sequence of times i<sub>0</sub>,i<sub>1</sub>,i<sub>2</sub>,... such that w(0,i<sub>0</sub>) ∈ α and w(i<sub>n</sub>,i<sub>n+1</sub>) ∈ β. Therefore, for all n > m, w(i<sub>m</sub>,i<sub>n</sub>) ∈ β\* and i<sub>n</sub> favors i<sub>m</sub>. So, all the i's are members of one of the finitely many equivalence classes (shown in Lemma 1). So, there must be an infinite subset of all i's that belongs to same class. The smallest member of this subset satisfies the right hand side of this lemma.

Conversely, suppose in w, there are infinitely many times that are equivalent to i and favoring i. From those times, we will construct a strictly increasing and infinite sequence of times i<sub>0</sub>,i<sub>1</sub>,i<sub>2</sub>,... such that w(0,i<sub>0</sub>) ∈ αβ\* and w(i<sub>n</sub>,i<sub>n+1</sub>) ∈ β\*. Therefore w would be in αβ<sup>ω</sup>. We define this sequence by induction:

*Base case*: w(0,i) ∈ αβ\* because i is in a [equivalence class](wikipedia://en/9260). So, we set i<sub>0</sub>=i. We set i<sub>1</sub> such that i<sub>1</sub> favors i<sub>0</sub> and E(i<sub>0</sub>,i<sub>1</sub>). So, w(i<sub>0</sub>,i<sub>1</sub>) ∈ β\*.

*Induction step*: Suppose E(i<sub>0</sub>,i<sub>n</sub>). So, there exists a time i' such that E(i<sub>0</sub>,i<sub>n</sub>,i'). We set i<sub>n+1</sub> such that i<sub>n+1</sub> > i', i<sub>n+1</sub> favors i<sub>0</sub>, and E(i<sub>0</sub>,i<sub>n+1</sub>). So, w(i<sub>0</sub>,i<sub>n+1</sub>) ∈ β\* and, since i<sub>n+1</sub> > i' we have by definition of E(i<sub>0</sub>,i<sub>n</sub>,i'), w(i<sub>n</sub>,i<sub>n+1</sub>) ∈ β\*.

:::

### Muller automaton construction {#Muller_automaton_construction}

We have used both the concepts of "favor" and "equivalence" in Lemma 2. Now, we are going to use the lemma to construct a Muller automaton for language αβ<sup>ω</sup>. The proposed automaton will accept a word if and only if a time i exists such that it will satisfy the right hand side of Lemma 2. The machine below is described informally. Note that this machine will be a deterministic Muller automaton.

The machine contains p+2 deterministic finite automaton and a master controller, where p is the size of A<sup>β\*</sup>. One of the p+2 machine can recognize αβ\* and this machine gets input in every cycle. And, it communicates at any time i to the master controller whether or not *w*(0,i) ∈ αβ\*. The rest of p+1 machines are copies of A<sup>β\*</sup>. The master can set the A<sup>β\*</sup> machines dormant or active. If master sets a A<sup>β\*</sup> machine to be dormant then it remains in its initial state and oblivious to the input. If master activates a A<sup>β\*</sup> machine then it reads the input and moves, until master makes it dormant and force it back to the initial state. Master can make a A<sup>β\*</sup> machine active and dormant as many times as it wants. The master stores the following information about the A<sup>β\*</sup> machines at each time instant.

- Current states of A<sup>β\*</sup> machines.
- List of the active A<sup>β\*</sup> machines in the order of their activation time.
- For each active A<sup>β\*</sup> machine M, the set of other active A<sup>β\*</sup> machines that were in an accepting state at the time of activation of M. In other words, if a machine is made active at time i and some other machine was last made active at j \< i and continue to be active till i then the master keeps the record whether or not i favors j. This record is dropped if the other machine goes dormant before M.

Initially, the master may behave 2 different ways depending on α. If α contains empty word then only one of the A<sup>β\*</sup> is active otherwise none of the A<sup>β\*</sup> machines are active at the start. Later at some time i, if w(0,i) ∈ αβ\* and none of A<sup>β\*</sup> machines are in initial state then master activates one of the dormant machines and the just activated A<sup>β\*</sup> machine start receiving input from time i+1. At some time, if two A<sup>β\*</sup> machines reach to the same state then master makes the machine dormant that was activated later than the other. Note that the master can make the above decisions using the information it stores.

For the output, the master also have a pair of red and green lights corresponding to each A<sup>β\*</sup> machine. If a A<sup>β\*</sup> machine goes from active state to dormant state then corresponding red light flashes. The green light for some A<sup>β\*</sup> machine M, which was activated at j, flashes at time i in the following two situations:

- M is in initial state, thus E(j,i,i) and i favors j ( the initial state has to be accepting state).
- For some other active A<sup>β\*</sup> machine M' activated at k, where j\< k \<i, k favors j (the master has record of this) and i is the earliest time at which E(j,k,i) ( M' goes dormant at time i ).

Note that the green light for M does not flash every time when a machine goes dormant due to M.

::: {#o9 .statement kind=statement/lemma cue=inline-head name="Lemma 3"}

**Lemma 3**

*If there exist a time equivalent to infinitely many times that favor it and i is the earliest such time, then a A<sup>β\*</sup> machine M is activated at i, remained active forever (no corresponding red light flash thereafter), and flashes the green light infinitely many times.*

**Proof:** Let's suppose a A<sup>β\*</sup> machine was activated at time j such that j \< i and this machine goes to initial state at time i. Therefore, if any time is equivalent and favors i then the time must be in the same relation with j. This contradicts the hypothesis that i is the earliest time such that infinitely many times equivalent to i and favoring i. So at time i, no active machine can be in the initial state. Hence, the master has to activate a new A<sup>β\*</sup> machine at time i, which is our M. This machine will never go dormant because if some other machine, which was activated at time l, makes it dormant at time k then E(l,i,k). Again, the same contradiction is implied. By construction and due to infinitely many times are equivalent to i and favor i, the green light will flash infinitely often.

:::

::: {#o10 .statement kind=statement/lemma cue=inline-head name="Lemma 4"}

**Lemma 4**

*Conversely, if there is a A<sup>β\*</sup> machine M whose green light flashed infinitely often and red light only finitely often then there are infinitely many times equivalent to and favoring the last time at which M became active.*

**Proof:** True by construction.

:::

::: {#o11 .statement kind=statement/lemma cue=inline-head name="Lemma 5"}

**Lemma 5**

*w ∈ αβ<sup>ω</sup> if and only if, for some A<sup>β\*</sup> machine, the green light flashes infinitely often and the red light flashes only finitely often.*

**Proof:** Due to Lemmas 2-4.

The above description of a full machine can be viewed as a large [deterministic automaton](https://en.wikipedia.org/wiki/Deterministic_automaton). Now, it is left to define the Muller acceptance condition. In this large automaton, we define μ<sub>n</sub> to be the set of states in which the green light flashes and the red light does not flash corresponding to n<sup>th</sup> A<sup>β\*</sup> machine. Let ν<sub>n</sub> be the set of states in which the red light does not flash corresponding to n<sup>th</sup> A<sup>β\*</sup> machine. So, Muller acceptance condition **F** = { S | ∃n μ<sub>n</sub> ⊆ S ⊆ ν<sub>n</sub> }. This finishes the construction of the desired Muller automaton. Q.E.D.

:::

## Other proofs {#Other_proofs}

Since McNaughton's proof, many other proofs have been proposed. The following are some of them.

- ω-regular languages can be shown equiv-expressive to [Büchi automata](wikipedia://en/344912). Büchi automata can be shown to equiv-expressive to [semi-deterministic Büchi automata](https://en.wikipedia.org/wiki/Semi-deterministic_Büchi_automaton). Semi-deterministic Büchi automata can be shown to be equiv-expressive to deterministic Muller automata. This proof follows the same lines as the above proof.
- Safra's construction transforms a non-deterministic Büchi automaton to a deterministic Rabin automaton.[^o13] This construction is known to be optimal.
- There is a purely algebraic proof[^o14] of McNaughton's theorem.
