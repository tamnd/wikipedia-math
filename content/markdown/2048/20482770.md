# Unimodular polynomial matrix

::: {#o1 .subject cue=lead name="Unimodular polynomial matrix"}

In [mathematics](wikipedia://en/18831), a **unimodular polynomial matrix** is a [square](wikipedia://en/166022#Square_matrices_and_related_definitions) [polynomial matrix](wikipedia://en/7852591) whose [inverse](https://en.wikipedia.org/wiki/Inverse_matrix) exists and is itself a polynomial matrix. Equivalently, a polynomial matrix *A* is unimodular if its [determinant](wikipedia://en/8468) det(*A*) is a nonzero [constant](https://en.wikipedia.org/wiki/Constant_polynomial).[^o2]

:::
