# Shelah cardinal

::: {#o1 .subject cue=lead name="Shelah cardinal"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), **Shelah cardinals** are a kind of [large cardinals](wikipedia://en/383644). A [cardinal](wikipedia://en/6173) $\kappa$ is called Shelah [iff](https://en.wikipedia.org/wiki/Iff) for every $f:\kappa\rightarrow\kappa$, there exists a [transitive class](https://en.wikipedia.org/wiki/Transitive_class) $N$ and an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) $j:V\rightarrow N$ with [critical point](wikipedia://en/4888510) $\kappa$; and $V_{j(f)(\kappa )}\subset N$.

:::

A Shelah cardinal has a normal [ultrafilter](https://en.wikipedia.org/wiki/Ultrafilter_%28set_theory%29) containing the set of [weakly hyper-Woodin cardinals](https://en.wikipedia.org/wiki/Weakly_hyper-Woodin_cardinal) below it.
