# Independent set (graph theory)

*Image: Independent set graph.svg.* The nine blue vertices form a maximum independent set for the [Generalized Petersen graph](wikipedia://en/23716451) GP(12,4).

::: {#o1 .subject cue=lead name="Independent set"}

In [graph theory](wikipedia://en/12401), an **independent set**, **stable set**, **coclique** or **anticlique** is a set of [vertices](wikipedia://en/638899) in a [graph](wikipedia://en/325806), no two of which are adjacent. That is, it is a set $S$ of vertices such that for every two vertices in $S$, there is no [edge](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) connecting the two. Equivalently, each edge in the graph has at most one endpoint in $S$. A set is independent if and only if it is a [clique](wikipedia://en/524466) in the [graph's complement](wikipedia://en/1175649). The size of an independent set is the number of vertices it contains. Independent sets have also been called "internally stable sets", of which "stable set" is a shortening.[^o2]

:::

A [maximal independent set](wikipedia://en/1793590) is an independent set that is not a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of any other independent set.

A **maximum independent set** is an independent set of largest possible size for a given graph $G$. This size is called the **independence number** of *$G$* and is usually denoted by $\alpha(G)$.[^o3] The [optimization problem](wikipedia://en/1126536) of finding such a set is called the **maximum independent set problem.** It is a [strongly NP-hard](wikipedia://en/6319351) problem.[^o4] As such, it is unlikely that there exists an efficient algorithm for finding a maximum independent set of a graph.

Every maximum independent set also is maximal, but the converse implication does not necessarily hold.

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Relationship to other graph parameters {#Relationship_to_other_graph_parameters}

A set is independent if and only if it is a [clique](wikipedia://en/524466) in the graph's [complement](wikipedia://en/1175649), so the two concepts are complementary. In fact, sufficiently large graphs with no large cliques have large independent sets, a theme that is explored in [Ramsey theory](wikipedia://en/157175).

A set is independent if and only if its complement is a [vertex cover](wikipedia://en/562782).[^o8] Therefore, the sum of the size of the largest independent set $\alpha(G)$ and the size of a minimum vertex cover $\beta(G)$ is equal to the number of vertices in the graph.

A [vertex coloring](wikipedia://en/426743) of a graph $G$ corresponds to a [partition](wikipedia://en/340240) of its vertex set into independent subsets. Hence the minimal number of colors needed in a vertex coloring, the *chromatic number* $\chi(G)$, is at least the quotient of the number of vertices in $G$ and the independence number $\alpha(G)$.

In a [bipartite graph](wikipedia://en/244431) with no isolated vertices, the number of vertices in a maximum independent set equals the number of edges in a minimum [edge covering](https://en.wikipedia.org/wiki/Edge_covering); this is [Kőnig's theorem](wikipedia://en/5465118).

### Maximal independent set {#Maximal_independent_set}

An independent set that is not a proper subset of another independent set is called *maximal*. Such sets are [dominating sets](wikipedia://en/1747972). Every graph contains at most 3<sup>*n*/3</sup> maximal independent sets,[^o10] but many graphs have far fewer. The number of maximal independent sets in *n*-vertex [cycle graphs](wikipedia://en/878962) is given by the [Perrin numbers](wikipedia://en/30863738), and the number of maximal independent sets in *n*-vertex [path graphs](wikipedia://en/4587190) is given by the [Padovan sequence](wikipedia://en/2161709).[^o11] Therefore, both numbers are proportional to powers of 1.324718..., the [plastic ratio](wikipedia://en/2148532).

:::

## Finding independent sets {#Finding_independent_sets}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), several [computational problems](https://en.wikipedia.org/wiki/Computational_problems) related to independent sets have been studied.

- In the **maximum independent set** problem, the input is an undirected graph, and the output is a maximum independent set in the graph. If there are multiple maximum independent sets, only one need be output. This problem is sometimes referred to as "**vertex packing**".
- In the **maximum-weight independent set** problem, the input is an undirected graph with weights on its vertices and the output is an independent set with maximum total weight. The maximum independent set problem is the special case in which all weights are one.
- In the **maximal independent set listing** problem, the input is an undirected graph, and the output is a list of all its maximal independent sets. The maximum independent set problem may be solved using as a subroutine an algorithm for the maximal independent set listing problem, because the maximum independent set must be included among all the maximal independent sets.
- In the **independent set decision** problem, the input is an undirected graph and a number *k*, and the output is a [Boolean value](wikipedia://en/161711): true if the graph contains an independent set of size *k*, and false otherwise.

The first three of these problems are all important in practical applications; the independent set decision problem is not, but is necessary in order to apply the theory of [NP-completeness](wikipedia://en/23385892) to problems related to independent sets.

### Maximum independent sets and maximum cliques {#Maximum_independent_sets_and_maximum_cliques}

The independent set problem and the [clique problem](wikipedia://en/249254) are complementary: a clique in *G* is an independent set in the [complement graph](wikipedia://en/1175649) of *G* and vice versa. Therefore, many computational results may be applied equally well to either problem. For example, the results related to the clique problem have the following corollaries:

- The independent set decision problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete), and hence it is not believed that there is an efficient algorithm for solving it.
- The maximum independent set problem is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) and it is also hard to [approximate](wikipedia://en/563105).

Despite the close relationship between maximum cliques and maximum independent sets in arbitrary graphs, the independent set and clique problems may be very different when restricted to special classes of graphs. For instance, for [sparse graphs](wikipedia://en/2777098) (graphs in which the number of edges is at most a constant times the number of vertices in any subgraph), the maximum clique has bounded size and may be found exactly in linear time;[^o14] however, for the same classes of graphs, or even for the more restricted class of bounded degree graphs, finding the maximum independent set is [MAXSNP-complete](https://en.wikipedia.org/wiki/SNP_%28complexity%29), implying that, for some constant *c* (depending on the degree) it is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) to find an approximate solution that comes within a factor of *c* of the optimum.[^o15]

### Exact algorithms {#Exact_algorithms}

The maximum independent set problem is NP-hard. However, it can be solved more efficiently than the O(*n*<sup>2</sup> 2<sup>*n*</sup>) time that would be given by a naive [brute force algorithm](https://en.wikipedia.org/wiki/Brute-force_search) that examines every vertex subset and checks whether it is an independent set.

As of 2017 it can be solved in time O(1.1996<sup>*n*</sup>) using polynomial space.[^o17] When restricted to graphs with maximum degree 3, it can be solved in time O(1.0836<sup>*n*</sup>).[^o18]

For many classes of graphs, a maximum weight independent set may be found in polynomial time. Famous examples are [claw-free graphs](wikipedia://en/12415907),[^o19] *P*<sub>5</sub>-free graphs[^o20] and [perfect graphs](wikipedia://en/670531).[^o21] For [chordal graphs](wikipedia://en/744165), a maximum weight independent set can be found in linear time.[^o22]

[Modular decomposition](wikipedia://en/28310124) is a good tool for solving the maximum weight independent set problem; the linear time algorithm on [cographs](wikipedia://en/1175666) is the basic example for that. Another important tool are [clique separators](https://en.wikipedia.org/wiki/Clique_separator) as described by Tarjan.[^o23]

[Kőnig's theorem](wikipedia://en/5465118) implies that in a [bipartite graph](wikipedia://en/244431) the maximum independent set can be found in polynomial time using a bipartite matching algorithm.

::: {#o25 .pointer-item cue=pointer name="Approximation algorithms for the maximum independent set problem"}

### Approximation algorithms {#Approximation_algorithms}

In general, the maximum independent set problem cannot be approximated to a constant factor in polynomial time (unless P = NP). In fact, Max Independent Set in general is [Poly-APX-complete](wikipedia://en/2018925#Related_complexity_classes), meaning it is as hard as any problem that can be approximated to a polynomial factor.[^o26] However, there are efficient approximation algorithms for restricted classes of graphs.

#### In planar graphs {#In_planar_graphs}

In [planar graphs](wikipedia://en/24314), the maximum independent set may be approximated to within any approximation ratio *c* \< 1 in polynomial time; similar [polynomial-time approximation schemes](wikipedia://en/666431) exist in any family of graphs closed under taking [minors](https://en.wikipedia.org/wiki/Minor_%28graph_theory%29).[^o28]

#### In bounded degree graphs {#In_bounded_degree_graphs}

In bounded degree graphs, effective approximation algorithms are known with [approximation ratios](https://en.wikipedia.org/wiki/Approximation_ratio) that are constant for a fixed value of the maximum degree; for instance, a [greedy algorithm](wikipedia://en/89247) that forms a maximal independent set by, at each step, choosing the minimum degree vertex in the graph and removing its neighbors, achieves an approximation ratio of (Δ+2)/3 on graphs with maximum degree Δ.[^o30] Approximation hardness bounds for such instances were proven in (Berman Karpinski 1999). Indeed, even Max Independent Set on 3-regular 3-edge-colorable graphs is [APX-complete](wikipedia://en/2018925).[^o32]

#### In interval intersection graphs {#In_interval_intersection_graphs}

An [interval graph](wikipedia://en/363423) is a graph in which the nodes are 1-dimensional intervals (e.g. time intervals) and there is an edge between two intervals if and only if they intersect. An independent set in an interval graph is just a set of non-overlapping intervals. The problem of finding maximum independent sets in interval graphs has been studied, for example, in the context of [job scheduling](https://en.wikipedia.org/wiki/Job_scheduling): given a set of jobs that has to be executed on a computer, find a maximum set of jobs that can be executed without interfering with each other. This problem can be solved exactly in polynomial time using [earliest deadline first scheduling](https://en.wikipedia.org/wiki/Earliest_deadline_first_scheduling).

#### In geometric intersection graphs {#In_geometric_intersection_graphs}

A geometric [intersection graph](wikipedia://en/7726759) is a graph in which the nodes are geometric shapes and there is an edge between two shapes if and only if they intersect. An independent set in a geometric intersection graph is just a set of disjoint (non-overlapping) shapes. The problem of finding maximum independent sets in geometric intersection graphs has been studied, for example, in the context of [Automatic label placement](https://en.wikipedia.org/wiki/Automatic_label_placement): given a set of locations in a map, find a maximum set of disjoint rectangular labels near these locations.

Finding a maximum independent set in intersection graphs is still NP-complete, but it is easier to approximate than the general maximum independent set problem. A recent survey can be found in the introduction of (Chan Har-Peled 2012).

#### In d-claw-free graphs {#In_d-claw-free_graphs}

A *d-claw* in a graph is a set of *d*+1 vertices, one of which (the "center") is connected to the other *d* vertices, but the other d vertices are not connected to each other. A *d*-[claw-free graph](wikipedia://en/12415907) is a graph that does not have a *d*-claw subgraph. Consider the algorithm that starts with an empty set, and incrementally adds an arbitrary vertex to it as long as it is not adjacent to any existing vertex. In *d*-claw-free graphs, every added vertex invalidates at most *d* − 1 vertices from the maximum independent set; therefore, this trivial algorithm attains a (*d* − 1)-approximation algorithm for the maximum independent set. In fact, it is possible to get much better approximation ratios:

- Neuwohner[^o37] presented a polynomial time algorithm that, for any constant ε>0, finds a (*d*/2 − 1/63,700,992+ε)-approximation for the maximum weight independent set in a *d*-claw free graph.
- Cygan[^o38] presented a [quasi-polynomial time](wikipedia://en/25269049) algorithm that, for any ε>0, attains a (d+ε)/3 approximation.

:::

::: {#o40 .pointer-item cue=pointer name="Vertex packing"}

### Finding maximal independent sets {#Finding_maximal_independent_sets}

The problem of finding a maximal independent set can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) by a trivial parallel [greedy algorithm](wikipedia://en/89247) .[^o41] All maximal independent sets can be found in time O(3<sup>*n*/3</sup>) = O(1.4423<sup>*n*</sup>).

:::

### Counting independent sets {#Counting_independent_sets}

::: {#o43 .problem cue=unsolved}

Is there a fully polynomial-time approximation algorithm for the number of independent sets in bipartite graphs?

:::

The [counting problem](https://en.wikipedia.org/wiki/Counting_problem_%28complexity%29) #IS asks, given an undirected graph, how many independent sets it contains. This problem is intractable, namely, it is [♯P](wikipedia://en/27924)-complete, already on graphs with maximal [degree](wikipedia://en/1374448) three.[^o44] It is further known that, assuming that [NP](wikipedia://en/21562) is different from [RP](wikipedia://en/54771), the problem cannot be tractably [approximated](wikipedia://en/563105) in the sense that it does not have a fully [polynomial-time approximation scheme](wikipedia://en/666431) with randomization (FPRAS), even on graphs with maximal degree six;[^o45] however it does have an fully polynomial-time approximation scheme (FPTAS) in the case where the maximal degree is five.[^o46] The problem #BIS, of counting independent sets on [bipartite graphs](wikipedia://en/244431), is also [♯P](wikipedia://en/27924)-complete, already on graphs with maximal [degree](wikipedia://en/1374448) three.[^o47] It is not known whether #BIS admits a FPRAS.[^o48]

The question of [counting maximal independent sets](https://en.wikipedia.org/wiki/Counting_maximal_independent_sets) has also been studied.

::: {#o50 .application cue=heading name="Applications"}

## Applications {#Applications}

The maximum independent set and its complement, the [minimum vertex cover](wikipedia://en/562782) problem, is involved in proving the [computational complexity](wikipedia://en/7543) of many theoretical problems.[^o51]

:::
