# Remarkable cardinal

::: {#o1 .subject cue=lead name="Remarkable cardinal"}

In [mathematics](wikipedia://en/18831), a **remarkable cardinal** is a certain kind of [large cardinal](wikipedia://en/383644) number.

:::

A [cardinal](wikipedia://en/6173) *κ* is called remarkable if for all [regular cardinals](wikipedia://en/374128) *θ* > *κ*, there exist *π*, *M*, *λ*, *σ*, *N* and *ρ* such that

1. *π* : *M* → *H*<sub>*θ*</sub> is an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding)
1. *M* is [countable](https://en.wikipedia.org/wiki/Countable) and [transitive](wikipedia://en/2462396)
1. *π*(*λ*) = *κ*
1. *σ* : *M* → *N* is an elementary embedding with [critical point](wikipedia://en/4888510) *λ*
1. *N* is countable and transitive
1. *ρ* = *M* ∩ **[Ord](wikipedia://en/26547932)** is a [regular cardinal](wikipedia://en/374128) in *N*
1. *σ*(*λ*) > *ρ*
1. *M* = *H*<sub>*ρ*</sub><sup>*N*</sup>, i.e., *M* ∈ *N* and *N* ⊨ "*M is the set of all sets that are hereditarily smaller than ρ*"

Equivalently, $\kappa$ is remarkable if and only if for every $\lambda>\kappa$ there is $\bar\lambda<\kappa$ such that in some [forcing](https://en.wikipedia.org/wiki/Forcing_%28set_theory%29) extension $V[G]$, there is an elementary embedding $j:V_{\bar\lambda}^V\rightarrow V_\lambda^V$ satisfying $j(\operatorname{crit}(j))=\kappa$. Although the definition is similar to one of the definitions of [supercompact cardinals](wikipedia://en/248116), the elementary embedding here only has to exist in $V[G]$, not in $V$.
