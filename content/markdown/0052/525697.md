# Ordered ring

*Image: Real number line.svg.* The [real numbers](wikipedia://en/20646438) are an ordered ring which is also an [ordered field](wikipedia://en/22430). The [integers](https://en.wikipedia.org/wiki/Integers), a subset of the real numbers, are an ordered ring that is not an ordered field.

::: {#o1 .subject cue=lead name="Ordered ring"}

In [abstract algebra](wikipedia://en/19616384), an **ordered ring** is a (usually [commutative](wikipedia://en/61346)) [ring](wikipedia://en/48404) *R* with a [total order](wikipedia://en/30330) ≤ such that for all *a*, *b*, and *c* in *R*:[^o2]

:::

- if *a* ≤ *b* then *a* + *c* ≤ *b* + *c*.
- if 0 ≤ *a* and 0 ≤ *b* then 0 ≤ *ab*.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Ordered rings are familiar from [arithmetic](wikipedia://en/3118). Examples include the [integers](wikipedia://en/14563), the [rationals](wikipedia://en/19727024) and the [real numbers](wikipedia://en/20646438).[^o5] (The rationals and reals in fact form [ordered fields](wikipedia://en/22430).) The [complex numbers](wikipedia://en/5826), in contrast, do not form an ordered ring or field, because there is no inherent order relationship between the elements 1 and *i*.

:::

## Positive elements {#Positive_elements}

In analogy with the real numbers, we call an element *c* of an ordered ring *R* **positive** if 0 \< *c*, and **negative** if *c* \< 0. 0 is considered to be neither positive nor negative.

The set of positive elements of an ordered ring *R* is often denoted by *R*<sub>\+</sub>. An alternative notation, favored in some disciplines, is to use *R*<sub>\+</sub> for the set of nonnegative elements, and *R*<sub>\++</sub> for the set of positive elements.

## Absolute value {#Absolute_value}

If $a$ is an element of an ordered ring *R*, then the **[absolute value](wikipedia://en/991)** of $a$, denoted $|a|$, is defined thus:

$$|a| := \begin{cases} a, & \mbox{if } 0 \leq a, \\ -a, & \mbox{otherwise}, \end{cases}$$

where $-a$ is the [additive inverse](wikipedia://en/228312) of $a$ and 0 is the additive [identity element](wikipedia://en/14962).

## Discrete ordered rings {#Discrete_ordered_rings}

A **discrete ordered ring** or **discretely ordered ring** is an ordered ring in which there is no element between 0 and 1. The integers are a discrete ordered ring, but the rational numbers are not.

::: {#o10 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

For all *a*, *b* and *c* in *R*:

- If *a* ≤ *b* and 0 ≤ *c*, then *ac* ≤ *bc*.[^o11] This property is sometimes used to define ordered rings instead of the second property in the definition above.
- \|*ab*| = |*a*||*b*|.[^o12]
- An ordered ring that is not [trivial](https://en.wikipedia.org/wiki/Trivial_ring) is infinite.[^o13]
- Exactly one of the following is true: *a* is positive, −*a* is positive, or *a* = 0.[^o14] This property follows from the fact that ordered rings are [abelian](wikipedia://en/2974), [linearly ordered groups](wikipedia://en/349014) with respect to addition.
- In an ordered ring, no negative element is a square:[^o15] Firstly, 0 is nonnegative. Now if *a* ≠ 0 and *a* = *b*<sup>2</sup> then *b* ≠ 0 and *a* = (−*b*)<sup>2</sup>; as either *b* or −*b* is positive, *a* must be nonnegative.

:::
