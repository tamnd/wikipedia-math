# Deterministic system

::: {#o1 .subject cue=lead name="Deterministic system"}

In [mathematics](wikipedia://en/18831), [computer science](https://en.wikipedia.org/wiki/Computer_science) and [physics](wikipedia://en/22939), a **deterministic system** is a system in which no [randomness](wikipedia://en/19196523) is involved in the development of future states of the system.[^o2] A deterministic [model](wikipedia://en/20590) will thus always produce the same output from a given starting condition or initial state.

:::

## In physics {#In_physics}

*Image: Parabolic trajectory.svg.* The [trajectory](https://en.wikipedia.org/wiki/Trajectory) of a [projectile](https://en.wikipedia.org/wiki/Projectile) launched from a [cannon](https://en.wikipedia.org/wiki/Cannon) is modeled by an [ODE](wikipedia://en/32742753) that is derived from Newton's second law.

[Physical laws](wikipedia://en/244629) that are described by [differential equations](wikipedia://en/1424309) represent deterministic systems, even though the state of the system at a given [point in time](https://en.wikipedia.org/wiki/Time-dependent_density_functional_theory) may be difficult to describe explicitly. In [quantum mechanics](wikipedia://en/25202), the [Schrödinger equation](wikipedia://en/59874), which describes the continuous [time evolution](wikipedia://en/937739) of a system's [wave function](wikipedia://en/145343), is deterministic. However, the relationship between a system's wave function and the [observable](wikipedia://en/294248) properties of the system appears to be non-deterministic.

## In mathematics {#In_mathematics}

The systems studied in [chaos theory](wikipedia://en/6295) are deterministic. If the initial state were known exactly, then the future state of such a system could [theoretically](wikipedia://en/30746) be [predicted](wikipedia://en/246066). However, in practice, knowledge about the future state is limited by the precision with which the initial state can be measured, and chaotic systems are characterized by a strong dependence on the initial conditions. This sensitivity to initial conditions can be measured with [Lyapunov exponents](https://en.wikipedia.org/wiki/Lyapunov_exponents). [Markov chains](wikipedia://en/60876) and other [random walks](wikipedia://en/235451) are not deterministic systems, because their development depends on random choices.

## In computer science {#In_computer_science}

A deterministic [model of computation](wikipedia://en/1773278), for example a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine), is a model of computation such that the successive states of the machine and the operations to be performed are completely determined by the preceding state. A [deterministic algorithm](https://en.wikipedia.org/wiki/Deterministic_algorithm) is an algorithm which, given a particular input, will always produce the same output, with the underlying machine always passing through the same sequence of states.

There may be non-deterministic algorithms that run on a deterministic machine, for example, an algorithm that relies on random choices. Generally, for such random choices, one uses a [pseudorandom number generator](wikipedia://en/45524), but one may also use some external physical process, such as the last digits of the time given by the computer clock. A *pseudorandom number generator* is a deterministic algorithm, that is designed to produce sequences of numbers that behave as random sequences. A [hardware random number generator](https://en.wikipedia.org/wiki/Hardware_random_number_generator), however, may be non-deterministic.

:::

## In economics {#In_economics}

In economics, the [Ramsey–Cass–Koopmans model](wikipedia://en/4701722) is deterministic. The stochastic equivalent is known as [real business-cycle theory](https://en.wikipedia.org/wiki/Real_business-cycle_theory). As determinism relates to modeling in the natural sciences, a deterministic model[^o8] uses existing data to model the future behavior of a system. The deterministic model is useful for systems that do not experience frequent or unexpected behavior - unless that behavior is already present in the system via existing data. This type of modeling is distinct from stochastic modeling[^o8] or forward modeling.[^o9] Stochastic modeling uses random data in the model while forward modeling uses a given model to predict future behavior in a system. Deterministic models are used across the natural sciences, including geology, oceanography,[^o10] physics, and other disciplines.
