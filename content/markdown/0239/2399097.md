# Numbering (computability theory)

::: {#o1 .subject cue=lead name="Numbering"}

In [computability theory](wikipedia://en/155414) a **numbering** is an assignment of [natural numbers](wikipedia://en/21474) to a [set](wikipedia://en/26691) of objects such as [functions](wikipedia://en/185427), [rational numbers](wikipedia://en/19727024), [graphs](wikipedia://en/325806), or words in some [formal language](wikipedia://en/10939). A numbering can be used to transfer the idea of computability and related concepts, which are originally defined on the natural numbers using [computable functions](wikipedia://en/1139338), to these different types of objects.

:::

Common examples of numberings include [Gödel numberings](wikipedia://en/207790) in [first-order logic](wikipedia://en/10983), the [description numbers](wikipedia://en/7805214) that arise from [universal Turing machines](wikipedia://en/71435) and [admissible numberings](https://en.wikipedia.org/wiki/Admissible_numbering) of the set of partial computable functions.

::: {#o3 .definition cue=heading name="Definition and examples"}

## Definition and examples {#Definition_and_examples}

A **numbering** of a set $S$ is a [surjective](wikipedia://en/27873) [partial function](wikipedia://en/23577) from $\mathbb{N}$ to *S* ([Ershov](wikipedia://en/2606710) 1999:477). The value of a numbering $\nu$ at a number *i* (if defined) is often written $\nu_i$ instead of the usual $\nu(i)$.

Examples of numberings include:

- The set of all finite subsets of $\mathbb{N}$ has a numbering $\gamma$ , defined so that $\gamma(0) = \emptyset$ and so that, for each finite nonempty set $A = \{a_0, \ldots, a_k\}$, $\gamma(n_A) = A$ where $n_A = \sum_{i \leq k} 2^{a_i}$ (Ershov 1999:477). This numbering is an injection.
- A fixed Gödel numbering $\varphi_i$ of the computable partial functions can be used to define a numbering *W* of the [computably enumerable sets](wikipedia://en/332090), by letting by *W*(*i*) be the domain of $\varphi_i$. This numbering will be surjective (like all numberings) but not injective: there will be distinct numbers that map to the same computably enumerable set under *W*.

:::

## Types of numberings {#Types_of_numberings}

A numbering is **total** if it is a total function. If the [domain](https://en.wikipedia.org/wiki/Domain_%28function%29) of a partial numbering is [computably enumerable](https://en.wikipedia.org/wiki/Computably_enumerable) then there always exists an equivalent total numbering (equivalence of numberings is defined below).

A numbering *η* is **decidable** if the set $\{ (x,y) : \eta(x) = \eta(y)\}$ is a decidable set.

A numbering *η* is **single-valued** if *η*(*x*) = *η*(*y*) if and only if *x*=*y*; in other words if *η* is an injective function. A single-valued numbering of the set of partial computable functions is called a [Friedberg numbering](wikipedia://en/37810060).

## Comparison of numberings {#Comparison_of_numberings}

There is a [preorder](wikipedia://en/23582) on the set of all numberings. Let $\nu_1: \mathbb{N} \rightharpoonup S$ and $\nu_2: \mathbb{N} \rightharpoonup S$ be two numberings. Then $\nu_1$ is **reducible** to $\nu_2$, written $\nu_1 \le \nu_2$, if

$$\exists f \in \mathbf{P}^{(1)} \, \forall i \in \mathrm{Domain}(\nu_1) : \nu_1(i) = \nu_2 \circ f(i).$$

Where $\mathbf{P}^{(1)}$ is the set of all partial computable functions $\mathbb N \to \mathbb N$.

If $\nu_1 \le \nu_2$ and $\nu_1 \ge \nu_2$ then $\nu_1$ is **equivalent** to $\nu_2$; this is written $\nu_1 \equiv \nu_2$.

## Computable numberings {#Computable_numberings}

When the objects of the set *S* being numbered are sufficiently "constructive", it is common to look at numberings that can be effectively decoded (Ershov 1999:486). For example, if *S* consists of computably enumerable sets, the numbering *η* is **computable** if the set of pairs (*x*,*y*) where *y* ∈ *η*(*x*) is computably enumerable. Similarly, a numbering *g* of partial functions is computable if the relation *R*(*x*,*y*,*z*) = "\[*g*(*x*)\](*y*) = *z*" is computably enumerable (Ershov 1999:487).

A computable numbering is called **principal** if every computable numbering of the same set is reducible to it. Both the set of all computably enumerable subsets of $\mathbb{N}$ and the set of all partial computable functions have principal numberings (Ershov 1999:487). A principal numbering of the set of partial computably functions is known as an [admissible numbering](https://en.wikipedia.org/wiki/Admissible_numbering) in the literature.
