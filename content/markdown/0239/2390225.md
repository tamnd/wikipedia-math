# Glossary of category theory

::: {#o1 .subject cue=lead name="Glossary of category theory"}

This is a glossary of properties and concepts in [category theory](wikipedia://en/5869) in [mathematics](wikipedia://en/18831), including those in [topos theory](https://en.wikipedia.org/wiki/Topos_theory). (See also [Outline of category theory](wikipedia://en/354319).)

:::

- **Notes on foundations**: In many expositions (e.g., Vistoli), the set-theoretic issues are ignored; this means, for instance, that one does not distinguish between small and large categories and that one can arbitrarily form a localization of a category.[^o2] Like those expositions, this glossary also generally ignores the set-theoretic issues, except when they are relevant (e.g., the discussion on accessibility.)

Especially for higher categories, the concepts from algebraic topology are also used in the category theory. For that see also [glossary of algebraic topology](wikipedia://en/48781047).

The notations and the conventions used throughout the article are:

- \[*n*\] = {0, 1, 2, …, *n*}, which is viewed as a category (by writing $i \to j \Leftrightarrow i \le j$.)
- **Cat**, the [category of (small) categories](https://en.wikipedia.org/wiki/Category_of_categories), where the objects are categories (which are small with respect to some universe) and the morphisms [functors](wikipedia://en/10987).
- **Fct**(*C*, *D*), the [functor category](wikipedia://en/407039): the category of [functors](wikipedia://en/10987) from a category *C* to a category *D*.
- **Set**, the category of (small) sets.
- *s***Set**, the category of [simplicial sets](wikipedia://en/1027784).
- "weak" instead of "strict" is given the default status; e.g., "*n*-category" means "weak *n*-category", not the strict one, by default.
- By an [∞-category](https://en.wikipedia.org/wiki/∞-category), we mean a [quasi-category](wikipedia://en/28662219), the most popular model, unless other models are being discussed.
- The number [zero](https://en.wikipedia.org/wiki/Zero) 0 is a natural number.

## !\$@ {#!$@}

::: {#o4 .entry cue=term name="2-category"}

**2-category**

A [2-category](wikipedia://en/2740708) is a generalization of a category where there are also 2-morphisms between morphisms.

A [(2, 1)-category](https://en.wikipedia.org/wiki/%282,_1%29-category) is a 2-category in which every 2-morphism is invertible.

:::

## A {#A}

::: {#o6 .entry cue=term name="abelian"}

**abelian**

A category is [abelian](wikipedia://en/45063) if it has a zero object, it has all pullbacks and pushouts, and all monomorphisms and epimorphisms are normal.

:::

::: {#o7 .entry cue=term name="accessible"}

**accessible**

Given a [cardinal number](wikipedia://en/6173) κ, an object *X* in a category is [κ-accessible](https://en.wikipedia.org/wiki/Accessible_object) (or κ-compact or κ-presentable) if $\operatorname{Hom}(X, -)$ commutes with κ-filtered colimits.

Given a [regular cardinal](wikipedia://en/374128) κ, a category is [κ-accessible](wikipedia://en/15311782) if it has κ-filtered colimits and there exists a small set *S* of κ-compact objects that generates the category under colimits, meaning every object can be written as a colimit of diagrams of objects in *S*.

:::

::: {#o8 .entry cue=term name="additive"}

**additive**

A category is [additive](wikipedia://en/60854) if it is preadditive (to be precise, has some pre-additive structure) and admits all finite [coproducts](wikipedia://en/310889). Although "preadditive" is an additional structure, one can show "additive" is a *property* of a category; i.e., one can ask whether a given category is additive or not.[^o9]

:::

::: {#o10 .entry cue=term name="adequate"}

**adequate**

An [adequate subcategory](wikipedia://en/82474244) is a subcategory on which the Yoneda embedding of the ambient category is still fully faithful.

:::

::: {#o11 .entry cue=term name="adjunction"}

**adjunction**

An [adjunction](https://en.wikipedia.org/wiki/Adjoint_functor) (also called an adjoint pair) is a pair of functors *F*: *C* → *D*, *G*: *D* → *C* such that there is a "natural" bijection

$\operatorname{Hom}_D (F(X), Y) \simeq \operatorname{Hom}_C (X, G(Y))$; *F* is said to be left adjoint to *G* and *G* to right adjoint to *F*. Here, "natural" means there is a natural isomorphism $\operatorname{Hom}_D (F(-), -) \simeq \operatorname{Hom}_C (-, G(-))$ of bifunctors (which are contravariant in the first variable.)

:::

::: {#o12 .entry cue=term name="algebra for a monad"}

**algebra for a monad**

Given a monad *T* in a category *X*, an [algebra for *T*](https://en.wikipedia.org/wiki/Algebra_for_a_monad) or a *T*-algebra is an object in *X* with a [monoid action](https://en.wikipedia.org/wiki/Monoid_action) of *T* ("algebra" is misleading and "*T*-object" is perhaps a better term.) For example, given a group *G* that determines a monad *T* in **Set** in the standard way, a *T*-algebra is a set with an [action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) of *G*.

:::

::: {#o13 .entry cue=term name="algebraic"}

**algebraic**

An [algebraic category](https://en.wikipedia.org/wiki/Algebraic_category) is a category that is [monadic](https://en.wikipedia.org/wiki/Monadic) over **Set**.

:::

::: {#o14 .entry cue=term name="amnestic"}

**amnestic**

A functor is amnestic if it has the property: if *k* is an isomorphism and *F*(*k*) is an identity, then *k* is an identity.

:::

::: {#o15 .entry cue=term name="anodyne"}

**anodyne**

[anodyne extension](https://en.wikipedia.org/wiki/Anodyne_extension)

:::

## B {#B}

::: {#o17 .entry cue=term name="balanced"}

**balanced**

A category is [balanced](wikipedia://en/77326358) if every [bimorphism](https://en.wikipedia.org/wiki/Bimorphism) (i.e., both mono and epi) is an isomorphism.

:::

::: {#o18 .entry cue=term name="Beck's theorem"}

**Beck's theorem**

[Beck's theorem](wikipedia://en/2082726) characterizes the category of [algebras for a given monad](https://en.wikipedia.org/wiki/Algebra_for_a_monad).

:::

::: {#o19 .entry cue=term name="bicategory"}

**bicategory**

A [bicategory](https://en.wikipedia.org/wiki/Bicategory) is a model of a weak [2-category](wikipedia://en/2740708).

:::

::: {#o20 .entry cue=term name="bifunctor"}

**bifunctor**

A [bifunctor](https://en.wikipedia.org/wiki/Bifunctor) from a pair of categories *C* and *D* to a category *E* is a functor *C* × *D* → *E*. For example, for any category *C*, $\operatorname{Hom}(-, -)$ is a bifunctor from *C*<sup>op</sup> and *C* to **Set**.

:::

::: {#o21 .entry cue=term name="bimonoidal"}

**bimonoidal**

A [bimonoidal category](wikipedia://en/69720399) is a category with two monoidal structures, one distributing over the other.

:::

::: {#o22 .entry cue=term name="bimorphism"}

**bimorphism**

A [bimorphism](https://en.wikipedia.org/wiki/Bimorphism) is a morphism that is both an epimorphism and a monomorphism.

:::

::: {#o23 .entry cue=term name="Bousfield localization"}

**Bousfield localization**

See [Bousfield localization](wikipedia://en/40776006).

:::

## C {#C}

::: {#o25 .entry cue=term name="calculus of functors"}

**calculus of functors**

The [calculus of functors](wikipedia://en/23694557) is a technique of studying functors in the manner similar to the way a [function](wikipedia://en/185427) is studied via its [Taylor series](wikipedia://en/30448) expansion; whence, the term "calculus".

:::

::: {#o26 .entry cue=term name="calculus of fractions"}

**calculus of fractions**

[calculus of fractions](https://en.wikipedia.org/wiki/Calculus_of_fractions).

:::

::: {#o27 .entry cue=term name="cartesian closed"}

**cartesian closed**

A category is [cartesian closed](wikipedia://en/237037) if it has a terminal object and that any two objects have a product and exponential.

:::

::: {#o28 .entry cue=term name="cartesian functor"}

**cartesian functor**

Given relative categories $p: F \to C, q: G \to C$ over the same base category *C*, a functor $f: F \to G$ over *C* is cartesian if it sends cartesian morphisms to cartesian morphisms.

:::

::: {#o29 .entry cue=term name="cartesian morphism"}

**cartesian morphism**

Given a functor π: *C* → *D* (e.g., a [prestack](wikipedia://en/39547490) over schemes), a morphism *f*: *x* → *y* in *C* is [π-cartesian](https://en.wikipedia.org/wiki/Cartesian_morphism) if, for each object *z* in *C*, each morphism *g*: *z* → *y* in *C* and each morphism *v*: π(*z*) → π(*x*) in *D* such that π(*g*) = π(*f*) ∘ *v*, there exists a unique morphism *u*: *z* → *x* such that π(*u*) = *v* and *g* = *f* ∘ *u*.

Given a functor π: *C* → *D* (e.g., a [prestack](wikipedia://en/39547490) over rings), a morphism *f*: *x* → *y* in *C* is [π-coCartesian](https://en.wikipedia.org/wiki/Cartesian_morphism) if, for each object *z* in *C*, each morphism *g*: *x* → *z* in *C* and each morphism *v*: π(*y*) → π(*z*) in *D* such that π(*g*) = *v* ∘ π(*f*), there exists a unique morphism *u*: *y* → *z* such that π(*u*) = *v* and *g* = *u* ∘ *f*. (In short, *f* is the dual of a π-cartesian morphism.)

:::

::: {#o30 .entry cue=term name="Cartesian square"}

**Cartesian square**

A commutative diagram that is isomorphic to the diagram given as a fiber product.

:::

::: {#o31 .entry cue=term name="categorical logic"}

**categorical logic**

[Categorical logic](wikipedia://en/1063799) is an approach to [mathematical logic](wikipedia://en/19636) that uses category theory.

:::

::: {#o32 .entry cue=term name="categorical probability"}

**categorical probability**

[categorical probability](wikipedia://en/77434685)

:::

::: {#o33 .entry cue=term name="categorification"}

**categorification**

[categorification](wikipedia://en/1596969) is a process of replacing sets and set-theoretic concepts with categories and category-theoretic concepts in some nontrivial way to capture categoric flavors. Decategorification is the reverse of categorification.

:::

The theory of categories originated ... with the need to guide complicated calculations involving passage to the limit in the study of the qualitative leap from spaces to homotopical/homological objects. ... But category theory does not rest content with mere classification in the spirit of Wolffian metaphysics (although a few of its practitioners may do so); rather it is the *mutability* of mathematically precise structures (by morphisms) which is the essential content of category theory.

::: {#o35 .entry cue=term name="category"}

**category**

A [category](wikipedia://en/53759) consists of the following data

A class of objects,

For each pair of objects *X*, *Y*, a set $\operatorname{Hom}(X, Y)$, whose elements are called morphisms from *X* to *Y*,

For each triple of objects *X*, *Y*, *Z*, a map (called composition)

$$\circ: \operatorname{Hom}(Y, Z) \times \operatorname{Hom}(X, Y) \to \operatorname{Hom}(X, Z), \, (g, f) \mapsto g \circ f,$$

For each object *X*, an identity morphism $\operatorname{id}_X \in \operatorname{Hom}(X, X)$ subject to the conditions: for any morphisms $f: X \to Y$, $g: Y \to Z$ and $h: Z \to W$,

$(h \circ g) \circ f = h \circ (g \circ f)$ and $\operatorname{id}_Y \circ f = f \circ \operatorname{id}_X = f$. For example, a [partially ordered set](wikipedia://en/23572) can be viewed as a category: the objects are the elements of the set and for each pair of objects *x*, *y*, there is a unique morphism $x \to y$ if and only if $x \le y$; the associativity of composition means transitivity.

:::

::: {#o36 .entry cue=term name="category of"}

**category of**

The [category of (small) categories](https://en.wikipedia.org/wiki/Category_of_categories), denoted by **Cat**, is a category where the objects are all the categories which are small with respect to some fixed universe and the morphisms are all the [functors](wikipedia://en/10987).

[Category of modules](wikipedia://en/11231812), [Category of topological spaces](wikipedia://en/435051), [Category of groups](wikipedia://en/800092), [Category of metric spaces](wikipedia://en/535617), etc.

:::

::: {#o37 .entry cue=term name="classifying space"}

**classifying space**

The [classifying space of a category](https://en.wikipedia.org/wiki/Classifying_space_of_a_category) *C* is the geometric realization of the nerve of *C*.

:::

::: {#o38 .entry cue=term name="co-"}

**co-**

Often used synonymous with op-; for example, a [colimit](https://en.wikipedia.org/wiki/Colimit) refers to an op-limit in the sense that it is a limit in the opposite category. But there might be a distinction; for example, an op-fibration is not the same thing as a [cofibration](wikipedia://en/1697216).

:::

::: {#o39 .entry cue=term name="codensity monad"}

**codensity monad**

[Codensity monad](wikipedia://en/61387397).

:::

::: {#o40 .entry cue=term name="coend"}

**coend**

The coend of a functor $F: C^{\text{op}} \times C \to X$ is the dual of the [end](wikipedia://en/3865669) of *F* and is denoted by

$\int^{c \in C} F(c, c)$. For example, if *R* is a ring, *M* a right *R*-module and *N* a left *R*-module, then the [tensor product](wikipedia://en/2993836) of *M* and *N* is

$M \otimes_R N = \int^{R} M \otimes_{\mathbb{Z}} N$ where *R* is viewed as a category with one object whose morphisms are the elements of *R*.

:::

::: {#o41 .entry cue=term name="coequalizer"}

**coequalizer**

The [coequalizer](wikipedia://en/431940) of a pair of morphisms $f, g: A \to B$ is the colimit of the pair. It is the dual of an equalizer.

:::

::: {#o42 .entry cue=term name="coherator"}

**coherator**

[coherator](https://en.wikipedia.org/wiki/Coherator)

:::

::: {#o43 .entry cue=term name="coherence theorem"}

**coherence theorem**

A [coherence theorem](https://en.wikipedia.org/wiki/Coherence_theorem) is a theorem of a form that states a weak structure is equivalent to a strict structure.

:::

::: {#o44 .entry cue=term name="coherent"}

**coherent**

A [coherent category](https://en.wikipedia.org/wiki/Coherent_category).

A [coherent topos](wikipedia://en/64383764).

:::

::: {#o45 .entry cue=term name="cohesive"}

**cohesive**

[cohesive category](https://en.wikipedia.org/wiki/Cohesive_category).

:::

::: {#o46 .entry cue=term name="coimage"}

**coimage**

The [coimage](wikipedia://en/632685) of a morphism *f*: *X* → *Y* is the coequalizer of $X \times_Y X \rightrightarrows X$.

:::

::: {#o47 .entry cue=term name="colored operad"}

**colored operad**

Another term for [multicategory](wikipedia://en/2145170), a generalized category where a morphism can have several domains. The notion of "colored operad" is more primitive than that of operad: in fact, an operad can be defined as a colored operad with a single object.

:::

::: {#o48 .entry cue=term name="comma"}

**comma**

Given functors $f: C \to B, g: D \to B$, the [comma category](wikipedia://en/840950) $(f \downarrow g)$ is a category where (1) the objects are morphisms $f(c) \to g(d)$ and (2) a morphism from $\alpha: f(c) \to g(d)$ to $\beta: f(c') \to g(d')$ consists of $c \to c'$ and $d \to d'$ such that $f(c) \to f(c') \overset{\beta}\to g(d')$ is $f(c) \overset{\alpha}\to g(d) \to g(d').$ For example, if *f* is the identity functor and *g* is the constant functor with a value *b*, then it is the slice category of *B* over an object *b*.

:::

::: {#o49 .entry cue=term name="comonad"}

**comonad**

A [comonad](https://en.wikipedia.org/wiki/Comonad) in a category *X* is a [comonoid](https://en.wikipedia.org/wiki/Comonoid) in the monoidal category of endofunctors of *X*.

:::

::: {#o50 .entry cue=term name="compact"}

**compact**

Probably synonymous with accessible.

:::

::: {#o51 .entry cue=term name="complete"}

**complete**

A category is [complete](wikipedia://en/62781) if all small limits exist.

:::

::: {#o52 .entry cue=term name="completeness"}

**completeness**

[Deligne's completeness theorem](wikipedia://en/82767134); see <https://www.math.ias.edu/~lurie/278xnotes/Lecture17X-Filtered.pdf>.

:::

::: {#o53 .entry cue=term name="composition"}

**composition**

A composition of morphisms in a category is part of the datum defining the category.

If $f: C \to D, \, g: D \to E$ are functors, then the composition $g \circ f$ or $gf$ is the functor defined by: for an object *x* and a morphism *u* in *C*, $(g \circ f)(x) = g(f(x)), \, (g \circ f)(u) = g(f(u))$.

Natural transformations are composed pointwise: if $\varphi: f \to g, \, \psi: g \to h$ are natural transformations, then $\psi \circ \varphi$ is the natural transformation given by $(\psi \circ \varphi)_x = \psi_x \circ \varphi_x$.

:::

::: {#o54 .entry cue=term name="computad"}

**computad**

[computad](https://en.wikipedia.org/wiki/Computad).

:::

::: {#o55 .entry cue=term name="concrete"}

**concrete**

A [concrete category](wikipedia://en/167001) *C* is a category such that there is a faithful functor from *C* to **[Set](wikipedia://en/26829)**; e.g., **[Vec](https://en.wikipedia.org/wiki/Category_of_vector_spaces)**, **[Grp](wikipedia://en/800092)** and **[Top](wikipedia://en/435051)**.

:::

::: {#o56 .entry cue=term name="cone"}

**cone**

A [cone](wikipedia://en/7533645) is a way to express the [universal property](wikipedia://en/32245) of a colimit (or dually a limit). One can show[^o57] that the colimit $\varinjlim$ is the left adjoint to the diagonal functor $\Delta: C \to \operatorname{Fct}(I, C)$, which sends an object *X* to the constant functor with value *X*; that is, for any *X* and any functor $f: I \to C$,

$\operatorname{Hom}(\varinjlim f, X) \simeq \operatorname{Hom}(f, \Delta_X),$ provided the colimit in question exists. The right-hand side is then the set of cones with vertex *X*.[^o58]

:::

::: {#o59 .entry cue=term name="connected"}

**connected**

A category is [connected](wikipedia://en/1411533) if, for each pair of objects *x*, *y*, there exists a finite sequence of objects *z*<sub>*i*</sub> such that $z_0 = x, z_n = y$ and either $\operatorname{Hom}(z_i, z_{i+1})$ or $\operatorname{Hom}(z_{i+1}, z_i)$ is nonempty for any *i*.

:::

::: {#o60 .entry cue=term name="conservative functor"}

**conservative functor**

A [conservative functor](wikipedia://en/49749141) is a functor that reflects isomorphisms. Many forgetful functors are conservative, but the forgetful functor from **Top** to **Set** is not conservative.

:::

::: {#o61 .entry cue=term name="constant"}

**constant**

A functor is [constant](https://en.wikipedia.org/wiki/Constant_functor) if it maps every object in a category to the same object *A* and every morphism to the identity on *A*. Put in another way, a functor $f: C \to D$ is constant if it factors as: $C \to \{ A \} \overset{i}\to D$ for some object *A* in *D*, where *i* is the inclusion of the discrete category { *A* }.

:::

::: {#o62 .entry cue=term name="contravariant functor"}

**contravariant functor**

A [contravariant functor](https://en.wikipedia.org/wiki/Contravariant_functor) *F* from a category *C* to a category *D* is a (covariant) functor from *C*<sup>op</sup> to *D*. It is sometimes also called a [presheaf](wikipedia://en/4840944) especially when *D* is **Set** or the variants. For example, for each set *S*, let $\mathfrak{P}(S)$ be the power set of *S* and for each function $f: S \to T$, define

$\mathfrak{P}(f): \mathfrak{P}(T) \to \mathfrak{P}(S)$ by sending a subset *A* of *T* to the pre-image $f^{-1}(A)$. With this, $\mathfrak{P}: \mathbf{Set} \to \mathbf{Set}$ is a contravariant functor.

:::

::: {#o63 .entry cue=term name="coproduct"}

**coproduct**

The [coproduct](wikipedia://en/310889) of a family of objects *X*<sub>*i*</sub> in a category *C* indexed by a set *I* is the inductive limit $\varinjlim$ of the functor $I \to C, \, i \mapsto X_i$, where *I* is viewed as a discrete category. It is the dual of the product of the family. For example, a coproduct in **[Grp](wikipedia://en/800092)** is a [free product](wikipedia://en/360036).

:::

::: {#o64 .entry cue=term name="core"}

**core**

The [core](https://en.wikipedia.org/wiki/Core_%28category_theory%29) of a category is the maximal groupoid contained in the category.

:::

::: {#o65 .entry cue=term name="cubical"}

**cubical**

A [cubical set](wikipedia://en/46250924) is an alternative for a simplicial set; a simplex is replaced by a cube.

:::

## D {#D}

::: {#o67 .entry cue=term name="Dagger compact category"}

**Dagger compact category**

[Dagger compact category](wikipedia://en/7155145).

:::

::: {#o68 .entry cue=term name="Day convolution"}

**Day convolution**

Given a group or monoid *M*, the [Day convolution](wikipedia://en/60061151) is the tensor product in $\mathbf{Fct}(M, \mathbf{Set})$.[^o69]

:::

::: {#o70 .entry cue=term name="Dendroidal"}

**Dendroidal**

[Dendroidal set](wikipedia://en/29199687).

:::

::: {#o71 .entry cue=term name="dense"}

**dense**

A [dense subcategory](https://en.wikipedia.org/wiki/Dense_subcategory) is another name for an [adequate subcategory](wikipedia://en/82474244).

:::

::: {#o72 .entry cue=term name="density theorem"}

**density theorem**

The [density theorem](wikipedia://en/54487799) states that every presheaf (a set-valued contravariant functor) is a colimit of representable presheaves. Yoneda's lemma embeds a category *C* into the category of presheaves on *C*. The density theorem then says the image is "dense", so to say. The name "density" is because of the analogy with the [Jacobson density theorem](wikipedia://en/488391) (or other variants) in abstract algebra.

:::

::: {#o73 .entry cue=term name="diagonal functor"}

**diagonal functor**

Given categories *I*, *C*, the [diagonal functor](wikipedia://en/4606683) is the functor

$\Delta: C \to \mathbf{Fct}(I, C), \, A \mapsto \Delta_A$ that sends each object *A* to the constant functor with value *A* and each morphism $f: A \to B$ to the natural transformation $\Delta_{f, i}: \Delta_A(i) = A \to \Delta_B(i) =B$ that is *f* at each *i*.

:::

::: {#o74 .entry cue=term name="diagram"}

**diagram**

Given a category *C*, a [diagram](wikipedia://en/7651625) in *C* is a functor $f: I \to C$ from a category *I*. For example, if $I = \mathbb{N}$ with no morphisms other than the identities, a diagram simply amounts to a sequence of objects. For a general *I*, typically there is a morphism between the images of objects in *I* under *f* (whence the term diagram).

[simplicial diagram](wikipedia://en/79777766), a diagram from the opposite $\Delta^{\textrm{op}}$ of the simplex category.

:::

::: {#o75 .entry cue=term name="diagrammatic set"}

**diagrammatic set**

A [diagrammatic set](https://en.wikipedia.org/wiki/Diagrammatic_set) is an alternative to a simplicial set or a cubical set.

:::

::: {#o76 .entry cue=term name="differential graded category"}

**differential graded category**

A [differential graded category](wikipedia://en/9492439) is a category whose Hom sets are equipped with structures of [differential graded modules](wikipedia://en/46781249). In particular, if the category has only one object, it is the same as a differential graded module.

:::

::: {#o77 .entry cue=term name="direct limit"}

**direct limit**

A [direct limit](wikipedia://en/211566) is the [colimit](https://en.wikipedia.org/wiki/Colimit) of a [direct system](https://en.wikipedia.org/wiki/Direct_system).

:::

::: {#o78 .entry cue=term name="discrete"}

**discrete**

A category is [discrete](wikipedia://en/808519) if each morphism is an identity morphism (of some object). For example, a set can be viewed as a discrete category.

:::

::: {#o79 .entry cue=term name="distributor"}

**distributor**

Another term for "profunctor".

:::

::: {#o80 .entry cue=term name="double"}

**double**

[double category](wikipedia://en/79772291).

:::

::: {#o81 .entry cue=term name="Dwyer–Kan equivalence"}

**Dwyer–Kan equivalence**

A [Dwyer–Kan equivalence](https://en.wikipedia.org/wiki/Dwyer–Kan_equivalence) is a generalization of an equivalence of categories to the simplicial context.[^o82]

:::

**empty**

::: {#o88 .entry cue=term name="end"}

**end**

The [end](wikipedia://en/3865669) of a functor $F: C^{\text{op}} \times C \to X$ is the limit

$\int_{c \in C} F(c, c) = \varprojlim (F^{\#}: C^{\#} \to X)$ where $C^{\#}$ is the category (called the [subdivision category](https://en.wikipedia.org/wiki/Subdivision_category) of *C*) whose objects are symbols $c^{\#}, u^{\#}$ for all objects *c* and all morphisms *u* in *C* and whose morphisms are $b^{\#} \to u^{\#}$ and $u^{\#} \to c^{\#}$ if $u: b \to c$ and where $F^{\#}$ is induced by *F* so that $c^{\#}$ would go to $F(c, c)$ and $u^{\#}, u: b \to c$ would go to $F(b, c)$. For example, for functors $F, G: C \to X$,

$\int_{c \in C} \operatorname{Hom}(F(c), G(c))$ is the set of natural transformations from *F* to *G*. For more examples, see [this mathoverflow thread](https://mathoverflow.net/q/78471). The dual of an end is a coend.

::: {#o89 .entry cue=term name="endofunctor"}

**endofunctor**

A functor between the same category.

::: {#o90 .entry cue=term name="enriched category"}

**enriched category**

Given a monoidal category (*C*, ⊗, 1), a [category enriched](https://en.wikipedia.org/wiki/Category_enriched) over *C* is, informally, a category whose Hom sets are in *C*. More precisely, a category *D* enriched over *C* is a data consisting of

A class of objects,

For each pair of objects *X*, *Y* in *D*, an object $\operatorname{Map}_D(X, Y)$ in *C*, called the [mapping object](https://en.wikipedia.org/wiki/Mapping_object) from *X* to *Y*,

For each triple of objects *X*, *Y*, *Z* in *D*, a morphism in *C*,

$$\circ: \operatorname{Map}_D(Y, Z) \otimes \operatorname{Map}_D(X, Y) \to \operatorname{Map}_D(X, Z),$$

called the composition,

For each object *X* in *D*, a morphism $1_X: 1 \to \operatorname{Map}_D(X, X)$ in *C*, called the unit morphism of *X* subject to the conditions that (roughly) the compositions are associative and the unit morphisms act as the multiplicative identity.

For example, a category enriched over sets is an ordinary category.

**essentially surjective**

**evaluation**

Given categories *C*, *D* and an object *A* in *C*, the [evaluation](https://en.wikipedia.org/wiki/Evaluation_%28category_theory%29) at *A* is the functor

$\mathbf{Fct}(C, D) \to D, \,\, F \mapsto F(A).$ For example, the [Eilenberg–Steenrod axioms](wikipedia://en/3122600) give an instance when the functor is an equivalence.

::: {#o97 .entry cue=term name="exact"}

**exact**

An [exact sequence](wikipedia://en/138215) is typically a sequence (from arbitrary negative integers to arbitrary positive integers) of maps

$$\cdots \to E_1 \overset{f_1}\to E_2 \overset{f_2}\to E_3 \to \cdots$$

such that the image of $f_i$ is the kernel of $f_{i+1}$. The notion can be generalized in various ways.

A short exact sequence is a sequence of the form $0 \to E \to F \to G \to 0$.

A functor (for example, between abelian categories) is said to be [exact](wikipedia://en/453945) if it takes short exact sequences to short exact sequences.

An [exact category](wikipedia://en/10987985) is roughly a category where there is the notion of a short exact sequence.

An [exact category in the sense of Barr](https://en.wikipedia.org/wiki/Exact_category_in_the_sense_of_Barr).

## F {#F}

::: {#o100 .entry cue=term name="faithful"}

**faithful**

A functor is [faithful](https://en.wikipedia.org/wiki/Faithful_functor) if it is injective when restricted to each [hom-set](https://en.wikipedia.org/wiki/Hom-set).

:::

::: {#o101 .entry cue=term name="fundamental category"}

**fundamental category**

The [fundamental category functor](https://en.wikipedia.org/wiki/Fundamental_category_functor) $\tau_1: s\mathbf{Set} \to \mathbf{Cat}$ is the left adjoint to the nerve functor *N*. For every category *C*, $\tau_1 NC = C$.

:::

::: {#o102 .entry cue=term name="fundamental groupoid"}

**fundamental groupoid**

The [fundamental groupoid](wikipedia://en/55264190) of a topological space *X* is a category where the objects are the points on *X* and the morphisms the homotopy classes of paths.

The fundamental groupoid of a Kan complex *X* is the category where an object is a 0-simplex (vertex) $\Delta^0 \to X$, a morphism is a homotopy class of a 1-simplex (path) $\Delta^1 \to X$ and a composition is determined by the Kan property.

:::

::: {#o103 .entry cue=term name="fibered category"}

**fibered category**

A functor π: *C* → *D* is said to exhibit *C* as a [category fibered over](https://en.wikipedia.org/wiki/Fibered_category) *D* if, for each morphism *g*: *x* → π(*y*) in *D*, there exists a π-cartesian morphism *f*: *x'* → *y* in *C* such that π(*f*) = *g*. If *D* is the category of affine schemes (say of finite type over some field), then π is more commonly called a [prestack](wikipedia://en/39547490). **Note**: π is often a forgetful functor and in fact the [Grothendieck construction](https://en.wikipedia.org/wiki/Grothendieck_construction) implies that every fibered category can be taken to be that form (up to equivalences in a suitable sense).

:::

::: {#o104 .entry cue=term name="fiber product"}

**fiber product**

Given a category *C* and a set *I*, the [fiber product](https://en.wikipedia.org/wiki/Fiber_product) over an object *S* of a family of objects *X*<sub>*i*</sub> in *C* indexed by *I* is the product of the family in the [slice category](https://en.wikipedia.org/wiki/Slice_category) $C_{/S}$ of *C* over *S* (provided there are $X_i \to S$). The fiber product of two objects *X* and *Y* over an object *S* is denoted by $X \times_S Y$ and is also called a [Cartesian square](https://en.wikipedia.org/wiki/Cartesian_square).

:::

::: {#o105 .entry cue=term name="fibrant"}

**fibrant**

An object is [fibrant](wikipedia://en/1782993) if the unique morphism from it to the final object is a fibration, when there is a notion of a fibration.

:::

::: {#o106 .entry cue=term name="filtered"}

**filtered**

A [filtered category](wikipedia://en/4322449) (also called a filtrant category) is a nonempty category with the properties (1) given objects *i* and *j*, there are an object *k* and morphisms *i* → *k* and *j* → *k* and (2) given morphisms *u*, *v*: *i* → *j*, there are an object *k* and a morphism *w*: *j* → *k* such that *w* ∘ *u* = *w* ∘ *v*. A category *I* is filtered if and only if, for each finite category *J* and functor *f*: *J* → *I*, the set $\varprojlim \operatorname{Hom}(f(j), i)$ is nonempty for some object *i* in *I*.

Given a cardinal number π, a category is said to be π-filtrant if, for each category *J* whose set of morphisms has cardinal number strictly less than π, the set $\varprojlim \operatorname{Hom}(f(j), i)$ is nonempty for some object *i* in *I*.

**free category**

The [free category](wikipedia://en/36769284) generated by a graph $G$ is a category together with the map $G \to UC$ = the underlying graph of $C$ such that (1) the objects are exactly the vertices of $G$ and (2) $G \to UD$ for a category $D$ uniquely factors through $G \to UC$. For example, $[n] = \{ 0, \cdots, n \}$ is a free category.

A [free functor](https://en.wikipedia.org/wiki/Free_functor) is a left adjoint to a forgetful functor. For example, for a ring *R*, the functor that sends a set *X* to the [free *R*-module](wikipedia://en/326454) generated by *X* is a free functor (whence the name).

**full**

A category *A* is a [full subcategory](https://en.wikipedia.org/wiki/Full_subcategory) of a category *B* if the inclusion functor from *A* to *B* is full.

::: {#o117 .entry cue=term name="functor"}

**functor**

Given categories *C*, *D*, a [functor](wikipedia://en/10987) *F* from *C* to *D* is a structure-preserving map from *C* to *D*; i.e., it consists of an object *F*(*x*) in *D* for each object *x* in *C* and a morphism *F*(*f*) in *D* for each morphism *f* in *C* satisfying the conditions: (1) $F(f \circ g) = F(f) \circ F(g)$ whenever $f \circ g$ is defined and (2) $F(\operatorname{id}_x) = \operatorname{id}_{F(x)}$. For example,

$\mathfrak{P}: \mathbf{Set} \to \mathbf{Set}, \, S \mapsto \mathfrak{P}(S)$, where $\mathfrak{P}(S)$ is the [power set](wikipedia://en/23799) of *S* is a functor if we define: for each function $f: S \to T$, $\mathfrak{P}(f): \mathfrak{P}(S) \to \mathfrak{P}(T)$ by $\mathfrak{P}(f)(A) = f(A)$.

:::

::: {#o118 .entry cue=term name="functor category"}

**functor category**

The [functor category](wikipedia://en/407039) **Fct**(*C*, *D*) or $D^C$ from a category *C* to a category *D* is the category where the objects are all the functors from *C* to *D* and the morphisms are all the natural transformations between the functors.

::: {#o151 .entry cue=term name="∞-category"}

**∞-category**

\[T\]he theory of ∞-categories is a semantic interpretation of the formal language of category theory. This means that one can systematically make sense of any statement formulated in the language of category theory in the setting of ∞-categories. An [∞-category](https://en.wikipedia.org/wiki/∞-category) is obtained from a category by replacing the class/set of objects and morphisms by the spaces of objects and morphisms. Precisely, an ∞-category *C* is a [simplicial set](wikipedia://en/1027784) satisfying the following condition: for each 0 \< *i* \< *n*,

every map of simplicial sets $f: \Lambda^n_i \to C$ extends to an *n*-simplex $f: \Delta^n \to C$ where Δ<sup>*n*</sup> is the standard *n*-simplex and $\Lambda^n_i$ is obtained from Δ<sup>*n*</sup> by removing the *i*-th face and the interior (see [Kan fibration#Definitions](wikipedia://en/8992759#Definitions)). For example, the [nerve of a category](https://en.wikipedia.org/wiki/Nerve_of_a_category) satisfies the condition and thus can be considered as an ∞-category.

**(∞, *n*)-category**

An [(∞, *n*)-category](https://en.wikipedia.org/wiki/%28∞,_n%29-category) is obtained from an ∞-category by replacing the space of morphisms by the (∞, *n* - 1)-category of morphisms.

An object *A* in an ∞-category *C* is initial if $\operatorname{Map}_C(A, B)$ is [contractible](wikipedia://en/1752414) for each object *B* in *C*.

::: {#o157 .entry cue=term name="interchange"}

**interchange**

The [interchange law](https://en.wikipedia.org/wiki/Interchange_law) says

$(\psi' \circ \varphi') * (\psi \circ \varphi) = (\psi' * \psi) \circ (\varphi' * \varphi)$ where $\circ, *$ denote [vertical composition](https://en.wikipedia.org/wiki/Vertical_composition) and [horizontal composition](https://en.wikipedia.org/wiki/Horizontal_composition). Together with preservation of identities, the law is equivalent to say

$* : \operatorname{Fct}(B, C) \times \operatorname{Fct}(A, B) \to \operatorname{Fct}(A, C)$ is a functor.

::: {#o158 .entry cue=term name="internal Hom"}

**internal Hom**

Given a [monoidal category](wikipedia://en/330604) (*C*, ⊗), the [internal Hom](https://en.wikipedia.org/wiki/Internal_Hom) is a functor $[-, -]: C^{\text{op}} \times C \to C$ such that $[Y, -]$ is the right adjoint to $- \otimes Y$ for each object *Y* in *C*. For example, the [category of modules](wikipedia://en/11231812) over a commutative ring *R* has the internal Hom given as $[M, N] = \operatorname{Hom}_R(M, N)$, the set of *R*-linear maps.

::: {#o159 .entry cue=term name="inverse"}

**inverse**

A morphism *f* is an [inverse](wikipedia://en/14907) to a morphism *g* if $g\circ f$ is defined and is equal to the identity morphism on the codomain of *g*, and $f\circ g$ is defined and equal to the identity morphism on the domain of *g*. The inverse of *g* is unique and is denoted by *g*<sup>−1</sup>. *f* is a left inverse to *g* if $f\circ g$ is defined and is equal to the identity morphism on the domain of *g*, and similarly for a right inverse.

An [inverse limit](wikipedia://en/15109) is the limit of an [inverse system](https://en.wikipedia.org/wiki/Inverse_system).

**Isbell**

## K {#K}

::: {#o164 .entry cue=term name="Kan"}

**Kan**

A [Kan complex](https://en.wikipedia.org/wiki/Kan_complex) is a [fibrant object](wikipedia://en/1782993) in the category of simplicial sets; i.e., the unique morphism from it to the final object is a fibration (Kan fibration). It is often taken as a model of an [∞-groupoid](wikipedia://en/40965675).

A [Kan fibration](wikipedia://en/8992759) between simplicial sets is a map having the right lifting property with respect to the horn inclusions $\Lambda^n_k \to \Delta^n$ for $n \ge 1$ and $0 \le k \le n$.

Consider the category of Kan complexes where each hom-set is a simplicoal set. The homotopy coherent nerve of it is an ∞-category denoted by **Kan**. In view of [homotopy hypothesis](wikipedia://en/40965653), the latter is often viewed as an ∞-category of spaces.

:::

::: {#o165 .entry cue=term name="Kan extension"}

**Kan extension**

Given a category *C*, the left [Kan extension](wikipedia://en/2502518) functor along a functor $f: I \to J$ is the left adjoint (if it exists) to $f^* = - \circ f: \operatorname{Fct}(J, C) \to \operatorname{Fct}(I, C)$ and is denoted by $f_!$. For any $\alpha: I \to C$, the functor $f_! \alpha: J \to C$ is called the left Kan extension of α along *f*.[^o166] One can show:

$(f_! \alpha)(j) = \varinjlim_{f(i) \to j} \alpha(i)$ where the colimit runs over all objects $f(i) \to j$ in the comma category.

The right Kan extension functor is the right adjoint (if it exists) to $f^*$ and is denoted by $f_*$.

[Ken Brown's lemma](wikipedia://en/79382796) gives a sufficient condition for a functor to preserve weak equivalences.

**Kleisli category**

Given a monad *T*, the [Kleisli category](wikipedia://en/3957200) of *T* is the full subcategory of the category of *T*-algebras (called Eilenberg–Moore category) that consists of free *T*-algebras.

::: {#o176 .entry cue=term name="limit"}

**limit**

The [limit](wikipedia://en/39248) (or [projective limit](https://en.wikipedia.org/wiki/Projective_limit)) of a functor $f: I^{\text{op}} \to \mathbf{Set}$ is

$$\varprojlim_{i \in I} f(i) = \{ (x_i|i) \in \prod_{i} f(i) \mid f(s)(x_j) = x_i \text{ for any } s: i \to j \}.$$

The limit $\varprojlim_{i \in I} f(i)$ of a functor $f: I^{\text{op}} \to C$ is an object, if any, in *C* that satisfies: for any object *X* in *C*, $\operatorname{Hom}(X, \varprojlim_{i \in I} f(i)) = \varprojlim_{i \in I} \operatorname{Hom}(X, f(i))$; i.e., it is an object representing the functor $X \mapsto \varprojlim_i \operatorname{Hom}(X, f(i)).$

The [colimit](https://en.wikipedia.org/wiki/Colimit) (or [inductive limit](https://en.wikipedia.org/wiki/Inductive_limit)) $\varinjlim_{i \in I} f(i)$ is the dual of a limit; i.e., given a functor $f: I \to C$, it satisfies: for any *X*, $\operatorname{Hom}(\varinjlim f(i), X) = \varprojlim \operatorname{Hom}(f(i), X)$. Explicitly, to give $\varinjlim f(i) \to X$ is to give a family of morphisms $f(i) \to X$ such that for any $i \to j$, $f(i) \to X$ is $f(i) \to f(j) \to X$. Perhaps the simplest example of a colimit is a [coequalizer](wikipedia://en/431940). For another example, take *f* to be the identity functor on *C* and suppose $L = \varinjlim_{X \in C} f(X)$ exists; then the identity morphism on *L* corresponds to a compatible family of morphisms $\alpha_X: X \to L$ such that $\alpha_L$ is the identity. If $f: X \to L$ is any morphism, then $f = \alpha_L \circ f = \alpha_X$; i.e., *L* is a final object of *C*.

::: {#o183 .entry cue=term name="monad"}

**monad**

A [monad](wikipedia://en/355140) in a category *X* is a [monoid object](https://en.wikipedia.org/wiki/Monoid_object) in the monoidal category of endofunctors of *X* with the monoidal structure given by composition. For example, given a group *G*, define an endofunctor *T* on **Set** by $T(X) = G \times X$. Then define the multiplication *μ* on *T* as the natural transformation $\mu: T \circ T \to T$ given by

$\mu_X: G \times (G \times X) \to G \times X, \,\, (g, (h, x)) \mapsto (gh, x)$ and also define the identity map *η* in the analogous fashion. Then (*T*, *μ*, *η*) constitutes a monad in **Set**. More substantially, an adjunction between functors $F: X \rightleftarrows A : G$ determines a monad in *X*; namely, one takes $T = G \circ F$, the identity map *η* on *T* to be a unit of the adjunction and also defines *μ* using the adjunction.

A functor is said to be [monadic](https://en.wikipedia.org/wiki/Monadic_functor) if it is a constituent of a monadic adjunction.

**monoid object**

A [monoid object](https://en.wikipedia.org/wiki/Monoid_object) in a monoidal category is an object together with the multiplication map and the identity map that satisfy the expected conditions like associativity. For example, a monoid object in **Set** is a usual monoid (unital semigroup) and a monoid object in **[*R*-mod](wikipedia://en/11231812)** is an [associative algebra](wikipedia://en/2112) over a commutative ring *R*.

**monomorphism**

A morphism *f* is a [monomorphism](wikipedia://en/59538) (also called monic) if $g=h$ whenever $f\circ g=f\circ h$; e.g., an [injection](wikipedia://en/45196) in **[Set](wikipedia://en/26829)**. In other words, *f* is the dual of an epimorphism.

## N {#N}

::: {#o191 .entry cue=term name="n-category"}

**n*-category**

\[T\]he issue of comparing definitions of weak *n*-category is a slippery one, as it is hard to say what it even *means* for two such definitions to be equivalent. \[...\] It is widely held that the structure formed by weak *n*-categories and the functors, transformations, ... between them should be a weak (*n* + 1)-category; and if this is the case then the question is whether your weak (*n* + 1)-category of weak *n-*categories is equivalent to mine—but whose definition of weak (*n* + 1)-category are we using here... ?

A [strict *n*-category](https://en.wikipedia.org/wiki/Strict_n-category) is defined inductively: a strict 0-category is a set and a strict *n*-category is a category whose Hom sets are strict (*n*-1)-categories. Precisely, a strict *n*-category is a category enriched over strict (*n*-1)-categories. For example, a strict 1-category is an ordinary category.

The notion of a [weak *n*-category](wikipedia://en/7349264) is obtained from the strict one by weakening the conditions like associativity of composition to hold only up to [coherent isomorphisms](https://en.wikipedia.org/wiki/Coherent_isomorphism) in the weak sense.

One can define an ∞-category as a kind of a colim of *n*-categories. Conversely, if one has the notion of a (weak) ∞-category (say a [quasi-category](wikipedia://en/28662219)) in the beginning, then a weak *n*-category can be defined as a type of a truncated ∞-category.

:::

::: {#o192 .entry cue=term name="natural"}

**natural**

A natural transformation is, roughly, a map between functors. Precisely, given a pair of functors *F*, *G* from a category *C* to category *D*, a [natural transformation](wikipedia://en/45022) φ from *F* to *G* is a set of morphisms in *D*

$\{ \phi_x: F(x) \to G(x) \mid x \in \operatorname{Ob}(C) \}$ satisfying the condition: for each morphism *f*: *x* → *y* in *C*, $\phi_y \circ F(f) = G(f) \circ \phi_x$. For example, writing $GL_n(R)$ for the group of invertible *n*-by-*n* matrices with coefficients in a commutative ring *R*, we can view $GL_n$ as a functor from the category **CRing** of commutative rings to the category **Grp** of groups. Similarly, $R \mapsto R^*$ is a functor from **CRing** to **Grp**. Then the [determinant](wikipedia://en/8468) det is a natural transformation from $GL_n$ to -<sup>\*</sup>.

A [natural isomorphism](https://en.wikipedia.org/wiki/Natural_isomorphism) is a natural transformation that is an isomorphism (i.e., admits the inverse).

::: {#o194 .entry cue=term name="nerve"}

**nerve**

The [nerve functor](https://en.wikipedia.org/wiki/Nerve_functor) *N* is the functor from **Cat** to *s***Set** given by $N(C)_n = \operatorname{Hom}_{\mathbf{Cat}}([n], C)$. For example, if $\varphi$ is a functor in $N(C)_2$ (called a 2-simplex), let $x_i = \varphi(i), \, 0 \le i \le 2$. Then $\varphi(0 \to 1)$ is a morphism $f: x_0 \to x_1$ in *C* and also $\varphi(1 \to 2) = g: x_1 \to x_2$ for some *g* in *C*. Since $0 \to 2$ is $0 \to 1$ followed by $1 \to 2$ and since $\varphi$ is a functor, $\varphi(0 \to 2) = g \circ f$. In other words, $\varphi$ encodes *f*, *g* and their compositions.

The [homotopy coherent nerve](https://en.wikipedia.org/wiki/Homotopy_coherent_nerve) of a simplicially enriched category is a generalization. For a 2-category, it is called the [Duskin nerve](https://en.wikipedia.org/wiki/Duskin_nerve) of it.

**product**

The [product of a family of categories](https://en.wikipedia.org/wiki/Product_of_categories) *C*<sub>*i*</sub>'s indexed by a set *I* is the category denoted by $\prod_i C_i$ whose class of objects is the product of the classes of objects of *C*<sub>*i*</sub>'s and whose hom-sets are $\prod_i \operatorname{Hom}_{\operatorname{C_i}}(X_i, Y_i)$; the morphisms are composed component-wise. ::: {#o238 .entry cue=term name="Serre functor"}

**Serre functor**

Given a *k*-linear category *C* over a field *k*, a [Serre functor](https://en.wikipedia.org/wiki/Serre_functor) $f: C \to C$ is an auto-equivalence such that $\operatorname{Hom}(A, B) \simeq \operatorname{Hom}(B,f(A))^*$ for any objects *A*, *B*.

:::

::: {#o239 .entry cue=term name="setoid"}

**setoid**

A [setoid](wikipedia://en/769434) is an object in the [free exact completion](https://en.wikipedia.org/wiki/Free_exact_completion) of the category of sets. If the axiom of choice is valid, it is the same as a set.

:::

::: {#o240 .entry cue=term name="sieve"}

**sieve**

In a category, a [sieve](wikipedia://en/2163544) on an object *x* is a set *S* of some morphisms with the target *x* such that, for each $f$ in $S$ and each morphism $g$ in the category, $f \circ g$ is in $S$ if the composition is defined.[^o241]

:::

::: {#o242 .entry cue=term name="simple object"}

**simple object**

A simple object in an abelian category is an object *A* that is not isomorphic to the zero object and whose every [subobject](wikipedia://en/540476) is isomorphic to zero or to *A*. For example, a [simple module](wikipedia://en/29430) is precisely a simple object in the category of (say left) modules.

:::

::: {#o243 .entry cue=term name="simplex category"}

**simplex category**

The [simplex category](wikipedia://en/1028841) Δ is the category where an object is a set \[*n*\] = { 0, 1, …, *n* }, n ≥ 0, totally ordered in the standard way and a morphism is an order-preserving function.

:::

::: {#o244 .entry cue=term name="simplicial category"}

**simplicial category**

A category enriched over simplicial sets.

:::

::: {#o245 .entry cue=term name="Simplicial localization"}

**Simplicial localization**

[Simplicial localization](wikipedia://en/40966773) is a method of localizing a category.

:::

::: {#o246 .entry cue=term name="simplicial object"}

**simplicial object**

A [simplicial object](https://en.wikipedia.org/wiki/Simplicial_object) in a category *C* is roughly a sequence of objects $X_0, X_1, X_2, \dots$ in *C* that forms a simplicial set. In other words, it is a covariant or contravariant functor Δ → *C*. For example, a [simplicial presheaf](wikipedia://en/39611193) is a simplicial object in the category of presheaves.

:::

::: {#o247 .entry cue=term name="Simpson"}

**Simpson**

[Simpson's semi-strictification conjecture](https://en.wikipedia.org/wiki/Simpson's_semi-strictification_conjecture) (as this is a red link, for now, see <https://ncatlab.org/nlab/show/Simpson%27s+conjecture>).

:::

::: {#o248 .entry cue=term name="simplicial set"}

**simplicial set**

A [simplicial set](wikipedia://en/1027784) is a contravariant functor from Δ to **Set**, where Δ is the [simplex category](wikipedia://en/1028841), a category whose objects are the sets \[*n*\] = { 0, 1, …, *n* } and whose morphisms are order-preserving functions. One writes $X_n = X([n])$ and an element of the set $X_n$ is called an *n*-simplex. For example, $\Delta^n = \operatorname{Hom}_{\Delta}(-, [n])$ is a simplicial set called the standard *n*-simplex. By Yoneda's lemma, $X_n \simeq \operatorname{Nat}(\Delta^n, X)$.

:::

::: {#o249 .entry cue=term name="site"}

**site**

A category equipped with a [Grothendieck topology](wikipedia://en/12910).

:::

::: {#o250 .entry cue=term name="skeletal"}

**skeletal**

A category is [skeletal](wikipedia://en/1812151) if isomorphic objects are necessarily identical.

A (not unique) [skeleton](wikipedia://en/1812151) of a category is a full subcategory that is skeletal.

:::

::: {#o251 .entry cue=term name="slice"}

**slice**

Given a category *C* and an object *A* in it, the [slice category](https://en.wikipedia.org/wiki/Slice_category) *C*<sub>/*A*</sub> of *C* over *A* is the category whose objects are all the morphisms in *C* with codomain *A*, whose morphisms are morphisms in *C* such that if *f* is a morphism from $p_X: X \to A$ to $p_Y: Y \to A$, then $p_Y \circ f = p_X$ in *C* and whose composition is that of *C*.

:::

::: {#o252 .entry cue=term name="small"}

**small**

A [small category](https://en.wikipedia.org/wiki/Small_category) is a category in which the class of all morphisms is a [set](wikipedia://en/26691) (i.e., not a [proper class](https://en.wikipedia.org/wiki/Proper_class)); otherwise **large**. A category is **locally small** if the morphisms between every pair of objects *A* and *B* form a set. Some authors assume a foundation in which the collection of all classes forms a "conglomerate", in which case a **quasicategory** is a category whose objects and morphisms merely form a [conglomerate](wikipedia://en/48611088).[^o253] (NB: some authors use the term "quasicategory" with a different meaning.[^o254])

An object in a category is said to be [small](https://en.wikipedia.org/wiki/Small_object) if it is κ-compact for some regular cardinal κ. The notion prominently appears in Quiilen's [small object argument](wikipedia://en/79556759) (cf. https://ncatlab.org/nlab/show/small+object+argument)

:::

::: {#o255 .entry cue=term name="species"}

**species**

A [(combinatorial) species](wikipedia://en/160076) is an endofunctor on the groupoid of finite sets with bijections. It is categorically equivalent to a [symmetric sequence](https://en.wikipedia.org/wiki/Symmetric_sequence).

:::

::: {#o256 .entry cue=term name="spherical"}

**spherical**

[Spherical category](wikipedia://en/41038739).

:::

::: {#o257 .entry cue=term name="stable"}

**stable**

An ∞-category is [stable](wikipedia://en/42081371) if (1) it has a zero object, (2) every morphism in it admits a fiber and a cofiber and (3) a triangle in it is a fiber sequence if and only if it is a cofiber sequence.

:::

::: {#o258 .entry cue=term name="strict"}

**strict**

A morphism *f* in a category admitting finite limits and finite colimits is [strict](https://en.wikipedia.org/wiki/Strict_morphism) if the natural morphism $\operatorname{Coim}(f) \to \operatorname{Im}(f)$ is an isomorphism.

A [strict epimorphism](https://en.wikipedia.org/wiki/Strict_epimorphism) *f* is an eqimorphism such that for each pair of morphisms $g, h$ such that $f \circ g = f \circ h$, we have $f$ is the coequalizer of $g, h$.

A [strict monomorphism](https://en.wikipedia.org/wiki/Strict_monomorphism) is a morphism such that it is a strict epimorphism in the opposite category.

:::

::: {#o259 .entry cue=term name="strict n-category"}

**strict *n*-category**

A strict 0-category is a set and for any integer *n* > 0, a [strict *n*-category](https://en.wikipedia.org/wiki/Strict_n-category) is a category enriched over strict (*n*-1)-categories. For example, a strict 1-category is an ordinary category. **Note**: the term "*n*-category" typically refers to "[weak *n*-category](wikipedia://en/7349264)"; not strict one.

:::

::: {#o260 .entry cue=term name="strictification"}

**strictification**

A [strictification](https://en.wikipedia.org/wiki/Strictification) is a process of replacing equalities holding weakly (i.e., up to coherent isomorphisms) by actual equalities.

:::

::: {#o261 .entry cue=term name="string"}

**string**

[String diagram](wikipedia://en/3967296)

:::

::: {#o262 .entry cue=term name="subcanonical"}

**subcanonical**

A topology on a category is [subcanonical](https://en.wikipedia.org/wiki/Subcanonical) if every representable contravariant functor on *C* is a sheaf with respect to that topology.[^o263] Generally speaking, some [flat topology](wikipedia://en/10538912) may fail to be subcanonical; but flat topologies appearing in practice tend to be subcanonical.

:::

::: {#o264 .entry cue=term name="subcategory"}

**subcategory**

A category *A* is a [subcategory](wikipedia://en/310959) of a category *B* if there is an inclusion functor from *A* to *B*.

:::

::: {#o265 .entry cue=term name="subobject"}

**subobject**

Given an object *A* in a category, a [subobject](wikipedia://en/540476) of *A* is an equivalence class of monomorphisms to *A*; two monomorphisms *f*, *g* are considered equivalent if *f* factors through *g* and *g* factors through *f*.

A [subobject classifier](wikipedia://en/366909) classifies subobjects. For example, for **Set**, the two-element set $\Omega = \{ 0, 1 \}$ serves as a subobject classifier since specifying a subset of a set amounts to partitioning the set into two parts. More precisely, each subset of a set $S$ is the fiber $\chi^{-1}(1)$ of some function $\chi : S \to \Omega$; that is, each set inclusion is classified in the sense it is obtained by pulling back the inclusion $\{ 1 \} \hookrightarrow \Omega$.

:::

::: {#o266 .entry cue=term name="subquotient"}

**subquotient**

A [subquotient](wikipedia://en/1639294) is a quotient of a subobject.

:::

::: {#o267 .entry cue=term name="subterminal object"}

**subterminal object**

A [subterminal object](wikipedia://en/49651604) is an object *X* such that every object has at most one morphism into *X*.

:::

::: {#o268 .entry cue=term name="surface"}

**surface**

A [surface diagram](https://en.wikipedia.org/wiki/Surface_diagram) is a higher-dimensional generalization of a string diagram. For now, see https://ncatlab.org/toddtrimble/published/Surface+diagrams

:::

::: {#o269 .entry cue=term name="symmetric monoidal category"}

**symmetric monoidal category**

A [symmetric monoidal category](wikipedia://en/3865249) is a [monoidal category](wikipedia://en/330604) (i.e., a category with ⊗) that has maximally symmetric braiding.

:::

::: {#o270 .entry cue=term name="symmetric sequence"}

**symmetric sequence**

A [symmetric sequence](https://en.wikipedia.org/wiki/Symmetric_sequence) is a sequence of objects with actions of [symmetric groups](wikipedia://en/28901). It is categorically equivalent to a [(combinatorial) species](wikipedia://en/160076).

:::

**syntactic category**

[syntactic category](https://en.wikipedia.org/wiki/Syntactic_category_%28mathematics%29)

## T {#T}

::: {#o273 .entry cue=term name="t-structure"}

**t-structure**

A [t-structure](wikipedia://en/1798923) is an additional structure on a [triangulated category](wikipedia://en/1679700) (more generally [stable ∞-category](wikipedia://en/42081371)) that axiomatizes the notions of complexes whose cohomology concentrated in non-negative degrees or non-positive degrees.

:::

::: {#o274 .entry cue=term name="Tannakian duality"}

**Tannakian duality**

The [Tannakian duality](https://en.wikipedia.org/wiki/Tannakian_duality) states that, in an appropriate setup, to give a morphism $f: X \to Y$ is to give a pullback functor $f^*$ along it. In other words, the Hom set $\operatorname{Hom}(X, Y)$ can be identified with the functor category $\operatorname{Fct}(D(Y), D(X))$, perhaps in the [derived sense](wikipedia://en/40778281), where $D(X)$ is the category associated to *X* (e.g., the derived category).[^o275][^o276]

:::

::: {#o277 .entry cue=term name="tensor category"}

**tensor category**

Usually synonymous with [monoidal category](wikipedia://en/330604) (though some authors distinguish between the two concepts.)

:::

::: {#o278 .entry cue=term name="tensor triangulated category"}

**tensor triangulated category**

A [tensor triangulated category](https://en.wikipedia.org/wiki/Tensor_triangulated_category) is a category that carries the structure of a symmetric monoidal category and that of a triangulated category in a compatible way.

:::

::: {#o279 .entry cue=term name="tensor product"}

**tensor product**

Given a monoidal category *B*, the **tensor product of functors** $F: C^{\text{op}} \to B$ and $G: C \to B$ is the coend:

$$F \otimes_C G = \int^{c \in C} F(c) \otimes G(c).$$

:::

::: {#o280 .entry cue=term name="terminal"}

**terminal**

An object *A* is [terminal](https://en.wikipedia.org/wiki/Terminal_object) (also called final) if there is exactly one morphism from each object to *A*; e.g., [singletons](wikipedia://en/381798) in **[Set](wikipedia://en/26829)**. It is the dual of an [initial object](https://en.wikipedia.org/wiki/Initial_object).

An object *A* in an ∞-category *C* is terminal if $\operatorname{Map}_C(B, A)$ is [contractible](wikipedia://en/1752414) for every object *B* in *C*. See [Quasi-category#Final objects and final maps](wikipedia://en/28662219#Final_objects_and_final_maps).

:::

::: {#o281 .entry cue=term name="Theta category"}

**Theta category**

[Joyal's theta category](wikipedia://en/79589477) is an alternative to the simplex category, that can be also used to defined an ∞-category.

:::

::: {#o282 .entry cue=term name="thick subcategory"}

**thick subcategory**

A full subcategory of an abelian category is [thick](https://en.wikipedia.org/wiki/Thick_subcategory) if it is closed under extensions.

:::

::: {#o283 .entry cue=term name="thin"}

**thin**

A [thin category](wikipedia://en/31353487) is a category where there is at most one morphism between any pair of objects.

:::

::: {#o284 .entry cue=term name="tiny"}

**tiny**

A [tiny object](https://en.wikipedia.org/wiki/Tiny_object). For now, see https://ncatlab.org/nlab/show/tiny+object

:::

::: {#o285 .entry cue=term name="topological"}

**topological**

A [topological concrete category](https://en.wikipedia.org/wiki/Topological_concrete_category).

A [topological topos](https://en.wikipedia.org/wiki/Topological_topos), a possible substitute for the category of topological spaces. See https://golem.ph.utexas.edu/category/2014/04/on\_a\_topological\_topos.html

:::

::: {#o286 .entry cue=term name="transfinite"}

**transfinite**

A [transfinite composition](https://en.wikipedia.org/wiki/Transfinite_composition) is a composition involving infinitely many morphisms. See [direct limit](wikipedia://en/211566) and [inverse limit](wikipedia://en/15109)

:::

::: {#o287 .entry cue=term name="triangulated category"}

**triangulated category**

A [triangulated category](wikipedia://en/1679700) is a category where one can talk about distinguished triangles, generalization of exact sequences. An abelian category is a prototypical example of a triangulated category. A [derived category](wikipedia://en/985897) is a triangulated category that is not necessary an abelian category.

:::

## U {#U}

::: {#o289 .entry cue=term name="U-category"}

**U-category**

For a universe *U*, a [U-category](https://en.wikipedia.org/wiki/U-category) is a category in which each hom-set is an element of *U* (i.e., a category that is locally *U*-small).

:::

::: {#o290 .entry cue=term name="universal"}

**universal**

Given a functor $f: C \to D$ and an object *X* in *D*, a [universal morphism](https://en.wikipedia.org/wiki/Universal_morphism) from *X* to *f* is an initial object in the [comma category](wikipedia://en/840950) $(X \downarrow f)$. (Its dual is also called a universal morphism.) For example, take *f* to be the forgetful functor $\mathbf{Vec}_k \to \mathbf{Set}$ and *X* a set. An initial object of $(X \downarrow f)$ is a function $j: X \to f(V_X)$. That it is initial means that if $k: X \to f(W)$ is another morphism, then there is a unique morphism from *j* to *k*, which consists of a linear map $V_X \to W$ that extends *k* via *j*; that is to say, $V_X$ is the [free vector space](https://en.wikipedia.org/wiki/Free_vector_space) generated by *X*.

Stated more explicitly, given *f* as above, a morphism $X \to f(u_X)$ in *D* is universal if and only if the natural map

$\operatorname{Hom}_C(u_X, c) \to \operatorname{Hom}_D(X, f(c)), \, \alpha \mapsto (X \to f(u_x) \overset{f(\alpha)}\to f(c))$ is bijective. In particular, if $\operatorname{Hom}_C(u_X, -) \simeq \operatorname{Hom}_D(X, f(-))$, then taking *c* to be *u*<sub>*X*</sub> one gets a universal morphism by sending the identity morphism. In other words, having a universal morphism is equivalent to the representability of the functor $\operatorname{Hom}_D(X, f(-))$.

:::

::: {#o291 .entry cue=term name="universe"}

**universe**

A [(Grothendieck) universe](wikipedia://en/1072144) *U* is a set such that

If $x \in y \in U$, then $x \in U$,

For $x, y$ in $U$ (possibly the same), $\{ x, y \} \in U$,

For $x$ in $U$, the power set of $x$ is in $U$,

For each function $f : x \to U$ with $x \in U$, the union $\cup_{i \in x} f(i)$ is in $U$,

$\mathbb{N} \in U$. A formulation of a functor category cannot usually be done inside the given universe *U*. Indeed, $\mathsf{Fct}(U, \{ 0, 1 \})$ amounts to the power set of *U*, which is not an element of *U*.

:::

## Y {#Y}

::: {#o299 .entry cue=term name="Yoneda"}

**Yoneda**

Yoneda’s Lemma asserts ... in more evocative terms, a mathematical object X is best thought of in the context of a category surrounding it, and is determined by the network of relations it enjoys with all the objects of that category. Moreover, to understand X it might be more germane to deal directly with the functor representing it. This is reminiscent of Wittgenstein’s ’language game’; i.e., that the meaning of a word is—in essence—determined by, in fact is nothing more than, its relations to all the utterances in a language. The [Yoneda lemma](wikipedia://en/34359) says: for each set-valued contravariant functor *F* on *C* and an object *X* in *C*, there is a natural bijection

$F(X) \simeq \operatorname{Nat}(\operatorname{Hom}_C(-, X), F)$ where Nat means the set of natural transformations. In particular, the functor

$y: C \to \mathbf{Fct}(C^{\text{op}}, \mathbf{Set}), \, X \mapsto \operatorname{Hom}_C(-, X)$ is fully faithful and is called the Yoneda embedding.[^o300]

If $F: C \to D$ is a functor and *y* is the Yoneda embedding of *C*, then the [Yoneda extension](https://en.wikipedia.org/wiki/Yoneda_extension) of *F* is the left Kan extension of *F* along *y*.

[2-Yoneda lemma](wikipedia://en/79738538) is an extension of the Yoneda lemma to 2-categories.

:::
