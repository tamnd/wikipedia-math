# Blum axioms

::: {#o1 .subject cue=lead name="Blum axioms"}

In [computational complexity theory](wikipedia://en/7543) the **Blum axioms** or **Blum complexity axioms** are [axioms](https://en.wikipedia.org/wiki/Axioms) that specify desirable properties of complexity measures on the set of [computable functions](wikipedia://en/1139338). The axioms were first defined by [Manuel Blum](https://en.wikipedia.org/wiki/Manuel_Blum) in 1967.[^o2]

:::

Importantly, [Blum's speedup theorem](wikipedia://en/2757528) and the [gap theorem](wikipedia://en/2815277) hold for any complexity measure satisfying these axioms. The most well-known measures satisfying these axioms are those of time (i.e., running time) and space (i.e., memory usage).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

To begin, we list all [partial computable functions](https://en.wikipedia.org/wiki/Partial_computable_functions). That is, we assign a computable [numbering](wikipedia://en/2399097) of these functions: $\varphi_0, \varphi_1, \dots$. For example, we may specify a specific [programming language](wikipedia://en/23015), then assign $\varphi_n$ to be the [length-lexicographically](https://en.wikipedia.org/wiki/Shortlex) *n*-th syntactically valid program according to that. Two programs $\varphi_n, \varphi_m$ may compute the exact same [partial function](wikipedia://en/23577), but have different numberings. This allows us to distinguish their "complexity"

Abstractly, to say that we are measuring the "complexity" of program $\varphi_n$ means finding a function $\Phi_n$, such that for any program input $x$, the complexity/cost of computing $\varphi_n$ on that input is $\Phi_n(x)$. If program $\varphi_n$ does not halt on $x$, then $\Phi_n(x)$ should be undefined. Otherwise, $\Phi_n(x)$ should be a definite [natural number](wikipedia://en/21474). This gives us the first axiom:

- The [domains](wikipedia://en/50263) of $\varphi_i$ and $\Phi_i$ are identical.

Further, the complexity measure should be computable in some sense, for non-computable complexity measures are not interesting in practice. This gives us the second axiom:

- There is a program that, given any $i, x, c \in \mathbb{N}$, decides whether $\Phi_i(x) \leq c$. Note that if $\Phi_i(x)$ is undefined, then by definition $\Phi_i(x) \leq c$ is FALSE for all $c \in \mathbb{N}$. In other words, the set $\{(i,x,c) \in \mathbb{N}^3 \mid \Phi_i(x) = c\}$ is [computable](wikipedia://en/332264).

These are the **Blum axioms**. A **Blum complexity measure** is a pairing $(\varphi, \Phi)$ that satisfies the Blum axioms.

Given a Blum complexity measure, and any total computable function $f$, we define $C[f]$ to be the class of functions of **complexity class** bounded by $f$. That is, $C[f]$ consists of total computable functions $\phi$, such that there exists some $\varphi_n$, such that $\forall x, \; \Phi_n(x) \leq f(x)$.

The definition of complexity class is sometimes loosened to $\bar C[f]$, the class of functions bounded by $f$ for *almost all* inputs. That is, $\bar C[f]$ consists of total computable functions $\phi$, such that there exists some $\varphi_n$, such that $\Phi_n(x) \leq f(x)$ for all but finitely many $x$.

::: {#o6 .example cue=heading name="Examples"}

### Examples {#Examples}

[Time complexity](wikipedia://en/405944) is a Blum complexity measure. To decide whether $\Phi_i(x) \leq c$, simulate $\varphi_i(x)$ for $c$ steps. If the machine halts before $c$ steps are done, then output TRUE, else output FALSE.

Similarly, [space complexity](wikipedia://en/338946) (or any computable combination of time and space), is a Blum complexity measure.

$(\varphi, \varphi)$ is *not* a complexity measure, since it fails the second axiom.

:::

## Properties {#Properties}

Assume all statements begin with "For any Blum complexity measure $(\varphi, \Phi)$...".

There are arbitrarily difficult ways of computing any function: for any total computable $f$, and any partial computable $\phi$, there exists some $\varphi_n$ such that $\phi = \varphi_n$, and for any $x$, if $\varphi_n(x)$ is defined, then $\Phi_n(x) > f(x)$.[^o9]

There are functions that are arbitrarily high in complexity class: for any total computable $f$, there exists total computable functions not in $\bar C[f]$.[^o9]

[Blum's speedup theorem](wikipedia://en/2757528).

[Gap theorem](wikipedia://en/2815277): Given any total computable $g$, there exists a total computable function $f$ such that $C[f] = C[g\circ f]$.

The construction is constructive. That is, the proof of the theorem is simply a program that, given a program computing $f$, outputs a program computing $g$.[^o9]

The [McCreight](https://en.wikipedia.org/wiki/Edward_M._McCreight) and [Meyer](https://en.wikipedia.org/wiki/Albert_R._Meyer) union theorem:[^o10] Let $f(n, x)$ be a total computable function, such that for any $n\in \mathbb{N}$, $f(n+1, x) > f(n, x)$ for all but finitely many $x$. Then there exists a total computable function $F$ such that $C[F] = \bigcup_{n \in \mathbb{N}} C[f(n, \cdot)]$.

[Compression theorem](wikipedia://en/2817175):[^o9] Let $g(x, n)$ be a total computable function. There exists a total computable function $f$ such that, for any $n \in \mathbb{N}$:

- If $\varphi_n(x)$ is defined, then $\varphi_{f(n)}(x) < x$. This condition is used to avoid trivially stacking up complexity in the output size.
- For any program $m$ such that $\varphi_m = \varphi_{f(n)}$, we have $\Phi_m(x) \geq \Phi_n(x)$ for almost all $x$. This gives the universal lower bound.
- $\Phi_{f(n)}(x) \leq g(x, \Phi_n(x))$ for almost all $x$. This gives the existential upper bound.

:::

## Complexity classes {#Complexity_classes}

For a [total computable function](https://en.wikipedia.org/wiki/Total_computable_function) $f$ [complexity classes](wikipedia://en/502426) of computable functions can be defined as

$$C(f) := \{ \varphi_i \in \mathbf{P}^{(1)} \mid \forall x.\ \Phi_i(x) \leq f(x) \}$$

$$C^0(f) := \{ h \in C(f) \mid \mathrm{codom}(h) \subseteq \{0,1\} \}$$

$C(f)$ is the set of all computable functions with a complexity less than $f$. $C^0(f)$ is the set of all [boolean-valued functions](wikipedia://en/2757237) with a complexity less than $f$. If we consider those functions as [indicator functions](wikipedia://en/240790) on sets, $C^0(f)$ can be thought of as a complexity class of sets.
