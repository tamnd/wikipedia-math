# Portmanteau test

::: {#o1 .subject cue=lead name="Portmanteau test"}

A **portmanteau test** is a type of [statistical hypothesis test](wikipedia://en/30284) in which the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) is well specified, but the [alternative hypothesis](https://en.wikipedia.org/wiki/Alternative_hypothesis) is more loosely specified. Tests constructed in this context can have the property of being at least moderately [powerful](https://en.wikipedia.org/wiki/Statistical_power) against a wide range of departures from the null hypothesis. Thus, in [applied statistics](https://en.wikipedia.org/wiki/Applied_statistics), a portmanteau test provides a reasonable way of proceeding as a general check of a [model's](wikipedia://en/27576) match to a dataset where there are many different ways in which the model may depart from the underlying [data generating process](wikipedia://en/11501746). The use of such tests avoids having to be very specific about the particular type of departure being tested.

:::

## Examples {#Examples}

In [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis), two well-known versions of a **portmanteau test** are available for testing for [autocorrelation](wikipedia://en/2724) in the residuals of a model: it tests whether any of a group of [autocorrelations](wikipedia://en/2724) of the residual [time series](wikipedia://en/406624) are different from zero. This test is the [Ljung–Box test](wikipedia://en/6534294),[^o4] which is an improved version of the [Box–Pierce test](https://en.wikipedia.org/wiki/Box–Pierce_test),[^o5] having been devised at essentially the same time; a seemingly trivial simplification (omitted in the improved test) was found to have a deleterious effect.[^o4] This portmanteau test is useful in working with [ARIMA](https://en.wikipedia.org/wiki/ARIMA) models.

In the context of [regression analysis](wikipedia://en/826997), including regression analysis with [time series](wikipedia://en/406624) structures, a **portmanteau test** has been devised,[^o6] which allows a general test to be made for the possibility that a range of types nonlinear transformations of combinations of the [explanatory variables](https://en.wikipedia.org/wiki/Independent_and_dependent_variables) should have been included in addition to a selected model structure.[^o7]
