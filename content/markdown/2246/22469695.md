# Color-coding

::: {#o1 .subject cue=lead name="Color-coding"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science) and [graph theory](wikipedia://en/12401), the term **color-coding** refers to an [algorithmic technique](wikipedia://en/60310734) which is useful in the discovery of [network motifs](https://en.wikipedia.org/wiki/Network_motif). For example, it can be used to detect a [simple path](wikipedia://en/638889) of length $k$ in a given [graph](wikipedia://en/12401). The traditional color-coding algorithm is [probabilistic](https://en.wikipedia.org/wiki/Probabilistic_algorithms), but it can be [derandomized](https://en.wikipedia.org/wiki/Derandomization#Derandomization) without much overhead in the running time.

:::

Color-coding also applies to the detection of [cycles](wikipedia://en/168609) of a given length, and more generally it applies to the [subgraph isomorphism problem](https://en.wikipedia.org/wiki/Subgraph_isomorphism) (an [NP-complete](https://en.wikipedia.org/wiki/NP-complete) problem), where it yields [polynomial time algorithms](https://en.wikipedia.org/wiki/Polynomial_time) when the subgraph pattern that it is trying to detect has bounded [treewidth](wikipedia://en/3987086).

The color-coding method was proposed and analyzed in 1994 by [Noga Alon](wikipedia://en/4939651), [Raphael Yuster](wikipedia://en/79944748), and [Uri Zwick](https://en.wikipedia.org/wiki/Uri_Zwick).[^o2][^o3]

::: {#o5 .statement cue=heading name="Results"}

## Results {#Results}

The following results can be obtained through the method of color-coding:

- For every fixed constant $k$, if a graph $G = (V, E)$ contains a simple cycle of size $k$, then such a cycle can be found in:
  - $O(|V|^\omega)$ expected time, or
  - $O(|V|^\omega \log |V|)$ worst-case time, where $\omega$ is the exponent of [matrix multiplication](wikipedia://en/125280).[^o6]
- For every fixed constant $k$, and every graph $G = (V, E)$ that is in any nontrivial [minor-closed graph family](https://en.wikipedia.org/wiki/Minor_%28graph_theory%29#Minor-closed_graph_families) (e.g., a [planar graph](wikipedia://en/24314)), if $G$ contains a simple cycle of size $k$, then such cycle can be found in:
  - $O(V)$ expected time, or
  - $O(V \log V)$ worst-case time.
- If a graph $G = (V, E)$ contains a subgraph isomorphic to a bounded [treewidth](wikipedia://en/3987086) graph which has $O(\log V)$ vertices, then such a subgraph can be found in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).

:::

::: {#o8 .definition kind=definition/construction cue=heading name="The method"}

## The method {#The_method}

To solve the problem of finding a subgraph $H = (V_H, E_H)$ in a given graph $G = (V, E)$, where $H$ can be a path, a cycle, or any bounded [treewidth](wikipedia://en/3987086) graph where $|V_H| = O(\log |V|)$, the method of color-coding begins by randomly coloring each vertex of $G$ with $k = |V_H|$ colors, and then tries to find a colorful copy of $H$ in colored $G$. Here, a graph is colorful if every vertex in it is colored with a distinct color. This method works by repeating (1) random coloring a graph and (2) finding colorful copy of the target subgraph, and eventually the target subgraph can be found if the process is repeated a sufficient number of times.

Suppose a copy of $H$ in $G$ becomes colorful with some non-zero probability $p$. It immediately follows that if the random coloring is repeated $\tfrac{1}{p}$ times, then this copy is expected to become colorful once. Note that though $p$ is small, it is shown that if $|V_H| = O(\log |V|)$, $p$ is only polynomially small. Suppose again there exists an algorithm such that, given a graph $G$ and a coloring which maps each vertex of $G$ to one of the $k$ colors, it finds a copy of colorful $H$, if one exists, within some runtime $O(r)$. Then the expected time to find a copy of $H$ in $G$, if one exists, is $O(\tfrac{r}{p})$.

Sometimes it is also desirable to use a more restricted version of colorfulness. For example, in the context of finding cycles in [planar graphs](https://en.wikipedia.org/wiki/Planar_graphs), it is possible to develop an algorithm that finds well-colored cycles. Here, a cycle is well-colored if its vertices are colored by consecutive colors.

::: {#o10 .example cue=heading name="Example"}

### Example {#Example}

An example would be finding a simple cycle of length $k$ in graph $G = (V, E)$.

By applying random coloring method, each simple cycle has a probability of $k!/k^k > e^{-k}$ to become colorful, since there are $k^k$ ways of coloring the $k$ vertices on the cycle, among which there are $k!$ colorful occurrences. Then an algorithm (described next) can be used to find colorful cycles in the randomly colored graph $G$ in time $O(V^\omega)$, where $\omega$ is the matrix multiplication constant. Therefore, it takes $e^k\cdot O(V^\omega)$ overall time to find a simple cycle of length $k$ in $G$.

The colorful cycle-finding algorithm works by first finding all pairs of vertices in $V$ that are connected by a simple path of length $k - 1$, and then checking whether the two vertices in each pair are connected. Given a coloring function $c : V \to \{1, ..., k\}$ to color graph $G$, enumerate all partitions of the color set $\{1, ..., k\}$ into two subsets $C_{1}, C_{2}$ of size $k/2$ each. Note that $V$ can be divided into $V_{1}$ and $V_{2}$ accordingly, and let $G_{1}$ and $G_{2}$ denote the subgraphs induced by $V_{1}$ and $V_{2}$ respectively. Then, recursively find colorful paths of length $k/2 - 1$ in each of $G_{1}$ and $G_{2}$. Suppose the Boolean matrix $A_{1}$ and $A_{2}$ represent the connectivity of each pair of vertices in $G_{1}$ and $G_{2}$ by a colorful path, respectively, and let $B$ be the matrix describing the adjacency relations between vertices of $V_{1}$ and those of $V_{2}$, the Boolean product $A_1BA_2$ gives all pairs of vertices in $V$ that are connected by a colorful path of length $k - 1$. Thus, the recursive relation of matrix multiplications is $t(k) \le 2^k\cdot t(k/2)$, which yields a runtime of $2^{O(k)}\cdot V^\omega$. Although this algorithm finds only the end points of the colorful path, another algorithm by Alon and Naor[^o11] that finds colorful paths themselves can be incorporated into it.

:::

## Derandomization {#Derandomization}

The [derandomization](https://en.wikipedia.org/wiki/Derandomization) of color-coding involves enumerating possible colorings of a graph $G$, such that the [randomness](wikipedia://en/19196523) of coloring $G$ is no longer required. For the target subgraph $H$ in $G$ to be discoverable, the enumeration has to include at least one instance where the $H$ is colorful. To achieve this, enumerating a $k$-perfect family $F$ of hash functions from $\{1, ..., |V|\}$ to $\{1, ..., k\}$ is sufficient. By definition, $F$ is $k$-perfect if for every subset $S$ of $\{1, ..., |V|\}$ where $|S| = k$, there exists a hash function $h$ in $F$ such that $h : S \to \{1, ..., k\}$ is [perfect](https://en.wikipedia.org/wiki/Perfect_hash). In other words, there must exist a [hash function](https://en.wikipedia.org/wiki/Hash_function) in $F$ that colors any given $k$ vertices with $k$ distinct colors.

There are several approaches to construct such a $k$-perfect hash family:

1. The best explicit construction is by [Moni Naor](https://en.wikipedia.org/wiki/Moni_Naor), [Leonard J. Schulman](https://en.wikipedia.org/wiki/Leonard_J._Schulman), and [Aravind Srinivasan](wikipedia://en/80751317),[^o13] where a family of size $e^k k^{O(\log k)} \log |V|$ can be obtained. This construction does not require the target subgraph to exist in the original subgraph finding problem.
1. Another explicit construction by [Jeanette P. Schmidt](https://en.wikipedia.org/wiki/Jeanette_P._Schmidt) and Alan Siegel[^o14] yields a family of size $2^{O(k)}\log^2 |V|$.
1. Another construction that appears in the original paper of [Noga Alon](wikipedia://en/4939651) et al.[^o3] can be obtained by first building a $k$-perfect family that maps $\{1, ..., |V|\}$ to $\{1, ..., k^{2}\},$ followed by building another $k$-perfect family that maps $\{1, ..., k^{2}\}$ to $\{1, ..., k\}.$ In the first step, it is possible to construct such a family with $2n\log k$ random bits that are almost $2\log k$-wise independent,[^o15][^o16] and the [sample space](wikipedia://en/22958) needed for generating those random bits can be as small as $k^{O(1)}\log |V|$. In the second step, it has been shown by Jeanette P. Schmidt and Alan Siegel[^o14] that the size of such $k$-perfect family can be $2^{O(k)}$. Consequently, by composing the $k$-perfect families from both steps, a $k$-perfect family of size $2^{O(k)}\log |V|$ that maps from $\{1, ..., |V|\}$ to $\{1, ..., k\}$ can be obtained.

In the case of derandomizing well-coloring, where each vertex on the subgraph is colored consecutively, a $k$-perfect family of hash functions from $\{1, ..., |V|\}$ to $\{1, ..., k!\}$ is needed. A sufficient $k$-perfect family which maps from $\{1, ..., |V|\}$ to $\{1, ..., k^{k}\}$ can be constructed in a way similar to the approach 3 above (the first step). In particular, it is done by using $nk\log k$ random bits that are almost $k\log k$ independent, and the size of the resulting $k$-perfect family will be $k^{O(k)}\log |V|$.

The derandomization of color-coding method can be easily parallelized, yielding efficient [NC](wikipedia://en/22073) algorithms.

::: {#o18 .application cue=heading name="Applications"}

## Applications {#Applications}

Recently, color-coding has attracted much attention in the field of [bioinformatics](wikipedia://en/4214). One example is the detection of [signaling pathways](https://en.wikipedia.org/wiki/Wnt_signaling_pathway) in [protein-protein interaction](https://en.wikipedia.org/wiki/Protein-protein_interaction) (PPI) networks. Another example is to discover and to count the number of [motifs](https://en.wikipedia.org/wiki/Structural_motif) in PPI networks. Studying both [signaling pathways](https://en.wikipedia.org/wiki/Wnt_signaling_pathway) and [motifs](https://en.wikipedia.org/wiki/Structural_motif) allows a deeper understanding of the similarities and differences of many biological functions, processes, and structures among organisms.

Due to the huge amount of gene data that can be collected, searching for pathways or motifs can be highly time consuming. However, by exploiting the color-coding method, the motifs or signaling pathways with $k=O(\log n)$ vertices in a network $G$ with $n$ vertices can be found very efficiently in polynomial time. Thus, this enables us to explore more complex or larger structures in PPI networks.

:::
