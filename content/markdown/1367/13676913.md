# Orthostochastic matrix

::: {#o1 .subject cue=lead name="Orthostochastic matrix"}

In [mathematics](wikipedia://en/18831), an **orthostochastic matrix** is a [doubly stochastic matrix](wikipedia://en/2906180) whose entries are the squares of the absolute values of the entries of some [orthogonal matrix](wikipedia://en/105620).

:::

The detailed definition is as follows. A square matrix *B* of size *n* is doubly stochastic (or *bistochastic*) if all its rows and columns sum to 1 and all its entries are nonnegative [real numbers](https://en.wikipedia.org/wiki/Real_numbers). It is orthostochastic if there exists an [orthogonal matrix](wikipedia://en/105620) *O* such that

$$B_{ij}=O_{ij}^2 \text{ for } i,j=1,\dots,n. \,$$

All 2-by-2 doubly stochastic matrices are orthostochastic (and also [unistochastic](wikipedia://en/13269420)) since for any

$$B= \begin{bmatrix} a & 1-a \\ 1-a & a \end{bmatrix}$$

we find the corresponding orthogonal matrix

$$O = \begin{bmatrix} \cos \phi & \sin \phi \\ - \sin \phi & \cos \phi \end{bmatrix},$$

with $\cos^2 \phi =a,$ such that $B_{ij}=O_{ij}^2 .$

For larger *n* the sets of bistochastic matrices includes the set of unistochastic matrices, which includes the set of orthostochastic matrices and these inclusion relations are proper.
