# Combined linear congruential generator

::: {#o1 .subject cue=lead name="Combined linear congruential generator"}

A **combined linear congruential generator** (**CLCG**) is a [pseudo-random](wikipedia://en/23210) number generator [algorithm](wikipedia://en/775) based on combining two or more [linear congruential generators](wikipedia://en/45527) (LCG). A traditional LCG has a [period](wikipedia://en/76848) which is inadequate for [complex system](https://en.wikipedia.org/wiki/Complex_system) simulation.[^o9] By combining two or more LCGs, random numbers with a longer period and better statistical properties can be created.[^o9] The algorithm is defined as:[^o10]

$$X_i \equiv \left( \sum_{j=1}^k (-1)^{j-1}Y_{i,j} \right)\pmod{m_1 - 1}$$

where:

:::

- $m_1$ is the "[modulus](https://en.wikipedia.org/wiki/Modulo_operation)" of the first LCG
- $Y_{i,j}$ is the *i*<sup>th</sup> input from the *j*<sup>th</sup> LCG
- $X_i$ is the *i*<sup>th</sup> generated random integer

with:

$$R_i \equiv \begin{cases} X_i/m_1 & \text{for } X_i > 0 \\ (m_1-1)/m_1 & \text{for } X_i=0 \end{cases}$$

where $R_{i}$ is a [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) random number between 0 and 1.

## Derivation {#Derivation}

If *W*<sub>*i*,1</sub>, *W*<sub>*i*,2</sub>, ..., *W*<sub>*i*,k</sub> are any independent, discrete, random-variables and one of them is uniformly distributed from 0 to *m*<sub>1</sub> − 2, then *Z*<sub>*i*</sub> is uniformly distributed between 0 and *m*<sub>1</sub> − 2, where:[^o10]

$$Z_i= \left( \sum_{j=1}^k W_{i,j} \right) \pmod {m_1-1}$$

Let *X*<sub>*i*,1</sub>, *X*<sub>*i*,2</sub>, ..., *X*<sub>*i*,*k*</sub> be outputs from *k* LCGs. If *W*<sub>*i*,*j*</sub> is defined as *X*<sub>*i*,*j*</sub> − 1, then *W*<sub>*i*,*j*</sub> will be approximately uniformly distributed from 0 to *m<sub>j</sub>* − 1.[^o10] The coefficient "(−1)<sup>*j*−1</sup>" implicitly performs the [subtraction](wikipedia://en/74141) of one from *X*<sub>*i*,*j*</sub>.[^o9]

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The CLCG provides an efficient way to calculate pseudo-random numbers. The LCG algorithm is computationally inexpensive to use.[^o11] The results of multiple LCG algorithms are combined through the CLCG algorithm to create pseudo-random numbers with a longer [period](wikipedia://en/76848) than is achievable with the LCG method by itself.[^o11]

The period of a CLCG is the [least common multiple](wikipedia://en/17961) of the periods of the individual generators, which are one less than the moduli. Since all the moduli are odd primes, the periods are even and thus share at least a common divisor of 2, but if the moduli are chosen so that 2 is the [greatest common divisor](wikipedia://en/12354) of each pair, this will result in a period of:[^o9]

$$P = \frac{(m_1-1)(m_2-1)\cdots(m_k-1)}{2^{k-1}}$$

The following is an example algorithm designed for use in 32-bit computers:[^o10]

$$k=2$$

The CLCG algorithm is set up as follows:

The maximum period of the two LCGs used is calculated using the formula:[^o9]

$$(m-1)$$

This equates to 2.1 billion for the two LCGs used.

This CLCG shown in this example has a maximum period of:

$$(m_1-1)(m_2-1)/2 \approx 2.3 \times 10^{18}$$

This represents a tremendous improvement over the period of the individual LCGs. It can be seen that the combined method increases the period by 9 orders of magnitude.

Surprisingly the period of this CLCG may not be sufficient for all applications.[^o9] Other algorithms using the CLCG method have been used to create pseudo-random number generators with periods as long as 3e57.[^o12][^o13][^o14]

The former of the two generators, using b = 40,014 and m = 2,147,483,563, is also used by the Texas Instruments *TI-30X IIS* [scientific calculator](wikipedia://en/439711).
