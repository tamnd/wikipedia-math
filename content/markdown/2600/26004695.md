# Π01 class

::: {#o1 .subject cue=lead name="Π01 class"}

In [computability theory](wikipedia://en/155414), a **Π<sup>0</sup><sub>1</sub> class** is a subset of 2<sup>ω</sup> of a certain form. These classes are of interest as technical tools within [recursion theory](https://en.wikipedia.org/wiki/Recursion_theory) and [effective descriptive set theory](wikipedia://en/3244136). They are also used in the application of recursion theory to other branches of mathematics (Cenzer 1999, p. 39).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The set 2<sup>\<ω</sup> consists of all finite sequences of 0s and 1s, while the set 2<sup>ω</sup> consists of all infinite sequences of 0s and 1s (that is, functions from ω = {0, 1, 2, ...} to the set {0,1}).

A [tree](wikipedia://en/2190732) on 2<sup>\<ω</sup> is a subset of 2<sup>\<ω</sup> that is closed under taking initial segments. An element *f* of 2<sup>ω</sup> is a **path** through a tree *T* on 2<sup>\<ω</sup> if every finite initial segment of *f* is in *T*.

A ([lightface](https://en.wikipedia.org/wiki/Lightface)) **Π<sup>0</sup><sub>1</sub> class** is a subset *C* of 2<sup>ω</sup> for which there is a [computable](wikipedia://en/332264) tree *T* such that *C* consists of exactly the paths through *T*. A **boldface Π<sup>0</sup><sub>1</sub> class** is a subset *D* of 2<sup>ω</sup> for which there is an oracle *f* in 2<sup>ω</sup> and a subtree tree *T* of 2<sup>\< ω</sup> computable from *f* such that *D* is the set of paths through *T*.

:::

## As effectively closed sets {#As_effectively_closed_sets}

The boldface Π<sup>0</sup><sub>1</sub> classes are exactly the same as the closed sets of 2<sup>ω</sup> and thus the same as the boldface Π<sup>0</sup><sub>1</sub> subsets of 2<sup>ω</sup> in the [Borel hierarchy](wikipedia://en/5539282).

Lightface Π<sup>0</sup><sub>1</sub> classes in 2<sup>ω</sup> (that is, Π<sup>0</sup><sub>1</sub> classes whose tree is computable with no oracle) correspond to **effectively closed sets**. A subset *B* of 2<sup>ω</sup> is effectively closed if there is a [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable) sequence ⟨σ<sub>*i*</sub> : i ∈ ω⟩ of elements of 2<sup>\< ω</sup> such that each *g* ∈ 2<sup>ω</sup> is in *B* if and only if there does not exist some *i* such that σ<sub>*i*</sub> is an initial segment of *B*.

## Relationship with effective theories {#Relationship_with_effective_theories}

For each effectively axiomatized theory *T* of [first-order logic](wikipedia://en/10983), the set of all completions of *T* is a $\Pi^0_1$ class. Moreover, for each $\Pi^0_1$ subset *S* of $2^\omega$ there is an effectively axiomatized theory *T* such that each element of *S* computes a completion of *T*, and each completion of *T* computes an element of *S* (Jockusch and Soare 1972b).
