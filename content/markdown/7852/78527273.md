# Structural set theory

::: {#o1 .subject cue=lead name="Structural set theory"}

In mathematics, a **structural set theory** is an approach to [set theory](wikipedia://en/27553) that emphasizes the aspect of sets as abstract structures. It is in contrast to a more traditional [ZFC](https://en.wikipedia.org/wiki/ZFC) set-theory, which emphasizes membership. A prime example is [Lawvere](wikipedia://en/872760)'s [Elementary Theory of the Category of Sets](https://en.wikipedia.org/wiki/Elementary_Theory_of_the_Category_of_Sets), which identifies sets in terms of relations to each other through functions. Another example is SEAR (Sets, Elements, And Relations).[^o2]

:::

The adjective "structural" comes from the [structuralism](wikipedia://en/29391369) in the philosophy of mathematics.
