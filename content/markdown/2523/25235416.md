# Nehari manifold

*Image: Nehari.png.* Nehari variety

::: {#o1 .subject cue=lead name="Nehari manifold"}

In the [calculus of variations](wikipedia://en/171882), a branch of [mathematics](wikipedia://en/18831), a **Nehari manifold** is a manifold of functions, whose definition is motivated by the work of (txt). It is a [differentiable manifold](wikipedia://en/2119219) associated to the [Dirichlet problem](wikipedia://en/571109) for the semilinear [elliptic partial differential equation](wikipedia://en/662787)

:::

$$-\triangle u = |u|^{p-2}u,\text{ with }u\mid_{\partial \Omega} = 0.$$

Here, Δ is the [Laplacian](https://en.wikipedia.org/wiki/Laplacian) on a bounded domain Ω in **R**<sup>*n*</sup>.

There are infinitely many solutions to this problem. Solutions are precisely the critical points for the [energy functional](https://en.wikipedia.org/wiki/Energy_functional)

$$J(v) = \frac12\int_{\Omega}{|\nabla v|^2\,d\mu}-\frac1{p+1}\int_{\Omega}{|v|^{p+1}\,d\mu}$$

on the [Sobolev space](wikipedia://en/611964) *H*${}^{1}_{0}$(Ω). The Nehari manifold is defined to be the set of *v* ∈ *H*${}^{1}_{0}$(Ω) such that

$$\|\nabla v\|^2_{L^2(\Omega)} = \|v\|^{p+1}_{L^{p+1}(\Omega)} > 0.$$

Solutions to the original variational problem that lie in the Nehari manifold are (constrained) minimizers of the energy, and so [direct methods in the calculus of variations](https://en.wikipedia.org/wiki/Direct_methods_in_the_calculus_of_variations) can be brought to bear.

More generally, given a suitable functional *J*, the associated Nehari manifold is defined as the set of functions *u* in an appropriate function space for which

$$\langle J'(u), u\rangle = 0.$$

Here *J*′ is the [functional derivative](wikipedia://en/301504) of *J*.
