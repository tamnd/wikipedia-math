# LogSumExp

::: {#o1 .subject cue=lead name="LogSumExp"}

*Image: LogSumExp graph.svg.* Graph of $\mathrm{LSE}(x,-x)$ compared to $\max(x,-x)$

The **LogSumExp** (LSE) (also called **RealSoftMax**[^o2] or multivariable **[softplus](wikipedia://en/37862957)**) [function](wikipedia://en/185427) is a [smooth maximum](wikipedia://en/45456706) – a [smooth](https://en.wikipedia.org/wiki/Smooth_function) [approximation](wikipedia://en/336271) to the [maximum](https://en.wikipedia.org/wiki/Maximum) function, mainly used by [machine learning](wikipedia://en/233488) algorithms.[^o3] It is defined as the [logarithm](wikipedia://en/17860) of the sum of the [exponentials](wikipedia://en/9678) of the arguments:

:::

$$\mathrm{LSE}(x_1, \dots, x_n) = \log\left( \exp(x_1) + \cdots + \exp(x_n) \right).$$

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The LogSumExp function [domain](wikipedia://en/50263) is $\mathbb{R}^n$, the [real coordinate space](wikipedia://en/1482083), and its codomain is $\mathbb{R}$, the [real line](https://en.wikipedia.org/wiki/Real_line). It is an approximation to the maximum $\max_i x_i$ with the following bounds

$$\max{\{x_1, \dots, x_n\}} \leq \mathrm{LSE}(x_1, \dots, x_n) \leq \max{\{x_1, \dots, x_n\}} + \log(n).$$

The first [inequality](wikipedia://en/89489) is strict unless $n = 1$. The second inequality is strict unless all arguments are equal. (Proof: Let $m = \max_i x_i$. Then $\exp(m) \leq \sum_{i=1}^n \exp(x_i) \leq n \exp(m)$. Applying the logarithm to the inequality gives the result.)

In addition, we can scale the function to make the bounds tighter. Consider the function $\frac 1 t \mathrm{LSE}(tx_1, \dots, tx_n)$. Then

$$\max{\{x_1, \dots, x_n\}} < \frac 1 t \mathrm{LSE}(tx_1, \dots, tx_n) \leq \max{\{x_1, \dots, x_n\}} + \frac{\log(n)}{t}.$$

(Proof: Replace each $x_i$ with $tx_i$ for some $t>0$ in the inequalities above, to give

$$\max{\{tx_1, \dots, tx_n\}} < \mathrm{LSE}(tx_1, \dots, tx_n)\leq \max{\{tx_1, \dots, tx_n\}} + \log(n).$$

and, since $t>0$

$$t \max{\{x_1, \dots, x_n\}} < \mathrm{LSE}(tx_1, \dots, tx_n)\leq t\max{\{x_1, \dots, x_n\}} + \log(n).$$

finally, dividing by $t$ gives the result.)

Also, if we multiply by a negative number instead, we of course find a comparison to the $\min$ function:

$$\min{\{x_1, \dots, x_n\}} - \frac{\log(n)}{t} \leq \frac 1 {-t} \mathrm{LSE}(-tx) < \min{\{x_1, \dots, x_n\}}.$$

The LogSumExp function is [convex](wikipedia://en/245568), and is [strictly increasing](https://en.wikipedia.org/wiki/Increasing_function) everywhere in its domain.[^o6] It is not strictly convex, since it is [affine](https://en.wikipedia.org/wiki/Affine_function) (linear plus a constant) on the diagonal and parallel lines:[^o7]

$$\mathrm{LSE}(x_1 + c, \dots, x_n + c) =\mathrm{LSE}(x_1, \dots, x_n) + c.$$

Other than this direction, it is strictly convex (the [Hessian](wikipedia://en/412108) has rank $n - 1$), so for example restricting to a [hyperplane](wikipedia://en/99862) that is transverse to the diagonal results in a strictly convex function. See $\mathrm{LSE}_0^+$, below.

Writing $\mathbf{x} = (x_1, \dots, x_n),$ the [partial derivatives](wikipedia://en/52565) are:

$$\frac{\partial}{\partial x_i}{\mathrm{LSE}(\mathbf{x})} = \frac{\exp x_i}{\sum_j \exp {x_j}},$$

which means the [gradient](wikipedia://en/12461) of LogSumExp is the [softmax function](wikipedia://en/6152185).

The [convex conjugate](wikipedia://en/1001490) of LogSumExp is the [negative entropy](https://en.wikipedia.org/wiki/Negative_entropy).

:::

## log-sum-exp trick for log-domain calculations {#log-sum-exp_trick_for_log-domain_calculations}

The LSE function is often encountered when the usual arithmetic computations are performed on a [logarithmic scale](wikipedia://en/164055), as in [log probability](https://en.wikipedia.org/wiki/Log_probability).[^o9]

Similar to multiplication operations in linear-scale becoming simple additions in log-scale, an addition operation in linear-scale becomes the LSE in log-scale:

$$\mathrm{LSE}(\log(x_1), ..., \log(x_n)) = \log(x_1 + \dots + x_n)$$

A common purpose of using log-domain computations is to increase accuracy and avoid underflow and overflow problems when very small or very large numbers are represented directly (i.e. in a linear domain) using limited-precision floating point numbers.[^o10]

Unfortunately, the use of LSE directly in this case can again cause overflow/underflow problems. Therefore, the following equivalent must be used instead (especially when the accuracy of the above 'max' approximation is not sufficient).

$$\mathrm{LSE}(x_1, \dots, x_n) = x^* + \log\left( \exp(x_1-x^*)+ \cdots + \exp(x_n-x^*) \right)$$

where $x^* = \max{\{x_1, \dots, x_n\}}$

Many math libraries such as [IT++](https://en.wikipedia.org/wiki/IT++) provide a default routine of LSE and use this formula internally.

## A strictly convex log-sum-exp type function {#A_strictly_convex_log-sum-exp_type_function}

LSE is convex but not strictly convex. We can define a strictly convex log-sum-exp type function[^o12] by adding an extra argument set to zero:

$$\mathrm{LSE}_0^+(x_1,...,x_n) = \mathrm{LSE}(0,x_1,...,x_n)$$

This function is a proper Bregman generator (strictly convex and [differentiable](wikipedia://en/330206)). It is encountered in machine learning, for example, as the cumulant of the multinomial/binomial family.

In [tropical analysis](wikipedia://en/59158120), this is the sum in the [log semiring](wikipedia://en/37563991).
