# WinBUGS

::: {#o2 .subject cue=lead name="WinBUGS"}

**WinBUGS** is [statistical software](https://en.wikipedia.org/wiki/Statistical_software) for [Bayesian analysis](https://en.wikipedia.org/wiki/Bayesian_analysis) using [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC) methods.

:::

It is based on the BUGS ([**B**ayesian inference](wikipedia://en/49571) **U**sing [**G**ibbs **S**ampling](wikipedia://en/509709)) project started in 1989. It runs under [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), though it can also be run on [Linux](https://en.wikipedia.org/wiki/Linux) or Mac using [Wine](https://en.wikipedia.org/wiki/Wine_%28software%29).[^o3]

It was developed by the BUGS Project, a team of British researchers at the [MRC](https://en.wikipedia.org/wiki/Medical_Research_Council_%28UK%29) [Biostatistics](wikipedia://en/3878) Unit, [Cambridge](https://en.wikipedia.org/wiki/Cambridge), and [Imperial College School of Medicine](https://en.wikipedia.org/wiki/Imperial_College_School_of_Medicine), London. Originally intended to solve problems encountered in medical statistics, it soon became widely used in other disciplines, such as ecology, sociology, and geology.[^o4]

The last version of WinBUGS was version 1.4.3, released in August 2007. Development is now focused on [OpenBUGS](wikipedia://en/3578854), an [open-source](https://en.wikipedia.org/wiki/Open-source_software) version of the package. WinBUGS 1.4.3 remains available as a stable version for routine use, but is no longer being developed.[^o5][^o6]
