# Modulus of convergence

::: {#o1 .subject cue=lead name="Modulus of convergence"}

In [real analysis](wikipedia://en/26478), a branch of [mathematics](wikipedia://en/18831), a **modulus of convergence** is a [function](wikipedia://en/185427) that tells how quickly a [convergent sequence](https://en.wikipedia.org/wiki/Convergent_sequence) converges. These moduli are often employed in the study of [computable analysis](wikipedia://en/21535996) and [constructive mathematics](https://en.wikipedia.org/wiki/Constructive_mathematics).

:::

If a sequence of [real numbers](wikipedia://en/20646438) $x_i$ converges to a real number $x$, then by definition, for every real $\varepsilon > 0$ there is a [natural number](wikipedia://en/21474) $N$ such that if $i > N$ then $\left|x - x_i\right| < \varepsilon$. A modulus of convergence is essentially a function that, given $\varepsilon$, returns a corresponding value of $N$.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Suppose that $x_i$ is a convergent sequence of real numbers with [limit](wikipedia://en/285773) $x$. There are two common ways of defining a modulus of convergence as a function from natural numbers to natural numbers:

- As a function $f$ such that for all $n$, if $i > f(n)$ then $\left|x - x_i\right| < 1/n$.
- As a function $g$ such that for all $n$, if $i \geq j > g(n)$ then $\left|x_i - x_j\right| < 1/n$.

The latter definition is often employed in constructive settings, where the limit $x$ may actually be identified with the convergent sequence. Some authors use an alternate definition that replaces $1/n$ with $2^{-n}$.

:::
