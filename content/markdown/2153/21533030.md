# Pasting lemma

::: {#o1 .subject cue=lead name="Pasting lemma"}

In [topology](wikipedia://en/29954), the **pasting** or **gluing lemma**, and sometimes the **gluing rule**, is an important result which says that two [continuous functions](wikipedia://en/6122) can be "glued together" to create another continuous function. The [lemma](wikipedia://en/18634) is implicit in the use of [piecewise functions](wikipedia://en/404130). For example, in the book *Topology and Groupoids*, where the condition given for the statement below is that $A \setminus B \subseteq \operatorname{Int} A$ and $B \setminus A \subseteq \operatorname{Int} B.$

:::

The pasting lemma is crucial to the construction of the [fundamental group](wikipedia://en/11004) and [fundamental groupoid](wikipedia://en/55264190) of a [topological space](wikipedia://en/30450); it allows one to concatenate [paths](wikipedia://en/1189553) to create a new path.

::: {#o3 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

Let $X,Y$ be both [closed](wikipedia://en/47279) (or both [open](wikipedia://en/39358)) subsets of a topological space $A$ such that $A = X \cup Y$, and let $B$ also be a topological space. If $f : A \to B$ is continuous when [restricted](wikipedia://en/1589032) to both $X$ and $Y,$ then $f$ is continuous.[^n1]

This result allows one to take two continuous functions defined on closed (or open) subsets of a topological space and create a new one.

::: {#o5 .proof cue=inline-head name="Proof"}

**Proof**: if $U$ is a closed subset of $B,$ then $f^{-1}(U )\cap X$ and $f^{-1}(U) \cap Y$ are both closed since each is the [preimage](https://en.wikipedia.org/wiki/Preimage) of $f$ when restricted to $X$ and $Y$ respectively, which by assumption are continuous. Then their [union](wikipedia://en/47949), $f^{-1}(U)$ is also closed, being a finite union of closed sets.

A similar argument applies when $X$ and $Y$ are both open. $\Box$

The infinite analog of this result (where $A = X_1 \cup X_2 \cup X_3 \cup \cdots$) is not true for closed $X_1, X_2, X_3, \ldots.$ For instance, the [inclusion map](wikipedia://en/492516) $\iota : \mathbb{Z} \to \mathbb{R}$ from the [integers](wikipedia://en/14563) to the [real line](https://en.wikipedia.org/wiki/Real_line) (with the integers equipped with the [cofinite topology](https://en.wikipedia.org/wiki/Cofinite_topology)) is continuous when restricted to an integer, but the preimage of a [bounded](wikipedia://en/48258) open set in the reals with this map is at most a finite number of points, so not open in $\mathbb{Z}.$

It is, however, true if the $X_1, X_2, X_3\ldots$ form a [locally finite collection](wikipedia://en/11611098) since a union of locally finite closed sets is closed. Similarly, it is true if the $X_1, X_2, X_3, \ldots$ are instead assumed to be open since a union of open sets is open.

:::
