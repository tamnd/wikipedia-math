# Quasiregular element

*This article addresses the notion of quasiregularity in the context of [ring theory](wikipedia://en/250424), a branch of [modern algebra](wikipedia://en/19616384). For other notions of quasiregularity in [mathematics](wikipedia://en/18831), see the disambiguation page [quasiregular](https://en.wikipedia.org/wiki/Quasiregular_%28disambiguation%29).*

::: {#o1 .subject cue=lead name="Quasiregular element"}

In [mathematics](wikipedia://en/18831), specifically [ring theory](wikipedia://en/250424), the notion of **quasiregularity** provides a computationally convenient way to work with the [Jacobson radical](wikipedia://en/57656) of a [ring](wikipedia://en/48404).[^o2] In this article, we primarily concern ourselves with the notion of quasiregularity for [unital rings](https://en.wikipedia.org/wiki/Unital_ring). However, one section is devoted to the theory of quasiregularity in non-unital rings, which constitutes an important aspect of [noncommutative](wikipedia://en/24062516) ring theory.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *R* be a ring (with [unity](https://en.wikipedia.org/wiki/Multiplicative_identity)) and let *r* be an element of *R*. Then *r* is said to be **quasiregular**, if 1 − *r* is a [unit](wikipedia://en/289666) in *R*; that is, invertible under multiplication.[^o2] The notions of **right or left quasiregularity** correspond to the situations where 1 − *r* has a right or left inverse, respectively.[^o2]

An element *x* of a non-unital ring *R* is said to be **right quasiregular** if there exists *y* in *R* such that $x + y - xy = 0$.[^o5] The notion of a **left quasiregular** element is defined in an analogous manner. The element *y* is sometimes referred to as a **right quasi-inverse** of *x*.[^o6] If the ring is unital, this definition of quasiregularity coincides with that given above.[^o7] If one writes $x \cdot y = x + y - xy$, then this [binary operation](wikipedia://en/3948) $\cdot$ is [associative](https://en.wikipedia.org/wiki/Associative).[^o8] In fact, in the unital case, the map $(R,\cdot)\to(R,\times); x\mapsto1-x$ (where × denotes the multiplication of the ring *R*) is a [monoid](wikipedia://en/19652) [isomorphism](wikipedia://en/14828).[^o7] Therefore, if an element possesses both a left and right quasi-inverse, they are equal.[^o9]

Note that some authors use different definitions. They call an element *x* right quasiregular if there exists *y* such that $x + y + xy = 0$,[^o10] which is equivalent to saying that 1 + *x* has a right inverse when the ring is unital. If we write $x\circ y=x+y+xy$, then $(-x)\circ(-y)=-(x\cdot y)$, so we can easily go from one set-up to the other by changing signs.[^o11] For example, *x* is right quasiregular in one set-up if and only if −*x* is right quasiregular in the other set-up.[^o11]

:::

::: {#o13 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *R* is a ring, then the additive identity of *R* is always quasiregular.
- If $x^2$ is right (resp. left) quasiregular, then $x$ is right (resp. left) quasiregular.[^o14]
- If *R* is a ring, every [nilpotent element](https://en.wikipedia.org/wiki/Nilpotent_element) of *R* is quasiregular.[^o15] This fact is supported by an elementary computation:

If $x^{n+1} = 0$, then

$(1-x)(1 + x + x^2 + \dotsb + x^n) = 1$ (or $(1+x)(1-x+x^2-\dotsb+(-x)^n)=1$ if we follow the second convention).

From this we see easily that the quasi-inverse of *x* is $-x-x^2-\dotsb-x^n$ (or $-x+x^2-\dotsb+(-x)^n$).

- In the second convention, a [matrix](wikipedia://en/20556859) is quasiregular in a [matrix ring](wikipedia://en/487541) if it does not possess −1 as an [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue). More generally, a [bounded operator](wikipedia://en/455961) is quasiregular if −1 is not in its [spectrum](wikipedia://en/206137).
- In a unital [Banach algebra](wikipedia://en/4665), if $\|x\| < 1$, then the [geometric series](wikipedia://en/12630) $\sum_0^\infty x^n$ [converges](wikipedia://en/1743431). Consequently, every such *x* is quasiregular.
- If *R* is a ring and *S* = *R*\[\[*X*<sub>1</sub>, ..., *X*<sub>*n*</sub>\]\] denotes the ring of [formal power series](wikipedia://en/60012) in *n* indeterminants over *R*, an element of *S* is quasiregular if and only its constant term is quasiregular as an element of *R*.

:::

::: {#o17 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every element of the [Jacobson radical](wikipedia://en/57656) of a (not necessarily [commutative](wikipedia://en/61346)) ring is quasiregular.[^o18] In fact, the Jacobson radical of a ring can be characterized as the unique right [ideal](wikipedia://en/25977) of the ring, maximal with respect to the property that every element is right quasiregular.[^o19][^o20] However, a right quasiregular element need not necessarily be a member of the Jacobson radical.[^o21] This justifies the remark in the beginning of the article – "bad elements" are quasiregular, although quasiregular elements are not necessarily "bad". Elements of the Jacobson radical of a ring are often deemed to be "bad".
- If an element of a ring is nilpotent and [central](https://en.wikipedia.org/wiki/Center_of_a_ring), then it is a member of the ring's Jacobson radical.[^o22] This is because the [principal right ideal](wikipedia://en/145126) generated by that element consists of quasiregular (in fact, nilpotent) elements only.
- If an element, *r*, of a ring is [idempotent](wikipedia://en/361940), it cannot be a member of the ring's Jacobson radical.[^o23] This is because idempotent elements cannot be quasiregular. This property, as well as the one above, justify the remark given at the top of the article that the notion of quasiregularity is computationally convenient when working with the Jacobson radical.[^o2]

## Generalization to semirings {#Generalization_to_semirings}

The notion of quasiregular element readily generalizes to [semirings](wikipedia://en/371468). If *a* is an element of a semiring *S*, then an affine map from *S* to itself is $\mu_a(r) = ra + 1$. An element *a* of *S* is said to be **right quasiregular** if $\mu_a$ has a [fixed point](wikipedia://en/449738), which need not be unique. Each such fixed point is called a **left quasi-inverse** of *a*. If *b* is a left quasi-inverse of *a* and additionally *b* = *ab* + 1, then *b* it is called a **quasi-inverse** of *a*; any element of the semiring that has a quasi-inverse is said to be **quasiregular**. It is possible that some but not all elements of a semiring be quasiregular; for example, in the semiring of nonnegative [reals](wikipedia://en/20646438) with the usual addition and multiplication of reals, $\mu_a$ has the fixed point $\frac{1}{1-a}$ for all *a* \< 1, but has no fixed point for *a* ≥ 1.[^o26] If every element of a semiring is quasiregular then the semiring is called a **quasi-regular semiring**, **closed semiring**,[^o27] or occasionally a **Lehmann semiring**[^o26] (the latter honoring the paper of Daniel J. Lehmann.[^o28])

Examples of quasi-regular semirings are provided by the [Kleene algebras](wikipedia://en/155430) (prominently among them, the algebra of [regular expressions](wikipedia://en/25717)), in which the quasi-inverse is lifted to the role of a unary operation (denoted by *a*\*) defined as the least fixedpoint solution. Kleene algebras are additively idempotent but not all quasi-regular semirings are so. We can extend the example of nonegative reals to include [infinity](wikipedia://en/20110824) and it becomes a quasi-regular semiring with the quasi-inverse of any element *a* ≥ 1 being the infinity. This quasi-regular semiring is not additively idempotent however, so it is not a Kleene algebra.[^o27] It is however a [complete semiring](https://en.wikipedia.org/wiki/Complete_semiring).[^o29] More generally, all complete semirings are quasiregular.[^o30] The term *closed semiring* is actually used by some authors to mean complete semiring rather than just quasiregular.[^o31][^o32]

[Conway semirings](https://en.wikipedia.org/wiki/Conway_semiring) are also quasiregular; the two Conway axioms are actually independent, i.e. there are semirings satisfying only the product-star \[Conway\] axiom, (*ab*)\* = 1+*a*(*ba*)\**b*, but not the sum-star axiom, (*a*+*b*)\* = (*a*\**b*)\**a*\* and vice versa; it is the product-star \[Conway\] axiom that implies that a semiring is quasiregular. Additionally, a [commutative semiring](https://en.wikipedia.org/wiki/Commutative_semiring) is quasiregular if and only if it satisfies the product-star Conway axiom.[^o26]

Quasiregular semirings appear in [algebraic path problems](wikipedia://en/41985#General_algebraic_framework_on_semirings:_the_algebraic_path_problem), a generalization of the [shortest path problem](wikipedia://en/41985).[^o27]
