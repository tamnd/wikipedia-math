# Set identification

::: {#o1 .subject cue=lead name="Set identification"}

In [statistics](wikipedia://en/26685) and [econometrics](wikipedia://en/10390), **set identification** (or **partial identification**) extends the concept of [identifiability](wikipedia://en/22884398) (or "point identification") in [statistical models](wikipedia://en/27576) to environments where the model and the distribution of observable variables are not sufficient to determine a unique value for the model [parameters](wikipedia://en/413291), but instead constrain the parameters to lie in a [strict subset](https://en.wikipedia.org/wiki/Strict_subset) of the parameter space. Statistical models that are set (or partially) identified arise in a variety of settings in [economics](https://en.wikipedia.org/wiki/Economics), including [game theory](wikipedia://en/11924) and the [Rubin causal model](wikipedia://en/5700418). Unlike approaches that deliver point-identification of the model parameters, methods from the literature on partial identification are used to obtain set estimates that are valid under weaker modelling assumptions.[^n1]

:::

## History {#History}

Early works containing the main ideas of set identification included (Frisch 1934) and (Marschak Andrews 1944). However, the methods were significantly developed and promoted by [Charles Manski](https://en.wikipedia.org/wiki/Charles_Manski), beginning with (Manski 1989) and (Manski 1990).

Partial identification continues to be a major theme in research in econometrics. (Powell 2017) named partial identification as an example of theoretical progress in the econometrics literature, and (Bonhomme Shaikh 2017) list partial identification as “one of the most prominent recent themes in econometrics.”

::: {#o11 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $U \in \mathcal{U} \subseteq \mathbb{R}^{d_{u}}$ denote a vector of latent variables, let $Z \in \mathcal{Z} \subseteq \mathbb{R}^{d_{z}}$ denote a vector of observed (possibly endogenous) explanatory variables, and let $Y \in \mathcal{Y} \subseteq \mathbb{R}^{d_{y}}$ denote a vector of observed endogenous outcome variables. A **structure** is a pair $s= (h,\mathcal{P}_{U\mid Z})$, where $\mathcal{P}_{U\mid Z}$ represents a collection of conditional distributions, and $h$ is a structural function such that $h(y,z,u) = 0$ for all realizations $(y,z,u)$ of the random vectors $(Y,Z,U)$. A **model** is a collection of admissible (i.e. possible) structures $s$.[^o12][^o13]

Let $\mathcal{P}_{Y\mid Z}(s)$ denote the collection of conditional distributions of $Y \mid Z$ consistent with the structure $s$. The admissible structures $s$ and $s'$ are said to be **observationally equivalent** if $\mathcal{P}_{Y\mid Z}(s) = \mathcal{P}_{Y\mid Z}(s')$.[^o12][^o13] Let $s^\star$ denotes the true (i.e. data-generating) structure. The model is said to be point-identified if for every $s \neq s^\star$ we have $\mathcal{P}_{Y\mid Z}(s) \neq \mathcal{P}_{Y\mid Z}(s^\star)$. More generally, the model is said to be **set** (or **partially**) **identified** if there exists at least one admissible $s\neq s^\star$ such that $\mathcal{P}_{Y\mid Z}(s)\neq \mathcal{P}_{Y\mid Z}(s^\star)$. The **identified set** of structures is the collection of admissible structures that are observationally equivalent to $s^\star$.[^n2]

In most cases the definition can be substantially simplified. In particular, when $U$ is independent of $Z$ and has a known (up to some finite-dimensional parameter) distribution, and when $h$ is known up to some finite-dimensional vector of parameters, each structure $s$ can be characterized by a finite-dimensional parameter vector $\theta \in \Theta \subset \mathbb{R}^{d_{\theta}}$. If $\theta_0$ denotes the true (i.e. data-generating) vector of parameters, then the **identified set**, often denoted as $\Theta_{I} \subset \Theta$, is the set of parameter values that are observationally equivalent to $\theta_0$.[^n2]

:::

## Example: missing data {#Example:_missing_data}

This example is due to (Tamer 2010). Suppose there are two [binary random variables](https://en.wikipedia.org/wiki/Binary_random_variable), $Y$ and $Z$. The econometrician is interested in $\mathrm P(Y = 1)$. There is a [missing data](wikipedia://en/7859676) problem, however: $Y$ can only be observed if $Z = 1$.

By the [law of total probability](wikipedia://en/312383),

$$\mathrm P(Y = 1) = \mathrm P(Y = 1 \mid Z = 1) \mathrm P(Z = 1) + \mathrm P(Y = 1 \mid Z = 0) \mathrm P(Z = 0).$$

The only unknown object is $\mathrm P(Y = 1 \mid Z = 0)$, which is constrained to lie between 0 and 1. Therefore, the identified set is

$$\Theta_I = \{ p \in [0, 1] : p = \mathrm P(Y = 1 \mid Z = 1) \mathrm P(Z = 1) + q \mathrm P(Z = 0), \text{ for some } q \in [0,1]\}.$$

Given the missing data constraint, the econometrician can only say that $\mathrm P(Y = 1) \in \Theta_I$. This makes use of all available information.

## Statistical inference {#Statistical_inference}

[Set estimation](wikipedia://en/39284847) cannot rely on the usual tools for statistical inference developed for [point estimation](wikipedia://en/160379). A literature in statistics and econometrics studies methods for [statistical inference](wikipedia://en/27577) in the context of set-identified models, focusing on constructing [confidence intervals](wikipedia://en/280911) or [confidence regions](wikipedia://en/1040970) with appropriate properties. For example, a method developed by (Chernozhukov Hong Tamer 2007) constructs confidence regions that cover the identified set with a given probability.
