# HP Prime

::: {#o6 .subject cue=lead name="HP Prime"}

The **HP Prime Graphing Calculator** is a [graphing calculator](wikipedia://en/335004) introduced by [Hewlett-Packard](https://en.wikipedia.org/wiki/Hewlett-Packard) in 2013 and manufactured by [HP Inc.](https://en.wikipedia.org/wiki/HP_Inc.) until the licensees [Moravia Consulting spol.&nbsp;s&nbsp;r.o.](https://en.wikipedia.org/wiki/Moravia_Consulting_spol.&nbsp;s&nbsp;r.o.) and [Royal Consumer Information Products, Inc.](https://en.wikipedia.org/wiki/Royal_Consumer_Information_Products,_Inc.) took over the continued development, manufacturing, distribution, marketing and support in 2022. It was designed with features resembling those of [smartphones](https://en.wikipedia.org/wiki/Smartphone), such as a rechargeable [lithium-ion battery](https://en.wikipedia.org/wiki/Lithium-ion_battery), full-color [touchscreen](https://en.wikipedia.org/wiki/Touchscreen) display, and a user interface centered around different [applications](https://en.wikipedia.org/wiki/Application_software).[^o7] It claims to be the world's smallest and thinnest [CAS](wikipedia://en/54427)-enabled calculator currently available.[^o5]

:::

The functionality of the HP Prime is also available as [emulation software](https://en.wikipedia.org/wiki/Emulator) for PCs and Macs,[^o8] as well as for various smartphones.

## Design and software {#Design_and_software}

The HP Prime's [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) features two separate [home screens](https://en.wikipedia.org/wiki/Home_screen), one of which contains an integrated [computer algebra system](wikipedia://en/54427) (CAS) based on the free and open-source [Xcas/Giac](https://en.wikipedia.org/wiki/Xcas) 1.5.0 engine, which evolved from that of the [HP 49G](https://en.wikipedia.org/wiki/HP_49G) and its successors. Both the standard and CAS modes function independently of each other and the calculator can quickly switch between the two, unlike some of its competitors, such as the [TI-Nspire series](https://en.wikipedia.org/wiki/TI-Nspire_series) by [Texas Instruments](https://en.wikipedia.org/wiki/Texas_Instruments), which comes in either CAS-supported models or non-CAS models.

The G1 model calculator has a 1,500 mAh battery, which is expected to last up to 15 hours on a single charge. The G2 model comes with a battery with a capacity of 2,000 mAh.

Unlike the [HP 50g](https://en.wikipedia.org/wiki/HP_50g) and its predecessors, the HP Prime does not have an [SD card](https://en.wikipedia.org/wiki/SD_card) slot and does not feature a beeper.

### Exam Mode {#Exam_Mode}

The HP Prime has a feature called *[Exam Mode](https://en.wikipedia.org/wiki/Exam_mode)*. This enables various features of the calculator (such as CAS functionality, user-created apps, notes, etc.) to be selectively disabled for a specific time, from 15 minutes to 8 hours. This can be done manually within the calculator's menus, or by using a computer with HP's connectivity software.[^o12] LEDs on the top of the calculator blink to let the instructor see that the calculator is in this mode. Despite this feature, the Prime is still prohibited in many examinations, such as the US's [ACT](https://en.wikipedia.org/wiki/ACT_%28test%29) college-entry test.[^o13] It is however starting to be accepted in other examinations, like those run by the Dutch [CvTE](https://en.wikipedia.org/wiki/CvTE),[^o14] the Swiss [IB](https://en.wikipedia.org/wiki/International_Baccalaureate),[^o15] or [Alberta](https://en.wikipedia.org/wiki/Alberta) (Canada)[^o16] education authorities.

:::

### Programming {#Programming}

The HP Prime's non-CAS home-screen supports textbook, [algebraic](https://en.wikipedia.org/wiki/Algebraic_input) and [128-level RPN](https://en.wikipedia.org/wiki/128-level_RPN) (aka [Advanced RPN](https://en.wikipedia.org/wiki/Advanced_RPN)) entry logic. Unlike [RPL](https://en.wikipedia.org/wiki/RPL_%28programming_language%29), which throws an error message when its [dynamic stack](https://en.wikipedia.org/wiki/Dynamic_RPN_stack) is exhausted, the Prime's fixed-sized stack just drops values off the stack on overflow (like with [four-level RPN](https://en.wikipedia.org/wiki/Four-level_RPN)).[^o31] The calculator uses a new operating system unrelated to HP's legacy [Saturn](https://en.wikipedia.org/wiki/HP_Saturn_%28microprocessor%29) and Saturn-emulated systems, which were used on HP's previous RPN/RPL graphing calculators; therefore, it is not compatible with any [User RPL](https://en.wikipedia.org/wiki/User_RPL) or [System RPL](https://en.wikipedia.org/wiki/System_RPL), or with programming in Saturn or ARM assembler language.

The calculator supports programming in a new, [Pascal](https://en.wikipedia.org/wiki/Pascal_%28programming_language%29)-like programming language now named **HP PPL** (for **Prime Programming Language**, but originally also referred to as [HP Basic](https://en.wikipedia.org/wiki/Prime_Programming_Language)) that also supports creating apps. This is based on a language introduced on the [HP 38G](wikipedia://en/740859) and built on in subsequent models.[^o18]

## Hardware revisions and model variants {#Hardware_revisions_and_model_variants}

*Image: Logic PCB again (10833511703).jpg.* Motherboard of the NW280AA model

The first production model (NW280AA) in 2013 reports its hardware revision as A. This model does not support wireless connectivity, unit-to-unit USB communication, or data streaming. The calculator is manufactured by [Inventec Besta](https://en.wikipedia.org/wiki/Inventec_Besta) and utilizes a modified version of their Besta operating system.

The second production model (G8X92AA) reports its hardware revision as C. It was introduced in May 2014. This model supports features lacking in the first production model, namely wireless connectivity (using the *HP Prime Wireless Kit* (FOK65AA)), unit-to-unit USB communication (through [USB OTG](https://en.wikipedia.org/wiki/USB_OTG)), and data streaming (using the *HP StreamSmart 410* (NW278AA) 4-port data streamer).[^o20] The wireless kit includes a base station connected to a PC and wireless modules to connect to up to 30 HP Prime calculators for use in a classroom.

The third production model, which was introduced in August 2016, has a revised color scheme with darker blue and orange colors for an improved readability of the keyboard.[^o21][^o22] It still carries the model number G8X92AA and reports a hardware revision of C, but the package shows a 2016 copyright.[^o23]

In July 2018, HP introduced a new hardware generation with model number 2AP18AA and hardware revision D. This version features an [NXP](https://en.wikipedia.org/wiki/NXP) [i.MX 6ULL](https://en.wikipedia.org/wiki/I.MX_6ULL) MCIMX6Y2 processor with ARM [Cortex A7](https://en.wikipedia.org/wiki/Cortex_A7) core and is about three times faster. It provides more RAM (256 MiB instead of 32 MiB) and a bigger Flash module (512 MB instead of 256 MB)[^o24] and runs [FreeRTOS](https://en.wikipedia.org/wiki/FreeRTOS). It is labelled "G2" on the back.[^o25]
