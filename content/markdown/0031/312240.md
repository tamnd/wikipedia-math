# UP (complexity)

::: {#o1 .subject cue=lead name="UP"}

In [complexity theory](wikipedia://en/7543), **UP** (**unambiguous non-deterministic polynomial-time**) is the [complexity class](wikipedia://en/502426) of [decision problems](wikipedia://en/8336) solvable in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) on an [unambiguous Turing machine](wikipedia://en/49020514) (a [nondeterministic Turing machine](wikipedia://en/21935) with at most one accepting path for each input). **UP** contains **[P](wikipedia://en/658550)** and is contained in **[NP](wikipedia://en/21562)**.

:::

A common reformulation of **NP** states that a language is in **NP** if and only if a given "certificate" can be verified by a deterministic machine in polynomial time. Similarly, a language is in **UP** if a given certificate can be verified in polynomial time, and the verifier machine only accepts at most *one* certificate for each problem instance.[^o2] More formally, a language *L* belongs to **UP** if there exists a two-input polynomial-time algorithm *A* and a constant *c* such that

if $x \in L$, then there exists a unique certificate *y* with $|y| = O(|x|^c)$ such that $A(x,y) = 1$

if $x \not\in L$, there is no certificate *y* with $|y| = O(|x|^c)$ such that $A(x,y) = 1$

algorithm *A* verifies *L* in polynomial time.

**UP** (and its [complement](wikipedia://en/1929955) **co-UP**) contain both the [integer factorization](wikipedia://en/15491) problem and [parity game](https://en.wikipedia.org/wiki/Parity_game) problem. Because determined effort has yet to find a polynomial-time solution to any of these problems, it is suspected to be difficult to show **P**=**UP**, or even **P**=(**UP** ∩ **co-UP**).

The [Valiant–Vazirani theorem](wikipedia://en/3003434) states that **NP** is contained in **RP**<sup>**Promise-UP**</sup>, which means that there is a randomized reduction from any problem in **NP** to a problem in **[Promise-UP](wikipedia://en/1471429)**.

**UP** is not known to have any [complete](wikipedia://en/1176530) problems.[^o3]
