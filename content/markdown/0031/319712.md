# Well-founded relation

::: {#o1 .subject cue=lead name="Well-founded relation"}

In [mathematics](wikipedia://en/18831), a [binary relation](wikipedia://en/3931) $R$ is called **well-founded** (or **wellfounded** or **foundational**)[^o2] on a [set](wikipedia://en/26691) or, more generally, a [class](wikipedia://en/20696) $X$ if every [non-empty](https://en.wikipedia.org/wiki/Non-empty) [subset](wikipedia://en/27631) (or subclass) $S \subseteq X$ has a [minimal element](https://en.wikipedia.org/wiki/Minimal_element) with respect to $R$; that is, there exists an $m \in S$ such that for every $s \in S$, one does not have $s R m$. More formally, a relation is well-founded if:

$$(\forall S \subseteq X)\; [S \neq \varnothing \implies (\exists m \in S) (\forall s \in S) \lnot(s \mathrel{R} m)].$$

Some authors include an extra condition that $R$ is [set-like](https://en.wikipedia.org/wiki/Set-like_relation), i.e., that the elements less than any given element form a set.

:::

Equivalently, assuming the [axiom of dependent choice](wikipedia://en/441950), a relation is well-founded when it contains no [infinite descending chains](https://en.wikipedia.org/wiki/Infinite_descending_chain), meaning there is no infinite sequence $x_{0}, x_{1}, x_{2}, ...$ of elements of $X$ such that $x_{n+1} R x_{n}$ for every natural number $n$.[^o3][^o4]

In [order theory](wikipedia://en/361924), a [partial order](https://en.wikipedia.org/wiki/Partial_order) is called well-founded if the corresponding [strict order](https://en.wikipedia.org/wiki/Strict_order) is a well-founded relation. If the order is a [total order](wikipedia://en/30330), then it is called a [well-order](wikipedia://en/33456).

In [set theory](wikipedia://en/27553), a set $x$ is called a **well-founded set** if the [set membership](https://en.wikipedia.org/wiki/Element_%28mathematics%29) relation is well-founded on the [transitive closure](https://en.wikipedia.org/wiki/Transitive_closure_%28set%29) of $x$. The [axiom of regularity](wikipedia://en/2113), which is one of the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214), asserts that all sets are well-founded.

A relation $R$ is **converse well-founded**, **upwards well-founded**, or **Noetherian** on $X$, if the [converse relation](wikipedia://en/3941020) $R^{-1}$ is well-founded on $X$. In this case $R$ is also said to satisfy the [ascending chain condition](wikipedia://en/3189). In the context of [rewriting](wikipedia://en/415847) systems, a Noetherian relation is also called **terminating**.

::: {#o6 .pointer-item cue=pointer name="Noetherian induction"}

## Induction and recursion {#Induction_and_recursion}

An important reason that well-founded relations are interesting is because a version of [transfinite induction](wikipedia://en/30461) can be used on them: if ($X, R$) is a well-founded relation, $P(x)$ is some property of elements of $X$, and we want to show that

$P(x)$ holds for all elements $x$ of $X$,

it suffices to show that:

If $x$ is an element of $X$ and $P(y)$ is true for all $y$ such that $y R x$, then $P(x)$ must also be true.

That is,

$$(\forall x \in X)\;[(\forall y \in X)\;[y\mathrel{R}x \implies P(y)] \implies P(x)]\quad\text{implies}\quad(\forall x \in X)\,P(x).$$

Well-founded induction is sometimes called Noetherian induction,[^o7] after [Emmy Noether](wikipedia://en/149896).

On par with induction, well-founded relations also support construction of objects by [transfinite recursion](https://en.wikipedia.org/wiki/Transfinite_recursion). Let $(X, R)$ be a [set-like](wikipedia://en/3931#Relations_over_a_set) well-founded relation and $F$ a function that assigns an object $F(x, g)$ to each pair of an element $x \in X$ and a function $g$ on the set $y: y R x$ of predecessors of $x$. Then there is a unique function $G$ such that for every $x \in X$,

$$G(x) = F\left(x, G\vert_{\left\{y:\, y\mathrel{R}x\right\}}\right).$$

That is, if we want to construct a function $G$ on $X$, we may define $G(x)$ using the values of $G(y)$ for $y R x$.

As an example, consider the well-founded relation $(\mathbf{N}, S)$, where $\mathbf{N}$ is the set of all [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), and $S$ is the graph of the successor function $x \mapsto x+1$. Then induction on $S$ is the usual [mathematical induction](wikipedia://en/18881), and recursion on $S$ gives [primitive recursion](https://en.wikipedia.org/wiki/Primitive_recursive_functions). If we consider the order relation $(\mathbf{N}, <)$, we obtain [complete induction](https://en.wikipedia.org/wiki/Complete_induction), and [course-of-values recursion](wikipedia://en/3989260). The statement that $(\mathbf{N}, <)$ is well-founded is also known as the [well-ordering principle](wikipedia://en/168864).

There are other interesting special cases of well-founded induction. When the well-founded relation is the usual ordering on the class of all [ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_numbers), the technique is called [transfinite induction](wikipedia://en/30461). When the well-founded set is a set of recursively defined data structures, the technique is called [structural induction](wikipedia://en/211399). When the well-founded relation is set membership on the universal class, the technique is known as [∈-induction](https://en.wikipedia.org/wiki/∈-induction). See those articles for more details.

:::

## Examples {#Examples}

Well-founded relations that are not totally ordered include:

- The positive [integers](wikipedia://en/14563) $1, 2, 3, ...$, with the order defined by $a < b$ [if and only if](wikipedia://en/14922) $a$ [divides](wikipedia://en/49492) $b$ and $a \ne b$.
- The set of all finite [strings](wikipedia://en/27701) over a fixed alphabet, with the order defined by $s < t$ if and only if $s$ is a proper substring of $t$.
- The set $\mathbf{N} \times \mathbf{N}$ of [pairs](wikipedia://en/24104095) of [natural numbers](wikipedia://en/21474), ordered by $(n_{1}, n_{2}) < (m_{1}, m_{2})$ if and only if $n_{1} < m_{1}$ and $n_{2} < m_{2}$.
- Every class whose elements are sets, with the relation ∈ ("is an element of"). This is the [axiom of regularity](wikipedia://en/2113).
- The nodes of any finite [directed acyclic graph](wikipedia://en/204002), with the relation $R$ defined such that $a R b$ if and only if there is an edge from $a$ to $b$.

Examples of relations that are not well-founded include:

- The negative integers $-1, -2, -3, ...$, with the usual order, since any unbounded subset has no least element.
- The set of strings over a finite alphabet with more than one element, under the usual ([lexicographic](https://en.wikipedia.org/wiki/Lexicographic_ordering)) order, since the sequence "B" > "AB" > "AAB" > "AAAB" > ... is an infinite descending chain. This relation fails to be well-founded even though the entire set has a minimum element, namely the empty string.
- The set of non-negative [rational numbers](wikipedia://en/19727024) (or [reals](https://en.wikipedia.org/wiki/Real_numbers)) under the standard ordering, since, for example, the subset of positive rationals (or reals) lacks a minimum.

:::

## Other properties {#Other_properties}

If $(X, <)$ is a well-founded relation and $x$ is an element of $X$, then the descending chains starting at $x$ are all finite, but this does not mean that their lengths are necessarily bounded. Consider the following example: Let $X$ be the union of the positive integers with a new element ω that is bigger than any integer. Then $X$ is a well-founded set, but there are descending chains starting at ω of arbitrary great (finite) length; the chain $\omega, n - 1, n - 2, ..., 2, 1$ has length $n$ for any $n$.

The [Mostowski collapse lemma](https://en.wikipedia.org/wiki/Mostowski_collapse) implies that set membership is a universal among the [extensional](wikipedia://en/294056#In_mathematics) well-founded relations: for any set-like well-founded relation $R$ on a class $X$ that is extensional, there exists a class $C$ such that $(X, R)$ is isomorphic to $(C, \in)$.

## Reflexivity {#Reflexivity}

A relation $R$ is said to be [reflexive](wikipedia://en/200458) if $a R a$ holds for every $a$ in the domain of the relation. Every reflexive relation on a nonempty domain has infinite descending chains, because any constant sequence is a descending chain. For example, in the natural numbers with their usual order ≤, we have 1 ≥ 1 ≥ 1 ≥ .... To avoid these trivial descending sequences, when working with a partial order ≤, it is common to apply the definition of well foundedness (perhaps implicitly) to the alternate relation \< defined such that $a < b$ if and only if $a \le b$ and $a \ne b$. More generally, when working with a [preorder](wikipedia://en/23582) ≤, it is common to use the relation \< defined such that $a < b$ if and only if $a \le b$ and $b \nleq a$. In the context of the natural numbers, this means that the relation \<, which is well-founded, is used instead of the relation ≤, which is not. In some texts, the definition of a well-founded relation is changed from the definition above to include these conventions.
