# Autonomous system (mathematics)

*Image: Stability\_Diagram.png.* [Stability diagram](wikipedia://en/5493795) classifying [Poincaré maps](wikipedia://en/876732#Poincaré_maps_and_stability_analysis) of linear **autonomous system** $x' = Ax,$ as stable or unstable according to their features. Stability generally increases to the left of the diagram.[^o1] Some sink, source or node are [equilibrium points](https://en.wikipedia.org/wiki/Equilibrium_point).

*Image: Phase plane nodes.svg.* 2-dimensional case refers to [Phase plane](wikipedia://en/2110756).

::: {#o2 .subject cue=lead name="Autonomous system"}

In [mathematics](wikipedia://en/18831), an **autonomous system** or **autonomous differential equation** is a [system](https://en.wikipedia.org/wiki/Simultaneous_equations) of [ordinary differential equations](wikipedia://en/32742753) which does not explicitly depend on the [independent variable](https://en.wikipedia.org/wiki/Independent_variable). When the variable is time, they are also called [time-invariant systems](https://en.wikipedia.org/wiki/Time-invariant_system).

:::

Many laws in [physics](wikipedia://en/22939), where the independent variable is usually assumed to be [time](https://en.wikipedia.org/wiki/Time), are expressed as autonomous systems because it is assumed the [laws of nature](https://en.wikipedia.org/wiki/Physical_law) which hold now are identical to those for any point in the past or future.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

An **autonomous system** is a [system of ordinary differential equations](https://en.wikipedia.org/wiki/System_of_ordinary_differential_equation) of the form

$$\frac{d}{dt}x(t)=f(x(t))$$

where $x$ takes values in $n$-dimensional [Euclidean space](wikipedia://en/9697); $t$ is often interpreted as time.

It is distinguished from systems of differential equations of the form

$$\frac{d}{dt}x(t)=g(x(t),t)$$

in which the law governing the evolution of the system does not depend solely on the system's current state but also the parameter $t$, again often interpreted as time; such systems are by definition not autonomous.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Solutions are invariant under horizontal translations:

Let $x_1(t)$ be a unique solution of the [initial value problem](wikipedia://en/498383) for an autonomous system

$$\frac{d}{dt}x(t)=f(x(t)) \, , \quad x(0)=x_0.$$

Then $x_2(t)=x_1(t-t_0)$ solves

$$\frac{d}{dt}x(t)=f(x(t)) \, , \quad x(t_0)=x_0.$$

Denoting $s=t-t_0$ gets $x_1(s)=x_2(t)$ and $ds=dt$, thus

$$\frac{d}{dt}x_2(t) = \frac{d}{dt}x_1(t-t_0)=\frac{d}{ds}x_1(s) = f(x_1(s)) = f(x_2(t)) .$$

For the initial condition, the verification is trivial,

$$x_2(t_0)=x_1(t_0-t_0)=x_1(0)=x_0 .$$

:::

::: {#o8 .example cue=heading name="Example"}

## Example {#Example}

The equation $y'= \left(2-y\right)y$ is autonomous, since the independent variable ($x$) does not explicitly appear in the equation. To plot the [slope field](wikipedia://en/1866685) and [isocline](wikipedia://en/8253822) for this equation, one can use the following code in [GNU Octave](wikipedia://en/48707)/[MATLAB](wikipedia://en/20412)

```matlab
Ffun = @(X, Y)(2 - Y) .* Y; % function f(x,y)=(2-y)y
[X, Y] = meshgrid(0:.2:6, -1:.2:3); % choose the plot sizes
DY = Ffun(X, Y); DX = ones(size(DY)); % generate the plot values
quiver(X, Y, DX, DY, 'k'); % plot the direction field in black
hold on;
contour(X, Y, DY, [0 1 2], 'g'); % add the isoclines(0 1 2) in green
title('Slope field and isoclines for f(x,y)=(2-y)y')
```

One can observe from the plot that the function $\left(2-y\right)y$ is $x$-invariant, and so is the shape of the solution, i.e. $y(x)=y(x-x_0)$ for any shift $x_0$.

Solving the equation symbolically in [MATLAB](wikipedia://en/20412), by running

```matlab
syms y(x);
equation = (diff(y) == (2 - y) * y);
% solve the equation for a general solution symbolically
y_general = dsolve(equation);
```

obtains two [equilibrium](https://en.wikipedia.org/wiki/Equilibrium_point) solutions, $y=0$ and $y=2$, and a third solution involving an unknown constant $C_3$,

```matlab
-2 / (exp(C3 - 2 * x) - 1)
```

.

Picking up some specific values for the [initial condition](wikipedia://en/1186804), one can add the plot of several solutions

*Image: Slop field with isoclines and solutions.png.* Slope field with isoclines and solutions

```matlab
% solve the initial value problem symbolically
% for different initial conditions
y1 = dsolve(equation, y(1) == 1); y2 = dsolve(equation, y(2) == 1);
y3 = dsolve(equation, y(3) == 1); y4 = dsolve(equation, y(1) == 3);
y5 = dsolve(equation, y(2) == 3); y6 = dsolve(equation, y(3) == 3);
% plot the solutions
ezplot(y1, [0 6]); ezplot(y2, [0 6]); ezplot(y3, [0 6]);
ezplot(y4, [0 6]); ezplot(y5, [0 6]); ezplot(y6, [0 6]);
title('Slope field, isoclines and solutions for f(x,y)=(2-y)y')
legend('Slope field', 'Isoclines', 'Solutions y_{1..6}');
text([1 2 3], [1 1 1], strcat('\leftarrow', {'y_1', 'y_2', 'y_3'}));
text([1 2 3], [3 3 3], strcat('\leftarrow', {'y_4', 'y_5', 'y_6'}));
grid on;
```

:::

## Qualitative analysis {#Qualitative_analysis}

Autonomous systems can be analyzed qualitatively using the [phase space](wikipedia://en/191101); in the one-variable case, this is the [phase line](wikipedia://en/29298399).

## Solution techniques {#Solution_techniques}

The following techniques apply to one-dimensional autonomous differential equations. Any one-dimensional equation of order $n$ is equivalent to an $n$-dimensional first-order system (as described in [reduction to a first-order system](wikipedia://en/32742753#Reduction_to_a_first-order_system)), but not necessarily vice versa.

### First order {#First_order}

The first-order autonomous equation

$$\frac{dx}{dt} = f(x)$$

is [separable](wikipedia://en/387750), so it can be solved by rearranging it into the integral form

$$t + C = \int \frac{dx}{f(x)}$$

### Second order {#Second_order}

The second-order autonomous equation

$$\frac{d^2x}{dt^2} = f(x, x')$$

is more difficult, but it can be solved[^o13] by introducing the new variable

$$v = \frac{dx}{dt}$$

and expressing the [second derivative](wikipedia://en/3224219) of $x$ via the [chain rule](wikipedia://en/6113) as

$$\frac{d^2x}{dt^2} = \frac{dv}{dt} = \frac{dx}{dt}\frac{dv}{dx} = v\frac{dv}{dx}$$

so that the original equation becomes

$$v\frac{dv}{dx} = f(x, v)$$

which is a first order equation containing no reference to the independent variable $t$. Solving provides $v$ as a function of $x$. Then, recalling the definition of $v$:

$$\frac{dx}{dt} = v(x) \quad \Rightarrow \quad t + C = \int \frac{d x}{v(x)}$$

which is an implicit solution.

::: {#o15 .statement kind=statement/generalization cue=heading name="Special case:"}

#### Special case: $x'' = f(x)$ {#Special_case:}

The special case where $f$ is independent of $x'$

$$\frac{d^2 x}{d t^2} = f(x)$$

benefits from separate treatment.[^o16] These types of equations are very common in [classical mechanics](wikipedia://en/19555586) because they are always [Hamiltonian systems](wikipedia://en/1197531).

The idea is to make use of the identity

$$\frac{d x}{d t} = \left(\frac{d t}{d x}\right)^{-1}$$

which follows from the [chain rule](wikipedia://en/6113), barring any issues due to [division by zero](wikipedia://en/185663).

By inverting both sides of a first order autonomous system, one can immediately integrate with respect to $x$:

$$\frac{d x}{d t} = f(x) \quad \Rightarrow \quad \frac{d t}{d x} = \frac{1}{f(x)} \quad \Rightarrow \quad t + C = \int \frac{dx}{f(x)}$$

which is another way to view the separation of variables technique. The second derivative must be expressed as a derivative with respect to $x$ instead of $t$:

$$\begin{aligned} \frac{d^2 x}{d t^2} &= \frac{d}{d t}\left(\frac{d x}{d t}\right) = \frac{d}{d x}\left(\frac{d x}{d t}\right) \frac{d x}{d t} \\[4pt] &= \frac{d}{d x}\left(\left(\frac{d t}{d x}\right)^{-1}\right) \left(\frac{d t}{d x}\right)^{-1} \\[4pt] &= - \left(\frac{d t}{d x}\right)^{-2} \frac{d^2 t}{d x^2} \left(\frac{d t}{d x}\right)^{-1} = - \left(\frac{d t}{d x}\right)^{-3} \frac{d^2 t}{d x^2} \\[4pt] &= \frac{d}{d x}\left(\frac{1}{2}\left(\frac{d t}{d x}\right)^{-2}\right) \end{aligned}$$

To reemphasize: what's been accomplished is that the second derivative with respect to $t$ has been expressed as a derivative of $x$. The original second order equation can now be integrated:

$$\begin{aligned} \frac{d^2 x}{d t^2} &= f(x) \\ \frac{d}{d x}\left(\frac{1}{2}\left(\frac{d t}{d x}\right)^{-2}\right) &= f(x) \\ \left(\frac{d t}{d x}\right)^{-2} &= 2 \int f(x) dx + C_1 \\ \frac{d t}{d x} &= \pm \frac{1}{\sqrt{2 \int f(x) dx + C_1}} \\ t + C_2 &= \pm \int \frac{dx}{\sqrt{2 \int f(x) dx + C_1}} \end{aligned}$$

This is an implicit solution. The greatest potential problem is inability to simplify the integrals, which implies difficulty or impossibility in evaluating the integration constants.

:::

::: {#o18 .statement kind=statement/generalization cue=heading name="Special case:"}

#### Special case: $x'' = x'^{n} f(x)$ {#Special_case:}

Using the above approach, the technique can extend to the more general equation

$$\frac{d^2 x}{d t^2} = \left(\frac{d x}{d t}\right)^n f(x)$$

where $n$ is some parameter not equal to two. This will work since the second derivative can be written in a form involving a power of $x'$. Rewriting the second derivative, rearranging, and expressing the left side as a derivative:

$$\begin{aligned} &- \left(\frac{d t}{d x}\right)^{-3} \frac{d^2 t}{d x^2} = \left(\frac{d t}{d x}\right)^{-n} f(x) \\[4pt] &- \left(\frac{d t}{d x}\right)^{n - 3} \frac{d^2 t}{d x^2} = f(x) \\[4pt] &\frac{d}{d x}\left(\frac{1}{2 - n}\left(\frac{d t}{d x}\right)^{n - 2}\right) = f(x) \\[4pt] &\left(\frac{d t}{d x}\right)^{n - 2} = (2 - n) \int f(x) dx + C_1 \\[2pt] &t + C_2 = \int \left((2 - n) \int f(x) dx + C_1\right)^{\frac{1}{n - 2}} dx \end{aligned}$$

The right will carry +/− if $n$ is even. The treatment must be different if $n = 2$:

$$\begin{aligned} - \left(\frac{d t}{d x}\right)^{-1} \frac{d^2 t}{d x^2} &= f(x) \\ -\frac{d}{d x}\left(\ln\left(\frac{d t}{d x}\right)\right) &= f(x) \\ \frac{d t}{d x} &= C_1 e^{-\int f(x) dx} \\ t + C_2 &= C_1 \int e^{-\int f(x) dx} dx \end{aligned}$$

:::

### Higher orders {#Higher_orders}

There is no analogous method for solving third- or higher-order autonomous equations. Such equations can only be solved exactly if they happen to have some other simplifying property, for instance [linearity](wikipedia://en/379868) or dependence of the right side of the equation on the dependent variable only[^o20][^o21] (i.e., not its derivatives). This should not be surprising, considering that nonlinear autonomous systems in three dimensions can produce truly [chaotic](wikipedia://en/6295) behavior such as the [Lorenz attractor](https://en.wikipedia.org/wiki/Lorenz_attractor) and the [Rössler attractor](wikipedia://en/1576293).

Likewise, general non-autonomous equations of second order are unsolvable explicitly, since these can also be chaotic, as in a periodically forced pendulum.[^o22]

### Multivariate case {#Multivariate_case}

In $\mathbf x'(t) = A \mathbf x(t)$, where $\mathbf x(t)$ is an $n$-dimensional column vector dependent on $t$.

The solution is $\mathbf x(t) = e^{A t} \mathbf c$ where $\mathbf c$ is an $n \times 1$ constant vector.[^o24]

### Finite durations {#Finite_durations}

For non-linear autonomous ODEs it is possible under some conditions to develop solutions of finite duration,[^o26] meaning here that from its own dynamics, the system will reach the value zero at an ending time and stay there in zero forever after. These finite-duration solutions cannot be [analytical functions](https://en.wikipedia.org/wiki/Analytical_function) on the whole real line, and because they will be non-[Lipschitz functions](https://en.wikipedia.org/wiki/Lipschitz_function) at the ending time, they don't stand uniqueness of solutions of Lipschitz differential equations.

As example, the equation:

$$y'= -\text{sgn}(y)\sqrt{|y|},\,\,y(0)=1$$

Admits the finite duration solution:

$$y(x)=\frac{1}{4}\left(1-\frac{x}{2}+\left|1-\frac{x}{2}\right|\right)^2$$
