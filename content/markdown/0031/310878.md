# Bounded lattice

::: {#o1 .subject cue=lead name="Bounded lattice"}

In [mathematics](wikipedia://en/18831), and in particular in [order theory](wikipedia://en/361924), a **bounded lattice** is a [lattice](wikipedia://en/469304) that has a [least element](https://en.wikipedia.org/wiki/Least_element) and a [greatest element](https://en.wikipedia.org/wiki/Greatest_element), usually denoted by $0$ and $1$, respectively.[^o2]

:::

Bounded lattices are of considerable importance because many algebraic structures are bounded lattices, including [complete lattices](wikipedia://en/44777), [Heyting algebras](wikipedia://en/309343), [Boolean algebras](wikipedia://en/3959), and others.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A bounded lattice can be defined in two equivalent ways: via an order relation or algebraically. These two definitions can be shown to be equivalent.

### Order-theoretic definition {#Order-theoretic_definition}

Let $(L,\le)$ be a [partially ordered set](wikipedia://en/23572). Then $L$ is called a **bounded lattice** if and only if:

1. $L$ is a lattice with respect to the order relation:
   1. For every pair $a,b\in L$, there exists an [infimum](https://en.wikipedia.org/wiki/Infimum).
   1. For every pair $a,b\in L$, there exists a [supremum](https://en.wikipedia.org/wiki/Supremum).
1. $L$ is a [bounded](wikipedia://en/48258) poset:
   1. There exists $m\in L$ such that for every $a\in L$, $m\le a$. This element is unique and is denoted by $0$.
   1. There exists $M\in L$ such that for every $a\in L$, $a\le M$. This element is unique and is denoted by $1$.

### Algebraic definition {#Algebraic_definition}

Let $L$ be a set equipped with two [binary operations](wikipedia://en/3948) $\land$ and $\lor$, and two distinguished elements $0,1\in L$. Then $L$ is called a **bounded lattice** if and only if the following conditions hold:

1. $L$ is a lattice with respect to $\land$ and $\lor$:
   1. [Associativity](wikipedia://en/1335): for all $a,b,c\in L$, $(a\land b)\land c = a\land (b\land c)$ and $(a\lor b)\lor c = a\lor (b\lor c)$.
   1. [Commutativity](wikipedia://en/294390): for all $a,b\in L$, $a\land b = b\land a$ and $a\lor b = b\lor a$.
   1. [Idempotence](wikipedia://en/14972): for all $a\in L$, $a\land a = a$ and $a\lor a = a$.
   1. Absorption: for all $a,b\in L$, $a\land (a\lor b) = a$ and $a\lor (a\land b) = a$.
1. $0$ and $1$ are [identity elements](wikipedia://en/14962) for $\lor$ and $\land$, respectively:
   1. For all $a\in L$, $a\lor 0 = a$.
   1. For all $a\in L$, $a\land 1 = a$.

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- In a bounded lattice $(L,\land,\lor,0,1)$, for every $a\in L$, one has $a\land 0 = 0$.
- In a bounded lattice $(L,\land,\lor,0,1)$, for every $a\in L$, one has $a\lor 1 = 1$.

:::

## Bounding a lattice {#Bounding_a_lattice}

Let $(L,\le)$ be an arbitrary lattice. One may ask whether there exists a bounded lattice $L'$ into which $L$ can be [order-embedded](wikipedia://en/762203).

Define $L' := \{\downarrow\!x \mid x\in L\}\cup\{\emptyset, L\}$, a collection of [subsets](wikipedia://en/27631) of $L$, where for each $x\in L$, $\downarrow\!x$ denotes the [principal lower set](https://en.wikipedia.org/wiki/Lower_set) generated by $x$. It can be shown that $L'$, ordered by inclusion $\subseteq$, is a bounded lattice. Define a function $\varphi\colon L\to L'$ by $\varphi(x):=\downarrow\!x$. One can prove that $\varphi$ is an order embedding.

The [Dedekind–MacNeille completion](wikipedia://en/16667323) proves a much stronger statement: every partially ordered set (not necessarily a lattice) can be embedded into a [complete lattice](wikipedia://en/44777) (which is necessarily bounded).[^o10]

## Complemented lattice {#Complemented_lattice}

Let $(L,\land,\lor,0,1)$ be a bounded lattice. It is called a **[complemented lattice](wikipedia://en/753521)** if and only if for every $a\in L$ there exists $b\in L$ such that $a\land b = 0$ and $a\lor b = 1$.

In this case, $b$ is called a **complement** of $a$. In contrast to a Boolean algebra, a complemented lattice may have more than one complement for a given element. Intuitively, a complement can be thought of as a negation of the element.

::: {#o13 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every finite partially ordered set that is a lattice is a [complete lattice](wikipedia://en/44777), and hence a bounded lattice.
- Every [closed interval](https://en.wikipedia.org/wiki/Closed_interval) in the [real line](https://en.wikipedia.org/wiki/Real_line) is a bounded lattice.
- Let $L$ be the collection of all [vector subspaces](https://en.wikipedia.org/wiki/Vector_subspace) of $\mathbb{R}^2$, ordered by inclusion. This is a bounded lattice with minimum ${0}$ and maximum $\mathbb{R}^2$.
- Let $C$ be the set of all continuous functions from $\mathbb{R}$ to the closed interval $[0,1]$, ordered pointwise: $f\le g$ if and only if $f(x)\le g(x)$ for all $x\in\mathbb{R}$. Then $(C,\le)$ is a lattice, since for any two functions one may take their pointwise minimum and maximum, which are again continuous. However, for an infinite family of continuous functions, this construction need not yield a continuous function. Hence, this lattice is not complete. It is bounded, since the constant functions $m(x):=0$ and $M(x):=1$ serve as global minimum and maximum.
- Let $P$ be the collection of all [convex](wikipedia://en/6292) and [closed](wikipedia://en/47279) [polygons](wikipedia://en/23621) in $\mathbb{R}^2$, together with the empty set $\emptyset$ and the whole space $\mathbb{R}^2$, ordered by inclusion. This is a lattice because the intersection of two closed convex polygons is again a closed convex polygon, and the [closure](wikipedia://en/42309) of the [convex hull](wikipedia://en/40634) of their union is also a closed convex polygon. It is bounded, with $\emptyset$ as minimum and $\mathbb{R}^2$ as maximum. However, it is not complete: the family of all closed convex polygons contained in the [unit disk](wikipedia://en/252738) has no supremum in this lattice, since their union is a [circle](wikipedia://en/6220), which is not a polygon.

:::
