# Weighting pattern

::: {#o1 .subject cue=lead name="Weighting pattern"}

A **weighting pattern** for a [linear dynamical system](wikipedia://en/4786318) describes the relationship between an input $u$ and output $y$. Given the [time-variant system](wikipedia://en/1291342) described by

:::

$$\dot{x}(t) = A(t)x(t) + B(t)u(t)$$

$$y(t) = C(t)x(t),$$

then the output can be written as

$$y(t) = y(t_0) + \int_{t_0}^t T(t,\sigma)u(\sigma) d\sigma,$$

where $T(\cdot,\cdot)$ is the weighting pattern for the system. For such a system, the weighting pattern is $T(t,\sigma) = C(t)\phi(t,\sigma)B(\sigma)$ such that $\phi$ is the [state transition matrix](https://en.wikipedia.org/wiki/State_transition_matrix).

The weighting pattern will determine a system, but if there exists a [realization](wikipedia://en/10353119) for this weighting pattern then there exist many that do so.[^o2]

## Linear time invariant system {#Linear_time_invariant_system}

In a [LTI system](https://en.wikipedia.org/wiki/LTI_system) then the weighting pattern is:

**Continuous**

$$T(t,\sigma) = C e^{A(t-\sigma)} B$$

where $e^{A(t-\sigma)}$ is the [matrix exponential](wikipedia://en/672731).

**Discrete**

$$T(k,l) = C A^{k-l-1} B.$$
