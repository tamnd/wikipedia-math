# Shafarevich's theorem on solvable Galois groups

::: {#o1 .subject cue=lead name="Shafarevich's theorem on solvable Galois groups"}

In [mathematics](wikipedia://en/18831), **Shafarevich's theorem** states that any [finite](wikipedia://en/323707) [solvable group](wikipedia://en/105012) is the [Galois group](wikipedia://en/12673) of some [finite extension](https://en.wikipedia.org/wiki/Finite_extension) of the [rational numbers](wikipedia://en/19727024). It was first [proved](wikipedia://en/82285) by (txt), though [Alexander Schmidt](wikipedia://en/63781826) later pointed out a gap in the proof, which was fixed by (txt).

:::
