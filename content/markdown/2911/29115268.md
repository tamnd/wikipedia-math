# Escaping set

::: {#o1 .subject cue=lead name="Escaping set"}

In mathematics, and particularly [complex dynamics](wikipedia://en/650518), the **escaping set** of an [entire function](wikipedia://en/10372) $f$ consists of all points that tend to infinity under the [repeated application](wikipedia://en/1448702) of $f$.[^o2] That is, a [complex number](wikipedia://en/5826) $z_0\in\mathbb{C}$ belongs to the escaping set if and only if the sequence defined by $z_{n+1} := f(z_n)$ converges to infinity as $n$ gets large. The escaping set of $f$ is denoted by $I(f)$.[^o2]

:::

For example, for $f(z)=e^z$, the origin $z=0$ belongs to the escaping set, since the sequence $0,1,e,e^e,e^{e^e},\dots$ tends to infinity.

## History {#History}

The iteration of transcendental entire functions was first studied by [Pierre Fatou](wikipedia://en/629100) in 1926[^o4] The escaping set occurs implicitly in his study of the explicit entire functions $f(z)=z+1+\exp(-z)$ and $f(z)=c\sin(z)$.

::: {#o5 .problem cue=unsolved}

Can the escaping set of a transcendental entire function have a bounded component?

:::

The first study of the escaping set for a general transcendental entire function is due to [Alexandre Eremenko](wikipedia://en/34534867) who used [Wiman-Valiron theory](https://en.wikipedia.org/wiki/Wiman-Valiron_theory).[^o6] He conjectured that every [connected component](https://en.wikipedia.org/wiki/Connected_component_%28topology%29) of the escaping set of a transcendental entire function is unbounded. This has become known as *Eremenko's conjecture*.[^o2][^o7] In 2021, a paper by Martí-Pete, [Rempe](wikipedia://en/46975110), and Waterman constructed a counterexample to Eremenko's conjecture.[^o8]

Eremenko also asked whether every escaping point can be connected to infinity by a curve in the escaping set; it was later shown that this is not the case. Indeed, there exist entire functions whose escaping sets do not contain any curves at all.[^o7]

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The following properties are known to hold for the escaping set of any non-constant and non-linear entire function. (Here *nonlinear* means that the function is not of the form $f(z)=az+b$.)

- The escaping set contains at least one point.
- The [boundary](wikipedia://en/72824) of the escaping set is exactly the [Julia set](wikipedia://en/56434). In particular, the escaping set is never [closed](wikipedia://en/47279).
- For a transcendental entire function, the escaping set always intersects the Julia set. In particular, the escaping set is [open](wikipedia://en/39358) if and only if $f$ is a polynomial.
- Every connected component of the closure of the escaping set is unbounded.
- The escaping set always has at least one unbounded connected component.[^o2]
- The escaping set is connected or has infinitely many components.[^o11]
- The set $I(f)\cup \{\infty\}$ is connected.[^o11]

Note that the final statement does not imply Eremenko's Conjecture. (Indeed, there exist connected spaces in which the removal of a single [dispersion point](wikipedia://en/7588072) leaves the remaining space totally disconnected.)

:::

## Examples {#Examples}

### Polynomials {#Polynomials}

A [polynomial](wikipedia://en/23000) of degree 2 extends to an analytic self-map of the [Riemann sphere](wikipedia://en/30876799), having a [super-attracting fixed point](wikipedia://en/449738) at infinity. The escaping set is precisely the [basin of attraction](wikipedia://en/191094) of this fixed point, and hence usually referred to as the \*\*basin of infinity\*\*. In this case, $I(f)$ is an [open](wikipedia://en/39358) and [connected](wikipedia://en/6233) subset of the complex plane, and the [Julia set](wikipedia://en/56434) is the boundary of this basin.

For instance the escaping set of the [complex quadratic polynomial](wikipedia://en/11735693) $f(z) = z^2$ consists precisely of the complement of the closed [unit disc](wikipedia://en/252738):

$$I(f) = \{z\in\mathbb{C} \colon |z| > 1 \}.$$

### Transcendental entire functions {#Transcendental_entire_functions}

*Image: Exp-esc.png.* Escaping set of $(\exp(z)-1)/2$.

For [transcendental entire functions](wikipedia://en/297021), the escaping set is much more complicated than for polynomials: in the simplest cases like the one illustrated in the picture it consists of uncountably many curves, called *hairs* or *rays*. In other examples the structure of the escaping set can be very different (a *spider's web*).[^o16] As mentioned above, there are examples of transcendental entire functions whose escaping set contains no curves.[^o7]

By definition, the escaping set is an [$F_{\sigma\delta}\text{ set}$](wikipedia://en/5539282). It is neither [$G_{\delta}$](wikipedia://en/252076) nor [$F_{\sigma}$](wikipedia://en/396575).[^o17] For functions in the exponential class $\exp(z)+a$, the escaping set is not $G_{\delta\sigma}$.[^o18]

A comprehensive survey of escaping sets of transcendental functions is given in the paper of Bergweiler and Rempe.[^o19]
