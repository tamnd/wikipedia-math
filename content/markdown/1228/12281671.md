# Dissipative operator

::: {#o1 .subject cue=lead name="Dissipative operator"}

In [mathematics](wikipedia://en/18831), a **dissipative operator** is a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) *A* defined on a [linear subspace](wikipedia://en/56357) *D*(*A*) of [Banach space](wikipedia://en/3989) *X*, taking values in *X* such that for all *λ* > 0 and all *x* ∈ *D*(*A*)

:::

$$\|(\lambda I-A)x\|\geq\lambda\|x\|.$$

A couple of equivalent definitions are given below. A dissipative operator is called **maximally dissipative** if it is dissipative and for all *λ* > 0 the operator *λI* − *A* is surjective, meaning that the range when applied to the domain *D* is the whole of the space *X*.

An operator that obeys a similar condition but with a plus sign instead of a minus sign (that is, the negation of a dissipative operator) is called an **accretive operator**.[^o2]

The main importance of dissipative operators is their appearance in the [Lumer–Phillips theorem](wikipedia://en/12281541) which characterizes maximally dissipative operators as the generators of [contraction semigroups](https://en.wikipedia.org/wiki/Contraction_semigroup).

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

A dissipative operator has the following properties:[^o5]

- From the inequality given above, we see that for any *x* in the domain of *A*, if ‖*x*‖ ≠ 0 then $\|(\lambda I-A)x\|\ne 0,$ so the [kernel](wikipedia://en/45240) of *λI* − *A* is just the [zero vector](https://en.wikipedia.org/wiki/Zero_vector) and *λI* − *A* is therefore [injective](https://en.wikipedia.org/wiki/Injective) and has an inverse for all *λ* > 0. (If we have the [strict inequality](https://en.wikipedia.org/wiki/Strict_inequality) $\|(\lambda I-A)x\|>\lambda\|x\|$ for all non-null *x* in the domain, then, by the [triangle inequality](wikipedia://en/53941), $\|\lambda x\|+\|Ax\|\ge\|(\lambda I-A)x\|>\lambda\|x\|,$ which implies that A itself has an inverse.) We may then state that

$$\|(\lambda I-A)^{-1}z\|\leq\frac{1}{\lambda}\|z\|$$

for all *z* in the range of *λI* − *A*. This is the same inequality as that given at the beginning of this article, with $z=(\lambda I-A)x.$ (We could equally well write these as $\|(I-\kappa A)^{-1}z\|\leq\|z\|\text{ or }\|(I-\kappa A)x\|\geq\|x\|$ which must hold for any positive κ.)

- *λI* − *A* is [surjective](https://en.wikipedia.org/wiki/Surjective) for some *λ* > 0 if and only if it is surjective for all *λ* > 0. (This is the aforementioned maximally dissipative case.) In that case one has (0, ∞) ⊂ *ρ*(*A*) (the [resolvent set](wikipedia://en/8721698) of *A*).
- *A* is a [closed operator](https://en.wikipedia.org/wiki/Closed_operator) if and only if the range of *λI* - *A* is closed for some (equivalently: for all) *λ* > 0.

:::

## Equivalent characterizations {#Equivalent_characterizations}

Define the duality set of *x* ∈ *X*, a subset of the [dual space](wikipedia://en/7988) *X**of*****X*, by***

$$J(x):=\left\{x'\in X':\|x'\|_{X'}^2=\|x\|_{X}^2=\langle x',x\rangle \right\}.$$

By the [Hahn–Banach theorem](wikipedia://en/13860) this set is nonempty.[^o7] In the [Hilbert space](wikipedia://en/20598932) case (using the [canonical duality](wikipedia://en/26452) between a Hilbert space and its dual) it consists of the single element *x*.[^o8] More generally, if *X* is a Banach space with a strictly convex dual, then *J*(*x*) consists of a single element.[^o9] Using this notation, *A* is dissipative if and only if[^o10] for all *x* ∈ *D*(*A*) there exists a *x*' ∈ *J*(*x*) such that

$${\rm Re}\langle Ax,x'\rangle\leq0.$$

In the case of Hilbert spaces, this becomes ${\rm Re}\langle Ax,x\rangle\leq0$ for all *x* in *D*(*A*). Since this is non-positive, we have

$$\|x-Ax\|^2=\|x\|^2+\|Ax\|^2-2{\rm Re}\langle Ax,x\rangle\geq\|x\|^2+\|Ax\|^2+2{\rm Re}\langle Ax,x\rangle=\|x+Ax\|^2$$

$$\therefore\|x-Ax\|\geq\|x+Ax\|$$

Since *I−A* has an inverse, this implies that $(I+A)(I-A)^{-1}$ is a [contraction](wikipedia://en/10907456), and more generally, $(\lambda I+A)(\lambda I-A)^{-1}$ is a contraction for any positive λ. The utility of this formulation is that if this operator is a contraction for **some** positive λ then *A* is dissipative. It is not necessary to show that it is a contraction for all positive λ (though this is true), in contrast to (λI−A)<sup>−1</sup> which must be proved to be a contraction for **all** positive values of λ.

## Examples {#Examples}

- For a simple finite-dimensional example, consider *n*-dimensional [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup> with its usual [dot product](wikipedia://en/157093). If *A* denotes the negative of the [identity operator](https://en.wikipedia.org/wiki/Identity_operator), defined on all of **R**<sup>*n*</sup>, then

$$x \cdot A x = x \cdot (-x) = - \| x \|^{2} \leq 0,$$

so *A* is a dissipative operator.

- So long as the domain of an operator *A* (a matrix) is the whole Euclidean space, then it is dissipative if and only if *A*+*A*<sup>\*</sup> (the sum of A and its [adjoint](https://en.wikipedia.org/wiki/Adjoint_matrix)) does not have any positive eigenvalue, and (consequently) all such operators are maximally dissipative. This criterion follows from the fact that the real part of $x^{*}Ax,$ which must be nonpositive for any *x*, is $x^{*}\frac{A+A^{*}}2x.$ The eigenvalues of this [quadratic form](wikipedia://en/251478) must therefore be nonpositive. (The fact that the real part of $x^{*}Ax,$ must be nonpositive implies that the real parts of the eigenvalues of *A* must be nonpositive, but this is not sufficient. For example, if $A=\begin{pmatrix}-1 & 3 \\0 & -1\end{pmatrix}$ then its eigenvalues are negative, but the eigenvalues of *A*+*A*<sup>\*</sup> are −5 and 1, so *A* is not dissipative.) An equivalent condition is that for some (and hence any) positive $\lambda, \lambda-A$ has an inverse and the operator $(\lambda+A)(\lambda-A)^{-1}$ is a contraction (that is, it either diminishes or leaves unchanged the norm of its operand). If the time derivative of a point *x* in the space is given by *Ax*, then the time evolution is governed by a [contraction semigroup](https://en.wikipedia.org/wiki/Contraction_semigroup) that constantly decreases the norm (or at least doesn't allow it to increase). (Note however that if the domain of *A* is a proper subspace, then *A* cannot be maximally dissipative because the range will not have a high enough dimensionality.)
- Consider *H* = [*L*<sup>2</sup>](wikipedia://en/28680558)(\[0, 1\]; **R**) with its usual inner product, and let *Au* = *u*′ (in this case a [weak derivative](wikipedia://en/1411087)) with domain *D*(*A*) equal to those functions *u* in the [Sobolev space](wikipedia://en/611964) $H^1([0,\;1];\;\mathbf{R})$ with *u*(1) = 0. *D*(*A*) is dense in *L*<sup>2</sup>(\[0, 1\]; **R**). Moreover, for every *u* in *D*(*A*), using [integration by parts](wikipedia://en/147252),

$$\langle u, A u \rangle = \int_{0}^{1} u(x) u'(x) \, \mathrm{d} x = - \frac1{2} u(0)^{2} \leq 0.$$

Hence, *A* is a dissipative operator. Furthermore, since there is a solution ([almost everywhere](wikipedia://en/44688)) in *D* to $u-\lambda u'=f$ for any *f* in *H*, the operator *A* is maximally dissipative. Note that in a case of infinite dimensionality like this, the range can be the whole Banach space even though the domain is only a proper subspace thereof.

- Consider *H* = *H*<sub>0</sub><sup>2</sup>(Ω; **R**) (see [Sobolev space](wikipedia://en/611964)) for an [open](wikipedia://en/39358) and [connected](wikipedia://en/6233) domain Ω ⊆ **R**<sup>*n*</sup> and let *A* = Δ, the [Laplace operator](wikipedia://en/174706), defined on the dense subspace of [compactly supported](https://en.wikipedia.org/wiki/Compactly_supported) smooth functions on Ω. Then, using integration by parts,

$$\langle u, \Delta u \rangle = \int_\Omega u(x) \Delta u(x) \, \mathrm{d} x = - \int_\Omega \big| \nabla u(x) \big|^{2} \, \mathrm{d} x = - \| \nabla u \|^2_{L^{2} (\Omega; \mathbf{R})} \leq 0,$$

so the Laplacian is a dissipative operator.
