# Simple point process

::: {#o1 .subject cue=lead name="Simple point process"}

A **simple point process** is a special type of [point process](wikipedia://en/2147685) in [probability theory](wikipedia://en/23542). In simple point processes, every point is assigned the weight one.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $S$ be a [locally compact](wikipedia://en/48632) [second countable](wikipedia://en/901459) [Hausdorff space](wikipedia://en/13637) and let $\mathcal S$ be its [Borel $\sigma$-algebra](wikipedia://en/43327). A [point process](wikipedia://en/2147685) $\xi$, interpreted as [random measure](wikipedia://en/10040846) on $(S, \mathcal S)$, is called a simple point process if it can be written as

$$\xi =\sum_{i \in I} \delta_{X_i}$$

for an [index set](wikipedia://en/393055) $I$ and [random elements](wikipedia://en/5215393) $X_i$ which are almost everywhere pairwise distinct. Here $\delta_x$ denotes the [Dirac measure](wikipedia://en/1019002) on the point $x$.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Simple point processes include many important classes of point processes such as [Poisson processes](https://en.wikipedia.org/wiki/Poisson_process), [Cox processes](wikipedia://en/6196078) and [binomial processes](wikipedia://en/57421458).

:::

## Uniqueness {#Uniqueness}

If $\mathcal I$ is a generating [ring](wikipedia://en/2686481) of $\mathcal S$ then a simple point process $\xi$ is uniquely determined by its values on the sets $U \in \mathcal I$. This means that two simple point processes $\xi$ and $\zeta$ have the same distributions iff

$$P(\xi(U)=0) = P(\zeta(U)=0) \text{ for all } U \in \mathcal I$$
