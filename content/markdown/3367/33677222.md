# Convex space

::: {#o1 .subject cue=lead name="Convex space"}

In [mathematics](wikipedia://en/18831), a **convex space** (or **barycentric algebra**) is a space in which it is possible to take [convex combinations](wikipedia://en/794534) of any finite set of points.[^o2][^o3]

:::

::: {#o5 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A convex space can be defined as a set $X$ equipped with a binary convex combination operation $c_\lambda : X \times X \rightarrow X$ for each $\lambda \in [0,1]$ satisfying:

- $$c_0(x,y)=x$$
- $$c_1(x,y)=y$$
- $$c_\lambda(x,x)=x$$
- $$c_\lambda(x,y)=c_{1-\lambda}(y,x)$$
- $c_\lambda(x,c_\mu(y,z))=c_{\lambda\mu}\left(c_{\frac{\lambda(1-\mu)}{1-\lambda\mu}}(x,y),z\right)$ (for $\lambda\mu\neq 1$)

From this, it is possible to define an n-ary convex combination operation, parametrised by an n-tuple $(\lambda_1, \dots, \lambda_n)$, where $\sum_i\lambda_i = 1$.

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

Any real [affine space](wikipedia://en/298834) is a convex space. More generally, any [convex subset](https://en.wikipedia.org/wiki/Convex_subset) of a real affine space is a convex space.

:::

## History {#History}

Convex spaces have been independently invented many times and given different names, dating back at least to [Stone](wikipedia://en/758331) (1949).[^o9] They were also studied by [Neumann](wikipedia://en/49819507) (1970)[^o10] and Świrszcz (1974),[^o11] among others.

[Herstein](https://en.wikipedia.org/wiki/Israel_Herstein) and [Milnor](wikipedia://en/61632) (1953)[^o12] used convex spaces to prove the [Mixture-space theorem](https://en.wikipedia.org/wiki/Mixture-space_theorem).
