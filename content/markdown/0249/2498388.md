# List of logic symbols

::: {#o1 .subject cue=lead name="List of logic symbols"}

In [logic](wikipedia://en/46426065), a set of [symbols](https://en.wikipedia.org/wiki/Symbol_%28logic%29) is commonly used to express logical representation. The following table lists many common symbols, together with their name, how they should be read out loud, and the related field of [mathematics](wikipedia://en/18831). In addition, the subsequent columns contain an informal explanation, a short example, the [Unicode](https://en.wikipedia.org/wiki/Unicode) location, the name for use in [HTML](https://en.wikipedia.org/wiki/HTML) documents,[^o2] and the [LaTeX](https://en.wikipedia.org/wiki/LaTeX) symbol.

:::
