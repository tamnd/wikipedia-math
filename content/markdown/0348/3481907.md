# Rank mobility index

::: {#o1 .subject cue=lead name="Rank mobility index"}

In [demographics](https://en.wikipedia.org/wiki/Demographics), the **rank mobility index (RMI)** is a measure of a [city](https://en.wikipedia.org/wiki/City)'s change in population rank among a group of cities.[^o2][^o3]

:::

Formally

$$RMI=\frac{R_1-R_2}{R_1+R_2},$$

where

- *R*<sub>1</sub> = city's rank at time 1
- *R*<sub>2</sub> = city's rank at time 2

A RMI value must be between −1 and 1. A RMI of 0 indicates no change.[^o4][^o5]
