# Double-negation translation

::: {#o1 .subject cue=lead name="Double-negation translation"}

In [proof theory](wikipedia://en/183478), a discipline within [mathematical logic](wikipedia://en/19636), **double-negation translation**, sometimes called **negative translation**, is a general approach for embedding [classical logic](wikipedia://en/55868) into [intuitionistic logic](wikipedia://en/169262). Typically it is done by [translating](wikipedia://en/73032003) [formulas](https://en.wikipedia.org/wiki/Formula_%28logic%29) to formulas that are classically equivalent but intuitionistically inequivalent. Particular instances of double-negation translations include **Glivenko's translation** for [propositional logic](wikipedia://en/18154), and the **Gödel–Gentzen translation** and **Kuroda's translation** for [first-order logic](wikipedia://en/10983).

:::

::: {#o3 .pointer-item cue=pointer name="Glivenko's translation"}

## Propositional logic {#Propositional_logic}

The easiest double-negation translation to describe comes from **Glivenko's theorem**, proved by [Valery Glivenko](wikipedia://en/21711296) in 1929.[^n1] It maps each classical formula φ to its [double negation](wikipedia://en/379833) ¬¬φ. Glivenko's theorem states:

If φ is a [propositional formula](wikipedia://en/1557634), then φ is a classical [tautology](wikipedia://en/4495335) [if and only if](wikipedia://en/14922) ¬¬φ is an intuitionistic tautology.

Glivenko's theorem implies the more general statement:

If *T* is a set of propositional formulas and φ a propositional formula, then *T* ⊢ φ in classical logic if and only if *T* ⊢ ¬¬φ in intuitionistic logic.

In particular, a set of propositional formulas is intuitionistically consistent if and only if it is classically [satisfiable](https://en.wikipedia.org/wiki/Satisfiable).

:::

## First-order logic {#First-order_logic}

The *Gödel–Gentzen translation* (named after [Kurt Gödel](wikipedia://en/16736) and [Gerhard Gentzen](wikipedia://en/46027)) associates with each formula φ in a first-order language another formula φ<sup>N</sup>, which is [defined inductively](wikipedia://en/1047605):

- If φ is atomic, then φ<sup>N</sup> is ¬¬φ

as above, but furthermore

- (φ ∨ θ)<sup>N</sup> is ¬(¬φ<sup>N</sup> ∧ ¬θ<sup>N</sup>)
- (∃*x* φ)<sup>N</sup> is ¬(∀*x* ¬φ<sup>N</sup>)

and otherwise

- (φ ∧ θ)<sup>N</sup> is φ<sup>N</sup> ∧ θ<sup>N</sup>
- (φ → θ)<sup>N</sup> is φ<sup>N</sup> → θ<sup>N</sup>
- (¬φ)<sup>N</sup> is ¬φ<sup>N</sup>
- (∀*x* φ)<sup>N</sup> is ∀*x* φ<sup>N</sup>

This translation has the property that φ<sup>N</sup> is classically equivalent to φ. [Troelstra](https://en.wikipedia.org/wiki/Anne_Troelstra) and [Van Dalen](wikipedia://en/26828544) give a description, due to Leivant, of formulas that do imply their Gödel–Gentzen translation in intuitionistic first-order logic also.[^n2] There, this is not the case for all formulas. (This is related to the fact that propositions with additional double-negations can be stronger than their simpler variant. E.g., ¬¬φ → θ always implies φ → θ, but the schema in the other direction would imply double-negation elimination.)

### Equivalent variants {#Equivalent_variants}

Due to constructive equivalences, there are several alternative definitions of the translation. For example, a valid [De Morgan's law](https://en.wikipedia.org/wiki/De_Morgan's_law) allows one to rewrite a negated [disjunction](wikipedia://en/7962). One possibility can thus succinctly be described as follows: Prefix "¬¬" before every [atomic formula](wikipedia://en/4472066), but also to every disjunction and [existential quantifier](https://en.wikipedia.org/wiki/Existential_quantifier),

- (φ ∨ θ)<sup>N</sup> is ¬¬(φ<sup>N</sup> ∨ θ<sup>N</sup>)
- (∃*x* φ)<sup>N</sup> is ¬¬∃*x* φ<sup>N</sup>

Another procedure, known as [Kuroda](wikipedia://en/57830988)'s translation, is to construct a translated φ by putting "¬¬" before the whole formula and after every [universal quantifier](https://en.wikipedia.org/wiki/Universal_quantifier). This procedure exactly reduces to the propositional translation whenever φ is propositional.

Thirdly, one may instead prefix "¬¬" before every subformula of φ, as done by [Kolmogorov](https://en.wikipedia.org/wiki/Kolmogorov). Such a translation is the logical counterpart to the [call-by-name](https://en.wikipedia.org/wiki/Call-by-name) [continuation-passing style](https://en.wikipedia.org/wiki/Continuation-passing_style) translation of [functional programming languages](https://en.wikipedia.org/wiki/Functional_programming_languages) along the lines of the [Curry–Howard correspondence](wikipedia://en/254299) between proofs and programs.[^o8]

The Gödel-Gentzen- and Kuroda-translated formulas of each φ are provably equivalent to one another, and this result holds already in [minimal propositional logic](wikipedia://en/26267678). And further, in intuitionistic propositional logic, the Kuroda- and Kolmogorov-translated formulas are equivalent also.

The mere propositional mapping of φ to ¬¬φ does not extend to a sound translation of first-order logic, as the so called double negation shift

∀*x* ¬¬φ(*x*) → ¬¬∀*x* φ(*x*)

is not a theorem of intuitionistic predicate logic. So the negations in φ<sup>N</sup> have to be placed in a more particular way.

::: {#o10 .statement cue=heading name="Results"}

### Results {#Results}

Let *T*<sup>N</sup> consist of the double-negation translations of the formulas in *T*.

The fundamental soundness theorem states:[^n3][^n4]

If *T* is a set of axioms and φ is a formula, then *T* proves φ using classical logic if and only if *T*<sup>N</sup> proves φ<sup>N</sup> using intuitionistic logic.

#### Arithmetic {#Arithmetic}

The double-negation translation was used by Gödel (1933) to study the relationship between classical and intuitionistic theories of the natural numbers ("arithmetic").[^n5] He obtains the following result:

If a formula φ is provable from the axioms of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic) then φ<sup>N</sup> is provable from the axioms of [Heyting arithmetic](wikipedia://en/2545815).

This result shows that if Heyting arithmetic is consistent then so is Peano arithmetic. This is because a contradictory formula θ ∧ ¬θ is interpreted as θ<sup>N</sup> ∧ ¬θ<sup>N</sup>, which is still contradictory. Moreover, the proof of the relationship is entirely constructive, giving a way to transform a proof of θ ∧ ¬θ in Peano arithmetic into a proof of θ<sup>N</sup> ∧ ¬θ<sup>N</sup> in Heyting arithmetic.

By combining the double-negation translation with the [Friedman translation](wikipedia://en/21775342), it is in fact possible to prove that Peano arithmetic is [Π<sup>0</sup><sub>2</sub>](wikipedia://en/186475)-[conservative](wikipedia://en/1840214) over Heyting arithmetic.

:::
