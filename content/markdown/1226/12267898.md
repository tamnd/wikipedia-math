# Alexander matrix

::: {#o1 .subject cue=lead name="Alexander matrix"}

In [mathematics](wikipedia://en/18831), an **Alexander matrix** is a presentation matrix for the [Alexander invariant](https://en.wikipedia.org/wiki/Alexander_invariant) of a [knot](wikipedia://en/366808). The [determinant](wikipedia://en/8468) of an Alexander matrix is the [Alexander polynomial](wikipedia://en/1107647) for the knot.[^o2]

:::
