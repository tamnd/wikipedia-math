# Garlic routing

::: {#o1 .subject cue=lead name="Garlic routing"}

**Garlic routing**[^o2] is a variant of [onion routing](https://en.wikipedia.org/wiki/Onion_routing) that encrypts multiple messages together to make it more difficult[^o3] for attackers to perform [traffic analysis](https://en.wikipedia.org/wiki/Traffic_analysis) while also increasing the speed of [data transfer](https://en.wikipedia.org/wiki/Data_transfer).[^o4]

:::

[Michael J. Freedman](https://en.wikipedia.org/wiki/Michael_J._Freedman) defined garlic routing as an extension of onion routing, in which multiple messages are bundled together. He called each message a "bulb", whereas I2P calls them "[garlic](https://en.wikipedia.org/wiki/Garlic) cloves."[^o5] All messages, each with their own delivery instructions, are exposed at the endpoint. This enables efficient bundling of an onion routing reply block with the original message.[^o6]

Garlic routing is one of the key factors that distinguishes [I2P](wikipedia://en/538434) from [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29) and other privacy-focused or [encryption](wikipedia://en/10294) networks. The name alludes to the [garlic](https://en.wikipedia.org/wiki/Garlic) plant, whose multi-layered structure this protocol resembles. "Garlic routing" was coined by Michael J. Freedman in [Roger Dingledine](wikipedia://en/48434704)'s Free Haven Master's thesis Section 8.1.1 (June 2000), as derived from [Onion Routing](https://en.wikipedia.org/wiki/Onion_routing).[^o7] However, the garlic routing implementation in [I2P](wikipedia://en/538434) differs from the design proposed by Freedman. The key distinction is that garlic routing used unidirectional tunnels, while mainstream alternatives like [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29) and [Mixmaster](https://en.wikipedia.org/wiki/Mixmaster_anonymous_remailer) use bidirectional tunnels.

## Garlic Cast: Lightweight and Decentralized Content Sharing {#Garlic_Cast:_Lightweight_and_Decentralized_Content_Sharing}

One potential implementation of the garlic routing protocol is shown in the paper *Garlic Cast: Lightweight and Decentralized Anonymous Content Sharing*.[^o9] The idea is to provide a resilient and low latency anonymous content sharing network based on garlic routing. The distinguishing benefit that makes the system different from traditional [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29) networks is that it is designed around secure, fast communication. This is achieved by allowing the Garlic Cast system to use random walks to find proxies in the overlay network, then applying a security-enhanced Information Dispersal Algorithm to deliver content efficiently and securely.[^o9] Lastly, the Garlic Cast network is designed to resist a wide range of attacks while maintaining a high level of anonymity.[^o10]

## List of P2P applications that use garlic routing {#List_of_P2P_applications_that_use_garlic_routing}

- [I2P](wikipedia://en/538434), an anonymizing [overlay network](https://en.wikipedia.org/wiki/Overlay_network) that allows applications to run on top of it (open-source, written in Java)
- [Perfect Dark](wikipedia://en/11926775), a P2P client which relies on a [mixnet](wikipedia://en/6200269) and [distributed datastore](https://en.wikipedia.org/wiki/Distributed_file_system) to provide anonymity (freeware, written for [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows))
