# Narayana number

::: {#o1 .subject cue=lead name="Narayana number"}

In [combinatorics](wikipedia://en/5170), the **Narayana numbers** $\operatorname{N}(n, k), n \in \mathbb{N}^+, 1 \le k \le n$ form a [triangular array](wikipedia://en/28639331) of [natural numbers](wikipedia://en/21474), called the **Narayana triangle,** that occur in various [counting problems](https://en.wikipedia.org/wiki/Combinatorial_enumeration). They are named after Canadian mathematician [T. V. Narayana (1930–1987)](wikipedia://en/75463339).

:::

::: {#o4 .statement cue=named-heading name="Formula"}

## Formula {#Formula}

The Narayana numbers can be expressed in terms of [binomial coefficients](wikipedia://en/4668):

$$\operatorname{N}(n, k) = \frac{1}{k} {n-1 \choose k-1} {n \choose k-1} = \frac{1}{n} {n \choose k} {n \choose k-1}$$

:::

## Combinatorial interpretations {#Combinatorial_interpretations}

### Dyck words {#Dyck_words}

An example of a counting problem whose solution can be given in terms of the Narayana numbers $\operatorname{N}(n, k)$, is the number of words containing $n$ pairs of parentheses, which are correctly matched (known as [Dyck words](https://en.wikipedia.org/wiki/Dyck_word)) and which contain $k$ distinct nestings. For instance, $\operatorname{N}(4, 2) = 6$, since with four pairs of parentheses, six sequences can be created which each contain two occurrences the sub-pattern ():

(()(())) ((()())) ((())()) ()((())) (())(()) ((()))()

From this example it should be obvious that $\operatorname{N}(n, 1) = 1$, since the only way to get a single sub-pattern () is to have all the opening parentheses in the first $n$ positions, followed by all the closing parentheses. Also $\operatorname{N}(n, n) = 1$, as $n$ distinct nestings can be achieved only by the repetitive pattern ()()()…().

More generally, it can be shown that the Narayana triangle is symmetric:

$$\operatorname{N}(n, k) = \operatorname{N}(n, n-k+1)$$

The sum of the rows in this triangle equal the [Catalan numbers](https://en.wikipedia.org/wiki/Catalan_numbers):

$$\operatorname{N}(n, 1) + \operatorname{N}(n, 2) + \operatorname{N}(n, 3) + \cdots + \operatorname{N}(n, n) = C_n$$

### Monotonic lattice paths {#Monotonic_lattice_paths}

The Narayana numbers also count the number of [lattice paths](wikipedia://en/42123338) from $(0, 0)$ to $(2n, 0)$, with steps only northeast and southeast, not straying below the $x$-axis, with $k$ peaks.

The sum of $\operatorname{N}(4, k)$ is 1 + 6 + 6 + 1 = 14, which is the 4th Catalan number, $C_4$. This sum coincides with the interpretation of Catalan numbers as the number of monotonic paths along the edges of an $n \times n$ grid that do not pass above the diagonal.

### Rooted trees {#Rooted_trees}

*Image: Unlabeled ordered rooted trees of 4 edges and 2 leaves.svg.* The 6 ordered rooted trees of 4 edges and 2 leaves, corresponding to the Narayana number N(4, 2)

The number of unlabeled [ordered](wikipedia://en/48560#Ordered_tree) [rooted](wikipedia://en/48560#Rooted_tree) trees with $n$ edges and $k$ leaves is equal to $\operatorname{N}(n, k)$.

This is analogous to the above examples:

- Each Dyck word can be represented as a rooted tree. We start with a single node – the root node. This is initially the *active node*. Reading the word from left to right, when the symbol is an opening parenthesis, add a child to the active node and set this child as the active node. When the symbol is a closing parenthesis, set the parent of the active node as the active node. This way we obtain a tree, in which every non-root node corresponds to a matching pair of parentheses, and its children are the nodes corresponding to the successive Dyck words within these parentheses. Leaf nodes correspond to empty parentheses: (). In analogous fashion, we can construct a Dyck word from a rooted tree via a depth-first search. Thus, there is an isomorphism between Dyck words and rooted trees.
- In the above figures of lattice paths, each upward edge from the horizontal line at height $y$ to $y$$+1$ corresponds to an edge between node $y$ and its child. A node $y$ has as many children, as there are upward edges leading from the horizontal line at height $y$. For example, in the first path for $\operatorname{N}(4, 3)$, the nodes $0$ and $1$ will have two children each; in the last (sixth) path, node $0$ will have three children and node $1$ will have one child. To construct a rooted tree from a lattice path and vice versa, we can employ an algorithm similar to the one mentioned the previous paragraph. As with Dyck words, there is an isomorphism between lattice paths and rooted trees.

## Partitions {#Partitions}

*Image: Noncrossing partitions 4; Hasse.svg.* The 1,6,6,1 [non-crossing partitions](https://en.wikipedia.org/wiki/Non-crossing_partition) with 1,2,3,4 blocks of a 4-element set

In the study of partitions, we see that in a set containing $n$ elements, we may partition that set in $B_n$ different ways, where $B_n$ is the $n$*<sup>th</sup>* [Bell number](wikipedia://en/201022). Furthermore, the number of ways to partition a set into exactly $k$ blocks we use the [Stirling numbers](wikipedia://en/2229292) $S(n, k)$. Both of these concepts are a bit off-topic, but a necessary foundation for understanding the use of the Narayana numbers. In both of the above two notions crossing partitions are accounted for.

To reject the crossing partitions and count only the [non-crossing partitions](https://en.wikipedia.org/wiki/Non-crossing_partition), we may use the [Catalan numbers](wikipedia://en/216488) to count the non-crossing partitions of all $n$ elements of the set, $C_n$. To count the non-crossing partitions in which the set is partitioned in exactly $k$ blocks, we use the Narayana number $\operatorname{N}(n, k)$.

## Generating function {#Generating_function}

The generating function for the Narayana numbers is [^n1]

$$\sum_{n=1}^\infty \sum_{k=1}^n \operatorname{N}(n, k) z^n t^{k-1} = \frac{1-z(t+1) - \sqrt{1-2z(t+1)+z^2(t-1)^2}}{2tz} \;.$$
