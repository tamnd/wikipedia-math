# Clifford module bundle

::: {#o1 .subject cue=lead name="Clifford module bundle"}

In [differential geometry](wikipedia://en/8625), a **Clifford module bundle**, a **bundle of Clifford modules** or just **Clifford module** is a [vector bundle](wikipedia://en/276524) whose fibers are [Clifford modules](wikipedia://en/709999), the representations of [Clifford algebras](wikipedia://en/45305). The canonical example is a [spinor bundle](wikipedia://en/348085).[^o2][^o3] In fact, on a [Spin manifold](https://en.wikipedia.org/wiki/Spin_manifold), every Clifford module is obtained by twisting the spinor bundle.[^o4]

:::

The notion "Clifford module bundle" should not be confused with a [Clifford bundle](wikipedia://en/8687388), which is a bundle of Clifford algebras.

## Spinor bundles {#Spinor_bundles}

Given an oriented [Riemannian manifold](wikipedia://en/144652) *M* one can ask whether it is possible to construct a bundle of [irreducible](https://en.wikipedia.org/wiki/Irreducible_module) [Clifford modules](wikipedia://en/709999) over *Cℓ*(*T*\**M*). In fact, such a bundle can be constructed if and only if *M* is a [spin manifold](https://en.wikipedia.org/wiki/Spin_manifold).

Let *M* be an *n*-dimensional spin manifold with [spin structure](wikipedia://en/2844303) *F*<sub>Spin</sub>(*M*) → *F*<sub>SO</sub>(*M*) on *M*. Given any *Cℓ*<sub>*n*</sub>**R**-module *V* one can construct the associated [spinor bundle](wikipedia://en/348085)

$$S(M) = F_{\mathrm{Spin}}(M) \times_\sigma V\,$$

where σ : Spin(*n*) → GL(*V*) is the representation of Spin(*n*) given by left multiplication on *S*. Such a spinor bundle is said to be *real*, *complex*, *graded* or *ungraded* according to whether on not *V* has the corresponding property. Sections of *S*(*M*) are called [spinors](wikipedia://en/29276) on *M*.

Given a spinor bundle *S*(*M*) there is a natural bundle map

$$C\ell(T^*M) \otimes S(M) \to S(M)$$

which is given by left multiplication on each fiber. The spinor bundle *S*(*M*) is therefore a bundle of [Clifford modules](wikipedia://en/709999) over *Cℓ*(*T*\**M*).
