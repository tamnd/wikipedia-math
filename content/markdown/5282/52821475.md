# D-space

::: {#o1 .subject cue=lead name="D-space"}

In [mathematics](wikipedia://en/18831), a **D-space** is a [topological space](wikipedia://en/30450) where for every [neighborhood](wikipedia://en/1529485) assignment of that space, a [cover](wikipedia://en/317552) can be created from the union of neighborhoods from the neighborhood assignment of some [closed](wikipedia://en/47279) [discrete](wikipedia://en/390557) [subset](wikipedia://en/27631) of the space.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An open neighborhood assignment is a function that assigns an open neighborhood to each element in the set. More formally, given a topological space $X$. An open neighborhood assignment is a function $f: X \to N(X)$ where $f(x)$ is an open neighborhood.

A topological space $X$ is a D-space if for every given neighborhood assignment $N_x : X \to N(X)$, there exists a closed discrete subset $D$ of the [space](wikipedia://en/27667) $X$ such that $\bigcup_{x\in D}N_x=X$.

:::

## History {#History}

The notion of D-spaces was introduced by Eric Karel van Douwen and E.A. Michael. It first appeared in a 1979 paper by van Douwen and Washek Frantisek Pfeffer in the [Pacific Journal of Mathematics](https://en.wikipedia.org/wiki/Pacific_Journal_of_Mathematics).[^o5] Whether every [Lindelöf](wikipedia://en/310480) and [regular](wikipedia://en/53058) [topological space](wikipedia://en/30450) is a D-space is known as the **D-space problem**. This problem is among twenty of the most important problems of set theoretic topology.[^o6]

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every [Menger space](wikipedia://en/51474451) is a D-space.[^o9]
- A subspace of a topological [linearly ordered](https://en.wikipedia.org/wiki/Linearly_ordered_set) space is a D-space [iff](https://en.wikipedia.org/wiki/Iff) it is a [paracompact space](wikipedia://en/48631).[^o10]

:::
