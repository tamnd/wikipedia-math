# Subsequential limit

::: {#o1 .subject cue=lead name="Subsequential limit"}

In [mathematics](wikipedia://en/18831), a **subsequential limit** of a [sequence](wikipedia://en/27838) is the [limit](wikipedia://en/285773) of some [subsequence](wikipedia://en/236098).[^o2] Every subsequential limit is a [cluster point](https://en.wikipedia.org/wiki/Cluster_point), but not conversely. In [first-countable](wikipedia://en/904940) spaces, the two concepts coincide.

:::

In a topological space, if every subsequence has a subsequential limit to the same point, then the original sequence also converges to that limit. This need not hold in more generalized notions of convergence, such as the space of [almost everywhere convergence](wikipedia://en/340198#Almost_everywhere_convergence).

The [supremum](https://en.wikipedia.org/wiki/Supremum) of the set of all subsequential limits of some sequence is called the limit superior, or limsup. Similarly, the infimum of such a set is called the limit inferior, or liminf. See [limit superior and limit inferior](https://en.wikipedia.org/wiki/Limit_superior_and_limit_inferior).[^o2]

If $(X, d)$ is a [metric space](wikipedia://en/20018) and there is a [Cauchy sequence](wikipedia://en/6085) such that there is a subsequence converging to some $x,$ then the sequence also converges to $x.$
