# Level set

::: {#o1 .subject cue=lead name="Level set"}

In [mathematics](wikipedia://en/18831), a **level set** of a [real-valued function](wikipedia://en/22284647) $f$ of $n$ [real variables](wikipedia://en/39783039) is a [set](wikipedia://en/26691) where the function takes on a given [constant](wikipedia://en/24758132) value $c$, that is:

:::

$$L_c(f) = \left\{ (x_1, \ldots, x_n) \mid f(x_1, \ldots, x_n) = c \right\}~.$$

When the number of independent variables is two, a level set is called a **level curve**, also known as *[contour line](wikipedia://en/650086)* or *isoline*; so a level [curve](wikipedia://en/89246) is the set of all real-valued solutions of an equation in two variables $x_{1}$ and $x_{2}$. When $n = 3$, a level set is called a **level surface** (or *[isosurface](https://en.wikipedia.org/wiki/Isosurface)*); so a level [surface](wikipedia://en/4342970) is the set of all real-valued roots of an equation in three variables $x_{1}$, $x_{2}$ and $x_{3}$. For higher values of $n$, the level set is a **level hypersurface**, the set of all real-valued roots of an equation in $n > 3$ variables (a [higher-dimensional](https://en.wikipedia.org/wiki/Higher-dimensional) [hypersurface](wikipedia://en/525101)).

A level set is a special case of a [fiber](wikipedia://en/6603892).

## Alternative names {#Alternative_names}

*Image: trefoil knot level curves.png.* Intersections of a [co-ordinate](https://en.wikipedia.org/wiki/Co-ordinate) function's level surfaces with a [trefoil knot](wikipedia://en/404773). Red curves are closest to the viewer, while yellow curves are farthest.

Level sets show up in many applications, often under different names. For example, an [implicit curve](wikipedia://en/11286809) is a level curve, which is considered independently of its neighbor curves, emphasizing that such a curve is defined by an [implicit equation](https://en.wikipedia.org/wiki/Implicit_equation). Analogously, a level surface is sometimes called an implicit surface or an [isosurface](https://en.wikipedia.org/wiki/Isosurface).

The name isocontour is also used, which means a contour of equal height. In various application areas, isocontours have received specific names, which indicate often the nature of the values of the considered function, such as [isobar](https://en.wikipedia.org/wiki/Isobar_%28meteorology%29), [isotherm](https://en.wikipedia.org/wiki/Isotherm_%28contour_line%29), [isogon](wikipedia://en/650086#Types), [isochrone](https://en.wikipedia.org/wiki/Isochrone_map), [isoquant](https://en.wikipedia.org/wiki/Isoquant) and [indifference curve](https://en.wikipedia.org/wiki/Indifference_curve).

## Examples {#Examples}

Consider the 2-dimensional Euclidean distance:

$$d(x, y) = \sqrt{x^2 + y^2}$$

A level set $L_r(d)$ of this function consists of those points that lie at a distance of $r$ from the origin, that make a [circle](wikipedia://en/6220). For example, $(3, 4) \in L_5(d)$, because $d(3, 4) = 5$. Geometrically, this means that the point $(3, 4)$ lies on the circle of radius 5 centered at the origin. More generally, a [sphere](wikipedia://en/27859) in a [metric space](wikipedia://en/20018) $(M, m)$ with radius $r$ centered at $x \in M$ can be defined as the level set $L_r(y \mapsto m(x, y))$.

A second example is the plot of [Himmelblau's function](wikipedia://en/17038012) shown in the figure to the right. Each curve shown is a level curve of the function, and they are spaced logarithmically: if a curve represents $L_x$, the curve directly "within" represents $L_{x/10}$, and the curve directly "outside" represents $L_{10x}$.

## Level sets versus the gradient {#Level_sets_versus_the_gradient}

*Image: level grad.svg.* Consider a function *f* whose graph looks like a hill. The blue curves are the level sets; the red curves follow the direction of the gradient. The cautious hiker follows the blue paths; the bold hiker follows the red paths. Note that blue and red paths always cross at right angles.

**[Theorem](wikipedia://en/30977):** If the function $f$ is [differentiable](wikipedia://en/330206), the [gradient](wikipedia://en/12461) of $f$ at a point is either zero, or perpendicular to the level set of $f$ at that point.

To understand what this means, imagine that two hikers are at the same location on a mountain. One of them is bold, and decides to go in the direction where the slope is steepest. The other one is more cautious and does not want to either climb or descend, choosing a path which stays at the same height. In our analogy, the above theorem says that the two hikers will depart in directions perpendicular to each other.

A consequence of this theorem (and its proof) is that if $f$ is differentiable, a level set is a [hypersurface](wikipedia://en/525101) and a [manifold](wikipedia://en/2073470) outside the [critical points](wikipedia://en/1951424) of $f$. At a critical point, a level set may be reduced to a point (for example at a [local extremum](https://en.wikipedia.org/wiki/Local_extremum) of $f$ ) or may have a [singularity](wikipedia://en/981915) such as a [self-intersection point](wikipedia://en/3148602) or a [cusp](wikipedia://en/6851758).

## Sublevel and superlevel sets {#Sublevel_and_superlevel_sets}

A set of the form

$$L_c^-(f) = \left\{ (x_1, \dots, x_n) \mid f(x_1, \dots, x_n) \leq c \right\}$$

is called a **sublevel set** of *f* (or, alternatively, a **lower level set** or **trench** of *f*). A **strict sublevel** set of *f* is

$$\left\{ (x_1, \dots, x_n) \mid f(x_1, \dots, x_n) < c \right\}$$

Similarly

$$L_c^+(f) = \left\{ (x_1, \dots, x_n) \mid f(x_1, \dots, x_n) \geq c \right\}$$

is called a **superlevel set** of *f* (or, alternatively, an **upper level set** of *f*). And a **strict superlevel set** of *f* is

$$\left\{ (x_1, \dots, x_n) \mid f(x_1, \dots, x_n) > c \right\}$$

Sublevel sets are important in [minimization theory](wikipedia://en/52033). By [Weierstrass's theorem](wikipedia://en/276881#Extension_to_semi-continuous_functions), the [boundness](https://en.wikipedia.org/wiki/Totally_bounded_set) of some [non-empty](wikipedia://en/9566) sublevel set and the lower-semicontinuity of the function implies that a function attains its minimum. The [convexity](wikipedia://en/6292) of all the sublevel sets characterizes [quasiconvex functions](wikipedia://en/5781226).[^o9]
