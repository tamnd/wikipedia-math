# Dinatural transformation

::: {#o1 .subject cue=lead name="Dinatural transformation"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **dinatural transformation** $\alpha$ between two [functors](wikipedia://en/10987)

:::

$$S,T : C^{\mathrm{op}}\times C\to D,$$

written

$$\alpha : S\ddot\to T,$$

is a function that to every object $c$ of $C$ associates an arrow

$\alpha_c : S(c,c)\to T(c,c)$ of $D$

and satisfies the following [coherence property](https://en.wikipedia.org/wiki/Coherence_property): for every morphism $f:c\to c'$ of $C$ the diagram

*Image: Dinatural transfo1.png.*

commutes.[^o2] Note the direction of $S(f,g)$ is opposite along $f$ in the first component since it is contravariant.

The composition of two dinatural transformations need not be dinatural.
