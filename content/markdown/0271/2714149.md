# Symmetry in mathematics

::: {#o1 .subject cue=lead name="Symmetry in mathematics"}

*Image: E8Petrie.svg.* The [root system](https://en.wikipedia.org/wiki/Root_system_of_a_semi-simple_Lie_algebra) of the exceptional [Lie group](wikipedia://en/17945) [E<sub>8</sub>](wikipedia://en/647994). Lie groups have many symmetries.

**[Symmetry](wikipedia://en/53741)** occurs not only in [geometry](wikipedia://en/18973446), but also in other branches of mathematics. Symmetry is a type of [invariance](wikipedia://en/1126638): the property that a mathematical object remains unchanged under a set of [operations](wikipedia://en/4140245) or [transformations](https://en.wikipedia.org/wiki/Transformation_%28mathematics%29).[^o2]

:::

Given a structured object *X* of any sort, a [symmetry](wikipedia://en/53741) is a [mapping](https://en.wikipedia.org/wiki/Mapping_%28mathematics%29) of the object onto itself which preserves the structure. This can occur in many ways; for example, if *X* is a set with no additional structure, a symmetry is a [bijective](wikipedia://en/3942) map from the set to itself, giving rise to [permutation groups](wikipedia://en/24634). If the object *X* is a set of points in the plane with its [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) structure or any other [metric space](wikipedia://en/20018), a symmetry is a [bijection](wikipedia://en/3942) of the set to itself which preserves the distance between each pair of points (i.e., an [isometry](wikipedia://en/254777)).

In general, every kind of structure in mathematics will have its own kind of symmetry, many of which are listed in the given points mentioned above.

## Symmetry in geometry {#Symmetry_in_geometry}

The types of symmetry considered in basic geometry include [reflectional symmetry](wikipedia://en/1390873), [rotational symmetry](wikipedia://en/701096), [translational symmetry](https://en.wikipedia.org/wiki/Translational_symmetry) and [glide reflection symmetry](https://en.wikipedia.org/wiki/Glide_reflection_symmetry), which are described more fully in the main article [Symmetry (geometry)](wikipedia://en/44362809).

## Symmetry in calculus {#Symmetry_in_calculus}

### Even and odd functions {#Even_and_odd_functions}

#### Even functions {#Even_functions}

*Image: Function x^2.svg.* *ƒ*(*x*) = *x*<sup>2</sup> is an example of an even function.[^o7]

Let *f*(*x*) be a [real](wikipedia://en/20646438)-valued function of a real variable, then *f* is **even** if the following equation holds for all *x* and *\-x* in the domain of *f*:

$$f(x) = f(-x)$$

Geometrically speaking, the graph face of an even function is [symmetric](wikipedia://en/53741) with respect to the *y*-axis, meaning that its [graph](wikipedia://en/87352) remains unchanged after [reflection](wikipedia://en/295829) about the *y*-axis. Examples of even functions include $|x|$, *x*<sup>2</sup>, *x*<sup>4</sup>, [cos](https://en.wikipedia.org/wiki/Trigonometric_function)(*x*), and [cosh](https://en.wikipedia.org/wiki/Hyperbolic_function)(*x*).

#### Odd functions {#Odd_functions}

*Image: Function x^3.svg.* *ƒ*(*x*) = *x*<sup>3</sup> is an example of an odd function.

Again, let *f* be a [real](wikipedia://en/20646438)-valued function of a real variable, then *f* is **odd** if the following equation holds for all *x* and *\-x* in the domain of *f*:

$$-f(x) = f(-x)$$

That is,

$$f(x) + f(-x) = 0 \, .$$

Geometrically, the graph of an odd function has rotational symmetry with respect to the [origin](wikipedia://en/1313432), meaning that its [graph](wikipedia://en/87352) remains unchanged after [rotation](https://en.wikipedia.org/wiki/Coordinate_rotation) of 180 [degrees](wikipedia://en/1195294) about the origin. Examples of odd functions are *x*, *x*<sup>3</sup>, [sin](https://en.wikipedia.org/wiki/Sine)(*x*), [sinh](https://en.wikipedia.org/wiki/Hyperbolic_function)(*x*), and [erf](wikipedia://en/177111)(*x*).

### Integrating {#Integrating}

The [integral](wikipedia://en/15532) of an odd function from −*A* to +*A* is zero, provided that *A* is finite and that the function is integrable (e.g., has no vertical asymptotes between −*A* and *A*).[^o10]

The integral of an even function from −*A* to +*A* is twice the integral from 0 to +*A*, provided that *A* is finite and the function is integrable (e.g., has no vertical asymptotes between −*A* and *A*).[^o10] This also holds true when *A* is infinite, but only if the integral converges.

### Series {#Series}

- The [Maclaurin series](https://en.wikipedia.org/wiki/Maclaurin_series) of an even function includes only even powers.
- The Maclaurin series of an odd function includes only odd powers.
- The [Fourier series](wikipedia://en/59038) of a [periodic](wikipedia://en/76848) even function includes only [cosine](https://en.wikipedia.org/wiki/Trigonometric_function) terms.
- The Fourier series of a periodic odd function includes only [sine](https://en.wikipedia.org/wiki/Trigonometric_function) terms.

## Symmetry in linear algebra {#Symmetry_in_linear_algebra}

### Symmetry in matrices {#Symmetry_in_matrices}

In [linear algebra](wikipedia://en/18422), a **symmetric matrix** is a [square matrix](wikipedia://en/166022) that is equal to its [transpose](wikipedia://en/173844) (i.e., it is invariant under matrix transposition). Formally, matrix *A* is symmetric if

$$A = A^{T}.$$

By the definition of matrix equality, which requires that the entries in all corresponding positions be equal, equal matrices must have the same dimensions (as matrices of different sizes or shapes cannot be equal). Consequently, only square matrices can be symmetric.

The entries of a symmetric matrix are symmetric with respect to the [main diagonal](wikipedia://en/194990). So if the entries are written as *A* = (*a*<sub>*ij*</sub>), then *a*<sub>*ij*</sub> = a<sub>*ji*</sub>, for all indices *i* and *j*.

For example, the following 3×3 matrix is symmetric:

$$\begin{bmatrix} 1 & 7 & 3\\ 7 & 4 & -5\\ 3 & -5 & 6\end{bmatrix}$$

Every square [diagonal matrix](wikipedia://en/174080) is symmetric, since all off-diagonal entries are zero. Similarly, each diagonal element of a [skew-symmetric matrix](wikipedia://en/174055) must be zero, since each is its own negative.

In linear algebra, a [real](wikipedia://en/20646438) symmetric matrix represents a [self-adjoint operator](wikipedia://en/187408) over a [real](wikipedia://en/20646438) [inner product space](wikipedia://en/14856). The corresponding object for a [complex](wikipedia://en/5826) inner product space is a [Hermitian matrix](wikipedia://en/189682) with complex-valued entries, which is equal to its [conjugate transpose](wikipedia://en/217548). Therefore, in linear algebra over the complex numbers, it is often assumed that a symmetric matrix refers to one which has real-valued entries. Symmetric matrices appear naturally in a variety of applications, and typical numerical linear algebra software makes special accommodations for them.

## Symmetry in abstract algebra {#Symmetry_in_abstract_algebra}

### Symmetric groups {#Symmetric_groups}

The **symmetric group** *S*<sub>*n*</sub> (on a [finite set](wikipedia://en/11742) of *n* symbols) is the [group](wikipedia://en/19447) whose elements are all the [permutations](https://en.wikipedia.org/wiki/Permutations) of the *n* symbols, and whose [group operation](https://en.wikipedia.org/wiki/Group_operation) is the [composition](wikipedia://en/195947) of such permutations, which are treated as [bijective functions](wikipedia://en/3942) from the set of symbols to itself.[^o16] Since there are *n*! (*n* [factorial](wikipedia://en/10606)) possible permutations of a set of *n* symbols, it follows that the [order](wikipedia://en/493527) (i.e., the number of elements) of the symmetric group *S*<sub>*n*</sub> is *n*!.

### Symmetric polynomials {#Symmetric_polynomials}

A **symmetric polynomial** is a [polynomial](wikipedia://en/23000) *P*(*X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*n*</sub>) in *n* variables, such that if any of the variables are interchanged, one obtains the same polynomial. Formally, *P* is a *symmetric polynomial* if for any [permutation](wikipedia://en/44027) σ of the subscripts 1, 2, ..., *n*, one has *P*(*X*<sub>σ(1)</sub>, *X*<sub>σ(2)</sub>, ..., *X*<sub>σ(*n*)</sub>) = *P*(*X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*n*</sub>).

Symmetric polynomials arise naturally in the study of the relation between the roots of a polynomial in one variable and its coefficients, since the coefficients can be given by polynomial expressions in the roots, and all roots play a similar role in this setting. From this point of view, the [elementary symmetric polynomials](wikipedia://en/1440695) are the most fundamental symmetric polynomials. A [theorem](wikipedia://en/1440695#The_fundamental_theorem_of_symmetric_polynomials) states that any symmetric polynomial can be expressed in terms of elementary symmetric polynomials, which implies that every *symmetric* [polynomial expression](https://en.wikipedia.org/wiki/Polynomial_expression) in the roots of a [monic polynomial](wikipedia://en/314730) can alternatively be given as a polynomial expression in the coefficients of the polynomial.

::: {#o19 .example cue=heading name="Examples"}

#### Examples {#Examples}

In two variables *X*<sub>1</sub> and *X*<sub>2</sub>, one has symmetric polynomials such as:

- $$X_1^3+ X_2^3-7$$
- $$4 X_1^2X_2^2 +X_1^3X_2 + X_1X_2^3 +(X_1+X_2)^4$$

and in three variables *X*<sub>1</sub>, *X*<sub>2</sub> and *X*<sub>3</sub>, one has as a symmetric polynomial:

- $$X_1 X_2 X_3 - 2 X_1 X_2 - 2 X_1 X_3 - 2 X_2 X_3 \,$$

:::

### Symmetric tensors {#Symmetric_tensors}

In [mathematics](wikipedia://en/18831), a **symmetric tensor** is [tensor](wikipedia://en/29965) that is invariant under a [permutation](wikipedia://en/44027) of its vector arguments:

$$T(v_1,v_2,\dots,v_r) = T(v_{\sigma 1},v_{\sigma 2},\dots,v_{\sigma r})$$

for every permutation σ of the symbols {1,2,...,*r*}. Alternatively, an *r*<sup>th</sup> order symmetric tensor represented in coordinates as a quantity with *r* indices satisfies

$$T_{i_1i_2\dots i_r} = T_{i_{\sigma 1}i_{\sigma 2}\dots i_{\sigma r}}.$$

The space of symmetric tensors of rank *r* on a finite-dimensional [vector space](wikipedia://en/32370) is [naturally isomorphic](https://en.wikipedia.org/wiki/Natural_isomorphism) to the dual of the space of [homogeneous polynomials](wikipedia://en/1698977) of degree *r* on *V*. Over [fields](wikipedia://en/10603) of [characteristic zero](https://en.wikipedia.org/wiki/Characteristic_zero), the [graded vector space](wikipedia://en/1155734) of all symmetric tensors can be naturally identified with the [symmetric algebra](wikipedia://en/654098) on *V*. A related concept is that of the [antisymmetric tensor](wikipedia://en/696955) or [alternating form](https://en.wikipedia.org/wiki/Alternating_form). Symmetric tensors occur widely in [engineering](https://en.wikipedia.org/wiki/Engineering), [physics](wikipedia://en/22939) and [mathematics](wikipedia://en/18831).

### Galois theory {#Galois_theory}

Given a polynomial, it may be that some of the roots are connected by various [algebraic equations](wikipedia://en/404001). For example, it may be that for two of the roots, say *A* and *B*, that *A*<sup>2</sup> + 5*B*<sup>3</sup> = 7. The central idea of Galois theory is to consider those [permutations](wikipedia://en/44027) (or rearrangements) of the roots having the property that *any* algebraic equation satisfied by the roots is *still satisfied* after the roots have been permuted. An important proviso is that we restrict ourselves to algebraic equations whose coefficients are [rational numbers](wikipedia://en/19727024). Thus, Galois theory studies the symmetries inherent in algebraic equations.

### Automorphisms of algebraic objects {#Automorphisms_of_algebraic_objects}

In [abstract algebra](wikipedia://en/19616384), an **automorphism** is an [isomorphism](wikipedia://en/14828) from a [mathematical object](wikipedia://en/19453961) to itself. It is, in some sense, a [symmetry](wikipedia://en/53741) of the object, and a way of [mapping](wikipedia://en/516931) the object to itself while preserving all of its structure. The set of all automorphisms of an object forms a [group](wikipedia://en/19447), called the **automorphism group**. It is, loosely speaking, the [symmetry group](wikipedia://en/28186) of the object.

::: {#o24 .example cue=heading name="Examples"}

#### Examples {#Examples}

- In [set theory](wikipedia://en/27553), an arbitrary [permutation](wikipedia://en/44027) of the elements of a set *X* is an automorphism. The automorphism group of *X* is also called the [symmetric group](wikipedia://en/28901) on *X*.
- In [elementary arithmetic](wikipedia://en/1567386), the set of [integers](wikipedia://en/14563), **Z**, considered as a group under addition, has a unique nontrivial automorphism: negation. Considered as a [ring](wikipedia://en/48404), however, it has only the trivial automorphism. Generally speaking, negation is an automorphism of any [abelian group](wikipedia://en/2974), but not of a ring or field.
- A group automorphism is a [group isomorphism](wikipedia://en/12397) from a group to itself. Informally, it is a permutation of the group elements such that the structure remains unchanged. For every group *G* there is a natural group homomorphism *G* → Aut(*G*) whose [image](wikipedia://en/579311) is the group Inn(*G*) of [inner automorphisms](wikipedia://en/61839) and whose [kernel](wikipedia://en/45240) is the [center](wikipedia://en/7125) of *G*. Thus, if *G* has [trivial](wikipedia://en/193059) center it can be embedded into its own automorphism group.[^o25]
- In [linear algebra](wikipedia://en/18422), an endomorphism of a [vector space](wikipedia://en/32370) *V* is a [linear operator](https://en.wikipedia.org/wiki/Linear_transformation) *V* → *V*. An automorphism is an invertible linear operator on *V*. When the vector space is finite-dimensional, the automorphism group of *V* is the same as the [general linear group](wikipedia://en/113564), GL(*V*).
- A field automorphism is a [bijective](wikipedia://en/3942) [ring homomorphism](wikipedia://en/26411) from a [field](wikipedia://en/10603) to itself. In the cases of the [rational numbers](wikipedia://en/19727024) (**Q**) and the [real numbers](wikipedia://en/20646438) (**R**) there are no nontrivial field automorphisms. Some subfields of **R** have nontrivial field automorphisms, which however do not extend to all of **R** (because they cannot preserve the property of a number having a square root in **R**). In the case of the [complex numbers](wikipedia://en/5826), **C**, there is a unique nontrivial automorphism that sends **R** into **R**: [complex conjugation](wikipedia://en/173918), but there are infinitely ([uncountably](https://en.wikipedia.org/wiki/Uncountable)) many "wild" automorphisms (assuming the [axiom of choice](wikipedia://en/840)).[^o26] Field automorphisms are important to the theory of [field extensions](wikipedia://en/11634), in particular [Galois extensions](wikipedia://en/457064). In the case of a Galois extension *L*/*K* the [subgroup](wikipedia://en/28011) of all automorphisms of *L* fixing *K* pointwise is called the [Galois group](wikipedia://en/12673) of the extension.

:::

## Symmetry in representation theory {#Symmetry_in_representation_theory}

### Symmetry in quantum mechanics: bosons and fermions {#Symmetry_in_quantum_mechanics:_bosons_and_fermions}

In quantum mechanics, bosons have representatives that are symmetric under permutation operators, and fermions have antisymmetric representatives.

This implies the Pauli exclusion principle for fermions. In fact, the Pauli exclusion principle with a single-valued many-particle wavefunction is equivalent to requiring the wavefunction to be antisymmetric. An antisymmetric two-particle state is represented as a [sum of states](wikipedia://en/1201321) in which one particle is in state $\scriptstyle |x \rangle$ and the other in state $\scriptstyle |y\rangle$:

$$|\psi\rangle = \sum_{x,y} A(x,y) |x,y\rangle$$

and antisymmetry under exchange means that *A*(*x*,*y*) = −*A*(*y*,*x*). This implies that *A*(*x*,*x*) = 0, which is Pauli exclusion. It is true in any basis, since unitary changes of basis keep antisymmetric matrices antisymmetric, although strictly speaking, the quantity *A*(*x*,*y*) is not a matrix but an antisymmetric rank-two [tensor](wikipedia://en/29965).

Conversely, if the diagonal quantities *A*(*x*,*x*) are zero *in every basis*, then the wavefunction component:

$$A(x,y)=\langle \psi|x,y\rangle = \langle \psi | ( |x\rangle \otimes |y\rangle )$$

is necessarily antisymmetric. To prove it, consider the matrix element:

$$\langle\psi| ((|x\rangle + |y\rangle)\otimes(|x\rangle + |y\rangle)) \,$$

This is zero, because the two particles have zero probability to both be in the superposition state $\scriptstyle |x\rangle + |y\rangle$. But this is equal to

$$\langle \psi |x,x\rangle + \langle \psi |x,y\rangle + \langle \psi |y,x\rangle + \langle \psi | y,y \rangle \,$$

The first and last terms on the right hand side are diagonal elements and are zero, and the whole sum is equal to zero. So the wavefunction matrix elements obey:

$$\langle \psi|x,y\rangle + \langle\psi |y,x\rangle = 0 \,.$$

or

$$A(x,y)=-A(y,x) \,$$

## Symmetry in set theory {#Symmetry_in_set_theory}

### Symmetric relation {#Symmetric_relation}

We call a relation symmetric if every time the relation stands from A to B, it stands too from B to A. Note that symmetry is not the exact opposite of [antisymmetry](wikipedia://en/1176).

## Symmetry in metric spaces {#Symmetry_in_metric_spaces}

### Isometries of a space {#Isometries_of_a_space}

An **isometry** is a [distance](wikipedia://en/39378)-preserving map between [metric spaces](https://en.wikipedia.org/wiki/Metric_spaces). Given a metric space, or a set and scheme for assigning distances between elements of the set, an isometry is a transformation which maps elements to another metric space such that the distance between the elements in the new metric space is equal to the distance between the elements in the original metric space. In a two-dimensional or three-dimensional space, two geometric figures are [congruent](wikipedia://en/39330) if they are related by an isometry: related by either a [rigid motion](wikipedia://en/455769), or a [composition](wikipedia://en/195947) of a rigid motion and a [reflection](wikipedia://en/295829). Up to a relation by a rigid motion, they are equal if related by a [direct isometry](wikipedia://en/652164#Direct_and_indirect_isometries).

Isometries have been used to unify the working definition of symmetry in geometry and for functions, probability distributions, matrices, strings, graphs, etc.[^o33]

## Symmetries of differential equations {#Symmetries_of_differential_equations}

A symmetry of a [differential equation](wikipedia://en/1424309) is a transformation that leaves the differential equation invariant. Knowledge of such symmetries may help solve the differential equation.

A [Line symmetry](https://en.wikipedia.org/wiki/Line_symmetry) of a [system of differential equations](wikipedia://en/63871781) is a continuous symmetry of the system of differential equations. Knowledge of a Line symmetry can be used to simplify an ordinary differential equation through [reduction of order](wikipedia://en/3421971).[^o35]

For [ordinary differential equations](https://en.wikipedia.org/wiki/Ordinary_differential_equations), knowledge of an appropriate set of Lie symmetries allows one to explicitly calculate a set of first integrals, yielding a complete solution without integration.

Symmetries may be found by solving a related set of ordinary differential equations.[^o35] Solving these equations is often much simpler than solving the original differential equations.

## Symmetry in probability {#Symmetry_in_probability}

In the case of a finite number of possible outcomes, symmetry with respect to permutations (relabelings) implies a [discrete uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29).

In the case of a real interval of possible outcomes, symmetry with respect to interchanging sub-intervals of equal length corresponds to a [continuous uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29).

In other cases, such as "taking a random integer" or "taking a random real number", there are no probability distributions at all symmetric with respect to relabellings or to exchange of equally long subintervals. Other reasonable symmetries do not single out one particular distribution, or in other words, there is not a unique probability distribution providing maximum symmetry.

There is one type of [isometry in one dimension](https://en.wikipedia.org/wiki/Symmetry_groups_in_one_dimension) that may leave the probability distribution unchanged, that is reflection in a point, for example zero.

A possible symmetry for randomness with positive outcomes is that the former applies for the logarithm, i.e., the outcome and its reciprocal have the same distribution. However this symmetry does not single out any particular distribution uniquely.

For a "random point" in a plane or in space, one can choose an origin, and consider a probability distribution with circular or spherical symmetry, respectively.
