# Guess value

::: {#o1 .subject cue=lead name="Guess value"}

In [mathematical modeling](https://en.wikipedia.org/wiki/Mathematical_modeling), a **guess value** is more commonly called a **starting value** or **initial value**. These are necessary for most [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) problems which use [search algorithms](https://en.wikipedia.org/wiki/Search_algorithms), because those algorithms are mainly [deterministic](https://en.wikipedia.org/wiki/Deterministic_algorithm) and [iterative](https://en.wikipedia.org/wiki/Iterative), and they need to start somewhere. One common type of application is [nonlinear regression](wikipedia://en/1045012).[^o2]

:::

::: {#o4 .application cue=heading name="Use"}

## Use {#Use}

The quality of the initial values can have a considerable impact on the success or lack of such of the search algorithm. This is because the [fitness function](https://en.wikipedia.org/wiki/Fitness_function) or [objective function](https://en.wikipedia.org/wiki/Objective_function) (in many cases a sum of squared errors ([SSE](https://en.wikipedia.org/wiki/Sum_of_squared_errors_of_prediction))) can have difficult shapes. In some parts of the search region, the function may increase exponentially, in others quadratically, and there may be regions where the function [asymptotes](https://en.wikipedia.org/wiki/Asymptotes) to a [plateau](wikipedia://en/1464827). Starting values that fall in an exponential region can lead to algorithm failure because of [arithmetic overflow](https://en.wikipedia.org/wiki/Arithmetic_overflow). Starting values that fall in the asymptotic plateau region can lead to algorithm failure because of "[dithering](https://en.wikipedia.org/wiki/Dithering)". Deterministic search algorithms may use a slope function to go to a minimum. If the slope is very small, then underflow errors can cause the algorithm to wander, seemingly aimlessly; this is dithering.

:::

## Finding value {#Finding_value}

Guess values can be determined a number of ways. Guessing is one of them. If one is familiar with the type of problem, then this is an educated guess or [guesstimate](wikipedia://en/2481546). Other techniques include [linearization](wikipedia://en/1118789), solving [simultaneous equations](https://en.wikipedia.org/wiki/Simultaneous_equations), reducing [dimensions](https://en.wikipedia.org/wiki/Dimensions), treating the problem as a [time series](wikipedia://en/406624), converting the problem to a (hopefully) [linear](https://en.wikipedia.org/wiki/Linear) [differential equation](wikipedia://en/1424309), and using [mean](https://en.wikipedia.org/wiki/Mean) values. Further methods for determining starting values and optimal values in their own right come from [stochastic](wikipedia://en/292222) methods, the most commonly known of these being [evolutionary algorithms](https://en.wikipedia.org/wiki/Evolutionary_algorithms) and particularly [genetic algorithms](https://en.wikipedia.org/wiki/Genetic_algorithms).
