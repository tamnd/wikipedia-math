# Moduli stack of vector bundles

::: {#o1 .subject cue=lead name="Moduli stack of vector bundles"}

In [algebraic geometry](wikipedia://en/1997), the **moduli stack of rank-*n* vector bundles** Vect<sub>*n*</sub> is the [stack](wikipedia://en/13185596) parametrizing [vector bundles](wikipedia://en/276524) (or [locally free sheaves](https://en.wikipedia.org/wiki/Locally_free_sheaf)) of rank *n* over some reasonable spaces.

:::

It is a [smooth](https://en.wikipedia.org/wiki/Smooth_stack) [algebraic](wikipedia://en/717377) stack of the negative dimension $-n^2$.[^o2] Moreover, viewing a rank-*n* vector bundle as a principal $GL_n$-bundle, Vect<sub>*n*</sub> is isomorphic to the [classifying stack](https://en.wikipedia.org/wiki/Classifying_stack) $BGL_n = [\text{pt}/GL_n].$

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For the base category, let *C* be the category of [schemes of finite type](https://en.wikipedia.org/wiki/Scheme_of_finite_type) over a fixed field *k*. Then $\operatorname{Vect}_n$ is the category where

1. an object is a pair $(U, E)$ of a scheme *U* in *C* and a rank-*n* vector bundle *E* over *U*
1. a morphism $(U, E) \to (V, F)$ consists of $f: U \to V$ in *C* and a [bundle isomorphism](https://en.wikipedia.org/wiki/Bundle_isomorphism) $f^* F \overset{\sim}\to E$.

Let $p: \operatorname{Vect}_n \to C$ be the [forgetful functor](wikipedia://en/844783). Via *p*, $\operatorname{Vect}_n$ is a [prestack](wikipedia://en/39547490) over *C*. That it is a stack over *C* is precisely the statement "vector bundles have the [descent](wikipedia://en/361449) property". Note that each fiber $\operatorname{Vect}_n(U) = p^{-1}(U)$ over *U* is the category of rank-*n* vector bundles over *U* where every morphism is an isomorphism (i.e., each fiber of *p* is a [groupoid](wikipedia://en/12543)).

:::
