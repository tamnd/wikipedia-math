# Irregular matrix

::: {#o1 .subject cue=lead name="Irregular matrix"}

An **irregular matrix**, or **ragged matrix**, is a [matrix](wikipedia://en/20556859) that has a different number of elements in each row. Ragged matrices are not used in [linear algebra](wikipedia://en/18422), since standard matrix transformations cannot be performed on them, but they are useful in [computing](https://en.wikipedia.org/wiki/Computing) as [arrays](https://en.wikipedia.org/wiki/Array_data_structure) which are called [jagged arrays](https://en.wikipedia.org/wiki/Jagged_array). Irregular matrices are typically stored using [Iliffe vectors](https://en.wikipedia.org/wiki/Iliffe_vector).

:::

For example, the following is an irregular matrix:

$$\begin{bmatrix} 1 & 31 & 12& -3 \\ 7 & 2 \\ 1 & 2 & 2 \end{bmatrix}$$
