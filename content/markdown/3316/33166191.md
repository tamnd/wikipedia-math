# Cochran's C test

::: {#o1 .subject cue=lead name="Cochran's C test"}

**Cochran's $C$ test**,[^o2] named after [William G. Cochran](wikipedia://en/2223833), is a [one-sided](https://en.wikipedia.org/wiki/One-tailed_test) upper limit variance [outlier](wikipedia://en/160951) [statistical test](https://en.wikipedia.org/wiki/Statistical_test). The C test is used to decide if a single [estimate](wikipedia://en/1565926) of a [variance](wikipedia://en/32344) (or a [standard deviation](wikipedia://en/27590)) is [significantly](wikipedia://en/160995) larger than a group of variances (or standard deviations) with which the single estimate is supposed to be comparable. The C test is discussed in many text books [^o3][^o4][^o5] and has been recommended by [IUPAC](https://en.wikipedia.org/wiki/IUPAC)[^o6] and [ISO](https://en.wikipedia.org/wiki/International_Organization_for_Standardization).[^o7] Cochran's C test should not be confused with [Cochran's Q](wikipedia://en/15918691) test, which applies to the [analysis](wikipedia://en/1134) of two-way [randomized block designs](https://en.wikipedia.org/wiki/Randomized_block_design).

:::

The C test assumes a balanced design, i.e. the considered full [data set](wikipedia://en/8495) should consist of individual data series that all have equal size. The C test further assumes that each individual data series is [normally distributed](https://en.wikipedia.org/wiki/Normally_distributed). Although primarily an outlier test, the C test is also in use as a simple alternative for regular [homoscedasticity](https://en.wikipedia.org/wiki/Homoscedasticity) tests such as [Bartlett's](wikipedia://en/2223782) test, [Levene's](wikipedia://en/4833235) test and the [Brown–Forsythe test](wikipedia://en/15317159) to check a [statistical data](https://en.wikipedia.org/wiki/Statistical_data) set for [homogeneity of variances](https://en.wikipedia.org/wiki/Homogeneity_of_variance). An even simpler way to check homoscedasticity is provided by [Hartley's F<sub>max</sub> test](wikipedia://en/13640881),[^o4] but Hartley's F<sub>max</sub> test has the disadvantage that it only accounts for the minimum and the maximum of the variance range, while the C test accounts for all variances within the range.

## Description {#Description}

The C test detects one exceptionally large variance value at a time. The corresponding data series is then omitted from the full data set. According to ISO standard 5725 [^o7] the C test may be [iterated](https://en.wikipedia.org/wiki/Iterate) until no further exceptionally large variance values are detected, but such practice may lead to excessive rejections if the underlying data series are not normally distributed. The C test evaluates the [ratio](wikipedia://en/87837):

$$C_j = \frac{S_j^2}{\displaystyle \sum_{i=1}^N S_i^2}$$

where:

*C<sub>j</sub>* = Cochran's C statistic for data series *j*

*S<sub>j</sub>* = standard deviation of data series *j*

*N* = number of data series that remain in the data set; *N* is decreased in steps of 1 upon each iteration of the C test

*S<sub>i</sub>* = standard deviation of data series i (1 ≤ *i* ≤ *N*)

The C test tests the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) (H<sub>0</sub>) against the [alternative hypothesis](https://en.wikipedia.org/wiki/Alternative_hypothesis) (H<sub>a</sub>):

H<sub>0</sub>: All variances are equal.

H<sub>a</sub>: At least one variance value is significantly larger than the other variance values.

## Critical values {#Critical_values}

The sample variance of data series *j* is considered an outlier at [significance level](https://en.wikipedia.org/wiki/Significance_level) *α* if *C<sub>j</sub>* exceeds the upper limit [critical value](https://en.wikipedia.org/wiki/Critical_value_%28statistics%29) C<sub>UL</sub>. C<sub>UL</sub> depends on the desired significance level *α*, the number of considered data series *N*, and the number of data points (*n*) per data series. Selections of values for C<sub>UL</sub> have been tabulated at significance levels α = 0.01,[^o7][^o10][^o11] α = 0.025,[^o11] and α = 0.05.[^o7][^o10][^o11] *C*<sub>UL</sub> can also be calculated from:[^o11][^o15]

$$C_\text {UL}(\alpha,n,N) = \left [ 1+ \frac{N-1}{F_\text {c}(\alpha/N,(n-1),(N-1)(n-1))} \right ]^{-1} .$$

Here:

*C*<sub>UL</sub> = upper limit critical value for one-sided test on a balanced design

*α* = significance level, e.g., 0.05

*n* = number of data points per data series

*F*<sub>c</sub> = critical value of [Fisher's F](wikipedia://en/26429557) ratio; *F*<sub>c</sub> can be obtained from tables of the [F distribution](https://en.wikipedia.org/wiki/F_distribution)[^o12] or using computer software for this function.

::: {#o14 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

The C test can be generalized to include unbalanced designs, one-sided lower limit tests and [two-sided](https://en.wikipedia.org/wiki/Two-tail) tests at any significance level *α*, for any number of data series *N*, and for any number of individual data points *n<sub>j</sub>* in data series *j*.[^o11][^o15]

:::
