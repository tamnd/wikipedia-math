# Pseudoprime

::: {#o1 .subject cue=lead name="Pseudoprime"}

A **pseudoprime** is a [probable prime](wikipedia://en/160560) (an [integer](wikipedia://en/14563) that shares a property common to all [prime numbers](wikipedia://en/23666)) that is not actually prime. Pseudoprimes are classified according to which property of primes they satisfy.

:::

Some sources use the term pseudoprime to describe all probable primes, both [composite numbers](wikipedia://en/82289) and actual primes.

Pseudoprimes are of primary importance in [public-key cryptography](wikipedia://en/24222), which makes use of the difficulty of factoring large numbers into their prime factors. [Carl Pomerance](wikipedia://en/2134159) estimated in 1988 that it would cost \$10 million to factor a number with 144 digits, and \$100 billion to factor a 200-digit number (the cost today is dramatically lower but still prohibitively high).[^o2][^o3] But finding two large prime numbers as needed for this use is also expensive, so various probabilistic [primality tests](wikipedia://en/183751) are used, some of which in rare cases inappropriately deliver composite numbers instead of primes. On the other hand, deterministic primality tests, such as the [AKS primality test](https://en.wikipedia.org/wiki/AKS_primality_test), do not give [false positives](https://en.wikipedia.org/wiki/False_positive); because of this, there are no pseudoprimes with respect to them.

## Fermat pseudoprimes {#Fermat_pseudoprimes}

[Fermat's little theorem](wikipedia://en/53453) states that if $p$ is prime and $a$ is [coprime](https://en.wikipedia.org/wiki/Coprime) to $p$, then $a^{p-1} - 1$ is [divisible](wikipedia://en/49492) by $p$. For an integer $a > 1$, if a composite integer $x$ divides $a^{x-1} - 1$, then $x$ is called a **Fermat pseudoprime** to base $a$. It follows that if $x$ is a Fermat pseudoprime to base $a$, then $x$ is coprime to $a$. Some sources use variations of this definition, for example to allow only odd numbers to be pseudoprimes.

An integer $x$ that is a Fermat pseudoprime to all values of $a$ that are coprime to $x$ is called a [Carmichael number](wikipedia://en/7723).
