# McXtrace

::: {#o1 .subject cue=lead name="McXtrace"}

**McXtrace** is an open source software package for performing Monte Carlo simulations of X-ray scattering experiments. While its chief objective is to aid in the optimization of beamlines at e.g. synchrotrons, it may also be used for data analysis and at laboratory sources and beamlines.[^o2] McXtrace is [free software](https://en.wikipedia.org/wiki/Free_software) released under the [GNU GPL](https://en.wikipedia.org/wiki/GNU_GPL).

:::

McXtrace was first spun off as a sister project to the well known and proven *neutron* ray-tracing package [McStas](https://en.wikipedia.org/wiki/McStas) in a project funded jointly by:

- DTU Physics at [The Technical University of Denmark (DTU)](https://en.wikipedia.org/wiki/Technical_University_of_Denmark)
- The [European Synchrotron Radiation Facility](https://en.wikipedia.org/wiki/European_Synchrotron_Radiation_Facility) (ESRF) (http://www.esrf.eu)
- [Niels Bohr Institute](https://en.wikipedia.org/wiki/Niels_Bohr_Institute) at [University of Copenhagen (KU)](https://en.wikipedia.org/wiki/University_of_Copenhagen)
- The Danish Strategic Research Council under the NaBiIT program
- SAXSLAB ApS. aka. JJ-XRay Systems (http://www.jjxray.dk)

## Description {#Description}

McXtrace works in the way that a user describes his/her beamline in a special file. This file is then analyzed by the system and converted into a c-file which may be compiled on the target computing system where the simulation is to be run. The beamline file generally contains relative coordinates of the devices present in the beamline.

McXtrace is well suited to describe X-ray synchrotron beam-lines by assembling a series of so-called components:

- a photon source
- optics
- samples
- detectors and monitors

Even-though McXtrace is similar to other pure ray-tracing such as [XRT](https://readthedocs.org/projects/xrt/), \[\["Synchrotron Radiation Workshop|SRW\]\], [OASYS/Shadow](https://www.aps.anl.gov/files/APS-Uploads/Aps-Upgrade/APS-U%20Forum_OASYS_xianbo_Nov102016.pdf) for the source and optics, what makes it different resides in its ability to handle sample models:

- powder diffraction
- single crystal diffraction
- absorption (XAS), which also covers tomography applications
- [small-angle scattering](https://en.wikipedia.org/wiki/Small-angle_scattering)
- inelastic scattering (IXS, currently from liquids and amorphous systems)
- fluorescence, Compton and Rayleigh
