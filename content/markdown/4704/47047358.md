# Eigenoperator

::: {#o1 .subject cue=lead name="Eigenoperator"}

In mathematics, an **eigenoperator**, *A*, of a [matrix](wikipedia://en/20556859) *H* is a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) such that

:::

$$[H,A] = \lambda A \,$$

where $\lambda$ is a corresponding [scalar](wikipedia://en/3588331) called an [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue).[^o2]
