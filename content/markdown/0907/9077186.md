# KN-Cipher

::: {#o1 .subject cue=lead name="KN-Cipher"}

In [cryptography](wikipedia://en/18934432), **KN-Cipher** is a [block cipher](wikipedia://en/4594) created by [Kaisa Nyberg](wikipedia://en/9413796) and [Lars Knudsen](https://en.wikipedia.org/wiki/Lars_Ramkilde_Knudsen) in 1995. One of the first ciphers designed to be [provably secure](wikipedia://en/1182348) against ordinary [differential cryptanalysis](wikipedia://en/8536), KN-Cipher was later broken using [higher order differential cryptanalysis](https://en.wikipedia.org/wiki/Higher_order_differential_cryptanalysis).

:::

Presented as "a prototype...compatible with [DES](wikipedia://en/7978)", the algorithm has a 64-bit [block size](wikipedia://en/294065) and a 6-round [Feistel network](wikipedia://en/352709) structure. The round function is based on the [cube](https://en.wikipedia.org/wiki/Cube_%28arithmetic%29) operation in the [finite field](wikipedia://en/11615) GF(2<sup>33</sup>).

The designers did not specify any [key schedule](wikipedia://en/609603) for the cipher; they state, "All round keys should be independent, therefore we need at least 198 key bits."[^o5]

## Cryptanalysis {#Cryptanalysis}

Jakobsen & Knudsen's [higher order differential cryptanalysis](https://en.wikipedia.org/wiki/Higher_order_differential_cryptanalysis) breaks KN-Cipher with only 512 chosen plaintexts and 2<sup>41</sup> running time, or with 32 chosen plaintexts and 2<sup>70</sup> running time.[^o6]
