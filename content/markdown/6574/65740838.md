# R package

::: {#o1 .subject cue=lead name="R package"}

*Image: R logo.svg.* R logo

**R packages** are [extensions](https://en.wikipedia.org/wiki/Software_extension) to the [R statistical programming language](wikipedia://en/376707). R packages contain code, data, and documentation in a standardised collection format that can be installed by users of R, typically via a centralised [software repository](https://en.wikipedia.org/wiki/Software_repository) such as CRAN (the Comprehensive R Archive Network).[^o2][^o3] The large number of packages available for R, and the ease of installing and using them, has been cited as a major factor driving the widespread adoption of the language in [data science](wikipedia://en/35458904).[^o4][^o5][^o6][^o7]

:::

Compared to [libraries](https://en.wikipedia.org/wiki/Library_%28computing%29) in other programming languages, R packages must conform to a relatively strict specification.[^o4] The *Writing R Extensions* manual[^o8] specifies a standard [directory structure](https://en.wikipedia.org/wiki/Directory_structure) for R source code, data, documentation, and package [metadata](https://en.wikipedia.org/wiki/Metadata), which enables them to be installed and loaded using R's in-built [package management](https://en.wikipedia.org/wiki/Package_management) tools.[^o4] Packages distributed on CRAN must meet additional standards.[^o4][^o9] According to [John Chambers](wikipedia://en/16745085), whilst these requirements "impose considerable demands" on package developers, they improve the [usability](https://en.wikipedia.org/wiki/Usability) and long-term stability of packages for end users.[^o4]

### Comprehensive R Archive Network (CRAN) {#Comprehensive_R_Archive_Network_(CRAN)}

*Image: CRAN\_homepage.png.* The Comprehensive R Archive Network (CRAN) homepage

The Comprehensive R Archive Network (CRAN) is R's central [software repository](https://en.wikipedia.org/wiki/Software_repository), supported by the R Foundation.[^o13] It contains an archive of the latest and previous versions of the R distribution, documentation, and contributed R packages.[^o14] It includes both [source packages](https://en.wikipedia.org/wiki/Source_code) and pre-[compiled](https://en.wikipedia.org/wiki/Compiled) [binaries](https://en.wikipedia.org/wiki/Executable) for [Windows](https://en.wikipedia.org/wiki/Windows) and [macOS](https://en.wikipedia.org/wiki/MacOS).[^o15] , more than 16,000 packages are available.[^o16] CRAN was created by [Kurt Hornik](https://en.wikipedia.org/wiki/Kurt_Hornik) and [Friedrich Leisch](https://en.wikipedia.org/wiki/Friedrich_Leisch) in 1997,[^o17][^o18] with the name paralleling other early packing systems such as [TeX](https://en.wikipedia.org/wiki/TeX)'s [CTAN](https://en.wikipedia.org/wiki/CTAN) (released 1992) and [Perl](https://en.wikipedia.org/wiki/Perl)'s [CPAN](https://en.wikipedia.org/wiki/CPAN) (released 1995).[^o19] , it is still maintained by Hornik and a team of volunteers.[^o13] The master site is located at the [Vienna University of Economics and Business](https://en.wikipedia.org/wiki/Vienna_University_of_Economics_and_Business) and is [mirrored](https://en.wikipedia.org/wiki/Mirror_site) on servers around the world.[^o14]

*Image: R\_Task\_Views\_Homepage.png.* Homepage for R CRAN Task Views

The "Task Views" page (subject list) on the CRAN website[^o20] lists a wide range of tasks (in fields such as finance, genetics, [high performance computing](https://en.wikipedia.org/wiki/High-performance_computing), [machine learning](wikipedia://en/233488), [medical imaging](https://en.wikipedia.org/wiki/Medical_imaging), [meta-analysis](wikipedia://en/62329), [social sciences](https://en.wikipedia.org/wiki/Social_science) and [spatial statistics](wikipedia://en/9467349)) for which R packages are available. Another way to browse CRAN packages is provided by Metacran,[^o39] which also maintains lists of featured, most downloaded, trending or most depended upon packages.

The number of CRAN packages has [grown exponentially](wikipedia://en/191933) for many years.[^o21] In 2018, an average of 21 submissions of new or updated packages were made every day;[^o7] this increased to 20–25 *new* package submissions each day in 2026.[^o22] Since each submission is manually reviewed by a small team of CRAN maintainers, there is a concern that this system is not sustainable in the long term.[^o7] The growth of CRAN has exposed limitations of its [dependency management](https://en.wikipedia.org/wiki/Coupling_%28computer_programming%29) infrastructure, particularly the fact that it assumes that dependencies always refer to the latest version of a package, meaning that new releases of CRAN packages must always be [backwards compatible](https://en.wikipedia.org/wiki/Backward_compatibility),[^o23] and that CRAN packages cannot have dependencies that are not on CRAN.[^o24] It has also led to concerns about declining quality of packages.[^o25]

:::

### MRAN and Posit Package Manager {#MRAN_and_Posit_Package_Manager}

*Image: MRAN\_homepage.png.* Homepage for the Microsoft R Application Network (MRAN)

The Microsoft R Application Network (MRAN) is a mirror of CRAN maintained by [Microsoft](https://en.wikipedia.org/wiki/Microsoft) which is based on the company's downstream distribution of R, [Microsoft R Open](https://en.wikipedia.org/wiki/Microsoft_R_Open) (formerly Revolution R Open).[^o27] It also includes an archive of daily CRAN snapshots, branded as the "CRAN Time Machine", which enables users of MRAN to bypass the dependency versioning limitations of CRAN by installing a fixed set of R package versions via the package checkpoint.[^o28][^o29] In January 2023 Microsoft announced that MRAN was being retired and the associated websites and repositories became unavailable in July 2023.[^o30]

*Image: Posit\_package\_manager\_homepage.png.* Homepage for the Posit Package Manager

The Posit Package Manager (formerly RStudio Package Manager) is a similar tool produced by the developers of [RStudio](wikipedia://en/36691501) which, in addition to CRAN snapshots, includes an archive of R packages from Bioconductor and [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) packages from the [Python Package Index](https://en.wikipedia.org/wiki/Python_Package_Index).[^o31] It also distributes pre-compiled binary packages for Linux (only Windows and macOS binaries are included on CRAN).[^o32]

### Other repositories {#Other_repositories}

The [Bioconductor](https://en.wikipedia.org/wiki/Bioconductor) project provides R packages for the analysis of [genomic](https://en.wikipedia.org/wiki/Genomics) data. This includes [object-oriented](https://en.wikipedia.org/wiki/Object-oriented_programming) data-handling and analysis tools for data from [Affymetrix](https://en.wikipedia.org/wiki/Affymetrix), [cDNA](https://en.wikipedia.org/wiki/Complementary_DNA) [microarray](https://en.wikipedia.org/wiki/Microarray), and next-generation [high-throughput sequencing](https://en.wikipedia.org/wiki/High-throughput_sequencing) methods.[^o34]

*Image: R-Forge\_Homepage.png.* Homepage for R-Forge

R-Forge,[^o35] is a central platform for the collaborative development of R packages, R-related software, and projects. R-Forge also hosts many unpublished beta packages, and development versions of CRAN packages.

## Base and recommended packages {#Base_and_recommended_packages}

R is distributed with fifteen "base packages": base, compiler, datasets, grDevices, graphics, grid, methods, parallel, splines, stats, stats4, tcltk, tools, translations, and utils.[^o37]

In addition, there are fifteen "recommended packages" from CRAN which are included with binary distributions of R: KernSmooth, MASS, Matrix, boot, class, cluster, codetools, foreign, lattice, mgcv, nlme, nnet, rpart, spatial, and survival.[^o37]

## Other packages {#Other_packages}

A group of packages called the [tidyverse](wikipedia://en/59164935), which can be considered a "dialect of the R language", is increasingly popular in the R ecosystem. As of 1 August 2025, Metacran listed 6 of the 8 core packages of the tidyverse in the list of most downloaded R packages.[^o39] The group of packages strives to provide a cohesive collection of functions to deal with common data science tasks, including [data import](https://en.wikipedia.org/wiki/Import_and_export_of_data), cleaning, transformation and [visualisation](https://en.wikipedia.org/wiki/Visualization_%28graphics%29) (notably with the [ggplot2](wikipedia://en/32380922) package).

The R Infrastructure packages support coding and the development of R packages and as of 1 August 2025, Metacran lists 8 of these packages among the 25 most downloaded packages.[^o39][^o40]

### Package maintainership {#Package_maintainership}

Software engineering studies of the CRAN repository show that package maintainers carry the primary responsibility for long-term code stability, bug resolution, and cross-platform compilation.[^o42] While the majority of CRAN contributors maintain a single package, a small group of prolific developers maintain dozens of active packages across diverse statistical domains, high-performance computing, and systems infrastructure.[^o43]
