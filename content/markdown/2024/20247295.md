# Garside element

::: {#o1 .subject cue=lead name="Garside element"}

In [mathematics](wikipedia://en/18831), a **Garside element** is an element of an [algebraic structure](wikipedia://en/106364) such as a [monoid](wikipedia://en/19652) that has several desirable properties.

:::

Formally, if *M* is a monoid, then an element Δ of *M* is said to be a **Garside element** if the set of all right divisors of Δ,

$$\{ r \in M \mid \text{for some } x \in M, \Delta = x r \},$$

is the same set as the set of all left divisors of Δ,

$$\{ \ell \in M \mid \text{for some } x \in M, \Delta = \ell x \},$$

and this set [generates](https://en.wikipedia.org/wiki/Generating_set) *M*.

A Garside element is in general not unique: any power of a Garside element is again a Garside element.

::: {#o3 .pointer-item cue=pointer name="Garside monoid"}

## Garside monoid and Garside group {#Garside_monoid_and_Garside_group}

A **Garside monoid** is a monoid with the following properties:

- Finitely generated and atomic;
- [Cancellative](https://en.wikipedia.org/wiki/Cancellative);
- The [partial order](wikipedia://en/23572) relations of divisibility are [lattices](wikipedia://en/469304);
- There exists a Garside element.

A Garside monoid satisfies the [Ore condition for multiplicative sets](https://en.wikipedia.org/wiki/Ore_condition_for_multiplicative_sets) and hence embeds in its group of fractions: such a group is a **Garside group**. A Garside group is [biautomatic](https://en.wikipedia.org/wiki/Biautomatic_group) and hence has solvable [word problem](wikipedia://en/33563) and [conjugacy problem](wikipedia://en/4942384). Examples of such groups include [braid groups](wikipedia://en/550138) and, more generally, [Artin groups](https://en.wikipedia.org/wiki/Artin_group) of [finite Coxeter type](https://en.wikipedia.org/wiki/Artin_group_of_finite_type).[^o4]

The name was coined by [Patrick Dehornoy](wikipedia://en/25223557) and Luis Paris[^o4] to mark the work on the conjugacy problem for braid groups of Frank Arnold Garside (1915–1988), a teacher at [Magdalen College School, Oxford](https://en.wikipedia.org/wiki/Magdalen_College_School,_Oxford) who served as [Lord Mayor of Oxford](https://en.wikipedia.org/wiki/List_of_mayors_of_Oxford) in 1984–1985.[^o5]
