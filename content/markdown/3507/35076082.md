# Transport Layer Security Channel ID

::: {#o1 .subject cue=lead name="Transport Layer Security Channel ID"}

**Transport Layer Security Channel ID** (**TLS Channel ID**, previously known as **Transport Layer Security – Origin Bound Certificates** **TLS-OBC**)[^o2] is a draft [RFC](https://en.wikipedia.org/wiki/Request_for_Comments) proposal[^o3][^o4] [Transport Layer Security](wikipedia://en/187813) (TLS) extension that aims to increase TLS [security](https://en.wikipedia.org/wiki/Computer_security) by using [certificates](wikipedia://en/223796) on both ends of the TLS connection. Notably, the client is permitted to dynamically create a local, [self-signed certificate](wikipedia://en/642850) that provides additional security.

:::

It can also protect users from the related domain cookie attack.[^o5][^o6]

## Token Binding {#Token_Binding}

**Token Binding** is an evolution of the TLS Channel ID feature,[^o8] and the IETF draft has Microsoft and Google as authors.[^o9]
