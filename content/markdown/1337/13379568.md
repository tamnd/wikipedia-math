# Cube-connected cycles

::: {#o1 .subject cue=lead name="Cube-connected cycles"}

*Image: Cube-connected cycles.svg.* The cube-connected cycles of order 3, arranged geometrically on the vertices of a [truncated cube](wikipedia://en/280529).

In [graph theory](wikipedia://en/12401), the **cube-connected cycles** is an [undirected](https://en.wikipedia.org/wiki/Undirected_graph) [cubic graph](wikipedia://en/980508), formed by replacing each [vertex](wikipedia://en/638899) of a [hypercube graph](wikipedia://en/6706815) by a [cycle](wikipedia://en/878962). It was introduced by (Preparata Vuillemin 1981) for use as a [network topology](https://en.wikipedia.org/wiki/Network_topology) in [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The cube-connected cycles of order *n* (denoted CCC<sub>*n*</sub>) can be defined as a graph formed from a set of *n*2<sup>*n*</sup> nodes, indexed by pairs of numbers (*x*, *y*) where 0 ≤ *x* \< 2<sup>*n*</sup> and 0 ≤ *y* \< *n*. Each such node is connected to three neighbors: (*x*, (*y* + 1) mod *n*), (*x*, (*y* − 1) mod *n*), and (*x* ⊕ 2<sup>*y*</sup>, *y*), where "⊕" denotes the [bitwise](wikipedia://en/264399) [exclusive or](wikipedia://en/105979) operation on binary numbers.

This graph can also be interpreted as the result of replacing each vertex of an *n*-dimensional hypercube graph by an *n*-vertex cycle. The hypercube graph vertices are indexed by the numbers *x*, and the positions within each cycle by the numbers *y*.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The cube-connected cycles of order *n* is the [Cayley graph](wikipedia://en/358277) of a [group](wikipedia://en/19447) that [acts](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) on binary words of length *n* by [rotation](wikipedia://en/1917276) and flipping bits of the word.[^o7] The generators used to form this Cayley graph from the group are the group elements that act by rotating the word one position left, rotating it one position right, or flipping its first bit. Because it is a Cayley graph, it is [vertex-transitive](wikipedia://en/581175): there is a symmetry of the graph mapping any vertex to any other vertex.

The [diameter](wikipedia://en/8007) of the cube-connected cycles of order *n* is 2*n* + ⌊n/2⌋ − 2 for any n ≥ 4; the farthest point from (*x*, *y*) is (2<sup>*n*</sup> − *x* − 1, (*y* + *n*/2) mod *n*).[^o8] (Sýkora Vrťo 1993) showed that the [crossing number](wikipedia://en/18298594) of CCC<sub>*n*</sub> is ((1/20) + o(1)) 4<sup>*n*</sup>.

According to the [Lovász conjecture](wikipedia://en/4367424), the cube-connected cycle graph should always contain a [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle), and this is now known to be true. More generally, although these graphs are not [pancyclic](wikipedia://en/28691490), they contain cycles of all but a bounded number of possible even lengths, and when *n* is odd they also contain many of the possible odd lengths of cycles.[^o10]

:::

## Parallel processing application {#Parallel_processing_application}

Cube-connected cycles were investigated by (Preparata Vuillemin 1981), who applied these graphs as the [interconnection pattern](https://en.wikipedia.org/wiki/Network_topology) of a [network](https://en.wikipedia.org/wiki/Computer_networking) connecting the processors in a [parallel computer](https://en.wikipedia.org/wiki/Parallel_computing). In this application, cube-connected cycles have the connectivity advantages of hypercubes while only requiring three connections per processor. Preparata and Vuillemin showed that a planar layout based on this network has optimal area × time<sup>2</sup> complexity for many parallel processing tasks.
