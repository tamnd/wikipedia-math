# Active-set method

::: {#o1 .subject cue=lead name="Active-set method"}

In mathematical [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29), the **active-set method** is an algorithm used to identify the active [constraints](wikipedia://en/7418540) in a set of [inequality](wikipedia://en/89489) constraints. The active constraints are then expressed as equality constraints, thereby transforming an inequality-constrained problem into a simpler equality-constrained subproblem.

:::

An optimization problem is defined using an objective function to minimize or maximize, and a set of constraints

$$g_1(x) \ge 0, \dots, g_k(x) \ge 0$$

that define the [feasible region](wikipedia://en/9157119), that is, the set of all *x* to search for the optimal solution. Given a point $x$ in the feasible region, a constraint

$$g_i(x) \ge 0$$

is called **active** at $x_0$ if $g_i(x_0) = 0$, and **inactive** at $x_0$ if $g_i(x_0) > 0.$ Equality constraints are always active. The **active set** at $x_0$ is made up of those constraints $g_i(x_0)$ that are active at the current point (Nocedal Wright 2006, 308).

The active set is particularly important in optimization theory, as it determines which constraints will influence the final result of optimization. For example, in solving the [linear programming](wikipedia://en/43730) problem, the active set gives the [hyperplanes](wikipedia://en/99862) that intersect at the solution point. In [quadratic programming](wikipedia://en/40324), as the solution is not necessarily on one of the edges of the bounding polygon, an estimation of the active set gives us a subset of inequalities to watch while searching the solution, which reduces the complexity of the search.

Active-set methods, which traverse the edges of the feasible set, stand in contrast to [interior-point methods](wikipedia://en/1622862), which try to always stay inside of the feasible set.

## Active-set methods {#Active-set_methods}

In general an active-set algorithm has the following structure:

Find a feasible starting point

**repeat until** "optimal enough"

*solve* the equality problem defined by the active set (approximately)

*compute* the [Lagrange multipliers](https://en.wikipedia.org/wiki/Lagrange_multipliers) of the active set

*remove* a subset of the constraints with negative Lagrange multipliers

*search* for infeasible constraints among the inactive constraints and add them to the problem

**end repeat**

The motivations for this is that near the optimum usually only a small number of all constraints are binding and the solve step usually takes superlinear time in the amount of constraints. Thus repeated solving of a series equality constrained problem, which drop constraints which are not violated when improving but are in the way of improvement (negative lagrange multipliers) and adding of those constraints which the current solution violates can converge against the true solution. The optima of the last problem can often provide an initial guess in case the equality constrained problem solver needs an initial value.

Methods that can be described as **active-set methods** include:[^o4]

- [Successive linear programming](https://en.wikipedia.org/wiki/Successive_linear_programming) (SLP)
- [Sequential quadratic programming](wikipedia://en/7415899) (SQP)
- [Sequential linear-quadratic programming](wikipedia://en/55675948) (SLQP)
- [Reduced gradient method](wikipedia://en/3152055) (RG)
- [Generalized reduced gradient method](https://en.wikipedia.org/wiki/Generalized_Reduced_Gradient) (GRG)

## Performance {#Performance}

Consider the problem of Linearly Constrained Convex Quadratic Programming. Under reasonable assumptions (the problem is feasible, the system of constraints is regular at every point, and the quadratic objective is strongly convex), the active-set method terminates after finitely many steps, and yields a global solution to the problem. Theoretically, the active-set method may perform a number of iterations exponential in *m*, like the [simplex method](https://en.wikipedia.org/wiki/Simplex_method). However, its practical behaviour is typically much better.[^o6]
