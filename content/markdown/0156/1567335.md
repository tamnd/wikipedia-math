# Derived set (mathematics)

::: {#o1 .subject cue=lead name="Derived set"}

In mathematics, more specifically in [point-set topology](https://en.wikipedia.org/wiki/Point-set_topology), the **derived set** of a subset $S$ of a [topological space](wikipedia://en/30450) is the set of all [limit points](https://en.wikipedia.org/wiki/Limit_point) of $S.$ It is usually denoted by $S'.$

:::

The concept was first introduced by [Georg Cantor](wikipedia://en/12216) in 1872 and he developed [set theory](wikipedia://en/27553) in large part to study derived sets on the [real line](https://en.wikipedia.org/wiki/Real_line).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The **derived set** of a [subset](wikipedia://en/26691) $S$ of a [topological space](wikipedia://en/30450) $X,$ denoted by $S',$ is the set of all points $x \in X$ that are [limit points](https://en.wikipedia.org/wiki/Limit_point) of $S,$ that is, points $x$ such that every [neighbourhood](wikipedia://en/1529485) of $x$ contains a point of $S$ other than $x$ itself.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

If $\mathbb{R}$ is endowed with its usual [Euclidean topology](wikipedia://en/1482085) then the derived set of the [half-open interval](https://en.wikipedia.org/wiki/Half-open_interval) $[0, 1)$ is the [closed interval](https://en.wikipedia.org/wiki/Closed_interval) $[0, 1].$

Consider $\mathbb{R}$ with the [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29) (open sets) consisting of the [empty set](wikipedia://en/9566) and any subset of $\mathbb{R}$ that contains 1. The derived set of $A := \{1\}$ is $A' = \mathbb{R} \setminus \{1\}.$[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $X$ denote a topological space in what follows.

If $A$ and $B$ are subsets of $X,$ the derived set has the following properties:[^o9]

- $$\varnothing' = \varnothing$$
- $a \in A'$ implies $a \in (A \setminus \{a\})'$
- $$(A \cup B)' = A' \cup B'$$
- $A \subseteq B$ implies $A' \subseteq B'$

A set $S\subseteq X$ is [closed](wikipedia://en/47279) precisely when $S' \subseteq S,$[^o6] that is, when $S$ contains all its limit points. For any $S\subseteq X,$ the set $S \cup S'$ is closed and is the [closure](wikipedia://en/42309) of $S$ (that is, the set $\overline{S}$).[^o10]

### Closedness of derived sets {#Closedness_of_derived_sets}

The derived set of a set need not be closed in general. For example, if $X = \{a, b\}$ with the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology), the set $S = \{a\}$ has derived set $S' = \{b\},$ which is not closed in $X.$ But the derived set of a closed set is always closed.[^o12]

For a point $x\in X,$ the derived set of the singleton $\{x\}$ is the set $\{x\}'=\overline{\{x\}}\setminus\{x\},$ consisting of the points in the closure of $\{x\}$ and different from $x.$ A space $X$ is called a **T<sub>D</sub> space**[^o13] if the derived set of every singleton in $X$ is closed; that is, if $\overline{\{x\}}\setminus\{x\}$ is closed for every $x\in X;$ in other words, if every point $x$ is isolated in $\overline{\{x\}}.$ A space $X$ has the property that $S'$ is closed for all sets $S\subseteq X$ if and only if it is a T<sub>D</sub> space.[^n1]

Every T<sub>D</sub> space is a [T<sub>0</sub> space](https://en.wikipedia.org/wiki/T0_space).[^o15]

Every [T<sub>1</sub> space](wikipedia://en/148721) is a T<sub>D</sub> space,[^o15] since every singleton is closed, hence $\{x\}'=\overline{\{x\}}\setminus\{x\}=\varnothing,$ which is closed. Consequently, in a T<sub>1</sub> space, the derived set of any set is closed.[^o16][^o17]

The relation between these properties can be summarized as

$$T_1\implies T_D\implies T_0.$$

The implications are not reversible. For example, the [Sierpiński space](wikipedia://en/387651) is T<sub>D</sub> and not T<sub>1</sub>. And the [right order topology](https://en.wikipedia.org/wiki/Right_order_topology) on $\mathbb{R}$ is T<sub>0</sub> and not T<sub>D</sub>.

### More properties {#More_properties}

Two subsets $S$ and $T$ are [separated](wikipedia://en/148911) precisely when they are [disjoint](wikipedia://en/39359) and each is disjoint from the other's derived set $S' \cap T = \varnothing = T' \cap S.$[^o19]

A [bijection](wikipedia://en/3942) between two topological spaces is a [homeomorphism](wikipedia://en/13660) if and only if the derived set of the [image](wikipedia://en/579311) (in the second space) of any subset of the first space is the image of the derived set of that subset.[^o20]

In a T<sub>1</sub> space, the derived set of any finite set is empty and furthermore,

$$(S - \{p\})' = S' = (S \cup \{p\})',$$

for any subset $S$ and any point $p$ of the space. In other words, the derived set is not changed by adding to or removing from the given set a finite number of points.[^o21]

A set $S$ with $S \subseteq S'$ (that is, $S$ contains no [isolated points](wikipedia://en/390557)) is called [dense-in-itself](wikipedia://en/8327127). A set $S$ with $S = S'$ is called a [perfect set](wikipedia://en/5075551).[^o22] Equivalently, a perfect set is a closed dense-in-itself set, or, put another way, a closed set with no isolated points. Perfect sets are particularly important in applications of the [Baire category theorem](wikipedia://en/55227).

The [Cantor–Bendixson theorem](https://en.wikipedia.org/wiki/Cantor–Bendixson_theorem) states that any [Polish space](wikipedia://en/396622) can be written as the union of a [countable set](wikipedia://en/6026) and a perfect set. Because any [G<sub>δ</sub>](https://en.wikipedia.org/wiki/G-delta_set) subset of a Polish space is again a Polish space, the theorem also shows that any G<sub>δ</sub> subset of a Polish space is the union of a countable set and a set that is perfect with respect to the [induced topology](https://en.wikipedia.org/wiki/Induced_topology).

:::

## Topology in terms of derived sets {#Topology_in_terms_of_derived_sets}

Because homeomorphisms can be described entirely in terms of derived sets, derived sets have been used as the primitive notion in [topology](wikipedia://en/29954). A set of points $X$ can be equipped with an operator $S \mapsto S^*$ mapping subsets of $X$ to subsets of $X,$ such that for any set $S$ and any point $a$:

1. $$\varnothing^* = \varnothing$$
1. $$S^{**} \subseteq S^*\cup S$$
1. $a \in S^*$ implies $a \in (S \setminus \{a\})^*$
1. $$(S \cup T)^* \subseteq S^* \cup T^*$$
1. $S \subseteq T$ implies $S^* \subseteq T^*.$

Calling a set $S$ closed if $S^* \subseteq S$ will define a topology on the space in which $S \mapsto S^*$ is the derived set operator, that is, $S^* = S'.$

## Cantor–Bendixson rank {#Cantor–Bendixson_rank}

For [ordinal numbers](wikipedia://en/26547932) $\alpha,$ the $\alpha$-th **Cantor–[Bendixson](https://en.wikipedia.org/wiki/Ivar_Otto_Bendixson) derivative** of a topological space *X* is defined by repeatedly applying the derived set operation using [transfinite recursion](https://en.wikipedia.org/wiki/Transfinite_recursion) as follows:

- $$\displaystyle X^0 = X$$
- $$\displaystyle X^{\alpha+1} = \left(X^\alpha\right)'$$
- $\displaystyle X^\lambda = \bigcap_{\alpha < \lambda} X^\alpha$ for [limit ordinals](wikipedia://en/373137) $\lambda.$

The transfinite sequence of Cantor–Bendixson derivatives of $X$ is [decreasing](https://en.wikipedia.org/wiki/Decreasing) and must eventually be constant. The smallest ordinal $\alpha$ such that $X^{\alpha+1} = X^\alpha$ is called the **Cantor–Bendixson rank** of $X.$

This investigation into the derivation process was one of the motivations for introducing [ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_numbers) by [Georg Cantor](wikipedia://en/12216).
