# Shekel function

::: {#o1 .subject cue=lead name="Shekel function"}

*Image: Shekel\_2D.jpg.* A Shekel function in 2 dimensions and with 10 maxima

The **Shekel function** or also **Shekel's foxholes** is a multidimensional, multimodal, continuous, deterministic [function](wikipedia://en/185427) commonly used as a test function for testing [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) techniques.[^o2]

:::

The mathematical form of a function in $n$ dimensions with $m$ maxima is:

$$f(\vec{x}) = \sum_{i = 1}^{m} \; \left( c_{i} + \sum\limits_{j = 1}^{n} (x_{j} - a_{ji})^2 \right)^{-1}$$

or, similarly,

$$f(x_1,x_2,...,x_{n-1},x_n) = \sum_{i = 1}^{m} \; \left( c_{i} + \sum\limits_{j = 1}^{n} (x_{j} - a_{ij})^2 \right)^{-1}$$

## Global minima {#Global_minima}

Numerically certified global minima and the corresponding solutions were obtained using interval methods for up to $n = 10$.[^o4]
