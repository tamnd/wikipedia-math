# Partially ordered ring

::: {#o1 .subject cue=lead name="Partially ordered ring"}

In [abstract algebra](wikipedia://en/19616384), a **partially ordered ring** is a [ring](wikipedia://en/48404) (*A*, +, **·**), together with a *compatible partial order*, that is, a [partial order](https://en.wikipedia.org/wiki/Partial_order) $\,\leq\,$ on the [underlying set](https://en.wikipedia.org/wiki/Underlying_set) *A* that is compatible with the ring operations in the sense that it satisfies:

$$x \leq y \text{ implies } x + z \leq y + z$$

and

$$0 \leq x \text{ and } 0 \leq y \text{ imply that } 0 \leq x \cdot y$$

for all $x, y, z\in A$.[^o2] Various extensions of this definition exist that constrain the ring, the partial order, or both. For example, an **Archimedean partially ordered ring** is a partially ordered ring $(A, \leq)$ where $A$'s partially ordered additive [group](wikipedia://en/172048) is [Archimedean](wikipedia://en/264169).[^o3]

:::

An **ordered ring**, also called a **totally ordered ring**, is a partially ordered ring $(A, \leq)$ where $\,\leq\,$ is additionally a [total order](wikipedia://en/30330).[^o2][^o3]

An **l-ring**, or **lattice-ordered ring**, is a partially ordered ring $(A, \leq)$ where $\,\leq\,$ is additionally a [lattice order](https://en.wikipedia.org/wiki/Lattice_order).

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The additive group of a partially ordered ring is always a [partially ordered group](wikipedia://en/172048).

The set of non-negative elements of a partially ordered ring (the set of elements $x$ for which $0 \leq x,$ also called the positive cone of the ring) is closed under addition and multiplication, that is, if $P$ is the set of non-negative elements of a partially ordered ring, then $P + P \subseteq P$ and $P \cdot P \subseteq P.$ Furthermore, $P \cap (-P) = \{0\}.$

The mapping of the compatible partial order on a ring $A$ to the set of its non-negative elements is [one-to-one](https://en.wikipedia.org/wiki/Injective);[^o2] that is, the compatible partial order uniquely determines the set of non-negative elements, and a set of elements uniquely determines the compatible partial order if one exists.

If $S \subseteq A$ is a [subset](wikipedia://en/27631) of a ring $A,$ and:

1. $$0 \in S$$
1. $$S \cap (-S) = \{0\}$$
1. $$S + S \subseteq S$$
1. $$S \cdot S \subseteq S$$

then the relation $\,\leq\,$ where $x \leq y$ [if and only if](wikipedia://en/14922) $y - x \in S$ defines a compatible partial order on $A$ (that is, $(A, \leq)$ is a partially ordered ring).[^o3]

In any l-ring, the absolute value $|x|$ of an element $x$ can be defined to be $x \vee(-x),$ where $x \vee y$ denotes the [maximal element](https://en.wikipedia.org/wiki/Maximal_element). For any $x$ and $y,$

$$|x \cdot y| \leq |x| \cdot |y|$$

holds.[^o6]

:::

## f-rings {#f-rings}

An **f-ring**, or **Pierce–Birkhoff ring**, is a lattice-ordered ring $(A, \leq)$ in which $x \wedge y = 0$[^o8] and $0 \leq z$ imply that $zx \wedge y = xz \wedge y = 0$ for all $x, y, z \in A.$ They were first introduced by [Garrett Birkhoff](wikipedia://en/1180916) and [Richard S. Pierce](wikipedia://en/82428847) in 1956, in a paper titled "Lattice-ordered rings",[^o9] in an attempt to restrict the class of l-rings so as to eliminate a number of pathological examples. For example, Birkhoff and Pierce demonstrated an l-ring with 1 in which 1 is not positive, even though it is a square.[^o3] The additional hypothesis required of f-rings eliminates this possibility.

::: {#o11 .example cue=heading name="Example"}

### Example {#Example}

Let $X$ be a [Hausdorff space](wikipedia://en/13637), and $\mathcal{C}(X)$ be the [space](wikipedia://en/30450) of all [continuous](wikipedia://en/6122), [real](wikipedia://en/20646438)-valued [functions](wikipedia://en/185427) on $X.$ $\mathcal{C}(X)$ is an Archimedean f-ring with 1 under the following pointwise operations:

$$[f + g](x) = f(x) + g(x)$$

$$[fg](x) = f(x) \cdot g(x)$$

$$[f \wedge g](x) = f(x) \wedge g(x).$$

[^o3]

From an algebraic point of view the rings $\mathcal{C}(X)$ are fairly rigid. For example, [localisations](wikipedia://en/252216), residue rings or limits of rings of the form $\mathcal{C}(X)$ are not of this form in general. A much more flexible class of f-rings containing all rings of continuous functions and resembling many of the properties of these rings is the class of [real closed rings](wikipedia://en/31088633).

:::

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- A [direct product](wikipedia://en/8887) of f-rings is an f-ring, an l-subring of an f-ring is an f-ring, and an l-homomorphic [image](wikipedia://en/579311) of an f-ring is an f-ring.[^o6]
- $|xy| = |x||y|$ in an f-ring.[^o6]
- The [category](wikipedia://en/53759) **Arf** consists of the Archimedean f-rings with 1 and the l-homomorphisms that preserve the identity.[^o14]
- Every ordered ring is an f-ring, so every sub-direct union of ordered rings is also an f-ring. Assuming the [axiom of choice](wikipedia://en/840), a theorem of Birkhoff shows the converse, and that an l-ring is an f-ring if and only if it is l-isomorphic to a sub-direct union of ordered rings.[^o3] Some mathematicians take this to be the definition of an f-ring.[^o6]

:::
