# Almost open map

::: {#o1 .subject cue=lead name="Almost open map"}

In [functional analysis](wikipedia://en/11180) and related areas of [mathematics](wikipedia://en/18831), an **almost open map** between [topological spaces](https://en.wikipedia.org/wiki/Topological_spaces) is a [map](wikipedia://en/185427) that satisfies a condition similar to, but weaker than, the condition of being an [open map](https://en.wikipedia.org/wiki/Open_map). As described below, for certain broad categories of [topological vector spaces](https://en.wikipedia.org/wiki/Topological_vector_spaces), all [surjective](https://en.wikipedia.org/wiki/Surjective_map) linear operators are necessarily almost open.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Given a surjective map $f : X \to Y,$ a point $x \in X$ is called a point of openness for $f$ and $f$ is said to be open at $x$ (or an open map at $x$) if for every open neighborhood $U$ of $x,$ $f(U)$ is a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of $f(x)$ in $Y$ (note that the neighborhood $f(U)$ is not required to be an open neighborhood).

A surjective map is called an [open map](https://en.wikipedia.org/wiki/Open_map) if it is open at every point of its domain, while it is called an almost open map if each of its [fibers](wikipedia://en/6603892) has some point of openness. Explicitly, a surjective map $f : X \to Y$ is said to be almost open if for every $y \in Y,$ there exists some $x \in f^{-1}(y)$ such that $f$ is open at $x.$ Every almost open surjection is necessarily a pseudo-open map (introduced by [Alexander Arhangelskii](wikipedia://en/36284117) in 1963), which by definition means that for every $y \in Y$ and every neighborhood $U$ of $f^{-1}(y)$ (that is, $f^{-1}(y) \subseteq \operatorname{Int}_X U$), $f(U)$ is necessarily a neighborhood of $y.$

### Almost open linear map {#Almost_open_linear_map}

A linear map $T : X \to Y$ between two [topological vector spaces](wikipedia://en/45752) (TVSs) is called a nearly open linear map or an almost open linear map if for any neighborhood $U$ of $0$ in $X,$ the closure of $T(U)$ in $Y$ is a neighborhood of the origin. Importantly, some authors use a different definition of "almost open map" in which they instead require that the linear map $T$ satisfy: for any neighborhood $U$ of $0$ in $X,$ the closure of $T(U)$ in $T(X)$ (rather than in $Y$) is a neighborhood of the origin; this article will not use this definition.[^n1]

If a linear map $T : X \to Y$ is almost open then because $T(X)$ is a vector subspace of $Y$ that contains a neighborhood of the origin in $Y,$ the map $T : X \to Y$ is necessarily [surjective](https://en.wikipedia.org/wiki/Surjective). For this reason many authors require surjectivity as part of the definition of "almost open".

If $T : X \to Y$ is a bijective linear operator, then $T$ is almost open if and only if $T^{-1}$ is [almost continuous](https://en.wikipedia.org/wiki/Almost_continuous).[^n1]

:::

## Relationship to open maps {#Relationship_to_open_maps}

Every surjective [open map](https://en.wikipedia.org/wiki/Open_map) is an almost open map but in general, the converse is not necessarily true. If a surjection $f : (X, \tau) \to (Y, \sigma)$ is an almost open map then it will be an open map if it satisfies the following condition (a condition that does not depend in any way on $Y$'s topology $\sigma$):

whenever $m, n \in X$ belong to the same [fiber](wikipedia://en/6603892) of $f$ (that is, $f(m) = f(n)$) then for every neighborhood $U \in \tau$ of $m,$ there exists some neighborhood $V \in \tau$ of $n$ such that $F(V) \subseteq F(U).$

If the map is continuous then the above condition is also necessary for the map to be open. That is, if $f : X \to Y$ is a continuous surjection then it is an open map if and only if it is almost open and it satisfies the above condition.

::: {#o9 .statement kind=statement/theorem cue=named-heading name="Open mapping theorems"}

### Open mapping theorems {#Open_mapping_theorems}

**Theorem**:[^n1] If $T : X \to Y$ is a surjective linear operator from a [locally convex](wikipedia://en/518844) space $X$ onto a [barrelled space](wikipedia://en/1733592) $Y$ then $T$ is almost open.

**Theorem**:[^n1] If $T : X \to Y$ is a surjective linear operator from a TVS $X$ onto a [Baire space](wikipedia://en/200550) $Y$ then $T$ is almost open.

The two theorems above do not require the surjective linear map to satisfy any topological conditions.

**Theorem**:[^n1] If $X$ is a complete [pseudometrizable TVS](wikipedia://en/64278078), $Y$ is a Hausdorff TVS, and $T : X \to Y$ is a closed and almost open linear surjection, then $T$ is an open map.

**Theorem**:[^n1] Suppose $T : X \to Y$ is a continuous linear operator from a complete [pseudometrizable TVS](wikipedia://en/64278078) $X$ into a Hausdorff TVS $Y.$ If the image of $T$ is non-[meager](https://en.wikipedia.org/wiki/Meager_set) in $Y$ then $T : X \to Y$ is a surjective open map and $Y$ is a complete metrizable space.

:::
