# Ξ function

::: {#o1 .subject cue=lead name="Ξ function"}

In [mathematics](wikipedia://en/18831), the **Ξ function** (named for the Greek letter [Ξ](https://en.wikipedia.org/wiki/Ξ) or Xi) may refer to:

:::

- [Riemann Xi function](https://en.wikipedia.org/wiki/Riemann_Xi_function), a variant of the Riemann zeta function with a simpler functional equation
- [Harish-Chandra's Ξ function](wikipedia://en/33194636), a special spherical function on a semisimple Lie group
