# Harish-Chandra's Ξ function

::: {#o1 .subject cue=lead name="Harish-Chandra's Ξ function"}

In [mathematics](wikipedia://en/18831), specifically [harmonic analysis](https://en.wikipedia.org/wiki/Abstract_harmonic_analysis), **Harish-Chandra's *Ξ* function** is a [special](https://en.wikipedia.org/wiki/Special_function) spherical function on a [semisimple Lie group](https://en.wikipedia.org/wiki/Semisimple_Lie_group). It was introduced by [Harish-Chandra](wikipedia://en/373190),[^n1] who used it to define [his Schwartz space](wikipedia://en/33194896).

:::

For $K$ a maximal [compact](wikipedia://en/6042) subgroup of a semisimple Lie group with [Iwasawa decomposition](wikipedia://en/1139148) $G=NAK$, $g$ an element of $G$, $a(g)$ the element $a$ in the Iwasawa decomposition $g=nak$ and $\rho$ a [Weyl vector](https://en.wikipedia.org/wiki/Weyl_vector), the $\Xi$ function is defined as

$$\Xi(g)=\int_Ka(kg)^\rho dk.$$

[Wallach](https://en.wikipedia.org/wiki/Nolan_Wallach) gives a detailed description of the properties of $\Xi$.[^n2]
