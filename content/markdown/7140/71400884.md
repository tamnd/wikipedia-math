# Nori-semistable vector bundle

::: {#o1 .subject cue=lead name="Nori-semistable vector bundle"}

In mathematics, a **Nori semistable vector bundle** is a particular type of [vector bundle](https://en.wikipedia.org/wiki/Vector_bundle_%28algebraic_geometry%29) whose first definition has been first implicitly suggested by [Madhav V. Nori](wikipedia://en/71398482),[^o2][^o3] as one of the main ingredients for the construction of the [fundamental group scheme](wikipedia://en/27509612). The original definition given by Nori was obviously not called *Nori semistable*. Also, Nori's definition was different from the one suggested nowadays.[^o4] The [category](wikipedia://en/53759) of Nori semistable vector bundles contains the [Tannakian category](wikipedia://en/7221237) of [essentially finite vector bundles](wikipedia://en/30035960), whose naturally associated group scheme is the [fundamental group scheme](wikipedia://en/27509612) $\pi_1(X,x)$.

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a scheme over a field $k$ and $V$ a vector bundle on $X$. It is said that $V$ is *Nori semistable* if for any smooth and proper curve $C$ over $\bar k$ and any morphism $j:C\to X$ the pull back $j^*(V)$ is [semistable](wikipedia://en/18909129) of degree 0.[^o7]

:::

## Difference with Nori's original definition {#Difference_with_Nori's_original_definition}

Nori semistable vector bundles were called by Nori *semistable* causing a lot of confusion with the already existing definition of semistable vector bundles. More importantly Nori simply said that the restriction of $V$ to any curve in $X$ had to be semistable of degree 0. Then for instance in positive characteristic a morphism $j$ like the [Frobenius morphism](https://en.wikipedia.org/wiki/Frobenius_morphism) was not included in Nori's original definition. The importance of including it is that the above definition makes the category of Nori semistable vector bundles tannakian and the group scheme associated to it is the $S$-fundamental group scheme[^o9] $\pi^S(X,x)$. Instead, Nori's original definition didn't give rise to a Tannakian category but only to an [abelian category](wikipedia://en/45063).
