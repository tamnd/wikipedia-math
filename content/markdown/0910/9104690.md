# Homogeneously Suslin set

::: {#o1 .subject cue=lead name="Homogeneously Suslin set"}

In [descriptive set theory](wikipedia://en/396619), a set $S$ is said to be **homogeneously Suslin** if it is the projection of a [homogeneous](wikipedia://en/9104798) [tree](wikipedia://en/2190732). $S$ is said to be **$\kappa$-homogeneously Suslin** if it is the projection of a $\kappa$-homogeneous tree.

:::

If $A\subseteq{}^\omega\omega$ is a $\mathbf{\Pi}_1^1$ set and $\kappa$ is a measurable cardinal, then $A$ is $\kappa$-homogeneously Suslin. This result is important in the proof that the existence of a [measurable cardinal](wikipedia://en/248102) implies that $\mathbf{\Pi}_1^1$ sets are [determined](wikipedia://en/2596030).
