# Infinitesimal cohomology

::: {#o1 .subject cue=lead name="Infinitesimal cohomology"}

In mathematics, **infinitesimal cohomology** is a [cohomology theory](https://en.wikipedia.org/wiki/Cohomology_theory) for [algebraic varieties](wikipedia://en/248808) introduced by (txt). In characteristic 0 it is essentially the same as [crystalline cohomology](wikipedia://en/10220067). In nonzero characteristic *p* (Ogus 1975) showed that it is closely related to [etale cohomology](https://en.wikipedia.org/wiki/Etale_cohomology) with mod *p* coefficients, a theory known to have undesirable properties.

:::
