# Bogacki–Shampine method

::: {#o1 .subject cue=lead name="Bogacki–Shampine method"}

The **Bogacki–Shampine method** is a method for the [numerical solution of ordinary differential equations](https://en.wikipedia.org/wiki/Numerical_ordinary_differential_equations), that was proposed by Przemysław Bogacki and Lawrence F. Shampine in 1989 (Bogacki Shampine 1989). The Bogacki–Shampine method is a [Runge–Kutta method](https://en.wikipedia.org/wiki/Runge–Kutta_method) of order three with four stages with the First Same As Last (FSAL) property, so that it uses approximately three function evaluations per step. It has an embedded second-order method which can be used to implement [adaptive step size](wikipedia://en/8449246). The Bogacki–Shampine method is implemented in the `ode3` for fixed step solver and `ode23` for a variable step solver function in [MATLAB](wikipedia://en/20412) (Shampine Reichelt 1997).

:::

Low-order methods are more suitable than higher-order methods like the [Dormand–Prince method](wikipedia://en/8452422) of order five, if only a crude approximation to the solution is required. Bogacki and Shampine argue that their method outperforms other third-order methods with an embedded method of order two.

The [Butcher tableau](https://en.wikipedia.org/wiki/Runge–Kutta_method#Explicit_Runge–Kutta_methods) for the Bogacki–Shampine method is:

|  | 0 |  |  |  |  |
|---|---|---|---|---|---|
|  | 1/2 | 1/2 |  |  |  |
|  | 3/4 | 0 | 3/4 |  |  |
|  | 1 | 2/9 | 1/3 | 4/9 |  |
|  |  | 2/9 | 1/3 | 4/9 | 0 |
|  |  | 7/24 | 1/4 | 1/3 | 1/8 |

Following the standard notation, the differential equation to be solved is $y'=f(t,y)$. Furthermore, $y_n$ denotes the numerical solution at time $t_n$ and $h_n$ is the step size, defined by $h_n = t_{n+1}-t_n$. Then, one step of the Bogacki–Shampine method is given by:

$$\begin{aligned} k_1 &= f(t_n, y_n) \\ k_2 &= f(t_n + \tfrac12 h_n, y_n + \tfrac12 h_n k_1) \\ k_3 &= f(t_n + \tfrac34 h_n, y_n + \tfrac34 h_n k_2) \\ y_{n+1} &= y_n + \tfrac29 h_n k_1 + \tfrac13 h_n k_2 + \tfrac49 h_n k_3 \\ k_4 &= f(t_n + h_n, y_{n+1}) \\ z_{n+1} &= y_n + \tfrac7{24} h_n k_1 + \tfrac14 h_n k_2 + \tfrac13 h_n k_3 + \tfrac18 h_n k_4. \end{aligned}$$

Here, $z_{n+1}$ is a second-order approximation to the exact solution. The method for calculating $y_{n+1}$ is due to (Ralston 1965). On the other hand, $y_{n+1}$ is a third-order approximation, so the difference between $y_{n+1}$ and $z_{n+1}$ can be used to [adapt the step size](https://en.wikipedia.org/wiki/Adaptive_stepsize). The FSAL—first same as last—property is that the stage value $k_4$ in one step equals $k_1$ in the next step; thus, only three function evaluations are needed per step.
