# Singular submodule

::: {#o1 .subject cue=lead name="Singular submodule"}

In the branches of [abstract algebra](wikipedia://en/19616384) known as [ring theory](wikipedia://en/250424) and [module theory](https://en.wikipedia.org/wiki/Module_theory), each right (resp. left) *R*-[module](wikipedia://en/276410) *M* has a **singular submodule** consisting of elements whose [annihilators](wikipedia://en/328684) are [essential](https://en.wikipedia.org/wiki/Essential_submodule) right (resp. left) [ideals](wikipedia://en/25977) in *R*. In set notation it is usually denoted as $\mathcal{Z}(M) = \{m\in M \mid \mathrm{ann}(m) \subseteq_e R\}\,$. For general [rings](wikipedia://en/48404), $\mathcal{Z}(M)$ is a good generalization of the [torsion submodule](https://en.wikipedia.org/wiki/Torsion_submodule) tors(*M*) which is most often defined for [domains](wikipedia://en/487627). In the case that *R* is a [commutative](wikipedia://en/61346) domain, $\operatorname{tors}(M) = \mathcal{Z}(M)$.

:::

If *R* is any ring, $\mathcal{Z}(R_R)$ is defined considering *R* as a right module, and in this case $\mathcal{Z}(R_R)$ is a two-sided ideal of *R* called the **right singular ideal** of *R*. The left handed analogue $\mathcal{Z}(_R R)$ is defined similarly. It is possible for $\mathcal{Z}(R_R) \neq \mathcal{Z}(_R R)$.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Here are several definitions used when studying singular submodules and singular ideals. In the following, *M* is an *R*-module:

- *M* is called a **singular module** if $\mathcal{Z}(M) = M\,$.
- *M* is called a **nonsingular module** if $\mathcal{Z}(M) = \{0\}\,$.
- *R* is called **right nonsingular** if $\mathcal{Z}(R_R) = \{0\}\,$. A **left nonsingular** ring is defined similarly, using the left singular ideal, and it is entirely possible for a ring to be right-but-not-left nonsingular.

In rings with unity it is always the case that $\mathcal{Z}(R_R)\subsetneq R\,$, and so "right singular ring" is not usually defined the same way as singular modules are. Some authors have used "singular ring" to mean "has a nonzero singular ideal", however this usage is not consistent with the usage of the adjectives for modules.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Some general properties of the singular submodule include:

- $\mathcal{Z}(M_R) \cdot \mathrm{soc}(R_R) = \{0\}\,$ where $\mathrm{soc}(M_R)\,$ denotes the [socle](wikipedia://en/3571350) of $R_R$.
- If *f* is a [homomorphism](wikipedia://en/474118) of *R*-modules from *M* to *N*, then $f(\mathcal{Z}(M))\subseteq \mathcal{Z}(N)\,$.
- If *N* is a [submodule](https://en.wikipedia.org/wiki/Submodule) of *M*, then $\mathcal{Z}(N)=N\cap \mathcal{Z}(M)\,$.
- The properties "singular" and "nonsingular" are [Morita invariant properties](wikipedia://en/3296134).
- The singular ideals of a ring contain central [nilpotent](wikipedia://en/252235) elements of the ring. Consequently, the singular ideal of a commutative ring contains the [nilradical](wikipedia://en/289636) of the ring.
- A general property of the torsion submodule is that $t(M/t(M))=\{0\}\,$, but this does not necessarily hold for the singular submodule. However, if *R* is a right nonsingular ring, then $\mathcal{Z}(M/\mathcal{Z}(M))=\{0\}\,$.
- If *N* is an essential submodule of *M* (both right modules) then *M*/*N* is singular. If *M* is a [free module](wikipedia://en/326454), or if *R* is right nonsingular, then the converse is true.
- A [semisimple module](wikipedia://en/1001361) is nonsingular [if and only if](wikipedia://en/14922) it is a [projective module](wikipedia://en/364488).
- If *R* is a right [self-injective ring](wikipedia://en/473775#Self-injective_rings), then $\mathcal{Z}(R_R)=J(R)\,$, where J(*R*) is the [Jacobson radical](wikipedia://en/57656) of *R*.

:::

## Examples {#Examples}

Right nonsingular rings are a very broad class, including [reduced rings](wikipedia://en/539749), right [(semi)hereditary rings](wikipedia://en/5123176), [von Neumann regular rings](wikipedia://en/907524), [domains](wikipedia://en/487627), [semisimple rings](https://en.wikipedia.org/wiki/Semisimple_ring), [Baer rings](wikipedia://en/7455223) and right [Rickart rings](https://en.wikipedia.org/wiki/Rickart_ring).

For commutative rings, being nonsingular is equivalent to being a reduced ring.

:::

::: {#o9 .statement kind=statement/theorem cue=named-heading name="Important theorems"}

## Important theorems {#Important_theorems}

**Johnson's Theorem** (due to R. E. Johnson (Lam 1999, 376)) contains several important equivalences. For any ring *R*, the following are equivalent:

1. *R* is right nonsingular.
1. The [injective hull](wikipedia://en/665821) E(*R*<sub>*R*</sub>) is a nonsingular right *R*-module.
1. The [endomorphism](wikipedia://en/9569) ring $S = \mathrm{End}(E(R_R))\,$ is a [semiprimitive ring](wikipedia://en/485855) (that is, $J(S)=\{0\}\,$).
1. The [maximal right ring of quotients](https://en.wikipedia.org/wiki/Maximal_ring_of_quotients) $Q_{max}^r(R)$ is von Neumann regular.

Right nonsingularity has a [strong interaction](https://en.wikipedia.org/wiki/Strong_interaction) with right self injective rings as well.

::: {#o11 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** If *R* is a right self injective ring, then the following conditions on *R* are equivalent: right nonsingular, von Neumann regular, right semihereditary, right Rickart, Baer, semiprimitive. (Lam 1999, 262)

The paper (Zelmanowitz 1983) used nonsingular modules to characterize the class of rings whose maximal right ring of quotients have a certain structure.

:::

::: {#o14 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** If *R* is a ring, then $Q_{max}^r(R)$ is a right [full linear ring](wikipedia://en/485862#Full_linear_rings) if and only if *R* has a nonsingular, [faithful](https://en.wikipedia.org/wiki/Faithful_module), [uniform module](wikipedia://en/31553078). Moreover, $Q_{max}^r(R)$ is a finite direct product of full linear rings if and only if *R* has a nonsingular, faithful module with finite [uniform dimension](https://en.wikipedia.org/wiki/Uniform_dimension).

:::
