# Young's inequality for integral operators

::: {#o1 .subject cue=lead name="Young's inequality for integral operators"}

In [mathematical analysis](wikipedia://en/48396), the **Young's inequality for integral operators**, is a bound on the $L^p\to L^q$ [operator norm](wikipedia://en/246722) of an [integral operator](wikipedia://en/2649421) in terms of $L^r$ norms of the kernel itself.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Assume that $X$ and $Y$ are measurable spaces, $K : X \times Y \to \mathbb{R}$ is measurable and $q,p,r\geq 1$ are such that $\frac{1}{q} = \frac{1}{p} + \frac{1}{r} -1$. If

$\int_{Y} |K (x, y)|^r \,\mathrm{d} y \le C^r$ for all $x\in X$

and

$\int_{X} |K (x, y)|^r \,\mathrm{d} x \le C^r$ for all $y\in Y$

then [^o4]

$$\int_{X} \left|\int_{Y} K (x, y) f(y) \,\mathrm{d} y\right|^q \, \mathrm{d} x \le C^q \left( \int_{Y} |f(y)|^p \,\mathrm{d} y\right)^\frac{q}{p}.$$

:::

## Particular cases {#Particular_cases}

### Convolution kernel {#Convolution_kernel}

If $X = Y = \mathbb{R}^d$ and $K (x, y) = h (x - y)$, then the inequality becomes [Young's convolution inequality](wikipedia://en/38542576).
