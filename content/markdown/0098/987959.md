# Gram matrix

::: {#o1 .subject cue=lead name="Gram matrix"}

In [linear algebra](wikipedia://en/18422), the **Gram matrix** (or **Gramian matrix**, **Gramian**) of vectors $v_1,\dots, v_n$ in an [inner product space](wikipedia://en/14856) is the [Hermitian matrix](wikipedia://en/189682) of [inner products](https://en.wikipedia.org/wiki/Inner_product), whose entries are given by the [inner product](https://en.wikipedia.org/wiki/Inner_product) $G_{ij} = \left\langle v_i, v_j \right\rangle$.[^o2] If the vectors $v_1,\dots, v_n$ are the columns of matrix $X$ then the Gram matrix is $X^\dagger X$ in the general case that the vector coordinates are complex numbers, which simplifies to $X^\top X$ for the case that the vector coordinates are real numbers.

:::

An important application is to compute [linear independence](wikipedia://en/101863): a set of vectors are linearly independent if and only if the Gram determinant (the [determinant](wikipedia://en/8468) of the Gram matrix) is non-zero.

It is named after [Jørgen Pedersen Gram](wikipedia://en/851232).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

For finite-dimensional real vectors in $\mathbb{R}^n$ with the usual Euclidean [dot product](wikipedia://en/157093), the Gram matrix is $G = V^\top V$, where $V$ is a matrix whose columns are the vectors $v_k$ and $V^\top$ is its [transpose](wikipedia://en/173844) whose rows are the vectors $v_k^\top$. For [complex](wikipedia://en/5826) vectors in $\mathbb{C}^n$, $G = V^\dagger V$, where $V^\dagger$ is the [conjugate transpose](wikipedia://en/217548) of $V$.

Given [square-integrable functions](wikipedia://en/28680558) $\{\ell_i(\cdot),\, i = 1,\dots,n\}$ on the interval $\left[t_0, t_f\right]$, the Gram matrix $G = \left[G_{ij}\right]$ is:

$$G_{ij} = \int_{t_0}^{t_f} \ell_i^*(\tau)\ell_j(\tau)\, d\tau.$$

where $\ell_i^*(\tau)$ is the [complex conjugate](wikipedia://en/173918) of $\ell_i(\tau)$.

For any [bilinear form](wikipedia://en/449477) $B$ on a [finite-dimensional](https://en.wikipedia.org/wiki/Finite-dimensional) [vector space](wikipedia://en/32370) over any [field](wikipedia://en/10603) we can define a Gram matrix $G$ attached to a set of vectors $v_1, \dots, v_n$ by $G_{ij} = B\left(v_i, v_j\right)$. The matrix will be symmetric if the bilinear form $B$ is symmetric.

::: {#o6 .application cue=heading name="Applications"}

### Applications {#Applications}

- In [Riemannian geometry](wikipedia://en/195243), given an embedded $k$-dimensional [Riemannian manifold](wikipedia://en/144652) $M\subset \mathbb{R}^n$ and a parametrization $\phi: U\to M$ for $(x_1, \ldots, x_k)\in U\subset\mathbb{R}^k$, the volume form $\omega$ on $M$ induced by the embedding may be computed using the Gramian of the coordinate tangent vectors: $$\omega = \sqrt{\det G}\ dx_1 \cdots dx_k,\quad G = \left[\left\langle \frac{\partial\phi}{\partial x_i},\frac{\partial\phi}{\partial x_j}\right\rangle\right].$$ This generalizes the classical surface integral of a parametrized surface $\phi:U\to S\subset \mathbb{R}^3$ for $(x, y)\in U\subset\mathbb{R}^2$: $$\int_S f\ dA = \iint_U f(\phi(x, y))\, \left|\frac{\partial\phi}{\partial x}\,{\times}\,\frac{\partial\phi}{\partial y}\right|\, dx\, dy.$$
- If the vectors are centered [random variables](wikipedia://en/25685), the Gramian is approximately proportional to the **[covariance matrix](wikipedia://en/191752)**, with the scaling determined by the number of elements in the vector.
- In [quantum chemistry](https://en.wikipedia.org/wiki/Quantum_chemistry), the Gram matrix of a set of [basis vectors](https://en.wikipedia.org/wiki/Basis_vectors) is the **[overlap matrix](https://en.wikipedia.org/wiki/Overlap_matrix)**.
- In [control theory](wikipedia://en/7039) (or more generally [systems theory](wikipedia://en/29238)), the **[controllability Gramian](wikipedia://en/5347320)** and **[observability Gramian](wikipedia://en/5347359)** determine properties of a linear system.
- Gramian matrices arise in covariance structure model fitting (see e.g., Jamshidian and Bentler, 1993, Applied Psychological Measurement, Volume 18, pp. 79–94).
- In the [finite element method](wikipedia://en/18233581), the Gram matrix arises from approximating a function from a finite dimensional space; the Gram matrix entries are then the inner products of the basis functions of the finite dimensional subspace.
- In [machine learning](wikipedia://en/233488), [kernel functions](https://en.wikipedia.org/wiki/Kernel_function) are often represented as Gram matrices.[^o7] (Also see [kernel PCA](wikipedia://en/5978424))
- Since the Gram matrix over the reals is a [symmetric matrix](wikipedia://en/126474), it is [diagonalizable](https://en.wikipedia.org/wiki/Diagonalizable) and its [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) are non-negative. The diagonalization of the Gram matrix is the [singular value decomposition](wikipedia://en/142207).

## Properties {#Properties}

### Positive-semidefiniteness {#Positive-semidefiniteness}

The Gram matrix is [symmetric](wikipedia://en/126474) in the case the inner product is real-valued; it is [Hermitian](wikipedia://en/189682) in the general, complex case by definition of an [inner product](https://en.wikipedia.org/wiki/Inner_product).

The Gram matrix is [positive semidefinite](https://en.wikipedia.org/wiki/Positive-semidefinite_matrix), and every positive semidefinite matrix is the Gramian matrix for some set of vectors. The fact that the Gramian matrix is positive-semidefinite can be seen from the following simple derivation:

$$x^\dagger \mathbf{G} x = \sum_{i,j}x_i^* x_j\left\langle v_i, v_j \right\rangle = \sum_{i,j}\left\langle x_i v_i, x_j v_j \right\rangle = \biggl\langle \sum_i x_i v_i, \sum_j x_j v_j \biggr\rangle = \biggl\| \sum_i x_i v_i \biggr\|^2 \geq 0 .$$

The first equality follows from the definition of matrix multiplication, the second and third from the bi-linearity of the [inner-product](https://en.wikipedia.org/wiki/Inner-product), and the last from the positive definiteness of the inner product. Note that this also shows that the Gramian matrix is positive definite if and only if the vectors $v_i$ are linearly independent (that is, $\sum_i x_i v_i \neq 0$ for all $x$).[^o2]

### Finding a vector realisation {#Finding_a_vector_realisation}

Given any positive semidefinite matrix $M$, one can decompose it as:

$$M = B^\dagger B,$$

where $B^\dagger$ is the [conjugate transpose](wikipedia://en/217548) of $B$ (or $M = B^\textsf{T} B$ in the real case).

Here $B$ is a $k \times n$ matrix, where $k$ is the [rank](https://en.wikipedia.org/wiki/Matrix_rank) of $M$. Various ways to obtain such a decomposition include computing the [Cholesky decomposition](wikipedia://en/134433) or taking the [non-negative square root](wikipedia://en/2929701) of $M$.

The columns $b^{(1)}, \dots, b^{(n)}$ of $B$ can be seen as *n* vectors in $\mathbb{C}^k$ (or *k*-dimensional Euclidean space $\mathbb{R}^k$, in the real case). Then

$$M_{ij} = b^{(i)} \cdot b^{(j)}$$

where the [dot product](wikipedia://en/157093) $a \cdot b = \sum_{\ell=1}^k a_\ell^* b_\ell$ is the usual inner product on $\mathbb{C}^k$.

Thus a [Hermitian matrix](wikipedia://en/189682) $M$ is positive semidefinite if and only if it is the Gram matrix of some vectors $b^{(1)}, \dots, b^{(n)}$. Such vectors are called a **vector realization** of $M$. The infinite-dimensional analog of this statement is [Mercer's theorem](wikipedia://en/303990).

### Uniqueness of vector realizations {#Uniqueness_of_vector_realizations}

If $M$ is the Gram matrix of vectors $v_1,\dots,v_n$ in $\mathbb{R}^k$ then applying any rotation or reflection of $\mathbb{R}^k$ (any [orthogonal transformation](wikipedia://en/1382381), that is, any [Euclidean isometry](https://en.wikipedia.org/wiki/Euclidean_isometry) preserving 0) to the sequence of vectors results in the same Gram matrix. That is, for any $k \times k$ [orthogonal matrix](wikipedia://en/105620) $Q$, the Gram matrix of $Q v_1,\dots, Q v_n$ is also $M$.

This is the only way in which two real vector realizations of $M$ can differ: the vectors $v_1,\dots,v_n$ are unique up to [orthogonal transformations](wikipedia://en/1382381). In other words, the dot products $v_i \cdot v_j$ and $w_i \cdot w_j$ are equal if and only if some rigid transformation of $\mathbb{R}^k$ transforms the vectors $v_1,\dots,v_n$ to $w_1, \dots, w_n$ and 0 to 0.

The same holds in the complex case, with [unitary transformations](wikipedia://en/236007) in place of orthogonal ones. That is, if the Gram matrix of vectors $v_1, \dots, v_n$ is equal to the Gram matrix of vectors $w_1, \dots, w_n$ in $\mathbb{C}^k$ then there is a [unitary](wikipedia://en/129222) $k \times k$ matrix $U$ (meaning $U^\dagger U = I$) such that $v_i = U w_i$ for $i = 1, \dots, n$.[^o13]

### Other properties {#Other_properties}

- Because $G = G^\dagger$, it is necessarily the case that $G$ and $G^\dagger$ commute. That is, a real or complex Gram matrix $G$ is also a [normal matrix](wikipedia://en/170366).
- The Gram matrix of any [orthonormal basis](wikipedia://en/195063) is the identity matrix. In particular, the Gram matrix of the rows or the columns of a real [rotation matrix](wikipedia://en/856005) is the identity matrix. Likewise, the Gram matrix of the rows or columns of a [unitary matrix](wikipedia://en/129222) is the identity matrix.
- The rank of the Gram matrix of vectors in $\mathbb{R}^k$ or $\mathbb{C}^k$ equals the dimension of the space [spanned](wikipedia://en/56353) by these vectors.[^o2]

## Gram determinant {#Gram_determinant}

The **Gram determinant** or **Gramian** is the determinant of the Gram matrix:

$$\bigl|G(v_1, \dots, v_n)\bigr| = \begin{vmatrix} \langle v_1,v_1\rangle & \langle v_1,v_2\rangle &\dots & \langle v_1,v_n\rangle \\ \langle v_2,v_1\rangle & \langle v_2,v_2\rangle &\dots & \langle v_2,v_n\rangle \\ \vdots & \vdots & \ddots & \vdots \\ \langle v_n,v_1\rangle & \langle v_n,v_2\rangle &\dots & \langle v_n,v_n\rangle \end{vmatrix}.$$

If $v_1, \dots, v_n$ are vectors in $\mathbb{R}^m$ then it is the square of the *n*-dimensional volume of the [parallelotope](wikipedia://en/23975#Parallelotope) formed by the vectors. In particular, the vectors are [linearly independent](wikipedia://en/101863) [if and only if](wikipedia://en/14922) the parallelotope has nonzero *n*-dimensional volume, if and only if Gram determinant is nonzero, if and only if the Gram matrix is [nonsingular](https://en.wikipedia.org/wiki/Non-singular_matrix). When *n* > *m* the determinant and volume are zero. When *n* = *m*, this reduces to the standard theorem that the absolute value of the determinant of *n* *n*-dimensional vectors is the *n*-dimensional volume. The volume of the [simplex](wikipedia://en/39781) formed by the vectors is $\operatorname{Volume}(\operatorname{parallelotope}) / n!$.

When $v_1, \dots, v_n$ are linearly independent, the distance between a point $x$ and the linear span of $v_1, \dots, v_n$ is $\sqrt{\frac{|G(x,v_1, \dots, v_n)|}{|G(v_1, \dots, v_n)|}}$.

Consider the moment problem: given $c_1, \dots, c_n \in \mathbb C$, find a vector $v$ such that $\left\langle v, v_i\right\rangle=c_i$, for all $1 \leqslant i \leqslant n$. There exists a unique solution with minimal norm:[^o17]

$$v=-\frac{1}{G\left(v_1, v_2, \ldots, v_n\right)} \det \begin{bmatrix} 0 & c_1 & c_2 & \cdots & c_n \\ v_1 & \left\langle v_1, v_1\right\rangle & \left\langle v_1, v_2\right\rangle & \cdots & \left\langle v_1, v_n\right\rangle \\ v_2 & \left\langle v_2, v_1\right\rangle & \left\langle v_2, v_2\right\rangle & \cdots & \left\langle v_2, v_n\right\rangle \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ v_n & \left\langle v_n, v_1\right\rangle & \left\langle v_n, v_2\right\rangle & \cdots & \left\langle v_n, v_n\right\rangle \end{bmatrix}$$

The Gram determinant can also be expressed in terms of the [exterior product](https://en.wikipedia.org/wiki/Exterior_product) of vectors by

$$\bigl|G(v_1, \dots, v_n)\bigr| = \| v_1 \wedge \cdots \wedge v_n\|^2.$$

The Gram determinant therefore supplies an [inner product](https://en.wikipedia.org/wiki/Exterior_product#inner_product) for the space ${\textstyle\bigwedge}^{\!n}(V)$. If an [orthonormal basis](wikipedia://en/195063) *e*<sub>*i*</sub>, *i* = 1, 2, ..., *n* on $V$ is given, the vectors

$$e_{i_1} \wedge \cdots \wedge e_{i_n},\quad i_1 < \cdots < i_n,$$

will constitute an orthonormal basis of *n*-dimensional volumes on the space ${\textstyle\bigwedge}^{\!n}(V)$. Then the Gram determinant $\bigl|G(v_1, \dots, v_n)\bigr|$ amounts to an *n*-dimensional [Pythagorean theorem](wikipedia://en/26513034#Sets_of_m-dimensional_objects_in_n-dimensional_space) for the volume of the parallelotope formed by the vectors $v_1 \wedge \cdots \wedge v_n$ in terms of its projections onto the basis volumes $e_{i_1} \wedge \cdots \wedge e_{i_n}$.

When the vectors $v_1, \ldots, v_n \in \mathbb{R}^m$ are defined from the positions of points $p_1, \ldots, p_n$ relative to some reference point $p_{n+1}$,

$$(v_1, v_2, \ldots, v_n) = (p_1 - p_{n+1}, p_2 - p_{n+1}, \ldots, p_n - p_{n+1})\,,$$

then the Gram determinant can be written as the difference of two Gram determinants,

$$\bigl|G(v_1, \dots, v_n)\bigr| = \bigl|G((p_1, 1), \dots, (p_{n+1}, 1))\bigr| - \bigl|G(p_1, \dots, p_{n+1})\bigr|\,,$$

where each $(p_j, 1)$ is the corresponding point $p_j$ supplemented with the coordinate value of 1 for an $(m+1)$-st dimension. Note that in the common case that $n = m$, the second term on the right-hand side will be zero.

:::

## Constructing an orthonormal basis {#Constructing_an_orthonormal_basis}

Given a set of linearly independent vectors $\{v_i\}$ with Gram matrix $G$ defined by $G_{ij}:= \langle v_i,v_j\rangle$, where the [inner product](wikipedia://en/14856) is conjugate linear in the first argument, one can construct an orthonormal basis

$$u_i := \sum_j \bigl(G^{-1/2}\bigr)_{ji} v_j.$$

In matrix notation, $U = V G^{-1/2}$, where $U$ has orthonormal basis vectors $\{u_i\}$ and the matrix $V$ is composed of the given column vectors $\{v_i\}$.

The matrix $G^{-1/2}$ is guaranteed to exist. Indeed, $G$ is Hermitian, and so can be decomposed as $G=UDU^\dagger$ with $U$ a unitary matrix and $D$ a real diagonal matrix. Additionally, the $v_i$ are linearly independent if and only if $G$ is positive definite, which implies that the diagonal entries of $D$ are positive. $G^{-1/2}$ is therefore uniquely defined by $G^{-1/2}:=UD^{-1/2}U^\dagger$. One can check that these new vectors are orthonormal:

$$\begin{aligned} \langle u_i,u_j \rangle &= \sum_{i'} \sum_{j'} \Bigl\langle \bigl(G^{-1/2}\bigr)_{i'i} v_{i'},\bigl(G^{-1/2}\bigr)_{j'j} v_{j'} \Bigr\rangle \\[10mu] &= \sum_{i'} \sum_{j'} \bigl(G^{-1/2}\bigr)_{ii'} G_{i'j'} \bigl(G^{-1/2}\bigr)_{j'j} \\[8mu] &= \bigl(G^{-1/2} G G^{-1/2}\bigr)_{ij} = \delta_{ij} \end{aligned}$$

where we used $\bigl(G^{-1/2}\bigr)^\dagger=G^{-1/2}$.
