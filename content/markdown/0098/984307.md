# Determinant line bundle

::: {#o1 .subject cue=lead name="Determinant line bundle"}

In [differential geometry](wikipedia://en/8625), the **determinant line bundle** is a construction, which assigns every [vector bundle](wikipedia://en/276524) over [paracompact spaces](wikipedia://en/48631) a [line bundle](wikipedia://en/361366). Its name comes from using the [determinant](wikipedia://en/8468) on their [classifying spaces](wikipedia://en/923556). Determinant line bundles naturally arise in four-dimensional [spin<sup>c</sup> structures](wikipedia://en/79367906) and are therefore of central importance for [Seiberg–Witten theory](wikipedia://en/3526032).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [paracompact space](wikipedia://en/48631), then there is a [bijection](wikipedia://en/3942) $[X,\operatorname{BO}(n)]\xrightarrow\cong\operatorname{Vect}_\mathbb{R}^n(X),[f]\mapsto f^*\gamma_\mathbb{R}^n$ with the real [universal vector bundle](https://en.wikipedia.org/wiki/Universal_vector_bundle) $\gamma_\mathbb{R}^n$.[^o4] The real determinant $\det\colon \operatorname{O}(n)\rightarrow\operatorname{O}(1)$ is a [group homomorphism](wikipedia://en/12396) and hence induces a [continuous map](https://en.wikipedia.org/wiki/Continuous_map) $\mathcal{B}\det\colon \operatorname{BO}(n)\rightarrow\operatorname{BO}(1)\cong\mathbb{R}P^\infty$ on the [classifying space for O(n)](wikipedia://en/11441746). Hence there is a postcomposition:

$$\det\colon \operatorname{Vect}_\mathbb{R}^n(X) \cong[X,\operatorname{BO}(n)] \xrightarrow{\mathcal{B}\det_*}[X,\operatorname{BO}(1)] \cong\operatorname{Vect}_\mathbb{R}^1(X).$$

Let $X$ be a [paracompact space](wikipedia://en/48631), then there is a [bijection](wikipedia://en/3942) $[X,\operatorname{BU}(n)]\xrightarrow\cong\operatorname{Vect}_\mathbb{C}^n(X),[f]\mapsto f^*\gamma_\mathbb{C}^n$ with the complex universal vector bundle $\gamma_\mathbb{C}^n$.[^o4] The complex determinant $\det\colon \operatorname{U}(n)\rightarrow\operatorname{U}(1)$ is a group homomorphism and hence induces a continuous map $\mathcal{B}\det\colon \operatorname{BU}(n)\rightarrow\operatorname{BU}(1)\cong\mathbb{C}P^\infty$ on the [classifying space for U(n)](wikipedia://en/2819900). Hence there is a postcomposition:

$$\det\colon \operatorname{Vect}_\mathbb{C}^n(X) \cong[X,\operatorname{BU}(n)] \xrightarrow{\mathcal{B}\det_*}[X,\operatorname{BU}(1)] \cong\operatorname{Vect}_\mathbb{C}^1(X).$$

Alternatively, the determinant line bundle can be defined as the last non-trivial exterior product. Let $E\twoheadrightarrow X$ be a vector bundle, then:[^o5]

$$\det(E) :=\Lambda^{\operatorname{rk}(E)}(E).$$

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The real determinant line bundle preserves the first [Stiefel–Whitney class](wikipedia://en/877761), which for real line bundles over [topological spaces](wikipedia://en/30450) with the [homotopy type](https://en.wikipedia.org/wiki/Homotopy_type) of a [CW complex](wikipedia://en/353022) is a [group isomorphism](wikipedia://en/12397).[^o8] Since in this case the first Stiefel–Whitney class vanishes if and only if a real line bundle is orientable,[^o9] both conditions are then equivalent to a trivial determinant line bundle.[^o10]
- The complex determinant line bundle preserves the first [Chern class](wikipedia://en/294349), which for complex line bundles over topological spaces with the homotopy type of a CW complex is a group isomorphism.[^o8]
- The pullback bundle commutes with the determinant line bundle. For a continuous map $f\colon X\rightarrow Y$ between paracompact spaces $X$ and $Y$ as well as a vector bundle $E\twoheadrightarrow Y$, one has:

$$\det(f^*E) \cong f^*\det(E).$$

Proof: Assume $E\twoheadrightarrow Y$ is a real vector bundle and let $g\colon Y\rightarrow\operatorname{BO}(n)$ be its classifying map with $E=g^*\gamma_\mathbb{R}^n$, then:

$$\det(f^*E) \cong\det(f^*g^*\gamma_\mathbb{R}^n) \cong\det((g\circ f)^*\gamma_\mathbb{R}^n) \cong(\mathcal{B}\det\circ g\circ f)^*\gamma_\mathbb{R}^1 \cong f^*(\mathcal{B}\det\circ g)^*\gamma_\mathbb{R}^1 \cong f^*\det(g^*\gamma_\mathbb{R}^n) \cong f^*\det(E).$$

For complex vector bundles, the proof is completely analogous.

- For vector bundles $E,F\twoheadrightarrow X$ (with the same fields as fibers), one has:

$$\det(E\otimes F) \cong\det(E)^{\operatorname{rk}(F)}\otimes\det(F)^{\operatorname{rk}(E)}.$$

:::
