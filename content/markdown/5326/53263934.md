# StatCrunch

::: {#o2 .subject cue=lead name="StatCrunch"}

**StatCrunch** is a [web-based](https://en.wikipedia.org/wiki/Web_application) [statistical software](https://en.wikipedia.org/wiki/Statistical_software) application from [Pearson Education](https://en.wikipedia.org/wiki/Pearson_Education). StatCrunch was originally created for use in college [statistics](wikipedia://en/26685) courses. As a full-featured statistics package, it is now also used for research and for other statistical analysis purposes.

:::

## History {#History}

American statistics professor Webster West created StatCrunch in 1997. Over the next 19 years West[^o4] assisted by others added many more statistical procedures and graphing capabilities, and made user interface improvements.

In 2005, West received two awards[^o4] for StatCrunch: the CAUSEweb Resource of the Year Award and the MERLOT Classics Award.[^o8] In 2013, the StatCrunch [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) code was rewritten in [JavaScript](https://en.wikipedia.org/wiki/JavaScript) in order to avoid Java browser security problems, and so that it would run on [iOS](https://en.wikipedia.org/wiki/IOS) and [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29). In 2015, new ways of importing data were added, including importing multi-page data directly from Wikipedia tables and other Web sources, and also importing with [drag-and-drop](https://en.wikipedia.org/wiki/Drag-and-drop) for various data formats.[^o5]

In 2016, StatCrunch was acquired by [Pearson Education](https://en.wikipedia.org/wiki/Pearson_Education),[^o6] which had already been serving as the primary distributor of StatCrunch for several years.

## Software {#Software}

A StatCrunch license is included with many of Pearson's statistical textbooks. Because StatCrunch is a [web application](https://en.wikipedia.org/wiki/Web_application), it works on multiple platforms, including [Windows](https://en.wikipedia.org/wiki/Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), iOS, and [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29).[^o8]

Data in StatCrunch is represented in a "data table" view, which is similar to a [spreadsheet](https://en.wikipedia.org/wiki/Spreadsheet) view, but unlike spreadsheets, the cells in a data table can only contain numbers or text. Formulas cannot be stored in these cells. There are many ways to import data into StatCrunch.[^o9] Data can be typed directly into cells in the data table. Entire blocks of data may be cut-and-pasted into the data table. Text files (.csv, .txt, etc.) and [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel) files (.xls and .xlsx) can be drag-and-dropped into the data table. Data can be pulled into StatCrunch directly from [Wikipedia](https://en.wikipedia.org/wiki/Wikipedia) tables or other Web tables, including multi-page tables. Data can be loaded directly from [Google Drive](https://en.wikipedia.org/wiki/Google_Drive) and [Dropbox](https://en.wikipedia.org/wiki/Dropbox). Shared data sets saved by other StatCrunch community users can be searched for by title or keyword and opened in a data table.

Graphs, results, and reports created by StatCrunch can be shared with other users, in addition to the sharing of data sets.[^o10] StatCrunch has a library of data transformation functions. StatCrunch can also recode and reorganize data. All data is stored in memory, and all processing happens on the client, so response is fast, even with large data sets.

StatCrunch can interact with multiple graphs simultaneously. If a user selects a data point on one graph, then that same data point is highlighted on all other displayed graphs.[^o11]

In addition to standard statistical and graphing procedures, StatCrunch has a collection of about forty "applets" which illustrate statistical concepts interactively.[^o5]
