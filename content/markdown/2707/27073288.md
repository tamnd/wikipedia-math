# Dini continuity

::: {#o1 .subject cue=lead name="Dini continuity"}

In [mathematical analysis](wikipedia://en/48396), **Dini continuity** is a refinement of [continuity](wikipedia://en/6122). Every Dini continuous function is continuous. Every [Lipschitz continuous](https://en.wikipedia.org/wiki/Lipschitz_continuous) function and every [Hölder continuous](wikipedia://en/4005892) function is Dini continuous.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [compact](wikipedia://en/6042) subset of a metric space (such as $\mathbb{R}^n$), and let $f:X\rightarrow X$ be a function from $X$ into itself. The [modulus of continuity](wikipedia://en/964161) of $f$ is

$$\omega_f(t) = \sup_{d(x,y)\le t} d(f(x),f(y)).$$

The function $f$ is called **Dini-continuous** if

$$\int_0^1 \frac{\omega_f(t)}{t}\,dt < \infty.$$

An equivalent condition is that, for any $\theta \in (0,1)$,

$$\sum_{i=1}^\infty \omega_f(\theta^i a) < \infty$$

where $a$ is the [diameter](wikipedia://en/20018#Bounded_and_totally_bounded_spaces) of $X$.
