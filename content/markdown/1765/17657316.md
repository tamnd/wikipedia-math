# StatPlus

::: {#o1 .subject cue=lead name="StatPlus"}

**StatPlus** is a [software](https://en.wikipedia.org/wiki/Software) product developed by AnalystSoft for basic univariate and multivariate [statistical analysis](https://en.wikipedia.org/wiki/Statistical_analysis) ([MANOVA](https://en.wikipedia.org/wiki/MANOVA), [GLM](wikipedia://en/877698), [Latin squares](wikipedia://en/37447)), as well as [time series](wikipedia://en/406624) analysis, [nonparametric statistics](wikipedia://en/223369), [survival analysis](wikipedia://en/419259) and statistical charts including [control charts](wikipedia://en/435754). It was originally developed for use in [biomedical sciences](https://en.wikipedia.org/wiki/Biomedical_science) and known as BioStat. It is nowadays mostly used in biomedicine and [natural sciences](https://en.wikipedia.org/wiki/Natural_science).

:::

The software has a version for the [Mac OS X](https://en.wikipedia.org/wiki/Mac_OS_X) known as StatPlus:mac.[^o2] This version may also be used as an add-on (software) to [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), similar to Microsoft's Analysis Toolpak on Windows.[^o3]
