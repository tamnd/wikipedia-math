# Weakly contractible space

::: {#o1 .subject cue=lead name="Weakly contractible space"}

In [mathematics](wikipedia://en/18831), a [topological space](wikipedia://en/30450) is said to be **weakly contractible** if all of its [homotopy groups](wikipedia://en/297506) are trivial. Equivalently, a space is weakly contractible if it is [weakly homotopy equivalent](wikipedia://en/34615176) to a point.

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every [contractible](https://en.wikipedia.org/wiki/Contractible) space is weakly contractible; conversely, it follows from [Whitehead's theorem](wikipedia://en/976793) that every weakly contractible [CW-complex](https://en.wikipedia.org/wiki/CW-complex) is contractible. For general topological spaces only the former implication holds.

Every weakly contractible space is in particular [path-connected](https://en.wikipedia.org/wiki/Path-connected), [simply connected](https://en.wikipedia.org/wiki/Simply_connected) and [aspherical](wikipedia://en/7147287).

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Define $S^\infty$ to be the [inductive limit](https://en.wikipedia.org/wiki/Inductive_limit) of the spheres $S^n, n\ge 1$. Then this space is weakly contractible. Since $S^\infty$ is moreover a CW-complex, it is also contractible. See [Contractibility of unit sphere in Hilbert space](https://en.wikipedia.org/wiki/Contractibility_of_unit_sphere_in_Hilbert_space) for more.

The [long line](wikipedia://en/338403) is an example of a space which is weakly contractible, but not contractible. This does not contradict Whitehead's theorem since the long line does not have the homotopy type of a CW-complex. Another prominent example for this phenomenon is the [Warsaw circle](https://en.wikipedia.org/wiki/Warsaw_circle).

:::
