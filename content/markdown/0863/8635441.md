# Ackermann set theory

::: {#o1 .subject cue=lead name="Ackermann set theory"}

In [mathematics](wikipedia://en/18831) and [logic](wikipedia://en/46426065), **Ackermann set theory** (AST, also known as $A^*/V$[^o2]) is an axiomatic [set theory](wikipedia://en/27553) proposed by [Wilhelm Ackermann](wikipedia://en/62727) in 1956.[^o3]

:::

AST differs from [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZF) in that it allows [proper classes](wikipedia://en/20696), that is, objects that are not sets, including a class of all sets. It replaces several of the standard ZF axioms for constructing new sets with a principle known as Ackermann's schema. Intuitively, the schema allows a new set to be constructed if it can be defined by a formula which does not refer to the class of all sets. In its use of classes, AST differs from other alternative set theories such as [Morse–Kelley set theory](wikipedia://en/2693655) and [Von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) in that a class may be an element of another class.

William N. Reinhardt established in 1970 that AST is effectively equivalent in strength to ZF, putting it on equal foundations. In particular, AST is [consistent](wikipedia://en/75802) [if and only if](wikipedia://en/14922) ZF is consistent.

## Preliminaries {#Preliminaries}

AST is formulated in [first-order logic](wikipedia://en/10983). The [language](wikipedia://en/10939) $L_{\{\in,V\}}$ of AST contains one [binary relation](wikipedia://en/3931) $\in$ denoting [set membership](https://en.wikipedia.org/wiki/Set_membership) and one [constant](wikipedia://en/24758132) $V$ denoting the [class of all sets](wikipedia://en/445980). Ackermann used a predicate $M$ instead of $V$; this is equivalent as each of $M$ and $V$ can be defined in terms of the other.[^o5]

We will refer to elements of $V$ as *sets*, and general objects as [classes](wikipedia://en/20696). A class that is not a set is called a proper class.

## Axioms {#Axioms}

The following formulation is due to Reinhardt.[^o8] The five axioms include two [axiom schemas](wikipedia://en/764613). Ackermann's original formulation included only the first four of these, omitting the [axiom of regularity](wikipedia://en/2113).[^o9][^o10][^o11]

::: {#o13 .statement kind=statement/axiom cue=named-heading name="1. Axiom of extensionality"}

### \1. Axiom of extensionality {#1._Axiom_of_extensionality}

If two classes have the same elements, then they are equal.

$$\forall x \; (x \in A \leftrightarrow x \in B) \to A = B.$$

This axiom is identical to the [axiom of extensionality](wikipedia://en/52376) found in many other set theories, including ZF.

:::

### \2. Heredity {#2._Heredity}

Any element or a subset of a set is a set.

$$(x \in y \lor x \subseteq y) \land y \in V \to x \in V.$$

### \3. Comprehension schema {#3._Comprehension_schema}

For any property, we can form the class of sets satisfying that property. Formally, for any formula $\phi$ where $X$ is not [free](https://en.wikipedia.org/wiki/Free_variable):

$$\exists X \; \forall x \; (x \in X \leftrightarrow x \in V \land \phi).$$

That is, the only restriction is that comprehension is restricted to objects in $V$. But the resulting object is not necessarily a set.

### \4. Ackermann's schema {#4._Ackermann's_schema}

For any formula $\phi$ with free variables $a_1, \ldots, a_n, x$ and no occurrences of $V$:

$$a_1, \ldots, a_n \in V \land \forall x \; (\phi \to x \in V) \to \exists X {\in} V \; \forall x \; (x \in X \leftrightarrow \phi).$$

Ackermann's schema is a form of set comprehension that is unique to AST. It allows constructing a new set (not just a class) as long as we can define it by a property that *does not refer* to the symbol $V$. This is the principle that replaces ZF axioms such as pairing, union, and [power set](wikipedia://en/23799).

### \5. Regularity {#5._Regularity}

Any non-empty set contains an element disjoint from itself:

$$\forall x \in V \; (x = \varnothing \lor \exists y (y \in x \land y \cap x = \varnothing)).$$

Here, $y \cap x = \varnothing$ is shorthand for $\not \exists z \; (z \in x \land z \in y)$. This axiom is identical to the [axiom of regularity](wikipedia://en/2113) in ZF.

This axiom is conservative in the sense that without it, we can simply use comprehension (axiom schema 3) to restrict our attention to the subclass of sets that are regular.[^o8]

:::

## Alternative formulations {#Alternative_formulations}

Ackermann's original axioms did not include regularity, and used a predicate symbol $M$ instead of the constant symbol $V$.[^o3] We follow Lévy and Reinhardt in replacing instances of $Mx$ with $x \in V$. This is equivalent because $M$ can be given a definition as $x \in V$, and conversely, the set $V$ can be obtained in Ackermann's original formulation by applying comprehension to the predicate $\phi = \text{True}$.[^o5]

In *axiomatic set theory,* Ralf Schindler replaces Ackermann's schema (axiom schema 4) with the following [reflection principle](wikipedia://en/3225574): for any formula $\phi$ with free variables $a_1, \ldots, a_n$,

$$a_1, \ldots, a_n {\in} V \to (\phi \leftrightarrow \phi^V).$$

Here, $\phi^V$ denotes the *relativization* of $\phi$ to $V$, which replaces all [quantifiers](wikipedia://en/43507260) in $\phi$ of the form $\forall x$ and $\exists x$ by $\forall x {\in} V$ and $\exists x {\in} V$, respectively.[^o19]

## Relation to Zermelo–Fraenkel set theory {#Relation_to_Zermelo–Fraenkel_set_theory}

Let $L_{\{\in\}}$ be the language of formulas that do not mention $V$.

In 1959, [Azriel Lévy](wikipedia://en/18329294) proved that if $\phi$ is a formula of $L_{\{\in\}}$ and AST proves $\phi^V$, then [ZF](wikipedia://en/152214) proves $\phi$.[^o5]

In 1970, William N. Reinhardt proved that if $\phi$ is a formula of $L_{\{\in\}}$ and ZF proves $\phi$, then AST proves $\phi^V$.[^o8]

Therefore, AST and ZF are mutually [interpretable](wikipedia://en/621176) in [conservative extensions](wikipedia://en/1840214) of each other. Thus they are [equiconsistent](wikipedia://en/3435716).

A remarkable feature of AST is that, unlike [NBG](wikipedia://en/528491) and its variants, a proper class can be an element of another proper class.[^o11]

## Extensions {#Extensions}

An extension of AST for [category theory](wikipedia://en/5869) called ARC was developed by F.A. Muller. Muller stated that ARC "founds Cantorian set-theory as well as category-theory and therefore can pass as a founding theory of the whole of mathematics".[^o23]

:::
