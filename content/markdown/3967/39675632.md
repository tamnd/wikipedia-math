# Turning point test

::: {#o1 .subject cue=lead name="Turning point test"}

In [statistical hypothesis testing](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing), a **turning point test** is a statistical test of the independence of a series of random variables.[^o2][^o3][^o4] [Maurice Kendall](wikipedia://en/589136) and Alan Stuart describe the test as "reasonable for a test against cyclicity but poor as a test against trend."[^o8][^o5] The test was first published by [Irénée-Jules Bienaymé](wikipedia://en/16087441) in 1874.[^o8][^o6]

:::

## Statement of test {#Statement_of_test}

The turning point test is a test of the null hypothesis[^o2]

*H*<sub>0</sub>: *X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*n*</sub> are [independent and identically distributed random variables](wikipedia://en/30876902) (iid)

against

*H*<sub>1</sub>: *X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*n*</sub> are not iid.

This test assumes that the *X*<sub>i</sub> have a *continuous* distribution (so adjacent values are almost surely never equal).[^o8]

### Test statistic {#Test_statistic}

We say *i* is a turning point if the vector *X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*i*</sub>, ..., *X*<sub>*n*</sub> is not monotonic at index *i*. The number of turning points is the number of maxima and minima in the series.[^o8]

Letting *T* be the number of turning points, then for large *n*, *T* is approximately [normally distributed](wikipedia://en/21462) with mean (2*n* − 4)/3 and variance (16*n* − 29)/90. The test statistic[^o10]

$$z =\frac{T - \frac{2n-4}{3}}{\sqrt{\frac{16n-29}{90}}}$$

is approximately standard normal for large values of n.

::: {#o12 .application cue=heading name="Applications"}

## Applications {#Applications}

The test can be used to verify the accuracy of a fitted [time series](wikipedia://en/406624) model such as that describing [irrigation](https://en.wikipedia.org/wiki/Irrigation) requirements.[^o13]

:::
