# Dedekind number

::: {#o1 .subject cue=lead name="Dedekind number"}

In [mathematics](wikipedia://en/18831), the **Dedekind numbers** are a rapidly growing [sequence of integers](wikipedia://en/51421) named after [Richard Dedekind](wikipedia://en/23475106), who defined them in 1897.[^n1] The Dedekind number $M(n)$ is the number of [monotone Boolean functions](https://en.wikipedia.org/wiki/Monotone_Boolean_function) of $n$ variables. Equivalently, it is the number of [antichains](wikipedia://en/348973) of subsets of an $n$-element set, the number of elements in a [free distributive lattice](https://en.wikipedia.org/wiki/Free_distributive_lattice) with $n$ generators, and one more than the number of [abstract simplicial complexes](wikipedia://en/723105) on a set with $n$ elements.

:::

Accurate [asymptotic](wikipedia://en/642090) estimates of $M(n)$ and an exact expression as a [summation](wikipedia://en/246160) are known.[^o3] However **Dedekind's problem** of computing the values of $M(n)$ remains difficult: no [closed-form expression](wikipedia://en/585143) for $M(n)$ is known, and exact values of $M(n)$ have been found only for $n\le 9$.[^n2]

::: {#o6 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A [Boolean function](wikipedia://en/753349) is a function that takes as input *n* [Boolean variables](https://en.wikipedia.org/wiki/Boolean_data_type) (that is, values that can be either false or true, or equivalently [binary values](https://en.wikipedia.org/wiki/Bit) that can be either 0 or 1), and produces as output another Boolean variable. It is [monotonic](https://en.wikipedia.org/wiki/Monotonic) if, for every combination of inputs, switching one of the inputs from false to true can only cause the output to switch from false to true and not from true to false. The Dedekind number $M(n)$ is the number of different monotonic Boolean functions on $n$ variables.[^n3]

An [antichain](wikipedia://en/348973) of sets (also known as a [Sperner family](wikipedia://en/748730)) is a family of sets, none of which is contained in any other set. If $V$ is a set of $n$ Boolean variables, an antichain $\mathcal{A}$ of subsets of $V$ defines a monotone Boolean function $f$ on the given variables, where the value of $f$ is true for a given set of inputs if some subset of the true inputs to $f$ belongs to $\mathcal{A}$ and false otherwise. Conversely every monotone Boolean function defines in this way an antichain, of the minimal subsets of Boolean variables that can force the function value to be true. Therefore, the Dedekind number $M(n)$ equals the number of different antichains of subsets of an $n$-element set.[^o8]

A third, equivalent way of describing the same class of objects uses [lattice theory](https://en.wikipedia.org/wiki/Lattice_theory). From any two monotone Boolean functions $f$ and $g$ we can find two other monotone Boolean functions $f\wedge g$ and $f\vee g$, their [logical conjunction](wikipedia://en/18152) and [logical disjunction](wikipedia://en/7962) respectively. The family of all monotone Boolean functions on $n$ inputs, together with these two operations, forms a [distributive lattice](wikipedia://en/310883), the lattice given by [Birkhoff's representation theorem](wikipedia://en/20489385) from the [partially ordered set](wikipedia://en/23572) of subsets of the $n$ variables with set inclusion as the partial order. This construction produces the [free distributive lattice](https://en.wikipedia.org/wiki/Free_distributive_lattice) with $n$ generators.[^o9] Thus, the Dedekind numbers count the elements in free distributive lattices.[^o10]

The Dedekind numbers also count one more than the number of [abstract simplicial complexes](wikipedia://en/723105) on a set with $n$ elements, families of sets with the property that any non-empty subset of a set in the family also belongs to the family. Any antichain (except $\{\emptyset\}$) determines a simplicial complex, the family of subsets of antichain members, and conversely the maximal simplices in a complex form an antichain.[^o11]

:::

## Example {#Example}

For $n=2$, there are six monotonic Boolean functions and six antichains of subsets of the two-element set $\{x,y\}$:

- The function *f*(*x*,*y*) = false that ignores its input values and always returns false corresponds to the [empty antichain](wikipedia://en/9566) Ø.
- The [logical conjunction](wikipedia://en/18152) *f*(*x*,*y*) = *x* ∧ *y* corresponds to the antichain { {*x*,*y*} } containing the single set {*x*,*y*}.
- The function *f*(*x*,*y*) = *x* that ignores its second argument and returns the first argument corresponds to the antichain { {*x*} } containing the single set {*x*}
- The function *f*(*x*,*y*) = *y* that ignores its first argument and returns the second argument corresponds to the antichain { {*y*} } containing the single set {*y*}
- The [logical disjunction](wikipedia://en/7962) *f*(*x*,*y*) = *x* ∨ *y* corresponds to the antichain { {*x*}, {*y*} } containing the two sets {*x*} and {*y*}.
- The function *f*(*x*,*y*) = true that ignores its input values and always returns true corresponds to the antichain {Ø} containing only the empty set.[^o14]

:::

## Values {#Values}

The exact values of the Dedekind numbers are known for 0 ≤ *n* ≤ 9:

2, 3, 6, 20, 168, 7581, 7828354, 2414682040998, 56130437228687557907788, 286386577668298411128469151667598498812366 .

The first five of these numbers (i.e., *M*(0) to *M*(4)) are given by (Dedekind 1897).[^n4] *M*(5) was calculated by [Randolph Church](https://en.wikipedia.org/wiki/Randolph_Church) in 1940.[^n5] *M*(6) was calculated by [Morgan Ward](wikipedia://en/28805642) in 1946,[^n6] *M*(7) was calculated by Church in 1965,[^o20] *M*(8) by Doug Wiedemann in 1991,[^n7] and *M*(9) was independently discovered in 2023 by Jäkel[^n8] and Van Hirtum et al.[^n9]

If *n* is even, then *M*(*n*) must also be even.[^o24] The calculation of the fifth Dedekind number *M*(5) = 7581 disproved a conjecture by [Garrett Birkhoff](wikipedia://en/1180916) that *M*(*n*) is always divisible by (2*n* − 1)(2*n* − 2).[^o25]

## Summation formula {#Summation_formula}

(Kisielewicz 1988) rewrote the logical definition of antichains into the following arithmetic formula for the Dedekind numbers:

$$M(n)=\sum_{k=1}^{2^{2^n}} \prod_{j=1}^{2^n-1} \prod_{i=0}^{j-1} \left(1-b_i^k b_j^k\prod_{m=0}^{\log_2 i} (1-b_m^i+b_m^i b_m^j)\right),$$

where $b_i^k$ is the $i$th [bit](https://en.wikipedia.org/wiki/Bit) of the number $k$, which can be written using the [floor function](https://en.wikipedia.org/wiki/Floor_function) as

$$b_i^k=\left\lfloor\frac{k}{2^i}\right\rfloor - 2\left\lfloor\frac{k}{2^{i+1}}\right\rfloor.$$

However, this formula is not helpful for computing the values of *M*(*n*) for large *n* due to the large number of terms in the summation.[^o29]

:::

## Asymptotics {#Asymptotics}

The [logarithm](wikipedia://en/17860) of the Dedekind numbers can be estimated accurately via the bounds

$${n\choose \lfloor n/2\rfloor}\le \log_2 M(n)\le {n\choose \lfloor n/2\rfloor}\left(1+O\left(\frac{\log n}{n}\right)\right).$$

Here the left inequality counts the antichains in which each set has exactly $\lfloor n/2\rfloor$ elements, and the right inequality was proven by (Kleitman Markowsky 1975).

(Korshunov 1981) provided the even more accurate estimates[^o33]

$$M(n) = (1+o(1)) 2^{n\choose \lfloor n/2\rfloor}\exp a(n)$$

for even *n*, and

$$M(n) = (1+o(1)) 2^{{n\choose \lfloor n/2\rfloor} + 1}\exp (b(n)+c(n))$$

for odd *n*, where

$$a(n)={n\choose n/2-1}(2^{-n/2} + n^2 2^{-n-5} - n2^{-n-4}),$$

$$b(n)={n\choose (n-3)/2}(2^{-(n+3)/2} + n^2 2^{-n-6} - n2^{-n-3}),$$

and

$$c(n)={n\choose (n-1)/2}(2^{-(n+1)/2} + n^2 2^{-n-4}).$$

The main idea behind these estimates is that, in most antichains, all the sets have sizes that are very close to *n*/2.[^o33] For *n* = 2, 4, 6, 8 Korshunov's formula provides an estimate that is inaccurate by a factor of 9.8%, 10.2%, 4.1%, and −3.3%, respectively.[^n10]
