# Normal element

::: {#o1 .subject cue=lead name="Normal element"}

In [mathematics](wikipedia://en/18831), an [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of a [\*-algebra](wikipedia://en/293426) is called **normal** if it [commutates](wikipedia://en/294390) with its adjoint.[^n1]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{A}$ be a \*-Algebra. An element $a \in \mathcal{A}$ is called normal if it commutes with $a^*$, i.e. it satisfies the [equation](wikipedia://en/9284) $aa^* = a^*a$.[^n1]

The [set](wikipedia://en/26691) of normal elements is denoted by $\mathcal{A}_N$ or $N(\mathcal{A})$.

A special case of particular importance is the case where $\mathcal{A}$ is a [complete normed \*-algebra](wikipedia://en/4665#Banach_*-algebras), that satisfies the C\*-identity ($\left\| a^*a \right\| = \left\| a \right\|^2 \ \forall a \in \mathcal{A}$), which is called a [C\*-algebra](wikipedia://en/7184).

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [self-adjoint element](https://en.wikipedia.org/wiki/Self-adjoint) of a a \*-algebra is normal.[^n1]
- Every [unitary element](wikipedia://en/20402624) of a a \*-algebra is normal.[^n2]
- If $\mathcal{A}$ is a C\*-Algebra and $a \in \mathcal{A}_N$ a normal element, then for every [continuous function](wikipedia://en/6122) $f$ on the [spectrum](wikipedia://en/4665#Spectral_theory) of $a$ the [continuous functional calculus](wikipedia://en/784808) defines another normal element $f(a)$.[^n3]

:::

## Criteria {#Criteria}

Let $\mathcal{A}$ be a \*-algebra. Then:

- An element $a \in \mathcal{A}$ is normal if and only if the \*-[subalgebra](wikipedia://en/45239) generated by $a$, meaning the smallest \*-algebra containing $a$, is commutative.[^n2]
- Every element $a \in \mathcal{A}$ can be uniquely decomposed into a [real and imaginary part](https://en.wikipedia.org/wiki/Real_and_imaginary_parts), which means there exist self-adjoint elements $a_1,a_2 \in \mathcal{A}_{sa}$, such that $a = a_1 + \mathrm{i} a_2$, where $\mathrm{i}$ denotes the [imaginary unit](wikipedia://en/52358). Exactly then $a$ is normal if $a_1 a_2 = a_2 a_1$, i.e. real and imaginary part commutate.[^n1]

::: {#o15 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### In \*-algebras {#In_*-algebras}

Let $a \in \mathcal{A}_N$ be a normal element of a \*-algebra $\mathcal{A}$. Then:

- The adjoint element $a^*$ is also normal, since $a = (a^*)^*$ holds for the [involution](wikipedia://en/293450) \*.[^n4]

### In C\*-algebras {#In_C*-algebras}

Let $a \in \mathcal{A}_N$ be a normal element of a C\*-algebra $\mathcal{A}$. Then:

- It is $\left\| a^2 \right\| = \left\| a \right\|^2$, since for normal elements using the C\*-identity $\left\| a^2 \right\|^2 = \left\| (a^2) (a^2)^* \right\| = \left\| (a^*a)^* (a^*a) \right\| = \left\| a^*a \right\|^2 = \left( \left\| a \right\|^2 \right)^2$ holds.[^n5]
- Every normal element is a normaloid element, i.e. the [spectral radius](wikipedia://en/386169) $r(a)$ equals the norm of $a$, i.e. $r(a)= \left\| a \right\|$.[^n6] This follows from the [spectral radius formula](wikipedia://en/386169#Gelfand's_formula) by repeated application of the previous property.[^n7]
- A continuous functional calculus can be developed which – put simply – allows the application of continuous functions on the spectrum of $a$ to $a$.[^n3]

:::
