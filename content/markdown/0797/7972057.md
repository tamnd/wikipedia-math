# MESH (cipher)

::: {#o2 .subject cue=lead name="MESH"}

In cryptography, **MESH** is a [block cipher](wikipedia://en/4594) designed in 2002 by [Jorge Nakahara, Jr.](https://en.wikipedia.org/wiki/Jorge_Nakahara,_Jr.), [Vincent Rijmen](https://en.wikipedia.org/wiki/Vincent_Rijmen), [Bart Preneel](wikipedia://en/1520490), and [Joos Vandewalle](https://en.wikipedia.org/wiki/Joos_Vandewalle). MESH is based directly on [IDEA](wikipedia://en/15076) and uses the same basic operations.

:::

MESH is actually a family of 3 variant ciphers with [block sizes](wikipedia://en/294065) of 64, 96, and 128 bits.[^o3] The [key size](wikipedia://en/5749) is twice the block size. The number of rounds is 8.5, 10.5, or 12.5, depending on the block size. The algorithm uses a [Lai–Massey scheme](https://en.wikipedia.org/wiki/Lai–Massey_scheme) based on IDEA's, but with a larger round structure, or "MA-box". MESH also has a more complex [key schedule](wikipedia://en/609603) than IDEA, intended to prevent [weak keys](wikipedia://en/719388) and other insecure patterns in subkeys.
