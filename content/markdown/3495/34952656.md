# Extension neglect

::: {#o1 .subject cue=lead name="Extension neglect"}

**Extension neglect** is a type of [cognitive bias](https://en.wikipedia.org/wiki/Cognitive_bias) which occurs when the [sample size](https://en.wikipedia.org/wiki/Sample_size) is ignored when its [determination](wikipedia://en/1776839) is relevant.[^o2] For instance, when reading an article about a scientific study, extension neglect occurs when the reader ignores the number of people involved in the study (sample size) but still makes inferences about a population based on the sample. In reality, if the sample size is too small, the results might risk errors in [statistical hypothesis testing](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing). A study based on only a few people may draw invalid conclusions because only one person has exceptionally high or low scores ([outlier](wikipedia://en/160951)), and there are not enough people there to correct this via averaging out. But often, the sample size is not prominently displayed in science articles, and the reader in this case might still believe the article's conclusion due to extension neglect.

:::

Extension neglect is described as being caused by judgment by prototype, of which the [representativeness heuristic](https://en.wikipedia.org/wiki/Representativeness_heuristic) is a special case.

Forms of extension neglect include:

- [base rate neglect](https://en.wikipedia.org/wiki/Base_rate_neglect)
- [insensitivity to sample size](https://en.wikipedia.org/wiki/Insensitivity_to_sample_size)
- [scope neglect](https://en.wikipedia.org/wiki/Scope_neglect)
- [duration neglect](https://en.wikipedia.org/wiki/Duration_neglect)
  - the [peak–end rule](https://en.wikipedia.org/wiki/Peak–end_rule)
- the [conjunction fallacy](wikipedia://en/732729)
- the [less-is-better effect](https://en.wikipedia.org/wiki/Less-is-better_effect)

The extension effect is "neither universal nor absolute". If attention is drawn to set size in an easily interpretable way, an **additive extension effect** is reported, according to which the valuation of a set is a function of the valuation of a prototypical member of the set *added* to set size, rather than *multiplied*.[^o2]
