# Baer group

::: {#o1 .subject cue=lead name="Baer group"}

In [mathematics](wikipedia://en/18831), a **Baer group** is a [group](wikipedia://en/19447) in which every [cyclic](wikipedia://en/52327) [subgroup](wikipedia://en/28011) is [subnormal](wikipedia://en/2774415). Every Baer group is [locally nilpotent](wikipedia://en/3100179).[^o2]

:::

Baer groups are named after [Reinhold Baer](wikipedia://en/1612114).
