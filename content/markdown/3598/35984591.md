# Seminormal ring

::: {#o1 .subject cue=lead name="Seminormal ring"}

In [algebra](wikipedia://en/18716923), a **seminormal ring** is a [commutative](wikipedia://en/61346) [reduced ring](wikipedia://en/539749) in which, whenever *x*, *y* satisfy $x^3 = y^2$, there is *s* with $s^2 = x$ and $s^3 = y$. This definition was given by (Swan 1980) as a simplification of the original definition of (Traverso 1970).

:::

A basic example is an [integrally closed domain](wikipedia://en/21420209), i.e., a normal ring. For an example which is not normal, one can consider the non-[integral ring](https://en.wikipedia.org/wiki/Integral_ring) $\mathbb{Z}[x, y]/xy$, or the ring of a [nodal](https://en.wikipedia.org/wiki/Node_%28singularity%29) curve.

In general, a [reduced scheme](https://en.wikipedia.org/wiki/Reduced_scheme) $X$ can be said to be **seminormal** if every [morphism](wikipedia://en/7482797) $Y \to X$ which induces a [homeomorphism](wikipedia://en/13660) of [topological spaces](wikipedia://en/30450), and an isomorphism on all [residue fields](wikipedia://en/10789680), is an isomorphism of schemes.

A [semigroup](wikipedia://en/27799) is said to be **seminormal** if its semigroup algebra is seminormal.
