# Almost commutative ring

::: {#o1 .subject cue=lead name="Almost commutative ring"}

In [algebra](wikipedia://en/18716923), a [filtered ring](https://en.wikipedia.org/wiki/Filtered_ring) *A* is said to be **almost commutative** if the associated [graded ring](wikipedia://en/103094) $\operatorname{gr}A = \oplus A_i/{A_{i-1}}$ is [commutative](wikipedia://en/61346).

:::

Basic examples of almost commutative rings involve [differential operators](wikipedia://en/263886). For example, the enveloping algebra of a complex [Lie algebra](wikipedia://en/17944) is almost commutative by the [PBW theorem](https://en.wikipedia.org/wiki/PBW_theorem). Similarly, a [Weyl algebra](wikipedia://en/491095) is almost commutative.
