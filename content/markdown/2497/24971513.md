# Maximal common divisor

::: {#o1 .subject cue=lead name="Maximal common divisor"}

In [abstract algebra](wikipedia://en/19616384), particularly [ring theory](wikipedia://en/250424), **maximal common divisors** are an abstraction of the [number theory](wikipedia://en/21527) concept of [greatest common divisor](wikipedia://en/12354) (GCD). This definition is slightly more general than GCDs, and may exist in rings in which GCDs do not. Halter-Koch (1998) provides the following definition.[^o2]

:::

$d\in H$ is a maximal common divisor of a subset, $B\subset H$ , if the following criteria are met:

1. $d|b$ for all $b\in B$
1. Suppose $c\in H$, $d|c$ and $c|b$ for all $b\in B$. Then $c \simeq d$.
