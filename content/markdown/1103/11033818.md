# Danskin's theorem

::: {#o1 .subject cue=lead name="Danskin's theorem"}

In [convex analysis](wikipedia://en/3237201), **Danskin's theorem** is a [theorem](wikipedia://en/30977) which provides information about the [derivatives](wikipedia://en/7921) of a [function](wikipedia://en/185427) of the form

$$f(x) = \max_{z \in Z} \phi(x,z).$$

:::

The theorem has applications in [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29), where it sometimes is used to solve [minimax](wikipedia://en/19589) problems. The original theorem given by J. M. Danskin in his 1967 monograph [^o2] provides a formula for the directional derivative of the maximum of a (not necessarily convex) directionally differentiable function.

An extension to more general conditions was proven 1971 by [Dimitri Bertsekas](wikipedia://en/23889091).

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

The following version is proven in "Nonlinear programming" (1991).[^o5] Suppose $\phi(x,z)$ is a [continuous function](wikipedia://en/6122) of two arguments,

$$\phi : \mathbb{R}^n \times Z \to \mathbb{R}$$

where $Z \subset \mathbb{R}^m$ is a [compact set](https://en.wikipedia.org/wiki/Compact_set).

Under these conditions, Danskin's theorem provides conclusions regarding the convexity and [differentiability](https://en.wikipedia.org/wiki/Differentiability) of the function

$$f(x) = \max_{z \in Z} \phi(x,z).$$

To state these results, we define the set of maximizing points $Z_0(x)$ as

$$Z_0(x) = \arg\max_{z\in Z} \phi(x,z) = \left\{\overline{z} : \phi(x,\overline{z}) = \max_{z \in Z} \phi(x,z)\right\}.$$

Danskin's theorem then provides the following results.

### Convexity {#Convexity}

If $\phi(x,z)$ is convex in $x$ for every $z \in Z$, then $f(x)$ is [convex](wikipedia://en/245568) in *$x$* (this extends the known fact that the maximum of finitely many convex functions is convex).

### Derivative {#Derivative}

If $Z_0(x)$ consists of a single element $\overline{z}$, then $f(x)$ is [differentiable](wikipedia://en/330206) at $x$, and its [derivative](wikipedia://en/7921) (or [gradient](wikipedia://en/12461) if $x$ is a vector) equals the derivative of $\phi(x,z)$ at the unique arg-max:

$$\frac{\partial f}{\partial x} = \frac{\partial \phi(x,\overline{z})}{\partial x}.$$

### Directional semi-derivative {#Directional_semi-derivative}

If $Z_0(x)$ contains more than one element, then $f(x)$ is not differentiable at $x$, but it has a [semi-differential](wikipedia://en/3084709). The semi-differential of $f(x)$ in the direction $y$, denoted $\partial_y\ f(x),$ is the maximum of different derivatives over all *z*:

$$\partial_y f(x) = \max_{z \in Z_0(x)} \phi'(x,z;y),$$

where $\phi'(x,z;y)$ is the directional derivative of the function $\phi(\cdot,z)$ at $x$ in the direction $y.$

#### Example of no [directional derivative](wikipedia://en/487859) {#Example_of_no_directional_derivative}

In the statement of Danskin, it is important to conclude semi-differentiability of $f$ and not directional-derivative as explains this simple example. Set $Z=\{-1,+1\},\ \phi(x,z)= zx$, we get $f(x)=|x|$ which is semi-differentiable with $\partial_-f(0)=-1, \partial_+f(0)=+1$ but has not a directional derivative at $x=0$.

### Subdifferential {#Subdifferential}

If $\phi(x,z)$ is differentiable with respect to $x$ for all $z \in Z,$ and if $\partial \phi/\partial x$ is continuous with respect to $z$ for all $x$, then the [subdifferential](https://en.wikipedia.org/wiki/Subdifferential) of $f(x)$ is given by

$$\partial f(x) = \mathrm{conv} \left\{\frac{\partial \phi(x,z)}{\partial x} : z \in Z_0(x)\right\}$$

where $\mathrm{conv}$ indicates the [convex hull](wikipedia://en/40634) operation.

:::

::: {#o12 .statement kind=statement/generalization cue=heading name="Extension"}

## Extension {#Extension}

The 1971 Ph.D. Thesis by [Dimitri P. Bertsekas](https://en.wikipedia.org/wiki/Dimitri_P._Bertsekas) (Proposition A.22) [^o13] proves a more general result, which does not require that $\phi(\cdot,z)$ is differentiable. Instead it assumes that $\phi(\cdot,z)$ is an extended real-valued closed proper convex function for each $z$ in the compact set $Z,$ that $\operatorname{int}(\operatorname{dom}(f)),$ the interior of the effective domain of $f,$ is nonempty, and that $\phi$ is continuous on the set $\operatorname{int}(\operatorname{dom}(f)) \times Z.$ Then for all $x$ in $\operatorname{int}(\operatorname{dom}(f)),$ the subdifferential of $f$ at $x$ is given by

$$\partial f(x) = \operatorname{conv} \left\{\partial \phi(x,z) : z \in Z_0(x)\right\}$$

where $\partial \phi(x,z)$ is the subdifferential of $\phi(\cdot,z)$ at $x$ for any $z$ in $Z.$

:::
