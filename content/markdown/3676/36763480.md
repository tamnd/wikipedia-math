# Saddle tower

*Image: Saddle Tower Minimal Surfaces.png.* Two periods of a 3-fold saddle tower.

::: {#o1 .subject cue=lead name="Saddle tower"}

In [differential geometry](wikipedia://en/8625), a **saddle tower** is a [minimal surface](wikipedia://en/276734) family generalizing the singly periodic [Scherk's second surface](wikipedia://en/8235776) so that it has *N*-fold (*N* > 2) symmetry around one axis.[^o2][^o3]

:::

These surfaces are the only properly embedded singly periodic minimal surfaces in $\mathbb{R}^3$ with [genus](wikipedia://en/61891) zero and finitely many Scherk-type [ends](wikipedia://en/6862105) in the quotient.[^o4]
