# Eulerian matroid

*Image: Eulerian matroid.svg.* The [graphic matroid](wikipedia://en/745714) of an [Eulerian graph](https://en.wikipedia.org/wiki/Eulerian_graph) (a graph with no vertices of odd degree) is always an **Eulerian matroid** by [Veblen's theorem](wikipedia://en/33868930).[^o6] The **circuits** of a [matroid](wikipedia://en/244321) are the minimal dependent sets (the sets which become independent sets when any element is removed), which here are $\{1, 2, 3\}$ and $\{4, 5, 6\}$ (blue and orange respectively). The matroid is Eulerian because all the elements can be partitioned into disjoint circuits.

::: {#o1 .subject cue=lead name="Eulerian matroid"}

In [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory), an **Eulerian matroid** is a matroid whose elements can be partitioned into a collection of disjoint circuits.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

In a [uniform matroid](wikipedia://en/27967069) $U{}^r_n$, the circuits are the sets of exactly $r+1$ elements. Therefore, a uniform matroid is Eulerian if and only if $r+1$ is a divisor of $n$. For instance, the $n$-point lines $U{}^2_n$ are Eulerian if and only if $n$ is divisible by three.

The [Fano plane](wikipedia://en/390404) has two kinds of circuits: sets of three collinear points, and sets of four points that do not contain any line. The three-point circuits are the [complements](wikipedia://en/54347) of the four-point circuits, so it is possible to partition the seven points of the plane into two circuits, one of each kind. Thus, the Fano plane is also Eulerian.

:::

## Relation to Eulerian graphs {#Relation_to_Eulerian_graphs}

Eulerian matroids were defined by (Welsh 1969) as a generalization of the [Eulerian graphs](https://en.wikipedia.org/wiki/Eulerian_graph), graphs in which every vertex has even degree. By [Veblen's theorem](wikipedia://en/33868930) the edges of every such graph may be partitioned into simple cycles, from which it follows that the [graphic matroids](wikipedia://en/745714) of Eulerian graphs are examples of Eulerian matroids.[^o6]

The definition of an Eulerian graph above allows graphs that are disconnected, so not every such graph has an Euler tour. (Wilde 1975) observes that the graphs that have Euler tours can be characterized in an alternative way that generalizes to matroids: a graph $G$ has an Euler tour if and only if it can be formed from some other graph $H$, and a cycle $C$ in $H$, by [contracting](wikipedia://en/353042) the edges of $H$ that do not belong to $C$. In the contracted graph, $C$ generally stops being a simple cycle and becomes instead an Euler tour. Analogously, Wilde considers the matroids that can be formed from a larger matroid by [contracting](wikipedia://en/36749660) the elements that do not belong to some particular circuit. He shows that this property is trivial for general matroids (it implies only that each element belongs to at least one circuit) but can be used to characterize the Eulerian matroids among the [binary matroids](wikipedia://en/36848165), matroids [representable](wikipedia://en/37165960) over [GF(2)](wikipedia://en/11137263): a binary matroid is Eulerian if and only if it is the contraction of another binary matroid onto a circuit.[^o8]

## Duality with bipartite matroids {#Duality_with_bipartite_matroids}

For [planar graphs](wikipedia://en/24314), the properties of being Eulerian and [bipartite](wikipedia://en/244431) are dual: a planar graph is Eulerian if and only if its [dual graph](wikipedia://en/2536864) is bipartite. As Welsh showed, this duality extends to binary matroids: a binary matroid is Eulerian if and only if its [dual matroid](wikipedia://en/23515837) is a [bipartite matroid](wikipedia://en/36886954), a matroid in which every circuit has an even number of elements.[^o6][^o10]

For matroids that are not binary, the duality between Eulerian and bipartite matroids may break down. For instance, the uniform matroid $U{}^2_6$ is Eulerian but its dual $U{}^4_6$ is not bipartite, as its circuits have size five. The self-dual uniform matroid $U{}^3_6$ is bipartite but not Eulerian.

## Alternative characterizations {#Alternative_characterizations}

Because of the correspondence between Eulerian and bipartite matroids among the binary matroids, the binary matroids that are Eulerian may be characterized in alternative ways. The characterization of (Wilde 1975) is one example; two more are that a binary matroid is Eulerian if and only if every element belongs to an odd number of circuits, if and only if the whole matroid has an odd number of partitions into circuits.[^o13] (Lovász Seress 1993) collect several additional characterizations of Eulerian binary matroids, from which they derive a [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) algorithm for testing whether a binary matroid is Eulerian.[^o15]

## Computational complexity {#Computational_complexity}

Any algorithm that tests whether a given matroid is Eulerian, given access to the matroid via an [independence oracle](wikipedia://en/36878315), must perform an exponential number of oracle queries, and therefore cannot take polynomial time. In particular, it is difficult to distinguish a [uniform matroid](wikipedia://en/27967069) on a set of $2n$ elements, with all cycles of size $n+1$, from a [paving matroid](wikipedia://en/37729421) that differs from the uniform matroid in having two complementary cycles of size $n$. The paving matroid is Eulerian but the uniform matroid is not. Any oracle algorithm, applied to the uniform matroid, must make $\tbinom{2n}{n}/2$ queries, an exponential number, to verify that the input is not instead an instance of the paving matroid.[^o17]

## Eulerian extension {#Eulerian_extension}

If $M$ is a binary matroid that is not Eulerian, then it has a unique **Eulerian extension**, a binary matroid $\bar M$ whose elements are the elements of $M$ together with one additional element $e$, such that the restriction of $\bar M$ to the elements of $M$ is isomorphic to $M$. The dual of $\bar M$ is a bipartite matroid formed from the dual of $M$ by adding $e$ to every odd circuit.[^o19]
