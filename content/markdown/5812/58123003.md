# Sorting number

::: {#o1 .subject cue=lead name="Sorting number"}

In [mathematics](wikipedia://en/18831) and [computer science](https://en.wikipedia.org/wiki/Computer_science), the **sorting numbers** are a sequence of numbers introduced in 1950 by [Hugo Steinhaus](wikipedia://en/71735) for the analysis of [comparison sort](wikipedia://en/3189304) algorithms. These numbers give the [worst-case](https://en.wikipedia.org/wiki/Worst-case_complexity) number of comparisons used by both [binary insertion sort](wikipedia://en/15205) and [merge sort](wikipedia://en/20039). However, there are other [algorithms](https://en.wikipedia.org/wiki/Algorithms) that use fewer comparisons.

:::

It is an example of a [2-regular sequence](wikipedia://en/49645022).

[Asymptotically](wikipedia://en/641995), the value of the $n$th sorting number fluctuates between approximately $n\log_2 n - n$ and $n\log_2 n - 0.915n,$ depending on the ratio between $n$ and the nearest [power of two](wikipedia://en/376948).

## Application to sorting {#Application_to_sorting}

In 1950, [Hugo Steinhaus](wikipedia://en/71735) observed that these numbers count the number of comparisons used by [binary insertion sort](wikipedia://en/15205), and conjectured (incorrectly) that they give the minimum number of comparisons needed to sort $n$ items using any [comparison sort](wikipedia://en/3189304). The conjecture was disproved in 1959 by [L. R. Ford Jr.](wikipedia://en/7183185) and [Selmer M. Johnson](https://en.wikipedia.org/wiki/Selmer_M._Johnson), who found a different sorting algorithm, the Ford–Johnson [merge-insertion sort](https://en.wikipedia.org/wiki/Merge-insertion_sort), using fewer comparisons.

The same sequence of sorting numbers also gives the [worst-case](https://en.wikipedia.org/wiki/Worst-case_complexity) number of comparisons used by [merge sort](wikipedia://en/20039) to sort $n$ items.

## Other applications {#Other_applications}

The sorting numbers (shifted by one position) also give the sizes of the shortest possible [superpatterns](wikipedia://en/7371807) for the [layered permutations](wikipedia://en/58109106).
