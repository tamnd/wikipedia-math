# Chetaev instability theorem

::: {#o1 .subject cue=lead name="Chetaev instability theorem"}

The **Chetaev instability theorem** for [dynamical systems](wikipedia://en/9087) states that if there exists, for the system $\dot{\textbf{x}} = X(\textbf{x})$ with an [equilibrium point](https://en.wikipedia.org/wiki/Equilibrium_point) at the origin, a continuously differentiable function V(**x**) such that

:::

1. the origin is a [boundary point](wikipedia://en/72824) of the set $G = \{\mathbf{x} \mid V(\mathbf{x})>0\}$;
1. there exists a [neighborhood](wikipedia://en/1529485) $U$ of the origin such that $\dot{V}(\textbf{x})>0$ for all $\mathbf{x} \in G \cap U$

then the origin is an unstable equilibrium point of the system.

This theorem is somewhat less restrictive than the [Lyapunov instability theorems](https://en.wikipedia.org/wiki/Lyapunov_instability_theorem), since a complete sphere (circle) around the origin for which $V$ and $\dot{V}$ both are of the same sign does not have to be produced.

It is named after [Nicolai Gurevich Chetaev](https://en.wikipedia.org/wiki/Nicolai_Gurevich_Chetaev).

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

Chetaev instability theorem has been used to analyze the unfolding dynamics of proteins under the effect of optical tweezers.[^o4]
