# Order embedding

::: {#o1 .subject cue=lead name="Order embedding"}

*Image: Order embedding.png.* An example of an order embedding. The left ordered set (in red) is embedded into the right ordered set.

In [order theory](wikipedia://en/361924), a branch of [mathematics](wikipedia://en/18831), an **order embedding** is a special kind of [monotone function](https://en.wikipedia.org/wiki/Monotone_function), which provides a way to include one [partially ordered set](wikipedia://en/23572) into another. Like [Galois connections](wikipedia://en/156411), order embeddings constitute a notion which is strictly weaker than the concept of an [order isomorphism](wikipedia://en/23916899). Both of these weakenings may be understood in terms of [category theory](wikipedia://en/5869).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Formally, given two partially ordered sets (posets) $(S, \leq)$ and $(T, \preceq)$, a [function](wikipedia://en/185427) $f: S \to T$ is an *order embedding* if $f$ is both [order-preserving](https://en.wikipedia.org/wiki/Order-preserving) and [order-reflecting](https://en.wikipedia.org/wiki/Order-reflecting), i.e. for all $x$ and $y$ in $S$, one has

$x\leq y \text{ if and only if } f(x)\preceq f(y).$[^o4]

Such a function is necessarily [injective](https://en.wikipedia.org/wiki/Injective), since $f(x) = f(y)$ implies $x \leq y$ and $y \leq x$.[^o4] If an order embedding exists from a poset $S$ to a poset $T$, one says that $S$ can be embedded into $T$.

:::

## Properties {#Properties}

*Image: Mutual embedding of open and closed real unit interval svg.svg.* Mutual order embedding of $(0,1)$ and $[0,1]$, using $f(x) = (94x+3)/100$ in both directions.

*Image: Lattice T(6).svg.* The set $S$ of divisors of 6, partially ordered by *x* divides *y*. The embedding $id: \{ 1,2,3 \} \to S$ cannot be a coretraction.

An order isomorphism can be characterized as a [surjective](https://en.wikipedia.org/wiki/Surjective) order embedding. As a consequence, any order embedding *f* restricts to an isomorphism between its [domain](wikipedia://en/50263) *S* and its [image](wikipedia://en/579311) *f*(*S*), which justifies the term "embedding".[^o4] On the other hand, it might well be that two (necessarily infinite) posets are mutually order-embeddable into each other without being order-isomorphic.

An example is provided by the [open interval](https://en.wikipedia.org/wiki/Open_interval) $(0,1)$ of [real numbers](wikipedia://en/20646438) and the corresponding [closed interval](https://en.wikipedia.org/wiki/Closed_interval) $[0,1]$. The function $f(x) = (94x+3) / 100$ maps the former to the [subset](wikipedia://en/27631) $(0.03,0.97)$ of the latter and the latter to the subset $[0.03,0.97]$ of the former, see picture. Ordering both sets in the natural way, $f$ is both order-preserving and order-reflecting (because it is an [affine function](wikipedia://en/152111)). Yet, no isomorphism between the two posets can exist, since e.g. $[0,1]$ has a [least element](https://en.wikipedia.org/wiki/Least_element) while $(0,1)$ does not. For a similar example using arctan to order-embed the real numbers into an interval, and the [identity map](https://en.wikipedia.org/wiki/Identity_map) for the reverse direction, see e.g. Just and Weese (1996).[^o7]

A retract is a pair $(f,g)$ of order-preserving maps whose [composition](wikipedia://en/195947) $g \circ f$ is the identity. In this case, $f$ is called a coretraction, and must be an order embedding.[^o8] However, not every order embedding is a coretraction. As a trivial example, the unique order embedding $f: \emptyset \to \{1\}$ from the empty poset to a nonempty poset has no retract, because there is no order-preserving map $g: \{1\} \to \emptyset$. More illustratively, consider the set $S$ of [divisors](wikipedia://en/49492) of 6, partially ordered by *x* [divides](https://en.wikipedia.org/wiki/Divides) *y*, see picture. Consider the embedded sub-poset $\{ 1,2,3 \}$. A retract of the embedding $id: \{ 1,2,3 \} \to S$ would need to send $6$ to somewhere in $\{ 1,2,3 \}$ above both $2$ and $3$, but there is no such place.

:::

## Additional perspectives {#Additional_perspectives}

Posets can straightforwardly be viewed from many perspectives, and order embeddings are basic enough that they tend to be visible from everywhere. For example:

- ([Model theoretically](wikipedia://en/19858)) *A* poset is a set equipped with a (reflexive, antisymmetric and transitive) [binary relation](wikipedia://en/3931). An order embedding *A* → *B* is an isomorphism from *A* to an [elementary substructure](https://en.wikipedia.org/wiki/Elementary_substructure) of *B*.
- ([Graph theoretically](wikipedia://en/12401)) *A* poset is a (transitive, acyclic, directed, reflexive) [graph](wikipedia://en/325806). An order embedding *A* → *B* is a [graph isomorphism](wikipedia://en/247577) from *A* to an [induced subgraph](wikipedia://en/1655188) of *B*.
- ([Category theoretically](wikipedia://en/5869)) A poset is a (small, thin, and skeletal) [category](wikipedia://en/53759) such that each [homset](https://en.wikipedia.org/wiki/Hom-set) has at most one element. An order embedding *A* → *B* is a full and faithful [functor](wikipedia://en/10987) from *A* to *B* which is injective on objects, or equivalently an isomorphism from *A* to a [full subcategory](https://en.wikipedia.org/wiki/Full_subcategory) of *B*.
