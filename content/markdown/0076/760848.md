# Hybrid logic

::: {#o1 .subject cue=lead name="Hybrid logic"}

**Hybrid logic** refers to a number of extensions to [propositional](wikipedia://en/18154) [modal logic](wikipedia://en/333365) with more expressive power, though still less than [first-order logic](wikipedia://en/10983). In [formal logic](https://en.wikipedia.org/wiki/Formal_logic), there is a trade-off between expressiveness and [computational tractability](wikipedia://en/6511). The history of hybrid logic began with [Arthur Prior](wikipedia://en/308764)'s work in [tense logic](https://en.wikipedia.org/wiki/Tense_logic).[^o2]

:::

Unlike ordinary modal logic, hybrid logic makes it possible to refer to states (possible worlds) in [formulas](https://en.wikipedia.org/wiki/Formula_%28logic%29).

This is achieved by a class of formulas called *nominals*, which are true in exactly one state, and by the use of the @ operator, which is defined as follows:

*@<sub>i</sub> p* is true [if and only if](https://en.wikipedia.org/wiki/Iff) *p* is true in the unique state named by the nominal *i* (i.e., the state where *i* is true).

Hybrid logics with extra or other operators exist, but @ is more-or-less standard.

Hybrid logics have many features in common with [temporal logics](wikipedia://en/321481) (which sometimes use nominal-like constructs to denote specific points in time), and they are a rich source of ideas for researchers in modern modal logic. They also have applications in the areas of [feature logic](https://en.wikipedia.org/wiki/Feature_logic), [model theory](wikipedia://en/19858), [proof theory](wikipedia://en/183478), and the logical analysis of [natural language](wikipedia://en/21173). Hybrid logic is also closely connected to [description logic](wikipedia://en/183503) because the use of nominals allows one to perform assertional [ABox](https://en.wikipedia.org/wiki/ABox) reasoning, as well as the more standard terminological [TBox](https://en.wikipedia.org/wiki/Abox) reasoning.
