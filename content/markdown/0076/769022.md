# Intermediate logic

::: {#o1 .subject cue=lead name="Intermediate logic"}

In [mathematical logic](wikipedia://en/19636), a **superintuitionistic logic** is a [propositional logic](wikipedia://en/18154) extending [intuitionistic logic](wikipedia://en/169262). A logic is a set of propositional formulas with certain closure properties. The logics are [partially ordered](wikipedia://en/23572) under containment. A logic is stronger than another iff it [contains](wikipedia://en/27631) the other.

:::

[Classical logic](wikipedia://en/55868) is the strongest [consistent](https://en.wikipedia.org/wiki/Consistent) superintuitionistic logic. Thus, the consistent superintuitionistic logics are called **intermediate logics**, because the logics are intermediate in how many formulas they contain between intuitionistic logic and classical logic.[^o2]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **superintuitionistic** logic is a set *L* of propositional formulas in a countable set of variables *p*<sub>*i*</sub> satisfying the following properties:

\1. all [axioms of intuitionistic logic](wikipedia://en/169262#Axiomatization) belong to *L*;

\2. if *F* and *G* are formulas such that *F* and *F* → *G* both belong to *L*, then *G* also belongs to *L* (closure under [modus ponens](wikipedia://en/18900));

\3. if *F*(*p*<sub>1</sub>, *p*<sub>2</sub>, ..., *p*<sub>*n*</sub>) is a formula of *L*, and *G*<sub>1</sub>, *G*<sub>2</sub>, ..., *G*<sub>*n*</sub> are any formulas, then *F*(*G*<sub>1</sub>, *G*<sub>2</sub>, ..., *G*<sub>*n*</sub>) belongs to *L* (closure under substitution).

Such a logic is **intermediate** if furthermore

\4. *L* is not the set of all formulas (i.e. the inconsistent logic).

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

There exists a [continuum](wikipedia://en/1574901) of different intermediate logics.

There exists a continuum of different intermediate logics with the [disjunction property](wikipedia://en/1010522) (DP).

Intermediate logics form a [complete lattice](wikipedia://en/44777), with intuitionistic logic as the [bottom](https://en.wikipedia.org/wiki/Bottom_element) and classical logic as the top. It has a unique [coatom](https://en.wikipedia.org/wiki/Coatom) called **SmL**. Similarly, superintuitionistic logics form a complete lattice, with intuitionistic logic as the bottom and inconsistent logic as the top. Classical logic is the only coatom.

:::

## Syntactics {#Syntactics}

Many intermediate logics are given by adding one or more axioms to intuitionistic logic (usually denoted as intuitionistic propositional calculus **IPC**, but also **Int**, **IL** or **H**). Examples include:

- Classical logic (**CPC**, **Cl**, **CL**):

\= **IPC** + ¬¬*p* → *p* (Double-negation elimination, DNE)

\= **IPC** + (¬*p* → *p*) → *p* ([Consequentia mirabilis](wikipedia://en/7821224))

\= **IPC** + *p* ∨ ¬*p* ([Principle of excluded middle](https://en.wikipedia.org/wiki/Principle_of_excluded_middle), PEM)

Immediate generalized variants of the above (but actually equivalent principles over intuitionistic logic) are, respectively,

\= **IPC** + (¬*p* → ¬*q*) → (*q* → *p*) (inverse [contraposition](wikipedia://en/8556497) principle)

\= **IPC** + ((*p* → *q*) → *p*) → *p* ([Peirce's principle](wikipedia://en/47261948) PP, compare to Consequentia mirabilis)

\= **IPC** + (*q* → *p*) → ((¬*q* → *p*) → *p*) (another schema generalizing Consequentia mirabilis)

\= **IPC** + *p* ∨ (*p* → *q*) (following from PEM via [principle of explosion](wikipedia://en/591394))

\= **IPC** + (*q* → *p*) → (*p* ∨ ¬*q*) (another variant of PEM, see [material implication](wikipedia://en/244516#The_equivalence_does_not_hold_in_intuitionistic_logic))

- Smetanich's logic (**SmL**):

\= **IPC** + (¬*q* → *p*) → (((*p* → *q*) → *p*) → *p*) (a conditional PP)

- [Gödel-Dummett logic](wikipedia://en/43269014) ([Dummett](https://en.wikipedia.org/wiki/Michael_Dummett) 1959) (**LC** or **G**, see extensions below):

\= **IPC** + (*p* → *q*) ∨ (*q* → *p*) (Dirk Gently’s principle, DGP, or linearity)

\= **IPC** + (*p* → (*q* ∨ *r*)) → ((*p* → *q*) ∨ (*p* → *r*)) (a form of [independence of premise](wikipedia://en/22833480) IP)

\= **IPC** + ((*p* ∧ *q*) → *r*) → ((*p* → *r*) ∨ (*q* → *r*)) (Generalized 4th [De Morgan's law](wikipedia://en/64669#In_intuitionistic_logic))

- Bounded depth 2 (**BD**<sub>*2*</sub>, see generalizations below. Compare with *p* ∨ (*p* → *q*)):

\= **IPC** + *p* ∨ (*p* → (*q* ∨ ¬*q*))

- [Jankov](https://en.wikipedia.org/wiki/V._A._Jankov)'s logic (1968)[^n1] or [De Morgan](wikipedia://en/18949289) logic (**KC**):

\= **IPC** + ¬¬*p* ∨ ¬*p* (weak PEM, a.k.a. WPEM)

\= **IPC** + (*p* → *q*) ∨ (¬*p* → ¬*q*) (a weak DGP)

\= **IPC** + (*p* → (*q* ∨ ¬*r*)) → ((*p* → *q*) ∨ (*p* → ¬*r*)) (a variant, with negation, of a form of IP)

\= **IPC** + ¬(*p* ∧ *q*) → (¬*q* ∨ ¬*p*) (4th [De Morgan's law](wikipedia://en/64669#In_intuitionistic_logic))

\= **IPC** + ¬¬(*p* ∨ *q*) → (¬¬*p* ∨ ¬¬*q*) (a form of double-negation shift)

- [Scott](wikipedia://en/161875)'s logic (**SL**):

\= **IPC** + ((¬¬*p* → *p*) → (*p* ∨ ¬*p*)) → (¬¬*p* ∨ ¬*p*) (a conditional WPEM)

- [Kreisel](wikipedia://en/11761785)–[Putnam](wikipedia://en/75233) logic (**KP**):

\= **IPC** + (¬*p* → (*q* ∨ *r*)) → ((¬*p* → *q*) ∨ (¬*p* → *r*)) (the other variant, with negation, of a form of IP)

This list is, for the most part, not any sort of ordering. For example, **LC** is known not to prove all theorems of **SmL**, but it does not directly compare in strength to **BD**<sub>*2*</sub>. Likewise, e.g., **KP** does not compare to **SL**. The list of equalities for each logic is by no means exhaustive either. For example, as with WPEM and De Morgan's law, several forms of DGP using conjunction may be expressed.

Even (¬¬*p* ∨ ¬*p*) ∨ (¬¬*p* → *p*), a further weakening of WPEM, is not a theorem of **IPC**.

It may also be worth noting that, taking all of intuitionistic logic for granted, the equalities notably rely on explosion. For example, over mere [minimal logic](wikipedia://en/26267678), as principle PEM is already equivalent to Consequentia mirabilis, but there does not imply the stronger DNE, nor PP, and is not comparable to DGP.

Going on:

- logics of bounded depth (**BD**<sub>*n*</sub>):

**IPC** + *p<sub>n</sub>* ∨ (*p<sub>n</sub>* → (*p*<sub>*n*−1</sub> ∨ (*p*<sub>*n*−1</sub> → ... → (*p*<sub>2</sub> ∨ (*p*<sub>2</sub> → (*p*<sub>1</sub> ∨ ¬*p*<sub>1</sub>)))...)))

- [Gödel](wikipedia://en/16736) *n*-valued logics (**G**<sub>*n*</sub>):

**LC** + **BD**<sub>*n*−1</sub>

\= **LC** + **BC**<sub>*n*−1</sub>

- logics of bounded cardinality (**BC**<sub>*n*</sub>):

$$\textstyle\mathbf{IPC}+\bigvee_{i=0}^n\bigl(\bigwedge_{j<i}p_j\to p_i\bigr)$$

- logics of bounded top width (**BTW**<sub>*n*</sub>):

$$\textstyle\mathbf{IPC}+\bigvee_{i=0}^n\bigl(\bigwedge_{j<i}p_j\to\neg\neg p_i\bigr)$$

- logics of bounded width, also known as the logic of bounded anti-chains, Ono (1972) (**BW**<sub>*n*</sub>, **BA**<sub>*n*</sub>):

$$\textstyle\mathbf{IPC}+\bigvee_{i=0}^n\bigl(\bigwedge_{j\ne i}p_j\to p_i\bigr)$$

- logics of bounded branching (Gabbay & de Jongh, 1974[^n2]) (**T**<sub>*n*</sub>, **BB**<sub>*n*</sub>):

$$\textstyle\mathbf{IPC}+\bigwedge_{i=0}^n\bigl(\bigl(p_i\to\bigvee_{j\ne i}p_j\bigr)\to\bigvee_{j\ne i}p_j\bigr)\to\bigvee_{i=0}^np_i$$

Furthermore:

- [Realizability](wikipedia://en/11009758) logics
- [Medvedev](https://en.wikipedia.org/wiki/Yuri_T._Medvedev)'s logic of finite problems (**LM**, **ML**):[^n3][^n4][^n5] defined semantically as the logic of all [frames](wikipedia://en/911960) of the form $\langle\mathcal P(X)\setminus\{X\},\subseteq\rangle$ for [finite sets](wikipedia://en/11742) *X* ("Boolean hypercubes without top"), not known to be recursively axiomatizable
- ...

The propositional logics **SL** and **KP** do have the disjunction property DP. Kleene realizability logic and the strong Medvedev's logic do have it as well. There is no unique maximal logic with DP on the lattice. Note that if a consistent theory validates WPEM but still has independent statements when assuming PEM, then it cannot have DP.

## Semantics {#Semantics}

[Kripke semantics](wikipedia://en/911960) is used to semantically study intuitionistic logic. Similarly, other intermediate logics can be studied by semantic models. For example, [Gödel–Dummett logic](https://en.wikipedia.org/wiki/Gödel–Dummett_logic) has a simple semantic characterization in terms of [total orders](wikipedia://en/30330).

Given a [Heyting algebra](wikipedia://en/309343) *H*, the set of [propositional formulas](wikipedia://en/1557634) that are valid in *H* is an intermediate logic. Conversely, given an intermediate logic it is possible to construct its [Lindenbaum–Tarski algebra](wikipedia://en/990343), which is then a Heyting algebra.

An intuitionistic [Kripke frame](https://en.wikipedia.org/wiki/Kripke_frame) *F* is a [partially ordered set](wikipedia://en/23572), and a Kripke model *M* is a Kripke frame with valuation such that $\{x\mid M,x\Vdash p\}$ is an [upper subset](https://en.wikipedia.org/wiki/Upper_set) of *F*. The set of propositional formulas that are valid in *F* is an intermediate logic. Given an intermediate logic *L* it is possible to construct a Kripke model *M* such that the logic of *M* is *L* (this construction is called the *canonical model*). A Kripke frame with this property may not exist, but a [general frame](wikipedia://en/6933049) always does.

## Relation to modal logics {#Relation_to_modal_logics}

Let *A* be a propositional formula. The *Gödel–[Tarski](wikipedia://en/59920) translation* of *A* is defined recursively as follows:

- $$T(p_n) = \Box p_n$$
- $$T(\neg A) = \Box \neg T(A)$$
- $$T(A \land B) = T(A) \land T(B)$$
- $$T(A \vee B) = T(A) \vee T(B)$$
- $$T(A \to B) = \Box (T(A) \to T(B))$$

If *M* is a [modal logic](wikipedia://en/333365) extending **S4** then ρ*M* = {*A* | *T*(*A*) ∈ *M*} is a superintuitionistic logic, and *M* is called a *modal companion* of ρ*M*. In particular:

- **IPC** = ρ**S4**
- **KC** = ρ**S4.2**
- **LC** = ρ**S4.3**
- **CPC** = ρ**S5**

For every intermediate logic *L* there are many modal logics *M* such that *L* = ρ*M*.
