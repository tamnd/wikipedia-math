# Lusternik–Schnirelmann category

::: {#o1 .subject cue=lead name="Lusternik–Schnirelmann category"}

In [mathematics](wikipedia://en/18831), the **Lyusternik–Schnirelmann category** (or, **Lusternik–Schnirelmann category**, **LS-category**) of a [topological space](wikipedia://en/30450) $X$ is the [homotopy invariant](wikipedia://en/212250) defined to be the smallest integer number $k$ such that there is an [open covering](https://en.wikipedia.org/wiki/Open_covering) $\{U_i\}_{1\leq i\leq k}$ of $X$ with the property that each [inclusion map](wikipedia://en/492516) $U_i\hookrightarrow X$ is [nullhomotopic](https://en.wikipedia.org/wiki/Nullhomotopic).

:::

For example, if $X$ is an $n$-sphere, this takes the value $2$. [Lusternik–Schnirelmann theorem](wikipedia://en/46792667) implies that the LS-category of $\mathbb{RP}^n$ is at least $n+1$ (and it is not difficult to show that $n+1$ sets suffice, so the category is exactly $n+1$).

Sometimes a different normalization of the invariant is adopted, which is one less than the definition above. Such a normalization has been adopted in the definitive monograph by Cornea, Lupton, Oprea, and Tanré (see below).

In general it is not easy to compute this invariant, which was initially introduced by [Lazar Lyusternik](wikipedia://en/4201372) and [Lev Schnirelmann](wikipedia://en/747223) in connection with [variational problems](wikipedia://en/171882). It has a close connection with [algebraic topology](wikipedia://en/38801), in particular [cup-length](wikipedia://en/1069723). In the modern normalization, the cup-length is a lower bound for the LS-category.

It was, as originally defined for the case of $X$ a [manifold](wikipedia://en/2073470), the lower bound for the number of [critical points](wikipedia://en/1951424) that a real-valued function on $X$ could possess (this should be compared with the result in [Morse theory](wikipedia://en/348560) that shows that the sum of the Betti numbers is a lower bound for the number of critical points of a Morse function).

The invariant has been generalized in several different directions (group actions, [foliations](wikipedia://en/371227), [simplicial complexes](https://en.wikipedia.org/wiki/Simplicial_complexes), etc.).
