# Disk algebra

::: {#o1 .subject cue=lead name="Disk algebra"}

In mathematics, specifically in [functional](wikipedia://en/11180) and [complex analysis](wikipedia://en/5759), the **disk algebra** *A*(**D**) (also spelled **disc algebra**) is the set of [holomorphic functions](wikipedia://en/14110)

:::

*ƒ* : **D** → $\mathbb{C}$

(where **D** is the [open unit disk](https://en.wikipedia.org/wiki/Open_unit_disk) in the [complex plane](wikipedia://en/217628) $\mathbb{C}$) that extend to a continuous function on the [closure](wikipedia://en/42309) of **D**. That is,

$$A(\mathbf{D}) = H^\infty(\mathbf{D}) \cap C(\overline{\mathbf{D}}),$$

where $H^{\infty}(\mathbf{D})$ denotes the [Banach space](wikipedia://en/3989) of bounded analytic functions on the unit disc **D** (i.e. a [Hardy space](wikipedia://en/314780)).

When endowed with the pointwise addition (*f* + *g*)(*z*) = *f*(*z*) + *g*(*z*) and pointwise multiplication (*fg*)(*z*) = *f*(*z*)*g*(*z*), this set becomes an [algebra](wikipedia://en/191788) over **C**, since if *f* and *g* belong to the disk algebra, then so do *f* + *g* and *fg*.

Given the [uniform norm](wikipedia://en/349755)

$$\|f\| = \sup\big\{|f(z)| \mid z \in \mathbf{D}\big\} = \max\big\{|f(z)| \mid z \in \overline{\mathbf{D}}\big\},$$

by construction, it becomes a [uniform algebra](wikipedia://en/4536974) and a commutative [Banach algebra](wikipedia://en/4665).

By construction, the disc algebra is a closed subalgebra of the [Hardy space](wikipedia://en/314780) [*H*<sup>∞</sup>](https://en.wikipedia.org/wiki/H_infinity). In contrast to the stronger requirement that a continuous extension to the circle exists, it is [a lemma of Fatou](wikipedia://en/10738834) that a general element of *H*<sup>∞</sup> can be radially extended to the circle [almost everywhere](wikipedia://en/44688).
