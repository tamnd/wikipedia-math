# TidyTuesday

::: {#o1 .subject cue=lead name="TidyTuesday"}

*Image: TidyTuesday logo.png.* TidyTuesday logo

**TidyTuesday**, also noted as **Tidy Tuesday**, **tidytuesday**, or **\#tidytuesday**, is a weekly [community of practice](https://en.wikipedia.org/wiki/Community_of_practice) that is currently organized by the Data Science Learning Community (DSLC).[^o2][^o3][^o4] A new data set is highlighted each week for participants to practice [exploring](wikipedia://en/416589), [visualizing](wikipedia://en/3461736), and sharing findings. Participants can follow the daily [hashtag](https://en.wikipedia.org/wiki/Hashtag) #tidytuesday on social media.

:::

## History {#History}

*Image: Graphic Diagrams The Graphic Visualization of Abstract Data - 36020369302.jpg.* Example data visualizations

TidyTuesday was started by Tom Mock, a product manager at [Posit PBC](https://en.wikipedia.org/wiki/Posit_PBC), on April 1, 2018.[^o6] The motivations to create this was for newcomers to data and more experienced data scientists to feel less socially isolated and a means to practice skills like acquiring, cleaning, wrangling, visualizing and presenting data.[^o4] Some participants have shared feeling inspired by others' data visualizations and noting that most people will share their code in order to replicate their work.[^o7]

## Impact {#Impact}

TidyTuesday has also been used by other groups or features published data. [R-Ladies Global](https://en.wikipedia.org/wiki/R-Ladies_Global) have used TidyTuesday datasets as a [hackathon](https://en.wikipedia.org/wiki/Hackathon) to practice data skills.[^o9] In February 2021, Allen Hillery, Athony Starks, and Sekou Tyler, started the #DuboisChallenge. This challenge had participants use modern data visualization tools to recreate the data visualizations by sociologist and activist [W.E.B.Du Bois](https://en.wikipedia.org/wiki/W._E._B._Du_Bois). Then in 2021 and 2022, TidyTuesday highlighted these datasets for the data community.[^o10] In 2021, TidyTuesday featured the zipcodeR dataset that contains 41,000 [ZIP codes](https://en.wikipedia.org/wiki/ZIP_Code) for analysis.[^o11]

*Image: A series of statistical charts illustrating the condition of the descendants of former African slaves now in residence in the United States of America LCCN2014645358.tif.* Data visualization by W.E.B. Du Bois

Educators training [data scientists](https://en.wikipedia.org/wiki/Data_scientists) have struggled to coordinate their preparation, but some have suggested to create a portfolio to have highlight technical skills and [data thinking](https://en.wikipedia.org/wiki/Data_thinking) skills.[^o12] TidyTuesday is one suggested way to find datasets to create a formal, visual project. This can be a means to help teach novice data practitioners on how to better program in programming languages like the [R programming language](wikipedia://en/376707).[^o13]
