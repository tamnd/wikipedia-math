# Locally finite space

::: {#o1 .subject cue=lead name="Locally finite space"}

In the [mathematical](wikipedia://en/18831) field of [topology](wikipedia://en/29954), a **locally finite space** is a [topological space](wikipedia://en/30450) in which every point has a [finite](wikipedia://en/11742) [neighborhood](wikipedia://en/1529485), that is, a neighborhood consisting of finitely many elements.

:::

## Background {#Background}

The conditions for local finiteness were created by [Jun-iti Nagata](wikipedia://en/36481031) and [Yury Smirnov](https://en.wikipedia.org/wiki/Yury_Smirnov) while searching for a stronger version of the [Urysohn metrization theorem](https://en.wikipedia.org/wiki/Urysohn_metrization_theorem). The motivation behind local finiteness was to formulate a new way to determine if a [topological space](wikipedia://en/30450) $X$ is [metrizable](https://en.wikipedia.org/wiki/Metrizable) without the countable basis requirement from Urysohn's theorem.[^o3]

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $T = ( S, \tau )$ be a topological space and let $\mathcal{F}$ be a set of subsets of $S$ Then $\mathcal{F}$ is locally finite [if and only if](wikipedia://en/14922) each element of $S$ has a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) which intersects a finite number of sets in $\mathcal{F}$.[^o6]

A locally finite space is an [Alexandrov](wikipedia://en/542198) space.[^o3]

A [T<sub>1</sub> space](wikipedia://en/148721) is locally finite if and only if it is [discrete](wikipedia://en/56061).[^o7]

:::
