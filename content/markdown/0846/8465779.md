# Craig's theorem

::: {#o1 .subject cue=lead name="Craig's theorem"}

In [mathematical logic](wikipedia://en/19636), **Craig's theorem** (also known as **Craig's trick**) states that any [recursively enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set) of [well-formed formulas](wikipedia://en/404582) of a [first-order language](https://en.wikipedia.org/wiki/First-order_language) is recursively [axiomatizable](https://en.wikipedia.org/wiki/Axiomatization), and even primitively recursively axiomatizable, and even decidable in [polynomial time](wikipedia://en/405944).

:::

This result is not related to the well-known [Craig interpolation](wikipedia://en/2056790) theorem, although both results are named after the same logician, [William Craig](wikipedia://en/11715384).

## Recursive axiomatization {#Recursive_axiomatization}

Let $A_1,A_2,\dots$ be an enumeration of the axioms of a recursively enumerable set $T$ of first-order formulas. Construct another set $T^*$ consisting of

$$\underbrace{A_i\land\dots\land A_i}_i$$

for each positive [integer](wikipedia://en/14563) $i$. That is,

$$T^* = \{ A_1, A_2 \land A_2, A_3 \land A_3 \land A_3, \ldots \}$$

The [deductive closures](wikipedia://en/7750539) of $T^*$ and $T$ are thus equivalent; the proof will show that $T^*$ is a recursive/decidable set.

Given any formula $X$, let its length be $|X|$. Then to decide $X \in T^*$, it suffices to first run the [enumeration algorithm](https://en.wikipedia.org/wiki/Enumeration_algorithm) until all $A_1, A_2, \dots, A_{|X|}$ are ouputted, then check if $X$ is equal to one of

$$A_1, A_2 \land A_2, \dots, \underbrace{A_{|X|}\land\dots\land A_{|X|}}_{|X|}.$$

## Primitive recursive axiomatization {#Primitive_recursive_axiomatization}

A set of axioms is [primitive recursive](https://en.wikipedia.org/wiki/Primitive_recursive) if there is a primitive recursive function that decides membership in the set. The algorithm given above is recursive, but not necessarily primitive recursive. The main issue is that, at the part where we "run the enumeration algorithm until all $A_1, A_2, \dots, A_{|X|}$ are ouputted", the enumeration algorithm may take a very long time to output all $A_1, A_2, \dots, A_{|X|}$.

For primitive recursion, all [loops](https://en.wikipedia.org/wiki/Loop_%28statement%29) must be bounded by a pre-computed upper bound. Consequently, we are not allowed to say "run the enumeration algorithm until...". However, we can say "run the enumeration algorithm for up to *k* steps", provided that we know what *k* should be.

Now, instead of replacing a formula $A_i$ with

$$\underbrace{A_i\land\dots\land A_i}_i$$

one replaces it with

$\underbrace{A_i\land\dots\land A_i}_{f(i)}$ (\*)

where $f$ is a function that, given $i$, returns the number of steps the enumeration [Turing machine](wikipedia://en/30403) takes in order to output $A_i$. In fact, this construction gives a decision algorithm that runs in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), which is a particularly well-behaved class of primitively recursive functions.

## Applications {#Applications}

The theorem has been used in proofs of [Gödel's incompleteness theorems](wikipedia://en/58863). One would first prove the theorems for all theories that with a set of axioms that is primitive recursive, then apply Craig's theorem to immediately conclude that the theorems hold for all theories with a set of axioms that is recursively enumerable.[^o6]

:::

## Philosophical implications {#Philosophical_implications}

If $T$ is a recursively axiomatizable theory and we divide its predicate symbols into two [disjoint sets](wikipedia://en/39359) $V_A$ and $V_B$, then those theorems of $T$ that are in the vocabulary $V_A$ are recursively enumerable, and hence, based on Craig's theorem, axiomatizable. [Carl G. Hempel](https://en.wikipedia.org/wiki/Carl_Gustav_Hempel) argued based on this that since all science's predictions are in the vocabulary of observation terms, the theoretical vocabulary of science is in principle eliminable. He himself raised two objections to this argument: 1) the new axioms of science are practically unmanageable, and 2) science uses [inductive reasoning](wikipedia://en/393736) and eliminating theoretical terms may alter the inductive relations between observational sentences. [Hilary Putnam](wikipedia://en/75233) argues that this argument is based on a misconception that the sole aim of science is successful prediction. He proposes that the main reason we need theoretical terms is that we wish to talk about theoretical entities (such as viruses, radio stars, and elementary particles).
