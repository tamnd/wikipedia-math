# Stone's method

::: {#o1 .subject cue=lead name="Stone's method"}

In [numerical analysis](wikipedia://en/21506), **Stone's method**, also known as the **strongly implicit procedure** or **SIP**, is an [algorithm](wikipedia://en/775) for solving a [sparse](wikipedia://en/341015) [linear system of equations](https://en.wikipedia.org/wiki/Linear_system_of_equations). The method uses an [incomplete LU decomposition](wikipedia://en/8517337), which approximates the exact [LU decomposition](wikipedia://en/6243993), to get an [iterative](wikipedia://en/15237) solution of the problem. The method is named after [Harold S. Stone](https://en.wikipedia.org/wiki/Harold_S._Stone), who proposed it in 1968.

:::

The LU decomposition is an excellent general-purpose linear equation solver. The biggest disadvantage is that it fails to take advantage of coefficient matrix to be a sparse matrix. The LU decomposition of a sparse matrix is usually not sparse, thus, for a large system of equations, LU decomposition may require a prohibitive amount of [memory](https://en.wikipedia.org/wiki/Random_access_memory) and number of [arithmetical operations](https://en.wikipedia.org/wiki/Instruction_%28computer_science%29).

In the [preconditioned](https://en.wikipedia.org/wiki/Preconditioned) [iterative methods](wikipedia://en/15237), if the preconditioner matrix *M* is a good approximation of coefficient matrix *A* then the convergence is faster. This brings one to idea of using approximate factorization *LU* of *A* as the iteration matrix *M*.

A version of incomplete lower-upper decomposition method was proposed by Stone in 1968. This method is designed for equation system arising from discretisation of [partial differential equations](wikipedia://en/52564) and was firstly used for a [pentadiagonal](https://en.wikipedia.org/wiki/Pentadiagonal_matrix) system of equations obtained while solving an [elliptic](wikipedia://en/550137) partial differential equation in a [two-dimensional](https://en.wikipedia.org/wiki/Two-dimensional) space by a [finite difference](wikipedia://en/39147) method. The LU approximate decomposition was looked in the same pentadiagonal form as the original matrix (three diagonals for *L* and three diagonals for *U*) as the best match of the seven possible equations for the five unknowns for each row of the matrix.

::: {#o3 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

**method** stone **is** For the linear system $\mathbf{A}x = b$ calculate incomplete $\mathbf{LU}$ factorization of matrix $\mathbf{A}$

$\mathbf{A}x = (\mathbf{M}-\mathbf{N})x = (\mathbf{LU}-\mathbf{N})x = b$ $\mathbf{M}x^{(k+1)} = \mathbf{N}x^{(k)}+b ,\text{ with } ||\mathbf{M}|| >> ||\mathbf{N}||$ $\mathbf{M}x^{(k+1)} = \mathbf{LU}x^{(k+1)} = c^{(k)}$ $\mathbf{LU}x^{(k)} = \mathbf{L}(\mathbf{U}x^{(k+1)}) = \mathbf{L}y^{(k)} = c^{(k)}$

set a guess

$$k = 0, x^{(k)} r^{(k)}=b - \mathbf{A}x^{(k)}$$

**while** ( $||r^{(k)}||_{2} \ge \varepsilon$ ) **do** evaluate new right hand side

$$c^{(k)} = \mathbf{N}x^{(k)} + b$$

solve $\mathbf{L}y^{(k)} = c^{(k)}$ by forward substitution

$$y^{(k)} = \mathbf{L}^{-1}c^{(k)}$$

solve $\mathbf{U}x^{(k+1)} = y^{(k)}$ by back substitution

$$x^{(k+1)} = \mathbf{U}^{-1}y^{(k)}$$

**end while**
