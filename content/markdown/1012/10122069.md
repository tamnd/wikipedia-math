# Trivial measure

::: {#o1 .subject cue=lead name="Trivial measure"}

In [mathematics](wikipedia://en/18831), specifically in [measure theory](https://en.wikipedia.org/wiki/Measure_theory), the **trivial measure** on any [measurable space](wikipedia://en/43333) (*X*, Σ) is the measure *μ* which assigns zero measure to every measurable set: *μ*(*A*) = 0 for all *A* in Σ.[^o2]

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties of the trivial measure"}

## Properties of the trivial measure {#Properties_of_the_trivial_measure}

Let *μ* denote the trivial measure on some measurable space (*X*, Σ).

- A measure *ν* is the trivial measure *μ* [if and only if](wikipedia://en/14922) *ν*(*X*) = 0.
- *μ* is an [invariant measure](wikipedia://en/7635201) (and hence a [quasi-invariant measure](wikipedia://en/2749048)) for any [measurable function](wikipedia://en/44055) *f* : *X* → *X*.

Suppose that *X* is a [topological space](wikipedia://en/30450) and that Σ is the [Borel *σ*-algebra](https://en.wikipedia.org/wiki/Borel_sigma_algebra) on *X*.

- *μ* trivially satisfies the condition to be a [regular measure](wikipedia://en/3390453).
- *μ* is never a [strictly positive measure](wikipedia://en/6607051), regardless of (*X*, Σ), since every measurable set has zero measure.
- Since *μ*(*X*) = 0, *μ* is always a finite measure, and hence a [locally finite measure](wikipedia://en/6621919).
- If *X* is a [Hausdorff](wikipedia://en/13637) topological space with its Borel *σ*-algebra, then *μ* trivially satisfies the condition to be a [tight measure](https://en.wikipedia.org/wiki/Tight_measure). Hence, *μ* is also a [Radon measure](wikipedia://en/521933). In fact, it is the vertex of the [pointed cone](https://en.wikipedia.org/wiki/Cone_%28linear_algebra%29) of all non-negative Radon measures on *X*.
- If *X* is an [infinite](wikipedia://en/20110824)-[dimensional](wikipedia://en/8398) [Banach space](wikipedia://en/3989) with its Borel *σ*-algebra, then *μ* is the only measure on (*X*, Σ) that is locally finite and invariant under all translations of *X*. See the article [There is no infinite-dimensional Lebesgue measure](https://en.wikipedia.org/wiki/There_is_no_infinite-dimensional_Lebesgue_measure).
- If *X* is *n*-dimensional [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup> with its usual *σ*-algebra and *n*-dimensional [Lebesgue measure](wikipedia://en/18198) *λ*<sup>*n*</sup>, *μ* is a [singular measure](wikipedia://en/4304500) with respect to *λ*<sup>*n*</sup>: simply decompose **R**<sup>*n*</sup> as *A* = **R**<sup>*n*</sup> \\ {0} and *B* = {0} and observe that *μ*(*A*) = *λ*<sup>*n*</sup>(*B*) = 0.

:::
