# Advanced Matrix Extensions

::: {#o1 .subject cue=lead name="Advanced Matrix Extensions"}

**Advanced Matrix Extensions** (**AMX**), also known as **Intel Advanced Matrix Extensions** (**Intel AMX**), are extensions to the [x86](https://en.wikipedia.org/wiki/X86) [instruction set architecture](https://en.wikipedia.org/wiki/Instruction_set_architecture) (ISA) for [microprocessors](https://en.wikipedia.org/wiki/Microprocessor) from [Intel](https://en.wikipedia.org/wiki/Intel) designed to work on [matrices](wikipedia://en/20556859) to accelerate [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) (AI) and [machine learning](wikipedia://en/233488) (ML) workloads.[^o2] Especially they perform [matrix multiplication](wikipedia://en/24107400) at the hardware level, making them apt for problems and algorithms that use matrix multiplication as their core.

:::

::: {#o4 .statement kind=statement/generalization cue=heading name="Extensions"}

## Extensions {#Extensions}

AMX was introduced by Intel in June 2020 and first supported by Intel with the [Sapphire Rapids](https://en.wikipedia.org/wiki/Sapphire_Rapids_%28microprocessor%29) [microarchitecture](https://en.wikipedia.org/wiki/Microarchitecture) for [Xeon](https://en.wikipedia.org/wiki/Xeon) servers, released in January 2023.[^o5][^o6] It introduced 2-dimensional [registers](https://en.wikipedia.org/wiki/Processor_register) called tiles upon which accelerators can perform operations. It is intended as an extensible architecture; the first accelerator implemented is called tile matrix multiply unit (TMUL).[^o7][^o8]

In Intel Architecture Instruction Set Extensions and Future Features revision 46, published in September 2022, a new AMX-FP16 extension was documented. This extension adds support for [half-precision floating-point](https://en.wikipedia.org/wiki/Half-precision_floating-point_format) numbers. In revision 48 from March 2023, AMX-COMPLEX was documented, adding support for half-precision floating-point [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers). Both extensions are available in the [Granite Rapids](https://en.wikipedia.org/wiki/Granite_Rapids) set of server processors (with AMX-COMPLEX support only being available in [Granite Rapids-D](https://en.wikipedia.org/wiki/Xeon_D) [^o9]).

### Tile matrix multiply unit {#Tile_matrix_multiply_unit}

TMUL unit supports [BF16](https://en.wikipedia.org/wiki/Bfloat16_floating-point_format) and [INT8](https://en.wikipedia.org/wiki/INT8) input types.[^o11] AMX-FP16 and AMX-COMPLEX also add support for real and complex [FP16](https://en.wikipedia.org/wiki/Half-precision_floating-point_format) numbers. The register file consists of 8 tiles, each with 16 rows of size of 64 bytes (32 BF16/FP16 or 64 INT8 elements). The only supported operation is matrix [multiply and accumulate (MMA)](https://en.wikipedia.org/wiki/Multiply–accumulate_operation), which is the extension of the [fused multiply–add (FMA)](https://en.wikipedia.org/wiki/Fused_multiply–add) operation for scalar values as applied to matrix operands:[^o12]

$C_{nm} = C_{nm} + \sum_{j=1}^J A_{nj}B_{jm}.$[^o7]

4th Gen Intel Xeon Scalable processor core can perform 2048 INT8 or 1024 BF16 operations per cycle:[^o13][^o14] the maximal input sizes are $16 \times J$ for $A$ and $J \times 16$ for $B$, where $J$ is 64 for INT8 and 32 for BF16. The matrix multiplication requires $256J$ multiplication and $256J$ additions, thus performing $512J$ operations in 16 cycles.[^o14]

## Software support {#Software_support}

- Compiler and assembler support
  - [LLVM](https://en.wikipedia.org/wiki/LLVM) 13[^o16][^o17][^o18][^o19]
  - [GCC](https://en.wikipedia.org/wiki/GNU_Compiler_Collection) 11[^o20][^o21][^o22]
  - [GNU Assembler](https://en.wikipedia.org/wiki/GNU_Assembler) (GAS) initial support committed on 25 June 2020[^o23][^o19]
- Operating system support
  - [glibc](https://en.wikipedia.org/wiki/Glibc) support for detecting AMX feature in CPUs committed on 25 June 2020[^o24]
  - [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel) support since version 5.16[^o25]
  - [VMware vSphere](https://en.wikipedia.org/wiki/VMware_vSphere) support for AMX in virtual machines released in [ESXi](https://en.wikipedia.org/wiki/ESXi) version 8.0u1 for VMs using Hardware Version 20[^o26]
