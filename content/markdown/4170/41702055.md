# Pseudo-functor

::: {#o1 .subject cue=lead name="Pseudo-functor"}

In mathematics, a **pseudofunctor** *F* is a mapping from a [category](wikipedia://en/53759) to the category **Cat** of (small) categories that is just like a [functor](wikipedia://en/10987) except that $F(f \circ g) = F(f) \circ F(g)$ and $F(1) = 1$ do not hold as exact equalities but only up to *[coherent isomorphisms](https://en.wikipedia.org/wiki/Coherent_isomorphism)*.

:::

A typical example is an assignment to each pullback $Ff = f^*$, which is a contravariant pseudofunctor since, for example for a quasi-coherent sheaf $\mathcal{F}$, we only have: $(g \circ f)^* \mathcal{F} \simeq f^* g^* \mathcal{F}.$

Since **Cat** is a [2-category](wikipedia://en/2740708), more generally, one can also consider a pseudofunctor between [2-categories](https://en.wikipedia.org/wiki/2-categories), where coherent isomorphisms are given as invertible 2-morphisms.

The [Grothendieck construction](https://en.wikipedia.org/wiki/Grothendieck_construction) associates to a contravariant pseudofunctor a [fibered category](https://en.wikipedia.org/wiki/Fibered_category), and conversely, each fibered category is induced by some contravariant pseudofunctor. Because of this, a contravariant pseudofunctor, which is a category-valued [presheaf](wikipedia://en/4840944), is often also called a [prestack](wikipedia://en/39547490) (a stack minus effective descent).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A pseudofunctor *F* from a category *C* to **Cat** consists of the following data

- a category $F(x)$ for each object *x* in *C*,
- a functor $Ff$ for each morphism *f* in *C*,
- a set of coherent isomorphisms for the identities and the compositions; namely, the invertible [natural transformations](wikipedia://en/45022)

$$F(f \circ g) \simeq F f \circ Fg,$$

$F(\operatorname{id}_x) \simeq \operatorname{id}_{F(x)}$ for each object *x*

such that

$F(fgh) \overset{\sim}\to F(fg) Fh \overset{\sim}\to Ff Fg Fh$ is the same as $F(fgh) \overset{\sim}\to Ff F(gh) \overset{\sim}\to Ff Fg Fh$,

$F (\operatorname{id}_x) \circ Ff \overset{\sim}\to F(\operatorname{id}_x \circ f) = Ff$ is the same as $F (\operatorname{id}_x) \circ Ff \simeq \operatorname{id}_{F(x)} \circ Ff = Ff$,

and similarly for $Ff \circ F (\operatorname{id}_x)$.[^o4]

:::

## Higher category interpretation {#Higher_category_interpretation}

The notion of a pseudofunctor is more efficiently handled in the language of [higher category theory](wikipedia://en/5274013). Namely, given an ordinary category *C*, we have the [functor category](wikipedia://en/407039) as the ∞-category

$$\textbf{Fct}(C, \textbf{Cat}).$$

Each pseudofunctor $C \to \textbf{Cat}$ belongs to the above, roughly because in an ∞-category, a composition is only required to hold weakly, and conversely (since a 2-morphism is invertible).
