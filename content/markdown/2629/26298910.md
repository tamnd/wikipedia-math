# Hoeffding's lemma

::: {#o1 .subject cue=lead name="Hoeffding's lemma"}

In [probability theory](wikipedia://en/23542), **Hoeffding's lemma** is an [inequality](wikipedia://en/89489) that bounds the [moment-generating function](https://en.wikipedia.org/wiki/Moment-generating_function) of any [bounded](wikipedia://en/311509) [random variable](wikipedia://en/25685),[^o2] implying that such variables are [subgaussian](wikipedia://en/47243817). It is named after the [Finnish](https://en.wikipedia.org/wiki/Finnish_people)–[American](https://en.wikipedia.org/wiki/United_States) [mathematical statistician](wikipedia://en/888711) [Wassily Hoeffding](wikipedia://en/2547060).

:::

The proof of Hoeffding's lemma uses [Taylor's theorem](wikipedia://en/51714). Hoeffding's lemma is itself used in the proof of [Hoeffding's inequality](wikipedia://en/1136348) as well as the generalization [McDiarmid's inequality](wikipedia://en/9181701).

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let *X* be any real-valued random variable such that $a \leq X \leq b$ [almost surely](wikipedia://en/351908), i.e. with probability one. Then, for all $\lambda \in \mathbb{R}$,

$$\mathbb{E} \left[ e^{\lambda X} \right] \leq \exp \Big(\lambda\mathbb{E}[X]+ \frac{\lambda^2 (b - a)^2}{8} \Big),$$

or equivalently,

$$\mathbb{E} \left[ e^{\lambda (X - \mathbb{E}[X])} \right] \leq \exp \Big(\frac{\lambda^2 (b - a)^2}{8} \Big).$$

::: {#o6 .proof cue=heading name="Proof"}

### Proof {#Proof}

The following proof is direct but somewhat ad-hoc.

::: {#o7 .proof cue=math-proof name="Proof"}

**Proof.**

Let $\mu = \mathbb{E}[X]$. Since the conclusion involves $b-a$, without loss of generality, one may replace $X$ by $X - \mu$, $a$ by $a - \mu$, and $b$ by $b - \mu$, which leaves the difference $b-a$ unchanged, and assume $\mathbb{E}[X] = 0$, so that $a \leq 0 \leq b$.

Since $e^{\lambda x}$ is a convex function of $x$, we have that for all $x \in [a,b]$,

$$e^{\lambda x}\leq \frac{b-x}{b-a}e^{\lambda a}+\frac{x-a}{b-a}e^{\lambda b}$$

So,

$$\begin{aligned} \mathbb{E}\left[e^{\lambda X}\right] &\leq \frac{b-\mathbb{E}[X]}{b-a}e^{\lambda a}+\frac{\mathbb{E}[X]-a}{b-a}e^{\lambda b}\\ &= \frac{b}{b-a}e^{\lambda a} + \frac{-a}{b-a}e^{\lambda b} \\ &= e^{L(\lambda(b-a))}, \end{aligned}$$

where $L(h)= \frac{ha}{b-a}+\ln(1 + \frac{a - e^ha}{b-a})$. By computing derivatives, we find

$L(0)=L'(0)=0$ and $L''(h)= -\frac{ab e^h}{(b-a e^h)^2}$.

From the [AMGM](https://en.wikipedia.org/wiki/Inequality_of_arithmetic_and_geometric_means) inequality we thus see that $L''(h)\le\frac14$ for all $h$, and thus, from [Taylor's theorem](wikipedia://en/51714), there is some $0 \le \theta \le 1$ such that

$$L(h) = L(0) + h L'(0) + \frac{1}{2} h^2 L''(h\theta) \leq \frac{1}{8}h^2.$$

Thus, $\mathbb{E}\left[e^{\lambda X}\right] \leq e^{\frac{1}{8}\lambda^2(b-a)^2}$.

:::

## Statement {#Statement}

This statement and proof uses the language of [subgaussian](wikipedia://en/47243817) variables and [exponential tilting](wikipedia://en/49288169), and is less ad-hoc.[^o10]

Let $X$ be any real-valued random variable such that $a \leq X \leq b$ [almost surely](wikipedia://en/351908), i.e. with probability one. Then it is subgaussian with [variance proxy](wikipedia://en/47243817#Variance_proxy) norm $\|X\|_{vp} \leq \frac{b-a}{2}$.

::: {#o11 .proof cue=math-proof name="Proof"}

**Proof.**

By the definition of variance proxy, it suffices to show that its cumulant generating function $K(t) := \log E[e^{t(X-E[X])}]$ satisfies $K''(t) \leq (b-a)^2/4$. Explicit calculation shows

$$K''(t) = \frac{E[(X-E[X])^2 e^{t(X-E[X])}]}{E[e^{t(X-E[X])}]} - \left(\frac{E[(X-E[X]) e^{t(X-E[X])}]}{E[e^{t(X-E[X])}]}\right)^2$$

Notice that the quantity $\frac{E[(X-E[X]) e^{t(X-E[X])}]}{E[e^{t(X-E[X])}]} = E\left[(X-E[X])\frac{e^{t(X-E[X])}}{E[e^{t(X-E[X])}]} \right]$ is precisely the expectation of a random variable obtained by exponentially tilting $X - E[X]$. Let this variable be $Y_t$. It remains to bound $Var[Y_t] \leq (b-a)^2/4$.

Notice that $Y_t$ still has range $[a-E[X], b-E[X]]$. So translate it to $Z_t := Y_t - \frac{a+b - E[X]}{2}$ so that its range has midpoint zero. It remains to bound $Var[Z_t] \leq (b-a)^2/4$. However, now the bound is trivial, since $|Z_t| \leq \frac{b-a}{2}$.

:::

Given this general case, the formula $\mathbb{E} \left[ e^{\lambda (X - \mathbb{E}[X])} \right] \leq e^{\frac{\lambda^2 (b - a)^2}{8}}$ is a mere corollary of a general property of variance proxy.

:::
