# Krichevsky–Trofimov estimator

::: {#o1 .subject cue=lead name="Krichevsky–Trofimov estimator"}

In [information theory](wikipedia://en/14773), given an unknown [stationary](wikipedia://en/329898) source $\pi$ with alphabet *A* and a sample *w* from $\pi$, the **Krichevsky–Trofimov (KT) estimator** produces an estimate *p*<sub>*i*</sub>(*w*) of the probability of each symbol *i* ∈ *A*. This estimator is optimal in the sense that it minimizes the worst-case [regret](wikipedia://en/16695601) asymptotically.

:::

For a binary alphabet and a string *w* with *m* zeroes and *n* ones, the KT estimator *p*<sub>*i*</sub>(*w*) is defined as:[^o2]

$$\begin{aligned} p_0(w) &= \frac{m + 1/2}{m + n + 1}, \\[5pt] p_1(w) &= \frac{n + 1/2}{m + n + 1}. \end{aligned}$$

This corresponds to the posterior mean of a [Beta-Bernoulli posterior distribution](wikipedia://en/846412) with prior $1/2$. For the general case the estimate is made using a [Dirichlet-Categorical](wikipedia://en/10072717#Bayesian_inference_using_conjugate_prior) distribution.
