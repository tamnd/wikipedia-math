# Owen's T function

::: {#o1 .subject cue=lead name="Owen's T function"}

In mathematics, **Owen's T function** *T*(*h*, *a*), named after [statistician](wikipedia://en/48661) Donald Bruce Owen, is defined by

:::

$$T(h,a)=\frac{1}{2\pi}\int_{0}^{a} \frac{e^{-\frac{1}{2} h^2 (1+x^2)}}{1+x^2} dx \quad \left(-\infty < h, a < +\infty\right).$$

The function was first introduced by Owen in 1956.[^o2]

::: {#o4 .application cue=heading name="Applications"}

## Applications {#Applications}

The function *T*(*h*, *a*) gives the probability of the event (*X* > *h* and 0 \< *Y* \< *aX*) where *X* and *Y* are [independent](https://en.wikipedia.org/wiki/Statistically_independent) [standard normal](https://en.wikipedia.org/wiki/Standard_normal_distribution) [random variables](wikipedia://en/25685).

This function can be used to calculate [bivariate normal distribution](https://en.wikipedia.org/wiki/Bivariate_normal_distribution) probabilities[^o5][^o6] and, from there, in the calculation of [multivariate normal distribution](wikipedia://en/50347) probabilities.[^o7] It also frequently appears in [various integrals involving Gaussian functions](wikipedia://en/30981930).

Computer algorithms for the accurate calculation of this function are available;[^o8] [quadrature](wikipedia://en/50579) having been employed since the 1970s. [^o9]

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

$$T(h,0) = 0$$

$$T(0,a) = \frac{1}{2\pi} \arctan(a)$$

$$T(-h,a) = T(h,a)$$

$$T(h,-a) = -T(h,a)$$

$$T(h,a) + T\left(ah,\frac{1}{a}\right) = \begin{cases} \frac{1}{2} \left(\Phi(h) + \Phi(ah)\right) - \Phi(h)\Phi(ah) &\text{if} \quad a \geq 0 \\ \frac{1}{2} \left(\Phi(h) + \Phi(ah)\right) - \Phi(h)\Phi(ah) - \frac{1}{2} & \text{if} \quad a < 0 \end{cases}$$

$$T(h, 1) = \frac{1}{2} \Phi(h) \left(1 - \Phi(h)\right)$$

$$\int T(0,x) \, \mathrm{d}x = x T(0,x) - \frac{1}{4 \pi} \ln\left(1+x^2\right) + C$$

Here Φ(*x*) is the [standard normal cumulative distribution function](wikipedia://en/21462)

$$\Phi(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^x \exp\left(-\frac{t^2 }{2}\right) \, \mathrm{d}t$$

More properties can be found in the literature.[^o12]

:::
