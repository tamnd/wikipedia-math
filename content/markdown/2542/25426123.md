# Kunen's inconsistency theorem

::: {#o1 .subject cue=lead name="Kunen's inconsistency theorem"}

In [set theory](wikipedia://en/27553), a branch of mathematics, **Kunen's inconsistency theorem**, proved by (txt), shows that several plausible [large cardinal](wikipedia://en/383644) axioms are [inconsistent](wikipedia://en/75802) with the [axiom of choice](wikipedia://en/840).

:::

Some consequences of Kunen's theorem (or its proof) are:

- There is no non-trivial [elementary embedding](wikipedia://en/972601) of the universe *V* into itself. In other words, there is no [Reinhardt cardinal](wikipedia://en/4687321).
- If *j* is an elementary embedding of the universe *V* into an inner model *M*, and λ is the smallest fixed point of *j* above the [critical point](wikipedia://en/4888510) κ of *j*, then *M* does not contain the set *j* "λ (the image of *j* restricted to λ).
- There is no [ω-huge cardinal](https://en.wikipedia.org/wiki/Ω-huge_cardinal).
- There is no non-trivial elementary embedding of *V*<sub>λ+2</sub> into itself.

It is not known if Kunen's theorem still holds in ZF (ZFC without the axiom of choice), though (Suzuki 1999) showed that there is no definable elementary embedding from *V* into *V*. That is there is no formula *J* in the language of set theory such that for some parameter *p*∈*V* for all sets *x*∈*V* and *y*∈*V*: $j(x)=y \leftrightarrow J(x,y,p) \,.$

Kunen used [Morse–Kelley set theory](wikipedia://en/2693655) in his proof. If the proof is re-written to use ZFC, then one must add the assumption that replacement holds for formulas involving *j*. Otherwise one could not even show that *j* "λ exists as a set. The forbidden set *j* "λ is crucial to the proof. The proof first shows that it cannot be in *M*. The other parts of the theorem are derived from that.

It is possible to have models of set theory that have elementary embeddings into themselves, at least if one assumes some mild large cardinal axioms. For example, if [0<sup>\#</sup>](wikipedia://en/248085) exists then there is an elementary embedding from the [constructible universe](wikipedia://en/343335) *L* into itself. This does not contradict Kunen's theorem because if 0<sup>\#</sup> exists then *L* cannot be the whole universe of sets.
