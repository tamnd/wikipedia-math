# Conway sphere

::: {#o1 .subject cue=lead name="Conway sphere"}

*Image: Algebraic Borromean link diagram.svg.* A Conway sphere (black dotted midline) for the [Borromean rings](wikipedia://en/873118)

In mathematical [knot theory](wikipedia://en/153008), a **Conway sphere**, named after [John Horton Conway](wikipedia://en/15807), is a [2-sphere](wikipedia://en/39782) intersecting a given knot or link in a [3-manifold](wikipedia://en/1018257) [transversely](https://en.wikipedia.org/wiki/Transversality_%28mathematics%29) in four points. In a [knot diagram](https://en.wikipedia.org/wiki/Knot_diagram), a Conway sphere can be represented by a simple closed curve crossing four points of the knot, the cross-section of the sphere; such a curve does not always exist for an arbitrary knot diagram of a knot with a Conway sphere, but it is always possible to choose a diagram for the knot in which the sphere can be depicted in this way. A Conway sphere is *essential* if it is [incompressible](wikipedia://en/896174) in the [knot complement](wikipedia://en/1350120).[^o2] Sometimes, this condition is included in the definition of Conway spheres.[^o3]
