# Recession cone

::: {#o1 .subject cue=lead name="Recession cone"}

In [mathematics](wikipedia://en/18831), especially [convex analysis](wikipedia://en/3237201), the **recession cone** of a set $A$ is a [cone](https://en.wikipedia.org/wiki/Cone_%28linear_algebra%29) containing all [vectors](https://en.wikipedia.org/wiki/Vector_%28mathematics%29) such that $A$ *recedes* in that direction. That is, the set extends outward in all the directions given by the recession cone.[^o2]

:::

## Mathematical definition {#Mathematical_definition}

Given a nonempty set $A \subset X$ for some [vector space](wikipedia://en/32370) $X$, then the recession cone $\operatorname{recc}(A)$ is given by

$\operatorname{recc}(A) = \{y \in X: \forall x \in A, \forall \lambda \geq 0: x + \lambda y \in A\}.$[^o4]

If $A$ is additionally a [convex set](wikipedia://en/6292) then the recession cone can equivalently be defined by

$\operatorname{recc}(A) = \{y \in X: \forall x \in A: x + y \in A\}.$[^o5]

If $A$ is a nonempty [closed](wikipedia://en/47279) convex set then the recession cone can equivalently be defined as

$\operatorname{recc}(A) = \bigcap_{t > 0} t(A - a)$ for any choice of $a \in A.$[^o5]

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If $A$ is a nonempty set then $0 \in \operatorname{recc}(A)$.
- If $A$ is a nonempty convex set then $\operatorname{recc}(A)$ is a [convex cone](wikipedia://en/3558266).[^o5]
- If $A$ is a nonempty closed convex subset of a finite-dimensional [Hausdorff space](wikipedia://en/13637) (e.g. $\mathbb{R}^d$), then $\operatorname{recc}(A) = \{0\}$ if and only if $A$ is bounded.[^o2][^o5]
- If $A$ is a nonempty set then $A + \operatorname{recc}(A) = A$ where the sum denotes [Minkowski addition](wikipedia://en/504105).

:::

## Relation to asymptotic cone {#Relation_to_asymptotic_cone}

The [asymptotic cone](https://en.wikipedia.org/wiki/Asymptotic_cone) for $C \subseteq X$ is defined by

$C_{\infty} = \{x \in X: \exists (t_i)_{i \in I} \subset (0,\infty), \exists (x_i)_{i \in I} \subset C: t_i \to 0, t_i x_i \to x\}.$[^o9][^o10]

By the definition it can easily be shown that $\operatorname{recc}(C) \subseteq C_\infty.$[^o9]

In a finite-dimensional space, then it can be shown that $C_{\infty} = \operatorname{recc}(C)$ if $C$ is nonempty, closed and convex.[^o10] In infinite-dimensional spaces, then the relation between asymptotic cones and recession cones is more complicated, with properties for their equivalence summarized in.[^o11]

## Sum of closed sets {#Sum_of_closed_sets}

- [Dieudonné's theorem](wikipedia://en/34978225): Let nonempty closed convex sets $A,B \subset X$ a [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space), if either $A$ or $B$ is [locally compact](https://en.wikipedia.org/wiki/Locally_compact) and $\operatorname{recc}(A) \cap \operatorname{recc}(B)$ is a [linear subspace](wikipedia://en/56357), then $A - B$ is closed.[^o13][^o5]
- Let nonempty closed convex sets $A,B \subset \mathbb{R}^d$ such that for any $y \in \operatorname{recc}(A) \backslash \{0\}$ then $-y \not\in \operatorname{recc}(B)$, then $A + B$ is closed.[^o2][^o9]
