# K-theory spectrum

::: {#o1 .subject cue=lead name="K-theory spectrum"}

In mathematics, given a [ring](wikipedia://en/48404) *R*, the ***K*-theory spectrum** of *R* is an [Ω-spectrum](https://en.wikipedia.org/wiki/Ω-spectrum) $K_R$ whose *n*th term is given by, writing $\Sigma R$ for the [suspension](wikipedia://en/41284472) of *R*,

:::

$$(K_R)_n = K_0(\Sigma^n R) \times BGL(\Sigma^n R)^+,$$

where "+" means the Quillen's [+ construction](https://en.wikipedia.org/wiki/+_construction).[^o2] By definition, $K_i(R) = \pi_i(K_R)$.
