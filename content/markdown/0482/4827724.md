# Banach function algebra

::: {#o1 .subject cue=lead name="Banach function algebra"}

In [functional analysis](wikipedia://en/11180), a **Banach function algebra** on a [compact](wikipedia://en/6042) [Hausdorff space](wikipedia://en/13637) *X* is [unital](https://en.wikipedia.org/wiki/Unital_algebra) [subalgebra](wikipedia://en/45239), *A*, of the [commutative](https://en.wikipedia.org/wiki/Commutative) [C\*-algebra](wikipedia://en/7184) *C(X)* of all [continuous](wikipedia://en/6122), [complex](wikipedia://en/5826)-valued functions from *X*, together with a [norm](wikipedia://en/990534) on *A* that makes it a [Banach algebra](wikipedia://en/4665).

:::

A function algebra is said to vanish at a point *p* if *f*(*p*) = 0 for all $f\in A$. A function algebra [separates points](wikipedia://en/13972359) if for each distinct pair of points $p,q \in X$, there is a function $f\in A$ such that $f(p) \neq f(q)$.

For every $x\in X$ define $\varepsilon_x(f)=f(x),$ for $f\in A$. Then $\varepsilon_x$ is a homomorphism (character) on $A$, non-zero if $A$ does not vanish at $x$.

::: {#o2 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** A Banach function algebra is [semisimple](wikipedia://en/3876151) (that is its [Jacobson radical](wikipedia://en/57656) is equal to zero) and each commutative [unital](https://en.wikipedia.org/wiki/Unital_ring), semisimple Banach algebra is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) (via the [Gelfand transform](https://en.wikipedia.org/wiki/Gelfand_transform)) to a Banach function algebra on its [character space](https://en.wikipedia.org/wiki/Character_space) (the space of algebra homomorphisms from *A* into the complex numbers given the [relative](https://en.wikipedia.org/wiki/Relative_topology) [weak\* topology](https://en.wikipedia.org/wiki/Weak*_topology)).

If the norm on $A$ is the uniform norm (or sup-norm) on $X$, then $A$ is called a **[uniform algebra](wikipedia://en/4536974)**. Uniform algebras are an important special case of Banach function algebras.

:::
