# Lacunary value

::: {#o1 .subject cue=lead name="Lacunary value"}

In [complex analysis](wikipedia://en/5759), a subfield of [mathematics](wikipedia://en/18831), a **lacunary value** or **gap** of a [complex](wikipedia://en/5826)-valued [function](wikipedia://en/185427) defined on a subset of the [complex plane](wikipedia://en/217628) is a complex number which is not in the [image](wikipedia://en/579311) of the function.[^o2]

:::

More specifically, given a subset *X* of the complex plane **C** and a function *f* : *X* → **C**, a complex number *z* is called a *lacunary value* of *f* if *z* ∉ image(*f*).

Note, for example, that 0 is the only lacunary value of the complex [exponential function](wikipedia://en/9678). The two [Picard theorems](wikipedia://en/674050) limit the number of possible lacunary values of certain types of [holomorphic functions](wikipedia://en/14110).
