# Liberman's lemma

::: {#o1 .subject cue=lead name="Liberman's lemma"}

**Liberman's lemma** is a theorem used in studying [intrinsic geometry](wikipedia://en/475335) of [convex surface](https://en.wikipedia.org/wiki/Convex_surface). It is named after [Joseph Liberman](wikipedia://en/45570719).

:::

::: {#o3 .definition cue=heading name="Formulation"}

## Formulation {#Formulation}

If $\gamma$ is a unit-speed minimizing [geodesic](wikipedia://en/91096) on the surface of a [convex body](wikipedia://en/8652020) *K* in [Euclidean space](wikipedia://en/9697) then for any point *p* ∈ *K*, the function

$$t\mapsto\operatorname{dist}^2\circ\gamma(t)-t^2$$

is concave.

:::
