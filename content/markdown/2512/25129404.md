# Lévy hierarchy

::: {#o1 .subject cue=lead name="Lévy hierarchy"}

In [set theory](wikipedia://en/27553) and [mathematical logic](wikipedia://en/19636), the **Lévy hierarchy**, introduced by [Azriel Lévy](wikipedia://en/18329294) in 1965, is a hierarchy of formulas in the [formal language](wikipedia://en/10939) of the [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC), which is typically called just the language of set theory. This is analogous to the [arithmetical hierarchy](wikipedia://en/186475), which provides a similar classification for sentences of the language of [arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

In the language of set theory, [atomic formulas](wikipedia://en/4472066) are of the form x = y or x ∈ y, standing for [equality](wikipedia://en/90446) and [set membership](https://en.wikipedia.org/wiki/Set_membership) predicates, respectively.

The first level of the Lévy hierarchy is defined as containing only formulas with no [unbounded quantifiers](wikipedia://en/5824808) and is denoted by $\Delta_0=\Sigma_0=\Pi_0$.[^o4] The next levels are given by finding a formula in [prenex normal form](wikipedia://en/421068) that is provably equivalent over ZFC, and counting the number of alternations of [quantifiers](wikipedia://en/43507260):[^o5]<sup>p. 184</sup>

A formula $A$ is called:[^o4][^o6]

- $\Sigma_{i+1}$ if $A$ is equivalent to $\exists x_1 ... \exists x_n B$ in ZFC, where $B$ is $\Pi_i$
- $\Pi_{i+1}$ if $A$ is equivalent to $\forall x_1 ... \forall x_n B$ in ZFC, where $B$ is $\Sigma_i$
- If a formula is both $\Sigma_i$ and $\Pi_i$ form, it is called $\Delta_i$.

As a formula might have several different equivalent formulas in prenex normal form, it might belong to several different levels of the hierarchy. In this case, the lowest possible level is the level of the formula.

Lévy's original notation was $\Sigma_i^\mathsf{ZFC}$ (respectively $\Pi_i^\mathsf{ZFC}$) due to the provable logical equivalence,[^o7] strictly speaking the above levels should be referred to as $\Sigma_i^\mathsf{ZFC}$ (respectively $\Pi_i^\mathsf{ZFC}$) to specify the theory in which the equivalence is carried out, however it is usually clear from context.[^o8]<sup>pp. 441–442</sup> Pohlers has defined $\Delta_1$ in particular semantically, in which a formula is "$\Delta_1$ in a structure $M$".[^o9]

The Lévy hierarchy is sometimes defined for other theories *S*. In this case $\Sigma_i$ and $\Pi_i$ by themselves refer only to formulas that start with a sequence of quantifiers with at most *i*−1 alternations, and $\Sigma_i^S$ and $\Pi_i^S$ refer to formulas equivalent to $\Sigma_i$ and $\Pi_i$ formulas in the language of the theory *S*. So strictly speaking the levels $\Sigma_i$ and $\Pi_i$ of the Lévy hierarchy for ZFC defined above should be denoted by $\Sigma^{\mathsf{ZFC}} _i$ and $\Pi^{\mathsf{ZFC}}_i$.

## Properties {#Properties}

Let $n\geq 1$. The Lévy hierarchy has the following properties:[^o5]<sup>p. 184</sup>

- If $\phi$ is $\Sigma_n$, then $\lnot\phi$ is $\Pi_n$.
- If $\phi$ is $\Pi_n$, then $\lnot\phi$ is $\Sigma_n$.
- If $\phi$ and $\psi$ are $\Sigma_n$, then $\exists x\phi$, $\phi\land\psi$, $\phi\lor\psi$, $\exists(x\in z)\phi$, and $\forall(x\in z)\phi$ are all $\Sigma_n$.
- If $\phi$ and $\psi$ are $\Pi_n$, then $\forall x\phi$, $\phi\land\psi$, $\phi\lor\psi$, $\exists(x\in z)\phi$, and $\forall(x\in z)\phi$ are all $\Pi_n$.
- If $\phi$ is $\Sigma_n$ and $\psi$ is $\Pi_n$, then $\phi\implies\psi$ is $\Pi_n$.
- If $\phi$ is $\Pi_n$ and $\psi$ is $\Sigma_n$, then $\phi\implies\psi$ is $\Sigma_n$.

Devlin p. 29
