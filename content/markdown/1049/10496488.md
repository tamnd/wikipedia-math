# Testimator

::: {#o1 .subject cue=lead name="Testimator"}

A **testimator** is an [estimator](wikipedia://en/10043) whose value depends on the result of a test for [statistical significance](wikipedia://en/160995). In the simplest case the value of the final estimator is that of the basic [estimator](wikipedia://en/10043) if the test result is significant, and otherwise the value is zero. However more general testimators are possible.[^o2]

:::

## History {#History}

An early use of the term "testimator" way made by Brewster & Zidek (1974).[^o4]
