# Learnable function class

::: {#o1 .subject cue=lead name="Learnable function class"}

In [statistical learning theory](wikipedia://en/1053303), a **learnable function class** is a [set](wikipedia://en/26691) of [functions](wikipedia://en/185427) for which an algorithm can be devised to asymptotically minimize the [expected risk](https://en.wikipedia.org/wiki/Expected_risk), uniformly over all probability distributions. The concept of learnable classes are closely related to [regularization](wikipedia://en/2009061) in [machine learning](wikipedia://en/233488), and provides large sample justifications for certain learning algorithms.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Background {#Background}

Let $\Omega = \mathcal{X} \times \mathcal{Y} = \{(x, y)\}$ be the [sample space](wikipedia://en/22958), where $y$ are the labels and $x$ are the covariates (predictors). $\mathcal{F} = \{ f: \mathcal{X} \mapsto \mathcal{Y} \}$ is a collection of mappings (functions) under consideration to link $x$ to $y$. $L: \mathcal{Y} \times \mathcal{Y} \mapsto \mathbb{R}$ is a pre-given [loss function](wikipedia://en/442137) (usually non-negative). Given a probability distribution $P(x, y)$ on $\Omega$, define the expected risk $I_P( f )$ to be:

$$I_P (f) = \int L( f(x), y ) d P( x, y )$$

The general goal in statistical learning is to find the function in $\mathcal{F}$ that minimizes the expected risk. That is, to find solutions to the following problem:[^o5]

$$\hat{f} = \arg \min_{f \in \mathcal{F}} I_P (f)$$

But in practice the distribution $P$ is unknown, and any learning task can only be based on finite samples. Thus we seek instead to find an algorithm that asymptotically minimizes the empirical risk, i.e., to find a sequence of functions $\{\hat{f}_n\}_{n=1}^\infty$ that satisfies

$$\lim_{n \rightarrow \infty} \mathbb{P}( I_P (\hat{f}_n) - \inf_{f \in \mathcal{F}}I_P( f ) > \epsilon ) = 0$$

One usual algorithm to find such a sequence is through [empirical risk minimization](wikipedia://en/1455062).

### Learnable function class {#Learnable_function_class}

We can make the condition given in the above equation stronger by requiring that the convergence is uniform for all probability distributions. That is:

::: {#o7 .equation cue=numblk name="1"}

$$\lim_{n \rightarrow \infty} \sup_P \mathbb{P}( I_P (\hat{f}_n) - \inf_{f \in \mathcal{F}}I_P( f ) > \epsilon ) = 0 \tag{1}$$

:::

The intuition behind the more strict requirement is as such: the rate at which sequence $\{\hat{f}_n\}$ converges to the minimizer of the expected risk can be very different for different $P(x, y)$. Because in real world the true distribution $P$ is always unknown, we would want to select a sequence that performs well under all cases.

However, by the [no free lunch theorem](wikipedia://en/1297317), such a sequence that satisfies ((1)) does not exist if $\mathcal{F}$ is too complex. This means we need to be careful and not allow too "many" functions in $\mathcal{F}$ if we want ((1)) to be a meaningful requirement. Specifically, function classes that ensure the existence of a sequence $\{\hat{f}_n\}$ that satisfies ((1)) are known as **learnable classes**.[^o5]

It is worth noting that at least for supervised classification and regression problems, if a function class is learnable, then the empirical risk minimization automatically satisfies ((1)).[^o8] Thus in these settings not only do we know that the problem posed by ((1)) is solvable, we also immediately have an algorithm that gives the solution.

:::

## Interpretations {#Interpretations}

If the true relationship between $y$ and $x$ is $y \sim f^*(x)$, then by selecting the appropriate loss function, $f^*$ can always be expressed as the minimizer of the expected loss across all possible functions. That is,

$$f^* = \arg\min_{f \in \mathcal{F}^*} I_P( f )$$

Here we let $\mathcal{F}^*$ be the collection of all possible functions mapping $\mathcal{X}$ onto $\mathcal{Y}$. $f^*$ can be interpreted as the actual data generating mechanism. However, the no free lunch theorem tells us that in practice, with finite samples we cannot hope to search for the expected risk minimizer over $\mathcal{F}^*$. Thus we often consider a subset of $\mathcal{F}^*$, $\mathcal{F}$, to carry out searches on. By doing so, we risk that $f^*$ might not be an element of $\mathcal{F}$. This tradeoff can be mathematically expressed as

::: {#o10 .equation cue=numblk name="2"}

$$I_P (\hat{f}_n) - \inf_{f \in \mathcal{F}^*}I_P( f ) = \underbrace{I_P (\hat{f}_n) - \inf_{f \in \mathcal{F}}I_P( f )}_{(a)} + \underbrace{\inf_{f \in \mathcal{F}}I_P( f ) - \inf_{f \in \mathcal{F}^*}I_P( f )}_{(b)} \tag{2}$$

:::

In the above decomposition, part $(b)$ does not depend on the data and is non-stochastic. It describes how far away our assumptions ($\mathcal{F}$) are from the truth ($\mathcal{F}^*$). $(b)$ will be strictly greater than 0 if we make assumptions that are too strong ($\mathcal{F}$ too small). On the other hand, failing to put enough restrictions on $\mathcal{F}$ will cause it to be not learnable, and part $(a)$ will not stochastically converge to 0. This is the well-known [overfitting](wikipedia://en/173332) problem in statistics and machine learning literature.

## Example: Tikhonov regularization {#Example:_Tikhonov_regularization}

A good example where learnable classes are used is the so-called [Tikhonov regularization](https://en.wikipedia.org/wiki/Tikhonov_regularization) in [reproducing kernel Hilbert space](wikipedia://en/651196) (RKHS). Specifically, let $\mathcal{F^*}$ be an RKHS, and $||\cdot||_2$ be the norm on $\mathcal{F^*}$ given by its inner product. It is shown in [^o12] that $\mathcal{F} = \{f: ||f||_2 \leq \gamma \}$ is a learnable class for any finite, positive $\gamma$. The empirical minimization algorithm to the [dual form](wikipedia://en/609737) of this problem is

$$\arg\min_{f \in \mathcal{F}^*} \left\{ \sum_{i = 1}^n L( f(x_i), y_i) + \lambda ||f||_2 \right\}$$

This was first introduced by Tikhonov[^o13] to solve ill-posed problems. Many statistical learning algorithms can be expressed in such a form (for example, the well-known [ridge regression](wikipedia://en/954328)).

The tradeoff between $(a)$ and $(b)$ in ((2)) is geometrically more intuitive with Tikhonov regularization in RKHS. We can consider a sequence of $\{\mathcal{F}_\gamma\}$, which are essentially balls in $\mathcal{F^*}$ with centers at 0. As $\gamma$ gets larger, $\mathcal{F}_\gamma$ gets closer to the entire space, and $(b)$ is likely to become smaller. However we will also suffer smaller convergence rates in $(a)$. The way to choose an optimal $\gamma$ in finite sample settings is usually through [cross-validation](wikipedia://en/416612).

## Relationship to empirical process theory {#Relationship_to_empirical_process_theory}

Part $(a)$ in ((2)) is closely linked to [empirical process](wikipedia://en/3690433) theory in statistics, where the empirical risk $\{\sum_{i=1}^n L( y_i, f(x_i) ), f \in \mathcal{F}\}$ are known as empirical processes.[^o15] In this field, the function class $\mathcal{F}$ that satisfies the stochastic convergence

::: {#o16 .equation cue=numblk name="3"}

$$\sup_P \mathbb{E} \sup_{f \in \mathcal{F}} | \sum_{i=1}^n L( y_i, f(x_i) ) - I_P(f) | = 0 \tag{3}$$

:::

are known as uniform [Glivenko–Cantelli classes](https://en.wikipedia.org/wiki/Glivenko–Cantelli_class). It has been shown that under certain regularity conditions, learnable classes and uniformly Glivenko-Cantelli classes are equivalent.[^o5] Interplay between $(a)$ and $(b)$ in statistics literature is often known as the [bias-variance tradeoff](https://en.wikipedia.org/wiki/Bias-variance_tradeoff).

However, note that in [^o8] the authors gave an example of [stochastic convex optimization](https://en.wikipedia.org/wiki/Stochastic_convex_optimization) for [General Setting of Learning](https://en.wikipedia.org/wiki/General_Setting_of_Learning) where learnability is not equivalent with [uniform convergence](wikipedia://en/50652).
