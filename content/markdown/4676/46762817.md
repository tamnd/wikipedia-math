# Network simplex algorithm

::: {#o1 .subject cue=lead name="Network simplex algorithm"}

In [mathematical optimization](wikipedia://en/52033), the **network simplex algorithm** is a [graph theoretic](wikipedia://en/12401) specialization of the [simplex algorithm](wikipedia://en/349458). The algorithm is usually formulated in terms of a [minimum-cost flow problem](wikipedia://en/6807932). The network simplex method works very well in practice, typically 200 to 300 times faster than the simplex method applied to general linear program of same dimensions.[^o2]

:::

## History {#History}

For a long time, the existence of a provably efficient network simplex algorithm was one of the major open problems in complexity theory, even though efficient-in-practice versions were available. In 1995 [Orlin](https://en.wikipedia.org/wiki/James_B._Orlin) provided the first polynomial algorithm with runtime of $O(V^2 E \log(VC))$ where $C$ is maximum cost of any edges.[^o4] Later [Tarjan](https://en.wikipedia.org/wiki/Robert_Tarjan) improved this to $O(VE \log V \log(VC))$ using [dynamic trees](https://en.wikipedia.org/wiki/Dynamic_trees) in 1997.[^o5] Strongly polynomial dual network simplex algorithms for the same problem, but with a higher dependence on the numbers of edges and vertices in the graph, have been known for longer.[^o6]

## Overview {#Overview}

The network simplex method is an adaptation of the bounded variable primal simplex algorithm. The basis is represented as a rooted spanning tree of the underlying network, in which variables are represented by arcs, and the simplex multipliers by node potentials. At each iteration, an entering variable is selected by some pricing strategy, based on the dual multipliers (node potentials), and forms a cycle with the arcs of the tree. The leaving variable is the arc of the cycle with the least augmenting flow. The substitution of entering for leaving arc, and the reconstruction of the tree is called a pivot. When no non-basic arc remains eligible to enter, the optimal solution has been reached.

## Applications {#Applications}

The network simplex algorithm can be used to solve many practical problems including,[^o10]

- [Transshipment problem](wikipedia://en/35852253)
- [Hitchcock transportation problem](wikipedia://en/6631661)
- [Assignment problem](wikipedia://en/140592)
- Chains and antichains in [partially ordered sets](wikipedia://en/23572)
- [System of distinct representatives](https://en.wikipedia.org/wiki/System_of_distinct_representatives)
- Covers and matching in [bipartite graphs](wikipedia://en/244431)
- Caterer problem
