# Waldspurger's theorem

::: {#o1 .subject cue=lead name="Waldspurger's theorem"}

In [mathematics](wikipedia://en/18831), **Waldspurger's theorem**, introduced by (txt), is a result that identifies [Fourier coefficients](https://en.wikipedia.org/wiki/Fourier_coefficient) of [modular forms](wikipedia://en/286000) of half-integral weight *k*+1/2 with the value of an [L-series](wikipedia://en/245283) at *s*=*k*/2.

:::
