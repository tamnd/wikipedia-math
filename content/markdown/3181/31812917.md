# Method of Four Russians

::: {#o1 .subject cue=lead name="Method of Four Russians"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), the **Method of Four Russians** or "The Four-Russians speedup,"[^o2] is a technique for speeding up [algorithms](wikipedia://en/775) involving [Boolean matrices](wikipedia://en/25417056), or more generally algorithms involving matrices in which each cell may take on only a bounded number of possible values.

:::

## Idea {#Idea}

The main idea of the method is to partition the matrix into small square blocks of size $t \times t$ for some parameter $t$, and to use a [lookup table](https://en.wikipedia.org/wiki/Lookup_table) to perform the algorithm quickly within each block. The index into the lookup table encodes the values of the matrix cells on the upper left of the block boundary prior to some operation of the algorithm, and the result of the lookup table encodes the values of the boundary cells on the lower right of the block after the operation. Thus, the overall algorithm may be performed by operating on only $(n/t)^{2}$ blocks instead of on $n^{2}$ matrix cells, where $n$ is the side length of the matrix. In order to keep the size of the lookup tables (and the time needed to initialize them) sufficiently small, $t$ is typically chosen to be $O(\log n)$.

The creation of the lookup tables can be done in $O(n \times t^{2})$ time, and if $t$ is set to $\log n$, this results in $O(n (\log n)^{2})$ time complexity for creating the tables. That time is still dominated by the search time $O(\tfrac{n^{2}}{(\log n)^{2}})$ time (assuming unit-cost RAM).[^o2]

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

Algorithms to which the Method of Four Russians may be applied include:

- computing the [transitive closure](wikipedia://en/292239) of a graph,
- Boolean [matrix multiplication](wikipedia://en/125280),
- [edit distance](wikipedia://en/406427) calculation,
- [sequence alignment](wikipedia://en/149289),
- index calculation for [binary jumbled pattern matching](https://en.wikipedia.org/wiki/Binary_jumbled_pattern_matching).

In each of these cases it speeds up the algorithm by one or two [logarithmic](wikipedia://en/17860) factors.

The Method of Four Russians matrix inversion algorithm published by Bard is implemented in M4RI library for fast arithmetic with dense matrices over *F*<sub>2</sub>. M4RI is used by [SageMath](https://en.wikipedia.org/wiki/SageMath) and the PolyBoRi library.[^o6]

:::

## History {#History}

The algorithm was introduced by [V. L. Arlazarov](https://en.wikipedia.org/wiki/Vladimir_Arlazarov), [E. A. Dinic](https://en.wikipedia.org/wiki/Yefim_Dinitz), [M. A. Kronrod](https://en.wikipedia.org/wiki/Mikhail_Aleksandrovich_Kronrod), and [I. A. Faradžev](https://en.wikipedia.org/wiki/Igor_Faradžev) in 1970.[^n1] The origin of the name is unknown; (Aho Hopcroft Ullman 1974) explain:

The second method, often called the "Four Russians'" algorithm, after the [cardinality](wikipedia://en/6174) and [nationality](https://en.wikipedia.org/wiki/Nationality) of its inventors, is somewhat more "practical" than the algorithm in Theorem 6.9.[^n2]

All four authors worked in [Moscow, Russia](https://en.wikipedia.org/wiki/Moscow) in the [Soviet Union](https://en.wikipedia.org/wiki/Soviet_Union) at the time,[^o11] however, only Arlazarov was Russian; the name has thus been said to reflect the West's, "general level of ignorance about ethnicities in the then Soviet Union."[^o2]
