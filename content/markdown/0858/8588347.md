# Arens–Fort space

Arens–Fort space

::: {#o1 .subject cue=lead name="Arens–Fort space"}

*Image: ArensFortSpace ZeroNeighbourhood.svg.* Example neighborhood of (0,0) in the Arens–Fort space

In [mathematics](wikipedia://en/18831), the **Arens–Fort space** is a special example in the theory of [topological spaces](wikipedia://en/30450), named for [Richard Friederich Arens](wikipedia://en/1794523) and [M. K. Fort, Jr.](https://en.wikipedia.org/wiki/M._K._Fort,_Jr.)

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Arens–Fort space is the topological space $(X,\tau)$ where $X$ is the set of ordered pairs of non-negative [integers](wikipedia://en/14563) $(m, n).$ A subset $U \subseteq X$ is [open](wikipedia://en/39358), that is, belongs to $\tau,$ if and only if:

- $U$ does not contain $(0, 0),$ or
- $U$ contains $(0, 0)$ and also all but a finite number of points of all but a finite number of columns, where a column is a set $\{ (m, n) ~:~ 0 \leq n \in \mathbb{Z} \}$ with $0 \leq m \in \mathbb{Z}$ fixed.

In other words, an open set is only "allowed" to contain $(0, 0)$ if only a finite number of its columns contain significant gaps, where a gap in a column is significant if it omits an infinite number of points.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

It is

- [Hausdorff](wikipedia://en/13637)
- [regular](wikipedia://en/53058)
- [normal](wikipedia://en/48629)

It is not:

- [second-countable](https://en.wikipedia.org/wiki/Second-countable)
- [first-countable](https://en.wikipedia.org/wiki/First-countable)
- [metrizable](https://en.wikipedia.org/wiki/Metrizable)
- [compact](wikipedia://en/6042)
- [sequential](wikipedia://en/4668395)
- [Fréchet–Urysohn](wikipedia://en/28480560)

There is no sequence in $X \setminus \{ (0, 0) \}$ that converges to $(0, 0).$ However, there is a sequence $x_{\bullet} = \left( x_i \right)_{i=1}^{\infty}$ in $X \setminus \{ (0, 0) \}$ such that $(0, 0)$ is a [cluster point](https://en.wikipedia.org/wiki/Cluster_point) of $x_{\bullet}.$

:::
