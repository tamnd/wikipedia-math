# List of cryptosystems

::: {#o1 .subject cue=lead name="List of cryptosystems"}

A **cryptosystem** is a set of [cryptographic](wikipedia://en/18934432) [algorithms](wikipedia://en/775) that map [ciphertexts](wikipedia://en/175560) and [plaintexts](wikipedia://en/157935) to each other.[^o2]

:::
