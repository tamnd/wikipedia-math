# Topological half-exact functor

::: {#o1 .subject cue=lead name="Topological half-exact functor"}

In [mathematics](wikipedia://en/18831), a **topological half-exact functor** *F* is a [functor](wikipedia://en/10987) from a fixed topological [category](wikipedia://en/53759) (for example [CW complexes](https://en.wikipedia.org/wiki/CW_complexes) or [pointed spaces](wikipedia://en/1236666)) to an [abelian category](wikipedia://en/45063) (most frequently in applications, category of [abelian groups](wikipedia://en/2974) or category of [modules](wikipedia://en/276410) over a fixed ring) that has a following property: for each sequence of spaces, of the form:

:::

*X* → *Y* → *C(f)*

where *C(f)* denotes a [mapping cone](wikipedia://en/1707756), the sequence:

*F(X)* → *F(Y)* → *F(C(f))*

is [exact](wikipedia://en/138215). If *F* is a contravariant functor, it is **half-exact** if for each sequence of spaces as above, the sequence *F(C(f))* → *F(Y)* → *F(X)* is exact.

[Homology](wikipedia://en/142432) is an example of a half-exact functor, and [cohomology](wikipedia://en/194060) (and [generalized cohomology theories](https://en.wikipedia.org/wiki/Generalized_cohomology_theories)) are examples of contravariant half-exact functors. If *B* is any fibrant topological space, the (representable) functor *F(X)=\[X,B\]* is half-exact.
