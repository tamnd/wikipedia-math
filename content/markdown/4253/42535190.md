# Indifference graph

*Image: Indifference graph = unit interval graph.svg.* An indifference graph, formed from a set of points on the real number line by connecting pairs of points whose distance is at most one. Also the intersection graph of the set of the unit intervals centered on the points.

::: {#o1 .subject cue=lead name="Indifference graph"}

In [graph theory](wikipedia://en/12401), a branch of mathematics, an **indifference graph** is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) constructed by assigning a [real number](wikipedia://en/20646438) to each vertex and connecting two vertices by an edge when their numbers are within one unit of each other.[^o2] An indifference graph is also the [intersection graph](wikipedia://en/7726759) of a set of [unit intervals](wikipedia://en/49324), or of properly nested intervals (intervals none of which contains any other one). Based on these two types of interval representations, these graphs are also called **unit interval graphs**[^o4] or **proper interval graphs**; they form a subclass of the [interval graphs](wikipedia://en/363423).

:::

## Equivalent characterizations {#Equivalent_characterizations}

*Image: Forbidden indifference subgraphs.svg.* [Forbidden induced subgraphs](wikipedia://en/13547826) for the indifference graphs: the claw, sun, and net (top, left–right), and cycles of length four or more (bottom)

A finite indifference graph may be equivalently characterized as:

- The [intersection graph](wikipedia://en/7726759) of a set of [unit intervals](wikipedia://en/49324).[^o2]
- The intersection graph of a set of intervals with the same length.[^o4]
- The intersection graph of a set of intervals no two of which are nested (one containing the other).[^o2][^o5]
- A [claw-free](wikipedia://en/12415907) [interval graph](wikipedia://en/363423).[^o2][^o5]
- A graph that does not have an [induced subgraph](wikipedia://en/1655188) isomorphic to a [claw](https://en.wikipedia.org/wiki/Claw_%28graph_theory%29) $K_{1,3}$, net (a triangle with a degree-one vertex adjacent to each of the triangle vertices), sun (a triangle surrounded by three other triangles that each share one edge with the central triangle), or hole (cycle of length four or more).[^o6]
- An [incomparability graph](wikipedia://en/6978672) of [semiorder](wikipedia://en/28771796).[^o2]
- An undirected graph that has a [linear order](https://en.wikipedia.org/wiki/Linear_order) such that, for every three vertices ordered $u$–$v$–$w$, if $uw$ is an edge then so are $uv$ and $vw$.[^o7]
- A graph with no **astral triple**, three vertices connected pairwise by paths that avoid the third vertex and also do not contain two consecutive neighbors of the third vertex.[^o8]
- A graph in which each connected component contains a path in which each [maximal clique](https://en.wikipedia.org/wiki/Maximal_clique) of the component forms a contiguous sub-path.[^o9]
- A graph whose vertices can be numbered in such a way that every shortest path forms a [monotonic sequence](https://en.wikipedia.org/wiki/Monotonic_sequence).[^o9]
- A graph whose [adjacency matrix](wikipedia://en/244463) can be ordered in such a way that, in each row and each column, the nonzeros of the matrix form a contiguous interval adjacent to the main diagonal of the matrix.[^o10]
- An induced subgraph of a power of a chordless path.[^o11]
- A [leaf power](wikipedia://en/49639194) having a leaf root which is a caterpillar.[^o11]

For an infinite graph, some of these definitions may differ.

## Properties {#Properties}

Because it is a special case of an [interval graph](wikipedia://en/363423), an indifference graph has all the properties of an interval graph; in particular, it is a special case of a [chordal graph](wikipedia://en/744165) and of a [perfect graph](wikipedia://en/670531). It is also a special case of a [circle graph](wikipedia://en/1399873), something that is not true of an interval graph more generally.

In the [Erdős–Rényi model](wikipedia://en/10477221) of [random graphs](wikipedia://en/358477), an $n$-vertex graph whose number of edges is significantly less than $n^{2/3}$ will be an indifference graph with high probability, whereas an $n$-vertex graph whose number of edges is significantly more than $n^{2/3}$ will not be an indifference graph with high probability.[^o14]

The [bandwidth](wikipedia://en/27414778) of an arbitrary graph $G$ is $1$ less than the size of the [maximum clique](https://en.wikipedia.org/wiki/Maximum_clique) in an indifference graph that contains $G$ as a subgraph and is chosen to minimize the size of the maximum clique.[^o15] This property parallels similar relations between [pathwidth](wikipedia://en/5133142) and [interval graphs](wikipedia://en/363423), and between [treewidth](wikipedia://en/3987086) and [chordal graphs](wikipedia://en/744165). A weaker notion of width, the [clique-width](wikipedia://en/16795502), may be arbitrarily large on indifference graphs.[^o16] However, any proper (i.e., strictly smaller) subclass of indifference graphs that is closed under [induced subgraphs](wikipedia://en/1655188) has an upper bound on the clique-width of its graphs.[^o17]

A [connected](https://en.wikipedia.org/wiki/Connected_graph) indifference graph has a [Hamiltonian path](wikipedia://en/244437).[^o18] An indifference graph has a [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle) if and only if it is [biconnected](https://en.wikipedia.org/wiki/K-vertex-connected_graph).[^o19]

An indifference graph obeys the [reconstruction conjecture](wikipedia://en/255594): it is uniquely determined by its vertex-deleted subgraphs.[^o20]

## Algorithms {#Algorithms}

As with higher dimensional [unit disk graphs](wikipedia://en/3686677), it is possible to transform a set of points into their indifference graph, or a set of unit intervals into their unit interval graph, in [linear time](https://en.wikipedia.org/wiki/Linear_time) as measured in terms of the size of the output graph. The algorithm rounds the points (or interval centers) down to the nearest smaller integer, uses a [hash table](wikipedia://en/13833) to find all pairs of points whose rounded integers are within $1$ of each other (the [fixed-radius near neighbors](https://en.wikipedia.org/wiki/Fixed-radius_near_neighbors) problem), and filters the resulting list of pairs for the ones whose unrounded values are also within $1$ of each other.[^o23]

It is possible to test whether a given graph is an indifference graph in linear time, by using [PQ trees](wikipedia://en/597568) to construct an interval representation of the graph and then testing whether a vertex ordering derived from this representation satisfies the properties of an indifference graph.[^o7] It is also possible to base a recognition algorithm for indifference graphs on [chordal graph](wikipedia://en/744165) recognition algorithms.[^o19] Several alternative linear time recognition algorithms are based on [breadth-first search](wikipedia://en/97026) or [lexicographic breadth-first search](https://en.wikipedia.org/wiki/Lexicographic_breadth-first_search) rather than on the relation between indifference graphs and interval graphs.[^o24][^o25][^o26][^o27]

Once the vertices have been sorted by the numerical values that describe an indifference graph (or by the sequence of unit intervals in an interval representation), the same ordering can be used to find an optimal [graph coloring](wikipedia://en/426743) for these graphs, to solve the [shortest path problem](wikipedia://en/41985), and to construct [Hamiltonian paths](wikipedia://en/244437) and [maximum matchings](https://en.wikipedia.org/wiki/Maximum_matching), all in linear time.[^o7] A [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle) can be found from a proper interval representation of the graph in time $O(n \log n)$,[^o18] but when the graph itself is given as input, the same problem admits linear-time solution that can be generalized to interval graphs.[^o28][^o29]

[List coloring](wikipedia://en/690669) remains [NP-complete](https://en.wikipedia.org/wiki/NP-complete) even when restricted to indifference graphs.[^o30] However, it is [fixed-parameter tractable](wikipedia://en/603026) when parameterized by the total number of colors in the input.[^o17]

## Applications {#Applications}

In [mathematical psychology](wikipedia://en/2081516), indifference graphs arise from [utility](wikipedia://en/45479) functions, by scaling the function so that one unit represents a difference in utilities small enough that individuals can be assumed to be indifferent to it. In this application, pairs of items whose utilities have a large difference may be [partially ordered](wikipedia://en/23572) by the relative order of their utilities, giving a [semiorder](wikipedia://en/28771796).[^o2][^o33]

In [bioinformatics](wikipedia://en/4214), the problem of augmenting a colored graph to a properly colored unit interval graph can be used to model the detection of false negatives in [DNA](https://en.wikipedia.org/wiki/DNA) [sequence assembly](https://en.wikipedia.org/wiki/Sequence_assembly) from complete [digests](https://en.wikipedia.org/wiki/Restriction_digest).[^o34]
