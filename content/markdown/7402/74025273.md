# Blackwell-Girshick equation

::: {#o1 .subject cue=lead name="Blackwell-Girshick equation"}

The **Blackwell-Girshick equation** is an equation in [probability theory](wikipedia://en/23542) that allows for the calculation of the [variance](wikipedia://en/32344) of random sums of [random variables](wikipedia://en/25685).[^o2] It is the equivalent of [Wald's lemma](https://en.wikipedia.org/wiki/Wald's_lemma) for the expectation of composite distributions.

:::

It is named after [David Blackwell](wikipedia://en/2202900) and [Meyer Abraham Girshick](wikipedia://en/75631435).

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $N$ be a random variable with values in $\mathbb{Z}_{\ge 0}$, let $X_1, X_2, X_3, \dots$ be [independent and identically distributed](https://en.wikipedia.org/wiki/Independent_and_identically_distributed) random variables, which are also independent of $N$, and assume that the second [moment](wikipedia://en/32960532) exists for all $X_i$ and $N$. Then, the random variable defined by

$$Y:=\sum_{i=1}^NX_i$$

has the variance

$$\operatorname{Var}(Y)=\operatorname{Var}(N)\operatorname{E}(X_1)^2+\operatorname{E}(N)\operatorname{Var}(X_1).$$

The Blackwell-Girshick equation can be derived using [conditional variance](wikipedia://en/11391180) and variance decomposition. If the $X_i$ are natural number-valued random variables, the derivation can be done elementarily using the [chain rule](wikipedia://en/6113) and the [probability-generating function](https://en.wikipedia.org/wiki/Probability-generating_function).[^o5]

:::

::: {#o7 .proof cue=heading name="Proof"}

## Proof {#Proof}

For each $n\ge 0$, let $\chi_n$ be the random variable which is 1 if $N$ equals $n$ and 0 otherwise, and let $Y_n:=X_1+\cdots+X_n$. Then

$$\begin{aligned} \operatorname{E}(Y^2) & = \sum_{n=0}^\infty \operatorname{E}(\chi_n Y_n^2)\\ &= \sum_{n=0}^\infty \operatorname{P}(N=n) \operatorname{E}(Y_n^2)\\ &= \sum_{n=0}^\infty\operatorname{P}(N=n) (\operatorname{Var}(Y_n)+\operatorname{E}(Y_n)^2)\\ &= \sum_{n=0}^\infty\operatorname{P}(N=n) (n \operatorname{Var}(X_1)+n^2\operatorname{E}(X_1)^2)\\ &= \operatorname{E}(N) \operatorname{Var}(X_1) + \operatorname{E}(N^2) \operatorname{E}(X_1)^2. \end{aligned}$$

By [Wald's equation](wikipedia://en/1512013), under the given hypotheses, $\operatorname{E}(Y)=\operatorname{E}(N) \operatorname{E}(X_1)$. Therefore,

$$\begin{aligned} \operatorname{Var}(Y)&=\operatorname{E}(Y^2)-\operatorname{E}(Y)^2\\ &= \operatorname{E}(N) \operatorname{Var}(X_1) + \operatorname{E}(N^2) \operatorname{E}(X_1)^2 - \operatorname{E}(N)^2 \operatorname{E}(X_1)^2 \\ &= \operatorname{E}(N) \operatorname{Var}(X_1) + \operatorname{Var}(N) \operatorname{E}(X_1)^2, \end{aligned}$$

as desired.

:::

::: {#o9 .example cue=heading name="Example"}

## Example {#Example}

Let $N$ have a [Poisson distribution](wikipedia://en/23009144) with expectation $\lambda$, and let $X_1, X_2, \dots$ follow a [Bernoulli distribution](wikipedia://en/199189) with parameter $p$. In this case, $Y$ is also Poisson distributed with expectation $\lambda p$, so its variance must be $\lambda p$. We can check this with the Blackwell-Girshick equation: $N$ has variance $\lambda$ while each $X_i$ has mean $p$ and variance $p(1-p)$, so we must have

$$\operatorname{Var}(Y)= \lambda p^2+\lambda p (1-p) = \lambda p.$$

:::

## Application and related concepts {#Application_and_related_concepts}

The Blackwell-Girshick equation is used in [actuarial mathematics](https://en.wikipedia.org/wiki/Actuarial_mathematics) to calculate the variance of composite distributions, such as the [compound Poisson distribution](wikipedia://en/949562). [Wald's equation](wikipedia://en/1512013) provides similar statements about the expectation of composite distributions.
