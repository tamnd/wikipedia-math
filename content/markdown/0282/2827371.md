# Immerman–Szelepcsényi theorem

::: {#o1 .subject cue=lead name="Immerman–Szelepcsényi theorem"}

In [computational complexity theory](wikipedia://en/7543), the **Immerman–Szelepcsényi theorem** states that [nondeterministic space](https://en.wikipedia.org/wiki/Nondeterministic_space) [complexity classes](wikipedia://en/502426) are closed under complementation. It was proven independently by [Neil Immerman](https://en.wikipedia.org/wiki/Neil_Immerman) and [Róbert Szelepcsényi](https://en.wikipedia.org/wiki/Róbert_Szelepcsényi) in 1987, for which they shared the 1995 [Gödel Prize](https://en.wikipedia.org/wiki/Gödel_Prize). In its general form the theorem states that [NSPACE](wikipedia://en/658518)(*s*(*n*)) = co-NSPACE(*s*(*n*)) for any function *s*(*n*) ≥ log *n*. The result is equivalently stated as [NL](wikipedia://en/1145955) = co-NL; although this is the special case when *s*(*n*) = log *n*, it implies the general theorem by a standard [padding argument](https://en.wikipedia.org/wiki/Padding_argument).[^o2] The result solved the [second LBA problem](wikipedia://en/1811962#LBA_problems).

:::

In other words, if a nondeterministic machine can solve a problem, another machine with the same resource bounds can solve its [complement](wikipedia://en/1929955) problem (with the *yes* and *no* answers reversed) in the same asymptotic amount of space. No similar result is known for the [time complexity](wikipedia://en/405944) classes, and indeed it is conjectured that [NP](wikipedia://en/21562) is not equal to [co-NP](wikipedia://en/6184).

The principle used to prove the theorem has become known as [inductive counting](https://en.wikipedia.org/wiki/Inductive_counting). It has also been used to prove other theorems in computational complexity, including the closure of [LOGCFL](wikipedia://en/4734121) under complementation and the existence of error-free randomized logspace algorithms for [USTCON](https://en.wikipedia.org/wiki/USTCON).[^o3]

::: {#o5 .proof cue=heading name="Proof"}

## Proof {#Proof}

We prove here that NL = co-NL. The theorem is obtained from this special case by a [padding argument](https://en.wikipedia.org/wiki/Padding_argument).

The [st-connectivity](https://en.wikipedia.org/wiki/St-connectivity) problem asks, given a [digraph](wikipedia://en/19721986) *G* and two vertices *s* and *t*, whether there is a directed path from *s* to *t* in *G*. This problem is NL-complete, therefore its complement *st-non-connectivity* is co-NL-complete. It suffices to show that *st-non-connectivity* is in NL. This proves co-NL ⊆ NL, and by complementation, NL ⊆ co-NL.

We fix a digraph *G*, a source vertex *s*, and a target vertex *t*. We denote by *R*<sub>*k*</sub> the set of vertices which are reachable from *s* in at most *k* steps. Note that if *t* is reachable from *s*, it is reachable in at most *n-1* steps, where *n* is the number of vertices, therefore we are reduced to testing whether *t* ∉ *R*<sub>*n-1*</sub>.

We remark that *R*<sub>0</sub> = { *s* }, and *R*<sub>*k*+1</sub> is the set of vertices *v* which are either in *R*<sub>*k*</sub>, or the target of an edge *w* → *v* where *w* is in *R*<sub>*k*</sub>. This immediately gives an algorithm to decide *t* ∈ *R*<sub>*n*</sub>, by successively computing *R*<sub>*1*</sub>, …, *R*<sub>*n*</sub>. However, this algorithm uses too much space to solve the problem in NL, since storing a set *R*<sub>*k*</sub> requires one bit per vertex.

The crucial idea of the proof is that instead of computing *R*<sub>*k*+1</sub> from *R*<sub>*k*</sub>, it is possible to compute the *size* of *R*<sub>*k*+1</sub> from the *size* of *R*<sub>*k*</sub>, with the help of non-determinism. We iterate over vertices and increment a counter for each vertex that is found to belong to *R*<sub>*k*+1</sub>. The problem is how to determine whether *v* ∈ *R*<sub>*k*+1</sub> for a given vertex *v*, when we only have the size of *R*<sub>*k*</sub> available.

To this end, we iterate over vertices *w*, and for each *w*, we non-deterministically *guess* whether *w* ∈ *R*<sub>*k*</sub>. If we guess *w* ∈ *R*<sub>*k*</sub>, and *v* = *w* or there is an edge *w* → *v*, then we determine that *v* belongs to *R*<sub>*k*+1</sub>. If this fails for all vertices *w*, then *v* does not belong to *R*<sub>*k*+1</sub>.

Thus, the computation that determines whether *v* belongs to *R*<sub>*k*+1</sub> splits into branches for the different guesses of which vertices belong to *R*<sub>*k*</sub>. A mechanism is needed to make all of these branches abort (reject immediately), except the one where all the guesses were correct. For this, when we have made a “yes-guess” that *w* ∈ *R*<sub>*k*</sub>, we *check* this guess, by non-deterministically looking for a path from *s* to *w* of length at most *k*. If this check fails, we abort the current branch. If it succeeds, we increment a counter of “yes-guesses”. On the other hand, we do not check the “no-guesses” that *w* ∉ *R*<sub>*k*</sub> (this would require solving *st-non-connectivity*, which is precisely the problem that we are solving in the first place). However, at the end of the loop over *w*, we check that the counter of “yes-guesses” matches the size of *R*<sub>*k*</sub>, which we know. If there is a mismatch, we abort. Otherwise, all the “yes-guesses” were correct, and there was exactly the right number of them, thus all “no-guesses” were correct as well.

This concludes the computation of the size of *R*<sub>*k*+1</sub> from the size of *R*<sub>*k*</sub>. Iteratively, we compute the sizes of *R*<sub>1</sub>, *R*<sub>2</sub>, …, *R*<sub>*n-2*</sub>. Finally, we check whether *t* ∈ *R*<sub>*n-1*</sub>, which is possible from the size of *R*<sub>*n*-2</sub> by the sub-algorithm that is used inside the computation of the size of *R*<sub>*k*+1</sub>.

The following [pseudocode](https://en.wikipedia.org/wiki/Pseudocode) summarizes the algorithm:

**function** verify\_reachable(G, s, w, k) *// Verifies that w ∈ R<sub>k</sub>. If this is not the case, aborts* *// the current computation branch, rejecting the input.* **if** s = w **then** **return** c ← s **repeat** k **times** *// Aborts if there is no edge from c, otherwise* *// non-deterministically branches* **guess** an edge c → d in G c ← d **if** c = w **then** **return** *// We did not guess a path.* **reject**

**function** is\_reachable(G, s, v, k, S) *// Assuming that R<sub>k</sub> has size S, determines whether v ∈ R<sub>k+1</sub>.* reachable ← **false** yes\_guesses ← 0 *// counter of yes-guesses w ∈ R<sub>k</sub>* **for each vertex** w **of** G **do** *// Guess whether w ∈ R<sub>k</sub>* **guess** a boolean b **if** b **then** verify\_reachable(G, s, w, k) yes\_guesses += 1 **if** v = w **or** there is an edge w → v in G **then** reachable ← **true** **if** yes\_guesses ≠ S **then** **reject** *// wrong number of yes-guesses* **return** reachable

**function** st\_non\_connectivity(G, s, t) n ← vertex\_count(G) *// Size of R<sub>k</sub>, initially 1 because R<sub>0</sub> = {s}* S ← 1 **for** k **from** 0 **to** n-3 **do** S' ← 0 *// size of R<sub>k+1</sub>* **for each vertex** v **of** G **do** **if** is\_reachable(G, s, v, k, S) **then** S' += 1 S ← S' **return** **not** is\_reachable(G, s, t, n-2, S)

:::

## Logspace hierarchy {#Logspace_hierarchy}

As a corollary, in the same article, Immerman proved that, using [descriptive complexity](https://en.wikipedia.org/wiki/Descriptive_complexity)'s equality between [NL](wikipedia://en/1145955) and [FO(Transitive Closure)](https://en.wikipedia.org/wiki/FO_%28complexity%29#Transitive_closure_is_NL), the logarithmic hierarchy, i.e. the languages decided by an [alternating Turing machine](https://en.wikipedia.org/wiki/Alternating_Turing_machine) in logarithmic space with a bounded number of alternations, is the same class as NL.
