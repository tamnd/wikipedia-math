# Grimm's conjecture

::: {#o1 .subject cue=lead name="Grimm's conjecture"}

In [mathematics](wikipedia://en/18831), specifically in [number theory](wikipedia://en/21527), **Grimm's conjecture** states that, for every set of consecutive [composite numbers](wikipedia://en/82289), there is an equally sized set of [prime numbers](wikipedia://en/23666), and a [bijection](wikipedia://en/3942) that maps each composite in the former set to a prime in the latter set that it is divisible by. It was first proposed by Carl Albert Grimm in 1969.[^n1]

:::

Though still unproven, the conjecture has been verified for all $n<1.9\times 10^{10}$.[^n2]

::: {#o5 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

If $n+1,n+2,\dots,n+k$ are all [composite numbers](https://en.wikipedia.org/wiki/Composite_numbers), then there is a sequence of distinct [prime numbers](wikipedia://en/23666) $\left(p_i\right)_{i=1}^k$ such that $p_i$ [divides](wikipedia://en/49492) $n+i$ for $1 \leq i \leq k$.

### Weaker version {#Weaker_version}

A weaker, though still unproven, version of this conjecture states that if there is no prime in the interval $[n+1, n+k]$, then

$$\prod_{1\,\leq \,x\,\leq \,k}(n+x)$$

has at least $k$ distinct [prime divisors](https://en.wikipedia.org/wiki/Prime_divisor).[^n3]

:::

## Consequences {#Consequences}

If Grimm's conjecture is true, then

$$p_{i+1} - p_i \ll \Big(\frac{p_i}{\log p_i}\Big)^{1/2}$$

for all consecutive primes $p_i$ and $p_{i+1}$.[^n3] This goes well beyond what the [Riemann hypothesis](wikipedia://en/19344125) would imply about [gaps between prime numbers](https://en.wikipedia.org/wiki/Prime_gaps): the Riemann hypothesis only implies an upper bound of $O(\sqrt{p_i}(\log p_i))$.[^n4]
