# Lévy distribution

::: {#o1 .subject cue=lead name="Lévy distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **Lévy distribution**, named after [Paul Lévy](wikipedia://en/556462), is a [continuous probability distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution) for a non-negative [random variable](wikipedia://en/25685). In [spectroscopy](https://en.wikipedia.org/wiki/Spectroscopy), this distribution, with frequency as the dependent variable, is known as a **van der Waals profile**.[^o2] It is a special case of the [inverse-gamma distribution](wikipedia://en/1653565) and a [stable distribution](wikipedia://en/1117869).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [probability density function](wikipedia://en/43487) of the Lévy distribution over the domain $x \ge \mu$ is

$$f(x; \mu, c) = \sqrt{\frac{c}{2\pi}} \, \frac{e^{-\frac{c}{2(x - \mu)}}}{(x - \mu)^{3/2}},$$

where $\mu$ is the [location parameter](wikipedia://en/17516) and $c$ is the [scale parameter](wikipedia://en/769503). The cumulative distribution function is

$$F(x; \mu, c) = \operatorname{erfc}\left(\sqrt{\frac{c}{2(x - \mu)}}\right) = 2 - 2 \Phi\left({\sqrt{\frac{c}{(x - \mu)}}}\right),$$

where $\operatorname{erfc}(z)$ is the complementary [error function](wikipedia://en/177111), and $\Phi(x)$ is the Laplace function ([CDF](https://en.wikipedia.org/wiki/Cumulative_Distribution_Function) of the standard [normal distribution](wikipedia://en/21462)). The shift parameter $\mu$ has the effect of shifting the curve to the right by an amount $\mu$ and changing the support to the interval \[$\mu$, $\infty$). Like all [stable distributions](wikipedia://en/1117869), the Lévy distribution has a standard form *f*(*x*; 0, 1) which has the following property:

$$f(x; \mu, c) \,dx = f(y; 0, 1) \,dy,$$

where *y* is defined as

$$y = \frac{x - \mu}{c}.$$

The [characteristic function](wikipedia://en/3229401) of the Lévy distribution is given by

$$\varphi(t; \mu, c) = e^{i\mu t - \sqrt{-2ict}}.$$

Note that the characteristic function can also be written in the same form used for the stable distribution with $\alpha = 1/2$ and $\beta = 1$:

$$\varphi(t; \mu, c) = e^{i\mu t - |ct|^{1/2} (1 - i\operatorname{sign}(t))}.$$

Assuming $\mu = 0$, the *n*th [moment](wikipedia://en/368684) of the unshifted Lévy distribution is formally defined by

$$m_n\ \stackrel{\text{def}}{=}\ \sqrt{\frac{c}{2\pi}} \int_0^\infty \frac{e^{-c/2x} x^n}{x^{3/2}} \,dx,$$

which diverges for all $n \geq 1/2$, so that the integer moments of the Lévy distribution do not exist (only some fractional moments).

The [moment-generating function](https://en.wikipedia.org/wiki/Moment-generating_function) would be formally defined by

$$M(t; c)\ \stackrel{\mathrm{def}}{=}\ \sqrt{\frac{c}{2\pi}} \int_0^\infty \frac{e^{-c/2x + tx}}{x^{3/2}} \,dx,$$

however, this diverges for $t > 0$ and is therefore not defined on an interval around zero, so the moment-generating function is actually undefined.

Like all [stable distributions](wikipedia://en/1117869) except the [normal distribution](wikipedia://en/21462), the wing of the probability density function exhibits heavy tail behavior falling off according to a power law:

$$f(x; \mu, c) \sim \sqrt{\frac{c}{2\pi}} \, \frac{1}{x^{3/2}}$$

as $x \to \infty,$

which shows that the Lévy distribution is not just [heavy-tailed](wikipedia://en/8092200) but also [fat-tailed](wikipedia://en/4357461). This is illustrated in the diagram below, in which the probability density functions for various values of *c* and $\mu = 0$ are plotted on a [log–log plot](wikipedia://en/1659215):

The standard Lévy distribution satisfies the condition of being [stable](wikipedia://en/1117869):

$$(X_1 + X_2 + \dotsb + X_n) \sim n^{1/\alpha}X,$$

where $X_1, X_2, \ldots, X_n, X$ are independent standard Lévy-variables with $\alpha = 1/2.$

## Related distributions {#Related_distributions}

- If $X \sim \operatorname{Levy}(\mu, c)$, then $kX + b \sim \operatorname{Levy}(k\mu + b, kc).$
- If $X \sim \operatorname{Levy}(0, c)$, then $X \sim \operatorname{Inv-Gamma}(1/2, c/2)$ ([inverse gamma distribution](https://en.wikipedia.org/wiki/Inverse_gamma_distribution)). Here, the Lévy distribution is a special case of a [Pearson type V distribution](wikipedia://en/1804023#The_Pearson_type_V_distribution).
- If $Y \sim \operatorname{Normal}(\mu, \sigma^2)$ ([normal distribution](wikipedia://en/21462)), then $(Y - \mu)^{-2} \sim \operatorname{Levy}(0, 1/\sigma^2).$
- If $Y \sim \operatorname{Normal}(\mu, 1/c)$, then $(Y - \mu)^{-2} \sim \operatorname{Levy}(0, c)$.
- If $X \sim \operatorname{Levy}(\mu, c)$, then $X \sim \operatorname{Stable}(1/2, 1, c, \mu)$ ([stable distribution](wikipedia://en/1117869)).
- If $X \sim \operatorname{Levy}(0, c)$, then $X\,\sim\,\operatorname{Scale-inv-\chi^2}(1, c)$ ([scaled-inverse-chi-squared distribution](https://en.wikipedia.org/wiki/Scaled-inverse-chi-squared_distribution)).
- If $X \sim \operatorname{Levy}(\mu, c)$, then $(X - \mu)^{-1/2} \sim \operatorname{FoldedNormal}(0, 1/\sqrt{c})$ ([folded normal distribution](wikipedia://en/6260959)).

## Random-sample generation {#Random-sample_generation}

Random samples from the Lévy distribution can be generated using [inverse transform sampling](wikipedia://en/45705). Given a random variate *U* drawn from the [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on the unit interval (0, 1\], the variate *X* given by[^o7]

$$X = F^{-1}(U) = \frac{c}{(\Phi^{-1}(1 - U/2))^2} + \mu$$

is Lévy-distributed with location $\mu$ and scale $c$. Here $\Phi(x)$ is the cumulative distribution function of the standard [normal distribution](wikipedia://en/21462).

## Applications {#Applications}

- The frequency of [geomagnetic reversals](wikipedia://en/2203131) appears to follow a Lévy distribution
- The [time of hitting](wikipedia://en/7059985) a single point, at distance $\alpha$ from the starting point, by the [Brownian motion](wikipedia://en/149984) has the Lévy distribution with $c=\alpha^2$. (For a Brownian motion with drift, this time may follow an [inverse Gaussian distribution](wikipedia://en/5246161), which has the Lévy distribution as a limit.)
- The length of the path followed by a photon in a turbid medium follows the Lévy distribution.[^o10]
- A [Cauchy process](wikipedia://en/38454328) can be defined as a [Brownian motion](wikipedia://en/4436) [subordinated](wikipedia://en/38445971) to a process associated with a Lévy distribution.[^o11]
