# Artin–Mazur zeta function

::: {#o1 .subject cue=lead name="Artin–Mazur zeta function"}

In [mathematics](wikipedia://en/18831), the **Artin–Mazur [zeta function](https://en.wikipedia.org/wiki/Zeta_function)**, named after [Michael Artin](wikipedia://en/1519821) and [Barry Mazur](wikipedia://en/23087679), is a function that is used for studying the [iterated functions](wikipedia://en/1448702) that occur in [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems) and [fractals](https://en.wikipedia.org/wiki/Fractals).

:::

It is defined from a given function $f$ as the [formal power series](wikipedia://en/60012)

$$\zeta_f(z)=\exp \left(\sum_{n=1}^\infty \bigl|\operatorname{Fix} (f^n)\bigr| \frac {z^n}{n}\right),$$

where $\operatorname{Fix} (f^n)$ is the set of [fixed points](wikipedia://en/449738) of the $n$th iterate of the function $f$, and $|\operatorname{Fix} (f^n)|$ is the number of fixed points (i.e. the [cardinality](wikipedia://en/6174) of that set).

Note that the zeta function is defined only if the set of fixed points is finite for each $n$. This definition is formal in that the series does not always have a positive [radius of convergence](wikipedia://en/61476).

The Artin–Mazur zeta function is invariant under [topological conjugation](wikipedia://en/5506149).

The [Milnor–Thurston theorem](wikipedia://en/16305705) states that the Artin–Mazur zeta function of an interval map $f$ is the inverse of the [kneading determinant](https://en.wikipedia.org/wiki/Kneading_determinant) of $f$.

## Analogues {#Analogues}

The Artin–Mazur zeta function is formally similar to the [local zeta function](wikipedia://en/396014), when a [diffeomorphism](wikipedia://en/8564) on a compact manifold replaces the [Frobenius mapping](https://en.wikipedia.org/wiki/Frobenius_mapping) for an [algebraic variety](wikipedia://en/248808) over a [finite field](wikipedia://en/11615).

The [Ihara zeta function](wikipedia://en/1342362) of a graph can be interpreted as an example of the Artin–Mazur zeta function.
