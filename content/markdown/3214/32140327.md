# Bernstein's theorem (approximation theory)

::: {#o1 .subject cue=lead name="Bernstein's theorem"}

In [approximation theory](wikipedia://en/1092713), **Bernstein's theorem** is a converse to [Jackson's theorem](wikipedia://en/9356047).[^o2] The first results of this type were proved by [Sergei Bernstein](wikipedia://en/976516) in 1912.[^o3]

:::

For approximation by [trigonometric polynomials](https://en.wikipedia.org/wiki/Trigonometric_polynomials), the result is as follows:

Let $f: [0, 2\pi] \to \mathbb{C}$ be a $2 \pi$ [periodic function](wikipedia://en/76848), and assume $r$ is a [positive integer](wikipedia://en/21474), and that $0 < \alpha < 1$ . If there exists some fixed number $~~ k( f ) > 0 ~~$ and a sequence of [trigonometric polynomials](wikipedia://en/591568) $~~ \Bigl(\ P_{n_0}(x)\ ,\ P_{n_0 + 1}(x)\ ,\ P_{n_0 + 2}(x)\ ,\ \ldots \Bigr) ~~$ for which $~~ \deg P_n = n ~~$ and $~~ \sup_{0 \leq x \leq 2\pi} \Bigl|f(x) - P_n(x)\Bigr| \leq \frac{\ k(f)\ }{~~ n^{r + \alpha}\ }\ ,$ for every $\ n \ge n_0\ ,$ then $f(x) = P_{n_{0}}(x) + \varphi(x)$ , where the function $\varphi(x)$ has a bounded $r$ th derivative which is [$\alpha$-Hölder continuous](wikipedia://en/4005892).
