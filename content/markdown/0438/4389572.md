# Factorial moment generating function

::: {#o1 .subject cue=lead name="Factorial moment generating function"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **factorial moment generating function** (FMGF) of the [probability distribution](wikipedia://en/23543) of a [real-valued](wikipedia://en/20646438) [random variable](wikipedia://en/25685) *X* is defined as

:::

$$M_X(t)=\operatorname{E}\bigl[t^{X}\bigr]$$

for all [complex numbers](wikipedia://en/5826) *t* for which this [expected value](wikipedia://en/9653) exists. This is the case at least for all *t* on the [unit circle](wikipedia://en/27072071) $|t|=1$, see [characteristic function](wikipedia://en/3229401). If *X* is a discrete random variable taking values only in the set {0,1, ...} of non-negative [integers](wikipedia://en/14563), then $M_X$ is also called [probability-generating function](https://en.wikipedia.org/wiki/Probability-generating_function) (PGF) of *X* and $M_X(t)$ is well-defined at least for all *t* on the [closed](wikipedia://en/47279) [unit disk](wikipedia://en/252738) $|t|\le1$.

The factorial moment generating function generates the [factorial moments](wikipedia://en/790823) of the [probability distribution](wikipedia://en/23543). Provided $M_X$ exists in a [neighbourhood](wikipedia://en/1529485) of *t* = 1, the *n*th factorial moment is given by [^o2]

$$\operatorname{E}[(X)_n]=M_X^{(n)}(1)=\left.\frac{\mathrm{d}^n}{\mathrm{d}t^n}\right|_{t=1} M_X(t),$$

where the [Pochhammer symbol](https://en.wikipedia.org/wiki/Pochhammer_symbol) (*x*)<sub>*n*</sub> is the [falling factorial](https://en.wikipedia.org/wiki/Falling_factorial)

$$(x)_n = x(x-1)(x-2)\cdots(x-n+1).\,$$

(Many mathematicians, especially in the field of [special functions](https://en.wikipedia.org/wiki/Special_function), use the same notation to represent the [rising factorial](https://en.wikipedia.org/wiki/Rising_factorial).)

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### Poisson distribution {#Poisson_distribution}

Suppose *X* has a [Poisson distribution](wikipedia://en/23009144) with [expected value](wikipedia://en/9653) λ, then its factorial moment generating function is

$$M_X(t) =\sum_{k=0}^\infty t^k\underbrace{\operatorname{P}(X=k)}_{=\,\lambda^ke^{-\lambda}/k!} =e^{-\lambda}\sum_{k=0}^\infty \frac{(t\lambda)^k}{k!} = e^{\lambda(t-1)},\qquad t\in\mathbb{C},$$

(use the [definition of the exponential function](wikipedia://en/9678#Formal_definition)) and thus we have

$$\operatorname{E}[(X)_n]=\lambda^n.$$

:::
