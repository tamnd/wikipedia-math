# Miscellaneous Mathematical Symbols-B

::: {#o4 .subject cue=lead name="Miscellaneous Mathematical Symbols-B"}

*Image: UCB\_Miscellaneous\_Mathematical\_Symbols-B.png.* Graphical representation of the Miscellaneous Mathematical Symbols-B Unicode block

**Miscellaneous Mathematical Symbols-B** is a [Unicode block](https://en.wikipedia.org/wiki/Unicode_block) containing miscellaneous mathematical symbols, including brackets, angles, and circle symbols.

:::

## Block {#Block}

::: {#o7 .statement kind=statement/generalization cue=heading name="Variant"}

## Variant {#Variant}

The Miscellaneous Mathematical Symbols-B block has one variation sequence defined for a [standardized variant](https://en.wikipedia.org/wiki/Variant_form_%28Unicode%29). Variation selector-1 (VS1) (U+FE00) can be used with 29B7 to request a [glyph](https://en.wikipedia.org/wiki/Glyph) where the parallel lines touch the circle.[^o8]

:::

## Usage {#Usage}

Some of these symbols are used in [Z notation](https://en.wikipedia.org/wiki/Z_notation). Specifically

- 2981
- 2982
- 2987
- 2988
- 2989
- 298A

The last two symbols are used in [combinatorial game theory](wikipedia://en/22537688)

- 29FE
- 29FF
