# Number Theory Library

::: {#o1 .subject cue=lead name="Number Theory Library"}

**NTL** is a [C++](https://en.wikipedia.org/wiki/C++) library for doing [number theory](wikipedia://en/21527). NTL supports arbitrary length [integer](wikipedia://en/14563) and [arbitrary precision](https://en.wikipedia.org/wiki/Arbitrary_precision_arithmetic) [floating point](https://en.wikipedia.org/wiki/Floating_point) [arithmetic](wikipedia://en/3118), [finite fields](https://en.wikipedia.org/wiki/Finite_fields), [vectors](wikipedia://en/32370), [matrices](wikipedia://en/20556859), [polynomials](https://en.wikipedia.org/wiki/Polynomials), [lattice basis reduction](https://en.wikipedia.org/wiki/Lattice_basis_reduction) and basic [linear algebra](wikipedia://en/18422). NTL is [free software](https://en.wikipedia.org/wiki/Free_software) released under the [GNU Lesser General Public License](https://en.wikipedia.org/wiki/GNU_Lesser_General_Public_License) v2.1.[^o4]
