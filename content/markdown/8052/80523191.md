# Knuth–Eve algorithm

::: {#o1 .subject cue=lead name="Knuth–Eve algorithm"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), the **Knuth–Eve algorithm** is an [algorithm](wikipedia://en/775) for [polynomial evaluation](wikipedia://en/64691694). It [preprocesses](wikipedia://en/64691694#Evaluation_with_preprocessing) the coefficients of the polynomial to reduce the number of multiplications required at [runtime](https://en.wikipedia.org/wiki/Execution_%28computing%29#Runtime).

:::

Ideas used in the algorithm were originally proposed by [Donald Knuth](wikipedia://en/8095) in 1962. His procedure opportunistically exploits structure in the polynomial being evaluated.[^o14] In 1964, James Eve determined for which polynomials this structure exists, and gave a simple method of "preconditioning" polynomials (explained below) to endow them with that structure.[^o15]

::: {#o3 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

### Preliminaries {#Preliminaries}

Consider an arbitrary polynomial $p \in \mathbb{R}[x]$ of [degree](wikipedia://en/5930652) $n$. Assume that $n \geq 3$. Define $m$ such that: if $n$ is odd then $n = 2m+1$, and if $n$ is even then $n = 2m+2$.[^o15]

Unless otherwise stated, all variables in this article represent either [real numbers](wikipedia://en/20646438) or univariate [polynomials](wikipedia://en/23000) with real coefficients.[^o14][^o15] All operations in this article are done over $\mathbb{R}$.[^o15]

Again, the goal is to create an algorithm that returns $p(x)$ given any $x$. The algorithm is allowed to depend on the polynomial $p$ itself, since its coefficients are known in advance.[^o14]

### Overview {#Overview}

#### Key idea {#Key_idea}

Using [polynomial long division](wikipedia://en/314205), we can write

$$p(x) = q(x) \cdot (x^2 - \alpha) + (\beta x + \gamma),$$

where $x^2 - \alpha$ is the divisor. Picking a value for $\alpha$ fixes both the quotient $q$ and the coefficients in the remainder $\beta$ and $\gamma$. The key idea is to cleverly choose $\alpha$ such that $\beta = 0$, so that

$$p(x) = q(x) \cdot (x^2 - \alpha) + \gamma.$$

[^o16] This way, no operations are needed to compute the remainder polynomial, since it's just a constant. We apply this procedure [recursively](wikipedia://en/4044867) to $q$, expressing

$$p(x) = \left( \left( q(x) \cdot (x^2 - \alpha_m) + \gamma_m \right) \cdots \right) \cdot (x^2 - \alpha_1) + \gamma_1.$$

After $m$ recursive calls, the quotient $q$ is either a [linear](wikipedia://en/39712387) or a [quadratic](wikipedia://en/187240) polynomial. In this base case, the polynomial can be evaluated with (say) [Horner's method](wikipedia://en/14263).[^o14][^o16][^o19]

#### "Preconditioning" {#"Preconditioning"}

For arbitrary $p$, it may not be possible to force $\beta = 0$ at every step of the recursion.[^o14] Consider the polynomials $p^e$ and $p^o$ with coefficients taken from the even and odd terms of $p$ respectively, so that

$$p(x) = p^e(x^2) + x \cdot p^o(x^2).$$

If every [root](wikipedia://en/264210#Polynomial_roots) of $p^o$ is real, then it is possible to write $p$ in the form given above. Each $\alpha_i$ is a different root of $p^o$, counting [multiple roots](wikipedia://en/19211790#Multiplicity_of_a_root_of_a_polynomial) as distinct.[^o16] Furthermore, if at least $n-1$ roots of $p$ lie in one half of the [complex plane](wikipedia://en/217628), then every root of $p^o$ is real.[^o15]

Ultimately, it may be necessary to "precondition" $p$ by shifting it by setting $p(x) \gets p(x + t)$ for some $t$ to endow it with the structure that most of its roots lie in one half of the complex plane. At runtime, this shift has to be "undone" by first setting $x \gets x - t$.[^o15]

### Preprocessing step {#Preprocessing_step}

The following algorithm is run once for a given polynomial $p$.[^o14][^o16] At this point, the values of $x$ that $p$ will be evaluated on are not known.[^o14]

blue

- Let $r_1, \cdots, r_n \in \mathbb{C}$ be the complex roots of $p$, sorted in descending order by real part
- Choose any $t \geq \text{Re}(r_2)$
- Set $p \gets p(x + t)$
- Let $p^e$ and $p^o$ be the polynomials such that $p(x) = p^e(x^2) + x \cdot p^o(x^2)$
- Let $\alpha_1, \cdots \alpha_m \in \mathbb{R}$ be the roots of $p^o$. All of its roots will be real.
- Initialize $q \gets p$
- For $i \gets 1, \cdots, m$:
  - Divide $q$ by $x^2 - \alpha_i$ to get quotient $q^\prime \in \mathbb{R}[x]$ and remainder $\gamma_i \in \mathbb{R}$. The remainder will be a constant polynomial a number.
  - Set $q \gets q^\prime$
- *Output:* The derived values $t$, $\alpha_1, \cdots, \alpha_m$, and $\gamma_1, \cdots, \gamma_m$; as well as the base-case polynomial $q$

#### Better choice of t {#Better_choice_of_t}

While any $t \geq \text{Re}(r_2)$ can work, it is possible to remove one addition during evaluation if $t$ is also chosen such that two roots of $p(x + t)$ are symmetric about the origin. In that case, $\alpha_1$ can be chosen such that the shifted polynomial has a factor of $x^2 - \alpha_1$, so $\gamma_1 = 0$. It is always possible to find such a $t$.[^o15]

One possible algorithm for choosing $t$ is:

blue

- If $r_1 \in \mathbb{R}$:
  - If $r_2 \in \mathbb{R}$: $t = \tfrac{1}{2} (r_1 + r_2)$
  - Else: $t = \text{Re}(r_2)$
- Else: $t = \text{Re}(r_1)$

### Evaluation step {#Evaluation_step}

The following algorithm evaluates $p$ at some, now known, point $x$.[^o14][^o15][^o16][^o19]

blue

Set $x \gets x - t$

Let $s = x^2$. Compute this once so it can be reused.

Compute $y \gets q(x)$ using [Horner's method](wikipedia://en/14263)

For $i \gets m, \cdots, 2, 1$:

Let $y \gets y \cdot (s - \alpha_i) + \gamma_i$

*Output:* $y$

Assuming $t$ is chosen optimally, $\gamma_1 = 0$. So, the final iteration of the loop can instead run

$$y \gets y \cdot (s - \alpha_i),$$

saving an addition.[^o15]

:::

## Analysis {#Analysis}

In total, evaluation using the Knuth–Eve algorithm for a polynomial of degree $n$ requires $n$ additions and $\lfloor n/2 \rfloor + 2$ multiplications, assuming $t$ is chosen optimally.[^o15]

No algorithm to evaluate a given polynomial of degree $n$ can use fewer than $n$ additions or fewer than $\lceil n/2 \rceil$ multiplications during evaluation. This result assumes only addition and multiplication are allowed during both preprocessing and evaluation.[^o17]

The Knuth–Eve algorithm is not [well-conditioned](wikipedia://en/6934).[^o18]
