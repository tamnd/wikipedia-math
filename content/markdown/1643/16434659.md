# IsaPlanner

::: {#o1 .subject cue=lead name="IsaPlanner"}

**IsaPlanner**[^o2] is a [proof planner](https://en.wikipedia.org/wiki/Proof_planning) for the interactive [proof assistant](wikipedia://en/1258607), [Isabelle](https://en.wikipedia.org/wiki/Isabelle_theorem_prover), originally developed by Lucas Dixon.[^o3]

:::
