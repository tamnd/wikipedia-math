# Weak order unit

::: {#o1 .subject cue=lead name="Weak order unit"}

In mathematics, specifically in [order theory](wikipedia://en/361924) and [functional analysis](wikipedia://en/11180), an element $x$ of a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) $X$ is called a **weak order unit** in $X$ if $x \geq 0$ and also for all $y \in X,$ $\inf \{ x, |y| \} = 0 \text{ implies } y = 0.$[^n1]

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- If $X$ is a [separable](wikipedia://en/27855) [Fréchet](wikipedia://en/233801) [topological vector lattice](wikipedia://en/63989962) then the set of weak order units is dense in the positive cone of $X.$[^n2]

:::
