# Abstract m-space

::: {#o1 .subject cue=lead name="Abstract m-space"}

In mathematics, specifically in [order theory](wikipedia://en/361924) and [functional analysis](wikipedia://en/11180), an **abstract *m*-space** or an **AM-space** is a [Banach lattice](wikipedia://en/54391334) $(X, \| \cdot \|)$ whose norm satisfies $\left\| \sup \{ x, y \} \right\| = \sup \left\{ \| x \|, \| y \| \right\}$ for all *x* and *y* in the positive cone of *X*. We say that an AM-space *X* is an **AM-space with unit** if in addition there exists some $u \ge 0$ in *X* such that the interval $[-u, u] := \{ z \in X : -u \le z\text{ and } z \le u \}$ is equal to the unit ball of *X*; such an element *u* is unique and an [order unit](wikipedia://en/38017102) of *X*.[^n1]

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

The strong dual of an [AL-space](https://en.wikipedia.org/wiki/AL-space) is an AM-space with unit.[^n1]

If *X* is an [Archimedean ordered](https://en.wikipedia.org/wiki/Archimedean_order) [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice), *u* is an [order unit](wikipedia://en/38017102) of *X*, and *p*<sub>*u*</sub> is the [Minkowski functional](wikipedia://en/3510908) of $[u, -u] := \{ x \in X : -u \leq x \text{ and } x \leq x \},$ then the complete of the [semi-normed space](https://en.wikipedia.org/wiki/Semi-normed_space) (*X*, *p*<sub>*u*</sub>) is an AM-space with unit *u*.[^n1]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every AM-space is isomorphic (as a Banach lattice) with some closed vector sublattice of some suitable $C_{\mathbb{R}}\left( X \right)$.[^n1] The strong dual of an AM-space with unit is an [AL-space](https://en.wikipedia.org/wiki/AL-space).[^n1]

If *X* ≠ { 0 } is an AM-space with unit then the set *K* of all extreme points of the positive face of the dual unit ball is a non-empty and weakly compact (i.e. $\sigma\left( X^{\prime}, X \right)$-compact) subset of $X^{\prime}$ and furthermore, the evaluation map $I : X \to C_{\mathbb{R}} \left( K \right)$ defined by $I(x) := I_x$ (where $I_x : K \to \mathbb{R}$ is defined by $I_x(t) = \langle x, t \rangle$) is an isomorphism.[^n1]
