# Quasi-interior point

Numbers

::: {#o1 .subject cue=lead name="Quasi-interior point"}

In mathematics, specifically in [order theory](wikipedia://en/361924) and [functional analysis](wikipedia://en/11180), an element $x$ of an [ordered topological vector space](wikipedia://en/63988132) $X$ is called a **quasi-interior point** of the positive cone $C$ of $X$ if $x \geq 0$ and if the order interval $[0, x] := \{ z \in X : 0 \leq z \text{ and } z \leq x \}$ is a total subset of $X$; that is, if the linear span of $[0, x]$ is a dense subset of $X.$[^n1]

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $X$ is a [separable](wikipedia://en/27855) [metrizable](wikipedia://en/64278078) [locally convex](wikipedia://en/518844) [ordered topological vector space](wikipedia://en/63988132) whose positive cone $C$ is a complete and total subset of $X,$ then the set of quasi-interior points of $C$ is dense in $C.$[^n1]

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

If $1 \leq p < \infty$ then a point in $L^p(\mu)$ is quasi-interior to the positive cone $C$ if and only it is a weak order unit, which happens if and only if the element (which recall is an equivalence class of functions) contains a function that is $>\, 0$ [almost everywhere](wikipedia://en/44688) (with respect to $\mu$).[^n1]

A point in $L^\infty(\mu)$ is quasi-interior to the positive cone $C$ if and only if it is interior to $C.$[^n1]

:::
