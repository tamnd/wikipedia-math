# Eleven-point conic

::: {#o1 .subject cue=lead name="Eleven-point conic"}

In geometry, an **eleven-point conic** is a [conic](https://en.wikipedia.org/wiki/Conic) associated to four points and a line, containing 11 special points.(Baker 1922, p. 49)

:::
