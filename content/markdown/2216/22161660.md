# AbsoluteTelnet

::: {#o2 .subject cue=lead name="AbsoluteTelnet"}

**AbsoluteTelnet** is a software terminal client for [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) that implements [Telnet](https://en.wikipedia.org/wiki/Telnet), [SSH](wikipedia://en/28814) 1 and 2, [SFTP](wikipedia://en/428987), [TAPI](https://en.wikipedia.org/wiki/Telephony_Application_Programming_Interface) Dialup and direct [COM port](https://en.wikipedia.org/wiki/COM_%28hardware_interface%29) connections. It is [commercial software](https://en.wikipedia.org/wiki/Proprietary_software), originally released in 1999 and is still in regular development by Brian Pence of Celestial Software.

:::

## Features {#Features}

Some features of AbsoluteTelnet:

- Post quantum key exchange including mlkem768x25519-sha256 and sntrup761x25519-sha512
- Support for external authentication agents (pageant, openssh, 1Password, bitwarden)
- Emulates [VT52](https://en.wikipedia.org/wiki/VT52), [VT100](https://en.wikipedia.org/wiki/VT100), [VT220](https://en.wikipedia.org/wiki/VT220), [VT320](https://en.wikipedia.org/wiki/VT320), [ANSI](https://en.wikipedia.org/wiki/ANSI_escape_code), [Xterm](https://en.wikipedia.org/wiki/Xterm), [QNX](https://en.wikipedia.org/wiki/QNX), SCO-ANSI, [ANSIBBS](https://en.wikipedia.org/wiki/ANSI_art), and WYSE60
- [Password](wikipedia://en/24304), [Public-key](https://en.wikipedia.org/wiki/Public-key), keyboard-interactive, [Smartcard](https://en.wikipedia.org/wiki/Smartcard) and [GSSAPI](https://en.wikipedia.org/wiki/Generic_Security_Services_Application_Program_Interface) authentication support
- Support [Triple DES](wikipedia://en/48375), [TWOFISH](wikipedia://en/26508356), [BLOWFISH](wikipedia://en/3940), [AES](wikipedia://en/1260), [ARCFOUR](wikipedia://en/25831), [CAST128](https://en.wikipedia.org/wiki/Cast-128) ciphers in CBC or CTR mode as well as AEAD ciphers such as AES/GCM.
- [Tabbed interface](https://en.wikipedia.org/wiki/Tab_%28interface%29) for multiple concurrent connections (Dockable)
- Scripting support using VBScript
- [Unicode](https://en.wikipedia.org/wiki/Unicode) 5.0 support, including bidirectional text, surrogates, combining characters, etc...
- Passthru printing
- [IPv6](https://en.wikipedia.org/wiki/IPv6) support.
- [IDNA](https://en.wikipedia.org/wiki/Internationalized_domain_name) support
- Localized into 8 languages (English, German, French, Portuguese, Chinese, Russian, Norwegian and Hungarian)
- Pocket PC support
- [XMODEM](https://en.wikipedia.org/wiki/XMODEM), [YMODEM](https://en.wikipedia.org/wiki/YMODEM), and [ZMODEM](https://en.wikipedia.org/wiki/ZMODEM) file transfer for all terminal connections
- [SSH File Transfer Protocol](wikipedia://en/428987) for ssh2 connections only
