# Hintikka set

::: {#o1 .subject cue=lead name="Hintikka set"}

In mathematical logic, a **Hintikka set** is a set of [logical formulas](https://en.wikipedia.org/wiki/Formula_%28logic%29) whose elements satisfy the following properties:

:::

1. An atom or its [conjugate](wikipedia://en/161019) can appear in the set but not both,
1. If a formula in the set has a main operator that is of "conjunctive-type", then its two operands appear in the set,
1. If a formula in the set has a main operator that is of "disjunctive-type", then at least one of its two operands appears in the set.

The exact meaning of "conjunctive-type" and "disjunctive-type" is defined by the method of [semantic tableaux](https://en.wikipedia.org/wiki/Semantic_tableaux).

Hintikka sets arise when attempting to prove completeness of propositional logic using [semantic tableaux](https://en.wikipedia.org/wiki/Semantic_tableaux). They are named after [Jaakko Hintikka](wikipedia://en/1710903).

## Propositional Hintikka sets {#Propositional_Hintikka_sets}

In a semantic tableau for [propositional logic](https://en.wikipedia.org/wiki/Propositional_calculus), Hintikka sets can be defined using [uniform notation for propositional tableaux](wikipedia://en/1027229#Propositional_tableau_with_unification). The elements of a propositional Hintikka set S satisfy the following conditions:[^o3]

1. No [variable](wikipedia://en/1557562) and its conjugate are both in S,
1. For any $\alpha$ in S, its components $\alpha_1, \alpha_2$ are both in S,
1. For any $\beta$ in S, at least one of its components $\beta_1,\beta_2$ are in S.

If a set S is a Hintikka set, then S is [satisfiable](https://en.wikipedia.org/wiki/Satisfiable).
