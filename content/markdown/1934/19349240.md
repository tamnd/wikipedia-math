# Guarded logic

::: {#o1 .subject cue=lead name="Guarded logic"}

**Guarded logic** is a [choice set](https://en.wikipedia.org/wiki/Choice_set) of [dynamic logic](wikipedia://en/31631871) involved in choices, where outcomes are limited.

:::

A simple example of guarded logic is as follows: if X is true, then Y, else Z can be expressed in dynamic logic as (X?;Y)∪(~X?;Z). This shows a guarded logical choice: if X holds, then X?;Y is equal to Y, and ~X?;Z is blocked, and Y∪block is also equal to Y. Hence, when X is true, the primary performer of the action can only take the Y branch, and when false the Z branch.[^o2]

A real-world example is the idea of [paradox](wikipedia://en/24390): something cannot be both true and false. A guarded logical choice is one where any change in true affects all decisions made down the line.[^o3]

## History {#History}

Before the use of guarded logic there were two major terms used to interpret modal logic. [Mathematical logic](wikipedia://en/19636) and [database theory](https://en.wikipedia.org/wiki/Database_theory) (Artificial Intelligence) were first-order predicate logic. Both terms found sub-classes of first-class logic and efficiently used in solvable languages which can be used for research. But neither could explain powerful fixed-point extensions to modal style logics.

Later [Moshe Y. Vardi](https://en.wikipedia.org/wiki/Moshe_Y._Vardi)[^o5] made a conjecture that a tree model would work for many modal style logics. The guarded fragment of [first-order logic](wikipedia://en/10983) was first introduced by [Hajnal Andréka](wikipedia://en/61779644), [István Németi](https://en.wikipedia.org/wiki/István_Németi) and [Johan van Benthem](wikipedia://en/1498176) in their article Modal languages and bounded fragments of predicate logic. They successfully transferred key properties of [description](wikipedia://en/183503), [modal](wikipedia://en/333365), and [temporal logic](wikipedia://en/321481) to predicate logic. It was found that the robust decidability of guarded logic could be generalized with a tree model property. The tree model can also be a strong indication that guarded logic extends modal framework which retains the basics of modal logics.

[Modal logics](wikipedia://en/333365) are generally characterized by invariances under [bisimulation](wikipedia://en/397571). It also so happens that invariance under bisimulation is the root of tree model property which helps towards defining [automata theory](wikipedia://en/103356).

## Types of guarded logic {#Types_of_guarded_logic}

Within Guarded Logic there exists numerous guarded objects. The first being guarded fragment which are first-order logic of modal logic. Guarded fragments generalize modal quantification through finding relative patterns of quantification. The syntax used to denote guarded fragment is **GF**. Another object is [guarded fixed point logic](https://en.wikipedia.org/wiki/Guarded_fixed_point_logic) denoted **μGF** naturally extends guarded fragment from fixed points of least to greatest. [Guarded bisimulations](https://en.wikipedia.org/wiki/Guarded_bisimulations) are objects which when analyzing guarded logic. All relations in a slightly modified standard [relational algebra](wikipedia://en/175285) with guarded bisimulation and first-order definable are known as *guarded relational algebra*. This is denoted using **GRA**.

Along with first-order guarded logic objects, there are objects of second-order guarded logic. It is known as [Guarded Second-Order Logic](https://en.wikipedia.org/wiki/Guarded_Second-Order_Logic) and denoted **GSO**. Similar to [second-order logic](wikipedia://en/341428), guarded second-order logic quantifies whose range over guarded relations restrict it semantically. This is different from second-order logic which the range is restricted over arbitrary relations.[^o7]

## Definitions of guarded logic {#Definitions_of_guarded_logic}

Let **B** be a relational structure with universe *B* and vocabulary τ.

*i)* A set X ⊆ B is *guarded* in **B** if there exists a ground atom α(b\_1, ..., b\_k) in **B** such that X = {b\_1, ..., b\_k}.

*ii)* A τ-structure **A**, in particular a substructure A ⊆ B, is *guarded* if its universe is a guarded set in *A* (in *B*).

*iii)* A tuple (b\_1, ..., b\_n) ∈ B^n is *guarded* in **B** if {b\_1, ..., b\_n} ⊆ X for some guarded set X ⊆ B.

*iv)* A tuple (b\_1, ..., b\_k) ∈ B^k is a guarded list in **B** if its components are pairwise distinct and {b\_1, ..., b\_k} is a guarded set. The empty list is taken to be a guarded list.

*v)* A relation X ⊆ B^n is *guarded* if it only consists of guarded tuples.[^o10]

### Guarded bisimulation {#Guarded_bisimulation}

A *guarded bisimulation* between two τ-structures **A** and **B** is a non-empty set *I* of finite partial isomorphic *f: X → Y* from **A** to **B** such that the back and forth conditions are satisfied.

**Back:** For every *f: X → Y* in *I* and for every guarded set *Y\` ⊆ B*, there exists a partial isomorphic *g: X\` → Y\`* in *I* such that *f^-1* and *g^-1* agree on *Y ∩ Y\`*.

**Forth** For every *f: X → Y* in *I* and for every guarded set *X\` ⊆ A*, there exists a partial isomorphic *g: X\` → Y\`* in *I* such that *f* and *g* agree on *X ∩ X\`*.
