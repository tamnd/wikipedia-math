# Bessel potential

::: {#o1 .subject cue=lead name="Bessel potential"}

In [mathematics](wikipedia://en/18831), the **Bessel potential** is a [potential](wikipedia://en/1431342) (named after [Friedrich Wilhelm Bessel](wikipedia://en/11574)) similar to the [Riesz potential](wikipedia://en/6779393) but with better decay properties at infinity.

:::

If *s* is a complex number with positive real part then the Bessel potential of order *s* is the operator

$$(I-\Delta)^{-s/2}$$

where Δ is the [Laplace operator](wikipedia://en/174706) and the [fractional power](wikipedia://en/229939) is defined using Fourier transforms.

[Yukawa potentials](https://en.wikipedia.org/wiki/Yukawa_potential) are particular cases of Bessel potentials for $s=2$ in the 3-dimensional space.

## Representation in Fourier space {#Representation_in_Fourier_space}

The Bessel potential acts by multiplication on the [Fourier transforms](wikipedia://en/52247): for each $\xi \in \mathbb{R}^d$

$$\mathcal{F}((I-\Delta)^{-s/2} u) (\xi)= \frac{\mathcal{F}u (\xi)}{(1 + 4 \pi^2 \vert \xi \vert^2)^{s/2}}.$$

## Integral representations {#Integral_representations}

When $s > 0$, the Bessel potential on $\mathbb{R}^d$ can be represented by

$$(I - \Delta)^{-s/2} u = G_s \ast u,$$

where the Bessel kernel $G_s$ is defined for $x \in \mathbb{R}^d \setminus \{0\}$ by the integral formula [^o4]

$$G_s (x) = \frac{1}{(4 \pi)^{s/2}\Gamma (s/2)} \int_0^\infty \frac{e^{-\frac{\pi \vert x \vert^2}{y}-\frac{y}{4 \pi}}}{y^{1 + \frac{d - s}{2}}}\,\mathrm{d}y.$$

Here $\Gamma$ denotes the [Gamma function](wikipedia://en/12316). The Bessel kernel can also be represented for $x \in \mathbb{R}^d \setminus \{0\}$ by[^o5]

$$G_s (x) = \frac{e^{-\vert x \vert}}{(2\pi)^\frac{d-1}{2} 2^\frac{s}{2} \Gamma (\frac{s}{2}) \Gamma (\frac{d - s + 1}{2})} \int_0^\infty e^{-\vert x \vert t} \Big(t + \frac{t^2}{2}\Big)^\frac{d - s - 1}{2} \,\mathrm{d}t.$$

This last expression can be more succinctly written in terms of a modified [Bessel function](wikipedia://en/4700),[^o6] for which the potential gets its name:

$$G_s(x)=\frac{1}{2^{(s-2)/2}(2\pi)^{d/2}\Gamma(\frac{s}{2})}K_{(d-s)/2}(\vert x \vert) \vert x \vert^{(s-d)/2}.$$

## Asymptotics {#Asymptotics}

At the origin, one has as $\vert x\vert \to 0$,[^o8]

$$G_s (x) = \frac{\Gamma (\frac{d - s}{2})}{2^s \pi^{s/2} \vert x\vert^{d - s}}(1 + o (1)) \quad \text{ if } 0 < s < d,$$

$$G_d (x) = \frac{1}{2^{d - 1} \pi^{d/2} }\ln \frac{1}{\vert x \vert}(1 + o (1)) ,$$

$$G_s (x) = \frac{\Gamma (\frac{s - d}{2})}{2^s \pi^{s/2} }(1 + o (1)) \quad \text{ if }s > d.$$

In particular, when $0 < s < d$ the Bessel potential behaves asymptotically as the [Riesz potential](wikipedia://en/6779393).

At infinity, one has, as $\vert x\vert \to \infty$,[^o9]

$$G_s (x) = \frac{e^{-\vert x \vert}}{2^\frac{d + s - 1}{2} \pi^\frac{d - 1}{2} \Gamma (\frac{s}{2}) \vert x \vert^\frac{d + 1 - s}{2}}(1 + o (1)).$$
