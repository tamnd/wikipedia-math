# T(1) theorem

::: {#o1 .subject cue=lead name="T(1) theorem"}

In mathematics, the **T(1) theorem**, first proved by (David Journé 1984), describes when an operator *T* given by a [kernel](https://en.wikipedia.org/wiki/Kernel_%28integral_operator%29) can be extended to a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) on the [Hilbert space](wikipedia://en/20598932) *L*<sup>2</sup>(**R**<sup>*n*</sup>). The name *T*(1) theorem refers to a condition on the [distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) *T*(1), given by the operator *T* applied to the function 1.

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Suppose that *T* is a [continuous operator](https://en.wikipedia.org/wiki/Continuous_operator) from [Schwartz functions](https://en.wikipedia.org/wiki/Schwartz_function) on **R**<sup>*n*</sup> to [tempered distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29), so that *T* is given by a kernel *K* which is a distribution. Assume that the kernel is standard, which means that off the diagonal it is given by a function satisfying certain conditions. Then the *T*(1) theorem states that *T* can be extended to a bounded operator on the Hilbert space *L*<sup>2</sup>(**R**<sup>*n*</sup>) if and only if the following conditions are satisfied:

- *T*(1) is of [bounded mean oscillation](wikipedia://en/4694026) (where *T* is extended to an operator on bounded smooth functions, such as 1).
- *T*<sup>\*</sup>(1) is of bounded mean oscillation, where *T*<sup>\*</sup> is the [adjoint](wikipedia://en/644032) of *T*.
- *T* is weakly bounded, a weak condition that is easy to verify in practice.

:::
