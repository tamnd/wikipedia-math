# Zero object (algebra)

::: {#o1 .subject cue=lead name="Zero object"}

*Image: Terminal and initial object.svg.* [Morphisms](wikipedia://en/27716891) to and from the zero object

In [algebra](wikipedia://en/18716923), the **zero object** of a given [algebraic structure](wikipedia://en/106364) is, in the sense explained below, the simplest object of such structure. As a [set](wikipedia://en/26691) it is a [singleton](wikipedia://en/381798), and as a [magma](https://en.wikipedia.org/wiki/Magma_%28mathematics%29) has a [trivial](wikipedia://en/193059) structure, which is also an [abelian group](wikipedia://en/2974). The aforementioned abelian group structure is usually identified as [addition](wikipedia://en/61338), and the only element is called [zero](https://en.wikipedia.org/wiki/Zero), so the object itself is typically denoted as $\{0\}$. One often refers to *the* trivial object (of a specified [category](wikipedia://en/53759)) since every trivial object is [isomorphic](wikipedia://en/14828) to any other (under a unique isomorphism).

:::

Instances of the zero object include, but are not limited to the following:

- As a [group](wikipedia://en/19447), the **zero group** or **[trivial group](wikipedia://en/193059)**.
- As a [ring](wikipedia://en/48404), the **[zero ring](wikipedia://en/1872874)** or **trivial ring**.
- As an [algebra over a field](wikipedia://en/191788) or [algebra over a ring](https://en.wikipedia.org/wiki/Algebra_over_a_ring), the **trivial algebra**.
- As a [module](wikipedia://en/276410) (over a [ring](https://en.wikipedia.org/wiki/Ring_%28algebra%29) $R$), the **zero module**. The term **trivial module** is also used, although it may be ambiguous, as a *trivial G-module* is a [*G*-module](wikipedia://en/26068776) with a trivial action.
- As a [vector space](wikipedia://en/32370) (over a [field](wikipedia://en/10603) $R$), the **zero vector space**, **zero-dimensional vector space** or just **zero space**.

These objects are described jointly not only based on the common singleton and trivial group structure, but also because of shared category-theoretical properties.

In the last three cases the [scalar multiplication](wikipedia://en/244373) by an element of the base ring (or field) is defined as:

$\kappa0 = 0\,$, where $\kappa \in R$.

The most general of them, the zero module, is a [finitely-generated module](https://en.wikipedia.org/wiki/Finitely-generated_module) with an [empty](wikipedia://en/9566) generating set.

For structures requiring the multiplication structure inside the zero object, such as the [trivial ring](https://en.wikipedia.org/wiki/Trivial_ring), there is only one possible, $0 \times 0 = 0$, because there are no non-zero elements. This structure is [associative](https://en.wikipedia.org/wiki/Associativity) and [commutative](https://en.wikipedia.org/wiki/Commutative). A ring $R$ which has both an additive and multiplicative identity is trivial if and only if $1 = 0$, since this equality implies that for all $r$ within $R$,

$$r = r \times 1 = r \times 0 = 0 .$$

In this case it is possible to define [division by zero](wikipedia://en/185663), since the single element is its own multiplicative inverse. Some properties of $\{0\}$ depend on exact definition of the multiplicative identity; see *\#Unital structures* below.

Any trivial algebra is also a trivial ring. A trivial [algebra over a field](wikipedia://en/191788) is simultaneously a zero vector space considered below. Over a [commutative ring](wikipedia://en/61346), a trivial [algebra](https://en.wikipedia.org/wiki/Algebra_over_a_ring) is simultaneously a zero module.

The trivial ring is an example of a [rng of square zero](wikipedia://en/3405004#Rng_of_square_zero). A trivial algebra is an example of a [zero algebra](wikipedia://en/191788#Zero_algebra).

The zero-dimensional vector space is an especially ubiquitous example of a zero object, a [vector space](wikipedia://en/32370) over a field with an empty [basis](wikipedia://en/18420). It therefore has [dimension](https://en.wikipedia.org/wiki/Dimension_%28mathematics%29) zero. It is also a [trivial group](wikipedia://en/193059) over [addition](wikipedia://en/61338), and a *trivial module* mentioned above.

The zero ring, zero module and zero vector space are the [zero objects](https://en.wikipedia.org/wiki/Zero_object) of, respectively, the [category of pseudo-rings](https://en.wikipedia.org/wiki/Category_of_pseudo-rings), the [category of modules](wikipedia://en/11231812) and the [category of vector spaces](https://en.wikipedia.org/wiki/Category_of_vector_spaces). However, the zero ring is not a zero object in the [category of rings](wikipedia://en/15300181), since there is no [ring homomorphism](wikipedia://en/26411) of the zero ring in any other ring.

The zero object, by definition, must be a terminal object, which means that a [morphism](wikipedia://en/27716891) $A \to \{0\}$ must exist and be unique for an arbitrary object $A$. This morphism maps any element of $A$ to $0$.

The zero object, also by definition, must be an initial object, which means that a morphism $\{0\} \to A$ must exist and be unique for an arbitrary object $A$. This morphism maps $0$, the only element of $\{0\}$, to the zero element $0 \in A$, called the [zero vector](https://en.wikipedia.org/wiki/Zero_vector) in vector spaces. This map is a [monomorphism](wikipedia://en/59538), and hence its image is isomorphic to $\{0\}$. For modules and vector spaces, this [subset](wikipedia://en/27631) $\{0\} \subset A$ is the only empty-generated [submodule](https://en.wikipedia.org/wiki/Submodule) (or 0-dimensional [linear subspace](wikipedia://en/56357)) in each module (or vector space) $A$.

### Unital structures {#Unital_structures}

The $\{0\}$ object is a [terminal object](https://en.wikipedia.org/wiki/Terminal_object) of any algebraic structure where it exists, like it was described for examples above. But its existence and, if it exists, the property to be an [initial object](https://en.wikipedia.org/wiki/Initial_object) (and hence, a *zero object* in the [category-theoretical](wikipedia://en/5869) sense) depend on exact definition of the [multiplicative identity](https://en.wikipedia.org/wiki/Multiplicative_identity) 1 in a specified structure.

If the definition of $1$ requires that $1 \ne 0$, then the $\{0\}$ object cannot exist because it may contain only one element. In particular, the zero ring is not a [field](wikipedia://en/10603). If mathematicians sometimes talk about a [field with one element](wikipedia://en/13798040), this abstract and somewhat mysterious mathematical object is not a field.

In categories where the multiplicative identity must be preserved by morphisms, but can equal to zero, the $\{0\}$ object can exist. But not as initial object because identity-preserving morphisms from $\{0\}$ to any object where $1 \ne 0$ do not exist. For example, in the [category of rings](wikipedia://en/15300181) **Ring** the ring of [integers](wikipedia://en/14563) **Z** is the initial object, not $\{0\}$.

If an algebraic structure requires the multiplicative identity, but neither its preservation by morphisms nor $1 \ne 0$, then zero morphisms exist and the situation is not different from non-unital structures considered in the previous section.

## Notation {#Notation}

Zero vector spaces and zero modules are usually denoted by $0$ (instead of $\{0\}$). This is always the case when they occur in an [exact sequence](wikipedia://en/138215).
