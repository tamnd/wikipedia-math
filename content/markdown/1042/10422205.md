# Classification of Fatou components

::: {#o1 .subject cue=lead name="Classification of Fatou components"}

In [mathematics](wikipedia://en/18831), Fatou components are [components](https://en.wikipedia.org/wiki/Connected_component_%28analysis%29) of the [Fatou set](https://en.wikipedia.org/wiki/Fatou_set). They were named after [Pierre Fatou](wikipedia://en/629100).

:::

## Rational case {#Rational_case}

If f is a [rational function](wikipedia://en/361210)

$$f = \frac{P(z)}{Q(z)}$$

defined in the [extended complex plane](https://en.wikipedia.org/wiki/Extended_complex_plane), and if it is a nonlinear function (degree > 1)

$$d(f) = \max(\deg(P),\, \deg(Q))\geq 2,$$

then for a periodic [component](https://en.wikipedia.org/wiki/Connected_component_%28analysis%29) $U$ of the [Fatou set](https://en.wikipedia.org/wiki/Fatou_set), exactly one of the following holds:

1. $U$ contains an **[attracting periodic point](https://en.wikipedia.org/wiki/Attracting_periodic_point)**
1. $U$ is **parabolic**[^o3]
1. $U$ is a **[Siegel disc](wikipedia://en/12247909)**: a simply connected Fatou component on which *f*(*z*) is analytically conjugate to a Euclidean rotation of the unit disc onto itself by an irrational rotation angle.
1. $U$ is a **[Herman ring](wikipedia://en/29176060)**: a double connected Fatou component (an [annulus](wikipedia://en/356158)) on which *f*(*z*) is analytically conjugate to a Euclidean rotation of a round annulus, again by an irrational rotation angle.

### Attracting periodic point {#Attracting_periodic_point}

The components of the map $f(z) = z - (z^3-1)/3z^2$ contain the attracting points that are the solutions to $z^3=1$. This is because the map is the one to use for finding solutions to the equation $z^3=1$ by [Newton–Raphson](https://en.wikipedia.org/wiki/Newton–Raphson) formula. The solutions must naturally be attracting fixed points.

### Herman ring {#Herman_ring}

The map

$$f(z) = e^{2 \pi i t} z^2(z - 4)/(1 - 4z)$$

and t = 0.6151732... will produce a Herman ring.[^o6] It is shown by [Shishikura](wikipedia://en/4403736) that the degree of such map must be at least 3, as in this example.

### More than one type of component {#More_than_one_type_of_component}

If degree d is greater than 2 then there is more than one critical point and then can be more than one type of component

## Transcendental case {#Transcendental_case}

### Baker domain {#Baker_domain}

In case of [transcendental functions](https://en.wikipedia.org/wiki/Transcendental_functions) there is another type of periodic Fatou components, called **Baker domain**: these are "[domains](wikipedia://en/16796643) on which the iterates tend to an [essential singularity](wikipedia://en/80862) (not possible for polynomials and rational functions)"[^o10][^o11] one example of such a function is:[^o12]

$$f(z) = z - 1 + (1 - 2z)e^z$$

### Wandering domain {#Wandering_domain}

Transcendental maps may have [wandering domains](wikipedia://en/2870010): these are Fatou components that are not eventually periodic.
