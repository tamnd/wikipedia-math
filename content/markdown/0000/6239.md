# Contraction mapping

::: {#o1 .subject cue=lead name="Contraction mapping"}

In [mathematics](wikipedia://en/18831), a **contraction mapping**, or **contraction** or **contractor**, on a [metric space](wikipedia://en/20018) (*M*, *d*) is a [function](wikipedia://en/185427) *f* from *M* to itself, with the property that there is some [real number](wikipedia://en/20646438) $0 \leq k < 1$ such that for all *x* and *y* in *M*,

$$d(f(x),f(y)) \leq k\,d(x,y).$$

The smallest such value of *k* is called the **[Lipschitz constant](https://en.wikipedia.org/wiki/Lipschitz_constant)** of *f*. Contractive maps are sometimes called **Lipschitzian maps**. If the above condition is instead satisfied for *k* ≤ 1, then the mapping is said to be a [non-expansive map](https://en.wikipedia.org/wiki/Non-expansive_map).

:::

More generally, the idea of a contractive mapping can be defined for maps between metric spaces. Thus, if (*M*, *d*) and (*N*, *d**) are two metric spaces, then $f:M \rightarrow N$ is a contractive mapping if there is a constant $0 \leq k < 1$ such that***

$$d'(f(x),f(y)) \leq k\,d(x,y)$$

for all *x* and *y* in *M*.

Every contraction mapping is [Lipschitz continuous](https://en.wikipedia.org/wiki/Lipschitz_continuous) and hence [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous) (for a Lipschitz continuous function, the constant *k* is no longer necessarily less than 1).

A contraction mapping has at most one [fixed point](wikipedia://en/449738). Moreover, the [Banach fixed-point theorem](wikipedia://en/46676) states that every contraction mapping on a [non-empty](wikipedia://en/9566) [complete metric space](wikipedia://en/7832) has a unique fixed point, and that for any *x* in *M* the [iterated function](wikipedia://en/1448702) sequence *x*, *f* (*x*), *f* (*f* (*x*)), *f* (*f* (*f* (*x*))), ... converges to the fixed point. This concept is very useful for [iterated function systems](https://en.wikipedia.org/wiki/Iterated_function_systems) where [contraction mappings are often used](wikipedia://en/71480557#contraction_mapping). Banach's fixed-point theorem is also applied in proving the existence of solutions of [ordinary differential equations](wikipedia://en/32742753), and is used in one proof of the [inverse function theorem](wikipedia://en/287229).[^o2]

Contraction mappings play an important role in [dynamic programming](wikipedia://en/125297) problems.[^o3][^o4]

## Firmly non-expansive mapping {#Firmly_non-expansive_mapping}

A non-expansive mapping with $k=1$ can be generalized to a **firmly non-expansive mapping** in a [Hilbert space](wikipedia://en/20598932) $\mathcal{H}$ if the following holds for all *x* and *y* in $\mathcal{H}$:

$$\|f(x)-f(y) \|^2 \leq \, \langle x-y, f(x) - f(y) \rangle,$$

where

$$d(x,y) = \|x-y\|.$$

This is a special case of $\alpha$ averaged nonexpansive operators with $\alpha = 1/2$.[^o6] A firmly non-expansive mapping is always non-expansive, via the [Cauchy–Schwarz inequality](wikipedia://en/38128).

The class of firmly non-expansive maps is closed under [convex combinations](wikipedia://en/794534), but not compositions.[^o7] This class includes [proximal mappings](wikipedia://en/51026323) of proper, convex, lower-semicontinuous functions, hence it also includes orthogonal [projections](wikipedia://en/3909097) onto non-empty closed [convex sets](wikipedia://en/6292). The class of firmly nonexpansive operators is equal to the set of resolvents of maximally [monotone operators](wikipedia://en/48260#Monotonicity_in_functional_analysis).[^o8] Surprisingly, while iterating non-expansive maps has no guarantee to find a fixed point (e.g. multiplication by -1), firm non-expansiveness is sufficient to [guarantee global convergence](wikipedia://en/71480557) to a fixed point, provided a fixed point exists. More precisely, if

$$\operatorname{Fix}f := \{x \in \mathcal{H} \ | \ f(x) = x\} \neq \varnothing,$$

then for any initial point $x_0 \in \mathcal{H}$, iterating

$$x_{n+1} = f(x_n), \quad \forall n \in \mathbb{N}$$

yields convergence to a fixed point $x_n \to z \in \operatorname{Fix} f$. This convergence might be [weak](wikipedia://en/2119266) in an infinite-dimensional setting.[^o7]

## Subcontraction map {#Subcontraction_map}

A **subcontraction map** or **subcontractor** is a map *f* on a metric space (*M*, *d*) such that

$$d(f(x), f(y)) \leq d(x,y);$$

$$d(f(f(x)),f(x)) < d(f(x),x) \quad \text{unless} \quad x = f(x).$$

If the [image](wikipedia://en/579311) of a subcontractor *f* is [compact](wikipedia://en/6042), then *f* has a fixed point.[^o11]

:::

## Locally convex spaces {#Locally_convex_spaces}

In a [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space) (*E*, *P*) with [topology](wikipedia://en/30450) given by a set *P* of [seminorms](wikipedia://en/292067), one can define for any *p* ∈ *P* a *p*-contraction as a map *f* such that there is some *k*<sub>*p*</sub> \< 1 such that *p*(*f*(*x*) − *f*(*y*)) ≤ *k<sub>p</sub> p*(*x* − *y*). If *f* is a *p*-contraction for all *p* ∈ *P* and (*E*, *P*) is sequentially complete, then *f* has a fixed point, given as limit of any sequence *x*<sub>*n*+1</sub> = *f*(*x*<sub>*n*</sub>), and if (*E*, *P*) is [Hausdorff](wikipedia://en/13637), then the fixed point is unique.[^o13]
