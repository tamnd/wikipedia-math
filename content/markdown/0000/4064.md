# Borsuk–Ulam theorem

*Image: Antipodal.png.* Antipodal points are opposite points on the sphere

*Image: Borsuk ulam.svg.* Matching antipodal points of a squashed balloon animal

::: {#o1 .subject cue=lead name="Borsuk–Ulam theorem"}

Informally, the **Borsuk–Ulam theorem** states that, for a "[balloon animal](https://en.wikipedia.org/wiki/Balloon_animal)" (or any arbitrarily distorted shape) made out of a [spherical](wikipedia://en/27859) balloon, and then squashed into a [plane](wikipedia://en/19469852) (letting the air out somehow), at least one pair of points that were opposite each other on the original sphere will be squashed onto the same point of the plane.

:::

More formally, every [continuous map](https://en.wikipedia.org/wiki/Continuous_map) from the sphere to the plane maps some pair of antipodal points to the same point. An analogous statement is true in higher dimensions (see below).

## General statement {#General_statement}

Formally, the theorem states that every [continuous function](wikipedia://en/6122) from an [*n*-sphere](wikipedia://en/39782) into [*n*-dimensional Euclidean space](wikipedia://en/9697) must map some pair of [antipodal points](wikipedia://en/367577) to the same point. Two points on a sphere are called antipodal if they lie in exactly opposite directions from the center—like the North and South Poles.

The Borsuk–Ulam theorem has several equivalent statements in terms of [odd functions](https://en.wikipedia.org/wiki/Odd_function). Recall that $S^n$ is the [*n*-sphere](wikipedia://en/39782) and $B^n$ is the [*n*-ball](https://en.wikipedia.org/wiki/N-ball):

- If $g : S^n \to \mathbb{R}^n$ is a continuous odd function, then there exists an $x\in S^n$ such that: $g(x)=0$.
- If $g : B^n \to \mathbb{R}^n$ is a continuous function which is odd on $S^{n-1}$ (the boundary of $B^n$), then there exists an $x\in B^n$ such that: $g(x)=0$.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

More compactly: if $f: S^n \to \mathbb{R}^n$ is continuous then there exists an $x\in S^n$ such that: $f(-x)=f(x)$.

The case $n=1$ can be illustrated by saying that there always exist a pair of opposite points on the [Earth](wikipedia://en/9228)'s equator with the same temperature. The same is true for any circle. This assumes the temperature varies continuously in space, which is, however, not always the case.[^o5]

The case $n=2$ is often illustrated by saying that at any moment, there is always a pair of antipodal points on the Earth's surface with equal temperatures and equal barometric pressures, assuming that both parameters vary continuously in space.

:::

## History {#History}

According to (Matoušek 2003, 25), the first historical mention of the statement of the Borsuk–Ulam theorem appears in (Lyusternik Shnirel'man 1930). The first proof was given by (txt), where the formulation of the problem was attributed to [Stanisław Ulam](wikipedia://en/41531). Since then, many alternative proofs have been found by various authors, as collected by (Steinlein 1985).

## Equivalent statements {#Equivalent_statements}

The following statements are equivalent to the Borsuk–Ulam theorem.[^o12]

### With odd functions {#With_odd_functions}

A function $g$ is called *odd* (aka *antipodal* or *antipode-preserving*) if for every $x$, $g(-x)=-g(x)$.

The Borsuk–Ulam theorem is equivalent to each of the following statements:

(1) Each continuous odd function $S^n\to \mathbb{R}^n$ has a zero.

(2) There is no continuous odd function $S^n \to S^{n-1}$.

Here is a proof that the Borsuk-Ulam theorem is equivalent to (1):

($\Longrightarrow$) If the theorem is correct, then it is specifically correct for odd functions, and for an odd function, $g(-x)=g(x)$ iff $g(x)=0$. Hence every odd continuous function has a zero.

($\Longleftarrow$) For every continuous function $f:S^n\to \mathbb{R}^n$, the following function is continuous and odd: $g(x)=f(x)-f(-x)$. If every odd continuous function has a zero, then $g$ has a zero, and therefore, $f(x)=f(-x)$.

To prove that (1) and (2) are equivalent, we use the following continuous odd maps:

- the obvious inclusion $i: S^{n-1}\to \mathbb{R}^n\setminus \{0\}$,
- and the radial projection map $p: \mathbb{R}^n\setminus \{0\} \to S^{n-1}$ given by $x \mapsto \frac{x}{|x|}$.

The proof now writes itself.

$((1) \Longrightarrow (2))$ We prove the contrapositive. If there exists a continuous odd function $f:S^n\to S^{n-1}$, then $i\circ f$ is a continuous odd function $S^n\to \mathbb{R}^n\setminus \{0\}$.

$((1) \Longleftarrow (2))$ Again we prove the contrapositive. If there exists a continuous odd function $f:S^n\to \mathbb{R}^{n}\setminus\{0\}$, then $p\circ f$ is a continuous odd function $S^n\to S^{n-1}$.

::: {#o15 .proof cue=heading name="Proofs"}

## Proofs {#Proofs}

### 1-dimensional case {#1-dimensional_case}

The 1-dimensional case can easily be proved using the [intermediate value theorem](wikipedia://en/14884) (IVT).

Let $g$ be the odd real-valued continuous function on a circle defined by $g(x)=f(x)-f(-x)$. Pick an arbitrary $x$. If $g(x)=0$ then we are done. Otherwise, [without loss of generality](wikipedia://en/296000), $g(x)>0.$ But $g(-x)<0.$ Hence, by the IVT, there is a point $y$ at which $g(y)=0$.

### General case {#General_case}

#### Algebraic topological proof {#Algebraic_topological_proof}

Assume that $h: S^n \to S^{n-1}$ is an odd continuous function with $n \geq 2$ (the case $n = 1$ is treated above). Note that the case $n = 2$ can also be handled using basic [covering theory](wikipedia://en/250323).

By passing to orbits under the antipodal action, we then get an induced continuous function $h': \mathbb{RP}^n \to \mathbb{RP}^{n-1}$ between [real projective spaces](wikipedia://en/1014694), and it induces an isomorphism on [fundamental groups](wikipedia://en/11004) because $h$ is odd.

By the [Hurewicz theorem](wikipedia://en/591587) and the [universal coefficient theorem](wikipedia://en/996107) for cohomology, the induced [homomorphism](wikipedia://en/13564) on [cohomology](wikipedia://en/194060) with $\mathbb Z/2\mathbb Z$ coefficients,

$$H^1(\mathbb{RP}^n; \mathbb Z/2\mathbb Z) \leftarrow H^1(\mathbb{RP}^{n-1}; \mathbb Z/2\mathbb Z),$$

is an isomorphism. Let $a$ be the generator of $H^1(\mathbb{RP}^{n}; \mathbb Z/2\mathbb Z) \cong \mathbb Z/2\mathbb Z$ and $b$ be that of $H^1(\mathbb{RP}^{n-1}; \mathbb Z/2\mathbb Z) \cong \mathbb Z/2\mathbb Z$. Then the isomorphism sends $b$ to $a$. Therefore, the induced [cohomology](wikipedia://en/194060) [ring homomorphism](wikipedia://en/26411),

$$(\mathbb Z/2\mathbb Z)[a]/a^{n+1} = H^*(\mathbb{RP}^n; \mathbb Z/2\mathbb Z) \leftarrow H^*(\mathbb{RP}^{n-1}; \mathbb Z/2\mathbb Z) = (\mathbb Z/2\mathbb Z)[b]/b^n,$$

sends $b^n = 0$ to $a^n \neq 0$, a contradiction.[^o19]

One can also show the stronger statement that any odd map $S^{n-1} \to S^{n-1}$ has odd [degree](wikipedia://en/3094450) and then deduce the theorem from this result.

#### Combinatorial proof {#Combinatorial_proof}

The Borsuk–Ulam theorem can be proved from [Tucker's lemma](wikipedia://en/17633708).[^o12][^o21][^o22]

Let $g : S^n \to \mathbb{R}^n$ be a continuous odd function. Because *g* is continuous on a [compact](wikipedia://en/6042) domain, it is [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous). Therefore, for every $\epsilon > 0$, there is a $\delta > 0$ such that, for every two points of $S_n$ which are within $\delta$ of each other, their images under *g* are within $\epsilon$ of each other.

Define a triangulation of $S_n$ with edges of length at most $\delta$. Label each vertex $v$ of the triangulation with a label $l(v)\in {\pm 1, \pm 2, \ldots, \pm n}$ in the following way:

- The [absolute value](wikipedia://en/991) of the label is the *index* of the coordinate with the highest absolute value of *g*: $|l(v)| = \arg\max_k (|g(v)_k|)$.
- The sign of the label is the sign of *g* at the above coordinate, so that: $l(v) = \operatorname{sgn} (g(v)_{|l(v)|}) |l(v)|$.

Because *g* is odd, the labeling is also odd: $l(-v) = -l(v)$. Hence, applying Tucker's lemma to a hemisphere of $S_n$ yields two adjacent vertices $u, v$ with opposite labels. Assume w.l.o.g. that the labels are $l(u)=1, l(v)=-1$. By the definition of *l*, this means that in both $g(u)$ and $g(v)$, coordinate #1 is the largest coordinate: in $g(u)$ this coordinate is positive while in $g(v)$ it is negative. By the construction of the triangulation, the distance between $g(u)$ and $g(v)$ is at most $\epsilon$, so in particular $|g(u)_1 - g(v)_1| = |g(u)_1| + |g(v)_1| \leq \epsilon$ (since $g(u)_1$ and $g(v)_1$ have opposite signs) and so $|g(u)_1| \leq \epsilon$. But since the largest coordinate of $g(u)$ is coordinate #1, this means that $|g(u)_k| \leq \epsilon$ for each $1 \leq k \leq n$. So $|g(u)| \leq c_n \epsilon$, where $c_n$ is some constant depending on $n$ and the norm $|\cdot|$ which you have chosen.

The above is true for every $\epsilon > 0$; since $S_n$ is compact there must hence be a point *u* in which $|g(u)|=0$.

:::

## Corollaries {#Corollaries}

- No subset of $\mathbb{R}^n$ is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to $S^n$
- The [ham sandwich theorem](wikipedia://en/702351): For any [compact](wikipedia://en/6042) sets *A*<sub>1</sub>, ..., *A<sub>n</sub>* in $\mathbb{R}^n$ we can always find a [hyperplane](wikipedia://en/99862) dividing each of them into two subsets of equal measure.

## Equivalent results {#Equivalent_results}

Above we showed how to prove the Borsuk–Ulam theorem from Tucker's lemma. The converse is also true: it is possible to prove Tucker's lemma from the Borsuk–Ulam theorem. Therefore, these two theorems are equivalent.

::: {#o26 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

- In the original theorem, the domain of the function *f* is the unit *n*-sphere (the boundary of the unit *n*-ball). In general, it is true also when the domain of *f* is the boundary of any open bounded symmetric subset of $\mathbb{R}^n$ containing the origin (Here, symmetric means that if *x* is in the subset then -*x* is also in the subset).
- More generally, if $M$ is a compact *n*-dimensional [Riemannian manifold](wikipedia://en/144652), and $f: M \rightarrow \mathbb{R}^n$ is continuous, there exists a pair of points *x* and *y* in $M$ such that $f(x) = f(y)$ and *x* and *y* are joined by a geodesic of length $\delta$, for any prescribed $\delta > 0$.[^o28][^o29]
- Consider the function *A* which maps a point to its antipodal point: $A(x) = -x.$ Note that $A(A(x))=x.$ The original theorem claims that there is a point *x* in which $f(A(x))=f(x).$ In general, this is true also for every function *A* for which $A(A(x))=x.$[^o30] However, in general this is not true for other functions *A*.[^o31]

:::
