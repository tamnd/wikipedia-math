# Data set

::: {#o1 .subject cue=lead name="Data set"}

the type of file

*Image: Iris dataset scatterplot.svg.* Various plots of the multivariate data set [*Iris* flower data set](wikipedia://en/10477224) introduced by [Ronald Fisher](wikipedia://en/140824) (1936).[^o10]

A **data set** (or **dataset**) is a collection of [data](https://en.wikipedia.org/wiki/Data). In the case of [tabular data](https://en.wikipedia.org/wiki/Tabular_data), a data set corresponds to one or more [database tables](https://en.wikipedia.org/wiki/Table_%28database%29), where every [column](https://en.wikipedia.org/wiki/Column_%28database%29) of a table represents a particular [variable](https://en.wikipedia.org/wiki/Variable_%28computer_science%29), and each [row](https://en.wikipedia.org/wiki/Row_%28database%29) corresponds to a given [record](https://en.wikipedia.org/wiki/Record_%28computer_science%29) of the data set in question. The data set lists values for each of the variables, such as for example height and weight of an object, for each member of the data set. Data sets can also consist of a collection of documents or files.[^o2]

:::

In the [open data](https://en.wikipedia.org/wiki/Open_data) discipline, a data set is a unit used to measure the amount of information released in a public open data repository. The European [data.europa.eu](https://en.wikipedia.org/wiki/Data.europa.eu) portal aggregates more than a million data sets.[^o3]

## Properties {#Properties}

Several characteristics define a data set's structure and properties. These include the number and types of the attributes or variables, and various [statistical measures](https://en.wikipedia.org/wiki/Statistical_measure) applicable to them, such as [standard deviation](wikipedia://en/27590) and [kurtosis](wikipedia://en/16848).[^o6]

The values may be numbers, such as [real numbers](wikipedia://en/20646438) or [integers](wikipedia://en/14563), for example representing a person's height in centimeters, but may also be [nominal data](https://en.wikipedia.org/wiki/Nominal_data) (i.e., not consisting of [numerical](wikipedia://en/21690) values), for example representing a person's ethnicity. More generally, values may be of any of the kinds described as a [level of measurement](wikipedia://en/821148). For each variable, the values are normally all of the same kind. [Missing values](https://en.wikipedia.org/wiki/Missing_values) may exist, which must be indicated somehow.

In [statistics](wikipedia://en/26685), data sets usually come from actual observations obtained by [sampling](wikipedia://en/160361) a [statistical population](wikipedia://en/27585), and each row corresponds to the observations on one element of that population. Data sets may further be generated by [algorithms](https://en.wikipedia.org/wiki/Algorithms) for the purpose of testing certain kinds of [software](https://en.wikipedia.org/wiki/Software). Some modern statistical analysis software such as [SPSS](wikipedia://en/179088) still present their data in the classical data set fashion. If data is missing or suspicious an [imputation](wikipedia://en/1309220) method may be used to complete a data set.[^o7]

:::

## Applications and use cases {#Applications_and_use_cases}

Data sets are widely used across various fields to support data analysis, research, and decision-making. In the sciences, data sets provide the empirical foundation for studies in disciplines such as [biology](https://en.wikipedia.org/wiki/Biology), [physics](wikipedia://en/22939), and [social science](https://en.wikipedia.org/wiki/Social_science), enabling discoveries in medicine, environmental science, and social research. In [machine learning](wikipedia://en/233488) and [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence), data sets are essential for training, validating, and testing algorithms for tasks such as image recognition, natural language processing, and predictive modeling. Governments and organizations publish open data sets to promote transparency, inform policy-making, and facilitate urban and social planning. The business sector uses data sets for market analysis, customer segmentation, and operational improvements. Additionally, healthcare relies on data sets for clinical research and improving patient outcomes. These varied applications demonstrate the critical role data sets play in enabling evidence-based insights and driving technological progress.

## Classics {#Classics}

Several classic data sets have been used extensively in the [statistical](https://en.wikipedia.org/wiki/Statistical) literature:

- [Iris flower data set](wikipedia://en/10477224) – Multivariate data set introduced by [Ronald Fisher](wikipedia://en/140824) (1936).[^o10] [Provided online by University of California-Irvine Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/Iris).[^o11]
- [MNIST database](https://en.wikipedia.org/wiki/MNIST_database) – Images of handwritten digits commonly used to test classification, clustering, and [image processing](https://en.wikipedia.org/wiki/Digital_image_processing) algorithms
- *[Categorical data analysis](https://en.wikipedia.org/wiki/Categorical_data_analysis)* – Data sets used in the book, *An Introduction to Categorical Data Analysis*, [provided online](https://stats.oarc.ucla.edu/other/examples/icda/) by UCLA Advanced Research Computing.[^o12]
- *[Robust statistics](wikipedia://en/2885691)* – Data sets used in *[Robust Regression and Outlier Detection](wikipedia://en/64209164)* ([Rousseeuw](wikipedia://en/30760578) and Leroy, 1968). [Provided online](https://web.archive.org/web/20050207032959/http://www.uni-koeln.de/themen/statistik/data/rousseeuw/) at the University of Cologne.[^o13]
- *[Time series](wikipedia://en/406624)* – Data used in Chatfield's book, *The Analysis of Time Series*, are [provided on-line](https://web.archive.org/web/20110102201323/http://lib.stat.cmu.edu/modules.php?op=modload&name=PostWrap&file=index&page=datasets/) by StatLib.[^o14]
- *Extreme values* – Data used in the book, *An Introduction to the Statistical Modeling of Extreme Values* are [a snapshot of the data as it was provided on-line by Stuart Coles](https://web.archive.org/web/20060910161517/http://homes.stat.unipd.it/coles/public_html/ismev/ismev.dat), the book's author.
- *Bayesian Data Analysis* – Data used in the book are [provided on-line](http://www.stat.columbia.edu/~gelman/book/data/) ([archive link](https://web.archive.org/web/20230122121643/http://www.stat.columbia.edu/~gelman/book/data/)) by [Andrew Gelman](wikipedia://en/25745941), one of the book's authors.
- The [Bupa liver data](https://web.archive.org/web/20171023174701/http://ftp.ics.uci.edu:80/pub/machine-learning-databases/liver-disorders/) – Used in several papers in the [machine learning](wikipedia://en/233488) (data mining) literature.
- [Anscombe's quartet](wikipedia://en/10019241) – Small data set illustrating the importance of graphing the data to avoid statistical fallacies.
