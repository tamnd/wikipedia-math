# Binary function

::: {#o1 .subject cue=lead name="Binary function"}

In [mathematics](wikipedia://en/18831), a **binary function** (also called **bivariate function**, or **function of two variables**) is a [function](wikipedia://en/185427) that takes two inputs.

:::

Precisely stated, a function $f$ is binary if there exist [sets](wikipedia://en/26691) $X, Y, Z$ such that

$$\,f \colon X \times Y \rightarrow Z$$

where $X \times Y$ is the [Cartesian product](wikipedia://en/24104095) of $X$ and $Y.$

::: {#o3 .definition cue=heading name="Alternative definitions"}

## Alternative definitions {#Alternative_definitions}

[Set-theoretically](wikipedia://en/4944), a binary function can be represented as a [subset](wikipedia://en/27631) of the [Cartesian product](wikipedia://en/24104095) $X \times Y \times Z$, where $(x,y,z)$ belongs to the subset [if and only if](wikipedia://en/14922) $f(x,y) = z$. Conversely, a subset $R$ defines a binary function if and only if [for any](wikipedia://en/76174) $x \in X$ and $y \in Y$, [there exists](wikipedia://en/91420) a [unique](wikipedia://en/276894) $z \in Z$ such that $(x,y,z)$ belongs to $R$. $f(x,y)$ is then defined to be this $z$.

Alternatively, a binary function may be interpreted as simply a [function](wikipedia://en/185427) from $X \times Y$ to $Z$. Even when thought of this way, however, one generally writes $f(x,y)$ instead of $f((x,y))$. (That is, the same pair of parentheses is used to indicate both [function application](wikipedia://en/20576545) and the formation of an [ordered pair](wikipedia://en/22362).)

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Division of [whole numbers](wikipedia://en/14563) can be thought of as a function. If $\mathbb{Z}$ is the set of [integers](wikipedia://en/14563), $\mathbb{N}^+$ is the set of [natural numbers](wikipedia://en/21474) (except for zero), and $\mathbb{Q}$ is the set of [rational numbers](wikipedia://en/19727024), then [division](wikipedia://en/53696) is a binary function $f:\mathbb{Z} \times \mathbb{N}^+ \to \mathbb{Q}$.

In a vector space *V* over a field *F*, [scalar multiplication](wikipedia://en/244373) is a binary function. A scalar *a* ∈ *F* is combined with a vector *v* ∈ *V* to produce a new vector *av* ∈ *V*.

Another example is that of inner products, or more generally functions of the form $(x,y)\mapsto x^\mathrm{T}My$, where $x$, $y$ are real-valued vectors of appropriate size and $M$ is a matrix. If $M$ is a [positive definite matrix](https://en.wikipedia.org/wiki/Positive_definite_matrix), this yields an [inner product](https://en.wikipedia.org/wiki/Inner_product).[^o6]

:::

## Functions of two real variables {#Functions_of_two_real_variables}

Functions whose domain is a subset of $\mathbb{R}^2$ are often also called functions of two variables even if their domain does not form a rectangle and thus the cartesian product of two sets.[^o8]

## Restrictions to ordinary functions {#Restrictions_to_ordinary_functions}

In turn, one can also derive ordinary functions of one variable from a binary function. Given any element $x \in X$, there is a function $f^x$, or $f(x,\cdot)$, from $Y$ to $Z$, given by $f^x(y) = f(x,y)$. Similarly, given any element $y \in Y$, there is a function $f_y$, or $f(\cdot,y)$, from $X$ to $Z$, given by $f_y(x) = f(x,y)$. In computer science, this identification between a function from $X \times Y$ to $Z$ and a function from $X$ to $Z^Y$, where $Z^Y$ is the set of all functions from $Y$ to $Z$, is called *[currying](wikipedia://en/6600)*.

## Generalisations {#Generalisations}

The various concepts relating to functions can also be generalised to binary functions. For example, the division example above is *[surjective](wikipedia://en/27873)* (or *onto*) because every rational number may be expressed as a quotient of an integer and a natural number. This example is *[injective](wikipedia://en/45196)* in each input separately, because the functions *f* <sup>*x*</sup> and *f* <sub>*y*</sub> are always injective. However, it's not injective in both variables simultaneously, because (for example) *f* (2,4) = *f* (1,2).

One can also consider *partial* binary functions, which may be defined only for certain values of the inputs. For example, the division example above may also be interpreted as a partial binary function from **Z** and **N** to **Q**, where **N** is the set of all natural numbers, including zero. But this function is undefined when the second input is zero.

A [binary operation](wikipedia://en/3948) is a binary function where the sets *X*, *Y*, and *Z* are all equal; binary operations are often used to define [algebraic structures](wikipedia://en/106364).

In [linear algebra](wikipedia://en/18422), a [bilinear transformation](https://en.wikipedia.org/wiki/Bilinear_operator) is a binary function where the sets *X*, *Y*, and *Z* are all [vector spaces](wikipedia://en/32370) and the derived functions *f* <sup>*x*</sup> and *f*<sub>*y*</sub> are all [linear transformations](https://en.wikipedia.org/wiki/Linear_transformation). A bilinear transformation, like any binary function, can be interpreted as a function from *X* × *Y* to *Z*, but this function in general won't be linear. However, the bilinear transformation can also be interpreted as a single linear transformation from the [tensor product](wikipedia://en/30844) $X \otimes Y$ to *Z*.

## Generalisations to ternary and other functions {#Generalisations_to_ternary_and_other_functions}

The concept of binary function generalises to *ternary* (or *3-ary*) *function*, *quaternary* (or *4-ary*) *function*, or more generally to *n-ary function* for any [natural number](wikipedia://en/21474) *n*. A *0-ary function* to *Z* is simply given by an element of *Z*. One can also define an *A-ary function* where *A* is any [set](wikipedia://en/26691); there is one input for each element of *A*.

## Category theory {#Category_theory}

In [category theory](wikipedia://en/5869), *n*-ary functions generalise to *n*-ary morphisms in a [multicategory](wikipedia://en/2145170). The interpretation of an *n*-ary morphism as an ordinary morphisms whose domain is some sort of product of the domains of the original *n*-ary morphism will work in a [monoidal category](wikipedia://en/330604). The construction of the derived morphisms of one variable will work in a [closed monoidal category](wikipedia://en/1396924). The category of sets is closed monoidal, but so is the category of vector spaces, giving the notion of bilinear transformation above.
