# Equivalence class

*Image: Congruent non-congruent triangles.svg.* [Congruence](wikipedia://en/39330) is an example of an equivalence relation. The leftmost two triangles are congruent, while the third and fourth triangles are not congruent to any other triangle shown here. Thus, the first two triangles are in the same equivalence class, while the third and fourth triangles are each in their own equivalence class.

::: {#o1 .subject cue=lead name="Equivalence class"}

In [mathematics](wikipedia://en/18831), when the elements of some [set](wikipedia://en/26691) $S$ have a notion of equivalence (formalized as an [equivalence relation](wikipedia://en/9259)), then one may naturally split the set $S$ into **equivalence classes**. These equivalence classes are constructed so that elements $a$ and $b$ belong to the same **equivalence class** [if, and only if](https://en.wikipedia.org/wiki/If,_and_only_if), they are equivalent.

:::

Formally, given a set $S$ and an equivalence relation $\sim$ on $S,$ the equivalence class of an element $a$ in $S$ is denoted $[a]$ or, equivalently, $[a]_{\sim}$ to emphasize its equivalence relation $\sim$, and is defined as the set of all elements in $S$ with which $a$ is $\sim$-related. The definition of equivalence relations implies that the equivalence classes form a [partition](wikipedia://en/340240) of $S,$ meaning, that every element of the set belongs to exactly one equivalence class. The set of the equivalence classes is sometimes called the **quotient set** or the **quotient space** of $S$ by $\sim,$ and is denoted by $S /{\sim}.$

When the set $S$ has some structure (such as a [group operation](wikipedia://en/19447) or a [topology](wikipedia://en/30450)) and the equivalence relation $\sim$ is compatible with this structure, the quotient set often inherits a similar structure from its parent set. Examples include [quotient spaces in linear algebra](wikipedia://en/898784), [quotient spaces in topology](wikipedia://en/237213), [quotient groups](wikipedia://en/11526), [homogeneous spaces](wikipedia://en/363325), [quotient rings](wikipedia://en/184635), [quotient monoids](https://en.wikipedia.org/wiki/Quotient_monoid), and [quotient categories](wikipedia://en/4004632).

::: {#o3 .definition cue=heading name="Definition and notation"}

## Definition and notation {#Definition_and_notation}

An [equivalence relation](wikipedia://en/9259) on a set $X$ is a [binary relation](wikipedia://en/3931) $\sim$ on $X$ satisfying the three properties:[^n1]

- $a \sim a$ for all $a \in X$ ([reflexivity](wikipedia://en/200458)),
- $a \sim b$ implies $b \sim a$ for all $a, b \in X$ ([symmetry](wikipedia://en/200459)),
- if $a \sim b$ and $b \sim c$ then $a \sim c$ for all $a, b, c \in X$ ([transitivity](wikipedia://en/200463)).

The equivalence class of an element $a$ is defined as[^n2]

$$[a] = \{ x \in X : a \sim x \}.$$

The word "class" in the term "equivalence class" may generally be considered as a synonym of "[set](wikipedia://en/26691)", although some equivalence classes are not sets but [proper classes](https://en.wikipedia.org/wiki/Proper_class). For example, "being [isomorphic](wikipedia://en/12397)" is an equivalence relation on [groups](wikipedia://en/19447), and the equivalence classes, called [isomorphism classes](https://en.wikipedia.org/wiki/Isomorphism_class), are not sets.

The set of all equivalence classes in $X$ with respect to an equivalence relation $R$ is denoted as $X / R,$ and is called $X$ [modulo](wikipedia://en/1352566) $R$ (or the **quotient set** of $X$ by $R$).[^o6] The [surjective map](https://en.wikipedia.org/wiki/Surjective_map) $x \mapsto [x]$ from $X$ onto $X / R,$ which maps each element to its equivalence class, is called the **canonical surjection**, or the **canonical projection**.

Every element of an equivalence class characterizes the class, and may be used to *represent* it. When such an element is chosen, it is called a **representative** of the class. The choice of a representative in each class defines an [injection](wikipedia://en/45196) from $X / R$ to $X$. Since its [composition](wikipedia://en/195947) with the canonical surjection is the identity of $X / R,$ such an injection is called a [section](wikipedia://en/10630303), when using the terminology of [category theory](wikipedia://en/5869).

Sometimes, there is a section that is more "natural" than the other ones. In this case, the representatives are called [canonical](wikipedia://en/515096) representatives. For example, in [modular arithmetic](wikipedia://en/20087), for every [integer](wikipedia://en/14563) $m$ greater than $1$, the [congruence modulo $m$](https://en.wikipedia.org/wiki/Congruence_modulo_m) is an equivalence relation on the integers, for which two integers $a$ and $b$ are equivalent—in this case, one says *congruent*—if $m$ divides $a-b;$ this is denoted $a\equiv b \pmod m.$ Each class contains a unique non-negative integer smaller than $m,$ and these integers are the canonical representatives.

The use of representatives for representing classes allows avoiding considering explicitly classes as sets. In this case, the canonical surjection that maps an element to its class is replaced by the function that maps an element to the representative of its class. In the preceding example, this function is denoted $a \bmod m,$ and produces the remainder of the [Euclidean division](wikipedia://en/679987) of $a$ by $m$.

:::

## Properties {#Properties}

For a set $X$ with an [equivalence relation](wikipedia://en/9259) $\sim$, every element $x$ of $X$ is a member of the equivalence class $[x]$ by [reflexivity](wikipedia://en/200458) ($a \sim a$ for all $a \in X$). Every two equivalence classes $[x]$ and $[y]$ are either equal if $x \sim y$, or [disjoint](wikipedia://en/39359) otherwise. Therefore, the set of all equivalence classes of $X$ forms a [partition](wikipedia://en/340240) of $X$: every element $x$ of $X$ belongs to one and only one equivalence class.[^o9]

Conversely, for a set $X$, every partition comes from an equivalence relation in this way, and different relations give different partitions. Thus $x \sim y$ if and only if $x$ and $y$ belong to the same set of the partition.[^o10]

It follows from the properties in the previous section that if $\,\sim\,$ is an equivalence relation on a set $X,$ and $x$ and $y$ are two elements of $X,$ the following statements are equivalent:

- $$x \sim y,$$
- $[x] = [y]$, and
- $$[x] \cap [y] \ne \emptyset.$$

## Examples {#Examples}

- Let $X$ be the set of all rectangles in a plane, and $\,\sim\,$ the equivalence relation "has the same area as", then for each positive real number $A,$ there will be an equivalence class of all the rectangles that have area $A.$[^o13]
  - For example, the rectangles with side lengths 2 by 4 and 1 by 8 both have the area 8. Although they differ, in shape, they are equivalent under the relation "has the same area" so they are in the same equivalence class.
- Consider the [modulo](wikipedia://en/20087) 2 equivalence relation on the set of [integers](wikipedia://en/14563), $\mathbb{Z},$ such that $x \sim y$ if and only if their difference $x - y$ is an [even number](https://en.wikipedia.org/wiki/Even_number). This relation gives rise to exactly two equivalence classes: one class consists of all even numbers, and the other class consists of all odd numbers. Using square brackets around one member of the class to denote an equivalence class under this relation, $[7], [9],$ and $[1]$ all represent the same element of $\mathbb{Z} /{\sim}.$[^n2]
  - Congruence [modulo](wikipedia://en/20087) 3 on the set of integers can be examined to demonstrate this. Under this equivalence relation,

\[0\] = {..., -9, -6, -3, 0, 3, 6, 9,...}

\[1\] = {..., -8, -5, -2, 1, 4, 7, 10,...}

\[2\] = {..., -7, -4, -1, 2, 5, 8, 11,...}

Each value in $\mathbb{Z}$ belongs to only one of the classes where elements 0, 1 and 2 are the [canonical](https://en.wikipedia.org/wiki/Canonical) representatives of their classes.

- Let $X$ be the set of [ordered pairs](wikipedia://en/22362) of integers $(a, b)$ with non-zero $b,$ and define an equivalence relation $\,\sim\,$ on $X$ such that $(a, b) \sim (c, d)$ if and only if $a d = b c,$ then the equivalence class of the pair $(a, b)$ can be identified with the [rational number](wikipedia://en/19727024) $a / b,$ and this equivalence relation and its equivalence classes can be used to give a formal definition of the set of rational numbers.[^o15] The same construction can be generalized to the [field of fractions](wikipedia://en/25271) of any [integral domain](wikipedia://en/15462).
  - The ordered pairs $(1, 2), (2, 4)$ and $(3, 6)$serve as an example of this. These pairs belong to the same equivalence class as each $(a, b)$ pairing represents the rational number $\tfrac{1}{2}$.
- If $X$ consists of all the lines in the [Euclidean plane](wikipedia://en/15575410), and $L \sim M$ means that $L$ and $M$ are [parallel lines](https://en.wikipedia.org/wiki/Parallel_lines), then the set of lines that are parallel to each other form an equivalence class, as long as a [line is considered parallel to itself](wikipedia://en/664497#Reflexive_variant). In this situation, each equivalence class determines a [point at infinity](wikipedia://en/403139).
  - In the [Cartesian plane](https://en.wikipedia.org/wiki/Cartesian_plane), the lines $y = 2x -3$ and $y = 2x + 1$ have the same slope—and are parallel—so they belong to the same equivalence class.
- For any set $X$, the relation $x \sim y \iff x=y$ is an equivalence relation in which every equivalence class is a set consisting of a single element.
  - If $X$ = $\{1, 2, 3\}$, then the equivalence classes are $[1], [2],$ and $[3]$ as no two distinct elements are considered equivalent under the equality relation.

:::

## Graphical representation {#Graphical_representation}

*Image: Equivalentie.svg.* Graph of an example equivalence with 7 classes

An [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) may be associated to any [symmetric relation](wikipedia://en/200459) on a set $X,$ where the vertices are the elements of $X,$ and two vertices $s$ and $t$ are joined if and only if $s \sim t.$ Among these graphs are the graphs of equivalence relations. These graphs, called [cluster graphs](wikipedia://en/50931136), are characterized as the graphs such that the [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) are [cliques](wikipedia://en/524466).[^n2]

## Invariants {#Invariants}

If $\,\sim\,$ is an equivalence relation on $X,$ and $P(x)$ is a property of elements of $X$ such that whenever $x \sim y,$ $P(x)$ is true if $P(y)$ is true, then the property $P$ is said to be an [invariant](wikipedia://en/1126638) of $\,\sim\,,$ or [well-defined](https://en.wikipedia.org/wiki/Well-defined) under the relation $\,\sim.$

A frequent particular case occurs when $f$ is a function from $X$ to another set $Y$; if $f\left(x_1\right) = f\left(x_2\right)$ whenever $x_1 \sim x_2,$ then $f$ is said to be class invariant under $\,\sim\,,$ or simply invariant under $\,\sim.$ This occurs, for example, in the [character theory](wikipedia://en/691741) of finite groups. Some authors use "compatible with $\,\sim\,$" or just "respects $\,\sim\,$" instead of "invariant under $\,\sim\,$".

Any [function](wikipedia://en/185427) $f : X \to Y$ is *class invariant under* $\,\sim\,,$ according to which $x_1 \sim x_2$ if and only if $f\left(x_1\right) = f\left(x_2\right).$ The equivalence class of $x$ is the set of all elements in $X$ which get mapped to $f(x),$ that is, the class $[x]$ is the [inverse image](https://en.wikipedia.org/wiki/Inverse_image) of $f(x).$ This equivalence relation is known as the [kernel](https://en.wikipedia.org/wiki/Kernel_of_a_function) of $f.$

More generally, a function may map equivalent arguments (under an equivalence relation $\sim_X$ on $X$) to equivalent values (under an equivalence relation $\sim_Y$ on $Y$). Such a function is a [morphism](wikipedia://en/27716891) of sets equipped with an equivalence relation.

## Quotient space in topology {#Quotient_space_in_topology}

In [topology](wikipedia://en/29954), a [quotient space](wikipedia://en/237213) is a [topological space](wikipedia://en/30450) formed on the set of equivalence classes of an equivalence relation on a topological space, using the original space's topology to create the topology on the set of equivalence classes.

In [abstract algebra](wikipedia://en/19616384), [congruence relations](wikipedia://en/48167) on the underlying set of an algebra allow the algebra to induce an algebra on the equivalence classes of the relation, called a [quotient algebra](wikipedia://en/310953). In [linear algebra](wikipedia://en/18422), a [quotient space](wikipedia://en/898784) is a vector space formed by taking a [quotient group](wikipedia://en/11526), where the quotient homomorphism is a [linear map](wikipedia://en/18102). By extension, in abstract algebra, the term quotient space may be used for [quotient modules](wikipedia://en/364820), [quotient rings](wikipedia://en/184635), [quotient groups](wikipedia://en/11526), or any quotient algebra. However, the use of the term for the more general cases can as often be by analogy with the orbits of a group action.

The orbits of a [group action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) on a set may be called the quotient space of the action on the set, particularly when the orbits of the group action are the right [cosets](wikipedia://en/98759) of a subgroup of a group, which arise from the action of the subgroup on the group by left translations, or respectively the left cosets as orbits under right translation.

A normal subgroup of a topological group, acting on the group by translation action, is a quotient space in the senses of topology, abstract algebra, and group actions simultaneously.

Although the term can be used for any equivalence relation's set of equivalence classes, possibly with further structure, the intent of using the term is generally to compare that type of equivalence relation on a set $X,$ either to an equivalence relation that induces some structure on the set of equivalence classes from a structure of the same kind on $X,$ or to the orbits of a group action. Both the sense of a structure preserved by an equivalence relation, and the study of [invariants](wikipedia://en/1126638) under group actions, lead to the definition of invariants of equivalence relations given above.
