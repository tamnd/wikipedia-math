# Bijection

*Image: Bijection.svg.* A bijective function, *f*: *X* → *Y*, where set X is {1, 2, 3, 4} and set Y is {D, C, B, A}. For example, *f*(1) = D.

::: {#o1 .subject cue=lead name="Bijection"}

In [mathematics](wikipedia://en/18831), a **bijection**, **bijective function**, or **one-to-one correspondence** is a [function](wikipedia://en/185427) between two [sets](wikipedia://en/26691) such that each element of the second set (the [codomain](wikipedia://en/50264)) is the image of exactly one element of the first set (the [domain](wikipedia://en/50263)). Given a function $f:A\to B$, the image of an [element](wikipedia://en/682629) $a\in A$ is the element $f(a)\in B$ in the codomain. The pre-image of an element $b\in B$ is any element $a\in A$ in the domain such that $f(a)=b$. Equivalently, a bijection is a [relation](wikipedia://en/3931) between two sets such that each element of either set is paired with exactly one element of the other set.

:::

A function is bijective if and only if it is [invertible](wikipedia://en/14907); that is, a function $f:X\to Y$ is bijective if and only if there is a function $g:Y\to X,$ the *inverse* of $f$, such that each of the two ways for [composing](wikipedia://en/195947) the two functions produces an [identity function](wikipedia://en/15069): $g(f(x)) = x$ for each $x$ in $X$ and $f(g(y)) = y$ for each $y$ in $Y.$

For example, the *multiplication by two* defines a bijection from the [integers](wikipedia://en/14563) to the [even numbers](https://en.wikipedia.org/wiki/Even_number), which has the *division by two* as its inverse function.

A function is bijective if and only if it is both [injective](https://en.wikipedia.org/wiki/Injective) (or *one-to-one*)—meaning that each element in the codomain is mapped from at most one element of the domain—and [surjective](https://en.wikipedia.org/wiki/Surjective) (or *onto*)—meaning that each element of the codomain is mapped from at least one element of the domain. The term *one-to-one correspondence* must not be confused with *[one-to-one function](https://en.wikipedia.org/wiki/One-to-one_function)*, which means injective but not necessarily surjective.

The elementary operation of [counting](wikipedia://en/275768) establishes a bijection from some [finite set](wikipedia://en/11742) to the first [natural numbers](wikipedia://en/21474) $(1, 2, 3, ...)$, up to the number of elements in the counted set. It results that two finite sets have the same number of elements if and only if there exists a bijection between them. More generally, two sets are said to have the same [cardinal number](wikipedia://en/6173) if there exists a bijection between them.

A bijective function from a set to itself is also called a [permutation](wikipedia://en/44027),[^o2] and the set of all permutations of a set forms its [symmetric group](wikipedia://en/28901).

Some bijections with further properties have received specific names, which include [automorphisms](wikipedia://en/1160), [isomorphisms](wikipedia://en/14828), [homeomorphisms](wikipedia://en/13660), [diffeomorphisms](wikipedia://en/8564), [permutations](wikipedia://en/44027), and most [geometric transformations](wikipedia://en/43194879). [Galois correspondences](https://en.wikipedia.org/wiki/Galois_correspondence) are bijections between sets of [mathematical objects](wikipedia://en/19453961) of apparently very different nature.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a [binary relation](wikipedia://en/3931) pairing elements of set *X* with elements of set *Y* to be a bijection, four properties must hold:

1. each element of *X* must be paired with at least one element of *Y*,
1. no element of *X* may be paired with more than one element of *Y*,
1. each element of *Y* must be paired with at least one element of *X*, and
1. no element of *Y* may be paired with more than one element of *X*.

Satisfying properties (1) and (2) means that a pairing is a [function](wikipedia://en/185427) with [domain](wikipedia://en/50263) *X*. It is more common to see properties (1) and (2) written as a single statement: Every element of *X* is paired with exactly one element of *Y*. Functions which satisfy property (3) are said to be "[onto](https://en.wikipedia.org/wiki/Onto) *Y* " and are called [surjections](wikipedia://en/27873) (or *surjective functions*). Functions which satisfy property (4) are said to be "[one-to-one functions](https://en.wikipedia.org/wiki/One-to-one_function)" and are called [injections](wikipedia://en/45196) (or *injective functions*).[^o5] With this terminology, a bijection is a function which is both a surjection and an injection, or using other words, a bijection is a function which is both "one-to-one" and "onto".[^o6]

:::

## Examples {#Examples}

Every map from [the empty set](wikipedia://en/9566) to itself is a bijection.

### Batting line-up of a baseball or cricket team {#Batting_line-up_of_a_baseball_or_cricket_team}

Consider the [batting line-up](https://en.wikipedia.org/wiki/Batting_order_%28baseball%29) of a baseball or [cricket](https://en.wikipedia.org/wiki/Cricket) team (or any list of all the players of any sports team where every player holds a specific spot in a line-up). The set *X* will be the players on the team (of size nine in the case of baseball) and the set *Y* will be the positions in the batting order (1st, 2nd, 3rd, etc.) The "pairing" is given by which player is in what position in this order. Property (1) is satisfied since each player is somewhere in the list. Property (2) is satisfied since no player bats in two (or more) positions in the order. Property (3) says that for each position in the order, there is some player batting in that position and property (4) states that two or more players are never batting in the same position in the list.

### Seats and students of a classroom {#Seats_and_students_of_a_classroom}

In a classroom, there are a certain number of seats. A group of students enter the room and the instructor asks them to be seated. After a quick look around the room, the instructor declares that there is a bijection between the set of students and the set of seats, where each student is paired with the seat they are sitting in. What the instructor observed in order to reach this conclusion was that:

1. Every student was in a seat (there was no one standing),
1. No student was in more than one seat,
1. Every seat had someone sitting there (there were no empty seats), and
1. No seat had more than one student in it.

The instructor was able to conclude that there were just as many seats as there were students, without having to count either set.

### Fingerprints {#Fingerprints}

Consider a sample of 100 distinct individuals and the corresponding set of their [fingerprints](https://en.wikipedia.org/wiki/Fingerprint). Assuming that no two individuals in that sample share the same fingerprint, the set is one-to-one (injective). Furthermore, there aren’t any fingerprints without an individual; the set is onto (surjective). Since both sets have the same [cardinality](wikipedia://en/6174) and the sets are injective and surjective, then it follows there’s a bijection between the set of individuals and their fingerprints.

:::

## More mathematical examples {#More_mathematical_examples}

*Image: A bijection from N to Z.png.* Bijection from the natural numbers to the integers, which maps 2*n* to −*n* and 2*n* + 1 to *n+1*, for *n* ≥ 0.

- For any set *X*, the [identity function](wikipedia://en/15069) **1**<sub>*X*</sub>: *X* → *X*, **1**<sub>*X*</sub>(*x*) = *x* is bijective.
- The [multiplicative inverse](wikipedia://en/229940) function gives a bijection of the [unit interval](wikipedia://en/49324) (0, 1) with the semi-infinite interval (1, +∞).
- The function *f*: **R** → **R**, *f*(*x*) = 2*x* + 1 is bijective, since for each *y* there is a unique *x* = (*y* − 1)/2 such that *f*(*x*) = *y*. More generally, any [linear function](wikipedia://en/152111) over the reals, *f*: **R** → **R**, *f*(*x*) = *ax* + *b* (where *a* is non-zero) is a bijection. Each real number *y* is obtained from (or paired with) the real number *x* = (*y* − *b*)/*a*.
- The function *f*: **R** → (−π/2, π/2), given by *f*(*x*) = arctan(*x*) is bijective, since each real number *x* is paired with exactly one angle *y* in the interval (−π/2, π/2) so that tan(*y*) = *x* (that is, *y* = arctan(*x*)). If the [codomain](wikipedia://en/50264) (−π/2, π/2) was made larger to include an integer multiple of π/2, then this function would no longer be onto (surjective), since there is no real number which could be paired with the multiple of π/2 by this arctan function.
- The [exponential function](wikipedia://en/9678), *g*: **R** → **R**, *g*(*x*) = e<sup>*x*</sup>, is not bijective: for instance, there is no *x* in **R** such that *g*(*x*) = −1, showing that *g* is not onto (surjective). However, if the codomain is restricted to the positive real numbers $\mathbb{R}^+ \equiv \left(0, \infty\right)$, then *g* would be bijective; its inverse (see below) is the [natural logarithm](wikipedia://en/21476) function ln.
- The function *h*: **R** → **R**<sup>\+</sup>, *h*(*x*) = *x*<sup>2</sup> is not bijective: for instance, *h*(−1) = *h*(1) = 1, showing that *h* is not one-to-one (injective). However, if the [domain](wikipedia://en/50263) is restricted to $\mathbb{R}^+_0 \equiv \left[0, \infty\right)$, then *h* would be bijective; its inverse is the positive square root function.
- By [Schröder–Bernstein theorem](wikipedia://en/44218028), given any two sets *X* and *Y*, and two injective functions *f*: *X → Y* and *g*: *Y → X*, there exists a bijective function *h*: *X → Y*.

## Inverses {#Inverses}

A bijection *f* with domain *X* (indicated by *f*: *X → Y* in [functional notation](wikipedia://en/185427#Notation)) also defines a [converse relation](wikipedia://en/3941020) starting in *Y* and going to *X* (by turning the arrows around). The process of "turning the arrows around" for an arbitrary function does not, *in general*, yield a function, but properties (3) and (4) of a bijection say that this inverse relation is a function with domain *Y*. Moreover, properties (1) and (2) then say that this inverse *function* is a surjection and an injection, that is, the [inverse function](wikipedia://en/14907) exists and is also a bijection. Functions that have inverse functions are said to be [invertible](https://en.wikipedia.org/wiki/Invertible_function). A function is invertible if and only if it is a bijection.

Stated in concise mathematical notation, a function *f*: *X → Y* is bijective if and only if it satisfies the condition

for every *y* in *Y* there is a unique *x* in *X* with *y* = *f*(*x*).

Continuing with the baseball batting line-up example, the function that is being defined takes as input the name of one of the players and outputs the position of that player in the batting order. Since this function is a bijection, it has an inverse function which takes as input a position in the batting order and outputs the player who will be batting in that position.

## Composition {#Composition}

*Image: Bijective composition.svg.* A bijection composed of an injection (X → Y) and a surjection (Y → Z).

The [composition](wikipedia://en/195947) $g \,\circ\, f$ of two bijections $f : X \to Y$ and $g : Y \to Z$ is a bijection, whose inverse is given by $g \,\circ\, f$ is $(g \,\circ\, f)^{-1} \;=\; (f^{-1}) \,\circ\, (g^{-1})$.

Conversely, if the composition $g \, \circ\, f$ of two functions is bijective, it only follows that *f* is [injective](wikipedia://en/45196) and *g* is [surjective](wikipedia://en/27873).

## Cardinality {#Cardinality}

If *X* and *Y* are [finite sets](wikipedia://en/11742), then there exists a bijection between the two sets *X* and *Y* [if and only if](wikipedia://en/14922) *X* and *Y* have the same number of elements. Indeed, in [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), this is taken as the definition of "same number of elements" ([equinumerosity](https://en.wikipedia.org/wiki/Equinumerosity)), and generalizing this definition to [infinite sets](wikipedia://en/142679) leads to the concept of [cardinal number](wikipedia://en/6173), a way to distinguish the various sizes of infinite sets.

Any [infinite set](wikipedia://en/142679) that has a bijection to the [natural numbers](wikipedia://en/21474) is said to be countably infinite. Likewise, any infinite set that has a bijection with the [integers](wikipedia://en/14563) or the [rational numbers](wikipedia://en/19727024) is also countably infinite, since they also have a bijection to the natural numbers. This concept is integral to determining if some functions are countable.

For example, the set of all even integers f(n)=2n is countably infinite because there’s a bijection between the even integers and the natural numbers.

## Properties {#Properties}

- A function *f*: **R** → **R** is bijective if and only if its [graph](wikipedia://en/87352) meets every horizontal and vertical line exactly once.
- If *X* is a set, then the bijective functions from *X* to itself, together with the operation of functional composition ($\circ$), form a [group](https://en.wikipedia.org/wiki/Group_%28algebra%29), the [symmetric group](wikipedia://en/28901) of *X*, which is denoted variously by S(*X*), *S<sub>X</sub>*, or *X*! (*X* [factorial](wikipedia://en/10606)).
- Bijections preserve [cardinalities](https://en.wikipedia.org/wiki/Cardinalities) of sets: for a subset *A* of the domain with cardinality |*A*| and subset *B* of the codomain with cardinality |*B*|, one has the following equalities:

\|*f*(*A*)| = |*A*| and |*f*<sup>−1</sup>(*B*)| = |*B*|.

- If *X* and *Y* are [finite sets](wikipedia://en/11742) with the same cardinality, and *f*: *X → Y*, then the following are equivalent:
  1. *f* is a bijection.
  1. *f* is a [surjection](https://en.wikipedia.org/wiki/Surjection).
  1. *f* is an [injection](https://en.wikipedia.org/wiki/Injection_%28mathematics%29).
- For a finite set *S*, there is a bijection between the set of possible [total orderings](https://en.wikipedia.org/wiki/Total_ordering) of the elements and the set of bijections from *S* to *S*. That is to say, the number of [permutations](wikipedia://en/44027) of elements of *S* is the same as the number of total orderings of that set—namely, *n*!.

:::

## Category theory {#Category_theory}

Bijections are precisely the [isomorphisms](wikipedia://en/14828) in the [category](wikipedia://en/5869) *[Set](wikipedia://en/26829)* of [sets](wikipedia://en/26691) and set functions. However, the bijections are not always the isomorphisms for more complex categories. For example, in the category *[Grp](wikipedia://en/800092)* of [groups](wikipedia://en/19447), the morphisms must be [homomorphisms](wikipedia://en/13564) since they must preserve the group structure, so the isomorphisms are *group isomorphisms* which are bijective homomorphisms.

::: {#o20 .pointer-item cue=pointer name="Partial bijection"}

## Generalization to partial functions {#Generalization_to_partial_functions}

The notion of one-to-one correspondence generalizes to [partial functions](https://en.wikipedia.org/wiki/Partial_functions), where they are called *partial bijections*, although partial bijections are only required to be injective. The reason for this relaxation is that a (proper) partial function is already undefined for a portion of its domain; thus there is no compelling reason to constrain its inverse to be a [total function](https://en.wikipedia.org/wiki/Total_function), i.e. defined everywhere on its domain. The set of all partial bijections on a given base set is called the [symmetric inverse semigroup](wikipedia://en/18442482).[^o21]

Another way of defining the same notion is to say that a partial bijection from *A* to *B* is any relation *R* (which turns out to be a partial function) with the property that *R* is the [graph of](wikipedia://en/87352) a bijection *f*:*A*→*B*, where *A* is a [subset](wikipedia://en/27631) of *A* and *B* is a subset of *B*.[^o22]

When the partial bijection is on the same set, it is sometimes called a *one-to-one partial [transformation](wikipedia://en/1904373)*.[^o23] An example is the [Möbius transformation](wikipedia://en/314493) simply defined on the complex plane, rather than its completion to the extended complex plane.[^o24]

:::
