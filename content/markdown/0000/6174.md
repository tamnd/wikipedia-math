# Cardinality

::: {#o1 .subject cue=lead name="Cardinality"}

*Image: Apples and Oranges v2.png.* A one-to-one correspondence between a set of apples and a set of oranges shows they have the same cardinality.

In [mathematics](wikipedia://en/18831), **cardinality** is an inherent property of [sets](wikipedia://en/26691), roughly meaning the number of individual [objects](wikipedia://en/19453961) they contain, which may be [infinite](wikipedia://en/20110824). The concept is understood through [one-to-one correspondences](https://en.wikipedia.org/wiki/One-to-one_correspondence) between sets. That is, if their objects can be paired such that each object has a pair, and no object is paired more than once.

:::

Two sets are said to be ***equinumerous*** or *have the same cardinality* if there exists a one-to-one correspondence between them. Otherwise, under the [axiom of choice](wikipedia://en/840), one of the two sets must be equinumerous with a [strict subset](https://en.wikipedia.org/wiki/Strict_subset) of the other and is said to be *strictly smaller* than it; the other set is *strictly larger*. Using this concept, it is possible to show there are different sizes of infinity.

A set is [countably infinite](wikipedia://en/6026) if it can be placed in one-to-one correspondence with the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $\{1,2,3,4,\cdots\}$. For example, the set of even numbers $\{2,4,6,\cdots\}$ and the set of [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) are countable. [Uncountable sets](wikipedia://en/32248) are those strictly larger than the set of natural numbers. The set of all [real numbers](https://en.wikipedia.org/wiki/Real_numbers) and the [powerset](https://en.wikipedia.org/wiki/Powerset) of the set of natural numbers are proven to be uncountable by so-called [diagonal arguments](wikipedia://en/51426). [Cantor's theorem](wikipedia://en/341442) generalizes these arguments to show there is an infinite hierarchy of infinities.

For [finite sets](https://en.wikipedia.org/wiki/Finite_sets), cardinality recovers the usual concept of size as "number of elements." However, it is more often difficult to ascribe "sizes" to [infinite sets](https://en.wikipedia.org/wiki/Infinite_sets). A system of [cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_numbers) can be developed to extend the [role of natural numbers in answering "how many"](https://en.wikipedia.org/wiki/Cardinal_numeral). Most commonly, the [Aleph numbers](https://en.wikipedia.org/wiki/Aleph_numbers) $\aleph_0, \aleph_1, \aleph_2, ... \aleph_\omega, \aleph_{\omega+1}...$ are used, since their definition naturally extends the process of [counting](wikipedia://en/275768), and it can be shown that every infinite set has cardinality equivalent to some Aleph.

The set of natural numbers has cardinality $\aleph_0$. The question of whether the real numbers have cardinality $\aleph_1$ is known as the [continuum hypothesis](wikipedia://en/5705), which has been shown to be both [unprovable and undisprovable](wikipedia://en/1141208) in standard set theories such as [Zermelo–Fraenkel set theory](wikipedia://en/152214). Alternative set theories and additional [axioms](https://en.wikipedia.org/wiki/Axioms) give rise to different properties and have often strange or unintuitive consequences. However, every theory of cardinality using standard logical foundations of mathematics admits [Skolem's paradox](wikipedia://en/1348798).

The basic concepts of cardinality go back as early as the 6th century BCE, and there are several close encounters with it throughout history, however, the results were generally dismissed as paradoxical. It is considered to have been first introduced formally to mathematics by [Georg Cantor](wikipedia://en/12216) at the turn of the 20th century. Cantor's theory of cardinality was then formalized, popularized, and explored by many influential mathematicians of the time, and has since become a fundamental concept of mathematics.

## Basics {#Basics}

::: {#o4 .definition cue=heading name="Definition"}

### Definition {#Definition}

Cardinality is an inherent property of [sets](wikipedia://en/26691) which defines their size, roughly meaning the number of individual [objects](wikipedia://en/19453961) they contain.[^o5] Fundamentally however, it is different from the concepts of [number](wikipedia://en/21690) or [counting](wikipedia://en/275768) as the cardinalities of two sets can be compared without referring to their number of elements, or defining number at all. For example, in the image above, a set of apples is compared to a set of oranges such that every fruit is used exactly once which shows these two sets have the same cardinality, even if one does not know how many of each there are.[^o6] Thus, cardinality is measured by putting sets in so-called [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence): each object in one set can be assigned a dedicated "pair" in the other, and no object from either set left unpaired. If it is possible, the sets are said to have the *same cardinality*, and if not, one set is said to be *strictly larger* or *strictly smaller* than the other.[^o7]

:::

The basic concepts of cardinality are developed in terms of [sets](wikipedia://en/26691) and [functions](wikipedia://en/185427), which are more abstract than their counterparts outside of mathematics. Informally, a set can be understood as any collection of objects, usually represented with [curly braces](https://en.wikipedia.org/wiki/Curly_braces). For example, $S = \{1,2,3\}$ specifies a set, called $S$, which contains the numbers 1, 2, and 3. The symbol $\in$ represents set membership, for example $1 \in S$ says "1 is a member of the set $S$" which is true by the definition of $S$ above. Here $S$ is [finite](wikipedia://en/78818375), but that is not a requirement in general. The only requirement for a set is that it is well-defined. That is, for any object, $x$, one can determine whether $x$ belongs to that set $(x \in S)$, or $x$ does not belong to that set $(x \notin S)$. One example of an infinite set is the set of all natural numbers $\{ 1,2,3,\cdots \}$.[^o10]

A [function](wikipedia://en/185427), or correspondence, maps each member of one set to a unique member of another, often represented with an arrow diagram. For example, the adjacent table depicts several functions which map sets of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) to sets of letters. If a function does not map two members to the same place, it is called [injective](https://en.wikipedia.org/wiki/Injective). If a function covers every member in the output set, it is called [surjective](https://en.wikipedia.org/wiki/Surjective). If a function is both injective and surjective, it is called [bijective](https://en.wikipedia.org/wiki/Bijective) or a one-to-one correspondence. Functions are not limited to those one can draw an arrow diagram for, so long as the function is well-defined. That is, for each possible input, the output is defined. For example, one may define a function $f$ on the natural numbers by multiplying by two: $f(1) = 2, \;$$f(2) = 4, \;$$f(3) = 6, \dots \,$ $f(n) = 2n \dots$ [^o11]

### Etymology and related terms {#Etymology_and_related_terms}

The term *cardinality* originates from the [post-classical Latin](https://en.wikipedia.org/wiki/Post-Classical_Latin_language) *cardo* ("to hinge"), which referred to something central or pivotal, both literally and metaphorically. This passed into [medieval Latin](https://en.wikipedia.org/wiki/Medieval_Latin) and then into English, where *cardinal* came to describe things considered to be, in some sense, fundamental, such as, *[cardinal sins](https://en.wikipedia.org/wiki/Cardinal_sins)*, *[cardinal directions](https://en.wikipedia.org/wiki/Cardinal_directions)*, and (in linguistics) *[cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_numbers_%28linguistics%29)*.[^o13][^o14] The last of which referred to numbers used for counting (e.g., *one*, *two*, *three*),[^o15] as opposed to *[ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_numbers_%28linguistics%29)*, which express order (e.g., *first, second, third*),[^o16] and *[nominal numbers](https://en.wikipedia.org/wiki/Nominal_number)* used for labeling without meaning (e.g., [jersey numbers](https://en.wikipedia.org/wiki/Jersey_numbers) and [serial numbers](https://en.wikipedia.org/wiki/Serial_numbers)).[^o17]

In mathematics, the notion of cardinality was first introduced by German mathematician [Georg Cantor](wikipedia://en/12216) in the late 19th century, who used the term *Mächtigkeit*, which may be translated as "magnitude" or "power", though Cantor credited the term to a work by [Jakob Steiner](wikipedia://en/567445) on [projective geometry](wikipedia://en/243849).[^o18] Around 1930, the terms *cardinality* and *cardinal number* were adopted from the grammatical sense, and later translations would use these terms.[^o19][^o20]

## Comparing sets {#Comparing_sets}

::: {#o23 .pointer-item cue=pointer name="Equinumerosity"}

### Equinumerosity {#Equinumerosity}

*Image: Aplicación 2 inyectiva sobreyectiva04.svg.* A one-to-one correspondence from **N**, the set of all non-negative integers, to the set **E** of non-negative [even numbers](https://en.wikipedia.org/wiki/Even_number). Although **E** is a proper subset of **N**, both sets have the same cardinality.

An intuitive relationship between two sets having the "same size" is that their objects can be paired one-to-one. That is, if each object in one set can be assigned a dedicated "pair" in the other, and no object from either set left unpaired, there are the same number of objects in each set. A one-to-one pairing between two sets defines a bijective function between them by mapping each object to its pair. Similarly, a bijection between two sets defines a pairing of their elements by pairing each object with the one it maps to. Therefore, these notions of "pairing" and "bijection" are, at least intuitively, equivalent.[^o24] Thus, the following definition is given:

Two sets are said to have the *same cardinality* or be *equinumerous* if their members can be paired one-to-one. That is, if there exists a function between them which is bijective. This is often written as $A \sim B$, or $A \approx B$. Alternatively, these sets may be said to be *equivalent*, *similar*, *equipotent*, or *equipollent*. For example, the set $E = \{0, 2, 4, 6, \text{...}\}$ of [even numbers](https://en.wikipedia.org/wiki/Even_number) has the same cardinality as the set $\mathbb{N} = \{0, 1, 2, 3, \text{...}\}$ of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), since the function $f(n) = 2n$ is a bijection from $\mathbb{N}$ to $E$.[^o25]

The property for finite sets that "the whole is greater than the part" is no longer true for infinite sets, and the existence of surjections or injections that do not work does not prove that there is no bijection. For example, the function $g$ from $\mathbb{N}$ to $E$, defined by multiplying by 4, $g(n) = 4n$, is injective, but not surjective (since 2, for instance, is not mapped to). Further, the function $h$ from $\mathbb{N}$ to $E$, defined by rounding down to the nearest even number, $h(n) = 2 \operatorname{floor}(n/2)$ (cf. *[floor function](https://en.wikipedia.org/wiki/Floor_function)*), is surjective, but not injective, (since 0 and 1 for instance both map to 0). Neither $g$ nor $h$ can challenge $E \sim \mathbb{N}$, which was established by the existence of $f$.[^o26]

#### Equivalence {#Equivalence}

*Image: Example for a composition of two functions.svg.* The composition of two functions applies one function to the output of another: $(g \circ f)(x) = g(f(x))$.

A fundamental result in developing a theory of cardinality is that equinumerosity forms an [equivalence relation](wikipedia://en/9259)that is, a [relation](wikipedia://en/22517558) satisfying the same three basic properties as equality: [reflexivity](wikipedia://en/200458), [symmetry](wikipedia://en/200459), and [transitivity](wikipedia://en/200463).[^o28]

Reflexivity, the property that every set has the same cardinality as itself $(A \sim A)$, follows from the [identity function](wikipedia://en/15069): for any set $A$, the function that maps each element to itself is a bijection from $A$ to **$A$**. Symmetry, the property that, if $A$ has the same cardinality as $B$ $(A \sim B)$, then $B$ has the same cardinality as $A$ $(B \sim A)$, holds because any bijection $f:A \to B$ has an [inverse function](wikipedia://en/14907) $f^{-1}:B \to A$, which is also bijective. Transitivity, the property that if $A$ and $B$ have the same cardinality $(A \sim B)$, and $B$ and $C$ have the same cardinality $(B \sim C)$ then so do $A$ and $C$ $(A \sim C)$, follows from the [composition of functions](https://en.wikipedia.org/wiki/Composition_of_functions): given bijections $f:A \to B$ and $g:B \to C$, their composition $g \circ f$ is a bijection from $A$ to $C$ (see image).[^o28]

Since equinumerosity satisfies all three properties, it is an equivalence relation. This means that it groups sets into [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes)groups of sets that are all equinumerous with one anotherwhere each group defines a possible size of a set. This motivates the notion of [cardinal numbers](wikipedia://en/6173), which are [representatives](https://en.wikipedia.org/wiki/Representative_%28mathematics%29) that stand for the "size" of each group, developed in [the section below](wikipedia://en/6174#Cardinal_numbers).[^o29]

:::

### Inequality {#Inequality}

*Image: Square to circle bijection.webm.* Given the two injections between a circle and a square above, the Schröder–Bernstein theorem constructs the following bijection.[^o36]

A set $A$ is not larger than a set $B$ if it can be mapped into $B$ without overlap. That is, the cardinality of $A$ is less than or equal to the cardinality of $B$ if there is an [injective function](wikipedia://en/45196) from $A$ to **$B$**, or equivalently, if there is a surjection from **$B$** to $A$ (or $A$ is [empty](wikipedia://en/9566)). This is written $A \preceq B$, or $A \lesssim B$. and read as "$A$ is *not greater than* $B$," or "$A$ is *dominated by* $B$."[^o32] If $A \preceq B$, but there is no injection from $B$ to $A$, then $A$ is said to be *strictly* smaller than $B$, written without the underline as $A \prec B$.[^o33] For example, if $A$ has four elements and $B$ has five, then the following are true $A \preceq A$, $A \preceq B$, and $A \prec B$.

The [basic properties of an inequality](wikipedia://en/89489#Formal_definitions_and_generalizations) are reflexivity (for any $a$, $a \leq a$), transitivity (if $a \leq b$ and $b \leq c$, then $a \leq c$) and [antisymmetry](wikipedia://en/1176) (if $a \leq b$ and $b \leq a$, then $a = b$). Cardinal inequality $(\preceq)$ as defined above is reflexive since the [identity function](wikipedia://en/15069) is injective, and is transitive by function composition.[^o34] Antisymmetrythe fact that, given injections in both directions, then one can find a bijectionis non-trivial, and is the content of the so-called [Schröder–Bernstein theorem](wikipedia://en/44218028).[^o35] One such proof can be summarized as follows, with the help of the adjacent illustration:

Given injections in both directions ($f: A \to B$, and $g: B \to A$), take set $A$ and "color" each point blue. Then take the [image](wikipedia://en/579311) of set $B$ on $A$ after the injectionthat is, the set of points that the injection projects on toand color those red. Then take the image of $A$ on this image of $B$, and color those points blue again. By [recursively](https://en.wikipedia.org/wiki/Recursively) alternating the images of these sets, one obtains a "coloring" of the original set (see illustration). For each point, it either stops at some finite stepand thus is definitively colored blue or redor continues switching indefinitely. Of the points in $A$ that are definitively colored blue, map them into the next recursive image (i.e. by applying $f$ then $g$), leaving all other points in place. This transforms the set $A$ into exactly the image of $B$. Taking this transformation, followed by the inverse of $g$, gives a bijection from $A$ to $B$ (since $g$ is injective and surjective on its image, its inverse is bijective).[^o36]

A further property of cardinal inequality is [totality](wikipedia://en/57495962), which says that any two sets are comparable. That is, for any $a$ and $b$, either $a \leq b$ or $b \leq a$. A full proof of which requires concepts introduced later, however the argument can be briefly summarized as follows. Every [well-ordered](wikipedia://en/33456) set is [isomorphic](https://en.wikipedia.org/wiki/Order_isomorphic) to a unique [ordinal number](wikipedia://en/26547932), called the [order type](wikipedia://en/4499021) of the set. By the [well-ordering theorem](wikipedia://en/33458), every set can be well-ordered. Then, by comparing their order types, one can show that $A \preceq B$ or $B \preceq A$. This fact is equivalent to the [axiom of choice](wikipedia://en/840).[^o37]

:::

## Countability {#Countability}

### Countable sets {#Countable_sets}

A set is called *[countable](https://en.wikipedia.org/wiki/Countable)* if it is [finite](wikipedia://en/11742) or has a bijection with the set of [natural numbers](wikipedia://en/21474) $(\mathbb{N})$, in which case it is called *countably infinite*. The term *[denumerable](https://en.wikipedia.org/wiki/Denumerable)* is also sometimes used for countably infinite sets.[^o40] For example, the set of all even natural numbers is countable, and therefore has the same cardinality as the whole set of natural numbers, even though it is a [proper subset](https://en.wikipedia.org/wiki/Proper_subset). Similarly, the set of [square numbers](https://en.wikipedia.org/wiki/Square_numbers) is countable, which was considered paradoxical for hundreds of years before modern set theory (cf. ). However, several other examples have historically been considered surprising or initially unintuitive since the rise of set theory.[^o41]

The [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) $(\mathbb{Q})$ are those which can be expressed as the [quotient](wikipedia://en/332640) or [fraction](https://en.wikipedia.org/wiki/Fraction_%28mathematics%29) $\tfrac p q$ of two [integers](wikipedia://en/14563). The rational numbers can be shown to be countable by considering the set of fractions as the set of all [ordered pairs](https://en.wikipedia.org/wiki/Ordered_pairs) of integers, which can be visualized as the set of all [integer points](wikipedia://en/3333402) on a grid. Then, an intuitive function can be described by drawing a line in a repeating pattern, or spiral, which eventually goes through each point in the grid. For example, going through each diagonal on the grid for positive fractions, or through a lattice spiral for all integer pairs.[^o42] These over-cover the rationals, since, for example, the fractions $\textstyle\frac{2}{4},\, \frac{3}{6}, \, \frac{4}{8}, \, \dots$ all get mapped to $\textstyle\frac{1}{2}$, as the grid method treats these all as distinct ordered pairs. So this function shows $\vert \mathbb{Q} \vert \leq \vert \mathbb{N} \vert$ not $\vert \mathbb{Q} \vert = \vert \mathbb{N} \vert$. This can be corrected by "skipping over" these numbers in the grid, using the Schröder–Bernstein theorem, or by designing a function which does this naturally, for example using the [Calkin–Wilf tree](wikipedia://en/22672164).[^o43]

*Image: Algebraicszoom.png.* Algebraic numbers on the [complex plane](wikipedia://en/217628), colored by degree

A number is called [algebraic](wikipedia://en/1158) if it is a solution of some [polynomial](wikipedia://en/23000) equation with integer [coefficients](wikipedia://en/51203). For example, the [square root of two](https://en.wikipedia.org/wiki/Square_root_of_two) $\sqrt2$ is a solution to $x^2 - 2 = 0$, and the rational number $p/q$ is the solution to $qx - p = 0$. Conversely, a number which cannot be the root of any polynomial is called [transcendental](wikipedia://en/30325). Two examples include [Euler's number](https://en.wikipedia.org/wiki/Euler's_number) (*$e$*) and [pi ($\pi$)](wikipedia://en/23601). In general, proving a number is transcendental is considered to be very difficult, and only a few classes of transcendental numbers are known. However, it can be shown that the set of algebraic numbers is countable by ordering the polynomials [lexicographically](https://en.wikipedia.org/wiki/Lexicographically) (for example, see *Cantor's first set theory article*). Since the set of algebraic numbers is countable while the real numbers are uncountable (shown in [the following subsection](wikipedia://en/6174#Uncountable_sets)), the transcendental numbers must form the vast majority of real numbers, even though they are individually much harder to identify. That is to say, [almost all](wikipedia://en/1309) real numbers are transcendental.[^o44]

#### Hilbert's hotel {#Hilbert's_hotel}

*Image: Hilbert's Hotel.png.* Visual representation of [Hilbert's hotel](https://en.wikipedia.org/wiki/Hilbert's_hotel). Each guest goes to the room with a number that is double their room number, leaving the odd-numbered rooms vacant.

[Hilbert's paradox of the Grand Hotel](wikipedia://en/37797) is a popular [thought experiment](wikipedia://en/49535) devised by the German mathematician [David Hilbert](wikipedia://en/8302) to illustrate a counterintuitive property of countably infinite sets, allowing them to have the same cardinality as a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of themselves. The scenario begins by imagining a hotel with an infinite number of rooms, one for each natural number, all of which are occupied. But then a new guest walks in asking for a room. The hotel accommodates by moving the occupant of room 1 to room 2, the occupant of room 2 to room 3, room 3 to room 4, and in general, room n to room n+1. Then every guest still has a room, but room 1 is open for the new guest.[^o46]

Then, the scenario continues by imagining an infinitely long bus of new guests seeking a room. The hotel accommodates by moving the person in room 1 to room 2, room 2 to room 4, and in general, room n to room 2n. Thus, all the even-numbered rooms are occupied, but all the odd-numbered rooms are vacant, leaving room for the infinite bus of new guests. The scenario continues further by assuming an infinite number of these infinite buses arrive at the hotel, and showing that the hotel is still able to accommodate. Finally, an infinite bus which has a seat for every [real number](wikipedia://en/20646438) arrives, and the hotel is no longer able to accommodate.[^o46]

### Uncountable sets {#Uncountable_sets}

A set is called *[uncountable](https://en.wikipedia.org/wiki/Uncountable)* if it is not countable; that is, it is infinite and strictly larger than the set of natural numbers. The usual first example of this is the set of [real numbers](https://en.wikipedia.org/wiki/Real_numbers) $(\mathbb{R})$, which can be understood as the set of all numbers on the [number line](wikipedia://en/287188). One method of proving that the reals are uncountable is called [Cantor's diagonal argument](wikipedia://en/51426), credited to Cantor for his 1891 proof,[^o48] though his method differs from the more common presentation.[^o49]

$$\begin{aligned} 1 \to & \; 0.{ \color{red} \textbf{6} }18033... \\ 2 \to & \; 0.1{ \color{red}\textbf{2} }3456... \\ 3 \to & \; 0.60{ \color{red}\textbf{7} }927... \\ 4 \to & \; 0.222{ \color{red}\textbf{2} }22... \\ \vdots \\ & \; 0.{ \color{red}\textbf{2323}22}... \end{aligned}$$

It begins by assuming, [by contradiction](https://en.wikipedia.org/wiki/Proof_by_contradiction), that there is some one-to-one mapping between the natural numbers and the set of real numbers between 0 and 1 (the interval $[0,1]$). Then, take the [decimal representation](wikipedia://en/3293594) of each real number, for example, $0.5772...$ with a leading zero followed by any sequence of digits. The number 1 is included in this set since 1 = [0.999...](wikipedia://en/1849799) Considering these real numbers in a list, it is always possible to create a new number such that the first digit of the new number is different from that of the first number in the list, the second digit is different from the second number in the list, and so on. The new number must also have a unique decimal representation, that is, it cannot end in [repeating nines](wikipedia://en/1849799) or repeating zeros. For example, if the digit is not 2, make the digit of the new number 2, and if it was 2, make it 3.[^o50] Then, this new number will be different from each of the numbers in the list by at least one digit, and therefore must not be in the list. This shows that the real numbers cannot be put into a one-to-one correspondence with the naturals, and thus must be strictly larger.[^o51]

*Image: Diagonal argument powerset svg.svg.* $\mathbb{N}$ does not have the same cardinality as its [power set](wikipedia://en/23799) $\mathcal{P}(\mathbb{N})$: For every function *f* from **$\mathbb{N}$** to $\mathcal{P}(\mathbb{N})$, the set $T = \{n \in N : n \notin f(n) \}$ disagrees with every set in the [range](wikipedia://en/275991) of $f$, hence $f$ cannot be surjective. The picture shows an example $f$ and the corresponding $T$; \#800000: $n \notin T$, \#000080: $n \in T$.

Another classical example of an uncountable set, established using a related reasoning, is the [power set](wikipedia://en/23799) of the natural numbers, denoted $\mathcal{P}(\mathbb{N})$. This is the set of all [subsets](https://en.wikipedia.org/wiki/Subsets) of $\mathbb{N}$, including the [empty set](wikipedia://en/9566) and $\mathbb{N}$ itself. The method is much closer to Cantor's original diagonal argument. Again, assume by contradiction that there exists a one-to-one correspondence $f$ between $\mathbb{N}$ and $\mathcal{P}(\mathbb{N})$, so that every subset of $\mathbb{N}$ is assigned to some natural number. These subsets are then placed in a list, in the order defined by $f$ (see image). Now, one may define a subset $T$ of $\mathbb{N}$ which is not in the list by taking the negation of the "diagonal" of this list as follows:[^o52]

If $1 \in f(1)$, then $1 \notin T$, that is, if 1 is in the first subset of the list, then 1 is *not* in the subset $T$. Further, if $2 \notin f(2)$, then $2 \in T$, that is if the number 2 is not in the second subset of the list, then 2 *is* in the subset $T$. Then in general, for each natural number $n$, $n \in T$ if and only if $n \notin f(n)$, meaning $n$ is put in the subset $T$ only if the nth subset in the list does not contain the number $n$. Then, for each natural number $n$, $T \neq f(n)$, meaning, $T$ is not the nth subset in the list, for any number $n$, and so it cannot appear anywhere in the list defined by $f$. Since $f$ was chosen arbitrarily, this shows that every function from $\mathbb{N}$ to $\mathcal{P}(\mathbb{N})$ must be missing at least one element, therefore no such bijection can exist, and so $\mathcal{P}(\mathbb{N})$ must be not be countable.[^o52]

These two sets, $\mathbb{R}$ and $\mathcal{P}(\mathbb{N})$ can be shown to have the same cardinality (by, for example, assigning each subset to a decimal expansion) called the [cardinality of the continuum](wikipedia://en/6174#Cardinality_of_the_continuum).[^o53]

[Cantor's theorem](wikipedia://en/341442) generalizes the second theorem above, showing that every set is strictly smaller than its powerset. In broad strokes, the proof goes as follows: Given a set $A$, assume by contradiction that there is a bijection $f$ from $A$ to $\mathcal{P}(A)$. Then, the subset $T \subseteq A$ given by taking the negation of the "diagonal", formally, $T = \{ a \in A : a \notin f(a) \}$, cannot be in the list. Therefore, every function is missing at least one element, and so $\vert A \vert < \vert\mathcal{P}(A)\vert$. Further, since $\mathcal{P}(A)$ is itself a set, the argument can be repeated to show $\vert A \vert < \vert \mathcal{P}(A)\vert < \vert\mathcal{P}(\mathcal{P}(A))\vert$. Taking $A = \mathbb{N}$, this shows that $\mathcal{P}(\mathcal{P}(\mathbb{N}))$ is even larger than $\mathcal{P}(\mathbb{N})$, which was already shown to be uncountable. Repeating this argument shows that there are infinitely many "sizes" of infinity.[^o54]

## Cardinal numbers {#Cardinal_numbers}

In the above sections, "the cardinality of a set" was described relationally. In other words, one set could be compared to another, intuitively comparing their "size". [Cardinal numbers](wikipedia://en/6173) are a means of measuring this "size" more explicitly. For finite sets, this is simply the [natural number](wikipedia://en/21474) found by counting the elements. This number is called the *cardinal number* of that set, or simply *the cardinality* of that set. The cardinal number of a set $A$ is generally denoted by $\vert A \vert$, with a [vertical bar](wikipedia://en/641073) on each side,[^o56] though it may also be denoted by $A$, $\operatorname{card}(A)$, or $\#A$.

For infinite sets, "cardinal number" is somewhat more difficult to define formally. However, cardinal numbers are not usually thought of in terms of their formal definition, but immaterially in terms of their arithmetic/algebraic properties.[^o57] The assumption that there is *some* [cardinality function](wikipedia://en/6173#Cardinality_function) $A \mapsto \vert A \vert$ which satisfies $A \sim B \iff \vert A \vert = \vert B \vert$ (in prose, "two sets are equinumerous exactly when they map to the same cardinal number"), sometimes called the *axiom of cardinality*[^o58] or *[Hume's principle](wikipedia://en/314743)*,[^o59] is sufficient for deriving most properties of cardinal numbers.[^o60]

Commonly in mathematics, if a relation satisfies the properties of an [equivalence relation](wikipedia://en/9259), the objects used to materialize this relation are [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes), each of which group objects equivalent to one another. These equivalence classes are called the *FregeRussell* cardinal numbers.[^o61] However, these equivalence classes are too large to form sets (apart from the cardinal number $\mathbf 0$ whose only element is the [empty set](wikipedia://en/9566)), since, for example, the cardinal number $\mathbf 1$ would be the set of all sets with one element, then $\{ \mathbf 1 \} \in \mathbf 1$, and would therefore contain itself, violating [regularity](wikipedia://en/2113).[^o62] Thus, due to [John von Neumann](wikipedia://en/15942), it is more common to assign [representatives](https://en.wikipedia.org/wiki/Representative_%28mathematics%29) of these classes.[^o63]

### Finite cardinals {#Finite_cardinals}

*Image: Bijection.svg.* A [bijective function](https://en.wikipedia.org/wiki/Bijective_function), $f: X \to Y$ from the set X = {1,2,3,4} to the set Y demonstrates that Y has cardinality 4.

Given a basic sense of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), a set is said to have cardinality $n$ if it can be put in one-to-one correspondence with the set $\{1,\,2,\, \dots, \, n \}$, analogous to [counting](wikipedia://en/275768) its elements. For example, the set $S = \{ A,B,C,D \}$ has a natural correspondence with the set $\{1,2,3,4\}$, and therefore is said to have cardinality 4. Other terminologies include "Its cardinality is 4" or "Its cardinal number is 4". In formal contexts, the natural numbers can be understood as some construction of objects satisfying the [Peano axioms](wikipedia://en/25005)a list of properties, such that any system satisfying these properties is, [in a certain sense](wikipedia://en/14828), just like the natural numbers.[^o66]

Showing that such a correspondence exists is not always trivial. [Combinatorics](wikipedia://en/5170) is the area of mathematics primarily concerned with [counting](wikipedia://en/275768), both as a means and as an end to obtaining results, and certain properties of finite structures.[^o67] The notion cardinality of finite sets is closely tied to many basic [combinatorial principles](wikipedia://en/1588279), and provides a set-theoretic foundation to recover them. It can be shown [by induction](https://en.wikipedia.org/wiki/By_induction) on the possible sizes of sets that finite cardinality corresponds uniquely with natural numbers (cf. *Finite set*).[^o68] This is related to several other concepts, verifying Hume's principle and the basis of [bijective proofs](wikipedia://en/917006), and is equivalent to a certain formulation of the [pigeonhole principle](wikipedia://en/54217), that a finite set cannot be put in one to one correspondence with a proper subset of itself.[^o69]

The [addition principle](wikipedia://en/1594239) asserts that given [disjoint](wikipedia://en/39359) sets $A$ and $B$, $\vert A \cup B\vert = \vert A \vert + \vert B \vert$, intuitively meaning that the sum of the parts is equal to the whole.[^o70] The [multiplication principle](https://en.wikipedia.org/wiki/Multiplication_principle) asserts that given two sets $A$ and $B$, $\vert A \times B\vert = \vert A \vert \cdot \vert B \vert$, intuitively meaning that there are $\vert A \vert \cdot \vert B \vert$ ways to pair objects from these sets.[^o71] Both of these can be proven by a [bijective proof](wikipedia://en/917006), together with induction.[^o72] The more general result is the [inclusion–exclusion principle](wikipedia://en/342684), which defines how to count the number of elements in overlapping sets.[^n1]

Naturally, a set is defined to be finite if it is [empty](wikipedia://en/9566) or can be put in correspondence with the set $\{1,\,2,\, \dots, \, n\}$, for some natural number $n$.[^o65] However, there exist [other definitions of "finite"](wikipedia://en/11742#Necessary_and_sufficient_conditions_for_finiteness) which do not rely on a definition of "number." For example, a set is called [Dedekind-finite](https://en.wikipedia.org/wiki/Dedekind-finite) if it cannot be put in one-to-one correspondence with a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of itself, though this definition requires the [axiom of choice](wikipedia://en/6174#Without_the_axiom_of_choice) to be equivalent to the original definition.[^o74]

### Aleph numbers {#Aleph_numbers}

*Image: Aleph0.svg.* [Aleph-nought](https://en.wikipedia.org/wiki/Aleph-nought), aleph-zero, or aleph-null: the smallest infinite cardinal number, and the cardinal number of the set of natural numbers.[^o76]

The [aleph numbers](https://en.wikipedia.org/wiki/Aleph_numbers) are a sequence of cardinal numbers that represent the sizes of [infinite sets](https://en.wikipedia.org/wiki/Infinite_sets), denoted with an [aleph](https://en.wikipedia.org/wiki/Aleph) $\aleph$, the first letter of the [Hebrew alphabet](https://en.wikipedia.org/wiki/Hebrew_alphabet).[^o76] The first aleph number is $\aleph_0$, called "aleph-nought", "aleph-zero", or "aleph-null", which represents the cardinality of the set of all [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers): $\aleph_0 = \vert \mathbb{N} \vert = \vert\{0,1,2,3,\cdots\}\vert$. Then, $\aleph_1$ represents the next largest cardinality, then $\aleph_2$, and so on.[^o77] The most common way this is formalized in set theory is through [Von Neumann ordinals](https://en.wikipedia.org/wiki/Von_Neumann_ordinal), known as [Von Neumann cardinal assignment](https://en.wikipedia.org/wiki/Von_Neumann_cardinal_assignment).[^o78]

[Ordinal numbers](wikipedia://en/26547932) generalize the notion of *order* to infinite sets. For example, 2 comes after 1, denoted $1 < 2$, and 3 comes after both, denoted $1 < 2 < 3$. Then, one defines a new number, $\omega$, which comes after every natural number, denoted $1 < 2 < 3 < \cdots < \omega$. Further $\omega < \omega+1< \dots < \omega+\omega=\omega\cdot 2$, and so on.[^o79] More formally, these ordinal numbers can be defined as follows:

$0 := \{\}$, the [empty set](wikipedia://en/9566), $1 := \{0\}$, $2 := \{0,1\}$, $3 := \{0,1,2\}$, and so on. Then one can define $m < n \text{, if } \, m \in n$, for example, $2 \in \{0,1,2\} = 3$, therefore $2 < 3$. Defining $\omega := \{0,1,2,3,\cdots\}$ gives $\omega$ the desired property of being the smallest ordinal greater than all finite ordinal numbers. Further, $\omega+1 := \{0,1,\cdots,\omega\}$, and so on.[^o80]

Since $\omega \sim \mathbb{N}$ by the natural correspondence, one may define $\aleph_0$ as the set of all finite ordinals. That is, $\aleph_0 := \omega$. Then, $\aleph_1$ is the set of all countable ordinals (all ordinals $\alpha$ with cardinality $\vert \alpha \vert \leq \aleph_0$), the [first uncountable ordinal](wikipedia://en/20860540). Since a set cannot contain itself, $\aleph_1$ must have a strictly larger cardinality: $\aleph_0 < \aleph_1$.[^o81] Furthermore, $\aleph_2$ is the set of all ordinals with cardinality less than or equal to $\aleph_1$, and in general the [successor cardinal](wikipedia://en/375210) $\kappa^+$is the set of all ordinals with cardinality up to $\kappa$. Put another way for infinite cardinals, $\kappa^+$ is the number of possible [well-orderings](wikipedia://en/33456) on $\kappa$ up to [order isomorphism](wikipedia://en/23916899).[^o82] Proving that such a set always exists is known as Hartogs' theorem, wherein the smallest ordinal not less or equal to than a set $\kappa$ is called the [Hartogs number](wikipedia://en/2977752) of $\kappa$.[^o83] Then, $\aleph_\lambda$ for a limit ordinal $\lambda$ is the [union](wikipedia://en/47949) of all lesser alephs.[^o84]

The importance of ordinal numbers here is to generalize the notion of counting to infinite sets. When counting, one implicitly assigns an order to their set of objects, but no matter what order one assigns the final result of the count is always the same, which demonstrates the connection between cardinal and ordinal numbers.[^o85] Further, by the [well-ordering theorem](wikipedia://en/33458), there cannot exist any set with cardinality between $\aleph_0$ and $\aleph_1$, and every infinite set has some cardinality corresponding uniquely to some aleph $\aleph_\alpha$, for some ordinal $\alpha$.[^o86] This allows one to use a constructive definition of the cardinality function, by assigning each set to its equinumerous aleph.[^o87]

### Cardinal arithmetic {#Cardinal_arithmetic}

*Image: AdditionShapes.svg.* The addition of the objects from the two disjoint sets is an instance of $3 + 2 = 5$.

Basic arithmetic can be done on cardinal numbers in a very natural way, by extending the theorems for finite combinatorial principles above. The intuitive principle that if $A$ and $B$ are disjoint then addition of these sets is simply taking their [union](wikipedia://en/47949), written as $\vert A \cup B\vert = \vert A \vert + \vert B \vert$.[^o89] Thus if $A$ and $B$ are infinite, cardinal addition is defined as $\vert A \vert + \vert B \vert := \vert A \sqcup B\vert$ where $\sqcup$ denotes [disjoint union](wikipedia://en/188946). Similarly, the multiplication of two sets is intuitively the number of ways to pair their elements (as in the [multiplication principle](https://en.wikipedia.org/wiki/Multiplication_principle)), therefore cardinal multiplication is defined as $\vert A \vert \cdot \vert B \vert := \vert A \times B\vert$, where $\times$ denotes the [Cartesian product](wikipedia://en/24104095).[^o90] These definitions can be shown to satisfy the basic properties of standard arithmetic:[^o91]

- [Associativity](https://en.wikipedia.org/wiki/Associativity): $\vert A \vert + \vert B \sqcup C\vert = \vert A \sqcup B\vert + \vert C \vert$, and $\vert A \vert \cdot \vert B \times C \vert = \vert A \times B \vert \cdot \vert C \vert$
- [Commutativity](https://en.wikipedia.org/wiki/Commutativity): $\vert A \vert + \vert B \vert = \vert B \vert + \vert A \vert$, and $\vert A \vert \cdot \vert B \vert = \vert B \vert \cdot \vert A \vert$
- [Distributivity](https://en.wikipedia.org/wiki/Distributivity): $\vert A \vert \cdot \vert B \sqcup C\vert = \vert A \times B\vert + \vert A \times C\vert$

Although a lot of properties of finite arithmetic hold for infinite arithmetic, as above and in the table below, strict inequalities (such as [Kőnig's theorem](wikipedia://en/184082)) are rare. For example, in finite arithmetic, for any nonzero number $n$, $n+n > n$. However, since both the set of even numbers $(E)$ and set of odd numbers $(F)$ have cardinality $\aleph_0$, it shows $\vert E \sqcup F \vert = \vert \mathbb{N} \vert$ thus $\aleph_0 + \aleph_0 = \aleph_0$. In fact, for any infinite cardinal, $\kappa+\kappa=\kappa\cdot\kappa=\kappa$. In this way, infinite cardinal addition and multiplication are considered to be remarkably well-behaved (at least under the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice)).[^o92]

Cardinal exponentiation $\vert A \vert^{\vert B \vert}$ is defined via [set exponentiation](https://en.wikipedia.org/wiki/Set_exponentiation), the set of all functions $f:B \mapsto A$, that is, $\vert A \vert^{\vert B \vert} := \vert A^B\vert$ which naturally extends the role of "repeated multiplication" to infinite sets.[^o93] For finite sets this can be shown to coincide with standard [natural number exponentiation](wikipedia://en/99491#Integer_exponents), but includes as a corollary that [zero to the power of zero](wikipedia://en/32130416) is one $(0^0 = 1)$ since there is exactly one function from the [empty set](wikipedia://en/9566) to itself: the [empty function](https://en.wikipedia.org/wiki/Empty_function).[^o94] A combinatorial argument can be used to show $2^{\vert A \vert} = \vert\mathcal{P}(A)\vert$, by considering the [indicator function](wikipedia://en/240790) of each subset. In general, cardinal exponentiation is not as well-behaved as addition and multiplication. For example, even though it can be proven that the expression $2^{\aleph_0}$does indeed correspond to some aleph, it is [unprovable](https://en.wikipedia.org/wiki/Unprovable) from standard set theories which aleph it corresponds to.[^o95]

### Set of all cardinal numbers {#Set_of_all_cardinal_numbers}

*Image: Frank-Rühl\_sample-Tav.svg.* The [Hebrew](https://en.wikipedia.org/wiki/Hebrew_alphabet) letter [Tav](https://en.wikipedia.org/wiki/Taw), denoting the [proper class](wikipedia://en/6174#Proper_classes) of all cardinal numbers[^o111]

The *set of all cardinal numbers* refers to a hypothetical set which contains all cardinal numbers. Such a set cannot exist, which has been considered paradoxical, and related to the [Burali-Forti paradox](wikipedia://en/51653). Using the definition of cardinal numbers as representatives of their cardinalities. It begins by assuming there is some set $S := \{ X \, \vert X \text{ is a cardinal number}\}$. Then, if there is some largest cardinal $\kappa \in S$, then the powerset $2^\kappa$ is strictly greater, and thus not in $S$. Conversely, if there is no largest element, then the [union](wikipedia://en/47949#Arbitrary_union) $\bigcup S$ contains the elements of all elements of $S$, and is therefore greater than or equal to each element. Since there is no largest element in $S$, for any element $x \in S$, there is another element $y \in S$ such that $\vert x \vert < \vert y \vert$ and $\vert y \vert \leq \Bigl\vert \bigcup S \Bigr\vert$. Thus, for any $x \in S$, $\vert x \vert < \Bigl\vert \bigcup S \Bigr \vert$, and so $\Bigl\vert \bigcup S \Bigr\vert \notin S$. Thus, the collection of all cardinal numbers is too large to form a set, and is a [proper class](wikipedia://en/6174#Proper_classes).[^o110] Georg Cantor denoted the collection of all cardinal numbers **Hebr** ([tav](https://en.wikipedia.org/wiki/Taw), the last letter of the [Hebrew alphabet](https://en.wikipedia.org/wiki/Hebrew_alphabet)), and considered it to be an "inconsistent multiplicity".[^o111]

## Cardinality of the continuum {#Cardinality_of_the_continuum}

*Image: Number line.png.* The [number line](wikipedia://en/287188), containing all points in its continuum

The [real numbers](wikipedia://en/20646438) $(\mathbb{R})$ formalize the intuitive notion of the *continuum*: the unbroken, gapless set of points on the [number line](wikipedia://en/287188).[^o113] There are numerous ways to construct and analyze the [continuum in set theory](wikipedia://en/24758677), for example, sets of [Cauchy sequences](https://en.wikipedia.org/wiki/Cauchy_sequences) of rational numbers, or [Dedekind cuts](wikipedia://en/45569). However, a somewhat informal definition as the set of infinite sequences of digits, e.g. $0.1234...$, with the usual arithmetic and order is a popular and sufficient choice for basic arguments involving the continuum.[^o114] The cardinality of this set, denoted "$\mathfrak c$" (a lowercase [fraktur script](https://en.wikipedia.org/wiki/Fraktur_%28script%29) "c"), turns out to be remarkably stable under various transformations.[^o115]

*Image: Cantor set binary tree.svg.* First five iterations approaching the [Cantor set](wikipedia://en/6172)

For example, all intervals on the real line e.g. $[0,1]$, and $[0,2]$, have the same cardinality as the entire set $\mathbb{R}$. First, $f(x) = 2x$ is a bijection from $[0,1]$ to $[0,2]$. The fact that two intervals of unequal length can be mapped one-to-one has been known, even if considered paradoxical, for thousands of years (cf. ).[^o116] Further, the [tangent function](https://en.wikipedia.org/wiki/Tangent_function) is a bijection from the interval $\textstyle\left( \frac{-\pi}{2} \, , \frac{\pi}{2} \right)$ to the whole real line. A more surprising example is the [Cantor set](wikipedia://en/6172), which is defined as follows: take the interval $[0,1]$ and remove the middle third $\textstyle( \frac{1}{3}, \frac{2}{3} )$, then remove the middle third of each of the two remaining segments, and continue removing middle thirds (see image). The Cantor set is the collection of points that survive this process. The remaining points are exactly those whose decimal expansion can be written in [ternary](wikipedia://en/62950) without a 1. Reinterpreting these decimal expansions as [binary](wikipedia://en/238686) (e.g. by replacing the 2s with 1s) gives a bijection between the Cantor set and the interval $[0,1]$. The Cantor set has a [measure](wikipedia://en/19873) or "length" of zero, and yet is still equinumerous to the whole real line.[^o117]

*Image: Peanocurve.svg.* Three iterations of a [Peano curve](wikipedia://en/358330) construction, whose [limit](wikipedia://en/285773) is a [space-filling curve](wikipedia://en/352398)

In the other direction, into higher dimensions, one can find a bijective map between a one-dimensional line and a two-dimensional square. Given a point in the [unit square](wikipedia://en/285301) in $\mathbb{R}^2$ (two-dimensional space) $\textstyle(0.a_1 a_2 a_3... \, , 0.b_1 b_2 b_3...)$, one can interleave their digits to get the unique number $\textstyle0.a_1 b_1 a_2 b_2...$ in the [unit interval](wikipedia://en/49324) $[0,1]$.[^o118] [Space-filling curves](https://en.wikipedia.org/wiki/Space-filling_curves) offer a more visual proof, giving a continuous map from the unit interval onto the unit square. Classical examples include the [Peano curve](wikipedia://en/358330) and [Hilbert curve](https://en.wikipedia.org/wiki/Hilbert_curve). Although these maps are not bijective, they are indeed sufficient to show $\vert \mathbb{R}^2 \vert \leq \vert \mathbb{R} \vert$ with the converse being immediate. Both of these methods can be reused at each dimension to show that $\vert \mathbb{R}^n \vert = \vert \mathbb{R}^{n+1}\vert$ and thus $\vert \mathbb{R} \vert = \vert \mathbb{R}^n\vert$ for any dimension $n \geq 1$.[^o119] Further, the infinite [cartesian product](wikipedia://en/24104095) $\mathbb{R}^\infty$ can also be shown to be equinumerous to $\mathbb{R}$ by cardinal arithmetic: $\textstyle \vert \mathbb{R}^\infty\vert = \vert \mathbb{R} \vert^{\aleph_0} = (2^{\aleph_0} )^{\aleph_0} = 2^{(\aleph_0 \cdot \aleph_0)} = 2^{\aleph_0} = \vert \mathbb{R} \vert$. Thus, the real numbers, all finite-dimensional real spaces, and the countable cartesian product have the same cardinality.[^o120]

As shown in , the set of real numbers is strictly larger than the set of natural numbers. Specifically, $\vert \mathbb{R} \vert = \vert\mathcal{P}(\mathbb{N})\vert$. The [Continuum Hypothesis](https://en.wikipedia.org/wiki/Continuum_Hypothesis) (CH) asserts that the real numbers have the next largest cardinality after the natural numbers, that is $\vert \mathbb{R} \vert = \aleph_1$. As shown by [Gödel](wikipedia://en/16736) and [Cohen](wikipedia://en/22994), the continuum hypothesis is [independent](wikipedia://en/1141208) of [ZFC](https://en.wikipedia.org/wiki/Zermelo–Fraenkel_set_theory_with_the_axiom_of_choice), a standard axiomatization of set theory; that is, it is impossible to prove the continuum hypothesis or its negation from ZFC—provided that ZFC is [consistent](wikipedia://en/75802), meaning it produces no contradictions.[^o121] ZFC imposes relatively little restriction on the cardinality of $\mathbb{R}$. [Easton's theorem](wikipedia://en/4691250) shows that ZFC only requires two conditions: that $\vert\mathbb{R}\vert > \aleph_0$, and a limit on its [cofinality](wikipedia://en/6693) (roughly, how difficult it is to approach $\mathfrak c$ from below) implying that $\vert\mathbb{R}\vert \neq \aleph_\omega$, though this is not an upper bound as it does not disallow the possibility that $\vert\mathbb{R}\vert = \aleph_ { \omega +1 }$.[^o122] The [Generalized Continuum Hypothesis](https://en.wikipedia.org/wiki/Generalized_Continuum_Hypothesis) (GCH) extends this to all infinite cardinals, stating that $2^{\aleph_\alpha} = \aleph_{\alpha+1}$ for every ordinal $\alpha$. Research on CH and GCH continues independent of ZFC, especially in [descriptive set theory](wikipedia://en/396619) and through the exploration of [large cardinal axioms](wikipedia://en/6174#Large_cardinals).[^o123] Without GCH, the cardinality of $\mathbb{R}$ cannot be written in terms of specific alephs. The [Beth numbers](https://en.wikipedia.org/wiki/Beth_numbers) ( $\textstyle\beth$, the second letter of the [Hebrew alphabet](https://en.wikipedia.org/wiki/Hebrew_alphabet)) provide a concise notation for powersets of the real numbers starting from $\beth_0 = \vert \mathbb{N} \vert$, then $\beth_1 = 2^{\beth_0} =\vert \mathbb{R} \vert$, and $\beth_2 = \vert\mathcal{P}(\mathbb{R})\vert = 2^{\beth_1}$, and in general $\beth_{n+1} = 2^{\beth_n}$ and $\beth_{\lambda} = \bigcup_{\alpha<\lambda} \beth_\alpha$ if $\lambda$ is a [limit ordinal](wikipedia://en/373137).[^o124]

## Alternative and additional axioms {#Alternative_and_additional_axioms}

Around the turn of the 20th century, set theory turned to an axiomatic approach to avoid rampant foundational issues related to its naive study (cf. ). The most common axiomatic set theory used today is [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC). In this system, the relevant axioms include: the [Axiom of Infinity](https://en.wikipedia.org/wiki/Axiom_of_Infinity), stating roughly "there is an infinite set", specifically, a set with cardinality of the natural numbers $\mathbb{N}$; the [Axiom of power set](wikipedia://en/52552), which says that, for any set $A$, the powerset $\mathcal P(A)$ also exists; and the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice), explained below. ZFC has been criticized both for being too strong, and too weak. Similarly, there are many "natural extensions" of ZFC studied by set theorists. Thus, there exist many alternative systems of axioms each of which has implications to the standard theory of cardinality discussed above.[^o127]

::: {#o129 .statement kind=statement/axiom cue=named-heading name="Without the axiom of choice"}

### Without the axiom of choice {#Without_the_axiom_of_choice}

*Image: Axiome\_du\_choix.svg.* For any infinite collection of "jars of marbles," the axiom of choice allows one to choose exactly one marble from each jar.

The [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice) (AC) is a fundamental principle in the foundations of mathematics which has seen much controversy in its history. Informally, it states that given any collection of non-empty sets, it is possible to construct a new set by choosing one element from each set, even if the collection is infinite. The controversy over AC had mostly to do with the nature of how it chose these elements. Whereas most axioms seem to describe what sets are or allow one to construct explicit sets, AC does not tell you *which* set you have constructed, just that such a choice function exists, leaving the constructed set implicit. It is hardly controversial to modern mathematicians. However, because of its unique historical controversy it is often given special treatment not given to other axioms that basic proofs which use it ought to call it out.[^o130]

The Axiom of Choice is very closely related to the nature of cardinality. AC imposes a strict structure on what cardinality can be and what it means to compare to sets. Assuming AC is false, cardinality has a much more intricate structure and resists the kind of linear order AC offers. For example, cardinal inequality does not treat injection and surjection equivalently. Specifically, there exists sets, such that there is a surjection from $A$ onto $B$, but no injection from $B$ into $A$. Thus injection is a strictly stronger notion, since, given an injection, it is always possible to find a surjection in the opposite direction. Similarly, although cardinal inequality maintains a partial order, there exist incomparable sets under cardinal inequality, that is, the [law of trichotomy](wikipedia://en/373956) fails to hold, and there are sets such that none of $A<B$, $A\sim B$, $A>B$ hold. Both of these (trichotomy and that surjection implies injection) are equivalent to AC.[^o131]

Because trichotomy does not hold and the aleph sequence has a natural well-order, there exist sets whose cardinality does not correspond to any aleph. As such, the cardinality function $A \mapsto \vert A\vert$ becomes somewhat more difficult to define. In fact, a cardinality function that maps each set to a unique "representative" of that cardinalityi.e. satisfying [Hume's principle](wikipedia://en/6174#Cardinal_numbers), and [idempotence](wikipedia://en/14972) ($\vert\vert S\vert\vert = \vert S \vert$ or $\vert S\vert \sim S$)is impossible without AC.[^o132] Set theories without AC address this by adopting the so-called *FregeRussellScott* definition, introduced by [Dana Scott](wikipedia://en/161875), reminiscent of the *FregeRussell* cardinal numbers. Under this definition, one considers the "Set of all sets" equinumerous with $A$, but applies [Scott's trick](wikipedia://en/22077085) to regularize these classes. Specifically, it reduces this class to only those sets of [minimal rank](https://en.wikipedia.org/wiki/Rank_%28set_theory%29); that is, those sets which appear earliest in the [von Neumann hierarchy](https://en.wikipedia.org/wiki/Von_Neumann_hierarchy). Since the von Neumann hierarchy is well-ordered, there is a least rank, and since these sets all share that rank, their collection is bounded in the hierarchy and thus constitutes a set rather than a proper class.[^o133]

Cardinal arithmetic is much more involved, losing many of its simplest identities. The identity $\vert A\vert + \vert B\vert = \operatorname{max}(\vert A\vert, \vert B\vert)$ requires a well-defined notion of "max" which requires all sets to be comparable, and therefore does not hold. Similarly, the proposition that $A \times A \sim B \times B \implies A \sim B$ (the function which squares cardinals is injective), and even the statement that the [arbitrary product](wikipedia://en/8887) of non-zero cardinal numbers always non-zerocalled the *Multiplicative axiom* by Bertrand Russellare both equivalent to AC.[^o134] Further, although the Generalized Continuum Hypothesis (GCH, that $\aleph_\alpha = \beth_\alpha$ for every $\alpha$) is independent of ZFC, it can be shown ZF+GCH is sufficient to derive AC, and therefore, if AC is false, it follows that GCH does not hold.[^o135]

### Proper classes {#Proper_classes}

Some set theories include [classes](wikipedia://en/20696), which are collections of sets, which allows theories to discuss any collection of sets without running into issues [self-reference](wikipedia://en/28545) (e.g. [the set of all sets that do not contain themselves](wikipedia://en/46095).). A class is called a proper class when, at least intuitively, it is "too large" to form a set. For example, the [universe of all sets](wikipedia://en/296838), the [class of all cardinal numbers](wikipedia://en/6174#Set_of_all_cardinal_numbers), and the [class of all ordinal numbers](wikipedia://en/51653) are proper classes. Such set theories include [Von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) (NBG), and [Morse–Kelley set theory](wikipedia://en/2693655) (MK). Cantor originally called the size of these "too large" sets "[absolute infinite](wikipedia://en/3231)", separating it from the transfinite. The former he characterized by its "inconsistency", causing paradoxes, and associated the concept with [God](https://en.wikipedia.org/wiki/God).[^o137]

Proper classes can, in a sense, be assigned cardinalities. The first to formally distinguish between sets and classes was [John von Neumann](wikipedia://en/15942), who formalized the notion of "too large to form sets". More accurately, he defined a class to be "too big" (a proper class) if and only if it was equinumerous with the whole universe of sets (cf. *[Axiom of limitation of size](wikipedia://en/5322450)*; used as an axiom in MK set theory, and derivable as a theorem in NBG). Thus, all proper classes have the same "size". The axiom has several implications, mostly relating to the [limitation of size](wikipedia://en/4190174) principles of early set theory. It implies the [axiom of specification](https://en.wikipedia.org/wiki/Axiom_of_specification), the [axiom of replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement), the [axiom of union](wikipedia://en/52553), and the [axiom of global choice](wikipedia://en/5322320).[^o138]

### Large cardinals {#Large_cardinals}

*Image: Large\_Cardinals.jpg.* Large cardinal hierarchy, ordered from bottom to top in terms of strength

[Large cardinal axioms](wikipedia://en/383644) assert the existence of cardinal numbers which, as the name suggests, are very large—so large that they cannot be proven to exist within ZFC. For example, an [inaccessible cardinal](wikipedia://en/248076) is, roughly, a cardinal that cannot be approached from below using basic set-theoretic operations such as unions, limits, and powersets (more formally, a [regular](wikipedia://en/374128), [limit cardinal](wikipedia://en/374002) greater than $\aleph_0$). Large cardinals are understood in terms of the [Von Neumann hierarchy](https://en.wikipedia.org/wiki/Von_Neumann_hierarchy), denoted $V_\alpha$ (for some ordinal $\alpha$), which can be understood as the sets that can be obtained from the empty set, followed by recursively applying the powerset $\alpha$ times. Specifically, $V_0 = \varnothing$, $V_{\alpha+1} = \mathcal P(V_\alpha)$ and $V_\lambda = \bigcup_{\alpha < \lambda} V_\alpha$ for a limit ordinal $\lambda$.[^o140]

There exist [many known properties defining large cardinals](wikipedia://en/3096183), which come seemingly in a linear hierarchy, in terms of consistency strength. As an analogy, in ZFC without the [Axiom of Infinity](https://en.wikipedia.org/wiki/Axiom_of_Infinity) can only prove the existence of finite sets. Therefore $V_\omega ( = \mathcal{P}(\varnothing) \cup \mathcal{P}(\mathcal{P}(\varnothing)) \cup \cdots )$, whose existence is provable in usual ZFC, can serve as a model of ZFCInfinity, and thus if ZFC is consistent, ZFCInfinity is consistent.[^o141] Analogously, ZFC$+$"There exists an inaccessible cardinal" implies the consistency of ZFC, since if $\kappa$ is inaccessible, $V_\kappa$ can serve as a model of ZFC (cf. *[Grothendieck universe](wikipedia://en/1072144)*). Stronger and stronger large cardinal axioms assert the existence of larger and larger cardinals, each of which proves the consistency of the weaker systems.[^o142]

Large cardinals are at the forefront of set-theoretic research for both practical and philosophical reasons. In a practical sense, it is often the case that unproven or unprovable conjectures can be settled by sufficiently strong large cardinal axioms. For example, the existence of a [measurable cardinal](wikipedia://en/248102) is inconsistent with [Gödel's constructibility axiom](wikipedia://en/696472). Similarly, the existence of a [Reinhardt cardinal](wikipedia://en/4687321) is inconsistent with the axiom of choice, which makes it a much more controversial large cardinal axiom. In a philosophical sense, according to a [platonic](wikipedia://en/2845761) view among set-theorists such as [W. Hugh Woodin](wikipedia://en/2275071), these axioms simply extend the system to include sets that are "supposed" to be considered. That is, there is some fundamental [universe of sets](wikipedia://en/296838), which these axioms grant further access to.[^o143] For this reason, large cardinal axioms are generally given preference compared to other possible axioms of set theory. This view is controversial among a competing philosophy, sometimes called [pluralism](https://en.wikipedia.org/wiki/Pluralism_%28philosophy%29),[^o144] which posits that set theory should be understood as a [multiverse](wikipedia://en/52912473) of set theories, but no "absolute" or "true" model.[^o145]

### Determinacy {#Determinacy}

*Image: Banach-Tarski\_Paradox.svg.* Illustration of the [Banach–Tarski paradox](wikipedia://en/19759220), which arises in ZFC, but is impossible in ZF+AD

The [Axiom of Determinacy](https://en.wikipedia.org/wiki/Axiom_of_Determinacy) (AD) asserts that [certain kinds](wikipedia://en/1002300#Types_of_games_that_are_determined) of [mathematical games](https://en.wikipedia.org/wiki/Mathematical_games) on the natural numbers are [determined](wikipedia://en/2596030); that is, one player will always have a guaranteed winning strategy.[^o147] The first serious study of the consequences of AD started during the 1960s in [descriptive set theory](wikipedia://en/396619)which, roughly, studies the definable sets of the real numbersafter it was noticed that it leads to very nice regulatory properties of the real numbers.[^o148] However, it was shown that [this axiom is inconsistent with AC](wikipedia://en/1002300#Incompatibility_with_the_axiom_of_choice) and thus was never taken as a fundamental axiom of set theory.[^o149]

AD is closely related to the cardinality of the real numbers, giving it a structure different from that under AC. Under AD, the real numbers cannot be well-ordered, meaning $\mathbb{R}$ does not correspond to any aleph. Despite this, AD imposes a rigid structure on the real numbers, known as the [perfect set property](wikipedia://en/2221109), implying that every set of real numbers is either countable, or has cardinality of exactly $2^{\aleph_0}$, equal to the whole real line. Similarly, it also implies that all sets of real numbers are [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable), eliminating the existence of sets whose size is non-zero, but cannot be assigned a length. Existence of such non-measurable sets allows the [Banach–Tarski paradox](wikipedia://en/19759220), demonstrating that one can cut one sphere into finitely many pieces, smoothly rearrange them, and end with two solid spheres, which becomes impossible under AD.[^o150]

On the other hand, due to the restrictions on what sets can exist, it implies that one can [partition](wikipedia://en/340240) the real numbers into *strictly* more groups than there are real numbers. Specifically, one can find an injection to show that $\vert\mathbb{R}\vert\leq\vert\mathbb{R}/\mathbb{Q}\vert$ (equivalence classes of reals, such that $x\sim y$ iff $x-y\in\mathbb{Q}$). However, if an injection $F:\mathbb{R}/\mathbb{Q} \to \mathbb{R}$ existed, then there is a linear order on $\mathbb{R}/\mathbb{Q}$ (given by $a \leq b$ if $F(a) \leq F(b)$). This allows one to construct a set which cannot be assigned a measure, contradicting AD. Therefore no such injection could exist, and thus $\vert\mathbb{R}\vert < \vert\mathbb{R}/\mathbb{Q}\vert$.[^o151]

However, its relationship with large cardinals and the continuum hypothesis is still of heavy interest among set theorists such as [Donald A. Martin](wikipedia://en/2270985), [John R. Steel](wikipedia://en/2290967), and [W. Hugh Woodin](wikipedia://en/2275071), at least in part because AD is equiconsistent with the large cardinal axiom that there exists infinitely many [Woodin cardinals](wikipedia://en/248105).[^o152]

## Skolem's paradox {#Skolem's_paradox}

*Image: Lowenheim-skolem.svg.* Illustration of the [Löwenheim–Skolem theorem](wikipedia://en/341482), where $\mathcal{M}$ and $\mathcal{N}$ are models of set theory, and $\kappa$ is an arbitrary infinite cardinal number

In [model theory](wikipedia://en/19858), a [model](https://en.wikipedia.org/wiki/Model_%28mathematical_logic%29) corresponds to a specific interpretation of a [formal language](wikipedia://en/10939) or [theory](wikipedia://en/3512103). It consists of a [domain](wikipedia://en/229180) (a set of objects) and an [interpretation](wikipedia://en/14511671) of the symbols in the language, such that the axioms of the theory are satisfied within this structure. In [first-order logic](wikipedia://en/10983), the [Löwenheim–Skolem theorem](wikipedia://en/341482) states that if a countable theory has an infinite model, then it also has models of every other infinite cardinality. Applied to set theory, it asserts that [Zermelo–Fraenkel set theory](wikipedia://en/152214), which proves the existence of uncountable sets such as $\mathcal P(\mathbb{N})$, nevertheless has a countable model. Thus, [Skolem's paradox](wikipedia://en/1348798) was posed as follows: how can it be that there exists a domain of set theory which only contains countably many objects, but is capable of [satisfying](wikipedia://en/23401166) the statement "there exists a set with uncountably many elements"?[^o155]

Skolem's paradox does not only apply to ZFC, but *any* first-order set theory, if it is countable and [consistent](https://en.wikipedia.org/wiki/Consistent), has a model which is countable. A mathematical explanation of the paradox, showing that it is not a true contradiction in mathematics, was first given in 1922 by [Thoralf Skolem](wikipedia://en/453765), who asserted it as a reason against founding mathematics on first order logic. He explained that the countability or uncountability of a set is not [absolute](wikipedia://en/12374236), but relative to the model in which the cardinality is measured. This is because, for example, if the set $X$ is countable in a model of set theory then there is a bijection $f : \mathbb{N} \mapsto X$. But a submodel containing $X$ which excludes all such functions would thus contain no bijection between $X$ and $\mathbb{N}$, and therefore $X$ would be uncountable. In [second-order](wikipedia://en/341428) and [higher-order logics](https://en.wikipedia.org/wiki/Higher-order_logics), the Löwenheim–Skolem theorem does not hold. This is due to the fact that second-order logic quantifies over all subsets of the domain. Skolem's work was harshly received by [Ernst Zermelo](wikipedia://en/178655), who argued against the limitations of first-order logic and Skolem's notion of "relativity", but the result quickly came to be accepted by the mathematical community.[^o156]

## History {#History}

### Ancient history {#Ancient_history}

*Image: AristotlesWheelLabeledDiagram.svg.* Diagram of Aristotle's wheel as described in *Mechanica*

From the 6th century BCE, the writings of [Greek philosophers](https://en.wikipedia.org/wiki/Greek_philosophers), such as [Anaximander](https://en.wikipedia.org/wiki/Anaximander), discussed infinite sets or objects, however, those objects were generally viewed as paradoxical and imperfect (cf. *[Zeno's paradoxes](wikipedia://en/34535)*). [Aristotle](wikipedia://en/308) distinguished between the notions of [actual and potential infinity](wikipedia://en/38106), arguing that Greek mathematicians understood the difference, and that they "do not need the \[actual\] infinite and do not use it." The Greek notion of number (*αριθμός*, *arithmos*) was used exclusively for a definite number of definite objects (i.e. finite numbers).[^o159] This was codified in [Euclid's *Elements*](wikipedia://en/244107), where the [fifth common notion](wikipedia://en/9417#common_notions) stated "The whole is greater than the part", called the *Euclidean principle*. This principle was the dominating philosophy in mathematics until the 19th century.[^o160]

Around the 4th century BCE, [Jaina mathematics](https://en.wikipedia.org/wiki/Jaina_mathematics) were the first to discuss different sizes of infinity. They defined three major classes of number: enumerable (finite numbers), unenumerable (*asamkhyata*, roughly, countably infinite), and infinite (*ananta*, roughly, [the continuum](wikipedia://en/6174#Cardinality_of_the_continuum)). Then they had five classes of infinite numbers: infinite in one direction, infinite in both directions, infinite in area, infinite everywhere, and infinite perpetually.[^o161]

One of the earliest explicit uses of a one-to-one correspondence is recorded in [Aristotle's *Mechanics*](https://en.wikipedia.org/wiki/Mechanics_%28Aristotle%29) (c. 350 BCE), known as [Aristotle's wheel paradox](wikipedia://en/2439294). The paradox can be briefly described as follows: A wheel is depicted as two [concentric circles](https://en.wikipedia.org/wiki/Concentric_circles). The larger, outer circle is tangent to a horizontal line (e.g. a road that it rolls on), while the smaller, inner circle is rigidly affixed to the larger. Assuming the larger circle rolls along the line without slipping (or skidding) for one full revolution, the distances moved by both circles are the same: the [circumference](wikipedia://en/5916) of the larger circle. Further, the lines traced by the bottom-most point of each is the same length.[^o162] Since the smaller wheel does not skip any points, and no point on the smaller wheel is used more than once, there is a one-to-one correspondence between the two circles.[^o163]

### Pre-Cantorian set theory {#Pre-Cantorian_set_theory}

[Galileo Galilei](wikipedia://en/29688374) presented what was later coined [Galileo's paradox](wikipedia://en/339195) in his book *[Two New Sciences](wikipedia://en/268475)* (1638),[^o165] which was a seeming paradox in infinite sequences of numbers. It went as follows: for each [perfect square](wikipedia://en/213919) $(n^2)$ 1, 4, 9, 16, and so on, there is a unique [square root](wikipedia://en/29208) $\textstyle(\sqrt{n^2} = n)$ 1, 2, 3, 4, and so on. Therefore, there are as many perfect squares as there are square roots. However, every number is a square root, since it can be [squared](wikipedia://en/659942), but not every number is a perfect square. Moreover, the proportion of perfect squares as one passes larger values diminishes, and is eventually smaller than any given fraction. Galileo denied that this was fundamentally contradictory, however he concluded that this meant we could not compare the sizes of infinite sets, missing the opportunity to discover cardinality.[^o166]

In *[A Treatise of Human Nature](https://en.wikipedia.org/wiki/A_Treatise_of_Human_Nature)* (1739), [David Hume](https://en.wikipedia.org/wiki/David_Hume) said "When two numbers are so combined, as that the one has always a unit answering to every unit of the other, we pronounce them equal"*,[^o167]* now called *[Hume's principle](wikipedia://en/314743)*, which was used extensively by [Gottlob Frege](wikipedia://en/48416) later during the rise of set theory.[^o168]

[Bernard Bolzano](wikipedia://en/302185)'s *[Paradoxes of the Infinite](wikipedia://en/32000609)* (*Paradoxien des Unendlichen*, 1851) is often considered the first systematic attempt to introduce the concept of sets into [mathematical analysis](wikipedia://en/48396). In this work, Bolzano defended the notion of [actual infinity](https://en.wikipedia.org/wiki/Actual_infinity), presented an early formulation of what would later be recognized as one-to-one correspondence between infinite sets. He discussed examples such as the pairing between the [intervals](wikipedia://en/49172) $[0,5]$ and $[0,12]$ by the relation $5y = 12x$, and revisited Galileo's paradox. However, he too resisted saying that these sets were, in that sense, the same size. While *Paradoxes of the Infinite* anticipated several ideas central to later set theory, the work had little influence on contemporary mathematics, in part due to its [posthumous publication](https://en.wikipedia.org/wiki/Posthumous_publication) and limited circulation.[^o169]

### Early set theory {#Early_set_theory}

#### Georg Cantor {#Georg_Cantor}

*Image: Georg\_Cantor3.jpg.* [Georg Cantor](wikipedia://en/12216), 4c. 1870

The concept of cardinality emerged nearly fully formed in the work of Georg Cantor during the 1870s and 1880s, in the context of [mathematical analysis](wikipedia://en/48396). In a series of papers beginning with *[On a Property of the Collection of All Real Algebraic Numbers](wikipedia://en/22697171)* (1874),[^o172] Cantor introduced the idea of comparing the sizes of infinite sets, through the notion of one-to-one correspondence.[^o173] He showed that the set of [real numbers](https://en.wikipedia.org/wiki/Real_numbers) was, in this sense, strictly larger than the set of natural numbers [using a nested intervals argument](wikipedia://en/22697171#Second_theorem).[^o174] This result was later refined into the more widely known [diagonal argument](wikipedia://en/51426) in 1891, published in *Über eine elementare Frage der Mannigfaltigkeitslehre,*[^o175] where he also proved the more general result (now called [Cantor's Theorem](https://en.wikipedia.org/wiki/Cantor's_Theorem)) that the [power set](wikipedia://en/23799) of any set is strictly larger than the set itself.[^o176]

Cantor introduced the notion [cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_numbers) together with [ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_numbers), which he viewed as abstractions of sets. For a given set $M$, he wrote $\textstyle\overline{M}$ to mean the abstraction of that set from its elements, while maintaining their order, and cardinal numbers were a double abstraction, written $\textstyle M$.[^o177] Specifically, his definition was "the general concept which, with the aid of our intelligence, results from a set when we abstract from the nature of its various elements and from the order of their being given."[^o178] This definition was considered to be imprecise, unclear, and purely psychological, and it would be some time before the concept was put on more rigorous footing.[^o179] He also introduced the Aleph sequence for infinite cardinal numbers. These notations appeared in correspondence and were formalized in his later writings, particularly the series *Beiträge zur Begründung der transfiniten Mengenlehre* (18951897).[^o180] In these works, Cantor developed an [arithmetic of cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_arithmetic), defining addition, multiplication, and exponentiation of cardinal numbers. This led to the formulation of the [Continuum Hypothesis](https://en.wikipedia.org/wiki/Continuum_Hypothesis): whether $2^{\aleph_0} = \aleph_1$. Cantor was unable to resolve CH and left it as an [open problem](wikipedia://en/1333335).[^o181]

#### Other contributors {#Other_contributors}

Parallel to Cantor's development, [Richard Dedekind](wikipedia://en/23475106) independently formulated many advanced theorems of set theory, and helped establish set-theoretic foundations of algebra and arithmetic.[^o183] Dedekind's *The Nature and Meaning of Numbers* (1888)[^o184] emphasized structural properties over extensional definitions, and supported the bijective formulation of size and number. Dedekind was in correspondence with Cantor during the development of set theory; he supplied Cantor with a proof of the countability of the [algebraic numbers](https://en.wikipedia.org/wiki/Algebraic_numbers), and gave feedback and modifications on Cantor's proofs before publishing.[^o185]

After Cantor's 1883 proof that all finite-dimensional spaces $(\mathbb{R}^n)$ have the same cardinality,[^o186] in 1890, [Giuseppe Peano](wikipedia://en/13043) introduced the [Peano curve](wikipedia://en/358330), which was a more visual proof that the [unit interval](wikipedia://en/49324) $[0,1]$ has the same cardinality as the [unit square](wikipedia://en/285301) on $\mathbb{R}^2$.[^o187] This created a new area of mathematical analysis studying what are now called [space-filling curves](https://en.wikipedia.org/wiki/Space-filling_curves).[^o188] In 1894, attempting to formalize Cantor's "cardinal number", Peano introduced "definition by abstraction": if one can define an equivalence relation, then one may define "that property" which an equivalence class describes. However, this was received harshly by [Russell](wikipedia://en/4163) for not considering that this property may not be unique.[^o189]

German logician [Gottlob Frege](wikipedia://en/48416) attempted to ground the concepts of number and arithmetic in logic using Cantor's theory of cardinality and [Hume's principle](wikipedia://en/314743) in *[Die Grundlagen der Arithmetik](https://en.wikipedia.org/wiki/Die_Grundlagen_der_Arithmetik)* (1884) and the subsequent *Grundgesetze der Arithmetik* (1893, 1903).[^o168] Frege defined cardinal numbers as [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes) of sets under equinumerosity. However, Frege's approach to set theory was later shown to be flawed. His approach was eventually reformalized by [Bertrand Russell](https://en.wikipedia.org/wiki/Bertrand_Russell_Peace_Foundation) and [Alfred Whitehead](wikipedia://en/43395) in *[Principia Mathematica](wikipedia://en/24133)* (19101913, vol. II)[^n2] using a [theory of types](wikipedia://en/40282#History).[^o191] This definition of cardinal numbers is now referred to as the *FregeRussell* definition.[^o61] This definition was eventually superseded by the convention established by [John von Neumann](wikipedia://en/15942) in 1928 which uses representatives to define cardinal numbers.[^o192]

At the [Paris](wikipedia://en/22989) conference of the [International Congress of Mathematicians](wikipedia://en/627842) in 1900, [David Hilbert](wikipedia://en/8302), one of the most influential mathematicians of the time, gave a speech wherein he presented ten unsolved problems (of a total of 23, later published, now called *[Hilbert's problems](wikipedia://en/154584)*). Of these, he placed "Cantor's problem" (now called the Continuum Hypothesis) as the first on the list. This list of problems would prove to be very influential in 20th century mathematics, and attracted a lot of attention from other mathematicians toward Cantor's theory of cardinality.[^o193]

### Axiomatic set theory {#Axiomatic_set_theory}

In 1908, [Ernst Zermelo](wikipedia://en/178655) proposed the first [axiomatization](https://en.wikipedia.org/wiki/Axiomatization) of set theory, now called [Zermelo set theory](wikipedia://en/322623), primarily to support his earlier (1904) proof of the [Well-ordering theorem](wikipedia://en/33458), which showed that all cardinal numbers could be represented as Alephs, though the proof required a controversial principle now known as the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice) (AC).[^o195] Zermelo's system was extended and formalized in [first-order logic](wikipedia://en/10983) by [Abraham Fraenkel](wikipedia://en/528451) and [Thoralf Skolem](wikipedia://en/453765) in the 1920s to create the standard foundation of set theory, called [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC, "C" for the Axiom of Choice). ZFC provided a rigorous foundation through which infinite cardinals could be systematically studied while avoiding the [paradoxes of naive set theory](wikipedia://en/10409979).[^o127]

Ignoring possible foundational issues, during the early 1900s, [Felix Hausdorff](wikipedia://en/10989) began studying "exorbitant numbers": roughly, very large cardinal numbers, or what are now called [inaccessible cardinals](https://en.wikipedia.org/wiki/Inaccessible_cardinals). This work was continued and popularized by several other influential set theorists such as [Paul Mahlo](wikipedia://en/25167931)who introduced [Mahlo cardinals](wikipedia://en/248081)as well as [Wacław Sierpiński](wikipedia://en/34122), and [Alfred Tarski](wikipedia://en/59920). Their work would eventually be known collectively as the study of [large cardinals](wikipedia://en/6174#Large_cardinals).[^o196]

In 1940, [Kurt Gödel](wikipedia://en/16736) showed that the Continuum Hypothesis (CH) cannot be *disproved* from the axioms of ZFC by showing that both CH and AC hold in his [constructible universe](wikipedia://en/343335): an [inner model](wikipedia://en/1118686) of ZFC. The existence of a model of ZFC in which additional axioms hold shows that the additional axioms are (relatively) [consistent](https://en.wikipedia.org/wiki/Consistent) with ZFC.[^o197] In 1963, [Paul Cohen](wikipedia://en/22994) showed that CH cannot be *proven* from the ZFC axioms, which showed that CH was [independent](wikipedia://en/1141208) from ZFC. To prove his result, Cohen developed the method of [forcing](wikipedia://en/152205), which has become a standard tool in set theory. Cohen was awarded the [Fields Medal](wikipedia://en/10859) in 1966 for his proof.[^o198]
