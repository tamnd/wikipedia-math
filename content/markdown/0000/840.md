# Axiom of choice

*Image: Axiome du choix.svg.* Illustration of the axiom of choice, with each set *S*<sub>*i*</sub> represented as a jar and its elements represented as marbles. Each element *x*<sub>*i*</sub> is represented as a marble on the right. Colors are used to suggest a functional association of marbles after adopting the choice axiom. The existence of such a choice function is in general independent of ZF for collections of infinite cardinality, even if all *S*<sub>*i*</sub> are finite.

*Image: Axiom of choice.svg.* (S<sub>*i*</sub>) is an infinite [indexed family](wikipedia://en/23624339) of sets indexed over the [real numbers](wikipedia://en/20646438) **R**; that is, there is a set S<sub>*i*</sub> for each real number *i*, with a small sample shown above. Each set contains at least one, and possibly infinitely many, elements. The axiom of choice allows us to select a single element from each set, forming a corresponding family of elements (*x*<sub>*i*</sub>) also indexed over the real numbers, with *x*<sub>*i*</sub> drawn from S<sub>*i*</sub>. In general, the collections may be indexed over any set *I*, (called index set whose elements are used as indices for elements in a set) not just **R**.

::: {#o1 .subject cue=lead name="Axiom of choice"}

In [mathematics](wikipedia://en/18831), the **axiom of choice**, abbreviated **AC** or **AoC**, is an [axiom](wikipedia://en/928) of [set theory](wikipedia://en/27553). Informally put, the axiom of choice says that given any [collection](wikipedia://en/723043) of non-empty sets, one can identify another set containing one element chosen from each set, even if the collection is [infinite](wikipedia://en/142679). Formally, the axiom establishes [existence](wikipedia://en/91420) rather than a [construction](wikipedia://en/21059); it states that for every set $I$ and every $I$-[indexed family](wikipedia://en/23624339) $(S_i)_{i \in I}$ of [nonempty](https://en.wikipedia.org/wiki/Nonempty) sets, there exists an $I$-indexed set $(x_i)_{i \in I}$ of elements of $\cup_{i\in I}S_i$ such that $x_i \in S_i$ for every $i \in I$. The axiom of choice was formulated in 1904 by [Ernst Zermelo](wikipedia://en/178655) in order to formalize his proof of the [well-ordering theorem](wikipedia://en/33458).[^n1]

:::

In many cases, a set created by choosing elements can be made without invoking the axiom of choice, particularly if the number of sets from which to choose the elements is finite (in which induction can be applied), or if a *canonical* rule on how to choose the elements is available – some distinguishing property that happens to hold for exactly one element in each set. An illustrative example is sets picked from the natural numbers. From such sets, one may always select the smallest number, e.g. given the sets {4, 5, 6}, {10, 12}, {1, 400, 617, 8000}, the set containing each smallest element is {4, 10, 1}. In this case, "select the smallest number" is a [choice function](wikipedia://en/1432664). Even if infinitely many sets are collected from the natural numbers, it will always be possible to form a choice function from choosing the smallest element from each set to produce a set; the axiom of choice is not needed here. On the other hand, for the collection of all non-empty subsets of the real numbers, there is *no* known *canonical* rule by which one can choose one element from each of these subsets. In that case, the axiom of choice must be invoked to construct the desired choice function.

[Bertrand Russell](wikipedia://en/4163) coined an analogy: for any (even infinite) collection of unordered pairs of shoes, one can pick out the left shoe from each pair to obtain an appropriate collection (i.e. set) of shoes; this makes it possible to define a choice function without using the axiom of choice. However, for an infinite collection of unordered pairs of *socks* (assumed to have no distinguishing features such as being a left sock rather than a right sock), there is no *natural* (i.e., canonical) way of choosing one sock from each pair, so one must appeal to the axiom of choice to construct the desired choice function.[^n2]

Although originally controversial, the axiom of choice is now used without reservation by most mathematicians,[^o4] and is included in the standard form of [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), [Zermelo–Fraenkel set theory](wikipedia://en/152214) with the axiom of choice (ZFC). One motivation for this is that a number of generally accepted mathematical results, such as [Tychonoff's theorem](wikipedia://en/82739), require the axiom of choice for their proofs. Contemporary set theorists also study axioms that are not compatible with the axiom of choice, such as the [axiom of determinacy](wikipedia://en/1002300). While some varieties of [constructive mathematics](https://en.wikipedia.org/wiki/Constructivism_%28mathematics%29) avoid the axiom of choice, others embrace it.

::: {#o6 .statement cue=heading name="Statement"}

## Statement {#Statement}

A [choice function](wikipedia://en/1432664) (also called selector or selection) is a function $f$, defined on a collection $X$ of nonempty sets, such that for every set $A$ in $X$, $f(A)$ is an element of $A$. With this concept, the axiom can be stated:

::: {#o7 .statement kind=statement/axiom cue=math-theorem name="Axiom"}

**Axiom.**

For any set $X$ of nonempty sets, there exists a choice function $f$ that is defined on $X$ and maps each set of $X$ to an element of that set.

:::

Formally, this may be expressed as follows:

$$\forall X \left[ \varnothing \in X \lor \exists f \left[ \mathrm{dom} \ f = X \land \forall A \in X \left[ f\left(A\right) \in A \right] \right] \right].$$

Each choice function on a family $X$ of nonempty sets is an element of the [Cartesian product](wikipedia://en/24104095#Infinite_Cartesian_products) of the sets in $X$, and vice versa. Therefore, an equivalent form of the axiom of choice is: The Cartesian product of any collection of nonempty sets is nonempty.

This form implies a more general form where the Cartesian product is of a general [indexed family](wikipedia://en/23624339) of sets (which may contain duplicates), since one can always select the same element from duplicate factors.

### Nomenclature {#Nomenclature}

In this article and other discussions of the axiom of choice the following abbreviations are common:

- AC – the axiom of choice. More rarely, AoC is used.[^n3]
- ZF – [Zermelo–Fraenkel set theory](wikipedia://en/152214) omitting the axiom of choice.
- ZFC – Zermelo–Fraenkel set theory, extended to include the axiom of choice.

::: {#o11 .statement kind=statement/generalization cue=heading name="Variants"}

### Variants {#Variants}

There are many other equivalent statements of the axiom of choice. These are equivalent in the sense that, in the presence of other basic axioms of set theory, they imply the axiom of choice and are implied by it.

One variation avoids the use of choice functions by, in effect, replacing each choice function with its range:

Given any set $X$, if the empty set is not an element of $X$ and the elements of $X$ are [pairwise disjoint](https://en.wikipedia.org/wiki/Pairwise_disjoint), then there exists a set $C$ such that its intersection with any of the elements of $X$ contains exactly one element.[^o12]

This can be formalized in first-order logic as:

$$\begin{aligned} \forall x (& \\ &\exists e (e \in x \land \lnot\exists y (y \in e)) \lor \\ &\exists a \, \exists b \, \exists c \, (a \in x \land b \in x \land c \in a \land c \in b \land \lnot(a = b)) \lor \\ &\exists c \, \forall e \, (e \in x \implies \exists a \, (a \in e \land a \in c \land \forall b \, ((b \in e \land b \in c) \implies a = b)))) \end{aligned}$$

Note that $P \lor Q \lor R$ is logically equivalent to $(\lnot P \land \lnot Q) \implies R$. In English, this first-order sentence reads:

Given any set $X$, $X$ contains the empty set as an element or the elements of $X$ are not pairwise disjoint or there exists a set $C$ such that its intersection with any of the elements of $X$ contains exactly one element.

This guarantees for any [partition of a set](wikipedia://en/340240) $X$ the existence of a subset $C$ of $X$ containing exactly one element from each part of the partition.

Another equivalent axiom only considers collections $X$ that are essentially powersets of other sets: For any set $A$, the [power set](wikipedia://en/23799) of $A$ (with the empty set removed) has a choice function. Authors who use this formulation often speak of the *choice function on $A$*, but this is a slightly different notion of choice function. Its domain is the power set of $A$ (with the empty set removed), and so makes sense for any set $A$, whereas with the definition used elsewhere in this article, the domain of a choice function on a *collection of sets* is that collection, and so only makes sense for sets of sets. With this alternate notion of choice function, the axiom of choice can be compactly stated as

Every set has a choice function.[^n4]

which is equivalent to

For any set $A$ there is a function $f:\mathcal P(A)\setminus\{ \emptyset \} \to A$ such that for any non-empty subset $B$ of $A$, $f(B)$ lies in $B$.

The negation of the axiom can thus be expressed as:

There is a set $A$ such that for all functions $f$ (on the set of non-empty subsets of $A$), there is a subset $B$ such that $f(B)$ does not lie in $B$.

:::

:::

## Usage {#Usage}

Until the late 19th century, the axiom of choice was often used implicitly, although it had not yet been formally stated. For example, after having established that the set *X* contains only non-empty sets, a mathematician might have said "let *F*(*s*) be one of the members of *s* for all *s* in *X*" to define a function *F*. In general, it is impossible to prove that *F* exists without the axiom of choice, but this seems to have gone unnoticed until Zermelo.

## Examples {#Examples}

::: {#o18 .statement kind=statement/axiom cue=named-heading name="Cases where the axiom of choice is not needed"}

### Cases where the axiom of choice is not needed {#Cases_where_the_axiom_of_choice_is_not_needed}

The existence of a choice function for a [finite collection](wikipedia://en/11742) of nonempty sets can be proved by the [principle of finite induction](wikipedia://en/18881), without appealing to the axiom of choice.[^n5] The proof uses the fact that, given a *single* nonempty set $A$, [first-order logic](wikipedia://en/10983) allows choosing some concrete $a \in A$. However, since a proof in first-order logic must be finite, one cannot make an infinite number of choices with first-order logic alone.

Another case where the axiom of choice is not needed is when there exists an explicit rule that gives a *canonical* choice function. For example, if each member of the collection $X$ is a nonempty subset of the natural numbers, then one such explicit rule is to choose the *smallest element* of each $A \in X$. The canonical choice function that maps each $A \in X$ to its smallest element can again be constructed in ZF without the axiom of choice.

In general, if the union of all sets in $X$ can be [well-ordered](wikipedia://en/33456), then a choice function for $X$ can be constructed without using the axiom of choice. Note that it does not suffice that each $A \in X$ can be well-ordered, since the axiom of choice may be needed to choose a *canonical well-ordering* for each $A$ anyway.

:::

### Real numbers {#Real_numbers}

As an example where the axiom of choice is required, let $X$ be the set of all non-empty subsets of the [real numbers](wikipedia://en/20646438). Choosing the least element from each set no longer works, because some subsets of the real numbers do not have least elements. For example, the [open interval](https://en.wikipedia.org/wiki/Open_interval) $(0,1)$ does not have a least element: if $x$ is in $(0,1)$, then so is $x/2$, and $x/2$ is always strictly smaller than $x$. This strategy fails here because the natural order of real numbers is not a [well-order](wikipedia://en/33456).

If there exists a different ordering of the real numbers which is a well-ordering, then applying the least-element strategy with respect to that ordering would give a choice function for $X$. Conversely, if there exists a choice function for $X$, then the proof of the [well-ordering theorem](wikipedia://en/33458) would show that a well-ordering of the real numbers does exist.

### Constructing a non-measurable set {#Constructing_a_non-measurable_set}

Let $S$ be the unit circle, and $G$ be the group consisting of all rational rotations (i.e., rotations by angles which are rational multiples of $\pi$). Since $G$ is countable while $S$ is uncountable, $S$ must break up into uncountably many [orbits](https://en.wikipedia.org/wiki/Orbit_%28group_theory%29) under the action of $G$.

Using the axiom of choice, we could pick a single point from each orbit, obtaining an uncountable subset $X$ of $S$ with the property that all of its translates by $G$ are disjoint from $X$. The set of those translates partitions the circle into a countable collection of pairwise disjoint sets, which are all pairwise congruent. The set $X$ will be non-measurable for any rotation-invariant countably additive measure on $S$: if $X$ has zero measure, countable additivity would imply that the whole circle has zero measure. If $X$ has positive measure, countable additivity would show that the circle has infinite measure.

Applying a similar construction to the three-dimensional ball can result in a set that is non-measurable even for any rotation-invariant *finitely* additive measure, as shown by the [Banach–Tarski paradox](wikipedia://en/19759220).

:::

## Criticism and acceptance {#Criticism_and_acceptance}

A proof requiring the axiom of choice may establish the existence of an object without *canonically* [defining](wikipedia://en/5569486) the object in the language of set theory. For example, while the axiom of choice implies that there is a [well-ordering](https://en.wikipedia.org/wiki/Well-ordering) of the real numbers, there are models of set theory with the axiom of choice in which no individual well-ordering of the reals is definable. Similarly, although a subset of the real numbers that is not [Lebesgue measurable](wikipedia://en/18198) can be proved to exist using the axiom of choice, it is [consistent](https://en.wikipedia.org/wiki/Consistent) that no such set is definable.[^n6]

The axiom of choice asserts the existence of these intangibles (objects that are proved to exist, but which cannot be constructed in any *canonical* way), which may conflict with some philosophical principles.[^n7] Because there is no canonical well-ordering of all sets, a construction that relies on a well-ordering may not produce a canonical result, even if a canonical result is desired (as is often the case in [category theory](wikipedia://en/5869)). This has been used as an argument against the use of the axiom of choice.

Another argument against the axiom of choice is that it implies the existence of objects that may seem counterintuitive.[^o25] One example is the [Banach–Tarski paradox](wikipedia://en/19759220), which says that it is possible to decompose the 3-dimensional solid unit ball into finitely many pieces and, using only rotations and translations, reassemble the pieces into two solid balls each with the same volume as the original. The pieces in this decomposition, constructed using the axiom of choice, are [non-measurable sets](wikipedia://en/620134).

Despite these seemingly paradoxical results, most mathematicians accept the axiom of choice as a valid principle for proving new results in mathematics. But the debate is interesting enough that it is considered notable when a theorem in ZFC (ZF plus AC) is [logically equivalent](wikipedia://en/169324) (with just the ZF axioms) to the axiom of choice, and mathematicians look for results that require the axiom of choice to be false, though this type of deduction is less common than the type that requires the axiom of choice to be true.

Theorems of ZF hold true in any [model](wikipedia://en/19858) of that theory, regardless of the truth or falsity of the axiom of choice in that particular model. The implications of choice below, including weaker versions of the axiom itself, are listed because they are not theorems of ZF. The Banach–Tarski paradox, for example, is neither provable nor disprovable from ZF alone: it is impossible to construct the required decomposition of the unit ball in ZF, but also impossible to prove there is no such decomposition. Such statements can be rephrased as conditional statements—for example, "If AC holds, then the decomposition in the Banach–Tarski paradox exists." Such conditional statements are provable in ZF when the original statements are provable from ZF and the axiom of choice.

## In constructive mathematics {#In_constructive_mathematics}

As discussed above, in the classical theory of ZFC, the axiom of choice enables [nonconstructive proofs](https://en.wikipedia.org/wiki/Nonconstructive_proof) in which the existence of a type of object is proved without an explicit canonical construction of an instance of this type. In fact, in set theory and [topos theory](https://en.wikipedia.org/wiki/Topos_theory), [Diaconescu's theorem](wikipedia://en/18288107) shows that the axiom of choice implies the [law of excluded middle](wikipedia://en/17637). The principle is thus not available in [constructive set theory](wikipedia://en/5042360), where non-classical logic is employed.

The situation is different when the principle is formulated in [Martin-Löf type theory](https://en.wikipedia.org/wiki/Martin-Löf_type_theory). There and higher-order [Heyting arithmetic](wikipedia://en/2545815), the appropriate statement of the axiom of choice is (depending on approach) included as an axiom or provable as a theorem.[^o27] A cause for this difference is that the axiom of choice in type theory does not have the [extensionality](wikipedia://en/294056) properties that the axiom of choice in constructive set theory does.[^o28] The type theoretical context is discussed further below.

Different choice principles have been thoroughly studied in the constructive contexts and the principles' status varies between different school and varieties of the constructive mathematics. Some results in constructive set theory use the [axiom of countable choice](wikipedia://en/421086) or the [axiom of dependent choice](wikipedia://en/441950), which do not imply the law of the excluded middle. [Errett Bishop](wikipedia://en/321995), who is notable for developing a framework for [constructive analysis](wikipedia://en/239851), argued that an axiom of choice was constructively acceptable, saying

A choice function exists in constructive mathematics, because a choice is implied by the very meaning of existence.[^o29]

Although the axiom of countable choice in particular is commonly used in constructive mathematics, its use has also been questioned.[^o30]

## Independence {#Independence}

It has been known since as early as 1922 that the axiom of choice may fail in a variant of ZF with [urelements](wikipedia://en/643648), through the technique of [permutation models](wikipedia://en/43782287) introduced by [Abraham Fraenkel](wikipedia://en/528451)[^n8] and developed further by [Andrzej Mostowski](wikipedia://en/1029314).[^n9] The basic technique can be illustrated as follows: Let *x*<sub>*n*</sub> and *y*<sub>*n*</sub> be distinct urelements for *n*=1, 2, 3..., and build a model where each set is symmetric under the interchange *x*<sub>*n*</sub> ↔ *y*<sub>*n*</sub> for all but a finite number of *n*. Then the set *X* = {{*x*<sub>1</sub>, *y*<sub>1</sub>}, {*x*<sub>2</sub>, *y*<sub>2</sub>}, {*x*<sub>3</sub>, *y*<sub>3</sub>}, ...} can be in the model but sets such as {*x*<sub>1</sub>, *x*<sub>2</sub>, *x*<sub>3</sub>, ...} cannot, and thus *X* cannot have a choice function.

In 1938,[^o35] [Kurt Gödel](wikipedia://en/16736) showed that the *negation* of the axiom of choice is not a theorem of ZF by constructing an [inner model](wikipedia://en/1118686) (the [constructible universe](wikipedia://en/343335)) that satisfies ZFC, thus showing that ZFC is consistent if ZF itself is consistent. In 1963, [Paul Cohen](https://en.wikipedia.org/wiki/Paul_Cohen_%28mathematician%29) employed the technique of [forcing](wikipedia://en/152205), developed for this purpose, to show that, assuming ZF is consistent, the axiom of choice itself is not a theorem of ZF. He did this by constructing a much more complex model that satisfies ZF¬C (ZF with the negation of AC added as axiom) and thus showing that ZF¬C is consistent. Cohen's model is a [symmetric model](https://en.wikipedia.org/wiki/Symmetric_model), which is similar to permutation models, but uses "generic" subsets of the natural numbers (justified by forcing) in place of urelements.[^o36]

Together these results establish that the axiom of choice is [logically independent](wikipedia://en/1141208) of ZF. The assumption that ZF is consistent is harmless because adding another axiom to an already inconsistent system cannot make the situation worse. Because of independence, the decision whether to use the axiom of choice (or its negation) in a proof cannot be made by appeal to other axioms of set theory. It must be made on other grounds.

One argument in favor of using the axiom of choice is that it is convenient because it allows one to prove some simplifying propositions that otherwise could not be proved. Many theorems provable using choice are of an elegant general character: the cardinalities of any two sets are comparable, every nontrivial unital [ring](wikipedia://en/48404) has a [maximal ideal](wikipedia://en/48164), every [vector space](wikipedia://en/32370) has a [basis](wikipedia://en/18420), every [connected graph](https://en.wikipedia.org/wiki/Connected_graph) has a [spanning tree](wikipedia://en/455770), and every [product](wikipedia://en/24910) of [compact spaces](wikipedia://en/6042) is compact, among many others. Frequently, the axiom of choice allows generalizing a theorem to "larger" objects. For example, it is provable without the axiom of choice that every vector space of finite dimension has a basis, but the generalization to all vector spaces requires the axiom of choice. Likewise, a finite product of compact spaces can be proven to be compact without the axiom of choice, but the generalization to infinite products ([Tychonoff's theorem](wikipedia://en/82739)) requires the axiom of choice.

The proof of the independence result also shows that a wide class of mathematical statements, including all statements that can be phrased in the language of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), are provable in ZF if and only if they are provable in ZFC.[^o37] Statements in this class include the statement that [P = NP](https://en.wikipedia.org/wiki/P_=_NP), the [Riemann hypothesis](wikipedia://en/19344125), and many other unsolved mathematical problems. When attempting to solve problems in this class, it makes no difference whether ZF or ZFC is employed if the only question is the existence of a proof. It is possible, however, that there is a shorter proof of a theorem from ZFC than from ZF.

The axiom of choice is not the only significant statement that is independent of ZF. For example, the [generalized continuum hypothesis](wikipedia://en/5705#The_generalized_continuum_hypothesis) (GCH) is not only independent of ZF, but also independent of ZFC. However, ZF plus GCH implies AC, making GCH a strictly stronger claim than AC, even though they are both independent of ZF.

:::

## Stronger axioms {#Stronger_axioms}

The [axiom of constructibility](wikipedia://en/696472) and the [generalized continuum hypothesis](wikipedia://en/5705#The_generalized_continuum_hypothesis) each imply the axiom of choice and are strictly stronger than it. In class theories such as [Von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) and [Morse–Kelley set theory](wikipedia://en/2693655), there is an axiom called the [axiom of global choice](wikipedia://en/5322320) that is stronger than the axiom of choice for sets because it also applies to proper classes. The axiom of global choice follows from the [axiom of limitation of size](wikipedia://en/5322450). Tarski's axiom, which is used in [Tarski–Grothendieck set theory](wikipedia://en/6105873) and states (in the vernacular) that every set belongs to some [Grothendieck universe](wikipedia://en/1072144), is stronger than the axiom of choice.

:::

## Equivalents {#Equivalents}

There are important statements that, assuming the axioms of [ZF](wikipedia://en/152214) but neither AC nor ¬AC, are equivalent to the axiom of choice (that is, their truth values in ZF, while undecidable, are the same as that of AC).[^o42] The most important among them are [Zorn's lemma](wikipedia://en/51442) and the [well-ordering theorem](wikipedia://en/33458). In fact, Zermelo initially introduced the axiom of choice in order to formalize his proof of the well-ordering theorem.

- [Set theory](wikipedia://en/27553)
  - Trichotomy: The cardinalities of any two sets are comparable with each other. That is, given any two sets, an [injection](wikipedia://en/45196) exists from (at least) one of the sets to the other.
  - [Tarski's theorem about choice](wikipedia://en/320578): For every infinite set $A$, the sets $A$ and $A\times A$ have the same [cardinality](wikipedia://en/6174); i.e., there exists a [bijection](https://en.wikipedia.org/wiki/Bijective_function) between them.
  - Every [surjection](wikipedia://en/27873) $f:S\to T$ has a [right inverse](wikipedia://en/14907#Left_and_right_inverses); i.e., there exists a function $g:T\to S$ such that $f\circ g = \mathrm{id}_T$.
  - For every disjoint collection $\mathcal{C}$ of nonempty sets, there exists a set $C\subseteq\cup_{S \in \mathcal{C}}(S)$ that intersects each member of $\mathcal{C}$ in exactly one element. That is, every [partition of a set](wikipedia://en/340240) has a [transversal](wikipedia://en/897733).[^o43]
  - If a relation $R$ from a set $X$ to a set $Y$ has the property that for every $x \in X$, there is a $y \in Y$ with $x R y$, then there exists a function $f:X\to Y$ such that $x R f(x)$ for all $x\in X$.
  - The [Cartesian product](wikipedia://en/24104095#Infinite_Cartesian_products) of any [indexed family](wikipedia://en/23624339) of nonempty sets is nonempty. That is, for any set $I$, and any $I$-indexed family $(S_i)_{i\in I}$ of nonempty sets, there exists an $I$-indexed set $(s_i)_{i\in I}$ of elements in $\cup_{i\in I}(S_i)$ such that $s_i\in S_i$ for all $i \in I$.
  - In any collection $\mathcal{A}$ of nonempty sets, there exists a disjoint subcollection $\mathcal{C}$ of sets whose union $\cup_{S\in\mathcal{C}}(S)$ intersects all the members of $\mathcal{A}$. (Note that such a disjoint subcollection is precisely one that is *maximal* with respect to set inclusion.)
  - For any set $X$, there exists a *maximal* (under set inclusion) collection $\mathcal{A}$ of subsets of $X$ for which every *finite* subcollection $\mathcal{C}$ of $\mathcal{A}$ has a nonempty intersection $\cap_{S\in\mathcal{C}}(S)$. (This statement is key to a standard proof of [Tychonoff's theorem](wikipedia://en/82739).)
  - [Well-ordering theorem](wikipedia://en/33458): Every set $A$ has a [well-ordering](https://en.wikipedia.org/wiki/Well-ordered_set) (i.e., a [total ordering](https://en.wikipedia.org/wiki/Totally_ordered_set) in which every nonempty subset of $A$ has a minimum element). Consequently, every [cardinal](wikipedia://en/6173) has an [initial ordinal](https://en.wikipedia.org/wiki/Initial_ordinal).
  - For every [ordinal](wikipedia://en/26547932) $\alpha$, the powerset (i.e., the set of all subsets) of $\alpha$ has a well-ordering.
  - [Hausdorff maximal principle](wikipedia://en/13665): Every [partially ordered set](wikipedia://en/23572) has a maximal [chain](https://en.wikipedia.org/wiki/Totally_ordered_set) (with respect to inclusion). Equivalently, in a partially ordered set, every chain can be extended to a maximal chain.
  - [Antichain](wikipedia://en/348973) principle: Every partially ordered set has a maximal [antichain](wikipedia://en/348973) (with respect to inclusion). Equivalently, in any partially ordered set, every antichain can be extended to a maximal antichain.
  - [Zorn's lemma](wikipedia://en/51442): If $(A,<)$ is any partially ordered set in which every chain has an upper bound in $A$, then $(A,<)$ has at least one maximal element.
  - [Kuratowski's lemma](https://en.wikipedia.org/wiki/Kuratowski's_lemma): If $\mathcal{A}$ is any family of sets with the property that for any subfamily $\mathcal{C}$ of $\mathcal{A}$ totally ordered by set inclusion, the union $\cup_{A\in\mathcal{C}}(A)$ is an element of $\mathcal{A}$, then $\mathcal{A}$ has at least one element *maximal* with respect to inclusion.
  - [Tukey's lemma](https://en.wikipedia.org/wiki/Tukey's_lemma): If $\mathcal{A}$ is any family of subsets of a set $X$ with the property that a set $B\subseteq X$ is an element of $\mathcal{A}$ iff every *finite* subset of $B$ is an element of $\mathcal{A}$, then $\mathcal{A}$ has at least one element *maximal* with respect to inclusion.
  - [König's theorem](https://en.wikipedia.org/wiki/König's_theorem_%28set_theory%29): Informally, the sum of a sequence of cardinals is strictly less than the product of a sequence of larger cardinals. (The reason for the term "informally" is that the sum or product of a "sequence" of cardinals cannot itself be defined without some aspect of the axiom of choice.)
- [Abstract algebra](wikipedia://en/19616384)
  - Every [vector space](wikipedia://en/32370) has a [basis](wikipedia://en/18420); equivalently, every [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) subset of a vector space can be extended to a basis, while every [spanning subset](https://en.wikipedia.org/wiki/Span_%28linear_algebra%29) contains a basis. In the language of [module theory](https://en.wikipedia.org/wiki/Module_theory), all vector spaces are [free modules](wikipedia://en/326454).[^o44]
  - [Krull's theorem](wikipedia://en/4128358): Every nontrivial unital [ring](wikipedia://en/48404) contains a [maximal ideal](wikipedia://en/48164); equivalently, every proper [ideal](wikipedia://en/25977) of a unital ring can be extended to a maximal ideal.
  - For every non-empty set $S$ there is a [binary operation](wikipedia://en/3948) defined on $S$ that gives it a [group structure](wikipedia://en/19447).[^o45] (A [cancellative](wikipedia://en/490646) binary operation is enough; see [Group structure and the axiom of choice](wikipedia://en/37039918).)
  - Every [free abelian group](wikipedia://en/247296) is [projective](wikipedia://en/364488).[^n10]
  - Baer's criterion: Every [divisible abelian group](wikipedia://en/472147) is [injective](wikipedia://en/473775).[^n10]
  - Every set is a [projective object](wikipedia://en/3017382) in the [category of sets](wikipedia://en/26829).[^o48]
- [Functional analysis](wikipedia://en/11180)
  - The closed unit ball of the dual of a [normed vector space](wikipedia://en/21538) over the reals has an [extreme point](wikipedia://en/454968).
- [Point-set topology](https://en.wikipedia.org/wiki/Point-set_topology)
  - [Tychonoff's theorem](wikipedia://en/82739): The [product](wikipedia://en/24910) of any [indexed family](wikipedia://en/23624339) of [compact topological spaces](wikipedia://en/6042) is compact.
  - The [closure](wikipedia://en/42309) of the product of any indexed family of subsets of a topological space is equal to the product of the closures of those subsets.
- [Mathematical logic](wikipedia://en/19636)
  - If $S$ is a set of sentences of [first-order logic](wikipedia://en/10983) and $B$ is a consistent subset of $S$, then $B$ is included in a set that is maximal among consistent subsets of $S$. The special case where $S$ is the set of **all** first-order sentences in a given [signature](wikipedia://en/7788156) is weaker, equivalent to the [Boolean prime ideal theorem](wikipedia://en/314919); see the section "Weaker forms" below.
  - [Löwenheim–Skolem theorem](wikipedia://en/341482): If a first-order theory has an infinite model, then it has an infinite model of every possible cardinality greater than or equal to the cardinality of the language of this theory.
- [Graph theory](wikipedia://en/12401)
  - Every connected [graph](wikipedia://en/12401) has a [spanning tree](wikipedia://en/455770); equivalently, every [tree](wikipedia://en/48560) in a connected graph can be extended to a spanning tree, while every [spanning subgraph](https://en.wikipedia.org/wiki/Spanning_subgraph) contains a spanning tree.[^o50][^o51]

### Category theory {#Category_theory}

Several results in [category theory](wikipedia://en/5869) invoke the axiom of choice for their proof. These results might be weaker than, equivalent to, or stronger than the axiom of choice, depending on the strength of the technical foundations. For example, if one defines categories in terms of sets, that is, as sets of objects and morphisms (usually called a [small category](https://en.wikipedia.org/wiki/Small_category)), then there is no [category of all sets](wikipedia://en/26829), and so it is difficult for a category-theoretic formulation to apply to all sets. On the other hand, other foundational descriptions of category theory are considerably stronger, and an identical category-theoretic statement of choice may be stronger than the standard formulation, à la class theory, mentioned above.

Examples of category-theoretic statements which require choice include:

- Every [small category](https://en.wikipedia.org/wiki/Small_category) has a [skeleton](wikipedia://en/1812151).
- If two small categories are weakly equivalent, then they are [equivalent](wikipedia://en/379051).
- Every continuous functor on a small-complete category which satisfies the appropriate solution set condition has a [left adjoint](wikipedia://en/53991) (the Freyd adjoint functor theorem).

## Weaker forms {#Weaker_forms}

There are several weaker statements unprovable in ZF that are logically implied by the axiom of choice (AC) within ZF but are not equivalent to AC. One example is the [axiom of dependent choice](wikipedia://en/441950) (DC). A still weaker example is the [axiom of countable choice](wikipedia://en/421086) (AC<sub>ω</sub> or CC), which states that a choice function exists for any countable family of nonempty sets. These axioms are sufficient for many proofs in elementary [mathematical analysis](wikipedia://en/48396), and are consistent with some principles, such as the Lebesgue measurability of all subsets of real numbers, that are disprovable from the full axiom of choice.

Given an ordinal parameter α ≥ ω+2 – for every set *S* with rank less than α, *S* is well-orderable. Given an ordinal parameter α ≥ 1 – for every set *S* with [Hartogs number](wikipedia://en/2977752) less than ω<sub>α</sub>, *S* is well-orderable. As the ordinal parameter is increased, these approximate the full axiom of choice more and more closely.

Other choice axioms weaker than axiom of choice include the [Boolean prime ideal theorem](wikipedia://en/314919) and the [axiom of uniformization](wikipedia://en/2148548). The former is equivalent in ZF to [Tarski](wikipedia://en/59920)'s 1930 [ultrafilter lemma](https://en.wikipedia.org/wiki/Ultrafilter_lemma): every [filter](wikipedia://en/12646549) is a subset of some [ultrafilter](wikipedia://en/67416519).

### Results requiring AC (or weaker forms) but weaker than it {#Results_requiring_AC_(or_weaker_forms)_but_weaker_than_it}

One of the most interesting aspects of the axiom of choice is the large number of places in mathematics where it shows up. Here are some statements that require the axiom of choice in the sense that they are not provable from ZF but are provable from ZFC (ZF plus AC). Equivalently, these statements are true in all models of ZFC but false in some models of ZF.

- [Set theory](wikipedia://en/27553)
  - [Axiom of countable choice](wikipedia://en/421086): The Cartesian product of any sequence (i.e., countable [indexed family](wikipedia://en/23624339)) of nonempty sets is nonempty. (This is just the axiom of choice with the indexing set restricted to countable size.)
  - [Axiom of dependent choice](wikipedia://en/441950): If $R$ is any relation on a set $S$ with the property that for every $x \in S$, there is a $y \in S$ with $x R y$, then, for every $x\in S$, there exists a sequence $\left(x_n\right)_{n \in \mathbb{N}}$ in $S$ starting at $x$ and satisfying $x_n R x_{n+1}$ for all $n \in \mathbb{N}$. (In ZF, this statement logically implies the [axiom of countable choice](wikipedia://en/421086), and is strictly stronger.)
  - Axiom of choice for finite sets: The Cartesian product of any indexed family of non-empty finite sets is nonempty. (Note that here, it is each *member* of the indexed family that is restricted in size, not the *indexing set*, in contrast with [countable choice](wikipedia://en/421086).)
  - Ultrafilter lemma: Every [filter](wikipedia://en/19719) on a set $S$ can be extended to an [ultrafilter](wikipedia://en/31911) on $S$. (In ZF, this statement logically implies the Axiom of choice for finite sets (above)[^o55].)
  - The [union](wikipedia://en/47949) of any countable family of [countable sets](https://en.wikipedia.org/wiki/Countable_sets) is countable. (In ZF, this statement is logically implied by the [axiom of countable choice](wikipedia://en/421086).)
  - Every [infinite](wikipedia://en/142679) set has a countable-infinite subset, i.e., has [cardinality](wikipedia://en/6173) greater than or equal to $\aleph_0$. (In ZF, this statement is logically implied by the [axiom of countable choice](wikipedia://en/421086) but is not equivalent; see [Dedekind infinite](https://en.wikipedia.org/wiki/Dedekind_infinite).)[^o56]
  - Eight definitions of a [finite set](wikipedia://en/11742#Other_concepts_of_finiteness) are equivalent.[^o57]
  - Every infinite [game](wikipedia://en/2596030#Basic_notions) $G_S$ in which $S$ is a [Borel](wikipedia://en/43327) subset of [Baire space](wikipedia://en/2078245) is [determined](wikipedia://en/2596030#Basic_notions).
  - Every infinite [cardinal](wikipedia://en/6173) $\kappa$ satisfies $2\kappa=\kappa$.[^o58]
- [Measure theory](https://en.wikipedia.org/wiki/Measure_theory)
  - The [Vitali theorem](wikipedia://en/424189): There exist subsets of $\mathbb{R}^n$ (for any $n>0$) that are not [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable); i.e., the set of all subsets of $\mathbb{R}^n$ does not form a [measure space](wikipedia://en/45270) of $\mathbb{R}^n$ under the standard (Lebesgue) outer-measure.
  - There exist Lebesgue-measurable subsets of $\mathbb{R}^n$ that are not [Borel sets](wikipedia://en/43327); i.e., the Borel $\sigma$-algebra on $\mathbb{R}^n$ is *strictly* contained in the Lebesgue-measure $\sigma$-algebra on $\mathbb{R}^n$.
  - The [Hausdorff paradox](wikipedia://en/634759).
  - The [Banach–Tarski paradox](wikipedia://en/19759220).
- [Abstract algebra](wikipedia://en/19616384)
  - Every [field](wikipedia://en/10603) has an [algebraic closure](wikipedia://en/3129).
  - Every [field extension](wikipedia://en/11634) has a [transcendence basis](https://en.wikipedia.org/wiki/Transcendence_basis).
  - Every infinite-dimensional [vector space](wikipedia://en/32370) contains an infinite linearly independent subset. (In ZF, this statement is logically implied by the [axiom of countable choice](wikipedia://en/421086).)
  - [Stone's representation theorem for Boolean algebras](wikipedia://en/604111) needs the [Boolean prime ideal theorem](wikipedia://en/314919).
  - The [Nielsen–Schreier theorem](wikipedia://en/18401725), that every subgroup of a free group is free.
  - The additive groups of **[R](https://en.wikipedia.org/wiki/Real_numbers)** and **[C](wikipedia://en/5826)** are isomorphic.[^o59][^o60]
- [Metric spaces](https://en.wikipedia.org/wiki/Metric_spaces)
  - In any metric space $X$, the topological and sequential definitions of an [accumulation point](wikipedia://en/226505) of a subset $S$ are equivalent. (In the topological definition, $x$ is an accumulation point of $S$ iff every neighborhood of $x$ in $X$ intersects $S-\{x\}$, while in the sequential definition, $x$ is an accumulation point of $S$ iff there exists a sequence in $S-\{x\}$ that converges to $x$ in $X$.) This equivalence as well as the two below equivalences require the [axiom of countable choice](wikipedia://en/421086), but not the full axiom of choice.
  - For functions between metric spaces, the topological and sequential definitions of [continuity](wikipedia://en/6122) are equivalent. (In the topological definition, a function $f:X \to Y$ is continuous at $x$ iff for every neighborhood $V$ of $f(x)$ in $Y$, there is a neighborhood $U$ of $x$ in $X$ such that $f(U)\subseteq V$. In the sequential definition, a function $f:X \to Y$ is continuous at $x$ iff for every sequence $\{x_n\}_{n\ge 1}$ in $X$ converging to $x$, the sequence $\{f(x_n)\}_{n\ge 1}$ converges to $f(x)$ in $Y$.)
  - For metric spaces, the topological and sequential definitions of [compactness](https://en.wikipedia.org/wiki/Compactness) are equivalent. (In the topological definition, $X$ is compact iff every collection of open subsets of $X$ that covers $X$ has a finite subcollection which also covers $X$. In the sequential definition, $X$ is compact iff every sequence in $X$ has a subsequence that converges in $X$.)
- [Functional analysis](wikipedia://en/11180)
  - The [Hahn–Banach theorem](wikipedia://en/13860) in [functional analysis](wikipedia://en/11180), allowing the extension of [linear functionals](wikipedia://en/18102).
  - The theorem that every [Hilbert space](wikipedia://en/20598932) has an orthonormal basis.
  - The [Banach–Alaoglu theorem](wikipedia://en/577366) about [compactness](https://en.wikipedia.org/wiki/Compactness) of sets of functionals.
  - The [Baire category theorem](wikipedia://en/55227) about [complete](https://en.wikipedia.org/wiki/Complete_space) [metric spaces](wikipedia://en/20018), and its consequences, such as the [open mapping theorem](wikipedia://en/17395276) and the [closed graph theorem](wikipedia://en/497834).
  - On every infinite-dimensional topological vector space there is a [discontinuous linear map](wikipedia://en/3531066).
- [General topology](wikipedia://en/178649)
  - A uniform space is compact if and only if it is complete and totally bounded.
  - Every [Tychonoff space](wikipedia://en/30554) has a [Stone–Čech compactification](wikipedia://en/52897).
  - [Urysohn's Lemma](https://en.wikipedia.org/wiki/Urysohn's_Lemma): For any two disjoint closed subsets $A$ and $B$ of a [normal space](https://en.wikipedia.org/wiki/Normal_space_%28topology%29) $X$, and any compact interval $[a,b]$ of $\mathbb{R}$, there exists a continuous map $f:X\to [a,b]$ such that $f(A)=\{a\}$ and $f(B)=\{b\}$. (In ZF, this statement is logically implied by the [axiom of dependent choice](wikipedia://en/441950), but not by the [axiom of countable choice](wikipedia://en/421086).)
  - [Tietze extension theorem](wikipedia://en/31404): For any closed subspace $A$ of a normal space $X$, and any closed or open interval $I$ of $\mathbb{R}$, and any continuous map $f:A\to I$, there exists a continuous map from $X$ to $I$ that extends $f$. (In ZF, this statement is logically equivalent to Urysohn's lemma.)
  - Existence of [partitions of unity](wikipedia://en/48636): For any [paracompact](https://en.wikipedia.org/wiki/Paracompactness) [Hausdorff](wikipedia://en/13637) space $X$ (in particular, any manifold), and any indexed open cover $(U_i)_{i\in I}$ of $X$, there exists a partition of unity of $X$ subordinate to $(U_i)_{i\in I}$.
- [Mathematical logic](wikipedia://en/19636)
  - [Gödel's completeness theorem](wikipedia://en/12450) for first-order logic: every consistent set of first-order sentences has a completion. That is, every consistent set of first-order sentences can be extended to a maximal consistent set.
  - The [compactness theorem](wikipedia://en/152207): If $\Sigma$ is a set of [first-order](https://en.wikipedia.org/wiki/First-order_predicate_calculus) (or alternatively, [zero-order](https://en.wikipedia.org/wiki/Propositional_calculus)) [sentences](wikipedia://en/2129527) such that every [finite](wikipedia://en/11742) subset of $\Sigma$ has a [model](https://en.wikipedia.org/wiki/Model_%28model_theory%29), then $\Sigma$ has a model.[^n11]

### Possibly equivalent implications of AC {#Possibly_equivalent_implications_of_AC}

::: {#o63 .problem cue=unsolved}

Does the partition principle imply the axiom of choice?

:::

There are several historically important set-theoretic statements implied by AC whose equivalence to AC is open. Zermelo cited the partition principle, which was formulated before AC itself, as a justification for believing AC. In 1906, Russell declared PP to be equivalent, but whether the partition principle implies AC is an old open problem in set theory,[^o64][^o65][^o66] and the equivalences of the other statements are similarly hard old open problems. In every *known* model of ZF where choice fails, these statements fail too, but it is unknown whether they can hold without choice.

- [Set theory](wikipedia://en/27553)
  - Partition principle: Given two sets *A* and *B*, if a [surjection](wikipedia://en/27873) exists from *A* to *B*, then an [injection](wikipedia://en/45196) exists from *B* to *A*. Equivalently, every [partition](wikipedia://en/340240) *P* of a set *S* is less than or equal to *S* in size.
  - Given any two sets *A* and *B* where *B* is nonempty, either an [injection](wikipedia://en/45196) or a [surjection](wikipedia://en/27873) (or both) exists from *A* to *B*.
  - Given any two nonempty sets, a [surjection](wikipedia://en/27873) exists from (at least) one of the sets to the other.
  - Converse [Schröder–Bernstein theorem](wikipedia://en/44218028): If two sets have surjections to each other, then they have the same [cardinality](wikipedia://en/6174).
  - Weak partition principle: Given two sets *A* and *B*, if both an [injection](wikipedia://en/45196) and a [surjection](wikipedia://en/27873) exists from *A* to *B*, then *A* and *B* have the same cardinality. Equivalently, a partition of a set *S* cannot be strictly larger than *S*. If WPP holds, this already implies the existence of a non-measurable set. Each of the previous three statements is implied by the preceding one, but it is unknown if any of these implications can be reversed.
  - There is no infinite decreasing sequence of cardinals. The equivalence was conjectured by Schoenflies in 1905.
- [Abstract algebra](wikipedia://en/19616384)
  - [Hahn embedding theorem](wikipedia://en/1075596): Every ordered abelian group *G* order-embeds as a subgroup of the additive group $\mathbb{R}^\Omega$ endowed with a [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order), where Ω is the set of Archimedean equivalence classes of *G*. This equivalence was conjectured by Hahn in 1907.

## Stronger forms of the negation of AC {#Stronger_forms_of_the_negation_of_AC}

If we abbreviate by BP the claim that every set of real numbers has the [property of Baire](wikipedia://en/2213768), then BP is stronger than ¬AC, which asserts the nonexistence of any choice function on perhaps only a single set of nonempty sets. Strengthened negations may be compatible with weakened forms of AC. For example, ZF + DC[^o68] + BP is consistent, if ZF is.

It is also consistent with ZF + DC that every set of reals is [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable), but this consistency result, due to [Robert M. Solovay](wikipedia://en/3160110), cannot be proved in ZFC itself, and requires a mild [large cardinal](wikipedia://en/383644) assumption (the existence of an [inaccessible cardinal](wikipedia://en/248076)). The much stronger [axiom of determinacy](wikipedia://en/1002300), or AD, implies that every set of reals is Lebesgue measurable, has the property of Baire, and has the [perfect set property](wikipedia://en/2221109) (all three of these results are refuted by AC itself). ZF + DC + AD is consistent provided that a sufficiently strong large cardinal axiom is consistent (the existence of infinitely many [Woodin cardinals](wikipedia://en/248105)).

[Quine](wikipedia://en/33833)'s system of axiomatic set theory, [New Foundations](wikipedia://en/945957) (NF), takes its name from the title ("New Foundations for Mathematical Logic") of the 1937 article that introduced it. In the NF axiomatic system, the axiom of choice can be disproved.[^o69]

## Statements implying the negation of AC {#Statements_implying_the_negation_of_AC}

There are models of Zermelo-Fraenkel set theory in which the axiom of choice is false. We shall abbreviate "Zermelo-Fraenkel set theory plus the negation of the axiom of choice" by ZF¬C. For certain models of ZF¬C, it is possible to validate the negation of some standard ZFC theorems. As any model of ZF¬C is also a model of ZF, it is the case that for each of the following statements, there exists a model of ZF in which that statement is true.

- The negation of the [weak partition principle](https://en.wikipedia.org/wiki/Partition_principle): There is a set that can be partitioned into strictly more equivalence classes than the original set has elements, and a function whose domain is strictly smaller than its range. In fact, this is the case in all *known* models.
- There is a function *f* from the real numbers to the real numbers such that *f* is not continuous at *a*, but *f* is [sequentially continuous](https://en.wikipedia.org/wiki/Sequential_continuity) at *a*, i.e., for any sequence {*x<sub>n</sub>*} converging to *a*, lim<sub>*n*</sub> f(*x<sub>n</sub>*)=f(a).
- There is an infinite set of real numbers without a countably infinite subset.
- The real numbers are a countable union of countable sets.[^o71] This does not imply that the real numbers are countable: As pointed out above, to show that a countable union of countable sets is itself countable requires the [Axiom of countable choice](wikipedia://en/421086).
- There is a field with no algebraic closure.
- There is a field with two non-isomorphic algebraic closures.
- In all models of ZF¬C there is a vector space with no basis.
- There is a vector space with two bases of different cardinalities.
- There is a free [complete Boolean algebra](wikipedia://en/1839944) on countably many generators.[^o72]
- There is [a set that cannot be linearly ordered](wikipedia://en/31251396).
- There exists a model of ZF¬C in which every set in R<sup>*n*</sup> is [measurable](https://en.wikipedia.org/wiki/Measurable). Thus it is possible to exclude counterintuitive results like the [Banach–Tarski paradox](wikipedia://en/19759220) which are provable in ZFC. Furthermore, this is possible whilst assuming the [Axiom of dependent choice](wikipedia://en/441950), which is weaker than AC but sufficient to develop most of [real analysis](wikipedia://en/26478).
- In all models of ZF¬C, the [generalized continuum hypothesis](https://en.wikipedia.org/wiki/Generalized_continuum_hypothesis) does not hold.

For proofs, see (Jech 2008).

Additionally, by imposing definability conditions on sets (in the sense of [descriptive set theory](wikipedia://en/396619)) one can often prove restricted versions of the axiom of choice from axioms incompatible with general choice. This appears, for example, in the [Moschovakis coding lemma](wikipedia://en/54225729).

::: {#o75 .statement kind=statement/axiom cue=named-heading name="Axiom of choice in type theory"}

## Axiom of choice in type theory {#Axiom_of_choice_in_type_theory}

In [type theory](wikipedia://en/40282), a different kind of statement is known as the axiom of choice. This form begins with two types, σ and τ, and a relation *R* between objects of type σ and objects of type τ. The axiom of choice states that if for each *x* of type σ there exists a *y* of type τ such that *R*(*x*,*y*), then there is a function *f* from objects of type σ to objects of type τ such that *R*(*x*,*f*(*x*)) holds for all *x* of type σ:

$$(\forall x^\sigma)(\exists y^\tau) R(x,y) \to (\exists f^{\sigma \to \tau})(\forall x^\sigma) R(x,f(x)).$$

Unlike in set theory, the axiom of choice in type theory is typically stated as an [axiom scheme](https://en.wikipedia.org/wiki/Axiom_scheme), in which *R* varies over all formulas or over all formulas of a particular logical form.
