# Almost all

::: {#o1 .subject cue=lead name="Almost all"}

In [mathematics](wikipedia://en/18831), the term "**almost all**" means "all but a negligible quantity". More precisely, if $X$ is a [set](wikipedia://en/26691), "almost all elements of $X$" means "all elements of $X$ but those in a [negligible](wikipedia://en/195132) [subset](wikipedia://en/27631) of $X$". The meaning of "negligible" depends on the mathematical context; for instance, it can mean [finite](wikipedia://en/11742), [countable](wikipedia://en/6026), or [null](wikipedia://en/21520).

:::

In contrast, "**almost no**" means "a negligible quantity"; that is, "almost no elements of $X$" means "a negligible quantity of elements of $X$".

## Meanings in different areas of mathematics {#Meanings_in_different_areas_of_mathematics}

### Prevalent meaning {#Prevalent_meaning}

Throughout mathematics, "almost all" is sometimes used to mean "all (elements of an [infinite set](wikipedia://en/142679)) except for [finitely](wikipedia://en/11742) many". This use occurs in philosophy as well. Similarly, "almost all" can mean "all (elements of an [uncountable set](wikipedia://en/32248)) except for [countably](wikipedia://en/6026) many".

Examples:

- Almost all positive integers are greater than 10<sup>12</sup>.p. 293
- Almost all [prime numbers](wikipedia://en/23666) are odd (2 is the only exception).[^o4]
- Almost all [polyhedra](https://en.wikipedia.org/wiki/Polyhedra) are [irregular](wikipedia://en/333299#The_regular_polyhedra) (as there are only nine exceptions: the five [platonic solids](wikipedia://en/23905) and the four [Kepler–Poinsot polyhedra](wikipedia://en/16814)).
- If P is a nonzero [polynomial](wikipedia://en/23000), then P(x) ≠ 0 for almost all x (if not all *x*).

### Meaning in measure theory {#Meaning_in_measure_theory}

*Image: CantorEscalier.svg.* The [Cantor function](wikipedia://en/320819) as a function that has zero derivative almost everywhere

When speaking about the [reals](wikipedia://en/20646438), sometimes "almost all" can mean "all reals except for a [null set](wikipedia://en/21520)". Similarly, if S is some set of reals, "almost all numbers in S" can mean "all numbers in S except for those in a null set". The [real line](https://en.wikipedia.org/wiki/Real_line) can be thought of as a one-dimensional [Euclidean space](wikipedia://en/9697). In the more general case of an n-dimensional space (where n is a positive integer), these definitions can be [generalised](https://en.wikipedia.org/wiki/Generalised) to "all points except for those in a null set" or "all points in S except for those in a null set" (this time, S is a set of points in the space). Even more generally, "almost all" is sometimes used in the sense of "[almost everywhere](wikipedia://en/44688)" in [measure theory](https://en.wikipedia.org/wiki/Measure_theory), or in the closely related sense of "[almost surely](wikipedia://en/351908)" in [probability theory](wikipedia://en/23542).

Examples:

- In a [measure space](wikipedia://en/45270), such as the real line, countable sets are null. The set of [rational numbers](wikipedia://en/19727024) is countable, so almost all real numbers are irrational.
- Georg [Cantor's first set theory article](wikipedia://en/22697171) proved that the set of [algebraic numbers](wikipedia://en/1158) is countable as well, so almost all reals are [transcendental](wikipedia://en/30325).
- Almost all reals are [normal](wikipedia://en/204277).
- The [Cantor set](wikipedia://en/6172) is also null. Thus, almost all reals are not in it even though it is uncountable.
- The derivative of the [Cantor function](wikipedia://en/320819) is 0 for almost all numbers in the [unit interval](wikipedia://en/49324). It follows from the previous example because the Cantor function is [locally constant](wikipedia://en/295629), and thus has derivative 0 outside the Cantor set.

### Meaning in number theory {#Meaning_in_number_theory}

In [number theory](wikipedia://en/21527), "almost all positive integers" can mean "the positive integers in a set whose [natural density](wikipedia://en/1819983) is 1". That is, if A is a set of positive integers, and if the proportion of positive integers in *A* below n (out of all positive integers below n) [tends to](wikipedia://en/285773) 1 as n tends to infinity, then almost all positive integers are in A.

More generally, let S be an infinite set of positive integers, such as the set of even positive numbers or the set of [primes](wikipedia://en/23666), if A is a subset of S, and if the proportion of elements of S below n that are in A (out of all elements of S below n) tends to 1 as n tends to infinity, then it can be said that almost all elements of S are in A.

Examples:

- The natural density of [cofinite sets](https://en.wikipedia.org/wiki/Cofinite_set) of positive integers is 1, so each of them contains almost all positive integers.
- Almost all positive integers are [composite](wikipedia://en/82289).
- Almost all even positive numbers can be expressed as the sum of two primes.p. 489
- Almost all primes are [isolated](wikipedia://en/41997#Isolated_prime). Moreover, for every positive integer $g$, almost all primes have [prime gaps](wikipedia://en/5075259) of more than $g$ both to their left and to their right; that is, there is no other prime between $p - g$ and $p + g$.

### Meaning in graph theory {#Meaning_in_graph_theory}

In [graph theory](wikipedia://en/12401), if A is a set of (finite [labelled](wikipedia://en/1609861)) [graphs](wikipedia://en/325806), it can be said to contain almost all graphs, if the proportion of graphs with n vertices that are in A tends to 1 as n tends to infinity. However, it is sometimes easier to work with probabilities, so the definition is reformulated as follows. The proportion of graphs with n vertices that are in A equals the probability that a random graph with n vertices (chosen with the [uniform distribution](wikipedia://en/1699214)) is in A, and choosing a graph in this way has the same outcome as generating a graph by flipping a coin for each pair of vertices to decide whether to connect them. Therefore, equivalently to the preceding definition, the set *A* contains almost all graphs if the probability that a coin-flip–generated graph with n vertices is in A tends to 1 as n tends to infinity. Sometimes, the latter definition is modified so that the graph is chosen randomly in some [other way](wikipedia://en/358477#Models), where not all graphs with n vertices have the same probability, and those modified definitions are not always equivalent to the main one.

The use of the term "almost all" in graph theory is not standard; the term "[asymptotically almost surely](https://en.wikipedia.org/wiki/Asymptotically_almost_surely)" is more commonly used for this concept.

Example:

- Almost all graphs are [asymmetric](wikipedia://en/20249418).
- Almost all graphs have [diameter](wikipedia://en/2979341) 2.

### Meaning in topology {#Meaning_in_topology}

In [topology](wikipedia://en/29954) and especially [dynamical systems theory](wikipedia://en/990632) (including applications in economics), "almost all" of a [topological space](wikipedia://en/30450)'s points can mean "all of the space's points except for those in a [meagre set](wikipedia://en/226975)". Some use a more limited definition, where a subset contains almost all of the space's points only if it contains some [open](wikipedia://en/39358) [dense set](wikipedia://en/23523594).

Example:

- Given an [irreducible](wikipedia://en/7556651) [algebraic variety](wikipedia://en/248808), the [properties](https://en.wikipedia.org/wiki/Property_%28mathematics%29) that hold for almost all points in the variety are exactly the [generic properties](wikipedia://en/12886758). This is due to the fact that in an irreducible algebraic variety equipped with the [Zariski topology](wikipedia://en/241744), all nonempty open sets are dense.

### Meaning in algebra {#Meaning_in_algebra}

In [abstract algebra](wikipedia://en/19616384) and [mathematical logic](wikipedia://en/19636), if U is an [ultrafilter](wikipedia://en/67416519) on a set X, "almost all elements of X" sometimes means "the elements of some *element* of U". For any [partition](wikipedia://en/340240) of X into two [disjoint sets](wikipedia://en/39359), one of them will necessarily contain almost all elements of X. It is possible to think of the elements of a [filter](wikipedia://en/12646549) on X as containing almost all elements of X, even if it isn't an ultrafilter.
