# Naive set theory

::: {#o1 .subject cue=lead name="Naive set theory"}

**Naive set theory** is any of several set theories used in the discussion of the [foundations of mathematics](wikipedia://en/169358). Unlike [axiomatic set theories](wikipedia://en/27553#Axiomatic_set_theory), which are defined using [formal logic](wikipedia://en/19636#Formal_logical_systems), naive set theory is defined informally, in [natural language](wikipedia://en/21173). It describes the aspects of [mathematical sets](wikipedia://en/26691) familiar in [discrete mathematics](wikipedia://en/8492) (for example [Venn diagrams](wikipedia://en/61701) and symbolic reasoning about their [Boolean algebra](wikipedia://en/54476844)), and suffices for the everyday use of set theory concepts in contemporary mathematics.[^o2]

:::

Sets are of great importance in mathematics; in modern formal treatments, most mathematical objects ([numbers](wikipedia://en/21690), [relations](wikipedia://en/22517558), [functions](wikipedia://en/185427), etc.) are defined in terms of sets. Naive set theory suffices for many purposes, while also serving as a stepping stone towards more formal treatments.

::: {#o4 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

A *naive theory* in the sense of "naive set theory" is a non-formalized theory, that is, a theory that uses [natural language](wikipedia://en/21173) to describe sets and operations on sets. Such theory treats sets as platonic absolute objects. The words "*and*, *or*, *if ... then*, *not*, *for some*, *for every* " are treated as in ordinary mathematics. As a matter of convenience, use of naive set theory and its formalism prevails even in higher mathematics – including in more formal settings of set theory itself.

The first development of [set theory](wikipedia://en/27553) was a naive set theory. It was created at the end of the 19th century by [Georg Cantor](wikipedia://en/12216) as part of his study of [infinite sets](wikipedia://en/142679)[^n1] and developed as a formal but inconsistent system [^o6] by [Gottlob Frege](wikipedia://en/48416) in his *Grundgesetze der Arithmetik*.

Naive set theory may refer to several very distinct notions. It may refer to

- Informal presentation of an axiomatic set theory, e.g. as in *[Naive Set Theory](wikipedia://en/21986)* by [Paul Halmos](wikipedia://en/318598).
- Early or later versions of [Georg Cantor](wikipedia://en/12216)'s theory and other informal systems.
- Decidedly inconsistent theories (whether axiomatic or not), such as a theory of [Gottlob Frege](wikipedia://en/48416)[^o7] that yielded [Russell's paradox](wikipedia://en/46095), and theories of [Giuseppe Peano](wikipedia://en/13043)[^o8] and [Richard Dedekind](wikipedia://en/23475106).

### Paradoxes {#Paradoxes}

The assumption that any property may be used to form a set, without restriction, leads to [paradoxes](wikipedia://en/10409979). One common example is [Russell's paradox](wikipedia://en/46095): there is no set consisting of "all sets that do not contain themselves". Thus consistent systems of (either naive or formal) set theory must include some limitations on the principles which can be used to form sets.

### Cantor's theory {#Cantor's_theory}

Some believe that [Georg Cantor](wikipedia://en/12216)'s set theory was not actually implicated in the set-theoretic paradoxes (see Frápolli 1991). One difficulty in determining this with certainty is that Cantor did not provide an axiomatization of his system. By 1899, Cantor was aware of some of the paradoxes following from unrestricted interpretation of his theory, for instance [Cantor's paradox](wikipedia://en/2732904)[^o11] and the [Burali-Forti paradox](wikipedia://en/51653),[^o12] and did not believe that they discredited his theory.[^o13] Cantor's paradox can actually be derived from the above (false) assumption—that any property $P(x)$ may be used to form a set—using for $P(x)$ "$x$ is a [cardinal number](wikipedia://en/6173)". Frege explicitly axiomatized a theory in which a formalized version of naive set theory can be interpreted, and it is *this* formal theory which [Bertrand Russell](wikipedia://en/4163) actually addressed when he presented his paradox, not necessarily a theory Cantorwho, as mentioned, was aware of several paradoxespresumably had in mind.

### Axiomatic theories {#Axiomatic_theories}

Axiomatic set theory was developed in response to these early attempts to understand sets, with the goal of determining precisely what operations were allowed and when.

### Consistency {#Consistency}

A naive set theory is not *necessarily* inconsistent, if it correctly specifies the sets allowed to be considered. This can be done by the means of definitions, which are implicit axioms. It is possible to state all the axioms explicitly, as in the case of Halmos' *Naive Set Theory*, which is actually an informal presentation of the usual axiomatic [Zermelo–Fraenkel set theory](wikipedia://en/152214). It is "naive" in that the language and notations are those of ordinary informal mathematics, and in that it does not deal with consistency or completeness of the axiom system.

Likewise, an axiomatic set theory is not necessarily consistent: not necessarily free of paradoxes. It follows from [Gödel's incompleteness theorems](wikipedia://en/58863) that a sufficiently complicated [first-order logic](wikipedia://en/10983) system (which includes most common axiomatic set theories) cannot be proved consistent[^o16] from within the theory itself – unless it is actually inconsistent. However, the common axiomatic systems are generally believed to be consistent; by their axioms they do exclude *some* paradoxes, like [Russell's paradox](wikipedia://en/46095). Based on [Gödel's theorem](wikipedia://en/58863), it is just not known – and never can be – if there are *no* paradoxes at all in these theories or in any sufficiently complicated first-order set theory, again, unless such theories are actually inconsistent. It should be mentioned, however, that results in [proof theoretical](wikipedia://en/183478) [ordinal analysis](wikipedia://en/16084282) are sometimes interpreted as [consistency proofs](wikipedia://en/4076831).

The term *naive set theory* is still today also used in some literature[^o17] to refer to the set theories studied by Frege and Cantor, rather than to the informal counterparts of modern axiomatic set theory.

### Utility {#Utility}

The choice between an axiomatic approach and other approaches is largely a matter of convenience. In everyday mathematics the best choice may be informal use of axiomatic set theory. References to particular axioms typically then occur only when demanded by tradition, e.g. the [axiom of choice](wikipedia://en/840) is often mentioned when used. Likewise, formal proofs occur only when warranted by exceptional circumstances. This informal usage of axiomatic set theory can have (depending on notation) precisely the *appearance* of naive set theory as outlined below. It is considerably easier to read and write (in the formulation of most statements, proofs, and lines of discussion) and is less error-prone than a strictly formal approach.

:::

## Sets, membership and equality {#Sets,_membership_and_equality}

In naive set theory, a **set** is described as a well-defined collection of objects. These objects are called the **elements** or **members** of the set. Objects can be anything: numbers, people, other sets, etc. For instance, 4 is a member of the set of all even [integers](wikipedia://en/14563). Clearly, the set of even numbers is infinitely large; there is no requirement that a set be finite.

### Note on consistency {#Note_on_consistency}

It does *not* follow from this definition *how* sets can be formed, and what operations on sets again will produce a set. The term "well-defined" in "well-defined collection of objects" cannot, by itself, guarantee the consistency and unambiguity of what exactly constitutes and what does not constitute a set. Attempting to achieve this would be the realm of axiomatic set theory or of axiomatic **class theory**.

The problem, in this context, with informally formulated set theories, not derived from (and implying) any particular axiomatic theory, is that there may be several widely differing formalized versions, that have both different sets and different rules for how new sets may be formed, that all conform to the original informal definition. For example, Cantor's verbatim definition allows for considerable freedom in what constitutes a set. On the other hand, it is unlikely that Cantor was particularly interested in sets containing cats and dogs, but rather only in sets containing purely mathematical objects. An example of such a class of sets could be the [von Neumann universe](wikipedia://en/445980). But even when fixing the class of sets under consideration, it is not always clear which rules for set formation are allowed without introducing paradoxes.

For the purpose of fixing the discussion below, the term "well-defined" should instead be interpreted as an *intention*, with either implicit or explicit rules (axioms or definitions), to rule out inconsistencies. The purpose is to keep the often deep and difficult issues of consistency away from the, usually simpler, context at hand. An explicit ruling out of *all* conceivable inconsistencies (paradoxes) cannot be achieved for an axiomatic set theory anyway, due to Gödel's second incompleteness theorem, so this does not at all hamper the utility of naive set theory as compared to axiomatic set theory in the simple contexts considered below. It merely simplifies the discussion. Consistency is henceforth taken for granted unless explicitly mentioned.

### Membership {#Membership}

*Image: First usage of the symbol ∈.png.* First usage of the symbol ϵ in the work *[Arithmetices principia nova methodo exposita](https://archive.org/details/arithmeticespri00peangoog)* by [Giuseppe Peano](wikipedia://en/13043)

If *x* is a member of a set *A*, then it is also said that *x* **belongs to** *A*, or that *x* is in *A*. This is denoted by *x* ∈ *A*. The symbol ∈ is a derivation from the lowercase Greek letter [epsilon](https://en.wikipedia.org/wiki/Epsilon), "ε", introduced by [Giuseppe Peano](wikipedia://en/13043) in 1889 and is the first letter of the word ἐστί (means "is"). The symbol ∉ is often used to write *x* ∉ *A*, meaning "x is not in A".

### Equality {#Equality}

Two sets *A* and *B* are defined to be **[equal](wikipedia://en/90446)** when they have precisely the same elements, that is, if every element of *A* is an element of *B* and every element of *B* is an element of *A*. (See [axiom of extensionality](wikipedia://en/52376).) Thus a set is completely determined by its elements; the description is immaterial. For example, the set with elements 2, 3, and 5 is equal to the set of all [prime numbers](wikipedia://en/23666) less than 6. If the sets *A* and *B* are equal, this is denoted symbolically as *A* = *B* (as usual).

### Empty set {#Empty_set}

The [empty set](wikipedia://en/9566), denoted as $\varnothing$ and sometimes $\{\}$, is a set with no members at all. Because a set is determined completely by its elements, there can be only one empty set. (See [axiom of empty set](wikipedia://en/52534).)[^n2] Although the empty set has no members, it can be a member of other sets. Thus $\varnothing\neq\{\varnothing\}$, because the former has no members and the latter has one member.[^n3]

## Specifying sets {#Specifying_sets}

The simplest way to describe a set is to list its elements between curly braces (known as defining a set *extensionally*). Thus $\{1, 2\}$ denotes the set whose only elements are 1 and 2. (See [axiom of pairing](wikipedia://en/52385).) Note the following points:

- The order of elements is immaterial; for example, $\{1, 2\} = \{2, 1\}$.
- Repetition ([multiplicity](wikipedia://en/19211790)) of elements is irrelevant; for example, $\{1, 2, 2\} = \{1, 1, 1, 2\} = \{1, 2\}$.

(These are consequences of the definition of equality in the previous section.)

This notation can be informally abused by saying something like $\{\operatorname{dogs}\}$ to indicate the set of all dogs, but this example would usually be read by mathematicians as "the set containing the single element *dogs*".

An extreme (but correct) example of this notation is $\{\}$, which denotes the empty set.

The notation $\{x : P(x)\}$, or sometimes $\{x\mid P(x)\}$, is used to denote the set containing all objects for which the condition $P$ holds (known as defining a set *intensionally*). For example, $\{x\mid x \in \mathbf{R}\}$ denotes the set of [real numbers](wikipedia://en/20646438), $\{x\mid x\text{ has } \operatorname{blonde} \operatorname{hair}\}$ denotes the set of everything with blonde hair.

This notation is called [set-builder notation](wikipedia://en/220089) (or "**set comprehension**", particularly in the context of [Functional programming](https://en.wikipedia.org/wiki/Functional_programming)). Some variants of set builder notation are:

- $\{x \in A\mid P(x)\}$ denotes the set of all $x$ that are already members of $A$ such that the condition $P$ holds for $x$. For example, if $\mathbf{Z}$ is the set of [integers](wikipedia://en/14563), then $\{x \in \mathbf{Z}\mid x\text{ is }\text{ even}\}$ is the set of all [even](https://en.wikipedia.org/wiki/Even_and_odd_numbers) integers. (See [axiom of specification](https://en.wikipedia.org/wiki/Axiom_of_specification).)
- $\{F(x)\mid x \in A\}$ denotes the set of all objects obtained by putting members of the set $A$ into the formula $F$. For example, $\{2x\mid x \in \mathbf{Z}\}$ is again the set of all even integers. (See [axiom of replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement).)
- $\{F(x)\mid P(x)\}$ is the most general form of set builder notation. For example, $\{x's \operatorname{owner}\mid x\text{ is } a \operatorname{dog}\}$ is the set of all dog owners.

## Subsets {#Subsets}

Given two sets *A* and *B*, *A* is a **[subset](wikipedia://en/27631)** of *B* if every element of *A* is also an element of *B*. In particular, each set *B* is a subset of itself; a subset of *B* that is not equal to *B* is called a **proper subset**.

If *A* is a subset of *B*, then one can also say that *B* is a **superset** of *A*, that *A* is **contained in** *B*, or that *B* **contains** *A*. In symbols, $A \subseteq B$ means that *A* is a subset of *B*, and $B \supseteq A$ means that *B* is a superset of *A*. Some authors use the symbols ⊂ and ⊃ for subsets, and others use these symbols only for *proper* subsets. For clarity, one can explicitly use the symbols ⊊ and ⊋ to indicate non-equality.

As an illustration, let **R** be the set of real numbers, let **Z** be the set of integers, let *O* be the set of odd integers, and let *P* be the set of current or former [U.S. Presidents](https://en.wikipedia.org/wiki/President_of_the_United_States). Then *O* is a subset of **Z**, **Z** is a subset of **R**, and (hence) *O* is a subset of **R**, where in all cases *subset* may even be read as *proper subset*. Not all sets are comparable in this way. For example, it is not the case either that **R** is a subset of *P* nor that *P* is a subset of **R**.

It follows immediately from the definition of equality of sets above that, given two sets *A* and *B*, $A = B$ if and only if $A \subseteq B$ and $B \subseteq A$. In fact this is often given as the definition of equality. Usually when trying to [prove](wikipedia://en/82285) that two sets are equal, one aims to show these two inclusions. The [empty set](wikipedia://en/9566) is a subset of every set (the statement that all elements of the empty set are also members of any set *A* is [vacuously true](https://en.wikipedia.org/wiki/Vacuously_true)).

The set of all subsets of a given set *A* is called the **[power set](wikipedia://en/23799)** of *A* and is denoted by $2^A$ or $P(A)$; the "$P$" is sometimes in a [script](https://en.wikipedia.org/wiki/Script_%28typefaces%29) font: $\wp(A)$. If the set *A* has *n* elements, then $P(A)$ will have $2^n$ elements.

## Universal sets and absolute complements {#Universal_sets_and_absolute_complements}

In certain contexts, one may consider all sets under consideration as being subsets of some given [universal set](wikipedia://en/296838). For instance, when investigating properties of the [real numbers](wikipedia://en/20646438) **R** (and subsets of **R**), **R** may be taken as the universal set. A true universal set is not included in standard set theory (see **Paradoxes** below), but is included in some non-standard set theories.

Given a universal set **U** and a subset *A* of **U**, the **[complement](wikipedia://en/54347)** of *A* (in **U**) is defined as

$$A^{C} := \{x \in \mathbf{U}\mid x \notin A\}.$$

In other words, *A*<sup>C</sup> ("*A-complement*"; sometimes simply *A**, "*****A-prime*" ) is the set of all members of****U**which are not members of*****A*.*** Thus with **R**, **Z** and *O* defined as in the section on subsets, if **Z** is the universal set, then *O<sup>C</sup>* is the set of even integers, while if **R** is the universal set, then *O<sup>C</sup>* is the set of all real numbers that are either even integers or not integers at all.

## Unions, intersections, and relative complements {#Unions,_intersections,_and_relative_complements}

Given two sets *A* and *B*, their **[union](wikipedia://en/47949)** is the set consisting of all objects which are elements of *A* or of *B* or of both (see [axiom of union](wikipedia://en/52553)). It is denoted by $A \cup B$.

The **[intersection](wikipedia://en/23476429)** of *A* and *B* is the set of all objects which are both in *A* and in *B*. It is denoted by $A \cap B$.

Finally, the **[relative complement](wikipedia://en/54347)** of *B* relative to *A*, also known as the **set theoretic difference** of *A* and *B*, is the set of all objects that belong to *A* but *not* to *B*. It is written as $A \setminus B$ or $A - B$.

Symbolically, these are respectively

$$A \cup B := \{x\mid (x \in A) \lor (x \in B)\};$$

$$A \cap B := \{x\mid (x \in A) \land (x \in B)\} = \{x \in A\mid x \in B\} = \{x \in B\mid x \in A\};$$

$$A \setminus B := \{x\mid (x \in A) \land \neg (x \in B)\} = \{x \in A\mid \neg (x \in B)\}.$$

The set *B* doesn't have to be a subset of *A* for $A \setminus B$ to make sense; this is the difference between the relative complement and the absolute complement ($A^{C} = U \setminus A$) from the previous section.

To illustrate these ideas, let *A* be the set of left-handed people, and let *B* be the set of people with blond hair. Then $A \cap B$ is the set of all left-handed blond-haired people, while $A \cup B$ is the set of all people who are left-handed or blond-haired or both. $A \setminus B$, on the other hand, is the set of all people that are left-handed but not blond-haired, while $B \setminus A$ is the set of all people who have blond hair but aren't left-handed.

Now let *E* be the set of all human beings, and let *F* be the set of all living things over 1000 years old. What is $E \cap F$ in this case? No living human being is [over 1000 years old](https://en.wikipedia.org/wiki/Oldest_people), so $E \cap F$ must be the [empty set](wikipedia://en/9566) {}.

For any set *A*, the power set $P(A)$ is a [Boolean algebra](wikipedia://en/3959) under the operations of union and intersection.

## Ordered pairs and Cartesian products {#Ordered_pairs_and_Cartesian_products}

Intuitively, an **[ordered pair](wikipedia://en/22362)** is simply a collection of two objects such that one can be distinguished as the *first element* and the other as the *second element*, and having the fundamental property that, two ordered pairs are equal if and only if their *first elements* are equal and their *second elements* are equal.

Formally, an ordered pair with **first coordinate** *a*, and **second coordinate** *b*, usually denoted by (*a*, *b*), can be defined as the set $\{\{a\}, \{a, b\}\}.$

It follows that, two ordered pairs (*a*,*b*) and (*c*,*d*) are equal if and only if $a = c$ and $b = d$.

Alternatively, an ordered pair can be formally thought of as a set {a,b} with a [total order](wikipedia://en/30330).

(The notation (*a*, *b*) is also used to denote an [open interval](https://en.wikipedia.org/wiki/Open_interval) on the [real number line](https://en.wikipedia.org/wiki/Real_number_line), but the context should make it clear which meaning is intended. Otherwise, the notation \]*a*, *b*\[ may be used to denote the open interval whereas (*a*, *b*) is used for the ordered pair).

If *A* and *B* are sets, then the **[Cartesian product](wikipedia://en/24104095)** (or simply **product**) is defined to be:

$$A \times B = \{(a,b)\mid a \in A\text{ and } b \in B\}.$$

That is, $A \times B$ is the set of all ordered pairs whose first coordinate is an element of *A* and whose second coordinate is an element of *B*.

This definition may be extended to a set $A \times B \times C$ of ordered triples, and more generally to sets of ordered [n-tuples](https://en.wikipedia.org/wiki/N-tuple) for any positive integer *n*. It is even possible to define infinite [Cartesian products](wikipedia://en/24104095), but this requires a more recondite definition of the product.

Cartesian products were first developed by [René Descartes](wikipedia://en/25525) in the context of [analytic geometry](wikipedia://en/2202). If **R** denotes the set of all [real numbers](wikipedia://en/20646438), then $\mathbf{R}^{2} := \mathbf{R} \times \mathbf{R}$ represents the [Euclidean plane](wikipedia://en/15575410) and $\mathbf{R}^{3} := \mathbf{R} \times \mathbf{R} \times \mathbf{R}$ represents three-dimensional [Euclidean space](wikipedia://en/9697).

## Some important sets {#Some_important_sets}

There are some ubiquitous sets for which the notation is almost universal. Some of these are listed below. In the list, *a*, *b*, and *c* refer to [natural numbers](wikipedia://en/21474), and *r* and *s* are [real numbers](wikipedia://en/20646438).

1. [Natural numbers](wikipedia://en/21474) are used for counting. A [blackboard bold](wikipedia://en/40276) capital **N** ($\mathbb{N}$) often represents this set.
1. [Integers](wikipedia://en/14563) appear as solutions for *x* in equations like *x* + *a* = *b*. A blackboard bold capital **Z** ($\mathbb{Z}$) often represents this set (from the German *Zahlen*, meaning *numbers*).
1. [Rational numbers](wikipedia://en/19727024) appear as solutions to equations like *a* + *bx* = *c*. A blackboard bold capital **Q** ($\mathbb{Q}$) often represents this set (for *[quotient](wikipedia://en/332640)*, because R is used for the set of real numbers).
1. [Algebraic numbers](wikipedia://en/1158) appear as solutions to [polynomial](wikipedia://en/23000) equations (with integer coefficients) and may involve [radicals](wikipedia://en/235029) (including $i=\sqrt{-1\,}$) and certain other [irrational numbers](wikipedia://en/20647689). A **Q** with an overline ($\overline{\mathbb{Q}}$) often represents this set. The overline denotes the operation of [algebraic closure](wikipedia://en/3129).
1. [Real numbers](wikipedia://en/20646438) represent the "real line" and include all numbers that can be approximated by rationals. These numbers may be rational or algebraic but may also be [transcendental numbers](wikipedia://en/30325), which cannot appear as solutions to polynomial equations with rational coefficients. A blackboard bold capital **R** ($\mathbb{R}$) often represents this set.
1. [Complex numbers](wikipedia://en/5826) are sums of a real and an imaginary number: $r+s\,i$. Here either $r$ or $s$ (or both) can be zero; thus, the set of real numbers and the set of strictly imaginary numbers are subsets of the set of complex numbers, which form an [algebraic closure](wikipedia://en/3129) for the set of real numbers, meaning that every polynomial with coefficients in $\mathbb{R}$ has at least one [root](https://en.wikipedia.org/wiki/Root_of_a_function) in this set. A blackboard bold capital **C** ($\mathbb{C}$) often represents this set. Note that since a number $r+s\,i$ can be identified with a point $(r,s)$ in the plane, $\mathbb{C}$ is basically "the same" as the [Cartesian product](wikipedia://en/24104095) $\mathbb{R}\times\mathbb{R}$ ("the same" meaning that any point in one determines a unique point in the other and for the result of calculations, it doesn't matter which one is used for the calculation, as long as multiplication rule is appropriate for $\mathbb{C}$).

## Paradoxes in early set theory {#Paradoxes_in_early_set_theory}

The unrestricted formation principle of sets referred to as the [axiom schema of unrestricted comprehension](wikipedia://en/52386#Unrestricted_comprehension),

If $P$ is a property, then there exists a set $Y = \{x : P(x)\}$,[^n4]

is the source of several early appearing paradoxes:

- $Y = \{x\mid x\text{ is }\text{ an } \operatorname{ordinal}\}$ led, in the year 1897, to the [Burali-Forti paradox](wikipedia://en/51653), the first published [antinomy](wikipedia://en/3175).
- $Y = \{x\mid x\text{ is } a \operatorname{cardinal}\}$ produced [Cantor's paradox](wikipedia://en/2732904) in 1897.[^o11]
- $Y = \{x\mid \{\} = \{\}\}$ yielded **Cantor's second antinomy** in the year 1899.[^o13] Here the property $P$ is true for all $x$, whatever $x$ may be, so $Y$ would be a [universal set](wikipedia://en/303405), containing everything.
- $Y = \{x\mid x \notin x\}$, i.e. the set of all sets that do not contain themselves as elements, gave [Russell's paradox](wikipedia://en/46095) in 1902.

If the axiom schema of unrestricted comprehension is weakened to the [axiom schema of specification](wikipedia://en/52386) or **axiom schema of separation**,

If $P$ is a property, then for any set $X$ there exists a set $Y = \{x \in X : P(x)\}$,[^n4]

then all the above paradoxes disappear.[^n4] There is a corollary. With the axiom schema of separation as an axiom of the theory, it follows, as a theorem of the theory:

The set of all sets does not exist.

Or, more spectacularly (Halmos' phrasing[^n5]): There is no [universe](wikipedia://en/229180). *Proof*: Suppose that it exists and call it $U$. Now apply the axiom schema of separation with $X = U$ and for $P(x)$ use $x \notin x$. This leads to Russell's paradox again. Hence $U$ cannot exist in this theory.[^n4]

Related to the above constructions is formation of the set

- $$Y = \{x\mid (x \in x) \to \{\} \ne \{\}\},$$

where the statement following the implication certainly is false. It follows, from the definition of $Y$, using the usual inference rules (and some afterthought when reading the proof in the linked article below) both that $Y \in Y \to \{\} \ne \{\}$ and $Y \in Y$ holds, hence $\{\} \ne \{\}$. This is [Curry's paradox](wikipedia://en/154163#Naive_set_theory).

It is (perhaps surprisingly) not the possibility of $x \in x$ that is problematic. It is again the axiom schema of unrestricted comprehension allowing $(x \in x) \to \{\} \ne \{\}$ for $P(x)$. With the axiom schema of specification instead of unrestricted comprehension, the conclusion $Y \in Y$ does not hold and hence $\{\} \ne \{\}$ is not a logical consequence.

Nonetheless, the possibility of $x \in x$ is often removed explicitly[^n6] or, e.g. in ZFC, implicitly,[^n7] by demanding the [axiom of regularity](wikipedia://en/2113) to hold.[^n7] One consequence of it is

There is no set $X$ for which $X \in X$,

or, in other words, no set is an element of itself.[^n8]

The axiom schema of separation is simply too weak (while unrestricted comprehension is a very strong axiom—too strong for set theory) to develop set theory with its usual operations and constructions outlined above.[^n4] The axiom of regularity is of a restrictive nature as well. Therefore, one is led to the formulation of other axioms to guarantee the existence of enough sets to form a set theory. Some of these have been described informally above and many others are possible. Not all conceivable axioms can be combined freely into consistent theories. For example, the [axiom of choice](wikipedia://en/840) of ZFC is incompatible with the conceivable "every set of reals is [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable)". The former implies the latter is false.
