# Absolute infinite

::: {#o1 .subject cue=lead name="Absolute infinite"}

The **absolute infinite** is an extension of the idea of [infinity](wikipedia://en/20110824) proposed by mathematician [Georg Cantor](wikipedia://en/12216). Cantor linked the absolute infinite with [God](https://en.wikipedia.org/wiki/God).[^o2][^o3][^o4] Some link the absolute infinite to various [mathematical](https://en.wikipedia.org/wiki/Mathematical) properties, including the [reflection principle](wikipedia://en/3225574): every property that can be ascribed to the absolute infinite is held by some smaller object.[^o5]

:::

## History {#History}

*Image: Georg\_Cantor\_(Porträt).jpg.* [Georg Cantor](wikipedia://en/12216)

During the 1870s1890s, German mathematician [Georg Cantor](wikipedia://en/12216) would publish a series of papers developing his theory of [cardinality](wikipedia://en/6174) (*Mächtigkeit*, magnitude) of [infinite sets](https://en.wikipedia.org/wiki/Infinite_sets). In his first paper, *[On a Property of the Collection of All Real Algebraic Numbers](https://en.wikipedia.org/wiki/On_a_Property_of_the_Collection_of_All_Real_Algebraic_Numbers)* (1874), he proved that it is impossible to put the [set](wikipedia://en/26691) of all [real numbers](https://en.wikipedia.org/wiki/Real_numbers) on the number line in one-to-one correspondence with the natural numbers, and therefore it must be a strictly larger set, despite the fact that both are infinite. Following this paper, in 1891, he published another paper introducing [his diagonal argument](wikipedia://en/51426)proving that there is an infinite hierarchy of infinitesand [cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_numbers)objects used to represent these possible infinite sizes. His diagonal argument, now called [Cantor's theorem](wikipedia://en/341442), stated that given any set, the [powerset](wikipedia://en/23799) (collection of all [subsets](https://en.wikipedia.org/wiki/Subsets)) must be strictly bigger than the original set. Cantor's proof showed that, given any [mapping](wikipedia://en/516931) from the original set to the powerset, one can always construct a new set which was not mapped to by taking the negation of the "diagonal" of the list, thus proving a one-to-one correspondence cannot exist.[^o7]

### Paradoxes {#Paradoxes}

When the diagonal argument is applied to the collection of all sets or [universe of sets](https://en.wikipedia.org/wiki/Universe_of_sets), by taking its powerset, one seemingly arrives at a paradox. If the powerset is indeed a set, then it is a subset of the universe of sets, and thus the [identity function](wikipedia://en/15069) from the universe to the powerset should be more than enough to cover it, and yet the diagonal argument can show that there is somehow one missing. This set had an interesting character as pointed out by [Bertrand Russell](wikipedia://en/4163) in 1901. The mechanism of Cantor's diagonal argument is taking the negation of the "diagonal" of these subsets $D$. For example, the diagonal argument on the mapping $f$ from natural numbers to its powerset says that if 1 is in the first subset of the list $f(1)$, then 1 is *not* in the subset $D$, and in general, for each natural number $n$, it is put in the subset $D$ only if the nth subset in the list $f(n)$ does not contain the number $n$. So this argument, applied to the universe with the identity mapping gives the set $R$: the collection of all sets that do not contain themselves. Then [Russell's paradox](wikipedia://en/46095) asks the question: "does $R$ contain itself?" If yes, then $R$ has the property of not containing itself (by the definition of $R$), and vice versa. Giving the contradiction that $R$ contains itself [if and only if](wikipedia://en/14922) it does not contain itself.[^o9]

In his Beiträge 1897,[^o10] Cantor published a result on the [ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_numbers). Informally, ordinals generalize the notion of *order* to infinite sets. For example, 2 comes after 1, denoted $1 < 2$, and 3 comes after both, denoted $1 < 2 < 3$. Then, one defines a new number, $\omega$, which comes after every natural number, denoted $1 < 2 < 3 < \cdots < \omega$. Further $\omega < \omega+1< \dots < \omega+\omega=\omega\cdot 2$, and so on. Specifically, ordinal numbers have the property that, for any set of ordinal numbers, there is always a unique *next* ordinal: [successor](wikipedia://en/375256) or [supremum](https://en.wikipedia.org/wiki/Supremum) (the [order type](wikipedia://en/4499021) of the set of all previous ordinals). For example, the set $\{ \omega, \omega\cdot 2, \omega\cdot 3 \cdots\}$ has the unique limit ordinal $\omega^2$; the set $\{ \omega, \omega^2, \omega^3 \cdots\}$ has the limit $\omega^\omega$, and the set of all countable ordinals has the limit $\omega_1$ (the [first uncountable ordinal](wikipedia://en/20860540)). Cantor's result showed that any collection of ordinal numbers can be [well-ordered](https://en.wikipedia.org/wiki/Well-ordered): the [usual notion of order](https://en.wikipedia.org/wiki/Partial_order), with the property that any subset of a well-ordered set has a least element. Also in 1897, [Cesare Burali-Forti](wikipedia://en/2452025) published a paper[^o11] on a property of [ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_numbers) which, unknown to him, contradicted Cantor's result that the ordinal numbers are not a [total order](wikipedia://en/30330)there are ordinal numbers such none of $a<b$, $a=b$, $a>b$ holda strictly weaker notion of order than Cantor's theorem, creating what is now called the [Burali-Forti paradox](wikipedia://en/51653). Burali-Forti showed that, when one considers the set of all ordinal numbers $\mathcal O$, by the definition of ordinal numbers, there must be a larger ordinal $\Omega$, and its successor $\Omega+1$. By definition of $\mathcal O$, both $\Omega$ and $\Omega+1$ must be a members of $\mathcal O$. However, since $\Omega$ was defined as the next largest ordinal in $\mathcal O$ it must be that $\Omega+1 \leq \Omega$, contradicting that $\Omega+1$ was a successor. However, it was not until 1903 when Bertrand Russell pointed out the contradiction and published it in his *[Principles of Mathematics](https://en.wikipedia.org/wiki/Principles_of_Mathematics)*[^o12] that it became known as a paradox.[^o13]

### Early reactions {#Early_reactions}

Cantor did not treat these paradoxes as genuine [antinomies](https://en.wikipedia.org/wiki/Antinomies), but rather [limitations of the language](https://en.wikipedia.org/wiki/Ineffability) used to describe these objects. In his Grundlagen 1883, prior to the discovery of any of these paradoxes, Cantor noticed these kinds of objects (universe of sets, collections of all cardinal or ordinal numbers) and considered them to be a strictly different kind of infinity than that of the cardinal and ordinal numbers. He conceived of two notions of "infinity": the [*transfinite*](wikipedia://en/189734)the class of infinity dealing with infinite cardinal numbers and ordinal numbersand the *absolute*the notion of infinity beyond psychological or mathematical comprehension, and the size of these kinds of objects:[^o15]

> "An essential difference, however, is that I fix the different degrees of the actual-infinite by the numbers \[$\aleph_0, \aleph_1, \aleph_2$\] etc. once and for all according to that concept and only then do I consider it a task to consider the relationships between them, not only to investigate the numbers mathematically, but also to determine them and record them wherever they occur in nature. There is no doubt for me that we will continue on this path, never reaching an insurmountable boundary, but also not reaching any sort of comprehension of the absolute. The absolute can only be recognized, but never known, not even approximately known." Georg Cantor, Grundlagen, 1883 (translated by James Meyer).[^o16]

Moreover, Cantor used the absolute as a tool in developing his theory of the transfinite. Later, writing to [David Hilbert](wikipedia://en/8302) and [Richard Dedekind](wikipedia://en/23475106) in 1897 and 1899 respectively, Cantor described a paradox similar to Burali-Forti, along with another paradox of cardinal numbers. Cantor showed how, for any set of cardinal numbers, there is always at least one cardinal missing: ordering the set of cardinal numbers, either the maximum cardinal (if there is one) has a powerset, which is strictly greater and thus not included; or if there is no maximum element, then the union of those cardinal numbers must be strictly greater. Thus, following the same reasoning as the Burali-Forti paradox, one could show the set **Hebr** of all cardinal numbers produces a similar paradox. In his 1899 letter to Dedekind, Cantor added a list of principles formalizing the notion of "set", which anticipated the axiomatic approach used later, and many of the axioms used, including informal precursors to the [axiom of specification](https://en.wikipedia.org/wiki/Axiom_of_specification) (any definable subset is a set), the [axiom of replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement) and [limitation of size](wikipedia://en/5322450) (if two collections are equinumerous, then either both are sets or both are inconsistent), and the [axiom of union](wikipedia://en/52553) (the union of sets is also a set). Cantor used these axioms in attempt to formalize his notion of the absolute infinite, and prove the [well-ordering theorem](wikipedia://en/33458): that every set has cardinality equivalent to some [aleph](wikipedia://en/293961). Essentially, the argument was, for any set $A$, one could iteratively map elements of the set of all ordinals $\Omega$ into $A$ until either all elements of $A$ had been mapped to and not all ordinals had been used, in which case $A$ is assigned an aleph; or that all elements of $\Omega$ had been used and $A$ has some subset equinumerous with $\Omega$ making the whole collection $A$ inconsistent, contradicting that it was a set.[^o17]

Hilbert, seeing the letter, could not accept that the set of all alephs is contradictory. Similar to Dedekind, Hilbert believed the fact that the concept of "aleph" being well-defined was enough for the collection of all alephs to be, making Cantor's proof a genuine contradiction. Over the next three years, by the 1900 Paris [International Congress of Mathematicians](wikipedia://en/627842), Hilbert grew to accept Cantor's view of the situation. Unlike Cantor, however, Hilbert did not accept that the way out was through [Platonistic](wikipedia://en/2845761) faith, but rather he believed the paradoxes were a symptom of the underdeveloped area of logic, and the solution was a more rigorous study of laws of logic in mathematics.[^o18] Cantor did not publish these paradoxes or the axiomatic definition of set from these letters, and the results would be rediscovered later by other mathematicians. Although Hilbert and some of his followers were prepared for the rediscovery of the paradoxes, the sequence of rediscovery of these paradoxes (along with other results) began an era now known as the [foundational crisis of mathematics](https://en.wikipedia.org/wiki/Foundational_crisis_of_mathematics). Russell rediscovered the paradox of set of all alephs in 1901, though he did not interpret it as a genuine paradox, it nevertheless began a period of serious distrust of Cantor's theorem. During this period, he engaged in more detailed analysis of the paradox, wherein he had begun to formulate the paradox that now bears his name. Between the years 1879 to 1903, logician and philosopher [Gottlob Frege](wikipedia://en/48416) had attempted to use Cantors notion cardinality to derive a foundation of arithmetic, ending only when Russell sent a letter to Frege describing his paradox. After initially trying to resolve the paradox, by his death in 1925, he believed his life's work, and set theory as a field to have been "destroyed" by it.[^o19]

### Axiomatic resolutions {#Axiomatic_resolutions}

[Ernst Zermelo](wikipedia://en/178655), a follower of Hilbert and Cantor, criticized Cantor's use of "time" in many arguments, such as in his proof of the well-ordering theorem, Cantor assumed he can sequentially "pick out" a new element of a set transfinitely many times. Zermelo's solution to this was a new axiom allowing one to "pick out" these elements all at once, now called the [Axiom of Choice](wikipedia://en/840). This was published later in his 1908 system of axioms, now called [Zermelo set theory](wikipedia://en/322623) (the first axiomatic set theory) where he attempted to prove the well-ordering theorem, while avoiding Russell's paradox. Zermelo's system would later be extended by [Abraham Fraenkel](wikipedia://en/528451) and [Thoralf Skolem](wikipedia://en/453765) in the 1920s to create the standard foundation of set theory, called [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC, "C" for the Axiom of Choice), the current [foundation of modern mathematics](wikipedia://en/169358). This system had an iterative approach, for example, asserting that if a given set X exists, then a set Y with specific properties also exists, excluding definitions like "the set of all objects such that..." as [primitives](wikipedia://en/23706). As a theorem, it proved that Cantor's absolute infinite collections causing the paradoxes did not exist (more specifically, that they were not sets).[^o21]

A guiding [heuristic](https://en.wikipedia.org/wiki/Heuristic) at the time to determine what kinds of axioms were admissible was [limitation of size](wikipedia://en/4190174), which claimed that the cause of set theoretic paradoxes were set theories allowing collections "too large" to be "sets", and disallowing axiomssuch as [unrestricted comprehension](https://en.wikipedia.org/wiki/Unrestricted_comprehension)that allowed the creation of these sets. Taking inspiration from Zermelo's 1908 axiom system, in 1923, [John von Neumann](wikipedia://en/15942) introduced a new system of axioms which was capable of including these "too big" sets as part of the theory, though separated them ontologically. He disallowed these "too big" collections to be elements of other collections. He later distinguished them as "sets" \[Mengen\] and "domains" \[Bereiche\]; the latter now commonly called "classes", resolving issues of [self-reference](wikipedia://en/28545) caused by, for example, allowing the collection of all sets to be a set, or the collection of all ordinal numbers to be an ordinal. Von Neumann's intuition of sets was heavily influenced by the limitation of size doctrine of the time, which he incorporated in to his system as the [axiom of limitation of size](wikipedia://en/5322450) (LoS): that a domain (class or collection) was "too big" if and only if it was equinumerous to the whole domain of all sets. By his own admission, this was a very effective axiom, implying many of Zermelo's original axiom, which he saw as a good reason to be suspicious of the axiom. So in 1928, he published a paper proving the axiom from a simpler system of axioms. This system was later refined by [Paul Bernays](wikipedia://en/2556580) and [Kurt Gödel](wikipedia://en/16736) between the 1930s to 1950s to create the system now called [von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) (NBG). This system was shown to be a [conservative extension](wikipedia://en/1840214) of ZFC, meaning any statement about sets that could be proven in NBG could also be proven in ZFC, and the implementation of classes in NBG is generally considered to capture Cantor's original notion of the absolute infinite.[^o22]

## Cantor's view {#Cantor's_view}

Cantor said:

The actual infinite was distinguished by three relations: first, as it is realized in the supreme [perfection](https://en.wikipedia.org/wiki/Perfection), in the completely independent, extra worldly existence, in Deo, where I call it absolute infinite or simply absolute; second to the extent that it is represented in the dependent, creatural world; third as it can be conceived in abstracto in thought as a mathematical magnitude, number or order type. In the latter two relations, where it obviously reveals itself as limited and capable for further proliferation and hence familiar to the finite, I call it *[Transfinitum](wikipedia://en/189734)* and strongly contrast it with the absolute.

While using the [Latin](https://en.wikipedia.org/wiki/Latin_language) expression *in Deo* (in God), Cantor identifies [absolute](https://en.wikipedia.org/wiki/Absolute_%28philosophy%29) infinity with [God](https://en.wikipedia.org/wiki/God) (GA 175–176, 376, 378, 386, 399). According to Cantor, Absolute Infinity is beyond [mathematical comprehension](https://en.wikipedia.org/wiki/Transcendence_%28philosophy%29) and shall be interpreted in terms of [negative theology](https://en.wikipedia.org/wiki/Negative_theology).[^o24]

Cantor also mentioned the idea in his letters to [Richard Dedekind](wikipedia://en/23475106) (text in square brackets not present in original):

A multiplicity \[he appears to mean what we now call a [set](wikipedia://en/26691)\] is called [well-ordered](https://en.wikipedia.org/wiki/Well-ordered) if it fulfills the condition that every sub-multiplicity has a first [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29); such a multiplicity I call for short a "sequence". ... Now I envisage the system of all \[ordinal\] numbers and denote it *Ω*. ... The system *Ω* in its natural ordering according to magnitude is a "sequence". Now let us adjoin 0 as an additional element to this sequence, and place it, obviously, in the first position; then we obtain a sequence *Ω*: 0, 1, 2, 3, ... ω<sub>0</sub>, ω<sub>0</sub>+1, ..., γ, ...

of which one can readily convince oneself that every number γ occurring in it is the type \[i.e., order-type\] of the sequence of all its preceding elements (including 0). (The sequence *Ω* has this property first for ω<sub>0</sub>+1. \[ω<sub>0</sub>+1 should be ω<sub>0</sub>.\])

Now *Ω* (and therefore also *Ω*) cannot be a consistent multiplicity. For if *Ω* were consistent, then as a well-ordered set, a number *δ* would correspond to it which would be greater than all numbers of the system *Ω*; the number *δ*, however, also belongs to the system *Ω*, because it comprises all numbers. Thus *δ* would be greater than *δ*, which is a contradiction. Therefore:

*The system Ω of all \[ordinal\] numbers is an inconsistent, absolutely infinite multiplicity.*

## The Burali-Forti paradox {#The_Burali-Forti_paradox}

The idea that the collection of all ordinal numbers cannot logically exist seems [paradoxical](https://en.wikipedia.org/wiki/Paradoxical) to many. This is related to the Burali-Forti's paradox which implies that there can be no greatest [ordinal number](wikipedia://en/26547932). All of these problems can be traced back to the idea that, for every property that can be logically defined, there exists a set of all objects that have that property. However, as in Cantor's argument (above), this idea leads to difficulties.

More generally, as noted by [A. W. Moore](https://en.wikipedia.org/wiki/A._W._Moore_%28philosopher%29), there can be no end to the process of set formation, and thus no such thing as the *totality of all sets*, or the *set hierarchy*. Any such totality would itself have to be a set, thus lying somewhere within the [hierarchy](wikipedia://en/7393195) and thus failing to contain every set.

A standard solution to this problem is found in [Zermelo set theory](wikipedia://en/322623), which does not allow the unrestricted formation of sets from arbitrary properties. Rather, we may form the set of all objects that have a given property *and lie in some given set* (Zermelo's [axiom of separation](wikipedia://en/52386)). This allows for the formation of sets based on properties, in a limited sense, while (hopefully) preserving the consistency of the theory.

While this solves the logical problem, one could argue that the philosophical problem remains. It seems natural that a set of individuals ought to exist, so long as the individuals exist. Indeed, [naive set theory](wikipedia://en/4944) might be said to be based on this notion. Although Zermelo's fix allows a [class](wikipedia://en/20696) to describe arbitrary (possibly "large") entities, these predicates of the [metalanguage](wikipedia://en/402929) may have no formal existence (i.e., as a set) within the theory. For example, the class of all sets would be a [proper class](https://en.wikipedia.org/wiki/Proper_class). This is philosophically unsatisfying to some and has motivated additional work in [set theory](wikipedia://en/27553) and other methods of formalizing the foundations of mathematics such as [New Foundations](wikipedia://en/945957#How_NF.28U.29_avoids_the_set-theoretic_paradoxes) by [Willard Van Orman Quine](wikipedia://en/33833).
