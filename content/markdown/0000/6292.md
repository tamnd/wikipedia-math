# Convex set

*Image: Convex polygon illustration1.svg.* Illustration of a convex set shaped like a deformed circle. The line segment joining points *x* and *y* lies completely within the set, illustrated in green. Since this is true for any potential locations of two points within the set, the set is convex.

*Image: Convex polygon illustration2.svg.* Illustration of a non-convex set. The line segment joining points *x* and *y* partially extends outside of the set, illustrated in red, and the intersection of the set with the line occurs in two places, illustrated in black.

::: {#o1 .subject cue=lead name="Convex set"}

In [geometry](wikipedia://en/18973446), a [set of points](https://en.wikipedia.org/wiki/Point_set) is **convex** if it contains every [line segment](wikipedia://en/22634860) between two points in the set.[^o2][^o3] For example, a solid [cube](https://en.wikipedia.org/wiki/Cube_%28geometry%29) is a convex set, but anything that is hollow or has an indent, such as a [crescent](https://en.wikipedia.org/wiki/Crescent) shape, is not convex.

:::

The [boundary](wikipedia://en/72824) of a convex set in the plane is always a [convex curve](wikipedia://en/29747989). The intersection of all the convex sets that contain a given subset $A$ of Euclidean space is called the [convex hull](wikipedia://en/40634) of $A$. It is the smallest convex set containing $A$.

A [convex function](wikipedia://en/245568) is a [real-valued function](wikipedia://en/22284647) defined on an [interval](wikipedia://en/49172) with the property that its [epigraph](wikipedia://en/5744061) (the set of points on or above the [graph](wikipedia://en/87352) of the function) is a convex set. [Convex minimization](https://en.wikipedia.org/wiki/Convex_minimization) is a subfield of [optimization](wikipedia://en/52033) that studies the problem of minimizing convex functions over convex sets. The branch of mathematics devoted to the study of properties of convex sets and convex functions is called [convex analysis](wikipedia://en/3237201).

Spaces in which convex sets are defined include the [Euclidean spaces](wikipedia://en/9697), the [affine spaces](wikipedia://en/298834) over the [real numbers](wikipedia://en/20646438), and certain [non-Euclidean geometries](wikipedia://en/58610).

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

*Image: Convex supergraph.svg.* A [function](wikipedia://en/245568) is convex if and only if its [epigraph](wikipedia://en/5744061), the region (in green) above its [graph](wikipedia://en/87352) (in blue), is a convex set.

Let $S$ be a [vector space](wikipedia://en/32370) or an [affine space](wikipedia://en/298834) over the [real numbers](wikipedia://en/20646438), or, more generally, over some [ordered field](wikipedia://en/22430) (this includes Euclidean spaces, which are affine spaces). A [subset](wikipedia://en/27631) $C$ of $S$ is convex if, for all $x$ and $y$ in $C$, the [line segment](wikipedia://en/22634860) connecting $x$ and $y$ is included in $C$.

This means that the [affine combination](wikipedia://en/298835) $(1 - t)x + ty$ belongs to $C$ for all $x,y$ in $C$ and $t$ in the [interval](wikipedia://en/49172) $[0, 1]$. This implies that convexity is invariant under [affine transformations](wikipedia://en/38449).[^o6] Further, it implies that a convex set in a [real](wikipedia://en/20646438) or [complex](wikipedia://en/5826) [topological vector space](wikipedia://en/45752) is [path-connected](https://en.wikipedia.org/wiki/Path-connected) (and therefore also [connected](wikipedia://en/6233)).

A set $C$ is **strictly convex** if for every $x$ and $y$ in $C$, every point on the line segment connecting $x$ and $y$ other than the endpoints is inside the [topological interior](wikipedia://en/55610) of $C$. A closed convex subset is strictly convex if and only if every one of its [boundary points](wikipedia://en/72824) is an [extreme point](wikipedia://en/454968).

A set $C$ is [absolutely convex](https://en.wikipedia.org/wiki/Absolutely_convex) if it is convex and [balanced](wikipedia://en/1734238).

::: {#o9 .example cue=heading name="Examples"}

### Examples {#Examples}

The convex [subsets](wikipedia://en/27631) of $\mathbf{R}$ (the set of real numbers) are the intervals and the points of $\mathbf{R}$. Some examples of convex subsets of the [Euclidean plane](wikipedia://en/15575410) are solid [regular polygons](wikipedia://en/333306), solid triangles, and intersections of solid triangles. Some examples of convex subsets of a [Euclidean 3-dimensional space](wikipedia://en/9697) are the [Archimedean solids](wikipedia://en/1847) and the [Platonic solids](wikipedia://en/23905). The [Kepler–Poinsot polyhedra](wikipedia://en/16814) are examples of non-convex sets.

:::

::: {#o11 .pointer-item cue=pointer name="Concave set"}

### Non-convex set {#Non-convex_set}

A set that is not convex is called a *non-convex set*. A [polygon](wikipedia://en/23621) that is not a [convex polygon](wikipedia://en/660019) is sometimes called a [concave polygon](wikipedia://en/605156),[^o12] and some sources more generally use the term *concave set* to mean a non-convex set, but most authorities prohibit this usage.[^o14][^o15]

The [complement](wikipedia://en/54347) of a convex set, such as the [epigraph](wikipedia://en/5744061) of a [concave function](wikipedia://en/263321), is sometimes called a *reverse convex set*, especially in the context of [mathematical optimization](wikipedia://en/52033).[^o16]

## Properties {#Properties}

Given $r$ points $u_{1}, ..., u_{r}$ in a convex set $S$, and $r$ [nonnegative numbers](wikipedia://en/154616) $\lambda_{1}, ..., \lambda_{r}$ such that $\lambda_{1} + ... + \lambda_{r} = 1$, the [affine combination](wikipedia://en/298835)

$$\sum_{k=1}^r\lambda_k u_k$$

belongs to $S$. As the definition of a convex set is the case $r = 2$, this property characterizes convex sets.

Such an affine combination is called a [convex combination](wikipedia://en/794534) of $u_{1}, ..., u_{r}$. The **convex hull** of a subset $S$ of a real vector space is defined as the intersection of all convex sets that contain $S$. More concretely, the convex hull is the set of all convex combinations of points in $S$. In particular, this is a convex set.

A *(bounded) [convex polytope](wikipedia://en/1817885)* is the convex hull of a finite subset of some Euclidean space $\mathbf{R}^{n}$.

### Intersections and unions {#Intersections_and_unions}

The collection of convex subsets of a vector space, an affine space, or a [Euclidean space](wikipedia://en/9697) has the following properties:[^o20][^o21]

1. The [empty set](wikipedia://en/9566) and the whole space are convex.
1. The intersection of any collection of convex sets is convex.
1. The *[union](https://en.wikipedia.org/wiki/Union_%28sets%29)* of a collection of convex sets is convex if those sets form a [chain](wikipedia://en/30330#Chains) (a totally ordered set) under inclusion. For this property, the restriction to chains is important, as the union of two convex sets need not be convex.

### Closed convex sets {#Closed_convex_sets}

[Closed](wikipedia://en/47279) convex sets are convex sets that contain all their [limit points](https://en.wikipedia.org/wiki/Limit_points). They can be characterised as the intersections of *closed [half-spaces](wikipedia://en/647297)* (sets of points in space that lie on and to one side of a [hyperplane](wikipedia://en/99862)).

From what has just been said, it is clear that such intersections are convex, and they will also be closed sets. To prove the converse, i.e., every closed convex set may be represented as such intersection, one needs the [supporting hyperplane theorem](https://en.wikipedia.org/wiki/Supporting_hyperplane_theorem) in the form that for a given closed convex set $C$ and point $P$ outside it, there is a closed half-space $H$ that contains $C$ and not $P$. The supporting hyperplane theorem is a special case of the [Hahn–Banach theorem](wikipedia://en/13860) of [functional analysis](wikipedia://en/11180).

### Face of a convex set {#Face_of_a_convex_set}

A **face** of a convex set $C$ is a convex subset $F$ of $C$ such that whenever a point $p$ in $F$ lies strictly between two points $x$ and $y$ in $C$, both $x$ and $y$ must be in $F$.[^n1] Equivalently, for any $x,y\in C$ and any real number $0<t<1$ such that $(1-t)x+ty$ is in $F$, $x$ and $y$ must be in $F$. According to this definition, $C$ itself and the empty set are faces of $C$; these are sometimes called the *trivial faces* of $C$. An **[extreme point](wikipedia://en/454968)** of $C$ is a point that is a face of $C$.

Let $C$ be a convex set in $\mathbb{R}^n$ that is [compact](wikipedia://en/6042) (or equivalently, closed and [bounded](wikipedia://en/48258)). Then $C$ is the convex hull of its extreme points.[^n2] More generally, each compact convex set in a [locally convex topological vector space](wikipedia://en/518844) is the closed convex hull of its extreme points (the [Krein–Milman theorem](wikipedia://en/3206654)).

For example:

- A [triangle](wikipedia://en/30654) in the plane (including the region inside) is a compact convex set. Its nontrivial faces are the three vertices and the three edges. (So the only extreme points are the three vertices.)
- The only nontrivial faces of the [closed unit disk](https://en.wikipedia.org/wiki/Closed_unit_disk) $\{ (x,y) \in \mathbb{R}^2: x^2+y^2 \leq 1 \}$ are its extreme points, namely the points on the [unit circle](wikipedia://en/27072071) $S^1 = \{ (x,y) \in \mathbb{R}^2: x^2+y^2=1 \}$.

### Convex sets and rectangles {#Convex_sets_and_rectangles}

Let $C$ be a [convex body](wikipedia://en/8652020) in the plane (a convex set whose interior is non-empty). We can inscribe a rectangle *r* in $C$ such that a [homothetic](https://en.wikipedia.org/wiki/Homothetic_transformation) copy *R* of *r* is circumscribed about $C$. The positive homothety ratio is at most 2 and:[^o27]

$$\tfrac{1}{2} \cdot\operatorname{Area}(R) \leq \operatorname{Area}(C) \leq 2\cdot \operatorname{Area}(r)$$

### Blaschke-Santaló diagrams {#Blaschke-Santaló_diagrams}

The set $\mathcal{K}^2$ of all planar convex bodies can be parameterized in terms of the convex body [diameter](wikipedia://en/68283333) *D*, its inradius *r* (the biggest circle contained in the convex body) and its circumradius *R* (the smallest circle containing the convex body). In fact, this set can be described by the set of inequalities given by[^o29][^o30]

$$2r \le D \le 2R$$

$$R \le \frac{\sqrt{3}}{3} D$$

$$r + R \le D$$

$$D^2 \sqrt{4R^2-D^2} \le 2R (2R + \sqrt{4R^2 -D^2})$$

and can be visualized as the image of the function *g* that maps a convex body to the $\mathbf{R}^{2}$ point given by (*r*/*R*, *D*/2*R*). The image of this function is known a (*r*, *D*, *R*) Blachke-Santaló diagram.[^o30]

*Image: Blaschke-Santaló\_diagram\_for\_planar\_convex\_bodies.pdf.* Blaschke-Santaló (*r*, *D*, *R*) diagram for planar convex bodies. $\mathbb{L}$ denotes the line segment, $\mathbb{I}_{\frac{\pi}{3}}$ the equilateral triangle, $\mathbb{RT}$ the [Reuleaux triangle](wikipedia://en/580252) and $\mathbb{B}_2$ the unit circle.

Alternatively, the set $\mathcal{K}^2$ can also be parametrized by its width (the smallest distance between any two different parallel support hyperplanes), perimeter and area.[^o29][^o30]

### Other properties {#Other_properties}

Let *X* be a topological vector space and $C \subseteq X$ be convex.

- $\operatorname{Cl} C$ and $\operatorname{Int} C$ are both convex (i.e. the closure and interior of convex sets are convex).
- If $a \in \operatorname{Int} C$ and $b \in \operatorname{Cl} C$ then $[a, b[ \, \subseteq \operatorname{Int} C$ (where $[a, b[ \, := \left\{ (1 - r) a + r b : 0 \leq r < 1 \right\}$).
- If $\operatorname{Int} C \neq \emptyset$ then:
  - $\operatorname{cl} \left( \operatorname{Int} C \right) = \operatorname{Cl} C$, and
  - $\operatorname{Int} C = \operatorname{Int} \left( \operatorname{Cl} C \right) = C^i$, where $C^{i}$ is the [algebraic interior](wikipedia://en/30823252) of *C*.

:::

## Convex hulls and Minkowski sums {#Convex_hulls_and_Minkowski_sums}

### Convex hulls {#Convex_hulls}

Every subset $A$ of the vector space is contained within a smallest convex set (called the *convex hull* of $A$), namely the intersection of all convex sets containing $A$. The convex-hull operator Conv() has the characteristic properties of a [closure operator](wikipedia://en/483120):

- *extensive*: $S \subseteq \operatorname{Conv}(S)$,
- *[non-decreasing](https://en.wikipedia.org/wiki/Monotone_function#Monotonicity_in_order_theory)*: $S \subseteq T$ implies that $\operatorname{Conv}(S) \subseteq \operatorname{Conv}(T)$, and
- *[idempotent](wikipedia://en/14972)*: $\operatorname{Conv}(\operatorname{Conv}(S)) = \operatorname{Conv}(S)$.

The convex-hull operation is needed for the set of convex sets to form a [lattice](wikipedia://en/469304), in which the ["*join*" operation](wikipedia://en/3956618) is the convex hull of the union of two convex sets

$$\operatorname{Conv}(S)\vee\operatorname{Conv}(T) = \operatorname{Conv}(S\cup T) = \operatorname{Conv}\bigl(\operatorname{Conv}(S)\cup\operatorname{Conv}(T)\bigr).$$

The intersection of any collection of convex sets is itself convex, so the convex subsets of a (real or complex) vector space form a complete [lattice](wikipedia://en/469304).

### Minkowski addition {#Minkowski_addition}

*Image: Minkowski sum graph - vector version.svg.* [Minkowski addition](wikipedia://en/504105) of sets. The [sum](https://en.wikipedia.org/wiki/Sumset) of the squares Q<sub>1</sub>=\[0,1\]<sup>2</sup> and Q<sub>2</sub>=\[1,2\]<sup>2</sup> is the square Q<sub>1</sub>+Q<sub>2</sub>=\[1,3\]<sup>2</sup>.

In a real vector-space, the *[Minkowski sum](wikipedia://en/504105)* of two (non-empty) sets, $S_{1}$ and $S_{2}$, is defined to be the [set](https://en.wikipedia.org/wiki/Sumset) $S_{1} + S_{2}$ formed by the addition of vectors element-wise from the summand-sets

$$S_1+S_2=\{x_1+x_2: x_1\in S_1, x_2\in S_2\}.$$

More generally, the *Minkowski sum* of a finite family of (non-empty) sets $S_{n}$ is the set formed by element-wise addition of vectors

$$\sum_n S_n = \left \{ \sum_n x_n : x_n \in S_n \right \}.$$

For Minkowski addition, the *zero set* $\{0\}$ containing only the [zero vector](wikipedia://en/1453977) $0$ has [special importance](wikipedia://en/14962): For every non-empty subset S of a vector space

$$S+\{0\}=S;$$

in algebraic terminology, $\{0\}$ is the [identity element](wikipedia://en/14962) of Minkowski addition (on the collection of non-empty sets).[^o35]

### Convex hulls of Minkowski sums {#Convex_hulls_of_Minkowski_sums}

Minkowski addition behaves well with respect to the operation of taking convex hulls, as shown by the following proposition:

Let $S_{1}, S_{2}$ be subsets of a real vector-space, the [convex hull](wikipedia://en/40634) of their Minkowski sum is the Minkowski sum of their convex hulls

$$\operatorname{Conv}(S_1+S_2)=\operatorname{Conv}(S_1)+\operatorname{Conv}(S_2).$$

This result holds more generally for each finite collection of non-empty sets:

$$\text{Conv}\left ( \sum_n S_n \right ) = \sum_n \text{Conv} \left (S_n \right).$$

In mathematical terminology, the [operations](wikipedia://en/4140245) of Minkowski summation and of forming [convex hulls](wikipedia://en/40634) are [commuting](https://en.wikipedia.org/wiki/Commutativity) operations.[^o37][^o38]

### Minkowski sums of convex sets {#Minkowski_sums_of_convex_sets}

The Minkowski sum of two compact convex sets is compact. The sum of a compact convex set and a closed convex set is closed.[^o40]

The following famous theorem, proved by Dieudonné in 1966, gives a sufficient condition for the difference of two closed convex subsets to be closed.[^o41] It uses the concept of a **recession cone** of a non-empty convex subset *S*, defined as:

$$\operatorname{rec} S = \left\{ x \in X \, : \, x + S \subseteq S \right\},$$

where this set is a [convex cone](wikipedia://en/3558266) containing $0 \in X$ and satisfying $S + \operatorname{rec} S = S$. Note that if *S* is closed and convex then $\operatorname{rec} S$ is closed and for all $s_0 \in S$,

$$\operatorname{rec} S = \bigcap_{t > 0} t (S - s_0).$$

::: {#o42 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** (Dieudonné). Let *A* and *B* be non-empty, closed, and convex subsets of a [locally convex topological vector space](wikipedia://en/518844) such that $\operatorname{rec} A \cap \operatorname{rec} B$ is a linear subspace. If *A* or *B* is [locally compact](https://en.wikipedia.org/wiki/Locally_compact) then *A* − *B* is closed.

:::

## Generalizations and extensions for convexity {#Generalizations_and_extensions_for_convexity}

The notion of convexity in the Euclidean space may be generalized by modifying the definition in some or other aspects. The common name "generalized convexity" is used, because the resulting objects retain certain properties of convex sets.

### Star-convex (star-shaped) sets {#Star-convex_(star-shaped)_sets}

Let $C$ be a set in a real or complex vector space. $C$ is **star convex (star-shaped)** if there exists an $x_{0}$ in $C$ such that the line segment from $x_{0}$ to any point $y$ in $C$ is contained in $C$. Hence a non-empty convex set is always star-convex but a star-convex set is not always convex.

### Orthogonal convexity {#Orthogonal_convexity}

An example of generalized convexity is **orthogonal convexity**.[^o46]

A set $S$ in the Euclidean space is called **orthogonally convex** or **ortho-convex**, if any segment parallel to any of the coordinate axes connecting two points of $S$ lies totally within $S$. It is easy to prove that an intersection of any collection of orthoconvex sets is orthoconvex. Some other properties of convex sets are valid as well.

### Non-Euclidean geometry {#Non-Euclidean_geometry}

The definition of a convex set and a convex hull extends naturally to geometries which are not Euclidean by defining a [geodesically convex set](wikipedia://en/12677098) to be one that contains the [geodesics](wikipedia://en/91096) joining any two points in the set.

### Order topology {#Order_topology}

Convexity can be extended for a [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set) $X$ endowed with the [order topology](wikipedia://en/213650).[^o49]

Let $Y \subseteq X$. The subspace $Y$ is a convex set if for each pair of points $a, b$ in $Y$ such that $a \le b$, the interval $[a, b] = \{x \in X | a \le x \le b\}$ is contained in $Y$. That is, $Y$ is convex if and only if for all $a, b$ in $Y$, $a \le b$ implies $[a, b] \subseteq Y$.

A convex set is not connected in general: a counter-example is given by the subspace {1,2,3} in $\mathbf{Z}$, which is both convex and not connected.

::: {#o51 .pointer-item cue=pointer name="Convexity space"}

### Convexity spaces {#Convexity_spaces}

The notion of convexity may be generalised to other objects, if certain properties of convexity are selected as [axioms](wikipedia://en/928).

Given a set $X$, a **convexity** over $X$ is a collection $\text{𝒞}$ of subsets of $X$ satisfying the following axioms:[^o20][^o21][^o52]

1. The empty set and $X$ are in $\text{𝒞}$.
1. The intersection of any collection from $\text{𝒞}$ is in $\text{𝒞}$.
1. The union of a [chain](wikipedia://en/30330) (with respect to the [inclusion relation](https://en.wikipedia.org/wiki/Inclusion_relation)) of elements of $\text{𝒞}$ is in $\text{𝒞}$.

The elements of $\text{𝒞}$ are called convex sets and the pair $(X, \text{𝒞})$ is called a **convexity space**. For the ordinary convexity, the first two axioms hold, and the third one is trivial.

For an alternative definition of abstract convexity, more suited to [discrete geometry](wikipedia://en/386468), see the *convex geometries* associated with [antimatroids](wikipedia://en/667063).

:::

### Convex spaces {#Convex_spaces}

Convexity can be generalised as an abstract algebraic structure: a space is convex if it is possible to take convex combinations of points.
