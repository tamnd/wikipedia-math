# Equivalence relation

*Image: Set partitions 5; matrices.svg.* The [52](wikipedia://en/201022) equivalence relations on a 5-element set depicted as $5 \times 5$ [logical matrices](wikipedia://en/4109196) (colored fields, including those in light gray, stand for ones; white fields for zeros). The row and column indices of nonwhite cells are the related elements, while the different colors, other than light gray, indicate the equivalence classes (each light gray cell is its own equivalence class).

::: {#o1 .subject cue=lead name="Equivalence relation"}

In [mathematics](wikipedia://en/18831), an **equivalence relation** is a [binary relation](wikipedia://en/3931) that is [reflexive](wikipedia://en/200458), [symmetric](wikipedia://en/200459), and [transitive](wikipedia://en/200463). The [equipollence](wikipedia://en/24022514) relation between line segments in geometry is a common example of an equivalence relation. A simpler example is numerical equality. Any number $a$ is equal to itself (reflexive). If $a = b$, then $b = a$ (symmetric). If $a = b$ and $b = c$, then $a = c$ (transitive).

:::

Each equivalence relation provides a [partition](wikipedia://en/340240) of the underlying set into disjoint [equivalence classes](wikipedia://en/9260). Two elements of the given set are equivalent to each other [if and only if](wikipedia://en/14922) they belong to the same equivalence class.

::: {#o3 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

Various notations are used in the literature to denote that two elements $a$ and $b$ of a set are equivalent with respect to an equivalence relation $R;$ the most common are "$a \sim b$" and "$a \equiv b$", which are used when $R$ is implicit, and variations of "$a \sim_R b$", "$a \equiv_R b$", or "${a\mathop{R}b}$" to specify $R$ explicitly. Non-equivalence may be written "$a \not\sim b$" or "$a \not\equiv b$".

:::

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A [binary relation](wikipedia://en/3931) $\,\sim\,$ on a set $X$ is said to be an equivalence relation if it is reflexive, symmetric and transitive. That is, for all $a, b,$ and $c$ in $X:$

- $a \sim a$ ([reflexivity](wikipedia://en/200458)).
- $a \sim b$ if and only if $b \sim a$ ([symmetry](wikipedia://en/200459)).
- If $a \sim b$ and $b \sim c$ then $a \sim c$ ([transitivity](wikipedia://en/200463)).

$X$ together with the relation $\,\sim\,$ is called a [setoid](wikipedia://en/769434). The [equivalence class](wikipedia://en/9259#Equivalence_class) of $a$ under $\,\sim,$ denoted $[a],$ is defined as $[a] = \{x \in X : x \sim a\}.$[^o6][^o7]

### Alternative definition using relational algebra {#Alternative_definition_using_relational_algebra}

In [relational algebra](wikipedia://en/175285), if $R\subseteq X\times Y$ and $S\subseteq Y\times Z$ are relations, then the [composite relation](wikipedia://en/7472170) $SR\subseteq X\times Z$ is defined so that $x \, SR \, z$ if and only if there is a $y\in Y$ such that $x \, R \, y$ and $y \, S \, z$.[^o9] This definition is a generalisation of the definition of [functional composition](wikipedia://en/195947). The defining properties of an equivalence relation $R$ on a set $X$ can then be reformulated as follows:

- $\operatorname{id} \subseteq R$. ([reflexivity](wikipedia://en/200458)). (Here, $\operatorname{id}$ denotes the [identity function](wikipedia://en/15069) on $X$.)
- $R=R^{-1}$ ([symmetry](wikipedia://en/200459)).
- $RR\subseteq R$ ([transitivity](wikipedia://en/200463)).[^o10]

:::

## Examples {#Examples}

::: {#o14 .example cue=heading name="Simple example"}

### Simple example {#Simple_example}

On the set $X = \{a, b, c\}$, the relation $R = \{(a, a), (b, b), (c, c), (b, c), (c, b)\}$ is an equivalence relation. The following sets are equivalence classes of this relation:

$$[a] = \{a\}, ~~~~ [b] = [c] = \{b, c\}.$$

The set of all equivalence classes for $R$ is $\{\{a\}, \{b, c\}\}.$ This set is a [partition](wikipedia://en/340240) of the set $X$. It is also called the [quotient set](wikipedia://en/9259#Quotient_set) of $X$ by $R$.

:::

### Equivalence relations {#Equivalence_relations}

The following relations are all equivalence relations:

- "Is equal to" on the set of numbers. For example, $\tfrac{1}{2}$ is equal to $\tfrac{4}{8}.$[^o7]
- "Is [similar](wikipedia://en/39377) to" on the set of all [triangles](https://en.wikipedia.org/wiki/Triangle_%28geometry%29).
- "Is [congruent](wikipedia://en/39330) to" on the set of all [triangles](https://en.wikipedia.org/wiki/Triangle_%28geometry%29).
- Given a [function](wikipedia://en/185427) $f:X \to Y$, "has the same [image](wikipedia://en/579311) under $f$ as" on the elements of $f$'s [domain](wikipedia://en/50263) $X$. For example, $0$ and $\pi$ have the same image under $\sin$, viz. $0$. In particular:
  - "Has the same absolute value as" on the set of real numbers
  - "Has the same cosine as" on the set of all angles.
  - Given a natural number $n$, "is congruent to, [modulo](wikipedia://en/20087) $n$" on the [integers](https://en.wikipedia.org/wiki/Integers).[^o7]
  - "Have the same length and direction" ([equipollence](wikipedia://en/24022514)) on the set of [directed line segments](https://en.wikipedia.org/wiki/Directed_line_segment).[^o16]
  - "Has the same birthday as" on the set of all people.

### Relations that are not equivalences {#Relations_that_are_not_equivalences}

- The relation "≥" between real numbers is reflexive and transitive, but not symmetric. For example, 7 ≥ 5 but not 5 ≥ 7.
- The relation "has a [common factor](https://en.wikipedia.org/wiki/Common_factor) greater than 1 with" between [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) greater than 1, is reflexive and symmetric, but not transitive. For example, the natural numbers 2 and 6 have a common factor greater than 1, and 6 and 3 have a common factor greater than 1, but 2 and 3 do not have a common factor greater than 1.
- The [empty relation](https://en.wikipedia.org/wiki/Empty_relation) *R* (defined so that *aRb* is never true) on a set *X* is [vacuously](https://en.wikipedia.org/wiki/Vacuously_true) symmetric and transitive; however, it is not reflexive (unless *X* itself is empty).
- The relation "is approximately equal to" between real numbers, even if more precisely defined, is not an equivalence relation, because although reflexive and symmetric, it is not transitive, since multiple small changes can accumulate to become a big change. However, if the approximation is defined asymptotically, for example by saying that two functions *f* and *g* are approximately equal near some point if the limit of *f − g* is 0 at that point, then this defines an equivalence relation.

:::

## Connections to other relations {#Connections_to_other_relations}

- A [partial order](https://en.wikipedia.org/wiki/Partial_order) is a relation that is reflexive, [antisymmetric](wikipedia://en/1176), and transitive.
- [Equality](wikipedia://en/90446) is both an equivalence relation and a partial order. Equality is also the only relation on a set that is reflexive, symmetric and antisymmetric. In [algebraic expressions](wikipedia://en/4283745), equal variables may be [substituted](https://en.wikipedia.org/wiki/Substitution_%28algebra%29) for one another, a facility that is not available for equivalence related variables. The equivalence classes of an equivalence relation can substitute for one another, but not individuals within a class.
- A [strict partial order](https://en.wikipedia.org/wiki/Strict_partial_order) is irreflexive, transitive, and [asymmetric](wikipedia://en/1229368).
- A [partial equivalence relation](wikipedia://en/3450320) is transitive and symmetric. Such a relation is reflexive [if and only if](wikipedia://en/14922) it is [total](wikipedia://en/1482218), that is, if for all $a,$ there exists some $b \text{ such that } a \sim b.$[^o19] Therefore, an equivalence relation may be alternatively defined as a symmetric, transitive, and total relation.
- A [ternary equivalence relation](wikipedia://en/47274958) is a ternary analogue to the usual (binary) equivalence relation.
- A reflexive and symmetric relation is a [dependency relation](wikipedia://en/10739341) (if finite), and a [tolerance relation](wikipedia://en/26014321) if infinite.
- A [preorder](wikipedia://en/23582) is reflexive and transitive.
- A [congruence relation](wikipedia://en/48167) is an equivalence relation whose domain $X$ is also the underlying set for an [algebraic structure](wikipedia://en/106364), and which respects the additional structure. In general, congruence relations play the role of [kernels](wikipedia://en/45240) of homomorphisms, and the quotient of a structure by a congruence relation can be formed. In many important cases, congruence relations have an alternative representation as substructures of the structure on which they are defined (e.g., the congruence relations on groups correspond to the [normal subgroups](wikipedia://en/21918)).
- Any equivalence relation is the negation of an [apartness relation](wikipedia://en/7844336), though the converse statement only holds in classical mathematics (as opposed to [constructive mathematics](https://en.wikipedia.org/wiki/Constructive_mathematics)), since it is equivalent to the [law of excluded middle](wikipedia://en/17637).
- Each relation that is both reflexive and left (or right) [Euclidean](wikipedia://en/11613832) is also an equivalence relation.

## Well-definedness under an equivalence relation {#Well-definedness_under_an_equivalence_relation}

If $\,\sim\,$ is an equivalence relation on $X,$ and $P(x)$ is a property of elements of $X,$ such that whenever $x \sim y,$ $P(x)$ is true if $P(y)$ is true, then the property $P$ is said to be [well-defined](https://en.wikipedia.org/wiki/Well-defined) or a class invariant under the relation $\,\sim.$

A frequent particular case occurs when $f$ is a function from $X$ to another set $Y;$ if $x_1 \sim x_2$ implies $f\left(x_1\right) = f\left(x_2\right)$ then $f$ is said to be a morphism for $\,\sim,$ a class invariant under $\,\sim,$ or simply invariant under $\,\sim.$ This occurs, e.g. in the character theory of finite groups. The latter case with the function $f$ can be expressed by a commutative triangle. See also [invariant](wikipedia://en/1126638). Some authors use "compatible with $\,\sim$" or just "respects $\,\sim$" instead of "invariant under $\,\sim$".

More generally, a function may map equivalent arguments (under an equivalence relation $\,\sim_A$) to equivalent values (under an equivalence relation $\,\sim_B$). Such a function is known as a morphism from $\,\sim_A$ to $\,\sim_B.$

## Related important definitions {#Related_important_definitions}

Let $a, b \in X$, and $\sim$ be an equivalence relation. Some key definitions and terminology follow:

### Equivalence class {#Equivalence_class}

A subset $Y$ of $X$ such that $a \sim b$ holds for all $a$ and $b$ in $Y$, and never for $a$ in $Y$ and $b$ outside $Y$, is called an *equivalence class* of $X$ by $\sim$. Let $[a] := \{x \in X : a \sim x\}$ denote the equivalence class to which $a$ belongs. All elements of $X$ equivalent to each other are also elements of the same equivalence class.

### Quotient set {#Quotient_set}

The set of all equivalence classes of $X$ by $\sim,$ denoted $X / \mathord{\sim} := \{[x] : x \in X\},$ is the *quotient set* of $X$ by $\sim.$ If $X$ is a [topological space](wikipedia://en/30450), there is a natural way of transforming $X / \sim$ into a topological space; see *[Quotient space](wikipedia://en/237213)* for the details.

### Projection {#Projection}

The *projection* of $\,\sim\,$ is the function $\pi : X \to X/\mathord{\sim}$ defined by $\pi(x) = [x]$ which maps elements of $X$ into their respective equivalence classes by $\,\sim.$

**Theorem** on [projections](wikipedia://en/3913145):[^o25] Let the function $f : X \to B$ be such that if $a \sim b$ then $f(a) = f(b).$ Then there is a unique function $g : X / \sim \to B$ such that $f = g \pi.$ If $f$ is a [surjection](https://en.wikipedia.org/wiki/Surjection) and $a \sim b \text{ if and only if } f(a) = f(b),$ then $g$ is a [bijection](wikipedia://en/3942).

### Equivalence kernel {#Equivalence_kernel}

The **equivalence kernel** of a function $f$ is the equivalence relation ~ defined by $x \sim y \text{ if and only if } f(x) = f(y).$ The equivalence kernel of an [injection](wikipedia://en/45196) is the [identity relation](https://en.wikipedia.org/wiki/Identity_relation).

### Partition {#Partition}

A *partition* of *X* is a set *P* of nonempty subsets of *X*, such that every element of *X* is an element of a single element of *P*. Each element of *P* is a *cell* of the partition. Moreover, the elements of *P* are [pairwise disjoint](https://en.wikipedia.org/wiki/Pairwise_disjoint) and their [union](wikipedia://en/47949) is *X*.

#### Counting partitions {#Counting_partitions}

Let *X* be a finite set with *n* elements. Since every equivalence relation over *X* corresponds to a partition of *X*, and vice versa, the number of equivalence relations on *X* equals the number of distinct partitions of *X*, which is the *n*th [Bell number](wikipedia://en/201022) *B<sub>n</sub>*:

$$B_n = \frac{1}{e} \sum_{k=0}^\infty \frac{k^n}{k!} \quad$$

([Dobinski's formula](https://en.wikipedia.org/wiki/Dobinski's_formula)).

::: {#o30 .statement kind=statement/theorem cue=named-heading name="Fundamental theorem of equivalence relations"}

## Fundamental theorem of equivalence relations {#Fundamental_theorem_of_equivalence_relations}

A key result links equivalence relations and partitions:[^o31][^o32][^o33]

- An equivalence relation ~ on a set *X* partitions *X*.
- Conversely, corresponding to any partition of *X*, there exists an equivalence relation ~ on *X*.

In both cases, the cells of the partition of *X* are the equivalence classes of *X* by ~. Since each element of *X* belongs to a unique cell of any partition of *X*, and since each cell of the partition is identical to an equivalence class of *X* by ~, each element of *X* belongs to a unique equivalence class of *X* by ~. Thus there is a natural [bijection](wikipedia://en/3942) between the set of all equivalence relations on *X* and the set of all partitions of *X*.

:::

## Comparing equivalence relations {#Comparing_equivalence_relations}

If $\sim$ and $\approx$ are two equivalence relations on the same set $S$, and $a \sim b$ implies $a \approx b$ for all $a, b \in S,$ then $\approx$ is said to be a **coarser** relation than $\sim$, and $\sim$ is a **finer** relation than $\approx$. Equivalently,

- $\sim$ is finer than $\approx$ if every equivalence class of $\sim$ is a subset of an equivalence class of $\approx$, and thus every equivalence class of $\approx$ is a union of equivalence classes of $\sim$.
- $\sim$ is finer than $\approx$ if the partition created by $\sim$ is a refinement of the partition created by $\approx$.

The equality equivalence relation is the finest equivalence relation on any set, while the universal relation, which relates all pairs of elements, is the coarsest.

The relation "$\sim$ is finer than $\approx$" on the collection of all equivalence relations on a fixed set is itself a partial order relation, which makes the collection a [geometric lattice](wikipedia://en/17243191).[^o35]

## Generating equivalence relations {#Generating_equivalence_relations}

- Given any set $X,$ an equivalence relation over the set $[X \to X]$ of all functions $X \to X$ can be obtained as follows. Two functions are deemed equivalent when their respective sets of [fixed points](wikipedia://en/449738) have the same [cardinality](wikipedia://en/6174).
- An equivalence relation $\,\sim\,$ on $X$ is the [equivalence kernel](wikipedia://en/9259#Equivalence_kernel) of its [surjective](https://en.wikipedia.org/wiki/Surjective) [projection](wikipedia://en/9259#Projection) $\pi : X \to X / \sim.$[^o37] Conversely, any [surjection](https://en.wikipedia.org/wiki/Surjection) between sets determines a partition on its domain, the set of [preimages](https://en.wikipedia.org/wiki/Preimage) of [singletons](wikipedia://en/381798) in the [codomain](wikipedia://en/50264). Thus an equivalence relation over $X,$ a partition of $X,$ and a projection whose domain is $X,$ are three equivalent ways of specifying the same thing.
- The intersection of any collection of equivalence relations over *X* (binary relations viewed as a [subset](wikipedia://en/27631) of $X \times X$) is also an equivalence relation. This yields a convenient way of generating an equivalence relation: given any binary relation *R* on *X*, the equivalence relation generated by R is the intersection of all equivalence relations containing *R* (also known as the smallest equivalence relation containing *R*). Concretely, *R* generates the equivalence relation

$a \sim b$ if there exists a [natural number](wikipedia://en/21474) $n$ and elements $x_0, \ldots, x_n \in X$ such that $a = x_0$, $b = x_n$, and $x_{i-1} \mathrel{R} x_i$ or $x_i \mathrel{R} x_{i-1}$, for $i = 1, \ldots, n.$

The equivalence relation generated in this manner can be trivial. For instance, the equivalence relation generated by any [total order](wikipedia://en/30330) on *X* has exactly one equivalence class, *X* itself.

- Equivalence relations can construct new spaces by "gluing things together." Let *X* be the unit [Cartesian square](https://en.wikipedia.org/wiki/Cartesian_square) $[0, 1] \times [0, 1],$ and let ~ be the equivalence relation on *X* defined by $(a, 0) \sim (a, 1)$ for all $a \in [0, 1]$ and $(0, b) \sim (1, b)$ for all $b \in [0, 1],$ Then the [quotient space](wikipedia://en/237213) $X / \sim$ can be naturally identified ([homeomorphism](wikipedia://en/13660)) with a [torus](wikipedia://en/74800): take a square piece of paper, bend and glue together the upper and lower edge to form a cylinder, then bend the resulting cylinder so as to glue together its two open ends, resulting in a torus.

## Algebraic structure {#Algebraic_structure}

Much of mathematics is grounded in the study of equivalences, and [order relations](https://en.wikipedia.org/wiki/Order_relation). [Lattice theory](wikipedia://en/469304) captures the mathematical structure of order relations. Even though equivalence relations are as ubiquitous in mathematics as order relations, the algebraic structure of equivalences is not as well known as that of orders. The former structure draws primarily on [group theory](wikipedia://en/41890) and, to a lesser extent, on the theory of lattices, [categories](wikipedia://en/5869), and [groupoids](wikipedia://en/12543).

### Group theory {#Group_theory}

Just as [order relations](https://en.wikipedia.org/wiki/Order_relation) are grounded in [ordered sets](wikipedia://en/23572), sets closed under pairwise [supremum](https://en.wikipedia.org/wiki/Supremum) and [infimum](https://en.wikipedia.org/wiki/Infimum), equivalence relations are grounded in [partitioned sets](wikipedia://en/340240), which are sets closed under [bijections](wikipedia://en/3942) that preserve partition structure. Since all such bijections map an equivalence class onto itself, such bijections are also known as [permutations](wikipedia://en/44027). Hence [permutation groups](wikipedia://en/24634) (also known as [transformation groups](wikipedia://en/12781)) and the related notion of [orbit](https://en.wikipedia.org/wiki/Orbit_%28group_theory%29) shed light on the mathematical structure of equivalence relations.

Let '~' denote an equivalence relation over some nonempty set *A*, called the [universe](wikipedia://en/296838) or underlying set. Let *G* denote the set of bijective functions over *A* that preserve the partition structure of *A*, meaning that for all $x \in A$ and $g \in G, g(x) \in [x].$ Then the following three connected theorems hold:[^o40]

- ~ partitions *A* into equivalence classes. (This is the Fundamental Theorem of Equivalence Relations, mentioned above);
- Given a partition of *A*, *G* is a transformation group under composition, whose orbits are the [cells](https://en.wikipedia.org/wiki/Partitions_of_a_set) of the partition;
- Given a transformation group *G* over *A*, there exists an equivalence relation ~ over *A*, whose equivalence classes are the orbits of *G*.[^o42][^o43]

In sum, given an equivalence relation ~ over *A*, there exists a [transformation group](https://en.wikipedia.org/wiki/Transformation_group) *G* over *A* whose orbits are the equivalence classes of *A* under ~.

This transformation group characterisation of equivalence relations differs fundamentally from the way [lattices](wikipedia://en/469304) characterize order relations. The arguments of the lattice theory operations [meet](https://en.wikipedia.org/wiki/Meet_%28mathematics%29) and [join](https://en.wikipedia.org/wiki/Join_%28mathematics%29) are elements of some universe *A*. Meanwhile, the arguments of the transformation group operations [composition](wikipedia://en/195947) and [inverse](wikipedia://en/14907) are elements of a set of [bijections](https://en.wikipedia.org/wiki/Bijections), *A* → *A*.

Moving to groups in general, let *H* be a [subgroup](wikipedia://en/28011) of some [group](wikipedia://en/19447) *G*. Let ~ be an equivalence relation on *G*, such that $a \sim b \text{ if and only if } a b^{-1} \in H.$ The equivalence classes of ~—also called the orbits of the [action](wikipedia://en/12781) of *H* on *G*—are the right **[cosets](wikipedia://en/98759)** of *H* in *G*. Interchanging *a* and *b* yields the left cosets.

Related thinking can be found in Rosen (2008: chpt. 10).

### Categories and groupoids {#Categories_and_groupoids}

Let *G* be a set and let "~" denote an equivalence relation over *G*. Then we can form a [groupoid](wikipedia://en/12543) representing this equivalence relation as follows. The objects are the elements of *G*, and for any two elements *x* and *y* of *G*, there exists a unique morphism from *x* to *y* [if and only if](wikipedia://en/14922) $x \sim y.$

The advantages of regarding an equivalence relation as a special case of a groupoid include:

- Whereas the notion of "free equivalence relation" does not exist, that of a [free groupoid](wikipedia://en/333835) on a [directed graph](wikipedia://en/19721986) does. Thus it is meaningful to speak of a "presentation of an equivalence relation," i.e., a presentation of the corresponding groupoid;
- Bundles of groups, [group actions](wikipedia://en/12781), sets, and equivalence relations can be regarded as special cases of the notion of groupoid, a point of view that suggests a number of analogies;
- In many contexts "quotienting," and hence the appropriate equivalence relations often called [congruences](wikipedia://en/48167), are important. This leads to the notion of an internal groupoid in a [category](wikipedia://en/53759).[^o45]

### Lattices {#Lattices}

The equivalence relations on any set *X*, when ordered by [set inclusion](https://en.wikipedia.org/wiki/Set_inclusion), form a [complete lattice](wikipedia://en/44777), called **Con** *X* by convention. The canonical [map](wikipedia://en/516931) **ker** : *X*^*X* → **Con** *X*, relates the [monoid](wikipedia://en/19652) *X*^*X* of all [functions](wikipedia://en/185427) on *X* and **Con** *X*. **ker** is [surjective](https://en.wikipedia.org/wiki/Surjective) but not [injective](https://en.wikipedia.org/wiki/Injective). Less formally, the equivalence relation **ker** on *X*, takes each function *f* : *X* → *X* to its [kernel](wikipedia://en/45240) **ker** *f*. Likewise, **ker(ker)** is an equivalence relation on *X*^*X*.

## Equivalence relations and mathematical logic {#Equivalence_relations_and_mathematical_logic}

Equivalence relations are a ready source of examples or counterexamples. For example, an equivalence relation with exactly two infinite equivalence classes is an easy example of a theory which is ω-[categorical](https://en.wikipedia.org/wiki/Morley's_categoricity_theorem), but not categorical for any larger [cardinal number](wikipedia://en/6173).

An implication of [model theory](wikipedia://en/19858) is that the properties defining a relation can be proved independent of each other (and hence necessary parts of the definition) if and only if, for each property, examples can be found of relations not satisfying the given property while satisfying all the other properties. Hence the three defining properties of equivalence relations can be proved mutually independent by the following three examples:

- *Reflexive and transitive*: The relation ≤ on **N**. Or any [preorder](wikipedia://en/23582);
- *Symmetric and transitive*: The relation *R* on **N**, defined as *aRb* ↔ *ab* ≠ 0. Or any [partial equivalence relation](wikipedia://en/3450320);
- *Reflexive and symmetric*: The relation *R* on **Z**, defined as *aRb* ↔ "*a* − *b* is divisible by at least one of 2 or 3." Or any [dependency relation](wikipedia://en/10739341).

Properties definable in [first-order logic](wikipedia://en/10983) that an equivalence relation may or may not possess include:

- The number of equivalence classes is finite or infinite;
- The number of equivalence classes equals the (finite) natural number *n*;
- All equivalence classes have infinite [cardinality](wikipedia://en/6174);
- The number of elements in each equivalence class is the natural number *n*.
