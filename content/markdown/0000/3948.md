# Binary operation

*Image: Binary operations as black box.svg.* A binary operation $\circ$ is a rule for combining the arguments $x$ and $y$ to produce $x\circ y$

::: {#o1 .subject cue=lead name="Binary operation"}

In [mathematics](wikipedia://en/18831), a **binary operation** or **dyadic operation** is a kind of [binary function](wikipedia://en/3943), i.e. given a [pair](wikipedia://en/22362) of input values (called [operands](wikipedia://en/22656)), it produces an output value. For example, addition is a binary operation: $3 + 4 = 7$. A binary operation is an [operation](wikipedia://en/4140245) of [arity](wikipedia://en/42301) two.

:::

Some definitions require the two inputs and the output to be [elements](wikipedia://en/682629) of the same [set](wikipedia://en/26691).

Binary operations are usually written using [infix notation](wikipedia://en/199014) such as $a \star b$ rather than by functional notation of the form $f(a, b)$. [Multiplication](wikipedia://en/20845) and [exponentiation](wikipedia://en/99491) are frequently written without operator, but with exponents as [superscript](https://en.wikipedia.org/wiki/Superscript).

In [abstract algebra](wikipedia://en/19616384), a binary operation on a [set](wikipedia://en/26691) $S$ is a [mapping](wikipedia://en/516931) of the elements of the [Cartesian product](wikipedia://en/24104095) $S \times S$ to $S$:[^o2][^o3][^o4]

$$\,f \colon S \times S \rightarrow S.$$

If the mapping is total, $(S, f)$ is a [magma](wikipedia://en/141916). However, if $f$ is a [partial mapping](https://en.wikipedia.org/wiki/Partial_mapping), then $f$ is a **partial binary operation**, which can be one of the operations in a [partial algebra](wikipedia://en/43662761) on $S$, such as the [partial groupoid](wikipedia://en/43662522) $(S, f)$.[^o5]

A binary operation $f$ on a set $S$ may be viewed as a [ternary relation](wikipedia://en/3784565) on $S$, that is, the set of triples $(a, b, f(a,b))$ in $S \times S \times S$ for all $a$ and $b$ in $S$.

Binary operations are the keystone of most [structures](wikipedia://en/106364) that are studied in [algebra](wikipedia://en/18716923), in particular in [semigroups](wikipedia://en/27799), [monoids](wikipedia://en/19652), [groups](wikipedia://en/19447), [rings](wikipedia://en/48404), [fields](wikipedia://en/10603), and [vector spaces](wikipedia://en/32370).

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

[Arithmetic operations](https://en.wikipedia.org/wiki/Arithmetic_operations) like [addition](wikipedia://en/61338) ($a + b$), [subtraction](wikipedia://en/74141) ($a - b$), and [multiplication](wikipedia://en/20845) ($a \times b$ or, using [juxtaposition](https://en.wikipedia.org/wiki/Juxtaposition#Mathematics), $ab$) are binary operations on [numbers](wikipedia://en/21690). Division ($a / b$ or $a \div b$) is only a partial binary operation on the set of [rational numbers](wikipedia://en/19727024) and the set of [real numbers](wikipedia://en/20646438), because [division by zero](wikipedia://en/185663) is undefined, but a (total) binary operation on the set of [positive real numbers](wikipedia://en/47172571).

[Union](wikipedia://en/47949) ($X \cup Y$), [intersection](wikipedia://en/41780044) ($X \cap Y$), and [set difference](https://en.wikipedia.org/wiki/Set_difference) ($X \backslash Y$) are binary operations on sets. There are 16 [binary operations on binary variables](wikipedia://en/25512250#Binary_operations), such as 'AND', 'OR', and 'XOR'.

If a broad definition of "binary operation" is used, such that the inputs and output do not have to be from the same set, then [scalar multiplication](wikipedia://en/244373) ($a \vec{v}$) is an binary operator from a [scalar](wikipedia://en/3588331) and a [vector](wikipedia://en/23218956) to a vector, and [dot product](wikipedia://en/157093) ($\vec{u} \cdot \vec{v}$) is a binary operator from two vectors to a scalar.

[Function composition](wikipedia://en/195947) ($g \circ h$) is a binary operation on compatible [functions](wikipedia://en/185427).

## Properties {#Properties}

Ways to classify binary operations include:

- The [commutative property](wikipedia://en/294390): $a \star b = b \star a$
- The [associative property](wikipedia://en/1335): $(a \star b) \star c = a \star (b \star c)$
- Having an [identity element](wikipedia://en/14962) $e$: $a \star e = a = e \star a$
  - Each element of $S$ having an [inverse element](wikipedia://en/45199): $a^{-1} \star a = e = a \star a^{-1}$
