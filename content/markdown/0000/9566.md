# Empty set

Empty

::: {#o1 .subject cue=lead name="Empty set"}

*Image: Nullset.svg.* The empty set is the set containing no elements.

In [mathematics](wikipedia://en/18831), the **empty set** or **void set** is the unique [set](wikipedia://en/26691) having no [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29); its size or [cardinality](wikipedia://en/6174) (count of elements in a set) is [zero](wikipedia://en/34513).[^o2] Some [axiomatic set theories](https://en.wikipedia.org/wiki/Axiomatic_set_theories) ensure that the empty set exists by including an [axiom of empty set](wikipedia://en/52534), while in other theories, its existence can be deduced. Many possible properties of sets are [vacuously true](https://en.wikipedia.org/wiki/Vacuously_true) for the empty set.

:::

Any set other than the empty set is called *non-empty*.

In some textbooks and popularizations, the empty set is referred to as the "null set".[^o2] However, [null set](wikipedia://en/21520) is a distinct notion within the context of [measure theory](https://en.wikipedia.org/wiki/Measure_theory), in which it describes a set of measure zero (which is not necessarily empty).

::: {#o4 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

*Image: Empty set symbol.svg.* A symbol for the empty set

Common notations for the empty set include "{ }", "$\emptyset$", and "∅". The latter two symbols were introduced by the [Bourbaki group](https://en.wikipedia.org/wiki/Bourbaki_group) (specifically [André Weil](wikipedia://en/2019)) in 1939, inspired by the letter [Ø](https://en.wikipedia.org/wiki/Ø) (d8) in the [Danish](https://en.wikipedia.org/wiki/Danish_orthography) and [Norwegian](https://en.wikipedia.org/wiki/Norwegian_orthography) alphabets.[^o5] In the past, "0" (the numeral [zero](https://en.wikipedia.org/wiki/Zero)) was occasionally used as a symbol for the empty set, but this is now considered to be an improper use of notation.[^o6]

The symbol ∅ is available at [Unicode](https://en.wikipedia.org/wiki/Unicode) point 2205.[^o7] It can be coded in [HTML](https://en.wikipedia.org/wiki/HTML) as ∅ and as ∅ or as ∅. It can be coded in [LaTeX](https://en.wikipedia.org/wiki/LaTeX) as \\varnothing. The symbol $\emptyset$ is coded in LaTeX as \\emptyset.

When writing in languages such as Danish and Norwegian, where the empty set character may be confused with the alphabetic letter Ø (as when using the symbol in linguistics), the Unicode character 29B0 may be used instead.[^o8]

## Properties {#Properties}

In standard [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), by the [principle of extensionality](wikipedia://en/52376), two sets are equal if they have the same elements (that is, neither of them has an element not in the other). As a result, there can be only one set with no elements, hence the usage of "the empty set" rather than "an empty set".

The only subset of the empty set is the empty set itself; equivalently, the [power set](wikipedia://en/23799) of the empty set is the set containing only the empty set. The number of elements of the empty set (i.e., its [cardinality](wikipedia://en/6174)) is zero. The empty set is the only set with either of these properties.

[For any](https://en.wikipedia.org/wiki/For_any) set *A*:

- The empty set is a [subset](wikipedia://en/27631) of *A*
- The [union](wikipedia://en/47949) of *A* with the empty set is *A*
- The [intersection](wikipedia://en/23476429) of *A* with the empty set is the empty set
- The [Cartesian product](wikipedia://en/24104095) of *A* and the empty set is the empty set

For any [property](wikipedia://en/508057) *P*:

- For every element of $\varnothing$, the property *P* holds ([vacuous truth](wikipedia://en/51672)).
- There is no element of $\varnothing$ for which the property *P* holds.

Conversely, if for some property *P* and some set *V*, the following two statements hold:

- For every element of *V* the property *P* holds
- There is no element of *V* for which the property *P* holds

then $V = \varnothing.$

By the definition of [subset](wikipedia://en/27631), the empty set is a subset of any set *A*. That is, every element *x* of $\varnothing$ belongs to *A*. Indeed, if it were not true that every element of $\varnothing$ is in *A*, then there would be at least one element of $\varnothing$ that is not present in *A*. Since there are no elements of $\varnothing$ at all, there is no element of $\varnothing$ that is not in *A*. Any statement that begins "for every element of $\varnothing$" is not making any substantive claim; it is a [vacuous truth](wikipedia://en/51672). This is often paraphrased as "everything is true of the elements of the empty set."

In the usual [set-theoretic definition of natural numbers](wikipedia://en/428484), zero is modelled by the empty set.

### Operations on the empty set {#Operations_on_the_empty_set}

When speaking of the [sum](wikipedia://en/246160) of the elements of a finite set, one is inevitably led to the convention that the sum of the elements of the empty set (the [empty sum](wikipedia://en/209748)) is zero. The reason for this is that zero is the [identity element](wikipedia://en/14962) for addition. Similarly, the [product](wikipedia://en/20845) of the elements of the empty set (the [empty product](wikipedia://en/181289)) should be considered to be [one](https://en.wikipedia.org/wiki/1_%28number%29), since one is the identity element for multiplication.[^o12]

A [derangement](wikipedia://en/162132) is a [permutation](wikipedia://en/44027) of a set without [fixed points](wikipedia://en/449738). The empty set can be considered a derangement of itself, because it has only one permutation ($0!=1$), and it is vacuously true that no element (of the empty set) can be found that retains its original position.

## In other areas of mathematics {#In_other_areas_of_mathematics}

### Extended real numbers {#Extended_real_numbers}

Since the empty set has no member when it is considered as a subset of any [ordered set](https://en.wikipedia.org/wiki/Ordered_set), every member of that set will be an upper bound and lower bound for the empty set. For example, when considered as a subset of the real numbers, with its usual ordering, represented by the [real number line](https://en.wikipedia.org/wiki/Real_number_line), every real number is both an upper and lower bound for the empty set.[^o15] When considered as a subset of the [extended reals](https://en.wikipedia.org/wiki/Extended_reals) formed by adding two "numbers" or "points" to the real numbers (namely [negative infinity](https://en.wikipedia.org/wiki/Negative_infinity), denoted $-\infty\!\,,$ which is defined to be less than every other extended real number, and [positive infinity](https://en.wikipedia.org/wiki/Positive_infinity), denoted $+\infty\!\,,$ which is defined to be greater than every other extended real number), we have that:

$$\sup\varnothing=\min(\{-\infty, +\infty \} \cup \mathbb{R})=-\infty,$$

and

$$\inf\varnothing=\max(\{-\infty, +\infty \} \cup \mathbb{R})=+\infty.$$

That is, the least upper bound (sup or [supremum](https://en.wikipedia.org/wiki/Supremum)) of the empty set is negative infinity, while the greatest lower bound (inf or [infimum](https://en.wikipedia.org/wiki/Infimum)) is positive infinity. By analogy with the above, in the domain of the extended reals, negative infinity is the identity element for the maximum and supremum operators, while positive infinity is the identity element for the minimum and infimum operators.

### Topology {#Topology}

In any [topological space](wikipedia://en/30450) $X$, the empty set is [open](wikipedia://en/39358) by definition, as is $X$. Since the [complement](wikipedia://en/54347) of an open set is [closed](wikipedia://en/47279) and the empty set and $X$ are complements of each other, the empty set is also closed, making it a [clopen set](wikipedia://en/233398). Moreover, the empty set is [compact](https://en.wikipedia.org/wiki/Compact_set) by the fact that every [finite set](wikipedia://en/11742) is compact.

A topological space $X$ is said to have the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology) if the only open sets are $\varnothing$ and the entire space.

The [closure](wikipedia://en/293802) of the empty set is empty. This is known as "preservation of [nullary](https://en.wikipedia.org/wiki/Nullary) [unions](wikipedia://en/47949)".[^o17]

### Category theory {#Category_theory}

If $A$ is a set, then there exists precisely one [function](wikipedia://en/185427) $f$ from $\varnothing$ to $A,$ the [empty function](https://en.wikipedia.org/wiki/Empty_function). As a result, the empty set is the unique [initial object](https://en.wikipedia.org/wiki/Initial_object) of the [category](wikipedia://en/5869) of sets and functions.

The empty set can be turned into a [topological space](wikipedia://en/30450), called the empty space, in just one way: by defining the empty set to be [open](wikipedia://en/39358). This empty topological space is the unique initial object in the [category of topological spaces](wikipedia://en/435051) with [continuous maps](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29). In fact, it is a [strict initial object](wikipedia://en/46597851): only the empty set has a function to the empty set.

### Set theory {#Set_theory}

In the [von Neumann construction of the ordinals](https://en.wikipedia.org/wiki/Von_Neumann_ordinal), 0 is defined as the empty set, and the successor of an ordinal is defined as $S(\alpha)=\alpha\cup\{\alpha\}$. Thus, we have $0=\varnothing$, $1 = 0\cup\{0\}=\{\varnothing\}$, $2=1\cup\{1\}=\{\varnothing,\{\varnothing\}\}$, and so on. The von Neumann construction, along with the [axiom of infinity](wikipedia://en/246449), which guarantees the existence of at least one infinite set, can be used to construct the set of natural numbers, $\mathbb{N}_0$, such that the [Peano axioms](wikipedia://en/25005) of arithmetic are satisfied.

## Existence {#Existence}

### Historical issues {#Historical_issues}

In the context of sets of real numbers, Cantor used $P\equiv O$ to denote "$P$ contains no single point". This $\equiv O$ notation was utilized in definitions; for example, Cantor defined two sets as being disjoint if their intersection has an absence of points; however, it is debatable whether Cantor viewed $O$ as an existent set on its own, or if Cantor merely used $\equiv O$ as an emptiness predicate. Zermelo accepted $O$ itself as a set, but considered it an "improper set".[^o22]

### Axiomatic set theory {#Axiomatic_set_theory}

In [Zermelo set theory](wikipedia://en/322623), the existence of the empty set is assured by the [axiom of empty set](wikipedia://en/52534), and its uniqueness follows from the [axiom of extensionality](wikipedia://en/52376). However, the axiom of empty set can be shown redundant in at least two ways:

- Standard [first-order logic](wikipedia://en/10983) implies, merely from the [logical axioms](https://en.wikipedia.org/wiki/Logical_axiom), that something exists, and in the language of set theory, that thing must be a set. Now the existence of the empty set follows easily from the [axiom of separation](https://en.wikipedia.org/wiki/Axiom_of_separation).
- Even using [free logic](wikipedia://en/1635110) (which does not logically imply that something exists), there is already an axiom implying the existence of at least one set, namely the [axiom of infinity](wikipedia://en/246449).

### Philosophical issues {#Philosophical_issues}

While the empty set is a standard and widely accepted mathematical concept, it remains an [ontological](https://en.wikipedia.org/wiki/Ontological) curiosity, whose meaning and usefulness are debated by philosophers and logicians.

The empty set is not the same thing as [nothing](wikipedia://en/72197); rather, it is a set with nothing inside it and a set is always something. This issue can be overcome by viewing a set as a bag—an empty bag undoubtedly still exists. Darling (2004) explains that the empty set is not nothing, but rather "the set of all triangles with four sides, the set of all numbers that are bigger than nine but smaller than eight, and the set of all [opening moves](https://en.wikipedia.org/wiki/Chess_opening) in [chess](https://en.wikipedia.org/wiki/Chess) that involve a [king](https://en.wikipedia.org/wiki/King_%28chess%29)."[^o25]

The popular [syllogism](wikipedia://en/48046)

Nothing is better than eternal happiness; a ham sandwich is better than nothing; therefore, a ham sandwich is better than eternal happiness

is often used to demonstrate the philosophical relation between the concept of nothing and the empty set. Darling writes that the contrast can be seen by rewriting the statements "Nothing is better than eternal happiness" and "\[A\] ham sandwich is better than nothing" in a mathematical tone. According to Darling, the former is equivalent to "The set of all things that are better than eternal happiness is $\varnothing$" and the latter to "The set {ham sandwich} is better than the set $\varnothing$". The first compares elements of sets, while the second compares the sets themselves.[^o25]

[Jonathan Lowe](wikipedia://en/304941) argues that while the empty set

was undoubtedly an important landmark in the history of mathematics, … we should not assume that its utility in calculation is dependent upon its actually denoting some object.

it is also the case that:

"All that we are ever informed about the empty set is that it (1) is a set, (2) has no members, and (3) is unique amongst sets in having no members. However, there are very many things that 'have no members', in the set-theoretical sense—namely, all non-sets. It is perfectly clear why these things have no members, for they are not sets. What is unclear is how there can be, uniquely amongst sets, a set which has no members. We cannot conjure such an entity into existence by mere stipulation."[^o26]

[George Boolos](wikipedia://en/340621) argued that much of what has been heretofore obtained by set theory can just as easily be obtained by [plural quantification](wikipedia://en/444789) over individuals, without reifying sets as singular entities having other entities as members.[^o27]
