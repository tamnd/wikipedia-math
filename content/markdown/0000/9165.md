# Directed set

::: {#o1 .subject cue=lead name="Directed set"}

In [mathematics](wikipedia://en/18831), a **directed set** (or a **directed preorder** or a **filtered set**) is a [preordered set](https://en.wikipedia.org/wiki/Preordered_set) in which every finite subset has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound).[^n1] In other words, it is a non-empty preordered set $A$ such that for any $a$ and $b$ in $A$ there exists $c$ in $A$ with $a \leq c$ and $b \leq c$. A directed set's preorder is called a **direction**.

:::

The notion defined above is sometimes called an **upward directed set**. A **downward directed set** is defined symmetrically,[^o3] meaning that every finite subset has a [lower bound](https://en.wikipedia.org/wiki/Lower_bound).[^o4] Some authors (and this article) assume that a directed set is directed upward, unless otherwise stated. Other authors call a set directed if and only if it is directed both upward and downward.[^o5]

Directed sets are a generalization of nonempty [totally ordered sets](https://en.wikipedia.org/wiki/Totally_ordered_set). That is, all totally ordered sets are directed sets (contrast [partially ordered sets](https://en.wikipedia.org/wiki/Partially_ordered_sets), which need not be directed). [Join-semilattices](https://en.wikipedia.org/wiki/Join-semilattice) (which are partially ordered sets) are directed sets as well, but not conversely. Likewise, [lattices](wikipedia://en/469304) are directed sets both upward and downward.

In [topology](wikipedia://en/29954), directed sets are used to define [nets](https://en.wikipedia.org/wiki/Net_%28topology%29), which generalize [sequences](wikipedia://en/27838) and unify the various notions of [limit](wikipedia://en/26551602) used in [analysis](wikipedia://en/48396). Directed sets also give rise to [direct limits](wikipedia://en/211566) in [abstract algebra](wikipedia://en/19616384) and (more generally) [category theory](wikipedia://en/5869).

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

The set of [natural numbers](wikipedia://en/21474) $\mathbb{N}$ with the ordinary order $\,\leq\,$ is one of the most important examples of a directed set. Every [totally ordered set](wikipedia://en/30330) is a directed set, including $(\mathbb{Z}, \leq),$ $(\mathbb{Q}, \leq),$ and $(\mathbb{R}, \leq).$

A (trivial) example of a partially ordered set that is **not** directed is the set $\{a, b\},$ in which the only order relations are $a \leq a$ and $b \leq b.$ A less trivial example is like the following example of the "reals directed towards $x_0$" but in which the ordering rule only applies to pairs of elements on the same side of $x_0$ (that is, if one takes an element $a$ to the left of $x_0,$ and $b$ to its right, then $a$ and $b$ are not comparable, and the subset $\{ a, b \}$ has no upper bound).

If an [abstract rewriting system](wikipedia://en/23947591) $(X, \to)$ is [confluent](wikipedia://en/3755377), then its transitive closure $(X, \to^*)$ is a directed set.

### Product of directed sets {#Product_of_directed_sets}

Let $\mathbb{D}_1$ and $\mathbb{D}_2$ be directed sets. Then the [Cartesian product](wikipedia://en/24104095) set $\mathbb{D}_1 \times \mathbb{D}_2$ can be made into a directed set by defining $\left(n_1, n_2\right) \leq \left(m_1, m_2\right)$ if and only if $n_1 \leq m_1$ and $n_2 \leq m_2.$ In analogy to the [product order](wikipedia://en/1956306) this is the product direction on the Cartesian product. For example, the set $\mathbb{N} \times \mathbb{N}$ of pairs of natural numbers can be made into a directed set by defining $\left(n_0, n_1\right) \leq \left(m_0, m_1\right)$ if and only if $n_0 \leq m_0$ and $n_1 \leq m_1.$

### Directed towards a point {#Directed_towards_a_point}

If $x_0$ is a [real number](wikipedia://en/20646438) then the set $I := \mathbb{R} \backslash \lbrace x_0 \rbrace$ can be turned into a directed set by defining $a \leq_I b$ if $\left|a - x_0\right| \geq \left|b - x_0\right|$ (so "greater" elements are closer to $x_0$). We then say that the reals have been **directed towards $x_0.$** This is an example of a directed set that is neither [partially ordered](https://en.wikipedia.org/wiki/Partial_order) nor [totally ordered](wikipedia://en/30330). This is because [antisymmetry](wikipedia://en/1176) breaks down for every pair $a$ and $b$ equidistant from $x_0,$ where $a$ and $b$ are on opposite sides of $x_0.$ Explicitly, this happens when $\{a, b\} = \left\{x_0 - r, x_0 + r\right\}$ for some real $r \neq 0,$ in which case $a \leq_I b$ and $b \leq_I a$ even though $a \neq b.$ Had this preorder been defined on $\mathbb{R}$ instead of $\mathbb{R} \backslash \lbrace x_0 \rbrace$ then it would still form a directed set but it would now have a (unique) [greatest element](https://en.wikipedia.org/wiki/Greatest_element), specifically $x_0$; however, it still wouldn't be partially ordered. This example can be generalized to a [metric space](wikipedia://en/20018) $(X, d)$ by defining on $X$ or $X \setminus \left\{x_0\right\}$ the preorder $a \leq b$ if and only if $d\left(a, x_0\right) \geq d\left(b, x_0\right).$

### Maximal and greatest elements {#Maximal_and_greatest_elements}

An element $m$ of a preordered set $(I, \leq)$ is a *[maximal element](wikipedia://en/303398)* if for every $j \in I,$ $m \leq j$ implies $j \leq m.$ It is a *[greatest element](wikipedia://en/663041)* if for every $j \in I,$ $j \leq m.$

Any preordered set with a greatest element is a directed set with the same preorder. For instance, in a [poset](https://en.wikipedia.org/wiki/Poset) $P,$ every [lower closure](https://en.wikipedia.org/wiki/Upper_set#Upper_closure_and_lower_closure) of an element; that is, every subset of the form $\{a \in P : a \leq x\}$ where $x$ is a fixed element from $P,$ is directed.

A preordered set is directed if and only if the (possibly empty) set of maximal elements is equal to the set of greatest elements.

### Subset inclusion {#Subset_inclusion}

The [subset inclusion](https://en.wikipedia.org/wiki/Subset_inclusion) relation $\,\subseteq,\,$ along with its [dual](wikipedia://en/600618) $\,\supseteq,\,$ define [partial orders](https://en.wikipedia.org/wiki/Partial_order) on any given [family of sets](wikipedia://en/723043). A non-empty [family of sets](wikipedia://en/723043) is a directed set with respect to the partial order $\,\supseteq\,$ (respectively, $\,\subseteq\,$) if and only if the intersection (respectively, union) of any two of its members contains as a subset (respectively, is contained as a subset of) some third member. In symbols, a family $I$ of sets is directed with respect to $\,\supseteq\,$ (respectively, $\,\subseteq\,$) if and only if

for all $A, B \in I,$ there exists some $C \in I$ such that $A \supseteq C$ and $B \supseteq C$ (respectively, $A \subseteq C$ and $B \subseteq C$)

or equivalently,

for all $A, B \in I,$ there exists some $C \in I$ such that $A \cap B \supseteq C$ (respectively, $A \cup B \subseteq C$).

Many important examples of directed sets can be defined using these partial orders. For example, by definition, a [prefilter](https://en.wikipedia.org/wiki/Prefilter) or filter base is a non-empty [family of sets](wikipedia://en/723043) that is a directed set with respect to the [partial order](https://en.wikipedia.org/wiki/Partial_order) $\,\supseteq\,$ and that also does not contain the empty set (this condition prevents triviality because otherwise, the empty set would then be a [greatest element](wikipedia://en/663041) with respect to $\,\supseteq\,$). Every [$\pi$-system](wikipedia://en/4050532), which is a non-empty [family of sets](wikipedia://en/723043) that is closed under the intersection of any two of its members, is a directed set with respect to $\,\supseteq\,.$ Every [λ-system](wikipedia://en/2549191) is a directed set with respect to $\,\subseteq\,.$ Every [filter](wikipedia://en/12646549), [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29), and [σ-algebra](wikipedia://en/29586) is a directed set with respect to both $\,\supseteq\,$ and $\,\subseteq\,.$

#### Tails of nets {#Tails_of_nets}

By definition, a [net](wikipedia://en/22170) is a function from a directed set and a [sequence](https://en.wikipedia.org/wiki/Sequence_%28mathematics%29) is a function from the natural numbers $\mathbb{N}.$ Every sequence canonically becomes a net by endowing $\mathbb{N}$ with $\,\leq.\,$

If $x_{\bullet} = \left(x_i\right)_{i \in I}$ is any [net](wikipedia://en/22170) from a directed set $(I, \leq)$ then for any index $i \in I,$ the set $x_{\geq i} := \left\{x_j : j \geq i \text{ with } j \in I\right\}$ is called the tail of $(I, \leq)$ starting at $i.$ The family $\operatorname{Tails}\left(x_{\bullet}\right) := \left\{x_{\geq i} : i \in I\right\}$ of all tails is a directed set with respect to $\,\supseteq;\,$ in fact, it is even a prefilter.

#### Neighborhoods {#Neighborhoods}

If $T$ is a [topological space](wikipedia://en/30450) and $x_0$ is a point in $T,$ the set of all [neighbourhoods](https://en.wikipedia.org/wiki/Topological_neighbourhood) of $x_0$ can be turned into a directed set by writing $U \leq V$ if and only if $U$ contains $V.$ For every $U,$ $V,$ and $W$:

- $U \leq U$ since $U$ contains itself.
- if $U \leq V$ and $V \leq W,$ then $U \supseteq V$ and $V \supseteq W,$ which implies $U \supseteq W.$ Thus $U \leq W.$
- because $x_0 \in U \cap V,$ and since both $U \supseteq U \cap V$ and $V \supseteq U \cap V,$ we have $U \leq U \cap V$ and $V \leq U \cap V.$

#### Finite subsets {#Finite_subsets}

The set $\operatorname{Finite}(I)$ of all finite subsets of a set $I$ is directed with respect to $\,\subseteq\,$ since given any two $A, B \in \operatorname{Finite}(I),$ their union $A \cup B \in \operatorname{Finite}(I)$ is an upper bound of $A$ and $B$ in $\operatorname{Finite}(I).$ This particular directed set is used to define the sum ${\textstyle\sum\limits_{i \in I}} r_i$ of a [generalized series](https://en.wikipedia.org/wiki/Generalized_series_%28mathematics%29) of an $I$-indexed collection of numbers $\left(r_i\right)_{i \in I}$ (or more generally, the sum of [elements in an](wikipedia://en/15287#Abelian_topological_groups) [abelian topological group](https://en.wikipedia.org/wiki/Abelian_topological_group), such as [vectors](wikipedia://en/15287#Series_in_topological_vector_spaces) in a [topological vector space](wikipedia://en/45752)) as the [limit of the net](https://en.wikipedia.org/wiki/Limit_of_a_net) of [partial sums](https://en.wikipedia.org/wiki/Partial_sum) $F \in \operatorname{Finite}(I) \mapsto {\textstyle\sum\limits_{i \in F}} r_i;$ that is:

$$\sum_{i \in I} r_i ~:=~ \lim_{F \in \operatorname{Finite}(I)} \ \sum_{i \in F} r_i ~=~ \lim \left\{\sum_{i \in F} r_i \,: F \subseteq I, F \text{ finite }\right\}.$$

### Logic {#Logic}

Let $S$ be a [formal theory](wikipedia://en/3512103), which is a set of [sentences](wikipedia://en/2129527) with certain properties (details of which can be found in [the article on the subject](wikipedia://en/3512103)). For instance, $S$ could be a [first-order theory](https://en.wikipedia.org/wiki/First-order_theory) (like [Zermelo–Fraenkel set theory](wikipedia://en/152214)) or a simpler [zeroth-order theory](https://en.wikipedia.org/wiki/Propositional_calculus). The preordered set $(S, \Leftarrow)$ is a directed set because if $A, B \in S$ and if $C := A \wedge B$ denotes the sentence formed by [logical conjunction](wikipedia://en/18152) $\,\wedge,\,$ then $A \Leftarrow C$ and $B \Leftarrow C$ where $C \in S.$ If $S / \sim$ is the [Lindenbaum–Tarski algebra](wikipedia://en/990343) associated with $S$ then $\left(S / \sim, \Leftarrow\right)$ is a partially ordered set that is also a directed set.

:::

## Contrast with semilattices {#Contrast_with_semilattices}

*Image: Directed\_set,\_but\_no\_join\_semi-lattice.png.* Example of a directed set which is not a join-semilattice

Directed set is a more general concept than (join) semilattice: every [join semilattice](wikipedia://en/755647) is a directed set, as the join or least upper bound of two elements is the desired $c.$ The converse does not hold however, witness the directed set {1000,0001,1101,1011,1111} [ordered bitwise](https://en.wikipedia.org/wiki/Coordinatewise_order) (e.g. $1000 \leq 1011$ holds, but $0001 \leq 1000$ does not, since in the last bit 1 > 0), where {1000,0001} has three upper bounds but no least upper bound, cf. picture. (Also note that without 1111, the set is not directed.)

## Directed subsets {#Directed_subsets}

The order relation in a directed set is not required to be [antisymmetric](wikipedia://en/1176), and therefore directed sets are not always [partial orders](https://en.wikipedia.org/wiki/Partial_order). However, the term directed set is also used frequently in the context of posets. In this setting, a subset $A$ of a partially ordered set $(P, \leq)$ is called a **directed subset** if it is a directed set according to the same partial order: in other words, it is not the [empty set](wikipedia://en/9566), and every pair of elements has an upper bound. Here the order relation on the elements of $A$ is inherited from $P$; for this reason, reflexivity and transitivity need not be required explicitly.

A directed subset of a poset is not required to be [downward closed](https://en.wikipedia.org/wiki/Lower_set); a subset of a poset is directed if and only if its downward closure is an [ideal](wikipedia://en/530559). While the definition of a directed set is for an "upward-directed" set (every pair of elements has an upper bound), it is also possible to define a downward-directed set in which every pair of elements has a common lower bound. A subset of a poset is downward-directed if and only if its upper closure is a [filter](wikipedia://en/12646549).

Directed subsets are used in [domain theory](wikipedia://en/325077), which studies [directed-complete partial orders](wikipedia://en/572352).[^n2] These are posets in which every upward-directed set is required to have a [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound). In this context, directed subsets again provide a generalization of convergent sequences.
