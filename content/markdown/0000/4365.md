# Bilinear map

::: {#o1 .subject cue=lead name="Bilinear map"}

In [mathematics](wikipedia://en/18831), a **bilinear map** is a [function](wikipedia://en/185427) combining elements of two [vector spaces](wikipedia://en/32370) to yield an element of a third vector space, and is [linear](wikipedia://en/18102) in each of its arguments. [Matrix multiplication](wikipedia://en/125280) is an example.

:::

A bilinear map can also be defined for [modules](wikipedia://en/276410). For that, see the article [pairing](wikipedia://en/1191490).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Vector spaces {#Vector_spaces}

Let $V, W$ and $X$ be three [vector spaces](wikipedia://en/32370) over the same base [field](wikipedia://en/10603) $F$. A bilinear map is a [function](wikipedia://en/185427)

$$B : V \times W \to X$$

such that for all $w \in W$, the map $B_w$

$$v \mapsto B(v, w)$$

is a [linear map](wikipedia://en/18102) from $V$ to $X,$ and for all $v \in V$, the map $B_v$

$$w \mapsto B(v, w)$$

is a linear map from $W$ to $X.$ In other words, when we hold the second entry of the bilinear map fixed while letting the first entry vary, yielding $B_w$, the result is a linear operator, and similarly for when we hold the first entry fixed.

Such a map $B$ satisfies the following properties.

- For any $\lambda \in F$, $B(\lambda v,w) = B(v, \lambda w) = \lambda B(v, w).$
- The map $B$ is additive in both components: if $v_1, v_2 \in V$ and $w_1, w_2 \in W,$ then $B(v_1 + v_2, w) = B(v_1, w) + B(v_2, w)$ and $B(v, w_1 + w_2) = B(v, w_1) + B(v, w_2).$

If $V = W$ and we have *B*(*v*, *w*) = *B*(*w*, *v*) for all $v, w \in V,$ then we say that *B* is *[symmetric](wikipedia://en/22510359)*. If *X* is the base field *F*, then the map is called a *[bilinear form](wikipedia://en/449477)*, which are well-studied (for example: [scalar product](https://en.wikipedia.org/wiki/Scalar_product), [inner product](https://en.wikipedia.org/wiki/Inner_product), and [quadratic form](wikipedia://en/251478)).

### Modules {#Modules}

The definition works without any changes if instead of vector spaces over a field *F*, we use [modules](wikipedia://en/276410) over a [commutative ring](wikipedia://en/61346) *R*. It generalizes to *n*-ary functions, where the proper term is *[multilinear](wikipedia://en/221525)*.

For non-commutative rings *R* and *S*, a left *R*-module *M* and a right *S*-module *N*, a bilinear map is a map *B* : *M* × *N* → *T* with *T* an (*R*, *S*)-[bimodule](wikipedia://en/492612), and for which any *n* in *N*, *m* ↦ *B*(*m*, *n*) is an *R*-module homomorphism, and for any *m* in *M*, *n* ↦ *B*(*m*, *n*) is an *S*-module homomorphism. This satisfies

*B*(*r* ⋅ *m*, *n*) = *r* ⋅ *B*(*m*, *n*)

*B*(*m*, *n* ⋅ *s*) = *B*(*m*, *n*) ⋅ *s*

for all *m* in *M*, *n* in *N*, *r* in *R* and *s* in *S*, as well as *B* being [additive](wikipedia://en/22473529) in each argument.

:::

## Properties {#Properties}

An immediate consequence of the definition is that *B*(*v*, *w*) = 0<sub>*X*</sub> whenever *v* = 0<sub>*V*</sub> or *w* = 0<sub>*W*</sub>. This may be seen by writing the [zero vector](https://en.wikipedia.org/wiki/Zero_vector) 0<sub>*V*</sub> as 0 ⋅ 0<sub>*V*</sub> (and similarly for 0<sub>*W*</sub>) and moving the scalar 0 "outside", in front of *B*, by bilinearity.

The set *L*(*V*, *W*; *X*) of all bilinear maps is a [linear subspace](wikipedia://en/56357) of the space ([viz.](https://en.wikipedia.org/wiki/Viz.) [vector space](wikipedia://en/32370), [module](wikipedia://en/276410)) of all maps from *V* × *W* into *X*.

If *V*, *W*, *X* are [finite-dimensional](https://en.wikipedia.org/wiki/Finite-dimensional), then so is *L*(*V*, *W*; *X*). For $X = F,$ that is, bilinear forms, the dimension of this space is dim *V* × dim *W* (while the space *L*(*V* × *W*; *F*) of *linear* forms is of dimension dim *V* + dim *W*). To see this, choose a [basis](wikipedia://en/18420) for *V* and *W*; then each bilinear map can be uniquely represented by the matrix *B*(*e*<sub>*i*</sub>, *f*<sub>*j*</sub>), and vice versa. Now, if *X* is a space of higher dimension, we obviously have dim *L*(*V*, *W*; *X*) = dim *V* × dim *W* × dim *X*.

:::

## Examples {#Examples}

- [Matrix multiplication](wikipedia://en/20556859) is a bilinear map M(*m*, *n*) × M(*n*, *p*) → M(*m*, *p*).
- If a [vector space](wikipedia://en/32370) *V* over the [real numbers](wikipedia://en/20646438) $\mathbb{R}$ carries an [inner product](wikipedia://en/14856), then the inner product is a bilinear map $V \times V \to \mathbb{R}.$
- In general, for a vector space *V* over a field *F*, a [bilinear form](wikipedia://en/449477) on *V* is the same as a bilinear map *V* × *V* → *F*.
- If *V* is a vector space with [dual space](wikipedia://en/7988) *V*<sup>∗</sup>, then the [canonical evaluation map](wikipedia://en/63735167#Canonical_duality_on_a_vector_space), *b*(*f*, *v*) = *f*(*v*) is a bilinear map from *V*<sup>∗</sup> × *V* to the base field.
- Let *V* and *W* be vector spaces over the same base field *F*. If *f* is a member of *V*<sup>∗</sup> and *g* a member of *W*<sup>∗</sup>, then *b*(*v*, *w*) = *f*(*v*)*g*(*w*) defines a bilinear map *V* × *W* → *F*.
- The [cross product](wikipedia://en/157092) in $\mathbb{R}^3$ is a bilinear map $\mathbb{R}^3 \times \mathbb{R}^3 \to \mathbb{R}^3.$
- Let $B : V \times W \to X$ be a bilinear map, and $L : U \to W$ be a [linear map](wikipedia://en/18102), then (*v*, *u*) ↦ *B*(*v*, *Lu*) is a bilinear map on *V* × *U*.

:::

## Continuity and separate continuity {#Continuity_and_separate_continuity}

Suppose $X, Y,$ and $Z$ are [topological vector spaces](wikipedia://en/45752) and let $b : X \times Y \to Z$ be a bilinear map. Then *b* is said to be **separately continuous** if the following two conditions hold:

1. for all $x \in X,$ the map $Y \to Z$ given by $y \mapsto b(x, y)$ is continuous;
1. for all $y \in Y,$ the map $X \to Z$ given by $x \mapsto b(x, y)$ is continuous.

Many separately continuous bilinear that are not continuous satisfy an additional property: [hypocontinuity](https://en.wikipedia.org/wiki/Hypocontinuity).[^n1] All continuous bilinear maps are hypocontinuous.

### Sufficient conditions for continuity {#Sufficient_conditions_for_continuity}

Many bilinear maps that occur in practice are separately continuous but not all are continuous. We list here sufficient conditions for a separately continuous bilinear map to be continuous.

- If *X* is a [Baire space](wikipedia://en/200550) and *Y* is [metrizable](https://en.wikipedia.org/wiki/Metrizable) then every separately continuous bilinear map $b : X \times Y \to Z$ is continuous.[^n1]
- If $X, Y, \text{ and } Z$ are the [strong duals](https://en.wikipedia.org/wiki/Strong_dual) of [Fréchet spaces](wikipedia://en/233801) then every separately continuous bilinear map $b : X \times Y \to Z$ is continuous.[^n1]
- If a bilinear map is continuous at (0, 0) then it is continuous everywhere.[^n2]

### Composition map {#Composition_map}

Let $X, Y, \text{ and } Z$ be [locally convex](https://en.wikipedia.org/wiki/Locally_convex) [Hausdorff spaces](wikipedia://en/13637) and let $C : L(X; Y) \times L(Y; Z) \to L(X; Z)$ be the composition map defined by $C(u, v) := v \circ u.$ In general, the bilinear map $C$ is not continuous (no matter what topologies the spaces of linear maps are given). We do, however, have the following results:

Give all three spaces of linear maps one of the following topologies:

1. give all three the topology of bounded convergence;
1. give all three the [topology of compact convergence](https://en.wikipedia.org/wiki/Topology_of_compact_convergence);
1. give all three the [topology of pointwise convergence](https://en.wikipedia.org/wiki/Topology_of_pointwise_convergence).

<!-- -->

- If $E$ is an [equicontinuous](https://en.wikipedia.org/wiki/Equicontinuous) subset of $L(Y; Z)$ then the restriction $C\big\vert_{L(X; Y) \times E} : L(X; Y) \times E \to L(X; Z)$ is continuous for all three topologies.[^n1]
- If $Y$ is a [barreled space](https://en.wikipedia.org/wiki/Barreled_space) then for every sequence $\left(u_i\right)_{i=1}^{\infty}$ converging to $u$ in $L(X; Y)$ and every sequence $\left(v_i\right)_{i=1}^{\infty}$ converging to $v$ in $L(Y; Z),$ the sequence $\left(v_i \circ u_i\right)_{i=1}^{\infty}$ converges to $v \circ u$ in $L(Y; Z).$[^n1]
