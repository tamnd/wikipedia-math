# Pseudoconvexity

::: {#o1 .subject cue=lead name="Pseudoconvexity"}

In [mathematics](wikipedia://en/18831), more precisely in the theory of functions of [several complex variables](wikipedia://en/360243), a **pseudoconvex set** is a special type of [open set](wikipedia://en/39358) in the *n*-dimensional complex space **C**<sup>*n*</sup>. Pseudoconvex sets are important, as they allow for classification of [domains of holomorphy](wikipedia://en/3236377).

:::

Let $G\subset {\mathbb{C}}^n$ be a [domain](wikipedia://en/16796643). One says that $G$ is *pseudoconvex* (or *[Hartogs](wikipedia://en/2977779) pseudoconvex*) if there exists a [continuous](wikipedia://en/6122) [plurisubharmonic function](wikipedia://en/2519085) $\varphi$ on $G$ such that the set $\{ z \in G \mid \varphi(z) < x \}$ is a [relatively compact](https://en.wikipedia.org/wiki/Relatively_compact) subset of $G$ for all [real numbers](wikipedia://en/20646438) $x.$ In other words, a domain is pseudoconvex if $G$ has a continuous plurisubharmonic [exhaustion function](https://en.wikipedia.org/wiki/Bounded_exhaustion_function). Every (geometrically) [convex set](wikipedia://en/6292) is pseudoconvex. However, there are pseudoconvex domains which are not geometrically convex.

When $G$ has a $C^2$ (twice [continuously differentiable](https://en.wikipedia.org/wiki/Smooth_function)) [boundary](wikipedia://en/72824), this notion is the same as Levi pseudoconvexity, which is easier to work with. More specifically, with a $C^2$ boundary, it can be shown that $G$ has a defining function, i.e., that there exists $\rho: \mathbb{C}^n \to \mathbb{R}$ which is $C^2$ so that $G=\{\rho <0 \}$, and $\partial G =\{\rho =0\}$. Now, $G$ is pseudoconvex if and only if for every $p \in \partial G$ and $w$ in the complex tangent space at p, that is,

$\nabla \rho(p) w = \sum_{i=1}^n \frac{\partial \rho (p)}{ \partial z_j }w_j =0$, we have

$$\sum_{i,j=1}^n \frac{\partial^2 \rho(p)}{\partial z_i \partial \bar{z_j} } w_i \bar{w_j} \geq 0.$$

The definition above is analogous to definitions of convexity in Real Analysis.

If $G$ does not have a $C^2$ boundary, the following approximation result can be useful.

::: {#o2 .statement kind=statement/proposition cue=inline-head name="Proposition 1"}

**Proposition 1** *If $G$ is pseudoconvex, then there exist [bounded](wikipedia://en/48258), strongly Levi pseudoconvex domains $G_k \subset G$ with $C^\infty$ ([smooth](https://en.wikipedia.org/wiki/Smooth_function)) boundary which are relatively compact in $G$, such that*

$$G = \bigcup_{k=1}^\infty G_k.$$

This is because once we have a $\varphi$ as in the definition we can actually find a *C*<sup>∞</sup> exhaustion function.

:::

## The case *n* = 1 {#The_case_n_=_1}

In one complex dimension, every open domain is pseudoconvex.
