# Pseudoconvex function

::: {#o1 .subject cue=lead name="Pseudoconvex function"}

In [convex analysis](wikipedia://en/3237201) and the [calculus of variations](wikipedia://en/171882), both branches of [mathematics](wikipedia://en/18831), a **pseudoconvex function** is a [function](wikipedia://en/185427) that behaves like a [convex function](wikipedia://en/245568) with respect to finding its [local minima](https://en.wikipedia.org/wiki/Local_extrema), but need not actually be convex. Informally, a differentiable function is pseudoconvex if it is increasing in any direction where it has a positive [directional derivative](wikipedia://en/487859). The property must hold in all of the function domain, and not only for nearby points.

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Consider a [differentiable](https://en.wikipedia.org/wiki/Differentiable) function $f:X \subseteq \mathbb{R}^{n} \rightarrow \mathbb{R}$, defined on a (nonempty) [convex](wikipedia://en/6292) [open set](wikipedia://en/39358) $X$ of the finite-dimensional [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$. This function is said to be **pseudoconvex** if the following property holds:[^o4]

for all $x,y \in X: \quad \nabla f(x) \cdot (y-x) \geq 0 \Rightarrow f(y) \geq f(x).$

Equivalently:

for all $x,y \in X: \quad f(y) < f(x) \Rightarrow \nabla f(x) \cdot (y-x) < 0.$

Here $\nabla f$ is the [gradient](wikipedia://en/12461) of $f$, defined by: $\nabla f = \left(\frac{\partial f}{\partial x_1},\dots,\frac{\partial f}{\partial x_n}\right).$

Note that the definition may also be stated in terms of the [directional derivative](wikipedia://en/487859) of $f$, in the direction given by the vector $v=y-x$. This is because, as $f$ is differentiable, this directional derivative is given by:

$$\frac{\partial f}{\partial v}(x) = \nabla f(x) \cdot v = \nabla f(x) \cdot (y-x).$$

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Relation to other types of "convexity" {#Relation_to_other_types_of_"convexity"}

Every convex function is pseudoconvex, but the converse is not true. For example, the function $f(x) = x + x^{3}$ is pseudoconvex but not convex. Similarly, any pseudoconvex function is [quasiconvex](wikipedia://en/5781226); but the converse is not true, since the function $f(x) = x^{3}$ is quasiconvex but not pseudoconvex. This can be summarized schematically as:

convex $\Rightarrow$ pseudoconvex $\Rightarrow$ quasiconvex

*Image: Pseudoquasiconvex.png.* Functions x^3 (quasiconvex but not pseudoconvex) and x^3 + x (pseudoconvex and thus quasiconvex). None of them is convex.

To see that $f(x) = x^{3}$ is not pseudoconvex, consider its derivative at $x = 0$: $f^{\prime}(0) = 0$. Then, if $f(x) = x^{3}$ was pseudoconvex, we should have:

$$f^{\prime}(0) (y-0) = 0 \geq 0 \Rightarrow f(y) \geq f(0), \quad \forall \, y \in \mathbb{R}.$$

In particular it should be true for $y=-1$. But it is not, as: $f(-1) = (-1)^{3} = -1 < f(0) = 0$.

### Sufficient optimality condition {#Sufficient_optimality_condition}

For any differentiable function, we have the [Fermat's theorem](https://en.wikipedia.org/wiki/Fermat's_theorem_%28stationary_points%29) necessary condition of optimality, which states that: if $f$ has a local minimum at $x^{*}$ in an [open](wikipedia://en/39358) domain, then $x^{*}$ must be a [stationary point](wikipedia://en/885651) of $f$ (that is: $\nabla f(x^{*}) = 0$).

Pseudoconvexity is of great interest in the area of [optimization](https://en.wikipedia.org/wiki/Optimization), because the converse is also true for any pseudoconvex function. That is:[^o9] if $x^{*}$ is a [stationary point](wikipedia://en/885651) of a pseudoconvex function $f$, then $f$ has a global minimum at $x^{*}$. Note also that the result guarantees a global minimum (not only local).

This last result is also true for a convex function, but it is not true for a quasiconvex function. Consider for example the quasiconvex function:

$$f(x)=\frac{e^{x}}{x^{2}+1} + \frac{1}{e^{x}}.$$

This function is not pseudoconvex, but it is quasiconvex. Also, the point $x=0$ is a critical point of $f$, as $f^{\prime}(0)=0$. However, $f$ does not have a global minimum at $x=0$ (not even a local minimum).

*Image: Quasiconvex optimality.png.* Example of a quasiconvex function that is not pseudoconvex. The function has a critical point at $x=0$, but this is not a minimum.

Finally, note that a pseudoconvex function may not have any critical point. Take for example the pseudoconvex function: $f(x)=x^{3}+x$, whose derivative is always positive: $f^{\prime}(x)=3x^{2}+1>0, \, \forall \, x \in \mathbb{R}$.

:::

## Examples {#Examples}

An example of a function that is pseudoconvex, but not convex, is: $f(x)=\frac{x^{2}}{x^{2}+k}, \, k > 0.$ The figure shows this function for the case where $k=0.2$. This example may be generalized to two variables as:

$$f(x)=\frac{x^{2}+y^{2}}{x^{2}+y^{2}+k}, \, k > 0.$$

*Image: Pseudoconvex.png.* Pseudoconvex function that is not convex.

The previous example may be modified to obtain a function that is not convex, nor pseudoconvex, but is quasiconvex:

$$f(x)=\frac{|x|^{p}}{|x|^{p}+k}, \, k > 0, \, p \in (0,1).$$

The figure shows this function for the case where $k=0.5, p=0.6$. As can be seen, this function is not convex because of the concavity, and it is not pseudoconvex because it is not differentiable at $x=0$.

*Image: Quasiconvex.png.* Quasiconvex function that is not convex, nor pseudoconvex.

## Generalization to nondifferentiable functions {#Generalization_to_nondifferentiable_functions}

The notion of pseudoconvexity can be generalized to nondifferentiable functions as follows.[^o13] Given any function $f:X \rightarrow \mathbb{R}$, we can define the upper [Dini derivative](wikipedia://en/2163404) of $f$ by:

$$f^{+}(x,u) = \limsup_{ h \to 0^{+} } \frac{f(x+hu) - f(x)}{h};$$

where *u* is any [unit vector](wikipedia://en/167053). The function is said to be pseudoconvex if it is increasing in any direction where the upper Dini derivative is positive. More precisely, this is characterized in terms of the [subdifferential](https://en.wikipedia.org/wiki/Subdifferential) $\partial f$ as follows:

For all $x, y \in X$: if $x^* \in \partial f(x)$ is such that $\langle x^* , y - x \rangle \geq 0$, then $f(x) \leq f(z)$, for all $z \in [x,y]$;

where $[x,y]$ denotes the line segment adjoining *x* and *y*.

## Related notions {#Related_notions}

A **pseudoconcave function** is a function whose negative is pseudoconvex. A **pseudolinear function** is a function that is both pseudoconvex and pseudoconcave.[^o15] For example, [linear–fractional programs](wikipedia://en/22989094) have pseudolinear [objective functions](https://en.wikipedia.org/wiki/Objective_function) and [linear–inequality constraints](wikipedia://en/43730). These properties allow fractional-linear problems to be solved by a variant of the [simplex algorithm](wikipedia://en/349458) (of [George B. Dantzig](https://en.wikipedia.org/wiki/George_B._Dantzig)).[^o16][^o17][^o18]

Given a vector-valued function $\eta$, there is a more general notion of $\eta$-pseudoconvexity[^o19][^o20] and $\eta$-pseudolinearity; wherein classical pseudoconvexity and pseudolinearity pertain to the case when $\eta (x, y) = y - x$.
