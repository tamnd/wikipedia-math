# List of exceptional set concepts

::: {#o1 .subject cue=lead name="List of exceptional set concepts"}

This is a **list of exceptional set concepts**. In [mathematics](wikipedia://en/18831), and in particular in [mathematical analysis](wikipedia://en/48396), it is very useful to be able to characterise [subsets](wikipedia://en/27631) of a given set *X* as 'small', in some definite sense, or 'large' if their [complement](wikipedia://en/54347) in *X* is small. There are numerous concepts that have been introduced to study 'small' or 'exceptional' subsets. In the case of sets of [natural numbers](wikipedia://en/21474), it is possible to define more than one concept of 'density', for example. See also [list of properties of sets of reals](wikipedia://en/2236863).

:::
