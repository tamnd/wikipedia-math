# Subharmonic function

::: {#o1 .subject cue=lead name="Subharmonic function"}

In [mathematics](wikipedia://en/18831), **subharmonic** and **superharmonic** functions are important classes of [functions](wikipedia://en/185427) used extensively in [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations), [complex analysis](wikipedia://en/5759) and [potential theory](wikipedia://en/1431342).

:::

Intuitively, subharmonic functions are related to [convex functions](wikipedia://en/245568) of one variable as follows. If the [graph](wikipedia://en/87352) of a convex function and a line intersect at two points, then the graph of the convex function is *below* the line between those points. In the same way, if the values of a subharmonic function are no larger than the values of a [harmonic function](wikipedia://en/55762) on the *boundary* of a [ball](wikipedia://en/160556), then the values of the subharmonic function are no larger than the values of the harmonic function also *inside* the ball.

*Superharmonic* functions can be defined by the same description, only replacing "no larger" with "no smaller". Alternatively, a superharmonic function is just the [negative](wikipedia://en/228312) of a subharmonic function, and for this reason any property of subharmonic functions can be easily transferred to superharmonic functions.

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Formally, the definition can be stated as follows. Let $G$ be a subset of the [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$ and let

$$\varphi \colon G \to \mathbb{R} \cup \{ - \infty \}$$

be an [upper semi-continuous function](wikipedia://en/57824). Then, $\varphi$ is called *subharmonic* if for any [closed ball](https://en.wikipedia.org/wiki/Closed_ball) $\overline{B(x,r)}$ of center $x$ and radius $r$ contained in $G$ and every [real](wikipedia://en/20646438)-valued [continuous function](wikipedia://en/6122) $h$ on $\overline{B(x,r)}$ that is [harmonic](wikipedia://en/55762) in $B(x,r)$ and satisfies $\varphi(y) \leq h(y)$ for all $y$ on the [boundary](wikipedia://en/72824) $\partial B(x,r)$ of $B(x,r)$, we have $\varphi(y) \leq h(y)$ for all $y \in B(x,r).$

Note that by the above, the function which is identically −∞ is subharmonic, but some authors exclude this function by definition.

A function $u$ is called *superharmonic* if $-u$ is subharmonic.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A function is [harmonic](wikipedia://en/55762) [if and only if](wikipedia://en/14922) it is both subharmonic and superharmonic.
- If $\phi$ is *C*<sup>2</sup> ([twice continuously differentiable](https://en.wikipedia.org/wiki/Smooth_function)) on an [open set](wikipedia://en/39358) $G$ in $\mathbb{R}^n$, then $\phi$ is subharmonic [if and only if](wikipedia://en/14922) one has $\Delta \phi \geq 0$ on $G$, where $\Delta$ is the [Laplacian](https://en.wikipedia.org/wiki/Laplacian).
- The [maximum](https://en.wikipedia.org/wiki/Maxima_and_minima) of a subharmonic function cannot be achieved in the [interior](wikipedia://en/55610) of its domain unless the function is constant, which is called the [maximum principle](wikipedia://en/1436104). However, the [minimum](https://en.wikipedia.org/wiki/Minimum) of a subharmonic function can be achieved in the interior of its domain.
- Subharmonic functions make a [convex cone](wikipedia://en/3558266), that is, a linear combination of subharmonic functions with positive coefficients is also subharmonic.
- The [pointwise maximum](https://en.wikipedia.org/wiki/Pointwise_maximum) of two subharmonic functions is subharmonic. If the pointwise maximum of a countable number of subharmonic functions is upper semi-continuous, then it is also subharmonic.
- The limit of a decreasing sequence of subharmonic functions is subharmonic (or identically equal to $-\infty$).
- Subharmonic functions are not necessarily continuous in the usual topology, however one can introduce the [fine topology](wikipedia://en/5170051) which makes them continuous.

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

If $f$ is [analytic](wikipedia://en/61478) then $\log|f|$ is subharmonic. More examples can be constructed by using the properties listed above, by taking maxima, convex combinations and limits. In dimension 1, all subharmonic functions can be obtained in this way.

:::

::: {#o9 .statement kind=statement/theorem cue=named-heading name="Riesz Representation Theorem"}

## Riesz Representation Theorem {#Riesz_Representation_Theorem}

If $u$ is subharmonic in a region $D$, in [Euclidean space](wikipedia://en/9697) of dimension $n$, $v$ is harmonic in $D$, and $u \leq v$, then $v$ is called a harmonic majorant of $u$. If a harmonic majorant exists, then there exists the least harmonic majorant, and

$$u(x) = v(x) - \int_D\frac{d\mu(y)}{|x-y|^{n-2}},\quad n\geq 3$$

while in dimension 2,

$$u(x) = v(x) + \int_D\log|x-y|d\mu(y),$$

where $v$ is the least harmonic majorant, and $\mu$ is a [Borel measure](wikipedia://en/4322) in $D$. This is called the [Riesz](https://en.wikipedia.org/wiki/Friedrich_Riesz) representation theorem.

:::

## Subharmonic functions in the complex plane {#Subharmonic_functions_in_the_complex_plane}

Subharmonic functions are of a particular importance in [complex analysis](wikipedia://en/5759), where they are intimately connected to [holomorphic functions](wikipedia://en/14110).

One can show that a real-valued, continuous function $\varphi$ of a complex variable (that is, of two real variables) defined on a set $G\subset \mathbb{C}$ is subharmonic if and only if for any closed disc $D(z,r) \subset G$ of center $z$ and radius $r$ one has

$$\varphi(z) \leq \frac{1}{2\pi} \int_0^{2\pi} \varphi(z+ re^{i\theta}) \, d\theta.$$

Intuitively, this means that a subharmonic function is at any point no greater than the [average](wikipedia://en/612) of the values in a circle around that point, a fact which can be used to derive the [maximum principle](wikipedia://en/1436104).

If $f$ is a holomorphic function, then

$$\varphi(z) = \log \left| f(z) \right|$$

is a subharmonic function if we define the value of $\varphi(z)$ at the zeros of $f$ to be $-\infty$. It follows that

$$\psi_\alpha(z) = \left| f(z) \right|^\alpha$$

is subharmonic for every *α* > 0. This observation plays a role in the theory of [Hardy spaces](https://en.wikipedia.org/wiki/Hardy_spaces), especially for the study of *H${}^{p}$* when 0 \< *p* \< 1.

In the context of the complex plane, the connection to the [convex functions](wikipedia://en/245568) can be realized as well by the fact that a subharmonic function $f$ on a domain $G \subset \mathbb{C}$ that is constant in the imaginary direction is convex in the real direction and vice versa.

### Harmonic majorants of subharmonic functions {#Harmonic_majorants_of_subharmonic_functions}

If $u$ is subharmonic in a [region](https://en.wikipedia.org/wiki/Region_%28mathematical_analysis%29) $\Omega$ of the complex plane, and $h$ is [harmonic](wikipedia://en/55762) on $\Omega$, then $h$ is a **harmonic majorant** of $u$ in $\Omega$ if $u \leq h$ in $\Omega$. Such an inequality can be viewed as a growth condition on $u$.[^n1]

### Subharmonic functions in the unit disc. Radial maximal function {#Subharmonic_functions_in_the_unit_disc._Radial_maximal_function}

Let *φ* be subharmonic, continuous and non-negative in an open subset Ω of the complex plane containing the closed unit disc *D*(0, 1). The *radial maximal function* for the function *φ* (restricted to the unit disc) is defined on the unit circle by

$$(M \varphi)(e^{i\theta}) = \sup_{0 \le r < 1} \varphi(re^{i\theta}).$$

If *P*<sub>*r*</sub> denotes the [Poisson kernel](wikipedia://en/2214583), it follows from the subharmonicity that

$$0 \le \varphi(re^{i\theta}) \le \frac{1}{2\pi} \int_0^{2\pi} P_r\left(\theta- t\right) \varphi\left(e^{it}\right) \, dt, \ \ \ r < 1.$$

It can be shown that the last integral is less than the value at *e*${}^{i\theta}$ of the [Hardy–Littlewood maximal function](wikipedia://en/10094198) *φ*<sup>∗</sup> of the restriction of *φ* to the unit circle **T**,

$$\varphi^*(e^{i\theta}) = \sup_{0 < \alpha \le \pi} \frac{1}{2 \alpha} \int_{\theta - \alpha}^{\theta + \alpha} \varphi\left(e^{it}\right) \, dt,$$

so that 0 ≤ *M* *φ* ≤ *φ*<sup>∗</sup>. It is known that the Hardy–Littlewood operator is bounded on [*L*<sup>*p*</sup>(**T**)](wikipedia://en/45194) when 1 \< *p* \< ∞. It follows that for some universal constant *C*,

$$\|M \varphi\|_{L^2(\mathbf{T})}^2 \le C^2 \, \int_0^{2\pi} \varphi(e^{i\theta})^2 \, d\theta.$$

If *f* is a function holomorphic in Ω and 0 \< *p* \< ∞, then the preceding inequality applies to *φ* = |*f*|${}^{p/2}$. It can be deduced from these facts that any function *F* in the classical Hardy space *H<sup>p</sup>* satisfies

$$\int_0^{2\pi} \left( \sup_{0 \le r < 1} \left|F(r e^{i\theta})\right| \right)^p \, d\theta \le C^2 \, \sup_{0 \leq r < 1} \int_0^{2\pi} \left|F(re^{i\theta})\right|^p \, d\theta.$$

With more work, it can be shown that *F* has radial limits *F*(*e*${}^{i\theta}$) almost everywhere on the unit circle, and (by the [dominated convergence theorem](wikipedia://en/351853)) that *F<sub>r</sub>*, defined by *F<sub>r</sub>*(*e*${}^{i\theta}$) = *F*(*r**e*${}^{i\theta}$) tends to *F* in *L*<sup>*p*</sup>(**T**).

## Subharmonic functions on Riemannian manifolds {#Subharmonic_functions_on_Riemannian_manifolds}

Subharmonic functions can be defined on an arbitrary [Riemannian manifold](wikipedia://en/144652).

*Definition:* Let *M* be a Riemannian manifold, and $f:\; M \to \mathbb{R}$ an [upper semicontinuous](https://en.wikipedia.org/wiki/Upper_semicontinuous) function. Assume that for any open subset $U\subset M$, and any [harmonic function](wikipedia://en/55762) *f*<sub>1</sub> on *U*, such that $f_1 \geq f$ on the boundary of *U*, the inequality $f_1 \geq f$ holds on all *U*. Then *f* is called *subharmonic*.

This definition is equivalent to one given above. Also, for twice differentiable functions, subharmonicity is equivalent to the inequality $\Delta f \geq 0$, where $\Delta$ is the usual [Laplacian](wikipedia://en/1763356).[^o15]
