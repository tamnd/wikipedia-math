# Effaceable functor

::: {#o1 .subject cue=lead name="Effaceable functor"}

In mathematics, an **effaceable functor** is an [additive functor](https://en.wikipedia.org/wiki/Additive_functor) *F* between [abelian categories](wikipedia://en/45063) *C* and *D* for which, for each object *A* in *C*, there exists a [monomorphism](wikipedia://en/59538) $u: A \to M$, for some *M*, such that $F(u) = 0$.

:::

Similarly, a **coeffaceable functor** is one for which, for each *A*, there is an epimorphism into *A* that is killed by *F*. The notions were introduced in Grothendieck's [Tohoku paper](https://en.wikipedia.org/wiki/Tohoku_paper).

A theorem of Grothendieck says that every effaceable [δ-functor](wikipedia://en/20850491) (i.e., effaceable in each positive degree) is universal.
