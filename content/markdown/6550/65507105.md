# Wielandt theorem

::: {#o1 .subject cue=lead name="Wielandt theorem"}

In [mathematics](wikipedia://en/18831), the **Wielandt theorem** [characterizes](wikipedia://en/780886) the [gamma function](wikipedia://en/12316), defined for all complex numbers $z$ for which $\mathrm{Re}\,z > 0$ by

:::

$$\Gamma(z)=\int_0^{+\infty} t^{z-1} \mathrm e^{-t}\,\mathrm dt,$$

as the only function $f$ defined on the half-plane $H := \{ z \in \mathbb{C} : \operatorname{Re}\,z > 0\}$ such that:

- $f$ is [holomorphic](wikipedia://en/14110) on $H$;
- $$f(1)=1;$$
- $f(z+1)=z\,f(z)$ for all $z \in H$ and
- $f$ is [bounded](wikipedia://en/311509) on the strip $\{ z \in \mathbb{C} : 1 \leq \operatorname{Re}\,z \leq 2\}$.

This theorem is named after the mathematician [Helmut Wielandt](https://en.wikipedia.org/wiki/Helmut_Wielandt).
