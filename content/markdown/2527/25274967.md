# Solovay model

::: {#o1 .subject cue=lead name="Solovay model"}

*Image: Robert\_M.\_Solovay\_2004.jpg.* Robert M. Solovay in Berkeley, California in 2004

In the mathematical field of [set theory](wikipedia://en/27553), the **Solovay model** is a [model](wikipedia://en/19858) constructed by [Robert M. Solovay](wikipedia://en/3160110)[^o2] in which all of the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZF) hold, exclusive of the [axiom of choice](wikipedia://en/840), but in which all [sets](wikipedia://en/26691) of [real numbers](wikipedia://en/20646438) are [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable). The construction relies on the existence of an [inaccessible cardinal](wikipedia://en/248076).

:::

In this way, Solovay showed that in the proof of the existence of a [non-measurable set](wikipedia://en/620134) from [ZFC](https://en.wikipedia.org/wiki/ZFC) (Zermelo–Fraenkel set theory plus the axiom of choice), the axiom of choice is essential, at least granted that the existence of an inaccessible cardinal is consistent with ZFC.

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

ZF stands for Zermelo–Fraenkel set theory, and DC for the [axiom of dependent choice](wikipedia://en/441950).

Solovay's theorem is as follows. Assuming the existence of an inaccessible cardinal, there is an [inner model](wikipedia://en/1118686) of ZF + DC of a suitable [forcing extension](https://en.wikipedia.org/wiki/Forcing_extension) *V*\[*G*\] such that every set of reals is Lebesgue measurable, has the [perfect set property](wikipedia://en/2221109), and has the [Baire property](https://en.wikipedia.org/wiki/Baire_property).

:::

::: {#o6 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

Solovay constructed his model in two steps, starting with a model *M* of ZFC containing an inaccessible cardinal *κ*.[^o2]

The first step is to take a [Levy collapse](https://en.wikipedia.org/wiki/Levy_collapse) *M*\[*G*\] of *M* by adding a generic set *G* for the notion of forcing that collapses all cardinals less than *κ* to ω. Then *M*\[*G*\] is a model of ZFC with the property that every set of reals that is definable over a countable sequence of ordinals is Lebesgue measurable, and has the Baire and perfect set properties. (This includes all definable and [projective sets](https://en.wikipedia.org/wiki/Projective_set) of reals; however for reasons related to [Tarski's undefinability theorem](wikipedia://en/583785) the notion of a definable set of reals cannot be defined in the language of set theory, while the notion of a set of reals definable over a countable sequence of ordinals can be.)

The second step is to construct Solovay's model *N* as the class of all sets in *M*\[*G*\] that are hereditarily definable over a countable sequence of ordinals. The model *N* is an inner model of *M*\[*G*\] satisfying ZF + DC such that every set of reals is Lebesgue measurable, has the perfect set property, and has the Baire property. The proof of this uses the fact that every real in *M*\[*G*\] is definable over a countable sequence of ordinals, and hence *N* and *M*\[*G*\] have the same reals.

Instead of using Solovay's model *N*, one can also use the smaller inner model [*L*(**R**)](wikipedia://en/2250604) of *M*\[*G*\], consisting of the constructible closure of the real numbers, which has similar properties.

:::

## Complements {#Complements}

Solovay suggested in his paper that the use of an inaccessible cardinal might not be necessary. Several authors proved weaker versions of Solovay's result without assuming the existence of an inaccessible cardinal. In particular (Krivine 1969)[^o9] showed there was a model of ZFC in which every ordinal-definable set of reals is measurable, Solovay showed there is a model of ZF + DC in which there is some translation-invariant extension of Lebesgue measure to all subsets of the reals,[^o2] and Shelah (1984)[^o10] showed that there is a model in which all sets of reals have the Baire property (so that the inaccessible cardinal is indeed unnecessary in this case).

The case of the perfect set property was solved by Specker (1957),[^o11] who showed (in ZF) that if every set of reals has the perfect set property and the first uncountable cardinal ℵ<sub>1</sub> is regular, then ℵ<sub>1</sub> is inaccessible in the [constructible universe](wikipedia://en/343335). Combined with Solovay's result, this shows that the statements "There is an inaccessible cardinal" and "ℵ<sub>1</sub> is regular + Every set of reals has the perfect set property" are equiconsistent over ZF.[^o12]<sup>p. 371</sup>

Finally, Shelah (1984)[^o10] showed that consistency of an inaccessible cardinal is also necessary for constructing a model in which all sets of reals are Lebesgue measurable. More precisely he showed that if every [**Σ**${}^{1}_{3}$](wikipedia://en/1236542#Table) set of reals is measurable then the first uncountable cardinal ℵ<sub>1</sub> is inaccessible in the constructible universe, so that the condition about an inaccessible cardinal cannot be dropped from Solovay's theorem. Shelah also showed that the **Σ**${}^{1}_{3}$ condition is close to the best possible by constructing a model (without using an inaccessible cardinal) in which all **Δ**${}^{1}_{3}$ sets of reals are measurable. See (Raisonnier 1984),[^o14] (Stern 1985) and (Miller 1989)[^o17] for expositions of Shelah's result.

(Shelah Woodin 1990)[^o19] showed that if [supercompact cardinals](wikipedia://en/248116) exist then every set of reals in *L*(**R**), the constructible sets generated by the reals, is Lebesgue measurable and has the Baire property; this includes every "reasonably definable" set of reals. Later it was shown that the usage of a supercompact cardinal could be significantly weakened, to only infinitely many [Woodin cardinals](wikipedia://en/248105) with a measurable cardinal above them all.
