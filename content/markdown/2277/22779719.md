# List of number fields with class number one

::: {#o1 .subject cue=lead name="List of number fields with class number one"}

This is an incomplete list of [number fields](https://en.wikipedia.org/wiki/Number_fields) with class number 1.

:::

It is believed that there are infinitely many such number fields, but this has not been proven.[^o6]

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The **class number** of a number field is by definition the order of the [ideal class group](wikipedia://en/150907) of its [ring of integers](wikipedia://en/460613).

Thus, a number field has class number 1 if and only if its ring of integers is a [principal ideal domain](wikipedia://en/25039) (and thus a [unique factorization domain](wikipedia://en/60546)). The [fundamental theorem of arithmetic](wikipedia://en/11556) says that **Q** has class number 1.

:::

## Quadratic number fields {#Quadratic_number_fields}

These are of the form *K* = **Q**($\sqrt{d}$), for a [square-free integer](wikipedia://en/29525) *d*.

### Real quadratic fields {#Real_quadratic_fields}

*K* is called real quadratic if *d* > 0. *K* has class number 1 for the following values of *d* :

- 2\*, 3, 5\*, 6, 7, 11, 13\*, 14, 17\*, 19, 21, 22, 23, 29\*, 31, 33, 37\*, 38, 41\*, 43, 46, 47, 53\*, 57, 59, 61\*, 62, 67, 69, 71, 73\*, 77, 83, 86, 89\*, 93, 94, 97\*, ...[^o6][^o7]

(complete until *d* = 100)

\*: The [narrow class number](wikipedia://en/2567750) is also 1 (see related sequence [A003655](https://en.wikipedia.org/wiki/OEIS:A003655) in OEIS).

Despite what would appear to be the case for these small values, not all prime numbers that are congruent to 1 modulo 4 appear on this list, notably the fields **Q**($\sqrt{d}$) for *d* = 229 and *d* = 257 both have class number greater than 1 (in fact equal to 3 in both cases).[^o8] The density of such primes for which **Q**($\sqrt{d}$) does have class number 1 is conjectured to be nonzero, and in fact close to 76%,[^o9] however it is not even known whether there are infinitely many real quadratic fields with class number 1.[^o6]

### Imaginary quadratic fields {#Imaginary_quadratic_fields}

*K* has class number 1 exactly for the 9 following negative values of *d*:

- −1, −2, −3, −7, −11, −19, −43, −67, −163.[^o6]

(By definition, these also all have narrow class number 1.)

## Cyclotomic fields {#Cyclotomic_fields}

The following is a complete list of thirty *n* for which the field $\mathbb{Q}$(ζ<sub>*n*</sub>) has class number 1:[^o16]

- 1, 3, 4, 5, 7, 8, 9, 11, 12, 13, 15, 16, 17, 19, 20, 21, 24, 25, 27, 28, 32, 33, 35, 36, 40, 44, 45, 48, 60, 84.

(Note that values of *n* congruent to 2 modulo 4 are redundant since $\mathbb{Q}$(ζ<sub>*2n*</sub>) = $\mathbb{Q}$(ζ<sub>*n*</sub>) when *n* is odd.)

On the other hand, the maximal real subfields $\mathbb{Q}$(cos(2π/2<sup>*n*</sup>)) of the 2-power cyclotomic fields $\mathbb{Q}$(ζ<sub>2<sup>*n*</sup></sub>) (where *n* is a positive integer) are known to have class number 1 for n≤8,[^o18] and it is conjectured that they have class number 1 for all *n*. [Weber](wikipedia://en/2643615) showed[^o19] that these fields have odd class number. In 2009, Fukuda and Komatsu showed that the class numbers of these fields have no prime factor less than 10<sup>7</sup>,[^o20] and later improved this bound to 10<sup>9</sup>.[^o21] These fields are the *n*-th layers of the cyclotomic $\mathbb{Z}$<sub>2</sub>-extension of $\mathbb{Q}$. Also in 2009, Morisawa showed that the class numbers of the layers of the cyclotomic $\mathbb{Z}$<sub>3</sub>-extension of $\mathbb{Q}$ have no prime factor less than 10<sup>4</sup>.[^o22] [Coates](wikipedia://en/230705) has raised the question of whether, for all primes *p*, every layer of the cyclotomic $\mathbb{Z}$<sub>*p*</sub>-extension of $\mathbb{Q}$ has class number 1.[^o23]

## CM fields {#CM_fields}

Simultaneously generalizing the case of imaginary quadratic fields and cyclotomic fields is the case of a CM field *K*, i.e. a [totally imaginary](wikipedia://en/34962418) quadratic extension of a [totally real field](https://en.wikipedia.org/wiki/Totally_real_field). In 1974, [Harold Stark](wikipedia://en/788807) conjectured that there are finitely many CM fields of class number 1.[^o25] He showed that there are finitely many of a fixed degree. Shortly thereafter, [Andrew Odlyzko](wikipedia://en/1986042) showed that there are only finitely many *[Galois](wikipedia://en/457064)* CM fields of class number 1.[^o26] In 2001, [V. Kumar Murty](wikipedia://en/34926069) showed that of all CM fields whose Galois closure has [solvable](wikipedia://en/105012) Galois group, only finitely many have class number 1.[^o27]

A complete list of the 172 abelian CM fields of class number 1 was determined in the early 1990s by Ken Yamamura and is available on pages 915–919 of his article on the subject.[^o28] Combining this list with the work of Stéphane Louboutin and Ryotaro Okazaki provides a full list of quartic CM fields of class number 1.[^o29]
