# Gauss's inequality

::: {#o1 .subject cue=lead name="Gauss's inequality"}

In [probability theory](wikipedia://en/23542), **Gauss's inequality** (or the **Gauss inequality**) gives an upper bound on the probability that a [unimodal](https://en.wikipedia.org/wiki/Unimodal) [random variable](wikipedia://en/25685) lies more than any given distance from its [mode](wikipedia://en/1432127).

:::

Let *X* be a unimodal random variable with mode *m*, and let *τ*<sup>2</sup> be the [expected value](wikipedia://en/9653) of (*X* − *m*)<sup>2</sup>. (*τ*<sup>2</sup> can also be expressed as (*μ* − *m*)<sup>2</sup> + *σ*<sup>2</sup>, where *μ* and *σ* are the mean and [standard deviation](wikipedia://en/27590) of *X*.) Then for any positive value of *k*,

$$\Pr(|X - m| > k) \leq \begin{cases} \left( \frac{2\tau}{3k} \right)^2 & \text{if } k \geq \frac{2\tau}{\sqrt{3}} \\[6pt] 1 - \frac{k}{\tau\sqrt{3}} & \text{if } 0 \leq k \leq \frac{2\tau}{\sqrt{3}}. \end{cases}$$

The theorem was first proved by [Carl Friedrich Gauss](wikipedia://en/6125) in 1823.

## Extensions to higher-order moments {#Extensions_to_higher-order_moments}

Winkler in 1866 extended Gauss's inequality to *r*<sup>th</sup> moments [^o3] where *r* > 0 and the distribution is unimodal with a mode of zero. This is sometimes called Camp–Meidell's inequality.[^o4][^o5]

$$P( | X | \ge k ) \le \left( \frac{ r } { r + 1 } \right)^r \frac{ \operatorname{ E }( | X | )^r } { k^r } \quad \text{if} \quad k^r \ge \frac{ r^r } { ( r + 1 )^{ r + 1 } } \operatorname{ E }( | X |^r ),$$

$$P( | X | \ge k) \le \left( 1 - \left[ \frac{ k^r }{ ( r + 1 ) \operatorname{ E }( | X | )^r } \right]^{ 1 / r } \right) \quad \text{if} \quad k^r \le \frac{r^r} { (r + 1)^{r + 1} } \operatorname{E}( | X |^r ).$$

Gauss's bound has been subsequently sharpened and extended to apply to departures from the mean rather than the mode due to the [Vysochanskiï–Petunin inequality](https://en.wikipedia.org/wiki/Vysochanskiï–Petunin_inequality). The latter has been extended by Dharmadhikari and Joag-Dev[^o6]

$$P( | X | > k ) \le \max\left( \left[ \frac r {( r + 1 ) k } \right]^r E| X^r |, \frac s {( s - 1 ) k^r } E| X^r | - \frac 1 { s - 1 } \right)$$

where *s* is a constant satisfying both *s* > *r* + 1 and *s*(*s* − *r* − 1) = *r*<sup>*r*</sup> and *r* > 0.

It can be shown that these inequalities are the best possible and that further sharpening of the bounds requires that additional restrictions be placed on the distributions.
