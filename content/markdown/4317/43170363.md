# Planarization

::: {#o1 .subject cue=lead name="Planarization"}

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [graph theory](wikipedia://en/12401), **planarization** is a method of extending [graph drawing](wikipedia://en/325813) methods from [planar graphs](wikipedia://en/24314) to graphs that are not planar, by [embedding](wikipedia://en/52119) the non-planar graphs within a larger planar graph.[^o2][^o3]

:::

Planarization may be performed by using any method to find a drawing (with crossings) for the given graph, and then replacing each crossing point by a new artificial [vertex](wikipedia://en/638899), causing each crossed edge to be subdivided into a [path](wikipedia://en/638889). The original graph will be represented as an [immersion minor](wikipedia://en/353042#Immersion_minor) of its planarization.

In **incremental planarization**, the planarization process is split into two stages. First, a large planar [subgraph](wikipedia://en/325802#Subgraphs) is found within the given graph. Then, the remaining edges that are not already part of this subgraph are added back one at a time, and routed through an embedding of the planar subgraph. When one of these edges crosses an already-embedded edge, the two edges that cross are replaced by two-edge paths, with a new artificial vertex that represents the crossing point placed at the middle of both paths.[^o2][^o3] In some case a third [local optimization](https://en.wikipedia.org/wiki/Local_search_%28optimization%29) stage is added to the planarization process, in which edges with many crossings are removed and re-added in an attempt to improve the planarization.[^o2]

## Finding the largest planar subgraph {#Finding_the_largest_planar_subgraph}

Using incremental planarization for graph drawing is most effective when the first step of the process finds as large a planar graph as possible. Unfortunately, finding the planar subgraph with the maximum possible number of edges (the *maximum planar subgraph* problem[^o6]) is [NP-hard](https://en.wikipedia.org/wiki/NP-hard), and [MaxSNP-hard](https://en.wikipedia.org/wiki/SNP_%28complexity%29), implying that there probably does not exist a [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) algorithm that solves the problem exactly or that approximates it arbitrarily well.[^o7]

In an *n*-vertex [connected graph](https://en.wikipedia.org/wiki/Connected_graph), the largest planar subgraph has at most 3*n* − 6 edges, and any [spanning tree](wikipedia://en/455770) forms a planar subgraph with *n* − 1 edges. Thus, it is easy to approximate the maximum planar subgraph within an [approximation ratio](https://en.wikipedia.org/wiki/Approximation_ratio) of one-third, simply by finding a spanning tree. A better approximation ratio, 9/4, is known, based on a method for finding a large [partial 2-tree](https://en.wikipedia.org/wiki/Partial_k-tree) as a subgraph of the given graph.[^o2][^o7] Alternatively, if it is expected that the planar subgraph will include almost all of the edges of the given graph, leaving only a small number *k* of non-planar edges for the incremental planarization process, then one can solve the problem exactly by using a [fixed-parameter tractable](wikipedia://en/603026) algorithm whose running time is linear in the graph size but non-polynomial in the parameter *k*.[^o8] The problem may also be solved exactly by a [branch and cut](wikipedia://en/3237914) algorithm, with no guarantees on running time, but with good performance in practice.[^o2][^o9] This parameter *k* is known as the **skewness** of the graph.[^o6]

There has also been some study of a related problem, finding the largest planar [induced subgraph](wikipedia://en/1655188) of a given graph. Again, this is NP-hard, but fixed-parameter tractable when all but a few vertices belong to the induced subgraph.[^o11] (Edwards Farr 2002) proved a tight bound of 3*n*/(Δ + 1) on the size of the largest planar induced subgraph, as a function of *n*, the number of vertices in the given graph, and Δ, its [maximum degree](wikipedia://en/1374448); their proof leads to a polynomial time algorithm for finding an induced subgraph of this size.[^o13]

:::

## Adding edges to a planarization {#Adding_edges_to_a_planarization}

Once a large planar subgraph has been found, the incremental planarization process continues by considering the remaining edges one by one. As it does so, it maintains a planarization of the subgraph formed by the edges that have already been considered. It adds each new edge to a planar embedding of this subgraph, forming a drawing with crossings, and then replaces each crossing point with a new artificial vertex subdividing the two edges that cross.[^o2][^o3] In some versions of this procedure, the order for adding edges is arbitrary, but it is also possible to choose the ordering to be a [random permutation](https://en.wikipedia.org/wiki/Random_permutation), running the same algorithm several times and returning the best planarization that it finds.[^o2]

In the simplest form of this process, the planar embedding of the planarized subgraph is not allowed to change while new edges are added. In order to add each new edge in a way that minimizes the number of crossings it forms, one can use a [shortest path algorithm](https://en.wikipedia.org/wiki/Shortest_path_algorithm) in the [dual graph](wikipedia://en/2536864) of the current embedding, in order to find the shortest sequence of faces of the embedding and edges to be crossed that connects the endpoints of the new edge to each other. This process takes polynomial time per edge.[^o3]

Fixing the embedding of the planarized subgraph is not necessarily optimal in terms of the number of crossings that result. In fact, there exist graphs that are formed by adding one edge to a planar subgraph, where the optimal drawing has only two crossings but where fixing the planar embedding of the subgraph forces a linear number of crossings to be created.[^o2] As a compromise between finding the optimal planarization of a planar subgraph plus one edge, and keeping a fixed embedding, it is possible to search over all embeddings of the planarized subgraph and find the one that minimizes the number of crossings formed by the new edge.[^o2][^o15]
