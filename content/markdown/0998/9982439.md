# Graph enumeration

::: {#o1 .subject cue=lead name="Graph enumeration"}

*Image: Cayley's formula 2-4.svg.* The complete list of all [free trees](wikipedia://en/48560#Rooted_tree) on 2, 3, and 4 labeled vertices: $2^{2-2}=1$ tree with 2 vertices, $3^{3-2}=3$ trees with 3 vertices, and $4^{4-2}=16$ trees with 4 vertices.

In [combinatorics](wikipedia://en/5170), an area of [mathematics](wikipedia://en/18831), **graph enumeration** describes a class of [combinatorial enumeration](https://en.wikipedia.org/wiki/Combinatorial_enumeration) problems in which one must count [undirected](https://en.wikipedia.org/wiki/Undirected_graph) or [directed graphs](wikipedia://en/19721986) of certain types, typically as a function of the number of vertices of the graph.[^o2] These problems may be solved either exactly (as an [algebraic enumeration](wikipedia://en/212117) problem) or [asymptotically](wikipedia://en/641995). The pioneers in this area of mathematics were [George Pólya](https://en.wikipedia.org/wiki/George_Pólya),[^o3] [Arthur Cayley](wikipedia://en/311034) and [J. Howard Redfield](wikipedia://en/7095290).[^o5]

:::

## Labeled vs unlabeled problems {#Labeled_vs_unlabeled_problems}

In some graphical enumeration problems, the vertices of the graph are considered to be *labeled* in such a way as to be distinguishable from each other, while in other problems any permutation of the vertices is considered to form the same graph, so the vertices are considered identical or *unlabeled*. In general, labeled problems tend to be easier.[^o7] As with combinatorial enumeration more generally, the [Pólya enumeration theorem](wikipedia://en/4396962) is an important tool for reducing unlabeled problems to labeled ones: each unlabeled class is considered as a symmetry class of labeled objects.

The number of unlabelled graphs with $n$ vertices is still not known in a [closed-form solution](https://en.wikipedia.org/wiki/Closed-form_solution), but as almost all graphs are [asymmetric](wikipedia://en/20249418) this number is [asymptotic to](wikipedia://en/641995)[^o9]

$$\frac{2^{\tbinom{n}{2}}}{n!}.$$

## Exact enumeration formulas {#Exact_enumeration_formulas}

Some important results in this area include the following.

- The number of labeled *n*-vertex [simple undirected graphs](https://en.wikipedia.org/wiki/Simple_graph) is 2<sup>*n*(*n*−1)/2</sup>.[^o12]
- The number of labeled *n*-vertex [simple directed graphs](https://en.wikipedia.org/wiki/Simple_directed_graph) is 2<sup>*n*(*n*−1)</sup>.[^o13]
- The number *C<sub>n</sub>* of [connected](https://en.wikipedia.org/wiki/Connected_graph) labeled *n*-vertex undirected graphs satisfies the [recurrence relation](wikipedia://en/146806)[^o14]

$$C_n=2^{n\choose 2} - \frac{1}{n}\sum_{k=1}^{n-1} k{n\choose k} 2^{n-k\choose 2} C_k.$$

from which one may easily calculate, for *n* = 1, 2, 3, ..., that the values for *C<sub>n</sub>* are

1, 1, 4, 38, 728, 26704, 1866256, ...

- The number of labeled *n*-vertex [free trees](wikipedia://en/48560#Rooted_tree) is *n*<sup>*n*−2</sup> ([Cayley's formula](wikipedia://en/1266713)).
- The number of unlabeled *n*-vertex [caterpillars](wikipedia://en/27258886) is[^o15]

$$2^{n-4}+2^{\lfloor (n-4)/2\rfloor}.$$

:::

## Graph database {#Graph_database}

Various research groups have provided searchable database that lists graphs with certain properties of a small sizes. For example

- [The House of Graphs](https://houseofgraphs.org)
