# Nth-term test

Series

::: {#o1 .subject cue=lead name="Nth-term test"}

In [mathematics](wikipedia://en/18831), the ***n*th-term test for divergence**[^o2] is a simple test for the [divergence](wikipedia://en/876428) of an [infinite series](https://en.wikipedia.org/wiki/Infinite_series):

> If $\lim_{n \to \infty} a_n \neq 0$ or if the limit does not exist, then $\sum_{n=1}^\infty a_n$ diverges.

Many authors do not name this test or give it a shorter name.[^o3]

:::

When testing if a series converges or diverges, this test is often checked first due to its ease of use.

In the case of [p-adic analysis](wikipedia://en/291327) the term test is a necessary and sufficient condition for convergence due to the non-Archimedean [ultrametric triangle inequality](https://en.wikipedia.org/wiki/Ultrametric_triangle_inequality).

## Usage {#Usage}

Unlike stronger [convergence tests](wikipedia://en/4576951), the term test cannot prove by itself that a series [converges](wikipedia://en/1743431). In particular, the converse to the test is not true; instead all one can say is:

> If $\lim_{n \to \infty} a_n = 0,$ then $\sum_{n=1}^\infty a_n$ may or may not converge. In other words, if $\lim_{n \to \infty} a_n = 0,$ the test is inconclusive.

The [harmonic series](wikipedia://en/142488) is a classic example of a divergent series whose terms approach zero in the limit as $n \rightarrow \infty$.[^o5] The more general class of [*p*-series](wikipedia://en/142488),

$$\sum_{n=1}^\infty \frac{1}{n^p},$$

exemplifies the possible results of the test:

- If *p* ≤ 0, then the *n*th-term test identifies the series as divergent.
- If 0 \< *p* ≤ 1, then the *n*th-term test is inconclusive, but the series is divergent by the [integral test for convergence](wikipedia://en/454016).
- If 1 \< *p*, then the *n*th-term test is inconclusive, but the series is convergent by the integral test for convergence.

::: {#o7 .proof cue=heading name="Proofs"}

## Proofs {#Proofs}

The test is typically proven in [contrapositive](https://en.wikipedia.org/wiki/Contrapositive) form:

> If $\sum_{n=1}^\infty a_n$ converges, then $\lim_{n \to \infty} a_n = 0.$

### Limit manipulation {#Limit_manipulation}

If *s*<sub>*n*</sub> are the partial sums of the series, then the assumption that the series converges means that

$$\lim_{n\to\infty} s_n = L$$

for some number *L*. Then[^o9]

$$\lim_{n\to\infty} a_n = \lim_{n\to\infty}(s_n-s_{n-1}) = \lim_{n\to\infty} s_n - \lim_{n\to\infty} s_{n-1} = L-L = 0.$$

::: {#o11 .statement cue=named-heading name="Cauchy's criterion"}

### Cauchy's criterion {#Cauchy's_criterion}

Assuming that the series converges implies that it passes [Cauchy's convergence test](wikipedia://en/3738733): for every $\varepsilon>0$ there is a number *N* such that

$$\left|a_{n+1}+a_{n+2}+\cdots+a_{n+p}\right|<\varepsilon$$

holds for all *n* > *N* and *p* ≥ 1. Setting *p* = 1 recovers the claim[^o12]

$$\lim_{n\to\infty} a_n = 0.$$

:::

:::

## Scope {#Scope}

The simplest version of the term test applies to infinite series of [real numbers](wikipedia://en/20646438). The above two proofs, by invoking the Cauchy criterion or the linearity of the limit, also work in any other [normed vector space](wikipedia://en/21538)[^o14] or any additively written [abelian group](wikipedia://en/2974).
