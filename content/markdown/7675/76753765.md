# Chromatic symmetric function

::: {#o1 .subject cue=lead name="Chromatic symmetric function"}

The **chromatic symmetric function** is a [symmetric function](wikipedia://en/364460) [invariant](wikipedia://en/1126638) of [graphs](wikipedia://en/12401) studied in [algebraic graph theory](wikipedia://en/1620216), a branch of [mathematics](wikipedia://en/18831). It is the weight [generating function](wikipedia://en/160993) for proper [graph colorings](wikipedia://en/426743), and was originally introduced by [Richard Stanley](wikipedia://en/1633397) as a generalization of the [chromatic polynomial](wikipedia://en/1460126) of a graph.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a finite graph $G=(V,E)$ with vertex set $V=\{v_1,v_2,\ldots, v_n\}$, a *vertex coloring* is a function $\kappa:V\to C$ where $C$ is a set of colors. A vertex coloring is called *proper* if all adjacent vertices are assigned distinct colors (i.e., $\{i,j\}\in E \implies \kappa(i)\neq\kappa(j)$). The **chromatic symmetric function** denoted $X_G(x_1,x_2,\ldots)$ is defined to be the weight generating function of proper vertex colorings of $G$:[^o2][^o5]

$$X_G(x_1,x_2,\ldots):=\sum_{\underset{\text{proper}}{\kappa:V\to\mathbb{N}}}x_{\kappa(v_1)}x_{\kappa(v_2)}\cdots x_{\kappa(v_n)}$$

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

For $\lambda$ a [partition](wikipedia://en/104790), let $m_\lambda$ be the [monomial symmetric polynomial](wikipedia://en/1440207#Monomial_symmetric_polynomials) associated to $\lambda$.

### Example 1: complete graphs {#Example_1:_complete_graphs}

Consider the [complete graph](wikipedia://en/85816) $K_n$ on $n$ vertices:

- There are $n!$ ways to color $K_n$ with exactly $n$ colors yielding the term $n!x_1\cdots x_n$
- Since every pair of vertices in $K_n$ is adjacent, it can be properly colored with no fewer than $n$ colors.

Thus, $X_{K_n}(x_1,\ldots,x_n)=n!x_1\cdots x_n = n!m_{(1,\ldots,1)}$

### Example 2: a path graph {#Example_2:_a_path_graph}

Consider the [path graph](wikipedia://en/4587190) $P_3$ of length $3$:

- There are $3!$ ways to color $P_3$ with exactly $3$ colors, yielding the term $6x_1x_2x_3$
- For each pair of colors, there are $2$ ways to color $P_3$ yielding the terms $x_i^2x_j$ and $x_ix_j^2$ for $i\neq j$

Altogether, the chromatic symmetric function of $P_3$ is then given by:[^o5]

$$X_{P_3}(x_1,x_2,x_3) = 6x_1x_2x_3 + x_1^2x_2 + x_1x_2^2 + x_1^2x_3 + x_1x_3^2 + x_2^2x_3 + x_2x_3^2 = 6m_{(1,1,1)} + m_{(1,2)}$$

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Let $\chi_G$ be the chromatic polynomial of $G$, so that $\chi_G(k)$ is equal to the number of proper vertex colorings of $G$ using at most $k$ distinct colors. The values of $\chi_G$ can then be computed by [specializing](wikipedia://en/364460#Specializations) the chromatic symmetric function, setting the first $k$ variables $x_i$ equal to $1$ and the remaining variables equal to $0$:[^o2] $$X_G(1^k)=X_G(1,\ldots,1,0,0,\ldots)=\chi_G(k)$$
- If $G\amalg H$ is the disjoint union of two graphs, then the chromatic symmetric function for $G\amalg H$ can be written as a product of the corresponding functions for $G$ and $H$:[^o2] $$X_{G\amalg H}=X_G\cdot X_H$$
- A *stable partition* $\pi$ of $G$ is defined to be a [set partition](https://en.wikipedia.org/wiki/Set_partition) of vertices $V$ such that each block of $\pi$ is an [independent set](wikipedia://en/524501) in $G$. The type of a stable partition $\text{type}(\pi)$ is the partition consisting of parts equal to the sizes of the [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) of the vertex induced subgraphs. For a partition $\lambda\vdash n$, let $z_\lambda$ be the number of stable partitions of $G$ with $\text{type}(\pi)=\lambda=\langle1^{r_1}2^{r2}\ldots\rangle$. Then, $X_G$ expands into the augmented monomial symmetric functions, $\tilde{m}_\lambda:=r_1!r_2!\cdots m_\lambda$ with coefficients given by the number of stable partitions of $G$:[^o2] $$X_G=\sum_{\lambda\vdash n}z_\lambda \tilde{m}_\lambda$$
- Let $p_\lambda$ be the [power-sum symmetric function](wikipedia://en/1440207#Power-sum_symmetric_polynomials) associated to a partition $\lambda$. For $S\subseteq E$, let $\lambda(S)$ be the partition whose parts are the vertex sizes of the connected components of the edge-induced subgraph of $G$ specified by $S$. The chromatic symmetric function can be expanded in the power-sum symmetric functions via the following formula:[^o2] $$X_G=\sum_{S\subseteq E}(-1)^{|S|}p_{\lambda(S)}$$
- Let $X_G=\sum_{\lambda\vdash n}c_\lambda e_\lambda$ be the expansion of $X_G$ in the basis of [elementary symmetric functions](wikipedia://en/1440695) $e_\lambda$. Let $\text{sink}(G,s)$ be the number of [acyclic orientations](wikipedia://en/36619881) on the graph $G$ which contain exactly $s$ sinks. Then we have the following formula for the number of sinks:[^o2] $$\text{sink}(G,s)=\sum_{\underset{l(\lambda)=s}{\lambda\vdash n}}c_\lambda$$

:::

## Problems regarding the chromatic symmetric functions {#Problems_regarding_the_chromatic_symmetric_functions}

There are a number of questions regarding the chromatic symmetric function which have received substantial attention in the literature surrounding them.

::: {#o14 .statement kind=statement/conjecture cue=named-heading name="(3+1)-free conjecture"}

### (3+1)-free conjecture {#(3+1)-free_conjecture}

For a partition $\lambda$, let $e_\lambda$ be the elementary symmetric function associated to $\lambda$.

A [partially ordered set](wikipedia://en/23572) $P$ is called $(3+1)$*\-free* if it does not contain a subposet isomorphic to the direct sum of the $3$ element [chain](https://en.wikipedia.org/wiki/Chain_%28poset%29) and the $1$ element chain. The [incomparability graph](wikipedia://en/6978672) $\text{inc}(P)$ of a poset $P$ is the graph with vertices given by the elements of $P$ which includes an edge between two vertices if and only if their corresponding elements in $P$ are [incomparable](wikipedia://en/3834818). The following result was conjectured by [Stanley](wikipedia://en/1633397) and [Stembridge](https://en.wikipedia.org/wiki/John_Stembridge) in 1993 and proven by Tatsuyuki Hikita in 2024[^o15].

::: {#o16 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** (Hikita) Let $G$ be the incomparability graph of a $(3+1)$-free poset, then $X_G$ is $e$-positive.

A weaker positivity result is known for the case of expansions into the basis of [Schur functions](wikipedia://en/3147062).

:::

::: {#o17 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** (Gasharov) Let $G$ be the incomparability graph of a $(3+1)$-free poset, then $X_G$ is $s$-positive.[^o18]

In the proof of the theorem above, there is a combinatorial formula for the coefficients of the Schur expansion given in terms of *$P$-tableaux* which are a generalization of [semistandard Young tableaux](https://en.wikipedia.org/wiki/Semistandard_Young_tableaux) instead labelled with the elements of $P$.

:::

::: {#o20 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

There are a number of generalizations of the chromatic symmetric function:

- There is a [categorification](wikipedia://en/1596969) of the invariant into a [homology theory](https://en.wikipedia.org/wiki/Homology_theory) which is called *chromatic symmetric homology.*[^o21] This homology theory is known to be a stronger invariant than the chromatic symmetric function alone.[^o22] The chromatic symmetric function can also be defined for vertex-weighted graphs,[^o23] where it satisfies a [deletion-contraction](wikipedia://en/60656372) property analogous to that of the chromatic polynomial. If the theory of chromatic symmetric homology is generalized to vertex-weighted graphs as well, this deletion-contraction property lifts to a long exact sequence of the corresponding homology theory.[^o24]
- There is also a [quasisymmetric](wikipedia://en/29661763) refinement of the chromatic symmetric function which can be used to refine the formulae expressing $X_G$ in terms of Gessel's basis of fundamental quasisymmetric functions and the expansion in the basis of Schur functions.[^o25] Fixing an order for the set of vertices, the ascent set of a proper coloring $\kappa$ is defined to be $\text{asc}(\kappa)=\{\{i,j\}\in E:i<j \text{ and } \kappa(i)<\kappa(j)\}$. The *chromatic quasisymmetric function* of a graph $G$ is then defined to be:[^o25] $$X_G(x_1,x_2,\ldots;t):=\sum_{\underset{\text{proper}}{\kappa:V\to \mathbb{N}}}t^{|asc(\kappa)|}x_{\kappa(v_1)}\cdots x_{\kappa(v_n)}$$

:::
