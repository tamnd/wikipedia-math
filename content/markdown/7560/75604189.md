# Zhegalkin algebra

::: {#o1 .subject cue=lead name="Zhegalkin algebra"}

In mathematics, **Zhegalkin algebra** is a set of [Boolean functions](https://en.wikipedia.org/wiki/Boolean_functions) defined by the nullary operation taking the value $1$, use of the binary operation of [conjunction](wikipedia://en/18152) $\land$, and use of the [binary sum operation for modulo 2](wikipedia://en/105979) $\oplus$. The constant $0$ is introduced as $1 \oplus 1 = 0$.[^o2] The negation operation is introduced by the relation $\neg x = x \oplus 1$. The disjunction operation follows from the identity $x \lor y = x \land y \oplus x \oplus y$.[^o3]

:::

Using Zhegalkin Algebra, any perfect disjunctive normal form can be uniquely converted into a [Zhegalkin polynomial](https://en.wikipedia.org/wiki/Zhegalkin_polynomial) (via the Zhegalkin Theorem).

## Basic identities {#Basic_identities}

- $x \land ( y \land z) = (x \land y) \land z$, $x \land y = y \land x$
- $x \oplus ( y \oplus z) = (x \oplus y) \oplus z$, $x \oplus y = y \oplus x$
- $$x \oplus x = 0$$
- $$x \oplus 0 = x$$
- $$x \land ( y \oplus z) = x \land y \oplus x \land z$$

Thus, the basis of Boolean functions $\bigl\langle \wedge, \oplus, 1 \bigr\rangle$ is [functionally complete.](wikipedia://en/5279259)

Its inverse logical basis $\bigl\langle \lor, \odot, 0 \bigr\rangle$ is also functionally complete, where $\odot$ is the [inverse of the XOR operation](https://en.wikipedia.org/wiki/XNOR_gate) (via [equivalence](wikipedia://en/3092370)). For the inverse basis, the identities are inverse as well: $0 \odot 0 = 1$ is the output of a constant, $\neg x = x \odot 0$ is the output of the [negation operation](wikipedia://en/161019), and $x \land y = x \lor y \odot x \odot y$ is the [conjunction operation](wikipedia://en/18152).

The functional completeness of the two bases follows from completeness of the basis $\{\neg, \land, \lor\}$.
