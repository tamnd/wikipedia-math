# Limit point compact

::: {#o1 .subject cue=lead name="Limit point compact"}

In mathematics, a [topological space](wikipedia://en/30450) $X$ is said to be **limit point compact**[^o2][^o3] or **weakly countably compact**[^o3] if every infinite subset of $X$ has a [limit point](https://en.wikipedia.org/wiki/Limit_point) in $X.$ This property generalizes a property of [compact spaces](https://en.wikipedia.org/wiki/Compact_spaces). In a [metric space](wikipedia://en/20018), limit point compactness, compactness, and [sequential compactness](https://en.wikipedia.org/wiki/Sequential_compactness) are all equivalent. For general topological spaces, however, these three notions of compactness are not equivalent.

:::

## Properties and examples {#Properties_and_examples}

- In a topological space, subsets without limit point are exactly those that are closed and discrete in the subspace topology. So a space is limit point compact if and only if all its closed discrete subsets are finite.
- A space $X$ is not limit point compact if and only if it has an infinite closed discrete subspace. Since any subset of a closed discrete subset of $X$ is itself closed in $X$ and discrete, this is equivalent to require that $X$ has a countably infinite closed discrete subspace.
- Some examples of spaces that are not limit point compact: (1) The set $\mathbb{R}$ of all real numbers with its usual topology, since the integers are an infinite set but do not have a limit point in $\mathbb{R}$; (2) an infinite set with the discrete topology; (3) the [countable complement topology](https://en.wikipedia.org/wiki/Countable_complement_topology) on an uncountable set.
- Every [countably compact space](wikipedia://en/8293816) (and hence every compact space) is limit point compact.
- For [T<sub>1</sub> spaces](wikipedia://en/148721), limit point compactness is equivalent to countable compactness.
- An example of limit point compact space that is not countably compact is obtained by "doubling the integers", namely, taking the product $X = \mathbb{Z} \times Y$ where $\mathbb{Z}$ is the set of all integers with the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) and $Y = \{0,1\}$ has the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology). The space $X$ is homeomorphic to the [odd-even topology](https://en.wikipedia.org/wiki/Odd-even_topology).[^o5] This space is not [T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space). It is limit point compact because every nonempty subset has a limit point.
- An example of T<sub>0</sub> space that is limit point compact and not countably compact is $X = \mathbb{R},$ the set of all real numbers, with the [right order topology](wikipedia://en/213650#Left_and_right_order_topologies), i.e., the topology generated by all intervals $(x, \infty).$[^o6] The space is limit point compact because given any point $a \in X,$ every $x<a$ is a limit point of $\{a\}.$
- For metrizable spaces, compactness, countable compactness, limit point compactness, and [sequential compactness](wikipedia://en/8293820) are all equivalent.
- Closed subspaces of a limit point compact space are limit point compact.
- The continuous image of a limit point compact space need not be limit point compact. For example, if $X = \mathbb{Z} \times Y$ with $\mathbb{Z}$ discrete and $Y$ indiscrete as in the example above, the map $f = \pi_{\mathbb{Z}}$ given by projection onto the first coordinate is continuous, but $f(X) = \mathbb{Z}$ is not limit point compact.
- A limit point compact space need not be [pseudocompact](https://en.wikipedia.org/wiki/Pseudocompact). An example is given by the same $X = \mathbb{Z} \times Y$ with $Y$ indiscrete two-point space and the map $f = \pi_{\mathbb{Z}},$ whose image is not bounded in $\mathbb{R}.$
- A limit point compact space need not be [compact](wikipedia://en/6042). The [integers](https://en.wikipedia.org/wiki/Integers) with the topology having the basis $\mathcal{B} = \{ \{2n, 2n+1\} : n \in \mathbb{Z} \}$ serve as an example of this fact.[^o7]
- A pseudocompact space need not be limit point compact. An example is given by an uncountable set with the [cocountable topology](wikipedia://en/801246).
- Every normal pseudocompact space is limit point compact.[^o8] *Proof*: Suppose $X$ is a normal space that is not limit point compact. There exists a countably infinite closed discrete subset $A = \{x_1, x_2, x_3, \ldots\}$ of $X.$ By the [Tietze extension theorem](wikipedia://en/31404) the continuous function $f$ on $A$ defined by $f(x_n) = n$ can be extended to an (unbounded) real-valued continuous function on all of $X.$ So $X$ is not pseudocompact.
- Limit point compact spaces have countable [extent](wikipedia://en/14189688#Cardinal_functions_in_topology).
- If $(X, \tau)$ and $(X, \sigma)$ are topological spaces with $\sigma$ finer than $\tau$ and $(X, \sigma)$ is limit point compact, then so is $(X, \tau).$
