# Lomax distribution

::: {#o1 .subject cue=lead name="Lomax distribution"}

The **Lomax distribution**, conditionally also called the **[Pareto Type II distribution](wikipedia://en/53057#Pareto_types_I–IV)**, is a [heavy-tail](https://en.wikipedia.org/wiki/Heavy_tail) [probability distribution](wikipedia://en/23543) used in business, economics, actuarial science, queueing theory and Internet traffic modeling.[^o2][^o3][^o4][^o20] It is named after K. S. Lomax. It is essentially a [Pareto distribution](wikipedia://en/53057) that has been shifted so that its support begins at zero.[^o5]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Characterization"}

## Characterization {#Characterization}

### Probability density function {#Probability_density_function}

The [probability density function](wikipedia://en/43487) (pdf) for the Lomax distribution is given by

$$p(x) = \frac\alpha\lambda \left(1 + \frac x\lambda \right)^{-(\alpha+1)}, \qquad x \geq 0,$$

with shape parameter $\alpha > 0$ and scale parameter $\lambda > 0$. The density can be rewritten in such a way that more clearly shows the relation to the [Pareto Type I distribution](wikipedia://en/53057). That is:

$$p(x) = \frac{\alpha\lambda^\alpha}{(x + \lambda)^{\alpha+1}}.$$

### Non-central moments {#Non-central_moments}

The $\nu$th non-central moment $E\left[X^\nu\right]$ exists only if the shape parameter $\alpha$ strictly exceeds $\nu$, when the moment has the value

$$E\left(X^\nu\right) = \frac{\lambda^\nu \Gamma(\alpha - \nu)\Gamma(1 + \nu)}{\Gamma(\alpha)}.$$

:::

## Related distributions {#Related_distributions}

### Relation to the Pareto distribution {#Relation_to_the_Pareto_distribution}

The Lomax distribution is a [Pareto Type I distribution](wikipedia://en/53057) shifted so that its support begins at zero. Specifically:

$$\text{If } Y \sim \operatorname{Pareto}(x_m = \lambda, \alpha), \text{ then } Y - x_m \sim \operatorname{Lomax}(\alpha,\lambda).$$

The Lomax distribution is a [Pareto Type II distribution](wikipedia://en/53057#Pareto_types_I–IV) with *x*<sub>*m*</sub> = *λ* and *μ* = 0:[^o12]

$$\text{If } X \sim \operatorname{Lomax}(\alpha, \lambda) \text{ then } X \sim \text{P(II)}\left(x_m = \lambda, \alpha, \mu = 0\right).$$

### Relation to the generalized Pareto distribution {#Relation_to_the_generalized_Pareto_distribution}

The Lomax distribution is a special case of the [generalized Pareto distribution](wikipedia://en/8599355). Specifically:

$$\mu = 0,~ \xi = {1 \over \alpha},~ \sigma = {\lambda \over \alpha} .$$

### Relation to the beta prime distribution {#Relation_to_the_beta_prime_distribution}

The Lomax distribution with scale parameter *λ* = 1 is a special case of the [beta prime distribution](wikipedia://en/3126406). If *X* has a Lomax distribution, then $\frac{X}{\lambda} \sim \beta^\prime(1, \alpha)$.

### Relation to the F distribution {#Relation_to_the_F_distribution}

The Lomax distribution with shape parameter *α* = 1 and scale parameter *λ* = 1 has density $f(x) = \frac{1}{(1 + x)^2}$, the same distribution as an [*F*(2,2) distribution](wikipedia://en/332116). This is the distribution of the ratio of two independent and identically distributed random variables with [exponential distributions](wikipedia://en/45906).

### Relation to the q-exponential distribution {#Relation_to_the_q-exponential_distribution}

The Lomax distribution is a special case of the [q-exponential distribution](wikipedia://en/32195081). The q-exponential extends this distribution to support on a bounded interval. The Lomax parameters are given by:

$$\alpha = {{2 - q} \over {q - 1}}, ~ \lambda = {1 \over \lambda_q(q - 1)} .$$

### Relation to the logistic distribution {#Relation_to_the_logistic_distribution}

The logarithm of a Lomax(shape = 1.0, scale = *λ*)-distributed variable follows a [logistic distribution](wikipedia://en/542666) with location log(*λ*) and scale 1.0.

### Gamma-exponential (scale-) mixture connection {#Gamma-exponential_(scale-)_mixture_connection}

The Lomax distribution arises as a [mixture](wikipedia://en/28897820) of [exponential distributions](wikipedia://en/45906) where the mixing distribution of the rate is a [gamma distribution](wikipedia://en/207079). If *λ* | *k*,*θ* ~ Gamma(shape = *k*, scale = *θ*) and *X* | *λ* ~ Exponential(rate = *λ*) then the marginal distribution of *X* | *k*,*θ* is Lomax(shape = *k*, scale = 1/*θ*). Since the [rate parameter](https://en.wikipedia.org/wiki/Rate_parameter) may equivalently be reparameterized to a [scale parameter](wikipedia://en/769503), the Lomax distribution constitutes a **[scale mixture](https://en.wikipedia.org/wiki/Scale_mixture)** of exponentials (with the [exponential](wikipedia://en/45906) [scale parameter](wikipedia://en/769503) following an [inverse-gamma distribution](wikipedia://en/1653565)).

### Relation to the gamma distribution {#Relation_to_the_gamma_distribution}

Let $X \sim \operatorname{Exp}(1)$ and $Y \sim \operatorname{Gamma}(\alpha,1)$, then $X/Y \sim \operatorname{Lomax}(\alpha,1).$[^o20]
