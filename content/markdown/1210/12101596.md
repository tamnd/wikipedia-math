# Convolution power

::: {#o1 .subject cue=lead name="Convolution power"}

In [mathematics](wikipedia://en/18831), the **convolution power** is the *n*-fold iteration of the [convolution](wikipedia://en/7519) with itself. Thus if $x$ is a [function](wikipedia://en/185427) on [Euclidean space](wikipedia://en/9697) **R**<sup>*d*</sup> and $n$ is a [natural number](wikipedia://en/21474), then the convolution power is defined by

:::

$$x^{*n} = \underbrace{x * x * x * \cdots * x * x}_n,\quad x^{*0}=\delta_0$$

where **∗** denotes the convolution operation of functions on **R**<sup>*d*</sup> and δ<sub>0</sub> is the [Dirac delta distribution](https://en.wikipedia.org/wiki/Dirac_delta_distribution). This definition makes sense if *x* is an [integrable](https://en.wikipedia.org/wiki/Integrable) function (in [L<sup>1</sup>](wikipedia://en/45194)), a rapidly decreasing [distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) (in particular, a compactly supported distribution) or is a finite [Borel measure](wikipedia://en/4322).

If *x* is the distribution function of a [random variable](wikipedia://en/25685) on the real line, then the *n*<sup>th</sup> convolution power of *x* gives the distribution function of the sum of *n* independent random variables with identical distribution *x*. The [central limit theorem](wikipedia://en/39406) states that if *x* is in L<sup>1</sup> and L<sup>2</sup> with mean zero and variance σ<sup>2</sup>, then

$$P\left(\frac{x^{*n}}{\sigma\sqrt{n}} < \beta\right) \to \Phi(\beta)\quad\rm{as}\ n\to\infty$$

where Φ is the cumulative [standard normal distribution](https://en.wikipedia.org/wiki/Standard_normal_distribution) on the real line. Equivalently, $x^{*n}/\sigma\sqrt{n}$ tends weakly to the standard normal distribution.

In some cases, it is possible to define powers *x*<sup>\**t*</sup> for arbitrary real *t* > 0. If μ is a [probability measure](wikipedia://en/45437), then μ is [infinitely divisible](wikipedia://en/13588803) provided there exists, for each positive integer *n*, a probability measure μ<sub>1/*n*</sub> such that

$$\mu_{1/n}^{* n} = \mu.$$

That is, a measure is infinitely divisible if it is possible to define all *n*th roots. Not every probability measure is infinitely divisible, and a characterization of infinitely divisible measures is of central importance in the abstract theory of [stochastic processes](wikipedia://en/47895). Intuitively, a measure should be infinitely divisible provided it has a well-defined "convolution logarithm." The natural candidate for measures having such a logarithm are those of (generalized) [Poisson](https://en.wikipedia.org/wiki/Poisson_process) type, given in the form

$$\pi_{\alpha,\mu} = e^{-\alpha}\sum_{n=0}^\infty \frac{\alpha^n}{n!}\mu^{*n}.$$

In fact, the [Lévy–Khinchin theorem](https://en.wikipedia.org/wiki/Lévy–Khinchin_theorem) states that a necessary and sufficient condition for a measure to be infinitely divisible is that it must lie in the closure, with respect to the [vague topology](wikipedia://en/15393951), of the class of Poisson measures (Stroock 1993, §3.2).

Many applications of the convolution power rely on being able to define the analog of [analytic functions](wikipedia://en/61478) as [formal power series](wikipedia://en/60012) with powers replaced instead by the convolution power. Thus if $\textstyle{F(z) = \sum_{n=0}^\infty a_n z^n}$ is an analytic function, then one would like to be able to define

$$F^*(x) = a_0\delta_0 + \sum_{n=1}^\infty a_n x^{*n}.$$

If *x* ∈ *L*<sup>1</sup>(**R**<sup>*d*</sup>) or more generally is a finite Borel measure on **R**<sup>*d*</sup>, then the latter series converges absolutely in norm provided that the norm of *x* is less than the radius of convergence of the original series defining *F*(*z*). In particular, it is possible for such measures to define the **convolutional exponential**

$$\exp^*(x) = \delta_0 + \sum_{n=1}^\infty \frac{x^{*n}}{n!}.$$

It is not generally possible to extend this definition to arbitrary distributions, although a class of distributions on which this series still converges in an appropriate weak sense is identified by (Ben Chrouda El Oued Ouerdiane 2002).

## Properties {#Properties}

If *x* is itself suitably differentiable, then from the [properties](wikipedia://en/7519#Differentiation) of convolution, one has

$$\mathcal{D}\big\{x^{*n}\big\} = (\mathcal{D}x) * x^{*(n-1)} = x * \mathcal{D}\big\{x^{*(n-1)}\big\}$$

where $\mathcal{D}$ denotes the [derivative](wikipedia://en/7921) operator. Specifically, this holds if *x* is a compactly supported distribution or lies in the [Sobolev space](wikipedia://en/611964) *W*<sup>1,1</sup> to ensure that the derivative is sufficiently regular for the convolution to be well-defined.

:::

## Applications {#Applications}

In the configuration random graph, the size distribution of [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) can be expressed via the convolution power of the excess [degree distribution](wikipedia://en/2129782) ((Kryven 2017)):

$$w(n)=\begin{cases} \frac{\mu_1}{n-1} u_1^{*n}(n-2),& n>1, \\ u(0) & n=1. \end{cases}$$

Here, $w(n)$ is the size distribution for connected components, $u_1(k) = \frac{k+1}{\mu_1} u(k+1),$ is the excess degree distribution, and $u(k)$ denotes the [degree distribution](wikipedia://en/2129782).

As [convolution algebras](https://en.wikipedia.org/wiki/Convolution_algebra) are special cases of [Hopf algebras](wikipedia://en/325714), the convolution power is a special case of the (ordinary) power in a Hopf algebra. In applications to [quantum field theory](wikipedia://en/25267), the convolution exponential, convolution logarithm, and other analytic functions based on the convolution are constructed as formal power series in the elements of the algebra (Brouder Frabetti Patras 2008). If, in addition, the algebra is a [Banach algebra](wikipedia://en/4665), then convergence of the series can be determined as above. In the formal setting, familiar identities such as

$$x = \log^*(\exp^*x) = \exp^*(\log^*x)$$

continue to hold. Moreover, by the permanence of functional relations, they hold at the level of functions, provided all expressions are well-defined in an open set by convergent series.
