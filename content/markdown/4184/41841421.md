# Tor2web

::: {#o3 .subject cue=lead name="Tor2web"}

**Tor2web** (pronounced "Tor to Web") is a software project to allow [Tor hidden services](https://en.wikipedia.org/wiki/List_of_Tor_onion_services) to be accessed from a standard [browser](https://en.wikipedia.org/wiki/Web_browser) without being connected to the [Tor network](wikipedia://en/20556944). It was created by [Aaron Swartz](https://en.wikipedia.org/wiki/Aaron_Swartz) and [Virgil Griffith](https://en.wikipedia.org/wiki/Virgil_Griffith).[^o4]

:::

## History {#History}

Tor is a network which enables people to use the Internet anonymously (though with known [weaknesses](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29#Attacks_and_limitations)) and to publish content on "hidden services", which exist only within the Tor network for security reasons and thus are typically only accessible to the relatively small number of people using a Tor-connected web browser. [Aaron Swartz](https://en.wikipedia.org/wiki/Aaron_Swartz) and [Virgil Griffith](https://en.wikipedia.org/wiki/Virgil_Griffith) developed Tor2web in 2008 as a way to support [whistleblowing](https://en.wikipedia.org/wiki/Whistleblowing) and other forms of [anonymous](https://en.wikipedia.org/wiki/Anonymity) [publishing](https://en.wikipedia.org/wiki/Web_publishing) through Tor, allowing materials to remain anonymous while making them accessible to a broader audience.[^o2][^o6] In an interview with *[Wired](https://en.wikipedia.org/wiki/Wired_%28magazine%29)* Swartz explained that Tor is great for anonymous publishing, but because its focus is not user-friendliness and thus not many people would install it, he wanted to "produce this hybrid where people could publish stuff using Tor and make it so that anyone on the internet could view it".[^o4]

The software developed by Swartz and Griffith is today considered version 1.0. Since then, it has been maintained and developed by Giovanni Pellerano from the [Hermes Center for Transparency and Digital Human Rights](https://en.wikipedia.org/wiki/Hermes_Center_for_Transparency_and_Digital_Human_Rights) as part of the [GlobaLeaks Project](https://en.wikipedia.org/wiki/GlobaLeaks), with financial support from the [Open Technology Fund](wikipedia://en/49417443). Version 2.0 was released in August 2011, and version 3.0 is in beta .[^o7]

## Operation and security {#Operation_and_security}

Rather than typical [top-level domains](https://en.wikipedia.org/wiki/Top-level_domain) like `.com`, `.org`, or `.net`, hidden service [URLs](https://en.wikipedia.org/wiki/URL) end with `[[.onion]]` and are only accessible when connected to Tor. Tor2web acts as a specialized [proxy](https://en.wikipedia.org/wiki/HTTP_proxy) or [middleman](https://en.wikipedia.org/wiki/Intermediary) between hidden services and users, making them visible to people who are not connected to Tor. To do so, a user takes the URL of a hidden service and replaces `.onion` with `.onion.to`.

Like Tor, Tor2web operates using servers run voluntarily by an open community of individuals and organizations.

Tor2web preserves the anonymity of content publishers but is not itself an anonymity tool and does not offer any protection to users beyond relaying data using [HTTP Secure](https://en.wikipedia.org/wiki/HTTP_Secure) (HTTPS).[^o9] Since version 2.0, a privacy and security warning is added to the header of each web page it fetches, encouraging readers to use the [Tor Browser](https://en.wikipedia.org/wiki/Tor_Browser) to obtain anonymity.
