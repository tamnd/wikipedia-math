# Ağrı Subregion

::: {#o2 .subject cue=lead name="Ağrı Subregion"}

The **Ağrı Subregion** ([Turkish](https://en.wikipedia.org/wiki/Turkish_language): *Ağrı Alt Bölgesi*) (TRA2) is a statistical subregion in [Turkey](https://en.wikipedia.org/wiki/Turkey).

:::

## Provinces {#Provinces}

- [Ağrı Province](https://en.wikipedia.org/wiki/Ağrı_Province) (TRA21)
- [Kars Province](https://en.wikipedia.org/wiki/Kars_Province) (TRA22)
- [Iğdır Province](https://en.wikipedia.org/wiki/Iğdır_Province) (TRA23)
- [Ardahan Province](https://en.wikipedia.org/wiki/Ardahan_Province) (TRA24)
