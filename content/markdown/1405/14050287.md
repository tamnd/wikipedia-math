# CEILIDH

::: {#o1 .subject cue=lead name="CEILIDH"}

**CEILIDH** is a [public key](https://en.wikipedia.org/wiki/Public_key) [cryptosystem](wikipedia://en/506383) based on the [discrete logarithm problem](https://en.wikipedia.org/wiki/Discrete_logarithm_problem) in [algebraic torus](wikipedia://en/504697). This idea was first introduced by [Alice Silverberg](wikipedia://en/44807694) and [Karl Rubin](https://en.wikipedia.org/wiki/Karl_Rubin) in 2003; Silverberg named CEILIDH after her cat.[^o2][^o3] The main advantage of the system is the reduced size of the keys for the same security over basic schemes.

:::

## Algorithms {#Algorithms}

### Parameters {#Parameters}

- Let $q$ be a prime power.
- An [integer](wikipedia://en/14563) $n$ is chosen such that :
  - The torus $T_n$ has an explicit rational parametrization.
  - $\Phi_n(q)$ is divisible by a big prime $l$ where $\Phi_n$ is the $n^\mathrm{th}$ [Cyclotomic polynomial](wikipedia://en/171992).
- Let $m=\phi(n)$ where $\phi$ is the [Euler function](wikipedia://en/2319945).
- Let $\rho \colon T_n(\mathbb{F}_q) \rightarrow {\mathbb{F}_q}^m$ a birational map and its inverse $\psi$.
- Choose $\alpha \in T_n$ of order $l$ and let $g=\rho(\alpha)$.

### Key agreement scheme {#Key_agreement_scheme}

This Scheme is based on the [Diffie-Hellman key agreement](https://en.wikipedia.org/wiki/Diffie-Hellman_key_agreement).

- Alice chooses a random number $a\ \pmod{\Phi_n(q)}$.
- She computes $P_A= \rho(\psi(g)^a) \in \mathbb{F}_q^m$ and sends it to Bob.
- Bob chooses a random number $b\ \pmod{\Phi_n(q)}$.
- He computes $P_B= \rho(\psi(g)^b) \in \mathbb{F}_q^m$ and sends it to Alice.
- Alice computes $\rho(\psi(P_B)^a) \in \mathbb{F}_q^m$
- Bob computes $\rho(\psi(P_A)^b) \in \mathbb{F}_q^m$

$\psi \circ \rho$ is the identity, thus we have: $\rho(\psi(P_B)^a) = \rho(\psi(P_A)^b) = \rho(\psi(g)^{ab})$, which is the shared secret of Alice and Bob.

### Encryption scheme {#Encryption_scheme}

This scheme is based on the [ElGamal encryption](wikipedia://en/59458).

- **Key Generation**
  - Alice chooses a random number $a\ \pmod{ \Phi_n(q)}$ as her private key.
  - The resulting public key is $P_A= \rho(\psi(g)^a) \in \mathbb{F}_q^m$.
- **Encryption**
  - The message $M$ is an element of $\mathbb{F}_q^m$.
  - Bob chooses a random integer $k$ in the range $1\leq k \leq l-1$.
  - Bob computes $\gamma = \rho(\psi(g)^k) \in \mathbb{F}_q^m$ and $\delta = \rho(\psi(M)\psi(P_A)^k) \in \mathbb{F}_q^m$.
  - Bob sends the ciphertext $(\gamma,\delta)$ to Alice.
- **Decryption**
  - Alice computes $M = \rho(\psi(\delta)\psi(\gamma)^{-a})$.

:::

## Security {#Security}

The CEILIDH scheme is based on the ElGamal scheme and thus has similar security properties.

If the [computational Diffie-Hellman assumption](https://en.wikipedia.org/wiki/Computational_Diffie-Hellman_assumption) holds the underlying cyclic group $G$, then the encryption function is [one-way](wikipedia://en/363890).[^o10] If the [decisional Diffie-Hellman assumption](https://en.wikipedia.org/wiki/Decisional_Diffie-Hellman_assumption) (DDH) holds in $G$, then CEILIDH achieves [semantic security](wikipedia://en/960585).[^o10] Semantic security is not implied by the computational Diffie-Hellman assumption alone.[^o11] See [decisional Diffie-Hellman assumption](https://en.wikipedia.org/wiki/Decisional_Diffie-Hellman_assumption) for a discussion of groups where the assumption is believed to hold.

CEILIDH encryption is unconditionally [malleable](wikipedia://en/87027), and therefore is not secure under [chosen ciphertext attack](https://en.wikipedia.org/wiki/Chosen_ciphertext_attack). For example, given an encryption $(c_1, c_2)$ of some (possibly unknown) message $m$, one can easily construct a valid encryption $(c_1, 2 c_2)$ of the message $2m$.
