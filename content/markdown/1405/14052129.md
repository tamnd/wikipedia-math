# Graphics Layout Engine

::: {#o2 .subject cue=lead name="Graphics Layout Engine"}

**Graphics Layout Engine** (GLE) is a [graphics](https://en.wikipedia.org/wiki/Graphic) [scripting language](https://en.wikipedia.org/wiki/Scripting_language) designed for creating publication quality [graphs](https://en.wikipedia.org/wiki/Graphics), plots, [diagrams](https://en.wikipedia.org/wiki/Diagram), figures and slides.[^o3][^o4] GLE supports various graph types such as function plots, [histograms](wikipedia://en/13266), [bar graphs](wikipedia://en/393311), [scatter plots](https://en.wikipedia.org/wiki/Scatterplot), [contour lines](wikipedia://en/650086), color maps and surface plots through a simple but flexible set of graphing commands. More complex output can be created by relying on GLE's scripting language, which is full featured with [subroutines](https://en.wikipedia.org/wiki/Subroutine), [variables](https://en.wikipedia.org/wiki/Variable_%28programming%29), and [logic control](https://en.wikipedia.org/wiki/Logic_control). GLE relies on [LaTeX](https://en.wikipedia.org/wiki/LaTeX) for text output and supports mathematical formula in graphs and figures. GLE's output formats include [EPS](https://en.wikipedia.org/wiki/Encapsulated_PostScript), [PS](https://en.wikipedia.org/wiki/PostScript), [PDF](https://en.wikipedia.org/wiki/Portable_Document_Format), [JPEG](https://en.wikipedia.org/wiki/JPEG), and [PNG](https://en.wikipedia.org/wiki/Portable_Network_Graphics).

:::

The GLE software dates back to the early 1990s[^o5] and it is still under active development. Currently, GLE development is hosted on [GitHub](https://en.wikipedia.org/wiki/GitHub).[^o6]

## Platforms {#Platforms}

GLE is available for all major operating systems including [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [Mac&nbsp;OS&nbsp;X](https://en.wikipedia.org/wiki/Mac&nbsp;OS&nbsp;X), and [Unix](https://en.wikipedia.org/wiki/Unix). It is included in [Linux](https://en.wikipedia.org/wiki/Linux) distributions such as [Debian](https://en.wikipedia.org/wiki/Debian),[^o8] [Fedora](https://en.wikipedia.org/wiki/Fedora_%28operating_system%29),[^o9] and [SUSE](https://en.wikipedia.org/wiki/SUSE_Linux).[^o10]
