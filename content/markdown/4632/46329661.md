# Rayleigh test

::: {#o1 .subject cue=lead name="Rayleigh test"}

**Rayleigh test** can refer to:

:::

- a test for periodicity in irregularly sampled data,[^o2]
- a derivation of the above to test for non-uniformity (as unimodal clustering) of a set of points on a circle (e.g. compass directions),[^o3] sometimes known as the Rayleigh *z* test.[^o4]
