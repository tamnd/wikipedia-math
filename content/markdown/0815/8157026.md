# Tarjan's algorithm

::: {#o1 .subject cue=lead name="Tarjan's algorithm"}

**Tarjan's algorithm** may refer to one of several algorithms attributed to [Robert Tarjan](https://en.wikipedia.org/wiki/Robert_Tarjan), including:

:::

- [Tarjan's strongly connected components algorithm](wikipedia://en/8244667)
- [Tarjan's off-line lowest common ancestors algorithm](wikipedia://en/243227)
- Tarjan's algorithm for finding [bridges](wikipedia://en/1305071) in an undirected graph[^o2]
- Tarjan's algorithm for finding [simple circuits](wikipedia://en/168609#Definitions) in a directed graph[^o3]
