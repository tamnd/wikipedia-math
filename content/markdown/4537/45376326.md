# Buchstab function

::: {#o1 .subject cue=lead name="Buchstab function"}

*Image: Buchstab-function-graph-from-1-to-4.png.* Graph of the Buchstab function *ω*(*u*) from *u* = 1 to *u* = 4.

The **Buchstab function** (or **Buchstab's function**) is the unique continuous function $\omega: \mathbb{R}_{\ge 1}\rightarrow \mathbb{R}_{>0}$ defined by the [delay differential equation](wikipedia://en/3941333)

:::

$$\omega(u)=\frac 1 u, \qquad\qquad\qquad 1\le u\le 2,$$

$${\frac{d}{du}} (u\omega(u))=\omega(u-1), \qquad u\ge 2.$$

In the second equation, the derivative at *u* = 2 should be taken as *u* approaches 2 from the right. It is named after [Alexander Buchstab](wikipedia://en/45421432), who wrote about it in 1937.

## Asymptotics {#Asymptotics}

The Buchstab function approaches $e^{-\gamma} \approx 0.561$ rapidly as $u\to\infty,$ where $\gamma$ is the [Euler–Mascheroni constant](https://en.wikipedia.org/wiki/Euler–Mascheroni_constant). In fact,

$$|\omega(u)-e^{-\gamma}|\le \frac{\rho(u-1)}{u}, \qquad u\ge 1,$$

where *ρ* is the [Dickman function](wikipedia://en/7635648).[^o3] Also, $\omega(u)-e^{-\gamma}$ oscillates in a regular way, alternating between extrema and zeroes; the extrema alternate between positive maxima and negative minima. The interval between consecutive extrema approaches 1 as *u* approaches infinity, as does the interval between consecutive zeroes.[^o4]

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

The Buchstab function is used to count [rough numbers](wikipedia://en/7375449). If Φ(*x*, *y*) is the number of positive integers less than or equal to *x* with no prime factor less than *y*, then for any fixed *u* > 1,

$$\Phi(x,x^{1/u}) \sim \omega(u)\frac{x}{\log x^{1/u}}, \qquad x\to\infty.$$

:::
