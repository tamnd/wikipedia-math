# Lapped transform

::: {#o1 .subject cue=lead name="Lapped transform"}

In [signal processing](wikipedia://en/29324), a **lapped transform** is a type of [linear](https://en.wikipedia.org/wiki/Linear_transformation) [discrete block transformation](wikipedia://en/30545311) where the [basis functions](wikipedia://en/50909) of the transformation overlap the block boundaries, yet the number of coefficients overall resulting from a series of overlapping block transforms remains the same as if a non-overlapping block transform had been used.[^o2][^o3][^o4][^o5]

:::

Lapped transforms substantially reduce the blocking artifacts that otherwise occur with block transform coding techniques, in particular those using the [discrete cosine transform](wikipedia://en/59962). The best known example is the [modified discrete cosine transform](https://en.wikipedia.org/wiki/Modified_discrete_cosine_transform) used in the [MP3](https://en.wikipedia.org/wiki/MP3), [Vorbis](https://en.wikipedia.org/wiki/Vorbis), [AAC](https://en.wikipedia.org/wiki/Advanced_Audio_Coding), and [Opus](https://en.wikipedia.org/wiki/Opus_%28codec%29) [audio codecs](https://en.wikipedia.org/wiki/Audio_codec).[^o6]

Although the best-known application of lapped transforms has been for audio coding, they have also been used for video and image coding and various other applications. They are used in video coding for coding [I-frames](https://en.wikipedia.org/wiki/I-frames) in [VC-1](https://en.wikipedia.org/wiki/VC-1) and for image coding in the [JPEG XR](https://en.wikipedia.org/wiki/JPEG_XR) format. More recently, a form of lapped transform has also been used in the development of the [Daala](https://en.wikipedia.org/wiki/Daala_%28video_codec%29) [video coding format](https://en.wikipedia.org/wiki/Video_coding_format).[^o6]
