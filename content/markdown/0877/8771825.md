# Kernel regression

::: {#o1 .subject cue=lead name="Kernel regression"}

In [statistics](wikipedia://en/26685), **kernel regression** is a [non-parametric](https://en.wikipedia.org/wiki/Non-parametric) technique to estimate the [conditional expectation](wikipedia://en/435099) of a [random variable](wikipedia://en/25685). The objective is to find a non-linear relation between a pair of random variables ***X*** and ***Y***.

:::

In any [nonparametric regression](wikipedia://en/4536068), the [conditional expectation](wikipedia://en/435099) of a variable $Y$ relative to a variable $X$ may be written:

$$\operatorname{E}(Y \mid X) = m(X)$$

where $m$ is an unknown function.

## Nadaraya–Watson kernel regression {#Nadaraya–Watson_kernel_regression}

[Nadaraya](wikipedia://en/69695543) and [Watson](wikipedia://en/7688869), both in 1964, proposed to estimate $m$ as a locally weighted average, using a [kernel](wikipedia://en/8771473) as a weighting function.[^o3][^o4][^o5] The Nadaraya–Watson estimator is:

$$\widehat{m}_h(x)=\frac{\sum_{i=1}^n K_h(x-x_i) y_i}{\sum_{i=1}^nK_h(x-x_i)}$$

where $K_h(t) = \frac{1}{h}K\left(\frac{t}{h}\right)$ is a kernel with a bandwidth $h$ such that $K(\cdot)$ is of order at least 1, that is $\int_{-\infty}^\infty u K(u) \, du = 0$.

### Derivation {#Derivation}

Starting with the definition of [conditional expectation](wikipedia://en/435099),

$$\operatorname{E}(Y \mid X=x) = \int y f(y\mid x) \, dy = \int y \frac{f(x,y)}{f(x)} \, dy$$

we estimate the joint distributions *f*(*x*,*y*) and *f*(*x*) using [kernel density estimation](wikipedia://en/2090057) with a kernel ***K***:

$$\hat{f}(x,y) = \frac{1}{n}\sum_{i=1}^n K_h(x-x_i) K_h(y-y_i),$$

$$\hat{f}(x) = \frac{1}{n} \sum_{i=1}^n K_h(x-x_i),$$

We get:

$$\begin{aligned} \operatorname{\hat E}(Y \mid X=x) &= \int y \frac{\hat{f}(x,y)}{\hat{f}(x)} \, dy,\\[6pt] &= \int y \frac{\sum_{i=1}^n K_h(x-x_i) K_h(y-y_i)}{\sum_{j=1}^n K_h(x-x_j)} \,dy,\\[6pt] &= \frac{\sum_{i=1}^n K_h(x-x_i) \int y \, K_h(y-y_i) \,dy}{\sum_{j=1}^n K_h(x-x_j)},\\[6pt] &= \frac{\sum_{i=1}^n K_h(x-x_i) y_i}{\sum_{j=1}^n K_h(x-x_j)}, \end{aligned}$$

which is the Nadaraya–Watson estimator.

## Priestley–Chao kernel estimator {#Priestley–Chao_kernel_estimator}

$$\widehat{m}_{PC}(x) = h^{-1} \sum_{i=2}^n (x_i - x_{i-1}) K\left(\frac{x-x_i}{h}\right) y_i$$

where $h$ is the bandwidth (or smoothing parameter).

## Gasser–Müller kernel estimator {#Gasser–Müller_kernel_estimator}

$$\widehat{m}_{GM}(x) = h^{-1} \sum_{i=1}^n \left[\int_{s_{i-1}}^{s_i} K\left(\frac{x-u}{h}\right) \, du\right] y_i$$

where $s_i = \frac{x_{i-1} + x_i}{2}.$[^o9]

## Example {#Example}

*Image: cps71 lc mean.png.* Estimated regression function.

This example is based upon Canadian cross-section wage data consisting of a random sample taken from the 1971 Canadian Census Public Use Tapes for male individuals having common education (grade 13). There are 205 observations in total.

The figure to the right shows the estimated regression function using a second order Gaussian kernel along with asymptotic variability bounds.

### Script for example {#Script_for_example}

The following commands of the [R programming language](https://en.wikipedia.org/wiki/R_programming_language) use the `npreg()` function to deliver optimal smoothing and to create the figure given above. These commands can be entered at the command prompt via cut and paste.

```r
install.packages("np")
library(np) # non parametric library
data(cps71)
attach(cps71)

m <- npreg(logwage~age)

plot(m, plot.errors.method="asymptotic",
     plot.errors.style="band",
     ylim=c(11, 15.2))

points(age, logwage, cex=.25)
detach(cps71)
```

:::

## Related {#Related}

According to [David Salsburg](wikipedia://en/2921764), the algorithms used in kernel regression were independently developed and used in [fuzzy systems](https://en.wikipedia.org/wiki/Fuzzy_system): "Coming up with almost exactly the same computer algorithm, fuzzy systems and kernel density-based regressions appear to have been developed completely independently of one another."[^o14]

## Statistical implementation {#Statistical_implementation}

- [GNU Octave](wikipedia://en/48707) mathematical program package
- [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29): [KernelEstimator.jl](https://github.com/panlanfeng/KernelEstimator.jl)
- [MATLAB](wikipedia://en/20412): A free MATLAB toolbox with implementation of kernel regression, kernel density estimation, kernel estimation of hazard function and many others is available on [these pages](https://www.math.muni.cz/english/science-and-research/developed-software/232-matlab-toolbox.html) (this toolbox is a part of the book [^o16]).
- [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29): the `[http://www.statsmodels.org/stable/generated/statsmodels.nonparametric.kernel_regression.KernelReg.html KernelReg]` class for mixed data types in the `[http://www.statsmodels.org/stable/nonparametric.html statsmodels.nonparametric]` sub-package (includes other kernel density related classes), the package [kernel\_regression](https://github.com/jmetzen/kernel_regression) as an extension of [scikit-learn](https://en.wikipedia.org/wiki/Scikit-learn) (inefficient memory-wise, useful only for small datasets)
- [R](wikipedia://en/376707): the function `npreg` of the *np* package can perform kernel regression.[^o17][^o18]
- [Stata](wikipedia://en/1809002): [npregress](https://web.archive.org/web/20180519032545/https://www.stata.com/manuals/rnpregress.pdf), [kernreg2](https://ideas.repec.org/c/boc/bocode/s372601.html)
