# Kernel (statistics)

::: {#o1 .subject cue=lead name="Kernel"}

The term **kernel** is used in [statistical analysis](wikipedia://en/26685) to refer to a [window function](wikipedia://en/244097). The term "kernel" has several distinct meanings in different branches of statistics.

:::

## Bayesian statistics {#Bayesian_statistics}

In statistics, especially in [Bayesian statistics](wikipedia://en/404412), the kernel of a [probability density function](wikipedia://en/43487) (pdf) or [probability mass function](wikipedia://en/154725) (pmf) is the form of the pdf or pmf in which any factors that are not functions of any of the variables in the domain are omitted.[^o3] Note that such factors may well be functions of the [parameters](wikipedia://en/25065) of the pdf or pmf. These factors form part of the [normalization factor](https://en.wikipedia.org/wiki/Normalization_factor) of the [probability distribution](wikipedia://en/23543), and are unnecessary in many situations. For example, in [pseudo-random number sampling](https://en.wikipedia.org/wiki/Pseudo-random_number_sampling), most sampling algorithms ignore the normalization factor. In addition, in [Bayesian analysis](https://en.wikipedia.org/wiki/Bayesian_analysis) of [conjugate prior](wikipedia://en/846412) distributions, the normalization factors are generally ignored during the calculations, and only the kernel considered. At the end, the form of the kernel is examined, and if it matches a known distribution, the normalization factor can be reinstated. Otherwise, it may be unnecessary (for example, if the distribution only needs to be sampled from).

For many distributions, the kernel can be written in closed form, but not the normalization constant.

An example is the [normal distribution](wikipedia://en/21462). Its [probability density function](wikipedia://en/43487) is

$$p(x|\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

and the associated kernel is

$$p(x|\mu,\sigma^2) \propto e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

Note that the factor in front of the exponential has been omitted, even though it contains the parameter $\sigma^2$ , because it is not a function of the domain variable $x$ .

## Pattern analysis {#Pattern_analysis}

The kernel of a [reproducing kernel Hilbert space](wikipedia://en/651196) is used in the suite of techniques known as [kernel methods](https://en.wikipedia.org/wiki/Kernel_methods) to perform tasks such as [statistical classification](wikipedia://en/1579244), [regression analysis](wikipedia://en/826997), and [cluster analysis](wikipedia://en/669675) on data in an implicit space. This usage is particularly common in [machine learning](wikipedia://en/233488).

## Nonparametric statistics {#Nonparametric_statistics}

In [nonparametric statistics](wikipedia://en/223369), a kernel is a weighting function used in [non-parametric](https://en.wikipedia.org/wiki/Non-parametric) estimation techniques. Kernels are used in [kernel density estimation](wikipedia://en/2090057) to estimate [random variables](wikipedia://en/25685)' [density functions](https://en.wikipedia.org/wiki/Density_function), or in [kernel regression](wikipedia://en/8771825) to estimate the [conditional expectation](wikipedia://en/435099) of a random variable. Kernels are also used in [time series](wikipedia://en/406624), in the use of the [periodogram](wikipedia://en/485457) to estimate the [spectral density](wikipedia://en/202672) where they are known as [window functions](https://en.wikipedia.org/wiki/Window_functions). An additional use is in the estimation of a time-varying intensity for a [point process](wikipedia://en/2147685) where window functions (kernels) are convolved with time-series data.

Commonly, kernel widths must also be specified when running a non-parametric estimation.

::: {#o7 .definition cue=heading name="Definition"}

### Definition {#Definition}

A kernel is a [non-negative](https://en.wikipedia.org/wiki/Non-negative) [real-valued](wikipedia://en/22284647) [integrable](https://en.wikipedia.org/wiki/Integrable) function *K.* For most applications, it is desirable to define the function to satisfy two additional requirements:

- [Normalization](wikipedia://en/398189):

$$\int_{-\infty}^{+\infty}K(u)\,du = 1\,;$$

- [Even-function](wikipedia://en/592151) Symmetry:

$$K(-u) = K(u) \mbox{ for all values of } u\,.$$

The first requirement ensures that the method of kernel density estimation results in a [probability density function](wikipedia://en/43487). The second requirement ensures that the average of the corresponding distribution is equal to that of the sample used.

If *K* is a kernel, then so is the function *K*\* defined by *K*\*(*u*) = λ*K*(λ*u*), where λ > 0. This can be used to select a scale that is appropriate for the data.

:::

### Kernel functions in common use {#Kernel_functions_in_common_use}

*Image: Kernels.svg.* Some of the kernels below in a common coordinate system.

Several types of kernel functions are commonly used: uniform, triangle, Epanechnikov,[^o9] quartic (biweight), tricube,[^o10] triweight, Gaussian, quadratic[^o11] and cosine.

In the table below, if $K$ is given with a bounded [support](wikipedia://en/381013), then $K(u) = 0$ for values of *u* lying outside the support.

|---|---|---|---|---|---|

| Triangular | $K(u) = (1-\|u\|)$ Support: $\|u\|\leq1$ | *Image: Kernel triangle.svg.* | $\frac{1}{6}$ | $\frac{2}{3}$ | \98.6% |
| [Epanechnikov](https://en.wikipedia.org/wiki/Epanechnikov_distribution) (parabolic) | $K(u) = \frac{3}{4}(1-u^2)$ Support: $\|u\|\leq1$ | *Image: Kernel epanechnikov.svg.* | $\frac{1}{5}$ | $\frac{3}{5}$ | 100% |
