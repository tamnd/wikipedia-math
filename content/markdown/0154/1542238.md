# Smooth structure

::: {#o1 .subject cue=lead name="Smooth structure"}

In [mathematics](wikipedia://en/18831), a **smooth structure** on a [manifold](wikipedia://en/2073470) allows for an unambiguous notion of [smooth function](https://en.wikipedia.org/wiki/Smooth_function). In particular, a smooth structure allows [mathematical analysis](wikipedia://en/48396) to be performed on the manifold.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A smooth structure on a manifold $M$ is a collection of smoothly equivalent smooth atlases. Here, a **smooth atlas** for a topological manifold $M$ is an [atlas](wikipedia://en/47436) for $M$ such that each [transition function](https://en.wikipedia.org/wiki/Transition_map) is a [smooth map](https://en.wikipedia.org/wiki/Smooth_map), and two smooth atlases for $M$ are **smoothly equivalent** provided their [union](wikipedia://en/47949) is again a smooth atlas for $M.$ This gives a natural [equivalence relation](wikipedia://en/9259) on the set of smooth atlases.

A [smooth manifold](https://en.wikipedia.org/wiki/Smooth_manifold) is a topological manifold $M$ together with a smooth structure on $M.$

::: {#o6 .pointer-item cue=pointer name="Maximal smooth atlas"}

### Maximal smooth atlases {#Maximal_smooth_atlases}

By taking the union of all [atlases](wikipedia://en/47436) belonging to a smooth structure, we obtain a **maximal smooth atlas**. This atlas contains every chart that is compatible with the smooth structure. There is a natural one-to-one correspondence between smooth structures and maximal smooth atlases. Thus, we may regard a smooth structure as a maximal smooth atlas and vice versa.

In general, computations with the maximal atlas of a manifold are rather unwieldy. For most applications, it suffices to choose a smaller atlas. For example, if the manifold is [compact](wikipedia://en/6042), then one can find an atlas with only finitely many charts.

:::

### Equivalence of smooth structures {#Equivalence_of_smooth_structures}

If $\mu$ and $\nu$ are two maximal atlases on $M$ the two smooth structures associated to $\mu$ and $\nu$ are said to be equivalent if there is a [diffeomorphism](wikipedia://en/8564) $f : M \to M$ such that $\mu \circ f = \nu.$

:::

## Exotic spheres {#Exotic_spheres}

[John Milnor](wikipedia://en/61632) showed in 1956 that the 7-dimensional sphere admits a smooth structure that is not equivalent to the standard smooth structure. A sphere equipped with a nonstandard smooth structure is called an [exotic sphere](wikipedia://en/1114931).

## E8 manifold {#E8_manifold}

The [E8 manifold](wikipedia://en/6091657) is an example of a [topological manifold](wikipedia://en/2119193) that does not admit a smooth structure. This essentially demonstrates that [Rokhlin's theorem](wikipedia://en/7031816) holds only for smooth structures, and not topological manifolds in general.

## Related structures {#Related_structures}

The smoothness requirements on the transition functions can be weakened, so that the transition maps are only required to be $k$-times continuously differentiable; or strengthened, so that the transition maps are required to be real-analytic. Accordingly, this gives a [$C^k$](https://en.wikipedia.org/wiki/Differential_manifold) or [(real-)analytic structure](wikipedia://en/3183798) on the manifold rather than a smooth one. Similarly, a [complex structure](wikipedia://en/509742) can be defined by requiring the transition maps to be holomorphic.
