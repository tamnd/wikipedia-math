# Bootstrapping populations

::: {#o1 .subject cue=lead name="Bootstrapping populations"}

**Bootstrapping populations** in [statistics](wikipedia://en/26685) and [mathematics](wikipedia://en/18831) starts with a [sample](https://en.wikipedia.org/wiki/Statistical_sample) $\{x_1,\ldots,x_m\}$ observed from a [random variable](wikipedia://en/25685).

:::

When *X* has a given [distribution law](wikipedia://en/5793) with a set of non fixed parameters, we denote with a vector $\boldsymbol\theta$, a [parametric inference](wikipedia://en/223366) problem consists of computing suitable values – call them [estimates](wikipedia://en/10043) – of these parameters precisely on the basis of the sample. An estimate is suitable if replacing it with the unknown parameter does not cause major damage in next computations. In [Algorithmic inference](wikipedia://en/20890511), suitability of an estimate reads in terms of [compatibility](wikipedia://en/20890511#compatible_distribution) with the observed sample.

In this framework, [resampling methods](wikipedia://en/3763850) are aimed at generating a set of candidate values to replace the unknown parameters that we read as compatible replicas of them. They represent a population of specifications of a random vector $\boldsymbol\Theta$ [^o2] compatible with an observed sample, where the compatibility of its values has the properties of a [probability distribution](wikipedia://en/23543). By plugging parameters into the expression of the questioned distribution law, we bootstrap entire populations of random variables [compatible](wikipedia://en/20890511#compatible_distribution) with the observed sample.

The rationale of the algorithms computing the replicas, which we denote *population bootstrap* procedures, is to identify a set of statistics $\{s_1,\ldots,s_k\}$ exhibiting specific properties, denoting a [well behavior](wikipedia://en/20890519), w.r.t. the unknown parameters. The statistics are expressed as functions of the observed values $\{x_1,\ldots,x_m\}$, by definition. The $x_i$ may be expressed as a function of the unknown parameters and a [random seed](https://en.wikipedia.org/wiki/Random_seed) specification $z_i$ through the [sampling mechanism](wikipedia://en/20890511#Sampling_mechanism) $(g_{\boldsymbol\theta},Z)$, in turn. Then, by plugging the second expression in the former, we obtain $s_j$ expressions as functions of seeds and parameters – the [master equations](wikipedia://en/20890511#Master_equation) – that we invert to find values of the latter as a function of: i) the statistics, whose values in turn are fixed at the observed ones; and ii) the seeds, which are random according to their own distribution. Hence from a set of seed samples we obtain a set of parameter replicas.

::: {#o4 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

Given a $\boldsymbol x=\{x_1,\ldots,x_m\}$ of a random variable *X* and a [sampling mechanism](wikipedia://en/20890511#Sampling_mechanism) $(g_{\boldsymbol\theta},Z)$ for *X*, the realization **x** is given by $\boldsymbol x=\{g_{\boldsymbol\theta}(z_1),\ldots,g_{\boldsymbol\theta}(z_m)\}$, with $\boldsymbol\theta=(\theta_1,\ldots,\theta_k)$. Focusing on [well-behaved statistics](wikipedia://en/20890519),

{|

\|- | $s_1=h_1(x_1,\ldots,x_m),$ |- | $\vdots\ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots$ |- | $s_k=h_k(x_1,\ldots,x_m),$ |}

for their parameters, the master equations read

{| width=100%

\|- | $s_1= h_1(g_{\boldsymbol\theta} (z_1),\ldots, g_{\boldsymbol\theta} (z_m))= \rho_1(\boldsymbol\theta;z_1,\ldots,z_m)$ |- | width=90% | $\vdots\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots$ | width=10% align="center" | (1) |- | $s_k= h_k(g_{\boldsymbol\theta} (z_1),\ldots, g_{\boldsymbol\theta} (z_m))= \rho_k(\boldsymbol\theta;z_1,\ldots,z_m).$ |}

For each sample seed $\{z_1,\ldots,z_m\}$ a vector of parameters $\boldsymbol\theta$ is obtained from the solution of the above system with $s_i$ fixed to the observed values. Having computed a huge set of compatible vectors, say *N*, the empirical [marginal distribution](wikipedia://en/506077) of $\Theta_j$ is obtained by:

{| width=100%

\|- | width=90% | $\widehat F_{\Theta_j}(\theta)=\sum_{i=1}^N\frac{1}{N}I_{(-\infty,\theta]}(\breve\theta_{j,i})$ | width=10% align="center" | (2) |}

where $\breve\theta_{j,i}$ is the j-th component of the generic solution of (1) and where $I_{(-\infty,\theta]}(\breve\theta_{j,i})$ is the [indicator function](wikipedia://en/240790) of $\breve\theta_{j,i}$ in the interval $(-\infty,\theta].$ Some indeterminacies remain if *X* is discrete and this we will be considered shortly. The whole procedure may be summed up in the form of the following Algorithm, where the index $\boldsymbol\Theta$ of $\boldsymbol s_{\boldsymbol\Theta}$ denotes the parameter vector from which the statistics vector is derived.

:::

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

::: {#o7 .table cue=table}

| Generating parameter populations through a bootstrap |
|---|
| Given a sample $\{x_1,\ldots,x_m\}$ from a random variable with parameter vector $\boldsymbol\theta$ unknown, Identify a vector of [well-behaved statistics](wikipedia://en/20890519) $\boldsymbol S$ for $\boldsymbol\Theta$; compute a specification $\boldsymbol s_{\boldsymbol\Theta}$ of $\boldsymbol S$ from the sample; repeat for a satisfactory number *N* of iterations: draw a sample seed $\breve{\boldsymbol z}_i$ of size *m* from the seed random variable; get $\breve{\boldsymbol\theta}_i=\mathrm{Inv}(\boldsymbol s,\boldsymbol z_i)$ as a solution of (1) in θ with $\boldsymbol s=\boldsymbol s_{\boldsymbol\Theta}$ and $\boldsymbol z_i = \{\breve z_1,\ldots,\breve z_m\}$; add $\breve{\boldsymbol\theta}_i$ to $\boldsymbol\Theta$; population. |

:::

*Image: Unicdf.png.* Cumulative distribution function of the parameter A of a uniform continuous random variable when statistic $s_A=9.91$

You may easily see from a [table of sufficient statistics](wikipedia://en/20890511#SufficientTable) that we obtain the curve in the picture on the left by computing the empirical distribution (2) on the population obtained through the above algorithm when: i) *X* is an Exponential random variable, ii) $s_\Lambda= \sum_{j=1}^m x_j$, and

$$\text{ iii) Inv}(s_\Lambda,\boldsymbol u_i) =\sum_{j=1}^m(-\log u_{ij})/s_\Lambda,$$

and the curve in the picture on the right when: i) *X* is a Uniform random variable in $[0,a]$, ii) $s_A= \max_{j=1, \ldots, m} x_j$, and

$$\text{iii) Inv}(s_A,\boldsymbol u_i) =s_A/\max_{j=1,\ldots,m}\{u_{ij}\}.$$

### Remark {#Remark}

Note that the accuracy with which a parameter distribution law of populations compatible with a sample is obtained is not a function of the sample size. Instead, it is a function of the number of seeds we draw. In turn, this number is purely a matter of computational time but does not require any extension of the observed data. With other [bootstrapping methods](wikipedia://en/6885770) focusing on a generation of sample replicas (like those proposed by (Efron Tibshirani 1993)) the accuracy of the estimate distributions depends on the sample size.

### Example {#Example}

For $\boldsymbol x$ expected to represent a [Pareto distribution](wikipedia://en/53057), whose specification requires values for the parameters $a$ and *k*,[^o13] we have that the cumulative distribution function reads:

*Image: Paretocdf.png.* Joint empirical cumulative distribution function of parameters $(A,K)$ of a Pareto random variable when $m=30, s_1=83.24$ and $s_{2}=8.37$ based on 5,000 replicas.

$$F_X(x)=1-\left(\frac{k}{x}\right)^a.$$

A [sampling mechanism](wikipedia://en/20890511#Sampling_mechanism) $(g_{(a,k)}, U)$ has $[0,1]$ [uniform seed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) *U* and explaining function $g_{(a,k)}$ described by:

$$x= g_{(a,k)}=(1 - u)^{-\frac{1}{a}} k$$

A relevant statistic $\boldsymbol s_\boldsymbol\Theta$ is constituted by the pair of [joint sufficient statistics](https://en.wikipedia.org/wiki/Sufficiency_%28statistics%29) for $A$ and *K*, respectively $s_1=\sum_{i=1}^m \log x_i, s_{2}=\min\{x_i\}$. The [master equations](wikipedia://en/20890511#Master_equation) read

$$s_1=\sum_{i=1}^m -\frac{1}{a}\log(1 - u_i)+m \log k$$

$$s_{2}=(1 - u_{\min})^{-\frac{1}{a}} k$$

with $u_{\min}=\min\{u_i\}$.

Figure on the right reports the three-dimensional plot of the empirical cumulative distribution function (2) of $(A,K)$.
