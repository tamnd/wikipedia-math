# Dynamic discrete choice

::: {#o1 .subject cue=lead name="Dynamic discrete choice"}

**Dynamic discrete choice (DDC) models**, also known as **discrete choice models of** [dynamic programming](wikipedia://en/125297), model an agent's choices over discrete options that have future implications. Rather than assuming observed choices are the result of static utility maximization, observed choices in DDC models are assumed to result from an agent's maximization of the [present value](https://en.wikipedia.org/wiki/Present_value) of utility, generalizing the [utility theory](https://en.wikipedia.org/wiki/Utility_theory) upon which [discrete choice](wikipedia://en/4902101) models are based.[^n1]

:::

The goal of DDC methods is to estimate the [structural parameters](wikipedia://en/12634266) of the agent's decision process. Once these parameters are known, the researcher can then use the estimates to simulate how the agent would behave in a counterfactual state of the world. (For example, how a prospective college student's enrollment decision would change in response to a tuition increase.)

## Mathematical representation {#Mathematical_representation}

Agent $n$'s [maximization problem](wikipedia://en/1236458#A_dynamic_decision_problem) can be written mathematically as follows:

$$V\left(x_{n0}\right)=\max_{\left\{d_{nt}\right\}_{t=1}^T} \mathbb{E} \left(\sum_{t^{\prime}=t}^T \sum_{i=1}^J \beta^{t'-t} \left(d_{nt}=i\right)U_{nit} \left(x_{nt}, \varepsilon_{nit}\right)\right),$$

where

- $x_{nt}$ are [state variables](https://en.wikipedia.org/wiki/State_variable), with $x_{n0}$ the agent's [initial condition](wikipedia://en/1186804)
- $d_{nt}$ represents $n$'s decision from among $J$ discrete alternatives
- $\beta \in \left(0,1\right)$ is the [discount factor](https://en.wikipedia.org/wiki/Discounting#Discount_factor)
- $U_{nit}$ is the [flow utility](https://en.wikipedia.org/wiki/Utility_theory) $n$ receives from choosing alternative $i$ in period $t$, and depends on both the state $x_{nt}$ and unobserved factors $\varepsilon_{nit}$
- $T$ is the [time horizon](https://en.wikipedia.org/wiki/Time_horizon)
- The expectation $\mathbb{E}\left(\cdot\right)$ is taken over both the $x_{nt}$'s and $\varepsilon_{nit}$'s in $U_{nit}$. That is, the agent is uncertain about future transitions in the states, and is also uncertain about future realizations of unobserved factors.

### Simplifying assumptions and notation {#Simplifying_assumptions_and_notation}

It is standard to impose the following simplifying assumptions and notation of the dynamic [decision problem](wikipedia://en/8336):

**\1. Flow utility is additively separable and linear in parameters**

The flow utility can be written as an additive sum, consisting of deterministic and stochastic elements. The deterministic component can be written as a linear function of the [structural parameters](wikipedia://en/12634266).

$$\begin{alignedat}{5} U_{nit}\left(x_{nt},\varepsilon_{nit}\right) &&\; = \;&& u_{nit} &&\; + \;&& \varepsilon_{nit} \\ &&\; = \;&& X_{nt}\alpha_{i} &&\; + \;&& \varepsilon_{nit} \end{alignedat}$$

**\2. The [optimization problem](wikipedia://en/1126536) can be written as a [Bellman equation](wikipedia://en/1236458)**

Define by $V_{nt}(x_{nt})$ the *ex ante* value function for individual $n$ in period $t$ just before $\varepsilon_{nt}$ is revealed:

$$V_{nt}(x_{nt}) = \mathbb{E} \max_i \left\{ u_{nit}(x_{nt}) + \varepsilon_{nit} + \beta \int_{x_{t+1}} V_{nt+1} (x_{nt+1}) \, dF\left(x_{t+1} \mid x_t \right) \right\}$$

where the expectation operator $\mathbb{E}$ is over the $\varepsilon$'s, and where $dF\left(x_{t+1} \mid x_t \right)$ represents the [probability distribution](wikipedia://en/23543) over $x_{t+1}$ conditional on $x_{t}$. The expectation over state transitions is accomplished by taking the integral over this probability distribution.

It is possible to decompose $V_{nt}(x_{nt})$ into deterministic and stochastic components:

$$V_{nt}(x_{nt}) = \mathbb{E} \max_i \left\{ v_{nit}(x_{nt}) + \varepsilon_{nit} \right\}$$

where $v_{nit}$ is the value to choosing alternative $i$ at time $t$ and is written as

$$v_{nit}(x_{nt}) = u_{nit}\left(x_{nt}\right) + \beta \int_{x_{t+1}} \mathbb{E} \max_{j} \left\{ v_{njt+1}(x_{nt+1}) + \varepsilon_{njt+1} \right\} \, dF(x_{t+1} \mid x_t)$$

where now the expectation $\mathbb{E}$ is taken over the $\varepsilon_{njt+1}$.

**\3. The optimization problem follows a [Markov decision process](wikipedia://en/1125883)**

The states $x_{t}$ follow a [Markov chain](wikipedia://en/60876). That is, attainment of state $x_{t}$ depends only on the state $x_{t-1}$ and not $x_{t-2}$ or any prior state.

## Conditional value functions and choice probabilities {#Conditional_value_functions_and_choice_probabilities}

The value function in the previous section is called the **conditional value function**, because it is the value function conditional on choosing alternative $i$ in period $t$. Writing the conditional value function in this way is useful in constructing formulas for the choice probabilities.

To write down the choice probabilities, the researcher must make an assumption about the distribution of the $\varepsilon_{nit}$'s. As in static discrete choice models, this distribution can be assumed to be [iid](https://en.wikipedia.org/wiki/Iid) [Type I extreme value](https://en.wikipedia.org/wiki/Type_I_extreme_value_distribution), [generalized extreme value](wikipedia://en/1494479), [multinomial probit](wikipedia://en/14758355), or [mixed logit](wikipedia://en/14645368).

For the case where $\varepsilon_{nit}$ is multinomial logit (i.e. drawn [iid](https://en.wikipedia.org/wiki/Iid) from the [Type I extreme value distribution](https://en.wikipedia.org/wiki/Type_I_extreme_value_distribution)), the formulas for the choice probabilities would be:

$$P_{nit} = \frac{\exp(v_{nit})}{\sum_{j=1}^J \exp(v_{njt})}$$

## Estimation {#Estimation}

Estimation of dynamic discrete choice models is particularly challenging, due to the fact that the researcher must solve the backwards recursion problem for each guess of the structural parameters.

The most common methods used to estimate the structural parameters are [maximum likelihood estimation](wikipedia://en/140806) and [method of simulated moments](wikipedia://en/12135521).

Aside from estimation methods, there are also solution methods. Different solution methods can be employed due to complexity of the problem. These can be divided into **full-solution methods** and **non-solution methods**.

### Full-solution methods {#Full-solution_methods}

The foremost example of a full-solution method is the nested fixed point (NFXP) algorithm developed by [John Rust](https://en.wikipedia.org/wiki/John_Rust) in 1987.[^n2] The NFXP algorithm is described in great detail in its documentation manual.[^o9]

A recent work by Che-Lin Su and [Kenneth Judd](https://en.wikipedia.org/wiki/Kenneth_Judd) in 2012[^o10] implements another approach (dismissed as intractable by Rust in 1987), which uses [constrained optimization](wikipedia://en/4171950) of the likelihood function, a special case of [mathematical programming with equilibrium constraints](wikipedia://en/18894568) (MPEC). Specifically, the likelihood function is maximized subject to the constraints imposed by the model, and expressed in terms of the additional variables that describe the model's structure. This approach requires powerful optimization software such as [Artelys Knitro](https://en.wikipedia.org/wiki/Artelys_Knitro) because of the high dimensionality of the optimization problem. Once it is solved, both the structural parameters that maximize the likelihood, and the solution of the model are found.

In the later article[^o11] Rust and coauthors show that the speed advantage of MPEC compared to NFXP is not significant. Yet, because the computations required by MPEC do not rely on the structure of the model, its implementation is much less labor intensive.

Despite numerous contenders, the NFXP maximum likelihood estimator remains the leading estimation method for Markov decision models.[^o11]

### Non-solution methods {#Non-solution_methods}

An alternative to full-solution methods is non-solution methods. In this case, the researcher can estimate the structural parameters without having to fully solve the backwards recursion problem for each parameter guess. Non-solution methods are typically faster while requiring more assumptions, but the additional assumptions are in many cases realistic.

The leading non-solution method is conditional choice probabilities, developed by V. Joseph Hotz and Robert A. Miller.[^o13]

## Examples {#Examples}

### Bus engine replacement model {#Bus_engine_replacement_model}

The bus engine replacement model developed in the seminal paper (Rust 1987) is one of the first dynamic stochastic models of discrete choice estimated using real data, and continues to serve as classical example of the problems of this type.[^o10]

The model is a simple regenerative [optimal stopping](wikipedia://en/7189886) stochastic dynamic problem faced by the decision maker, Harold Zurcher, superintendent of maintenance at the [Madison Metropolitan Bus Company](https://en.wikipedia.org/wiki/Metro_Transit_%28Madison%29) in [Madison, Wisconsin](https://en.wikipedia.org/wiki/Madison,_Wisconsin). For every [bus](https://en.wikipedia.org/wiki/Bus) in operation in each time period Harold Zurcher has to decide whether to replace the [engine](https://en.wikipedia.org/wiki/Engine) and bear the associated replacement cost, or to continue operating the bus at an ever raising cost of operation, which includes insurance and the cost of lost ridership in the case of a breakdown.

Let $x_t$ denote the [odometer](https://en.wikipedia.org/wiki/Odometer) reading (mileage) at period $t$, $c(x_t,\theta)$ cost of operating the bus which depends on the vector of parameters $\theta$, $RC$ cost of replacing the engine, and $\beta$ the [discount factor](https://en.wikipedia.org/wiki/Discount_factor). Then the per-period utility is given by

$$U(x_t,\xi_t,d,\theta)= \begin{cases} -c(x_t,\theta) + \xi_{t,\text{keep}}, & \\ -RC-c(0,\theta) + \xi_{t,\text{replace}}, & \end{cases} = u(x_t,d,\theta) + \begin{cases} \xi_{t,\text{keep}}, & \textrm{if }\;\; d=\text{keep}, \\ \xi_{t,\text{replace}}, & \textrm{if }\;\; d=\text{replace}, \end{cases}$$

where $d$ denotes the decision (keep or replace) and $\xi_{t,\text{keep}}$ and $\xi_{t,\text{replace}}$ represent the component of the utility observed by Harold Zurcher, but not John Rust. It is assumed that $\xi_{t,\text{keep}}$ and $\xi_{t,\text{replace}}$ are independent and identically distributed with the [Type I extreme value distribution](https://en.wikipedia.org/wiki/Type_I_extreme_value_distribution), and that $\xi_{t,\bullet}$ are independent of $\xi_{t-1,\bullet}$ conditional on $x_t$.

Then the optimal decisions satisfy the [Bellman equation](wikipedia://en/1236458)

$$V(x,\xi,\theta) = \max_{d=\text{keep},\text{replace}} \left\{ u(x,d,\theta)+\xi_d + \iint V(x',\xi',\theta) q(d\xi'\mid x',\theta) p(dx'\mid x,d,\theta) \right\}$$

where $p(dx'\mid x,d,\theta)$ and $q(d\xi'\mid x',\theta)$ are respectively transition densities for the observed and unobserved states variables. Time indices in the Bellman equation are dropped because the model is formulated in the infinite horizon settings, the unknown optimal policy is [stationary](wikipedia://en/329898), i.e. independent of time.

Given the distributional assumption on $q(d\xi'\mid x',\theta)$, the probability of particular choice $d$ is given by

$$P(d\mid x,\theta) = \frac{ \exp\{ u(x,d,\theta)+\beta EV(x,d,\theta)\}}{\sum_{d' \in D(x)} \exp\{ u(x,d',\theta)+\beta EV(x,d',\theta)\} }$$

where $EV(x,d,\theta)$ is a unique solution to the [functional equation](wikipedia://en/364377)

$$EV(x,d,\theta)= \int \left[ \log\left( \sum_{d=\text{keep},\text{replace}} \exp\{u(x,d',\theta)+\beta EV(x',d',\theta)\}\right) \right] p(x'\mid x,d,\theta).$$

It can be shown that the latter functional equation defines a [contraction mapping](wikipedia://en/6239) if the state space $x_t$ is bounded, so there will be a unique solution $EV(x,d,\theta)$ for any $\theta$, and further the [implicit function theorem](wikipedia://en/581005) holds, so $EV(x,d,\theta)$ is also a [smooth function](https://en.wikipedia.org/wiki/Smooth_function) of $\theta$ for each $(x,d)$.

#### Estimation with nested fixed point algorithm {#Estimation_with_nested_fixed_point_algorithm}

The contraction mapping above can be solved numerically for the fixed point $EV(x,d,\theta)$ that yields choice probabilities $P(d\mid x,\theta)$ for any given value of $\theta$. The [log-likelihood](https://en.wikipedia.org/wiki/Log-likelihood) function can then be formulated as

$$L(\theta) = \sum_{i=1}^N \sum_{t=1}^{T_i} \log(P(d_{it}\mid x_{it},\theta))+\log(p(x_{it}\mid x_{it-1},d_{it-1},\theta)),$$

where $x_{i,t}$ and $d_{i,t}$ represent data on state variables (odometer readings) and decision (keep or replace) for $i=1,\dots,N$ individual buses, each in $t=1,\dots,T_i$ periods.

The joint algorithm for solving the fixed point problem given a particular value of parameter $\theta$ and maximizing the log-likelihood $L(\theta)$ with respect to $\theta$ was named by John Rust *nested fixed point algorithm* (NFXP).

Rust's implementation of the nested fixed point algorithm is highly optimized for this problem, using [Newton–Kantorovich iterations](wikipedia://en/22145#In_a_Banach_space) to calculate $P(d\mid x,\theta)$ and [quasi-Newton methods](wikipedia://en/7883127), such as the [Berndt–Hall–Hall–Hausman algorithm](wikipedia://en/4229002), for likelihood maximization.[^o11]

#### Estimation with MPEC {#Estimation_with_MPEC}

In the nested fixed point algorithm, $P(d\mid x,\theta)$ is recalculated for each guess of the parameters $\theta$. The MPEC method instead solves the [constrained optimization](wikipedia://en/4171950) problem:[^o10]

$$\begin{aligned} \max & \qquad L(\theta) & \\ \text{subject to} & \qquad EV(x,d,\theta)= \int \left[ \log\left( \sum_{d=\text{keep},\text{replace}} \exp\{ u(x,d',\theta) + \beta EV(x',d',\theta)\}\right) \right] p(x'\mid x,d,\theta) \end{aligned}$$

This method is faster to compute than non-optimized implementations of the nested fixed point algorithm, and takes about as long as highly optimized implementations.[^o11]

#### Estimation with non-solution methods {#Estimation_with_non-solution_methods}

The conditional choice probabilities method of Hotz and Miller can be applied in this setting. Hotz, Miller, Sanders, and Smith proposed a computationally simpler version of the method, and tested it on a study of the bus engine replacement problem. The method works by estimating conditional choice probabilities using [simulation](https://en.wikipedia.org/wiki/Simulation), then backing out the implied differences in [value functions](wikipedia://en/12617694).[^n3][^o22]
