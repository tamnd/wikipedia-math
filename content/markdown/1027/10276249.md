# CLEFIA

::: {#o1 .subject cue=lead name="CLEFIA"}

**CLEFIA** is a proprietary [block cipher](wikipedia://en/4594) [algorithm](wikipedia://en/775), developed by [Sony](https://en.wikipedia.org/wiki/Sony).[^o4] Its name is derived from the French word *clef*, meaning "key". The block size is 128-bits, and the key size can be 128-bit, 192-bit or 256-bits. It is intended to be used in [DRM](wikipedia://en/18938226) systems. It is among the [cryptographic](wikipedia://en/18934432) techniques recommended candidate for Japanese government use by [CRYPTREC](wikipedia://en/549159) revision in 2013.

:::

## Standardization {#Standardization}

CLEFIA is included in the following standards.

- ISO/IEC 29192-2:2019, *[Information security](wikipedia://en/15036) - Lightweight cryptography - Part 2: Block ciphers*[^o6]
- 6114[^o7]
