# Projective cover

::: {#o1 .subject cue=lead name="Projective cover"}

In the branch of abstract mathematics called [category theory](wikipedia://en/5869), a **projective cover** of an object *M* is in a sense the best approximation of *M* by a [projective object](wikipedia://en/3017382) *P*. Projective covers are the [dual](wikipedia://en/310885) of [injective envelopes](https://en.wikipedia.org/wiki/Injective_envelope).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{C}$ be a [category](wikipedia://en/53759) and *M* an object in $\mathcal{C}$. A **projective cover** is a pair (*P*,*p*), with *P* a [projective object](wikipedia://en/3017382) in $\mathcal{C}$ and *p* a superfluous epimorphism in Hom(*P*, *M*).

If *R* is a ring, then in the category of *R*-modules, a **superfluous epimorphism** is then an [epimorphism](wikipedia://en/59539) $p : P \to M$ such that the [kernel](wikipedia://en/45240) of *p* is a [superfluous submodule](https://en.wikipedia.org/wiki/Superfluous_submodule) of *P*.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Projective covers and their superfluous epimorphisms, when they exist, are unique up to [isomorphism](wikipedia://en/14828). The isomorphism need not be unique, however, since the projective property is not a full fledged [universal property](wikipedia://en/32245).

The main effect of *p* having a superfluous kernel is the following: if *N* is any proper submodule of *P*, then $p(N) \ne M$.[^o6] Informally speaking, this shows the superfluous kernel causes *P* to cover *M* optimally, that is, no submodule of *P* would suffice. This does not depend upon the projectivity of *P*: it is true of all superfluous epimorphisms.

If (*P*,*p*) is a projective cover of *M*, and *P'* is another projective module with an epimorphism $p':P'\rightarrow M$, then there is a [split epimorphism](wikipedia://en/59539#Related_concepts) α from *P'* to *P* such that $p\alpha=p'$

Unlike [injective envelopes](https://en.wikipedia.org/wiki/Injective_envelope) and [flat covers](wikipedia://en/34846642), which exist for every left (right) [*R*-module](wikipedia://en/276410) regardless of the [ring](wikipedia://en/48404) *R*, left (right) *R*-modules do not in general have projective covers. A ring *R* is called left (right) [perfect](wikipedia://en/22658615) if every left (right) *R*-module has a projective cover in *R*-Mod (Mod-*R*).

A ring is called [semiperfect](https://en.wikipedia.org/wiki/Semiperfect_ring) if every [finitely generated](wikipedia://en/326430) left (right) *R*-module has a projective cover in *R*-Mod (Mod-*R*). "Semiperfect" is a left-right symmetric property.

A ring is called *lift/rad* if [idempotents lift](wikipedia://en/361940#Category_of_R-modules) from *R*/*J* to *R*, where *J* is the [Jacobson radical](wikipedia://en/57656) of *R*. The property of being lift/rad can be characterized in terms of projective covers: *R* is lift/rad if and only if direct summands of the *R* module *R*/*J* (as a right or left module) have projective covers.[^n1]

:::

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

In the category of *R* modules:

- If *M* is already a projective module, then the identity map from *M* to *M* is a superfluous epimorphism (its kernel being zero). Hence, projective modules always have projective covers.
- If J(*R*)=0, then a module *M* has a projective cover if and only if *M* is already projective.
- In the case that a module *M* is [simple](wikipedia://en/29430), then it is necessarily the [top](wikipedia://en/21094724) of its projective cover, if it exists.
- The injective envelope for a module always exists, however over certain rings modules may not have projective covers. For example, the natural map from **Z** onto **Z**/2**Z** is not a projective cover of the **Z**-module **Z**/2**Z** (which in fact has no projective cover). The class of rings which provides all of its right modules with projective covers is the class of right [perfect rings](wikipedia://en/22658615).
- Any *R*-module *M* has a [flat cover](wikipedia://en/34846642), which is equal to the projective cover if *M* has a projective cover.

:::
