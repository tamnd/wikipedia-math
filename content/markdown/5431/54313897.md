# Quotient space of an algebraic stack

::: {#o1 .subject cue=lead name="Quotient space of an algebraic stack"}

In algebraic geometry, the **quotient space** of an [algebraic stack](wikipedia://en/717377) *F*, denoted by |*F*|, is a [topological space](wikipedia://en/30450) which as a set is the set of all integral substacks of *F* and which then is given a "[Zariski topology](wikipedia://en/241744)": an open subset has a form $|U| \subset |F|$ for some open substack *U* of *F*.[^o2]

:::

The construction $X \mapsto |X|$ is functorial; i.e., each morphism $f: X \to Y$ of algebraic stacks determines a continuous map $f: |X| \to |Y|$.

An algebraic stack *X* is **punctual** if $|X|$ is a [point](https://en.wikipedia.org/wiki/Point_topological_space).

When *X* is a moduli stack, the quotient space $|X|$ is called the [moduli space](wikipedia://en/361609) of *X*. If $f: X \to Y$ is a morphism of algebraic stacks that induces a [homeomorphism](wikipedia://en/13660) $f: |X| \overset{\sim}\to |Y|$, then *Y* is called *a* coarse moduli stack of *X*. ("The" coarse moduli requires a universality.)

[^o2]: In other words, there is a natural bijection between the set of all open immersions to *F* and the set of all open subsets of $|F|$.
