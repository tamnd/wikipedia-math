# Location–scale family

::: {#o1 .subject cue=lead name="Location–scale family"}

In [probability theory](wikipedia://en/23542), especially in mathematical [statistics](wikipedia://en/26685), a **location–scale family** is a [family](wikipedia://en/23624339) of [probability distributions](wikipedia://en/23543) parametrized by a [location parameter](wikipedia://en/17516) and a non-negative [scale parameter](wikipedia://en/769503). For any [random variable](wikipedia://en/25685) $X$ whose probability distribution function belongs to such a family, the distribution function of $Y \,\stackrel{d}{=}\, a + b X$ also belongs to the family (where $\stackrel{d}{=}$ means "[equal in distribution](wikipedia://en/25685#Equality_in_distribution)"—that is, "has the same distribution as").

:::

In other words, a class $\Omega$ of probability distributions is a location–scale family if for all [cumulative distribution functions](https://en.wikipedia.org/wiki/Cumulative_distribution_functions) $F \in \Omega$ and any real numbers $a \in \mathbb{R}$ and $b > 0$, the distribution function $G(x) = F(a + b x)$ is also a member of $\Omega$.

- If $X$ has a [cumulative distribution function](wikipedia://en/5793) $F_X(x)= P(X\le x)$, then $Y= a + b X$ has a cumulative distribution function $F_Y(y) = F_X\left(\frac{y-a}{b}\right)$.
- If $X$ is a [discrete random variable](https://en.wikipedia.org/wiki/Discrete_random_variable) with [probability mass function](wikipedia://en/154725) $p_X(x)= P(X=x)$, then $Y= a + b X$ is a discrete random variable with probability mass function $p_Y(y) = p_X\left(\frac{y-a}{b}\right)$.
- If $X$ is a [continuous random variable](https://en.wikipedia.org/wiki/Continuous_random_variable) with [probability density function](wikipedia://en/43487) $f_X(x)$, then $Y= a + b X$ is a continuous random variable with probability density function $f_Y(y) = \frac{1}{b}f_X\left(\frac{y-a}{b}\right)$.
- If $X$ has a [moment generating function](wikipedia://en/194634) $M_X(t)$, then $Y= a + b X$ has a moment generating function $M_Y(t)=e^{at}M_X(bt)$.
- If $X$ has a [characteristic function](wikipedia://en/3229401) $\varphi_X(t)$, then $Y= a + b X$ has a characteristic function $\varphi_Y(t)=e^{iat}\varphi_X(bt)$.

Moreover, if $X$ and $Y$ are two random variables whose distribution functions are members of the family, and assuming existence of the first two moments and $X$ has zero mean and unit variance, then $Y$ can be written as $Y \,\stackrel{d}{=}\, \mu_Y + \sigma_Y X$ , where $\mu_Y$ and $\sigma_Y$ are the mean and standard deviation of $Y$.

In [decision theory](wikipedia://en/446216), if all alternative distributions available to a decision-maker are in the same location–scale family, and the first two moments are finite, then a [two-moment decision model](https://en.wikipedia.org/wiki/Two-moment_decision_models) can apply, and decision-making can be framed in terms of the [means](wikipedia://en/9653) and the [variances](wikipedia://en/32344) of the distributions.[^o2][^o3][^o4]

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

Often, location–scale families are restricted to those where all members have the same functional form. Most location–scale families are [univariate](wikipedia://en/9253219), though not all. Well-known families in which the functional form of the distribution is consistent throughout the family include the following:

- [Normal distribution](wikipedia://en/21462)
- [Elliptical distributions](wikipedia://en/27014075)
- [Cauchy distribution](wikipedia://en/7003)
- [Uniform distribution (continuous)](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29)
- [Uniform distribution (discrete)](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29)
- [Logistic distribution](wikipedia://en/542666)
- [Laplace distribution](wikipedia://en/1106213)
- [Student's t-distribution](wikipedia://en/105375#Location-scale_t-distribution)
- [Generalized extreme value distribution](wikipedia://en/1494479)

:::

## Converting a single distribution to a location–scale family {#Converting_a_single_distribution_to_a_location–scale_family}

The following shows how to implement a location–scale family in a statistical package or programming environment where only functions for the "standard" version of a distribution are available. It is designed for [R](wikipedia://en/376707) but should generalize to any language and library.

The example here is of the [Student's *t*-distribution](wikipedia://en/105375), which is normally provided in R only in its standard form, with a single [degrees of freedom](wikipedia://en/2321606) parameter `df`. The versions below with `_ls` appended show how to generalize this to a [generalized Student's t-distribution](wikipedia://en/105375#Location-scale_t-distribution) with an arbitrary location parameter `m` and scale parameter `s`.

| [Probability density function](wikipedia://en/43487) (PDF): | `dt_ls(x, df, m, s) =` | `1/s * dt((x - m) / s, df)` |
|---|---|---|
| [Cumulative distribution function](wikipedia://en/5793) (CDF): | `pt_ls(x, df, m, s) =` | `pt((x - m) / s, df)` |
| [Quantile function](wikipedia://en/10167616) (inverse CDF): | `qt_ls(prob, df, m, s) =` | `qt(prob, df) * s + m` |
| Generate a [random variate](https://en.wikipedia.org/wiki/Random_variate): | `rt_ls(df, m, s) =` | `rt(df) * s + m` |

Note that these generalized functions do not have standard deviation `s` since standard *t* distributions do not have a standard deviation of 1.
