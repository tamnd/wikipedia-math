# Siconos

::: {#o1 .subject cue=lead name="Siconos"}

**SICONOS** is an [open source](https://en.wikipedia.org/wiki/Open_source) scientific software primarily targeted at modeling and simulating non-smooth dynamical systems (NSDS):[^o3]

:::

- Mechanical systems ([Rigid body](wikipedia://en/455769) or [solid](wikipedia://en/5918)) with [Unilateral contact](https://en.wikipedia.org/wiki/Unilateral_contact) and [Coulomb friction](https://en.wikipedia.org/wiki/Coulomb_friction) as we find in [Non-smooth mechanics](wikipedia://en/15947157), [Contact dynamics](https://en.wikipedia.org/wiki/Contact_dynamics) or [Granular material](https://en.wikipedia.org/wiki/Granular_material).
- Switched Electrical Circuit such as [Power converter](https://en.wikipedia.org/wiki/Power_converter), [Rectifier](https://en.wikipedia.org/wiki/Rectifier), [Phase-locked loop](https://en.wikipedia.org/wiki/Phase-locked_loop) ([PLL](https://en.wikipedia.org/wiki/Phase-locked_loop)) or [Analog-to-digital converter](https://en.wikipedia.org/wiki/Analog-to-digital_converter)
- [Sliding mode control](wikipedia://en/371255) systems

Other applications are found in Systems and Control (hybrid systems, differential inclusions, [optimal control](wikipedia://en/362565) with state constraints), Optimization ([Complementarity problem](https://en.wikipedia.org/wiki/Complementarity_problem) and [Variational inequality](wikipedia://en/1468817)) Biology [Gene regulatory network](wikipedia://en/356382), [Fluid Mechanics](https://en.wikipedia.org/wiki/Fluid_Mechanics) and [Computer graphics](https://en.wikipedia.org/wiki/Computer_graphics), etc.

## Components {#Components}

The software is based on 3 main components[^o5]

- Siconos/Numerics (C [API](https://en.wikipedia.org/wiki/API)). Collection of low-level [algorithms](wikipedia://en/775) for solving basic [Algebra](wikipedia://en/18716923) and optimization problems arising in the simulation of nonsmooth dynamical systems
  - [Linear complementarity problem](wikipedia://en/1470767) (LCP)
  - [Mixed linear complementarity problem](wikipedia://en/23629444) (MLCP)
  - [Nonlinear complementarity problem](wikipedia://en/26548937) (NCP)
  - [Quadratic programming](wikipedia://en/40324) problems (QP)
  - Friction-contact problems (2D or 3D) (Second-order cone programming (SOCP))
  - Primal or Dual Relay problems
- Siconos/Kernel. API C++ that allows one to model and simulate the nonsmooth dynamical systems. It contains
  - Dynamical systems classes : first order one, [Lagrangian systems](wikipedia://en/24585634), [Newton-Euler systems](wikipedia://en/3015195)
  - Nonsmooth laws : complementarity, Relay, Friction, Contact, [impact](https://en.wikipedia.org/wiki/Impact_%28mechanics%29)
- Siconos/Front-end (API Python) Mainly an auto-generated [SWIG](https://en.wikipedia.org/wiki/SWIG) interface of the API C++ which a special support for data structure.

## Performance {#Performance}

According to [peer reviewed](https://en.wikipedia.org/wiki/Peer_reviewed) studies published by its developers, Siconos was approximately five times faster than [Ngspice](https://en.wikipedia.org/wiki/Ngspice) or ELDO (a commercial SPICE by [Mentor Graphics](https://en.wikipedia.org/wiki/Mentor_Graphics)) and 250 times faster than [PLECS](https://en.wikipedia.org/wiki/PLECS) when solving a [buck converter](https://en.wikipedia.org/wiki/Buck_converter).[^o7][^o8]
