# Orbit capacity

::: {#o1 .subject cue=lead name="Orbit capacity"}

In [mathematics](wikipedia://en/18831), the **orbit capacity** of a subset of a [topological dynamical system](https://en.wikipedia.org/wiki/Topological_dynamical_system) may be thought of heuristically as a “topological dynamical [probability measure](wikipedia://en/45437)” of the subset. More precisely, its value for a set is a tight upper bound for the normalized number of visits of orbits in this set.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A topological dynamical system consists of a [compact](wikipedia://en/6042) [Hausdorff](wikipedia://en/13637) [topological space](wikipedia://en/30450) *X* and a [homeomorphism](wikipedia://en/13660) $T:X\rightarrow X$. Let $E\subset X$ be a set. [Lindenstrauss](wikipedia://en/28371257) introduced the definition of orbit capacity:[^o4]

$$\operatorname{ocap}(E)=\lim_{n\rightarrow\infty}\sup_{x\in X} \frac 1 n \sum_{k=0}^{n-1} \chi_E (T^k x)$$

Here, $\chi_E(x)$ is the [membership function](https://en.wikipedia.org/wiki/Membership_function) for the set $E$. That is $\chi_E(x)=1$ if $x\in E$ and is zero otherwise.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

One has $0\le\operatorname{ocap}(E)\le 1$. By convention, topological dynamical systems do not come equipped with a [measure](wikipedia://en/19873); the orbit capacity can be thought of as defining one, in a "natural" way. It is not a true measure, it is only a sub-additive:

- Orbit capacity is [sub-additive](wikipedia://en/745789):

$$\operatorname{ocap}(A\cup B)\leq \operatorname{ocap}(A)+\operatorname{ocap}(B)$$

- For a closed set *C*,

$$\operatorname{ocap}(C)=\sup_{\mu\in \operatorname{M}_T(X)}\mu(C)$$

Where M<sub>*T*</sub>(*X*) is the collection of *T*-[invariant probability measures](wikipedia://en/7635201) on *X*.

:::

## Small sets {#Small_sets}

When $\operatorname{ocap}(A)=0$, $A$ is called **small**. These sets occur in the definition of the [small boundary property](wikipedia://en/55638696).
