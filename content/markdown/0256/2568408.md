# Polymatroid

::: {#o1 .subject cue=lead name="Polymatroid"}

In mathematics, a **polymatroid** is a [polytope](wikipedia://en/23471) associated with a [submodular function](https://en.wikipedia.org/wiki/Submodular_function). The notion was introduced by [Jack Edmonds](wikipedia://en/3625459) in 1970.[^o16] It is also a generalization of the notion of a [matroid](wikipedia://en/244321).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Polyhedral definition {#Polyhedral_definition}

Let $E$ be a finite [set](wikipedia://en/26691) and $f: 2^E\rightarrow \mathbb{R}_{\geq 0}$ a non-decreasing [submodular function](wikipedia://en/33273315), that is, for each $A\subseteq B \subseteq E$ we have $f(A)\leq f(B)$, and for each $A, B \subseteq E$ we have $f(A)+f(B) \geq f(A\cup B) + f(A\cap B)$. We define the **polymatroid** associated to $f$ to be the following [polytope](wikipedia://en/23471):

$$P_f= \Big\{\textbf{x}\in \mathbb{R}_{\geq 0}^E~\Big|~\sum_{e\in U}\textbf{x}(e)\leq f(U), \forall U\subseteq E\Big\}.$$

When we allow the entries of $\textbf{x}$ to be negative we denote this polytope by $EP_f$, and call it the extended polymatroid associated to $f$.[^o17]

### Matroidal definition {#Matroidal_definition}

In matroid theory, polymatroids are defined as the pair consisting of the set and the function as in the above definition. That is, a **polymatroid** is a pair $(E, f)$ where $E$ is a [finite set](wikipedia://en/11742) and $f:2^E\rightarrow \mathbb{R}_{\geq 0}$, or $\mathbb{Z}_{\geq 0},$ is a non-decreasing submodular function. If the [codomain](wikipedia://en/50264) is $\mathbb{Z}_{\geq 0},$ we say that $(E,f)$ is an **integer polymatroid**. We call $E$ the **ground set** and $f$ the **rank function** of the polymatroid. This definition generalizes the definition of a matroid in terms of its rank function. A vector $x\in \mathbb{R}_{\geq 0}^E$ is **independent** if $\sum_{e\in U}x(e)\leq f(U)$ for all $U\subseteq E$. Let $P$ denote the set of independent vectors. Then $P$ is the polytope in the previous definition, called the **independence polytope** of the polymatroid.[^o6]

Under this definition, a matroid is a special case of integer polymatroid. While the rank of an element in a matroid can be either $0$ or $1$, the rank of an element in a polymatroid can be any nonnegative [real number](wikipedia://en/20646438), or nonnegative integer in the case of an integer polymatroid. In this sense, a polymatroid can be considered a multiset analogue of a matroid.

### Vector definition {#Vector_definition}

Let $E$ be a finite [set](wikipedia://en/26691). If $\textbf{u}, \textbf{v} \in \mathbb{R}^E$ then we denote by $|\textbf{u}|$ the sum of the entries of $\textbf{u}$, and write $\textbf{u} \leq \textbf{v}$ whenever $\textbf{v}(i)-\textbf{u}(i)\geq 0$ for every $i \in E$ (notice that this gives a [partial order](wikipedia://en/23572) to $\mathbb{R}_{\geq 0}^E$). A **polymatroid** on the ground set $E$ is a nonempty [compact](https://en.wikipedia.org/wiki/Compact_%28mathematics%29) subset $P$, the set of independent vectors, of $\mathbb{R}_{\geq 0}^E$ such that:

1. If $\textbf{v} \in P$, then $\textbf{u} \in P$ for every $\textbf{u}\leq \textbf{v}.$
1. If $\textbf{u},\textbf{v} \in P$ with $|\textbf{v}|> |\textbf{u}|$, then there is a vector $\textbf{w}\in P$ such that $\textbf{u}<\textbf{w}\leq (\max\{\textbf{u}(1),\textbf{v}(1)\},\dots,\max\{\textbf{u}({|E|}),\textbf{v}({|E|})\}).$

This definition is equivalent to the one described before,[^o18] where $f$ is the function defined by

$f(A) = \max\Big\{\sum_{i\in A} \textbf{v}(i)~\Big|~ \textbf{v} \in P\Big\}$ for every $A\subseteq E$.

The second property may be simplified to

If $\textbf{u},\textbf{v} \in P$ with $|\textbf{v}|> |\textbf{u}|$, then $(\max\{\textbf{u}(1),\textbf{v}(1)\},\dots,\max\{\textbf{u}({|E|}),\textbf{v}({|E|})\})\in P.$

Then compactness is implied if $P$ is assumed to be bounded.

:::

## Discrete polymatroids {#Discrete_polymatroids}

A **discrete polymatroid** or **integral polymatroid** is a polymatroid for which the codomain of $f$ is $\mathbb{Z}_{\geq 0}$, so the vectors are in $\mathbb{Z}^E_{\geq 0}$ instead of $\mathbb{R}^E_{\geq 0}$. Discrete polymatroids can be understood by focusing on the [lattice points](https://en.wikipedia.org/wiki/Lattice_points) of a polymatroid, and are of great interest because of their relationship to [monomial ideals](wikipedia://en/43023424).

Discrete polymatroids are related to matroids. Given a positive integer $k$, a discrete polymatroid $(E,f)$ (using the matroidal definition) is a **$k$-polymatroid** if $f(e) \leq k$ for all $e \in E$. Thus, a $1$-polymatroid is a matroid. Also, for any discrete polymatroid $(E, f)$, there is a matroid whose independent sets are the sets $A \subseteq E$ such that $f(U) \ge |U|$ for all $U \subseteq A$.[^o9]

## Relation to generalized permutahedra {#Relation_to_generalized_permutahedra}

A **generalized permutahedron** (alternative spelling: permutohedron) is a [polytope](wikipedia://en/23471) whose [normal fan](wikipedia://en/60958781) is a coarsening of the **braid fan**, defined by the hyperplanes $x_j = x_k$ in $\mathbb{R}^n$; note that the braid fan is the normal fan of the standard [permutahedron](https://en.wikipedia.org/wiki/Permutahedron). Thus the geometry of generalized permutahedra is intimately connected to the combinatorics of the [symmetric group](wikipedia://en/28901).

Alternatively, a generalized permutahedron can be characterized as a polytope obtained by parallel translations of the facets of the standard [permutahedron](https://en.wikipedia.org/wiki/Permutahedron).[^o11] Thus $P$ is a generalized permutahedron precisely if

$$P = \left\{ x \in \mathbb{R}^n : \, \sum_{i=1}^n x_i = z_{[n]}, \ \sum_{i \in S} x_i \ge z_S \, \text{ for all nonempty } \, S \subseteq [n] \right\}$$

for some submodular function $z: 2^{[n]} \to \mathbb{R}$.

The [0/1-polytopes](wikipedia://en/73074954) among generalized permutahedra are precisely the [matroid polytopes](wikipedia://en/38726681).

## Properties {#Properties}

$P_f$ is nonempty [if and only if](wikipedia://en/14922) $f\geq 0$ and that $EP_f$ is nonempty if and only if $f(\emptyset)\geq 0$.

Given any extended polymatroid $EP$ there is a unique submodular function $f$ such that $f(\emptyset)=0$ and $EP_f=EP$.

:::

## Contrapolymatroids {#Contrapolymatroids}

For a [supermodular](https://en.wikipedia.org/wiki/Supermodular) *f* one analogously may define the **contrapolymatroid**

$$\Big\{w \in\mathbb{R}_{\geq 0}^E~\Big|~\forall S \subseteq E, \sum_{e\in S}w(e)\ge f(S)\Big\}.$$

This analogously generalizes the dominant of the [spanning set](https://en.wikipedia.org/wiki/Spanning_set#Matroids) [polytope](wikipedia://en/23471) of matroids.
