# Narrow class group

::: {#o1 .subject cue=lead name="Narrow class group"}

In [algebraic number theory](wikipedia://en/174705), the **narrow class group** of a [number field](wikipedia://en/28730822) *K* is a refinement of the [class group](https://en.wikipedia.org/wiki/Class_group) of *K* that takes into account some information about embeddings of *K* into the [field](wikipedia://en/10603) of [real numbers](wikipedia://en/20646438).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Suppose that *K* is a [finite extension of **Q**](wikipedia://en/28730822). Recall that the ordinary class group of *K* is defined as the [quotient](wikipedia://en/11526)

$$C_K = I_K / P_K,\,$$

where *I*<sub>*K*</sub> is the [group](wikipedia://en/19447) of [fractional ideals](wikipedia://en/460700) of *K*, and *P*<sub>*K*</sub> is the [subgroup](wikipedia://en/28011) of principal fractional ideals of *K*, that is, ideals of the form *aO*<sub>*K*</sub> where *a* is an element of *K*.

The **narrow class group** is defined to be the quotient

$$C_K^+ = I_K / P_K^+,$$

where now *P*<sub>*K*</sub><sup>\+</sup> is the group of **totally positive principal fractional ideals** of *K*; that is, ideals of the form *aO*<sub>*K*</sub> where *a* is an element of *K* such that σ(*a*) is *positive* for every embedding

$$\sigma : K \to \mathbb{R}.$$

:::

::: {#o5 .application cue=heading name="Uses"}

## Uses {#Uses}

The narrow class group features prominently in the theory of representing [integers](wikipedia://en/14563) by [quadratic forms](wikipedia://en/251478). An example is the following result (Fröhlich and Taylor, Chapter V, Theorem 1.25).

**Theorem**. Suppose that $K = \mathbb{Q}(\sqrt{d}\,),$ where *d* is a [square-free integer](wikipedia://en/29525), and that the narrow class group of *K* is [trivial](wikipedia://en/193059). Suppose that

$$\{ \omega_1, \omega_2 \}\,\!$$

is a basis for the [ring of integers](wikipedia://en/460613) of *K*. Define a quadratic form

$$q_K(x,y) = N_{K/\mathbb{Q}}(\omega_1 x + \omega_2 y),$$

where *N*<sub>*K*/**Q**</sub> is the [norm](wikipedia://en/450555). Then a [prime number](wikipedia://en/23666) *p* is of the form

$$p = q_K(x,y)\,$$

for some integers *x* and *y* **if and only if** either

$$p \mid d_K\,\!,$$

or

$$p = 2 \quad \mbox{ and } \quad d_K \equiv 1 \pmod 8,$$

or

$$p > 2 \quad \mbox{ and} \quad \left(\frac {d_K} p\right) = 1,$$

where *d*<sub>*K*</sub> is the [discriminant](wikipedia://en/3022963) of *K*, and

$$\left(\frac ab\right)$$

denotes the [Legendre symbol](wikipedia://en/18567).

::: {#o7 .example cue=heading name="Examples"}

### Examples {#Examples}

For example, one can [prove](wikipedia://en/82285) that the [quadratic fields](wikipedia://en/454781) **Q**($\sqrt{-1}$), **Q**($\sqrt{2}$), **Q**($\sqrt{-3}$) all have trivial narrow class group. Then, by choosing appropriate bases for the integers of each of these fields, the above [theorem](wikipedia://en/30977) implies the following:

- A prime *p* is of the form *p* = *x*<sup>2</sup> + *y*<sup>2</sup> for integers *x* and *y* if and only if

$$p = 2 \quad \mbox{or} \quad p \equiv 1 \pmod 4.$$

(This is known as [Fermat's theorem on sums of two squares](wikipedia://en/1850216).)

- A prime *p* is of the form *p* = *x*<sup>2</sup> − 2*y*<sup>2</sup> for integers *x* and *y* if and only if

$$p = 2 \quad \mbox{or} \quad p \equiv 1, 7 \pmod 8.$$

- A prime *p* is of the form *p* = *x*<sup>2</sup> − *xy* + *y*<sup>2</sup> for integers *x* and *y* if and only if

$p = 3 \quad \mbox{or} \quad p \equiv 1 \pmod 3.$ (cf. [Eisenstein prime](https://en.wikipedia.org/wiki/Eisenstein_prime))

An example that illustrates the difference between the narrow class group and the usual [class group](wikipedia://en/150907) is the case of **Q**($\sqrt{6}$). This has trivial class group, but its narrow class group has [order](https://en.wikipedia.org/wiki/Order_of_a_group) 2. Because the class group is trivial, the following statement is true:

- A prime *p* or its inverse −*p* is of the form ± *p* = *x*<sup>2</sup> − 6*y*<sup>2</sup> for integers *x* and *y* if and only if

$$p = 2 \quad \mbox{or} \quad p = 3 \quad \mbox{or} \quad \left(\frac{6}{p}\right)=1.$$

However, this statement is false if we focus only on *p* and not −*p* (and is in fact even false for *p* = 2), because the narrow class group is nontrivial. The statement that classifies the positive *p* is the following:

- A prime *p* is of the form *p* = *x*<sup>2</sup> − 6*y*<sup>2</sup> for integers *x* and *y* if and only if *p* = 3 or

$$\left(\frac{6}{p}\right)=1 \quad \mbox{and}\quad \left(\frac{-2}{p}\right)=1.$$

(Whereas the first statement allows primes $p \equiv 1, 5, 19, 23 \pmod {24}$, the second only allows primes $p \equiv 1, 19 \pmod {24}$.)
