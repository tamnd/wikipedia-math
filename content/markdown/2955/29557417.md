# Metavariable

::: {#o1 .subject cue=lead name="Metavariable"}

In [logic](wikipedia://en/46426065), a **metavariable** (also **metalinguistic variable**[^n1] or **syntactical variable**)[^o3] is a [symbol](wikipedia://en/24028642) or symbol string which belongs to a [metalanguage](wikipedia://en/402929) and stands for elements of some object language. For instance, in the sentence

:::

*Let **A** and **B** be two sentences of a language ℒ*

the symbols **A** and **B** are part of the metalanguage in which the statement about the object language ℒ is formulated.

[John Corcoran](wikipedia://en/23686234) considered this terminology unfortunate because it obscures the use of [schemata](https://en.wikipedia.org/wiki/Schema_%28logic%29) and because such "variables" do not actually range over a domain.[^o4](November 2012)

The convention is that a metavariable is to be uniformly substituted with the same instance in all its appearances in a given schema. This is in contrast with [nonterminal](https://en.wikipedia.org/wiki/Nonterminal) symbols in [formal grammars](https://en.wikipedia.org/wiki/Formal_grammars) where the nonterminals on the right of a production can be substituted by different instances.[^o5]

Attempts to formalize the notion of metavariable result in some kind of [type theory](wikipedia://en/40282).[^o6]
