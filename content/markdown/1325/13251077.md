# Arborescence (graph theory)

*Image: Arborescence.png.* An instance of an arborescence, where any vertex $v$ has exactly one directed walk from the root vertex to itself.

::: {#o1 .subject cue=lead name="Arborescence"}

In [graph theory](wikipedia://en/12401), an **arborescence** is a [directed graph](wikipedia://en/19721986) where there exists a [vertex](wikipedia://en/638899) $r$ (called the *root*) such that, for any other vertex $v$, there is exactly one [directed walk](wikipedia://en/638889) from $r$ to $v$ (noting that the root $r$ is unique).[^o2] An arborescence is thus the directed-graph form of a [rooted tree](https://en.wikipedia.org/wiki/Rooted_tree), understood here as an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph).[^o3][^o9] An arborescence is also a directed rooted [tree](wikipedia://en/48560) in which all edges point away from the root; a number of other equivalent characterizations exist.[^o4][^o5]

:::

Every arborescence is a [directed acyclic graph](wikipedia://en/204002) (DAG), but not every DAG is an arborescence.

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

The term *arborescence* comes from French.[^o8] Some authors object to it on grounds that it is cumbersome to spell.[^o10] There is a large number of synonyms for arborescence in graph theory, including **directed rooted tree**,[^o9][^o10] **out-arborescence**,[^o11] **out-tree**,[^o12] and even **branching** being used to denote the same concept.[^o12] *Rooted tree* itself has been defined by some authors as a directed graph.[^o13][^o14][^o16]

### Further definitions {#Further_definitions}

Furthermore, some authors define an arborescence to be a spanning directed tree of a given digraph.[^o16] The same can be said about some of its synonyms, especially *branching*.[^o17] Other authors use *branching* to denote a forest of arborescences, with the latter notion defined in broader sense given at beginning of this article,[^o18][^o19] but a variation with both notions of the spanning flavor is also encountered.[^o16]

It's also possible to define a useful notion by reversing all the edges of an arborescence, i.e. making them all point in the direction of the root rather than away from it. Such digraphs are also designated by a variety of terms, such as **in-tree**[^o20] or **anti-arborescence**.[^o21] [W. T. Tutte](wikipedia://en/52021) distinguishes between the two cases by using the phrases *arborescence diverging from* \[some root\] and *arborescence converging to* \[some root\].[^o22]

The number of rooted trees (or arborescences) with $n$ nodes is given by the sequence:

0, 1, 1, 2, 4, 9, 20, 48, 115, 286, 719, 1842, 4766, 12486, ... .
