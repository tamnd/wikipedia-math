# Parity of zero

*Image: Scale of justice 2.svg.* The weighing pans of this [balance scale](https://en.wikipedia.org/wiki/Balance_scale) contain zero objects, divided into two equal groups.

EN-Parity\_of\_zero.ogg

::: {#o1 .subject cue=lead name="Parity of zero"}

In mathematics, [zero](wikipedia://en/34513) is an [even number](https://en.wikipedia.org/wiki/Even_number). In other words, its [parity](wikipedia://en/143135)—the quality of an [integer](wikipedia://en/14563) being even or odd—is even. This can be easily verified based on the definition of "even": zero is an integer [multiple](wikipedia://en/3912709) of [2](https://en.wikipedia.org/wiki/2_%28number%29), specifically 0 × 2. As a result, zero shares all the properties that characterize even numbers: for example, 0 is neighbored on both sides by odd numbers, any decimal integer has the same parity as its last digit—so, since 10 is even, 0 will be even, and if $y$ is even then $y + x$ has the same parity as $x$—indeed, $0 + x$ and $x$ always have the same parity.

:::

Zero also fits into the patterns formed by other even numbers. The parity rules of arithmetic, such as *even* − *even* = *even*, require 0 to be even. Zero is the additive [identity element](wikipedia://en/14962) of the [group](wikipedia://en/19447) of even integers, and it is the starting case from which other even [natural numbers](wikipedia://en/21474) are [recursively defined](wikipedia://en/1047605). Applications of this recursion from [graph theory](wikipedia://en/12401) to [computational geometry](wikipedia://en/176927) rely on zero being even. Not only is 0 divisible by 2, it is divisible by every [power of 2](https://en.wikipedia.org/wiki/Power_of_2), which is relevant to the [binary numeral system](https://en.wikipedia.org/wiki/Binary_numeral_system) used by computers. In this sense, 0 is the "most even" number of all.[^o2]

Among the general public, the parity of zero can be a source of confusion. In [reaction time](https://en.wikipedia.org/wiki/Reaction_time) experiments, most people are slower to identify 0 as even than 2, 4, 6, or 8. Some teachers—and some children in mathematics classes—think that zero is odd, or both even and odd, or neither. Researchers in [mathematics education](wikipedia://en/326471) propose that these misconceptions can become learning opportunities. Studying equalities like 0 × 2 = 0 can address students' doubts about calling 0 a [number](wikipedia://en/21690) and using it in [arithmetic](wikipedia://en/3118). Class discussions can lead students to appreciate the basic principles of mathematical reasoning, such as the importance of definitions. Evaluating the parity of this exceptional number is an early example of a pervasive theme in mathematics: the [abstraction](wikipedia://en/454446) of a familiar concept to an unfamiliar setting.

## Why zero is even {#Why_zero_is_even}

The standard definition of "even number" can be used to directly [prove](wikipedia://en/82285) that zero is even. A number is called "even" if it is an integer multiple of 2. As an example, the reason that 10 is even is that it equals 5 × 2. In the same way, zero is an integer multiple of 2, namely 0 × 2, so zero is even.[^o4]

It is also possible to explain why zero is even without referring to formal definitions.[^o5] The following explanations make sense of the idea that zero is even in terms of fundamental number concepts. From this foundation, one can provide a rationale for the definition itself—and its applicability to zero.

### Basic explanations {#Basic_explanations}

*Image: 012345Pairs.svg.* The box with 0 objects has no red object left over.[^o7]

Given a set of objects, one uses a number to describe how many objects are in the set. Zero is the count of *no objects*; in more formal terms, it is the number of objects in the [empty set](wikipedia://en/9566). The concept of parity is used for making groups of two objects. If the objects in a set can be marked off into groups of two, with none left over, then the number of objects is even. If an object is left over, then the number of objects is odd. The empty set contains zero groups of two, and no object is left over from this grouping, so zero is even.[^o8]

These ideas can be illustrated by drawing objects in pairs. It is difficult to depict zero groups of two, or to emphasize the nonexistence of a leftover object, so it helps to draw other groupings and to compare them with zero. For example, in the group of five objects, there are two pairs. More importantly, there is a leftover object, so 5 is odd. In the group of four objects, there is no leftover object, so 4 is even. In the group of just one object, there are no pairs, and there is a leftover object, so 1 is odd. In the group of zero objects, there is no leftover object, so 0 is even.[^o9]

There is another concrete definition of evenness: if the objects in a set can be placed into two groups of equal size, then the number of objects is even. This definition is equivalent to the first one. Again, zero is even because the empty set can be divided into two groups of zero items each.[^n1]

Numbers can also be visualized as points on a [number line](wikipedia://en/287188). When even and odd numbers are distinguished from each other, their pattern becomes obvious, especially if negative numbers are included:

*Image: EvenOddNumberLine.svg.*

The even and odd numbers alternate. Starting at any even number, [counting](wikipedia://en/275768) up or down by twos reaches the other even numbers, and there is no reason to skip over zero.[^o11]

With the introduction of [multiplication](wikipedia://en/20845), parity can be approached in a more formal way using arithmetic expressions. Every integer is either of the form (2 × ▢) + 0 or (2 × ▢) + 1; the former numbers are even and the latter are odd. For example, 1 is odd because 1 = (2 × 0) + 1, and 0 is even because 0 = (2 × 0) + 0. Making a table of these facts then reinforces the number line picture above.[^o12]

### Defining parity {#Defining_parity}

The precise [definition](wikipedia://en/7964) of a mathematical term, such as "even" meaning "integer multiple of two", is ultimately a [convention](https://en.wikipedia.org/wiki/Convention_%28norm%29). Unlike "even", some mathematical terms are purposefully constructed to exclude [trivial](https://en.wikipedia.org/wiki/Trivial_%28mathematics%29) or [degenerate](https://en.wikipedia.org/wiki/Degenerate_%28mathematics%29) cases. [Prime numbers](wikipedia://en/23666) are a famous example. Before the 20th century, definitions of primality were inconsistent, and significant mathematicians such as [Goldbach](wikipedia://en/6290), [Lambert](wikipedia://en/93085), [Legendre](wikipedia://en/49695), [Cayley](wikipedia://en/311034), and [Kronecker](wikipedia://en/318450) wrote that 1 was prime.[^n2] The modern definition of "prime number" is "positive integer with exactly 2 [factors](wikipedia://en/49492)", so 1 is not prime. This definition can be rationalized by observing that it more naturally suits mathematical theorems that concern the primes. For example, the [fundamental theorem of arithmetic](wikipedia://en/11556) is easier to state when 1 is not considered prime.[^o15]

It would be possible to similarly redefine the term "even" in a way that no longer includes zero. However, in this case, the new definition would make it more difficult to state theorems concerning the even numbers. Already the effect can be seen in [the algebraic rules governing even and odd numbers](wikipedia://en/143135#Properties).[^o16] The most relevant rules concern [addition](wikipedia://en/61338), [subtraction](wikipedia://en/74141), and [multiplication](wikipedia://en/20845):

even ± even = even

odd ± odd = even

even × integer = even

Inserting appropriate values into the left sides of these rules, one can produce 0 on the right sides:

2 − 2 = 0

−3 + 3 = 0

4 × 0 = 0

The above rules would therefore be incorrect if zero were not even.[^o16] At best they would have to be modified. For example, one test study guide asserts that even numbers are characterized as integer multiples of two, but zero is "neither even nor odd".[^o17] Accordingly, the guide's rules for even and odd numbers contain exceptions:

even ± even = even **(or zero)**

odd ± odd = even **(or zero)**

even × **nonzero** integer = even[^o17]

Making an exception for zero in the definition of evenness forces one to make such exceptions in the rules for even numbers. From another perspective, taking the rules obeyed by positive even numbers and requiring that they continue to hold for integers forces the usual definition and the evenness of zero.[^o16]

## Mathematical contexts {#Mathematical_contexts}

Countless results in [number theory](wikipedia://en/21527) invoke the fundamental theorem of arithmetic and the algebraic properties of even numbers, so the above choices have far-reaching consequences. For example, the fact that positive numbers have unique [factorizations](wikipedia://en/15491) means that one can determine whether a number has an even or odd number of distinct prime factors. Since 1 is not prime, nor does it have prime factors, it is a [product of 0](wikipedia://en/181289) distinct primes; since 0 is an even number, 1 has an even number of distinct prime factors. This implies that the [Möbius function](wikipedia://en/20961) takes the value μ(1) = 1, which is necessary for it to be a [multiplicative function](wikipedia://en/20059) and for the [Möbius inversion formula](wikipedia://en/20963) to work.[^o19]

### Not being odd {#Not_being_odd}

A number $n$ is odd if there is an integer $k$ such that $n = 2k + 1$. One way to prove that zero is not odd is [by contradiction](https://en.wikipedia.org/wiki/Proof_by_contradiction): if $0 = 2k + 1$ then $k = -1/2$, which is not an integer.[^n3] Since zero is not odd, if an unknown number is proven to be odd, then it cannot be zero. This apparently trivial observation can provide a convenient and revealing proof explaining why an odd number is nonzero.

A classic result of [graph theory](wikipedia://en/12401) states that a [graph](wikipedia://en/325806) of odd [order](https://en.wikipedia.org/wiki/Order_%28graph_theory%29) (having an odd number of vertices) always has at least one [vertex of even degree](wikipedia://en/1374448). (The statement itself requires zero to be even: the [empty graph](https://en.wikipedia.org/wiki/Empty_graph) has an even order, and an [isolated vertex](https://en.wikipedia.org/wiki/Isolated_vertex) has an even degree.)[^o22] In order to prove the statement, it is actually easier to prove a stronger result: any odd-order graph has an *odd number* of even degree vertices. The appearance of this odd number is explained by a still more general result, known as the [handshaking lemma](wikipedia://en/9607933): any graph has an even number of vertices of odd degree.[^o23] Finally, the even number of odd vertices is naturally explained by the [degree sum formula](https://en.wikipedia.org/wiki/Degree_sum_formula).

[Sperner's lemma](wikipedia://en/465067) is a more advanced application of the same strategy. The lemma states that a certain kind of [coloring](wikipedia://en/426743) on a [triangulation](wikipedia://en/1440970) of a [simplex](wikipedia://en/39781) has a subsimplex that contains every color. Rather than directly construct such a subsimplex, it is more convenient to prove that there exists an odd number of such subsimplices through an [induction](wikipedia://en/18881) argument.[^o24] A stronger statement of the lemma then explains why this number is odd: it naturally breaks down as (*n* + 1) + *n* when one considers the two possible [orientations](https://en.wikipedia.org/wiki/Orientation_%28mathematics%29) of a simplex.[^o25]

### Even-odd alternation {#Even-odd_alternation}

*Image: RecursiveEven.svg.* Recursive definition of natural number parity

The fact that zero is even, together with the fact that even and odd numbers alternate, is enough to determine the parity of every other [natural number](wikipedia://en/21474). This idea can be formalized into a [recursive definition](wikipedia://en/1047605) of the set of even natural numbers:

- 0 is even.
- (*n* + 1) is even if and only if *n* is not even.

This definition has the conceptual advantage of relying only on the minimal foundations of the natural numbers: the existence of 0 and of [successors](wikipedia://en/325637). As such, it is useful for computer logic systems such as [LF](https://en.wikipedia.org/wiki/Edinburgh_Logical_Framework) and the [Isabelle theorem prover](https://en.wikipedia.org/wiki/Isabelle_%28theorem_prover%29).[^o27] With this definition, the evenness of zero is not a theorem but an axiom. Indeed, "zero is an even number" may be interpreted as one of the [Peano axioms](wikipedia://en/25005), of which the even natural numbers are a model.[^o28] A similar construction [extends the definition of parity](wikipedia://en/14415118) to transfinite [ordinal numbers](wikipedia://en/26547932): every [limit ordinal](wikipedia://en/373137) is even, including zero, and [successors](wikipedia://en/375256) of even ordinals are odd.[^o29]

*Image: RecursiveEvenPolygon.svg.* Point in polygon test

The classic [point in polygon](wikipedia://en/504484) test from [computational geometry](wikipedia://en/176927) applies the above ideas. To determine if a point lies within a [polygon](wikipedia://en/23621), one casts a [ray](https://en.wikipedia.org/wiki/Ray_%28mathematics%29) from infinity to the point and counts the number of times the ray crosses the edge of polygon. The crossing number is even [if and only if](wikipedia://en/14922) the point is outside the polygon. This [algorithm](wikipedia://en/775) works because if the ray never crosses the polygon, then its crossing number is zero, which is even, and the point is outside. Every time the ray does cross the polygon, the crossing number alternates between even and odd, and the point at its tip alternates between outside and inside.[^o30]

*Image: RecursiveEvenBipartite.svg.* Constructing a bipartition

In graph theory, a [bipartite graph](wikipedia://en/244431) is a graph whose vertices are split into two [colors](wikipedia://en/426743), such that neighboring vertices have different colors. If a [connected](https://en.wikipedia.org/wiki/Connected_graph) graph has no odd [cycles](wikipedia://en/168609), then a bipartition can be constructed by choosing a base vertex *v* and coloring every vertex black or white, depending on whether its [distance](wikipedia://en/1020021) from *v* is even or odd. Since the distance between *v* and itself is 0, and 0 is even, the base vertex is colored differently from its neighbors, which lie at a distance of 1.[^o31]

### Algebraic patterns {#Algebraic_patterns}

*Image: EvenIntegersSubgroup.svg.* 2**Z** (blue) as subgroup of **Z**

In [abstract algebra](wikipedia://en/19616384), the even integers form various [algebraic structures](wikipedia://en/106364) that require the inclusion of zero. The fact that the [additive identity](wikipedia://en/4178225) (zero) is even, together with the evenness of sums and [additive inverses](wikipedia://en/228312) of even numbers and the [associativity](https://en.wikipedia.org/wiki/Associativity) of addition, means that the even integers form a [group](wikipedia://en/19447). Moreover, the group of even integers under addition is a [subgroup](wikipedia://en/28011) of the group of all integers; this is an elementary example of the subgroup concept.[^o22] The earlier observation that the rule "even − even = even" forces 0 to be even is part of a general pattern: any [nonempty](https://en.wikipedia.org/wiki/Nonempty) subset of an additive group that is [closed under](https://en.wikipedia.org/wiki/Closed_under) subtraction must be a subgroup, and in particular, must contain the [identity](wikipedia://en/14962).[^o33]

Since the even integers form a subgroup of the integers, they [partition](wikipedia://en/340240) the integers into [cosets](wikipedia://en/98759). These cosets may be described as the [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes) of the following [equivalence relation](wikipedia://en/9259): *x* ~ *y* if (*x* − *y*) is even. Here, the evenness of zero is directly manifested as the [reflexivity](wikipedia://en/200458) of the [binary relation](wikipedia://en/3931) ~.[^o34] There are only two cosets of this subgroup—the even and odd numbers—so it has [index](wikipedia://en/230581) 2.

Analogously, the [alternating group](wikipedia://en/49726) is a subgroup of index 2 in the [symmetric group](wikipedia://en/28901) on *n* letters. The elements of the alternating group, called [even permutations](https://en.wikipedia.org/wiki/Even_permutation), are the products of even numbers of [transpositions](https://en.wikipedia.org/wiki/Transposition_%28mathematics%29). The [identity map](wikipedia://en/15069), an [empty product](wikipedia://en/181289) of no transpositions, is an even permutation since zero is even; it is the identity element of the group.[^o35]

The rule "even × integer = even" means that the even numbers form an [ideal](wikipedia://en/25977) in the [ring](wikipedia://en/48404) of integers, and the above equivalence relation can be described as [equivalence modulo this ideal](wikipedia://en/20087). In particular, even integers are exactly those integers *k* where *k* ≡ 0 (mod 2). This formulation is useful for investigating integer [zeroes](https://en.wikipedia.org/wiki/Root_of_a_function) of [polynomials](wikipedia://en/23000).[^o36]

### 2-adic order {#2-adic_order}

There is a sense in which some multiples of 2 are "more even" than others. Multiples of 4 are called [doubly even](https://en.wikipedia.org/wiki/Doubly_even), since they can be divided by 2 twice. Not only is zero divisible by 4, zero has the unique property of being divisible by every [power of 2](https://en.wikipedia.org/wiki/Power_of_2), so it surpasses all other numbers in "evenness".[^o2]

One consequence of this fact appears in the [bit-reversed ordering](https://en.wikipedia.org/wiki/Bit-reversed_order) of [integer data types](https://en.wikipedia.org/wiki/Integer_%28computer_science%29) used by some computer algorithms, such as the [Cooley–Tukey](wikipedia://en/352702) [fast Fourier transform](wikipedia://en/11512). This ordering has the property that the farther to the left the first 1 occurs in a number's [binary expansion](https://en.wikipedia.org/wiki/Binary_expansion), or the more times it is divisible by 2, the sooner it appears. Zero's bit reversal is still zero; it can be divided by 2 any number of times, and its binary expansion does not contain any 1s, so it always comes first.[^o38]

Although 0 is divisible by 2 more times than any other number, it is not straightforward to quantify exactly how many times that is. For any nonzero integer *n*, one may define the [2-adic order](https://en.wikipedia.org/wiki/2-adic_order) of *n* to be the number of times *n* is divisible by 2. This description does not work for 0; no matter how many times it is divided by 2, it can always be divided by 2 again. Rather, the usual convention is to set the 2-order of 0 to be [infinity](wikipedia://en/20110824) as a special case.[^o39] This convention is not peculiar to the 2-order; it is one of the axioms of an additive [valuation](wikipedia://en/347049) in higher algebra.[^o40]

The powers of two—1, 2, 4, 8, ...—form a simple [sequence](wikipedia://en/27838) of numbers of increasing 2-order. In the [2-adic numbers](wikipedia://en/51423), such sequences actually [converge](wikipedia://en/285773) to zero.[^o41]

## Education {#Education}

*Image: FrobisherZeroParity.svg.* Percentage responses over time[^o43]

The subject of the parity of zero is often treated within the first two or three years of [primary education](https://en.wikipedia.org/wiki/Primary_education), as the concept of even and odd numbers is introduced and developed.[^o44]

### Students' knowledge {#Students'_knowledge}

The chart on the right[^o43] depicts children's beliefs about the parity of zero, as they progress from [Year 1](https://en.wikipedia.org/wiki/Year_One_%28School%29) (age 5–6 years) to [Year 6](https://en.wikipedia.org/wiki/Year_Six_%28School%29) (age 10–11 years) of the [English education system](https://en.wikipedia.org/wiki/Education_in_England). The data is from Len Frobisher, who conducted a pair of surveys of English schoolchildren. Frobisher was interested in how knowledge of single-digit parity translates to knowledge of multiple-digit parity, and zero figures prominently in the results.[^o46]

In a preliminary survey of nearly 400 seven-year-olds, 45% chose *even* over *odd* when asked the parity of zero.[^o47] A follow-up investigation offered more choices: *neither*, *both*, and *don't know*. This time the number of children in the same age range identifying zero as even dropped to 32%.[^o48] Success in deciding that zero is even initially shoots up and then levels off at around 50% in Years 3 to 6.[^o49] For comparison, the easiest task, identifying the parity of a single digit, levels off at about 85% success.[^o50]

In interviews, Frobisher elicited the students' reasoning. One fifth-year decided that 0 was even because it was found on the 2 [times table](https://en.wikipedia.org/wiki/Times_table). A couple of fourth-years realized that zero can be split into equal parts. Another fourth-year reasoned "1 is odd and if I go down it's even."[^o51] The interviews also revealed the misconceptions behind incorrect responses. A second-year was "quite convinced" that zero was odd, on the basis that "it is the first number you count".[^o52] A fourth-year referred to 0 as "none" and thought that it was neither odd nor even, since "it's not a number".[^o53] In another study, Annie Keith observed a class of 15 second-graders who convinced each other that zero was an even number based on even-odd alternation and on the possibility of splitting a group of zero things in two equal groups.[^o54]

More in-depth investigations were conducted by Esther Levenson, Pessia Tsamir, and Dina Tirosh, who interviewed a pair of sixth-grade students in the USA who were performing highly in their mathematics class. One student preferred deductive explanations of mathematical claims, while the other preferred practical examples. Both students initially thought that 0 was neither even nor odd, for different reasons. Levenson et al. demonstrated how the students' reasoning reflected their concepts of zero and division.[^o55]

[Deborah Loewenberg Ball](https://en.wikipedia.org/wiki/Deborah_Loewenberg_Ball) analyzed US third grade students' ideas about even and odd numbers and zero, which they had just been discussing with a group of fourth-graders. The students discussed the parity of zero, the rules for even numbers, and how mathematics is done. The claims about zero took many forms, as seen in the list on the right.[^o57] Ball and her coauthors argued that the episode demonstrated how students can "do mathematics in school", as opposed to the usual reduction of the discipline to the mechanical solution of exercises.[^n4]

One of the themes in the research literature is the tension between students' [concept images](https://en.wikipedia.org/wiki/Concept_image) of parity and their concept definitions.[^o59] Levenson et al.'s sixth-graders both defined even numbers as multiples of 2 or numbers divisible by 2, but they were initially unable to apply this definition to zero, because they were unsure how to multiply or divide zero by 2. The interviewer eventually led them to conclude that zero was even; the students took different routes to this conclusion, drawing on a combination of images, definitions, practical explanations, and abstract explanations. In another study, David Dickerson and Damien Pitman examined the use of definitions by five advanced [undergraduate](https://en.wikipedia.org/wiki/Undergraduate_education) mathematics [majors](https://en.wikipedia.org/wiki/Academic_major). They found that the undergraduates were largely able to apply the definition of "even" to zero, but they were still not convinced by this reasoning, since it conflicted with their concept images.[^n5]

### Teachers' knowledge {#Teachers'_knowledge}

Researchers of [mathematics education](wikipedia://en/326471) at the [University of Michigan](https://en.wikipedia.org/wiki/University_of_Michigan) have included the true-or-false prompt "0 is an even number" in a database of over 250 questions designed to measure teachers' content knowledge. For them, the question exemplifies "common knowledge ... that any well-educated adult should have", and it is "ideologically neutral" in that the answer does not vary between [traditional](https://en.wikipedia.org/wiki/Traditional_mathematics) and [reform mathematics](wikipedia://en/9902256). In a 2000–2004 study of 700 primary teachers in the [United States](https://en.wikipedia.org/wiki/United_States), overall performance on these questions significantly predicted improvements in students' [standardized test](https://en.wikipedia.org/wiki/Standardized_test) scores after taking the teachers' classes.[^o62] In a more in-depth 2008 study, the researchers found a school where all of the teachers thought that zero was neither odd nor even, including one teacher who was exemplary by all other measures. The misconception had been spread by a math coach in their building.[^n6]

It is uncertain how many teachers harbor misconceptions about zero. The Michigan studies did not publish data for individual questions. Betty Lichtenberg, an associate professor of mathematics education at the [University of South Florida](https://en.wikipedia.org/wiki/University_of_South_Florida), in a 1972 study reported that when a group of prospective elementary school teachers were given a true-or-false test including the item "Zero is an even number", they found it to be a "tricky question", with about two thirds answering "False".[^o64]

### Implications for instruction {#Implications_for_instruction}

Mathematically, proving that zero is even is a simple matter of applying a definition, but more explanation is needed in the context of education. One issue concerns the foundations of the proof; the definition of "even" as "integer multiple of 2" is not always appropriate. A student in the first years of primary education may not yet have learned what "integer" or "multiple" means, much less how to multiply with 0.[^o66] Additionally, stating a definition of parity for all integers can seem like an arbitrary conceptual shortcut if the only even numbers investigated so far have been positive. It can help to acknowledge that as the number concept is extended from positive integers to include zero and negative integers, number properties such as parity are also extended in a nontrivial way.[^o67]

## Numerical cognition {#Numerical_cognition}

*Image: Nuerk figure 4 bare.svg.* Statistical analysis of experimental data, showing separation of 0. In this [smallest space analysis](https://en.wikipedia.org/wiki/Smallest_space_analysis), only the clustering of data is meaningful; the axes are arbitrary.[^o69]

Adults who do believe that zero is even can nevertheless be unfamiliar with thinking of it as even, enough so to measurably slow them down in a [reaction time](https://en.wikipedia.org/wiki/Reaction_time) experiment. [Stanislas Dehaene](https://en.wikipedia.org/wiki/Stanislas_Dehaene), a pioneer in the field of [numerical cognition](wikipedia://en/6258906), led a series of such experiments in the early 1990s. A [numeral](wikipedia://en/21170) is flashed to the subject on a [monitor](https://en.wikipedia.org/wiki/Computer_display), and a [computer](https://en.wikipedia.org/wiki/Computer) records the time it takes the subject to push one of two buttons to identify the number as odd or even. The results showed that 0 was slower to process than other even numbers. Some variations of the experiment found delays as long as 60 [milliseconds](https://en.wikipedia.org/wiki/Millisecond) or about 10% of the average reaction time—a small difference but a significant one.[^o70]

Dehaene's experiments were not designed specifically to investigate 0 but to compare competing models of how parity information is processed and extracted. The most specific model, the mental calculation hypothesis, suggests that reactions to 0 should be fast; 0 is a small number, and it is easy to calculate 0 × 2 = 0. (Subjects are known to compute and name the result of multiplication by zero faster than multiplication of nonzero numbers, although they are slower to verify proposed results like 2 × 0 = 0.) The results of the experiments suggested that something quite different was happening: parity information was apparently being recalled from memory along with a cluster of related properties, such as being [prime](wikipedia://en/23666) or a [power of two](wikipedia://en/376948). Both the sequence of powers of two and the sequence of positive even numbers 2, 4, 6, 8, ... are well-distinguished mental categories whose members are prototypically even. Zero belongs to neither list, hence the slower responses.[^o71]

Repeated experiments have shown a delay at zero for subjects with a variety of ages and national and linguistic backgrounds, confronted with number names in [numeral](wikipedia://en/21170) form, spelled out, and spelled in a mirror image. Dehaene's group did find one differentiating factor: mathematical expertise. In one of their experiments, students in the [École Normale Supérieure](https://en.wikipedia.org/wiki/École_Normale_Supérieure) were divided into two groups: those in literary studies and those studying mathematics, physics, or biology. The slowing at 0 was "essentially found in the \[literary\] group", and in fact, "before the experiment, some L subjects were unsure whether 0 was odd or even and had to be reminded of the mathematical definition".[^o72]

This strong dependence on familiarity again undermines the mental calculation hypothesis.[^o73] The effect also suggests that it is inappropriate to include zero in experiments where even and odd numbers are compared as a group. As one study puts it, "Most researchers seem to agree that zero is not a typical even number and should not be investigated as part of the mental number line."[^o74]

## Everyday contexts {#Everyday_contexts}

Some of the contexts where the parity of zero makes an appearance are purely rhetorical. Linguist Joseph Grimes muses that asking, "Is zero an even number?" to married couples is a good way to get them to disagree.[^o76] People who think that zero is neither even nor odd may use the parity of zero as proof that every rule has a [counterexample](wikipedia://en/143151),[^o77] or as an example of a [trick question](https://en.wikipedia.org/wiki/Trick_question).[^o78]

Around the year 2000, media outlets noted a pair of unusual milestones: "1999/11/19" was the last [calendar date](https://en.wikipedia.org/wiki/Calendar_date) composed of all odd digits that would occur for a very long time, and that "2000/02/02" was the first all-even date to occur in a very long time.[^o79] Since these results make use of 0 being even, some readers disagreed with the idea.[^o80]

In [standardized tests](https://en.wikipedia.org/wiki/Standardized_test), if a question asks about the behavior of even numbers, it might be necessary to keep in mind that zero is even.[^o81] Official publications relating to the [GMAT](https://en.wikipedia.org/wiki/Graduate_Management_Admission_Test) and [GRE](https://en.wikipedia.org/wiki/Graduate_Record_Examinations) tests both state that 0 is even.[^o82]

The parity of zero is relevant to [odd–even rationing](wikipedia://en/24013164), in which cars may drive or purchase [gasoline](https://en.wikipedia.org/wiki/Gasoline) on alternate days, according to the parity of the last digit in their [license plates](https://en.wikipedia.org/wiki/License_plate). Half of the numbers in a given range end in 0, 2, 4, 6, 8 and the other half in 1, 3, 5, 7, 9, so it makes sense to include 0 with the other even numbers. However, in 1977, a Paris rationing system led to confusion; on an odd-only day, the police did not know whether 0 was even, so they avoided fining drivers whose plates ended in 0.[^o83] To avoid such confusion, the relevant legislation sometimes stipulates that zero is even; such laws have been passed in [New South Wales](https://en.wikipedia.org/wiki/New_South_Wales)[^o84] and [Maryland](https://en.wikipedia.org/wiki/Maryland).[^o85]

On [U.S. Navy](https://en.wikipedia.org/wiki/United_States_Navy) vessels, even-numbered compartments are found on the [port](https://en.wikipedia.org/wiki/Port_%28nautical%29) side, but zero is reserved for compartments that intersect the centerline. That is, the numbers read 6-4-2-0-1-3-5 from port to starboard.[^o86]

In the game of [roulette](https://en.wikipedia.org/wiki/Roulette), the number 0 does not count as even or odd, giving the [casino](https://en.wikipedia.org/wiki/Casino) an advantage on such bets.[^o87] Similarly, the parity of zero can affect payoffs in [prop bets](https://en.wikipedia.org/wiki/Proposition_bet) when the outcome depends on whether some randomized number is odd or even, and it turns out to be zero.[^o88]

The game of "[odds and evens](https://en.wikipedia.org/wiki/Odds_and_evens_%28hand_game%29)" is also affected: if both players cast zero fingers, the total number of fingers is zero, so the even player wins.[^o89] One teachers' manual suggests playing this game as a way to introduce children to the concept that 0 is divisible by 2.[^o90]
