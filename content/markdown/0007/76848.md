# Periodic function

Aperiodic

*Image: Periodic function illustration.svg.* An illustration of a periodic function with period $P.$

::: {#o1 .subject cue=lead name="Periodic function"}

A **periodic function** is a [function](wikipedia://en/185427) that repeats its values at regular intervals. For example, the trigonometric functions, which are used to describe [waves](wikipedia://en/33516) and other repeating phenomena, are periodic. Many aspects of the natural world have periodic behavior, such as the [phases of the Moon](https://en.wikipedia.org/wiki/Phases_of_the_Moon), the swinging of a [pendulum](https://en.wikipedia.org/wiki/Pendulum), and the [beating](https://en.wikipedia.org/wiki/Human_heart) of a heart.

:::

The length of the interval over which a periodic function repeats is called its **period**. Any function that is not periodic is called **aperiodic**.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Sine.svg.* A graph of the sine function. It is periodic with a fundamental period of $2\pi$.

A function is defined as *periodic* if its values repeat at regular intervals. For example, the positions of the hands on a clock display periodic behavior as they cycle through the same positions every 12 hours. This repeating interval is known as the *period*.

More formally, a function $f$ is *periodic* if there exists a nonzero constant $P$ such that

$$f(x+P) = f(x)$$

for all values of $x$ in the [domain](wikipedia://en/50263). A nonzero constant $P$ for which this condition holds is called a *period* of the function.[^o4]

If a period $P$ exists, any integer multiple $nP$ (for a positive integer $n$) is also a period. If there is a least positive period, it is called the **fundamental period** (also **primitive period** or **basic period**).[^o5] Often, "the" period of a function is used to refer to its fundamental period.

Geometrically, a periodic function's graph exhibits [translational symmetry](https://en.wikipedia.org/wiki/Translational_symmetry). Its graph is [invariant](wikipedia://en/1126638) under [translation](wikipedia://en/204682) in the $x$-direction by a distance of $P$. This implies that the entire graph can be formed from copies of one particular portion, repeated at regular intervals.

:::

## Examples {#Examples}

Periodic behavior can be illustrated through both common, everyday examples and more formal mathematical functions.

### Real-valued functions {#Real-valued_functions}

Functions that map real numbers to real numbers can display periodicity, which is often visualized on a graph.

#### Sawtooth wave {#Sawtooth_wave}

An example is the function $f$ that represents the "[fractional part](wikipedia://en/501532)" of its argument. Its period is 1. For instance,

$$f(0.5) = f(1.5) = f(2.5) = \cdots = 0.5$$

The graph of the function $f$ is a [sawtooth wave](wikipedia://en/52147).

#### Trigonometric functions {#Trigonometric_functions}

*Image: Sine cosine plot.svg.* A plot of $f(x) = \sin(x)$ and $g(x) = \cos(x)$; both functions are periodic with period $2\pi$.

The trigonometric functions are common examples of periodic functions. The [sine function](https://en.wikipedia.org/wiki/Sine_function) and [cosine function](https://en.wikipedia.org/wiki/Cosine_function) are periodic with a fundamental period of $2\pi$, as illustrated in the figure to the right. For the sine function, this is expressed as:

$$\sin(x + 2\pi) = \sin x$$

for all values of $x$.

The field of [Fourier series](wikipedia://en/59038) investigates the concept that an arbitrary periodic function can be expressed as a sum of trigonometric functions with matching periods.

#### Exotic functions {#Exotic_functions}

Some functions are periodic but possess properties that make them less intuitive. The [Dirichlet function](wikipedia://en/630005), for example, is periodic, with any nonzero rational number serving as a period. However, it does not possess a fundamental period.

### Complex-valued functions {#Complex-valued_functions}

Functions with a domain in the [complex numbers](wikipedia://en/5826) can exhibit more complex periodic properties.

#### Complex exponential {#Complex_exponential}

The complex exponential function is a periodic function with a purely imaginary period:

$$e^{ikx} = \cos kx + i\,\sin kx$$

Given that the cosine and sine functions are both periodic with period $2\pi$, [Euler's formula](wikipedia://en/9613) demonstrates that the complex exponential function has a period $L$ such that

$$L = \frac{2\pi}{k}.$$

#### Double-periodic functions {#Double-periodic_functions}

A function on the complex plane can have two distinct, incommensurate periods without being a constant function. The [elliptic functions](wikipedia://en/69939) are a primary example of such functions. ("Incommensurate" in this context refers to periods that are not real multiples of each other.)

## Properties {#Properties}

Periodic functions can take on values many times. More specifically, if a function $f$ is periodic with period $P$, then for all $x$ in the domain of $f$ and all positive integers $n$,[^o17]

$$f(x + nP) = f(x)$$

A significant property related to integration is that if $f(x)$ is an [integrable](wikipedia://en/15532) periodic function with period $P$, then its definite integral over any interval of length $P$ is the same.[^o17] That is, for any real number $a$:

$$\int_a^{a+P} f(x) \, dx = \int_0^P f(x) \, dx$$

This property is crucial in areas such as [Fourier series](wikipedia://en/59038), where the coefficients are determined by integrals over one period.

If $f(x)$ is a function with period $P$, then $f(ax)$, where $a$ is a non-zero real number such that $ax$ is within the domain of $f$, is periodic with period $\frac{P}{|a|}$. For example, $f(x) = \sin(x)$ has period $2\pi$ and, therefore, $\sin(5x)$ will have period $\frac{2\pi}{5}$.

A key property of many periodic functions is that they can be described by a [Fourier series](wikipedia://en/59038). This series represents a periodic function as a sum of simpler periodic functions, namely [sines and cosines](wikipedia://en/5010838). For example, a sound wave from a musical instrument can be broken down into the fundamental note and various [overtones](https://en.wikipedia.org/wiki/Overtone). This decomposition is a powerful tool in fields like physics and signal processing. While most "well-behaved" periodic functions can be represented this way,[^o18] Fourier series can only be used for periodic functions or for functions defined on a finite length. If $f$ is a periodic function with period $P$ that can be described by a Fourier series, the coefficients of the series can be described by an [integral](wikipedia://en/15532) over an interval of length $P$.

Any function that is a combination of periodic functions with the same period is also periodic (though its fundamental period may be smaller). This includes:

- addition, [subtraction](wikipedia://en/74141), multiplication and division of periodic functions,[^o4] and
- taking a power or a root of a periodic function (provided it is defined for all $x$)

:::

## Generalizations {#Generalizations}

The concept of periodicity can be generalized beyond functions on the real number line. For example, the idea of a repeating pattern can be applied to shapes in multiple dimensions, such as a periodic [tessellation](wikipedia://en/321671) of the plane. A [sequence](https://en.wikipedia.org/wiki/Sequence_%28mathematics%29) can also be viewed as a function defined on the [natural numbers](wikipedia://en/21474), and the concept of a [periodic sequence](wikipedia://en/810250) is defined accordingly.

::: {#o22 .pointer-item cue=pointer name="Anti-periodic"}

### Antiperiodic functions {#Antiperiodic_functions}

One subset of periodic functions is that of **antiperiodic functions**. This is a function $f$ such that $f(x+P) = -f(x)$ for all $x$. For example, the sine and cosine functions are $\pi$-antiperiodic and $2\pi$-periodic. While a $P$-antiperiodic function is a $2P$-periodic function, the [converse](wikipedia://en/155941) is not necessarily true.[^o23]

:::

### Bloch-periodic functions {#Bloch-periodic_functions}

A further generalization appears in the context of [Bloch's theorems](https://en.wikipedia.org/wiki/Bloch's_theorem) and [Floquet theory](wikipedia://en/2987843), which govern the solution of various periodic differential equations. In this context, the solution (in one dimension) is typically a function of the form

$$f(x+P) = e^{ikP} f(x) ~,$$

where $k$ is a real or complex number (the *Bloch wavevector* or *Floquet exponent*). Functions of this form are sometimes called **Bloch-periodic** in this context. A periodic function is the special case $k=0$, and an antiperiodic function is the special case $k=\pi/P$. Whenever $k P/ \pi$ is rational, the function is also periodic.

### Quotient spaces as domain {#Quotient_spaces_as_domain}

In [signal processing](wikipedia://en/29324) you encounter the problem, that [Fourier series](wikipedia://en/59038) represent periodic functions and that Fourier series satisfy [convolution theorems](wikipedia://en/53268) (i.e. [convolution](wikipedia://en/7519) of Fourier series corresponds to multiplication of represented periodic function and vice versa), but periodic functions cannot be convolved with the usual definition, since the involved integrals diverge. A possible way out is to define a periodic function on a bounded but periodic domain. To this end you can use the notion of a [quotient space](wikipedia://en/898784):

$${\mathbb{R}/\mathbb{Z}} = \{x+\mathbb{Z} : x\in\mathbb{R}\} = \{\{y : y\in\mathbb{R}\land y-x\in\mathbb{Z}\} : x\in\mathbb{R}\}.$$

That is, each element in ${\mathbb{R}/\mathbb{Z}}$ is an [equivalence class](wikipedia://en/9260) of [real numbers](wikipedia://en/20646438) that share the same [fractional part](wikipedia://en/501532). Thus a function like $f : {\mathbb{R}/\mathbb{Z}}\to\mathbb{R}$ is a representation of a 1-periodic function.

:::

## Calculating period {#Calculating_period}

Consider a real waveform consisting of superimposed frequencies, expressed in a set as ratios to a [fundamental frequency](https://en.wikipedia.org/wiki/Fundamental_frequency), f: F = $\tfrac{1}{f}$\[f${}_{1}$ f${}_{2}$ f${}_{3}$ ... f${}_{N}$\] where all non-zero elements ≥1 and at least one of the elements of the set is 1. To find the period, T, first find the least common denominator of all the elements in the set. Period can be found as T = $\tfrac{\operatorname{LCD}}{f}$. Consider that for a simple sinusoid, T = $\tfrac{1}{f}$. Therefore, the LCD can be seen as a periodicity multiplier.

- For set representing all notes of Western [major scale](https://en.wikipedia.org/wiki/Major_scale): \[1 $\tfrac{9}{8}$ $\tfrac{5}{4}$ $\tfrac{4}{3}$ $\tfrac{3}{2}$ $\tfrac{5}{3}$ $\tfrac{15}{8}$\] the LCD is 24 therefore T = $\tfrac{24}{f}$.
- For set representing all notes of a major triad: \[1 $\tfrac{5}{4}$ $\tfrac{3}{2}$\] the LCD is 4 therefore T = $\tfrac{4}{f}$.
- For set representing all notes of a minor triad: \[1 $\tfrac{6}{5}$ $\tfrac{3}{2}$\] the LCD is 10 therefore T = $\tfrac{10}{f}$.

If no least common denominator exists, for instance if one of the above elements were irrational, then the wave would not be periodic.[^o27]
