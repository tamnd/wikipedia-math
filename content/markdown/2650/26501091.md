# Arden's rule

::: {#o1 .subject cue=lead name="Arden's rule"}

In [theoretical computer science](wikipedia://en/323392), **Arden's rule**, also known as **Arden's lemma**, is a mathematical statement about a certain form of [language equations](wikipedia://en/8031241).

:::

## Background {#Background}

A [(formal) language](wikipedia://en/10939) is simply a set of strings. Such sets can be specified by means of some [language equation](wikipedia://en/8031241), which in turn is based on operations on languages. Language equations are mathematical statements that resemble numerical equations, but the variables assume values of formal languages rather than numbers. Among the most common operations on two languages *A* and *B* are the [set union](https://en.wikipedia.org/wiki/Set_union) *A* ∪ *B*, and their [concatenation](wikipedia://en/64474#Concatenation_of_sets_of_strings) *A*⋅*B*. Finally, as an operation taking a single [operand](wikipedia://en/22656), the set *A*<sup>\*</sup> denotes the [Kleene star](wikipedia://en/16750) of the language *A*.

::: {#o4 .statement cue=heading name="Statement of Arden's rule"}

## Statement of Arden's rule {#Statement_of_Arden's_rule}

Arden's rule states that the set *A*<sup>\*</sup>⋅*B* is the smallest language that is a solution for *X* in the [linear equation](wikipedia://en/17570) *X* = *A*⋅*X* ∪ *B* where *X*, *A*, *B* are sets of strings. Moreover, if the set *A* does not contain the empty word, then this solution is unique.[^o5][^o6]

Equivalently, the set *B*⋅*A*<sup>\*</sup> is the smallest language that is a solution for *X* in *X* = *X*⋅*A* ∪ *B*.

:::

::: {#o8 .application cue=heading name="Application"}

## Application {#Application}

Arden's rule can be used to help convert some finite automatons to regular expressions, as in [Kleene's algorithm](wikipedia://en/42923391).

:::
