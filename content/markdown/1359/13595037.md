# Variance inflation factor

::: {#o1 .subject cue=lead name="Variance inflation factor"}

In [statistics](wikipedia://en/26685), the **variance inflation factor** (**VIF**) is the ratio ([quotient](wikipedia://en/332640)) of the variance of a parameter estimate when fitting a full model that includes other parameters to the variance of the parameter estimate if the model is fit with only the parameter on its own.[^o2] The VIF provides an index that measures how much the [variance](wikipedia://en/32344) (the square of the estimate's [standard deviation](wikipedia://en/27590)) of an estimated regression coefficient is increased because of [collinearity](wikipedia://en/3189581).

:::

[Cuthbert Daniel](https://en.wikipedia.org/wiki/Cuthbert_Daniel) claims to have invented the concept behind the variance inflation factor, but did not come up with the name.[^o3]

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Consider the following [linear model](wikipedia://en/17904) with *k* independent variables:

*Y* = *β*<sub>0</sub> + *β*<sub>1</sub> *X*<sub>1</sub> + *β*<sub>2</sub> *X* <sub>2</sub> + ... + *β*<sub>*k*</sub> *X*<sub>*k*</sub> + *ε*.

The [standard error](https://en.wikipedia.org/wiki/Standard_error_%28statistics%29) of the estimate of *β*<sub>*j*</sub> is the [square root](wikipedia://en/29208) of the *j* + 1 diagonal element of *s*<sup>2</sup>(*X*′*X*)<sup>−1</sup>, where *s* is the [root mean squared error (RMSE)](https://en.wikipedia.org/wiki/Root-mean-square_deviation) (note that RMSE<sup>2</sup> is a [consistent estimator](wikipedia://en/1497569) of the true variance of the error term, $\sigma^2$); *X* is the regression [design matrix](wikipedia://en/949189) — a matrix such that *X*<sub>*i*, *j*+1</sub> is the value of the *j*<sup>th</sup> [independent variable](wikipedia://en/437701) for the *i*<sup>th</sup> case or observation, and such that *X*<sub>*i*,1</sub>, the predictor vector associated with [the intercept](https://en.wikipedia.org/wiki/The_Intercept) term, equals 1 for all *i*. It turns out that the square of this standard error, the estimated variance of the estimate of *β*<sub>*j*</sub>, can be equivalently expressed as:[^o6][^o7]

$$\widehat{\operatorname{var}}(\hat{\beta}_j) = \frac{s^2}{(n-1)\widehat{\operatorname{var}}(X_j)}\cdot \frac{1}{1-R_j^2},$$

where *R*<sub>*j*</sub><sup>2</sup> is the [multiple *R*<sup>2</sup>](wikipedia://en/1500869) for the regression of *X*<sub>*j*</sub> on the other covariates (a regression that does not involve the response variable *Y*) and $\hat{\beta}_j$ are the coefficient estimates, id est, the estimates of ${\beta}_j$. This identity separates the influences of several distinct factors on the variance of the coefficient estimate:

- *s*<sup>2</sup>: greater scatter in the data around the regression surface leads to proportionately more variance in the coefficient estimates
- *n*: greater sample size results in proportionately less variance in the coefficient estimates
- $\widehat\operatorname{var}(X_j)$: greater variability in a particular covariate leads to proportionately less variance in the corresponding coefficient estimate

The remaining term, 1 / (1 − *R*<sub>*j*</sub><sup>2</sup>) is the VIF. It reflects all other factors that influence the uncertainty in the coefficient estimates. The VIF equals 1 when the vector *X*<sub>*j*</sub> is [orthogonal](https://en.wikipedia.org/wiki/Orthogonal) to each column of the design matrix for the regression of *X*<sub>*j*</sub> on the other covariates. By contrast, the VIF is greater than 1 when the vector *X*<sub>*j*</sub> is not orthogonal to all columns of the design matrix for the regression of *X*<sub>*j*</sub> on the other covariates. Finally, note that the VIF is invariant to the scaling of the variables (that is, we could scale each variable *X*<sub>*j*</sub> by a constant *c*<sub>*j*</sub> without changing the VIF).

$$\widehat{\operatorname{var}}(\hat{\beta}_j) = s^2 [(X^T X)^{-1}]_{jj}$$

Now let $r= X^T X$, and without losing generality, we reorder the columns of *X* to set the first column to be $X_j$

$$r^{-1} = \begin{bmatrix} r_{j,j} & r_{j,-j} \\ r_{-j,j} & r_{-j,-j}\end{bmatrix}^{-1}$$

$$r_{j,j} = X_j^T X_j, r_{j,-j} = X_j^T X_{-j}, r_{-j,j} = X_{-j}^T X_j, r_{-j,-j} = X_{-j}^T X_{-j}.$$

By using [Schur complement](wikipedia://en/372620), the element in the first row and first column in $r^{-1}$ is,

$$r^{-1}_{1,1} = [r_{j,j} - r_{j,-j} r_{-j,-j}^{-1} r_{-j,j} ]^{-1}$$

Then we have,

$$\begin{aligned} & \widehat{\operatorname{var}}(\hat{\beta}_j) = s^2 [(X^T X)^{-1}]_{jj} = s^2 r^{-1}_{1,1} \\ = {} & s^2 [X_j^T X_j - X_j^T X_{-j} (X_{-j}^T X_{-j})^{-1} X_{-j}^T X_j ]^{-1} \\ = {} & s^2 [X_j^T X_j - X_j^T X_{-j} (X_{-j}^T X_{-j})^{-1} (X_{-j}^T X_{-j}) (X_{-j}^T X_{-j})^{-1} X_{-j}^T X_j ]^{-1} \\ = {} & s^2 [X_j^T X_j - \hat{\beta}_{*j}^T(X_{-j}^T X_{-j}) \hat{\beta}_{*j} ]^{-1} \\ = {} & s^2 \frac{1}{\mathrm{RSS}_j} \\ = {} & \frac{s^2}{(n-1)\widehat\operatorname{var}(X_j)}\cdot \frac{1}{1-R_j^2} \end{aligned}$$

Here $\hat{\beta}_{*j}$ is the coefficient of regression of dependent variable $X_j$ over covariate $X_{-j}$. $\mathrm{RSS}_j$ is the corresponding [residual sum of squares](wikipedia://en/2473303).

:::

## Calculation and analysis {#Calculation_and_analysis}

We can calculate *k* different VIFs (one for each *X*<sub>*i*</sub>) in three steps:

### Step one {#Step_one}

First we run an ordinary least square regression that has *X*<sub>*i*</sub> as a function of all the other explanatory variables in the first equation. If *i* = 1, for example, equation would be

$$X_1=\alpha_0 + \alpha_2 X_2 + \alpha_3 X_3 + \cdots + \alpha_k X_k +\varepsilon$$

where $\alpha_0$ is a constant and $\varepsilon$ is the [error term](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics).

### Step two {#Step_two}

Then, calculate the VIF factor for $\hat\alpha_i$ with the following formula :

$$\mathrm{VIF}_i = \frac{1}{1-R^2_i}$$

where *R*<sup>2</sup><sub>*i*</sub> is the [coefficient of determination](wikipedia://en/1500869) of the regression equation in step one, with $X_i$ on the left hand side, and all other predictor variables (all the other X variables) on the right hand side.

### Step three {#Step_three}

Analyze the magnitude of [multicollinearity](wikipedia://en/1486691) by considering the size of the $\operatorname{VIF}(\hat \alpha_i)$. A [rule of thumb](https://en.wikipedia.org/wiki/Rule_of_thumb) is that if $\operatorname{VIF}(\hat \alpha_i) > 10$ then multicollinearity is high[^o12] (a cutoff of 5 is also commonly used[^o13]). However, there is no value of VIF greater than 1 in which the variance of the slopes of predictors isn't inflated. As a result, including two or more variables in a multiple regression that are not orthogonal (i.e. have correlation = 0), will alter each other's slope, SE of the slope, and [P-value](wikipedia://en/554994), because there is shared variance between the predictors that can't be uniquely attributed to any one of them.[^o14]

Some software instead calculates the tolerance which is just the reciprocal of the VIF. The choice of which to use is a matter of personal preference.

## Interpretation {#Interpretation}

The square root of the variance inflation factor indicates how much larger the standard error increases compared to if that variable had 0 correlation to other predictor variables in the model.

::: {#o16 .example cue=inline-head name="Example"}

**Example** If the variance inflation factor of a predictor variable were 5.27 (√5.27 = 2.3), this means that the standard error for the coefficient of that predictor variable is 2.3 times larger than if that predictor variable had 0 correlation with the other predictor variables.

:::

## Implementation {#Implementation}

- `vif` function in the [car](https://cran.r-project.org/package=car) [R](wikipedia://en/376707) package
- `ols_vif_tol` function in the [olsrr](https://cran.r-project.org/package=olsrr) [R](wikipedia://en/376707) package
- `PROC REG` in SAS [System](https://support.sas.com/documentation/cdl/en/statug/63033/HTML/default/viewer.htm#statug_reg_sect007.htm)
- `variance_inflation_factor` function in [statsmodels](http://www.statsmodels.org) [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) package
- `estat vif` in [Stata](https://www.stata.com/help.cgi?regress_postestimation)
- [r.vif](https://grass.osgeo.org/grass78/manuals/addons/r.vif.html) addon for [GRASS GIS](https://en.wikipedia.org/wiki/GRASS_GIS)
- `vif` (non categorical) and `gvif` (categorical data) functions in [StatsModels](https://juliastats.org/StatsModels.jl/stable/) [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29) programing language
