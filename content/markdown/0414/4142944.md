# Interior extremum theorem

::: {#o1 .subject cue=lead name="Interior extremum theorem"}

*Image: Interior extremum graph.svg.* A differentiable function graph with lines tangent to the minimum and maximum. The interior extremum theorem guarantees that these lines will always be horizontal.

In [calculus](wikipedia://en/5176) and [real analysis](wikipedia://en/26478), the **interior extremum theorem** states that any [local extremum](wikipedia://en/298420) of a real function at which it is [differentiable](wikipedia://en/330206) is a [stationary point](wikipedia://en/885651). It is also known as **Fermat's theorem**, named after the French mathematician [Pierre de Fermat](wikipedia://en/7576966).

:::

The interior extremum theorem gives a [necessary](wikipedia://en/169319#Necessity), but not [sufficient](wikipedia://en/169319#Sufficiency) condition for local extrema at which the function is differentiable, as some stationary points are not local extrema.

The [second derivative](wikipedia://en/3224219), if non-zero, can be used to determine whether a local extremum at which the function is twice differentiable is a maximum or a minimum. However, the second derivative can be zero at local extrema.

## History {#History}

[Pierre de Fermat](wikipedia://en/7576966) proposed in a collection of treatises titled *Maxima et minima* a method to find maximum or minimum, similar to the modern interior extremum theorem using an approach he called [adequality](wikipedia://en/30609033).[^o3]p. 456–457[^o10]p. 2[^o4] After [Marin Mersenne](wikipedia://en/72947) passed the treatises onto [René Descartes](wikipedia://en/25525), Descartes was doubtful, remarking "if \[...\] he speaks of wanting to send you still more papers, I beg of you to ask him to think them out more carefully than those preceding".[^o10]p. 3 Descartes later agreed that the method was valid.[^o10]p. 8

::: {#o6 .statement cue=heading name="Statement"}

## Statement {#Statement}

One way to state the interior extremum theorem is that, if a function has a local [extremum](https://en.wikipedia.org/wiki/Maxima_and_minima) at some point and is [differentiable](wikipedia://en/330206) there, then the function's derivative at that point must be zero. In precise mathematical language:

Let $f\colon (a,b) \rightarrow \mathbb{R}$ be a function from an [open interval](https://en.wikipedia.org/wiki/Open_interval) $(a,b)$ to $\mathbb{R}$, and suppose that $x_0 \in (a,b)$ is a point where $f$ has a local extremum. If $f$ is differentiable at $x_0$, then $f'(x_0) = 0$.[^o7]p. 377

Another way to understand the theorem is via the [contrapositive](https://en.wikipedia.org/wiki/Contrapositive) statement: if the derivative of a function at any point is not zero, then there is not a local extremum at that point. Formally:

If $f$ is differentiable at $x_0 \in (a,b)$, and $f'(x_0) \neq 0$, then $x_0$ is not a local extremum of $f$.

::: {#o9 .statement kind=statement/corollary cue=named-heading name="Corollary"}

### Corollary {#Corollary}

Every global extremum of a function *f* on a [domain](wikipedia://en/50263) *A* occurs only at the [boundary](wikipedia://en/72824) of *A*, non-differentiable points, or stationary points. If $x_0$ is a global extremum of *f*, then one of the following is true:[^o10]p. 1

- **boundary:** $x_0$ is in the boundary of *A*
- **non-differentiable:** *f* is not differentiable at $x_0$
- **stationary point:** $f'(x_0)=0$

The function $f(x)=x^3$ has no extrema. The function $f(x)=x^3-x$ has no global extrema, although it has local extrema.

:::

::: {#o12 .statement kind=statement/generalization cue=heading name="Extension"}

### Extension {#Extension}

A similar statement holds for the [partial derivatives](https://en.wikipedia.org/wiki/Partial_derivatives) of [multivariate functions](https://en.wikipedia.org/wiki/Multivariate_function). Suppose that some real-valued function of the real numbers $f = f(t_1, t_2, \ldots,t_k)$ has an extremum at a point $C$, defined by $C = (a_1, a_2,\ldots ,a_k)$. If $f$ is differentiable at $C$, then:

$$\frac{\partial}{\partial t_i}f(C)=0$$

for each $i = 1, 2, \ldots ,k$.[^o13]p. 16

The statement can also be extended to [differentiable manifolds](https://en.wikipedia.org/wiki/Differentiable_manifolds). If $f : M \to \mathbb{R}$ is a [differentiable function](wikipedia://en/2119219#Differentiable_functions) on a manifold $M$, then its local extrema must be [critical points](wikipedia://en/1951424) of $f$, in particular points where the [exterior derivative](wikipedia://en/220782) $df$ is zero.[^o14]

:::

::: {#o16 .application cue=heading name="Applications"}

## Applications {#Applications}

The interior extremum theorem is central for determining [maxima and minima](https://en.wikipedia.org/wiki/Maxima_and_minima) of [piecewise differentiable functions](wikipedia://en/404130) of one variable: an extremum is either a [stationary point](wikipedia://en/885651) (that is, a [zero](wikipedia://en/264210) of the derivative), a non-differentiable point (that is a point where the function is not [differentiable](wikipedia://en/330206)), or a [boundary point](https://en.wikipedia.org/wiki/Boundary_point) of the [domain of the function](wikipedia://en/50263). Since the number of these points is typically finite, the computation of the values of the function at these points provides the maximum and the minimum, simply by comparing the obtained values.[^o17]p. 25[^o10]p. 1

:::

::: {#o19 .proof cue=heading name="Proof"}

## Proof {#Proof}

Suppose that $x_0$ is a local maximum. (A similar argument applies if $x_0$ is a local minimum.) Then there is some [neighbourhood](wikipedia://en/1529485) around $x_0$ such that $f(x_0) \ge f(x)$ for all $x$ within that neighborhood. If $x > x_0$, then the [difference quotient](wikipedia://en/241863) $\frac{f(x) - f(x_0)}{x - x_0}$ is non-positive for $x$ in this neighborhood. This implies

$$\lim_{x\rightarrow x_0^+}\frac{f(x) - f(x_0)}{x - x_0} \le 0.$$

Similarly, if $x < x_0$, then the difference quotient is non-negative, and so

$$\lim_{x\rightarrow x_0^-}\frac{f(x) - f(x_0)}{x - x_0} \geq 0.$$

Since $f$ is differentiable, the above limits must both be equal to $f'(x_0)$. This is only possible if both limits are equal to 0, so $f'(x_0) = 0$.[^o20]p. 182

:::
