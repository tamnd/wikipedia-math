# Finiteness properties of groups

::: {#o1 .subject cue=lead name="Finiteness properties of groups"}

In [mathematics](wikipedia://en/18831), **finiteness properties** of a [group](wikipedia://en/19447) are a collection of properties that allow the use of various [algebraic](wikipedia://en/18716923) and [topological](wikipedia://en/29954) tools, for example [group cohomology](wikipedia://en/248635), to study the group. It is mostly of interest for the study of infinite groups.

:::

Special cases of groups with finiteness properties are [finitely generated](wikipedia://en/963042) and [finitely presented](https://en.wikipedia.org/wiki/Finitely_presented_group) groups.

## Topological finiteness properties {#Topological_finiteness_properties}

Given an [integer](wikipedia://en/14563) *n* ≥ 1, a group $\Gamma$ is said to be *of type* *F*<sub>*n*</sub> if there exists an [aspherical CW-complex](wikipedia://en/7147287) whose [fundamental group](wikipedia://en/11004) is [isomorphic](wikipedia://en/12397) to $\Gamma$ (a [classifying space](wikipedia://en/923556) for $\Gamma$) and whose [*n*-skeleton](wikipedia://en/2977910) is finite. A group is said to be of type *F*<sub>∞</sub> if it is of type *F*<sub>*n*</sub> for every *n*. It is of type *F* if there exists a finite aspherical CW-complex of which it is the fundamental group.

For small values of *n* these conditions have more classical interpretations:

- a group is of type *F*<sub>1</sub> if and only if it is [finitely generated](wikipedia://en/963042) (the rose with petals indexed by a finite generating family is the 1-skeleton of a classifying space, the [Cayley graph](wikipedia://en/358277) of the group for this generating family is the 1-skeleton of its universal cover);
- a group is of type *F*<sub>2</sub> if and only if it is [finitely presented](wikipedia://en/99494#Finitely_presented_groups) (the [presentation complex](wikipedia://en/12821736), i.e. the rose with petals indexed by a finite generating set and 2-cells corresponding to each relation, is the 2-skeleton of a classifying space, whose universal cover has the [Cayley complex](https://en.wikipedia.org/wiki/Cayley_complex) as its 2-skeleton).

It is known that for every *n* ≥ 1 there are groups of type *F*<sub>*n*</sub> which are not of type *F*<sub>*n*+1</sub>. Finite groups are of type *F*<sub>∞</sub> but not of type *F*. [Thompson's group](wikipedia://en/612245) $F$ is an example of a torsion-free group which is of type *F*<sub>∞</sub> but not of type *F*.[^o3]

A reformulation of the *F*<sub>*n*</sub> property is that a group has it if and only if it [acts](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) properly discontinuously, freely and cocompactly on a CW-complex whose [homotopy groups](wikipedia://en/297506) $\pi_0, \ldots, \pi_{n-1}$ vanish. Another finiteness property can be formulated by replacing homotopy with homology: a group is said to be of type *FH*<sub>n</sub> if it acts as above on a CW-complex whose *n* first homology groups vanish.

## Algebraic finiteness properties {#Algebraic_finiteness_properties}

Let $\Gamma$ be a group and $\mathbb Z\Gamma$ its [group ring](wikipedia://en/349223). The group $\Gamma$ is said to be of type FP<sub>*n*</sub> if there exists a [resolution](wikipedia://en/19745659) of the trivial $\mathbb Z\Gamma$-[module](wikipedia://en/276410) $\mathbb Z$ such that the *n* first terms are finitely generated [projective](wikipedia://en/364488) $\mathbb Z\Gamma$-modules.[^n1] The types *FP*<sub>∞</sub> and *FP* are defined in the obvious way.

The same statement with projective modules replaced by [free modules](wikipedia://en/326454) defines the classes *FL*<sub>*n*</sub> for *n* ≥ 1, *FL*<sub>∞</sub> and *FL*.

It is also possible to define classes *FP*<sub>*n*</sub>(*R*) and *FL*<sub>*n*</sub>(*R*) for any [commutative ring](wikipedia://en/61346) *R*, by replacing the group ring $\mathbb Z\Gamma$ by $R\Gamma$ in the definitions above.

Either of the conditions *F*<sub>n</sub> or *FH*<sub>*n*</sub> imply *FP*<sub>*n*</sub> and *FL*<sub>*n*</sub> (over any commutative ring). A group is of type *FP*<sub>1</sub> if and only if it is finitely generated,[^n1] but for any *n* ≥ 2 there exists groups which are of type *FP*<sub>*n*</sub> but not *F*<sub>*n*</sub>.[^o7]

If a group is of type *F*<sub>*2*</sub> and *FP*<sub>*n*</sub>, then it is of type *F*<sub>*n*</sub>.

## Group cohomology {#Group_cohomology}

If a group is of type *FP*<sub>*n*</sub> then its cohomology groups $H^i(\Gamma)$ are finitely generated for $0 \le i \le n$. If it is of type *FP* then it is of finite cohomological dimension. Thus finiteness properties play an important role in the cohomology theory of groups.

## Examples {#Examples}

### Finite groups {#Finite_groups}

A finite cyclic group $G$ acts freely on the unit sphere in $\mathbb R^{\mathbb N}$, preserving a CW-complex structure with finitely many cells in each dimension.[^n2] Since this unit sphere is contractible, every finite cyclic group is of type F<sub>∞</sub>.

The standard resolution [^n3] for a group $G$ gives rise to a contractible CW-complex with a free $G$-action in which the cells of dimension $n$ correspond to $(n+1)$-tuples of elements of $G$. This shows that every finite group is of type F<sub>∞</sub>.

A [non-trivial](wikipedia://en/193059) finite group is never of type *F* because it has infinite cohomological dimension. This also implies that a group with a non-trivial [torsion subgroup](wikipedia://en/144052) is never of type *F*.

### Nilpotent groups {#Nilpotent_groups}

If $\Gamma$ is a [torsion-free](wikipedia://en/3039330), finitely generated [nilpotent group](wikipedia://en/144569) then it is of type F.[^n4]

### Geometric conditions for finiteness properties {#Geometric_conditions_for_finiteness_properties}

Negatively curved groups ([hyperbolic](wikipedia://en/3172817) or [CAT(0)](https://en.wikipedia.org/wiki/CAT%280%29) groups) are always of type *F*<sub>∞</sub>.[^n5] Such a group is of type *F* if and only if it is torsion-free.

As an example, cocompact [S-arithmetic groups](https://en.wikipedia.org/wiki/S-arithmetic_group) in [algebraic groups](wikipedia://en/247924) over [number fields](https://en.wikipedia.org/wiki/Number_field) are of type F<sub>∞</sub>. The Borel–Serre compactification shows that this is also the case for non-cocompact arithmetic groups.

Arithmetic groups over [function fields](wikipedia://en/447645) have very different finiteness properties: if $\Gamma$ is an arithmetic group in a simple algebraic group of [rank](wikipedia://en/360136) $r$ over a global function field (such as $\mathbb F_q(t)$) then it is of type F<sub>r</sub> but not of type F<sub>r+1</sub>.[^o18]
