# Symbolic language (programming)

::: {#o1 .subject cue=lead name="Symbolic language"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), a **symbolic language**, or assembly language, is a language that uses [characters](https://en.wikipedia.org/wiki/Character_%28computing%29) or [symbols](https://en.wikipedia.org/wiki/Symbols) to represent concepts, such as [mathematical operations](wikipedia://en/4140245) and the entities (or [operands](https://en.wikipedia.org/wiki/Operands)) on which these operations are performed.[^o2]

:::

Modern [programming languages](https://en.wikipedia.org/wiki/Programming_languages) use symbols to represent concepts and/or data and are, therefore, examples of symbolic languages.[^o2]

Some programming languages (such as [Lisp](https://en.wikipedia.org/wiki/Lisp_%28programming_language%29) and [Mathematica](wikipedia://en/49024)) make it easy to represent higher-level [abstractions](https://en.wikipedia.org/wiki/Abstraction_%28computer_science%29) as [expressions](https://en.wikipedia.org/wiki/Expression_%28computer_science%29) in the language, enabling [symbolic programming](https://en.wikipedia.org/wiki/Symbolic_programming).[^o3][^o4]
