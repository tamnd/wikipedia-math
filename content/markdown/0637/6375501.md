# Origin (data analysis software)

::: {#o2 .subject cue=lead name="Origin"}

**Origin** is a proprietary computer program for interactive [scientific graphing](wikipedia://en/19774918) and [data analysis](wikipedia://en/2720954). It is produced by [OriginLab Corporation](https://en.wikipedia.org/wiki/OriginLab_Corporation), and runs on [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows). It has inspired several [platform-independent](https://en.wikipedia.org/wiki/Cross-platform) [open-source](https://en.wikipedia.org/wiki/Open-source_software) [clones](https://en.wikipedia.org/wiki/Clone_%28computing%29) and alternatives like [LabPlot](https://en.wikipedia.org/wiki/LabPlot) and [SciDAVis](https://en.wikipedia.org/wiki/SciDAVis).

:::

Graphing support in Origin includes various 2D/3D plot types. Data analyses in Origin include [statistics](wikipedia://en/26685), [signal processing](wikipedia://en/29324), [curve fitting](wikipedia://en/555425) and peak analysis. Origin's curve fitting is performed by a [nonlinear least squares](wikipedia://en/1045012) fitter which is based on the [Levenberg–Marquardt algorithm](wikipedia://en/892446).

Origin imports data files in various formats such as [ASCII text](https://en.wikipedia.org/wiki/ASCII_text), [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [NI TDM, DIADem](https://en.wikipedia.org/wiki/National_Instruments), [NetCDF](https://en.wikipedia.org/wiki/NetCDF), [SPC](https://en.wikipedia.org/wiki/SPC_file_format), etc. It also exports the graph to various image file formats such as [JPEG](https://en.wikipedia.org/wiki/JPEG), [GIF](https://en.wikipedia.org/wiki/GIF), [EPS](https://en.wikipedia.org/wiki/Encapsulated_PostScript), [TIFF](https://en.wikipedia.org/wiki/Tagged_Image_File_Format), etc. There is also a built-in query tool for accessing database data via [ADO](https://en.wikipedia.org/wiki/ActiveX_Data_Objects).[^o3]

## Features {#Features}

*Image: Cshome price sparklines.jpg.* Origin Workbook with [sparklines](wikipedia://en/1743077) above data columns; this allows a quick glance of the data without plotting them.

Origin is primarily a [GUI](https://en.wikipedia.org/wiki/Graphical_user_interface) software with a [spreadsheet](https://en.wikipedia.org/wiki/Spreadsheet) front end. Unlike popular spreadsheets like [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), Origin's worksheet is column oriented. Each column has associated attributes like name, units and other user definable labels. Instead of cell formula, Origin uses column formula for calculations.

Recent versions of Origin have introduced and expanded on batch capabilities, with the goal of eliminating the need to program many routine operations. Instead the user relies on customizable graph templates, analysis dialog box Themes which save a particular suite of operations, auto recalculation on changes to data or analysis parameters, and Analysis Templates™ which save a collection of operations within the workbook.

Origin also has a [scripting language](https://en.wikipedia.org/wiki/Scripting_language) (LabTalk) for controlling the software, which can be extended using a built-in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29)/[C++](https://en.wikipedia.org/wiki/C++)-based [compiled language](https://en.wikipedia.org/wiki/Compiled_language) (Origin C). Other programming options include an embedded [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) environment, and an [R](wikipedia://en/376707) Console plus support for [Rserve](https://en.wikipedia.org/wiki/R_%28software%29).

Origin can be also used as a [COM](https://en.wikipedia.org/wiki/Component_Object_Model) server for programs which may be written in [Visual Basic .NET](https://en.wikipedia.org/wiki/Visual_Basic_.NET), [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29), [LabVIEW](https://en.wikipedia.org/wiki/LabVIEW), etc.

Older (.OPJ), but not newer (.OPJU), Origin project files can be read by the open-source [LabPlot](https://en.wikipedia.org/wiki/LabPlot) or [SciDAVis](https://en.wikipedia.org/wiki/SciDAVis) software. The native origin file viewer can read them and can convert newer OPJU files to older OPJ files for older versions of Origin.[^o5] The files can also be read by [QtiPlot](https://en.wikipedia.org/wiki/QtiPlot) but only with a paid "Pro" version. Finally the liborigin[^o6] library can also read. OPJ files such as by using the `opj2dat` script, which exports the data tables contained in the file.

There is also a free component (Orglab) maintained by Originlab that can be used to create (or read) OPJ files. A free Viewer application is also available.

## History {#History}

Origin was first created for use solely with microcalorimeters manufactured by MicroCal Inc. (acquired by Malvern Instruments in 2014[^o8]) The software was used to graph the instruments data, and perform nonlinear curve fitting and parameter calculation.

The software was first published for the public in 1992 by Microcal Software, which later was renamed to OriginLab Corporation,[^o9] located in [Northampton](https://en.wikipedia.org/wiki/Northampton_%28Massachusetts%29), [Massachusetts](https://en.wikipedia.org/wiki/Massachusetts).

### Editions and support {#Editions_and_support}

Origin is available in two editions, the regular version Origin and the pricier **OriginPro**. The latter adds additional data analysis features like surface fitting, short-time Fourier Transform, and more advanced statistics.[^o3] A few version types have been offered from Origin and OriginPro as personal, academic, government and student versions.
