# Non-negative least squares

::: {#o1 .subject cue=lead name="Non-negative least squares"}

In [mathematical optimization](wikipedia://en/52033), the problem of **non-negative least squares** (**NNLS**) is a type of [constrained least squares](wikipedia://en/48526234) problem where the coefficients are not allowed to become negative. That is, given a matrix $\mathbf{A}$ and a (column) vector of [response variables](https://en.wikipedia.org/wiki/Response_variable) $\mathbf{y}$, the goal is to find[^o12]

:::

$\operatorname{arg\,min}\limits_\mathbf{x} \|\mathbf{Ax} - \mathbf{y}\|_2^2$ subject to $\mathbf{x} \ge 0$.

Here $\mathbf{x} \ge 0$ means that each component of the vector $\mathbf{x}$ should be non-negative, and $\|\cdot\|_{2}$ denotes the [Euclidean norm](https://en.wikipedia.org/wiki/Euclidean_norm).

Non-negative least squares problems turn up as subproblems in [matrix decomposition](wikipedia://en/253873), e.g. in algorithms for [PARAFAC](https://en.wikipedia.org/wiki/CP_decomposition)[^o10] and [non-negative matrix/tensor factorization](wikipedia://en/3681279).[^o2][^o3] The latter can be considered a generalization of NNLS.[^o12]

Another generalization of NNLS is **bounded-variable least squares** (BVLS), with simultaneous upper and lower bounds $\alpha_{i} \le \mathbf{x}_{i} \le \beta_{i}$.[^o4]

## Quadratic programming version {#Quadratic_programming_version}

The NNLS problem is equivalent to a [quadratic programming](wikipedia://en/40324) problem

$$\operatorname{arg\,min}\limits_\mathbf{x \ge 0} \left(\frac{1}{2} \mathbf{x}^\mathsf{T} \mathbf{Q}\mathbf{x} + \mathbf{c}^\mathsf{T} \mathbf{x}\right),$$

where $\mathbf{Q}$ = $\mathbf{A}^{T}\mathbf{A}$ and $\mathbf{c}$ = $-\mathbf{A}^{T} \mathbf{y}$. This problem is [convex](wikipedia://en/1674411), as $\mathbf{Q}$ is [positive semidefinite](https://en.wikipedia.org/wiki/Positive-semidefinite_matrix) and the non-negativity constraints form a convex feasible set.[^o6]

::: {#o8 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

The first widely used algorithm for solving this problem is an [active-set method](wikipedia://en/1560090) published by Lawson and Hanson in their 1974 book *Solving Least Squares Problems*.[^o9] In [pseudocode](https://en.wikipedia.org/wiki/Pseudocode), this algorithm looks as follows:[^o10]

blue

- Inputs:
  - a real-valued matrix $A$ of dimension $m \times n$,
  - a real-valued vector $\mathbf{y}$ of dimension $m$,
  - a real value $\varepsilon$, the tolerance for the stopping criterion.
- Initialize:
  - Set $P = \emptyset$.
  - Set $R = \{1, ..., n$}.
  - Set $\mathbf{x}$ to an all-zero vector of dimension $n$.
  - Set $\mathbf{w} = A^{T}(\mathbf{y} - A\mathbf{x})$.
  - Let $w^{R}$ denote the sub-vector with indexes from *R*
- Main loop: while $R \ne \emptyset$ and $\max(\mathbf{w^{R}}) > \varepsilon$:
  - Let $j$ in $R$ be the index of $\max(\mathbf{w^{R}})$ in $\mathbf{w}$.
  - Add $j$ to $P$.
  - Remove $j$ from $R$.
  - Let $A^{P}$ be $A$ restricted to the variables included in $P$.
  - Let $s$ be vector of same length as $\mathbf{x}$. Let $s^{P}$ denote the sub-vector with indexes from *P* Let $s^{R}$ denote the sub-vector with indexes from *R*.
  - Set $s^{P} = ((A^{P})^{T} A^{P})^{-1} (A^{P})^{T}\mathbf{y}$
  - Set $s^{R}$ to zero
  - While $\min(s^{P}) \le 0$:
    - Let $\alpha = \min\,\tfrac{x_{i}}{x_{i} - s_{i}}\text{ for } i\text{ in } P\text{ where } s_{i} \le 0$.
    - Set $\mathbf{x}$ to $\mathbf{x} + \alpha(s - x)$.
    - Move to $R$ all indices $j$ in $P$ such that $x_{j} \le 0$.
    - Set $s^{P} = ((A^{P})^{T} A^{P})^{-1} (A^{P})^{T}\mathbf{y}$
    - Set $s^{R}$ to zero.
  - Set $\mathbf{x}$ to $s$.
  - Set $\mathbf{w}$ to $A^{T}(\mathbf{y} - A\mathbf{x})$.
- Output: **x**

This algorithm takes a finite number of steps to reach a solution and smoothly improves its candidate solution as it goes (so it can find good approximate solutions when cut off at a reasonable number of iterations), but is very slow in practice, owing largely to the computation of the [pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse) $((\mathbf{A}^{P})^{T} \mathbf{A}^{P})^{-1}$. Variants of this algorithm are available in [MATLAB](wikipedia://en/20412) as the routine lsqnonneg[^o11][^o12] and in [SciPy](https://en.wikipedia.org/wiki/SciPy) as optimize.nnls.[^o13]

Many improved algorithms have been suggested since 1974. Fast NNLS (FNNLS) is an optimized version of the Lawson–Hanson algorithm. Other algorithms include variants of [Landweber](wikipedia://en/35717958)'s [gradient descent](wikipedia://en/201489) method,[^o14] [coordinate-wise optimization](wikipedia://en/33837524) based on the quadratic programming problem above, and an active set method called TNT-NN.[^o15]
