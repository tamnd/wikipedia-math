# Four-spiral semigroup

::: {#o1 .subject cue=lead name="Four-spiral semigroup"}

In [mathematics](wikipedia://en/18831), the **four-spiral semigroup** is a special [semigroup](wikipedia://en/27799) generated by four [idempotent](https://en.wikipedia.org/wiki/Idempotent) elements. This special semigroup was first studied by Karl Byleen in a doctoral dissertation submitted to the [University of Nebraska–Lincoln](https://en.wikipedia.org/wiki/University_of_Nebraska–Lincoln) in 1977.[^o2][^o3] It has several interesting properties: it is one of the most important examples of bi-simple but not completely-simple semigroups;[^o4] it is also an important example of a fundamental [regular semigroup](wikipedia://en/6797677);[^o3] it is an indispensable building block of bisimple, idempotent-generated regular semigroups.[^o3] A certain semigroup, called **double four-spiral semigroup**, generated by five idempotent elements has also been studied along with the four-spiral semigroup.[^o15][^o3]

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

The four-spiral semigroup, denoted by *Sp<sub>4</sub>*, is the [free semigroup](https://en.wikipedia.org/wiki/Free_semigroup) generated by four elements *a*, *b*, *c*, and *d* satisfying the following eleven conditions:[^o3]

- *a*<sup>2</sup> = *a*, *b*<sup>2</sup> = *b*, *c*<sup>2</sup> = *c*, *d*<sup>2</sup> = *d*.
- *ab* = *b*, *ba* = *a*, *bc* = *b*, *cb* = *c*, *cd* = *d*, *dc* = *c*.
- *da* = *d*.

The first set of conditions imply that the elements *a*, *b*, *c*, *d* are idempotents. The second set of conditions imply that *a R b L c R d* where *R* and *L* are the [Green's relations](wikipedia://en/1192012) in a semigroup. The lone condition in the third set can be written as *d* ω<sup>l</sup> *a*, where ω<sup>l</sup> is a [biorder relation](wikipedia://en/22367851) defined by [Nambooripad](wikipedia://en/23534956). The diagram below summarises the various relations among *a*, *b*, *c*, *d*:

$$\begin{matrix} & & \mathcal{R} & & \\ & a & \longleftrightarrow & b & \\ \omega^l & \Big \uparrow & & \Big \updownarrow & \mathcal{L} \\ & d & \longleftrightarrow & c & \\ & & \mathcal{R} & & \end{matrix}$$

:::

### General elements {#General_elements}

Every element of *Sp*<sub>4</sub> can be written uniquely in one of the following forms:[^o3]

\[*c*\] (*ac*)<sup>*m*</sup> \[a\]

\[*d*\] (*bd*)<sup>*n*</sup> \[*b*\]

\[*c*\] (*ac*)<sup>*m*</sup> *ad* (*bd*)<sup>*n*</sup> \[*b*\]

where *m* and *n* are non-negative integers and terms in square brackets may be omitted as long as the remaining product is not empty. The forms of these elements imply that *Sp*<sub>4</sub> has a [partition](wikipedia://en/340240) *Sp*<sub>4</sub> = *A* ∪ *B* ∪ *C* ∪ *D* ∪ *E* where

*A* = { *a*(*ca*)<sup>*n*</sup>, (*bd*)<sup>*n*+1</sup>, *a*(*ca*)<sup>*m*</sup>*d*(*bd*)<sup>*n*</sup> : *m*, *n* non-negative integers }

*B* = { (*ac*)<sup>*n*+1</sup>, *b*(*db*)<sup>*n*</sup>, *a*(*ca*)<sup>*m*</sup>(*db*) <sup>*n*+1</sup> : *m*, *n* non-negative integers }

*C* = { *c*(*ac*)<sup>*m*</sup>, (*db*)<sup>*n*+1</sup>, (*ca*)<sup>*m*+1</sup>(*db*)<sup>*n*+1</sup> : *m*, *n* non-negative integers }

*D* = { *d*(*bd*)<sup>*n*</sup>, (*ca*)<sup>*m*+1</sup>(*db*)<sup>*n*+1</sup>*d* : *m*, *n* non-negative integers }

*E* = { (*ca*)<sup>*m*</sup> : *m* positive integer }

The sets *A*, *B*, *C*, *D* are [bicyclic semigroups](wikipedia://en/1209346), *E* is an infinite [cyclic semigroup](https://en.wikipedia.org/wiki/Cyclic_semigroup) and the subsemigroup *D* ∪ *E* is a [nonregular semigroup](wikipedia://en/6797677).

### Idempotent elements {#Idempotent_elements}

The set of idempotents of *Sp*<sub>4</sub>,[^o10] is {*a*<sub>*n*</sub>, *b*<sub>*n*</sub>, *c*<sub>*n*</sub>, *d*<sub>*n*</sub> : *n* = 0, 1, 2, ...} where, *a*<sub>0</sub> = *a*, *b*<sub>0</sub> = *b*, *c*<sub>0</sub> = *c*, *d*<sub>0</sub> = *d*, and for *n* = 0, 1, 2, ....,

*a*<sub>*n*+1</sub> = *a*(*ca*)<sup>*n*</sup>(*db*)<sup>*n*</sup>*d*

*b*<sub>*n*+1</sub> = *a*(*ca*)<sup>*n*</sup>(*db*)<sup>*n*+1</sup>

*c*<sub>*n*+1</sub> = (*ca*)<sup>*n*+1</sup>(*db*)<sup>*n*+1</sup>

*d*<sub>*n*+1</sub> = (*ca*)<sup>*n*+1</sup>(*db*)<sup>*n*+l</sup>*d*

The sets of idempotents in the subsemigroups *A*, *B*, *C*, *D* (there are no idempotents in the subsemigroup *E*) are respectively:

*E*<sub>*A*</sub> = { *a*<sub>*n*</sub> : *n* = 0,1,2, ... }

*E*<sub>*B*</sub> = { *b*<sub>*n*</sub> : *n* = 0,1,2, ... }

*E*<sub>*C*</sub> = { *c*<sub>*n*</sub> : *n* = 0,1,2, ... }

*E*<sub>*D*</sub> = { *d*<sub>*n*</sub> : *n* = 0,1,2, ... }

## Four-spiral semigroup as a Rees-matrix semigroup {#Four-spiral_semigroup_as_a_Rees-matrix_semigroup}

Let *S* be the set of all quadruples (*r*, *x*, *y*, *s*) where *r*, *s*, ∈ { 0, 1 } and *x* and *y* are nonnegative integers and define a [binary operation](wikipedia://en/3948) in *S* by

$$(r, x, y, s) * (t, z, w, u) = \begin{cases} (r, x-y + \max(y , z + 1), \max(y - 1, z) - z + w, u) & \text{if } s = 0, t = 1\\ (r, x - y+ \max(y, z), \max(y, z) - z + w, u)&\text{otherwise.} \end{cases}$$

The set *S* with this operation is a [Rees matrix semigroup](wikipedia://en/41983973) over the [bicyclic semigroup](wikipedia://en/1209346), and the four-spiral semigroup *Sp*<sub>4</sub> is isomorphic to *S*.[^o3]

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- By definition itself, the four-spiral semigroup is an *idempotent generated semigroup* (*Sp*<sub>4</sub> is generated by the four idempotents *a*, *b*. *c*, *d*.)
- The four-spiral semigroup is a fundamental semigroup, that is, the only congruence on *Sp*<sub>4</sub> which is contained in the Green's relation *H* in *Sp*<sub>4</sub> is the equality relation.

:::

## Double four-spiral semigroup {#Double_four-spiral_semigroup}

The **fundamental double four-spiral semigroup**, denoted by *DSp*<sub>4</sub>, is the semigroup generated by five elements *a*, *b*, *c*, *d*, *e* satisfying the following conditions:[^o3][^o15]

- *a*<sup>2</sup> = *a*, *b*<sup>2</sup> = *b*, *c*<sup>2</sup> = *c*, *d*<sup>2</sup> = *d*, *e*<sup>2</sup> = *e*
- *ab* = *b*, *ba* = *a*, *bc* = *b*, *cb* = *c*, *cd* = *d*, *dc* = *c*, *de* = *d*, *ed* = *e*
- *ae* = *e*, *ea* = *e*

The first set of conditions imply that the elements *a*, *b*, *c*, *d*, *e* are idempotents. The second set of conditions state the Green's relations among these idempotents, namely, *a R b L c R d L e*. The two conditions in the third set imply that *e* ω *a* where ω is the [biorder relation](wikipedia://en/22367851) defined as ω = ω<sup>l</sup> ∩ ω<sup>r</sup>.
