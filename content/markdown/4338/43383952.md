# Briar (software)

::: {#o1 .subject cue=lead name="Briar"}

**Briar** is an [open-source software](https://en.wikipedia.org/wiki/Open-source_software) communication technology, intended to provide secure and resilient [peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) communications with no centralized servers and minimal reliance on external infrastructure. Messages can be transmitted through [Bluetooth](https://en.wikipedia.org/wiki/Bluetooth), [Wi-Fi](https://en.wikipedia.org/wiki/Wi-Fi), over the internet via [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29) or removable storage, such as [USB sticks](https://en.wikipedia.org/wiki/USB_flash_drive). All communication is [end-to-end](wikipedia://en/1065362) encrypted. Relevant content is stored in encrypted form on participating devices. Long-term plans for the project include support for distributed applications such as crisis mapping and collaborative document editing.

:::

The initial target audience for Briar includes "activists, journalists and civil society" with plans to make the system "simple enough to help anyone keep their data safe."[^o5] As the ability to function in the absence of internet infrastructure may also make the project valuable to disaster response and aid organizations, the developers are working with the Open Humanitarian Initiative and Taarifa.[^o6] Ultimately, the developers aim to create a system which is "as simple to use as [WhatsApp](wikipedia://en/32058867), as secure as [PGP](wikipedia://en/23080), and that keeps working if somebody breaks the Internet."[^o6] It is possible for an Android device to download Briar from another Android device which already has Briar installed.[^o7]

Briar's source code is published as [free software](https://en.wikipedia.org/wiki/Free_software) and the Android app is distributed under the terms of the [GNU GPL-3.0-or-later](https://en.wikipedia.org/wiki/GNU_General_Public_License) license, while the desktop version is released under the [GNU Affero General Public License](https://en.wikipedia.org/wiki/GNU_Affero_General_Public_License).[^o8] Briar Desktop runs on Windows, macOS and Linux. Briar Desktop will also run on true Linux (non-Android) mobile phones, running operating systems like [Manjaro](https://en.wikipedia.org/wiki/Manjaro), [PureOS](https://en.wikipedia.org/wiki/PureOS) and [postmarketOS](https://en.wikipedia.org/wiki/PostmarketOS),[^o9] once it has been adapted to mobile form-factors.[^o10]

Briar’s core protocol, threat model, development process, and user experience design began development in 2011 by Michael Rogers and Eleanor Saitta.[^o11][^o12]

Briar was audited by [Cure53](https://en.wikipedia.org/wiki/Cure53) and spoken highly of in a report delivered 20 March 2017, and was recommended to be given a second audit after development completes.[^o13][^o14] As of 2018 the project received \$361,100 of funding from the *[Open Technology Fund](wikipedia://en/49417443)*.[^o15]

Briar uses the Bramble [protocol suite](https://en.wikipedia.org/wiki/Protocol_suite) (Bramble Handshake Protocol, Bramble QR Code Protocol, Bramble Rendezvous Protocol, Bramble Synchronisation Protocol, Bramble Transport Protocol) that is specifically designed for [delay-tolerant networks](https://en.wikipedia.org/wiki/Delay-tolerant_networking).[^o16] As of January 2023, these protocols are not implemented by other messengers; Briar can only talk to Briar.

## iOS support {#iOS_support}

Briar developers have no plans for providing iOS app.[^o18][^o19]

Similar opensource alternative Berty Messenger provides both Android and iOS apps, as well desktop client for common desktop OS.[^o20]
