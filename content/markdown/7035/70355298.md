# Høffding

::: {#o1 .subject cue=lead name="Høffding"}

**Høffding** (or **Hoeffding**) is a surname. Notable people with the name include:

:::

- [Finn Høffding](https://en.wikipedia.org/wiki/Finn_Høffding) (1899–1997), Danish composer
- [Harald Høffding](https://en.wikipedia.org/wiki/Harald_Høffding) (1843–1931), Danish philosopher and theologian
- [Wassily Hoeffding](wikipedia://en/2547060) (1914–1991), Finnish statistician
