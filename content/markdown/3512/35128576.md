# Bipolar theorem

::: {#o1 .subject cue=lead name="Bipolar theorem"}

In [mathematics](wikipedia://en/18831), the **bipolar theorem** is a [theorem](wikipedia://en/30977) in [functional analysis](wikipedia://en/11180) that characterizes the bipolar (that is, the [polar](wikipedia://en/1764022) of the polar) of a set. In [convex analysis](wikipedia://en/3237201), the **bipolar theorem** refers to a [necessary and sufficient conditions](https://en.wikipedia.org/wiki/Necessary_and_sufficient_conditions) for a [cone](https://en.wikipedia.org/wiki/Cone_%28linear_algebra%29) to be equal to its [bipolar](https://en.wikipedia.org/wiki/Polar_cone). The bipolar theorem can be seen as a special case of the [Fenchel–Moreau theorem](wikipedia://en/35099255).[^o2]

:::

## Preliminaries {#Preliminaries}

Suppose that $X$ is a [topological vector space](wikipedia://en/45752) (TVS) with a [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) $X^{\prime}$ and let $\left\langle x, x^{\prime} \right\rangle := x^{\prime}(x)$ for all $x \in X$ and $x^{\prime} \in X^{\prime}.$ The **[convex hull](wikipedia://en/40634)** of a set $A,$ denoted by $\operatorname{co} A,$ is the smallest [convex set](wikipedia://en/6292) containing $A.$ The **[convex balanced hull](https://en.wikipedia.org/wiki/Convex_balanced_hull)** of a set $A$ is the smallest [convex](wikipedia://en/6292) [balanced](wikipedia://en/1734238) set containing $A.$

The **[polar](wikipedia://en/1764022)** of a subset $A \subseteq X$ is defined to be:

$$A^\circ := \left\{ x^{\prime} \in X^{\prime} : \sup_{a \in A} \left| \left\langle a, x^{\prime} \right\rangle \right| \leq 1 \right\}.$$

while the **prepolar** of a subset $B \subseteq X^{\prime}$ is:

$${}^{\circ} B := \left\{ x \in X : \sup_{x^{\prime} \in B} \left| \left\langle x, x^{\prime} \right\rangle \right| \leq 1 \right\}.$$

The **bipolar** of a subset $A \subseteq X,$ often denoted by $A^{\circ\circ}$ is the set

$$A^{\circ\circ} := {}^{\circ}\left(A^{\circ}\right) = \left\{ x \in X : \sup_{x^{\prime} \in A^{\circ}} \left|\left\langle x, x^{\prime} \right\rangle\right| \leq 1 \right\}.$$

## Statement in functional analysis {#Statement_in_functional_analysis}

Let $\sigma\left(X, X^{\prime}\right)$ denote the [weak topology](wikipedia://en/33662) on $X$ (that is, the weakest TVS topology on $X$ making all linear functionals in $X^{\prime}$ continuous).

**The bipolar theorem**:[^n1] The bipolar of a subset $A \subseteq X$ is equal to the $\sigma\left(X, X^{\prime}\right)$-closure of the [convex balanced hull](https://en.wikipedia.org/wiki/Convex_balanced_hull) of $A.$

## Statement in convex analysis {#Statement_in_convex_analysis}

**The bipolar theorem**:[^o2][^o7] For any [nonempty](https://en.wikipedia.org/wiki/Nonempty_set) cone $A$ in some [linear space](https://en.wikipedia.org/wiki/Linear_space) $X,$ the bipolar set $A^{\circ \circ}$ is given by:

$$A^{\circ \circ} = \operatorname{cl} (\operatorname{co} \{ r a : r \geq 0, a \in A \}).$$

::: {#o9 .statement kind=statement/generalization cue=heading name="Special case"}

### Special case {#Special_case}

A subset $C \subseteq X$ is a nonempty [closed](wikipedia://en/293802) [convex cone](wikipedia://en/3558266) if and only if $C^{++} = C^{\circ \circ} = C$ when $C^{++} = \left(C^{+}\right)^{+},$ where $A^{+}$ denotes the positive dual cone of a set $A.$[^o7][^o10] Or more generally, if $C$ is a nonempty convex cone then the bipolar cone is given by

$$C^{\circ \circ} = \operatorname{cl} C.$$

:::

::: {#o12 .statement kind=statement/theorem cue=named-heading name="Relation to the Fenchel–Moreau theorem"}

## Relation to the [Fenchel–Moreau theorem](wikipedia://en/35099255) {#Relation_to_the_Fenchel–Moreau_theorem}

Let

$$f(x) := \delta(x|C) = \begin{cases}0 & x \in C\\ \infty & \text{otherwise}\end{cases}$$

be the [indicator function](https://en.wikipedia.org/wiki/Characteristic_function_%28convex_analysis%29) for a cone $C.$ Then the [convex conjugate](wikipedia://en/1001490),

$$f^*(x^*) = \delta\left(x^*|C^\circ\right) = \delta^*\left(x^*|C\right) = \sup_{x \in C} \langle x^*,x \rangle$$

is the [support function](wikipedia://en/9377661) for $C,$ and $f^{**}(x) = \delta(x|C^{\circ\circ}).$ Therefore, $C = C^{\circ \circ}$ if and only if $f = f^{**}.$[^o2][^o10]

:::
