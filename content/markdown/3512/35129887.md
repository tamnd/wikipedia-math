# Bayesian inference using Gibbs sampling

::: {#o1 .subject cue=lead name="Bayesian inference using Gibbs sampling"}

**Bayesian inference using Gibbs sampling** (**BUGS**) is a [statistical software](https://en.wikipedia.org/wiki/Statistical_software) for performing [Bayesian inference](wikipedia://en/49571) using [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC) methods. It was developed by [David Spiegelhalter](wikipedia://en/2803355) at the Medical Research Council Biostatistics Unit in [Cambridge](https://en.wikipedia.org/wiki/University_of_Cambridge) in 1989 and released as free software in 1991.[^o2][^o3]

:::

The BUGS project has evolved through four main versions: ClassicBUGS,[^o4] [WinBUGS](wikipedia://en/10794084),[^o5] [OpenBUGS](wikipedia://en/3578854)[^o2] and [MultiBUGS](https://www.multibugs.org/).[^o6] MultiBUGS is built on the existing algorithms and tools in OpenBUGS and WinBUGS, which are no longer developed, and implements [parallelization](https://en.wikipedia.org/wiki/Parallel_computing) to speed up computation. Several [R](wikipedia://en/376707) packages are available, [R2MultiBUGS](https://github.com/MultiBUGS/R2MultiBUGS) acts as an interface to MultiBUGS, while [Nimble](https://r-nimble.org/) is an extension of the BUGS language.

Alternative implementations of the BUGS language include [JAGS](wikipedia://en/21845564) and [Stan](wikipedia://en/42243853).
