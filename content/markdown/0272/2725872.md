# Kitchen sink regression

::: {#o1 .subject cue=lead name="Kitchen sink regression"}

[Pejoratively](https://en.wikipedia.org/wiki/Pejorative), a **kitchen sink regression** is a statistical [regression](wikipedia://en/826997) which uses a long list of possible [independent variables](https://en.wikipedia.org/wiki/Independent_variable) to attempt to explain [variance](wikipedia://en/32344) in a [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable). In [economics](https://en.wikipedia.org/wiki/Economics), [psychology](https://en.wikipedia.org/wiki/Psychology), and other [social sciences](https://en.wikipedia.org/wiki/Social_sciences), regression analysis is typically used [deductively](wikipedia://en/61093) to test hypotheses, but a kitchen sink regression does not follow this norm. Instead, the analyst throws "everything but the kitchen sink" into the regression in hopes of finding some statistical pattern.

:::

This type of regression often leads to [overfitting](wikipedia://en/173332) (i.e. misleadingly suggesting relationships between independent and dependent variables in the data, which can lead to [hasty generalizations](https://en.wikipedia.org/wiki/Hasty_generalization)). The reason for this is that the more independent variables are included in a regression, the greater the probability that one or more will be found to be [statistically significant](wikipedia://en/160995) while in fact having no causal effect on the dependent variable as an implication of the definition of [confidence intervals](https://en.wikipedia.org/wiki/Confidence_intervals)—that is, the more likely the results are to be afflicted with [Type I error](https://en.wikipedia.org/wiki/Type_I_error).
