# Conull set

::: {#o1 .subject cue=lead name="Conull set"}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), a **conull set** is a set whose [complement](wikipedia://en/54347) is [null](wikipedia://en/21520), i.e., the [measure](wikipedia://en/19873) of the complement is zero.[^o2] For example, the set of [irrational numbers](wikipedia://en/20647689) is a conull [subset](wikipedia://en/27631) of the [real line](https://en.wikipedia.org/wiki/Real_line) with [Lebesgue measure](wikipedia://en/18198).[^o3]

:::

A property that is true of the elements of a conull set is said to be true [almost everywhere](wikipedia://en/44688).[^o4]
