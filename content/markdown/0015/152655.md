# Connector (mathematics)

::: {#o1 .subject cue=lead name="Connector"}

In [mathematics](wikipedia://en/18831), a **connector** is a map which can be defined for a [linear connection](wikipedia://en/391816) and used to define the [covariant derivative](wikipedia://en/431848) on a [vector bundle](wikipedia://en/276524) from the linear connection.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let ∇ be a connection on the tangent space TN of a smooth manifold N. For smooth mappings h:M→TN from any smooth manifold M, the connector K:TTN→TN satisfies : [∇](https://en.wikipedia.org/wiki/Nabla_symbol) h = K○Th:TM→TN where Th:TM→TTN is the differential of h.

:::
