# Linear function

::: {#o1 .subject cue=lead name="Linear function"}

In [mathematics](wikipedia://en/18831), the term **linear function** refers to two distinct but related notions:[^o2]

:::

- In [calculus](wikipedia://en/5176) and related areas, a [*linear function*](wikipedia://en/39712387) is a [function](wikipedia://en/185427) whose [graph](wikipedia://en/87352) is a [straight line](https://en.wikipedia.org/wiki/Straight_line), that is, a [polynomial function](https://en.wikipedia.org/wiki/Polynomial_function) of [degree](https://en.wikipedia.org/wiki/Polynomial_degree) zero (a constant polynomial) or one (a linear polynomial).[^o3] For distinguishing such a linear function from the other concept, the term *[affine function](https://en.wikipedia.org/wiki/Affine_function)* is often used.[^o4]
- In [linear algebra](wikipedia://en/18422), [mathematical analysis](wikipedia://en/48396),[^o5] and [functional analysis](wikipedia://en/11180), a *[linear function](https://en.wikipedia.org/wiki/Linear_function_%28linear_algebra%29)* is a kind of function between [vector spaces](wikipedia://en/32370).[^o6]

## As a polynomial function {#As_a_polynomial_function}

*Image: Linear Function Graph.svg.* Graphs of two linear functions.

In calculus, [analytic geometry](wikipedia://en/2202) and related areas, a linear function is a polynomial of degree one or less, including the [zero polynomial](https://en.wikipedia.org/wiki/Zero_polynomial). (The latter is a polynomial with no terms, and it is not considered to have degree zero.)

When the function is of only one [variable](wikipedia://en/3728109), it is of the form

$$f(x)=ax+b,$$

where $a$ and $b$ are [constants](wikipedia://en/24758132), often [real numbers](wikipedia://en/20646438). The [graph](wikipedia://en/87352) of such a function of one variable is a nonvertical line. $a$ is frequently referred to as the slope of the line, and $b$ as the intercept.

If *a > 0* then the [gradient](wikipedia://en/29368) is positive and the graph slopes upwards.

If *a \< 0* then the [gradient](wikipedia://en/29368) is negative and the graph slopes downwards.

For a function $f(x_1, \ldots, x_k)$ of any finite number of variables, the general formula is

$$f(x_1, \ldots, x_k) = b + a_1 x_1 + \cdots + a_k x_k ,$$

and the graph is a [hyperplane](wikipedia://en/99862) of dimension *k*.

A [constant function](wikipedia://en/320861) is also considered linear in this context, as it is a polynomial of degree zero or is the zero polynomial. Its graph, when there is only one variable, is a horizontal line.

In this context, a function that is also a linear map (the other meaning of linear functions, see below) may be referred to as a [homogeneous](wikipedia://en/622844) linear function or a [linear form](wikipedia://en/214137). In the context of linear algebra, the polynomial functions of degree 0 or 1 are the scalar-valued [affine maps](https://en.wikipedia.org/wiki/Affine_map).

## As a linear map {#As_a_linear_map}

*Image: Integral as region under curve.svg.* An [integral](wikipedia://en/15532) of an integrable function is a linear map from a vector space of integrable functions to real numbers (that is also a vector space).

In linear algebra, a linear function is a map $f$ from a [vector space](wikipedia://en/32370) $\mathbf{V}$ to a vector space $\mathbf{W}$ (Both spaces are not necessarily different.) over a same [field](wikipedia://en/10603) $K$ such that

$$f(\mathbf{x} + \mathbf{y}) = f(\mathbf{x}) + f(\mathbf{y})$$

$$f(a\mathbf{x}) = af(\mathbf{x}).$$

Here $a$ denotes a constant belonging to the field $K$ of [scalars](wikipedia://en/3588331) (for example, the [real numbers](wikipedia://en/20646438)), and $\mathbf{x}$ and $\mathbf{y}$ are elements of $\mathbf{V}$, which might be $K$ itself. Even if the same symbol $+$ is used, the operation of addition between $\mathbf{x}$ and $\mathbf{y}$ (belonging to $\mathbf{V}$) is not necessarily same to the operation of addition between $f\left( \mathbf{x} \right)$ and $f\left( \mathbf{y} \right)$ (belonging to $\mathbf{W}$).

In other terms the linear function preserves [vector addition](https://en.wikipedia.org/wiki/Vector_addition) and [scalar multiplication](wikipedia://en/244373).

Some authors use "linear function" only for linear maps that take values in the scalar field;[^o9] these are more commonly called [linear forms](wikipedia://en/214137).

The "linear functions" of calculus qualify as "linear maps" when (and only when) $f(0, ..., 0) = 0$, or, equivalently, when the constant $b$ equals zero in the one-degree polynomial above. Geometrically, the graph of the function must pass through the origin.
