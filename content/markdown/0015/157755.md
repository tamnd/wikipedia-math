# Fermat primality test

::: {#o1 .subject cue=lead name="Fermat primality test"}

The **Fermat primality test** is a [probabilistic](wikipedia://en/495383) test to determine whether a number is a [probable prime](wikipedia://en/160560).

:::

## Concept {#Concept}

[Fermat's little theorem](wikipedia://en/53453) states that if *p* is prime and *a* is not divisible by *p*, then

$$a^{p-1} \equiv 1 \pmod{p}.$$

If one wants to test whether *p* is prime, then we can pick random integers *a* not divisible by *p* and see whether the congruence holds. If it does not hold for a value of *a*, then *p* is composite. This congruence is unlikely to hold for a random *a* if *p* is composite.[^o3] Therefore, if the equality does hold for one or more values of *a*, then we say that *p* is [probably prime](wikipedia://en/160560).

However, note that the above congruence holds trivially for $a \equiv 1 \pmod{p}$, because the congruence relation is [compatible with exponentiation](wikipedia://en/20087#Basic_properties). It also holds trivially for $a \equiv -1 \pmod{p}$ if *p* is odd, for the same reason. That is why one usually chooses a random *a* in the interval $1 < a < p - 1$.

Any *a* such that

$$a^{n-1} \equiv 1 \pmod{n}$$

when *n* is composite is known as a *Fermat liar*. In this case *n* is called [Fermat pseudoprime](wikipedia://en/45891) to base *a*.

If we do pick an *a* such that

$$a^{n-1} \not\equiv 1 \pmod{n}$$

then *a* is known as a *Fermat witness* for the compositeness of *n*.

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

Suppose we wish to determine whether *n* = 221 is prime. Randomly pick 1 \< *a* \< 220, say *a* = 38. We check the above congruence and find that it holds:

$$a^{n-1} = 38^{220} \equiv 1 \pmod{221}.$$

Either 221 is prime, or 38 is a Fermat liar, so we take another *a*, say 24:

$$a^{n-1} = 24^{220} \equiv 81 \not\equiv 1 \pmod{221}.$$

So 221 is composite and 38 was indeed a Fermat liar. Furthermore, 24 is a Fermat witness for the compositeness of 221.

:::

::: {#o7 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

The algorithm can be written as follows:

**Inputs**: *n*: a value to test for primality, *n*>3; *k*: a parameter that determines the number of times to test for primality

**Output**: *composite* if *n* is composite, otherwise *probably prime*

Repeat *k* times:

Pick *a* randomly in the range \[2, *n* − 2\]

If $a^{n-1}\not\equiv1 \pmod n$, then return *composite*

If composite is never returned: return *probably prime*

The *a* values 1 and *n* − 1 are not used as the equality holds for all *n* and all odd *n* respectively, hence testing them adds no value.

### Complexity {#Complexity}

Using fast algorithms for [modular exponentiation](wikipedia://en/903032) and multiprecision multiplication, the running time of this algorithm is $O(k \log^{2}n \log \log n) = \text{Õ}(k \log^{2}n)$, where *k* is the number of times we test a random *a*, and *n* is the value we want to test for primality; see [Miller–Rabin primality test](wikipedia://en/188999#Complexity) for details.

:::

## Flaw {#Flaw}

There are infinitely many [Fermat pseudoprimes](wikipedia://en/45891) to any given basis *a* > 1.p. Theorem 1 Even worse, there are infinitely many [Carmichael numbers](wikipedia://en/7723).[^o10] These are numbers $n$ for which *all* values of $a$ with $\operatorname{gcd}(a, n) = 1$ are Fermat liars. For these numbers, repeated application of the Fermat primality test performs the same as a simple random search for factors. While Carmichael numbers are substantially rarer than prime numbers (Erdős' upper bound for the number of Carmichael numbers[^o11] is lower than the [prime number function n/log(n)](wikipedia://en/23692)) there are enough of them that Fermat's primality test is not often used in the above form. Instead, other more powerful extensions of the Fermat test, such as [Baillie–PSW](wikipedia://en/3609890), [Miller–Rabin](wikipedia://en/188999), and [Solovay–Strassen](wikipedia://en/1013089) are more commonly used.

In general, if $n$ is a composite number that is not a Carmichael number, then at least half of all

$a\in(\mathbb{Z}/n\mathbb{Z})^*$ (i.e. $\operatorname{gcd}(a,n)=1$)

are Fermat witnesses. For proof of this, let $a$ be a Fermat witness and $a_1$, $a_2$, ..., $a_s$ be Fermat liars. Then

$$(a\cdot a_i)^{n-1} \equiv a^{n-1}\cdot a_i^{n-1} \equiv a^{n-1} \not\equiv 1\pmod{n}$$

and so all $a \cdot a_i$ for $i = 1, 2, ..., s$ are Fermat witnesses.

## Corollaries {#Corollaries}

Analogous to the [Lucas–Lehmer residue](https://en.wikipedia.org/wiki/Lucas–Lehmer_residue), $r = a^{n-1} \pmod{n}$ is called the **Fermet residue** of *n* to base *a*. There are a few variants that produce different types of residues,[^o17] most importantly the [strong probable prime](https://en.wikipedia.org/wiki/Strong_probable_prime) (SPRP) residue.[^o13]

### Efficient exponentiation {#Efficient_exponentiation}

For Mersenne numbers (or more broadly, any $n = 2^p - 1$, *p* not necessarily a prime), it is more efficient to calculate $a^2r = a^{2^p} \pmod{n}$ than to calculate $r$ due to [exponentiation by squaring](wikipedia://en/10237) preferring a low [Hamming weight](wikipedia://en/1127884) (number of ones) in the exponent. The desired *r* may be recovered by multiplying by the [modular inverse](https://en.wikipedia.org/wiki/Modular_inverse) of $a^2$ mod *n*. It can alternatively be recovered by finding a small multiplier *u* such that $\operatorname{lift}(a^2r) + un$ is divisible by $a^2$ in ordinary integer arithmetic, then $r = (\operatorname{lift}(a^2r) + un) / a^2$. This can proceed by trial and error, or by noticing that $u = \operatorname{modinv}(n, a^2)$.[^o15]

### Testing cofactors of *n* {#Testing_cofactors_of_n}

If the residue *r* for *n* to base *a* is known, then for any proper divisor *k* of *n*, it is possible to perform a quick though weaker primality test on *n*/*k*. If *n*/*k* is prime, by Fermat's theorem $a^{n/k} = a^k \pmod{n/k}$ and $a^n = a^k \pmod{n/k}$. As a result $r = a^{k-1} \pmod{n/k}$, which can be much more efficiently checked for values of *k* much smaller than *n*. (This is the method used by the [Great Internet Mersenne Prime Search](wikipedia://en/12917) for testing cofactors.)[^o17]

A even weaker form of the test can be conducted with a truncated $a^n \pmod{n} \pmod{2^t}$ if storage space for the residue is a concern, so long as $d \leq 2^t$ and $n > 2^t$. Let $s = a^k \pmod{n/k}$, then $r = s+wn/k$ for some *w*. Take this mod 2<sup>*t*</sup> and we have $w = (n/k)^{-1}(s-r) \pmod{2^t}$. *n*/*k* is composite if $w \geq d$. A similar test can be done on truncated Lucas–Lehmer residues.[^o18]

### Path to being deterministic {#Path_to_being_deterministic}

It is also true that if all bases *a* are systematically checked in the interval $[2,\sqrt{n}]$, each demonstrating congruence to 1, the test is effectively deterministic. We may say that *n* is definitely prime. At cursory glance one may assume that *n* exists in the union of both primes and Carmichael numbers for such a scenario, but if *a*-values are systematically checked in the interval, one is bound to be a prime factor of a composite *n* at some point before $\sqrt{n}$, thus making *a* and *n* not coprime, and failing the congruence, even if *n* is indeed a Carmichael number. Carmichael numbers do fail Fermat's congruence to 1 if the base used is not coprime. Though this is more computationally expensive than brute force divisibility checking (trial division), it is of theoretical value.

::: {#o21 .application cue=heading name="Applications"}

## Applications {#Applications}

As mentioned above, most applications use a [Miller–Rabin](wikipedia://en/188999) or [Baillie–PSW](wikipedia://en/3609890) test for primality. Sometimes a Fermat test (along with some trial division by small primes) is performed first to improve performance. [GMP](https://en.wikipedia.org/wiki/GNU_Multiple_Precision_Arithmetic_Library) since version 3.0 uses a base-210 Fermat test after trial division and before running Miller–Rabin tests. [Libgcrypt](wikipedia://en/29870579) uses a similar process with base 2 for the Fermat test, but [OpenSSL](wikipedia://en/438819) does not.

In practice with most big number libraries such as GMP, the Fermat test is not noticeably faster than a Miller–Rabin test, and can be slower for many inputs.[^o22]

As an exception, OpenPFGW uses only the Fermat test for probable prime testing. The program is typically used with multi-thousand digit inputs with a goal of maximum speed with very large inputs. Another well known program that relies only on the Fermat test is [PGP](wikipedia://en/23080) where it is only used for testing of self-generated large random values (an open source counterpart, [GNU Privacy Guard](wikipedia://en/38809), uses a Fermat pretest followed by Miller–Rabin tests).

### Prime number search projects {#Prime_number_search_projects}

Internet [volunteer computing](https://en.wikipedia.org/wiki/Volunteer_computing) projects such as [Great Internet Mersenne Prime Search](wikipedia://en/12917) (GIMPS) and [PrimeGrid](wikipedia://en/3255603) use the Fermat primality test because there is an efficient proof scheme (Gerbicz-Li) for modular exponentiation. Selected intermediate results, combined with a [verifiable delay function](https://en.wikipedia.org/wiki/Verifiable_delay_function), are used to generate a "[proof](wikipedia://en/3691235)" file for verifying the authenticity and correctness of the computation, protecting against both hardware error and malicious actors. This proof is hard to forge given a low order assumption. The original form of the verification (Gerbicz-Pietrzak) only worked with *n* being derivable from powers of 2, such as in the case of Mersenne primes, Mersenne cofactors, and Proth primes; Li's modification generalizes it to any *n*.[^o24]

The GIMPS in particular tests Mersenne primes and Mersenne cofactors. The default is to use *a* = 3 as all Mersenne numbers would pass the test with *a* = 2.
