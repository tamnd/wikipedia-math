# Tree decomposition

::: {#o1 .subject cue=lead name="Tree decomposition"}

*Image: Tree decomposition.svg.* A graph with eight vertices, and a tree decomposition of it onto a tree with six nodes. Each graph edge connects two vertices that are listed together at some tree node, and each graph vertex is listed at the nodes of a contiguous subtree of the tree. Each tree node lists at most three vertices, so the width of this decomposition is two.

In [graph theory](wikipedia://en/12401), a **tree decomposition** is a mapping of a [graph](wikipedia://en/325806) into a [tree](wikipedia://en/48560) that can be used to define the [treewidth](wikipedia://en/3987086) of the graph and speed up solving certain computational problems on the graph.

:::

Tree decompositions are also called **junction trees**, **clique trees**, or **join trees**. They play an important role in problems like [probabilistic inference](wikipedia://en/800010), [constraint satisfaction](https://en.wikipedia.org/wiki/Constraint_satisfaction), [query optimization](https://en.wikipedia.org/wiki/Query_optimization),[^n1] and [matrix decomposition](wikipedia://en/253873).

The concept of tree decomposition was originally introduced by (txt). Later it was rediscovered by (txt) and has since been studied by many other authors.[^o5]

## Definition {#Definition}

Intuitively, a tree decomposition represents the vertices of a given graph $G$ as subtrees of a tree, in such a way that vertices in $G$ are adjacent only when the corresponding subtrees intersect. Thus, $G$ forms a [subgraph](wikipedia://en/325802#Subgraphs) of the [intersection graph](wikipedia://en/7726759) of the subtrees. The full intersection graph is a [chordal graph](wikipedia://en/744165).

Each subtree associates a graph vertex with a set of tree nodes. To define this formally, we represent each tree node as the set of vertices associated with it. Thus, given a graph $G = (V, E)$, a tree decomposition is a pair $(X, T)$, where $X = \{X_{1}, \ldots, X_{n}\}$ is a family of subsets (sometimes called *bags*) of $V$, and $T$ is a tree whose nodes are the subsets $X_{i}$, satisfying the following properties:[^o8]

1. The union of all sets $X_{i}$ equals $V$. That is, each graph vertex is associated with at least one tree node.
1. For every edge $(v, w)$ in the graph, there is a subset $X_{i}$ that contains both $v$ and $w$. That is, vertices are adjacent in the graph only when the corresponding subtrees have a node in common.
1. If $X_{i}$ and $X_{j}$ both contain a vertex $v$, then all nodes $X_{k}$ of the tree in the (unique) path between $X_{i}$ and $X_{j}$ contain $v$ as well. That is, the nodes associated with vertex $v$ form a connected subset of $T$. This is also known as coherence, or the *running intersection property*. It can be stated equivalently that if $X_{i}$, $X_{j}$ and $X_{k}$ are nodes, and $X_{k}$ is on the path from $X_{i}$ to $X_{j}$, then $X_i \cap X_j \subseteq X_k$.

The tree decomposition of a graph is far from unique; for example, a trivial tree decomposition contains all vertices of the graph in its single root node.

A tree decomposition in which the underlying tree is a [path graph](wikipedia://en/4587190) is called a path decomposition, and the width parameter derived from these special types of tree decompositions is known as [pathwidth](wikipedia://en/5133142).

A tree decomposition $(X, T = (I, F))$ of treewidth $k$ is *smooth*, if for all $i \in I : |X_i| = k + 1$, and for all $(i, j) \in F : |X_i \cap X_j| = k$.[^o9]

:::

## Treewidth {#Treewidth}

*Image: Treedecompsnocolour.JPG.* Two different tree-decompositions of the same graph

The *width* of a tree decomposition is the size of its largest set $X_{i}$ minus one. The [treewidth](wikipedia://en/3987086) $\operatorname{tw}(G)$ of a graph $G$ is the minimum width among all possible tree decompositions of $G$. In this definition, the size of the largest set is diminished by one in order to make the treewidth of a tree equal to one. Treewidth may also be defined from other structures than tree decompositions, including [chordal graphs](wikipedia://en/744165), [brambles](wikipedia://en/36601188), and [havens](wikipedia://en/5133456).

It is NP-complete to determine whether a given graph $G$ has treewidth at most a given variable $k$.[^o11] However, when $k$ is any fixed constant, the graphs with treewidth $k$ can be recognized, and a width $k$ tree decomposition constructed for them, in linear time.[^o9] The time dependence of this algorithm on $k$ is an exponential function of $k^{3}$.

## Dynamic programming {#Dynamic_programming}

At the beginning of the 1970s, it was observed that a large class of combinatorial optimization problems defined on graphs could be efficiently solved by non-serial [dynamic programming](wikipedia://en/125297) as long as the graph had a bounded *dimension*,[^n2] a parameter related to treewidth. Later, several authors independently observed, at the end of the 1980s,[^o14] that many algorithmic problems that are [NP-complete](wikipedia://en/23385892) for arbitrary graphs may be solved efficiently by [dynamic programming](wikipedia://en/125297) for graphs of bounded treewidth, using the tree-decompositions of these graphs.

As an example, consider the problem of finding the [maximum independent set](https://en.wikipedia.org/wiki/Maximum_independent_set) in a graph of treewidth $k$. To solve this problem, first choose one of the nodes of the tree decomposition to be the root, arbitrarily. For a node $X_{i}$ of the tree decomposition, let $D_{i}$ be the union of the sets $X_{j}$ descending from $X_{i}$. For an independent set $S \subset X_i,$ let $A(S,i)$ denote the size of the largest independent subset $I$ of $D_{i}$ such that $I \cap X_i = S.$ Similarly, for an adjacent pair of nodes $X_{i}$ and $X_{j}$, with $X_{i}$ farther from the root of the tree than $X_{j}$, and an independent set $S \subset X_i \cap X_j,$ let $B(S,i,j)$ denote the size of the largest independent subset $I$ of $D_{i}$ such that $I \cap X_i \cap X_j = S.$ We may calculate these $A$ and $B$ values by a bottom-up traversal of the tree:

$$A(S,i)=|S| + \sum_{j} \left(B(S\cap X_j, j,i) - |S\cap X_j|\right)$$

$$B(S,i,j)=\max_{S'\subset X_i\atop S=S'\cap X_j} A(S',i)$$

where the sum in the calculation of $A(S,i)$ is over the children of node $X_{i}$.

At each node or edge, there are at most $2^{k}$ sets $S$ for which we need to calculate these values, so if $k$ is a constant then the whole calculation takes constant time per edge or node. The size of the maximum independent set is the largest value stored at the root node, and the maximum independent set itself can be found (as is standard in dynamic programming algorithms) by backtracking through these stored values starting from this largest value. Thus, in graphs of bounded treewidth, the maximum independent set problem may be solved in linear time. Similar algorithms apply to many other graph problems.

This dynamic programming approach is used in [machine learning](wikipedia://en/233488) via the [junction tree algorithm](wikipedia://en/4855682) for [belief propagation](wikipedia://en/800010) in graphs of bounded treewidth. It also plays a key role in algorithms for computing the treewidth and constructing tree decompositions: typically, such algorithms have a first step that [approximates](wikipedia://en/563105) the treewidth, constructing a tree decomposition with this approximate width, and then a second step that performs dynamic programming in the approximate tree decomposition to compute the exact value of the treewidth.[^o9]
