# Transect

::: {#o1 .subject cue=lead name="Transect"}

*Image: Ed Williams measuring a transect (9664326339).jpg.* A transect running across a stream.

A **transect** is a path along which one counts and records occurrences of the objects of study (e.g. plants).[^o2]

:::

It requires an observer to move along a fixed path and to count occurrences along the path and, at the same time (in some procedures), obtain the distance of the object from the path. This results in an estimate of the area covered and an estimate of the way in which detectability increases from probability 0 (far from the path) towards 1 (near the path). Using the raw count and this probability function, one can arrive at an estimate of the actual density of objects.

*Image: Transects of fire boundary above Backhouse Tarn.jpg.* Transects being used to measure the changes around the boundary of a grassland fire near Backhouse Tarn, Tasmania.

The estimation of the abundance of populations (such as terrestrial mammal species) can be achieved using a number of different types of transect methods, such as strip transects, [line transects](wikipedia://en/17076220), [belt transects](wikipedia://en/5044718), [point transects](https://en.wikipedia.org/wiki/Point_transect)[^o3], [gradsects](https://en.wikipedia.org/wiki/Gradsect) and curved line transects.[^o4]
