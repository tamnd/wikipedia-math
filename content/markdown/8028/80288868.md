# Weierstrass–Mandelbrot function

*Image: A terrain generated using the Weierstrass–Mandelbrot function rendered in Blender.png.* A [fractal surface](https://en.wikipedia.org/wiki/Fractal_surface) generated using the Weierstrass–Mandelbrot function rendered in Blender

::: {#o1 .subject cue=lead name="Weierstrass–Mandelbrot function"}

The **Weierstrass–Mandelbrot function** (often abbreviated **W-M function** and sometimes referred to as Weierstrass–Mandelbrot Noise) is a generalization of the classical [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function), extended to higher dimensions to model natural [fractal phenomena](wikipedia://en/28782). It is frequently used in [terrain generation](https://en.wikipedia.org/wiki/Terrain_generation), particularly in simulated environments for [robotics](https://en.wikipedia.org/wiki/Robotics) and [autonomous vehicle](https://en.wikipedia.org/wiki/Autonomous_vehicle) testing. Unlike its 1D counterpart, the W-M function in multiple dimensions displays directionality, [anisotropy](https://en.wikipedia.org/wiki/Anisotropy), and multifractality, making it suitable for simulations of physically realistic surfaces.[^o2]

:::

## Mathematical formulation {#Mathematical_formulation}

The most common definition of the W-M function is:

$$z(x, y) = A \sum_{m=1}^{M} \sum_{n=1}^{n_{\text{max}}} \gamma^{(D - 3)n} \left[ \cos(\phi_{m,n}) - \cos \left\{ 2\pi \gamma^n \frac{\sqrt{x^2 + y^2}}{L} \cos \left( \arctan\left(\frac{y}{x}\right) - \frac{\pi m}{M} \right) + \phi_{m,n} \right\} \right]$$

where:

- $z(x, y)$ is the terrain height at the spatial coordinates $(x, y)$,
- $(x, y)$ are the 2D spatial coordinates on the ground plane,
- $A = L \left( \frac{G}{L} \right)^{D - 2} \left( \frac{\ln(\gamma)}{M} \right)^{1/2}$ is a normalization factor,
- $\gamma$ is the frequency scaling factor,
- $D$ is the fractal dimension,
- $\phi_{m,n}$ is a uniformly distributed random phase,
- $M$ is the number of angular directions,
- $n_{\text{max}}$ is the maximum frequency index,
- $L$ is the sampling length,
- $G$ is the scaling coefficient.[^o4]

*Image: The\_Weierstrass-Mandelbrot\_function\_on\_a\_2D\_grid.png.* The Weierstrass-Mandelbrot function, top view

The W-M function generates statistically self-similar surfaces with control over roughness, orientation, and frequency distribution, making it ideal for modeling realistic and irregular topographies.

## History {#History}

The Weierstrass–Mandelbrot function was first explicitly studied and named in a 1980 paper by [Michael V. Berry](https://en.wikipedia.org/wiki/Michael_V._Berry) and Z. V. Lewis, titled “On the Weierstrass–Mandelbrot Fractal Function.”[^o6] This work was published in the [Proceedings of the Royal Society](https://en.wikipedia.org/wiki/Proceedings_of_the_Royal_Society) and marked the initial introduction of the function as a [fractal](wikipedia://en/10913) object with applications in physics and mathematics. Berry and Lewis provided computer-generated visualizations of the function, helping establish it as a useful model for fractal phenomena. The function extends the classical [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function), which was originally introduced in the late 19th century by [Karl Weierstrass](wikipedia://en/93459) as an example of a continuous but nowhere differentiable function. The Weierstrass–Mandelbrot function builds on this foundation by incorporating multifractal and multidimensional characteristics, as further explored in subsequent studies such as those by Marcel Ausloos and D. H. Berman in 1985.[^o7] Since then, the function has been adopted in a range of fields, including terrain modeling, due to its ability to simulate realistic, self-similar rough surfaces.

## Use in terrain generation {#Use_in_terrain_generation}

The Weierstrass–Mandelbrot function has found wide usage in [procedural generation](https://en.wikipedia.org/wiki/Procedural_generation) of digital terrains. Its multifractal nature allows the synthesis of realistic [elevation maps](https://en.wikipedia.org/wiki/Digital_elevation_model) for evaluating the performance of ground vehicles, particularly autonomous robots navigating rough or off-road environments.[^o4]

The function is especially useful for testing suspension, traction, and path planning modules of [autonomous ground vehicles](https://en.wikipedia.org/wiki/Autonomous_ground_vehicle) in computer simulations.

## Implementation in Python / NumPy {#Implementation_in_Python_/_NumPy}

```python
import numpy as np

def weierstrass_mandelbrot_3d(x, y, D, G, L, gamma, M, n_max):
    """
    Compute the 3D Weierstrass–Mandelbrot function z(x, y).

    Parameters:
        x, y : 2D np.ndarrays
            Meshgrid arrays of spatial coordinates.
        D : float
            Fractal dimension (typically between 2 and 3).
        G : float
            Amplitude roughness coefficient.
        L : float
            Transverse width of the profile.
        gamma : float
            Frequency scaling factor (typically > 1).
        M : int
            Number of ridges (azimuthal angles).
        n_max : int
            Upper cutoff frequency index.

    Returns:
        z : 2D np.ndarray
            The height field generated by the WM function.
    """
    A = L * (G / L) ** (D - 2) * (np.log(gamma) / M) ** 0.5
    z = np.zeros_like(x)

    for m in range(1, M + 1):
        theta_m = np.arctan2(y, x) - np.pi * m / M
        phi_mn = np.random.uniform(0, 2 * np.pi, size=n_max + 1)

        for n in range(n_max + 1):
            gamma_n = gamma**n
            r = np.sqrt(x**2 + y**2)
            term = np.cos(phi_mn[n]) - np.cos(
                2 * np.pi * gamma_n * r / L * np.cos(theta_m) + phi_mn[n]
            )
            z += gamma ** ((D - 3) * n) * term

    return A * z
```
