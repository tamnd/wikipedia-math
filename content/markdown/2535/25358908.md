# Minimum k-cut

*Image: Minimum k-cut.svg.* Minimum $k$-cut for $k$ $=2$ and $3$ respectively (cuts highlighted red)

::: {#o1 .subject cue=lead name="Minimum k-cut"}

In mathematics, the **minimum $k$-cut** is a [combinatorial optimization](wikipedia://en/420555) problem that requires finding a set of edges whose removal would partition the graph to at least $k$ [connected components](wikipedia://en/246223). These edges are referred to as **$k$-cut**. The goal is to find the minimum-weight $k$-cut. This partitioning can have applications in [VLSI](https://en.wikipedia.org/wiki/VLSI) design, [data-mining](https://en.wikipedia.org/wiki/Data-mining), [finite elements](https://en.wikipedia.org/wiki/Finite_elements) and communication in [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Given an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) $G = (V, E)$ with an assignment of weights to the edges $w: E \to N$ and an [integer](wikipedia://en/14563) $k \in \{2,3, \ldots, |V|\},$ [partition](https://en.wikipedia.org/wiki/Partition_%28mathematics%29) $V$ into $k$ [disjoint sets](wikipedia://en/39359) $F = \{ C_1,C_2,\ldots,C_k \}$ while minimizing

$$\sum_{i=1}^{k-1} \ \sum_{j=i+1}^k \sum_{\begin{smallmatrix} v_1 \in C_i \\ v_2 \in C_j \end{smallmatrix}} w ( \left \{ v_1, v_2 \right \} ).$$

For a fixed $k$, the problem is [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) solvable in $O \bigl(|V|^{k^2} \bigr).$[^o4] However, the problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) if $k$ is part of the input.[^o5] It is also NP-complete if we specify $k$ vertices and ask for the minimum $k$-cut which separates these vertices among each of the sets.[^o6]

:::

## Approximations {#Approximations}

Several [approximation algorithms](https://en.wikipedia.org/wiki/Approximation_algorithms) exist with an approximation of $2-\tfrac 2 k.$ A simple [greedy algorithm](wikipedia://en/89247) that achieves this approximation factor computes a [minimum cut](wikipedia://en/3562453) in each of the connected components and removes the lightest one. This algorithm requires a total of $n - 1$ [max flow](https://en.wikipedia.org/wiki/Max_flow) computations. Another algorithm achieving the same guarantee uses the [Gomory–Hu tree](wikipedia://en/24093092) representation of minimum cuts. Constructing the Gomory–Hu tree requires $n - 1$ max flow computations, but the algorithm requires an overall $O(kn)$ max flow computations. Yet, it is easier to analyze the approximation factor of the second algorithm.[^o8][^o9] Moreover, under the [small set expansion hypothesis](wikipedia://en/73292008) (a conjecture closely related to the [unique games conjecture](wikipedia://en/3000842)), the problem is NP-hard to approximate to within $(2 - \varepsilon)$ factor for every constant $\varepsilon > 0$,[^o10] meaning that the aforementioned approximation algorithms are essentially tight for large $k$.

A variant of the problem asks for a minimum weight $k$-cut where the output partitions have pre-specified sizes. This problem variant is approximable to within a factor of 3 for any fixed $k$ if one restricts the graph to a metric space, meaning a [complete graph](wikipedia://en/85816) that satisfies the [triangle inequality](wikipedia://en/53941).[^o11] More recently, [polynomial time approximation schemes](https://en.wikipedia.org/wiki/Polynomial_time_approximation_scheme) (PTAS) were discovered for those problems.[^o12]

While the minimum $k$-cut problem is [W\[1\]-hard](wikipedia://en/603026) parameterized by $k$,[^o13] a [parameterized approximation scheme](wikipedia://en/72808068) can be obtained for this parameter.[^o14]
