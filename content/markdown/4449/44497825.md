# Alt-Ergo

::: {#o1 .subject cue=lead name="Alt-Ergo"}

**Alt-Ergo**, an automatic solver for [mathematical](wikipedia://en/18831) [formulas](wikipedia://en/164040), is mainly used in [formal program verification](https://en.wikipedia.org/wiki/Formal_verification). It operates on the principle of [satisfiability modulo theories](https://en.wikipedia.org/wiki/Satisfiability_modulo_theories) (SMT). Development was undertaken by researchers at the [Paris-Sud University](https://en.wikipedia.org/wiki/Paris-Sud_University), Laboratoire de Recherche en Informatique, Inria Saclay Ile-de-France, and [CNRS](https://en.wikipedia.org/wiki/CNRS). Since 2013, project management and oversight has been conducted by OCamlPro company.[^o3] It is released under the [free and open-source software](https://en.wikipedia.org/wiki/Free_and_open-source_software) CeCILL-C license.

:::

## Technologies {#Technologies}

### Design choices {#Design_choices}

Alt-Ergo employs a specialized input language with [prenex polymorphism](https://en.wikipedia.org/wiki/Parametric_polymorphism#Rank-1_.28prenex.29_polymorphism), designed to reduce the number of axioms requiring quantification and to simplify the complexity of problems. While Alt-Ergo offers partial support for the [SMT-LIB](https://en.wikipedia.org/wiki/SMT-LIB) 2 language, its efficiency with SMT files is comparatively limited.

### Main components {#Main_components}

The core architecture of Alt-Ergo comprises three main elements: a [depth-first search](wikipedia://en/97034) (DFS)-based [SAT solver](https://en.wikipedia.org/wiki/SAT_solver), a quantifiers instantiation engine that uses [e-matching](https://en.wikipedia.org/wiki/E-graph), and an assembly of [decision procedures](https://en.wikipedia.org/wiki/Decision_procedure) for a range of built-in theories. These components collectively enable Alt-Ergo's abilities in automatic formula solving.

### Built-in theories {#Built-in_theories}

Alt-Ergo implements (semi-)decision procedures for the following theories:

- [Empty theory](https://en.wikipedia.org/wiki/Empty_theory)
- Linear integer arithmetic
- Linear rational arithmetic
- Non-linear arithmetic
- [Floating point arithmetic](https://en.wikipedia.org/wiki/Floating_point_arithmetic)
- [Polymorphic](https://en.wikipedia.org/wiki/Polymorphism_%28computer_science%29) arrays
- [Enumerated](https://en.wikipedia.org/wiki/Enumerated_type) [data types](https://en.wikipedia.org/wiki/Data_type)
- AC symbols
- [Record](https://en.wikipedia.org/wiki/Record_%28computer_science%29) [data types](https://en.wikipedia.org/wiki/Data_type)

## Industrial uses {#Industrial_uses}

Several verification platforms are built on Alt-Ergo:

- [Why3](http://why3.lri.fr/), a platform for deductive program verification, uses Alt-Ergo as main prover[^o9]
- CAVEAT, a C-verifier developed by CEA and used by Airbus; Alt-Ergo was included in the qualification DO-178C of one of its aircraft
- [Frama-C](https://en.wikipedia.org/wiki/Frama-C), a framework to analyse C-code, uses Alt-Ergo in the Jessie and WP plugins (dedicated to *deductive program verification*)
- [SPARK](https://en.wikipedia.org/wiki/SPARK_%28programming_language%29), uses Alt-Ergo (behind GNATprove) to automate the verification of some assertions in Spark 2014
- [Atelier-B](https://en.wikipedia.org/wiki/B-Method) can use Alt-Ergo instead of its main prover (raising success from 84% to 98% on [ANR Bware project benchmarks](http://alt-ergo.lri.fr/documents/ABZ-2014.pdf))
- [Rodin](https://en.wikipedia.org/wiki/Rodin_tool), a B-method framework developed by Systerel, can use Alt-Ergo as a back-end
- [Cubicle](http://cubicle.lri.fr/), an open source model checker to verify safety properties of array-based transition systems
- [EasyCrypt](https://www.easycrypt.info/), a toolset for reasoning about relational properties of probabilistic computations with adversarial code
- BWARE[^o10]
- Cafein[^o10]
- FUI Hi-Lite[^o10]
- Decert[^o10]
- ADT Alt-Ergo[^o10]
- A3PAT[^o10]
