# Fernique's theorem

::: {#o1 .subject cue=lead name="Fernique's theorem"}

**Fernique's theorem** is a result about [Gaussian measures](wikipedia://en/6572909) on [Banach spaces](wikipedia://en/3989). It extends the finite-dimensional result that a Gaussian [random variable](wikipedia://en/25685) has [exponential](wikipedia://en/9678) tails. The result was proved in 1970 by [Xavier Fernique](wikipedia://en/18412809).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let (*X*, || ||) be a [separable](wikipedia://en/27855) Banach space. Let *μ* be a centred Gaussian measure on *X*, i.e. a [probability measure](wikipedia://en/45437) defined on the [Borel sets](wikipedia://en/43327) of *X* such that, for every [bounded linear functional](https://en.wikipedia.org/wiki/Bounded_linear_functional) *ℓ* : *X* → **R**, the [push-forward measure](https://en.wikipedia.org/wiki/Push-forward_measure) *ℓ*<sub>∗</sub>*μ* defined on the [Borel sets](https://en.wikipedia.org/wiki/Borel_sets) of **R** by

$$( \ell_{\ast} \mu ) (A) = \mu ( \ell^{-1} (A) ),$$

is a Gaussian measure (a [normal distribution](wikipedia://en/21462)) with zero [mean](wikipedia://en/9653). Then there exists *α* > 0 such that

$$\int_{X} \exp ( \alpha \| x \|^{2} ) \, \mathrm{d} \mu (x) < + \infty.$$

*[A fortiori](https://en.wikipedia.org/wiki/A_fortiori)*, *μ* (equivalently, any *X*-valued random variable *G* whose [law](wikipedia://en/23543) is *μ*) has [moments](wikipedia://en/368684) of all orders: for all *k* ≥ 0,

$$\mathbb{E} [ \| G \|^{k} ] = \int_{X} \| x \|^{k} \, \mathrm{d} \mu (x) < + \infty.$$

:::
