# Weakly harmonic function

::: {#o1 .subject cue=lead name="Weakly harmonic function"}

In [mathematics](wikipedia://en/18831), a function $f$ is **weakly harmonic** in a domain $D$ if

:::

$$\int_D f\, \Delta g = 0$$

for all $g$ with [compact support](https://en.wikipedia.org/wiki/Compact_support) in $D$ and continuous second derivatives, where Δ is the [Laplacian](https://en.wikipedia.org/wiki/Laplacian).[^o2] This is the same notion as a [weak derivative](wikipedia://en/1411087), however, a function can have a weak derivative and not be differentiable. In this case, we have the somewhat surprising result that a function is weakly harmonic if and only if it is harmonic. Thus weakly harmonic is actually equivalent to the seemingly stronger harmonic condition.
