# Whirlpool (hash function)

::: {#o3 .subject cue=lead name="Whirlpool"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science) and [cryptography](wikipedia://en/18934432), **Whirlpool** (sometimes styled **WHIRLPOOL**) is a [cryptographic hash function](wikipedia://en/439526). It was designed by [Vincent Rijmen](https://en.wikipedia.org/wiki/Vincent_Rijmen) (co-creator of the [Advanced Encryption Standard](wikipedia://en/1260)) and [Paulo S. L. M. Barreto](https://en.wikipedia.org/wiki/Paulo_S._L._M._Barreto), who first described it in 2000. It is named after the [Whirlpool galaxy](https://en.wikipedia.org/wiki/Whirlpool_Galaxy) in [Canes Venatici](https://en.wikipedia.org/wiki/Canes_Venatici) ([M51](https://en.wikipedia.org/wiki/M51_Group), or [NGC 5194](https://en.wikipedia.org/wiki/NGC_5194)), the first one recognized to have a spiral structure by [William Parsons](https://en.wikipedia.org/wiki/William_Parsons,_3rd_Earl_of_Rosse), third Earl of Rosse, in April 1845[^o2].

:::

The hash has been recommended by the [NESSIE](wikipedia://en/497430) project. It has also been adopted by the [International Organization for Standardization](https://en.wikipedia.org/wiki/International_Organization_for_Standardization) (ISO) and the [International Electrotechnical Commission](https://en.wikipedia.org/wiki/International_Electrotechnical_Commission) (IEC) as part of the joint ISO/IEC 10118-3 [international standard](https://en.wikipedia.org/wiki/International_standard).

## Design features {#Design_features}

*Image: Messier51 sRGB.jpg.* The [Whirlpool Galaxy](https://en.wikipedia.org/wiki/Whirlpool_Galaxy) (M51), which inspired the name of the algorithm.[^o5]

Whirlpool is a hash designed after the [Square](wikipedia://en/613945) [block cipher](wikipedia://en/4594), and is considered to be in that family of block cipher functions.

Whirlpool is a [Miyaguchi–Preneel](wikipedia://en/3851622#Miyaguchi–Preneel) construction based on a substantially modified [Advanced Encryption Standard](wikipedia://en/1260) (AES).

Whirlpool takes a message of any length less than 2<sup>256</sup> bits and returns a 512-bit [message digest](https://en.wikipedia.org/wiki/Message_digest).[^o6]

The authors have declared that

"WHIRLPOOL is not (and will never be) [patented](https://en.wikipedia.org/wiki/Patent). It may be used free of charge for any purpose."[^o5]

### Version changes {#Version_changes}

The original Whirlpool will be called *Whirlpool-0*, the first revision of Whirlpool will be called *Whirlpool-T* and the latest version will be called *Whirlpool* in the following test vectors.

- In the first revision in 2001, the [S-box](wikipedia://en/240991) was changed from a randomly generated one with good cryptographic properties to one which has better cryptographic properties and is easier to implement in hardware.
- In the second revision (2003), a flaw in the [diffusion matrix](wikipedia://en/8288796) was found that lowered the estimated security of the algorithm below its potential.[^o8] Changing the 8x8 rotating matrix constants from (1, 1, 3, 1, 5, 8, 9, 5) to (1, 1, 4, 1, 8, 5, 2, 9) solved this issue.

## Internal structure {#Internal_structure}

The Whirlpool hash function is a [Merkle–Damgård construction](wikipedia://en/4076217) based on an [AES](wikipedia://en/1260)-like [block cipher](wikipedia://en/4594) W in [Miyaguchi–Preneel](wikipedia://en/3851622#Miyaguchi–Preneel) mode.[^o5]

The [block cipher](wikipedia://en/4594) $W$ consists of an 8×8 state matrix $S$ of bytes, for a total of 512 bits.

The encryption process consists of updating the state with four round functions over 10 rounds. The four round functions are SubBytes (SB or $\gamma$), ShiftColumns (SC or $\pi$), MixRows (MR or $\theta$) and AddRoundKey (AK or $\sigma[k]$). During each round the new state is computed as $S := \left( AK \circ MR \circ SC \circ SB \right)(S)$.

### SubBytes {#SubBytes}

The **SubBytes** operation applies a non-linear permutation (the S-box) to each byte of the state independently. The 8-bit S-box is composed of 3 smaller 4-bit S-boxes.

### ShiftColumns {#ShiftColumns}

The **ShiftColumns** operation cyclically shifts each byte in each column of the state. Column *j* has its bytes shifted downwards by *j* positions.

### MixBytesInRows {#MixBytesInRows}

The **MixBytesInRows** operation is a right-multiplication of each row by an 8×8 [matrix](wikipedia://en/20556859) over $GF({2^8})$. The matrix is chosen such that the [branch number](wikipedia://en/73558859) (an important property when looking at resistance to [differential cryptanalysis](wikipedia://en/8536)) is 9, which is maximal.

### AddRoundKey {#AddRoundKey}

The **AddRoundKey** operation uses bitwise [xor](wikipedia://en/105979) to add a key calculated by the key schedule to the current state. The key schedule is identical to the encryption itself, except the AddRoundKey function is replaced by an **AddRoundConstant** function that adds a predetermined constant in each round.

## Complete process of the Whirlpool algorithm {#Complete_process_of_the_Whirlpool_algorithm}

Here is the detailed explanation of the Whirlpool [algorithm](wikipedia://en/775) as described in the official release paper[^o2].

First, let's define the [notation](wikipedia://en/277184) used:

- Every number used is an 8-bit (1 [byte](https://en.wikipedia.org/wiki/Byte)) integer.
- $\{0, 1\}^n$ is a *n*-bit [binary string](https://en.wikipedia.org/wiki/Bit_array).
- $\mathcal{M}_{n \times m}$ is an *n*-by-*m* [matrix](wikipedia://en/20556859) of [bytes](https://en.wikipedia.org/wiki/Byte).
- $f: A \to B$ is a function that [maps](wikipedia://en/516931) elements from [set](wikipedia://en/26691) A to [set](wikipedia://en/26691) B.
- $a \oplus b$ is the bitwise [XOR](wikipedia://en/105979) of $a$ and $b$. If $a$ and $b$ are [matrices](wikipedia://en/20556859), the [XOR](wikipedia://en/105979) is applied element-wise ($a \oplus b = c \ \Leftrightarrow \ c_{i,j} = a_{i,j} \oplus b_{i,j}$).
- $f \circ g$ is the composition function of $f$ and $g$ such that $\left(f \circ g\right)\left(x\right) = g\left(f\left(x\right)\right)$;
- ${\underset{k=m}\overset{n}{\bigcirc}} \alpha_k, \ \forall \left(m; n; k\right) \in \mathbb{Z}^3, \ m \leq k \leq n$ is the ascending repetition of $\alpha_m \circ \alpha_{m + 1} \circ \ldots \circ \alpha_{n - 1} \circ \alpha_n$;
- ${\underset{m}\overset{k=n}{\bigcirc}} \alpha_k, \ \forall \left(m; n; k\right) \in \mathbb{Z}^3, \ m \leq k \leq n$ is the descending repetition of $\alpha_n \circ \alpha_{n - 1} \circ \ldots \circ \alpha_{m + 1} \circ \alpha_m$.

### Whirlpool algorithm {#Whirlpool_algorithm}

The message $M$ that is to be hashed is first [padded](wikipedia://en/592505) to ensure its length is a multiple of the block size (512 bits). This is done using the standard [padding](wikipedia://en/592505) scheme defined in the [ISO/IEC 10118-1](https://cdn.standards.iteh.ai/samples/64213/4902e1c6ea75432bbd41eb2c17b76e59/ISO-IEC-10118-1-2016.pdf) standard (the same used for [md5](wikipedia://en/18826), [sha-2](wikipedia://en/1638777), and others):

1. Append a '1' bit;
1. Append as many '0' bits as needed for the length to reach a multiple of 256 ($512-256$);
1. Append the original length of the message in bits using 256-bit [big-endian](https://en.wikipedia.org/wiki/Endianness) format.

Then, the padded message is divided into $t$ 512-bit blocks $m_i$, $1 \leq i \leq t$.

Whirlpool iterates the [Miyaguchi-Preneel](wikipedia://en/3851622) hashing scheme over these blocks <sup>\[sections 3.11 and 3.12\]</sup>[^o2]:

$$\begin{aligned} & \begin{aligned} \eta_i & = \mu\left(m_i\right), \\ H_0 & = \mu\left(IV\right), \\ H_i & = W\left[H_{i-1}\right]\left(\eta_i\right) \oplus H_{i-1} \oplus \eta_i, \ 1 \leq i \leq t \\ \end{aligned} \\ & \text{Whirlpool}\left(M\right) \equiv \mu^{-1}\left(H_t\right) \end{aligned}$$

Where:

- $\mu: \{0, 1\}^{512} \to \mathcal{M}_{8 \times 8}$ is the [string](https://en.wikipedia.org/wiki/Bit_array) to [matrix](wikipedia://en/20556859) conversion function;
- $\mu^{-1}: \mathcal{M}_{8 \times 8} \to \{0, 1\}^{512}$ is the [matrix](wikipedia://en/20556859) to [string](https://en.wikipedia.org/wiki/Bit_array) conversion function;
- $IV$ is the *initialization vector*, a [string](https://en.wikipedia.org/wiki/Bit_array) of 512 0-bits;
- $W$ is the Whirlpool cipher function.

:::

### Cipher W {#Cipher_W}

The internal block cipher function $W\left[\mathcal{M}_{8 \times 8}\right]: \mathcal{M}_{8 \times 8} \to \mathcal{M}_{8 \times 8}$ <sup>\[section 3.9\]</sup>[^o2] operates on and returns an 8x8 [matrix](wikipedia://en/20556859):

$$\begin{aligned} W\left[K\right] = \left( {\underset{1}\overset{r=R}{\bigcirc}} \rho\left[K_r\right] \right) \circ \sigma\left[K_0\right] \end{aligned}$$

Where:

- $R$ is the number of rounds (the standard Whirlpool uses $R = 10$);
- $K_n$ is the *nth* key of the $K$ key schedule;
- $\rho$ is the round function.

The key schedule expands the key $K \in \mathcal{M}_{8 \times 8}$ into a [sequence](wikipedia://en/27838) of keys $K_r \in \mathcal{M}_{8 \times 8}, \ 0 \leq r \leq R$ <sup>\[section 3.8\]</sup>[^o2]:

$$\begin{aligned} K_0 & = K, \\ K_r & = \rho\left[c^r\right]\left(K_{r-1}\right), \ 1 \leq r \leq R \\ \end{aligned}$$

Where:

- $c^r \in \mathcal{M}_{8 \times 8}$ is the *rth* round constant [matrix](wikipedia://en/20556859).

The round constant for the *rth* round, $r > 0$, is a [matrix](wikipedia://en/20556859) $c^r \in \mathcal{M}_{8 \times 8}$, defined as:

$$\begin{aligned} c^r_{0, j} & = S\left[8\left(r - 1\right) + j\right], & 0 \leq j < 8 \\ c^r_{i, j} & = 0, & 1 \leq i < 8, 0 \leq j < 8 \\ \end{aligned}$$

Where:

- $S \in \mathcal{M}_{16 \times 16}$ is the S-box.

### Round function ρ {#Round_function_ρ}

The round function $\rho\left[\mathcal{M}_{8 \times 8}\right]: \mathcal{M}_{8 \times 8} \to \mathcal{M}_{8 \times 8}$ <sup>\[section 3.7\]</sup>[^o2] is defined as:

$$\begin{aligned} \rho\left[k\right] & = \sigma\left[k\right] \circ \theta \circ \pi \circ \gamma \\ & _{\left( = \ AK \ \circ \ MR \ \circ \ SC \ \circ \ SB \right)} \\ \end{aligned}$$

Where:

- $\gamma$ is the non-linear layer;
- $\pi$ is the cyclical [permutation](wikipedia://en/44027);
- $\theta$ is the diffusion layer;
- $\sigma$ is the key addition.

#### Non-linear layer γ (SubBytes) {#Non-linear_layer_γ_(SubBytes)}

The function $\gamma: \mathcal{M}_{8 \times 8} \to \mathcal{M}_{8 \times 8}$ consists of the parallel application of a non-linear [substitution](wikipedia://en/5438948) $\psi: x_{\text{(Byte)}} \to S\left[x\right]_{\text{(Byte)}}$ to each [bytes](https://en.wikipedia.org/wiki/Byte) of the argument independently <sup>\[section 3.2\]</sup>[^o2]:

$$\begin{aligned} \gamma\left(a\right) = b \ \Leftrightarrow \ b_{i, j} = S\left[a_{i, j}\right], \ 0 \leq i < 8, \ 0 \leq j < 8, \\ \end{aligned}$$

#### Cyclical permutation π (ShiftColumns) {#Cyclical_permutation_π_(ShiftColumns)}

The [permutation](wikipedia://en/44027) $\pi : \mathcal{M}_{8 \times 8} \to \mathcal{M}_{8 \times 8}$ cyclically shifts each column of its argument independently, so that column $j$ is shifted downwards by $j$ positions <sup>\[section 3.3\]</sup>[^o2]:

$$\begin{aligned} \pi\left(a\right) = b \ \Leftrightarrow \ b_{i, j} = a_{\left( \left(i - j\right) \ \text{mod} \ 8 \right), \ j}, \ 0 \leq i < 8, \ 0 \leq j < 8 \\ \end{aligned}$$

#### Diffusion layer θ (MixBytesInRows) {#Diffusion_layer_θ_(MixBytesInRows)}

The linear diffusion layer $\theta: \mathcal{M}_{8 \times 8} \to \mathcal{M}_{8 \times 8}$ is a linear [mapping](wikipedia://en/516931) based on the [circular matrix](wikipedia://en/889936) $C = \text{cir}\left(01_{(16)}, 01_{(16)}, 04_{(16)}, 01_{(16)}, 08_{(16)}, 05_{(16)}, 02_{(16)}, 09_{(16)}\right)$ <sup>\[section 3.4\]</sup>[^o2]:

$$\begin{aligned} \theta\left(a\right) = a \cdot C, \ 0 \leq i < 8, \ 0 \leq j < 8 \\ \end{aligned}$$

A [circulant matrix](wikipedia://en/889936) $C\in\mathcal{M}_{n\times n}$ is defined as a matrix where each row is a cyclic shift of the previous row <sup>\[section 2.2\]</sup>[^o2]. Formally, a [circulant matrix](wikipedia://en/889936) can be represented as:

$$\begin{aligned} & \text{cir}(a_0, a_1, \ldots, a_{n-1}) = \begin{pmatrix} a_0 & a_1 & a_2 & \cdots & a_{n-1} \\ a_{n-1} & a_0 & a_1 & \cdots & a_{n-2} \\ a_{n-2} & a_{n-1} & a_0 & \cdots & a_{n-3} \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ a_1 & a_2 & a_3 & \cdots & a_0 \\ \end{pmatrix}, \ \forall a_n \in \mathbb{F}_{2^8}, \ n \in \mathbb{N} \\ & \text{or simply} \\ & \text{cir}(a_0, a_1, \ldots, a_{n-1}) = c \ \Leftrightarrow \ c_{i, j} = a_{\left(i - j\right) \ \text{mod} \ 8}, \ 0 \leq i < 8, \ 0 \leq j < 8, \ \forall a_n \in \mathbb{F}_{2^8}, \ n \in \mathbb{N} \\ \end{aligned}$$

For example, [circulant matrix](wikipedia://en/889936) $C = \text{cir}\left(01_{(16)}, 01_{(16)}, 04_{(16)}, 01_{(16)}, 08_{(16)}, 05_{(16)}, 02_{(16)}, 09_{(16)}\right)$ is the [matrix](wikipedia://en/20556859):

$$\begin{aligned} C = \begin{pmatrix} 01_{(16)} & 01_{(16)} & 04_{(16)} & 01_{(16)} & 08_{(16)} & 05_{(16)} & 02_{(16)} & 09_{(16)} \\ 09_{(16)} & 01_{(16)} & 01_{(16)} & 04_{(16)} & 01_{(16)} & 08_{(16)} & 05_{(16)} & 02_{(16)} \\ 02_{(16)} & 09_{(16)} & 01_{(16)} & 01_{(16)} & 04_{(16)} & 01_{(16)} & 08_{(16)} & 05_{(16)} \\ 05_{(16)} & 02_{(16)} & 09_{(16)} & 01_{(16)} & 01_{(16)} & 04_{(16)} & 01_{(16)} & 08_{(16)} \\ 08_{(16)} & 05_{(16)} & 02_{(16)} & 09_{(16)} & 01_{(16)} & 01_{(16)} & 04_{(16)} & 01_{(16)} \\ 01_{(16)} & 08_{(16)} & 05_{(16)} & 02_{(16)} & 09_{(16)} & 01_{(16)} & 01_{(16)} & 04_{(16)} \\ 04_{(16)} & 01_{(16)} & 08_{(16)} & 05_{(16)} & 02_{(16)} & 09_{(16)} & 01_{(16)} & 01_{(16)} \\ 01_{(16)} & 04_{(16)} & 01_{(16)} & 08_{(16)} & 05_{(16)} & 02_{(16)} & 09_{(16)} & 01_{(16)} \\ \end{pmatrix} \\ \end{aligned}$$

#### Key addition σ (AddRoundKey) {#Key_addition_σ_(AddRoundKey)}

The affine key addition $\sigma\left[\mathcal{M}_{8 \times 8}\right]: \mathcal{M}_{8 \times 8} \to \mathcal{M}_{8 \times 8}$ consists of the bitwise [XOR](wikipedia://en/105979) of a key [matrix](wikipedia://en/20556859) $k \in \mathcal{K}_{8 \times 8}$:

$$\begin{aligned} \sigma\left[k\right]\left(a\right) = a \oplus k \\ \end{aligned}$$

## Whirlpool hashes {#Whirlpool_hashes}

The Whirlpool algorithm has undergone two revisions since its original 2000 specification.

People incorporating Whirlpool will most likely use the most recent revision of Whirlpool; while there are no known security weaknesses in earlier versions of Whirlpool, the most recent revision has better hardware implementation efficiency characteristics, and is also likely to be more secure. As mentioned earlier, it is also the version adopted in the ISO/IEC 10118-3 [international standard](https://en.wikipedia.org/wiki/International_standard).

The 512-bit (64-byte) Whirlpool hashes (also termed *message digests*) are typically represented as 128-digit [hexadecimal](wikipedia://en/13263) numbers. ## Implementations {#Implementations}

The authors provide [reference implementations](https://en.wikipedia.org/wiki/Reference_implementation) of the Whirlpool algorithm, including a version written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) and a version written in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29).[^o5] These reference implementations have been released into the public domain.[^o5]

Research on the security analysis of the Whirlpool function however, has revealed that on average, the introduction of 8 random faults is sufficient to compromise the 512-bit Whirlpool hash message being processed and the secret key of HMAC-Whirlpool within the context of Cloud of Things (CoTs). This emphasizes the need for increased security measures in its implementation.[^o28]

## Adoption {#Adoption}

Two of the first widely used mainstream cryptographic programs that started using Whirlpool were [FreeOTFE](wikipedia://en/4954583), followed by [TrueCrypt](wikipedia://en/905962) in 2005.

[VeraCrypt](wikipedia://en/45345491) (a fork of [TrueCrypt](wikipedia://en/905962)) included Whirlpool (the final version) as one of its supported hash algorithms.[^o31]
