# Solution set

::: {#o1 .subject cue=lead name="Solution set"}

In [mathematics](wikipedia://en/18831), the **solution set** of a [system of equations](wikipedia://en/249617) or [inequality](wikipedia://en/89489) is the [set](wikipedia://en/26691) of all its solutions, that is the values that satisfy all equations and inequalities.[^o2] Also, the solution set or the **truth set** of a statement or a [predicate](https://en.wikipedia.org/wiki/Predicate_%28mathematical_logic%29) is the set of all values that satisfy it.

:::

If there is no solution, the solution set is the [empty set](wikipedia://en/9566).[^o3]

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The solution set of the single equation $x=0$ is the [singleton set](https://en.wikipedia.org/wiki/Singleton_set) $\{ 0 \}$.
- Since there do not exist numbers $x$ and $y$ making the two equations $$\begin{cases} x + 2y = 3,&\\ x + 2y = -3 \end{cases}$$ simultaneously true, the solution set of this system is the [empty set](wikipedia://en/9566) $\emptyset$.
- The solution set of a [constrained optimization problem](https://en.wikipedia.org/wiki/Constrained_optimization_problem) is its [feasible region](wikipedia://en/9157119).
- The truth set of the predicate $P(n): n \mathrm{\ is\ even}$ is $\{ 2,4,6,8,\ldots \}$.

:::

## Remarks {#Remarks}

In [algebraic geometry](wikipedia://en/1997), solution sets are called [algebraic sets](https://en.wikipedia.org/wiki/Algebraic_set) if there are no inequalities. Over the [reals](wikipedia://en/20646438), and with inequalities, there are called [semialgebraic sets](wikipedia://en/13329722).

## Other meanings {#Other_meanings}

More generally, the **solution set** to an arbitrary collection *E* of [relations](wikipedia://en/22517558) (*E<sub>i</sub>*) (*i* varying in some index set *I*) for a collection of unknowns ${(x_j)}_{j\in J}$, supposed to take values in respective spaces ${(X_j)}_{j\in J}$, is the set *S* of all solutions to the relations *E*, where a solution $x^{(k)}$ is a family of values ${\left( x^{(k)}_j \right)}_{j\in J}\in \prod_{j\in J} X_j$ such that substituting ${\left(x_j\right)}_{j\in J}$ by $x^{(k)}$ in the collection *E* makes all relations "true".

(Instead of relations depending on unknowns, one should speak more correctly of [predicates](https://en.wikipedia.org/wiki/Predicate_%28mathematics%29), the collection *E* is their [logical conjunction](wikipedia://en/18152), and the solution set is the [inverse image](https://en.wikipedia.org/wiki/Inverse_image) of the Boolean value *true* by the associated [Boolean-valued function](wikipedia://en/2757237).)

The above meaning is a special case of this one, if the set of polynomials *f<sub>i</sub>* if interpreted as the set of equations *f<sub>i</sub>*(*x*)=0.

::: {#o9 .example cue=heading name="Examples"}

### Examples {#Examples}

- The solution set for *E* = { *x*+*y* = 0 } with respect to $(x,y)\in \mathbb{R}^2$ is *S* = { (*a*,−*a*) : *a* ∈ **R** }.
- The solution set for *E* = { *x*+*y* = 0 } with respect to $x \in \mathbb{R}$ is *S* = { −*y* }. (Here, *y* is not "declared" as an unknown, and thus to be seen as a [parameter](wikipedia://en/25065) on which the equation, and therefore the solution set, depends.)
- The solution set for $E = \{ \sqrt x \le 4 \}$ with respect to $x\in\mathbb{R}$ is the interval *S* = \[0,16\] (since $\sqrt x$ is undefined for negative values of *x*).
- The solution set for $E = \{ e^{i x} = 1 \}$ with respect to $x\in\mathbb{C}$ is *S* = 2π**Z** (see [Euler's identity](wikipedia://en/46740)).

:::
