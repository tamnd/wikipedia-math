# 4000 (number)

::: {#o1 .subject cue=lead name="4000"}

**4000** (**four thousand**) is the [natural number](wikipedia://en/21474) following 3999 and preceding 4001. It is a [decagonal number](https://en.wikipedia.org/wiki/Decagonal_number).

:::
