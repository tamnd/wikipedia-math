# Global optimization

::: {#o1 .subject cue=lead name="Global optimization"}

**Global optimization** is a branch of [operations research](wikipedia://en/43476), [applied mathematics](wikipedia://en/24295969), and [numerical analysis](wikipedia://en/21506) that attempts to find the global [minimum or maximum](wikipedia://en/298420) of a function or a set of functions on a given set. It is usually described as a minimization problem because the maximization of the real-valued function $g(x)$ is equivalent to the minimization of the function $f(x):=(-1)\cdot g(x)$.

:::

Given a possibly nonlinear and non-convex continuous function $f:\Omega\subset\mathbb{R}^n\to\mathbb{R}$ with the global minimum $f^*$ and the set of all global minimizers $X^*$ in $\Omega$, the standard minimization problem can be given as

$$\min_{x\in\Omega}f(x),$$

that is, finding $f^*$ and a global minimizer in $X^*$; where $\Omega$ is a (not necessarily convex) compact set defined by inequalities $g_i(x)\geqslant0, i=1,\ldots,r$.

Global optimization is distinguished from local optimization by its focus on finding the minimum or maximum over the given set, as opposed to finding *local* minima or maxima. Finding an arbitrary local minimum is relatively straightforward by using classical *local optimization* methods. Finding the global minimum of a function is far more difficult: analytical methods are frequently not applicable, and the use of numerical solution strategies often leads to very hard challenges.

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

Typical examples of global optimization applications include:

- [Protein structure prediction](wikipedia://en/306769) (minimize the energy/free energy function)
- [Computational phylogenetics](wikipedia://en/3986130) (e.g., minimize the number of character transformations in the tree)
- [Traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem) and electrical circuit design (minimize the path length)
- [Chemical engineering](https://en.wikipedia.org/wiki/Chemical_engineering) (e.g., analyzing the [Gibbs energy](wikipedia://en/238181))
- Safety verification, [safety engineering](https://en.wikipedia.org/wiki/Safety_engineering) (e.g., of mechanical structures, buildings)
- [Worst-case analysis](https://en.wikipedia.org/wiki/Worst_case)
- Mathematical problems (e.g., the [Kepler conjecture](wikipedia://en/368311))
- Object packing (configuration design) problems
- The starting point of several [molecular dynamics](wikipedia://en/198608) simulations consists of an initial optimization of the energy of the system to be simulated.
- [Spin glasses](wikipedia://en/148555)
- Calibration of [radio propagation models](https://en.wikipedia.org/wiki/Radio_propagation_models) and of many other models in the sciences and engineering
- [Curve fitting](wikipedia://en/555425) like [non-linear least squares](wikipedia://en/15652764) analysis and other generalizations, used in fitting model parameters to experimental data in chemistry, physics, biology, economics, finance, medicine, astronomy, engineering.
- [IMRT](https://en.wikipedia.org/wiki/Radiation_therapy#Intensity-modulated_radiation_therapy_%28IMRT%29) radiation therapy planning

:::

## Deterministic methods {#Deterministic_methods}

The most successful general exact strategies are:

### Inner and outer approximation {#Inner_and_outer_approximation}

In both of these strategies, the set over which a function is to be optimized is approximated by polyhedra. In inner approximation, the polyhedra are contained in the set, while in outer approximation, the polyhedra contain the set.

### Cutting-plane methods {#Cutting-plane_methods}

The **cutting-plane method** is an umbrella term for optimization methods which iteratively refine a [feasible set](https://en.wikipedia.org/wiki/Feasible_set) or objective function by means of linear inequalities, termed *cuts*. Such procedures are popularly used to find [integer](wikipedia://en/14563) solutions to [mixed integer linear programming](https://en.wikipedia.org/wiki/Mixed_integer_linear_programming) (MILP) problems, as well as to solve general, not necessarily differentiable [convex optimization](wikipedia://en/1674411) problems. The use of cutting planes to solve MILP was introduced by [Ralph E. Gomory](https://en.wikipedia.org/wiki/Ralph_E._Gomory) and [Václav Chvátal](https://en.wikipedia.org/wiki/Václav_Chvátal).

### Branch and bound methods {#Branch_and_bound_methods}

**Branch and bound** (**BB** or **B&B**) is an [algorithm](wikipedia://en/775) design paradigm for [discrete](wikipedia://en/420567) and [combinatorial optimization](wikipedia://en/420555) problems. A branch-and-bound algorithm consists of a systematic enumeration of candidate solutions by means of [state space search](https://en.wikipedia.org/wiki/State_space_search): the set of candidate solutions is thought of as forming a [rooted tree](wikipedia://en/48560) with the full set at the root. The algorithm explores *branches* of this tree, which represent subsets of the solution set. Before enumerating the candidate solutions of a branch, the branch is checked against upper and lower estimated *bounds* on the optimal solution, and is discarded if it cannot produce a better solution than the best one found so far by the algorithm.

### Interval methods {#Interval_methods}

**Interval arithmetic**, **interval mathematics**, **interval analysis**, or **interval computation**, is a method developed by mathematicians since the 1950s and 1960s as an approach to putting bounds on [rounding errors](https://en.wikipedia.org/wiki/Rounding_error) and [measurement errors](https://en.wikipedia.org/wiki/Measurement_error) in [mathematical computation](wikipedia://en/21506) and thus developing [numerical methods](https://en.wikipedia.org/wiki/Numerical_methods) that yield reliable results. Interval arithmetic helps find reliable and guaranteed solutions to equations and optimization problems.

### Methods based on real algebraic geometry {#Methods_based_on_real_algebraic_geometry}

**Real algebra** is the part of algebra which is relevant to real algebraic (and semialgebraic) geometry. It is mostly concerned with the study of [ordered fields](wikipedia://en/22430) and [ordered rings](wikipedia://en/525697) (in particular [real closed fields](wikipedia://en/1066093)) and their applications to the study of [positive polynomials](wikipedia://en/28416554) and [sums-of-squares of polynomials](wikipedia://en/17001761). It can be used in [convex optimization](wikipedia://en/1674411).

## Stochastic methods {#Stochastic_methods}

Several exact or inexact Monte-Carlo-based algorithms exist:

### Direct Monte-Carlo sampling {#Direct_Monte-Carlo_sampling}

In this method, random simulations are used to find an approximate solution.

Example: The [traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem) is what is called a conventional optimization problem. That is, all the facts (distances between each destination point) needed to determine the optimal path to follow are known with certainty and the goal is to run through the possible travel choices to come up with the one with the lowest total distance. However, let's assume that instead of wanting to minimize the total distance traveled to visit each desired destination, we wanted to minimize the total time needed to reach each destination. This goes beyond conventional optimization since travel time is inherently uncertain (traffic jams, time of day, etc.). As a result, to determine our optimal path we would want to use simulation - optimization to first understand the range of potential times it could take to go from one point to another (represented by a probability distribution in this case rather than a specific distance) and then optimize our travel decisions to identify the best path to follow taking that uncertainty into account.

### Stochastic tunneling {#Stochastic_tunneling}

**Stochastic tunneling** (STUN) is an approach to global optimization based on the [Monte Carlo method](wikipedia://en/56098)-[sampling](https://en.wikipedia.org/wiki/Sampling_%28signal_processing%29) of the function to be objectively minimized in which the function is nonlinearly transformed to allow for easier tunneling among regions containing function minima. Easier tunneling allows for faster exploration of sample space and faster convergence to a good solution.

### Parallel tempering {#Parallel_tempering}

**Parallel tempering**, also known as **replica exchange MCMC sampling**, is a [simulation](https://en.wikipedia.org/wiki/Simulation) method aimed at improving the dynamic properties of [Monte Carlo method](wikipedia://en/56098) simulations of physical systems, and of [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC) sampling methods more generally. The replica exchange method was originally devised by Swendsen,[^o14] then extended by Geyer[^o15] and later developed, among others, by [Giorgio Parisi](https://en.wikipedia.org/wiki/Giorgio_Parisi).,[^o16][^o17] Sugita and Okamoto formulated a [molecular dynamics](wikipedia://en/198608) version of parallel tempering:[^o18] this is usually known as replica-exchange molecular dynamics or REMD.

Essentially, one runs *N* copies of the system, randomly initialized, at different temperatures. Then, based on the Metropolis criterion one exchanges configurations at different temperatures. The idea of this method is to make configurations at high temperatures available to the simulations at low temperatures and vice versa. This results in a very robust ensemble which is able to sample both low and high energy configurations. In this way, thermodynamical properties such as the specific heat, which is in general not well computed in the canonical ensemble, can be computed with great precision.

## Heuristics and metaheuristics {#Heuristics_and_metaheuristics}

Other approaches include heuristic strategies to search the search space in a more or less intelligent way, including:

- [Ant colony optimization](https://en.wikipedia.org/wiki/Ant_colony_optimization_algorithms) (ACO)
- [Simulated annealing](wikipedia://en/172244), a generic probabilistic metaheuristic
- [Tabu search](https://en.wikipedia.org/wiki/Tabu_search), an extension of [local search](https://en.wikipedia.org/wiki/Local_search_%28optimization%29) capable of escaping from local minima
- [Evolutionary algorithms](https://en.wikipedia.org/wiki/Evolutionary_algorithm) (e.g., [genetic algorithms](https://en.wikipedia.org/wiki/Genetic_algorithms) and [evolution strategies](https://en.wikipedia.org/wiki/Evolution_strategies))
- [Differential evolution](https://en.wikipedia.org/wiki/Differential_evolution), a method that [optimizes](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) a problem by [iteratively](wikipedia://en/15237) trying to improve a [candidate solution](https://en.wikipedia.org/wiki/Candidate_solution) with regard to a given measure of quality
- [Swarm-based optimization algorithms](https://en.wikipedia.org/wiki/Swarm_intelligence) (e.g., [particle swarm optimization](https://en.wikipedia.org/wiki/Particle_swarm_optimization), [social cognitive optimization](wikipedia://en/44955090), [multi-swarm optimization](https://en.wikipedia.org/wiki/Multi-swarm_optimization) and [ant colony optimization](https://en.wikipedia.org/wiki/Ant_colony_optimization))
- [Memetic algorithms](https://en.wikipedia.org/wiki/Memetic_algorithm), combining global and local search strategies
- Reactive search optimization (i.e. integration of sub-symbolic machine learning techniques into search heuristics)
- [Graduated optimization](wikipedia://en/22359135), a technique that attempts to solve a difficult optimization problem by initially solving a greatly simplified problem, and progressively transforming that problem (while optimizing) until it is equivalent to the difficult optimization problem.[^o20][^o21][^o22]

## Response surface methodology-based approaches {#Response_surface_methodology-based_approaches}

- [IOSO](https://en.wikipedia.org/wiki/IOSO) Indirect Optimization based on Self-Organization
- [Bayesian optimization](wikipedia://en/40973765), a sequential design strategy for global [optimization](https://en.wikipedia.org/wiki/Optimization) of black-box functions using [Bayesian statistics](wikipedia://en/404412)[^o24]
