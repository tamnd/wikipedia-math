# Torus-based cryptography

::: {#o1 .subject cue=lead name="Torus-based cryptography"}

**Torus-based cryptography** involves using [algebraic tori](wikipedia://en/504697) to construct a [group](wikipedia://en/19447) for use in [ciphers](wikipedia://en/5244) based on the [discrete logarithm problem](https://en.wikipedia.org/wiki/Discrete_logarithm_problem). This idea was first introduced by [Alice Silverberg](wikipedia://en/44807694) and [Karl Rubin](https://en.wikipedia.org/wiki/Karl_Rubin) in 2003 in the form of a [public key algorithm](https://en.wikipedia.org/wiki/Public_key_algorithm) by the name of [CEILIDH](wikipedia://en/14050287). It improves on conventional cryptosystems by representing some elements of large finite fields compactly and therefore transmitting fewer bits.[^o2][^o3]

:::
