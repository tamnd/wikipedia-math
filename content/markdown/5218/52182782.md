# TWANG

::: {#o1 .subject cue=lead name="TWANG"}

**TWANG**, the Toolkit for Weighting and Analysis of Nonequivalent Groups, developed by the statistics group of the [RAND Corporation](https://en.wikipedia.org/wiki/RAND_Corporation), contains a set of functions to support [Rubin causal modeling](wikipedia://en/5700418) of [observational data](https://en.wikipedia.org/wiki/Observational_data) through the estimation and evaluation of [propensity score](https://en.wikipedia.org/wiki/Propensity_score) weights by applying [gradient boosting](wikipedia://en/26649339). It has been applied in several studies.[^o2][^o3][^o4][^o5][^o6]

:::
