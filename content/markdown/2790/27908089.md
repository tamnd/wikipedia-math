# Infinite-dimensional vector function

::: {#o1 .subject cue=lead name="Infinite-dimensional vector function"}

An **infinite-dimensional vector function** is a [function](wikipedia://en/185427) whose values lie in an [infinite-dimensional](https://en.wikipedia.org/wiki/Infinite-dimensional) [topological vector space](wikipedia://en/45752), such as a [Hilbert space](wikipedia://en/20598932) or a [Banach space](wikipedia://en/3989).

:::

Such functions are applied in most sciences including [physics](wikipedia://en/22939).

::: {#o3 .example cue=heading name="Example"}

## Example {#Example}

Set $f_k(t) = t/k^2$ for every positive [integer](wikipedia://en/14563) $k$ and every [real number](wikipedia://en/20646438) $t.$ Then the function $f$ defined by the formula

$$f(t) = (f_1(t), f_2(t), f_3(t), \ldots)\, ,$$

takes values that lie in the infinite-dimensional [vector space](wikipedia://en/32370) $X$ (or $\mathbb{R}^{\mathbb{N}}$) of real-valued [sequences](wikipedia://en/27838). For example,

$$f(2) = \left(2, \frac{2}{4}, \frac{2}{9}, \frac{2}{16}, \frac{2}{25}, \ldots\right).$$

As a number of different [topologies](wikipedia://en/30450) can be defined on the space $X,$ to talk about the [derivative](wikipedia://en/7921) of $f,$ it is first necessary to specify a topology on $X$ or the concept of a [limit](wikipedia://en/26551602) in $X.$

Moreover, for any set $A,$ there exist infinite-dimensional vector spaces having the (Hamel) [dimension](wikipedia://en/38267) of the [cardinality](wikipedia://en/6174) of $A$ (for example, the space of functions $A \to K$ with finitely-many nonzero elements, where $K$ is the desired [field](wikipedia://en/10603) of scalars). Furthermore, the argument $t$ could lie in any set instead of the set of real numbers.

:::

## Integral and derivative {#Integral_and_derivative}

Most theorems on [integration](wikipedia://en/15532) and [differentiation](wikipedia://en/7921) of scalar functions can be generalized to vector-valued functions, often using essentially the same [proofs](wikipedia://en/82285). Perhaps the most important exception is that [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) functions need not equal the integrals of their (a.e.) derivatives (unless, for example, $X$ is a Hilbert space); see [Radon–Nikodym theorem](wikipedia://en/338746)

A [curve](https://en.wikipedia.org/wiki/Topological_curve) is a [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) map of the [unit interval](wikipedia://en/49324) (or more generally, of a non−degenerate [closed](https://en.wikipedia.org/wiki/Closed_interval) [interval](wikipedia://en/49172) of real numbers) into a [topological space](wikipedia://en/30450). An *[arc](https://en.wikipedia.org/wiki/Arc_%28topology%29)* is a curve that is also a [topological embedding](https://en.wikipedia.org/wiki/Topological_embedding). A curve valued in a [Hausdorff space](wikipedia://en/13637) is an arc [if and only if](wikipedia://en/14922) it is [injective](wikipedia://en/45196).

### Derivatives {#Derivatives}

If $f : [0,1] \to X,$ where $X$ is a Banach space or another [topological vector space](wikipedia://en/45752) then the [derivative](wikipedia://en/7921) of $f$ can be defined in the usual way:

$$f'(t) = \lim_{h\to 0}\frac{f(t+h)-f(t)}{h}.$$

#### Functions with values in a Hilbert space {#Functions_with_values_in_a_Hilbert_space}

If $f$ is a function of real numbers with values in a Hilbert space $X,$ then the derivative of $f$ at a point $t$ can be defined as in the finite-dimensional case:

$$f'(t)=\lim_{h\to 0} \frac{f(t+h)-f(t)}{h}.$$

Most results of the finite-dimensional case also hold in the infinite-dimensional case too, with some modifications. Differentiation can also be defined to functions of several variables (for example, $t \in R^n$ or even $t\in Y,$ where $Y$ is an infinite-dimensional vector space).

If $X$ is a Hilbert space then any derivative (and any other limit) can be computed componentwise: if

$$f = (f_1,f_2,f_3,\ldots)$$

(that is, $f = f_1 e_1+f_2 e_2+f_3 e_3+\cdots,$ where $e_1,e_2,e_3,\ldots$ is an [orthonormal basis](wikipedia://en/195063) of the space $X$), and $f'(t)$ exists, then

$$f'(t) = (f_1'(t),f_2'(t),f_3'(t),\ldots).$$

However, the existence of a componentwise derivative does not guarantee the existence of a derivative, as componentwise convergence in a Hilbert space does not guarantee convergence with respect to the actual topology of the Hilbert space.

Most of the above hold for other [topological vector spaces](wikipedia://en/45752) $X$ too. However, not as many classical results hold in the [Banach space](wikipedia://en/3989) setting, for example, an [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) function with values in a [suitable Banach space](https://en.wikipedia.org/wiki/Radon–Nikodym_property) need not have a derivative anywhere. Moreover, in most Banach spaces setting there are no orthonormal bases.

### Crinkled arcs {#Crinkled_arcs}

If $[a, b]$ is an interval contained in the [domain](wikipedia://en/50263) of a curve $f$ that is valued in a [topological vector space](wikipedia://en/45752) then the vector $f(b) - f(a)$ is called the *chord of $f$ determined by $[a, b]$*.[^n1] If $[c, d]$ is another interval in its domain then the two chords are said to be *non−overlapping chords* if $[a, b]$ and $[c, d]$ have at most one end−point in common.[^n1] Intuitively, two non−overlapping chords of a curve valued in an [inner product space](wikipedia://en/14856) are [orthogonal vectors](https://en.wikipedia.org/wiki/Orthogonal_vectors) if the curve makes a [right angle](wikipedia://en/76956) turn somewhere along its path between its starting point and its ending point. If every pair of non−overlapping chords are orthogonal then such a right turn happens at every point of the curve; such a curve can not be [differentiable](https://en.wikipedia.org/wiki/Differentiable) at any point.[^n1] A *crinkled arc* is an injective continuous curve with the property that any two non−overlapping chords are orthogonal vectors. An example of a crinkled arc in the [Hilbert](wikipedia://en/20598932) [$L^2$ space](wikipedia://en/45194) $L^2(0, 1)$ is:[^n2]

$$\begin{alignedat}{4} f :\;&& [0, 1] &&\;\to \;& L^2(0, 1) \\[0.3ex] && t &&\;\mapsto\;& \mathbb{1}_{[0,t]} \\ \end{alignedat}$$

where $\mathbb{1}_{[0,\,t]} : (0, 1) \to \{0, 1\}$ is the [indicator function](wikipedia://en/240790) defined by

$$x \;\mapsto\; \begin{cases}1 & \text{ if } x \in [0, t]\\ 0 & \text{ otherwise } \end{cases}$$

A crinkled arc can be found in every infinite−dimensional Hilbert space because any such space contains a [closed](wikipedia://en/47279) [vector subspace](https://en.wikipedia.org/wiki/Vector_subspace) that is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to $L^2(0, 1).$[^n2] A crinkled arc $f : [0, 1] \to X$ is said to be *normalized* if $f(0) = 0,$ $\|f(1)\| = 1,$ and the [span](https://en.wikipedia.org/wiki/Span_%28linear_algebra%29) of its [image](wikipedia://en/579311) $f([0, 1])$ is a [dense subset](wikipedia://en/23523594) of $X.$[^n2]

::: {#o15 .statement kind=statement/proposition cue=math-theorem name="Proposition"}

**Proposition[^n2].**

Given any two normalized crinkled arcs in a Hilbert space, each is unitarily equivalent to a reparameterization of the other.

:::

If $h : [0, 1] \to [0, 1]$ is an [increasing](https://en.wikipedia.org/wiki/Increasing_function) [homeomorphism](wikipedia://en/13660) then $f \circ h$ is called a *reparameterization* of the curve $f : [0, 1] \to X.$[^n1] Two curves $f$ and $g$ in an [inner product space](wikipedia://en/14856) $X$ are *unitarily equivalent* if there exists a [unitary operator](wikipedia://en/225999) $L : X \to X$ (which is an [isometric](wikipedia://en/254777) [linear](wikipedia://en/18102) [bijection](wikipedia://en/3942)) such that $g = L \circ f$ (or equivalently, $f = L^{-1} \circ g$).

### Measurability {#Measurability}

The [measurability](wikipedia://en/44055) of $f$ can be defined by a number of ways, most important of which are [Bochner measurability](https://en.wikipedia.org/wiki/Bochner_measurability) and [weak measurability](https://en.wikipedia.org/wiki/Weak_measurability).

### Integrals {#Integrals}

The most important integrals of $f$ are called [Bochner integral](wikipedia://en/3675277) (when $X$ is a Banach space) and [Pettis integral](wikipedia://en/20983125) (when $X$ is a topological vector space). Both these integrals commute with [linear functionals](https://en.wikipedia.org/wiki/Linear_functional). Also $L^p$ spaces have been [defined](wikipedia://en/6751583) for such functions.
