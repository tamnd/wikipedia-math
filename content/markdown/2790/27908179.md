# Strongly measurable function

::: {#o1 .subject cue=lead name="Strongly measurable function"}

**Strong measurability** has a number of different meanings, some of which are explained below.

:::

## Values in Banach spaces {#Values_in_Banach_spaces}

For a function *f* with values in a [Banach space](wikipedia://en/3989) (or [Fréchet space](wikipedia://en/233801)), *strong measurability* usually means [Bochner measurability](https://en.wikipedia.org/wiki/Bochner_measurability).

However, if the values of *f* lie in the space $\mathcal{L}(X,Y)$ of [continuous linear operators](wikipedia://en/1802169) from *X* to *Y*, then often *strong measurability* means that the operator *f(x)* is Bochner measurable for each fixed *x* in the domain of *f*, whereas the Bochner measurability of *f* is called *uniform measurability* (cf. "[uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous)" vs. "[strongly continuous](https://en.wikipedia.org/wiki/Strongly_continuous)").

## Bounded operators {#Bounded_operators}

A family of bounded linear operators combined with the [direct integral](wikipedia://en/1256105) is strongly measurable, when each of the individual operators is strongly measurable.

## Semigroups {#Semigroups}

A [semigroup](wikipedia://en/27799) of linear operators can be strongly measurable yet not strongly continuous.[^o5] It is uniformly measurable if and only if it is uniformly continuous, i.e., if and only if its generator is bounded.
