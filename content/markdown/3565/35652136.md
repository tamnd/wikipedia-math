# Snell envelope

::: {#o1 .subject cue=lead name="Snell envelope"}

The **Snell envelope**, used in [stochastics](https://en.wikipedia.org/wiki/Stochastics) and [mathematical finance](wikipedia://en/33589680), is the smallest [supermartingale](wikipedia://en/274536) dominating a [stochastic process](wikipedia://en/47895). The Snell envelope is named after [James Laurie Snell](https://en.wikipedia.org/wiki/James_Laurie_Snell).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a [filtered probability space](https://en.wikipedia.org/wiki/Filtered_probability_space) $(\Omega,\mathcal{F},(\mathcal{F}_t)_{t \in [0,T]},\mathbb{P})$ and an [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) [probability measure](wikipedia://en/45437) $\mathbb{Q} \ll \mathbb{P}$ then an [adapted process](wikipedia://en/6583420) $U = (U_t)_{t \in [0,T]}$ is the Snell envelope with respect to $\mathbb{Q}$ of the process $X = (X_t)_{t \in [0,T]}$ if

1. $U$ is a $\mathbb{Q}$-supermartingale
1. $U$ dominates $X$, i.e. $U_t \geq X_t$ $\mathbb{Q}$-[almost surely](wikipedia://en/351908) for all times $t \in [0,T]$
1. If $V = (V_t)_{t \in [0,T]}$ is a $\mathbb{Q}$-supermartingale which dominates $X$, then $V$ dominates $U$.[^o4]

:::

::: {#o6 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

Given a (discrete) [filtered probability space](https://en.wikipedia.org/wiki/Filtered_probability_space) $(\Omega,\mathcal{F},(\mathcal{F}_n)_{n = 0}^N,\mathbb{P})$ and an [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous#Absolute_continuity_of_measures) [probability measure](wikipedia://en/45437) $\mathbb{Q} \ll \mathbb{P}$ then the Snell envelope $(U_n)_{n = 0}^N$ with respect to $\mathbb{Q}$ of the process $(X_n)_{n = 0}^N$ is given by the recursive scheme

$$U_N := X_N,$$

$U_n := X_n \lor \mathbb{E}^{\mathbb{Q}}[U_{n+1} \mid \mathcal{F}_n]$ for $n = N-1,...,0$

where $\lor$ is the [join](wikipedia://en/3956618) (in this case equal to the maximum of the two random variables).[^o4]

:::

::: {#o8 .application cue=heading name="Application"}

## Application {#Application}

- If $X$ is a discounted [American option](https://en.wikipedia.org/wiki/American_option) payoff with Snell envelope $U$ then $U_t$ is the minimal capital requirement to hedge $X$ from time $t$ to the expiration date.[^o4]

:::
