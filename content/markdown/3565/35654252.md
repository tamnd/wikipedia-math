# Hesse's theorem

::: {#o1 .subject cue=lead name="Hesse's theorem"}

In geometry, **Hesse's theorem**, named for [Otto Hesse](wikipedia://en/740995), states that if two pairs of opposite vertices of a [quadrilateral](wikipedia://en/25278) are conjugate with respect to some conic, then so is the third pair. A quadrilateral with this property is called a **Hesse quadrilateral**.

:::
