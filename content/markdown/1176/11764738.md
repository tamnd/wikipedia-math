# Bonnet's theorem

::: {#o1 .subject cue=lead name="Bonnet's theorem"}

In [classical mechanics](wikipedia://en/19555586), **Bonnet's theorem** states that if *n* different [force](https://en.wikipedia.org/wiki/Force) fields each produce the same geometric orbit (say, an ellipse of given dimensions) albeit with different [speeds](https://en.wikipedia.org/wiki/Speed) *v*<sub>1</sub>, *v*<sub>2</sub>,...,*v*<sub>*n*</sub> at a given point *P*, then the same orbit will be followed if the speed at point *P* equals

:::

$$v_{\mathrm{combined}} = \sqrt{v_{1}^{2} + v_{2}^{2} + \cdots + v_{n}^{2}}$$

## History {#History}

This theorem was first derived by [Adrien-Marie Legendre](wikipedia://en/49695) in 1817,[^o3] but it is named after [Pierre Ossian Bonnet](wikipedia://en/703244).

## Derivation {#Derivation}

The shape of an [orbit](https://en.wikipedia.org/wiki/Orbit) is determined only by the [centripetal forces](https://en.wikipedia.org/wiki/Centripetal_force) at each point of the orbit, which are the forces acting perpendicular to the orbit. By contrast, forces *along* the orbit change only the speed, but not the direction, of the [velocity](wikipedia://en/20491903).

Let the instantaneous radius of curvature at a point *P* on the orbit be denoted as *R*. For the *k*<sup>th</sup> force field that produces that orbit, the force normal to the orbit *F*<sub>*k*</sub> must provide the [centripetal force](https://en.wikipedia.org/wiki/Centripetal_force)

$$F_{k} = \frac{m}{R} v_{k}^{2}$$

Adding all these forces together yields the equation

$$\sum_{k=1}^{n} F_{k} = \frac{m}{R} \sum_{k=1}^{n} v_{k}^{2}$$

Hence, the combined force-field produces the same orbit if the speed at a point *P* is set equal to

$$v_{\mathrm{combined}} = \sqrt{v_{1}^{2} + v_{2}^{2} + \cdots + v_{n}^{2}}$$
