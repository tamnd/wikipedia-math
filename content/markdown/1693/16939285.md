# TinkerPlots

::: {#o2 .subject cue=lead name="TinkerPlots"}

***TinkerPlots*** is [exploratory data analysis](wikipedia://en/416589) and modeling software designed for use by students in grades 4 through university.[^o3] It was designed by Clifford Konold and Craig Miller at the [University of Massachusetts Amherst](https://en.wikipedia.org/wiki/University_of_Massachusetts_Amherst) and is currently published by [Learn Troop](https://en.wikipedia.org/wiki/Learn_Troop).[^o4] It runs on [Windows XP](https://en.wikipedia.org/wiki/Windows_XP) or later and [Mac OS 10.4](https://en.wikipedia.org/wiki/Mac_OS_10.4) or later.[^o5] The program allows users to enter their own [data](https://en.wikipedia.org/wiki/Data), to import them from other applications or [the Web](https://en.wikipedia.org/wiki/The_Web), or to generate them using a sampling engine. The program also comes with 50 [multivariate](wikipedia://en/19384) data sets.

:::

Using TinkerPlots, students can make a large variety of [graphs](https://en.wikipedia.org/wiki/Graphics), including those specified for middle school in Common Core State Standards for Mathematics But rather than making these graphs directly using commands, students construct them by progressively organizing cases using basic operations including "stack," "order," and "separate." Responding to these operations, case icons animate into different screen positions. The interface was based on observations of people organizing "data cards" on a table to make graphs to answer specific questions [^o6]

Innovations of TinkerPlots include using a superimposed color gradient[^o7] to detect [covariation](https://en.wikipedia.org/wiki/Covariation) in two numeric attributes and a "hat plot,"[^o8] a reformulated and generalized version of the [box plot](wikipedia://en/160960).

The latest version is 3.0.37.[^o9] This version does not have substantively different features from versions 2.1, 2.2 or 2.3, but is a complete re-write in a code sense, and has a number of bug fixes and enhancements to remain compatible with the latest versions of Windows and MacOS.[^o10]
