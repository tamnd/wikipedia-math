# Pivot algorithm

::: {#o1 .subject cue=lead name="Pivot algorithm"}

*Image: PivotWiki.png.* Example of the pivot algorithm modifying the configuration of a short self-avoiding walk on a square lattice. The red monomer is chosen as the pivot point. If rotated clockwise about that point, two monomers would occupy the same site and the move is rejected. If it is rotated counterclockwise, the move is accepted.

The **pivot algorithm** is a form of [Monte Carlo algorithm](https://en.wikipedia.org/wiki/Monte_Carlo_algorithm) used to generate configurations of [self-avoiding walks](wikipedia://en/11186496), typically on a [lattice](wikipedia://en/469246).[^o3] The algorithm typically begins with a straight line consisting of some number N points on the lattice, and transforms it into a disorganized shape known as a walk, in which no two points on the walk occupy the same site on the lattice. In [two dimensions](https://en.wikipedia.org/wiki/Two_dimensions) it operates according to the following steps:

:::

1. Select a random point $p$ between 1 and $N$ about which to pivot. This splits the walk in two, one of length $p$ and one of length ($N$−$p$).
1. Randomly select which side of the point to pivot.
1. Randomly select a [transform](wikipedia://en/692458) such as [rotation](wikipedia://en/39789) by 90, 180, or 270 degrees or [reflection](wikipedia://en/295829) about the horizontal or vertical axis and apply it the points on the selected side of the pivot.
1. Check whether any two points occupy the same site on the lattice. If they do, reject the pivot and try again. If they do not, proceed with another pivot.

The configurations generated by the algorithm provide information about the [combinatorics](wikipedia://en/5170) of self-avoiding walks and are used to understand the physics of [polymers](https://en.wikipedia.org/wiki/Polymer), which can be approximated as self-avoiding walks. The algorithm was invented by Moti Lal in 1969.[^o2] It can be implemented efficiently, having a [computational complexity](wikipedia://en/6511) that allows walks of length *N* to be generated in a time proportional to the logarithm of *N*, known as [logarithmic time](wikipedia://en/405944#Logarithmic_time).[^o3]
