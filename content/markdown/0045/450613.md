# Snefru

::: {#o1 .subject cue=lead name="Snefru"}

**Snefru** is a [cryptographic hash function](wikipedia://en/439526) invented by [Ralph Merkle](wikipedia://en/25849) in 1990 while working at [Xerox PARC](https://en.wikipedia.org/wiki/Xerox_PARC).[^o3] The function supports 128-bit and 256-bit output. It was named after the [Egyptian](https://en.wikipedia.org/wiki/Ancient_Egypt) [Pharaoh](https://en.wikipedia.org/wiki/Pharaoh) [Sneferu](https://en.wikipedia.org/wiki/Sneferu), continuing the tradition of the [Khufu](wikipedia://en/634695#Khufu) and [Khafre](wikipedia://en/634695#Khafre) [block ciphers](wikipedia://en/4594).

:::

The original design of Snefru was shown to be insecure by [Eli Biham](wikipedia://en/348920) and [Adi Shamir](wikipedia://en/57314) who were able to use [differential cryptanalysis](wikipedia://en/8536) to find hash collisions. The design was then modified by increasing the number of iterations of the main pass of the algorithm from two to eight. Although differential cryptanalysis can break the revised version with less complexity than [brute force search](https://en.wikipedia.org/wiki/Brute_force_attack) (a certificational weakness), the attack requires $2^{88.5}$ operations and is thus not currently feasible in practice.[^o4]
