# Glossary of order theory

::: {#o1 .subject cue=lead name="Glossary of order theory"}

This is a glossary of some terms used in various branches of [mathematics](wikipedia://en/18831) that are related to the fields of [order](wikipedia://en/361924), [lattice](wikipedia://en/469304), and [domain theory](wikipedia://en/325077). Note that there is a structured [list of order topics](https://en.wikipedia.org/wiki/List_of_order_topics) available as well. Other helpful resources might be the following overview articles:

:::

- [completeness properties](wikipedia://en/549445) of partial orders
- [distributivity laws](wikipedia://en/616019) of order theory

In the following, partial orders will usually just be denoted by their carrier sets. As long as the intended meaning is clear from the context, $\,\leq\,$ will suffice to denote the corresponding relational symbol, even without prior introduction. Furthermore, \< will denote the [strict order](https://en.wikipedia.org/wiki/Strict_order) induced by $\,\leq.$

::: {#o3 .pointer-item cue=pointer name="Acyclic relation"}

## A {#A}

- **Acyclic**. A [binary relation](wikipedia://en/3931) is acyclic if it contains no "cycles": equivalently, its [transitive closure](wikipedia://en/292239) is [antisymmetric](wikipedia://en/1176).[^o21]
- **Adjoint**. See *Galois connection*.
- **[Alexandrov topology](wikipedia://en/542198)**. For a preordered set *P*, any upper set *O* is **Alexandrov-open**. Inversely, a topology is Alexandrov if any intersection of open sets is open.
- **[Algebraic poset](https://en.wikipedia.org/wiki/Algebraic_poset)**. A poset is algebraic if it has a base of compact elements.
- **[Antichain](wikipedia://en/348973)**. An antichain is a poset in which no two elements are comparable, i.e., there are no two distinct elements *x* and *y* such that *x* ≤ *y*. In other words, the order relation of an antichain is just the identity relation.
- **Approximates relation**. See *way-below relation*.
- **Antisymmetric relation**. A [homogeneous relation](wikipedia://en/12987179) *R* on a set *X* is **[antisymmetric](wikipedia://en/1176)**, if *x R y* and *y R x* implies *x = y*, for all elements *x*, *y* in *X*.
- **Antitone**. An [antitone](https://en.wikipedia.org/wiki/Antitone) function *f* between posets *P* and *Q* is a function for which, for all elements *x*, *y* of *P*, *x* ≤ *y* (in *P*) implies *f*(*y*) ≤ *f*(*x*) (in *Q*). Another name for this property is *order-reversing*. In [analysis](wikipedia://en/48396), in the presence of [total orders](wikipedia://en/30330), such functions are often called **monotonically decreasing**, but this is not a very convenient description when dealing with non-total orders. The dual notion is called *monotone* or *order-preserving*.
- **[Asymmetric relation](wikipedia://en/1229368)**. A [homogeneous relation](wikipedia://en/12987179) *R* on a set *X* is asymmetric, if *x R y* implies *not y R x*, for all elements *x*, *y* in *X*.
- **[Atom](wikipedia://en/998824)**. An atom in a poset *P* with least element 0, is an element that is minimal among all elements that are unequal to 0.
- **Atomic**. An atomic poset *P* with least element 0 is one in which, for every non-zero element *x* of *P*, there is an atom *a* of *P* with *a* ≤ *x*.

:::

## B {#B}

- **Base**. See *continuous poset*.
- **[Binary relation](wikipedia://en/3931)**. A binary relation over two sets $X \text{ and } Y$ is a subset of their [Cartesian product](wikipedia://en/24104095) $X \times Y.$
- **[Boolean algebra](wikipedia://en/3959)**. A Boolean algebra is a distributive lattice with least element 0 and greatest element 1, in which every element *x* has a complement ¬*x*, such that *x* ∧ ¬*x* = 0 and *x* ∨ ¬*x* = 1.
- **[Bounded poset](https://en.wikipedia.org/wiki/Bounded_poset)**. A [bounded](https://en.wikipedia.org/wiki/Bounded_poset) poset is one that has a least element and a greatest element.
- **[Bounded complete](https://en.wikipedia.org/wiki/Bounded_complete)**. A poset is [bounded complete](https://en.wikipedia.org/wiki/Bounded_complete) if every of its subsets with some upper bound also has a least such upper bound. The dual notion is not common.

## C {#C}

- **[Chain](wikipedia://en/30330#Chains)**. A chain is a totally ordered set or a totally ordered subset of a poset. See also total order.
- **[Chain complete](https://en.wikipedia.org/wiki/Chain_complete)**. A [partially ordered set](wikipedia://en/23572) in which every [chain](wikipedia://en/30330#Chains) has a [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound).
- **[Closure operator](wikipedia://en/483120)**. A closure operator on the poset *P* is a function *C* : *P* → *P* that is monotone, [idempotent](https://en.wikipedia.org/wiki/Idempotent), and satisfies *C*(*x*) ≥ *x* for all *x* in *P*.
- **[Compact](wikipedia://en/680261)**. An element *x* of a poset is compact if it is *[way below](https://en.wikipedia.org/wiki/Way-below_relation)* itself, i.e. *x*\<\<*x*. One also says that such an *x* is finite.
- **[Comparable](wikipedia://en/3834818)**. Two elements *x* and *y* of a poset *P* are comparable if either *x* ≤ *y* or *y* ≤ *x*.
- **[Comparability graph](wikipedia://en/6978672)**. The comparability graph of a poset (*P*, ≤) is the [graph](wikipedia://en/325806) with vertex set *P* in which the edges are those pairs of distinct elements of *P* that are comparable under ≤ (and, in particular, under its reflexive reduction \<).
- **[Complete Boolean algebra](wikipedia://en/1839944)**. A [Boolean algebra](wikipedia://en/3959) that is a complete lattice.
- **[Complete Heyting algebra](wikipedia://en/650751)**. A [Heyting algebra](wikipedia://en/309343) that is a complete lattice is called a complete Heyting algebra. This notion coincides with the concepts *frame* and *locale*.
- **[Complete lattice](wikipedia://en/44777)**. A complete [lattice](wikipedia://en/469304) is a poset in which arbitrary (possibly infinite) joins (suprema) and meets (infima) exist.
- **[Complete partial order](wikipedia://en/572352)**. A complete partial order, or **cpo**, is a [directed complete partial order](https://en.wikipedia.org/wiki/Directed_complete_partial_order) (q.v.) with least element.
- **Complete relation**. Synonym for *[Connected relation](wikipedia://en/57495962)*.
- **Complete semilattice**. The notion of a *complete semilattice* is defined in different ways. As explained in the article on [completeness (order theory)](wikipedia://en/549445), any poset for which either all suprema or all infima exist is already a complete lattice. Hence the notion of a complete semilattice is sometimes used to coincide with the one of a complete lattice. In other cases, complete (meet-) semilattices are defined to be [bounded complete](https://en.wikipedia.org/wiki/Bounded_complete) [cpos](wikipedia://en/572352), which is arguably the most complete class of posets that are not already complete lattices.
- **[Completely distributive lattice](wikipedia://en/7482029)**. A complete lattice is completely distributive if arbitrary joins distribute over arbitrary meets.
- **Completion**. A completion of a poset is an [order-embedding](https://en.wikipedia.org/wiki/Order-embedding) of the poset in a complete lattice.
- **[Completion by cuts](wikipedia://en/16667323)**. Synonym of [Dedekind–MacNeille completion](wikipedia://en/16667323).
- **[Connected relation](wikipedia://en/57495962)**. A total or complete relation *R* on a set *X* has the property that for all elements *x*, *y* of *X*, at least one of *x R y* or *y R x* holds.
- **[Continuous poset](wikipedia://en/71369165)**. A poset is continuous if it has a **base**, i.e. a subset *B* of *P* such that every element *x* of *P* is the supremum of a directed set contained in {*y* in *B* | *y*\<\<*x*}.
- **Continuous function**. See *Scott-continuous*.
- **Converse**. The converse \<° of an order \< is that in which x \<° y whenever y \< x.
- **Cover**. An element *y* of a poset *P* is said to cover an element *x* of *P* (and is called a cover of *x*) if *x* \< *y* and there is no element *z* of *P* such that *x* \< *z* \< *y*.
- **[cpo](wikipedia://en/572352)**. See *complete partial order*.

## D {#D}

- **dcpo**. See *[directed complete partial order](https://en.wikipedia.org/wiki/Directed_complete_partial_order)*.
- **[Dedekind–MacNeille completion](wikipedia://en/16667323)**. The Dedekind–MacNeille completion of a [partially ordered set](wikipedia://en/23572) is the smallest [complete lattice](wikipedia://en/44777) that contains it.
- **[Dense order](wikipedia://en/6320997)**. A **[dense](wikipedia://en/6320997)** poset *P* is one in which, for all elements *x* and *y* in *P* with *x* \< *y*, there is an element *z* in *P*, such that *x* \< *z* \< *y*. A subset *Q* of *P* is **dense in** *P* if for any elements *x* \< *y* in *P*, there is an element *z* in *Q* such that *x* \< *z* \< *y*.
- **[Derangement](wikipedia://en/162132)**. A permutation of the elements of a set, such that no element appears in its original position.
- **[Directed set](wikipedia://en/9165)**. A [non-empty](https://en.wikipedia.org/wiki/Non-empty) subset *X* of a poset *P* is called directed, if, for all elements *x* and *y* of *X*, there is an element *z* of *X* such that *x* ≤ *z* and *y* ≤ *z*. The dual notion is called *filtered*.
- **[Directed complete partial order](https://en.wikipedia.org/wiki/Directed_complete_partial_order)**. A poset *D* is said to be a directed complete poset, or **dcpo**, if every directed subset of *D* has a supremum.
- **[Distributive](wikipedia://en/616019)**. A lattice *L* is called distributive if, for all *x*, *y*, and *z* in *L*, we find that *x* ∧ (*y* ∨ *z*) = (*x* ∧ *y*) ∨ (*x* ∧ *z*). This condition is known to be equivalent to its order dual. A meet-[semilattice](wikipedia://en/755647) is distributive if for all elements *a*, *b* and *x*, *a* ∧ *b* ≤ *x* implies the existence of elements *a'* ≥ *a* and *b'* ≥ *b* such that *a'* ∧ *b'* = *x*. See also *completely distributive*.
- **[Domain](wikipedia://en/325077)**. Domain is a general term for objects like those that are studied in [domain theory](wikipedia://en/325077). If used, it requires further definition.
- **Down-set**. See *lower set*.
- **[Dual](wikipedia://en/600618)**. For a poset (*P*, ≤), the dual order *P*<sup>*d*</sup> = (*P*, ≥) is defined by setting *x ≥ y* [if and only if](wikipedia://en/14922) *y ≤ x*. The dual order of *P* is sometimes denoted by *P*<sup>op</sup>, and is also called *opposite* or *converse* order. Any order theoretic notion induces a dual notion, defined by applying the original statement to the order dual of a given set. This exchanges ≤ and ≥, meets and joins, zero and unit.

## E {#E}

- **Extension**. For partial orders ≤ and ≤′ on a set *X*, ≤′ is an extension of ≤ provided that for all elements *x* and *y* of *X*, *x* ≤ *y* implies that *x* ≤′ *y*.

## F {#F}

- **[Filter](wikipedia://en/19719)**. A subset *X* of a poset *P* is called a filter if it is a filtered upper set. The dual notion is called *ideal*.
- **Filtered**. A [non-empty](https://en.wikipedia.org/wiki/Non-empty) subset *X* of a poset *P* is called filtered, if, for all elements *x* and *y* of *X*, there is an element *z* of *X* such that *z* ≤ *x* and *z* ≤ *y*. The dual notion is called *directed*.
- **Finite element**. See *compact*.
- **[Frame](wikipedia://en/650751)**. A frame *F* is a complete lattice, in which, for every *x* in *F* and every subset *Y* of *F*, the infinite distributive law *x* ∧ $\bigvee$*Y* = $\bigvee${*x* ∧ *y* | *y* in *Y*} holds. Frames are also known as *locales* and as complete [Heyting algebras](wikipedia://en/309343).

## G {#G}

- **[Galois connection](wikipedia://en/156411)**. Given two posets *P* and *Q*, a pair of monotone functions *F*:*P* → *Q* and *G*:*Q* → *P* is called a Galois connection, if *F*(*x*) ≤ *y* is equivalent to *x* ≤ *G*(*y*), for all *x* in *P* and *y* in *Q*. *F* is called the **lower adjoint** of *G* and *G* is called the **upper adjoint** of *F*.
- **[Greatest element](https://en.wikipedia.org/wiki/Greatest_element)**. For a subset *X* of a poset *P*, an element *a* of *X* is called the greatest element of *X*, if *x* ≤ *a* for every element *x* in *X*. The dual notion is called *least element*.
- **Ground set**. The ground set of a poset (*X*, ≤) is the set *X* on which the partial order ≤ is defined.

## H {#H}

- **[Heyting algebra](wikipedia://en/309343)**. A Heyting algebra *H* is a bounded lattice in which the function *f*<sub>*a*</sub>: *H* → *H*, given by *f*<sub>*a*</sub>(*x*) = *a* ∧ *x* is the lower adjoint of a [Galois connection](wikipedia://en/156411), for every element *a* of *H*. The upper adjoint of *f*<sub>*a*</sub> is then denoted by *g*<sub>*a*</sub>, with *g*<sub>*a*</sub>(*x*) = *a* ⇒; *x*. Every [Boolean algebra](wikipedia://en/3959) is a Heyting algebra.
- **[Hasse diagram](wikipedia://en/338199)**. A Hasse diagram is a type of mathematical diagram used to represent a finite partially ordered set, in the form of a drawing of its [transitive reduction](wikipedia://en/3757117).
- **[Homogeneous relation](wikipedia://en/12987179)**. A [homogeneous relation](wikipedia://en/12987179) on a set $X$ is a subset of $X \times X.$ Said differently, it is a [binary relation](wikipedia://en/3931) over $X$ and itself.

## I {#I}

- **[Ideal](wikipedia://en/530559)**. An **[ideal](wikipedia://en/530559)** is a subset *X* of a poset *P* that is a directed lower set. The dual notion is called *filter*.
- **[Incidence algebra](wikipedia://en/166980)**. The **[incidence algebra](wikipedia://en/166980)** of a poset is the [associative algebra](wikipedia://en/2112) of all scalar-valued functions on intervals, with addition and scalar multiplication defined pointwise, and multiplication defined as a certain convolution; see [incidence algebra](wikipedia://en/166980) for the details.
- **[Infimum](https://en.wikipedia.org/wiki/Infimum)**. For a poset *P* and a subset *X* of *P*, the greatest element in the set of lower bounds of *X* (if it exists, which it may not) is called the **infimum**, **meet**, or **greatest lower bound** of *X*. It is denoted by inf *X* or $\bigwedge$*X*. The infimum of two elements may be written as inf{*x*,*y*} or *x* ∧ *y*. If the set *X* is finite, one speaks of a **finite infimum**. The dual notion is called *supremum*.
- **[Interval](wikipedia://en/49172)**. For two elements *a*, *b* of a partially ordered set *P*, the *interval* \[*a*,*b*\] is the subset {*x* in *P* | *a* ≤ *x* ≤ *b*} of *P*. If *a* ≤ *b* does not hold the interval will be empty.
- **Interval finite poset**. A partially ordered set *P* is **interval finite** if every interval of the form {x in P | x ≤ a} is a finite set.[^o12]
- **Inverse**. See *converse*.
- **[Irreflexive](https://en.wikipedia.org/wiki/Irreflexive)**. A [relation](wikipedia://en/22517558) *R* on a set *X* is irreflexive, if there is no element *x* in *X* such that *x R x*.
- **Isotone**. See *monotone*.

## J {#J}

- **Join**. See *supremum*.

## L {#L}

- **[Lattice](wikipedia://en/469304)**. A lattice is a poset in which all non-empty finite joins (suprema) and meets (infima) exist.
- **[Least element](https://en.wikipedia.org/wiki/Least_element)**. For a subset *X* of a poset *P*, an element *a* of *X* is called the least element of *X*, if *a* ≤ *x* for every element *x* in *X*. The dual notion is called *greatest element*.
- The **length** of a chain is the number of elements less one. A chain with 1 element has length 0, one with 2 elements has length 1, etc.
- **Linear**. See *total order*.
- **[Linear extension](wikipedia://en/11726298)**. A linear extension of a partial order is an extension that is a linear order, or total order.
- **[Locale](wikipedia://en/650751)**. A locale is a *complete Heyting algebra*. Locales are also called *frames* and appear in [Stone duality](wikipedia://en/379619) and [pointless topology](wikipedia://en/24764).
- **[Locally finite poset](wikipedia://en/19357321)**. A partially ordered set *P* is *locally finite* if every interval \[*a*, *b*\] = {*x* in *P* | *a* ≤ *x* ≤ *b*} is a finite set.
- **[Lower bound](https://en.wikipedia.org/wiki/Lower_bound)**. A lower bound of a subset *X* of a poset *P* is an element *b* of *P*, such that *b* ≤ *x*, for all *x* in *X*. The dual notion is called *upper bound*.
- **[Lower set](https://en.wikipedia.org/wiki/Lower_set)**. A subset *X* of a poset *P* is called a lower set if, for all elements *x* in *X* and *p* in *P*, *p* ≤ *x* implies that *p* is contained in *X*. The dual notion is called *upper set*.

::: {#o16 .pointer-item cue=pointer name="Maximal chain"}

## M {#M}

- **Maximal chain**. A [chain](wikipedia://en/30330#Chains) in a poset to which no element can be added without losing the property of being totally ordered. This is stronger than being a saturated chain, as it also excludes the existence of elements either less than all elements of the chain or greater than all its elements. A finite saturated chain is maximal if and only if it contains both a minimal and a maximal element of the poset.
- **[Maximal element](https://en.wikipedia.org/wiki/Maximal_element)**. A maximal element of a subset *X* of a poset *P* is an element *m* of *X*, such that *m* ≤ *x* implies *m* = *x*, for all *x* in *X*. The dual notion is called *minimal element*.
- **[Maximum element](https://en.wikipedia.org/wiki/Greatest_element)**. Synonym of greatest element. For a subset *X* of a poset *P*, an element *a* of *X* is called the maximum element of *X* if *x* ≤ *a* for every element *x* in *X*. A maxim*um* element is necessarily maxim*al*, but the converse need not hold.
- **Meet**. See *infimum*.
- **[Minimal element](https://en.wikipedia.org/wiki/Minimal_element)**. A minimal element of a subset *X* of a poset *P* is an element *m* of *X*, such that *x* ≤ *m* implies *m* = *x*, for all *x* in *X*. The dual notion is called *maximal element*.
- **[Minimum element](https://en.wikipedia.org/wiki/Least_element)**. Synonym of least element. For a subset *X* of a poset *P*, an element *a* of *X* is called the minimum element of *X* if *x* ≥ *a* for every element *x* in *X*. A minim*um* element is necessarily minim*al*, but the converse need not hold.
- **[Monotone](https://en.wikipedia.org/wiki/Monotone_function)**. A function *f* between posets *P* and *Q* is monotone if, for all elements *x*, *y* of *P*, *x* ≤ *y* (in *P*) implies *f*(*x*) ≤ *f*(*y*) (in *Q*). Other names for this property are *isotone* and *order-preserving*. In [analysis](wikipedia://en/48396), in the presence of [total orders](wikipedia://en/30330), such functions are often called **monotonically increasing**, but this is not a very convenient description when dealing with non-total orders. The dual notion is called *antitone* or *order reversing*.

:::

## O {#O}

- **Order-dual**. The order dual of a partially ordered set is the same set with the partial order relation replaced by its converse.
- **[Order-embedding](https://en.wikipedia.org/wiki/Order-embedding)**. A function *f* between posets *P* and *Q* is an order-embedding if, for all elements *x*, *y* of *P*, *x* ≤ *y* (in *P*) is equivalent to *f*(*x*) ≤ *f*(*y*) (in *Q*).
- **[Order isomorphism](wikipedia://en/23916899)**. A mapping *f*: *P* → *Q* between two posets *P* and *Q* is called an order isomorphism, if it is [bijective](https://en.wikipedia.org/wiki/Bijective) and both *f* and *f*<sup>−1</sup> are [monotone functions](https://en.wikipedia.org/wiki/Monotone_function). Equivalently, an order isomorphism is a surjective *order embedding*.
- **[Order-preserving](https://en.wikipedia.org/wiki/Order-preserving)**. See *monotone*.
- **[Order-reversing](https://en.wikipedia.org/wiki/Order-reversing)**. See *antitone*.

::: {#o19 .pointer-item cue=pointer name="Projection (order theory)"}

## P {#P}

- **[Partial order](https://en.wikipedia.org/wiki/Partial_order)**. A partial order is a [binary relation](wikipedia://en/3931) that is [reflexive](wikipedia://en/200458), [antisymmetric](wikipedia://en/1176), and [transitive](wikipedia://en/200463). In a slight abuse of terminology, the term is sometimes also used to refer not to such a relation, but to its corresponding partially ordered set.
- **[Partially ordered set](wikipedia://en/23572)**. A partially ordered set $(P, \leq),$ or poset for short, is a set $P$ together with a partial order $\,\leq\,$ on $P.$
- **Poset**. A partially ordered set.
- **[Preorder](wikipedia://en/23582)**. A preorder is a [binary relation](wikipedia://en/3931) that is [reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200463). Such orders may also be called quasiorders or non-strict preorder. The term preorder is also used to denote an acyclic [binary relation](wikipedia://en/3931) (also called an acyclic digraph).
- **[Preordered set](https://en.wikipedia.org/wiki/Preordered_set)**. A preordered set $(P, \leq)$ is a set $P$ together with a preorder $\,\leq\,$ on $P.$
- **Preserving**. A function *f* between posets *P* and *Q* is said to preserve suprema (joins), if, for all subsets *X* of *P* that have a supremum sup *X* in *P*, we find that sup{*f*(*x*): *x* in *X*} exists and is equal to *f*(sup *X*). Such a function is also called **join-preserving**. Analogously, one says that *f* preserves finite, non-empty, directed, or arbitrary joins (or meets). The converse property is called *join-reflecting*.
- **[Prime](https://en.wikipedia.org/wiki/Order_ideal)**. An ideal *I* in a lattice *L* is said to be prime, if, for all elements *x* and *y* in *L*, *x* ∧ *y* in *I* implies *x* in *I* or *y* in *I*. The dual notion is called a *prime filter*. Equivalently, a set is a prime filter [if and only if](wikipedia://en/14922) its complement is a prime ideal.
- **[Principal](https://en.wikipedia.org/wiki/Order_ideal)**. A filter is called *principal filter* if it has a least element. Dually, a *principal ideal* is an ideal with a greatest element. The least or greatest elements may also be called *principal elements* in these situations.
- **Projection (operator)**. A self-map on a [partially ordered set](wikipedia://en/23572) that is [monotone](wikipedia://en/48260) and [idempotent](https://en.wikipedia.org/wiki/Idempotent) under [function composition](wikipedia://en/195947). Projections play an important role in [domain theory](wikipedia://en/325077).
- **Pseudo-complement**. In a [Heyting algebra](wikipedia://en/309343), the element *x* ⇒; *0* is called the pseudo-complement of *x*. It is also given by sup{*y* : *y* ∧ *x* = 0}, i.e. as the least upper bound of all elements *y* with *y* ∧ *x* = 0.

:::

## Q {#Q}

- **Quasiorder**. See *preorder*.
- **[Quasitransitive](wikipedia://en/6770393)**. A relation is quasitransitive if the relation on distinct elements is transitive. Transitive implies quasitransitive and quasitransitive implies acyclic.[^o21]

## R {#R}

- **Reflecting**. A function *f* between posets *P* and *Q* is said to reflect suprema (joins), if, for all subsets *X* of *P* for which the supremum sup{*f*(*x*): *x* in *X*} exists and is of the form *f*(*s*) for some *s* in *P*, then we find that sup *X* exists and that sup *X* = *s* . Analogously, one says that *f* reflects finite, non-empty, directed, or arbitrary joins (or meets). The converse property is called *join-preserving*.
- **[Reflexive](wikipedia://en/200458)**. A [binary relation](wikipedia://en/3931) *R* on a set *X* is reflexive, if *x R x* holds for every element *x* in *X*.
- **Residual**. A dual map attached to a [residuated mapping](wikipedia://en/18272082).
- **[Residuated mapping](wikipedia://en/18272082)**. A monotone map for which the preimage of a principal down-set is again principal. Equivalently, one component of a Galois connection.

::: {#o24 .pointer-item cue=pointer name="Saturated chain"}

## S {#S}

- **Saturated chain**. A [chain](wikipedia://en/30330#Chains) in a poset such that no element can be added *between two of its elements* without losing the property of being totally ordered. If the chain is finite, this means that in every pair of successive elements the larger one covers the smaller one. See also maximal chain.
- **[Scattered](wikipedia://en/15922429)**. A total order is scattered if it has no densely ordered subset.
- **[Scott-continuous](https://en.wikipedia.org/wiki/Scott-continuous)**. A monotone function *f* : *P* → *Q* between posets *P* and *Q* is Scott-continuous if, for every directed set *D* that has a supremum sup *D* in *P*, the set {*fx* | *x* in *D*} has the supremum *f*(sup *D*) in *Q*. Stated differently, a Scott-continuous function is one that preserves all directed suprema. This is in fact equivalent to being [continuous](https://en.wikipedia.org/wiki/Continuity_%28topology%29) with respect to the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology) on the respective posets.
- **[Scott domain](wikipedia://en/710483)**. A Scott domain is a partially ordered set which is a [bounded complete](https://en.wikipedia.org/wiki/Bounded_complete) [algebraic](https://en.wikipedia.org/wiki/Algebraic_poset) [cpo](wikipedia://en/572352).
- **Scott open**. See *Scott topology*.
- **Scott topology**. For a poset *P*, a subset *O* is **Scott-open** if it is an [upper set](https://en.wikipedia.org/wiki/Upper_set) and all directed sets *D* that have a supremum in *O* have non-empty intersection with *O*. The set of all Scott-open sets forms a [topology](wikipedia://en/29954), the **Scott topology**.
- **[Semilattice](wikipedia://en/755647)**. A semilattice is a poset in which either all finite non-empty joins (suprema) or all finite non-empty meets (infima) exist. Accordingly, one speaks of a **join-semilattice** or **meet-semilattice**.
- **Smallest element**. See *least element*.
- [Sperner property of a partially ordered set](wikipedia://en/26534180)
- [Sperner poset](https://en.wikipedia.org/wiki/Sperner_poset)
- [Strictly Sperner poset](https://en.wikipedia.org/wiki/Strictly_Sperner_poset)
- [Strongly Sperner poset](https://en.wikipedia.org/wiki/Strongly_Sperner_poset)
- **[Strict order](https://en.wikipedia.org/wiki/Strict_order)**. See strict partial order.
- **[Strict partial order](https://en.wikipedia.org/wiki/Strict_partial_order)**. A strict partial order is a [homogeneous binary relation](wikipedia://en/12987179) that is [transitive](wikipedia://en/200463), [irreflexive](https://en.wikipedia.org/wiki/Irreflexive_relation), and [antisymmetric](wikipedia://en/1176).
- **[Strict preorder](https://en.wikipedia.org/wiki/Strict_preorder)**. See strict partial order.
- **[Supremum](https://en.wikipedia.org/wiki/Supremum)**. For a poset *P* and a subset *X* of *P*, the [least element](https://en.wikipedia.org/wiki/Least_element) in the set of [upper bounds](https://en.wikipedia.org/wiki/Upper_bound) of *X* (if it exists, which it may not) is called the **supremum**, **join**, or **least upper bound** of *X*. It is denoted by sup *X* or $\bigvee$*X*. The supremum of two elements may be written as sup{*x*,*y*} or *x* ∨ *y*. If the set *X* is finite, one speaks of a **finite supremum**. The dual notion is called *infimum*.
- **Suzumura consistency**. A binary relation R is Suzumura consistent if *x* R<sup>∗</sup> *y* implies that *x* R *y* or not *y* R *x*.[^o21]
- **[Symmetric relation](wikipedia://en/200459)**. A [homogeneous relation](wikipedia://en/12987179) *R* on a set *X* is symmetric, if *x R y* implies *y R x*, for all elements *x*, *y* in *X*.

## T {#T}

- **Top**. See *unit*.
- **[Total order](wikipedia://en/30330)**. A total order *T* is a partial order in which, for each *x* and *y* in *T*, we have *x* ≤ *y* or *y* ≤ *x*. Total orders are also called *linear orders* or *chains*.
- **[Total relation](wikipedia://en/57495962)**. Synonym for *[Connected relation](wikipedia://en/57495962)*.
- **[Transitive relation](wikipedia://en/200463)**. A [relation](wikipedia://en/12987179) *R* on a set *X* is transitive, if *x R y* and *y R z* imply *x R z*, for all elements *x*, *y*, *z* in *X*.
- **[Transitive closure](wikipedia://en/292239)**. The transitive closure R<sup>∗</sup> of a relation R consists of all pairs *x*,*y* for which there exists a finite chain *x* R *a*, *a* R *b*, ..., *z* R *y*.[^o21]

## U {#U}

- **Unit**. The [greatest element](https://en.wikipedia.org/wiki/Greatest_element) of a poset *P* can be called *unit* or just *1* (if it exists). Another common term for this element is **top**. It is the infimum of the empty set and the supremum of *P*. The dual notion is called *zero*.
- **Up-set**. See *upper set*.
- **[Upper bound](https://en.wikipedia.org/wiki/Upper_bound)**. An upper bound of a subset *X* of a poset *P* is an element *b* of *P*, such that *x* ≤ *b*, for all *x* in *X*. The dual notion is called *lower bound*.
- **[Upper set](https://en.wikipedia.org/wiki/Upper_set)**. A subset *X* of a poset *P* is called an upper set if, for all elements *x* in *X* and *p* in *P*, *x* ≤ *p* implies that *p* is contained in *X*. The dual notion is called *lower set*.

## V {#V}

- **Valuation**. Given a lattice $X$, a valuation $\nu : X \to [0,1]$ is strict (that is, $\nu(\varnothing) = 0$), monotone, modular (that is, $\nu(U) + \nu(V) = \nu(U \cup V) + \nu(U \cap V)$) and positive. Continuous valuations are a generalization of measures.

## W {#W}

- **[Way-below relation](https://en.wikipedia.org/wiki/Way-below_relation)**. In a poset *P*, some element *x* is *way below* *y*, written *x*\<\<*y*, if for all directed subsets *D* of *P* which have a supremum, *y* ≤ *sup D* implies *x* ≤ *d* for some *d* in *D*. One also says that *x* **approximates** *y*. See also [domain theory](wikipedia://en/325077).
- **[Weak order](https://en.wikipedia.org/wiki/Weak_order)**. A partial order ≤ on a set *X* is a weak order provided that the poset (X, ≤) is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to a countable collection of sets ordered by comparison of [cardinality](wikipedia://en/6174).

## Z {#Z}

- **Zero**. The [least element](https://en.wikipedia.org/wiki/Least_element) of a poset *P* can be called *zero* or just *0* (if it exists). Another common term for this element is **bottom**. Zero is the supremum of the empty set and the infimum of *P*. The dual notion is called *unit*.
