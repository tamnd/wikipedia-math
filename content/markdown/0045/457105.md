# Field trace

::: {#o1 .subject cue=lead name="Field trace"}

In [mathematics](wikipedia://en/18831), the **field trace** is a particular [function](wikipedia://en/185427) defined with respect to a [finite](https://en.wikipedia.org/wiki/Finite_extension) [field extension](wikipedia://en/11634) *L*/*K*, which is a [*K*-linear map](wikipedia://en/18102) from *L* onto *K*.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *K* be a [field](wikipedia://en/10603) and *L* a finite extension (and hence an [algebraic extension](wikipedia://en/2125)) of *K*. *L* can be viewed as a [vector space](wikipedia://en/32370) over *K*. Multiplication by *α*, an element of *L*,

$$m_\alpha:L\to L \text{ given by } m_\alpha (x) = \alpha x,$$

is a *K*-[linear transformation](https://en.wikipedia.org/wiki/Linear_transformation) of this vector space into itself. The *trace*, **Tr**<sub>*L*/*K*</sub>(*α*), is defined as the [trace](wikipedia://en/43270) (in the [linear algebra](wikipedia://en/18422) sense) of this linear transformation.[^o4]

For *α* in *L*, let *σ*${}_{1}$(*α*), ..., *σ*${}_{n}$(*α*) be the [roots](https://en.wikipedia.org/wiki/Root_of_a_polynomial) (counted with multiplicity) of the [minimal polynomial](wikipedia://en/9667106) of *α* over *K* (in some extension field of *K*). Then

$$\operatorname{Tr}_{L/K}(\alpha) = [L:K(\alpha)]\sum_{j=1}^n\sigma_j(\alpha).$$

If *L*/*K* is [separable](wikipedia://en/363340) then each root appears only once[^o5] (however this does not mean the coefficient above is one; for example if *α* is the identity element 1 of *K* then the trace is \[*L*:*K*\] times 1).

More particularly, if *L*/*K* is a [Galois extension](wikipedia://en/457064) and *α* is in *L*, then the trace of *α* is the sum of all the [Galois conjugates](https://en.wikipedia.org/wiki/Galois_conjugate) of *α*,[^o4] i.e.,

$$\operatorname{Tr}_{L/K}(\alpha)=\sum_{\sigma\in\operatorname{Gal}(L/K)}\sigma(\alpha),$$

where Gal(*L*/*K*) denotes the [Galois group](wikipedia://en/12673) of *L*/*K*.

:::

::: {#o7 .example cue=heading name="Example"}

## Example {#Example}

Let $L = \mathbb{Q}(\sqrt{d})$ be a [quadratic extension](https://en.wikipedia.org/wiki/Quadratic_extension) of $\mathbb{Q}$. Then a [basis](wikipedia://en/18420) of $L/\mathbb{Q}$ is $\{1, \sqrt{d}\}.$ If $\alpha = a + b\sqrt{d}$ then the [matrix](wikipedia://en/20556859) of $m_{\alpha}$ is:

$$\left [ \begin{matrix} a & bd \\ b & a \end{matrix} \right ],$$

and so, $\operatorname{Tr}_{L/\mathbb{Q}}(\alpha) = [L:\mathbb{Q}(\alpha)]\left( \sigma_1(\alpha) + \sigma_2(\alpha)\right) = 1\times \left( \sigma_1(\alpha) + \overline{\sigma_1}(\alpha)\right) = a+b\sqrt{d} + a-b\sqrt{d} = 2a$.[^o4] The minimal polynomial of *α* is *X*${}^{2}$ − 2*a* *X* + (*a*<sup>2</sup> − *db*<sup>2</sup>).

:::

## Properties of the trace {#Properties_of_the_trace}

Several properties of the trace function hold for any finite extension.[^o9]

The trace Tr${}_{L/K}$ : *L* → *K* is a *K*-[linear map](wikipedia://en/18102) (a *K*-linear functional), that is

$$\operatorname{Tr}_{L/K}(\alpha a + \beta b) = \alpha \operatorname{Tr}_{L/K}(a)+ \beta \operatorname{Tr}_{L/K}(b) \text{ for all }\alpha, \beta \in K.$$

If *α* ∈ *K* then $\operatorname{Tr}_{L/K}(\alpha) = [L:K] \alpha.$

Additionally, trace behaves well in [towers of fields](wikipedia://en/28194169): if *M* is a finite extension of *L*, then the trace from *M* to *K* is just the [composition](wikipedia://en/195947) of the trace from *M* to *L* with the trace from *L* to *K*, i.e.

$$\operatorname{Tr}_{M/K}=\operatorname{Tr}_{L/K}\circ\operatorname{Tr}_{M/L}.$$

## Finite fields {#Finite_fields}

Let *L* = GF(*q*<sup>*n*</sup>) be a finite extension of a [finite field](wikipedia://en/11615) *K* = GF(*q*). Since *L*/*K* is a [Galois extension](wikipedia://en/457064), if *α* is in *L*, then the trace of *α* is the sum of all the [Galois conjugates](https://en.wikipedia.org/wiki/Galois_conjugate) of *α*, i.e.[^o11]

$$\operatorname{Tr}_{L/K}(\alpha)=\alpha + \alpha^q + \cdots + \alpha^{q^{n-1}}.$$

In this setting we have the additional properties:[^o12]

- $$\operatorname{Tr}_{L/K}(a^q) = \operatorname{Tr}_{L/K}(a) \text{ for } a \in L.$$
- For any $\alpha \in K$, there are exactly $q^{n-1}$ elements $b\in L$ with $\operatorname{Tr}_{L/K}(b) = \alpha$.

*Theorem*.[^o13] For *b* ∈ *L*, let *F*<sub>*b*</sub> be the map $a \mapsto \operatorname{Tr}_{L/K}(ba).$ Then *F*<sub>*b*</sub> ≠ *F*<sub>*c*</sub> if *b* ≠ *c*. Moreover, the *K*-linear transformations from *L* to *K* are exactly the maps of the form *F*<sub>*b*</sub> as *b* varies over the field *L*.

When *K* is the [prime subfield](https://en.wikipedia.org/wiki/Prime_subfield) of *L*, the trace is called the *absolute trace* and otherwise it is a *relative trace*.[^o11]

::: {#o15 .application cue=heading name="Application"}

### Application {#Application}

A [quadratic equation](wikipedia://en/25175), *ax*${}^{2}$ + *bx* + *c* = 0 with *a* ≠ 0, and coefficients in the finite field $\operatorname{GF}(q) = \mathbb{F}_q$ has either 0, 1 or 2 roots in GF(*q*) (and two roots, counted with multiplicity, in the quadratic extension GF(*q*<sup>2</sup>)). If the [characteristic](wikipedia://en/1066621) of GF(*q*) is [odd](wikipedia://en/143135), the [discriminant](wikipedia://en/55607) Δ = *b*<sup>2</sup> − 4*ac* indicates the number of roots in GF(*q*) and the classical [quadratic formula](wikipedia://en/59217) gives the roots. However, when GF(*q*) has [even](wikipedia://en/143135) characteristic (i.e., *q* = 2<sup>*h*</sup> for some positive [integer](wikipedia://en/14563) *h*), these formulas are no longer applicable.

Consider the quadratic equation *ax*${}^{2}$ + *bx* + c = 0 with coefficients in the finite field GF(2<sup>*h*</sup>).[^o16] If *b* = 0 then this equation has the unique solution $x = \sqrt{\frac{c}{a}}$ in GF(*q*). If *b* ≠ 0 then the substitution *y* = *ax*/*b* converts the quadratic equation to the form:

$$y^2 + y + \delta = 0, \text { where } \delta = \frac{ac}{b^2}.$$

This equation has two solutions in GF(*q*) [if and only if](wikipedia://en/14922) the absolute trace $\operatorname{Tr}_{GF(q)/GF(2)}(\delta) = 0.$ In this case, if *y* = *s* is one of the solutions, then *y* = *s* + 1 is the other. Let *k* be any element of GF(*q*) with $\operatorname{Tr}_{GF(q)/GF(2)}(k) = 1.$ Then a solution to the equation is given by:

$$y = s = k \delta^2 + (k + k^2)\delta^4 + \ldots + (k + k^2 + \ldots + k^{2^{h-2}})\delta^{2^{h-1}}.$$

When *h* = 2*m**\+ 1, a solution is given by the simpler expression:***

$$y = s = \delta + \delta^{2^2} + \delta^{2^4} + \ldots + \delta^{2^{2m}}.$$

:::

::: {#o18 .pointer-item cue=pointer name="Trace form"}

## Trace form {#Trace_form}

When *L*/*K* is separable, the trace provides a [duality theory](https://en.wikipedia.org/wiki/Duality_theory) via the **trace form**: the map from *L* × *L* to *K* sending (*x*, *y*) to Tr${}_{L/K}$(*xy*) is a [nondegenerate](https://en.wikipedia.org/wiki/Nondegenerate_form), [symmetric bilinear form](wikipedia://en/1803375) called the trace form. If *L*/*K* is a Galois extension, the trace form is invariant with respect to the Galois group.

The trace form is used in [algebraic number theory](wikipedia://en/174705) in the theory of the [different ideal](wikipedia://en/2371783).

The trace form for a finite degree field extension *L*/*K* has non-negative [signature](https://en.wikipedia.org/wiki/Signature_%28quadratic_form%29) for any [field ordering](https://en.wikipedia.org/wiki/Field_ordering) of *K*.[^o19] The [converse](wikipedia://en/155941), that every [Witt equivalence](https://en.wikipedia.org/wiki/Witt_ring_%28forms%29) class with non-negative signature contains a trace form, is true for [algebraic number fields](wikipedia://en/28730822) *K*.[^o19]

If *L*/*K* is an [inseparable extension](https://en.wikipedia.org/wiki/Inseparable_extension), then the trace form is identically 0.[^o20]

:::
