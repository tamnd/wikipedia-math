# Incomplete gamma function

::: {#o1 .subject cue=lead name="Incomplete gamma function"}

*Image: Upper incomplete gamma function.jpg.* The upper incomplete gamma function for some values of s: 0 (blue), 1 (red), 2 (green), 3 (orange), 4 (purple).

*Image: Plot of the regularized incomplete gamma function Q(2,z) in the complex plane from -2-2i to 2+2i with colors created with Mathematica 13.1 function ComplexPlot3D.svg.* Plot of the regularized incomplete gamma function Q(2,z) in the complex plane from $-2-2i$ to $2+2i$.

In [mathematics](wikipedia://en/18831), the **upper** and **lower incomplete gamma functions** are types of [special functions](wikipedia://en/23709110) which arise as solutions to certain [integrals](wikipedia://en/15532).

:::

Their respective names stem from their integral definitions, which are defined similarly to the [gamma function](wikipedia://en/12316) but with different or "incomplete" integral limits. The usual gamma function is defined as an integral from zero to infinity. This contrasts with the lower incomplete gamma function, which is defined as an integral from zero to a variable upper limit. Similarly, the upper incomplete gamma function is defined as an integral from a variable lower limit to infinity.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The upper incomplete gamma function is defined as

$$\Gamma(s,x) = \int_x^{\infty} t^{s-1}e^{-t}\, dt ,$$

and the lower incomplete gamma function is defined as

$$\gamma(s,x) = \int_0^x t^{s-1}e^{-t}\, dt .$$

In both cases, $s$ is a [complex number](wikipedia://en/5826) with positive [real part](wikipedia://en/5826).

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

By [integration by parts](wikipedia://en/147252), we find the [recurrence relations](https://en.wikipedia.org/wiki/Recurrence_relations)

$$\Gamma(s+1,x) = s\Gamma(s,x) + x^{s} e^{-x}$$

and

$$\gamma(s+1,x) = s\gamma(s,x) - x^{s} e^{-x}.$$

Since the ordinary gamma function is defined as

$$\Gamma(s) = \int_0^{\infty} t^{s-1}\,e^{-t}\, dt,$$

we have

$$\Gamma(s) = \Gamma(s,0) = \lim_{x \to \infty} \gamma(s,x)$$

and

$$\gamma(s,x) + \Gamma(s,x) = \Gamma(s).$$

### Continuation to complex values {#Continuation_to_complex_values}

The lower incomplete gamma and the upper incomplete gamma function, as defined above for real positive $s$ and $x$, can be developed into [holomorphic functions](wikipedia://en/14110), with respect both to $x$ and $s$, defined for almost all combinations of complex $x$ and $s$.[^o7] Complex analysis shows how properties of the real incomplete gamma functions extend to their holomorphic counterparts.

#### Lower incomplete gamma function {#Lower_incomplete_gamma_function}

##### Holomorphic extension {#Holomorphic_extension}

Repeated application of the recurrence relation for the **lower incomplete gamma** function leads to the [power series](wikipedia://en/59958) expansion: [^o10]

$$\gamma(s, x) = \sum_{k=0}^\infty \frac{x^s e^{-x} x^k}{s(s+1)\cdots(s+k)} = x^s \, \Gamma(s) \, e^{-x} \sum_{k=0}^\infty\frac{x^k}{\Gamma(s+k+1)}.$$

Given the rapid growth in [absolute value](wikipedia://en/991#Complex_numbers) of $\Gamma(z + k)$ when $k \to \infty$, and the fact that the [reciprocal of $\Gamma(z)$](https://en.wikipedia.org/wiki/Reciprocal_Gamma_function) is an [entire function](wikipedia://en/10372), the coefficients in the rightmost sum are well-defined, and locally the sum [converges uniformly](wikipedia://en/50652) for all complex $s$ and $x$. By a theorem of [Weierstrass](https://en.wikipedia.org/wiki/Weierstrass),[^o11] the limiting function, sometimes denoted as $\gamma^*$,[^o12]

$$\gamma^*(s, z) := e^{-z}\sum_{k=0}^\infty\frac{z^k}{\Gamma(s+k+1)}$$

is [entire](wikipedia://en/10372) with respect to both $z$ (for fixed $s$) and $s$ (for fixed $z$),[^o7] and, thus, holomorphic on $\mathbf{C} \times \mathbf{C}$ by [Hartogs' theorem](wikipedia://en/2978799).[^o13] Hence, the following *decomposition*[^o7]

$$\gamma(s,z) = z^s \, \Gamma(s) \, \gamma^*(s,z),$$

extends the real lower incomplete gamma function as a [holomorphic function](wikipedia://en/14110), both jointly and separately in $z$ and $s$. It follows from the properties of $z^s$ and the [Γ-function](wikipedia://en/12316), that the first two factors capture the [singularities](https://en.wikipedia.org/wiki/Mathematical_singularity) of $\gamma(s,z)$ (at $z = 0$ or $s$ a non-positive integer), whereas the last factor contributes to its zeros.

##### Multi-valuedness {#Multi-valuedness}

The [complex logarithm](wikipedia://en/4870290) $\log z = \log \lvert z\rvert + i \arg z$ is determined up to a multiple of $2\pi i$ only, which renders it [multi-valued](https://en.wikipedia.org/wiki/Multi-valued_function). Functions involving the complex logarithm typically inherit this property. Among these are the [complex power](wikipedia://en/99491#nth_roots_of_a_complex_number), and, since $z^{s}$ appears in its decomposition, the $\gamma$-function, too.

The indeterminacy of multi-valued functions introduces complications, since it must be stated how to select a value. Strategies to handle this are:

- (the most general way) replace the domain $\mathbf{C}$ of multi-valued functions by a suitable manifold in $\mathbf{C} \times \mathbf{C}$ called [Riemann surface](wikipedia://en/173181). While this removes multi-valuedness, one has to know the theory behind it;[^o15]
- restrict the domain such that a multi-valued function decomposes into separate single-valued [branches](wikipedia://en/483173), which can be handled individually.

The following set of rules can be used to interpret formulas in this section correctly. If not mentioned otherwise, the following is assumed:

###### Sectors {#Sectors}

Sectors in $\mathbf{C}$ having their vertex at $z = 0$ often prove to be appropriate domains for complex expressions. A sector $D$ consists of all complex $z$ fulfilling $z \ne 0$ and $\alpha - \delta < \arg z < \alpha + \delta$ with some $\alpha$ and $0 < \delta \le \pi$. Often, $\alpha$ can be arbitrarily chosen and is not specified then. If $\delta$ is not given, it is assumed to be $\pi$, and the sector is in fact the whole plane $\mathbf{C}$, with the exception of a half-line originating at $z = 0$ and pointing into the direction of $-\alpha$, usually serving as a [branch cut](https://en.wikipedia.org/wiki/Branch_cut#Branch_cuts). Note: In many applications and texts, $\alpha$ is silently taken to be 0, which centers the sector around the positive real axis.

###### Branches {#Branches}

In particular, a single-valued and holomorphic logarithm exists on any such sector D having its imaginary part bound to the range *α* − *δ*, *α* + *δ*. Based on such a restricted logarithm, $z^{s}$ and the incomplete gamma functions in turn collapse to single-valued, holomorphic functions on $D$ (or $\mathbf{C}\times D$), called branches of their multi-valued counterparts on D. Adding a multiple of $2\pi$ to $\alpha$ yields a different set of correlated branches on the same set $D$. However, in any given context here, $\alpha$ is assumed fixed and all branches involved are associated to it. If $\lvert \alpha\rvert < \delta$, the branches are called [principal](https://en.wikipedia.org/wiki/Principal_branch), because they equal their real analogues on the positive real axis. Note: In many applications and texts, formulas hold only for principal branches.

###### Relation between branches {#Relation_between_branches}

The values of different branches of both the complex power function and the lower incomplete gamma function can be derived from each other by multiplication of $e^{2\pi iks}$,[^o7] for $k$ a suitable integer.

##### Behavior near branch point {#Behavior_near_branch_point}

The decomposition above further shows, that γ behaves near $z = 0$ [asymptotically](https://en.wikipedia.org/wiki/Asymptotic) like:

$$\gamma(s, z) \asymp z^s \, \Gamma(s) \, \gamma^*(s, 0) = z^s \, \Gamma(s)/\Gamma(s+1) = z^s/s.$$

For positive real $x$, $y$ and $s$, $x^{y}/y \to 0$, when $(x, y) \to (0, s)$. This seems to justify setting $\gamma(s, 0) = 0$ for real $s > 0$. However, matters are somewhat different in the complex realm. Only if (a) the real part of $s$ is positive, and (b) values $u^{v}$ are taken from just a [finite set](wikipedia://en/11742) of branches, they are guaranteed to converge to zero as $(u, v) \to (0, s)$, and so does $\gamma(u, v)$. On a single [branch](wikipedia://en/483173) of $\gamma(b)$ is naturally fulfilled, so **there** $\gamma(s, 0) = 0$ for $s$ with positive real part is a [continuous limit](wikipedia://en/6122). Also note that such a continuation is by no means an [analytic one](wikipedia://en/80842).

##### Algebraic relations {#Algebraic_relations}

All algebraic relations and [differential equations](wikipedia://en/1424309) observed by the real $\gamma(s, z)$ hold for its holomorphic counterpart as well. This is a consequence of the [identity theorem](wikipedia://en/3553654), stating that equations between holomorphic functions valid on a real interval, hold everywhere. In particular, the recurrence relation [^o10] and $\partial\gamma(s, z)/\partial z = z^{s-1} e^{-z}$ [^o10] are preserved on corresponding branches.

##### Integral representation {#Integral_representation}

The last relation tells us, that, for fixed $s$, $\gamma$ is a [primitive or antiderivative](https://en.wikipedia.org/wiki/Primitive_function) of the holomorphic function $z^{s-1} e^{-z}$. Consequently, for any complex $u, v \ne 0$,

$$\int_u^v t^{s-1}\,e^{-t}\, dt = \gamma(s,v) - \gamma(s,u)$$

holds, as long as the [path of integration](wikipedia://en/21245414) is entirely contained in the domain of a branch of the integrand. If, additionally, the real part of $s$ is positive, then the limit $\gamma(s, u) \to 0$ for $u \to 0$ applies, finally arriving at the complex integral definition of $\gamma$[^o7]

$$\gamma(s, z) = \int_0^z t^{s-1}\,e^{-t}\, dt, \, \Re(s) > 0.$$

Any path of integration containing 0 only at its beginning, otherwise restricted to the domain of a branch of the integrand, is valid here, for example, the straight line connecting $0$ and $z$.

##### Limit for $z \to +\infty$ {#Limit_for}

###### Real values {#Real_values}

Given the integral representation of a principal branch of $\gamma$, the following equation holds for all positive real $s$, $x$:[^o24]

$$\Gamma(s) = \int_0^\infty t^{s-1}\,e^{-t}\, dt = \lim_{x \to \infty} \gamma(s, x)$$

###### *s* complex {#s_complex}

This result extends to complex $s$. Assume first $1 \le \operatorname{Re}(s) \le 2$ and $1 < a < b$. Then

$$\left|\gamma(s, b) - \gamma(s, a)\right| \le \int_a^b \left|t^{s-1}\right| e^{-t}\, dt = \int_a^b t^{\Re s-1} e^{-t}\, dt \le \int_a^b t e^{-t}\, dt$$

where[^o26]

$$\left|z^s\right| = \left|z\right|^{\Re s} \, e^{-\Im s\arg z}$$

has been used in the middle. Since the final integral becomes arbitrarily small if only $a$ is large enough, $\gamma(s, x)$ converges uniformly for $x \to \infty$ on the strip $1 \le \operatorname{Re}(s) \le 2$ towards a holomorphic function,[^o11] which must be Γ(s) because of the identity theorem. Taking the limit in the recurrence relation $\gamma(s, x) = (s - 1) \gamma(s - 1, x) - x^{s - 1} e^{-x}$ and noting, that lim $x^{n} e^{-x} = 0$ for $x \to \infty$ and all $n$, shows, that $\gamma(s, x)$ converges outside the strip, too, towards a function obeying the recurrence relation of the Γ-function. It follows

$$\Gamma(s) = \lim_{x \to \infty} \gamma(s, x)$$

for all complex $s$ not a non-positive integer, $x$ real and $\gamma$ principal.

###### Sectorwise convergence {#Sectorwise_convergence}

Now let $u$ be from the sector $\lvert \arg z\rvert < \delta < \pi/2$ with some fixed $\delta$ ($\alpha = 0$), $\gamma$ be the principal branch on this sector, and look at

$$\Gamma(s) - \gamma(s, u) = \Gamma(s) - \gamma(s, |u|) + \gamma(s, |u|) - \gamma(s, u).$$

As shown above, the first difference can be made arbitrarily small, if $\lvert u\rvert$ is sufficiently large. The second difference allows for following estimation:

$$\left|\gamma(s, |u|) - \gamma(s, u)\right| \le \int_u^{|u|} \left|z^{s-1} e^{-z}\right| dz = \int_u^{|u|} \left|z\right|^{\Re s - 1} \, e^{-\Im s\,\arg z} \, e^{-\Re z} \, dz,$$

where we made use of the integral representation of $\gamma$ and the formula about $\lvert z^{s}\rvert$ above. If we integrate along the arc with radius $R = \lvert u\rvert$ around 0 connecting $u$ and $\lvert u\rvert$, then the last integral is

$$\le R \left|\arg u\right| R^{\Re s - 1}\, e^{\Im s\,|\arg u|}\,e^{-R\cos\arg u} \le \delta\,R^{\Re s}\,e^{\Im s\,\delta}\,e^{-R\cos\delta} = M\,(R\,\cos\delta)^{\Re s}\,e^{-R\cos\delta}$$

where $M = \delta(\cos \delta)^{-\operatorname{Re} s} e^{\operatorname{Im} s\delta}$ is a constant independent of $u$ or $R$. Again referring to the behavior of $x^{n} e^{-x}$ for large $x$, we see that the last expression approaches 0 as $R$ increases towards $\infty$. In total we now have:

$$\Gamma(s) = \lim_{|z| \to \infty} \gamma(s, z), \quad \left|\arg z\right| < \pi/2 - \epsilon,$$

if $s$ is not a non-negative integer, $0 < \varepsilon < \pi/2$ is arbitrarily small, but fixed, and $\gamma$ denotes the principal branch on this domain.

##### Overview {#Overview}

$\gamma(s, z)$ is:

- [entire](wikipedia://en/10372) in $z$ for fixed, positive integer $s$;
- multi-valued [holomorphic](wikipedia://en/14110) in $z$ for fixed $s$ not an integer, with a [branch point](wikipedia://en/483173) at $z = 0$;
- on each branch [meromorphic](https://en.wikipedia.org/wiki/Meromorphic) in $s$ for fixed $z \ne 0$, with simple poles at non-positive integers s.

#### Upper incomplete gamma function {#Upper_incomplete_gamma_function}

As for the **upper incomplete gamma function**, a [holomorphic](wikipedia://en/14110) extension, with respect to $z$ or $s$, is given by[^o7]

$$\Gamma(s,z) = \Gamma(s) - \gamma(s, z)$$

at points $(s, z)$, where the right hand side exists. Since $\gamma$ is multi-valued, the same holds for $\Gamma$, but a restriction to principal values only yields the single-valued principal branch of $\Gamma$.

When $s$ is a non-positive integer in the above equation, neither part of the difference is defined, and a [limiting process](wikipedia://en/285759), here developed for $s \to 0$, fills in the missing values. [Complex analysis](wikipedia://en/5759) guarantees [holomorphicity](wikipedia://en/14110), because $\Gamma(s,z)$ proves to be [bounded](wikipedia://en/311509) in a [neighbourhood](wikipedia://en/1529485) of that limit for a fixed $z$.

To determine the limit, the power series of $\gamma^*$ at $z = 0$ is useful. When replacing $e^{-x}$ by its power series in the integral definition of $\gamma$, one obtains (assume $x$,$s$ positive reals for now):

$$\begin{aligned} \gamma(s, x) &= \int_0^x t^{s-1} e^{-t} \, dt = \int_0^x \sum_{k=0}^\infty \left(-1\right)^k \, \frac{t^{s+k-1}}{k!} \, dt \\[1ex] &= \sum_{k=0}^\infty \left(-1\right)^k \, \frac{x^{s+k}}{k!(s+k)} = x^s\,\sum_{k=0}^\infty \frac{(-x)^k}{k!(s+k)} \end{aligned}$$

or[^o12]

$$\gamma^*(s,x) = \sum_{k=0}^\infty \frac{(-x)^k}{k!\,\Gamma(s)(s+k)},$$

which, as a series representation of the entire $\gamma^*$ function, converges for all complex $x$ (and all complex $s$ not a non-positive integer).

With its restriction to real values lifted, the series allows the expansion:

$$\begin{aligned} \gamma(s, z) - \frac{1}{s} &= - \frac{1}{s} + z^s\,\sum_{k=0}^\infty \frac{(-z)^k}{k!(s+k)} \\[1ex] &= \frac{z^s-1}{s} + z^s\, \sum_{k=1}^\infty \frac{\left(-z\right)^k}{k!(s+k)}, & \Re(s) > -1, \,s \ne 0. \end{aligned}$$

When $s \to 0$:[^o30]

$$\frac{z^s-1}{s} \to \ln(z),\quad \Gamma(s) - \frac{1}{s} = \frac{1}{s} - \gamma + O(s) - \frac{1}{s} \to -\gamma,$$

($\gamma$ is the [Euler–Mascheroni constant](https://en.wikipedia.org/wiki/Euler–Mascheroni_constant) here), hence,

$$\begin{aligned} \Gamma(0,z) &= \lim_{s \to 0}\left(\Gamma(s) - \tfrac{1}{s} - \left(\gamma(s, z) - \tfrac{1}{s}\right)\right) \\ &= -\gamma - \ln(z) - \sum_{k=1}^\infty \frac{\left(-z\right)^k}{k\,(k!)} \end{aligned}$$

is the limiting function to the upper incomplete gamma function as $s \to 0$, also known as the [exponential integral](wikipedia://en/648614) $E_1(z)$.[^o31]

By way of the recurrence relation, values of $\Gamma(-n, z)$ for positive integers $n$ can be derived from this result,[^o32]

$$\Gamma(-n, z) = \frac{1}{n!} \left(\frac{e^{-z}}{z^n} \sum_{k = 0}^{n - 1} (-1)^k (n - k - 1)! \, z^k + \left(-1\right)^n \Gamma(0, z)\right)$$

so the upper incomplete gamma function proves to exist and be holomorphic, with respect both to $z$ and $s$, for all $s$ and $z \ne 0$.

$\Gamma(s, z)$ is:

- [entire](wikipedia://en/10372) in $z$ for fixed, positive integral $s$;
- multi-valued [holomorphic](wikipedia://en/14110) in $z$ for fixed $s$ non zero and not a positive integer, with a [branch point](wikipedia://en/483173) at $z = 0$;
- equal to $\Gamma(s)$ for $s$ with positive real part and $z = 0$ (the limit when $(s_i,z_i) \to (s, 0)$), but this is a continuous extension, not an [analytic one](wikipedia://en/80842) (**does not** hold for real $s < 0$!);
- on each branch [entire](wikipedia://en/10372) in $s$ for fixed $z \ne 0$.

### Special values {#Special_values}

- $\Gamma(s+1,1) = \frac{\lfloor e s! \rfloor}{e}$ if $s$ is a positive [integer](wikipedia://en/14563),
- $\Gamma(s,x) = (s-1)!\, e^{-x} \sum_{k=0}^{s-1} \frac{x^k}{k!}$ if $s$ is a positive [integer](wikipedia://en/14563),[^o34]
- $$\Gamma(s,0) = \Gamma(s), \Re(s) > 0,$$
- $$\Gamma(1,x) = e^{-x},$$
- $$\gamma(1,x) = 1 - e^{-x},$$
- $\Gamma(0,x) = -\operatorname{Ei}(-x)$ for $x > 0$,
- $$\Gamma(s,x) = x^s \operatorname{E}_{1-s}(x),$$
- $$\Gamma\left(\tfrac{1}{2}, x\right) = \sqrt\pi \operatorname{erfc}\left(\sqrt x\right),$$
- $$\gamma\left(\tfrac{1}{2}, x\right) = \sqrt\pi \operatorname{erf}\left(\sqrt x\right).$$

Here, $\operatorname{Ei}$ is the [exponential integral](wikipedia://en/648614), $\operatorname{E}_n$ is the [generalized exponential integral](wikipedia://en/648614#Relation_with_other_functions), $\operatorname{erf}$ is the [error function](wikipedia://en/177111), and $\operatorname{erfc}$ is the [complementary error function](https://en.wikipedia.org/wiki/Complementary_error_function), $\operatorname{erfc}(x) = 1 - \operatorname{erf}(x)$.

### Asymptotic behavior {#Asymptotic_behavior}

- $\frac{\gamma(s,x)}{x^s} \to \frac{1}{s}$ as $x \to 0$,
- $\frac{\Gamma(s,x)}{x^s} \to -\frac{1}{s}$ as $x \to 0$ and $\Re (s) < 0$ (for real $s$, the error of $\Gamma(s, x) \sim -x^{s} / s$ is on the order of $O(x^{\min\{s + 1, 0\}})$ if $s \ne -1$ and $O(\ln(x))$ if $s = -1$),
- $\Gamma(s,x) \sim \Gamma(s) - \sum_{n=0}^\infty (-1)^n \frac{x^{s+n}}{n!(s+n)}$ as an [asymptotic series](https://en.wikipedia.org/wiki/Asymptotic_series) where $x\to0^+$ and $s\neq 0,-1,-2,\dots$.[^o36]
- $\Gamma(-N,x) \sim C_N + \frac{(-1)^{N+1}}{N!} \ln x - \sum_{n=0,n\ne N}^\infty (-1)^n \frac{x^{n-N}}{n!(n-N)}$ as an [asymptotic series](https://en.wikipedia.org/wiki/Asymptotic_series) where $x \to 0^+$ and $N = 1, 2, \dots$, where $C_N = \frac{(-1)^{N+1}}{N!} \left( \gamma - \displaystyle\sum_{n=1}^N \frac{1}{n} \right)$, where $\gamma$ is the [Euler-Mascheroni constant](https://en.wikipedia.org/wiki/Euler-Mascheroni_constant).[^o36]
- $\gamma(s,x) \to \Gamma(s)$ as $x \to \infty$.[^o37]
- $\frac{\Gamma(s,x)}{x^{s-1} e^{-x}} \to 1$ as $x \to \infty$ [^o38],
- if $s$ ≥ 0 is real-valued, $\Gamma(s,z) \sim z^{s-1} e^{-z} \sum_{k=0} \frac {\Gamma(s)} {\Gamma(s-k)} z^{-k}$ as an [asymptotic series](https://en.wikipedia.org/wiki/Asymptotic_series) where $|z| \to \infty$ and $\left|\arg z\right| < \tfrac{3}{2} \pi$.[^o39]

:::

## Evaluation formulae {#Evaluation_formulae}

The lower gamma function can be evaluated using the power series expansion:[^o41]

$$\gamma(s, z) = \sum_{k=0}^\infty \frac{z^s e^{-z} z^k}{s (s+1) \dots (s+k)}=z^s e^{-z}\sum_{k=0}^\infty\dfrac{z^k}{s^{\overline{k+1}}}$$

where $s^{\overline{k+1}}$ is the [Pochhammer symbol](wikipedia://en/230193).

An alternative expansion is

$$\gamma(s,z)= \sum_{k=0}^\infty \frac{(-1)^k}{k!} \frac{z^{s+k}}{s+k}= \frac{z^s}{s} M(s, s+1,-z),$$

where $M$ is Kummer's [confluent hypergeometric function](wikipedia://en/1516095).

### Connection with Kummer's confluent hypergeometric function {#Connection_with_Kummer's_confluent_hypergeometric_function}

When the real part of $z$ is positive,

$$\gamma(s,z) = s^{-1} z^s e^{-z} M(1,s+1,z)$$

where

$$M(1, s+1, z) = 1 + \frac{z}{(s+1)} + \frac{z^2}{(s+1)(s+2)} + \frac{z^3}{(s+1)(s+2)(s+3)} + \cdots$$

has an infinite radius of convergence.

Again with [confluent hypergeometric functions](https://en.wikipedia.org/wiki/Confluent_hypergeometric_functions) and employing Kummer's identity,

$$\begin{aligned} \Gamma(s,z) &= e^{-z} U(1{-}s, 1{-}s, z) = \frac{z^s e^{-z}}{\Gamma(1-s)} \int_0^\infty \frac{e^{-u}}{u^s (z+u)} du \\ &= e^{-z} z^s U(1,1{+}s,z) = e^{-z} \int_0^\infty e^{-u} (z+u)^{s-1} du \\ &= e^{-z} z^s \int_0^\infty e^{-z u} (1+u)^{s-1} du. \end{aligned}$$

For the actual computation of numerical values, [Gauss's continued fraction](wikipedia://en/11771113) provides a useful expansion:

$$\gamma(s, z) = \cfrac{z^s e^{-z}}{s - \cfrac{s z}{s+1 + \cfrac{z}{s+2 - \cfrac{(s+1)z} {s+3 + \cfrac{2z}{s+4 - \cfrac{(s+2)z}{s+5 + \cfrac{3z}{s+6 - \ddots}}}}}}}.$$

This continued fraction converges for all complex $z$, provided only that $s$ is not a negative integer.

The upper gamma function has the continued fraction[^o43]

$$\Gamma(s, z) = \cfrac{z^s e^{-z}}{z+\cfrac{1-s}{1 + \cfrac{1}{z + \cfrac{2-s} {1 + \cfrac{2}{z+ \cfrac{3-s}{1+ \ddots}}}}}}$$

and

$$\Gamma(s, z)= \cfrac{z^s e^{-z}}{1+z-s+ \cfrac{s-1}{3+z-s+ \cfrac{2(s-2)}{5+z-s+ \cfrac{3(s-3)} {7+z-s+ \cfrac{4(s-4)}{9+z-s+ \ddots}}}}}$$

::: {#o45 .statement kind=statement/theorem cue=named-heading name="Multiplication theorem"}

### Multiplication theorem {#Multiplication_theorem}

The following [multiplication theorem](wikipedia://en/8720712) holds true:

$$\begin{aligned} \Gamma(s,z) &= \frac 1 {t^s} \sum_{i=0}^{\infty} \frac{\left(1-\frac 1 t \right)^i}{i!} \Gamma(s+i,t z) \\ &= \Gamma(s,t z) -(t z)^s e^{-t z} \sum_{i=1}^{\infty} \frac{\left(\frac 1 t-1 \right)^i}{i} L_{i-1}^{(s-i)}(t z). \end{aligned}$$

:::

### Software implementation {#Software_implementation}

The incomplete gamma functions are available in various of the [computer algebra systems](wikipedia://en/54427).

Even if unavailable directly, however, incomplete function values can be calculated using functions commonly included in [spreadsheets](https://en.wikipedia.org/wiki/Spreadsheet) (and computer algebra packages). In [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), for example, these can be calculated using the [gamma function](wikipedia://en/12316) combined with the [gamma distribution](wikipedia://en/207079) function.

- The lower incomplete function: $\gamma(s, x)$ `= EXP(GAMMALN(s))*GAMMA.DIST(x,s,1,TRUE)`.
- The upper incomplete function: $\Gamma(s, x)$ `= EXP(GAMMALN(s))*(1-GAMMA.DIST(x,s,1,TRUE))`.

These follow from the definition of the [gamma distribution's cumulative distribution function](wikipedia://en/207079#Cumulative_distribution_function).

In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), the Scipy library provides implementations of incomplete gamma functions under scipy.special, however, it does not support negative values for the first argument. The function gammainc from the mpmath library supports all complex arguments.

## Regularized gamma functions and Poisson random variables {#Regularized_gamma_functions_and_Poisson_random_variables}

Two related functions are the regularized gamma functions:

$$\begin{aligned} P(s,x) &= \frac{\gamma(s,x)}{\Gamma(s)}, \\[1ex] Q(s,x) &= \frac{\Gamma(s,x)}{\Gamma(s)} = 1 - P(s,x). \end{aligned}$$

$P(s,x)$ is the [cumulative distribution function](wikipedia://en/5793) for [gamma random variables](wikipedia://en/207079) with [shape parameter](wikipedia://en/9210865) $s$ and [scale parameter](wikipedia://en/769503) 1.

When $s$ is an integer, $Q(s+1, \lambda)$ is the cumulative distribution function for [Poisson random variables](https://en.wikipedia.org/wiki/Poisson_random_variable): If $X$ is a $\mathrm{Poi}(\lambda)$ random variable then

$$\Pr(X \leq s) = \sum_{i \leq s} e^{-\lambda} \frac{\lambda^i}{i!} = \frac{\Gamma(s+1,\lambda)}{\Gamma(s+1)} = Q(s+1,\lambda).$$

This formula can be derived by repeated integration by parts.

$P(s,x)$ and $Q(s, x)$ are implemented as `gammainc`[^o49] and `gammaincc`[^o50] in [scipy](https://en.wikipedia.org/wiki/Scipy).

:::

## Partial derivatives {#Partial_derivatives}

Using the integral representation above, the derivative of the upper incomplete gamma function $\Gamma (s,x)$ with respect to $x$ is

$$\frac{\partial \Gamma (s,x) }{\partial x} = - x^{s-1} e^{-x}$$

The derivative with respect to its first argument $s$ is given by[^o52]

$$\frac{\partial \Gamma (s,x) }{\partial s} = \ln x \Gamma (s,x) + x\,T(3,s,x)$$

and the [second derivative](wikipedia://en/3224219) by

$$\frac{\partial^2 \Gamma (s,x) }{\partial s^2} = \ln^2 x \Gamma (s,x) + 2 x \left[\ln x\,T(3,s,x) + T(4,s,x) \right]$$

where the function $T(m,s,x)$ is a special case of the [Meijer G-function](wikipedia://en/6453527)

$$T(m,s,x) = G_{m-1,\,m}^{\,m,\,0} \!\left( \left. \begin{matrix} 0, 0, \dots, 0 \\ s-1, -1, \dots, -1 \end{matrix} \; \right| \, x \right).$$

This particular special case has internal *closure* properties of its own because it can be used to express *all* successive derivatives. In general,

$$\frac{\partial^m \Gamma (s,x) }{\partial s^m} = \ln^m x \Gamma (s,x) + m x\,\sum_{n=0}^{m-1} P_n^{m-1} \ln^{m-n-1} x\,T(3+n,s,x)$$

where $P_j^n$ is the [permutation](wikipedia://en/44027) defined by the [Pochhammer symbol](https://en.wikipedia.org/wiki/Pochhammer_symbol):

$$P_j^n = \binom{n}{j} j! = \frac{n!}{(n-j)!}.$$

All such derivatives can be generated in succession from:

$$\frac{\partial T (m,s,x) }{\partial s} = \ln x ~ T(m,s,x) + (m-1) T(m+1,s,x)$$

and

$$\frac{\partial T (m,s,x) }{\partial x} = -\frac{T(m-1,s,x) + T(m,s,x)}{x}$$

This function $T(m,s,x)$ can be computed from its series representation valid for $|z| < 1$,

$$T(m,s,z) = - \frac{\left(-1\right)^{m-1} }{(m-2)! } \left.\frac{d^{m-2} }{dt^{m-2} } \left[\Gamma (s-t) z^{t-1}\right]\right|_{t=0} + \sum_{n=0}^{\infty} \frac{\left(-1\right)^n z^{s-1+n}}{n! \left(-s-n\right)^{m-1} }$$

with the understanding that $s$ is not a negative integer or zero. In such a case, one must use a limit. Results for $|z| \ge 1$ can be obtained by [analytic continuation](wikipedia://en/80842). Some special cases of this function can be simplified. For example, $T(2,s,x)=\Gamma(s,x)/x$, $x\,T(3,1,x) = \mathrm{E}_1(x)$, where $\mathrm{E}_1(x)$ is the [exponential integral](wikipedia://en/648614). These derivatives and the function $T(m,s,x)$ provide exact solutions to a number of integrals by repeated differentiation of the integral definition of the upper incomplete gamma function.[^o53][^o54] For example,

$$\int_{x}^{\infty} \frac{t^{s-1} \ln^m t}{e^t} dt= \frac{\partial^m}{\partial s^m} \int_{x}^{\infty} \frac{t^{s-1}}{e^t} dt = \frac{\partial^m}{\partial s^m} \Gamma (s,x)$$

This formula can be further *inflated* or generalized to a huge class of [Laplace transforms](wikipedia://en/18610) and [Mellin transforms](wikipedia://en/387297). When combined with a [computer algebra system](wikipedia://en/54427), the exploitation of special functions provides a powerful method for solving definite integrals, in particular those encountered by practical engineering applications (see [Symbolic integration](wikipedia://en/1652672) for more details).

## Indefinite and definite integrals {#Indefinite_and_definite_integrals}

The following indefinite integrals are readily obtained using [integration by parts](wikipedia://en/147252) (with the [constant of integration](wikipedia://en/147939) omitted in both cases):

$$\begin{aligned} \int x^{b-1} \gamma(s,x) \, dx &= \frac{1}{b} \left( x^b \gamma(s,x) - \gamma(s+b,x) \right), \\[1ex] \int x^{b-1} \Gamma(s,x) \, dx &= \frac{1}{b} \left( x^b \Gamma(s,x) - \Gamma(s+b,x) \right). \end{aligned}$$

The lower and the upper incomplete gamma function are connected via the [Fourier transform](wikipedia://en/52247):

$$\int_{-\infty}^\infty \frac {\gamma\left(\frac s 2, z^2 \pi \right)} {(z^2 \pi)^\frac s 2} e^{-2 \pi i k z} dz = \frac {\Gamma\left(\frac {1-s} 2, k^2 \pi \right)} {(k^2 \pi)^\frac {1-s} 2}.$$

This follows, for example, by suitable specialization of (Gradshteyn Ryzhik Geronimus Tseytlin 2015, §7.642).
