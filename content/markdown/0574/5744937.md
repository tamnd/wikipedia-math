# Arc (projective geometry)

::: {#o1 .subject cue=lead name="Arc"}

*Image: Hyperoval in Fano plane.svg.* The red points are a 4-arc in [Fano plane](wikipedia://en/390404), the projective plane of order 2.

A (simple) **arc** in finite [projective geometry](wikipedia://en/243849) is a set of points which satisfies, in an intuitive way, a feature of *curved* figures in [continuous geometries](wikipedia://en/32590824). Loosely speaking, they are sets of points that are far from "line-like" in a plane or far from "plane-like" in a three-dimensional space. In this finite setting it is typical to include the number of points in the set in the name, so these simple arcs are called $\boldsymbol{k}$-**arcs**. An important generalization of $k$-arcs, also referred to as arcs in the literature, is the ($k, d$)-arcs.

:::

## $k$-arcs in a projective plane {#-arcs_in_a_projective_plane}

In a finite [projective plane](wikipedia://en/24350) $\pi$ (not necessarily [Desarguesian](https://en.wikipedia.org/wiki/Desarguesian)) a set $A$ of $k (k \ge 3)$ points such that no three points of $A$ are [collinear](https://en.wikipedia.org/wiki/Collinear_points) (on a line) is called a $\boldsymbol{k - arc}$. If the plane $\pi$ has order $q$ then $k \le q + 2$, however the maximum value of $k$ can only be achieved if $q$ is even.[^o3] In a plane of order $q$, a $(q + 1)$-arc is called an **[oval](wikipedia://en/4255174)** and, if $q$ is even, a $(q + 2)$-arc is called a **[hyperoval](wikipedia://en/4255174)**.

Every conic in the Desarguesian projective plane PG(2,$q$), i.e., the set of zeros of an irreducible homogeneous quadratic equation, is an oval. A celebrated result of [Beniamino Segre](wikipedia://en/3534031) states that when $q$ is odd, every $(q + 1)$-arc in PG(2,$q$) is a conic ([Segre's theorem](wikipedia://en/49713321)). This is one of the pioneering results in [finite geometry](wikipedia://en/267061).

If $q$ is even and $A$ is a $(q + 1)$-arc in $\pi$, then it can be shown via combinatorial arguments that there must exist a unique point in $\pi$ (called the **nucleus** of $A$) such that the union of $A$ and this point is a ($q$ + 2)-arc. Thus, every oval can be uniquely extended to a hyperoval in a finite projective plane of even order.

A $k$-arc which can not be extended to a larger arc is called a ***complete arc***. In the Desarguesian projective planes, PG(2,$q$), no $q$-arc is complete, so they may all be extended to ovals.[^o4]

## $k$-arcs in a projective space {#-arcs_in_a_projective_space}

In the finite [projective space](wikipedia://en/242135) PG($n, q$) with $n \ge 3$, a set $A$ of $k \ge n + 1$ points such that no $n + 1$ points lie in a common [hyperplane](https://en.wikipedia.org/wiki/Hyperplane_%28geometry%29) is called a (spatial) $\boldsymbol{k}$-**arc**. This definition generalizes the definition of a $k$-arc in a plane (where $n = 2$).

## ($k, d$)-arcs in a projective plane {#()-arcs_in_a_projective_plane}

A ($k, d$)-**arc** ($k, d > 1$) in a finite [projective plane](wikipedia://en/24350) $\pi$ (not necessarily [Desarguesian](https://en.wikipedia.org/wiki/Desarguesian)) is a set, $A$ of $k$ points of $\pi$ such that each line intersects $A$ in at most $d$ points, and there is at least one line that does intersect $A$ in $d$ points. A ($k, 2$)-arc is a **$k$-arc** and may be referred to as simply an **arc** if the size is not a concern.

The number of points $k$ of a ($k, d$)-arc $A$ in a projective plane of order $q$ is at most $qd + d - q$. When equality occurs, one calls $A$ a **[maximal arc](https://en.wikipedia.org/wiki/Maximal_arc)**.

Hyperovals are maximal arcs. Complete arcs need not be maximal arcs.
