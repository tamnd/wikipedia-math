# Kaniadakis exponential distribution

::: {#o1 .subject cue=lead name="Kaniadakis exponential distribution"}

The **Kaniadakis exponential distribution** (or ***κ*-exponential distribution)** is a [probability distribution](wikipedia://en/23543) arising from the maximization of the [Kaniadakis entropy](https://en.wikipedia.org/wiki/Kaniadakis_entropy) under appropriate constraints. It is one example of a [Kaniadakis distribution](wikipedia://en/71322459). The *κ*-exponential is a generalization of the [exponential distribution](wikipedia://en/45906) in the same way that Kaniadakis entropy is a generalization of standard [Boltzmann–Gibbs entropy](wikipedia://en/4701125) or [Shannon entropy](wikipedia://en/15445).[^o2] The *κ*-exponential distribution of Type I is a particular case of the [*κ*-Gamma distribution](https://en.wikipedia.org/wiki/Kaniadakis_Gamma_distribution), whilst the *κ*-exponential distribution of Type II is a particular case of the [*κ*-Weibull distribution](wikipedia://en/71231546).

:::

## Type I {#Type_I}

### Probability density function {#Probability_density_function}

The Kaniadakis *κ*-exponential distribution of Type I is part of a class of [statistical distributions](https://en.wikipedia.org/wiki/Statistical_distributions) emerging from the [Kaniadakis κ-statistics](wikipedia://en/70596336) which exhibit power-law tails. This distribution has the following [probability density function](wikipedia://en/43487):[^o5]

$$f_{_{\kappa}}(x) = (1 - \kappa^2) \beta \exp_\kappa(-\beta x)$$

valid for $x \ge 0$, where $0 \leq |\kappa| < 1$ is the entropic index associated with the [Kaniadakis entropy](wikipedia://en/70596336) and $\beta > 0$ is known as [rate parameter](https://en.wikipedia.org/wiki/Rate_parameter). The [exponential distribution](wikipedia://en/45906) is recovered as $\kappa \rightarrow 0.$

### Cumulative distribution function {#Cumulative_distribution_function}

The [cumulative distribution function](wikipedia://en/5793) of *κ*-exponential distribution of Type I is given by

$$F_\kappa(x) = 1-\Big(\sqrt{1+\kappa^2\beta^2 x^2} + \kappa^2 \beta x \Big)\exp_k({-\beta x)}$$

for $x \ge 0$. The cumulative [exponential distribution](wikipedia://en/45906) is recovered in the classical limit $\kappa \rightarrow 0$.

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

#### Moments, expectation value and variance {#Moments,_expectation_value_and_variance}

The *κ*-exponential distribution of type I has moment of order $m \in \mathbb{N}$ given by[^o5]

$$\operatorname{E}[X^m] = \frac{1 - \kappa^2}{\prod_{n=0}^{m+1} [1-(2n-m-1) \kappa ]} \frac{m!}{\beta^m}$$

where $f_\kappa(x)$ is finite if $0 < m + 1 < 1/\kappa$.

The expectation is defined as:

$$\operatorname{E}[X] = \frac{1}{\beta} \frac{1 - \kappa^2}{1 - 4\kappa^2}$$

and the variance is:

$$\operatorname{Var}[X] = \sigma_\kappa^2 = \frac{1}{\beta^2} \frac{2(1-4\kappa^2)^2 - (1 - \kappa^2)^2(1-9\kappa^2)}{(1-4\kappa^2)^2(1-9\kappa^2)}$$

#### Kurtosis {#Kurtosis}

The [kurtosis](wikipedia://en/16848) of the *κ*-exponential distribution of type I may be computed thought:

$$\operatorname{Kurt}[X] = \operatorname{E}\left[\frac{\left[ X - \frac{1}{\beta} \frac{1 - \kappa^2}{1 - 4\kappa^2}\right]^4}{\sigma_\kappa^4}\right]$$

Thus, the [kurtosis](wikipedia://en/16848) of the *κ*-exponential distribution of type I distribution is given by:

> $$\operatorname{Kurt}[X] = \frac{ 9(1-\kappa^2)(1200\kappa^{14} - 6123\kappa^{12} + 562\kappa^{10} +1539 \kappa^8 - 544 \kappa^6 + 143 \kappa^4 -18\kappa^2 + 1 )}{ \beta^4 \sigma_\kappa^4 (1 - 4\kappa^2)^4 (3600\kappa^8 -4369\kappa^6 + 819\kappa^4 - 51\kappa^2 + 1) } \quad \text{for} \quad 0 \leq \kappa < 1/5$$

or

> $$\operatorname{Kurt}[X] = \frac{ 9(9\kappa^2-1)^2(\kappa^2-1)(1200\kappa^{14} - 6123\kappa^{12} + 562\kappa^{10} +1539 \kappa^8 - 544 \kappa^6 + 143 \kappa^4 -18\kappa^2 + 1 )}{ \beta^2 (1 - 4\kappa^2)^2(9\kappa^6 + 13\kappa^4 - 5\kappa^2 +1)(3600\kappa^8 -4369\kappa^6 + 819\kappa^4 - 51\kappa^2 + 1) } \quad \text{for} \quad 0 \leq \kappa < 1/5$$

The [kurtosis](wikipedia://en/16848) of the ordinary [exponential distribution](wikipedia://en/45906) is recovered in the limit $\kappa \rightarrow 0$.

#### Skewness {#Skewness}

The [skewness](wikipedia://en/28212) of the *κ*-exponential distribution of type I may be computed thought:

$$\operatorname{Skew}[X] = \operatorname{E}\left[\frac{\left[ X - \frac{1}{\beta} \frac{1 - \kappa^2}{1 - 4\kappa^2}\right]^3}{\sigma_\kappa^3}\right]$$

Thus, the [skewness](wikipedia://en/28212) of the *κ*-exponential distribution of type I distribution is given by:

> $$\operatorname{Shew}[X] = \frac{ 2 (1-\kappa^2) (144 \kappa^8+23 \kappa^6+27 \kappa^4-6 \kappa^2+1) }{ \beta^3 \sigma^3_\kappa (4 \kappa^2-1)^3 (144 \kappa^4-25 \kappa^2+1) } \quad \text{for} \quad 0 \leq \kappa < 1/4$$

The [kurtosis](wikipedia://en/16848) of the ordinary [exponential distribution](wikipedia://en/45906) is recovered in the limit $\kappa \rightarrow 0$.

:::

## Type II {#Type_II}

### Probability density function {#Probability_density_function}

The Kaniadakis *κ*-exponential distribution of Type II also is part of a class of [statistical distributions](https://en.wikipedia.org/wiki/Statistical_distributions) emerging from the [Kaniadakis κ-statistics](wikipedia://en/70596336) which exhibit power-law tails, but with different constraints. This distribution is a particular case of the [Kaniadakis *κ*-Weibull distribution](wikipedia://en/71231546) with $\alpha = 1$ is:[^o14]

$$f_{_{\kappa}}(x) = \frac{\beta}{\sqrt{1+\kappa^2 \beta^2 x^2}} \exp_\kappa(-\beta x)$$

valid for $x \ge 0$, where $0 \leq |\kappa| < 1$ is the entropic index associated with the [Kaniadakis entropy](wikipedia://en/70596336) and $\beta > 0$ is known as [rate parameter](https://en.wikipedia.org/wiki/Rate_parameter).

The [exponential distribution](wikipedia://en/45906) is recovered as $\kappa \rightarrow 0.$

### Cumulative distribution function {#Cumulative_distribution_function}

The [cumulative distribution function](wikipedia://en/5793) of *κ*-exponential distribution of Type II is given by

$$F_\kappa(x) = 1-\exp_k({-\beta x)}$$

for $x \ge 0$. The cumulative [exponential distribution](wikipedia://en/45906) is recovered in the classical limit $\kappa \rightarrow 0$.

::: {#o17 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

#### Moments, expectation value and variance {#Moments,_expectation_value_and_variance}

The *κ*-exponential distribution of type II has moment of order $m < 1/\kappa$ given by[^o14]

$$\operatorname{E}[X^m] = \frac{\beta^{-m} m!}{\prod_{n=0}^{m} [1-(2n- m) \kappa ]}$$

The expectation value and the variance are:

$$\operatorname{E}[X] = \frac{1}{\beta} \frac{1}{1 - \kappa^2}$$

$$\operatorname{Var}[X] = \sigma_\kappa^2 = \frac{1}{\beta^2} \frac{1+2 \kappa^4}{(1-4\kappa^2)(1-\kappa^2)^2}$$

The mode is given by:

$$x_{\textrm{mode}} = \frac{1}{\kappa \beta\sqrt{2(1-\kappa^2)}}$$

#### Kurtosis {#Kurtosis}

The [kurtosis](wikipedia://en/16848) of the *κ*-exponential distribution of type II may be computed thought:

$$\operatorname{Kurt}[X] = \operatorname{E}\left[\left(\frac{X - \frac{1}{\beta} \frac{1}{1 - \kappa^2} }{\sigma_\kappa} \right)^4 \right]$$

Thus, the [kurtosis](wikipedia://en/16848) of the *κ*-exponential distribution of type II distribution is given by:

$$\operatorname{Kurt}[X] = \frac{3 (72 \kappa^{10} - 360 \kappa^8 - 44 \kappa^6-32 \kappa^4+7 \kappa^2-3) }{ \beta^4 \sigma_\kappa^4 (\kappa^2 - 1)^4 (576 \kappa^6 - 244 \kappa^4 + 29 \kappa^2 - 1) } \quad \text{ for } \quad 0 \leq \kappa < 1/4$$

or

$$\operatorname{Kurt}[X] = \frac{3 (72 \kappa^{10} - 360 \kappa^8 - 44 \kappa^6-32 \kappa^4+7 \kappa^2-3) }{ (4\kappa^2-1)^{-1} (2 \kappa^4+1)^2 (144 \kappa^4-25 \kappa^2+1) } \quad \text{ for } \quad 0 \leq \kappa < 1/4$$

#### Skewness {#Skewness}

The [skewness](wikipedia://en/28212) of the *κ*-exponential distribution of type II may be computed thought:

$$\operatorname{Skew}[X] = \operatorname{E}\left[\frac{\left[ X - \frac{1}{\beta} \frac{1}{1 - \kappa^2}\right]^3}{\sigma_\kappa^3}\right]$$

Thus, the [skewness](wikipedia://en/28212) of the *κ*-exponential distribution of type II distribution is given by:

> $$\operatorname{Skew}[X] = -\frac{ 2 (15 \kappa^6+6 \kappa^4+2 \kappa^2+1) }{ \beta^3 \sigma_\kappa^3 (\kappa^2 - 1)^3 (36 \kappa^4 - 13 \kappa^2 + 1) } \quad \text{for} \quad 0 \leq \kappa < 1/3$$

or

> $$\operatorname{Skew}[X] = \frac{ 2 (15 \kappa^6+6 \kappa^4+2 \kappa^2+1) }{ (1 - 9\kappa^2)(2 \kappa^4 + 1) } \sqrt{ \frac{1 - 4\kappa^2 }{ 1 + 2\kappa^4 } } \quad \text{for} \quad 0 \leq \kappa < 1/3$$

The [skewness](wikipedia://en/28212) of the ordinary [exponential distribution](wikipedia://en/45906) is recovered in the limit $\kappa \rightarrow 0$.

#### Quantiles {#Quantiles}

The [quantiles](wikipedia://en/25184) are given by the following expression

> $$x_{\textrm{quantile}} (F_\kappa) = \beta^{-1} \ln_\kappa \Bigg(\frac{1}{1 - F_\kappa} \Bigg)$$

with $0 \leq F_\kappa \leq 1$, in which the median is the case :

> $$x_{\textrm{median}} (F_\kappa) = \beta^{-1} \ln_\kappa (2)$$

#### Lorenz curve {#Lorenz_curve}

The [Lorenz curve](wikipedia://en/18135) associated with the *κ*-exponential distribution of type II is given by:[^o14]

$$\mathcal{L}_\kappa(F_\kappa) = 1 + \frac{1 - \kappa}{2 \kappa}(1 - F_\kappa)^{1 + \kappa} - \frac{1 + \kappa}{2 \kappa}(1 - F_\kappa)^{1 - \kappa}$$

The [Gini coefficient](wikipedia://en/12883) is

> $$\operatorname{G}_\kappa = \frac{2 + \kappa^2}{4 - \kappa^2}$$

#### Asymptotic behavior {#Asymptotic_behavior}

The *κ*-exponential distribution of type II behaves [asymptotically](https://en.wikipedia.org/wiki/Asymptotically) as follows:[^o14]

$$\lim_{x \to +\infty} f_\kappa (x) \sim \kappa^{-1} (2 \kappa \beta)^{-1/\kappa} x^{(-1 - \kappa)/\kappa}$$

$$\lim_{x \to 0^+} f_\kappa (x) = \beta$$

:::

::: {#o25 .application cue=heading name="Applications"}

## Applications {#Applications}

The *κ*-exponential distribution has been applied in several areas, such as:

- In [geomechanics](https://en.wikipedia.org/wiki/Geomechanics), for analyzing the properties of rock masses;[^o26]
- In quantum theory, in physical analysis using [Planck's radiation law](https://en.wikipedia.org/wiki/Planck's_law);[^o27]
- In [inverse problems](wikipedia://en/203956), the *κ*-exponential distribution has been used to formulate a robust approach;[^o28]
- In [Network theory](wikipedia://en/766409).[^o29]
