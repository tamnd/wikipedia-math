# Cyclic sieving

*Image: Example of cyclic sieving with tableaux.svg.* A *q*-analogue of the [hook length formula](wikipedia://en/41497810) exhibits cyclic sieving, with evaluations at roots of unity counting the number of rectangular standard [Young tableaux](https://en.wikipedia.org/wiki/Young_tableaux) fixed by repeated applications of [jeu de taquin](wikipedia://en/17053866) promotion.

::: {#o1 .subject cue=lead name="Cyclic sieving"}

In [combinatorial mathematics](wikipedia://en/5170), **cyclic sieving** is a phenomenon in which an integer [polynomial](wikipedia://en/23000) evaluated at certain [roots of unity](wikipedia://en/171950) counts the rotational symmetries of a [finite set](wikipedia://en/11742).[^o2] Given a family of cyclic sieving phenomena, the polynomials give a [*q*-analogue](wikipedia://en/1619396) for the enumeration of the sets, and often arise from an underlying algebraic structure, such as a [representation](wikipedia://en/19378200).

:::

The first study of cyclic sieving was published by Reiner, Stanton and White in 2004.[^o3] The phenomenon generalizes the "*q* = −1 phenomenon" of [John Stembridge](https://en.wikipedia.org/wiki/John_Stembridge), which considers evaluations of the polynomial only at the first and second roots of unity (that is, *q* = 1 and *q* = −1).[^o4]

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

For every positive integer $n$, let $\omega_n$ denote the primitive $n$<sup>th</sup> root of unity $e^{2\pi i/n}$.

Let $X$ be a finite set with an [action](wikipedia://en/12781) of the cyclic group $C_n$, and let $f(q)$ be an [integer](wikipedia://en/14563) polynomial. The triple $(X,C_n,f(q))$ exhibits the **cyclic sieving phenomenon** (or **CSP**) if for every positive integer $d$ dividing $n$, the number of elements in $X$ fixed by the action of the subgroup $C_d$ of $C_n$ is equal to $f(\omega_d)$. If $C_n$ acts as rotation by $2\pi/n$, this counts elements in $X$ with $d$-fold [rotational symmetry](wikipedia://en/701096).

Equivalently, suppose $\sigma:X\to X$ is a [bijection](wikipedia://en/3942) on $X$ such that $\sigma^n=\rm{id}$, where $\rm{id}$ is the identity map. Then $\sigma$ induces an action of $C_n$ on $X$, where a given [generator](wikipedia://en/99945) $c$ of $C_n$ acts by $\sigma$. Then $(X,C_n,f(q))$ exhibits the cyclic sieving phenomenon if the number of elements in $X$ fixed by $\sigma^d$ is equal to $f(\omega_n^d)$ for every integer $d$.

:::

::: {#o8 .example cue=heading name="Example"}

## Example {#Example}

Let $X$ be the 2-element subsets of $\{1, 2, 3, 4\}$. Define a bijection $\sigma:X\to X$ which increases each element in the pair by one (and sends $4$ back to $1$). This induces an action of $C_4$ on $X$, which has an [orbit](wikipedia://en/12781#Orbits_and_stabilizers)

$$\{1,3\}\mapsto\{2,4\}\mapsto\{1,3\}$$

of size two and an orbit

$$\{1, 2\} \mapsto \{2, 3\} \mapsto \{3, 4\} \mapsto \{1, 4\} \mapsto \{1, 2\}$$

of size four. If $f(q)=1+q+2q^2+q^3+q^4$, then $f(1)=6$ is the number of elements in $X$, $f(i)=0$ counts fixed points of $\sigma$, $f(-1)=2$ is the number of fixed points of $\sigma^2$, and $f(-i)=0$ is the number of fixed points of $\sigma^3$. Hence, the triple $(X,C_4,f(q))$ exhibits the cyclic sieving phenomenon.

More generally, set $[n]_q:=1+q+\cdots+q^{n-1}$ and define the [*q*-binomial coefficient](https://en.wikipedia.org/wiki/Q-binomial_coefficient) by

$$\left[{n \atop k}\right]_q = \frac{[n]_q\cdots [2]_q[1]_q}{[k]_q\cdots [2]_q[1]_q[n-k]_q\cdots [2]_q[1]_q}.$$

which is an integer polynomial evaluating to the usual [binomial coefficient](wikipedia://en/4668) at $q=1$. For any positive integer $d$ dividing $n$,

$$\left[{n \atop k}\right]_{\omega_d} = \begin{cases}\left({n/d \atop k/d}\right)&\text{if }d\mid k,\\ 0 & \text{otherwise}.\end{cases}$$

If $X_{n,k}$ is the set of size-$k$ subsets of $\{1,\dots,n\}$ with $C_n$ acting by increasing each element in the subset by one (and sending $n$ back to $1$), and if $f_{n,k}(q)$ is the *q*-binomial coefficient above, then $(X_{n,k},C_n,f_{n,k}(q))$ exhibits the cyclic sieving phenomenon for every $0\leq k\leq n$.[^o9]

:::

## In representation theory {#In_representation_theory}

The cyclic sieving phenomenon can be naturally stated in the language of representation theory. The group action of $C_n$ on $X$ is linearly extended to obtain a representation, and the decomposition of this representation into irreducibles determines the required coefficients of the polynomial $f(q)$.[^o11]

Let $V=\mathbb{C}(X)$ be the [vector space](wikipedia://en/32370) over the [complex numbers](wikipedia://en/5826) with a [basis](https://en.wikipedia.org/wiki/Basis_%28mathematics%29) indexed by a finite set $X$. If the cyclic group $C_n$ acts on $X$, then linearly extending each action turns $V$ into a representation of $C_n$.

For a generator $c$ of $C_n$, its action on $\mathbb{C}(X)$ is given by a [permutation matrix](wikipedia://en/238849) $[c]$, and the [trace](wikipedia://en/43270) of $[c]^d$ counts the elements of $X$ fixed by $c^d$. In particular, the triple $(X,C_n,f(q))$ exhibits the cyclic sieving phenomenon if and only if $f(\omega_n^d)=\chi(c^d)$ for every $0\leq d<n$, where $\chi$ is the [character](wikipedia://en/293418#Character_of_a_representation) of $V$.

This gives a method for determining $f(q)$. For every integer $k$, let $V^{(k)}$ be the one-dimensional representation of $C_n$ in which $c$ acts as [scalar multiplication](wikipedia://en/244373) by $\omega_n^k$. For an integer polynomial $f(q)=\sum_{k\geq 0}m_kq^k$, the triple $(X,C_n,f(q))$ exhibits the cyclic sieving phenomenon if and only if

$$V\cong\bigoplus_{k\geq 0}m_kV^{(k)}.$$

## Further examples {#Further_examples}

### Words {#Words}

Let $W$ be a finite set of [words](wikipedia://en/20913490) of the form $w=w_1\cdots w_n$ where each letter $w_j$ is an integer and $W$ is closed under permutation (that is, if $w$ is in $W$, then so is any [anagram](https://en.wikipedia.org/wiki/Anagram) of $w$). The *major index* of a word $w$ is the sum of all indices $j$ such that $w_j>w_{j+1}$, and is denoted ${\rm{maj}}(w)$.

If $C_n$ acts on $W$ by rotating the letters of each word, and

$$f(q)=\sum_{w\in W}q^{{\rm{maj}}(w)}$$

then $(W,C_n,f(q))$ exhibits the cyclic sieving phenomenon.[^o15]

### Rectangular standard Young tableaux {#Rectangular_standard_Young_tableaux}

Let $\lambda$ be a [partition](wikipedia://en/104790) of size $n$ with rectangular shape, and let $X_\lambda$ be the set of [standard Young tableaux](wikipedia://en/683368) with shape $\lambda$. [Jeu de taquin](wikipedia://en/17053866) promotion gives an action of $C_n$ on $X$. Let $f(q)$ be the following *q*-analog of the [hook length formula](wikipedia://en/41497810):

$$f_\lambda(q)=\frac{[n]_q\cdots [1]_q}{\prod_{(i,j)\in \lambda} [h(i,j)]_q}.$$

Then $(X_\lambda,C_n,f_\lambda(q))$ exhibits the cyclic sieving phenomenon. If $\chi_\lambda$ is the character for the [irreducible representation of the symmetric group](wikipedia://en/874641) associated to $\lambda$, then $f_\lambda(\omega_n^d)=\pm\chi_\lambda(c^d)$ for every $0\leq d<n$, where $c$ is the [long cycle](wikipedia://en/44027#cycle_notation) $(12\cdots n)$.[^o17]

If $Y$ is the set of semistandard Young tableaux of shape $\lambda$ with entries in $\{1,\dots,k\}$, then promotion gives an action of the cyclic group $C_k$ on $Y_\lambda$. Define $\kappa(\lambda)=\sum_i(i-1)\lambda_i$ and

$$g(q)=q^{-\kappa(\lambda)}s_\lambda(1,q,\dots,q^{k-1}),$$

where $s_\lambda$ is the [Schur polynomial](wikipedia://en/3147062). Then $(Y,C_k,g(q))$ exhibits the cyclic sieving phenomenon.[^o18]

### Non-crossing configurations {#Non-crossing_configurations}

If $X$ is the set of non-crossing (1,2)-configurations of $\{1,\dots,n-1\}$, then $C_{n-1}$ acts on these by rotation. Let $f(q)$ be the following *q*-analog of the $n$<sup>th</sup> [Catalan number](wikipedia://en/216488):

$$f(q)=\frac{1}{[n+1]_q}\left[{2n \atop n}\right]_q.$$

Then $(X,C_{n-1},f(q))$ exhibits the cyclic sieving phenomenon.[^o20]

### Square semi-standard Young tableaux {#Square_semi-standard_Young_tableaux}

Let $X$ be the set of semi-standard Young tableaux of shape $(n,n)$ with maximal entry $2n-k$, where entries along each row and column are strictly increasing. If $C_{2n-k}$ acts on $X$ by $K$-promotion and

$$f(q)=q^{n+\binom{k}{2}} \frac{\left[{n-1 \atop k}\right]_q \left[{2n-k \atop n-k-1}\right]_q}{ [n-k]_q},$$

then $(X,C_{2n-k},f(q))$ exhibits the cyclic sieving phenomenon.[^o22]

### Permutations of a fixed cycle type {#Permutations_of_a_fixed_cycle_type}

Let $S_{\lambda,j}$ be the set of [permutations](https://en.wikipedia.org/wiki/Permutations) of cycle type $\lambda$ with exactly $j$ exceedances. Conjugation gives an action of $C_n$ on $S_{\lambda,j}$, and if

$$a_{\lambda,j}(q)=\sum_{\sigma \in S_{\lambda,j} }q^{\operatorname{maj}(\sigma)-j}$$

then $(S_{\lambda,j}, C_n, a_{\lambda,j}(q))$ exhibits the cyclic sieving phenomenon.[^o24]
