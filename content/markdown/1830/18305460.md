# Tutte matrix

::: {#o1 .subject cue=lead name="Tutte matrix"}

In [graph theory](wikipedia://en/12401), the **Tutte matrix** *A* of a [graph](wikipedia://en/325806) *G* = (*V*, *E*) is a [matrix](wikipedia://en/20556859) used to determine the existence of a [perfect matching](wikipedia://en/44031): that is, a set of [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) which is incident with each [vertex](wikipedia://en/638899) exactly once.

:::

If the set of vertices is $V = \{1, 2, \dots , n\}$ then the Tutte matrix is an *n*-by-*n* [skew-symmetric matrix](wikipedia://en/174055) *A* with entries

$$A_{ij} = \begin{cases} x_{ij}\;\;\mbox{if}\;(i,j) \in E \mbox{ and } i<j\\ -x_{ji}\;\;\mbox{if}\;(i,j) \in E \mbox{ and } i>j\\ 0\;\;\;\;\mbox{otherwise} \end{cases}$$

where the *x*<sub>*ij*</sub> are [indeterminates](https://en.wikipedia.org/wiki/Indeterminate_%28variable%29). The [determinant](wikipedia://en/8468) of this matrix is then a [polynomial](wikipedia://en/23000) (in the variables *x<sub>ij</sub>*, *i \< j* ): this coincides with the square of the [Pfaffian](wikipedia://en/530060) of the matrix *A* and is non-zero (as a polynomial) [if and only if](wikipedia://en/14922) a perfect matching exists. (This polynomial is not the [Tutte polynomial](wikipedia://en/3892303) of *G*.)

The Tutte matrix is named after [W. T. Tutte](wikipedia://en/52021), and is a generalisation of the [Edmonds matrix](wikipedia://en/11415890) for a balanced [bipartite graph](wikipedia://en/244431).
