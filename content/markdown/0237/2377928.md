# Oakley protocol

::: {#o1 .subject cue=lead name="Oakley protocol"}

The **Oakley Key Determination Protocol** is a [key-agreement protocol](wikipedia://en/63944) that allows authenticated parties to exchange keying material across an insecure connection using the [Diffie–Hellman key exchange](wikipedia://en/7903) algorithm. The protocol was proposed by Hilarie K. Orman in 1998, and formed the basis for the more widely used [Internet Key Exchange](https://en.wikipedia.org/wiki/Internet_Key_Exchange) protocol.[^o2][^o3]

:::

The Oakley protocol has also been implemented in [Cisco Systems](https://en.wikipedia.org/wiki/Cisco_Systems)' [ISAKMP](https://en.wikipedia.org/wiki/ISAKMP) [daemon](https://en.wikipedia.org/wiki/Daemon_%28computer_software%29).[^o4]
