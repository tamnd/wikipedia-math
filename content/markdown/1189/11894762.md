# Polyad (mathematics)

::: {#o1 .subject cue=lead name="Polyad"}

In mathematics, **polyad** is a concept of [category theory](wikipedia://en/5869) introduced by [Jean Bénabou](wikipedia://en/70081438) in generalising [monads](wikipedia://en/355140).[^o2] A **polyad** in a [bicategory](https://en.wikipedia.org/wiki/Bicategory) *D* is a bicategory morphism *Φ* from a locally punctual bicategory *C* to *D*, *Φ* : *C* → *D*. (A bicategory *C* is called locally punctual if all hom-categories *C*(*X*,*Y*) consist of one object and one morphism only.) Monads are polyads *Φ* : *C* → *D* where *C* has only one object.

:::
