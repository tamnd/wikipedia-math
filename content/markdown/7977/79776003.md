# Extension (simplicial set)

::: {#o1 .subject cue=lead name="Extension"}

In [higher category theory](wikipedia://en/5274013) in [mathematics](wikipedia://en/18831), the **extension** of [simplicial sets](wikipedia://en/1027784) (**extension functor** or **Ex functor**) is an [endofunctor](https://en.wikipedia.org/wiki/Endofunctor) on the [category of simplicial sets](https://en.wikipedia.org/wiki/Category_of_simplicial_sets). Due to many remarkable properties, the extension functor has plenty and strong applications in homotopical algebra. Among the most well-known is its application in the construction of [Kan complexes](https://en.wikipedia.org/wiki/Kan_complexes) from arbitrary simplicial sets, which often enables [without loss of generality](wikipedia://en/296000) to take the former for proofs about the latter. It is furthermore very well compatible with the [Kan–Quillen model structure](https://en.wikipedia.org/wiki/Kan–Quillen_model_structure) and can for example be used to explicitly state its factorizations or to search for [weak homotopy equivalences](wikipedia://en/34615176).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Using the [subdivision](wikipedia://en/79775996) of simplicial sets, the extension of simplicial sets is defined as:[^o4][^o5]

$$\operatorname{Ex}\colon \mathbf{sSet}\rightarrow\mathbf{sSet}, \operatorname{Ex}(Y)_n :=\operatorname{Hom}(\operatorname{Sd}(\Delta^n),Y).$$

Due to the [Yoneda lemma](wikipedia://en/34359), one also has $\operatorname{Ex}(Y)_n \cong\operatorname{Hom}(\Delta^n,\operatorname{Ex}(Y))$.[^o5] All connecting maps of the sets are given by precomposition with the application of the subdivision functor to all canonical inclusions $\Delta^{n-1}\hookrightarrow\Delta^n$. Since the subdivision functor by definition commutes with all [colimits](https://en.wikipedia.org/wiki/Colimits), and for every simplicial set $X$ there is an [isomorphism](wikipedia://en/14828):[^o6]

$$X\cong\varinjlim_{\Delta^n\rightarrow X}\Delta^n,$$

it is in fact [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint) to the extension functor, denoted $\operatorname{Sd}\dashv\operatorname{Ex}$.[^o5] For simplicial sets $X$ and $Y$, one has:

$$\begin{aligned} \operatorname{Hom}(\operatorname{Sd}(X),Y) &\cong\operatorname{Hom}(\operatorname{Sd}(\varinjlim_{\Delta^n\rightarrow X}\Delta^n),Y) \cong\operatorname{Hom}(\varinjlim_{\Delta^n\rightarrow X}\operatorname{Sd}(\Delta^n),Y) \cong\varprojlim_{\Delta^n\rightarrow X}\operatorname{Hom}(\operatorname{Sd}(\Delta^n),Y) \\ &\cong\varprojlim_{\Delta^n\rightarrow X}\operatorname{Hom}(\Delta^n,\operatorname{Ex}(Y)) \cong\operatorname{Hom}(\varinjlim_{\Delta^n\rightarrow X}\Delta^n,\operatorname{Ex}(Y)) \cong\operatorname{Hom}(X,\operatorname{Ex}(Y)). \end{aligned}$$

It is therefore possible to also simply define the extension functor as the right adjoint to the subdivision functor. Both of their construction as extension by colimits and definition is similar to that of the adjunction between [geometric realization](https://en.wikipedia.org/wiki/Geometric_realization_functor) and the singular functor, with an important difference being that there is **no** isomorphism:

$$X\cong\varinjlim_{|\Delta^n|\rightarrow X}|\Delta^n|$$

for every topological space $X$. This is because the colimit is always a [CW complex](wikipedia://en/353022), for which the isomorphism does indeed hold.

The [natural transformation](wikipedia://en/45022) $a\colon\operatorname{Sd}\Rightarrow\operatorname{Id}$ induces a natural transformation $b\colon \operatorname{Id}\Rightarrow\operatorname{Ex}$ under the adjunction $\operatorname{Sd}\dashv\operatorname{Ex}$. In particular there is a canonical morphism $b_X\colon X\rightarrow\operatorname{Ex}(X)$ for every simplicial set $X$.

:::

::: {#o8 .pointer-item cue=pointer name="Ex∞"}

## Ex∞ functor {#Ex∞_functor}

For a simplicial set $X$, the canonical morphism $b_X\colon X\rightarrow\operatorname{Ex}(X)$ includes an $\mathbb{N}$-shaped [cone](wikipedia://en/7533645) $X\rightarrow\operatorname{Ex}(X)\rightarrow\operatorname{Ex}^2(X)\rightarrow\operatorname{Ex}^3(X)\rightarrow\ldots$, whose [limit](wikipedia://en/39248) is denoted:[^o9][^o10]

$$\operatorname{Ex}^\infty(X) :=\varinjlim_{n\in\mathbb{N}}\operatorname{Ex}^n(X).$$

Since limit and colimit are switched, there is **no** adjunction $\operatorname{Sd}^\infty\dashv\operatorname{Ex}^\infty$ with the [Sd∞ functor](https://en.wikipedia.org/wiki/Sd∞_functor). But for the study of simplices, this is of no concern as any $m$-simplex $\Delta^m\rightarrow\operatorname{Ex}^\infty(X)$ due to the [compactness](https://en.wikipedia.org/wiki/Compactness) of the standard $m$-simplex $\Delta^m$ factors over a morphism $\Delta^m\rightarrow\operatorname{Ex}^n(X)$ for a $n\in\mathbb{N}$, for which the adjunction $\operatorname{Sd}^n\dashv\operatorname{Ex}^n$ can then be applied to get a morphism $\operatorname{Sd}^n(\Delta^m)\rightarrow X$.

The natural transformation $b\colon \operatorname{Id}\Rightarrow\operatorname{Ex}$ induces a natural transformation $\beta\colon \operatorname{Id}\Rightarrow\operatorname{Ex}^\infty$. In particular there is a canonical morphism $\beta_X\colon X\rightarrow\operatorname{Ex}^\infty(X)$ for every simplicial set $X$.

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- For every simplicial set $X$, the canonical morphism $b_X\colon X\rightarrow\operatorname{Ex}(X)$ is a [weak homotopy equivalence](wikipedia://en/34615176).[^o13][^o14]
- The extension functor $\operatorname{Ex}$ preserves weak homotopy equivalences (which follows directly from the preceding property and their 2-of-3 property) and [Kan fibrations](wikipedia://en/8992759),[^o15] hence fibrations and trivial fibrations of the [Kan–Quillen model structure](https://en.wikipedia.org/wiki/Kan–Quillen_model_structure). This makes the adjunction $\operatorname{Sd}\dashv\operatorname{Ex}$ even into a [Quillen adjunction](wikipedia://en/11344467) $\operatorname{Sd}\colon \mathbf{sSet}_\mathrm{KQ}\rightleftarrows\mathbf{sSet}_\mathrm{KQ}\colon \operatorname{Ex}$.
- For every horn inclusion $\Lambda_k^n\hookrightarrow\operatorname{Ex}(X)$ with a simplicial set $X$ there exists an extension $\Delta^n\hookrightarrow\operatorname{Ex}^2(X)$.[^o16][^o17]
- For every simplicial set $X$, the simplicial set $\operatorname{Ex}^\infty(X)$ is a [Kan complex](https://en.wikipedia.org/wiki/Kan_complex), hence a fibrant object of the Kan–Quillen model structure.[^o18][^o19][^o20] This follows directly from the preceding property. Furthermore the canonical morphism $\beta_X\colon X\hookrightarrow\operatorname{Ex}^\infty(X)$ is a [monomorphism](wikipedia://en/59538) and a [weak homotopy equivalence](wikipedia://en/34615176), hence a trivial cofibration of the Kan–Quillen model structure.[^o18][^o20] $\operatorname{Ex}^\infty(X)$ is therefore the *fibrant replacement* of $X$ in the Kan–Quillen model structure, hence the [factorization](wikipedia://en/82341) of the [terminal](https://en.wikipedia.org/wiki/Terminal_object) morphism $X\rightarrow\Delta^0$ in a trivial cofibration followed by a fibration. Furthermore, there is a restriction $\operatorname{Ex}^\infty\colon \mathbf{sSet}\rightarrow\mathbf{Kan}$ with the [subcategory](wikipedia://en/310959) $\mathbf{Kan}\hookrightarrow\mathbf{sSet}$ of Kan complexes.
- The infinite extension functor $\operatorname{Ex}^\infty$ preserves all three classes of the Kan–Quillen model structure, hence Kan fibrations, monomorphisms and weak homotopy equivalences (which again follows directly from the preceding property and their 2-of-3 property).[^o21][^o22]
- The extension functor $\operatorname{Ex}$ and the infinite extension functor $\operatorname{Ex}^\infty$ both preserve the set of $0$-simplices, which follows directly from $\operatorname{Sd}(\Delta^0) \cong\Delta^0$. For a simplicial set $X$, one has:[^o23]

$$\operatorname{Ex}(X)_0 =X_0,$$

$$\operatorname{Ex}^\infty(X)_0 =X_0.$$

- The extension functor fixes the singular functor. For a [topological space](wikipedia://en/30450) $X$, one has:

$$\operatorname{Ex}\operatorname{Sing}(X) \cong\operatorname{Sing}(X).$$

This follows from $|\operatorname{Sd}(X)| \cong|X|$ for every simplicial set $X$[^o24] by using the adjunctions $|-|\dashv\operatorname{Sing}$ and $\operatorname{Sd}\dashv\operatorname{Ex}$. In particular, for a topological space $X$, one has:

$$\operatorname{Ex}^\infty\operatorname{Sing}(X) \cong\operatorname{Sing}(X),$$

which fits the fact that the singular functor already produces a Kan complex, which can be its own fibrant replacement.
