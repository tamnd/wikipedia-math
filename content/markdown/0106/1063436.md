# T-schema

::: {#o1 .subject cue=lead name="T-schema"}

The **T-schema** ("truth [schema](https://en.wikipedia.org/wiki/Schema_%28logic%29)", not to be confused with "[Convention T](https://en.wikipedia.org/wiki/Convention_T)") is used to check if an [inductive definition](https://en.wikipedia.org/wiki/Inductive_definition) of truth is valid, which lies at the heart of any realisation of [Alfred Tarski](wikipedia://en/59920)'s [semantic theory of truth](wikipedia://en/601240). Some authors refer to it as the "Equivalence Schema", a synonym introduced by [Michael Dummett](https://en.wikipedia.org/wiki/Michael_Dummett).[^o2]

:::

The T-schema is often expressed in [natural language](wikipedia://en/21173), but it can be formalized in [many-sorted predicate logic](https://en.wikipedia.org/wiki/Predicate_logic) or [modal logic](wikipedia://en/333365); such a formalisation is called a "**T-theory**." T-theories form the basis of much fundamental work in [philosophical logic](wikipedia://en/304939), where they are applied in several important controversies in [analytic philosophy](wikipedia://en/159211).

As expressed in semi-natural language (where 'S' is the name of the sentence abbreviated to S): 'S' is true [if and only if](wikipedia://en/14922) S.

Example: 'snow is white' is true if and only if snow is white.

## The inductive definition {#The_inductive_definition}

By using the schema one can give an inductive definition for the truth of compound sentences. [Atomic sentences](https://en.wikipedia.org/wiki/Atomic_sentences) are assigned [truth values](wikipedia://en/161711) [disquotationally](wikipedia://en/21899301). For example, the sentence "'Snow is white' is true" becomes materially equivalent with the sentence "snow is white", i.e. 'snow is white' is true if and only if snow is white. Said again, a sentence of the form "A" is true if and only if A is true. The truth of more complex sentences is defined in terms of the components of the sentence:

- A sentence of the form "A and B" is true if and only if A is true and B is true
- A sentence of the form "A or B" is true if and only if A is true or B is true
- A sentence of the form "if A then B" is true if and only if A is false or B is true; see [material implication](wikipedia://en/244516).
- A sentence of the form "not A" is true if and only if A is false
- A sentence of the form "for all x, A(*x*)" is true if and only if, for every possible value of *x*, A(*x*) is true.
- A sentence of the form "for some x, A(*x*)" is true if and only if, for some possible value of *x*, A(*x*) is true.

Predicates for truth that meet all of these criteria are called "satisfaction classes", a notion often defined with respect to a fixed language (such as the language of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic)); these classes are considered acceptable definitions for the notion of truth.[^o4]

## Natural languages {#Natural_languages}

[Joseph Heath](https://en.wikipedia.org/wiki/Joseph_Heath) points out that "the analysis of the [truth predicate](wikipedia://en/4807326) provided by Tarski's Schema T is not capable of handling all occurrences of the truth predicate in natural language. In particular, Schema T treats only "freestanding" uses of the predicate—cases when it is applied to complete sentences."[^o6] He gives as an "obvious problem" the sentence:

- Everything that Bill believes is true.

Heath argues that analyzing this sentence using T-schema generates the [sentence fragment](https://en.wikipedia.org/wiki/Sentence_fragment)—"everything that Bill believes"—on the righthand side of the [logical biconditional](https://en.wikipedia.org/wiki/Biconditional).
