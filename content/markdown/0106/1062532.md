# Codress message

::: {#o1 .subject cue=lead name="Codress message"}

In military [cryptography](wikipedia://en/18934432), a **codress message** is an [encrypted](wikipedia://en/10294) message whose address is also encrypted.[^o2] This is usually done to prevent [traffic analysis](https://en.wikipedia.org/wiki/Traffic_analysis).

:::
