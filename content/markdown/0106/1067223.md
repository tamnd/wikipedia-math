# Formally real field

::: {#o1 .subject cue=lead name="Formally real field"}

In [mathematics](wikipedia://en/18831), in particular in [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29) and [real algebra](wikipedia://en/7252198), a **formally real field** is a [field](wikipedia://en/10603) that can be equipped with an (not necessarily unique) [ordering](wikipedia://en/30330) that makes it an [ordered field](wikipedia://en/22430).

:::

::: {#o3 .definition cue=heading name="Alternative definitions"}

## Alternative definitions {#Alternative_definitions}

The definition given above is not a [first-order](wikipedia://en/10983) definition, as it requires quantifiers over [sets](wikipedia://en/26691). However, the following criteria can be coded as (infinitely many) first-order [sentences](wikipedia://en/2129527) in the language of fields and are equivalent to the above definition.

A formally real field *F* is a field that satisfies one of the following equivalent properties:[^o4][^o5]

- −1 is not a sum of [squares](wikipedia://en/213919) in *F*. In other words, the [Stufe](wikipedia://en/35551843) of *F* is infinite. (In particular, such a field must have [characteristic](wikipedia://en/1066621) 0, since in a field of characteristic *p* the element −1 is a sum of 1s.) This can be expressed in first-order logic by $\forall x_1 (-1 \ne x_1^2)$, $\forall x_1 x_2 (-1 \ne x_1^2 + x_2^2)$, etc., with one sentence for each number of variables.
- There exists an element of *F* that is not a sum of squares in *F*, and the characteristic of *F* is not 2.
- If any sum of squares of elements of *F* equals zero, then each of those elements must be zero.

It is easy to see that these three properties are equivalent. It is also easy to see that a field that admits an ordering must satisfy these three properties.

A proof that if *F* satisfies these three properties, then *F* admits an ordering uses the notion of [prepositive cones](wikipedia://en/22430#Positive_cone) and positive cones. Suppose −1 is not a sum of squares; then a [Zorn's Lemma](https://en.wikipedia.org/wiki/Zorn's_Lemma) argument shows that the prepositive cone of sums of squares can be extended to a positive cone *P* ⊆ *F*. One uses this positive cone to define an ordering: *a* ≤ *b* if and only if *b* − *a* belongs to *P*. Since the positive cone *P* need not be unique, the ordering need not be unique either.

:::

## Real closed fields {#Real_closed_fields}

A formally real field with no formally real proper [algebraic extension](wikipedia://en/2125) is a [real closed field](wikipedia://en/1066093).[^o7] If *K* is formally real and Ω is an [algebraically closed field](wikipedia://en/1018) containing *K*, then there is a real closed [subfield](wikipedia://en/11634) of Ω containing *K*. A real closed field can be ordered in a unique way,[^o7] and the non-negative elements are exactly the squares.
