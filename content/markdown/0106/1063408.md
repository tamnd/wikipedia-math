# HAS-160

::: {#o1 .subject cue=lead name="HAS-160"}

**HAS-160** is a [cryptographic hash function](wikipedia://en/439526) designed for use with the [Korean](https://en.wikipedia.org/wiki/Korea) [KCDSA](https://en.wikipedia.org/wiki/KCDSA) [digital signature](wikipedia://en/59644) algorithm. It is derived from [SHA-1](wikipedia://en/26672), with assorted changes intended to increase its security. It produces a 160-bit output.

:::

HAS-160 is used in the same way as SHA-1. First it divides input in blocks of 512 bits each and pads the final block. A digest function updates the intermediate hash value by processing the input blocks in turn.

The message digest algorithm consists of 80 rounds.
