# Programming with Big Data in R

::: {#o1 .subject cue=lead name="Programming with Big Data in R"}

**Programming with Big Data in R** (pbdR)[^o3] is a series of [R](wikipedia://en/376707) packages and an environment for [statistical computing](https://en.wikipedia.org/wiki/Statistical_computing) with [big data](wikipedia://en/27051151) by using high-performance statistical computation.[^o4][^o5] The pbdR uses the same programming language as R with [S3/S4](wikipedia://en/919313) classes and methods which is used among [statisticians](wikipedia://en/48661) and [data miners](wikipedia://en/42253) for developing [statistical software](https://en.wikipedia.org/wiki/Statistical_software). The significant difference between pbdR and R code is that pbdR mainly focuses on [distributed memory](https://en.wikipedia.org/wiki/Distributed_memory) systems, where data are distributed across several processors and analyzed in a [batch mode](https://en.wikipedia.org/wiki/Batch_processing), while communications between processors are based on [MPI](https://en.wikipedia.org/wiki/Message_Passing_Interface) that is easily used in large [high-performance computing (HPC)](https://en.wikipedia.org/wiki/High-performance_computing) systems. R system mainly focuses on single [multi-core](https://en.wikipedia.org/wiki/Multi-core_processor) machines for data analysis via an interactive mode such as [GUI interface](https://en.wikipedia.org/wiki/Graphical_user_interface).

:::

Two main implementations in [R](wikipedia://en/376707) using [MPI](https://en.wikipedia.org/wiki/Message_Passing_Interface) are Rmpi[^o6] and pbdMPI of pbdR.

- The pbdR built on pbdMPI uses [SPMD parallelism](https://en.wikipedia.org/wiki/SPMD) where every processor is considered as worker and owns parts of data. The [SPMD parallelism](https://en.wikipedia.org/wiki/SPMD) introduced in mid 1980 is particularly efficient in homogeneous computing environments for large data, for example, performing [singular value decomposition](wikipedia://en/142207) on a large matrix, or performing [clustering analysis](wikipedia://en/871681) on high-dimensional large data. On the other hand, there is no restriction to use [manager/workers parallelism](https://en.wikipedia.org/wiki/Master/slave_%28technology%29) in [SPMD parallelism](https://en.wikipedia.org/wiki/SPMD) environment.
- The Rmpi[^o6] uses [manager/workers parallelism](https://en.wikipedia.org/wiki/Master/slave_%28technology%29) where one main processor (manager) serves as the control of all other processors (workers). The [manager/workers parallelism](https://en.wikipedia.org/wiki/Master/slave_%28technology%29) introduced around early 2000 is particularly efficient for large tasks in small [clusters](https://en.wikipedia.org/wiki/Computer_cluster), for example, [bootstrap method](wikipedia://en/6885770) and [Monte Carlo simulation](wikipedia://en/56098) in applied statistics since [i.i.d.](wikipedia://en/30876902) assumption is commonly used in most [statistical analysis](wikipedia://en/26685). In particular, task pull parallelism has better performance for Rmpi in heterogeneous computing environments.

The idea of [SPMD parallelism](https://en.wikipedia.org/wiki/SPMD) is to let every processor do the same amount of work, but on different parts of a large data set. For example, a modern [GPU](https://en.wikipedia.org/wiki/Graphics_processing_unit) is a large collection of slower co-processors that can simply apply the same computation on different parts of relatively smaller data, but the SPMD parallelism ends up with an efficient way to obtain final solutions (i.e. time to solution is shorter).[^o7]

## Package design {#Package_design}

Programming with pbdR requires usage of various packages developed by pbdR core team. Packages developed are the following.

::: {#o9 .table cue=table}

| General | I/O | Computation | Application | Profiling | Client/Server |
|---|---|---|---|---|---|
| pbdDEMO | pbdNCDF4 | pbdDMAT | pmclust | pbdPROF | pbdZMQ |
| pbdMPI | pbdADIOS | pbdBASE | pbdML | pbdPAPI | remoter |
|  |  | pbdSLAP |  | hpcvis | pbdCS |
|  |  | kazaam |  |  | pbdRPC |

:::

*Image: Pbd overview.png.* The images describes how various pbdr packages are correlated.

Among these packages, pbdMPI provides wrapper functions to [MPI](https://en.wikipedia.org/wiki/Message_Passing_Interface) library, and it also produces a [shared library](https://en.wikipedia.org/wiki/Library_%28computing%29) and a configuration file for MPI environments. All other packages rely on this configuration for installation and library loading that avoids difficulty of library linking and compiling. All other packages can directly use MPI functions easily.

- pbdMPI --- an efficient interface to MPI either [OpenMPI](https://en.wikipedia.org/wiki/Open_MPI) or [MPICH2](https://en.wikipedia.org/wiki/MPICH2) with a focus on Single Program/Multiple Data ([SPMD](https://en.wikipedia.org/wiki/SPMD)) parallel programming style
- pbdSLAP --- bundles scalable dense linear algebra libraries in double precision for R, based on [ScaLAPACK](https://en.wikipedia.org/wiki/ScaLAPACK) version 2.0.2 which includes several scalable linear algebra packages (namely [BLACS](https://en.wikipedia.org/wiki/BLACS), [PBLAS](https://en.wikipedia.org/wiki/PBLAS), and [ScaLAPACK](https://en.wikipedia.org/wiki/ScaLAPACK)).
- pbdNCDF4 --- interface to Parallel Unidata [NetCDF](https://en.wikipedia.org/wiki/NetCDF)4 format data files
- pbdBASE --- low-level [ScaLAPACK](https://en.wikipedia.org/wiki/ScaLAPACK) codes and wrappers
- pbdDMAT --- distributed matrix classes and computational methods, with a focus on linear algebra and statistics
- pbdDEMO --- set of package demonstrations and examples, and this unifying vignette
- pmclust --- parallel [model-based clustering](wikipedia://en/76187094) using pbdR
- pbdPROF --- profiling package for MPI codes and visualization of parsed stats
- pbdZMQ --- interface to [ØMQ](https://en.wikipedia.org/wiki/ZeroMQ)
- remoter --- R client with remote R servers
- pbdCS --- pbdR client with remote pbdR servers
- pbdRPC --- remote procedure call
- kazaam --- very tall and skinny distributed matrices
- pbdML --- machine learning toolbox

Among those packages, the pbdDEMO package is a collection of 20+ package demos which offer example uses of the various pbdR packages, and contains a vignette that offers detailed explanations for the demos and provides some mathematical or statistical insight.

## Examples {#Examples}

### Example 1 {#Example_1}

Hello World! Save the following code in a file called "demo.r"

```r
### Initial MPI
library(pbdMPI, quiet = TRUE)
init()

comm.cat("Hello World!\n")

### Finish
finalize()
```

and use the command

```bash
mpiexec -np 2 Rscript demo.r
```

to execute the code where [Rscript](wikipedia://en/376707) is one of command line executable program.

### Example 2 {#Example_2}

The following example modified from pbdMPI illustrates the basic [syntax of the language](https://en.wikipedia.org/wiki/Programming_language_syntax) of pbdR. Since pbdR is designed in [SPMD](https://en.wikipedia.org/wiki/SPMD), all the R scripts are stored in files and executed from the command line via mpiexec, mpirun, etc. Save the following code in a file called "demo.r"

```r
### Initial MPI
library(pbdMPI, quiet = TRUE)
init()
.comm.size <- comm.size()
.comm.rank <- comm.rank()

### Set a vector x on all processors with different values
N <- 5
x <- (1:N) + N * .comm.rank

### All reduce x using summation operation
y <- allreduce(as.integer(x), op = "sum")
comm.print(y)
y <- allreduce(as.double(x), op = "sum")
comm.print(y)

### Finish
finalize()
```

and use the command

```bash
mpiexec -np 4 Rscript demo.r
```

to execute the code where [Rscript](wikipedia://en/376707) is one of command line executable program.

### Example 3 {#Example_3}

The following example modified from pbdDEMO illustrates the basic ddmatrix computation of pbdR which performs [singular value decomposition](wikipedia://en/142207) on a given matrix. Save the following code in a file called "demo.r"

```r
# Initialize process grid
library(pbdDMAT, quiet=T)
if(comm.size() != 2)
  comm.stop("Exactly 2 processors are required for this demo.")
init.grid()

# Setup for the remainder
comm.set.seed(diff=TRUE)
M <- N <- 16
BL <- 2 # blocking --- passing single value BL assumes BLxBL blocking
dA <- ddmatrix("rnorm", nrow=M, ncol=N, mean=100, sd=10)

# LA SVD
svd1 <- La.svd(dA)
comm.print(svd1$d)

# Finish
finalize()
```

and use the command

```bash
mpiexec -np 2 Rscript demo.r
```

to execute the code where [Rscript](wikipedia://en/376707) is one of command line executable program.
