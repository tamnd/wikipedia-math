# List of things named after Charles Hermite

::: {#o1 .subject cue=lead name="List of things named after Charles Hermite"}

Numerous things are named after the French mathematician [Charles Hermite](wikipedia://en/22870422) (1822–1901):

:::

## Hermite {#Hermite}

::: {#o3 .entry cue=list-entry name="Cubic Hermite spline"}

- [Cubic Hermite spline](wikipedia://en/656586), a type of third-degree spline

:::

::: {#o4 .entry cue=list-entry name="Gauss–Hermite quadrature"}

- [Gauss–Hermite quadrature](wikipedia://en/18531701), an extension of [Gaussian quadrature](wikipedia://en/50579) method

:::

::: {#o5 .entry cue=list-entry name="Hermite class"}

- [Hermite class](wikipedia://en/38132925)

:::

::: {#o6 .entry cue=list-entry name="Hermite differential equation"}

- [Hermite differential equation](wikipedia://en/3166061#Hermite_differential_equation)

:::

::: {#o7 .entry cue=list-entry name="Hermite distribution"}

- [Hermite distribution](https://en.wikipedia.org/wiki/Hermite_distribution), a parametrized family of discrete probability distributions

:::

::: {#o8 .entry cue=list-entry name="Hermite–Lindemann theorem"}

- [Hermite–Lindemann theorem](https://en.wikipedia.org/wiki/Hermite–Lindemann_theorem), theorem about transcendental numbers

:::

::: {#o9 .entry cue=list-entry name="Hermite constant"}

- [Hermite constant](wikipedia://en/12528854), a constant related to the geometry of certain [lattices](wikipedia://en/469246)

:::

::: {#o10 .entry cue=list-entry name="Hermite-Gaussian modes"}

- [Hermite-Gaussian modes](wikipedia://en/41206#Hermite-Gaussian_modes)

:::

::: {#o11 .entry cue=list-entry name="Hermite–Hadamard inequality"}

- The [Hermite–Hadamard inequality](wikipedia://en/17183245) on convex functions and their integrals

:::

::: {#o12 .entry cue=list-entry name="Hermite interpolation"}

- [Hermite interpolation](wikipedia://en/2085700), a method of interpolating data points by a polynomial

:::

::: {#o13 .entry cue=list-entry name="Hermite–Kronecker–Brioschi characterization"}

- [Hermite–Kronecker–Brioschi characterization](wikipedia://en/3191883#The_Hermite–Kronecker–Brioschi_characterization)

:::

::: {#o14 .entry cue=list-entry name="Hermite–Minkowski theorem"}

- The [Hermite–Minkowski theorem](wikipedia://en/39606032), stating that only finitely many number fields have small discriminants

:::

::: {#o15 .entry cue=list-entry name="Hermite normal form"}

- [Hermite normal form](wikipedia://en/9025098), a form of row-reduced matrices

:::

::: {#o16 .entry cue=list-entry name="Hermite number"}

- [Hermite numbers](wikipedia://en/18543082), integers related to the Hermite polynomials

:::

::: {#o17 .entry cue=list-entry name="Hermite polynomials"}

- [Hermite polynomials](wikipedia://en/195984), a sequence of polynomials orthogonal with respect to the [normal distribution](wikipedia://en/21462)

:::

  - [Continuous q-Hermite polynomials](wikipedia://en/32848732)
  - [Continuous big q-Hermite polynomials](wikipedia://en/32848676)
  - [Discrete q-Hermite polynomials](wikipedia://en/32848697)
  - [Wiener–Hermite expansion](wikipedia://en/27608024)

::: {#o18 .entry cue=list-entry name="Hermite reciprocity"}

- [Hermite reciprocity](https://en.wikipedia.org/wiki/Hermite_reciprocity), a [reciprocity law](wikipedia://en/247622) concerning covariants of binary forms

:::

::: {#o19 .entry cue=list-entry name="Hermite ring"}

- [Hermite ring](wikipedia://en/33812870), a [ring](https://en.wikipedia.org/wiki/Ring_%28algebra%29) over which every stably free module is free of unique rank

:::

::: {#o20 .entry cue=list-entry name="Hermite-Sobolev spaces"}

- [Hermite-Sobolev spaces](wikipedia://en/34205013#Sobolev_spaces)

:::

::: {#o22 .entry cue=list-entry name="Hermite's cotangent identity"}

- [Hermite's cotangent identity](wikipedia://en/33751809), a trigonometric identity

:::

::: {#o23 .entry cue=list-entry name="Hermite's criterion"}
