# Multipartition

::: {#o1 .subject cue=lead name="Multipartition"}

In [number theory](wikipedia://en/21527) and [combinatorics](wikipedia://en/5170), a **multipartition** of a positive [integer](wikipedia://en/14563) *n* is a way of writing *n* as a [sum](wikipedia://en/246160), each element of which is in turn an [integer partition](wikipedia://en/104790).[^o2] The concept is also found in the theory of [Lie algebras](wikipedia://en/17944).[^o2][^o3]

:::

## r-component multipartitions {#r-component_multipartitions}

An *r*-component multipartition of an integer *n* is an *r*-tuple of partitions *λ*<sup>(1)</sup>, ..., *λ*<sup>(r)</sup> where each *λ*<sup>(*i*)</sup> is a partition of some *a*<sub>*i*</sub> and the *a*<sub>*i*</sub> sum to *n*. The number of *r*-component multipartitions of *n* is denoted *P*<sub>*r*</sub>(*n*). Congruences for the function *P*<sub>*r*</sub>(*n*) have been studied by [A. O. L. Atkin](wikipedia://en/3721430).[^o2][^o5]
