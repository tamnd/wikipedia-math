# Infinite set

::: {#o1 .subject cue=lead name="Infinite set"}

*Image: Real numbers.svg.* Set Theory Image

In [set theory](wikipedia://en/27553), an **infinite set** is a [set](wikipedia://en/26691) that is not a [finite set](wikipedia://en/11742). [Infinite](wikipedia://en/20110824) sets may be [countable](wikipedia://en/6026) or [uncountable](wikipedia://en/32248).[^o4]

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) (whose existence is postulated by the [axiom of infinity](wikipedia://en/246449)) is infinite.[^o4] It is the only set that is directly required by the [axioms](wikipedia://en/928) to be infinite. The existence of any other infinite set can be proved in [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC), but only by showing that it follows from the existence of the natural numbers.

A set is infinite if and only if for every natural number, the set has a [subset](wikipedia://en/27631) whose [cardinality](wikipedia://en/6174) is that natural number.[^o5]

If the [axiom of choice](wikipedia://en/840) holds, then a set is infinite if and only if it includes a countable infinite subset.

If a [set of sets](https://en.wikipedia.org/wiki/Set_of_sets) is infinite or contains an infinite element, then its union is infinite. The [power set](wikipedia://en/23799) of an infinite set is infinite.[^o16] Any [superset](wikipedia://en/27631) of an infinite set is infinite. If an infinite set is partitioned into finitely many subsets, then at least one of them must be infinite. Any set which can be mapped *[onto](https://en.wikipedia.org/wiki/Onto)* an infinite set is infinite. The [Cartesian product](wikipedia://en/24104095) of an infinite set and a nonempty set is infinite. The Cartesian product of an infinite number of sets, each containing at least two elements, is either empty or infinite; if the axiom of choice holds, then it is infinite.

If an infinite set is a [well-ordered set](https://en.wikipedia.org/wiki/Well-ordered_set), then it must have a nonempty, nontrivial subset that has no greatest element.

In ZF, a set is infinite if and only if the [power set](wikipedia://en/23799) of its power set is a [Dedekind-infinite set](wikipedia://en/1074742), having a proper subset [equinumerous](https://en.wikipedia.org/wiki/Equinumerous) to itself.[^o6] If the axiom of choice is also true, then infinite sets are precisely the Dedekind-infinite sets.

If an infinite set is a [well-orderable set](https://en.wikipedia.org/wiki/Well-orderable_set), then it has many well-orderings which are non-isomorphic.

:::

## History {#History}

Important ideas discussed by David Burton in his book *The History of Mathematics: An Introduction* include how to define "elements" or parts of a set, how to define unique elements in the set, and how to prove infinity.[^o8] Burton also discusses proofs for different types of infinity, including countable and uncountable sets.[^o8] Topics used when comparing infinite and finite sets include [ordered sets](https://en.wikipedia.org/wiki/Ordered_set), cardinality, equivalency, [coordinate planes](https://en.wikipedia.org/wiki/Coordinate_plane), [universal sets](wikipedia://en/303405), mapping, subsets, continuity, and [transcendence](wikipedia://en/1157698).[^o8] [Cantor's](wikipedia://en/12216) set ideas were influenced by trigonometry and irrational numbers. Other key ideas in infinite set theory mentioned by Burton, Paula, Narli and Rodger include real numbers such as [$\pi$](wikipedia://en/23601), integers, and [Euler's number](https://en.wikipedia.org/wiki/Euler's_number).[^o8][^o9][^o10]

Both Burton and Rogers use finite sets to start to explain infinite sets using proof concepts such as mapping, proof by induction, or proof by contradiction.[^o8][^o10] [Mathematical trees](wikipedia://en/704160) can also be used to understand infinite sets.[^o11] Burton also discusses proofs of infinite sets including ideas such as unions and subsets.[^o8]

In Chapter 12 of *The History of Mathematics: An Introduction*, Burton emphasizes how mathematicians such as [Zermelo](wikipedia://en/178655), [Dedekind](https://en.wikipedia.org/wiki/Dedekind), [Galileo](https://en.wikipedia.org/wiki/Galileo), [Kronecker](wikipedia://en/318450), Cantor, and [Bolzano](wikipedia://en/302185) investigated and influenced infinite set theory. Many of these mathematicians either debated infinity or otherwise added to the ideas of infinite sets. Potential historical influences, such as how Prussia's history in the 1800s, resulted in an increase in scholarly mathematical knowledge, including Cantor's theory of infinite sets.[^o8]

One potential application of infinite set theory is in genetics and biology.[^o12]

## Examples {#Examples}

### Countably infinite sets {#Countably_infinite_sets}

The set of all [integers](wikipedia://en/14563), {..., −1, 0, 1, 2, ...} is a countably infinite set. The set of all even integers is also a countably infinite set, even if it is a proper subset of the integers.[^o16]

The set of all [rational numbers](wikipedia://en/19727024) is a countably infinite set as there is a bijection to the set of integers.[^o16]

### Uncountably infinite sets {#Uncountably_infinite_sets}

The set of all [real numbers](wikipedia://en/20646438) is an uncountably infinite set. The set of all [irrational numbers](wikipedia://en/20647689) is also an uncountably infinite set.[^o16]

The set of all subsets of the integers is uncountably infinite.
