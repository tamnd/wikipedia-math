# Gauss–Markov process

::: {#o1 .subject cue=lead name="Gauss–Markov process"}

**Gauss–Markov stochastic processes** (named after [Carl Friedrich Gauss](wikipedia://en/6125) and [Andrey Markov](wikipedia://en/915)) are [stochastic processes](wikipedia://en/47895) that satisfy the requirements for both [Gaussian processes](wikipedia://en/302944) and [Markov processes](https://en.wikipedia.org/wiki/Markov_process).[^o2][^o3] A stationary Gauss–Markov process is unique up to rescaling; such a process is also known as an [Ornstein–Uhlenbeck process](wikipedia://en/2183186).

:::

Gauss–Markov processes obey [Langevin equations](wikipedia://en/166890).[^o4]

::: {#o6 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

Every Gauss–Markov process *X*(*t*) possesses the three following properties:[^o7]

1. If *h*(*t*) is a non-zero scalar function of *t*, then *Z*(*t*) = *h*(*t*)*X*(*t*) is also a Gauss–Markov process
1. If *f*(*t*) is a non-decreasing scalar function of *t*, then *Z*(*t*) = *X*(*f*(*t*)) is also a Gauss–Markov process
1. If the process is non-degenerate and mean-square continuous, then there exists a non-zero scalar function *h*(*t*) and a strictly increasing scalar function *f*(*t*) such that *X*(*t*) = *h*(*t*)*W*(*f*(*t*)), where *W*(*t*) is the standard [Wiener process](wikipedia://en/149984).

Property (3) means that every non-degenerate mean-square continuous Gauss–Markov process can be synthesized from the standard Wiener process (SWP).

:::

## Other properties {#Other_properties}

A stationary Gauss–Markov process with [variance](wikipedia://en/32344) $\textbf{E}(X^{2}(t)) = \sigma^{2}$ and [time constant](https://en.wikipedia.org/wiki/Time_constant) $\beta^{-1}$ has the following properties.

- Exponential [autocorrelation](wikipedia://en/2724): $$\textbf{R}_{x}(\tau) = \sigma^{2}e^{-\beta |\tau|}.$$
- A power [spectral density](wikipedia://en/202672) (PSD) function that has the same shape as the [Cauchy distribution](wikipedia://en/7003): $$\textbf{S}_{x}(j\omega) = \frac{2\sigma^{2}\beta}{\omega^{2} + \beta^{2}}.$$ (Note that the Cauchy distribution and this spectrum differ by scale factors.)
- The above yields the following spectral factorization: $$\textbf{S}_{x}(s) = \frac{2\sigma^{2}\beta}{-s^{2} + \beta^{2}} = \frac{\sqrt{2\beta}\,\sigma}{(s + \beta)} \cdot\frac{\sqrt{2\beta}\,\sigma}{(-s + \beta)}.$$ which is important in [Wiener filtering](wikipedia://en/1216721) and other areas.

There are also some trivial exceptions to all of the above.
