# Generalized linear mixed model

::: {#o1 .subject cue=lead name="Generalized linear mixed model"}

In [statistics](wikipedia://en/26685), a **generalized linear mixed model** (**GLMM**) is an extension to the [generalized linear model](wikipedia://en/747122) (GLM) in which the linear predictor contains [random effects](https://en.wikipedia.org/wiki/Random_effects) in addition to the usual [fixed effects](https://en.wikipedia.org/wiki/Fixed_effects).[^o2][^o3][^o4] They also inherit from generalized linear models the idea of extending [linear mixed models](wikipedia://en/5431921) to non-[normal](wikipedia://en/21462) data.

:::

Generalized linear mixed models provide a broad range of models for the analysis of grouped data, since the differences between groups can be modelled as a random effect. These models are useful in the analysis of many kinds of data, including [longitudinal data](wikipedia://en/1557623).[^o5]

## Model {#Model}

Generalized linear mixed models are generally defined such that, conditioned on the random effects $u$, the dependent variable $y$ is distributed according to the [exponential family](wikipedia://en/339174) with its expectation related to the linear predictor $X\beta+Zu$ via a link function $g$:

$$g(E[y\vert u])=X\beta+Zu.$$

Here $X$ and $\beta$ are the fixed effects [design matrix](wikipedia://en/949189), and fixed effects respectively; $Z$ and $u$ are the random effects design matrix and random effects respectively. To understand this very brief definition you will first need to understand the definition of a [generalized linear model](wikipedia://en/747122) and of a [mixed model](wikipedia://en/5431921).

Generalized linear mixed models are a special cases of [hierarchical generalized linear models](wikipedia://en/38265760) in which the random effects are normally distributed.

The complete likelihood[^o7]

$$p(y)=\int p(y\vert u)\,p(u)\,du$$

has no general closed form, and integrating over the random effects is usually extremely computationally intensive. In addition to numerically approximating this integral (e.g., via [Gauss–Hermite quadrature](wikipedia://en/18531701)), methods motivated by [Laplace approximation](https://en.wikipedia.org/wiki/Laplace_approximation) have been proposed.[^o8] For example, the penalized [quasi-likelihood](wikipedia://en/15214777) method, which essentially involves repeatedly fitting (i.e. doubly iterative) a weighted normal mixed model with a working variate,[^o9] is implemented by various commercial and open source statistical programs.

## Fitting a model {#Fitting_a_model}

Fitting generalized linear mixed models via [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) (as via the [Akaike information criterion (AIC)](wikipedia://en/690512)) involves [integrating](wikipedia://en/15532) over the random effects. In general, those integrals cannot be expressed in [analytical form](https://en.wikipedia.org/wiki/Analytic_expression). Various approximate methods have been developed, but none has good properties for all possible models and [data sets](wikipedia://en/8495) (e.g. ungrouped [binary data](https://en.wikipedia.org/wiki/Boolean_value) are particularly problematic). For this reason, methods involving [numerical quadrature](https://en.wikipedia.org/wiki/Numerical_quadrature) or [Markov chain Monte Carlo](wikipedia://en/236801) have increased in use, as increasing computing power and advances in methods have made them more practical.

The Akaike information criterion is a common criterion for [model selection](wikipedia://en/3664073). Estimates of the Akaike information criterion for generalized linear mixed models based on certain [exponential family](wikipedia://en/339174) distributions have recently been obtained.[^o11]

## Software {#Software}

- Several contributed packages in [R](wikipedia://en/376707) provide functionality for generalized linear mixed models,[^o13][^o14] including `lme4`[^o15] and `glmm`.[^o16]
- Generalized linear mixed models can be fitted using [SAS](wikipedia://en/990677) and [SPSS](wikipedia://en/179088)[^o17]
- [MATLAB](wikipedia://en/20412) also provides a `fitglme` function to fit generalized linear mixed model models.
- The [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) `Statsmodels` package supports binomial and poisson implementations.[^o18]
- The Julia package `MixedModels.jl` provides a function called `GeneralizedLinearMixedModel` that fits a generalized linear mixed model to provided data.[^o19]
- DHARMa: residual diagnostics for hierarchical (multi-level/mixed) regression models (utk.edu)[^o20]
