# Ground axiom

::: {#o1 .subject cue=lead name="Ground axiom"}

In set theory, the **ground axiom** states that the [universe](wikipedia://en/296838) of set theory is not a nontrivial set-[forcing](wikipedia://en/152205) extension of an [inner model](wikipedia://en/1118686). The axiom was introduced by (Hamkins 2005) and (Reitz 2007).

:::
