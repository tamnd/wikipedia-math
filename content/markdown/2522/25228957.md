# Connes embedding problem

::: {#o1 .subject cue=lead name="Connes embedding problem"}

**Connes' embedding problem**, formulated by [Alain Connes](wikipedia://en/340) in the 1970s, is a major problem in [von Neumann algebra](wikipedia://en/294185) theory. During that time, the problem was reformulated in several different areas of [mathematics](wikipedia://en/18831). [Dan Voiculescu](wikipedia://en/7656821) developing his free entropy theory found that Connes' embedding problem is related to the existence of microstates. Some results of von Neumann algebra theory can be obtained assuming positive solution to the problem. The problem is connected to some basic questions in quantum theory, which led to the realization that it also has important implications in [computer science](https://en.wikipedia.org/wiki/Computer_science).

:::

The problem admits a number of equivalent formulations.[^o2] Notably, it is equivalent to the following long-standing problems:

- Kirchberg's QWEP conjecture in [C\*-algebra](wikipedia://en/7184) theory
- [Tsirelson's problem](https://en.wikipedia.org/wiki/Tsirelson's_bound#Tsirelson's_problem) in quantum information theory
- The predual of any (separable) von Neumann algebra is finitely representable in the trace class.

In January 2020, Ji, Natarajan, Vidick, Wright, and Yuen announced a result in [quantum complexity theory](wikipedia://en/24092190)[^o3] that implies a negative answer to Connes' embedding problem.[^o4][^o5] However, an error was discovered in September 2020 in an earlier result they used; a new proof avoiding the earlier result was published as a preprint in September.[^o6] A broad outline was published in *[Communications of the ACM](https://en.wikipedia.org/wiki/Communications_of_the_ACM)* in November 2021,[^o7] and an article explaining the connection between MIP\*=RE and the Connes Embedding Problem appeared in October 2022.[^o8]

## Statement {#Statement}

Let $\omega$ be a [free ultrafilter](wikipedia://en/31911) on the [natural numbers](wikipedia://en/21474) and let *R* be the [hyperfinite type II<sub>1</sub> factor](wikipedia://en/972868) with trace $\tau$. One can construct the [ultrapower](https://en.wikipedia.org/wiki/Ultrapower) $R^\omega$ as follows: let $l^\infty(R)=\{(x_n)_n\subseteq R:\sup_n||x_n||<\infty\}$ be the von Neumann algebra of norm-bounded sequences and let $I_\omega=\{(x_n)\in l^\infty(R):\lim_{n\rightarrow\omega}\tau(x_n^*x_n)^{\frac{1}{2}}=0\}$. The quotient $R^\omega = l^\infty(R)/I_\omega$ turns out to be a II<sub>1</sub> factor with trace $\tau_{R^\omega}(x)=\lim_{n\rightarrow\omega}\tau(x_n+I_\omega)$, where $(x_n)_n$ is any representative sequence of $x$.

Connes' embedding problem asks whether every [type II<sub>1</sub> factor](wikipedia://en/294185) on a separable [Hilbert space](wikipedia://en/20598932) can be embedded into some $R^\omega$.

A positive solution to the problem would imply that invariant subspaces exist for a large class of operators in type II<sub>1</sub> factors ([Uffe Haagerup](wikipedia://en/46705302)); all countable discrete groups are [hyperlinear](https://en.wikipedia.org/wiki/Hyperlinear_group). A positive solution to the problem would be implied by equality between free entropy $\chi^*$ and free entropy defined by [microstates](wikipedia://en/3066350) ([Dan Voiculescu](wikipedia://en/7656821)). In January 2020, a group of researchers[^o3] claimed to have resolved the problem in the negative, i.e., there exist type II<sub>1</sub> von Neumann factors that do not embed in an ultrapower $R^\omega$ of the hyperfinite II<sub>1</sub> factor.

The isomorphism class of $R^\omega$ is independent of the ultrafilter if and only if the [continuum hypothesis](wikipedia://en/5705) is true (Ge-Hadwin and Farah-Hart-Sherman), but such an embedding property does not depend on the ultrafilter because von Neumann algebras acting on separable Hilbert spaces are, roughly speaking, very small.

:::
