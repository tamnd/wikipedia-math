# Square root biased sampling

::: {#o1 .subject cue=lead name="Square root biased sampling"}

**Square root biased sampling** is a [sampling](wikipedia://en/160361) method proposed by [William H. Press](https://en.wikipedia.org/wiki/William_H._Press), a [computer scientist](https://en.wikipedia.org/wiki/Computer_scientist) and [computational biologist](https://en.wikipedia.org/wiki/Computational_biology), for use in [airport screenings](https://en.wikipedia.org/wiki/Airport_security). It is the mathematically optimal compromise between [simple random sampling](wikipedia://en/23809392) and [strong profiling](https://en.wikipedia.org/wiki/Offender_profiling) that most quickly finds a rare malfeasor, given fixed screening resources.[^o2][^o7]

:::

Using this method, if a group is $n$ times as likely as the average to be a security risk, then persons from that group will be $\sqrt{n}$ times as likely to undergo [additional screening](https://en.wikipedia.org/wiki/Airport_security#Process_and_equipment).[^o2] For example, if someone from a profiled group is nine times more likely than the average person to be a security risk, then when using [square root](wikipedia://en/29208) biased sampling, people from the profiled group would be screened three times more often than the average person.

## History {#History}

Press developed square root biased sampling as a way to sample long sequences of [DNA](https://en.wikipedia.org/wiki/DNA).[^o8] It had also been developed independently by Ruben Abagyan, a professor at [TSRI](https://en.wikipedia.org/wiki/Scripps_Research_Institute) in La Jolla, California, for use in a different biological context.[^o4][^o5] An even earlier discovery was by Martin L. Shooman, who used square root biased sampling in a test apportionment model for software reliability.[^o6]

Press' later proposal to use square root biased sampling for airport security was published in 2009.[^o2] There, he argued that this method would be a more efficient use of the limited resources possessed for screening, as compared to the current practice, which can lead to screening the same persons frequently and repeatedly.[^o7][^o8] However, use of this method presupposes that those doing the screening have accurate [statistical](https://en.wikipedia.org/wiki/Statistical) information on who is more likely to be a security risk, which is not necessarily the case.[^o9]
