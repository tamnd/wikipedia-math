# Mehler–Fock transform

::: {#o1 .subject cue=lead name="Mehler–Fock transform"}

In mathematics, the **Mehler–Fock transform** is an [integral transform](wikipedia://en/430912) introduced by (txt) and rediscovered by (txt).

:::

It is given by

$$F(x) =\int_0^\infty P_{it-1/2}(x)f(t) dt,\quad (1 \leq x \leq \infty),$$

where *P* is a [Legendre function](wikipedia://en/196402) of the first kind.

Under appropriate conditions, the following inversion formula holds:

$$f(t) = t \tanh(\pi t) \int_1^\infty P_{it-1/2}(x)F(x) dx ,\quad (0 \leq t \leq \infty).$$
