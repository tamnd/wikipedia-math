# Location testing for Gaussian scale mixture distributions

::: {#o1 .subject cue=lead name="Location testing for Gaussian scale mixture distributions"}

In [statistics](wikipedia://en/26685), the topic of **location testing for Gaussian scale mixture distributions** arises in some particular types of situations where the more standard [Student's t-test](wikipedia://en/536080) is inapplicable. Specifically, these cases allow [tests of location](wikipedia://en/22747655) to be made where the assumption that sample observations arise from populations having a [normal distribution](wikipedia://en/21462) can be replaced by the assumption that they arise from a Gaussian scale mixture distribution. The class of Gaussian scale mixture distributions contains all symmetric [stable distributions](wikipedia://en/1117869), [Laplace distributions](wikipedia://en/1106213), [logistic distributions](wikipedia://en/542666), and exponential power distributions, etc.[^o2][^o3]

:::

Introduce

*t*<sup>G</sup><sub>*n*</sub>(*x*),

the counterpart of [Student's t-distribution](wikipedia://en/105375) for Gaussian scale mixtures. This means that if we test the null hypothesis that the center of a Gaussian scale mixture distribution is 0, say, then *t*<sub>*n*</sub><sup>*G*</sup>(*x*) (*x* ≥ 0) is the [infimum](https://en.wikipedia.org/wiki/Infimum) of all monotone nondecreasing functions *u*(*x*) ≥ 1/2, *x* ≥ 0 such that if the critical values of the test are *u*<sup>−1</sup>(1 − *α*), then the [significance level](https://en.wikipedia.org/wiki/Significance_level) is at most *α* ≥ 1/2 for all Gaussian scale mixture distributions \[*t*<sup>*G*</sup><sub>*n*</sub>(x) = 1 − *t*<sup>*G*</sup><sub>*n*</sub>(−*x*), for *x* \< 0\]. An explicit formula for *t*<sup>*G*</sup><sub>*n*</sub>(*x*), is given in the papers in the references in terms of [Student’s t-distributions](https://en.wikipedia.org/wiki/Student’s_t-distribution), *t*<sub>*k*</sub>, *k* = 1, 2, ..., *n*. Introduce

Φ<sup>*G*</sup>(*x*):= lim<sub>*n* → ∞</sub> *t*<sup>*G*</sup><sub>*n*</sub>(*x*),

the Gaussian scale mixture counterpart of the standard normal [cumulative distribution function](wikipedia://en/5793), Φ(x).

::: {#o4 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Φ<sup>*G*</sup>(*x*) = 1/2 for 0 ≤ *x* \< 1, Φ<sup>*G*</sup>(1) = 3/4, Φ<sup>*G*</sup>(*x*) = *C*(*x*/(2 − *x*<sup>2</sup>)<sup>1/2</sup>) for quantiles between 1/2 and 0.875, where *C*(*x*) is the standard [Cauchy cumulative distribution function](wikipedia://en/7003). This is the convex part of the curve Φ<sup>*G*</sup>(*x*), *x* ≥ 0 which is followed by a linear section Φ<sup>*G*</sup>(*x*) = *x*/(2$\sqrt{3}$) + 1/2 for 1.3136... \< *x* \< 1.4282... Thus the 90% quantile is exactly 4$\sqrt{3}$/5. Most importantly,

Φ<sup>G</sup>(*x*) = Φ(*x*) for *x* ≥ $\sqrt{3}$.

Note that Φ($\sqrt{3}$) = 0.958..., thus the classical 95% confidence interval for the unknown expected value of Gaussian distributions covers the center of symmetry with at least 95% probability for Gaussian scale mixture distributions. On the other hand, the 90% quantile of Φ<sup>G</sup>(*x*) is 4$\sqrt{3}$/5 = 1.385... > Φ<sup>−1</sup>(0.9) = 1.282... The following critical values are important in applications: 0.95 = Φ(1.645) = Φ<sup>G</sup>(1.651), and 0.9 = Φ(1.282) = Φ<sup>G</sup>(1.386).[^o5]

For the extension of the Theorem to all symmetric [unimodal distributions](https://en.wikipedia.org/wiki/Unimodal_distribution) one can start with a classical result of [Aleksandr Khinchin](wikipedia://en/1029748): namely that all symmetric unimodal distributions are scale mixtures of symmetric uniform distributions.

:::

::: {#o7 .statement kind=statement/conjecture cue=heading name="Open problem"}

## Open problem {#Open_problem}

The counterpart of the Theorem above for the class of all symmetric distributions, or equivalently, for the class of scale mixtures of coin flipping random variables, leads to the following problem:[^o8]

*How many vertices of an*n*\-dimensional [unit cube](wikipedia://en/407763) can be covered by a sphere with given radius*r*(and varying center)?* Answer this question for all positive integers *n* and all positive real numbers *r*. (Certain special cases can be easy to compute.)

:::
