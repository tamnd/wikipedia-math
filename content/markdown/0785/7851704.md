# Proof by example

::: {#o1 .subject cue=lead name="Proof by example"}

In [logic](wikipedia://en/46426065) and [mathematics](wikipedia://en/18831), **proof by example** (sometimes known as **inappropriate generalization**) is a [logical fallacy](wikipedia://en/1655450) whereby the validity of a statement is illustrated through one or more examples or cases—rather than a full-fledged [proof](wikipedia://en/82285).[^o2][^o3]

:::

The structure, [argument form](https://en.wikipedia.org/wiki/Argument_form) and formal form of a proof by example generally proceeds as follows:

Structure:

I know that *X* is such.

Therefore, anything related to *X* is also such.

[Argument form](https://en.wikipedia.org/wiki/Argument_form):

I know that *x*, which is a member of group *X*, has the property *P*.

Therefore, all other elements of *X* must have the property *P*.[^o3]

[Formal form](wikipedia://en/19636):

$$\exists x:P(x)\;\;\vdash\;\;\forall x:P(x)$$

The following example demonstrates why this line of reasoning is a logical fallacy:

I've seen a person shoot someone dead.

Therefore, all people are murderers.

In the common discourse, a proof by example can also be used to describe an attempt to establish a claim using [statistically insignificant](https://en.wikipedia.org/wiki/Statistically_insignificant) examples. In which case, the merit of each argument might have to be assessed on an individual basis.[^o4]

## Valid cases of proof by example {#Valid_cases_of_proof_by_example}

In certain circumstances, examples can suffice as [logically valid](https://en.wikipedia.org/wiki/Logically_valid) proof.

::: {#o7 .proof cue=heading name="Proofs of existential statements"}

### Proofs of existential statements {#Proofs_of_existential_statements}

In some scenarios, an argument by example may be valid if it leads from a singular premise to an *existential* conclusion (i.e. proving that a claim is true for at least one case, instead of for all cases). For example:

Socrates is wise.

Therefore, someone is wise.

(or)

I've seen a person steal.

Therefore, (some) people can steal.

These examples outline the informal version of the logical rule known as [existential introduction](wikipedia://en/354285#Rules_of_classical_predicate_calculus), also known as *particularisation* or *existential generalization*:

**Existential Introduction**

$$\frac{\varphi(\beta / \alpha)}{\exists \alpha\, \varphi}$$

(where $\varphi(\beta / \alpha)$ denotes the [formula](https://en.wikipedia.org/wiki/Formula_%28logic%29) formed by substituting all [free occurrences](https://en.wikipedia.org/wiki/Free_occurrence) of the variable $\alpha$ in $\varphi$ by $\beta$.)

Likewise, finding a [counterexample](wikipedia://en/143151) disproves (proves the [negation](https://en.wikipedia.org/wiki/Logical_negation) of) a universal conclusion. This is used in a [proof by contradiction](https://en.wikipedia.org/wiki/Proof_by_contradiction).

:::

### Exhaustive proofs {#Exhaustive_proofs}

Examples also constitute valid, if [inelegant](https://en.wikipedia.org/wiki/Mathematical_elegance), proof, when it has *also* been demonstrated that the examples treated cover all possible cases.

In mathematics, proof by example can also be used to refer to attempts to illustrate a claim by proving cases of the claim, with the understanding that these cases contain key ideas which can be generalized into a full-fledged proof.[^o9]
