# Shift theorem

::: {#o1 .subject cue=lead name="Shift theorem"}

In [mathematics](wikipedia://en/18831), the (exponential) **shift theorem** is a [theorem](wikipedia://en/30977) about [polynomial](wikipedia://en/23000) [differential operators](https://en.wikipedia.org/wiki/Differential_operators) (*D*-operators) and [exponential functions](wikipedia://en/9678). It permits one to eliminate, in certain cases, the exponential from under the *D*-operators.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

The theorem states that, if *P*(*D*) is a polynomial of the *D*-operator, then, for any sufficiently [differentiable](wikipedia://en/330206) function *y*,

$$P(D)(e^{ax}y)\equiv e^{ax}P(D+a)y.$$

To prove the result, proceed by [induction](wikipedia://en/18881). Note that only the special case

$$P(D)=D^n$$

needs to be proved, since the general result then follows by [linearity](wikipedia://en/147909) of *D*-operators.

The result is clearly true for *n* = 1 since

$$D(e^{ax}y)=e^{ax}(D+a)y.$$

Now suppose the result true for *n* = *k*, that is,

$$D^k(e^{ax}y)=e^{ax}(D+a)^k y.$$

Then,

$$\begin{aligned} D^{k+1}(e^{ax}y)&\equiv\frac{d}{dx}\left\{e^{ax}\left(D+a\right)^ky\right\}\\ &{}=e^{ax}\frac{d}{dx}\left\{\left(D+a\right)^k y\right\} + ae^{ax}\left\{\left(D+a\right)^ky\right\}\\ &{}=e^{ax}\left\{\left(\frac{d}{dx}+a\right) \left(D+a\right)^ky\right\}\\ &{}=e^{ax}(D+a)^{k+1}y. \end{aligned}$$

This completes the proof.

The shift theorem can be applied equally well to inverse operators:

$$\frac{1}{P(D)}(e^{ax}y)=e^{ax}\frac{1}{P(D+a)}y.$$

:::

## Related {#Related}

There is a similar version of the shift theorem for [Laplace transforms](wikipedia://en/18610) ($t<a$):

$$e^{-as}\mathcal{L}\{f(t)\} = \mathcal{L}\{f(t-a)\}.$$

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

The exponential shift theorem can be used to speed the calculation of higher derivatives of functions that is given by the product of an exponential and another function. For instance, if $f(x) = \sin(x) e^x$, one has that

$$\begin{aligned} D^3 f &= D^3 (e^x\sin(x)) = e^x (D+1)^3 \sin (x) \\ &= e^x \left(D^3 + 3D^2 + 3D + 1\right) \sin(x) \\ &= e^x\left(-\cos(x)-3\sin(x)+3\cos(x)+\sin(x)\right) \end{aligned}$$

Another application of the exponential shift theorem is to solve [linear differential equations](wikipedia://en/379868) whose [characteristic polynomial](wikipedia://en/31050469) has repeated roots.[^o7]
