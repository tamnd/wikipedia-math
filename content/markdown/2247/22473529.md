# Additive map

::: {#o1 .subject cue=lead name="Additive map"}

In [algebra](wikipedia://en/19616384), an **additive map** or **additive function** is a [function](wikipedia://en/185427) $f$ that preserves the addition operation:

$$f(x + y) = f(x) + f(y)$$

for every pair of elements $x$ and $y$ in the [domain](wikipedia://en/50263) of $f$. For example, any [linear map](wikipedia://en/18102) is additive. When the domain is the [integers](wikipedia://en/14563) (ℤ), this is called a **$\mathbb{Z}$-linear map**. When the domain is the [real numbers](wikipedia://en/20646438), this is *[Cauchy's functional equation](wikipedia://en/5270898)*. For a specific case of this definition, see [additive polynomial](wikipedia://en/1374699).

:::

More formally, an additive map is a $\mathbb{Z}$-[module homomorphism](wikipedia://en/474118). Since an [abelian group](wikipedia://en/2974) is a $\mathbb{Z}$-[module](wikipedia://en/276410), it may be defined as a [group homomorphism](wikipedia://en/12396) between abelian groups.

A map $V \times W \to X$ that is additive in each of two arguments separately is called a **bi-additive map** or a **$\mathbb{Z}$-bilinear map**.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Typical examples include maps between [rings](wikipedia://en/48404), [vector spaces](wikipedia://en/32370), or [modules](wikipedia://en/276410) that preserve the [additive group](wikipedia://en/332229). An additive map does not necessarily preserve any other structure of the object; for example, the product operation of a ring.

If $f$ and $g$ are additive maps, then the map $f + g$ (defined [pointwise](wikipedia://en/4786797)) is additive.

:::

## Properties {#Properties}

::: {#o6 .definition cue=inline-head name="Definition of scalar multiplication by an integer"}

**Definition of scalar multiplication by an integer**

Suppose that $X$ is an additive group with [identity element](wikipedia://en/14962) $0$ and that the inverse of $x \in X$ is denoted by $-x$. For any $x \in X$ and integer $n \in \mathbb{Z}$, let:

$$n x := \left\{ \begin{alignedat}{9} & &&0 && && &&~~~~ && &&~\text{ when } n = 0 \\ & &&x &&+ \cdots + &&x &&~~~~ \text{(} n &&\text{ summands) } &&~\text{ when } n > 0 \\ & (-&&x) &&+ \cdots + (-&&x) &&~~~~ \text{(} |n| &&\text{ summands) } &&~\text{ when } n < 0. \\ \end{alignedat} \right.$$

Thus $(-1) x = - x$ and it can be shown that for all integers $m, n \in \mathbb{Z}$ and all $x \in X$, $(m + n) x = m x + n x$ and $- (n x) = (-n) x = n (-x)$. This definition of [scalar multiplication](wikipedia://en/244373) makes the cyclic subgroup $\mathbb{Z} x$ of $X$ into a [left $\mathbb{Z}$-module](wikipedia://en/276410); if $X$ is commutative, then it also makes $X$ into a left $\mathbb{Z}$-module.

**Homogeneity over the integers**

If $f : X \to Y$ is an additive map between additive groups then $f(0) = 0$ and for all $x \in X$, $f(-x) = - f(x)$ (where negation denotes the [additive inverse](wikipedia://en/228312)) and[^o7]

$$f(n x) = n f(x) \quad \text{ for all } n \in \mathbb{Z}.$$

Consequently, $f(x - y) = f(x) - f(y)$ for all $x, y \in X$ (where, by definition, $x - y := x + (-y)$).

In other words, every additive map is [homogeneous over the integers](wikipedia://en/622844). Consequently, every additive map between [abelian groups](wikipedia://en/2974) is a [homomorphism of $\mathbb{Z}$-modules](wikipedia://en/474118).

**Homomorphism of $\mathbb{Q}$-modules**

If the additive [abelian groups](wikipedia://en/2974) $X$ and $Y$ are also a [unital](https://en.wikipedia.org/wiki/Unital_module) [modules](wikipedia://en/276410) over the rationals $\mathbb{Q}$ (such as real or complex [vector spaces](wikipedia://en/32370)) then an additive map $f : X \to Y$ satisfies:[^o8]

$$f(q x) = q f(x) \quad \text{ for all } q \in \mathbb{Q} \text{ and } x \in X.$$

In other words, every additive map is [homogeneous over the rational numbers](https://en.wikipedia.org/wiki/Homogeneous_over_the_rational_numbers). Consequently, every additive maps between unital [$\mathbb{Q}$-modules](wikipedia://en/276410) is a [homomorphism of $\mathbb{Q}$-modules](wikipedia://en/474118).

Despite being homogeneous over $\mathbb{Q}$, as described in the article on [Cauchy's functional equation](wikipedia://en/5270898), even when $X = Y = \mathbb{R}$, it is nevertheless still possible for the additive function $f : \mathbb{R} \to \mathbb{R}$ to not be [homogeneous over the real numbers](https://en.wikipedia.org/wiki/Real_homogeneity); said differently, there exist additive maps $f : \mathbb{R} \to \mathbb{R}$ that are not of the form $f(x) = s_0 x$ for some constant $s_0 \in \mathbb{R}$. In particular, there exist additive maps that are not [linear maps](wikipedia://en/18102) with respect to an existing ring structure of the [codomain](wikipedia://en/50264).

[^o7]: $f(0) = f(0 + 0) = f(0) + f(0)$ so adding $-f(0)$ to both sides proves that $f(0) = 0$. If $x \in X$ then $0 = f(0) = f(x + (-x)) = f(x) + f(-x)$ so that $f(-x) = - f(x)$ where, by definition, $(-1) f(x) := - f(x)$. Induction shows that if $n \in \mathbb{N}$ is positive then $f(n x) = n f(x)$ and that the additive inverse of $n f(x)$ is $n (-f(x))$, which implies that $f((-n) x) = f(n (-x)) = n f(-x) = n (- f(x)) = -(n f(x)) = (-n) f(x)$ (this shows that $f(n x) = n f(x)$ holds for $n < 0$). $\blacksquare$
[^o8]: Let $x \in X$ and $q = \frac{m}{n} \in \mathbb{Q}$ where $m, n \in \mathbb{Z}$ and $n > 0$. Let $y := \frac{1}{n} x$. Then $n y = n \left(\frac{1}{n} x\right) = \left(n \frac{1}{n}\right) x = (1) x = x$, which implies $f(x) = f(n y) = n f(y) = n f\left(\frac{1}{n} x\right)$ so that multiplying both sides by $\frac{1}{n}$ proves that $f\left(\frac{1}{n} x\right) = \frac{1}{n} f(x)$. Consequently, $f(q x) = f\left(\frac{m}{n} x\right) = m f\left(\frac{1}{n} x\right) = m\left(\frac{1}{n} f(x)\right) = q f(x)$. $\blacksquare$
