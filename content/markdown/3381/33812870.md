# Hermite ring

::: {#o1 .subject cue=lead name="Hermite ring"}

In [algebra](wikipedia://en/19616384), the term **Hermite ring** (after [Charles Hermite](wikipedia://en/22870422)) has been applied to three different objects.

:::

According to [Kaplansky](https://en.wikipedia.org/wiki/Irving_Kaplansky) (1949),[^o2] a [ring](wikipedia://en/48404) is **right Hermite** if, for every two elements *a* and *b* of the ring, there is an element *d* of the ring and an [invertible](wikipedia://en/217122) 2×2 [matrix](wikipedia://en/20556859) *M* over the ring such that (*a* *b*)*M* = (*d* 0), and the term **left Hermite** is defined similarly. Matrices over such a ring can be put in [Hermite normal form](wikipedia://en/9025098) by right multiplication by a [square](wikipedia://en/166022) invertible matrix.[^o2] [Lam](https://en.wikipedia.org/wiki/Tsit_Yuen_Lam) (2006)[^o3] calls this property **K-Hermite**, using *Hermite* instead in the sense given below.

According to Lam (1978),[^o4] a ring is **right Hermite** if any finitely generated [stably free](wikipedia://en/19745945) right [module](wikipedia://en/276410) over the ring is [free](wikipedia://en/326454). This is equivalent to requiring that any row vector (*b*<sub>1</sub>,...,*b<sub>n</sub>*) of elements of the ring which generate it as a right module (i.e., *b*<sub>1</sub>*R* + ... + *b<sub>n</sub>R* = *R*) can be completed to a (not necessarily square) invertible matrix by adding some number of rows. The criterion of being **left Hermite** can be defined similarly. Lissner (1965)[^o5] earlier called a [commutative ring](wikipedia://en/61346) with this property an **H-ring**.

According to [Cohn](wikipedia://en/18326967) (2006),[^o6] a ring is **Hermite** if, in addition to every stably free (left) module being free, it has [invariant basis number](wikipedia://en/3327998).

All commutative rings which are Hermite in the sense of Kaplansky are also Hermite in the sense of Lam, but the [converse](wikipedia://en/155941) is not necessarily true. All [Bézout domains](wikipedia://en/3131407) are Hermite in the sense of Kaplansky, and a commutative ring which is Hermite in the sense of Kaplansky is also a [Bézout ring](https://en.wikipedia.org/wiki/Bézout_ring).[^o3]

The **Hermite ring conjecture**, introduced by Lam (1978),[^o4] states that if *R* is a commutative Hermite ring, then the [polynomial ring](wikipedia://en/373065) *R*\[*x*\] is also a Hermite ring.
