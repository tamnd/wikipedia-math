# Recursive language

::: {#o1 .subject cue=lead name="Recursive language"}

In [mathematics](wikipedia://en/18831), [logic](wikipedia://en/46426065) and [computer science](https://en.wikipedia.org/wiki/Computer_science), a **recursive** (or *decidable*) language is a [recursive subset](https://en.wikipedia.org/wiki/Recursive_set) of the [Kleene closure](https://en.wikipedia.org/wiki/Kleene_closure) of an [alphabet](wikipedia://en/4292269). Equivalently, a [formal language](wikipedia://en/10939) is **recursive** if there exists a Turing machine that [decides](https://en.wikipedia.org/wiki/Decider_%28Turing_machine%29) the formal language.[^n1] In [theoretical computer science](wikipedia://en/323392), such always-halting Turing machines are called [total Turing machines](https://en.wikipedia.org/wiki/Total_Turing_machine) or **algorithms**.[^n2]

:::

The concept of **decidability** may be extended to other [models of computation](https://en.wikipedia.org/wiki/Models_of_computation). For example, one may speak of languages decidable on a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine). Therefore, whenever an ambiguity is possible, the synonym used for "recursive language" is **Turing-decidable language**, rather than simply *decidable*.

The class of all recursive languages is often called **[R](wikipedia://en/3106763)**, although this name is also used for the class [RP](wikipedia://en/54771).

This type of language was not defined in the [Chomsky hierarchy](wikipedia://en/6011).[^n3] All recursive languages are also [recursively enumerable](wikipedia://en/54789). All [regular](wikipedia://en/25723), [context-free](wikipedia://en/6867) and [context-sensitive](wikipedia://en/6212) languages are recursive.

::: {#o6 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There are two equivalent major definitions for the concept of a recursive language:

1. A recursive language is a [recursive](https://en.wikipedia.org/wiki/Recursive_set) subset of the set of all possible finite-length [words](wikipedia://en/10939) over an [alphabet](wikipedia://en/4292269).
1. A recursive language is a [formal language](wikipedia://en/10939) for which there exists a [Turing machine](wikipedia://en/30403) that [decides](https://en.wikipedia.org/wiki/Decider_%28Turing_machine%29) it.

On the other hand, we can show that a [decision problem](wikipedia://en/8336) is decidable by exhibiting a Turing machine running an [algorithm](wikipedia://en/775) that terminates on all inputs. An [undecidable problem](wikipedia://en/15631055) is a problem that is not decidable.

:::

## Examples {#Examples}

As noted above, every context-sensitive language is recursive. Thus, a simple example of a recursive language is the set *L={abc, aabbcc, aaabbbccc, ...}*; more formally, the set

$$L=\{\,w \in \{a,b,c\}^* \mid w=a^nb^nc^n \mbox{ for some } n\ge 1 \,\}$$

is context-sensitive and therefore recursive.

Examples of decidable languages that are not context-sensitive are more difficult to describe. For one such example, some familiarity with [mathematical logic](wikipedia://en/19636) is required: [Presburger arithmetic](wikipedia://en/23756) is the first-order theory of the natural numbers with addition (but without multiplication). While the set of [well-formed formulas](wikipedia://en/10983#Formulas) in Presburger arithmetic is context-free, every deterministic Turing machine accepting the set of true statements in Presburger arithmetic has a worst-case runtime of at least $2^{2^{pn}}$, for some constant *p*>0.[^n4] Here, *n* denotes the length of the given formula. Since every context-sensitive language can be accepted by a [linear bounded automaton](wikipedia://en/1811962), and such an automaton can be simulated by a deterministic Turing machine with worst-case running time at most $q^n$ for some constant *q*,[^n5] the set of valid formulas in Presburger arithmetic is not context-sensitive. On a positive side, it is known that there is a deterministic Turing machine running in time at most triply exponential in *n* that decides the set of true formulas in Presburger arithmetic.[^n6] Thus, this is an example of a language that is decidable but not context-sensitive.

:::

## Closure properties {#Closure_properties}

Recursive languages are [closed](wikipedia://en/293802) under the following operations. That is, if *L* and *P* are two recursive languages, then the following languages are recursive as well:

- The [Kleene star](wikipedia://en/16750) $L^*$
- The image φ(L) under an [e-free homomorphism](wikipedia://en/13564#Formal_language_theory) φ
- The concatenation $L \circ P$
- The union $L \cup P$
- The intersection $L \cap P$
- The complement of $L$
- The set difference $L - P$

The last property follows from the fact that the set difference can be expressed in terms of intersection and complement.
