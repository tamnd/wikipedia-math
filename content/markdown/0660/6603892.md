# Fiber (mathematics)

::: {#o1 .subject cue=lead name="Fiber"}

In [mathematics](wikipedia://en/18831), a **fiber** ([US English](https://en.wikipedia.org/wiki/American_English)) or **fibre** ([British English](https://en.wikipedia.org/wiki/British_English)) of a [map](wikipedia://en/516931) or [function](wikipedia://en/185427) $f:X\to Y$ is an equivalence class in *X* for the relation of having the same image under *f*. If *y* is that image, then this fiber equals the [inverse image](https://en.wikipedia.org/wiki/Inverse_image) $f^{-1}(y) = \{ x\in X : f(x) = y \}$ of $y$[^o9] and is called the fiber of *f* over *y*.

:::

## Properties and applications {#Properties_and_applications}

### In elementary set theory {#In_elementary_set_theory}

Any map $f:X\to Y$ defines a relation $\equiv_f$ on *X*, where $x_1\equiv_f x_2$ holds when $f(x_1)=f(x_2)$, and this is always an [equivalence relation](wikipedia://en/9259). The **fibers of** $f$ are the [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes) for this relation $\equiv_f$. Each such fiber is associated to the (by definition constant) value of *f* on the fiber, and if $y\in Y$ is that value (necessarily an element of the image set of *f*), then the fiber is the set $f^{-1}(y) = \{ x\in X : f(x) = y\}$ of [preimages](https://en.wikipedia.org/wiki/Preimage) of *y* under *f*, which is called the fiber of *f* over *y*. The set of all fibers of *f* forms is a [partition](https://en.wikipedia.org/wiki/Partition_%28mathematics%29) of $X$. The mentioned correspondence defines a [bijection](wikipedia://en/3942) from the [quotient set](https://en.wikipedia.org/wiki/Quotient_set) $X/{\equiv_f}$ (the set of fibers of *f*) to the image set $f(X)$. Note that in case $f$ is not a [surjective map](https://en.wikipedia.org/wiki/Surjective_map), one only considers fibers over elements of the subset $f(X)$ of *Y*, thus avoiding the [empty set](wikipedia://en/9566), which cannot be an element of any [partition](wikipedia://en/340240), among the fibers of *f*. The fiber containing an element $x\in X$ is the set $f^{-1}(f(x))$.

For example, let $f$ be the function from $\mathbb{R}^2$ to $\mathbb{R}$ that sends point $(a,b)$ to $a+b$. The fiber of 5 under $f$ are all the points on the straight line with [equation](https://en.wikipedia.org/wiki/Equation_%28mathematics%29) $a+b=5$. The fibers of $f$ are that line and all the straight lines parallel to it, which form a partition of the plane $\mathbb{R}^2$.

More generally, if $f$ is a [linear map](wikipedia://en/18102) from some [linear vector space](https://en.wikipedia.org/wiki/Linear_vector_space) $X$ to some other linear space $Y$, the fibers of $f$ are [affine subspaces](wikipedia://en/298834) of $X$, which are all the translated copies of the [null space](https://en.wikipedia.org/wiki/Null_space) of $f$.

If $f$ is a [real](wikipedia://en/20646438)-valued [function of several real variables](wikipedia://en/39783039), the fibers of the function are the [level sets](wikipedia://en/559622) of $f$. If $f$ is also a [continuous function](wikipedia://en/6122) and $y\in\mathbb{R}$ is in the [image](wikipedia://en/579311) of $f,$ the level set $f^{-1}(y)$ will typically be a [curve](https://en.wikipedia.org/wiki/Curve_%28mathematics%29) in [2D](wikipedia://en/19469852), a [surface](wikipedia://en/4342970) in [3D](wikipedia://en/3054853), and, more generally, a [hypersurface](wikipedia://en/525101) in the domain of $f.$

### In topology {#In_topology}

In [point set topology](https://en.wikipedia.org/wiki/Point_set_topology), one generally considers functions from [topological spaces](https://en.wikipedia.org/wiki/Topological_spaces) to topological spaces.

If $f$ is a [continuous function](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) and if $Y$ (or more generally, the image set $f(X)$) is a [T<sub>1</sub> space](wikipedia://en/148721) then every fiber is a [closed subset](wikipedia://en/47279) of $X.$ In particular, if $f$ is a [local homeomorphism](wikipedia://en/248582) from $X$ to $Y$, each fiber of $f$ is a [discrete](wikipedia://en/56061) [subspace](https://en.wikipedia.org/wiki/Topological_subspace) of $X$.

A function between topological spaces is called monotone if every fiber is a [connected](wikipedia://en/6233) [subspace](https://en.wikipedia.org/wiki/Topological_subspace) of its domain. A function $f : \mathbb{R} \to \mathbb{R}$ is monotone in this topological sense if and only if it is [non-increasing](https://en.wikipedia.org/wiki/Nonincreasing_function) or [non-decreasing](https://en.wikipedia.org/wiki/Nondecreasing_function), which is the usual meaning of "[monotone function](https://en.wikipedia.org/wiki/Monotone_function)" in [real analysis](wikipedia://en/26478).

A function between topological spaces is (sometimes) called a [proper map](wikipedia://en/1190262) if every fiber is a [compact](wikipedia://en/6042) subspace of its domain. However, many authors use other non-equivalent competing definitions of "proper map" so it is advisable to always check how a particular author defines this term. A [continuous](wikipedia://en/6122) [closed](https://en.wikipedia.org/wiki/Closed_map) [surjective function](wikipedia://en/27873) whose fibers are all compact is called a [perfect map](wikipedia://en/17921433).

A [fiber bundle](wikipedia://en/276526) is a function $f$ between [topological spaces](https://en.wikipedia.org/wiki/Topological_spaces) $X$ and $Y$ whose fibers have certain special properties related to the topology of those spaces.

### In algebraic geometry {#In_algebraic_geometry}

In [algebraic geometry](wikipedia://en/1997), if $f : X \to Y$ is a [morphism of schemes](wikipedia://en/7482797), the **fiber** of a [point](wikipedia://en/11494409) $p$ in $Y$ is the [fiber product of schemes](wikipedia://en/56444110)

$$X \times_Y \operatorname{Spec} k(p)$$

where $k(p)$ is the [residue field](wikipedia://en/10789680) at $p.$
