# Semialgebraic set

::: {#o1 .subject cue=lead name="Semialgebraic set"}

In [mathematics](wikipedia://en/18831), a **basic semialgebraic set** is a set defined by polynomial equalities and polynomial inequalities, and a **semialgebraic set** is a [finite](wikipedia://en/11742) [union](wikipedia://en/47949) of basic semialgebraic sets. A **semialgebraic function** is a [function](wikipedia://en/185427) with a semialgebraic [graph](wikipedia://en/87352). Such sets and functions are the main object of study of [real algebraic geometry](wikipedia://en/7252198) the part of [algebraic geometry](wikipedia://en/1997) devoted to points with real [coordinates](https://en.wikipedia.org/wiki/Coordinates).

:::

[Tarski–Seidenberg theorem](wikipedia://en/19389633) implies that the semialgebraic sets are exactly those sets that can be defined by a [well-formed formula](wikipedia://en/404582) built with [quantifiers](wikipedia://en/43507260) $\forall, \exists$, [logical connectives](wikipedia://en/18153) $\land,\lor, \lnot$, basic [arithmetic operators](https://en.wikipedia.org/wiki/Arithmetic_operator) $+,-,\times,/$, [equality](wikipedia://en/90446) and [inequality](wikipedia://en/89489) signs $=, <, \le$, [integers](wikipedia://en/14563), and [variables](wikipedia://en/3728109) representing real numbers.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathbb{R}$ be the [field](wikipedia://en/10603) of [real numbers](wikipedia://en/20646438), or, more generally, any [real closed field](wikipedia://en/1066093).

A *basic semialgebraic set* in $\mathbb{R}^n$ is the set of the common solutions of a finite number of [polynomial equations](https://en.wikipedia.org/wiki/Polynomial_equation) and [inequalities](wikipedia://en/89489) of the form

$$P(x_1, \ldots, x_n)=0$$

or

$$Q(x_1, \ldots, x_n)>0,$$

where $P$ and $Q$ are polynomial coefficients

A *semialgebraic set* in $\mathbb{R}^n$ is a finite union of basic semialgebraic sets.

[Tarski–Seidenberg theorem](wikipedia://en/19389633) and basic rules of [Boolean algebra](wikipedia://en/54476844) and [algebra](wikipedia://en/18716923) imply that semialgebra sets are exactly those subsets of $\mathbb{R}^n$ that can be defined by a [well-formed formula](wikipedia://en/404582) built from the [quantifiers](wikipedia://en/43507260) $\forall, \exists$, the [logical connectives](wikipedia://en/18153) $\land,\lor,\lnot$, [equality](wikipedia://en/90446) and [inequality](wikipedia://en/89489) signs $=, <, \le$, the [arithmetic operators](https://en.wikipedia.org/wiki/Arithmetic_operator) $+,-,\times,/$, integers, and the variables $x_1,\ldots,x_n$.

So, the definition of semialgebraic sets may be viewed as a kind of [normal form](https://en.wikipedia.org/wiki/Normal_form_%28mathematics%29) for this general class of [first-order formulas](https://en.wikipedia.org/wiki/First-order_formula).

## Dimension 1 {#Dimension_1}

In $\mathbb{R}$, a semialgebraic set is the union a finite number of [intervals](wikipedia://en/49172) whose end points are [algebraic numbers](wikipedia://en/1158); this includes zero-length intervals that are each reduced to a single algebraic number. Conversely, such an union is a always a semialgebraic set.

For proving this we define first some special basic semialgebraic sets. Then we prove that every basic algebraic sset is a [disjoint union](wikipedia://en/188946) of such special sets and that this implies the result.

By definition of an algebraic number, an algebraic number $\alpha$ is a [root](https://en.wikipedia.org/wiki/Polynomial_root) of a [square-free polynomial](wikipedia://en/3816655) $P(x)$ with integer coefficients and positive [leading coefficient](https://en.wikipedia.org/wiki/Leading_coefficient) (the square-free condition implies that the polynomial changes of sign at each root). [Real-root isolation](wikipedia://en/44012866) provides algorithms for computing two [rational numbers](wikipedia://en/19727024) $a$ and $b$ such that $a<\alpha <b$ and there is no other root of $P$ in the interval $[a,b]$. So, the singleton

$$\{\alpha\}=\{x\mid P(x)=0\land x-a>0 \land b-x>0\}$$

is a basic semialgebraic set.

With the same notation, if $\alpha$ is the largest root of $P$, the open interval $(\alpha, +\infty)$ a basic semialgebraic set, since

$$(\alpha, +\infty)=\{x\mid P(x)>0\land x-a>0\}.$$

Similarly, if $\alpha$ is the smallest root, one has the basic semialgebraic set

$$(-\infty,\alpha)=\{x\mid P(a)P(x)>0\land b-x>0\}.$$

If $\alpha<\beta$ are two consecutive roots of $P$, real-root isolation provides three rational numbers $a$, $b$ and $c$ such that $a<\alpha<b<\beta<c$ and the interval $[a,b]$ does not contain any other root of $P$. In this case,

$$(\alpha,\beta)=\{x\mid P(b)P(x)>0\land c-x>0 \land x-a>0\}$$

expresses $(\alpha,\beta)$ as a basic algebraic set.

Now, given a basic semialgebraic set, there are two cases: firstly if its definition contains at least one equation $P(x)=0$, the set consists of a subset of the roots of $P$, and is thus the union of above special basic sets.

If there is no equation in the definition of the basic algebraic set, it has the form

$$S=\{x\mid P_1(x)>0\land \cdots \land P_k(x)>0\}.$$

Since each $P_i$ has a constant sign in each open interval delimited by two consecutive roots of the product $P=P_1 \cdots P_k$, the set $S$ is the union of some ot these intervals, and thus a union of special basic semialgebraic sets.

The final result follows since a finite union of singletons and open intervals is also a disjoint union of points nd intervals.

## Properties {#Properties}

Similarly to [algebraic subvarieties](https://en.wikipedia.org/wiki/Algebraic_subvariety), finite unions and [intersections](wikipedia://en/23476429) of semialgebraic sets are still semialgebraic sets. Furthermore, unlike subvarieties, the [complement](wikipedia://en/54347) of a semialgebraic set is again semialgebraic. Finally, and most importantly, the [Tarski–Seidenberg theorem](wikipedia://en/19389633) says that they are also closed under the projection operation: in other words a semialgebraic set projected onto a [linear subspace](wikipedia://en/56357) yields another semialgebraic set (as is the case for [quantifier elimination](https://en.wikipedia.org/wiki/Elimination_of_quantifiers)). These properties together mean that semialgebraic sets form an [o-minimal structure](https://en.wikipedia.org/wiki/O-minimal_structure) on *R*.

A semialgebraic set (or function) is said to be **defined over a subring** *A* of *R* if there is some description, as in the definition, where the polynomials can be chosen to have coefficients in *A*.

On a [dense](wikipedia://en/23523594) [open subset](https://en.wikipedia.org/wiki/Open_subset) of the semialgebraic set *S*, it is (locally) a [submanifold](wikipedia://en/525095). One can define the dimension of *S* to be the largest dimension at points at which it is a submanifold. It is not hard to see that a semialgebraic set lies inside an algebraic subvariety of the same dimension.
