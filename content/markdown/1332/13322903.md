# Relative neighborhood graph

::: {#o1 .subject cue=lead name="Relative neighborhood graph"}

*Image: Relative neighborhood graph.svg.* The relative neighborhood graph of 100 random points in a unit square.

In [computational geometry](wikipedia://en/176927), the **relative neighborhood graph** (**RNG**) is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) defined on a set of points in the [Euclidean plane](wikipedia://en/15575410) by connecting two points $p$ and $q$ by an edge whenever there does not exist a third point $r$ that is closer to both $p$ and $q$ than they are to each other. This graph was proposed by [Godfried Toussaint](https://en.wikipedia.org/wiki/Godfried_Toussaint) in 1980 as a way of defining a structure from a set of points that would match human perceptions of the shape of the set.[^o2][^o3]

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

(Supowit 1983) showed how to construct the relative neighborhood graph of $n$ points in the plane efficiently in $O(n\log n)$ time.[^o7] It can be computed in $O(n)$ [expected time](https://en.wikipedia.org/wiki/Expected_time), for random set of points [distributed uniformly](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) in the [unit square](wikipedia://en/285301).[^o8] The relative neighborhood graph can be computed in [linear time](https://en.wikipedia.org/wiki/Linear_time) from the [Delaunay triangulation](wikipedia://en/8864) of the point set.[^o9][^o10]

:::

::: {#o12 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

Because it is defined only in terms of the distances between points, the relative neighborhood graph can be defined for point sets in any dimension,[^o2][^o13][^o14] and for non-Euclidean metrics.[^o2][^o9][^o15][^o16] Computing the relative neighborhood graph, for higher-dimensional point sets, can be done in time $O(n^2)$.

:::

## Related graphs {#Related_graphs}

The relative neighborhood graph is an example of a [lens](wikipedia://en/2038396)-based [beta skeleton](wikipedia://en/26266763). It is a [subgraph](wikipedia://en/325802#Subgraphs) of the [Delaunay triangulation](wikipedia://en/8864). In turn, the [Euclidean minimum spanning tree](wikipedia://en/1040597) is a subgraph of it, from which it follows that it is a [connected graph](https://en.wikipedia.org/wiki/Connected_graph).

The [Urquhart graph](wikipedia://en/24438021), the graph formed by removing the longest edge from every triangle in the Delaunay triangulation, was originally proposed as a fast method to compute the relative neighborhood graph.[^o18] Although the Urquhart graph sometimes differs from the relative neighborhood graph[^o19] it can be used as an approximation to the relative neighborhood graph.[^o20]
