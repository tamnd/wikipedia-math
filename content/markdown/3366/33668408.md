# In-crowd algorithm

::: {#o1 .subject cue=lead name="In-crowd algorithm"}

The **in-crowd algorithm** is a numerical method for solving [basis pursuit denoising](wikipedia://en/29276362) quickly; faster than any other algorithm for large, sparse problems.[^o2] This algorithm is an [active set method](https://en.wikipedia.org/wiki/Active_set_method), which minimizes iteratively sub-problems of the global basis pursuit denoising:

:::

$$\min_x \frac{1}{2}\|y-Ax\|^2_2+\lambda\|x\|_1.$$

where $y$ is the observed signal, $x$ is the sparse signal to be recovered, $Ax$ is the expected signal under $x$, and $\lambda$ is the regularization parameter trading off signal fidelity and simplicity. The simplicity is here measured using the sparsity of the solution $x$, measure through its $\ell_1$-norm. The active set strategies are very efficient in this context as only few coefficient are expected to be non-zero. Thus, if they can be identified, solving the problem restricted to these coefficients yield the solution. Here, the features are greedily selected based on the [absolute value](wikipedia://en/991) of their gradient at the current estimate.

Other active-set methods for the basis pursuit denoising includes BLITZ,[^o3] where the selection of the active set is performed using the [duality gap](wikipedia://en/33328430) of the problem, and The Feature Sign Search,[^o4] where the features are included based on the estimate of their sign.

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

It consists of the following:

1. Declare $x$ to be 0, so the unexplained residual $r = y$
1. Declare the active set $I$ to be the [empty set](wikipedia://en/9566), and $I^c$ to be its complement (the inactive set)
1. Calculate the usefulness $u_j = | \langle r A_j \rangle |$ for each component in $I^c$
1. If on $I^c$, no $u_j > \lambda$, terminate
1. Otherwise, add $L \approx 25$ components to $I$ based on their usefulness
1. Solve basis pursuit denoising exactly on $I$, and throw out any component of $I$ whose value attains exactly 0. This problem is dense, so [quadratic programming](wikipedia://en/40324) techniques work very well for this sub problem.
1. Update $r = y - Ax$ - n.b. can be computed in the subproblem as all elements outside of $I$ are 0
1. Go to step 3.

Since every time the in-crowd algorithm performs a global search it adds up to $L$ components to the active set, it can be a factor of $L$ faster than the best alternative algorithms when this search is computationally expensive. A theorem[^o2] guarantees that the global optimum is reached in spite of the many-at-a-time nature of the in-crowd algorithm.

:::
