# Cartan's lemma

::: {#o1 .subject cue=lead name="Cartan's lemma"}

In [mathematics](wikipedia://en/18831), **Cartan's lemma** refers to a number of results named after either [Élie Cartan](wikipedia://en/386274) or his son [Henri Cartan](wikipedia://en/362536):

:::

- In [exterior algebra](wikipedia://en/221537):[^o2] Suppose that *v*<sub>1</sub>, ..., *v*<sub>*p*</sub> are linearly independent elements of a vector space *V* and *w*<sub>1</sub>, ..., *w*<sub>*p*</sub> are such that

$$v_1\wedge w_1 + \cdots + v_p\wedge w_p = 0$$

in Λ*V*. Then there are scalars *h*<sub>*ij*</sub> = *h*<sub>*ji*</sub> such that

$$w_i = \sum_{j=1}^p h_{ij}v_j.$$

- In [several complex variables](wikipedia://en/360243):[^o3] Let *a*<sub>1</sub> \< *a*<sub>2</sub> \< *a*<sub>3</sub> \< *a*<sub>4</sub> and *b*<sub>1</sub> \< *b*<sub>2</sub> and define rectangles in the complex plane **C** by

$$\begin{aligned} K_1 &= \{ z_1=x_1+iy_1 | a_2 < x_1 < a_3, b_1 < y_1 < b_2\} \\ K_1' &= \{ z_1=x_1+iy_1 | a_1 < x_1 < a_3, b_1 < y_1 < b_2\} \\ K_1'' &= \{ z_1=x_1+iy_1 | a_2 < x_1 < a_4, b_1 < y_1 < b_2\} \end{aligned}$$

so that $K_1 = K_1'\cap K_1''$. Let *K*<sub>2</sub>, ..., *K*<sub>*n*</sub> be simply connected domains in **C** and let

$$\begin{aligned} K &= K_1\times K_2\times\cdots \times K_n\\ K' &= K_1'\times K_2\times\cdots \times K_n\\ K'' &= K_1''\times K_2\times\cdots \times K_n \end{aligned}$$

so that again $K = K'\cap K''$. Suppose that *F*(*z*) is a complex analytic matrix-valued function on a rectangle *K* in **C**<sup>*n*</sup> such that *F*(*z*) is an invertible matrix for each *z* in *K*. Then there exist analytic functions $F'$ in $K'$ and $F''$ in $K''$ such that

$$F(z) = F'(z)F''(z)$$

in *K*.

- In [potential theory](wikipedia://en/1431342), a result that estimates the [Hausdorff measure](wikipedia://en/504109) of the set on which a logarithmic [Newtonian potential](wikipedia://en/814816) is small. See [Cartan's lemma (potential theory)](wikipedia://en/27429912).
