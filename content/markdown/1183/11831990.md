# Bloch's theorem (complex analysis)

::: {#o1 .subject cue=lead name="Bloch's theorem"}

In [complex analysis](wikipedia://en/5759), a branch of [mathematics](wikipedia://en/18831), **Bloch's theorem** describes the behaviour of [holomorphic functions](wikipedia://en/14110) defined on the [unit disk](wikipedia://en/252738). It gives a lower bound on the size of a disk in which an inverse to a holomorphic function exists. It is named after [André Bloch](wikipedia://en/11772883).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let *f* be a holomorphic function in the unit disk |*z*| ≤ 1 for which

$$|f'(0)|=1$$

Bloch's theorem states that there is a disk S ⊂ D on which f is [biholomorphic](wikipedia://en/6077963) and f(S) contains a disk with radius 1/72.

:::

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Landau's theorem"}

## Landau's theorem {#Landau's_theorem}

If *f* is a holomorphic function in the unit disk with the property |*f′*(0)| = 1, then let *L<sub>f</sub>* be the radius of the largest disk contained in the image of *f*.

Landau's theorem states that there is a constant *L* defined as the infimum of *L<sub>f</sub>* over all such functions *f*, and that *L* is greater than Bloch's constant *L* ≥ *B*.

This theorem is named after [Edmund Landau](wikipedia://en/222230).

:::

::: {#o7 .statement kind=statement/theorem cue=named-heading name="Valiron's theorem"}

## Valiron's theorem {#Valiron's_theorem}

Bloch's theorem was inspired by the following theorem of [Georges Valiron](https://en.wikipedia.org/wiki/Georges_Valiron):

::: {#o8 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** If *f* is a non-constant entire function then there exist disks *D* of arbitrarily large radius and analytic functions φ in *D* such that *f*(φ(*z*)) = *z* for *z* in *D*.

Bloch's theorem corresponds to Valiron's theorem via the [Bloch's principle](wikipedia://en/34529648).

:::

:::

::: {#o10 .proof cue=heading name="Proof"}

## Proof {#Proof}

::: {#o12 .statement kind=statement/theorem cue=named-heading name="Landau's theorem"}

### Landau's theorem {#Landau's_theorem}

We first prove the case when *f*(0) = 0, *f′*(0) = 1, and |*f′*(*z*)| ≤ 2 in the unit disk.

By [Cauchy's integral formula](wikipedia://en/72827), we have a bound

$$|f''(z)|=\left|\frac{1}{2\pi i}\oint_\gamma\frac{f'(w)}{(w-z)^2}\,\mathrm{d}w\right|\le\frac{1}{2\pi}\cdot2\pi r\sup_{w=\gamma(t)}\frac{|f'(w)|}{|w-z|^2}\le\frac{2}{r},$$

where γ is the counterclockwise circle of radius *r* around *z*, and 0 \< *r* \< 1 − |*z*|.

By [Taylor's theorem](wikipedia://en/51714), for each *z* in the unit disk, there exists 0 ≤ *t* ≤ 1 such that *f*(*z*) = *z* + *z*<sup>2</sup>*f″*(*tz*) / 2.

Thus, if |*z*| = 1/3 and |*w*| \< 1/6, we have

$$|(f(z)-w)-(z-w)|=\frac12|z|^2|f''(tz)|\le\frac{|z|^2}{1-t|z|}\le\frac{|z|^2}{1-|z|}=\frac16<|z|-|w|\le|z-w|.$$

By [Rouché's theorem](wikipedia://en/1141150), the range of *f* contains the disk of radius 1/6 around 0.

Let *D*(*z*<sub>0</sub>, *r*) denote the open disk of radius *r* around *z*<sub>0</sub>. For an analytic function *g* : *D*(*z*<sub>0</sub>, *r*) → **C** such that *g*(*z*<sub>0</sub>) ≠ 0, the case above applied to (*g*(*z*<sub>0</sub> + *rz*) − *g*(*z*<sub>0</sub>)) / (*rg′*(0)) implies that the range of *g* contains *D*(*g*(*z*<sub>0</sub>), |*g′*(0)|*r* / 6).

For the general case, let *f* be an analytic function in the unit disk such that |*f′*(0)| = 1, and *z*<sub>0</sub> = 0.

- If |*f′*(*z*)| ≤ 2|*f′*(*z*<sub>0</sub>)| for |*z* − *z*<sub>0</sub>| \< 1/4, then by the first case, the range of *f* contains a disk of radius |*f′*(z<sub>0</sub>)| / 24 = 1/24.
- Otherwise, there exists *z*<sub>1</sub> such that |*z*<sub>1</sub> − *z*<sub>0</sub>| \< 1/4 and |*f′*(*z*<sub>1</sub>)| > 2|*f′*(*z*<sub>0</sub>)|.
- If |*f′*(*z*)| ≤ 2|*f′*(*z*<sub>1</sub>)| for |*z* − *z*<sub>1</sub>| \< 1/8, then by the first case, the range of *f* contains a disk of radius |*f′*(*z*<sub>1</sub>)| / 48 > |*f′*(z<sub>0</sub>)| / 24 = 1/24.
- Otherwise, there exists *z*<sub>2</sub> such that |*z*<sub>2</sub> − *z*<sub>1</sub>| \< 1/8 and |*f′*(*z*<sub>2</sub>)| > 2|*f′*(*z*<sub>1</sub>)|.

Repeating this argument, we either find a disk of radius at least 1/24 in the range of *f*, proving the theorem, or find an infinite sequence (*z<sub>n</sub>*) such that |*z<sub>n</sub>* − *z*<sub>*n*−1</sub>| \< 1/2<sup>*n*+1</sup> and |*f′*(*z<sub>n</sub>*)| > 2|*f′*(*z*<sub>*n*−1</sub>)|.

In the latter case the sequence is in *D*(0, 1/2), so *f′* is unbounded in *D*(0, 1/2), a contradiction.

:::

::: {#o14 .statement kind=statement/theorem cue=named-heading name="Bloch's theorem"}

### Bloch's theorem {#Bloch's_theorem}

In the proof of Landau's Theorem above, Rouché's theorem implies that not only can we find a disk *D* of radius at least 1/24 in the range of *f*, but there is also a small disk *D*<sub>0</sub> inside the unit disk such that for every *w* ∈ *D* there is a unique *z* ∈ *D*<sub>0</sub> with *f*(*z*) = *w*. Thus, *f* is a [bijective](https://en.wikipedia.org/wiki/Bijective) analytic function from *D*<sub>0</sub> ∩ *f*<sup>−1</sup>(*D*) to *D*, so its inverse φ is also analytic by the [inverse function theorem](wikipedia://en/287229).

:::

:::

## Bloch's and Landau's constants {#Bloch's_and_Landau's_constants}

The number *B* is called **Bloch's constant**. The lower bound 1/72 in Bloch's theorem is not the best possible. Bloch's theorem tells us *B* ≥ 1/72, but the exact value of *B* is still unknown.

The best known bounds for *B* at present are

$$0.4332\approx\frac{\sqrt{3}}{4}+2\times10^{-4}\leq B\leq \sqrt{\frac{\sqrt{3}-1}{2}} \cdot \frac{\Gamma(\frac{1}{3})\Gamma(\frac{11}{12})}{\Gamma(\frac{1}{4})}\approx 0.47186,$$

where Γ is the [Gamma function](wikipedia://en/12316). The lower bound was proved by Chen and Gauthier, and the upper bound dates back to [Ahlfors](wikipedia://en/61636) and Grunsky.

The similarly defined optimal constant *L* in Landau's theorem is called **Landau's constant**. Its exact value is also unknown, but it is known that

$$0.5 < L \le \frac{\Gamma(\frac{1}{3})\Gamma(\frac{5}{6})}{\Gamma(\frac{1}{6})} = 0.543258965342... \,\!$$

In their paper, Ahlfors and Grunsky conjectured that their upper bounds are actually the true values of *B* and *L*.

For [injective](https://en.wikipedia.org/wiki/Injective) holomorphic functions on the unit disk, a constant *A* can similarly be defined. It is known that

$$0.5 < A \le 0.7853$$
