# List of numerical libraries

::: {#o1 .subject cue=lead name="List of numerical libraries"}

This is a list of **numerical libraries**, which are [libraries](https://en.wikipedia.org/wiki/Library_%28computing%29) used in [software development](https://en.wikipedia.org/wiki/Software_development) for performing [numerical](wikipedia://en/21506) calculations. It is not a complete listing but is instead a list of numerical libraries with articles on Wikipedia, with few exceptions.

:::

The choice of a typical library depends on a range of requirements such as: desired features (e.g. large dimensional linear algebra, parallel computation, partial differential equations), licensing, readability of API, portability or platform/compiler dependence (e.g. Linux, Windows, Visual C++, GCC), performance, ease-of-use, continued support from developers, standard compliance/precision/reproducibility, specialized optimization in code for specific application scenario, or even the size of the code-base to be installed.

This list is sorted by from what languages a library is designed to be usable, not by what the libraries are written in (an implementation detail).

Some numerical tasks are performed by [standard library](https://en.wikipedia.org/wiki/Standard_library) functions. These are not listed here, though some "see also" links to relevant pages may be included.

## Multi-language {#Multi-language}

On most computer systems, the C [application binary interface](https://en.wikipedia.org/wiki/Application_binary_interface) (ABI) functions as a "lingua franca" ABI callable from a variety of languages via a [foreign function interface](https://en.wikipedia.org/wiki/Foreign_function_interface). This makes the "C" section also multi-language. To resolve this ambiguity, this section specifically lists libraries with more than one *designed* interfaces, e.g. a C API/ABI and a Fortran API/ABI.

### BLAS, LAPACK, etc. {#BLAS,_LAPACK,_etc.}

::: {#o4 .entry cue=list-entry name="BLAS"}

- [BLAS](https://en.wikipedia.org/wiki/BLAS) (Basic Linear Algebra Subprograms) is a [application programming interface](https://en.wikipedia.org/wiki/Application_programming_interface) standard for libraries that perform basic [linear algebra](wikipedia://en/18422) operations such as [vector](wikipedia://en/32370) and [matrix multiplication](wikipedia://en/125280).

:::

::: {#o5 .entry cue=list-entry name="LAPACK"}

- [LAPACK](wikipedia://en/1013768)[^o6][^o7] (Linear Algebra Package) is a [software library](https://en.wikipedia.org/wiki/Software_library) for [numerical computing](https://en.wikipedia.org/wiki/Numerical_computation) originally written in [FORTRAN 77](https://en.wikipedia.org/wiki/Fortran) and now written in [Fortran 90](https://en.wikipedia.org/wiki/Fortran).

:::

Both of these used to be Fortran-only software libraries that later gained C interfaces. Both of these libraries were originally hosted on the [Netlib](https://en.wikipedia.org/wiki/Netlib) repository with very permissive licenses, resulting in them being widely [forked](https://en.wikipedia.org/wiki/Fork_%28software_development%29) and turning into *de facto* API standards. BLAS has since officially evolved into an interface specification.

Related libraries that have remained Fortran-only include:

::: {#o8 .entry cue=list-entry name="EISPACK"}

- [EISPACK](https://en.wikipedia.org/wiki/EISPACK) is a [software library](https://en.wikipedia.org/wiki/Software_library) for [numerical computation](https://en.wikipedia.org/wiki/Numerical_computation) of [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) and [eigenvectors](https://en.wikipedia.org/wiki/Eigenvectors) of matrices,[^o9] written in [FORTRAN](https://en.wikipedia.org/wiki/FORTRAN). It contains subroutines for calculating the eigenvalues of nine classes of [matrices](https://en.wikipedia.org/wiki/Matrix_%28Mathematics%29): complex general, complex [Hermitian](https://en.wikipedia.org/wiki/Hermitian), real general, real symmetric, real symmetric [banded](wikipedia://en/1451476), real symmetric tridiagonal, special real tridiagonal, generalized real, and generalized real symmetric matices.

:::

::: {#o10 .entry cue=list-entry name="LINPACK"}

- [LINPACK](https://en.wikipedia.org/wiki/LINPACK) is a software [library](https://en.wikipedia.org/wiki/Library_%28computer_science%29) for performing numerical [linear algebra](wikipedia://en/18422) on digital computers.[^o11][^o12][^o13] It was written in [Fortran](https://en.wikipedia.org/wiki/Fortran) by [Jack Dongarra](https://en.wikipedia.org/wiki/Jack_Dongarra), Jim Bunch, [Cleve Moler](wikipedia://en/562706), and Pete Stewart, and was intended for use on [supercomputers](https://en.wikipedia.org/wiki/Supercomputer) in the 1970s and early 1980s. It has been largely superseded by [LAPACK](wikipedia://en/1013768), which will run more efficiently on modern architectures.

:::

These two have superseded, but as their inclusion in Intel MKL show, they were also widely-forked *de facto* standards in their hayday.

### Numerically-oriented programming languages {#Numerically-oriented_programming_languages}

A few programming languages are designed for numerical work. These include [GNU Octave](wikipedia://en/48707), Maple, MATLAB, Mathematica, [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), etc. Programs written in these languages may be invoked from a variety of programing languages.

## OCaml {#OCaml}

[OCaml](https://en.wikipedia.org/wiki/OCaml) programming language has support for array programming in the standard library, also with a specific module named bigarrays for multi-dimensional, numerical arrays, with both C and Fortran layout options. A comprehensive support of numerical computations is provided by the library [Owl Scientific Computing](https://en.wikipedia.org/wiki/Owl_Scientific_Computing) which provides methods for statistics, linear algebra (using OpenBLAS), differential equations, algorithmic differentiation, Fourier fast transform, or deep neural networks.[^o25] Other numerical libraries in OCaml are [Lacaml](https://mmottl.github.io/lacaml/) that interfaces BLAS and LAPACK Fortran/C libraries, [L-BFGS-ocaml](https://github.com/Chris00/L-BFGS-ocaml) (OCaml bindings for L-BFGS). For visualization there are libraries for plotting using [PLplot](https://en.wikipedia.org/wiki/PLplot), [gnuplot](https://en.wikipedia.org/wiki/Gnuplot) or [matplotlib](https://en.wikipedia.org/wiki/Matplotlib).

## Perl {#Perl}

::: {#o27 .entry cue=list-entry name="Perl Data Language"}

- [Perl Data Language](https://en.wikipedia.org/wiki/Perl_Data_Language) gives standard Perl the ability to compactly store and speedily manipulate the large *N*-dimensional data arrays.[^o28] It can perform complex and matrix maths, and has interfaces for the [GNU Scientific Library](https://en.wikipedia.org/wiki/GNU_Scientific_Library), [LINPACK](https://en.wikipedia.org/wiki/LINPACK), [PROJ](https://en.wikipedia.org/wiki/PROJ), and plotting with [PGPLOT](https://en.wikipedia.org/wiki/PGPLOT). There are libraries on [CPAN](https://en.wikipedia.org/wiki/CPAN) adding support for the linear algebra library [LAPACK](wikipedia://en/1013768),[^o29] the Fourier transform library [FFTW](https://en.wikipedia.org/wiki/Fastest_Fourier_Transform_in_the_West),[^o30] and plotting with [gnuplot](https://en.wikipedia.org/wiki/Gnuplot),[^o31] and [PLplot](https://en.wikipedia.org/wiki/PLplot).[^o32]

:::
