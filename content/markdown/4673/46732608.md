# Finsler's lemma

::: {#o1 .subject cue=lead name="Finsler's lemma"}

**Finsler's lemma** is a mathematical result named after [Paul Finsler](wikipedia://en/27007280). It states equivalent ways to express the [positive definiteness](https://en.wikipedia.org/wiki/Positive_definite) of a [quadratic form](wikipedia://en/251478) *Q* constrained by a [linear form](wikipedia://en/214137) *L*. Since it is equivalent to another lemmas used in optimization and [control theory](wikipedia://en/7039), such as [Yakubovich's S-lemma](wikipedia://en/48706354),[^o2] Finsler's lemma has been given many proofs and has been widely used, particularly in results related to [robust optimization](wikipedia://en/8232682) and [linear matrix inequalities](wikipedia://en/5410577).

:::

::: {#o4 .statement cue=heading name="Statement of Finsler's lemma"}

## Statement of Finsler's lemma {#Statement_of_Finsler's_lemma}

Let $x \in \mathbb{R}^n$, and $Q \in \mathbb{R}^{n \times n}$ and $L \in \mathbb{R}^{n \times n}$ be symmetric matrices. The following statements are equivalent:[^o5]

- $$\displaystyle x^{T}Lx=0 \text{ and } x \ne 0 \text{ implies } x^T Q x < 0.$$
- $$\exists \mu \in \mathbb{R} : Q - \mu L \prec 0.$$

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="Variants"}

## Variants {#Variants}

::: {#o9 .statement kind=statement/lemma cue=named-heading name="Non-Strict Finsler Lemma"}

### Non-Strict Finsler Lemma {#Non-Strict_Finsler_Lemma}

When the matrix *L* is indefinite, replacing strict inequalities with non-strict ones still maintains the equivalence between the statements of Finsler's lemma. However, if *L* is not indefinite, additional assumptions are necessary to ensure equivalence between the statements.[^o10]

:::

### Extra equivalences when *L* is positive semi-definite {#Extra_equivalences_when_L_is_positive_semi-definite}

In the particular case that *L* is positive semi-definite, it is possible to decompose it as $L = B^{T}B$. The following statements, which are also referred as Finsler's lemma in the literature, are equivalent:[^o12]

- $$x^T Q x < 0 \text{ for all } x \in \ker(B)\smallsetminus\{0\}$$
- $$B^{\perp^T} Q B^\perp \prec 0$$
- $$\exists \mu \in \mathbb{R} : Q - \mu B^T B \prec 0$$
- $$\exists X \in \mathbb{R}^{n \times m} : Q + XB + B^T X^T \prec 0$$

::: {#o14 .statement kind=statement/lemma cue=named-heading name="Matrix Finsler's lemma"}

### Matrix Finsler's lemma {#Matrix_Finsler's_lemma}

There is also a variant of Finsler's lemma for quadratic matrix inequalities, known as **matrix Finsler's lemma**, which states that the following statements are equivalent for symmetric matrices *Q* and *L* belonging to **R**<sup>(*l*+*k*)x(*l*+*k*)</sup>:[^o15][^o16]

- $$\left[\begin{array}{l} I \\ Z \end{array}\right]^{\top} Q\left[\begin{array}{l} I \\ Z \end{array}\right] \succeq 0 \text{ for all } Z \in \mathbb{R}^{l \times k} \text { such that }\left[\begin{array}{l} I \\ Z \end{array}\right]^{\top} L\left[\begin{array}{l} I \\ Z \end{array}\right]=0$$
- $$\exists \mu \in \mathbb{R} : Q - \mu L \succeq 0$$

under the assumption that

$Q = \begin{bmatrix} Q_{11} & Q_{12} \\ Q_{12}^T & Q_{22} \end{bmatrix}$ and $L = \begin{bmatrix} L_{11} & L_{12} \\ L_{12}^T & L_{22} \end{bmatrix}$

satisfy the following assumptions:

1. *Q*<sub>12</sub> = 0 and *Q*<sub>22</sub> \< 0,
1. *L*<sub>22</sub> \< 0, and *L*<sub>11</sub> - *L*<sub>12</sub>*L*<sub>22</sub><sup>\+</sup>*L*<sub>12</sub> = 0, and
1. there exists a matrix *G* such that *Q*<sub>11</sub> + *G*<sup>T</sup>*Q*<sub>22</sub>*G* > 0 and *L*<sub>22</sub>*G* = *L*<sub>12</sub><sup>T</sup><sub>.</sub>

:::

## Generalizations {#Generalizations}

::: {#o20 .statement kind=statement/lemma cue=named-heading name="Projection lemma"}

### Projection lemma {#Projection_lemma}

The equivalence between the following statements is also common on the literature of [linear matrix inequalities](wikipedia://en/5410577), and is known as the Projection Lemma (or also as Elimination Lemma):[^o21]

- $$B^{\perp^T} Q B^\perp \prec 0 \text{ and } C^{T \perp T} Q C^{T \perp} \prec 0$$
- $$\exists X \in \mathbb{R}^{n \times m} : Q + CXB + B^T X^T C^T \prec 0$$

This lemma generalizes one of the Finsler's lemma variants by including an extra matrix *C* and an extra constraint involving this extra matrix.

It is interesting to note that if the strict inequalities are changed to non-strict inequalities, the equivalence does not hold anymore: only the second statement imply the first statement. Nevertheless, it still possible to obtain the equivalence between the statements under extra assumptions.[^o22]

:::

### Robust version {#Robust_version}

Finsler's lemma also generalizes for matrices *Q* and *B* depending on a parameter *s* within a set *S*. In this case, it is natural to ask if the same variable μ (respectively *X*) can satisfy $Q(s)-\mu B^{T}(s)B(s) \prec 0$ for all $s\in S$ (respectively, $Q(s) + X(s)B(s)+B^T(s)X^T(s) \prec 0$). If *Q* and *B* depends continuously on the parameter *s*, and *S* is [compact](https://en.wikipedia.org/wiki/Compact_car), then this is true. If *S* is not compact, but *Q* and *B* are still continuous matrix-valued functions, then μ and *X* can be guaranteed to be at least continuous functions.[^o24]

:::

::: {#o26 .application cue=heading name="Applications"}

## Applications {#Applications}

### Data-driven control {#Data-driven_control}

The matrix variant of Finsler lemma has been applied to the data-driven control of Lur'e systems[^o15] and in a data-driven robust linear matrix inequality-based model predictive control scheme.[^o28]

### S-Variable approach to robust control of linear dynamical systems {#S-Variable_approach_to_robust_control_of_linear_dynamical_systems}

Finsler's lemma can be used to give novel linear matrix inequality (LMI) characterizations to stability and control problems.[^o12] The set of LMIs stemmed from this procedure yields less conservative results when applied to control problems where the system matrices has dependence on a parameter, such as [robust control](wikipedia://en/3282143) problems and control of linear-parameter varying systems.[^o30] This approach has recently been called as S-variable approach[^o31][^o32] and the LMIs stemming from this approach are known as SV-LMIs (also known as dilated LMIs[^o33]).

### Sufficient condition for universal stabilizability of non-linear systems {#Sufficient_condition_for_universal_stabilizability_of_non-linear_systems}

A [nonlinear system](wikipedia://en/146103) has the universal stabilizability property if every forward-complete solution of a system can be globally stabilized. By the use of Finsler's lemma, it is possible to derive a sufficient condition for universal stabilizability in terms of a differential linear matrix inequality.[^o35]

:::
