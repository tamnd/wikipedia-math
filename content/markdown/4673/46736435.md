# Poincaré–Miranda theorem

::: {#o1 .subject cue=lead name="Poincaré–Miranda theorem"}

In mathematics, the **Poincaré–Miranda theorem** is a generalization of [intermediate value theorem](wikipedia://en/14884), from a single function in a single dimension, to $n$ functions in $n$ dimensions. It says as follows:

:::

Consider $n$ continuous, real-valued functions of $n$ variables, $f_1,\ldots, f_n\colon [-1,1]^n\to \mathbb{R}$. Assume that for each variable $x_i$, the function $f_i$ is nonpositive when $x_i=-1$ and nonnegative when $x_i=1$. Then there is a point in the $n$-dimensional [cube](wikipedia://en/6285) $[-1,1]^n$ in which all functions are *simultaneously* equal to $0$.

The theorem is named after [Henri Poincaré](wikipedia://en/48740) — who conjectured it in 1883 — and [Carlo Miranda](wikipedia://en/49974918) — who in 1940 showed that it is equivalent to the [Brouwer fixed-point theorem](wikipedia://en/4101).[^o2][^o3]p. 545[^o4] It is sometimes called the **Miranda theorem** or the **Bolzano–Poincaré–Miranda theorem.**[^o5]

## Intuitive description {#Intuitive_description}

The picture on the right shows an illustration of the Poincaré–Miranda theorem for $n = 2$ functions. Consider a couple of functions $(f,g)$ whose [domain of definition](wikipedia://en/50263) is $[-1,1]^{2}$ (i.e., the unit square). The function $f$ is negative on the left boundary and positive on the right boundary (green sides of the square), while the function $g$ is negative on the lower boundary and positive on the upper boundary (red sides of the square). When we go from left to right along *any* path, we must go through a point in which $f$ is $0$. Therefore, there must be a "wall" separating the left from the right, along which $f$ is $0$ (green curve inside the square). Similarly, there must be a "wall" separating the top from the bottom, along which $g$ is $0$ (red curve inside the square). These walls must intersect in a point in which both functions are $0$ (blue point inside the square).

## Generalizations {#Generalizations}

The simplest generalization, as a matter of fact a [corollary](wikipedia://en/168865), of this theorem is the following one. For every variable $x_{i}$, let $a_{i}$ be any value in the range $[\sup_{x_{i} = 0} f_{i}, \inf_{x_{i} = 1} f_{i}]$. Then there is a point in the unit cube in which for all $i$:

$$f_i=a_i.$$

This statement can be reduced to the original one by a simple [translation of axes](wikipedia://en/47331006),

$$x^\prime_i=x_i\qquad y^\prime_i=y_i-a_i\qquad \forall i\in\{1,\dots,n\}$$

where

- $x_{i}$ are the [coordinates](https://en.wikipedia.org/wiki/Coordinates) in the domain of the function
- $y_{i}$ are the coordinates in the [codomain](wikipedia://en/50264) of the function.

By using [topological degree theory](wikipedia://en/18203720) it is possible to prove yet another generalization.[^o9] Poincare-Miranda was also generalized to infinite-dimensional spaces.[^o10]
