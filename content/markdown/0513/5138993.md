# Admissible set

::: {#o1 .subject cue=lead name="Admissible set"}

In [set theory](wikipedia://en/27553), a discipline within mathematics, an **admissible set** is a [transitive set](wikipedia://en/2462396) $A\,$ such that $\langle A,\in \rangle$ is a [model](wikipedia://en/19858) of [Kripke–Platek set theory](wikipedia://en/1124695) (Barwise 1975).

:::

The smallest example of an admissible set is the set of [hereditarily finite sets](wikipedia://en/332621). Another example is the set of [hereditarily countable sets](wikipedia://en/5126046).
