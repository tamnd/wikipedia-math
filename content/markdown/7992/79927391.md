# Krasnoselskii genus

::: {#o1 .subject cue=lead name="Krasnoselskii genus"}

In [nonlinear functional analysis](wikipedia://en/8546912), the **Krasnoselskii genus** generalizes the notion of [dimension](wikipedia://en/8398) for [vector spaces](https://en.wikipedia.org/wiki/Vector_spaces). The Krasnoselskii genus of a linear space $A$ is the smallest [natural number](wikipedia://en/21474) $n$ for which there exists a [continuous](wikipedia://en/6122) [odd function](https://en.wikipedia.org/wiki/Odd_function) of the form $f : A \to \mathbb{R}^n \setminus {0}$. The genus was introduced by [Mark Aleksandrovich Krasnoselskii](https://en.wikipedia.org/wiki/Mark_Krasnoselsky) in 1964,[^o2] and an equivalent definition was provided by Charles Coffman in 1969.[^o3]

:::

## Krasnoselskii Genus {#Krasnoselskii_Genus}

We follow the definition given by Coffman.[^o3]

Let

- $E$ be a [Banach space](wikipedia://en/3989),
- $\mathcal{A} = \{A \subset E : A \text{ closed},; A = -A\}$ be the collection of symmetric closed subsets of $E$,
- $C(A,\mathbb{R}^n)$ the space of continuous functions $A \to \mathbb{R}^n$.

For $A \in \mathcal{A}$ define the set

$$K_A =\{ n \in \mathbb{N} : \exists f \in C(A,\mathbb{R}^n \setminus {0}),; f(-x) = -f(x)\}$$

Then the Krasnoselskii genus of $A$ is defined as[^o5]

$$\gamma(A)=\begin{cases}\inf K_A &\text{if }K_A\neq \emptyset,\\ \infty &\text{if }K_A=\emptyset, \\ 0 & \text{if } A=\emptyset.\end{cases}$$

In other words, if $\gamma(A) = n$ then there exists a continuous odd function $\varphi : A \to \mathbb{R}^n$ such that $0 \notin \varphi(A)$. Moreover $n$ is the minimal possible dimension, i.e. there exists no such function $\theta : A \to \mathbb{R}^d$ with $d < n$.

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- Let $\Omega \subset \mathbb{R}^n$ be a bounded symmetric neighborhood of $0$ in $\mathbb{R}^n$. Then the genus of its boundary is $\gamma(\partial \Omega) = n$.[^o8]
- For $A, B \in \mathcal{A}$, the following holds:[^o9]

<!-- -->

1. If there exists an odd function $f \in C(A, B)$, then $\gamma(A) \leq \gamma(B)$.
1. If $A \subset B$, then $\gamma(A) \leq \gamma(B)$.
1. If there exists an odd [homeomorphism](wikipedia://en/13660) between $A$ and $B$, then $\gamma(A) = \gamma(B)$.

Combining these statements, it follows immediately that if there exists an odd homeomorphism between $A$ and $\partial \Omega$ then $\gamma(A) = n$.

:::
