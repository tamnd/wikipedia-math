# Transit route network design problem

::: {#o1 .subject cue=lead name="Transit route network design problem"}

The **transit route network design problem** is a [mathematical optimization](wikipedia://en/52033) problem in the context of [transportation networks](https://en.wikipedia.org/wiki/Transportation_network_%28graph_theory%29) with well-defined stops, routes and timetables such as [bus](https://en.wikipedia.org/wiki/Bus) and [railway](https://en.wikipedia.org/wiki/Railway) networks.[^o2][^o3]

:::

The problem can be broken down into five subproblems: [transportation network design](https://en.wikipedia.org/wiki/Transportation_network_design), [frequency setting](https://en.wikipedia.org/wiki/Frequency_setting), [timetable development](https://en.wikipedia.org/wiki/Timetable_development), [vehicle scheduling](https://en.wikipedia.org/wiki/Vehicle_scheduling), and [crew scheduling](https://en.wikipedia.org/wiki/Crew_scheduling).[^o4]
