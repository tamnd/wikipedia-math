# Sawmill (software)

::: {#o1 .subject cue=lead name="Sawmill"}

**Sawmill** was a software package for the [statistical analysis](https://en.wikipedia.org/wiki/Log_analysis) and reporting of [log files](https://en.wikipedia.org/wiki/Logging_%28computing%29). Sawmill also incorporated real-time reporting and alerting.

:::

Sawmill supported approximately 850 server log file formats. It included a [page-tagging](wikipedia://en/2475872#Page_tagging) server and a JavaScript [page tag](https://en.wikipedia.org/wiki/Page_tag) for analyzing client-side clicks (client requests), providing a view of visitor traffic and on-site activity.

Sawmill Analytics was offered in three forms: a software package for user deployment, a system appliance for use on-premises, and an application for [software as a service (SaaS)](https://en.wikipedia.org/wiki/Software_as_a_service). Sawmill analyzed devices or software packages to produce a log file that included [web servers](https://en.wikipedia.org/wiki/Web_server), [firewalls](https://en.wikipedia.org/wiki/Firewall_%28computing%29), [proxy servers](https://en.wikipedia.org/wiki/Proxy_server), [mail servers](https://en.wikipedia.org/wiki/Mail_transfer_agent), [network devices](https://en.wikipedia.org/wiki/Computer_network), [syslog servers](https://en.wikipedia.org/wiki/Syslog), and [databases](https://en.wikipedia.org/wiki/Database).

Branded versions of Sawmill included *Sawmill for IronPort* by [Cisco Systems](https://en.wikipedia.org/wiki/Cisco_Systems),[^o3] *InterGate Intelligence* by Vicomsoft Ltd,[^o4] and SonicWALL Aventail Advanced Reporting by [SonicWALL](https://en.wikipedia.org/wiki/SonicWALL).[^o5]

Sawmill went out of business on 17 May 2021.[^o6]
