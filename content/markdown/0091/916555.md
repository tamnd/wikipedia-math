# Corkscrew (program)

::: {#o1 .subject cue=lead name="Corkscrew"}

**Corkscrew** is a computer program, written by Patrick Padgett, that enables the user to tunnel [SSH](https://en.wikipedia.org/wiki/SSH) connections through most [HTTP](https://en.wikipedia.org/wiki/HTTP) and [HTTPS](wikipedia://en/13586) [proxy servers](https://en.wikipedia.org/wiki/Proxy_server).[^o2] Combined with features of [SSH](wikipedia://en/28814) such as [port forwarding](https://en.wikipedia.org/wiki/Port_forwarding), this can allow many types of services to be run securely over the SSH via HTTP connections.

:::

Supported proxy servers:

- [Gauntlet](https://en.wikipedia.org/wiki/Gauntlet_%28proxy_server%29)
- [CacheFlow](https://en.wikipedia.org/wiki/CacheFlow)
- [Internet Junkbuster](https://en.wikipedia.org/wiki/Internet_Junkbuster)
- [Squid](https://en.wikipedia.org/wiki/Squid_%28software%29)
- Apache's [mod\_proxy](https://en.wikipedia.org/wiki/Mod_proxy)
