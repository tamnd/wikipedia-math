# Joint entropy

*Image: Entropy-mutual-information-relative-entropy-relation-diagram.svg.* A [Venn diagram](wikipedia://en/61701) showing additive, and subtractive relationships between various [information measures](wikipedia://en/6101309) associated with correlated variables X and Y. The area contained by both circles is the joint entropy H(X,Y). The circle on the left (red and violet) is the [individual entropy](wikipedia://en/15445) H(X), with the red being the [conditional entropy](wikipedia://en/908548) H(X$|$Y). The circle on the right (blue and violet) is H(Y), with the blue being H(Y$|$X). The violet is the [mutual information](wikipedia://en/427282) I(X;Y).

::: {#o1 .subject cue=lead name="Joint entropy"}

In [information theory](wikipedia://en/14773), **joint [entropy](wikipedia://en/15445)** is a measure of the uncertainty associated with a set of [variables](https://en.wikipedia.org/wiki/Random_variables).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The joint [Shannon entropy](https://en.wikipedia.org/wiki/Shannon_entropy) (in [bits](https://en.wikipedia.org/wiki/Bit)) of two discrete [random variables](wikipedia://en/25685) $X$ and $Y$ with images $\mathcal X$ and $\mathcal Y$ is defined as[^o5]

$$\mathrm{H}(X,Y) = -\sum_{x\in\mathcal X} \sum_{y\in\mathcal Y} P(x,y) \log_2[P(x,y)]$$

where $x$ and $y$ are particular values of $X$ and $Y$, respectively, $P(x,y)$ is the [joint probability](https://en.wikipedia.org/wiki/Joint_probability) of these values occurring together, and $P(x,y) \log_2[P(x,y)]$ is defined to be 0 if $P(x,y)=0$.

For more than two random variables $X_1, ..., X_n$ this expands to

$$\mathrm{H}(X_1, ..., X_n) = -\sum_{x_1 \in\mathcal X_1} ... \sum_{x_n \in\mathcal X_n} P(x_1, ..., x_n) \log_2[P(x_1, ..., x_n)]$$

where $x_1,...,x_n$ are particular values of $X_1,...,X_n$, respectively, $P(x_1, ..., x_n)$ is the probability of these values occurring together, and $P(x_1, ..., x_n) \log_2[P(x_1, ..., x_n)]$ is defined to be 0 if $P(x_1, ..., x_n)=0$.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Nonnegativity {#Nonnegativity}

The joint entropy of a set of random variables is a nonnegative number.

$$\mathrm{H}(X,Y) \geq 0$$

$$\mathrm{H}(X_1,\ldots, X_n) \geq 0$$

### Greater than individual entropies {#Greater_than_individual_entropies}

The joint entropy of a set of variables is greater than or equal to the maximum of all of the individual entropies of the variables in the set.

$$\mathrm{H}(X,Y) \geq \max \left[\mathrm{H}(X),\mathrm{H}(Y) \right]$$

$$\mathrm{H} \bigl(X_1,\ldots, X_n \bigr) \geq \max_{1 \le i \le n} \Bigl\{ \mathrm{H}\bigl(X_i\bigr) \Bigr\}$$

### Less than or equal to the sum of individual entropies {#Less_than_or_equal_to_the_sum_of_individual_entropies}

The joint entropy of a set of variables is less than or equal to the sum of the individual entropies of the variables in the set. This is an example of [subadditivity](wikipedia://en/745789). This inequality is an equality if and only if $X$ and $Y$ are [statistically independent](https://en.wikipedia.org/wiki/Statistically_independent).[^o5]

$$\mathrm{H}(X,Y) \leq \mathrm{H}(X) + \mathrm{H}(Y)$$

$$\mathrm{H}(X_1,\ldots, X_n) \leq \mathrm{H}(X_1) + \ldots + \mathrm{H}(X_n)$$

:::

## Relations to other entropy measures {#Relations_to_other_entropy_measures}

Joint entropy is used in the definition of [conditional entropy](wikipedia://en/908548)[^o5]

$$\mathrm{H}(X|Y) = \mathrm{H}(X,Y) - \mathrm{H}(Y)\,,$$

and

$$\mathrm{H}(X_1,\dots,X_n) = \sum_{k=1}^n \mathrm{H}(X_k|X_{k-1},\dots, X_1).$$

For two variables $X$ and $Y$, this means that

$$\mathrm{H}(X,Y) = \mathrm{H}(Y) + \mathrm{H}(X|Y) = \mathrm{H}(X) + \mathrm{H}(Y|X).$$

Joint entropy is also used in the definition of [mutual information](wikipedia://en/427282)[^o5]

$$\operatorname{I}(X;Y) = \mathrm{H}(X) + \mathrm{H}(Y) - \mathrm{H}(X,Y)\,.$$

In [quantum information theory](https://en.wikipedia.org/wiki/Quantum_information_theory), the joint entropy is generalized into the [joint quantum entropy](https://en.wikipedia.org/wiki/Joint_quantum_entropy).

## Joint differential entropy {#Joint_differential_entropy}

::: {#o14 .definition cue=heading name="Definition"}

### Definition {#Definition}

The above definition is for discrete random variables and just as valid in the case of continuous random variables. The continuous version of discrete joint entropy is called *joint differential (or continuous) entropy*. Let $X$ and $Y$ be a continuous random variables with a [joint probability density function](https://en.wikipedia.org/wiki/Joint_probability_density_function) $f(x,y)$. The differential joint entropy $h(X,Y)$ is defined as[^o5]

$$h(X,Y) = -\int_{\mathcal X , \mathcal Y} f(x,y)\log f(x,y)\,dx dy$$

For more than two continuous random variables $X_1, ..., X_n$ the definition is generalized to:

$$h(X_1, \ldots,X_n) = -\int f(x_1, \ldots,x_n)\log f(x_1, \ldots,x_n)\,dx_1 \ldots dx_n$$

The [integral](wikipedia://en/15532) is taken over the support of $f$. It is possible that the integral does not exist in which case we say that the differential entropy is not defined.

:::

::: {#o16 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

As in the discrete case the joint differential entropy of a set of random variables is smaller or equal than the sum of the entropies of the individual random variables:

$h(X_1,X_2, \ldots,X_n) \le \sum_{i=1}^n h(X_i)$[^o5]

The following chain rule holds for two random variables:

$$h(X,Y) = h(X|Y) + h(Y)$$

In the case of more than two random variables this generalizes to:[^o5]

$$h(X_1,X_2, \ldots,X_n) = \sum_{i=1}^n h(X_i|X_1,X_2, \ldots,X_{i-1})$$

Joint differential entropy is also used in the definition of the [mutual information](wikipedia://en/427282) between continuous random variables:

$$\operatorname{I}(X,Y)=h(X)+h(Y)-h(X,Y)$$

:::
