# Lévy C curve

::: {#o1 .subject cue=lead name="Lévy C curve"}

C curve In [mathematics](wikipedia://en/18831), the **Lévy C curve** is a [self-similar](https://en.wikipedia.org/wiki/Self-similar) [fractal curve](wikipedia://en/4972605) that was first described and whose [differentiability](https://en.wikipedia.org/wiki/Differentiability) properties were analysed by [Ernesto Cesàro](wikipedia://en/605144) in 1906 and [Georg Faber](wikipedia://en/33026490) in 1910, but now bears the name of [French](https://en.wikipedia.org/wiki/France) [mathematician](wikipedia://en/18902) [Paul Lévy](wikipedia://en/556462), who was the first to describe its [self-similarity](wikipedia://en/28782) properties as well as to provide a geometrical construction showing it as a representative curve in the same class as the [Koch curve](wikipedia://en/46959). It is a special case of a period-doubling curve, a [de Rham curve](wikipedia://en/4539673).

:::

## L-system construction {#L-system_construction}

*Image: Levy C construction.png.* First eight stages in the construction of a Lévy C curve

*Image: Levy C Curve.svg.* Lévy C curve (from a L-system, after the first 12 stages)

If using a [Lindenmayer system](https://en.wikipedia.org/wiki/Lindenmayer_system) then the construction of the C curve starts with a straight line. An [isosceles](https://en.wikipedia.org/wiki/Isosceles) triangle with angles of 45°, 90° and 45° is built using this line as its [hypotenuse](wikipedia://en/251366). The original line is then replaced by the other two sides of this triangle.

At the second stage, the two new lines each form the base for another right-angled isosceles triangle, and are replaced by the other two sides of their respective triangle. So, after two stages, the curve takes the appearance of three sides of a rectangle with the same length as the original line, but only half as wide.

At each subsequent stage, each straight line segment in the curve is replaced by the other two sides of a right-angled isosceles triangle built on it. After *n* stages the curve consists of 2<sup>*n*</sup> line segments, each of which is smaller than the original line by a factor of 2<sup>*n*/2</sup>.

This L-system can be described as follows:

| **Variables**: | F |
|---|---|
| **Constants**: | \+ − |
| **Start**: | F |
| **Rules**: | F → +F−−F+ |

where "F" means "draw forward", "+" means "turn clockwise 45°", and "−" means "turn anticlockwise 45°".

The [fractal curve](wikipedia://en/4972605) that is the limit of this "infinite" process is the Lévy C curve. It takes its name from its resemblance to a highly ornamented version of the letter "C". The curve resembles the finer details of the [Pythagoras tree](wikipedia://en/2508505).

The [Hausdorff dimension](wikipedia://en/14294) of the C curve equals 2 (it contains open sets), whereas the boundary has dimension about 1.9340 <https://mathworld.wolfram.com/LevyFractal.html>.

::: {#o4 .statement kind=statement/generalization cue=heading name="Variations"}

### Variations {#Variations}

The standard C curve is built using 45° isosceles triangles. Variations of the C curve can be constructed by using isosceles triangles with angles other than 45°. As long as the angle is less than 60°, the new lines introduced at each stage are each shorter than the lines that they replace, so the construction process tends towards a limit curve. Angles less than 45° produce a fractal that is less tightly "curled".

:::

## IFS construction {#IFS_construction}

*Image: Lévy's C-curve (IFS).jpg.* Lévy C curve (from IFS, infinite levels)

If using an [iterated function system](wikipedia://en/505225) (IFS, or the [chaos game](https://en.wikipedia.org/wiki/Chaos_game) IFS-method actually), then the construction of the C curve is a bit easier. It will need a set of two "rules" which are: Two [points](wikipedia://en/593693) in a [plane](wikipedia://en/19469852) (the [translators](https://en.wikipedia.org/wiki/Translation)), each associated with a [scale factor](https://en.wikipedia.org/wiki/Scale_factor) of 1/$\sqrt{2}$. The first rule is a rotation of 45° and the second −45°. This set will [iterate](https://en.wikipedia.org/wiki/Iterate) a point \[*x*, *y*\] from randomly choosing any of the two rules and use the parameters associated with the rule to scale/rotate and translate the point using a 2D-[transform](https://en.wikipedia.org/wiki/Transformation_%28mathematics%29) function.

Put into formulae:

$$f_1(z)=\frac{(1-i)z}{2}$$

$$f_2(z)=1+\frac{(1+i)(z-1)}{2}$$

from the initial set of points $S_0 = \{0,1\}$.

## Sample Implementation of Levy C Curve {#Sample_Implementation_of_Levy_C_Curve}

```java
// Java Sample Implementation of Levy C Curve

import java.awt.Color;
import java.awt.Graphics;
import java.awt.Graphics2D;
import javax.swing.JFrame;
import javax.swing.JPanel;
import java.util.concurrent.ThreadLocalRandom;

public class C_curve extends JPanel {

    public float x, y, len, alpha_angle;
    public int iteration_n;

    public void paint(Graphics g) {
        Graphics2D g2d = (Graphics2D) g;
        c_curve(x, y, len, alpha_angle, iteration_n, g2d);
    }

    public void c_curve(double x, double y, double len, double alpha_angle, int iteration_n, Graphics2D g) {
        double fx = x; 
        double fy = y;
        double length = len;
        double alpha = alpha_angle;
        int it_n = iteration_n;
        if (it_n > 0) {
            length = (length / Math.sqrt(2));
            c_curve(fx, fy, length, (alpha + 45), (it_n - 1), g); // Recursive Call
            fx = (fx + (length * Math.cos(Math.toRadians(alpha + 45))));
            fy = (fy + (length * Math.sin(Math.toRadians(alpha + 45))));
            c_curve(fx, fy, length, (alpha - 45), (it_n - 1), g); // Recursive Call
        } else {
            Color[] A = {Color.RED, Color.ORANGE, Color.BLUE, Color.DARK_GRAY};
            g.setColor(A[ThreadLocalRandom.current().nextInt(0, A.length)]); //For Choosing Different Color Values
            g.drawLine((int) fx, (int) fy, (int) (fx + (length * Math.cos(Math.toRadians(alpha)))), (int) (fy + (length * Math.sin(Math.toRadians(alpha)))));
        }
    }

    public static void main(String[] args) {
        C_curve points = new C_curve();
        points.x = 200; // Stating x value
        points.y = 100; // Stating y value
        points.len = 150; // Stating length value
        points.alpha_angle = 90; // Stating angle value
        points.iteration_n = 15; // Stating iteration value

        JFrame frame = new JFrame("Points");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.add(points);
        frame.setSize(500, 500);
        frame.setLocationRelativeTo(null);
        frame.setVisible(true);

    }
}
```
