# KSEG (software)

::: {#o2 .subject cue=lead name="KSEG"}

**KSEG** is a free ([GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License)) [interactive geometry software](https://en.wikipedia.org/wiki/Interactive_geometry_software) for exploring [Euclidean geometry](wikipedia://en/9417). It was created by Ilya Baran.[^o3] It runs on [Unix](https://en.wikipedia.org/wiki/Unix)-based platforms. It also compiles and runs on [Mac OS X](https://en.wikipedia.org/wiki/Mac_OS_X) and should run on anything that [Qt](https://en.wikipedia.org/wiki/Qt_%28framework%29) supports. Additionally, it was also ported to [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows).

:::

KSEG is a tool designed to let you easily visualize dynamic properties of [compass and straightedge](https://en.wikipedia.org/wiki/Compass_and_straightedge) construction and to make geometric exploration as fast and easy as possible. KSEG was inspired by [the Geometer's Sketchpad](https://en.wikipedia.org/wiki/The_Geometer's_Sketchpad), but it goes beyond the functionality that Sketchpad provides. KSEG can be used in the classroom, for personal exploration of geometry, or for making high-quality figures for [LaTeX](https://en.wikipedia.org/wiki/LaTeX).[^o4]
