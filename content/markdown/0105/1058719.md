# Harmonic spectrum

::: {#o1 .subject cue=lead name="Harmonic spectrum"}

*Image: Fourier Series-Square wave 3 H (no scale).png.* Approximating a [square wave](wikipedia://en/314652) by $\sin(t) + \sin(3t)/3 + \sin(5t)/5$

A **harmonic spectrum** is a [spectrum](https://en.wikipedia.org/wiki/Spectrum_of_an_operator) containing only frequency components whose [frequencies](wikipedia://en/10779) are [whole number](wikipedia://en/14563) multiples of the [fundamental frequency](https://en.wikipedia.org/wiki/Fundamental_frequency); such frequencies are known as [harmonics](https://en.wikipedia.org/wiki/Harmonic). "The individual partials are not heard separately but are blended together by the ear into a single tone."[^o2]

:::

In other words, if $\omega$ is the fundamental frequency, then a harmonic spectrum has the form

$$\{\dots, -2\omega, -\omega, 0, \omega, 2\omega, \dots\}.$$

A standard result of [Fourier analysis](wikipedia://en/11659) is that a function has a harmonic spectrum if and only if it is [periodic](wikipedia://en/76848).
