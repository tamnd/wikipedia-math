# Generating function (physics)

::: {#o1 .subject cue=lead name="Generating function"}

*Image: Generating\_a\_Sine.png.* Generating a sine from a circle.

In physics, and more specifically in [Hamiltonian mechanics](wikipedia://en/198319), a **generating function** is, loosely, a function whose partial derivatives generate the differential equations that determine a system's dynamics. Common examples are the [partition function](wikipedia://en/312252) of [statistical mechanics](wikipedia://en/28481), the Hamiltonian, and the function which acts as a bridge between two sets of canonical variables when performing a [canonical transformation](wikipedia://en/514534).

:::

## In canonical transformations {#In_canonical_transformations}

There are four basic generating functions, summarized by the following table:[^o3]

::: {#o4 .table cue=table}

| Generating function | Its derivatives |
|---|---|
| $F = F_1(q, Q, t)$ | $p = ~~\frac{\partial F_1}{\partial q} \,\!$ and $P = - \frac{\partial F_1}{\partial Q} \,\!$ |
| $\begin{aligned} F &= F_2(q, P, t) \\ &= F_1 + QP \end{aligned}$ | $p = ~~\frac{\partial F_2}{\partial q} \,\!$ and $Q = ~~\frac{\partial F_2}{\partial P} \,\!$ |
| $\begin{aligned} F &= F_3(p, Q, t) \\ &= F_1 - qp \end{aligned}$ | $q = - \frac{\partial F_3}{\partial p} \,\!$ and $P = - \frac{\partial F_3}{\partial Q} \,\!$ |
| $\begin{aligned} F &= F_4(p, P, t) \\ &= F_1 - qp + QP \end{aligned}$ | $q = - \frac{\partial F_4}{\partial p} \,\!$ and $Q = ~~\frac{\partial F_4}{\partial P} \,\!$ |

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

Sometimes a given Hamiltonian can be turned into one that looks like the [harmonic oscillator](wikipedia://en/13899) Hamiltonian, which is

$$H = aP^2 + bQ^2.$$

For example, with the Hamiltonian

$$H = \frac{1}{2q^2} + \frac{p^2 q^4}{2},$$

where $p$ is the generalized momentum and $q$ is the [generalized coordinate](wikipedia://en/473514), a good canonical transformation to choose would be

::: {#o7 .equation cue=numblk name="1"}

$$P = pq^2 \text{ and }Q = \frac{-1}{q}. \tag{1}$$

:::

This turns the Hamiltonian into

$$H = \frac{Q^2}{2} + \frac{P^2}{2},$$

which is in the form of the harmonic oscillator Hamiltonian.

The generating function $F$ for this transformation is of the third kind,

$$F = F_3(p,Q).$$

To find $F$ explicitly, use the equation for its derivative from the table above,

$$P = - \frac{\partial F_3}{\partial Q},$$

and substitute the expression for $P$ from equation ((1)), expressed in terms of $p$ and $Q$:

$$\frac{p}{Q^2} = - \frac{\partial F_3}{\partial Q}$$

Integrating this with respect to $Q$ results in an equation for the generating function of the transformation given by equation ((1)):

To confirm that this is the correct generating function, verify that it matches ((1)):

$$q = - \frac{\partial F_3}{\partial p} = \frac{-1}{Q}$$

:::
