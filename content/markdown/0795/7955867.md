# DFC (cipher)

::: {#o2 .subject cue=lead name="DFC"}

In [cryptography](wikipedia://en/18934432), **DFC** (**Decorrelated Fast Cipher**) is a [symmetric](wikipedia://en/53042) [block cipher](wikipedia://en/4594) which was created in 1998 by a group of researchers from [École Normale Supérieure](https://en.wikipedia.org/wiki/École_Normale_Supérieure), [CNRS](https://en.wikipedia.org/wiki/CNRS), and [France Télécom](https://en.wikipedia.org/wiki/France_Télécom) (including [Jacques Stern](https://en.wikipedia.org/wiki/Jacques_Stern_%28cryptographer%29) and [Serge Vaudenay](https://en.wikipedia.org/wiki/Serge_Vaudenay)) and submitted to the [AES competition](https://en.wikipedia.org/wiki/AES_competition).

:::

Like other AES candidates, DFC operates on blocks of 128 bits, using a key of 128, 192, or 256 bits. It uses an 8-round [Feistel network](https://en.wikipedia.org/wiki/Feistel_network). The round function uses a single 6×32-bit [S-box](https://en.wikipedia.org/wiki/Substitution_box), as well as an [affine transformation](wikipedia://en/38449) mod 2<sup>64</sup>+13. DFC can actually use a key of any size up to 256 bits; the [key schedule](wikipedia://en/609603) uses another 4-round Feistel network to generate a 1024-bit "expanded key". The arbitrary constants, including all entries of the S-box, are derived using the binary expansion of [e](wikipedia://en/9633) as a source of "[nothing up my sleeve numbers](https://en.wikipedia.org/wiki/Nothing_up_my_sleeve_number)".

Soon after DFC's publication, Ian Harvey raised the concern that reduction modulo a 65-bit number was beyond the native capabilities of most platforms, and that careful implementation would be required to protect against [side-channel attacks](wikipedia://en/667678), especially [timing attacks](wikipedia://en/481813). Although DFC was designed using Vaudenay's [decorrelation theory](wikipedia://en/12930296) to be [provably secure](wikipedia://en/1182348) against ordinary [differential](wikipedia://en/8536) and [linear cryptanalysis](wikipedia://en/59469), in 1999 [Lars Knudsen](https://en.wikipedia.org/wiki/Lars_Ramkilde_Knudsen) and [Vincent Rijmen](https://en.wikipedia.org/wiki/Vincent_Rijmen) presented a differential [chosen-ciphertext attack](wikipedia://en/103586) that breaks 6 rounds faster than exhaustive search.

In 2000, Vaudenay, et al. presented an updated version of the algorithm, called **DFCv2**. This variant allows for more choice in the cipher's parameters, and uses a modified key schedule to eliminate certain [weak keys](wikipedia://en/719388) discovered by [Don Coppersmith](wikipedia://en/540090).
