# Critical pair (order theory)

::: {#o1 .subject cue=lead name="Critical pair"}

*Image: Critical pair (order theory).svg.* Hasse diagram of a partial order with a critical pair ⟨*b*,*c*⟩. Adding the \#c0c0c0 line would make *b*\<*c* without requiring any other changes. Conversely, ⟨*c*,*b*⟩ is not a critical pair, since *d*\<*c*, but not *d*\<*b*.

In [order theory](wikipedia://en/361924), a discipline within mathematics, a **critical pair** is a pair of elements in a [partially ordered set](wikipedia://en/23572) that are [incomparable](wikipedia://en/3834818) but that could be made comparable without requiring any other changes to the partial order.

:::

Formally, let $P = (S, \le)$ be a partially ordered set. Then a critical pair is an ordered pair $(x, y)$ of elements of $S$ with the following three properties:

- $x$ and $y$ are incomparable in $P$,
- for every $z$ in $S$, if $z < x$ then $z < y$, and
- for every $z$ in $S$, if $y < z$ then $x < z$.

If $(x, y)$ is a critical pair, then the [binary relation](wikipedia://en/3931) obtained from $P$ by adding the single relationship $x \le y$ is also a partial order. The properties required of critical pairs ensure that, when the relationship $x \le y$ is added, the addition does not cause any violations of the [transitive property](https://en.wikipedia.org/wiki/Transitive_property).

A set $R$ of [linear extensions](wikipedia://en/11726298) of $P$ is said to *reverse* a critical pair $(x, y)$ in $P$ if there exists a linear extension in $R$ for which $y$ occurs earlier than $x$. This property may be used to characterize [realizers](wikipedia://en/3121852) of finite partial orders: A nonempty set $R$ of linear extensions is a realizer if and only if it reverses every critical pair.
