# Probabilistic classification

::: {#o1 .subject cue=lead name="Probabilistic classification"}

In [machine learning](wikipedia://en/233488), a **probabilistic classifier** is a [classifier](wikipedia://en/1579244) that is able to predict, given an observation of an input, a [probability distribution](wikipedia://en/23543) over a [set](wikipedia://en/26691) of classes, rather than only outputting the most likely class that the observation should belong to. Probabilistic classifiers provide classification that can be useful in its own right[^o2] or when combining classifiers into [ensembles](https://en.wikipedia.org/wiki/Ensemble_classifier).

:::

## Types of classification {#Types_of_classification}

Formally, an "ordinary" classifier is some rule, or [function](wikipedia://en/185427), that assigns to a sample $x$ a class label $\text{ŷ}$:

$$\hat{y} = f(x)$$

The samples come from some set $X$ (e.g., the set of all [documents](https://en.wikipedia.org/wiki/Document_classification), or the set of all [images](https://en.wikipedia.org/wiki/Computer_vision#Bababoui)), while the class labels form a finite set $Y$ defined prior to training.

Probabilistic classifiers generalize this notion of classifiers: instead of functions, they are [conditional](wikipedia://en/24104134) distributions $\Pr(Y \vert X)$, meaning that for a given $x \in X$, they assign probabilities to all $y \in Y$ (and these probabilities sum to one). "Hard" classification can then be done using the [optimal decision rule](wikipedia://en/6978815)[^o4]

$$\hat{y} = \operatorname{\arg\max}_{y} \Pr(Y=y \vert X)$$

or, in English, the predicted class is that which has the highest probability.

Binary probabilistic classifiers are also called [binary regression](wikipedia://en/60567021) models in [statistics](wikipedia://en/26685). In [econometrics](wikipedia://en/10390), probabilistic classification in general is called [discrete choice](wikipedia://en/4902101).

Some classification models, such as [naive Bayes](wikipedia://en/87339), [logistic regression](wikipedia://en/226631) and [multilayer perceptrons](https://en.wikipedia.org/wiki/Multilayer_perceptron) (when trained under an appropriate [loss function](wikipedia://en/442137)) are naturally probabilistic. Other models such as [support vector machines](wikipedia://en/65309) are not, but methods exist to turn them into probabilistic classifiers.

## Generative and conditional training {#Generative_and_conditional_training}

Some models, such as [logistic regression](wikipedia://en/226631), are conditionally trained: they optimize the conditional probability $\Pr(Y \vert X)$ directly on a training set (see [empirical risk minimization](wikipedia://en/1455062)). Other classifiers, such as [naive Bayes](https://en.wikipedia.org/wiki/Naive_Bayes), are trained [generatively](wikipedia://en/1222578): at training time, the class-conditional distribution $\Pr(X \vert Y)$ and the class [prior](wikipedia://en/472877) $\Pr(Y)$ are found, and the conditional distribution $\Pr (Y \vert X)$ is derived using [Bayes' rule](wikipedia://en/49569).[^o4]

## Probability calibration {#Probability_calibration}

Not all classification models are naturally probabilistic, and some that are, notably naive Bayes classifiers, [decision trees](wikipedia://en/577003) and [boosting](https://en.wikipedia.org/wiki/Boosting_%28machine_learning%29) methods, produce distorted class probability distributions.[^o8] In the case of decision trees, where $\Pr(y|\mathbf{x})$ is the proportion of training samples with label $y$ in the leaf where $\mathbf{x}$ ends up, these distortions come about because learning algorithms such as [C4.5](https://en.wikipedia.org/wiki/C4.5) or [CART](wikipedia://en/4141563#Classification_and_regression_trees) explicitly aim to produce homogeneous leaves (giving probabilities close to zero or one, and thus high [bias](wikipedia://en/8450479)) while using few samples to estimate the relevant proportion (high [variance](wikipedia://en/40678189)).[^o9]

*Image: Calibration plot.png.* An example calibration plot

Calibration can be assessed using a **calibration plot** (also called a **reliability diagram**).[^o8][^o10] A calibration plot shows the proportion of items in each class for bands of predicted probability or score (such as a distorted probability distribution or the "signed distance to the hyperplane" in a support vector machine). Deviations from the identity function indicate a poorly-calibrated classifier for which the predicted probabilities or scores can not be used as probabilities. In this case one can use a method to turn these scores into properly [calibrated](wikipedia://en/740955) class membership probabilities.

For the [binary](wikipedia://en/205393) case, a common approach is to apply [Platt scaling](https://en.wikipedia.org/wiki/Platt_scaling), which learns a [logistic regression](wikipedia://en/226631) model on the scores.[^o11] An alternative method using [isotonic regression](wikipedia://en/2836143)[^o12] is generally superior to Platt's method when sufficient training data is available.[^o8]

In the [multiclass](wikipedia://en/26338110) case, one can use a reduction to binary tasks, followed by univariate calibration with an algorithm as described above and further application of the pairwise coupling algorithm by Hastie and Tibshirani.[^o13]

:::

## Evaluating probabilistic classification {#Evaluating_probabilistic_classification}

*Image: Accuracy, Calibration, Sharpness, Dispersion.png.* Models are assessed via Accuracy, Calibration, Sharpness (minimal uncertainty), and Dispersion (similar uncertainties everywhere).

A method used to assign scores to pairs of predicted probabilities and actual discrete outcomes, so that different predictive methods can be compared, is called a [scoring rule](wikipedia://en/4079010). Scoring rules are used to compare the predicted probability to observed outcomes, these include for example [log loss](https://en.wikipedia.org/wiki/Log_loss), [Brier score](wikipedia://en/2538987), [Continuous ranked probability score](https://en.wikipedia.org/wiki/Continuous_ranked_probability_score) and others.

Specific aspects like accuracy, calibration, sharpness or dispersion may vary from one probabilistic classifier to another one and may be specifically investigated.

Calibration errors metrics aim to quantify the extent to which a probabilistic classifier's outputs are *well-calibrated*. As [Philip Dawid](https://en.wikipedia.org/wiki/Philip_Dawid) put it, "a forecaster is well-calibrated if, for example, of those events to which he assigns a probability 30 percent, the long-run proportion that actually occurs turns out to be 30 percent".[^o15] Foundational work in the domain of measuring calibration error is the Expected Calibration Error (ECE) metric.[^o16] More recent works propose variants to ECE that address limitations of the ECE metric that may arise when classifier scores concentrate on narrow subset of the \[0,1\], including the Adaptive Calibration Error (ACE) [^o17] and Test-based Calibration Error (TCE).[^o18]

## Software Implementations {#Software_Implementations}

- MoRPE[^o20] is a trainable probabilistic classifier that uses [isotonic regression](wikipedia://en/2836143) for probability calibration. It solves the [multiclass](wikipedia://en/26338110) case by reduction to binary tasks. It is a type of kernel machine that uses an inhomogeneous polynomial kernel.
