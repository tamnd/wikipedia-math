# Quasi-continuous function

::: {#o1 .subject cue=lead name="Quasi-continuous function"}

In [mathematics](wikipedia://en/18831), the notion of a **quasi-continuous function** is similar to, but weaker than, the notion of a [continuous function](wikipedia://en/6122). All continuous functions are quasi-continuous but the converse is not true in general.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [topological space](wikipedia://en/30450). A real-valued function $f:X \rightarrow \mathbb{R}$ is quasi-continuous at a point $x \in X$ if for any $\epsilon > 0$ and any [open neighborhood](https://en.wikipedia.org/wiki/Open_neighborhood) $U$ of $x$ there is a non-empty [open set](wikipedia://en/39358) $G \subset U$ such that

$$|f(x) - f(y)| < \epsilon \;\;\;\; \forall y \in G$$

Note that in the above definition, it is not necessary that $x \in G$.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If $f: X \rightarrow \mathbb{R}$ is continuous then $f$ is quasi-continuous
- If $f: X \rightarrow \mathbb{R}$ is continuous and $g: X \rightarrow \mathbb{R}$ is quasi-continuous, then $f+g$ is quasi-continuous.

:::

::: {#o7 .example cue=heading name="Example"}

## Example {#Example}

Consider the function $f: \mathbb{R} \rightarrow \mathbb{R}$ defined by $f(x) = 0$ whenever $x \leq 0$ and $f(x) = 1$ whenever $x > 0$. Clearly f is continuous everywhere except at x=0, thus quasi-continuous everywhere except (at most) at x=0. At x=0, take any open neighborhood U of x. Then there exists an open set $G \subset U$ such that $y < 0 \; \forall y \in G$. Clearly this yields $|f(0) - f(y)| = 0 \; \forall y \in G$ thus f is quasi-continuous.

In contrast, the function $g: \mathbb{R} \rightarrow \mathbb{R}$ defined by $g(x) = 0$ whenever $x$ is a [rational number](wikipedia://en/19727024) and $g(x) = 1$ whenever $x$ is an [irrational number](wikipedia://en/20647689) is nowhere quasi-continuous, since every nonempty open set $G$ contains some $y_1, y_2$ with $|g(y_1) - g(y_2)| = 1$.

:::
