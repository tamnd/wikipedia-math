# Binomial test

::: {#o1 .subject cue=lead name="Binomial test"}

**Binomial test** is an [exact test](wikipedia://en/2485378) of the [statistical significance](wikipedia://en/160995) of deviations from a theoretically expected distribution of observations into two categories using sample data.

:::

## Usage {#Usage}

A binomial test is a [statistical hypothesis test](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing) used to determine whether the proportion of successes in a sample differs from an expected proportion in a binomial distribution. It is useful for situations when there are two possible outcomes (e.g., success/failure, yes/no, heads/tails), i.e., where repeated experiments produce [binary data](https://en.wikipedia.org/wiki/Binary_data). If one assumes an underlying probability $\pi_0$ between 0 and 1, the null hypothesis is

$$H_0\colon\pi=\pi_0$$

For a sample of size $n$, we would expect $n\pi_0$ successes. The formula of the [binomial distribution](wikipedia://en/3876) gives the probability of those $n$ samples instead producing $k$ successes:

$$\Pr(X=k)=\binom{n}{k}\pi_0^k(1-\pi_0)^{n-k}$$

Suppose that we want to test the alternative hypothesis

$$H_{A}\colon\pi<\pi_0$$

i.e., we suspect that the actual probability of success is lower than $\pi_0$. Then the $p$-value of our experiment would be computed using a one-tailed test; specifically, we compute the probability of seeing an outcome as extreme as, or more extreme (i.e., less likely), than $k$ (where $k$ is defined as the number of successes in the $n$ trials of our experiment):

$$p = \sum_{i=0}^k\Pr(X=i)=\sum_{i=0}^k\binom{n}{i}\pi_0^i(1-\pi_0)^{n-i}$$

An analogous computation can be done if we're testing if $\pi>\pi_0$ using the summation of the range from $k$ to $n$ instead.

Calculating a $p$-value for a two-tailed test is slightly more complicated, since a binomial distribution isn't symmetric if $\pi_0\neq 0.5$. This means that we can't just double the $p$-value from the one-tailed test. Recall that we want to consider events that are as extreme, or more extreme, than the one we've seen, so we should consider the probability that we would see an event that is as, or less, likely than $X=k$. Let $\mathcal{I}=\{i\colon\Pr(X=i)\leq \Pr(X=k)\}$ denote all such events. Then the two-tailed $p$-value is calculated as,

$$p = \sum_{i\in\mathcal{I}}\Pr(X=i)=\sum_{i\in\mathcal{I}}\binom{n}{i}\pi_0^i(1-\pi_0)^{n-i}$$

## Common use {#Common_use}

One common use of the binomial test is the case where the [null hypothesizes](https://en.wikipedia.org/wiki/Null_hypothesis) that two categories occur with equal frequency ($H_0\colon\pi=0.5$), such as a coin toss. Tables are widely available to give the significance observed numbers of observations in the categories for this case. However, as the example below shows, the binomial test is not restricted to this case.

When there are more than two categories, and an exact test is required, the [multinomial test](wikipedia://en/16093546), based on the [multinomial distribution](wikipedia://en/1045553), must be used instead of the binomial test.[^o4]

Most common measures of [effect size](wikipedia://en/437276) for Binomial tests are [Cohen's h](wikipedia://en/47072912) or [Cohen's g](https://en.wikipedia.org/wiki/Cohen's_g).

## Large samples {#Large_samples}

For large samples such as the example below, the [binomial distribution](wikipedia://en/3876) is well approximated by convenient [continuous distributions](https://en.wikipedia.org/wiki/Continuous_distribution), and these are used as the basis for alternative tests that are much quicker to compute, such as [Pearson's chi-squared test](wikipedia://en/226676) and the [G-test](wikipedia://en/914820). However, for small samples these approximations break down, and there is no alternative to the binomial test.

The most usual (and easiest) approximation is through the [standard normal distribution](wikipedia://en/21462), in which a [z-test](wikipedia://en/332213) is performed of the [test statistic](wikipedia://en/1416975) $Z$, given by

$$Z=\frac{k-n\pi}{\sqrt{n\pi(1-\pi)}}$$

where $k$ is the number of successes observed in a sample of size $n$ and $\pi$ is the probability of success according to the null hypothesis. An improvement on this approximation is possible by introducing a [continuity correction](wikipedia://en/572382):

$$Z=\frac{k-n\pi\pm \frac{1}{2}}{\sqrt{n\pi(1-\pi)}}$$

For very large $n$, this continuity correction will be unimportant, but for intermediate values, where the exact binomial test doesn't work, it will yield a substantially more accurate result.

In notation in terms of a measured sample proportion $\hat{p}$, null hypothesis for the proportion $p_0$, and sample size $n$, where $\hat{p}=k/n$ and $p_0=\pi$, one may rearrange and write the z-test above as

$$Z=\frac{ \hat{p}-p_0 } { \sqrt{ \frac{p_0(1-p_0)}{n} } }$$

by dividing by $n$ in both numerator and denominator, which is a form that may be more familiar to some readers.

## Example {#Example}

Suppose we have a [board game](https://en.wikipedia.org/wiki/Board_game) that depends on the roll of one [die](https://en.wikipedia.org/wiki/Dice) and attaches special importance to rolling a 6. In a particular game, the die is rolled 235 times, and 6 comes up 51 times. If the die is fair, we would expect 6 to come up

$$235\times1/6 = 39.17$$

times. We have now observed that the number of 6s is higher than what we would expect on average by pure chance had the die been a fair one. But, is the number significantly high enough for us to conclude anything about the fairness of the die? This question can be answered by the binomial test. Our [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) would be that the die is fair (probability of each number coming up on the die is 1/6).

To find an answer to this question using the binomial test, we use the [binomial distribution](wikipedia://en/3876)

$B(N=235, p=1/6)$ with [pmf](wikipedia://en/154725) $f(k,n,p) = \Pr(k;n,p) = \Pr(X = k) = \binom{n}{k}p^k(1-p)^{n-k}$ .

As we have observed a value greater than the expected value, we could consider the probability of observing 51 6s or higher under the null, which would constitute a [one-tailed test](wikipedia://en/1361141) (here we are basically testing whether this die is biased towards generating more 6s than expected). In order to calculate the probability of 51 or more 6s in a sample of 235 under the null hypothesis we add up the probabilities of getting exactly 51 6s, exactly 52 6s, and so on up to probability of getting exactly 235 6s:

$$\sum_{i=51}^{235} {235\choose i}p^i(1-p)^{235-i} = 0.02654$$

If we have a significance level of 5%, then this result (0.02654 \< 5%) indicates that we have evidence that is significant enough to reject the null hypothesis that the die is fair.

Normally, when we are testing for fairness of a die, we are also interested if the die is biased towards generating fewer 6s than expected, and not only more 6s as we considered in the one-tailed test above. In order to consider both the biases, we use a [two-tailed test](wikipedia://en/1361141). Note that to do this we cannot simply double the one-tailed p-value unless the probability of the event is 1/2. This is because the binomial distribution becomes asymmetric as that probability deviates from 1/2. There are two methods to define the two-tailed p-value. One method is to sum the probability that the total deviation in numbers of events in either direction from the expected value is either more than or less than the expected value. The probability of that occurring in our example is 0.0437. The second method involves computing the probability that the deviation from the expected value is as unlikely or more unlikely than the observed value, i.e. from a comparison of the probability density functions. This can create a subtle difference, but in this example yields the same probability of 0.0437. In both cases, the two-tailed test reveals significance at the 5% level, indicating that the number of 6s observed was significantly different for this die than the expected number at the 5% level.

:::

## In statistical software packages {#In_statistical_software_packages}

Binomial tests are available in most software used for statistical purposes. E.g.

- In [R](wikipedia://en/376707) the above example could be calculated with the following code:
  - ```r
binom.test(51, 235, 1/6, alternative = "less")
``` (one-tailed test)
  - ```r
binom.test(51, 235, 1/6, alternative = "greater")
``` (one-tailed test)
  - ```r
binom.test(51, 235, 1/6, alternative = "two.sided")
``` (two-tailed test)
- In [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) using the [Apache Commons](https://en.wikipedia.org/wiki/Apache_Commons) library:
  - ```java
new BinomialTest().binomialTest(235, 51, 1.0 / 6, AlternativeHypothesis.LESS_THAN)
``` (one-tailed test)
  - ```java
new BinomialTest().binomialTest(235, 51, 1.0 / 6, AlternativeHypothesis.GREATER_THAN)
``` (one-tailed test)
  - ```java
new BinomialTest().binomialTest(235, 51, 1.0 / 6, AlternativeHypothesis.TWO_SIDED)
``` (two-tailed test)
- In [SAS](wikipedia://en/990677) the test is available in the Frequency procedure ```sas
PROC FREQ DATA=DiceRoll ;
	TABLES Roll / BINOMIAL (P=0.166667) ALPHA=0.05 ;
	EXACT  BINOMIAL ;
	WEIGHT Freq ;
RUN;
```
- In [SPSS](wikipedia://en/179088) the test can be utilized through the menu *Analyze* > *Nonparametric test* > *Binomial* ```text
 npar tests 
 /binomial (.5) = node1 node2.
```
- In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), use [SciPy](https://en.wikipedia.org/wiki/SciPy)'s [binomtest](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html):
  - ```python
scipy.stats.binomtest(51, 235, 1.0/6, alternative="greater")
``` (one-tailed test)
  - ```python
scipy.stats.binomtest(51, 235, 1.0/6, alternative="two-sided")
``` (two-tailed test)
- In [MATLAB](wikipedia://en/20412), use [myBinomTest](http://www.mathworks.com/matlabcentral/fileexchange/24813-binomial-test), which is available via [Mathworks](https://en.wikipedia.org/wiki/MathWorks)' community File Exchange website. myBinomTest will directly calculate the p-value for the observations given the hypothesized probability of a success. ```matlab
[pout]=myBinomTest(51, 235, 1/6)
``` (generally two-tailed, but can optionally perform a one-tailed test).
- In [Stata](wikipedia://en/1809002), use bitest.
- In [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), use Binom.Dist. The function takes parameters (Number of successes, Trials, Probability of Success, Cumulative). The "Cumulative" parameter takes a Boolean True or False, with True giving the Cumulative probability of finding this many successes (a left-tailed test), and False the exact probability of finding this many successes.
