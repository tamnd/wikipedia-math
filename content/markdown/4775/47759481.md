# Slonimski's Theorem

::: {#o1 .subject cue=lead name="Slonimski's Theorem"}

**Slonimski's Theorem** is an observation by [Hayyim Selig Slonimski](https://en.wikipedia.org/wiki/Hayyim_Selig_Slonimski) that the sequence of carry digits in a multiplication table is the [Farey sequence](wikipedia://en/350164).

:::

This observation allowed Slonimski to create very compact multiplication tables for use in hand calculations. He received several awards for different devices for presenting these tables. The most common format were [Joffe Bars](https://en.wikipedia.org/wiki/Joffe_Bars) similar to [Napier's Rods](https://en.wikipedia.org/wiki/Napier's_Rods). Joffe Bars were popular in Eastern Europe in the late 19th and early 20th century.
