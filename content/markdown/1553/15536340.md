# Post's lattice

*Image: Post-lattice.svg.* [Hasse diagram](wikipedia://en/338199) of Post's lattice.

::: {#o1 .subject cue=lead name="Post's lattice"}

In [logic](wikipedia://en/46426065) and [universal algebra](wikipedia://en/45200), **Post's lattice** denotes the [lattice](wikipedia://en/469304) of all [clones](wikipedia://en/15535840) on a two-element set {0, 1}, ordered by [inclusion](https://en.wikipedia.org/wiki/Inclusion_%28set_theory%29). It is named for [Emil Post](wikipedia://en/362382), who published a complete description of the lattice in 1941.[^o2]

:::

The lattice is shown in the image on the right. The relative simplicity of Post's lattice is in stark contrast to the lattice of clones on a three-element (or larger) set, which has the [cardinality of the continuum](wikipedia://en/1574901), and a complicated inner structure.

As a special case, the lattice implies [Post's functional completeness theorem](https://en.wikipedia.org/wiki/Post's_functional_completeness_theorem): any set of Boolean operations is [functionally complete](wikipedia://en/5279259) if and only if it is *not* a subset of either the monotone, affine, self-dual, truth-preserving, or false-preserving functions.

Post's lattice consists of 9 named clones, two [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) families of clones indexed by the positive integers, and all finite intersections of these.

## Basic concepts {#Basic_concepts}

A [Boolean function](wikipedia://en/753349), or [logical connective](wikipedia://en/18153), is an *n*-ary [operation](wikipedia://en/4140245) *f*: **2**<sup>*n*</sup> → **2** for some *n* ≥ 1, where **2** denotes the two-element set {0, 1}. Particular Boolean functions are the [projections](wikipedia://en/3913145)

$$\pi_k^n(x_1,\dots,x_n)=x_k,$$

and given an *m*-ary function *f*, and *n*-ary functions *g*<sub>1</sub>, ..., *g*<sub>*m*</sub>, we can construct another *n*-ary function

$$h(x_1,\dots,x_n)=f(g_1(x_1,\dots,x_n),\dots,g_m(x_1,\dots,x_n)),$$

called their [composition](wikipedia://en/195947). A set of functions closed under composition, and containing all projections, is called a [clone](wikipedia://en/15535840).

Let *B* be a set of connectives. The functions that can be defined by a [formula](https://en.wikipedia.org/wiki/Formula_%28mathematical_logic%29) using [propositional variables](wikipedia://en/1557562) and connectives from *B* form a clone \[*B*\], indeed it is the smallest clone that includes *B*. We call \[*B*\] the clone *generated* by *B*, and say that *B* is the *basis* of \[*B*\]. For example, \[¬, ∧\] are all Boolean functions, and \[0, 1, ∧, ∨\] are the monotone functions.

We use the operations ¬, N*p*, ([negation](wikipedia://en/161019)), ∧, K*pq*, ([conjunction](wikipedia://en/18152) or [meet](https://en.wikipedia.org/wiki/Meet_%28mathematics%29)), ∨, A*pq*, ([disjunction](https://en.wikipedia.org/wiki/Disjunction) or [join](https://en.wikipedia.org/wiki/Join_%28mathematics%29)), →, C*pq*, ([implication](wikipedia://en/658808)), ↔, E*pq*, ([biconditional](wikipedia://en/228783)), +, J*pq* ([exclusive disjunction](https://en.wikipedia.org/wiki/Exclusive_disjunction) or [Boolean ring](wikipedia://en/54356) [addition](wikipedia://en/61338)), ↛, L*pq*,[^o4] ([nonimplication](wikipedia://en/11880982)), ?: (the ternary conditional operator) and the constant unary functions 0 and 1. Moreover, we need the threshold functions

$$\mathrm{th}^n_k(x_1,\dots,x_n)=\begin{cases}1&\text{if }\bigl|\{i\mid x_i=1\}\bigr|\ge k,\\ 0&\text{otherwise.}\end{cases}$$

For example, th${}^{n}_{1}$ is the large disjunction of all the variables *x*<sub>*i*</sub>, and th${}^{n}_{n}$ is the large conjunction. Of particular importance is the [majority function](wikipedia://en/20823)

$$\mathrm{maj}=\mathrm{th}^3_2=(x\land y)\lor(x\land z)\lor(y\land z).$$

We denote elements of **2**<sup>*n*</sup> (i.e., truth-assignments) as vectors: **a** = (*a*<sub>1</sub>, ..., *a*<sub>*n*</sub>). The set **2**<sup>*n*</sup> carries a natural [product](wikipedia://en/24104095) [Boolean algebra](wikipedia://en/3959) structure. That is, ordering, meets, joins, and other operations on *n*-ary truth assignments are defined pointwise:

$$(a_1,\dots,a_n)\le(b_1,\dots,b_n)\iff a_i\le b_i\text{ for }i=1,\dots,n,$$

$$(a_1,\dots,a_n)\land(b_1,\dots,b_n)=(a_1\land b_1,\dots,a_n\land b_n).$$

## Naming of clones {#Naming_of_clones}

[Intersection](wikipedia://en/23476429) of an arbitrary number of clones is again a clone. It is convenient to denote intersection of clones by simple juxtaposition, i.e., the clone *C*<sub>1</sub> ∩ *C*<sub>2</sub> ∩ ... ∩ *C*<sub>*k*</sub> is denoted by *C*<sub>1</sub>*C*<sub>2</sub>...*C*<sub>*k*</sub>. Some special clones are introduced below:

- M = \[∧, ∨, 0, 1\] is the set of [monotone](wikipedia://en/5279259#Characterization_of_functional_completeness) functions: *f*(**a**) ≤ *f*(**b**) for every **a** ≤ **b**.
- *D* = \[maj, ¬\] is the set of [self-dual](wikipedia://en/5279259#Characterization_of_functional_completeness) functions: ¬*f*(**a**) = *f*(¬**a**).
- *A* = \[↔, 0\] is the set of [affine](wikipedia://en/5279259#Characterization_of_functional_completeness) functions: the functions satisfying

$$\begin{aligned} & f(a_1,\dots,a_{i-1},c,a_{i+1},\dots,a_n)=f(a_1,\dots,d,a_{i+1},\dots)\\ \Rightarrow & f(b_1,\dots,c,b_{i+1},\dots)=f(b_1,\dots,d,b_{i+1},\dots) \end{aligned}$$

for every *i* ≤ *n*, **a**, **b** ∈ **2**<sup>*n*</sup>, and *c*, *d* ∈ **2**. Equivalently, the functions expressible as *f*(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>) = *a*<sub>0</sub> + *a*<sub>1</sub>*x*<sub>1</sub> + ... + *a*<sub>*n*</sub>*x*<sub>*n*</sub> for some *a*<sub>0</sub>, **a**.

- *U* = \[¬, 0\] is the set of *essentially unary* functions, i.e., functions that depend on at most one input variable: there exists an *i* = 1, ..., *n* such that *f*(**a**) = *f*(**b**) whenever *a*<sub>*i*</sub> = *b*<sub>*i*</sub>.
- Λ = \[∧, 0, 1\] is the set of *conjunctive* functions: *f*(**a** ∧ **b**) = *f*(**a**) ∧ *f*(**b**). The clone Λ consists of the conjunctions $f(x_1,\dots,x_n)=\bigwedge_{i\in I}x_i$ for all subsets *I* of {1, ..., *n*} (including the empty conjunction, i.e., the constant 1), and the constant 0.
- V = \[∨, 0, 1\] is the set of *disjunctive* functions: *f*(**a** ∨ **b**) = *f*(**a**) ∨ *f*(**b**). Equivalently, V consists of the disjunctions $f(x_1,\dots,x_n)=\bigvee_{i\in I}x_i$ for all subsets *I* of {1, ..., *n*} (including the empty disjunction 0), and the constant 1.
- For any *k* ≥ 1, *T*${}^{k}_{0}$ = \[th${}^{k+2}_{k+1}$, ↛\] is the set of functions *f* such that

$$\mathbf a^1\land\cdots\land\mathbf a^k=\mathbf 0\ \Rightarrow\ f(\mathbf a^1)\land\cdots\land f(\mathbf a^k)=0.$$

As a special case, *P*<sub>0</sub> = *T*${}^{1}_{0}$ = \[∨, +\] is the set of *0-preserving* functions: *f*(**0**) = 0. Furthermore, ⊤ can be considered *T*${}^{0}_{0}$ when one takes the empty meet into account.

- Moreover, $\mathrm{T}_0^\infty=\bigcap_{k=1}^\infty\mathrm{T}_0^k$ = \[↛\] is the set of functions bounded above by a variable: there exists *i* = 1, ..., *n* such that *f*(**a**) ≤ *a*<sub>*i*</sub> for all **a**.
- For any *k* ≥ 1, T${}^{k}_{1}$ = \[th${}^{k+2}_{k+1}$, →\] is the set of functions *f* such that

$$\mathbf a^1\lor\cdots\lor\mathbf a^k=\mathbf 1\ \Rightarrow\ f(\mathbf a^1)\lor\cdots\lor f(\mathbf a^k)=1,$$

The special case *P*<sub>1</sub> = *T*${}^{1}_{1}$ = \[∧, →\] consists of the *1-preserving* functions: *f*(**1**) = 1. Furthermore, ⊤ can be considered *T*${}^{0}_{1}$ when one takes the empty join into account.

- Moreover, $\mathrm{T}_1^\infty=\bigcap_{k=1}^\infty\mathrm{T}_1^k$ = \[→\] is the set of functions bounded below by a variable: there exists *i* = 1, ..., *n* such that *f*(**a**) ≥ *a*<sub>*i*</sub> for all **a**.
- The largest clone of all functions is denoted ⊤ = \[∨, ¬\].

In addition, the smallest clone (which contains only projections) is denoted ⊥ = \[\], and *P* = *P*<sub>0</sub>*P*<sub>1</sub> = \[*x* ? *y* : *z*\] is the clone of *constant-preserving* functions.

## Description of the lattice {#Description_of_the_lattice}

The set of all clones is a [closure system](https://en.wikipedia.org/wiki/Closure_system), hence it forms a [complete lattice](wikipedia://en/44777). The lattice is [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite), and all its members are finitely generated. All the clones are listed in the table below.

The lattice has a natural symmetry mapping each clone *C* to its dual clone *C*<sup>*d*</sup> = {*f*<sup>d</sup> | *f* ∈ *C*}, where *f*<sup>*d*</sup>(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>) = ¬*f*(¬*x*<sub>1</sub>, ..., ¬*x*<sub>*n*</sub>) is the [de Morgan dual](https://en.wikipedia.org/wiki/De_Morgan_dual) of a Boolean function *f*. For example, Λ<sup>*d*</sup> = V, (T<sub>0</sub><sup>*k*</sup>)<sup>*d*</sup> = T<sub>1</sub><sup>*k*</sup>, and M<sup>*d*</sup> = M.

## Applications {#Applications}

The complete classification of Boolean clones given by Post helps to resolve various questions about classes of Boolean functions. For example:

- An inspection of the lattice shows that the maximal clones different from ⊤ (often called **Post's classes**) are M, D, A, P<sub>0</sub>, P<sub>1</sub>, and every proper subclone of ⊤ is contained in one of them. As a set *B* of connectives is [functionally complete](wikipedia://en/5279259) if and only if it generates ⊤, we obtain the following characterization: *B* is functionally complete if and only if it is not included in any of the five Post's classes.
- The [satisfiability problem](https://en.wikipedia.org/wiki/Satisfiability_problem) for Boolean formulas is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) by [Cook's theorem](https://en.wikipedia.org/wiki/Cook's_theorem). Consider a restricted version of the problem: for a fixed finite set *B* of connectives, let *B*-SAT be the algorithmic problem of checking whether a given *B*-formula is satisfiable. Lewis[^o10] used the description of Post's lattice to show that *B*-SAT is NP-complete if the function ↛ can be generated from *B* (i.e., \[*B*\] ⊇ T<sub>0</sub><sup>∞</sup>), and in all the other cases *B*-SAT is [polynomial-time](wikipedia://en/658550) decidable.

## Variants {#Variants}

*Image: Post lattice with constants.svg.* Subset of Post's lattice showing the 7 clones containing all constant functions

### Clones containing the constant functions {#Clones_containing_the_constant_functions}

If one only considers clones that contain the constant functions $0$ and $1$ (i.e., UP<sub>0</sub> and UP<sub>1</sub>), the classification is simpler. There are only 7 such clones: UM, Λ, V, U, A, M, and ⊤. This can be derived from the full classification or via a simpler proof taking less than a page.[^o14]

### Clones allowing nullary functions {#Clones_allowing_nullary_functions}

Composition alone does not allow to generate a nullary function from the corresponding unary constant function, this is the technical reason why nullary functions are excluded from clones in Post's classification. If we lift the restriction, we get more clones. Namely, each clone *C* in Post's lattice that contains at least one constant function corresponds to two clones under the less restrictive definition: *C*, and *C* together with all nullary functions whose unary versions are in *C*.

### Iterative systems {#Iterative_systems}

Post originally did not work with the modern definition of clones, but with the so-called *iterative systems*, which are sets of operations closed under substitution

$$h(x_1,\dots,x_{n+m-1})=f(x_1,\dots,x_{n-1},g(x_n,\dots,x_{n+m-1})),$$

as well as permutation and identification of variables. The main difference is that iterative systems do not necessarily contain all projections. Every clone is an iterative system, and there are 20 non-empty iterative systems that are not clones. (Post also excluded the empty iterative system from the classification, hence his diagram has no least element and fails to be a lattice.) As another alternative, some authors work with the notion of a *closed class*, which is an iterative system closed under introduction of dummy variables. There are four closed classes that are not clones: the empty set, the set of constant 0 functions, the set of constant 1 functions, and the set of all constant functions.
