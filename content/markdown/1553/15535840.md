# Clone (algebra)

::: {#o1 .subject cue=lead name="Clone"}

In the area of mathematics known as [universal algebra](wikipedia://en/45200), a **clone** is a [set](wikipedia://en/26691) *C* of [finitary](wikipedia://en/404456) [operations](wikipedia://en/4140245) on a set *A* such that

:::

- *C* contains all the [projections](wikipedia://en/3913145) $\pi$<sub>*k*</sub><sup>*n*</sup>: *A<sup>n</sup>* → *A*, defined by $\pi$<sub>*k*</sub><sup>*n*</sup>(*x*<sub>1</sub>, …, *x<sub>n</sub>*) = *x<sub>k</sub>*,
- *C* is closed under [(finitary multiple) composition](https://en.wikipedia.org/wiki/Generalized_composition) (or "superposition"):[^o2] if *f*, *g*<sub>1</sub>, …, *g<sub>m</sub>* are members of *C* such that *f* is *m*-ary, and *g<sub>j</sub>* is *n*-ary for all *j*, then the *n*-ary operation *h*(*x*<sub>1</sub>, …, *x<sub>n</sub>*) := *f*(*g*<sub>1</sub>(*x*<sub>1</sub>, …, *x<sub>n</sub>*), …, *g<sub>m</sub>*(*x*<sub>1</sub>, …, *x<sub>n</sub>*)) is in *C*.

The question whether clones should contain nullary operations or not is not treated uniformly in the literature. The classical approach as evidenced by the standard monographs[^o3][^o4][^o5] on clone theory considers clones only containing at-least-unary operations. However, with only minor modifications (related to the empty invariant relation) most of the usual theory can be lifted to clones allowing nullary operations.[^o6] The more general concept[^o7] includes all clones without nullary operations as subclones of the clone of all at-least-unary operations[^o6] and is in accordance with the custom to allow nullary terms and nullary term operations in universal algebra. Typically, publications studying clones as abstract clones, e.g. in the [category theoretic](https://en.wikipedia.org/wiki/Category_theoretic) setting of [Lawvere](https://en.wikipedia.org/wiki/Lawvere)'s [algebraic theories](wikipedia://en/22305825), will include nullary operations.[^o8][^o9]

Given an [algebra](wikipedia://en/45200) in a [signature](wikipedia://en/7788156) *σ*, the set of operations on its carrier definable by a *σ*-[term](wikipedia://en/10983#Formation_rules) (the *term functions*) is a clone. Conversely, every clone can be realized as the clone of term functions in a suitable algebra by simply taking the clone itself as source for the signature *σ* so that the algebra has the whole clone as its fundamental operations.

If *A* and *B* are algebras with the same carrier such that every basic function of *A* is a term function in *B* and vice versa, then *A* and *B* have the same clone. For this reason, modern universal algebra often treats clones as a representation of algebras that abstracts from their signature.

There is only one clone on the one-element set (there are two if nullary operations are considered). The [lattice](wikipedia://en/469304) of clones on a two-element set is countable,[^o13][^o12][^o4] and has been completely described by [Emil Post](https://en.wikipedia.org/wiki/Emil_Post)[^o10][^o12] (see [Post's lattice](wikipedia://en/15536340),[^o4] which traditionally does not show clones with nullary operations). Clones on larger sets do not admit a simple classification; there are [continuum](wikipedia://en/1574901)-many clones on a finite set of size at least three,[^o11][^o4] and 2<sup>2<sup>*κ*</sup></sup> (even just maximal,[^o12][^o4] i.e. precomplete) clones on an infinite set of [cardinality](wikipedia://en/6174) *κ*.[^o13][^o4]

## Abstract clones {#Abstract_clones}

[Philip Hall](wikipedia://en/1655033) introduced the concept of *abstract clone*.[^o15] An abstract clone is different from a concrete clone in that the set *A* is not given. Formally, an abstract clone comprises

- a set *C<sub>n</sub>* for each natural number *n*,
- elements $\pi$<sub>*k*,*n*</sub> in *C<sub>n</sub>* for all *k* ≤ *n*, and
- a family of functions ∗:*C*<sub>*m*</sub> × (*C*<sub>*n*</sub>)<sup>*m*</sup> → *C*<sub>*n*</sub> for all *m* and *n*

such that

- *c* \* ($\pi$<sub>1,*n*</sub>, …, $\pi$<sub>*n*,*n*</sub>) = *c*
- $\pi$<sub>*k*,*m*</sub> \* (*c*<sub>1</sub>, …, *c*<sub>*m*</sub>) = *c*<sub>*k*</sub>
- *c* \* (*d*<sub>1</sub> \* (*e*<sub>1</sub>, …, *e*<sub>*n*</sub>), …, *d*<sub>*m*</sub> \* (*e*<sub>1</sub>, …, *e*<sub>*n*</sub>)) = (*c* \* (*d*<sub>1</sub>, …, *d*<sub>*m*</sub>)) \* (*e*<sub>1</sub>, …, *e*<sub>*n*</sub>).

Any concrete clone determines an abstract clone in the obvious manner.

Any [algebraic theory](wikipedia://en/24497685) determines an abstract clone where *C<sub>n</sub>* is the set of terms (up to equivalence) in *n* variables, $\pi$<sub>*k*,*n*</sub> are variables, and ∗ is [substitution](wikipedia://en/5438948). Two theories determine isomorphic clones if and only if the corresponding categories of algebras are [isomorphic](wikipedia://en/489935). Conversely every abstract clone determines an algebraic theory with an *n*-ary operation for each element of *C<sub>n</sub>*. This gives a bijective correspondence between abstract clones and algebraic theories.

Every abstract clone *C* induces a [Lawvere theory](wikipedia://en/22305825) in which the morphisms *m* → *n* are the elements of (*C<sub>m</sub>*)<sup>*n*</sup>. This induces a bijective correspondence between Lawvere theories and abstract clones.
