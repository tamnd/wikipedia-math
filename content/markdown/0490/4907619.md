# Truncated regression model

::: {#o1 .subject cue=lead name="Truncated regression model"}

**Truncated regression models** are a class of [models](wikipedia://en/826997) in which the [sample](https://en.wikipedia.org/wiki/Sample_%28statistics%29) has been [truncated](wikipedia://en/18374571) for certain ranges of the [dependent variable](wikipedia://en/437701). That means observations with values in the dependent variable below or above certain thresholds are systematically excluded from the sample. Therefore, whole observations are missing, so that neither the dependent nor the independent variable is known. This is in contrast to [censored regression models](wikipedia://en/4907628) where only the value of the dependent variable is clustered at a lower threshold, an upper threshold, or both, while the value for [independent variables](wikipedia://en/437701) is available.[^o2]

:::

Sample truncation is a pervasive issue in quantitative social sciences when using [observational data](https://en.wikipedia.org/wiki/Observational_data), and consequently the development of suitable estimation techniques has long been of interest in [econometrics](wikipedia://en/10390) and related disciplines.[^o3] In the 1970s, [James Heckman](https://en.wikipedia.org/wiki/James_Heckman) noted the similarity between truncated and otherwise non-randomly selected samples, and developed the [Heckman correction](wikipedia://en/16728089).[^o4][^o5]

Estimation of truncated regression models is usually done via parametric maximum likelihood method. More recently, various semi-parametric and non-parametric generalisation were proposed in the literature, e.g., based on the local least squares approach[^o6] or the local maximum likelihood approach,[^o7] which are kernel based methods.
