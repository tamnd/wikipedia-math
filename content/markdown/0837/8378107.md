# Simon model

::: {#o1 .subject cue=lead name="Simon model"}

In applied probability theory, the **Simon model** is a class of [stochastic models](https://en.wikipedia.org/wiki/Stochastic_model) that results in a [power-law](https://en.wikipedia.org/wiki/Power-law) distribution function. It was proposed by [Herbert A. Simon](https://en.wikipedia.org/wiki/Herbert_A._Simon)[^o2] to account for the wide range of empirical [distributions](https://en.wikipedia.org/wiki/Frequency_distribution) following a power-law. It models the dynamics of a system of elements with associated counters (e.g., words and their frequencies in texts, or nodes in a network and their connectivity $k$). In this model the dynamics of the system is based on constant growth via addition of new elements (new instances of words) as well as incrementing the counters (new occurrences of a word) at a rate proportional to their current values.

:::

## Description {#Description}

To model this type of network growth as described above, Bornholdt and Ebel[^o4] considered a network with $n$ nodes, and each node with connectivities $k_i$, $i = 1, \ldots, n$. These nodes form classes $[k]$ of $f(k)$ nodes with identical connectivity $k$. Repeat the following steps:

1. With probability $\alpha$ add a new node and attach a link to it from an arbitrarily chosen node.
1. With probability $1-\alpha$ add one link from an arbitrary node to a node $j$ of class $[k]$ chosen with a probability proportional to $k f(k)$.

For this stochastic process, Simon found a stationary solution exhibiting [power-law](https://en.wikipedia.org/wiki/Power-law) scaling, $P(k) \propto k^{- \gamma}$, with exponent $\gamma = 1 + \frac{1}{1- \alpha}.$

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

1. [Barabási-Albert (BA) model](https://en.wikipedia.org/wiki/Barabási-Albert_%28BA%29_model) can be mapped to the subclass $\alpha= 1/2$ of Simon's model, when using the simpler probability for a node being connected to another node $i$ with connectivity $k_i$ $P(\mathrm{new\ link\ to\ } i) \propto k_i$ (same as the preferential attachment at [BA model](https://en.wikipedia.org/wiki/BA_model)). In other words, the Simon model describes a general class of stochastic processes that can result in a [scale-free network](wikipedia://en/227155), appropriate to capture [Pareto and Zipf's laws](wikipedia://en/43218).
1. The only free parameter of the model $\alpha$ reflects the relative growth of number of nodes versus the number of links. In general $\alpha$ has small values; therefore, the scaling exponents can be predicted to be $\gamma\approx 2$. For instance, Bornholdt and Ebel[^o4] studied the linking dynamics of World Wide Web, and predicted the scaling exponent as $\gamma \approx 2.1$, which was consistent with observation.
1. The interest in the scale-free model comes from its ability to describe the topology of [complex networks](wikipedia://en/1704711). The Simon model does not have an underlying network structure, as it was designed to describe events whose frequency follows a [power-law](https://en.wikipedia.org/wiki/Power-law). Thus network measures going beyond the [degree distribution](wikipedia://en/2129782) such as the [average path length](https://en.wikipedia.org/wiki/Average_path_length), [spectral properties](https://web.archive.org/web/20070128124135/http://austria.phys.nd.edu/netwiki/index.php/Graph_Spectra), and [clustering coefficient](wikipedia://en/1457636), cannot be obtained from this mapping.

The Simon model is related to [generalized scale-free models](https://en.wikipedia.org/wiki/Generalized_scale-free_model) with growth and preferential attachment properties. For more reference, see.[^o7][^o8]

:::
