# Pseudoanalytic function

::: {#o1 .subject cue=lead name="Pseudoanalytic function"}

In mathematics, **pseudoanalytic functions** are functions introduced by (txt) that generalize [analytic functions](wikipedia://en/61478) and satisfy a weakened form of the [Cauchy–Riemann equations](wikipedia://en/7583).

:::

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $z=x+iy$ and let $\sigma(x,y)=\sigma(z)$ be a real-valued function defined in a bounded domain $D$. If $\sigma>0$ and $\sigma_x$ and $\sigma_y$ are [Hölder continuous](https://en.wikipedia.org/wiki/Hölder_continuous), then $\sigma$ is admissible in $D$. Further, given a [Riemann surface](wikipedia://en/173181) $F$, if $\sigma$ is admissible for some neighborhood at each point of $F$, $\sigma$ is admissible on $F$.

The complex-valued function $f(z)=u(x,y)+iv(x,y)$ is pseudoanalytic with respect to an admissible $\sigma$ at the point $z_0$ if all partial derivatives of $u$ and $v$ exist and satisfy the following conditions:

$$u_x=\sigma(x,y)v_y, \quad u_y=-\sigma(x,y)v_x$$

If $f$ is pseudoanalytic at every point in some domain, then it is pseudoanalytic in that domain.[^o5]

:::

## Similarities to analytic functions {#Similarities_to_analytic_functions}

- If $f(z)$ is not the constant $0$, then the zeroes of $f$ are all isolated.
- Therefore, any [analytic continuation](wikipedia://en/80842) of $f$ is unique.[^o7]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- Complex constants are pseudoanalytic.
- Any [linear combination](wikipedia://en/55632) with real coefficients of pseudoanalytic functions is pseudoanalytic.[^o5]

:::
