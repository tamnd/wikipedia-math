# Finite-state transducer

::: {#o1 .subject cue=lead name="Finite-state transducer"}

A **finite-state transducer** (**FST**) is a [finite-state machine](wikipedia://en/10931) with two memory *tapes*, following the terminology for [Turing machines](wikipedia://en/30403): an input tape and an output tape. This contrasts with an ordinary [finite-state automaton](https://en.wikipedia.org/wiki/Finite-state_automaton), which has a single tape. An FST is a type of finite-state automaton (FSA) that maps between two sets of symbols.[^o2] An FST is more general than an FSA. An FSA defines a [formal language](wikipedia://en/10939) by defining a set of accepted strings, while an FST defines a [relation](wikipedia://en/19509) between sets of strings.

:::

An FST will read a set of strings on the input tape and generate a set of relations on the output tape. An FST can be thought of as a translator or relater between strings in a set.

In [morphological parsing](https://en.wikipedia.org/wiki/Morphological_parsing), an example would be inputting a string of letters into the FST, the FST would then output a string of [morphemes](https://en.wikipedia.org/wiki/Morphemes).

## Overview {#Overview}

An [automaton](https://en.wikipedia.org/wiki/Automaton) can be said to *recognize* a string if we view the content of its tape as input. In other words, the automaton computes a function that maps strings into the set {0,1}. Alternatively, we can say that an automaton *generates* strings, which means viewing its tape as an output tape. On this view, the automaton generates a [formal language](wikipedia://en/10939), which is a set of strings. The two views of automata are equivalent: the function that the automaton computes is precisely the [indicator function](wikipedia://en/240790) of the set of strings it generates. The class of languages generated by finite automata is known as the class of [regular languages](wikipedia://en/25723).

The two tapes of a transducer are typically viewed as an input tape and an output tape. On this view, a transducer is said to *transduce* (i.e., translate) the contents of its input tape to its output tape, by accepting a string on its input tape and generating another string on its output tape. It may do so [nondeterministically](wikipedia://en/665957) and it may produce more than one output for each input string. A transducer may also produce no output for a given input string, in which case it is said to *reject* the input. In general, a transducer computes a [relation](wikipedia://en/22517558) between two formal languages.

Each string-to-string finite-state transducer relates the input alphabet Σ to the output alphabet Γ. Relations *R* on Σ\*×Γ\* that can be implemented as finite-state transducers are called **rational relations**. Rational relations that are [partial functions](wikipedia://en/23577), i.e. that relate every input string from Σ\* to at most one Γ\*, are called **rational functions**.

Finite-state transducers are often used for [phonological](https://en.wikipedia.org/wiki/Phonology) and [morphological analysis](https://en.wikipedia.org/wiki/Morphology_%28linguistics%29) in [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing) research and applications. Pioneers in this field include [Ronald Kaplan](https://en.wikipedia.org/wiki/Ronald_Kaplan), [Lauri Karttunen](https://en.wikipedia.org/wiki/Lauri_Karttunen), [Martin Kay](https://en.wikipedia.org/wiki/Martin_Kay) and [Kimmo Koskenniemi](https://en.wikipedia.org/wiki/Kimmo_Koskenniemi).[^o4] A common way of using transducers is in a so-called "cascade", where transducers for various operations are combined into a single transducer by repeated application of the composition operator (defined below).

## Formal construction {#Formal_construction}

Formally, a finite transducer *T* is a 6-tuple ($Q, \Sigma, \Gamma, I, F, \delta$) such that:

- $Q$ is a [finite set](wikipedia://en/11742), the set of *states*;
- $\Sigma$ is a finite set, called the *input alphabet*;
- $\Gamma$ is a finite set, called the *output alphabet*;
- $I$ is a [subset](wikipedia://en/27631) of $Q$, the set of *initial states*;
- $F$ is a subset of $Q$, the set of *final states*; and
- $\delta \subseteq Q \times (\Sigma\cup\{\epsilon\}) \times (\Gamma\cup\{\epsilon\}) \times Q$ (where ε is the [empty string](wikipedia://en/835827)) is the *transition relation*.

We can view (*Q*, *δ*) as a labeled [directed graph](wikipedia://en/19721986), known as the *transition graph* of *T*: the set of vertices is *Q*, and $(q,a,b,r)\in\delta$ means that there is a labeled edge going from vertex *q* to vertex *r*. We also say that *a* is the *input label* and *b* the *output label* of that edge.

NOTE: This definition of finite transducer is also called *letter transducer* (Roche and Schabes 1997); alternative definitions are possible, but can all be converted into transducers following this one.

Define the *extended transition relation* $\delta^*$ as the smallest set such that:

- $$\delta\subseteq\delta^*;$$
- $(q,\epsilon,\epsilon,q)\in\delta^*$ for all $q\in Q$; and
- whenever $(q,x,y,r) \in \delta^*$ and $(r,a,b,s) \in \delta$ then $(q,xa,yb,s) \in \delta^*$.

The extended transition relation is essentially the reflexive [transitive closure](wikipedia://en/292239) of the transition graph that has been augmented to take edge labels into account. The elements of $\delta^*$ are known as *paths*. The edge labels of a path are obtained by concatenating the edge labels of its constituent transitions in order.

The *behavior* of the transducer *T* is the rational relation \[*T*\] defined as follows: $x[T]y$ [if and only if](wikipedia://en/14922) there exists $i \in I$ and $f \in F$ such that $(i,x,y,f) \in \delta^*$. This is to say that *T* transduces a string $x\in\Sigma^*$ into a string $y\in\Gamma^*$ if there exists a path from an initial state to a final state whose input label is *x* and whose output label is *y*.

### Weighted automata {#Weighted_automata}

Finite State Transducers can be weighted, where each transition is labelled with a weight in addition to the input and output labels. A Weighted Finite State Transducer (WFST) over a set *K* of weights can be defined similarly to an unweighted one as an 8-tuple $T=(Q, \Sigma, \Gamma, I, F, E, \lambda, \rho)$, where:

- $Q, \Sigma, \Gamma, I, F$ are defined as above;
- $E \subseteq Q \times (\Sigma\cup\{\epsilon\}) \times (\Gamma\cup\{\epsilon\}) \times Q \times K$ (where *ε* is the [empty string](wikipedia://en/835827)) is the finite set of transitions;
- $\lambda: I \rightarrow K$ maps initial states to weights;
- $\rho: F \rightarrow K$ maps final states to weights.

In order to make certain operations on WFSTs well-defined, it is convenient to require the set of weights to form a [semiring](wikipedia://en/371468).[^o8] Two typical semirings used in practice are the [log semiring](wikipedia://en/37563991) and [tropical semiring](wikipedia://en/3892336): [nondeterministic automata](wikipedia://en/653406) may be regarded as having weights in the [Boolean semiring](https://en.wikipedia.org/wiki/Boolean_semiring).[^o9]

Two weighted FST can be composed.[^o10]

:::

## Operations on finite-state transducers {#Operations_on_finite-state_transducers}

The following operations defined on finite automata also apply to finite transducers:

- [Union](wikipedia://en/47949). Given transducers $T$ and $S$, there exists a transducer $T\cup S$ such that $x[T\cup S]y$ if and only if $x[T]y$ or $x[S]y$.
- [Concatenation](wikipedia://en/64474). Given transducers $T$ and $S$, there exists a transducer $T\cdot S$ such that $x[T\cdot S]y$ if and only if there exist $x_1, x_2, y_1, y_2$ with $x=x_1x_2, y =y_1y_2, x_1[T]y_1$ and $x_2[S]y_2.$
- [Kleene closure](https://en.wikipedia.org/wiki/Kleene_closure). Given a transducer $T$, there might exist a transducer $T^*$ with the following properties:[^o12]

::: {#o13 .equation cue=numblk name="k1"}

$$\epsilon[T^*]\epsilon; \tag{k1}$$

:::

::: {#o14 .equation cue=numblk name="k2"}

if $w[T^*]y$ and $x[T]z$, then $wx[T^*]yz$; (k2)

:::

and $x[T^*]y$ does not hold unless mandated by ((k1)) or ((k2)).

- [Composition](wikipedia://en/7472170). Given a transducer $T$ on alphabets Σ and Γ and a transducer $S$ on alphabets Γ and Δ, there exists a transducer $T \circ S$ on Σ and Δ such that $x[T \circ S]z$ if and only if there exists a string $y\in\Gamma^*$ such that $x[T]y$ and $y[S]z$. This operation extends to the weighted case.[^o15]

This definition uses the same notation used in mathematics for [relation composition](wikipedia://en/7472170). However, the conventional reading for relation composition is the other way around: given two relations $T$ and $S$, $(x,z)\in T\circ S$ when there exist some $y$ such that $(x,y)\in S$ and $(y,z)\in T.$

- [Projection](wikipedia://en/3909097) to an automaton. There are two projection functions: $\pi_1$ preserves the input tape, and $\pi_2$ preserves the output tape. The first projection, $\pi_1$ is defined as follows:

Given a transducer $T$, there exists a finite automaton $\pi_1 T$ such that $\pi_1 T$ accepts *x* if and only if there exists a string *y* for which $x[T]y.$

:The second projection, $\pi_2$ is defined similarly.

- [Determinization](https://en.wikipedia.org/wiki/Determinization). Given a transducer $T$, we want to build an equivalent transducer that has a unique initial state and such that no two transitions leaving any state share the same input label. The [powerset construction](wikipedia://en/1163167) can be extended to transducers, or even weighted transducers, but sometimes fails to halt; indeed, some non-deterministic transducers do not admit equivalent deterministic transducers.[^o16] [Characterizations](wikipedia://en/780886) of determinizable transducers have been proposed[^o17] along with efficient algorithms to test them:[^o18] they rely on the [semiring](wikipedia://en/371468) used in the weighted case as well as a general property on the structure of the transducer (the [twins property](https://en.wikipedia.org/wiki/Twins_property)).
- Weight pushing for the weighted case.[^o19]
- Minimization for the weighted case.[^o20]
- Removal of [epsilon-transitions](wikipedia://en/653406).

## Additional properties of finite-state transducers {#Additional_properties_of_finite-state_transducers}

- It is [decidable](wikipedia://en/913118) whether the relation \[*T*\] of a transducer *T* is empty.
- It is decidable whether there exists a string *y* such that *x*\[*T*\]*y* for a given string *x*.
- It is [undecidable](wikipedia://en/15631055) whether two transducers are equivalent.[^o22] Equivalence is however decidable in the special case where the relation \[*T*\] of a transducer *T* is a (partial) function.

## Applications {#Applications}

FSTs are used in the [lexical analysis](https://en.wikipedia.org/wiki/Lexical_analysis) phase of [compilers](https://en.wikipedia.org/wiki/Compilers) to associate semantic value with the discovered tokens.[^o25]

Context-sensitive rewriting rules of the form *a* → *b* / *c* \_ *d*, used in [linguistics](https://en.wikipedia.org/wiki/Linguistics) to model [phonological rules](https://en.wikipedia.org/wiki/Phonological_rule) and [sound change](https://en.wikipedia.org/wiki/Sound_change), are computationally equivalent to finite-state transducers, provided that application is nonrecursive, i.e. the rule is not allowed to rewrite the same substring twice.[^o26]

Weighted FSTs found applications in [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing),[^o27] including [machine translation](https://en.wikipedia.org/wiki/Machine_translation),[^o28] [speech recognition](https://en.wikipedia.org/wiki/Speech_recognition),[^o29][^o30] [speech synthesis](https://en.wikipedia.org/wiki/Speech_synthesis),[^o31] and [optical character recognition](https://en.wikipedia.org/wiki/Optical_character_recognition).[^o32] Also in [image compression](https://en.wikipedia.org/wiki/Image_compression),[^o33] and [machine learning](wikipedia://en/233488) in general.[^o34] An implementation for [part-of-speech tagging](https://en.wikipedia.org/wiki/Part-of-speech_tagging) can be found as one component of the [OpenGrm](http://opengrm.org/) library.
