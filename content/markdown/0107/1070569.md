# Glossary of cryptographic keys

::: {#o1 .subject cue=lead name="Glossary of cryptographic keys"}

*Image: Enigma keylist 3 rotor.jpg.* Key list for a German World War II [Enigma machine](wikipedia://en/9256)

This glossary lists types of [keys](wikipedia://en/53039) as the term is used in [cryptography](wikipedia://en/18934432), as opposed to [door locks](https://en.wikipedia.org/wiki/Key_%28lock%29). Terms that are primarily used by the U.S. [National Security Agency](wikipedia://en/21939) are marked *(NSA)*. For classification of keys according to their usage see [cryptographic key types](wikipedia://en/2979642).

:::

- **40-bit key** - key with a [length of 40 bits](wikipedia://en/487403), once the upper limit of what could be [exported](wikipedia://en/25872370) from the U.S. and other countries without a license. Considered very insecure. *See* [key size](wikipedia://en/5749) for a discussion of this and other lengths.
- **Authentication key** - Key used in a keyed-hash message authentication code, or [HMAC](wikipedia://en/17112).
- **Benign key** - (NSA) a key that has been protected by encryption or other means so that it can be distributed without fear of its being stolen. Also called **BLACK key**.
- **Content-encryption key (CEK)** a key that may be further encrypted using a KEK, where the content may be a message, audio, image, video, executable code, etc.
- **Crypto ignition key** An NSA key storage device ([KSD-64](https://en.wikipedia.org/wiki/KSD-64)) shaped to look like an ordinary physical key.
- **Cryptovariable** - NSA calls the output of a [stream cipher](wikipedia://en/49007) a key or key stream. It often uses the term **cryptovariable** for the bits that control the stream cipher, what the public cryptographic community calls a [key](wikipedia://en/53039).
- **Data encryption key (DEK)** used to encrypt the underlying data.
- **Derived key** - keys computed by applying a predetermined [hash algorithm](https://en.wikipedia.org/wiki/Hash_algorithm) or [key derivation function](wikipedia://en/449781) to a [password](wikipedia://en/24304) or, better, a [passphrase](https://en.wikipedia.org/wiki/Passphrase).
- **DRM key** - A key used in [digital rights management](wikipedia://en/18938226) to protect media
- **Electronic key** - (NSA) key that is distributed in electronic (as opposed to paper) form. *See* [EKMS](https://en.wikipedia.org/wiki/EKMS).
- **[Ephemeral key](https://en.wikipedia.org/wiki/Ephemeral_key)** - A key that only exists within the lifetime of a communication session.
- **Expired key** - Key that was issued for a use in a limited time frame ([cryptoperiod](wikipedia://en/18938044) in NSA parlance) which has passed and, hence, the key is no longer valid.
- **[FIREFLY key](wikipedia://en/3250254)** - (NSA) keys used in an NSA system based on [public key cryptography](https://en.wikipedia.org/wiki/Public_key_cryptography).
- **[Key derivation function](wikipedia://en/449781) (KDF)** - function used to derive a key from a secret value, e.g. to derive KEK from Diffie-Hellman key exchange.
- **Key encryption key (KEK)** - key used to protect MEK keys (or DEK/TEK if MEK is not used).
- **Key production key (KPK)** -Key used to initialize a keystream generator for the production of other electronically generated keys.
- **Key fill** - (NSA) loading keys into a cryptographic device. *See* [fill device](wikipedia://en/4319754).
- **Master key** - key from which all other keys (or a large group of keys) can be derived. Analogous to a [physical key](https://en.wikipedia.org/wiki/Key_%28lock%29) that can open all the doors in a building.
- **Master encryption key (MEK)** - Used to encrypt the DEK/TEK key.
- **Master key encryption key (MKEK)** - Used to encrypt multiple KEK keys. For example, an HSM can generate several KEK and wrap them with an MKEK before export to an external DB - such as OpenStack Barbican.[^o2]

*Image: NSA DIANA one time pad.tiff.* A sample NSA [one-time pad](wikipedia://en/22210)

- **[One time pad](https://en.wikipedia.org/wiki/One_time_pad) (OTP or OTPad)** - keying material that should be as long as the [plaintext](wikipedia://en/157935) and should only be used once. If truly random and not reused it's the most secure encryption method. *See* [one-time pad](wikipedia://en/22210) article.
- **[One time password](wikipedia://en/1190077) (OTP)** - One time password based on a prebuilt single use code list or based on a mathematical formula with a secret seed known to both parties, uses event or time to modify output (see TOTP/HOTP).
- **[Paper key](wikipedia://en/14148458)** - (NSA) keys that are distributed in paper form, such as printed lists of settings for [rotor machines](wikipedia://en/196223), or keys in [punched card](https://en.wikipedia.org/wiki/Punched_card) or [paper tape](https://en.wikipedia.org/wiki/Paper_tape) formats. Paper keys are easily copied. *See* [Walker spy ring](https://en.wikipedia.org/wiki/Walker_spy_ring), *RED key*.
- **Poem key** - Keys used by [OSS](https://en.wikipedia.org/wiki/Office_of_Strategic_Services) agents in World War II in the form of a poem that was easy to remember. *See* [Leo Marks](wikipedia://en/18446).
- **Public/private key** - in [public key cryptography](https://en.wikipedia.org/wiki/Public_key_cryptography), separate keys are used to encrypt and decrypt a message. The encryption key (**public key**) need not be kept secret and can be published. The decryption or **private key** must be kept secret to maintain confidentiality. Public keys are often distributed in a signed [public key certificate](wikipedia://en/223796).
- **[Public key infrastructure](wikipedia://en/194112)** - (PKI) a set of roles, policies, hardware, software and procedures needed to create, manage, distribute, use, store and revoke digital certificates and manage [public-key encryption](wikipedia://en/194112).
- **Pre-placed key** - (NSA) large numbers of keys (perhaps a year's supply) that are loaded into an encryption device allowing frequent key change without refill.
- **RED key** - (NSA) symmetric key in a format that can be easily copied, e.g. *paper key* or unencrypted *electronic key*. Opposite of *BLACK* or *benign key*.
- **Revoked key** - a public key that should no longer be used, typically because its owner is no longer in the role for which it was issued or because it may have been compromised. Such keys are placed on a [certificate revocation list](wikipedia://en/296365) or **CRL**.
- **[Session key](wikipedia://en/63941)** - key used for one message or an entire communications session. *See traffic encryption key.*
- **[Symmetric key](wikipedia://en/53042)** - a key that is used both to encrypt and decrypt a message. Symmetric keys are typically used with a cipher and must be kept secret to maintain confidentiality.
- **Traffic encryption key (TEK)/data encryption key (DEK)** - a symmetric key that is used to encrypt messages. TEKs are typically changed frequently, in some systems daily and in others for every message. See *session key*. DEK is used to specify any data form type (in communication payloads or anywhere else).
- **Transmission security key (TSK)** - (NSA) seed for a [pseudorandom number generator](wikipedia://en/45524) that is used to control a radio in [frequency hopping](https://en.wikipedia.org/wiki/Frequency_hopping) or [direct-sequence spread spectrum](https://en.wikipedia.org/wiki/Direct-sequence_spread_spectrum) modes. *See* [HAVE QUICK](https://en.wikipedia.org/wiki/HAVE_QUICK), [SINCGARS](https://en.wikipedia.org/wiki/SINCGARS), [electronic warfare](https://en.wikipedia.org/wiki/Electronic_warfare).
- **Seed key** - (NSA) a key used to initialize a cryptographic device so it can accept operational keys using benign transfer techniques. Also a key used to initialize a [pseudorandom number generator](wikipedia://en/45524) to generate other keys.
- **Signature key** - [public key cryptography](https://en.wikipedia.org/wiki/Public_key_cryptography) can also be used to electronically sign messages. The private key is used to create the electronic signature, the public key is used to verify the signature. Separate public/private key pairs **must** be used for signing and encryption. The former is called **signature keys**.
- **Stream key** - the output of a [stream cipher](wikipedia://en/49007) as opposed to the key (or *cryptovariable* in NSA parlance) that controls the cipher
- **Training key** - (NSA) un[classified](https://en.wikipedia.org/wiki/Classified_information) key used for instruction and practice exercises.
- **Type 1 key** - (NSA) keys used to protect [classified information](https://en.wikipedia.org/wiki/Classified_information). *See* [Type 1 product](https://en.wikipedia.org/wiki/Type_1_product).
- **Type 2 key** - (NSA) keys used to protect sensitive but unclassified (SBU) information. *See* [Type 2 product](https://en.wikipedia.org/wiki/Type_2_product).
- **Vernam key** - Type of key invented by [Gilbert Vernam](wikipedia://en/578127) in 1918. *See stream key*.
- **Zeroized key** - key that has been erased (see [zeroisation](https://en.wikipedia.org/wiki/Zeroisation).)
