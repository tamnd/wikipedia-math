# Grothendieck universe

::: {#o1 .subject cue=lead name="Grothendieck universe"}

In [set theory](wikipedia://en/27553), a **Grothendieck universe** is a set $U$ with the following properties:

:::

1. If $x$ is an element of $U$ and if $y$ is an element of $x$, then $y$ is also an element of $U$. ($U$ is a [transitive set](wikipedia://en/2462396).)
1. If $x$ and $y$ are both elements of $U$, then $\{x,y\}$ is an element of $U$.
1. If $x$ is an element of $U$, then $\mathcal{P}(x)$, the [power set](wikipedia://en/23799) of $x$, is also an element of $U$.
1. If $\{x_\alpha\}_{\alpha\in I}$ is a family of elements of $U$, and if $I$ is an element of $U$, then the union $\bigcup_{\alpha\in I} x_\alpha$ is an element of $U$.

A Grothendieck universe is meant to provide a set in which all of mathematics can be performed. In fact, [uncountable](https://en.wikipedia.org/wiki/Uncountable) Grothendieck universes provide [models](wikipedia://en/19858) of set theory with the natural ∈-relation, natural power set operation, etc. Elements of a Grothendieck universe are sometimes called **small sets**. The idea of universes is due to [Alexander Grothendieck](wikipedia://en/2042), who used them as a way of avoiding [proper classes](https://en.wikipedia.org/wiki/Proper_class) in [algebraic geometry](wikipedia://en/1997). Grothendieck’s original proposal was to add the following **axiom of universes** to the usual axioms of set theory: For every set $s$, there exists a universe $U$ that contains $s$, i.e., $s \in U$.

The existence of a nontrivial Grothendieck universe goes beyond the usual axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214); in particular it would imply the existence of [strongly inaccessible cardinals](wikipedia://en/248076). [Tarski–Grothendieck set theory](wikipedia://en/6105873) is an axiomatic treatment of set theory, used in some automatic proof systems, in which every set belongs to a Grothendieck universe. The concept of a Grothendieck universe can also be defined in an [elementary topos](wikipedia://en/815802).[^o2]

## Properties {#Properties}

As an example, we will prove an easy proposition.

**Proposition**. If $x \in U$ and $y \subseteq x$, then $y \in U$.

*Proof*. $y \in P(x)$ because $y \subseteq x$. $P(x) \in U$ because $x \in U$, so $y \in U$.

It is similarly easy to prove that any Grothendieck universe $U$ contains:

- All [singletons](wikipedia://en/381798) of each of its elements,
- All [products](wikipedia://en/24104095#Infinite_Cartesian_products) of all families of elements of $U$ indexed by an element of $U$,
- All [disjoint unions](wikipedia://en/188946) of all families of elements of $U$ indexed by an element of $U$,
- All intersections of all nonempty families of elements of $U$ indexed by an element of $U$,
- All functions between any two elements of $U$, and
- All subsets of $U$ whose [cardinality](wikipedia://en/6174) is an element of $U$.

In particular, it follows from the last axiom that if $U$ is non-empty, it must contain all of its finite subsets and a subset of each finite cardinality. One can also prove immediately from the definitions that the intersection of any nonempty class of universes is a universe.

:::

## Grothendieck universes and inaccessible cardinals {#Grothendieck_universes_and_inaccessible_cardinals}

There are two simple examples of Grothendieck universes: the empty set and the set of all [hereditarily finite sets](wikipedia://en/332621).

Other examples are more difficult to construct. Loosely speaking, this is because Grothendieck universes are equivalent to [strongly inaccessible cardinals](wikipedia://en/248076). More formally, the following two axioms are equivalent:

(U) For each set $x$, there exists a Grothendieck universe $U$ such that $x\in U$.

(C) For each cardinal $\kappa$, there is a strongly inaccessible cardinal $\lambda$ that is strictly larger than $\kappa$.

To prove this fact, we introduce the function

$$\mathbf{c}(U) := \sup_{x \in U} |x|,$$

where by $|x|$ we mean the cardinality of $x$. Then for any universe $U$, $\mathbf{c}(U)$ is either zero, $\aleph_0$, or strongly inaccessible. Assuming it is uncountable, it is a [strong limit cardinal](wikipedia://en/374002) because the power set of any element of $U$ is an element of $U$ and every element of $U$ is a subset of $U$. To see that it is regular, suppose that $c_\lambda$ is a collection of cardinals indexed by $I$, where the cardinality of $I$ and of each $c_\lambda$ is less than $\mathbf{c}(U)$. Then, by the definition of $\mathbf{c}(U)$, $I$ and each $c_\lambda$ can be replaced by an element of $U$. The union of elements of $U$ indexed by an element of $U$ is an element of $U$, so the sum of the $c_\lambda$ has the cardinality of an element of $U$, hence is less than $\mathbf{c}(U)$.

By invoking the axiom of foundation, that no set is contained in itself, it can be shown that $\mathbf{c}(U)$ equals $|U|$; when the axiom of foundation is not assumed, there are counterexamples: we may take for example $U$ to be the set of all finite sets of finite sets etc. of the sets $x_\alpha$ where the index $\alpha$ is any real number, and $x_\alpha=\{x_\alpha\}$ for each $\alpha$. Then $U$ has the cardinality of the continuum, but all of its members have finite cardinality and so $\mathbf{c}(U) = \aleph_0$ (see Bourbaki's article for more details).

Now let $\kappa$ be a strongly inaccessible cardinal. Say that a set $S$ is strictly of type $\kappa$ if for any sequence, we have $s_n\in\cdots\in s_0\in S$, with $|s_n|<\kappa$. ($S$ itself corresponds to the empty sequence.) Then the set $u(\kappa)$ of all sets strictly of type $\kappa$ is a Grothendieck universe of cardinality $\kappa$. For details, again refer to Bourbaki's article, listed in the references.

To show that the large cardinal axiom (C) implies the universe axiom (U), choose a set $x$. Let $x_0=x$, and for each $n$, let $x_{n+1} = \textstyle\bigcup x_n$ be the union of the elements of $x_n$. Let $y = \textstyle \bigcup_n x_n$. By (C), there is a strongly inaccessible cardinal $\kappa$ such that $|y|<\kappa$. Let $u(\kappa)$ be the universe of the previous paragraph. Then $x$ is strictly of type $\kappa$, so $x\in u(\kappa)$. To show that the universe axiom (U) implies the large cardinal axiom (C), choose a cardinal $\kappa$. $\kappa$ is a set, so it is an element of a Grothendieck universe $U$. The cardinality of $U$ is strongly inaccessible and strictly larger than that of $\kappa$.

In fact, any Grothendieck universe is of the form $u(\kappa)$ for some $\kappa$. This gives another form of the equivalence between Grothendieck universes and strongly inaccessible cardinals:

For any Grothendieck universe $U$, $|U|$ is either zero, $\aleph_0$, or a strongly inaccessible cardinal. And if $\kappa$ is zero, $\aleph_0$, or a strongly inaccessible cardinal, then there is a Grothendieck universe $u(\kappa)$. Furthermore, $u(|U|)=U$, and $|u(\kappa)|=\kappa$.

Since the existence of strongly inaccessible cardinals cannot be proved from the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC), the existence of universes other than the empty set and $V_\omega$ cannot be proved from ZFC either. However, strongly inaccessible cardinals are on the lower end of the [list of large cardinals](wikipedia://en/3096183); thus, most set theories that use large cardinals (such as "ZFC plus there is a [measurable cardinal](wikipedia://en/248102)", "ZFC plus there are infinitely many [Woodin cardinals](wikipedia://en/248105)") will prove that Grothendieck universes exist.
