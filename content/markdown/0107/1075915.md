# Sparse binary polynomial hashing

::: {#o1 .subject cue=lead name="Sparse binary polynomial hashing"}

**Sparse binary polynomial hashing** (SBPH) is a generalization of [Bayesian spam filtering](https://en.wikipedia.org/wiki/Bayesian_spam_filtering) that can match mutating phrases as well as single words.

:::

SBPH is a way of generating a large number of features from an incoming [text](https://en.wikipedia.org/wiki/Text_messaging) automatically, and then using [statistics](wikipedia://en/26685) to determine the weights for each of those features in terms of their predictive values for [spam](https://en.wikipedia.org/wiki/Spamming)/nonspam evaluation.
