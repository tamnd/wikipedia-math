# Trapezoidal rule (differential equations)

::: {#o1 .subject cue=lead name="Trapezoidal rule"}

In [numerical analysis](wikipedia://en/21506) and [scientific computing](https://en.wikipedia.org/wiki/Scientific_computing), the **trapezoidal rule** is a [numerical method](wikipedia://en/272829) to solve [ordinary differential equations](https://en.wikipedia.org/wiki/Ordinary_differential_equations) derived from the [trapezoidal rule](wikipedia://en/573452) for computing integrals. The trapezoidal rule is an [implicit](https://en.wikipedia.org/wiki/Implicit_and_explicit_methods) second-order method, which can be considered as both a [Runge–Kutta method](https://en.wikipedia.org/wiki/Runge–Kutta_method) and a [linear multistep method](wikipedia://en/2090865).

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

Suppose that we want to solve the differential equation

$$y' = f(t,y).$$

The trapezoidal rule is given by the formula

$$y_{n+1} = y_n + \tfrac 1 2 h \Big( f(t_n,y_n) + f(t_{n+1},y_{n+1}) \Big),$$

where $h = t_{n+1} - t_n$ is the step size.[^o4]

This is an implicit method: the value $y_{n+1}$ appears on both sides of the equation, and to actually calculate it, we have to solve an equation which will usually be nonlinear. One possible method for solving this equation is [Newton's method](wikipedia://en/22145). We can use the [Euler method](wikipedia://en/3011098) to get a fairly good estimate for the solution, which can be used as the initial guess of Newton's method.[^o5] Cutting short, using only the guess from Eulers method is equivalent to performing [Heun's method](wikipedia://en/11754125).

:::

## Motivation {#Motivation}

Integrating the differential equation from $t_n$ to $t_{n+1}$, we find that

$$y(t_{n+1}) - y(t_n) = \int_{t_n}^{t_{n+1}} f(t,y(t)) \,\mathrm{d}t.$$

The [trapezoidal rule](wikipedia://en/573452) states that the integral on the right-hand side can be approximated as

$$\int_{t_n}^{t_{n+1}} f(t,y(t)) \,\mathrm{d}t \approx \tfrac12 h \Big( f(t_n,y(t_n)) + f(t_{n+1},y(t_{n+1})) \Big).$$

Now combine both formulas and use that $y_n \approx y(t_n)$ and $y_{n+1} \approx y(t_{n+1})$ to get the trapezoidal rule for solving ordinary differential equations.[^o7]

## Error analysis {#Error_analysis}

It follows from the error analysis of the trapezoidal rule for quadrature that the [local truncation error](https://en.wikipedia.org/wiki/Local_truncation_error) $\tau_n$ of the trapezoidal rule for solving differential equations can be bounded as:

$$|\tau_n| \le \tfrac1{12} h^3 \max_t |y'''(t)|.$$

Thus, the trapezoidal rule is a second-order method.[^o9] This result can be used to show that the global error is $O(h^2)$ as the step size $h$ tends to zero (see [big O notation](wikipedia://en/44578) for the meaning of this).[^o10]

## Stability {#Stability}

*Image: Stability region for trapezoidal method.svg.* The pink region is the stability region for the trapezoidal method.

The [region of absolute stability](wikipedia://en/2091823) for the trapezoidal rule is

$$\{ z \in \mathbb{C} \mid \operatorname{Re}(z) < 0 \}.$$

This includes the left-half plane, so the trapezoidal rule is A-stable. The second Dahlquist barrier states that the trapezoidal rule is the most accurate amongst the A-stable linear multistep methods. More precisely, a linear multistep method that is A-stable has at most order two, and the error constant of a second-order A-stable linear multistep method cannot be better than the error constant of the trapezoidal rule.[^o12]

In fact, the region of absolute stability for the trapezoidal rule is precisely the left-half plane. This means that if the trapezoidal rule is applied to the linear test equation *y**\= λ*****y*, the numerical solution decays to zero if and only if the exact solution does. However, the decay of the numerical solution can be many orders of magnitude slower than that of the true solution.***
