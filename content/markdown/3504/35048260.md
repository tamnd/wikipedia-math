# Bott cannibalistic class

::: {#o1 .subject cue=lead name="Bott cannibalistic class"}

In mathematics, the **Bott cannibalistic class**, introduced by (txt), is an element $\theta_k(V)$ of the [representation ring](wikipedia://en/16673816) of a [compact Lie group](https://en.wikipedia.org/wiki/Compact_Lie_group) that describes the action of the [Adams operation](wikipedia://en/1226666) $\psi^k$ on the [Thom class](https://en.wikipedia.org/wiki/Thom_class) $\lambda_V$ of a complex [representation](wikipedia://en/292786) $V$. The term "cannibalistic" for these classes was introduced by Frank Adams.[^o3]

:::
