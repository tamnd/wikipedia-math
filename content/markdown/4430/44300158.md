# Root Cause Analysis Solver Engine

::: {#o1 .subject cue=lead name="Root Cause Analysis Solver Engine"}

**Root Cause Analysis Solver Engine** (informally **RCASE**) is a proprietary [algorithm](wikipedia://en/775) developed from research originally at the [Warwick Manufacturing Group (WMG)](https://en.wikipedia.org/wiki/Warwick_Manufacturing_Group) at [Warwick University](https://en.wikipedia.org/wiki/Warwick_University).[^o3][^o4] RCASE development commenced in 2003 to provide an automated version of [root cause analysis](https://en.wikipedia.org/wiki/Root_cause_analysis), the method of problem solving that tries to identify the root causes of faults or problems.[^o5] RCASE is now owned by the spin-out company Warwick Analytics where it is being applied to automated predictive analytics software.

:::

::: {#o7 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

The algorithm has been built from the ground up to be particularly suitable for the following situations:

- ['dirty' data](https://en.wikipedia.org/wiki/Dirty_data)
- incomplete data
- big data
- small datasets
- complex problems for example multi-modal failure or with more than one solution

RCASE is considered to be an innovator in the field of [Predictive analytics](wikipedia://en/4141563) and falls within the category of *[classification algorithms](wikipedia://en/126706#Classification_algorithms_.28supervised_algorithms_predicting_categorical_labels.29)*. Because it was built to handle the data types above, it has been proven to have many advantages over other types of classification algorithms and [machine learning](wikipedia://en/233488#Software) algorithms such as [decision trees](https://en.wikipedia.org/wiki/Decision_trees), [neural networks](https://en.wikipedia.org/wiki/Artificial_neural_network) and [regression techniques](wikipedia://en/826997). It does not require [hypotheses](https://en.wikipedia.org/wiki/Hypotheses).[^o8]

It has since been commercialised and made available for operating systems such as [SAP](https://en.wikipedia.org/wiki/SAP_SE),[^o9] [Teradata](wikipedia://en/168680) and [Microsoft](https://en.wikipedia.org/wiki/Microsoft).[^o10] RCASE originated from manufacturing and is widely used in applications such as [Six Sigma](wikipedia://en/222448), [quality control](wikipedia://en/41613) and [engineering](https://en.wikipedia.org/wiki/Engineering), [product design](https://en.wikipedia.org/wiki/Product_design) and warranty issues. However it is also used in other industries such as [e-commerce](https://en.wikipedia.org/wiki/E-commerce), [financial services](https://en.wikipedia.org/wiki/Financial_services) and utilities where root cause analysis is required.[^o11]

:::

## Mechanism & architecture {#Mechanism_&_architecture}

RCASE is non-statistical and thus does not require any [hypotheses](https://en.wikipedia.org/wiki/Hypotheses).[^o13] If the key parameters causing the issue or fault in a process are not present in a [dataset](https://en.wikipedia.org/wiki/Dataset), it will still narrow the search space and advise where the root cause may lie. This is a different approach to statistical theories which try to find a [best fit](https://en.wikipedia.org/wiki/Best_fit).[^o14]

RCASE is based on optimised combinatorial theory and runs on either a grid cluster or a [high performance](https://en.wikipedia.org/wiki/High-performance_computing) [in-memory database](https://en.wikipedia.org/wiki/In-memory_database). The software will interface with all [MES](https://en.wikipedia.org/wiki/Manufacturing_execution_system) and [ERP](https://en.wikipedia.org/wiki/Enterprise_resource_planning) systems.[^o15] The result is a security system monitoring and preventing defective products from being produced. The output from the analysis will be markers that identify either an exact root cause of failure or a parametric region pointing high probability of failure (i.e. data-driven guidance on where to look next to gather data and resolve the root cause exactly).[^o16]

The software can be installed on Linux or Microsoft operating systems and deployed as [On-Premises](https://en.wikipedia.org/wiki/On-premises_software) or [Software-as-a-Service](https://en.wikipedia.org/wiki/Software_as_a_service) (“SaaS” or “cloud”).[^o17]
