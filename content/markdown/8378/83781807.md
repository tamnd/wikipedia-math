# Prismatic cohomology

::: {#o1 .subject cue=lead name="Prismatic cohomology"}

In [mathematics](wikipedia://en/18831), specifically [arithmetic geometry](wikipedia://en/1973177), **prismatic cohomology** is a [cohomology](wikipedia://en/194060) introduced by [Bhargav Bhatt](wikipedia://en/67165881) and [Peter Scholze](wikipedia://en/39409306) for [$p$-adic](wikipedia://en/51423) [formal schemes](wikipedia://en/18829483).[^n1] It generalizes various $p$-adic cohomology theories.

:::

Fix a [prime](wikipedia://en/23666) $p$. A **prism** is a pair $(A,I)$, where $A$ is a [$\delta$-ring](wikipedia://en/26343492) with $p$-derivation $\delta_A$ and $I$ is an ideal of $A$ defining a [Cartier divisor](wikipedia://en/1693055#Cartier_divisor) in $\operatorname{Spec}(A)$, such that $A$ is derived $(p,I)$-adically complete and the ideal $I+\phi_A(I)A$ contains $p$,[^n2] where the associated map $\phi_A : A\to A$ given by

$$\phi_A(x) = x^p + p \delta_A(x)$$

is a [ring homomorphism](wikipedia://en/26411), which then necessarily lifts the [Frobenius endomorphism](wikipedia://en/1088270) on $A/(p)$.[^n3]
