# Multiplicative distance

::: {#o1 .subject cue=lead name="Multiplicative distance"}

In [algebraic geometry](wikipedia://en/1997), $\mu$ is said to be a multiplicative [distance](wikipedia://en/39378) function over a [field](wikipedia://en/10603) if it satisfies[^o2]

:::

- $$\mu(AB)>1.\,$$
- *AB* is [congruent](wikipedia://en/48167) to A'B' [iff](https://en.wikipedia.org/wiki/Iff) $\mu(AB)=\mu(A'B').\,$
- *AB* \< *A'B'* iff $\mu(AB)<\mu(A'B').\,$
- $$\mu(AB+CD)=\mu(AB)\mu(CD).\,$$
