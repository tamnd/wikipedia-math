# Decision rule

::: {#o1 .subject cue=lead name="Decision rule"}

In [decision theory](wikipedia://en/446216), a **decision rule** is a function which maps an observation to an appropriate action.[^o2] Decision rules play an important role in the theory of [statistics](wikipedia://en/26685) and [economics](https://en.wikipedia.org/wiki/Economics), and are closely related to the concept of a [strategy](wikipedia://en/1434441) in [game theory](wikipedia://en/11924).

:::

In order to evaluate the usefulness of a decision rule, it is necessary to have a [loss function](wikipedia://en/442137) detailing the outcome of each action under different states.

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Given an observable random variable *X* over the [probability space](wikipedia://en/43325) $\scriptstyle (\mathcal{X},\Sigma, P_\theta)$, determined by a parameter *θ* ∈ *Θ*, and a set *A* of possible actions, a (deterministic) **decision rule** is a function *δ* : $\scriptstyle\mathcal{X}$→ *A*.

:::

## Examples of decision rules {#Examples_of_decision_rules}

- An [estimator](wikipedia://en/10043) is a decision rule used for estimating a parameter. In this case the set of actions is the parameter space, and a loss function details the cost of the discrepancy between the true value of the parameter and the estimated value. For example, in a linear model with a single scalar parameter $\theta$, the domain of $\theta$ may extend over $\mathcal{R}$ (all real numbers). An associated decision rule for estimating $\theta$ from some observed data might be, "choose the value of the $\theta$, say $\hat{\theta}$, that minimizes the sum of squared error between some observed responses, and responses predicted from the corresponding covariates given that you chose $\hat{\theta}$." Thus, the cost function is the sum of squared error, and one would aim to minimize this cost. Once the cost function is defined, $\hat{\theta}$ could be chosen, for instance, using some optimization algorithm.
- Out of sample [prediction](wikipedia://en/246066) in [regression](wikipedia://en/826997) and [classification](wikipedia://en/1579244) models.
