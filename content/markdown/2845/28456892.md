# Wente torus

::: {#o1 .subject cue=lead name="Wente torus"}

In [differential geometry](wikipedia://en/8625), a **Wente torus** is an [immersed](wikipedia://en/6993953) [torus](wikipedia://en/74800) in $\mathbb{R}^3$ of constant [mean curvature](wikipedia://en/684210), discovered by (txt). It is a counterexample to the conjecture of [Heinz Hopf](wikipedia://en/543082) that every [closed](wikipedia://en/669475), [compact](wikipedia://en/6042), [constant-mean-curvature surface](wikipedia://en/35544695) is a [sphere](wikipedia://en/27859) (though this is true if the surface is [embedded](wikipedia://en/52119)). There are similar examples known for every positive [genus](wikipedia://en/61891).

:::
