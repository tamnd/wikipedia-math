# Path ordering (term rewriting)

::: {#o1 .subject cue=lead name="Path ordering"}

In [theoretical computer science](wikipedia://en/323392), in particular in [term rewriting](https://en.wikipedia.org/wiki/Term_rewriting), a **path ordering** is a [well-founded](https://en.wikipedia.org/wiki/Well-founded) [strict total order](https://en.wikipedia.org/wiki/Strict_total_order) (>) on the set of all [terms](wikipedia://en/24885593) such that

:::

*f*(...) > *g*(*s*<sub>1</sub>,...,*s*<sub>*n*</sub>) if *f* <sup>.</sup>> *g* and *f*(...) > *s*<sub>*i*</sub> for *i*=1,...,*n*,

where (<sup>.</sup>>) is a user-given [total precedence order](https://en.wikipedia.org/wiki/Strict_total_order) on the set of all [function symbols](wikipedia://en/24885593#Formal_definition).

Intuitively, a term *f*(...) is bigger than any term *g*(...) built from terms *s*<sub>*i*</sub> smaller than *f*(...) using a lower-precedence root symbol *g*. In particular, by [structural induction](wikipedia://en/211399), a term *f*(...) is bigger than any term containing only symbols smaller than *f*.

A path ordering is often used as [reduction ordering](https://en.wikipedia.org/wiki/Reduction_ordering) in term rewriting, in particular in the [Knuth–Bendix completion algorithm](wikipedia://en/614147). As an example, a term rewriting system for "[multiplying out](wikipedia://en/9710#Evaluating_expressions)" mathematical expressions could contain a rule *x*\*(*y*+*z*) → (*x*\**y*) + (*x*\**z*). In order to prove [termination](https://en.wikipedia.org/wiki/Termination_%28term_rewriting%29), a [reduction ordering](https://en.wikipedia.org/wiki/Reduction_ordering) (>) must be found with respect to which the term *x*\*(*y*+*z*) is greater than the term (*x*\**y*)+(*x*\**z*). This is not trivial, since the former term contains both fewer function symbols and fewer variables than the latter. However, setting the precedence (\*) <sup>.</sup>> (+), a path ordering can be used, since both *x*\*(*y*+*z*) > *x*\**y* and *x*\*(*y*+*z*) > *x*\**z* is easy to achieve.

There may also be systems for certain [general recursive functions](wikipedia://en/26469), for example a system for the [Ackermann function](wikipedia://en/2925) may contain the rule A(*a*<sup>\+</sup>, *b*<sup>\+</sup>) → A(*a*, A(*a*<sup>\+</sup>, *b*)),[^o2] where *b*<sup>\+</sup> denotes the [successor](wikipedia://en/325637) of *b*.

Given two terms *s* and *t*, with a root symbol *f* and *g*, respectively, to decide their relation their root symbols are compared first.

- If *f* \<<sup>.</sup> *g*, then *s* can dominate *t* only if one of *s**s subterms does.***
- If *f* <sup>.</sup>> *g*, then *s* dominates *t* if *s* dominates each of *t**s subterms.***
- If *f* = *g*, then the immediate [subterms](wikipedia://en/24885593#Operations_with_terms) of *s* and *t* need to be compared recursively. Depending on the particular method, different variations of path orderings exist.[^o3][^o4]

The latter variations include:

- the **multiset path ordering** (**mpo**), originally called **recursive path ordering** (**rpo**)[^o5]
- the **lexicographic path ordering** (**lpo**)[^o6]
- a combination of mpo and lpo, called **recursive path ordering** by Dershowitz, Jouannaud (1990)[^o7][^o8][^o9]

Dershowitz, Okada (1988) list more variants, and relate them to [Ackermann](wikipedia://en/62727)'s system of [ordinal notations](wikipedia://en/16137162). In particular, an upper bound given on the order types of recursive path orderings with *n* function symbols is φ(*n*,0), using [Veblen's function](wikipedia://en/16124925) for large countable ordinals.[^o8]

## Formal definitions {#Formal_definitions}

The **multiset path ordering** (>) can be defined as follows:[^o12]

| *s* = *f*(*s*<sub>1</sub>,...,*s*<sub>*m*</sub>) > *t* = *g*(*t*<sub>1</sub>,...,*t*<sub>*n*</sub>) |  |  |  |  |  |  |  |  | if |
|---|---|---|---|---|---|---|---|---|---|
| *f* | <sup>.</sup>> | *g* | and | *s* | \> | *t*<sub>*j*</sub> | for each | *j*∈{1,...,*n*}, | or |
|  |  |  |  | *s*<sub>*i*</sub> | ≥ | *t* | for some | *i*∈{1,...,*m*}, | or |
| *f* | \= | *g* | and | { *s*<sub>1</sub>,...,*s*<sub>*m*</sub> } >> { *t*<sub>1</sub>,...,*t*<sub>*n*</sub> } |  |  |  |  |  |

where

- (≥) denotes the [reflexive closure](wikipedia://en/22603618) of the mpo (>),
- { *s*<sub>1</sub>,...,*s*<sub>*m*</sub> } denotes the [multiset](wikipedia://en/305303) of *s*’s subterms, similar for *t*, and
- (>>) denotes the multiset extension of (>), defined by { *s*<sub>1</sub>,...,*s*<sub>*m*</sub> } >> { *t*<sub>1</sub>,...,*t*<sub>*n*</sub> } if { *t*<sub>1</sub>,...,*t*<sub>*n*</sub> } can be obtained from { *s*<sub>1</sub>,...,*s*<sub>*m*</sub> }
  - by deleting at least one element, or
  - by replacing an element by a multiset of strictly smaller (w.r.t. the mpo) elements.[^o13]

More generally, an **order [functional](https://en.wikipedia.org/wiki/Higher-order_function)** is a function *O* mapping an ordering to another one, and satisfying the following properties:[^o14]

- If (>) is [transitive](wikipedia://en/200463), then so is *O*(>).
- If (>) is [irreflexive](https://en.wikipedia.org/wiki/Irreflexive), then so is *O*(>).
- If *s* > *t*, then *f*(...,*s*,...) *O*(>) *f*(...,*t*,...).
- *O* is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28set_theory%29) on relations, i.e. if *R*<sub>0</sub>, *R*<sub>1</sub>, *R*<sub>2</sub>, *R*<sub>3</sub>, ... is an infinite sequence of relations, then *O*(∪${}^{\infty}_{i=0}$ *R*<sub>*i*</sub>) = ∪${}^{\infty}_{i=0}$ *O*(*R*<sub>*i*</sub>).

The multiset extension, mapping (>) above to (>>) above is one example of an order functional: (>>)=*O*(>). Another order functional is the [lexicographic](https://en.wikipedia.org/wiki/Lexicographical_order) extension, leading to the **lexicographic path ordering**.
