# Reedy category

::: {#o1 .subject cue=lead name="Reedy category"}

In mathematics, especially [category theory](wikipedia://en/5869), a **Reedy category** is a category *R* that has a structure so that the [functor category](wikipedia://en/407039) from *R* to a [model category](wikipedia://en/2895304) *M* would also get the induced model category structure. A prototypical example is the [simplex category](wikipedia://en/1028841) or its opposite. It was introduced by Christopher Reedy in his unpublished manuscript.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A Reedy category consists of the following data: a category *R*, two [wide](https://en.wikipedia.org/wiki/Wide_subcategory) (lluf) subcategories $R_-, R_+$ and a functorial factorization of each map into a map in $R_-$ followed by a map in $R_+$ that are subject to the condition: for some total preordering (degree), the nonidentity maps in $R_-, R_+$ lower or raise degrees.[^o5]

Note some authors such as nlab require each factorization to be unique.[^o6][^o7]

:::

## Reedy model structure {#Reedy_model_structure}

A Reedy model structure is a canonical model-category structure placed on the functor category M^R when R is a Reedy category and M is a model category.

::: {#o10 .pointer-item cue=pointer name="Eilenberg-Zilber category"}

## Eilenberg–Zilber category {#Eilenberg–Zilber_category}

An **Eilenberg–Zilber category** is a variant of a Reedy category.

:::
