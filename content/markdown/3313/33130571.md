# Android Privacy Guard

the OpenPGP compatible Android app

::: {#o2 .subject cue=lead name="Android Privacy Guard"}

**Android Privacy Guard** (APG) is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source) [app](https://en.wikipedia.org/wiki/Mobile_app) for the [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29) [operating system](https://en.wikipedia.org/wiki/Operating_system) that provides strong, user-based [encryption](wikipedia://en/10294) which is compatible with the [Pretty Good Privacy](wikipedia://en/23080) (PGP) and [GNU Privacy Guard](wikipedia://en/38809) (GPG) programs. This allows users to encrypt, decrypt, [digitally sign](wikipedia://en/59644), and verify signatures for [text](https://en.wikipedia.org/wiki/Text_file), [emails](https://en.wikipedia.org/wiki/Email), and other [files](https://en.wikipedia.org/wiki/Computer_file).

:::

The application allows the user to store the [credentials](https://en.wikipedia.org/wiki/Credential#Cryptography) of other users with whom they interact, and to encrypt files such that only a specified user can decrypt them. In the same manner, if a file is received from another user and its credentials are saved, the receiver can verify the authenticity of that file and decrypt it if necessary.

The specific implementation in APG relies on the [Spongy Castle APIs](wikipedia://en/3636963).

APG has not been updated since March 2014 and is no longer under active development. The development has been picked up by [OpenKeychain](https://en.wikipedia.org/wiki/OpenKeychain).

## Reception {#Reception}

After its initial release in June 2010,[^o4] it has gained a strong following with over 2000 reviews and over 100,000 installs from the Google Play store.[^o5] Several tutorials have been written which instruct new users in how to set up APG on an Android phone.[^o6][^o7] These tutorials generally reference APGs interaction with the [K-9 Mail](https://en.wikipedia.org/wiki/K-9_Mail) Android e-mail client.[^o8][^o9]

### OpenKeychain {#OpenKeychain}

Between December 2010 and October 2013 no new version of APG was released.[^o11] In the light of the [global surveillance disclosures](https://en.wikipedia.org/wiki/Global_surveillance_disclosures_%282013–present%29) this lack of development was viewed critically by the community.[^o12] In September 2013 a [fork](https://en.wikipedia.org/wiki/Fork_%28software_development%29) of APG was released, version 2.1 of [OpenKeychain](https://en.wikipedia.org/wiki/OpenKeychain).[^o13] Some of the new features and improvements were subsequently merged back to APG. However, this process stopped in March 2014, while the OpenKeychain project continued to release new versions.[^o14] As of February 2016 the development of OpenKeychain is more active than that of APG.[^o15] Notable features of OpenKeychain include a modern user interface, support for [NFC](https://en.wikipedia.org/wiki/Near_field_communication) and the [YubiKey NEO](https://en.wikipedia.org/wiki/YubiKey).[^o16]
