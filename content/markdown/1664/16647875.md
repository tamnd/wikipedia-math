# Bivariegated graph

::: {#o1 .subject cue=lead name="Bivariegated graph"}

In [graph theory](wikipedia://en/12401), a **bivariegated graph** is a graph whose vertex set can be [partitioned](wikipedia://en/340240) into two equal parts such that each vertex is adjacent to exactly one vertex from the other set not containing it.[^o2][^o3][^o4] In a bivarigated graph *G* with 2*n* vertices, there exists a set of *n* independent edges such that no odd number of them lie on a cycle of *G*.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

The [Petersen graph](wikipedia://en/194926), shown below, is a bivariegated graph: if one partitions it into an outer pentagon and an inner five-point star, each vertex on one side of the partition has exactly one neighbor on the other side of the partition. More generally, the same is true for any [generalized Petersen graph](wikipedia://en/23716451) formed by connecting an outer polygon and an inner star with the same number of points; for instance, this applies to the [Möbius–Kantor graph](wikipedia://en/13396591) and the [Desargues graph](wikipedia://en/1578059).

*Image: Petersen1 tiny.svg.*

Any [hypercube graph](wikipedia://en/6706815), such as the four-dimensional hypercube shown below, is also bivariegated.

*Image: Hypercubecentral.svg.*

However, the graph shown below is not bivariegated. Whatever you choose the three independent edges, one of them is an edge of a cycle.

:::

## Bivariegated trees {#Bivariegated_trees}

A tree *T* with 2*n* vertices, is bivariegated if and only if the [independence number](https://en.wikipedia.org/wiki/Independence_number) of *T* is *n*, or, equivalently, if and only if it has a [perfect matching](wikipedia://en/44031).[^o2]

::: {#o9 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

The ***k*-varigated graph**, *k* ≥ 3, can be defined similarly. A graph is said to be *k*-varigated if its vertex set can be partitioned into *k* equal parts such that each vertex is adjacent to exactly one vertex from every other part not containing it.[^o3]

:::

## Notes {#Notes}

- Characterizing the [degree sequences](https://en.wikipedia.org/wiki/Degree_sequence) of bivariegated graphs has been an unsolved problem in graph theory.
