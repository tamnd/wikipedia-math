# Probabilistic genotyping

::: {#o1 .subject cue=lead name="Probabilistic genotyping"}

**Probabilistic genotyping** is the use of statistical methods and mathematical algorithms in [DNA Profiling](https://en.wikipedia.org/wiki/DNA_Profiling). It may be used instead of manual methods in difficult situations, such as when a DNA sample is very small or includes a mixture of multiple individuals' DNA.[^o2] Probabilistic genotyping, unlike [traditional methods](https://en.wikipedia.org/wiki/Genotyping), avoids the need for subjective judgment.[^o2] The reliability of the method has been questioned by some defense lawyers because the source code of some probabilistic genotyping programs is [proprietary](https://en.wikipedia.org/wiki/Proprietary_software).[^o3]

:::
