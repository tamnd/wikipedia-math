# Preordered class

::: {#o1 .subject cue=lead name="Preordered class"}

In [mathematics](wikipedia://en/18831), a **preordered class** is a [class](https://en.wikipedia.org/wiki/Class_%28mathematics%29) equipped with a [preorder](wikipedia://en/23582).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

When dealing with a class *C*, it is possible to define a class relation on *C* as a [subclass](wikipedia://en/1828474) of the power class *C $\times$ C* . Then, it is convenient to use the language of [relations](wikipedia://en/22517558) on a set.

A **preordered class** is a class with a [preorder](wikipedia://en/23582) on it. *Partially ordered class* and *totally ordered class* are defined in a similar way. These concepts generalize respectively those of [preordered set](https://en.wikipedia.org/wiki/Preordered_set), [partially ordered set](wikipedia://en/23572) and [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set). However, it is difficult to work with them as in the *small* case because many constructions common in a [set theory](wikipedia://en/27553) are no longer possible in this framework.

Equivalently, a preordered class is a **[thin category](wikipedia://en/31353487)**, that is, a [category](wikipedia://en/53759) with at most one morphism from an object to another.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- In any [category](wikipedia://en/53759) *C*, when *D* is a class of morphisms of *C* containing identities and closed under composition, the relation 'there exists a *D*-morphism from *X* to *Y**is a preorder on the class of objects of*****C*.***
- The class **Ord** of all [ordinals](wikipedia://en/26547932) is a totally ordered class with the classical ordering of ordinals.

:::
