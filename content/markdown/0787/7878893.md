# Andrica's conjecture

::: {#o1 .subject cue=lead name="Andrica's conjecture"}

**Andrica's conjecture** (named after Romanian mathematician Dorin Andrica) is a [conjecture](wikipedia://en/6138) regarding the [gaps](wikipedia://en/5075259) between [prime numbers](wikipedia://en/23666).[^o2]

:::

The conjecture states that the inequality

$$\sqrt{p_{n+1}} - \sqrt{p_n} < 1$$

holds for all $n$, where $p_n$ is the $n$-th prime number. If $g_n = p_{n+1} - p_n$ denotes the $n$-th [prime gap](wikipedia://en/5075259), then Andrica's conjecture can also be rewritten as

$$g_n < 2\sqrt{p_n} + 1.$$

## Empirical evidence {#Empirical_evidence}

Imran Ghory has used data on the largest prime gaps to confirm the conjecture for $n$ up to \1.3002 × 10<sup>16</sup>.[^o4] Using a more recent table of [maximal gaps](https://en.wikipedia.org/wiki/Prime_gaps#Numerical_results), the confirmation value can be extended exhaustively to 2 × 10<sup>19</sup> > 2<sup>64</sup>.

The discrete function $A_n = \sqrt{p_{n+1}}-\sqrt{p_n}$ is plotted in the figures opposite. The high-water marks for $A_n$ occur for *n* = 1, 2, and 4, with *A*<sub>4</sub> ≈ 0.670873..., with no larger value among the first 10<sup>5</sup> primes. Since the Andrica function decreases [asymptotically](https://en.wikipedia.org/wiki/Asymptotically) as *n* increases, a prime gap of ever increasing size is needed to make the difference large as *n* becomes large. It therefore seems highly likely the conjecture is true, although this has not yet been proven.

The best proven bound on gap sizes is *g*<sub>*n*</sub> \< *p*<sub>*n*</sub><sup>\0.525</sup> (for *n* sufficiently large). Thus, using an inequality of *p*<sub>*n*</sub><sup>\0.525</sup>\< *2p*<sub>*n*</sub><sup>\0.5</sup>+1, the conjecture is verified for *p*<sub>*n*</sub> up to 1.099532599291×10<sup>12</sup>.

::: {#o6 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

*Image: Generalized Andrica's conjecture.svg.* Value of *x* in the generalized Andrica's conjecture for the first 100 primes, with the conjectured value of *x*<sub>min</sub> labeled.

As a generalization of Andrica's conjecture, the following equation has been considered:

$$p _ {n+1} ^ x - p_ n ^ x = 1,$$

where $p_n$ is the *n*th prime and *x* can be any positive number.

The largest possible solution for *x* is easily seen to occur for *n*=1, when *x*<sub>max</sub> = 1. The smallest solution for *x* is conjectured to be *x*<sub>min</sub> ≈ 0.567148... which occurs for *n* = 30.

This conjecture has also been stated as an [inequality](wikipedia://en/89489), the generalized Andrica conjecture:

$p _ {n+1} ^ x - p_ n ^ x < 1$ for $x < x_{\min}.$
