# Spread of a matrix

::: {#o1 .subject cue=lead name="Spread of a matrix"}

In [mathematics](wikipedia://en/18831), and more specifically [matrix theory](wikipedia://en/20556859), the **spread of a matrix** is the largest distance in the [complex plane](wikipedia://en/217628) between any two [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of the matrix.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $A$ be a [square matrix](wikipedia://en/166022) with eigenvalues $\lambda_1, \ldots, \lambda_n$. That is, these values $\lambda_i$ are the [complex numbers](wikipedia://en/5826) such that there exists a vector $v_i$ on which $A$ acts by [scalar multiplication](wikipedia://en/244373):

$$Av_i=\lambda_i v_i.$$

Then the **spread** of $A$ is the [non-negative number](https://en.wikipedia.org/wiki/Non-negative_number)

$$s(A) = \max \{|\lambda_i - \lambda_j| : i,j=1,\ldots n\}.$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- For the [zero matrix](wikipedia://en/1168888) and the [identity matrix](wikipedia://en/59718), the spread is zero. The zero matrix has only zero as its eigenvalues, and the identity matrix has only one as its eigenvalues. In both cases, all eigenvalues are equal, so no two eigenvalues can be at nonzero distance from each other.
- For a [projection](wikipedia://en/3909097), the only eigenvalues are zero and one. A [projection matrix](wikipedia://en/15180479) therefore has a spread that is either $0$ (if all eigenvalues are equal) or $1$ (if there are two different eigenvalues).
- All eigenvalues of a [unitary matrix](wikipedia://en/129222) $A$ lie on the [unit circle](wikipedia://en/27072071). Therefore, in this case, the spread is at most equal to the [diameter](wikipedia://en/8007) of the circle, the number 2.
- The spread of a matrix depends only on the [spectrum](wikipedia://en/506713) of the matrix (its multiset of eigenvalues). If a second matrix $B$ of the same size is [invertible](wikipedia://en/217122), then $BAB^{-1}$ has the same spectrum as $A$. Therefore, it also has the same spread as $A$.

:::
