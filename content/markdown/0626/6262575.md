# Stretched exponential function

*Image: Stretched exponential.svg.* **Figure 1**. Plot of $f_{\beta}(t) = e^{-t^{\beta}}$ for varying values of *β*, with stretched exponentials ($\beta < 1$) in reddish colors, compressed exponentials ($\beta > 1$) in green and blue colors, and the standard exponential function in yellow. The [degenerate cases](https://en.wikipedia.org/wiki/Degenerate_case) $\beta \to 0$ and $\beta \to +\infty$ are marked in dotted lines.

::: {#o1 .subject cue=lead name="Stretched exponential function"}

The **stretched exponential function**

$$f_\beta (t) = e^{ -t^\beta }$$

is obtained by inserting a fractional [power law](wikipedia://en/24522) into the [exponential function](wikipedia://en/9678). In most applications, it is meaningful only for arguments $t$ between 0 and +∞. With $\beta = 1$, the usual exponential function is recovered. With a *stretching exponent* *β* between 0 and 1, the graph of log *f* versus *t* is characteristically *stretched*, hence the name of the function. The **compressed exponential function** (with $\beta > 1$) has less practical importance, with the notable exceptions of $\beta = 2$, which gives the [normal distribution](wikipedia://en/21462), and of compressed exponential relaxation in the dynamics of [amorphous solids](https://en.wikipedia.org/wiki/Amorphous_solids).[^o2]

:::

In mathematics, the stretched exponential is also known as the [complementary cumulative](wikipedia://en/5793#Complementary_cumulative_distribution_function_%28tail_distribution%29) [Weibull distribution](wikipedia://en/206948). The stretched exponential is also the [characteristic function](wikipedia://en/3229401), basically the [Fourier transform](wikipedia://en/52247), of the [Lévy symmetric alpha-stable distribution](wikipedia://en/1117869).

In physics, the stretched exponential function is often used as a phenomenological description of [relaxation](wikipedia://en/1780263) in disordered systems. It was first introduced by [Rudolf Kohlrausch](https://en.wikipedia.org/wiki/Rudolf_Kohlrausch) in 1854 to describe the discharge of a [capacitor](https://en.wikipedia.org/wiki/Capacitor);[^o3] thus it is also known as the **Kohlrausch function**. In 1970, G. Williams and D.C. Watts used the [Fourier transform](wikipedia://en/52247) of the stretched exponential to describe [dielectric spectra](https://en.wikipedia.org/wiki/Dielectric_spectroscopy) of polymers;[^o4] in this context, the stretched exponential or its Fourier transform are also called the **Kohlrausch–Williams–Watts (KWW) function**. The Kohlrausch–Williams–Watts (KWW) function corresponds to the [time domain](wikipedia://en/173419) charge response of the main dielectric models, such as the [Cole–Cole equation](https://en.wikipedia.org/wiki/Cole–Cole_equation), the [Cole–Davidson equation](wikipedia://en/70105931), and the [Havriliak–Negami relaxation](https://en.wikipedia.org/wiki/Havriliak–Negami_relaxation), for small time arguments.[^o5]

In phenomenological applications, it is often not clear whether the stretched exponential function should be used to describe the differential or the integral distribution function—or neither. In each case, one gets the same asymptotic decay, but a different power law prefactor, which makes fits more ambiguous than for simple exponentials. In a few cases,[^o6][^o7][^o8][^o9] it can be shown that the asymptotic decay is a stretched exponential, but the prefactor is usually an unrelated power.

## Mathematical properties {#Mathematical_properties}

### Moments {#Moments}

Following the usual physical interpretation, we interpret the function argument *t* as time, and *f*<sub>β</sub>(*t*) is the differential distribution. The area under the curve can thus be interpreted as a *mean relaxation time*. One finds

$$\langle\tau\rangle \equiv \int_0^\infty dt\, e^{-(t/\tau_K)^\beta} = {\tau_K \over \beta } \Gamma {\left( \frac 1 \beta \right)}$$

where $\Gamma$ is the [gamma function](wikipedia://en/12316). For [exponential decay](wikipedia://en/330320), $\langle\tau\rangle = \tau_{K}$ is recovered.

The higher [moments](wikipedia://en/368684) of the stretched exponential function are[^o12]

$$\langle\tau^n\rangle \equiv \int_0^\infty dt\, t^{n-1}\, e^{-(t/\tau_K)^\beta} = {{\tau_K}^n \over \beta }\Gamma {\left(\frac n \beta \right)}.$$

### Distribution function {#Distribution_function}

In physics, attempts have been made to explain stretched exponential behaviour as a linear superposition of simple exponential decays. This requires a nontrivial distribution of relaxation times, *ρ*(*u*), which is implicitly defined by

$$e^{-t^\beta} = \int_0^\infty du\,\rho(u)\, e^{-t/u}.$$

Alternatively, a distribution

$$G = u \rho (u)$$

is used.

*ρ* can be computed from the series expansion:[^o14]

$$\rho (u ) = -{ 1 \over \pi u} \sum_{k = 0}^\infty {(-1)^k \over k!} \sin (\pi \beta k)\Gamma (\beta k + 1) u^{\beta k}$$

For rational values of *β*, *ρ*(*u*) can be calculated in terms of elementary functions. But the expression is in general too complex to be useful except for the case $\beta = 1/2$ where

$$G(u) = u \rho(u) = { 1 \over 2\sqrt{\pi}} \sqrt{u} e^{-u/4}$$

Figure 2 shows the same results plotted in both a [linear](https://en.wikipedia.org/wiki/Linear) and a [log](wikipedia://en/17860) representation. The curves converge to a [Dirac delta function](wikipedia://en/37021) peaked at $u = 1$ as *β* approaches 1, corresponding to the simple exponential function.

The moments of the original function can be expressed as

$$\langle\tau^n\rangle = \Gamma(n) \int_0^\infty d\tau\, t^n \, \rho(\tau).$$

The first logarithmic moment of the distribution of simple-exponential relaxation times is

$$\langle\ln\tau\rangle = \left( 1 - {1 \over \beta} \right) \gamma + \ln \tau_K$$

where *γ* is the [Euler constant](https://en.wikipedia.org/wiki/Euler_constant).[^o16]

## Fourier transform {#Fourier_transform}

To describe results from spectroscopy or [inelastic scattering](https://en.wikipedia.org/wiki/Inelastic_scattering), the sine or cosine Fourier transform of the stretched exponential is needed. It must be calculated either by numeric integration, or from a series expansion.[^o18] The series here as well as the one for the distribution function are special cases of the [Fox–Wright function](wikipedia://en/34287523).[^o19] For practical purposes, the Fourier transform may be approximated by the [Havriliak–Negami function](https://en.wikipedia.org/wiki/Havriliak–Negami_relaxation),[^o20] though nowadays the numeric computation can be done so efficiently[^o21] that there is no longer any reason not to use the Kohlrausch–Williams–Watts function in the frequency domain.

## History and further applications {#History_and_further_applications}

*Image: Pibmasterplot.png.* **Figure 3**. Illustration of a stretched exponential fit (with *β*=0.52) to an empirical master curve. For comparison, a least squares single and a [double exponential](wikipedia://en/8541166) fit are also shown. The data are rotational [anisotropy](https://en.wikipedia.org/wiki/Anisotropy) of [anthracene](https://en.wikipedia.org/wiki/Anthracene) in [polyisobutylene](https://en.wikipedia.org/wiki/Polyisobutylene) of several [molecular masses](https://en.wikipedia.org/wiki/Molecular_mass).[^o23] The plots have been made to overlap by dividing time (*t*) by the respective characteristic [time constant](https://en.wikipedia.org/wiki/Time_constant).

As said in the introduction, the stretched exponential was introduced by the [German](https://en.wikipedia.org/wiki/Germans) [physicist](https://en.wikipedia.org/wiki/Physicist) [Rudolf Kohlrausch](https://en.wikipedia.org/wiki/Rudolf_Kohlrausch) in 1854 to describe the discharge of a capacitor ([Leyden jar](https://en.wikipedia.org/wiki/Leyden_jar)) that used glass as dielectric medium. The next documented usage is by [Friedrich Kohlrausch](https://en.wikipedia.org/wiki/Friedrich_Kohlrausch_%28physicist%29), son of Rudolf, to describe torsional relaxation. [A. Werner](https://en.wikipedia.org/wiki/A._Werner) used it in 1907 to describe complex luminescence decays; [Theodor Förster](https://en.wikipedia.org/wiki/Theodor_Förster) in 1949 as the fluorescence decay law of electronic energy donors.[^o24]

Outside [condensed matter physics](https://en.wikipedia.org/wiki/Condensed_matter_physics), the stretched exponential has been used to describe the removal rates of small, stray bodies in the solar system,[^o25] the diffusion-weighted MRI signal in the brain,[^o26] and the production from unconventional gas wells.[^o27]

### In probability {#In_probability}

If the integrated distribution is a stretched exponential, the normalized [probability density function](wikipedia://en/23543) is given by

$$p(\tau \mid \lambda, \beta)~d\tau = \frac{\lambda}{\Gamma(1 + \beta^{-1})} ~ e^{-(\tau \lambda)^\beta} ~ d\tau$$

Note that confusingly some authors have been known to use the name "stretched exponential" to refer to the [Weibull distribution](wikipedia://en/206948).[^o29]

### Modified functions {#Modified_functions}

A modified stretched exponential function

$$f_\beta (t) = e^{ -t^{\beta(t)} }$$

with a slowly *t*-dependent exponent *β* has been used for biological survival curves.[^o31][^o32]

### Wireless communications {#Wireless_communications}

In wireless communications, a scaled version of the stretched exponential function has been shown to appear in the Laplace Transform for the interference power $I$ when the transmitters' locations are modeled as a 2D [Poisson Point Process](wikipedia://en/41597450) with no exclusion region around the receiver.[^o34]

The [Laplace transform](wikipedia://en/18610) can be written for arbitrary [fading](https://en.wikipedia.org/wiki/Fading) distribution as follows:

$$L_I(s) = \exp\left(-\pi \lambda \mathbb{E}{\left[g^\frac{2}{\eta} \right]} \Gamma{\left(1 - \frac{2}{\eta} \right)} s^\frac{2}{\eta}\right) = \exp\left(- t s^\beta \right)$$

where $g$ is the power of the fading, $\eta$ is the [path loss exponent](wikipedia://en/41492#Loss_exponent), $\lambda$ is the density of the 2D Poisson Point Process, $\Gamma(\cdot)$ is the Gamma function, and $\mathbb{E}[x]$ is the expectation of the variable $x$.

The same reference also shows how to obtain the inverse Laplace Transform for the stretched exponential $\exp\left(-s^\beta \right)$ for higher order integer $\beta = \beta_q \beta_b$ from lower order integers $\beta_a$ and $\beta_b$.

### Internet streaming {#Internet_streaming}

The stretched exponential has been used to characterize Internet media accessing patterns, such as YouTube and other stable [streaming media](https://en.wikipedia.org/wiki/Streaming_media) sites.[^o36] The commonly agreed power-law accessing patterns of Web workloads mainly reflect text-based content Web workloads, such as daily updated news sites.[^o37]
