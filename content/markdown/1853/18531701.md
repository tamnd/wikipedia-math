# Gauss–Hermite quadrature

::: {#o1 .subject cue=lead name="Gauss–Hermite quadrature"}

*Image: Gauss-Hermite quadrature weights.svg.* Weights versus *x<sub>i</sub>* for four choices of *n*

In [numerical analysis](wikipedia://en/21506), **Gauss–Hermite quadrature** is a form of [Gaussian quadrature](wikipedia://en/50579) for approximating the value of integrals of the following kind:

:::

$$\int_{-\infty}^{+\infty} e^{-x^2} f(x)\,dx.$$

In this case

$$\int_{-\infty}^{+\infty} e^{-x^2} f(x)\,dx \approx \sum_{i=1}^n w_i f(x_i)$$

where *n* is the number of sample points used. The *x*<sub>*i*</sub> are the roots of the physicists' version of the [Hermite polynomial](https://en.wikipedia.org/wiki/Hermite_polynomial) *H*<sub>*n*</sub>(*x*) (*i* = 1,2,...,*n*), and the associated weights *w*<sub>*i*</sub> are given by [^o2]

$$w_i = \frac {2^{n-1} n! \sqrt{\pi}} {n^2[H_{n-1}(x_i)]^2}.$$

## Example with change of variable {#Example_with_change_of_variable}

Consider a function *h(y)*, where the variable *y* is [normally distributed](wikipedia://en/21462): $y \sim \mathcal{N}(\mu,\sigma^2)$. The [expectation](wikipedia://en/9653) of *h* corresponds to the following integral:

$$E[h(y)] = \int_{-\infty}^{+\infty} \frac{1}{\sigma \sqrt{2\pi}} \exp \left( -\frac{(y-\mu)^2}{2\sigma^2} \right) h(y) dy$$

As this does not exactly correspond to the Hermite polynomial, we need to change variables:

$$x = \frac{y-\mu}{\sqrt{2} \sigma} \Leftrightarrow y = \sqrt{2} \sigma x + \mu$$

Coupled with the [integration by substitution](wikipedia://en/193748), we obtain:

$$E[h(y)] = \int_{-\infty}^{+\infty} \frac{1}{\sqrt{\pi}} \exp(-x^2) h(\sqrt{2} \sigma x + \mu) dx$$

leading to:

$$E[h(y)] \approx \frac{1}{\sqrt{\pi}} \sum_{i=1}^n w_i h(\sqrt{2} \sigma x_i + \mu)$$

As an illustration, in the simplest non-trivial case, with $n = 2$, we have $x_1 = -\frac{1}{\sqrt{2}}, x_2 = \frac{1}{\sqrt{2}}$ and $w_1 = w_2 = \frac{\sqrt{\pi}}{2}$, so the estimate reduces to:

$$E[h(y)] \approx \frac{1}{2}(h(\mu - \sigma) + h(\mu + \sigma))$$

– i.e. the average of the function's values one standard deviation below and above the mean.
