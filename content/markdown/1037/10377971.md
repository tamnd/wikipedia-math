# Virtually

::: {#o1 .subject cue=lead name="Virtually"}

In [mathematics](wikipedia://en/18831), especially in the area of [abstract algebra](wikipedia://en/19616384) that studies [infinite groups](wikipedia://en/4587030), the adverb **virtually** is used to modify a property so that it need only hold for a [subgroup](wikipedia://en/28011) of finite [index](wikipedia://en/230581). Given a property P, the group *G* is said to be *virtually P* if there is a finite index subgroup $H \le G$ such that *H* has property P.

:::

Common uses for this would be when P is [abelian](wikipedia://en/2974), [nilpotent](wikipedia://en/144569), [solvable](wikipedia://en/105012) or [free](wikipedia://en/59735). For example, virtually solvable groups are one of the two alternatives in the [Tits alternative](wikipedia://en/12704641), while [Gromov's theorem](wikipedia://en/635483) states that the finitely generated groups with [polynomial growth](wikipedia://en/498727) are precisely the finitely generated virtually nilpotent groups.

This terminology is also used when P is just another group. That is, if *G* and *H* are groups then *G* is *virtually* *H* if *G* has a subgroup *K* of finite index in *G* such that *K* is [isomorphic](wikipedia://en/14828) to *H*.

In particular, a group is virtually trivial if and only if it is finite. Two groups are virtually equal if and only if they are [commensurable](wikipedia://en/29343178).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

### Virtually abelian {#Virtually_abelian}

The following groups are virtually abelian.

- Any abelian group.
- Any [semidirect product](wikipedia://en/48246) $N\rtimes H$ where *N* is abelian and *H* is finite. (For example, any [generalized dihedral group](wikipedia://en/7149681).)
- Any semidirect product $N\rtimes H$ where *N* is finite and *H* is abelian.
- Any finite group (since the trivial subgroup is abelian).

### Virtually nilpotent {#Virtually_nilpotent}

- Any group that is virtually abelian.
- Any nilpotent group.
- Any semidirect product $N\rtimes H$ where *N* is nilpotent and *H* is finite.
- Any semidirect product $N\rtimes H$ where *N* is finite and *H* is nilpotent.

[Gromov's theorem](wikipedia://en/635483) says that a finitely generated group is virtually nilpotent if and only if it has polynomial growth.

### Virtually free {#Virtually_free}

- Any [free group](wikipedia://en/59735).
- Any finite group (since the trivial subgroup is the free group on the empty set of generators).
- Any virtually [cyclic group](wikipedia://en/52327). (Either it is finite in which case it falls into the above case, or it is infinite and contains $\mathbb{Z}$ as a subgroup.)
- Any semidirect product $N\rtimes H$ where *N* is free and *H* is finite.
- Any semidirect product $N\rtimes H$ where *N* is finite and *H* is free.
- Any [free product](wikipedia://en/360036) $H*K$, where *H* and *K* are both finite. (For example, the [modular group](wikipedia://en/325019) $\operatorname{PSL}(2,\mathbb{Z})$.)

It follows from [Stalling's theorem](wikipedia://en/19196631#Applications_and_generalizations) that any torsion-free virtually free group is free.

:::

### Others {#Others}

The free group $F_2$ on 2 generators is virtually $F_n$ for any $n\ge 2$ as a consequence of the [Nielsen–Schreier theorem](wikipedia://en/18401725) and the [Schreier index formula](https://en.wikipedia.org/wiki/Schreier_index_formula).

The group $\operatorname{O}(n)$ is virtually connected as $\operatorname{SO}(n)$ has index 2 in it.

:::
