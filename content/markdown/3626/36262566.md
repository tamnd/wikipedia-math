# Büchi arithmetic

::: {#o1 .subject cue=lead name="Büchi arithmetic"}

**Büchi arithmetic** of base *k* is the [first-order theory](https://en.wikipedia.org/wiki/First-order_predicate_calculus) of the [natural numbers](wikipedia://en/21474) with [addition](wikipedia://en/61338) and the function $V_k(x)$ which is defined as the largest power of *k* dividing *x*, named in honor of the Swiss mathematician [Julius Richard Büchi](wikipedia://en/6736044). The [signature](https://en.wikipedia.org/wiki/Signature_%28mathematical_logic%29) of Büchi arithmetic contains only the addition operation, $V_k$ and equality, omitting the multiplication operation entirely.

:::

Unlike [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), Büchi arithmetic is a [decidable theory](wikipedia://en/913118). This means it is possible to effectively determine, for any sentence in the language of Büchi arithmetic, whether that sentence is provable from the axioms of Büchi arithmetic.

## Büchi arithmetic and automata {#Büchi_arithmetic_and_automata}

A subset $X\subseteq \mathbb N^n$ is definable in Büchi arithmetic of base *k* if and only if it is [*k*-recognisable](wikipedia://en/7740302).

If $n=1$ this means that the set of integers of *X* in base *k* is accepted by an [automaton](wikipedia://en/103356). Similarly if $n>1$ there exists an automaton that reads the first digits, then the second digits, and so on, of *n* integers in base *k*, and accepts the words if the *n* integers are in the relation *X*.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties of Büchi arithmetic"}

## Properties of Büchi arithmetic {#Properties_of_Büchi_arithmetic}

If *k* and *l* are [multiplicatively dependent](wikipedia://en/50027042), then the Büchi arithmetics of base *k* and *l* have the same expressivity. Indeed $V_l$ can be defined in $\text{FO}(V_k,+)$, the first-order theory of $V_k$ and $+$.

Otherwise, an arithmetic theory with *both* $V_k$ and $V_l$ functions is equivalent to [Peano arithmetic](wikipedia://en/25005), which has both addition and multiplication, since multiplication is definable in $\text{FO}(V_k,V_l,+)$.

Further, by the [Cobham–Semënov theorem](wikipedia://en/7740302#Properties), if a relation is definable in both *k* and *l* Büchi arithmetics, then it is definable in [Presburger arithmetic](wikipedia://en/23756).[^o5][^o6]

:::
