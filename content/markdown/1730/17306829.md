# Conceptual necessity

::: {#o1 .subject cue=lead name="Conceptual necessity"}

**Conceptual necessity** is a property of the certainty with which a state of affairs, as presented by a certain description, occurs:[^o2] it occurs by conceptual necessity if and only if it occurs just by virtue of the meaning of the description. If someone is a [bachelor](https://en.wikipedia.org/wiki/Bachelor), for instance, then he is bound to be unmarried by conceptual necessity, because the meaning of the word "bachelor" determines that he is.

:::

Alternatively, there is [metaphysical necessity](wikipedia://en/741170), which is a certainty determined, not by the meaning of a description, but instead by facts in the world described.

Historically, [Baruch Spinoza](https://en.wikipedia.org/wiki/Baruch_Spinoza) was a subscriber to this belief.[^o3]
