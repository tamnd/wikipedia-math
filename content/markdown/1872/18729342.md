# Multidimensional Chebyshev's inequality

::: {#o1 .subject cue=lead name="Multidimensional Chebyshev's inequality"}

In [probability theory](wikipedia://en/23542), the **multidimensional Chebyshev's inequality**[^o2] is a generalization of [Chebyshev's inequality](wikipedia://en/156533), which puts a bound on the probability of the event that a [random variable](wikipedia://en/25685) differs from its [expected value](wikipedia://en/9653) by more than a specified amount.

:::

Let $X$ be an $N$-dimensional [random vector](https://en.wikipedia.org/wiki/Random_vector) with [expected value](wikipedia://en/9653) $\mu=\operatorname{E}[X]$ and [covariance matrix](wikipedia://en/191752)

$$V=\operatorname{E} [(X - \mu) (X - \mu)^T]. \,$$

If $V$ is a [positive-definite matrix](https://en.wikipedia.org/wiki/Positive-definite_matrix), for any [real number](wikipedia://en/20646438) $t>0$:

$$\Pr \left( \sqrt{( X-\mu)^T V^{-1} (X-\mu) } > t\right) \le \frac N {t^2}$$

::: {#o4 .proof cue=heading name="Proof"}

## Proof {#Proof}

Since $V$ is positive-definite, so is $V^{-1}$. Define the random variable

$$y = (X-\mu)^T V^{-1} (X-\mu).$$

Since $y$ is positive, [Markov's inequality](wikipedia://en/238232) holds:

$$\Pr\left( \sqrt{(X-\mu)^T V^{-1} (X-\mu) } > t\right) = \Pr( \sqrt{y} > t) = \Pr(y > t^2) \le \frac{\operatorname{E}[y]}{t^2}.$$

Finally,

$\begin{aligned} \operatorname{E}[y] &= \operatorname{E}[(X-\mu)^T V^{-1} (X-\mu)]\\[6pt] &=\operatorname{E}[ \operatorname{trace} ( V^{-1} (X-\mu) (X-\mu)^T )]\\[6pt] &= \operatorname{trace} ( V^{-1} V ) = N \end{aligned}.$[^o2][^o5]

:::

## Infinite dimensions {#Infinite_dimensions}

There is a straightforward extension of the vector version of Chebyshev's inequality to infinite dimensional settings<sup>\[more refs. needed\]</sup>.[^o7] Let $X$ be a random variable which takes values in a [Fréchet space](wikipedia://en/233801) $\mathcal X$ (equipped with seminorms $|| \cdot ||_{\alpha}$). This includes most common settings of vector-valued random variables, e.g., when $\mathcal X$ is a [Banach space](wikipedia://en/3989) (equipped with a single norm), a [Hilbert space](wikipedia://en/20598932), or the finite-dimensional setting as described above.

Suppose that $X$ is of "[strong order two](https://en.wikipedia.org/wiki/Strong_order_two)", meaning that

$$\operatorname{E}\left(\| X\|_\alpha^2 \right) < \infty$$

for every seminorm $|| \cdot ||_{\alpha}$. This is a generalization of the requirement that $X$ have finite variance, and is necessary for this strong form of Chebyshev's inequality in infinite dimensions. The terminology "strong order two" is due to [Vakhania](https://en.wikipedia.org/wiki/Vakhania).[^o8]

Let $\mu \in \mathcal X$ be the [Pettis integral](wikipedia://en/20983125) of $X$ (i.e., the vector generalization of the mean), and let

$$\sigma_a := \sqrt{\operatorname{E}\|X - \mu\|_\alpha^2}$$

be the [standard deviation](wikipedia://en/27590) with respect to the seminorm $|| \cdot ||_{\alpha}$. In this setting we can state the following:

**General version of Chebyshev's inequality.** $\forall k > 0: \quad \Pr\left( \|X - \mu\|_\alpha \ge k \sigma_\alpha \right) \le \frac{1}{ k^2 }.$

::: {#o9 .proof cue=inline-head name="Proof"}

**Proof.** The proof is straightforward, and essentially the same as the finitary version<sup>\[source needed\]</sup>. If $\sigma_{\alpha} = 0$, then $X$ is constant (and equal to $\mu$) [almost surely](wikipedia://en/351908), so the inequality is trivial.

If

$$\|X - \mu\|_\alpha \ge k \sigma_\alpha$$

then $||X - \mu||_{\alpha} > 0$, so we may safely divide by $||X - \mu||_{\alpha}$. The crucial trick in Chebyshev's inequality is to recognize that $1 = \tfrac{\|X - \mu\|_\alpha^2}{\|X - \mu\|_\alpha^2}$.

The following calculations complete the proof:

$$\begin{aligned} \Pr\left( \|X - \mu\|_\alpha \ge k \sigma_\alpha \right) &= \int_\Omega \mathbf{1}_{\|X - \mu\|_\alpha \ge k \sigma_\alpha} \, \mathrm d\Pr \\ & = \int_\Omega \left ( \frac{\|X - \mu\|_\alpha^2}{\|X - \mu\|_\alpha^2} \right ) \cdot \mathbf{1}_{\|X - \mu\|_\alpha \ge k \sigma_\alpha} \, \mathrm d\Pr \\[6pt] &\le \int_\Omega \left (\frac{\|X - \mu\|_\alpha^2}{(k\sigma_\alpha)^2} \right ) \cdot \mathbf{1}_{\|X - \mu\|_\alpha \ge k \sigma_\alpha} \, \mathrm d\Pr \\[6pt] &\le \frac{1}{k^2 \sigma_\alpha^2} \int_\Omega \|X - \mu\|_\alpha^2 \, \mathrm d\Pr && \mathbf{1}_{\|X - \mu\|_\alpha \ge k \sigma_\alpha} \le 1\\[6pt] &= \frac{1}{k^2 \sigma_\alpha^2} \left (\operatorname{E}\|X - \mu\|_\alpha^2 \right )\\[6pt] &= \frac{1}{k^2 \sigma_\alpha^2} \left (\sigma_\alpha^2 \right )\\[6pt] &= \frac{1}{k^2} \end{aligned}$$

:::
