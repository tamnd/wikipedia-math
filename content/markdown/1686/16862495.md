# Partial autocorrelation function

::: {#o1 .subject cue=lead name="Partial autocorrelation function"}

*Image: Partial autocorrelation function.png.* Partial autocorrelation function of [Lake Huron](https://en.wikipedia.org/wiki/Lake_Huron)'s depth with confidence interval (in blue, plotted around 0)

In [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis), the **partial autocorrelation function** (**PACF**) gives the [partial correlation](wikipedia://en/8771567) of a stationary time series with its own lagged values, regressed the values of the time series at all shorter lags. It contrasts with the [autocorrelation function](https://en.wikipedia.org/wiki/Autocorrelation_function), which does not control for other lags.

:::

This function plays an important role in data analysis aimed at identifying the extent of the lag in an [autoregressive (AR) model](wikipedia://en/1434444). The use of this function was introduced as part of the [Box–Jenkins](https://en.wikipedia.org/wiki/Box–Jenkins) approach to time series modelling, whereby plotting the partial autocorrelative functions one could determine the appropriate lags **p** in an AR (**p**) [model](wikipedia://en/1434444) or in an extended [ARIMA](wikipedia://en/1510134) (**p**,**d**,**q**) model.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a time series $z_t$, the partial autocorrelation of lag $k$, denoted $\phi_{k,k}$, is the [autocorrelation](wikipedia://en/2724) between $z_t$ and $z_{t+k}$ with the linear dependence of $z_t$ on $z_{t+1}$ through $z_{t+k-1}$ removed. Equivalently, it is the autocorrelation between $z_t$ and $z_{t+k}$ that is not accounted for by lags $1$ through $k-1$, inclusive.[^o4]

$$\phi_{1,1} = \operatorname{corr}(z_{t+1}, z_{t}),\text{ for }k= 1,$$

$$\phi_{k,k} = \operatorname{corr}(z_{t+k} - \hat{z}_{t+k},\, z_{t} - \hat{z}_{t}),\text{ for }k\geq 2,$$

where $\hat{z}_{t+k}$ and $\hat{z}_t$ are [linear combinations](wikipedia://en/55632) of $\{z_{t+1}, z_{t+2}, ..., z_{t+k-1}\}$ that minimize the [mean squared error](wikipedia://en/201816) of $z_{t+k}$ and $z_t$ respectively. For [stationary processes](wikipedia://en/329898), the coefficients in $\hat{z}_{t+k}$ and $\hat{z}_t$ are the same, but reversed:[^o5]

$$\hat{z}_{t+k}=\beta_1z_{t+k-1}+\cdots+\beta_{k-1}z_{t+1}\qquad\text{and}\qquad\hat{z}_t=\beta_1z_{t+1}+\cdots+\beta_{k-1}z_{t+k-1}.$$

:::

## Calculation {#Calculation}

The theoretical partial autocorrelation function of a stationary time series can be calculated by using the Durbin–Levinson Algorithm:

$$\phi_{n,n} = \frac{\rho(n) - \sum_{k=1}^{n-1} \phi_{n-1, k} \rho(n - k)}{1 - \sum_{k=1}^{n-1} \phi_{n-1, k} \rho(k) }$$

where $\phi_{n,k} = \phi_{n-1, k} - \phi_{n,n} \phi_{n-1,n-k}$ for $1 \leq k \leq n - 1$ and $\rho(n)$ is the autocorrelation function.[^o7][^o8][^o9]

The formula above can be used with sample autocorrelations to find the sample partial autocorrelation function of any given time series.[^o10][^o11]

::: {#o13 .example cue=heading name="Examples"}

## Examples {#Examples}

The following table summarizes the partial autocorrelation function of different models:[^o9][^o14]

::: {#o15 .table cue=table}

| Model | PACF |
|---|---|
| [White noise](wikipedia://en/46182) | The partial autocorrelation is 0 for all lags. |
| [Autoregressive model](wikipedia://en/1434444) | The partial autocorrelation for an AR(*p*) model is nonzero for lags less than or equal to *p* and 0 for lags greater than *p*. |
| [Moving-average model](wikipedia://en/20238265) | If $\phi_{1,1} > 0$, the partial autocorrelation [oscillates](wikipedia://en/475449) to 0. |
|  | If $\phi_{1,1} < 0$, the partial autocorrelation [geometrically](wikipedia://en/330320) decays to 0. |
| [Autoregressive–moving-average model](https://en.wikipedia.org/wiki/Autoregressive–moving-average_model) | An ARMA(*p*, *q*) model's partial autocorrelation geometrically decays to 0 but only after lags greater than *p*. |

:::

The behavior of the partial autocorrelation function mirrors that of the autocorrelation function for autoregressive and moving-average models. For example, the partial autocorrelation function of an AR(*p*) series cuts off after lag *p* similar to the autocorrelation function of an MA(*q*) series with lag *q*. In addition, the autocorrelation function of an AR(*p*) process tails off just like the partial autocorrelation function of an MA(*q*) process.[^o5]

:::

## Autoregressive model identification {#Autoregressive_model_identification}

*Image: Partial Autocorrelation Function Graph.png.* Sample partial autocorrelation function with confidence interval of a simulated AR(3) time series

Partial autocorrelation is a commonly used tool for identifying the order of an autoregressive model.[^o10] As previously mentioned, the partial autocorrelation of an AR(*p*) process is zero at lags greater than *p*.[^o9][^o14] If an AR model is determined to be appropriate, then the sample partial autocorrelation plot is examined to help identify the order.

The partial autocorrelation of lags greater than *p* for an AR(*p*) time series are approximately independent and [normal](wikipedia://en/21462) with a [mean](https://en.wikipedia.org/wiki/Mean) of 0.[^o22] Therefore, a [confidence interval](wikipedia://en/280911) can be constructed by dividing a selected [z-score](wikipedia://en/221722) by $\sqrt{n}$. Lags with partial autocorrelations outside of the confidence interval indicate that the AR model's order is likely greater than or equal to the lag. Plotting the partial autocorrelation function and drawing the lines of the confidence interval is a common way to analyze the order of an AR model. To evaluate the order, one examines the plot to find the lag after which the partial autocorrelations are all within the confidence interval. This lag is determined to likely be the AR model's order.[^o4]
