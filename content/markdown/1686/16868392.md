# List of types of functions

::: {#o1 .subject cue=lead name="List of types of functions"}

In [mathematics](wikipedia://en/18831), [functions](wikipedia://en/185427) can be identified according to the properties they have. These properties describe the functions' behaviour under certain conditions.

:::

## Relative to [set theory](wikipedia://en/27553) {#Relative_to_set_theory}

These properties concern the [domain](wikipedia://en/50263), the [codomain](wikipedia://en/50264) and the [image](wikipedia://en/579311) of functions.

::: {#o3 .entry cue=list-entry name="Injective function"}

- [Injective function](wikipedia://en/45196): has a distinct value for each distinct input. Also called an injection or, sometimes, one-to-one function. In other words, every element of the function's codomain is the image of at most one element of its domain.

:::

::: {#o4 .entry cue=list-entry name="Surjective function"}

- [Surjective function](wikipedia://en/27873): has a [preimage](https://en.wikipedia.org/wiki/Preimage) for every element of the [codomain](wikipedia://en/50264), that is, the codomain equals the image. Also called a surjection or [onto function](https://en.wikipedia.org/wiki/Onto_function).

:::

::: {#o5 .entry cue=list-entry name="Bijective function"}

- [Bijective function](https://en.wikipedia.org/wiki/Bijective_function): is both an [injection](wikipedia://en/45196) and a [surjection](https://en.wikipedia.org/wiki/Surjection), and thus [invertible](wikipedia://en/14907).

:::

::: {#o6 .entry cue=list-entry name="Identity function"}

- [Identity function](wikipedia://en/15069): maps any given element to itself.

:::

::: {#o7 .entry cue=list-entry name="Constant function"}

- [Constant function](wikipedia://en/320861): has a fixed value regardless of its input.

:::

::: {#o8 .entry cue=list-entry name="Empty function"}

- [Empty function](https://en.wikipedia.org/wiki/Empty_function): whose domain equals the [empty set](wikipedia://en/9566).

:::

::: {#o9 .entry cue=list-entry name="Set function"}

- [Set function](wikipedia://en/25911217): whose input is a set.

:::

::: {#o10 .entry cue=list-entry name="Set-valued function"}

- [Set-valued function](wikipedia://en/12506030): whose values are sets.

:::

::: {#o11 .entry cue=list-entry name="Choice function"}

- [Choice function](wikipedia://en/1432664) called also [selector](https://en.wikipedia.org/wiki/List_of_selection_theorems) or [uniformizing function](wikipedia://en/2148548): assigns to each set one of its elements.

:::

## Relative to an operator (c.q. a [group](wikipedia://en/41890) or other [structure](wikipedia://en/1809181)) {#Relative_to_an_operator_(c.q._a_group_or_other_structure)}

These properties concern how the function is affected by [arithmetic](wikipedia://en/3118) operations on its argument.

The following are special examples of a [homomorphism](wikipedia://en/13564) on a [binary operation](wikipedia://en/3948):

::: {#o13 .entry cue=list-entry name="Additive function"}

- [Additive function](wikipedia://en/22473529): preserves the addition operation: *f*(*x* + *y*) = *f*(*x*) + *f*(*y*).

:::

::: {#o14 .entry cue=list-entry name="Multiplicative function"}

- [Multiplicative function](wikipedia://en/20059): preserves the multiplication operation: *f*(*xy*) = *f*(*x*)*f*(*y*).

:::

Relative to [negation](wikipedia://en/228312):

::: {#o15 .entry cue=list-entry name="Even function"}

- [Even function](https://en.wikipedia.org/wiki/Even_function): is symmetric with respect to the *Y*-axis. Formally, for each *x*: *f*(*x*) = *f*(−*x*).

:::

::: {#o16 .entry cue=list-entry name="Odd function"}

- [Odd function](https://en.wikipedia.org/wiki/Odd_function): is symmetric with respect to the [origin](wikipedia://en/1313432). Formally, for each *x*: *f*(−*x*) = −*f*(*x*).

:::

Relative to a binary operation and an [order](wikipedia://en/361924):

::: {#o17 .entry cue=list-entry name="Subadditive function"}

- [Subadditive function](https://en.wikipedia.org/wiki/Subadditive_function): for which the value of *f*(*x* + *y*) is less than or equal to *f*(*x*) + *f*(*y*).

:::

::: {#o18 .entry cue=list-entry name="Superadditive function"}

- [Superadditive function](https://en.wikipedia.org/wiki/Superadditive_function): for which the value of *f*(*x* + *y*) is greater than or equal to *f*(*x*) + *f*(*y*).

:::

## Relative to a topology {#Relative_to_a_topology}

::: {#o20 .entry cue=list-entry name="Continuous function"}

- [Continuous function](wikipedia://en/6122): in which [preimages](https://en.wikipedia.org/wiki/Preimage) of [open sets](wikipedia://en/39358) are open.

:::

::: {#o21 .entry cue=list-entry name="Nowhere continuous"}

- [Nowhere continuous](https://en.wikipedia.org/wiki/Nowhere_continuous) function: is not continuous at any point of its domain; for example, the [Dirichlet function](wikipedia://en/630005).

:::

::: {#o22 .entry cue=list-entry name="Locally constant function"}

- [Locally constant function](wikipedia://en/295629): a continuous function into a discrete space.

:::

::: {#o23 .entry cue=list-entry name="Homeomorphism"}

- [Homeomorphism](wikipedia://en/13660): is a bijective function that is also continuous, and whose [inverse](wikipedia://en/14907) is continuous.

:::

::: {#o24 .entry cue=list-entry name="Open function"}

- [Open function](https://en.wikipedia.org/wiki/Open_function): maps open sets to open sets.

:::

::: {#o25 .entry cue=list-entry name="Closed function"}

- [Closed function](https://en.wikipedia.org/wiki/Closed_function): maps [closed sets](wikipedia://en/47279) to closed sets.

:::

::: {#o26 .entry cue=list-entry name="Compactly supported function"}

- [Compactly supported function](wikipedia://en/381013#Compact_support): [vanishes](https://en.wikipedia.org/wiki/Vanish_%28mathematics%29) outside a compact set.

:::

::: {#o27 .entry cue=list-entry name="Càdlàg"}

- [Càdlàg](wikipedia://en/30862839) function, called also RCLL function, corlol function, etc.: right-continuous, with left limits.

:::

::: {#o28 .entry cue=list-entry name="Quasi-continuous function"}

- [Quasi-continuous function](wikipedia://en/931978): roughly, close to *f*(*x*) for some but not all *y* near *x* (rather technical).

:::

Relative to topology and order:

::: {#o29 .entry cue=list-entry name="Semicontinuous function"}

- [Semicontinuous function](https://en.wikipedia.org/wiki/Semicontinuous_function): upper or lower semicontinuous.

:::

::: {#o30 .entry cue=list-entry name="Right-continuous function"}

- [Right-continuous function](wikipedia://en/6122#Directional_and_semi-continuity): no jump when the limit point is approached from the right. Left-continuous function: defined similarly.

:::

::: {#o31 .entry cue=list-entry name="Locally bounded"}

- [Locally bounded](https://en.wikipedia.org/wiki/Locally_bounded) function: bounded around every point.

:::

## Relative to an ordering {#Relative_to_an_ordering}

::: {#o33 .entry cue=list-entry name="Monotonic function"}

- [Monotonic function](wikipedia://en/48260): does not reverse the ordering of any pair of inputs.

:::

::: {#o34 .entry cue=list-entry name="Monotonic function"}

- Strict [monotonic function](wikipedia://en/48260): preserves the given order.

:::

## Relative to the real/complex/hypercomplex/*p*-adic numbers {#Relative_to_the_real/complex/hypercomplex/p-adic_numbers}

::: {#o36 .entry cue=list-entry name="Real function"}

- [Real function](https://en.wikipedia.org/wiki/Real_function): a function whose domain is [real](wikipedia://en/20646438).

:::

::: {#o37 .entry cue=list-entry name="Complex function"}

- [Complex function](https://en.wikipedia.org/wiki/Complex_function): a function whose domain is [complex](wikipedia://en/5826).

:::

::: {#o38 .entry cue=list-entry name="Holomorphic function"}

- [Holomorphic function](wikipedia://en/14110): complex-valued function of a complex variable which is [differentiable](https://en.wikipedia.org/wiki/Differentiable) at every point in its domain.

:::

::: {#o39 .entry cue=list-entry name="Meromorphic function"}

- [Meromorphic function](wikipedia://en/80857): complex-valued function that is holomorphic everywhere, apart from at [isolated points](wikipedia://en/390557) where there are [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29).

:::

::: {#o40 .entry cue=list-entry name="Entire function"}

- [Entire function](wikipedia://en/10372): A holomorphic function whose domain is the entire [complex plane](wikipedia://en/5826).

:::

::: {#o41 .entry cue=list-entry name="Quaternionic function"}

- [Quaternionic function](wikipedia://en/23779912): a function whose domain is [quaternionic](wikipedia://en/51440).

:::

::: {#o42 .entry cue=list-entry name="Hypercomplex function"}

- [Hypercomplex function](wikipedia://en/26666199): a function whose domain is [hypercomplex](wikipedia://en/51438) (e.g. quaternions, [octonions](wikipedia://en/51436), [sedenions](wikipedia://en/51434), [trigintaduonions](wikipedia://en/25474499) etc.)

:::

::: {#o43 .entry cue=list-entry name="p-adic function"}

- [*p*-adic function](wikipedia://en/291327): a function whose domain is [*p*-adic](wikipedia://en/51423).

:::

::: {#o44 .entry cue=list-entry name="Convex function"}

- [Convex function](wikipedia://en/245568): line segment between any two points on the [graph](wikipedia://en/87352) lies above the graph. Also [concave function](wikipedia://en/263321).

:::

::: {#o45 .entry cue=list-entry name="Arithmetic function"}

- [Arithmetic function](wikipedia://en/3170): A function from the positive [integers](wikipedia://en/14563) into the complex numbers.

:::

::: {#o46 .entry cue=list-entry name="Analytic function"}

- [Analytic function](wikipedia://en/61478): Can be defined locally by a [convergent](wikipedia://en/1743431) [power series](wikipedia://en/59958).

:::

::: {#o47 .entry cue=list-entry name="Quasi-analytic function"}

- [Quasi-analytic function](wikipedia://en/22385007): not analytic, but still locally determined by its derivatives at a point.

:::

::: {#o48 .entry cue=list-entry name="Differentiable function"}

- [Differentiable function](wikipedia://en/330206): Has a [derivative](wikipedia://en/7921).

:::

::: {#o49 .entry cue=list-entry name="Continuously differentiable function"}

- [Continuously differentiable function](https://en.wikipedia.org/wiki/Continuously_differentiable_function): differentiable, with continuous derivative.

:::

::: {#o50 .entry cue=list-entry name="Smooth function"}

- [Smooth function](https://en.wikipedia.org/wiki/Smooth_function): Has derivatives of all orders.

:::

::: {#o51 .entry cue=list-entry name="Lipschitz function"}

- [Lipschitz function](https://en.wikipedia.org/wiki/Lipschitz_function), [Holder function](https://en.wikipedia.org/wiki/Holder_function): somewhat more than [uniformly continuous function](https://en.wikipedia.org/wiki/Uniformly_continuous_function).

:::

::: {#o52 .entry cue=list-entry name="Harmonic function"}

- [Harmonic function](wikipedia://en/55762): its value at the center of a [ball](wikipedia://en/160556) is equal to the average value on the surface of the ball [(mean value property)](wikipedia://en/55762#The_mean_value_property). Also [subharmonic function](wikipedia://en/3237359) and [superharmonic function](https://en.wikipedia.org/wiki/Superharmonic_function).

:::

::: {#o53 .entry cue=list-entry name="Elementary function"}

- [Elementary function](wikipedia://en/10412): [composition](wikipedia://en/195947) of arithmetic operations, [exponentials](wikipedia://en/9678), [logarithms](wikipedia://en/17860), constants, and solutions of [algebraic equations](wikipedia://en/404001).

:::

::: {#o54 .entry cue=list-entry name="Special functions"}

- [Special functions](wikipedia://en/23709110): non-elementary functions that have established names and notations due to their importance.

:::

  - [List of eponyms of special functions](wikipedia://en/3036515)

::: {#o55 .entry cue=list-entry name="Trigonometric functions"}

- [Trigonometric functions](wikipedia://en/30367): relate the angles of a [triangle](wikipedia://en/30654) to the lengths of its sides.

:::

::: {#o56 .entry cue=list-entry name="Nowhere differentiable function"}

- [Nowhere differentiable function](https://en.wikipedia.org/wiki/Nowhere_differentiable_function) called also [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function): continuous everywhere but not differentiable even at a single point.

:::

::: {#o57 .entry cue=list-entry name="Fast-growing"}

- [Fast-growing](wikipedia://en/24947285) (or rapidly increasing) function; in particular, [Ackermann function](wikipedia://en/2925).

:::

::: {#o58 .entry cue=list-entry name="Simple function"}

- [Simple function](wikipedia://en/1890594): a real-valued function over a [subset](wikipedia://en/27631) of the real line, similar to a [step function](wikipedia://en/170939).

:::

## Relative to measurability {#Relative_to_measurability}

::: {#o60 .entry cue=list-entry name="Measurable function"}

- [Measurable function](wikipedia://en/44055): the preimage of each [measurable set](https://en.wikipedia.org/wiki/Measurable_set) is measurable.

:::

::: {#o61 .entry cue=list-entry name="Borel function"}

- [Borel function](https://en.wikipedia.org/wiki/Borel_function): the preimage of each [Borel set](wikipedia://en/43327) is a Borel set.

:::

::: {#o62 .entry cue=list-entry name="Baire function"}

- [Baire function](wikipedia://en/3575729) called also [Baire measurable function](https://en.wikipedia.org/wiki/Baire_measurable_function): obtained from continuous functions by transfinite iteration of the operation of forming pointwise limits of [sequences](wikipedia://en/27838) of functions.

:::

::: {#o63 .entry cue=list-entry name="Singular function"}

- [Singular function](wikipedia://en/51453): continuous, with zero derivative [almost everywhere](wikipedia://en/44688), but non-constant.

:::

  - [Quartic function](wikipedia://en/308152)
  - [Quintic function](https://en.wikipedia.org/wiki/Quintic_function)

::: {#o70 .entry cue=list-entry name="Rational function"}

:::

::: {#o71 .entry cue=list-entry name="Algebraic function"}

- [Algebraic function](wikipedia://en/974169): defined as the [root](https://en.wikipedia.org/wiki/Root_of_a_polynomial) of a polynomial equation.

:::

::: {#o72 .entry cue=list-entry name="Transcendental function"}

- [Transcendental function](wikipedia://en/297021): analytic but not algebraic. Also [hypertranscendental function](wikipedia://en/11017352).

:::

::: {#o73 .entry cue=list-entry name="Composite function"}

- [Composite function](https://en.wikipedia.org/wiki/Composite_function): is formed by the composition of two functions *f* and *g*, by mapping *x* to *f*(*g*(*x*)).

:::

::: {#o74 .entry cue=list-entry name="Inverse function"}

- [Inverse function](wikipedia://en/14907): is declared by "doing the reverse" of a given function (e.g. [arcsine](https://en.wikipedia.org/wiki/Arcsine) is the inverse of [sine](https://en.wikipedia.org/wiki/Sine)).

:::

::: {#o75 .entry cue=list-entry name="Implicit function"}

- [Implicit function](wikipedia://en/250896): defined implicitly by a relation between the argument(s) and the value.

:::

::: {#o76 .entry cue=list-entry name="Piecewise function"}

- [Piecewise function](wikipedia://en/404130): is defined by different expressions on different intervals.

:::

::: {#o77 .entry cue=list-entry name="Computable function"}

- [Computable function](wikipedia://en/1139338): an algorithm can do the job of the function. Also [semicomputable function](wikipedia://en/22032894); [primitive recursive function](wikipedia://en/24829); [partial recursive function](https://en.wikipedia.org/wiki/Partial_recursive_function).

:::

In general, functions are often defined by specifying the name of a dependent variable, and a way of calculating what it should map to. For this purpose, the $\mapsto$ symbol or [Church](wikipedia://en/49731)'s [$\lambda$](wikipedia://en/18203) is often used. Also, sometimes mathematicians notate a function's [domain](wikipedia://en/50263) and [codomain](wikipedia://en/50264) by writing e.g. $f:A\rightarrow B$. These notions extend directly to [lambda calculus](wikipedia://en/18203) and [type theory](wikipedia://en/40282), respectively.

## Relation to category theory {#Relation_to_category_theory}

[Category theory](wikipedia://en/5869) is a branch of mathematics that formalizes the notion of a special function via arrows or [morphisms](wikipedia://en/27716891). A [category](wikipedia://en/53759) is an algebraic object that (abstractly) consists of a class of *objects*, and for every pair of objects, a set of *morphisms*. A partial (equiv. [dependently typed](https://en.wikipedia.org/wiki/Dependently_typed)) binary operation called [composition](wikipedia://en/195947) is provided on morphisms, every object has one special morphism from it to itself called the [identity](https://en.wikipedia.org/wiki/Identity_morphism) on that object, and composition and identities are required to obey certain relations.

In a so-called [concrete category](wikipedia://en/167001), the objects are associated with mathematical structures like [sets](wikipedia://en/26691), [magmas](wikipedia://en/141916), [groups](wikipedia://en/19447), [rings](wikipedia://en/48404), [topological spaces](wikipedia://en/30450), [vector spaces](wikipedia://en/32370), [metric spaces](wikipedia://en/20018), [partial orders](wikipedia://en/361924), [differentiable manifolds](wikipedia://en/2119219), [uniform spaces](wikipedia://en/32339), etc., and morphisms between two objects are associated with *structure-preserving functions* between them. In the examples above, these would be [functions](wikipedia://en/185427), magma [homomorphisms](wikipedia://en/13564), [group homomorphisms](wikipedia://en/12396), [ring homomorphisms](wikipedia://en/26411), [continuous functions](wikipedia://en/6122), [linear transformations](https://en.wikipedia.org/wiki/Linear_transformation) (or [matrices](wikipedia://en/20556859)), [metric maps](wikipedia://en/469760), [monotonic functions](wikipedia://en/48260), [differentiable functions](wikipedia://en/330206), and [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous) functions, respectively.

As an algebraic theory, one of the advantages of category theory is to enable one to prove many general results with a minimum of assumptions. Many common notions from mathematics (e.g. [surjective](https://en.wikipedia.org/wiki/Surjective), [injective](https://en.wikipedia.org/wiki/Injective), [free object](wikipedia://en/333835), [basis](wikipedia://en/18420), finite [representation](wikipedia://en/12695), [isomorphism](wikipedia://en/14828)) are definable purely in category theoretic terms (cf. [monomorphism](wikipedia://en/59538), [epimorphism](wikipedia://en/59539)).

Category theory has been suggested as a foundation for mathematics on par with [set theory](wikipedia://en/27553) and [type theory](wikipedia://en/40282) (cf. [topos](wikipedia://en/21391464)).

[Allegory theory](https://en.wikipedia.org/wiki/Allegory_%28category_theory%29)[^o85] provides a generalization comparable to category theory for [relations](wikipedia://en/22517558) instead of functions.
