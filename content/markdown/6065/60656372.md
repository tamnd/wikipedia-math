# Deletion–contraction formula

::: {#o1 .subject cue=lead name="Deletion–contraction formula"}

In [graph theory](wikipedia://en/12401), a **deletion-contraction formula / recursion** is any formula of the following [recursive](wikipedia://en/146806) form:

:::

$$f(G) = f(G \setminus e) + f(G / e).$$

Here *G* is a [graph](wikipedia://en/325806), *f* is a function on graphs, *e* is any edge of *G*, *G* \\ *e* denotes edge deletion, and *G* / *e* denotes [contraction](wikipedia://en/3758115). Tutte refers to such a function as a **W-function**.[^o2] The formula is sometimes referred to as the **fundamental reduction theorem**.[^o3] In this article we abbreviate to **DC**.

[R. M. Foster](https://en.wikipedia.org/wiki/R._M._Foster) had already observed that the [chromatic polynomial](wikipedia://en/1460126) is one such function, and Tutte began to discover more, including a function *f* = *t*(*G*) counting the number of [spanning trees](wikipedia://en/455770) of a graph (also see [Kirchhoff's theorem](wikipedia://en/1270691)). It was later found that the [flow polynomial](https://en.wikipedia.org/wiki/Flow_polynomial) is yet another; and soon Tutte discovered an entire class of functions called [Tutte polynomials](wikipedia://en/3892303) (originally referred to as **dichromates**) that satisfy DC.[^o2]

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

### Spanning trees {#Spanning_trees}

The number of spanning trees $t(G)$ satisfies DC.[^o7]

::: {#o8 .proof cue=inline-head name="Proof"}

**Proof.** $t(G \setminus e)$ denotes the number of spanning trees not including *e*, whereas $t(G/e)$ the number including *e*. To see the second, if *T* is a spanning tree of *G* then contracting *e* produces another spanning tree of $G/e$. Conversely, if we have a spanning tree *T* of $G/e$, then expanding the edge *e* gives two disconnected trees; adding *e* connects the two and gives a spanning tree of *G*.

:::

### Laplacian characteristic polynomials {#Laplacian_characteristic_polynomials}

By Kirchhoff's theorem, the number of spanning trees in a graph is counted by a cofactor of the [Laplacian matrix](wikipedia://en/1448472). However, the Laplacian [characteristic polynomial](wikipedia://en/218268) does not satisfy DC. By studying Laplacians with vertex weights, one can find a deletion-contraction relation between the scaled vertex-weighted Laplacian characteristic polynomials.[^o10]

### Chromatic polynomials {#Chromatic_polynomials}

The chromatic polynomial $\chi_G(k)$ counting the number of *k*-colorings of *G* does not satisfy DC, but a slightly modified formula (which can be made equivalent):[^o2]

$$\chi_G(k) = \chi_{G - e}(k) - \chi_{G / e}(k).$$

::: {#o12 .proof cue=inline-head name="Proof"}

**Proof.** If *e* = *uv*, then a *k*-coloring of *G* is the same as a *k*-coloring of *G* \\ *e* where *u* and *v* have different colors. There are $\chi_{G\setminus e}(k)$ total *G* \\ *e* colorings. We need now subtract the ones where *u* and *v* are colored the same. But such colorings correspond to the *k*-colorings of $\chi_{G/e}(k)$ where *u* and *v* are merged.

This above property can be used to show that the chromatic polynomial $\chi_G(k)$ is indeed a [polynomial](wikipedia://en/23000) in *k*. We can do this via [induction](wikipedia://en/18881) on the number of edges and noting that in the base case where there are no edges, there are $k^{|V(G)|}$ possible colorings (which is a polynomial in *k*).

:::
