# Barnette's conjecture

::: {#o1 .subject cue=lead name="Barnette's conjecture"}

*Image: Barnette's conjecture.svg.* The left and right are the same graph, displayed in different ways. The graph is [planar](wikipedia://en/24314), because it can be arranged so that no edges overlap, and is [bipartite](wikipedia://en/244431), because the vertices can be colored so that there is no edge connecting 2 vertices of the same color (red and blue here). It is also [cubic](wikipedia://en/980508), because every vertex has 3 edges connected to it (every vertex has [degree](wikipedia://en/1374448) 3), and [polyhedral](wikipedia://en/24656270), because the graph stays [connected](wikipedia://en/1614492) when removing any 2 points (also known as [3-vertex-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph)). The conjecture states that every graph which meets all these criteria is also [Hamiltonian](https://en.wikipedia.org/wiki/Hamiltonian_cycle), meaning there is a [cycle](wikipedia://en/168609) that goes through all vertices of the graph (one such is drawn green here).

::: {#o2 .problem cue=unsolved}

Is every cubic bipartite polyhedral graph Hamiltonian?

:::

**Barnette's conjecture** is an [unsolved problem](wikipedia://en/6138) in [graph theory](wikipedia://en/12401), a branch of [mathematics](wikipedia://en/18831), concerning [Hamiltonian cycles](https://en.wikipedia.org/wiki/Hamiltonian_cycle) in graphs. It is named after [David W. Barnette](https://en.wikipedia.org/wiki/David_W._Barnette), a [professor emeritus](https://en.wikipedia.org/wiki/Professor_emeritus) at the [University of California, Davis](https://en.wikipedia.org/wiki/University_of_California,_Davis); it states that every [bipartite](wikipedia://en/244431) [polyhedral graph](wikipedia://en/24656270) with [three edges per vertex](wikipedia://en/980508) has a Hamiltonian cycle.

:::

## Definitions {#Definitions}

A [planar graph](wikipedia://en/24314) is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) that can be [embedded](wikipedia://en/8149170) into the [Euclidean plane](wikipedia://en/15575410) without any [crossings](wikipedia://en/18298594). A planar graph is called [polyhedral](wikipedia://en/24656270) if and only if it is [3-vertex-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph), that is, if there do not exist two vertices the removal of which would disconnect the rest of the graph. A graph is [bipartite](wikipedia://en/244431) if its vertices can be [colored](wikipedia://en/426743) with two different colors such that each edge has one endpoint of each color. A graph is [cubic](wikipedia://en/980508) (or [3-regular](wikipedia://en/85821)) if each vertex is the endpoint of exactly three edges. Finally, a graph is [Hamiltonian](https://en.wikipedia.org/wiki/Hamiltonian_cycle) if there exists a cycle that passes through each of its vertices exactly once. Barnette's conjecture states that every cubic bipartite polyhedral graph is Hamiltonian.

By [Steinitz's theorem](wikipedia://en/19762817), a planar graph represents the edges and vertices of a [convex polyhedron](https://en.wikipedia.org/wiki/Convex_polyhedron) if and only if it is polyhedral. A three-dimensional polyhedron has a cubic graph if and only if it is a [simple polyhedron](https://en.wikipedia.org/wiki/Simple_polyhedron). And, a planar graph is bipartite if and only if, in a planar embedding of the graph, all face cycles have even length. Therefore, Barnette's conjecture may be stated in an equivalent form: suppose that a three-dimensional simple [convex polyhedron](https://en.wikipedia.org/wiki/Convex_polyhedron) has an even number of edges on each of its faces. Then, according to the conjecture, the graph of the polyhedron has a Hamiltonian cycle.

## History {#History}

(txt) conjectured that every cubic polyhedral graph is Hamiltonian; this came to be known as [Tait's conjecture](wikipedia://en/52435). It was disproven by (txt), who constructed a [counterexample](wikipedia://en/143151) with 46 vertices; other researchers later found even smaller counterexamples. However, none of these known counterexamples is bipartite. Tutte himself conjectured that every cubic 3-connected bipartite graph is Hamiltonian, but this was shown to be false by the discovery of a counterexample, the [Horton graph](wikipedia://en/24116567).[^o8] (txt) proposed a weakened combination of Tait's and Tutte's conjectures, stating that every bipartite cubic polyhedron is Hamiltonian, or, equivalently, that every counterexample to Tait's conjecture is non-bipartite.[^n1]

## Equivalent forms {#Equivalent_forms}

(Kelmans 1994) showed that Barnette's conjecture is equivalent to a superficially stronger statement, that for every two edges *e* and *f* on the same face of a bipartite cubic polyhedron, there exists a Hamiltonian cycle that contains *e* but does not contain *f*. Clearly, if this statement is true, then every bipartite cubic polyhedron contains a Hamiltonian cycle: just choose *e* and *f* arbitrarily. In the other directions, Kelmans showed that a counterexample could be transformed into a counterexample to the original Barnette conjecture.[^o13]

Barnette's conjecture is also equivalent to the statement that the vertices of the dual of every cubic bipartite polyhedral graph can be partitioned into two subsets whose [induced subgraphs](wikipedia://en/1655188) are trees. The cut induced by such a partition in the dual graph corresponds to a Hamiltonian cycle in the primal graph.[^n2]

## Partial results {#Partial_results}

Although the truth of Barnette's conjecture remains unknown, computational experiments have shown that there is no counterexample with fewer than 86 vertices.[^o16]

If Barnette's conjecture turns out to be false, then it can be shown to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete) to test whether a bipartite cubic polyhedron is Hamiltonian.[^o17] If a planar graph is bipartite and cubic but only of connectivity 2, then it may be non-Hamiltonian, and it is NP-complete to test Hamiltonicity for these graphs.[^o18] Another result was obtained by (Alt Payne Schmidt Wood 2016): if the dual graph can be vertex-colored with colors blue, red and green such that every red-green cycle contains a vertex of degree 4, then the primal graph is Hamiltonian.

## Related problems {#Related_problems}

A related conjecture of Barnette states that every cubic polyhedral graph in which all faces have six or fewer edges is Hamiltonian. Computational experiments have shown that, if a counterexample exists, it would have to have more than 177 vertices.[^o21] The conjecture was proven by (Kardoš 2020).[^n3]

The intersection of these two conjectures would be that every bipartite cubic polyhedral graph in which all faces have four or six edges is Hamiltonian. This was proved to be true by (Goodey 1975).[^n4]
