# Meertens number

::: {#o1 .subject cue=lead name="Meertens number"}

In [number theory](wikipedia://en/21527) and [mathematical logic](wikipedia://en/19636), a **Meertens number** in a given [number base](https://en.wikipedia.org/wiki/Number_base) $b$ is a [natural number](wikipedia://en/21474) that is its own [Gödel number](wikipedia://en/207790). It was named after [Lambert Meertens](https://en.wikipedia.org/wiki/Lambert_Meertens) by [Richard S. Bird](https://en.wikipedia.org/wiki/Richard_S._Bird) as a present during the celebration of his 25 years at the [CWI](wikipedia://en/506063), [Amsterdam](https://en.wikipedia.org/wiki/Amsterdam).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $n$ be a natural number. We define the **Meertens function** for base $b > 1$ $F_{b} : \mathbb{N} \rightarrow \mathbb{N}$ to be the following:

$$F_{b}(n) = \prod_{i=0}^{k - 1} p_{k - i - 1}^{d_i}.$$

where $k = \lfloor \log_{b}{n} \rfloor + 1$ is the number of digits in the number in base $b$, $p_i$ is the $i$-th [prime number](wikipedia://en/23666) (starting at 0), and

$$d_i = \frac{n \bmod{b^{i+1}} - n \bmod b^i}{b^i}$$

is the value of each digit of the number. A natural number $n$ is a **Meertens number** if it is a [fixed point](wikipedia://en/449738) for $F_{b}$, which occurs if $F_{b}(n) = n$. This corresponds to a [Gödel encoding](https://en.wikipedia.org/wiki/Gödel_encoding).

For example, the number 3020 in base $b = 4$ is a Meertens number, because

$$3020 = 2^{3}3^{0}5^{2}7^{0}.$$

A natural number $n$ is a **sociable Meertens number** if it is a [periodic point](wikipedia://en/4941621) for $F_{b}$, where $F_{b}^k(n) = n$ for a positive integer $k$, and forms a [cycle](wikipedia://en/810250) of period $k$. A Meertens number is a sociable Meertens number with $k = 1$, and a [amicable](wikipedia://en/3259) **Meertens number** is a sociable Meertens number with $k = 2$.

The number of iterations $i$ needed for $F_{b}^{i}(n)$ to reach a fixed point is the Meertens function's [persistence](wikipedia://en/624708) of $n$, and undefined if it never reaches a fixed point.

:::
