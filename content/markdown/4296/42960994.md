# Graph coloring game

*Image: Graph coloring game.gif.* The **vertex coloring game** on a given graph between Alice and Bob. Here, vertices labeled "A" are colored by Alice, and "B" by Bob. The players take turns (starting with Alice) [coloring properly](wikipedia://en/426743#Vertex_coloring) vertices of the graph. If the graph is fully colored properly at the end, Alice wins. If at any point there is a vertex that becomes impossible to properly color, Bob wins. The **game chromatic number** $\chi_g(G)$ is the minimum number of colors needed for Alice to win the vertex coloring game on $G$. For this graph, $\chi_g(G)=3$, as it is the [Cartesian product](wikipedia://en/2856852) $S_5 \square P_2$[^o1]

::: {#o2 .problem cue=unsolved}

Suppose Alice has a winning strategy for the vertex coloring game on a graph *G* with *k* colors. Does she have one for *k+1* colors?

:::

::: {#o3 .subject cue=lead name="Graph coloring game"}

The **graph coloring game** is a mathematical game related to [graph theory](wikipedia://en/12401). **Coloring game problems** arose as game-theoretic versions of well-known [graph coloring](wikipedia://en/426743) problems. In a coloring game, two players use a given set of colors to construct a coloring of a [graph](wikipedia://en/325806), following specific rules depending on the game we consider. One player tries to successfully complete the coloring of the graph, while the other one tries to prevent him from achieving it.

:::

## Vertex coloring game {#Vertex_coloring_game}

The **vertex coloring game** was introduced in 1981 by [Steven Brams](https://en.wikipedia.org/wiki/Steven_Brams) as a [map-coloring game](https://en.wikipedia.org/wiki/Map-coloring_game)[^o5][^o6] and rediscovered ten years after by Bodlaender.[^o7] Its rules are as follows:

1. [Alice and Bob](wikipedia://en/679079) color the vertices of a graph *G* with a set *k* of colors.
1. Alice and Bob take turns, [coloring properly](wikipedia://en/426743#Vertex_coloring) an uncolored vertex (in the standard version, Alice begins).
1. If a vertex *v* is impossible to color properly (for any color, *v* has a neighbor colored with it), then Bob wins.
1. If the graph is completely colored, then Alice wins.

The **game chromatic number** of a graph $G$, denoted by $\chi_g(G)$, is the minimum number of colors needed for Alice to win the vertex coloring game on $G$. Trivially, for every graph $G$, we have $\chi(G) \le \chi_g(G) \le \Delta(G) + 1$, where $\chi(G)$ is the [chromatic number](wikipedia://en/426743#Vertex_coloring) of $G$ and $\Delta(G)$ its maximum [degree](wikipedia://en/1374448).[^o8]

In the 1991 Bodlaender's paper,[^o9] the computational complexity was left as "*an interesting open problem*". Only in 2020 it was proved that the game is [PSPACE-Complete](wikipedia://en/54685).[^o10]

### Relation with other notions {#Relation_with_other_notions}

**Acyclic coloring.** Every graph $G$ with [acyclic chromatic number](wikipedia://en/690769) $k$ has $\chi_g(G) \le k(k+1)$.[^o12]

**Marking game.** For every graph $G$, $\chi_g(G) \le col_g(G)$, where $col_g(G)$ is the [game coloring number](https://en.wikipedia.org/wiki/Marking_game) of $G$. Almost every known upper bound for the game chromatic number of graphs are obtained from bounds on the game coloring number.

**Cycle-restrictions on edges.** If every edge of a graph $G$ belongs to at most $c$ cycles, then $\chi_g(G) \le 4+c$.[^o13]

### Graph Classes {#Graph_Classes}

For a class ${\mathcal C}$ of graphs, we denote by $\chi_g({\mathcal C})$ the smallest integer $k$ such that every graph $G$ of ${\mathcal C}$ has $\chi_g(G) \le k$. In other words, $\chi_g({\mathcal C})$ is the exact upper bound for the game chromatic number of graphs in this class. This value is known for several standard graph classes, and bounded for some others:

- [Forests](wikipedia://en/48560): $\chi_g({\mathcal F}) = 4$.[^o15] Simple criteria are known to determine the game chromatic number of a forest without vertex of degree 3.[^o16] It seems difficult to determine the game chromatic number of forests with vertices of degree 3, even for forests with maximum degree 3.
- [Cactuses](wikipedia://en/9944209): $\chi_g({\mathcal C}) = 5$.[^o17]
- [Outerplanar graphs](wikipedia://en/352343): $6 \le \chi_g({\mathcal O}) \le 7$.[^o18]
- [Planar graphs](wikipedia://en/24314): $7 \le \chi_g({\mathcal P}) \le 17$.[^o19]
- [Planar graphs](wikipedia://en/24314) of given [girth](wikipedia://en/12013): $\chi_g({\mathcal P}_4) \le 13$,[^o20] $\chi_g({\mathcal P}_5) \le 8$, $\chi_g({\mathcal P}_6) \le 6$, $\chi_g({\mathcal P}_8) \le 5$.[^o21]
- [Toroidal grids](https://en.wikipedia.org/wiki/Toroidal_grid): $\chi_g({\mathcal TG}) = 5$.[^o22]
- [Partial *k*-trees](wikipedia://en/31104438): $\chi_g({\mathcal T}_k) \le 3k+2$.[^o23]
- [Interval graphs](wikipedia://en/363423): $2\omega \le \chi_g({\mathcal I}) \le 3\omega-2$, where $\omega$ is for a graph the size of its largest [clique](wikipedia://en/524466).[^o24]

**Cartesian products.** The game chromatic number of the [cartesian product](wikipedia://en/2856852) $G \square H$ is not bounded by a function of $\chi_g(G)$ and $\chi_g(H)$. In particular, the game chromatic number of any complete bipartite graph $K_{n,n}$ is equal to 3, but there is no upper bound for $\chi_g(K_{n,n} \square K_{m,m})$ for arbitrary $n, m$.[^o25] On the other hand, the game chromatic number of $G \square H$ is bounded above by a function of $\textrm{col}_g(G)$ and $\textrm{col}_g(H)$. In particular, if $\textrm{col}_g(G)$ and $\textrm{col}_g(H)$ are both at most $t$, then $\chi_g(G \square H) \le t^5 - t^3 + t^2$.[^o26]

- For a single edge we have:[^o25]

$$\begin{aligned} \chi_g(K_2 \square P_k) &= \begin{cases} 2 & k = 1 \\ 3 & k=2,3 \\ 4 & k \ge 4 \end{cases} \\ \chi_g(K_2 \square C_k) &= 4 && k \ge 3 \\ \chi_g(K_2 \square K_k) &= k+1 \end{aligned}$$

- For [stars](wikipedia://en/19310129) we have:[^o1]

$$\begin{aligned} \chi_g(S_m \square P_k) &= \begin{cases} 2 & k = 1 \\ 3 & k=2 \\ 4 & k \ge 3 \end{cases} \\ \chi_g(S_m \square C_k) &= 4 && k \ge 3 \end{aligned}$$

- [Trees](wikipedia://en/48560): $\chi_g(T_1 \square T_2) \le 12.$
- [Wheels](wikipedia://en/1655876): $\chi_g(P_2 \square W_n) = 5$ if $n \ge 9.$[^o1]
- [Complete bipartite graphs](wikipedia://en/525320): $\chi_g(P_2 \square K_{m,n}) = 5$ if $m, n \ge 5.$[^o1]

::: {#o28 .statement kind=statement/conjecture cue=heading name="Open problems"}

### Open problems {#Open_problems}

These questions are still open to this date.

#### More colors for Alice {#More_colors_for_Alice}

- Suppose Alice has a winning strategy for the vertex coloring game on a graph *G* with *k* colors. Does she have one for *k+1* colors ? *One would expect the answers to be "yes", as having more colors seems an advantage to Alice. However, no proof exists that this statement is true.*[^o30]
- Is there a function *f* such that, if Alice has a winning strategy for the vertex coloring game on a graph *G* with *k* colors, then Alice has a winning strategy on *G* with *f(k)* ? *Relaxation of the previous question.*

#### Relations with other notions {#Relations_with_other_notions}

- Suppose a monotone class of graphs (i.e. a class of graphs closed by subgraphs) has bounded *game chromatic number*. Is it true that this class of graph has bounded *[game coloring number](https://en.wikipedia.org/wiki/Marking_game)* ? [^o30]
- Suppose a monotone class of graphs (i.e. a class of graphs closed by subgraphs) has bounded *game chromatic number*. Is it true that this class of graph has bounded *[arboricity](wikipedia://en/2476311)* ?
- Is it true that a monotone class of graphs of bounded *game chromatic number* has bounded *[acyclic chromatic number](wikipedia://en/690769)* ?

#### Reducing maximum degree {#Reducing_maximum_degree}

- **Conjecture:** Is $F$ is a forest, there exists $F' \subseteq F$ such that $\Delta(F') \le \chi_g(F)$ and $\chi_g(F') = \chi_g(F)$. [^o16]
- Let ${\mathcal G}$ be the class of graphs such that for any $G \in {\mathcal G}$, there exists $G' \subseteq G$ such that $\Delta(G') \le \chi_g(G)$ and $\chi_g(G') = \chi_g(G)$. What families of graphs are in ${\mathcal G}$ ?

#### Hypercubes {#Hypercubes}

- Is it true that $\chi_g(G) = n+1$ for any hypercube $Q_n$ ? *It is known to be true for $n \le 4$.*[^o25]

:::

## Edge coloring game {#Edge_coloring_game}

The **edge coloring game**, introduced by Lam, Shiu and Zu,[^o35] is similar to the vertex coloring game, except Alice and Bob construct a proper [edge coloring](wikipedia://en/690647) instead of a proper vertex coloring. Its rules are as follows:

1. Alice and Bob are coloring the edges a graph *G* with a set *k* of colors.
1. Alice and Bob are taking turns, [coloring properly](wikipedia://en/690647) an uncolored edge (in the standard version, Alice begins).
1. If an edge *e* is impossible to color properly (for any color, *e* is adjacent to an edge colored with it), then Bob wins.
1. If the graph is completely edge-colored, then Alice wins.

Although this game can be considered as a particular case of the **vertex coloring game** on [line graphs](wikipedia://en/675231), it is mainly considered in the scientific literature as a distinct game. The **game chromatic index** of a graph $G$, denoted by $\chi'_g(G)$, is the minimum number of colors needed for Alice to win this game on $G$.

### General case {#General_case}

For every graph *G*, $\chi'(G) \le \chi'_g(G) \le 2\Delta(G) -1$. There are graphs reaching these bounds but all the graphs we know reaching this upper bound have small maximum degree.[^o35] There exists graphs with $\chi'_g(G) > 1.008\Delta(G)$ for arbitrary large values of $\Delta(G)$.[^o37]

::: {#o38 .statement kind=statement/conjecture cue=inline-head name="Conjecture"}

**Conjecture.** *There is an $\epsilon > 0$ such that, for any arbitrary graph $G$, we have $\chi'_g(G) \le (2-\epsilon)\Delta(G)$.* This conjecture is true when $\Delta(G)$ is large enough compared to the number of vertices in $G$.[^o37]

- **Arboricity.** Let $a(G)$ be the [arboricity](wikipedia://en/2476311) of a graph $G$. Every graph $G$ with maximum [degree](wikipedia://en/1374448) $\Delta(G)$ has $\chi'_g(G) \le \Delta(G) + 3a(G) - 1$.[^o39]

:::

### Graph Classes {#Graph_Classes}

For a class ${\mathcal C}$ of graphs, we denote by $\chi'_g({\mathcal C})$ the smallest integer $k$ such that every graph $G$ of ${\mathcal C}$ has $\chi'_g(G) \le k$. In other words, $\chi'_g({\mathcal C})$ is the exact upper bound for the game chromatic index of graphs in this class. This value is known for several standard graph classes, and bounded for some others:

- [Wheels](wikipedia://en/1655876): $\chi'_g(W_3) = 5$ and $\chi'_g(W_n) = n+1$ when $n\ge4$.[^o35]
- [Forests](wikipedia://en/48560) : $\chi'_g({\mathcal F}_\Delta) \le \Delta + 1$ when $\Delta \ne 4$, and $5 \le \chi'_g({\mathcal F}_4) \le 6$.[^o41] Moreover, if every tree of a forest $F$ of ${\mathcal F}_4$ is obtained by subdivision from a [caterpillar tree](wikipedia://en/27258886) or contains no two adjacent vertices with degree 4, then $\chi'_g(F) \le 5$.[^o42]

::: {#o44 .statement kind=statement/conjecture cue=heading name="Open Problems"}

### Open Problems {#Open_Problems}

**Upper bound.** Is there a constant $c \ge 2$ such that $\chi'_g(G) \le \Delta(G) + c$ for each graph $G$ ? If it is true, is $c = 2$ enough ?[^o35]

::: {#o45 .statement kind=statement/conjecture cue=inline-head name="Conjecture on large minimum degrees"}

**Conjecture on large minimum degrees.** *There are a $\epsilon > 0$ and an integer $d_0$ such that any graph $G$ with $\delta(G) \ge d_0$ satisfies $\chi'_g(G) \ge (1+\epsilon)\delta(G)$.* [^o37]

:::

:::

## Incidence coloring game {#Incidence_coloring_game}

The **incidence coloring game** is a graph coloring game, introduced by Andres,[^o47] and similar to the vertex coloring game, except Alice and Bob construct a proper [incidence coloring](wikipedia://en/47290509) instead of a proper vertex coloring. Its rules are as follows:

1. Alice and Bob are coloring the [incidences](https://en.wikipedia.org/wiki/Incidence_%28graph%29) of a graph *G* with a set *k* of colors.
1. Alice and Bob are taking turns, coloring properly an uncolored incidence (in the standard version, Alice begins).
1. If an [incidence](https://en.wikipedia.org/wiki/Incidence_%28graph%29) *i* is impossible to color properly (for any color, *i* is adjacent to an incident colored with it), then Bob wins.
1. If all the incidences are properly colored, then Alice wins.

The **incidence game chromatic number** of a graph $G$, denoted by $i_g(G)$, is the minimum number of colors needed for Alice to win this game on $G$.

For every graph $G$ with maximum degree $\Delta$, we have $\frac{3\Delta - 1}{2} < i_g(G) < 3\Delta - 1$.[^o47]

### Relations with other notions {#Relations_with_other_notions}

- **[*(a,d)*-Decomposition](https://en.wikipedia.org/wiki/%28a,b%29-decomposability).** This is the best upper bound we know for the general case. If the edges of a graph $G$ can be partitioned into two sets, one of them inducing a graph with [arboricity](wikipedia://en/2476311) $a$, the second inducing a graph with maximum degree $d$, then $i_g(G) \le \left\lfloor \frac{3\Delta(G) - a}{2} \right\rfloor + 8a + 3d - 1$.[^o49] If moreover $\Delta(G) \ge 5a + 6d$, then $i_g(G) \le \left\lfloor \frac{3\Delta(G) - a}{2} \right\rfloor + 8a + d - 1$.[^o49]
- **Degeneracy.** If $G$ is a [*k*-degenerated graph](wikipedia://en/27545816) with maximum [degree](wikipedia://en/1374448) $\Delta(G)$, then $i_g(G) \le 2\Delta(G) + 4k - 2$. Moreover, $i_g(G) \le 2\Delta(G) + 3k - 1$ when $\Delta(G) \ge 5k - 1$ and $i_g(G) \le \Delta(G) + 8k - 2$ when $\Delta(G) \le 5k -1$.[^o47]

### Graph Classes {#Graph_Classes}

For a class ${\mathcal C}$ of graphs, we denote by $i_g({\mathcal C})$ the smallest integer $k$ such that every graph $G$ of ${\mathcal C}$ has $i_g(G) \le k$.

- [Paths](wikipedia://en/4587190) : For $k \ge 13$, $i_g(P_k) = 5$.
- [Cycles](wikipedia://en/878962) : For $k \ge 3$, $i_g(C_k) = 5$.[^o51]
- [Stars](wikipedia://en/19310129) : For $k \ge 1$, $i_g(S_{2k}) = 3k$.[^o47]
- [Wheels](wikipedia://en/1655876) : For $k \ge 6$, $i_g(W_{2k+1}) = 3k + 2$. For $k \ge 7$, $i_g(W_{2k}) = 3k$.[^o47]
- Subgraphs of [Wheels](wikipedia://en/1655876) : For $k \ge 13$, if $G$ is a subgraph of $W_k$ having $S_k$ as a subgraph, then $i_g(G) = \left\lceil \frac{3k}{2} \right\rceil$.[^o52]

::: {#o54 .statement kind=statement/conjecture cue=heading name="Open Problems"}

### Open Problems {#Open_Problems}

- Is the upper bound $i_g(G) < 3\Delta(G) - 1$ tight for every value of $\Delta(G)$ ?[^o47]
- Is the incidence game chromatic number a monotonic parameter (i.e. is it as least as big for a graph *G* as for any subgraph of *G*) ?[^o47]

:::
