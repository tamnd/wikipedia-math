# Rewrite order

*Image: Triangle diagram of rewrite rule application svg.svg.* Rewriting *s* to *t* by a rule $l::=r$. If $l$ and $r$ are related by a **rewrite relation**, so are $s$ and $t$. A **simplification ordering** always relates $l$ and $s$, and similarly $r$ and $t$.

::: {#o1 .subject cue=lead name="Rewrite order"}

In [theoretical computer science](wikipedia://en/323392), in particular in [automated reasoning](wikipedia://en/2884728) about formal equations, **reduction orderings** are used to prevent [endless loops](https://en.wikipedia.org/wiki/Endless_loop). **Rewrite orders**, and, in turn, **rewrite relations**, are generalizations of this concept that have turned out to be useful in theoretical investigations.

:::

## Motivation {#Motivation}

Intuitively, a reduction order *R* relates two [terms](wikipedia://en/24885593) *s* and *t* if *t* is properly "simpler" than *s* in some sense.

For example, simplification of terms may be a part of a [computer algebra](wikipedia://en/23659805) program, and may be using the rule set { *x*+0 → *x* , 0+*x* → *x* , *x*\*0 → 0, 0\**x* → 0, *x*\*1 → *x* , 1\**x* → *x* }. In order to prove impossibility of endless loops when simplifying a term using these rules, the reduction order defined by "*sRt* if term *t* is properly shorter than term *s*" can be used; applying any rule from the set will always properly shorten the term.

In contrast, to establish termination of "distributing-out" using the rule *x*\*(*y*+*z*) → *x*\**y*+*x*\**z*, a more elaborate reduction order will be needed, since this rule may blow up the term size due to duplication of *x*. The theory of rewrite orders aims at helping to provide an appropriate order in such cases.

::: {#o4 .definition cue=heading name="Formal definitions"}

## Formal definitions {#Formal_definitions}

Formally, a [binary relation](wikipedia://en/3931) (→) on the set of [terms](wikipedia://en/24885593) is called a **rewrite relation** if it is [closed](wikipedia://en/293802#Closed_sets) under [contextual embedding](https://en.wikipedia.org/wiki/Context_%28term_rewriting%29) and under [instantiation](wikipedia://en/5438948#First-order_logic); formally: if $l\to r$ implies $u[l\sigma]_{p}\to u[r\sigma]_{p}$ for all terms $l, r, u,$ each path *p* of *u*, and each [substitution](wikipedia://en/5438948#First-order_logic) σ. If (→) is also [irreflexive](https://en.wikipedia.org/wiki/Irreflexive_relation) and [transitive](wikipedia://en/200463), then it is called a **rewrite ordering**,[^o20] or **rewrite [preorder](wikipedia://en/23582)**. If the latter (→) is moreover [well-founded](https://en.wikipedia.org/wiki/Well-founded), it is called a **reduction ordering**,[^o5] or a **reduction preorder**. Given a binary relation *R*, its **rewrite [closure](wikipedia://en/293802#Binary_relation_closures)** is the smallest rewrite relation containing *R*.[^o6] A transitive and reflexive rewrite relation that contains the [subterm](wikipedia://en/24885593#Operations_with_terms) ordering is called a **simplification ordering**.[^o7]

## Properties {#Properties}

- The [converse](wikipedia://en/3941020), the [symmetric closure](wikipedia://en/22603634), the [reflexive closure](wikipedia://en/22603618), and the [transitive closure](wikipedia://en/292239) of a rewrite relation is again a rewrite relation, as are the union and the intersection of two rewrite relations.[^o20]
- The converse of a rewrite order is again a rewrite order.
- While rewrite orders exist that are total on the set of [ground terms](wikipedia://en/24885593#Ground_and_linear_terms) ("ground-total" for short), no rewrite order can be total on the set of [all terms](wikipedia://en/24885593#Formal_definition).[^o21][^o22]
- A [term rewriting system](wikipedia://en/415847#Term_rewriting_systems) $\{l_{1}::=r_{1},...,l_{n}::=r_{n}, ...\}$ is [terminating](https://en.wikipedia.org/wiki/Termination_%28rewriting%29) if its rules are a subset of a reduction ordering.[^o23][^o5]
- Conversely, for every terminating term rewriting system, the [transitive closure](wikipedia://en/292239) of (::=) is a reduction ordering,[^o5] which need not be extendable to a ground-total one, however. For example, the ground term rewriting system { *f*(*a*)::=*f*(*b*), *g*(*b*)::=*g*(*a*) } is terminating, but can be shown so using a reduction ordering only if the constants *a* and *b* are incomparable.[^o24][^o25]
- A ground-total and well-founded rewrite ordering[^o26] necessarily contains the [proper subterm](wikipedia://en/24885593#Operations_with_terms) relation on ground terms.
- Conversely, a rewrite ordering that contains the subterm relation[^o28] is necessarily well-founded, when the set of function symbols is finite.[^o22][^o29]
- A finite term rewriting system $\{l_{1}::=r_{1},...,l_{n}::=r_{n}, ...\}$ is terminating if its rules are subset of the strict part of a simplification ordering.[^o7][^o30]

:::
