# Comparison of BitTorrent clients

::: {#o1 .subject cue=lead name="Comparison of BitTorrent clients"}

The following is a general comparison of [BitTorrent clients](https://en.wikipedia.org/wiki/Glossary_of_BitTorrent_terms#Client), which are [computer programs](https://en.wikipedia.org/wiki/Computer_program) designed for [peer-to-peer file sharing](https://en.wikipedia.org/wiki/Peer-to-peer_file_sharing) using the [BitTorrent protocol](https://en.wikipedia.org/wiki/BitTorrent).[^o2]

:::

The BitTorrent protocol coordinates segmented file transfer among [peers](https://en.wikipedia.org/wiki/Glossary_of_BitTorrent_terms#Peer) connected in a [swarm](https://en.wikipedia.org/wiki/Glossary_of_BitTorrent_terms#Swarm). A BitTorrent client enables a user to exchange data as a peer in one or more swarms. Because BitTorrent is a [peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) [communications protocol](https://en.wikipedia.org/wiki/Communications_protocol) that does not need a [server](https://en.wikipedia.org/wiki/Server_%28computing%29), the BitTorrent definition of *client* differs from [the conventional meaning](https://en.wikipedia.org/wiki/Client_%28computing%29) expressed in the [client–server model](https://en.wikipedia.org/wiki/Client–server_model).[^o2]

[Bram Cohen](https://en.wikipedia.org/wiki/Bram_Cohen), author of the BitTorrent protocol, made the first BitTorrent client, which he also called [BitTorrent](https://en.wikipedia.org/wiki/BitTorrent_%28software%29), and published it in July 2001.[^o3]

Many BitTorrent programs are [open-source software](https://en.wikipedia.org/wiki/Open-source_software); others are [freeware](https://en.wikipedia.org/wiki/Freeware), [adware](https://en.wikipedia.org/wiki/Adware) or [shareware](https://en.wikipedia.org/wiki/Shareware). Some [download managers](https://en.wikipedia.org/wiki/Download_manager), such as [FlashGet](https://en.wikipedia.org/wiki/FlashGet) and [GetRight](https://en.wikipedia.org/wiki/GetRight), are BitTorrent-ready. [Opera 12](https://en.wikipedia.org/wiki/Opera_%28web_browser%29), a [web browser](https://en.wikipedia.org/wiki/Web_browser), can also transfer files via BitTorrent.

In 2013 Thunder Networking Technologies publicly revealed that some of their employees surreptitiously distributed a Trojan horse with certain releases of [Xunlei](https://en.wikipedia.org/wiki/Xunlei), the company's BitTorrent-ready download manager.[^o4][^o5] Xunlei is included in the comparison tables.
