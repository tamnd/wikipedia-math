# Mint (web analytics software)

::: {#o1 .subject cue=lead name="Mint"}

**Mint** is a deprecated server-based [web analytics](wikipedia://en/2475872) tool. It tracks [traffic](https://en.wikipedia.org/wiki/Web_traffic) trends, [HTTP referrers](https://en.wikipedia.org/wiki/HTTP_referrer), and [search](https://en.wikipedia.org/wiki/Web_search_engine) trends.[^o2][^o3]

:::

The developer Shaun Inman discontinued sales and support on December 24, 2016.[^o4]
