# Speed prior

::: {#o1 .subject cue=lead name="Speed prior"}

The **speed prior** is a [complexity](https://en.wikipedia.org/wiki/Complexity) measure similar to [Kolmogorov complexity](wikipedia://en/1635), except that it is based on [computation](wikipedia://en/5926) speed as well as [program](https://en.wikipedia.org/wiki/Computer_program) length.[^o2] The speed prior complexity of a program is its size in bits plus the logarithm of the maximum time we are willing to run it to get a prediction.

:::

When compared to traditional measures, use of the Speed. Prior has the disadvantage of leading to less optimal predictions, and the advantage of providing computable predictions.
