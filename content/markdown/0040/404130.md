# Piecewise function

*Image: Piecewise linear function gnuplot.svg.* Plot of the [piecewise linear function](wikipedia://en/444224) $f(x) = \left\{ \begin{array}{lll} -3-x & \text{if} & x \leq -3 \\ x+3 & \text{if} & -3 \leq x \leq 0 \\ 3-2x & \text{if} & 0 \leq x \leq 3 \\ 0.5x - 4.5 & \text{if} & 3 \leq x \\ \end{array} \right.$

::: {#o1 .subject cue=lead name="Piecewise function"}

In [mathematics](wikipedia://en/18831), a **piecewise function** (also called a **piecewise-defined function**, a **hybrid function**, or a **function defined by cases**) is a [function](wikipedia://en/185427) whose [domain](wikipedia://en/50263) is [partitioned](wikipedia://en/340240) into several [intervals](wikipedia://en/49172) ("subdomains") on which the function may be defined differently.[^o2][^o4] Piecewise definition is actually a way of specifying the function, rather than a characteristic of the resulting function itself, as every function whose domain contains at least two points can be rewritten as a piecewise function. The first three paragraphs of this article only deal with this first meaning of "piecewise".

:::

Terms like **piecewise linear**, **piecewise smooth**, **piecewise continuous**, and others are also very common. The meaning of a function being piecewise $P$, for a property $P$, is roughly that the domain of the function can be partitioned into pieces on which the property $P$ holds, but this term is used slightly differently by different authors.[^o5][^o6] Unlike the first meaning, this is a property of the function itself and not only a way to specify it. Sometimes the term is used in a more global sense involving triangulations; see [Piecewise linear manifold](wikipedia://en/2174184).

## Notation and interpretation {#Notation_and_interpretation}

*Image: Absolute value.svg.* Graph of the absolute value function, $y=\vert x\vert$

*Image: PiecewiseMonoDiff svg.svg.* The function $f(x) = \min(1,x^2)$ is piecewise [monotonic](wikipedia://en/48260) (subdomains $(-\infty,0]$, $[0,+\infty)$) and piecewise [differentiable](wikipedia://en/330206) (subdomains $(-\infty,-1]$, $[-1,+1]$, and $[+1,+\infty)$).

Piecewise functions can be defined using the common [functional notation](https://en.wikipedia.org/wiki/Functional_notation), where the body of the function is an array of functions and associated subdomains. A semicolon or comma may follow the subfunction or subdomain columns.[^o3] The $\text{if}$ or $\text{for}$ is rarely omitted at the start of the right column.[^o3]

The subdomains together must cover the whole [domain](wikipedia://en/50263); sometimes it is also required that they are pairwise disjoint, i.e. form a partition of the domain.[^o8] This is enough for a function to be "defined by cases", but in order for the overall function to be "piecewise", the subdomains are typically required to be nonempty intervals (some may be degenerate intervals, i.e. single points or unbounded intervals) and they are often not allowed to have infinitely many subdomains in any bounded interval. This means that functions with bounded domains will only have finitely many subdomains, while functions with unbounded domains can have infinitely many subdomains, as long as they are appropriately spread out.

As an example, consider the piecewise definition of the [absolute value](wikipedia://en/991) function:[^o3]

$$|x| = \begin{cases} -x, & \text{if } x < 0 \\ +x, & \text{if } x \ge 0. \end{cases}$$

For all values of $x$ less than zero, the first sub-function ($-x$) is used, which negates the sign of the input value, making negative numbers positive. For all values of $x$ greater than or equal to zero, the second sub-function ($x$) is used, which evaluates trivially to the input value itself.

The following table documents the absolute value function at certain values of $x$:

::: {#o9 .table cue=table}

| *x* | *f*(*x*) | Sub-function used |
|---|---|---|
| −3 | 3 | $-x$ |
| −0.1 | \0.1 | $-x$ |
| 0 | 0 | $x$ |
| 1/2 | 1/2 | $x$ |
| 5 | 5 | $x$ |

:::

In order to evaluate a piecewise-defined function at a given input value, the appropriate subdomain needs to be chosen in order to select the correct sub-function—and produce the correct output value.

::: {#o11 .example cue=heading name="Examples"}

## Examples {#Examples}

- A [step function](wikipedia://en/170939) or piecewise constant function, composed of constant sub-functions
- [Piecewise linear function](wikipedia://en/444224), composed of [linear](wikipedia://en/39712387) sub-functions
- Piecewise smooth function, composed of [smooth](https://en.wikipedia.org/wiki/Smooth_function) sub-functions
- [Broken power law](https://en.wikipedia.org/wiki/Broken_power_law), a function composed of power-law sub-functions
- [Spline](wikipedia://en/457680), a function composed of polynomial sub-functions, often constrained to be smooth at the joints between pieces
  - [B-spline](wikipedia://en/21834)
- $f(x)= \begin{cases} \exp\left( -\frac{1}{1 - x^2}\right), & x \in (-1,1) \\ 0, & \text{otherwise} \end{cases}$ and some other common [Bump functions](wikipedia://en/815799). These are infinitely differentiable, but [analyticity](wikipedia://en/61478) holds only piecewise.

## Continuity and differentiability of piecewise-defined functions {#Continuity_and_differentiability_of_piecewise-defined_functions}

*Image: Upper semi.svg.* Plot of the piecewise-[quadratic function](wikipedia://en/187240) $f(x) = \left\{ \begin{array}{lll} x^2 & \text{if} & x < 0.707 \\ 1.5 - (x - 1.414)^2 & \text{if} & 0.707 \leq x \\ \end{array} \right.$ Its only discontinuity is at $x_0 = 0.707$.

A piecewise-defined function is [continuous](wikipedia://en/6122) on a given interval in its domain if the following conditions are met:

- its sub-functions are continuous on the corresponding intervals (subdomains),
- there is no discontinuity at an endpoint of any subdomain within that interval.

The pictured function, for example, is piecewise-continuous throughout its subdomains, but is not continuous on the entire domain, as it contains a jump discontinuity at $x_0$. The filled circle indicates that the value of the right sub-function is used in this position.

For a piecewise-defined function to be differentiable on a given interval in its domain, the following conditions have to fulfilled in addition to those for continuity above:

- its sub-functions are differentiable on the corresponding *open* intervals,
- the one-sided derivatives exist at all intervals' endpoints,
- at the points where two subintervals touch, the corresponding one-sided derivatives of the two neighboring subintervals coincide.[^o15][^o16]

## Applications {#Applications}

In applied mathematical analysis, "piecewise-regular" functions have been found to be consistent with many [models of the human visual system](https://en.wikipedia.org/wiki/Visual_perception#Cognitive_and_computational_approaches), where images are perceived at a first stage as consisting of smooth regions separated by edges (as in a [cartoon](https://en.wikipedia.org/wiki/Cartoon));[^o19] a **cartoon-like function** is a [C<sup>2</sup>](wikipedia://en/1408000#Example:_finitely-times_differentiable_%28Ck%29) function, smooth except for the existence of discontinuity curves.[^o20] In particular, [shearlets](wikipedia://en/41918927) have been used as a representation system to provide sparse approximations of this model class in 2D and 3D.

Piecewise defined functions are also commonly used for interpolation, such as in [nearest-neighbor interpolation](https://en.wikipedia.org/wiki/Nearest-neighbor_interpolation).
