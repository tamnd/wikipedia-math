# Principal value

::: {#o1 .subject cue=lead name="Principal value"}

In mathematics, specifically [complex analysis](wikipedia://en/5759), a multivalued function has often the property that, near almost every point, the [graph](wikipedia://en/87352) of the function is the [disjoint union](wikipedia://en/188946) of one or several graphs of [smooth functions](https://en.wikipedia.org/wiki/Smooth_function), which are called **branches** of the multivalued functions. In the case of complex analytic functions, these branches can be prolongated to smooth functions that are defined in the whole complex plane except a finite number of points, and are equal to one value of the multivalued function in their domain. Often, a *branch* refers value specifically to such a maximal branch.

:::

The **principal branch** of a multivariate function is one of these maximal branches that is selected once for all. Typically, the principal branch is the branch that takes a real value for small positive values of the variable.

A **principal value** is the [value](wikipedia://en/4095147) at a point of the function defined by the principal branch. In many cases, the principal value at a point of a multivalued function is distinguished from the other values by being the one whose [argument](wikipedia://en/14699765) has the smallest absolute value, and, when there are two such values, the one with positive real part.

A simple example is given by the [square root](wikipedia://en/29208) function: every nonzero [complex number](wikipedia://en/5826) has two square roots. The principal value of the square root of a positive [real number](wikipedia://en/20646438) is the positive square root denoted $\sqrt x$. The principal square root of a non real complex number is the one with an argument in the interval $(-\pi/2,\pi/2)$, and the principal square root of a negative real number $-x$ is $i\sqrt x$.

## Motivation {#Motivation}

Consider the [complex logarithm](wikipedia://en/4870290) function $\log z$. It is defined as the [complex number](wikipedia://en/5826) $w$ such that

$$e^w = z.$$

Now, for example, say we wish to find $\log i$. This means we want to solve

$$e^w = i$$

for $w$. The value $i\pi/2$ is a solution.

However, there are other solutions, which is evidenced by considering the position of $i$ in the [complex plane](wikipedia://en/217628) and in particular its [argument](wikipedia://en/14699765) $\arg i$. We can rotate counterclockwise $\pi/2$ radians from 1 to reach $i$ initially, but if we rotate further another $2\pi$ we reach $i$ again. So, we can conclude that $i(\pi/2 + 2\pi)$ is *also* a solution for $\log i$. It becomes clear that we can add any multiple of $2\pi$ to our initial solution to obtain all values for $\log i$.

But this has a consequence that may be surprising in comparison of real valued functions: $\log i$ does not have one definite value. For $\log z$, we have

$$\log{z} = \ln{|z|} + i\left(\mathrm{arg}\ z \right) = \ln{|z|} + i\left(\mathrm{Arg}\ z+2\pi k\right)$$

for an [integer](wikipedia://en/14563) $k$, where $\operatorname{Arg} z$ is the (principal) argument of $z$ defined to lie in the [interval](wikipedia://en/49172) $(-\pi,\ \pi]$. Each value of $k$ determines what is known as a *[branch](https://en.wikipedia.org/wiki/Branch_%28mathematical_analysis%29)* (or *sheet*), a single-valued component of the multiple-valued log function. When the focus is on a single branch, sometimes a [branch cut](https://en.wikipedia.org/wiki/Branch_cut) is used; in this case removing the non-positive real numbers from the domain of the function and eliminating $\pi$ as a possible value for $\operatorname{Arg} z$. With this branch cut, the single-branch function is [continuous](wikipedia://en/6122) and [analytic](wikipedia://en/61478) everywhere in its domain.

The branch corresponding to $k = 0$ is known as the *principal branch*, and along this branch, the values the function takes are known as the *principal values*.

## General case {#General_case}

In general, if $f(z)$ is multiple-valued, the principal branch of $f$ is denoted

$$\mathrm{pv}\,f(z)$$

such that for $z$ in the [domain](wikipedia://en/50263) of $f$, $\operatorname{pv} f(z)$ is single-valued.

### Principal values of standard functions {#Principal_values_of_standard_functions}

Complex valued [elementary functions](wikipedia://en/54316) can be multiple-valued over some domains. The principal value of some of these functions can be obtained by decomposing the function into simpler ones whereby the principal value of the simple functions are straightforward to obtain.

#### Logarithm function {#Logarithm_function}

We have examined the [logarithm function](https://en.wikipedia.org/wiki/Logarithm_function) above, i.e.,

$$\log{z} = \ln{|z|} + i\left(\mathrm{arg}\ z\right).$$

Now, $\arg z$ is intrinsically multivalued. One often defines the argument of some complex number to be between $-\pi$ (exclusive) and $\pi$ (inclusive), so we take this to be the principal value of the argument, and we write the argument function on this branch $\operatorname{Arg} z$ (with the leading capital A). Using $\operatorname{Arg} z$ instead of $\arg z$, we obtain the principal value of the logarithm, and we write[^o6]

$$\mathrm{pv}\log{z} = \mathrm{Log}\,z = \ln{|z|} + i\left(\mathrm{Arg}\,z\right).$$

#### Square root {#Square_root}

For a complex number $z = r e^{i \phi}\,$ the principal value of the [square root](wikipedia://en/29208) is:

$$\mathrm{pv}\sqrt{z} = \exp\left(\frac{\mathrm{pv}\log z}{2}\right) = \sqrt{r}\, e^{i \phi / 2}$$

with [argument](https://en.wikipedia.org/wiki/Arg_%28mathematics%29) $-\pi < \phi \le \pi.$ Sometimes a branch cut is introduced so that negative real numbers are not in the domain of the square root function and eliminating the possibility that $\phi = \pi.$

#### Inverse trigonometric and inverse hyperbolic functions {#Inverse_trigonometric_and_inverse_hyperbolic_functions}

Inverse trigonometric functions ($\arcsin$, $\arccos$, $\arctan$, etc.) and inverse hyperbolic functions ($\operatorname{arsinh}$, $\operatorname{arcosh}$, $\operatorname{artanh}$, etc.) can be defined in terms of logarithms and their principal values can be defined in terms of the principal values of the logarithm.

#### Complex argument {#Complex_argument}

*Image: Atan2atan.png.* comparison of [atan](wikipedia://en/374220) and [atan2](wikipedia://en/3856703) functions

The principal value of [complex number argument](https://en.wikipedia.org/wiki/Arg_%28mathematics%29) measured in [radians](wikipedia://en/26003) can be defined as:

- values in the range $[0, 2\pi)$
- values in the range $(-\pi, \pi]$

For example, many computing systems include an [$\operatorname{atan}2(y, x)$](wikipedia://en/3856703) function. The value of $\operatorname{atan}2(\operatorname{imaginary}\_\operatorname{part}(z), \operatorname{real}\_\operatorname{part}(z))$ will be in the interval $(-\pi, \pi].$ In comparison, $\operatorname{atan} y/x$ is typically in $(\tfrac{-\pi}{2}, \tfrac{\pi}{2}].$
