# Morera's theorem

::: {#o1 .subject cue=lead name="Morera's theorem"}

*Image: GeschlosseneKurve.png.* If the integral along every *C* is zero, then *f* is [holomorphic](wikipedia://en/14110) on *D*.

In [complex analysis](wikipedia://en/5759), a branch of [mathematics](wikipedia://en/18831), **Morera's theorem**, named after [Giacinto Morera](https://en.wikipedia.org/wiki/Giacinto_Morera), gives a criterion for proving that a [function](wikipedia://en/185427) is [holomorphic](wikipedia://en/14110).

:::

Morera's theorem states that a [continuous](wikipedia://en/6122), [complex](wikipedia://en/5826)-valued function *f* defined on an [open set](wikipedia://en/39358) *D* in the [complex plane](wikipedia://en/217628) that satisfies

$$\oint_\gamma f(z)\,dz = 0$$

for every closed piecewise *C*<sup>1</sup> curve $\gamma$ in *D* must be holomorphic on *D*.

The assumption of Morera's theorem is equivalent to *f* having an [antiderivative](wikipedia://en/6038197) on *D*.

The converse of the theorem is not true in general. A holomorphic function need not possess an antiderivative on its domain, unless one imposes additional assumptions. The converse does hold e.g. if the domain is [simply connected](https://en.wikipedia.org/wiki/Simply_connected); this is [Cauchy's integral theorem](wikipedia://en/61190), stating that the [line integral](wikipedia://en/21245414) of a holomorphic function along a [closed curve](https://en.wikipedia.org/wiki/Closed_curve) is zero.

The standard "counterexample" is the function $f(z) = 1/z$, which is holomorphic on **C** − {0}. On any simply connected neighborhood U in **C** − {0}, 1/*z* has an antiderivative defined by $L(z) = \ln(r) + i\theta$, where $z = re^{i\theta}$. Because of the ambiguity of *θ* up to the addition of any integer multiple of 2$\pi$, any continuous choice of *θ* on *U* will suffice to define an antiderivative of 1/*z* on *U*. (It is the fact that *θ* cannot be defined continuously on a simple closed curve containing the origin in its interior that is the root of why 1/*z* has no antiderivative on its entire domain **C** − {0}.) And because the derivative of an additive constant is 0, any constant may be added to the antiderivative and the result will still be an antiderivative of 1/*z*.

::: {#o3 .proof cue=heading name="Proof"}

## Proof {#Proof}

*Image: Kurveab.png.* The integrals along two paths from *a* to *b* are equal, since their difference is the integral along a closed loop.

To prove the theorem, we construct an [anti-derivative](wikipedia://en/6038197) for *f*. Since the anti-derivative is holomorphic (by construction!), and since [holomorphic functions are analytic](wikipedia://en/481100), it follows that *f* is holomorphic.

Without loss of generality, it can be assumed that *D* is [connected](wikipedia://en/6233). Fix a point *z*<sub>0</sub> in *D*, and for any $z\in D$, let $\gamma: [0,1]\to D$ be a piecewise *C*<sup>1</sup> curve such that $\gamma(0)=z_0$ and $\gamma(1)=z$. Then define the function *F* to be

$$F(z) = \int_\gamma f(\zeta)\,d\zeta.$$

To see that the function is well-defined, suppose $\tau: [0,1]\to D$ is another piecewise *C*<sup>1</sup> curve such that $\tau(0)=z_0$ and $\tau(1)=z$. The curve $\gamma \tau^{-1}$ (i.e. the curve combining $\gamma$ with $\tau$ in reverse) is a closed piecewise *C*<sup>1</sup> curve in *D*. Then,

$$\int_{\gamma} f(\zeta)\,d\zeta + \int_{\tau^{-1}} f(\zeta) \, d\zeta =\oint_{\gamma \tau^{-1}} f(\zeta)\,d\zeta = 0.$$

And it follows that

$$\int_\gamma f(\zeta)\,d\zeta = \int_\tau f(\zeta)\,d\zeta.$$

Then using the continuity of *f* to estimate difference quotients, we get that *F*′(*z*) = *f*(*z*). Had we chosen a different *z*<sub>0</sub> in *D*, *F* would change by a constant: namely, the result of integrating *f* along *any* piecewise regular curve between the new *z*<sub>0</sub> and the old, and this does not change the derivative.

:::

## Applications {#Applications}

Morera's theorem is a standard tool in [complex analysis](wikipedia://en/5759). It is used in almost any argument that involves a non-algebraic construction of a holomorphic function.

### Uniform limits {#Uniform_limits}

For example, suppose that *f*<sub>1</sub>, *f*<sub>2</sub>, ... is a sequence of holomorphic functions, [converging uniformly](wikipedia://en/50652) to a continuous function *f* on an open disc. By [Cauchy's theorem](wikipedia://en/61190), we know that

$$\oint_C f_n(z)\,dz = 0$$

for every *n*, along any closed curve *C* in the disc. Then the uniform convergence implies that

$$\oint_C f(z)\,dz = \oint_C \lim_{n\to \infty} f_n(z)\,dz =\lim_{n\to \infty} \oint_C f_n(z)\,dz = 0$$

for every closed curve *C*, and therefore by Morera's theorem *f* must be holomorphic. This fact can be used to show that, for any [open set](wikipedia://en/39358) $\Omega \subseteq \mathbf{C}$, the set $A(\Omega)$ of all [bounded](wikipedia://en/311509), analytic functions $u : \Omega \to \mathbf{C}$ is a [Banach space](wikipedia://en/3989) with respect to the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm).

### Infinite sums and integrals {#Infinite_sums_and_integrals}

Morera's theorem can also be used in conjunction with [Fubini's theorem](wikipedia://en/255245) and the [Weierstrass M-test](wikipedia://en/444456) to show the analyticity of functions defined by sums or integrals, such as the [Riemann zeta function](wikipedia://en/25809)

$$\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s}$$

or the [Gamma function](wikipedia://en/12316)

$$\Gamma(\alpha) = \int_0^\infty x^{\alpha-1} e^{-x}\,dx.$$

Specifically one shows that

$$\oint_C \Gamma(\alpha)\,d\alpha = 0$$

for a suitable closed curve *C*, by writing

$$\oint_C \Gamma(\alpha)\,d\alpha = \oint_C \int_0^\infty x^{\alpha-1} e^{-x} \, dx \,d\alpha$$

and then using Fubini's theorem to justify changing the order of integration, getting

$$\int_0^\infty \oint_C x^{\alpha-1} e^{-x} \,d\alpha \,dx = \int_0^\infty e^{-x} \oint_C x^{\alpha-1} \, d\alpha \,dx.$$

Then one uses the analyticity of $\alpha \mapsto x^{\alpha-1}$ to conclude that

$$\oint_C x^{\alpha-1} \, d\alpha = 0,$$

and hence the double integral above is 0. Similarly, in the case of the zeta function, the M-test justifies interchanging the integral along the closed curve and the sum.

:::

## Weakening of hypotheses {#Weakening_of_hypotheses}

The hypotheses of Morera's theorem can be weakened considerably. In particular, it suffices for the integral

$$\oint_{\partial T} f(z)\, dz$$

to be zero for every closed (solid) triangle *T* contained in the region *D*. This in fact [characterizes](wikipedia://en/780886) holomorphy, i.e. *f* is holomorphic on *D* if and only if the above conditions hold. It also implies the following generalisation of the aforementioned fact about uniform limits of holomorphic functions: if *f*<sub>1</sub>, *f*<sub>2</sub>, ... is a sequence of holomorphic functions defined on an open set $\Omega \subseteq \mathbf{C}$ that converges to a function *f* uniformly on compact subsets of Ω, then *f* is holomorphic.
