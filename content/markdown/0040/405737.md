# Exact differential

::: {#o1 .subject cue=lead name="Exact differential"}

In [multivariate calculus](https://en.wikipedia.org/wiki/Multivariate_calculus), a [differential](https://en.wikipedia.org/wiki/Differential_%28infinitesimal%29) or [differential form](wikipedia://en/221519) is said to be **exact** or **perfect** (*exact differential*), as contrasted with an [inexact differential](https://en.wikipedia.org/wiki/Inexact_differential), if it is equal to the general differential $dQ$ for some [differentiable function](wikipedia://en/330206) $Q$ in an [orthogonal coordinate system](wikipedia://en/5006088) (hence $Q$ is a multivariable function [whose variables are independent](wikipedia://en/437701#In_pure_mathematics), as they are always expected to be when treated in [multivariable calculus](wikipedia://en/615222)).

:::

An exact differential is sometimes also called a *total differential*, or a *full differential*, or, in the study of [differential geometry](wikipedia://en/8625), it is termed an [exact form](https://en.wikipedia.org/wiki/Exact_form).

The integral of an exact differential over any integral path is [path-independent](wikipedia://en/461454#Path_independence), and this fact is used to identify [state functions](wikipedia://en/341436) in [thermodynamics](wikipedia://en/29952).

## Overview {#Overview}

::: {#o4 .definition cue=heading name="Definition"}

### Definition {#Definition}

Even if we work in three dimensions here, the definitions of exact differentials for other dimensions are structurally similar to the three dimensional definition. In three dimensions, a form of the type

$$A(x, y, z) \,dx + B(x, y, z) \,dy + C(x, y, z) \,dz$$

is called a [differential form](wikipedia://en/221519). This form is called *exact* on an open domain $D \subset \mathbb{R}^3$ in space if there exists some [differentiable](wikipedia://en/330206) [scalar function](https://en.wikipedia.org/wiki/Scalar_function) $Q = Q(x, y, z)$ defined on $D$ such that

$$dQ \equiv \left(\frac{\partial Q}{\partial x}\right)_{y,z} \, dx + \left(\frac{\partial Q}{\partial y}\right)_{x,z} \, dy + \left(\frac{\partial Q}{\partial z}\right)_{x,y} \, dz, \quad dQ = A \, dx + B \, dy + C \, dz$$

throughout $D$, where $x, y, z$ are [orthogonal coordinates](wikipedia://en/5006088) (e.g., [Cartesian](wikipedia://en/7706), [cylindrical](https://en.wikipedia.org/wiki/Cylindrical), or [spherical coordinates](wikipedia://en/29181)). In other words, in some open domain of a space, a differential form is an *exact differential* if it is equal to the general differential of a differentiable function in an orthogonal coordinate system.

The subscripts outside the parenthesis in the above [mathematical expression](wikipedia://en/609125) indicate which variables are being held constant during differentiation. Due to the definition of the [partial derivative](wikipedia://en/52565), these subscripts are not required, but they are explicitly shown here as reminders.

:::

### Integral path independence {#Integral_path_independence}

The exact differential for a differentiable scalar function $Q$ defined in an open domain $D \subset \mathbb{R}^n$ is equal to $dQ = \nabla Q \cdot d \mathbf{r}$, where $\nabla Q$ is the [gradient](wikipedia://en/12461) of $Q$, $\cdot$ represents the [scalar product](wikipedia://en/157093), and $d \mathbf{r}$ is the general differential displacement vector, if an orthogonal coordinate system is used. If $Q$ is of differentiability class $C^1$ ([continuously differentiable](wikipedia://en/1408000#Multivariate_differentiability_classes)), then $\nabla Q$ is a [conservative vector field](wikipedia://en/461454) for the corresponding potential $Q$ by the definition. For three dimensional spaces, expressions such as $d \mathbf{r} = (dx, dy, dz)$ and $\nabla Q = \left(\frac{\partial Q}{\partial x}, \frac{\partial Q}{\partial y},\frac{\partial Q}{\partial z}\right)$ can be made.

The [gradient theorem](wikipedia://en/5337437) states

$$\int _{i}^{f} dQ = \int _{i}^{f}\nabla Q (\mathbf {r} )\cdot d \mathbf {r} = Q \left(f \right) - Q \left(i \right)$$

that does not depend on which integral path between the given path endpoints $i$ and $f$ is chosen. So it is concluded that *the integral of an exact differential is independent of the choice of an integral path between given path endpoints [(path independence)](wikipedia://en/461454#Path_independence).*

For three dimensional spaces, if $\nabla Q$ defined on an open domain $D \subset \mathbb{R}^3$ is of [differentiability class](wikipedia://en/1408000#Multivariate_differentiability_classes) $C^1$ (equivalently $Q$ is of $C^2$), then this integral path independence can also be proved by using the [vector calculus identity](https://en.wikipedia.org/wiki/Vector_calculus_identity#Curl_of_gradient_is_zero) $\nabla \times ( \nabla Q ) = \mathbf{0}$ and [Stokes' theorem](wikipedia://en/25441497).

$$\oint _{\partial \Sigma }\nabla Q \cdot d \mathbf {r} = \iint _{\Sigma }(\nabla \times \nabla Q)\cdot d \mathbf {a} = 0$$

for a simply closed loop $\partial \Sigma$ with the smooth oriented surface $\Sigma$ in it. If the open domain $D$ is [simply connected open space](wikipedia://en/523879) (roughly speaking, a single piece open space without a hole within it), then any irrotational vector field (defined as a $C^1$ vector field $\mathbf{v}$ which curl is zero, i.e., $\nabla \times \mathbf{v} = \mathbf{0}$) has the path independence by the Stokes' theorem, so the following statement is made; *In a simply connected open region, any* $C^1$ *vector field that has the path-independence property (so it is a conservative vector field.) must also be irrotational and vice versa.* The equality of the path independence and conservative vector fields is shown [here](wikipedia://en/461454#Path_independence_and_conservative_vector_field).

#### Thermodynamic state function {#Thermodynamic_state_function}

In [thermodynamics](wikipedia://en/29952), when $dQ$ is exact, the function $Q$ is a [state function](wikipedia://en/341436) of the system: a [mathematical function](wikipedia://en/185427) which depends solely on the current [equilibrium state](wikipedia://en/265823), not on the path taken to reach that state. [Internal energy](wikipedia://en/340757) $U$, [Entropy](wikipedia://en/9891) $S$, [Enthalpy](wikipedia://en/10274) $H$, [Helmholtz free energy](wikipedia://en/255447) $A$, and [Gibbs free energy](wikipedia://en/238181) $G$ are [state functions](wikipedia://en/341436). Generally, neither [work](wikipedia://en/3616613) $W$ nor [heat](wikipedia://en/19593167) $Q$ is a state function. (Note: $Q$ is commonly used to represent heat in physics. It should not be confused with the use earlier in this article as the parameter of an exact differential.)

### One dimension {#One_dimension}

In one dimension, a differential form

$$A(x) \, dx$$

is exact [if and only if](wikipedia://en/14922) $A$ has an [antiderivative](wikipedia://en/2823) (but not necessarily one in terms of [elementary functions](wikipedia://en/10412)). If $A$ has an antiderivative and let $Q$ be an antiderivative of $A$ so $\frac{dQ}{dx} = A$, then $A(x) \, dx$ obviously satisfies the condition for exactness. If $A$ does *not* have an antiderivative, then we cannot write $dQ = \frac{dQ}{dx}dx$ with $A = \frac{dQ}{dx}$ for a differentiable function $Q$ so $A(x) \, dx$ is inexact.

### Two and three dimensions {#Two_and_three_dimensions}

By [symmetry of second derivatives](wikipedia://en/412094), for any "well-behaved" (non-[pathological](wikipedia://en/372742)) function $Q$, we have

$$\frac{\partial ^2 Q}{\partial x \, \partial y} = \frac{\partial ^2 Q}{\partial y \, \partial x}.$$

Hence, in a [simply-connected](https://en.wikipedia.org/wiki/Simply-connected) region *R* of the *xy*-plane, where $x,y$ are independent,[^o9] a differential form

$$A(x, y)\,dx + B(x, y)\,dy$$

is an exact differential if and only if the equation

$$\left( \frac{\partial A}{\partial y} \right)_x = \left( \frac{\partial B}{\partial x} \right)_y$$

holds. If it is an exact differential so $A=\frac{\partial Q}{\partial x}$ and $B=\frac{\partial Q}{\partial y}$, then $Q$ is a differentiable (smoothly continuous) function along $x$ and $y$, so $\left( \frac{\partial A}{\partial y} \right)_x = \frac{\partial ^2 Q}{\partial y \partial x} = \frac{\partial ^2 Q}{\partial x \partial y} = \left( \frac{\partial B}{\partial x} \right)_y$. If $\left( \frac{\partial A}{\partial y} \right)_x = \left( \frac{\partial B}{\partial x} \right)_y$ holds, then $A$ and $B$ are differentiable (again, smoothly continuous) functions along $y$ and $x$ respectively, and $\left( \frac{\partial A}{\partial y} \right)_x = \frac{\partial ^2 Q}{\partial y \partial x} = \frac{\partial ^2 Q}{\partial x \partial y} = \left( \frac{\partial B}{\partial x} \right)_y$ is only the case.

For three dimensions, in a simply-connected region *R* of the *xyz*-coordinate system, by a similar reason, a differential

$$dQ = A(x, y, z) \, dx + B(x, y, z) \, dy + C(x, y, z) \, dz$$

is an exact differential if and only if between the functions *A*, *B* and *C* there exist the relations

$\left( \frac{\partial A}{\partial y} \right)_{x,z} \!\!\!= \left( \frac{\partial B}{\partial x} \right)_{y,z}$**;** $\left( \frac{\partial A}{\partial z} \right)_{x,y} \!\!\!= \left( \frac{\partial C}{\partial x} \right)_{y,z}$**;** $\left( \frac{\partial B}{\partial z} \right)_{x,y} \!\!\!= \left( \frac{\partial C}{\partial y} \right)_{x,z}.$

These conditions are equivalent to the following sentence: If *G* is the graph of this vector valued function then for all tangent vectors *X*,*Y* of the *surface* *G* then *s*(*X*, *Y*) = 0 with *s* the [symplectic form](wikipedia://en/28356).

These conditions, which are easy to generalize, arise from the independence of the order of differentiations in the calculation of the second derivatives. So, in order for a differential *dQ*, that is a function of four variables, to be an exact differential, there are six conditions (the [combination](wikipedia://en/5308) $C(4,2)=6$) to satisfy.

## Partial differential relations {#Partial_differential_relations}

If a [differentiable function](wikipedia://en/330206) $z(x,y)$ is [one-to-one (injective)](wikipedia://en/45196) for each independent variable, e.g., $z(x,y)$ is one-to-one for $x$ at a fixed $y$ while it is not necessarily one-to-one for $(x,y)$, then the following [total differentials](https://en.wikipedia.org/wiki/Total_differential) exist because each independent variable is a differentiable function for the other variables, e.g., $x(y,z)$.

$$d x = {\left ( \frac{\partial x}{\partial y} \right )}_z \, d y + {\left ( \frac{\partial x}{\partial z} \right )}_y \,dz$$

$$d z = {\left ( \frac{\partial z}{\partial x} \right )}_y \, d x + {\left ( \frac{\partial z}{\partial y} \right )}_x \,dy.$$

Substituting the first equation into the second and rearranging, we obtain

$$d z = {\left ( \frac{\partial z}{\partial x} \right )}_y \left [ {\left ( \frac{\partial x}{\partial y} \right )}_z d y + {\left ( \frac{\partial x}{\partial z} \right )}_y dz \right ] + {\left ( \frac{\partial z}{\partial y} \right )}_x dy,$$

$$d z = \left [ {\left ( \frac{\partial z}{\partial x} \right )}_y {\left ( \frac{\partial x}{\partial y} \right )}_z + {\left ( \frac{\partial z}{\partial y} \right )}_x \right ] d y + {\left ( \frac{\partial z}{\partial x} \right )}_y {\left ( \frac{\partial x}{\partial z} \right )}_y dz,$$

$$\left [ 1 - {\left ( \frac{\partial z}{\partial x} \right )}_y {\left ( \frac{\partial x}{\partial z} \right )}_y \right ] dz = \left [ {\left ( \frac{\partial z}{\partial x} \right )}_y {\left ( \frac{\partial x}{\partial y} \right )}_z + {\left ( \frac{\partial z}{\partial y} \right )}_x \right ] d y.$$

Since $y$ and $z$ are independent variables, $d y$ and $d z$ may be chosen without restriction. For this last equation to generally hold, the bracketed terms must be equal to zero.[^o11] The left bracket equal to zero leads to the reciprocity relation while the right bracket equal to zero goes to the cyclic relation as shown below.

::: {#o13 .pointer-item cue=pointer name="Reciprocity relation"}

### Reciprocity relation {#Reciprocity_relation}

Setting the first term in brackets equal to zero yields

$${\left ( \frac{\partial z}{\partial x} \right )}_y {\left ( \frac{\partial x}{\partial z} \right )}_y = 1.$$

A slight rearrangement gives a reciprocity relation,

$${\left ( \frac{\partial z}{\partial x} \right )}_y = \frac{1}{{\left ( \frac{\partial x}{\partial z} \right )}_y}.$$

There are two more [permutations](https://en.wikipedia.org/wiki/Permutations) of the foregoing derivation that give a total of three reciprocity relations between $x$, $y$ and $z$.

:::

### Cyclic relation {#Cyclic_relation}

The cyclic relation is also known as the cyclic rule or the [Triple product rule](wikipedia://en/6296376). Setting the second term in brackets equal to zero yields

$${\left ( \frac{\partial z}{\partial x} \right )}_y {\left ( \frac{\partial x}{\partial y} \right )}_z = - {\left ( \frac{\partial z}{\partial y} \right )}_x.$$

Using a reciprocity relation for $\tfrac{\partial z}{\partial y}$ on this equation and reordering gives a cyclic relation (the [triple product rule](wikipedia://en/6296376)),

$${\left ( \frac{\partial x}{\partial y} \right )}_z {\left ( \frac{\partial y}{\partial z} \right )}_x {\left ( \frac{\partial z}{\partial x} \right )}_y = -1.$$

If, *instead*, reciprocity relations for $\tfrac{\partial x}{\partial y}$ and $\tfrac{\partial y}{\partial z}$ are used with subsequent rearrangement, a [standard form for implicit differentiation](wikipedia://en/250896#Formula_for_two_variables) is obtained:

$${\left ( \frac{\partial y}{\partial x} \right )}_z = - \frac { {\left ( \frac{\partial z}{\partial x} \right )}_y }{ {\left ( \frac{\partial z}{\partial y} \right )}_x }.$$

## Some useful equations derived from exact differentials in two dimensions {#Some_useful_equations_derived_from_exact_differentials_in_two_dimensions}

(See also [Bridgman's thermodynamic equations](https://en.wikipedia.org/wiki/Bridgman's_thermodynamic_equations) for the use of exact differentials in the theory of [thermodynamic equations](https://en.wikipedia.org/wiki/Thermodynamic_equations))

Suppose we have five state functions $z,x,y,u$, and $v$. Suppose that the state space is two-dimensional and any of the five quantities are differentiable. Then by the [chain rule](wikipedia://en/6113)

::: {#o16 .equation cue=numblk name="1"}

$$dz = \left(\frac{\partial z}{\partial x}\right)_y dx+ \left(\frac{\partial z}{\partial y}\right)_x dy = \left(\frac{\partial z}{\partial u}\right)_v du +\left(\frac{\partial z}{\partial v}\right)_u dv \tag{1}$$

:::

but also by the chain rule:

::: {#o17 .equation cue=numblk name="2"}

$$dx = \left(\frac{\partial x}{\partial u}\right)_v du +\left(\frac{\partial x}{\partial v}\right)_u dv \tag{2}$$

:::

and

::: {#o18 .equation cue=numblk name="3"}

$$dy= \left(\frac{\partial y}{\partial u}\right)_v du +\left(\frac{\partial y}{\partial v}\right)_u dv \tag{3}$$

:::

so that (by substituting (2) and (3) into (1)):

::: {#o19 .equation cue=numblk name="4"}

$$\begin{aligned} dz = & \left[ \left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial u}\right)_v + \left(\frac{\partial z}{\partial y}\right)_x \left(\frac{\partial y}{\partial u}\right)_v \right] du \\ + & \left[ \left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial v}\right)_u + \left(\frac{\partial z}{\partial y}\right)_x \left(\frac{\partial y}{\partial v}\right)_u \right] dv \end{aligned} \tag{4}$$

:::

which implies that (by comparing (4) with (1)):

::: {#o20 .equation cue=numblk name="5"}

$$\left(\frac{\partial z}{\partial u}\right)_v = \left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial u}\right)_v + \left(\frac{\partial z}{\partial y}\right)_x \left(\frac{\partial y}{\partial u}\right)_v \tag{5}$$

:::

Letting $v=y$ in (5) gives:

::: {#o21 .equation cue=numblk name="6"}

$$\left(\frac{\partial z}{\partial u}\right)_y = \left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial u}\right)_y \tag{6}$$

:::

Letting $u=y$ in (5) gives:

::: {#o22 .equation cue=numblk name="7"}

$$\left(\frac{\partial z}{\partial y}\right)_v = \left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial y}\right)_v + \left(\frac{\partial z}{\partial y}\right)_x \tag{7}$$

:::

Letting $u=y$ and $v=z$ in (7) gives:

::: {#o23 .equation cue=numblk name="8"}

$$\left(\frac{\partial z}{\partial y}\right)_x = - \left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial y}\right)_z \tag{8}$$

:::

using ($\partial a/\partial b)_c = 1/(\partial b/\partial a)_c$ gives the [triple product rule](wikipedia://en/6296376):

::: {#o24 .equation cue=numblk name="9"}

$$\left(\frac{\partial z}{\partial x}\right)_y \left(\frac{\partial x}{\partial y}\right)_z \left(\frac{\partial y}{\partial z}\right)_x =-1 \tag{9}$$

:::
