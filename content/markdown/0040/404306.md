# Normal function

::: {#o1 .subject cue=lead name="Normal function"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), a function $f : \operatorname{Ord} \to \operatorname{Ord}$ is called **normal** (or a **normal function**) if it is [continuous](wikipedia://en/6122#Continuous_functions_between_partially_ordered_sets) (with respect to the [order topology](wikipedia://en/213650)) and [strictly monotonically increasing](wikipedia://en/48260). This is equivalent to the following two conditions:

:::

1. For every [limit ordinal](wikipedia://en/373137) $\gamma$ (i.e. $\gamma$ is neither zero nor a [successor](wikipedia://en/375256)), it is the case that $f(\gamma) = \sup\{f(\nu) : \nu < \gamma\}$.
1. For all ordinals $\alpha < \beta$, it is the case that $f(\alpha) < f(\beta)$.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

A simple normal function is given by $f(\alpha) = 1 + \alpha$ (see [ordinal arithmetic](wikipedia://en/2139226)). But $f(\alpha) = \alpha + 1$ is *not* normal because it is not continuous at any limit ordinal (for example, $f(\omega) = \omega+1 \ne \omega = \sup \{f(n) : n < \omega\}$). If $\beta$ is a fixed ordinal, then the functions $f(\alpha) = \beta + \alpha$, $f(\alpha) = \beta \times \alpha$ (for $\beta \ge 1$), and $f(\alpha) = \beta^{\alpha}$ (for $\beta \ge 2$) are all normal.

More important examples of normal functions are given by the [aleph numbers](wikipedia://en/293961) $f(\alpha) = \aleph_\alpha$, which connect ordinal and [cardinal numbers](wikipedia://en/6173), and by the [beth numbers](wikipedia://en/393359) $f(\alpha) = \beth_\alpha$.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $f$ is normal, then for any ordinal $\alpha$,

$f(\alpha) \ge \alpha$.[^o6]

::: {#o7 .proof cue=inline-head name="Proof"}

**Proof**: If not, choose $\gamma$ minimal such that $f(\gamma) < \gamma$. Since $f$ is strictly monotonically increasing, $f(f(\gamma)) < f(\gamma)$, contradicting minimality of $\gamma$.

Furthermore, for any [non-empty](wikipedia://en/9566) set $S$ of ordinals, we have

$$f(\sup S) = \sup f(S).$$

:::

::: {#o8 .proof cue=inline-head name="Proof"}

**Proof**: "≥" follows from the monotonicity of $f$ and the definition of the [supremum](https://en.wikipedia.org/wiki/Supremum). For "$\le$", consider three cases:

- if $\sup S = 0$, then $S = \{0\}$ and $\sup f(S) = f(0) = f(\sup S)$;
- if $\sup S = \nu + 1$ is a successor, then $\sup S$ is in $S$, so $f(\sup S)$ is in $f(S)$, i.e. $f(\sup S) \le \sup f(S)$;
- if $\sup S$ is a nonzero limit, then for any $\nu < \sup S$ there exists an $s$ in $S$ such that $\nu < s$, i.e. $f(\nu) < f(s) \le \sup f(S)$, yielding $f(\sup S) = \sup \{f(\nu) : \nu < \sup S\} \le \sup f(S)$.

Every normal function $f$ has arbitrarily large fixed points; see the [fixed-point lemma for normal functions](wikipedia://en/404343) for a proof. One can create a normal function $f' : \operatorname{Ord} \to \operatorname{Ord}$, called the **derivative** of $f$, such that $f'(\alpha)$ is the $\alpha$-th fixed point of $f$.[^o9] For a hierarchy of normal functions, see [Veblen functions](wikipedia://en/16124925).
