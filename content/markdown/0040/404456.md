# Finitary

::: {#o1 .subject cue=lead name="Finitary"}

In [mathematics](wikipedia://en/18831) and [logic](wikipedia://en/46426065), an [operation](wikipedia://en/4140245) is **finitary** if it has [finite](https://en.wikipedia.org/wiki/Finite_cardinality) [arity](wikipedia://en/42301), i.e. if it has a finite number of input values. Similarly, an **infinitary** operation is one with an [infinite number](wikipedia://en/142679) of input values.

:::

In standard mathematics, an operation is finitary by definition. Therefore, these terms are usually only used in the context of [infinitary logic](wikipedia://en/630478).

## Finitary argument {#Finitary_argument}

A **finitary argument** is one which can be translated into a [finite set](wikipedia://en/11742) of symbolic propositions starting from a finite[^o3] set of [axioms](wikipedia://en/928). In other words, it is a [proof](wikipedia://en/82285) (including all assumptions) that can be written on a large enough sheet of paper.

By contrast, **[infinitary logic](wikipedia://en/630478)** studies logics that allow infinitely long [statements](https://en.wikipedia.org/wiki/Statement_%28logic%29) and [proofs](wikipedia://en/82285). In such a logic, one can regard the [existential quantifier](https://en.wikipedia.org/wiki/Existential_quantifier), for instance, as derived from an infinitary [disjunction](https://en.wikipedia.org/wiki/Disjunction).

## History {#History}

[Logicians](wikipedia://en/46426065) in the early 20th century aimed to solve the [problem of foundations](wikipedia://en/169358), such as, "What is the true base of mathematics?" The program was to be able to rewrite all mathematics using an entirely syntactical language *without semantics*. In the words of [David Hilbert](wikipedia://en/8302) (referring to [geometry](wikipedia://en/18973446)), "it does not matter if we call the things *chairs*, *tables* and *beer mugs* or *points*, *lines* and *planes*."

The stress on finiteness came from the idea that human *mathematical* thought is based on a finite number of principles and all the reasonings follow essentially one rule: the *[modus ponens](wikipedia://en/18900)*. The project was to fix a finite number of symbols (essentially the [numerals](wikipedia://en/280582) 1, 2, 3, ... the letters of alphabet and some special symbols like "+", "⇒", "(", ")", etc.), give a finite number of propositions expressed in those symbols, which were to be taken as "foundations" (the axioms), and some [rules of inference](wikipedia://en/252311) which would model the way humans make conclusions. From these, *regardless of the semantic interpretation of the symbols* the remaining theorems should follow *formally* using only the stated rules (which make mathematics look like a *game with symbols* more than a *science*) without the need to rely on ingenuity. The hope was to prove that from these axioms and rules *all* the theorems of mathematics could be deduced. That aim is known as [logicism](wikipedia://en/350672).
