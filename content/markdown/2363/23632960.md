# Sardinas–Patterson algorithm

::: {#o1 .subject cue=lead name="Sardinas–Patterson algorithm"}

In [coding theory](wikipedia://en/321869), the **Sardinas–Patterson algorithm** is a classical algorithm for determining in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) whether a given [variable-length code](https://en.wikipedia.org/wiki/Variable-length_code) is uniquely decodable, named after August Albert Sardinas and George W. Patterson, who published it in 1953.[^n1] The algorithm carries out a systematic search for a string which admits two different decompositions into codewords. As [Knuth](wikipedia://en/8095) reports, the algorithm was rediscovered about ten years later in 1963 by [Floyd](https://en.wikipedia.org/wiki/Robert_W._Floyd), despite the fact that it was at the time already well known in coding theory.[^o3]

:::

## Idea of the algorithm {#Idea_of_the_algorithm}

Consider the code $\{\, \texttt{a} \mapsto \texttt{1}, \texttt{b} \mapsto \texttt{011}, \texttt{c}\mapsto \texttt{01110}, \texttt{d}\mapsto \texttt{1110}, \texttt{e}\mapsto \texttt{10011}\,\}$. This code, which is based on an example by Berstel,[^o5] is an example of a code which is not uniquely decodable, since the string

011101110011

can be interpreted as the sequence of codewords

01110 – 1110 – 011,

but also as the sequence of codewords

011 – 1 – 011 – 10011.

Two possible decodings of this encoded string are thus given by cdb and babe.

In general, a codeword can be found by the following idea: In the first round, we choose two codewords $x_1$ and $y_1$ such that $x_1$ is a [prefix](https://en.wikipedia.org/wiki/Prefix_%28computer_science%29) of $y_1$, that is, $x_1w = y_1$ for some "dangling suffix" $w$. If one tries first $x_1=\texttt{011}$ and $y_1=\texttt{01110}$, the dangling [suffix](https://en.wikipedia.org/wiki/Suffix_%28computer_science%29) is $\texttt{w} = \texttt{10}$. If we manage to find two sequences $x_2,\ldots,x_p$ and $y_2,\ldots,y_q$ of codewords such that $x_2\cdots x_p = wy_2\cdots y_q$, then we are finished: For then the string $x = x_1x_2\cdots x_p$ can alternatively be decomposed as $y_1y_2\cdots y_q$, and we have found the desired string having at least two different decompositions into codewords.

In the second round, we try out two different approaches: the first trial is to look for a codeword that has *w* as prefix. Then we obtain a new dangling suffix *w*, with which we can continue our search. If we eventually encounter a dangling suffix that is itself a codeword (or the [empty word](https://en.wikipedia.org/wiki/Empty_word)), then the search will terminate, as we know there exists a string with two decompositions. The second trial is to seek for a codeword that is itself a prefix of *w*. In our example, we have $w = \texttt{10}$, and the sequence 1 is a codeword. We can thus also continue with $w = \texttt{0}$ as the new dangling suffix.

The algorithm is described most conveniently using [quotients](wikipedia://en/208850) of [formal languages](wikipedia://en/10939). In general, for two sets of strings *D* and *N*, the (left) quotient $N^{-1}D$ is defined as the residual words obtained from *D* by removing some prefix in *N*. Formally, $N^{-1}D = \{\,y \mid xy\in D ~\textrm{ and }~ x \in N \,\}$. Now let $C$ denote the (finite) set of codewords in the given code.

The algorithm proceeds in rounds, where we maintain in each round not only one dangling suffix as described above, but the (finite) set of all potential dangling suffixes. Starting with round $i=1$, the set of potential dangling suffixes will be denoted by $S_i$. The sets $S_i$ are defined [inductively](wikipedia://en/1047605) as follows:

$S_1 = C^{-1}C \setminus \{\varepsilon\}$. Here, the symbol $\varepsilon$ denotes the [empty word](https://en.wikipedia.org/wiki/Empty_word).

$S_{i+1} = C^{-1}S_i\cup S_i^{-1}C$, for all $i\ge 1$.

The algorithm computes the sets $S_i$ in increasing order of $i$. As soon as one of the $S_i$ contains a word from *C* or the empty word, then the algorithm terminates and answers that the given code is not uniquely decodable. Otherwise, once a set $S_i$ equals a previously encountered set $S_j$ with $j<i$, then the algorithm would enter in principle an endless loop. Instead of continuing endlessly, it answers that the given code is uniquely decodable.

## Termination and correctness of the algorithm {#Termination_and_correctness_of_the_algorithm}

Since all sets $S_i$ are sets of suffixes of a finite set of codewords, there are only finitely many different candidates for $S_i$. Since visiting one of the sets for the second time will cause the algorithm to stop, the algorithm cannot continue endlessly and thus must always terminate. More precisely, the total number of dangling suffixes that the algorithm considers is at most equal to the total of the lengths of the codewords in the input, so the algorithm runs in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) as a function of this input length. By using a [suffix tree](https://en.wikipedia.org/wiki/Suffix_tree) to speed the comparison between each dangling suffix and the codewords, the time for the algorithm can be bounded by O(*nk*), where *n* is the total length of the codewords and *k* is the number of codewords.[^n2] The algorithm can be implemented using a [pattern matching](https://en.wikipedia.org/wiki/Pattern_matching) machine. [^n3] The algorithm can also be implemented to run on a [nondeterministic Turing machine](wikipedia://en/21935) that uses only [logarithmic space](wikipedia://en/1145955); the problem of testing unique decipherability is [NL-complete](wikipedia://en/4595166), so this space bound is optimal.[^o12]

A proof that the algorithm is [correct](https://en.wikipedia.org/wiki/Correctness_%28computer_science%29), i.e. that it always gives the correct answer, is found in the textbooks by [Salomaa](wikipedia://en/11157003)[^o13] and by Berstel et al.[^o14]
