# Total set

::: {#o1 .subject cue=lead name="Total set"}

In [functional analysis](wikipedia://en/11180), a **total set** (also called a **complete set**) in a [vector space](wikipedia://en/32370) is a set of [linear functionals](https://en.wikipedia.org/wiki/Linear_functional) $T$ with the property that if a vector $x \in X$ satisfies $f(x) = 0$ for all $f \in T,$ then $x = 0$ is the zero vector.[^o2]

:::

In a more general setting, a subset $T$ of a [topological vector space](wikipedia://en/45752) $X$ is a total set or **fundamental set** if the [linear span](wikipedia://en/56353) of $T$ is [dense](wikipedia://en/23523594) in $X.$[^o3]
