# Arithmetical set

::: {#o1 .subject cue=lead name="Arithmetical set"}

In [mathematical logic](wikipedia://en/19636), an **arithmetical set** (or **arithmetic set**) is a [set](wikipedia://en/26691) of [natural numbers](wikipedia://en/21474) that can be defined by a [formula](wikipedia://en/404582) of [first-order](wikipedia://en/10983) [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic). The arithmetical sets are classified by the [arithmetical hierarchy](wikipedia://en/186475).

:::

The definition can be extended to an arbitrary [countable set](wikipedia://en/6026) *A* (e.g. the set of *n*-[tuples](wikipedia://en/132729) of [integers](https://en.wikipedia.org/wiki/Integers), the set of [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers), the set of formulas in some [formal language](wikipedia://en/10939), etc.) by using [Gödel numbers](https://en.wikipedia.org/wiki/Gödel_number) to represent elements of the set and declaring a [subset](wikipedia://en/27631) of *A* to be arithmetical if the set of corresponding Gödel numbers is arithmetical.

A [function](wikipedia://en/185427) $f:A \subseteq \mathbb{N}^k \to \mathbb{N}$ is called **arithmetically definable** if the [graph](wikipedia://en/87352) of $f$ is an arithmetical set.

A [real number](wikipedia://en/20646438) is called **arithmetical** if the set of all smaller rational numbers is arithmetical. A [complex number](wikipedia://en/5826) is called arithmetical if its [real and imaginary parts](https://en.wikipedia.org/wiki/Real_and_imaginary_parts) are both arithmetical.

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A set *X* of natural numbers is **arithmetical** or **arithmetically definable** if there is a first-order formula φ(*n*) in the language of Peano arithmetic such that each number *n* is in *X* if and only if φ(*n*) holds in the standard model of arithmetic. Similarly, a *k*-ary [relation](wikipedia://en/19509) $R(n_1,\ldots,n_k)$ is arithmetical if there is a formula $\psi(n_1,\ldots,n_k)$ such that $R(n_1,\ldots,n_k) \iff \psi(n_1,\ldots,n_k)$ holds for all *k*-tuples $(n_1,\ldots,n_k)$ of natural numbers.

A [function](wikipedia://en/185427) $f:\subseteq \mathbb{N}^k \to \mathbb{N}$ is called arithmetical if its graph is an arithmetical (*k*+1)-ary relation.

A set *A* is said to be **arithmetical in** a set *B* if *A* is definable by an arithmetical formula that has *B* as a set parameter.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The set of all [prime numbers](wikipedia://en/23666) is arithmetical.
- Every [recursively enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set) is arithmetical.
- Every [computable function](wikipedia://en/1139338) is arithmetically definable.
- The set encoding the [halting problem](wikipedia://en/21391870) is arithmetical.
- [Chaitin's constant Ω](https://en.wikipedia.org/wiki/Chaitin's_constant_Ω) is an arithmetical real number.
- [Tarski's indefinability theorem](https://en.wikipedia.org/wiki/Tarski's_indefinability_theorem) shows that the (Gödel numbers of the) set of true formulas of first-order arithmetic is not arithmetically definable.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The [complement](wikipedia://en/54347) of an arithmetical set is an arithmetical set.
- The [Turing jump](wikipedia://en/1681091) of an arithmetical set is an arithmetical set.
- The collection of arithmetical sets is countable, but the [sequence](wikipedia://en/27838) of arithmetical sets is not arithmetically definable. Thus, there is no arithmetical formula φ(*n*,*m*) that is true if and only if *m* is a member of the *n*th arithmetical predicate.

In fact, such a formula would describe a decision problem for all finite [Turing jumps](wikipedia://en/1681091), and hence belongs to 0<sup>(ω)</sup>, which cannot be formalized in [first-order arithmetic](https://en.wikipedia.org/wiki/First-order_arithmetic), as [it does not belong to the first-order arithmetical hierarchy](wikipedia://en/186475#Summary_of_main_results).

- The set of real arithmetical numbers is [countable](wikipedia://en/6026), [dense](wikipedia://en/6320997) and [order-isomorphic](https://en.wikipedia.org/wiki/Order-isomorphic) to the set of rational numbers.

:::

## Implicitly arithmetical sets {#Implicitly_arithmetical_sets}

Each arithmetical set has an arithmetical formula that says whether particular numbers are in the set. An alternative notion of definability allows for a formula that does not say whether particular numbers are in the set but says whether the set itself satisfies some arithmetical property.

A set *Y* of natural numbers is **implicitly arithmetical** or **implicitly arithmetically definable** if it is definable with an arithmetical formula that is able to use *Y* as a parameter. That is, if there is a formula $\theta(Z)$ in the language of Peano arithmetic with no free number variables and a new set parameter *Z* and set membership relation $\in$ such that *Y* is the unique set *Z* such that $\theta(Z)$ holds.

Every arithmetical set is implicitly arithmetical; if *X* is arithmetically defined by φ(*n*) then it is implicitly defined by the formula

$$\forall n [n \in Z \Leftrightarrow \phi(n)].$$

Not every implicitly arithmetical set is arithmetical, however. In particular, the truth set of first-order arithmetic is implicitly arithmetical but not arithmetical.
