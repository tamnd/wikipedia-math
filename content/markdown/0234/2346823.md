# De Bruijn graph

::: {#o1 .subject cue=lead name="De Bruijn graph"}

In [graph theory](wikipedia://en/12401), an $n$-dimensional **De Bruijn graph** of $m$ symbols is a [directed graph](wikipedia://en/19721986) representing overlaps between sequences of symbols. It has $m^{n}$ [vertices](wikipedia://en/638899), consisting of all possible length-$n$ sequences of the given symbols; the same symbol may appear multiple times in a sequence. For a [set](wikipedia://en/26691) of $m$ symbols $S = \{s_{1}, \ldots, s_{m}\},$ the set of vertices is:

:::

$$V=S^n=\{(s_1,\dots,s_1,s_1),(s_1,\dots,s_1,s_2),\dots,(s_1,\dots,s_1,s_m),(s_1,\dots,s_2,s_1),\dots,(s_m,\dots,s_m,s_m)\}.$$

If one of the vertices can be expressed as another vertex by shifting all its symbols by one place to the left and adding a new symbol at the end of this vertex, then the latter has a directed edge to the former vertex. Thus the set of arcs (that is, directed edges) is

$$E=\{((t_1,t_2,\dots,t_n),(t_2,\dots,t_n,s_j)) : t_i \in S, 1\le i\le n, 1\le j\le m \}.$$

Although De Bruijn graphs are named after [Nicolaas Govert de Bruijn](wikipedia://en/3166399), they were invented independently by both de Bruijn[^o9] and [I. J. Good](wikipedia://en/404404).[^o11] Much earlier, Camille Flye Sainte-Marie[^o10] implicitly used their properties.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If $n = 1$, then the condition for any two vertices forming an edge holds [vacuously](https://en.wikipedia.org/wiki/Vacuously), and hence all the vertices are connected, forming a total of $m^{2}$ edges.
- Each vertex has exactly $m$ incoming and $m$ outgoing edges.
- Each $n$-dimensional De Bruijn graph is the [line digraph](wikipedia://en/675231) of the $(n - 1)$-dimensional De Bruijn graph with the same set of symbols.[^o14]
- Each De Bruijn graph is [Eulerian](https://en.wikipedia.org/wiki/Euler_cycle) and [Hamiltonian](https://en.wikipedia.org/wiki/Hamiltonian_graph). The Euler cycles and Hamiltonian cycles of these graphs (equivalent to each other via the line graph construction) are [De Bruijn sequences](wikipedia://en/1565267).

The [line graph](wikipedia://en/675231) construction of the three smallest binary De Bruijn graphs is depicted below. As can be seen in the illustration, each vertex of the $n$-dimensional De Bruijn graph corresponds to an edge of the $(n - 1)$-dimensional De Bruijn graph, and each edge in the $n$-dimensional De Bruijn graph corresponds to a two-edge path in the $(n - 1)$-dimensional De Bruijn graph.

## Dynamical systems {#Dynamical_systems}

Binary De Bruijn graphs can be drawn in such a way that they resemble objects from the theory of [dynamical systems](wikipedia://en/9087), such as the [Lorenz attractor](https://en.wikipedia.org/wiki/Lorenz_attractor):

This analogy can be made rigorous: the $n$-dimensional $m$-symbol De Bruijn graph is a model of the [Bernoulli map](https://en.wikipedia.org/wiki/Bernoulli_map)

$$x\mapsto mx\ \bmod\ 1.$$

The Bernoulli map (also called the $2x \bmod 1$ map for $m = 2$) is an [ergodic](https://en.wikipedia.org/wiki/Ergodic) dynamical system, which can be understood to be a single [shift](wikipedia://en/467384) of a [$m$-adic number](https://en.wikipedia.org/wiki/P-adic).[^o13] The trajectories of this dynamical system correspond to walks in the De Bruijn graph, where the correspondence is given by mapping each real $x$ in the interval $[0,1)$ to the vertex corresponding to the first $n$ digits in the [base](wikipedia://en/701207)-$m$ representation of $x$. Equivalently, walks in the De Bruijn graph correspond to trajectories in a one-sided [subshift of finite type](wikipedia://en/1986265).

*Image: de\_Bruijn\_binary\_graph.svg.* Directed graphs of two $B(2,3)$ [de Bruijn sequences](wikipedia://en/1565267) and a $B(2,4)$ sequence. In $B(2,3)$, each vertex is visited once, whereas in $B(2,4)$, each edge is traversed once.

Embeddings resembling this one can be used to show that the binary De Bruijn graphs have [queue number](wikipedia://en/46183215) 2[^o12] and that they have [book thickness](https://en.wikipedia.org/wiki/Book_thickness) at most 5.[^o19]

## Uses {#Uses}

- Some [grid network](https://en.wikipedia.org/wiki/Grid_network) topologies are De Bruijn graphs.
- The [distributed hash table](https://en.wikipedia.org/wiki/Distributed_hash_table) protocol [Koorde](https://en.wikipedia.org/wiki/Koorde) uses a De Bruijn graph.
- In [bioinformatics](wikipedia://en/4214), De Bruijn graphs are used for [*de novo* assembly](https://en.wikipedia.org/wiki/De_novo_sequence_assemblers) of sequencing reads into a [genome](https://en.wikipedia.org/wiki/Genome).[^o15][^o16][^o17][^o18][^o20] Instead of the complete De Bruijn graphs described above that contain all possible k-mers, de novo sequence assemblers make use of De Bruijn subgraphs that contain only the k-mers observed in a sequencing dataset.
- In [time series](wikipedia://en/406624) [forecasting](wikipedia://en/246074), De Bruijn graphs have been adapted to encode temporal patterns by mapping discrete subsequences (n-grams) of observations to graph nodes. This enables the modeling of sequential dependencies in symbolic or [discretized](https://en.wikipedia.org/wiki/Discretized) time series data.[^o22][^o23] [Multivariate](wikipedia://en/19384) De Bruijn graphs extend this idea by jointly encoding patterns across multiple correlated variables, allowing for the representation of complex inter-variable temporal dynamics in multivariate time series.[^o21]
