# Spectrum of a sentence

::: {#o1 .subject cue=lead name="Spectrum of a sentence"}

In [mathematical logic](wikipedia://en/19636), the **spectrum of a sentence** is the [set](wikipedia://en/26691) of [natural numbers](wikipedia://en/21474) occurring as the size of a [finite model](wikipedia://en/1773596) in which a given [sentence](wikipedia://en/2129527) is true. By a result in [descriptive complexity](https://en.wikipedia.org/wiki/Descriptive_complexity), a set of natural numbers is a spectrum if and only if it can be recognized in [non-deterministic "weak" exponential time (2<sup>O(n)</sup>)](wikipedia://en/663673), which is a subclass of NEXP.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *ψ* be a sentence in [first-order logic](wikipedia://en/10983). The *spectrum* of *ψ* is the set of natural numbers *n* such that there is a finite model for *ψ* with *n* elements.

If the vocabulary for *ψ* consists only of relational symbols, then *ψ* can be regarded as a sentence in [existential second-order logic](https://en.wikipedia.org/wiki/Existential_second-order_logic) (ESOL) quantified over the relations, over the empty vocabulary. A *generalised spectrum* is the set of models of an ESOL sentence.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The spectrum of the [first-order formula](https://en.wikipedia.org/wiki/First-order_formula)

$$\exists z,o ~ \forall a,b,c ~ \exists d,e$$

$$a+z=a=z+a ~ \land~ a\cdot z=z=z\cdot a ~ \land~ a+d = z$$

$$\land~ a+b = b+a ~ \land~ a\cdot(b+c) = a\cdot b+a\cdot c ~ \land~(a+b)+c=a+(b+c)$$

$$\land~ a \cdot o=a=o \cdot a ~ \land~ a\cdot e=o ~\land~ (a\cdot b)\cdot c=a\cdot (b\cdot c)$$

is $\{p^{n}\mid p \text{ prime}, n \in \mathbb{N}\}$, the set of powers of a [prime number](wikipedia://en/23666). Indeed, with $z$ for $0$ and $o$ for $1$, this sentence describes the set of [fields](wikipedia://en/10603); the [cardinality](wikipedia://en/6174) of a [finite field](wikipedia://en/11615) is the power of a prime number.

- The spectrum of the monadic second-order logic formula $\exists S, T ~ \forall x ~ \left\{x\in S\iff x\not\in T \land~ f(f(x)) = x \land~ x \in S \iff f(x) \in T\right\}$ is the set of [even](wikipedia://en/143135) numbers. Indeed, $f$ is a [bijection](wikipedia://en/3942) between $S$ and $T$, and $S$ and $T$ are a partition of the universe. Hence the cardinality of the universe is even.
- The set of finite and co-finite sets is the set of spectra of first-order logic with the successor relation.
- The set of ultimately periodic sets is the set of spectra of monadic second-order logic with a unary function. It is also the set of spectra of monadic second-order logic with the successor function.

:::

## Descriptive complexity {#Descriptive_complexity}

*[Fagin's theorem](wikipedia://en/3122050)* is a result in [descriptive complexity theory](https://en.wikipedia.org/wiki/Descriptive_complexity) that states that the set of all properties expressible in existential [second-order logic](wikipedia://en/341428) is precisely the [complexity class](wikipedia://en/502426) [NP](https://en.wikipedia.org/wiki/NP_%28complexity_class%29). It is remarkable since it is a characterization of the class NP that does not invoke a model of computation such as a [Turing machine](wikipedia://en/30403). The theorem was proven by [Ronald Fagin](https://en.wikipedia.org/wiki/Ronald_Fagin) in 1974 (strictly, in 1973 in his doctoral thesis).

As a corollary, Jones and [Selman](wikipedia://en/68418053) showed that a set is in the complexity class [NE](wikipedia://en/663673) if it is a spectrum.[^o7]

One direction of the proof is to show that, for every first-order formula $\varphi$, the problem of determining whether there is a model of the formula of [cardinality](wikipedia://en/6174) *n* is equivalent to the [problem of satisfying a formula](wikipedia://en/4715) of size polynomial in *n*, which is in NP(n) and thus in NE of the input to the problem (the number *n* in binary form, which is a string of size log(*n*)).

This is done by replacing every [existential quantifier](https://en.wikipedia.org/wiki/Existential_quantifier) in $\varphi$ with [disjunction](https://en.wikipedia.org/wiki/Disjunction) over all the elements in the model and replacing every [universal quantifier](https://en.wikipedia.org/wiki/Universal_quantifier) with [conjunction](wikipedia://en/18152) over all the elements in the model. Now every predicate is on elements in the model, and finally every appearance of a predicate on specific elements is replaced by a new propositional variable. Equalities are replaced by their truth values according to their assignments.

For example:

$$\forall{x} \forall{y} \left(P(x)\wedge P(y)\right)\rightarrow (x=y)$$

For a model of cardinality 2 (i.e. *n*= 2) is replaced by

$$\big(\left(P(a_1)\wedge P(a_1)\right)\rightarrow (a_1=a_1)\big)\wedge \big(\left(P(a_1)\wedge P(a_2)\right)\rightarrow (a_1=a_2)\big)\wedge \big(\left(P(a_2)\wedge P(a_1)\right)\rightarrow (a_2=a_1)\big)\wedge \big(\left(P(a_2)\wedge P(a_2)\right)\rightarrow (a_2=a_2)\big)$$

Which is then replaced by $\big(\left(p_1\wedge p_1\right)\rightarrow \top\big)\wedge \big(\left(p_1\wedge p_2\right)\rightarrow \bot\big)\wedge \big(\left(p_2\wedge p_1\right)\rightarrow \bot\big)\wedge \big(\left(p_2\wedge p_2\right)\rightarrow \top\big)$

where $\top$ is truth, $\bot$ is falsity, and $p_1$, $p_2$ are propositional variables. In this particular case, the last formula is equivalent to $\neg(p_1\wedge p_2)$, which is satisfiable.

The other direction of the proof is to show that, for every set of binary strings accepted by a non-deterministic Turing machine running in exponential time ($2^{cx}$ for input length x), there is a first-order formula $\varphi$ such that the set of numbers represented by these binary strings are the spectrum of $\varphi$.

Jones and Selman mention that the spectrum of first-order formulas without equality is just the set of all natural numbers not smaller than some minimal cardinality.

### Other properties {#Other_properties}

The set of spectra of a theory is closed under [union](wikipedia://en/47949), [intersection](wikipedia://en/23476429), addition, and multiplication. In full generality, it is not known if the set of spectra of a theory is closed by complementation; this is the so-called Asser's problem. By the result of Jones and Selman, it is equivalent to the problem of whether NE = co-NE; that is, whether NE is closed under complementation. By Fagin's theorem, this is also equivalent to determining if unary NP and unary Co-NP are the same. To show that the set of first-order spectra is not closed under complementation thus entails showing that P is not equal to NP.[^o9]
