# Mostowski model

::: {#o1 .subject cue=lead name="Mostowski model"}

In mathematical [set theory](wikipedia://en/27553), the **Mostowski model** is a [model](wikipedia://en/19858) of set theory with [atoms](https://en.wikipedia.org/wiki/Atom_%28set_theory%29) where the full [axiom of choice](wikipedia://en/840) fails, but every set can be [linearly ordered](wikipedia://en/11726298#Order-extension_principle). It was introduced by (txt). The Mostowski model can be constructed as the [permutation model](wikipedia://en/43782287) corresponding to the [group of all automorphisms](wikipedia://en/56661772) of the ordered set of [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) and the ideal of finite subsets of the rational numbers.

:::
