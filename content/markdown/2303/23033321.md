# Rational quadratic covariance function

::: {#o1 .subject cue=lead name="Rational quadratic covariance function"}

In [statistics](wikipedia://en/26685), the **rational quadratic [covariance function](wikipedia://en/9793263)** is used in [spatial statistics](wikipedia://en/9467349), [geostatistics](wikipedia://en/51531), [machine learning](wikipedia://en/233488), image analysis, and other fields where multivariate statistical analysis is conducted on [metric spaces](wikipedia://en/20018). It is commonly used to define the statistical [covariance](wikipedia://en/157059) between measurements made at two points that are *d* units distant from each other. Since the covariance only depends on distances between points, it is [stationary](wikipedia://en/329898). If the distance is [Euclidean distance](wikipedia://en/53932), the **rational quadratic covariance function** is also [isotropic](https://en.wikipedia.org/wiki/Isotropic).

:::

The **rational quadratic covariance** between two points separated by *d* distance units is given by

$$C(d) = \Bigg(1+\frac{d^2}{2\alpha k^2}\Bigg)^{-\alpha}$$

where *α* and *k* are non-negative [parameters](wikipedia://en/25065) of the covariance.[^o2][^o3]
