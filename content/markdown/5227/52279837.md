# Slim lattice

::: {#o1 .subject cue=lead name="Slim lattice"}

In [lattice theory](https://en.wikipedia.org/wiki/Lattice_theory), a mathematical discipline, a finite [lattice](wikipedia://en/469304) is **slim** if no three join-irreducible elements form an [antichain](wikipedia://en/348973).[^o2] Every slim lattice is [planar](https://en.wikipedia.org/wiki/Planar_lattice). A finite planar [semimodular lattice](wikipedia://en/13881586) is slim if and only if it contains no cover-preserving diamond sublattice M<sub>3</sub> (this is the original definition of a slim lattice due to [George Grätzer](wikipedia://en/42456445) and Edward Knapp).[^o3]

:::
