# Participation criterion

::: {#o1 .subject cue=lead name="Participation criterion"}

The **participation criterion** is a [voting system criterion](wikipedia://en/53544734) that says candidates should never lose an election as a result of receiving too many votes in support.[^o2][^o3] More formally, it says that adding more voters who prefer *Alice* to *Bob* should not cause *Alice* to lose the election to *Bob*.[^o4]

:::

Voting systems that fail the participation criterion exhibit the **no-show paradox**,[^o5] where a voter is effectively disenfranchised by the electoral system because turning out to vote could make the result worse for them; such voters are sometimes referred to as having [negative vote weights](https://en.wikipedia.org/wiki/Negative_vote_weight), particularly in the context of [German constitutional law](https://en.wikipedia.org/wiki/Basic_Law_for_the_Federal_Republic_of_Germany), where courts have ruled such a possibility violates the principle of [one man, one vote](https://en.wikipedia.org/wiki/One_man,_one_vote).[^o6][^o7][^o8]

[Positional methods](https://en.wikipedia.org/wiki/Positional_voting) and [score voting](https://en.wikipedia.org/wiki/Score_voting) satisfy the participation criterion. All deterministic voting rules that satisfy [pairwise majority-rule](wikipedia://en/44446)[^o5][^o9] can fail in situations involving four-way [cyclic ties](https://en.wikipedia.org/wiki/Cyclic_tie), though such scenarios are empirically rare, and the [randomized Condorcet rule](https://en.wikipedia.org/wiki/Maximal_lottery) is not affected by the pathology. The [majority judgment](https://en.wikipedia.org/wiki/Majority_judgment) rule fails as well.[^o10] [Instant-runoff voting](https://en.wikipedia.org/wiki/Instant-runoff_voting) and the [two-round system](https://en.wikipedia.org/wiki/Two-round_system) both fail the participation criterion with high frequency in competitive elections, typically as a result of a [center squeeze](wikipedia://en/76866010).[^o2][^o3][^o11]

The no-show paradox is similar to, but not the same as, the [perverse response paradox](https://en.wikipedia.org/wiki/Mono-raise_criterion). Perverse response happens when an *existing* voter can make a candidate win by *de*creasing their rating of that candidate (or vice-versa). For example, under [instant-runoff voting](https://en.wikipedia.org/wiki/Instant-runoff_voting), moving a candidate from first-place to last-place on a ballot can cause them to win.[^o12]

## Noncompliant methods {#Noncompliant_methods}

### Instant-runoff (ranked-choice) voting {#Instant-runoff_(ranked-choice)_voting}

The most common cause of no-show paradoxes is the use of [instant-runoff](https://en.wikipedia.org/wiki/Instant-runoff_voting) (often called [ranked-choice voting in the United States](https://en.wikipedia.org/wiki/Ranked-choice_voting_in_the_United_States)). In instant-runoff voting, a no-show paradox can occur even in elections with only three candidates,[^o12] and occur in 50%-60% of all 3-candidate elections where the results of IRV disagree with those of plurality.[^o11][^o3]

A notable example is given in the [2009 Burlington mayoral election](https://en.wikipedia.org/wiki/2009_Burlington_mayoral_election), the United States' second [instant-runoff election](https://en.wikipedia.org/wiki/Instant-runoff_voting) in the modern era, where [Bob Kiss](https://en.wikipedia.org/wiki/Bob_Kiss) won the election as a result of 750 ballots ranking him in last place.[^o15]

An example with three parties (Top, Center, Bottom) is shown below. In this scenario, the Center party initially wins. However, say that a group of pro-Top voters joins the election, all of whom cast their ballots with the ranking Top > Center > Bottom:

::: {#o16 .table cue=table}

| Baseline |  |  |  | More votes ranking Center > Bottom |  |  |
|---|---|---|---|---|---|---|
|  | Round 1 | Round 2 |  |  | Round 1 | Round 2 |
| ***Top*** | 25 |  | \+6 | ***Top*** | 31 | 46 |
| ***Center*** | 30 | **55** |  | ***Center*** | 30 |  |
| ***Bottom*** | 39 | 39 |  | ***Bottom*** | 39 | **54** |

:::

The participation criterion says that the addition of voters who prefer Center over Bottom should not cause Bottom to win. Yet the increase in support for the Top party allows it to defeat the Center party in the first round. As a result, 15 votes that previously counted toward Center now count toward their second preference, Bottom, which is enough to give Bottom the victory. This makes the election an example of a [center-squeeze](wikipedia://en/76866010), a class of elections where instant-runoff and [plurality](https://en.wikipedia.org/wiki/Plurality_voting) have difficulty electing the majority-preferred candidate.[^o17]

### Condorcet methods {#Condorcet_methods}

When there are at most 3 major candidates, [Minimax Condorcet](https://en.wikipedia.org/wiki/Minimax_Condorcet) and its variants (such as [ranked pairs](https://en.wikipedia.org/wiki/Ranked_Pairs) and [Schulze's method](https://en.wikipedia.org/wiki/Schulze's_method)) satisfy the participation criterion.[^o5] However, with more than 3 candidates, [Hervé Moulin](wikipedia://en/46510192) proved that every deterministic Condorcet method can sometimes fail participation.[^o5][^o9] Similar incompatibilities have also been shown for [set-valued](https://en.wikipedia.org/wiki/Resolvability_criterion) voting rules.[^o9][^o20][^o21] The [randomized Condorcet rule](https://en.wikipedia.org/wiki/Maximal_lottery) satisfies the criterion, but fails the closely related [monotonicity criterion](https://en.wikipedia.org/wiki/Monotonicity_criterion) in situations with Condorcet cycles.[^o22]

Studies suggest such failures may be empirically rare, however. One study surveying 306 publicly available election datasets found no participation failures for methods in the [ranked pairs](https://en.wikipedia.org/wiki/Ranked_pairs)-[minimax](https://en.wikipedia.org/wiki/Minimax_Condorcet) family.[^o23]

In addition to participation, an even more severe paradox property can occur with Condorcet's principle: it may be better for a voter to submit a completely reversed ballot than to submit a ballot that ranks all candidates honestly.[^o24][^o25]

:::

### Implementations of proportional representation {#Implementations_of_proportional_representation}

Some [proportional representation](https://en.wikipedia.org/wiki/Proportional_representation) systems allow for no-show paradoxes. Rules based on the [Droop quota](https://en.wikipedia.org/wiki/Droop_quota) (including all current implementations of the [single transferable vote](https://en.wikipedia.org/wiki/Single_transferable_vote)) allow for no-show paradoxes.[^o6][^o27]

[Hamilton's method](https://en.wikipedia.org/wiki/Hamilton's_method) exhibits a milder form of the paradox called the [population paradox](https://en.wikipedia.org/wiki/Population_paradox), but does not have a true no-show paradox. However, adding an [electoral threshold](https://en.wikipedia.org/wiki/Electoral_threshold) produces a no-show paradox.[^o28]

#### In Germany {#In_Germany}

In Germany, situations where a voter's ballot has the opposite of its intended effect (e.g. a vote *for* a party or candidate causes them to *lose*) are called *negatives Stimmgewicht* (negative voting weights). An infamous example occurred in the [2005 German federal election](https://en.wikipedia.org/wiki/2005_German_federal_election), when an article in *[Der Spiegel](https://en.wikipedia.org/wiki/Der_Spiegel)* laid out how [CDU](https://en.wikipedia.org/wiki/Christian_Democratic_Union_of_Germany) voters in [Dresden I](https://en.wikipedia.org/wiki/Dresden_I) would have to vote *against* their own party if they wished to avoid losing a seat in the [Bundestag](https://en.wikipedia.org/wiki/Bundestag).[^o6] This led to a lawsuit by [electoral reform](https://en.wikipedia.org/wiki/Electoral_reform) organization Mehr Demokratie and [Alliance 90/The Greens](https://en.wikipedia.org/wiki/Alliance_90/The_Greens), joined by the neo-Nazi [NPD of Germany](https://en.wikipedia.org/wiki/National_Democratic_Party_of_Germany), who argued the election law was unconstitutionally undemocratic.[^o30]

The [Federal Constitutional Court](https://en.wikipedia.org/wiki/Federal_Constitutional_Court) agreed with the plaintiffs, ruling that negative vote weights violate the [German constitution](https://en.wikipedia.org/wiki/Basic_Law_for_the_Federal_Republic_of_Germany)'s guarantee of [equal and direct suffrage](https://en.wikipedia.org/wiki/One_man,_one_vote). The majority wrote that:[^o7][^o8]A seat allocation procedure that allows an increase in votes to lead to a loss of seats, or results in more seats being won if \[proportionally\] fewer votes are cast for it, contradicts the meaning and purpose of a democratic election\[...\]

Such nonsensical relationships between voting and electoral success not only impair the equality of the right to vote and the equal opportunities of the parties, but also the principle of a popular election, as it is no longer apparent to the voter how their vote results in the success or failure of a candidate.\[...\]

Negative vote weights cannot be accepted as constitutional on the premise that they cannot be predicted or planned, and thus can hardly be influenced by the individual voter. To what extent this is true can be set aside, as such arbitrary results make a mockery of the democratic competition for support from the electorate.The ruling forced the [Bundestag](https://en.wikipedia.org/wiki/Bundestag) to abandon its old practice of ignoring [overhang seats](https://en.wikipedia.org/wiki/Overhang_seat), and instead adopt a new system of compensation involving [leveling seats](https://en.wikipedia.org/wiki/Leveling_seat).[^o30]

### Quorum requirements {#Quorum_requirements}

A common cause of no-show paradoxes is the use of a [quorum](https://en.wikipedia.org/wiki/Quorum). For example, if a public [referendum](https://en.wikipedia.org/wiki/Referendum) requires 50% turnout to be binding, additional "no" votes may push turnout above 50%, causing the measure to pass. A referendum that instead required a minimum number of yes votes (e.g. >25% of the population voting "yes") would pass the participation criterion.[^o32]

Many representative bodies have quorum requirements where the same dynamic can be at play. For example, the requirement for a two-thirds [quorum](https://en.wikipedia.org/wiki/Quorum) in the [Oregon Legislative Assembly](https://en.wikipedia.org/wiki/Oregon_Legislative_Assembly) effectively creates an unofficial two-thirds [supermajority](https://en.wikipedia.org/wiki/Supermajority) requirement for passing bills, and can result in a law passing if too many senators turn out to oppose it.[^o33] Deliberate ballot-spoiling strategies have been successful in ensuring referendums remain non-binding, as in the [2023 Polish referendum](https://en.wikipedia.org/wiki/2023_Polish_referendum).

## Manipulation {#Manipulation}

The participation criterion can also be justified as a weaker form of [strategyproofness](wikipedia://en/886330): while it is impossible for honesty to always be the *best* strategy (by [Gibbard's theorem](wikipedia://en/53957416)), the participation criterion guarantees honesty will always be an effective, rather than actively counterproductive, strategy (i.e. a voter can always safely cast a sincere vote).[^o5] This can be particularly effective for encouraging honest voting if voters exhibit [loss aversion](https://en.wikipedia.org/wiki/Loss_aversion). Rules with no-show paradoxes do not always allow voters to cast a sincere vote; for example, a sincere Palin > Begich > Peltola voter in the [2022 Alaska special election](https://en.wikipedia.org/wiki/2022_Alaska's_at-large_congressional_district_special_election) would have been better off if they had not shown up at all, rather than casting an honest vote.

While no-show paradoxes can be deliberately exploited as a kind of [strategic voting](https://en.wikipedia.org/wiki/Strategic_voting), systems that fail the participation criterion are typically considered to be undesirable because they expose the underlying system as logically incoherent or "[spiteful](https://en.wikipedia.org/wiki/Spite_%28sentiment%29)" (actively seeking to violate the preferences of some voters).[^o35]

## Examples {#Examples}

### Majority judgment {#Majority_judgment}

This example shows that majority judgment violates the participation criterion. Assume two candidates A and B with 5 potential voters and the following ratings:

::: {#o40 .table cue=table}

| Candidates |  | of voters |
|---|---|---|
| A | B |  |
| Excellent | Good | 2 |
| Fair | Poor | 2 |
| Poor | Good | 1 |

:::

The two voters rating A "Excellent" are unsure whether to participate in the election.

#### Voters not participating {#Voters_not_participating}

Assume the 2 voters would not show up at the polling place.

The ratings of the remaining 3 voters would be:

::: {#o42 .table cue=table}

| Candidates |  | of voters |
|---|---|---|
| A | B |  |
| Fair | Poor | 2 |
| Poor | Good | 1 |

:::

The sorted ratings would be as follows:

| Candidate | ↓ Median point |
|---|---|
| A |  |
| B |  |
|  | Excellent Good Fair Poor |

**Result**: A has the median rating of "Fair" and B has the median rating of "Poor". Thus, **A** is elected majority judgment winner.

#### Voters participating {#Voters_participating}

Now, consider the 2 voters decide to participate:

::: {#o44 .table cue=table}

| Candidates |  | of voters |
|---|---|---|
| A | B |  |
| Excellent | Good | 2 |
| Fair | Poor | 2 |
| Poor | Good | 1 |

:::

The sorted ratings would be as follows:

| Candidate | ↓ Median point |
|---|---|
| A |  |
| B |  |
|  | Excellent Good Fair Poor |

**Result**: A has the median rating of "Fair" and B has the median rating of "Good". Thus, **B** is the majority judgment winner.

### Condorcet methods {#Condorcet_methods}

This example shows how Condorcet methods can violate the participation criterion when there is a [preference paradox](https://en.wikipedia.org/wiki/Preference_paradox). Assume four candidates A, B, C and D with 26 potential voters and the following preferences:

::: {#o46 .table cue=table}

| Preferences | \# of voters |
|---|---|
| A > D > B > C | 8 |
| B > C > A > D | 7 |
| C > D > B > A | 7 |

:::

This gives the [pairwise counting](https://en.wikipedia.org/wiki/Pairwise_counting) method:

*Pairwise election results*

::: {#o47 .table cue=table name="Pairwise election results"}

|  | A | B | C | D |
|---|---|---|---|---|
| A |  |  |  |  |
| B |  |  |  |  |
| C |  |  |  |  |
| D |  |  |  |  |
| Pairwise results for X, won-tied-lost | 1-0-2 | 2-0-1 | 2-0-1 | 1-0-2 |

:::

The sorted list of victories would be:

::: {#o48 .table cue=table}

| Pair | Winner |
|---|---|
| A (15) vs. D (7) | A 15 |
| B (15) vs. C (7) | B 15 |
| B (7) vs. D (15) | D 15 |
| A (8) vs. B (14) | B 14 |
| A (8) vs. C (14) | C 14 |
| C (14) vs. D (8) | C 14 |

:::

**Result**: A > D, B > C and D > B are locked in (and the other three can't be locked in after that), so the full ranking is A > D > B > C. Thus, **A** is elected ranked pairs winner.

#### Voters participating {#Voters_participating}

Now, assume an extra 4 voters, in the top row, decide to participate:

::: {#o50 .table cue=table}

| Preferences | \# of voters |
|---|---|
| A > B > C > D | 4 |
| A > D > B > C | 8 |
| B > C > A > D | 7 |
| C > D > B > A | 7 |

:::

The results would be tabulated as follows:

*Pairwise election results*

::: {#o51 .table cue=table name="Pairwise election results"}

|  | A | B | C | D |
|---|---|---|---|---|
| A |  |  |  |  |
| B |  |  |  |  |
| C |  |  |  |  |
| D |  |  |  |  |
| Pairwise results for X, won-tied-lost | 1-0-2 | 2-0-1 | 2-0-1 | 1-0-2 |

:::

The sorted list of victories would be:

::: {#o52 .table cue=table}

| Pair | Winner |
|---|---|
| A (19) vs. D (7) | A 19 |
| B (19) vs. C (7) | B 19 |
| C (18) vs. D (8) | C 18 |
| B (11) vs. D (15) | D 15 |
| A (12) vs. B (14) | B 14 |
| A (12) vs. C (14) | C 14 |

:::

**Result**: A > D, B > C and C > D are locked in first. Now, D > B can't be locked in since it would create a cycle B > C > D > B. Finally, B > A and C > A are locked in. Hence, the full ranking is B > C > A > D. Thus, **B** is elected ranked pairs winner by adding a set of voters who prefer A to B.

:::
