# Set partitioning in hierarchical trees

::: {#o1 .subject cue=lead name="Set partitioning in hierarchical trees"}

**Set partitioning in hierarchical trees** (**SPIHT**)[^o2] is an [image](https://en.wikipedia.org/wiki/Image_compression) [compression algorithm](https://en.wikipedia.org/wiki/Compression_algorithm) that exploits the inherent similarities across the subbands in a [wavelet decomposition](wikipedia://en/3352292) of [an image](https://en.wikipedia.org/wiki/Digital_image). The algorithm was developed by Brazilian engineer Amir Said with William A. Pearlman in 1996.[^o2]

:::

## General description {#General_description}

The algorithm [codes](https://en.wikipedia.org/wiki/Code) the most important [wavelet transform](wikipedia://en/3352292) [coefficients](https://en.wikipedia.org/wiki/Coefficients) first, and transmits the bits so that an increasingly refined copy of the original image can be obtained progressively.
