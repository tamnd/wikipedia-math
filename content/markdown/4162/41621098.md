# Chiasmus (cipher)

::: {#o2 .subject cue=lead name="Chiasmus"}

**Chiasmus** is a secret German government [block cipher](wikipedia://en/4594) that was leaked by [reverse engineering](https://en.wikipedia.org/wiki/Reverse_engineering). It became notorious for its dilettante use in the [BSI](https://en.wikipedia.org/wiki/Federal_Office_for_Information_Security)'s software GSTOOL, which used it in insecure [Electronic Codebook (ECB)](wikipedia://en/160202#ECB) mode and generated the key with a [pseudo random number generator](wikipedia://en/45524) initialized to the current system time, which means an effective key length that can easily be broken by [brute force](wikipedia://en/53784). The [BSI](https://en.wikipedia.org/wiki/BSI_Group) tried to prevent the publication of these findings with legal threats.

:::

Chiasmus seems to be resistant against the most common cryptographic attacks ([linear](wikipedia://en/59469) and [differential cryptanalysis](wikipedia://en/8536)), but a lot slower than the openly available state of the art ciphers such as [AES](wikipedia://en/1260).[^o3][^o4]
