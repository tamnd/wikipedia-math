# Reciprocity (engineering)

::: {#o1 .subject cue=lead name="Reciprocity"}

**Reciprocity** in [linear systems](wikipedia://en/722503) is the principle that a response **Rab**, measured at a location (and direction if applicable) **a**, when the system has an excitation signal applied at a location (and direction if applicable) **b**, is exactly equal to **Rba** which is the response at location **b**, when that same excitation is applied at **a**. This applies for all frequencies of the excitation signal. If **Hab** is the [transfer function](wikipedia://en/31146) between **a** and **b** then **Hab** = **Hba**, if the system is linear.

:::

In the special case of a [modal analysis](wikipedia://en/7542417) this is known as Maxwell's reciprocity theorem.[^o2] In electromagnetism the concept is known as [Lorentz reciprocity](wikipedia://en/2421650), a special case of which is the [reciprocity theorem](https://en.wikipedia.org/wiki/Reciprocity_%28electrical_networks%29) of electrical networks.

The reciprocity principle is also used in the analysis of structures.[^o3] When combined with [superposition](wikipedia://en/1201321), symmetry and anti-symmetry, it can be used to resolve complex load conditions.
