# Reduced derivative

::: {#o1 .subject cue=lead name="Reduced derivative"}

In [mathematics](wikipedia://en/18831), the **reduced derivative** is a generalization of the notion of [derivative](wikipedia://en/7921) that is well-suited to the study of functions of [bounded variation](wikipedia://en/330673). Although functions of bounded variation have derivatives in the sense of [Radon measures](wikipedia://en/521933), it is desirable to have a derivative that takes values in the same space as the functions themselves. Although the precise definition of the reduced derivative is quite involved, its key properties are quite easy to remember:

:::

- it is a multiple of the usual derivative wherever it exists;
- at jump points, it is a multiple of the jump vector.

The notion of reduced derivative appears to have been introduced by [Alexander Mielke](wikipedia://en/77078826) and Florian Theil in 2004.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* be a [separable](wikipedia://en/27855), [reflexive](wikipedia://en/210091) [Banach space](wikipedia://en/3989) with [norm](wikipedia://en/990534) || || and fix *T* > 0. Let BV<sub>−</sub>(\[0, *T*\]; *X*) denote the space of all [left-continuous](wikipedia://en/6122) functions *z* : \[0, *T*\] → *X* with bounded variation on \[0, *T*\].

For any function of time *f*, use subscripts +/− to denote the right/left continuous versions of *f*, i.e.

$$f_{+} (t) = \lim_{s \downarrow t} f(s);$$

$$f_{-} (t) = \lim_{s \uparrow t} f(s).$$

For any sub-interval \[*a*, *b*\] of \[0, *T*\], let Var(*z*, \[*a*, *b*\]) denote the variation of *z* over \[*a*, *b*\], i.e., the [supremum](https://en.wikipedia.org/wiki/Supremum)

$$\mathrm{Var}(z, [a, b]) = \sup \left\{ \left. \sum_{i = 1}^{k} \| z(t_{i}) - z(t_{i - 1}) \| \right| a = t_{0} < t_{1} < \cdots < t_{k} = b, k \in \mathbb{N} \right\}.$$

The first step in the construction of the reduced derivative is the "stretch" time so that *z* can be linearly interpolated at its jump points. To this end, define

$$\hat{\tau} \colon [0, T] \to [0, + \infty);$$

$$\hat{\tau}(t) = t + \int_{[0, t]} \| \mathrm{d} z \| = t + \mathrm{Var}(z, [0, t]).$$

The "stretched time" function *τ̂* is left-continuous (i.e. *τ̂* = *τ̂*<sub>−</sub>); moreover, *τ̂*<sub>−</sub> and *τ̂*<sub>\+</sub> are [strictly increasing](https://en.wikipedia.org/wiki/Strictly_increasing) and agree except at the (at most countable) jump points of *z*. Setting *T̂* = *τ̂*(*T*), this "stretch" can be inverted by

$$\hat{t} \colon [0, \hat{T}] \to [0, T];$$

$$\hat{t}(\tau) = \max \{ t \in [0, T] | \hat{\tau}(t) \leq \tau \}.$$

Using this, the stretched version of *z* is defined by

$$\hat{z} \in C^{0} ([0, \hat{T}]; X);$$

$$\hat{z}(\tau) = (1 - \theta) z_{-}(t) + \theta z_{+}(t)$$

where *θ* ∈ \[0, 1\] and

$$\tau = (1 - \theta) \hat{\tau}_{-} (t) + \theta \hat{\tau}_{+} (t).$$

The effect of this definition is to create a new function *ẑ* which "stretches out" the jumps of *z* by linear interpolation. A quick calculation shows that *ẑ* is not just continuous, but also lies in a [Sobolev space](wikipedia://en/611964):

$$\hat{z} \in W^{1, \infty} ([0, \hat{T}]; X);$$

$$\left\| \frac{\mathrm{d} \hat{z}}{\mathrm{d} \tau} \right\|_{L^{\infty} ([0, \hat{T}]; X)} \leq 1.$$

The derivative of *ẑ*(*τ*) with respect to *τ* is defined [almost everywhere](wikipedia://en/44688) with respect to [Lebesgue measure](wikipedia://en/18198). The **reduced derivative** of *z* is the [pull-back](https://en.wikipedia.org/wiki/Pull-back) of this derivative by the stretching function *τ̂* : \[0, *T*\] → \[0, *T̂*\]. In other words,

$$\mathrm{rd}(z) \colon [0, T] \to \{ x \in X | \| x \| \leq 1 \};$$

$$\mathrm{rd}(z)(t) = \frac{\mathrm{d} \hat{z}}{\mathrm{d} \tau} \left( \frac{\hat{\tau}_{-} (t) + \hat{\tau}_{+}(t)}{2} \right).$$

Associated with this pull-back of the derivative is the pull-back of Lebesgue measure on \[0, *T̂*\], which defines the **differential measure** *μ*<sub>*z*</sub>:

$$\mu_{z} ([t_{1}, t_{2})) = \lambda ([\hat{\tau}(t_{1}), \hat{\tau}(t_{2})) = \hat{\tau} (t_{2}) - \hat{\tau}(t_{1}) = t_{2} - t_{1} + \int_{[t_{1}, t_{2}]} \| \mathrm{d} z \|.$$

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The reduced derivative rd(*z*) is defined only *μ*<sub>*z*</sub>-almost everywhere on \[0, *T*\].
- If *t* is a jump point of *z*, then

$$\mu_{z} (\{ t \}) = \| z_{+}(t) - z_{-}(t) \| \mbox{ and } \mathrm{rd}(z)(t) = \frac{z_{+}(t) - z_{-}(t)}{\| z_{+}(t) - z_{-}(t) \|}.$$

- If *z* is differentiable on (*t*<sub>1</sub>, *t*<sub>2</sub>), then

$$\mu_{z} ((t_{1}, t_{2})) = \int_{t_{1}}^{t_{2}} 1 + \| \dot{z}(t) \| \, \mathrm{d} t$$

and, for *t* ∈ (*t*<sub>1</sub>, *t*<sub>2</sub>),

$$\mathrm{rd}(z)(t) = \frac{\dot{z}(t)}{1 + \| \dot{z}(t) \|},$$

- For 0 ≤ *s* \< *t* ≤ *T*,

$$\int_{[s, t)} \mathrm{rd}(z)(r) \, \mathrm{d} \mu_{z} (r) = \int_{[s, t)} \mathrm{d} z = z(t) - z(s).$$

:::
