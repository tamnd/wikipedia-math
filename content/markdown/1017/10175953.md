# 0†

::: {#o1 .subject cue=lead name="0†"}

In [set theory](wikipedia://en/27553), **0<sup>†</sup>** (**zero [dagger](https://en.wikipedia.org/wiki/†)**) is a particular subset of the natural numbers, first defined by [Robert M. Solovay](wikipedia://en/3160110) in unpublished work in the 1960s.[^o2] The definition is a bit awkward, because there might be *no* set of natural numbers satisfying the conditions. Specifically, if [ZFC](https://en.wikipedia.org/wiki/ZFC) is [consistent](wikipedia://en/75802), then ZFC + "0<sup>†</sup> does not exist" is consistent. ZFC + "0<sup>†</sup> exists" is not known to be inconsistent (and most set theorists believe that it is consistent). In other words, it is believed to be independent (see [large cardinal](https://en.wikipedia.org/wiki/Large_cardinal_property) for a discussion). It is usually formulated as follows:

:::

0<sup>†</sup> exists [if and only if](wikipedia://en/14922) there exists a non-trivial [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* : *L*\[*U*\] → *L*\[*U*\] for the relativized [Gödel constructible universe](https://en.wikipedia.org/wiki/Gödel_constructible_universe) *L*\[*U*\], where *U* is an [ultrafilter](wikipedia://en/31911) witnessing that some [cardinal](wikipedia://en/6173) *κ* is [measurable](wikipedia://en/248102).

If 0<sup>†</sup> exists, then a careful analysis of the embeddings of *L*\[*U*\] into itself reveals that there is a [closed unbounded subset](wikipedia://en/1251559) of *κ*, and a closed unbounded [proper class](https://en.wikipedia.org/wiki/Proper_class) of [ordinals](wikipedia://en/26547932) greater than *κ*, which together are *[indiscernible](wikipedia://en/4075543)* for the structure (*L*, ∈, *U*), and 0<sup>†</sup> is defined to be the set of [Gödel numbers](https://en.wikipedia.org/wiki/Gödel_number) of the true formulas about the indiscernibles in *L*\[*U*\].

Solovay showed that the existence of 0<sup>†</sup> follows from the existence of two measurable cardinals. It is traditionally considered a [large cardinal axiom](https://en.wikipedia.org/wiki/Large_cardinal_axiom), although it is not even a cardinal, let alone a large one.
