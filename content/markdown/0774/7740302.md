# Automatic sequence

::: {#o1 .subject cue=lead name="Automatic sequence"}

In [mathematics](wikipedia://en/18831) and [theoretical computer science](wikipedia://en/323392), an **automatic sequence** (also called a ***k*-automatic sequence** or a ***k*-recognizable sequence** when one wants to indicate that the base of the numerals used is *k*) is an infinite [sequence](wikipedia://en/27838) of terms characterized by a [finite automaton](https://en.wikipedia.org/wiki/Finite_automaton). The *n*-th term of an automatic sequence *a*(*n*) is a mapping of the final state reached in a finite automaton accepting the digits of the number *n* in some fixed [base](wikipedia://en/701207) *k*.[^o2][^o3]

:::

An **automatic set** is a set of non-negative integers *S* for which the sequence of values of its characteristic function χ<sub>*S*</sub> is an automatic sequence; that is, *S* is *k*-automatic if χ<sub>*S*</sub>(*n*) is *k*-automatic, where χ<sub>*S*</sub>(*n*) = 1 if *n* $\in$ *S* and 0 otherwise.[^o4][^o8]

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Automatic sequences may be defined in a number of ways, all of which are equivalent. Four common definitions are as follows.

### Automata-theoretic {#Automata-theoretic}

Let *k* be a positive [integer](wikipedia://en/14563), and let *D* = (*Q*, Σ<sub>*k*</sub>, δ, *q<sub>0</sub>*, Δ, τ) be a [deterministic finite automaton](wikipedia://en/653404) *with output*, where

- *Q* is the finite [set](wikipedia://en/26691) of states;
- the input alphabet Σ<sub>*k*</sub> consists of the set {0,1,...,*k*-1} of possible digits in [base](wikipedia://en/701207)-*k* notation;
- δ : *Q* × Σ<sub>*k*</sub> → *Q* is the transition function;
- *q<sub>0</sub>* ∈ *Q* is the initial state;
- the output alphabet Δ is a finite set; and
- τ : *Q* → Δ is the output function mapping from the set of internal states to the output alphabet.

Extend the transition function δ from acting on single digits to acting on strings of digits by defining the action of δ on a string *s* consisting of digits *s*<sub>1</sub>*s*<sub>2</sub>...*s*<sub>*t*</sub> as:

δ(*q*,*s*) = δ(δ(*q*, *s*<sub>1</sub>*s*<sub>2</sub>...*s*<sub>*t*-1</sub>), *s*<sub>*t*</sub>).

Define a function *a* from the set of positive integers to the output alphabet Δ as follows:

*a*(*n*) = τ(δ(*q<sub>0</sub>*,*s*(*n*))),

where *s*(*n*) is *n* written in base *k*. Then the sequence *a* = *a*(1)*a*(2)*a*(3)... is a *k*-automatic sequence.[^o2]

An automaton reading the base *k* digits of *s*(*n*) starting with the most significant digit is said to be *direct reading*, while an automaton starting with the least significant digit is *reverse reading*.[^o8] The above definition holds whether *s*(*n*) is direct or reverse reading.[^o9]

### Substitution {#Substitution}

Let $\varphi$ be a *k*-[uniform morphism](https://en.wikipedia.org/wiki/Uniform_morphism) of a [free monoid](wikipedia://en/523166) $\Sigma^*$ and let $\tau$ be a *coding* (that is, a $1$-uniform morphism), as in the automata-theoretic case. If $w$ is a [fixed point](wikipedia://en/449738) of $\varphi$—that is, if $w = \varphi(w)$—then $s = \tau(w)$ is a *k*-automatic sequence.[^o11] Conversely, every *k*-automatic sequence is obtainable in this way.[^o8] This result is due to [Cobham](wikipedia://en/68162815), and it is referred to in the literature as *Cobham's little theorem*.[^o3][^o12]

### *k*-kernel {#k-kernel}

Let *k* ≥ 2. The *k-kernel* of the sequence *s*(*n*) is the set of subsequences

$$K_{k}(s) = \{s(k^e n + r) : e \geq 0 \text{ and } 0 \leq r \leq k^e - 1\}.$$

In most cases, the *k*-kernel of a sequence is infinite. However, if the *k*-kernel is finite, then the sequence *s*(*n*) is *k*-automatic, and the converse is also true. This is due to Eilenberg.[^o14][^o15][^o16]

It follows that a *k*-automatic sequence is necessarily a sequence on a finite alphabet.

### Formal power series {#Formal_power_series}

Let *u*(*n*) be a sequence over an alphabet Σ and suppose that there is an [injective function](wikipedia://en/45196) β from Σ to the [finite field](wikipedia://en/11615) **F**<sub>*q*</sub>, where *q* = *p*<sup>*n*</sup> for some prime *p*. The associated [formal power series](wikipedia://en/60012) is

$$\sum_{i \geq 0} \beta(u(i)) X^i .$$

Then the sequence *u* is *q*-automatic if and only if this formal [power series](wikipedia://en/59958) is [algebraic](wikipedia://en/974169) over **F**<sub>*q*</sub>(*X*). This result is due to Christol, and it is referred to in the literature as *Christol's theorem*.[^o18]

:::

## History {#History}

Automatic sequences were introduced by [Büchi](wikipedia://en/6736044) in 1960,[^o20] although his paper took a more logico-theoretic approach to the matter and did not use the terminology found in this article. The notion of automatic sequences was further studied by Cobham in 1972, who called these sequences "uniform [tag sequences](https://en.wikipedia.org/wiki/Tag_system)".[^o12]

The term "automatic sequence" first appeared in a paper of Deshouillers.[^o21]

## Examples {#Examples}

The following sequences are automatic:

### Thue–Morse sequence {#Thue–Morse_sequence}

*Image: ThueMorseAutomaton.png.* DFAO generating the Thue–Morse sequence

The [Thue–Morse sequence](wikipedia://en/491903) *t*(*n*) () is the [fixed point](wikipedia://en/449738) of the morphism 0 → 01, 1 → 10. Since the *n*-th term of the Thue–Morse sequence counts the number of ones [modulo](https://en.wikipedia.org/wiki/Modulo_operation) 2 in the base-2 representation of *n*, it is generated by the two-state deterministic finite automaton with output pictured here, where being in state *q*<sub>0</sub> indicates there are an even number of ones in the representation of *n* and being in state *q*<sub>1</sub> indicates there are an odd number of ones. Hence, the Thue–Morse sequence is 2-automatic.

### Period-doubling sequence {#Period-doubling_sequence}

The *n*-th term of the period-doubling sequence *d*(*n*) () is determined by the parity of the exponent of the highest power of 2 dividing *n*. It is also the fixed point of the morphism 0 → 01, 1 → 00.[^o26] Starting with the initial term *w* = 0 and iterating the 2-uniform morphism φ on *w* where φ(0) = 01 and φ(1) = 00, it is evident that the period-doubling sequence is the fixed-point of φ(*w*) and thus it is 2-automatic.

### Rudin–Shapiro sequence {#Rudin–Shapiro_sequence}

The *n*-th term of the [Rudin–Shapiro sequence](wikipedia://en/20256156) *r*(*n*) () is determined by the number of consecutive ones in the base-2 representation of *n*. The 2-kernel of the Rudin–Shapiro sequence[^o28] is

$$\begin{aligned} r(2n) &= r(n), \\ r(4n+1) &= r(n), \\ r(8n+7) &= r(2n+1), \\ r(16n+3) &= r(8n+3), \\ r(16n+11) &= r(4n+3). \end{aligned}$$

Since the 2-kernel consists only of *r*(*n*), *r*(2*n* + 1), *r*(4*n* + 3), and *r*(8*n* + 3), it is finite and thus the Rudin–Shapiro sequence is 2-automatic.

### Other sequences {#Other_sequences}

Both the [Baum–Sweet sequence](wikipedia://en/20236431)[^o30] () and the [regular paperfolding sequence](wikipedia://en/20313560)[^o31][^o32][^o33] () are automatic. In addition, the general paperfolding sequence with a periodic sequence of folds is also automatic.[^o34]

:::

## Properties {#Properties}

Automatic sequences exhibit a number of interesting properties. A non-exhaustive list of these properties is presented below.

- Every automatic sequence is a [morphic word](wikipedia://en/37432570).[^o37]
- For *k* ≥ 2 and *r* ≥ 1, a sequence is *k*-automatic if and only if it is *k*<sup>*r*</sup>-automatic. This result is due to Eilenberg.[^o38]
- For *h* and *k* [multiplicatively independent](wikipedia://en/50027042), a sequence is both *h*-automatic and *k*-automatic if and only if it is ultimately periodic.[^o39] This result is due to Cobham also known as [Cobham's theorem](wikipedia://en/68044793),[^o40] with a multidimensional generalisation due to Semenov.[^o41][^o42]
- If *u*(*n*) is a *k*-automatic sequence over an alphabet Σ and *f* is a [uniform morphism](https://en.wikipedia.org/wiki/Uniform_morphism) from Σ<sup>∗</sup> to another alphabet Δ<sup>∗</sup>, then *f*(*u*) is a *k*-automatic sequence over Δ.[^o43]
- If *u*(*n*) is a *k*-automatic sequence, then the sequences *u*(*k*<sup>*n*</sup>) and *u*(*k*<sup>*n*</sup> − 1) are ultimately periodic.[^o44] Conversely, if *u*(*n*) is an ultimately periodic sequence, then the sequence *v* defined by *v*(*k*<sup>*n*</sup>) = *u*(*n*) and otherwise zero is *k*-automatic.[^o45]
- A real number with an automatic decimal expansion in a given base is either rational or [transcendental](wikipedia://en/30325).[^o46]
- A real number with an automatic [continued fraction](wikipedia://en/739199) expansion is either [quadratic irrational](wikipedia://en/305331) or transcendental.[^o47]

:::

## Proving and disproving automaticity {#Proving_and_disproving_automaticity}

Given a candidate sequence $s = (s_n)_{n \ge 0}$, it is usually easier to disprove its automaticity than to prove it. By the *k*-kernel characterization of *k*-automatic sequences, it suffices to produce infinitely many distinct elements in the *k*-kernel $K_k(s)$ to show that $s$ is not *k*-automatic. Heuristically, one might try to prove automaticity by checking the agreement of terms in the *k*-kernel, but this can occasionally lead to wrong guesses. For example, let

$$t = 011010011\dots$$

be the Thue–Morse word. Let $s$ be the word given by concatenating successive terms in the sequence of run-lengths of $t$. Then $s$ begins

$$s = 12112221\dots..$$

It is known that $s$ is the fixed point $h^{\omega}(1)$ of the morphism

$$h(1) = 121, h(2) = 12221.$$

The word $s$ is not 2-automatic, but certain elements of its 2-kernel agree for many terms. For example, $s_{16n+1} = s_{64n+1} \text{ for } 0 \le n \le 1864134$

but not for $n = 1864135$.[^o49]

Given a sequence that is conjectured to be automatic, there are a few useful approaches to proving it actually is. One approach is to directly construct a [deterministic automaton](https://en.wikipedia.org/wiki/Deterministic_automaton) with output that gives the sequence. Let $(s_n)_{n \ge 0}$ written in the alphabet $\Delta$, and let $(n)_k$ denote the base-$k$ expansion of $n$. Then the sequence $s = (s_n)_{n \ge 0}$ is $k$-automatic if and only each of the fibres

$$I_k(s,d) := \{(n)_k \mid s_n = d\}$$

is a regular language.[^o50] Checking regularity of the fibres can often be done using the [pumping lemma for regular languages](wikipedia://en/2070351).

If $s_k(n)$ denotes the sum of the digits in the base-$k$ expansion of $n$ and $p(X)$ is a polynomial with non-negative integer coefficients, and if $k \ge 2$, $m \ge 1$ are integers, then the sequence

$$(s_k(p(n)) \pmod{m})_{n \ge 0}$$

is $k$-automatic if and only if $\deg p \le 1$ or $m \mid k-1$.[^o51]

## 1-automatic sequences {#1-automatic_sequences}

*k*-automatic sequences are normally only defined for *k* ≥ 2.[^o2] The concept can be extended to *k* = 1 by defining a 1-automatic sequence to be a sequence whose *n*-th term depends on the [unary notation](wikipedia://en/32316) for *n*; that is, (1)<sup>*n*</sup>. Since a finite state automaton must eventually return to a previously visited state, all 1-automatic sequences are ultimately periodic.

::: {#o54 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

Automatic sequences are robust against variations to either the definition or the input sequence. For instance, as noted in the automata-theoretic definition, a given sequence remains automatic under both direct and reverse reading of the input sequence. A sequence also remains automatic when an alternate set of digits is used or when the base is negated; that is, when the input sequence is represented in base −*k* instead of in base *k*.[^o55] However, in contrast to using an alternate set of digits, a change of base may affect the automaticity of a sequence.

The domain of an automatic sequence can be extended from the natural numbers to the integers via *two-sided* automatic sequences. This stems from the fact that, given *k* ≥ 2, every integer can be represented uniquely in the form $\sum_{0 \leq i \leq r} a_{i}(-k)^{i} ,$ where $a_{i} \in \{0, \dots, k-1\}$. Then a two-sided infinite sequence *a*(*n*)<sub>*n* $\in \mathbb{Z}$</sub> is (−*k*)-automatic if and only if its subsequences *a*(*n*)<sub>n ≥ 0</sub> and *a*(−*n*)<sub>n ≥ 0</sub> are *k*-automatic.[^o56]

The alphabet of a *k*-automatic sequence can be extended from finite size to infinite size via [*k*-regular sequences](wikipedia://en/49645022).[^o57] The *k*-regular sequences can be characterized as those sequences whose *k*-kernel is finitely-generated. Every bounded *k*-regular sequence is automatic.[^o58]

:::

## Logical approach {#Logical_approach}

For many 2-automatic sequences $s = (s_n)_{n \ge 0}$, the map $n \mapsto s_n$ has the property that the first-order theory $\text{FO}(\mathbb{N},+,0,1,n \mapsto s_n)$ is [decidable](wikipedia://en/913118). Since many non-trivial properties of automatic sequences can be written in [first-order logic](wikipedia://en/10983), it is possible to prove these properties mechanically by executing the decision procedure.[^o60]

For example, the following properties of the Thue–Morse word can all be verified mechanically in this way:

- The Thue–Morse word is overlap-free, i.e., it does not contain a word of the form $cxcxc$ where $c$ is a single letter and $w$ is a possibly empty word.
- A non-empty word $x$ is *bordered* if there is a non-empty word $w$ and a possibly empty word $y$ with $x = wyw$. The Thue–Morse word contains a bordered factor for each length greater than 1.[^o61]
- There is an unbordered factor of length $n$ in the Thue–Morse word if and only if $(n)_2 \notin 1(01^*0)^*10^*1$ where $(n)_2$ denotes the binary representation of $n$.[^o62]

The software Walnut,[^o63][^o64] developed by Hamoon Mousavi, implements a decision procedure for deciding many properties of certain automatic words, such as the Thue–Morse word. This implementation is a consequence of the above work on the logical approach to automatic sequences.
