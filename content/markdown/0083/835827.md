# Empty string

::: {#o1 .subject cue=lead name="Empty string"}

In [formal language theory](https://en.wikipedia.org/wiki/Formal_language_theory), the **empty string**, also known as the **empty word** or **null string**, is the unique [string](wikipedia://en/27701) of length zero.

:::

## Formal theory {#Formal_theory}

Formally, a string is a finite, ordered sequence of [characters](https://en.wikipedia.org/wiki/Character_%28symbol%29) such as letters, digits or spaces. The empty string is the special case where the sequence has length zero, so there are no symbols in the string. There is only one empty string, because two strings are only different if they have different lengths or a different sequence of symbols. In formal treatments,[^o3] the empty string is denoted with **[ε](https://en.wikipedia.org/wiki/Ε)** or sometimes **[Λ](https://en.wikipedia.org/wiki/Λ)** or **[λ](https://en.wikipedia.org/wiki/Λ)**.

The empty string should not be confused with the empty language [∅](https://en.wikipedia.org/wiki/∅), which is a [formal language](wikipedia://en/10939) (i.e. a set of strings) that contains no strings, not even the empty string.

The empty string has several properties:

- \|ε| = 0. Its [string length](wikipedia://en/27701#Formal_theory) is zero.
- ε ⋅ s = s ⋅ ε = s. The empty string is the [identity element](wikipedia://en/14962) of the [concatenation](wikipedia://en/64474) operation. The set of all strings forms a [free monoid](wikipedia://en/523166) with respect to ⋅ and ε.
- ε<sup>R</sup> = ε. Reversal of the empty string produces the empty string, so the empty string is a [palindrome](https://en.wikipedia.org/wiki/Palindrome).
- $\forall c \in s: P(c)$. Statements that are about all characters in a string are [vacuously true](wikipedia://en/51672).
- The empty string precedes any other string under [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order), because it is the shortest of all strings.[^o4]

In [context-free grammars](wikipedia://en/6759), a [production rule](https://en.wikipedia.org/wiki/Production_%28computer_science%29) that allows a [symbol](https://en.wikipedia.org/wiki/Symbol_%28logic%29) to produce the empty string is known as an ε-production, and the symbol is said to be "nullable".

## Use in programming languages {#Use_in_programming_languages}

In most [programming languages](wikipedia://en/23015), the term "string" often refers to instances of a [data type](https://en.wikipedia.org/wiki/Data_type) and thus they're a concept distinct from the one in the formal theory. Such strings are typically stored at distinct [memory addresses](https://en.wikipedia.org/wiki/Memory_address) (locations) and thus have an identity. Thus, representatives of the same formal string (e.g., the empty string) may be stored in two or more places in memory and they can be taken as names of the formal empty string.

In this way, there could be multiple representatives of the empty string in memory, in contrast with the formal theory definition, for which there is only one possible empty string. However, a "string comparison function" would indicate that all of these representatives are equal to each other.

Even a string of length zero can require memory to store it, depending on the format being used. In most programming languages, the empty string is distinct from a [null reference](https://en.wikipedia.org/wiki/Null_reference) (or null pointer) because a null reference points to no string at all, not even the empty string. The empty string is a legitimate string, upon which most string operations should work. Some languages treat some or all of the following in similar ways: empty strings, null references, the integer 0, the floating point number 0, the Boolean value [false](wikipedia://en/229823), the [ASCII](https://en.wikipedia.org/wiki/ASCII) character [NUL](https://en.wikipedia.org/wiki/Null_character), or other such values.

The empty string is usually represented similarly to other strings. In implementations with string terminating character ([null-terminated strings](https://en.wikipedia.org/wiki/Null-terminated_string) or plain text lines), the empty string is indicated by the immediate use of this terminating character.

Different functions, methods, macros, or [idioms](https://en.wikipedia.org/wiki/Programming_idiom) exist for checking if a string is empty in different languages.

### Representations of the empty string {#Representations_of_the_empty_string}

The empty string is a syntactically valid representation of [zero](https://en.wikipedia.org/wiki/Zero) in [positional notation](wikipedia://en/437052) (in any base), which does not contain [leading zeros](https://en.wikipedia.org/wiki/Leading_zero). Since the empty string does not have a standard visual representation outside of formal language theory, the number zero is traditionally represented by a single [decimal digit](https://en.wikipedia.org/wiki/Decimal_digit) **0** instead.

Zero-filled memory area, interpreted as a [null-terminated string](https://en.wikipedia.org/wiki/Null-terminated_string), is an empty string.

Empty lines of text show the empty string. This can occur from two consecutive [EOLs](https://en.wikipedia.org/wiki/End_of_line), as often occur in [text files](https://en.wikipedia.org/wiki/Text_file). This is sometimes used in [text processing](https://en.wikipedia.org/wiki/Text_processing) to separate [paragraphs](https://en.wikipedia.org/wiki/Paragraph), e.g. in [MediaWiki](https://en.wikipedia.org/wiki/MediaWiki).
