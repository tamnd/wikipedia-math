# Complete partial order

::: {#o1 .subject cue=lead name="Complete partial order"}

In [mathematics](wikipedia://en/18831), the phrase **complete partial order** is variously used to refer to at least three similar, but distinct, classes of [partially ordered sets](wikipedia://en/23572), characterized by particular [completeness properties](wikipedia://en/549445). Complete partial orders play a central role in [theoretical computer science](wikipedia://en/323392): in [denotational semantics](wikipedia://en/55275) and [domain theory](wikipedia://en/325077).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

The term **complete partial order**, abbreviated **cpo**, has several possible meanings depending on context.

A partially ordered set is a **directed-complete partial order** (**dcpo**) if each of its [directed subsets](wikipedia://en/9165) has a [supremum](https://en.wikipedia.org/wiki/Supremum). (A subset of a partial order is directed if it is [non-empty](wikipedia://en/9566) and every pair of elements has an upper bound in the subset.) In the literature, dcpos sometimes also appear under the label **up-complete poset**.

A **pointed directed-complete partial order** (**pointed dcpo**, sometimes abbreviated **cppo**), is a dcpo with a [least element](https://en.wikipedia.org/wiki/Least_element) (usually denoted $\bot$). Formulated differently, a pointed dcpo has a supremum for every directed *or empty* subset. The term **chain-complete partial order** is also used, because of the characterization of pointed dcpos as posets in which every [chain](https://en.wikipedia.org/wiki/Chain_%28ordered_set%29) has a supremum.

A related notion is that of **ω-complete partial order** (**ω-cpo**). These are posets in which every ω-chain ($x_1 \leq x_2 \leq x_3 \leq ...$) has a supremum that belongs to the poset. The same notion can be extended to other [cardinalities](wikipedia://en/6174) of chains. [^o4]

Every dcpo is an ω-cpo, since every ω-chain is a directed set, but the [converse](wikipedia://en/155941) is not true. However, every ω-cpo with a [basis](wikipedia://en/325077#Bases_of_domains) is also a dcpo (with the same basis).[^o5] An ω-cpo (dcpo) with a basis is also called a **continuous** ω-cpo (or continuous dcpo).

Note that *complete partial order* is never used to mean a poset in which *all* subsets have suprema; the terminology [complete lattice](wikipedia://en/44777) is used for this concept.

Requiring the existence of directed suprema can be motivated by viewing directed sets as generalized approximation sequences and suprema as *limits* of the respective (approximative) computations. This intuition, in the context of denotational semantics, was the motivation behind the development of [domain theory](wikipedia://en/325077).

The [dual](wikipedia://en/600618) notion of a directed-complete partial order is called a **filtered-complete partial order**. However, this concept occurs far less frequently in practice, since one usually can work on the dual order explicitly.

By analogy with the [Dedekind–MacNeille completion](wikipedia://en/16667323) of a partially ordered set, every partially ordered set can be extended uniquely to a minimal dcpo.[^o4]

## Examples {#Examples}

- Every finite poset is directed complete.
- All [complete lattices](wikipedia://en/44777) are also directed complete.
- For any poset, the set of all non-empty [filters](wikipedia://en/19719), ordered by [subset inclusion](https://en.wikipedia.org/wiki/Inclusion_%28set_theory%29), is a dcpo. Together with the empty filter it is also pointed. If the order has binary [meets](wikipedia://en/3956618), then this construction (including the empty filter) actually yields a [complete lattice](wikipedia://en/44777).
- Every set *S* can be turned into a pointed dcpo by adding a least element ⊥ and introducing a flat order with ⊥ ≤ *s* and s ≤ *s* for every *s* in *S* and no other order relations.
- The set of all [partial functions](wikipedia://en/23577) on some given set *S* can be ordered by defining *f* ≤ *g* if and only if *g* extends *f*, i.e. if the [domain](wikipedia://en/50263) of *f* is a subset of the domain of *g* and the values of *f* and *g* agree on all inputs for which they are both defined. (Equivalently, *f* ≤ *g* if and only if *f* ⊆ *g* where *f* and *g* are identified with their respective [graphs](wikipedia://en/87352).) This order is a pointed dcpo, where the least element is the nowhere-defined partial function (with empty domain). In fact, ≤ is also [bounded complete](https://en.wikipedia.org/wiki/Bounded_complete). This example also demonstrates why it is not always natural to have a greatest element.
- The set of all [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) [subsets](wikipedia://en/27631) of a [vector space](wikipedia://en/32370) *V*, ordered by [inclusion](https://en.wikipedia.org/wiki/Inclusion_%28set_theory%29).
- The set of all partial [choice functions](wikipedia://en/1432664) on a collection of [non-empty](wikipedia://en/9566) sets, ordered by restriction.
- The set of all [prime ideals](wikipedia://en/24928) of a [ring](wikipedia://en/48404), ordered by inclusion.
- The [specialization order](https://en.wikipedia.org/wiki/Specialization_order) of any [sober space](wikipedia://en/602490) is a dcpo.
- Let us use the term "[deductive system](https://en.wikipedia.org/wiki/Deductive_system)" as a set of [sentences](wikipedia://en/2129527) closed under consequence (for defining notion of consequence, let us use e.g. [Alfred Tarski](wikipedia://en/59920)'s algebraic approach[^o8][^o9]). There are interesting theorems that concern a set of deductive systems being a directed-complete partial ordering.[^o10][^o8] Also, a set of deductive systems can be chosen to have a least element in a natural way (so that it can be also a pointed dcpo), because the set of all consequences of the empty set (i.e. "the set of the logically provable/logically valid sentences") is (1) a deductive system (2) contained by all deductive systems.

## Characterizations {#Characterizations}

([Markowsky's theorem](https://en.wikipedia.org/wiki/Markowsky's_theorem_%28order_theory%29)) An ordered set is a dcpo if and only if it is chain complete; i.e., every non-empty [chain](https://en.wikipedia.org/wiki/Chain_%28order_theory%29) has a supremum.

As a corollary, an ordered set is a pointed dcpo if and only if every (possibly empty) chain has a supremum, i.e., if and only if it is [chain-complete](https://en.wikipedia.org/wiki/Chain-complete_partial_order).[^o4][^o13][^o14][^o15] Proofs rely on the [axiom of choice](wikipedia://en/840).

Alternatively, an ordered set $P$ is a pointed dcpo if and only if every [order-preserving](https://en.wikipedia.org/wiki/Order-preserving) self-map of $P$ has a least [fixpoint](https://en.wikipedia.org/wiki/Fixpoint).

:::

## Continuous functions and fixed-points {#Continuous_functions_and_fixed-points}

A [function](wikipedia://en/185427) *f* between two dcpos *P* and *Q* is called **[(Scott) continuous](wikipedia://en/743106)** if it maps directed sets to directed sets while preserving their suprema:

- $f(D) \subseteq Q$ is directed for every directed $D \subseteq P$.
- $f(\sup D) = \sup f(D)$ for every directed $D \subseteq P$.

Note that every continuous function between dcpos is a [monotone function](https://en.wikipedia.org/wiki/Monotone_function#Monotonicity_in_order_theory). This notion of continuity is equivalent to the [topological continuity](https://en.wikipedia.org/wiki/Topological_continuity) induced by the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology).

The set of all continuous functions between two dcpos *P* and *Q* is denoted \[*P* → *Q*\]. Equipped with the [pointwise order](wikipedia://en/4786797#Pointwise_relations), this is again a dcpo, and pointed whenever *Q* is pointed. Thus the complete partial orders with Scott-continuous maps form a [cartesian closed](wikipedia://en/237037) [category](wikipedia://en/53759).[^o17]

Every order-preserving self-map *f* of a pointed dcpo (*P*, ⊥) has a least fixed-point.[^o18] If *f* is continuous then this fixed-point is equal to the supremum of the [iterates](wikipedia://en/1448702) (⊥, *f*(⊥), *f*(*f*(⊥)), ... *f*<sup>*n*</sup>(⊥), ...) of ⊥ (see also the [Kleene fixed-point theorem](wikipedia://en/1234125)).

Another fixed point theorem is the [Bourbaki–Witt theorem](wikipedia://en/1011270), stating that if $f$ is a function from a dcpo to itself with the property that $f(x) \geq x$ for all $x$, then $f$ has a fixed point. This theorem, in turn, can be used to prove that [Zorn's lemma](wikipedia://en/51442) is a consequence of the axiom of choice.[^o19][^o20]
