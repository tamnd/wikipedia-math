# Continuity correction

::: {#o1 .subject cue=lead name="Continuity correction"}

In [mathematics](wikipedia://en/18831), a **continuity correction** is an adjustment made when a [discrete object](wikipedia://en/8492) is approximated using a [continuous object](wikipedia://en/6122).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

### Binomial {#Binomial}

If a [random variable](wikipedia://en/25685) *X* has a [binomial distribution](wikipedia://en/3876) with parameters *n* and *p*, i.e., *X* is distributed as the number of "successes" in *n* independent [Bernoulli trials](wikipedia://en/102653) with probability *p* of success on each trial, then

$$P(X\leq x) = P(X<x+1)$$

for any *x* ∈ {0, 1, 2, ... *n*}. If *np* and *np*(1 − *p*) are large (sometimes taken as both ≥ 5), then the probability above is fairly well approximated by

$$P(Y\leq x+1/2)$$

where *Y* is a [normally distributed](wikipedia://en/21462) random variable with the same [expected value](wikipedia://en/9653) and the same [variance](wikipedia://en/32344) as *X*, i.e., E(*Y*) = *np* and var(*Y*) = *np*(1 − *p*). This addition of 1/2 to *x* is a continuity correction.

### Poisson {#Poisson}

A continuity correction can also be applied when other discrete distributions supported on the integers are approximated by the normal distribution. For example, if *X* has a [Poisson distribution](wikipedia://en/23009144) with expected value λ then the variance of *X* is also λ, and

$$P(X\leq x)=P(X<x+1)\approx P(Y\leq x+1/2)$$

if *Y* is normally distributed with expectation and variance both λ.

:::

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

Before the ready availability of [statistical software](https://en.wikipedia.org/wiki/Statistical_software) having the ability to evaluate [probability distribution](wikipedia://en/23543) functions accurately, continuity corrections played an important role in the practical application of [statistical tests](wikipedia://en/30284) in which the [test statistic](wikipedia://en/1416975) has a discrete distribution: it had a special importance for manual calculations. A particular example of this is the [binomial test](wikipedia://en/935655), involving the [binomial distribution](wikipedia://en/3876), as in [checking whether a coin is fair](wikipedia://en/1604994). Where extreme accuracy is not necessary, computer calculations for some ranges of parameters may still rely on using continuity corrections to improve accuracy while retaining simplicity.

:::
