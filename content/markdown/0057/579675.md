# Linear logic

::: {#o1 .subject cue=lead name="Linear logic"}

**Linear logic** is a [substructural logic](wikipedia://en/412909) proposed by French [logician](https://en.wikipedia.org/wiki/Logician) [Jean-Yves Girard](wikipedia://en/579673) as a refinement of [classical](wikipedia://en/55868) and [intuitionistic logic](wikipedia://en/169262), joining the [dualities](wikipedia://en/609737#Duality_in_logic_and_set_theory) of the former with many of the [constructive](https://en.wikipedia.org/wiki/Constructivism_%28mathematics%29) properties of the latter.[^n1] Although the logic has also been studied for its own sake, more broadly, ideas from linear logic have been influential in fields such as [programming languages](https://en.wikipedia.org/wiki/Programming_languages), [game semantics](wikipedia://en/617121), and [quantum physics](https://en.wikipedia.org/wiki/Quantum_physics) (because linear logic can be seen as the logic of [quantum information theory](https://en.wikipedia.org/wiki/Quantum_information_theory)),[^n2] as well as [linguistics](https://en.wikipedia.org/wiki/Linguistics),[^n3] particularly because of its emphasis on resource-boundedness, duality, and interaction.

:::

Linear logic lends itself to many different presentations, explanations, and intuitions. [Proof-theoretically](wikipedia://en/183478), it derives from an analysis of classical [sequent calculus](wikipedia://en/252329) in which uses of (the [structural rules](wikipedia://en/697666)) [contraction](https://en.wikipedia.org/wiki/Idempotency_of_entailment) and [weakening](wikipedia://en/693185) are carefully controlled. Operationally, this means that logical deduction is no longer merely about an ever-expanding collection of persistent "truths", but also a way of manipulating *resources* that cannot always be duplicated or thrown away at will. In terms of simple [denotational models](wikipedia://en/55275), linear logic may be seen as refining the interpretation of intuitionistic logic by replacing [cartesian (closed) categories](https://en.wikipedia.org/wiki/Cartesian_closed_categories) by [symmetric monoidal (closed) categories](https://en.wikipedia.org/wiki/Symmetric_monoidal_categories), or the interpretation of classical logic by replacing [Boolean algebras](https://en.wikipedia.org/wiki/Boolean_algebras) by [C\*-algebras](https://en.wikipedia.org/wiki/C*-algebras).

## Connectives, duality, and polarity {#Connectives,_duality,_and_polarity}

### Syntax {#Syntax}

The [language](https://en.wikipedia.org/wiki/Language_%28logic%29) $\mathcal{L}$ of classical propositional linear logic can be [defined recursively](wikipedia://en/1047605) as follows.

1. If $\varphi$ is an atomic formula, then $\varphi$ is a formula of $\mathcal{L}$.
1. If $\varphi$ is an atomic formula, then $\varphi^\bot$ is a formula of $\mathcal{L}$.
1. If $\varphi$ and $\psi$ are formulas of $\mathcal{L}$, then $\varphi\otimes \psi$ is too.
1. If $\varphi$ and $\psi$ are formulas of $\mathcal{L}$, then $\varphi$ $\text{⅋}$ $\psi$ is too.
1. If $\varphi$ and $\psi$ are formulas of $\mathcal{L}$, then $\varphi\ \& \ \psi$ is too.
1. If $\varphi$ and $\psi$ are formulas of $\mathcal{L}$, then $\varphi\oplus \psi$ is too.
1. If $\varphi$ is a formula of $\mathcal{L}$, then $!\varphi$ is too.
1. If $\varphi$ is a formula of $\mathcal{L}$, then $? \varphi$ is too.
1. $\bf{1}$ is a formula of $\mathcal{L}$.
1. $\bot$ is a formula of $\mathcal{L}$.
1. $\top$ is a formula of $\mathcal{L}$.
1. $\bf{0}$ is a formula of $\mathcal{L}$.

Here $p$ and $p^{\perp}$ range over [logical atoms](wikipedia://en/4472066). For reasons to be explained below, the [connectives](wikipedia://en/18153) ⊗, ⅋, 1, and ⊥ are called *multiplicatives*, the connectives &, ⊕, ⊤, and 0 are called *additives*, and the connectives ! and ? are called *exponentials*. We can further employ the following terminology:

::: {#o12 .table cue=table}

| Symbol | Name |  |  |  |
|---|---|---|---|---|
| ⊗ | multiplicative [conjunction](wikipedia://en/18152) | times | tensor |  |
| ⊕ | additive [disjunction](wikipedia://en/7962) | plus |  |  |
| & | additive [conjunction](wikipedia://en/18152) | with |  |  |
| ⅋ | multiplicative [disjunction](wikipedia://en/7962) | par |  |  |
| ! | of course | bang |  |  |
| ? | why not | quest |  |  |

:::

Binary connectives ⊗, ⊕, & and ⅋ are associative and commutative; 1 is the unit for ⊗, 0 is the unit for ⊕, ⊥ is the unit for ⅋ and ⊤ is the unit for &.

Every proposition $A$ in CLL has a **dual** $A^{\perp}$, defined as follows:

| $(p)^{\perp} = p^{\perp}$ |  |  | $(p^{\perp})^{\perp} = p$ |  |  |
|---|---|---|---|---|---|
| $(A \otimes B)^{\perp} = A^{\perp} \text{⅋} B^{\perp}$ |  |  | $(A \text{⅋} B)^{\perp} = A^{\perp} \otimes B^{\perp}$ |  |  |
| $(A \oplus B)^{\perp} = A^{\perp} \& B^{\perp}$ |  |  | $(A \& B)^{\perp} = A^{\perp} \oplus B^{\perp}$ |  |  |
| $(1)^{\perp} = \perp$ |  |  | $(\perp)^{\perp} = 1$ |  |  |
| $(0)^{\perp} = \top$ |  |  | $(\top)^{\perp} = 0$ |  |  |
| $(!A)^{\perp} = ?(A^{\perp})$ |  |  | $(?A)^{\perp} = !(A^{\perp})$ |  |  |

*Classification of connectives*

::: {#o13 .table cue=table name="Classification of connectives"}

|  | add | mul | exp |
|---|---|---|---|
| pos | ⊕ 0 | ⊗ 1 | ! |
| neg | & ⊤ | ⅋ ⊥ | ? |

:::

Observe that $(-)^{\perp}$ is an [involution](wikipedia://en/293450), i.e., $A^{\perp\perp} = A$ for all propositions. $A^{\perp}$ is also called the *linear negation* of $A$.

The columns of the table suggest another way of classifying the connectives of linear logic, termed **polarity**: the connectives negated in the left column (⊗, ⊕, 1, 0, !) are called *positive*, while their duals on the right (⅋, &, ⊥, ⊤, ?) are called *negative*; cf. table on the right.

Linear implication is not included in the grammar of connectives, but is definable in CLL using linear negation and multiplicative disjunction, by $A \text{⊸} B:= A^{\perp} \text{⅋} B$. The connective ⊸ is sometimes pronounced "[lollipop](https://en.wikipedia.org/wiki/Lollipop)", owing to its shape.

## Sequent calculus presentation {#Sequent_calculus_presentation}

One way of defining linear logic is as a [sequent calculus](wikipedia://en/252329). We use the letters $\Gamma$ and $\Delta$ to range over finite [lists](https://en.wikipedia.org/wiki/List_%28mathematics%29) of propositions $A_{1}, ..., A_{n}$, also called *contexts*. A *sequent* places a context to the left and the right of the [turnstile](wikipedia://en/7954712), written $\Gamma \Delta$. Intuitively, the sequent asserts that the conjunction of $\Gamma$ [entails](wikipedia://en/37531624) the disjunction of $\Delta$ (though we mean the "multiplicative" conjunction and disjunction, as explained below). Girard describes classical linear logic using only *one-sided* sequents (where the left-hand context is empty), and we follow here that more economical presentation. This is possible because any premises to the left of a turnstile can always be moved to the other side and dualised.

We now give [inference rules](wikipedia://en/252329#Inference_rules) describing how to build proofs of sequents.[^n4]

First, to formalize the fact that we do not care about the order of propositions inside a context, we add the structural rule of [exchange](https://en.wikipedia.org/wiki/Exchange_rule):

| $\Gamma, A_{1}, A_{2}, \Delta$ |
|---|
| $\Gamma, A_{2}, A_{1}, \Delta$ |

Note that we do **not** add the structural rules of weakening and contraction, because we do care about the absence of propositions in a sequent, and the number of copies present.

Next we add *initial sequents* and *cuts*:

| $A, A^{\perp}$ |  | $\Gamma, A$ $A^{\perp}, \Delta$ $\Gamma, \Delta$ |
|---|---|---|

The cut rule can be seen as a way of composing proofs, and initial sequents serve as the [units](wikipedia://en/14962) for composition. In a certain sense these rules are redundant: as we introduce additional rules for building proofs below, we will obtain the property that arbitrary initial sequents can be derived from atomic initial sequents, and that whenever a sequent is provable it can be given a cut-free proof. Ultimately, this [canonical form](wikipedia://en/515096) property (which can be divided into the [completeness of atomic initial sequents](wikipedia://en/23252771) and the [cut-elimination theorem](wikipedia://en/910234), inducing a notion of [analytic proof](wikipedia://en/1007110)) lies behind the applications of linear logic in computer science, since it allows the logic to be used in proof search and as a resource-aware [lambda-calculus](https://en.wikipedia.org/wiki/Lambda-calculus).

Now, we explain the connectives by giving *logical rules*. Typically in sequent calculus one gives both "right-rules" and "left-rules" for each connective, essentially describing two modes of reasoning about propositions involving that connective (e.g., verification and falsification). In a one-sided presentation, one instead makes use of negation: the right-rules for a connective (say ⅋) effectively play the role of left-rules for its dual (⊗). So, we should expect a certain ["harmony"](wikipedia://en/1606990) between the rule(s) for a connective and the rule(s) for its dual.

### Multiplicatives {#Multiplicatives}

The rules for multiplicative conjunction (⊗) and disjunction (⅋):

| $\Gamma, A$ $\Delta, B$ $\Gamma, \Delta, A \otimes B$ |  | $\Gamma, A, B$ $\Gamma, A \text{⅋} B$ |
|---|---|---|

and for their units:

| $1$ |  | $\Gamma$ $\Gamma, \perp$ |
|---|---|---|

Observe that the rules for multiplicative conjunction and disjunction are [admissible](wikipedia://en/1151794) for plain *conjunction* and *disjunction* under a classical interpretation (i.e., they are admissible rules in [LK](wikipedia://en/252329#The_system_LK)).

### Additives {#Additives}

The rules for additive conjunction (&) and disjunction (⊕):

| $\Gamma, A$ $\Gamma, B$ $\Gamma, A \& B$ |  | $\Gamma, A$ $\Gamma, A \oplus B$ |  | $\Gamma, B$ $\Gamma, A \oplus B$ |
|---|---|---|---|---|

and for their units:

| $\Gamma, \top$ |  | (no rule for $0$) |
|---|---|---|

Observe that the rules for additive conjunction and disjunction are again admissible under a classical interpretation. But now we can explain the basis for the multiplicative/additive distinction in the rules for the two different versions of conjunction: for the multiplicative connective (⊗), the context of the conclusion ($\Gamma, \Delta$) is split up between the premises, whereas for the additive case connective (&) the context of the conclusion ($\Gamma$) is carried whole into both premises.

### Exponentials {#Exponentials}

The exponentials are used to give controlled access to weakening and contraction. Specifically, we add structural rules of weakening and contraction for $?$'d propositions:[^n5]

| $\Gamma$ $\Gamma, ?A$ |  | $\Gamma, ?A, ?A$ $\Gamma, ?A$ |
|---|---|---|

and use the following logical rules, in which $?\Gamma$ stands for a list of propositions each prefixed with $?$:

| $?\Gamma, A$ $?\Gamma, !A$ |  | $\Gamma, A$ $\Gamma, ?A$ |
|---|---|---|

One might observe that the rules for the exponentials follow a different pattern from the rules for the other connectives, resembling the inference rules governing modalities in sequent calculus formalisations of the [normal modal logic](wikipedia://en/911820) [S4](https://en.wikipedia.org/wiki/S4_%28modal_logic%29), and that there is no longer such a clear symmetry between the duals $!$ and $?$. This situation is remedied in alternative presentations of CLL (e.g., the [LU](https://en.wikipedia.org/wiki/Logic_of_unity) presentation).

## Remarkable formulas {#Remarkable_formulas}

In addition to the [De Morgan dualities](wikipedia://en/64669) described above, some important equivalences in linear logic include:

**Distributivity**

| $A \otimes (B \oplus C) \text{≣} (A \otimes B) \oplus (A \otimes C)$ |
|---|
| $(A \oplus B) \otimes C \text{≣} (A \otimes C) \oplus (B \otimes C)$ |
| $A \text{⅋} (B \& C) \text{≣} (A \text{⅋} B) \& (A \text{⅋} C)$ |
| $(A \& B) \text{⅋} C \text{≣} (A \text{⅋} C) \& (B \text{⅋} C)$ |

By definition of $A \text{⊸} B$ as $A^{\perp} \text{⅋} B$, the last two distributivity laws also give:

| $A \text{⊸} (B \& C) \text{≣} (A \text{⊸} B) \& (A \text{⊸} C)$ |
|---|
| $(A \oplus B) \text{⊸} C \text{≣} (A \text{⊸} C) \& (B \text{⊸} C)$ |

(Here $A \text{≣} B$ is $(A \text{⊸} B) \& (B \text{⊸} A)$.)

**Exponential isomorphism**

| $!(A \& B) \text{≣} !A \otimes !B$ |
|---|
| $?(A \oplus B) \text{≣} ?A \text{⅋} ?B$ |

**Linear distributions**

A map that is not an isomorphism yet plays a crucial role in linear logic is:

| $(A \otimes (B \text{⅋} C)) \text{⊸} ((A \otimes B) \text{⅋} C)$ |
|---|

Linear distributions are fundamental in the proof theory of linear logic. The consequences of this map were first investigated in Cockett & Seely (1997) and called a "weak distribution".[^n6] In subsequent work it was renamed to "linear distribution" to reflect the fundamental connection to linear logic.

**Other implications**

The following distributivity formulas are not in general an equivalence, only an implication:

| $!A \otimes !B \text{⊸} !(A \otimes B)$ |
|---|
| $!A \oplus !B \text{⊸} !(A \oplus B)$ |
| $?(A \text{⅋} B) \text{⊸} ?A \text{⅋} ?B$ |
|---|
| $?(A \& B) \text{⊸} ?A \& ?B$ |
| $(A \& B) \otimes C \text{⊸} (A \otimes C) \& (B \otimes C)$ |
|---|
| $(A \& B) \oplus C \text{⊸} (A \oplus C) \& (B \oplus C)$ |
| $(A \text{⅋} C) \oplus (B \text{⅋} C) \text{⊸} (A \oplus B) \text{⅋} C$ |
|---|
| $(A \& C) \oplus (B \& C) \text{⊸} (A \oplus B) \& C$ |

:::

## Extending classical/intuitionistic logic {#Extending_classical/intuitionistic_logic}

Both intuitionistic and classical implication can be recovered from linear implication by inserting exponentials: intuitionistic implication is encoded as $!A \text{⊸} B$, while classical implication can be encoded as $!?A \text{⊸} ?B$ or $!A \text{⊸} ?!B$ (or a variety of alternative possible translations).[^n7] The idea is that exponentials allow us to use a formula as many times as we need, which is always possible in classical and intuitionistic logic.

Formally, there exists a translation of formulas of intuitionistic logic to formulas of linear logic in a way that guarantees that the original formula is provable in intuitionistic logic if and only if the translated formula is provable in linear logic. Using the [Gödel–Gentzen negative translation](https://en.wikipedia.org/wiki/Gödel–Gentzen_negative_translation), we can thus embed classical [first-order logic](wikipedia://en/10983) into linear first-order logic.

### Proof nets {#Proof_nets}

Introduced by [Jean-Yves Girard](wikipedia://en/579673), proof nets have been created to avoid the *bureaucracy*, that is all the things that make two derivations different in the logical point of view, but not in a "moral" point of view.

For instance, these two proofs are "morally" identical:

| $A, B, C, D$ $A \text{⅋} B, C, D$ $A \text{⅋} B, C \text{⅋} D$ | $A, B, C, D$ $A, B, C \text{⅋} D$ $A \text{⅋} B, C \text{⅋} D$ |
|---|---|

The goal of proof nets is to make them identical by creating a graphical representation of them.

## Semantics {#Semantics}

Multiple distinct semantics have been developed for linear logic, reflecting its complex nature as a resource-sensitive logical system. Unlike classical or intuitionistic logic, linear logic distinguishes between different ways of combining formulas and treats assumptions as finite resources that are consumed during proof rather than being endlessly reproducible.[^o30]

The main semantic approaches include:

**Phase semantics**

An early model focusing on provability.

**[Categorical semantics](https://en.wikipedia.org/wiki/Categorical_semantics)**

An algebraic framework that models proofs as [morphisms](wikipedia://en/27716891). The appropriate category is a subcategory of complete, separated, [bornological vector space](wikipedia://en/64304060) with [continuous linear maps](https://en.wikipedia.org/wiki/Continuous_linear_map).[^o31]

**Game semantics**

An interactive model that interprets formulas as games and proofs as strategies.[^o32]

**Denotational semantics**

A model that interprets proofs as mathematical objects.[^o33]

The [algebraic semantics](https://en.wikipedia.org/wiki/Algebraic_semantics_%28math%29) of linear logic is that of [quantales](wikipedia://en/716803).

In [linguistics](https://en.wikipedia.org/wiki/Linguistics), linear logic models grammatical [parsing](https://en.wikipedia.org/wiki/Parsing) as [deduction](https://en.wikipedia.org/wiki/Logical_deduction). In that circumstance, a valid parse tree corresponds to proving the existence of a sentence using implication rules encoding the grammar.[^o34]

### The resource interpretation {#The_resource_interpretation}

Lafont (1993) first showed how intuitionistic linear logic can be explained as a logic of resources, so providing the logical language with access to formalisms that can be used for reasoning about resources within the logic itself, rather than, as in classical logic, by means of non-logical predicates and relations. [Tony Hoare](https://en.wikipedia.org/wiki/Tony_Hoare) (1985) used purchases at a [vending machine](https://en.wikipedia.org/wiki/Vending_machine) to illustrate the logic, and culinary transactions have become the traditional example to describe use of the connectives.[^n8]

In particular, a *[prix fixe](https://en.wikipedia.org/wiki/Prix_fixe)* menu corresponds to a linear implication from the price to the meal; either

(Cash) ⊸ (Meal)

or equivalently

(Cash)<sup>⊥</sup> ⅋ (Meal)

depending on if implication or par is taken to be the primitive connective. Different courses are then conjoined using tensor, as a purchased meal is guaranteed to consist of both. For example, one might define (Meal) as

(Meal) := (Appetizer) ⊗ (Main) ⊗ (Dessert) ⊗ (Drink)

The customer's choice is conjoined using &:

(Appetizer) := (Soup) & (Salad)

indicating that the customer must choose either a soup or a salad. Contrariwise, the restaurant's choice is disjoined using ⊕: if the dessert is seasonal fruits, then it might be well-modeled as

(Dessert) := (Summer berries) ⊕ (Apple slices) ⊕ (Winter pineapple) ⊕ (Cherries)

Finally, an all-you-can-eat/drink item is modeled with !:[^n8]

(Drink) := (Coffee) & (Tea) & !(Tap water)

In the resource interpretation, the constant 1 denotes the absence of any resource, and so functions as the unit of ⊗ (any formula $A$ is equivalent to $A \otimes 1$). ⊤ is the unit for & and consumes any unneeded resources; 0 represents a product that cannot be made, and thus serves as the unit of ⊕ (a machine that might produce $A$ or $0$ is as good as a machine that always produces $A$, because it will never succeed in producing a 0); and ⊥ denotes unconsumable resources.[^n9]

## Decidability/complexity of entailment {#Decidability/complexity_of_entailment}

The [entailment](https://en.wikipedia.org/wiki/Entailment) relation in full CLL is [undecidable](wikipedia://en/15631055). When considering fragments of CLL, the decision problem has varying complexity:

- Multiplicative linear logic (MLL): only the multiplicative connectives. MLL entailment is [NP-complete](https://en.wikipedia.org/wiki/NP-complete), even restricting to [Horn clauses](https://en.wikipedia.org/wiki/Horn_clauses) in the purely implicative fragment,[^n10] or to atom-free formulas.[^n11]
- Multiplicative-additive linear logic (MALL): only multiplicatives and additives (i.e., exponential-free). MALL entailment is [PSPACE-complete](wikipedia://en/54685).[^n12]
- Multiplicative-exponential linear logic (MELL): only multiplicatives and exponentials. By reduction from the reachability problem for [Petri nets](https://en.wikipedia.org/wiki/Petri_nets),[^n13] MELL entailment must be at least [EXPSPACE-hard](wikipedia://en/54703), although decidability itself has had the status of a longstanding open problem. In 2015, a proof of decidability was published in the journal *[Theoretical Computer Science](https://en.wikipedia.org/wiki/Theoretical_Computer_Science_%28journal%29)*,[^n14] but was later shown erroneous.[^n15]
- [Affine linear logic](wikipedia://en/693233) (that is linear logic with weakening, an extension rather than a fragment) was shown to be decidable, in 1995.[^n16]

## Variants {#Variants}

Many variations of linear logic arise by further tinkering with the structural rules:

- [Affine logic](wikipedia://en/693233), which forbids contraction but allows global weakening (a decidable extension).
- [Strict logic](https://en.wikipedia.org/wiki/Strict_logic) or [relevance logic](wikipedia://en/185076), which forbids weakening but allows global contraction.
- [Non-commutative logic](wikipedia://en/693282) or ordered logic, which removes the rule of exchange, in addition to barring weakening and contraction. In ordered logic, linear implication divides further into left-implication and right-implication.

Different intuitionistic variants of linear logic have been considered. When based on a single-conclusion sequent calculus presentation, like in ILL (Intuitionistic Linear Logic), the connectives ⅋, ⊥, and ? are absent, and linear implication is treated as a primitive connective. In FILL (Full Intuitionistic Linear Logic) the connectives ⅋, ⊥, and ? are present, linear implication is a primitive connective and, similarly to what happens in intuitionistic logic, all connectives (except linear negation) are independent. There are also first- and higher-order extensions of linear logic, whose formal development is somewhat standard (see [first-order logic](wikipedia://en/10983) and [higher-order logic](wikipedia://en/562883)).
