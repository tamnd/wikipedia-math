# Repeated median regression

::: {#o1 .subject cue=lead name="Repeated median regression"}

In [robust statistics](wikipedia://en/2885691), **repeated median regression**, also known as the **repeated median estimator**, is a [robust linear regression](https://en.wikipedia.org/wiki/Robust_linear_regression) algorithm. The estimator has a [breakdown point](https://en.wikipedia.org/wiki/Breakdown_point) of 50%.[^o2] Although it is [equivariant](https://en.wikipedia.org/wiki/Equivariant) under scaling, or under [linear transformations](https://en.wikipedia.org/wiki/Linear_transformation) of either its explanatory variable or its response variable, it is not under [affine transformations](wikipedia://en/38449) that combine both variables.[^o2] It can be calculated in $O(n^2)$ time by brute force, in $O(n \log^2 n)$ time using more sophisticated techniques,[^o3] or in $O(n\log n)$ randomized expected time.[^o4] It may also be calculated using an [on-line algorithm](https://en.wikipedia.org/wiki/On-line_algorithm) with $O(n)$ update time.[^o5]

:::

::: {#o7 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

The repeated median method estimates the slope of the regression line $y = A + Bx$ for a set of points $(X_i, Y_i)$ as

$$\widehat B = \underset{i}{\operatorname{median}} \ \underset{j\,\ne\,i}{\operatorname{median}} \ \operatorname{slope}(i, j)$$

where $\operatorname{slope}(i,j)$ is defined as $(Y_j - Y_i) / (X_j - X_i)$.[^o8]

The estimated Y-axis intercept is defined as

$$\widehat A = \underset{i}{\operatorname{median}} \ \underset{j\,\ne\,i}{\operatorname{median}} \ \operatorname{intercept}(i, j)$$

where $\operatorname{intercept}(i, j)$ is defined as $(X_j Y_i - X_i Y_j ) / (X_j - X_i)$.[^o8]

A simpler and faster alternative to estimate the intercept $\widehat A$ is to use the value $\widehat B$ just estimated, thus:[^o8]

$$\widehat A = \underset{i}{\operatorname{median}} \ (y_i - \widehat {B} x_i)$$

Note: The direct and hierarchical methods of estimating $\widehat A$ give slightly different values, with the hierarchical method normally being the best estimate. This latter hierarchical approach is identical to the method of estimating $\widehat A$ in [Theil–Sen estimator](wikipedia://en/32292709) regression.
