# KeePassXC

::: {#o3 .subject cue=lead name="KeePassXC"}

**KeePassXC** (originally **KeePassX**[^o4][^o5]) is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source_software) cross-platform [password manager](wikipedia://en/4696394). It is built using the [Qt toolkit](https://en.wikipedia.org/wiki/Qt_%28toolkit%29), which allows it to run on [Linux](https://en.wikipedia.org/wiki/Linux), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), and [BSD](https://en.wikipedia.org/wiki/Berkeley_Software_Distribution),[^o6][^o7][^o8] unlike the original [KeePass](wikipedia://en/30858923) software.

:::

KeePassXC uses the KeePass 2.x (.kdbx) password database format natively.[^o9] It can also import (and convert) version 2 and the older KeePass 1 (.kdb) databases. KeePassXC supports having key files and [YubiKey](https://en.wikipedia.org/wiki/YubiKey) challenge-response for additional security.[^o4]

The [Electronic Frontier Foundation](https://en.wikipedia.org/wiki/Electronic_Frontier_Foundation) mentions KeePassXC as "easy-to-use \[and\] robust software".[^o10] A security review of KeePassXC version 2.7.4 was completed in late 2022.[^o11]

An accompanying browser extension[^o12] is available for [Firefox](https://en.wikipedia.org/wiki/Firefox),[^o13] [Tor Browser](wikipedia://en/20556944), [Google Chrome](https://en.wikipedia.org/wiki/Google_Chrome),[^o14] [Vivaldi](https://en.wikipedia.org/wiki/Vivaldi_%28web_browser%29), [Microsoft Edge](https://en.wikipedia.org/wiki/Microsoft_Edge),[^o15] and [Chromium](https://en.wikipedia.org/wiki/Chromium_%28web_browser%29). Extensions can be linked by enabling browser integration in the desktop application.[^o16]

KeePassXC uses zxcvbn to assess [password strength](wikipedia://en/4459886) and can search for credential breaches using [Have I Been Pwned?](https://en.wikipedia.org/wiki/Have_I_Been_Pwned?).[^o17]
