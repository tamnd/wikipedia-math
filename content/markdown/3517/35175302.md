# Hypocontinuous bilinear map

::: {#o1 .subject cue=lead name="Hypocontinuous bilinear map"}

In mathematics, a **hypocontinuous** is a condition on [bilinear maps](wikipedia://en/4365) of [topological vector spaces](wikipedia://en/45752) that is weaker than continuity but stronger than [separate continuity](https://en.wikipedia.org/wiki/Separate_continuity). Many important bilinear maps that are not continuous are, in fact, hypocontinuous.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $X$, $Y$ and $Z$ are [topological vector spaces](wikipedia://en/45752) then a [bilinear map](wikipedia://en/4365) $\beta: X\times Y\to Z$ is called *hypocontinuous* if the following two conditions hold:

- for every [bounded set](wikipedia://en/1789812) $A\subseteq X$ the set of linear maps $\{\beta(x,\cdot) \mid x\in A\}$ is an [equicontinuous](https://en.wikipedia.org/wiki/Equicontinuous) subset of $Hom(Y,Z)$, and
- for every bounded set $B\subseteq Y$ the set of linear maps $\{\beta(\cdot,y) \mid y\in B\}$ is an equicontinuous subset of $Hom(X,Z)$.

:::

## Sufficient conditions {#Sufficient_conditions}

::: {#o5 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem**:[^n1] Let *X* and *Y* be [barreled spaces](https://en.wikipedia.org/wiki/Barreled_space) and let *Z* be a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) space. Then every separately continuous bilinear map of $X \times Y$ into *Z* is hypocontinuous.

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *X* is a Hausdorff [locally convex](https://en.wikipedia.org/wiki/Locally_convex) [barreled space](https://en.wikipedia.org/wiki/Barreled_space) over the field $\mathbb{F}$, then the bilinear map $X \times X^{\prime} \to \mathbb{F}$ defined by $\left( x, x^{\prime} \right) \mapsto \left\langle x, x^{\prime} \right\rangle := x^{\prime}\left( x \right)$ is hypocontinuous.[^n1]

:::
