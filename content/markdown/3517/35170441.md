# Benson's algorithm

::: {#o1 .subject cue=lead name="Benson's algorithm"}

**Benson's algorithm**, named after [Harold Benson](wikipedia://en/73549739), is a method for solving [multi-objective linear programming](wikipedia://en/54647220) problems and vector linear programs. This works by finding the "efficient extreme points in the outcome set".[^o2] The primary concept in Benson's algorithm is to evaluate the upper image of the [vector optimization](wikipedia://en/32718008) problem by [cutting planes](wikipedia://en/1597680).[^o3]

:::

## Idea of algorithm {#Idea_of_algorithm}

Consider a vector linear program

$$\min_C Px \; \text{ subject to } A x \geq b$$

for $P \in \mathbb{R}^{q \times n}$, $A \in \mathbb{R}^{m \times n}$, $b \in \mathbb{R}^m$ and a polyhedral convex ordering cone $C$ having nonempty interior and containing no lines. The feasible set is $S=\{x \in \mathbb{R}^n:\; A x \geq b\}$. In particular, Benson's algorithm finds the [extreme points](wikipedia://en/454968) of the set $P[S] + C$, which is called upper image.[^o3]

In case of $C=\mathbb{R}^q_+:=\{y \in \mathbb{R}^q : y_1 \geq 0,\dots, y_q \geq 0\}$, one obtains the special case of a multi-objective linear program ([multiobjective optimization](https://en.wikipedia.org/wiki/Multiobjective_optimization)).

## Dual algorithm {#Dual_algorithm}

There is a dual variant of Benson's algorithm,[^o6] which is based on geometric duality[^o7] for multi-objective linear programs.
