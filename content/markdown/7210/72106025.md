# P4-metric

::: {#o1 .subject cue=lead name="P4-metric"}

The **P<sub>4</sub>** metric [^o2][^o3] (also known as FS or Symmetric F [^o4]) enables performance evaluation of a [binary classifier](wikipedia://en/205393). The P<sub>4</sub> metric is calculated from [precision](wikipedia://en/14343887#Precision), [recall](wikipedia://en/14343887#Recall), [specificity](wikipedia://en/5599330#Specificity), and [NPV](wikipedia://en/1556952#Negative_predictive_value_%28NPV%29) (negative predictive value). The definition of the P<sub>4</sub> metric is similar to that of the [F<sub>1</sub> metric](wikipedia://en/4011785), however the P<sub>4</sub> metric definition addresses [criticisms](wikipedia://en/4011785#Criticism) leveled against the definition of the F<sub>1</sub> metric. The definition of the P<sub>4</sub> metric may, therefore, be understood as an extension of the F<sub>1</sub> metric.

:::

Like the other known metrics, the P<sub>4</sub> metric is a function of: TP (true positives), TN (true negatives), FP ([false positives](wikipedia://en/43286898#False_positive_error)), FN ([false negatives](wikipedia://en/43286898#False_negative_error)).

## Justification {#Justification}

The key concept of the P<sub>4</sub> metric is to leverage the four key conditional probabilities:

1. $P(+ \mid C{+})$ — the probability that the sample is positive, provided the classifier result was positive.
1. $P(C{+} \mid +)$ — the probability that the classifier result will be positive, provided the sample is positive.
1. $P(C{-} \mid -)$ — the probability that the classifier result will be negative, provided the sample is negative.
1. $P(- \mid C{-})$ — the probability the sample is negative, provided the classifier result was negative.

The main assumption behind this metric is that all the probabilities mentioned above are close to 1 for a properly designed binary classifier. Indeed, $\mathrm{P}_4 = 1$ if, and only if, all of the probabilities above are equal to 1. Another important feature is that $\mathrm{P}_4$ tends to zero any of the above probabilities tend to zero.

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

P<sub>4</sub> is defined as a [harmonic mean](wikipedia://en/14463) of four key conditional probabilities:

$$\mathrm{P}_4 = \frac{4}{\frac{1}{P(+ \mid C{+})} + \frac{1}{P(C{+} \mid +)} + \frac{1}{P(C{-} \mid -)} + \frac{1}{P(- \mid C{-})}} = \frac{4}{\frac{1}{\mathit{precision}} + \frac{1}{\mathit{recall}} + \frac{1}{\mathit{specificity}} + \frac{1}{\mathit{NPV}}}.$$

In terms of TP,TN,FP,FN it can be calculated as follows:

$$\mathrm{P}_4 = \frac{4\cdot\mathrm{TP}\cdot\mathrm{TN}}{4\cdot\mathrm{TP}\cdot\mathrm{TN} + (\mathrm{TP} + \mathrm{TN}) \cdot (\mathrm{FP} + \mathrm{FN})}.$$

:::

## Evaluation of the binary classifier performance {#Evaluation_of_the_binary_classifier_performance}

Evaluating the performance of binary classifiers is a multidisciplinary concept. It spans from the evaluation of medical tests, psychiatric tests to [machine learning](wikipedia://en/233488) classifiers from a variety of fields. Thus, many of the metrics in use exist under several names, some defined independently.

## Properties of P<sub>4</sub> metric {#Properties_of_P4_metric}

- Symmetry — contrasting to the F<sub>1</sub> metric, P<sub>4</sub> is symmetrical. It means - it does not change its value when dataset labeling is changed - positives named negatives and negatives named positives.
- Range: $\mathrm{P}_4 \in [0,1]$.
- Achieving $\mathrm{P}_4 \approx 1$ requires all the key four conditional probabilities being close to 1.
- For $\mathrm{P}_4 \approx 0$ it is sufficient that one of the key four conditional probabilities is close to 0.

## Examples, comparing with the other metrics {#Examples,_comparing_with_the_other_metrics}

Dependency table for selected metrics ("true" means depends, "false" - does not depend):

::: {#o11 .table cue=table}

|  | $P(+ \mid C{+})$ | $P(C{+} \mid +)$ | $P(C{-} \mid -)$ | $P(- \mid C{-})$ |
|---|---|---|---|---|
| P<sub>4</sub> | true | true | true | true |
| [F<sub>1</sub>](wikipedia://en/4011785) | true | true | false | false |
| [Informedness](wikipedia://en/14092544) | false | true | true | false |
| [Markedness](https://en.wikipedia.org/wiki/Markedness) | true | false | false | true |

:::

Metrics that do not depend on a given probability are prone to misrepresentation when the probability approaches 0.

### Example 1: Rare disease detection test {#Example_1:_Rare_disease_detection_test}

Let us consider a medical test used to detect a rare disease. Suppose a population size of 100000 and 0.05% of the population is infected. Further suppose the following test performance: 95% of all positive individuals are classified correctly ([TPR](wikipedia://en/5599330#Sensitivity)=0.95) and 95% of all negative individuals are classified correctly ([TNR](wikipedia://en/5599330#Specificity)=0.95). In such a case, due to high population imbalance and in spite of having high test [accuracy](wikipedia://en/41932) (0.95), the probability that an individual who has been classified as positive is in fact positive is very low:

$$P(+ \mid C{+}) = 0.0095.$$

We can observe how this low probability is reflected in some of the metrics:

- $$\mathrm{P}_4 = 0.0370,$$
- $$\mathrm{F}_1 = 0.0188,$$
- $\mathrm{J} = \mathbf{0.9100}$ (*Informedness* / *Youden index*),
- $\mathrm{MK} = 0.0095$ (*Markedness*).

### Example 2: Image recognition — cats vs dogs {#Example_2:_Image_recognition_—_cats_vs_dogs}

Consider the problem of training a neural network based image classifier with only two types of images: those containing dogs (labeled as 0) and those containing cats (labeled as 1). Thus, the goal is to distinguish between the cats and dogs. Suppose that the classifier overpredicts in favour of cats ("positive" samples): 99.99% of cats are classified correctly and only 1% of dogs are classified correctly. Further, suppose that the image dataset consists of 100000 images, 90% of which are pictures of cats and 10% are pictures of dogs. In this situation, the probability that the picture containing dog will be classified correctly is pretty low:

$$P(C-|-) = 0.01.$$

Not all metrics are notice this low probability:

- $$\mathrm{P}_4 = 0.0388,$$
- $$\mathrm{F}_1 = \mathbf{0.9478},$$
- $\mathrm{J} = 0.0099$ (*Informedness* / *Youden index*),
- $\mathrm{MK} = \mathbf{0.8183}$ (*Markedness*).
