# System of bilinear equations

::: {#o1 .subject cue=lead name="System of bilinear equations"}

In [mathematics](wikipedia://en/18831), a **system of bilinear equations** is a special sort of [system of polynomial equations](wikipedia://en/27420015), where each equation equates a [bilinear form](wikipedia://en/449477) with a constant (possibly zero). More precisely, given two sets of variables represented as [coordinate vectors](wikipedia://en/879358) $x$ and *y*, then each equation of the system can be written

$$y^TA_ix=g_i,$$

where, $i$ is an [integer](wikipedia://en/14563) whose value ranges from 1 to the number of equations, each $A_i$ is a [matrix](wikipedia://en/20556859), and each $g_i$ is a [real number](wikipedia://en/20646438). Systems of bilinear equations arise in many subjects including [engineering](https://en.wikipedia.org/wiki/Engineering), [biology](https://en.wikipedia.org/wiki/Biology), and [statistics](wikipedia://en/26685).

:::
