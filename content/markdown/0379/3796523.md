# Lee Hwa Chung theorem

::: {#o1 .subject cue=lead name="Lee Hwa Chung theorem"}

The **Lee Hwa Chung theorem** is a [theorem](wikipedia://en/30977) in [symplectic topology](https://en.wikipedia.org/wiki/Symplectic_topology).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

::: {#o4 .statement kind=statement/theorem cue=math-theorem name="Lee Hwa Chung theorem"}

**Lee Hwa Chung theorem.**

Let $M$ be a [symplectic manifold](wikipedia://en/28356) with symplectic form $\omega$. Let $\alpha$ be a [differential $k$-form](wikipedia://en/221519) on $M$ which is invariant for all [Hamiltonian vector fields](wikipedia://en/1818270). Then:

If $k$ is odd, $\alpha = 0$.

If $k$ is even, $\alpha = c \times \omega^{\wedge \frac{k}{2}}$, where $c \in \mathbb{R}$.

:::
