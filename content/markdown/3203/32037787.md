# Trapping region

::: {#o1 .subject cue=lead name="Trapping region"}

In [applied mathematics](wikipedia://en/24295969), a **trapping region** of a [dynamical system](wikipedia://en/9087) is a region such that every trajectory that starts within the trapping region will move to the region's interior and remain there as the system evolves.

:::

More precisely, given a [dynamical system](wikipedia://en/9087) with [flow](wikipedia://en/2619735) $\phi_t$ defined on the phase space $D$, a subset of the phase space $N$ is a trapping region if it is [compact](wikipedia://en/6042) and $\phi_t(N) \subset \mathrm{int}(N)$ for all $t > 0$.[^o2]
