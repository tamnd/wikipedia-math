# Contraction principle (large deviations theory)

::: {#o1 .subject cue=lead name="Contraction principle"}

In [mathematics](wikipedia://en/18831) — specifically, in [large deviations theory](wikipedia://en/3772909) — the **contraction principle** is a [theorem](wikipedia://en/30977) that states how a large deviation principle on one space "pushes forward" (via the [pushforward](wikipedia://en/9412979) of a probability measure) to a large deviation principle on another space *via* a [continuous function](wikipedia://en/6122).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let *X* and *Y* be [Hausdorff](wikipedia://en/13637) [topological spaces](wikipedia://en/30450) and let (*μ*<sub>*ε*</sub>)<sub>*ε*>0</sub> be a family of [probability measures](wikipedia://en/45437) on *X* that satisfies the large deviation principle with [rate function](wikipedia://en/3772816) *I* : *X* → \[0, +∞\]. Let *T* : *X* → *Y* be a continuous function, and let *ν*<sub>*ε*</sub> = *T*<sub>∗</sub>(*μ*<sub>*ε*</sub>) be the push-forward measure of *μ*<sub>*ε*</sub> by *T*, i.e., for each [measurable set](https://en.wikipedia.org/wiki/Measurable_set)/event *E* ⊆ *Y*, *ν*<sub>*ε*</sub>(*E*) = *μ*<sub>*ε*</sub>(*T*<sup>−1</sup>(*E*)). Let

$$J(y) := \inf \{ I(x) \mid x \in X \text{ and } T(x) = y \},$$

with the convention that the [infimum](https://en.wikipedia.org/wiki/Infimum) of *I* over the [empty set](wikipedia://en/9566) ∅ is +∞. Then:

- *J* : *Y* → \[0, +∞\] is a rate function on *Y*,
- *J* is a good rate function on *Y* if *I* is a good rate function on *X*, and
- (*ν*<sub>*ε*</sub>)<sub>*ε*>0</sub> satisfies the large deviation principle on *Y* with rate function *J*.

:::
