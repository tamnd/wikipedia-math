# Richardson's theorem

::: {#o1 .subject cue=lead name="Richardson's theorem"}

In [mathematics](wikipedia://en/18831), **Richardson's theorem** establishes the [undecidability](wikipedia://en/15631055) of the equality of [real numbers](wikipedia://en/20646438) defined by [expressions](wikipedia://en/609125) involving [integers](https://en.wikipedia.org/wiki/Integers), $\pi$, $\ln 2$, and [exponential](wikipedia://en/9678) and [sine](https://en.wikipedia.org/wiki/Sine) functions. It was proved in 1968 by the mathematician and computer scientist Daniel Richardson of the [University of Bath](https://en.wikipedia.org/wiki/University_of_Bath).

:::

Specifically, the class of expressions for which the theorem holds is that generated by rational numbers, the number [π](wikipedia://en/23601), the number $\ln 2$, the variable $x$, the operations of addition, subtraction, multiplication, [composition](wikipedia://en/195947), and the [sin](https://en.wikipedia.org/wiki/Sine), [exp](wikipedia://en/9678), and [abs](wikipedia://en/991) functions.

For some classes of expressions generated by other primitives than in Richardson's theorem, there exist algorithms that can determine whether an expression is zero.[^o2]

::: {#o4 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Richardson's theorem can be stated as follows:[^o5] Let *E* be a set of expressions that represent $\mathbb{R}\to\mathbb{R}$ functions. Suppose that *E* includes these expressions:

- $x$ (representing the identity function)
- $e^x$ (representing the exponential functions)
- $\sin x$ (representing the sin function)
- all rational numbers, $\ln 2$, and π (representing constant functions that ignore their input and produce the given number as output)

Suppose *E* is also closed under a few standard operations. Specifically, suppose that if *A* and *B* are in *E*, then all of the following are also in *E*:

- *A* + *B* (representing the pointwise addition of the functions that *A* and *B* represent)
- *A* − *B* (representing pointwise subtraction)
- *AB* (representing pointwise multiplication)
- *A*∘*B* (representing the composition of the functions represented by *A* and *B*)

Then the following [decision problems](wikipedia://en/8336) are unsolvable:

- Deciding whether an expression *A* in *E* represents a function that is nonnegative everywhere
- If *E* includes also the expression $|x|$ (representing the absolute value function), deciding whether an expression *A* in *E* represents a function that is zero everywhere
- If *E* includes an expression *B* representing a function whose [antiderivative](wikipedia://en/2823) has no representative in *E*, deciding whether an expression *A* in *E* represents a function whose antiderivative can be represented in *E*. (Example: $e^{ax^2}$ has an antiderivative in the [elementary functions](wikipedia://en/10412) if and only if $a = 0$).

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="Extensions"}

## Extensions {#Extensions}

After [Hilbert's tenth problem](wikipedia://en/101851) was solved in 1970, B. F. Caviness observed that the use of $e^x$ and $\ln 2$ could be removed.[^o8] Wang later noted that under the same assumptions under which the question of whether there was $x$ with $A(x) < 0$ was unsolvable, the question of whether there was $x$ with $A(x) = 0$ was also unsolvable.[^o9]

[Miklós Laczkovich](wikipedia://en/6021299) removed also the need for π and reduced the use of composition.[^o10] In particular, given an expression $A(x)$ in the ring generated by the integers, $x$, $\sin x^n$, and $\sin(x \sin x^n)$ (for $n$ ranging over positive integers), both the question of whether $A(x) > 0$ for some $x$ and whether $A(x) = 0$ for some $x$ are unsolvable.

By contrast, the [Tarski–Seidenberg theorem](wikipedia://en/19389633) says that the first-order theory of the real field is decidable, so it is not possible to remove the sine function entirely.

:::
