# Adleman–Pomerance–Rumely primality test

::: {#o1 .subject cue=lead name="Adleman–Pomerance–Rumely primality test"}

In [computational number theory](wikipedia://en/511466), the **Adleman–Pomerance–Rumely primality test** is an [algorithm](wikipedia://en/775) for determining whether a number is [prime](wikipedia://en/23666). Unlike other, more efficient algorithms for this purpose, it avoids the use of random numbers, so it is a [deterministic](https://en.wikipedia.org/wiki/Deterministic_algorithm) [primality test](wikipedia://en/183751). It is named after its discoverers, [Leonard Adleman](https://en.wikipedia.org/wiki/Leonard_Adleman), [Carl Pomerance](wikipedia://en/2134159), and [Robert Rumely](wikipedia://en/24708114). The test involves arithmetic in [cyclotomic fields](wikipedia://en/30872462).

:::

It was later improved by [Henri Cohen](https://en.wikipedia.org/wiki/Henri_Cohen_%28number_theorist%29) and [Hendrik Willem Lenstra](https://en.wikipedia.org/wiki/Hendrik_Willem_Lenstra), commonly referred to as **APR-CL**. It can test primality of an integer *n* in time:

$$(\log n)^{O(\log\,\log\,\log n)}.$$

## Software implementations {#Software_implementations}

- [UBASIC](https://en.wikipedia.org/wiki/UBASIC) provides an implementation under the name APRT-CLE (APR Test CL extended)
- A [factoring applet](http://www.alpertron.com.ar/ECM.HTM) that uses APR-CL on certain conditions (source code included)
- [Pari/GP](https://web.archive.org/web/20190929045643/http://pari.math.u-bordeaux.fr/) uses APR-CL conditionally in its implementation of isprime().
- [mpz\_aprcl](https://sourceforge.net/projects/mpzaprcl/) is an open source implementation using C and GMP.
- [Jean Penné's LLR](http://jpenne.free.fr/index2.html) uses APR-CL on certain types of prime tests as a fallback option.
