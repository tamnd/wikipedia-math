# Stationary sequence

::: {#o1 .subject cue=lead name="Stationary sequence"}

In [probability theory](wikipedia://en/23542) – specifically in the theory of [stochastic processes](wikipedia://en/47895), a **stationary sequence** is a [random sequence](wikipedia://en/48256) whose [joint probability distribution](wikipedia://en/879637) is [invariant](wikipedia://en/1126638) over time. If a random sequence *X*<sub>*j*</sub> is stationary then the following holds:

:::

$$\begin{aligned} & {} \quad F_{X_n,X_{n+1},\dots,X_{n+N-1}}(x_n, x_{n+1},\dots,x_{n+N-1}) \\ & = F_{X_{n+k},X_{n+k+1},\dots,X_{n+k+N-1}}(x_n, x_{n+1},\dots,x_{n+N-1}), \end{aligned}$$

where *F* is the joint [cumulative distribution function](wikipedia://en/5793) of the [random variables](wikipedia://en/25685) in the subscript.

If a sequence is stationary then it is [wide-sense stationary](https://en.wikipedia.org/wiki/Wide-sense_stationary).

If a sequence is stationary then it has a constant [mean](https://en.wikipedia.org/wiki/Mean_%28mathematics%29) (which may not be finite):

$$E(X[n]) = \mu \quad \text{for all } n .$$
