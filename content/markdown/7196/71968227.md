# Snowflake (software)

::: {#o2 .subject cue=lead name="Snowflake"}

**Snowflake** is a software package for assisting others in [circumventing internet censorship](wikipedia://en/32936800) by relaying data requests. Snowflake proxy nodes are meant to be created by people in countries where [Tor](wikipedia://en/20556944) and Snowflake are not blocked.[^o32] People under censorship then use a Snowflake client (packaged with the [Tor Browser](https://en.wikipedia.org/wiki/Tor_Browser) and Onion Browser)[^o16] to access the Tor network, using Snowflake relays as [proxy servers](https://en.wikipedia.org/wiki/Proxy_server). Access to the Tor network can in turn give access to other blocked services (like blocked websites).[^o32] A Snowflake proxy can be created by either installing a browser extension, installing a stand-alone program or browsing a webpage with an embedded Snowflake proxy. The proxy runs after the user has voluntarily enabled it and the [browser](https://en.wikipedia.org/wiki/Web_browser) or program is connected to the [internet](https://en.wikipedia.org/wiki/Internet).

:::

In contrast to regular [VPNs](wikipedia://en/147130) and proxy services, creating a Snowflake proxy does not require [port forwarding](https://en.wikipedia.org/wiki/Port_forwarding) or having a [dedicated IP address](https://en.wikipedia.org/wiki/Dedicated_IP),[^o31] with simply installing a browser extension being enough most of the time. The ease and accessibility of creating proxies increases the difficulty of blocking their IP addresses due to the large number of them in existence.[^o31][^o3]

As of 2024, Snowflake proxies are hosted on about 140000 unique IP addresses concurrently.[^o31] The average number of users that use Snowflake to connect to Tor is 35000 and 29 [TB](https://en.wikipedia.org/wiki/Terabyte) of their traffic is relayed by Snowflake proxies daily.[^o31]

## History {#History}

Snowflake was originated by [Serene](wikipedia://en/69573996), a hacker and former Google engineer and concert pianist.[^o38] It was inspired by [Flash proxy](https://en.wikipedia.org/wiki/Flash_proxy), a similar censorship circumvention system.[^o34] The name "Snowflake" was coined as her metaphor for a large number of ephemeral proxies[^o32] in relation to "[ICE](https://en.wikipedia.org/wiki/Interactive_Connectivity_Establishment) Negotiation".[^o34] Three programmers published the first version in January 2016. In 2019, it became available as a [browser extension](https://en.wikipedia.org/wiki/Browser_extension) for [Firefox](https://en.wikipedia.org/wiki/Firefox) and [Chrome](https://en.wikipedia.org/wiki/Chrome_%28browser%29).[^o32] It can also be run on derived browsers, such as [Brave](https://en.wikipedia.org/wiki/Brave_%28browser%29) and [Microsoft Edge](https://en.wikipedia.org/wiki/Microsoft_Edge).[^o26][^o16] In February 2023 a thoroughly upgraded, stand-alone version dubbed *Snowstorm* was released; written in [Rust](https://en.wikipedia.org/wiki/Rust_%28programming_language%29) and funded by the [Open Tech Fund](https://en.wikipedia.org/wiki/Open_Tech_Fund), beta testing is by invitation.[^o5][^o33]

## Function {#Function}

*Image: Snowflake-(Tor)-schematic.png.*

Normal internet data packages come labelled with the original source and the final recipient of the data. For example, a package containing the encrypted text of a website would be labelled with the destination (the [IP address](https://en.wikipedia.org/wiki/IP_address) of the reader's computer), and the source (the IP address of the website's server).[^o7][^o8] This means that even if the actual content is encrypted, a censor can identify and block all packages from certain sources.[^o9][^o36][^o10]

[The Tor network](wikipedia://en/20556944) can be used to access such blocked sites[^o8] by acting as a proxy, covering the real destination address of the user's request.[^o11][^o12] In order to prevent circumvention, censors may try to disable direct access to Tor by blocking connections to its relays, which are publicly known.[^o8]

Snowflake provides covert, indirect access to Tor.[^o31] A Snowflake client is provided with the IP address of a currently-active Snowflake proxy by asking a broker server,[^o16][^o13] which in turn uses [domain fronting](https://en.wikipedia.org/wiki/Domain_fronting) to pretend to be a major website. The client then talks directly to the Snowflake proxy, which relays into the Tor network. The traffic looks like ordinary [peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) traffic, such as that used by many videoconferencing apps.[^o13]

A Snowflake proxy runs whenever the browser or program is connected to the internet. If the proxy host has a [dynamic IP](https://en.wikipedia.org/wiki/Dynamic_IP), the proxy will change its IP address over time.[^o38][^o16]

Snowflake proxies are thus used as Tor entry nodes, not as exit nodes. Tor exit nodes might face legal action in the country in which they are hosted if they relay content that is illegal in that jurisdiction. It is unlikely that Snowflake proxy hosts could face such liabilities, since they do not know what content they are relaying.[^o38] There are, however, countries where using Tor for any purpose is illegal, such as Russia and Iran.[^o14]

### Deployment {#Deployment}

`<nowiki><iframe src="https://snowflake.torproject.org/embed.html" width="320" height="240" frameborder="0" scrolling="no"></iframe> </nowiki>` Snowflake uses [WebRTC](https://en.wikipedia.org/wiki/WebRTC) to allow browsers to communicate directly with one another.[^o16] Either installing a browser extension, or keeping a tab open to a webpage with the right embedded code, causes one's browser to act as a proxy.[^o32] Embedding a Snowflake badge in a website allows visitors to make their browser into a proxy, exactly as installing the extension does, but by clicking a button on the website rather than by installing software.[^o17] Snowflake can also be run as a stand-alone program in a [Docker](https://en.wikipedia.org/wiki/Docker_%28software%29) container.[^o16]

Proxying traffic increases the proxy host's [bandwidth](https://en.wikipedia.org/wiki/Bandwidth_%28computing%29) usage, which may be a problem for those with bandwidth limits on their internet plans.[^o38] In practice, hosting a Snowflake proxy does not seem to appreciably slow one's internet connection[^o26] or disrupt browsing.[^o16]

### Countermeasures {#Countermeasures}

Countermeasures believed to be currently in use against Snowflake from Russia include [browser fingerprinting](https://en.wikipedia.org/wiki/Browser_fingerprinting) Snowflake hosts and then blocking them. Censors may also install and use Tor, then block all the IP addresses offered as Snowflake servers. Both of these techniques are weakened when there are larger numbers of servers.[^o35]

Censors may attempt to block the broker's IP address. To circumvent this, the Snowflake client utilizes [domain fronting](https://en.wikipedia.org/wiki/Domain_fronting). This makes it infeasible for the censor to block a single website without blocking all the other websites hosted on the same cloud service. [Google Cloud Platform](https://en.wikipedia.org/wiki/Google_Cloud_Platform) and [Amazon's AWS](https://en.wikipedia.org/wiki/Amazon_Web_Services) are examples of services that host hundreds of thousands of websites. Blocking all the servers of one of these major hosts would have disruptive side effects.[^o13] However, the cloud provider can and often does block domain fronting.[^o19][^o37]

If overseas connections from data centers are allowed, but residential and mobile services are restricted to local connections, then Tor bridges may be secretly and illegally set up in local data centers.[^o20]

When a state shuts down access to foreign internet connections altogether, essentially cutting the country off from the global internet, Snowflake and other internet anonymity tools are defeated.[^o38] This method has been applied by countries such as Iran, Ethiopia and Belarus, although it can carry a severe negative impact to the economy (in Iran in 2022, the cost was estimated at \$37 million US a day[^o21]), so these interventions are usually restricted to short periods of time.[^o38][^o22]

## Uses {#Uses}

Snowflake came to be widely discussed online in the first week of October 2022, as a way of combating internet restrictions in Iran during the [Mahsa Amini protests](https://en.wikipedia.org/wiki/Mahsa_Amini_protests),[^o38] and a guide in [Persian](https://en.wikipedia.org/wiki/Persian_language) was released.[^o25][^o13]

In 2022, the [Russian government](https://en.wikipedia.org/wiki/Government_of_Russia) increased efforts to block access to Tor through technical and political means, and the Tor network reported an increase in traffic from Russia using Snowflake.[^o35]

Snowflake is integrated into the Tor network. Usage of the Tor network is becoming more common in [Russia](https://en.wikipedia.org/wiki/Russia), [Belarus](https://en.wikipedia.org/wiki/Belarus), and [Iran](https://en.wikipedia.org/wiki/Iran), , as [internet censorship](https://en.wikipedia.org/wiki/Internet_censorship) in these countries has become more strict.[^o26]
