# Biracks and biquandles

::: {#o1 .subject cue=lead name="Biracks and biquandles"}

In [mathematics](wikipedia://en/18831), **biquandles** and **biracks** are sets with binary operations that generalize [quandles and racks](wikipedia://en/1140981). In the theory of [virtual knots](wikipedia://en/6436991), biquandles are analagous to quandles in the theory of classical [knots](wikipedia://en/366808). Biracks and racks have the same relation, while a biquandle is a birack which satisfies some additional conditions.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A **birack** is a set $X$, two [right-invertible](https://en.wikipedia.org/wiki/Right_invertible) operations $\underline{\triangleright}$$, \overline{\triangleright}$ and a [bijection](wikipedia://en/3942) $\pi \colon X \to X$ such that for all $a,b,c \in X$,

\1. $\pi(a \overline{\triangleright} a) = a \underline{\triangleright} a$ and $\pi(a) \overline{\triangleright} a = a \underline{\triangleright} \pi(a)$.

\2. The map $H \colon X \times X \to X \times X$ defined by $H(a,b) = (b \overline{\triangleright} a, a \underline{\triangleright} b)$ is invertible.

\3. The exchange laws

- $$(a \underline{\triangleright} b) \underline{\triangleright} (c \underline{\triangleright} b ) = (a \underline{\triangleright} c) \underline{\triangleright} (b \overline{\triangleright} c )$$
- $$(a \underline{\triangleright} b) \overline{\triangleright} (c \underline{\triangleright} b ) = (a \overline{\triangleright} c) \underline{\triangleright} (b \overline{\triangleright} c )$$
- $$(a \overline{\triangleright} b) \overline{\triangleright} (c \overline{\triangleright} b ) = (a \overline{\triangleright} c) \overline{\triangleright} (b \underline{\triangleright} c ).$$

If $\pi = id$ is the [identity map](wikipedia://en/15069), $X$ is called a **biquandle.**[^o4]

Biracks and biquandles were first introduced by Roger Fenn, Mercedes Jordan-Santana and Louis Kauffman in 2004.[^o5]

Note that the three conditions above correspond directly to the three [Reidemeister moves](wikipedia://en/1152374) in knot therory, showing the close connections between [knots](wikipedia://en/366808) and biracks.[^o6]

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

Let $X$ be a set with two bijection $\sigma, \tau \colon X \to X$ that commute. Then the **constant action birack** is defined by $a \underline{\triangleright} b = \sigma (a)$ and $a \overline{\triangleright} b = \tau ( x )$ and $\pi ( a) = \tau^{-1}(\sigma(a))$.

Any [rack](wikipedia://en/1140981) $(X, \triangleright)$ is a birack with $a \underline{\triangleright} b = a \triangleright b$ and $a \overline{\triangleright} b = a$ for all $a, b \in X$. Note that if we insert these operations into the conditions in the definition above, we regain the exact definition of a rack.

Let $R$ be a [commutative ring](wikipedia://en/61346) with identity and $X$ an $R[s^{\pm1}, t^{\pm1}]$-[module](wikipedia://en/276410). Then the **Alexander biquandle** is defined as $a \underline{\triangleright} b = ta + (s-t)b$ and $a \overline{\triangleright} b = sa$. For $s = 1$ this is a quandle.

:::
