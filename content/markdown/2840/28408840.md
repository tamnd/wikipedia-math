# Pytkeev space

::: {#o1 .subject cue=lead name="Pytkeev space"}

In mathematics, and especially [topology](wikipedia://en/29954), a **Pytkeev space** is a [topological space](wikipedia://en/30450) that satisfies qualities more subtle than a [convergence](wikipedia://en/1743431) of a [sequence](wikipedia://en/27838). They are named after E. G. Pytkeev, who proved in 1983 that [sequential spaces](wikipedia://en/4668395) have this property.[^o2]

:::

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let *X* be a topological space. For a subset *S* of *X* let *S* denote the [closure](wikipedia://en/42309) of *S*. Then a point *x* is called a *Pytkeev point* if for every set A with *x* ∈ *A* \\ {*x*}, there is a countable $\pi$-net of infinite subsets of *A*. A *Pytkeev space* is a space in which every point is a Pytkeev point.[^o5]

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [sequential space](wikipedia://en/4668395) is also a Pytkeev space. This is because, if *x* ∈ *A* \\ {*x*} then there exists a sequence {*a<sub>k</sub>*} that converges to *x*. So take the countable π-net of infinite subsets of *A* to be {*A<sub>k</sub>*} = {*a<sub>k</sub>*, *a*<sub>*k*+1</sub>, *a*<sub>*k*+2</sub>, …}.[^o5]
- If *X* is a Pytkeev space, then it is also a [Weakly Fréchet–Urysohn space](https://en.wikipedia.org/wiki/Weakly_Fréchet–Urysohn_space).

:::
