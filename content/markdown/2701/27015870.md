# Cunningham function

::: {#o1 .subject cue=lead name="Cunningham function"}

In [statistics](wikipedia://en/26685), the **Cunningham function** or **Pearson–Cunningham function** ω<sub>*m*,*n*</sub>(*x*) is a generalisation of a special function introduced by (Pearson 1906) and studied in the form here by (Cunningham 1908). It can be defined in terms of the [confluent hypergeometric function](wikipedia://en/1516095) *U*, by

:::

$$\displaystyle \omega_{m,n}(x) = \frac{e^{-x+\pi i (m/2-n)}}{\Gamma(1+n-m/2)}U(m/2-n,1+m,x).$$

The function was studied by Cunningham[^o4] in the context of a multivariate generalisation of the [Edgeworth expansion](https://en.wikipedia.org/wiki/Edgeworth_expansion) for approximating a [probability density function](wikipedia://en/43487) based on its (joint) [moments](wikipedia://en/368684). In a more general context, the function is related to the solution of the constant-coefficient [diffusion equation](wikipedia://en/645335), in one or more dimensions.[^o4]

The function ω<sub>*m*,*n*</sub>(*x*) is a solution of the differential equation for *X*:[^o4]

$$xX''+(x+1+m)X'+(n+\tfrac{1}{2}m+1)X.$$

The special function studied by Pearson is given, in his notation by,[^o4]

$$\omega_{2n}(x) =\omega_{0,n}(x).$$
