# LISREL

::: {#o1 .subject cue=lead name="LISREL"}

**LISREL** (**li**near **s**tructural **rel**ations) is a proprietary [statistical software package](https://en.wikipedia.org/wiki/List_of_statistical_packages) used in [structural equation modeling](wikipedia://en/2007748) (SEM) for [manifest](wikipedia://en/4237572) and [latent variables](https://en.wikipedia.org/wiki/Latent_variable).

:::

## History {#History}

LISREL was developed in the 1970s by [Karl Jöreskog](https://en.wikipedia.org/wiki/Karl_Jöreskog), then a scientist at [Educational Testing Service](https://en.wikipedia.org/wiki/Educational_Testing_Service) in [Princeton](https://en.wikipedia.org/wiki/Princeton,_New_Jersey), [New Jersey](https://en.wikipedia.org/wiki/New_Jersey),[^o3] and Dag Sörbom, later both professors of [Uppsala University](https://en.wikipedia.org/wiki/Uppsala_University) in [Sweden](https://en.wikipedia.org/wiki/Sweden).[^o4]

## Command language, graphical user interface {#Command_language,_graphical_user_interface}

LISREL is mainly syntax-based, although recent versions have featured a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) (GUI).

In early 2020, SSI was acquired by the Vector Psychometric Group, a US-based software and consulting company.[^o6]
