# Panama (cryptography)

::: {#o2 .subject cue=lead name="Panama"}

**Panama** is a cryptographic primitive which can be used both as a [hash function](https://en.wikipedia.org/wiki/Hash_function) and a [stream cipher](wikipedia://en/49007), but its hash function mode of operation has been broken and is not suitable for cryptographic use. Based on [StepRightUp](https://en.wikipedia.org/wiki/StepRightUp), it was designed by [Joan Daemen](https://en.wikipedia.org/wiki/Joan_Daemen) and Craig Clapp and presented in the paper *Fast Hashing and Stream Encryption with PANAMA* on the Fast Software Encryption (FSE) conference 1998.[^o3] The cipher has influenced several other designs, for example [MUGI](https://en.wikipedia.org/wiki/MUGI) and [SHA-3](wikipedia://en/20394543).[^o4][^o5]

:::

The primitive can be used both as a [hash function](https://en.wikipedia.org/wiki/Hash_function) and a [stream cipher](wikipedia://en/49007). The stream cipher uses a 256-bit key and the performance of the cipher is very good reaching 2 [cycles per byte](https://en.wikipedia.org/wiki/Cycles_per_byte).[^o6]

## Hash function {#Hash_function}

As a hash function, collisions have been shown by [Vincent Rijmen](https://en.wikipedia.org/wiki/Vincent_Rijmen) et al. in the paper *Producing Collisions for PANAMA* presented at FSE 2001. The attack shows a [computational complexity](wikipedia://en/7543) of 2<sup>82</sup> and with negligible memory requirements.[^o9]

At FSE 2007, Joan Daemen and Gilles Van Assche presented a practical attack on the Panama hash function that generates a collision in 2<sup>6</sup> evaluations of the state updating function.[^o10]

Guido Bertoni, [Joan Daemen](https://en.wikipedia.org/wiki/Joan_Daemen), Michaël Peeters, and Gilles Van Assche, at [NIST](https://en.wikipedia.org/wiki/NIST)'s 2006 Second Cryptographic Hash Workshop, unveiled a Panama variant called [RadioGatún](wikipedia://en/8625699). The hash function workings of RadioGatún does not have the known weaknesses that Panama's hash function has. In turn, RadioGatún inspired the new cryptographic standard [SHA-3](wikipedia://en/20394543).[^o4]
