# Arrival theorem

::: {#o1 .subject cue=lead name="Arrival theorem"}

In [queueing theory](wikipedia://en/50578), a discipline within the mathematical [theory of probability](wikipedia://en/23542), the **arrival theorem**[^o2] (also referred to as the **random observer property**, **ROP** or **job observer property**[^o3]) states that "upon arrival at a station, a job observes the system as if in steady state at an arbitrary instant for the system without that job."[^o4]

:::

## Overview {#Overview}

The arrival theorem always holds in open [product-form networks](wikipedia://en/21254527) with unbounded queues at each node, but it also holds in more general networks. A necessary and sufficient condition for the arrival theorem to be satisfied in product-form networks is given in terms of [Palm probabilities](https://en.wikipedia.org/wiki/Palm_probabilities) in Boucherie & Dijk, 1997.[^o6] A similar result also holds in some closed networks. Examples of product-form networks where the arrival theorem does not hold include reversible Kingman networks[^o6][^o7] and networks with a delay protocol.[^o4]

Mitrani offers the intuition that "The state of node *i* as seen by an incoming job has a different distribution from the state seen by a random observer. For instance, an incoming job can never see all **k*jobs present at node*i*, because it itself cannot be among the jobs already present."[^o8]***

::: {#o10 .statement kind=statement/theorem cue=named-heading name="Theorem for arrivals governed by a Poisson process"}

## Theorem for arrivals governed by a Poisson process {#Theorem_for_arrivals_governed_by_a_Poisson_process}

For [Poisson processes](https://en.wikipedia.org/wiki/Poisson_processes) the property is often referred to as the **PASTA property** (Poisson Arrivals See Time Averages) and states that the probability of the state as seen by an outside random observer is the same as the probability of the state seen by an arriving customer.[^o11] The property also holds for the case of a [doubly stochastic Poisson process](https://en.wikipedia.org/wiki/Doubly_stochastic_Poisson_process) where the rate parameter is allowed to vary depending on the state.[^o12]

:::

::: {#o14 .statement kind=statement/theorem cue=named-heading name="Theorem for Jackson networks"}

## Theorem for Jackson networks {#Theorem_for_Jackson_networks}

In an open [Jackson network](wikipedia://en/3374374) with *m* queues, write $\mathbf{n} = (n_1, n_2, \ldots, n_m)$ for the state of the network. Suppose $\pi(\mathbf{n})$ is the equilibrium probability that the network is in state $\mathbf{n}$. Then the probability that the network is in state $\mathbf{n}$ immediately before an arrival to any node is also $\pi(\mathbf{n})$.

Note that this theorem does not follow from [Jackson's theorem](https://en.wikipedia.org/wiki/Jackson's_theorem_%28queueing_theory%29), where the steady state in continuous time is considered. Here we are concerned with particular points in time, namely arrival times.[^o15] This theorem first published by Sevcik and Mitrani in 1981.[^o19]

:::

::: {#o17 .statement kind=statement/theorem cue=named-heading name="Theorem for Gordon–Newell networks"}

## Theorem for Gordon–Newell networks {#Theorem_for_Gordon–Newell_networks}

In a closed [Gordon–Newell network](https://en.wikipedia.org/wiki/Gordon–Newell_network) with *m* queues, write ${\mathbf{n} = (n_1, n_2, \ldots, n_m)}$ for the state of the network. For a customer in transit to state $i$, let ${\alpha_i(\mathbf{n}-\mathbf{e}_i)}$ denote the probability that immediately before arrival the customer 'sees' the state of the system to be

$$\mathbf{n}-\mathbf{e}_i = (n_1,n_2,\ldots,n_i - 1,\ldots,n_m).$$

This probability, ${\alpha_i(\mathbf{n}-\mathbf{e}_i)}$, is the same as the steady state probability for state ${\mathbf{n}-\mathbf{e}_i}$ for a network of the same type with *one customer less*.[^o18] It was published independently by Sevcik and Mitrani,[^o19] and Reiser and Lavenberg,[^o20] where the result was used to develop [mean value analysis](wikipedia://en/22440733).

:::
