# Aperiodic graph

::: {#o1 .subject cue=lead name="Aperiodic graph"}

*Image: Aperiodic-graph.svg.* An aperiodic graph. The cycles in this graph have lengths 5 and 6; therefore, there is no *k* > 1 that divides all cycle lengths.

*Image: Period-3-graph.svg.* A [strongly connected graph](wikipedia://en/684680) with period three.

In the [mathematical](wikipedia://en/18831) area of [graph theory](wikipedia://en/12401), a [directed graph](wikipedia://en/19721986) is said to be **aperiodic** if there is no [integer](wikipedia://en/14563) *k* > 1 that [divides](wikipedia://en/49492) the length of every [cycle](wikipedia://en/168609) of the graph. Equivalently, a graph is aperiodic if the [greatest common divisor](wikipedia://en/12354) of the lengths of its cycles is one; this greatest common divisor for a graph *G* is called the *period* of *G*.

:::

## Graphs that cannot be aperiodic {#Graphs_that_cannot_be_aperiodic}

In any directed [bipartite graph](wikipedia://en/244431), all cycle lengths are [even](wikipedia://en/143135). Therefore, no directed bipartite graph can be aperiodic. In any [directed acyclic graph](wikipedia://en/204002), it is a [vacuous truth](wikipedia://en/51672) that every *k* divides all cycles (because there are no directed cycles to divide) so no directed acyclic graph can be aperiodic. And in any directed [cycle graph](wikipedia://en/878962), there is only one cycle, so every cycle's length is divisible by *n*, the length of that cycle.

## Testing for aperiodicity {#Testing_for_aperiodicity}

Suppose that *G* is [strongly connected](https://en.wikipedia.org/wiki/Strongly_connected) and that *k* divides the lengths of all cycles in *G*. Consider the results of performing a [depth-first search](wikipedia://en/97034) of *G*, starting at any vertex, and assigning each vertex *v* to a set *V*<sub>*i*</sub> where *i* is the length (taken [modulo](wikipedia://en/20087) *k*) of the path in the depth-first search tree from the root to *v*. It can be shown (Jarvis Shier 1996) that this partition into sets *V*<sub>*i*</sub> has the property that each edge in the graph goes from a set *V<sub>i</sub>* to another set *V*<sub>(*i* + 1) mod *k*</sub>. [Conversely](wikipedia://en/155941), if a partition with this property exists for a strongly connected graph *G*, *k* must divide the lengths of all cycles in *G*.

Thus, we may find the period of a strongly connected graph *G* by the following steps:

- Perform a depth-first search of *G*
- For each *e* in *G* that connects a vertex on level *i* of the depth-first search tree to a vertex on level *j*, let *k*<sub>*e*</sub> = *j* − *i* − 1.
- Compute the greatest common divisor of the set of numbers *k*<sub>*e*</sub>.

The graph is aperiodic [if and only if](wikipedia://en/14922) the period computed in this fashion is 1.

If *G* is not strongly connected, we may perform a similar computation in each [strongly connected component](wikipedia://en/684680) of *G*, ignoring the edges that pass from one strongly connected component to another.

Jarvis and Shier describe a very similar algorithm using [breadth first search](https://en.wikipedia.org/wiki/Breadth_first_search) in place of depth-first search; the advantage of depth-first search is that the strong connectivity analysis can be incorporated into the same search.

## Applications {#Applications}

In a [strongly connected graph](wikipedia://en/684680), if one defines a [Markov chain](wikipedia://en/60876) on the vertices, in which the probability of transitioning from *v* to *w* is nonzero if and only if there is an edge from *v* to *w*, then this chain is aperiodic if and only if the graph is aperiodic. A Markov chain in which all states are recurrent has a strongly connected state transition graph, and the Markov chain is aperiodic if and only if this graph is aperiodic. Thus, aperiodicity of graphs is a useful concept in analyzing the aperiodicity of Markov chains.

Aperiodicity is also an important necessary condition for solving the [road coloring problem](https://en.wikipedia.org/wiki/Road_coloring_problem). According to the solution of this problem (Trahtman 2009), a strongly connected directed graph in which all vertices have the same [outdegree](https://en.wikipedia.org/wiki/Outdegree) has a synchronizable edge coloring if and only if it is aperiodic.
