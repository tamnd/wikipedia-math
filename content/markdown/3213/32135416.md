# Constructive function theory

::: {#o1 .subject cue=lead name="Constructive function theory"}

In [mathematical analysis](wikipedia://en/48396), **constructive function theory** is a field which studies the connection between the smoothness of a [function](wikipedia://en/185427) and its degree of [approximation](wikipedia://en/1092713).[^o2] It is closely related to [approximation theory](wikipedia://en/1092713). The term was coined by [Sergei Bernstein](wikipedia://en/976516).

:::

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

Let *f* be a 2*π*-periodic function. Then *f* is *α*-[Hölder](wikipedia://en/4005892) for some 0 \< *α* \< 1 if and only if for every natural *n* there exists a [trigonometric polynomial](wikipedia://en/591568) *P<sub>n</sub>* of degree *n* such that

$$\max_{0 \leq x \leq 2\pi} | f(x) - P_n(x) | \leq \frac{C(f)}{n^\alpha},$$

where *C*(*f*) is a positive number depending on *f*. The "only if" is due to [Dunham Jackson](https://en.wikipedia.org/wiki/Dunham_Jackson), see [Jackson's inequality](wikipedia://en/9356047); the "if" part is due to [Sergei Bernstein](wikipedia://en/976516), see [Bernstein's theorem (approximation theory)](wikipedia://en/32140327).

:::
