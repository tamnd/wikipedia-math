# Infrastructure (number theory)

::: {#o1 .subject cue=lead name="Infrastructure"}

In [mathematics](wikipedia://en/18831), an **infrastructure** is a [group](wikipedia://en/19447)-like structure appearing in [global fields](wikipedia://en/288358).

:::

## Historic development {#Historic_development}

In 1972, [D. Shanks](wikipedia://en/18171362) first discovered the infrastructure of a [real quadratic number field](wikipedia://en/454781) and applied his [baby-step giant-step](wikipedia://en/563928) algorithm to compute the [regulator](wikipedia://en/460227#The_regulator) of such a field in $\mathcal{O}(D^{1/4+\varepsilon})$ binary operations (for every $\varepsilon > 0$), where $D$ is the [discriminant](wikipedia://en/454781#Discriminant) of the quadratic field; previous methods required $\mathcal{O}(D^{1/2+\varepsilon})$ binary operations.[^o3] Ten years later, [H. W. Lenstra](https://en.wikipedia.org/wiki/Hendrik_Lenstra) published[^o4] a mathematical framework describing the infrastructure of a real quadratic number field in terms of "circular groups". It was also described by R. Schoof[^o5] and H. C. Williams,[^o6] and later extended by H. C. Williams, G. W. Dueck and B. K. Schmid to certain [cubic number fields](wikipedia://en/22076179) of [unit rank](wikipedia://en/460227) one[^o7][^o8] and by J. Buchmann and H. C. Williams to all number fields of unit rank one.[^o9] In his [habilitation thesis](https://en.wikipedia.org/wiki/Habilitation), J. Buchmann presented a baby-step giant-step algorithm to compute the regulator of a number field of *arbitrary* unit rank.[^o10] The first description of infrastructures in number fields of [arbitrary unit](https://en.wikipedia.org/wiki/Arbitrary_unit) rank was given by R. Schoof using [Arakelov divisors](https://en.wikipedia.org/wiki/Arakelov_divisor) in 2008.[^o11]

The infrastructure was also described for other [global fields](wikipedia://en/288358), namely for [algebraic function fields](wikipedia://en/447645) over [finite fields](wikipedia://en/11615). This was done first by A. Stein and H. G. Zimmer in the case of real [hyperelliptic](wikipedia://en/499361) function fields.[^o12] It was extended to certain [cubic function](wikipedia://en/243709) fields of unit rank one by [Renate Scheidler](wikipedia://en/77148270) and A. Stein.[^o13][^o14] In 1999, S. Paulus and H.-G. Rück related the infrastructure of a real [quadratic function](wikipedia://en/187240) field to the divisor class group.[^o15] This connection can be generalized to arbitrary function fields and, combining with R. Schoof's results, to all global fields.[^o16]

## One-dimensional case {#One-dimensional_case}

### Abstract definition {#Abstract_definition}

A **one-dimensional (abstract) infrastructure** $(X, d)$ consists of a [real number](wikipedia://en/20646438) $R > 0$, a [finite set](wikipedia://en/11742) $X \neq \emptyset$ together with an [injective](wikipedia://en/45196) map $d : X \to \mathbb{R}/R\mathbb{Z}$.[^o19] The map $d$ is often called the *distance map*.

By interpreting $\mathbb{R}/R\mathbb{Z}$ as a [circle](wikipedia://en/6220) of [circumference](wikipedia://en/5916) $R$ and by identifying $X$ with $d(X)$, one can see a one-dimensional infrastructure as a circle with a finite set of points on it.

### Baby steps {#Baby_steps}

A **baby step** is a [unary operation](wikipedia://en/161006) $bs : X \to X$ on a one-dimensional infrastructure $(X, d)$. Visualizing the infrastructure as a circle, a baby step assigns each point of $d(X)$ the next one. Formally, one can define this by assigning to $x \in X$ the real number $f_x := \inf\{ f' > 0 \mid d(x) + f' \in d(X) \}$; then, one can define $bs(x) := d^{-1}(d(x) + f_x)$.

### Giant steps and reduction maps {#Giant_steps_and_reduction_maps}

Observing that $\mathbb{R}/R\mathbb{Z}$ is naturally an [abelian group](wikipedia://en/2974), one can consider the sum $d(x) + d(y) \in \mathbb{R}/R\mathbb{Z}$ for $x, y \in X$. In general, this is not an element of $d(X)$. But instead, one can take an element of $d(X)$ which lies *nearby*. To formalize this concept, assume that there is a map $red : \mathbb{R}/R\mathbb{Z} \to X$; then, one can define $gs(x, y) := red(d(x) + d(y))$ to obtain a [binary operation](wikipedia://en/3948) $gs : X \times X \to X$, called the **giant step** operation. Note that this operation is in general *not* [associative](https://en.wikipedia.org/wiki/Associativity).

The main difficulty is how to choose the map $red$. Assuming that one wants to have the condition $red \circ d = \mathrm{id}_X$, a range of possibilities remain. One possible choice[^o19] is given as follows: for $v \in \mathbb{R}/R\mathbb{Z}$, define $f_v := \inf\{ f \ge 0 \mid v - f \in d(X) \}$; then one can define $red(v) := d^{-1}(v - f_v)$. This choice, seeming somewhat arbitrary, appears in a natural way when one tries to obtain infrastructures from global fields.[^o16] Other choices are possible as well, for example choosing an element $x \in d(X)$ such that $|d(x) - v|$ is minimal (here, $|d(x) - v|$ is stands for $\inf\{ |f - v| \mid f \in d(x) \}$, as $d(x)$ is of the form $v + R\mathbb{Z}$); one possible construction in the case of real quadratic hyperelliptic function fields is given by S. D. Galbraith, M. Harrison and D. J. Mireles Morales.[^o22]

### Relation to real quadratic fields {#Relation_to_real_quadratic_fields}

D. Shanks observed the infrastructure in real quadratic number fields when he was looking at cycles of reduced [binary quadratic forms](wikipedia://en/1867129). Note that there is a close relation between reducing binary quadratic forms and [continued fraction expansion](wikipedia://en/46802); one step in the continued fraction expansion of a certain [quadratic irrationality](https://en.wikipedia.org/wiki/Quadratic_irrational) gives a [unary operation](wikipedia://en/161006) on the set of reduced forms, which cycles through all reduced forms in one [equivalence class](wikipedia://en/9260). Arranging all these reduced forms in a cycle, Shanks noticed that one can quickly jump to reduced forms further away from the beginning of the circle by [composing](https://en.wikipedia.org/wiki/Composition_of_binary_quadratic_forms) two such forms and reducing the result. He called this [binary operation](wikipedia://en/3948) on the set of reduced forms a **giant step**, and the operation to go to the next reduced form in the cycle a **baby step**.

### Relation to $\mathbb{R}/R\mathbb{Z}$ {#Relation_to_\mathbb{R}/R\mathbb{Z}}

The set $\mathbb{R}/R\mathbb{Z}$ has a natural group operation and the giant step operation is defined in terms of it. Hence, it makes sense to compare the arithmetic in the infrastructure to the arithmetic in $\mathbb{R}/R\mathbb{Z}$. It turns out that the group operation of $\mathbb{R}/R\mathbb{Z}$ can be described using giant steps and baby steps, by representing elements of $\mathbb{R}/R\mathbb{Z}$ by elements of $X$ together with a relatively small real number; this has been first described by D. Hühnlein and S. Paulus[^o25] and by M. J. Jacobson, Jr., R. Scheidler and H. C. Williams[^o26] in the case of infrastructures obtained from real quadratic number fields. They used floating point numbers to represent the real numbers, and called these representations CRIAD-representations resp. $(f, p)$-representations. More generally, one can define a similar concept for all one-dimensional infrastructures; these are sometimes called $f$-representations.[^o19]

A **set of $f$-representations** is a subset $fRep$ of $X \times \mathbb{R}/R\mathbb{Z}$ such that the map $\Psi_{fRep} : fRep \to \mathbb{R}/R\mathbb{Z}, \; (x, f) \mapsto d(x) + f$ is a bijection and that $(x, 0) \in fRep$ for every $x \in X$. If $red : \mathbb{R}/R\mathbb{Z} \to X$ is a reduction map, $fRep_{red} := \{ (x, f) \in X \times \mathbb{R}/R\mathbb{Z} \mid red(d(x) + f) = x \}$ is a set of $f$-representations; conversely, if $fRep$ is a set of $f$-representations, one can obtain a reduction map by setting $red(f) = \pi_1(\Psi_{fRep}^{-1}(f))$, where $\pi_1 : X \times \mathbb{R}/R\mathbb{Z} \to X, \; (x, f) \mapsto x$ is the projection on \$X\$. Hence, sets of $f$-representations and reduction maps are in a [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence).

Using the bijection $\Psi_{fRep} : fRep \to \mathbb{R}/R\mathbb{Z}$, one can pull over the group operation on $\mathbb{R}/R\mathbb{Z}$ to $fRep$, hence turning $fRep$ into an abelian group $(fRep, +)$ by $x + y := \Psi_{fRep}^{-1}(\Psi_{fRep}(x) + \Psi_{fRep}(y))$, $x, y \in fRep$. In certain cases, this group operation can be explicitly described without using $\Psi_{fRep}$ and $d$.

In case one uses the reduction map $red : \mathbb{R}/R\mathbb{Z} \to X, \; v \mapsto d^{-1}(v - \inf\{ f \ge 0 \mid v - f \in d(X) \})$, one obtains $fRep_{red} = \{ (x, f) \mid f \ge 0, \; \forall f' \in [0, f) : d(x) + f' \not\in d(X) \}$. Given $(x, f), (x', f') \in fRep_{red}$, one can consider $(x'', f'')$ with $x'' = gs(x, x')$ and $f'' = f + f' + (d(x) + d(x') - d(gs(x, x'))) \ge 0$; this is in general no element of $fRep_{red}$, but one can reduce it as follows: one computes $bs^{-1}(x'')$ and $f'' - (d(x'') - d(bs^{-1}(x'')))$; in case the latter is not negative, one replaces $(x'', f'')$ with $(bs^{-1}(x''), f'' - (d(x'') - d(bs^{-1}(x''))))$ and continues. If the value was negative, one has that $(x'', f'') \in fRep_{red}$ and that $\Psi_{fRep_{red}}(x, f) + \Psi_{fRep_{red}}(x', f') = \Psi_{fRep_{red}}(x'', f'')$, i.e. $(x, f) + (x', f') = (x'', f'')$.
