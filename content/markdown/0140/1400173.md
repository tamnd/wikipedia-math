# Generic polynomial

::: {#o1 .subject cue=lead name="Generic polynomial"}

In [mathematics](wikipedia://en/18831), a **generic polynomial** refers usually to a [polynomial](wikipedia://en/23000) whose [coefficients](wikipedia://en/51203) are [indeterminates](https://en.wikipedia.org/wiki/Indeterminate_%28variable%29). For example, if $a$, $b$, and $c$ are indeterminates, the generic polynomial of degree two in $x$ is $ax^2+bx+c.$

:::

However in [Galois theory](wikipedia://en/61316), a branch of [algebra](wikipedia://en/18716923), and in this article, the term *generic polynomial* has a different, although related, meaning: a **generic polynomial** for a [finite group](wikipedia://en/323707) *G* and a [field](wikipedia://en/10603) *F* is a [monic polynomial](wikipedia://en/314730) *P* with coefficients in the [field of rational functions](https://en.wikipedia.org/wiki/Field_of_rational_functions) *L* = *F*(*t*<sub>1</sub>, ..., *t*<sub>*n*</sub>) in *n* indeterminates over *F*, such that the [splitting field](wikipedia://en/174440) *M* of *P* has [Galois group](wikipedia://en/12673) *G* over *L*, and such that every extension *K*/*F* with Galois group *G* can be obtained as the splitting field of a polynomial which is the specialization of *P* resulting from setting the *n* indeterminates to *n* elements of *F*. This is sometimes called *F-generic* or relative to the field *F*; a **Q**-*generic* polynomial, which is generic relative to the rational numbers is called simply generic.

The existence, and especially the construction, of a generic polynomial for a given Galois group provides a complete solution to the [inverse Galois problem](wikipedia://en/739166) for that group. However, not all Galois groups have generic polynomials, a counterexample being the [cyclic group](wikipedia://en/52327) of order eight.

## Groups with generic polynomials {#Groups_with_generic_polynomials}

- The [symmetric group](wikipedia://en/28901) *S*<sub>*n*</sub>. This is trivial, as

$$x^n + t_1 x^{n-1} + \cdots + t_n$$

is a generic polynomial for *S*<sub>*n*</sub>.

- Cyclic groups *C*<sub>*n*</sub>, where *n* is not [divisible](https://en.wikipedia.org/wiki/Divisibility) by eight. [Lenstra](https://en.wikipedia.org/wiki/Hendrik_Lenstra) showed that a cyclic group does not have a generic polynomial if *n* is divisible by eight, and G. W. Smith explicitly constructs such a polynomial in case *n* is not divisible by eight.
- The cyclic group construction leads to other classes of generic polynomials; in particular the [dihedral group](wikipedia://en/100267) *D*<sub>*n*</sub> has a generic polynomial if and only if *n* is not divisible by eight.
- The [quaternion group](wikipedia://en/153130) *Q*<sub>8</sub>.
- [Heisenberg groups](wikipedia://en/448518) $H_{p^3}$ for any [odd](wikipedia://en/143135) [prime](wikipedia://en/23666) *p*.
- The [alternating group](wikipedia://en/49726) *A*<sub>4</sub>.
- The alternating group *A*<sub>5</sub>.
- Reflection groups defined over **Q**, including in particular groups of the root systems for *E*<sub>6</sub>, *E*<sub>7</sub>, and *E*<sub>8</sub>.
- Any group which is a [direct product](wikipedia://en/3706015) of two groups both of which have generic polynomials.
- Any group which is a [wreath product](wikipedia://en/146625) of two groups both of which have generic polynomials.

## Examples of generic polynomials {#Examples_of_generic_polynomials}

| Group | Generic Polynomial |
|---|---|
| *C*<sub>*2*</sub> | $x^2-t$ |
| *C*<sub>*3*</sub> | $x^3-tx^2+(t-3)x+1$ |
| *S*<sub>*3*</sub> | $x^3-t(x+1)$ |
| *V* | $(x^2-s)(x^2-t)$ |
| *C*<sub>*4*</sub> | $x^4-2s(t^2+1)x^2+s^2t^2(t^2+1)$ |
| *D*<sub>*4*</sub> | $x^4 - 2stx^2 + s^2t(t-1)$ |
| *S*<sub>*4*</sub> | $x^4+sx^2-t(x+1)$ |
| *D*<sub>*5*</sub> | $x^5+(t-3)x^4+(s-t+3)x^3+(t^2-t-2s-1)x^2+sx+t$ |
| *S*<sub>*5*</sub> | $x^5+sx^3-t(x+1)$ |

Generic polynomials are known for all transitive groups of degree 5 or less.

## Generic dimension {#Generic_dimension}

The **generic dimension** for a finite group *G* over a field *F*, denoted $gd_{F}G$, is defined as the minimal number of parameters in a generic polynomial for *G* over *F*, or $\infty$ if no generic polynomial exists.

Examples:

- $$gd_{\mathbb{Q}}A_3=1$$
- $$gd_{\mathbb{Q}}S_3=1$$
- $$gd_{\mathbb{Q}}D_4=2$$
- $$gd_{\mathbb{Q}}S_4=2$$
- $$gd_{\mathbb{Q}}D_5=2$$
- $$gd_{\mathbb{Q}}S_5=2$$
