# Ordinal definable set

::: {#o1 .subject cue=lead name="Ordinal definable set"}

In [mathematical](wikipedia://en/18831) [set theory](wikipedia://en/27553), a [set](wikipedia://en/26691) *S* is said to be **ordinal definable** if, informally, it can be defined in terms of a finite number of [ordinals](wikipedia://en/26547932) by a [first-order formula](https://en.wikipedia.org/wiki/First-order_formula). Ordinal definable sets were introduced by (Gödel 1965).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A drawback to the above informal definition is that it requires quantification over all first-order formulas, which cannot be formalized in the standard language of set theory. However, there is a different, formal such characterization:

A set *S* is **ordinal definable** if there is some collection of ordinals *α*<sub>1</sub>, ..., *α*<sub>*n*</sub> and a first-order formula *φ* taking *α*<sub>2</sub>, ..., *α*<sub>*n*</sub> as parameters that uniquely defines $S$ as an element of $V_{\alpha_1}$, i.e., such that *S* is the unique object validating *φ*(*S*, *α*<sub>2</sub>,...,*α*<sub>*n*</sub>), with its quantifiers ranging over $V_{\alpha_1}$.

The latter denotes the set in the [von Neumann hierarchy](wikipedia://en/445980) indexed by the ordinal *α*<sub>1</sub>. The [class](https://en.wikipedia.org/wiki/Proper_class) of all ordinal definable sets is denoted OD; it is not necessarily [transitive](wikipedia://en/2462396), and need not be a model of [ZFC](https://en.wikipedia.org/wiki/ZFC) because it might not satisfy the [axiom of extensionality](wikipedia://en/52376).

A set further is **hereditarily ordinal definable** if it is ordinal definable and all elements of its [transitive closure](wikipedia://en/2462396) are ordinal definable. The class of hereditarily ordinal definable sets is denoted by HOD, and is a [transitive model](https://en.wikipedia.org/wiki/Transitive_model) of ZFC, with a definable well ordering.

It is consistent with the axioms of set theory that all sets are ordinal definable, and so hereditarily ordinal definable. The assertion that this situation holds is referred to as V = OD or V = HOD. It follows from [V = L](https://en.wikipedia.org/wiki/V_=_L), and is equivalent to the existence of a (definable) [well-ordering](wikipedia://en/33456) of the universe. Note however that the formula expressing V = HOD need not hold true within HOD, as it is not [absolute](wikipedia://en/12374236) for models of set theory: within HOD, the interpretation of the formula for HOD may yield an even smaller inner model.

HOD has been found to be useful in that it is an [inner model](wikipedia://en/1118686) that can accommodate essentially all known [large cardinals](wikipedia://en/383644). This is in contrast with the situation for [core models](wikipedia://en/3781904), as core models have not yet been constructed that can accommodate [supercompact cardinals](wikipedia://en/248116), for example.
