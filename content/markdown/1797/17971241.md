# Barwise compactness theorem

::: {#o1 .subject cue=lead name="Barwise compactness theorem"}

In [mathematical logic](wikipedia://en/19636), the **Barwise compactness theorem**, named after [Jon Barwise](wikipedia://en/912858), is a generalization of the usual [compactness theorem](wikipedia://en/152207) for [first-order logic](wikipedia://en/10983) to a certain class of [infinitary languages](https://en.wikipedia.org/wiki/Infinitary_language). It was stated and proved by Barwise in 1967.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $A$ be a countable [admissible set](wikipedia://en/5138993). Let $L$ be an $A$-finite relational [language](wikipedia://en/10939). Suppose $\Gamma$ is a set of $L_A$-sentences, where $\Gamma$ is a $\Sigma_1$ set with parameters from $A$, and every $A$-finite subset of $\Gamma$ is [satisfiable](wikipedia://en/23401166). Then $\Gamma$ is satisfiable.

:::
