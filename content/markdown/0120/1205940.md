# Stein factorization

::: {#o1 .subject cue=lead name="Stein factorization"}

In [algebraic geometry](wikipedia://en/1997), the **Stein factorization**, introduced by (txt) for the case of complex spaces, states that a [proper morphism](wikipedia://en/603782) of [schemes](wikipedia://en/364754) can be factorized as a composition of a [finite mapping](wikipedia://en/2139357) and a proper morphism with [connected](wikipedia://en/6233) fibers. Roughly speaking, Stein factorization contracts the connected components of the fibers of a mapping to points.

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

One version for schemes states the following: (EGA, III.4.3.1)

> Let *X* be a [scheme](wikipedia://en/364754), *S* a [locally noetherian scheme](https://en.wikipedia.org/wiki/Locally_noetherian_scheme) and $f: X \to S$ a [proper morphism](wikipedia://en/603782). Then one can write
>
> $f = g \circ f'$ where $g\colon S' \to S$ is a [finite morphism](wikipedia://en/2139357) and $f'\colon X \to S'$ is a proper morphism so that $f'_* \mathcal{O}_X = \mathcal{O}_{S'}.$

The existence of this decomposition itself is not difficult. See below. But, by [Zariski's connectedness theorem](wikipedia://en/13982192), the last part in the above says that the fiber $f'^{-1}(s)$ is connected for any $s \in S'$. It follows:

::: {#o6 .statement kind=statement/corollary cue=inline-head name="Corollary"}

**Corollary**: For any $s \in S$, the set of connected components of the fiber $f^{-1}(s)$ is in bijection with the set of points in the fiber $g^{-1}(s)$.

:::

:::

::: {#o8 .proof cue=heading name="Proof"}

## Proof {#Proof}

Set:

$$S' = \operatorname{Spec}_S f_* \mathcal{O}_X$$

where Spec<sub>*S*</sub> is the [relative **Spec**](https://en.wikipedia.org/wiki/Relative_Spec). The construction gives the natural map $g\colon S' \to S$, which is finite since $\mathcal{O}_X$ is [coherent](wikipedia://en/603780) and *f* is proper. The morphism *f* factors through *g* and one gets $f'\colon X \to S'$, which is proper. By construction, $f'_* \mathcal{O}_X = \mathcal{O}_{S'}$. One then uses the [theorem on formal functions](wikipedia://en/36834283) to show that the last equality implies $f'$ has connected fibers. (This part is sometimes referred to as Zariski's connectedness theorem.)

:::
