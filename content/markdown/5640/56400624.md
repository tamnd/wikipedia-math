# Universal homeomorphism

::: {#o1 .subject cue=lead name="Universal homeomorphism"}

In [algebraic geometry](wikipedia://en/1997), a **universal homeomorphism** is a [morphism of schemes](wikipedia://en/7482797) $f: X \to Y$ such that, for each morphism $Y' \to Y$, the base change $X \times_Y Y' \to Y'$ is a [homeomorphism](wikipedia://en/13660) of topological spaces.

:::

A morphism of schemes is a universal homeomorphism if and only if it is [integral](wikipedia://en/9478630#Integral_morphisms), [radicial](wikipedia://en/14483490) and surjective.[^o2] In particular, a morphism of locally of finite type is a universal homeomorphism if and only if it is [finite](wikipedia://en/2139357), radicial and surjective.

For example, an [absolute Frobenius morphism](https://en.wikipedia.org/wiki/Absolute_Frobenius_morphism) is a universal homeomorphism.
