# Kuratowski embedding

::: {#o1 .subject cue=lead name="Kuratowski embedding"}

In [mathematics](wikipedia://en/18831), the **Kuratowski embedding** allows one to view any [metric space](wikipedia://en/20018) as a subset of some [Banach space](wikipedia://en/3989). It is named after [Kazimierz Kuratowski](wikipedia://en/46075).

:::

The statement obviously holds for the empty space. If (*X*,*d*) is a metric space, *x*<sub>0</sub> is a point in *X*, and *C<sub>b</sub>*(*X*) denotes the Banach space of all bounded [continuous](wikipedia://en/6122) real-valued functions on *X* with the [supremum norm](wikipedia://en/349755), then the map

$$\Phi : X \rightarrow C_b(X)$$

defined by

$$\Phi(x)(y) = d(x,y)-d(x_0,y) \quad\mbox{for all}\quad x,y\in X$$

is an [isometry](wikipedia://en/254777).[^o2]

The above construction can be seen as embedding a [pointed metric space](wikipedia://en/1236666) into a Banach space.

The **Kuratowski–Wojdysławski** theorem states that every bounded metric space *X* is isometric to a [closed subset](wikipedia://en/47279) of a [convex](wikipedia://en/6292) subset of some Banach space.[^o3] (N.B. the image of this embedding is closed in the convex subset, not necessarily in the Banach space.) Here we use the isometry

$$\Psi : X \rightarrow C_b(X)$$

defined by

$$\Psi(x)(y) = d(x,y) \quad\mbox{for all}\quad x,y\in X$$

The convex set mentioned above is the [convex hull](wikipedia://en/40634) of Ψ(*X*).

In both of these embedding theorems, we may replace *C<sub>b</sub>*(*X*) by the Banach space *ℓ*<sup>∞</sup>(*X*) of all bounded functions *X* → **R**, again with the supremum norm, since *C<sub>b</sub>*(*X*) is a closed linear subspace of *ℓ*<sup>∞</sup>(*X*).

These embedding results are useful because Banach spaces have a number of useful properties not shared by all metric spaces: they are [vector spaces](wikipedia://en/32370) which allows one to add points and do elementary geometry involving lines and planes etc.; and they are [complete](https://en.wikipedia.org/wiki/Complete_space). Given a function with [codomain](wikipedia://en/50264) *X*, it is frequently desirable to extend this function to a larger domain, and this often requires simultaneously enlarging the codomain to a Banach space containing *X*.

## History {#History}

Formally speaking, this embedding was first introduced by [Kuratowski](wikipedia://en/46075),[^o5] but a very close variation of this embedding appears already in the papers of [Fréchet](https://en.wikipedia.org/wiki/Maurice_Fréchet). Those papers make use of the embedding respectively to exhibit $\ell^\infty$ as a "universal" [separable metric space](https://en.wikipedia.org/wiki/Separable_metric_space) (it isn't itself separable, hence the scare quotes)[^o6] and to construct a general metric on $\mathbb{R}$ by pulling back the metric on a simple [Jordan curve](https://en.wikipedia.org/wiki/Jordan_curve) in $\ell^\infty$.[^o7]
