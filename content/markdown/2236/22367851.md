# Biordered set

::: {#o1 .subject cue=lead name="Biordered set"}

A **biordered set** (otherwise known as **boset**) is a [mathematical object](wikipedia://en/19453961) that occurs in the description of the [structure](https://en.wikipedia.org/wiki/Structure) of the set of [idempotents](https://en.wikipedia.org/wiki/Idempotent) in a [semigroup](wikipedia://en/27799).

:::

The set of idempotents in a semigroup is a biordered set and every biordered set is the set of idempotents of some semigroup.[^o6][^o2] A regular biordered set is a biordered set with an additional property. The set of idempotents in a [regular semigroup](wikipedia://en/6797677) is a regular biordered set, and every regular biordered set is the set of idempotents of some regular semigroup.[^o6]

## History {#History}

The concept and the terminology were developed by [K S S Nambooripad](https://en.wikipedia.org/wiki/K_S_S_Nambooripad) in the early 1970s.[^o4][^o5][^o6] In 2002, Patrick Jordan introduced the term boset as an abbreviation of biordered set.[^o7] The defining properties of a biordered set are expressed in terms of two [quasiorders](https://en.wikipedia.org/wiki/Quasiorder) defined on the set and hence the name biordered set.

According to Mohan S. Putcha, "The axioms defining a biordered set are quite complicated. However, considering the general nature of semigroups, it is rather surprising that such a finite axiomatization is even possible."[^o8] Since the publication of the original definition of the biordered set by Nambooripad, several variations in the definition have been proposed. David Easdown simplified the definition and formulated the axioms in a special arrow notation invented by him.[^o9]

## Definition {#Definition}

### Preliminaries {#Preliminaries}

If *X* and *Y* are [sets](wikipedia://en/26691) and $\rho \subseteq X \times Y$, let $\rho (y) = \{x \in X : x \rho y\}.$

Let *E* be a [set](wikipedia://en/26691) in which a [partial](wikipedia://en/23577) [binary operation](wikipedia://en/3948), indicated by juxtaposition, is defined. If *D*<sub>*E*</sub> is the [domain](wikipedia://en/50263) of the partial binary operation on *E* then *D*<sub>*E*</sub> is a [relation](wikipedia://en/22517558) on *E* and (*e*,*f*) is in *D*<sub>*E*</sub> if and only if the product *ef* exists in *E*. The following relations can be defined in *E*:

$$\omega^r = \{(e,f) \, :\, fe = e\}$$

$$\omega^l = \{ (e,f)\, :\, ef = e \}$$

$$R = \omega^r\, \cap \, (\omega^r)^{-1}$$

$$L = \omega^l\, \cap \, (\omega^l)^{-1}$$

$$\omega = \omega^r \, \cap \, \omega^l$$

If *T* is any [statement](https://en.wikipedia.org/wiki/Proposition_%28mathematics%29) about *E* involving the partial binary operation and the above relations in *E*, one can define the left-right [dual](https://en.wikipedia.org/wiki/Dual_%28mathematics%29) of *T* denoted by *T*\*. If *D*<sub>*E*</sub> is [symmetric](wikipedia://en/200459) then *T*\* is meaningful whenever *T* is.

::: {#o14 .definition cue=heading name="Formal definition"}

### Formal definition {#Formal_definition}

The set *E* is called a biordered set if the following [axioms](wikipedia://en/928) and their duals hold for arbitrary elements *e*, *f*, *g*, etc. in *E*.

(B1) $\omega^{r}$ and $\omega^{l}$ are [reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200463) relations on *E* and $D_{E} = (\omega^{r} \cup \omega^{l}) \cup (\omega^{r} \cup \omega^{l})^{-1}.$

(B21) If *f* is in *ω*<sup>*r*</sup>(*e*) then *f R fe ω e*.

(B22) If $g \omega^{l} f$ and if *f* and *g* are in $\omega^{r} (e)$ then $ge \omega^{l} fe$.

(B31) If $g \omega^{r} f$ and $f \omega^{r} e$ then *gf* = (*ge*)*f*.

(B32) If $g \omega^{l} f$ and if *f* and *g* are in $\omega^{r} (e)$ then (*fg*)*e* = (*fe*)(*ge*).

In $M (e, f) = \omega^{l} (e) \cap \omega^{r} (f)$ (the ***M*-set** of *e* and *f* in that order), define a relation $\prec$ by

$$g \prec h\quad \Longleftrightarrow \quad eg \,\,\omega^r\,\, eh\,,\,\,\, gf\,\, \omega^l \,\,hf.$$

Then the set

$$S(e,f) = \{ h\in M(e,f) : g\prec h \text{ for all } g\in M(e,f) \}$$

is called the **sandwich set** of *e* and *f* in that order.

(B4) If *f* and *g* are in *ω*<sup>*r*</sup> (*e*) then *S*(*f*, *g*)*e* = *S* (*fe*, *ge*).

:::

### *M*-biordered sets and regular biordered sets {#M-biordered_sets_and_regular_biordered_sets}

We say that a biordered set *E* is an ***M*-biordered set** if *M* (*e*, *f*) ≠ ∅ for all *e* and *f* in *E*. Also, *E* is called a **regular biordered set** if *S* (*e*, *f*) ≠ ∅ for all *e* and *f* in *E*.

In 2012 Roman S. Gigoń gave a simple proof that *M*-biordered sets arise from [*E*-inversive semigroups](https://en.wikipedia.org/wiki/E-inversive_semigroup).[^o16]

:::

## Subobjects and morphisms {#Subobjects_and_morphisms}

### Biordered subsets {#Biordered_subsets}

A subset *F* of a biordered set *E* is a biordered subset (subboset) of *E* if *F* is a biordered set under the partial binary operation inherited from *E*.

For any *e* in *E* the sets $\omega^{r} (e), \omega^{l} (e)$ and $\omega (e)$ are biordered subsets of *E*.[^o6]

### Bimorphisms {#Bimorphisms}

A mapping *φ* : *E* → *F* between two biordered sets *E* and *F* is a biordered set homomorphism (also called a bimorphism) if for all (*e*, *f*) in *D*<sub>*E*</sub> we have (*eφ*) (*fφ*) = (*ef*)*φ*.

## Illustrative examples {#Illustrative_examples}

### Vector space example {#Vector_space_example}

Let *V* be a [vector space](wikipedia://en/32370) and

$$E = \{(A, B)\mid V = A \oplus B\}$$

where *V* = *A* ⊕ *B* means that *A* and *B* are [subspaces](wikipedia://en/56357) of *V* and *V* is the [internal direct sum](https://en.wikipedia.org/wiki/Internal_direct_sum) of *A* and *B*. The partial binary operation ⋆ on E defined by

$$(A, B) \star (C, D) = (A + ( B \cap C), (B + C) \cap D )$$

makes *E* a biordered set. The quasiorders in *E* are characterised as follows:

$$(A, B) \omega^{r} (C, D) \Leftrightarrow A \supseteq C$$

$$(A, B) \omega^{l} (C, D) \Leftrightarrow B \subseteq D$$

### Biordered set of a semigroup {#Biordered_set_of_a_semigroup}

The set *E* of idempotents in a semigroup *S* becomes a biordered set if a partial binary operation is defined in *E* as follows: *ef* is defined in *E* if and only if $ef = e$ or $ef = f$ or $fe = e$ or $fe = f$ holds in *S*. If *S* is a regular semigroup then *E* is a regular biordered set.

As a concrete example, let *S* be the semigroup of all mappings of $X = \{1, 2, 3\}$ into itself. Let the symbol (*abc*) denote the map for which $1 \to a, 2 \to b,$ and $3 \to c$. The set *E* of idempotents in *S* contains the following elements:

(111), (222), (333) (constant maps)

(122), (133), (121), (323), (113), (223)

(123) (identity map)
