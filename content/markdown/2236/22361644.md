# Lattice word

::: {#o1 .subject cue=lead name="Lattice word"}

In [mathematics](wikipedia://en/18831), a **lattice word** (or **lattice permutation**) is a [string](wikipedia://en/27701#Formal_theory) composed of positive [integers](wikipedia://en/14563), in which every [prefix](https://en.wikipedia.org/wiki/Prefix_%28computer_science%29) contains at least as many positive integers *i* as integers *i* + 1.

:::

A **reverse lattice word**, or **Yamanouchi word** (named after [Takahiko Yamanouchi](https://en.wikipedia.org/wiki/Takahiko_Yamanouchi)), is a string whose [reversal](wikipedia://en/27701#Reversal) is a lattice word.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

For instance, 11122121 is a lattice permutation, so 12122111 is a Yamanouchi word, but 12122111 is not a lattice permutation, since the prefix 12122 contains more 2s than 1s.

:::
