# Intersection type discipline

::: {#o1 .subject cue=lead name="Intersection type discipline"}

In [mathematical logic](wikipedia://en/19636), the **intersection type discipline** is a branch of [type theory](wikipedia://en/40282) encompassing [type systems](wikipedia://en/199701) that use the **intersection type constructor** $(\cap)$ to assign multiple types to a single term.[^o35] In particular, if a term $M$ can be assigned *both* the type $\varphi_1$ and the type $\varphi_2$, then $M$ can be assigned the [intersection type](wikipedia://en/24140211) $\varphi_1 \cap \varphi_2$ (and vice versa). Therefore, the intersection [type constructor](wikipedia://en/24047271) can be used to express finite heterogeneous [ad hoc polymorphism](https://en.wikipedia.org/wiki/Ad_hoc_polymorphism) (as opposed to [parametric polymorphism](https://en.wikipedia.org/wiki/Parametric_polymorphism)). For example, the [λ-term](wikipedia://en/44382704#Definition) $\lambda x.\!(x\;x)$ can be assigned the type $((\alpha \to \beta) \cap \alpha) \to \beta$ in most intersection type systems, assuming for the term variable $x$ both the [function type](wikipedia://en/583532) $\alpha \to \beta$ and the corresponding argument type $\alpha$.

:::

Prominent intersection type systems include the Coppo–Dezani type assignment system,[^o25] the Barendregt-Coppo–Dezani type assignment system,[^o28] and the essential intersection type assignment system.[^o34] Most strikingly, intersection type systems are closely related to (and often exactly characterize) normalization properties of [λ-terms](wikipedia://en/44382704#Definition) under [β-reduction](wikipedia://en/44382704#β-reduction).

In programming languages, such as TypeScript[^o2] and Scala,[^o3] intersection types are used to express [ad hoc polymorphism](https://en.wikipedia.org/wiki/Ad_hoc_polymorphism).

## History {#History}

The intersection type discipline was pioneered by Mario Coppo, [Mariangiola Dezani-Ciancaglini](wikipedia://en/65506526), Patrick Sallé, and Garrel Pottinger.[^o25][^o26][^o24] The underlying motivation was to study semantic properties (such as [normalization](https://en.wikipedia.org/wiki/Normalization_property_%28abstract_rewriting%29)) of the [λ-calculus](wikipedia://en/44382704) by means of [type theory](wikipedia://en/40282).[^o23] While the initial work by Coppo and Dezani established a type theoretic characterization of strong normalization for the λI-calculus,[^o25] Pottinger extended this characterization to the λK-calculus.[^o26] In addition, Sallé contributed the notion of the universal type $\omega$ that can be assigned to any λ-term, thereby corresponding to the empty intersection.[^o24] Using the universal type $\omega$ allowed for a fine-grained analysis of head normalization, normalization, and strong normalization.[^o27] In collaboration with [Henk Barendregt](wikipedia://en/1651213), a filter λ-model for an intersection type system was given, tying intersection types ever more closely to λ-calculus semantics.

Due to the correspondence with normalization, [typability](https://en.wikipedia.org/wiki/Typability) in infinite intersection type systems is [undecidable](wikipedia://en/15631055). However restricting intersection types to finite rank makes their typeability decidable for any finite rank, which is in contrast with [system F](wikipedia://en/767637), where (quantifier) restrictions to finite ranks above 3 still have undecidable typeability.[^o5] On the other hand, if [recursive types](https://en.wikipedia.org/wiki/Recursive_type) are added to a system with rank-2 or higher intersection types, typability becomes undecidable, in general.[^o6]

Complementarily, [undecidability](wikipedia://en/15631055) of the dual problem of [type inhabitation](https://en.wikipedia.org/wiki/Type_inhabitation) in prominent intersection type systems was proven by Paweł Urzyczyn.[^o32] Later, this result was refined showing [exponential space completeness](wikipedia://en/54703) of rank 2 intersection type inhabitation and [undecidability](wikipedia://en/15631055) of rank 3 intersection type inhabitation.[^o33] Remarkably, [principal type](https://en.wikipedia.org/wiki/Principal_type) inhabitation is decidable in [polynomial time](wikipedia://en/658550).[^o37]

To deal with the difficulties in applying the [Curry-Howard correspondence](https://en.wikipedia.org/wiki/Curry-Howard_correspondence) to intersection types, Kamareddine and Wells have replaced the intersection constructor in the deduction system with finite-set declarations (FSD) for the domain of each variable in a lambda abstraction, turning them into [Π types](wikipedia://en/1949487#Π_type). And they extended the [lambda cube](wikipedia://en/901593) to what they call the f-cube, which has with FSD-encoded intersection types at all vertices. [Urzyczyn's term U](wikipedia://en/49481270), which is untypable in the λ-cube, is typable in the f-cube.[^o7]

## Coppo–Dezani type assignment system {#Coppo–Dezani_type_assignment_system}

The **Coppo–Dezani type assignment system** $(\vdash_{\text{CD}})$ extends the [simply typed λ-calculus](wikipedia://en/1986011) by allowing multiple types to be assumed for a term variable.[^o25]

### Term language {#Term_language}

The term language of $(\vdash_\text{CD})$ is given by [λ-terms](wikipedia://en/44382704#Definition) (or, [lambda expressions](wikipedia://en/44382704#Definition)):

$$\begin{aligned} M, N & ::= x \mid (\lambda x.\!M) \mid (M\;N) && \text{ where } x \text{ ranges over term variables}\\ \end{aligned}$$

### Type language {#Type_language}

The type language of $(\vdash_\text{CD})$ is inductively defined by the following grammar:

$$\begin{aligned} \varphi & ::= \alpha \mid \sigma \to \varphi && \text{ where } \alpha \text{ ranges over type variables}\\ \sigma & ::= \varphi_1 \cap \cdots \cap \varphi_n && \text{ where } n \geq 1 \end{aligned}$$

The intersection type constructor ($\cap$) is taken modulo associativity, commutativity and [idempotence](wikipedia://en/14972).

### Typing rules {#Typing_rules}

The [typing rules](https://en.wikipedia.org/wiki/Typing_rule) $(\to\!\!\text{I})$, $(\to\!\!\text{E})$, $(\cap\text{I})$, and $(\cap\text{E})$ of $(\vdash_\text{CD})$ are:

$$\begin{array}{cc} \dfrac{\Gamma, x : \sigma \vdash_\text{CD} M : \varphi}{\Gamma \vdash_\text{CD} \lambda x.\!M : \sigma \to \varphi}(\to\!\!\text{I}) &\dfrac{\Gamma \vdash_\text{CD} M : \sigma \to \varphi \quad \Gamma \vdash_\text{CD} N : \sigma}{\Gamma \vdash_\text{CD} M\;N : \varphi}(\to\!\!\text{E})\\\\ \dfrac{\Gamma \vdash_\text{CD} M : \varphi_1 \quad \ldots \quad \Gamma \vdash_\text{CD} M : \varphi_n}{\Gamma \vdash_\text{CD} M : \varphi_1 \cap \cdots \cap \varphi_n}(\cap\text{I}) &\dfrac{(1 \leq i \leq n)}{\Gamma, x : \varphi_1 \cap \cdots \cap \varphi_n \vdash_\text{CD} x : \varphi_i}(\cap\text{E}) \end{array}$$

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

Typability and normalization are closely related in $(\vdash_{\text{CD}})$ by the following properties:[^o25]

- **[Subject reduction](https://en.wikipedia.org/wiki/Subject_reduction)**: If $\Gamma \vdash_{\text{CD}} M : \sigma$ and $M \to_\beta N$, then $\Gamma \vdash_{\text{CD}} N : \sigma$.
- **[Normalization](https://en.wikipedia.org/wiki/Normalization_property_%28abstract_rewriting%29)**: If $\Gamma \vdash_{\text{CD}} M : \sigma$, then $M$ has a [β-normal form](wikipedia://en/1800460).
- **Typability of [strongly normalizing](https://en.wikipedia.org/wiki/Normalization_property_%28abstract_rewriting%29) λ-terms**: If $M$ is [strongly normalizing](https://en.wikipedia.org/wiki/Normalization_property_%28abstract_rewriting%29), then $\Gamma \vdash_{\text{CD}} M : \sigma$ for some $\Gamma$ and $\sigma$.
- **Characterization of λI-normalization**: $M$ has a normal form in the λI-calculus, [if and only if](wikipedia://en/14922) $\Gamma \vdash_{\text{CD}} M : \sigma$ for some $\Gamma$ and $\sigma$.

If the type language is extended to contain the empty intersection, i.e. $\sigma = \varphi_1 \cap \cdots \cap \varphi_n \text{ where } n = 0$, then $(\vdash_{\text{CD}})$ is closed under β-equality and is sound and complete for inference semantics.[^o30]

:::

## Barendregt–Coppo–Dezani type assignment system {#Barendregt–Coppo–Dezani_type_assignment_system}

The **Barendregt–Coppo–Dezani type assignment system** $(\vdash_{\text{BCD}})$ extends the Coppo–Dezani type assignment system in the following three aspects:[^o28]

- $(\vdash_\text{BCD})$ introduces the **universal type constant** $\omega$ (akin to the empty intersection) that can be assigned to any λ-term.
- $(\vdash_{\text{BCD}})$ allows the intersection type constructor $(\cap)$ to appear on the right-hand side of the arrow type constructor $(\to)$.
- $(\vdash_\text{BCD})$ introduces the **intersection type subtyping** $(\leq)$ partial order on types together with a corresponding typing rule.

### Term language {#Term_language}

The term language of $(\vdash_{\text{BCD}})$ is given by [λ-terms](wikipedia://en/44382704#Definition) (or, [lambda expressions](wikipedia://en/44382704#Definition)):

$$\begin{aligned} M, N & ::= x \mid (\lambda x.\!M) \mid (M\;N) && \text{ where } x \text{ ranges over term variables}\\ \end{aligned}$$

### Type language {#Type_language}

The type language of $(\vdash_{\text{BCD}})$ is inductively defined by the following grammar:

$$\begin{aligned} \sigma, \tau & ::= \alpha \mid \omega \mid \sigma \to \tau \mid \sigma \cap \tau && \text{ where } \alpha \text{ ranges over type variables} \end{aligned}$$

### Intersection type subtyping {#Intersection_type_subtyping}

Intersection type [subtyping](wikipedia://en/213508) $(\leq)$ is defined as the smallest [preorder](wikipedia://en/23582) ([reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200458) relation) over intersection types satisfying the following properties:

$$\begin{aligned} &\sigma \leq \omega, \quad \omega \leq \omega\to\omega, \quad \sigma \cap \tau \leq \sigma, \quad \sigma \cap \tau \leq \tau, \\ & (\sigma\to\tau_1) \cap (\sigma\to\tau_2) \leq \sigma \to \tau_1 \cap \tau_2,\\ &\text{if }\sigma \leq \tau_1 \text{ and } \sigma\leq \tau_2 \text{, then } \sigma \leq \tau_1 \cap \tau_2, \\ &\text{if } \sigma_2 \leq \sigma_1 \text{ and } \tau_1 \leq \tau_2 \text{, then } \sigma_1\to\tau_1 \leq \sigma_2\to\tau_2 \end{aligned}$$

Intersection type subtyping is decidable in quadratic time.[^o36]

### Typing rules {#Typing_rules}

The [typing rules](https://en.wikipedia.org/wiki/Typing_rule) $(\to\!\!\text{I})$, $(\to\!\!\text{E})$, $(\cap\text{I})$, $(\leq)$, $(\text{A})$, and $(\omega)$ of $(\vdash_{\text{BCD}})$ are:

$$\begin{array}{cc} \dfrac{\Gamma, x : \sigma \vdash_{\text{BCD}} M : \tau}{\Gamma \vdash_{\text{BCD}} \lambda x.\!M : \sigma \to \tau}(\to\!\!\text{I}) &\dfrac{\Gamma \vdash_{\text{BCD}} M : \sigma \to \tau \quad \Gamma \vdash_{\text{BCD}} N : \sigma}{\Gamma \vdash_{\text{BCD}} M\;N : \tau}(\to\!\!\text{E})\\\\ \dfrac{\Gamma \vdash_{\text{BCD}} M : \sigma \quad \Gamma \vdash_{\text{BCD}} M : \tau}{\Gamma \vdash_{\text{BCD}} M : \sigma \cap \tau}(\cap\text{I}) &\dfrac{\Gamma \vdash_{\text{BCD}} M : \sigma \quad (\sigma \leq \tau)}{\Gamma \vdash_{\text{BCD}} M : \tau}(\leq)\\\\ \dfrac{}{\Gamma, x : \sigma \vdash_{\text{BCD}} x : \sigma}(\text{A}) &\dfrac{}{\Gamma \vdash_{\text{BCD}} M : \omega}(\omega) \end{array}$$

::: {#o20 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- **Semantics**: $(\vdash_{\text{BCD}})$ is sound and complete wrt. a filter λ-model, in which the interpretation of a λ-term coincides with the set of types that can be assigned to it.[^o28]
- **[Subject reduction](https://en.wikipedia.org/wiki/Subject_reduction)**: If $\Gamma \vdash_{\text{BCD}} M : \sigma$ and $M \to_{\beta} N$, then $\Gamma \vdash_{\text{BCD}} N : \sigma$.[^o28]
- **Subject expansion**: If $\Gamma \vdash_{\text{BCD}} N : \sigma$ and $M \to_{\beta} N$, then $\Gamma \vdash_{\text{BCD}} M : \sigma$.[^o28]
- **Characterization of [strong normalization](https://en.wikipedia.org/wiki/Normalization_property_%28abstract_rewriting%29)**: $M$ is strongly normalizing wrt. β-reduction, if and only if $\Gamma \vdash_{\text{BCD}} M : \sigma$ is derivable without rule $(\omega)$ for some $\Gamma$ and $\sigma$.[^o31]
- **Principal pairs** (also known as "principal typings"[^o21]): If $M$ is strongly normalizing, then there exists a principal pair $(\Gamma, \sigma)$ such that for any typing $\Gamma' \vdash_{\text{BCD}} M : \sigma'$ the pair $(\Gamma', \sigma')$ can be obtained from the principal pair $(\Gamma, \sigma)$ by means of type expansions, liftings, and substitutions.[^o29]

:::
