# List of mathematical constants

::: {#o1 .subject cue=lead name="List of mathematical constants"}

A [mathematical constant](wikipedia://en/48779551) is a key [number](wikipedia://en/21690) whose value is fixed by an unambiguous definition, often referred to by a symbol (e.g., an [alphabet letter](https://en.wikipedia.org/wiki/Letter_%28alphabet%29)), or by mathematicians' names to facilitate using it across multiple [mathematical problems](wikipedia://en/256700).[^o2] For example, the constant [π](wikipedia://en/23601) may be defined as the ratio of the length of a circle's [circumference](wikipedia://en/5916) to its [diameter](wikipedia://en/8007). The following list includes a [decimal expansion](https://en.wikipedia.org/wiki/Decimal_expansion) and set containing each number, ordered by year of discovery.

:::
