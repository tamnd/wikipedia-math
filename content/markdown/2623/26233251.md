# EL++

::: {#o1 .subject cue=lead name="EL++"}

**EL++** is a lightweight [description logic](wikipedia://en/183503) that was designed to

> capture the [expressive power](https://en.wikipedia.org/wiki/Expressive_power_%28computer_science%29) that is used by large-scale [ontologies](https://en.wikipedia.org/wiki/Ontologies) from practical applications
>
> have polytime reasoning problems, in particular classification and instance checking <sub>(www.w3.org 2010)</sub>

:::

**EL++** has been incorporated into [OWL 2](https://en.wikipedia.org/wiki/OWL_2) as a [OWL 2 EL Profile](http://www.w3.org/TR/2009/REC-owl2-profiles-20091027/#OWL_2_EL).
