# Index set

::: {#o1 .subject cue=lead name="Index set"}

In [mathematics](wikipedia://en/18831), an **index set** is a [set](wikipedia://en/26691) whose members label (or index) members of another set.[^o2][^o3] For instance, if the elements of a set $A$ may be *indexed* or *labeled* by means of the elements of a set $J$, then $J$ is an index set. The indexing consists of a [surjective function](wikipedia://en/27873) from $J$ onto $A$, and the indexed collection is typically called an *[indexed family](wikipedia://en/23624339)*, often written as $\{A_{j}\}_{j\in J}$.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- An [enumeration](wikipedia://en/212115) of a set $S$ gives an index set $J \subset \mathbb{N}$, where $f : J \to S$ is the particular enumeration of $S$.
- Any [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) set can be (injectively) indexed by the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $\mathbb{N}$.
- For $r \in \mathbb{R}$, the [indicator function](wikipedia://en/240790) on $r$ is the function $\mathbf{1}_r\colon \mathbb{R} \to \{0,1\}$ given by $$\mathbf{1}_r (x) := \begin{cases} 0, & \mbox{if } x \ne r \\ 1, & \mbox{if } x = r. \end{cases}$$

The set of all such indicator functions, $\{ \mathbf{1}_r \}_{r\in\mathbb{R}}$, is an [uncountable set](wikipedia://en/32248) indexed by $\mathbb{R}$.

:::

## Other uses {#Other_uses}

In [computational complexity theory](wikipedia://en/7543) and [cryptography](wikipedia://en/18934432), an index set is a set for which there exists an algorithm $I$ that can sample the set efficiently; e.g., on input $1^{n}$, $I$ can efficiently select a poly(n)-bit long element from the set.[^o7]
