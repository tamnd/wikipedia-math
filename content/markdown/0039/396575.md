# Fσ set

::: {#o1 .subject cue=lead name="Fσ set"}

In [general topology](wikipedia://en/178649), an **F<sub>σ</sub> set** (pronounced **F-sigma set**) is a [countable](https://en.wikipedia.org/wiki/Countable) [union](wikipedia://en/47949) of [closed sets](wikipedia://en/47279). The notation originated in [French](https://en.wikipedia.org/wiki/French_language) with F for fr (*French*: closed) and σ for fr (*French*: sum, union).[^o2]

:::

The [complement](wikipedia://en/54347) of an F<sub>σ</sub> set is a [G<sub>δ</sub> set](wikipedia://en/252076).[^o2]

F<sub>σ</sub> is the same as $\mathbf{\Sigma}^0_2$ in the [Borel hierarchy](wikipedia://en/5539282).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Each closed set is an F<sub>σ</sub> set.

The set $\mathbb{Q}$ of [rationals](wikipedia://en/19727024) is an F<sub>σ</sub> set in $\mathbb{R}$. More generally, any countable set in a [T<sub>1</sub> space](wikipedia://en/148721) is an F<sub>σ</sub> set, because every singleton $\{x\}$ is closed.

The set $\mathbb{R}\setminus\mathbb{Q}$ of irrationals is not an F<sub>σ</sub> set.

In [metrizable](https://en.wikipedia.org/wiki/Metrizable) spaces, every [open set](wikipedia://en/39358) is an F<sub>σ</sub> set.[^o5]

The intersection or union of finitely many F<sub>σ</sub> sets is an F<sub>σ</sub> set.

Assuming the [Axiom of countable choice](wikipedia://en/421086), the union of countably many F<sub>σ</sub> sets is an F<sub>σ</sub> set.

The set $A$ of all [points](wikipedia://en/593693) $(x,y)$ in the [Cartesian plane](https://en.wikipedia.org/wiki/Cartesian_plane) such that $x/y$ is [rational](wikipedia://en/19727024) is an F<sub>σ</sub> set because it can be expressed as the union of all the [lines](https://en.wikipedia.org/wiki/Line_%28mathematics%29) passing through the [origin](wikipedia://en/1313432) with rational [slope](https://en.wikipedia.org/wiki/Slope_%28mathematics%29):

$$A = \bigcup_{r \in \mathbb{Q}} \{(ry,y) \mid y \in \mathbb{R}\},$$

where $\mathbb{Q}$ is the set of rational numbers, which is a countable set.
