# Normalizing constant

::: {#o1 .subject cue=lead name="Normalizing constant"}

In [probability theory](wikipedia://en/23542), a **normalizing constant** or **normalizing factor** is used to reduce any nonnegative function whose integral is finite to a [probability density function](wikipedia://en/43487).

:::

For example, a Gaussian function can be normalized into a probability density function, which gives the standard normal distribution. In Bayes' theorem, a normalizing constant is used to ensure that the sum of all possible hypotheses equals 1. Other uses of normalizing constants include making the value of a Legendre polynomial at 1 and in the orthogonality of orthonormal functions.

A similar concept has been used in areas other than probability, such as for polynomials.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

In [probability theory](wikipedia://en/23542), a **normalizing constant** is a constant by which an everywhere non-negative function must be multiplied so the area under its graph is 1, e.g., to make it a [probability density function](wikipedia://en/43487) or a [probability mass function](wikipedia://en/154725).[^o4][^o5]

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

If we start from the simple [Gaussian function](wikipedia://en/245552)

$$p(x) = e^{-x^2/2}, \quad x\in(-\infty,\infty)$$

we have the corresponding [Gaussian integral](wikipedia://en/567580)

$$\int_{-\infty}^\infty p(x) \, dx = \int_{-\infty}^\infty e^{-x^2/2} \, dx = \sqrt{2\pi\,},$$

Now if we use the latter's [reciprocal value](https://en.wikipedia.org/wiki/Reciprocal_value) as a normalizing constant for the former, defining a function $\varphi(x)$ as

$$\varphi(x) = \frac{1}{\sqrt{2\pi\,}} p(x) = \frac{1}{\sqrt{2\pi\,}} e^{-x^2/2}$$

so that its [integral](https://en.wikipedia.org/wiki/Integral_of_a_Gaussian_function) is unit

$$\int_{-\infty}^\infty \varphi(x) \, dx = \int_{-\infty}^\infty \frac{1}{\sqrt{2\pi\,}} e^{-x^2/2} \, dx = 1$$

then the function $\varphi(x)$ is a probability density function.[^o8] This is the density of the standard [normal distribution](wikipedia://en/21462). (*Standard*, in this case, means the [expected value](wikipedia://en/9653) is 0 and the [variance](wikipedia://en/32344) is 1.)

And constant $\frac{1}{\sqrt{2\pi}}$ is the **normalizing constant** of function $p(x)$.

Similarly,

$$\sum_{n=0}^\infty \frac{\lambda^n}{n!} = e^{\lambda} ,$$

and consequently

$$f(n) = \frac{\lambda^n e^{-\lambda}}{n!}$$

is a probability mass function on the set of all nonnegative integers.[^o9] This is the probability mass function of the [Poisson distribution](wikipedia://en/23009144) with expected value λ.

Note that if the probability density function is a function of various parameters, so too will be its normalizing constant. The parametrised normalizing constant for the [Boltzmann distribution](wikipedia://en/4107) plays a central role in [statistical mechanics](wikipedia://en/28481). In that context, the normalizing constant is called the [partition function](wikipedia://en/312252).

:::

::: {#o11 .statement kind=statement/theorem cue=named-heading name="Bayes' theorem"}

## Bayes' theorem {#Bayes'_theorem}

[Bayes' theorem](wikipedia://en/49569) says that the posterior probability measure is proportional to the product of the prior probability measure and the [likelihood function](wikipedia://en/44968). *Proportional to* implies that one must multiply or divide by a normalizing constant to assign measure 1 to the whole space, i.e., to get a probability measure. In a simple discrete case we have

$$P(H_0\mid D) = \frac{P(D\mid H_0)P(H_0)}{P(D)}$$

where P(H<sub>0</sub>) is the prior probability that the hypothesis is true; P(D\\mid H<sub>0</sub>) is the [conditional probability](wikipedia://en/24104134) of the data given that the hypothesis is true, but given that the data are known it is the [likelihood](wikipedia://en/44968) of the hypothesis (or its parameters) given the data; P(H<sub>0</sub> | D) is the posterior probability that the hypothesis is true given the data. P(D) should be the probability of producing the data, but on its own is difficult to calculate, so an alternative way to describe this relationship is as one of proportionality:

$$P(H_0\mid D) \propto P(D\mid H_0)P(H_0) \text{ as a function of } H_0.$$

Since $P(H\mid D)$ is a probability, the sum over all possible (mutually exclusive) hypotheses should be 1, leading to the conclusion that

$$P(H_0\mid D) = \frac{P(D\mid H_0)P(H_0)}{\displaystyle\sum_i P(D\mid H_i)P(H_i)} .$$

In this case, the [reciprocal](wikipedia://en/229940) of the value

$$P(D) = \sum_i P(D\mid H_i)P(H_i) \;$$

is the *normalizing constant*.[^o12] It can be extended from countably many hypotheses to uncountably many by replacing the sum by an integral.

For concreteness, there are many methods of estimating the normalizing constant for practical purposes. Methods include the bridge sampling technique, the naive Monte Carlo estimator, the generalized [harmonic mean](wikipedia://en/14463) estimator, and importance sampling.[^o13]

:::

## Non-probabilistic uses {#Non-probabilistic_uses}

The [Legendre polynomials](wikipedia://en/100349) are characterized by [orthogonality](wikipedia://en/102221) with respect to the uniform measure on the interval \[−1, 1\] and the fact that they are **normalized** so that their value at 1 is 1. The constant by which one multiplies a polynomial so its value at 1 is a normalizing constant.

[Orthonormal](https://en.wikipedia.org/wiki/Orthonormal) functions are normalized such that

$$\langle f_i , \, f_j \rangle = \, \delta_{i,j}$$

with respect to some inner product $\langle f, g\rangle$.

The constant $1/\sqrt{2}$ is used to establish the [hyperbolic functions](wikipedia://en/56567#Comparison_with_circular_functions) cosh and sinh from the lengths of the adjacent and opposite sides of a [hyperbolic triangle](wikipedia://en/1139926#Hyperbolic_triangle).
