# Comparison of topologies

::: {#o1 .subject cue=lead name="Comparison of topologies"}

In [topology](wikipedia://en/29954) and related areas of [mathematics](wikipedia://en/18831), the set of all possible topologies on a given set forms a [partially ordered set](wikipedia://en/23572). This [order relation](https://en.wikipedia.org/wiki/Order_relation) can be used for **comparison of the topologies**.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A topology on a set may be defined as the collection of [subsets](wikipedia://en/27631) which are considered to be "open". (An alternative definition is that it is the collection of subsets which are considered "closed". These two ways of defining the topology are essentially equivalent because the [complement](wikipedia://en/54347) of an [open set](wikipedia://en/39358) is closed and vice versa. In the following, it doesn't matter which definition is used.)

For definiteness the reader should think of a topology as the family of **open sets** of a topological space, since that is the standard meaning of the word "topology".

Let *τ*<sub>1</sub> and *τ*<sub>2</sub> be two topologies on a set *X* such that *τ*<sub>1</sub> is contained in *τ*<sub>2</sub>:

$$\tau_1 \subseteq \tau_2.$$

That is, every element of *τ*<sub>1</sub> is also an element of *τ*<sub>2</sub>. Then the topology *τ*<sub>1</sub> is said to be a **coarser** (**weaker** or **smaller**) **topology** than *τ*<sub>2</sub>, and *τ*<sub>2</sub> is said to be a **finer** (**stronger** or **larger**) **topology** than *τ*<sub>1</sub>. [^o4]

If additionally

$$\tau_1 \neq \tau_2$$

we say *τ*<sub>1</sub> is **strictly coarser** than *τ*<sub>2</sub> and *τ*<sub>2</sub> is **strictly finer** than *τ*<sub>1</sub>.[^n1]

The [binary relation](wikipedia://en/3931) ⊆ defines a [partial ordering relation](https://en.wikipedia.org/wiki/Partial_ordering_relation) on the set of all possible topologies on *X*.

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

The finest topology on *X* is the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology); this topology makes all subsets open. The coarsest topology on *X* is the [trivial topology](wikipedia://en/382447); this topology only admits the empty set and the whole space as open sets.

In [function spaces](wikipedia://en/340630) and spaces of [measures](wikipedia://en/19873) there are often a number of possible topologies. See [topologies on the set of operators on a Hilbert space](https://en.wikipedia.org/wiki/Topologies_on_the_set_of_operators_on_a_Hilbert_space) for some intricate relationships.

All possible [polar topologies](wikipedia://en/1789978) on a [dual pair](https://en.wikipedia.org/wiki/Dual_pair) are finer than the [weak topology](https://en.wikipedia.org/wiki/Weak_topology_%28polar_topology%29) and coarser than the [strong topology](https://en.wikipedia.org/wiki/Strong_topology_%28polar_topology%29).

The [complex vector space](wikipedia://en/39125683) **C**<sup>*n*</sup> may be equipped with either its usual (Euclidean) topology, or its [Zariski topology](wikipedia://en/241744). In the latter, a subset *V* of **C**<sup>*n*</sup> is closed if and only if it consists of all solutions to some system of polynomial equations. Since any such *V* also is a closed set in the ordinary sense, but not *vice versa*, the Zariski topology is strictly weaker than the ordinary one.

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let *τ*<sub>1</sub> and *τ*<sub>2</sub> be two topologies on a set *X*. Then the following statements are equivalent:

- *τ*<sub>1</sub> ⊆ *τ*<sub>2</sub>.
- The [identity map](wikipedia://en/15069) id<sub>X</sub> : (*X*, *τ*<sub>2</sub>) → (*X*, *τ*<sub>1</sub>) is a [continuous map](https://en.wikipedia.org/wiki/Continuous_map_%28topology%29).
- The identity map id<sub>X</sub> : (*X*, *τ*<sub>1</sub>) → (*X*, *τ*<sub>2</sub>) is a [strongly open map](https://en.wikipedia.org/wiki/Open_map).
- The identity map id<sub>X</sub> : (*X*, *τ*<sub>1</sub>) → (*X*, *τ*<sub>2</sub>) is a [relatively open map](https://en.wikipedia.org/wiki/Open_map).

(The identity map id<sub>X</sub> is [surjective](wikipedia://en/27873) and therefore it is strongly open if and only if it is relatively open.)

Two immediate corollaries of the above equivalent statements are

- A continuous map *f* : *X* → *Y* remains continuous if the topology on *Y* becomes *coarser* or the topology on *X* *finer*.
- An open (resp. closed) map *f* : *X* → *Y* remains open (resp. closed) if the topology on *Y* becomes *finer* or the topology on *X* *coarser*.

One can also compare topologies using [neighborhood bases](https://en.wikipedia.org/wiki/Neighborhood_base). Let *τ*<sub>1</sub> and *τ*<sub>2</sub> be two topologies on a set *X* and let *B*<sub>*i*</sub>(*x*) be a local base for the topology *τ*<sub>*i*</sub> at *x* ∈ *X* for *i* = 1,2. Then *τ*<sub>1</sub> ⊆ *τ*<sub>2</sub> if and only if for all *x* ∈ *X*, each open set *U*<sub>1</sub> in *B*<sub>1</sub>(*x*) contains some open set *U*<sub>2</sub> in *B*<sub>2</sub>(*x*). Intuitively, this makes sense: a finer topology should have smaller neighborhoods.

:::

## Lattice of topologies {#Lattice_of_topologies}

The set of all topologies on a set *X* together with the partial ordering relation ⊆ forms a [complete lattice](wikipedia://en/44777) that is also closed under arbitrary intersections.[^o12] That is, any collection of topologies on *X* have a *meet* (or [infimum](https://en.wikipedia.org/wiki/Infimum)) and a *join* (or [supremum](https://en.wikipedia.org/wiki/Supremum)). The meet of a collection of topologies is the [intersection](wikipedia://en/23476429) of those topologies. The join, however, is not generally the [union](wikipedia://en/47949) of those topologies (the union of two topologies need not be a topology) but rather the topology [generated by](wikipedia://en/395395) the union.

Every complete lattice is also a [bounded lattice](wikipedia://en/310878), which is to say that it has a [greatest](https://en.wikipedia.org/wiki/Greatest_element) and [least element](https://en.wikipedia.org/wiki/Least_element). In the case of topologies, the greatest element is the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) and the least element is the [trivial topology](wikipedia://en/382447).

The lattice of topologies on a set $X$ is a [complemented lattice](wikipedia://en/753521); that is, given a topology $\tau$ on $X$ there exists a topology $\tau'$ on $X$ such that the intersection $\tau\cap\tau'$ is the trivial topology and the topology generated by the union $\tau\cup\tau'$ is the discrete topology.[^o13][^o14]

If the set $X$ has at least three elements, the lattice of topologies on $X$ is not [modular](wikipedia://en/1089311),[^n2] and hence not [distributive](wikipedia://en/310883) either.
