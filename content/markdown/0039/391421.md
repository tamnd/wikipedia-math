# Comparametric equation

::: {#o1 .subject cue=lead name="Comparametric equation"}

A **comparametric equation** is an [equation](wikipedia://en/9284) that describes a [parametric](wikipedia://en/25065) relationship between a [function](wikipedia://en/185427) and a [dilated](wikipedia://en/651752) version of the same function, where the equation does not involve the [parameter](wikipedia://en/25065). For example, *ƒ*(2*t*) = 4*ƒ*(*t*) is a comparametric equation, when we define *g*(*t*) = *ƒ*(2*t*), so that we have *g* = 4*ƒ* no longer contains the parameter, *t*. The comparametric equation *g* = 4*ƒ* has a family of solutions, one of which is *ƒ* = *t*<sup>2</sup>. [^o2]

:::

To see that *ƒ* = *t*<sup>2</sup> is a solution, we merely substitute back in: *g* = *ƒ*(2*t*) = (2*t*)<sup>2</sup> = 4*t*<sup>2</sup> = 4*ƒ*, so that *g* = 4*ƒ*.

Comparametric equations arise naturally in [signal processing](wikipedia://en/29324) when we have multiple measurements of the same phenomenon, in which each of the measurements was acquired using a different sensitivity. For example, two or more differently exposed pictures of the same subject matter give rise to a comparametric relationship, the solution of which is the response function of the camera, image sensor, or imaging system. In this sense, comparametric equations are the fundamental mathematical basis for [HDR (high dynamic range) imaging](https://en.wikipedia.org/wiki/High-dynamic-range_imaging),[^o3][^o4][^o5] as well as HDR audio.[^o6][^o7]

Comparametric equations have been used in many areas of research, and have many practical applications to the real world. They are used in [radar](https://en.wikipedia.org/wiki/Radar), [microphone arrays](https://en.wikipedia.org/wiki/Microphone_array), and have been used in processing crime scene video in [homicide](https://en.wikipedia.org/wiki/Homicide) trials in which the only evidence against the accused was video recordings of the murder.

## Solution {#Solution}

An existing solution is comparametric camera response function (CCRF) for real-time comparametric analysis. It has applications in the analysis of multiple images.[^o9][^o10]
