# Isolated point

*Image: Điểm cô lập-Isolated point.svg.* "0" is an isolated point of $A = \{0\} \cup [1, 2]$

::: {#o1 .subject cue=lead name="Isolated point"}

In [mathematics](wikipedia://en/18831), a [point](https://en.wikipedia.org/wiki/Point_%28topology%29) $x$ is called an **isolated point** of a subset $S$ (in a [topological space](wikipedia://en/30450) $X$) if $x$ is an element of $S$ and there exists a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) of $x$ that does not contain any other points of $S$. This is equivalent to saying that the [singleton](wikipedia://en/381798) $\{x\}$ is an [open set](wikipedia://en/39358) in the topological space $S$ (considered as a [subspace](wikipedia://en/910926) of $X$). Another equivalent formulation is: an element $x$ of $S$ is an isolated point of $S$ if and only if it is not a [limit point](https://en.wikipedia.org/wiki/Limit_point) of $S$.

:::

If the space $X$ is a [metric space](wikipedia://en/20018), for example a [Euclidean space](wikipedia://en/9697), then an element $x$ of $S$ is an isolated point of $S$ if there exists an [open ball](https://en.wikipedia.org/wiki/Open_ball) around $x$ that contains only finitely many elements of $S$. A [point set](https://en.wikipedia.org/wiki/Point_set) that is made up only of isolated points is called a **discrete set** or **discrete point set** (see also [discrete space](wikipedia://en/56061)).

## Related notions {#Related_notions}

Any discrete subset $S$ of Euclidean space must be [countable](https://en.wikipedia.org/wiki/Countable), since the isolation of each of its points together with the fact that [rationals](wikipedia://en/19727024) are [dense](wikipedia://en/23523594) in the [reals](wikipedia://en/20646438) means that the points of $S$ may be mapped injectively onto a set of points with rational coordinates, of which there are only countably many. However, not every countable set is discrete, of which the rational numbers under the usual Euclidean metric are the canonical example.

A set with no isolated point is said to be *[dense-in-itself](wikipedia://en/8327127)* (every neighbourhood of a point contains other points of the set). A [closed set](wikipedia://en/47279) with no isolated point is called a *[perfect set](wikipedia://en/5075551)* (it contains all its limit points and no isolated points).

The number of isolated points is a [topological invariant](https://en.wikipedia.org/wiki/Topological_invariant), i.e. if two [topological spaces](https://en.wikipedia.org/wiki/Topological_spaces) $X, Y$ are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic), the number of isolated points in each is equal.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### Standard examples {#Standard_examples}

[Topological spaces](wikipedia://en/30450) in the following three examples are considered as [subspaces](wikipedia://en/910926) of the [real line](https://en.wikipedia.org/wiki/Real_line) with the standard topology.

- For the set $S=\{0\}\cup [1, 2],$ the point 0 is an isolated point.
- For the set $S=\{0\}\cup \{1, \tfrac 1 2, \tfrac 1 3, \dots \},$ each of the points $\tfrac 1 k$ is an isolated point, but $0$ is not an isolated point because there are other points in $S$ as close to $0$ as desired.
- The set $\mathbb{N} = \{0, 1, 2, \ldots \}$ of [natural numbers](wikipedia://en/21474) is a discrete set.

In the topological space $X=\{a,b\}$ with topology $\tau=\{\emptyset,\{a\},X\},$ the element $a$ is an isolated point, even though $b$ belongs to the [closure](wikipedia://en/293802) of $\{a\}$ (and is therefore, in some sense, "close" to $a$). Such a situation is not possible in a [Hausdorff space](wikipedia://en/13637).

The [Morse lemma](wikipedia://en/348560#Morse_lemma) states that [non-degenerate critical points](https://en.wikipedia.org/wiki/Non-degenerate_critical_point) of certain functions are isolated.

### Two counter-intuitive examples {#Two_counter-intuitive_examples}

Consider the set $F$ of points $x$ in the real interval $(0,1)$ such that every digit $x_{i}$ of their [binary](wikipedia://en/238686) representation fulfills the following conditions:

- Either $x_i=0$ or $x_i=1.$
- $x_i=1$ only for finitely many indices $i$.
- If $m$ denotes the largest index such that $x_m=1,$ then $x_{m-1}=0.$
- If $x_i=1$ and $i < m,$ then exactly one of the following two conditions holds: $x_{i-1}=1$ or $x_{i+1}=1.$

Informally, these conditions means that every digit of the binary representation of $x$ that equals 1 belongs to a pair ...0110..., except for ...010... at the very end.

Now, $F$ is an explicit set consisting entirely of isolated points but has the counter-intuitive property that its [closure](wikipedia://en/42309) is an [uncountable set](wikipedia://en/32248).[^o7]

Another set $F$ with the same properties can be obtained as follows. Let $C$ be the middle-thirds [Cantor set](wikipedia://en/6172), let $I_1,I_2,I_3,\ldots,I_k,\ldots$ be the [component](wikipedia://en/6233#Connected_components) intervals of $[0,1]-C$, and let $F$ be a set consisting of one point from each $I_{k}$. Since each $I_{k}$ contains only one point from $F$, every point of $F$ is an isolated point. However, if $p$ is any point in the Cantor set, then every neighborhood of $p$ contains at least one $I_{k}$, and hence at least one point of $F$. It follows that each point of the Cantor set lies in the closure of $F$, and therefore $F$ has uncountable closure.
