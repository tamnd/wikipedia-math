# Unsatisfiable core

::: {#o1 .subject cue=lead name="Unsatisfiable core"}

In [mathematical logic](wikipedia://en/19636), given an [unsatisfiable](wikipedia://en/4715) Boolean [propositional formula](wikipedia://en/1557634) in [conjunctive normal form](wikipedia://en/73342), a subset of clauses whose conjunction is still unsatisfiable is called an **unsatisfiable core** of the original formula.

:::

Many [SAT solvers](https://en.wikipedia.org/wiki/SAT_solver) can produce a *resolution graph* which proves the unsatisfiability of the original problem. This can be analyzed to produce a smaller unsatisfiable core.

An unsatisfiable core is called a *minimal unsatisfiable core*, if every proper subset (allowing removal of any arbitrary clause or clauses) of it is satisfiable. Thus, such a core is a [local minimum](https://en.wikipedia.org/wiki/Maxima_and_minima), though not necessarily a global one. There are several practical methods of computing minimal unsatisfiable cores.[^o2][^o3]

A *minimum unsatisfiable core* contains the smallest number of the original clauses required to still be unsatisfiable. No practical algorithms for computing the minimum unsatisfiable core are known,[^o4] and computing a minimum unsatisfiable core of an input formula in [conjunctive normal form](wikipedia://en/73342) is a [$\Sigma_2^\mathsf{P}$](https://en.wikipedia.org/wiki/Sigma2p)-complete problem.[^o5] Notice the terminology: whereas the ***[minimal](wikipedia://en/303398)****unsatisfiable core* was a **local** problem with an easy solution, the ***[minimum](https://en.wikipedia.org/wiki/Maxima_and_minima)****unsatisfiable core* is a **global** problem with no known easy solution.
