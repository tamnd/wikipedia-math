# KeeWeb

Products

::: {#o2 .subject cue=lead name="KeeWeb"}

**KeeWeb** is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source_software) [password manager](wikipedia://en/4696394) compatible with [KeePass](wikipedia://en/30858923), available as a web version and desktop apps. The underlying file format is KDBX (KeePass database file).[^o3]

:::

## Technology {#Technology}

KeeWeb is written in [JavaScript](https://en.wikipedia.org/wiki/JavaScript) and uses [WebCrypto](https://en.wikipedia.org/wiki/Web_Cryptography_API) and [WebAssembly](https://en.wikipedia.org/wiki/WebAssembly) to process password files in the browser, without uploading them to a server. It can synchronize files with popular file hosting services, such as [Dropbox](https://en.wikipedia.org/wiki/Dropbox_%28service%29), [Google Drive](https://en.wikipedia.org/wiki/Google_Drive), and [OneDrive](https://en.wikipedia.org/wiki/OneDrive).[^o5]

KeeWeb is also available as an [Electron](https://en.wikipedia.org/wiki/Electron_%28software_framework%29) bundle which resembles a desktop app. The desktop version adds some features not available on web:[^o6]

- auto-typing passwords
- ability to open and save local files
- sync to [WebDAV](https://en.wikipedia.org/wiki/WebDAV) without [CORS](https://en.wikipedia.org/wiki/Cross-origin_resource_sharing) enabled

KeeWeb can also be deployed as a standalone server, or installed as a [Nextcloud](https://en.wikipedia.org/wiki/Nextcloud) app.[^o7]

## Reception {#Reception}

KeeWeb was praised by Ghacks Technology News in 2016 as "brand-new" fixing the "shortcoming of a web-based version" of KeePass, and by Tech Advisor in 2020 as "well-designed cross-platform password manager".[^o9][^o10]
