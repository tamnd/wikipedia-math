# Kuratowski–Ulam theorem

::: {#o1 .subject cue=lead name="Kuratowski–Ulam theorem"}

In [mathematics](wikipedia://en/18831), the **Kuratowski–Ulam theorem**, introduced by (txt), called also the Fubini theorem for [category](wikipedia://en/226975#Terminology), is an analog of [Fubini's theorem](wikipedia://en/255245) for arbitrary [second countable](https://en.wikipedia.org/wiki/Second_countable) [Baire spaces](wikipedia://en/200550).

:::

Let *X* and *Y* be second countable Baire spaces (or, in particular, [Polish spaces](wikipedia://en/396622)), and let $A \subset X \times Y$. Then the following are equivalent if *A* has the [Baire property](wikipedia://en/2213768):

1. *A* is [meager](https://en.wikipedia.org/wiki/Meager_set) (respectively comeager).
1. The [set](wikipedia://en/26691) $\{ x \in X :A_x \text{ is meager (resp. comeager) in }Y \}$ is comeager in X, where $A_x=\pi_Y[A\cap \lbrace x \rbrace \times Y]$, where $\pi_Y$ is the projection onto *Y*.

Even if *A* does not have the Baire property, 2. follows from 1.[^o3] Note that the theorem still holds (perhaps vacuously) for *X* an arbitrary [Hausdorff space](wikipedia://en/13637) and *Y* a Hausdorff space with countable [π-base](https://en.wikipedia.org/wiki/Π-base).

The theorem is analogous to the regular Fubini's theorem for the case where the considered [function](wikipedia://en/185427) is a [characteristic function](wikipedia://en/240790) of a [subset](wikipedia://en/27631) in a product space, with the usual correspondences, namely, [meagre set](wikipedia://en/226975) with a set of measure zero, comeagre set with one of full measure, and a set with the Baire property with a measurable set.
