# Random surfing model

::: {#o1 .subject cue=lead name="Random surfing model"}

The **random surfing model** is a [graph model](wikipedia://en/12401) which describes the probability of a random user visiting a [web page](https://en.wikipedia.org/wiki/Web_page). The model attempts to predict the chance that a random internet surfer will arrive at a page by either clicking a [link](https://en.wikipedia.org/wiki/Hyperlink) or by accessing the site directly, for example by directly entering the website's [URL](https://en.wikipedia.org/wiki/URL) in the address bar. For this reason, an assumption is made that all users surfing the internet will eventually stop following links in favor of switching to another site completely. The model is similar to a [Markov chain](wikipedia://en/60876), where the chain's states are web pages the user lands on and transitions are equally probable links between these pages.

:::

## Description {#Description}

*Image: Hyperlink diagram.svg.* Navigation through hyperlinks, after directly arriving at a site's [home page](https://en.wikipedia.org/wiki/Home_page)

A user navigates the internet in two primary ways; the user may access a site directly by entering the site's URL or clicking a [bookmark](https://en.wikipedia.org/wiki/Bookmark_%28digital%29), or the user may use a series of hyperlinks to get to the desired page. The random surfer model assumes that the link which the user selects next is picked at random. The model also assumes that the number of successive links is not infinite – the user will at some point lose interest and leave the current site for a completely new site.[^o3]

The random surfer model is presented as a series of [nodes](wikipedia://en/638899) which indicate web pages that can be accessed at random by users. A new node is added to the a graph when a new website is published. The movement about the graphs nodes is modeled by choosing a start node at random, then performing a short and random [traversal](https://en.wikipedia.org/wiki/Tree_traversal) of the nodes, or [random walk](wikipedia://en/235451). This traversal is analogous to a user accessing a website, then following hyperlink $t$ number of times, until the user either exits the page or accesses another site completely. Connections to other nodes in this graph are formed when outbound links are placed on the page.

## Graph definitions {#Graph_definitions}

In the random surfing model, [webgraphs](wikipedia://en/31961387) are presented as a sequence of [directed graphs](wikipedia://en/19721986) $G_t,t = 1,2,\ldots$ such that a graph $G_t$ has $t$ vertices and $t$ edges. The process of defining graphs is parameterized with a probability $p$, thus we let $q= 1-p$.[^o5]

Nodes of the model arrive one at time, forming $k$ connections to the existing graph $G_t$. In some models, connections represent directed edges, and in others, connections represent undirected edges. Models start with a single node $v_0$ and have $k$ [self-loops](wikipedia://en/1449083). $v_t$ denotes a vertex added in the $t^{th}$ step, and $n$ denotes the total number of vertices.[^o3]

### Model 1. (1-step walk with self-loop) {#Model_1._(1-step_walk_with_self-loop)}

At time $t$, vertex $v_t$ makes $k$ connections by $k$ iterations of the following steps:

1. Pick an existing node $v$ uniformly at random from $\{ v_0, v_1, \ldots , v_{t-1} \}$
1. With probability $p$ stay at $v$; with probability $1 - p$ take a 1-step walk to a random neighbor of $v$
1. Add an edge from $v_t$ to the current node

For directed graphs, edges added are directed from $v_t$ into the existing graph. Edges are undirected in respective undirected graphs.

### Model 2. (Random walks with coin flips) {#Model_2._(Random_walks_with_coin_flips)}

At time $t$, vertex $v_t$ makes $k$ connections by $k$ iterations of the following steps:

1. Pick an existing node $v$ uniformly at random from $\{ v_0, v_1, ..., v_{t-1} \}$
1. Flip a coin of [bias](wikipedia://en/184099) $p$
1. If the coin comes up heads add an edge from $v_t$ to the current node and stop
1. If the coin comes up tails, move to a random neighbor of the current node and go back to step 2

For directed graphs, edges added are directed from $v_t$ into the existing graph. Edges are undirected in respective undirected graphs.

## Limitations {#Limitations}

There are some caveats to the standard random surfer model, one of which is that the model ignores the content of the sites which users select – since the model assumes links are selected at random. Because users tend to have a goal in mind when surfing the internet, the content of the linked sites is a determining factor of whether or not the user will click a link.[^o3][^o5]

## Application {#Application}

The [normalized eigenvector centrality](wikipedia://en/3495507) combined with random surfer model's assumption of random jumps created the foundation of [Google](https://en.wikipedia.org/wiki/Google)'s [PageRank algorithm](https://en.wikipedia.org/wiki/PageRank).[^o5][^o11]
