# Jech–Kunen tree

::: {#o1 .subject cue=lead name="Jech–Kunen tree"}

A **Jech–Kunen tree** is a [set-theoretic tree](wikipedia://en/704160) with properties that are incompatible with the [generalized continuum hypothesis](https://en.wikipedia.org/wiki/Generalized_continuum_hypothesis). It is named after [Thomas Jech](wikipedia://en/6207903) and [Kenneth Kunen](https://en.wikipedia.org/wiki/Kenneth_Kunen), both of whom studied the possibility and consequences of its existence.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

In set theory, a [tree](wikipedia://en/704160) is a [partially ordered set](wikipedia://en/23572) in which the predecessors of any element form a [well-ordering](https://en.wikipedia.org/wiki/Well-ordering). The height of any element is the [order type](wikipedia://en/4499021) of this well-ordering, and the height of the tree is the least [ordinal number](wikipedia://en/26547932) that exceeds the height of all elements. A *branch* of a tree is a maximal well-ordered subset. A *ω*<sub>1</sub>-tree is a tree with [cardinality](wikipedia://en/6174) $\aleph_1$ and height *ω*<sub>1</sub>, where *ω*<sub>1</sub> is the [first uncountable ordinal](wikipedia://en/20860540) and $\aleph_1$ is the associated [cardinal number](wikipedia://en/6173). A Jech–Kunen tree is a *ω*<sub>1</sub>-tree in which the number of branches is greater than $\aleph_1$ and less than $2^{\aleph_1}$.

:::

## Existence {#Existence}

The [generalized continuum hypothesis](https://en.wikipedia.org/wiki/Generalized_continuum_hypothesis) implies that there is no [cardinal number](wikipedia://en/6173) between $\aleph_1$ and $2^{\aleph_1}$; when this is the case, a Jech–Kunen tree cannot exist, because it is required to have a number of branches strictly between these two numbers. (txt) found the first [model](wikipedia://en/19858) in which this tree exists, and (txt) showed that, assuming the [continuum hypothesis](wikipedia://en/5705) and $2^{\aleph_1} > \aleph_2$ , the existence of a Jech–Kunen tree is equivalent to the existence of a compact [Hausdorff space](wikipedia://en/13637) with [weight](wikipedia://en/59220#Definition_and_basic_properties) $\aleph_1$ and cardinality strictly between $\aleph_1$ and $2^{\aleph_1}$.
