# Language, Proof and Logic

::: {#o1 .subject cue=lead name="Language, Proof and Logic"}

**Language, Proof and Logic** is an educational software package, devised and written by [Jon Barwise](wikipedia://en/912858) and [John Etchemendy](wikipedia://en/5503538), geared to teaching [formal logic](https://en.wikipedia.org/wiki/Formal_logic) through the use of a tight integration between a textbook (same name as the package) and four software programs, where three of them are logic related (Boole, Fitch and Tarski's World) and the other (Submit) is an internet-based grading service. The name is a [pun](https://en.wikipedia.org/wiki/Pun) derived from *[Language, Truth, and Logic](wikipedia://en/3291133)*, the philosophy book by [A. J. Ayer](https://en.wikipedia.org/wiki/A._J._Ayer).

:::

On September 2, 2014, there was launched a [massive open online course](https://en.wikipedia.org/wiki/Massive_open_online_course) (MOOC) with the same name, which utilizes this educational software package.

## Description {#Description}

A short description of the programs:

- Boole (named after [George Boole](wikipedia://en/38298)) - a program that facilitates the construction and checking of truth tables and related notions ([tautology](wikipedia://en/4495335), tautological consequence, etc.);
- Fitch (named after [Frederic Brenton Fitch](https://en.wikipedia.org/wiki/Frederic_Brenton_Fitch)) - a natural deduction proof environment in [Fitch-style calculus](https://en.wikipedia.org/wiki/Fitch-style_calculus) for giving and checking first-order proofs;
- [Tarski's World](wikipedia://en/37645464) (named after [Alfred Tarski](wikipedia://en/59920)) - a program that teaches the basic first-order language and its semantics using a model theoretic-like approach, where the "world" consists of a little grid and some simple objects;
- Submit - a program that allows students to submit exercises done with the above programs to the Grade Grinder, the online grading service.[^o3]
