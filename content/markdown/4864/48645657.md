# Banach game

::: {#o1 .subject cue=lead name="Banach game"}

In mathematics, the **Banach game** is a [topological game](wikipedia://en/15334997) introduced by [Stefan Banach](wikipedia://en/29646) in 1935 in the second addendum to problem 43 of the [Scottish book](https://en.wikipedia.org/wiki/Scottish_book) as a variation of the [Banach–Mazur game](wikipedia://en/365811).[^o2]

:::

Given a subset $X$ of [real numbers](wikipedia://en/20646438), two players alternately write down arbitrary (not necessarily in $X$) positive real numbers $x_0, x_1, x_2,\ldots$ such that $x_0 > x_1 > x_2 >\cdots$ Player one wins if and only if $\sum^\infty_{i=0} x_i$ exists and is in $X$.[^o3]

One observation about the game is that if $X$ is a [countable set](wikipedia://en/6026), then either of the players can cause the final sum to avoid the set.[^n1] Thus in this situation the second player has a [winning strategy](https://en.wikipedia.org/wiki/Winning_strategy).
