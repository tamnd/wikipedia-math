# Cyclic vector

::: {#o1 .subject cue=lead name="Cyclic vector"}

In the [mathematics](wikipedia://en/18831) of [operator theory](wikipedia://en/712675), an [operator](https://en.wikipedia.org/wiki/Linear_operator) $A$ on an ([infinite-dimensional](wikipedia://en/38267)) [Banach space](wikipedia://en/3989) or [Hilbert space](wikipedia://en/20598932) $H$ has a cyclic vector $f$ if the vectors $f, Af, A^2f,\dots$ [span](https://en.wikipedia.org/wiki/Spanning_set) $H$. Equivalently, $f$ is a cyclic vector for $A$ in case the set of all vectors of the form $p(A)f$, where $p$ varies over all [polynomials](wikipedia://en/23000), is [dense](wikipedia://en/23523594) in $H$.[^n1][^o3]

:::
