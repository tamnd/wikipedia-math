# Perfect set property

::: {#o1 .subject cue=lead name="Perfect set property"}

In the [mathematical](wikipedia://en/18831) field of [descriptive set theory](wikipedia://en/396619), a [subset](wikipedia://en/27631) of a [Polish space](wikipedia://en/396622) has the **perfect set property** if it is either [countable](wikipedia://en/6026) or has a [nonempty](wikipedia://en/9566) [perfect](wikipedia://en/5075551) subset.[^n1] Note that having the perfect set property is not the same as being a [perfect set](wikipedia://en/5075551).

:::

As nonempty perfect sets in a Polish space always have the [cardinality of the continuum](wikipedia://en/1574901), and the [reals](wikipedia://en/20646438) form a Polish space, a set of reals with the perfect set property cannot be a [counterexample](wikipedia://en/143151) to the [continuum hypothesis](wikipedia://en/5705) (stated in the form that every [uncountable set](wikipedia://en/32248) of reals has the cardinality of the continuum).

The **Cantor–Bendixson theorem** states that [closed sets](wikipedia://en/47279) of a Polish space $X$ have the perfect set property in a particularly strong form: any closed subset of $X$ can be written uniquely as the [disjoint union](wikipedia://en/188946) of a perfect set and a countable set. In particular, every uncountable Polish space has the perfect set property, and can be written as the disjoint union of a perfect set and a countable [open set](wikipedia://en/39358).

As a consequence, if a subset $S \subseteq X$ of a Polish space $X$ is such that its [derived sets](wikipedia://en/1567335) eventually reach the empty set, that is, $S^{(\alpha)} = \varnothing$ for some ordinal $\alpha$, then $S$ is countable.

The [axiom of choice](wikipedia://en/840) implies the existence of sets of reals that do not have the perfect set property, such as [Bernstein sets](wikipedia://en/24910076). However, in [Solovay's model](https://en.wikipedia.org/wiki/Solovay's_model), which satisfies all axioms of [ZF](https://en.wikipedia.org/wiki/Zermelo_Fraenkel_set_theory) but not the axiom of choice, every set of reals has the perfect set property, so the use of the axiom of choice is necessary. Every [analytic set](wikipedia://en/634261) has the perfect set property. It follows from the existence of sufficiently [large cardinals](wikipedia://en/383644) that every [projective set](https://en.wikipedia.org/wiki/Projective_set) has the perfect set property.

::: {#o4 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

Let $\omega_1$ be the least uncountable [ordinal](wikipedia://en/26547932). In an analog of [Baire space](wikipedia://en/200550) derived from the $\omega_1$-fold [Cartesian product](wikipedia://en/24104095) of $\omega_1$ with itself, any closed set is the disjoint union of an $\omega_1$-perfect set and a set of [cardinality](wikipedia://en/6174) $\leq\aleph_1$, where $\omega_1$-closedness of a set is defined via a [topological game](wikipedia://en/15334997) in which members of $\omega_1^{\omega_1}$ are played.[^n2]
