# Effective method

::: {#o1 .subject cue=lead name="Effective method"}

In [metalogic](wikipedia://en/387934), [mathematical logic](wikipedia://en/19636), and [computability theory](wikipedia://en/155414), an **effective method** or **effective procedure** is a finite-time, [deterministic procedure](https://en.wikipedia.org/wiki/Deterministic_algorithm) for [solving a problem](wikipedia://en/1467948) from a specific class.[^o3][^o4] An effective method is sometimes also called a *mechanical* method or procedure.[^o5] Functions for which an effective method exists are sometimes called *[effectively calculable](wikipedia://en/1139338)*.

:::

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, a method is called *effective* to a specific class of problems when it satisfies the following criteria:

- It consists of a finite number of exact, finite instructions.
- When it is applied to a problem from its class:
  - It always finishes (*terminates*) after a finite number of steps.
  - It always produces a correct answer.
- In principle, it can be done by a human without any aids except writing materials.
- Its instructions need only to be followed [rigorously](wikipedia://en/655974) to succeed. In other words, it requires no [ingenuity](https://en.wikipedia.org/wiki/Creativity) to succeed.[^o8]

Optionally, it may also be required that the method never returns a result as if it were an answer when the method is applied to a problem from *outside* its class. Adding this requirement reduces the set of classes for which there is an effective method.

:::

::: {#o10 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

An effective method for calculating the values of a function is called "an [algorithm](wikipedia://en/775)".

:::

## Computable functions {#Computable_functions}

Several independent efforts to give a formal characterization of effective calculability led to a variety of proposed definitions ([general recursive functions](wikipedia://en/26469), [Turing machines](wikipedia://en/30403), [λ-calculus](https://en.wikipedia.org/wiki/Λ-calculus)) that later were shown to be equivalent. The notion captured by these definitions is known as [recursive or effective computability](wikipedia://en/1139338).

The [Church–Turing thesis](wikipedia://en/6854) states that the two notions coincide: any [number-theoretic function](https://en.wikipedia.org/wiki/Number-theoretic_function) that is effectively calculable is [recursively computable](wikipedia://en/1139338).
