# False nearest neighbor algorithm

::: {#o1 .subject cue=lead name="False nearest neighbor algorithm"}

Within [dynamical systems](wikipedia://en/9087), the **false nearest neighbor algorithm** is an [algorithm](wikipedia://en/775) for estimating the [embedding dimension](https://en.wikipedia.org/wiki/Embedding_dimension). The concept was proposed by Kennel et al. (1992).[^o2] The main idea is to examine how the number of neighbors of a point along a signal [trajectory](https://en.wikipedia.org/wiki/Trajectory) change with increasing embedding dimension. In too low an embedding dimension, many of the neighbors will be false, but in an appropriate embedding dimension or higher, the neighbors are real. With increasing dimension, the false neighbors will no longer be neighbors. Therefore, by examining how the number of neighbors change as a function of dimension, an appropriate embedding can be determined.[^o3][^o4]

:::
