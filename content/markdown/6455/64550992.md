# Ryser's conjecture

*Image: Ryser's Conjecture.svg.* The [**matchings**](wikipedia://en/63030703), the 3 sets of hyperedges colored blue, red, and yellow, are sets of edges such that each vertex appears in at most one of the edges in its set. The largest size of a matching in a hypergraph *H* is denoted by $\nu(H)$. The [**transversals**](wikipedia://en/64318108), the 3 sets of vertices colored light gray, gray, and dark gray, are sets of vertices such that each hyperedge contains at least one of the vertices in its set. The smallest size of a transversal in a hypergraph *H* is denoted by $\tau(H)$. Ryser's conjecture states that for any *r-uniform* and *r-partite hypergraph*, $\tau(H) \leq (r-1)\cdot \nu(H)$. In the graph shown, which is 3-uniform and 3-partite, $3 \leq (3-1)\cdot 3$ evaluates to $3 \leq 6$, so the conjecture holds.

::: {#o1 .problem cue=unsolved}

**Conjecture:** $\tau(H) \leq (r-1)\cdot \nu(H)$

:::

::: {#o2 .subject cue=lead name="Ryser's conjecture"}

In [graph theory](wikipedia://en/12401), **Ryser's conjecture** is a conjecture relating the [maximum matching](https://en.wikipedia.org/wiki/Maximum_cardinality_matching) size and the minimum transversal size in [hypergraphs](wikipedia://en/232535).

:::

This conjecture first appeared in 1971 in the Ph.D. thesis of J. R. Henderson, whose advisor was [Herbert John Ryser](wikipedia://en/20825197).[^o3]

## Preliminaries {#Preliminaries}

A [**matching** in a hypergraph](wikipedia://en/63030703) is a set of hyperedges such that each vertex appears in at most one of them. The largest size of a matching in a hypergraph *H* is denoted by $\nu(H)$.

A [**transversal** (or **vertex cover**) in a hypergraph](wikipedia://en/64318108) is a set of vertices such that each hyperedge contains at least one of them. The smallest size of a transversal in a hypergraph *H* is denoted by $\tau(H)$.

For every *H*, $\nu(H)\leq \tau(H)$, since every cover must contain at least one point from each edge in any matching.

If H is *r*-uniform (each hyperedge has exactly *r* vertices), then $\tau(H) \leq r\cdot \nu(H)$, since the union of the edges from any maximal matching is a set of at most *rv* vertices that meets every edge.

::: {#o6 .statement kind=statement/conjecture cue=heading name="The conjecture"}

## The conjecture {#The_conjecture}

Ryser's conjecture is that, if H is not only *r*-uniform but also *r-partite* (i.e., its vertices can be partitioned into *r* sets so that every edge contains exactly one element of each set), then:

> $$\tau(H) \leq (r-1)\cdot \nu(H)$$

I.e., the multiplicative factor in the above inequality can be decreased by 1.[^o7]

:::

## Extremal hypergraphs {#Extremal_hypergraphs}

An **extremal hypergraph** to Ryser's conjecture is a hypergraph in which the conjecture holds with equality, i.e., $\tau(H) = (r-1)\cdot \nu(H)$. The existence of such hypergraphs show that the factor *r*-1 is the smallest possible.

An example of an extremal hypergraph is the [truncated projective plane](wikipedia://en/64551468) - the [projective plane](wikipedia://en/24350) of order *r*-1 in which one vertex and all lines containing it is removed.[^o9] It is known to exist whenever *r*-1 is the power of a prime integer.

There are other families of such extremal hypergraphs.[^o10]

::: {#o12 .statement kind=statement/generalization cue=heading name="Special cases"}

## Special cases {#Special_cases}

In the case *r*=2, the hypergraph becomes a [bipartite graph](wikipedia://en/244431), and the conjecture becomes $\tau(H) \leq \nu(H)$. This is known to be true by [Kőnig's theorem](wikipedia://en/5465118).

In the case *r*=3, the conjecture has been proved by [Ron Aharoni](wikipedia://en/22744244).[^o13] The proof uses the [Aharoni-Haxell theorem](wikipedia://en/64398432) for matching in hypergraphs.

In the cases *r*=4 and *r*=5, the following weaker version has been proved by [Penny Haxell](wikipedia://en/47808077) and Scott:[^o14] there exists some ε > 0 such that

> $$\tau(H) \leq (r-\varepsilon)\cdot \nu(H).$$

Moreover, in the cases *r*=4 and *r*=5, Ryser's conjecture has been proved by Tuza (1978) in the special case $\nu(H)=1$, i.e.:

> $$\nu(H) = 1 \implies \tau(H)\leq r-1.$$

:::

## Fractional variants {#Fractional_variants}

A **[fractional matching](wikipedia://en/64410778)** in a hypergraph is an assignment of a weight to each hyperedge such that the sum of weights near each vertex is at most one. The largest size of a fractional matching in a hypergraph *H* is denoted by $\nu^*(H)$.

A **fractional transversal** in a hypergraph is an assignment of a weight to each vertex such that the sum of weights in each hyperedge is at least one. The smallest size of a fractional transversal in a hypergraph *H* is denoted by $\tau^*(H)$. [Linear programming duality](wikipedia://en/15772894) implies that $\nu^*(H) = \tau^*(H)$.

[Furedi](wikipedia://en/22730000) has proved the following fractional version of Ryser's conjecture: If *H* is *r*-partite and *r*-regular (each vertex appears in exactly *r* hyperedges), then[^o16]

> $$\tau^*(H) \leq (r-1)\cdot \nu(H).$$

[Lovasz](wikipedia://en/1623938) has shown that[^o17]

> $$\tau(H) \leq \frac{r}{2}\cdot \nu^*(H).$$
