# Golomb sequence

::: {#o1 .subject cue=lead name="Golomb sequence"}

In mathematics, the **Golomb sequence**, named after [Solomon W. Golomb](wikipedia://en/1860707) (but also called **Silverman's sequence**), is a [monotonically increasing](https://en.wikipedia.org/wiki/Monotonically_increasing) [integer sequence](wikipedia://en/51421) where *a<sub>n</sub>* is the number of times that *n* occurs in the sequence, starting with *a*<sub>1</sub> = 1, and with the property that for *n* > 1 each *a<sub>n</sub>* is the smallest positive integer which makes it possible to satisfy the condition. For example, *a*<sub>1</sub> = 1 says that 1 only occurs once in the sequence, so *a*<sub>2</sub> cannot be 1 too, but it can be 2, and therefore must be 2. The first few values are

:::

1, 2, 2, 3, 3, 4, 4, 4, 5, 5, 5, 6, 6, 6, 6, 7, 7, 7, 7, 8, 8, 8, 8, 9, 9, 9, 9, 9, 10, 10, 10, 10, 10, 11, 11, 11, 11, 11, 12, 12, 12, 12, 12, 12 .

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

*a*<sub>1</sub> = 1 Therefore, 1 occurs exactly one time in this sequence.

*a*<sub>2</sub> > 1 *a*<sub>2</sub> = 2

2 occurs exactly 2 times in this sequence. *a*<sub>3</sub> = 2

3 occurs exactly 2 times in this sequence.

*a*<sub>4</sub> = *a*<sub>5</sub> = 3

4 occurs exactly 3 times in this sequence. 5 occurs exactly 3 times in this sequence.

*a*<sub>6</sub> = *a*<sub>7</sub> = *a*<sub>8</sub> = 4 *a*<sub>9</sub> = *a*<sub>10</sub> = *a*<sub>11</sub> = 5

etc.

:::

## Recurrence {#Recurrence}

Colin Mallows has given an explicit [recurrence relation](wikipedia://en/146806) $a(1) = 1; a(n+1) = 1 + a(n + 1 - a(a(n)))$. An [asymptotic expression](https://en.wikipedia.org/wiki/Asymptotic_expression) for *a<sub>n</sub>* is

$$\varphi^{2-\varphi}n^{\varphi-1}$$

where $\varphi$ is the [golden ratio](wikipedia://en/12386) (approximately equal to 1.618034).[^o5]
