# Nonlinear functional analysis

*Image: 3D-Leveltorus.png.* [Morse theory](wikipedia://en/348560) is a branch of nonlinear functional analysis.

::: {#o1 .subject cue=lead name="Nonlinear functional analysis"}

**Nonlinear functional analysis** is a branch of [mathematical analysis](wikipedia://en/48396) that deals with [nonlinear](https://en.wikipedia.org/wiki/Nonlinear) [mappings](wikipedia://en/516931).

:::

## Topics {#Topics}

Its subject matter includes:[^o3]

- generalizations of [calculus](wikipedia://en/5176) to [Banach spaces](wikipedia://en/3989)
- [implicit function theorems](wikipedia://en/581005)
- fixed-point theorems ([Brouwer fixed point theorem](https://en.wikipedia.org/wiki/Brouwer_fixed_point_theorem), [Fixed point theorems in infinite-dimensional spaces](https://en.wikipedia.org/wiki/Fixed_point_theorems_in_infinite-dimensional_spaces), [topological degree theory](wikipedia://en/18203720), [Jordan separation theorem](https://en.wikipedia.org/wiki/Jordan_separation_theorem), [Lefschetz fixed-point theorem](wikipedia://en/582530))
- [Morse theory](wikipedia://en/348560) and [Lusternik–Schnirelmann category](wikipedia://en/764433) theory
- methods of [complex function theory](https://en.wikipedia.org/wiki/Complex_function_theory)
