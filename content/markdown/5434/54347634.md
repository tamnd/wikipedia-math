# Nested sequent calculus

::: {#o1 .subject cue=lead name="Nested sequent calculus"}

In [structural proof theory](wikipedia://en/929998), the **nested sequent calculus** is a reformulation of the [sequent calculus](wikipedia://en/252329) to allow [deep inference](wikipedia://en/1250664).[^o2]

:::
