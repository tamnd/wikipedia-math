# Analytically normal ring

::: {#o1 .subject cue=lead name="Analytically normal ring"}

In [commutative algebra](wikipedia://en/245990), an **analytically normal ring** is a [local ring](wikipedia://en/153391) whose [completion](https://en.wikipedia.org/wiki/Completion_%28ring_theory%29) is a [normal ring](https://en.wikipedia.org/wiki/Normal_ring); in other words, an [integral domain](wikipedia://en/15462) that is [integrally closed](https://en.wikipedia.org/wiki/Integral_closure) in its [quotient field](https://en.wikipedia.org/wiki/Quotient_field).

:::

[Zariski](wikipedia://en/359352)[^n1] proved that if a local ring of an [algebraic variety](wikipedia://en/248808) is normal, then it is analytically normal, which is in some sense a variation of [Zariski's main theorem](wikipedia://en/13969950). [Nagata](wikipedia://en/3086117)[^n2][^n3] gave an example of a normal [Noetherian](wikipedia://en/56129) local ring that is [analytically reducible](https://en.wikipedia.org/wiki/Analytically_reducible) and therefore not analytically normal.
