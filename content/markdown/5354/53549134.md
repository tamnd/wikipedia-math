# 261 (number)

::: {#o1 .subject cue=lead name="261"}

**261** (**two hundred \[and\] sixty-one**) is the [natural number](wikipedia://en/21474) following [260](https://en.wikipedia.org/wiki/260_%28number%29) and preceding [262](https://en.wikipedia.org/wiki/262_%28number%29).

:::

## In Mathematics {#In_Mathematics}

There are six divisors of this number, the divisors being 1, 3, 9, 29, 87, and 261 itself.[^o4] 261 is a [deficient number](wikipedia://en/321843), since $1 + 3 + 9 + 29 + 87 = 129 < 261.$

261 is [nonagonal number](wikipedia://en/910285), [unique period](https://en.wikipedia.org/wiki/Unique_prime) in [base 2](https://en.wikipedia.org/wiki/Base_2), and the number of possible unfolded [tesseract](wikipedia://en/31112) patterns.

261 is a [lucky number](wikipedia://en/208183), as well as an [odious number](wikipedia://en/2924960), meaning it has an odd number of 1's in its [binary](wikipedia://en/238686) expansion, which is $100000101_{2}$ (with 3 ones in it).[^o7]
