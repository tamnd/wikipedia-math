# EnergyPlus

::: {#o1 .subject cue=lead name="EnergyPlus"}

[EnergyPlus](wikipedia://en/50825030)[^o2] is a whole-building energy simulation program that [engineers](https://en.wikipedia.org/wiki/Engineer), [architects](https://en.wikipedia.org/wiki/Architect), and [researchers](https://en.wikipedia.org/wiki/Research) use to model both energy consumption — for heating, cooling, ventilation, lighting, and process and [plug loads](https://en.wikipedia.org/wiki/Plug_load) — and water use in buildings. Its development is funded by the [U.S. Department of Energy](https://en.wikipedia.org/wiki/U.S._Department_of_Energy) Building Technologies Office.[^o2] EnergyPlus is a console-based program that reads input and writes output to text files. Several comprehensive graphical interfaces for EnergyPlus are also available.

:::

## Main features {#Main_features}

- Integrated, simultaneous solution[^o2] of thermal zone conditions and [HVAC](https://en.wikipedia.org/wiki/HVAC) system response that does not assume that the [HVAC](https://en.wikipedia.org/wiki/HVAC) system can meet zone loads and can simulate un-conditioned and under-conditioned spaces.
- Sub-hourly, user-definable time steps[^o2] for interaction between thermal zones and the environment; with automatically varied time steps for interactions between thermal zones and [HVAC](https://en.wikipedia.org/wiki/HVAC) systems
- Heat balance-based solution[^o2] of [radiant](wikipedia://en/185239) and [convective](https://en.wikipedia.org/wiki/Convective) effects that produce surface temperatures thermal comfort and condensation calculations
- Atmospheric pollutant calculations[^o2]
- [Anisotropic](https://en.wikipedia.org/wiki/Anisotropic) sky model[^o2]
- Combined heat and mass transfer model[^o2] that accounts for air movement between zones.
- [Heat transfer](wikipedia://en/184726) model[^o2]
- Simulation based on climate zone[^o2]
- Advanced [fenestration](https://en.wikipedia.org/wiki/Fenestration_%28architecture%29) models[^o2] including controllable window blinds, [electrochromic](https://en.wikipedia.org/wiki/Electrochromic) glazings, and layer-by-layer heat balances that calculate solar energy absorbed by window panes.
- Component-based [HVAC](https://en.wikipedia.org/wiki/HVAC)[^o2] that supports both standard and novel system configurations.

### Stand-alone vs coupled simulation {#Stand-alone_vs_coupled_simulation}

EnergyPlus is normally used as a stand-alone command-line application or together with one of many free or commercial GUIs. However, EnergyPlus can be linked with other applications to simulate more advanced numerical models. One method is **BCVTB**[^o5] (*Building Controls Virtual Test Bed*), which allows users to couple different simulation programs for co-simulation, and to couple simulation programs with actual hardware. For example, the BCVTB can simulate a building in EnergyPlus and the HVAC and control system in Modelica, exchanging data between them as they simulate. Programs that can be linked to BCVTB include [EnergyPlus](wikipedia://en/50825030), [Modelica](https://en.wikipedia.org/wiki/Modelica) ([OpenModelica](https://en.wikipedia.org/wiki/OpenModelica) or Dymola), [Functional Mock-up Units](https://en.wikipedia.org/wiki/Functional_Mock-up_Units), [MATLAB](wikipedia://en/20412), and [Simulink](https://en.wikipedia.org/wiki/Simulink), [Radiance](https://en.wikipedia.org/wiki/Radiance_%28software%29) for [ray-tracing](wikipedia://en/17003295), [ESP-r](https://en.wikipedia.org/wiki/ESP-r), [TRNSYS](https://en.wikipedia.org/wiki/TRNSYS), [BACnet](https://en.wikipedia.org/wiki/BACnet) stack.

## Applications for sensitivity analysis with EnergyPlus {#Applications_for_sensitivity_analysis_with_EnergyPlus}

There exist many software tools that can automate sensitivity analysis to various degrees. Here is a non-exhaustive list. Most of these tools have multiple options, including one-at-a-time sensitivity analysis, multidimensional discrete parametric, continuous low-discrepancy distributions, and pareto-front optimization (listed alphabetically):

- **EnergyPlus** parametric IDF objects.[^o7] This simple method is limited to discrete parametric analysis, using the auxiliary ParametricPreprocessor program that is bundled with EnergyPlus.
- **EPlusR**[^o8] (*EnergyPlus R*): A research-level scripting toolkit for EnergyPlus in [R (programming language)](wikipedia://en/376707).
- **EpXL**[^o9] (*EnergyPlus Excel*): A simple Excel spreadsheet application with options for sensitivity/parametric analysis and pareto-front optimization.
- **GenOpt**[^o10] (*Generic Optimization Program*), optionally with the free GenOpt GUI ExcalibBEM[^o11]
- **jEPlus**[^o12] (*Jython EnergyPlus*): A simulation manager for parametric analysis with EnergyPlus.
- **OpenStudio** Analysis Framework and Spreadsheet:[^o13] A front-end for the OpenStudio Server, allowing for users to create large-scale cloud analyses using OpenStudio measures.
- **SALib**:[^o14] A Python library for general sensitivity analysis, which can be used with user-defined scripts to run EnergyPlus and extract results.
