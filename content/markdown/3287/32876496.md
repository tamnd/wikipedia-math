# Krein's condition

::: {#o1 .subject cue=lead name="Krein's condition"}

In [mathematical analysis](wikipedia://en/48396), **Krein's condition** provides a necessary and sufficient condition for exponential sums

:::

$$\left\{ \sum_{k=1}^n a_k \exp(i \lambda_k x), \quad a_k \in \mathbb{C}, \, \lambda_k \geq 0 \right\},$$

to be [dense](https://en.wikipedia.org/wiki/Dense_%28topology%29) in a [weighted L<sub>2</sub> space](https://en.wikipedia.org/wiki/Lp-space#Weighted_Lp_spaces) on the real line. It was discovered by [Mark Krein](wikipedia://en/1190470) in the 1940s.[^o2] A corollary, also called Krein's condition, provides a sufficient condition for the indeterminacy of the [moment problem](wikipedia://en/1244992).[^o4]

::: {#o6 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let *μ* be an [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous#Absolute_continuity_of_measures) [measure](wikipedia://en/19873) on the real line, d*μ*(*x*) = *f*(*x*) d*x*. The exponential sums

$$\sum_{k=1}^n a_k \exp(i \lambda_k x), \quad a_k \in \mathbb{C}, \, \lambda_k \geq 0$$

are dense in *L*<sub>2</sub>(*μ*) if and only if

$$\int_{-\infty}^\infty \frac{- \ln f(x)}{1 + x^2} \, dx = \infty.$$

:::

## Indeterminacy of the moment problem {#Indeterminacy_of_the_moment_problem}

Let *μ* be as above; assume that all the [moments](wikipedia://en/368684)

$$m_n = \int_{-\infty}^\infty x^n d\mu(x), \quad n = 0,1,2,\ldots$$

of *μ* are finite. If

$$\int_{-\infty}^\infty \frac{- \ln f(x)}{1 + x^2} \, dx < \infty$$

holds, then the [Hamburger moment problem](wikipedia://en/3216491) for *μ* is indeterminate; that is, there exists another measure *ν* ≠ *μ* on **R** such that

$$m_n = \int_{-\infty}^\infty x^n \, d\nu(x), \quad n = 0,1,2,\ldots$$

This can be derived from the "only if" part of Krein's theorem above.[^o8]

::: {#o10 .example cue=heading name="Example"}

### Example {#Example}

Let

$$f(x) = \frac{1}{\sqrt{\pi}} \exp \left\{ - \ln^2 x \right\};$$

the measure d*μ*(*x*) = *f*(*x*) d*x* is called the [Stieltjes–Wigert measure](wikipedia://en/27403688). Since

$$\int_{-\infty}^\infty \frac{- \ln f(x)}{1+x^2} dx = \int_{-\infty}^\infty \frac{\ln^2 x + \ln \sqrt{\pi}}{1 + x^2} \, dx < \infty,$$

the Hamburger moment problem for *μ* is indeterminate.

:::
