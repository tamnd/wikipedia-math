# Totally imaginary number field

::: {#o1 .subject cue=lead name="Totally imaginary number field"}

In [algebraic number theory](wikipedia://en/174705), a [number field](https://en.wikipedia.org/wiki/Number_field) is called **totally imaginary** (or **totally complex**) if it cannot be [embedded](wikipedia://en/52119) in the [real numbers](wikipedia://en/20646438).[^n1] Specific examples include [imaginary quadratic fields](https://en.wikipedia.org/wiki/Imaginary_quadratic_field), [cyclotomic fields](wikipedia://en/30872462), and, more generally, [CM fields](https://en.wikipedia.org/wiki/CM_field).

:::

Any number field that is [Galois](wikipedia://en/457064) over the [rationals](wikipedia://en/19727024) must be either [totally real](wikipedia://en/312853) or totally imaginary.
