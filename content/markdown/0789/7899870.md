# Cauchy matrix

::: {#o1 .subject cue=lead name="Cauchy matrix"}

In [mathematics](wikipedia://en/18831), a **Cauchy matrix**, named after [Augustin-Louis Cauchy](wikipedia://en/1842), is an *m*×*n* [matrix](wikipedia://en/20556859) with elements *a*<sub>*ij*</sub> in the form

:::

$$a_{ij}={\frac{1}{x_i-y_j}};\quad x_i-y_j\neq 0,\quad 1 \le i \le m,\quad 1 \le j \le n$$

where $x_i$ and $y_j$ are elements of a [field](wikipedia://en/10603) $\mathcal{F}$, and $(x_i)$ and $(y_j)$ are [injective](https://en.wikipedia.org/wiki/Injective) sequences (they contain *distinct* elements).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every [submatrix](https://en.wikipedia.org/wiki/Submatrix) of a Cauchy matrix is itself a Cauchy matrix.

The [Hilbert matrix](wikipedia://en/265000) is a special case of the Cauchy matrix, where

$$x_i-y_j = i+j-1. \;$$

:::

## Cauchy determinants {#Cauchy_determinants}

The determinant of a Cauchy matrix is clearly a [rational fraction](https://en.wikipedia.org/wiki/Rational_fraction) in the parameters $(x_i)$ and $(y_j)$. If the sequences were not injective, the determinant would vanish, and tends to infinity if some $x_i$ tends to $y_j$. A subset of its zeros and poles are thus known. The fact is that there are no more zeros and poles:

The determinant of a square Cauchy matrix **A** is known as a **Cauchy determinant** and can be given explicitly as

$\det \mathbf{A}={{\prod_{i=2}^n \prod_{j=1}^{i-1} (x_i-x_j)(y_j-y_i)}\over {\prod_{i=1}^n \prod_{j=1}^n (x_i-y_j)}}$ (Schechter 1959, eqn 4; Cauchy 1841, p. 154, eqn. 10).

It is always nonzero, and thus all square Cauchy matrices are [invertible](wikipedia://en/217122). The inverse **A**<sup>−1</sup> = **B** = \[b<sub>ij</sub>\] is given by

$b_{ij} = (x_j - y_i) A_j(y_i) B_i(x_j) \,$ (Schechter 1959, Theorem 1)

where *A*<sub>i</sub>(x) and *B*<sub>i</sub>(x) are the [Lagrange polynomials](https://en.wikipedia.org/wiki/Lagrange_polynomials) for $(x_i)$ and $(y_j)$, respectively. That is,

$$A_i(x) = \frac{A(x)}{A^\prime(x_i)(x-x_i)} \quad\text{and}\quad B_i(x) = \frac{B(x)}{B^\prime(y_i)(x-y_i)},$$

with

$$A(x) = \prod_{i=1}^n (x-x_i) \quad\text{and}\quad B(x) = \prod_{i=1}^n (x-y_i).$$

::: {#o6 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

A matrix **C** is called **Cauchy-like** if it is of the form

$$C_{ij}=\frac{r_i s_j}{x_i-y_j}.$$

Defining **X**=diag(x<sub>i</sub>), **Y**=diag(y<sub>i</sub>), one sees that both Cauchy and Cauchy-like matrices satisfy the [displacement equation](https://en.wikipedia.org/wiki/Displacement_rank)

$$\mathbf{XC}-\mathbf{CY}=rs^\mathrm{T}$$

(with $r=s=(1,1,\ldots,1)$ for the Cauchy one). Hence Cauchy-like matrices have a common [displacement structure](https://en.wikipedia.org/wiki/Displacement_structure), which can be exploited while working with the matrix. For example, there are known algorithms in literature for

- approximate Cauchy matrix-vector multiplication with $O(n \log n)$ [ops](https://en.wikipedia.org/wiki/FLOPS) (e.g. the [fast multipole method](wikipedia://en/8280771)),
- ([pivoted](wikipedia://en/9811503)) [LU factorization](https://en.wikipedia.org/wiki/LU_factorization) with $O(n^2)$ ops (GKO algorithm), and thus linear system solving,
- linear system solving in $\tilde O({\alpha ^{\omega - 1}}n)$ ops with the use of [fast matrix multiplication algorithms](wikipedia://en/24107400), instead of $\tilde O({\alpha ^2}n)$ ops without it, where $\alpha$ is the [displacement rank](https://en.wikipedia.org/wiki/Displacement_rank) and $^ \sim 2.37 \le \omega < 3$[^o7].
- approximated or unstable algorithms for linear system solving in $O(n \log^2 n)$.

Here $n$ denotes the size of the matrix (one usually deals with square matrices, though all algorithms can be easily generalized to rectangular matrices).
