# Wolfram Demonstrations Project

::: {#o1 .subject cue=lead name="Wolfram Demonstrations Project"}

*Image: Tangent 1.jpg.* One of the Demonstrations about [surface tangents](wikipedia://en/31482)

The **Wolfram Demonstrations Project** is an [open-source](https://en.wikipedia.org/wiki/Open_source) collection of [interactive programmes](https://en.wikipedia.org/wiki/Interactive_computing) called Demonstrations. It is hosted by [Wolfram Research](wikipedia://en/594109). At its launch, it contained 1300 demonstrations but has grown to over 10,000. The site won a [Parents' Choice Award](https://en.wikipedia.org/wiki/Parents'_Choice_Award) in 2008.

:::

[Wolfram Research](wikipedia://en/594109)'s staff organizes and edits the Demonstrations, which may be created by any user of [Mathematica](wikipedia://en/49024), then freely published[^o2] and freely downloaded.

## Technology {#Technology}

The Demonstrations run in [Mathematica](wikipedia://en/49024) 6 or above and in Wolfram [CDF Player](https://en.wikipedia.org/wiki/Computable_Document_Format), which is a free modified version of [Wolfram Mathematica](wikipedia://en/49024)[^o4] and available for [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [Linux](https://en.wikipedia.org/wiki/Linux), and [macOS](https://en.wikipedia.org/wiki/MacOS)[^o5] and can operate as a web [browser plugin](https://en.wikipedia.org/wiki/Browser_extension). Demonstrations can also be embedded into a website.[^o6] Each Demonstration page includes a snippet of [JavaScript](https://en.wikipedia.org/wiki/JavaScript) code in the Share section of the sidebar.

The Demonstrations typically consist of a direct user interface to a graphic or visualization that dynamically responds to user actions. Each Demonstration also has a description of the concept. The website is organized by topic, for example: science,[^o7] art, and biology.
