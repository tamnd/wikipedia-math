# Thousands of Problems for Theorem Provers

::: {#o1 .subject cue=lead name="Thousands of Problems for Theorem Provers"}

**TPTP** (Thousands of Problems for Theorem Provers)[^o2] is a freely available collection of problems for [automated theorem proving](wikipedia://en/2546). It is used to evaluate the efficacy of automated reasoning algorithms.[^o3][^o4][^o5] Problems are expressed in a simple text-based format for first order logic or higher-order logic.[^o6] TPTP is used as the source of some problems in [CASC](https://en.wikipedia.org/wiki/CADE_ATP_System_Competition).

:::
