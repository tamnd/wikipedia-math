# Looman–Menchoff theorem

::: {#o1 .subject cue=lead name="Looman–Menchoff theorem"}

In the [mathematical](wikipedia://en/18831) field of [complex analysis](wikipedia://en/5759), the **Looman–Menchoff theorem** states that a [continuous](wikipedia://en/6122) [complex](wikipedia://en/5826)-valued function defined in an [open set](wikipedia://en/39358) of the [complex plane](wikipedia://en/217628) is [holomorphic](wikipedia://en/14110) if and only if it satisfies the [Cauchy–Riemann equations](wikipedia://en/7583). It is thus a generalization of a [theorem](wikipedia://en/7583#Goursat's_theorem_and_its_generalizations) by [Édouard Goursat](wikipedia://en/1674255), which instead of assuming the continuity of *f*, assumes its [Fréchet differentiability](wikipedia://en/2735727) when regarded as a function from a subset of **R**<sup>2</sup> to **R**<sup>2</sup>. This theorem bears the name of Dutch mathematician [Herman Looman](https://en.wikipedia.org/wiki/Herman_Looman_%28mathematician%29) and Soviet mathematician [Dmitrii Menshov](wikipedia://en/6096579).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

A complete statement of the theorem is as follows:

- Let Ω be an open set in **C** and *f* : Ω → **C** be a continuous function. Suppose that the [partial derivatives](wikipedia://en/52565) $\partial f/\partial x$ and $\partial f/\partial y$ exist everywhere but a countable set in Ω. Then *f* is holomorphic if and only if it satisfies the Cauchy–Riemann equation:

$$\frac{\partial f}{\partial\bar{z}} = \frac{1}{2}\left(\frac{\partial f}{\partial x} + i\frac{\partial f}{\partial y}\right)=0.$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Looman pointed out that the function given by *f*(*z*) = exp(−*z*<sup>−4</sup>) for *z* ≠ 0, *f*(0) = 0 satisfies the Cauchy–Riemann equations everywhere but is not analytic (or even continuous) at *z* = 0. This shows that the function *f* must be assumed continuous in the theorem.

The function given by *f*(*z*) = *z*<sup>5</sup>/|*z*|<sup>4</sup> for *z* ≠ 0, *f*(0) = 0 is continuous everywhere and satisfies the Cauchy–Riemann equations at *z* = 0, but is not analytic at *z* = 0 (or anywhere else). This shows that a naive generalization of the Looman–Menchoff theorem to a single point is **false**:

- Let *f* be continuous at a neighborhood of a point *z*, and such that $\partial f/\partial x$ and $\partial f/\partial y$ exist at *z*. Then *f* is holomorphic at *z* if and only if it satisfies the Cauchy–Riemann equation at *z*.

:::
