# SAS language

::: {#o2 .subject cue=lead name="SAS language"}

The **SAS language** is a [fourth-generation](https://en.wikipedia.org/wiki/Fourth-generation_programming_language) computer [programming language](wikipedia://en/23015) used for statistical analysis, created by [Anthony James Barr](https://en.wikipedia.org/wiki/Anthony_James_Barr) at [North Carolina State University](https://en.wikipedia.org/wiki/North_Carolina_State_University).[^o3][^o4] Its primary applications include [data mining](wikipedia://en/42253) and [machine learning](wikipedia://en/233488). The SAS language runs under [compilers](https://en.wikipedia.org/wiki/Compiler) such as the [SAS System](https://en.wikipedia.org/wiki/SAS_System) that can be used on [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [Linux](https://en.wikipedia.org/wiki/Linux), [UNIX](https://en.wikipedia.org/wiki/UNIX) and [mainframe computers](https://en.wikipedia.org/wiki/Mainframe_computers).[^o5]

:::

## History {#History}

SAS was developed in the 1960s by [Anthony James Barr](https://en.wikipedia.org/wiki/Anthony_James_Barr), who built its fundamental structure,[^o7] and [SAS Institute](wikipedia://en/194872) CEO [James Goodnight](wikipedia://en/6900671), who developed a number of features including analysis procedures.[^o8] The language is currently developed and sponsored by the [SAS Institute](wikipedia://en/194872), of which Goodnight is founder and CEO.[^o9]

## Language {#Language}

Base SAS is a [fourth-generation](https://en.wikipedia.org/wiki/Fourth-generation_programming_language) [procedural programming](https://en.wikipedia.org/wiki/Procedural_programming) language designed for the statistical analysis of data.[^o11] It is [Turing-complete](https://en.wikipedia.org/wiki/Turing-complete) and domain specific, with many of the attributes of a [command language](https://en.wikipedia.org/wiki/Command_language). As an [interpreted language](https://en.wikipedia.org/wiki/Interpreted_language), it is generally parsed, compiled, and executed step by step.[^o12] The SAS system was originally a [single instruction, single data](https://en.wikipedia.org/wiki/Single_instruction,_single_data) (SISD) engine, but [single instruction, multiple data](https://en.wikipedia.org/wiki/Single_instruction,_multiple_data) (SIMD) and [multiple instruction, multiple data](https://en.wikipedia.org/wiki/Multiple_instruction,_multiple_data) (MIMD) functionality was later added.[^o13] Most base SAS code can be ported between versions, but some are functions and parameters are specific to certain operating systems and interfaces.[^o14]

All SAS programs are written within the SAS language, although some packages use menu-driven [graphical user interfaces](https://en.wikipedia.org/wiki/Graphical_user_interfaces) on the [front-end](https://en.wikipedia.org/wiki/Front-end_web_development).[^o15] Various SAS editors use color coding to identify components like step boundaries, keywords and constants.[^o16] It can read in data from common spreadsheets and databases and output the results of statistical analyses in tables, graphs, and as [RTF](https://en.wikipedia.org/wiki/Rich_Text_Format), [HTML](https://en.wikipedia.org/wiki/HTML) and [PDF](https://en.wikipedia.org/wiki/PDF) documents.[^o17]

### Syntax {#Syntax}

The language consists of two main types of blocks: DATA blocks and PROC blocks.[^o19] DATA blocks can be used to read and manipulate input data, and create data sets. PROC blocks are used to perform analyses and operations on these data sets, sort data, and output results in the form of [descriptive statistics](wikipedia://en/8187), tables, results, charts and plots.[^o20][^o21] PROC SQL can be used to work with [SQL](wikipedia://en/29004) syntax within SAS.[^o22]

Users can input both numeric and character data into base SAS. SAS statements must begin with a reserved keyword and end with ;[^o23] but the language is otherwise flexible in terms of formatting and most statements are [case insensitive](https://en.wikipedia.org/wiki/Case_insensitive).[^o24] SAS statements can continue across multiple lines and do not require indenting, although indents can improve readability.[^o23] Comments are delimited by /\* and \*/.[^o25]

A standard SAS program typically entails the definition of data, the creation of a [data set](wikipedia://en/8495), and the performance of procedures such as analysis on that data set.[^o23] SAS scripts have the .sas extension.

A simple example of SAS code is the following

```sas
* COMMENT;
Data TEMP;
   input X Y Z;
   datalines;
1 2 3
5 6 7
;
run;

PROC PRINT DATA = TEMP;
RUN;
```

### SAS macro language {#SAS_macro_language}

The SAS [macro language](https://en.wikipedia.org/wiki/Macro_language) is made available within base SAS software to reduce the amount of code, and create [code generators](https://en.wikipedia.org/wiki/Code_generation_%28compiler%29) for building more versatile and flexible programs.[^o27] The macro language can be used for functionalities as simple as symbolic substitution and as complex as [dynamic programming](https://en.wikipedia.org/wiki/Dynamic_programming_language).[^o12] SAS macro is considered to be a rich language,[^o28] although its overall syntax is very similar to that of base SAS. The names of macro variables in SAS are usually preceded by &, while macro program statements are usually preceded by %.[^o12]

## Software {#Software}

SAS Institute develops a number of tools and software suites, also called SAS, which are used for creating programs in the language. These suites include [JMP](wikipedia://en/1979375), [SAS Viya](https://en.wikipedia.org/wiki/SAS_Viya), SAS Enterprise Guide and SAS Enterprise Miner.[^o5][^o13][^o22] In 2002, [World Programming](https://en.wikipedia.org/wiki/World_Programming) also developed software that allows the execution of most SAS scripts.[^o22]

::: {#o31 .application cue=heading name="Uses"}

## Uses {#Uses}

The SAS language is used as a standard in many industries,[^o22] and was ranked #22 on the [TIOBE index](https://en.wikipedia.org/wiki/TIOBE_index) in February 2024.[^o32] It is especially widely used for [machine learning](wikipedia://en/233488),[^o33] [data mining](wikipedia://en/42253), and [data warehousing](https://en.wikipedia.org/wiki/Data_warehousing) in the finance, insurance, manufacturing, health care and pharmaceutical industries.[^o19] It has a high level of documentation and community support,[^o25] which has contributed to its uptake.[^o33]

### Machine learning {#Machine_learning}

SAS is used for preparing input data, and building and optimizing [machine learning](wikipedia://en/233488) algorithms.[^o35] Various models, such as [artificial neural networks](https://en.wikipedia.org/wiki/Artificial_neural_networks) (ANN), [convolutional neural networks](https://en.wikipedia.org/wiki/Convolutional_neural_networks) and [deep learning](https://en.wikipedia.org/wiki/Deep_learning) models, are developed and trained in SAS.[^o36] These are applied to areas such as [computer vision](https://en.wikipedia.org/wiki/Computer_vision) and [fraud detection](https://en.wikipedia.org/wiki/Fraud_detection).[^o37] SAS has also been noted for its applications in the area of [decision intelligence](https://en.wikipedia.org/wiki/Decision_intelligence).[^o38]

### Data mining and warehousing {#Data_mining_and_warehousing}

While SAS was originally developed for [data analysis](wikipedia://en/2720954), it became an important language for [data storage](https://en.wikipedia.org/wiki/Computer_data_storage).[^o8] SAS is one of the primary languages used for data mining in business intelligence and statistics.[^o40] According to [Gartner](https://en.wikipedia.org/wiki/Gartner)'s [Magic Quadrant](https://en.wikipedia.org/wiki/Magic_Quadrant) and [Forrester Research](https://en.wikipedia.org/wiki/Forrester_Research), the SAS Institute is one of the largest vendors of data mining software.[^o33]
