# Topological indistinguishability

::: {#o1 .subject cue=lead name="Topological indistinguishability"}

In [topology](wikipedia://en/29954), two points of a [topological space](wikipedia://en/30450) *X* are **topologically indistinguishable**[^o2] if they have exactly the same [neighborhoods](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29). That is, if *x* and *y* are points in *X*, and *N<sub>x</sub>* is the set of all neighborhoods that contain *x*, and *N<sub>y</sub>* is the set of all neighborhoods that contain *y*, then *x* and *y* are "topologically indistinguishable" [if and only if](wikipedia://en/14922) *N<sub>x</sub>* = *N<sub>y</sub>*. (See Hausdorff's axiomatic [neighborhood systems](https://en.wikipedia.org/wiki/Characterizations_of_the_category_of_topological_spaces).)

:::

Intuitively, two points are topologically indistinguishable if the topology of *X* is unable to discern between the points.

Two points of *X* are **topologically distinguishable** if they are not topologically indistinguishable. This means there is an [open set](wikipedia://en/39358) containing precisely one of the two points (equivalently, there is a [closed set](wikipedia://en/47279) containing precisely one of the two points). This open set can then be used to distinguish between the two points. A [T<sub>0</sub> space](https://en.wikipedia.org/wiki/T0_space) is a topological space in which every pair of distinct points is topologically distinguishable. This is the weakest of the [separation axioms](wikipedia://en/40117302).

Topological indistinguishability defines an [equivalence relation](wikipedia://en/9259) on any topological space *X*. If *x* and *y* are points of *X* we write *x* ≡ *y* for "*x* and *y* are topologically indistinguishable". The [equivalence class](wikipedia://en/9260) of *x* will be denoted by \[*x*\].

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

By definition, any two distinct points in a [T<sub>0</sub> space](https://en.wikipedia.org/wiki/T0_space) are topologically distinguishable. On the other hand, [regularity](wikipedia://en/53058) and [normality](wikipedia://en/48629) do not imply T<sub>0</sub>, so we can find nontrivial examples of topologically indistinguishable points in regular or normal topological spaces. In fact, almost all of the examples given below are [completely regular](https://en.wikipedia.org/wiki/Completely_regular).

- In an [indiscrete space](https://en.wikipedia.org/wiki/Indiscrete_space), any two points are topologically indistinguishable.
- In a [pseudometric space](wikipedia://en/68503), two points are topologically indistinguishable if and only if the distance between them is zero.
- In a [seminormed vector space](https://en.wikipedia.org/wiki/Seminormed_vector_space), *x* ≡ *y* if and only if ‖*x* − *y*‖ = 0.
  - For example, let *L*<sup>2</sup>(**R**) be the space of all [measurable functions](wikipedia://en/44055) from **R** to **R** which are [square integrable](https://en.wikipedia.org/wiki/Square_integrable) (see [*L*<sup>*p*</sup> space](wikipedia://en/45194)). Then two functions *f* and *g* in *L*<sup>2</sup>(**R**) are topologically indistinguishable if and only if they are equal [almost everywhere](wikipedia://en/44688).
- In a [topological group](wikipedia://en/42315), *x* ≡ *y* if and only if *x*<sup>−1</sup>*y* ∈ cl{*e*} where cl{*e*} is the [closure](wikipedia://en/42309) of the [trivial subgroup](https://en.wikipedia.org/wiki/Trivial_subgroup). The equivalence classes are just the [cosets](wikipedia://en/98759) of cl{*e*} (which is always a [normal subgroup](wikipedia://en/21918)).
- [Uniform spaces](wikipedia://en/32339) generalize both pseudometric spaces and topological groups. In a uniform space, *x* ≡ *y* if and only if the pair (*x*, *y*) belongs to every [entourage](https://en.wikipedia.org/wiki/Entourage_%28topology%29). The intersection of all the entourages is an equivalence relation on *X* which is just that of topological indistinguishability.
- Let *X* have the [initial topology](wikipedia://en/1197123) with respect to a family of functions $\{f_\alpha : X \to Y_\alpha\}$. Then two points *x* and *y* in *X* will be topologically indistinguishable if the family $f_\alpha$ does not separate them (i.e. $f_\alpha(x) = f_\alpha(y)$ for all $\alpha$).
- Given any equivalence relation on a set *X* there is a topology on *X* for which the notion of topological indistinguishability agrees with the given equivalence relation. One can simply take the equivalence classes as a [base](wikipedia://en/59220) for the topology. This is called the [partition topology](wikipedia://en/5334930) on *X*.

:::

## Specialization preorder {#Specialization_preorder}

The topological indistinguishability relation on a space *X* can be recovered from a natural [preorder](wikipedia://en/23582) on *X* called the [specialization preorder](wikipedia://en/542347). For points *x* and *y* in *X* this preorder is defined by

*x* ≤ *y* [if and only if](wikipedia://en/14922) *x* ∈ cl{*y*}

where cl{*y*} denotes the [closure](wikipedia://en/42309) of {*y*}. Equivalently, *x* ≤ *y* if the [neighborhood system](https://en.wikipedia.org/wiki/Neighborhood_system) of *x*, denoted *N*<sub>*x*</sub>, is contained in the neighborhood system of *y*:

*x* ≤ *y* if and only if *N*<sub>*x*</sub> ⊂ *N*<sub>*y*</sub>.

It is easy to see that this relation on *X* is [reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200463) and so defines a preorder. In general, however, this preorder will not be [antisymmetric](wikipedia://en/1176). Indeed, the equivalence relation determined by ≤ is precisely that of topological indistinguishability:

*x* ≡ *y* if and only if *x* ≤ *y* and *y* ≤ *x*.

A topological space is said to be [symmetric (or R<sub>0</sub>)](https://en.wikipedia.org/wiki/R0_space) if the specialization preorder is [symmetric](wikipedia://en/200459) (i.e. *x* ≤ *y* implies *y* ≤ *x*). In this case, the relations ≤ and ≡ are identical. Topological indistinguishability is better behaved in these spaces and easier to understand. Note that this class of spaces includes all [regular](wikipedia://en/53058) and [completely regular spaces](https://en.wikipedia.org/wiki/Completely_regular_space).

## Properties {#Properties}

### Equivalent conditions {#Equivalent_conditions}

There are several equivalent ways of determining when two points are topologically indistinguishable. Let *X* be a topological space and let *x* and *y* be points of *X*. Denote the respective [closures](wikipedia://en/42309) of *x* and *y* by cl{*x*} and cl{*y*}, and the respective [neighborhood systems](https://en.wikipedia.org/wiki/Neighborhood_system) by *N*<sub>*x*</sub> and *N*<sub>*y*</sub>. Then the following statements are equivalent:

- *x* ≡ *y*
- for each open set *U* in *X*, *U* contains either both *x* and *y* or neither of them
- *N*<sub>*x*</sub> = *N*<sub>*y*</sub>
- *x* ∈ cl{*y*} and *y* ∈ cl{*x*}
- cl{*x*} = cl{*y*}
- *x* ∈ ∩*N*<sub>*y*</sub> and *y* ∈ ∩*N*<sub>*x*</sub>
- ∩*N*<sub>*x*</sub> = ∩*N*<sub>*y*</sub>
- *x* ∈ cl{*y*} and *x* ∈ ∩*N*<sub>*y*</sub>
- *x* belongs to every open set and every closed set containing *y*
- a [net](https://en.wikipedia.org/wiki/Net_%28topology%29) or [filter](https://en.wikipedia.org/wiki/Filter_%28topology%29) converges to *x* if and only if it converges to *y*

These conditions can be simplified in the case where *X* is [symmetric space](https://en.wikipedia.org/wiki/R0_space). For these spaces (in particular, for [regular spaces](wikipedia://en/53058)), the following statements are equivalent:

- *x* ≡ *y*
- for each open set *U*, if *x* ∈ *U* then *y* ∈ *U*
- *N*<sub>*x*</sub> ⊂ *N*<sub>*y*</sub>
- *x* ∈ cl{*y*}
- *x* ∈ ∩*N*<sub>*y*</sub>
- *x* belongs to every closed set containing *y*
- *x* belongs to every open set containing *y*
- every net or filter that converges to *x* converges to *y*

### Equivalence classes {#Equivalence_classes}

To discuss the [equivalence class](wikipedia://en/9260) of *x*, it is convenient to first define the [upper](https://en.wikipedia.org/wiki/Upper_set) and [lower sets](https://en.wikipedia.org/wiki/Lower_set) of *x*. These are both defined with respect to the [specialization preorder](wikipedia://en/542347) discussed above.

The lower set of *x* is just the closure of {*x*}:

$$\mathop{\downarrow}x = \{y\in X: y\leq x\} = \textrm{cl}\{x\}$$

while the upper set of *x* is the [intersection](wikipedia://en/23476429) of the [neighborhood system](https://en.wikipedia.org/wiki/Neighborhood_system) at *x*:

$$\mathop{\uparrow}x = \{y\in X: x\leq y\} = \bigcap \mathcal{N}_x.$$

The equivalence class of *x* is then given by the intersection

$$[x] = {\mathop{\downarrow}x} \cap {\mathop{\uparrow}x}.$$

Since ↓*x* is the intersection of all the closed sets containing *x* and ↑*x* is the intersection of all the open sets containing *x*, the equivalence class \[*x*\] is the intersection of all the open sets and closed sets containing *x*.

Both cl{*x*} and ∩*N*<sub>*x*</sub> will contain the equivalence class \[*x*\]. In general, both sets will contain additional points as well. In [symmetric spaces](https://en.wikipedia.org/wiki/R0_space) (in particular, in [regular spaces](wikipedia://en/53058)) however, the three sets coincide:

$$[x] = \textrm{cl}\{x\} = \bigcap\mathcal{N}_x.$$

In general, the equivalence classes \[*x*\] will be closed if and only if the space is symmetric.

### Continuous functions {#Continuous_functions}

Let *f* : *X* → *Y* be a [continuous function](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29). Then for any *x* and *y* in *X*

*x* ≡ *y* implies *f*(*x*) ≡ *f*(*y*).

The converse is generally false (There are [quotients](wikipedia://en/237213) of T<sub>0</sub> spaces which are [trivial](wikipedia://en/382447)). The converse will hold if *X* has the [initial topology](wikipedia://en/1197123) induced by *f*. More generally, if *X* has the initial topology induced by a family of maps $f_\alpha : X \to Y_\alpha$ then

*x* ≡ *y* if and only if *f*<sub>α</sub>(*x*) ≡ *f*<sub>α</sub>(*y*) for all α.

It follows that two elements in a [product space](https://en.wikipedia.org/wiki/Product_space) are topologically indistinguishable if and only if each of their components are topologically indistinguishable.

:::

## Kolmogorov quotient {#Kolmogorov_quotient}

Since topological indistinguishability is an equivalence relation on any topological space *X*, we can form the [quotient space](wikipedia://en/237213) *KX* = *X*/≡. The space *KX* is called the **[Kolmogorov quotient](https://en.wikipedia.org/wiki/Kolmogorov_quotient)** or **T<sub>0</sub> identification** of *X*. The space *KX* is, in fact, T<sub>0</sub> (i.e. all points are topologically distinguishable). Moreover, by the characteristic property of the quotient map any continuous map *f* : *X* → *Y* from *X* to a T<sub>0</sub> space factors through the quotient map *q* : *X* → *KX*. Categorically, the T<sub>0</sub> spaces form a [reflective subcategory](wikipedia://en/3967424) of the category of topological spaces, with the Kolmogorov quotient as the reflector.

Although the quotient map *q* is generally not a [homeomorphism](wikipedia://en/13660) (since it is not generally [injective](wikipedia://en/45196)), it does induce a [bijection](wikipedia://en/3942) between the topology on *X* and the topology on *KX*. Intuitively, the Kolmogorov quotient does not alter the topology of a space. It just reduces the point set until points become topologically distinguishable.
