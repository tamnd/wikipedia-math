# Darboux

::: {#o1 .subject cue=lead name="Darboux"}

**Darboux** is a surname. Notable people with the surname include:

:::

- [Jean Gaston Darboux](wikipedia://en/1142530) (1842–1917), French mathematician
- [Lauriane Doumbouya](https://en.wikipedia.org/wiki/Lauriane_Doumbouya) (née Darboux), the current First Lady of Guinea since 5 September 2021
- [Paul Darboux](https://en.wikipedia.org/wiki/Paul_Darboux) (1919–1982), Beninese politician
