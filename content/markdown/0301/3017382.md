# Projective object

::: {#o1 .subject cue=lead name="Projective object"}

In [category theory](wikipedia://en/5869), the notion of a **projective object** generalizes the notion of a [projective module](wikipedia://en/364488). Projective objects in [abelian](wikipedia://en/45063) [categories](wikipedia://en/53759) are used in [homological algebra](wikipedia://en/139410). The [dual](wikipedia://en/609737) notion of a projective object is that of an [injective object](wikipedia://en/473779).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29) $P$ in a category $\mathcal{C}$ is *projective* if for any [epimorphism](wikipedia://en/59539) $e:E\twoheadrightarrow X$ and [morphism](wikipedia://en/27716891) $f:P\to X$, there is a morphism $\overline{f}:P\to E$ such that $e\circ \overline{f}=f$, i.e. the following diagram [commutes](wikipedia://en/138484):

*Image: Projective object.svg.*

That is, every morphism $P\to X$ [factors through](https://en.wikipedia.org/wiki/Mathematical_jargon#factor_through) every epimorphism $E\twoheadrightarrow X$.[^o4]

If *C* is [locally small](wikipedia://en/53759#Small_and_large_categories), i.e., in particular $\operatorname{Hom}_C(P, X)$ is a [set](wikipedia://en/26691) for any object *X* in *C*, this definition is equivalent to the condition that the [hom functor](wikipedia://en/2741037) (also known as [corepresentable functor](wikipedia://en/844461))

$$\operatorname{Hom}(P,-)\colon\mathcal{C}\to\mathbf{Set}$$

preserves [epimorphisms](wikipedia://en/59539).[^o5]

### Projective objects in abelian categories {#Projective_objects_in_abelian_categories}

If the category *C* is an abelian category such as, for example, the [category of abelian groups](wikipedia://en/454748), then *P* is projective if and only if

$$\operatorname{Hom}(P,-)\colon\mathcal{C}\to\mathbf{Ab}$$

is an [exact functor](wikipedia://en/453945), where **Ab** is the category of [abelian groups](wikipedia://en/2974).

An abelian category $\mathcal{A}$ is said to have *enough projectives* if, for every object $A$ of $\mathcal{A}$, there is a projective object $P$ of $\mathcal{A}$ and an epimorphism from *P* to *A* or, equivalently, a [short exact sequence](https://en.wikipedia.org/wiki/Short_exact_sequence)

$$0 \to K \to P \to A \to 0.$$

The purpose of this definition is to ensure that any object *A* admits a [projective resolution](https://en.wikipedia.org/wiki/Projective_resolution), i.e., a (long) exact sequence

$$\dots P_2 \to P_1 \to P_0 \to A \to 0$$

where the objects $P_0, P_1, \dots$ are projective.

### Projectivity with respect to restricted classes {#Projectivity_with_respect_to_restricted_classes}

(Semadeni 1963) discusses the notion of projective (and dually injective) objects relative to a so-called bicategory, which consists of a pair of subcategories of "injections" and "surjections" in the given category *C*. These subcategories are subject to certain formal properties including the requirement that any surjection is an epimorphism. A projective object (relative to the fixed class of surjections) is then an object *P* so that Hom(*P*, −) turns the fixed class of surjections (as opposed to all epimorphisms) into surjections of sets (in the usual sense).

## Properties {#Properties}

- The [coproduct](wikipedia://en/310889) of two projective objects is projective.[^o11]
- A [retract](wikipedia://en/10630303) of a projective object is projective.[^o12]

:::

::: {#o14 .example cue=heading name="Examples"}

## Examples {#Examples}

The statement that all sets are projective is equivalent to the [axiom of choice](wikipedia://en/840).

The projective objects in the category of abelian groups are the [free abelian groups](wikipedia://en/247296).

Let $R$ be a [ring](wikipedia://en/48404) with identity. Consider the (abelian) category $R$-**Mod** of left $R$-modules. The projective objects in $R$-**Mod** are precisely the [projective left R-modules](wikipedia://en/364488). Consequently, $R$ is itself a projective object in $R$-**Mod**. Dually, the injective objects in $R$-**Mod** are exactly the [injective left R-modules](wikipedia://en/473775).

The category of left (right) $R$-modules also has enough projectives. This is true since, for every left (right) $R$-module $M$, we can take $F$ to be the free (and hence projective) $R$-module generated by a generating set $X$ for $M$ (for example we can take $X$ to be $M$). Then the [canonical projection](https://en.wikipedia.org/wiki/Canonical_projection) $\pi\colon F\to M$ is the required [surjection](https://en.wikipedia.org/wiki/Surjection).

The projective objects in the category of [compact Hausdorff spaces](https://en.wikipedia.org/wiki/Compact_Hausdorff_space) are precisely the [extremally disconnected spaces](wikipedia://en/5783949). This result is due to (Gleason 1958), with a simplified proof given by (Rainwater 1959).

In the category of [Banach spaces](https://en.wikipedia.org/wiki/Banach_spaces) and contractions (i.e., functionals whose norm is at most 1), the epimorphisms are precisely the maps with dense [image](wikipedia://en/579311). (Wiweger 1969) shows that the [zero space](wikipedia://en/1463006#Trivial_or_zero_vector_space) is the only projective object in this category. There are non-trivial spaces, though, which are projective with respect to the class of surjective contractions. In the category of [normed vector spaces](wikipedia://en/21538) with contractions (and surjective maps as "surjections"), the projective objects are precisely the $l^1$-spaces.[^o18]

$$l^1(S) = \{(x_s)_{s \in S}, \sum_{s \in S} ||x_s|| < \infty \}.$$
