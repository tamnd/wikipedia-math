# Torsion-free module

::: {#o1 .subject cue=lead name="Torsion-free module"}

In [algebra](wikipedia://en/19616384), a **torsion-free module** is a [module](wikipedia://en/276410) over a [ring](wikipedia://en/48404) such that zero is the only element [annihilated](wikipedia://en/14206224) by a [regular element](https://en.wikipedia.org/wiki/Zero-divisor) (non [zero-divisor](https://en.wikipedia.org/wiki/Zero-divisor)) of the ring. In other words, a module is *torsion free* if its [torsion submodule](https://en.wikipedia.org/wiki/Torsion_submodule) contains only the zero element.

:::

In [integral domains](wikipedia://en/15462) the regular elements of the ring are its nonzero elements, so in this case a torsion-free module is one such that zero is the only element annihilated by some non-zero element of the ring. Some authors work only over integral domains and use this condition as the definition of a torsion-free module, but this does not work well over more general rings, for if the ring contains zero-divisors then the only module satisfying this condition is the [zero module](wikipedia://en/3476379#Zero_module).

## Examples of torsion-free modules {#Examples_of_torsion-free_modules}

Over a [commutative ring](wikipedia://en/61346) *R* with [total quotient ring](https://en.wikipedia.org/wiki/Total_quotient_ring) *K*, a module *M* is torsion-free if and only if [Tor](wikipedia://en/856347)<sub>1</sub>(*K*/*R*,*M*) vanishes. Therefore [flat modules](wikipedia://en/492616), and in particular [free](wikipedia://en/326454) and [projective modules](wikipedia://en/364488), are torsion-free, but the converse need not be true. An example of a torsion-free module that is not flat is the [ideal](wikipedia://en/25977) (*x*, *y*) of the [polynomial ring](wikipedia://en/373065) *k*\[*x*, *y*\] over a [field](wikipedia://en/10603) *k*, interpreted as a module over *k*\[*x*, *y*\].

Any [torsionless module](wikipedia://en/27481586) over a [domain](wikipedia://en/15462) is a torsion-free module, but the converse is not true, as **Q** is a torsion-free **Z**-module that is *not* torsionless.

## Structure of torsion-free modules {#Structure_of_torsion-free_modules}

Over a [Noetherian](wikipedia://en/56129) integral domain, torsion-free modules are the modules whose only [associated prime](wikipedia://en/17286442) is zero. More generally, over a Noetherian commutative ring the torsion-free modules are those modules all of whose associated primes are contained in the associated primes of the ring.

Over a Noetherian [integrally closed domain](wikipedia://en/21420209), any finitely-generated torsion-free module has a free submodule such that the [quotient](wikipedia://en/364820) by it is [isomorphic](wikipedia://en/14828) to an ideal of the ring.

Over a [Dedekind domain](wikipedia://en/145132), a finitely-generated module is torsion-free if and only if it is projective, but is in general not free. Any such module is isomorphic to the sum of a finitely-generated free module and an ideal, and the class of the ideal is uniquely determined by the module.

Over a [principal ideal domain](wikipedia://en/25039), finitely-generated modules are torsion-free if and only if they are free.

## Torsion-free covers {#Torsion-free_covers}

Over an integral domain, every module *M* has a torsion-free cover *F* → *M* from a torsion-free module *F* onto *M*, with the properties that any other torsion-free module mapping onto *M* factors through *F*, and any [endomorphism](wikipedia://en/9569) of *F* over *M* is an [automorphism](wikipedia://en/1160) of *F*. Such a torsion-free cover of *M* is unique up to isomorphism. Torsion-free covers are closely related to [flat covers](wikipedia://en/34846642).

## Torsion-free quasicoherent sheaves {#Torsion-free_quasicoherent_sheaves}

A [quasicoherent sheaf](https://en.wikipedia.org/wiki/Quasicoherent_sheaf) *F* over a [scheme](wikipedia://en/364754) *X* is a [sheaf](wikipedia://en/245466) of $\mathcal{O}_X$-modules such that for any open [affine subscheme](https://en.wikipedia.org/wiki/Affine_scheme) *U* = Spec(*R*) the [restriction](wikipedia://en/1589032) *F*|<sub>U</sub> is [associated](https://en.wikipedia.org/wiki/Sheaf_associated_to_a_module) to some module *M* over *R*. The sheaf *F* is said to be **torsion-free** if all those modules *M* are torsion-free over their respective rings. Alternatively, *F* is torsion-free if and only if it has no local torsion sections.[^o7]

:::
