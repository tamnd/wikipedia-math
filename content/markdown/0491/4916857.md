# Binomial regression

::: {#o1 .subject cue=lead name="Binomial regression"}

In [statistics](wikipedia://en/26685), **binomial regression** is a [regression analysis](wikipedia://en/826997) technique in which the [response](https://en.wikipedia.org/wiki/Dependent_variable) (often referred to as *Y*) has a [binomial distribution](wikipedia://en/3876): it is the number of successes in a series of $n$ independent [Bernoulli trials](wikipedia://en/102653), where each trial has probability of success $p$.[^o6] In binomial regression, the probability of a success is related to [explanatory variables](https://en.wikipedia.org/wiki/Explanatory_variable): the corresponding concept in ordinary regression is to relate the mean value of the unobserved response to explanatory variables.

:::

Binomial regression is closely related to [binary regression](wikipedia://en/60567021): a binary regression can be considered a binomial regression with $n = 1$, or a regression on [ungrouped](https://en.wikipedia.org/wiki/Ungrouped_data) binary data, while a binomial regression can be considered a regression on [grouped](wikipedia://en/27705422) binary data (see comparison).[^n1] Binomial regression models are essentially the same as [binary choice models](https://en.wikipedia.org/wiki/Binary_choice_model), one type of [discrete choice](wikipedia://en/4902101) model: the primary difference is in the theoretical motivation (see comparison). In [machine learning](wikipedia://en/233488), binomial regression is considered a special case of [probabilistic classification](wikipedia://en/42378348), and thus a generalization of [binary classification](wikipedia://en/205393).

## Example application {#Example_application}

In one published example of an application of binomial regression,[^o4] the details were as follows. The observed outcome variable was whether or not a fault occurred in an industrial process. There were two explanatory variables: the first was a simple two-case factor representing whether or not a modified version of the process was used and the second was an ordinary quantitative variable measuring the purity of the material being supplied for the process.

## Specification of model {#Specification_of_model}

The response variable *Y* is assumed to be [binomially distributed](wikipedia://en/3876) conditional on the explanatory variables *X*. The number of trials *n* is known, and the probability of success for each trial *p* is specified as a function *θ(X)*. This implies that the [conditional expectation](wikipedia://en/435099) and [conditional variance](wikipedia://en/11391180) of the observed fraction of successes, *Y/n*, are

$$E(Y/n \mid X) = \theta(X)$$

$$\operatorname{Var}(Y/n \mid X) = \theta(X) (1 - \theta(X)) / n$$

The goal of binomial regression is to estimate the function *θ(X)*. Typically the statistician assumes $\theta(X) = m(\beta^\mathrm T X)$, for a known function *m*, and estimates *β*. Common choices for *m* include the [logistic function](wikipedia://en/84563).[^o6]

The data are often fitted as a [generalised linear model](https://en.wikipedia.org/wiki/Generalised_linear_model) where the predicted values μ are the probabilities that any individual event will result in a success. The [likelihood](https://en.wikipedia.org/wiki/Likelihood) of the predictions is then given by

$$L(\boldsymbol{\mu}\mid Y)=\prod_{i=1}^n \left ( 1_{y_i=1}(\mu_i) + 1_{y_i=0} (1-\mu_i) \right ), \,\!$$

where *1<sub>A</sub>* is the [indicator function](wikipedia://en/240790) which takes on the value one when the event *A* occurs, and zero otherwise: in this formulation, for any given observation *y<sub>i</sub>*, only one of the two terms inside the product contributes, according to whether *y<sub>i</sub>*=0 or 1. The likelihood function is more fully specified by defining the formal parameters *μ<sub>i</sub>* as parameterised functions of the explanatory variables: this defines the likelihood in terms of a much reduced number of parameters. Fitting of the model is usually achieved by employing the method of [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) to determine these parameters. In practice, the use of a formulation as a generalised linear model allows advantage to be taken of certain algorithmic ideas which are applicable across the whole class of more general models but which do not apply to all maximum likelihood problems.

Models used in binomial regression can often be extended to multinomial data.

There are many methods of generating the values of *μ* in systematic ways that allow for interpretation of the model; they are discussed below.

## Link functions {#Link_functions}

There is a requirement that the modelling linking the probabilities μ to the explanatory variables should be of a form which only produces values in the range 0 to 1. Many models can be fitted into the form

$$\boldsymbol{\mu} = g(\boldsymbol{\eta}) \, .$$

Here *η* is an intermediate variable representing a linear combination, containing the regression parameters, of the explanatory variables. The function *g* is the [cumulative distribution function](wikipedia://en/5793) (cdf) of some [probability distribution](wikipedia://en/23543). Usually this probability distribution has a [support](wikipedia://en/381013) from minus infinity to plus infinity so that any finite value of *η* is transformed by the function *g* to a value inside the range 0 to 1.

In the case of [logistic regression](wikipedia://en/226631), the link function is the log of the [odds ratio](wikipedia://en/406880) or [logistic function](wikipedia://en/84563). In the case of [probit](wikipedia://en/1611247), the link is the cdf of the [normal distribution](wikipedia://en/21462). The [linear probability model](wikipedia://en/1611124) is not a proper binomial regression specification because predictions need not be in the range of zero to one; it is sometimes used for this type of data when the probability space is where interpretation occurs or when the analyst lacks sufficient sophistication to fit or calculate approximate linearizations of probabilities for interpretation.

## Comparison with binary regression {#Comparison_with_binary_regression}

Binomial regression is closely connected with binary regression. If the response is a [binary variable](https://en.wikipedia.org/wiki/Binary_variable) (two possible outcomes), then these alternatives can be coded as 0 or 1 by considering one of the outcomes as "success" and the other as "failure" and considering these as [count data](wikipedia://en/15690807): "success" is 1 success out of 1 trial, while "failure" is 0 successes out of 1 trial. This can now be considered a binomial distribution with $n = 1$ trial, so a binary regression is a special case of a binomial regression. If these data are [grouped](wikipedia://en/27705422) (by adding counts), they are no longer binary data, but are count data for each group, and can still be modeled by a binomial regression; the individual binary outcomes are then referred to as "ungrouped data". An advantage of working with grouped data is that one can test the goodness of fit of the model;[^n1] for example, grouped data may exhibit [overdispersion](wikipedia://en/4190350) relative to the variance estimated from the ungrouped data.

## Comparison with binary choice models {#Comparison_with_binary_choice_models}

A binary choice model assumes a [latent variable](https://en.wikipedia.org/wiki/Latent_variable) *U<sub>n</sub>*, the utility (or net benefit) that person *n* obtains from taking an action (as opposed to not taking the action). The utility the person obtains from taking the action depends on the characteristics of the person, some of which are observed by the researcher and some are not:

$$U_n = \boldsymbol\beta \cdot \mathbf{s_n} + \varepsilon_n$$

where $\boldsymbol\beta$ is a set of [regression coefficients](https://en.wikipedia.org/wiki/Regression_coefficient) and $\mathbf{s_n}$ is a set of [independent variables](https://en.wikipedia.org/wiki/Independent_variable) (also known as "features") describing person *n*, which may be either discrete "[dummy variables](wikipedia://en/285156)" or regular continuous variables. $\varepsilon_n$ is a [random variable](wikipedia://en/25685) specifying "noise" or "error" in the prediction, assumed to be distributed according to some distribution. Normally, if there is a mean or variance parameter in the distribution, it cannot be [identified](wikipedia://en/22884398), so the parameters are set to convenient values — by convention usually mean 0, variance 1.

The person takes the action, *y<sub>n</sub>* = 1, if *U<sub>n</sub>* > 0. The unobserved term, *ε<sub>n</sub>*, is assumed to have a [logistic distribution](wikipedia://en/542666).

The specification is written succinctly as:

- *U<sub>n</sub>* = *βs<sub>n</sub>* + *ε<sub>n</sub>*
- $$Y_n = \begin{cases} 1, & \text{if } U_n > 0, \\ 0, & \text{if } U_n \le 0 \end{cases}$$
- *ε* ∼ [logistic](wikipedia://en/542666), standard [normal](wikipedia://en/21462), etc.

Let us write it slightly differently:

- *U<sub>n</sub>* = *βs<sub>n</sub>* − *e<sub>n</sub>*
- $$Y_n = \begin{cases} 1, & \text{if } U_n > 0, \\ 0, & \text{if } U_n \le 0 \end{cases}$$
- *e* ∼ [logistic](wikipedia://en/542666), standard [normal](wikipedia://en/21462), etc.

Here we have made the substitution *e<sub>n</sub>* = −*ε<sub>n</sub>*. This changes a random variable into a slightly different one, defined over a negated domain. As it happens, the error distributions we usually consider (e.g. [logistic distribution](wikipedia://en/542666), standard [normal distribution](wikipedia://en/21462), standard [Student's t-distribution](wikipedia://en/105375), etc.) are symmetric about 0, and hence the distribution over *e<sub>n</sub>* is identical to the distribution over *ε<sub>n</sub>*.

Denote the [cumulative distribution function](wikipedia://en/5793) (CDF) of $e$ as $F_e,$ and the [quantile function](wikipedia://en/10167616) (inverse CDF) of $e$ as $F^{-1}_e .$

Note that

$$\begin{aligned} \Pr(Y_n=1) &= \Pr(U_n > 0) \\[6pt] &= \Pr(\boldsymbol\beta \cdot \mathbf{s_n} - e_n > 0) \\[6pt] &= \Pr(-e_n > -\boldsymbol\beta \cdot \mathbf{s_n}) \\[6pt] &= \Pr(e_n \le \boldsymbol\beta \cdot \mathbf{s_n}) \\[6pt] &= F_e(\boldsymbol\beta \cdot \mathbf{s_n}) \end{aligned}$$

Since $Y_n$ is a [Bernoulli trial](wikipedia://en/102653), where $\mathbb{E}[Y_n] = \Pr(Y_n = 1),$ we have

$$\mathbb{E}[Y_n] = F_e(\boldsymbol\beta \cdot \mathbf{s_n})$$

or equivalently

$$F^{-1}_e(\mathbb{E}[Y_n]) = \boldsymbol\beta \cdot \mathbf{s_n} .$$

Note that this is exactly equivalent to the binomial regression model expressed in the formalism of the [generalized linear model](wikipedia://en/747122).

If $e_n \sim \mathcal{N}(0,1),$ i.e. distributed as a [standard normal distribution](https://en.wikipedia.org/wiki/Standard_normal_distribution), then

$$\Phi^{-1}(\mathbb{E}[Y_n]) = \boldsymbol\beta \cdot \mathbf{s_n}$$

which is exactly a [probit model](wikipedia://en/1611247).

If $e_n \sim \operatorname{Logistic}(0,1),$ i.e. distributed as a standard [logistic distribution](wikipedia://en/542666) with mean 0 and [scale parameter](wikipedia://en/769503) 1, then the corresponding [quantile function](wikipedia://en/10167616) is the [logit function](https://en.wikipedia.org/wiki/Logit_function), and

$$\operatorname{logit}(\mathbb{E}[Y_n]) = \boldsymbol\beta \cdot \mathbf{s_n}$$

which is exactly a [logit model](https://en.wikipedia.org/wiki/Logit_model).

Note that the two different formalisms — [generalized linear models](wikipedia://en/747122) (GLM's) and [discrete choice](wikipedia://en/4902101) models — are equivalent in the case of simple binary choice models, but can be extended if differing ways:

- GLM's can easily handle arbitrarily distributed [response variables](https://en.wikipedia.org/wiki/Response_variable) ([dependent variables](https://en.wikipedia.org/wiki/Dependent_variable)), not just [categorical variables](wikipedia://en/821165) or [ordinal variables](https://en.wikipedia.org/wiki/Ordinal_variable), which discrete choice models are limited to by their nature. GLM's are also not limited to link functions that are [quantile functions](wikipedia://en/10167616) of some distribution, unlike the use of an [error variable](https://en.wikipedia.org/wiki/Error_variable), which must by assumption have a [probability distribution](wikipedia://en/23543).
- On the other hand, because discrete choice models are described as types of [generative models](wikipedia://en/1222578), it is conceptually easier to extend them to complicated situations with multiple, possibly correlated, choices for each person, or other variations.

## Latent variable interpretation / derivation {#Latent_variable_interpretation_/_derivation}

A [latent variable model](wikipedia://en/4237572) involving a binomial observed variable *Y* can be constructed such that *Y* is related to the latent variable *Y\** via

$$Y = \begin{cases} 0, & \mbox{if }Y^*>0 \\ 1, & \mbox{if }Y^*<0. \end{cases}$$

The latent variable *Y\** is then related to a set of regression variables *X* by the model

$$Y^* = X\beta + \epsilon \ .$$

This results in a binomial regression model.

The variance of *ϵ* can not be identified and when it is not of interest is often assumed to be equal to one. If *ϵ* is normally distributed, then a probit is the appropriate model and if *ϵ* is [log-Weibull](wikipedia://en/1494479) distributed, then a logit is appropriate. If *ϵ* is uniformly distributed, then a linear probability model is appropriate.
