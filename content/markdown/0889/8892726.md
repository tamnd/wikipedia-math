# Negative pedal curve

::: {#o1 .subject cue=lead name="Negative pedal curve"}

*Image: NegativePedal.gif.* [Circle](wikipedia://en/6220) — negative pedal curve of a [limaçon](wikipedia://en/641715)

In [geometry](wikipedia://en/18973446), a **negative pedal curve** is a [plane curve](wikipedia://en/971691) that can be constructed from another plane curve *C* and a fixed point *P*. For each point *X* ≠ *P* on the curve *C*, the negative pedal curve has a [tangent](wikipedia://en/31482) that passes through *X* and is [perpendicular](wikipedia://en/76944) to line *XP*. Constructing the negative pedal curve is the [inverse operation](https://en.wikipedia.org/wiki/Inverse_operation) to constructing a [pedal curve](wikipedia://en/845864).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

In the plane, for every point *X* other than *P* there is a unique line through *X* perpendicular to *XP*. For a given curve in the plane and a given fixed point *P*, called the **pedal point**, the **negative pedal curve** is the [envelope](wikipedia://en/880235) of the lines *XP* for which *X* lies on the given curve.[^o4]

:::

## Parameterization {#Parameterization}

For a parametrically defined curve, its negative pedal curve with pedal point (0; 0) is defined as:[^o6]

$$X[x,y]=\frac{(y^2-x^2)y'+2xyx'}{xy'-yx'}$$

$$Y[x,y]=\frac{(x^2-y^2)x'+2xyy'}{xy'-yx'}$$

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

The negative pedal curve of a [line](wikipedia://en/946975) is a parabola. The negative pedal curves of a [circle](wikipedia://en/6220) are an [ellipse](wikipedia://en/9277) if *P* is chosen to be inside the circle, and a [hyperbola](wikipedia://en/14052) if *P* is chosen to be outside the circle.[^o4] The negative pedal curve of a [parabola](wikipedia://en/23231) with respect to its focus is the [Tschirnhausen cubic](wikipedia://en/10475041).[^o9]

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The negative pedal curve of a [pedal curve](wikipedia://en/845864) with the same pedal point is the original curve.[^o12]

:::
