# Universal one-way hash function

::: {#o1 .subject cue=lead name="Universal one-way hash function"}

In [cryptography](wikipedia://en/18934432) a **universal one-way hash function** (**UOWHF**, often pronounced "woof") is a type of [universal hash function](wikipedia://en/4024666) of particular importance to [cryptography](wikipedia://en/18934432). UOWHFs are proposed as an alternative to [collision-resistant hash functions](wikipedia://en/439526) (CRHFs). CRHFs have a strong collision-resistance property: that it is hard, given randomly chosen hash function parameters, to find any collision of the hash function. In contrast, UOWHFs require that it be hard to find a collision where one [preimage](https://en.wikipedia.org/wiki/Preimage) is chosen independently of the hash function parameters. The primitive was suggested by [Moni Naor](https://en.wikipedia.org/wiki/Moni_Naor) and [Moti Yung](https://en.wikipedia.org/wiki/Moti_Yung) and is also known as "target collision resistant" hash functions; it was employed to construct general digital signature schemes without trapdoor functions, and also within chosen-ciphertext secure public key encryption schemes.

:::

The UOWHF family contains a finite number of hash functions with each having the same probability of being used.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The security property of a UOWHF is as follows. Let $A$ be an algorithm that operates in two phases:

- Initially, $A$ receives no input (or just a security parameter) and chooses a value $x$.
- A hash function $H$ is chosen randomly from the family. $A$ then receives $H$ and must output $y \ne x$ such that $H(x) = H(y)$.

Then for all polynomial-time $A$ the probability that $A$ succeeds is negligible.

:::

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

UOWHFs are thought to be less computationally expensive than CRHFs, and are most often used for efficiency purposes in schemes where the choice of the hash function happens at some stage of execution, rather than beforehand. For instance, the [Cramer–Shoup cryptosystem](wikipedia://en/1564406) uses a UOWHF as part of the validity check in its ciphertexts.

:::
