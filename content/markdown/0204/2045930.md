# Chaff algorithm

::: {#o1 .subject cue=lead name="Chaff algorithm"}

**Chaff** is an [algorithm](wikipedia://en/775) for solving instances of the [Boolean satisfiability problem](wikipedia://en/4715) in programming. It was designed by researchers at [Princeton University](https://en.wikipedia.org/wiki/Princeton_University). The algorithm is an instance of the [DPLL algorithm](wikipedia://en/2745094) with a number of enhancements for efficient implementation.

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Implementations"}

## Implementations {#Implementations}

Some available implementations of the algorithm in software are `mChaff` and **`zChaff`**, the latter one being the most widely known and used. zChaff was originally written by Dr. Lintao Zhang, hence the “z”. It is now maintained by researchers at [Princeton University](https://en.wikipedia.org/wiki/Princeton_University) and available for [download](https://en.wikipedia.org/wiki/Download) as both source code and binaries on [Linux](https://en.wikipedia.org/wiki/Linux). zChaff is free for non-commercial use.

:::
