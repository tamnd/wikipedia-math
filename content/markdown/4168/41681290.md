# Datafly algorithm

::: {#o1 .subject cue=lead name="Datafly algorithm"}

**Datafly algorithm** is an [algorithm](wikipedia://en/775) for providing anonymity in medical data. The algorithm was developed by [Latanya Arvette Sweeney](https://en.wikipedia.org/wiki/Latanya_Arvette_Sweeney) in 1997−98.[^o2][^o3] Anonymization is achieved by automatically generalizing, substituting, inserting, and removing information as appropriate without losing many of the details found within the data. The method can be used on-the-fly in [role-based](https://en.wikipedia.org/wiki/Role-based_access_control) security within an institution, and in [batch](https://en.wikipedia.org/wiki/Batch_processing) mode for [exporting data](https://en.wikipedia.org/wiki/Import_and_export_of_data) from an institution. Organizations release and receive medical data with all explicit [identifiers](https://en.wikipedia.org/wiki/Identifier)—such as name—removed, in the erroneous belief that [patient confidentiality](https://en.wikipedia.org/wiki/Physician–patient_privilege) is maintained because the resulting data look anonymous. However the remaining data can be used to re-identify individuals by linking or matching the data to other databases or by looking at unique characteristics found in the [fields](https://en.wikipedia.org/wiki/Field_%28computer_science%29) and [records](https://en.wikipedia.org/wiki/Row_%28database%29) of the [database](https://en.wikipedia.org/wiki/Database) itself.

:::

The Datafly algorithm has been criticized for trying to achieve anonymization by overgeneralization. The algorithm selects the [attribute](https://en.wikipedia.org/wiki/Attribute_%28computing%29) with the greatest number of distinct [values](https://en.wikipedia.org/wiki/Value_%28computer_science%29) as the one to generalize first.[^o4]

## Core algorithm {#Core_algorithm}

An outline of the Datafly algorithm is presented below.[^o6]

**[Input](https://en.wikipedia.org/wiki/Input_%28computer_science%29)**: Private [Table](https://en.wikipedia.org/wiki/Table_%28database%29) PT; [quasi-identifier](wikipedia://en/40659495) QI = ( *A*<sub>1</sub>, ..., *A*<sub>n</sub> ), *k*-anonymity constraint *k*; domain generalization hierarchies DGH<sub>A<sub>i</sub></sub>, where *i* = 1,...,*n* with accompanying [functions](wikipedia://en/185427) *f*<sub>A<sub>i</sub></sub>, and loss, which is a limit on the percentage of [tuples](wikipedia://en/132729) that can be suppressed. PT\[id\] is the set of unique identifiers or keys for each tuple.

**[Output](https://en.wikipedia.org/wiki/Output_%28computing%29)**: MGT a generalization of PT\[QI\] that enforces *k*-anonymity

**Assumes**: | PT | ≤ *k*, and loss \* | PT | = *k*

**algorithm Datafly**:

// Construct a frequency [list](https://en.wikipedia.org/wiki/List_%28abstract_data_type%29) containing unique [sequences](wikipedia://en/27838) of values across the quasi-identifier in PT,

// along with the number of occurrences of each sequence.

\1. let freq be an expandable and collapsible [vector](wikipedia://en/23218956) with no elements initially. Each element is of the form ( QI, frequency, SID ), where SID = { *id<sub>i</sub>* : ∃ *t*\[*id*\] ∈ \[*id*\] ⇒ *t*\[*id*\] = *id*<sub>i</sub> }; and, frequency = |SID|. Therefore, freq is also accessible as a table over (QI, frequency, SID).

\2. let pos $\gets$ 0, total $\gets$ 0

\3. while total ≠ |PT| do

\3.1 freq\[pos\] $\gets$ ( *t*\[QI\], occurs, SID ) where *t*\[QI\] ∈ \[QI\], ( *t*\[ QI \],\_\_, \_\_\_ ) $\not\in$ freq; occurs = |PT| - |PT\[QI\] – {*t*\[QI\]}|; and, SID = { *id*<sub>i</sub> : ∃ *t*\[*id*\] $\gets$ PT\[id\] ⇒ *t*\[*id*\] = *id*<sub>i</sub> }

\3.2 pos $\gets$ pos + 1, total $\gets$ total + occurs

// Make a solution by generalizing the attribute with the most number of distinct values

// and suppressing no more than the allowed number of tuples.

\4. let belowk $\gets$ 0

\5. for pos $\gets$ 1 to |freq| do

\5.1 ( \_\_, count ) $\gets$ freq\[pos\]

\5.2 if count \< *k* then do

\5.2.1 belowk $\gets$ belowk + count

\6. if belowk > *k* then do: // Note. loss \* |PT| = *k*.

\6.1 freq $\gets$ generalize(freq)

\6.2 go to step 4

\7. else do

// assert: the number of tuples to suppress in freq is ≤ loss \* |PT|

\7.1 freq $\gets$ suppress(freq, belowk )

\7.2 MGT $\gets$ reconstruct(freq)

\8. return MGT.
