# Spherical code

::: {#o1 .subject cue=lead name="Spherical code"}

In [geometry](wikipedia://en/18973446) and [coding theory](wikipedia://en/321869), a **spherical code** with parameters (*n*,*N*,*t*) is a set of *N* points on the unit [hypersphere](https://en.wikipedia.org/wiki/Hypersphere) in *n* dimensions for which the [dot product](wikipedia://en/157093) of unit vectors from the origin to any two points is less than or equal to *t*. The [kissing number problem](https://en.wikipedia.org/wiki/Kissing_number_problem) may be stated as the problem of finding the maximal *N* for a given *n* for which a spherical code with parameters (*n*,*N*,1/2) exists. The [Tammes problem](wikipedia://en/19332734) may be stated as the problem of finding a spherical code with minimal *t* for given *n* and *N*.

:::
