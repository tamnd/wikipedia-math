# PA degree

::: {#o1 .subject cue=lead name="PA degree"}

In the mathematical field of [computability theory](wikipedia://en/155414), a **PA degree** is a [Turing degree](wikipedia://en/764405) that computes a complete extension of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic) (Jockusch 1987). These degrees are closely related to fixed-point-free (DNR) functions, and have been thoroughly investigated in recursion theory.

:::

## Background {#Background}

In recursion theory, $\phi_e$ denotes the [computable function](wikipedia://en/1139338) with index (program) *e* in some standard numbering of computable functions, and $\phi^B_e$ denotes the *e*th computable function using a set *B* of natural numbers as an oracle.

A set *A* of natural numbers is [Turing reducible](https://en.wikipedia.org/wiki/Turing_reducibility) to a set *B* if there is a [computable function](wikipedia://en/1139338) that, given an oracle for set *B*, computes the [characteristic function](wikipedia://en/240790) χ<sub>A</sub> of the set *A*. That is, there is an *e* such that $\chi_A = \phi^B_e$. This relationship is denoted *A* ≤<sub>T</sub> *B*; the relation ≤<sub>T</sub> is a [preorder](wikipedia://en/23582).

Two sets of natural numbers are [Turing equivalent](wikipedia://en/764405) if each is Turing reducible to the other. The notation *A* ≡<sub>T</sub> *B* indicates *A* and *B* are Turing equivalent. The relation ≡<sub>T</sub> is an [equivalence relation](wikipedia://en/9259) known as Turing equivalence. A [Turing degree](wikipedia://en/764405) is a collection of sets of natural numbers, such that any two sets in the collection are Turing equivalent. Equivalently, a Turing degree is an equivalence class of the relation ≡<sub>T</sub>.

The Turing degrees are [partially ordered](https://en.wikipedia.org/wiki/Partial_order) by Turing reducibility. The notation **a** ≤<sub>T</sub> **b** indicates there is a set in degree **b** that computes a set in degree **a**. Equivalently, **a** ≤<sub>T</sub> **b** holds if and only if every set in **b** computes every set in **a**.

A function *f* from the natural numbers to the natural numbers is said to be **diagonally nonrecursive (DNR)** if, for all *n*, $f(n) \not = \phi_n(n)$ (here inequality holds by definition if $\phi_n(n)$ is undefined). If the range of *f* is the set {0,1} then *f* is a DNR<sub>2</sub> function. It is known that there are DNR functions that do not compute any DNR<sub>2</sub> function.

## Completions of Peano arithmetic {#Completions_of_Peano_arithmetic}

A completion of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic) is a set of formulas in the language of Peano arithmetic, such that the set is consistent in [first-order logic](wikipedia://en/10983) and such that, for each formula, either that formula or its negation is included in the set. Once a Gödel numbering of the formulas in the language of PA has been fixed, it is possible to identify completions of PA with sets of natural numbers, and thus to speak about the computability of these completions.

A Turing degree is defined to be a **PA degree** if there is a set of natural numbers in the degree that computes a completion of Peano Arithmetic. (This is equivalent to the proposition that every set in the degree computes a completion of PA.) Because there are no computable completions of PA, the degree **0** consisting of the computable sets of natural numbers is not a PA degree.

Because PA is an effective first-order theory, the completions of PA can be characterized as the infinite paths through a particular computable subtree of 2<sup>\<ω</sup>. Thus the PA degrees are exactly the degrees that compute an infinite path through this tree.

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The PA degrees are upward closed in the Turing degrees: if **a** is a PA degree and **a** ≤<sub>T</sub> **b** then **b** is a PA degree.

The Turing degree **0**‘, which is the degree of the [halting problem](wikipedia://en/21391870), is a PA degree. There are also PA degrees that are not above **0**‘. For example, the [low basis theorem](wikipedia://en/9767227) implies that there is a low PA degree. On the other hand, Antonín Kučera has proved that there is a degree less than **0**‘ that computes a DNR function but is not a PA degree (Jockusch 1989:197).

[Carl Jockusch](wikipedia://en/9859617) and [Robert Soare](https://en.wikipedia.org/wiki/Robert_Soare) (1972) proved that the PA degrees are exactly the degrees of DNR<sub>2</sub> functions.

By definition, a degree is PA if and only if it computes a path through the tree of completions of Peano arithmetic. A stronger property holds: a degree **a** is a PA degree if and only if **a** computes a path through *every* infinite computable subtree of 2<sup>\<ω</sup> (Simpson 1977).

:::

::: {#o7 .statement cue=named-heading name="Arslanov's completeness criterion"}

## Arslanov's completeness criterion {#Arslanov's_completeness_criterion}

M. M. Arslanov gave a characterisation of which c.e. sets are complete (i.e. Turing equivalent to $\varnothing'$). For a c.e. set $A \subseteq \mathbb{N}$, $A \equiv_\mathrm{T} \varnothing'$ if and only if $A$ computes a DNR function. In particular, every PA degree is DNR<sub>2</sub> and hence DNR, so $\varnothing'$ is the only c.e. PA degree.

:::
