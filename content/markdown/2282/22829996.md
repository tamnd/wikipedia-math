# Extremal orders of an arithmetic function

::: {#o1 .subject cue=lead name="Extremal orders of an arithmetic function"}

The **extremal orders of an arithmetic function** in [number theory](wikipedia://en/21527), a branch of [mathematics](wikipedia://en/18831), are the best possible bounds of the given [arithmetic function](wikipedia://en/3170). Specifically, if *f*(*n*) is an arithmetic function and *m*(*n*) is a non-decreasing [function](wikipedia://en/185427) that is ultimately positive and

:::

$$\liminf_{n \to \infty} \frac{f(n)}{m(n)} = 1$$

we say that *m* is a **minimal order** for *f*. Similarly if *M*(*n*) is a non-decreasing function that is ultimately positive and

$$\limsup_{n \to \infty} \frac{f(n)}{M(n)} = 1$$

we say that *M* is a **maximal order** for *f*.[^o2] Here, $\liminf_{n \to \infty}$ and $\limsup_{n \to \infty}$ denote the [limit inferior and limit superior](https://en.wikipedia.org/wiki/Limit_superior_and_limit_inferior), respectively.

The subject was first studied systematically by [Ramanujan](wikipedia://en/47717) starting in 1915.[^o2]

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- For the [sum-of-divisors function](https://en.wikipedia.org/wiki/Sum-of-divisors_function) σ(*n*) we have the trivial result $$\liminf_{n \to \infty} \frac{\sigma(n)}{n} = 1$$ because always σ(*n*) ≥ *n* and for [primes](wikipedia://en/23666) σ(*p*) = *p* + 1. We also have $$\limsup_{n \to \infty} \frac{\sigma(n)}{n \ln \ln n} = e^\gamma,$$ proved by [Gronwall](wikipedia://en/3849173) in 1913.[^o2][^o5][^o6] Therefore *n* is a minimal order and $e^{-\gamma} n \ln\,\ln\,n$ is a maximal order for σ(*n*).
- For the [Euler totient](https://en.wikipedia.org/wiki/Euler_totient) φ(*n*) we have the trivial result $$\limsup_{n \to \infty} \frac{\phi(n)}{n} = 1$$ because always φ(*n*) ≤ *n* and for primes φ(*p*) = *p* − 1. We also have $$\liminf_{n \to \infty} \frac{\phi(n) \ln \ln n}{n} = e^{-\gamma},$$ proven by [Landau](wikipedia://en/222230) in 1903.[^o2][^o5]
- For the [number of divisors](https://en.wikipedia.org/wiki/Number_of_divisors) function *d*(*n*) we have the trivial lower bound 2 ≤ *d*(*n*), in which equality occurs when *n* is prime, so 2 is a minimal order. For ln *d*(*n*) we have a maximal order $\ln\,2 \ln\,n / \ln\,\ln\,n$, proved by Wigert in 1907.[^o2][^o5]
- For the number of distinct [prime factors](https://en.wikipedia.org/wiki/Prime_factors) ω(*n*) we have a trivial lower bound 1 ≤ ω(*n*), in which equality occurs when *n* is a [prime power](wikipedia://en/1630483). A maximal order for ω(*n*) is $\ln n / \ln\,\ln\,n$.[^o2]
- For the number of prime factors counted with multiplicity Ω(*n*) we have a trivial lower bound 1 ≤ Ω(*n*), in which equality occurs when *n* is prime. A maximal order for Ω(*n*) is $\ln\,n / \ln\,2$[^o2]
- It is [conjectured](wikipedia://en/6138) that the [Mertens function](wikipedia://en/435639), or summatory function of the [Möbius function](wikipedia://en/20961), satisfies $\limsup_{n \to \infty} \frac{|M(x)|}{\sqrt{x}} = +\infty,$ though to date this limit superior has only been shown to be larger than a small constant. This statement is compared with the disproof of [Mertens conjecture](wikipedia://en/379847) given by Odlyzko and te Riele in their several decades old breakthrough paper *Disproof of the Mertens Conjecture*. In contrast, we note that while extensive computational evidence suggests that the above conjecture is true, i.e., along some increasing sequence of $\{x_n\}_{n \geq 1}$ tending to infinity the average order of $\sqrt{x_n} |M(x_n)|$ grows unbounded, that the [Riemann hypothesis](wikipedia://en/19344125) is equivalent to the limit $\lim_{x \to \infty} M(x) / x^{\frac{1}{2} + \varepsilon} = 0$ being true for all (sufficiently small) $\varepsilon > 0$.
