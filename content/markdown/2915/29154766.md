# Regenerative process

::: {#o1 .subject cue=lead name="Regenerative process"}

*Image: Warehouse md17.jpg.* Regenerative processes have been used to model problems in inventory control. The inventory in a warehouse such as this one decreases via a stochastic process due to sales until it gets replenished by a new order.[^o2]

In [applied probability](wikipedia://en/366719), a **regenerative process** is a class of [stochastic process](wikipedia://en/47895) with the property that certain portions of the process can be treated as being [statistically independent](https://en.wikipedia.org/wiki/Statistically_independent) of each other.[^o3] This property can be used in the derivation of theoretical properties of such processes.

:::

## History {#History}

Regenerative processes were first defined by [Walter L. Smith](wikipedia://en/14537040) in [Proceedings of the Royal Society A](https://en.wikipedia.org/wiki/Proceedings_of_the_Royal_Society_A) in 1955.[^o5][^o6]

::: {#o8 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **regenerative process** is a [stochastic process](wikipedia://en/47895) with time points at which, from a probabilistic point of view, the process restarts itself.[^o9] These time point may themselves be determined by the evolution of the process. That is to say, the process {*X*(*t*), *t* ≥ 0} is a regenerative process if there exist time points 0 ≤ *T*<sub>0</sub> \< *T*<sub>1</sub> \< *T*<sub>2</sub> \< ... such that the post-*T<sub>k</sub>* process {*X*(*T<sub>k</sub>* + *t*) : *t* ≥ 0}

- has the same distribution as the post-*T*<sub>0</sub> process {*X*(*T*<sub>0</sub> + *t*) : *t* ≥ 0}
- is independent of the pre-*T<sub>k</sub>* process {*X*(*t*) : 0 ≤ *t* \< *T<sub>k</sub>*}

for *k* ≥ 1.[^o10] Intuitively this means a regenerative process can be split into [i.i.d.](https://en.wikipedia.org/wiki/Independent_and_identically_distributed) cycles.[^o11]

When *T*<sub>0</sub> = 0, *X*(*t*) is called a **nondelayed regenerative process**. Else, the process is called a **delayed regenerative process**.[^o10]

:::

::: {#o13 .example cue=heading name="Examples"}

## Examples {#Examples}

- [Renewal processes](https://en.wikipedia.org/wiki/Renewal_process) are regenerative processes, with *T*<sub>1</sub> being the first renewal.[^o9]
- Alternating [renewal processes](https://en.wikipedia.org/wiki/Renewal_process), where a system alternates between an 'on' state and an 'off' state.[^o9]
- A recurrent [Markov chain](wikipedia://en/60876) is a regenerative process, with *T*<sub>1</sub> being the time of first recurrence.[^o9] This includes [Harris chains](wikipedia://en/19485126).
- [Reflected Brownian motion](wikipedia://en/35046943) is a regenerative process (where one measures the time it takes particles to leave and come back).[^o11]

:::

::: {#o15 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- By the [renewal reward theorem](https://en.wikipedia.org/wiki/Renewal_reward_theorem), with probability 1,[^o16]

$$\lim_{t \to \infty} \frac{1}{t}\int_0^t X(s) ds= \frac{\mathbb{E}[R]}{\mathbb{E}[\tau]}.$$

where $\tau$ is the length of the first cycle and $R=\int_0^\tau X(s) ds$ is the value over the first cycle.

- A [measurable function](wikipedia://en/44055) of a regenerative process is a regenerative process with the same regeneration time[^o16]

:::
