# Optimal apportionment

::: {#o1 .subject cue=lead name="Optimal apportionment"}

**Optimal apportionment** is an approach to [apportionment](wikipedia://en/68407499) that is based on [mathematical optimization](wikipedia://en/52033).

:::

In a problem of apportionment, there is a *resource* to allocate, denoted by $h$. For example, it can be an integer representing the number of seats in a *h*ouse of representatives. The resource should be allocated between some $n$ *agents*. For example, these can be [federal states](https://en.wikipedia.org/wiki/Federal_states) or [political parties](https://en.wikipedia.org/wiki/Political_party). The agents have different *entitlements*, denoted by a vector of fractions $t_1,\ldots,t_n$ with a sum of 1. For example, *t<sub>i</sub>* can be the fraction of votes won by party *i*. The goal is to find an *allocation* - a vector $a_1,\ldots,a_n$ with $\sum_{i=1}^n a_i = h$.

The ideal share for agent *i* is his/her *quota*, defined as $q_i := t_i\cdot h$. If it is possible to give each agent his/her quota, then the allocation is maximally fair. However, exact fairness is usually unattainable, since the quotas are not integers and the allocations must be integers. There are various approaches to cope with this difficulty (see [mathematics of apportionment](wikipedia://en/68407499)). The optimization-based approach aims to attain, for eacn instance, an allocation that is "as fair as possible" for this instance. An allocation is "fair" if $a_i = q_i$ for all agents *i*, that is, each agent's allocation is exactly proportional to his/her entitlement. in this case, we say that the "unfairness" of the allocation is 0. If this equality must be violated, one can define a measure of "total unfairness", and try to minimize it.

## Minimizing the sum of unfairness levels {#Minimizing_the_sum_of_unfairness_levels}

The most natural measure is the *sum* of unfairness levels for individual agents, as in the [utilitarian rule](https://en.wikipedia.org/wiki/Utilitarian_rule):[^o6]

- One can minimize the sum of differences $\sum_{i=1}^n |a_i - q_i|$, or the sum of squares $\sum_{i=1}^n (a_i - q_i)^2$, which weight every state (or party) equally. Both minimization problems are solved by [Hamilton's method](https://en.wikipedia.org/wiki/Hamilton's_method).
- One can weight the elements in the sum by the population, or equivalently by the quota, and try to minimize the [chi-squared statistic](wikipedia://en/20351457) $\sum_{i=1}^n q_i (a_i/q_i - 1)^2$. This leads to [Webster's method](https://en.wikipedia.org/wiki/Webster/Sainte-Laguë_method).
- One can weight the elements in the sum by the allocations, and try to minimize $\sum_{i=1}^n a_i (q_i/a_i - 1)^2$. This leads to [Hill's method](https://en.wikipedia.org/wiki/Hill's_method).

## Minimizing the largest unfairneses {#Minimizing_the_largest_unfairneses}

One can minimize the *largest* unfairness, as in the [egalitarian rule](wikipedia://en/67856304):

- One can minimize $\max_{i=1}^n |q_i / a_i - 1|$, and proceed to minimize the next-largest unfairness etc., using the [leximin order](wikipedia://en/65470806). This yields a method called the *leximin apportionment method*. It was first developed by Biro, Koczy and Sziklai, who presented an efficient algorithm to compute it.[^o7] Its main goal is to satisfy the requirement of the [Venice Commission](https://en.wikipedia.org/wiki/Venice_Commission) that the maximum departure from equal distribution of items among agents should be as small as possible. Its disadvantage is that it violates the [quota rule](wikipedia://en/58854243) and all monotonicity criteria.[^o8]
- Burt and Harris (1963) suggested to minimize $\max_{i,j=1}^n |q_i / a_i - q_j/a_j|$.[^o4]
- Minimizing $\max_{i=1}^n q_i/a_i$ leads to Adams's method.
- Minimizing $\max_{i=1}^n a_i/q_i$ leads to Jefferson's method.
- It is also possible to maximize $\min_{i=1}^n (a_i - q_i)$, or equivalently, minimize $\max_{i=1}^n (q_i - a_i)$. This method satisfies both quotas.
- The minimax method can be generalized to any chosen priority ordering on the fairness criteria.[^o9]
