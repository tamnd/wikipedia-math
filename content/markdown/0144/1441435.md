# Equilibrium point (mathematics)

*Image: Stability\_Diagram.png.* [Stability diagram](wikipedia://en/5493795) classifying [Poincaré maps](wikipedia://en/876732#Poincaré_maps_and_stability_analysis) of linear [autonomous system](wikipedia://en/312398) $x' = Ax,$ as stable or unstable according to their features. Stability generally increases to the left of the diagram.[^o1] Some sink, source or node are equilibrium points.

::: {#o2 .subject cue=lead name="Equilibrium point"}

In [mathematics](wikipedia://en/18831), specifically in [differential equations](https://en.wikipedia.org/wiki/Differential_equations), an **equilibrium point** is a constant solution to a differential equation.

:::

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

The point $\tilde{\mathbf{x}}\in \mathbb{R}^n$ is an **equilibrium point** for the [differential equation](wikipedia://en/1424309)

$$\frac{d\mathbf{x}}{dt} = \mathbf{f}(t,\mathbf{x})$$

if $\mathbf{f}(t,\tilde{\mathbf{x}})=\mathbf{0}$ for all $t$.

Similarly, the point $\tilde{\mathbf{x}}\in \mathbb{R}^n$ is an **equilibrium point** (or [fixed point](wikipedia://en/449738)) for the [difference equation](https://en.wikipedia.org/wiki/Difference_equation)

$$\mathbf{x}_{k+1} = \mathbf{f}(k,\mathbf{x}_k)$$

if $\mathbf{f}(k,\tilde{\mathbf{x}})= \tilde{\mathbf{x}}$ for $k=0,1,2,\ldots$.

*Image: Fixed Points.gif.* Schematic visualization of four of the most common kinds of fixed points, in dimension 2.

Equilibria can be classified by looking at the signs of the [eigenvalues](wikipedia://en/2161429) of the linearization of the equations about the equilibria. That is to say, by evaluating the [Jacobian matrix](https://en.wikipedia.org/wiki/Jacobian_matrix) at each of the equilibrium points of the system, and then finding the resulting eigenvalues, the equilibria can be categorized. Then the behavior of the system in the neighborhood of each equilibrium point can be qualitatively determined, (or even quantitatively determined, in some instances), by finding the eigenvector(s) associated with each eigenvalue.

An equilibrium point is *[hyperbolic](wikipedia://en/3948604)* if none of the eigenvalues have zero real part. If all eigenvalues have negative real parts, the point is *stable*. If at least one has a positive real part, the point is *unstable*. If at least one eigenvalue has negative real part and at least one has positive real part, the equilibrium is a [saddle point](wikipedia://en/640249) and it is unstable. If all the eigenvalues are real and have the same sign the point is called a *node*.
