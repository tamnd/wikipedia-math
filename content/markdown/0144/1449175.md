# Degree matrix

::: {#o1 .subject cue=lead name="Degree matrix"}

In the [mathematical](wikipedia://en/18831) field of [algebraic graph theory](wikipedia://en/1620216), the **degree matrix** of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is a [diagonal matrix](wikipedia://en/174080) which contains information about the [degree](wikipedia://en/1374448) of each [vertex](wikipedia://en/638899)—that is, the number of edges attached to each vertex.[^o2] It is used together with the [adjacency matrix](wikipedia://en/244463) to construct the [Laplacian matrix](wikipedia://en/1448472) of a graph: the Laplacian matrix is the difference of the degree matrix and the adjacency matrix.[^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a graph $G=(V,E)$ with $|V|=n$, the **degree matrix** $D$ for $G$ is a $n \times n$ [diagonal matrix](wikipedia://en/174080) defined as[^o2]

$$D_{i,j}:=\left\{ \begin{matrix} \deg(v_i) & \mbox{if}\ i = j \\ 0 & \mbox{otherwise} \end{matrix} \right.$$

where the degree $\deg(v_i)$ of a vertex counts the number of times an edge terminates at that vertex. In an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph), this means that each loop increases the degree of a vertex by two. In a [directed graph](wikipedia://en/19721986), the term *degree* may refer either to [indegree](https://en.wikipedia.org/wiki/Indegree) (the number of incoming edges at each vertex) or [outdegree](https://en.wikipedia.org/wiki/Outdegree) (the number of outgoing edges at each vertex).

:::

Note that in the case of undirected graphs, an edge that starts and ends in the same node increases the corresponding degree value by 2 (i.e. it is counted twice).

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The degree matrix of a [k-regular graph](https://en.wikipedia.org/wiki/K-regular_graph) has a constant diagonal of $k$.

According to the [degree sum formula](https://en.wikipedia.org/wiki/Degree_sum_formula), the [trace](wikipedia://en/43270) of the degree matrix is twice the number of edges of the considered graph.

:::
