# Accessible quasi-category

::: {#o1 .subject cue=lead name="Accessible quasi-category"}

In mathematics, especially [category theory](wikipedia://en/5869), an **accessible quasi-category** is a [quasi-category](wikipedia://en/28662219) in which each object is an [ind-object](wikipedia://en/61387167) on some small quasi-category. In particular, an accessible quasi-category is typically large (not small). The notion is a generalization of an earlier 1-category version of it, an [accessible category](wikipedia://en/15311782) introduced by Adámek and Rosický.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

An [∞-category](https://en.wikipedia.org/wiki/∞-category) is called accessible or more precisely $\kappa$-accessible if it is equivalent to the ∞-category of $\kappa$-ind objects on some small ∞-category for some regular cardinal $\kappa$.[^o5]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Facts"}

## Facts {#Facts}

A small ∞-category is accessible if and only if it is [idempotent-complete](https://en.wikipedia.org/wiki/Idempotent-complete).[^o8]

:::
