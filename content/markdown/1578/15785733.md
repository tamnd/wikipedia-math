# Tangential angle

*Image: Intrinsic coordinates (Whewell equation).png.* The tangential angle $\varphi$ for an arbitrary curve $A$ in $P$.

::: {#o1 .subject cue=lead name="Tangential angle"}

In [geometry](wikipedia://en/18973446), the **tangential angle** of a [curve](wikipedia://en/89246) in the Cartesian plane, at a specific point, is the angle between the [tangent line](https://en.wikipedia.org/wiki/Tangent_line) to the curve at the given point and the $x$-axis. (Some authors define the angle as the deviation from the direction of the curve at some fixed starting point. This is equivalent to the definition given here by the addition of a constant to the angle or by rotating the curve.[^o3])

:::

## Equations {#Equations}

### Parametric {#Parametric}

If a curve is given [parametrically](wikipedia://en/576108) by $(x(t), y(t))$, then the tangential angle $\varphi$ at $t$ is defined (up to a multiple of $2\pi$) by

$$\frac{\big(x'(t),\ y'(t)\big)}{\big|x'(t),\ y'(t)\big|} = (\cos \varphi,\ \sin \varphi).$$

Here, the [prime symbol](https://en.wikipedia.org/wiki/Prime_%28symbol%29) denotes the [derivative](wikipedia://en/7921) with respect to $t$. Thus, the tangential angle specifies the direction of the [velocity](wikipedia://en/20491903) vector $(x(t), y(t))$, while the [speed](https://en.wikipedia.org/wiki/Speed) specifies its magnitude. The vector

$$\frac{\big(x'(t),\ y'(t)\big)}{\big|x'(t),\ y'(t)\big|}$$

is called the [unit tangent vector](https://en.wikipedia.org/wiki/Unit_tangent_vector), so an equivalent definition is that the tangential angle at $t$ is the angle $\varphi$ such that $(\cos \varphi, \sin \varphi)$ is the unit tangent vector at $t$.

If the curve is parametrized by [arc length](wikipedia://en/1898401) $s$, so $\lvert x'(s), y'(s)\rvert = 1$, then the definition simplifies to

$$\big(x'(s),\ y'(s)\big) = (\cos \varphi,\ \sin \varphi).$$

In this case, the [curvature](wikipedia://en/60770) $\kappa$ is given by $\varphi'(s)$, where $\kappa$ is taken to be positive if the curve bends to the left and negative if the curve bends to the right.[^o2] Conversely, the tangent angle at a given point equals the definite integral of curvature up to that point:[^o7][^o2]

$$\varphi(s) = \int_{0}^s \kappa(s) ds + \varphi_0$$

$$\varphi(t) = \int_{0}^t \kappa(t) s'(t) dt + \varphi_0$$

### Explicit {#Explicit}

If the curve is given by the [graph of a function](wikipedia://en/87352) $y = f(x)$, then we may take $(x, f(x))$ as the parametrization, and we may assume $\varphi$ is between $-\tfrac{\pi}{2}$ and $\tfrac{\pi}{2}$. This produces the explicit expression

$$\varphi = \arctan f'(x).$$

## Polar tangential angle {#Polar_tangential_angle}

In [polar coordinates](wikipedia://en/25120), the **polar tangential angle** is defined as the angle between the tangent line to the curve at the given point and ray from the origin to the point.[^o11] If $\psi$ denotes the polar tangential angle, then $\psi = \varphi - \theta$, where $\varphi$ is as above and $\theta$ is, as usual, the polar angle.

If the curve is defined in polar coordinates by $r = f(\theta)$, then the polar tangential angle $\psi$ at $\theta$ is defined (up to a multiple of $2\pi$) by

$$\frac{\big(f'(\theta),\ f(\theta)\big)}{\big|f'(\theta),\ f(\theta)\big|} = (\cos \psi,\ \sin \psi).$$

If the curve is parametrized by arc length $s$ as $r = r(s)$, $\theta = \theta(s)$, so $\lvert (r'(s), r\theta'(s))\rvert = 1$, then the definition becomes

$$\big(r'(s),\ r\theta'(s)\big) = (\cos \psi,\ \sin \psi).$$

The [logarithmic spiral](wikipedia://en/42373) can be defined a curve whose polar tangential angle is constant.[^o11][^o10]
