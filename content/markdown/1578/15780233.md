# Tukey lambda distribution

::: {#o1 .subject cue=lead name="Tukey lambda distribution"}

Formalized by [John Tukey](wikipedia://en/415974), the **Tukey lambda distribution** is a continuous, symmetric probability distribution defined in terms of its [quantile function](wikipedia://en/10167616). It is typically used to identify an appropriate distribution (see the comments below) and not used in [statistical models](wikipedia://en/27576) directly.

:::

The Tukey lambda distribution has a single [shape parameter](wikipedia://en/9210865), $\lambda$, and as with other probability distributions, it can be transformed with a [location parameter](wikipedia://en/17516), $\mu$, and a [scale parameter](wikipedia://en/769503), $\sigma$. Since the general form of probability distribution can be expressed in terms of the standard distribution, the subsequent formulas are given for the standard form of the function.

## Quantile function {#Quantile_function}

For the standard form of the Tukey lambda distribution, the quantile function, $~ Q(p) ~,$ (i.e. the inverse function to the [cumulative distribution function](wikipedia://en/5793)) and the quantile density function, $~ q = \frac{\ \operatorname{d}Q\ }{ \operatorname{d}p }\ ,$ are

$$\ Q\left(\ p\ ; \lambda\ \right) ~=~ \begin{cases} \tfrac{ 1 }{\ \lambda\ } \left[\ p^\lambda - (1 - p)^\lambda\ \right]\ , &\ \mbox{ if }\ \lambda \ne 0~, \\ {} \\ \ln\left( \frac{ p }{\ 1 - p\ } \right)~, &\ \mbox{ if }\ \lambda = 0 ~. \end{cases}$$

$$q \left(\ p\ ; \lambda\ \right) ~=~ \frac{\ \operatorname{d}Q\ }{ \operatorname{d}p } ~=~ p^{ \lambda - 1 } + \left(\ 1 - p\ \right)^{ \lambda - 1 } ~.$$

For most values of the shape parameter, $\lambda$, the [probability density function](wikipedia://en/43487) (PDF) and [cumulative distribution function](wikipedia://en/5793) (CDF) must be computed numerically. The Tukey lambda distribution has a simple, closed form for the CDF and / or PDF only for a few exceptional values of the shape parameter, for example: $\lambda$ ∈ { 2, 1, $\tfrac{\,1\,}{2}$, 0 } (see [uniform distribution](wikipedia://en/1699223) \[ cases $\lambda = 1$ and $\lambda = 2$ \] and the [logistic distribution](wikipedia://en/542666) \[ case $\lambda = 0$ \].

However, for any value of $\lambda$ both the CDF and PDF can be tabulated for any number of cumulative probabilities, $p$, using the quantile function $Q$ to calculate the value $x$, for each cumulative probability $p$, with the probability density given by $\tfrac{1}{q}$, the reciprocal of the quantile density function. As is the usual case with statistical distributions, the Tukey lambda distribution can readily be used by looking up values in a prepared table.

## Moments {#Moments}

The Tukey lambda distribution is symmetric around zero, therefore the expected value of this distribution, if it exists, is equal to zero. The variance exists for $\lambda > -\tfrac{\,1\,}{2}$ , and except when $\lambda = 0$ , is given by the formula

$$\operatorname{Var}[\ X\ ] = \frac{2}{\lambda^2}\bigg(\ \frac{ 1 }{\ 1 + 2\lambda\ } ~ - ~ \frac{\ \Gamma(\lambda+1)^2\ }{\ \Gamma(2\lambda+2)\ }\ \bigg) ~.$$

More generally, the $n$-th order moment is finite when $\lambda > \tfrac{-1}{n}$ and is expressed (except when $\lambda = 0$ ) in terms of the [beta function](wikipedia://en/245660) $\mathrm{B}(x,y)$ :

$$\mu_n \equiv \operatorname{E}[\ X^n\ ] = \frac{1}{\lambda^n} \sum_{k=0}^n\ (-1)^k\ {n \choose k}\ \mathrm{B}(\ \lambda\ k + 1\ ,\ (n - k)\ \lambda + 1\ ) ~.$$

Due to symmetry of the density function, all moments of odd orders, if they exist, are equal to zero.

## L-moments {#L-moments}

Differently from the central moments, [L-moments](https://en.wikipedia.org/wiki/L-moments) can be expressed in a closed form. For $\lambda > -1\ ,$ the $\ r$th L-moment, $\ \ell_r\ ,$ is given by[^o7]

$$\begin{aligned} \ell_{r} &= \frac{\ 1 + (-1)^{r}\ }{ \lambda }\ \sum_{k=0}^{r-1}\ (-1)^{ r - 1 - k }\ \binom{r-1}{k}\ \binom{ r + k -1 }{ k }\ \left(\frac{ 1 }{\ k + 1 + \lambda\ } \right) \\ {} \\ &= \bigl( 1 + (-1)^{r} \bigr) \frac{\ \Gamma( 1 + \lambda )\ \Gamma( r - 1 - \lambda )\ }{\ \Gamma( 1 - \lambda )\ \Gamma( r + 1 + \lambda)\ } ~. \end{aligned}$$

The first six L-moments can be presented as follows:[^o7]

$$\ell_{1} = ~~ 0\ ,$$

$$\ell_2 = \frac{ 2 }{\ \lambda\ }\ \left[\ -\frac{ 1 }{\ 1 + \lambda\ } + \frac{ 2 }{\ 2 + \lambda\ }\ \right]\ ,$$

$$\ell_3 = ~~ 0\ ,$$

$$\ell_4 = \frac{2}{\ \lambda\ }\ \left[ - \frac{ 1 }{\ 1 + \lambda\ } + \frac{ 12 }{\ 2 + \lambda\ } - \frac{ 3 0}{\ 3 + \lambda\ } + \frac{ 20 }{\ 4 + \lambda\ }\ \right]\ ,$$

$$\ell_5 = ~~ 0\ ,$$

$$\ell_6 = \frac{ 2 }{\ \lambda\ }\ \left[\ -\frac{ 1 }{\ 1 + \lambda\ } + \frac{ 30 }{\ 2 + \lambda\ } - \frac{ 210 }{\ 3 + \lambda\ } +\frac{ 560 }{\ 4 + \lambda\ } - \frac{ 630 }{\ 5 + \lambda\ } + \frac{ 252 }{\ 6 + \lambda\ }\ \right] ~.$$

## Comments {#Comments}

*Image: Several samples of the pdfs of the Tukey lambda distributions.svg.* Probability density plots of Tukey lambda distributions

The Tukey lambda distribution is actually a family of distributions that can approximate a number of common distributions. For example,

{| class="wikitable"

\|- | $\lambda \approx -1$ | approx. [Cauchy](wikipedia://en/7003) $C( 0, \pi )$ |- | $\lambda = 0$ | exactly [logistic](wikipedia://en/542666) |- | $\lambda \approx 0.14$ | approx. [normal](wikipedia://en/21462) $N( 0, 2.142^{\pm} )$ |- | {{nobr| $\lambda = \tfrac{\,1\,}{2}$ | strictly [concave](wikipedia://en/263321) ($\cap$-shaped) |- | $\lambda = 1$ | exactly [uniform](wikipedia://en/1699223) $U( -1, +1 )$ |- | $\lambda = 2$ | exactly [uniform](wikipedia://en/1699223) $U( -\tfrac{\,1\,}{2} , +\tfrac{\,1\,}{2} )$ |}

The most common use of this distribution is to generate a Tukey lambda [PPCC plot](https://en.wikipedia.org/wiki/PPCC_plot) of a [data set](wikipedia://en/8495). Based on the value for $\lambda$ with best correlation, as shown on the [PPCC plot](https://en.wikipedia.org/wiki/PPCC_plot), an appropriate [model](wikipedia://en/27576) for the data is suggested. For example, if the best-fit of the curve to the data occurs for a value of $\lambda$ at or near $0.14$, then empirically the data could be well-modeled with a normal distribution. Values of $\lambda$ less than 0.14 suggests a heavier-tailed distribution.

A milepost at $\lambda = 0$ ([logistic](wikipedia://en/542666)) would indicate quite fat tails, with the extreme limit at $\lambda = -1$ , approximating [Cauchy](wikipedia://en/7003) and small sample versions of the [Student's $t$](https://en.wikipedia.org/wiki/Student's_t_distribution). That is, as the best-fit value of $\lambda$ varies from thin tails at $0.14$ towards fat tails $-1$, a bell-shaped PDF with increasingly heavy tails is suggested. Similarly, an optimal curve-fit value of $\lambda$ greater than $0.14$ suggests a distribution with *exceptionally* thin tails (based on the point of view that the normal distribution itself is thin-tailed to begin with; the [exponential distribution](wikipedia://en/45906) is often chosen as the exemplar of tails intermediate between fat and thin).

Except for values of $\lambda$ approaching $0$ and those below, all the PDF functions discussed have finite [support](https://en.wikipedia.org/wiki/Support_of_a_function), between $\tfrac{-1}{|\lambda|}$ and $\tfrac{+1}{|\lambda|}$ .

Since the Tukey lambda distribution is a [symmetric](wikipedia://en/1390873) distribution, the use of the Tukey lambda PPCC plot to determine a reasonable distribution to model the data only applies to symmetric distributions. A [histogram](wikipedia://en/13266) of the data should provide evidence as to whether the data can be reasonably modeled with a symmetric distribution.[^o9]

## Generalization {#Generalization}

The **generalized lambda distribution** (GLD) generalizes the lambda distribution by splitting the occurrences of λ in the quantile into two shape parameters (accounts for asymmetry), a scale parameter, and adds a location parameter. It is defined by the quantile function[^o12]

$$Q_{\text {RS74}} = \lambda_1 + \tfrac{ 1 }{\ \lambda_2\ } \left[\ p^{\lambda_3} - (1 - p)^{\lambda_4}\ \right].$$

The inverse function is the cumulative distribution function. This distribution also has (rather complex) expressions for μ, σ, and the moments.[^o12]

The above parameterization is the original form proposed by Ramberg and Schmeiser; some choices of λ<sub>3,4</sub> yield invalid quantile functions (a quantile function should not be negative).[^o13] A more commonly used form is FMKL (1988) which is valid as long as λ2 > 0;. There is also a variant of FMKL that adds skewness. The other alternative parameterization is GPD of van Staden and Loots (2009), which has simpler expressions for L-moments, a simple rule for parameter validity, and a skew parameter *δ*.[^o14]

$$\begin{aligned} Q_{\text{FMKL}} =&\ \lambda_1 + \tfrac{ 1 }{\ \lambda_2\ } \left[ \frac{p^{\lambda_3} - 1}{\lambda_3} - \frac{{(1 - p)}^{\lambda_4} -1}{\lambda_4} \right] &\ \mbox{ if }\ \lambda_2 > 0,\\ Q_{\text{GPD}} =&\ \alpha + \frac{\beta}{\lambda} \left[ (1-\delta)(p^\lambda-1) - \delta ({(1-p)}^\lambda - 1) \right] &\ \text{ if }\ \beta > 0 \mbox{ and } -1 \le \delta \le 1. \end{aligned}$$

The GLD was developed by Ramberg and Schmeiser in 1974 for generating random numbers for Monte Carlo simulation. Other researchers found it useful for fitting various measurements in the natural sciences, finance, and economy.[^o15] Its use spread to the field of [statistical quality control](https://en.wikipedia.org/wiki/Statistical_quality_control) and procedures are available for using it in the calculation of [process capability indices](wikipedia://en/3420357).[^o12]
