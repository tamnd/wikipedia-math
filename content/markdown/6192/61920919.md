# Pseudoalgebra

::: {#o1 .subject cue=lead name="Pseudoalgebra"}

In algebra, given a 2-[monad](wikipedia://en/355140) *T* in a [2-category](wikipedia://en/2740708), a **pseudoalgebra** for *T* is a 2-category-version of [algebra for *T*](https://en.wikipedia.org/wiki/Algebra_for_a_monad), that satisfies the laws up to [coherent isomorphisms](https://en.wikipedia.org/wiki/Coherent_isomorphism).[^o2]

:::
