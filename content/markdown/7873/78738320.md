# Thurston's 24 questions

::: {#o1 .subject cue=lead name="Thurston's 24 questions"}

*Image: William Thurston.jpg.* American mathematician [William Thurston](wikipedia://en/39190)

**Thurston's 24 questions** are a set of [mathematical problems](wikipedia://en/183091) in [differential geometry](wikipedia://en/8625) posed by [American](https://en.wikipedia.org/wiki/Americans) [mathematician](wikipedia://en/18902) [William Thurston](wikipedia://en/39190) in his influential 1982 paper *Three-dimensional manifolds, [Kleinian groups](wikipedia://en/1362652) and [hyperbolic geometry](wikipedia://en/241291)* published in the *[Bulletin of the American Mathematical Society](wikipedia://en/2668304)*.[^o2] These questions significantly influenced the development of [geometric topology](wikipedia://en/621732) and related fields over the following decades.

:::

## History {#History}

The questions appeared following Thurston's announcement of the [geometrization conjecture](wikipedia://en/220642), which proposed that all [compact](wikipedia://en/6042) [3-manifolds](wikipedia://en/1018257) could be decomposed into geometric pieces.[^o2] This [conjecture](wikipedia://en/6138), later [proven](wikipedia://en/82285) by [Grigori Perelman](wikipedia://en/225266) in 2003, represented a complete [classification](wikipedia://en/4576710) of 3-manifolds and included the famous [Poincaré conjecture](wikipedia://en/23798) as a special case.[^o4]

By 2012, 22 of Thurston's 24 questions had been resolved.[^o4]

## Table of problems {#Table_of_problems}

Thurston's 24 questions are:[^o2]

::: {#o6 .table cue=table}

| Problem | Brief description | Status | Year solved |
|---|---|---|---|
| 1st | [Thurston's geometrization conjecture](https://en.wikipedia.org/wiki/Thurston's_geometrization_conjecture): every [3-manifold](wikipedia://en/1018257) can be decomposed into prime manifolds of eight canonical geometries. |  | 2003 |
| 2nd | Is every [finite](wikipedia://en/323707) [group action](wikipedia://en/12781) on 3-manifold equivalent to isometric action? |  | 2009 |
| 3rd | The [geometrization conjecture](wikipedia://en/220642) for 3-dimensional [orbifolds](wikipedia://en/293504): if such orbifold have no with no 2-dimesional suborbifolds, can it be geometrically decomposed? |  | 2005 |
| 4th | Global theory of [hyperbolic Dehn surgery](wikipedia://en/4450009): give upper bound for nonhyperbolic surgeries and find description of geometry that is created when hyperbolic surgery breaks down. |  | 2000–2013 |
| 5th | Are all [Kleinian groups](wikipedia://en/1362652) [geometrically tame](wikipedia://en/31219878)? |  | 1986–1993 |
| 6th | Can every Kleinian group be obtained as a limit of geometrically finite groups? |  | 2012 |
| 7th | Develop theory of [Schottky groups](wikipedia://en/5871034) and their limits, that will be analogous to quasi-Fuchsian groups theory. |  | 2012 |
| 8th | Analysis of limits of [quasi-Fuchsian groups](wikipedia://en/30960521) with accidental parabolics. |  | 2000 |
| 9th | Are all Kleinian groups [topologically tame](wikipedia://en/31219878)? |  | 2004 |
| 10th | The [Ahlfors measure zero problem](wikipedia://en/31197103): group obtained as a limit set of finitely-generated Kleinian group have either full measure or measure 0. In case of full measure, does it act [ergodically](wikipedia://en/5456824)? |  | 2004 |
| 11th | [Ending lamination conjecture](wikipedia://en/30997240): can geometrically tame representations of given group be parametrized by their ending laminations and their parabolics? |  | 2012 |
| 12th | Describe quasi-isometry type of Kleinian groups |  | 2012 |
| 13th | Is the limit set of Kleinian groups with [Hausdorff dimension](wikipedia://en/14294) less than 2 [geometrically finite](wikipedia://en/31212031)? |  | 1997 |
| 14th | Existence of [Cannon–Thurston maps](wikipedia://en/63553560) for hyperbolic spaces. |  | 2009–2012 |
| 15th | Is it possible to [residually separate](wikipedia://en/5780875#Profinite_topology) finitely-generated subgroups in a finitely-generated Kleinian group? |  | 2013 |
| 16th | [Virtually Haken conjecture](wikipedia://en/4692183): does every aspherical or hyperbolic 3-manifold have a finite Haken cover? |  | 2012 |
| 17th | Having 3-manifold that is aspherical, does it have finite cover with positive first [Betti number](wikipedia://en/346262)? |  | 2013 |
| 18th | [Virtually fibered conjecture](wikipedia://en/2823145): every hyperbolic 3-manifold have a finite cover which is a [surface bundle over the circle](wikipedia://en/2011690). |  | 2013 |
| 19th | Describe topology and geometry of manifolds constructed as quotient spaces of [PSL(2,C)](wikipedia://en/382667) by [arithmetic subgroups](wikipedia://en/630741). |  | — |
| 20th | Develop software for calculation of canonical form of surface diffeomorphisms and group action of diffeomorphisms of projectivized lamination spaces. |  | 1990s–2000s |
| 21st | Develop software to compute hyperbolic structures on 3-manifold. |  | 1990s–2000s |
| 22nd | Develop software for tabulation of basics informations about 3-manifolds, ie: their volumes, Chern-Simon invariants or knots. |  | 1990s–2000s |
| 23rd | Are hyperbolic volumes of 3-manifold [rationally independent](wikipedia://en/17904953)? |  | — |
| 24th | Existence of hyperbolic structures on 3-manifolds with given Heegaard genus. |  | 2009 |

:::
