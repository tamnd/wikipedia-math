# Hilbert basis (linear programming)

::: {#o1 .subject cue=lead name="Hilbert basis"}

The **Hilbert basis** of a [convex cone](wikipedia://en/3558266) *C* is a minimal set of integer [vectors](https://en.wikipedia.org/wiki/Vector_%28mathematics%29) in *C* such that every [integer](wikipedia://en/14563) vector in *C* is a [conical combination](wikipedia://en/19634578) of the vectors in the Hilbert basis with integer coefficients.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Hilbert basis.gif.* Hilbert basis visualization. Two rays in the plane define an infinite cone of all the points lying between them. The unique Hilbert basis points of the cone are circled in yellow. Every integer point in the cone can be written as a sum of these basis elements. As you change the cone by moving one of the rays, the Hilbert basis also changes.

Given a [lattice](wikipedia://en/469246) $L\subset\mathbb{Z}^d$ and a convex polyhedral cone with generators $a_1,\ldots,a_n\in\mathbb{Z}^d$

$$C=\{ \lambda_1 a_1 + \ldots + \lambda_n a_n \mid \lambda_1,\ldots,\lambda_n \geq 0, \lambda_1,\ldots,\lambda_n \in\mathbb{R}\}\subset\mathbb{R}^d,$$

we consider the [monoid](wikipedia://en/19652) $C\cap L$. By [Gordan's lemma](wikipedia://en/23835696), this monoid is finitely generated, i.e., there exists a [finite set](wikipedia://en/11742) of lattice points $\{x_1,\ldots,x_m\}\subset C\cap L$ such that every lattice point $x\in C\cap L$ is an integer conical combination of these points:

$$x=\lambda_1 x_1+\ldots+\lambda_m x_m, \quad\lambda_1,\ldots,\lambda_m\in\mathbb{Z}, \lambda_1,\ldots,\lambda_m\geq0.$$

The cone *C* is called pointed if $x,-x\in C$ implies $x=0$. In this case there exists a unique minimal generating set of the monoid $C\cap L$—the **Hilbert basis** of *C*. It is given by the set of irreducible lattice points: An element $x\in C\cap L$ is called irreducible if it can not be written as the sum of two non-zero elements, i.e., $x=y+z$ implies $y=0$ or $z=0$.

:::
