# Iterated conditional modes

::: {#o1 .subject cue=lead name="Iterated conditional modes"}

In [statistics](wikipedia://en/26685), **iterated conditional modes** is a [deterministic algorithm](https://en.wikipedia.org/wiki/Deterministic_algorithm) for obtaining a configuration of a local maximum of the [joint probability](https://en.wikipedia.org/wiki/Joint_probability) of a [Markov random field](wikipedia://en/1323985). It does this by iteratively maximizing the probability of each variable [conditioned](https://en.wikipedia.org/wiki/Conditional_distribution) on the rest.

:::
