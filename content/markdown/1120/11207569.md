# Automorphic factor

::: {#o1 .subject cue=lead name="Automorphic factor"}

In [mathematics](wikipedia://en/18831), an **automorphic factor** is a certain type of [analytic function](wikipedia://en/61478), defined on [subgroups](wikipedia://en/28011) of [SL(2,R)](https://en.wikipedia.org/wiki/SL%282,R%29), appearing in the theory of [modular forms](wikipedia://en/286000). The general case, for general groups, is reviewed in the article '[factor of automorphy](https://en.wikipedia.org/wiki/Factor_of_automorphy)'.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An *automorphic factor of weight k* is a function

$$\nu : \Gamma \times \mathbb{H} \to \mathbb{C}$$

satisfying the four properties given below. Here, the notation $\mathbb{H}$ and $\mathbb{C}$ refer to the [upper half-plane](wikipedia://en/287826) and the [complex plane](wikipedia://en/217628), respectively. The notation $\Gamma$ is a subgroup of SL(2,R), such as, for example, a [Fuchsian group](wikipedia://en/471365). An element $\gamma \in \Gamma$ is a 2×2 matrix

$$\gamma = \begin{bmatrix}a&b \\c & d\end{bmatrix}$$

with *a*, *b*, *c*, *d* real numbers, satisfying *ad*−*bc*=1.

An automorphic factor must satisfy:

1. For a fixed $\gamma\in\Gamma$, the function $\nu(\gamma,z)$ is a [holomorphic function](wikipedia://en/14110) of $z\in\mathbb{H}$.
1. For all $z\in\mathbb{H}$ and $\gamma\in\Gamma$, one has $$\vert\nu(\gamma,z)\vert = \vert cz + d\vert^k$$ for a fixed [real number](wikipedia://en/20646438) *k*.
1. For all $z\in\mathbb{H}$ and $\gamma,\delta \in \Gamma$, one has $$\nu(\gamma\delta, z) = \nu(\gamma,\delta z)\nu(\delta,z)$$ Here, $\delta z$ is the [fractional linear transform](https://en.wikipedia.org/wiki/Fractional_linear_transform) of $z$ by $\delta$.
1. If $-I\in\Gamma$, then for all $z\in\mathbb{H}$ and $\gamma \in \Gamma$, one has $$\nu(-\gamma,z) = \nu(\gamma,z)$$ Here, *I* denotes the [identity matrix](wikipedia://en/59718).

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every automorphic factor may be written as

$$\nu(\gamma, z)=\upsilon(\gamma) (cz+d)^k$$

with

$$\vert\upsilon(\gamma)\vert = 1$$

The function $\upsilon:\Gamma\to S^1$ is called a **multiplier system**. Clearly,

$$\upsilon(I)=1,$$

while, if $-I\in\Gamma$, then

$$\upsilon(-I)=e^{-i\pi k}$$

which equals $(-1)^k$ when *k* is an [integer](wikipedia://en/14563).

:::

## Complex generalization {#Complex_generalization}

There exist non-holomorphic automorphic factors of the type

$$\nu(\gamma, z)=\upsilon(\gamma) (cz+d)^\alpha (c\bar z+d)^\beta$$

where $\alpha,\beta\in\mathbb{C}$ are arbitrary coweights. The condition

$$\nu(\gamma\delta, z) = \nu(\gamma,\delta z)\nu(\delta,z)$$

reduces to $\upsilon(\gamma\delta)=\upsilon(\gamma)\upsilon(\delta)$ if $\alpha-\beta\in\mathbb{Z}$.

If $\Gamma=SL_2(\mathbb{Z})$ is the [modular group](wikipedia://en/325019) and $\Re\alpha,\Re\beta\in [0,1)$, then there exists a multiplier system such that

$$\upsilon\left(\begin{smallmatrix} 1 & 1 \\ 0 & 1 \end{smallmatrix}\right) = e^{i\frac{\pi}{6}(\alpha-\beta)} \quad , \quad \upsilon\left(\begin{smallmatrix} 0 & -1 \\ 1 & 0 \end{smallmatrix}\right) = e^{-i\frac{\pi}{2}(\alpha-\beta)}$$

For $\eta(z)$ the [Dedekind eta function](wikipedia://en/447020), the [modular form](wikipedia://en/286000) $f_{\alpha,\beta}(z)=\eta(z)^{2\alpha}\overline{\eta(z)^{2\overline{\beta}}}$ is such that $f_{\alpha,\beta}(\gamma(z)) = \nu(\gamma,z)f_{\alpha,\beta}(z)$ for any $\gamma\in SL_2(\mathbb{Z})$.
