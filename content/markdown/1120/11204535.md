# AWPP

::: {#o1 .subject cue=lead name="AWPP"}

In [theoretical computer science](wikipedia://en/323392), **almost wide probabilistic polynomial-time** (**AWPP**) is a [complexity class](wikipedia://en/502426) contained in [PP](wikipedia://en/659322) defined via [GapP](wikipedia://en/4788155) functions. The class often arises in the context of [quantum computing](wikipedia://en/25220).

:::

AWPP contains the complexity class [BQP](wikipedia://en/4080) (bounded-error quantum polynomial time), which contains the [decision problems](wikipedia://en/8336) solvable by a quantum computer in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), with an error probability of at most 1/3 for all instances. In fact, it is the smallest classical complexity class that upper bounds BQP. Furthermore, it is contained in the [APP](https://en.wikipedia.org/wiki/APP_%28complexity_class%29) class.
