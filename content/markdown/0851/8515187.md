# Matrix-free methods

::: {#o1 .subject cue=lead name="Matrix-free methods"}

In [computational mathematics](wikipedia://en/10433833), a **matrix-free method** is an algorithm for solving a [linear system of equations](https://en.wikipedia.org/wiki/Linear_system_of_equations) or an [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue) problem that does not store the coefficient [matrix](wikipedia://en/20556859) explicitly, but accesses the matrix by evaluating matrix-vector products.[^o2] Such methods can be preferable when the matrix is sufficiently large that storing and manipulating it would be prohibitively expensive with respect to memory or computation time, even with the use of methods for [sparse matrices](wikipedia://en/341015). Many [iterative methods](wikipedia://en/15237) allow for a matrix-free implementation, including:

:::

- the [power method](https://en.wikipedia.org/wiki/Power_method),
- the [Lanczos algorithm](wikipedia://en/2593852),[^o3]
- Locally Optimal Block Preconditioned Conjugate Gradient Method ([LOBPCG](wikipedia://en/26951185)),[^o4]
- Wiedemann's coordinate recurrence algorithm,[^o5]
- the [conjugate gradient method](wikipedia://en/1448821),[^o6]
- [Krylov subspace methods](wikipedia://en/2542615).

Distributed solutions have also been explored using coarse-grain parallel software systems to achieve homogeneous solutions of linear systems.[^o7]

It is generally used in solving non-linear equations like Euler's equations in [computational fluid dynamics](wikipedia://en/305924). Matrix-free conjugate gradient method has been applied in the non-linear elasto-plastic finite element solver.[^o8] Solving these equations requires the calculation of the [Jacobian](wikipedia://en/195351) which is costly in terms of CPU time and storage. To avoid this expense, matrix-free methods are employed. In order to remove the need to calculate the Jacobian, the Jacobian vector product is formed instead, which is in fact a vector itself. Manipulating and calculating this vector is easier than working with a large matrix or linear system.
