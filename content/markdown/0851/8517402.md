# Symmetric successive over-relaxation

::: {#o1 .subject cue=lead name="Symmetric successive over-relaxation"}

In applied mathematics, **symmetric successive over-relaxation (SSOR)**,[^o2] is a [preconditioner](wikipedia://en/5165246).

:::

If the original matrix can be [split](wikipedia://en/36743227) into diagonal, lower and upper triangular as $A=D+L+L^\mathsf{T}$ then the SSOR preconditioner matrix is defined as

$$M=(D+L) D^{-1} (D+L)^\mathsf{T}$$

It can also be parametrised by $\omega$ as follows.[^o3]

$$M(\omega)={\omega\over{2-\omega}} \left ( {1\over\omega} D + L \right ) D^{-1} \left ( {1\over\omega} D + L\right)^\mathsf{T}$$
