# Polydisc

::: {#o1 .subject cue=lead name="Polydisc"}

In the theory of functions of [several complex variables](wikipedia://en/360243), a branch of [mathematics](wikipedia://en/18831), a **polydisc** is a [Cartesian product](wikipedia://en/24104095) of [discs](https://en.wikipedia.org/wiki/Disc_%28mathematics%29).

:::

More specifically, if we denote by $D(z,r)$ the [open](wikipedia://en/39358) disc of center *z* and radius *r* in the [complex plane](wikipedia://en/217628), then an open polydisc is a set of the form

$$D(z_1,r_1) \times \dots \times D(z_n,r_n).$$

It can be equivalently written as

$$\{ w=(w_1, w_2, \dots, w_n) \in {\mathbf{C}}^n : \vert z_k - w_k \vert < r_k, \mbox{ for all } k = 1,\dots,n \}.$$

One should not confuse the polydisc with the [open ball](https://en.wikipedia.org/wiki/Open_ball) in **C**<sup>n</sup>, which is defined as

$$\{ w \in \mathbf{C}^n : \lVert z - w \rVert < r \}.$$

Here, the [norm](wikipedia://en/990534) is the [Euclidean distance](wikipedia://en/53932) in **C**<sup>n</sup>.

When $n > 1$, open balls and open polydiscs are *not* biholomorphically equivalent, that is, there is no [biholomorphic mapping](https://en.wikipedia.org/wiki/Biholomorphic_mapping) between the two. This was proven by [Poincaré](wikipedia://en/48740) in 1907 by showing that their [automorphism groups](wikipedia://en/56661772) have different dimensions as [Lie groups](wikipedia://en/17945).[^o2]

When $n=2$ the term *bidisc* is sometimes used.

A polydisc is an example of [logarithmically convex](https://en.wikipedia.org/wiki/Logarithmically_convex_set) [Reinhardt domain](https://en.wikipedia.org/wiki/Reinhardt_domain).
