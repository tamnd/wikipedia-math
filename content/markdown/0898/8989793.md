# Coding (social sciences)

::: {#o1 .subject cue=lead name="Coding"}

In the [social sciences](https://en.wikipedia.org/wiki/Social_science), **coding** is an analytical process in which data, in both [quantitative](wikipedia://en/389564) form (such as [questionnaires](wikipedia://en/956483) results) or [qualitative](wikipedia://en/371299) form (such as [interview](https://en.wikipedia.org/wiki/Interview) transcripts) are categorized to facilitate analysis.

:::

One purpose of coding is to [transform the data](https://en.wikipedia.org/wiki/Data_transformation) into a form suitable for computer-aided analysis. This categorization of [information](wikipedia://en/18985062) is an important step, for example, in preparing [data](https://en.wikipedia.org/wiki/Data) for [computer](https://en.wikipedia.org/wiki/Computer) processing with [statistical software](https://en.wikipedia.org/wiki/List_of_statistical_packages). Prior to coding, an annotation scheme is defined. It consists of codes or tags. During coding, coders manually add codes into data where required features are identified. The coding scheme ensures that the codes are added consistently across the data set and allows for verification of previously tagged data.[^o2]

Some studies will employ multiple coders working independently on the same data. This also minimizes the chance of [errors](wikipedia://en/22346) from coding and is believed to increase the [reliability](wikipedia://en/239138) of data.

## Directive {#Directive}

One code should apply to only one category and categories should be comprehensive. There should be clear guidelines for *coders* (individuals who do the coding) so that code is consistent.

## Quantitative approach {#Quantitative_approach}

For quantitative analysis, data is coded usually into [measured and recorded as nominal or ordinal](https://en.wikipedia.org/wiki/Levels_of_measurement) [variables](https://en.wikipedia.org/wiki/Variable_%28programming%29).

Questionnaire data can be *pre-coded* (process of assigning codes to expected answers on designed questionnaire), *field-coded* (process of assigning codes as soon as data is available, usually during [fieldwork](https://en.wikipedia.org/wiki/Fieldwork)), *post-coded* (coding of [open questions](https://en.wikipedia.org/wiki/Open-ended_question) on completed questionnaires) or *office-coded* (done after fieldwork). Note that some of the above are not mutually exclusive.

In social sciences, [spreadsheets](https://en.wikipedia.org/wiki/Spreadsheets) such as [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel) and more advanced software packages such as [R](wikipedia://en/376707), [Matlab](https://en.wikipedia.org/wiki/Matlab), [PSPP](wikipedia://en/16653967)/[SPSS](wikipedia://en/179088), [DAP](wikipedia://en/16671308)/[SAS](https://en.wikipedia.org/wiki/SAS_System), [MiniTab](https://en.wikipedia.org/wiki/MiniTab) and [Stata](wikipedia://en/1809002) are often used.

## Qualitative approach {#Qualitative_approach}

For disciplines in which a [qualitative](wikipedia://en/371299) format is preferential, including [ethnography](https://en.wikipedia.org/wiki/Ethnography), [humanistic geography](https://en.wikipedia.org/wiki/Humanistic_geography) or [phenomenological psychology](https://en.wikipedia.org/wiki/Phenomenological_psychology) a varied approach to coding can be applied. Iain Hay (2005) outlines a two-step process beginning with basic coding in order to distinguish overall themes, followed by a more in depth, interpretive code in which more specific trends and patterns can be interpreted.[^o7]

Much of qualitative coding can be attributed to either grounded or [*a priori*](wikipedia://en/6679056) coding.[^o8] Grounded coding refers to allowing notable themes and patterns emerge from the document themselves, where as *a priori* coding requires the researcher to apply pre-existing theoretical frameworks to analyze the documents. As coding methods are applied across various texts, the researcher is able to apply axial coding, which is the process of selecting core thematic categories present in several documents to discover common patterns and relations.[^o9]

Coding is considered a process of discovery and is done in cycles. Prior to constructing categories, a researcher might apply a first and second cycle coding methods.[^o8] There are a multitude of methods available, and a researcher will want to pick one that is suited for the format and nature of their documents. Not all methods can be applied to every type of document. Some examples of first cycle coding methods include:

- *In vivo coding*: Codes terms and phrases used by the participants themselves. The objective is to attempt to give the participants a voice in the research.
- *Process coding*: This method uses gerunds ("-ing" words) only to describe and display actions throughout the document. It is useful for examining processes, emotional phases and rituals.
- *Versus coding*: Uses binary terms to describe groups and processes. The goal is to see which processes and organizations are in conflict with each other throughout the document. These can be both conceptual and grounded objects.
- *Values coding*: codes that attempt to exhibit the inferred values, attitudes and beliefs of participants. In doing so, the research may discern patterns in world views.
- *Sub-coding*: Other names of this method are embedded coding, nested coding or joint coding. This involves assigning primary and second order codes to a word or phrase. It serves the purpose of adding detail to a code. The primary and secondary codes are often called parent and children codes.[^o10]
- *Simultaneous coding*: When same parts of the data have different meanings and two or more codes are applied to the same parts, then this kind of coding is called simultaneous coding.[^o8]

The process can be done manually, which can be as simple as highlighting different concepts with different colours, or fed into a software package. Some examples of [qualitative software packages](https://en.wikipedia.org/wiki/Computer-assisted_qualitative_data_analysis_software) include [Atlas.ti](https://en.wikipedia.org/wiki/Atlas.ti), [MAXQDA](https://en.wikipedia.org/wiki/MAXQDA), [NVivo](https://en.wikipedia.org/wiki/NVivo), [QDA Miner](https://en.wikipedia.org/wiki/QDA_Miner), and [RQDA](https://en.wikipedia.org/wiki/RQDA).

After assembling codes it is time to organize them into broader themes and categories. The process generally involves identifying themes from the existing codes, reducing the themes to a manageable number, creating hierarchies within the themes and then linking themes together through theoretical modeling.[^o11]

:::

## Memos {#Memos}

Creating memos during the coding process is integral to both grounded and a priori coding approaches. Qualitative research is inherently reflexive; as the researcher delves deeper into their subject, it is important to chronicle their own thought processes through reflective or methodological memos, as doing so may highlight their own subjective interpretations of data.[^o13] It is crucial to begin memoing at the onset of research. Regardless of the type of memo produced, what is important is that the process initiates critical thinking and productivity in the research. Doing so will facilitate easier and more coherent analyses as the project draws on.[^o14] Memos can be used to map research activities, uncover meaning from data, maintaining research momentum and engagement and opening communication.[^o15]
