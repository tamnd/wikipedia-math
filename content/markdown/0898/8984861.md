# Spectral set

::: {#o1 .subject cue=lead name="Spectral set"}

In [operator theory](wikipedia://en/712675), a set $X\subseteq\mathbb{C}$ is said to be a **spectral set** for a (possibly [unbounded](https://en.wikipedia.org/wiki/Unbounded_linear_operator)) linear operator $T$ on a [Banach space](wikipedia://en/3989) if the [spectrum](https://en.wikipedia.org/wiki/Spectrum_of_an_operator) of $T$ is in $X$ and [von-Neumann's inequality](wikipedia://en/16244706) holds for $T$ on $X$ - i.e. for all rational functions $r(x)$ with no [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) on $X$

:::

$$\left\Vert r(T) \right\Vert \leq \left\Vert r \right\Vert_{X} = \sup \left\{\left\vert r(x) \right\vert : x\in X \right\}$$

This concept is related to the topic of analytic [functional calculus](wikipedia://en/965348) of operators. In general, one wants to get more details about the operators constructed from functions with the original operator as the variable.

For a detailed discussion of spectral sets and von Neumann's inequality, see.[^o2]
