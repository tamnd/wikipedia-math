# Dirichlet algebra

::: {#o1 .subject cue=lead name="Dirichlet algebra"}

In [mathematics](wikipedia://en/18831), a **Dirichlet algebra** is a particular type of [algebra](wikipedia://en/7184) associated to a [compact Hausdorff space](https://en.wikipedia.org/wiki/Compact_Hausdorff_space) *X*. It is a closed subalgebra of *C*(*X*), the [uniform algebra](wikipedia://en/4536974) of bounded [continuous functions](https://en.wikipedia.org/wiki/Continuous_functions) on *X*, whose real parts are dense in the algebra of bounded continuous real functions on *X*. The concept was introduced by (txt).

:::

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

Let $\mathcal{R}(X)$ be the set of all [rational functions](wikipedia://en/361210) that are continuous on $X$; in other words functions that have no [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) in $X$. Then

$$\mathcal{S} = \mathcal{R}(X) + \overline{\mathcal{R}(X)}$$

is a \*-subalgebra of $C(X)$, and of $C\left(\partial X\right)$. If $\mathcal{S}$ is [dense](wikipedia://en/23523594) in $C\left(\partial X\right)$, we say $\mathcal{R}(X)$ is a **Dirichlet algebra**.

It can be shown that if an operator $T$ has $X$ as a [spectral set](wikipedia://en/8984861), and $\mathcal{R}(X)$ is a Dirichlet algebra, then $T$ has a [normal boundary dilation](wikipedia://en/3319942). This generalises [Sz.-Nagy's dilation theorem](wikipedia://en/9750065), which can be seen as a consequence of this by letting

$$X=\mathbb{D}.$$

:::
