# Poly-Weibull distribution

::: {#o1 .subject cue=lead name="Poly-Weibull distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **poly-Weibull distribution** is a continuous probability distribution. The distribution is defined to be that of a [random variable](wikipedia://en/25685) defined to be the smallest of a number of [statistically independent](https://en.wikipedia.org/wiki/Statistical_independence) random variables having non-identical [Weibull distributions](wikipedia://en/206948).

:::
