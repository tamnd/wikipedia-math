# Bruhat order

::: {#o1 .subject cue=lead name="Bruhat order"}

In mathematics, the **Bruhat order** (also called the **strong order**, **strong Bruhat order**, **Chevalley order**, **Bruhat–Chevalley order**, or **Chevalley–Bruhat order**) is a [partial order](https://en.wikipedia.org/wiki/Partial_order) on the elements of a [Coxeter group](wikipedia://en/297004), that corresponds to the inclusion order on [Schubert varieties](https://en.wikipedia.org/wiki/Schubert_varieties).

:::

## History {#History}

The Bruhat order on the [Schubert varieties](wikipedia://en/10469987) of a [flag manifold](https://en.wikipedia.org/wiki/Flag_manifold) or a [Grassmannian](wikipedia://en/373810) was first studied by (Ehresmann 1934), and the analogue for more general [semisimple algebraic groups](https://en.wikipedia.org/wiki/Semisimple_algebraic_group) was studied by [Claude Chevalley](wikipedia://en/366040) in an unpublished manuscript from 1958, not published until 1994.[^n1] (Verma 1968) started the combinatorial study of the Bruhat order on the [Weyl group](wikipedia://en/296332), and introduced the name "Bruhat order" because of the relation to the [Bruhat decomposition](wikipedia://en/1139142) introduced by [François Bruhat](wikipedia://en/9169813).

The left and right weak Bruhat orderings were studied by (txt).

::: {#o8 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $(W, S)$ is a [Coxeter system](https://en.wikipedia.org/wiki/Coxeter_system) with generators $S$, then the Bruhat order is a partial order on the group $W$. The definition of Bruhat order relies on several other definitions: first, *[reduced word](https://en.wikipedia.org/wiki/Reduced_word)* for an element $w$ of $W$ is a minimum-length expression of $w$ as a product of elements of $S$, and the *length* $\ell(w)$ of $w$ is the length of its reduced words. Then the (strong) Bruhat order is defined by $u \le v$ if some substring of some (or every) reduced word for $v$ is a reduced word for $u$. (Here a substring is not necessarily a consecutive substring.)

There are two other related partial orders:

- the weak left (Bruhat) order is defined by $u \le_{L} v$ if some final substring of some reduced word for $v$ is a reduced word for $u$, and
- the weak right (Bruhat) order is defined by $u \le_{R} v$ if some initial substring of some reduced word for $v$ is a reduced word for $u$.

For more on the weak orders, see the article [Weak order of permutations](https://en.wikipedia.org/wiki/Weak_order_of_permutations).

:::

## Bruhat graph {#Bruhat_graph}

The Bruhat graph is a directed graph related to the (strong) Bruhat order. The vertex set is the set of elements of the Coxeter group and the edge set consists of directed edges $(u, v)$ whenever $u = tv$ for some reflection $t$ and $\ell(u) < \ell(v)$. One may view the graph as an edge-labeled directed graph with edge labels coming from the set of reflections. (One could also define the Bruhat graph using multiplication on the right; as graphs, the resulting objects are isomorphic, but the edge labelings are different.)

The strong Bruhat order on the symmetric group (permutations) has [Möbius function](https://en.wikipedia.org/wiki/Möbius_function_of_a_poset) given by $\mu(\pi,\sigma)=(-1)^{\ell(\sigma)-\ell(\pi)}$, and thus this poset is [Eulerian](wikipedia://en/26703335), meaning its Möbius function is produced by the rank function on the poset.
