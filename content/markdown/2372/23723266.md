# Subliminal channel

::: {#o1 .subject cue=lead name="Subliminal channel"}

In cryptography, **subliminal channels** are [covert channels](https://en.wikipedia.org/wiki/Covert_channels) that can be used to communicate secretly in normal looking communication over an [insecure channel](https://en.wikipedia.org/wiki/Insecure_channel).[^o2] Subliminal channels in [digital signature](wikipedia://en/59644) crypto systems were found in 1984 by [Gustavus Simmons](wikipedia://en/7440474).

:::

Simmons describes how the "Prisoners' Problem" can be solved through parameter substitution in [digital signature](wikipedia://en/59644) algorithms.[^o3]

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

An easy example of a narrowband subliminal channel for normal human-language text would be to define that an even word count in a sentence is associated with the bit "0" and an odd word count with the bit "1". The question "Hello, how do you do?" would therefore send the subliminal message "1".

The [Digital Signature Algorithm](wikipedia://en/59470) has one subliminal broadband[^o6] and three subliminal narrow-band channels[^o7]

:::

## Improvements {#Improvements}

A modification to the [Brickell and DeLaurentis signature scheme](https://en.wikipedia.org/wiki/Brickell_and_DeLaurentis_signature_scheme) provides a broadband channel without the necessity to share the authentication key.[^o9] The [Newton channel](https://en.wikipedia.org/wiki/Newton_channel) is not a subliminal channel, but it can be viewed as an enhancement.[^o10]

## Countermeasures {#Countermeasures}

With the help of the [zero-knowledge proof](wikipedia://en/450541) and the [commitment scheme](wikipedia://en/439489) it is possible to prevent the usage of the subliminal channel.[^o12][^o13]

This countermeasure has a 1-bit subliminal channel because for is the problem that a proof can succeed or purposely fail.[^o14]

Another countermeasure can detect, and not prevent, the subliminal usage of the randomness.[^o15]
