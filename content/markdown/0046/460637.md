# Continuous linear extension

::: {#o1 .subject cue=lead name="Continuous linear extension"}

In [functional analysis](wikipedia://en/11180), it is often convenient to define a [linear transformation](https://en.wikipedia.org/wiki/Linear_transformation) on a [complete](https://en.wikipedia.org/wiki/Complete_space), [normed vector space](wikipedia://en/21538) $X$ by first defining a linear transformation $L$ on a [dense](wikipedia://en/23523594) [subset](wikipedia://en/27631) of $X$ and then [continuously extending](https://en.wikipedia.org/wiki/Continuous_extension) $L$ to the whole space via the theorem below. The resulting extension remains [linear](wikipedia://en/18102) and [bounded](wikipedia://en/455961), and is thus [continuous](wikipedia://en/6122), which makes it a **continuous [linear extension](https://en.wikipedia.org/wiki/Linear_extension_%28linear_algebra%29)**.

:::

This procedure is known as **continuous linear extension**.

::: {#o3 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

Every bounded linear transformation $L$ from a normed vector space $X$ to a complete, normed vector space $Y$ can be uniquely extended to a bounded linear transformation $\widehat{L}$ from the [completion](https://en.wikipedia.org/wiki/Complete_space#Completion) of $X$ to $Y.$ In addition, the [operator norm](wikipedia://en/246722) of $L$ is $c$ [if and only if](wikipedia://en/14922) the norm of $\widehat{L}$ is $c.$

This theorem is sometimes called the **BLT theorem**.

:::

::: {#o5 .application cue=heading name="Application"}

## Application {#Application}

Consider, for instance, the definition of the [Riemann integral](wikipedia://en/26390). A [step function](wikipedia://en/170939) on a [closed](wikipedia://en/293802) [interval](wikipedia://en/49172) $[a,b]$ is a function of the form: $f\equiv r_1 \mathbf{1}_{[a,x_1)}+r_2 \mathbf{1}_{[x_1,x_2)} + \cdots + r_n \mathbf{1}_{[x_{n-1},b]}$ where $r_1, \ldots, r_n$ are real numbers, $a = x_0 < x_1 < \ldots < x_{n-1} < x_n = b,$ and $\mathbf{1}_S$ denotes the [indicator function](wikipedia://en/240790) of the set $S.$ The space of all step functions on $[a,b],$ normed by the $L^\infty$ norm (see [Lp space](wikipedia://en/45194)), is a normed vector space which we denote by $\mathcal{S}.$ Define the integral of a step function by:

$$I \left(\sum_{i=1}^n r_i \mathbf{1}_{ [x_{i-1},x_i)}\right) = \sum_{i=1}^n r_i (x_i-x_{i-1}).$$

$I$ as a function is a bounded linear transformation from $\mathcal{S}$ into $\mathbb{R}.$[^o6]

Let $\mathcal{PC}$ denote the space of bounded, [piecewise](https://en.wikipedia.org/wiki/Piecewise) continuous functions on $[a,b]$ that are continuous from the right, along with the $L^\infty$ norm. The space $\mathcal{S}$ is dense in $\mathcal{PC},$ so we can apply the BLT theorem to extend the linear transformation $I$ to a bounded linear transformation $\widehat{I}$ from $\mathcal{PC}$ to $\mathbb{R}.$ This defines the Riemann integral of all functions in $\mathcal{PC}$; for every $f\in \mathcal{PC},$ $\int_a^b f(x)dx=\widehat{I}(f).$

:::

::: {#o8 .statement kind=statement/theorem cue=named-heading name="The Hahn–Banach theorem"}

## The Hahn–Banach theorem {#The_Hahn–Banach_theorem}

The above theorem can be used to extend a bounded linear transformation $T : S \to Y$ to a bounded linear transformation from $\bar{S} = X$ to $Y,$ *if* $S$ is dense in $X.$ If $S$ is not dense in $X,$ then the [Hahn–Banach theorem](wikipedia://en/13860) may sometimes be used to show that an extension [exists](https://en.wikipedia.org/wiki/Existence). However, the extension may not be unique.

:::
