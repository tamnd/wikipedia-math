# Antiholomorphic function

::: {#o1 .subject cue=lead name="Antiholomorphic function"}

In [mathematics](wikipedia://en/18831), **antiholomorphic functions** (also called **antianalytic functions**[^o2]) are a family of [functions](wikipedia://en/185427) closely related to but distinct from [holomorphic functions](wikipedia://en/14110).

:::

A function of the complex variable $z$ defined on an [open set](wikipedia://en/39358) in the [complex plane](wikipedia://en/217628) is said to be **antiholomorphic** if its [derivative](wikipedia://en/7921) with respect to $\bar z$ exists in the neighbourhood of each and every point in that set, where $\bar z$ is the [complex conjugate](wikipedia://en/173918) of $z$.

A definition of antiholomorphic function follows:[^o2]

> "\[a\] function $f(z) = u + i v$ of one or more complex variables $z = \left(z_1, \dots, z_n\right) \in \mathbb{C}^n$ \[is said to be anti-holomorphic if (and only if) it\] is the complex conjugate of a holomorphic function $\overline{f \left(z\right)} = u - i v$."

One can show that if $f(z)$ is a [holomorphic function](wikipedia://en/14110) on an open set $D$, then $f(\bar z)$ is an antiholomorphic function on $\bar D$, where $\bar D$ is the reflection of $D$ across the real axis; in other words, $\bar D$ is the set of complex conjugates of elements of $D$. Moreover, any antiholomorphic function can be obtained in this manner from a holomorphic function. This implies that a function is antiholomorphic [if and only if](wikipedia://en/14922) it can be expanded in a [power series](wikipedia://en/59958) in $\bar z$ in a neighborhood of each point in its domain. Also, a function $f(z)$ is antiholomorphic on an open set $D$ if and only if the function $\overline{f(z)}$ is holomorphic on $D$.

If a function is both holomorphic and antiholomorphic, then it is constant on any [connected component](wikipedia://en/6233) of its domain.[^o3]
