# Vanish at infinity

::: {#o1 .subject cue=lead name="Vanish at infinity"}

In [mathematics](wikipedia://en/18831), a [function](wikipedia://en/185427) is said to **vanish at infinity** if its values approach 0 as the input grows without bounds. There are two different ways to define this with one definition applying to functions defined on [normed vector spaces](wikipedia://en/21538) and the other applying to functions defined on [locally compact spaces](wikipedia://en/48632). Aside from this difference, both of these notions correspond to the intuitive notion of adding a point at infinity, and requiring the values of the function to get arbitrarily close to zero as one approaches it. This definition can be formalized in many cases by adding an (actual) [point at infinity](https://en.wikipedia.org/wiki/Locally_compact#The_point_at_infinity).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A function $f:X\rightarrow\mathbb{C}$ on a [normed vector space](wikipedia://en/21538) $(X,\|\cdot\|)$ is said to **vanish at infinity** if the values of the function approach $0$ as the input grows without bounds (that is, $f(x) \to 0$ as $\|x\| \to \infty$), i.e.,

$$\lim_{\|x\| \to \infty} f(x) = 0.$$

On the real line $X = \mathbb{R}$, this simplifies to

$$\lim_{x \to -\infty} f(x) = \lim_{x \to +\infty} f(x) = 0.$$

For example, the function

$$f(x) = \frac{1}{x^2+1},$$

defined on the [real line](https://en.wikipedia.org/wiki/Real_line), vanishes at infinity.

Alternatively, a function $f:\Omega\rightarrow\mathbb{K}$ on a [locally compact space](wikipedia://en/48632) $\Omega$ **vanishes at infinity**, if given any [positive number](https://en.wikipedia.org/wiki/Positive_number) $\varepsilon > 0$, there exists a [compact](wikipedia://en/6042) subset $K \subseteq \Omega$ such that[^o4][^o5]

$$\forall x\in\Omega\setminus K\, ,\quad |f(x)| < \varepsilon.$$

In other words, for each positive number $\varepsilon > 0$, the set $\left\{ x \in \Omega : |f(x)| \geq \varepsilon \right\}$ has compact closure. For a given locally compact space $\Omega$, the [set](wikipedia://en/26691) of such functions

$$f : \Omega \to \mathbb{K}$$

valued in $\mathbb{K},$ which is either $\mathbb{R}$ or $\mathbb{C},$ forms a $\mathbb{K}$-[vector space](wikipedia://en/32370) with respect to [pointwise](wikipedia://en/4786797) [scalar multiplication](wikipedia://en/244373) and [addition](wikipedia://en/61338), which is often denoted $C_0(\Omega).$

As an example, the function

$$h(x, y) = \frac{1}{x+y}$$

where $x$ and $y$ are [reals](wikipedia://en/20646438) greater or equal 1 and correspond to the point $(x, y)$ on $\mathbb{R}_{\ge 1}^2$ vanishes at infinity.

A [normed space](https://en.wikipedia.org/wiki/Normed_space) is locally compact if and only if it is finite-dimensional so in this particular case, there are two different definitions of a function "vanishing at infinity". The two definitions could be inconsistent with each other: if $f(x) = \|x\|^{-1}$ in an infinite dimensional [Banach space](wikipedia://en/3989), then $f$ vanishes at infinity by the $\|f(x)\| \to 0$ definition, but not by the compact set definition.

:::

## Rapidly decreasing {#Rapidly_decreasing}

Refining the concept, one can look more closely to the rate of vanishing of functions at infinity. One of the basic intuitions of [mathematical analysis](wikipedia://en/48396) is that the [Fourier transform](wikipedia://en/52247) interchanges [smoothness](https://en.wikipedia.org/wiki/Smooth_function) conditions with rate conditions on vanishing at infinity. Using [big *O* notation](wikipedia://en/44578), the **rapidly decreasing** test functions of [tempered distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29#Tempered_distributions_and_Fourier_transform) theory are [smooth functions](https://en.wikipedia.org/wiki/Smooth_function) that are

$$O\left(|x|^{-N}\right)$$

for all $N$, as $|x| \to \infty$, and such that all their [partial derivatives](wikipedia://en/52565) satisfy the same condition too. This condition is set up so as to be self-dual under Fourier transform, so that the corresponding [distribution theory](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) of tempered distributions will have the same property.
