# System of parameters

::: {#o1 .subject cue=lead name="System of parameters"}

In [mathematics](wikipedia://en/18831), a **system of parameters** for a [local](wikipedia://en/153391) [Noetherian ring](wikipedia://en/56129) of [Krull dimension](wikipedia://en/56079) *d* with [maximal ideal](wikipedia://en/48164) *m* is a set of elements *x*<sub>1</sub>, ..., *x*<sub>*d*</sub> that satisfies any of the following equivalent conditions:

:::

1. *m* is a [minimal prime](wikipedia://en/16143832) over (*x*<sub>1</sub>, ..., *x*<sub>*d*</sub>).
1. The [radical](wikipedia://en/252009) of (*x*<sub>1</sub>, ..., *x*<sub>*d*</sub>) is *m*.
1. Some power of *m* is contained in (*x*<sub>1</sub>, ..., *x*<sub>*d*</sub>).
1. (*x*<sub>1</sub>, ..., *x*<sub>*d*</sub>) is [*m*-primary](wikipedia://en/3021435).
1. R/(*x*<sub>1</sub>, ..., *x*<sub>*d*</sub>) is an [Artinian ring](wikipedia://en/489273).

Every local Noetherian ring admits a system of parameters.[^o2]

It is not possible for fewer than *d* elements to generate an ideal whose radical is *m* because then the dimension of *R* would be less than *d*.

If *M* is a *k*-dimensional module over a local ring, then *x*<sub>1</sub>, ..., *x*<sub>*k*</sub> is a **system of parameters** for *M* if the [length](wikipedia://en/816070) of *M* / (*x*<sub>1</sub>, ..., *x*<sub>*k*</sub>) *M* is finite.
