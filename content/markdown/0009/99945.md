# Generating set of a group

::: {#o1 .subject cue=lead name="Generating set of a group"}

*Image: One5Root.svg.* The 5th [roots of unity](https://en.wikipedia.org/wiki/Roots_of_unity) in the complex plane form a [group](wikipedia://en/19447) under multiplication. Each non-identity element generates the group.

In [abstract algebra](wikipedia://en/19616384), a **generating set of a group** is a [subset](wikipedia://en/27631) of the group set such that every element of the [group](wikipedia://en/19447) can be expressed as a combination (under the group operation) of finitely many elements of the subset and their [inverses](wikipedia://en/45199).

:::

In other words, if $S$ is a subset of a group $G$, then $\langle S\rangle$, the *subgroup generated by $S$*, is the smallest [subgroup](wikipedia://en/28011) of $G$ containing every element of $S$, which is equal to the intersection over all subgroups containing the elements of $S$; equivalently, $\langle S\rangle$ is the subgroup of all elements of $G$ that can be expressed as the finite product of elements in $S$ and their inverses. (Note that inverses are only needed if the group is infinite; in a finite group, the inverse of an element can be expressed as a power of that element.)

If $G=\langle S\rangle$, then we say that $S$ *generates* $G$, and the elements in $S$ are called *generators* or *group generators*. If $S$ is the empty set, then $\langle S\rangle$ is the [trivial group](wikipedia://en/193059) $\{e\}$, since we consider the [empty product](wikipedia://en/181289) to be the identity.

When there is only a single element $x$ in $S$, $\langle S\rangle$ is usually written as $\langle x\rangle$. In this case, $\langle x\rangle$ is the *cyclic subgroup* of the powers of $x$, a [cyclic group](wikipedia://en/52327), and we say this group is generated by $x$. Equivalent to saying an element $x$ generates a group is saying that $\langle x\rangle$ equals the entire group $G$. For [finite groups](wikipedia://en/323707), it is also equivalent to saying that $x$ has [order](wikipedia://en/493527) $|G|$.

A group may need an infinite number of generators. For example, the additive group of [rational numbers](wikipedia://en/19727024) $\mathbb{Q}$ is not finitely generated. It is generated by the inverses of all the integers, but any finite number of these generators can be removed from the generating set without it ceasing to be a generating set. In a case like this, all the elements in a generating set are nevertheless "non-generating elements", as are in fact all the elements of the whole group − see [Frattini subgroup](wikipedia://en/540707) below.

If $G$ is a [topological group](wikipedia://en/42315) then a subset $S$ of $G$ is called a set of *topological generators* if $\langle S\rangle$ is [dense](wikipedia://en/23523594) in $G$, i.e. the [closure](wikipedia://en/42309) of $\langle S\rangle$ is the whole group $G$.

## Finitely generated group {#Finitely_generated_group}

If $S$ is finite, then a group $G=\langle S\rangle$ is called *finitely generated*. The structure of [finitely generated abelian groups](wikipedia://en/58527) in particular is easily described. Many theorems that are true for finitely generated groups fail for groups in general. It has been proven that if a finite group is generated by a subset $S$, then each group element may be expressed as a word from the alphabet $S$ of length less than or equal to the order of the group.

Every finite group is finitely generated since $\langle G\rangle =G$. The [integers](wikipedia://en/14563) under addition are an example of an [infinite group](wikipedia://en/4587030) which is finitely generated by both 1 and −1, but the group of [rationals](wikipedia://en/19727024) under addition cannot be finitely generated. No [uncountable](https://en.wikipedia.org/wiki/Uncountable) group can be finitely generated. For example, the group of real numbers under addition, $(\mathbb{R},+)$.

Different subsets of the same group can be generating subsets. For example, if $p$ and $q$ are integers with $\gcd(p, q) = 1$, then $\{p,q\}$ also generates the group of integers under addition by [Bézout's identity](wikipedia://en/4947).

While it is true that every [quotient](wikipedia://en/11526) of a [finitely generated group](wikipedia://en/963042) is finitely generated (the images of the generators in the quotient give a finite generating set), a [subgroup](wikipedia://en/28011) of a finitely generated group need not be finitely generated. For example, let $G$ be the [free group](wikipedia://en/59735) in two generators, $x$ and $y$ (which is clearly finitely generated, since $G=\langle \{x,y\}\rangle$), and let $S$ be the subset consisting of all elements of $G$ of the form $y^nxy^{-n}$ for some [natural number](wikipedia://en/21474) $n$. $\langle S\rangle$ is [isomorphic](wikipedia://en/14828) to the free group in countably infinitely many generators, and so cannot be finitely generated. However, every subgroup of a finitely generated [abelian group](wikipedia://en/2974) is in itself finitely generated. In fact, more can be said: the class of all finitely generated groups is closed under [extensions](wikipedia://en/345807). To see this, take a generating set for the (finitely generated) [normal subgroup](wikipedia://en/21918) and quotient. Then the generators for the normal subgroup, together with preimages of the generators for the quotient, generate the group.

## Examples {#Examples}

- The [multiplicative group of integers modulo 9](wikipedia://en/1195234), $U_{9} = \{1, 2, 4, 5, 7, 8\}$, is the group of all integers [relatively prime](https://en.wikipedia.org/wiki/Coprime) to 9 under multiplication $\bmod 9$. The element 7 is not a generator of $U_{9}$, since $$\{7^i \bmod 9 \mid i \in \mathbb{N}\} = \{7,4,1\},$$ while 2 is, since $$\{2^i \bmod 9 \mid i \in \mathbb{N}\} = \{2,4,8,7,5,1\}.$$
- The [symmetric group](wikipedia://en/28901) *S*<sub>*n*</sub> of degree *n* is not generated by any one element (is not [cyclic](wikipedia://en/52327)) when *n* > 2. However, in these cases *S*<sub>*n*</sub> can always be generated by two permutations: in [cycle notation](wikipedia://en/44027#Cycle_notation), the [transposition](https://en.wikipedia.org/wiki/Transposition_%28mathematics%29) (1 2) and the cycle $(1 2 3 ... n)$ form a generating set. For example, the 6 elements of *S*<sub>3</sub> can be generated from the two generators, (1 2) and (1 2 3), as shown by the right hand side of the following equations (composition is left-to-right):

*e* = (1 2)(1 2)

(1 2) = (1 2)

(1 3) = (1 2)(1 2 3)

(2 3) = (1 2 3)(1 2)

(1 2 3) = (1 2 3)

(1 3 2) = (1 2)(1 2 3)(1 2)

- Infinite groups can have finite generating sets. The additive group of integers has 1 as a generating set. The element 2 is not a generating set, as the odd numbers will be missing. The two-element subset $\{3, 5\}$ is a generating set, since $(-5) + 3 + 3 = 1$ (in fact, any pair of [coprime](wikipedia://en/6556) numbers is, as a consequence of [Bézout's identity](wikipedia://en/4947)).
- The [dihedral group](wikipedia://en/100267) of an [*n*-gon](wikipedia://en/23621) (which has [order](wikipedia://en/493527) $2n$) is generated by the set $\{r, s\}$, where $r$ represents rotation by $2\pi/n$ and $s$ is any reflection across a line of symmetry.[^o5]
- The [cyclic group](wikipedia://en/52327) of order $n$, $\mathbb{Z}/n\mathbb{Z}$, and the $n$<sup>th</sup> [roots of unity](wikipedia://en/171950) are all generated by a single element (in fact, these groups are [isomorphic](wikipedia://en/12397) to one another).[^o6]
- A [presentation of a group](wikipedia://en/99494) is defined as a set of generators and a collection of relations between them, so any of the examples listed on that page contain examples of generating sets.[^o7]

:::

## Free group {#Free_group}

The most general group generated by a set $S$ is the group [freely generated](wikipedia://en/59735) by $S$. Every group generated by $S$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to a [quotient](wikipedia://en/11526) of this group, a feature which is utilized in the expression of a group's [presentation](wikipedia://en/99494).

## Frattini subgroup {#Frattini_subgroup}

An interesting companion topic is that of *non-generators*. An element $x$ of the group $G$ is a non-generator if every set $S$ containing $x$ that generates $G$, still generates $G$ when $x$ is removed from $S$. In the integers with addition, the only non-generator is 0. The set of all non-generators forms a subgroup of $G$, the [Frattini subgroup](wikipedia://en/540707).

## Semigroups and monoids {#Semigroups_and_monoids}

If $G$ is a [semigroup](wikipedia://en/27799) or a [monoid](wikipedia://en/19652), one can still use the notion of a generating set $S$ of $G$. $S$ is a semigroup/monoid generating set of $G$ if $G$ is the smallest semigroup/monoid containing $S$.

The definitions of generating set of a group using finite sums, given above, must be slightly modified when one deals with semigroups or monoids. Indeed, this definition should not use the notion of inverse operation anymore. The set $S$ is said to be a semigroup generating set of $G$ if each element of $G$ is a finite sum of elements of $S$. Similarly, a set $S$ is said to be a monoid generating set of $G$ if each non-zero element of $G$ is a finite sum of elements of $S$.

For example, {1} is a monoid generator of the set of [natural numbers](wikipedia://en/21474) $\mathbb{N}$. The set {1} is also a semigroup generator of the positive natural numbers $\mathbb{N}_{>0}$. However, the integer 0 can not be expressed as a (non-empty) sum of 1s, thus {1} is not a semigroup generator of the natural numbers.

Similarly, while {1} is a group generator of the set of [integers](wikipedia://en/14563) $\mathbb Z$, {1} is not a monoid generator of the set of integers. Indeed, the integer −1 cannot be expressed as a finite sum of 1s.
