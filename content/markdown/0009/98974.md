# Linear classifier

::: {#o1 .subject cue=lead name="Linear classifier"}

In [machine learning](wikipedia://en/233488), a **linear classifier** makes a [classification](wikipedia://en/1579244) decision for each object based on a [linear combination](wikipedia://en/55632) of its [features](https://en.wikipedia.org/wiki/Feature_%28machine_learning%29). A simpler definition is to say that a linear classifier is one whose decision boundaries are *linear*. Such classifiers work well for practical problems such as [document classification](https://en.wikipedia.org/wiki/Document_classification), and more generally for problems with many variables ([features](https://en.wikipedia.org/wiki/Feature_vector)), reaching accuracy levels comparable to non-linear classifiers while taking less time to train and use.

:::

## Definition {#Definition}

*Image: Svm separating hyperplanes.png.* In this case, the solid and empty dots can be correctly classified by any number of linear classifiers. H1 (blue) classifies them correctly, as does H2 (red). H2 could be considered "better" in the sense that it is also furthest from both groups. H3 (green) fails to correctly classify the dots.

If the input feature vector to the classifier is a [real](wikipedia://en/20646438) vector $\vec x$, then the output score is

$$y = f(\vec{w}\cdot\vec{x}) = f\left(\sum_j w_j x_j\right),$$

where $\vec w$ is a real vector of weights and *f* is a function that converts the [dot product](wikipedia://en/157093) of the two vectors into the desired output. (In other words, $\vec{w}$ is a [one-form](wikipedia://en/314692) or [linear functional](https://en.wikipedia.org/wiki/Linear_functional) mapping $\vec x$ onto **R**.) The weight vector $\vec w$ is learned from a set of labeled training samples. Often *f* is a **threshold function**, which maps all values of $\vec{w}\cdot\vec{x}$ above a certain threshold to the first class and all other values to the second class; e.g.,

$$f(\mathbf{x}) = \begin{cases}1 & \text{if }\ \mathbf{w}^T \cdot \mathbf{x} > \theta,\\0 & \text{otherwise}\end{cases}$$

The superscript T indicates the transpose and $\theta$ is a scalar threshold. A more complex *f* might give the probability that an item belongs to a certain class.

For a two-class classification problem, one can visualize the operation of a linear classifier as splitting a [high-dimensional](https://en.wikipedia.org/wiki/High-dimensional_space) input space with a [hyperplane](wikipedia://en/99862): all points on one side of the hyperplane are classified as "yes", while the others are classified as "no".

A linear classifier is often used in situations where the speed of classification is an issue, since it is often the fastest classifier, especially when $\vec x$ is sparse. Also, linear classifiers often work very well when the number of dimensions in $\vec x$ is large, as in [document classification](https://en.wikipedia.org/wiki/Document_classification), where each element in $\vec x$ is typically the number of occurrences of a word in a document (see [document-term matrix](https://en.wikipedia.org/wiki/Document-term_matrix)). In such cases, the classifier should be well-[regularized](https://en.wikipedia.org/wiki/Regularization_%28machine_learning%29).

## Generative models vs. discriminative models {#Generative_models_vs._discriminative_models}

There are two broad classes of methods for determining the parameters of a linear classifier $\vec w$. They can be [generative](wikipedia://en/1222578) and [discriminative](wikipedia://en/12155912) models.[^o5][^o6] Methods of the former model [joint probability distribution](wikipedia://en/879637), whereas methods of the latter model [conditional density functions](wikipedia://en/504458) $P({\rm class}|\vec x)$. Examples of such algorithms include:

- [Linear Discriminant Analysis](wikipedia://en/1470657) (LDA)—assumes [Gaussian](wikipedia://en/21462) conditional density models
- [Naive Bayes classifier](wikipedia://en/87339) with multinomial or multivariate Bernoulli event models.

The second set of methods includes [discriminative models](wikipedia://en/12155912), which attempt to maximize the quality of the output on a [training set](https://en.wikipedia.org/wiki/Training_set). Additional terms in the training cost function can easily perform [regularization](https://en.wikipedia.org/wiki/Regularization_%28machine_learning%29) of the final model. Examples of discriminative training of linear classifiers include:

- [Logistic regression](wikipedia://en/226631)—maximum likelihood estimation of $\vec w$ assuming that the observed training set was generated by a binomial model that depends on the output of the classifier.
- [Perceptron](wikipedia://en/172777)—an algorithm that attempts to fix all errors encountered in the training set
- Fisher's Linear Discriminant Analysis—an algorithm (different than "LDA") that maximizes the ratio of between-class scatter to within-class scatter, without any other assumptions. It is in essence a method of dimensionality reduction for binary classification.[^o7]
- [Support vector machine](wikipedia://en/65309)—an algorithm that maximizes the [margin](https://en.wikipedia.org/wiki/Margin_%28machine_learning%29) between the decision hyperplane and the examples in the training set.

**Note:** Despite its name, LDA does not belong to the class of discriminative models in this taxonomy. However, its name makes sense when we compare LDA to the other main linear [dimensionality reduction](wikipedia://en/579867) algorithm: [principal components analysis](https://en.wikipedia.org/wiki/Principal_components_analysis) (PCA). LDA is a [supervised learning](wikipedia://en/20926) algorithm that utilizes the labels of the data, while PCA is an [unsupervised learning](wikipedia://en/233497) algorithm that ignores the labels. To summarize, the name is a historical artifact.[^o8]

Discriminative training often yields higher accuracy than modeling the conditional density functions. However, handling missing data is often easier with conditional density models.

All of the linear classifier algorithms listed above can be converted into non-linear algorithms operating on a different input space $\varphi(\vec x)$, using the [kernel trick](https://en.wikipedia.org/wiki/Kernel_trick).

### Discriminative training {#Discriminative_training}

Discriminative training of linear classifiers usually proceeds in a [supervised](wikipedia://en/20926) way, by means of an [optimization algorithm](https://en.wikipedia.org/wiki/Optimization_algorithm) that is given a training set with desired outputs and a [loss function](wikipedia://en/442137) that measures the discrepancy between the classifier's outputs and the desired outputs. Thus, the learning algorithm solves an optimization problem of the form[^o10]

$$\underset{\mathbf{w}}{\arg\min} \;R(\mathbf{w}) + C \sum_{i=1}^N L(y_i, \mathbf{w}^\mathsf{T} \mathbf{x}_i)$$

where

- $\mathbf{w}$ is a vector of classifier parameters,
- $L(y_{i}, \mathbf{w}^{T}\mathbf{x}_{i})$ is a loss function that measures the discrepancy between the classifier's prediction and the true output $y_{i}$ for the $i$'th training example,
- $R(\mathbf{w})$ is a [regularization](wikipedia://en/2009061) function that prevents the parameters from getting too large (causing [overfitting](wikipedia://en/173332)), and
- $C$ is a scalar constant (set by the user of the learning algorithm) that controls the balance between the regularization and the loss function.

Popular loss functions include the [hinge loss](wikipedia://en/33100241) (for linear SVMs) and the [log loss](https://en.wikipedia.org/wiki/Log_loss) (for linear logistic regression). If the regularization function $R$ is [convex](wikipedia://en/245568), then the above is a [convex problem](wikipedia://en/1674411). Many algorithms exist for solving such problems; popular ones for linear classification include ([stochastic](wikipedia://en/1180641)) [gradient descent](wikipedia://en/201489), [L-BFGS](https://en.wikipedia.org/wiki/L-BFGS), [coordinate descent](wikipedia://en/33837524) and [Newton methods](https://en.wikipedia.org/wiki/Newton_method).
