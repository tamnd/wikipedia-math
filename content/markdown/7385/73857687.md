# Zero-sum Ramsey theory

::: {#o1 .subject cue=lead name="Zero-sum Ramsey theory"}

In mathematics, **zero-sum Ramsey theory** or **zero-sum theory** is a branch of [combinatorics](wikipedia://en/5170). It deals with problems of the following kind: given a [combinatorial](https://en.wikipedia.org/wiki/Combinatorial) structure whose elements are assigned different weights (usually elements from an [Abelian group](wikipedia://en/2974) $A$), one seeks for conditions that guarantee the existence of certain substructure whose weights of its elements sum up to zero (in $A$). It combines tools from [number theory](wikipedia://en/21527), [algebra](wikipedia://en/18716923), [linear algebra](wikipedia://en/18422), [graph theory](wikipedia://en/12401), [discrete analysis](https://en.wikipedia.org/wiki/Discrete_analysis), and other branches of mathematics.

:::

The classic result in this area is the 1961 theorem of [Paul Erdős](wikipedia://en/601284), [Abraham Ginzburg](https://en.wikipedia.org/wiki/Abraham_Ginzburg), and [Abraham Ziv](wikipedia://en/45030219):[^o2] for any $2m - 1$ elements of $\mathbb{Z}_m$, there is a subset of size $m$ that sums to zero.[^o3] (This bound is tight, as a sequence of $m - 1$ zeroes and $m - 1$ ones cannot have any subset of size $m$ summing to zero.[^o3]) There are known proofs of this result using the [Cauchy-Davenport theorem](https://en.wikipedia.org/wiki/Cauchy-Davenport_theorem), [Fermat's little theorem](wikipedia://en/53453), or the [Chevalley–Warning theorem](wikipedia://en/2934314).[^o3]

Generalizing this result, one can define for any abelian group *G* the minimum quantity $EGZ(G)$ of elements of *G* such that there must be a subsequence of $o(G)$ elements (where $o(G)$ is the order of the group) which adds to zero. It is known that $EGZ(G)\leq 2o(G) - 1$, and that this bound is strict if and only if $G = \mathbb{Z}_m$.[^o3]
