# Codd's theorem

::: {#o1 .subject cue=lead name="Codd's theorem"}

**Codd's theorem** states that [relational algebra](wikipedia://en/175285) and the domain-independent [relational calculus](https://en.wikipedia.org/wiki/Relational_calculus) queries, two well-known foundational query languages for the relational model, are precisely equivalent in expressive power. That is, a database query can be formulated in one language if and only if it can be expressed in the other.

:::

The theorem is named after [Edgar F. Codd](https://en.wikipedia.org/wiki/Edgar_F._Codd), the father of the [relational model](https://en.wikipedia.org/wiki/Relational_model) for database management.

The domain independent [relational calculus](https://en.wikipedia.org/wiki/Relational_calculus) queries are precisely those relational calculus queries that are invariant under choosing domains of values beyond those appearing in the database itself. That is, queries that may return different results for different domains are excluded. An example of such a forbidden query is the query "select all tuples other than those occurring in relation R", where R is a relation in the database. Assuming different domains, i.e., sets of atomic data items from which tuples can be constructed, this query returns different results and thus is clearly not domain independent.

Codd's Theorem is notable since it establishes the equivalence of two syntactically quite dissimilar languages: [relational algebra](wikipedia://en/175285) is a variable-free language, while relational calculus is a logical language with variables and [quantification](wikipedia://en/43507282).

Relational calculus is essentially equivalent to first-order logic,[^o2] and indeed, Codd's Theorem had been known to logicians since the late 1940s.[^o3][^o4]

Query languages that are equivalent in expressive power to relational algebra were called **relationally complete** by Codd. By Codd's Theorem, this includes relational calculus. Relational completeness clearly does not imply that any interesting database query can be expressed in relationally complete languages. Well-known examples of inexpressible queries include simple [aggregations](https://en.wikipedia.org/wiki/Aggregate_function) (counting tuples, or summing up values occurring in tuples, which are operations expressible in SQL but not in relational algebra) and computing the [transitive closure](wikipedia://en/292239) of a graph given by its binary edge relation (see also [expressive power](https://en.wikipedia.org/wiki/Expressive_power_%28computer_science%29)). Codd's theorem also doesn't consider [SQL nulls](https://en.wikipedia.org/wiki/Null_%28SQL%29) and the [three-valued logic](wikipedia://en/249904) they entail; the logical treatment of nulls remains mired in controversy.[^o5] Additionally, SQL has [multiset](wikipedia://en/305303) semantics as allowing duplicate rows. Nevertheless, relational completeness constitutes an important yardstick by which the expressive power of query languages can be compared.
