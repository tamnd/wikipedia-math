# Griewank function

*Image: 1st order Griewank function.png.* 2D Plot of the one dimensional Griewank function

::: {#o1 .subject cue=lead name="Griewank function"}

In [mathematics](wikipedia://en/18831), the **Griewank [test function](wikipedia://en/37526558)** is a [smooth](wikipedia://en/1408000) multidimensional mathematical function used in unconstrained [optimization](wikipedia://en/52033). It is commonly employed to evaluate the performance of [global optimization](wikipedia://en/563854) algorithms. The function is defined as[^o2]

:::

$$f(x) = 1 + \frac{1}{4000}\sum_{i=1}^n x_i^2 - \prod_{i=1}^n P_i(x_i),$$

where $x = (x_1,\dots,x_n) \in \mathbb{R}^n$ and $P_i(x_i)=\cos(x_i/\sqrt{i})$. The non-linear and [non-convex](wikipedia://en/245568) function is characterized by its unique multimodal structure, featuring multiple local [minima and maxima](wikipedia://en/298420) around its single global minimum at $x^\ast = 0$, where the function has minimal value $f(x^\ast) = 0$. The number of stationary points increases as the dimensionality $n$ grows.

*Image: Griewank function 3D plot.png.* 3D plot of the two dimensional Griewank function

For instance, the one-dimensional Griewank function $f(x_1) = 1+(1/4000)\cdot x_1^2-\cos(x_1)$ has 6365 [critical points](wikipedia://en/1951424) in the interval $[-10000,10000]$, where the first derivative vanishes. These points satisfy the equation

$$\nabla f(x_1) = \frac{1}{2000} \cdot x_1 + \sin(x_1) = 0.$$

*Image: 2nd order Griewank function contour plot.png.* Contour plot of the two dimensional Griewank function

The multimodal structure of the Griewank function presents a challenge for many [deterministic](https://en.wikipedia.org/wiki/Deterministic_algorithm) optimization algorithms, which may become trapped in one of the numerous local minima. This is particularly problematic for [gradient](wikipedia://en/12461)-based methods. The Griewank function is commonly used to benchmark global optimization algorithms, such as [genetic algorithms](https://en.wikipedia.org/wiki/Genetic_algorithms) or [particle swarm optimization](https://en.wikipedia.org/wiki/Particle_swarm_optimization). In addition to the original version, there are several variants of the Griewank function specifically designed to test algorithms in high-dimensional optimization scenarios.[^o3]

## Non-smooth variant {#Non-smooth_variant}

A non-smooth version of the Griewank function has been developed to emulate the characteristics of objective functions frequently encountered in optimization problems from [machine learning](wikipedia://en/233488).[^o5] These functions often exhibit [piecewise](wikipedia://en/404130) smooth or non-smooth behavior due to the presence of [regularization terms](wikipedia://en/2009061), [activation functions](https://en.wikipedia.org/wiki/Activation_function), or constraints in learning models.

A non-smooth variant of the Griewank function is the following:

$$f(x) = 1 + \frac{1}{4000} \sum_{i=1}^n x_i^2 - \prod_{i=1}^n P_i(x_i) \text{ with } P_i(x_i)=\left| \cos\left(\frac{x_i}{2\sqrt{i}}\right) \right| - \left| \sin\left(\frac{x_i}{2\sqrt{i}}\right) \right|.$$

By incorporating non-smooth elements, such as absolute values in the cosine and sine terms, this function mimics the irregularities present in many ML loss landscapes. It offers a robust benchmark for evaluating optimization algorithms, especially those designed to handle the challenges of non-convex, non-smooth, or high-dimensional problems, including sub-gradient, hybrid, and evolutionary methods.

The function's resemblance to practical ML objective functions makes it particularly valuable for testing the robustness and efficiency of algorithms in tasks such as [hyperparameter tuning](https://en.wikipedia.org/wiki/Hyperparameter_tuning), neural network training, and constrained optimization.
