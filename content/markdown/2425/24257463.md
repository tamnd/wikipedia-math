# Solinas prime

::: {#o1 .subject cue=lead name="Solinas prime"}

In [mathematics](wikipedia://en/18831), a **Solinas prime,** or **generalized Mersenne prime**, is a [prime number](wikipedia://en/23666) that has the form $f(2^m)$, where $f(x)$ is a low-[degree](wikipedia://en/5930652) [polynomial](wikipedia://en/23000) with small [integer](wikipedia://en/14563) [coefficients](wikipedia://en/51203).[^o2][^o3] These primes allow fast modular reduction algorithms and are widely used in [cryptography](wikipedia://en/18934432). They are named after Jerome Solinas.

:::

This class of numbers encompasses a few other categories of prime numbers:

- [Mersenne primes](https://en.wikipedia.org/wiki/Mersenne_primes), which have the form $2^k-1$,
- Crandall or pseudo-Mersenne primes, which have the form $2^k-c$ for small [odd](wikipedia://en/143135) $c$,[^o4] including $c=$ 3 , 5 , 7 , 9 , etc.

## Modular reduction algorithm {#Modular_reduction_algorithm}

Let $f(t) = t^d - c_{d-1}t^{d-1} - ... - c_0$ be a [monic polynomial](wikipedia://en/314730) of degree $d$ with coefficients in $\mathbb{Z}$ and suppose that $p = f(2^m)$ is a Solinas prime. Given a number $n < p^2$ with up to $2md$ bits, we want to find a number [congruent](wikipedia://en/20087) to $n$ mod $p$ with only as many bits as $p$ – that is, with at most $md$ bits.

First, represent $n$ in base $2^m$:

$$n = \sum_{j=0}^{2d-1}A_j2^{mj}$$

Next, generate a $d$-by-$d$ [matrix](wikipedia://en/20556859) $X = (X_{i,j})$ by stepping $d$ times the [linear-feedback shift register](wikipedia://en/58992) defined over $\mathbb{Z}$ by the polynomial $f$: starting with the $d$-integer register $[0 | 0 |...| 0 | 1]$, shift right one position, injecting $0$ on the left and adding (component-wise) the output value times the vector $[c_0,...,c_{d-1}]$ at each step (see \[1\] for details). Let $X_{i,j}$ be the integer in the $j$th register on the $i$th step and note that the first row of $X$ is given by $(X_{0,j}) = [c_0,...,c_{d-1}]$. Then if we denote by $B = (B_i)$ the integer vector given by:

$$(B_0 ... B_{d-1}) = (A_0 ... A_{d-1}) + (A_d ... A_{2d-1})X,$$

it can be easily checked that:

$$\sum_{j=0}^{d-1}B_j2^{mj}\equiv\sum_{j=0}^{2d-1}A_j2^{mj} \mod p.$$

Thus $B$ represents an $md$-bit integer congruent to $n$.

For judicious choices of $f$ (again, see \[1\]), this algorithm involves only a relatively small number of additions and subtractions (and no divisions!), so it can be much more efficient than the naive modular reduction algorithm ($n - p \cdot (n / p)$).

## Examples {#Examples}

In 1999, [NIST](https://en.wikipedia.org/wiki/NIST) recommended four Solinas primes as moduli for [elliptic curve cryptography](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography):[^o8]

- curve p-192 uses modulus $2^{192} - 2^{64} - 1$
- curve p-224 uses modulus $2^{224} - 2^{96} + 1$
- curve p-256 uses modulus $2^{256} - 2^{224} + 2^{192} + 2^{96} -1$
- curve p-384 uses modulus $2^{384} - 2^{128} - 2^{96} + 2^{32} - 1$.

A newer [Curve448](wikipedia://en/56665655) uses modulus $2^{448} - 2^{224} - 1$.

A Solinas prime that fits into a typical 64-bit unsigned integer is $2^{64}-2^{32}+1$, it is $\Phi_{192}(2)$ where $\Phi$ is the [cyclotomic polynomial](wikipedia://en/171992), thus it is a [unique prime](https://en.wikipedia.org/wiki/Unique_prime) in [base 2](https://en.wikipedia.org/wiki/Binary_numeral_system) (with [period length](https://en.wikipedia.org/wiki/Period_length) 192). This size is too small for cryptography, but finds use in implementing a [number-theoretic transform](https://en.wikipedia.org/wiki/Number-theoretic_transform) for efficient multiplication of large numbers.[^o9]

A complete list of $f(2^k)=2^m - 2^n \pm 1$ with $m \leq 2000$, a small modular reduction weight $wt < 15$, and $k=8,16,32,64$ (i.e. multiples of a [computer word](https://en.wikipedia.org/wiki/Computer_word) size) was produced by José de Jesús Angel Angel and Guillermo Morales-Luna in 2010.[^o10]

The [Curve25519](wikipedia://en/17935444) uses $2^{255} - 19$, which has also been called pseudo-Mersenne.[^o11]
