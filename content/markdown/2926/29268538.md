# Unital map

::: {#o1 .subject cue=lead name="Unital map"}

In [abstract algebra](wikipedia://en/19616384), a **unital map** on a [C\*-algebra](wikipedia://en/7184) is a map $\phi$ which preserves the identity element:

:::

$$\phi ( I ) = I.$$

This condition appears often in the context of [completely positive maps](wikipedia://en/6083511), especially when they represent [quantum operations](wikipedia://en/666107).

If $\phi$ is completely positive, it can always be represented as

$$\phi ( \rho ) = \sum_i E_i \rho E_i^\dagger.$$

(The $E_i$ are the [Kraus operators](https://en.wikipedia.org/wiki/Kraus_operator) associated with $\phi$). In this case, the unital condition can be expressed as

$$\sum_i E_i E_i ^\dagger= I.$$
