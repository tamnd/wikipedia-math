# Matrix consimilarity

::: {#o1 .subject cue=lead name="Matrix consimilarity"}

In [linear algebra](wikipedia://en/18422), two *n*-by-*n* [matrices](wikipedia://en/20556859) *A* and *B* are called **consimilar** if

:::

$$A = S B \bar{S}^{-1} \,$$

for some invertible $n \times n$ matrix $S$, where $\bar{S}$ denotes the elementwise [complex conjugation](https://en.wikipedia.org/wiki/Complex_conjugation). So for real matrices similar by some real matrix $S$, consimilarity is the same as [matrix similarity](wikipedia://en/341149).

Like ordinary similarity, consimilarity is an [equivalence relation](wikipedia://en/9259) on the set of $n \times n$ matrices, and it is reasonable to ask what properties it preserves.

The theory of ordinary similarity arises as a result of studying [linear transformations](https://en.wikipedia.org/wiki/Linear_transformation) referred to different bases. Consimilarity arises as a result of studying [antilinear transformations](wikipedia://en/293432) referred to different bases.

A matrix is consimilar to itself, its complex conjugate, its [transpose](wikipedia://en/173844) and its [adjoint matrix](https://en.wikipedia.org/wiki/Adjoint_matrix). Every matrix is consimilar to a real matrix and to a [Hermitian matrix](wikipedia://en/189682). There is a standard form for the consimilarity class, analogous to the [Jordan normal form](wikipedia://en/312877).
