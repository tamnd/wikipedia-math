# Göbel's sequence

::: {#o1 .subject cue=lead name="Göbel's sequence"}

In [mathematics](wikipedia://en/18831), **a Göbel sequence** is a sequence of [rational numbers](wikipedia://en/19727024) defined by the [recurrence relation](wikipedia://en/146806)

:::

$$x_n = \frac{ x_0^2+x_1^2+\cdots+x_{n-1}^2}{n-1},\!\,$$

with starting value

$$x_0 = x_1 = 1.$$

Göbel's sequence starts with

1, 1, 2, 3, 5, 10, 28, 154, 3520, 1551880, ...

The first non-integral value is *x*<sub>44</sub>.[^o2]

## History {#History}

This sequence was developed by the German mathematician [Fritz Göbel](https://en.wikipedia.org/wiki/Fritz_Göbel) in the 1970s.[^o7] In 1975, the Dutch mathematician [Hendrik Lenstra](https://en.wikipedia.org/wiki/Hendrik_Lenstra) showed that the 44th term is not an integer.[^o7]

::: {#o5 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

Göbel's sequence can be generalized to *k*th powers by

$$x_n = \frac{1+x_0^k+x_1^k+\cdots+x_{n-1}^k}{n},$$

with starting value

$$x_0 = 1.$$

The least indices at which the *k*-Göbel sequences assume a non-integral value are

43, 89, 97, 214, 19, 239, 37, 79, 83, 239, ...

Regardless of the value chosen for *k*, the initial 19 terms are always integers.[^o6][^o7]

:::
