# Separation principle

::: {#o1 .subject cue=lead name="Separation principle"}

In [control theory](wikipedia://en/7039), a **separation principle**, more formally known as a **principle of separation of estimation and control**, states that under some assumptions the problem of designing an optimal feedback controller for a stochastic system can be solved by designing an optimal [observer](wikipedia://en/1261170) for the state of the system, which feeds into an optimal deterministic [controller](https://en.wikipedia.org/wiki/Controller_%28control_theory%29) for the system. Thus the problem can be broken into two separate parts, which facilitates the design.

:::

The first instance of such a principle is in the setting of deterministic linear systems, namely that if a stable [observer](wikipedia://en/1261170) and a stable state [feedback](wikipedia://en/11545) are designed for a [linear time-invariant system](https://en.wikipedia.org/wiki/LTI_system_theory) (LTI system hereafter), then the combined observer and feedback is [stable](wikipedia://en/1145733). The separation principle does not hold in general for nonlinear systems.

Another instance of the separation principle arises in the setting of linear stochastic systems, namely that state estimation (possibly nonlinear) together with an optimal state feedback controller designed to minimize a quadratic cost, is optimal for the stochastic control problem with output measurements. When process and observation noise are Gaussian, the optimal solution separates into a [Kalman filter](wikipedia://en/180855) and a [linear-quadratic regulator](https://en.wikipedia.org/wiki/Linear-quadratic_regulator). This is known as [linear-quadratic-Gaussian control](https://en.wikipedia.org/wiki/Linear-quadratic-Gaussian_control). More generally, under suitable conditions and when the noise is a martingale (with possible jumps), again a separation principle applies and is known as the [separation principle in stochastic control](wikipedia://en/58383744).[^o2][^o3][^o4][^o5][^o6][^o7]

The separation principle also holds for high gain observers used for state estimation of a class of nonlinear systems[^o8] and control of quantum systems.

## Proof of separation principle for deterministic LTI systems {#Proof_of_separation_principle_for_deterministic_LTI_systems}

Consider a deterministic LTI system:

$$\begin{aligned} \dot{x}(t) & = A x(t) + B u(t) \\ y(t) & = C x(t) \end{aligned}$$

where

$u(t)$ represents the input signal,

$y(t)$ represents the output signal, and

$x(t)$ represents the internal state of the system.

We can design an observer of the form

$$\dot{\hat{x}} = ( A - L C ) \hat{x} + B u + L y \,$$

and state feedback

$$u(t) = - K \hat{x} \, .$$

Define the error *e*:

$$e = x - \hat{x} \, .$$

Then

$$\dot{e} = (A - L C) e \,$$

$$u(t) = - K ( x - e ) \, .$$

Now we can write the closed-loop dynamics as

$$\begin{bmatrix} \dot{x} \\ \dot{e} \\ \end{bmatrix} = \begin{bmatrix} A - B K & BK \\ 0 & A - L C \\ \end{bmatrix} \begin{bmatrix} x \\ e \\ \end{bmatrix}.$$

Since this is a [triangular matrix](wikipedia://en/374222), the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) are just those of *A* − *BK* together with those of *A* − *LC*.[^o11] Thus the stability of the observer and feedback are [independent](wikipedia://en/101863).

:::
