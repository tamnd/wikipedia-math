# Kempner number

::: {#o2 .subject cue=lead name="Kempner number"}

The **Kempner number**[^o3] is the sum of the series

:::

$$\kappa:=2^{-2^0} + 2^{-2^1} + 2^{-2^2} + \cdots = \sum_{n\ge 0} 2^{-2^n}.$$

It is named after [Aubrey Kempner](https://en.wikipedia.org/wiki/Aubrey_Kempner), who proved it [transcendental](wikipedia://en/30325) in 1916.[^o4] It is an example of a number easy to prove transcendental which is not a [Liouville number](wikipedia://en/50964).[^o3]

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

By definition, the binary expansion of the Kempner number has zeroes everywhere except at places which are powers of two:

κ = 0.110100010000000100000000000000010000000000000000000000000000000100... (base two.)

Since the first proof of transcendence by Kempner, many other proofs have been given; see the references.[^o3][^o7][^o8][^o9][^o10][^o11][^o12][^o13]

[Jeffrey Shallit](https://en.wikipedia.org/wiki/Jeffrey_Shallit) has proven that it has a simple [continued fraction](wikipedia://en/739199) expansion, obtainable by the following construction:[^o14]

1. Start with the partial expansion $[0, 1, 3]$.
1. If the partial expansion is $[a, b, ..., y, z]$, replace it by $[a, b, ..., y, z + 1, z - 1, y, ..., b]$.
1. If this generated a zero, replace $[..., a, 0, b, ...]$ by $[..., a + b, ...]$.
1. Repeat steps 2 and 3 indefinitely.

This generates the expansion

$$[0; 1, 4, 2, 4, 4, 6, 4, 2, 4, 6, ...]=0+\cfrac {1}{1+\cfrac {1}{4+\cfrac {1}{2 + \cfrac{1}{4 + \ _{\ddots}}}}}.$$

After the first partial quotients, the remainders are all 2, 4 or 6. Since this continued fraction has bounded partial quotients, the Kempner number has [irrationality measure](wikipedia://en/5968488) 2.

:::
