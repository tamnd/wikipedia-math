# Semi-local ring

::: {#o1 .subject cue=lead name="Semi-local ring"}

In [mathematics](wikipedia://en/18831), a **semi-local ring** is a [ring](wikipedia://en/48404) for which *R*/J(*R*) is a [semisimple ring](https://en.wikipedia.org/wiki/Semisimple_ring), where J(*R*) is the [Jacobson radical](wikipedia://en/57656) of *R*. (Lam 2001, §20)(Mikhalev Pilz 2002, C.7)

:::

The above definition is satisfied if *R* has a finite number of maximal right ideals (and finite number of maximal left ideals). When *R* is a [commutative ring](wikipedia://en/61346), the converse implication is also true, and so the definition of semi-local for commutative rings is often taken to be "having finitely many [maximal ideals](wikipedia://en/48164)".

Some literature refers to a commutative semi-local ring in general as a *quasi-semi-local ring*, using semi-local ring to refer to a [Noetherian ring](wikipedia://en/56129) with finitely many maximal ideals.

A semi-local ring is thus more general than a [local ring](wikipedia://en/153391), which has only one maximal (right/left/two-sided) ideal.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any right or left [Artinian ring](wikipedia://en/489273), any [serial ring](https://en.wikipedia.org/wiki/Serial_ring), and any [semiperfect ring](https://en.wikipedia.org/wiki/Semiperfect_ring) is semi-local.
- The quotient $\mathbb{Z}/m\mathbb{Z}$ is a semi-local ring. In particular, if $m$ is a prime power, then $\mathbb{Z}/m\mathbb{Z}$ is a local ring.
- A finite direct sum of fields $\bigoplus_{i=1}^n{F_i}$ is a semi-local ring.
- In the case of commutative rings with unity, this example is prototypical in the following sense: the [Chinese remainder theorem](wikipedia://en/7713) shows that for a semi-local commutative ring *R* with unit and maximal ideals *m*<sub>1</sub>, ..., *m<sub>n</sub>*

$$R/\bigcap_{i=1}^n m_i\cong\bigoplus_{i=1}^n R/m_i\,.$$

(The map is the natural projection). The right hand side is a direct sum of fields. Here we note that ∩<sub>i</sub> m<sub>i</sub>=J(*R*), and we see that *R*/J(*R*) is indeed a semisimple ring.

- The [classical ring of quotients](https://en.wikipedia.org/wiki/Classical_ring_of_quotients) for any commutative Noetherian ring is a semilocal ring.
- The [endomorphism ring](wikipedia://en/59623) of an [Artinian module](wikipedia://en/542336) is a semilocal ring.
- Semi-local rings occur for example in [algebraic geometry](wikipedia://en/1997) when a (commutative) ring *R* is [localized](https://en.wikipedia.org/wiki/Localization_of_a_ring) with respect to the [multiplicatively closed](https://en.wikipedia.org/wiki/Multiplicatively_closed) subset *S = ∩ (R \\ p<sub>i</sub>)*, where the *p<sub>i</sub>* are finitely many [prime ideals](wikipedia://en/24928).

:::
