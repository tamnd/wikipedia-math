# Elementary equivalence

::: {#o1 .subject cue=lead name="Elementary equivalence"}

In [model theory](wikipedia://en/19858), a branch of [mathematical logic](wikipedia://en/19636), two [structures](wikipedia://en/4055928) *M* and *N* of the same [signature](https://en.wikipedia.org/wiki/Signature_%28mathematical_logic%29) *σ* are called **elementarily equivalent** if they satisfy the same [first-order](wikipedia://en/10983) [*σ*-sentences](wikipedia://en/2129527).

:::

If *N* is a [substructure](wikipedia://en/2057747) of *M*, one often needs a stronger condition. In this case *N* is called an **elementary substructure** of *M* if every first-order *σ*-formula *φ*(*a*<sub>1</sub>, …, *a*<sub>*n*</sub>) with parameters *a*<sub>1</sub>, …, *a*<sub>*n*</sub> from *N* is true in *N* if and only if it is true in *M*. If *N* is an elementary substructure of *M*, then *M* is called an **elementary extension** of *N*. An [embedding](wikipedia://en/52119#Universal_algebra_and_model_theory) *h*: *N* → *M* is called an **elementary embedding** of *N* into *M* if *h*(*N*) is an elementary substructure of *M*.

A substructure *N* of *M* is elementary if and only if it passes the **Tarski–Vaught test**: every [first-order formula](https://en.wikipedia.org/wiki/First-order_formula) *φ*(*x*, *b*<sub>1</sub>, …, *b*<sub>*n*</sub>) with parameters in *N* that has a solution in *M* also has a solution in *N* when evaluated in *M*. One can prove that two structures are elementarily equivalent with the [Ehrenfeucht–Fraïssé games](https://en.wikipedia.org/wiki/Ehrenfeucht–Fraïssé_games).

Elementary embeddings are used in the study of [large cardinals](https://en.wikipedia.org/wiki/Large_cardinals), including [rank-into-rank](wikipedia://en/311017).

## Elementarily equivalent structures {#Elementarily_equivalent_structures}

Two structures *M* and *N* of the same signature *σ* are **elementarily equivalent** if every first-order sentence (formula without free variables) over *σ* is true in *M* if and only if it is true in *N*, i.e. if *M* and *N* have the same [complete](wikipedia://en/10086335) first-order theory. If *M* and *N* are elementarily equivalent, one writes *M* ≡ *N*.

A first-order [theory](wikipedia://en/3512103) is complete if and only if any two of its models are elementarily equivalent.

For example, consider the language with one binary relation symbol '\<'. The model **R** of [real numbers](https://en.wikipedia.org/wiki/Real_numbers) with its usual order and the model **Q** of [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) with its usual order are elementarily equivalent, since they both interpret '\<' as an unbounded dense [linear ordering](https://en.wikipedia.org/wiki/Linear_ordering). This is sufficient to ensure elementary equivalence, because the theory of [unbounded dense linear orderings](wikipedia://en/6320997) is complete, as can be shown by the [Łoś–Vaught test](wikipedia://en/22229525).

More generally, any first-order theory with an infinite model has non-isomorphic, elementarily equivalent models, which can be obtained via the [Löwenheim–Skolem theorem](wikipedia://en/341482). Thus, for example, there are [non-standard models](wikipedia://en/6251420) of [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), which contain other objects than just the numbers 0, 1, 2, etc., and yet are elementarily equivalent to the standard model.

## Elementary substructures and elementary extensions {#Elementary_substructures_and_elementary_extensions}

*N* is an **elementary substructure** or **elementary submodel** of *M* if *N* and *M* are structures of the same [signature](https://en.wikipedia.org/wiki/Signature_%28mathematical_logic%29) *σ* such that for all first-order *σ*-formulas *φ*(*x*<sub>1</sub>, …, *x*<sub>*n*</sub>) with free variables *x*<sub>1</sub>, …, *x*<sub>*n*</sub>, and all elements *a*<sub>1</sub>, …, *a*<sub>n</sub> of *N*, *φ*(*a*<sub>1</sub>, …, *a*<sub>n</sub>) holds in *N* if and only if it holds in *M*:

$$N \models \varphi(a_1, \dots, a_n) \text{ if and only if } M \models \varphi(a_1, \dots, a_n).$$

This definition first appears in Tarski, Vaught (1957).[^o4] It follows that *N* is a substructure of *M*.

If *N* is a substructure of *M*, then both *N* and *M* can be interpreted as structures in the signature *σ*<sub>*N*</sub> consisting of *σ* together with a new constant symbol for every element of *N*. Then *N* is an elementary substructure of *M* if and only if *N* is a substructure of *M* and *N* and *M* are elementarily equivalent as *σ*<sub>*N*</sub>-structures.

If *N* is an elementary substructure of *M*, one writes *N* $\preceq$ *M* and says that *M* is an **elementary extension** of *N*: *M* $\succeq$ *N*.

The downward [Löwenheim–Skolem theorem](wikipedia://en/341482) gives a countable elementary substructure for any infinite first-order structure in at most countable signature; the upward Löwenheim–Skolem theorem gives elementary extensions of any infinite first-order structure of arbitrarily large cardinality.

## Tarski–Vaught test {#Tarski–Vaught_test}

The **Tarski–Vaught test** (or **Tarski–Vaught criterion**) is a necessary and sufficient condition for a substructure *N* of a structure *M* to be an elementary substructure. It can be useful for constructing an elementary substructure of a large structure.

Let *M* be a structure of signature *σ* and *N* a substructure of *M*. Then *N* is an elementary substructure of *M* if and only if for every first-order formula *φ*(*x*, *y*<sub>1</sub>, …, *y*<sub>*n*</sub>) over *σ* and all elements *b*<sub>1</sub>, …, *b*<sub>*n*</sub> from *N*, if *M* $\models$ *x* *φ*(*x*, *b*<sub>1</sub>, …, *b*<sub>*n*</sub>), then there is an element *a* in *N* such that *M* $\models$ *φ*(*a*, *b*<sub>1</sub>, …, *b*<sub>*n*</sub>).[^o7]

:::

## Elementary embeddings {#Elementary_embeddings}

An **elementary embedding** of a structure *N* into a structure *M* of the same signature *σ* is a map *h*: *N* → *M* such that for every first-order *σ*-formula *φ*(*x*<sub>1</sub>, …, *x*<sub>*n*</sub>) and all elements *a*<sub>1</sub>, …, *a*<sub>n</sub> of *N*,

*N* $\models$ *φ*(*a*<sub>1</sub>, …, *a*<sub>*n*</sub>) if and only if *M* $\models$ *φ*(*h*(*a*<sub>1</sub>), …, *h*(*a*<sub>*n*</sub>)).

Every elementary embedding is a [strong homomorphism](wikipedia://en/4055928#Homomorphisms), and it induces an isomorphism between *N* and an elementary substructure of *M*.

Elementary embeddings are the most important maps in model theory. In [set theory](wikipedia://en/27553), elementary embeddings whose domain is *V* (the universe of set theory) play an important role in the theory of [large cardinals](https://en.wikipedia.org/wiki/Large_cardinals) (see also [Critical point](wikipedia://en/4888510)).
