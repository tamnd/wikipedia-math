# Truncated power function

::: {#o1 .subject cue=lead name="Truncated power function"}

In mathematics, the **truncated power function**[^o2] with exponent $n$ is defined as

:::

$$x_+^n = \begin{cases} x^n &:\ x > 0 \\ 0 &:\ x \le 0. \end{cases}$$

In particular,

$$x_+ = \begin{cases} x &:\ x > 0 \\ 0 &:\ x \le 0. \end{cases}$$

and interpret the exponent as conventional [power](https://en.wikipedia.org/wiki/Power_function).

## Relations {#Relations}

- Truncated power functions can be used for construction of [B-splines](wikipedia://en/21834).
- $x \mapsto x_+^0$ is the [Heaviside function](https://en.wikipedia.org/wiki/Heaviside_function).
- $\chi_{[a,b)}(x) = (b-x)_+^0 - (a-x)_+^0$ where $\chi$ is the [indicator function](wikipedia://en/240790).
- Truncated power functions are [refinable](wikipedia://en/4557519).
