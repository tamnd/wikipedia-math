# Infinite conjugacy class property

::: {#o1 .subject cue=lead name="Infinite conjugacy class property"}

In [mathematics](wikipedia://en/18831), a [group](wikipedia://en/19447) is said to have the **infinite conjugacy class property**, or to be an **ICC group**, if the [conjugacy class](wikipedia://en/49176) of every group element but the identity is [infinite](wikipedia://en/20110824).p. 907

:::

The [von Neumann group algebra](https://en.wikipedia.org/wiki/Von_Neumann_group_algebra) of a group is a [factor](https://en.wikipedia.org/wiki/Factor_%28functional_analysis%29) if and only if the group has the infinite conjugacy class property. It will then be, provided the group is nontrivial, of type *II<sub>1</sub>*, i.e. it will possess a unique, faithful, tracial state.[^o2]

Examples of ICC groups are the group of [permutations](wikipedia://en/44027) of an infinite set that leave all but a finite subset of elements fixed,p. 908 and [free groups](wikipedia://en/59735) on two generators.p. 908

In [abelian groups](wikipedia://en/2974), every conjugacy class consists of only one element, so ICC groups are, in a way, as far from being abelian as possible.
