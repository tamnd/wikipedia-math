# Lovász conjecture

::: {#o1 .problem cue=unsolved}

Does every finite [connected](wikipedia://en/1614492) [vertex-transitive](wikipedia://en/581175) graph contain a Hamiltonian path?

:::

::: {#o2 .subject cue=lead name="Lovász conjecture"}

In [graph theory](wikipedia://en/12401), the **Lovász conjecture** (1969) is a classical problem on [Hamiltonian paths](wikipedia://en/244437) in [graphs](wikipedia://en/325806). It says:

:::

Every finite [connected](wikipedia://en/1614492) [vertex-transitive](wikipedia://en/581175) graph contains a Hamiltonian path.

Originally [László Lovász](wikipedia://en/1623938) stated the problem in the opposite way, but this version became standard. In 1996, [László Babai](wikipedia://en/3461604) published a [conjecture](wikipedia://en/6138) sharply contradicting this conjecture,[^o3] but both conjectures remain widely [open](wikipedia://en/1333335). It is not even known if a single [counterexample](wikipedia://en/143151) would necessarily lead to a series of counterexamples.

## Historical remarks {#Historical_remarks}

The problem of finding Hamiltonian paths in highly symmetric graphs is quite old. As [Donald Knuth](wikipedia://en/8095) describes it in volume 4 of *[The Art of Computer Programming](https://en.wikipedia.org/wiki/The_Art_of_Computer_Programming)*,[^o5] the problem originated in [British](https://en.wikipedia.org/wiki/United_Kingdom) [campanology](https://en.wikipedia.org/wiki/Change_ringing) (bell-ringing). Such Hamiltonian paths and [cycles](https://en.wikipedia.org/wiki/Hamiltonian_cycle) are also closely connected to [Gray codes](wikipedia://en/50564). In each case the constructions are explicit.

## Variants of the Lovász conjecture {#Variants_of_the_Lovász_conjecture}

### Hamiltonian cycle {#Hamiltonian_cycle}

Another version of **Lovász conjecture** states that

*Every finite connected vertex-transitive graph contains a Hamiltonian cycle* except the five known counterexamples.

There are 5 known examples of vertex-transitive graphs with no Hamiltonian cycles (but with Hamiltonian paths): the [complete graph](wikipedia://en/85816) $K_2$, the [Petersen graph](wikipedia://en/194926), the [Coxeter graph](wikipedia://en/5358570) and two graphs derived from the Petersen and Coxeter graphs by replacing each vertex with a triangle.[^o9]

### Cayley graphs {#Cayley_graphs}

None of the 5 vertex-transitive graphs with no Hamiltonian cycles is a [Cayley graph](wikipedia://en/358277). This observation leads to a weaker version of the conjecture:

*Every finite connected Cayley graph contains a Hamiltonian cycle*.

The advantage of the Cayley graph formulation is that such graphs correspond to a [finite group](wikipedia://en/323707) $G$ and a [generating set](wikipedia://en/99945) $S$. Thus one can ask for which $G$ and $S$ the conjecture holds rather than attack it in full generality.

### Directed Cayley graph {#Directed_Cayley_graph}

For directed Cayley graphs (digraphs) the Lovász conjecture is false. Various counterexamples were obtained by [Robert Alexander Rankin](wikipedia://en/5884314). Still, many of the below results hold in this restrictive setting.

:::

## Special cases {#Special_cases}

*Image: Steinhaus-Johnson-Trotter-Permutohedron.svg.* A Hamiltonian path in the [permutohedron](wikipedia://en/12745947), a Cayley graph of the symmetric group with Coxeter generators

Every directed Cayley graph of an [abelian group](wikipedia://en/2974) has a Hamiltonian path; however, every [cyclic group](wikipedia://en/52327) whose [order](https://en.wikipedia.org/wiki/Order_of_a_group) is not a [prime power](wikipedia://en/1630483) has a directed Cayley graph that does not have a Hamiltonian cycle.[^o14] In 1986, D. Witte proved that the Lovász conjecture holds for the Cayley graphs of [*p*-groups](wikipedia://en/24664). It is open even for [dihedral groups](wikipedia://en/100267), although for special sets of generators some progress has been made.

For the [symmetric group](wikipedia://en/28901) $S_n$, there are many attractive generating sets. For example, the Lovász conjecture holds in the following cases of generating sets:

- $a = (1,2,\dots,n), b = (1,2)$ (long cycle and a [transposition](https://en.wikipedia.org/wiki/Transposition_%28mathematics%29)).
- $s_1 = (1,2), s_2 = (2,3), \dots, s_{n-1} = (n-1,n)$ ([Coxeter generators](wikipedia://en/297004)). In this case a Hamiltonian cycle is generated by the [Steinhaus–Johnson–Trotter algorithm](https://en.wikipedia.org/wiki/Steinhaus–Johnson–Trotter_algorithm).
- any set of transpositions corresponding to a [labelled tree](wikipedia://en/48560) on $\{1,2,..,n\}$.
- $$a =(1,2), b = (1,2)(3,4)\cdots, c = (2,3)(4,5)\cdots$$

Stong has shown that the conjecture holds for the Cayley graph of the [wreath product](wikipedia://en/146625) **Z**<sub>*m*</sub> wr **Z**<sub>*n*</sub> with the natural minimal generating set when *m* is either [even](wikipedia://en/143135) or three. In particular this holds for the [cube-connected cycles](wikipedia://en/13379568), which can be generated as the Cayley graph of the wreath product **Z**<sub>2</sub> wr **Z**<sub>*n*</sub>.[^o15]

:::

## General groups {#General_groups}

For general finite [groups](wikipedia://en/19447), only a few results are known:

- $S=\{a,b\}, (ab)^2=1$ ([Rankin](wikipedia://en/5884314) generators)
- $S=\{a,b,c\}, a^2= b^2=c^2=[a,b]=1$ ([Rapaport–Strasser](https://en.wikipedia.org/wiki/Rapaport–Strasser) generators)
- $S=\{a,b,c\}, a^2=1, c = a^{-1}ba$ ([Pak](https://en.wikipedia.org/wiki/Igor_Pak)–[Radoičić](https://en.wikipedia.org/wiki/Radoš_Radoičić) generators[^o17])
- $S=\{a,b\}, a^2 = b^s =(ab)^3 = 1,$ where $|G|,s = 2~mod ~4$ (here we have (2,s,3)-[presentation](wikipedia://en/99494), Glover–Marušič theorem).[^o18]

Finally, it is known that for every finite group $G$ there exists a generating set of size at most $\log_2 |G|$ such that the corresponding Cayley graph is Hamiltonian (Pak-Radoičić). This result is based on [classification of finite simple groups](wikipedia://en/7445).

The Lovász conjecture was also established for random generating sets of size $\Omega(\log^5 |G|)$.[^o19]
