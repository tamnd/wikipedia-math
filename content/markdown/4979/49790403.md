# Qvist's theorem

::: {#o1 .subject cue=lead name="Qvist's theorem"}

*Image: Qvist-0-en.svg.* Qvist's theorem on finite ovals

In [projective geometry](wikipedia://en/243849), **Qvist's theorem**, named after the Finnish mathematician Bertil Qvist, is a statement on [ovals](wikipedia://en/4255174) in *finite* [projective planes](wikipedia://en/24350). Standard examples of ovals are non-degenerate [(projective) conic sections](wikipedia://en/19008673). The theorem gives an answer to the question *How many tangents to an oval can pass through a point in a finite projective plane?* The answer depends essentially upon the [order](wikipedia://en/24350#Finite_projective_planes) (number of points on a line −1) of the plane.

:::

## Definition of an oval {#Definition_of_an_oval}

- In a [projective plane](wikipedia://en/24350) a set $\Omega$ of points is called an **oval**, if:

<!-- -->

1. Any line $l$ meets $\Omega$ in at most two points, and
1. For any point $P \in \Omega$ there exists exactly one tangent line $t$ through $P$, i.e., $t \cap \Omega = \{P$}.

When $\lvert l \cap \Omega\rvert = 0$ the line $l$ is an *exterior line* (or *passant*),[^o3] if $\lvert l \cap \Omega\rvert = 1$ a *tangent line* and if $\lvert l \cap \Omega\rvert = 2$ the line is a *secant line*.

For *finite* planes (i.e. the set of points is finite) we have a more convenient characterization:[^o4]

- For a finite projective plane of *order* $n$ (i.e. any line contains $n + 1$ points) a set $\Omega$ of points is an oval [if and only if](wikipedia://en/14922) $\lvert \Omega\rvert = n + 1$ and no three points are [collinear](https://en.wikipedia.org/wiki/Collinear) (on a common line).

::: {#o6 .proof cue=named-heading name="Statement and proof of Qvist's theorem"}

## Statement and proof of Qvist's theorem {#Statement_and_proof_of_Qvist's_theorem}

**Qvist's theorem[^o7][^o8]**

Let $\Omega$ be an oval in a finite projective plane of order $n$.

(a) If $n$ is *odd*,

every point $P \notin \Omega$ is incident with 0 or 2 tangents.

(b) If $n$ is *even*,

there exists a point $N$, the *nucleus* or *knot*, such that, the set of tangents to oval $\Omega$ is the pencil of all lines through $N$.

*Image: Qvist-theorem-a-en.svg.* Qvist's theorem: to the proof in case of n odd

*Image: Qvist-theorem-b-en.svg.* Qvist's theorem: to the proof in case of n even

::: {#o9 .proof cue=inline-head name="Proof"}

**Proof**

(a) Let $t_{R}$ be the tangent to $\Omega$ at point $R$ and let $P_{1}, ... , P_{n}$ be the remaining points of this line. For each $i$, the lines through $P_{i}$ partition $\Omega$ into sets of cardinality 2 or 1 or 0. Since the number $\lvert \Omega\rvert = n + 1$ is even, for any point $P_{i}$, there must exist at least one more tangent through that point. The total number of tangents is $n + 1$, hence, there are exactly two tangents through each $P_{i}$, $t_{R}$ and one other. Thus, for any point $P$ not in oval $\Omega$, if $P$ is on any tangent to $\Omega$ it is on exactly two tangents.

(b) Let $s$ be a secant, $s \cap \Omega = \{P_{0}, P_{1}$} and $s= \{P_{0}, P_{1},...,P_{n}$}. Because $\lvert \Omega\rvert = n + 1$ is odd, through any $P_{i}, i = 2,...,n$, there passes at least one tangent $t_{i}$. The total number of tangents is $n + 1$. Hence, through any point $P_{i}$ for $i = 2,...,n$ there is exactly one tangent. If $N$ is the point of intersection of two tangents, no secant can pass through $N$. Because $n + 1$, the number of tangents, is also the number of lines through any point, any line through $N$ is a tangent.

:::

::: {#o10 .example cue=inline-head name="Example in a pappian plane of even order"}

**Example in a pappian plane of even order**

Using [inhomogeneous coordinates](wikipedia://en/243316) over a field $K, \lvert K\rvert = n$ even, the set

$\Omega_{1} = \{(x, y) | y = x^{2}\} \cup \{(\infty)$},

the projective closure of the parabola $y = x^{2}$, is an oval with the point $N = (0)$ as nucleus (see image), i.e., any line $y = c$, with $c \in K$, is a tangent.

## Definition and property of hyperovals {#Definition_and_property_of_hyperovals}

- Any oval $\Omega$ in a *finite* projective plane of *even* order $n$ has a nucleus $N$.

The point set $\overline{\Omega} := \Omega \cup \{N$} is called a **[hyperoval](https://en.wikipedia.org/wiki/Hyperoval)** or ($n + 2$)-*arc*. (A finite oval is an ($n + 1$)-*arc*.)

One easily checks the following essential property of a hyperoval:

- For a hyperoval $\overline{\Omega}$ and a point $R \in \overline{\Omega}$ the pointset $\overline{\Omega} \backslash \{R$} is an oval.

*Image: Proj-kegs-parab-s.svg.* projective conic section $\Omega_{1}$

This property provides a simple means of constructing additional ovals from a given oval.

::: {#o12 .example cue=inline-head name="Example"}

**Example**

For a projective plane over a [finite field](wikipedia://en/11615) $K, \lvert K\rvert = n$ even and $n > 4$, the set

$\Omega_{1} = \{(x, y) | y = x^{2}\} \cup \{(\infty)$} is an oval (conic section) (see image),

$\overline{\Omega}_{1} = \{(x, y) | y = x^{2}\} \cup \{(0), (\infty)$} is a hyperoval and

$\Omega_{2} = \{(x, y) | y = x^{2}\} \cup \{(0)$} is another oval that is not a conic section. (Recall that a conic section is determined uniquely by 5 points.)

:::
