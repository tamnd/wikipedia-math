# Dicut

*Image: Dicut.svg.* All edges crossing between vertices of different colors are directed from red to blue. The set of these edges between colors is therefore a **dicut**. The set of blue vertices is a **closure** because there are no edges which exit it.

::: {#o1 .subject cue=lead name="Dicut"}

In mathematics, a **dicut** is a set of edges in a [directed graph](wikipedia://en/19721986), defined from a [partition](wikipedia://en/11973947) of the vertices into two subsets, so that each edge that has an endpoint in both subsets is directed from the first subset to the second. This is analogous to a [cut](wikipedia://en/2180494) in [undirected graphs](https://en.wikipedia.org/wiki/Undirected_graph) (although the cut refers to the partition of vertices rather than the set of edges between them, so it is more accurate to say that the dicut is analogous to the **cut-set**). Each [strongly connected component](wikipedia://en/684680) of the graph must be entirely contained in one of the two subsets, so a [strongly connected graph](https://en.wikipedia.org/wiki/Strongly_connected_graph) has no nontrivial dicuts. Often, the underlying directed graph is assumed to be [weakly connected](wikipedia://en/1614492); if not, the empty edge set would correspond to multiple vertex partitions.

:::

The second of the two subsets in a dicut, a subset of vertices with no edges that exit the subset, is called a closure. The [closure problem](https://en.wikipedia.org/wiki/Closure_problem) is the algorithmic problem of finding a dicut, in an edge-weighted directed graph, whose total weight is as large as possible. It can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).

In weakly connected [planar graphs](wikipedia://en/24314), dicuts and [cycles](wikipedia://en/168609) are dual concepts. The [dual graph](wikipedia://en/2536864) of a directed graph, embedded in the plane, is a graph with a vertex for each face of the given graph, and a dual edge between two dual vertices when the corresponding two faces are separated by an edge. Each dual edge crosses one of the original graph edges, turned by 90° clockwise. For a dicut in the given graph, the duals of the edges in the dicut form a directed cycle in the dual graph, and vice versa.

A [dijoin](wikipedia://en/72418335) can be defined as a set of edges that contains at least one edge from every dicut; for this to exist, the given directed graph must be weakly connected. When the edges of a dijoin are contracted, the result is a strongly connected graph. [Woodall's conjecture](wikipedia://en/72418333), an unsolved problem in this area, states that in any directed graph the minimum number of edges in a dicut (the unweighted minimum closure) equals the maximum number of disjoint dijoins that can be found in the graph (a packing of dijoins). A fractional weighted version of the conjecture, posed by [Jack Edmonds](wikipedia://en/3625459) and Rick Giles, was refuted by [Alexander Schrijver](wikipedia://en/35280549). In the other direction, the [Lucchesi–Younger theorem](wikipedia://en/72418334) states that the minimum size of a dijoin equals the maximum number of disjoint dicuts that can be found in a given graph.
