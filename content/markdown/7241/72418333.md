# Woodall's conjecture

::: {#o1 .subject cue=lead name="Woodall's conjecture"}

::: {#o2 .problem cue=unsolved}

Does the minimum number of edges in a dicut of a directed graph always equal the maximum number of disjoint dijoins?

:::

In the mathematics of [directed graphs](wikipedia://en/19721986), **Woodall's conjecture** is an unproven relationship between [dicuts](wikipedia://en/72418332) and [dijoins](wikipedia://en/72418335). It was posed by [Douglas Woodall](wikipedia://en/70804411) in 1976.

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

A dicut, in a directed graph, is a set of edges defined from a partition of the vertices into two subsets such that all edges that cross the partition do so in the same direction. A dijoin is a subset of edges that, when contracted, produces a [strongly connected graph](https://en.wikipedia.org/wiki/Strongly_connected_graph); equivalently, it is a subset of edges that includes at least one edge from each dicut.

*Image: Woodall.png.* On the left, a dicut with the minimum number of edges for the given graph, that being 3 edges (in red), forming 2 partitions (the set of blue vertices, and the set of green). On the right, the same number of disjoint dijoins (each represented by a different color).

According to the [Lucchesi-Younger theorem](https://en.wikipedia.org/wiki/Lucchesi-Younger_theorem), if the minimum number of edges in a dicut is $k$, then there can be at most $k$ disjoint dijoins in the graph, because each one must include a different edge from the smallest dicut. Woodall's conjecture states that, in this case, it is always possible to find $k$ disjoint dijoins. That is, any directed graph the minimum number of edges in a dicut equals the maximum number of disjoint dijoins that can be found in the graph (a packing of dijoins).

:::

## Partial results {#Partial_results}

It is a folklore result that the theorem is true for directed graphs whose minimum dicut has two edges. Any instance of the problem can be reduced to a [directed acyclic graph](wikipedia://en/204002) by taking the [condensation](https://en.wikipedia.org/wiki/Condensation_%28graph_theory%29) of the instance, a graph formed by contracting each strongly connected component to a single vertex. Another class of graphs for which the theorem has been proven true are the directed acyclic graphs in which every source vertex (a vertex without incoming edges) has a path to every sink vertex (a vertex without outgoing edges).

In every graph whose minimum dicut size is $k$, there exist at least $\lfloor k/6\rfloor$ disjoint dijoins. If a conjecture of [W. T. Tutte](wikipedia://en/52021) on the existence of [nowhere-zero 5-flows](wikipedia://en/9909979) in [biconnected undirected graphs](wikipedia://en/4989397) is true, this bound would improve to $\lfloor k/5\rfloor$.

::: {#o7 .statement kind=statement/generalization cue=heading name="Related results"}

## Related results {#Related_results}

A fractional weighted version of the conjecture, posed by [Jack Edmonds](wikipedia://en/3625459) and Rick Giles, was refuted by [Alexander Schrijver](wikipedia://en/35280549). In the other direction, the [Lucchesi–Younger theorem](wikipedia://en/72418334) states that the minimum size of a dijoin equals the maximum number of disjoint dicuts that can be found in a given graph.

:::
