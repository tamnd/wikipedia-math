# Coherent ring

::: {#o1 .subject cue=lead name="Coherent ring"}

In [mathematics](wikipedia://en/18831), a (left) **coherent ring** is a [ring](wikipedia://en/48404) in which every [finitely generated](wikipedia://en/25977#Types_of_ideals) left [ideal](wikipedia://en/25977) is [finitely presented](https://en.wikipedia.org/wiki/Finitely_presented_module).

:::

Many theorems about [finitely generated modules](wikipedia://en/326430) over [Noetherian rings](wikipedia://en/56129) can be extended to finitely presented modules over coherent rings.

Every left Noetherian ring is left coherent. The ring of [polynomials](wikipedia://en/23000) in an infinite number of variables over a left Noetherian ring is an example of a left coherent ring that is not left Noetherian.

A ring is left coherent [if and only if](wikipedia://en/14922) every [direct product](wikipedia://en/8887) of [flat](wikipedia://en/492616) right [modules](wikipedia://en/276410) is flat (Chase 1960), (Anderson Fuller 1992, 229). Compare this to: A ring is left Noetherian if and only if every [direct sum](wikipedia://en/58899) of [injective](wikipedia://en/473775) left modules is injective.
