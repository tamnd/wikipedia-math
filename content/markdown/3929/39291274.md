# Cyclic reduction

::: {#o1 .subject cue=lead name="Cyclic reduction"}

**Cyclic reduction** is a [numerical method](wikipedia://en/1678715) for solving large linear systems by repeatedly splitting the problem. Each step eliminates even or odd rows and columns of a matrix and remains in a similar form. The elimination step is relatively expensive but splitting the problem allows parallel computation.

:::

## Applicability {#Applicability}

The method only applies to matrices that can be represented as a (block) [Toeplitz matrix](wikipedia://en/151569). Such problems often arise in implicit solutions for partial differential equations on a lattice. For example fast solvers for [Poisson's equation](wikipedia://en/193735) express the problem as solving a tridiagonal matrix, discretising the solution on a regular grid.

## Accuracy {#Accuracy}

Systems which have good numerical stability initially tend to get better with each step. Moreover, to a point where a good approximate solution can be given,[^o4] but because the special matrix form must be preserved pivoting cannot be performed to improve numerical accuracy.

## Comparison to multigrid {#Comparison_to_multigrid}

The method is not iterative, it seeks an exact solution to the linear problem consistent with the given boundary values, contrast that with the similar but computationally cheaper [multigrid method](wikipedia://en/1747763) which propagates error-correction estimates down and allows for different relaxation parameters at different scales, the iterative aspect allowing better incorporation of non-linear features.

## Combination with [fast Fourier transform](wikipedia://en/11512) FFT {#Combination_with_fast_Fourier_transform_FFT}

Transforming from the spatial domain and restating the PDE is called a [spectral method](wikipedia://en/243110), Fourier analysis and cyclic reduction are combined in the FACR algorithm[^o7] which is explained in Numerical Recipes – see 19.4 Fourier and Cyclic Reduction Methods for Boundary Value Problems.[^o8]
