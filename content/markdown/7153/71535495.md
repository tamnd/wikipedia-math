# Kuratowski's intersection theorem

::: {#o1 .subject cue=lead name="Kuratowski's intersection theorem"}

In [mathematics](wikipedia://en/18831), **Kuratowski's intersection theorem** is a result in [general topology](wikipedia://en/178649) that gives a sufficient condition for a nested sequence of sets to have a non-empty [intersection](wikipedia://en/41780044). Kuratowski's result is a generalisation of [Cantor's intersection theorem](wikipedia://en/28046776). Whereas Cantor's result requires that the sets involved be [compact](wikipedia://en/6042), Kuratowski's result allows them to be non-compact, but insists that their non-compactness "tends to zero" in an appropriate sense. The theorem is named for the [Polish](https://en.wikipedia.org/wiki/Polish_people) [mathematician](wikipedia://en/18902) [Kazimierz Kuratowski](wikipedia://en/46075), who proved it in 1930.

:::

## Statement of the theorem {#Statement_of_the_theorem}

Let (*X*, *d*) be a [complete metric space](wikipedia://en/7832). Given a subset *A* ⊆ *X*, its [**Kuratowski measure of non-compactness**](wikipedia://en/212935) *α*(*A*) ≥ 0 is defined by

$$\alpha(A) = \inf \left\{ r \geq 0 \left| \begin{array}{c} A \text{ can be covered by finitely many subsets} \\ \text{of } X \text{, each with diameter at most } r \end{array} \right. \right\}.$$

Note that, if *A* is itself compact, then *α*(*A*) = 0, since every cover of *A* by open balls of arbitrarily small diameter will have a finite subcover. The converse is also true: if *α*(*A*) = 0, then *A* must be [precompact](https://en.wikipedia.org/wiki/Relatively_compact_set), and indeed compact if *A* is closed. Also, if *A* is a subset of *B*, then *α*(*A*) ≤ *α*(*B*). In some sense, the quantity *α*(*A*) is a numerical description of "how non-compact" the set *A* is.

Now consider a sequence of sets *A*<sub>*n*</sub> ⊆ *X*, one for each natural number *n*. **Kuratowski's intersection theorem** asserts that if these sets are non-empty, [closed](wikipedia://en/47279), decreasingly nested (i.e. *A*<sub>*n*+1</sub> ⊆ *A*<sub>*n*</sub> for each *n*), and *α*(*A*<sub>*n*</sub>) → 0 as *n* → ∞, then their infinite intersection

$$\bigcap_{n \in \mathbb{N}} A_{n}$$

is a non-empty compact set.

The result also holds if one works with the ball measure of non-compactness or the separation measure of non-compactness, since these three measures of non-compactness are mutually Lipschitz equivalent; if any one of them tends to zero as *n* → ∞, then so must the other two.
