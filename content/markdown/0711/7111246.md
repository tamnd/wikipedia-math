# Shared secret

::: {#o1 .subject cue=lead name="Shared secret"}

In [cryptography](wikipedia://en/18934432), a **shared secret** is a piece of data, known only to the parties involved, in a [secure communication](https://en.wikipedia.org/wiki/Secure_communication). This usually refers to the [key](wikipedia://en/53039) of a [symmetric cryptosystem](wikipedia://en/53042). The shared secret can be a [PIN code](https://en.wikipedia.org/wiki/Personal_identification_number), a [password](wikipedia://en/24304), a [passphrase](https://en.wikipedia.org/wiki/Passphrase), a big number, or an array of randomly chosen bytes.

:::

The shared secret is either shared beforehand between the communicating parties, in which case it can also be called a [pre-shared key](wikipedia://en/4934057), or it is created at the start of the communication session by using a [key-agreement protocol](wikipedia://en/63944), for instance using [public-key cryptography](wikipedia://en/24222) such as [Diffie–Hellman](wikipedia://en/7903) or using [symmetric-key cryptography](wikipedia://en/53042) such as [Kerberos](wikipedia://en/16947).

The shared secret can be used for authentication (for instance when logging in to a remote system) using methods such as [challenge–response](wikipedia://en/412627) or it can be fed to a [key derivation function](wikipedia://en/449781) to produce one or more [keys](wikipedia://en/53039) to use for encryption and/or [MACing](wikipedia://en/567523) of messages.

To make unique [session and message keys](wikipedia://en/63941) the shared secret is usually combined with an [initialization vector](wikipedia://en/105971) (IV). An example of this is the [derived unique key per transaction](wikipedia://en/4625359) method.

It is also often used as an authentication measure in [web APIs](https://en.wikipedia.org/wiki/Web_API).
