# Eventually (mathematics)

::: {#o1 .subject cue=lead name="Eventually"}

In the [mathematical](wikipedia://en/18831) areas of [number theory](wikipedia://en/21527) and [analysis](wikipedia://en/48396), an infinite [sequence](wikipedia://en/27838) or a [function](wikipedia://en/185427) is said to **eventually** have a certain [property](wikipedia://en/508057), if it does not have the said property across all its ordered instances, but will after some instances have passed. The use of the term "eventually" can be often rephrased as "for sufficiently large numbers",[^o2] and can be also extended to the class of properties that apply to elements of any [ordered set](wikipedia://en/23572) (such as sequences and [subsets](wikipedia://en/27631) of $\mathbb{R}$).

:::

::: {#o4 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

The general form where the phrase **eventually** (or **sufficiently large**) is found appears as follows:

$P$ is *eventually* true for $x$ ($P$ is true for *sufficiently large* $x$),

where $\forall$ and $\exists$ are the [universal](https://en.wikipedia.org/wiki/Universal_quantifier) and [existential quantifiers](https://en.wikipedia.org/wiki/Existential_quantifier), which is actually a shorthand for:

$\exists a \in \mathbb{R}$ such that $P$ is true $\forall x \ge a$

or somewhat more formally:

$$\exists a \in \mathbb{R}: \forall x \in \mathbb{R}:x \ge a \Rightarrow P(x)$$

This does not necessarily mean that any particular value for $a$ is known, but only that such an $a$ exists. The phrase "sufficiently large" should not be confused with the phrases "[arbitrarily large](wikipedia://en/1118832)" or "[infinitely](wikipedia://en/20110824) large". For more, see [Arbitrarily large#Arbitrarily large vs. sufficiently large vs. infinitely large](wikipedia://en/1118832#Arbitrarily_large_vs._sufficiently_large_vs._infinitely_large).

:::

## Motivation and definition {#Motivation_and_definition}

For an infinite sequence, one is often more interested in the long-term behaviors of the sequence than the behaviors it exhibits early on. In which case, one way to formally capture this concept is to say that the sequence possesses a certain property *eventually*, or equivalently, that the property is satisfied by one of its [subsequences](wikipedia://en/236098) $(a_n)_{n \geq N}$, for some $N \in \mathbb{N}$.[^o6]

For example, the definition of a sequence of [real numbers](wikipedia://en/20646438) $(a_n)$ converging to some [limit](wikipedia://en/285773) *$a$* is:

For each positive number $\varepsilon$, there exists a [natural number](wikipedia://en/21474) $N$ such that for all $n >N$, $\left\vert a_n - a \right\vert<\varepsilon$.

When the term "eventually*"* is used as a shorthand for "there exists a natural number $N$ such that for all $n > N$", the convergence definition can be restated more simply as:

For each positive number $\varepsilon>0$, eventually $\left\vert a_n-a \right\vert<\varepsilon$.

Here, notice that the [set](wikipedia://en/26691) of natural numbers that do not satisfy this property is a finite set; that is, the set is [empty](wikipedia://en/9566) or has a maximum element. As a result, the use of "eventually" in this case is synonymous with the expression "for all but a finite number of terms" – a [special case](wikipedia://en/31308010) of the expression "for [almost all](wikipedia://en/1309) terms" (although "almost all" can also be used to allow for infinitely many exceptions as well).

At the basic level, a sequence can be thought of as a function with natural numbers as its [domain](wikipedia://en/50263), and the notion of "eventually" applies to functions on more general sets as well—in particular to those that have an ordering with no [greatest element](https://en.wikipedia.org/wiki/Greatest_element).

More specifically, if $S$ is such a set and there is an element $s$ in $S$ such that the function $f$ is defined for all elements greater than $s$, then $f$ is said to have some property eventually if there is an element $x_0$ such that whenever *$x>x_0$*, $f(x)$ has the said property. This notion is used, for example, in the study of [Hardy fields](wikipedia://en/32185451), which are fields made up of real functions, each of which have certain properties eventually.

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- "All [primes](wikipedia://en/23666) greater than 2 are [odd](wikipedia://en/143135)" implies that "Eventually, all primes are odd.”
- Eventually, all primes are [congruent](wikipedia://en/20087) to ±1 modulo 6.
- The [square](wikipedia://en/659942) of a prime is eventually congruent to 1 mod 24 (specifically, this is true for all primes greater than 3).
- The [factorial](wikipedia://en/10606) of a natural number eventually ends in the digit 0 (specifically, this is true for all natural numbers greater than 4).

:::

## Other uses in mathematics {#Other_uses_in_mathematics}

- A [3-manifold](wikipedia://en/1018257) is called sufficiently large if it contains a properly embedded 2-sided [incompressible surface](wikipedia://en/896174). This property is the main requirement for a 3-manifold to be called a [Haken manifold](wikipedia://en/236567).
- [Temporal logic](wikipedia://en/321481) introduces an operator that can be used to express statements interpretable as: Certain property will eventually hold in a future moment in time.
