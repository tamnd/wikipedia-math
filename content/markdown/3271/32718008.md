# Vector optimization

::: {#o1 .subject cue=lead name="Vector optimization"}

Multi-objective optimization **Vector optimization** is a subarea of [mathematical optimization](wikipedia://en/52033) where [optimization problems](wikipedia://en/1126536) with a vector-valued [objective functions](https://en.wikipedia.org/wiki/Objective_function) are optimized with respect to a given [partial ordering](https://en.wikipedia.org/wiki/Partial_ordering) and subject to certain constraints. A [multi-objective optimization](wikipedia://en/10251864) problem is a special case of a vector optimization problem: The objective space is the finite dimensional [Euclidean space](wikipedia://en/9697) partially ordered by the component-wise "less than or equal to" ordering.

:::

## Problem formulation {#Problem_formulation}

In mathematical terms, a vector optimization problem can be written as:

$$C\operatorname{-}\min_{x \in S} f(x)$$

where $f: X \to Z$ for a partially ordered [vector space](wikipedia://en/32370) $Z$. The partial ordering is induced by a cone $C \subseteq Z$. $X$ is an arbitrary set and $S \subseteq X$ is called the feasible set.

## Solution concepts {#Solution_concepts}

There are different minimality notions, among them:

- $\bar{x} \in S$ is a *weakly efficient point* (weak minimizer) if for every $x \in S$ one has $f(x) - f(\bar{x}) \not\in -\operatorname{int} C$.
- $\bar{x} \in S$ is an *efficient point* (minimizer) if for every $x \in S$ one has $f(x) - f(\bar{x}) \not\in -C \backslash \{0\}$.
- $\bar{x} \in S$ is a *properly efficient point* (proper minimizer) if $\bar{x}$ is a weakly efficient point with respect to a [closed](wikipedia://en/293802) [pointed convex cone](wikipedia://en/3558266) $\tilde{C}$ where $C \backslash \{0\} \subseteq \operatorname{int} \tilde{C}$.

Every proper minimizer is a minimizer. And every minimizer is a weak minimizer.[^o4]

Modern solution concepts not only consists of minimality notions but also take into account [infimum](https://en.wikipedia.org/wiki/Infimum) attainment.[^o5]

## Solution methods {#Solution_methods}

- [Benson's algorithm](wikipedia://en/35170441) for *linear* vector optimization problems.[^o7]

## Relation to multi-objective optimization {#Relation_to_multi-objective_optimization}

Any multi-objective optimization problem can be written as

$$\mathbb{R}^d_+\operatorname{-}\min_{x \in M} f(x)$$

where $f: X \to \mathbb{R}^d$ and $\mathbb{R}^d_+$ is the non-negative [orthant](wikipedia://en/1283725) of $\mathbb{R}^d$. Thus the minimizer of this vector optimization problem are the [Pareto efficient](https://en.wikipedia.org/wiki/Pareto_efficient) points.
