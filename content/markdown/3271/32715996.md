# Alexiewicz norm

::: {#o1 .subject cue=lead name="Alexiewicz norm"}

In [mathematics](wikipedia://en/18831) — specifically, in [integration theory](wikipedia://en/15532) — the **Alexiewicz norm** is an integral [norm](wikipedia://en/990534) associated to the [Henstock&ndash;Kurzweil integral](https://en.wikipedia.org/wiki/Henstock&ndash;Kurzweil_integral). The Alexiewicz norm turns the space of Henstock–Kurzweil integrable functions into a [topological vector space](wikipedia://en/45752) that is [barrelled](wikipedia://en/1733592) but not [complete](https://en.wikipedia.org/wiki/Complete_space). The Alexiewicz norm is named after the [Polish](https://en.wikipedia.org/wiki/Poland) mathematician [Andrzej Alexiewicz](wikipedia://en/28952583), who introduced it in 1948.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let HK(**R**) denote the space of all functions *f*: **R** → **R** that have finite Henstock–Kurzweil integral. Define the **Alexiewicz semi-norm** of *f* ∈ HK(**R**) by

$$\| f \| := \sup \left\{ \left| \int_{I} f \right| : I \subseteq \mathbb{R} \text{ is an interval} \right\}.$$

This defines a [semi-norm](https://en.wikipedia.org/wiki/Semi-norm) on HK(**R**); if functions that are equal [Lebesgue](wikipedia://en/18198)-[almost everywhere](wikipedia://en/44688) are identified, then this procedure defines a *bona fide* norm on the [quotient](wikipedia://en/237213) of HK(**R**) by the [equivalence relation](wikipedia://en/9259) of equality almost everywhere. (Note that the only constant function *f*: **R** → **R** that is integrable is the one with constant value zero.)

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The Alexiewicz norm endows HK(**R**) with a topology that is barrelled but incomplete.
- The Alexiewicz norm as defined above is [equivalent](wikipedia://en/990534#Properties) to the norm defined by

$$\| f \|' := \sup_{x \in \mathbb{R}} \left| \int_{- \infty}^{x} f \right|.$$

- The [completion](wikipedia://en/7832) of HK(**R**) with respect to the Alexiewicz norm is often denoted A(**R**) and is a subspace of the space of [tempered distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29), the dual of [Schwartz space](wikipedia://en/4277567). More precisely, A(**R**) consists of those tempered distributions that are [distributional derivatives](https://en.wikipedia.org/wiki/Distributional_derivative) of functions in the collection

$$\left\{ F \colon \mathbb{R} \to \mathbb{R} \,\left|\, F \text{ is continuous, } \lim_{x \to - \infty} F(x) = 0, \lim_{x \to + \infty} F(x) \in \mathbb{R} \right. \right\}.$$

Therefore, if *f* ∈ A(**R**), then *f* is a tempered distribution and there exists a continuous function *F* in the above collection such that

$$\langle F', \varphi \rangle = - \langle F, \varphi' \rangle = - \int_{- \infty}^{+ \infty} F \varphi' = \langle f, \varphi \rangle$$

for every [compactly supported](https://en.wikipedia.org/wiki/Compactly_supported) [*C*<sup>∞</sup>](https://en.wikipedia.org/wiki/Smooth_function) [test function](wikipedia://en/301505) *φ*: **R** → **R**. In this case, it holds that

$$\| f \|' = \sup_{x \in \mathbb{R}} |F(x)| = \| F \|_{\infty}.$$

- The translation operator is continuous with respect to the Alexiewicz norm. That is, if for *f* ∈ HK(**R**) and *x* ∈ **R** the translation *T*<sub>*x*</sub>*f* of *f* by *x* is defined by

$$(T_{x} f)(y) := f(y - x),$$

then

$$\| T_{x} f - f \| \to 0 \text{ as } x \to 0.$$
