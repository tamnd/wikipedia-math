# InfoQ

::: {#o1 .subject cue=lead name="InfoQ"}

**Information quality** (**InfoQ**) is the extent to which a [data set](wikipedia://en/8495) can help achieve a specific scientific or practical goal when it is used with a particular [empirical analysis method](https://en.wikipedia.org/wiki/Empirical_research).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

InfoQ is often expressed as `InfoQ = U(X,f|g)`, where X is the data, f is the analysis method, g is the goal, and U is the utility function. In simpler terms, it describes how useful a given set of data is for answering a particular question with a particular method. InfoQ is related to both [data quality](wikipedia://en/1609808) and [analysis quality](wikipedia://en/27250866), but it is not the same as either one; it depends on the quality of the data, the suitability of the analysis, and how well the data, method, and goal fit together.

InfoQ has been applied in fields including healthcare, customer surveys, [data science](wikipedia://en/35458904) programmes, advanced manufacturing, and [Bayesian network](wikipedia://en/203996) applications.

Kenett and [Shmueli](https://en.wikipedia.org/wiki/Galit_Shmueli) (2014) proposed eight dimensions to help assess InfoQ and various methods for increasing InfoQ: data resolution, [data structure](wikipedia://en/8519), data integration, temporal relevance, chronology of data and goal, [generalization](wikipedia://en/12746), [operationalization](wikipedia://en/747363), and communication.
