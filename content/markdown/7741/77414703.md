# Glossary of real and complex analysis

::: {#o1 .subject cue=lead name="Glossary of real and complex analysis"}

This is a glossary of concepts and results in [real analysis](wikipedia://en/26478) and [complex analysis](wikipedia://en/5759) in mathematics. In particular, it includes those in [measure theory](https://en.wikipedia.org/wiki/Measure_theory) (as there is no glossary for measure theory in Wikipedia right now). Also, the topics in [algebraic analysis](wikipedia://en/20846707) are included. However, the items in the theory of differential equations are *not* included.

:::

See also: [list of real analysis topics](wikipedia://en/339396), [list of complex analysis topics](wikipedia://en/340617) and [glossary of functional analysis](wikipedia://en/64208634).

## B {#B}

::: {#o15 .entry cue=term name="Bargmann"}

**Bargmann**

[Bargmann transform](https://en.wikipedia.org/wiki/Bargmann_transform)

:::

::: {#o16 .entry cue=term name="Basel"}

**Basel**

The [Basel problem](wikipedia://en/490303) says $\sum_1^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}.$

:::

::: {#o17 .entry cue=term name="Berezin"}

**Berezin**

[Berezin integral](wikipedia://en/20041308)

:::

::: {#o18 .entry cue=term name="Bolzano"}

**Bolzano**

The [Bolzano-Weierstrass theorem](https://en.wikipedia.org/wiki/Bolzano-Weierstrass_theorem) says a bounded sequence in $\mathbb{R}^n$ has a convergent subsequence. Today it is subsumed in the statement that a subset of a metric space is compact if and only if it is [sequentially compact](https://en.wikipedia.org/wiki/Sequentially_compact) (i.e., every sequence has a convergent subsequence) and the [Heine–Borel theorem](wikipedia://en/59595).

:::

::: {#o19 .entry cue=term name="Borel"}

**Borel**

A [Borel measure](wikipedia://en/4322) is a measure whose domain is the Borel σ-algebra.

The [Borel σ-algebra](https://en.wikipedia.org/wiki/Borel_σ-algebra) on a topological space is the smallest σ-algebra containing all open sets.

[Borel's lemma](wikipedia://en/1461105) says that a given formal power series, there is a smooth function whose Taylor series coincides with the given series.

The [Borel–Lebesgue lemma](https://en.wikipedia.org/wiki/Borel–Lebesgue_lemma) is another name for the [Heine-Borel theorem](https://en.wikipedia.org/wiki/Heine-Borel_theorem).

:::

::: {#o20 .entry cue=term name="bounded"}

**bounded**

A subset $A$ of a metric space $(X,d)$ is [bounded](wikipedia://en/48258) if there is some $C > 0$ such that $d(a,b) < C$ for all $a,b \in A$.

:::

::: {#o21 .entry cue=term name="bump"}

**bump**

A [bump function](wikipedia://en/815799) is a nonzero compactly-supported smooth function, usually constructed using the exponential function.

:::

::: {#o22 .entry cue=term name="BV"}

**BV**

A [BV-function](https://en.wikipedia.org/wiki/BV-function) or a [bounded variation](wikipedia://en/330673) is a function with bounded total variation.

::: {#o30 .entry cue=term name="Cauchy"}

**Cauchy**

The [Cauchy–Riemann equations](wikipedia://en/7583) are a system of differential equations such that a function satisfying it (in the distribution sense) is a [holomorphic function](wikipedia://en/14110).

[Cauchy integral formula](https://en.wikipedia.org/wiki/Cauchy_integral_formula).

[Cauchy residue theorem](https://en.wikipedia.org/wiki/Cauchy_residue_theorem).

[Cauchy's estimate](https://en.wikipedia.org/wiki/Cauchy's_estimate).

The [Cauchy principal value](wikipedia://en/408195) is, when possible, a number assigned to a function when the function is not integrable.

On a metric space, a sequence $x_n$ is called a [Cauchy sequence](wikipedia://en/6085) if $d(x_n, x_m) \to 0$; i.e., for each $\epsilon > 0$, there is an $N > 0$ such that $d(x_n, x_m) < \epsilon$ for all $n, m \ge N$.

[Cauchy condensation test](wikipedia://en/3497105).

**Cavalieri**

:::

::: {#o32 .entry cue=term name="Cesàro"}

**Cesàro**

[Cesàro summation](wikipedia://en/705600) is one way to compute a [divergent series](wikipedia://en/876428).

:::

::: {#o33 .entry cue=term name="Clarke generalized derivative"}

**Clarke generalized derivative**

[Clarke generalized derivative](wikipedia://en/72966849).

:::

::: {#o34 .entry cue=term name="cluster"}

**cluster**

A [cluster point](https://en.wikipedia.org/wiki/Cluster_point) of a net $x_{\alpha}$ (or a sequence) is a point in $\bigcap_{\alpha} \overline{\{ x_{\beta} \mid \beta \gtrsim \alpha \} }$. The notion gives a convenient criterion for compactness: a space (resp. a metric space) is compact if and only if each net (resp. sequence) has a cluster point.

For a [first countable space](https://en.wikipedia.org/wiki/First_countable_space), a point is a cluster point of a sequence $x_i$ if and only if there is a subsequence converging to that point.

:::

::: {#o35 .entry cue=term name="complex"}

**complex**

A [complex number](wikipedia://en/5826) is an element in $\mathbb{C} = \mathbb{R}[x]/(x^2+1)$, the [quotient ring](wikipedia://en/184635) of a polynomial ring, where the image of the indeterminate $x$ is denoted by $i$. As a set, $\mathbb{C}$ can be identified with $\mathbb{R}^2$ and that gives a topology on it.

[complex logarithm](wikipedia://en/4870290).

Given a function $f$ on an open set $U \subset \mathbb{C}$, the [complex derivative](https://en.wikipedia.org/wiki/Complex_derivative) of it is, if any, the limit $\lim_{\mathbb{C} \ni h \to 0} \frac{f(z+h) - f(z)}{h}$.

:::

::: {#o36 .entry cue=term name="continuous"}

**continuous**

A function $f : X \to Y$ between metric spaces $(X,d_X)$ and $(Y,d_Y)$ is [continuous](wikipedia://en/6122) if for any convergent sequence $x_n \to x$ in $X$, we have $f(x_n) \to f(x)$ in $Y$.

:::

::: {#o37 .entry cue=term name="contour"}

**contour**

The [contour integral](https://en.wikipedia.org/wiki/Contour_integral) of a measurable function $f$ over a piece-wise smooth curve $\gamma : [0, 1] \to \mathbb{C}$ is $\int_{\gamma} f \, dz := \int_0^1 \gamma^*(f \, dz)$.

:::

::: {#o38 .entry cue=term name="converge"}

**converge**

A sequence $x_n$ in a topological space is said to [converge](https://en.wikipedia.org/wiki/Converge_%28mathematics%29) to a point $x$ if for each open neighborhood $U$ of $x$, the set $\{ n \mid x_n \not\in U \}$ is finite.

A sequence $x_n$ in a metric space is said to converge to a point $x$ if for all $\epsilon > 0$, there exists an $N > 0$ such that for all $n > N$, we have $d(x_n,x) < \epsilon$.

A series $x_1 + x_2 + \cdots$ on a normed space (e.g., $\mathbb{R}^n$) is said to [converge](wikipedia://en/1743431) if the sequence of the partial sums $s_n := \sum_1^n x_j$ converges.

:::

::: {#o39 .entry cue=term name="convolution"}

**convolution**

The [convolution](wikipedia://en/7519) $f * g$ of two functions on a convex set is given by

$(f * g)(x) = \int f(y - x)g(y) \, dy,$ provided the integration converges.

:::

::: {#o40 .entry cue=term name="Cousin"}

**Cousin**

[Cousin problems](wikipedia://en/622966).

:::

::: {#o41 .entry cue=term name="critical"}

**critical**

[critical point](https://en.wikipedia.org/wiki/Critical_point).

:::

::: {#o42 .entry cue=term name="cutoff"}

**cutoff**

For sets $F \subset U$, $F$ closed, $U$ open, a [cutoff function](https://en.wikipedia.org/wiki/Cutoff_function) is a function that is $1$ on $F$ and has support contained in $U$. It’s usually required to be continuous or smooth.

:::

## D {#D}

::: {#o44 .entry cue=term name="de Branges"}

**de Branges**

[de Branges's theorem](wikipedia://en/252075).

:::

::: {#o45 .entry cue=term name="Dedekind"}

**Dedekind**

A [Dedekind cut](wikipedia://en/45569) is one definition of a real number. By definition, it is a nonempty proper [lower subset](https://en.wikipedia.org/wiki/Lower_subset) $\alpha$ of $\mathbb{Q}$ that has no maximal element, where *lower* means it contains $\{ q \in \mathbb{Q} \mid q < p \}$ for each $p$ in $\alpha$. For example, $\sqrt{2} = \{ p \in \mathbb{Q} \mid p < 0 \text{ or } p^2 < 2 \}$.

:::

::: {#o46 .entry cue=term name="derivative"}

**derivative**

Given a map $f : E \to F$ between normed spaces, the [derivative](wikipedia://en/7921) of $f$ at a point *x* is a (unique) linear map $T : E \to F$ such that $\lim_{h \to 0} \| f(x + h) - f(x) - Th \|/\|h\| = 0$.

:::

::: {#o47 .entry cue=term name="differentiable"}

**differentiable**

A map between normed space is differentiable at a point *x* if the derivative at *x* exists.

:::

::: {#o48 .entry cue=term name="differentiation"}

**differentiation**

[Differentiation under the integral sign](https://en.wikipedia.org/wiki/Differentiation_under_the_integral_sign)

:::

::: {#o49 .entry cue=term name="Dini"}

**Dini**

[Dini's theorem](wikipedia://en/9177825).

:::

::: {#o50 .entry cue=term name="Dirac"}

**Dirac**

The [Dirac delta function](wikipedia://en/37021) $\delta_0$ on $\mathbb{R}^n$ is a distribution (so not exactly a function) given as $\langle \delta_0, \varphi \rangle = \varphi(0).$

A [Dirac sequence](https://en.wikipedia.org/wiki/Dirac_sequence).<https://planetmath.org/diracsequence>

:::

::: {#o51 .entry cue=term name="distribution"}

**distribution**

A [distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) is a type of a generalized function; precisely, it is a continuous linear functional on the space of test functions.

:::

::: {#o52 .entry cue=term name="divergent"}

**divergent**

A [divergent series](wikipedia://en/876428) is a series whose partial sum does not converge. For example, $\sum_1^{\infty} \frac{1}{n}$ is divergent.

:::

::: {#o53 .entry cue=term name="division conjecture"}

**division conjecture**

The [division conjecture of L. Schwartz](https://en.wikipedia.org/wiki/Division_conjecture_of_L._Schwartz) (now a theorem) says a distribution divided by a real analytic function is again a distribution.

:::

::: {#o54 .entry cue=term name="dominated"}

**dominated**

[Lebesgue's dominated convergence theorem](https://en.wikipedia.org/wiki/Lebesgue's_dominated_convergence_theorem) says $\int f_n \, d\mu$ converges to $\int f \, d\mu$ if $f_n$ is a sequence of measurable functions such that $f_n$ converges to $f$ pointwise and $|f_n| \le g$ for some integrable function $g$.

:::

## E {#E}

::: {#o56 .entry cue=term name="e"}

**e**

[Euler's number](https://en.wikipedia.org/wiki/Euler's_number). One definition is through the series representation of the exponential function; namely, $e = \sum_0^{\infty} \frac{1}{n!}$. Another is through natural logarithm; namely, $\log(e) = 1$.

:::

::: {#o57 .entry cue=term name="edge"}

**edge**

[Edge-of-the-wedge theorem](wikipedia://en/1657665).

:::

::: {#o58 .entry cue=term name="Egoroff"}

**Egoroff**

[Egoroff's theorem](https://en.wikipedia.org/wiki/Egoroff's_theorem).

:::

::: {#o59 .entry cue=term name="entire"}

**entire**

An [entire function](wikipedia://en/10372) is a holomorphic function whose domain is the entire complex plane.

:::

::: {#o60 .entry cue=term name="equicontinuous"}

**equicontinuous**

A set $S$ of maps between fixed metric spaces is said to be [equicontinuous](https://en.wikipedia.org/wiki/Equicontinuous) if for each $\epsilon > 0$, there exists a $\delta > 0$ such that $\sup_{f \in S} d(f(x), f(y)) < \epsilon$ for all $x, y$ with $d(x, y) < \delta$. A map $f$ is uniformly continuous if and only if $\{ f \}$ is equicontinuous.

:::

::: {#o61 .entry cue=term name="Euler"}

**Euler**

The [Euler–Maclaurin formula](wikipedia://en/9637).

:::

::: {#o62 .entry cue=term name="exponential"}

**exponential**

The [exponential function](wikipedia://en/9678) is the function $z \mapsto e^z$ on the complex plane, where $e$ is [Euler's number](https://en.wikipedia.org/wiki/Euler's_number). If the number $e$ is defined through the exponential function, then the exponential function is defined more directly as: $z \mapsto \sum_1^{\infty} \frac{z^n}{n!}$.

## F {#F}

::: {#o64 .entry cue=term name="Fatou"}

**Fatou**

[Fatou's lemma](wikipedia://en/291614)

:::

::: {#o65 .entry cue=term name="finite interesection property"}

**finite interesection property**

Given a topological space $X$, a family $F$ of closed subsets of $X$ is said to have the [finite intersection property](wikipedia://en/365026) if each finite subset of $F$ has nonempty intersection. Then saying $X$ is compact can be restated as: each family of closed subsets of $X$ with the finite intersection property has nonempty intersection.

:::

::: {#o66 .entry cue=term name="filter"}

**filter**

A [filter](https://en.wikipedia.org/wiki/Filter_%28topology%29) $F$ on a set $X$ is a proper subset of the power set of $X$ such that

([upper](https://en.wikipedia.org/wiki/Upper_set)) if $S$ is in $F$, each subset of $X$ containing $S$ is also in $F$ and

([downward directed](https://en.wikipedia.org/wiki/Directed_downward)) the intersection of each finite subset of $F$ is in $F$. Its role is similar to that of nets but in analysis, nets are more commonly used.

Given a net $x_{\alpha}$, there is the filter $F$ determined by it; namely, the filter generated by the tails $\{ x_{\beta} \mid \beta \gtrsim \alpha \}$. Then for example, $x_{\alpha}$ converges to a point $x$ if and only if $F$ converges to $x$ (meaning $F$ contains every neighborhood of $x$). Conversely, given a filter, we can choose a net associated to it so that all the associated nets determine the original filter.[^o67]

:::

::: {#o68 .entry cue=term name="first"}

**first**

A [first countable space](https://en.wikipedia.org/wiki/First_countable_space) is a topological space in which each point $x$ has a decreasing sequence of neighborhoods $x \in \cdots \subset U_2 \subset U_1 \subset U_0$ such that each neighborhood of $x$ contains some $U_n$. An important property of such a space is that a point is in the closure of a set $E$ if and only if there is a sequence in $E$ that converges to that point.

:::

::: {#o69 .entry cue=term name="Fock"}

**Fock**

[Fock space](wikipedia://en/230491)

:::

::: {#o70 .entry cue=term name="Fourier"}

**Fourier**

The [Fourier transform](wikipedia://en/52247) of a function $f$ on $\mathbb{R}^n$ is: (provided it makes sense)

$$\widehat{f}(\xi) = \int f(x) e^{-2\pi i x \cdot \xi} \, dx.$$

The Fourier transform $\widehat{f}$ of a distribution $f$ is $\langle \widehat{f}, \varphi \rangle = \langle f, \widehat{\varphi} \rangle$. For example, $\widehat{\delta_0} = 1$ (Fourier's inversion formula).

:::

::: {#o71 .entry cue=term name="Fubini"}

**Fubini**

[Fubini's theorem](wikipedia://en/255245) computes an integral as iterated integrals.

:::

## H {#H}

::: {#o80 .entry cue=term name="Hardy-Littlewood maximal inequality"}

**Hardy-Littlewood maximal inequality**

The [Hardy-Littlewood maximal function](https://en.wikipedia.org/wiki/Hardy-Littlewood_maximal_function) of $f \in L^1(\mathbb R^n)$ is

$Hf(x) := \sup_{r>0} \frac{1}{m(B_r(x))} \int_{B_r(x)} |f|.$ The [Hardy-Littlewood maximal inequality](https://en.wikipedia.org/wiki/Hardy-Littlewood_maximal_inequality) states that there is some constant $C$ such that for all $f \in L^1(\mathbb R^n)$ and all $\alpha > 0$,

$$m\left(\{ x : Hf(x) > \alpha \}\right) < \frac{C}{\alpha} \int_{\mathbb R^n} |f|.$$

:::

::: {#o81 .entry cue=term name="Hardy space"}

**Hardy space**

[Hardy space](wikipedia://en/314780)

:::

::: {#o82 .entry cue=term name="Hartogs"}

**Hartogs**

[Hartogs extension theorem](https://en.wikipedia.org/wiki/Hartogs_extension_theorem)

[Hartogs's theorem on separate holomorphicity](wikipedia://en/2978799)

:::

::: {#o83 .entry cue=term name="harmonic"}

**harmonic**

A function is [harmonic](wikipedia://en/55762) if it satisfies the Laplace equation (in the distribution sense if the function is not twice differentiable).

:::

::: {#o84 .entry cue=term name="Hausdorff"}

**Hausdorff**

The [Hausdorff–Young inequality](wikipedia://en/22386332) says that the Fourier transformation $\widehat{\cdot} : L^p(\mathbb{R}^n) \to L^{p'}(\mathbb{R}^n)$ is a well-defined bounded operator when $1/p + 1/p' = 1$.

:::

::: {#o85 .entry cue=term name="Heaviside"}

**Heaviside**

The [Heaviside function](https://en.wikipedia.org/wiki/Heaviside_function) is the function *H* on $\mathbb{R}$ such that $H(x) = 1, \, x \ge 0$ and $H(x) = 0, \, x < 0$.

:::

::: {#o86 .entry cue=term name="Heine"}

**Heine**

The [Heine–Borel theorem](wikipedia://en/59595) says a subset of $\mathbb{R}^n$ is compact if and only if it is closed and bounded.

The above theorem follows from a more general result: a metric space is compact if and only if it is complete and totally ordered, since a bounded set in a Euclidean space is totally bounded.

:::

::: {#o87 .entry cue=term name="Hermite"}

**Hermite**

[Hermite polynomial](https://en.wikipedia.org/wiki/Hermite_polynomial)

:::

::: {#o88 .entry cue=term name="Hilbert space"}

**Hilbert space**

A [Hilbert space](wikipedia://en/20598932) is a real or complex inner product space that is a complete metric space with the metric induced by the inner product.

[Hilbert transform](wikipedia://en/574024).

:::

::: {#o89 .entry cue=term name="holomorphic function"}

**holomorphic function**

A function defined on an open subset of $\mathbb C^n$ is [holomorphic](https://en.wikipedia.org/wiki/Holomorphic) if it is [complex differentiable](https://en.wikipedia.org/wiki/Complex_differentiable). Equivalently, a function is holomorphic if it satisfies the Cauchy–Riemann equations (in the distribution sense if the function is not differentiable).

:::

::: {#o90 .entry cue=term name="hypoelliptic"}

**hypoelliptic**

A [hypoelliptic operator](wikipedia://en/9282128) is an operator for which the elliptic regularity holds.

:::

## I {#I}

::: {#o92 .entry cue=term name="infinitesimal"}

**infinitesimal**

An [infinitesimal](wikipedia://en/160990) is a "number" that is greater then zero but is smaller than any positive real number; in particular, it is not a real number.

:::

::: {#o93 .entry cue=term name="integrable"}

**integrable**

A measurable function $f$ is said to be [integrable](https://en.wikipedia.org/wiki/Integrable_function) if $\int |f| \, d\mu < \infty$.

:::

::: {#o94 .entry cue=term name="integral"}

**integral**

The [integral](wikipedia://en/15532) of the [indicator function](wikipedia://en/240790) on a measurable set is the measure (volume) of the set.

The integral of a measurable function is then defined by approximating the function by linear combinations of indicator functions.

:::

::: {#o95 .entry cue=term name="inverse"}

**inverse**

The [inverse function theorem](wikipedia://en/287229) gives a necessary and sufficient condition for a function to be injective. Note it only gives an "inverse function" on the image of the function.

:::

::: {#o96 .entry cue=term name="isolated"}

**isolated**

An [isolated point](wikipedia://en/390557) of a set is a point that is not a limit point of the set.

:::

::: {#o97 .entry cue=term name="isometry"}

**isometry**

An isometry between metric spaces $(X,d_X)$ and $(Y,d_Y)$ is a bijection $f : X \to Y$ that preserves the metric: $d_X(x,x') = d_Y(f(x),f(x'))$ for all $x,x' \in X$.

:::

## J {#J}

::: {#o99 .entry cue=term name="jet"}

**Lebesgue differentiation theorem**

The [Lebesgue differentiation theorem](wikipedia://en/5766547) states that for locally integrable $f \in L^1_{\text{loc}}(\mathbb R^n)$, the equalities

$\lim_{r \to 0} \frac{1}{m(B_r(x))} \int_{B_r(x)} |f(y)-f(x)| \,dy = 0$ and

$\lim_{r \to 0} \frac{1}{m(B_r(x))} \int_{B_r(x)} f = f(x)$ hold for almost every $x$. The set where they hold is called the Lebesgue set of $f$, and points in the Lebesgue set are called [Lebesgue points](wikipedia://en/1519594).

A [measure](wikipedia://en/19873) is a function on a measurable space that assigns to each measurable set a number representing its measure or size. Specifically, if $X$ is a set and $\Sigma$ is a $\sigma$-algebra on $X$, then a set-function $\mu$ from $\Sigma$ to the extended real number line is called a measure if the following conditions hold:

::: {#o138 .entry cue=term name="normed vector space"}

**normed vector space**

A [normed vector space](wikipedia://en/21538), also called a normed space, is a real or complex vector space $V$ on which a norm is defined. A norm is a map $\lVert\cdot \rVert : V \to \mathbb R$ satisfying four axioms:

Non-negativity: for every $x\in V$,$\; \lVert x \rVert \ge 0$.

Positive definiteness: for every $x \in V$, $\; \lVert x\rVert=0$ if and only if $x$ is the zero vector.

Absolute homogeneity: for every scalar $\lambda$ and $x\in V$,

$$\lVert \lambda x \rVert = |\lambda|\, \lVert x\rVert$$

Triangle inequality: for every $x\in V$ and $y\in V$,

$$\|x+y\| \leq \|x\| + \|y\|.$$

::: {#o156 .entry cue=term name="Radon"}

**Radon**

Let $X$ be a locally compact Hausdorff space and let $I$ be a positive linear functional on the space of continuous functions with compact support $C_c(X)$. Positivity means that $I(f) \geq 0$ if $f \geq 0$. There exist Borel measures $\mu$ on $X$ such that $I(f) = \int f \, d\mu$ for all $f \in C_c(X)$. A [Radon measure](wikipedia://en/521933) on $X$ is a Borel measure that is finite on all compact sets, [outer regular](https://en.wikipedia.org/wiki/Outer_regular) on all Borel sets, and [inner regular](https://en.wikipedia.org/wiki/Inner_regular) on all open sets. These conditions guarantee that there exists a *unique* Radon measure $\mu$ on $X$ such that $I(f) = \int f \, d\mu$ for all $f \in C_c(X)$.

[Radon–Nikodym theorem](wikipedia://en/338746).

::: {#o180 .entry cue=term name="Stone–Weierstrass theorem"}

**Stone–Weierstrass theorem**

The [Stone–Weierstrass theorem](wikipedia://en/28858) is any one of a number of related generalizations of the Weierstrass approximation theorem, which states that any continuous real-valued function defined on a closed interval can be uniformly approximated by polynomials. Let $X$ be a compact Hausdorff space and let $C(X,\mathbb R)$ have the uniform metric. One version of the Stone–Weierstrass theorem states that if $\mathcal A$ is a closed subalgebra of $C(X,\mathbb R)$ that separates points and contains a nonzero constant function, then in fact $\mathcal A = C(X,\mathbb R)$. If a subalgebra is not closed, taking the closure and applying the previous version of the Stone–Weierstrass theorem reveals a different version of the theorem: if $\mathcal A$ is a subalgebra of $C(X,\mathbb R)$ that separates points and contains a nonzero constant function, then $\mathcal A$ is dense in $C(X,\mathbb R)$.

The [Whitney extension theorem](wikipedia://en/5456164) gives a necessary and sufficient condition for a function to be extended from a closed set to a smooth function on the ambient space.
