# Lieb's square ice constant

*Image: Square ice.svg.* An [Eulerian orientation](https://en.wikipedia.org/wiki/Eulerian_orientation) of a 4×4 [periodic](wikipedia://en/9667552) [grid graph](https://en.wikipedia.org/wiki/Grid_graph). The [orientation](wikipedia://en/36619818) (assignment of a direction to the edges of an undirected graph) is *Eulerian* because every vertex has equally many edges entering and leaving.

::: {#o2 .subject cue=lead name="Lieb's square ice constant"}

**Lieb's square ice constant** is a [mathematical constant](wikipedia://en/48779551) used in the field of [combinatorics](wikipedia://en/5170) to approximately count [Eulerian orientations](https://en.wikipedia.org/wiki/Eulerian_orientation) of [grid graphs](https://en.wikipedia.org/wiki/Grid_graph). It was introduced by [Elliott H. Lieb](https://en.wikipedia.org/wiki/Elliott_H._Lieb) in 1967.[^o3] It is called the square ice constant because the orientations that it counts arise in [statistical mechanics](wikipedia://en/28481) of crystalline structures as the states of an [ice-type model](wikipedia://en/20096022) on a square grid.

:::

The value of Lieb's square ice constant is

$$\frac{8 \sqrt{3}}{9}\approx 1.5396.$$

Based on this, the number of Eulerian orientations of an $n\times n$ grid is

$$\left(\frac{8 \sqrt{3}}{9}-o(1)\right)^{n^2},$$

where the $o(1)$ term, an instance of [little o notation](https://en.wikipedia.org/wiki/Little_o_notation), hides parts of the formula that tend to zero in the limit as $n$ grows.

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

An $n\times n$ grid graph has $n^2$ vertices. When constructed with [periodic boundary conditions](wikipedia://en/9667552) (with edges that wrap around from left to right and from top to bottom) it has $2n^2$ edges and is [4-regular](wikipedia://en/85821), meaning that each vertex has exactly four neighbors. An [orientation](wikipedia://en/36619818) of this graph is an assignment of a [direction](wikipedia://en/19721986) to each edge. It is an [Eulerian orientation](wikipedia://en/333219) if it gives each vertex exactly two incoming edges and exactly two outgoing edges. An Eulerian orientation can be constructed by orienting each row of the grid (including the wraparound edge) as a cycle, and each column as another cycle, but there are many more orientations that are not of this special form.

Denote the number of Eulerian orientations of this graph by $f(n)$. Then this number is approximately exponential in $n^2$, with Lieb's square ice constant as the base of the exponential. More precisely,

$$\lim_{n \to \infty}\sqrt[n^2]{f(n)}=\left(\frac{4}{3}\right)^\frac{3}{2}=\frac{8 \sqrt{3}}{9}=1.5396007\dots$$

is Lieb's square ice constant. Lieb used a [transfer-matrix method](wikipedia://en/8964423) to compute this exactly.[^o3]

:::

## Applications {#Applications}

Lieb's original motivation for studying this counting problem comes from [statistical mechanics](wikipedia://en/28481). In this area, the [ice-type models](wikipedia://en/20096022) are used to model [hydrogen bonds](https://en.wikipedia.org/wiki/Hydrogen_bond) in crystalline structures such as [water ice](https://en.wikipedia.org/wiki/Ice) where each element of the structure (such as a water molecule) has bonds connecting it to four neighbors, with two bonds of each [polarity](https://en.wikipedia.org/wiki/Chemical_polarity). A state of this system describes the polarity of the hydrogen bond for each of the four neighbors. If the elements and their adjacencies are described by the vertices and edges of an undirected graph, the polarities of their bonds can be described by orienting this graph, with two edges of each direction at each vertex. With an additional assumption that all consistent choices of orientation have equal energy, the number of possible states equals the [partition function](wikipedia://en/312252), important for calculating the properties of a system at [thermodynamic equilibrium](wikipedia://en/265823). Different crystalline structures have different partition functions; the value calculated by Lieb is for an unrealistic model in which the water molecules or other elements are arranged in a square grid.[^o3] As well as for hydrogen bonds, analogous arrangements of elements with four neighbors, obeying the same two-in two-out rules, can occur in [spin ice](https://en.wikipedia.org/wiki/Spin_ice), and the same calculation of the partition function applies in that case.

The function $f(n)$ also counts the number of [3-colorings](wikipedia://en/426743) of grid graphs, the number of [nowhere-zero 3-flows](wikipedia://en/9909979) in grid graphs, and the number of local flat foldings of the [Miura fold](wikipedia://en/2894962).[^o11]
