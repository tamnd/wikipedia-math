# Priority matching

::: {#o1 .subject cue=lead name="Priority matching"}

In [graph theory](wikipedia://en/12401), a **priority matching** (also called: **maximum priority matching**) is a [matching](wikipedia://en/581797) that maximizes the number of high-priority [vertices](wikipedia://en/638899) that participate in the matching. Formally, we are given a [graph](wikipedia://en/325806) $G = (V, E)$, and a [partition](wikipedia://en/11973947) of the vertex-set $V$ into some $k$ subsets, $V_{1}, \ldots, V_{k}$, called *priority classes*. A priority matching is a matching that, among all possible matchings, saturates the largest number of vertices from $V_{1}$; subject to this, it saturates the largest number of vertices from $V_{2}$; subject to this, it saturates the largest number of vertices from $V_{3}$; and so on.

:::

Priority matchings were introduced by [Alvin Roth](https://en.wikipedia.org/wiki/Alvin_E._Roth), [Tayfun Sonmez](https://en.wikipedia.org/wiki/Tayfun_Sönmez) and [Utku Unver](https://en.wikipedia.org/wiki/Utku_Unver)[^o2] in the context of [kidney exchange](https://en.wikipedia.org/wiki/Kidney_exchange). In this problem, the vertices are patient-donor pairs, and each edge represents a mutual medical compatibility. For example, an edge between pair 1 and pair 2 indicates that donor 1 is compatible with patient 2 and donor 2 is compatible with patient 1. The priority classes correspond to medical priority among patients. For example, some patients are in a more severe condition so they must be matched first. Roth, Sonmez and Unver assumed that each priority-class contains a single vertex, i.e., the priority classes induce a [total order](wikipedia://en/30330) among the pairs.

Later, Yasunori Okumura[^o3] extended the work to priority-classes that may contain any number of vertices. He also showed how to find a priority matching efficiently using an algorithm for [maximum-cardinality matching](https://en.wikipedia.org/wiki/Maximum_cardinality_matching), with a [run-time complexity](https://en.wikipedia.org/wiki/Run-time_complexity) of $O(\lvert V\rvert\lvert E\rvert + \lvert V\rvert^{2} \log \lvert V\rvert)$.

[Jonathan S. Turner](https://en.wikipedia.org/wiki/Jonathan_S._Turner)[^o4] presented a variation of the augmenting path method ([Edmonds' algorithm](wikipedia://en/11510650)) that finds a priority matching in time $O(\lvert V\rvert\lvert E\rvert)$. Later, he found a faster algorithm for [bipartite graphs](wikipedia://en/244431): the algorithm runs in time[^o5]

$$O(k |E| \sqrt{|V|} )$$
