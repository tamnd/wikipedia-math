# Landweber iteration

::: {#o1 .subject cue=lead name="Landweber iteration"}

The **Landweber iteration** or **Landweber algorithm** is an algorithm to solve [ill-posed](https://en.wikipedia.org/wiki/Ill-posed) linear [inverse problems](https://en.wikipedia.org/wiki/Inverse_problems), and it has been extended to solve non-linear problems that involve constraints. The method was first proposed in the 1950s by [Louis Landweber](https://en.wikipedia.org/wiki/Louis_Landweber),[^o15] and it can be now viewed as a special case of many other more general methods.[^o16]

:::

## Basic algorithm {#Basic_algorithm}

The original Landweber algorithm[^o15] attempts to recover a signal *x* from (noisy) measurements *y*. The linear version assumes that $y = Ax$ for a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) *A*. When the problem is in finite [dimensions](https://en.wikipedia.org/wiki/Dimensions), *A* is just a matrix.

When *A* is [nonsingular](wikipedia://en/253260#Singularities), then an explicit solution is $x = A^{-1} y$. However, if *A* is [ill-conditioned](https://en.wikipedia.org/wiki/Ill-conditioned), the explicit solution is a poor choice since it is sensitive to any noise in the data *y*. If *A* is [singular](https://en.wikipedia.org/wiki/Mathematical_singularity), this explicit solution doesn't even exist. The Landweber algorithm is an attempt to [regularize](wikipedia://en/2009061) the problem, and is one of the alternatives to [Tikhonov regularization](https://en.wikipedia.org/wiki/Tikhonov_regularization). We may view the Landweber algorithm as solving:

$$\min_x \|Ax-y\|_2^2/2$$

using an [iterative method](wikipedia://en/15237). The algorithm is given by the update

$$x_{k+1} = x_{k} - \omega A^*(Ax_k - y).$$

where the relaxation factor $\omega$ satisfies $0 < \omega < 2/\sigma_1^2$. Here $\sigma_1$ is the largest [singular value](wikipedia://en/142207) of $A$. If we write $f(x) = \|Ax-y\|_2^2 /2$, then the update can be written in terms of the [gradient](wikipedia://en/12461)

$$x_{k+1} = x_k - \omega \nabla f(x_k)$$

and hence the algorithm is a special case of [gradient descent](wikipedia://en/201489).

For [ill-posed](https://en.wikipedia.org/wiki/Ill-posed) problems, the iterative method needs to be stopped at a suitable iteration index, because it semi-converges. This means that the iterates approach a regularized solution during the first iterations, but become unstable in further iterations. The reciprocal of the iteration index $1/k$ acts as a regularization parameter. A suitable parameter is found, when the mismatch $\|Ax_k-y\|_2^2$ approaches the noise level.

Using the Landweber iteration as a [regularization](wikipedia://en/2009061) algorithm has been discussed in the literature.[^o3][^o4]

## Nonlinear extension {#Nonlinear_extension}

In general, the updates generated by $x_{k+1} = x_{k} - \tau \nabla f(x_k)$ will generate a sequence $f(x_k)$ that [converges](wikipedia://en/26551602) to a minimizer of *f* whenever *f* is [convex](wikipedia://en/245568) and the stepsize $\tau$ is chosen such that $0 < \tau < 2/( \|\nabla f\|^2 )$ where $\|\cdot \|$ is the [spectral norm](https://en.wikipedia.org/wiki/Spectral_norm).

Since this is special type of gradient descent, there currently is not much benefit to analyzing it on its own as the nonlinear Landweber, but such analysis was performed historically by many communities not aware of unifying frameworks.

The nonlinear Landweber problem has been studied in many papers in many communities; see, for example.[^o6]

## Extension to constrained problems {#Extension_to_constrained_problems}

If *f* is a [convex function](wikipedia://en/245568) and *C* is a [convex set](wikipedia://en/6292), then the problem

$$\min_{x \in C} f(x)$$

can be solved by the constrained, nonlinear Landweber iteration, given by:

$$x_{k+1} = \mathcal{P}_C( x_{k} - \tau \nabla f(x_k) )$$

where $\mathcal{P}$ is the [projection](wikipedia://en/3909097) onto the set *C*. Convergence is guaranteed when $0 < \tau < 2/( \|A\|^2 )$.[^o8] This is again a special case of [projected gradient descent](https://en.wikipedia.org/wiki/Projected_gradient_descent) (which is a special case of the [forward–backward algorithm](https://en.wikipedia.org/wiki/Forward–backward_algorithm_%28operator_splitting%29)) as discussed in.[^o16]

## Applications {#Applications}

Since the method has been around since the 1950s, it has been adopted and rediscovered by many scientific communities, especially those studying ill-posed problems. In [X-ray computed tomography](https://en.wikipedia.org/wiki/X-ray_computed_tomography) it is called simultaneous [iterative reconstruction](https://en.wikipedia.org/wiki/Iterative_reconstruction) technique (SIRT). It has also been used in the [computer vision](https://en.wikipedia.org/wiki/Computer_vision) community[^o11] and the signal restoration community.[^o12] It is also used in [image processing](https://en.wikipedia.org/wiki/Image_processing), since many image problems, such as [deconvolution](wikipedia://en/275626), are ill-posed. Variants of this method have been used also in [sparse approximation](wikipedia://en/15951862) problems and [compressed sensing](wikipedia://en/11403316) settings.[^o13]
