# Ellis–Numakura lemma

::: {#o1 .subject cue=lead name="Ellis–Numakura lemma"}

In [mathematics](wikipedia://en/18831), the **Ellis–Numakura lemma** states that if *S* is a non-empty [semigroup](wikipedia://en/27799) with a topology such that *S* is a [compact space](wikipedia://en/6042) and the product is semi-continuous, then *S* has an [idempotent](https://en.wikipedia.org/wiki/Idempotent) element *p*, (that is, with *pp* = *p*). The [lemma](wikipedia://en/18634) is named after Robert Ellis and Katsui Numakura.

:::

The compact topological semigroups appearing in this lemma should be distinguished with [compact semigroups](wikipedia://en/37442539), in which "compact" is not used with its topological meaning.

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

Applying this lemma to the [Stone–Čech compactification](wikipedia://en/52897) *βN* of the natural numbers shows that there are idempotent elements in *βN*. The product on *βN* is not continuous, but is only semi-continuous (right or left, depending on the preferred construction, but never both).

:::

::: {#o5 .proof cue=heading name="Proof"}

## Proof {#Proof}

- By compactness and [Zorn's Lemma](https://en.wikipedia.org/wiki/Zorn's_Lemma), there is a minimal non-empty compact sub semigroup of *S*, so replacing *S* by this sub semi group we can assume *S* is minimal.
- Choose *p* in *S*. The set *Sp* is a non-empty compact subsemigroup, so by minimality it is *S* and in particular contains *p*, so the set of elements *q* with *qp* = *p* is non-empty.
- The set of all elements *q* with *qp* = *p* is a compact semigroup, and is nonempty by the previous step, so by minimality it is the whole of *S* and therefore contains *p*. So *pp* = *p*.

:::
