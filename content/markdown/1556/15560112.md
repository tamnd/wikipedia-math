# Stability spectrum

::: {#o1 .subject cue=lead name="Stability spectrum"}

In [model theory](wikipedia://en/19858), a branch of [mathematical logic](wikipedia://en/19636), a [complete](wikipedia://en/10086335) [first-order theory](https://en.wikipedia.org/wiki/First-order_theory) *T* is called **stable in λ** (an infinite [cardinal number](wikipedia://en/6173)), if the [Stone space](wikipedia://en/3741564#Stone_spaces) of every [model](wikipedia://en/4055928) of *T* of size ≤ λ has itself size ≤ λ. *T* is called a **stable theory** if there is no upper bound for the cardinals κ such that *T* is stable in κ. The **stability spectrum** of *T* is the class of all cardinals κ such that *T* is stable in κ.

:::

For countable theories there are only four possible stability spectra. The corresponding [dividing lines](https://en.wikipedia.org/wiki/Dividing_line_%28model_theory%29) are those for [total transcendentality](https://en.wikipedia.org/wiki/Totally_transcendental_theory), [superstability](https://en.wikipedia.org/wiki/Superstable_theory) and [stability](wikipedia://en/15828771). This result is due to [Saharon Shelah](wikipedia://en/331211), who also defined stability and superstability.

::: {#o3 .statement kind=statement/theorem cue=named-heading name="The stability spectrum theorem for countable theories"}

## The stability spectrum theorem for countable theories {#The_stability_spectrum_theorem_for_countable_theories}

::: {#o4 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Every countable complete first-order theory *T* falls into one of the following classes:

- *T* is stable in λ for all infinite cardinals λ—*T* is totally transcendental.
- *T* is stable in λ exactly for all cardinals λ with λ ≥ 2<sup>ω</sup>—*T* is superstable but not totally transcendental.
- *T* is stable in λ exactly for all cardinals λ that satisfy λ = λ<sup>ω</sup>—*T* is stable but not superstable.
- *T* is not stable in any infinite cardinal λ—*T* is unstable.

The condition on λ in the third case holds for cardinals of the form λ = κ<sup>ω</sup>, but not for cardinals λ of cofinality ω (because λ \< λ<sup>cof λ</sup>).

:::

### Totally transcendental theories {#Totally_transcendental_theories}

A complete first-order theory *T* is called **totally transcendental** if every formula has bounded [Morley rank](wikipedia://en/1401941), i.e. if RM(φ) \< ∞ for every formula φ(*x*) with parameters in a model of *T*, where *x* may be a tuple of variables. It is sufficient to check that RM(*x*=*x*) \< ∞, where *x* is a single variable.

For countable theories total transcendence is equivalent to stability in ω, and therefore countable totally transcendental theories are often called **ω-stable** for brevity. A totally transcendental theory is stable in every λ ≥ |*T*|, hence a countable ω-stable theory is stable in all infinite cardinals.

Every [uncountably categorical](https://en.wikipedia.org/wiki/Morley's_categoricity_theorem) countable theory is totally transcendental. This includes complete theories of vector spaces or algebraically closed fields. The theories of [groups of finite Morley rank](https://en.wikipedia.org/wiki/Group_of_finite_Morley_rank) are another important example of totally transcendental theories.

### Superstable theories {#Superstable_theories}

A complete first-order theory *T* is superstable if there is a rank function on complete types that has essentially the same properties as Morley rank in a totally transcendental theory. Every totally transcendental theory is superstable. A theory *T* is superstable if and only if it is stable in all cardinals λ ≥ 2<sup>\|*T*|</sup>.

### Stable theories {#Stable_theories}

A theory that is stable in one cardinal λ ≥ |*T*| is stable in all cardinals λ that satisfy λ = λ<sup>\|*T*|</sup>. Therefore a theory is stable if and only if it is stable in some cardinal λ ≥ |*T*|.

### Unstable theories {#Unstable_theories}

Most mathematically interesting theories fall into this category, including complicated theories such as any complete extension of ZF set theory, and relatively tame theories such as the theory of real closed fields. This shows that the stability spectrum is a relatively blunt tool. To get somewhat finer results one can look at the exact cardinalities of the Stone spaces over models of size ≤ λ, rather than just asking whether they are at most λ.

:::

## The uncountable case {#The_uncountable_case}

For a general stable theory *T* in a possibly uncountable language, the stability spectrum is determined by two cardinals κ and λ<sub>0</sub>, such that *T* is stable in λ exactly when λ ≥ λ<sub>0</sub> and λ<sup>μ</sup> = λ for all μ\<κ. So λ<sub>0</sub> is the smallest infinite cardinal for which *T* is stable. These invariants satisfy the inequalities

- κ ≤ |*T*|<sup>\+</sup>
- κ ≤ λ<sub>0</sub>
- λ<sub>0</sub> ≤ 2<sup>\|*T*|</sup>
- If λ<sub>0</sub> > |*T*|, then λ<sub>0</sub> ≥ 2<sup>ω</sup>

When |*T*| is countable the 4 possibilities for its stability spectrum correspond to the following values of these cardinals:

- κ and λ<sub>0</sub> are not defined: *T* is unstable.
- λ<sub>0</sub> is 2<sup>ω</sup>, κ is ω<sub>1</sub>: *T* is stable but not superstable
- λ<sub>0</sub> is 2<sup>ω</sup>, κ is ω: *T* is superstable but not ω-stable.
- λ<sub>0</sub> is ω, κ is ω: *T* is totally transcendental (or ω-stable)
