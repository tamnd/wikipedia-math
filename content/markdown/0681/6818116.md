# Regulated integral

::: {#o1 .subject cue=lead name="Regulated integral"}

In [mathematics](wikipedia://en/18831), the **regulated integral** is a definition of [integration](wikipedia://en/15532) for [regulated functions](wikipedia://en/9776617), which are defined to be [uniform limits](wikipedia://en/349755) of [step functions](wikipedia://en/170939). The use of the regulated integral instead of the [Riemann integral](wikipedia://en/26390) has been advocated by [Nicolas Bourbaki](wikipedia://en/167394) and [Jean Dieudonné](wikipedia://en/1070084).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Definition on step functions {#Definition_on_step_functions}

Let \[*a*, *b*\] be a fixed [closed](wikipedia://en/47279), [bounded](wikipedia://en/48258) [interval](wikipedia://en/49172) in the [real line](https://en.wikipedia.org/wiki/Real_line) **R**. A real-valued function *φ* : \[*a*, *b*\] → **R** is called a **step function** if there exists a finite [partition](wikipedia://en/471332)

$$\Pi = \{ a = t_0 < t_1 < \cdots < t_k = b \}$$

of \[*a*, *b*\] such that *φ* is constant on each [open](wikipedia://en/39358) interval (*t*<sub>*i*</sub>, *t*<sub>*i*+1</sub>) of Π; suppose that this constant value is *c*<sub>*i*</sub> ∈ **R**. Then, define the **integral** of a step function *φ* to be

$$\int_a^b \varphi(t) \, \mathrm{d} t := \sum_{i = 0}^{k - 1} c_i | t_{i + 1} - t_i |.$$

It can be shown that this definition is independent of the choice of partition, in that if Π<sub>1</sub> is another partition of \[*a*, *b*\] such that *φ* is constant on the open intervals of Π<sub>1</sub>, then the numerical value of the integral of *φ* is the same for Π<sub>1</sub> as for Π.

### Extension to regulated functions {#Extension_to_regulated_functions}

A function *f* : \[*a*, *b*\] → **R** is called a **[regulated function](wikipedia://en/9776617)** if it is the uniform limit of a sequence of step functions on \[*a*, *b*\]:

- there is a sequence of step functions (*φ*<sub>*n*</sub>)<sub>*n*∈**N**</sub> such that || *φ*<sub>*n*</sub> − *f* ||<sub>∞</sub> → 0 as *n* → ∞; or, equivalently,
- for all *ε* > 0, there exists a step function *φ*<sub>*ε*</sub> such that || *φ*<sub>*ε*</sub> − *f* ||<sub>∞</sub> \< *ε*; or, equivalently,
- *f* lies in the closure of the space of step functions, where the closure is taken in the space of all [bounded functions](wikipedia://en/311509) \[*a*, *b*\] → **R** and with respect to the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm) || ⋅ ||<sub>∞</sub>; or equivalently,
- for every *t* ∈ \[*a*, *b*), the right-sided limit

$$f(t+) = \lim_{s \downarrow t} f(s)$$

exists, and, for every *t* ∈ (*a*, *b*\], the left-sided limit

$$f(t-) = \lim_{s \uparrow t} f(s)$$

exists as well.

Define the **integral** of a regulated function *f* to be

$$\int_{a}^{b} f(t) \, \mathrm{d} t := \lim_{n \to \infty} \int_{a}^{b} \varphi_{n} (t) \, \mathrm{d} t,$$

where (*φ*<sub>*n*</sub>)<sub>*n*∈**N**</sub> is any sequence of step functions that converges uniformly to *f*.

One must check that this limit exists and is independent of the chosen sequence, but this is an immediate consequence of the [continuous linear extension](wikipedia://en/460637) theorem of elementary functional analysis: a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) *T*<sub>0</sub> defined on a [dense](https://en.wikipedia.org/wiki/Dense_%28topology%29) [linear subspace](wikipedia://en/56357) *E*<sub>0</sub> of a [normed linear space](https://en.wikipedia.org/wiki/Normed_linear_space) *E* and taking values in a Banach space *F* extends uniquely to a bounded linear operator *T* : *E* → *F* with the same (finite) [operator norm](wikipedia://en/246722).

:::

## Properties of the regulated integral {#Properties_of_the_regulated_integral}

- The integral is a [linear operator](https://en.wikipedia.org/wiki/Linear_operator): for any regulated functions *f* and *g* and constants *α* and *β*,

$$\int_{a}^{b} \alpha f(t) + \beta g(t) \, \mathrm{d} t = \alpha \int_{a}^{b} f(t) \, \mathrm{d} t + \beta \int_{a}^{b} g(t) \, \mathrm{d} t.$$

- The integral is also a [bounded operator](wikipedia://en/455961): every regulated function *f* is bounded, and if *m* ≤ *f*(*t*) ≤ *M* for all *t* ∈ \[*a*, *b*\], then

$$m | b - a | \leq \int_{a}^{b} f(t) \, \mathrm{d} t \leq M | b - a |.$$

In particular:

$$\left| \int_{a}^{b} f(t) \, \mathrm{d} t \right| \leq \int_{a}^{b} | f(t) | \, \mathrm{d} t.$$

- Since step functions are integrable and the integrability and the value of a Riemann integral are compatible with uniform limits, the regulated integral is a special case of the Riemann integral.

:::

## Extension to functions defined on the whole real line {#Extension_to_functions_defined_on_the_whole_real_line}

It is possible to extend the definitions of step function and regulated function and the associated integrals to functions defined on the whole [real line](https://en.wikipedia.org/wiki/Real_line). However, care must be taken with certain technical points:

- the partition on whose open intervals a step function is required to be constant is allowed to be a countable set, but must be a [discrete set](https://en.wikipedia.org/wiki/Discrete_set), i.e. have no [limit points](https://en.wikipedia.org/wiki/Limit_point);
- the requirement of uniform convergence must be loosened to the requirement of uniform convergence on [compact sets](wikipedia://en/6042), i.e. [closed](wikipedia://en/47279) and [bounded](wikipedia://en/48258) intervals;
- not every [bounded function](wikipedia://en/311509) is integrable (e.g. the function with constant value 1). This leads to a notion of [local integrability](wikipedia://en/4258398).

## Extension to vector-valued functions {#Extension_to_vector-valued_functions}

The above definitions go through *[mutatis mutandis](wikipedia://en/742665)* in the case of functions taking values in a [Banach space](wikipedia://en/3989) *X*.
