# Pi-system

::: {#o1 .subject cue=lead name="Pi-system"}

$\pi$-system in mathematics In [mathematics](wikipedia://en/18831), a **$\pi$-system** (or **pi-system**) on a [set](wikipedia://en/26691) $\Omega$ is a [collection](wikipedia://en/723043) $P$ of certain [subsets](wikipedia://en/27631) of $\Omega,$ such that

:::

- $P$ is [non-empty](wikipedia://en/9566).
- If $A, B \in P$ then $A \cap B \in P.$

That is, $P$ is a non-empty family of subsets of $\Omega$ that is [closed](wikipedia://en/293802) under non-empty finite [intersections](wikipedia://en/23476429).[^o2] The importance of $\pi$-systems arises from the fact that if two [probability measures](wikipedia://en/45437) agree on a $\pi$-system, then they agree on the [\-algebra](https://en.wikipedia.org/wiki/Sigma_algebra) generated by that $\pi$-system. Moreover, if other properties, such as equality of integrals, hold for the $\pi$-system, then they hold for the generated -algebra as well. This is the case whenever the collection of subsets for which the property holds is a [\-system](wikipedia://en/2549191). $\pi$-systems are also useful for checking independence of random variables.

This is desirable because in practice, $\pi$-systems are often simpler to work with than -algebras. For example, it may be awkward to work with -algebras generated by infinitely many sets $\sigma(E_1, E_2, \ldots).$ So instead we may examine the union of all -algebras generated by finitely many sets $\bigcup_n \sigma(E_1, \ldots, E_n).$ This forms a $\pi$-system that generates the desired -algebra. Another example is the collection of all [intervals](wikipedia://en/49172) of the [real line](https://en.wikipedia.org/wiki/Real_line), along with the empty set, which is a $\pi$-system that generates the very important [Borel -algebra](wikipedia://en/43327) of subsets of the real line.

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A $\pi$-system is a non-empty collection of sets $P$ that is closed under non-empty finite intersections, which is equivalent to $P$ containing the intersection of any two of its elements. If every set in this $\pi$-system is a subset of $\Omega$ then it is called a $\pi$-system on $\Omega.$

For any non-empty [family](wikipedia://en/723043) $\Sigma$ of subsets of $\Omega,$ there exists a $\pi$-system $\mathcal{I}_{\Sigma},$ called the **$\pi$-system generated by $\boldsymbol\varSigma$**, that is the unique smallest $\pi$-system of $\Omega$ containing every element of $\Sigma.$ It is equal to the intersection of all $\pi$-systems containing $\Sigma,$ and can be explicitly described as the set of all possible non-empty finite intersections of elements of $\Sigma:$

$$\left\{E_1 \cap \cdots \cap E_n ~:~ 1 \leq n \in \mathbb{N} \text{ and } E_1, \ldots, E_n \in \Sigma\right\}.$$

A non-empty family of sets has the [finite intersection property](wikipedia://en/365026) if and only if the $\pi$-system it generates does not contain the empty set as an element.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- For any real numbers $a$ and $b,$ the intervals $(-\infty, a]$ form a $\pi$-system, and the intervals $(a, b]$ form a $\pi$-system if the empty set is also included.
- The [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29) (collection of [open subsets](https://en.wikipedia.org/wiki/Open_subset)) of any [topological space](wikipedia://en/30450) is a $\pi$-system.
- Every [filter](wikipedia://en/12646549) is a $\pi$-system. Every $\pi$-system that doesn't contain the empty set is a [prefilter](https://en.wikipedia.org/wiki/Prefilter) (also known as a filter base).
- For any [measurable function](wikipedia://en/44055) $f : \Omega \to \mathbb{R},$ the set $\mathcal{I}_f = \left\{f^{-1}((-\infty, x]) : x \in \mathbb{R}\right\}$ defines a $\pi$-system, and is called the $\pi$-system generated by $f.$ (Alternatively, $\left\{f^{-1}((a, b]) : a, b \in \mathbb{R}, a < b\right\} \cup \{\varnothing\}$ defines a $\pi$-system generated by $f.$)
- If $P_1$ and $P_2$ are $\pi$-systems for $\Omega_1$ and $\Omega_2,$ respectively, then $\{A_1 \times A_2 : A_1 \in P_1, A_2 \in P_2\}$ is a $\pi$-system for the [Cartesian product](wikipedia://en/24104095) $\Omega_1 \times \Omega_2.$
- Every -algebra is a $\pi$-system.

:::

## Relationship to -systems {#Relationship_to_-systems}

A [\-system](wikipedia://en/2549191) on $\Omega$ is a set $D$ of subsets of $\Omega,$ satisfying

- $$\Omega \in D,$$
- if $A \in D$ then $\Omega \setminus A \in D,$
- if $A_1, A_2, A_3, \ldots$ is a sequence of [(pairwise) disjoint](wikipedia://en/39359) subsets in $D$ then $\textstyle\bigcup\limits_{n=1}^\infty A_n \in D.$

Whilst it is true that any -algebra satisfies the properties of being both a $\pi$-system and a -system, it is not true that any $\pi$-system is a -system, and moreover it is not true that any $\pi$-system is a -algebra. However, a useful classification is that any set system which is both a -system and a $\pi$-system is a -algebra. This is used as a step in proving the $\pi$- theorem.

::: {#o9 .statement kind=statement/theorem cue=named-heading name="The - theorem"}

### The $\pi$- theorem {#The_-_theorem}

Let $D$ be a -system, and let $\mathcal{I} \subseteq D$ be a $\pi$-system contained in $D.$ The $\pi$- theorem[^o10] states that the -algebra $\sigma(\mathcal{I})$ generated by $\mathcal{I}$ is contained in $D ~:~$ $\sigma(\mathcal{I}) \subseteq D.$

The $\pi$- theorem can be used to prove many elementary [measure theoretic](https://en.wikipedia.org/wiki/Measure_theory) results. For instance, it is used in proving the uniqueness claim of the [Carathéodory extension theorem](https://en.wikipedia.org/wiki/Carathéodory_extension_theorem) for -finite measures.[^o11]

The $\pi$- theorem is closely related to the [monotone class theorem](wikipedia://en/4719864), which provides a similar relationship between monotone classes and algebras, and can be used to derive many of the same results. Since $\pi$-systems are simpler classes than algebras, it can be easier to identify the sets that are in them while, on the other hand, checking whether the property under consideration determines a -system is often relatively easy. Despite the difference between the two theorems, the $\pi$- theorem is sometimes referred to as the monotone class theorem.[^o10]

::: {#o13 .example cue=heading name="Example"}

#### Example {#Example}

Let $\mu_1, \mu_2 : F \to \mathbb{R}$ be two measures on the -algebra $F,$ and suppose that $F = \sigma(I)$ is generated by a $\pi$-system $I.$ If

1. $\mu_1(A) = \mu_2(A)$ for all $A \in I,$ and
1. $$\mu_1(\Omega) = \mu_2(\Omega) < \infty,$$

then $\mu_1 = \mu_2.$ This is the uniqueness statement of the Carathéodory extension theorem for finite measures. If this result does not seem very remarkable, consider the fact that it usually is very difficult or even impossible to fully describe every set in the -algebra, and so the problem of equating measures would be completely hopeless without such a tool.

**Idea of the proof**[^o11] Define the collection of sets

$$D = \left\{ A \in \sigma(I) \colon \mu_1(A) = \mu_2(A) \right\}.$$

By the first assumption, $\mu_1$ and $\mu_2$ agree on $I$ and thus $I \subseteq D.$ By the second assumption, $\Omega \in D,$ and it can further be shown that $D$ is a -system. It follows from the $\pi$- theorem that $\sigma(I) \subseteq D \subseteq \sigma(I),$ and so $D = \sigma(I).$ That is to say, the measures agree on $\sigma(I).$

:::

## $\pi$-Systems in probability {#-Systems_in_probability}

$\pi$-systems are more commonly used in the study of probability theory than in the general field of measure theory. This is primarily due to probabilistic notions such as [independence](wikipedia://en/27593), though it may also be a consequence of the fact that the $\pi$- theorem was proven by the probabilist [Eugene Dynkin](wikipedia://en/1351540). Standard measure theory texts typically prove the same results via [monotone classes](https://en.wikipedia.org/wiki/Monotone_class), rather than $\pi$-systems.

### Equality in distribution {#Equality_in_distribution}

The $\pi$- theorem motivates the common definition of the [probability distribution](wikipedia://en/23543) of a [random variable](wikipedia://en/25685) $X : (\Omega, \mathcal F, \operatorname P) \to \mathbb{R}$ in terms of its [cumulative distribution function](wikipedia://en/5793). Recall that the cumulative distribution of a random variable is defined as

$$F_X(a) = \operatorname{P}[X \leq a], \qquad a \in \mathbb{R},$$

whereas the seemingly more general law of the variable is the probability measure

$$\mathcal{L}_X(B) = \operatorname{P}\left[X^{-1}(B)\right] \quad \text{ for all } B \in \mathcal{B}(\mathbb{R}),$$

where $\mathcal{B}(\mathbb{R})$ is the Borel -algebra. The random variables $X :(\Omega, \mathcal F, \operatorname P) \to \mathbb{R}$ and $Y : (\tilde\Omega,\tilde{\mathcal F}, \tilde{\operatorname P}) \to \mathbb{R}$ (on two possibly different [probability spaces](wikipedia://en/43325)) are [equal in distribution](https://en.wikipedia.org/wiki/Equal_in_distribution) (or law), denoted by $X \,\stackrel{\mathcal D}{=}\, Y,$ if they have the same cumulative distribution functions; that is, if $F_X = F_Y.$ The motivation for the definition stems from the observation that if $F_X = F_Y,$ then that is exactly to say that $\mathcal{L}_X$ and $\mathcal{L}_Y$ agree on the $\pi$-system $\{(-\infty, a] : a \in \mathbb{R}\}$ which generates $\mathcal{B}(\mathbb{R}),$ and so by the example above: $\mathcal{L}_X = \mathcal{L}_Y.$

A similar result holds for the joint distribution of a random vector. For example, suppose $X$ and $Y$ are two random variables defined on the same probability space $(\Omega, \mathcal{F}, \operatorname{P}),$ with respectively generated $\pi$-systems $\mathcal{I}_X$ and $\mathcal{I}_Y.$ The joint cumulative distribution function of $(X, Y)$ is

$$F_{X,Y}(a, b) = \operatorname{P}[X \leq a, Y \leq b] = \operatorname{P}\left[X^{-1}((-\infty, a]) \cap Y^{-1}((-\infty, b])\right], \quad \text{ for all } a, b \in \mathbb{R}.$$

However, $A = X^{-1}((-\infty, a]) \in \mathcal{I}_X$ and $B = Y^{-1}((-\infty, b]) \in \mathcal{I}_Y.$ Because

$$\mathcal{I}_{X,Y} = \left\{A \cap B : A \in \mathcal{I}_X, \text{ and } B \in \mathcal{I}_Y\right\}$$

is a $\pi$-system generated by the random pair $(X, Y),$ the $\pi$- theorem is used to show that the joint cumulative distribution function suffices to determine the joint law of $(X, Y).$ In other words, $(X, Y)$ and $(W, Z)$ have the same distribution if and only if they have the same joint cumulative distribution function.

In the theory of [stochastic processes](wikipedia://en/47895), two processes $(X_t)_{t \in T}, (Y_t)_{t \in T}$ are known to be equal in distribution if and only if they agree on all finite-dimensional distributions; that is, for all $t_1, \ldots, t_n \in T, \, n \in \mathbb{N},$

$$\left(X_{t_1}, \ldots, X_{t_n}\right) \,\stackrel{\mathcal{D}}{=}\, \left(Y_{t_1}, \ldots, Y_{t_n}\right).$$

The proof of this is another application of the $\pi$- theorem.[^o16]

### Independent random variables {#Independent_random_variables}

The theory of $\pi$-system plays an important role in the probabilistic notion of [independence](wikipedia://en/27593). If $X$ and $Y$ are two random variables defined on the same probability space $(\Omega, \mathcal{F}, \operatorname{P})$ then the random variables are independent if and only if their $\pi$-systems $\mathcal{I}_X, \mathcal{I}_Y$ satisfy for all $A \in \mathcal{I}_X$ and $B \in \mathcal{I}_Y,$

$$\operatorname{P}[A \cap B] ~=~ \operatorname{P}[A] \operatorname{P}[B],$$

which is to say that $\mathcal{I}_X, \mathcal{I}_Y$ are independent. This actually is a special case of the use of $\pi$-systems for determining the distribution of $(X, Y).$

::: {#o19 .example cue=heading name="Example"}

#### Example {#Example}

Let $Z = \left(Z_1, Z_2\right),$ where $Z_1, Z_2 \sim \mathcal{N}(0, 1)$ are [iid](wikipedia://en/30876902) standard normal random variables. Define the radius and argument (arctan) variables

$$R = \sqrt{Z_1^2 + Z_2^2}, \qquad \Theta = \tan^{-1}\left(Z_2 / Z_1\right).$$

Then $R$ and $\Theta$ are independent random variables.

To prove this, it is sufficient to show that the $\pi$-systems $\mathcal{I}_R, \mathcal{I}_\Theta$ are independent: that is, for all $\rho \in [0, \infty)$ and $\theta \in [0, 2 \pi],$

$$\operatorname{P}[R \leq \rho, \Theta \leq \theta] = \operatorname{P}[R \leq \rho] \operatorname{P}[\Theta \leq \theta].$$

Confirming that this is the case is an exercise in changing variables. Fix $\rho \in [0, \infty)$ and $\theta \in [0, 2 \pi],$ then the probability can be expressed as an integral of the probability density function of $Z.$

$$\begin{aligned} \operatorname P [R \leq \rho, \Theta \leq \theta] &= \int_{R \leq \rho, \, \Theta \leq \theta} \frac{1}{2\pi}\exp\left({-\frac12(z_1^2 + z_2^2)}\right) dz_1 \, dz_2 \\[5pt] & = \int_0^{\theta} \int_0^\rho \frac{1}{2 \pi}e^{-\frac{r^2}{2}} \; r \, dr \, d\tilde\theta \\[5pt] & = \left(\int_0^\theta \frac{1}{2 \pi} \, d\tilde \theta\right) \; \left(\int_0^\rho e^{-\frac{r^2}{2}} \; r \, dr\right) \\[5pt] & = \operatorname P[\Theta \leq \theta]\operatorname P[R \leq \rho]. \end{aligned}$$

:::
