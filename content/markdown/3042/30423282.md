# Variable and attribute (research)

::: {#o1 .subject cue=lead name="Variable and attribute"}

In [science](https://en.wikipedia.org/wiki/Science) and [research](https://en.wikipedia.org/wiki/Research), an **attribute** is a quality of an object (person, thing, etc.).[^o2] Attributes are closely related to variables. A **variable** is a [logical](wikipedia://en/46426065) set of attributes.[^o2] Variables can "vary" – for example, be high or low.[^o2] How high, or how low, is determined by the value of the attribute (and in fact, an attribute could be just the word "low" or "high").[^o2] *(For example see: [Binary option](https://en.wikipedia.org/wiki/Binary_option))*

:::

While an attribute is often intuitive, the **variable** is the [operationalized](wikipedia://en/747363) way in which the attribute is represented for further [data processing](https://en.wikipedia.org/wiki/Data_processing). In data processing [data](https://en.wikipedia.org/wiki/Data) are often represented by a combination of *items* (objects organized in rows), and multiple variables (organized in columns).

Values of each variable statistically "vary" (or are distributed) across the variable's domain. A domain is a set of all possible values that a variable is allowed to have. The values are ordered in a logical way and must be defined for each variable. Domains can be bigger or smaller. The smallest possible domains have those variables that can only have two values, also called *binary* (or dichotomous) variables. Bigger domains have *non-dichotomous* variables and the ones with a higher [level of measurement](wikipedia://en/821148). (See also [domain of discourse](wikipedia://en/229180).)

Semantically, greater precision can be obtained when considering an object's characteristics by distinguishing 'attributes' (characteristics that are attributed to an object) from '[traits](https://en.wikipedia.org/wiki/Phenotypic_trait)' (characteristics that are inherent to the object).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

[Age](https://en.wikipedia.org/wiki/Ageing) is an attribute that can be operationalized in many ways. It can be dichotomized so that only two values – "old" and "young" – are allowed for further data processing. In this case the attribute "age" is operationalized as a binary variable. If more than two values are possible and they can be ordered, the attribute is represented by ordinal variable, such as "young", "middle age", and "old". Next it can be made of rational values, such as 1, 2, 3.... 99.[^o2]

The "social class" attribute can be operationalized in similar ways as age, including "lower", "middle" and "upper class" and each class could be differentiated between upper and lower, transforming thus changing the three attributes into six (see the [model proposed by William Lloyd Warner](https://en.wikipedia.org/wiki/Social_class#William_Lloyd_Warner)) or it could use different terminology (such as the [working class](https://en.wikipedia.org/wiki/Working_class) as in the [model by Gilbert and Kahl](https://en.wikipedia.org/wiki/Social_class#Gilbert_.26_Kahl)).
