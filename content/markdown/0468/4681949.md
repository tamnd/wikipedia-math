# Pseudorandom permutation

::: {#o1 .subject cue=lead name="Pseudorandom permutation"}

In [cryptography](wikipedia://en/18934432), a **pseudorandom permutation (PRP)** is a function that cannot be distinguished from a [random permutation](https://en.wikipedia.org/wiki/Random_permutation) (that is, a permutation selected at random with uniform probability, from the family of all permutations on the function's domain) with practical effort.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *F* be a mapping $\left\{0, 1\right\}^n \times \left\{0, 1\right\}^s \rightarrow \left\{0, 1\right\}^n$. *F* is a PRP if and only if

- For any $K \in \left\{0, 1\right\}^s$, $F_K$ is a [bijection](wikipedia://en/3942) from $\left\{0, 1\right\}^n$ to $\left\{0, 1\right\}^n$, where $F_K(x)=F(x,K)$.
- For any $K \in \left\{0, 1\right\}^s$, there is an "efficient" algorithm to evaluate $F_K(x)$ for any $x \in \left\{0, 1\right\}^n$,.
- For all probabilistic polynomial-time [distinguishers](wikipedia://en/4636092) $D$: $\left| Pr\left(D^{F_K}(1^n) = 1\right) - Pr\left(D^{f_n}(1^n) = 1\right) \right| < \varepsilon(s)$, where $K \in \left\{0, 1\right\}^s$ is chosen uniformly at random and $f_n$ is chosen uniformly at random from the set of permutations on *n*-bit strings.[^o4]

A **pseudorandom permutation family** is a collection of pseudorandom permutations, where a specific permutation may be chosen using a key.

:::

## The model of block ciphers {#The_model_of_block_ciphers}

The idealized abstraction of a (keyed) [block cipher](wikipedia://en/4594) is a truly [random permutation](https://en.wikipedia.org/wiki/Random_permutation) on the mappings between [plaintext](wikipedia://en/157935) and [ciphertext](wikipedia://en/175560). If a distinguishing algorithm exists that achieves significant [advantage](wikipedia://en/4636092) with less effort than specified by the block cipher's [security parameter](wikipedia://en/2290431) (this usually means the effort required should be about the same as a brute force search through the cipher's key space), then the cipher is considered broken at least in a certificational sense, even if such a break doesn't immediately lead to a practical [security](https://en.wikipedia.org/wiki/Computer_security) failure.[^o6]

Modern ciphers are expected to have super pseudorandomness. That is, the cipher should be [indistinguishable from a randomly chosen permutation](wikipedia://en/2187252#Indistinguishable_from_random_noise) on the same message space, even if the adversary has black-box access to the forward and inverse directions of the cipher.[^o7]

## Connections with pseudorandom function {#Connections_with_pseudorandom_function}

[Michael Luby](wikipedia://en/9552275) and Charles Rackoff[^o9] showed that a "strong" pseudorandom permutation can be built from a [pseudorandom function](https://en.wikipedia.org/wiki/Pseudorandom_function) using a [Luby–Rackoff construction](wikipedia://en/352709#Theoretical_work) which is built using a [Feistel cipher](wikipedia://en/352709).

## Related concepts {#Related_concepts}

### Unpredictable permutation {#Unpredictable_permutation}

An **unpredictable permutation** (**UP**) *F*<sub>*k*</sub> is a [permutation](wikipedia://en/44027) whose values cannot be predicted by a fast [randomized algorithm](wikipedia://en/495383). Unpredictable permutations may be used as a [cryptographic primitive](wikipedia://en/4928985), a building block for cryptographic systems with more complex properties.

An [adversary](wikipedia://en/789126) for an unpredictable permutation is defined to be an algorithm that is given access to an oracle for both forward and inverse permutation operations. The adversary is given a challenge input *k* and is asked to predict the value of *F*<sub>*k*</sub>. It is allowed to make a series of queries to the oracle to help it make this prediction, but is not allowed to query the value of *k* itself.[^o12]

A randomized algorithm for generating permutations generates an **unpredictable permutation** if its outputs are permutations on a set of items (described by length-*n* binary strings) that cannot be predicted with accuracy significantly better than random by an adversary that makes a polynomial (in *n*) number of queries to the oracle prior to the challenge round, whose running time is [polynomial](https://en.wikipedia.org/wiki/Polynomial_time) in *n*, and whose error probability is less than 1/2 for all instances. That is, it cannot be predicted in the [complexity class](wikipedia://en/502426) [PP](wikipedia://en/659322), [relativized](wikipedia://en/22431) by the oracle for the permutation.[^o12]

#### Properties of unpredictable permutations {#Properties_of_unpredictable_permutations}

It can be shown that a function *F*<sub>*k*</sub> is not a secure [message authentication code](wikipedia://en/567523) (MAC) if it satisfies only the unpredictability requirement. It can also be shown that one cannot build an efficient variable input length MAC from a block cipher which is modelled as a UP of *n* bits. It has been shown that the output of a *k* = *n*/*ω*(log *λ*) round Feistel construction with unpredictable round functions may leak all the intermediate round values.[^o12] Even for realistic Unpredictable Functions (UF), some partial information about the intermediate round values may be leaked through the output. It was later shown that if a super-logarithmic number of rounds in the Feistel construction is used, then the resulting UP construction is secure even if the adversary gets all the intermediate round values along with the permutation output.[^o14]

There is also a theorem that has been proven in this regard which states that if there exists an efficient UP adversary *A*<sub>*π*</sub> that has non-negligible advantage *ε*<sub>*π*</sub> in the unpredictability game against UP construction ψ<sub>U,k</sub> and which makes a polynomial number of queries to the challenger, then there also exists a UF adversary *A*<sub>*f*</sub> that has non-negligible advantage in the unpredictability game against a UF sampled from the UF family *F* . From this, it can be shown that the maximum advantage of the UP adversary *A*<sub>*π*</sub> is *ε*<sub>*π*</sub> = O (*ε*<sub>*f*.</sub> (*qk*)<sup>6</sup>). Here *ε*<sub>*f*</sub> denotes the maximum advantage of a UF adversary running in time O(*t* + (*qk*)<sup>5</sup>) against a UF sampled from *F*, where *t* is the running time of the PRP adversary *A*<sub>*ψ*</sub> and *q* is the number of queries made by it.[^o14][^o15]

In addition, a signature scheme that satisfies the property of unpredictability and not necessarily pseudo-randomness is essentially a Verifiable Unpredictable Function (VUF). A verifiable unpredictable function is defined analogously to a Verifiable Pseudorandom Function (VRF) but for pseudo-randomness being substituted with weaker unpredictability. Verifiable unpredictable permutations are the permutation analogs of VUFs or unpredictable analogs of VRPs. A VRP is also a VUP and a VUP can actually be built by building a VRP via the Feistel construction applied to a VRF. But this is not viewed useful since VUFs appear to be much easier to construct than VRFs.[^o16]
