# Multiplicity function for N noninteracting spins

::: {#o1 .subject cue=lead name="Multiplicity function for N noninteracting spins"}

The **multiplicity function** for a two state paramagnet, W(n,N), is the number of spin states such that n of the N spins point in the z-direction. This function is given by the [combinatoric function C(N,n)](https://en.wikipedia.org/wiki/Combinations). That is:

$$W (n,N) = {N \choose n} = {{N!} \over {n!(N - n)!}}$$

:::

It is primarily used in introductory [statistical mechanics](wikipedia://en/28481) and [thermodynamics](wikipedia://en/29952) textbooks to explain the microscopic definition of entropy to students. If the spins are non-interacting, then the multiplicity function counts the number of states which have the same energy in an external magnetic field. By definition, the [entropy](wikipedia://en/9891) S is then given by the [natural logarithm](wikipedia://en/21476) of this number:

$S = k\ln{W }\,$ [^o2] Where k is the [Boltzmann constant](https://en.wikipedia.org/wiki/Boltzmann_constant)
