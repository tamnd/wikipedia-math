# Closed category

::: {#o1 .subject cue=lead name="Closed category"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **closed category** is a special kind of [category](wikipedia://en/53759).

:::

In a [locally small](https://en.wikipedia.org/wiki/Locally_small_category) category, the *external hom* (*x*, *y*) maps a pair of [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) to a set of [morphisms](wikipedia://en/27716891). So in the [category of sets](wikipedia://en/26829), this is an object of the category itself. In the same vein, in a closed category, the (object of) morphisms from one object to another can be seen as lying inside the category. This is the *internal hom* \[*x*, *y*\].

Every closed category has a [forgetful functor](wikipedia://en/844783) to the category of sets, which in particular takes the internal hom to the external hom.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **closed category** can be defined as a category $\mathcal{C}$ with a so-called [internal Hom functor](https://en.wikipedia.org/wiki/Internal_Hom_functor)

$$\left[-\ -\right] : \mathcal{C}^{op} \times \mathcal{C} \to \mathcal{C}$$

with left [Yoneda arrows](https://en.wikipedia.org/wiki/Yoneda_arrow)

$$L : \left[B\ C\right] \to \left[\left[A\ B\right] \left[A\ C\right]\right]$$

[natural](wikipedia://en/45022) in $B$ and $C$ and [dinatural](wikipedia://en/3865755) in $A$, and a fixed object $I$ of $\mathcal{C}$ with a [natural isomorphism](https://en.wikipedia.org/wiki/Natural_isomorphism)

$$i_A : A \cong \left[I\ A\right]$$

and a [dinatural transformation](wikipedia://en/3865755)

$$j_A : I \to \left[A\ A\right],$$

all satisfying certain coherence conditions.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- [Cartesian closed categories](https://en.wikipedia.org/wiki/Cartesian_closed_categories) are closed categories. In particular, any [elementary topos](wikipedia://en/815802) is closed. The canonical example is the category of sets.
- [Compact closed categories](wikipedia://en/5557623) are closed categories. The canonical example is the category **FdVect** with [finite-dimensional](wikipedia://en/38267) [vector spaces](wikipedia://en/32370) as objects and [linear maps](wikipedia://en/18102) as morphisms.
- More generally, any [monoidal closed category](https://en.wikipedia.org/wiki/Monoidal_closed_category) is a closed category. In this case, the object $I$ is the [monoidal unit](wikipedia://en/330604).

:::
