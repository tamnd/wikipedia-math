# Iteratively reweighted least squares

::: {#o1 .subject cue=lead name="Iteratively reweighted least squares"}

The method of **iteratively reweighted least squares** (**IRLS**) is used to solve certain optimization problems with [objective functions](https://en.wikipedia.org/wiki/Objective_function) of the form of a [*p*-norm](https://en.wikipedia.org/wiki/P-norm),

$$\operatorname{arg\,min}_{\boldsymbol\beta} \sum_{i=1}^n \big| y_i - f_i (\boldsymbol\beta) \big|^p,$$

by an [iterative method](wikipedia://en/15237) in which each step involves solving a [weighted least squares](wikipedia://en/2407860) problem of the form[^o2]

$$\boldsymbol\beta^{(t+1)} = \operatorname{arg\,min}_{\boldsymbol\beta} \sum_{i=1}^n w_i (\boldsymbol\beta^{(t)}) \big| y_i - f_i (\boldsymbol\beta) \big|^2.$$

:::

IRLS is used to find the [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimates of a [generalized linear model](wikipedia://en/747122), and in [robust regression](wikipedia://en/2713327) to find an [M-estimator](wikipedia://en/4225388), as a way of mitigating the influence of outliers in an otherwise normally distributed data set, for example, by minimizing the [least absolute errors](https://en.wikipedia.org/wiki/Least_absolute_errors) rather than the [least square errors](wikipedia://en/82359).

One of the advantages of IRLS over [linear programming](wikipedia://en/43730) and [convex programming](https://en.wikipedia.org/wiki/Convex_programming) is that it can be used with [Gauss–Newton](https://en.wikipedia.org/wiki/Gauss–Newton) and [Levenberg–Marquardt](https://en.wikipedia.org/wiki/Levenberg–Marquardt) numerical algorithms.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### *L*<sub>1</sub> minimization for sparse recovery {#L1_minimization_for_sparse_recovery}

IRLS can be used for **[*ℓ*<sub>1</sub>](https://en.wikipedia.org/wiki/L1_norm)** minimization and smoothed **[*ℓ*<sub>p</sub>](https://en.wikipedia.org/wiki/Lp_quasi-norm)** minimization, *p* \< 1, in [compressed sensing](wikipedia://en/11403316) problems. It has been proved that the algorithm has a linear rate of convergence for *ℓ*<sub>1</sub> norm and superlinear for *ℓ*<sub>*t*</sub> with *t* \< 1, under the [restricted isometry property](wikipedia://en/23452012), which is generally a sufficient condition for sparse solutions.[^o6][^o7]

### *L<sup>p</sup>* norm linear regression {#Lp_norm_linear_regression}

To find the parameters ***β*** = (*β*<sub>1</sub>, …,*β*<sub>*k*</sub>)<sup>T</sup> which minimize the [*L<sup>p</sup>* norm](wikipedia://en/45194) for the [linear regression](wikipedia://en/48758386) problem,

$$\underset{\boldsymbol \beta}{ \operatorname{arg\,min} } \big\| \mathbf y - X \boldsymbol \beta \|_p = \underset{\boldsymbol \beta}{ \operatorname{arg\,min} } \sum_{i=1}^n \left| y_i - X_i \boldsymbol\beta \right|^p ,$$

the IRLS algorithm at step *t* + 1 involves solving the [weighted linear least squares](https://en.wikipedia.org/wiki/Linear_least_squares_%28mathematics%29#Weighted_linear_least_squares) problem[^o9]

$$\boldsymbol\beta^{(t+1)} = \underset{\boldsymbol\beta}{ \operatorname{arg\,min} } \sum_{i=1}^n w_i^{(t)} \left| y_i - X_i \boldsymbol\beta \right|^2 = (X^{\rm T} W^{(t)} X)^{-1} X^{\rm T} W^{(t)} \mathbf{y},$$

where *W*<sup>(*t*)</sup> is the [diagonal matrix](wikipedia://en/174080) of weights, usually with all elements set initially to

$$w_i^{(0)} = 1$$

and updated after each iteration to

$$w_i^{(t)} = \big|y_i - X_i \boldsymbol \beta ^{(t)} \big|^{p-2}.$$

In the case *p* = 1, this corresponds to [least absolute deviation](https://en.wikipedia.org/wiki/Least_absolute_deviation) regression (in this case, the problem would be better approached by use of [linear programming](wikipedia://en/43730) methods,[^o10] so the result would be exact) and the formula is

$$w_i^{(t)} = \frac{1}{\big|y_i - X_i \boldsymbol \beta ^{(t)} \big|}.$$

To avoid dividing by zero, [regularization](wikipedia://en/2009061) must be done, so in practice the formula is

$$w_i^{(t)} = \frac 1 {\max\left\{\delta, \left|y_i - X_i \boldsymbol \beta ^{(t)} \right|\right\} }.$$

where $\delta$ is some small value, like 0.0001.[^o10] Note the use of $\delta$ in the weighting function is equivalent to the [Huber loss](wikipedia://en/26357083) function in robust estimation.[^o11]
