# Weakly measurable function

::: {#o1 .subject cue=lead name="Weakly measurable function"}

In [mathematics](wikipedia://en/18831)—specifically, in [functional analysis](wikipedia://en/11180)—a **weakly measurable function** taking values in a [Banach space](wikipedia://en/3989) is a [function](wikipedia://en/185427) whose [composition](wikipedia://en/195947) with any element of the [dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) is a [measurable function](wikipedia://en/44055) in the usual (strong) sense. For [separable spaces](wikipedia://en/27855), the notions of weak and strong measurability agree.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $(X, \Sigma)$ is a [measurable space](wikipedia://en/43333) and $B$ is a Banach space over a [field](wikipedia://en/10603) $\mathbb{K}$ (which is the [real numbers](wikipedia://en/20646438) $\mathbb{R}$ or [complex numbers](wikipedia://en/5826) $\mathbb{C}$), then $f : X \to B$ is said to be **weakly measurable** if, for every [continuous linear functional](https://en.wikipedia.org/wiki/Continuous_linear_functional) $g : B \to \mathbb{K},$ the function

$$g \circ f \colon X \to \mathbb{K} \quad \text{ defined by } \quad x \mapsto g(f(x))$$

is a measurable function with respect to $\Sigma$ and the usual [Borel $\sigma$-algebra](https://en.wikipedia.org/wiki/Borel_sigma_algebra) on $\mathbb{K}.$

A measurable function on a [probability space](wikipedia://en/43325) is usually referred to as a [random variable](wikipedia://en/25685) (or [random vector](https://en.wikipedia.org/wiki/Random_vector) if it takes values in a vector space such as the Banach space $B$). Thus, as a special case of the above definition, if $(\Omega, \mathcal{P})$ is a probability space, then a function $Z : \Omega \to B$ is called a ($B$-valued) **weak random variable** (or **weak random vector**) if, for every continuous linear functional $g : B \to \mathbb{K},$ the function

$$g \circ Z \colon \Omega \to \mathbb{K} \quad \text{ defined by } \quad \omega \mapsto g(Z(\omega))$$

is a $\mathbb{K}$-valued random variable (i.e. measurable function) in the usual sense, with respect to $\Sigma$ and the usual Borel $\sigma$-algebra on $\mathbb{K}.$

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The relationship between measurability and weak measurability is given by the following result, known as **[Pettis](https://en.wikipedia.org/wiki/B._J._Pettis)' theorem** or **Pettis measurability theorem**.

A function $f$ is said to be **[almost surely](wikipedia://en/351908) separably valued** (or **essentially separably valued**) if there exists a subset $N \subseteq X$ with $\mu(N) = 0$ such that $f(X \setminus N) \subseteq B$ is separable.

::: {#o6 .statement kind=statement/theorem cue=math-theorem name="Theorem (Pettis, 1938)"}

**Theorem (Pettis, 1938).**

A function $f : X \to B$ defined on a [measure space](wikipedia://en/45270) $(X, \Sigma, \mu)$ and taking values in a Banach space $B$ is (strongly) measurable (that equals a.e. the limit of a sequence of measurable countably-valued functions) [if and only if](wikipedia://en/14922) it is both weakly measurable and almost surely separably valued.

:::

In the case that $B$ is separable, since any subset of a separable Banach space is itself separable, one can take $N$ above to be empty, and it follows that the notions of weak and strong measurability agree when $B$ is separable.

:::
