# Ergodic Ramsey theory

::: {#o1 .subject cue=lead name="Ergodic Ramsey theory"}

**Ergodic Ramsey theory** is a branch of [mathematics](wikipedia://en/18831) where problems motivated by [additive combinatorics](wikipedia://en/18243392) are proven using [ergodic theory](wikipedia://en/258986).

:::

## History {#History}

Ergodic Ramsey theory arose shortly after [Endre Szemerédi's proof](wikipedia://en/591703) that a set of positive [upper density](https://en.wikipedia.org/wiki/Upper_density) contains arbitrarily long [arithmetic progressions](wikipedia://en/168389), when [Hillel Furstenberg](wikipedia://en/6450152) gave a new proof of this theorem using ergodic theory. It has since produced combinatorial results, some of which have yet to be obtained by other means, and has also given a deeper understanding of the structure of [measure-preserving dynamical systems](wikipedia://en/398931).

::: {#o4 .statement kind=statement/theorem cue=named-heading name="Szemerédi's theorem"}

## Szemerédi's theorem {#Szemerédi's_theorem}

[Szemerédi's theorem](wikipedia://en/591703) is a result in [arithmetic combinatorics](wikipedia://en/18243381), concerning [arithmetic progressions](wikipedia://en/168389) in subsets of the integers. In 1936, [Erdős](wikipedia://en/601284) and [Turán](wikipedia://en/614998) conjectured[^o5] that every set of integers *A* with positive [natural density](wikipedia://en/1819983) contains a *k*-term arithmetic progression for every *k*. This conjecture, which became Szemerédi's theorem, generalizes the statement of [van der Waerden's theorem](wikipedia://en/157178). [Hillel Furstenberg](wikipedia://en/6450152) proved the theorem using ergodic principles in 1977.[^o6]

:::
