# Tobler's hiking function

::: {#o1 .subject cue=lead name="Tobler's hiking function"}

*Image: Tobler's hiking function.svg.* Tobler's hiking function – walking speed vs. slope angle chart.

**Tobler's hiking function** is an [exponential function](wikipedia://en/9678) determining the [hiking](https://en.wikipedia.org/wiki/Hiking) speed, taking into account the [slope](wikipedia://en/259162) angle.[^o9][^o10][^o11] It was formulated by [Waldo Tobler](https://en.wikipedia.org/wiki/Waldo_Tobler). This function was estimated from empirical data of the Swiss cartography professor [Eduard Imhof](https://en.wikipedia.org/wiki/Eduard_Imhof).[^o12]

:::

::: {#o3 .statement cue=named-heading name="Formula"}

## Formula {#Formula}

Walking velocity:

$$W=6e^{\displaystyle-3.5\left\vert\frac{dh}{dx}+0.05\right\vert}$$

$$\frac{dh}{dx}=S=\tan\theta$$

where

*W* = walking velocity \[km/h\][^o10]

*dh* = elevation difference,

*dx* = distance,

*S* = slope,

*θ* = angle of slope (inclination).

The velocity on the flat terrain is 5 km / h, the maximum speed of 6 km / h is achieved roughly at -2.86°.[^o13]

On flat terrain this formula works out to 5 km/h. For off-path travel, this value should be multiplied by 3/5, for horseback by 5/4.[^o9]

:::

## Pace {#Pace}

[Pace](https://en.wikipedia.org/wiki/Pace_%28running%29) is the reciprocal of speed.[^o14][^o15] For Tobler's hiking function it can be calculated from the following conversion:[^o15]

$$p=0.6e^{\displaystyle3.5\left\vert m+0.05\right\vert}$$

where

*p* = pace \[s/m\]

*m* = gradient uphill or downhill (*dh/dx = S* in Tobler's formula),
