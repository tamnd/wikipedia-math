# Limitation of size

::: {#o1 .subject cue=lead name="Limitation of size"}

In the [philosophy of mathematics](wikipedia://en/46439), specifically the philosophical foundations of [set theory](wikipedia://en/27553), **limitation of size** is a concept developed by [Philip Jourdain](wikipedia://en/3966802) and/or [Georg Cantor](wikipedia://en/12216) to avoid [Cantor's paradox](wikipedia://en/2732904). It identifies certain "inconsistent multiplicities", in Cantor's terminology, that cannot be [sets](wikipedia://en/26691) because they are "too large". In modern terminology these are called [proper classes](wikipedia://en/20696).

:::

::: {#o3 .application cue=heading name="Use"}

## Use {#Use}

The [axiom of limitation of size](wikipedia://en/5322450) is an axiom in some versions of [von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) or [Morse–Kelley set theory](wikipedia://en/2693655). This axiom says that any class that is not "too large" is a set, and a set cannot be "too large". "Too large" is defined as being large enough that the class of all sets can be mapped one-to-one into it.

:::
