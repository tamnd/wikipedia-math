# Relevance vector machine

::: {#o1 .subject cue=lead name="Relevance vector machine"}

Supervised learning In [mathematics](wikipedia://en/18831), a **Relevance Vector Machine (RVM)** is a [machine learning](wikipedia://en/233488) technique that uses [Bayesian inference](wikipedia://en/49571) to obtain [parsimonious](wikipedia://en/36797) solutions for [regression](wikipedia://en/826997) and [probabilistic classification](wikipedia://en/42378348).[^o2] A greedy optimisation procedure and thus fast version were subsequently developed.[^o3][^o4] The RVM has an identical functional form to the [support vector machine](wikipedia://en/65309), but provides probabilistic classification.

:::

It is actually equivalent to a [Gaussian process](wikipedia://en/302944) model with [covariance function](wikipedia://en/9793263):

$$k(\mathbf{x},\mathbf{x'}) = \sum_{j=1}^N \frac{1}{\alpha_j} \varphi(\mathbf{x},\mathbf{x}_j)\varphi(\mathbf{x}',\mathbf{x}_j)$$

where $\varphi$ is the [kernel function](https://en.wikipedia.org/wiki/Kernel_function) (usually Gaussian), $\alpha_j$ are the variances of the prior on the weight vector $w \sim N(0,\alpha^{-1}I)$, and $\mathbf{x}_1,\ldots,\mathbf{x}_N$ are the input vectors of the [training set](https://en.wikipedia.org/wiki/Training_set).[^o5]

Compared to that of [support vector machines](wikipedia://en/65309) (SVM), the Bayesian formulation of the RVM avoids the set of free parameters of the SVM (that usually require cross-validation-based post-optimizations). However RVMs use an [expectation maximization](https://en.wikipedia.org/wiki/Expectation_maximization) (EM)-like learning method and are therefore at risk of local minima. This is unlike the standard [sequential minimal optimization](https://en.wikipedia.org/wiki/Sequential_minimal_optimization) (SMO)-based algorithms employed by [SVMs](wikipedia://en/65309), which are guaranteed to find a global optimum (of the convex problem).

The relevance vector machine was [patented in the United States](https://en.wikipedia.org/wiki/Software_patents_under_United_States_patent_law) by [Microsoft](https://en.wikipedia.org/wiki/Microsoft) (patent expired September 4, 2019).[^o6]
