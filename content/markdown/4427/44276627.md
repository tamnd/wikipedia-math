# Ricochet (software)

::: {#o3 .subject cue=lead name="Ricochet"}

**Ricochet** or **Ricochet IM** is a [free software](https://en.wikipedia.org/wiki/Free_software), [multi-platform](https://en.wikipedia.org/wiki/Multi-platform), [instant messaging](https://en.wikipedia.org/wiki/Instant_messaging) software project originally developed by John Brooks[^o4] and later adopted as the official instant messaging client project of the Invisible.im group.[^o5] A goal of the Invisible.im group is to help people maintain privacy by developing a "[metadata](https://en.wikipedia.org/wiki/Metadata) free" instant messaging client.[^o6]

:::

## History {#History}

Originally called Torsion IM, Ricochet was renamed in June 2014.[^o8] Ricochet is a modern alternative to [TorChat](wikipedia://en/17873905),[^o9] which hasn't been updated in several years, and to [Tor Messenger](https://en.wikipedia.org/wiki/Tor_Messenger), which is discontinued.[^o10] On September 17, 2014, it was announced that the Invisible.im group would be working with Brooks on further development of Ricochet in a *[Wired](https://en.wikipedia.org/wiki/Wired_%28magazine%29)* article by [Kim Zetter](https://en.wikipedia.org/wiki/Kim_Zetter).[^o4] Zetter also wrote that Ricochet's future plans included a protocol redesign and file-transfer capabilities.[^o4] The protocol redesign was implemented in April 2015.[^o11]

In February 2016, Ricochet's developers made public a [security audit](https://en.wikipedia.org/wiki/Security_audit) that had been sponsored by the [Open Technology Fund](wikipedia://en/49417443) and carried out by the [NCC Group](https://en.wikipedia.org/wiki/NCC_Group) in November 2015.[^o12] The results of the audit were "reasonably positive".[^o13] The audit identified "multiple areas of improvement" and one vulnerability that could be used to deanonymize users.[^o12] According to Brooks, the vulnerability has been fixed as of 2016.[^o14]

After extended hiatus, blueprint for free speech sponsored a refreshed version named "Ricochet Refresh", it supports [onion address v3](wikipedia://en/3648703) instead of v2.[^o15]

## Technology {#Technology}

Ricochet is a decentralized instant messenger, meaning there is no server to connect to and share metadata with.[^o9] Further, using [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29), Ricochet starts a [Tor hidden service](https://en.wikipedia.org/wiki/Tor_hidden_service) locally on a person's computer and can communicate only with other Ricochet users who are also running their own Ricochet-created Tor hidden services. This way, Ricochet communication never leaves the Tor network. A user [screen name](https://en.wikipedia.org/wiki/Screen_name_%28computing%29) (example: ricochet:hslmfsg47dmcqctb) is auto-generated upon first starting Ricochet; the first half of the screen name is the word "ricochet", with the second half being the address of the Tor hidden service. Before two Ricochet users can talk, at least one of them must privately or publicly share their unique screen name in some way.

## Privacy benefits {#Privacy_benefits}

- Ricochet does not reveal user IP addresses or physical locations because it uses Tor.[^o4]
- Message content is cryptographically authenticated and private.[^o12]
- There is no need to register anywhere in order to use Ricochet, particularly with a fixed server.[^o9]
- Contact list information is stored locally, and it would be very difficult for passive surveillance techniques to determine whom the user is chatting with.[^o4]
- Ricochet does not save chat history. When the user closes a conversation, the chat log is not recoverable.
- The use of Tor hidden services prevents network traffic from ever leaving the Tor network, thereby preserving anonymity and complicating passive network surveillance.[^o4][^o9]
- Ricochet is a [portable application](https://en.wikipedia.org/wiki/Portable_application), users do not need to install any software to use Ricochet. Ricochet connects to the Tor network automatically.[^o9]

## Correlation attack {#Correlation_attack}

From 2019 to 2021, Ricochet was used by the admins (as well as an undercover investigator) of the child porn onion site [Boystown](https://en.wikipedia.org/wiki/Boystown_%28website%29). To identify the perpetrators, German police used a [correlation analysis attack](wikipedia://en/481813). By sending Ricochet messages to perpetrators and monitoring several hundred Tor nodes for simultaneous traffic of the correct size, authorities were able to identify intermediate Tor nodes and then also the perpetrator's entry nodes, revealing the perpetrators' [IP addresses](https://en.wikipedia.org/wiki/IP_address).[^o19]
