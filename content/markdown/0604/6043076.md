# Herbrand quotient

::: {#o1 .subject cue=lead name="Herbrand quotient"}

In [mathematics](wikipedia://en/18831), the **Herbrand quotient** is a [quotient](wikipedia://en/332640) of orders of [cohomology](wikipedia://en/248635) groups of a [cyclic group](wikipedia://en/52327). It was invented by [Jacques Herbrand](wikipedia://en/159901). It has an important application in [class field theory](wikipedia://en/242695).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If *G* is a finite cyclic group acting on a [*G*-module](wikipedia://en/26068776) *A*, then the cohomology groups *H*<sup>*n*</sup>(*G*,*A*) have period 2 for *n*≥1; in other words

*H*<sup>*n*</sup>(*G*,*A*) = *H*<sup>*n*+2</sup>(*G*,*A*),

an [isomorphism](wikipedia://en/14828) induced by [cup product](wikipedia://en/848684) with a generator of *H*<sup>*2*</sup>(*G*,**Z**). (If instead we use the [Tate cohomology groups](wikipedia://en/6070279) then the periodicity extends down to *n*=0.)

A **Herbrand module** is an *A* for which the cohomology groups are finite. In this case, the **Herbrand quotient** *h*(*G*,*A*) is defined to be the quotient

*h*(*G*,*A*) = |*H*<sup>*2*</sup>(*G*,*A*)|/|*H*<sup>*1*</sup>(*G*,*A*)|

of the order of the even and odd cohomology groups.

::: {#o5 .definition cue=heading name="Alternative definition"}

### Alternative definition {#Alternative_definition}

The quotient may be defined for a pair of [endomorphisms](wikipedia://en/9569) of an [Abelian group](wikipedia://en/2974), *f* and *g*, which satisfy the condition *fg* = *gf* = 0. Their Herbrand quotient *q*(*f*,*g*) is defined as

$$q(f,g) = \frac{|\mathrm{ker} f:\mathrm{im} g|}{|\mathrm{ker} g:\mathrm{im} f|}$$

if the two [indices](https://en.wikipedia.org/wiki/Index_of_a_group) are finite. If *G* is a cyclic group with generator γ acting on an Abelian group *A*, then we recover the previous definition by taking *f* = 1 - γ and *g* = 1 + γ + γ<sup>2</sup> + ... .

:::

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The Herbrand quotient is [multiplicative](wikipedia://en/20059) on [short exact sequences](https://en.wikipedia.org/wiki/Short_exact_sequence).[^o8] In other words, if

0 → *A* → *B* → *C* → 0

is exact, and any two of the quotients are defined, then so is the third and[^o9]

*h*(*G*,*B*) = *h*(*G*,*A*)*h*(*G*,*C*)

- If *A* is finite then *h*(*G*,*A*) = 1.[^o9]
- For *A* is a submodule of the *G*-module *B* of finite index, if either quotient is defined then so is the other and they are equal:[^o8] more generally, if there is a *G*-morphism *A* → *B* with finite kernel and cokernel then the same holds.[^o9]
- If **Z** is the integers with *G* acting trivially, then *h*(*G*,**Z**) = |*G*|
- If *A* is a finitely generated *G*-module, then the Herbrand quotient *h*(*A*) depends only on the complex *G*-module **C**⊗*A* (and so can be read off from the character of this complex representation of *G*).

These properties mean that the Herbrand quotient is usually relatively easy to calculate, and is often much easier to calculate than the orders of either of the individual cohomology groups.
