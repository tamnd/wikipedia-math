# Adequate pointclass

::: {#o1 .subject cue=lead name="Adequate pointclass"}

In the mathematical field of [descriptive set theory](wikipedia://en/396619), a **[pointclass](wikipedia://en/9304834)** can be called **adequate** if it contains all [recursive](https://en.wikipedia.org/wiki/Recursive_set) pointsets and is closed under recursive substitution, [bounded](wikipedia://en/5824808) universal and existential quantification and preimages by recursive functions.[^o2][^o3] This ensures that an adequate pointclass is robust enough to include computable sets and remain stable under fundamental operations, making it a key tool for studying the complexity and definability of sets in effective descriptive set theory.

:::
