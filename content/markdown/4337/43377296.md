# Ω-bounded space

::: {#o1 .subject cue=lead name="Ω-bounded space"}

In [mathematics](wikipedia://en/18831), an **ω-bounded space** is a [topological space](wikipedia://en/30450) in which the [closure](wikipedia://en/42309) of every [countable subset](wikipedia://en/6026) is [compact](wikipedia://en/6042). More generally, if *P* is some property of subspaces, then a *P*-bounded space is one in which every subspace with property *P* has compact closure.

:::

Every compact space is ω-bounded, and every ω-bounded space is [countably compact](https://en.wikipedia.org/wiki/Countably_compact). The [long line](wikipedia://en/338403) is ω-bounded but not compact.

The [bagpipe theorem](wikipedia://en/43365664) describes the ω-bounded surfaces.
