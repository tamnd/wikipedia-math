# Alternating multilinear map

::: {#o1 .subject cue=lead name="Alternating multilinear map"}

In [mathematics](wikipedia://en/18831), more specifically in [multilinear algebra](wikipedia://en/243946), an **alternating multilinear map** is a [multilinear map](wikipedia://en/221525) with all arguments belonging to the same vector space (for example, a [bilinear form](wikipedia://en/449477) or a [multilinear form](wikipedia://en/832212)) that is zero whenever any pair of its arguments is equal. This generalizes directly to a [module](wikipedia://en/276410) over a [commutative ring](wikipedia://en/61346).

:::

The notion of **alternatization** (or **alternatisation**) is used to derive an alternating multilinear map from any multilinear map of which all arguments belong to the same space.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $R$ be a commutative ring and $V$, $W$ be modules over $R$. A multilinear map of the form $f: V^n \to W$ is said to be **alternating** if it satisfies the following equivalent conditions:

1. whenever there exists $1 \leq i \leq n-1$ such that $x_i = x_{i+1}$ then $f(x_1,\ldots,x_n) = 0$.[^n1][^n2]
1. whenever there exists $1 \leq i \neq j \leq n$ such that $x_i = x_j$ then $f(x_1,\ldots,x_n) = 0$.[^n1][^n3]

:::

## Vector spaces {#Vector_spaces}

Let $V, W$ be vector spaces over the same field. Then a multilinear map of the form $f: V^n \to W$ is alternating if it satisfies the following condition:

- if $x_1,\ldots,x_n$ are [linearly dependent](https://en.wikipedia.org/wiki/Linearly_dependent) then $f(x_1,\ldots,x_n) = 0$.

::: {#o10 .example cue=heading name="Example"}

## Example {#Example}

In a [Lie algebra](wikipedia://en/17944), the [Lie bracket](wikipedia://en/17944) is an alternating bilinear map. The [determinant](wikipedia://en/8468) of a matrix is a multilinear alternating map of the rows or columns of the matrix.

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If any component $x_i$ of an alternating multilinear map is replaced by $x_i + c x_j$ for any $j \neq i$ and $c$ in the base [ring](wikipedia://en/48404) $R$, then the value of that map is not changed.[^n3]

Every alternating multilinear map is [antisymmetric](https://en.wikipedia.org/wiki/Antisymmetric_map),[^n4] meaning that[^n1]

$$f(\dots,x_i,x_{i+1},\dots)=-f(\dots,x_{i+1},x_i,\dots) \quad \text{ for any } 1 \leq i \leq n-1,$$

or equivalently,

$$f(x_{\sigma(1)},\dots,x_{\sigma(n)}) = (\operatorname{sgn}\sigma)f(x_1,\dots,x_n) \quad \text{ for any } \sigma\in \mathrm{S}_n,$$

where $\mathrm{S}_n$ denotes the [permutation group](wikipedia://en/24634) of degree $n$ and $\operatorname{sgn}\sigma$ is the [sign](wikipedia://en/49727) of $\sigma$.[^n5] If $n!$ is a [unit](wikipedia://en/289666) in the base ring $R$, then every antisymmetric $n$-multilinear form is alternating.

:::

## Alternatization {#Alternatization}

Given a multilinear map of the form $f : V^n \to W,$ the alternating multilinear map $g : V^n \to W$ defined by

$$g(x_1, \ldots, x_n) \mathrel{:=} \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma)f(x_{\sigma(1)}, \ldots, x_{\sigma(n)})$$

is said to be the **alternatization** of $f$.

**Properties**

- The alternatization of an $n$-multilinear alternating map is $n!$ times itself.
- The alternatization of a [symmetric map](wikipedia://en/22510359) is zero.
- The alternatization of a [bilinear map](wikipedia://en/4365) is bilinear. Most notably, the alternatization of any [cocycle](wikipedia://en/138404) is bilinear. This fact plays a crucial role in identifying the second [cohomology group](wikipedia://en/194060) of a [lattice](wikipedia://en/469246) with the [group](wikipedia://en/19447) of alternating [bilinear forms](wikipedia://en/449477) on a lattice.
