# Spatial descriptive statistics

::: {#o1 .subject cue=lead name="Spatial descriptive statistics"}

**Spatial descriptive statistics** is the intersection of [spatial statistics](wikipedia://en/9467349) and [descriptive statistics](wikipedia://en/8187); these methods are used for a variety of purposes in [geography](https://en.wikipedia.org/wiki/Geography), particularly in [quantitative data analyses](https://en.wikipedia.org/wiki/Quantitative_data_analysis) involving [Geographic Information Systems (GIS)](https://en.wikipedia.org/wiki/GIS).

:::

## Types of spatial data {#Types_of_spatial_data}

The simplest forms of spatial data are *gridded data*, in which a scalar quantity is measured for each point in a regular grid of points, and *point sets*, in which a set of coordinates (e.g. of points in the plane) is observed. An example of gridded data would be a [satellite image](https://en.wikipedia.org/wiki/Satellite_image) of forest density that has been digitized on a grid. An example of a point set would be the latitude/longitude coordinates of all [elm trees](https://en.wikipedia.org/wiki/Elm_tree) in a particular plot of land. More complicated forms of data include marked point sets and spatial [time series](wikipedia://en/406624).

## Measures of spatial central tendency {#Measures_of_spatial_central_tendency}

The coordinate-wise mean of a point set is the [centroid](wikipedia://en/187926), which solves the same [variational problem](https://en.wikipedia.org/wiki/Central_tendency#Solutions_to_variational_problems) in the plane (or higher-dimensional [Euclidean space](wikipedia://en/9697)) that the familiar average solves on the real line — that is, the centroid has the smallest possible average squared distance to all points in the set.

## Measures of spatial dispersion {#Measures_of_spatial_dispersion}

[Dispersion](wikipedia://en/23773247) captures the degree to which points in a point set are separated from each other. For most applications, spatial dispersion should be quantified in a way that is invariant to rotations and reflections. Several simple measures of spatial dispersion for a point set can be defined using the [covariance matrix](wikipedia://en/191752) of the coordinates of the points. The [trace](wikipedia://en/43270), the [determinant](wikipedia://en/8468), and the largest [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue) of the covariance matrix can be used as measures of spatial dispersion.

A measure of spatial dispersion that is not based on the covariance matrix is the average distance between nearest neighbors.[^o5]

## Measures of spatial homogeneity {#Measures_of_spatial_homogeneity}

A homogeneous set of points in the plane is a set that is distributed such that approximately the same number of points occurs in any circular region of a given area. A set of points that lacks homogeneity may be *spatially clustered* at a certain [spatial scale](https://en.wikipedia.org/wiki/Spatial_scale). A simple probability model for spatially homogeneous points is the [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) in the plane with constant intensity function.

### Ripley's *K* and *L* functions {#Ripley's_K_and_L_functions}

Ripley's *K* and *L* functions introduced by [Brian D. Ripley](wikipedia://en/6608281)[^o8] are closely related descriptive statistics for detecting deviations from spatial homogeneity. The *K* function (technically its sample-based estimate) is defined as

$$\widehat{K}(t) = \lambda^{-1} \sum_{i\ne j} \frac{I(d_{ij}<t)} n,$$

where *d*<sub>*ij*</sub> is the Euclidean distance between the *i*<sup>th</sup> and *j*<sup>th</sup> points in a [data set](wikipedia://en/8495) of *n* points, t is the search radius, λ is the average density of points (generally estimated as *n*/*A*, where *A* is the area of the region containing all points) and *I* is the [indicator function](wikipedia://en/240790) (i.e. 1 if its operand is true, 0 otherwise).[^o9] In 2 dimensions, if the points are approximately homogeneous, $\widehat{K}(t)$ should be approximately equal to π*t*<sup>2</sup>.

For data analysis, the variance stabilized Ripley *K* function called the *L* function is generally used. The sample version of the *L* function is defined as

$$\widehat{L}(t) = \left( \frac{\widehat{K}(t)} \pi \right)^{1/2}.$$

For approximately homogeneous data, the *L* function has expected value *t* and its variance is approximately constant in *t*. A common plot is a graph of $t - \widehat{L}(t)$ against *t*, which will approximately follow the horizontal zero-axis with constant dispersion if the data follow a homogeneous Poisson process.

Using Ripley's *K* function it can be determined whether points have a random, dispersed or clustered distribution pattern at a certain scale.[^o10]
