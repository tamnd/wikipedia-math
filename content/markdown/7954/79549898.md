# Power-bounded element

::: {#o1 .subject cue=lead name="Power-bounded element"}

A **power-bounded element** is an element of a [topological ring](wikipedia://en/60097) whose powers are bounded. These elements are used in the theory of [adic spaces](https://en.wikipedia.org/wiki/Adic_space).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $A$ be a topological ring. A subset $T \subset A$ is called **bounded**, if, for every [neighbourhood](wikipedia://en/1529485) $U$ of zero, there exists an open neighbourhood $V$ of zero such that $T \cdot V := \{t \cdot v \mid t \in T, v \in V\} \subset U$ holds. An element $a \in A$ is called **power-bounded**, if the set $\{a^n \mid n \in \mathbb N\}$ is bounded.[^o4]

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- An element $x \in \mathbb R$ is power-bounded if and only if $|x| \leq 1$.
- More generally, if $A$ is a topological commutative ring whose topology is induced by an [absolute value](wikipedia://en/5042667), then an element $x \in A$ is power-bounded if and only if $|x| \leq 1$ holds. If the absolute value is [non-Archimedean](wikipedia://en/5042667#Types_of_absolute_value), the power-bounded elements form a [subring](wikipedia://en/24873145) (a [valuation ring](wikipedia://en/966856)), denoted by $A^{\circ}$. This follows from the [ultrametric inequality](https://en.wikipedia.org/wiki/Ultrametric_inequality).
- The ring of power-bounded elements in $\mathbb Q_p$, the [p-adic numbers](https://en.wikipedia.org/wiki/P-adic_numbers), is $\mathbb Q_p^{\circ} = \mathbb Z_p$.
- Every topologically nilpotent element is power-bounded.[^o7]

:::
