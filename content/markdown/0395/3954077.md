# Boolean domain

::: {#o1 .subject cue=lead name="Boolean domain"}

In [mathematics](wikipedia://en/18831) and [abstract algebra](wikipedia://en/19616384), a **Boolean domain** is a [set](wikipedia://en/26691) consisting of exactly two elements whose interpretations include *false* and *true*. In [logic](wikipedia://en/46426065), mathematics and [theoretical computer science](wikipedia://en/323392), a Boolean domain is usually written as {0, 1},[^o6][^o7][^o8][^o9][^o10] or $\mathbb{B}.$[^o11][^o12]

:::

The [algebraic structure](wikipedia://en/106364) that naturally builds on a Boolean domain is the [Boolean algebra with two elements](wikipedia://en/2584449). The [initial object](https://en.wikipedia.org/wiki/Initial_object) in the [category](wikipedia://en/53759) of [bounded lattices](wikipedia://en/310878) is a Boolean domain.

In [computer science](https://en.wikipedia.org/wiki/Computer_science), a Boolean variable is a [variable](https://en.wikipedia.org/wiki/Variable_%28programming%29) that takes values in some Boolean domain. Some [programming languages](wikipedia://en/23015) feature [reserved words](https://en.wikipedia.org/wiki/Reserved_word) or symbols for the elements of the Boolean domain, for example `false` and `true`. However, many programming languages do not have a [Boolean data type](https://en.wikipedia.org/wiki/Boolean_data_type) in the strict sense. In [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) or [BASIC](https://en.wikipedia.org/wiki/BASIC), for example, falsity is represented by the number 0 and truth is represented by the number 1 or −1, and all variables that can take these values can also take any other numerical values.

::: {#o3 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

The Boolean domain {0, 1} can be replaced by the [unit interval](wikipedia://en/49324) 0,1, in which case rather than only taking values 0 or 1, any value between and including 0 and 1 can be assumed. Algebraically, negation (NOT) is replaced with $1-x,$ conjunction (AND) is replaced with multiplication ($xy$), and disjunction (OR) is defined via [De Morgan's law](https://en.wikipedia.org/wiki/De_Morgan's_law) to be $1-(1-x)(1-y)=x+y-xy$.

Interpreting these values as logical [truth values](wikipedia://en/161711) yields a [multi-valued logic](https://en.wikipedia.org/wiki/Multi-valued_logic), which forms the basis for [fuzzy logic](wikipedia://en/49180) and [probabilistic logic](wikipedia://en/5017608). In these interpretations, a value is interpreted as the "degree" of truth – to what extent a proposition is true, or the probability that the proposition is true.
