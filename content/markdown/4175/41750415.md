# Denjoy–Carleman–Ahlfors theorem

::: {#o1 .subject cue=lead name="Denjoy–Carleman–Ahlfors theorem"}

The ***Denjoy–Carleman–Ahlfors theorem*** is a mathematical theorem that states that the number of [asymptotic](https://en.wikipedia.org/wiki/Asymptotic) values attained by a non-constant [entire function](wikipedia://en/10372) of order ρ on curves going outwards toward infinite [absolute value](wikipedia://en/991) is less than or equal to 2ρ. It was first conjectured by [Arnaud Denjoy](wikipedia://en/1485520) in 1907.[^o2] [Torsten Carleman](wikipedia://en/6063370) showed that the number of asymptotic values was less than or equal to (5/2)ρ in 1921.[^o3] In 1929 [Lars Ahlfors](wikipedia://en/61636) confirmed Denjoy's conjecture of 2ρ.[^o4] Finally, in 1933, Carleman published a very short proof.[^o5]

:::

The use of the term "asymptotic value" does not mean that the ratio of that value to the value of the function approaches 1 (as in [asymptotic analysis](wikipedia://en/641995)) as one moves along a certain curve, but rather that the function value approaches the asymptotic value along the curve. For example, as one moves along the real axis toward negative infinity, the function $\exp(z)$ approaches zero, but the quotient $0/\exp(z)$ does not go to 1.

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

The function $\exp(z)$ is of order 1 and has only one asymptotic value, namely 0. The same is true of the function $\sin(z)/z,$ but the asymptote is attained in two opposite directions.

A case where the number of asymptotic values is equal to 2ρ is the [sine integral](https://en.wikipedia.org/wiki/Sine_integral) $\text{Si}(z)=\int_0^z\frac{\sin \zeta}{\zeta}\,d\zeta$, a function of order 1 which goes to −π/2 along the real axis going toward negative infinity, and to +π/2 in the opposite direction.

The integral of the function $a\sin(z^2)/z+b\sin(z^2)/z^2$ is an example of a function of order 2 with four asymptotic values (if *b* is not zero), approached as one goes outward from zero along the real and imaginary axes.

More generally, $f(z)=\int_0^z\frac{\sin(\zeta^\rho)}{\zeta^\rho}d\zeta,$ with ρ any positive [integer](wikipedia://en/14563), is of order ρ and has 2ρ asymptotic values.

It is clear that the theorem applies to polynomials only if they are not constant. A constant polynomial has 1 asymptotic value, but is of order 0.

:::

## Generalized version {#Generalized_version}

[Lars Ahlfors](wikipedia://en/61636) later generalized the theorem, in his work on [Ahlfors theory](wikipedia://en/34351523), which he published in 1935. The generalized theorem states that the number of asymptotic values of any [meromorphic function](wikipedia://en/80857), of the order p, is smaller than or equal to 2pR where R denotes the number of sheets of the associated [Riemann surface](wikipedia://en/173181).

A case where the number of asymptotic values is equal to 2ρR is the function $f(z) = \exp(z^p)$. Given $z^p$, the number of sheets of the associated Riemann surface is obviously equal to that of $f$.
