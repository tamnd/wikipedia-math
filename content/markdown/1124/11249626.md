# Statistical model specification

::: {#o1 .subject cue=lead name="Statistical model specification"}

In [statistics](wikipedia://en/26685), **model specification** is part of the process of building a [statistical model](wikipedia://en/27576): specification consists of selecting an appropriate [functional form](wikipedia://en/185427) for the model and choosing which variables to include. For example, given [personal income](https://en.wikipedia.org/wiki/Personal_income) $y$ together with years of schooling $s$ and on-the-job experience $x$, we might specify a functional relationship $y = f(s,x)$ as follows:[^o2]

:::

$$\ln y = \ln y_0 + \rho s + \beta_1 x + \beta_2 x^2 + \varepsilon$$

where $\varepsilon$ is the unexplained [error term](wikipedia://en/461509) that is supposed to comprise [independent and identically distributed](wikipedia://en/30876902) [Gaussian variables](wikipedia://en/21462).

The statistician [Sir David Cox](wikipedia://en/1990771) has said, "How \[the\] translation from subject-matter problem to statistical model is done is often the most critical part of an analysis".[^o3]

## Specification error and bias {#Specification_error_and_bias}

Specification error occurs when the functional form or the choice of [independent variables](https://en.wikipedia.org/wiki/Independent_variable) poorly represent relevant aspects of the true data-generating process. In particular, [bias](wikipedia://en/184099) (the [expected value](wikipedia://en/9653) of the difference of an estimated [parameter](wikipedia://en/25065) and the true underlying value) occurs if an independent variable is correlated with the errors inherent in the underlying process. There are several different possible causes of specification error; some are listed below.

- An inappropriate functional form could be employed.
- A variable omitted from the model may have a relationship with both the [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable) and one or more of the independent variables (causing [omitted-variable bias](wikipedia://en/1528061)).[^o5]
- An irrelevant variable may be included in the model (although this does not create bias, it involves [overfitting](wikipedia://en/173332) and so can lead to poor predictive performance).
- The dependent variable may be part of a system of [simultaneous equations](wikipedia://en/250436) (giving simultaneity bias).

Additionally, [measurement errors](https://en.wikipedia.org/wiki/Measurement_errors) may affect the independent variables: while this is not a specification error, it can create statistical bias.

Note that all models will have some specification error. Indeed, in statistics there is a common aphorism that "[all models are wrong](wikipedia://en/44732699)". In the words of Burnham & Anderson,

> "Modeling is an art as well as a science and is directed toward finding a good approximating model ... as the basis for statistical inference".[^o6]

### Detection of misspecification {#Detection_of_misspecification}

The [Ramsey RESET test](wikipedia://en/5611588) can help test for specification error in [regression analysis](wikipedia://en/826997).

In the example given above relating personal income to schooling and job experience, if the assumptions of the model are correct, then the [least squares](wikipedia://en/82359) estimates of the parameters $\rho$ and $\beta$ will be [efficient](wikipedia://en/27250866) and [unbiased](wikipedia://en/184099). Hence specification diagnostics usually involve testing the first to fourth [moment](wikipedia://en/368684) of the [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics).[^o8]

## Model building {#Model_building}

Building a model involves finding a set of relationships to represent the process that is generating the data. This requires avoiding all the sources of misspecification mentioned above.

One approach is to start with a model in general form that relies on a theoretical understanding of the data-generating process. Then the model can be fit to the data and checked for the various sources of misspecification, in a task called *[statistical model validation](wikipedia://en/26502065)*. Theoretical understanding can then guide the modification of the model in such a way as to retain theoretical validity while removing the sources of misspecification. But if it proves impossible to find a theoretically acceptable specification that fits the data, the theoretical model may have to be rejected and replaced with another one.

A quotation from [Karl Popper](https://en.wikipedia.org/wiki/Karl_Popper) is apposite here: "Whenever a theory appears to you as the only possible one, take this as a sign that you have neither understood the theory nor the problem which it was intended to solve".[^o10]

Another approach to model building is to specify several different models as candidates, and then compare those candidate models to each other. The purpose of the comparison is to determine which candidate model is most appropriate for statistical inference. Common criteria for comparing models include the following: [*R*<sup>2</sup>](wikipedia://en/1500869), [Bayes factor](wikipedia://en/824552), and the [likelihood-ratio test](wikipedia://en/45035) together with its generalization [relative likelihood](wikipedia://en/55754796). For more on this topic, see *[statistical model selection](https://en.wikipedia.org/wiki/Statistical_model_selection)*.
