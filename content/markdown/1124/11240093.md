# Intransitive game

::: {#o1 .subject cue=lead name="Intransitive game"}

An **intransitive** or **non-transitive game** is a [zero-sum](wikipedia://en/34417) game in which pairwise competitions between the strategies contain a cycle. If strategy A beats strategy B, B beats C, and C beats A, then the binary relation "to beat" is intransitive, since transitivity would require that A beat C. The terms "transitive game" or "intransitive game" are not used in [game theory](wikipedia://en/11924).

:::

A prototypical example of an intransitive game is the game [rock, paper, scissors](https://en.wikipedia.org/wiki/Rock,_paper,_scissors). In [probabilistic](wikipedia://en/22934) games like [Penney's game](https://en.wikipedia.org/wiki/Penney's_game), the violation of transitivity results in a more subtle way, and is often presented as a probability [paradox](wikipedia://en/24390).
