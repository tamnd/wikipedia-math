# Real projective line

::: {#o1 .subject cue=lead name="Real projective line"}

*Image: Real Projective Line (RP1).png.* The real projective line can be modeled by the [projectively extended real line](wikipedia://en/1014534), which consists of the [real line](https://en.wikipedia.org/wiki/Real_line) together with a [point at infinity](wikipedia://en/403139); i.e., the [one-point compactification](https://en.wikipedia.org/wiki/One-point_compactification) of **R**.

In [geometry](wikipedia://en/18973446), a **real projective line** is a [projective line](wikipedia://en/398578) over the [real numbers](wikipedia://en/20646438). It is an extension of the usual concept of a [line](wikipedia://en/946975) that has been historically introduced to solve a problem set by visual [perspective](https://en.wikipedia.org/wiki/Perspective_%28visual%29): two [parallel lines](https://en.wikipedia.org/wiki/Parallel_lines) do not intersect but seem to intersect "at infinity". For solving this problem, [points at infinity](https://en.wikipedia.org/wiki/Points_at_infinity) have been introduced, in such a way that in a [real projective plane](wikipedia://en/411325), two distinct projective lines meet in exactly one point. The set of these points at infinity, the "horizon" of the visual perspective in the plane, is a real projective line. It is the set of directions emanating from an observer situated at any point, with opposite directions identified.

:::

An example of a real projective line is the [projectively extended real line](wikipedia://en/1014534), which is often called *the* projective line.

Formally, a real projective line **P**(**R**) is defined as the set of all one-dimensional linear subspaces of a two-dimensional vector space over the reals. The [automorphisms](wikipedia://en/1160) of a real projective line are called [projective transformations](https://en.wikipedia.org/wiki/Projective_transformation), [homographies](wikipedia://en/3051962), or [linear fractional transformations](wikipedia://en/401769). They form the [projective linear group](wikipedia://en/382667) PGL(2, **R**). Each element of PGL(2, **R**) can be defined by a [nonsingular](https://en.wikipedia.org/wiki/Nonsingular_matrix) 2×2 real matrix, and two matrices define the same element of PGL(2, **R**) if one is the product of the other and a nonzero real number.

Topologically, real projective lines are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to [circles](wikipedia://en/6220). The complex analog of a real projective line is a [complex projective line](https://en.wikipedia.org/wiki/Complex_projective_line), also called a [Riemann sphere](wikipedia://en/30876799).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The points of the real projective line are usually defined as [equivalence classes](wikipedia://en/9260) of an [equivalence relation](wikipedia://en/9259). The starting point is a [real vector space](https://en.wikipedia.org/wiki/Real_vector_space) of dimension 2, $V$. Define on $V \setminus 0$ the [binary relation](wikipedia://en/3931) $\mathbf{v} \sim \mathbf{w}$ to hold when there exists a nonzero real number $t$ such that $\mathbf{v} = t\mathbf{w}$. The definition of a vector space implies almost immediately that this is an equivalence relation. The equivalence classes are the vector lines from which the zero vector has been removed. The real projective line $\mathbf{P}(\mathbf{V})$ is the set of all equivalence classes. Each equivalence class is considered as a single point, or, in other words, a *point* is defined as being an equivalence class.

If one chooses a basis of $V$, this amounts (by identifying a vector with its [coordinate vector](wikipedia://en/879358)) to identify $V$ with the direct product $\mathbf{R} \times \mathbf{R} = \mathbf{R}^{2}$, and the equivalence relation becomes $(x, y) \sim (w, z)$ if there exists a nonzero real number $t$ such that $(x, y) = (tw, tz)$. In this case, the projective line $\mathbf{P}(\mathbf{R}^{2})$ is preferably denoted $\mathbf{P}^{1}(\mathbf{R})$ or $\mathbb{R}\mathbb{P}^1$. The equivalence class of the pair $(x, y)$ is traditionally denoted $[x: y]$, the colon in the notation recalling that, if $y \ne 0$, the [ratio](wikipedia://en/87837) $x : y$ is the same for all elements of the equivalence class. If a point $P$ is the equivalence class $[x: y]$ one says that $(x, y)$ is a pair of [projective coordinates](https://en.wikipedia.org/wiki/Projective_coordinates) of $P$.[^o4]

As $\mathbf{P}(\mathbf{V})$ is defined through an equivalence relation, the [canonical projection](https://en.wikipedia.org/wiki/Canonical_projection) from $V$ to $\mathbf{P}(\mathbf{V})$ defines a topology (the [quotient topology](https://en.wikipedia.org/wiki/Quotient_topology)) and a [differential structure](wikipedia://en/725272) on the projective line. However, the fact that equivalence classes are not finite induces some difficulties for defining the differential structure. These are solved by considering $\mathbf{V}$ as a [Euclidean vector space](https://en.wikipedia.org/wiki/Euclidean_vector_space). The [circle](wikipedia://en/6220) of the [unit vectors](wikipedia://en/167053) is, in the case of $\mathbf{R}^{2}$, the set of the vectors whose coordinates satisfy $x^{2} + y^{2} = 1$. This circle intersects each equivalence classes in exactly two opposite points. Therefore, the projective line may be considered as the quotient space of the circle by the equivalence relation such that $\mathbf{v} \sim \mathbf{w}$ if and only if either $\mathbf{v} = \mathbf{w}$ or $\mathbf{v} = -\mathbf{w}$.

:::

## Charts {#Charts}

The projective line is a [manifold](wikipedia://en/2073470). This can be seen by above construction through an equivalence relation, but is easier to understand by providing an [atlas](wikipedia://en/47436) consisting of two [charts](https://en.wikipedia.org/wiki/Chart_%28topology%29)

- Chart #1: $y\ne 0, \quad [x: y] \mapsto \frac {x}{y}$
- Chart #2: $x\ne 0, \quad [x: y] \mapsto \frac {y}{x}$

The equivalence relation provides that all representatives of an equivalence class are sent to the same real number by a chart.

Either of $x$ or $y$ may be zero, but not both, so both charts are needed to cover the projective line. The [transition map](https://en.wikipedia.org/wiki/Transition_map) between these two charts is the [multiplicative inverse](wikipedia://en/229940). As it is a [differentiable function](wikipedia://en/330206), and even an [analytic function](wikipedia://en/61478) (outside of zero), the real projective line is both a [differentiable manifold](wikipedia://en/2119219) and an [analytic manifold](wikipedia://en/3183798).

The [inverse function](wikipedia://en/14907) of chart #1 is the map

$$x \mapsto [x: 1].$$

It defines an [embedding](wikipedia://en/52119) of the [real line](https://en.wikipedia.org/wiki/Real_line) into the projective line, whose complement of the image is the point $[1: 0]$. The pair consisting of this embedding and the projective line is called the [projectively extended real line](wikipedia://en/1014534). Identifying the real line with its image by this embedding, one sees that the projective line may be considered as the union of the real line and the single point $[1: 0]$, called the [point at infinity](wikipedia://en/403139) of the projectively extended real line, and denoted $\infty$. This embedding allows us to identify the point $[x: y]$ either with the real number $\tfrac{x}{y}$ if $y \ne 0$, or with $\infty$ in the other case.

The same construction may be done with the other chart. In this case, the point at infinity is $[0: 1]$. This shows that the notion of point at infinity is not intrinsic to the real projective line, but is relative to the choice of an embedding of the real line into the projective line.

## Structure {#Structure}

*Image: Real\_projective\_2.png.* Same color means same point.

Points of the real projective line can be associated with pairs of [antipodal points](https://en.wikipedia.org/wiki/Antipodal_points) on a circle. Generally, a projective n-space is formed from antipodal pairs on a sphere in (n+1)-space; in this case the sphere is a circle in the plane.

The real projective line is a [complete](https://en.wikipedia.org/wiki/Complete_space) [projective range](wikipedia://en/34644484) that is found in the real projective plane and in the complex projective line. Its structure is thus inherited from these superstructures. Primary among these structures is the relation of [projective harmonic conjugates](https://en.wikipedia.org/wiki/Projective_harmonic_conjugates) among the points of the projective range.

The real projective line has a [cyclic order](wikipedia://en/434673) that extends the usual order of the real numbers.

## Automorphisms {#Automorphisms}

### The projective linear group and its action {#The_projective_linear_group_and_its_action}

Matrix-vector multiplication defines a right action of $\operatorname{GL}_{2}(\mathbf{R})$ on the space $\mathbf{R}^{2}$ of [row vectors](https://en.wikipedia.org/wiki/Row_vector): explicitly,

$$(x , y) \begin{pmatrix} a & c \\ b & d \end{pmatrix} = (ax+by : cx+dy) .$$

Since each matrix in $\operatorname{GL}_{2}(\mathbf{R})$ fixes the zero vector and maps proportional vectors to proportional vectors, there is an induced action of $\operatorname{GL}_{2}(\mathbf{R})$ on $\mathbf{P}^{1}(\mathbf{R})$: explicitly,[^o9]

$$[x:y] \begin{pmatrix} a & c \\ b & d \end{pmatrix} = [ ax+by : cx+dy ].$$

(Here and below, the notation $[x:y]$ for [homogeneous coordinates](wikipedia://en/243316) denotes the equivalence class of the row vector.

The elements of $\operatorname{GL}_{2}(\mathbf{R})$ that act trivially on $\mathbf{P}^{1}(\mathbf{R})$ are the nonzero scalar multiples of the identity matrix; these form a subgroup denoted $\mathbf{R}^{\times}$. The [projective linear group](wikipedia://en/382667) is defined to be the [quotient group](wikipedia://en/11526) $\operatorname{PGL}_{2}(\mathbf{R}) = \operatorname{GL}_{2}(\mathbf{R})/\mathbf{R}^{\times}$. By the above, there is an induced faithful action of $\operatorname{PGL}_{2}(\mathbf{R})$ on $\mathbf{P}^{1}(\mathbf{R})$. For this reason, the group $\operatorname{PGL}_{2}(\mathbf{R})$ may also be called the *group of linear automorphisms* of $\mathbf{P}^{1}(\mathbf{R})$.

### Linear fractional transformations {#Linear_fractional_transformations}

Using the identification $\mathbf{R} \cup \infty \to \mathbf{P}^{1}(\mathbf{R})$ sending $x$ to $[x:1]$ and $\infty$ to $[1:0]$, one obtains a corresponding action of $\operatorname{PGL}_{2}(\mathbf{R})$ on $\mathbf{R} \cup \infty$ , which is by [linear fractional transformations](wikipedia://en/401769): explicitly, since

$$[x:1] \begin{pmatrix} a & c \\ b & d \end{pmatrix} = [ ax+b : cx+d ] \quad \mathrm{and} \quad [1:0] \begin{pmatrix} a & c \\ b & d \end{pmatrix} = [ a : c],$$

the class of $\begin{pmatrix} a & c \\ b & d \end{pmatrix}$ in $\operatorname{PGL}_{2}(\mathbf{R})$ acts as $x \mapsto \frac{ax+b}{cx+d}$ with the understanding that each fraction with denominator 0 should be interpreted as $\infty$.[^o11] and $\infty \mapsto \frac{a}{c}$.[^o12]

Some authors use left action on column vectors which entails switching *b* and *c* in the matrix operator.[^o13][^o14][^o15]

::: {#o17 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- Given two ordered triples of distinct points in $\mathbf{P}^{1}(\mathbf{R})$, there exists a unique element of $\operatorname{PGL}_{2}(\mathbf{R})$ mapping the first triple to the second; that is, the action is [sharply 3-transitive](wikipedia://en/12781#Transitivity_properties). For example, the linear fractional transformation mapping $(0, 1, \infty)$ to $(-1, 0, 1)$ is the [Cayley transform](wikipedia://en/882010#Real_homography) $x\mapsto \frac{x-1}{x+1}$.
- The [stabilizer](https://en.wikipedia.org/wiki/Stabilizer_subgroup) in $\operatorname{PGL}_{2}(\mathbf{R})$ of the point $\infty$ is the [affine group](wikipedia://en/298828) of the real line, consisting of the transformations $x \mapsto ax+b$ for all $a \in \mathbf{R}^{*}$ and $b \in \mathbf{R}$.

:::
