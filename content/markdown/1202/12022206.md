# Common reference string model

::: {#o1 .subject cue=lead name="Common reference string model"}

In cryptography, the **common reference string** (CRS) model captures the assumption that a trusted setup in which all involved parties get access to the same string *crs* taken from some distribution *D* exists. Schemes [proven secure](wikipedia://en/1182348) in the CRS model are secure given that the setup was performed correctly. The common reference string model is a generalization of the **common random string** model, in which *D* is the uniform distribution of bit strings. As stated in,[^o2] the CRS model is equivalent to the *reference string model* [^o3] and the *public parameters model*.[^o4]

:::

The CRS model has applications in the study of [non-interactive zero-knowledge proofs](wikipedia://en/11589052) and [universal composability](wikipedia://en/15385848).
