# Carathéodory's theorem (convex hull)

::: {#o1 .subject cue=lead name="Carathéodory's theorem"}

**Carathéodory's theorem** is a theorem in [convex geometry](wikipedia://en/4165882). It states that if a point $x$ lies in the [convex hull](wikipedia://en/40634) $\mathrm{Conv}(P)$ of a set $P\subset \mathbb{R}^d$, then $x$ lies in some *$d$*-dimensional [simplex](wikipedia://en/39781) with vertices in $P$. Equivalently, $x$ can be written as the [convex combination](wikipedia://en/794534) of $d+1$ or fewer points in $P$. Additionally, $x$ can be written as the convex combination of at most $d+1$ *extremal* points in $P$, as non-extremal points can be removed from $P$ without changing the membership of *$x$* in the convex hull.

:::

An equivalent theorem for [conical combinations](wikipedia://en/19634578) states that if a point $x$ lies in the [conical hull](https://en.wikipedia.org/wiki/Conical_hull) $\mathrm{Cone}(P)$ of a set $P\subset \mathbb{R}^d$, then $x$ can be written as the conical combination of at most $d$ points in $P$.

Two other theorems of [Helly](wikipedia://en/1409506) and [Radon](wikipedia://en/1406385) are closely related to Carathéodory's theorem: the latter theorem can be used to prove the former theorems and vice versa.[^o3]

The result is named for [Constantin Carathéodory](wikipedia://en/470625), who proved the theorem in 1911 for the case when $P$ is [compact](wikipedia://en/6042).[^o4] In 1914 [Ernst Steinitz](wikipedia://en/3966685) expanded Carathéodory's theorem for arbitrary sets.[^o5]

::: {#o7 .example cue=heading name="Example"}

## Example {#Example}

*Image: Caratheodorys theorem example.svg.* An illustration of Carathéodory's theorem for a square in **R**<sup>2</sup>

Carathéodory's theorem in 2 dimensions states that we can construct a triangle consisting of points from *P* that encloses any point in the convex hull of *P*.

For example, let *P* = {(0,0), (0,1), (1,0), (1,1)}. The convex hull of this set is a square. Let *x* = (1/4, 1/4) in the convex hull of *P*. We can then construct a set {(0,0),(0,1),(1,0)} = *P*′, the convex hull of which is a triangle and encloses *x.*

:::

## Proof {#Proof}

**Note:** We will only use the fact that $\mathbb{R}$ is an [ordered field](wikipedia://en/22430), so the theorem and proof works even when $\mathbb{R}$ is replaced by any field $\mathbb F$, together with a total order.

We first formally state Carathéodory's theorem:[^o10]

::: {#o11 .statement kind=statement/theorem cue=math-theorem name="Carathéodory's theorem"}

**Carathéodory's theorem.**

If $x \in \mathrm{Cone}(S) \subset \mathbb{R}^d$, then $x$ is the nonnegative sum of at most $d$ points of $S$.

If $x \in \mathrm{Conv}(S) \subset \mathbb{R}^d$, then $x$ is the convex sum of at most $d+1$ points of $S$.

:::

The essence of Carathéodory's theorem is in the finite case. This reduction to the finite case is possible because $\mathrm{Conv}(S)$ is the set of *finite* convex combination of elements of $S$ (see the [convex hull](wikipedia://en/40634) page for details).

::: {#o12 .statement kind=statement/lemma cue=math-theorem name="Lemma"}

**Lemma.**

If $q_1, ..., q_N \in \mathbb{R}^d$ then $\forall x \in \mathrm{Cone}(\{q_1, ..., q_N\})$, there exist $w_1, ..., w_N \geq 0$ such that $x = \sum_n w_n q_n$, and at most $d$ of them are nonzero.

:::

With the lemma, Carathéodory's theorem is a simple extension:

::: {#o13 .proof cue=math-proof name="Proof of Carathéodory's theorem"}

**Proof of Carathéodory's theorem.**

For the first part: take any $x\in \mathrm{Cone}(S)$, represent $x=\sum_{n=1}^N w_n q_n$ for some $q_1, ..., q_N\in S$ and $w_n\geq0$, then $x\in \mathrm{Cone}(\{q_1, ..., q_N\})$, and we use the lemma.

The second part reduces to the first part by "lifting up one dimension", a common trick used to reduce affine geometry to linear algebra, and reduce convex bodies to convex cones.

Explicitly, let $S\subset \mathbb{R}^d$, then identify $\mathbb{R}^d$ with the subset $\{w \in \mathbb{R}^{d+1}: w_{d+1} = 1\}$. This induces an embedding of $S$ into $S \times \{1\}\subset \mathbb{R}^{d+1}$.

Any $x\in \mathrm{Conv}(S)$ has a representation $x = \sum_{n=1}^N w_n q_n$, with $\sum_{n=1}^N w_n = 1$ and $w_n\geq0$; x has a "lifted" representation $(x, 1) = \sum_{n=1}^N w_n (q_n, 1)$, and so, by the first part, it has a representation $(x, 1) = \sum_{n=1}^N w'_n (q_n, 1)$ with $w'_n\geq0$, where at most $d+1$ of $w'_n$ are nonzero. That is, $x = \sum_{n=1}^N w'_n q_n$ and $1 =\sum_{n=1}^N w'_n$, which completes the proof.

:::

::: {#o14 .proof cue=math-proof name="Proof of lemma"}

**Proof of lemma.**

This is trivial when $N \leq d$. If we can prove it for all $N = d+1$, then by induction we have proved it for all $N \geq d+1$. Thus it remains to prove it for $N = d+1$. This we prove by induction on $d$.

Base case: $d=1, N = 2$, trivial.

Induction case. Represent $x = \sum_{n=1}^{d+1} w_n q_n$. If some $w_n = 0$, then the proof is finished. So assume all $w_n > 0$

If $\{q_1, ..., q_{d}\}$ is linearly dependent, then we can use induction on its linear span to eliminate one nonzero term in $\sum_{n=1}^d \frac{w_n}{w_1 + \cdots + w_d}q_n$, and thus eliminate it in $x = \sum_{n=1}^{d+1} w_n q_n$ as well.

Else, there exists $(u_1, ..., u_{d}) \in \mathbb{R}^{d}$, such that $\sum_{n=1}^{d} u_n q_n = q_{d+1}$. Then we can interpolate a full interval of representations:

$$x = \sum_{n=1}^{d} (w_n+ \theta w_{d+1}u_n) q_n + (1-\theta) w_{d+1} q_{d+1}; \quad \theta\in[0, 1]$$

If $w_n + w_{d+1} u_n \geq 0$ for all $n=1, ..., d$, then set $\theta = 1$. Otherwise, let $\theta$ be the smallest $\theta$ such that one of $w_n + \theta w_{d+1} u_n = 0$. Then we obtain a representation of $x$ as a linear combination with non-negative coefficients, with at most $d$ nonzero terms.

:::

Alternative proofs use [Helly's theorem](wikipedia://en/1409506) or the [Perron–Frobenius theorem](wikipedia://en/1540333).[^o15][^o16]

:::

## Variants {#Variants}

### Carathéodory's number {#Carathéodory's_number}

For any nonempty $P\subset \mathbb{R}^d$, define its **Carathéodory's number** to be the smallest integer $r$, such that for any $x\in \mathrm{Conv}(P)$, there exists a representation of $x$ as a convex sum of up to $r$ elements in $P$.

Carathéodory's theorem simply states that any nonempty subset of $\mathbb{R}^d$ has Carathéodory's number $\leq d+1$. This upper bound is not necessarily reached. For example, the unit sphere in $\mathbb{R}^d$ has Carathéodory's number equal to 2, since any point inside the sphere is the convex sum of two points on the sphere.

With additional assumptions on $P\subset \mathbb{R}^d$, upper bounds strictly lower than $d+1$ can be obtained.[^o20]

### Dimensionless variant {#Dimensionless_variant}

Caratheodory's theorem type results where the diameter replaces the dependency on the dimension are well known.[^o22] An explicit statement of a no-dimensional Caratheodory's theorem was provided by Barman.[^o23] It is probable that this theorem was stated much earlier, as it is an easy consequence of the analysis of the Perceptron algorithm of Novikoff.[^o24] Specifically, for every positive integer $r$ and every point within the [convex hull](wikipedia://en/40634) of a finite point set $P$, there exists an $r$-point subset $R$ such that the given point is within distance $\operatorname{diam} P/\sqrt{2r}$ of the convex hull of $R$.[^o25]

::: {#o27 .statement kind=statement/theorem cue=named-heading name="Colorful Carathéodory theorem"}

### Colorful Carathéodory theorem {#Colorful_Carathéodory_theorem}

Let *X*<sub>1</sub>, ..., *X*<sub>*d*+1</sub> be sets in **R**<sup>*d*</sup> and let *x* be a point contained in the intersection of the convex hulls of all these *d*+1 sets.

Then there is a set *T* = {*x*<sub>1</sub>, ..., *x*<sub>*d*+1</sub>}, where $x_{1} \in X_{1}, ..., x_{d+1} \in X_{d+1}$, such that the convex hull of *T* contains the point *x*.[^o28]

By viewing the sets *X*<sub>1</sub>, ..., *X*<sub>*d*+1</sub> as different colors, the set *T* is made by points of all colors, hence the "colorful" in the theorem's name.[^o29] The set *T* is also called a *rainbow simplex*, since it is a *d*-dimensional [simplex](wikipedia://en/39781) in which each corner has a different color.[^o30]

This theorem has a variant in which the convex hull is replaced by the [conical hull](https://en.wikipedia.org/wiki/Conical_hull).[^o28] Let *X*<sub>1</sub>, ..., *X*<sub>*d*</sub> be sets in **R**<sup>d</sup> and let *x* be a point contained in the intersection of the *conical hulls* of all these *d* sets. Then there is a set *T* = {*x*<sub>1</sub>, ..., *x*<sub>*d*</sub>}, where $x_{1} \in X_{1}, ..., x_{d} \in X_{d}$, such that the *conical hull* of *T* contains the point *x*.[^o28]

Mustafa and Ray extended this colorful theorem from points to convex bodies.[^o30]

The computational problem of finding the colorful set lies in the intersection of the complexity classes [PPAD](wikipedia://en/9192019) and [PLS](wikipedia://en/4669257).[^o31]
