# Schreier's lemma

::: {#o1 .subject cue=lead name="Schreier's lemma"}

In [group theory](wikipedia://en/41890), **Schreier's lemma** is a [theorem](wikipedia://en/30977) used in the [Schreier–Sims algorithm](wikipedia://en/893640) and also for finding a [presentation](wikipedia://en/99494) of a [subgroup](wikipedia://en/28011).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Suppose $H$ is a subgroup of $G$ with [generating set](wikipedia://en/99945) $S$, that is, $G = \langle S\rangle$.

Let $R$ be a right [transversal](wikipedia://en/897733) of $H$ in $G$ with the neutral element $e$ in $R$. In other words, let $R$ be a set containing exactly one element from each right [coset](wikipedia://en/98759) of $H$ in $G$.

For each $g\in G$, we define $\overline{g}$ as the chosen representative of the coset $Hg$ in the transversal $R$.

Then $H$ is generated by the set

$\{rs(\overline{rs})^{-1}|r\in R, s\in S\}$.[^o4][^o5]

Hence, in particular, Schreier's lemma implies that every subgroup of finite [index](wikipedia://en/230581) of a finitely generated group is again finitely generated.[^o6]

:::

::: {#o8 .example cue=heading name="Example"}

## Example {#Example}

The group $\mathbb{Z}_3 = \mathbb{Z}\,/\,3 \mathbb{Z}$ is cyclic. Via [Cayley's theorem](wikipedia://en/105967), $\mathbb{Z}_3$ is isomorphic to a subgroup of the [symmetric group](wikipedia://en/28901) $S_3$. Now,

$$\mathbb{Z}_3 = \{ e, (1\ 2\ 3), (1\ 3\ 2) \}$$

$$S_3 = \{ e, (1\ 2), (1\ 3), (2\ 3), (1\ 2\ 3), (1\ 3\ 2) \}$$

where $e$ is the identity [permutation](wikipedia://en/44027). Note that $S_3$ is generated by $S = \{ s_1 = (1\ 2),\, s_2 = (1\ 2\ 3) \}$.

$\mathbb{Z}_3$ has just two right cosets in $S_3$, namely $\mathbb{Z}_3$ and $S_3 \setminus \mathbb{Z}_3 = \{ (1\ 2), (1\ 3), (2\ 3)\}$, so we select the right transversal $R = \{ r_1 = e,\, r_2 = (1\ 2) \}$, and we have

$$\begin{aligned} r_1s_1 &= (1\ 2), & \text{so} && \overline{r_1s_1} &= (1\ 2) \\ r_1s_2 &= (1\ 2\ 3), & \text{so} && \overline{r_1s_2} &= e \\ r_2s_1 &= e , & \text{so} && \overline{r_2s_1} &= e \\ r_2s_2 &= (2\ 3), & \text{so} && \overline{r_2s_2} &= (1\ 2). \\ \end{aligned}$$

Finally,

$$r_1s_1\left(\overline{r_1s_1}\right)^{-1} = e$$

$$r_1s_2\left(\overline{r_1s_2}\right)^{-1} = (1\ 2\ 3)$$

$$r_2s_1\left(\overline{r_2s_1}\right)^{-1} = e$$

$$r_2s_2\left(\overline{r_2s_2}\right)^{-1} = (1\ 2\ 3).$$

Thus, by Schreier's lemma, $\{ e, (1\ 2\ 3) \}$ generates $\mathbb{Z}_3$, but having the identity in the generating set is redundant, so it can be removed to obtain another generating set for $\mathbb{Z}_3$, $\{ (1\ 2\ 3) \}$.

:::
