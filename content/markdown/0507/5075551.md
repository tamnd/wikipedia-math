# Perfect set

::: {#o1 .subject cue=lead name="Perfect set"}

In [general topology](wikipedia://en/178649), a subset of a [topological space](wikipedia://en/30450) is **perfect** if it is [closed](wikipedia://en/47279) and has no [isolated points](wikipedia://en/390557). Equivalently: the set $S$ is perfect if $S=S'$, where $S'$ denotes the set of all [limit points](https://en.wikipedia.org/wiki/Limit_point) of $S$, also known as the [derived set](wikipedia://en/1567335) of $S$. (Some authors do not consider the empty set to be perfect.[^o2])

:::

In a perfect set, every point can be approximated arbitrarily well by other points from the set: given any point of $S$ and any [neighborhood](wikipedia://en/1529485) of the point, there is another point of $S$ that lies within the neighborhood. Furthermore, any point of the space that can be so approximated by points of $S$ belongs to $S$.

The term *perfect space* is also used, incompatibly, to refer to other properties of a topological space, such as being a [G<sub>δ</sub> space](https://en.wikipedia.org/wiki/G-delta_space). As another possible source of confusion, having the [perfect set property](wikipedia://en/2221109) is not the same as being a perfect set.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of perfect subsets of the [real line](https://en.wikipedia.org/wiki/Real_line) $\mathbb{R}$ are the [empty set](wikipedia://en/9566), all [closed intervals](https://en.wikipedia.org/wiki/Closed_interval), the real line itself, and the [Cantor set](wikipedia://en/6172). The latter is noteworthy in that it is [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected).

Whether a set is perfect or not (and whether it is closed or not) depends on the surrounding space. For instance, the set $S=[0,1]\cap \mathbb{Q}$ is perfect as a subset of the space $\mathbb{Q}$ but not perfect as a subset of the space $\mathbb{R}$, since it fails to be [closed](wikipedia://en/47279) in the latter.

:::

## Connection with other topological properties {#Connection_with_other_topological_properties}

Every topological space can be written in a unique way as the disjoint union of a perfect set and a [scattered set](wikipedia://en/40260318).[^o6][^o7]

[Cantor](wikipedia://en/12216) proved that every closed subset of the real line can be uniquely written as the disjoint union of a perfect set and a [countable set](wikipedia://en/6026). This is also true more generally for all closed subsets of [Polish spaces](wikipedia://en/396622), in which case the theorem is known as the [Cantor–Bendixson theorem](https://en.wikipedia.org/wiki/Cantor–Bendixson_theorem).

Cantor also showed that every non-empty perfect subset of the real line has [cardinality](wikipedia://en/6174) $2^{\aleph_0}$, the [cardinality of the continuum](wikipedia://en/1574901). These results are extended in [descriptive set theory](wikipedia://en/396619) as follows:

- If *X* is a [complete metric space](wikipedia://en/7832) with no isolated points, then the [Cantor space](wikipedia://en/352376) 2<sup>ω</sup> can be [continuously](wikipedia://en/6122) embedded into *X*. Thus, *X* has cardinality at least $2^{\aleph_0}$. If *X* is a [separable](wikipedia://en/27855), complete metric space with no isolated points, the cardinality of *X* is exactly $2^{\aleph_0}$.
- If *X* is a [locally compact](https://en.wikipedia.org/wiki/Locally_compact) [Hausdorff space](wikipedia://en/13637) with no isolated points, there is an [injective function](wikipedia://en/45196) (not necessarily continuous) from the Cantor space to *X*, and so *X* has cardinality at least $2^{\aleph_0}$.
