# Pseudocompact space

::: {#o1 .subject cue=lead name="Pseudocompact space"}

In [mathematics](wikipedia://en/18831), in the field of [topology](wikipedia://en/29954), a [topological space](wikipedia://en/30450) is said to be **pseudocompact** if its image under any [continuous function](wikipedia://en/6122) to **R** is [bounded](wikipedia://en/48258). Many authors include the requirement that the space be [completely regular](wikipedia://en/30554) in the definition of pseudocompactness. Pseudocompact spaces were defined by [Edwin Hewitt](wikipedia://en/7482590) in 1948.[^o2]

:::

## Properties related to pseudocompactness {#Properties_related_to_pseudocompactness}

- For a [Tychonoff space](wikipedia://en/30554) *X* to be **pseudocompact** requires that every [locally finite collection](wikipedia://en/11611098) of [non-empty](wikipedia://en/9566) [open sets](wikipedia://en/39358) of *X* be [finite](wikipedia://en/11742). There are many equivalent conditions for pseudocompactness (sometimes some [separation axiom](wikipedia://en/40117302) should be assumed); a large number of them are quoted in Stephenson 2003. Some historical remarks about earlier results can be found in Engelking 1989, p. 211.
- Every [countably compact](https://en.wikipedia.org/wiki/Countably_compact) space is pseudocompact. For [normal Hausdorff spaces](https://en.wikipedia.org/wiki/Normal_Hausdorff_space) the converse is true.
- As a consequence of the above result, every [sequentially compact](https://en.wikipedia.org/wiki/Sequentially_compact) space is pseudocompact. The converse is true for [metric spaces](https://en.wikipedia.org/wiki/Metric_spaces). As sequential compactness is an equivalent condition to [compactness](wikipedia://en/6042) for metric spaces this implies that compactness is an equivalent condition to pseudocompactness for metric spaces also.
- The weaker result that every compact space is pseudocompact is easily proved: the image of a compact space under any continuous function is compact, and every compact set in a metric space is bounded.
- If *Y* is the continuous image of pseudocompact *X*, then *Y* is pseudocompact. Note that for continuous functions *g* : *X* → *Y* and *h* : *Y* → **R**, the [composition](wikipedia://en/195947) of *g* and *h*, called *f*, is a continuous function from *X* to the real numbers. Therefore, *f* is bounded, and *Y* is pseudocompact.
- Let *X* be an infinite set given the [particular point topology](wikipedia://en/5336200). Then *X* is neither compact, sequentially compact, countably compact, [paracompact](https://en.wikipedia.org/wiki/Paracompact) nor [metacompact](https://en.wikipedia.org/wiki/Metacompact) (although it is [orthocompact](https://en.wikipedia.org/wiki/Orthocompact)). However, since *X* is [hyperconnected](wikipedia://en/7556651), it is pseudocompact. This shows that pseudocompactness doesn't imply any of these other forms of compactness.
- For a [Hausdorff space](wikipedia://en/13637) *X* to be **compact** requires that *X* be **pseudocompact** and **realcompact** (see Engelking 1968, p. 153).
- For a [Tychonoff space](wikipedia://en/30554) *X* to be **compact** requires that *X* be **pseudocompact** and **metacompact** (see Watson).

## Pseudocompact topological groups {#Pseudocompact_topological_groups}

A relatively refined theory is available for pseudocompact [topological groups](wikipedia://en/42315).[^o5] In particular, [W. W. Comfort](https://en.wikipedia.org/wiki/William_Wistar_Comfort_%28mathematician%29) and [Kenneth A. Ross](https://en.wikipedia.org/wiki/Kenneth_A._Ross) proved that a product of pseudocompact topological groups is still pseudocompact (this might fail for arbitrary topological spaces).[^o6]
