# Hemicompact space

::: {#o1 .subject cue=lead name="Hemicompact space"}

In [mathematics](wikipedia://en/18831), in the field of [topology](wikipedia://en/29954), a [Hausdorff](wikipedia://en/13637) [topological space](wikipedia://en/30450) is said to be **hemicompact** if it has a sequence of [compact](wikipedia://en/6042) subsets such that every compact subset of the space lies inside some compact set in the sequence.[^o2] This forces the [union](wikipedia://en/47949) of the sequence to be the whole space, because every point is compact and hence must lie in one of the compact sets.

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [compact space](wikipedia://en/6042) is hemicompact.
- The [real line](https://en.wikipedia.org/wiki/Real_line) is hemicompact.
- Every [locally compact](https://en.wikipedia.org/wiki/Locally_compact) [Lindelöf space](wikipedia://en/310480) is hemicompact.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every hemicompact space is [σ-compact](wikipedia://en/346681)[^o7] and if in addition it is [first countable](wikipedia://en/904940) then it is [locally compact](wikipedia://en/48632). If a hemicompact space is [weakly locally compact](https://en.wikipedia.org/wiki/Weakly_locally_compact), then it is [exhaustible by compact sets](https://en.wikipedia.org/wiki/Exhaustible_by_compact_sets).

:::

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

If $X$ is a hemicompact space, then the space $C(X, M)$ of all [continuous functions](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) $f : X \to M$ to a [metric space](wikipedia://en/20018) $(M, \delta)$ with the [compact-open topology](wikipedia://en/726335) is [metrizable](https://en.wikipedia.org/wiki/Metrizable).[^o10] To see this, take a sequence $K_1,K_2,\dots$ of compact subsets of $X$ such that every compact subset of $X$ lies inside some compact set in this sequence (the existence of such a sequence follows from the hemicompactness of $X$). Define [pseudometrics](wikipedia://en/68503)

$$d_n (f,g) = \sup_{x \in K_n} \delta\bigl( f(x), g(x) \bigr), \quad f,g \in C(X,M), n \in \mathbb{N}.$$

Then

$$d(f,g) = \sum_{n=1}^{\infty} \frac{1}{2^n} \cdot \frac{d_n (f,g)}{1+d_n (f,g)}$$

defines a [metric](wikipedia://en/20018#Definition) on $C(X,M)$ which induces the compact-open topology.

:::
