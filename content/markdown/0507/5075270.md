# Pseudonormal space

::: {#o1 .subject cue=lead name="Pseudonormal space"}

In [mathematics](wikipedia://en/18831), in the field of [topology](wikipedia://en/29954), a [topological space](wikipedia://en/30450) is said to be **pseudonormal** if given two disjoint [closed sets](wikipedia://en/47279) in it, one of which is [countable](https://en.wikipedia.org/wiki/Countable), there are disjoint open sets containing them.[^o2] Note the following:

:::

- Every [normal space](wikipedia://en/48629) is pseudonormal.
- Every pseudonormal space is [regular](wikipedia://en/53058).

An example of a pseudonormal [Moore space](wikipedia://en/8016525) that is not [metrizable](wikipedia://en/20018) was given by (txt), in connection with the conjecture that all normal Moore spaces are metrizable.[^o2][^o4]
