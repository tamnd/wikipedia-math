# Mesocompact space

::: {#o1 .subject cue=lead name="Mesocompact space"}

In [mathematics](wikipedia://en/18831), in the field of [general topology](wikipedia://en/178649), a [topological space](wikipedia://en/30450) is said to be **mesocompact** if every [open cover](https://en.wikipedia.org/wiki/Open_cover) has a *compact-finite* open [refinement](https://en.wikipedia.org/wiki/Refinement_%28topology%29).[^o2] That is, given any open cover, we can find an open refinement with the property that every compact set meets only finitely many members of the refinement.[^o3]

:::

The following facts are true about mesocompactness:

- Every [compact space](wikipedia://en/6042), and more generally every [paracompact space](wikipedia://en/48631) is mesocompact. This follows from the fact that any [locally finite](wikipedia://en/11611098) cover is automatically compact-finite.
- Every mesocompact space is [metacompact](wikipedia://en/5074872), and hence also [orthocompact](wikipedia://en/5074937). This follows from the fact that points are compact, and hence any compact-finite cover is automatically point finite.
