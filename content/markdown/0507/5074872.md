# Metacompact space

::: {#o1 .subject cue=lead name="Metacompact space"}

In the [mathematical](wikipedia://en/18831) field of [general topology](wikipedia://en/178649), a [topological space](wikipedia://en/30450) is said to be **metacompact** if every [open cover](https://en.wikipedia.org/wiki/Open_cover) has a [point-finite](https://en.wikipedia.org/wiki/Point-finite) open [refinement](https://en.wikipedia.org/wiki/Refinement_%28topology%29). That is, given any open cover of the topological space, there is a refinement that is again an open cover with the property that every point is contained only in finitely many sets of the refining cover.

:::

A space is **countably metacompact** if every [countable](wikipedia://en/6026) open cover has a point-finite open refinement.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The following can be said about metacompactness in relation to other properties of topological spaces:

- Every [paracompact space](wikipedia://en/48631) is metacompact. This implies that every [compact space](wikipedia://en/6042) is metacompact, and every [metric space](wikipedia://en/20018) is metacompact. The converse does not hold: a counter-example is the [Dieudonné plank](wikipedia://en/34995146).
- Every metacompact space is [orthocompact](https://en.wikipedia.org/wiki/Orthocompact).
- Every metacompact [normal space](wikipedia://en/48629) is a [shrinking space](wikipedia://en/5075898)
- The product of a [compact space](wikipedia://en/6042) and a metacompact space is metacompact. This follows from the [tube lemma](wikipedia://en/3614395).
- An easy example of a non-metacompact space (but a countably metacompact space) is the [Moore plane](wikipedia://en/5516188).
- In order for a [Tychonoff space](wikipedia://en/30554) *X* to be **compact** it is necessary and sufficient that *X* be **metacompact** and **[pseudocompact](https://en.wikipedia.org/wiki/Pseudocompact)** (see Watson).

:::

## Covering dimension {#Covering_dimension}

A topological space *X* is said to be of [covering dimension](https://en.wikipedia.org/wiki/Covering_dimension) *n* if every open cover of *X* has a point-finite open refinement such that no point of *X* is included in more than *n* + 1 sets in the refinement and if *n* is the minimum value for which this is true. If no such minimal *n* exists, the space is said to be of infinite covering dimension.
