# Binade

*Image: Binade.svg.* The binade of exponent −2 in the floating-point numbers with 3 bits of precision and minimum exponent −5

::: {#o1 .subject cue=lead name="Binade"}

In [software engineering](https://en.wikipedia.org/wiki/Software_engineering) and [numerical analysis](wikipedia://en/21506), a **binade** is a set of numbers in a binary [floating-point format](wikipedia://en/11376) that all have the same sign and exponent. In other words, a binade is the [interval](wikipedia://en/49172) $[2^e, 2^{e + 1})$ or $(-2^{e + 1}, -2^e]$ for some integer value $e$, that is, the set of real numbers or floating-point numbers $x$ of the same sign such that $2^e \leq |x| < 2^{e + 1}$.[^o2][^o3][^o4]

:::

Some authors use the convention of the closed interval $[2^e, 2^{e + 1}]$ instead of a half-open interval,[^o5] sometimes using both conventions in a single paper.[^o6] Some authors additionally treat each of various special quantities such as [NaN](https://en.wikipedia.org/wiki/NaN), infinities, and zeroes as its own binade,[^o7] or similarly for the exceptional interval $(0, 2^{\mathrm{emin}})$ of [subnormal numbers](wikipedia://en/141163).[^o8]
