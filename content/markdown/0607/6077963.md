# Biholomorphism

::: {#o1 .subject cue=lead name="Biholomorphism"}

*Image: Biholomorphism illustration.svg.* The complex [exponential function](wikipedia://en/9678) mapping biholomorphically a rectangle to a quarter-[annulus](wikipedia://en/356158).

In the [mathematical theory](wikipedia://en/18831) of functions of [one](wikipedia://en/5759) or [more complex variables](wikipedia://en/360243), and also in [complex algebraic geometry](https://en.wikipedia.org/wiki/Complex_algebraic_geometry), a **biholomorphism** or **biholomorphic function** is a [bijective](https://en.wikipedia.org/wiki/Bijective) [holomorphic function](wikipedia://en/14110) whose [inverse](wikipedia://en/14907) is also [holomorphic](wikipedia://en/14110). Note that the last condition is redundant: the inverse of a bijective holomorphic function is always holomorphic.

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Formally, a *biholomorphic function* is a function $\phi$ defined on an [open subset](https://en.wikipedia.org/wiki/Open_subset) *U* of the $n$-dimensional complex space **C**<sup>*n*</sup> with values in **C**<sup>*n*</sup> which is [holomorphic](wikipedia://en/14110) and [one-to-one](https://en.wikipedia.org/wiki/Bijective_function), such that its [image](wikipedia://en/579311) is an open set $V$ in **C**<sup>*n*</sup> and the inverse $\phi^{-1}:V\to U$ is also [holomorphic](wikipedia://en/14110). More generally, *U* and *V* can be [complex manifolds](wikipedia://en/509742). As in the case of functions of a single complex variable, a sufficient condition for a holomorphic map to be biholomorphic onto its image is that the map is injective, in which case the inverse is also holomorphic.[^o4]

If there exists a biholomorphism $\phi \colon U \to V$, we say that *U* and *V* are **biholomorphically equivalent** or that they are **biholomorphic**.

:::

::: {#o6 .statement kind=statement/theorem cue=named-heading name="Riemann mapping theorem and generalizations"}

## Riemann mapping theorem and generalizations {#Riemann_mapping_theorem_and_generalizations}

If $n=1,$ every [simply connected](https://en.wikipedia.org/wiki/Simply_connected) open set other than the whole complex plane is biholomorphic to the [unit disc](https://en.wikipedia.org/wiki/Unit_disc) (this is the [Riemann mapping theorem](wikipedia://en/26215)). The situation is very different in higher dimensions. For example, open [unit balls](https://en.wikipedia.org/wiki/Unit_ball) and open unit [polydiscs](wikipedia://en/1599249) are not biholomorphically equivalent for $n>1.$ In fact, there does not exist even a [proper](wikipedia://en/1190262) holomorphic function from one to the other.

:::

::: {#o8 .definition cue=heading name="Alternative definitions"}

## Alternative definitions {#Alternative_definitions}

In the case of maps *f* : *U* → **C** defined on an open subset *U* of the complex plane **C**, some authors[^o9] define a [conformal map](wikipedia://en/50627) to be an injective map with nonzero derivative i.e., *f*’(*z*)≠ 0 for every *z* in *U*. According to this definition, a map *f* : *U* → **C** is conformal if and only if *f*: *U* → *f*(*U*) is biholomorphic. Notice that per definition of biholomorphisms, nothing is assumed about their derivatives, so, this equivalence contains the claim that a homeomorphism that is complex differentiable must actually have nonzero derivative everywhere. Other authors[^o10] define a conformal map as one with nonzero derivative, but without requiring that the map be injective. According to this weaker definition, a conformal map need not be biholomorphic, even though it is locally biholomorphic, for example, by the inverse function theorem. For example, if *f*: *U* → *U* is defined by *f*(*z*) = *z*<sup>2</sup> with *U* = **C**–{0}, then *f* is conformal on *U*, since its derivative *f*’(*z*) = 2*z* ≠ 0, but it is not biholomorphic, since it is 2-1.

:::
