# Continuous function (ordinal theory)

::: {#o1 .subject cue=lead name="Continuous function"}

In [set theory](wikipedia://en/27553), a **continuous function** is a [sequence](wikipedia://en/27838) of [ordinals](wikipedia://en/26547932) such that the values assumed at [limit stages](wikipedia://en/373137) are the limits ([limit suprema and limit infima](https://en.wikipedia.org/wiki/Limit_superior_and_limit_inferior)) of all values at previous stages. More formally, let *γ* be an ordinal, and $s := \langle s_{\alpha}| \alpha < \gamma\rangle$ be a *γ*-sequence of ordinals. Then *s* is continuous if at every limit ordinal *β* \< *γ*,

:::

$$s_{\beta} = \limsup\{s_{\alpha}: \alpha < \beta\} = \inf \{ \sup\{s_{\alpha}: \delta \leq \alpha < \beta\} : \delta < \beta\}$$

and

$$s_{\beta} = \liminf\{s_{\alpha}: \alpha < \beta\} = \sup \{ \inf\{s_{\alpha}: \delta \leq \alpha < \beta\} : \delta < \beta\} \,.$$

Alternatively, if *s* is an [increasing function](https://en.wikipedia.org/wiki/Increasing_function) then *s* is continuous if *s*: *γ* → range(*s*) is a [continuous function](https://en.wikipedia.org/wiki/Continuous_%28topology%29) when the sets are each equipped with the [order topology](wikipedia://en/213650). These continuous functions are often used in [cofinalities](wikipedia://en/6693) and [cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_numbers).

A [normal function](wikipedia://en/404306) is a function that is both continuous and [strictly increasing](wikipedia://en/48260).
