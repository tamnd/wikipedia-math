# Radial function

::: {#o1 .subject cue=lead name="Radial function"}

In [mathematics](wikipedia://en/18831), a **radial function** is a [real-valued function](wikipedia://en/22284647) defined on a [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$ whose value at each point depends only on the distance between that point and the [origin](wikipedia://en/1313432). The distance is usually the [Euclidean distance](wikipedia://en/53932). For example, a radial function $\Phi$ in two dimensions has the form[^o2]

$$\Phi(x,y) = \varphi(r), \quad r = \sqrt{x^2+y^2}$$

where $\varphi$ is a function of a single non-negative real variable. Radial functions are contrasted with [spherical functions](wikipedia://en/203056), and any descent function (e.g., [continuous](wikipedia://en/6122) and [rapidly decreasing](https://en.wikipedia.org/wiki/Rapidly_decreasing)) on Euclidean space can be decomposed into a series consisting of radial and spherical parts: the [solid spherical harmonic](https://en.wikipedia.org/wiki/Solid_spherical_harmonic) expansion.

:::

A function is radial [if and only if](wikipedia://en/14922) it is invariant under all [rotations](wikipedia://en/39789) leaving the origin fixed. That is, $f$ is radial if and only if

$$f\circ \rho = f\,$$

for all $\rho \in \operatorname{SO}(n)$, the [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group) in $n$ dimensions. This characterization of radial functions makes it possible also to define radial [distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29). These are distributions $S$ on $\mathbb{R}^n$ such that

$$S[\varphi] = S[\varphi\circ\rho]$$

for every test function $\varphi$ and rotation $\rho$.

Given any (locally integrable) function $f$, its radial part is given by averaging over spheres centered at the origin. To wit,

$$\phi(x) = \frac{1}{\omega_{n-1}}\int_{S^{n-1}} f(rx')\,dx'$$

where $\omega_{n-1}$ is the surface area of the [(*n*−1)-sphere](https://en.wikipedia.org/wiki/N_sphere) $S^{n-1}$, and $r = \lvert x\rvert$, $x' = x/r$. It follows essentially by [Fubini's theorem](wikipedia://en/255245) that a locally integrable function has a well-defined radial part at [almost every](https://en.wikipedia.org/wiki/Almost_every) $r$.

The [Fourier transform](wikipedia://en/52247) of a radial function is also radial, and so radial functions play a vital role in [Fourier analysis](wikipedia://en/11659). Furthermore, the Fourier transform of a radial function typically has stronger decay behavior at infinity than non-radial functions: for radial functions bounded in a neighborhood of the origin, the Fourier transform decays faster than $R^{-(n-1)/2}$. The [Bessel functions](https://en.wikipedia.org/wiki/Bessel_functions) are a special class of radial function that arise naturally in Fourier analysis as the radial [eigenfunctions](wikipedia://en/228601) of the [Laplacian](https://en.wikipedia.org/wiki/Laplacian); as such they appear naturally as the radial portion of the Fourier transform.
