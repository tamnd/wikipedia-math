# Big-line-big-clique conjecture

::: {#o1 .subject cue=lead name="Big-line-big-clique conjecture"}

*Image: Convex\_grid\_subset.svg.* The blue points have big lines of up to ten points, but no big clique (the largest mutually-visible subsets of any convex grid subset have only four points). The yellow points form a big clique of ten points, but have no big line (the largest collinear subset of points in convex position has only two points). According to the big-line-big-clique conjecture, no point set can avoid both big lines and big cliques.

The **big-line-big-clique conjecture** is an unsolved problem in [discrete geometry](wikipedia://en/386468), stating that [finite sets](wikipedia://en/11742) of many points in the [Euclidean plane](wikipedia://en/15575410) either have many [collinear points](wikipedia://en/3189581), or they have many points that are [all mutually visible to each other](wikipedia://en/1448291) (no third point blocks any two of them from seeing each other).

:::

## Statement and history {#Statement_and_history}

More precisely, the big-line big-clique conjecture states that, for any positive integers $k$ and $\ell$ there should exist another number $n_{k,\ell}$, such that every set of $n_{k,\ell}$ points contains $\ell$ collinear points (a "big line"), $k$ mutually visible points (a "big clique"), or both.

The big-line-big-clique conjecture was posed by Jan Kára, Attila Pór, and [David R. Wood](wikipedia://en/65829777) in a 2005 publication. It has led to much additional research on point-to-point visibility in point sets.

## Partial results {#Partial_results}

Finite point sets in [general position](wikipedia://en/383736) (no three collinear) do always contain a big clique, so the conjecture is true for $\ell\le 3$. Additionally, finite point sets that have no five mutually visible points (such as the intersections of the [integer lattice](wikipedia://en/3333402) with convex sets) do always contain many collinear points, so the conjecture is true for $k\le 5$.

Generalizing the integer lattice example, projecting a $d$-dimensional system of lattice points of size $(\ell-1)\times(\ell-1)\times\cdots=(\ell-1)^d$ onto the plane, using a generic linear projection, produces a set of points with no $\ell$ collinear points and no $2^d+1$ mutually visible points. Therefore, when $n_{k,\ell}$ exists, it must be greater than $(\ell-1)^{\log_2(k-1)}$.

## Related problems {#Related_problems}

The visibilities among any system of points can be analyzed by using the [visibility graph](wikipedia://en/1448291) of the points, a graph that has the points as vertices and that connects two points by an edge whenever the [line segment](wikipedia://en/22634860) connecting them is disjoint from the other points. The "big cliques" of the big-line-big-clique conjecture are [cliques](wikipedia://en/524466) in the visibility graph. However, although a system of points that is entirely collinear can be characterized by having a [bipartite](wikipedia://en/244431) visibility graph, this characterization does not extend to subsets of points: a subset can have a bipartite [induced subgraph](wikipedia://en/1655188) of the visibility graph without being collinear.

According to the solution of the [happy ending problem](wikipedia://en/2576185), every subset of points with no three in line includes a large subset forming the vertices of a [convex polygon](wikipedia://en/660019). More generally, it can be proven using the same methods that every set of sufficiently many points either includes $\ell$ collinear points or $k$ points in [convex position](wikipedia://en/40079283). However, some of these pairs of convex points could be blocked from visibility by points within the convex polygon they form.

Another related question asks whether points in general position (or with no lines of more than some given number of points) contain the vertices of an *empty convex polygon* or *hole*. This is a polygon whose vertices belong to the point set, but that has no other points in the intersection of the point set with its convex hull. If a hole of a given size exists, its vertices all necessarily see each other. All sufficiently large sets of points in general position contain five vertices forming an empty [pentagon](wikipedia://en/20741014) or [hexagon](wikipedia://en/59733), but there exist arbitrarily large sets in general position with no empty [heptagons](wikipedia://en/365349).

A strengthening of the big line big clique conjecture asks for the big clique to be a "visible island", a set of points that are mutually visible and that are formed from the given larger point set by intersecting it with a convex set. However, this strengthened version is false: if a point set in general position has no empty heptagon, then replacing each of its points by a closely spaced triple of collinear points produces a point set with no four in a line and with no visible islands of 13 or more points.

There is no possibility of an [infinitary](https://en.wikipedia.org/wiki/Infinitary) version of the same conjecture: Pór and Wood found examples of countable sets of points with no four points on a line and with no triangle of mutually visible points.
