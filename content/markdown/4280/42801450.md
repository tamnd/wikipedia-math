# Adversarial queueing network

::: {#o1 .subject cue=lead name="Adversarial queueing network"}

In [queueing theory](wikipedia://en/50578), an **adversarial queueing network** is a model where the traffic to the network is supplied by an [opponent](https://en.wikipedia.org/wiki/Adversary_model) rather than as the result of a [stochastic process](wikipedia://en/47895).

:::

## History {#History}

The model was first introduced in 1996.[^o3] It has seen use in describing the impact of [packet injections](https://en.wikipedia.org/wiki/Packet_injection) on the performance of [communication networks](https://en.wikipedia.org/wiki/Communication_networks).[^o4] The stability of an adversarial queueing network can be determined by considering a [fluid limit](wikipedia://en/40878507).[^o5]
