# Pohlig–Hellman algorithm

::: {#o1 .subject cue=lead name="Pohlig–Hellman algorithm"}

*Image: Pohlig-Hellman-Diagram.svg.* Steps of the Pohlig–Hellman algorithm.

In [group theory](wikipedia://en/41890), the **Pohlig–Hellman algorithm**, sometimes credited as the **Silver–Pohlig–Hellman algorithm**,[^o2] is a special-purpose [algorithm](wikipedia://en/775) for computing [discrete logarithms](wikipedia://en/181334) in a [finite abelian group](https://en.wikipedia.org/wiki/Finite_abelian_group) whose order is a [smooth integer](https://en.wikipedia.org/wiki/Smooth_integer).

:::

The algorithm was introduced by Roland Silver, but first published by [Stephen Pohlig](https://en.wikipedia.org/wiki/Stephen_Pohlig) and [Martin Hellman](wikipedia://en/422387), who credit Silver with its earlier independent but unpublished discovery. Pohlig and Hellman also list Richard Schroeppel and H. Block as having found the same algorithm, later than Silver, but again without publishing it.[^n1]

## Groups of prime-power order {#Groups_of_prime-power_order}

As an important special case, which is used as a subroutine in the general algorithm (see below), the Pohlig–Hellman algorithm applies to [groups](wikipedia://en/19447) whose order is a [prime power](wikipedia://en/1630483). The basic idea of this algorithm is to iteratively compute the $p$-adic digits of the logarithm by repeatedly "shifting out" all but one unknown digit in the exponent, and computing that digit by elementary methods.

(Note that for readability, the algorithm is stated for cyclic groups — in general, $G$ must be replaced by the subgroup $\langle g\rangle$ generated by $g$, which is always cyclic.)

**Input.** A cyclic group $G$ of order $n=p^e$ with generator $g$ and an element $h\in G$.

**Output.** The unique integer $x\in\{0,\dots,n-1\}$ such that $g^x=h$.

1. Initialize $x_0:=0.$
1. Compute $\gamma:=g^{p^{e-1}}$. By [Lagrange's theorem](wikipedia://en/31150), this element has order $p$.
1. For all $k\in\{0,\dots,e-1\}$, do:
   1. Compute $h_k:=(g^{-x_k}h)^{p^{e-1-k}}$. By construction, the order of this element must divide $p$, hence $h_k\in\langle\gamma\rangle$.
   1. Using the [baby-step giant-step algorithm](wikipedia://en/563928), compute $d_k\in\{0,\dots,p-1\}$ such that $\gamma^{d_k}=h_k$. It takes time [$O(\sqrt p)$](wikipedia://en/44578).
   1. Set $x_{k+1}:=x_k+p^kd_k$.
1. Return $x_e$.

The algorithm computes discrete logarithms in time complexity [$O(e\sqrt p)$](wikipedia://en/44578), far better than the [baby-step giant-step algorithm's](wikipedia://en/563928) [$O(\sqrt{p^e})$](wikipedia://en/44578) when $e$ is large.

## The general algorithm {#The_general_algorithm}

In this section, we present the general case of the Pohlig–Hellman algorithm. The core ingredients are the algorithm from the previous section (to compute a logarithm modulo each prime power in the group order) and the [Chinese remainder theorem](wikipedia://en/7713) (to combine these to a logarithm in the full group).

(Again, we assume the group to be cyclic, with the understanding that a non-cyclic group must be replaced by the subgroup generated by the logarithm's base element.)

**Input.** A cyclic group $G$ of order $n$ with generator $g$, an element $h\in G$, and a prime factorization $n=\prod_{i=1}^rp_i^{e_i}$.

**Output.** The unique integer $x\in\{0,\dots,n-1\}$ such that $g^x=h$.

1. For each $i\in\{1,\dots,r\}$, do:
   1. Compute $g_i:=g^{n/p_i^{e_i}}$. By [Lagrange's theorem](wikipedia://en/31150), this element has order $p_i^{e_i}$.
   1. Compute $h_i:=h^{n/p_i^{e_i}}$. By construction, $h_i\in\langle g_i\rangle$.
   1. Using the algorithm above in the group $\langle g_i\rangle$, compute $x_i\in\{0,\dots,p_i^{e_i}-1\}$ such that $g_i^{x_i}=h_i$.
1. Solve the simultaneous congruence $$x\equiv x_i\pmod{p_i^{e_i}} \quad\forall i\in\{1,\dots,r\} \text{.}$$ The [Chinese remainder theorem](wikipedia://en/7713) guarantees there exists a unique solution $x\in\{0,\dots,n-1\}$.
1. Return $x$.

The correctness of this algorithm can be verified via the [classification of finite abelian groups](wikipedia://en/2974#Classification): raising $g$ and $h$ to the power of $n/p_i^{e_i}$ can be understood as the projection to the factor group of order $p_i^{e_i}$.

## Complexity {#Complexity}

The worst-case input for the Pohlig–Hellman algorithm is a group of prime order: in that case, it degrades to the [baby-step giant-step algorithm](wikipedia://en/563928), hence the worst-case time complexity is $\mathcal O(\sqrt n)$. However, it is much more efficient if the order is smooth: Specifically, if $\prod_i p_i^{e_i}$ is the prime factorization of $n$, then the algorithm's complexity is

$$\mathcal O\left(\sum_i {e_i(\log n+\sqrt {p_i})}\right)$$

group operations.[^o7]
