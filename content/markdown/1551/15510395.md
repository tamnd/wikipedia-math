# Chaplygin problem

::: {#o1 .subject cue=lead name="Chaplygin problem"}

In [mathematics](wikipedia://en/18831), particularly in the fields of [nonlinear dynamics](https://en.wikipedia.org/wiki/Nonlinear_dynamics) and the [calculus of variations](wikipedia://en/171882), the **Chaplygin problem** is an isoperimetric problem with a [differential](wikipedia://en/7921) [constraint](wikipedia://en/7418540). Specifically, the problem is to determine what flight path an airplane in a constant wind field should take in order to encircle the maximum possible area in a given amount of time. The airplane is assumed to be constrained to move in a plane, moving at a constant [airspeed](https://en.wikipedia.org/wiki/Airspeed) *v*, for time *T*, and the wind is assumed to move in a constant direction with speed *w*.

:::

The solution of the problem is that the airplane should travel in an [ellipse](wikipedia://en/9277) whose major axis is perpendicular to *w*, with eccentricity *w*/*v*.
