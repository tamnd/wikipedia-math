# Certified dominating set

::: {#o1 .subject cue=lead name="Certified dominating set"}

*Image: Certified dominating set.svg.* A graph with a minimum **certified dominating set** colored. Red vertices are **illuminated**, while blue vertices are **shadowed**.

In [graph theory](wikipedia://en/12401), a **certified dominating set** of a [graph](wikipedia://en/325806) is a type of [dominating set](wikipedia://en/1747972) in which every vertex in the set has either zero or at least two [neighbours](https://en.wikipedia.org/wiki/Neighborhood_%28graph_theory%29) outside the set. The concept was introduced by Dettlaff, Lemańska, Topp, Ziemann, and Żyliński in 2018.[^o2]

:::

The concept models a scenario involving officials and civilians in a social network. Given a set $D$ of officials and a set $W$ of civilians, each civilian must be served by some official, and whenever an official serves a civilian, there must be at least one other civilian who can observe the official, acting as a witness to prevent potential abuse. The certified domination number represents the minimum number of officials needed to guarantee such a service.[^o2]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G = (V, E)$ be a graph. A [dominating set](wikipedia://en/1747972) $D \subseteq V$ is called a **certified dominating set** if for every vertex $v \in D$, the number of neighbours of $v$ in $V \setminus D$ is either zero or at least two. Equivalently, no vertex in $D$ has exactly one neighbour outside $D$.[^o2]

The **certified domination number** of $G$, denoted $\gamma_{\text{cer}}(G)$, is the minimum cardinality of a certified dominating set in $G$. A certified dominating set of minimum cardinality is called a $\gamma_{\text{cer}}$**\-set**.[^o2][^o5]

The vertices of $D$ can be classified based on their neighbours in $V \setminus D$. A vertex in $D$ with no neighbours in $V \setminus D$ is called **shadowed**, a vertex in $D$ with exactly one neighbour in $V \setminus D$ is called **half-shadowed**, and a vertex in $D$ with at least two neighbours in $V \setminus D$ is called **illuminated**. A dominating set is certified if and only if it contains no half-shadowed vertices.[^o2]

:::

## Properties and examples {#Properties_and_examples}

For any graph $G$ of order $n$:[^o2]

- The vertex set $V$ is always a certified dominating set, so $1 \leq \gamma_{\text{cer}}(G) \leq n$.
- $\gamma_{\text{cer}}(G) \neq n - 1$ for any graph.
- Every [support vertex](wikipedia://en/82228818) of $G$ belongs to every certified dominating set.
- $\gamma_{\text{cer}}(G) = 1$ if and only if $G$ has order at least three and contains a [universal vertex](wikipedia://en/51352780).
- If $G_1, G_2, \ldots, G_k$ are the [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) of $G$, then $\gamma_{\text{cer}}(G) = \sum_{i=1}^{k} \gamma_{\text{cer}}(G_i)$.

The certified domination number is known exactly for several families of graphs:[^o2]

- For the [path](wikipedia://en/4587190) $P_n$:
  - $\gamma_{\text{cer}}(P_n) = 1$ if $n = 1$ or $n = 3$
  - $\gamma_{\text{cer}}(P_n) = 2$ if $n = 2$
  - $\gamma_{\text{cer}}(P_n) = 4$ if $n = 4$
  - $\gamma_{\text{cer}}(P_n) = \lceil n/3 \rceil$ otherwise
- For the [cycle](wikipedia://en/878962) $C_n$ with $n \geq 3$:
  - $$\gamma_{\text{cer}}(C_n) = \lceil n/3 \rceil$$
- For the [complete graph](wikipedia://en/85816) $K_n$:
  - $\gamma_{\text{cer}}(K_n) = 1$ if $n = 1$ or $n \geq 3$
  - $\gamma_{\text{cer}}(K_n) = 2$ if $n = 2$
- For the [complete bipartite graph](wikipedia://en/525320) $K_{m,n}$ with $1 \leq m \leq n$:
  - $\gamma_{\text{cer}}(K_{m,n}) = 1$ if $m = 1$ and $n > 1$
  - $\gamma_{\text{cer}}(K_{m,n}) = 2$ otherwise
- For the [wheel graph](wikipedia://en/1655876) $W_n$:
  - $$\gamma_{\text{cer}}(W_n) = 1$$

### Bounds and relation to domination number {#Bounds_and_relation_to_domination_number}

Since every certified dominating set is a dominating set, $\gamma(G) \leq \gamma_{\text{cer}}(G)$ for all graphs $G$. For a connected graph $G$, the certified domination number satisfies:[^o2]

$$\gamma_{\text{cer}}(G) \leq \gamma(G) + |S_1(G)|$$

where $\gamma(G)$ is the [domination number](https://en.wikipedia.org/wiki/Domination_number) and $S_1(G)$ is the set of weak support vertices (support vertices adjacent to exactly one [leaf](https://en.wikipedia.org/wiki/Leaf_%28graph_theory%29)). This bound is sharp, as equality holds for the [corona](wikipedia://en/79527671) of any graph without isolated vertices. As a consequence, $\gamma_{\text{cer}}(G) \leq 2\gamma(G)$. Additionally, if the strong support vertices of $G$ are adjacent to $k$ leaves in total, then $\gamma_{\text{cer}}(G) \leq n - k$.[^o2]

Equality $\gamma_{\text{cer}}(G) = \gamma(G)$ holds in several cases:[^o2][^o5]

- If $G$ has no weak support vertex (in particular, if $\delta(G) \geq 2$), then $\gamma_{\text{cer}}(G) = \gamma(G)$.
- If $G$ has a unique minimum dominating set, then $\gamma_{\text{cer}}(G) = \gamma(G)$.
- If $\gamma(G - v) \geq \gamma(G)$ for every vertex $v$ belonging to at least one $\gamma$-set of $G$, then $\gamma_{\text{cer}}(G) = \gamma(G)$.
- If $G$ is a connected [$P_4$-free graph](https://en.wikipedia.org/wiki/P4-free_graph) and $G \neq K_2$, then $\gamma_{\text{cer}}(G) = \gamma(G)$.

More generally, for a connected graph $G$ of order at least three, $\gamma_{\text{cer}}(G) = \gamma(G)$ if and only if $G$ has a $\gamma$-set $D$ such that every vertex in $D$ has at least two neighbours in $V \setminus D$.[^o5]

A graph $G$ is called **$\gamma\gamma_{\text{cer}}$-perfect** if $\gamma(H) = \gamma_{\text{cer}}(H)$ for every induced connected subgraph $H \neq K_2$ of $G$. A graph is $\gamma\gamma_{\text{cer}}$-perfect if and only if it is $P_4$-free.[^o5]

### Graphs with large certified domination number {#Graphs_with_large_certified_domination_number}

*Image: Certified dominating all shadow.svg.* The minimum certified dominating set for the graph shown consists of the entire vertex set

A graph $G$ of order $n$ satisfies $\gamma_{\text{cer}}(G) = n$ if and only if $G$ is the [complement](https://en.wikipedia.org/wiki/Complement_%28graph_theory%29) of a [complete graph](wikipedia://en/85816), the [corona](wikipedia://en/79527671) of a graph, or the disjoint union of both.[^o2]

A **diadem graph** is a graph obtained from the corona $H \circ K_1$ by adding a new vertex and joining it to one support vertex of $H \circ K_1$. A graph $G$ of order $n \geq 3$ satisfies $\gamma_{\text{cer}}(G) = n - 2$ if and only if $G$ is $C_3$, $C_4$, or a diadem graph, possibly combined with the corona of a graph and isolated vertices.[^o2]

### Effects of graph modifications {#Effects_of_graph_modifications}

Adding an edge to a [connected graph](https://en.wikipedia.org/wiki/Connected_graph) cannot increase the certified domination number: $\gamma_{\text{cer}}(G + e) \leq \gamma_{\text{cer}}(G)$. However, both deleting an edge from a graph and adding an edge to a disconnected graph may arbitrarily increase the certified domination number.[^o2]

Adding a leaf vertex may arbitrarily increase the certified domination number, but adding a non-leaf vertex $v$ to a graph $G$ satisfies $\gamma_{\text{cer}}(G + v) \leq \gamma_{\text{cer}}(G) + 1$.[^o2]

### Nordhaus–Gaddum type inequalities {#Nordhaus–Gaddum_type_inequalities}

For a graph $G$ of order $n \geq 5$ with [complement](https://en.wikipedia.org/wiki/Complement_%28graph_theory%29) $\overline{G}$:[^o2]

$$\gamma_{\text{cer}}(G) + \gamma_{\text{cer}}(\overline{G}) \leq n + 2$$

$$\gamma_{\text{cer}}(G) \cdot \gamma_{\text{cer}}(\overline{G}) \leq 2n$$

Equality holds in both inequalities simultaneously if and only if $G$ or $\overline{G}$ is the corona of some graph.[^o2]

If $\min\{\delta(G), \delta(\overline{G})\} \geq 2$, stronger bounds hold:[^o2]

$$\gamma_{\text{cer}}(G) + \gamma_{\text{cer}}(\overline{G}) \leq \left\lfloor \frac{n}{2} \right\rfloor + 2$$

$$\gamma_{\text{cer}}(G) \cdot \gamma_{\text{cer}}(\overline{G}) \leq n$$

## Computational complexity {#Computational_complexity}

The problem of determining the certified domination number is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) even for [bipartite](wikipedia://en/244431) [planar](wikipedia://en/24314) subcubic graphs with no leaves. This follows from the equality $\gamma_{\text{cer}}(G) = \gamma(G)$ for graphs with no weak support vertices and the known NP-hardness of the domination problem in such graph classes.[^o2]

Determining whether $\gamma(G) \neq \gamma_{\text{cer}}(G)$ for a given graph $G$ is also NP-hard, even when $G$ has only one weak support vertex. This is shown by a reduction from [3SAT](wikipedia://en/4715#3-satisfiability).[^o12]
