# P-constrained group

::: {#o1 .subject cue=lead name="P-constrained group"}

In [mathematics](wikipedia://en/18831), a **p-constrained group** is a [finite group](wikipedia://en/323707) resembling the centralizer of an element of [prime](wikipedia://en/23666) order *p* in a [group of Lie type](wikipedia://en/1691490) over a [finite field](wikipedia://en/11615) of [characteristic](wikipedia://en/1066621) *p*. They were introduced by (txt, p.169) in order to extend some of Thompson's results about odd groups to groups with [dihedral](wikipedia://en/100267) Sylow 2-subgroups.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

If a group has trivial *p* [core](wikipedia://en/893516) O<sub>*p*</sub>(*G*), then it is defined to be *p*-constrained if the *p*-core O<sub>*p*</sub>(*G*) contains its centralizer, or in other words if its [generalized Fitting subgroup](https://en.wikipedia.org/wiki/Generalized_Fitting_subgroup) is a *p*-group. More generally, if O<sub>*p*</sub>(*G*) is non-trivial, then *G* is called *p*-constrained if *G*/O<sub>*p*</sub>(*G*) is *p*-constrained.

All [*p*-solvable groups](https://en.wikipedia.org/wiki/P-solvable_group) are *p*-constrained.

:::
