# Genius (mathematics software)

::: {#o1 .subject cue=lead name="Genius"}

**Genius** (also known as the Genius Math Tool) is a [free](https://en.wikipedia.org/wiki/Free_software) [open-source](https://en.wikipedia.org/wiki/Open-source_software) [numerical computing](wikipedia://en/21506) environment and [programming language](wikipedia://en/23015),[^o3] similar in some aspects to [MATLAB](wikipedia://en/20412), [GNU Octave](wikipedia://en/48707), [Mathematica](https://en.wikipedia.org/wiki/Mathematica) and [Maple](https://en.wikipedia.org/wiki/Maple_%28software%29). Genius is aimed at mathematical experimentation rather than computationally intensive tasks. It is also very useful as just a calculator. The programming language is called GEL and aims to have a mathematically friendly syntax. The software comes with a [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface) and a [GUI](https://en.wikipedia.org/wiki/GUI), which uses the [GTK+](https://en.wikipedia.org/wiki/GTK+) libraries. The graphical version supports both 2D and 3D plotting. The graphical version includes a set of tutorials originally aimed at in class demonstrations.

:::

## History {#History}

Genius was the original calculator for the [GNOME](https://en.wikipedia.org/wiki/GNOME) project started in 1997, but was split into a separate project soon after the 0.13 release of GNOME in 1998. Because of this ancestry, it was also known as Genius Calculator or GNOME Genius. There was an attempt to merge Genius and the [Dr. Geo](https://en.wikipedia.org/wiki/Dr._Geo) [interactive geometry software](https://en.wikipedia.org/wiki/Interactive_geometry_software),[^o5] but this merge never materialized.[^o6] Version 1.0 was released in 2007 almost 10 years after the initial release.

## Example GEL source code {#Example_GEL_source_code}

Here is a sample definition of a function calculating the factorial recursively

```
function f(x) = (
  if x <= 1 then
    1
  else
    (f(x-1)*x)
)
```

GEL contains primitives for writing the product iteratively and hence we can get the following iterative version

```
function f(x) = prod k=1 to x do k
```
