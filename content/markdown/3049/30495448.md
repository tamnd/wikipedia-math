# Cyclic number (group theory)

::: {#o1 .subject cue=lead name="Cyclic number"}

A **cyclic number**[^o2][^o3] is a [natural number](wikipedia://en/21474) *n* such that *n* and *φ*(*n*) are [coprime](https://en.wikipedia.org/wiki/Coprime). Here *φ* is [Euler's totient function](wikipedia://en/53452). An equivalent definition is that a number *n* is cyclic [if and only if](wikipedia://en/14922) any [group](wikipedia://en/19447) of [order](wikipedia://en/493527) *n* is [cyclic](wikipedia://en/52327).[^o4]

:::

Any [prime number](wikipedia://en/23666) is clearly cyclic. All cyclic numbers are [square-free](wikipedia://en/29525).[^o5] Let *n* = *p*<sub>1</sub> *p*<sub>2</sub> ... *p*<sub>*k*</sub>, where the *p*<sub>*i*</sub> are distinct primes, then *φ*(*n*) = (*p*<sub>1</sub> − 1)(*p*<sub>2</sub> − 1)...(*p*<sub>*k*</sub> − 1). If no *p*<sub>*i*</sub> divides any (*p*<sub>*j*</sub> − 1), then *n* and *φ*(*n*) have no common (prime) divisor, and *n* is cyclic.

The first non-prime cyclic numbers are 1, 15, 33, 35, 51, 65, 69, 77, 85, 87, 91, 95, 115, 119, 123, 133, 141, 143, 145, 159, 161, 177, 185, 187, 209, 213, 215, 217, 221, 235, 247, 249, 255, 259, 265, 267, 287, 295, 299, 303, 319, 321, 323, 329, 335, 339, 341, 345, 365, 371, 377, 391, 393, 395, 403, ...
