# Grzegorczyk hierarchy

::: {#o1 .subject cue=lead name="Grzegorczyk hierarchy"}

The **Grzegorczyk hierarchy** (, ), named after the Polish logician [Andrzej Grzegorczyk](wikipedia://en/24824350), is a hierarchy of functions used in [computability theory](wikipedia://en/155414).[^n1] Every [function](wikipedia://en/185427) in the Grzegorczyk hierarchy is a [primitive recursive function](wikipedia://en/24829), and every primitive recursive function appears in the hierarchy at some level. The hierarchy deals with the rate at which the values of the functions grow; intuitively, functions in lower levels of the hierarchy grow slower than functions in the higher levels.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

First we introduce an infinite set of functions, denoted *E<sub>i</sub>* for some [natural number](wikipedia://en/21474) *i*. We define

$$\begin{array}{lcl} E_0(x,y) & = & x + y \\ E_1(x) & = & x^2 + 2 \\ E_{n+2}(0) & = & 2 \\ E_{n+2}(x+1) & = & E_{n+1}(E_{n+2}(x)) \\ \end{array}$$

$E_0$ is the addition function, and $E_1$ is a unary function which squares its argument and adds two. Then, for each *n* greater than 1, $E_n(x)=E^{x}_{n-1}(2)$, i.e. the *x*-th [iterate](wikipedia://en/1448702) of $E_{n-1}$ evaluated at 2.

From these functions we define the Grzegorczyk hierarchy. $\mathcal{E}^n$, the *n*-th set in the hierarchy, contains the following functions:

1. *E<sub>k</sub>* for *k* \< *n*
1. the zero function (*Z*(*x*) = 0);
1. the [successor function](wikipedia://en/325637) (*S*(*x*) = *x* + 1);
1. the [projection functions](https://en.wikipedia.org/wiki/Projection_function) ($p_i^m(t_1, t_2, \dots, t_m) = t_i$);
1. the (generalized) [compositions of functions](wikipedia://en/195947) in the set (if *h*, *g*<sub>1</sub>, *g*<sub>2</sub>, ... and *g*<sub>*m*</sub> are in $\mathcal{E}^n$, then $f(\bar{u}) = h(g_1(\bar{u}), g_2(\bar{u}), \dots, g_m(\bar{u}))$ is as well);[^o5] and
1. the results of limited (primitive) recursion applied to functions in the set, (if *g*, *h* and *j* are in $\mathcal{E}^n$ and $f(t, \bar{u}) \leq j(t, \bar{u})$ for all *t* and $\bar{u}$, and further $f(0, \bar{u}) = g(\bar{u})$ and $f(t+1, \bar{u}) = h(t,\bar{u},f(t,\bar{u}))$, then *f* is in $\mathcal{E}^n$ as well).[^o5]

In other words, $\mathcal{E}^n$ is the [closure](wikipedia://en/293802) of set $B_n = \{Z, S, (p_i^m)_{i \le m}, E_k : k < n\}$ with respect to function composition and limited recursion (as defined above).

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

These sets clearly form the hierarchy

$$\mathcal{E}^0 \subseteq \mathcal{E}^1 \subseteq \mathcal{E}^2 \subseteq \cdots$$

because they are closures over the $B_n$'s and $B_0 \subseteq B_1 \subseteq B_2 \subseteq \cdots$.

They are strict subsets.[^n2][^n3] In other words

$$\mathcal{E}^0 \subsetneq \mathcal{E}^1 \subsetneq \mathcal{E}^2 \subsetneq \cdots$$

because the [hyperoperation](wikipedia://en/33731923) $H_n$ is in $\mathcal{E}^n$ but not in $\mathcal{E}^{n-1}$.

- $\mathcal{E}^0$ includes functions such as $x+1, \; x+2, \; \ldots$

Every unary function $f(x)$ in $\mathcal{E}^0$ is *upper bounded* by some $x+n$.

However, $\mathcal{E}^0$ also includes more complicated functions like $x \mathbin{\dot{-}} 1$,[^o10] $x \mathbin{\dot{-}} y$,[^o10] $x \bmod y, \; \ldots$

- $\mathcal{E}^1$ provides all addition functions, such as $x+y, \; 4x, \; \ldots$
- $\mathcal{E}^2$ provides all multiplication functions, such as $xy, \; x^4, \; \ldots$
- $\mathcal{E}^3$ provides all exponentiation functions, such as $x^y, \; 2^{2^{2^x}}$, and is exactly the [elementary recursive functions](https://en.wikipedia.org/wiki/ELEMENTARY).
- $\mathcal{E}^4$ provides all [tetration](wikipedia://en/482379) functions, and so on.

Notably, both the function $U$ and the characteristic function of the predicate $T$ from the [Kleene normal form theorem](https://en.wikipedia.org/wiki/Kleene_normal_form_theorem) are definable in a way such that they lie at level $\mathcal{E}^0$ of the Grzegorczyk hierarchy. This implies in particular that every [computably enumerable](https://en.wikipedia.org/wiki/Computably_enumerable) set is enumerable by some $\mathcal{E}^0$-function.

:::

## Relation to primitive recursive functions {#Relation_to_primitive_recursive_functions}

The definition of $\mathcal{E}^n$ is the same as that of the [primitive recursive functions](wikipedia://en/24829), PR, except that recursion is *limited* ($f(t, \bar{u}) \leq j(t, \bar{u})$ for some *j* in $\mathcal{E}^n$) and the functions $(E_k)_{k<n}$ are explicitly included in $\mathcal{E}^n$. Thus the Grzegorczyk hierarchy can be seen as a way to *limit* the power of primitive recursion to different levels.

It is clear from this fact that all functions in any level of the Grzegorczyk hierarchy are primitive recursive functions (i.e. $\mathcal{E}^n \subseteq \mathsf{PR}$) and thus:

$$\bigcup_n{\mathcal{E}^n} \subseteq \mathsf{PR}$$

It can also be shown that all primitive recursive functions are in some level of the hierarchy,[^n2][^n3] thus

$$\bigcup_n{\mathcal{E}^n} = \mathsf{PR}$$

and the sets $\mathcal{E}^0, \mathcal{E}^1 - \mathcal{E}^0, \mathcal{E}^2 - \mathcal{E}^1, \dots, \mathcal{E}^n - \mathcal{E}^{n-1}, \dots$ [partition](wikipedia://en/340240) the set of primitive recursive functions, PR.

[Meyer](https://en.wikipedia.org/wiki/Albert_R._Meyer) and [Ritchie](https://en.wikipedia.org/wiki/Dennis_Ritchie) introduced another hierarchy subdividing the primitive recursive functions, based on the nesting depth of loops needed to write a [LOOP](https://en.wikipedia.org/wiki/LOOP_%28programming_language%29) program that computes the function. For a natural number $i$, let $\mathcal{L}_i$ denote the set of functions computable by a LOOP program with `LOOP` and `END` commands nested no deeper than $i$ levels.[^n4] Fachini and Maggiolo-Schettini showed that $\mathcal{L}_i$ coincides with $\mathcal{E}_{i+1}$ for all integers $i>1$.[^n5]

## Extensions {#Extensions}

The Grzegorczyk hierarchy can be extended to [transfinite](wikipedia://en/189734) [ordinals](wikipedia://en/26547932). Such extensions define a [fast-growing hierarchy](wikipedia://en/24947285). To do this, the generating functions $E_\alpha$ must be [recursively defined](wikipedia://en/30461#Transfinite_recursion) for [limit ordinals](wikipedia://en/373137) (note they have already been recursively defined for [successor ordinals](wikipedia://en/375256) by the relation $E_{\alpha+1}(n) = E_\alpha^n(2)$). If there is a standard way of defining a *[fundamental sequence](wikipedia://en/73752551)* $\lambda_m$, whose limit ordinal is $\lambda$, then the generating functions can be defined $E_\lambda(n) = E_{\lambda_n}(n)$. However, this definition depends upon a standard way of defining the fundamental sequence. (Rose 1984) suggests a standard way for all ordinals *α* \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29).

The original extension was due to [Martin Löb](wikipedia://en/7268088) and [Stan S. Wainer](https://en.wikipedia.org/wiki/Stan_S._Wainer) and is sometimes called the [Löb–Wainer hierarchy](https://en.wikipedia.org/wiki/Löb–Wainer_hierarchy).[^n6]
