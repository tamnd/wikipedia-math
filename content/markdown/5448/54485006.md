# Formal criteria for adjoint functors

::: {#o1 .subject cue=lead name="Formal criteria for adjoint functors"}

In [category theory](wikipedia://en/5869), a branch of mathematics, the **formal criteria for adjoint functors** are criteria for the existence of a left or right [adjoint](wikipedia://en/53991) of a given [functor](wikipedia://en/10987).

:::

One criterion is the following, which first appeared in [Peter J. Freyd](wikipedia://en/4593361)'s 1964 book *Abelian Categories,[^o2] an Introduction to the Theory of Functors*:

::: {#o4 .statement kind=statement/theorem cue=math-theorem name="Freyd's adjoint functor theorem"}

**Freyd's adjoint functor theorem[^o3].**

Let $G: \mathcal{B} \to \mathcal{A}$ be a functor between categories such that $\mathcal{B}$ is complete. Then the following are equivalent (for simplicity ignoring the set-theoretic issues):

*G* has a left adjoint.

$G$ preserves all limits, and the following *solution set condition* is satisfied: for each object *x* in $\mathcal{A}$, there exist a set *I* and an *I*-indexed family of morphisms $f_i : x \to G y_i$ such that each morphism $x \to Gy$ is of the form $G(y_i \to y) \circ f_i$ for some morphism $y_i \to y$.

:::

Another criterion is:

::: {#o5 .statement cue=math-theorem name="Kan criterion for the existence of a left adjoint"}

**Kan criterion for the existence of a left adjoint.**

Let $G: \mathcal{B} \to \mathcal{A}$ be a functor between categories. Then the following are equivalent.

*G* has a left adjoint.

*G* preserves [limits](wikipedia://en/39248) and, for each object *x* in $\mathcal{A}$, the limit $\lim ({(x \downarrow G) \to \mathcal{B}})$ exists in $\mathcal{B}$.[^o6]

The right [Kan extension](wikipedia://en/2502518#Adjoints_as_Kan_extensions) $G_! 1_{\mathcal{B}}$ of the identity functor $1_{\mathcal{B}}$ along *G* exists and is preserved by *G*.[^o7][^o8][^o9] Moreover, when this is the case then a left adjoint of *G* can be computed using the right [Kan extension](wikipedia://en/2502518).[^o6]

:::
