# Density theorem (category theory)

::: {#o1 .subject cue=lead name="Density theorem"}

In [category theory](wikipedia://en/5869), a branch of mathematics, the **density theorem** states that every [presheaf of sets](https://en.wikipedia.org/wiki/Presheaf_of_sets) is a [colimit](wikipedia://en/54494563) of [representable presheaves](wikipedia://en/844461) in a canonical way.[^o2]

:::

For example, by definition, a [simplicial set](wikipedia://en/1027784) is a presheaf on the [simplex category](wikipedia://en/1028841) Δ and a representable simplicial set is exactly of the form $\Delta^n = \operatorname{Hom}(-, [n])$ (called the standard *n*-simplex) so the theorem says: for each simplicial set *X*,

$$X \simeq \varinjlim \Delta^n$$

where the colim runs over an index category determined by *X*.

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let *F* be a presheaf on a category *C*; i.e., an object of the [functor category](wikipedia://en/407039) $\widehat{C} = \mathbf{Fct}(C^\text{op}, \mathbf{Set})$. For an index category over which a colimit will run, let *I* be the [category of elements](wikipedia://en/4877413) of *F*: it is the category where

1. an object is a pair $(U, x)$ consisting of an object *U* in *C* and an element $x \in F(U)$,
1. a morphism $(U, x) \to (V, y)$ consists of a morphism $u: U \to V$ in *C* such that $(Fu)(y) = x.$

It comes with the [forgetful functor](wikipedia://en/844783) $p: I \to C$.

Then *F* is the colimit of the [diagram](wikipedia://en/7651625) (i.e., a functor)

$$I \overset{p}\to C \to \widehat{C}$$

where the second arrow is the [Yoneda embedding](https://en.wikipedia.org/wiki/Yoneda_embedding): $U \mapsto h_U = \operatorname{Hom}(-, U)$.

:::

::: {#o6 .proof cue=heading name="Proof"}

## Proof {#Proof}

Let *f* denote the above diagram. To show the colimit of *f* is *F*, we need to show: for every presheaf *G* on *C*, there is a natural [bijection](wikipedia://en/3942):

$$\operatorname{Hom}_{\widehat{C}} (F, G) \simeq \operatorname{Hom} (f, \Delta_G)$$

where $\Delta_G$ is the [constant functor](https://en.wikipedia.org/wiki/Constant_functor) with value *G* and Hom on the right means the set of [natural transformations](wikipedia://en/45022). This is because the [universal property](wikipedia://en/32245) of a colimit amounts to saying $\varinjlim -$ is the [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint) to the [diagonal functor](wikipedia://en/4606683) $\Delta_{-}.$

For this end, let $\alpha: f \to \Delta_G$ be a natural transformation. It is a family of morphisms indexed by the objects in *I*:

$$\alpha_{U, x}: f(U, x) = h_U \to \Delta_G(U, x) = G$$

that satisfies the property: for each morphism $(U, x) \to (V, y), u: U \to V$ in *I*, $\alpha_{V, y} \circ h_u = \alpha_{U, x}$ (since $f((U, x) \to (V, y)) = h_u.$)

The Yoneda lemma says there is a natural bijection $G(U) \simeq \operatorname{Hom}(h_U, G)$. Under this bijection, $\alpha_{U, x}$ corresponds to a unique element $g_{U, x} \in G(U)$. We have:

$$(Gu)(g_{V, y}) = g_{U, x}$$

because, according to the Yoneda lemma, $Gu: G(V) \to G(U)$ corresponds to $- \circ h_u: \operatorname{Hom}(h_V, G) \to \operatorname{Hom}(h_U, G).$

Now, for each object *U* in *C*, let $\theta_U: F(U) \to G(U)$ be the function given by $\theta_U(x) = g_{U, x}$. This determines the natural transformation $\theta: F \to G$; indeed, for each morphism $(U, x) \to (V, y), u: U \to V$ in *I*, we have:

$$(G u \circ \theta_V)(y) = (Gu)(g_{V, y}) = g_{U, x} = (\theta_U \circ Fu)(y),$$

since $(Fu)(y) = x$. Clearly, the construction $\alpha \mapsto \theta$ is reversible. Hence, $\alpha \mapsto \theta$ is the requisite natural bijection.

:::
