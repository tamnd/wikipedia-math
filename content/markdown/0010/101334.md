# Euler–Jacobi pseudoprime

::: {#o1 .subject cue=lead name="Euler–Jacobi pseudoprime"}

In [number theory](wikipedia://en/21527), an [odd](https://en.wikipedia.org/wiki/Odd_number) [integer](wikipedia://en/14563) *n* is called an **Euler–Jacobi probable prime** (or, more commonly, an **Euler probable prime**) to base *a*, if *a* and *n* are [coprime](https://en.wikipedia.org/wiki/Coprime), and

:::

$$a^{(n-1)/2} \equiv \left(\frac{a}{n}\right)\pmod{n}$$

where $\left(\frac{a}{n}\right)$ is the [Jacobi symbol](wikipedia://en/97313). The Jacobi symbol evaluates to 0 if *a* and *n* are not coprime, so the test can alternatively be expressed as:

$$a^{(n-1)/2} \equiv \left(\frac{a}{n}\right) \neq 0 \pmod{n}.$$

If *n* is an odd [composite](wikipedia://en/82289) integer that satisfies the above congruence, then *n* is called an **Euler–Jacobi pseudoprime** (or, more commonly, an **Euler pseudoprime**) to base *a*.

As long as *a* is not a multiple of *n* (usually 2 ≤ *a* \< *n*), then if *a* and *n* are not coprime, *n* is definitely composite, as 1 \< [gcd](wikipedia://en/12354)(*a*,*n*) \< *n* is a factor of *n*.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The motivation for this definition is the fact that all [prime numbers](wikipedia://en/23666) *n* satisfy the above equation, as explained in the [Euler's criterion](wikipedia://en/105622) article. The equation can be tested rather quickly, which can be used for probabilistic [primality testing](https://en.wikipedia.org/wiki/Prime_testing). These tests are over twice as strong as tests based on [Fermat's little theorem](wikipedia://en/53453).

Every Euler–Jacobi pseudoprime is also a [Fermat pseudoprime](wikipedia://en/45891) and an [Euler pseudoprime](wikipedia://en/225261). There are no numbers which are Euler–Jacobi pseudoprimes to all bases as [Carmichael numbers](wikipedia://en/7723) are. [Solovay](wikipedia://en/3160110) and [Strassen](wikipedia://en/771960) showed that for every composite *n*, for at least *n*/2 bases less than *n*, *n* is not an Euler–Jacobi pseudoprime.[^o4]

The smallest Euler–Jacobi pseudoprime base 2 is 561. There are 11347 Euler–Jacobi pseudoprimes base 2 that are less than 25·10<sup>9</sup> (see ) (page 1005 of [^o5]).

In the literature (for example,[^o5]), an Euler–Jacobi pseudoprime as defined above is often called simply an Euler pseudoprime.

:::
