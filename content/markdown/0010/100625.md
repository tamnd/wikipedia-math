# Inverter (logic gate)

*Image: Not-gate-en.svg.* Traditional NOT gate (inverter) symbol

::: {#o1 .subject cue=lead name="Inverter"}

In digital logic, an **inverter** or **NOT gate** is a [logic gate](https://en.wikipedia.org/wiki/Logic_gate) which implements [logical negation](https://en.wikipedia.org/wiki/Logical_negation). It outputs a [bit](https://en.wikipedia.org/wiki/Bit) whose value is opposite of the input bit's value. The bit values are typically represented using [two different voltage levels](https://en.wikipedia.org/wiki/Logic_level#2-level_logic), which may be called 0 and 1, or *true* and *false*, or *high* and *low*.

:::

## Description {#Description}

::: {#o3 .table cue=table}

| Inverter [truth table](wikipedia://en/25512250) |  |
|---|---|
| **Input** | **Output** |
| A | NOT A |
| 0 | 1 |
| 1 | 0 |

:::

The NOT gate outputs 0 when given 1, and outputs 1 when given 0. Hence, it inverts its inputs. Colloquially, this inversion of bits is called "flipping" bits.[^o4]

It is equivalent to the [logical negation](https://en.wikipedia.org/wiki/Logical_negation) operator (¬) in [mathematical logic](wikipedia://en/19636). Because it has only one input, it is a [unary operation](wikipedia://en/161006) and has the simplest type of [truth table](wikipedia://en/25512250). It is also called the complement gate[^o5] because it produces the [ones' complement](wikipedia://en/30670886) of a binary number, swapping 0s and 1s.

The NOT gate is one of three basic logic gates from which any [Boolean circuit](wikipedia://en/7087423) may be built up. Together with the [AND gate](https://en.wikipedia.org/wiki/AND_gate) and the [OR gate](https://en.wikipedia.org/wiki/OR_gate), any function in binary mathematics may be implemented. All other [logic gates](https://en.wikipedia.org/wiki/Logic_gates) may be made from these three.[^o6]

The terms "programmable inverter" or "controlled inverter" do not refer to this gate; instead, these terms refer to the [XOR gate](https://en.wikipedia.org/wiki/XOR_gate) because it can conditionally function like a NOT gate.[^o4][^o6]

## Symbols {#Symbols}

The traditional symbol for an inverter circuit is a triangle touching a small circle or "bubble". Input and output lines are attached to the symbol; the bubble is typically attached to the output line. To symbolize [active-low input](https://en.wikipedia.org/wiki/Logic_level#2-level_logic), sometimes the bubble is instead placed on the input line.[^o8] Sometimes only the circle portion of the symbol is used, and it is attached to the input or output of another gate; the symbols for [NAND](https://en.wikipedia.org/wiki/NAND_gate) and [NOR](https://en.wikipedia.org/wiki/NOR_gate) are formed in this way.[^o6]

A bar or [overline](wikipedia://en/4780165) ( ‾ ) above a variable can denote negation (or inversion or complement) performed by a NOT gate.[^o8] A slash (/) before the variable is also used.[^o6]

## Electronic implementation {#Electronic_implementation}

An inverter circuit outputs a voltage representing the opposite logic-level to its input. Its main function is to invert the input signal applied. If the applied input is low then the output becomes high and vice versa. Inverters can be constructed using a single [NMOS](https://en.wikipedia.org/wiki/NMOS_logic) transistor or a single [PMOS](https://en.wikipedia.org/wiki/PMOS_logic) transistor coupled with a [resistor](https://en.wikipedia.org/wiki/Resistor). Since this "resistive-drain" approach uses only a single type of transistor, it can be fabricated at a low cost. However, because current flows through the resistor in one of the two states, the resistive-drain configuration is disadvantaged for power consumption and processing speed. Alternatively, inverters can be constructed using two complementary transistors in a [CMOS](https://en.wikipedia.org/wiki/CMOS) configuration. This configuration greatly reduces power consumption since one of the transistors is always off in both logic states.[^o10] Processing speed can also be improved due to the relatively low resistance compared to the NMOS-only or PMOS-only type devices. Inverters can also be constructed with [bipolar junction transistors](https://en.wikipedia.org/wiki/Bipolar_junction_transistor) (BJT) in either a [resistor–transistor logic](https://en.wikipedia.org/wiki/Resistor–transistor_logic) (RTL) or a [transistor–transistor logic](https://en.wikipedia.org/wiki/Transistor–transistor_logic) (TTL) configuration.

[Digital](wikipedia://en/8276) electronics circuits operate at fixed voltage levels corresponding to a logical 0 or 1 (see [binary](https://en.wikipedia.org/wiki/Binary_numeral_system)). An inverter circuit serves as the basic logic gate to swap between those two voltage levels. Implementation determines the actual voltage, but common levels include (0, +5V) for TTL circuits.

### Digital building block {#Digital_building_block}

*Image: CMOS 4049 diagram.svg.* This schematic diagram shows the arrangement of NOT gates within a standard 4049 CMOS hex inverting buffer.

The inverter is a basic building block in digital electronics. Multiplexers, decoders, state machines, and other sophisticated digital devices may use inverters.

The *hex inverter* is an [integrated circuit](https://en.wikipedia.org/wiki/Integrated_circuit) that contains six (*hexa-*) inverters. For example, the [7404](https://en.wikipedia.org/wiki/7400_series) [TTL](https://en.wikipedia.org/wiki/Transistor–transistor_logic) chip which has 14 pins and the 4049 [CMOS](https://en.wikipedia.org/wiki/CMOS) chip which has 16 pins, 2 of which are used for power/referencing, and 12 of which are used by the inputs and outputs of the six inverters (the 4049 has 2 pins with no connection).

### Alternatives {#Alternatives}

If no specific NOT gates are available, one can be made from the universal [NAND](https://en.wikipedia.org/wiki/NAND_gate) or [NOR](https://en.wikipedia.org/wiki/NOR_gate) gates,[^o14] an [XOR gate](https://en.wikipedia.org/wiki/XOR_gate) by setting one input to high or an [XNOR gate](https://en.wikipedia.org/wiki/XNOR_gate) by setting one input to low.

### Performance measurement {#Performance_measurement}

*Image: Inverter voltage transfer curve.png.* Voltage transfer curve for a 20 μm inverter fabricated at [North Carolina State University](https://en.wikipedia.org/wiki/North_Carolina_State_University)

Digital inverter quality is often measured using the voltage transfer curve (VTC), which is a plot of output vs. input voltage. From such a graph, device parameters including noise tolerance, gain, and operating logic levels can be obtained.

Ideally, the VTC appears as an inverted step function – this would indicate precise switching between *on* and *off* – but in real devices, a gradual transition region exists. The VTC indicates that for low input voltage, the circuit outputs high voltage; for high input, the output tapers off towards the low level. The slope of this transition region is a measure of quality – steep (close to vertical) slopes yield precise switching.

The tolerance to noise can be measured by comparing the minimum input to the maximum output for each region of operation (on / off).

#### Linear region as analog amplifier {#Linear_region_as_analog_amplifier}

Since the transition region is steep and approximately linear, a properly-biased CMOS inverter digital logic gate may be used as a high-gain analog [linear amplifier](https://en.wikipedia.org/wiki/Linear_amplifier)[^o17][^o18][^o19][^o20][^o21] or even combined to form an [opamp](https://en.wikipedia.org/wiki/Opamp).[^o22] Maximum gain is achieved when the input and output operating points are the same voltage, which can be biased by connecting a resistor between the output and input.[^o23]
