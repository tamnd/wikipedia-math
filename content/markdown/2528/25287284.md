# Hessenberg variety

::: {#o1 .subject cue=lead name="Hessenberg variety"}

In [geometry](wikipedia://en/18973446), **Hessenberg varieties**, first studied by Filippo De Mari, [Claudio Procesi](wikipedia://en/35219117), and Mark A. Shayman, are [subvarieties](wikipedia://en/248808) of the full [flag variety](https://en.wikipedia.org/wiki/Flag_variety) that are defined in terms of a Hessenberg function *h* and a linear transformation *X*. The study of Hessenberg varieties was first motivated by questions in [numerical analysis](wikipedia://en/21506) in relation to algorithms for computing eigenvalues and eigenspaces of the linear operator *X*. Later work by [T. A. Springer](wikipedia://en/10836474), Dale Peterson, [Bertram Kostant](wikipedia://en/3520590), among others, found connections with [combinatorics](wikipedia://en/5170), [representation theory](wikipedia://en/19378200) and [cohomology](wikipedia://en/194060).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A *Hessenberg function* is a map

$$h :\{1,2, \ldots,n \} \rightarrow \{1,2, \ldots,n \}$$

such that

$$h(i+1) \geq \text{max }(i,h(i))$$

for each *i*. For example, the function that sends the numbers 1 to 5 (in order) to 2, 3, 3, 4, and 5 is a Hessenberg function.

For any Hessenberg function *h* and a linear transformation

$$X: \mathbb{C}^n \rightarrow \mathbb{C}^n, \,$$

the *Hessenberg variety* $\mathcal{H}(X,h)$ is the set of all [flags](wikipedia://en/390646) $F_{\bullet}$ such that

$$X \cdot F_i \subseteq F_{h(i)}$$

for all *i*.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of Hessenberg varieties (with their $h$ functions) include:

The full flag variety: *h*(*i*) = *n* for all *i*.

The [Peterson variety](https://en.wikipedia.org/wiki/Peterson_variety): $h(i) = i+1$ for $i = 1,2,\dots, n-1.$

The [Springer variety](https://en.wikipedia.org/wiki/Springer_variety): $h(i) = i$ for all $i.$
