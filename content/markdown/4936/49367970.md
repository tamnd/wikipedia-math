# Algebroid function

::: {#o1 .subject cue=lead name="Algebroid function"}

In [mathematics](wikipedia://en/18831), an **algebroid function** is a solution of an [algebraic equation](wikipedia://en/404001) whose coefficients are [analytic functions](wikipedia://en/61478). So *y*(*z*) is an algebroid function if it satisfies

:::

$$a_d(z)y^d + \ldots + a_0(z) = 0,$$

where $a_k(z)$ are analytic.[^o2] If this equation is irreducible then the function is *d*-valued, and can be defined on a [Riemann surface](wikipedia://en/173181) having *d* sheets.[^o3]
