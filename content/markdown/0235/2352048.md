# Unit function

::: {#o1 .subject cue=lead name="Unit function"}

In [number theory](wikipedia://en/21527), the **unit function** is a completely [multiplicative function](wikipedia://en/20059) on the positive integers defined as:

:::

$$\varepsilon(n) = \begin{cases} 1, & \mbox{if }n=1 \\ 0, & \mbox{if }n \neq 1 \end{cases}$$

It is called the unit function because it is the [identity element](wikipedia://en/14962) for [Dirichlet convolution](wikipedia://en/179017).[^o2]

It may be described as the "[indicator function](wikipedia://en/240790) of 1" within the set of positive integers. It is also written as $u(n)$ (not to be confused with $\mu(n)$, which generally denotes the [Möbius function](wikipedia://en/20961)).
