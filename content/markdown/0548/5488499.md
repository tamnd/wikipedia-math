# Continuum function

::: {#o1 .subject cue=lead name="Continuum function"}

In mathematics, the **continuum function** is the function $\kappa\mapsto 2^\kappa$ on [cardinals](wikipedia://en/6173), i.e. raising 2 to the power of *κ* using [cardinal exponentiation](https://en.wikipedia.org/wiki/Cardinal_exponentiation).[^o2] Given a cardinal number, the cardinal function yields the cardinality of the [power set](wikipedia://en/23799) of a set of the given cardinality.

:::
