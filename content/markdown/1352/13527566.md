# Heine's identity

::: {#o1 .subject cue=lead name="Heine's identity"}

In [mathematical analysis](wikipedia://en/48396), **Heine's identity**, named after [Eduard Heine](wikipedia://en/608289),[^n1] is a [Fourier expansion](https://en.wikipedia.org/wiki/Fourier_expansion) of a [reciprocal](https://en.wikipedia.org/wiki/Reciprocal_%28mathematics%29) [square root](wikipedia://en/29208):[^n2]

:::

$$\frac{1}{\sqrt{z-\cos\psi}} = \frac{\sqrt{2}}{\pi}\sum_{m=-\infty}^\infty Q_{m-\frac12}(z) e^{im\psi},$$

where $Q_{m-1/2}$ is a [Legendre function of the second kind](wikipedia://en/196402#Legendre_function_of_the_second_kind_%28Qn%29) and $z\in\mathbb{R}_{>1}$. This expression can be generalized for arbitrary half-integer powers as follows:[^n3]

$$(z-\cos\psi)^{n-\frac12} = \sqrt{\frac{2}{\pi}}\frac{(z^2-1)^{\frac{n}{2}}}{\Gamma(\frac12-n)} \sum_{m=-\infty}^{\infty} \frac{\Gamma(m-n+\frac12)}{\Gamma(m+n+\frac12)}Q_{m-\frac12}^n(z)e^{im\psi},$$

where $\Gamma$ is the [gamma function](wikipedia://en/12316).
