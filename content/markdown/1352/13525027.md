# Dual norm

::: {#o1 .subject cue=lead name="Dual norm"}

In [functional analysis](wikipedia://en/11180), the **dual norm** is a measure of size for a [continuous](wikipedia://en/6122) [linear function](wikipedia://en/152111) defined on a [normed vector space](wikipedia://en/21538).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [normed vector space](wikipedia://en/21538) with norm $\|\cdot\|$ and let $X^*$ denote its [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space). The **dual norm** of a continuous [linear functional](https://en.wikipedia.org/wiki/Linear_functional) $f$ belonging to $X^*$ is the non-negative real number defined[^o4] by any of the following equivalent formulas:

$$\begin{alignedat}{5} \| f \| &= \sup &&\{\,|f(x)| &&~:~ \|x\| \leq 1 ~&&~\text{ and } ~&&x \in X\} \\ &= \sup &&\{\,|f(x)| &&~:~ \|x\| < 1 ~&&~\text{ and } ~&&x \in X\} \\ &= \inf &&\{\,c \in [0, \infty) &&~:~ |f(x)| \leq c \|x\| ~&&~\text{ for all } ~&&x \in X\} \\ &= \sup &&\{\,|f(x)| &&~:~ \|x\| = 1 \text{ or } 0 ~&&~\text{ and } ~&&x \in X\} \\ &= \sup &&\{\,|f(x)| &&~:~ \|x\| = 1 ~&&~\text{ and } ~&&x \in X\} \;\;\;\text{ this equality holds if and only if } X \neq \{0\} \\ &= \sup &&\bigg\{\,\frac{|f(x)|}{\|x\|} ~&&~:~ x \neq 0 &&~\text{ and } ~&&x \in X\bigg\} \;\;\;\text{ this equality holds if and only if } X \neq \{0\} \\ \end{alignedat}$$

where $\sup$ and $\inf$ denote the [supremum and infimum](https://en.wikipedia.org/wiki/Supremum_and_infimum), respectively. The constant $0$ map is the origin of the vector space $X^*$ and it always has norm $\|0\| = 0.$ If $X = \{0\}$ then the only linear functional on $X$ is the constant $0$ map and moreover, the sets in the last two rows will both be empty and consequently, their [supremums](https://en.wikipedia.org/wiki/Supremum) will equal $\sup \varnothing = - \infty$ instead of the correct value of $0.$

Importantly, a linear function $f$ is not, in general, guaranteed to achieve its norm $\|f\| = \sup \{|f (x)| : \|x\| \leq 1, x \in X\}$ on the closed unit ball $\{x \in X : \|x\| \leq 1\},$ meaning that there might not exist any vector $u \in X$ of norm $\|u\| \leq 1$ such that $\|f\| = |f u|$ (if such a vector does exist and if $f \neq 0,$ then $u$ would necessarily have unit norm $\|u\| = 1$). R.C. James proved [James's theorem](wikipedia://en/17868139) in 1964, which states that a [Banach space](wikipedia://en/3989) $X$ is [reflexive](wikipedia://en/210091) if and only if every bounded linear function $f \in X^*$ achieves its norm on the closed unit ball.[^n1] It follows, in particular, that every non-reflexive Banach space has some bounded linear functional that does not achieve its norm on the closed unit ball. However, the [Bishop–Phelps theorem](wikipedia://en/40644951) guarantees that the set of bounded linear functionals that achieve their norm on the unit sphere of a [Banach space](wikipedia://en/3989) is a norm-[dense subset](wikipedia://en/23523594) of the [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space).[^o6][^o7]

The map $f \mapsto \|f\|$ defines a [norm](wikipedia://en/21538) on $X^*.$ (See Theorems 1 and 2 below.) The dual norm is a special case of the [operator norm](wikipedia://en/246722) defined for each (bounded) linear map between normed vector spaces. Since the [ground field](wikipedia://en/27161748) of $X$ ($\mathbb{R}$ or $\mathbb{C}$) is [complete](wikipedia://en/7832), $X^*$ is a [Banach space](wikipedia://en/3989#Linear_operators,_isomorphisms). The topology on $X^*$ [induced by](wikipedia://en/21538#Topological_structure) $\|\cdot\|$ turns out to be stronger than the [weak-\* topology](wikipedia://en/33662#The_weak-.2A_topology) on $X^*.$

:::

## The double dual of a normed linear space {#The_double_dual_of_a_normed_linear_space}

The [double dual](https://en.wikipedia.org/wiki/Double_dual) (or second dual) $X^{**}$ of $X$ is the dual of the normed vector space $X^*$. There is a natural map $\varphi: X \to X^{**}$. Indeed, for each $w^*$ in $X^*$ define

$$\varphi(v)(w^*): = w^*(v).$$

The map $\varphi$ is [linear](wikipedia://en/18102), [injective](https://en.wikipedia.org/wiki/Injective), and [distance preserving](wikipedia://en/254777).[^o9] In particular, if $X$ is complete (i.e. a Banach space), then $\varphi$ is an isometry onto a closed subspace of $X^{**}$.[^o10]

In general, the map $\varphi$ is not surjective. For example, if $X$ is the Banach space $L^{\infty}$ consisting of bounded functions on the real line with the supremum norm, then the map $\varphi$ is not surjective. (See [$L^p$ space](https://en.wikipedia.org/wiki/Lp_spaces)). If $\varphi$ is surjective, then $X$ is said to be a [reflexive Banach space](https://en.wikipedia.org/wiki/Reflexive_Banach_space). If $1 < p < \infty,$ then the [space $L^p$](https://en.wikipedia.org/wiki/Lp_spaces) is a reflexive Banach space.

## Examples {#Examples}

### Dual norm for matrices {#Dual_norm_for_matrices}

The [*Frobenius norm*](wikipedia://en/1543735#Frobenius_norm) defined by

$$\| A\|_{\text{F}} = \sqrt{\sum_{i=1}^m\sum_{j=1}^n \left| a_{ij} \right|^2} = \sqrt{\operatorname{trace}(A^*A)} = \sqrt{\sum_{i=1}^{\min\{m,n\}} \sigma_{i}^2}$$

is self-dual, i.e., its dual norm is $\| \cdot \|'_{\text{F}} = \| \cdot \|_{\text{F}}.$

The *spectral norm*, a special case of the [*induced norm*](wikipedia://en/1543735#induced_norm) when $p=2$, is defined by the maximum [singular values](wikipedia://en/142207#Singular_values,_singular_vectors,_and_their_relation_to_the_SVD) of a matrix, that is,

$$\| A \| _2 = \sigma_{\max}(A),$$

has the nuclear norm as its dual norm, which is defined by

$$\|B\|'_2 = \sum_i \sigma_i(B),$$

for any matrix $B$ where $\sigma_i(B)$ denote the singular values.

If $p, q \in [1, \infty]$ the [Schatten $\ell^p$-norm](wikipedia://en/1543735) on matrices is dual to the Schatten $\ell^q$-norm.

### Finite-dimensional spaces {#Finite-dimensional_spaces}

Let $\|\cdot\|$ be a norm on $\mathbb{R}^n.$ The associated *dual norm*, denoted $\| \cdot \|_*,$ is defined as

$$\|z\|_* = \sup\{z^\intercal x : \|x\| \leq 1 \}.$$

(This can be shown to be a norm.) The dual norm can be interpreted as the [operator norm](wikipedia://en/246722) of $z^\intercal,$ interpreted as a $1 \times n$ matrix, with the norm $\|\cdot\|$ on $\mathbb{R}^n$, and the absolute value on $\mathbb{R}$:

$$\|z\|_* = \sup\{|z^\intercal x| : \|x\| \leq 1 \}.$$

From the definition of dual norm we have the inequality

$$z^\intercal x = \|x\| \left(z^\intercal \frac{x}{\|x\|} \right) \leq \|x\| \|z\|_*$$

which holds for all $x$ and $z.$[^o15][^o16] The dual of the dual norm is the original norm: we have $\|x\|_{**} = \|x\|$ for all $x.$ (This need not hold in infinite-dimensional vector spaces.)

The dual of the [Euclidean norm](wikipedia://en/990534#Euclidean_norm) is the Euclidean norm, since

$$\sup\{z^\intercal x : \|x\|_2 \leq 1 \} = \|z\|_2.$$

(This follows from the [Cauchy–Schwarz inequality](wikipedia://en/38128); for nonzero $z,$ the value of $x$ that maximises $z^\intercal x$ over $\|x\|_2 \leq 1$ is $\tfrac{z}{\|z\|_2}.$)

The dual of the $\ell^\infty$-norm is the $\ell^1$-norm:

$$\sup\{z^\intercal x : \|x\| _\infty \leq 1\} = \sum_{i=1}^n |z_i| = \|z\| _1,$$

and the dual of the $\ell^1$-norm is the $\ell^\infty$-norm.

More generally, [Hölder's inequality](wikipedia://en/191538) shows that the dual of the [$\ell^p$-norm](https://en.wikipedia.org/wiki/Lp_spaces) is the $\ell^q$-norm, where $q$ satisfies $\tfrac{1}{p} + \tfrac{1}{q} = 1,$ that is, $q = \tfrac{p}{p-1}.$

As another example, consider the $\ell^2$- or spectral norm on $\mathbb{R}^{m\times n}$. The associated dual norm is

$$\|Z\| _{2*} = \sup\{\mathbf{tr}(Z^\intercal X) : \|X\|_2 \leq 1\},$$

which turns out to be the sum of the singular values,

$$\|Z\| _{2*} = \sigma_1(Z) + \cdots + \sigma_r(Z) = \mathbf{tr} (\sqrt{Z^\intercal Z}),$$

where $r = \mathbf{rank} Z.$ This norm is sometimes called the [*nuclear norm*](wikipedia://en/63684284).[^o17]

### *L<sup>p</sup>* and ℓ<sup>*p*</sup> spaces {#Lp_and_ℓp_spaces}

For $p \in [1, \infty],$ $p$-norm (also called $\ell_p$-norm) of vector $\mathbf{x} = (x_n)_n$ is

$$\|\mathbf{x}\|_p ~:=~ \left(\sum_{i=1}^n \left|x_i\right|^p\right)^{1/p}.$$

If $p, q \in [1, \infty]$ satisfy $1/p+1/q=1$ then the $\ell^p$ and $\ell^q$ norms are dual to each other and the same is true of the $L^p$ and $L^q$ norms, where $(X, \Sigma, \mu),$ is some [measure space](wikipedia://en/19873). In particular the [Euclidean norm](https://en.wikipedia.org/wiki/L2_norm) is self-dual since $p = q = 2.$ For $\sqrt{x^{\mathrm{T}}Qx}$, the dual norm is $\sqrt{y^{\mathrm{T}}Q^{-1}y}$ with $Q$ positive definite.

For $p = 2,$ the $\|\,\cdot\,\|_2$-norm is even induced by a canonical [inner product](https://en.wikipedia.org/wiki/Inner_product) $\langle \,\cdot,\,\cdot\rangle,$ meaning that $\|\mathbf{x}\|_2 = \sqrt{\langle \mathbf{x}, \mathbf{x} \rangle}$ for all vectors $\mathbf{x}.$ This inner product can expressed in terms of the norm by using the [polarization identity](wikipedia://en/2047965). On $\ell^2,$ this is the *Euclidean inner product* defined by

$$\langle \left(x_n\right)_{n}, \left(y_n\right)_{n} \rangle_{\ell^2} ~=~ \sum_n x_n \overline{y_n}$$

while for the space $L^2(X, \mu)$ associated with a [measure space](wikipedia://en/19873) $(X, \Sigma, \mu),$ which consists of all [square-integrable functions](wikipedia://en/28680558), this inner product is

$$\langle f, g \rangle_{L^2} = \int_X f(x) \overline{g(x)} \, \mathrm dx.$$

The norms of the continuous dual spaces of $\ell^2$ and $\ell^2$ satisfy the [polarization identity](wikipedia://en/2047965), and so these dual norms can be used to define inner products. With this inner product, this dual space is also a [Hilbert space](wikipedia://en/20598932).

:::

## Properties {#Properties}

Given normed vector spaces $X$ and $Y,$ let $L(X,Y)$[^o21] be the collection of all [bounded linear mappings](wikipedia://en/455961) (or operators) of $X$ into $Y.$ Then $L(X,Y)$ can be given a canonical norm.

::: {#o22 .statement kind=statement/theorem cue=math-theorem name="Theorem 1"}

**Theorem 1.**

Let $X$ and $Y$ be normed spaces. Assigning to each continuous linear operator $f \in L(X, Y)$ the scalar

$$\|f\| = \sup \{\|f(x)\| : x \in X, \|x\| \leq 1\}$$

defines a norm $\|\cdot\| ~:~ L(X, Y) \to \mathbb{R}$ on $L(X, Y)$ that makes $L(X, Y)$ into a normed space. Moreover, if $Y$ is a Banach space then so is $L(X, Y).$[^o23]

:::

::: {#o24 .proof cue=collapse name="Proof"}

A subset of a normed space is bounded [if and only if](wikipedia://en/14922) it lies in some multiple of the [unit sphere](wikipedia://en/27033090); thus $\|f\| < \infty$ for every $f \in L(X,Y)$ if $\alpha$ is a scalar, then $(\alpha f)(x) = \alpha \cdot f x$ so that

$$\|\alpha f\| = |\alpha| \|f\|.$$

The [triangle inequality](wikipedia://en/53941) in $Y$ shows that

$$\begin{aligned} \| \left(f_1 + f_2\right) x \| ~&=~ \|f_1 x + f_2 x\| \\ &\leq~ \|f_1 x\| + \|f_2 x\| \\ &\leq~ \left(\|f_1\| + \|f_2\|\right) \|x\| \\ &\leq~ \|f_1\| + \|f_2\| \end{aligned}$$

for every $x \in X$ satisfying $\|x\| \leq 1.$ This fact together with the definition of $\| \cdot \| ~:~ L(X, Y) \to \mathbb{R}$ implies the triangle inequality:

$$\|f + g\| \leq \|f\| + \|g\|.$$

Since $\{ |f(x)| : x \in X, \|x\| \leq 1 \}$ is a non-empty set of non-negative real numbers, $\|f\| = \sup \left\{ |f(x)| : x \in X, \| x \| \leq 1 \right\}$ is a non-negative real number. If $f \neq 0$ then $f x_0 \neq 0$ for some $x_0 \in X,$ which implies that $\left\|f x_0\right\| > 0$ and consequently $\|f\| > 0.$ This shows that $\left( L(X, Y), \| \cdot \|\right)$ is a normed space.[^o25]

Assume now that $Y$ is complete and we will show that $( L(X, Y), \| \cdot \|)$ is complete. Let $f_{\bullet} = \left(f_n\right)_{n=1}^{\infty}$ be a [Cauchy sequence](wikipedia://en/6085) in $L(X, Y),$ so by definition $\left\|f_n - f_m\right\| \to 0$ as $n, m \to \infty.$ This fact together with the relation

$$\left\|f_n x - f_m x\right\| = \left\| \left( f_n - f_m \right) x \right\| \leq \left\|f_n - f_m\right\| \|x\|$$

implies that $\left(f_nx \right)_{n=1}^{\infty}$ is a Cauchy sequence in $Y$ for every $x \in X.$ It follows that for every $x \in X,$ the limit $\lim_{n \to \infty} f_n x$ exists in $Y$ and so we will denote this (necessarily unique) limit by $f x,$ that is:

$$f x ~=~ \lim_{n \to \infty} f_n x.$$

It can be shown that $f: X \to Y$ is linear. If $\varepsilon > 0$, then $\left\|f_n - f_m\right\| \| x \| ~\leq~ \varepsilon \|x\|$ for all sufficiently large integers $n$ and $m$. It follows that

$$\left\|fx - f_m x\right\| ~\leq~ \varepsilon \|x\|$$

for sufficiently all large $m.$ Hence $\|fx\| \leq \left( \left\|f_m\right\| + \varepsilon \right) \|x\|,$ so that $f \in L(X, Y)$ and $\left\|f - f_m\right\| \leq \varepsilon.$ This shows that $f_m \to f$ in the norm topology of $L(X, Y).$ This establishes the completeness of $L(X, Y).$[^o26]

:::

When $Y$ is a [scalar field](wikipedia://en/161879) (i.e. $Y = \mathbb{C}$ or $Y = \mathbb{R}$) so that $L(X,Y)$ is the [dual space](wikipedia://en/7988) $X^*$ of $X.$

::: {#o27 .statement kind=statement/theorem cue=math-theorem name="Theorem 2"}

**Theorem 2.**

Let $X$ be a normed space and for every $x^* \in X^*$ let

$$\left\|x^*\right\| ~:=~ \sup \left\{| \langle x, x^* \rangle | ~:~ x \in X \text{ with } \| x \| \leq 1 \right\}$$

where by definition $\langle x, x^* \rangle ~:=~ x^{*}(x)$ is a scalar. Then

$\| \, \cdot \, \| : X^* \to \mathbb{R}$ is a [norm](wikipedia://en/990534) that makes $X^*$ a Banach space.[^o28] If $B^*$ is the closed unit ball of $X^*$ then for every $x \in X,$

$$\begin{alignedat}{4} \| x \| ~&=~ \sup \left\{ | \langle x, x^* \rangle | ~:~ x^* \in B^* \right\} \\ &=~ \sup \left\{ \left|x^*(x)\right| ~:~ \left\|x^*\right\| \leq 1 \text{ with } x^* \in X^* \right\}. \\ \end{alignedat}$$

Consequently, $x^* \mapsto \langle x, x^* \rangle$ is a bounded [linear functional](https://en.wikipedia.org/wiki/Linear_functional) on $X^*$ with norm $\| x^* \| ~=~ \| x \|.$ $B^*$ is weak\*-compact.

:::

::: {#o29 .proof cue=collapse name="Proof"}

Let $B ~=~ \sup\{ x \in X ~:~ \| x \| \le 1 \}$denote the closed unit ball of a normed space $X.$ When $Y$ is the [scalar field](wikipedia://en/161879) then $L(X,Y) = X^*$ so part (a) is a corollary of Theorem 1. Fix $x \in X.$ There exists[^o30] $y^* \in B^*$ such that

$$\langle{x,y^*}\rangle = \|x\|.$$

but,

$$|\langle{x,x^*}\rangle| \leq \|x\|\|x^*\| \leq \|x\|$$

for every $x^* \in B^*$. (b) follows from the above. Since the open unit ball $U$ of $X$ is dense in $B$, the definition of $\|x^*\|$ shows that $x^* \in B^*$ [if and only if](wikipedia://en/14922) $|\langle{x,x^*}\rangle| \leq 1$ for every $x \in U$. The proof for (c)[^o31] now follows directly.[^o32]

:::

As usual, let $d(x, y) := \|x - y\|$ denote the canonical [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) induced by the norm on $X,$ and denote the distance from a point $x$ to the subset $S \subseteq X$ by

$$d(x, S) ~:=~ \inf_{s \in S} d(x, s) ~=~ \inf_{s \in S} \|x - s\|.$$

If $f$ is a bounded linear functional on a normed space $X,$ then for every vector $x \in X,$[^n2]

$$|f(x)| = \|f\| \, d(x, \ker f),$$

where $\ker f = \{k \in X : f(k) = 0\}$ denotes the [kernel](wikipedia://en/1072915) of $f.$

:::
