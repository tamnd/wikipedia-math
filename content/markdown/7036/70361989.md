# Glossary of linear algebra

::: {#o1 .subject cue=lead name="Glossary of linear algebra"}

This **glossary of linear algebra** is a list of definitions and terms relevant to the field of [linear algebra](wikipedia://en/18422), the branch of mathematics concerned with linear equations and their representations as [vector spaces](wikipedia://en/32370).

:::

For a glossary related to the generalization of vector spaces through [modules](wikipedia://en/276410), see [glossary of module theory](wikipedia://en/25334192).

## A {#A}

::: {#o3 .entry cue=term name="affine transformation"}

**[affine transformation](wikipedia://en/38449)**

A composition of functions consisting of a linear transformation between vector spaces followed by a translation.[^n1] Equivalently, a function between vector spaces that preserves affine combinations.

:::

::: {#o5 .entry cue=term name="affine combination"}

**[affine combination](wikipedia://en/298835)**

A linear combination in which the sum of the coefficients is 1.

:::

## B {#B}

::: {#o7 .entry cue=term name="basis"}

**basis**

In a vector space, a linearly independent set of vectors spanning the whole vector space.[^n2]

:::

::: {#o9 .entry cue=term name="basis vector"}

**basis vector**

An element of a given basis of a vector space.[^n2]

:::

::: {#o11 .entry cue=term name="bilinear form"}

**bilinear form**

On vector space *V* over field *K*, a bilinear form is a function $B : V \times V \to K$ that is linear in each variable.

:::

## C {#C}

::: {#o13 .entry cue=term name="column vector"}

**column vector**

A matrix with only one column.[^n3]

:::

::: {#o15 .entry cue=term name="complex number"}

**[complex number](wikipedia://en/5826)**

An element of a complex plane

:::

::: {#o16 .entry cue=term name="complex plane"}

**[complex plane](wikipedia://en/217628)**

A linear algebra over the real numbers with basis {1, i }, where i is an imaginary unit[^o17]

:::

::: {#o18 .entry cue=term name="coordinate vector"}

**[coordinate vector](wikipedia://en/879358)**

The [tuple](wikipedia://en/132729) of the [coordinates](https://en.wikipedia.org/wiki/Coordinates) of a vector on a basis.

:::

::: {#o19 .entry cue=term name="covector"}

**[covector](https://en.wikipedia.org/wiki/Covector)**

An element of the dual space of a vector space, (that is a linear form), identified to an element of the vector space through an [inner product](https://en.wikipedia.org/wiki/Inner_product).

:::

## D {#D}

::: {#o21 .entry cue=term name="determinant"}

**[determinant](wikipedia://en/8468)**

The unique scalar function over square matrices which is distributive over matrix multiplication, multilinear in the rows and columns, and takes the value of $1$ for the identity matrix.[^o22]

:::

::: {#o23 .entry cue=term name="diagonal matrix"}

**[diagonal matrix](wikipedia://en/174080)**

A matrix in which only the entries on the main diagonal are non-zero.[^n4]

:::

::: {#o25 .entry cue=term name="dimension"}

**dimension**

The number of elements of any basis of a vector space.[^n2]

:::

::: {#o27 .entry cue=term name="dot product"}

**[dot product](wikipedia://en/157093)**

Given two vectors of the same length, the dot product is the sum of the products of their corresponding indices.

:::

::: {#o28 .entry cue=term name="dual space"}

**[dual space](wikipedia://en/7988)**

The vector space of all linear forms on a given vector space.[^n5]

:::

## E {#E}

::: {#o31 .entry cue=term name="Elementary matrix"}

**Elementary matrix**

Square matrix that differs from the identity matrix by at most one entry

:::

## H {#H}

::: {#o33 .entry cue=term name="hyperbolic unit"}

**hyperbolic unit**

An operator (*x, y*) → (*y, x*), reflecting the plane in the 45° diagonal

In a linear algebra, a linear map which when composed with itself yields the identity

:::

## I {#I}

::: {#o35 .entry cue=term name="Identity matrix"}

**Identity matrix**

A diagonal matrix all of the diagonal elements of which are equal to $1$.[^n4]

:::

::: {#o37 .entry cue=term name="imaginary unit"}

**[imaginary unit](wikipedia://en/52358)**

An operator (*x, y*) → (*y, –x*), rotating the plane 90° counterclockwise

In a linear algebra, a linear map which when composed with itself produces the negative of the identity

:::

::: {#o38 .entry cue=term name="inverse matrix"}

**[inverse matrix](https://en.wikipedia.org/wiki/Inverse_matrix)**

Of a matrix $A$, another matrix $B$ such that $A$ multiplied by $B$ and $B$ multiplied by $A$ both equal the identity matrix.[^n4]

:::

::: {#o40 .entry cue=term name="Isotropic vector"}

**Isotropic vector**

In a vector space with a [quadratic form](wikipedia://en/251478), a non-zero vector for which the form is zero.

:::

::: {#o41 .entry cue=term name="isotropic quadratic form"}

**[isotropic quadratic form](wikipedia://en/10917170)**

A vector space with a quadratic form which has a null vector.

:::

## L {#L}

::: {#o43 .entry cue=term name="linear algebra"}

**[linear algebra](wikipedia://en/18422)**

The branch of mathematics that deals with vectors, vector spaces, linear transformations and systems of linear equations.

A vector space that has a [binary operation](wikipedia://en/3948) making it a [ring](wikipedia://en/48404). This linear algebra is also known as an [algebra over a field](wikipedia://en/191788).[^o44]

:::

::: {#o45 .entry cue=term name="linear combination"}

**[linear combination](wikipedia://en/55632)**

A sum, each of whose summands is an appropriate vector times an appropriate scalar (or ring element).[^n6]

:::

::: {#o47 .entry cue=term name="linear dependence"}

**[linear dependence](https://en.wikipedia.org/wiki/Linear_dependence)**

A linear dependence of a tuple of vectors $\vec v_1,\ldots,\vec v_n$ is a nonzero tuple of scalar coefficients $c_1,\ldots,c_n$ for which the linear combination $c_1\vec v_1+\cdots+c_n\vec v_n$ equals $\vec0$.

:::

::: {#o48 .entry cue=term name="linear equation"}

**[linear equation](wikipedia://en/17570)**

A [polynomial equation](https://en.wikipedia.org/wiki/Polynomial_equation) of degree one (such as $x = 2y - 7$).[^n7]

:::

::: {#o50 .entry cue=term name="linear form"}

**[linear form](wikipedia://en/214137)**

A linear map from a vector space to its field of scalars.[^n8]

:::

::: {#o52 .entry cue=term name="linear independence"}

**[linear independence](wikipedia://en/101863)**

Property of being not linearly dependent.[^n9]

:::

::: {#o54 .entry cue=term name="linear map"}

**[linear map](wikipedia://en/18102)**

A [function](wikipedia://en/185427) between vector spaces which respects addition and scalar multiplication.

:::

::: {#o55 .entry cue=term name="linear transformation"}

**[linear transformation](https://en.wikipedia.org/wiki/Linear_transformation)**

A linear map whose [domain](wikipedia://en/50263) and [codomain](wikipedia://en/50264) are equal; it is generally supposed to be [invertible](wikipedia://en/14907).

:::

## M {#M}

::: {#o57 .entry cue=term name="matrix"}

**matrix**

Rectangular arrangement of numbers or other [mathematical objects](wikipedia://en/19453961).[^n4] A matrix is written *A* = (a<sub>i, j</sub>), where a<sub>i, j</sub> is the entry at row i and column j.

:::

::: {#o59 .entry cue=term name="matrix multiplication"}

**[matrix multiplication](wikipedia://en/125280)**

If a matrix *A* has the same number of columns as does matrix *B* of rows, then a product *C* = *AB* may be formed with *c*<sub>i, j</sub> equal to the dot product of row i of *A* with column j of *B*.

:::

## N {#N}

::: {#o61 .entry cue=term name="null vector"}

**[null vector](wikipedia://en/1453977)**

Another term for an isotropic vector.

Another term for a zero vector.

:::

## O {#O}

::: {#o63 .entry cue=term name="orthogonality"}

**[orthogonality](wikipedia://en/71675950)**

Two vectors *u* and *v* are orthogonal with respect to a bilinear form *B* when *B*(*u,v*) = 0.

:::

::: {#o64 .entry cue=term name="orthonormality"}

**[orthonormality](wikipedia://en/194743)**

A set of vectors is orthonormal when they are all unit vectors and are pairwise orthogonal.

:::

::: {#o65 .entry cue=term name="orthogonal matrix"}

**[orthogonal matrix](wikipedia://en/105620)**

A real square matrix with rows (or columns) that form an orthonormal set.

:::

## R {#R}

::: {#o67 .entry cue=term name="row vector"}

**[row vector](wikipedia://en/149968)**

A matrix with only one row.[^n4]

:::

## S {#S}

::: {#o70 .entry cue=term name="scalar"}

**[scalar](wikipedia://en/3588331)**

A scalar is an element of a [field](wikipedia://en/10603) used in the definition of a vector space.

:::

::: {#o71 .entry cue=term name="singular-value decomposition"}

**[singular-value decomposition](https://en.wikipedia.org/wiki/Singular-value_decomposition)**

a factorization of an $m \times n$ complex matrix $\mathbf{M}$ as $\mathbf{U\Sigma V^*}$, where $\mathbf{U}$ is an $m \times m$ complex [unitary matrix](wikipedia://en/129222), $\mathbf{\Sigma}$ is an $m \times n$ [rectangular diagonal matrix](https://en.wikipedia.org/wiki/Rectangular_diagonal_matrix) with non-negative real numbers on the diagonal, and $\mathbf{V}$ is an $n \times n$ complex unitary matrix.[^n10]

:::

::: {#o73 .entry cue=term name="spectrum"}

**spectrum**

Set of the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of a matrix.[^n11]

:::

::: {#o75 .entry cue=term name="split-complex number"}

**[split-complex number](wikipedia://en/893559)**

An element of a split-complex plane.

:::

::: {#o76 .entry cue=term name="split-complex plane"}

**split-complex plane**

A linear algebra over the real numbers with basis {1, j }, where j is a hyperbolic unit.

:::

::: {#o77 .entry cue=term name="square matrix"}

**square matrix**

A matrix having the same number of rows as columns.[^n4]

:::

## T {#T}

::: {#o80 .entry cue=term name="transpose"}

**[transpose](wikipedia://en/173844)**

The transpose of an n × m matrix *M* is an m × n matrix *M*<sup>T</sup> obtained by using the rows of *M* for the columns of *M*<sup>T</sup>.

:::

## U {#U}

::: {#o82 .entry cue=term name="unit vector"}

**[unit vector](wikipedia://en/167053)**

a vector in a normed vector space whose [norm](wikipedia://en/990534) is 1, or a [Euclidean vector](wikipedia://en/32533) of length one.[^n12]

:::

## V {#V}

::: {#o85 .entry cue=term name="vector"}

**[vector](wikipedia://en/23218956)**

A directed quantity, one with both magnitude and direction.

An element of a vector space.[^n13]

:::

::: {#o87 .entry cue=term name="vector space"}

**[vector space](wikipedia://en/32370)**

A [set](wikipedia://en/26691), whose elements can be added together, and multiplied by elements of a [field](wikipedia://en/10603) (this is [scalar multiplication](wikipedia://en/244373)); the set must be an [abelian group](wikipedia://en/2974) under addition, and the scalar multiplication must be a [linear map](wikipedia://en/18102).[^n14]

:::

## Z {#Z}

::: {#o90 .entry cue=term name="zero vector"}

**[zero vector](https://en.wikipedia.org/wiki/Zero_vector)**

The [additive identity](wikipedia://en/4178225) in a vector space. In a [normed vector space](wikipedia://en/21538), it is the unique vector of norm zero. In a [Euclidean vector space](https://en.wikipedia.org/wiki/Euclidean_vector_space), it is the unique vector of length zero.[^n15]

:::
