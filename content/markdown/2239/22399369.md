# Parity function

::: {#o1 .subject cue=lead name="Parity function"}

In [Boolean algebra](https://en.wikipedia.org/wiki/Boolean_algebra_%28logic%29), a **parity function** is a [Boolean function](wikipedia://en/753349) whose value is one [if and only if](wikipedia://en/14922) the input vector has an odd number of ones. The parity function of two inputs is also known as the [XOR](wikipedia://en/105979) function.

:::

The parity function is notable for its role in theoretical investigation of [circuit complexity](wikipedia://en/7641969) of Boolean functions.

The output of the parity function is the [parity bit](wikipedia://en/194467).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The $n$-variable parity function is the [Boolean function](wikipedia://en/753349) $f:\{0,1\}^n\to\{0,1\}$ with the property that $f(x)=1$ [if and only if](wikipedia://en/14922) the number of ones in the vector $x\in\{0,1\}^n$ is odd. In other words, $f$ is defined as follows:

$$f(x)=x_1\oplus x_2 \oplus \dots \oplus x_n$$

where $\oplus$ denotes [exclusive or](wikipedia://en/105979).

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Parity only depends on the number of ones and is therefore a [symmetric Boolean function](wikipedia://en/22399366).

The *n*-variable parity function and its negation are the only Boolean functions for which all [disjunctive normal forms](wikipedia://en/73341) have the maximal number of 2<sup>*n* − 1</sup> [monomials](wikipedia://en/357416) of length *n* and all [conjunctive normal forms](wikipedia://en/73342) have the maximal number of 2<sup>*n* − 1</sup> clauses of length *n*.[^o6]

:::

## Computational complexity {#Computational_complexity}

Some of the earliest work in computational complexity was 1961 bound of [Bella Subbotovskaya](wikipedia://en/37006272) showing the size of a [Boolean formula](wikipedia://en/3126968) computing parity must be at least $\Omega(n^{3/2})$. This work uses the method of random restrictions. This exponent of $3/2$ has been increased through careful analysis to $1.63$ by [Paterson](https://en.wikipedia.org/wiki/Mike_Paterson) and [Zwick](https://en.wikipedia.org/wiki/Uri_Zwick) (1993) and then to $2$ by [Håstad](https://en.wikipedia.org/wiki/Johan_Håstad) (1998). [^o8]

In the early 1980s, [Merrick Furst](https://en.wikipedia.org/wiki/Merrick_L._Furst), [James Saxe](https://en.wikipedia.org/wiki/James_Saxe) and [Michael Sipser](wikipedia://en/3644015)[^o9] and independently [Miklós Ajtai](https://en.wikipedia.org/wiki/Miklós_Ajtai)[^o10] established super-polynomial [lower bounds](https://en.wikipedia.org/wiki/Lower_bound) on the size of constant-depth [Boolean circuits](https://en.wikipedia.org/wiki/Boolean_circuits) for the parity function, i.e., they showed that polynomial-size constant-depth circuits cannot compute the parity function. Similar results were also established for the majority, multiplication and [transitive closure](wikipedia://en/292239) functions, by reduction from the parity function.[^o9]

(Håstad 1987) established tight exponential lower bounds on the size of constant-depth [Boolean circuits](https://en.wikipedia.org/wiki/Boolean_circuits) for the parity function. [Håstad's Switching Lemma](https://en.wikipedia.org/wiki/Håstad's_Switching_Lemma) is the key technical tool used for these lower bounds and [Johan Håstad](https://en.wikipedia.org/wiki/Johan_Håstad) was awarded the [Gödel Prize](https://en.wikipedia.org/wiki/Gödel_Prize) for this work in 1994. The precise result is that depth-$k$ circuits with AND, OR, and NOT gates require size $\exp(\Omega(n^{\frac{1}{k-1}}))$ to compute the parity function. This is asymptotically almost optimal as there are depth-$k$ circuits computing parity which have size $\exp(O(n^{\frac{1}{k-1}})t)$.

## Infinite version {#Infinite_version}

An infinite parity function is a function $f\colon \{0, 1\}^{\omega} \to \{0, 1\}$ mapping every infinite binary string to 0 or 1, having the following property: if $w$ and $v$ are infinite binary strings differing only on finitely many coordinates, then $f(w) = f(v)$ if and only if $w$ and $v$ differ on an [even number](wikipedia://en/143135) of coordinates.

Assuming [axiom of choice](wikipedia://en/840) it can be proved that parity functions exist and there are $2^{2^{\aleph_0}}$ many of them; as many as the number of all functions from $\{0, 1\}^{\omega}$ to $\{0, 1\}$. It is enough to take one representative per [equivalence class](wikipedia://en/9260) of relation $\approx$ defined as follows: $w \approx v$ if $w$ and $v$ differ at finite number of coordinates. Having such representatives, we can map all of them to $0$; the rest of $f$ values are deducted unambiguously.

Another construction of an infinite parity function can be done using a non-principal [ultrafilter](wikipedia://en/67416519) $U$ on $\omega$. The existence of non-principal ultrafilters on $\omega$ follows from – and is strictly weaker than – the axiom of choice. For any $w:\omega\to\{0,1\}$ we consider the set $A_w=\{n\in\omega\mid \{k\leq n\mid w(k)=0\}\text{ is even}\}$. The infinite parity function $f$ is defined by mapping $w$ to $0$ if and only if $A_w$ is an element of the ultrafilter.

It is necessary to assume at least some amount of choice to prove that infinite parity functions exist. If $f$ is an infinite parity function and we consider the inverse image $f^{-1}[0]$ as a subset of the [Cantor space](wikipedia://en/352376) $\{0, 1\}^{\omega}$, then $f^{-1}[0]$ is a [non-measurable](wikipedia://en/620134) set and does not have the [property of Baire](wikipedia://en/2213768). Without the axiom of choice, it is consistent (relative to [ZF](https://en.wikipedia.org/wiki/Zermelo-Fraenkel_set_theory)) that all subsets of the Cantor space are measurable and have the property of Baire and thus that no infinite parity function exists; this holds in the [Solovay model](wikipedia://en/25274967), for instance.

:::
