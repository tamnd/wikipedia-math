# Monus

::: {#o1 .subject cue=lead name="Monus"}

In mathematics, **monus** is an operator on certain [commutative](wikipedia://en/294390) [monoids](wikipedia://en/19652#Commutative_monoid) that are not [groups](wikipedia://en/19447). A commutative monoid on which a monus operator is defined is called a **commutative monoid with monus**, or **CMM**. The monus operator may be denoted with the [minus sign](https://en.wikipedia.org/wiki/Minus_sign), "$-$", because the [natural numbers](wikipedia://en/21474) are a CMM under [subtraction](wikipedia://en/74141). It is also denoted with a dotted minus sign, "$\mathbin{\dot{-}}$", to distinguish it from the standard subtraction operator.

:::

## Definition {#Definition}

Let $(M, +, 0)$ be a commutative [monoid](wikipedia://en/19652). Define a [binary relation](wikipedia://en/3931) $\leq$ on this monoid as follows: for any two elements $a$ and $b$, define $a \leq b$ if there exists an element $c$ such that $a + c = b$. It is easy to check that $\leq$ is [reflexive](wikipedia://en/200458)[^o9] and that it is [transitive](wikipedia://en/200463).[^o10] $M$ is called **naturally ordered** if the $\leq$ relation is additionally [antisymmetric](wikipedia://en/1176) and hence a [partial order](https://en.wikipedia.org/wiki/Partial_order). Further, if for each pair of elements $a$ and $b$, a unique smallest element $c_0$ exists such that $a \leq b + c_0$, then $M$ is called a **commutative monoid with monus**[^n2] and the **monus** $a \mathbin{\dot{-}} b$ of any two elements $a$ and $b$ can be defined as this unique smallest element $c_0$ such that $a \leq b + c_0$.

An example of a commutative monoid that is not naturally ordered is $(\mathbb{Z}, +, 0)$, the commutative monoid of the [integers](wikipedia://en/14563) with usual [addition](wikipedia://en/61338), as for any $a, b \in \mathbb{Z}$ there exists $c$ such that $a + c = b$, so $a \leq b$ holds for any $a, b \in \mathbb{Z}$, so $\leq$ is not antisymmetric and therefore not a partial order. There are also examples of monoids that are naturally ordered but are not semirings with monus.[^n3]

## Other structures {#Other_structures}

Beyond monoids, the notion of monus can be applied to other structures. For instance, a **naturally ordered semiring** (sometimes called a **dioid**[^n4]) is a [semiring](wikipedia://en/371468) where the commutative monoid induced by the addition operator is naturally ordered. When this monoid is a commutative monoid with monus, the semiring is called a **semiring with monus**, or **m-semiring**.

:::

## Examples {#Examples}

If $M$ is an [ideal](wikipedia://en/27799#Subsemigroups_and_ideals) in a [Boolean algebra](wikipedia://en/54476844), then $M$ is a commutative monoid with monus under $a + b = a \vee b$ and $a \mathbin{\dot{-}} b = a \wedge \neg b$.[^n2]

::: {#o20 .pointer-item cue=pointer name="Limited subtraction"}

### Natural numbers {#Natural_numbers}

The [natural numbers](wikipedia://en/21474) including 0 form a commutative monoid with monus, with their ordering being the usual order of natural numbers and the monus operator being a [saturating](https://en.wikipedia.org/wiki/Saturation_arithmetic) variant of standard subtraction, variously referred to as **truncated subtraction**,[^n5] **limited subtraction**, **proper subtraction**, **doz** (*difference or zero*),[^n6] and **monus**.[^n7] Truncated subtraction is usually defined as[^n5]

$$a \mathbin{\dot{-}} b = \begin{cases} 0 & \mbox{if } a < b \\ a - b & \mbox{if } a \ge b, \end{cases}$$

where − denotes standard [subtraction](wikipedia://en/74141). For example, $5 - 3 = 2$ and $3 - 5 = -2$ in regular subtraction, whereas in truncated subtraction $3 \mathbin{\dot{-}} 5 = 0$. Truncated subtraction may also be defined as[^n7]

$$a \mathbin{\dot{-}} b = \max(a - b, 0).$$

In [Peano arithmetic](wikipedia://en/25005), truncated subtraction is defined in terms of the predecessor function $P$ (the inverse of the [successor function](wikipedia://en/325637)):[^n5]

$$\begin{aligned} P(0) &= 0 \\ P(S(a)) &= a \\ a \mathbin{\dot{-}} 0 &= a \\ a \mathbin{\dot{-}} S(b) &= P(a \mathbin{\dot{-}} b). \end{aligned}$$

A definition that does not need the predecessor function is:

$$\begin{aligned} a \mathbin{\dot{-}} 0 &= a \\ 0 \mathbin{\dot{-}} b &= 0 \\ S(a) \mathbin{\dot{-}} S(b) &= a \mathbin{\dot{-}} b. \end{aligned}$$

Truncated subtraction is useful in contexts such as [primitive recursive functions](wikipedia://en/24829), which are not defined over negative numbers.[^n5] Truncated subtraction is also used in the definition of the [multiset](wikipedia://en/305303#Multiplicity_function) [difference](https://en.wikipedia.org/wiki/Set_difference) operator.

## Properties {#Properties}

The class of all commutative monoids with monus form a [variety](wikipedia://en/1021753).[^n2] The equational basis for the variety of all CMMs consists of the axioms for [commutative monoids](wikipedia://en/19652#Commutative_monoid), as well as the following axioms:

$$\begin{aligned} a + (b \mathbin{\dot{-}} a) &= b + (a \mathbin{\dot{-}} b),\\ (a \mathbin{\dot{-}} b) \mathbin{\dot{-}} c &= a \mathbin{\dot{-}} (b + c),\\ (a \mathbin{\dot{-}} a) &= 0,\\ (0 \mathbin{\dot{-}} a) &= 0.\\ \end{aligned}$$

:::
