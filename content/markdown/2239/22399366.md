# Symmetric Boolean function

::: {#o1 .subject cue=lead name="Symmetric Boolean function"}

In [mathematics](wikipedia://en/18831), a **symmetric Boolean function** is a [Boolean function](wikipedia://en/753349) whose value does not depend on the [order](wikipedia://en/44027) of its input bits, i.e., it depends only on the number of ones (or zeros) in the input.[^o2] For this reason they are also known as **Boolean counting functions**.[^o3]

:::

There are 2<sup>*n*+1</sup> symmetric *n*-ary Boolean functions. Instead of the [truth table](wikipedia://en/25512250), traditionally used to represent Boolean functions, one may use a more compact representation for an *n*-variable symmetric Boolean function: the (*n* + 1)-vector, whose *i*-th entry (*i* = 0, ..., *n*) is the value of the function on an input vector with *i* ones. Mathematically, the symmetric Boolean functions correspond one-to-one with the functions that map *n+1* elements to two elements, $f: \{0, 1, ..., n\} \rightarrow \{0, 1\}$.

Symmetric Boolean functions are used to classify [Boolean satisfiability problems](wikipedia://en/4715).

::: {#o5 .statement kind=statement/generalization cue=heading name="Special cases"}

## Special cases {#Special_cases}

A number of special cases are recognized:[^o2]

- **[Majority function](wikipedia://en/20823)**: their value is 1 on input vectors with more than n/2 ones
- **Threshold functions**: their value is 1 on input vectors with *k* or more ones for a fixed *k*
- **All-equal** and **not-all-equal function**: their values is 1 when the inputs do (not) all have the same value
- **Exact-count functions**: their value is 1 on input vectors with *k* ones for a fixed *k*
  - **[One-hot](https://en.wikipedia.org/wiki/One-hot)** or **1-in-n function**: their value is 1 on input vectors with exactly one one
  - **One-cold function**: their value is 1 on input vectors with exactly one zero
- **Congruence functions**: their value is 1 on input vectors with the number of ones congruent to *k* mod *m* for fixed *k*, *m*
- **[Parity function](wikipedia://en/22399369)**: their value is 1 if the input vector has odd number of ones

The n-ary versions of [AND](https://en.wikipedia.org/wiki/AND_gate), [OR](https://en.wikipedia.org/wiki/OR_gate), [XOR](https://en.wikipedia.org/wiki/XOR_gate), [NAND](https://en.wikipedia.org/wiki/NAND_gate), [NOR](https://en.wikipedia.org/wiki/NOR_gate) and [XNOR](https://en.wikipedia.org/wiki/XNOR_gate) are also symmetric Boolean functions.

:::

## Properties {#Properties}

In the following, $f_k$ denotes the value of the function $f: \{0, 1\}^n \rightarrow \{0, 1\}$ when applied to an input vector of [weight](wikipedia://en/1127884) $k$.

### Weight {#Weight}

The weight of the function can be calculated from its value vector:

$$|f| = \sum_{k=0}^n \binom{n}{k}f_k$$

### Algebraic normal form {#Algebraic_normal_form}

The [algebraic normal form](wikipedia://en/1048680) either contains all monomials of certain order $m$, or none of them; i.e. the [Möbius transform](https://en.wikipedia.org/wiki/Zhegalkin_polynomial#Möbius_transformation) $\hat f$ of the function is also a symmetric function. It can thus also be described by a simple (*n*+1) bit vector, the *ANF vector* $\hat f_m$. The ANF and value vectors are related by a Möbius relation:

$$\hat f_m = \bigoplus_{k_2 \subseteq m_2} f_k$$

where $k_2 \subseteq m_2$ denotes all the weights *k* whose [base-2](https://en.wikipedia.org/wiki/Base_2) representation is covered by the base-2 representation of *m* (a consequence of [Lucas’ theorem](wikipedia://en/7879246)).[^o10] Effectively, an n-variable symmetric Boolean function corresponds to a log(n)-variable ordinary [Boolean function](wikipedia://en/753349) acting on the base-2 representation of the input weight.

For example, for three-variable functions:

$$\begin{array}{lcl}\hat f_0 & = & f_0 \\ \hat f_1 & = & f_0 \oplus f_1 \\ \hat f_2 & = & f_0 \oplus f_2 \\ \hat f_3 & = & f_0 \oplus f_1 \oplus f_2 \oplus f_3 \end{array}$$

So the three variable [majority function](wikipedia://en/20823) with value vector (0, 0, 1, 1) has ANF vector (0, 0, 1, 0), i.e.:

$$\text{Maj}(x, y, z) = xy \oplus xz \oplus yz$$

### Unit hypercube polynomial {#Unit_hypercube_polynomial}

The coefficients of the real polynomial agreeing with the function on $\{0, 1\}^n$ are given by:

$$f^*_m = \sum_{k = 0}^m (-1)^{|k|+|m|} \binom{m}{k} f_k$$

For example, the three variable [majority function](wikipedia://en/20823) polynomial has coefficients (0, 0, 1, -2):

$$\text{Maj}(x, y, z) = (xy + xz + yz) -2(xyz)$$
