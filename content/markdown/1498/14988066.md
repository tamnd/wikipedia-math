# Knaster–Kuratowski fan

*Image: Kuratowski fan.svg.* The Knaster–Kuratowski fan

::: {#o1 .subject cue=lead name="Knaster–Kuratowski fan"}

In [topology](wikipedia://en/29954), a branch of mathematics, the **Knaster–Kuratowski fan** (named after Polish mathematicians [Bronisław Knaster](wikipedia://en/1003125) and [Kazimierz Kuratowski](wikipedia://en/46075)) is a specific [connected](wikipedia://en/6233) [topological space](wikipedia://en/30450) with the property that the removal of a single point makes it [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected). It is also known as **Cantor's leaky tent**[^n1] (after [Georg Cantor](wikipedia://en/12216)).

:::

The same space with the [apex](wikipedia://en/6022079) point removed is called the **punctured Knaster-Kuratowski fan** or **Cantor's [teepee](https://en.wikipedia.org/wiki/Teepee)**.[^n2]

::: {#o5 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

To construct the fan start with the [Cantor set](wikipedia://en/6172) which we will call $C$ along the x axis and a point at $\left(\tfrac1{2},\tfrac1{2}\right)$ which we will call $p$. Join every point in $C$ to $p$ with a straight line. We now have a set that is [connected](wikipedia://en/6233) and becomes disconnected if we remove $p$.

To make the set [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected) when we remove $p$ we need to remove more points. If we look at how the Cantor set $C$ was constructed we see that some points in $C$ like $\tfrac1{3}$ or 1 were the endpoints of [intervals](wikipedia://en/49172) we removed when constructing it and others like $\tfrac1{4}$ are not. We use this to decide which of the points we remove from every line. If the point at the bottom of a line (which will be part of $C$) is one of the points that was an end point of an interval we remove all coordinates with [irrational](wikipedia://en/20647689) y coordinates. Otherwise we remove all points on the line with [rational](wikipedia://en/19727024) y coordinates. This set is the Knaster–Kuratowski fan.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The fan is [connected](wikipedia://en/6233)[^o8] but becomes [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected) if we remove $p$.

The proof of connectedness (that you cannot divide the fan into 2 [open](wikipedia://en/39358) [disjoint](wikipedia://en/39359) sets) is not trivial but can be thought of as starting with $p$ in one of the sets and then having to add a little region around $p$ to make the set open. You then need to add a little region around each of the points you added making the set slightly bigger. This continues until the whole fan is in the set[^o9]

To show that the fan is totally disconnected when you remove $p$ you can start by noticing that each of the lines is now disconnected and then carry on splitting each of the lines down until you are left with individual points.[^o9]
