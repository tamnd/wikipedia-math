# Erdős space

::: {#o1 .subject cue=lead name="Erdős space"}

In [mathematics](wikipedia://en/18831), **Erdős space** is a [topological space](wikipedia://en/30450) named after [Paul Erdős](wikipedia://en/601284), who described it in 1940.[^o2] Erdős space is defined as a [subspace](wikipedia://en/910926) $E\subset\ell^2$ of the [Hilbert space](wikipedia://en/20598932) of square summable sequences, consisting of the sequences whose elements are all [rational numbers](wikipedia://en/19727024).

:::

Erdős space is a [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected), [one-dimensional](https://en.wikipedia.org/wiki/Dimension_theory) topological space.[^o2] The space $E$ is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to $E\times E$ in the [product topology](wikipedia://en/24910). If the set of all homeomorphisms of the [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$ (for $n\ge 2$) that leave invariant the set $\mathbb{Q}^n$ of rational vectors is endowed with the [compact-open topology](wikipedia://en/726335), it becomes homeomorphic to the Erdős space.[^o3]

Erdős space also surfaces in [complex dynamics](wikipedia://en/650518) via iteration of the function $f(z)=e^z-1$. Let $f^n$ denote the $n$-fold composition of $f$. The set of all points $z\in \mathbb C$ such that $\text{Im}(f^n(z))\to\infty$ is a collection of pairwise disjoint rays (homeomorphic copies of $[0,\infty)$), each joining an endpoint in $\mathbb C$ to the point at infinity. The set of finite endpoints is homeomorphic to Erdős space $E$.[^o4]
