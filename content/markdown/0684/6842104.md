# Galahad library

::: {#o1 .subject cue=lead name="Galahad library"}

The **Galahad library** is a [thread-safe](https://en.wikipedia.org/wiki/Thread_safety) [library](https://en.wikipedia.org/wiki/Library_%28computing%29) of packages for the solution of [mathematical optimization](wikipedia://en/52033) problems. The areas covered by the library are unconstrained and [bound-constrained optimization](wikipedia://en/4171950), [quadratic programming](wikipedia://en/40324), [nonlinear programming](wikipedia://en/679709), systems of nonlinear equations and inequalities, and [non-linear least squares](wikipedia://en/15652764) problems. The library is mostly written in the [Fortran 90](https://en.wikipedia.org/wiki/Fortran) programming language.

:::

The GALAHAD Library is authored and maintained by N.I.M. Gould, D. Orban and Ph.L. Toint.[^o2]

## Name {#Name}

The name of the library originates from its major package for general [nonlinear programming](wikipedia://en/679709), LANCELOT-B, the successor of the original [augmented Lagrangian](wikipedia://en/30898832) package LANCELOT of Conn, Gould and Toint.[^o4]

## Offered packages {#Offered_packages}

Other packages in the library include:

- a filter-based method for systems of linear and nonlinear equations and inequalities,
- an active-set method for nonconvex [quadratic programming](wikipedia://en/40324),
- a primal-dual interior-point method for nonconvex [quadratic programming](wikipedia://en/40324),
- a presolver for quadratic programs,
- a [Lanczos method](wikipedia://en/2593852) for trust-region subproblems,
- an interior-point method to solve [linear programs](wikipedia://en/43730) or separable [convex programs](wikipedia://en/1674411) or alternatively, to compute the analytic center of a set defined by such constraints, if it exists.

Packages in the GALAHAD library accept problems modeled in either the [Standard Input Format](https://en.wikipedia.org/wiki/Standard_Input_Format) (SIF),[^o6] or the [AMPL modeling language](https://en.wikipedia.org/wiki/AMPL). For problems modeled in the SIF, the GALAHAD library naturally relies upon the [CUTEr](https://en.wikipedia.org/wiki/CUTEr) package, an optimization toolbox providing all low-level functionalities required by solvers.

## Availability {#Availability}

The library is available on several popular computing platforms, including Compaq (DEC) Alpha, Cray, HP, IBM RS/6000, Intel-like PCs, SGI and Sun. It is designed to be easily adapted to other platforms. Support is provided for many operating systems, including [Tru64](https://en.wikipedia.org/wiki/Tru64), [Linux](https://en.wikipedia.org/wiki/Linux), [HP-UX](https://en.wikipedia.org/wiki/HP-UX), [AIX](https://en.wikipedia.org/wiki/AIX_%28operating_system%29), [IRIX](https://en.wikipedia.org/wiki/Irix) and [Solaris](https://en.wikipedia.org/wiki/Solaris_%28operating_system%29), and for a variety of popular [Fortran 90](https://en.wikipedia.org/wiki/Fortran) compilers on these platforms and operating systems.
