# Branch number

::: {#o1 .subject cue=lead name="Branch number"}

In [cryptography](wikipedia://en/18934432), the **branch number** is a numerical value that characterizes the amount of [diffusion](https://en.wikipedia.org/wiki/Diffusion_%28cryptography%29) introduced by a [vectorial Boolean function](https://en.wikipedia.org/wiki/Vectorial_Boolean_function) $F$ that maps an input vector $a$ to output vector $F(a)$. For the (usual[^n1]) case of a [linear](https://en.wikipedia.org/wiki/Linear_Boolean_function) $F$ the value of the *differential branch number* is produced by:

:::

1. applying nonzero values of $a$ (i.e., values that have at least one non-zero component of the vector) to the input of $F$;
1. calculating for each input value $a$ the [Hamming weight](wikipedia://en/1127884) $W$ (number of nonzero components), and adding weights $W(a)$ and $W(F(a))$ together;
1. selecting the smallest combined weight across for all nonzero input values: $B_d(F) = \underset {a \ne 0} {\min} (W(a) + W(F(a)))$.

If both $a$ and $F(a)$ have $s$ components, the result is obviously limited on the high side by the value $s+1$ (this "perfect" result is achieved when any single nonzero component in $a$ makes all components of $F(a)$ to be non-zero). A high branch number suggests higher resistance to the [differential cryptanalysis](wikipedia://en/8536): the small variations of input will produce large changes on the output and in order to obtain small variations of the output, large changes of the input value will be required.[^n2]

The term was introduced by [Daemen](https://en.wikipedia.org/wiki/Joan_Daemen) and [Rijmen](https://en.wikipedia.org/wiki/Vincent_Rijmen) in early 2000s and quickly became a typical tool to assess the diffusion properties of the transformations.[^n1]

## Mathematics {#Mathematics}

The branch number concept is not limited to the linear transformations, Daemen and Rijmen provided two general metrics:[^n3]

- **differential branch number**, where the minimum is obtained over inputs of $F$ that are constructed by independently sweeping all the values of two nonzero and unequal vectors $a$, $b$ ($\oplus$ is a component-by-component [exclusive-or](https://en.wikipedia.org/wiki/Exclusive-or)): $B_d(F) = \underset {a \ne b} {\min} (W(a \oplus b) + W(F(a) \oplus F(b))$;
- for **linear branch number**, the independent candidates $\alpha$ and $\beta$ are independently swept; they should be nonzero and correlated with respect to $F$ (the $LAT(\alpha,\beta)$ coefficient of the [linear approximation table](https://en.wikipedia.org/wiki/Linear_approximation_table) of $F$ should be nonzero): $B_l(F) = \underset {\alpha \ne 0,\beta,LAT(\alpha,\beta) \ne 0} {\min} (W(\alpha) + W(\beta))$.[^o7]
