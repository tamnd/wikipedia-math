# SC2000

::: {#o2 .subject cue=lead name="SC2000"}

In [cryptography](wikipedia://en/18934432), **SC2000** is a [block cipher](wikipedia://en/4594) invented by a research group at [Fujitsu](https://en.wikipedia.org/wiki/Fujitsu) Labs. It was submitted to the [NESSIE](wikipedia://en/497430) project, but was not selected. It was among the cryptographic techniques recommended for Japanese government use by [CRYPTREC](wikipedia://en/549159) in 2003; however, it was dropped to "candidate" by CRYPTREC revision in 2013.

:::

The algorithm uses a key size of 128, 192, or 256 bits. It operates on blocks of 128 bits using 6.5 or 7.5 rounds of encryption. Each round consists of [S-box](https://en.wikipedia.org/wiki/Substitution_box) lookups, key additions, and an unkeyed two-round [Feistel network](wikipedia://en/352709). There are 3 S-boxes: a 4×4-bit one used at the beginning of each round, a 5×5-bit one and a 6×6-bit one used in the Feistel network.

No [analysis](wikipedia://en/5715) of the full SC2000 has been announced, but a reduced version of 4.5 rounds is susceptible to [linear cryptanalysis](wikipedia://en/59469), and a reduced version of 5 rounds is susceptible to [differential cryptanalysis](wikipedia://en/8536).[^o3][^o4][^o5]

In 2014, [Alex Biryukov](wikipedia://en/9189491) and Ivica Nikolić found a weakness in the [key schedule](wikipedia://en/609603) of SC2000 which allows an attacker to find colliding keys which result in identical encryptions in just 2<sup>39</sup> time for 256 bit keys. They proved that there are 2<sup>68</sup> colliding key pairs and the whole set can be found in 2<sup>58</sup> time.[^o6]
