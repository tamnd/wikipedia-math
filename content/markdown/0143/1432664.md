# Choice function

::: {#o1 .subject cue=lead name="Choice function"}

Let *X* be a [set of sets](https://en.wikipedia.org/wiki/Set_of_sets) none of which are empty. Then a **choice function** (**selector**, **selection**) on *X* is a [mathematical function](https://en.wikipedia.org/wiki/Mathematical_function) *f* that is defined on *X* such that *f* is a mapping that assigns each element of *X* to one of its elements.

:::

::: {#o3 .example cue=heading name="An example"}

## An example {#An_example}

Let *X* = { {1,4,7}, {9}, {2,7} }. Then the function *f* defined by *f*({1, 4, 7}) = 7, *f*({9}) = 9 and *f*({2, 7}) = 2 is a choice function on *X*.

:::

## History and importance {#History_and_importance}

[Ernst Zermelo](wikipedia://en/178655) (1904) introduced choice functions as well as the [axiom of choice](wikipedia://en/840) (AC) and proved the [well-ordering theorem](wikipedia://en/33458),[^o5] which states that every set can be [well-ordered](https://en.wikipedia.org/wiki/Well_ordering). AC states that every set of nonempty sets has a choice function. A weaker form of AC, the [axiom of countable choice](wikipedia://en/421086) (AC<sub>ω</sub>) states that every [countable set](wikipedia://en/6026) of nonempty sets has a choice function. However, in the absence of either AC or AC<sub>ω</sub>, some sets can still be shown to have a choice function.

- If $X$ is a [finite](wikipedia://en/11742) set of nonempty sets, then one can construct a choice function for $X$ by picking one element from each member of $X.$ This requires only finitely many choices, so neither AC or AC<sub>ω</sub> is needed.
- If every member of $X$ is a nonempty set, and the [union](wikipedia://en/47949) $\bigcup X$ is well-ordered, then one may choose the least element of each member of $X$. In this case, it was possible to simultaneously well-order every member of $X$ by making just one choice of a well-order of the union, so neither AC nor AC<sub>ω</sub> was needed. (This example shows that the well-ordering theorem implies AC. The [converse](wikipedia://en/155941) is also true, but less trivial.)

## Choice function of a multivalued map {#Choice_function_of_a_multivalued_map}

Given two sets $X$ and $Y$, let $F$ be a [multivalued map](wikipedia://en/222367) from $X$ to $Y$ (equivalently, $F:X\rightarrow\mathcal{P}(Y)$ is a function from $X$ to the [power set](wikipedia://en/23799) of $Y$).

A function $f: X \rightarrow Y$ is said to be a **selection** of $F$, if:

$$\forall x \in X \, ( f(x) \in F(x) ) \,.$$

The existence of more regular choice functions, namely continuous or measurable selections is important in the theory of [differential inclusions](wikipedia://en/13725281), [optimal control](wikipedia://en/362565), and [mathematical economics](wikipedia://en/18967255).[^o7] See [Selection theorem](wikipedia://en/27035751).

A survey of selectors was published by [Claude Ambrose Rogers](wikipedia://en/33382489) and John E. Jayne in 2002.[^o8]

## Bourbaki tau function {#Bourbaki_tau_function}

[Nicolas Bourbaki](wikipedia://en/167394) used [epsilon calculus](wikipedia://en/11027904) for their foundations that had a $\tau$ symbol that could be interpreted as choosing an object (if one existed) that satisfies a given proposition. So if $P(x)$ is a predicate, then $\tau_{x}(P)$ is one particular object that satisfies $P$ (if one exists, otherwise it returns an arbitrary object). Hence we may obtain quantifiers from the choice function, for example $P( \tau_{x}(P))$ was equivalent to $(\exists x)(P(x))$.[^o10]

However, Bourbaki's choice operator is stronger than usual: it's a *global* choice operator. That is, it implies the [axiom of global choice](wikipedia://en/5322320).[^o11] Hilbert realized this when introducing epsilon calculus.[^o12]
