# Multiscroll attractor

*Image: DoubleScrollAttractor3D.svg.* A double-scroll Chen attractor from a simulation

::: {#o1 .subject cue=lead name="Multiscroll attractor"}

In the mathematics of [dynamical systems](wikipedia://en/9087), the **double-scroll attractor** (sometimes known as **Chua's attractor**) is a [strange attractor](https://en.wikipedia.org/wiki/Strange_attractor) observed from a physical electronic [chaotic](wikipedia://en/6295) circuit (generally, [Chua's circuit](https://en.wikipedia.org/wiki/Chua's_circuit)) with a single [nonlinear](wikipedia://en/146103) resistor (see [Chua's diode](https://en.wikipedia.org/wiki/Chua's_diode)). The double-scroll system is often described by a system of three nonlinear ordinary differential equations and a 3-segment piecewise-linear equation (see [Chua's equations](https://en.wikipedia.org/wiki/Chua's_circuit)). This makes the system easily simulated numerically and easily manifested physically due to Chua's circuits' simple design.

:::

Using a Chua's circuit, this shape is viewed on an oscilloscope using the X, Y, and Z output signals of the circuit. This chaotic attractor is known as the double scroll because of its shape in three-dimensional space, which is similar to two saturn-like rings connected by swirling lines.

The attractor was first observed in simulations, then realized physically after [Leon Chua](https://en.wikipedia.org/wiki/Leon_Chua) invented the [autonomous](https://en.wikipedia.org/wiki/Autonomous_circuit) chaotic circuit which became known as Chua's circuit.[^o2] The double-scroll attractor from the Chua circuit was rigorously proven to be chaotic[^o3] through a number of [Poincaré return maps](wikipedia://en/876732) of the attractor explicitly derived by way of compositions of the [eigenvectors](https://en.wikipedia.org/wiki/Eigenvector) of the 3-dimensional state space.[^o4]

Numerical analysis of the double-scroll attractor has shown that its geometrical structure is made up of an infinite number of fractal-like layers. Each cross section appears to be a [fractal](wikipedia://en/10913) at all scales.[^o5] Recently, there has also been reported the discovery of [hidden attractors](https://en.wikipedia.org/wiki/Hidden_oscillation) within the double scroll.[^o6]

In 1999 [Guanrong Chen](https://en.wikipedia.org/wiki/Chen_Guanrong) (陈关荣) and Ueta proposed another double scroll chaotic attractor, called the Chen system or Chen attractor.[^o7][^o8]

## Chen attractor {#Chen_attractor}

The Chen system is defined as follows[^o8]

$$\frac{dx(t)}{dt}=a(y(t)-x(t))$$

$$\frac{dy(t)}{dt}=(c-a)x(t)-x(t)z(t)+cy(t)$$

$$\frac{dz(t)}{dt}=x(t)y(t)-bz(t)$$

Plots of Chen attractor can be obtained with the [Runge-Kutta method](https://en.wikipedia.org/wiki/Runge-Kutta_method):[^o10]

initial conditions: x(0) = -0.1, y(0) = 0.5, z(0) = -0.6

## Other attractors {#Other_attractors}

Multiscroll attractors also called *n*-scroll attractor include the Lu Chen attractor, the modified Chen chaotic attractor, PWL Duffing attractor, [Rabinovich Fabrikant attractor](https://en.wikipedia.org/wiki/Rabinovich-Fabrikant_equation), modified Chua chaotic attractor, that is, multiple scrolls in a single attractor.[^o12]

### Lu Chen attractor {#Lu_Chen_attractor}

*Image: LuChenAttractor3D.svg.* Lu Chen Attractor

An extended Chen system with multiscroll was proposed by Jinhu Lu (吕金虎) and Guanrong Chen[^o12]

Lu Chen system equation

$$\frac{dx(t)}{dt}=a(y(t)-x(t))$$

$$\frac{dy(t)}{dt}=x(t)-x(t)z(t)+cy(t)+u$$

$$\frac{dz(t)}{dt}=x(t)y(t)-bz(t)$$

parameters：a = 36, c = 20, b = 3, u = -15.15

initial conditions：x(0) = .1, y(0) = .3, z(0) = -.6

### Modified Lu Chen attractor {#Modified_Lu_Chen_attractor}

*Image: LuChenAttractorModified3D.svg.* Lu Chen Attractor modified

System equations:[^o12]

$$\frac{dx(t)}{dt}=a(y(t)-x(t)),$$

$$\frac{dy(t)}{dt}=(c-a)x(t)-x(t)f+cy(t),$$

$$\frac{dz(t)}{dt}=x(t)y(t)-bz(t)$$

In which

$$f = d0z(t) + d1z(t - \tau ) - d2\sin(z(t - \tau ))$$

params := a = 35, c = 28, b = 3, d0 = 1, d1 = 1, d2 = -20..20, tau = .2

initv := x(0) = 1, y(0) = 1, z(0) = 14

### Modified Chua chaotic attractor {#Modified_Chua_chaotic_attractor}

*Image: ChuaAttractorModified.svg.* Chua Attractor

In 2001, Tang et al. proposed a modified Chua chaotic system[^o16]

$$\frac{dx(t)}{dt}= \alpha (y(t)-h)$$

$$\frac{dy(t)}{dt}=x(t)-y(t)+z(t)$$

$$\frac{dz(t)}{dt}=-\beta y(t)$$

In which

$$h := -b \sin\left(\frac{\pi x(t)}{2a}+d\right)$$

params := alpha = 10.82, beta = 14.286, a = 1.3, b = .11, c = 7, d = 0

initv := x(0) = 1, y(0) = 1, z(0) = 0

### PWL Duffing chaotic attractor {#PWL_Duffing_chaotic_attractor}

*Image: PWLDuffingAttractor.svg.* PWL Duffing Attractor

Aziz Alaoui investigated PWL Duffing equation in 2000:[^o18]

PWL Duffing system:

$$\frac{dx(t)}{dt}=y(t)$$

$$\frac{dy(t)}{dt}=-m_1x(t)-(1/2(m_0-m_1))(|x(t)+1|-|x(t)-1|)-ey(t)+\gamma \cos(\omega t)$$

params := e = .25, gamma = .14+(1/20)i, m0 = -0.845e-1, m1 = .66, omega = 1; c := (.14+(1/20)i)，i=-25...25;

initv := x(0) = 0, y(0) = 0;

### Modified Lorenz chaotic system {#Modified_Lorenz_chaotic_system}

*Image: LorenzModified3D.svg.* Lorenz system modified

Miranda & Stone proposed a modified Lorenz system:[^o20]

$\frac{dx(t)}{dt} = 1/3*(-(a+1)x(t)+a-c+z(t)y(t))+((1-a)(x(t)^2-y(t)^2)+(2(a+c-z(t)))x(t)y(t))$$\frac{1}{3\sqrt{x(t)^2+y(t)^2}}$

$\frac{dy(t)}{dt}= 1/3((c-a-z(t))x(t)-(a+1)y(t))+((2(a-1))x(t)y(t)+(a+c-z(t))(x(t)^2-y(t)^2))$$\frac{1}{3\sqrt{x(t)^2+y(t)^2}}$

$$\frac{dz(t)}{dt} = 1/2(3x(t)^2y(t)-y(t)^3)-bz(t)$$

parameters： a = 10, b = 8/3, c = 137/5;

initial conditions： x(0) = -8, y(0) = 4, z(0) = 10
