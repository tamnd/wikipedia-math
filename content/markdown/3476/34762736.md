# Open Web Analytics

::: {#o2 .subject cue=lead name="Open Web Analytics"}

**Open Web Analytics (OWA)** is [open-source](https://en.wikipedia.org/wiki/Open-source_software) web analytics software created by Peter Adams.

:::

OWA is written in [PHP](https://en.wikipedia.org/wiki/PHP) and uses a [MySQL](https://en.wikipedia.org/wiki/MySQL) database, which makes it compatible for running with an [AMP](https://en.wikipedia.org/wiki/List_of_AMP_packages) [solution stack](https://en.wikipedia.org/wiki/Solution_stack) on various [web servers](https://en.wikipedia.org/wiki/Web_server).[^o3]

## Overview {#Overview}

OWA is comparable to [Google Analytics](https://en.wikipedia.org/wiki/Google_Analytics), though OWA is server software anyone can install and run on their own host, while Google Analytics is a [software service](https://en.wikipedia.org/wiki/Software_as_a_service) offered by Google.[^o5]

OWA supports tracking with [WordPress](https://en.wikipedia.org/wiki/WordPress) and [MediaWiki](https://en.wikipedia.org/wiki/MediaWiki), two popular website frameworks.[^o6] This application helps [webmasters](https://en.wikipedia.org/wiki/Webmaster) keep track of and observe the influx of views on their websites.[^o7]

The program also tracks the websites of competitors and their company's growth compared to the site in question.[^o8]
