# Polynomially reflexive space

::: {#o1 .subject cue=lead name="Polynomially reflexive space"}

In [mathematics](wikipedia://en/18831), a **polynomially reflexive space** is a [Banach space](wikipedia://en/3989) *X*, on which the space of all polynomials in each degree is a [reflexive space](wikipedia://en/210091).

:::

Given a [multilinear](wikipedia://en/221525) [functional](wikipedia://en/1374948) *M*<sub>*n*</sub> of degree *n* (that is, *M*<sub>*n*</sub> is *n*-linear), we can define a polynomial *p* as

$$p(x)=M_n(x,\dots,x)$$

(that is, applying *M*<sub>*n*</sub> on the *[diagonal](wikipedia://en/349251)*) or any finite sum of these. If only *n*-linear functionals are in the sum, the polynomial is said to be *n*-homogeneous.

We define the space *P*<sub>*n*</sub> as consisting of all *n*-homogeneous polynomials.

The *P*<sub>1</sub> is identical to the [dual space](wikipedia://en/7988), and is thus reflexive for all reflexive *X*. This implies that reflexivity is a prerequisite for polynomial reflexivity.

## Relation to continuity of forms {#Relation_to_continuity_of_forms}

On a finite-dimensional linear space, a [quadratic form](wikipedia://en/251478) *x*↦*f*(*x*) is always a (finite) linear combination of products *x*↦*g*(*x*) *h*(*x*) of two [linear functionals](https://en.wikipedia.org/wiki/Linear_functional) *g* and *h*. Therefore, assuming that the scalars are complex numbers, every sequence *x<sub>n</sub>* satisfying *g*(*x<sub>n</sub>*) → 0 for all linear functionals *g*, satisfies also *f*(*x<sub>n</sub>*) → 0 for all quadratic forms *f*.

In infinite dimension the situation is different. For example, in a [Hilbert space](wikipedia://en/20598932), an [orthonormal](https://en.wikipedia.org/wiki/Orthonormal) sequence *x<sub>n</sub>* [satisfies](wikipedia://en/2119266#Weak_convergence_of_orthonormal_sequences) *g*(*x<sub>n</sub>*) → 0 for all linear functionals *g*, and nevertheless *f*(*x<sub>n</sub>*) = 1 where *f* is the quadratic form *f*(*x*) = ||*x*||<sup>2</sup>. In more technical words, this quadratic form fails to be [weakly](wikipedia://en/2119266) [sequentially continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29#Sequences_and_nets) at the origin.

On a [reflexive](wikipedia://en/210091) [Banach space](wikipedia://en/3989) with the [approximation property](wikipedia://en/628962) the following two conditions are equivalent:[^o3]

- every quadratic form is weakly sequentially continuous at the origin;
- the Banach space of all quadratic forms is reflexive.

Quadratic forms are 2-homogeneous polynomials. The equivalence mentioned above holds also for *n*-homogeneous polynomials, *n*=3,4,...

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

For the $\ell^p$ [spaces](wikipedia://en/45194), the *P*<sub>*n*</sub> is reflexive if and only if $n$ \< $p$. Thus, no $\ell^p$ is polynomially reflexive. ($\ell^\infty$ is ruled out because it is not reflexive.)

Thus if a Banach space admits $\ell^p$ as a [quotient space](wikipedia://en/898784), it is not polynomially reflexive. This makes polynomially reflexive spaces rare.

The [Tsirelson space](wikipedia://en/628352) *T*\* is polynomially reflexive.[^o6]

:::
