# Log-Cauchy distribution

::: {#o1 .subject cue=lead name="Log-Cauchy distribution"}

In probability theory, a **log-Cauchy distribution** is a [probability distribution](wikipedia://en/23543) of a [random variable](wikipedia://en/25685) whose [logarithm](wikipedia://en/17860) is distributed in accordance with a [Cauchy distribution](wikipedia://en/7003). If *X* is a random variable with a Cauchy distribution, then *Y* = [exp(*X*)](wikipedia://en/9678) has a log-Cauchy distribution; likewise, if *Y* has a log-Cauchy distribution, then *X* = log(*Y*) has a Cauchy distribution.[^o6]

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Characterization"}

## Characterization {#Characterization}

The log-Cauchy distribution is a special case of the [log-t distribution](wikipedia://en/70445407) where the [degrees of freedom](wikipedia://en/176622) parameter is equal to 1.[^o4]

### Probability density function {#Probability_density_function}

The log-Cauchy distribution has the [probability density function](wikipedia://en/43487):

$$\begin{aligned} f(x; \mu,\sigma) & = \frac{1}{x\pi\sigma \left[1 + \left(\frac{\ln x - \mu}{\sigma}\right)^2\right]}, \ \ x>0 \\ & = { 1 \over x\pi } \left[ { \sigma \over (\ln x - \mu)^2 + \sigma^2 } \right], \ \ x>0 \end{aligned}$$

where $\mu$ is a [real number](wikipedia://en/20646438) and $\sigma >0$.[^o6][^o7] If $\sigma$ is known, the [scale parameter](wikipedia://en/769503) is $e^{\mu}$.[^o6] $\mu$ and $\sigma$ correspond to the [location parameter](wikipedia://en/17516) and [scale parameter](wikipedia://en/769503) of the associated Cauchy distribution.[^o6][^o8] Some authors define $\mu$ and $\sigma$ as the [location](wikipedia://en/17516) and scale parameters, respectively, of the log-Cauchy distribution.[^o8]

For $\mu = 0$ and $\sigma =1$, corresponding to a standard Cauchy distribution, the probability density function reduces to:[^o16]

$$f(x; 0,1) = \frac{1}{x\pi [1 + (\ln x)^2]}, \ \ x>0$$

### Cumulative distribution function {#Cumulative_distribution_function}

The cumulative distribution function ([cdf](wikipedia://en/5793)) when $\mu = 0$ and $\sigma =1$ is:[^o16]

$$F(x; 0, 1)=\frac{1}{2} + \frac{1}{\pi} \arctan(\ln x), \ \ x>0$$

### Survival function {#Survival_function}

The [survival function](wikipedia://en/30876757) when $\mu = 0$ and $\sigma =1$ is:[^o16]

$$S(x; 0, 1)=\frac{1}{2} - \frac{1}{\pi} \arctan(\ln x), \ \ x>0$$

### Hazard rate {#Hazard_rate}

The [hazard rate](https://en.wikipedia.org/wiki/Hazard_rate) when $\mu = 0$ and $\sigma =1$ is:[^o16]

$$\lambda(x; 0,1) = \left\{\frac{1}{x\pi \left[1 + \left(\ln x\right)^2\right]} \left[\frac{1}{2} - \frac{1}{\pi} \arctan(\ln x)\right]\right\}^{-1}, \ \ x>0$$

The hazard rate decreases at the beginning and at the end of the distribution, but there may be an interval over which the hazard rate increases.[^o16]

:::

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The log-Cauchy distribution is an example of a [heavy-tailed distribution](wikipedia://en/8092200).[^o14] Some authors regard it as a "super-heavy tailed" distribution, because it has a heavier tail than a [Pareto distribution](wikipedia://en/53057)-type heavy tail, i.e., it has a [logarithmically decaying](wikipedia://en/4001300) tail.[^o14][^o15] As with the Cauchy distribution, none of the non-trivial [moments](wikipedia://en/368684) of the log-Cauchy distribution are finite.[^o16] The [mean](https://en.wikipedia.org/wiki/Mean) is a moment so the log-Cauchy distribution does not have a defined mean or [standard deviation](wikipedia://en/27590).[^o17][^o18]

The log-Cauchy distribution is [infinitely divisible](wikipedia://en/13588803) for some parameters but not for others.[^o19] Like the [lognormal distribution](https://en.wikipedia.org/wiki/Lognormal_distribution), [log-t or log-Student distribution](wikipedia://en/70445407) and [Weibull distribution](wikipedia://en/206948), the log-Cauchy distribution is a special case of the [generalized beta distribution of the second kind](wikipedia://en/36221287#Generalized_beta_of_the_second_kind_.28GB2.29).[^o20][^o21] The log-Cauchy is actually a special case of the log-t distribution, similar to the Cauchy distribution being a special case of the [Student's t distribution](https://en.wikipedia.org/wiki/Student's_t_distribution) with 1 degree of freedom.[^o22][^o23]

Since the Cauchy distribution is a [stable distribution](wikipedia://en/1117869), the log-Cauchy distribution is a logstable distribution.[^o24] Logstable distributions have [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) at x=0.[^o23]

:::

## Estimating parameters {#Estimating_parameters}

The [median](wikipedia://en/18837) of the [natural logarithms](wikipedia://en/21476) of a [sample](https://en.wikipedia.org/wiki/Sample_%28statistics%29) is a [robust estimator](https://en.wikipedia.org/wiki/Robust_estimator) of $\mu$.[^o6] The [median absolute deviation](wikipedia://en/10050999) of the natural logarithms of a sample is a robust estimator of $\sigma$.[^o6]

::: {#o27 .application cue=heading name="Uses"}

## Uses {#Uses}

In [Bayesian statistics](wikipedia://en/404412), the log-Cauchy distribution can be used to approximate the [improper](https://en.wikipedia.org/wiki/Improper_prior) [Jeffreys](https://en.wikipedia.org/wiki/Harold_Jeffreys)-Haldane density, 1/k, which is sometimes suggested as the [prior distribution](https://en.wikipedia.org/wiki/Prior_distribution) for k where k is a positive parameter being estimated.[^o28][^o29] The log-Cauchy distribution can be used to model certain survival processes where significant [outliers](wikipedia://en/160951) or extreme results may occur.[^o7][^o8][^o30] An example of a process where a log-Cauchy distribution may be an appropriate model is the time between someone becoming infected with [HIV](https://en.wikipedia.org/wiki/HIV) and showing symptoms of the disease, which may be very long for some people.[^o8] It has also been proposed as a model for [species abundance](https://en.wikipedia.org/wiki/Species_abundance) patterns.[^o31]

:::
