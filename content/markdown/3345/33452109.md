# Quasi-relative interior

::: {#o1 .subject cue=lead name="Quasi-relative interior"}

In [topology](wikipedia://en/29954), a branch of mathematics, the **quasi-relative interior** of a subset of a [vector space](wikipedia://en/32370) is a refinement of the concept of the [interior](wikipedia://en/55610). Formally, if $X$ is a [linear space](wikipedia://en/32370) then the quasi-relative interior of $A \subseteq X$ is

$$\operatorname{qri}(A) := \left\{x \in A : \operatorname{\overline{cone}}(A - x) \text{ is a linear subspace}\right\}$$

where $\operatorname{\overline{cone}}(\cdot)$ denotes the [closure](wikipedia://en/42309) of the [conic hull](https://en.wikipedia.org/wiki/Conic_hull).[^n1]

:::

Let $X$ be a [normed](https://en.wikipedia.org/wiki/Normed_space) vector space. If $C \subseteq X$ is a [convex](wikipedia://en/6292) [finite-dimensional](https://en.wikipedia.org/wiki/Finite-dimensional) set then $\operatorname{qri}(C) = \operatorname{ri}(C)$ such that $\operatorname{ri}$ is the [relative interior](wikipedia://en/8612907).[^o3]
