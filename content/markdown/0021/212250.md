# Homotopy

::: {#o1 .subject cue=lead name="Homotopy"}

*Image: HomotopySmall.gif.* The two dashed [paths](wikipedia://en/1189553) shown above are homotopic relative to their endpoints. The animation represents one possible homotopy.

In [topology](wikipedia://en/29954), two [continuous functions](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) from one [topological space](wikipedia://en/30450) to another are called **homotopic** (from ὁμός grc same, similar and τόπος grc place) if one can be "continuously deformed" into the other, such a deformation being called a **homotopy** ([^o2] ; [^o3] ) between the two functions. A notable use of homotopy is the definition of [homotopy groups](https://en.wikipedia.org/wiki/Homotopy_groups) and [cohomotopy groups](https://en.wikipedia.org/wiki/Cohomotopy_groups), important [invariants](wikipedia://en/1126638) in [algebraic topology](wikipedia://en/38801).[^o4]

:::

In practice, there are technical difficulties in using homotopies with certain spaces. Algebraic topologists work with [compactly generated spaces](wikipedia://en/899382), [CW complexes](wikipedia://en/353022), or [spectra](https://en.wikipedia.org/wiki/Spectrum_%28homotopy_theory%29).

::: {#o6 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

*Image: Mug and Torus morph.gif.* A homotopy and its inverse, between two [embeddings](wikipedia://en/52119) of the [torus](wikipedia://en/74800) into $\mathbb{R}^3$: as "the surface of a doughnut" and as "the surface of a coffee mug". This is also an example of an isotopy.

Formally, a homotopy between two [continuous functions](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) *f* and *g* from a topological space *X* to a topological space *Y* is defined to be a [continuous function](wikipedia://en/39783039#Continuity_and_limit) $H: X \times [0,1] \to Y$ from the [product](wikipedia://en/24910) of the space *X* with the [unit interval](wikipedia://en/49324) \[0, 1\] to *Y* such that $H(x,0) = f(x)$ and $H(x,1) = g(x)$ for all $x \in X$.

If we think of the second [parameter](wikipedia://en/25065) of *H* as time, then *H* describes a *continuous deformation* of *f* into *g*: at time 0, we have the function *f*, and at time 1, we have the function *g*. We can also think of the second parameter as a "slider control" that allows us to smoothly transition from *f* to *g* as the slider moves from 0 to 1, and vice versa.

An alternative notation is to say that a homotopy between two continuous functions $f, g: X \to Y$ is a family of continuous functions $h_t: X \to Y$ for $t \in [0,1]$ such that $h_0 = f$ and $h_1 = g$, and the [map](wikipedia://en/516931) $(x, t) \mapsto h_t(x)$ is continuous from $X \times [0,1]$ to $Y$. The two versions coincide by setting $h_t(x) = H(x,t)$. It is not sufficient to require each map $h_t(x)$ to be continuous.[^o7]

The animation that is shown in this section provides an example of a homotopy between two [embeddings](wikipedia://en/52119), *f* and *g*, of the [torus](wikipedia://en/74800) into *R*<sup>3</sup>. *X* is the torus, *Y* is *R*<sup>3</sup>, *f* is some continuous function from the torus to *R*<sup>3</sup> that takes the torus to the embedded surface-of-a-doughnut shape with which the animation starts; *g* is some continuous function that takes the torus to the embedded surface-of-a-coffee-mug shape. The animation shows the image of *h*<sub>*t*</sub>(X) as a function of the parameter *t*, where *t* varies with time from 0 to 1 over each cycle of the animation loop. It pauses, then shows the image as *t* varies back from 1 to 0, pauses, and repeats this cycle.

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

Continuous functions *f* and *g* are said to be homotopic if and only if there is a homotopy *H* taking *f* to *g* as described above. Being homotopic is an [equivalence relation](wikipedia://en/9259) on the set of all continuous functions from *X* to *Y*. This homotopy relation is compatible with [function composition](wikipedia://en/195947) in the following sense: if *f*<sub>1</sub>, *g*<sub>1</sub> : *X* → *Y* are homotopic, and *f*<sub>2</sub>, *g*<sub>2</sub> : *Y* → *Z* are homotopic, then their compositions *f*<sub>2</sub> ∘ *f*<sub>1</sub> and *g*<sub>2</sub> ∘ *g*<sub>1</sub> : *X* → *Z* are also homotopic.

## Examples {#Examples}

- If $f, g: \mathbb{R} \to \mathbb{R}^2$ are given by $f(x) := \left(x, x^3\right)$ and $g(x) = \left(x, e^x\right)$, then the map $H: \mathbb{R} \times [0, 1] \to \mathbb{R}^2$ given by $H(x, t) = \left(x, (1 - t)x^3 + te^x\right)$ is a homotopy between them.
- More generally, if $C \subseteq \mathbb{R}^n$ is a [convex](wikipedia://en/6292) subset of [Euclidean space](wikipedia://en/9697) and $f, g: [0, 1] \to C$ are [paths](wikipedia://en/1189553) with the same endpoints, then there is a **linear homotopy**[^o12] (or **straight-line homotopy**) given by

$$\begin{aligned} H: [0, 1] \times [0, 1] &\longrightarrow C \\ (s, t) &\longmapsto (1 - t)f(s) + tg(s). \end{aligned}$$

- Let $\operatorname{id}_{B^n}:B^n\to B^n$ be the [identity function](wikipedia://en/15069) on the unit *n*-[disk](wikipedia://en/160556); i.e. the set $B^n := \left\{x\in\mathbb{R}^n: \|x\| \leq 1\right\}$. Let $c_{\vec{0}}: B^n \to B^n$ be the [constant function](wikipedia://en/320861) $c_\vec{0}(x) := \vec{0}$ which sends every point to the [origin](wikipedia://en/1313432). Then the following is a homotopy between them:

$$\begin{aligned} H: B^n \times [0, 1] &\longrightarrow B^n \\ (x, t) &\longmapsto (1 - t)x. \end{aligned}$$

:::

## Homotopy equivalence {#Homotopy_equivalence}

Given two topological spaces *X* and *Y*, a **homotopy equivalence** between *X* and *Y* is a pair of continuous [maps](wikipedia://en/516931) *f* : *X* → *Y* and *g* : *Y* → *X*, such that *g* ∘ *f* is homotopic to the [identity map](wikipedia://en/15069) id<sub>*X*</sub> and *f* ∘ *g* is homotopic to id<sub>*Y*</sub>. If such a pair exists, then *X* and *Y* are said to be **homotopy equivalent**, or of the same **homotopy type**. This relation of homotopy equivalence is often denoted $\simeq$.[^o14] Intuitively, two spaces *X* and *Y* are homotopy equivalent if they can be transformed into one another by bending, shrinking and expanding operations. Spaces that are homotopy equivalent to a point are called [contractible](https://en.wikipedia.org/wiki/Contractible).

### Homotopy equivalence vs. homeomorphism {#Homotopy_equivalence_vs._homeomorphism}

A [homeomorphism](wikipedia://en/13660) is a special case of a homotopy equivalence, in which *g* ∘ *f* is equal to the identity map id<sub>*X*</sub> (not only homotopic to it), and *f* ∘ *g* is equal to id<sub>*Y*</sub>.[^o16] Therefore, if X and Y are homeomorphic, then they are homotopy equivalent, but the converse is not necessarily true. Some examples:

- A solid disk is homotopy equivalent to a single point, since you can deform the disk along radial lines continuously to a single point; however, they are not homeomorphic, since there is no [bijection](wikipedia://en/3942) between them (since one is an infinite set, while the other is finite).
- The [Möbius strip](wikipedia://en/37817) and an untwisted (closed) strip are homotopy equivalent, since you can deform both strips continuously to a circle. But they are not homeomorphic.

::: {#o18 .example cue=heading name="Examples"}

### Examples {#Examples}

- The first example of a homotopy equivalence is $\mathbb{R}^n$ with a point, denoted $\mathbb{R}^n \simeq \{ 0\}$. The part that needs to be checked is the existence of a homotopy $H: I \times \mathbb{R}^n \to \mathbb{R}^n$ between $\operatorname{id}_{\mathbb{R}^n}$ and $p_0$, the projection of $\mathbb{R}^n$ onto the origin. This can be described as $H(t,\cdot) = t\cdot p_0 + (1-t)\cdot\operatorname{id}_{\mathbb{R}^n}$.
- There is a homotopy equivalence between $S^1$ (the [1-sphere](wikipedia://en/39782)) and $\mathbb{R}^2-\{0\}$.
  - More generally, $\mathbb{R}^n-\{ 0\} \simeq S^{n-1}$.
- Any [fiber bundle](wikipedia://en/276526) $\pi: E \to B$ with fibers $F_b$ homotopy equivalent to a point has homotopy-equivalent total and base spaces. This generalizes the previous two examples since $\pi:\mathbb{R}^n - \{0\} \to S^{n-1}$ is a fiber bundle with fiber $\mathbb{R}_{>0}$.
- Every [vector bundle](wikipedia://en/276524) is a fiber bundle with a fiber homotopy equivalent to a point.
- $\mathbb{R}^n - \mathbb{R}^k \simeq S^{n-k-1}$ for any $0 \le k < n$, by writing $\mathbb{R}^n - \mathbb{R}^k$ as the total space of the fiber bundle $\mathbb{R}^k \times (\mathbb{R}^{n-k}-\{0\})\to (\mathbb{R}^{n-k}-\{0\})$, then applying the homotopy equivalences above.
- If a subcomplex $A$ of a [CW complex](wikipedia://en/353022) $X$ is contractible, then the [quotient space](wikipedia://en/237213) $X/A$ is homotopy equivalent to $X$.[^o19]
- A [deformation retraction](https://en.wikipedia.org/wiki/Deformation_retraction) is a homotopy equivalence.

:::

### Null-homotopy {#Null-homotopy}

A function $f$ is said to be **null-homotopic** if it is homotopic to a constant function. (The homotopy from $f$ to a constant function is then sometimes called a **null-homotopy**.) For example, a map $f$ from the [unit circle](wikipedia://en/27072071) $S^1$ to any space $X$ is null-homotopic precisely when it can be continuously extended to a map from the [unit disk](wikipedia://en/252738) $D^2$ to $X$ that agrees with $f$ on the boundary.

It follows from these definitions that a space $X$ is contractible if and only if the identity map from $X$ to itself—which is always a homotopy equivalence—is null-homotopic.

::: {#o22 .pointer-item cue=pointer name="Homotopy invariant"}

## Invariance {#Invariance}

Homotopy equivalence is important because in [algebraic topology](wikipedia://en/38801) many concepts are **homotopy invariant**, that is, they respect the relation of homotopy equivalence. For example, if *X* and *Y* are homotopy equivalent spaces, then:

- *X* is [path-connected](wikipedia://en/6233) if and only if *Y* is.
- *X* is [simply connected](https://en.wikipedia.org/wiki/Simply_connected) if and only if *Y* is.
- The (singular) [homology](wikipedia://en/142432) and [cohomology groups](https://en.wikipedia.org/wiki/Cohomology_group) of *X* and *Y* are [isomorphic](wikipedia://en/12397).
- If *X* and *Y* are path-connected, then the [fundamental groups](wikipedia://en/11004) of *X* and *Y* are isomorphic, and so are the higher [homotopy groups](wikipedia://en/297506). (Without the path-connectedness assumption, one has π<sub>1</sub>(*X*, *x*<sub>0</sub>) isomorphic to π<sub>1</sub>(*Y*, *f*(*x*<sub>0</sub>)) where *f* : *X* → *Y* is a homotopy equivalence and *x*<sub>0</sub> ∈ *X*.)

An example of an algebraic invariant of topological spaces which is not homotopy invariant is [compactly supported homology](wikipedia://en/2574552) (which is, roughly speaking, the homology of the [compactification](wikipedia://en/6617), and compactification is not homotopy invariant).

:::

## Variants {#Variants}

::: {#o26 .pointer-item cue=pointer name="Homotopy retract"}

### Relative homotopy {#Relative_homotopy}

In order to define the [fundamental group](wikipedia://en/11004), one needs the notion of **homotopy relative to a subspace**. These are homotopies which keep the elements of the subspace fixed. Formally: if *f* and *g* are continuous maps from *X* to *Y* and *K* is a [subset](wikipedia://en/27631) of *X*, then we say that *f* and *g* are homotopic relative to *K* if there exists a homotopy *H* : *X* × \[0, 1\] → *Y* between *f* and *g* such that *H*(*k*, *t*) = *f*(*k*) = *g*(*k*) for all *k* ∈ *K* and *t* ∈ \[0, 1\]. Also, if *g* is a [retraction](wikipedia://en/2120001) from *X* to *K* and *f* is the identity map, this is known as a strong [deformation retract](https://en.wikipedia.org/wiki/Deformation_retract) of *X* to *K*. When *K* is a point, the term **pointed homotopy** is used.

:::

::: {#o28 .pointer-item cue=pointer name="Isotopy (topology)"}

### Isotopy {#Isotopy}

When two given continuous functions *f* and *g* from the topological space *X* to the topological space *Y* are [embeddings](wikipedia://en/52119), one can ask whether they can be connected 'through embeddings'. This gives rise to the concept of **isotopy**, which is a homotopy, *H*, in the notation used before, such that for each fixed *t*, *H*(*x*, *t*) gives an embedding.

A related, but separate, concept is that of [ambient isotopy](wikipedia://en/7404467).

Requiring that two embeddings be isotopic is a stronger requirement than that they be homotopic. For example, the map from the interval \[−1, 1\] into the real numbers defined by *f*(*x*) = −*x* is *not* isotopic to the identity *g*(*x*) = *x*. Any homotopy from *f* to the identity would have to exchange the endpoints, which would mean that they would have to 'pass through' each other. Moreover, *f* has changed the orientation of the interval and *g* has not, which is impossible under an isotopy. However, the maps are homotopic; one homotopy from *f* to the identity is *H*: \[−1, 1\] × \[0, 1\] → \[−1, 1\] given by *H*(*x*, *y*) = 2*yx* − *x*.

Two homeomorphisms (which are special cases of embeddings) of the unit ball which agree on the boundary can be shown to be isotopic using [Alexander's trick](wikipedia://en/2846775). For this reason, the map of the [unit disc](https://en.wikipedia.org/wiki/Unit_disc) in $\mathbb{R}^2$ defined by *f*(*x*, *y*) = (−*x*, −*y*) is isotopic to a 180-degree [rotation](wikipedia://en/39789) around the origin, and so the identity map and *f* are isotopic because they can be connected by rotations.

In [geometric topology](wikipedia://en/621732)—for example, in [knot theory](wikipedia://en/153008)—the idea of isotopy is used to construct equivalence relations. For example, when should two knots be considered the same? We take two knots, *K*<sub>1</sub> and *K*<sub>2</sub>, in three-[dimensional](wikipedia://en/8398) space. A knot is an [embedding](wikipedia://en/52119) of a one-dimensional space, the "loop of string" (or the circle), into this space, and this embedding gives a homeomorphism between the circle and its image in the embedding space. One may try to define knot equivalence based on isotopy instead of the more restricted property of [ambient isotopy](wikipedia://en/7404467). That is, two knots are isotopic when there exists a continuous function starting at *t* = 0 giving the *K*<sub>1</sub> embedding, ending at *t* = 1 giving the *K*<sub>2</sub> embedding, with all intermediate values corresponding to embeddings. However, this definition would make every knot equivalent to the unknot, as the knotted portions can be "contracted" down to a straight line. The problem is that, while continuous, this is not an injective function of the [Euclidean space](wikipedia://en/9697) that the knot is embedded in. An [ambient isotopy](wikipedia://en/7404467), studied in this context, is an isotopy of the larger space, considered in light of its action on the embedded submanifold. Knots *K*<sub>1</sub> and *K*<sub>2</sub> are considered equivalent when there is a continuous \[0, 1\]-indexed family of maps which moves *K*<sub>1</sub> to *K*<sub>2</sub> via homeomorphisms of the Euclidean space.

Similar language is used for the equivalent concept in contexts where one has a stronger notion of equivalence. For example, a path between two smooth embeddings is a **smooth isotopy**.

:::

### Timelike homotopy {#Timelike_homotopy}

On a [Lorentzian manifold](https://en.wikipedia.org/wiki/Lorentzian_manifold), certain curves are distinguished as [timelike](https://en.wikipedia.org/wiki/Timelike) (representing something that only goes forwards, not backwards, in time, in every local frame). A [timelike homotopy](wikipedia://en/6905183) between two [timelike curves](https://en.wikipedia.org/wiki/Timelike_curve) is a homotopy such that the curve remains timelike during the continuous transformation from one curve to another. No [closed timelike curve](wikipedia://en/287091) (CTC) on a Lorentzian manifold is timelike homotopic to a point (that is, null timelike homotopic); such a manifold is therefore said to be [multiply connected](https://en.wikipedia.org/wiki/Multiply_connected) by timelike curves. A manifold such as the [3-sphere](wikipedia://en/39792) can be [simply connected](https://en.wikipedia.org/wiki/Simply_connected) (by any type of curve), and yet be [timelike multiply connected](https://en.wikipedia.org/wiki/Timelike_multiply_connected).[^o31]

:::

## Properties {#Properties}

### Lifting and extension properties {#Lifting_and_extension_properties}

If we have a homotopy $H:X\times [0,1]\rightarrow Y$ and a cover $p:\overline Y\rightarrow Y$ and we are given a map $\overline h_0:X\rightarrow \overline Y$ such that $H_0=P \circ \overline h_0$ ($\overline h_0$ is called a [lift](wikipedia://en/10504570) of $h_0$), then we can lift all $H$ to a map $\overline H: X \times [0,1]\rightarrow \overline Y$ such that $p \circ \overline H = H$. The homotopy lifting property is used to characterize [fibrations](wikipedia://en/316826).

Another useful property involving homotopy is the [homotopy extension property](wikipedia://en/4029308), which characterizes the extension of a homotopy between two functions from a subset of some set to the set itself. It is useful when dealing with [cofibrations](wikipedia://en/1697216).

### Groups {#Groups}

Since the relation of two functions $f, g\colon X\to Y$ being homotopic relative to a subspace is an equivalence relation, we can look at the [equivalence classes](wikipedia://en/9260) of maps between a fixed *X* and *Y*. If we fix $X = [0,1]^n$, the unit interval \[0, 1\] [crossed](wikipedia://en/24104095) with itself *n* times, and we take its [boundary](wikipedia://en/72824) $\partial([0,1]^n)$ as a subspace, then the equivalence classes form a group, denoted $\pi_n(Y,y_0)$, where $y_0$ is in the image of the subspace $\partial([0,1]^n)$.

We can define the action of one equivalence class on another, and so we get a group. These groups are called the [homotopy groups](wikipedia://en/297506). In the case $n = 1$, it is also called the [fundamental group](wikipedia://en/11004).

### Homotopy category {#Homotopy_category}

The idea of homotopy can be turned into a formal category of [category theory](wikipedia://en/5869). The **[homotopy category](wikipedia://en/2040756)** is the category whose objects are topological spaces, and whose morphisms are homotopy equivalence classes of continuous maps. Two topological spaces *X* and *Y* are isomorphic in this category if and only if they are homotopy equivalent. Then a [functor](wikipedia://en/10987) on the category of topological spaces is homotopy invariant if it can be expressed as a functor on the homotopy category.

For example, homology groups are a *functorial* homotopy invariant: this means that if *f* and *g* from *X* to *Y* are homotopic, then the [group homomorphisms](wikipedia://en/12396) induced by *f* and *g* on the level of [homology groups](https://en.wikipedia.org/wiki/Homology_group) are the same: H<sub>*n*</sub>(*f*) = H<sub>*n*</sub>(*g*) : H<sub>*n*</sub>(*X*) → H<sub>*n*</sub>(*Y*) for all *n*. Likewise, if *X* and *Y* are in addition [path-connected](wikipedia://en/87141), and the homotopy between *f* and *g* is pointed, then the group homomorphisms induced by *f* and *g* on the level of [homotopy groups](wikipedia://en/297506) are also the same: π<sub>*n*</sub>(*f*) = π<sub>*n*</sub>(*g*) : π<sub>*n*</sub>(*X*) → π<sub>*n*</sub>(*Y*).

## Applications {#Applications}

Based on the concept of the homotopy, [computation methods](https://en.wikipedia.org/wiki/Numerical_methods) for [algebraic](https://en.wikipedia.org/wiki/Algebraic_equations) and [differential equations](https://en.wikipedia.org/wiki/Differential_equations) have been developed. The methods for algebraic equations include the [homotopy continuation](https://en.wikipedia.org/wiki/Homotopy_continuation) method[^o39] and the continuation method (see [numerical continuation](wikipedia://en/9752560)). The methods for differential equations include the [homotopy analysis method](wikipedia://en/22844401).

Homotopy theory can be used as a foundation for [homology theory](wikipedia://en/142432): one can [represent](wikipedia://en/844461) a cohomology functor on a space *X* by mappings of *X* into an appropriate fixed space, up to homotopy equivalence. For example, for any abelian group *G*, and any based CW-complex *X*, the set $[X,K(G,n)]$ of based homotopy classes of based maps from *X* to the [Eilenberg–MacLane space](wikipedia://en/1073230) $K(G,n)$ is in natural bijection with the *n*-th [singular cohomology](https://en.wikipedia.org/wiki/Singular_cohomology) group $H^n(X,G)$ of the space *X*. One says that the [omega-spectrum](wikipedia://en/1033697) of Eilenberg-MacLane spaces are [representing spaces](https://en.wikipedia.org/wiki/Representing_space) for singular cohomology with coefficients in *G*. Using this fact, homotopy classes between a CW complex and a multiply connected space can be calculated using cohomology as described by the [Hopf–Whitney theorem](wikipedia://en/79124667).

Recently, homotopy theory has been used to develop [deep learning](https://en.wikipedia.org/wiki/Deep_learning)-based [generative models](wikipedia://en/1222578) like [diffusion models](https://en.wikipedia.org/wiki/Diffusion_model) and [flow-based generative models](wikipedia://en/67064736). Perturbing the complex non-[Gaussian states](https://en.wikipedia.org/wiki/Gaussian_state) is a challenging task. Using deep learning and homotopy, such complex states can be transformed to Gaussian state and mildly perturbed to get transformed back to perturbed complex states.[^o40]
