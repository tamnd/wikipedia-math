# Algebraic enumeration

::: {#o1 .subject cue=lead name="Algebraic enumeration"}

**Algebraic enumeration** is a subfield of [enumeration](wikipedia://en/212115) that deals with finding exact formulas for the number of [combinatorial objects](wikipedia://en/5170) of a given type, rather than estimating this number [asymptotically](wikipedia://en/641995). Methods of finding these formulas include [generating functions](wikipedia://en/160993) and the solution of [recurrence relations](wikipedia://en/146806). The field involves bijections, power series and formal [Laurent series](wikipedia://en/61213). [^o2]

:::
