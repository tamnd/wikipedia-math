# Enumeration

::: {#o1 .subject cue=lead name="Enumeration"}

An **enumeration** is a complete, ordered [listing](wikipedia://en/71429322) of all the items in a collection. The term is commonly used in [mathematics](wikipedia://en/18831) and [computer science](https://en.wikipedia.org/wiki/Computer_science) to refer to a listing of all of the [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of a [set](wikipedia://en/26691). The precise requirements for an enumeration (for example, whether the set must be [finite](wikipedia://en/11742), or whether the list is allowed to contain repetitions) depend on the discipline of study and the context of a given problem.

:::

Some sets can be enumerated by means of a **natural ordering** (such as 1, 2, 3, 4, ... for the set of [positive integers](https://en.wikipedia.org/wiki/Positive_integer)), but in other cases it may be necessary to impose a (perhaps arbitrary) ordering. In some contexts, such as [enumerative combinatorics](wikipedia://en/3925533), the term *enumeration* is used more in the sense of *[counting](wikipedia://en/275768)* – with emphasis on determination of the number of elements that a set contains, rather than the production of an explicit listing of those elements.

## Combinatorics {#Combinatorics}

In combinatorics, enumeration means [counting](wikipedia://en/275768), i.e., determining the exact number of elements of finite sets, usually grouped into infinite families, such as the family of sets each consisting of all [permutations](wikipedia://en/44027) of some finite set. There are flourishing subareas in many branches of mathematics concerned with enumerating in this sense. For instance, in *[partition](wikipedia://en/104790) enumeration* and *[graph enumeration](wikipedia://en/9982439)* the objective is to count partitions or graphs that meet certain conditions.

## Programming languages {#Programming_languages}

Originating in common linguistic practice, enumeration is a conceptualization and mechanism borrowed primarily from [philosophy](https://en.wikipedia.org/wiki/Philosophy) —along with [linguistics](https://en.wikipedia.org/wiki/Linguistics), [logic](wikipedia://en/46426065), [mathematics](wikipedia://en/18831), [semantics](wikipedia://en/29107) and [semiotics](https://en.wikipedia.org/wiki/Semiotics)). As such, most [programming languages](wikipedia://en/23015) offer enumerations as an [extensional method](https://en.wikipedia.org/wiki/Extensional_definition) for defining concepts, providing a contrast and alternative to [intensional definitions](https://en.wikipedia.org/wiki/Intensional_definition), allowed by most programming languages.

::: {#o5 .example cue=heading name="Examples"}

### Examples {#Examples}

- Java

```java
enum Level {
  LOW, MEDIUM, HIGH
}
```

- C++

```cpp
enum Color { RED, GREEN, BLUE }; // RED=0, GREEN=1, BLUE=2
Color myColor = RED;
```

:::

## Set theory {#Set_theory}

In [set theory](wikipedia://en/27553), the notion of enumeration has a broader sense, and does not require the set being enumerated to be finite.

### Listing {#Listing}

When an enumeration is used in an [ordered list](wikipedia://en/27838) context, we impose some sort of ordering structure requirement on the [index set](https://en.wikipedia.org/wiki/Index_set_%28recursion_theory%29). While we can make the requirements on the ordering quite lax in order to allow for great generality, the most natural and common prerequisite is that the index set be [well-ordered](https://en.wikipedia.org/wiki/Well-ordered). According to this characterization, an ordered enumeration is defined to be a surjection (an onto relationship) with a well-ordered domain. This definition is natural in the sense that a given well-ordering on the index set provides a unique way to list the next element given a partial enumeration.

### Countable vs. uncountable {#Countable_vs._uncountable}

Unless otherwise specified, an enumeration is done by means of [natural numbers](wikipedia://en/21474). That is, an *enumeration* of a [set](wikipedia://en/26691) $S$ is a [bijective function](https://en.wikipedia.org/wiki/Bijective_function) from the [natural numbers](wikipedia://en/21474) $\mathbb{N}$ or an [initial segment](https://en.wikipedia.org/wiki/Initial_segment) $\{1, ..., n\}$ of the natural numbers to $S$.

A set is [countable](wikipedia://en/6026) if it can be enumerated, that is, if there exists an enumeration of it. Otherwise, it is [uncountable](https://en.wikipedia.org/wiki/Uncountable). For example, the set of the real numbers is uncountable.

A set is [finite](wikipedia://en/11742) if it can be enumerated by means of a proper initial segment $\{1, ..., n\}$ of the natural numbers, in which case, its [cardinality](wikipedia://en/6174) is $n$. The [empty set](wikipedia://en/9566) is finite, as it can be enumerated by means of the empty initial segment of the natural numbers.

The term **enumerable set** is sometimes used for countable sets. However it is also often used for [computably enumerable sets](wikipedia://en/332090), which are the countable sets for which an enumeration function can be computed with an algorithm.

For avoiding to distinguish between finite and countably infinite set, it is often useful to use another definition that is equivalent: A set $S$ is countable if and only if there exists an [injective function](wikipedia://en/45196) from it into the natural numbers.

::: {#o10 .example cue=heading name="Examples"}

#### Examples {#Examples}

- The [natural numbers](wikipedia://en/21474) are enumerable by the function *f*(*x*) = *x*. In this case $f\colon\mathbb{N} \to \mathbb{N}$ is simply the [identity function](wikipedia://en/15069).
- $\mathbb{Z}$, the set of [integers](https://en.wikipedia.org/wiki/Integers) is enumerable by

$$f(x):=\frac {1-(-1)^x\,(2\,x+1)} 4$$

$$f\colon\mathbb{N}_0 \to \mathbb{Z}$$

is a bijection since every natural number corresponds to exactly one integer. The following table gives the first few values of this enumeration:

| *x* | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| *f*(*x*) | 0 | 1 | \-1 | 2 | \-2 | 3 | \-3 | 4 | \-4 |
- All (non empty) finite sets are enumerable. Let *S* be a finite set with *n > 0* elements and let *K* = {1,2,...,*n*}. Select any element *s* in *S* and assign *f*(*n*) = *s*. Now set *S'* = *S* − {*s*} (where − denotes [set difference](https://en.wikipedia.org/wiki/Set_difference)). Select any element *s'* ∈ *S'* and assign *f*(*n* − 1) = *s'*. Continue this process until all elements of the set have been assigned a natural number. Then $f: K \to S$ is an enumeration of *S*.
- The [real numbers](wikipedia://en/20646438) have no countable enumeration as proved by [Cantor's diagonal argument](wikipedia://en/51426) and [Cantor's first uncountability proof](https://en.wikipedia.org/wiki/Cantor's_first_uncountability_proof).

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

#### Properties {#Properties}

- There exists an enumeration for a set (in this sense) if and only if the set is [countable](https://en.wikipedia.org/wiki/Countable).
- If a set is enumerable it will have an [uncountable](https://en.wikipedia.org/wiki/Uncountable) infinity of different enumerations, except in the degenerate cases of the empty set or (depending on the precise definition) sets with one element. However, if one requires enumerations to be injective *and* allows only a limited form of partiality such that if *f*(*n*) is defined then *f*(*m*) must be defined for all *m* \< *n*, then a finite set of *N* elements has exactly *N*! enumerations.
- An enumeration *e* of a set *S* with domain $\mathbb{N}$ induces a [well-order](wikipedia://en/33456) ≤ on that set defined by *s* ≤ *t* if and only if $\min e^{-1}(s) \leq \min e^{-1}(t)$. Although the order may have little to do with the underlying set, it is useful when some order of the set is necessary.

:::

### Ordinals {#Ordinals}

In [set theory](wikipedia://en/27553), there is a more general notion of an enumeration than the characterization requiring the domain of the listing function to be an [initial segment](https://en.wikipedia.org/wiki/Initial_segment) of the Natural numbers where the domain of the enumerating function can assume any [ordinal](wikipedia://en/26547932). Under this definition, an enumeration of a set *S* is any [surjection](https://en.wikipedia.org/wiki/Surjection) from an ordinal α onto *S*. The more restrictive version of enumeration mentioned before is the special case where α is a finite ordinal or the first limit ordinal ω. This more generalized version extends the aforementioned definition to encompass [transfinite](wikipedia://en/30461) listings.

Under this definition, the [first uncountable ordinal $\omega_1$](wikipedia://en/20860540) can be enumerated by the identity function on $\omega_1$ so that these two notions do **not** coincide. More generally, it is a theorem of ZF that any [well-ordered](https://en.wikipedia.org/wiki/Well-ordered) set can be enumerated under this characterization so that it coincides up to relabeling with the generalized listing enumeration. If one also assumes the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice), then all sets can be enumerated so that it coincides up to relabeling with the most general form of enumerations.

Since [set theorists](https://en.wikipedia.org/wiki/Set_theorist) work with infinite sets of arbitrarily large [cardinalities](wikipedia://en/6174), the default definition among this group of mathematicians of an enumeration of a set tends to be any arbitrary α-sequence exactly listing all of its elements. Indeed, in Jech's book, which is a common reference for set theorists, an enumeration is defined to be exactly this. Therefore, in order to avoid ambiguity, one may use the term finitely enumerable or [denumerable](https://en.wikipedia.org/wiki/Denumerable) to denote one of the corresponding types of distinguished countable enumerations.

### Comparison of cardinalities {#Comparison_of_cardinalities}

Formally, the most inclusive definition of an enumeration of a set *S* is any [surjection](https://en.wikipedia.org/wiki/Surjection) from an arbitrary [index set](wikipedia://en/393055) *I* onto *S*. In this broad context, every set *S* can be trivially enumerated by the [identity function](wikipedia://en/15069) from *S* onto itself. If one does *not* assume the [axiom of choice](wikipedia://en/840) or one of its variants, *S* need not have any [well-ordering](https://en.wikipedia.org/wiki/Well-ordering). Even if one does assume the axiom of choice, *S* need not have any natural well-ordering.

This general definition therefore lends itself to a counting notion where we are interested in "how many" rather than "in what order." In practice, this broad meaning of enumeration is often used to compare the relative sizes or [cardinalities](wikipedia://en/6174) of different sets. If one works in [Zermelo–Fraenkel set theory](wikipedia://en/152214) without the axiom of choice, one may want to impose the additional restriction that an enumeration must also be [injective](https://en.wikipedia.org/wiki/Injective) (without repetition) since in this theory, the existence of a surjection from *I* onto *S* need not imply the existence of an [injection](https://en.wikipedia.org/wiki/Injection_%28mathematics%29) from *S* into *I*.

## Computability and complexity theory {#Computability_and_complexity_theory}

In [computability theory](wikipedia://en/155414) one often considers countable enumerations with the added requirement that the mapping from $\mathbb{N}$ (set of all natural numbers) to the enumerated set must be [computable](wikipedia://en/1139338). The set being enumerated is then called [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable) (or computably enumerable in more contemporary language), referring to the use of [recursion theory](https://en.wikipedia.org/wiki/Recursion_theory) in formalizations of what it means for the map to be computable.

In this sense, a subset of the natural numbers is [computably enumerable](https://en.wikipedia.org/wiki/Computably_enumerable) if it is the range of a computable function. In this context, enumerable may be used to mean computably enumerable. However, these definitions characterize distinct classes since there are uncountably many subsets of the natural numbers that can be enumerated by an arbitrary function with domain ω and only countably many computable functions. A specific example of a set with an enumeration but not a computable enumeration is the complement of the [halting set](wikipedia://en/21391870).

Furthermore, this characterization illustrates a place where the ordering of the listing is important. There exists a computable enumeration of the halting set, but **not** one that lists the elements in an increasing ordering. If there were one, then the halting set would be [decidable](https://en.wikipedia.org/wiki/Decidable_language), which is provably false. In general, being recursively enumerable is a weaker condition than being a [decidable set](https://en.wikipedia.org/wiki/Decidable_set).

The notion of enumeration has also been studied from the point of view of [computational complexity theory](wikipedia://en/7543) for various tasks in the context of [enumeration algorithms](https://en.wikipedia.org/wiki/Enumeration_algorithm).
