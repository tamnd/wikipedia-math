# Caratheodory-π solution

::: {#o1 .subject cue=lead name="Caratheodory-π solution"}

A **Carathéodory-$\pi$ solution** is a generalized solution to an [ordinary differential equation](wikipedia://en/32742753). The concept is due to [I. Michael Ross](wikipedia://en/36457556) and named in honor of [Constantin Carathéodory](wikipedia://en/470625).[^o2] Its practicality was demonstrated in 2008 by Ross et al.[^o3] in a laboratory implementation of the concept. The concept is most useful for implementing [feedback controls](https://en.wikipedia.org/wiki/Feedback_control), particularly those generated by an application of Ross' [pseudospectral optimal control](wikipedia://en/15983837) theory.[^o4]

:::

## Mathematical background {#Mathematical_background}

A Carathéodory-$\pi$ solution addresses the fundamental problem of defining a solution to a differential equation,

$$\dot x = g(x,t)$$

when *g*(*x*,*t*) is not differentiable with respect to *x*. Such problems arise quite naturally[^o6] in defining the meaning of a solution to a controlled differential equation,

$$\dot x = f(x,u)$$

when the control, *u*, is given by a feedback law,

$$u = k(x,t)$$

where the function *k*(*x*,*t*) may be non-smooth with respect to *x*. Non-smooth feedback controls arise quite often in the study of optimal feedback controls and have been the subject of extensive study going back to the 1960s.[^o7]

## Ross' concept {#Ross'_concept}

An ordinary differential equation,

$$\dot x = g(x,t)$$

is equivalent to a controlled differential equation,

$$\dot x = u$$

with feedback control, $u = g(x,t)$. Then, given an [initial value problem](wikipedia://en/498383), Ross partitions the time interval $[0, \infty)$ to a grid, $\pi = \{t_i\}_{i\ge 0}$ with $t_i \to \infty \text{ as } i \to \infty$. From $t_0$ to $t_1$, generate a control trajectory,

$$u(t) = g(x_0, t), \quad x(t_0) = x_0, \quad t_0 \le t \le t_1$$

to the controlled differential equation,

$$\dot x = u(t), \quad x(t_0) = x_0$$

A [Carathéodory solution](https://en.wikipedia.org/wiki/Carathéodory_existence_theorem) exists for the above equation because $t \mapsto u$ has discontinuities at most in *t*, [the independent](https://en.wikipedia.org/wiki/The_Independent) variable. At $t = t_1$, set $x_1 = x(t_1)$ and restart the system with $u(t) = g(x_1, t)$,

$$\dot x(t) = u(t), \quad x(t_1) = x_1, \quad t_1 \le t \le t_2$$

Continuing in this manner, the Carathéodory segments are stitched together to form a Carathéodory-$\pi$ solution.

## Engineering applications {#Engineering_applications}

A Carathéodory-$\pi$ solution can be applied towards the practical stabilization of a control system.[^o10][^o11] It has been used to stabilize an [inverted pendulum](wikipedia://en/265421),[^o10] control and optimize the motion of robots,[^o11][^o12] slew and control the NPSAT1 spacecraft[^o4] and produce guidance commands for low-thrust space missions.[^o3]
