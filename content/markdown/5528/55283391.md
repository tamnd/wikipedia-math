# Seriation (statistics)

::: {#o1 .subject cue=lead name="Seriation"}

In [combinatorial data analysis](wikipedia://en/17825553), **seriation** is the process of finding an arrangement of all objects in a set, in a [linear order](https://en.wikipedia.org/wiki/Linear_order), given a [loss function](wikipedia://en/442137).[^o2] The main goal is exploratory, to reveal structural information.

:::
