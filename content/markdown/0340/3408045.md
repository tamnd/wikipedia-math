# Cochran–Armitage test for trend

::: {#o1 .subject cue=lead name="Cochran–Armitage test for trend"}

The **Cochran–Armitage test for trend**,[^o2][^o3] named for [William Cochran](wikipedia://en/2223833) and [Peter Armitage](wikipedia://en/225226), is used in [categorical data analysis](https://en.wikipedia.org/wiki/Categorical_data_analysis) when the aim is to assess for the presence of an [association](https://en.wikipedia.org/wiki/Association_%28statistics%29) between a variable with two categories and an ordinal variable with *k* categories. It modifies the [Pearson chi-squared test](https://en.wikipedia.org/wiki/Pearson_chi-squared_test) to incorporate a suspected ordering in the effects of the *k* categories of the second variable. For example, doses of a treatment can be ordered as 'low', 'medium', and 'high', and we may suspect that the treatment benefit cannot become smaller as the dose increases. The trend test is often used as a [genotype](https://en.wikipedia.org/wiki/Genotype)-based test for [case-control](https://en.wikipedia.org/wiki/Case-control_study) [genetic](https://en.wikipedia.org/wiki/Genetics) [association studies](https://en.wikipedia.org/wiki/Genetic_association).[^o4]

:::

## Introduction {#Introduction}

The trend test is applied when the data take the form of a 2 × *k* [contingency table](wikipedia://en/935515). For example, if *k* = 3 we have

::: {#o6 .table cue=table}

|  | B = 1 | B = 2 | B = 3 |
|---|---|---|---|
| A = 1 | *N*<sub>11</sub> | *N*<sub>12</sub> | *N*<sub>13</sub> |
| A = 2 | *N*<sub>21</sub> | *N*<sub>22</sub> | *N*<sub>23</sub> |

:::

This table can be completed with the marginal totals of the two variables

::: {#o7 .table cue=table}

|  | B = 1 | B = 2 | B = 3 | Sum |
|---|---|---|---|---|
| A = 1 | *N*<sub>11</sub> | *N*<sub>12</sub> | *N*<sub>13</sub> | *R*<sub>1</sub> |
| A = 2 | *N*<sub>21</sub> | *N*<sub>22</sub> | *N*<sub>23</sub> | *R*<sub>2</sub> |
| Sum | *C*<sub>1</sub> | *C*<sub>2</sub> | *C*<sub>3</sub> | N |

:::

where *R*<sub>1</sub> = *N*<sub>11</sub> + *N*<sub>12</sub> + *N*<sub>13</sub>, and *C*<sub>1</sub> = *N*<sub>11</sub> + *N*<sub>21</sub>, etc.

The trend [test statistic](wikipedia://en/1416975) is

$$T \equiv \sum_{i=1}^k t_i (N_{1i} R_2 - N_{2i} R_1),$$

where the *t*<sub>*i*</sub> are weights, and the difference *N*<sub>1*i*</sub>*R*<sub>2</sub> −*N*<sub>2*i*</sub>*R*<sub>1</sub> can be seen as the difference between *N*<sub>1*i*</sub> and *N*<sub>2*i*</sub> after reweighting the rows to have the same total.

The hypothesis of no association (the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis)) can be expressed as:

$$\Pr(A=1| B=1) = \cdots = \Pr(A=1| B=k).$$

Assuming this holds, then, using [iterated expectation](wikipedia://en/9653#Iterated_expectation),

$$\operatorname{E}(T) = \operatorname{E} \left( \operatorname{E}(T|R_1,R_2) \right) = \operatorname{E} (0) = 0.$$

The variance can be computed by [decomposition](wikipedia://en/32344#Decomposition), yielding

$${\rm Var}(T) = \frac{R_1R_2}{N} \left(\sum_{i=1}^kt_i^2C_i(N-C_i) - 2\sum_{i=1}^{k-1}\sum_{j=i+1}^kt_it_jC_iC_j\right),$$

and as a large sample approximation,

$$\frac{T }{\sqrt{\mathrm{Var}(T)}} \sim \mathrm{N}(0,1).$$

The weights *t*<sub>*i*</sub> can be chosen such that the trend test becomes locally most [powerful](https://en.wikipedia.org/wiki/Statistical_power) for detecting particular types of associations. For example, if *k* = 3 and we suspect that *B* = 1 and *B* = 2 have similar frequencies (within each row), but that *B* = 3 has a different frequency, then the weights *t* = (1,1,0) should be used. If we suspect a linear trend in the frequencies, then the weights *t* = (0,1,2) should be used. These weights are also often used when the frequencies are suspected to change monotonically with *B*, even if the trend is not necessarily linear.

## Interpretation and role {#Interpretation_and_role}

The trend test will have higher [power](https://en.wikipedia.org/wiki/Statistical_power) than the chi-squared test when the suspected trend is correct, but the ability to detect unsuspected trends is sacrificed. This is an example of a general technique of directing hypothesis tests toward narrow [alternatives](https://en.wikipedia.org/wiki/Alternative_hypothesis). The trend test exploits the suspected effect direction to increase power, but this does not affect the sampling distribution of the test statistic under the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis). Thus, the suspected trend in effects is not an assumption that must hold in order for the test results to be meaningful.

## Application to genetics {#Application_to_genetics}

Suppose that there are three possible [genotypes](https://en.wikipedia.org/wiki/Genotype) at some [locus](https://en.wikipedia.org/wiki/Locus_%28genetics%29), and we refer to these as aa, Aa and AA. The distribution of genotype counts can be put in a 2 × 3 contingency table. For example, consider the following data, in which the genotype frequencies vary linearly in the cases and are constant in the controls:

::: {#o10 .table cue=table}

|  | Genotype aa | Genotype Aa | Genotype AA | Sum |
|---|---|---|---|---|
| Controls | 20 | 20 | 20 | 60 |
| Cases | 10 | 20 | 30 | 60 |
| Sum | 30 | 40 | 50 | 120 |

:::

In genetics applications, the weights are selected according to the suspected [mode of inheritance](https://en.wikipedia.org/wiki/Heredity). For example, in order to test whether [allele](https://en.wikipedia.org/wiki/Allele) a is [dominant](https://en.wikipedia.org/wiki/Dominance_relationship#Dominant_allele) over allele A, the choice *t* = (1, 1, 0) is locally optimal. To test whether allele a is [recessive](https://en.wikipedia.org/wiki/Recessive_%28genetics%29) to allele A, the optimal choice is *t* = (0, 1, 1). To test whether alleles a and A are [codominant](https://en.wikipedia.org/wiki/Codominant#Co-dominance), the choice *t* = (0, 1, 2) is locally optimal. For [complex diseases](https://en.wikipedia.org/wiki/Complex_disease#Multifactorial_and_polygenic_.28complex.29_disorders), the underlying genetic model is often unknown. In [genome-wide association studies](https://en.wikipedia.org/wiki/Genome-wide_association_study), the additive (or codominant) version of the test is often used.

In the numerical example, the standardized test statistics for various weight vectors are

::: {#o11 .table cue=table}

| Weights | Standardized test statistic | p-value (two-sided) | p-value (one-sided) |
|---|---|---|---|
| 1, 1, 0 | \1.85 | \0.064 | \0.032 |
| 0, 1, 1 | \-2.11 | \0.035 | \0.018 |
| 0, 1, 2 | \-2.28 | \0.022 | \0.011 |

:::

In this example, the one-sided p-values could only be used if it was known a priori that the A allele increased the risk of disease. We obtain a stronger significance level if the weights corresponding to additive (codominant) inheritance are used. The Pearson chi-squared test for correlation gives test statistic χ<sup>2</sup> = 5.33 at df = 2, corresponding to a p-value of 0.0695. The Cochran-Armitage p-values above are more significant, as explained [above](wikipedia://en/3408045#Interpretation_and_role). Note that for the significance level to give a [p-value](wikipedia://en/554994) with the usual probabilistic interpretation, the weights must be specified before examining the data, and only one set of weights may be used.
