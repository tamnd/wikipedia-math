# Rng (algebra)

::: {#o1 .subject cue=lead name="Rng"}

In [abstract algebra](wikipedia://en/19616384), a **rng** (pronounced "rung" ) or **non-unital ring** or **[pseudo-ring](wikipedia://en/51508407)** is an alternative name for a ring that does not assume the existence of a [multiplicative identity](https://en.wikipedia.org/wiki/Multiplicative_identity). The term *rng* is meant to suggest that it is a ring without *i*, that is, without the requirement for an identity element.[^n1]

:::

There is no consensus in the community as to whether the existence of a multiplicative identity must be one of the [ring axioms](https://en.wikipedia.org/wiki/Ring_axioms) (see *Ring (mathematics)*). The term *rng* was coined to alleviate this ambiguity when people want to refer explicitly to a ring without the axiom of multiplicative identity.

A number of algebras of functions considered in [analysis](wikipedia://en/48396) are not unital, for instance the algebra of functions decreasing to zero at infinity, especially those with [compact support](https://en.wikipedia.org/wiki/Compact_support) on some (non-[compact](wikipedia://en/6042)) space.

## Definition {#Definition}

Formally, a **rng** is a [set](wikipedia://en/26691) *R* with two [binary operations](https://en.wikipedia.org/wiki/Binary_operations) (+, ·) called *addition* and *multiplication* such that

- (*R*, +) is an [abelian group](wikipedia://en/2974),
- (*R*, ·) is a [semigroup](wikipedia://en/27799),
- Multiplication [distributes](https://en.wikipedia.org/wiki/Distributive_law) over addition.

A **rng homomorphism** is a function *f* : *R* → *S* from one rng to another such that

- *f*(*x* + *y*) = *f*(*x*) + *f*(*y*)
- *f*(*x* · *y*) = *f*(*x*) · *f*(*y*)

for all *x* and *y* in *R*.

If *R* and *S* are rings, then a [ring homomorphism](wikipedia://en/26411) *R* → *S* is the same as a rng homomorphism *R* → *S* that maps 1 to 1.

:::

## Examples {#Examples}

All rings are rngs. A simple example of a rng that is not a ring is given by the [even integers](https://en.wikipedia.org/wiki/Even_number) with the ordinary addition and multiplication of integers. Another example is given by the set of all 3-by-3 real [matrices](wikipedia://en/20556859) whose bottom row is zero. Both of these examples are instances of the general fact that every (one- or two-sided) [ideal](wikipedia://en/25977) is a rng.

Any [abelian group](wikipedia://en/2974) can be made a rng by defining the multiplication so that *xy* = 0 for all *x* and *y*. (See *\#Rng of square zero*)

Rngs often appear naturally in [functional analysis](wikipedia://en/11180) when [linear operators](https://en.wikipedia.org/wiki/Linear_operator) on infinite-[dimensional](https://en.wikipedia.org/wiki/Dimension_%28linear_algebra%29) [vector spaces](wikipedia://en/32370) are considered. Take for instance any infinite-dimensional vector space *V* and consider the set of all linear operators *f* : *V* → *V* with finite [rank](wikipedia://en/26561) (i.e. dim *f*(*V*) \< ∞). Together with addition and [composition](https://en.wikipedia.org/wiki/Functional_composition) of operators, this is a rng, but not a ring. Another example is the rng of all real [sequences](wikipedia://en/27838) that [converge to](wikipedia://en/285773) 0, with component-wise operations.

Also, many test function spaces occurring in the [theory of distributions](https://en.wikipedia.org/wiki/Theory_of_distributions) consist of functions decreasing to zero at infinity, like e.g. [Schwartz space](wikipedia://en/4277567). Thus, the function everywhere equal to one, which would be the only possible identity element for pointwise multiplication, cannot exist in such spaces, which therefore are rngs (for pointwise addition and multiplication). In particular, the real-valued [continuous functions](wikipedia://en/6122) with [compact](wikipedia://en/6042) [support](wikipedia://en/381013) defined on some [topological space](wikipedia://en/30450), together with pointwise addition and multiplication, form a rng; this is not a ring unless the underlying space is [compact](wikipedia://en/6042).

### Example: even integers {#Example:_even_integers}

The set 2**Z** of even integers is closed under addition and multiplication and has an additive identity, 0, so it is a rng, but it does not have a multiplicative identity, so it is not a ring.

In 2**Z**, the only multiplicative [idempotent](wikipedia://en/14972) is 0, the only [nilpotent](wikipedia://en/252235) is 0, and the only element with a [reflexive inverse](wikipedia://en/7043631) is 0.

### Example: finite [quinary](wikipedia://en/486117) sequences {#Example:_finite_quinary_sequences}

The direct sum $\mathcal T = \bigoplus_{i=1}^\infty \mathbf{Z}/5 \mathbf{Z}$ equipped with coordinate-wise addition and multiplication is a rng with the following properties:

- Its [idempotent](wikipedia://en/14972) elements form a lattice with no upper bound.
- Every element *x* has a [reflexive inverse](wikipedia://en/7043631), namely an element *y* such that *xyx* = *x* and *yxy* = *y*.
- For every finite subset of $\mathcal T$, there exists an idempotent in $\mathcal T$ that acts as an identity for the entire subset: the sequence with a one at every position where a sequence in the subset has a non-zero element at that position, and zero in every other position.

## Properties {#Properties}

Ideals, [quotient rings](wikipedia://en/184635), and [modules](https://en.wikipedia.org/wiki/Module_%28algebra%29) can be defined for rngs in the same manner as for rings.; Working with rngs instead of rings complicates some related definitions, however. For example, in a ring *R*, the left ideal (*f*) generated by an element *f*, defined as the smallest left ideal containing *f*, is simply *Rf*, but if *R* is only a rng, then *Rf* might not contain *f*, so instead $(f) = Rf + \mathbf{Z} f = \{ af+nf : a \in R ~\text{and}~ n\in \mathbf{Z} \},$ where *nf* must be interpreted using repeated addition/subtraction since *n* need not represent an element of *R*. Similarly, the left ideal generated by elements *f*${}_{1}$, ..., *f*${}_{m}$ of a rng *R* is $(f_1,\ldots,f_m) = \{ a_1 f_1 + \cdots + a_m f_m + n_1 f_1 + \cdots n_m f_m : a_i \in R \;\mathrm{and}\; n_i\in \mathbf{Z} \},$ a formula that goes back to [Emmy Noether](wikipedia://en/149896).[^n2] Similar complications arise in the definition of [submodule](https://en.wikipedia.org/wiki/Submodule) generated by a set of elements of a module.; Some theorems for rings are false for rngs. For example, in a ring, every proper ideal is contained in a [maximal ideal](wikipedia://en/48164), so a nonzero ring always has at least one maximal ideal. Both these statements fail for rngs.; A rng homomorphism *f* : *R* → *S* maps any [idempotent element](https://en.wikipedia.org/wiki/Idempotent_element_%28ring_theory%29) to an idempotent element.; If *f* : *R* → *S* is a rng homomorphism from a ring to a rng, and the image of *f* contains a non-zero-divisor of *S*, then *S* is a ring, and *f* is a ring homomorphism.

## Properties weaker than having an identity {#Properties_weaker_than_having_an_identity}

There are several properties that have been considered in the literature that are weaker than having an identity element, but not so general. For example:

- Rings with enough idempotents: A rng *R* is said to be a ring with enough idempotents when there exists a subset *E* of *R* given by orthogonal (i.e. *ef* = 0 for all *e* ≠ *f* in *E*) idempotents (i.e. *e*<sup>2</sup> = *e* for all *e* in *E*) such that *R* = ⊕<sub>*e*∈*E*</sub> *eR* = ⊕<sub>*e*∈*E*</sub> *Re*.
- Rings with local units: A rng *R* is said to be a ring with local units in case for every finite set *r*<sub>1</sub>, *r*<sub>2</sub>, ..., *r<sub>t</sub>* in *R* we can find *e* in *R* such that *e*<sup>2</sup> = *e* and *er<sub>i</sub>* = *r<sub>i</sub>* = *r<sub>i</sub>e* for every *i*.
- *s*-unital rings: A rng *R* is said to be *s*-unital in case for every finite set *r*<sub>1</sub>, *r*<sub>2</sub>, ..., *r<sub>t</sub>* in *R* we can find *s* in *R* such that *sr<sub>i</sub>* = *r<sub>i</sub>* = *r<sub>i</sub>s* for every *i*.
- Firm rings: A rng *R* is said to be firm if the canonical homomorphism *R* ⊗<sub>*R*</sub> *R* → *R* given by *r* ⊗ *s* ↦ *rs* is an isomorphism.
- Idempotent rings: A rng *R* is said to be idempotent (or an irng) in case *R*<sup>2</sup> = *R*, that is, for every element *r* of *R* we can find elements *r<sub>i</sub>* and *s<sub>i</sub>* in *R* such that $r = \sum_i r_i s_i$.

It is not difficult to check that each of these properties is weaker than having an identity element and weaker than the property preceding it.

- Rings are rings with enough idempotents, using *E* = $\{1\}$. A ring with enough idempotents that has no identity is for example the ring of infinite matrices over a field with just a finite number of nonzero entries. Those matrices with a 1 in precisely one entry of the main diagonal and 0s in all other entries are the orthogonal idempotents.
- Rings with enough idempotents are rings with local units as can be seen by taking finite sums of the orthogonal idempotents to satisfy the definition.
- Rings with local units are in particular *s*-unital; *s*-unital rings are firm and firm rings are idempotent.

:::

## Rng of square zero {#Rng_of_square_zero}

A **rng of square zero** is a rng *R* such that *xy* = 0 for all *x* and *y* in *R*. Any [abelian group](wikipedia://en/2974) can be made a rng of square zero by defining the multiplication so that *xy* = 0 for all *x* and *y*;[^n4] thus every abelian group is the additive group of some rng. The only rng of square zero with a multiplicative identity is the [zero ring](wikipedia://en/1872874) {0}.[^n4]

Any additive [subgroup](wikipedia://en/28011) of a rng of square zero is an [ideal](wikipedia://en/25977). Thus a rng of square zero is [simple](wikipedia://en/443387) if and only if its additive group is a simple abelian group, i.e., a [cyclic group](wikipedia://en/52327) of prime order.[^n5]

:::

## Unital homomorphism {#Unital_homomorphism}

Given two unital algebras *A* and *B*, an algebra [homomorphism](wikipedia://en/13564)

is **unital** if it maps the identity element of *A* to the identity element of *B*.
