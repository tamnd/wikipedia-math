# Fekete's lemma

::: {#o1 .subject cue=lead name="Fekete's lemma"}

In mathematics, and in particular in [calculus](wikipedia://en/5176), **Fekete's lemma** (also called **Fekete's subadditive lemma**) is a [lemma](wikipedia://en/18634) concerning the [limit](wikipedia://en/26551602) of [subadditive sequences](wikipedia://en/745789). The lemma provides an estimate for the linear growth rate of such sequences.

:::

The lemma is named after the Hungarian-Israeli mathematician [Michael Fekete](https://en.wikipedia.org/wiki/Michael_Fekete), who proved it in 1923.[^o2]

::: {#o4 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

In this article, $\mathbb{N}$ denotes the [natural numbers](wikipedia://en/21474). This set does not include the number 0.

A sequence of [real numbers](wikipedia://en/20646438) $\{a_n\}_{n=1}^\infty$ is called a **subadditive sequence** if and only if for all $m,n\in\mathbb{N}$ one has

$$a_{n+m}\le a_n+a_m.$$

**Fekete's lemma** states that for every subadditive sequence,

$$\lim_{n\to\infty}\frac{a_n}{n}=\inf_{n\in\mathbb{N}}\frac{a_n}{n}.$$

That is, the sequence $\frac{a_n}{n}$ converges to its [infimum](https://en.wikipedia.org/wiki/Infimum). Note that this infimum may be $-\infty$.

:::

::: {#o6 .proof cue=heading name="Proof"}

## Proof {#Proof}

To prove that the limit exists and equals the infimum, it suffices to show that

$$\inf_{n\in\mathbb{N}}\frac{a_n}{n}\le \liminf_{n\to\infty}\frac{a_n}{n}\le \limsup_{n\to\infty}\frac{a_n}{n}\le \inf_{n\in\mathbb{N}}\frac{a_n}{n},$$

where $\liminf$ and $\limsup$ denote the [limit inferior](https://en.wikipedia.org/wiki/Limit_inferior) and [limit superior](https://en.wikipedia.org/wiki/Limit_superior), respectively. The two left inequalities always hold, so it is enough to prove the rightmost inequality

$$\limsup_{n\to\infty}\frac{a_n}{n}\le \inf_{n\in\mathbb{N}}\frac{a_n}{n}.$$

Since the sequence is subadditive, one can prove by [induction](wikipedia://en/18881) that for all $m,n,l,k\in\mathbb{N}$,

$$a_{nl+mk}\le na_l+ma_k.$$

Define $a_0=0$. Then this inequality also holds when one of the indices $m,n,l,k$ is 0.

Now fix some $q\in\mathbb{N}$. For every $n\in\mathbb{N}$ there exist $m\in\mathbb{N}$ and $0\le r\le q-1$ such that $n=mq+r$. Hence, by the inequality above,

$$a_n\le ma_q+a_r.$$

Define $C_q=\max(a_0,a_1,\dots,a_{q-1})$. Dividing the inequality above by $n$ yields

$$\frac{a_n}{n}\le \frac{ma_q+a_r}{n} = \frac{ma_q}{n}+\frac{a_r}{n} \le \frac{ma_q}{mq}+\frac{C_q}{n} = \frac{a_q}{q}+\frac{C_q}{n}.$$

Taking the limit superior as $n\to\infty$, we obtain $\limsup_{n\to\infty}\frac{a_n}{n}\le \frac{a_q}{q}.$

Since $q$ was arbitrary, this holds for all $q$, and therefore

$$\limsup_{n\to\infty}\frac{a_n}{n}\le \inf_{n\in\mathbb{N}}\frac{a_n}{n}.$$

Combining the inequalities, we conclude that

$$\lim_{n\to\infty}\frac{a_n}{n}=\inf_{n\in\mathbb{N}}\frac{a_n}{n}.$$

∎

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

### Square root {#Square_root}

Define a sequence $\{a_n\}_{n=1}^\infty$ by, for all $n\in\mathbb{N}$,

$$a_n:=n+\sqrt{n}.$$

One can show that this sequence is subadditive, since for all $n,m\in\mathbb{N}$,

$$a_{n+m}=n+m+\sqrt{n+m} \le n+m+\sqrt{n}+\sqrt{m} = a_n+a_m.$$

Indeed,

$$\lim_{n\to\infty}\frac{a_n}{n} = \inf_{n\in\mathbb{N}}\frac{a_n}{n} = \inf_{n\in\mathbb{N}}\frac{n+\sqrt{n}}{n} = 1.$$

### Integer value {#Integer_value}

Let $0<c\in\mathbb{R}$. Define a sequence $\{a_n\}_{n=1}^\infty$ by, for all $n\in\mathbb{N}$,

$$a_n:=\lceil cn\rceil,$$

where $\lceil\cdot\rceil$ denotes the [ceiling function](https://en.wikipedia.org/wiki/Ceiling_function). The sequence is subadditive, since for all $n,m\in\mathbb{N}$,

$$a_{n+m} = \lceil c(n+m)\rceil = \lceil cn+cm\rceil \le \lceil cn\rceil+\lceil cm\rceil = a_n+a_m.$$

Indeed,

$$\lim_{n\to\infty}\frac{a_n}{n} = \inf_{n\in\mathbb{N}}\frac{a_n}{n} = \inf_{n\in\mathbb{N}}\frac{\lceil cn\rceil}{n} = c.$$

:::

## Corollaries {#Corollaries}

### Superadditive sequences {#Superadditive_sequences}

A sequence of real numbers $\{a_n\}_{n=1}^\infty$ is called **superadditive** if and only if for all $m,n\in\mathbb{N}$,

$$a_{n+m}\ge a_n+a_m.$$

Using Fekete's lemma, one can show that for every superadditive sequence,[^o13]

$$\lim_{n\to\infty}\frac{a_n}{n} = \sup_{n\in\mathbb{N}}\frac{a_n}{n}.$$

That is, the sequence $\frac{a_n}{n}$ converges to its [supremum](https://en.wikipedia.org/wiki/Supremum). As in the subadditive case, this supremum may be $\infty$.

The proof follows by applying Fekete's lemma to the sequence $b_n:=-a_n$.

### Submultiplicative sequences {#Submultiplicative_sequences}

A sequence of real numbers $\{a_n\}_{n=1}^\infty$ is called **submultiplicative** if and only if for all $m,n\in\mathbb{N}$,

$$a_{n+m}\le a_na_m.$$

Using Fekete's lemma, one can show that for every submultiplicative sequence with positive terms,

$$\lim_{n\to\infty}\sqrt[n]{a_n} = \inf_{n\in\mathbb{N}}\sqrt[n]{a_n}.$$

The proof follows by applying Fekete's lemma to the sequence $b_n:=\ln a_n$, where $\ln$ denotes the [natural logarithm](wikipedia://en/21476).

Note that since Fekete's lemma for submultiplicative sequences applies only to positive sequences, the infimum is necessarily finite and nonnegative. This fact has important applications, for example:

- Any [power series](wikipedia://en/59958) whose coefficients have [absolute values](wikipedia://en/991) forming a submultiplicative sequence has a positive [radius of convergence](wikipedia://en/61476) (the [Cauchy–Hadamard theorem](wikipedia://en/13620523)).
- Every [lattice](wikipedia://en/15782871) admits a [connective constant](wikipedia://en/36246682) describing the growth rate of the number of possible [self-avoiding walks](wikipedia://en/11186496).

### Almost subadditive sequence {#Almost_subadditive_sequence}

Let $\{a_n\}_{n=1}^\infty$ be a sequence of real numbers for which there exists $C\in\mathbb{R}$ such that for all $m,n\in\mathbb{N}$,

$$a_{n+m}\le a_n+a_m+C.$$

Such a sequence is called **almost subadditive**. Then,

$$\lim_{n\to\infty}\frac{a_n}{n} = \inf_{n\in\mathbb{N}}\frac{a_n+C}{n}.$$

::: {#o17 .proof cue=heading name="Proof"}

#### Proof {#Proof}

Define a new sequence $b_n:=a_n+C$. It is subadditive, since

$$b_{n+m} = a_{n+m}+C \le a_n+a_m+C+C = b_n+b_m.$$

Therefore,

$$\lim_{n\to\infty}\frac{b_n}{n} = \inf_{n\in\mathbb{N}}\frac{b_n}{n} = \inf_{n\in\mathbb{N}}\frac{a_n+C}{n}.$$

On the other hand,

$$\left|\frac{b_n}{n}-\frac{a_n}{n}\right| = \frac{C}{n}\to 0,$$

so the two sequences have the same limit. Hence,

$$\lim_{n\to\infty}\frac{a_n}{n} = \inf_{n\in\mathbb{N}}\frac{a_n+C}{n}.$$

∎

:::
