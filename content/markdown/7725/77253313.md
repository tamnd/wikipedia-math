# Game form

::: {#o1 .subject cue=lead name="Game form"}

In [game theory](wikipedia://en/11924) and related fields, a **game form**, **game frame**, **ruleset**, or **outcome function** is the set of [rules](https://en.wikipedia.org/wiki/Game_rule) that govern a game and determine its outcome based on each player's choices. A game form differs from a game in that it does not stipulate the [utilities](wikipedia://en/45479) or payoffs for each agent.[^o4]

:::

[Mathematically](wikipedia://en/18831), a game form can be defined as a [mapping](wikipedia://en/516931) going [from](wikipedia://en/50263) an *action* *space[^o2]*[^o3]—which describes all the possible moves a player can make—[to](wikipedia://en/50264) an *outcome space*. The action space is also often called a *message space* when the actions consist of providing information about beliefs or preferences, in which case it is called a **direct mechanism**.[^o3] For example, an [electoral system](wikipedia://en/29066482) is a game form mapping a message space consisting of [ballots](https://en.wikipedia.org/wiki/Ballot) to a winning candidate (the outcome).[^o4] Similarly, an [auction](https://en.wikipedia.org/wiki/Auction) is a game form that takes each [bidder's price](https://en.wikipedia.org/wiki/Bid_price) and maps them to both a winner and a set of payments by the bidders.

Often, a game form is a set of rules or [institutions](https://en.wikipedia.org/wiki/Institution) designed to implement some [normative](https://en.wikipedia.org/wiki/Normative_economics) goal (called a [social choice function](https://en.wikipedia.org/wiki/Social_choice_function)), by motivating [agents](https://en.wikipedia.org/wiki/Agent_%28economics%29) to act in a particular way through an appropriate choice of [incentives](https://en.wikipedia.org/wiki/Incentive). Then, the game form is called an **implementation** or **[mechanism](wikipedia://en/689895)**. This approach is widely used in the study of [auctions](wikipedia://en/5827247) and [electoral systems](wikipedia://en/29066482).[^o5]

The social choice function represents the desired outcome or goal of the game, such as maximizing social welfare or achieving a fair allocation of resources. The [mechanism designer](wikipedia://en/689895)'s task is to design the game form in such a way that when each player plays their best response (i.e. behaves strategically), the resulting equilibrium implements the desired social choice function.
