# Nonlinear complementarity problem

::: {#o1 .subject cue=lead name="Nonlinear complementarity problem"}

In [applied mathematics](wikipedia://en/24295969), a **nonlinear complementarity problem** (**NCP**) with respect to a mapping *ƒ* : **R**<sup>*n*</sup> → **R**<sup>*n*</sup>, denoted by NCP*ƒ*, is to find a vector *x* ∈ **R**<sup>*n*</sup> such that

:::

$$x \geq 0,\ f(x) \geq 0 \text{ and } x^{T}f(x)=0$$

where *ƒ*(*x*) is a smooth mapping. The case of a discontinuous mapping was discussed by Habetler and Kostreva (1978).
