# Conjugacy class sum

::: {#o1 .subject cue=lead name="Conjugacy class sum"}

In [abstract algebra](wikipedia://en/19616384), a **conjugacy class sum**, or simply **class sum**, is a [function](wikipedia://en/185427) defined for each [conjugacy class](wikipedia://en/49176) of a [finite](wikipedia://en/323707) [group](wikipedia://en/19447) *G* as the sum of the elements in that conjugacy class. The class sums of a group form a basis for the [center](wikipedia://en/342453) of the associated [group algebra](wikipedia://en/349223#Group_algebra_over_a_finite_group).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *G* be a finite group, and let *C*<sub>1</sub>,...,*C*<sub>*k*</sub> be the distinct conjugacy classes of *G*. For 1 ≤ *i* ≤ *k*, define

$$\overline{C_i}=\sum_{g\in C_i}g.$$

The functions $\overline{C_1},\ldots,\overline{C_k}$ are the class sums of *G*.

:::

## In the group algebra {#In_the_group_algebra}

Let **C***G* be the [complex](wikipedia://en/5826) group algebra over *G*. Then the center of **C***G*, denoted Z(**C***G*), is defined by

$$\operatorname{Z}(\mathbf{C}G) = \{f \in \mathbf{C}G \mid \forall g\in \mathbf{C}G, fg = gf \}.$$

This is equal to the set of all [class functions](wikipedia://en/1001329) (functions which are constant on conjugacy classes). To see this, note that *f* is central [if and only if](wikipedia://en/14922) *f*(*yx*) = *f*(*xy*) for all *x*,*y* in *G*. Replacing *y* by *yx*<sup>−1</sup>, this condition becomes

$$f(xyx^{-1})=f(y) \text{ for } x,y \in G.$$

The class sums are a basis for the set of all class functions, and thus they are a basis for the center of the algebra.

In particular, this shows that the dimension of *Z*(**C***G*) is equal to the number of class sums of *G*.
