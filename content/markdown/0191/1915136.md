# Code-talker paradox

::: {#o1 .subject cue=lead name="Code-talker paradox"}

A **code-talker paradox** is a situation in which a [language](https://en.wikipedia.org/wiki/Language) prevents communication. As an issue in [linguistics](https://en.wikipedia.org/wiki/Linguistics), the [paradox](wikipedia://en/24390) raises questions about the fundamental nature of languages. As such, the paradox is a problem in [philosophy of language](https://en.wikipedia.org/wiki/Philosophy_of_language).

:::

The term code-talker paradox was coined in 2001 by [Mark Baker](https://en.wikipedia.org/wiki/Mark_Baker_%28linguist%29) to describe the Navajo code talking used during [World War II](https://en.wikipedia.org/wiki/World_War_II). [Code talkers](https://en.wikipedia.org/wiki/Code_talkers) are able to create a language [mutually intelligible](https://en.wikipedia.org/wiki/Mutually_intelligible) to each other but completely unintelligible to everyone who does not know the code. This causes a conflict of interests without actually causing any conflict at all. In the case of Navajo code-talkers, [cryptanalysts](https://en.wikipedia.org/wiki/Cryptanalysts) were unable to decode messages in [Navajo](https://en.wikipedia.org/wiki/Navajo_Language), even when using the most sophisticated methods available. At the same time, the code talkers were able to encrypt and decrypt messages quickly and easily by translating them into and from Navajo. Thus the code talker paradox refers to how human languages can be so similar and different at once: so similar that one can learn them both and gain the ability to translate from one to the other, yet so different that if someone knows one language but does not know another, it is not always possible to derive the meaning of a text by analyzing it or infer it from the other language.
