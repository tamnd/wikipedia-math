# Feasible region

*Image: IP polytope with LP relaxation.svg.* A problem with five linear constraints (in blue, including the non-negativity constraints). In the absence of integer constraints the feasible set is the entire region bounded by blue, but with [integer constraints](https://en.wikipedia.org/wiki/Integer_constraint) it is the set of red dots.

*Image: 3dpoly.svg.* A closed feasible region of a [linear programming](wikipedia://en/43730) problem with three variables is a convex [polyhedron](wikipedia://en/23470).

::: {#o1 .subject cue=lead name="Feasible region"}

In [mathematical optimization](wikipedia://en/52033) and [computer science](https://en.wikipedia.org/wiki/Computer_science), a **feasible region,** **feasible set,** or **solution space** is the set of all possible points (sets of values of the choice variables) of an [optimization problem](wikipedia://en/1126536) that satisfy the problem's [constraints](wikipedia://en/7418540), potentially including [inequalities](wikipedia://en/89489), [equalities](wikipedia://en/90446), and [integer](wikipedia://en/14563) constraints.[^o2] This is the initial set of [candidate solutions](https://en.wikipedia.org/wiki/Candidate_solution) to the problem, before the set of candidates has been narrowed down.

:::

For example, consider the problem of minimizing the function $x^2+y^4$ with respect to the variables $x$ and $y,$ subject to $1 \le x \le 10$ and $5 \le y \le 12. \,$ Here the feasible set is the set of pairs (*x*, *y*) in which the value of *x* is at least 1 and at most 10 and the value of *y* is at least 5 and at most 12. The feasible set of the problem is separate from the [objective function](https://en.wikipedia.org/wiki/Objective_function), which states the criterion to be optimized and which in the above example is $x^2+y^4.$

In many problems, the feasible set reflects a constraint that one or more variables must be non-negative. In pure [integer programming](wikipedia://en/411215) problems, the feasible set is the set of integers (or some subset thereof). In [linear programming](wikipedia://en/43730) problems, the feasible set is a [convex](wikipedia://en/6292) [polytope](wikipedia://en/23471): a region in [multidimensional space](https://en.wikipedia.org/wiki/Dimension_%28mathematics_and_physics%29) whose boundaries are formed by [hyperplanes](https://en.wikipedia.org/wiki/Hyperplanes) and whose corners are [vertices](wikipedia://en/11308417).

[Constraint satisfaction](https://en.wikipedia.org/wiki/Constraint_satisfaction) is the process of finding a point in the feasible region.

## Convex feasible set {#Convex_feasible_set}

*Image: Solution Spaces.jpg.* A unimodal, convex solution space with a single global minimum (left), and a nonlinear, multimodal solution space with multiple local minima (right).

A [convex](wikipedia://en/6292) feasible set is one in which a line segment connecting any two feasible points goes through only other feasible points, and not through any points outside the feasible set. Convex feasible sets arise in many types of problems, including linear programming problems, and they are of particular interest because, if the problem has a [convex objective function](wikipedia://en/245568) that is to be minimized, it will generally be easier to solve in the presence of a convex feasible set and any [local optimum](https://en.wikipedia.org/wiki/Local_optimum) will also be a [global optimum](https://en.wikipedia.org/wiki/Global_optimum).

## No feasible set {#No_feasible_set}

If the constraints of an optimization problem are mutually contradictory, there are no points that satisfy all the constraints and thus the feasible region is the [empty set](wikipedia://en/9566). In this case the problem has no solution and is said to be *infeasible*.

## Bounded and unbounded feasible sets {#Bounded_and_unbounded_feasible_sets}

*Image: Bounded unbounded.svg.* A bounded feasible set (top) and an unbounded feasible set (bottom). The set at the bottom continues forever towards the right.

Feasible sets may be [bounded or unbounded](wikipedia://en/48258). For example, the feasible set defined by the constraint set {*x* ≥ 0, *y* ≥ 0} is unbounded because in some directions there is no limit on how far one can go and still be in the feasible region. In contrast, the feasible set formed by the constraint set {*x* ≥ 0, *y* ≥ 0, *x* + 2*y* ≤ 4} is bounded because the extent of movement in any direction is limited by the constraints.

In linear programming problems with *n* variables, a [necessary but insufficient condition](https://en.wikipedia.org/wiki/Necessary_and_sufficient_conditions) for the feasible set to be bounded is that the number of constraints be at least *n* + 1 (as illustrated by the above example).

If the feasible set is unbounded, there may or may not be an optimum, depending on the specifics of the objective function. For example, if the feasible region is defined by the constraint set {*x* ≥ 0, *y* ≥ 0}, then the problem of maximizing *x* + *y* has no optimum since any candidate solution can be improved upon by increasing *x* or *y*; yet if the problem is to *minimize* *x* + *y*, then there is an optimum (specifically at (*x*, *y*) = (0, 0)).

## Candidate solution {#Candidate_solution}

In [optimization](wikipedia://en/52033) and other branches of [mathematics](wikipedia://en/18831), and in [search algorithms](https://en.wikipedia.org/wiki/Search_algorithm) (a topic in [computer science](https://en.wikipedia.org/wiki/Computer_science)), a **candidate solution** is a [member](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of the [set](wikipedia://en/26691) of possible solutions in the feasible region of a given problem.[^o8] A candidate solution does not have to be a likely or reasonable solution to the problem—it is simply in the set that satisfies all [constraints](wikipedia://en/7418540); that is, it is in the set of *feasible solutions*. Algorithms for solving various types of optimization problems often narrow the set of candidate solutions down to a subset of the feasible solutions, whose points remain as candidate solutions while the other feasible solutions are henceforth excluded as candidates.

The space of all candidate solutions, before any feasible points have been excluded, is called the feasible region, feasible set, search space, or solution space.[^o8] This is the set of all possible solutions that satisfy the problem's constraints. [Constraint satisfaction](https://en.wikipedia.org/wiki/Constraint_satisfaction) is the process of finding a point in the feasible set.

### Genetic algorithm {#Genetic_algorithm}

In the case of the [genetic algorithm](https://en.wikipedia.org/wiki/Genetic_algorithm), the candidate solutions are the individuals in the population being evolved by the algorithm.[^o10]

### Calculus {#Calculus}

In calculus, an optimal solution is sought using the [first derivative test](https://en.wikipedia.org/wiki/First_derivative_test): the [first derivative](https://en.wikipedia.org/wiki/First_derivative) of the function being optimized is equated to zero, and any values of the choice variable(s) that satisfy this equation are viewed as candidate solutions (while those that do not are ruled out as candidates). There are several ways in which a candidate solution might not be an actual solution. First, it might give a minimum when a maximum is being sought (or vice versa), and second, it might give neither a minimum nor a maximum but rather a [saddle point](wikipedia://en/640249) or an [inflection point](wikipedia://en/379845), at which a temporary pause in the local rise or fall of the function occurs. Such candidate solutions may be able to be ruled out by use of the [second derivative test](https://en.wikipedia.org/wiki/Second_derivative_test), the satisfaction of which is sufficient for the candidate solution to be at least locally optimal. Third, a candidate solution may be a [local optimum](https://en.wikipedia.org/wiki/Local_optimum) but not a [global optimum](https://en.wikipedia.org/wiki/Global_optimum).

In taking [antiderivatives](wikipedia://en/2823) of [monomials](wikipedia://en/357416) of the form $x^n,$ the candidate solution using [Cavalieri's quadrature formula](wikipedia://en/30839740) would be $\tfrac{1}{n+1}x^{n+1}+C.$ This candidate solution is in fact correct except when $n=-1.$

### Linear programming {#Linear_programming}

*Image: Linear\_Programming\_Feasible\_Region.svg.* A series of [linear programming](wikipedia://en/43730) constraints on two variables produce a region of possible values for those variables. Solvable two-variable problems will have a feasible region in the shape of a [convex](wikipedia://en/6292) [simple polygon](wikipedia://en/1059530) if it is bounded. In an algorithm that tests feasible points sequentially, each tested point is in turn a candidate solution.

In the [simplex method](https://en.wikipedia.org/wiki/Simplex_method) for solving [linear programming](wikipedia://en/43730) problems, a [vertex](wikipedia://en/11308417) of the feasible [polytope](wikipedia://en/23471) is selected as the initial candidate solution and is tested for optimality; if it is rejected as the optimum, an adjacent vertex is considered as the next candidate solution. This process is continued until a candidate solution is found to be the optimum.
