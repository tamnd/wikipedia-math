# Weight function

::: {#o1 .subject cue=lead name="Weight function"}

A **weight function** is a mathematical device used when performing a sum, integral, or average to give some elements more "weight" or influence on the result than other elements in the same set. The result of this application of a weight function is a **weighted sum** or [weighted average](wikipedia://en/189822). Weight functions occur frequently in [statistics](wikipedia://en/26685) and [analysis](wikipedia://en/48396), and are closely related to the concept of a [measure](wikipedia://en/19873). Weight functions can be employed in both discrete and continuous settings. They can be used to construct systems of calculus called "weighted calculus"[^o2] and "meta-calculus".[^o3]

:::

## Discrete weights {#Discrete_weights}

::: {#o6 .definition cue=heading name="General definition"}

### General definition {#General_definition}

In the discrete setting, a weight function $w \colon A \to \mathbb{R}^+$ is a positive function defined on a [discrete](wikipedia://en/8492) [set](wikipedia://en/26691) $A$, which is typically [finite](wikipedia://en/11742) or [countable](https://en.wikipedia.org/wiki/Countable). The weight function $w(a) := 1$ corresponds to the *unweighted* situation in which all elements have equal weight. One can then apply this weight to various concepts.

If the function $f\colon A \to \mathbb{R}$ is a [real](wikipedia://en/20646438)-valued [function](https://en.wikipedia.org/wiki/Mathematical_function), then the *unweighted [sum](wikipedia://en/246160) of $f$ on $A$* is defined as

$$\sum_{a \in A} f(a);$$

but given a *weight function* $w\colon A \to \mathbb{R}^+$, the **weighted sum** or [conical combination](wikipedia://en/19634578) is defined as

$$\sum_{a \in A} f(a) w(a).$$

One common application of weighted sums arises in [numerical integration](wikipedia://en/170089).

If *B* is a [finite](wikipedia://en/11742) subset of *A*, one can replace the unweighted [cardinality](wikipedia://en/6174) |*B*| of *B* by the *weighted cardinality*

$$\sum_{a \in B} w(a).$$

If *A* is a [finite](wikipedia://en/11742) non-empty set, one can replace the unweighted [mean](https://en.wikipedia.org/wiki/Mean) or [average](wikipedia://en/60167)

$$\frac{1}{|A|} \sum_{a \in A} f(a)$$

by the [weighted mean](https://en.wikipedia.org/wiki/Weighted_mean) or [weighted average](wikipedia://en/189822)

$$\frac{\sum_{a \in A} f(a) w(a)}{\sum_{a \in A} w(a)}.$$

In this case only the *relative* weights are relevant.

:::

### Statistics {#Statistics}

Weighted means are commonly used in [statistics](wikipedia://en/26685) to compensate for the presence of [bias](wikipedia://en/184099). For a quantity $f$ measured multiple independent times $f_i$ with [variance](wikipedia://en/32344) $\sigma^2_i$, the best estimate of the signal is obtained by averaging all the measurements with weight $w_i = 1 / {\sigma_i^2}$, and the resulting variance is smaller than each of the independent measurements $\sigma^2 = 1 / \sum_i w_i$. The [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) method weights the difference between fit and data using the same weights $w_i$.

The [expected value](wikipedia://en/9653) of a random variable is the weighted average of the possible values it might take on, with the weights being the respective [probabilities](wikipedia://en/22934). More generally, the expected value of a function of a random variable is the probability-weighted average of the values the function takes on for each possible value of the random variable.

In [regressions](wikipedia://en/48758386) in which the [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable) is assumed to be affected by both current and lagged (past) values of the [independent variable](https://en.wikipedia.org/wiki/Independent_variable), a [distributed lag](wikipedia://en/15438225) function is estimated, this function being a weighted average of the current and various lagged independent variable values. Similarly, a [moving average model](https://en.wikipedia.org/wiki/Moving_average_model) specifies an evolving variable as a weighted average of current and various lagged values of a random variable.

### Mechanics {#Mechanics}

The terminology *weight function* arises from [mechanics](https://en.wikipedia.org/wiki/Mechanics): if one has a collection of $n$ objects on a [lever](https://en.wikipedia.org/wiki/Lever), with weights $w_1, \ldots, w_n$ (where [weight](https://en.wikipedia.org/wiki/Weight) is now interpreted in the physical sense) and locations $\boldsymbol{x}_1,\dotsc,\boldsymbol{x}_n$, then the lever will be in balance if the [fulcrum](https://en.wikipedia.org/wiki/Lever) of the lever is at the [center of mass](wikipedia://en/173961)

$$\frac{\sum_{i=1}^n w_i \boldsymbol{x}_i}{\sum_{i=1}^n w_i},$$

which is also the weighted average of the positions $\boldsymbol{x}_i$.

## Continuous weights {#Continuous_weights}

In the continuous setting, a weight is a positive [measure](wikipedia://en/19873) such as $w(x) \, dx$ on some [domain](wikipedia://en/16796643) $\Omega$, which is typically a [subset](wikipedia://en/27631) of a [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$. For instance, $\Omega$ could be an [interval](wikipedia://en/49172) $[a,b]$. Here $dx$ is [Lebesgue measure](wikipedia://en/18198) and $w\colon \Omega \to \mathbb{R}^+$ is a non-negative [measurable](https://en.wikipedia.org/wiki/Measurable) [function](https://en.wikipedia.org/wiki/Mathematical_function). In this context, the weight function $w(x)$ is sometimes referred to as a [density](https://en.wikipedia.org/wiki/Density).

::: {#o11 .definition cue=heading name="General definition"}

### General definition {#General_definition}

If $f\colon \Omega \to \mathbb{R}$ is a [real](wikipedia://en/20646438)-valued [function](https://en.wikipedia.org/wiki/Mathematical_function), then the *unweighted* [integral](wikipedia://en/15532)

$$\int_\Omega f(x)\ dx$$

can be generalized to the *weighted integral*

$$\int_\Omega f(x) w(x)\, dx$$

Note that one may need to require $f$ to be [absolutely integrable](https://en.wikipedia.org/wiki/Absolutely_integrable_function) with respect to the weight $w(x) \, dx$ in order for this integral to be finite.

:::

### Weighted volume {#Weighted_volume}

If *E* is a subset of $\Omega$, then the [volume](wikipedia://en/32498) vol(*E*) of *E* can be generalized to the *weighted volume*

$$\int_E w(x)\ dx,$$

### Weighted average {#Weighted_average}

If $\Omega$ has finite non-zero weighted volume, then we can replace the unweighted [average](wikipedia://en/60167)

$$\frac{1}{\mathrm{vol}(\Omega)} \int_\Omega f(x)\ dx$$

by the **weighted average**

$$\frac{\displaystyle\int_\Omega f(x)\, w(x) \, dx}{\displaystyle\int_\Omega w(x) \, dx}$$

### Bilinear form {#Bilinear_form}

If $f\colon \Omega \to {\mathbb R}$ and $g\colon \Omega \to {\mathbb R}$ are two functions, one can generalize the unweighted [bilinear form](wikipedia://en/449477)

$$\langle f, g \rangle := \int_\Omega f(x) g(x)\ dx$$

to a weighted bilinear form

$${\langle f, g \rangle}_w := \int_\Omega f(x) g(x) w(x)\ dx.$$

See the entry on [orthogonal polynomials](wikipedia://en/32811718) for examples of weighted [orthogonal functions](wikipedia://en/453041).
