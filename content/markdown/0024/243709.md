# Cubic function

*Image: Polynomialdeg3.svg.* Graph of a cubic function with 3 [real](wikipedia://en/20646438) [roots](https://en.wikipedia.org/wiki/Root_of_a_function) (where the curve crosses the horizontal axis—where $y = 0$). The case shown has two [critical points](wikipedia://en/1951424). Here the function is $f(x) = (x^{3} + 3x^{2} - 6x - 8)/4$.

::: {#o1 .subject cue=lead name="Cubic function"}

In [mathematics](wikipedia://en/18831), a **cubic function** is a [function](wikipedia://en/185427) of the form

$$f(x)=ax^3+bx^2+cx+d,$$

with $a\neq 0$, that is, a [polynomial function](https://en.wikipedia.org/wiki/Polynomial_function) of degree three. In many texts, the *coefficients* $a$, $b$, $c$, and $d$ are supposed to be [real numbers](https://en.wikipedia.org/wiki/Real_numbers), and the function is considered as a [real function](https://en.wikipedia.org/wiki/Real_function) that maps real numbers to real numbers or as a complex function that maps [complex numbers](wikipedia://en/5826) to complex numbers. In other cases, the coefficients may be complex numbers, and the function is a complex function that has the set of the complex numbers as its [codomain](wikipedia://en/50264), even when the [domain](wikipedia://en/50263) is restricted to the real numbers.

:::

Setting $f(x) = 0$ produces a [cubic equation](wikipedia://en/180787) of the form

$$ax^3+bx^2+cx+d=0,$$

whose solutions are called [roots](https://en.wikipedia.org/wiki/Root_of_a_function) of the function. The [derivative](wikipedia://en/7921) of a cubic function is a [quadratic function](wikipedia://en/187240).

A cubic function with real coefficients has either one or three real roots ([which may not be distinct](wikipedia://en/19211790));[^o2] all odd-degree polynomials with real coefficients have at least one real root.

The [graph](wikipedia://en/87352) of a cubic function always has a single [inflection point](wikipedia://en/379845). It may have two [critical points](wikipedia://en/1951424), a local minimum and a local maximum. Otherwise, a cubic function is [monotonic](https://en.wikipedia.org/wiki/Monotonic). The graph of a cubic function is symmetric with respect to its inflection point; that is, it is invariant under a rotation of a half turn around this point. [Up to](wikipedia://en/44787) an [affine transformation](wikipedia://en/38449), there are only three possible graphs for cubic functions.

Cubic functions are fundamental for [cubic interpolation](https://en.wikipedia.org/wiki/Cubic_interpolation).

## Critical and inflection points {#Critical_and_inflection_points}

The [critical points](wikipedia://en/1951424) of a cubic function are its [stationary points](wikipedia://en/885651), that is the points where the slope of the function is zero.[^o5] Thus the critical points of a cubic function $f$ defined by

$$f(x) = ax^{3} + bx^{2} + cx + d,$$

occur at values of $x$ such that the [derivative](wikipedia://en/7921)

$$3ax^2 + 2bx + c = 0$$

of the cubic function is zero.

The solutions of this equation are the $x$-values of the critical points and are given, using the [quadratic formula](wikipedia://en/59217), by

$$x_\text{critical}=\frac{-b \pm \sqrt {b^2-3ac}}{3a}.$$

The sign of the expression $\Delta_{0} =$$b^{2} - 3ac$ inside the square root determines the number of critical points. If it is positive, then there are two critical points, one is a local maximum, and the other is a local minimum. If $b^{2} - 3ac = 0$, then there is only one critical point, which is an [inflection point](wikipedia://en/379845). If $b^{2} - 3ac < 0$, then there are no (real) critical points. In the two latter cases, that is, if $b^{2} - 3ac$ is nonpositive, the cubic function is strictly [monotonic](https://en.wikipedia.org/wiki/Monotonic). See the figure for an example of the case $\Delta_{0} > 0$.

The inflection point of a function is where that function changes [concavity](wikipedia://en/3224219#Concavity).[^o6] An inflection point occurs when the [second derivative](wikipedia://en/3224219) $f''(x) = 6ax + 2b,$ is zero, and the third derivative is nonzero. Thus a cubic function has always a single inflection point, which occurs at

$$x_\text{inflection} = -\frac{b}{3a}.$$

## Classification {#Classification}

*Image: Cubic function (different c).svg.* Cubic functions of the form $y=x^3+cx.$The graph of any cubic function is [similar](wikipedia://en/39377) to such a curve.

The [graph](wikipedia://en/87352) of a cubic function is a [cubic curve](https://en.wikipedia.org/wiki/Cubic_curve), though many cubic curves are not graphs of functions.

Although cubic functions depend on four parameters, their graph can have only very few shapes. In fact, the graph of a cubic function is always [similar](wikipedia://en/39377) to the graph of a function of the form

$$y=x^3+px.$$

This similarity can be built as the composition of [translations](https://en.wikipedia.org/wiki/Translation) parallel to the coordinates axes, a [homothecy](https://en.wikipedia.org/wiki/Homothecy) ([uniform scaling](https://en.wikipedia.org/wiki/Uniform_scaling)), and, possibly, a [reflection](wikipedia://en/295829) ([mirror image](https://en.wikipedia.org/wiki/Mirror_image)) with respect to the $y$-axis. A further [non-uniform scaling](https://en.wikipedia.org/wiki/Uniform_scaling) can transform the graph into the graph of one among the three cubic functions

$$\begin{aligned} y&=x^3+x\\ y&=x^3\\ y&=x^3-x. \end{aligned}$$

This means that there are only three graphs of cubic functions [up to](wikipedia://en/44787) an [affine transformation](wikipedia://en/38449).

The above [geometric transformations](wikipedia://en/43194879) can be built in the following way, when starting from a general cubic function $y=ax^3+bx^2+cx+d.$

Firstly, if $a < 0$, the [change of variable](https://en.wikipedia.org/wiki/Change_of_variable) $x \to -x$ allows supposing $a > 0$. After this change of variable, the new graph is the mirror image of the previous one, with respect of the $y$-axis.

Then, the change of variable $x = x_{1} - \tfrac{b}{3a}$ provides a function of the form

$$y=ax_1^3+px_1+q.$$

This corresponds to a translation parallel to the $x$-axis.

The change of variable $y = y_{1} + q$ corresponds to a translation with respect to the $y$-axis, and gives a function of the form

$$y_1=ax_1^3+px_1.$$

The change of variable $\textstyle x_1=\frac {x_2}\sqrt a, y_1=\frac {y_2}\sqrt a$ corresponds to a uniform scaling, and give, after multiplication by $\sqrt a,$ a function of the form

$$y_2=x_2^3+px_2,$$

which is the simplest form that can be obtained by a similarity.

Then, if $p \ne 0$, the non-uniform scaling $\textstyle x_2=x_3\sqrt{|p|},\quad y_2=y_3\sqrt{|p|^3}$ gives, after division by $\textstyle \sqrt{|p|^3},$

$$y_3 =x_3^3 + x_3\operatorname{sgn}(p),$$

where $\operatorname{sgn}(p)$ has the value 1 or −1, depending on the sign of $p$. If one defines $\operatorname{sgn}(0)=0,$ the latter form of the function applies to all cases (with $x_2 = x_3$ and $y_2 = y_3$).

## Symmetry {#Symmetry}

For a cubic function of the form $y=x^3+px,$ the inflection point is thus the origin. As such a function is an [odd function](https://en.wikipedia.org/wiki/Odd_function), its graph is symmetric with respect to the inflection point, and invariant under a rotation of a half turn around the inflection point. As these properties are invariant by [similarity](wikipedia://en/39377), the following is true for all cubic functions.

*The graph of a cubic function is symmetric with respect to its inflection point, and is invariant under a rotation of a half turn around the inflection point.*

:::

## Collinearities {#Collinearities}

*Image: Cubica colinear.png.* The points $P_{1}$, $P_{2}$, and $P_{3}$ (in blue) are collinear and belong to the graph of $x^{3} + \tfrac{3}{2}x^{2} - \tfrac{5}{2}x + \tfrac{5}{4}$. The points $T_{1}$, $T_{2}$, and $T_{3}$ (in red) are the intersections of the (dotted) tangent lines to the graph at these points with the graph itself. They are collinear too.

The tangent lines to the graph of a cubic function at three [collinear points](https://en.wikipedia.org/wiki/Collinear_points) intercept the cubic again at collinear points.[^o11] This can be seen as follows.

As this property is invariant under a [rigid motion](https://en.wikipedia.org/wiki/Rigid_motion), one may suppose that the function has the form

$$f(x)=x^3+px.$$

If $\alpha$ is a real number, then the tangent to the graph of $f$ at the point $(\alpha, f(\alpha))$ is the line $\{(x, f(\alpha) + (x - \alpha)f\,'(\alpha)) : x \in \mathbf{R}\}$ So, the intersection point between this line and the graph of $f$ can be obtained solving the equation $f(x) = f(\alpha) + (x - \alpha)f\,'(\alpha)$, that is

$$x^3+px=\alpha^3+p\alpha+ (x-\alpha)(3\alpha^2+p),$$

which can be rewritten

$$x^3 - 3\alpha^2 x +2\alpha^3=0,$$

and factorized as

$$(x-\alpha)^2(x+2\alpha)=0.$$

So, the tangent intercepts the cubic at

$$(-2\alpha, -8\alpha^3-2p\alpha)=(-2\alpha, -8f(\alpha)+6p\alpha).$$

So, the function that maps a point $(x, y)$ of the graph to the other point where the tangent intercepts the graph is

$$(x,y)\mapsto (-2x, -8y+6px).$$

This is an [affine transformation](wikipedia://en/38449) that transforms collinear points into collinear points. This proves the claimed result.

## Cubic interpolation {#Cubic_interpolation}

Given the values of a function and its derivative at two points, there is exactly one cubic function that has the same four values, which is called a [cubic Hermite spline](wikipedia://en/656586).

There are two standard ways for using this fact. Firstly, if one knows, for example by physical measurement, the values of a function and its derivative at some sampling points, one can *interpolate* the function with a [continuously differentiable function](https://en.wikipedia.org/wiki/Continuously_differentiable_function), which is a [piecewise](https://en.wikipedia.org/wiki/Piecewise) cubic function.

If the value of a function is known at several points, [cubic interpolation](https://en.wikipedia.org/wiki/Cubic_interpolation) consists in approximating the function by a [continuously differentiable function](https://en.wikipedia.org/wiki/Continuously_differentiable_function), which is [piecewise](https://en.wikipedia.org/wiki/Piecewise) cubic. For having a uniquely defined interpolation, two more constraints must be added, such as the values of the derivatives at the endpoints, or a zero [curvature](wikipedia://en/60770) at the endpoints.
