# Inverse Laplace transform

::: {#o1 .subject cue=lead name="Inverse Laplace transform"}

In [mathematics](wikipedia://en/18831), the **inverse Laplace transform** of a [function](wikipedia://en/185427) $F$ is a [real](wikipedia://en/20646438) function $f$ that is piecewise-[continuous](wikipedia://en/6122), exponentially-restricted (that is, $|f(t)|\leq Me^{\alpha t}$ $\forall t \geq 0$ for some constants $M > 0$ and $\alpha \in \mathbb{R}$) and has the property:

:::

$$\mathcal{L}\{f\}(s) = F(s),$$

where $\mathcal{L}$ denotes the [Laplace transform](wikipedia://en/18610).

It can be proven that, if a function $F$ has the inverse Laplace transform $f$, then $f$ is uniquely determined (considering functions that differ from each other only on a point set having [Lebesgue measure](wikipedia://en/18198) zero as the same). This result was first proven by [Mathias Lerch](wikipedia://en/4436105) in 1903 and is known as Lerch's theorem.[^o2][^o3]

The [Laplace transform](wikipedia://en/18610) and the inverse Laplace transform together have a number of properties that make them useful for analysing [linear dynamical systems](wikipedia://en/4786318).

::: {#o5 .statement cue=named-heading name="Bromwich's inverse formula"}

## Bromwich's inverse formula {#Bromwich's_inverse_formula}

There is an integral formula for the inverse [Laplace transform](wikipedia://en/18610), called the [*Bromwich*](https://en.wikipedia.org/wiki/Thomas_John_I'Anson_Bromwich)*'s inversion formula*[^o6] and is given by the [line integral](wikipedia://en/21245414):

$$f(t) = \mathcal{L}^{-1} \{F(s)\}(t) = \frac{1}{2\pi i}\lim_{T\to\infty}\int_{\gamma-iT}^{\gamma+iT}e^{st}F(s)\,ds$$

where the integration is done along the vertical line $\textrm{Re}(s) = \gamma$ in the [complex plane](wikipedia://en/217628) such that $\gamma$ is greater than the real part of all [singularities](https://en.wikipedia.org/wiki/Mathematical_singularity) of $F$ and $F$ is bounded on the line, for example if the contour path is in the [region of convergence](https://en.wikipedia.org/wiki/Region_of_convergence).

In the common special case where *all* singularities, $s_k$, satisfy $\Re(s_k)<0$ (i.e., lie in the open left half‑plane), or $F$ is an [entire function](wikipedia://en/10372), then $\gamma$ can be set to zero and the above inverse integral formula becomes identical to the [inverse Fourier transform](https://en.wikipedia.org/wiki/Inverse_Fourier_transform).

In practice, computing the complex integral can be done by using the [Cauchy residue theorem](https://en.wikipedia.org/wiki/Cauchy_residue_theorem).

This integral is closely related to the [Mellin inversion theorem](wikipedia://en/1498625) for the [Mellin transform](wikipedia://en/387297).

:::

::: {#o8 .statement cue=named-heading name="Post's inversion formula"}

## Post's inversion formula {#Post's_inversion_formula}

**Post's inversion formula** for [Laplace transforms](wikipedia://en/18610), named after [Emil Post](wikipedia://en/362382),[^o9] is a simple-looking but usually impractical formula for evaluating an inverse Laplace transform.

The statement of the formula is as follows: Let $f$ be a continuous function on the interval $[0,\infty)$ of exponential order, i.e.

$$\sup_{t>0} \frac{f(t)}{e^{bt}} < \infty$$

for some real number $b$. Then for all $s > b$, the Laplace transform for $f$ exists and is infinitely differentiable with respect to $s$. Furthermore, if $F$ is the Laplace transform of $f$, then the inverse Laplace transform of $F$ is given by

$$f(t) = \mathcal{L}^{-1} \{F\}(t) = \lim_{k \to \infty} \frac{(-1)^k}{k!} \left( \frac{k}{t} \right) ^{k+1} F^{(k)} \left( \frac{k}{t} \right)$$

for $t > 0$, where $F^{(k)}$ is the $k$th derivative of $F$ with respect to $s$.

As can be seen from the formula, the need to evaluate derivatives of arbitrarily high orders renders this formula impractical for most purposes.

With the advent of powerful personal computers, the main efforts to use this formula have come from dealing with approximations or asymptotic analysis of the inverse Laplace transform, using the [Grunwald–Letnikov differintegral](https://en.wikipedia.org/wiki/Grunwald–Letnikov_differintegral) to evaluate the derivatives.

Post's inversion has attracted interest due to the improvement in computational science and the fact that it is not necessary to know where the [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) of $F$ lie, which make it possible to calculate the asymptotic behaviour for big $x$ using inverse [Mellin transforms](wikipedia://en/387297) for several arithmetical functions related to the [Riemann hypothesis](wikipedia://en/19344125).
