# Strong cardinal

::: {#o1 .subject cue=lead name="Strong cardinal"}

In [set theory](wikipedia://en/27553), a **strong cardinal** is a type of [large cardinal](wikipedia://en/383644). It is a weakening of the notion of a [supercompact cardinal](wikipedia://en/248116).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

If λ is any [ordinal](wikipedia://en/26547932), κ is **λ-strong** means that κ is a [cardinal number](wikipedia://en/6173) and there exists an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* from the universe *V* into a transitive [inner model](wikipedia://en/1118686) *M* with [critical point](wikipedia://en/4888510) κ and

$$V_\lambda\subseteq M$$

That is, *M* agrees with *V* on an initial segment. Then κ is **strong** means that it is λ-strong for all ordinals λ.

:::

## Relationship with other large cardinals {#Relationship_with_other_large_cardinals}

By definitions, strong cardinals lie below [supercompact cardinals](wikipedia://en/248116) and above [measurable cardinals](wikipedia://en/248102) in the consistency strength hierarchy.

κ is κ+1-strong if and only if it is measurable. If κ is strong or λ-strong for λ ≥ κ+2, then the [ultrafilter](wikipedia://en/31911) *U* witnessing that κ is measurable will be in *V*<sub>κ+2</sub> and thus in *M*. So for any α \< κ, we have that there exist an ultrafilter *U* in *j*(*V*<sub>κ</sub>) − *j*(*V*<sub>α</sub>), remembering that *j*(α) = α. Using the elementary embedding backwards, we get that there is an ultrafilter in *V*<sub>κ</sub> − *V*<sub>α</sub>. So there are arbitrarily large measurable cardinals below κ which is regular, and thus κ is a limit of κ-many measurable cardinals.

Strong cardinals also lie below [superstrong cardinals](wikipedia://en/248114) and [Woodin cardinals](wikipedia://en/248105) in consistency strength. However, the least strong cardinal is larger than the least superstrong cardinal.

Every strong cardinal is [strongly unfoldable](wikipedia://en/853783) and therefore [totally indescribable](wikipedia://en/248097).
