# Local homeomorphism

::: {#o1 .subject cue=lead name="Local homeomorphism"}

In [mathematics](wikipedia://en/18831), more specifically [topology](wikipedia://en/29954), a **local homeomorphism** is a [function](wikipedia://en/185427) between [topological spaces](wikipedia://en/30450) that, intuitively, preserves local (though not necessarily global) structure. If $f : X \to Y$ is a local homeomorphism, $X$ is said to be an **étale space** over $Y.$ Local homeomorphisms are used in the study of [sheaves](wikipedia://en/245466). Typical examples of local homeomorphisms are [covering maps](https://en.wikipedia.org/wiki/Covering_map).

:::

A topological space $X$ is **locally homeomorphic** to $Y$ if every point of $X$ has a neighborhood that is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to an open subset of $Y.$ For example, a [manifold](wikipedia://en/2073470) of dimension $n$ is locally homeomorphic to $\mathbb{R}^n.$

If there is a local homeomorphism from $X$ to $Y,$ then $X$ is locally homeomorphic to $Y,$ but the converse is not always true. For example, the two dimensional [sphere](wikipedia://en/27859), being a manifold, is locally homeomorphic to the plane $\mathbb{R}^2,$ but there is no local homeomorphism $S^2 \to \mathbb{R}^2.$

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A function $f : X \to Y$ between two [topological spaces](wikipedia://en/30450) is called a local homeomorphism[^o4] if every point $x \in X$ has an [open neighborhood](https://en.wikipedia.org/wiki/Open_neighborhood) $U$ whose [image](wikipedia://en/579311) $f(U)$ is open in $Y$ and the [restriction](wikipedia://en/1589032) $f\big\vert_U : U \to f(U)$ is a [homeomorphism](wikipedia://en/13660) (where the respective [subspace topologies](wikipedia://en/910926) are used on $U$ and on $f(U)$).

:::

## Examples and sufficient conditions {#Examples_and_sufficient_conditions}

**Covering maps**

Every homeomorphism is a local homeomorphism. The function $\mathbb{R} \to S^1$ defined by $t \mapsto e^{it}$ (so that geometrically, this map wraps the [real line](https://en.wikipedia.org/wiki/Real_line) around the [circle](wikipedia://en/6220) in the complex plane) is a local homeomorphism but not a homeomorphism. The map $f : S^1 \to S^1$ defined by $f(z) = z^n,$ where $n$ is a fixed integer, wraps the circle around itself $n$ times (that is, has [winding number](wikipedia://en/86113) $n$) and is a local homeomorphism for all non-zero $n,$ but it is a homeomorphism only when it is [bijective](https://en.wikipedia.org/wiki/Bijective) (that is, only when $n = 1$ or $n = -1$).

Generalizing the previous two examples, every [covering map](wikipedia://en/250323) is a local homeomorphism; in particular, the [universal cover](https://en.wikipedia.org/wiki/Universal_cover) $p : C \to Y$ of a space $Y$ is a local homeomorphism. In certain situations the converse is true. For example: if $p : X \to Y$ is a [proper](wikipedia://en/1190262) local homeomorphism between two [Hausdorff spaces](wikipedia://en/13637) and if $Y$ is also [locally compact](https://en.wikipedia.org/wiki/Locally_compact), then $p$ is a covering map.

**Inclusion maps of open subsets**

If $U \subseteq X$ is any subspace (where as usual, $U$ is equipped with the [subspace topology](https://en.wikipedia.org/wiki/Subspace_%28topology%29) induced by $X$) then the [inclusion map](wikipedia://en/492516) $i : U \to X$ is always a [topological embedding](https://en.wikipedia.org/wiki/Topological_embedding). It is a local homeomorphism if and only if $U$ is open in $X.$

**Invariance of domain**

[Invariance of domain](wikipedia://en/210731) guarantees that if $f : U \to \mathbb{R}^n$ is a [continuous](wikipedia://en/6122) [injective map](https://en.wikipedia.org/wiki/Injective_map) from an open subset $U$ of $\mathbb{R}^n,$ then $f(U)$ is open in $\mathbb{R}^n$ and $f : U \to f(U)$ is a [homeomorphism](wikipedia://en/13660). Consequently, a continuous map $f : U \to \mathbb{R}^n$ from an open subset $U \subseteq \mathbb{R}^n$ will be a local homeomorphism if and only if it is a [*locally* injective map](https://en.wikipedia.org/wiki/Locally_injective_function) (meaning that every point in $U$ has a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) $N$ such that the restriction of $f$ to $N$ is injective).

**Local homeomorphisms in analysis**

It is shown in [complex analysis](wikipedia://en/5759) that a complex [analytic](wikipedia://en/14110) function $f : U \to \mathbb{C}$ (where $U$ is an open subset of the [complex plane](wikipedia://en/217628) $\mathbb{C}$) is a local homeomorphism precisely when the [derivative](wikipedia://en/7921) $f^{\prime}(z)$ is non-zero for all $z \in U.$ The function $f(z) = z^n$, with fixed integer $n$, defined on an open disk around $0$, is not a local homeomorphism when $n \geq 2.$ In that case $0$ is a point of "[ramification](wikipedia://en/384644)" (intuitively, $n$ sheets come together there).

Using the [inverse function theorem](wikipedia://en/287229) one can show that a continuously differentiable function $f : U \to \mathbb{R}^n$ (where $U$ is an open subset of $\mathbb{R}^n$) is a local homeomorphism if the derivative $D_x f$ is an invertible linear map (invertible square matrix) for every $x \in U.$ (The converse is false, as shown by the local homeomorphism $f : \mathbb{R} \to \mathbb{R}$ with $f(x) = x^3$). An analogous condition can be formulated for maps between [differentiable manifolds](wikipedia://en/2119219).

**Local homeomorphisms and Hausdorffness**

There exist local homeomorphisms $f : X \to Y$ where $Y$ is a [Hausdorff space](wikipedia://en/13637) but $X$ is not. Consider for instance the [quotient space](wikipedia://en/237213) $X = \left(\mathbb{R} \sqcup \mathbb{R}\right) / {\sim},$ where the [equivalence relation](wikipedia://en/9259) $\sim$ on the [disjoint union](wikipedia://en/1564380) of two copies of the reals identifies every negative real of the first copy with the corresponding negative real of the second copy. The two copies of $0$ are not identified and they do not have any disjoint neighborhoods, so $X$ is not Hausdorff. One readily checks that the natural map $f : X \to \mathbb{R}$ is a local homeomorphism. The fiber $f^{-1}(\{y\})$ has two elements if $y \geq 0$ and one element if $y < 0.$

Similarly, it is possible to construct a local homeomorphisms $f : X \to Y$ where $X$ is Hausdorff and $Y$ is not: pick the natural map from $X = \mathbb{R} \sqcup \mathbb{R}$ to $Y = \left(\mathbb{R} \sqcup \mathbb{R}\right) / {\sim}$ with the same equivalence relation $\sim$ as above.

**Local homeomorphisms and fibers**

Suppose $f : X \to Y$ is a continuous [open](https://en.wikipedia.org/wiki/Open_map) surjection between two [Hausdorff](wikipedia://en/13637) [second-countable](wikipedia://en/901459) spaces where $X$ is a [Baire space](wikipedia://en/200550) and $Y$ is a [normal space](wikipedia://en/48629). If every [fiber](wikipedia://en/6603892) of $f$ is a [discrete subspace](wikipedia://en/56061) of $X$ (which is a necessary condition for $f : X \to Y$ to be a local homeomorphism) then $f$ is a $Y$-valued local homeomorphism on a dense open subset of $X.$ To clarify this statement's conclusion, let $O = O_f$ be the (unique) largest open subset of $X$ such that $f\big\vert_O : O \to Y$ is a local homeomorphism.[^o6] If every [fiber](wikipedia://en/6603892) of $f$ is a [discrete subspace](wikipedia://en/56061) of $X$ then this open set $O$ is necessarily a [dense subset](https://en.wikipedia.org/wiki/Dense_subset) of $X.$ In particular, if $X \neq \varnothing$ then $O \neq \varnothing;$ a conclusion that may be false without the assumption that $f$'s fibers are discrete (see this footnote[^o7] for an example). One corollary is that every continuous open surjection $f$ between [completely metrizable](wikipedia://en/7975189) second-countable spaces that has [discrete](wikipedia://en/56061) fibers is "almost everywhere" a local homeomorphism (in the topological sense that $O_f$ is a dense open subset of its domain). For example, the map $f : \mathbb{R} \to [0, \infty)$ defined by the polynomial $f(x) = x^2$ is a continuous open surjection with discrete fibers so this result guarantees that the maximal open subset $O_f$ is dense in $\mathbb{R};$ with additional effort (using the [inverse function theorem](wikipedia://en/287229) for instance), it can be shown that $O_f = \mathbb{R} \setminus \{0\},$ which confirms that this set is indeed dense in $\mathbb{R}.$ This example also shows that it is possible for $O_f$ to be a proper dense subset of $f$'s domain. Because [every fiber of every non-constant polynomial is finite](wikipedia://en/51414) (and thus a discrete, and even compact, subspace), this example generalizes to such polynomials whenever the mapping induced by it is an open map.[^o8]

## Properties {#Properties}

A map $f : X \to Y$ is a local homeomorphism if and only if it is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29), [open](https://en.wikipedia.org/wiki/Open_map), and [locally injective](https://en.wikipedia.org/wiki/Locally_injective_function) (the latter means that every point in $X$ has a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) $N$ such that the restriction of $f$ to $N$ is injective). It follows that the map $f$ is a homeomorphism if and only if it is a [bijective](https://en.wikipedia.org/wiki/Bijective) local homeomorphism.

Every [fiber](wikipedia://en/6603892) of a local homeomorphism $f : X \to Y$ is a [discrete subspace](wikipedia://en/56061) of its [domain](wikipedia://en/50263) $X.$

Whether or not a function is a local homeomorphism depends on its codomain: A map $f : X \to Y$ is a local homeomorphism if and only if the surjection $f : X \to f(X)$ is a local homeomorphism (where $f(X)$ has the [subspace topology](wikipedia://en/910926) inherited from $Y$) and $f(X)$ is an open subset of $Y.$

### Local homeomorphisms and composition of functions {#Local_homeomorphisms_and_composition_of_functions}

The [composition](wikipedia://en/195947) of two local homeomorphisms is a local homeomorphism; explicitly, if $f : X \to Y$ and $g : Y \to Z$ are local homeomorphisms then the composition $g \circ f : X \to Z$ is also a local homeomorphism. The restriction of a local homeomorphism to any open subset of the domain will again be a local homeomorphism; explicitly, if $f : X \to Y$ is a local homeomorphism then its restriction $f\big\vert_U : U \to Y$ to any $U$ open subset of $X$ is also a local homeomorphism.

If $f : X \to Y$ is continuous while both $g : Y \to Z$ and $g \circ f : X \to Z$ are local homeomorphisms, then $f$ is also a local homeomorphism.

### Preserved properties {#Preserved_properties}

A local homeomorphism $f : X \to Y$ transfers "local" topological properties in both directions:

- $X$ is [locally connected](wikipedia://en/6959754) if and only if $f(X)$ is;
- $X$ is [locally path-connected](https://en.wikipedia.org/wiki/Locally_path-connected) if and only if $f(X)$ is;
- $X$ is [locally compact](wikipedia://en/48632) if and only if $f(X)$ is;
- $X$ is [first-countable](wikipedia://en/904940) if and only if $f(X)$ is.

As pointed out above, the Hausdorff property is not local in this sense and need not be preserved by local homeomorphisms.

### Sheaves {#Sheaves}

The local homeomorphisms with [codomain](wikipedia://en/50264) $Y$ stand in a natural one-to-one correspondence with the [sheaves](wikipedia://en/245466) of sets on $Y;$ this correspondence is in fact an [equivalence of categories](wikipedia://en/379051). Furthermore, every continuous map with codomain $Y$ gives rise to a uniquely defined local homeomorphism with codomain $Y$ in a natural way. All of this is explained in detail in the article on [sheaves](wikipedia://en/245466).

:::

## Generalizations and analogous concepts {#Generalizations_and_analogous_concepts}

The idea of a local homeomorphism can be formulated in geometric settings different from that of topological spaces. For [differentiable manifolds](wikipedia://en/2119219), we obtain the [local diffeomorphisms](wikipedia://en/1728483); for [schemes](wikipedia://en/364754), we have the [formally étale morphisms](wikipedia://en/30285123) and the [étale morphisms](wikipedia://en/3022771); and for [toposes](wikipedia://en/21391464), we get the [étale geometric morphisms](https://en.wikipedia.org/wiki/Étale_geometric_morphism).
