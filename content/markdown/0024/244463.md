# Adjacency matrix

::: {#o1 .subject cue=lead name="Adjacency matrix"}

In [graph theory](wikipedia://en/12401) and [computer science](https://en.wikipedia.org/wiki/Computer_science), an **adjacency matrix** is a [square matrix](wikipedia://en/166022) used to represent a finite [graph](wikipedia://en/325806). The elements of the [matrix](wikipedia://en/20556859) indicate whether pairs of [vertices](wikipedia://en/638899) are [adjacent](wikipedia://en/7309251) or not within the graph.

:::

In the special case of a finite [simple graph](https://en.wikipedia.org/wiki/Simple_graph), the adjacency matrix is a [(0,1)-matrix](https://en.wikipedia.org/wiki/%280,1%29-matrix) with zeros on its diagonal. If the graph is [undirected](https://en.wikipedia.org/wiki/Glossary_of_graph_theory_terms#undirected) (i.e. all of its [edges](https://en.wikipedia.org/wiki/Glossary_of_graph_theory_terms#edge) are bidirectional), the adjacency matrix is [symmetric](wikipedia://en/126474). The relationship between a graph and the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) and [eigenvectors](https://en.wikipedia.org/wiki/Eigenvector) of its adjacency matrix is studied in [spectral graph theory](wikipedia://en/534914).

The adjacency matrix of a graph should be distinguished from its [incidence matrix](wikipedia://en/420919), a different matrix representation whose elements indicate whether vertex–edge pairs are [incident](https://en.wikipedia.org/wiki/Incidence_%28graph%29) or not, and its [degree matrix](wikipedia://en/1449175), which contains information about the [degree](wikipedia://en/1374448) of each vertex.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a simple graph with vertex set $U = \{u_{1}, ..., u_{n}\}$, the adjacency matrix is a square $n \times n$ matrix $A$ such that its element $A_{ij}$ is 1 when there is an edge from vertex $u_{i}$ to vertex $u_{j}$, and 0 when there is no edge.[^o4] The diagonal elements of the matrix are all 0, since edges from a vertex to itself ([loops](wikipedia://en/1449083)) are not allowed in simple graphs. It is also sometimes useful in [algebraic graph theory](wikipedia://en/1620216) to replace the nonzero elements with algebraic variables.[^o5] The same concept can be extended to [multigraphs](wikipedia://en/1774970) and graphs with loops by storing the number of edges between each two vertices in the corresponding matrix element, and by allowing nonzero diagonal elements. Loops may be counted either once (as a single edge) or twice (as two vertex-edge incidences), as long as a consistent convention is followed. Undirected graphs often use the latter convention of counting loops twice, whereas directed graphs typically use the former convention.

::: {#o7 .pointer-item cue=pointer name="Adjacency matrix of a bipartite graph"}

### Of a bipartite graph {#Of_a_bipartite_graph}

The adjacency matrix $A$ of a [bipartite graph](wikipedia://en/244431) whose two parts have $r$ and $s$ vertices can be written in the form

$$A = \begin{pmatrix} 0_{r,r} & B \\ B^\mathsf{T} & 0_{s,s} \end{pmatrix},$$

where $B$ is an $r \times s$ matrix, and $0_{r,r}$ and $0_{s,s}$ represent the $r \times r$ and $s \times s$ [zero matrices](wikipedia://en/1168888). In this case, the smaller matrix $B$ uniquely represents the graph, and the remaining parts of $A$ can be discarded as redundant. $B$ is sometimes called the *biadjacency matrix*.

Formally, let $G = (U, V, E)$ be a [bipartite graph](wikipedia://en/244431) with parts $U = \{u_{1}, ..., u_{r}\}$, $V = \{v_{1}, ..., v_{s}\}$ and edges $E$. The biadjacency matrix is the $r \times s$ 0–1 matrix $B$ in which $b_{i,j} = 1$ [if and only if](wikipedia://en/14922) $(u_{i}, v_{j}) \in E$.

If $G$ is a bipartite [multigraph](wikipedia://en/1774970) or [weighted graph](https://en.wikipedia.org/wiki/Weighted_graph), then the elements $b_{i,j}$ are taken to be the number of edges between the vertices or the weight of the edge $(u_{i}, v_{j})$, respectively.

:::

::: {#o9 .statement kind=statement/generalization cue=heading name="Variations"}

### Variations {#Variations}

An $(a, b, c)$-adjacency matrix $A$ of a simple graph has $A_{i,j} = a$ if $(i, j)$ is an edge, $b$ if it is not, and $c$ on the diagonal. The [Seidel adjacency matrix](wikipedia://en/7770329) is a $(-1, 1, 0)$-adjacency matrix. This matrix is used in studying [strongly regular graphs](wikipedia://en/1399856) and [two-graphs](wikipedia://en/2705947).[^o10]

The [distance matrix](wikipedia://en/831350) has in position $(i, j)$ the distance between vertices $v_{i}$ and $v_{j}$. The distance is the length of a shortest path connecting the vertices. Unless lengths of edges are explicitly provided, the length of a path is the number of edges in it. The distance matrix resembles a high power of the adjacency matrix, but instead of telling only whether or not two vertices are connected (i.e., the connection matrix, which contains [Boolean values](wikipedia://en/54476844)), it gives the exact distance between them.

:::

### Undirected graphs {#Undirected_graphs}

The convention followed here (for undirected graphs) is that each edge adds 1 to the appropriate cell in the matrix, and each loop (an edge from a vertex to itself) adds 2 to the appropriate cell on the diagonal in the matrix.[^o14] This allows the degree of a vertex to be easily found by taking the sum of the values in either its respective row or column in the adjacency matrix.

### Directed graphs {#Directed_graphs}

The adjacency matrix of a directed graph can be asymmetric. One can define the adjacency matrix of a directed graph either such that

1. a non-zero element $A_{ij}$ indicates an edge from $i$ to $j$ or
1. it indicates an edge from $j$ to $i$.

The former definition is commonly used in graph theory and social network analysis (e.g., sociology, political science, economics, psychology).[^o18] The latter is more common in other applied sciences (e.g., dynamical systems, physics, network science) where $A$ is sometimes used to describe linear dynamics on graphs.[^o19]

Using the first definition, the [in-degrees](wikipedia://en/19721986#Indegree_and_outdegree) of a vertex can be computed by summing the entries of the corresponding column and the out-degree of vertex by summing the entries of the corresponding row. When using the second definition, the in-degree of a vertex is given by the corresponding row sum and the out-degree is given by the corresponding column sum.

### Trivial graphs {#Trivial_graphs}

The adjacency matrix of a [complete graph](wikipedia://en/85816) contains all ones except along the diagonal where there are only zeros. The adjacency matrix of an [empty graph](https://en.wikipedia.org/wiki/Empty_graph) is a [zero matrix](wikipedia://en/1168888).

:::

## Properties {#Properties}

### Spectrum {#Spectrum}

The adjacency matrix of an undirected simple graph is [symmetric](wikipedia://en/126474), and therefore has a complete set of [real](wikipedia://en/20646438) [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) and an orthogonal [eigenvector](https://en.wikipedia.org/wiki/Eigenvector) basis. The set of eigenvalues of a graph is the **spectrum** of the graph.[^o26] It is common to denote the eigenvalues by $\lambda_1\geq \lambda_2\geq \cdots \geq \lambda_n.$

The greatest eigenvalue $\lambda_1$ is bounded above by the maximum degree. This can be seen as result of the [Perron–Frobenius theorem](wikipedia://en/1540333), but it can be proved easily. Let $v$ be one eigenvector associated to $\lambda_1$ and $x$ an entry in which $v$ has maximum absolute value. Without loss of generality assume $v_{x}$ is positive since otherwise you simply take the eigenvector −$v$, also associated to $\lambda_1$. Then

$$\lambda_1 v_x = (Av)_x = \sum_{y=1}^n A_{x,y}v_y \leq \sum_{y=1}^n A_{x,y} v_x = v_x \deg(x).$$

For $d$-regular graphs, $d$ is the first eigenvalue of $A$ for the vector $v = (1, ..., 1)$ (it is easy to check that it is an eigenvalue and it is the maximum because of the above bound). The multiplicity of this eigenvalue is the number of connected components of $G$, in particular $\lambda_1>\lambda_2$ for connected graphs. It can be shown that for each eigenvalue $\lambda_i$, its opposite $-\lambda_i = \lambda_{n+1-i}$ is also an eigenvalue of $A$ if $G$ is a [bipartite graph](wikipedia://en/244431).[^o27] In particular −$d$ is an eigenvalue of any $d$-regular bipartite graph.

The difference $\lambda_1 - \lambda_2$ is called the [spectral gap](wikipedia://en/7999250) and it is related to the [expansion](wikipedia://en/9313) of $G$. It is also useful to introduce the [spectral radius](wikipedia://en/386169) of $A$ denoted by $\lambda(G) = \max_{\left|\lambda_i\right| < d} |\lambda_i|$. This number is bounded by $\lambda(G) \geq 2\sqrt{d-1} - o(1)$. This bound is tight in the [Ramanujan graphs](https://en.wikipedia.org/wiki/Ramanujan_graphs).

### Isomorphism and invariants {#Isomorphism_and_invariants}

Suppose two directed or undirected graphs $G_{1}$ and $G_{2}$ with adjacency matrices $A_{1}$ and $A_{2}$ are given. $G_{1}$ and $G_{2}$ are [isomorphic](wikipedia://en/247577) if and only if there exists a [permutation matrix](wikipedia://en/238849) $P$ such that

$$P A_1 P^{-1} = A_2.$$

In particular, $A_{1}$ and $A_{2}$ are [similar](https://en.wikipedia.org/wiki/Similar_%28linear_algebra%29) and therefore have the same [minimal polynomial](wikipedia://en/9667107), [characteristic polynomial](wikipedia://en/218268), [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues), [determinant](wikipedia://en/8468) and [trace](https://en.wikipedia.org/wiki/Trace_%28matrix%29). These can therefore serve as isomorphism invariants of graphs. However, two graphs may possess the same set of eigenvalues but not be isomorphic.[^o29] Such [linear operators](https://en.wikipedia.org/wiki/Linear_operator) are said to be [isospectral](wikipedia://en/386031).

### Matrix powers {#Matrix_powers}

If $A$ is the adjacency matrix of the directed or undirected graph $G$, then the matrix $A^{n}$ (i.e., the [matrix product](wikipedia://en/125280) of $n$ copies of $A$) has an interesting interpretation: the element $(i, j)$ gives the number of (directed or undirected) [walks](wikipedia://en/638889) of length $n$ from vertex $i$ to vertex $j$.[^o31] If $n$ is the smallest nonnegative integer, such that for some $i$, $j$, the element $(i, j)$ of $A^{n}$ is positive, then $n$ is the distance between vertex $i$ and vertex $j$. A great example of how this is useful is in counting the number of triangles in an undirected graph $G$, which is exactly the [trace](wikipedia://en/43270) of $A^{3}$ divided by 3 or 6 depending on whether the graph is directed or not. We divide by those values to compensate for the overcounting of each triangle. In an undirected graph, each triangle will be counted twice for all three nodes, because the path can be followed clockwise or counterclockwise : ijk or ikj. The adjacency matrix can be used to determine whether or not the graph is [connected](wikipedia://en/1614492).

If a directed graph has a [nilpotent](wikipedia://en/1167800) adjacency matrix (i.e., if there exists $n$ such that $A^{n}$ is the zero matrix), then it is a [directed acyclic graph](wikipedia://en/204002).[^o32]

:::

## Data structures {#Data_structures}

The adjacency matrix may be used as a [data structure](wikipedia://en/8519) for the [representation of graphs](wikipedia://en/557931) in computer programs for manipulating graphs. [Boolean data types](https://en.wikipedia.org/wiki/Boolean_data_type) are used, such as `True` and `False` in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29). The main alternative data structure, also in use for this application, is the [adjacency list](wikipedia://en/392431).[^o34][^o35]

The space needed to represent an adjacency matrix and the time needed to perform operations on them is dependent on the [matrix representation](wikipedia://en/1523927) chosen for the underlying matrix. [Sparse matrix representations](https://en.wikipedia.org/wiki/Sparse_matrix_representation) only store non-zero matrix entries and implicitly represent the zero entries. They can, for example, be used to represent [sparse graphs](https://en.wikipedia.org/wiki/Sparse_graph) without incurring the space overhead from storing the many zero entries in the adjacency matrix of the sparse graph. In the following section the adjacency matrix is assumed to be represented by an [array data structure](https://en.wikipedia.org/wiki/Array_data_structure) so that zero and non-zero entries are all directly represented in storage.

Because each entry in the adjacency matrix requires only one bit, it can be represented in a very compact way, occupying only $|V\,|^{2}/8$ bytes to represent a directed graph, or (by using a packed triangular format and only storing the lower triangular part of the matrix) approximately $|V\,|^{2}/16$ bytes to represent an undirected graph. Although slightly more succinct representations are possible, this method gets close to the information-theoretic lower bound for the minimum number of bits needed to represent all $n$-vertex graphs.[^o36] For storing graphs in [text files](https://en.wikipedia.org/wiki/Text_file), fewer bits per byte can be used to ensure that all bytes are text characters, for instance by using a [Base64](https://en.wikipedia.org/wiki/Base64) representation.[^o37] Besides avoiding wasted space, this compactness encourages [locality of reference](https://en.wikipedia.org/wiki/Locality_of_reference). However, for a large [sparse graph](https://en.wikipedia.org/wiki/Sparse_graph), adjacency lists require less storage space, because they do not waste any space representing edges that are *not* present.[^o35][^o38]

An alternative form of adjacency matrix (which, however, requires a larger amount of space) replaces the numbers in each element of the matrix with pointers to edge objects (when edges are present) or null pointers (when there is no edge).[^o38] It is also possible to store [edge weights](https://en.wikipedia.org/wiki/Weighted_graph) directly in the elements of an adjacency matrix.[^o35]

Besides the space tradeoff, the different data structures also facilitate different operations. Finding all vertices adjacent to a given vertex in an adjacency list is as simple as reading the list, and takes time proportional to the number of neighbors. With an adjacency matrix, an entire row must instead be scanned, which takes a larger amount of time, proportional to the number of vertices in the whole graph. On the other hand, testing whether there is an edge between two given vertices can be determined at once with an adjacency matrix, while requiring time proportional to the minimum degree of the two vertices with the adjacency list.[^o35][^o38]
