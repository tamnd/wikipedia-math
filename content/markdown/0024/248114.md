# Superstrong cardinal

::: {#o1 .subject cue=lead name="Superstrong cardinal"}

In [mathematics](wikipedia://en/18831), a [cardinal number](wikipedia://en/6173) κ is called **superstrong** [if and only if](wikipedia://en/14922) there exists an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* : *V* → *M* from *V* into a transitive inner model *M* with [critical point](wikipedia://en/4888510) κ and $V_{j(\kappa)}$ ⊆ *M*.

:::

Similarly, a cardinal κ is **n-superstrong** if and only if there exists an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* : *V* → *M* from *V* into a transitive inner model *M* with [critical point](wikipedia://en/4888510) κ and $V_{j^n(\kappa)}$ ⊆ *M*. [Akihiro Kanamori](wikipedia://en/22363114) has shown that the consistency strength of an n+1-superstrong cardinal exceeds that of an [n-huge cardinal](https://en.wikipedia.org/wiki/N-huge_cardinal) for each n > 0.
