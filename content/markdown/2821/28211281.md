# Soft set

::: {#o1 .subject cue=lead name="Soft set"}

**Soft set** theory is a generalization of [fuzzy set theory](https://en.wikipedia.org/wiki/Fuzzy_set_theory), that was proposed by Molodtsov in 1999 to deal with uncertainty in a parametric manner.[^o2] A soft set is a parameterised family of sets - intuitively, this is "soft" because the boundary of the set depends on the parameters. Formally, a soft set, over a universal set X and set of parameters E is a [pair](wikipedia://en/22362) (*f*, *A*) where *A* is a [subset](wikipedia://en/27631) of E, and *f* is a [function](https://en.wikipedia.org/wiki/Mapping_%28mathematics%29) from *A* to the power set of X. For each *e* in *A*, the set *f*(*e*) is called the **value set** of *e* in (*f*, *A*).

:::

A systematic literature review on soft set theory was published in the journal Neural Computing and Applications in February 2024.[^o3]

One of the most important steps for the new theory of soft sets was to define mappings on soft sets, which was achieved in 2009 by the mathematicians Athar Kharal and Bashir Ahmad, with the results published in 2011.[^o4] Soft sets have also been applied to the problem of medical diagnosis for use in medical expert systems. Fuzzy soft sets[^o5] and N-soft sets[^o6] have also been introduced. Mappings on fuzzy soft sets were defined and studied by Kharal and Ahmad.[^o7]
