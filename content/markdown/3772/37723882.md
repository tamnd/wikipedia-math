# Local language (formal language)

::: {#o1 .subject cue=lead name="Local language"}

In mathematics, a **local language** is a [formal language](wikipedia://en/10939) for which membership of a word in the language can be determined by looking at the first and last symbol and each two-symbol substring of the word.[^o2] Equivalently, it is a language recognised by a [local automaton](https://en.wikipedia.org/wiki/Local_automaton), a particular kind of [deterministic finite automaton](wikipedia://en/653404).[^o3]

:::

Formally, a language *L* over an alphabet *A* is defined to be *local* if there are subsets *R* and *S* of *A* and a subset *F* of *A*×*A* such that a word *w* is in *L* if and only if the first letter of *w* is in *R*, the last letter of *w* is in *S* and no factor of length 2 in *w* is in *F*.[^o4] This corresponds to the [regular expression](wikipedia://en/25717)[^o2][^o5]

$$(RA^* \cap A^*S) \setminus A^*FA^* \ .$$

More generally, a *k*-*testable* language *L* is one for which membership of a word *w* in *L* depends only on the prefix and suffix of length *k* and the set of factors of *w* of length *k*;[^o6] a language is *locally testable* if it is *k*-testable for some *k*.[^o7] A local language is 2-testable.[^o2]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- Over the alphabet {*a*,*b*,*\[*,*\]*}[^o5]

$$aa^*,\ [ab] \ .$$

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The family of local languages over *A* is closed under intersection and [Kleene star](wikipedia://en/16750), but not complement, union or concatenation.[^o5]
- Every [regular language](wikipedia://en/25723) not containing the empty string is the image of a local language under a [strictly alphabetic morphism](https://en.wikipedia.org/wiki/Strictly_alphabetic_morphism).[^o2][^o12][^o13]

:::
