# List of recreational number theory topics

::: {#o1 .subject cue=lead name="List of recreational number theory topics"}

This is a list of **recreational number theory topics** (see [number theory](wikipedia://en/21527), [recreational mathematics](wikipedia://en/26446)). Listing here is not [pejorative](https://en.wikipedia.org/wiki/Pejorative): many famous topics in number theory have origins in challenging problems posed purely for their own sake.

:::

See [list of number theory topics](wikipedia://en/346955) for pages dealing with aspects of number theory with more consolidated theories.
