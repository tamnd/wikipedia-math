# Rasiowa–Sikorski lemma

::: {#o1 .subject cue=lead name="Rasiowa–Sikorski lemma"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **Rasiowa–Sikorski lemma** named after [Helena Rasiowa](wikipedia://en/3482432) and [Roman Sikorski](wikipedia://en/1983335) is one of the most fundamental facts used in the technique of [forcing](wikipedia://en/152205). In the area of forcing, a subset *E* of a [poset](https://en.wikipedia.org/wiki/Poset) (*P*, ≤) is called **dense** in *P* if for any *p* ∈ *P* there is *e* ∈ *E* with *e* ≤ *p*. If *D* is a set of dense subsets of *P*, then a [filter](wikipedia://en/19719) *F* in *P* is called *D*-[generic](wikipedia://en/2213247) if

:::

*F* ∩ *E* ≠ ∅ for all *E* ∈ *D*.

Now we can state the **Rasiowa–Sikorski lemma**:

Let (*P*, ≤) be a poset and *p* ∈ *P*. If *D* is a [countable](https://en.wikipedia.org/wiki/Countable) set of [dense](wikipedia://en/6320997) subsets of *P* then there exists a *D*-generic [filter](wikipedia://en/19719) *F* in *P* such that *p* ∈ *F*.

::: {#o3 .proof cue=heading name="Proof of the Rasiowa–Sikorski lemma"}

## Proof of the Rasiowa–Sikorski lemma {#Proof_of_the_Rasiowa–Sikorski_lemma}

Let *p* ∈ *P* be given. Since *D* is countable, *D* = { *D*<sub>*i*</sub> | *i* ∈ **N** }, i.e., one can enumerate the dense subsets of *P* as *D*<sub>1</sub>, *D*<sub>2</sub>, ... and, by density, there exists *p*<sub>1</sub> ≤ *p* with *p*<sub>1</sub> ∈ *D*<sub>1</sub>. Iterating that, one gets ... ≤ *p*<sub>2</sub> ≤ *p*<sub>1</sub> ≤ *p* with *p*<sub>*i*</sub> ∈ *D*<sub>*i*</sub>. Then *G* = { *q* ∈ *P* | ∃*i*. *q* ≥ *p*<sub>*i*</sub> } is a *D*-generic filter.

The Rasiowa–Sikorski lemma can be viewed as an equivalent to a weaker form of [Martin's axiom](wikipedia://en/1550783). More specifically, it is equivalent to MA(ℵ<sub>0</sub>) and to the [axiom of countable choice](wikipedia://en/421086).[^o4]

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- For (*P*, ≤) = (Func(*X*, *Y*), ⊇), the poset of [partial functions](wikipedia://en/23577) from *X* to *Y*, reverse-ordered by inclusion, define *D*<sub>*x*</sub> = { *s* ∈ *P* | *x* ∈ dom(*s*) }. Let *D* = { *D*<sub>*x*</sub> | *x* ∈ *X* }. If *X* is countable, the Rasiowa–Sikorski lemma yields a *D*-generic filter *F* and thus a function *F*: *X* → *Y*.
- If we adhere to the notation used in dealing with *D*-[generic filters](wikipedia://en/2213247), { *H* ∪ *G*<sub>0</sub> | *P*<sub>*ij*</sub>*P*<sub>*t*</sub> } forms an *H*-[generic filter](wikipedia://en/2213247).
- If *D* is uncountable, but of [cardinality](wikipedia://en/6174) strictly smaller than 2<sup>ℵ<sub>0</sub></sup> and the poset has the [countable chain condition](wikipedia://en/1550771), we can instead use [Martin's axiom](wikipedia://en/1550783). However, Martin's axiom is not provable in [ZFC](https://en.wikipedia.org/wiki/ZFC).

:::
