# Rademacher system

::: {#o1 .subject cue=lead name="Rademacher system"}

*Image: Rademacherfunktionen.png.*

In mathematics, in particular in [functional analysis](wikipedia://en/11180), the **Rademacher system**, named after [Hans Rademacher](wikipedia://en/1864916), is an [incomplete orthonormal system](https://en.wikipedia.org/wiki/Complete_orthogonal_system#Incomplete_orthogonal_sets) of functions on the [unit interval](wikipedia://en/49324) of the following form:

:::

$$\{ t \mapsto r_{n}(t)=\operatorname{sgn} \left( \sin 2^{n+1} \pi t \right) ; t \in [0,1], n \in \mathbb{N} \}.$$

The Rademacher system is stochastically independent, and is closely related to the [Walsh system](https://en.wikipedia.org/wiki/Walsh_functions). Specifically, the Walsh system can be constructed as a product of Rademacher functions.

To see that the Rademacher system is an incomplete orthonormal system and not an orthonormal basis, consider the function on the unit interval defined by the following equation:

$$f(t) = 4 \left|x-\frac 12\right| - 1$$

This function is orthogonal to all the functions in the Rademacher system, yet is nonzero.

Viewed as a sequence of random variables on the unit interval with the Lebesgue measure, the law of each $r_{n}$ is a [Rademacher distribution](wikipedia://en/1856890), and the $r_{n}$'s are independent of each other. From [Khintchine's inequality](wikipedia://en/10002357), it follows that the closed linear span of the Rademacher functions in $L^{p}$ is the same as the closed linear span in $L^{2}$.
