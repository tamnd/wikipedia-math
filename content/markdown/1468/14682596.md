# Finite topological space

::: {#o1 .subject cue=lead name="Finite topological space"}

In [mathematics](wikipedia://en/18831), a **finite topological space** is a [topological space](wikipedia://en/30450) for which the underlying [point set](wikipedia://en/26691) is [finite](wikipedia://en/11742). That is, it is a topological space which has only finitely many elements.

:::

Finite topological spaces are often used to provide examples of interesting phenomena or [counterexamples](wikipedia://en/143151) to plausible sounding conjectures. [William Thurston](wikipedia://en/39190) has called the study of finite topologies in this sense "an oddball topic that can lend good insight to a variety of questions".[^o2]

## Topologies on a finite set {#Topologies_on_a_finite_set}

Let $X$ be a finite set. A [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29) on $X$ is a subset $\tau$ of $P(X)$ (the [power set](wikipedia://en/23799) of $X$) such that

1. $\varnothing \in \tau$ and $X\in \tau$.
1. if $U, V \in \tau$ then $U \cup V \in \tau$.
1. if $U, V \in \tau$ then $U \cap V \in \tau$.

In other words, a subset $\tau$ of $P(X)$ is a topology if $\tau$ contains both $\varnothing$ and $X$ and is closed under arbitrary [unions](wikipedia://en/47949) and [intersections](wikipedia://en/23476429). Elements of $\tau$ are called [open sets](wikipedia://en/39358). The general description of topological spaces requires that a topology be closed under arbitrary (finite or infinite) unions of open sets, but only under intersections of finitely many open sets. Here, that distinction is unnecessary. Since the power set of a finite set is finite there can be only finitely many [open sets](wikipedia://en/39358) (and only finitely many [closed sets](wikipedia://en/47279)).

A topology on a finite set can also be thought of as a [sublattice](https://en.wikipedia.org/wiki/Sublattice) of $(P(X), \subset)$ which includes both the bottom element $\varnothing$ and the top element $X$.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

### 0 or 1 points {#0_or_1_points}

There is a unique topology on the [empty set](wikipedia://en/9566) ∅. The only open set is the empty one. Indeed, this is the only subset of ∅.

Likewise, there is a unique topology on a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) {*a*}. Here the open sets are ∅ and {*a*}. This topology is both [discrete](wikipedia://en/56061) and [trivial](wikipedia://en/382447), although in some ways it is better to think of it as a discrete space since it shares more properties with the family of finite discrete spaces.

For any topological space *X* there is a unique [continuous function](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) from ∅ to *X*, namely the [empty function](https://en.wikipedia.org/wiki/Empty_function). There is also a unique continuous function from *X* to the singleton space {*a*}, namely the [constant function](wikipedia://en/320861) to *a*. In the language of [category theory](wikipedia://en/5869) the empty space serves as an [initial object](https://en.wikipedia.org/wiki/Initial_object) in the [category of topological spaces](wikipedia://en/435051) while the singleton space serves as a [terminal object](https://en.wikipedia.org/wiki/Terminal_object).

### 2 points {#2_points}

Let *X* = {*a*,*b*} be a set with 2 elements. There are four distinct topologies on *X*:

1. {∅, {*a*,*b*}} (the [trivial topology](wikipedia://en/382447))
1. {∅, {*a*}, {*a*,*b*}}
1. {∅, {*b*}, {*a*,*b*}}
1. {∅, {*a*}, {*b*}, {*a*,*b*}} (the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology))

The second and third topologies above are easily seen to be [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic). The function from *X* to itself which swaps *a* and *b* is a homeomorphism. A topological space homeomorphic to one of these is called a [Sierpiński space](wikipedia://en/387651). So, in fact, there are only three inequivalent topologies on a two-point set: the trivial one, the discrete one, and the Sierpiński topology.

The specialization preorder on the Sierpiński space {*a*,*b*} with {*b*} open is given by: *a* ≤ *a*, *b* ≤ *b*, and *a* ≤ *b*.

### 3 points {#3_points}

Let *X* = {*a*,*b*,*c*} be a set with 3 elements. There are 29 distinct topologies on *X* but only 9 inequivalent topologies:

1. {∅, {*c*}, {*a*,*b*,*c*}}

1. {∅, {*c*}, {*a*,*c*}, {*b*,*c*}, {*a*,*b*,*c*}} ([T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space))
1. {∅, {*a*}, {*b*}, {*a*,*b*}, {*a*,*b*,*c*}} ([T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space))

The last 5 of these are all [T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space). The first one is trivial, while in 2, 3, and 4 the points *a* and *b* are [topologically indistinguishable](https://en.wikipedia.org/wiki/Topologically_indistinguishable).

## Properties {#Properties}

### Specialization preorder {#Specialization_preorder}

Topologies on a finite set *X* are in [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence) with [preorders](wikipedia://en/23582) on *X*. Recall that a preorder on *X* is a [binary relation](wikipedia://en/3931) on *X* which is [reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200463).

Given a (not necessarily finite) topological space *X* we can define a preorder on *X* by

*x* ≤ *y* if and only if *x* ∈ cl{*y*}

where cl{*y*} denotes the [closure](wikipedia://en/42309) of the [singleton set](https://en.wikipedia.org/wiki/Singleton_set) {*y*}. This preorder is called the *[specialization preorder](wikipedia://en/542347)* on *X*. Every open set *U* of *X* will be an [upper set](https://en.wikipedia.org/wiki/Upper_set) with respect to ≤ (i.e. if *x* ∈ *U* and *x* ≤ *y* then *y* ∈ *U*). Now if *X* is finite, the converse is also true: every upper set is open in *X*. So for finite spaces, the topology on *X* is uniquely determined by ≤.

Going in the other direction, suppose (*X*, ≤) is a preordered set. Define a topology τ on *X* by taking the open sets to be the upper sets with respect to ≤. Then the relation ≤ will be the specialization preorder of (*X*, τ). The topology defined in this way is called the [Alexandrov topology](wikipedia://en/542198) determined by ≤.

The equivalence between preorders and finite topologies can be interpreted as a version of [Birkhoff's representation theorem](wikipedia://en/20489385), an equivalence between finite distributive lattices (the lattice of open sets of the topology) and partial orders (the partial order of equivalence classes of the preorder). This correspondence also works for a larger class of spaces called [finitely generated spaces](https://en.wikipedia.org/wiki/Finitely_generated_space). Finitely generated spaces can be characterized as the spaces in which an arbitrary intersection of open sets is open. Finite topological spaces are a special class of finitely generated spaces.

### Compactness and countability {#Compactness_and_countability}

Every finite topological space is [compact](wikipedia://en/6042) since any [open cover](https://en.wikipedia.org/wiki/Open_cover) must already be finite. Indeed, compact spaces are often thought of as a generalization of finite spaces since they share many of the same properties.

Every finite topological space is also [second-countable](https://en.wikipedia.org/wiki/Second-countable) (there are only finitely many open sets) and [separable](wikipedia://en/27855) (since the space itself is [countable](wikipedia://en/6026)).

### Separation axioms {#Separation_axioms}

If a finite topological space is [T<sub>1</sub>](wikipedia://en/148721) (in particular, if it is [Hausdorff](wikipedia://en/13637)) then it must, in fact, be discrete. This is because the [complement](wikipedia://en/54347) of a singleton is the union of finitely many closed singletons and therefore closed. It follows that each singleton must be open.

Therefore, any finite topological space which is not discrete cannot be T<sub>1</sub>, Hausdorff, or anything stronger.

However, it is possible for a non-discrete finite space to be [T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space). In general, two points *x* and *y* are [topologically indistinguishable](https://en.wikipedia.org/wiki/Topologically_indistinguishable) if and only if *x* ≤ *y* and *y* ≤ *x*, where ≤ is the specialization preorder on *X*. It follows that a space *X* is T<sub>0</sub> [if and only if](wikipedia://en/14922) the specialization preorder ≤ on *X* is a [partial order](https://en.wikipedia.org/wiki/Partial_order). There are numerous partial orders on a finite set. Each defines a unique T<sub>0</sub> topology.

Similarly, a space is [R<sub>0</sub>](https://en.wikipedia.org/wiki/R0_space) if and only if the specialization preorder is an [equivalence relation](wikipedia://en/9259). Given any equivalence relation on a finite set *X* the associated topology is the [partition topology](wikipedia://en/5334930) on *X*. The equivalence classes will be the classes of topologically indistinguishable points. Since the partition topology is [pseudometrizable](https://en.wikipedia.org/wiki/Pseudometrizable_space), a finite space is R<sub>0</sub> if and only if it is [completely regular](https://en.wikipedia.org/wiki/Completely_regular).

Non-discrete finite spaces can also be [normal](wikipedia://en/48629). The [excluded point topology](wikipedia://en/5539197) on any finite set is a [completely normal](https://en.wikipedia.org/wiki/Completely_normal_space) T<sub>0</sub> space which is non-discrete.

:::

### Connectivity {#Connectivity}

Connectivity in a finite space *X* is best understood by considering the specialization preorder ≤ on *X*. We can associate to any preordered set *X* a [directed graph](wikipedia://en/19721986) Γ by taking the points of *X* as vertices and drawing an edge *x* → *y* whenever *x* ≤ *y*. The connectivity of a finite space *X* can be understood by considering the [connectivity](wikipedia://en/1614492) of the associated graph Γ.

In any topological space, if *x* ≤ *y* then there is a [path](wikipedia://en/1189553) from *x* to *y*. One can simply take *f*(0) = *x* and *f*(*t*) = *y* for *t* > 0. It is easy to verify that *f* is continuous. It follows that the [path components](https://en.wikipedia.org/wiki/Path_component) of a finite topological space are precisely the (weakly) [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) of the associated graph Γ. That is, there is a topological path from *x* to *y* if and only if there is an [undirected path](wikipedia://en/638889) between the corresponding vertices of Γ.

Every finite space is [locally path-connected](https://en.wikipedia.org/wiki/Locally_path-connected) since the set

$$\mathop{\uparrow}x = \{y \in X : x \leq y\}$$

is a path-connected open [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of *x* that is contained in every other neighborhood. In other words, this single set forms a [local base](https://en.wikipedia.org/wiki/Local_base) at *x*.

Therefore, a finite space is [connected](wikipedia://en/6233) if and only if it is path-connected. The connected components are precisely the path components. Each such component is both [closed and open](wikipedia://en/233398) in *X*.

Finite spaces may have stronger connectivity properties. A finite space *X* is

- [hyperconnected](wikipedia://en/7556651) if and only if there is a [greatest element](https://en.wikipedia.org/wiki/Greatest_element) with respect to the specialization preorder. This is an element whose closure is the whole space *X*.
- [ultraconnected](wikipedia://en/8101374) if and only if there is a [least element](https://en.wikipedia.org/wiki/Least_element) with respect to the specialization preorder. This is an element whose only neighborhood is the whole space *X*.

For example, the [particular point topology](wikipedia://en/5336200) on a finite space is hyperconnected while the [excluded point topology](wikipedia://en/5539197) is ultraconnected. The [Sierpiński space](wikipedia://en/387651) is both.

### Additional structure {#Additional_structure}

A finite topological space is [pseudometrizable](https://en.wikipedia.org/wiki/Pseudometrizable_space) if and only if it is [R<sub>0</sub>](https://en.wikipedia.org/wiki/R0_space). In this case, one possible [pseudometric](wikipedia://en/68503) is given by

$$d(x,y) = \begin{cases}0 & x\equiv y \\ 1 & x\not\equiv y\end{cases}$$

where *x* ≡ *y* means *x* and *y* are [topologically indistinguishable](https://en.wikipedia.org/wiki/Topologically_indistinguishable). A finite topological space is [metrizable](wikipedia://en/19738) if and only if it is discrete.

Likewise, a topological space is [uniformizable](wikipedia://en/1774701) if and only if it is R<sub>0</sub>. The [uniform structure](https://en.wikipedia.org/wiki/Uniform_structure) will be the pseudometric uniformity induced by the above pseudometric.

### Algebraic topology {#Algebraic_topology}

Perhaps surprisingly, there are finite topological spaces with nontrivial [fundamental groups](wikipedia://en/11004). A simple example is the [pseudocircle](wikipedia://en/3441237), which is space *X* with four points, two of which are open and two of which are closed. There is a continuous map from the [unit circle](wikipedia://en/27072071) *S*<sup>1</sup> to *X* which is a [weak homotopy equivalence](https://en.wikipedia.org/wiki/Weak_homotopy_equivalence) (i.e. it induces an [isomorphism](wikipedia://en/14828) of [homotopy groups](wikipedia://en/297506)). It follows that the fundamental group of the pseudocircle is [infinite cyclic](https://en.wikipedia.org/wiki/Infinite_cyclic_group).

More generally it has been shown that for any finite [abstract simplicial complex](wikipedia://en/723105) *K*, there is a finite topological space *X*<sub>*K*</sub> and a weak homotopy equivalence *f* : |*K*| → *X*<sub>*K*</sub> where |*K*| is the [geometric realization](wikipedia://en/723105) of *K*. It follows that the homotopy groups of |*K*| and *X*<sub>*K*</sub> are isomorphic. In fact, the underlying set of *X*<sub>*K*</sub> can be taken to be *K* itself, with the topology associated to the inclusion partial order.

:::

## Number of topologies on a finite set {#Number_of_topologies_on_a_finite_set}

As discussed above, topologies on a finite set are in one-to-one correspondence with [preorders](wikipedia://en/23582) on the set, and [T<sub>0</sub> topologies](https://en.wikipedia.org/wiki/T0_space) are in one-to-one correspondence with [partial orders](https://en.wikipedia.org/wiki/Partial_order). Therefore, the number of topologies on a finite set is equal to the number of preorders and the number of T<sub>0</sub> topologies is equal to the number of partial orders.

Let *T*(*n*) denote the number of distinct topologies on a set with *n* points. There is no known simple formula to compute *T*(*n*) for arbitrary *n*. The [Online Encyclopedia of Integer Sequences](https://en.wikipedia.org/wiki/Online_Encyclopedia_of_Integer_Sequences) presently lists *T*(*n*) for *n* ≤ 18.

The number of distinct T<sub>0</sub> topologies on a set with *n* points, denoted *T*<sub>0</sub>(*n*), is related to *T*(*n*) by the formula

$$T(n) = \sum_{k=0}^{n}S(n,k)\,T_0(k)$$

where *S*(*n*,*k*) denotes the [Stirling number of the second kind](https://en.wikipedia.org/wiki/Stirling_number_of_the_second_kind).
