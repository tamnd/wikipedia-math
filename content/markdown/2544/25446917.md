# Enumerations of specific permutation classes

::: {#o1 .subject cue=lead name="Enumerations of specific permutation classes"}

In the study of [permutation patterns](wikipedia://en/24360911), there has been considerable interest in enumerating specific [permutation classes](wikipedia://en/40940518), especially those with relatively few basis elements. This area of study has turned up unexpected instances of [Wilf equivalence](wikipedia://en/44185220), where two seemingly-unrelated permutation classes have the same number of permutations of each length.

:::

## Classes avoiding one pattern of length 3 {#Classes_avoiding_one_pattern_of_length_3}

There are two symmetry classes and a single [Wilf class](https://en.wikipedia.org/wiki/Wilf_class) for single permutations of length three.

:::

There are seven symmetry classes and three Wilf classes for single permutations of length four.

| [1234](https://permpal.com/perms/basis/1234/) [1243](https://permpal.com/perms/basis/1243/) [1432](https://permpal.com/perms/basis/1432/) [2143](wikipedia://en/31942906) | 1, 2, 6, 23, 103, 513, 2761, 15767, ... |  | [holonomic](wikipedia://en/5817043) (nonalgebraic) [g.f.](wikipedia://en/160993) | (Gessel 1990) |
| 1324 | 1, 2, 6, 23, 103, 513, 2762, 15793, ... |  |  |  |

:::

No non-recursive formula counting 1324-avoiding permutations is known. A recursive formula was given by (Marinov Radoičić 2003). A more efficient algorithm using functional equations was given by (Johansson Nakamura 2014), which was enhanced by (Conway Guttmann 2015), and then further enhanced by (Conway Guttmann Zinn-Justin 2018) who give the first 50 terms of the enumeration. (Bevan Brignall Elvey Price Pantone 2020) currently have the best rigorously established lower and upper bounds for the growth rate of this class, having established that this growth rate lies in the interval \[10.271, 13.5\].

## Classes avoiding two patterns of length 4 {#Classes_avoiding_two_patterns_of_length_4}

*Image: Heatmaps of all non-finite permutation classes avoiding two length four patterns 11 by 5.png.* Heatmaps of classes avoiding two patterns of length 4.

There are 56 symmetry classes and 38 Wilf equivalence classes. Only 3 of these remain unenumerated, and their [generating functions](wikipedia://en/160993) are conjectured not to satisfy any [algebraic differential equation](wikipedia://en/9501827) (ADE) by (Albert Homberger Pantone Shar 2018); in particular, their conjecture would imply that these generating functions are not [D-finite](wikipedia://en/5817043).

Heatmaps of each of the non-finite classes are shown on the right, from (Albert Bean Claesson Nadeau Pantone). The lexicographically minimal symmetry is used for each class, and the classes are ordered in lexicographical order. To create each heatmap, one million permutations of length 300 were sampled uniformly at random from the class. The color of the point $(i,j)$ represents how many permutations have value $j$ at index $i$. Higher resolution versions can be obtained at [PermPal](https://permpal.com/)
