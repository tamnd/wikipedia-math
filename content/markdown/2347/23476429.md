# Intersection (set theory)

Intersection (mathematics)

::: {#o1 .statement cue=infobox-mathematical-statement name="Intersection"}

**Intersection.**

The intersection of $A$ and $B$ is the set $A \cap B$ of elements that lie in both set $A$ and set $B$.

:::

::: {#o2 .subject cue=lead name="Intersection"}

In [set theory](wikipedia://en/27553), the **intersection** of two [sets](wikipedia://en/26691) $A$ and $B,$ denoted by $A \cap B,$[^o3] is the set containing all elements of $A$ that also belong to $B$ or equivalently, all elements of $B$ that also belong to $A.$[^o4] The notion of intersection as an [algebraic operation](wikipedia://en/5438924) [with sets as operands](https://en.wikipedia.org/wiki/Set_operation_%28Boolean%29) has been generalized from [geometry](wikipedia://en/18973446), where it is [encountered](wikipedia://en/41604289) in the case of geometric sets of [points](wikipedia://en/593693), such as individual points, lines (infinite [uncountable sets](wikipedia://en/32248) of points), planes, etc.

:::

## Notation and terminology {#Notation_and_terminology}

Intersection is written using the symbol "$\cap$" between the terms; that is, in [infix notation](wikipedia://en/199014). For example:

$$\{1,2,3\}\cap\{2,3,4\}=\{2,3\}$$

$$\{1,2,3\}\cap\{4,5,6\}=\varnothing$$

$$\mathbb{Z}\cap\mathbb{N}=\mathbb{N}$$

$$\{x\in\mathbb{R}:x^2=1\}\cap\mathbb{N}=\{1\}$$

The intersection of more than two sets (generalized intersection) can be written as:

$$\bigcap_{i=1}^n A_i$$

which is similar to [capital-sigma notation](https://en.wikipedia.org/wiki/Capital-sigma_notation).

For an explanation of the symbols used in this article, refer to the [table of mathematical symbols](https://en.wikipedia.org/wiki/Table_of_mathematical_symbols).

## Definition {#Definition}

*Image: Venn diagram gr la ru.svg.* Intersections of the unaccented modern [Greek](https://en.wikipedia.org/wiki/Greek_alphabet), [Latin](https://en.wikipedia.org/wiki/Latin_script), and [Cyrillic](https://en.wikipedia.org/wiki/Cyrillic_script) ([Russian alphabet](https://en.wikipedia.org/wiki/Russian_alphabet)) scripts, considering only the shapes of the letters and ignoring their pronunciation

*Image: PolygonsSetIntersection.svg.* Example of an intersection with sets

The intersection of two sets $A$ and $B,$ denoted by $A \cap B$,[^o8] is the set of all objects that are members of both the sets $A$ and $B.$ In symbols:

$$A \cap B = \{ x: x \in A \text{ and } x \in B\}.$$

That is, $x$ is an element of the intersection $A \cap B$ [if and only if](wikipedia://en/14922) $x$ is both an element of $A$ and an element of $B.$[^o8]

For example:

- The intersection of the sets {1, 2, 3} and {2, 3, 4} is {2, 3}.
- The number 9 is not in the intersection of the set of [prime numbers](wikipedia://en/23666) {2, 3, 5, 7, 11, ...} and the set of [odd numbers](https://en.wikipedia.org/wiki/Odd_numbers) {1, 3, 5, 7, 9, 11, ...}, because 9 is not prime.
- The intersection of two geometric sets of points such as two lines is a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) of one point for distinct non-parallel lines in the same plane.

### Intersecting and disjoint sets {#Intersecting_and_disjoint_sets}

We say that $A$ intersects (meets) $B$ if there exists some $x$ that is an element of both $A$ and $B,$ in which case we also say that $A$ intersects (meets) $B$ **at** $x$. Equivalently, $A$ intersects $B$ if their intersection $A \cap B$ is an [inhabited set](wikipedia://en/5473033), meaning that there exists some $x$ such that $x \in A \cap B.$

We say that $A$ and $B$ are [disjoint](wikipedia://en/39359) if $A$ does not intersect $B.$ In plain language, they have no elements in common. $A$ and $B$ are disjoint if their intersection is [empty](wikipedia://en/9566), denoted $A \cap B = \varnothing.$

For example:

- the sets $\{1, 2\}$ and $\{3, 4\}$ are disjoint, while the set of even numbers intersects the set of [multiples](wikipedia://en/3912709) of 3 at the multiples of 6.
- two parallel lines in the same plane are disjoint.

## Algebraic properties {#Algebraic_properties}

Binary intersection is an [associative](https://en.wikipedia.org/wiki/Associative) operation; that is, for any sets $A, B,$ and $C,$ one has

$$A \cap (B \cap C) = (A \cap B) \cap C.$$

Thus the parentheses may be omitted without ambiguity: either of the above can be written as $A \cap B \cap C$. Intersection is also [commutative](wikipedia://en/294390). That is, for any $A$ and $B,$ one has

$$A \cap B = B \cap A.$$

The intersection of any set with the [empty set](wikipedia://en/9566) results in the empty set; that is, that for any set $A$,

$$A \cap \varnothing = \varnothing$$

Also, the intersection operation is [idempotent](wikipedia://en/14972); that is, any set $A$ satisfies that $A \cap A = A$. All these properties follow from analogous facts about [logical conjunction](wikipedia://en/18152).

Intersection [distributes](wikipedia://en/103118) over [union](wikipedia://en/47949) and union distributes over intersection. That is, for any sets $A, B,$ and $C,$ one has

$$\begin{aligned} A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \\ A \cup (B \cap C) = (A \cup B) \cap (A \cup C) \end{aligned}$$

Inside a universe $U,$ one may define the [complement](wikipedia://en/54347) $A^c$ of $A$ to be the set of all elements of $U$ not in $A.$ Furthermore, the intersection of $A$ and $B$ may be written as the complement of the [union](wikipedia://en/47949) of their complements, derived easily from [De Morgan's laws](wikipedia://en/64669):

$$A \cap B = \left(A^{c} \cup B^{c}\right)^c$$

## Arbitrary intersections {#Arbitrary_intersections}

Iterated binary operation

The most general notion is the intersection of an arbitrary nonempty collection of sets. If $M$ is a [nonempty](wikipedia://en/9566) set whose elements are themselves sets, then $x$ is an element of the intersection of $M$ if and only if [for every](wikipedia://en/76174) element $A$ of $M,$ $x$ is an element of $A.$ In symbols:

$$\left( x \in \bigcap_{A \in M} A \right) \Leftrightarrow \left( \forall A \in M, \ x \in A \right).$$

The notation for this last concept can vary considerably. [Set theorists](wikipedia://en/27553) will sometimes write "$\bigcap M$", while others will instead write "${\bigcap}_{A \in M} A$". The latter notation can be generalized to "${\bigcap}_{i \in I} A_i$", which refers to the intersection of the collection $\left\{ A_i : i \in I \right\}.$ Here $I$ is a nonempty set, and $A_i$ is a set for every $i \in I.$

In the case that the [index set](wikipedia://en/393055) $I$ is the set of [natural numbers](wikipedia://en/21474), notation analogous to that of an [infinite product](wikipedia://en/26382006) may be seen:

$$\bigcap_{i=1}^{\infty} A_i.$$

When formatting is difficult, this can also be written "$A_1 \cap A_2 \cap A_3 \cap \cdots$". This last example, an intersection of countably many sets, is actually very common; for an example, see the article on [σ-algebras](https://en.wikipedia.org/wiki/Sigma_algebra).

## Nullary intersection {#Nullary_intersection}

*Image: Variadic logical AND.svg.* [Conjunctions](wikipedia://en/18152) of the arguments in parenthesesThe conjunction of no argument is the [tautology](wikipedia://en/4495335) (compare: [empty product](wikipedia://en/181289)); accordingly the intersection of no set is the [universe](https://en.wikipedia.org/wiki/Universe_%28set_theory%29).

In the previous section, we excluded the case where $M$ was the [empty set](wikipedia://en/9566) ($\varnothing$). The reason is as follows: The intersection of the collection $M$ is defined as the set (see [set-builder notation](wikipedia://en/220089))

$$\bigcap_{A \in M} A = \{x : \text{ for all } A \in M, x \in A\}.$$

If $M$ is empty, there are no sets $A$ in $M,$ so the question becomes "which $x$'s satisfy the stated condition?" The answer seems to be every possible $x$. When $M$ is empty, the condition given above is an example of a [vacuous truth](wikipedia://en/51672). So the intersection of the empty family should be the [universal set](wikipedia://en/303405) (the [identity element](wikipedia://en/14962) for the operation of intersection),[^o16] but in standard ([ZF](wikipedia://en/152214)) set theory, the universal set does not exist.

However, when restricted to the context of subsets of a given fixed set $X$, the notion of the intersection of an empty collection of subsets of $X$ is well-defined. In that case, if $M$ is empty, its intersection is $\bigcap M=\bigcap\varnothing=\{x\in X: x\in A \text{ for all }A\in\varnothing\}$. Since all $x\in X$ vacuously satisfy the required condition, the intersection of the empty collection of subsets of $X$ is all of $X.$ In formulas, $\bigcap\varnothing=X.$ This matches the intuition that as collections of subsets become smaller, their respective intersections become larger; in the extreme case, the empty collection has an intersection equal to the whole underlying set.

Also, in [type theory](wikipedia://en/40282) $x$ is of a prescribed type $\tau,$ so the intersection is understood to be of type $\mathrm{set}\ \tau$ (the type of sets whose elements are in $\tau$), and we can define $\bigcap_{A \in \emptyset} A$ to be the universal set of $\mathrm{set}\ \tau$ (the set whose elements are exactly all terms of type $\tau$).
