# Einstein–Weyl geometry

::: {#o1 .subject cue=lead name="Einstein–Weyl geometry"}

An **Einstein–Weyl geometry** is a smooth [conformal manifold](https://en.wikipedia.org/wiki/Conformal_manifold), together with a compatible [Weyl connection](wikipedia://en/14889315) that satisfies an appropriate version of the [Einstein vacuum equations](https://en.wikipedia.org/wiki/Einstein_equations), first considered by (Cartan 1943) and named after [Albert Einstein](wikipedia://en/736) and [Hermann Weyl](wikipedia://en/187544). Specifically, if $M$ is a manifold with a conformal metric $[g]$, then a Weyl connection is by definition a torsion-free [affine connection](wikipedia://en/607690) $\nabla$ such that

$$\nabla g = \alpha\otimes g$$

where $\alpha$ is a one-form.

:::

The curvature tensor is defined in the usual manner by

$$R(X,Y)Z = (\nabla_X\nabla_Y - \nabla_Y\nabla_X - \nabla_{[X,Y]})Z,$$

and the [Ricci curvature](wikipedia://en/276582) is

$$Rc(Y,Z) = \operatorname{tr}(X\mapsto R(X,Y)Z).$$

The Ricci curvature for a Weyl connection may fail to be symmetric (its skew part is essentially the exterior derivative of $\alpha$.)

An Einstein–Weyl geometry is then one for which the symmetric part of the Ricci curvature is a multiple of the metric, by an arbitrary smooth function:[^o3]

$$Rc(X,Y) + Rc(Y,X) = f\,g(X,Y).$$

The global analysis of Einstein–Weyl geometries is generally more subtle than that of conformal geometry. For example, the [Einstein cylinder](https://en.wikipedia.org/wiki/Einstein_cylinder) is a global static conformal structure, but only one period of the cylinder (with the conformal structure of the [de Sitter metric](https://en.wikipedia.org/wiki/De_Sitter_metric)) is Einstein–Weyl.
