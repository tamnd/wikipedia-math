# Stieltjes matrix

::: {#o1 .subject cue=lead name="Stieltjes matrix"}

In [mathematics](wikipedia://en/18831), particularly [matrix theory](wikipedia://en/20556859), a **Stieltjes matrix**, named after [Thomas Joannes Stieltjes](wikipedia://en/40589), is a [real](https://en.wikipedia.org/wiki/Real_numbers) [symmetric](wikipedia://en/126474) [positive definite matrix](https://en.wikipedia.org/wiki/Positive_definite_matrix) with [nonpositive](https://en.wikipedia.org/wiki/Nonpositive) [off-diagonal](https://en.wikipedia.org/wiki/Off-diagonal) entries. A Stieltjes matrix is necessarily an [M-matrix](wikipedia://en/7939066). Every *n×n* Stieltjes matrix is invertible to a nonsingular symmetric [nonnegative](wikipedia://en/3945884) matrix, though the converse of this statement is not true in general for *n* > 2.

:::

From the above definition, a Stieltjes matrix is a symmetric invertible [Z-matrix](wikipedia://en/7838302) whose eigenvalues have positive real parts. As it is a Z-matrix, its off-diagonal entries are less than or equal to zero.
