# Ordered vector space

*Image: Ordered space illustration.svg.* A point $x$ in $\mathbb{R}^2$ and the [set](wikipedia://en/26691) of all $y$ such that $x \leq y$ (in red). The order here is $x \leq y$ if and only if $x_1 \leq y_1$ and $x_2 \leq y_2.$

::: {#o1 .subject cue=lead name="Ordered vector space"}

In [mathematics](wikipedia://en/18831), an **ordered vector space** or **partially ordered vector space** is a [real vector space](https://en.wikipedia.org/wiki/Real_vector_space) equipped with a [partial order](https://en.wikipedia.org/wiki/Partial_order) that is compatible with the vector space operations.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a vector space $X$ over the [real numbers](wikipedia://en/20646438) $\mathbb{R}$ and a [preorder](wikipedia://en/23582) $\,\leq\,$ on the [set](wikipedia://en/26691) $X,$ the pair $(X, \leq)$ is called a **preordered vector space** and we say that the preorder $\,\leq\,$ **is compatible with the vector space structure** of $X$ and call $\,\leq\,$ a **vector preorder** on $X$ if for all $x, y, z \in X$ and $r \in \mathbb{R}$ with $r \geq 0$ the following two axioms are satisfied

1. $x \leq y$ implies $x + z \leq y + z,$
1. $y \leq x$ implies $r y \leq r x.$

If $\,\leq\,$ is a [partial order](https://en.wikipedia.org/wiki/Partial_order) compatible with the vector space structure of $X$ then $(X, \leq)$ is called an **ordered vector space** and $\,\leq\,$ is called a **vector partial order** on $X.$ The two axioms imply that [translations](wikipedia://en/204682) and [positive homotheties](https://en.wikipedia.org/wiki/Positive_homothety) are [automorphisms](wikipedia://en/1160) of the order structure and the mapping $x \mapsto -x$ is an [isomorphism](wikipedia://en/14828) to the [dual order structure](wikipedia://en/600618). Ordered vector spaces are [ordered groups](https://en.wikipedia.org/wiki/Ordered_group) under their addition operation. Note that $x \leq y$ if and only if $-y \leq -x.$

:::

## Positive cones and their equivalence to orderings {#Positive_cones_and_their_equivalence_to_orderings}

A [subset](wikipedia://en/27631) $C$ of a vector space $X$ is called a **cone** if for all real $r > 0,$ $r C \subseteq C$. A cone is called **pointed** if it contains the origin. A cone $C$ is convex if and only if $C + C \subseteq C.$ The [intersection](wikipedia://en/23476429) of any [non-empty](wikipedia://en/9566) family of cones (resp. convex cones) is again a cone (resp. convex cone); the same is true of the [union](wikipedia://en/47949) of an increasing (under [set inclusion](wikipedia://en/27631)) family of cones (resp. convex cones). A cone $C$ in a vector space $X$ is said to be **generating** if $X = C - C.$[^n1]

Given a preordered vector space $X,$ the subset $X^+$ of all elements $x$ in $(X, \leq)$ satisfying $x \geq 0$ is a pointed [convex cone](wikipedia://en/3558266) (that is, a convex cone containing $0$) called the **positive cone** of $X$ and denoted by $\operatorname{PosCone} X.$ The elements of the positive cone are called **positive**. If $x$ and $y$ are elements of a preordered vector space $(X, \leq),$ then $x \leq y$ if and only if $y - x \in X^+.$ The positive cone is generating if and only if $X$ is a [directed set](wikipedia://en/9165) under $\,\leq.$ Given any pointed convex cone $C$ one may define a preorder $\,\leq\,$ on $X$ that is compatible with the vector space structure of $X$ by declaring for all $x, y \in X,$ that $x \leq y$ if and only if $y - x \in C;$ the positive cone of this resulting preordered vector space is $C.$ There is thus a one-to-one correspondence between pointed convex cones and vector preorders on $X.$[^n1] If $X$ is preordered then we may form an [equivalence relation](wikipedia://en/9259) on $X$ by defining $x$ is equivalent to $y$ if and only if $x \leq y$ and $y \leq x;$ if $N$ is the [equivalence class](wikipedia://en/9260) containing the origin then $N$ is a vector subspace of $X$ and $X / N$ is an ordered vector space under the relation: $A \leq B$ if and only there exist $a \in A$ and $b \in B$ such that $a \leq b.$[^n1]

A subset of $C$ of a vector space $X$ is called a **[proper cone](https://en.wikipedia.org/wiki/Proper_cone)** if it is a convex cone satisfying $C \cap (- C) = \{0\}.$ Explicitly, $C$ is a proper cone if (1) $C + C \subseteq C,$ (2) $r C \subseteq C$ for all $r > 0,$ and (3) $C \cap (- C) = \{0\}.$[^n2] The intersection of any non-empty family of proper cones is again a proper cone. Each proper cone $C$ in a real vector space induces an order on the vector space by defining $x \leq y$ if and only if $y - x \in C,$ and furthermore, the positive cone of this ordered vector space will be $C.$ Therefore, there exists a one-to-one correspondence between the proper convex cones of $X$ and the vector partial orders on $X.$

By a **total vector ordering** on $X$ we mean a [total order](wikipedia://en/30330) on $X$ that is compatible with the vector space structure of $X.$ The family of total vector orderings on a vector space $X$ is in one-to-one correspondence with the family of all proper cones that are maximal under set inclusion.[^n1] A total vector ordering *cannot* be [Archimedean](https://en.wikipedia.org/wiki/Archimedean_order) if its [dimension](wikipedia://en/38267), when considered as a vector space over the reals, is greater than 1.[^n1]

If $R$ and $S$ are two orderings of a vector space with positive cones $P$ and $Q,$ respectively, then we say that $R$ is **finer** than $S$ if $P \subseteq Q.$[^n2]

:::

## Intervals and the order bound dual {#Intervals_and_the_order_bound_dual}

An **order interval** in a preordered vector space is a set of the form

$$\begin{alignedat}{4} [a, b] &= \{x : a \leq x \leq b\}, \\[0.1ex] [a, b[ &= \{x : a \leq x < b\}, \\ ]a, b] &= \{x : a < x \leq b\}, \text{ or } \\ ]a, b[ &= \{x : a < x < b\}. \\ \end{alignedat}$$

From axioms 1 and 2 above it follows that $x, y \in [a, b]$ and $0 < t < 1$ implies $t x + (1 - t) y$ belongs to $[a, b];$ thus these order intervals are convex. A subset is said to be **order bounded** if it is contained in some order interval.[^n2] In a preordered real vector space, if for $x \geq 0$ then the interval of the form $[-x, x]$ is [balanced](wikipedia://en/1734238).[^n2] An **[order unit](wikipedia://en/38017102)** of a preordered vector space is any element $x$ such that the set $[-x, x]$ is [absorbing](wikipedia://en/1728179).[^n2]

The set of all [linear functionals](https://en.wikipedia.org/wiki/Linear_functional) on a preordered vector space $X$ that map every order interval into a bounded set is called the **[order bound dual](wikipedia://en/63989481)** of $X$ and denoted by $X^{\operatorname{b}}.$[^n2] If a space is ordered then its order bound dual is a vector subspace of its [algebraic dual](https://en.wikipedia.org/wiki/Algebraic_dual).

A subset $A$ of an ordered vector space $X$ is called **[order complete](wikipedia://en/63989777)** if for every non-empty subset $B \subseteq A$ such that $B$ is order bounded in $A,$ both $\sup B$ and $\inf B$ exist and are elements of $A.$ We say that an ordered vector space $X$ is **order complete** is $X$ is an order complete subset of $X.$[^n3]

::: {#o20 .example cue=heading name="Examples"}

### Examples {#Examples}

If $(X, \leq)$ is a preordered vector space over the reals with order unit $u,$ then the map $p(x) := \inf \{t \in \mathbb{R} : x \leq t u\}$ is a [sublinear functional](https://en.wikipedia.org/wiki/Sublinear_functional).[^n4]

:::

## Properties {#Properties}

If $X$ is a preordered vector space then for all $x, y \in X,$

- $x \geq 0$ and $y \geq 0$ imply $x + y \geq 0.$[^n4]
- $x \leq y$ if and only if $-y \leq -x.$[^n4]
- $x \leq y$ and $r < 0$ imply $r x \geq r y.$[^n4]
- $x \leq y$ if and only if $y = \sup \{x, y\}$ if and only if $x = \inf \{x, y\}$[^n4]
- $\sup \{x, y\}$ exists if and only if $\inf \{-x, -y\}$ exists, in which case $\inf \{-x, -y\} = - \sup \{x, y\}.$[^n4]
- $\sup \{x, y\}$ exists if and only if $\inf \{x, y\}$ exists, in which case for all $z \in X,$[^n4]
  - $\sup \{x + z, y + z\} = z + \sup \{x, y\},$ and
  - $$\inf \{x + z, y + z\} = z + \inf \{x, y\}$$
  - $$x + y = \inf\{x, y\} + \sup \{x, y\}.$$
- $X$ is a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) if and only if $\sup \{0, x\}$ exists for all $x \in X.$[^n4]

:::

## Spaces of linear maps {#Spaces_of_linear_maps}

A cone $C$ is said to be **generating** if $C - C$ is equal to the whole vector space.[^n2] If $X$ and $W$ are two non-trivial ordered vector spaces with respective positive cones $P$ and $Q,$ then $P$ is generating in $X$ if and only if the set $C = \{u \in L(X; W) : u(P) \subseteq Q\}$ is a proper cone in $L(X; W),$ which is the space of all linear maps from $X$ into $W.$ In this case, the ordering defined by $C$ is called the **canonical ordering** of $L(X; W).$[^n2] More generally, if $M$ is any vector subspace of $L(X; W)$ such that $C \cap M$ is a proper cone, the ordering defined by $C \cap M$ is called the **canonical ordering** of $M.$[^n2]

### Positive functionals and the order dual {#Positive_functionals_and_the_order_dual}

A [linear function](wikipedia://en/152111) $f$ on a preordered vector space is called **positive** if it satisfies either of the following equivalent conditions:

1. $x \geq 0$ implies $f(x) \geq 0.$
1. if $x \leq y$ then $f(x) \leq f(y).$[^n4]

The set of all positive linear forms on a vector space with positive cone $C,$ called the **[dual cone](wikipedia://en/10063937)** and denoted by $C^*,$ is a cone equal to the [polar](wikipedia://en/1764022) of $-C.$ The preorder induced by the dual cone on the space of linear functionals on $X$ is called the **dual preorder**.[^n4]

The **[order dual](wikipedia://en/12259232)** of an ordered vector space $X$ is the set, denoted by $X^+,$ defined by $X^+ := C^* - C^*.$ Although $X^+ \subseteq X^b,$ there do exist ordered vector spaces for which set equality does not hold.[^n2]

## Special types of ordered vector spaces {#Special_types_of_ordered_vector_spaces}

Let $X$ be an ordered vector space. We say that an ordered vector space $X$ is **[Archimedean ordered](wikipedia://en/63989376)** and that the order of $X$ is **Archimedean** if whenever $x$ in $X$ is such that $\{n x : n \in \mathbb{N}\}$ is **[majorized](wikipedia://en/2864495)** (that is, there exists some $y \in X$ such that $n x \leq y$ for all $n \in \mathbb{N}$) then $x \leq 0.$[^n2] A [topological vector space](wikipedia://en/45752) (TVS) that is an ordered vector space is necessarily Archimedean if its positive cone is closed.[^n2]

We say that a preordered vector space $X$ is **[regularly ordered](wikipedia://en/63990309)** and that its order is **regular** if it is [Archimedean ordered](https://en.wikipedia.org/wiki/Archimedean_ordered) and $X^+$ distinguishes points in $X.$[^n2] This property guarantees that there are sufficiently many positive linear forms to be able to successfully use the tools of duality to study ordered vector spaces.[^n2]

An ordered vector space is called a **[vector lattice](https://en.wikipedia.org/wiki/Vector_lattice)** if for all elements $x$ and $y,$ the [supremum](https://en.wikipedia.org/wiki/Supremum) $\sup (x, y)$ and [infimum](https://en.wikipedia.org/wiki/Infimum) $\inf (x, y)$ exist.[^n2]

## Subspaces, quotients, and products {#Subspaces,_quotients,_and_products}

Throughout let $X$ be a preordered vector space with positive cone $C.$

**Subspaces**

If $M$ is a vector subspace of $X$ then the canonical ordering on $M$ induced by $X$'s positive cone $C$ is the partial order induced by the pointed convex cone $C \cap M,$ where this cone is proper if $C$ is proper.[^n2]

**Quotient space**

Let $M$ be a vector subspace of an ordered vector space $X,$ $\pi : X \to X / M$ be the canonical projection, and let $\hat{C} := \pi(C).$ Then $\hat{C}$ is a cone in $X / M$ that induces a canonical preordering on the [quotient space](wikipedia://en/898784) $X / M.$ If $\hat{C}$ is a proper cone in$X / M$ then $\hat{C}$ makes $X / M$ into an ordered vector space.[^n2] If $M$ is [$C$-saturated](wikipedia://en/63990850) then $\hat{C}$ defines the canonical order of $X / M.$[^n1] Note that $X = \mathbb{R}^2_0$ provides an example of an ordered vector space where $\pi(C)$ is not a proper cone.

If $X$ is also a [topological vector space](wikipedia://en/45752) (TVS) and if for each [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) $V$ of the origin in $X$ there exists a neighborhood $U$ of the origin such that $[(U + N) \cap C] \subseteq V + N$ then $\hat{C}$ is a [normal cone](wikipedia://en/63990912) for the [quotient topology](https://en.wikipedia.org/wiki/Quotient_topology).[^n1]

If $X$ is a [topological vector lattice](wikipedia://en/63989962) and $M$ is a closed [solid](wikipedia://en/63989659) sublattice of $X$ then $X / L$ is also a topological vector lattice.[^n1]

**Product**

If $S$ is any set then the space $X^S$ of all functions from $S$ into $X$ is canonically ordered by the proper cone $\left\{f \in X^S : f(s) \in C \text{ for all } s \in S\right\}.$[^n2]

Suppose that $\left\{X_\alpha : \alpha \in A\right\}$ is a family of preordered vector spaces and that the positive cone of $X_\alpha$ is $C_\alpha.$ Then $C := \prod_\alpha C_\alpha$ is a pointed convex cone in $\prod_\alpha X_\alpha,$ which determines a canonical ordering on $\prod_\alpha X_\alpha;$ $C$ is a proper cone if all $C_\alpha$ are proper cones.[^n2]

**Algebraic direct sum**

The algebraic [direct sum](wikipedia://en/2084687) $\bigoplus_\alpha X_\alpha$ of $\left\{X_\alpha : \alpha \in A\right\}$ is a vector subspace of $\prod_\alpha X_\alpha$ that is given the canonical subspace ordering inherited from $\prod_\alpha X_\alpha.$[^n2] If $X_1, \dots, X_n$ are ordered vector subspaces of an ordered vector space $X$ then $X$ is the ordered direct sum of these subspaces if the canonical algebraic isomorphism of $X$ onto $\prod_\alpha X_\alpha$ (with the canonical product order) is an [order isomorphism](wikipedia://en/23916899).[^n2]

## Examples {#Examples}

- The [real numbers](wikipedia://en/20646438) with the usual ordering form a totally ordered vector space. For all [integers](wikipedia://en/14563) $n \geq 0,$ the [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$ considered as a vector space over the reals with the [lexicographic ordering](wikipedia://en/567667) forms a preordered vector space whose order is [Archimedean](wikipedia://en/63989376) if and only if $n = 1$.[^n4]
- $\mathbb{R}^2$ is an ordered vector space with the $\,\leq\,$ relation defined in any of the following ways (in order of increasing strength, that is, decreasing sets of pairs):
  - [Lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order): $(a, b) \leq (c, d)$ if and only if $a < c$ or $(a = c \text{ and } b \leq d).$ This is a [total order](wikipedia://en/30330). The positive cone is given by $x > 0$ or $(x = 0 \text{ and } y \geq 0),$ that is, in [polar coordinates](wikipedia://en/25120), the set of points with the angular coordinate satisfying $-\pi / 2 < \theta \leq \pi / 2,$ together with the origin.
  - $(a, b) \leq (c, d)$ if and only if $a \leq c$ and $b \leq d$ (the [product order](wikipedia://en/1956306) of two copies of $\mathbb{R}$ with $\leq$). This is a partial order. The positive cone is given by $x \geq 0$ and $y \geq 0,$ that is, in polar coordinates $0 \leq \theta \leq \pi / 2,$ together with the origin.
  - $(a, b) \leq (c, d)$ if and only if $(a < c \text{ and } b < d)$ or $(a = c \text{ and } b = d)$ (the [reflexive closure](wikipedia://en/22603618) of the [direct product](wikipedia://en/8887#Direct_product_of_binary_relations) of two copies of $\mathbb{R}$ with "\<"). This is also a partial order. The positive cone is given by $(x > 0 \text{ and } y > 0)$ or $x = y = 0),$ that is, in polar coordinates, $0 < \theta < \pi / 2,$ together with the origin.

Only the second order is, as a subset of $\mathbb{R}^4,$ closed; see [partial orders in topological spaces](wikipedia://en/23572#Partial_orders_in_topological_spaces).

For the third order the two-dimensional "[intervals](wikipedia://en/23572#Intervals)" $p < x < q$ are [open sets](wikipedia://en/39358) which generate the topology.

- $\mathbb{R}^n$ is an ordered vector space with the $\,\leq\,$ relation defined similarly. For example, for the second order mentioned above:
  - $x \leq y$ if and only if $x_i \leq y_i$ for $i = 1, \dots, n.$
- A [Riesz space](wikipedia://en/8099018) is an ordered vector space where the order gives rise to a [lattice](wikipedia://en/469304).
- The space of continuous functions on $[0, 1]$ where $f \leq g$ if and only if $f(x) \leq g(x)$ for all $x$ in $[0, 1].$
- Let $\mbox{Sym}_n(\mathbb{R})$ denote the symmetric $n \times n$ matrices with real entries. The [Loewner order](wikipedia://en/46706590) $\preccurlyeq$ on two symmetric matrices $A,B \in \mbox{Sym}_n(\mathbb{R})$is defined by $A \preccurlyeq B \Leftrightarrow B - A$ is [positive semi-definite](https://en.wikipedia.org/wiki/Positive_semi-definite_matrix). Its positive cone is, by definition, the set of all positive definite matrices. Furthermore, the [spectral theorem](wikipedia://en/123495) applied to symmetric matrices establishes that this cone is generating.

### Pointwise order {#Pointwise_order}

If $S$ is any set and if $X$ is a vector space (over the reals) of real-valued [functions](wikipedia://en/185427) on $S,$ then the **pointwise order** on $X$ is given by, for all $f, g \in X,$ $f \leq g$ if and only if $f(s) \leq g(s)$ for all $s \in S.$[^n4]

Spaces that are typically assigned this order include:

- the space $\ell^\infty(S, \mathbb{R})$ of [bounded](wikipedia://en/311509) real-valued maps on $S.$
- the space $c_0(\mathbb{R})$ of real-valued [sequences](https://en.wikipedia.org/wiki/Sequences) that [converge](wikipedia://en/285773) to $0.$
- the space $C(S, \mathbb{R})$ of [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) real-valued functions on a [topological space](wikipedia://en/30450) $S.$
- for any non-negative integer $n,$ the Euclidean space $\mathbb{R}^n$ when considered as the space $C(\{1, \dots, n\}, \mathbb{R})$ where $S = \{1, \dots, n\}$ is given the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology).

The space $\mathcal{L}^\infty(\mathbb{R}, \mathbb{R})$ of all [measurable](wikipedia://en/44055) [almost-everywhere](https://en.wikipedia.org/wiki/Almost-everywhere) bounded real-valued maps on $\mathbb{R},$ where the preorder is defined for all $f, g \in \mathcal{L}^\infty(\mathbb{R}, \mathbb{R})$ by $f \leq g$ if and only if $f(s) \leq g(s)$ almost everywhere.[^n4]
