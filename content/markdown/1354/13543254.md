# GGobi

::: {#o2 .subject cue=lead name="GGobi"}

**GGobi** is a [free](https://en.wikipedia.org/wiki/Free_software) [statistical software](https://en.wikipedia.org/wiki/List_of_statistical_packages) tool for [interactive data visualization](https://en.wikipedia.org/wiki/Interactive_data_visualization). GGobi allows extensive exploration of the data with Interactive dynamic [graphics](https://en.wikipedia.org/wiki/Graphics). It is also a tool for looking at multivariate data. [R](wikipedia://en/376707) can be used in sync with GGobi (through [rggobi](https://cran.r-project.org/web/packages/rggobi/index.html)). The GGobi software can be embedded as a library in other programs and program packages using an application programming interface (API) (integration into a stand-alone application) or as an add-on to existing languages and scripting environments, e.g., with the R command line or from a [Perl](https://en.wikipedia.org/wiki/Perl) or [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) scripts. GGobi prides itself on its ability to link multiple graphs together.[^o3]

:::

## Overview {#Overview}

GGobi was created to look at data matrices. The designers were interested in exploring multi-dimensional data. The program developers went through many name changes before settling on GGobi (A combination of the words [GTK+](https://en.wikipedia.org/wiki/GTK+) and the [Gobi Desert](https://en.wikipedia.org/wiki/Gobi_Desert)). The original concept, Dataviewer, began in the mid-80s, and a predecessor, XGobi, began in 1989. Work began on the current version of GGobi in 1999. The main reason for the different versions was the change in technology.[^o5] Current version for [MS Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) is 2.1.10a (12 March 2010) with an update for 64 bit usage from 10 June 2012.

Released under a combination of three [free software licenses](https://en.wikipedia.org/wiki/Free_software_licenses), GGobi is [free software](https://en.wikipedia.org/wiki/Free_software).[^o6]

### Importance of graphics {#Importance_of_graphics}

Looking at data through various graphs can reveal more information about the distribution than just looking at the numbers or a summary of them. Using the different tools within GGobi, clusters, non-linear distributions, outliers, and other important variations in the data can be discovered. GGobi is a program which allows [exploratory data analysis](wikipedia://en/416589) to occur for multi-dimensional data.

### Supported data sources {#Supported_data_sources}

GGobi can read [CSV](https://en.wikipedia.org/wiki/Comma-separated_values) and [XML](https://en.wikipedia.org/wiki/XML) file types.[^o10]

### Types of graphics {#Types_of_graphics}

- 1D: [Average shifted histogram](https://en.wikipedia.org/wiki/Average_shifted_histogram), [textured dot plot](https://en.wikipedia.org/wiki/Textured_dot_plot), [barchart](https://en.wikipedia.org/wiki/Barchart), [spineplot](https://en.wikipedia.org/wiki/Spineplot)
- 2D: [Scatterplot](https://en.wikipedia.org/wiki/Scatterplot)
- High-D:
  - [Scatterplot matrix](https://en.wikipedia.org/wiki/Scatterplot_matrix)
  - [Parallel coordinates](wikipedia://en/1254148)
  - [Grand tour](https://en.wikipedia.org/wiki/Grand_Tour_%28data_visualisation%29), [projection pursuit](wikipedia://en/2830368) guided tour, manual tour
- Time series plot

### Interactions {#Interactions}

These tools can be used to pick out special points or clusters of data.

- [Brushing](wikipedia://en/20349155)

As the brush moves over a point, the point will be highlighted.

If "persistent" is selected, the points the brush has moved over will remain "painted".

- Identify

As the cursor moves over a point, a label, or variable value will appear at the top of the graphic screen.

- Linking

Multiple plots are linked so identifying one point in one plot will identify the same point on all other graphs, and brushing a group of points in one plot will highlight the same points in other plots. The linking can be one-to-one, or according to the values of a categorical variable in the data set.

- Moving points

Points in a plot can be moved interactively, e.g. to gauge results from multidimensional scaling.

- Add/remove points or edges.
