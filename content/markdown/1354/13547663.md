# Jacobsthal number

::: {#o1 .subject cue=lead name="Jacobsthal number"}

In [mathematics](wikipedia://en/18831), the **Jacobsthal numbers** are an [integer sequence](wikipedia://en/51421) named after the [German](https://en.wikipedia.org/wiki/Germany) mathematician [Ernst Jacobsthal](wikipedia://en/13578362). Like the related [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number), they are a specific type of [Lucas sequence](wikipedia://en/734635) $U_n(P,Q)$ for which *P* = 1, and *Q* = −2—and are defined by a similar [recurrence relation](wikipedia://en/146806): in simple terms, the sequence starts with 0 and 1, then each following number is found by adding the number before it to twice the number before that. The first Jacobsthal numbers are:

[0](https://en.wikipedia.org/wiki/0_%28number%29), [1](https://en.wikipedia.org/wiki/1_%28number%29), 1, [3](https://en.wikipedia.org/wiki/3_%28number%29), [5](https://en.wikipedia.org/wiki/5_%28number%29), [11](wikipedia://en/208156), [21](wikipedia://en/209248), [43](https://en.wikipedia.org/wiki/43_%28number%29), [85](https://en.wikipedia.org/wiki/85_%28number%29), [171](https://en.wikipedia.org/wiki/171_%28number%29), 341, 683, 1365, 2731, 5461, 10923, 21845, 43691, 87381, 174763, 349525, …

## Jacobsthal numbers {#Jacobsthal_numbers}

Jacobsthal numbers are defined by the recurrence relation:

$$J_n = \begin{cases} 0 & \mbox{if } n = 0; \\ 1 & \mbox{if } n = 1; \\ J_{n-1} + 2J_{n-2} & \mbox{if } n > 1. \\ \end{cases}$$

The next Jacobsthal number is also given by the recursion formula

$$J_{n+1} = 2J_n + (-1)^n,$$

or by

$$J_{n+1} = 2^n - J_n.$$

The second recursion formula above is also satisfied by the [powers of 2](https://en.wikipedia.org/wiki/Powers_of_2).

The Jacobsthal number at a specific point in the sequence may be calculated directly using the closed-form equation:[^o6]

$$J_n = \frac{2^n - (-1)^n}{3}.$$

The [generating function](wikipedia://en/160993) for the Jacobsthal numbers is

$$\frac{x}{(1+x)(1-2x)}.$$

The sum of the [reciprocals](wikipedia://en/229940) of the Jacobsthal numbers is approximately 2.7186, slightly larger than [e](wikipedia://en/9633).

The Jacobsthal numbers can be extended to negative indices using the recurrence relation or the explicit formula, giving

$J_{-n} = (-1)^{n+1} J_n / 2^n$ (see )

The following identities holds

$2^n(J_{-n} + J_n) = 3 J_n^2$ (see )

$J_n = F_n + \sum_{i=0}^{n-2}J_iF_{n-i-1}$ where $F_n$ is the *nth* Fibonacci number.

## Jacobsthal–Lucas numbers {#Jacobsthal–Lucas_numbers}

Jacobsthal–Lucas numbers represent the complementary Lucas sequence $V_n(1,-2)$. They satisfy the same recurrence relation as Jacobsthal numbers but have different initial values:

$$j_n = \begin{cases} 2 & \mbox{if } n = 0; \\ 1 & \mbox{if } n = 1; \\ j_{n-1} + 2j_{n-2} & \mbox{if } n > 1. \\ \end{cases}$$

The following Jacobsthal–Lucas number also satisfies:

$$j_{n+1} = 2j_n - 3(-1)^n. \,$$

The Jacobsthal–Lucas number at a specific point in the sequence may be calculated directly using the closed-form equation:[^o6]

$$j_n = 2^n + (-1)^n. \,$$

The first Jacobsthal–Lucas numbers are:

[2](https://en.wikipedia.org/wiki/2_%28number%29), [1](https://en.wikipedia.org/wiki/1_%28number%29), [5](https://en.wikipedia.org/wiki/5_%28number%29), [7](https://en.wikipedia.org/wiki/7_%28number%29), [17](wikipedia://en/208288), [31](https://en.wikipedia.org/wiki/31_%28number%29), [65](https://en.wikipedia.org/wiki/65_%28number%29), [127](https://en.wikipedia.org/wiki/127_%28number%29), [257](https://en.wikipedia.org/wiki/257_%28number%29), [511](https://en.wikipedia.org/wiki/511_%28number%29), 1025, 2047, 4097, [8191](wikipedia://en/48189814), 16385, 32767, [65537](https://en.wikipedia.org/wiki/65,537), 131071, 262145, 524287, 1048577, … .
