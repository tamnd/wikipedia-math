# Global dimension

::: {#o1 .subject cue=lead name="Global dimension"}

In [ring theory](wikipedia://en/250424) and [homological algebra](wikipedia://en/139410), the **global dimension** (or **global homological dimension**; sometimes just called **homological dimension**) of a [ring](wikipedia://en/48404) *A* denoted gl dim *A*, is a non-negative [integer](wikipedia://en/14563) or infinity which is a homological invariant of the ring. It is defined to be the [supremum](https://en.wikipedia.org/wiki/Supremum) of the set of [projective dimensions](https://en.wikipedia.org/wiki/Projective_dimension) of all *A*-[modules](wikipedia://en/276410). Global dimension is an important technical notion in the dimension theory of [Noetherian rings](wikipedia://en/56129). By a theorem of [Jean-Pierre Serre](wikipedia://en/205483), global dimension can be used to characterize within the class of [commutative](wikipedia://en/61346) Noetherian [local rings](wikipedia://en/153391) those rings which are [regular](wikipedia://en/506959). Their global dimension coincides with the [Krull dimension](wikipedia://en/56079), whose definition is module-theoretic.

:::

When the ring *A* is [noncommutative](wikipedia://en/24062516), one initially has to consider two versions of this notion, right global dimension that arises from consideration of the right *A*-modules, and left global dimension that arises from consideration of the left *A*-modules. For an arbitrary ring *A* the right and left global dimensions may differ. However, if *A* is a Noetherian ring, both of these dimensions turn out to be equal to *[weak global dimension](https://en.wikipedia.org/wiki/Weak_global_dimension)*, whose definition is left-right symmetric. Therefore, for noncommutative Noetherian rings, these two versions coincide and one is justified in talking about the global dimension.[^o2]

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- Let *A* = *K*\[*x*<sub>1</sub>,...,*x*<sub>*n*</sub>\] be the [ring of polynomials](https://en.wikipedia.org/wiki/Ring_of_polynomials) in *n* variables over a [field](wikipedia://en/10603) *K*. Then the global dimension of *A* is equal to *n*. This statement goes back to [David Hilbert](wikipedia://en/8302)'s foundational work on homological properties of polynomial rings; see [Hilbert's syzygy theorem](wikipedia://en/1280843). More generally, if *R* is a Noetherian ring of finite global dimension *k* and *A* = *R*\[x\] is a ring of polynomials in one variable over *R* then the global dimension of *A* is equal to *k* + 1.
- A ring has global dimension zero if and only if it is [semisimple](https://en.wikipedia.org/wiki/Semisimple_ring).
- The global dimension of a ring *A* is less than or equal to one if and only if *A* is [hereditary](wikipedia://en/5123176). In particular, a commutative [principal ideal domain](wikipedia://en/25039) which is not a field has global dimension one. For example $\mathbb{Z}$ has global dimension one.
- The first [Weyl algebra](wikipedia://en/491095) *A*<sub>1</sub> is a noncommutative Noetherian [domain](wikipedia://en/487627) of global dimension one.
- If a ring is right Noetherian, then the right global dimension is the same as the weak global dimension, and is at most the left global dimension. In particular if a ring is right and left Noetherian then the left and right global dimensions and the weak global dimension are all the same.
- The [triangular matrix ring](wikipedia://en/30536078) $\begin{bmatrix}\mathbb Z&\mathbb Q \\0&\mathbb Q \end{bmatrix}$ has right global dimension 1, weak global dimension 1, but left global dimension 2. It is right Noetherian but not left Noetherian.

:::

## Alternative characterizations {#Alternative_characterizations}

The right global dimension of a ring *A* can be alternatively defined as:

- the supremum of the set of projective dimensions of all [cyclic](wikipedia://en/4128720) right *A*-modules;
- the supremum of the set of projective dimensions of all [finite](https://en.wikipedia.org/wiki/Finitely-generated_module) right *A*-modules;
- the supremum of the [injective dimensions](https://en.wikipedia.org/wiki/Injective_dimension) of all right *A*-modules;
- when *A* is a commutative Noetherian [local ring](wikipedia://en/153391) with [maximal ideal](wikipedia://en/48164) *m*, the [projective dimension](https://en.wikipedia.org/wiki/Projective_dimension) of the [residue field](wikipedia://en/10789680) *A*/*m*.

The left global dimension of *A* has analogous characterizations obtained by replacing "right" with "left" in the above list.

Serre [proved](wikipedia://en/82285) that a commutative Noetherian local ring *A* is [regular](wikipedia://en/506959) if and only if it has finite global dimension, in which case the global dimension coincides with the [Krull dimension](wikipedia://en/56079) of *A*. This theorem opened the door to application of homological methods to commutative algebra.
