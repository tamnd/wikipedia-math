# Portable, Extensible Toolkit for Scientific Computation

::: {#o2 .subject cue=lead name="Portable, Extensible Toolkit for Scientific Computation"}

The **Portable, Extensible Toolkit for Scientific Computation** (**PETSc**, pronounced PET-see; the S is silent), is a suite of [data structures](https://en.wikipedia.org/wiki/Data_structures) and [routines](https://en.wikipedia.org/wiki/Source_code) developed by [Argonne National Laboratory](https://en.wikipedia.org/wiki/Argonne_National_Laboratory) for the [scalable](https://en.wikipedia.org/wiki/Scalability) ([parallel](https://en.wikipedia.org/wiki/Parallel_computing)) solution of [scientific applications](https://en.wikipedia.org/wiki/Scientific_computing) modeled by [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations). It employs the [Message Passing Interface](https://en.wikipedia.org/wiki/Message_Passing_Interface) (MPI) standard for all message-passing communication. PETSc is the world’s most widely used parallel numerical software library for [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations) and [sparse matrix](wikipedia://en/341015) computations. PETSc received an R&D 100 Award in 2009.[^o3][^o4][^o5] The PETSc Core Development Group won the SIAM/ACM Prize in Computational Science and Engineering for 2015.[^o6]

:::

PETSc is intended for use in [large-scale](https://en.wikipedia.org/wiki/Scale_%28computing%29) application projects, many ongoing computational science projects are built around the PETSc [libraries](https://en.wikipedia.org/wiki/Library_%28computer_science%29). Its careful design allows advanced users to have detailed control over the solution process. PETSc includes a large suite of parallel [linear](wikipedia://en/18422) and [nonlinear](https://en.wikipedia.org/wiki/Nonlinearity) [equation solvers](wikipedia://en/113087) that are easily used in application codes written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), [C++](https://en.wikipedia.org/wiki/C++), [Fortran](https://en.wikipedia.org/wiki/Fortran) and now [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29). PETSc provides many of the mechanisms needed within parallel application code, such as simple parallel [matrix](wikipedia://en/20556859) and [vector](wikipedia://en/32370) assembly routines that allow the overlap of [communication](https://en.wikipedia.org/wiki/Computer_networking) and [computation](wikipedia://en/5926). In addition, PETSc includes support for parallel distributed [arrays](https://en.wikipedia.org/wiki/Array_data_structure) useful for [finite difference](wikipedia://en/39147) methods.[^o7]

## Components {#Components}

*Image: Library structure.svg.* Components of the PETSc software package as of version 3.15

PETSc consists of a variety of components consisting of major [classes](https://en.wikipedia.org/wiki/Class_%28computer_science%29) and supporting infrastructure. Users typically interact with [objects](https://en.wikipedia.org/wiki/Object_%28computer_science%29) of the highest level classes relevant to their application, essential lower level objects such as vectors, and may customize or extend any others. All major components of PETSc have an extensible plugin architecture.

## Features and modules {#Features_and_modules}

**PETSc** provides many features for parallel computation, broken into several modules:

- Index sets, including [permutations](https://en.wikipedia.org/wiki/Permutations), for [indexing](https://en.wikipedia.org/wiki/Index_mapping) into vectors, renumbering, etc.
- Parallel [vectors](https://en.wikipedia.org/wiki/Vector_%28geometric%29); and [matrices](wikipedia://en/20556859) (generally [sparse](wikipedia://en/341015))
- [Scatters](https://en.wikipedia.org/wiki/Parallel_computing) (handles communicating ghost point information) and [gathers](https://en.wikipedia.org/wiki/Parallel_computing) (the opposite of scatters)
- Data management for parallel [structured](https://en.wikipedia.org/wiki/Structured_grid) and [unstructured meshes](wikipedia://en/3772072)
- Several [sparse](wikipedia://en/341015) [storage](https://en.wikipedia.org/wiki/Computer_storage) [formats](https://en.wikipedia.org/wiki/File_format)
- Scalable parallel [preconditioners](https://en.wikipedia.org/wiki/Preconditioning), including [multigrid](https://en.wikipedia.org/wiki/Multigrid) and sparse direct solvers
- [Krylov subspace](wikipedia://en/2542615) methods
- Parallel nonlinear solvers, such as [Newton's method](wikipedia://en/22145) and nonlinear GMRES
- Parallel [time-stepping](wikipedia://en/272829) ([ODE](wikipedia://en/32742753) and [DAE](https://en.wikipedia.org/wiki/Differential_algebraic_equation)) solvers
- Parallel [optimization](wikipedia://en/52033) solvers, such as [BFGS](wikipedia://en/1926409)
- Automatic profiling of [floating point](https://en.wikipedia.org/wiki/Floating_point) and [memory](https://en.wikipedia.org/wiki/Memory_%28computers%29) usage
- Consistent [interface](https://en.wikipedia.org/wiki/Interface_%28computer_science%29)
- Intensive error checking
- Portable to [UNIX](https://en.wikipedia.org/wiki/UNIX), [Mac OS X](https://en.wikipedia.org/wiki/Mac_OS_X), and [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows)
