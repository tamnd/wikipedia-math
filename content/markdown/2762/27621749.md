# Dijkstra

::: {#o3 .subject cue=lead name="Dijkstra"}

**Dijkstra** ( ) is a [Dutch](https://en.wikipedia.org/wiki/Dutch_language) family name of [West Frisian](https://en.wikipedia.org/wiki/West_Frisian_language) origin. It most commonly refers to:

:::

- [Edsger W. Dijkstra](https://en.wikipedia.org/wiki/Edsger_W._Dijkstra) (1930–2002), Dutch computer scientist
  - Named after him: [Dijkstra's algorithm](wikipedia://en/45809), [Dijkstra Prize](https://en.wikipedia.org/wiki/Dijkstra_Prize), [Dijkstra–Scholten algorithm](wikipedia://en/4032816)
