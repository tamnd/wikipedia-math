# D-interval hypergraph

::: {#o1 .subject cue=lead name="D-interval hypergraph"}

In [graph theory](wikipedia://en/12401), a **$d$-interval hypergraph** is a kind of a [hypergraph](wikipedia://en/232535) constructed using [intervals](wikipedia://en/49172) of [real lines](https://en.wikipedia.org/wiki/Real_line). The parameter $d$ is a [positive integer](https://en.wikipedia.org/wiki/Positive_integer). The *[vertices](wikipedia://en/638899)* of a $d$-interval hypergraph are the points of $d$ disjoint [lines](wikipedia://en/946975) (thus there are [uncountably many](https://en.wikipedia.org/wiki/Uncountably_many) vertices). The *edges* of the graph are $d$-[tuples](wikipedia://en/132729) of intervals, one interval in every real line.[^o2]

:::

The simplest case is $d = 1$. The vertex set of a 1-interval hypergraph is the set of real numbers; each edge in such a hypergraph is an interval of the real line. For example, the [set](wikipedia://en/26691) $\{ [-2, -1], [0, 5], [3, 7] \}$ defines a 1-interval hypergraph. Note the difference from an [interval graph](wikipedia://en/363423): in an interval graph, the vertices are the intervals (a [finite set](wikipedia://en/11742)); in a 1-interval hypergraph, the vertices are all points in the real line (an [uncountable set](wikipedia://en/32248)).

As another example, in a 2-interval hypergraph, the vertex set is the [disjoint union](wikipedia://en/188946) of two real lines, and each edge is a union of two intervals: one in line #1 and one in line #2.

The following two concepts are defined for $d$-interval hypergraphs just like for finite hypergraphs:

- A [*matching*](wikipedia://en/63030703) is a set of non-intersecting edges, i.e., a set of non-intersecting $d$-intervals. For example, in the 1-interval hypergraph $\{ [-2, -1], [0, 5], [3, 7] \},$ the set $\{ [-2, -1], [0, 5] \}$ is a matching of size 2, but the set $\{ [0, 5], [3, 7] \}$ is not a matching since its elements intersect. The largest matching size in $H$ is denoted by $\nu(H)$.
- A [*covering*](wikipedia://en/64318108) or a *transversal* is a set of vertices that intersects every edge, i.e., a set of points that intersects every $d$-interval. For example, in the 1-interval hypergraph $\{ [-2, -1], [0, 5], [3, 7] \},$ the set $\{-1.5, 4\}$ is a covering of size 2, but the set $\{-1.5, 1\}$ is not a covering since it does not intersect the edge $[3, 7]$. The smallest transversal size in $H$ is denoted by $\tau(H)$.

$\nu(H) \le \tau(H)$ is true for any hypergraph $H$.

[Tibor Gallai](wikipedia://en/1651618) proved that, in a 1-interval hypergraph, they are equal: $\tau(H) = \nu(H)$. This is analogous to [Kőnig's theorem](wikipedia://en/5465118) for [bipartite graphs](wikipedia://en/244431).

[Gabor Tardos](https://en.wikipedia.org/wiki/Gábor_Tardos)[^o2] proved that, in a 2-interval hypergraph, $\tau(H) \le 2\nu(H)$, and it is tight (i.e., every 2-interval hypergraph with a matching of size $m$, can be covered by $2m$ points).

Kaiser[^o3] proved that, in a $d$-interval hypergraph, $\tau(H) \le d(d - 1)\nu(H)$, and moreover, every $d$-interval hypergraph with a matching of size $m$, can be covered by at $d(d - 1)m$ points, $(d - 1)m$ points on each line.

Frick and Zerbib[^o4] proved a colorful ("[rainbow](wikipedia://en/42366612)") version of this theorem.
