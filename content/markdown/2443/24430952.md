# GrabCut

::: {#o1 .subject cue=lead name="GrabCut"}

**GrabCut** is an image [segmentation](https://en.wikipedia.org/wiki/Segmentation_%28image_processing%29) method based on [graph cuts](https://en.wikipedia.org/wiki/Graph_cuts_in_computer_vision).

:::

Starting with a user-specified [bounding box](https://en.wikipedia.org/wiki/Bounding_box) around the object to be segmented, the algorithm estimates the color distribution of the target object and that of the background using a [Gaussian mixture model](https://en.wikipedia.org/wiki/Gaussian_mixture_model). This is used to construct a [Markov random field](wikipedia://en/1323985) over the pixel labels, with an [energy function](https://en.wikipedia.org/wiki/Energy_function) that prefers connected regions having the same label, and running a graph cut based optimization to infer their values. As this estimate is likely to be more accurate than the original, taken from the bounding box, this two-step procedure is repeated until convergence.

Estimates can be further corrected by the user by pointing out misclassified regions and rerunning the optimization. The method also corrects the results to preserve edges.

There are several [open source](https://en.wikipedia.org/wiki/Open_source) implementations available including [OpenCV](https://en.wikipedia.org/wiki/OpenCV) (as of version 2.1).
