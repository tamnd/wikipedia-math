# Convolution random number generator

::: {#o1 .subject cue=lead name="Convolution random number generator"}

In [statistics](wikipedia://en/26685) and [computer software](https://en.wikipedia.org/wiki/Computer_software), a **convolution random number generator** is a [pseudo-random number sampling](https://en.wikipedia.org/wiki/Pseudo-random_number_sampling) method that can be used to generate [random variates](https://en.wikipedia.org/wiki/Random_variate) from certain classes of [probability distribution](wikipedia://en/23543). The particular advantage of this type of approach is that it allows advantage to be taken of existing software for generating random variates from other, usually non-uniform, distributions. However, faster algorithms may be obtainable for the same distributions by other more complicated approaches.[^o2]

:::

A number of distributions can be expressed in terms of the (possibly weighted) sum of two or more [random variables](wikipedia://en/25685) from other distributions. (The distribution of the sum is the [convolution](wikipedia://en/7519) of the distributions of the individual random variables).

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

Consider the problem of generating a random variable with an [Erlang distribution](wikipedia://en/199028), $X\ \sim \operatorname{Erlang}(k, \theta)$. Such a random variable can be defined as the sum of *k* random variables each with an [exponential distribution](wikipedia://en/45906) $\operatorname{Exp}(k \theta) \,$. This problem is equivalent to generating a random number for a special case of the [Gamma distribution](wikipedia://en/207079), in which the [shape parameter](wikipedia://en/9210865) takes an integer value.

Notice that:

$$\operatorname{E}[X] = \frac{1}{k \theta} + \frac{1}{k \theta} + \cdots + \frac{1}{k \theta} = \frac{1}{\theta} .$$

One can now generate $\operatorname{Erlang}(k, \theta)$ samples using a random number generator for the exponential distribution:

if $X_i\ \sim \operatorname{Exp}(k \theta)$ then $X=\sum_{i=1}^k X_i \sim \operatorname{Erlang}(k,\theta) .$

:::
