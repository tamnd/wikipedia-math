# M/M/∞ queue

::: {#o1 .subject cue=lead name="M/M/∞ queue"}

In [queueing theory](wikipedia://en/50578), a discipline within the mathematical [theory of probability](wikipedia://en/23542), the **M/M/∞ queue** is a multi-server [queueing model](https://en.wikipedia.org/wiki/Queueing_model) where every arrival experiences immediate service and does not wait.[^o2] In [Kendall's notation](wikipedia://en/7345405) it describes a system where arrivals are governed by a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process), there are infinitely many servers, so jobs do not need to wait for a server. Each job has an exponentially distributed service time. It is a limit of the [M/M/c queue](wikipedia://en/23152853) model where the number of servers *c* becomes very large.

:::

The model can be used to model bound [lazy deletion](https://en.wikipedia.org/wiki/Lazy_deletion) performance.[^o9]

## Model definition {#Model_definition}

An M/M/∞ queue is a [stochastic process](wikipedia://en/47895) whose [state space](https://en.wikipedia.org/wiki/State_space) is the set {0,1,2,3,...}, where the value corresponds to the number of customers currently being served. Since the number of servers in parallel is infinite, there is no queue and the number of customers in the systems coincides with the number of customers being served at any moment.

- Arrivals occur at rate *λ* according to a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) and move the process from state *i* to *i* + 1.
- Service times have an [exponential distribution](wikipedia://en/45906) with parameter *μ,* and there are always sufficient servers such that every arriving job is served immediately. Transitions from state *i* to *i* − 1 are at rate *iμ*

The model has transition rate matrix

$$Q=\begin{pmatrix} -\lambda & \lambda \\ \mu & -(\mu+\lambda) & \lambda \\ &2\mu & -(2\mu+\lambda) & \lambda \\ &&3\mu & -(3\mu+\lambda) & \lambda \\ &&&&\ddots \end{pmatrix}.$$

## Transient solution {#Transient_solution}

Assuming the system starts in state 0 at time 0, then the probability the system is in state *j* at time *t* can be written as[^o5]

$$p_{0j}(t) = \exp \left( -\frac{\lambda}{\mu}(1-e^{-\mu t}) \right) \frac{\left(\frac{\lambda}{\mu}(1-e^{-\mu t})\right)^j}{j!} \text{ for } j \geq 0$$

from which the mean queue length at time *t* can be computed (writing *N*(*t*) for the number of customers in the system at time *t* given the system is empty at time zero)

$$\mathbb E(N(t) | N(0)=0) = \frac{\lambda}{\mu} (1-e^{-\mu t}) \text{ for } t \geq 0.$$

### Response time {#Response_time}

The response time for each arriving job is a single exponential distribution with parameter *μ*. The average response time is therefore 1/*μ*.[^o7]

### Maximum number of customers in the system {#Maximum_number_of_customers_in_the_system}

Given the system is in equilibrium at time 0, we can compute the [cumulative distribution function](wikipedia://en/5793) of the process maximum over a finite time horizon *T* in terms of [Charlier polynomials](wikipedia://en/19585960).[^o9]

### Congestion period {#Congestion_period}

The congestion period is the length of time the process spends above a fixed level *c*, where timing is started from the instant the process transitions to state *c* + 1. This period has [mean value](https://en.wikipedia.org/wiki/Mean_value)[^o11]

$$\frac{1}{\lambda}\sum_{i>c} \frac{c!}{i!}\left( \frac{\lambda}{\mu} \right)^{i-c}$$

and the Laplace transform can be expressed in terms of [Kummer's function](wikipedia://en/1516033).[^o12]

## Stationary analysis {#Stationary_analysis}

The stationary probability mass function is a [Poisson distribution](wikipedia://en/23009144)[^o14]

$$\pi_k = \frac{(\lambda/\mu)^k e^{-\lambda/\mu}}{k!} \quad k \geq 0$$

so the mean number of jobs in the system is *λ*/*μ*.

The stationary distribution of the M/G/∞ queue is the same as that of the M/M/∞ queue.[^o15]

## Heavy traffic {#Heavy_traffic}

Writing *N*<sub>*t*</sub> for the number of customers in the system at time t as ρ → ∞ the scaled process

$$X_t = \frac{N_t - \lambda/\mu}{\sqrt{\lambda/\mu}}$$

converges to an [Ornstein–Uhlenbeck process](wikipedia://en/2183186) with [normal distribution](wikipedia://en/21462) and correlation parameter 1, defined by the [Itō calculus](https://en.wikipedia.org/wiki/Itō_calculus) as[^o11][^o17]

$$dX_t = -Xdt+\sqrt{2}dW_t$$

where *W* is a [standard Brownian motion](https://en.wikipedia.org/wiki/Standard_Brownian_motion).
