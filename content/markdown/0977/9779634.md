# Up (game theory)

::: {#o1 .subject cue=lead name="Up"}

In [combinatorial game theory](wikipedia://en/292231), **up**, written as $\uparrow$, is the value of the game where Left can only move to a [zero game](https://en.wikipedia.org/wiki/Zero_game), while Right can only move to a [star game](wikipedia://en/650789). It is greater than [zero](wikipedia://en/34513) and less than all [positive numbers](wikipedia://en/47172571), hence it is an [infinitesimal](wikipedia://en/160990). $\uparrow$ may be represented by the [surreal form](wikipedia://en/51432)

$$\uparrow=\{0\mid* \}.$$

Because $\uparrow>0$, Left always wins a game with value $\uparrow$. Its [additive inverse](wikipedia://en/228312), down, written as $\downarrow$, may be represented as

$$\downarrow=\{*\mid 0\}.$$

Similarly, $\downarrow$ is less than zero and greater than all [negative numbers](wikipedia://en/154616).

:::

$\uparrow$ and $\downarrow$ are equivalent to $+_0$ and $-_0$, [tiny-0 and miny-0](wikipedia://en/22537688).[^o2]

## Value-$\uparrow$ games {#Value-\uparrow_games}

### Hackenbush {#Hackenbush}

*Image: Blue Flower in Hackenbush.png.* A 1-petaled blue flower, often called a delphinium. It has value $\uparrow+*$.

In [Hackenbush](wikipedia://en/1613052), a 1-petaled delphinium, that is, a blue edge on top of a green edge, has value $\{0,*\mid0 \}=\uparrow+*$.[^o5] Hence, a green edge along with a 1-petaled delphinium has value $\uparrow+*+*=\uparrow$.

### Col {#Col}

Because a [Col](https://en.wikipedia.org/wiki/Col_%28game%29) position can have only values $z$ or $z+*$ for some number $z$,[^o5] no Col position can have value $\uparrow$.

### Toads and Frogs {#Toads_and_Frogs}

In [Toads and Frogs](wikipedia://en/21795379), $\uparrow$ may be represented by the position[^o5]

$$T\square TFF=\{\square TTFF\mid TFT\square F\}=\{0\mid\{TF\square TF\mid TFTF\square\}\}=\{0\mid\{0\mid0\}\}=\uparrow .$$

## Confusion with nimbers {#Confusion_with_nimbers}

The only [nimber](wikipedia://en/164501) confused with $\uparrow$ is $*$. This is easily illustrated by the Hackenbush example, as a blue delphinium and a green edge along with a $*2$ position is not [fuzzy](https://en.wikipedia.org/wiki/Fuzzy_game).[^o2][^o5]
