# Regulated function

::: {#o1 .subject cue=lead name="Regulated function"}

In [mathematics](wikipedia://en/18831), a **regulated function**, or **ruled function**, is a certain kind of well-behaved [function](wikipedia://en/185427) of a single [real](wikipedia://en/20646438) variable. Regulated functions arise as a class of [integrable functions](https://en.wikipedia.org/wiki/Integration_%28mathematics%29), and have several equivalent characterisations. Regulated functions were introduced by [Nicolas Bourbaki](wikipedia://en/167394) in 1949, in their book "Livre IV: Fonctions d'une variable réelle".

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* be a [Banach space](wikipedia://en/3989) with norm || - ||<sub>*X*</sub>. A function *f* : \[0, *T*\] → *X* is said to be a **regulated function** if one (and hence both) of the following two equivalent conditions holds true:[^o4]

- for every *t* in the [interval](wikipedia://en/49172) \[0, *T*\], both the [left and right limits](wikipedia://en/285759) *f*(*t*−) and *f*(*t*+) exist in *X* (apart from, obviously, *f*(0−) and *f*(*T*+));
- there exists a [sequence](https://en.wikipedia.org/wiki/Sequence_%28mathematics%29) of [step functions](wikipedia://en/170939) *φ*<sub>*n*</sub> : \[0, *T*\] → *X* [converging uniformly](wikipedia://en/50652) to *f* (i.e. with respect to the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm) || - ||<sub>∞</sub>).

For this equivalence to hold, the definition of "step function" must be the one that allows degenerate intervals (i.e., singletons).

It requires a little work to show that these two conditions are equivalent. However, it is relatively easy to see that the second condition may be re-stated in the following equivalent ways:

- for every *δ* > 0, there is some step function *φ*<sub>*δ*</sub> : \[0, *T*\] → *X* such that

$$\| f - \varphi_\delta \|_\infty = \sup_{t \in [0, T]} \| f(t) - \varphi_\delta (t) \|_X < \delta;$$

- *f* lies in the [closure](wikipedia://en/47279) of the space Step(\[0, *T*\]; *X*) of all step functions from \[0, *T*\] into *X* (taking closure with respect to the supremum norm in the space B(\[0, *T*\]; *X*) of all bounded functions from \[0, *T*\] into *X*).

:::

## Properties of regulated functions {#Properties_of_regulated_functions}

Let Reg(\[0, *T*\]; *X*) denote the [set](wikipedia://en/26691) of all regulated functions *f* : \[0, *T*\] → *X*.

- Sums and scalar multiples of regulated functions are again regulated functions. In other words, Reg(\[0, *T*\]; *X*) is a [vector space](wikipedia://en/32370) over the same [field](wikipedia://en/10603) **K** as the space *X*; typically, **K** will be the [real](wikipedia://en/20646438) or [complex numbers](wikipedia://en/5826). If *X* is equipped with an operation of multiplication, then products of regulated functions are again regulated functions. In other words, if *X* is a **K**-[algebra](wikipedia://en/191788), then so is Reg(\[0, *T*\]; *X*).
- The supremum norm is a [norm](wikipedia://en/990534) on Reg(\[0, *T*\]; *X*), and Reg(\[0, *T*\]; *X*) is a [topological vector space](wikipedia://en/45752) with respect to the topology induced by the supremum norm.
- As noted above, Reg(\[0, *T*\]; *X*) is the closure in B(\[0, *T*\]; *X*) of Step(\[0, *T*\]; *X*) with respect to the supremum norm.
- If *X* is a [Banach space](wikipedia://en/3989), then Reg(\[0, *T*\]; *X*) is also a Banach space with respect to the supremum norm.
- Reg(\[0, *T*\]; **R**) forms an infinite-dimensional real [Banach algebra](wikipedia://en/4665): finite linear combinations and products of regulated functions are again regulated functions.
- Since a [continuous function](wikipedia://en/6122) defined on a [compact space](wikipedia://en/6042) (such as \[0, *T*\]) is automatically [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous_function), every continuous function *f* : \[0, *T*\] → *X* is also regulated. In fact, with respect to the supremum norm, the space *C*<sup>0</sup>(\[0, *T*\]; *X*) of continuous functions is a [closed](wikipedia://en/47279) [linear subspace](wikipedia://en/56357) of Reg(\[0, *T*\]; *X*).
- If *X* is a [Banach space](wikipedia://en/3989), then the space BV(\[0, *T*\]; *X*) of functions of [bounded variation](wikipedia://en/330673) forms a [dense](wikipedia://en/23523594) linear subspace of Reg(\[0, *T*\]; *X*):

$$\mathrm{Reg}([0, T]; X) = \overline{\mathrm{BV} ([0, T]; X)} \mbox{ w.r.t. } \| \cdot \|_{\infty}.$$

- If *X* is a Banach space, then a function *f* : \[0, *T*\] → *X* is regulated [if and only if](wikipedia://en/14922) it is of [bounded *φ*-variation](wikipedia://en/330673#Weighted_BV_functions) for some *φ*:

$$\mathrm{Reg}([0, T]; X) = \bigcup_{\varphi} \mathrm{BV}_{\varphi} ([0, T]; X).$$

- If *X* is a [separable](wikipedia://en/27855) [Hilbert space](wikipedia://en/20598932), then Reg(\[0, *T*\]; *X*) satisfies a compactness theorem known as the [Fraňková–Helly selection theorem](wikipedia://en/9775880).
- The set of [discontinuities](https://en.wikipedia.org/wiki/Discontinuity_%28mathematics%29) of a regulated function of [bounded variation](wikipedia://en/330673) BV is [countable](https://en.wikipedia.org/wiki/Countable) for such functions have only jump-type of discontinuities. To see this it is sufficient to note that given $\epsilon > 0$, the set of points at which the right and left limits differ by more than $\epsilon$ is finite. In particular, the discontinuity set has [measure zero](https://en.wikipedia.org/wiki/Measure_zero), from which it follows that a regulated function has a well-defined [Riemann integral](wikipedia://en/26390).
- Remark: By the [Baire category theorem](wikipedia://en/55227) the set of points of discontinuity of such function $F_\sigma$ is either meager or else has nonempty interior. This is not always equivalent with countability.[^o6]
- The integral, as defined on step functions in the obvious way, extends naturally to Reg(\[0, *T*\]; *X*) by defining the integral of a regulated function to be the limit of the integrals of any sequence of step functions converging uniformly to it. This extension is [well-defined](https://en.wikipedia.org/wiki/Well-defined) and satisfies all of the usual properties of an integral. In particular, the [regulated integral](wikipedia://en/6818116)
  - is a [bounded linear function](https://en.wikipedia.org/wiki/Bounded_linear_function) from Reg(\[0, *T*\]; *X*) to *X*; hence, in the case *X* = **R**, the integral is an element of the [space that is dual](https://en.wikipedia.org/wiki/Continuous_dual_space) to Reg(\[0, *T*\]; **R**);
  - agrees with the [Riemann integral](wikipedia://en/26390).
