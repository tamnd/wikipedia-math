# Analytic semigroup

::: {#o1 .subject cue=lead name="Analytic semigroup"}

In [mathematics](wikipedia://en/18831), an **analytic semigroup** is particular kind of [strongly continuous semigroup](https://en.wikipedia.org/wiki/C0_semigroup). Analytic semigroups are used in the solution of [partial differential equations](wikipedia://en/52564); compared to strongly continuous semigroups, analytic semigroups provide better [regularity](https://en.wikipedia.org/wiki/Smooth_function) of solutions to [initial value problems](wikipedia://en/498383), better results concerning perturbations of the [infinitesimal generator](https://en.wikipedia.org/wiki/C0_semigroup#Infinitesimal_generator), and a relationship between the type of the semigroup and the [spectrum](wikipedia://en/206137) of the infinitesimal generator.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let Γ(*t*) = exp(*At*) be a strongly continuous one-parameter semigroup on a [Banach space](wikipedia://en/3989) (*X*, ||·||) with infinitesimal generator *A*. Γ is said to be an **analytic semigroup** if

- for some 0 \< *θ* \< π/2, the [continuous linear operator](wikipedia://en/1802169) exp(*At*) : *X* → *X* can be extended to *t* ∈ Δ<sub>*θ*</sub>,

$$\Delta_{\theta} = \{ 0 \} \cup \{ t \in \mathbb{C} : | \mathrm{arg}(t) | < \theta \},$$

and the usual semigroup conditions hold for *s*, *t* ∈ Δ<sub>*θ*</sub>: exp(*A*0) = id, exp(*A*(*t* + *s*)) = exp(*At*) exp(*As*), and, for each *x* ∈ *X*, exp(*At*)*x* is [continuous](wikipedia://en/6122) in *t*;

- and, for all *t* ∈ Δ<sub>*θ*</sub> \\ {0}, exp(*At*) is [analytic](wikipedia://en/61478) in *t* in the sense of the [uniform operator topology](wikipedia://en/50652).

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Characterization"}

## Characterization {#Characterization}

The infinitesimal generators of analytic semigroups have the following characterization:

A [closed](https://en.wikipedia.org/wiki/Closed_operator), [densely defined](wikipedia://en/23523594) [linear operator](https://en.wikipedia.org/wiki/Linear_operator) *A* on a Banach space *X* is the generator of an analytic semigroup [if and only if](wikipedia://en/14922) there exists an *ω* ∈ **R** such that the [half-plane](https://en.wikipedia.org/wiki/Half-plane) Re(*λ*) > *ω* is contained in the [resolvent set](wikipedia://en/8721698) of *A* and, moreover, there is a constant *C* such that for the [resolvent](wikipedia://en/3378540) $R_\lambda(A)$ of the operator *A* we have

$$\| R_{\lambda} (A) \| \leq \frac{C}{| \lambda - \omega |}$$

for Re(*λ*) > *ω*. Such operators are called *[sectorial](wikipedia://en/73278652)*. If this is the case, then the resolvent set actually contains a sector of the form

$$\left\{ \lambda \in \mathbf{C} : | \mathrm{arg} (\lambda - \omega) | < \frac{\pi}{2} + \delta \right\}$$

for some *δ* > 0, and an analogous resolvent estimate holds in this sector. Moreover, the semigroup is represented by

$$\exp (At) = \frac1{2 \pi i} \int_{\gamma} e^{\lambda t} ( \lambda \mathrm{id} - A )^{-1} \, \mathrm{d} \lambda,$$

where *γ* is any curve from *e*<sup>−*iθ*</sup>∞ to *e*<sup>\+*iθ*</sup>∞ such that *γ* lies entirely in the sector

$$\big\{ \lambda \in \mathbf{C} : | \mathrm{arg} (\lambda - \omega) | \leq \theta \big\},$$

with π/2 \< *θ* \< π/2 + *δ*.

:::
