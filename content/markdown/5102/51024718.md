# Thurston norm

::: {#o1 .subject cue=lead name="Thurston norm"}

In mathematics, the **Thurston norm** is a function on the second [homology group](https://en.wikipedia.org/wiki/Homology_group) of an oriented [3-manifold](wikipedia://en/1018257) introduced by [William Thurston](wikipedia://en/39190), which measures in a natural way the topological complexity of homology classes represented by surfaces.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $M$ be a [differentiable manifold](wikipedia://en/2119219) and $c \in H_2(M)$. Then $c$ can be represented by a smooth [embedding](wikipedia://en/52119) $S \to M$, where $S$ is a (not necessarily connected) [surface](wikipedia://en/27865) that is [compact](wikipedia://en/6042) and without boundary. The Thurston norm of $c$ is then defined to be[^n1]

$$\|c\|_T = \min_{S} \sum_{i=1}^n \chi_-(S_i),$$

where the minimum is taken over all embedded surfaces $S = \bigcup_i S_i$ (the $S_i$ being the connected components) representing $c$ as above, and $\chi_-(F) = \max(0, -\chi(F))$ is the absolute value of the [Euler characteristic](wikipedia://en/148420) for surfaces which are not spheres (and 0 for spheres).

This function satisfies the following properties:

- $\| kc \|_T = |k| \cdot \| c \|_T$ for $c \in H_2(M), k \in \mathbb{Z}$;
- $\| c_1 + c_2 \|_T \le \| c_1 \|_T + \| c_2 \|_T$ for $c_1, c_2 \in H_2(M)$.

These properties imply that $\| \cdot \|$ extends to a function on $H_2(M, \mathbb{Q})$ which can then be extended by continuity to a [seminorm](wikipedia://en/990534) $\| \cdot \|_T$ on $H_2(M,\mathbb{R})$.[^n2] By [Poincaré duality](wikipedia://en/540732), one can define the Thurston norm on $H^1(M, \mathbb{R})$.

When $M$ is compact with boundary, the Thurston norm is defined in a similar manner on the [relative homology](wikipedia://en/1248647) group $H_2(M, \partial M, \mathbb{R})$ and its Poincaré dual $H^1(M,\mathbb{R})$.

It follows from further work of [David Gabai](wikipedia://en/6129609)[^n3] that one can also define the Thurston norm using only [immersed](wikipedia://en/6993953) surfaces. This implies that the Thurston norm is also equal to half the [Gromov norm](https://en.wikipedia.org/wiki/Gromov_norm) on homology.

:::

## Topological applications {#Topological_applications}

The Thurston norm was introduced in view of its applications to [fiberings](wikipedia://en/276526) and [foliations](wikipedia://en/371227) of 3-manifolds.

The unit ball $B$ of the Thurston norm of a 3-manifold $M$ is a [polytope](wikipedia://en/23471) with integer vertices. It can be used to describe the structure of the set of fiberings of $M$ over the circle: if $M$ can be written as the [mapping torus](wikipedia://en/21034384) of a diffeomorphism $f$ of a surface $S$ then the embedding $S \hookrightarrow M$ represents a class in a top-dimensional (or open) face of $B$: moreover all other integer points on the same face are also fibers in such a fibration.[^n4]

Embedded surfaces which minimise the Thurston norm in their homology class are exactly the closed leaves of foliations of $M$.[^n3]
