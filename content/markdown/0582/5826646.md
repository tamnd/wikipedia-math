# Capable group

::: {#o1 .subject cue=lead name="Capable group"}

In [mathematics](wikipedia://en/18831), in the realm of [group theory](wikipedia://en/41890), a [group](wikipedia://en/19447) is said to be **capable** if it is isomorphic to the quotient $G / Z(G)$ of some group $G$ by its [center](wikipedia://en/7125).

:::

These groups were first studied by [Reinhold Baer](wikipedia://en/1612114), who showed that a [finite](wikipedia://en/323707) [abelian group](wikipedia://en/2974) is capable if and only if it is a [product](wikipedia://en/3706015) of [cyclic groups](wikipedia://en/52327) of [orders](https://en.wikipedia.org/wiki/Order_of_a_group) *n*<sub>1</sub>, ..., *n*<sub>*k*</sub> where *n*<sub>*i*</sub> [divides](wikipedia://en/49492) *n*<sub>*i*+1</sub> and *n*<sub>*k*−1</sub> = *n*<sub>*k*</sub>.

An equivalent condition for a group to be capable is if it occurs as the [inner automorphism](wikipedia://en/61839) group of some group. To see this, note that the canonical surjective map $G \to \operatorname{Inn}(G)$ has kernel $Z(G)$; by the [first isomorphism theorem](https://en.wikipedia.org/wiki/First_Isomorphism_Theorem), $G / Z(G)$ is equivalent to $\operatorname{Inn}(G)$.
