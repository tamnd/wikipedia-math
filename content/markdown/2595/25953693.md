# Brown–Gibson model

::: {#o1 .subject cue=lead name="Brown–Gibson model"}

The **Brown–Gibson model** is one of the many techniques for [multi-attribute decision making](https://en.wikipedia.org/wiki/Multi-criteria_decision_analysis). The method was developed in 1972 by P. Brown and D. Gibson.[^o2] This is one of the few models which integrates both [objective](https://en.wikipedia.org/wiki/Objectivity_%28science%29) and [subjective](https://en.wikipedia.org/wiki/Subjectivity) factors in [decision making](https://en.wikipedia.org/wiki/Decision_making).

:::

The Brown–Gibson model can be [mathematically](wikipedia://en/18831) represented as follows:

$$M_i = C_i \cdot \big[ D \cdot O_i + (1 - D) S_i \big]$$

where

*M*<sub>*i*</sub> = measure for an alternative *i*

*C*<sub>*i*</sub> = critical [factor](wikipedia://en/9541) measure, which could be either 0 or 1 for an alternative *i*

*O* = [objective factor](https://en.wikipedia.org/wiki/Objectivity_%28philosophy%29) measure, which could be between 0 and 1; however, the sum of all objective factor measures for different alternatives should add back to 1

*S* = [subjective factor](https://en.wikipedia.org/wiki/Subject_%28philosophy%29) measure, which could be between 0 and 1; however, the sum of all subjective factor measures for different alternatives should add back to 1

*D* = objective factor decision weight; should be between 0 and 1

One would select the alternative whose measure is the highest.
