# Probabilistic relevance model

::: {#o1 .subject cue=lead name="Probabilistic relevance model"}

The **probabilistic relevance model**[^o2][^o3] was devised by [Stephen E. Robertson](https://en.wikipedia.org/wiki/Stephen_Robertson_%28computer_scientist%29) and [Karen Spärck Jones](https://en.wikipedia.org/wiki/Karen_Spärck_Jones) as a framework for [probabilistic models](wikipedia://en/27576) to come. It is a formalism of [information retrieval](https://en.wikipedia.org/wiki/Information_retrieval) useful to derive [ranking functions](https://en.wikipedia.org/wiki/Ranking_function) used by [search engines](https://en.wikipedia.org/wiki/Search_engine) and [web search engines](https://en.wikipedia.org/wiki/Web_search_engine) in order to rank matching documents according to their [relevance](https://en.wikipedia.org/wiki/Relevance_%28information_retrieval%29) to a given search query.

:::

It is a theoretical model estimating the probability that a document *d<sub>j</sub>* is relevant to a query *q*. The model assumes that this probability of relevance depends on the query and document representations. Furthermore, it assumes that there is a portion of all documents that is preferred by the user as the answer set for query *q*. Such an ideal answer set is called *R* and should maximize the overall probability of relevance to that user. The prediction is that documents in this set *R* are relevant to the query, while documents not present in the set are non-relevant.

$$sim(d_{j},q) = \frac{P(R|\vec{d}_j)}{P(\bar{R}|\vec{d}_j)}$$

## Related models {#Related_models}

There are some limitations to this framework that need to be addressed by further development:

- There is no accurate estimate for the first run probabilities
- Index terms are not weighted
- Terms are assumed mutually independent

To address these and other concerns, other models have been developed from the probabilistic relevance framework, among them the [Binary Independence Model](https://en.wikipedia.org/wiki/Binary_Independence_Model) from the same author. The best-known derivatives of this framework are the [Okapi (BM25)](https://en.wikipedia.org/wiki/Probabilistic_relevance_model_%28BM25%29) weighting scheme and its multifield refinement, BM25F.
