# Differential algebraic group

::: {#o1 .subject cue=lead name="Differential algebraic group"}

In [mathematics](wikipedia://en/18831), a **differential algebraic group** is a [differential algebraic variety](https://en.wikipedia.org/wiki/Differential_algebraic_variety) with a compatible [group](wikipedia://en/19447) structure. Differential algebraic groups were introduced by (Cassidy 1972).

:::
