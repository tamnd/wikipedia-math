# List of numerical-analysis software

::: {#o1 .subject cue=lead name="List of numerical-analysis software"}

Listed here are notable end-user computer applications intended for use with [numerical](wikipedia://en/21506) or [data analysis](wikipedia://en/2720954):

:::

## Numerical-software packages {#Numerical-software_packages}

::: {#o3 .entry cue=list-entry name="Analytica"}

- [Analytica](https://en.wikipedia.org/wiki/Analytica_%28software%29) is a widely used [proprietary software](https://en.wikipedia.org/wiki/Proprietary_software) tool for building and analyzing numerical models. It is a [declarative](https://en.wikipedia.org/wiki/Declarative_programming) and [visual programming language](https://en.wikipedia.org/wiki/Visual_programming_language) based on [influence diagrams](wikipedia://en/1194259).

:::

::: {#o4 .entry cue=list-entry name="FlexPro"}

- [FlexPro](https://en.wikipedia.org/wiki/FlexPro) is a program to analyze and present measurement data. It has a rich Excel-like user interface and a built-in vector programming language [FPScript](https://en.wikipedia.org/wiki/FPScript) has a syntax similar to [MATLAB](wikipedia://en/20412).

:::

::: {#o5 .entry cue=list-entry name="FreeMat"}

- [FreeMat](https://en.wikipedia.org/wiki/FreeMat), an [open-source](https://en.wikipedia.org/wiki/Open-source_software) MATLAB-like environment with a [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License) (GPL).

:::

::: {#o6 .entry cue=list-entry name="GNU Octave"}

- [GNU Octave](wikipedia://en/48707) is a [high-level programming language](https://en.wikipedia.org/wiki/High-level_programming_language), intended for mainly numerical computing. It has a convenient [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface) to solve linear and nonlinear problems numerically, and to perform other numerical experiments using a language that is compatible mostly with MATLAB. The 4.0 and newer releases of Octave include a GUI. Several independently developed [Linux](https://en.wikipedia.org/wiki/Linux) programs ([Cantor](https://en.wikipedia.org/wiki/Cantor_%28mathematics_software%29), [KAlgebra](https://en.wikipedia.org/wiki/KAlgebra)) also offer GUI front-ends to Octave. An active community provides technical support to users.

:::

::: {#o7 .entry cue=list-entry name="GroovyLab"}

- [GroovyLab](https://en.wikipedia.org/wiki/GroovyLab) (formerly jLab), a research platform to build an open-source MATLAB-like environment in pure [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) and [Groovy](https://en.wikipedia.org/wiki/Groovy_%28programming_language%29). Supports interpreted j-Scripts (MATLAB-like) and compiled GroovySci (extension to Groovy) scripts that give direct interfacing to Java code and scripting access to many popular Java scientific libraries (e.g., [Weka](https://en.wikipedia.org/wiki/Weka_%28machine_learning%29) and [JSci](https://en.wikipedia.org/wiki/JSci)) and application Wizards.

:::

::: {#o8 .entry cue=list-entry name="Igor Pro"}

- [Igor Pro](https://en.wikipedia.org/wiki/Igor_Pro) is proprietary software to perform complex numerical calculations, statistical analysis, and produce publication-quality graphics. It comes with its own programming language, in which numerical algorithms can be implemented.

:::

::: {#o9 .entry cue=list-entry name="Jacket"}

- [Jacket](https://en.wikipedia.org/wiki/Jacket_%28software%29), a proprietary GPU toolbox for MATLAB, enabling some computations to be offloaded to the GPU for acceleration and data visualization.

:::

::: {#o10 .entry cue=list-entry name="Julia"}

- [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29) is a high-level dynamic language with a surface similarity to MATLAB. Packages such as DataFrames.jl are available.

:::

::: {#o11 .entry cue=list-entry name="LabVIEW"}

- [LabVIEW](https://en.wikipedia.org/wiki/LabVIEW) offers both textual and [graphical-programming](https://en.wikipedia.org/wiki/Graphical_programming) approaches to numerical analysis. Its text-based programming language MathScript uses .m-file-script syntax providing some compatibility with [MATLAB](wikipedia://en/20412) and its clones.

:::

::: {#o12 .entry cue=list-entry name="LAPACK"}

- [LAPACK](wikipedia://en/1013768) has Fortran 90 routines for solving systems of simultaneous linear equations, least-squares solutions of linear systems of equations, eigenvalue problems, and singular value problems and the associated matrix factorizations (LU, Cholesky, QR, SVD, Schur, and generalized Schur).

:::

::: {#o13 .entry cue=list-entry name="MATLAB"}

- [MATLAB](wikipedia://en/20412) is a widely used proprietary software to perform numerical computations.[^o14][^o15][^o16] It comes with its own programming language, in which numerical algorithms can be implemented.

:::

::: {#o17 .entry cue=list-entry name="MCSim"}

- [MCSim](https://en.wikipedia.org/wiki/MCSim) a simulation and numerical integration package, with fast Monte Carlo and Markov chain Monte Carlo abilities.

:::

::: {#o18 .entry cue=list-entry name="ML.NET"}

- [ML.NET](https://en.wikipedia.org/wiki/ML.NET) is a [free software](https://en.wikipedia.org/wiki/Free_software) [machine learning](wikipedia://en/233488) [library](https://en.wikipedia.org/wiki/Library_%28computing%29) for the [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29) programming language.[^o19][^o20]

:::

::: {#o21 .entry cue=list-entry name="NAG Numerical Libraries"}

- [NAG Numerical Libraries](https://en.wikipedia.org/wiki/NAG_Numerical_Libraries) is an extensive software library of highly optimized numerical-analysis routines for various programming environments.

:::

::: {#o22 .entry cue=list-entry name="O-Matrix"}

- [O-Matrix](https://en.wikipedia.org/wiki/O-Matrix) is a proprietary licensed matrix programming language for mathematics, engineering, science, and financial analysis.

:::

::: {#o23 .entry cue=list-entry name="pandas"}

- [pandas](https://en.wikipedia.org/wiki/Pandas_%28software%29) is a [BSD-licensed](https://en.wikipedia.org/wiki/BSD_licenses) library providing data structures and data analysis tools for the Python programming language.

:::

::: {#o24 .entry cue=list-entry name="Perl Data Language"}

- [Perl Data Language](https://en.wikipedia.org/wiki/Perl_Data_Language) has large multidimensional arrays for the [Perl](https://en.wikipedia.org/wiki/Perl) programming language, and utilities for image processing and graphical plotting.

:::

::: {#o25 .entry cue=list-entry name="ScaLAPACK"}

- [ScaLAPACK](https://en.wikipedia.org/wiki/ScaLAPACK) is a library of high-performance linear algebra routines for parallel distributed-memory machines that features functionality similar to LAPACK (solvers for dense and banded linear systems, least-squares problems, eigenvalue problems, and singular-value problem).

:::

::: {#o26 .entry cue=list-entry name="Scilab"}

- [Scilab](https://en.wikipedia.org/wiki/Scilab) is advanced numerical analysis package similar to MATLAB or Octave.[^o27][^o28] Comes with a complete GUI and Xcos which is alternative to Simulink. ([free software](https://en.wikipedia.org/wiki/Free_software), [GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License)-compatible [CeCILL](https://en.wikipedia.org/wiki/CeCILL) license)

:::

::: {#o29 .entry cue=list-entry name="Sysquake"}

- [Sysquake](https://en.wikipedia.org/wiki/Sysquake) is a computing environment with [interactive](https://en.wikipedia.org/wiki/Interactive) graphics for mathematics, physics and engineering. Like other applications from [Calerga](https://en.wikipedia.org/wiki/Calerga), it is based on a MATLAB-compatible language.

:::

::: {#o30 .entry cue=list-entry name="TK Solver"}

- [TK Solver](https://en.wikipedia.org/wiki/TK_Solver) is a mathematical modeling and problem-solving software system based on a declarative, rule-based language, commercialized by Universal Technical Systems, Inc.

:::

::: {#o31 .entry cue=list-entry name="Torch"}

- [Torch](https://en.wikipedia.org/wiki/Torch_%28machine_learning%29) is a deep-learning library with support for manipulation, statistical analysis and presentation of Tensors.

:::

::: {#o32 .entry cue=list-entry name="XLfit"}

- [XLfit](wikipedia://en/21935905), A plugin to Excel for curve-fitting and statistical analysis.

:::

## General-purpose computer algebra systems {#General-purpose_computer_algebra_systems}

::: {#o34 .entry cue=list-entry name="Macsyma"}

- [Macsyma](https://en.wikipedia.org/wiki/Macsyma), a general-purpose computer algebra system, which has a free GPL-licensed version called [Maxima](https://en.wikipedia.org/wiki/Maxima_%28software%29).

:::

::: {#o35 .entry cue=list-entry name="Maple"}

- [Maple](https://en.wikipedia.org/wiki/Maple_%28software%29), a general-purpose commercial mathematics software package.

:::

::: {#o36 .entry cue=list-entry name="Mathcad"}

- [Mathcad](https://en.wikipedia.org/wiki/Mathcad) offers a [WYSIWYG](https://en.wikipedia.org/wiki/WYSIWYG) interface and the ability to generate publication-quality mathematical equations.

:::

::: {#o37 .entry cue=list-entry name="Mathematica"}

- [Mathematica](https://en.wikipedia.org/wiki/Mathematica) offers numerical evaluation, optimization and visualization of a very wide range of numerical functions. It also includes a programming language and computer algebra abilities.[^o38][^o39][^o40][^o41]

:::

::: {#o42 .entry cue=list-entry name="PARI/GP"}

- [PARI/GP](https://en.wikipedia.org/wiki/PARI/GP) is a widely used computer algebra system designed for fast computations in number theory (factorizations, algebraic number theory, elliptic curves...), but also contains a large number of other useful functions to compute with mathematical entities such as matrices, polynomials, power series, algebraic numbers etc., and a lot of transcendental functions. PARI is also available as a C library to allow for faster computations.

:::

::: {#o43 .entry cue=list-entry name="SageMath"}

- [SageMath](https://en.wikipedia.org/wiki/SageMath) is an open-source math software,[^o44] with a unified Python interface which is available as a text interface or a graphical web-based one. Includes interfaces for open-source and proprietary general purpose CAS, and other numerical analysis programs, like PARI/GP, GAP, gnuplot, Magma, and Maple.

:::

::: {#o45 .entry cue=list-entry name="Speakeasy"}

- [Speakeasy](https://en.wikipedia.org/wiki/Speakeasy_%28computational_environment%29) is an interactive numerical environment also featuring an interpreted programming language. Born in the mid '60s for matrix manipulation and still in continuous evolution, it pioneered the most common paradigms of this kind of tools, featuring dynamic typing of the structured data objects, dynamic allocation and garbage collection, operators overloading, dynamic linking of compiled or interpreted additional modules contributed by the community of the users and so on.

:::

::: {#o46 .entry cue=list-entry name="Trilinos"}

- [Trilinos](https://en.wikipedia.org/wiki/Trilinos) is a collection of [open-source](https://en.wikipedia.org/wiki/Open-source_software) [object-oriented](https://en.wikipedia.org/wiki/Object-oriented_programming) libraries for use in scientific and engineering applications. Trilinos is based on scalable, parallel linear-algebra algorithms.

:::

## Interface-oriented {#Interface-oriented}

::: {#o48 .entry cue=list-entry name="Baudline"}

- [Baudline](https://en.wikipedia.org/wiki/Baudline) is a time-frequency browser for numerical signals analysis and scientific visualization.

:::

::: {#o49 .entry cue=list-entry name="COMSOL Multiphysics"}

- [COMSOL Multiphysics](https://en.wikipedia.org/wiki/COMSOL_Multiphysics) is a finite-element analysis, solver and simulation software / FEA Software package for various physics and engineering applications, especially coupled phenomena, or multiphysics.

:::

::: {#o50 .entry cue=list-entry name="Dataplot"}

- [Dataplot](wikipedia://en/16025102) is provided by [NIST](https://en.wikipedia.org/wiki/NIST).

:::

::: {#o51 .entry cue=list-entry name="DADiSP"}

- [DADiSP](https://en.wikipedia.org/wiki/DADiSP) is a commercial program focused on [digital signal processing](https://en.wikipedia.org/wiki/Digital_signal_processing) (DSP) that combines the numerical ability of MATLAB with a [spreadsheet](https://en.wikipedia.org/wiki/Spreadsheet)-like interface.

:::

::: {#o52 .entry cue=list-entry name="Easy Java Simulations"}

- [Easy Java Simulations](https://en.wikipedia.org/wiki/Easy_Java_Simulations) (EJS) is an [open-source software](https://en.wikipedia.org/wiki/Open-source_software) tool, written in Java, for generating simulations.

:::

::: {#o53 .entry cue=list-entry name="Euler Mathematical Toolbox"}

- [Euler Mathematical Toolbox](https://en.wikipedia.org/wiki/Euler_Mathematical_Toolbox) is a powerful numerical laboratory with a programming language that can handle real, complex and interval numbers, vectors and matrices. It can produce 2D/3D plots.

:::

::: {#o54 .entry cue=list-entry name="FEATool Multiphysics"}

- [FEATool Multiphysics](https://en.wikipedia.org/wiki/FEATool_Multiphysics) is a [MATLAB](wikipedia://en/20412) GUI toolbox for finite element FEM and PDE multiphysics simulations.

:::

::: {#o55 .entry cue=list-entry name="FEniCS Project"}

- [FEniCS Project](https://en.wikipedia.org/wiki/FEniCS_Project) is a collection of project for automated solutions to [partial differential equations](wikipedia://en/52564) (PDEs).

:::

::: {#o56 .entry cue=list-entry name="Hermes"}

- [Hermes](https://en.wikipedia.org/wiki/Hermes_Project) is a [C++](https://en.wikipedia.org/wiki/C++) library of advanced adaptive finite element algorithms to solve [PDEs](https://en.wikipedia.org/wiki/Partial_differential_equations) and multiphysics coupled problems.

:::

::: {#o57 .entry cue=list-entry name="Fityk"}

- [Fityk](https://en.wikipedia.org/wiki/Fityk) is a curve fitting and data-analysis program. Primarily used for peak fitting and analyzing peak data.

:::

::: {#o58 .entry cue=list-entry name="FlexPro"}

- [FlexPro](https://en.wikipedia.org/wiki/FlexPro) is a commercial program for interactive and automated analysis and presentation of mainly measurement data. It supports many binary instrument data formats and has its own vectorized programming language.

:::

::: {#o59 .entry cue=list-entry name="IGOR Pro"}

- [IGOR Pro](https://en.wikipedia.org/wiki/IGOR_Pro), a software package with emphasis on time series, image analysis, and curve fitting. It comes with its own programming language and can be used interactively.

:::

::: {#o60 .entry cue=list-entry name="LabPlot"}

- [LabPlot](https://en.wikipedia.org/wiki/LabPlot) is a data analysis and visualization application built on the KDE Platform.

:::

::: {#o61 .entry cue=list-entry name="MFEM"}

- [MFEM](https://en.wikipedia.org/wiki/MFEM) is a free, lightweight, scalable C++ library for [finite element methods](wikipedia://en/18233581).

:::

::: {#o62 .entry cue=list-entry name="Origin"}

- [Origin](wikipedia://en/6375501), a software package that is widely used for making scientific graphs. It comes with its own C/C++ compiler that conforms quite closely to ANSI standard.

:::

::: {#o63 .entry cue=list-entry name="PAW"}

- [PAW](https://en.wikipedia.org/wiki/Physics_Analysis_Workstation) is a free [data analysis](wikipedia://en/2720954) package developed at [CERN](https://en.wikipedia.org/wiki/CERN).

:::

::: {#o64 .entry cue=list-entry name="SPSS"}

- [SPSS](wikipedia://en/179088),[^o65][^o66][^o67][^o68][^o69] an application for statistical analysis.

:::

::: {#o70 .entry cue=list-entry name="QtiPlot"}

- [QtiPlot](https://en.wikipedia.org/wiki/QtiPlot) is a data analysis and scientific visualisation program, similar to Origin.

:::

::: {#o71 .entry cue=list-entry name="ROOT"}

- [ROOT](https://en.wikipedia.org/wiki/ROOT) is a free object-oriented multi-purpose [data-analysis](wikipedia://en/2720954) package, developed at [CERN](https://en.wikipedia.org/wiki/CERN).

:::

::: {#o72 .entry cue=list-entry name="Salome"}

- [Salome](https://en.wikipedia.org/wiki/Salome_%28software%29) is a free software tool that is a generic platform for pre- and post-processing for numerical simulation.

:::

::: {#o73 .entry cue=list-entry name="Shogun"}

- [Shogun](https://en.wikipedia.org/wiki/Shogun_%28toolbox%29), an [open-source](https://en.wikipedia.org/wiki/Open-source_software) large-scale [machine learning](wikipedia://en/233488) toolbox that gives several SVM implementations (like libSVM, SVMlight) under a common framework and interfaces to MATLAB, Octave, Python, R

:::

::: {#o74 .entry cue=list-entry name="Waffles"}

- [Waffles](https://en.wikipedia.org/wiki/Waffles_%28machine_learning%29) is a free-software collection of command-line tools designed for scripting machine-learning operations in automated experiments and processes.

:::

::: {#o75 .entry cue=list-entry name="Weka"}

- [Weka](https://en.wikipedia.org/wiki/Weka_%28machine_learning%29) is a suite of [machine learning](wikipedia://en/233488) software written at the [University of Waikato](https://en.wikipedia.org/wiki/University_of_Waikato).

:::

## Language-oriented {#Language-oriented}

::: {#o77 .entry cue=list-entry name="acslX"}

- [acslX](https://en.wikipedia.org/wiki/Advanced_Continuous_Simulation_Language) is a software application for modeling and evaluating the performance of continuous systems described by time-dependent, nonlinear differential equations.

:::

::: {#o78 .entry cue=list-entry name="ADMB"}

- [ADMB](wikipedia://en/20527175) is a software suite for non-linear statistical modeling based on C++ which uses automatic differentiation.

:::

::: {#o79 .entry cue=list-entry name="AMPL"}

- [AMPL](https://en.wikipedia.org/wiki/AMPL) is a mathematical modeling language for describing and solving high complexity problems for large-scale optimization.

:::

::: {#o80 .entry cue=list-entry name="Calcpad"}

- [Calcpad](wikipedia://en/82056772) is an open-source [numerical software](https://en.wikipedia.org/wiki/Numerical_software) for engineering calculations. Supports numerical differentiation and integration, root and extrema finding, vector and matrix calculations.

:::

::: {#o81 .entry cue=list-entry name="Ch"}

- [Ch](https://en.wikipedia.org/wiki/Ch_%28computer_programming%29), a commercial C/C++-based interpreted language with computational array for scientific numerical computation and visualization.[^o82]

:::

::: {#o83 .entry cue=list-entry name="APMonitor"}

- [APMonitor](https://en.wikipedia.org/wiki/APMonitor): APMonitor is a mathematical modeling language for describing and solving representations of physical systems in the form of differential and algebraic equations.

:::

::: {#o84 .entry cue=list-entry name="Armadillo"}

- [Armadillo](https://en.wikipedia.org/wiki/Armadillo_%28C++_library%29) is C++ template library for linear algebra; includes various decompositions, factorisations, and statistics functions; its syntax (application programming interface ([API](https://en.wikipedia.org/wiki/API)) is similar to MATLAB.

:::

::: {#o85 .entry cue=list-entry name="Clojure"}

- [Clojure](https://en.wikipedia.org/wiki/Clojure) with numeric libraries Neanderthal, ClojureCUDA, and ClojureCL to call optimized matrix and linear algebra functions on CPU and GPU.

:::

::: {#o86 .entry cue=list-entry name="Julia"}

- [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29)[^o87][^o88] is designed for cloud parallel scientific computing in mind on [LLVM](https://en.wikipedia.org/wiki/LLVM)-based [just-in-time compilation](https://en.wikipedia.org/wiki/Just-in-time_compilation) (JIT) as a backend. Lightweight *green* threading (coroutines). Direct calls of C functions from code (no wrappers or special APIs needed), support for Unicode. Powerful shell-like abilities to manage other processes. [Lisp](https://en.wikipedia.org/wiki/Lisp_%28programming_language%29)-like macros and other metaprogramming facilities.

:::

::: {#o89 .entry cue=list-entry name="ELKI"}

- Environment for DeveLoping KDD-Applications Supported by Index-Structures ([ELKI](https://en.wikipedia.org/wiki/ELKI)) a [software framework](https://en.wikipedia.org/wiki/Software_framework) for developing [data mining](wikipedia://en/42253) algorithms in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29).

:::

::: {#o90 .entry cue=list-entry name="GAUSS"}

- [GAUSS](https://en.wikipedia.org/wiki/GAUSS), a matrix programming language for mathematics and statistics.

:::

::: {#o91 .entry cue=list-entry name="GNU Data Language"}

- [GNU Data Language](https://en.wikipedia.org/wiki/GNU_Data_Language), a free compiler designed as a drop-in replacement for IDL.

:::

::: {#o92 .entry cue=list-entry name="IDL"}

- [IDL](https://en.wikipedia.org/wiki/IDL_%28programming_language%29),[^o93] a commercial interpreted language based on FORTRAN with some vectorization. Widely used in the [solar physics](https://en.wikipedia.org/wiki/Solar_physics), [fusion power](https://en.wikipedia.org/wiki/Fusion_power), [atmospheric sciences](https://en.wikipedia.org/wiki/Atmospheric_science) and [medical](https://en.wikipedia.org/wiki/Medicine) communities. The [GNU Data Language](https://en.wikipedia.org/wiki/GNU_Data_Language) is a free alternative.

:::

::: {#o94 .entry cue=list-entry name="ILNumerics"}

- [ILNumerics](https://en.wikipedia.org/wiki/ILNumerics), a [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29) math library that brings numeric computing functions for science, engineering and financial analysis to the [.NET](https://en.wikipedia.org/wiki/.NET) framework.

:::

::: {#o95 .entry cue=list-entry name="Kinetic PreProcessor"}

- [Kinetic PreProcessor](https://en.wikipedia.org/wiki/Kinetic_PreProcessor) (KPP) generates [Fortran 90](https://en.wikipedia.org/wiki/Fortran#Fortran_90), [FORTRAN 77](https://en.wikipedia.org/wiki/Fortran#FORTRAN_77), [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), or [MATLAB](wikipedia://en/20412) code for the integration of [ordinary differential equations](wikipedia://en/272829) (ODEs) resulting from chemical reaction mechanisms.

:::

::: {#o96 .entry cue=list-entry name="Madagascar"}

- [Madagascar](https://en.wikipedia.org/wiki/Madagascar_%28software%29), an open-source software package for multidimensional data analysis and reproducible computational experiments.

:::

::: {#o97 .entry cue=list-entry name="Mlpack"}

- [mlpack](https://en.wikipedia.org/wiki/Mlpack) is an open-source library for machine learning, providing a simple and consistent API, while exploiting C++ language features to provide maximum performance and flexibility

:::

::: {#o98 .entry cue=list-entry name="NCAR Command Language"}

- [NCAR Command Language](https://en.wikipedia.org/wiki/NCAR_Command_Language) is an interpreted language designed specifically for scientific [data analysis](wikipedia://en/2720954) and visualization.

:::

::: {#o99 .entry cue=list-entry name="O-Matrix"}

- [O-Matrix](https://en.wikipedia.org/wiki/O-Matrix) - a matrix programming language for mathematics, engineering, science, and financial analysis.

:::

::: {#o100 .entry cue=list-entry name="OptimJ"}

- [OptimJ](https://en.wikipedia.org/wiki/OptimJ) is a mathematical Java-based modeling language for describing and solving high-complexity problems for large-scale optimization.

:::

::: {#o101 .entry cue=list-entry name="Perl Data Language"}

- [Perl Data Language](https://en.wikipedia.org/wiki/Perl_Data_Language),[^o102][^o103] also known as PDL, an array extension to [Perl](https://en.wikipedia.org/wiki/Perl) ver.5, used for data manipulation, statistics, numerical simulation and visualization.

:::

::: {#o104 .entry cue=list-entry name="Python"}

- [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29)[^o105][^o106] with well-known scientific computing packages: [NumPy](https://en.wikipedia.org/wiki/NumPy), [SymPy](https://en.wikipedia.org/wiki/SymPy) and [SciPy](https://en.wikipedia.org/wiki/SciPy).[^o107][^o108][^o109]

:::

::: {#o110 .entry cue=list-entry name="R"}

- [R](wikipedia://en/376707) is a widely used system with a focus on data manipulation and statistics which implements the [S](wikipedia://en/919313) language.[^o111] Many add-on packages are available ([free software](https://en.wikipedia.org/wiki/Free_software), [GNU](https://en.wikipedia.org/wiki/GNU) [GPL license](https://en.wikipedia.org/wiki/GNU_General_Public_License)).

:::

::: {#o112 .entry cue=list-entry name="SAS"}

- [SAS](wikipedia://en/990677),[^o113] a system of software products for statistics. It includes SAS/IML,[^o114] a matrix programming language.

:::

::: {#o115 .entry cue=list-entry name="Stata"}

- [Stata](wikipedia://en/1809002) is a general-purpose statistical software package for data manipulation, visualization, statistics, and automated reporting. It is used by researchers in many fields, including biomedicine, economics, epidemiology, and sociology.

:::

::: {#o116 .entry cue=list-entry name="VisSim"}

- [VisSim](https://en.wikipedia.org/wiki/VisSim) is a visual [block-diagram](https://en.wikipedia.org/wiki/Block_diagram) language for simulation of nonlinear dynamic systems and model-based embedded development. Its fast ODE engine supports real-time simulation of complex large-scale models. The highly efficient fixed-point code generator allows targeting of low-cost fixed-point embedded processors.

:::

::: {#o117 .entry cue=list-entry name="Wolfram Language"}

- [Wolfram Language](https://en.wikipedia.org/wiki/Wolfram_Language) which is used within many Wolfram technologies such as [Mathematica](https://en.wikipedia.org/wiki/Mathematica) and the Wolfram Cloud

:::

::: {#o118 .entry cue=list-entry name="World Programming System"}

- [World Programming System](wikipedia://en/9406780) (WPS), supports mixing [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [R](wikipedia://en/376707) and [SAS](wikipedia://en/19060492) [programming languages](wikipedia://en/23015) in a single-user program for statistical analysis and data manipulation

:::

::: {#o119 .entry cue=list-entry name="Yorick"}

- [Yorick](https://en.wikipedia.org/wiki/Yorick_%28programming_language%29) is an interpreted programming language designed for numerics, graph plotting and simulation.

:::

## Historically significant {#Historically_significant}

::: {#o121 .entry cue=list-entry name="Expensive Desk Calculator"}

- [Expensive Desk Calculator](https://en.wikipedia.org/wiki/Expensive_Desk_Calculator) written for the [TX-0](https://en.wikipedia.org/wiki/TX-0) and [PDP-1](https://en.wikipedia.org/wiki/PDP-1) in the late 1950s or early 1960s.
