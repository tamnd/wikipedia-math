# Integral operator

::: {#o1 .subject cue=lead name="Integral operator"}

An **integral operator** is an [operator](wikipedia://en/22213) that involves [integration](wikipedia://en/15532). Special instances are:

:::

- The operator of integration itself, denoted by the [integral symbol](wikipedia://en/3171907)
- [Integral linear operators](wikipedia://en/63688957), which are [linear operators](https://en.wikipedia.org/wiki/Linear_operator) induced by [bilinear forms](wikipedia://en/449477) involving integrals
- [Integral transforms](wikipedia://en/430912), which are maps between two [function spaces](wikipedia://en/340630), which involve integrals
