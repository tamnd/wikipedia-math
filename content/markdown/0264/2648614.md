# Superposition calculus

::: {#o1 .subject cue=lead name="Superposition calculus"}

The **superposition calculus** is a [calculus](wikipedia://en/396102) for [reasoning](wikipedia://en/2546) in [equational logic](wikipedia://en/33522862). It was developed in the early 1990s and combines concepts from [first-order resolution](https://en.wikipedia.org/wiki/First-order_resolution) with ordering-based equality handling as developed in the context of (unfailing) [Knuth–Bendix completion](wikipedia://en/614147). It can be seen as a generalization of either resolution (to equational logic) or unfailing completion (to full [clausal logic](wikipedia://en/4638484)). Like most [first-order](wikipedia://en/10983) calculi, superposition tries to show the *unsatisfiability* of a set of first-order [clauses](https://en.wikipedia.org/wiki/Clauses), i.e. it performs proofs by [refutation](https://en.wikipedia.org/wiki/Refutation). Superposition is [refutation complete](wikipedia://en/31271451#Refutation_completeness)—given unlimited resources and a *fair* derivation strategy, from any [unsatisfiable](https://en.wikipedia.org/wiki/Unsatisfiable) clause set a contradiction will eventually be derived.

:::

Many (state-of-the-art) [theorem provers](https://en.wikipedia.org/wiki/Automated_theorem_prover) for first-order logic are based on superposition (e.g. the [E equational theorem prover](https://en.wikipedia.org/wiki/E_equational_theorem_prover)), although only a few implement the pure calculus.
