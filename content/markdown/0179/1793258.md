# Borel–Carathéodory theorem

::: {#o1 .subject cue=lead name="Borel–Carathéodory theorem"}

In [mathematics](wikipedia://en/18831), the **Borel–Carathéodory theorem** in [complex analysis](wikipedia://en/5759) shows that an [analytic function](wikipedia://en/61478) may be [bounded](wikipedia://en/311509) by its [real part](https://en.wikipedia.org/wiki/Real_part). It is an application of the [maximum modulus principle](wikipedia://en/880710). It is named for [Émile Borel](wikipedia://en/356161) and [Constantin Carathéodory](wikipedia://en/470625).

:::

::: {#o3 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let a function $f$ be analytic on a [closed disc](https://en.wikipedia.org/wiki/Closed_disc) of [radius](wikipedia://en/1780815) *R* centered at the [origin](wikipedia://en/1313432). Suppose that *r* \< *R*. Then, we have the following inequality:

$$\|f\|_r \le \frac{2r}{R-r} \sup_{|z| \le R} \operatorname{Re} f(z) + \frac{R+r}{R-r} |f(0)|.$$

Here, the norm on the left-hand side denotes the maximum value of *f* in the closed disc:

$$\|f\|_r = \max_{|z| \le r} |f(z)| = \max_{|z| = r} |f(z)|$$

(where the last equality is due to the maximum modulus principle).

:::

::: {#o5 .proof cue=heading name="Proof"}

## Proof {#Proof}

Define *A* by

$$A = \sup_{|z| \le R} \operatorname{Re} f(z).$$

If *f* is constant *c*, the inequality follows from $(R+r)|c|+2r\operatorname{Re}c\ge(R-r)|c|$, so we may assume *f* is nonconstant. First let *f*(0) = 0. Since Re *f* is harmonic, Re *f*(0) is equal to the average of its values around any circle centered at 0. That is,

$$\operatorname{Re} f(0) = \int_0^1 \operatorname{Re} f(R{\rm e}^{2\pi{\rm i} s}){\,\rm d}s.$$

Since *f* is regular and nonconstant, we have that Re *f* is also nonconstant. Since Re *f*(0) = 0, we must have Re $f(z) > 0$ for some *z* on the circle $|z|=R$, so we may take $A>0$. Now *f* maps into the half-plane *P* to the left of the *x*=*A* line. Roughly, our goal is to map this half-plane to a disk, apply [Schwarz's lemma](https://en.wikipedia.org/wiki/Schwarz's_lemma) there, and make out the stated inequality.

$w \mapsto w/A - 1$ sends *P* to the standard left half-plane. $w \mapsto R(w+1)/(w-1)$ sends the left half-plane to the circle of radius *R* centered at the origin. The composite, which maps 0 to 0, is the desired map:

$$w \mapsto \frac{Rw}{w-2A}.$$

From Schwarz's lemma applied to the composite of this map and *f*, we have

$$\frac{|Rf(z)|}{|f(z)-2A|} \leq |z|.$$

Take |*z*| ≤ *r*. The above becomes

$$R|f(z)| \leq r|f(z) - 2A| \leq r|f(z)| + 2Ar$$

so

$$|f(z)| \leq \frac{2Ar}{R-r},$$

as claimed. In the general case, we may apply the above to *f*(*z*)-*f*(0):

$$\begin{aligned} |f(z)|-|f(0)| &\leq |f(z)-f(0)| \leq \frac{2r}{R-r} \sup_{|w| \leq R} \operatorname{Re}(f(w) - f(0)) \\ &\leq \frac{2r}{R-r} \left(\sup_{|w| \leq R} \operatorname{Re} f(w) + |f(0)|\right), \end{aligned}$$

which, when rearranged, gives the claim.

:::

## Alternative result and proof {#Alternative_result_and_proof}

We start with the following result:[^o7]

::: {#o8 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

If $f = u + iv$ is analytic on $B(0, R+\epsilon)$ for some $\epsilon > 0$, and $u \leq M$ on $\partial B(0, R)$, then $\forall n\geq 1$,

$$|f^{(n)}(0) | \leq \frac{2n!}{R^n} (M -u(0))$$

and similarly if $v \leq M$.

:::

::: {#o10 .proof cue=math-proof name="Proof"}

**Proof[^o9].**

It suffices to prove the $u$ case, since the $v$ case is found by $-if = v - iu$.

WLOG, subtract a constant away, to get $f(0) = 0$.

Do three contour integrals around $\partial B(0, R)$ using Cauchy integral formula:

$$f^{(n)}(0)/n! =\frac{1}{2\pi i} \oint \frac{f(z)}{z^{n+1}}dz = \int_0^1 \frac{f(Re^{2\pi i t})}{R^ne^{2\pi in t} }dt$$

$$\int_0^1 f(Re^{2\pi i t}) e^{2\pi int}dt = \frac{1}{2\pi i R^n}\oint f(z) z^{n-1}dz = 0$$

$$\int_0^1 f(Re^{2\pi i t})dt = \frac{1}{2\pi i}\oint f(z) z^{-1}dz = f(0) = 0$$

Pick angle $\theta$, so that $e^{-i\theta} f^{(n)}(0) = | f^{(n)}(0)|$. Then by linearly combining the three integrals, we get

$$\int_0^1 f(Re^{2\pi i t})dt (1 + \cos(2\pi nt + \theta)) = \frac 12 R^n |f^{(n)} (0)|/n!$$

The imaginary part vanishes, and the real part gives

$$\int_0^1 u(Re^{2\pi i t})dt (1 + \cos(2\pi nt + \theta)) = \frac 12 R^n |f^{(n)} (0)|/n!$$

The integral is bounded above by $M\int_0^1 dt (1 + \cos(2\pi nt + \theta)) = M$, so we have the result.

:::

::: {#o11 .statement kind=statement/corollary cue=math-theorem name="Corollary 1"}

**Corollary 1.**

With the same assumptions, for all $r\in (0, R)$,

$$\max_{z\in \partial B(0, r)}| f(z)| \leq \frac{2r}{R-r} M + \frac{R+r}{R-r}|f(0)|$$

:::

::: {#o12 .proof cue=math-proof name="Proof"}

**Proof.**

It suffices to prove the case of $f(0) = 0$.

By previous result, using the Taylor expansion,

$$|f(z)| \leq \sum_{n=0}^\infty \frac{1}{n!}|f^{(n)}(0)|\cdot |z|^n \leq |f(0)| + \sum_{n=1}^\infty2M (r/R)^n = \frac{2r}{R-r} M$$

:::

::: {#o13 .statement kind=statement/corollary cue=math-theorem name="Corollary 2 (Titchmarsh, 5.51, improved)"}

**Corollary 2 (Titchmarsh, 5.51, improved).**

With the same assumptions, for all $r\in (0, R)$, and all integer $n\geq 1$

$$\max_{z\in \partial B(0, r)}| f^{(n)}(z)| \leq \frac{2n!}{(R-r)^{n+1}} R(M- u(0))$$

:::

::: {#o14 .proof cue=math-proof name="Proof"}

**Proof.**

It suffices to prove the case of $f(0) = 0$ as well. And similarly to above,

$$\begin{aligned} |f^{(n)}(z)| &\leq \sum_{k=n}^\infty \frac{k\cdots (k-n+1)}{k!}|f^{(k)}(0)|\cdot |z|^{k-n} \\ &\leq \frac{2(M - u(0))}{R^n}\sum_{k=n}^\infty k\cdots (k-n+1) \left(\frac rR\right)^{k-n} \\ &= \frac{2n!}{(R-r)^{n+1}} R(M- u(0)) \end{aligned}$$

:::

::: {#o16 .application cue=heading name="Applications"}

## Applications {#Applications}

Borel–Carathéodory is often used to bound the logarithm of derivatives, such as in the proof of [Hadamard factorization theorem](wikipedia://en/2369798).

The following example is a strengthening of [Liouville's theorem](wikipedia://en/312293).

::: {#o17 .statement kind=statement/theorem cue=math-theorem name="Liouville's theorem, improved"}

**Liouville's theorem, improved.**

If $f$ is an entire function, such that there exists a sequence $r_k \nearrow \infty$ with $\max_{z \in \partial B(0, r_k)} \Re(f(z)) = o(r_k^{n+1})$, then $f$ is a polynomial of degree at most $n$.

:::

::: {#o18 .proof cue=math-proof name="Proof"}

**Proof.**

By Borel-Caratheodory lemma, for any $0 < r< r_k$,

$$\max_{z\in \partial B(0, r)}| f^{(n+1)}(z)| \leq \frac{4n!}{(r_k-r)^{n+2}} r_k M$$

where $M = \max_{z\in \partial B(0, r_k)} \Re(f(z)) = o(r_k^{n+1})$.

Letting $r \leq \frac{r_k}{2}$, and taking the $k \nearrow \infty$ limit:

$$\max_{z\in \partial B(0, r)}| f^{(n+1)}(z)| = o(1) \to 0$$

Thus by Liouville's theorem, $f^{(n+1)}$ is a constant function, and it converges to zero, so it is zero. So $f$ is a polynomial of degree at most $n$.

:::

::: {#o19 .statement kind=statement/corollary cue=math-theorem name="Corollary"}

**Corollary.**

note

If an entire function $f$ has no roots and is of finite [order](wikipedia://en/10372#Order_and_type) $\rho$, then $f(z) = e^{p(z)}$ for some polynomial $p$ of degree $\deg(p) \leq \rho$.

:::

::: {#o20 .proof cue=math-proof name="Proof"}

**Proof.**

Apply the improved Liouville theorem to $g = \log(f)$.

:::
