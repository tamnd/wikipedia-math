# Pulation square

::: {#o1 .subject cue=lead name="Pulation square"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **pulation square** (also called a **Doolittle diagram**) is a diagram that is simultaneously a [pullback](wikipedia://en/841689) square and a [pushout](wikipedia://en/582024) square. It is a [self-dual](wikipedia://en/310885) concept.

:::
