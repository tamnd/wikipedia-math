# Mackey topology

::: {#o1 .subject cue=lead name="Mackey topology"}

In [functional analysis](wikipedia://en/11180) and related areas of [mathematics](wikipedia://en/18831), the **Mackey topology**, named after [George Mackey](https://en.wikipedia.org/wiki/George_Mackey), is the [finest topology](https://en.wikipedia.org/wiki/Finer_topology) for a [topological vector space](wikipedia://en/45752) which still preserves the [continuous dual](https://en.wikipedia.org/wiki/Continuous_dual). In other words the Mackey topology does not make linear functions continuous which were discontinuous in the default topology. A [topological vector space](wikipedia://en/45752) (TVS) is called a **[Mackey space](wikipedia://en/1804899)** if its topology is the same as the Mackey topology.

:::

The Mackey topology is the opposite of the [weak topology](wikipedia://en/33662), which is the [coarsest topology](wikipedia://en/393069) on a [topological vector space](wikipedia://en/45752) which preserves the continuity of all linear functions in the continuous dual.

The [Mackey–Arens theorem](wikipedia://en/29072525) states that all possible [dual topologies](wikipedia://en/1790140) are finer than the weak topology and coarser than the Mackey topology.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Definition for a pairing {#Definition_for_a_pairing}

Given a [pairing](https://en.wikipedia.org/wiki/Dual_pair) $(X, Y, b),$ the **Mackey topology** on $X$ induced by $(X, Y, b),$ denoted by $\tau(X, Y, b),$ is the [polar topology](wikipedia://en/1789978) defined on $X$ by using the set of all [$\sigma(Y, X, b)$-compact](wikipedia://en/63735167#Weak_topology) [disks](https://en.wikipedia.org/wiki/Absolutely_convex) in $Y.$

When $X$ is endowed with the Mackey topology then it will be denoted by $X_{\tau(X, Y, b)}$ or simply $X_{\tau(X, Y)}$ or $X_{\tau}$ if no ambiguity can arise.

A linear map $F : X \to W$ is said to be **Mackey continuous** (with respect to pairings $(X, Y, b)$ and $(W, Z, c)$) if $F : (X, \tau(X, Y, b)) \to (W, \tau(W, Z, c))$ is continuous.

### Definition for a topological vector space {#Definition_for_a_topological_vector_space}

The definition of the Mackey topology for a [topological vector space](wikipedia://en/45752) (TVS) is a specialization of the above definition of the Mackey topology of a pairing. If $X$ is a TVS with [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) $X^{\prime},$ then the evaluation map $\left(x, x^{\prime}\right) \mapsto x^{\prime}(x)$ on $X \times X^{\prime}$ is called the **canonical pairing**.

The **Mackey topology** on a TVS $X,$ denoted by $\tau\left(X, X^{\prime}\right),$ is the Mackey topology on $X$ induced by the canonical pairing $\left\langle X, X^{\prime} \right\rangle.$

That is, the Mackey topology is the [polar topology](wikipedia://en/1789978) on $X$ obtained by using the set of all [weak\*-compact](https://en.wikipedia.org/wiki/Weak*_topology) [disks](https://en.wikipedia.org/wiki/Absolutely_convex) in $X^{\prime}.$ When $X$ is endowed with the Mackey topology then it will be denoted by $X_{\tau\left(X, X^{\prime}\right)}$ or simply $X_{\tau}$ if no ambiguity can arise.

A linear map $F : X \to Y$ between TVSs is **Mackey continuous** if $F : \left(X, \tau\left(X, X^{\prime}\right)\right) \to \left(Y, \tau\left(Y, Y^{\prime}\right)\right)$ is continuous.

:::

## Examples {#Examples}

Every [metrizable](wikipedia://en/64278078) [locally convex](wikipedia://en/518844) $(X, \nu)$ with continuous dual $X^{\prime}$ carries the Mackey topology, that is $\nu = \tau\left(X, X^{\prime}\right)$ or to put it more succinctly every metrizable locally convex space is a [Mackey space](wikipedia://en/1804899).

Every [Hausdorff](wikipedia://en/13637) [barreled](wikipedia://en/1733592) locally convex space is Mackey.

Every [Fréchet space](wikipedia://en/233801) $(X, \nu)$ carries the Mackey topology and the topology coincides with the [strong topology](wikipedia://en/589726), that is $\nu = \tau\left(X, X^{\prime}\right) = \beta\left(X, X^{\prime}\right).$

:::
