# Linear grammar

::: {#o1 .subject cue=lead name="Linear grammar"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), a **linear grammar** is a [context-free grammar](wikipedia://en/6759) that has at most one nonterminal in the [right-hand side](https://en.wikipedia.org/wiki/Left-hand_side_and_right-hand_side_of_an_equation) of each of its productions.

:::

A **linear language** is a language generated by some linear grammar.

::: {#o3 .example cue=heading name="Example"}

## Example {#Example}

An example of a linear grammar is *G* with *N* = {S}, Σ = {a, b}, *P* with start symbol *S* and rules

S → aSb

S → ε

It generates the language $\{ a^ib^i \mid i \geq 0\}$.

:::

## Relationship with regular grammars {#Relationship_with_regular_grammars}

Two special types of linear grammars are the following:

- the **left-linear** or left-regular grammars, in which all rules are of the form *A → αw* where *α* is either empty or a single nonterminal and *w* is a string of terminals;
- the **right-linear** or right-regular grammars, in which all rules are of the form *A → wα* where *w* is a string of terminals and *α* is either empty or a single nonterminal.

Each of these can describe exactly the [regular languages](wikipedia://en/25723). A [regular grammar](wikipedia://en/25855) is a grammar that is left-linear or right-linear.

Note that having a mix of left-linear and right-linear rules does *not* impose any reduction in the expressive power of linear grammars. Indeed, by adding new nonterminals as abbreviations, any linear grammar can be turned into an equivalent one where some of the rules are left-linear and some are right-linear. For instance, the rules of the grammar *G* above generating $\{ a^ib^i \mid i \geq 0 \}$ can be replaced with

S → aA

A → Sb

S → ε

which generates the same language. It is the requirement that *all* rules be left-linear, or all rules be right-linear, that characterizes regular languages and thus leads to a strict decrease in the expressive power of linear grammars.

## Expressive power, nondeterminism, and complexity {#Expressive_power,_nondeterminism,_and_complexity}

All regular languages are linear; conversely, $\{ a^ib^i \mid i \geq 0 \}$ is an example of a non-regular linear language. All linear languages are [context-free](wikipedia://en/6867); conversely, an example of a context-free, non-linear language is the [Dyck language](wikipedia://en/1852078) of well-balanced bracket pairs. Hence, the regular languages are a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of the linear languages, which in turn are a proper subset of the context-free languages.

Just as the regularity problem for context-free languages is undecidable, it cannot be decided whether a given context-free language is a linear context-free language.[^o6]

While regular languages are [deterministic](wikipedia://en/7962589), there exist linear languages that are nondeterministic. For example, the language of even-length [palindromes](https://en.wikipedia.org/wiki/Palindrome) on the alphabet of 0 and 1 has the linear grammar S → 0S0 | 1S1 | ε, but cannot be recognized by any [deterministic pushdown automaton](https://en.wikipedia.org/wiki/Deterministic_pushdown_automaton).[^o7] In particular, the existence of nondeterministic linear languages can be used to derive Ω(n²/log n) lower bounds for the [online](https://en.wikipedia.org/wiki/Online_algorithm) recognition problem for linear grammars.[^o8]

## One-turn pushdown automata and ultralinear grammars {#One-turn_pushdown_automata_and_ultralinear_grammars}

A language is linear iff it can be generated by a *one-turn pushdown automaton* – a pushdown automaton that, once it starts popping, never pushes again. If one instead places a finite bound on the number of turns then one obtains a more general class of languages known as *ultralinear*, still strictly contained in the context-free languages, and which have a corresponding grammatical characterization.[^o10] A grammar is **ultralinear** if the set of nonterminals can be decomposed as a disjoint union of sets $N = N_0 \cup N_1 \cup \dots \cup N_k$, such that for each nonterminal $X \in N_i$, each production rule is of the form $X \to \alpha Y \beta$ or $X \to \alpha$, where $Y \in N_i$ and $\alpha,\beta \in (\Sigma \cup N_0 \cup \dots \cup N_{i-1})^*$. (Thus linear grammars correspond to the case $k = 0$.)

## Closure properties {#Closure_properties}

### Positive cases {#Positive_cases}

Linear languages are closed under [union](wikipedia://en/47949). Construction is the same as the construction for the union of context-free languages. Let $L_1, L_2$ be two linear languages, then $L_1\cup L_2$ is constructed by a linear grammar with $S \to S_1|S_2$, and $S_1, S_2$ playing the role of the linear grammars for $L_1, L_2$.

If *L* is a linear language and *M* is a *regular* language, then the [intersection](wikipedia://en/23476429) $L \cap M$ is again a linear language; in other words, the linear languages are closed under intersection with regular sets.

Linear languages are closed under [homomorphism](https://en.wikipedia.org/wiki/String_operations#String_homomorphism) and [inverse homomorphism](https://en.wikipedia.org/wiki/String_operations#String_homomorphism).[^o13]

As a [corollary](wikipedia://en/168865), linear languages form a [full trio](https://en.wikipedia.org/wiki/Cone_%28formal_languages%29). Full trios in general are language families that enjoy a couple of other desirable mathematical properties.

### Negative cases {#Negative_cases}

Linear languages are not closed under intersection. For example, let $L_1 = \{a^nb^nc^m \mid n, m \geq 0\}, L_2 = \{a^nb^mc^m \mid n, m \geq 0\}$, then their intersection is not only not linear, but also not context-free. See [pumping lemma for context-free languages](wikipedia://en/3193758#Usage_of_the_lemma).

As a corollary, linear languages are not closed under complement (as intersection can be constructed by [de Morgan's laws](wikipedia://en/64669) out of union and complement).
