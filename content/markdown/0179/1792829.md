# Clifford group

::: {#o1 .subject cue=lead name="Clifford group"}

The **Clifford group** encompasses a set of [quantum operations](wikipedia://en/666107) that map the set of *n*-fold [Pauli group](wikipedia://en/5045613) products into itself. It is most famously studied for its use in [quantum error correction](wikipedia://en/892803).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [Pauli matrices](wikipedia://en/24868),

$$\sigma_0=I=\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \quad \sigma_1=X=\begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}, \quad \sigma_2=Y=\begin{bmatrix} 0 & -i \\ i & 0 \end{bmatrix}, \text{ and } \sigma_3=Z=\begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix}$$

provide a basis for the [density operators](https://en.wikipedia.org/wiki/Density_operator) of a single [qubit](wikipedia://en/25284), as well as for the [unitaries](wikipedia://en/225999) that can be applied to them. For the $n$-qubit case, one can construct a group, known as the [Pauli group](wikipedia://en/5045613), according to

$$\mathbf{P}_n=\left\{ e^{i\theta\pi/2} \sigma_{j_1} \otimes \cdots \otimes \sigma_{j_n} \mid \theta = 0,1,2,3,j_k = 0,1,2,3 \right\}.$$

The Clifford group is defined as the group of unitaries that [normalize](wikipedia://en/145661) the Pauli group: $\mathbf{C}_n=\{V\in U_{2^n}\mid V\mathbf{P}_nV^\dagger = \mathbf{P}_n\}.$ Under this definition, $\mathbf{C}_n$ is infinite, since it contains all unitaries of the form $e^{i \theta}I$ for a real number $\theta$ and the [identity matrix](wikipedia://en/59718) $I$.[^o5] Any unitary in $\mathbf{C}_n$ is equivalent (up to a global [phase factor](https://en.wikipedia.org/wiki/Phase_factor)) to a circuit generated using [Hadamard](wikipedia://en/888587#Hadamard), [S](wikipedia://en/888587#Phase_shift_gates), and [CNOT](https://en.wikipedia.org/wiki/Controlled_NOT_gate) gates,[^o6] so the Clifford group is sometimes defined as the (finite) group of unitaries generated using Hadamard, S, and CNOT gates. The *n*-qubit Clifford group $\mathbf{C}_n$ defined in this manner contains $2^{n^2+2n+3}\prod_{j=1}^{n}(4^j-1)$ elements.[^o7]

Some authors choose to define the Clifford group as the [quotient group](wikipedia://en/11526) $\mathbf{C}_n/U(1)$, which counts elements in $\mathbf{C}_n$ that differ only by an overall global phase factor as the same element. The smallest global phase is $\frac{1+i}{\sqrt{2}}$, the eighth complex root of the number 1, arising from the circuit identity $HSHSHS=\frac{1+i}{\sqrt{2}}I$, where $H$ is the Hadamard gate and $S$ is the Phase gate. For $n=$ 1, 2, and 3, this group contains 24, 11,520, and 92,897,280 elements, respectively. The number of elements in $\mathbf{C}_n/U(1)$ is $2^{n^2+2n}\prod_{j=1}^{n}(4^j-1)$.

Another possible definition of the Clifford group can be obtained from the above by further factoring out the Pauli group $\{I,X,Y,Z\}$ on each qubit. The leftover group is [isomorphic](wikipedia://en/14828) to the group of $2n\times 2n$ [symplectic matrices](wikipedia://en/173983) $\operatorname{Sp}(2n,2)$ over the field $\mathbb{F}_2$ of two elements.[^o7] It has $2^{n^2}\prod_{j=1}^{n}(4^j-1)$ elements.

::: {#o10 .example cue=heading name="Example"}

### Example {#Example}

In the case of a single qubit, each element in the single-qubit Clifford group $\mathbf{C}_1/U(1)$ can be expressed as a matrix product $\mathbf{A}\mathbf{B}$, where $\mathbf{A}\in\{I,H,S,HS,SH,HSH\}$ and $\mathbf{B}=\{I,X,Y,Z\}$. Here $H$ is the Hadamard gate and $S$ the Phase gate.

## Generating gate library {#Generating_gate_library}

The Clifford group is generated by three gates, [Hadamard](wikipedia://en/888587#Hadamard_gate), phase gate [*S*](wikipedia://en/888587#Phase_shift_gates), and [CNOT](https://en.wikipedia.org/wiki/CNOT).

## Circuit complexity {#Circuit_complexity}

Arbitrary Clifford group element can be generated as a circuit with no more than $O(n^2/ \log(n))$ gates.[^o13][^o14] Here, reference[^o13] reports an 11-stage decomposition -H-C-P-C-P-C-H-P-C-P-C-, where H, C, and P stand for computational stages using Hadamard, CNOT, and Phase gates, respectively, and reference[^o14] shows that the CNOT stage can be implemented using $O(n^2/ \log(n))$ gates (stages -H- and -P- rely on the single-qubit gates and thus can be implemented using linearly many gates, which does not affect asymptotics).

## Notable subgroups {#Notable_subgroups}

The Clifford group has a rich subgroup structure often exposed by the quantum circuits generating various subgroups. The subgroups of the Clifford group $\mathbf{C}_n$ include:

- *n*-fold Pauli product group $\mathbf{P}_n$. It has $2^{2n+2}$ elements ($2^{2n}$ without the global phase) and it is generated by the quantum circuits with Pauli-X and Pauli-Z gates.
- [General linear group](wikipedia://en/113564) GL$(n,\mathbb{F}_2)$. It has $\prod_{j=0}^{n-1}(2^n-2^j)=2^{n^2+O(1)}$ elements and it is generated by the circuits with the CNOT gates.
- [Symmetric group](wikipedia://en/28901) $\mathrm{S}_n$. It has $n!$ elements and it is generated by the circuits with the SWAP gates.
- Diagonal subgroup, consisting of diagonal Clifford unitaries. It has $2^{0.5n^2+O(n)}$ elements and it is generated by the quantum circuits with Phase and CZ gates.
- Hadamard-free subgroup is generated by the quantum circuits over Phase and CNOT gates. It has $2^{1.5n^2+O(n)}$ elements.
- [Weyl group](wikipedia://en/296332), which is generated by the SWAP and Hadamard gates.[^o16] It has $2^{n\log(n)+O(n)}$ elements.
- [Borel group](https://en.wikipedia.org/wiki/Borel_group), a maximal [solvable subgroup](https://en.wikipedia.org/wiki/Solvable_subgroup), which is generated by the product of the lower triangular invertible Boolean matrices (CNOT circuits with controls on top qubits and targets on the bottom qubits) with diagonal subgroup elements (circuits with Phase and CZ gates).[^o16] This group is a subgroup of the Hadamard-free subgroup; it has $2^{n^2+O(n)}$ elements.

## Properties {#Properties}

The order of Clifford gates and Pauli gates can be interchanged. For example, this can be illustrated by considering the following operator on 2 qubits

$$A=(X \otimes Z)CZ.$$

We know that: $CZ(X \otimes I)CZ^\dagger =X \otimes Z$. If we multiply by *CZ* from the right

$$CZ(X \otimes I) =(X \otimes Z)CZ.$$

So *A* is equivalent to

$$A=(X \otimes Z)CZ = CZ(X \otimes I).$$

### Simulatability {#Simulatability}

The [Gottesman–Knill theorem](wikipedia://en/5006371) states that a [quantum circuit](wikipedia://en/707404) using only the following elements can be simulated efficiently on a classical computer:

1. Preparation of [qubits](wikipedia://en/25284) in computational basis states,
1. Clifford gates, and
1. Measurements in the computational basis.

The Gottesman–Knill theorem shows that even some highly [entangled](wikipedia://en/25336) states can be simulated efficiently. Several important types of [quantum algorithms](https://en.wikipedia.org/wiki/Quantum_algorithm) use only Clifford gates, most importantly the standard algorithms for [entanglement distillation](wikipedia://en/20511149) and for [quantum error correction](wikipedia://en/892803).
