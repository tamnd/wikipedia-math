# Core model

::: {#o1 .subject cue=lead name="Core model"}

In [set theory](wikipedia://en/27553), the **core model** is a definable [inner model](wikipedia://en/1118686) of the [universe](wikipedia://en/445980) of all [sets](wikipedia://en/26691). Even though set theorists refer to "the core model", it is not a uniquely identified [mathematical object](wikipedia://en/19453961). Rather, it is a class of inner models that under the right set-theoretic assumptions have very special properties, most notably [covering properties](wikipedia://en/326356). Intuitively, the core model is "the largest canonical inner model there is",[^o2] (here "canonical" is an undefined term)[^o3]<sup>p. 28</sup> and is typically associated with a [large cardinal](wikipedia://en/383644) notion. If Φ is a large cardinal notion, then the phrase "core model below Φ" refers to the definable inner model that exhibits the special properties under the assumption that there does *not* exist a cardinal satisfying Φ. The **core model program** seeks to analyze large cardinal axioms by determining the core models below them.

:::

## History {#History}

The first core model was [Kurt Gödel](wikipedia://en/16736)'s [constructible universe](wikipedia://en/343335) **L**. [Ronald Jensen](wikipedia://en/3785996) proved the [covering lemma](wikipedia://en/326356) for **L** in the 1970s under the assumption of the non-existence of [zero sharp](wikipedia://en/248085), establishing that **L** is the "core model below zero sharp". The work of [Solovay](https://en.wikipedia.org/wiki/Solovay) isolated another core model **L**\[*U*\], for *U* an [ultrafilter](wikipedia://en/31911) on a [measurable cardinal](wikipedia://en/248102) (and its associated "sharp", [zero dagger](https://en.wikipedia.org/wiki/Zero_dagger)). Together with Tony Dodd, Jensen constructed the [Dodd–Jensen core model](https://en.wikipedia.org/wiki/Dodd–Jensen_core_model) ("the core model below a measurable cardinal") and proved the covering lemma for it and a generalized covering lemma for **L**\[*U*\].

Mitchell used coherent sequences of measures to develop core models containing multiple or higher-order measurables. Still later, the Steel core model used [extenders](wikipedia://en/24047112) and iteration trees to construct a core model below a [Woodin cardinal](wikipedia://en/248105).

## Construction of core models {#Construction_of_core_models}

Core models are constructed by [transfinite recursion](https://en.wikipedia.org/wiki/Transfinite_recursion) from small fragments of the core model called [mice](https://en.wikipedia.org/wiki/Mouse_%28Set_Theory%29). An important ingredient of the construction is the comparison lemma that allows giving a [wellordering](https://en.wikipedia.org/wiki/Wellordering) of the relevant mice.

At the level of [strong cardinals](wikipedia://en/248104) and above, one constructs an intermediate countably certified core model K<sup>c</sup>, and then, if possible, extracts K from K<sup>c</sup>.

## Properties of core models {#Properties_of_core_models}

K<sub>c</sub> (and hence K) is a fine-structural countably iterable extender model below long extenders. (It is not currently known how to deal with long extenders, which establish that a cardinal is [superstrong](wikipedia://en/248114).) Here countable iterability means ω<sub>1</sub>+1 iterability for all countable elementary substructures of initial segments, and it suffices to develop basic theory, including certain condensation properties. The theory of such models is canonical and well understood. They satisfy [GCH](https://en.wikipedia.org/wiki/Generalized_Continuum_Hypothesis), the [diamond principle](wikipedia://en/691736) for all [stationary subsets](https://en.wikipedia.org/wiki/Stationary_subset) of regular cardinals, the [square principle](wikipedia://en/2292730) (except at [subcompact cardinals](wikipedia://en/3994376)), and other principles holding in L.

K<sup>c</sup> is maximal in several senses. K<sup>c</sup> computes the successors of measurable and many singular cardinals correctly. Also, it is expected that under an appropriate weakening of countable certifiability, K<sup>c</sup> would correctly compute the successors of all [weakly compact](wikipedia://en/272054) and singular [strong limit cardinals](https://en.wikipedia.org/wiki/Strong_limit_cardinal) correctly. If V is closed under a mouse operator (an inner model operator), then so is K<sup>c</sup>. K<sup>c</sup> has no sharp: There is no natural non-trivial [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) of K<sup>c</sup> into itself. (However, unlike K, K<sup>c</sup> may be elementarily self-embeddable.)

If in addition there are also no Woodin cardinals in this model (except in certain specific cases, it is not known how the core model should be defined if K<sub>c</sub> has Woodin cardinals), we can extract the actual core model K. K is also its own core model. K is locally definable and generically absolute: For every generic extension of V, for every cardinal κ>ω<sub>1</sub> in V\[G\], K as constructed in H(κ) of V\[G\] equals K∩H(κ). (This would not be possible had K contained Woodin cardinals). K is maximal, universal, and fully iterable. This implies that for every iterable extender model M (called a mouse), there is an elementary embedding M→N and of an initial segment of K into N, and if M is universal, the embedding is of K into M.

It is conjectured that if K exists and V is closed under a sharp operator M, then K is Σ<sup>1</sup><sub>1</sub> correct allowing real numbers in K as parameters and M as a predicate. That amounts to Σ<sup>1</sup><sub>3</sub> correctness (in the usual sense) if M is x→x<sup>\#</sup>.

The core model can also be defined above a particular set of ordinals X: X belongs to K(X), but K(X) satisfies the usual properties of K above X. If there is no iterable inner model with ω Woodin cardinals, then for some X, K(X) exists. The above discussion of K and K<sup>c</sup> generalizes to K(X) and K<sup>c</sup>(X).

## Construction of core models {#Construction_of_core_models}

::: {#o8 .statement kind=statement/conjecture cue=inline-head name="Conjecture"}

**Conjecture:**

- If there is no ω<sub>1</sub>+1 iterable model with long extenders (and hence models with superstrong cardinals), then K<sup>c</sup> exists.
- If K<sup>c</sup> exists and as constructed in every generic extension of V (equivalently, under some generic collapse Coll(ω, \<κ) for a sufficiently large ordinal κ) satisfies "there are no Woodin cardinals", then the Core Model K exists.

Partial results for the conjecture are that:

1. If there is no inner model with a Woodin cardinal, then K exists.
1. If (boldface) Σ<sup>1</sup><sub>n</sub> [determinacy](wikipedia://en/2596030) (n is finite) holds in every generic extension of V, but there is no iterable inner model with n Woodin cardinals, then K exists.
1. If there is a measurable cardinal κ, then either K<sup>c</sup> below κ exists, or there is an ω<sub>1</sub>+1 iterable model with measurable limit λ of both Woodin cardinals and cardinals strong up to λ.

If V has Woodin cardinals but not cardinals strong past a Woodin one, then under appropriate circumstances (a candidate for) K can be constructed by constructing K below each Woodin cardinal (and below the class of all ordinals) κ but above that K as constructed below the [supremum](wikipedia://en/39382) of Woodin cardinals below κ. The candidate core model is not fully iterable (iterability fails at Woodin cardinals) or generically absolute, but otherwise behaves like K.

:::
