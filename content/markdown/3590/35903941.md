# Steinberg symbol

::: {#o1 .subject cue=lead name="Steinberg symbol"}

In mathematics a **Steinberg symbol** is a pairing function which generalises the [Hilbert symbol](wikipedia://en/5924217) and plays a role in the [algebraic K-theory](wikipedia://en/598500) of [fields](wikipedia://en/10603). It is named after mathematician [Robert Steinberg](https://en.wikipedia.org/wiki/Robert_Steinberg).

:::

For a field $F$ we define a *Steinberg symbol* (or simply a *symbol*) to be a function $( \cdot , \cdot ) : F^* \times F^* \rightarrow G$, where $G$ is an abelian group, written multiplicatively, such that for all $a, b, c \in F^*$,

- $( ab, c) = (a, c)(b, c)$ and $( a, bc) = (a, b)(a, c)$, and
- if $a+b = 1$ then $(a,b) = 1$.

The first condition is sometimes referred to as $( \cdot , \cdot )$ being *bimultiplicative*, while the second condition is known as the *Steinberg property*.

The symbols on $F$ derive from a "universal" symbol, which may be regarded as taking values in $F^* \otimes F^* / \langle a \otimes 1-a \rangle$. By a theorem of [Hideya Matsumoto](https://en.wikipedia.org/wiki/Hideya_Matsumoto), this group is $K_2 F$ and is part of the [Milnor K-theory](wikipedia://en/2914128) for a field.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $(\cdot ,\cdot)$ is a symbol on $F$, then for all $a, b \in F^*$ we have

- $$(a, -a) = 1;$$
- $$(b, a) = (a, b)^{-1};$$
- $(a, a) = (a, -1)$ is an element of order 1 or 2;
- $$(a, b) = (a+b, -b/a).$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The trivial symbol which is identically 1.
- The [Hilbert symbol](wikipedia://en/5924217) on $F$ with values in {±1} defined by[^o6][^o7]

$$(a,b)=\begin{cases}1,&\mbox{ if }z^2=ax^2+by^2\mbox{ has a non-zero solution }(x,y,z)\in F^3;\\-1,&\mbox{ if not.}\end{cases}$$

- The [Contou-Carrère symbol](wikipedia://en/38656223) is a symbol for the ring of [Laurent power series](https://en.wikipedia.org/wiki/Laurent_power_series) over an [Artinian ring](wikipedia://en/489273).

:::

## Continuous symbols {#Continuous_symbols}

If $F$ is a [topological field](https://en.wikipedia.org/wiki/Topological_field) then a symbol *c* is *weakly continuous* if for each *y* in *F*<sup>∗</sup> the set of *x* in *F*<sup>∗</sup> such that *c*(*x*,*y*) = 1 is [closed](wikipedia://en/47279) in *F*<sup>∗</sup>. This makes no reference to a topology on the codomain *G*. If *G* is a [topological group](wikipedia://en/42315), then one may speak of a *continuous symbol*, and when *G* is [Hausdorff](wikipedia://en/13637) then a continuous symbol is weakly continuous.[^o9]

The only weakly continuous symbols on **R** are the trivial symbol and the Hilbert symbol; the only weakly continuous symbol on **C** is the trivial symbol.[^o10] The characterisation of weakly continuous symbols on a non-Archimedean [local field](wikipedia://en/145375) *F* was obtained by Moore. The group K<sub>2</sub>(*F*) is the direct sum of a [cyclic group](wikipedia://en/52327) of order *m* and a [divisible group](wikipedia://en/472147) K<sub>2</sub>(*F*)<sup>*m*</sup>. A symbol on *F* lifts to a homomorphism on K<sub>2</sub>(*F*) and is weakly continuous precisely when it annihilates the divisible component K<sub>2</sub>(*F*)<sup>*m*</sup>. It follows that every weakly continuous symbol factors through the [norm residue symbol](https://en.wikipedia.org/wiki/Norm_residue_symbol).[^o11]
