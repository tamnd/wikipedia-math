# Compact convergence

::: {#o1 .subject cue=lead name="Compact convergence"}

In [mathematics](wikipedia://en/18831) **compact convergence** (or **uniform convergence on compact sets**) is a type of [convergence](wikipedia://en/285773) that generalizes the idea of [uniform convergence](wikipedia://en/50652). It is associated with the [compact-open topology](wikipedia://en/726335).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(X, \mathcal{T})$ be a [topological space](wikipedia://en/30450) and $(Y,d_{Y})$ be a [metric space](wikipedia://en/20018). A sequence of functions

$f_{n} : X \to Y$, $n \in \mathbb{N},$

is said to **converge compactly** as $n \to \infty$ to some function $f : X \to Y$ if, for every [compact set](https://en.wikipedia.org/wiki/Compact_set) $K \subseteq X$,

$$f_{n}|_{K} \to f|_{K}$$

[uniformly](wikipedia://en/50652) on $K$ as $n \to \infty$. This means that for all compact $K \subseteq X$,

$$\lim_{n \to \infty} \sup_{x \in K} d_{Y} \left( f_{n} (x), f(x) \right) = 0.$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- If $X = (0, 1) \subseteq \mathbb{R}$ and $Y = \mathbb{R}$ with their usual topologies, with $f_{n} (x) := x^{n}$, then $f_{n}$ converges compactly to the constant function with value 0, but [uniform convergence](wikipedia://en/50652) does not hold.
- If $X=(0,1]$, $Y=\mathbb{R}$ and $f_n(x)=x^n$, then $f_n$ converges [pointwise](wikipedia://en/340198) to the function that is zero on $(0,1)$ and one at $1$, but the sequence does not converge compactly.
- A very powerful tool for showing compact convergence is the [Arzelà–Ascoli theorem](wikipedia://en/596622). There are several versions of this theorem, roughly speaking it states that every sequence of [equicontinuous](https://en.wikipedia.org/wiki/Equicontinuous) and [uniformly bounded](https://en.wikipedia.org/wiki/Uniformly_bounded) maps has a subsequence that converges compactly to some continuous map.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If $f_{n} \to f$ uniformly, then $f_{n} \to f$ compactly.
- If $(X, \mathcal{T})$ is a [compact space](wikipedia://en/6042) and $f_{n} \to f$ compactly, then $f_{n} \to f$ uniformly.
- If $(X, \mathcal{T})$ is a [locally compact space](wikipedia://en/48632), then $f_{n} \to f$ compactly if and only if $f_{n} \to f$ locally uniformly.
- If $(X, \mathcal{T})$ is a [compactly generated space](wikipedia://en/899382), $f_n\to f$ compactly, and each $f_n$ is [continuous](wikipedia://en/6122), then $f$ is continuous.

:::
