# NUSH

::: {#o3 .subject cue=lead name="NUSH"}

In [cryptography](wikipedia://en/18934432), **NUSH** is a [block cipher](wikipedia://en/4594) invented by [Anatoly Lebedev](https://en.wikipedia.org/wiki/Anatoly_Lebedev) and [Alexey Volchkov](https://en.wikipedia.org/wiki/Alexey_Volchkov) for the Russian company [LAN Crypto](https://en.wikipedia.org/wiki/LAN_Crypto). It was submitted to the [NESSIE](wikipedia://en/497430) project, but was not selected.

:::

NUSH exists in several different variants, using keys of 128, 192, or 256 bits, and a block size of 64, 128, or 256 bits. The number of rounds is 9, 17, or 33, depending on the block size. The algorithm uses [key whitening](wikipedia://en/2990178), but no [S-boxes](https://en.wikipedia.org/wiki/Substitution_box); the only operations it uses are [AND](https://en.wikipedia.org/wiki/Binary_and), [OR](wikipedia://en/7962), [XOR](https://en.wikipedia.org/wiki/XOR), [modular addition](wikipedia://en/20087), and [bit rotation](https://en.wikipedia.org/wiki/Bit_rotation).

It has been shown that [linear cryptanalysis](wikipedia://en/59469) can break NUSH with less effort than a [brute force attack](https://en.wikipedia.org/wiki/Brute_force_attack).[^o4]
