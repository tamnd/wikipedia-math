# Propositional function

::: {#o1 .subject cue=lead name="Propositional function"}

In [propositional calculus](https://en.wikipedia.org/wiki/Propositional_calculus), a **propositional function** or a **predicate** is a sentence expressed in a way that would assume the value of [true](wikipedia://en/3986852) or [false](wikipedia://en/229823), except that within the sentence there is a [variable](wikipedia://en/3728109) (*x*) that is not defined or specified (thus being a [free variable](https://en.wikipedia.org/wiki/Free_variable)), which leaves the statement undetermined. The sentence may contain several such variables (e.g. *n* variables, in which case the function takes *n* arguments).

:::

## Overview {#Overview}

As a [mathematical function](wikipedia://en/185427), *A*(*x*) or *A*(*x*${}_{1}$, *x*${}_{2}$, ..., *x*${}_{n}$), the propositional function is abstracted from [predicates](https://en.wikipedia.org/wiki/Predicate_%28mathematical_logic%29) or propositional forms. As an example, consider the predicate scheme, "x is hot". The substitution of any entity for *x* will produce a specific proposition that can be described as either true or false, even though "*x* is hot" on its own has no value as either a true or false statement. However, when a value is assigned to *x*, such as [lava](https://en.wikipedia.org/wiki/Lava), the function then has the value *true*; while one assigns to *x* a value like [ice](https://en.wikipedia.org/wiki/Ice), the function then has the value *false*.

Propositional functions are useful in [set theory](wikipedia://en/27553) for the formation of [sets](wikipedia://en/26691). For example, in 1903 [Bertrand Russell](wikipedia://en/4163) wrote in *[The Principles of Mathematics](https://en.wikipedia.org/wiki/The_Principles_of_Mathematics)* (page 106):

"...it has become necessary to take *propositional function* as a [primitive notion](wikipedia://en/23706).

Later Russell examined the problem of whether propositional functions were predicative or not, and he proposed two theories to try to get at this question: the zig-zag theory and the ramified theory of types.[^o3]

A Propositional Function, or a predicate, in a variable *x* is an [open formula](wikipedia://en/228361) *p*(*x*) involving *x* that becomes a proposition when one gives *x* a definite value from the set of values it can take.

According to [Clarence Lewis](https://en.wikipedia.org/wiki/Clarence_Lewis), "A [proposition](wikipedia://en/81094) is any expression which is either true or false; a propositional function is an expression, containing one or more variables, which becomes a proposition when each of the variables is replaced by some one of its values from a [discourse domain](wikipedia://en/229180) of individuals."[^o4] Lewis used the notion of propositional functions to introduce [relations](wikipedia://en/22517558), for example, a propositional function of *n* variables is a relation of [arity](wikipedia://en/42301) *n*. The case of *n* = 2 corresponds to [binary relations](wikipedia://en/3931), of which there are [homogeneous relations](wikipedia://en/12987179) (both variables from the same set) and [heterogeneous relations](https://en.wikipedia.org/wiki/Heterogeneous_relation).
