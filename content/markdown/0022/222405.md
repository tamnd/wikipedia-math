# Linnik's theorem

::: {#o1 .subject cue=lead name="Linnik's theorem"}

**Linnik's theorem** in [analytic number theory](wikipedia://en/251513) answers a natural question after [Dirichlet's theorem on arithmetic progressions](wikipedia://en/101453). It asserts that there exist positive *c* and *L* such that, if we denote p(*a*,*d*) the least [prime in the arithmetic progression](wikipedia://en/11740178)

:::

$$a + nd,\$$

where *n* runs through the positive [integers](wikipedia://en/14563) and *a* and *d* are any given positive [coprime integers](wikipedia://en/6556) with 1 ≤ *a* ≤ *d* − 1, then:

$$\operatorname{p}(a,d) < c d^{L}. \;$$

The theorem is named after [Yuri Vladimirovich Linnik](https://en.wikipedia.org/wiki/Yuri_Vladimirovich_Linnik), who [proved](wikipedia://en/82285) it in 1944.[^o2][^o3] Although Linnik's proof showed *c* and *L* to be [effectively computable](wikipedia://en/250237), he provided no numerical values for them.

It follows from [Zsigmondy's theorem](wikipedia://en/5767229) that p(1,*d*) ≤ 2<sup>*d*</sup> − 1, for all *d* ≥ 3. It is known that p(1,*p*) ≤ L<sub>*p*</sub>, for all [primes](wikipedia://en/23666) *p* ≥ 5, as L<sub>*p*</sub> is [congruent](wikipedia://en/20087) to 1 modulo *p* for all prime numbers *p*, where L<sub>*p*</sub> denotes the *p*-th [Lucas number](wikipedia://en/398404). Just like [Mersenne numbers](https://en.wikipedia.org/wiki/Mersenne_numbers), Lucas numbers with prime indices have [divisors](wikipedia://en/49492) of the form 2*kp*+1.

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

It is known that *L* ≤ 2 for [almost all](wikipedia://en/1309) integers *d*.[^o6]

On the [generalized Riemann hypothesis](wikipedia://en/152567) it can be shown that

$$\operatorname{p}(a,d) \leq (1+o(1))\varphi(d)^2 (\log d)^2 \; ,$$

where $\varphi$ is the [totient function](https://en.wikipedia.org/wiki/Totient_function),[^o21] and the stronger bound

$$\operatorname{p}(a,d) \leq \varphi(d)^2 (\log d)^2 \; ,$$

has been also proved.[^o7]

It is also [conjectured](wikipedia://en/6138) that:

$\operatorname{p}(a,d) < d^2. \;$ [^o21]

:::

## Bounds for *L* {#Bounds_for_L}

The constant *L* is called **Linnik's constant**[^o9] and the following table shows the progress that has been made on determining its size.

|---|---|---|
| 10000 | 1957 | [Pan](https://en.wikipedia.org/wiki/Pan_Chengdong)[^o10] |
| 5448 | 1958 | Pan |
| 777 | 1965 | [Chen](wikipedia://en/352985)[^o11] |
| 630 | 1971 | [Jutila](wikipedia://en/6716887) |
| 550 | 1970 | Jutila[^o12] |
| 168 | 1977 | Chen[^o13] |
| 80 | 1977 | Jutila[^o14] |
| 36 | 1977 | [Graham](wikipedia://en/6716686)[^o15] |
| 20 | 1981 | Graham[^o16] (submitted before Chen's 1979 paper) |
| 17 | 1979 | Chen[^o17] |
| 16 | 1986 | Wang |
| \13.5 | 1989 | Chen and [Liu](https://en.wikipedia.org/wiki/Liu_Jian_Min)[^o18][^o19] |
| 8 | 1990 | Wang[^o20] |
| \5.5 | 1992 | [Heath-Brown](wikipedia://en/2984550)[^o21] |
| \5.18 | 2009 | Xylouris[^o22] |
| 5 | 2011 | Xylouris[^o23] |
| 5 − ε | 2018 | Xylouris[^o24] |

Moreover, in Heath-Brown's result the constant *c* is effectively computable.
