# False (logic)

::: {#o1 .subject cue=lead name="False"}

In [logic](wikipedia://en/46426065), **false** (Its noun form is [falsity](wikipedia://en/29920)) or **untrue** is the state of possessing negative [truth value](wikipedia://en/161711) and is a [nullary](https://en.wikipedia.org/wiki/Nullary) [logical connective](wikipedia://en/18153). In a [truth-functional](wikipedia://en/604707) system of propositional logic, it is one of two postulated truth values, along with its [negation](wikipedia://en/161019), [truth](wikipedia://en/3986852).[^o2] Usual notations of the false are [0](https://en.wikipedia.org/wiki/0_%28number%29) (especially in [Boolean logic](https://en.wikipedia.org/wiki/Boolean_Logic) and [computer science](https://en.wikipedia.org/wiki/Computer_science)), O (in [prefix notation](wikipedia://en/25056), O*pq*), and the [up tack](wikipedia://en/25016871) symbol $\bot$.[^o3][^o4]

:::

Another approach is used for several [formal theories](wikipedia://en/3512103) (e.g., [intuitionistic propositional calculus](https://en.wikipedia.org/wiki/Intuitionistic_propositional_calculus)), where a propositional constant (i.e. a nullary connective), $\bot$, is introduced, the truth value of which being always false in the sense above.[^o5][^o6][^o7] It can be treated as an absurd proposition, and is often called absurdity.

## In classical logic and Boolean logic {#In_classical_logic_and_Boolean_logic}

In [Boolean logic](https://en.wikipedia.org/wiki/Boolean_logic), each variable denotes a [truth value](wikipedia://en/161711) which can be either true (1), or false (0).

In a [classical](wikipedia://en/55868) [propositional calculus](https://en.wikipedia.org/wiki/Propositional_calculus), each [proposition](wikipedia://en/81094) will be assigned a truth value of either true or false.[^o9][^o10] Some systems of classical logic include dedicated symbols for false (0 or $\bot$), while others instead rely upon formulas such as $p \land \neg p$ and $\neg(p \to p)$.

In both Boolean logic and Classical logic systems, true and false are opposite with respect to [negation](wikipedia://en/161019); the negation of false gives true, and the negation of true gives false.

The negation of false is equivalent to the truth not only in classical logic and Boolean logic, but also in most other logical systems, as explained below.

#### Conjunction (AND ∧) {#Conjunction_(AND_∧)}

False ∧ True = False (False AND anything is False).

#### Disjunction (OR ∨) {#Disjunction_(OR_∨)}

False ∨ True = True (OR is True if at least one operand is True).

#### Implication (→) {#Implication_(→)}

False → True = True (A false premise makes the implication vacuously true).

## False, negation and contradiction {#False,_negation_and_contradiction}

In most logical systems, [negation](wikipedia://en/161019), [material conditional](wikipedia://en/658808) and false are related as:

$$\neg p \Leftrightarrow (p \to \perp)$$

In fact, this is the definition of negation in some systems,[^o20] such as [intuitionistic logic](wikipedia://en/169262), and can be proven in propositional calculi where negation is a fundamental connective. Because $p \to p$ is usually a theorem or axiom, a consequence is that the negation of false ($\neg \perp$) is true.

A [contradiction](wikipedia://en/75807) is the situation that arises when a [statement](https://en.wikipedia.org/wiki/Statement_%28logic%29) that is assumed to be true is shown to [entail](https://en.wikipedia.org/wiki/Entailment) false (i.e., $\varphi \vdash \perp$). Using the equivalence above, the fact that φ is a contradiction may be derived, for example, from $\vdash \neg\varphi$. A statement that entails false itself is sometimes called a contradiction, and contradictions and false are sometimes not distinguished, especially due to the [Latin](https://en.wikipedia.org/wiki/Latin) term *falsum* being used in English to denote either, but false is one specific [proposition](wikipedia://en/81094).

Logical systems may or may not contain the [principle of explosion](wikipedia://en/591394) (*ex falso quodlibet* in [Latin](https://en.wikipedia.org/wiki/Latin)), $\perp \vdash \varphi$ for all $\varphi$. By that principle, contradictions and false are equivalent, since each entails the other.

## Consistency {#Consistency}

A [formal theory](wikipedia://en/3512103) using the "$\bot$" connective is defined to be consistent, if and only if the false is not among its [theorems](wikipedia://en/30977). In the absence of propositional constants, some substitutes (such as the ones described above) may be used instead to define consistency.
