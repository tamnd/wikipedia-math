# Open formula

::: {#o1 .subject cue=lead name="Open formula"}

An **open formula** is a [formula](https://en.wikipedia.org/wiki/Formula_%28logic%29) that contains at least one [free variable](https://en.wikipedia.org/wiki/Free_variable).[^o2]

:::

## Definition and uses {#Definition_and_uses}

An open formula does not have a [truth value](wikipedia://en/161711) assigned to it, in contrast with a [closed formula](https://en.wikipedia.org/wiki/Sentence_%28logic%29) which constitutes a proposition and thus can have a truth value like *true* or *false*. An open formula can be transformed into a closed formula by applying a quantifier for each free variable. This transformation is called capture of the free variables to make them bound variables.

For example, when reasoning about [natural numbers](wikipedia://en/21474), the formula "*x*+2 > *y*" is open, since it contains the free variables *x* and *y*. In contrast, the formula "[∃](wikipedia://en/91420)*y* [∀](wikipedia://en/76174)*x*: *x*+2 > *y*" is closed, and has truth value *true*.

Open formulas are often used in rigorous mathematical definitions of properties, like

"*x* is an aunt of *y* if, for some person *z*, *z* is a parent of *y*, and *x* is a sister of *z*"

(with free variables *x*, *y*, and bound variable *z*) defining the notion of "aunt" in terms of "parent" and "sister". Another, more formal example, which defines the property of being a [prime number](wikipedia://en/23666), is

"*P*(*x*) if ∀*m*,*n*∈$\mathbb{N}$: *m*>1 ∧ *n*>1 → *x*≠ *m*⋅*n*",

(with free variable *x* and bound variables *m*,*n*).

## Fermat example {#Fermat_example}

An example of a closed formula with truth value *false* involves the sequence of [Fermat numbers](wikipedia://en/91127)

$$F_{n} = 2^{2^n} + 1,$$

studied by Fermat in connection to the primality. The attachment of the predicate letter P (*is prime*) to each number from the Fermat sequence gives a set of closed formulae. While they are true for *n* = 0,...,4, no larger value of *n* is known that obtains a true formula, ; for example, $F_5 = 4 \,294 \,967 \,297 = 641 \cdot 6\,700\,417$ is not a prime. Thus the closed formula ∀*n* *P*(*F*<sub>*n*</sub>) is false.

In [database theory](https://en.wikipedia.org/wiki/Database_theory), when expressing a query as an open [first-order formula](https://en.wikipedia.org/wiki/First-order_formula), the free variables represent the ones that in an [SQL](wikipedia://en/29004) query would occur in the [SELECT](https://en.wikipedia.org/wiki/Select_%28SQL%29) clause. For example, a formula like:

$$\varphi(son) = birthYear(son,2020) \land \exists mom\textbf{.}(motherOf(mom,son) \land birthYear(mom,1999))$$

where $son$ is the only free variable, could be expressed in SQL as follows:

```sql
SELECT y1.person AS son
FROM birth_year y1
WHERE y1.year = 2020
AND EXISTS (
  SELECT *
  FROM mother_of m1
  JOIN birth_year y2 ON m1.mother = y2.person
  WHERE m1.son = y1.person
  AND y2.year = 1999
)
```

which selects all the people born in 2020 and having a mother born in 1999.

Formally, executing the above SQL query over a database is equivalent to look for all the [substitutions](wikipedia://en/5438948) $\sigma$ of the free variables of $\varphi$ with constants such that the [Herbrand interpretation](wikipedia://en/7731831) of $\mathcal{D}$ [satisfies](https://en.wikipedia.org/wiki/Satisfaction_%28logic%29) $\sigma(\varphi)$, where $\mathcal{D}$ is the set of [ground atoms](https://en.wikipedia.org/wiki/Ground_atom) representing the database.
