# Multivalued function

::: {#o1 .subject cue=lead name="Multivalued function"}

*Image: Multivalued\_function.svg.* Multivalued function {1,2,3} → {a,b,c,d}.

In [mathematics](wikipedia://en/18831), a **multivalued function**,[^o2] **multiple-valued function**,[^o3] **many-valued function**,[^o4] or **multifunction**,[^o5] is a function that has two or more values in its range for at least one point in its domain.[^o6] It is a [set-valued function](wikipedia://en/12506030) with additional properties depending on context; though some authors do not distinguish between set-valued functions and multifunctions.[^o7]

:::

A *multivalued function* of sets *f : X → Y* is a subset

$$\Gamma_f\ \subseteq \ X\times Y.$$

Write *f(x)* for the set of those *y* ∈ *Y* with (*x,y*) ∈ *Γ<sub>f</sub>*. If *f* is an ordinary function, it is a multivalued function by taking its [graph](wikipedia://en/87352)

$$\Gamma_f\ =\ \{(x,f(x))\ :\ x\in X\}.$$

They are called **single-valued functions** to distinguish them.

## Motivation {#Motivation}

The term multivalued function originated in complex analysis, from [analytic continuation](wikipedia://en/80842). It often occurs that one knows the value of a complex [analytic function](wikipedia://en/61478) $f(z)$ in some [neighbourhood](wikipedia://en/1529485) of a point $z=a$. This is the case for functions defined by the [implicit function theorem](wikipedia://en/581005) or by a [Taylor series](wikipedia://en/30448) around $z=a$. In such a situation, one may extend the domain of the single-valued function $f(z)$ along curves in the complex plane starting at $a$. In doing so, one finds that the value of the extended function at a point $z=b$ depends on the chosen curve from $a$ to $b$; since none of the new values is more natural than the others, all of them are incorporated into a multivalued function.

For example, let $f(z)=\sqrt{z}\,$ be the usual [square root](wikipedia://en/29208) function on positive real numbers. One may extend its domain to a neighbourhood of $z=1$ in the complex plane, and then further along curves starting at $z=1$, so that the values along a given curve vary continuously from $\sqrt{1}=1$. Extending to negative real numbers, one gets two opposite values for the square root—for example $\pm i$ for $-1$—depending on whether the domain has been extended through the upper or the lower half of the complex plane. This phenomenon is very frequent, occurring for [$n$th roots](wikipedia://en/235029), [logarithms](wikipedia://en/17860), and [inverse trigonometric functions](https://en.wikipedia.org/wiki/Inverse_trigonometric_function).

To define a single-valued function from a complex multivalued function, one may distinguish one of the multiple values as the [principal value](wikipedia://en/408225), producing a single-valued function on the whole plane which is discontinuous along certain boundary curves. Alternatively, dealing with the multivalued function allows having something that is everywhere continuous, at the cost of possible value changes when one follows a closed path ([monodromy](wikipedia://en/251250)). These problems are resolved in the theory of [Riemann surfaces](wikipedia://en/173181): to consider a multivalued function $f(z)$ as an ordinary function without discarding any values, one multiplies the domain into a many-layered [covering space](wikipedia://en/3002253), a [manifold](wikipedia://en/2073470) which is the Riemann surface associated to $f(z)$.

## Inverses of functions {#Inverses_of_functions}

If *f : X → Y* is an ordinary function, then its inverse is the multivalued function

$$\Gamma_{f^{-1}}\ \subseteq \ Y\times X$$

defined as *Γ<sub>f</sub>*, viewed as a subset of *X* × *Y*. When *f* is a [differentiable function](wikipedia://en/330206) between [manifolds](wikipedia://en/2073470), the [inverse function theorem](wikipedia://en/287229) gives conditions for this to be single-valued locally in *X*.

For example, the [complex logarithm](wikipedia://en/4870290) *log(z)* is the multivalued inverse of the exponential function *e<sup>z</sup>* : **C** → **C**<sup>×</sup>, with graph

$$\Gamma_{\log(z)}\ =\ \{(z,w)\ :\ w=\log (z)\}\ \subseteq\ \mathbf{C}\times\mathbf{C}^\times.$$

It is not single valued, given a single *w* with *w = log(z)*, we have

$$\log(z)\ =\ w\ +\ 2\pi i \mathbf{Z}.$$

Given any [holomorphic](wikipedia://en/14110) function on an open subset of the [complex plane](wikipedia://en/217628) **C**, its [analytic continuation](wikipedia://en/80842) is always a multivalued function.

## Concrete examples {#Concrete_examples}

- Every [real number](wikipedia://en/20646438) greater than zero has two real [square roots](wikipedia://en/29208), so that square root may be considered a multivalued function. For example, we may write $\sqrt{4}=\pm 2=\{2,-2\}$; although zero has only one square root, $\sqrt{0} =\{0\}$. Note that $\sqrt{x}$ usually denotes only the principal square root of $x$.
- Each nonzero [complex number](wikipedia://en/5826) has two square roots, three [cube roots](wikipedia://en/292506), and in general *n* [*n*th roots](wikipedia://en/235029). The only *n*th root of 0 is 0.
- The [complex logarithm](wikipedia://en/4870290) function is multiple-valued. The values assumed by $\log(a+bi)$ for real numbers $a$ and $b$ are $\log{\sqrt{a^2 + b^2}} + i\arg (a+bi) + 2 \pi n i$ for all [integers](wikipedia://en/14563) $n$.
- [Inverse trigonometric functions](https://en.wikipedia.org/wiki/Inverse_trigonometric_function) are multiple-valued because trigonometric functions are periodic. We have $$\tan\left(\tfrac{\pi}{4}\right) = \tan\left(\tfrac{5\pi}{4}\right) = \tan\left({\tfrac{-3\pi}{4}}\right) = \tan\left({\tfrac{(4n+1)\pi}{4}}\right) = \cdots = 1.$$ As a consequence, arctan(1) is intuitively related to several values: $\pi$/4, 5$\pi$/4, −3$\pi$/4, and so on. We can treat arctan as a single-valued function by restricting the domain of tan *x* to −$\pi$/2 \< *x* \< $\pi$/2 – a domain over which tan *x* is monotonically increasing. Thus, the range of arctan(*x*) becomes −$\pi$/2 \< *y* \< $\pi$/2. These values from a restricted domain are called *[principal values](wikipedia://en/408225)*.
- The [antiderivative](wikipedia://en/2823) can be considered as a multivalued function. The antiderivative of a function is the set of functions whose derivative is that function. The [constant of integration](wikipedia://en/147939) follows from the fact that the derivative of a constant function is 0.
- [Inverse hyperbolic functions](wikipedia://en/3804557) over the complex domain are multiple-valued because hyperbolic functions are periodic along the imaginary axis. Over the reals, they are single-valued, except for arcosh and arsech.

These are all examples of multivalued functions that come about from non-[injective functions](wikipedia://en/45196). Since the original functions do not preserve all the information of their inputs, they are not reversible. Often, the restriction of a multivalued function is a [partial inverse](https://en.wikipedia.org/wiki/Partial_inverse) of the original function.

## Branch points {#Branch_points}

Branch point Multivalued functions of a complex variable have [branch points](wikipedia://en/483173). For example, for the *n*th root and logarithm functions, 0 is a branch point; for the arctangent function, the imaginary units *i* and −*i* are branch points. Using the branch points, these functions may be redefined to be single-valued functions, by restricting the range. A suitable interval may be found through use of a [branch cut](https://en.wikipedia.org/wiki/Branch_cut), a kind of curve that connects pairs of branch points, thus reducing the multilayered [Riemann surface](wikipedia://en/173181) of the function to a single layer. As in the case with real functions, the restricted range may be called the *principal branch* of the function.

## Applications {#Applications}

In physics, multivalued functions play an increasingly important role. They form the mathematical basis for [Dirac](wikipedia://en/24742)'s [magnetic monopoles](wikipedia://en/175470), for the theory of [defects](https://en.wikipedia.org/wiki/Crystallographic_defect) in crystals and the resulting [plasticity](wikipedia://en/240123) of materials, for [vortices](https://en.wikipedia.org/wiki/Vortex) in [superfluids](https://en.wikipedia.org/wiki/Superfluid) and [superconductors](https://en.wikipedia.org/wiki/Superconductor), and for [phase transitions](wikipedia://en/54423) in these systems, for instance [melting](https://en.wikipedia.org/wiki/Melting) and [quark confinement](https://en.wikipedia.org/wiki/Quark_confinement). They are the origin of [gauge field](https://en.wikipedia.org/wiki/Gauge_field) structures in many branches of physics.
