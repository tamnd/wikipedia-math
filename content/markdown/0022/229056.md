# Truncation

::: {#o1 .subject cue=lead name="Truncation"}

In [mathematics](wikipedia://en/18831) and [computer science](https://en.wikipedia.org/wiki/Computer_science), **truncation** is limiting the number of [digits](wikipedia://en/280582) right of the [decimal point](https://en.wikipedia.org/wiki/Decimal_point).

:::

## Truncation and floor function {#Truncation_and_floor_function}

Truncation of positive real numbers can be done using the [floor function](https://en.wikipedia.org/wiki/Floor_function). Given a number $x \in \mathbb{R}_+$ to be truncated and $n \in \mathbb{N}_0$, the number of elements to be kept behind the decimal point, the truncated value of x is

$$\operatorname{trunc}(x,n) = \frac{\lfloor 10^n \cdot x \rfloor}{10^n}.$$

However, for negative numbers truncation does not round in the same direction as the floor function: truncation always rounds toward zero, the $\operatorname{floor}$ function rounds towards negative infinity. For a given number $x \in \mathbb{R}_-$, the function $\operatorname{ceil}$ is used instead

$$\operatorname{trunc}(x,n) = \frac{\lceil 10^n \cdot x \rceil}{10^n}.$$

## Causes of truncation {#Causes_of_truncation}

With computers, truncation can occur when a decimal number is [typecast](https://en.wikipedia.org/wiki/Type_conversion) as an [integer](wikipedia://en/14563); it is truncated to zero decimal digits because integers cannot store non-integer [real numbers](https://en.wikipedia.org/wiki/Real_numbers).

## In algebra {#In_algebra}

An analogue of truncation can be applied to [polynomials](wikipedia://en/23000). In this case, the truncation of a polynomial *P* to degree *n* can be defined as the sum of all terms of *P* of degree *n* or less. Polynomial truncations arise in the study of [Taylor polynomials](https://en.wikipedia.org/wiki/Taylor_polynomial), for example.[^o5]
