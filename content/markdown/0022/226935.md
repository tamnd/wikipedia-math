# Yates's correction for continuity

::: {#o1 .subject cue=lead name="Yates's correction for continuity"}

In [statistics](wikipedia://en/26685), **Yates's correction for continuity** (or **Yates's chi-squared test**) is a [statistical test](https://en.wikipedia.org/wiki/Statistical_test) commonly used when analyzing count data organized in a [contingency table](wikipedia://en/935515), particularly when sample sizes are small. It is specifically designed for testing whether two [categorical variables](wikipedia://en/821165) are related or [independent](wikipedia://en/27593) of each other. The correction modifies the standard [chi-squared test](wikipedia://en/226680) to account for the fact that a continuous distribution ([chi-squared](wikipedia://en/113424)) is used to approximate discrete data. Almost exclusively applied to 2×2 contingency tables, it involves subtracting 0.5 from the absolute difference between observed and expected frequencies before squaring the result.

:::

Unlike the standard [Pearson chi-squared statistic](wikipedia://en/226676), Yates's correction is approximately [unbiased](wikipedia://en/8450479) for small sample sizes. It is considered more conservative than the uncorrected chi-squared test, as it increases the [p-value](wikipedia://en/554994) and thus reduces the likelihood of rejecting the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) when it is true. While widely taught in introductory [statistics](wikipedia://en/26685) courses, modern [computational methods](https://en.wikipedia.org/wiki/Statistical_computing) like [Fisher's exact test](wikipedia://en/819467) may be preferred for analyzing small samples in 2×2 tables, with Yates's correction serving as a middle ground between uncorrected chi-squared tests and Fisher's exact test.

The correction was first published by [Frank Yates](wikipedia://en/165733) in 1934.[^o3]

## Correction for approximation error {#Correction_for_approximation_error}

Using the [chi-squared distribution](wikipedia://en/113424) to interpret [Pearson's chi-squared statistic](wikipedia://en/226676) requires one to assume that the [discrete](https://en.wikipedia.org/wiki/Discrete_probability_distribution) probability of observed [binomial frequencies](wikipedia://en/3876) in the table can be approximated by the continuous [chi-squared distribution](wikipedia://en/113424). This assumption is not quite correct, and introduces some error.

To reduce the error in approximation, [Frank Yates](wikipedia://en/165733), an [English](https://en.wikipedia.org/wiki/England) [statistician](wikipedia://en/48661), suggested a correction for continuity that adjusts the formula for [Pearson's chi-squared test](wikipedia://en/226676) by subtracting 0.5 from the difference between each observed value and its expected value in a 2 × 2 contingency table.[^o3] This reduces the chi-squared value obtained and thus increases its [p-value](wikipedia://en/554994).

The effect of Yates's correction is to prevent overestimation of statistical significance for small data. This formula is chiefly used when at least one cell of the table has an expected count smaller than 5.

$$\sum_{i=1}^N O_i = 20 \,$$

The following is Yates's corrected version of [Pearson's chi-squared statistics](wikipedia://en/226676):

$$\chi_\text{Yates}^2 = \sum_{i=1}^{N} {(|O_i - E_i| - 0.5)^2 \over E_i}$$

where:

*O<sub>i</sub>* = an observed frequency

*E<sub>i</sub>* = an expected (theoretical) frequency, asserted by the null hypothesis

*N* = number of distinct events

## 2 × 2 table {#2_×_2_table}

As a short-cut, for a 2 × 2 table with the following entries:

::: {#o5 .table cue=table}

|  | S | F |  |
|---|---|---|---|
| A | *a* | *b* | a+b |
| B | *c* | *d* | c+d |
|  | a+c | b+d | *N* |

:::

$$\chi_\text{Yates}^2 = \frac{N(|ad - bc| - N/2)^2}{(a+b) (c+d) (a+c) (b+d)}.$$

In some cases, this is better.

$$\chi_\text{Yates}^2 = \frac{N( \max(0, |ad - bc| - N/2) )^2}{N_S N_F N_A N_B}.$$

Yates's correction should always be applied, as it will tend to improve the accuracy of the p-value obtained. However, in situations with large sample sizes, using the correction will have little effect on the value of the test statistic, and hence the p-value.
