# Image plane

::: {#o1 .subject cue=lead name="Image plane"}

In [3D computer graphics](https://en.wikipedia.org/wiki/3D_computer_graphics), the **image plane**, also called **screen space**, is that [plane in the world](wikipedia://en/84029) which corresponds to the [display monitor](https://en.wikipedia.org/wiki/Display_monitor) used to view the image that is being [rendered](https://en.wikipedia.org/wiki/3D_rendering). If one makes the analogy of taking a [photograph](https://en.wikipedia.org/wiki/Photograph) to [rendering](https://en.wikipedia.org/wiki/Rendering_%28computer_graphics%29) a 3D image, the surface of the [film](https://en.wikipedia.org/wiki/Photographic_film) (or the [image sensor](https://en.wikipedia.org/wiki/Image_sensor)) is the image plane. In this case, the [viewing transformation](https://en.wikipedia.org/wiki/Viewing_transformation) is a [projection](wikipedia://en/313741) that maps the world onto the image plane. A rectangular region of this plane, called the viewing window or [viewport](https://en.wikipedia.org/wiki/Viewport), maps to the monitor. This establishes the mapping between [pixels](https://en.wikipedia.org/wiki/Pixels) on the monitor and points (or rather, [rays](https://en.wikipedia.org/wiki/Ray_%28geometry%29)) in the 3D world. The plane is not usually an actual [geometric object](https://en.wikipedia.org/wiki/Geometric_object) in a [3D scene](https://en.wikipedia.org/wiki/3D_scene), but instead is usually a collection of target coordinates or dimensions that are used during the [rasterization](https://en.wikipedia.org/wiki/Rasterization) process so the final output can be displayed as intended on the physical screen.

:::

In [optics](https://en.wikipedia.org/wiki/Optics), the image plane is the plane that contains the object's projected image, and lies beyond the back [focal plane](https://en.wikipedia.org/wiki/Focal_plane).[^o2]
