# Boolean satisfiability algorithm heuristics

::: {#o1 .subject cue=lead name="Boolean satisfiability algorithm heuristics"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), there are certain classes of algorithms ([heuristics](wikipedia://en/14220429)) that solves types of the [Boolean satisfiability problem](wikipedia://en/4715) despite there being [no known efficient algorithm](wikipedia://en/6115) in the general case.

:::

## Overview {#Overview}

The Boolean satisfiability (or SAT) problem can be stated formally as: given a Boolean expression $B$ with variables $V = \{v_0, \ldots , v_n\}$, finding an assignment $V^*$ of the variables such that $B(V^*)$ is true. It is seen as the canonical [NP-complete](https://en.wikipedia.org/wiki/NP-complete) problem. Although no known algorithm is known to solve SAT in polynomial time, there are classes of SAT problems which do have efficient algorithms that solve them.

The classes of problems amenable to SAT heuristics arise from many practical problems in [AI planning](https://en.wikipedia.org/wiki/AI_planning), [circuit testing](wikipedia://en/34599223), and [software verification](https://en.wikipedia.org/wiki/Software_verification).[^o3][^o4] Research on constructing efficient SAT solvers has been based on various principles such as [resolution](wikipedia://en/2724082), search, local search and [random walk](wikipedia://en/235451), binary decisions, and Stalmarck's algorithm.[^o4] Some of these algorithms are [deterministic](https://en.wikipedia.org/wiki/Deterministic_algorithm), while others may be [stochastic](wikipedia://en/495383).

As there exist polynomial-time algorithms to convert any [Boolean expression](wikipedia://en/3126968) to [conjunctive normal form](wikipedia://en/73342) (such as [Tseitin's algorithm](https://en.wikipedia.org/wiki/Tseytin_transformation)), posing SAT problems in CNF does not change their computational difficulty. SAT problems are canonically expressed in CNF because CNF has certain properties that can help prune the search space and speed up the search process.[^o4]

## Branching heuristics in conflict-driven algorithms {#Branching_heuristics_in_conflict-driven_algorithms}

One of the cornerstone SAT-solver algorithms is the [DPLL algorithm](wikipedia://en/2745094).[^o4] The algorithm works by iteratively assigning free variables, and when the algorithm encounters a bad assignment, it backtracks to a previous iteration and chooses a different assignment of variables. It relies on a *branching heuristic* to pick the next free variable assignment; the branching algorithm effectively makes choosing the variable assignment into a decision tree. Different implementations of this heuristic produce markedly different decision trees, and thus have significant effect on the efficiency of the solver.

### Early branching heuristics {#Early_branching_heuristics}

Heuristics such as *Bohm's heuristic*, *maximum occurrences on minimum-sized clauses*, and the *Jeroslow-Wang heuristic* can be regarded as [greedy algorithms](https://en.wikipedia.org/wiki/Greedy_algorithms). Their basic premise is to choose a free-variable assignment that will satisfy the most already-unsatisfied clauses in the Boolean expression. However, as Boolean expressions get larger, more complicated, or more structured, these heuristics fail to capture useful information about these problems that could improve efficiency; they often get stuck in local maxima or do not consider the distribution of variables. Additionally, larger problems require more processing, as the operation of counting free variables in unsatisfied clauses dominates the run time.

### Variable state-independent decaying sum {#Variable_state-independent_decaying_sum}

An influential heuristic called *variable state-independent decaying sum* (VSIDS) attempts to score each variable. VSIDS grades variables by their presence in conflicts and learned clauses, and selects the highest-graded variable to make the next decision from. To prioritize recent conflicts over older ones, it periodically decays each variable's score by some constant.

VSIDS is quite effective because the scores of variable phases are independent of the current variable assignment, so [backtracking](https://en.wikipedia.org/wiki/Backtracking) is much easier. Further, VSIDS guarantees that each variable assignment satisfies the greatest number of recently searched segments of the Boolean expression.

## Stochastic solvers {#Stochastic_solvers}

For [MAX-SAT](https://en.wikipedia.org/wiki/MAX-SAT), the version of SAT in which the number of satisfied clauses is maximized, solvers also use probabilistic algorithms.[^o9] If we are given a Boolean expression $B$ with variables $V = \{v_0, \ldots , v_n\}$, and we set each variable randomly, then for each clause $c$, with $|c|$ variables, the chance of $B$ being satisfied by a particular variable assignment is

$$\operatorname{Pr}(c\text{ is satisfied}) = 1 - 2^{-|c|}.$$

This is because each variable in $c$ has probability $\tfrac{1}{2}$ of being satisfied, and we only need one variable in $c$ to be satisfied. This works for all $|c| \geq 1$, so

$$\operatorname{Pr}(c\text{ is satisfied}) = 1 - 2^{-|c|} \geq \frac{1}{2}.$$

Now we show that randomly assigning variable values is a $\tfrac{1}{2}$-[approximation algorithm](wikipedia://en/563105), which means that is an optimal approximation algorithm unless P = NP. Suppose we are given a Boolean expression $B = \{c_i\}_{i=1}^n$ and

$$\delta_{ij} = \begin{cases} 0 &\text{if } c_i \text{ is satisfied}, \\ 1 &\text{if } c_i \text{ is not satisfied}. \end{cases}$$

Then we have that

$$\begin{aligned} E[\text{Num Clauses Satisfied}] & = \sum_i E[\delta_i] = \sum_{i} 1-2^{-|c_i|} \\ & \geq \sum_i \frac{1}{2} = \frac{1}{2}|i| = \frac{1}{2} OPT. \end{aligned}$$

This algorithm cannot be further optimized by the [PCP theorem](wikipedia://en/3001241) unless P = NP.

Other stochastic SAT solvers, such as [WalkSAT](wikipedia://en/2853246) and [GSAT](https://en.wikipedia.org/wiki/GSAT) are an improvement to the above procedure. They start by randomly assigning values to each variable and then traverse the given Boolean expression to identify which variables to flip to minimize the number of unsatisfied clauses. They may randomly select a variable to flip or select a new [random variable](wikipedia://en/25685) assignment to escape local maxima, much like a [simulated annealing](wikipedia://en/172244) algorithm.

## Weighted SAT problems {#Weighted_SAT_problems}

Numerous weighted SAT problems exist as [optimization versions](wikipedia://en/1126536) of the general SAT problem. In this class of problems, each clause in a CNF Boolean expression is given a weight. The objective is the maximize or minimize the total sum of the weights of the satisfied clauses given a Boolean expression. Weighted Max-SAT is the maximization version of this problem, and [Max-SAT](https://en.wikipedia.org/wiki/Maximum_satisfiability_problem) is an instance of weighted MAX-SAT problem where the weights of each clause are the same. The partial Max-SAT problem is the problem where some clauses necessarily must be satisfied (hard clauses) and the sum total of weights of the rest of the clauses (soft clauses) are to be maximized or minimized, depending on the problem. Partial Max-SAT represents an intermediary between Max-SAT (all clauses are soft) and SAT (all clauses are hard).

Stochastic probabilistic solvers can also be used to find approximations for Max-SAT.

### Variable splitting {#Variable_splitting}

Variable splitting is a tool to find [upper and lower bounds](wikipedia://en/42693) on a Max-SAT problem. It involves splitting a variable $a$ into new variables for all but one occurrence of $a$ in the original Boolean expression. For example, the Boolean expression

> $$B = (a \lor b \lor c) \wedge (\neg a \lor e \lor \neg b) \wedge (a \lor \neg c \lor f)$$

becomes

> $$B^* = (a \lor b \lor c) \wedge (\neg a_1 \lor e \lor \neg b) \wedge (a_2 \lor \neg c \lor f),$$

with $a,a_1,a_2,\ldots,a_n$ being all distinct variables.

This relaxes the problem by introducing new variables into the Boolean expression,[^o12] which has the effect of removing many of the constraints in the expression. Because any assignment of variables in $B$ can be represented by an assignment of variables in $B^*$, the minimization and maximization of the weights of $B^*$ represent lower and upper bounds on the minimization and maximization of the weights of $B$.

### Partial Max-SAT {#Partial_Max-SAT}

Partial Max-SAT can be solved by first considering all of the hard clauses and solving them as an instance of SAT. The total maximum (or minimum) weight of the soft clauses can be evaluated given the variable assignment necessary to satisfy the hard clauses and trying to optimize the free variables (the variables that the satisfaction of the hard clauses does not depend on). The latter step is an implementation of Max-SAT given some pre-defined variables. Of course, different variable assignments that satisfy the hard clauses might have different optimal free variable assignments, so it is necessary to check different hard-clause satisfaction variable assignments.

## Data structures for storing clauses {#Data_structures_for_storing_clauses}

As SAT solvers and practical SAT problems (e.g. circuit verification) get more advanced, the Boolean expressions of interest may exceed millions of variables with several million clauses; therefore, efficient data structures to store and evaluate the clauses must be used.[^o4]

Expressions can be stored as a list of clauses, where each clause is a list of variables, much like an [adjacency list](wikipedia://en/392431). Though these data structures are convenient for manipulation (adding elements, deleting elements, etc.), they rely on many pointers, which increases their memory overhead, decreases [cache locality](https://en.wikipedia.org/wiki/Cache_locality), and increases [cache misses](https://en.wikipedia.org/wiki/Cache_misses), which renders them impractical for problems with large clause counts and large clause sizes.

When clause sizes are large, more-efficient analogous implementations include storing expressions as a list of clauses, where each clause is represented as a matrix that represents the clauses and the variables present in that clause, much like an [adjacency matrix](wikipedia://en/244463). The elimination of pointers and the contiguous memory occupation of arrays serve to decrease memory usage and increase cache locality and cache hits, which offers a run-time speedup compared to the aforesaid implementation.
