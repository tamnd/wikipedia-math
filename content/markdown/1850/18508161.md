# Gauss–Kronrod quadrature formula

::: {#o1 .subject cue=lead name="Gauss–Kronrod quadrature formula"}

The **Gauss–Kronrod quadrature formula** is an [adaptive method](wikipedia://en/8099744) for [numerical integration](wikipedia://en/170089). It is a variant of [Gaussian quadrature](wikipedia://en/50579), in which the evaluation points are chosen so that an accurate approximation can be computed by re-using the information produced by the computation of a less accurate approximation. It is an example of what is called a [nested quadrature rule](https://en.wikipedia.org/wiki/Nested_quadrature_rule): for the same set of function evaluation points, it has two quadrature rules, one higher order and one lower order (the latter called an *embedded* rule). The difference between these two approximations is used to estimate the calculational error of the integration. Like the [Gaussian quadrature](wikipedia://en/50579) method it is based on, Gauss-Kronrod curvature assumes the integrand is a polynomial and will not converge rapidly over intervals where the integrand is not infinitely smooth.

:::

These formulas are named after [Alexander Kronrod](https://en.wikipedia.org/wiki/Alexander_Kronrod), who invented them in the 1960s, and [Carl Friedrich Gauss](wikipedia://en/6125).

## Description {#Description}

The problem in numerical integration is to approximate definite integrals of the form

$$\int_a^b f(x)\,dx.$$

Such integrals can be approximated, for example, by *n*-point [Gaussian quadrature](wikipedia://en/50579)

$$\int_a^b f(x)\,dx \approx \sum_{i=1}^n w_i f(x_i),$$

where *w*<sub>*i*</sub>, are the [weights](wikipedia://en/245523) and *x*<sub>*i*</sub> are points at which to evaluate the function *f*(*x*).

If the interval \[*a*, *b*\] is subdivided, the Gauss evaluation points of the new subintervals never coincide with the previous evaluation points (except at the midpoint for odd numbers of evaluation points), and thus the integrand must be evaluated at every point. Gauss–Kronrod formulas are extensions of the Gauss quadrature formulas generated by adding $n+1$ points to an $n$-point rule in such a way that the resulting rule is exact for polynomials of degree less than or equal to $3n+1$ ((Laurie 1997, p. 1133); the corresponding Gauss rule is of order $2n-1$). These extra points are the zeros of [Stieltjes polynomials](wikipedia://en/32896001). This allows for computing higher-order estimates while reusing the function values of a lower-order estimate. The difference between a Gauss quadrature rule and its Kronrod extension is often used as an estimate of the approximation error.

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

A popular example combines a 7-point Gauss rule with a 15-point Kronrod rule (Kahaner Moler Nash 1989, §5.5). Because the Gauss points are incorporated into the Kronrod points, a total of only 15 function evaluations are needed.

The integral is then estimated by the Kronrod rule $K15$ and the error can be estimated as $|G7-K15|$.

For an arbitrary interval $[a,b]$ the node positions $x_i$ **and** weights $w_i$ are scaled to the interval as follows:

$$x_{i,\text{scaled}}=\frac{x_i+1}{2}(b-a)+a$$

$$w_{i,\text{scaled}}=w_i\frac{b-a}{2}$$

(Patterson 1968) showed how to find further extensions of this type, (Piessens Branders 1974) and (Monegato 1978) proposed improved [algorithms](wikipedia://en/775), and finally the most efficient algorithm was proposed by (Laurie 1997). Quadruple precision (34 decimal digits) coefficients for (G7, K15), (G10, K21), (G15, K31), (G20, K41) and others are computed and tabulated.[^o11]

## Implementations {#Implementations}

Routines for Gauss–Kronrod quadrature are provided by the [QUADPACK](https://en.wikipedia.org/wiki/QUADPACK) library, the [GNU Scientific Library](https://en.wikipedia.org/wiki/GNU_Scientific_Library), the [NAG Numerical Libraries](https://en.wikipedia.org/wiki/NAG_Numerical_Libraries), [R](wikipedia://en/376707),[^o14] the [C++](https://en.wikipedia.org/wiki/C++) library [Boost](https://en.wikipedia.org/wiki/Boost_%28C++_libraries%29).,[^o15] as well as the [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29) package QuadGK.jl[^o16] (which can compute Gauss–Kronrod formulas to [arbitrary precision](wikipedia://en/600892)).
