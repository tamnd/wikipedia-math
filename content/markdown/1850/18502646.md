# Hutchinson operator

::: {#o1 .subject cue=lead name="Hutchinson operator"}

In [mathematics](wikipedia://en/18831), in the study of [fractals](wikipedia://en/10913), a **Hutchinson operator**[^o2] is the collective action of a set of contractions, called an [iterated function system](wikipedia://en/505225).[^o3] The [iteration](wikipedia://en/1448702) of the operator converges to a unique [attractor](wikipedia://en/191094), which is the often [self-similar](https://en.wikipedia.org/wiki/Self-similar) fixed set of the operator.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\{f_i : X \to X\ |\ 1\leq i \leq N\}$ be an [iterated function system](wikipedia://en/505225), or a [set](wikipedia://en/26691) of [contractions](wikipedia://en/6239) from a [compact set](https://en.wikipedia.org/wiki/Compact_set) $X$ to itself. The operator $H$ is defined over subsets $S\subset X$ as

$$H(S) = \bigcup_{i=1}^N f_i(S).\,$$

A key question is to describe the attractors $A=H(A)$ of this operator, which are compact sets. One way of generating such a set is to start with an initial compact set $S_0\subset X$ (which can be a single point, called a seed) and iterate $H$ as follows

$$S_{n+1} = H(S_n) = \bigcup_{i=1}^N f_i(S_n)$$

and taking the limit, the iteration converges to the attractor

$$A = \lim_{n \to \infty} S_n .$$

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Hutchinson showed in 1981 the existence and uniqueness of the attractor $A$. The proof follows by showing that the Hutchinson operator is contractive on the set of compact subsets of $X$ in the [Hausdorff distance](wikipedia://en/429296).

The collection of functions $f_i$ together with composition form a [monoid](wikipedia://en/19652). With *N* functions, then one may visualize the monoid as a full [N-ary tree](https://en.wikipedia.org/wiki/K-ary_tree) or a [Cayley tree](https://en.wikipedia.org/wiki/Cayley_tree).

:::
