# Partial groupoid

::: {#o1 .subject cue=lead name="Partial groupoid"}

In [abstract algebra](wikipedia://en/19616384), a **partial [groupoid](wikipedia://en/141916)** (also called **halfgroupoid**, **pargoid**, or **partial magma**) is a set endowed with a [partial binary operation](wikipedia://en/3948#Terminology).[^o2][^o3]

:::

A partial groupoid is a [partial algebra](wikipedia://en/43662761).

## Partial semigroup {#Partial_semigroup}

A partial groupoid $(G,\circ)$ is called a **partial semigroup** if the following [associative law](https://en.wikipedia.org/wiki/Associative_law) holds:[^o5]

For all $x,y,z \in G$ such that $x\circ y\in G$ and $y\circ z\in G$, the following two statements hold:

1. $x \circ (y \circ z) \in G$ if and only if $( x \circ y) \circ z \in G$, and
1. $x \circ (y \circ z ) = ( x \circ y) \circ z$ if $x \circ (y \circ z) \in G$ (and, because of 1., also $( x \circ y) \circ z \in G$).
