# Darboux differential equation

::: {#o1 .subject cue=lead name="Darboux differential equation"}

In mathematics, a [differential equation](wikipedia://en/1424309) is called **Darboux differential equation** if it satisfies the form

:::

$M(x, y) dx - L(x, y) dy + N(x, y) (x dy - y dx) = 0$.[^o2]

where $M(x, y)$, $L(x, y)$ and $N(x, y)$ are polynomials of $x$ and $y$.

The [explicit](wikipedia://en/32742753) form of this equation is

$y'(x) = \frac {y N(x, y) - M(x, y)} {x N(x, y) - L(x, y)}$.[^o3]

which, compared to the aforementioned form, may also include [equillibrium points](wikipedia://en/1441435), which must satisfy the following:

$$\begin{cases} y L(x, y) - x M(x, y) = 0 \\ L = x N(x, y) \end{cases}$$

## The solution {#The_solution}

### General case {#General_case}

Source:[^o2]

Since the Darboux equation is effectively the gereralization of the [Riccati equation](wikipedia://en/304999), the solution to it, generally speaking, cannot be found in quadratures. Darboux equation can be solved in very specific cases where certain amount of [particular](https://en.wikipedia.org/wiki/Particular_solution) irreducable polynomial solutions $\check{P}_{i}(x, y)$, $1 \leqslant i \leqslant p$ are found. Let $m = \max(\deg M, \deg L, \deg N)$.

#### Case 1. {#Case_1.}

If $p \geqslant \frac {1} {2} m (m + 1) + 2$, the general solution has the form of $u(x, y) = C$, where $u(x, y) = \prod_{i=1}^p {g(x, y, z)^{\alpha_{i}}}$, $g_{i}(x, y, z) = \check{P}_{i}\left( \frac {x} {z}, \frac {y} {z} \right) z^{\deg \check{P}_{i}}$, $\alpha_{i}$ are constants to be determined and variable $z$ in this product vanishes.

#### Case 2. {#Case_2.}

If $p = \frac {1} {2} m (m + 1) + 1$, given Darboux equation allows the [integrating factor](wikipedia://en/1912874) to be found. This factor has the exact form, as the $u(x, y)$ above.

### Homogenous case. {#Homogenous_case.}

If three polynomials $M(x, y)$, $L(x, y)$ and $N(x, y)$ happen to be [homogenous](wikipedia://en/1698977) and $M(x, y)$ with $L(x, y)$ are of the same degree, the exact solution can be expressed and found in quadratures.[^o3]

Denote $\deg M = \deg L = k$, $\deg N = n$.

Case, where $k - n = 1$, makes whole equation [homogenous](wikipedia://en/6954092).

In any other situation substituting $y(x) = x t(x)$ leads to the equation of [Bernoulli](wikipedia://en/1911217) type over the [inverse function](wikipedia://en/14907) $x = x(t)$.

Since $M(x, y)$, $L(x, y)$ and $N(x, y)$ are homogenous with degrees $k$, $k$ and $n$ respectively, there exist polynomials $\mu(t)$, $\lambda(t)$ and $\nu(t)$, such as

$M(x, y) = x^{k} \mu\left(\frac {y} {x}\right) = x^{k} \mu(t)$, $L(x, y) = x^{k} \lambda\left(\frac {y} {x}\right) = x^{k} \lambda(t)$, and $N(x, y) = x^{n} \nu\left(\frac {y} {x}\right) = x^{n} \nu(t)$.

Putting everything together yields $x t'(x) = \frac {x^{n + 1} t \nu(t) - x^{k} \mu(t)} {x^{n + 1} \nu(t) - x^{k}\nu(t)} - t = \frac {x^{k} \big( \lambda(t) - \mu(t) \big)} {x^{n + 1} \nu(t) - x^{k} \lambda(t)} = \frac {\lambda(t) - \mu(t)} {x^{n + 1 - k} \nu(t) - \lambda(t)}$.

If $k - n = 1$ the resulting equation is [separable](wikipedia://en/387750), while in any other case, according to the [inverse function rule](wikipedia://en/148064),

$$x'(t) + \frac {\lambda(t)} {\lambda(t) - \mu(t)} x(t) = \frac {\nu(t)} {\lambda(t) - \mu(t)} \big(x(t)\big)^{n + 2 - k}.$$

The latter is the Bernoulli equation, which is always integrable in quadratures.

## Generalized Darboux equation {#Generalized_Darboux_equation}

The differential equation is called **generalized (homogenous) Darboux equation**[^o10] if it has the form of

$$\phi\left( \frac {y} {x} \right) dx + \psi \left( \frac {y} {x} \right) dy + x^{k} \chi \left( \frac {y} {x} \right) (x dy - y dx) = 0$$

where functions $\phi( \frac {y} {x}) = \phi(t)$, $\psi( \frac {y} {x}) = \psi(t)$ and $\chi( \frac {y} {x}) = \chi(t)$ are arbitrary.

It can be reduced to [Bernoulli equation](wikipedia://en/1911217) by following the same approach, mentioned above. Substituting $y(x) = x t(x)$ leads to the equation

$$\big( \phi(t) + t \psi(t) \big) dx + \big( x\psi(t) + x^{k + 2} \chi(t) \big) dt = 0$$

or in the explicit form

$$x'(t) + \frac {\psi(t)} {\phi(t) + t \psi(t)} x(t) + \frac {\chi(t)} {\phi(t) + t \psi(t)} \big(x(t)\big)^{k + 2} = 0$$

which is either separable if $k = -2$, or the Bernoulli equation over $x = x(t)$ otherwise.
