# Glaeser's composition theorem

::: {#o1 .subject cue=lead name="Glaeser's composition theorem"}

In [mathematics](wikipedia://en/18831), **Glaeser's theorem**, introduced by (txt), is a theorem giving conditions for a [smooth function](https://en.wikipedia.org/wiki/Smooth_function) to be a [composition](wikipedia://en/195947) of *F* and θ for some given smooth function θ. One consequence is a generalization of [Newton's theorem](https://en.wikipedia.org/wiki/Newton's_theorem_on_symmetric_polynomials) that every [symmetric polynomial](wikipedia://en/1440207) is a [polynomial](wikipedia://en/23000) in the [elementary symmetric polynomials](wikipedia://en/1440695), from polynomials to smooth functions.

:::
