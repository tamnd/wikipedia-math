# Morphism of algebraic stacks

::: {#o1 .subject cue=lead name="Morphism of algebraic stacks"}

In [algebraic geometry](wikipedia://en/1997), given [algebraic stacks](wikipedia://en/717377) $p: X \to C, \, q: Y \to C$ over a base [category](wikipedia://en/53759) *C*, a **morphism $f: X \to Y$ of algebraic stacks** is a [functor](wikipedia://en/10987) such that $q \circ f = p$.

:::

More generally, one can also consider a morphism between [prestacks](wikipedia://en/39547490#Morphisms) (a stackification would be an example).

::: {#o3 .pointer-item cue=pointer name="Smooth stack"}

## Types {#Types}

One particular important example is a presentation of a stack, which is widely used in the study of stacks.

An algebraic stack *X* is said to be **smooth** of dimension *n* - *j* if there is a smooth presentation $U \to X$ of relative dimension *j* for some [smooth scheme](wikipedia://en/35033819) *U* of dimension *n*. For example, if $\operatorname{Vect}_n$ denotes the [moduli stack of rank-*n* vector bundles](wikipedia://en/54274216), then there is a presentation $\operatorname{Spec}(k) \to \operatorname{Vect}_n$ given by the trivial bundle $\mathbb{A}^n_k$ over $\operatorname{Spec}(k)$.

A **quasi-affine morphism** between [algebraic stacks](wikipedia://en/717377) is a morphism that factorizes as a [quasi-compact](wikipedia://en/12410777) [open immersion](https://en.wikipedia.org/wiki/Open_immersion) followed by an [affine morphism](https://en.wikipedia.org/wiki/Affine_morphism).[^o4]

:::
