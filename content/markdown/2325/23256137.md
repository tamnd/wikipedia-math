# Arf ring

::: {#o1 .subject cue=lead name="Arf ring"}

In [mathematics](wikipedia://en/18831), an **Arf ring** was defined by (Lipman 1971) to be a 1-[dimensional](wikipedia://en/56079) [commutative](wikipedia://en/61346) [semi-local](wikipedia://en/977725) [Macaulay](wikipedia://en/497407) [ring](wikipedia://en/48404) satisfying some extra conditions studied by (txt).

:::
