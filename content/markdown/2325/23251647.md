# Continuity set

::: {#o1 .subject cue=lead name="Continuity set"}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), a branch of [mathematics](wikipedia://en/18831), a **continuity set** of a [measure](wikipedia://en/19873) $\mu$ is any [Borel set](wikipedia://en/43327) $B$ such that

$$\mu(\partial B) = 0,$$

where $\partial B$ is the (topological) [boundary](wikipedia://en/72824) of $B$. For [signed measures](wikipedia://en/2985811), one instead asks that

$$|\mu|(\partial B) = 0.$$

:::

The collection of all continuity sets for a given measure $\mu$ forms a [ring of sets](wikipedia://en/2686481).[^o2]

Similarly, for a [random variable](wikipedia://en/25685) $X$, a set $B$ is called a **continuity set** of $X$ if

$$\Pr[X \in \partial B] = 0.$$

## Continuity set of a function {#Continuity_set_of_a_function}

The **continuity set** $C(f)$ of a [function](wikipedia://en/185427) $f$ is the set of points where $f$ is [continuous](wikipedia://en/6122).
