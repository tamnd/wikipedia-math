# Matroid intersection

::: {#o1 .subject cue=lead name="Matroid intersection"}

In [combinatorial optimization](wikipedia://en/420555), the **matroid intersection** problem is to find a largest common independent set in two [matroids](wikipedia://en/244321) over the same ground set. If the elements of the matroid are assigned real weights, the **weighted matroid intersection** problem is to find a common independent set with the maximum possible weight. These problems generalize many problems in graph theory and combinatorial optimization including finding [maximum matchings](https://en.wikipedia.org/wiki/Maximum_matching) and [maximum weight matchings](https://en.wikipedia.org/wiki/Maximum_weight_matching) in [bipartite graphs](wikipedia://en/244431) and finding [arborescences](wikipedia://en/13251077) in [directed graphs](wikipedia://en/19721986).

:::

The **matroid intersection theorem**, due to [Jack Edmonds](wikipedia://en/3625459),[^o2] says that for any two matroids $M_1 = (E, \mathcal I_1)$ and $M_2 = (E, \mathcal I_2)$ we have

$$\max_{I\in\mathcal I_1\cap\mathcal I_2} |I| = \min_{A\subseteq E}(r_1(A)+r_2(E\setminus A))$$

where $r_1$ and $r_2$ are the respective rank functions of $M_1$ and $M_2$. In other words, there is always a simple upper bound proof, consisting of a partitioning of the ground set amongst the two matroids, whose value (the sum of the respective [ranks](wikipedia://en/37123010)) equals the size of a maximum common independent set.

Based on this theorem, the matroid intersection problem for two matroids can be solved in polynomial time using [matroid partitioning](wikipedia://en/36950801) algorithms.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Let *G* = (*U*,*V*;*E*) be a [bipartite graph](wikipedia://en/244431). One may define a [partition matroid](wikipedia://en/36780298) *M<sub>U</sub>* on the ground set *E*, in which a set of edges is independent if no two of the edges have the same endpoint in *U*. Similarly one may define a matroid *M<sub>V</sub>* in which a set of edges is independent if no two of the edges have the same endpoint in *V*. Any set of edges that is independent in both *M<sub>U</sub>* and *M<sub>V</sub>* has the property that no two of its edges share an endpoint; that is, it is a [matching](wikipedia://en/581797). Thus, the largest common independent set of *M<sub>U</sub>* and *M<sub>V</sub>* is a [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching) in *G*.

Similarly, if each edge has a weight, then the maximum-weight independent set of *M<sub>U</sub>* and *M<sub>V</sub>* is a [Maximum weight matching](https://en.wikipedia.org/wiki/Maximum_weight_matching) in *G*.

## Algorithms {#Algorithms}

There are several polynomial-time algorithms for weighted matroid intersection, with different run-times. The run-times are given in terms of $n$ - the number of elements in the common base-set, $r$ - the maximum between the ranks of the two matroids, $T$ - the number of operations required for a [circuit-finding oracle](https://en.wikipedia.org/wiki/Circuit-finding_oracle), and $k$ - the number of elements in the intersection (in case we want to find an intersection of a specific size $k$).

- [Edmonds](wikipedia://en/3625459)' algorithm uses [linear programming](wikipedia://en/43730) and polyhedra.[^o2]
- [Lawler](https://en.wikipedia.org/wiki/Eugene_Lawler)'s algorithm.[^o7]
- Iri and Tomizawa's algorithm[^o8]
- [Andras Frank](wikipedia://en/22912777)'s algorithm[^o9] uses $O(n ^3 T)$ arithmetic operations.
- [Orlin](https://en.wikipedia.org/wiki/James_B._Orlin) and Vande-Vate's algorithm.[^o10]
- Cunningham's algorithm[^o11] requires $O(r^{1.5}n T)$ operations on general matroids, and $O(n r^{2} \log{r})$ operations on [linear matroid](https://en.wikipedia.org/wiki/Linear_matroid), for two *r*-by-*n* matrices.
- Brezovec, Cornuejos and Glover[^o12] present two algorithms for weighted matroid intersection.
  - The first algorithm requires that all weights be integers, and finds an intersection of cardinality $k$ in time $O((n^3 k^2 + n k T)\cdot(1+\log{W}))$.
  - The second algorithm runs in time $O(n r \cdot (\log{n}+r+T))$.
- Huang, Kakimura and Kamiyama[^o13] show that the weighted matroid intersection problem can be solved by solving *W* instances of the unweighted matroid intersection problem, where *W* is the largest given weight, assuming that all given weights are integral. This algorithm is faster than previous algorithms when *W* is small. They also present an [approximation algorithm](wikipedia://en/563105) that finds an *e*-approximate solution by solving $O(\epsilon^{-1}\log {r})$ instances of the unweighted matroid intersection problem, where *r* is the smaller rank of the two input matroids.
- Ghosh, Gurjar and Raj[^o14] study the run-time complexity of matroid intersection in the [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing) model.
- Bérczi, Király, Yamaguchi and Yokoi[^o15] present strongly polynomial-time algorithms for weighted matroid intersection using more restricted oracles.

## Extensions {#Extensions}

### Maximizing weight subject to cardinality {#Maximizing_weight_subject_to_cardinality}

In a variant of weighted matroid intersection, called "(P<sub>k</sub>)", the goal is to find a common independent set with the maximum possible weight among all such sets with cardinality *k*, if such a set exists. This variant, too, can be solved in polynomial time.[^o12]

### Three matroids {#Three_matroids}

The matroid intersection problem becomes [NP-hard](https://en.wikipedia.org/wiki/NP-hard) when three matroids are involved, instead of only two.

One proof of this hardness result uses a [reduction](wikipedia://en/848067) from the [Hamiltonian path](wikipedia://en/244437) problem in [directed graphs](wikipedia://en/19721986). Given a directed graph *G* with *n* vertices, and specified nodes *s* and *t*, the Hamiltonian path problem is the problem of determining whether there exists a simple path of length *n* − 1 that starts at *s* and ends at *t*. It may be assumed without loss of generality that *s* has no incoming edges and *t* has no outgoing edges. Then, a Hamiltonian path exists if and only if there is a set of *n* − 1 elements in the intersection of three matroids on the edge set of the graph: two partition matroids ensuring that the in-degree and out-degree of the selected edge set are both at most one, and the [graphic matroid](wikipedia://en/745714) of the [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) formed by forgetting the edge orientations in *G*, ensuring that the selected edge set has no cycles.[^o20]

### Matroid parity {#Matroid_parity}

Another computational problem on matroids, the [matroid parity problem](wikipedia://en/56069479), was formulated by Lawler[^o22] as a common generalization of matroid intersection and non-bipartite graph matching. However, although it can be solved in polynomial time for [linear matroids](https://en.wikipedia.org/wiki/Linear_matroid), it is NP-hard for other matroids, and requires exponential time in the [matroid oracle](wikipedia://en/36878315) model.[^o23]

### Valuated matroids {#Valuated_matroids}

A **valuated matroid** is a matroid equipped with a value function *v* on the set of its bases, with the following *exchange property*: for any two distinct bases $A$ and $B$, if $a\in A\setminus B$, then there exists an element $b\in B\setminus A$ such that both $(A \setminus \{ a \}) \cup \{b\}$ and $(B \setminus \{ b \}) \cup \{a\}$ are bases, and :$v(A)+v(B) \leq v(B \setminus \{ b \} \cup \{a\}) + v(A \setminus \{ a \} \cup \{b\})$.

Given a weighted [bipartite graph](wikipedia://en/244431) *G* = (*X*+*Y*, *E*) and two valuated matroids, one on *X* with bases set *B<sub>X</sub>* and valuation *v<sub>X</sub>*, and one on *Y* with bases *B<sub>Y</sub>* and valuation *v<sub>Y</sub>*, the **valuated independent assignment problem** is the problem of finding a matching *M* in *G*, such that *M<sub>X</sub>* (the subset of *X* matched by *M*) is a base in *B<sub>X</sub>*, *M<sub>Y</sub>* is a base in *B<sub>Y</sub>*, and subject to this, the sum $w(M) + v_X(M_X)+v_Y(M_Y)$ is maximized. The weighted matroid intersection problem is a special case in which the matroid valuations are constant, so we only seek to maximize $w(M)$ subject to *M<sub>X</sub>* is a base in *B<sub>X</sub>* and *M<sub>Y</sub>* is a base in *B<sub>Y</sub>* *.[^o25]* Murota presents a polynomial-time algorithm for this problem.[^o26]
