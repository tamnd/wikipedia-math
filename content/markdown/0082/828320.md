# Birkhoff's axioms

::: {#o1 .subject cue=lead name="Birkhoff's axioms"}

In 1932, [G. D. Birkhoff](wikipedia://en/30871906) created a set of four [postulates](https://en.wikipedia.org/wiki/Postulate) of [Euclidean geometry](wikipedia://en/9417) in the plane, sometimes referred to as **Birkhoff's axioms**.[^o2] These postulates are all based on basic [geometry](wikipedia://en/18973446) that can be confirmed experimentally with a [scale](https://en.wikipedia.org/wiki/Vernier_scale) and [protractor](https://en.wikipedia.org/wiki/Protractor). Since the postulates build upon the [real numbers](wikipedia://en/20646438), the approach is similar to a [model](wikipedia://en/19858)-based introduction to Euclidean geometry.

:::

Birkhoff's [axiomatic system](wikipedia://en/188401) was utilized in the secondary-school textbook by Birkhoff and Beatley.[^o3] These axioms were also modified by the [School Mathematics Study Group](wikipedia://en/1700591) to provide a new standard for teaching high school geometry, known as [SMSG axioms](https://web.archive.org/web/20130615062200/http://userpages.umbc.edu/~rcampbel/Math306/Axioms/SMSG.html). A few other textbooks in the [foundations of geometry](wikipedia://en/21317755) use variants of Birkhoff's axioms.[^o4]

## Birkhoff's four postulates {#Birkhoff's_four_postulates}

The distance between two points $A$ and $B$ is denoted by $d(A, B)$, and the angle formed by three points $A, B, C$ is denoted by $\angle ABC$.

**Postulate I: Postulate of line measure**. The set of points $\{A, B, ...\}$ on any line can be put into a 1:1 correspondence with the [real numbers](wikipedia://en/20646438) $\{a, b, ...\}$ so that $|b - a| = d(A, B)$ for all points $A$ and $B$.

**Postulate II: Point-line postulate**. There is one and only one line $\ell$ that contains any two given distinct points $P$ and $Q$.

**Postulate III: Postulate of angle measure**. The set of rays $\{\ell, m, n, ...\}$ through any point $O$ can be put into 1:1 correspondence with the real numbers $a\pmod{2\pi}$ so that if $A$ and $B$ are points (not equal to $O$) of $\ell$ and $m$, respectively, the difference $a_{m} - a_{\ell}\pmod{2\pi}$ of the numbers associated with the lines $\ell$ and $m$ is $\angle AOB$. Furthermore, if the point $B$ on $m$ varies [continuously](wikipedia://en/6122) in a line $r$ not containing the vertex $O$, the number $a_{m}$ varies continuously also.

**Postulate IV: Postulate of similarity**. Given two triangles $ABC$ and $A'B'C'$ and some constant $k > 0$ such that $d(A', B' ) = kd(A, B), d(A', C' ) = kd(A, C)$ and $\angle B'A'C' = \pm\angle BAC$, then $d(B', C' ) = kd(B, C), \angle C'B'A' = \pm\angle CBA$, and $\angle A'C'B' = \pm\angle ACB$.
