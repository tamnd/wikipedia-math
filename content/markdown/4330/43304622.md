# Graph realization problem

*Image: Conjugate-dessins.svg.* Two non-isomorphic graphs realized from the degree sequence (3, 2, 2, 2, 2, 1, 1, 1).

::: {#o1 .subject cue=lead name="Graph realization problem"}

The **graph realization problem** is a [decision problem](wikipedia://en/8336) in [graph theory](wikipedia://en/12401). Given a finite sequence $(d_1,\dots,d_n)$ of natural numbers, the problem asks whether there is a labeled [simple graph](wikipedia://en/325806) such that $(d_1,\dots,d_n)$ is the [degree sequence](https://en.wikipedia.org/wiki/Degree_sequence) of this graph.

:::

In the context of localization, the **graph realization problem** may also refer to finding a set of positions $(x_1,\dots,x_n)$ in some Euclidean space such that the squared distances between the positions, given by $d^2_{ij}$, match the edge weights $w_{ij}$ for all edges in an incomplete, undirected, weighted graph.[^o2]

## Solutions {#Solutions}

The problem can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time). One method of showing this uses the [Havel–Hakimi algorithm](wikipedia://en/43304405) constructing a special solution with the use of a [recursive algorithm](wikipedia://en/4044867).[^o4][^o5] Alternatively, following the characterization given by the [Erdős–Gallai theorem](wikipedia://en/30208106), the problem can be solved by testing the validity of $n$ inequalities.[^o6]

## Other notations {#Other_notations}

The problem can also be stated in terms of [symmetric matrices](wikipedia://en/126474) of zeros and ones. The connection can be seen if one realizes that each graph has an [adjacency matrix](wikipedia://en/244463) where the column sums and row sums correspond to $(d_1,\ldots,d_n)$. The problem is then sometimes denoted by *symmetric 0-1-matrices for given row sums*.

## Related problems {#Related_problems}

Similar problems describe the [degree sequences](wikipedia://en/244431) of [simple bipartite graphs](wikipedia://en/244431) or the [degree sequences](wikipedia://en/19721986) of [simple directed graphs](wikipedia://en/19721986). The first problem is the so-called [bipartite realization problem](wikipedia://en/43264877). The second is known as the [digraph realization problem](https://en.wikipedia.org/wiki/Digraph_realization_problem).

The problem of constructing a solution for the graph realization problem with the additional constraint that each such solution comes with the same probability was shown to have a [polynomial-time approximation scheme](wikipedia://en/666431) for the degree sequences of [regular graphs](wikipedia://en/85821) by Cooper, Martin, and Greenhill.[^o9] The general problem is still unsolved.
