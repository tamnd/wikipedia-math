# C+-probability

::: {#o1 .subject cue=lead name="C+-probability"}

In statistics, a **c<sup>\+</sup>-probability** is the probability that a [contrast variable](https://en.wikipedia.org/wiki/Contrast_variable) obtains a positive value.[^o2] Using a replication probability, the c<sup>\+</sup>-probability is defined as follows: if we get a random draw from each group (or factor level) and calculate the sampled value of the contrast variable based on the random draws, then the c<sup>\+</sup>-probability is the chance that the sampled values of the contrast variable are greater than 0 when the random drawing process is repeated infinite times. The c<sup>\+</sup>-probability is a probabilistic index accounting for distributions of compared groups (or factor levels).[^o3]

:::

The c<sup>\+</sup>-probability and [SMCV](https://en.wikipedia.org/wiki/SMCV) are two characteristics of a [contrast variable](https://en.wikipedia.org/wiki/Contrast_variable). There is a link between [SMCV](https://en.wikipedia.org/wiki/SMCV) and c<sup>\+</sup>-probability.[^o2] [^o3] The SMCV and c<sup>\+</sup>-probability provides a consistent interpretation to the strength of comparisons in contrast analysis.[^o3] When only two groups are involved in a comparison, the c<sup>\+</sup>-probability becomes d<sup>\+</sup>-probability which is the probability that the difference of values from two groups is positive.[^o4] To some extent, the d<sup>\+</sup>-probability (especially in the independent situations) is equivalent to the well-established probabilistic index P(*X* > *Y*). Historically, the index P(*X* > *Y*) has been studied and applied in many areas.[^o5] [^o6] [^o7] [^o8] [^o9] The c<sup>\+</sup>-probability and d<sup>\+</sup>-probability have been used for data analysis in high-throughput experiments and biopharmaceutical research.[^o2] [^o3]
