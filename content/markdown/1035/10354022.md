# Realization (probability)

::: {#o1 .subject cue=lead name="Realization"}

In [probability](wikipedia://en/22934) and [statistics](wikipedia://en/26685), a **realization** or **observation** (also called **observed value**) of a [random variable](wikipedia://en/25685) or [random element](wikipedia://en/5215393) is the [value](https://en.wikipedia.org/wiki/Data_value) that is actually [observed](https://en.wikipedia.org/wiki/Observation) or [measured](wikipedia://en/19022). For example, if the random variable is [human height](https://en.wikipedia.org/wiki/Human_height), a given realization could be "2 [meters](https://en.wikipedia.org/wiki/Meter)”. The random variable itself is the process dictating how the observation comes about. Statistical quantities computed from realizations without deploying a statistical model are often called "[empirical](https://en.wikipedia.org/wiki/Empirical)", as in [empirical distribution function](wikipedia://en/2690455) or [empirical probability](wikipedia://en/10384312). Conventionally, to avoid confusion, upper case letters denote random variables and the corresponding lower case letters denote their realizations.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

In [probability theory](wikipedia://en/23542), a random variable is a [function](wikipedia://en/185427) $X$ defined from a [sample space](wikipedia://en/22958) $\Omega$ to another measurable space called the **state space**[^o5]. If an element in $\Omega$ is mapped to an element in state space by $X$, then that element in state space is a realization. That is, at a point $\omega\in\Omega$, the value $x = X(\omega)$ is called a realization of $X$[^o6].

Elements of the sample space can be thought of as all the different possibilities that *could* happen; while a realization (an element of the state space) can be thought of as the value $X$ attains when one of the possibilities *did* happen. [Probability](wikipedia://en/22934) is a [mapping](wikipedia://en/516931) that assigns numbers between zero and one to certain [subsets](wikipedia://en/27631) of the sample space, namely the measurable subsets, known here as [events](wikipedia://en/22961). Subsets of the sample space that contain only one element are called [elementary events](wikipedia://en/22960).

## Random variate {#Random_variate}

In [probability](wikipedia://en/22934) and [statistics](wikipedia://en/26685), a random variate or simply variate is a particular outcome or [*realization*](wikipedia://en/10354022) of a [random variable](wikipedia://en/25685); the random variates which are other outcomes of the same random variable might have different values ([random numbers](wikipedia://en/41627) or other random symbols or labels).[^o9] Random variates are used when [simulating](https://en.wikipedia.org/wiki/Simulation#Computer_simulation) processes driven by random influences ([stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes)).

[Devroye](https://en.wikipedia.org/wiki/Luc_Devroye) defines a random variate generation algorithm (for [real numbers](wikipedia://en/20646438)) as follows:[^o10]

Assume that

1. Computers can manipulate real numbers.
1. Computers have access to a source of random variates that are [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on the [closed interval](https://en.wikipedia.org/wiki/Closed_interval) \[0,1\].

Then a random variate generation algorithm is any program that halts [almost surely](wikipedia://en/351908) and exits with a real number *x*. This *x* is called a **random variate**.

Note that both assumptions are violated in most real computers. Computers necessarily lack the ability to manipulate real numbers, typically using [floating point](https://en.wikipedia.org/wiki/Floating_point) representations instead. Most computers lack a source of true randomness (like certain [hardware random number generators](https://en.wikipedia.org/wiki/Hardware_random_number_generator)), and instead use [pseudorandom number](https://en.wikipedia.org/wiki/Pseudorandom_number) sequences.

The distinction between *random variable* and *random variate* is subtle and is not always made in the literature. It is useful when one wants to distinguish between a random variable itself with an associated [probability distribution](wikipedia://en/23543) on the one hand, and random draws from that probability distribution on the other, in particular when those draws are ultimately derived by [floating-point arithmetic](wikipedia://en/11376) from a pseudo-random sequence.
