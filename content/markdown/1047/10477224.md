# Iris flower data set

::: {#o1 .subject cue=lead name="Iris flower data set"}

*Image: Iris\_dataset\_scatterplot.svg.* [Scatterplot](https://en.wikipedia.org/wiki/Scatterplot) of the data set

The ***Iris* flower data set** or **Fisher's *Iris* data set** is a [multivariate](wikipedia://en/19384) [data set](wikipedia://en/8495) used and made famous by the British [statistician](wikipedia://en/48661) and [biologist](https://en.wikipedia.org/wiki/Biologist) [Ronald Fisher](wikipedia://en/140824) in his 1936 paper *The use of multiple measurements in taxonomic problems* as an example of [linear discriminant analysis](wikipedia://en/1470657).[^o2] It is sometimes called **Anderson's *Iris* data set** because [Edgar Anderson](https://en.wikipedia.org/wiki/Edgar_Anderson) collected the data to quantify the [morphologic](https://en.wikipedia.org/wiki/Morphology_%28biology%29) variation of *[Iris](https://en.wikipedia.org/wiki/Iris_%28plant%29)* flowers of three related species.[^o3] Two of the three species were collected in the [Gaspé Peninsula](https://en.wikipedia.org/wiki/Gaspé_Peninsula) "all from the same pasture, and picked on the same day and measured at the same time by the same person with the same apparatus".[^o4]

:::

The data set consists of 50 samples from each of three species of *Iris* (*[Iris setosa](https://en.wikipedia.org/wiki/Iris_setosa)*, *[Iris virginica](https://en.wikipedia.org/wiki/Iris_virginica)* and *[Iris versicolor](https://en.wikipedia.org/wiki/Iris_versicolor)*). Four [features](https://en.wikipedia.org/wiki/Features_%28pattern_recognition%29) were measured from each sample: the length and the width of the [sepals](https://en.wikipedia.org/wiki/Sepal) and [petals](https://en.wikipedia.org/wiki/Petal), in centimeters. Based on the combination of these four features, Fisher developed a [linear discriminant](wikipedia://en/1470657) model to distinguish each species. Fisher's paper was published in the *[Annals of Eugenics](https://en.wikipedia.org/wiki/Annals_of_Eugenics)* (today the *Annals of Human Genetics*).[^o2]

## Use of the data set {#Use_of_the_data_set}

*Image: Iris Flowers Clustering kMeans.svg.* Unsatisfactory [k-means clustering](wikipedia://en/1860407) (the data cannot be clustered into the known classes) and actual species visualized using [ELKI](https://en.wikipedia.org/wiki/Environment_for_DeveLoping_KDD-Applications_Supported_by_Index-Structures)

*Image: Principal tree for Iris data set.png.* An example of the so-called "metro map" for the *Iris* data set[^o6] Only a small fraction of *Iris-virginica* is mixed with *Iris-versicolor*. All other samples of the different *Iris* species belong to the different nodes.

Originally used as an example data set on which Fisher's [linear discriminant analysis](wikipedia://en/1470657) was applied, it became a typical test case for many [statistical classification](wikipedia://en/1579244) techniques in [machine learning](wikipedia://en/233488) such as [support vector machines](https://en.wikipedia.org/wiki/Support_vector_machines).[^o7]

The use of this data set in [cluster analysis](wikipedia://en/669675) however is not common, since the data set only contains two clusters with rather obvious separation. One of the clusters contains *Iris setosa*, while the other cluster contains both *Iris virginica* and *Iris versicolor* and is not separable without the species information Fisher used. This makes the data set a good example to explain the difference between supervised and unsupervised techniques in [data mining](wikipedia://en/42253): Fisher's linear discriminant model can only be obtained when the object species are known: class labels and clusters are not necessarily the same.[^o8]

Nevertheless, all three species of *Iris* are separable in the projection on the nonlinear and branching principal component.[^o9] The data set is approximated by the closest tree with some penalty for the excessive number of nodes, bending and stretching. Then the so-called "metro map" is constructed.[^o6] The data points are projected into the closest node. For each node the [pie diagram](wikipedia://en/728487) of the projected points is prepared. The area of the pie is proportional to the number of the projected points. It is clear from the diagram (left) that the absolute majority of the samples of the different *Iris* species belong to the different nodes. Only a small fraction of *Iris-virginica* is mixed with *Iris-versicolor* (the mixed blue-green nodes in the diagram). Therefore, the three species of Iris (*Iris setosa*, *Iris virginica* and *Iris versicolor*) are separable by the unsupervising procedures of nonlinear [principal component analysis](wikipedia://en/76340). To discriminate them, it is sufficient just to select the corresponding nodes on the principal tree.

The iris data set is widely used as a beginner's data set for machine learning purposes. The data set is included in [R](wikipedia://en/376707) *base* and Python in the machine learning library [scikit-learn](https://en.wikipedia.org/wiki/Scikit-learn), so that users can access it without having to find a source for it.

Several versions of the data set have been published.[^o12]

### [R](wikipedia://en/376707) code illustrating usage {#R_code_illustrating_usage}

The example R code shown below reproduce the scatterplot displayed at the top of this article:

```r
# Show the data set
iris
# Show the help page, with information about the data set
?iris

# Create scatterplots of all pairwise combination of the 4 variables in the data set
pairs(iris[1:4], main="Iris Data (red=setosa,green=versicolor,blue=virginica)",
      pch=21, bg=c("red","green3","blue")[unclass(iris$Species)])
 

# Alternatively using ggplot and ggally.
install.packages(c("ggplot2","GGally")) # install packages if you don't have it.

#Load libraries.
library(ggplot2)
library(GGally)

# Plot scatter plot matrix for the iris data set
ggpairs(data = iris, # your iris data
        columns = 1:4, # columns for the scatter plot 
        mapping = aes(colour = Species,fill = Species),
        title = 'Scatter Plot Matrix for Iris Data Set',
        ) +
  theme(plot.title = element_text(hjust = 0.5,face = 'bold')) +
  scale_color_brewer(palette = 'Set1') 

 
```

### [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) code illustrating usage {#Python_code_illustrating_usage}

```python
from sklearn.datasets import load_iris

iris = load_iris()
```
