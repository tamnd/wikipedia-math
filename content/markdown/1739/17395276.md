# Open mapping theorem (functional analysis)

::: {#o1 .subject cue=lead name="Open mapping theorem"}

In [functional analysis](wikipedia://en/11180), the **open mapping theorem**, also known as the **Banach–Schauder theorem** or the **Banach theorem**[^n1] (named after [Stefan Banach](wikipedia://en/29646) and [Juliusz Schauder](wikipedia://en/685314)), is a fundamental result that states that if a [bounded](https://en.wikipedia.org/wiki/Bounded_linear_operator) or [continuous linear operator](wikipedia://en/1802169) between [Banach spaces](wikipedia://en/3989) is [surjective](https://en.wikipedia.org/wiki/Surjective) then it is an [open map](https://en.wikipedia.org/wiki/Open_map).

:::

A special case is also called the **bounded inverse theorem** (also called inverse mapping theorem or Banach isomorphism theorem), which states that a bijective bounded linear operator $T$ from one Banach space to another has bounded inverse $T^{-1}$.

## Statement and proof {#Statement_and_proof}

::: {#o4 .statement kind=statement/theorem cue=math-theorem name="Open mapping theorem"}

**Open mapping theorem.**

[^o5][^o6] Let $T: E \to F$ be a surjective continuous linear map between Banach spaces (or more generally [Fréchet spaces](wikipedia://en/233801)). Then $T$ is an open mapping (that is, if $U \subset E$ is an open subset, then $T(U)$ is open).

:::

The proof here uses the [Baire category theorem](wikipedia://en/55227), and [completeness](wikipedia://en/7832) of both $E$ and $F$ is essential to the theorem. The statement of the theorem is no longer true if either space is assumed to be only a [normed vector space](wikipedia://en/21538); see .

The proof is based on the following lemmas, which are also somewhat of independent interest. A linear map $f : E \to F$ between topological vector spaces is said to be [nearly open](https://en.wikipedia.org/wiki/Nearly_open_map) if, for each neighborhood $U$ of zero, the closure $\overline{f(U)}$ contains a neighborhood of zero. The next lemma may be thought of as a weak version of the open mapping theorem.

::: {#o7 .statement kind=statement/lemma cue=math-theorem name="Lemma"}

**Lemma.**

[^o8][^o9] A linear map $f : E \to F$ between normed spaces is nearly open if the image of $f$ is [non-meager](https://en.wikipedia.org/wiki/Meager_set) in $F$. (The continuity is not needed.)

:::

Proof: Shrinking $U$, we can assume $U$ is an open ball centered at zero. We have $f(E) = f\left(\bigcup_{n \in \mathbb{N}} n U\right) = \bigcup_{n \in \mathbb{N}} f(nU)$. Thus, some $\overline{f(nU)}$ contains an interior point $y$; that is, for some radius $r > 0$,

$$B(y, r) \subset \overline{f(nU)}.$$

Then for any $v$ in $F$ with $\|v\| < r$, by linearity, convexity and $(-1)U \subset U$,

$$v = v - y + y \in \overline{f(-nU)} + \overline{f(nU)} \subset \overline{f(2nU)},$$

which proves the lemma by dividing by $2n$.$\square$ (The same proof works if $E, F$ are pre-Fréchet spaces.)

The completeness on the domain then allows to upgrade nearly open to open.

::: {#o10 .statement kind=statement/lemma cue=math-theorem name="Lemma (Schauder)"}

**Lemma (Schauder).**

[^o16][^o11] Let $f: E \to F$ be a continuous linear map between normed spaces.

If $f$ is nearly-open and if $E$ is complete, then $f$ is open and surjective.

More precisely, if $B(0, \delta) \subset \overline{f(B(0, 1))}$ for some $\delta > 0$ and if $E$ is complete, then

$B(0, \delta) \subset f(B(0, 1))$ where $B(x, r)$ is an open ball with radius $r$ and center $x$.

:::

Proof: Let $y$ be in $B(0, \delta)$ and $c_n > 0$ some sequence. We have: $\overline{B(0, \delta)} \subset \overline{f(B(0,1))}$. Thus, for each $\epsilon > 0$ and $z$ in $F$, we can find an $x$ with $\|x\| < \delta^{-1}\|z\|$ and $z$ in $B(f(x), \epsilon)$. Thus, taking $z = y$, we find an $x_1$ such that

$$\|y - f(x_1) \| < c_1, \, \|x_1 \| < \delta^{-1} \|y\|.$$

Applying the same argument with $z = y - f(x_1)$, we then find an $x_2$ such that

$$\|y - f(x_1) - f(x_2)\| < c_2, \, \|x_2\| < \delta^{-1}c_1$$

where we observed $\|x_2\| < \delta^{-1} \|z\| < \delta^{-1} c_1$. Then so on. Thus, if $c := \sum c_n < \infty$, we found a sequence $x_n$ such that $x = \sum_1^{\infty} x_n$ converges and $f(x) = y$. Also,

$$\|x\| \le \sum_1^{\infty} \|x_n\| \le \delta^{-1} \|y\| + \delta^{-1} c.$$

Since $\delta^{-1} \|y\| < 1$, by making $c$ small enough, we can achieve $\|x\| < 1$. $\square$ (Again the same proof is valid if $E, F$ are pre-Fréchet spaces.)

Proof of the theorem: By Baire's category theorem, the first lemma applies. Then the conclusion of the theorem follows from the second lemma. $\square$

In general, a continuous bijection between topological spaces is not necessarily a homeomorphism. The open mapping theorem, when it applies, implies the bijectivity is enough:

::: {#o12 .statement kind=statement/corollary cue=math-theorem name="Corollary (Bounded inverse theorem)"}

**Corollary (Bounded inverse theorem).**

[^o13] A continuous bijective linear operator between Banach spaces (or Fréchet spaces) has a continuous inverse. That is, the inverse operator is continuous.

:::

Even though the above bounded inverse theorem is a special case of the open mapping theorem, the open mapping theorem in turn follows from that. Indeed, a surjective continuous linear operator $T : E \to F$ factors as

$$T : E \overset{p}\to E/\operatorname{ker} T \overset{T_0}\to F.$$

Here, $T_0$ is continuous and bijective and thus is a homeomorphism by the bounded inverse theorem; in particular, it is an open mapping. As a quotient map for topological groups is open, $T$ is open then.

Because the open mapping theorem and the bounded inverse theorem are essentially the same result, they are often simply called **Banach's theorem**.

### Transpose formulation {#Transpose_formulation}

Here is a formulation of the open mapping theorem in terms of the [transpose](wikipedia://en/173844) of an operator.

::: {#o15 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

[^o16] Let $X$ and $Y$ be Banach spaces, let $B_X$ and $B_Y$ denote their open unit balls, and let $T : X \to Y$ be a bounded linear operator. If $\delta > 0$ then among the following four statements we have $(1) \implies (2) \implies (3) \implies (4)$ (with the same $\delta$)

$\delta \left\|y'\right\| \le \left\|T' y'\right\|$ for all $y' \in Y'$ = continuous dual of $Y$;

$$\delta B_Y \subset \overline{T\left(B_X\right)};$$

$$\delta B_Y \subset {T\left(B_X\right)};$$

$T$ is surjective. Furthermore, if $T$ is surjective then (1) holds for some $\delta > 0.$

:::

Proof: The idea of 1. $\Rightarrow$ 2. is to show: $y \notin \overline{T(B_X)} \Rightarrow \|y\| > \delta,$ and that follows from the [Hahn–Banach theorem](wikipedia://en/13860). 2. $\Rightarrow$ 3. is exactly the second lemma in . Finally, 3. $\Rightarrow$ 4. is trivial and 4. $\Rightarrow$ 1. easily follows from the open mapping theorem. $\square$

Alternatively, 1. implies that $T'$ is injective and has closed image and then by the [closed range theorem](wikipedia://en/23483982), that implies $T$ has dense image and closed image, respectively; i.e., $T$ is surjective. Hence, the above result is a variant of a special case of the closed range theorem.

### Quantitative formulation {#Quantitative_formulation}

[Terence Tao](wikipedia://en/1118498) gives the following quantitative formulation of the theorem:[^o18]

::: {#o19 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

Let $T: E \to F$ be a bounded operator between Banach spaces. Then the following are equivalent:

$T$ is open.

$T$ is surjective.

There exists a constant $C > 0$ such that, for each $f$ in $F$, the equation $Tu = f$ has a solution $u$ with $\|u\| \le C \|f\|$.

\3. holds for $f$ in some dense subspace of $F$.

:::

The proof follows a [cycle of implications](wikipedia://en/77621259) $1\Rightarrow 4\Rightarrow 3\Rightarrow 2\Rightarrow 1$. Here $2 \Rightarrow 1$ is the usual open mapping theorem.

$1 \Rightarrow 4$: For some $r > 0$, we have $B(0, 2) \subset T(B(0, r))$ where $B$ means an open ball. Then $\frac{f}{\|f\|} = T \left(\frac{u}{\|f\|} \right)$ for some $\frac{u}{\|f\|}$ in $B(0, r)$. That is, $Tu = f$ with $\|u\| < r\|f\|$.

$4 \Rightarrow 3$: We can write $f = \sum_0^{\infty} f_j$ with $f_j$ in the dense subspace and the sum converging in norm. Then, since $E$ is complete, $u = \sum_0^{\infty} u_j$ with $\|u_j\| \le C \|f_j\|$ and $Tu_j = f_j$ is a required solution.

Finally, $3 \Rightarrow 2$ is trivial. $\square$

::: {#o21 .example kind=example/counterexample cue=heading name="Counterexample"}

## Counterexample {#Counterexample}

The open mapping theorem may not hold for normed spaces that are not complete. A quickest way to see this is to note that the [closed graph theorem](wikipedia://en/64620077), a consequence of the open mapping theorem, fails without completeness. But here is a more concrete counterexample. Consider the space $X$ of [sequences](wikipedia://en/27838) $x:\mathbb{N}\rightarrow\mathbb{R}$ with only finitely many non-zero terms equipped with the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm). The map $T:X\rightarrow X$ defined by

$$T x = \left( x_{1}, \frac{x_{2}}{2}, \frac{x_{3}}{3}, \dots \right)$$

is bounded, linear and invertible, but $T^{-1}$ is unbounded. This does not contradict the bounded inverse theorem since $X$ is not [complete](https://en.wikipedia.org/wiki/Completeness_%28topology%29), and thus is not a Banach space. To see that it's not complete, consider the sequence of sequences $x^{(n)}\in X$ given by

$$x^{(n)} = \left( 1, \frac1{2}, \dots, \frac1{n}, 0, 0, \dots \right)$$

converges as $n\rightarrow\infty$ to the sequence $x^{(\infty)}$ given by

$$x^{(\infty)} = \left( 1, \frac1{2}, \dots, \frac1{n}, \dots \right),$$

which has all its terms non-zero, and so does not lie in $X$.

The completion of $X$ is the [space $c_0$](wikipedia://en/17543372) of all sequences that converge to zero, which is a (closed) subspace of the [ℓ<sup>*p*</sup> space](wikipedia://en/45194) $\ell^{\infty}(\mathbb{N})$, which is the space of all bounded sequences. However, in this case, the map $T$ is not onto, and thus not a bijection. To see this, one need simply note that the sequence

$$x = \left( 1, \frac12, \frac13, \dots \right),$$

is an element of $c_0$, but is not in the range of $T:c_0\to c_0$. The same reasoning applies to show $T$ is also not onto in $\ell^\infty$, for example $x = \left( 1, 1, 1, \dots \right)$ is not in the range of $T$.

Even if the domain is complete (or the codomain is), the Open Mapping Theorem still requires both spaces to be complete. To see this, consider the identity map from the space $Y$ of absolutely summable sequences (that is, those with finite 1-norm) with the 1-norm to the space $Y$ with the supremum norm. Since this map is norm decreasing, it is bounded, but it is not open. To see that the domain must also be complete, let $(Z,\|\cdot\|)$ be a Banach space with a discontinuous linear functional $f$ on it. Then $(Z,\|\cdot\|+|f(\cdot)|)$ is a non-complete normed space, and the identity map from $(Z,\|\cdot\|+|f(\cdot)|)$ to $(Z,\|\cdot\|)$ is a norm-decreasing (therefore bounded) map which is not open.

:::

## Consequences {#Consequences}

The open mapping theorem has several important consequences:

- If $T : X \to Y$ is a [bijective](https://en.wikipedia.org/wiki/Bijective) continuous linear operator between the Banach spaces $X$ and $Y,$ then the [inverse operator](wikipedia://en/14907) $T^{-1} : Y \to X$ is continuous as well (this is called the **bounded inverse theorem**).[^n2]
- If $T : X \to Y$ is a linear operator between the Banach spaces $X$ and $Y,$ and if for every [sequence](wikipedia://en/27838) $\left(x_n\right)$ in $X$ with $x_n \to 0$ and $T x_n \to y$ it follows that $y = 0,$ then $T$ is continuous (the [closed graph theorem](wikipedia://en/64620077)).[^n3]
- Given a bounded operator $T : E \to F$ between normed spaces, if the image of $T$ is [non-meager](https://en.wikipedia.org/wiki/Non-meager) and if $E$ is complete, then $T$ is open and surjective and $F$ is complete (to see this, use the two lemmas in the proof of the theorem).[^o25]
- An exact sequence of Banach spaces (or more generally Fréchet spaces) is [topologically exact](https://en.wikipedia.org/wiki/Topologically_exact).
- The [closed range theorem](wikipedia://en/23483982), which says an operator (under some assumption) has closed image if and only if its transpose has closed image (see [closed range theorem#Sketch of proof](wikipedia://en/23483982#Sketch_of_proof)).

The open mapping theorem does not imply that a continuous surjective linear operator admits a continuous linear section. What we have is:[^o18]

- A surjective continuous linear operator between Banach spaces admits a continuous linear section if and only if the kernel is topologically complemented.

In particular, the above applies to an operator between Hilbert spaces or an operator with finite-dimensional kernel (by the [Hahn–Banach theorem](wikipedia://en/13860)). If one drops the requirement that a section be linear, a surjective continuous linear operator between Banach spaces admits a continuous section; this is the [Bartle–Graves theorem](https://en.wikipedia.org/wiki/Bartle–Graves_theorem).[^o26][^o27]

## Generalizations {#Generalizations}

Local convexity of $X$ or $Y$ is not essential to the proof, but completeness is: the theorem remains true in the case when $X$ and $Y$ are [F-spaces](wikipedia://en/200440). Furthermore, the theorem can be combined with the Baire category theorem in the following manner:

::: {#o31 .statement kind=statement/theorem cue=math-theorem name="Open mapping theorem for continuous maps"}

**Open mapping theorem for continuous maps[^o25][^n4].**

Let $A : X \to Y$ be a [continuous linear operator](wikipedia://en/1802169) from a complete [pseudometrizable TVS](wikipedia://en/64278078) $X$ onto a Hausdorff TVS $Y.$ If $\operatorname{Im} A$ is [nonmeager](https://en.wikipedia.org/wiki/Nonmeager_set) in $Y$ then $A : X \to Y$ is a (surjective) open map and $Y$ is a complete pseudometrizable TVS. Moreover, if $X$ is assumed to be hausdorff (i.e. a [F-space](wikipedia://en/200440)), then $Y$ is also an F-space.

:::

(The proof is essentially the same as the Banach or Fréchet cases; we modify the proof slightly to avoid the use of convexity,)

Furthermore, in this latter case if $N$ is the [kernel](wikipedia://en/1072915) of $A,$ then there is a canonical factorization of $A$ in the form

$$X \to X/N \overset{\alpha}{\to} Y$$

where $X / N$ is the [quotient space](wikipedia://en/898784) (also an F-space) of $X$ by the [closed](wikipedia://en/47279) subspace $N.$ The quotient mapping $X \to X / N$ is open, and the mapping $\alpha$ is an [isomorphism](wikipedia://en/14828) of [topological vector spaces](wikipedia://en/45752).[^n5]

An important special case of this theorem can also be stated as

::: {#o34 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^o33].**

Let $X$ and $Y$ be two [F-spaces](wikipedia://en/200440). Then every continuous linear map of $X$ onto $Y$ is a [TVS homomorphism](wikipedia://en/63987005), where a linear map $u : X \to Y$ is a topological vector space (TVS) homomorphism if the induced map $\hat{u} : X / \ker(u) \to Y$ is a TVS-isomorphism onto its image.

:::

On the other hand, a more general formulation, which implies the first, can be given:

::: {#o36 .statement kind=statement/theorem cue=math-theorem name="Open mapping theorem"}

**Open mapping theorem[^n4].**

Let $A : X \to Y$ be a surjective [linear map](wikipedia://en/18102) from a [complete](wikipedia://en/53695856) [pseudometrizable TVS](wikipedia://en/64278078) $X$ onto a TVS $Y$ and suppose that at least one of the following two conditions is satisfied:

$Y$ is a [Baire space](wikipedia://en/200550), or

$X$ is [locally convex](https://en.wikipedia.org/wiki/Locally_convex) and $Y$ is a [barrelled space](wikipedia://en/1733592), If $A$ is a [closed linear operator](wikipedia://en/64713671) then $A$ is an open mapping. If $A$ is a [continuous linear operator](wikipedia://en/1802169) and $Y$ is Hausdorff then $A$ is (a closed linear operator and thus also) an open mapping.

:::

**Nearly/Almost open linear maps**

A linear map $A : X \to Y$ between two topological vector spaces (TVSs) is called a nearly open map (or sometimes, an [almost open map](wikipedia://en/65738568)) if for every neighborhood $U$ of the origin in the domain, the closure of its image $\operatorname{cl} A(U)$ is a neighborhood of the origin in $Y.$[^n6] Many authors use a different definition of "nearly/almost open map" that requires that the closure of $A(U)$ be a neighborhood of the origin in $A(X)$ rather than in $Y,$[^n6] but for surjective maps these definitions are equivalent. A bijective linear map is nearly open if and only if its inverse is continuous.[^n6] Every surjective linear map from [locally convex TVS](wikipedia://en/518844) onto a [barrelled TVS](wikipedia://en/1733592) is nearly open.[^n7] The same is true of every surjective linear map from a TVS onto a [Baire](wikipedia://en/200550) TVS.[^n7]

::: {#o43 .statement kind=statement/theorem cue=math-theorem name="Open mapping theorem"}

**Open mapping theorem[^n8].**

If a closed surjective linear map from a [complete](wikipedia://en/53695856) [pseudometrizable TVS](wikipedia://en/64278078) onto a Hausdorff TVS is nearly open then it is open.

:::

::: {#o45 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n9].**

If $A : X \to Y$ is a continuous linear bijection from a [complete](wikipedia://en/53695856) [Pseudometrizable](wikipedia://en/64278078) [topological vector space](wikipedia://en/45752) (TVS) onto a Hausdorff TVS that is a [Baire space](wikipedia://en/200550), then $A : X \to Y$ is a [homeomorphism](wikipedia://en/13660) (and thus an isomorphism of TVSs).

:::

[Webbed spaces](wikipedia://en/41717785) are a class of [topological vector spaces](wikipedia://en/45752) for which the open mapping theorem and the [closed graph theorem](wikipedia://en/497834) hold.

:::
