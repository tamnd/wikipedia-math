# Glicksberg's theorem

::: {#o1 .subject cue=lead name="Glicksberg's theorem"}

In the study of [zero sum](https://en.wikipedia.org/wiki/Zero_sum) [games](wikipedia://en/11924), **Glicksberg's theorem** (also **Glicksberg's existence theorem**) is a result that shows certain games have a [minimax](wikipedia://en/19589) value.[^o2] If *A* and *B* are Hausdorff [compact spaces](wikipedia://en/6042), and *K* is an [upper semicontinuous](https://en.wikipedia.org/wiki/Upper_semicontinuous) or [lower semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous) function on $A\times B$, then

:::

$$\sup_{f}\inf_{g}\iint K\,df\,dg = \inf_{g}\sup_{f}\iint K\,df\,dg$$

where *f* and *g* run over [Borel probability measures](https://en.wikipedia.org/wiki/Borel_probability_measure) on *A* and *B*.

The theorem is useful if *f* and *g* are interpreted as [mixed strategies](https://en.wikipedia.org/wiki/Mixed_strategy) of two players in the context of a [continuous game](https://en.wikipedia.org/wiki/Continuous_game). If the [payoff function](https://en.wikipedia.org/wiki/Payoff_function) *K* is upper semicontinuous, then the game has a value.

The continuity condition may not be dropped: see [example of a game with no value](https://en.wikipedia.org/wiki/Example_of_a_game_with_no_value).[^o3]
