# Linear-fractional programming

::: {#o1 .subject cue=lead name="Linear-fractional programming"}

In [mathematical optimization](wikipedia://en/52033), **linear-fractional programming** (**LFP**) is a generalization of [linear programming](wikipedia://en/43730) (LP). Whereas the objective function in a linear program is a [linear function](https://en.wikipedia.org/wiki/Linear_functional), the objective function in a linear-fractional program is a ratio of two linear functions. A linear program can be regarded as a special case of a linear-fractional program in which the denominator is the [constant function](wikipedia://en/320861) 1.

:::

The constraints have to restrict the [feasible region](wikipedia://en/9157119) to $\{\mathbf{x} | \mathbf{d}^T\mathbf{x} + \beta > 0\}$, i.e. the region on which the denominator is positive.[^o2][^o3] Alternatively, the denominator of the objective function has to be strictly negative in the entire feasible region.

## Motivation by comparison to linear programming {#Motivation_by_comparison_to_linear_programming}

Both linear programming and linear-fractional programming represent optimization problems using linear equations and [linear inequalities](wikipedia://en/19575563), which for each problem-instance define a [feasible set](https://en.wikipedia.org/wiki/Feasible_set). Fractional linear programs have a richer set of objective functions. Informally, linear programming computes a policy delivering the best outcome, such as maximum profit or lowest cost. In contrast, a linear-fractional programming is used to achieve the highest *ratio* of outcome to cost, the ratio representing the highest efficiency. For example, in the context of LP we maximize the objective function **profit = income − cost** and might obtain maximum profit of \$100 (= \$1100 of income − \$1000 of cost). Thus, in LP we have an efficiency of \$100/\$1000 = 0.1. Using LFP we might obtain an efficiency of \$10/\$50 = 0.2 with a profit of only \$10, but only requiring \$50 of investment.

## Transformation to a linear program {#Transformation_to_a_linear_program}

Any linear-fractional program can be transformed into a linear program, assuming that the feasible region is non-empty and bounded, using the **Charnes–Cooper transformation**.[^o2] The main idea is to introduce a new non-negative variable $t$ to the program which will be used to rescale the constants involved in the program ($\alpha, \beta, \mathbf{b}$). This allows us to require that the denominator of the objective function ($\mathbf{d}^T \mathbf{x} + \beta$) equals 1. (To understand the transformation, it is instructive to consider the simpler special case with $\alpha = \beta = 0$.)

## Properties and algorithms {#Properties_and_algorithms}

The objective function in a linear-fractional problem is both quasiconcave and [quasiconvex](wikipedia://en/5781226) (hence quasilinear) with a [monotone](https://en.wikipedia.org/wiki/Monotonicity) property, [pseudoconvexity](wikipedia://en/3237132), which is a stronger property than [quasiconvexity](wikipedia://en/5781226). A linear-fractional objective function is both pseudoconvex and pseudoconcave, hence [pseudolinear](https://en.wikipedia.org/wiki/Pseudolinear_function). Since an LFP can be transformed to an LP, it can be solved using any LP solution method, such as the [simplex algorithm](wikipedia://en/349458) (of [George B. Dantzig](https://en.wikipedia.org/wiki/George_B._Dantzig)),[^o10][^o11][^o12][^o13] the [criss-cross algorithm](wikipedia://en/31255067),[^o14] or [interior-point methods](wikipedia://en/1622862).
