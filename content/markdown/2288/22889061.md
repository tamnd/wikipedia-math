# Enoki surface

::: {#o1 .subject cue=lead name="Enoki surface"}

In mathematics, an **Enoki surface** is [compact](wikipedia://en/6042) [complex](wikipedia://en/5826) [surface](wikipedia://en/4342970) with positive second [Betti number](wikipedia://en/346262) that has a [global spherical shell](https://en.wikipedia.org/wiki/Global_spherical_shell) and a non-trivial divisor *D* with *H*<sup>0</sup>(O(*D*)) ≠ 0 and (*D*, *D*) = 0. (Enoki 1980) constructed some examples. They are [surfaces of class VII](https://en.wikipedia.org/wiki/Surfaces_of_class_VII), so are non-Kähler and have [Kodaira dimension](wikipedia://en/1866873) −∞.

:::
