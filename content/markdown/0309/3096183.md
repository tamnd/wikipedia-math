# List of large cardinal properties

::: {#o1 .subject cue=lead name="List of large cardinal properties"}

This page includes a list of [large cardinal](wikipedia://en/383644) properties in the mathematical field of [set theory](wikipedia://en/27553). It is arranged roughly in order of the consistency strength of the [axiom](wikipedia://en/928) asserting the existence of [cardinals](wikipedia://en/6173) with the given property. Existence of a cardinal number *κ* of a given type implies the existence of cardinals of most of the types listed above that type, and for most listed cardinal descriptions *φ* of lesser consistency strength, [*V*<sub>*κ*</sub>](wikipedia://en/445980) satisfies "there is an unbounded class of cardinals satisfying *φ*".

:::

The following table usually arranges cardinals in order of [consistency strength](wikipedia://en/3435716#Consistency_strength), with size of the cardinal used as a tiebreaker. In a few cases (such as strongly compact cardinals) the exact consistency strength is not known and the table uses the current best guess.

::: {#o2 .entry cue=list-entry name="Aleph number"}

- "Small" cardinals: 0, 1, 2, ..., $\aleph_0, \aleph_1$,..., $\kappa = \aleph_{\kappa}$, ... (see [Aleph number](wikipedia://en/293961)); the height of the [minimal transitive model](wikipedia://en/18374778) of ZFC

:::

::: {#o3 .entry cue=list-entry name="Worldly cardinal"}

- [worldly cardinals](wikipedia://en/49944843)

:::

::: {#o4 .entry cue=list-entry name="inaccessible"}

- weakly and strongly [inaccessible](wikipedia://en/248076), [α-inaccessible](wikipedia://en/248076#α-inaccessible_cardinals_and_hyper-inaccessible_cardinals), and hyper inaccessible cardinals

:::

::: {#o5 .entry cue=list-entry name="Mahlo"}

- weakly and strongly [Mahlo](wikipedia://en/248081), α-[Mahlo](wikipedia://en/248081), and hyper Mahlo cardinals.

:::

::: {#o6 .entry cue=list-entry name="reflecting"}

- [reflecting](wikipedia://en/18449365) cardinals

:::

- pseudo uplifting cardinals, uplifting cardinals[^o7]

::: {#o8 .entry cue=list-entry name="weakly compact"}

- [weakly compact](wikipedia://en/272054) (= Π${}^{1}_{1}$-indescribable), [Π${}^{m}_{n}$-indescribable](wikipedia://en/248097), [totally indescribable](wikipedia://en/248097) cardinals, [ν-indescribable](wikipedia://en/248097) cardinals

:::

::: {#o9 .entry cue=list-entry name="λ-unfoldable"}

- [λ-unfoldable](wikipedia://en/853783), [unfoldable](wikipedia://en/853783) cardinals, [λ-shrewd](wikipedia://en/23963758), [shrewd](wikipedia://en/23963758) cardinals, strongly uplifting cardinals (not clear how these relate to each other).

:::

::: {#o10 .entry cue=list-entry name="ethereal cardinals"}

- [ethereal cardinals](wikipedia://en/326550), [subtle cardinals](wikipedia://en/326550)

:::

::: {#o11 .entry cue=list-entry name="almost ineffable"}

- [almost ineffable](https://en.wikipedia.org/wiki/Almost_ineffable_cardinal), [ineffable](wikipedia://en/270005), [*n*-ineffable](wikipedia://en/270005), [totally ineffable](wikipedia://en/270005) cardinals

:::

::: {#o12 .entry cue=list-entry name="Iterable cardinal"}

- 1-[iterable cardinal](wikipedia://en/46316193), [remarkable cardinal](wikipedia://en/529468), [virtually extendible cardinal](https://en.wikipedia.org/wiki/Virtually_extendible_cardinal), [γ-iterable cardinal for 2≤γ≤ω](wikipedia://en/46316193), [virtually rank-into-rank cardinal](https://en.wikipedia.org/wiki/Virtually_rank-into-rank_cardinal), ω-[Erdős cardinal](wikipedia://en/326540)

:::

::: {#o13 .entry cue=list-entry name="Iterable cardinal"}

- λ-[iterable cardinal](wikipedia://en/46316193), λ-[Erdős cardinal](wikipedia://en/326540) (for ω+1≤λ\<ω<sub>1</sub>)

:::

::: {#o14 .entry cue=list-entry name="Silver cardinal"}

- [Silver cardinal](https://en.wikipedia.org/wiki/Silver_cardinal), [0<sup>\#</sup>](wikipedia://en/248085) (not a cardinal), ω<sub>1</sub>-[iterable cardinal](wikipedia://en/46316193), ω<sub>1</sub>-[Erdős cardinal](wikipedia://en/326540)

:::

::: {#o15 .entry cue=list-entry name="almost Ramsey"}

- [almost Ramsey](https://en.wikipedia.org/wiki/Almost_Ramsey_cardinal), [Jónsson](wikipedia://en/3317988), [Rowbottom](wikipedia://en/3317885), [Ramsey](wikipedia://en/326533), [ineffably Ramsey](https://en.wikipedia.org/wiki/Ineffably_Ramsey_cardinal), completely Ramsey, strongly Ramsey, super Ramsey cardinals, Magidor cardinals[^o16]

:::

::: {#o17 .entry cue=list-entry name="Measurable cardinal"}

- [measurable cardinals](wikipedia://en/248102), [0<sup>†</sup>](https://en.wikipedia.org/wiki/Zero_dagger)

:::

::: {#o18 .entry cue=list-entry name="λ-strong"}

- [λ-strong](wikipedia://en/248104), [strong](wikipedia://en/248104) cardinals, [tall](wikipedia://en/34369888) cardinals

:::

::: {#o19 .entry cue=list-entry name="Woodin"}

- [Woodin](wikipedia://en/248105), [weakly hyper-Woodin](https://en.wikipedia.org/wiki/Weakly_hyper-Woodin_cardinal), [Shelah](wikipedia://en/529392), [hyper-Woodin](https://en.wikipedia.org/wiki/Hyper-Woodin_cardinal) cardinals

:::

::: {#o20 .entry cue=list-entry name="Superstrong cardinal"}

- [superstrong cardinals](wikipedia://en/248114) (=1-superstrong; for *n*-superstrong for *n*≥2 see further down.)

:::

::: {#o21 .entry cue=list-entry name="subcompact"}

- [subcompact](wikipedia://en/3994376), [strongly compact](wikipedia://en/1957057) (Woodin\< strongly compact≤supercompact), [supercompact](wikipedia://en/248116), [hypercompact](https://en.wikipedia.org/wiki/Hypercompact_cardinal) cardinals

:::

::: {#o22 .entry cue=list-entry name="η-extendible"}

- [η-extendible](wikipedia://en/325950), [extendible](wikipedia://en/325950) cardinals

:::

- almost high jump cardinals

::: {#o23 .entry cue=list-entry name="Vopěnka cardinal"}

- [Vopěnka cardinals](https://en.wikipedia.org/wiki/Vopěnka_cardinal), Shelah for supercompactness, [high jump cardinals](https://en.wikipedia.org/wiki/High_jump_cardinal), super high jump cardinals

:::

::: {#o24 .entry cue=list-entry name="superstrong (n&ge;2)"}

- *n*-[superstrong (*n*≥2)](wikipedia://en/248114), *n*-[almost huge](wikipedia://en/248117), *n*-[super almost huge](wikipedia://en/248117), *n*-[huge](wikipedia://en/248117), *n*-[superhuge](wikipedia://en/248117) cardinals (1-huge=huge, etc.)

:::

::: {#o25 .entry cue=list-entry name="Exacting cardinals"}

- [exacting cardinals](https://en.wikipedia.org/wiki/Exacting_cardinals), [ultraexacting cardinals](https://en.wikipedia.org/wiki/Ultraexacting_cardinals)[^o26]

:::

::: {#o27 .entry cue=list-entry name="Wholeness axiom"}

- [Wholeness axiom](wikipedia://en/53098168), [rank-into-rank](wikipedia://en/311017) (Axioms I3, I2, I1, and I0)

:::

The following even stronger large cardinal properties are not consistent with the [axiom of choice](wikipedia://en/840), but their existence has not yet been refuted in [ZF](https://en.wikipedia.org/wiki/ZFC) alone (that is, without use of the axiom of choice).

::: {#o28 .entry cue=list-entry name="Weakly Reinhardt cardinal"}

- [weakly Reinhardt cardinal](https://en.wikipedia.org/wiki/Weakly_Reinhardt_cardinal), [Reinhardt cardinal](wikipedia://en/4687321), proto-Berkeley cardinal, [Berkeley cardinal](wikipedia://en/46229692), [super Reinhardt cardinal](https://en.wikipedia.org/wiki/Super_Reinhardt_cardinal), [totally Reinhardt cardinal](https://en.wikipedia.org/wiki/Totally_Reinhardt_cardinal), [club Berkeley cardinal](https://en.wikipedia.org/wiki/Club_Berkeley_cardinal), limit club Berkeley cardinal[^o29]

:::

Many of these large cardinals axioms also have *virtual* versions.[^o30]
