# Bimonster group

::: {#o1 .subject cue=lead name="Bimonster group"}

In [mathematics](wikipedia://en/18831), the **bimonster** is a [group](wikipedia://en/19447) that is the [wreath product](wikipedia://en/146625) of the [monster group](wikipedia://en/47422) *M* with **Z**<sub>2</sub>:

:::

$$Bi = M \wr \mathbb{Z}_2. \,$$

The Bimonster is also a quotient of the [Coxeter group](wikipedia://en/297004) corresponding to the [Dynkin diagram](wikipedia://en/277109) *Y*<sub>555</sub>, a Y-shaped [graph](wikipedia://en/12401) with 16 nodes:

nodes

*Image: BimonsterGroup.svg.*

Actually, the 3 outermost nodes are redundant. This is because the subgroup *Y*<sub>124</sub> is the [E<sub>8</sub>](wikipedia://en/647994) Coxeter group. It generates the remaining node of *Y*<sub>125</sub>. This pattern extends all the way to *Y*<sub>444</sub>: it automatically generates the 3 extra nodes of *Y*<sub>555</sub>.

[John H. Conway](https://en.wikipedia.org/wiki/John_H._Conway) [conjectured](wikipedia://en/6138) that a [presentation](wikipedia://en/99494) of the bimonster could be given by adding a certain extra relation to the presentation defined by the *Y*<sub>444</sub> diagram. More specifically, the affine E<sub>6</sub> Coxeter group is $\mathbb{Z}^6:O_5(3):2$, which can be reduced to the finite group $3^5:O_5(3):2$ by adding a single relation called the *spider relation*. Once this relation is added, and the diagram is extended to *Y*<sub>444</sub>, the group generated is the bimonster. This was proved in 1990 by [Simon P. Norton](wikipedia://en/1641166); the proof was simplified in 1999 by A. A. Ivanov.

## Other Y-groups {#Other_Y-groups}

Many subgroups of the (bi)monster can be defined by adjoining the spider relation to smaller Coxeter diagrams, most notably the [Fischer groups](https://en.wikipedia.org/wiki/Fischer_groups) and the [baby monster group](wikipedia://en/324799). The groups *Y*<sub>0ij</sub>, *Y*<sub>11i</sub>, *Y*<sub>122</sub>, *Y*<sub>123</sub>, and *Y*<sub>124</sub> are finite even without adjoining additional relations. They are the Coxeter groups *A*<sub>i+j+1</sub>, *D*<sub>i+3</sub>, *E*<sub>6</sub>, *E*<sub>7</sub>, and *E*<sub>8</sub>, respectively. Other groups, which would be infinite without the spider relation, are summarized below:

::: {#o3 .table cue=table}

| Y-group name | Group generated |
|---|---|
| *Y*<sub>222</sub> | $3^5:O_5(3):2$ |
| *Y*<sub>223</sub> | $O_7(3)\times2$ |
| *Y*<sub>224</sub> | $O_8^+(3):2$[^o4] |
| *Y*<sub>133</sub> | $2^7:(O_7(2)\times2)$[^o5] |
| *Y*<sub>134</sub> | $O_9(2)\times2$[^o5] |
| *Y*<sub>144</sub> | $O_{10}^-(2):2$[^o5] |
| *Y*<sub>233</sub> | $2\times2Fi_{22}$ |
| *Y*<sub>234</sub> | $2\times Fi_{23}$ |
| *Y*<sub>244</sub> | $3\cdot Fi_{24}$ |
| *Y*<sub>333</sub> | $2\times2^2\cdot\,^2E_6(2)$ |
| *Y*<sub>334</sub> | $2\times2\mathbb{B}$ |
| *Y*<sub>344</sub> | $2\times\mathbb{M}$ |
| *Y*<sub>444</sub> | $\mathbb{M}\wr2$[^o6] |

:::
