# Successor function

::: {#o1 .subject cue=lead name="Successor function"}

In [mathematics](wikipedia://en/18831), the **successor function** or **successor operation** sends a [natural number](wikipedia://en/21474) to the next one. The successor function is denoted by $S$, so $S(n)=n+1$. For example, $S(1)=2$ and $S(2)=3$. The successor function is one of the basic components used to build a [primitive recursive function](wikipedia://en/24829).

:::

Successor operations are also known as **zeration** in the context of a zeroth [hyperoperation](wikipedia://en/33731923). In this context, the extension of zeration is [addition](wikipedia://en/61338), which is defined as repeated succession.

## Overview {#Overview}

The successor function is part of the [formal language](wikipedia://en/10939) used to state the [Peano axioms](wikipedia://en/25005), which formalise the structure of the natural numbers. In this formalisation, the successor function is a primitive operation on the natural numbers, in terms of which the standard natural numbers and addition are defined.[^o3] 1 is defined to be $S(0)$, 2 is $S(1)$, etc.; and addition on natural numbers is defined recursively by:

$$\begin{aligned} m + 0 &= m \\ m + S(n) &= S(m+n) \end{aligned}$$

This can be used to compute the addition of any two natural numbers. For example:

$$\begin{aligned} 5 + 2 \\ &= 5 + S(1) \\ &= 5 + S(S(0)) \\ &= S(5 + S(0)) \\ &= S(S(5 + 0)) \\ &= S(S(5)) \\ &= S(6) \\ &= 7 \end{aligned}$$

Several [constructions of the natural numbers](wikipedia://en/428484) within set theory have been proposed. For example, [John von Neumann](wikipedia://en/15942) constructs the number 0 as the [empty set](wikipedia://en/9566) and the successor of $n$ as the set $n\cup\{n\}$. The [axiom of infinity](wikipedia://en/246449) then guarantees the existence of a set that contains 0 and is [closed](wikipedia://en/293802#Closure_operator) with respect to $S$. The smallest such set is denoted by $\mathbb N$, and its members are called [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers).[^o4]

The successor function is the level-0 foundation of the infinite [Grzegorczyk hierarchy](wikipedia://en/14334415) of [hyperoperations](wikipedia://en/33731923), used to build [addition](wikipedia://en/61338), [multiplication](wikipedia://en/20845), [exponentiation](wikipedia://en/99491), [tetration](wikipedia://en/482379), etc. It was studied in 1986 in an investigation involving generalization of the pattern for hyperoperations.[^o5]

It is also one of the primitive functions used in the characterization of [computability](https://en.wikipedia.org/wiki/Computability) by [recursive functions](wikipedia://en/1139338).
