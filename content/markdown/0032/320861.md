# Constant function

::: {#o1 .subject cue=lead name="Constant function"}

In [mathematics](wikipedia://en/18831), a **constant function** is a [function](wikipedia://en/185427) whose (output) value is the same for every input value.

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

*Image: wiki constant function 175 200.png.* An example of a constant function is $y(x) = 4$, because the value of $y(x)$ is 4 regardless of the input value $x$.

As a real-valued function of a real-valued argument, a constant function has the general form $y(x) = c$ or just $y = c$. For example, the function $y(x) = 4$ is the specific constant function where the output value is $c = 4$. The [domain of this function](wikipedia://en/50263) is the set of all [real numbers](wikipedia://en/20646438). The [image](wikipedia://en/579311) of this function is the [singleton](wikipedia://en/381798) set $\{4\}$. The independent variable *x* does not appear on the right side of the function expression and so its value is "vacuously substituted"; namely $y(0) = 4$, $y(-2.7) = 4$, $y(\pi) = 4$, and so on. No matter what value of $x$ is input, the output is $4$.[^o4]

The graph of the constant function $y = c$ is a *horizontal line* in the [plane](https://en.wikipedia.org/wiki/Plane_%28geometry%29) that passes through the point $(0, c)$.[^o5] In the context of a [polynomial](wikipedia://en/23000) in one variable $x$, the constant function is called *non-zero constant function* because it is a polynomial of degree 0, and its general form is $f(x) = c$, where $c$ is nonzero. This function has no intersection point with the $x$-axis, meaning it has no [root (zero)](wikipedia://en/264210). On the other hand, the polynomial $f(x) = 0$ is the *identically zero function*. It is the (trivial) constant function and every $x$ is a root. Its graph is the $x$-axis in the plane.[^o6] Its graph is symmetric with respect to the $y$-axis, and therefore a constant function is an [even function](wikipedia://en/592151).[^o7]

In the context where it is defined, the [derivative](wikipedia://en/7921) of a function is a measure of the rate of change of function values with respect to change in input values. Because a constant function does not change, its derivative is 0.[^o8] This is often written: $(x \mapsto c)' = 0$. The converse is also true. Namely, if $y'(x) = 0$ for all real numbers $x$, then $y$ is a constant function.[^o9] For example, given the constant function $y(x) = -\sqrt{2}$. The derivative of $y$ is the identically zero function $y'(x) = \left(x \mapsto -\sqrt{2}\right)' = 0$.

:::

## Other properties {#Other_properties}

For functions between [preordered sets](wikipedia://en/23582), constant functions are both [order-preserving](https://en.wikipedia.org/wiki/Order-preserving) and [order-reversing](https://en.wikipedia.org/wiki/Order-reversing); conversely, if $f$ is both order-preserving and order-reversing, and if the [domain](wikipedia://en/50263) of $f$ is a [lattice](wikipedia://en/469304), then $f$ must be constant.

- Every constant function whose [domain](wikipedia://en/50263) and [codomain](wikipedia://en/50264) are the same set $X$ is a [left zero](https://en.wikipedia.org/wiki/Left_zero) of the [full transformation monoid](https://en.wikipedia.org/wiki/Full_transformation_monoid) on $X$, which implies that it is also [idempotent](https://en.wikipedia.org/wiki/Idempotent).
- It has zero [slope](wikipedia://en/29368) or [gradient](wikipedia://en/12461).
- Every constant function between [topological spaces](wikipedia://en/30450) is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29).
- A constant function factors through the [one-point set](wikipedia://en/381798), the [terminal object](https://en.wikipedia.org/wiki/Terminal_object) in the [category of sets](wikipedia://en/26829). This observation is instrumental for [F. William Lawvere](https://en.wikipedia.org/wiki/F._William_Lawvere)'s axiomatization of set theory, the [Elementary Theory of the Category of Sets](https://en.wikipedia.org/wiki/Elementary_Theory_of_the_Category_of_Sets) (ETCS).[^o11]
- For any non-empty $X$, every set $Y$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the set of constant functions in $X \to Y$. For any $X$ and each element $y$ in $Y$, there is a unique function $\tilde{y}: X \to Y$ such that $\tilde{y}(x) = y$ for all $x \in X$. Conversely, if a function $f: X \to Y$ satisfies $f(x) = f(x')$ for all $x, x' \in X$, $f$ is by definition a constant function.
  - As a corollary, the one-point set is a [generator](wikipedia://en/9550415) in the category of sets.
  - Every set $X$ is canonically isomorphic to the function set $X^1$, or [hom set](https://en.wikipedia.org/wiki/Hom_set) $\operatorname{hom}(1,X)$ in the category of sets, where 1 is the one-point set. Because of this, and the adjunction between Cartesian products and hom in the category of sets (so there is a canonical isomorphism between functions of two variables and functions of one variable valued in functions of another (single) variable, $\operatorname{hom}(X \times Y, Z) \cong \operatorname{hom}(X(\operatorname{hom}(Y, Z))$) the category of sets is a [closed monoidal category](wikipedia://en/1396924) with the [Cartesian product](wikipedia://en/24104095) of sets as tensor product and the one-point set as tensor unit. In the isomorphisms $\lambda: 1 \times X \cong X \cong X \times 1: \rho$ [natural in $X$](wikipedia://en/45022), the left and right unitors are the projections $p_1$ and $p_2$ the [ordered pairs](wikipedia://en/22362) $(*, x)$ and $(x, *)$ respectively to the element $x$, where $*$ is the unique [point](https://en.wikipedia.org/wiki/Point_%28mathematics%29) in the one-point set.

A function on a [connected set](https://en.wikipedia.org/wiki/Connected_set) is [locally constant](https://en.wikipedia.org/wiki/Locally_constant) if and only if it is constant.
