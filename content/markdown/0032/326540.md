# Erdős cardinal

::: {#o1 .subject cue=lead name="Erdős cardinal"}

In [mathematics](wikipedia://en/18831), an **Erdős cardinal**, also called a **partition cardinal** is a certain kind of [large cardinal](wikipedia://en/383644) number introduced by (txt).

:::

A cardinal $\kappa$ is called $\alpha$-Erdős if for every function $f:[\kappa]^{<\omega} \to \{0,1\}$, there is a set of [order type](wikipedia://en/4499021) $\alpha$ that is [homogeneous](https://en.wikipedia.org/wiki/Homogeneous_%28large_cardinal_property%29) for $f$. In the notation of the [partition calculus](https://en.wikipedia.org/wiki/Partition_calculus), $\kappa$ is $\alpha$-Erdős if

$$\kappa \rightarrow (\alpha)^{<\omega}.$$

Under this definition, any cardinal larger than the least $\alpha$-Erdős cardinal is $\alpha$-Erdős.

The existence of [zero sharp](wikipedia://en/248085) implies that the [constructible universe](wikipedia://en/343335) $L$ satisfies "for every [countable ordinal](https://en.wikipedia.org/wiki/Countable_ordinal) $\alpha$, there is an $\alpha$-Erdős cardinal". In fact, for every [indiscernible](https://en.wikipedia.org/wiki/Indiscernible) $\kappa$, $L_\kappa$ satisfies "for every ordinal $\alpha$, there is an $\alpha$-Erdős cardinal in $\mathrm{Coll}(\omega, \alpha)$" (the [Lévy collapse](https://en.wikipedia.org/wiki/Lévy_collapse) to make $\alpha$ countable).

However, the existence of an $\omega_1$-Erdős cardinal implies existence of [zero sharp](wikipedia://en/248085). If $f$ is the [satisfaction relation](https://en.wikipedia.org/wiki/Satisfaction_relation) for $L$ (using ordinal parameters), then the existence of zero sharp is equivalent to there being an $\omega_1$-Erdős ordinal with respect to $f$. Thus, the existence of an $\omega_1$-Erdős cardinal implies that the [axiom of constructibility](wikipedia://en/696472) is false.

The least $\omega$-Erdős cardinal is not weakly compact,[^o3]<sup>p. 39.</sup> nor is the least $\omega_1$-Erdős cardinal.[^o3]<sup>p. 39</sup>

If $\kappa$ is $\alpha$-Erdős, then it is $\alpha$-Erdős in every [transitive model](https://en.wikipedia.org/wiki/Transitive_model) satisfying "$\alpha$ is countable."

## Dodd's notion of Erdős cardinals {#Dodd's_notion_of_Erdős_cardinals}

For a limit ordinal $\alpha$, a cardinal $\kappa$ is less often called $\alpha$-Erdős if for every [closed unbounded](wikipedia://en/1251559) $C\subseteq\kappa$ and every function $f:[C]^{<\omega}\rightarrow\kappa$ such that $f(x)<\min(x)$ for all $x\in [C]^{<\omega}$, there is a set $H\subseteq C$ of order-type $\alpha$ that is homogeneous for $f$.[^o5]<sup>p. 138.</sup>

An equivalent definition is that $\kappa$ is $\alpha$-Erdős if for any $A\subseteq\kappa$, there is a set $I$ of order-type $\alpha$ of [order-indiscernibles](wikipedia://en/4075543) for the structure $(L_\kappa[A];\in, A)$ such that:

- for every $\beta\in I$, $(L_\beta[A];\in, A)\prec (L_\kappa[A];\in, A)$, and
- for every $\gamma<\kappa$, the set $I\setminus\gamma$ forms a set of order-indiscernibles for the structure $(L_\kappa[A];\in, A, \xi)_{\xi<\gamma}$.

The least cardinal $\kappa$ to satisfy the partition relation $\kappa \rightarrow (\alpha)^{<\omega}$ is still $\alpha$-Erdős under this definition. Every $\omega$-Erdős cardinal is an [inaccessible](wikipedia://en/248076) limit of [ineffable cardinals](wikipedia://en/270005).[^o6]

## Strength relative to other large cardinals {#Strength_relative_to_other_large_cardinals}

For any ordinal α, α-Erdős cardinal is stronger than α-[iterable cardinal](wikipedia://en/46316193), but weaker than α+1-iterable cardinal. [virtually rank-into-rank cardinal](https://en.wikipedia.org/wiki/Virtually_rank-into-rank_cardinal) is weaker than ω-Erdős cardinal. If α \< ω<sub>1</sub>, then α-Erdős cardinal is weaker than [Silver cardinal](https://en.wikipedia.org/wiki/Silver_cardinal). ω<sub>1</sub>-Erdős cardinal is stronger than [zero sharp](wikipedia://en/248085).
