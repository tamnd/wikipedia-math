# Hyperperfect number

::: {#o1 .subject cue=lead name="Hyperperfect number"}

In [number theory](wikipedia://en/21527), a **$k$-hyperperfect number** is a [natural number](wikipedia://en/21474) $n$ for which the equality $n = 1+k(\sigma(n)-n-1)$ holds, where $\sigma(n)$ is the [divisor function](wikipedia://en/407249) (i.e., [the sum](wikipedia://en/12374274) of all positive [divisors](wikipedia://en/49492) of $n$). A **hyperperfect number** is a $k$-hyperperfect number for some integer $k$. Hyperperfect numbers generalize [perfect numbers](wikipedia://en/23670), which are 1-hyperperfect.[^o2]

:::

The first few numbers in the sequence of $k$-hyperperfect numbers are 6, 21, 28, 301, 325, 496, 697, ... , with the corresponding values of $k$ being 1, 2, 1, 6, 3, 1, 12, ... . The first few $k$-hyperperfect numbers that are not perfect are 21, 301, 325, 697, 1333, ... .

It can be shown that if $k > 1$ is an [odd](https://en.wikipedia.org/wiki/Even_and_odd_numbers) [integer](wikipedia://en/14563) and $p = \tfrac{3k+1}{2}$ and $q = 3k+4$ are [prime numbers](wikipedia://en/23666), then $p^2q$ is $k$-hyperperfect; Judson S. McCranie has conjectured in 2000 that all $k$-hyperperfect numbers for odd $k > 1$ are of this form, but the hypothesis has not been proven so far. Furthermore, it can be proven that if $p \ne q$ are odd primes and $k$ is an integer such that $k(p+q) = pq-1,$ then $pq$ is $k$-hyperperfect.

It is also possible to show that if $k > 0$ and $p = k+1$ is prime, then for all $i > 1$ such that $q = p^i - p+1$ is prime, $n = p^{i-1}q$ is $k$-hyperperfect. The following table lists known values of $k$ and corresponding values of $i$ for which $n$ is $k$-hyperperfect:
