# Woodall number

::: {#o1 .subject cue=lead name="Woodall number"}

In [number theory](wikipedia://en/21527), a **Woodall number** (*W*<sub>*n*</sub>) is any [natural number](wikipedia://en/21474) of the form

:::

$$W_n = n \cdot 2^n - 1$$

for some natural number *n*. The first few Woodall numbers are:

1, 7, 23, 63, 159, 383, 895, … .

## History {#History}

Woodall numbers were first studied by [Allan J. C. Cunningham](wikipedia://en/1572371) and [H. J. Woodall](wikipedia://en/1561620) in 1917,[^o3] inspired by [James Cullen](wikipedia://en/741786)'s earlier study of the similarly defined [Cullen numbers](wikipedia://en/321895).

## Woodall primes {#Woodall_primes}

::: {#o5 .problem cue=unsolved}

Are there infinitely many Woodall primes?

:::

Woodall numbers that are also [prime numbers](wikipedia://en/23666) are called **Woodall primes**; the first few exponents *n* for which the corresponding Woodall numbers *W*<sub>*n*</sub> are prime are 2, 3, 6, 30, 75, 81, 115, 123, 249, 362, 384, ... ; the Woodall primes themselves begin with 7, 23, 383, 32212254719, ... .

In 1976 [Christopher Hooley](wikipedia://en/5380265) showed that [almost all](wikipedia://en/1309) Cullen numbers are [composite](wikipedia://en/82289).[^o6] In October 1995, Wilfred Keller published a paper discussing several new Cullen primes and the efforts made to [factorise](https://en.wikipedia.org/wiki/Prime_factorisation) other Cullen and Woodall numbers. Included in that paper is a personal communication to Keller from [Hiromi Suyama](https://en.wikipedia.org/wiki/Hiromi_Suyama), asserting that Hooley's method can be reformulated to show that it works for any sequence of numbers $n \cdot 2^{n + a} + b$, where *a* and *b* are [integers](wikipedia://en/14563), and in particular, that almost all Woodall numbers are composite.[^o7] It is an [open problem](wikipedia://en/183091#Prime_numbers) whether there are infinitely many Woodall primes. , thirty-four Woodall primes are known, and the largest known Woodall prime is 17016602 × 2<sup>17016602</sup> − 1.[^o8] It has 5,122,515 digits and was found by Diego Bertolotti in March 2018 in the [distributed computing](https://en.wikipedia.org/wiki/Distributed_computing) project [PrimeGrid](wikipedia://en/3255603).[^o9]

## Restrictions {#Restrictions}

Starting with *W*<sub>4</sub> = 63 and *W*<sub>5</sub> = 159, every sixth Woodall number is [divisible](https://en.wikipedia.org/wiki/Divisible) by 3; thus, in order for *W*<sub>*n*</sub> to be prime, the index *n* cannot be [congruent](wikipedia://en/20087) to 4 or 5 (modulo 6). Also, for a positive integer *m*, the Woodall number *W*<sub>2<sup>*m*</sup></sub> may be prime only if 2<sup>*m*</sup> + *m* is prime. As of January 2019, the only known primes that are both Woodall primes and [Mersenne primes](https://en.wikipedia.org/wiki/Mersenne_primes) are *W*<sub>2</sub> = *M*<sub>3</sub> = 7, and *W*<sub>512</sub> = *M*<sub>521</sub>.

## Divisibility properties {#Divisibility_properties}

Like Cullen numbers, Woodall numbers have many divisibility properties. For example, if *p* is a prime number, then *p* divides

*W*<sub>(*p* + 1) / 2</sub> if the [Jacobi symbol](wikipedia://en/97313) $\left(\frac{2}{p}\right)$ is +1 and

*W*<sub>(3*p* − 1) / 2</sub> if the Jacobi symbol $\left(\frac{2}{p}\right)$ is −1.[^n1]

## Generalization {#Generalization}

A **generalized Woodall number base *b*** is defined to be a number of the form *n* × *b*<sup>*n*</sup> − 1, where *n* + 2 > *b*; if a prime can be written in this form, it is then called a **generalized Woodall prime**.

The smallest value of *n* such that *n* × *b*<sup>*n*</sup> − 1 is prime for *b* = 1, 2, 3, ... are[^o15]

3, 2, 1, 1, 8, 1, 2, 1, 10, 2, 2, 1, 2, 1, 2, 167, 2, 1, 12, 1, 2, 2, 29028, 1, 2, 3, 10, 2, 26850, 1, 8, 1, 42, 2, 6, 2, 24, 1, 2, 3, 2, 1, 2, 1, 2, 2, 140, 1, 2, 2, 22, 2, 8, 1, 2064, 2, 468, 6, 2, 1, 362, 1, 2, 2, 6, 3, 26, 1, 2, 3, 20, 1, 2, 1, 28, 2, 38, 5, 3024, 1, 2, 81, 858, 1, 2, 3, 2, 8, 60, 1, 2, 2, 10, 5, 2, 7, 182, 1, 17782, 3, ...

, the largest known generalized Woodall prime with base greater than 2 is 2740879 × 32<sup>2740879</sup> − 1.[^o16]

:::
