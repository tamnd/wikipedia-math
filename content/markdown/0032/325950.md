# Extendible cardinal

::: {#o1 .subject cue=lead name="Extendible cardinal"}

In [mathematics](wikipedia://en/18831), **extendible cardinals** are [large cardinals](wikipedia://en/383644) introduced by (Reinhardt 1974), who was partly motivated by [reflection principles](wikipedia://en/3225574). Intuitively, such a cardinal represents a point beyond which initial pieces of the [universe of sets](wikipedia://en/445980) start to look similar, in the sense that each is [elementarily embeddable](https://en.wikipedia.org/wiki/Elementary_embedding) into a later one.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For every [ordinal](wikipedia://en/26547932) *η*, a [cardinal](wikipedia://en/6173) κ is called **η-extendible** if for some ordinal *λ* there is a nontrivial [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* of *V*<sub>κ+η</sub> into *V*<sub>λ</sub>, where *κ* is the [critical point](wikipedia://en/4888510) of *j*, and as usual *V<sub>α</sub>* denotes the *α*th level of the [von Neumann hierarchy](wikipedia://en/445980). A cardinal *κ* is called an **extendible cardinal** if it is *η*-extendible for every nonzero ordinal *η* (Kanamori 2003).

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

For a cardinal $\kappa$, say that a logic $L$ is $\kappa$-compact if for every set $A$ of $L$-sentences, if every subset of $A$ or cardinality $<\kappa$ has a model, then $A$ has a model. (The usual [compactness theorem](wikipedia://en/152207) shows $\aleph_0$-compactness of first-order logic.) Let $L_\kappa^2$ be the [infinitary logic](wikipedia://en/630478) for second-order set theory, permitting infinitary conjunctions and disjunctions of length $<\kappa$. $\kappa$ is extendible iff $L_\kappa^2$ is $\kappa$-compact.[^o7]

:::

## Variants and relation to other cardinals {#Variants_and_relation_to_other_cardinals}

A cardinal *κ* is called *η-C<sup>(n)</sup>*-extendible if there is an elementary embedding *j* witnessing that *κ* is *η*-extendible (that is, *j* is elementary from *V<sub>κ+η</sub>* to some *V<sub>λ</sub>* with critical point *κ*) such that furthermore, *V<sub>j(κ)</sub>* is *Σ<sub>n</sub>*-correct in *V*. That is, for every [*Σ<sub>n</sub>*](wikipedia://en/25129404#Definitions) formula *φ*, *φ* holds in *V<sub>j(κ)</sub>* if and only if *φ* holds in *V*. A cardinal *κ* is said to be **C<sup>(n)</sup>-extendible** if it is *η-C<sup>(n)</sup>*-extendible for every ordinal *η*. Every extendible cardinal is *C<sup>(1)</sup>*-extendible, but for *n≥1*, the least *C<sup>(n)</sup>*-extendible cardinal is never *C<sup>(n+1)</sup>*-extendible (Bagaria 2011).

[Vopěnka's principle](wikipedia://en/3995195) implies the existence of extendible cardinals; in fact, Vopěnka's principle (for definable classes) is equivalent to the existence of *C<sup>(n)</sup>*-extendible cardinals for all *n* (Bagaria 2011). All extendible cardinals are [supercompact cardinals](wikipedia://en/248116) (Kanamori 2003).
