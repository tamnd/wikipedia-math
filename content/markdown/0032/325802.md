# Glossary of graph theory

::: {#o1 .subject cue=lead name="Glossary of graph theory"}

This is a **glossary of graph theory**. [Graph theory](wikipedia://en/12401) is the study of [graphs](wikipedia://en/325806), systems of nodes or [vertices](wikipedia://en/638899) connected in pairs by lines or edges.

:::

## Symbols {#Symbols}

::: {#o3 .entry cue=term name="square bracket"}

**square bracket**

$G[S]$ is the induced subgraph of a graph $G$ for vertex subset $S$.

:::

::: {#o4 .entry cue=term name="′"}

**′**

The [prime symbol](https://en.wikipedia.org/wiki/Prime_%28symbol%29) is often used to modify notation for graph invariants so that it applies to the [line graph](wikipedia://en/675231) instead of the given graph. For instance, $\alpha(G)$ is the independence number of a graph; $\alpha'(G)$ is the matching number of the graph, which equals the independence number of its line graph. Similarly, $\chi(G)$ is the chromatic number of a graph; $\chi\,'(G)$ is the chromatic index of the graph, which equals the chromatic number of its line graph.

:::

## A {#A}

::: {#o6 .entry cue=term name="absorbing"}

**absorbing**

An absorbing set $A$ of a directed graph $G$ is a set of vertices such that for any vertex $v \in G \setminus A$, there is an edge from $v$ towards a vertex of $A$.

:::

::: {#o7 .entry cue=term name="achromatic"}

**achromatic**

The [achromatic number](https://en.wikipedia.org/wiki/Achromatic_number) of a graph is the maximum number of colors in a complete coloring.[^o8]

:::

::: {#o9 .entry cue=term name="acyclic"}

**acyclic**

A graph is acyclic if it has no cycles. An undirected acyclic graph is the same thing as a [forest](wikipedia://en/48560). An acyclic directed graph, which is a digraph without directed cycles, is often called a [directed acyclic graph](wikipedia://en/204002), especially in computer science.[^o10]

An [acyclic coloring](wikipedia://en/690769) of an undirected graph is a proper coloring in which every two color classes induce a forest.[^o11]

:::

::: {#o12 .entry cue=term name="adjacency matrix"}

**adjacency matrix**

The [adjacency matrix](wikipedia://en/244463) of a graph is a matrix whose rows and columns are both indexed by vertices of the graph, with a one in the cell for row $i$ and column $j$ when vertices $i$ and $j$ are adjacent, and a zero otherwise.[^o13]

:::

::: {#o14 .entry cue=term name="adjacent"}

**adjacent**

The relation between two vertices that are both endpoints of the same edge.[^o10]

The relation between two distinct edges that share an end vertex.[^o15]

:::

::: {#o16 .entry cue=term name="alpha"}

**alpha**

For a graph $G$, $\alpha(G)$ (using the Greek letter alpha) is its independence number (see independent), and $\alpha'(G)$ is its matching number (see matching).

:::

::: {#o17 .entry cue=term name="alternating"}

**alternating**

In a graph with a matching, an alternating path is a path whose edges alternate between matched and unmatched edges. An alternating cycle is, similarly, a cycle whose edges alternate between matched and unmatched edges. An augmenting path is an alternating path that starts and ends at unsaturated vertices. A larger matching can be found as the [symmetric difference](wikipedia://en/262288) of the matching and the augmenting path; a matching is maximum if and only if it has no augmenting path.

:::

::: {#o18 .entry cue=term name="antichain"}

**antichain**

In a [directed acyclic graph](wikipedia://en/204002), a subset $S$ of vertices that are pairwise incomparable, i.e., for any $x \leq y$ in $S$, there is no directed path from $x$ to $y$ or from $y$ to $x$. Inspired by the notion of [antichains](wikipedia://en/348973) in [partially ordered sets](wikipedia://en/23572).

:::

::: {#o19 .entry cue=term name="anti-edge"}

**anti-edge**

Synonym for *non-edge*, a pair of non-adjacent vertices.

:::

::: {#o20 .entry cue=term name="anti-triangle"}

**anti-triangle**

A three-vertex independent set, the complement of a triangle.

:::

::: {#o21 .entry cue=term name="apex"}

**apex**

An [apex graph](wikipedia://en/28228942) is a graph in which one vertex can be removed, leaving a planar subgraph. The removed vertex is called the apex. A $k$-apex graph is a graph that can be made planar by the removal of $k$ vertices.

Synonym for [universal vertex](wikipedia://en/51352780), a vertex adjacent to all other vertices.

:::

::: {#o22 .entry cue=term name="arborescence"}

**arborescence**

Synonym for a rooted and directed tree; see tree.

:::

::: {#o23 .entry cue=term name="arc"}

**arc**

See edge.

:::

::: {#o24 .entry cue=term name="arrow"}

**arrow**

An [ordered pair](wikipedia://en/22362) of vertices, such as an edge in a directed graph. An arrow $(x, y)$ has a tail $x$, a head $y$, and a direction $\text{from } x\text{ to } y$; $y$ is said to be the direct successor to $x$ and $x$ the direct predecessor to $y$. The arrow $(y, x)$ is the inverted arrow of the arrow $(x, y)$.

:::

::: {#o25 .entry cue=term name="articulation point"}

**articulation point**

A vertex in a connected graph whose removal would disconnect the graph. More generally, a vertex whose removal increases the number of components.

:::

::: {#o26 .entry cue=term name="k-ary"}

**k-ary**

A [$k$-ary tree](https://en.wikipedia.org/wiki/K-ary_tree) is a rooted tree in which every internal vertex has no more than $k$ children. A 1-ary tree is just a path. A 2-ary tree is also called a [binary tree](wikipedia://en/4321), although that term more properly refers to 2-ary trees in which the children of each node are distinguished as being left or right children (with at most one of each type). A $k$-ary tree is said to be complete if every internal vertex has exactly $k$ children.

:::

::: {#o27 .entry cue=term name="augmenting"}

**augmenting**

A special type of alternating path; see alternating.

:::

::: {#o28 .entry cue=term name="automorphism"}

**automorphism**

A [graph automorphism](wikipedia://en/15094186) is a symmetry of a graph, an isomorphism from the graph to itself.

:::

## B {#B}

::: {#o30 .entry cue=term name="bag"}

**bag**

One of the sets of vertices in a tree decomposition.

:::

::: {#o31 .entry cue=term name="balanced"}

**balanced**

A bipartite or multipartite graph is balanced if each two subsets of its vertex partition have sizes within one of each other.

:::

::: {#o32 .entry cue=term name="ball"}

**ball**

A ball (also known as a neighborhood ball or distance ball) is the set of all vertices that are at most distance r from a vertex. More formally, for a given vertex v and radius r, the ball B(v,r) consists of all vertices whose shortest path distance to v is less than or equal to r.

:::

::: {#o33 .entry cue=term name="bandwidth"}

**bandwidth**

The [bandwidth](wikipedia://en/27414778) of a graph $G$ is the minimum, over all orderings of vertices of $G$, of the length of the longest edge (the number of steps in the ordering between its two endpoints). It is also one less than the size of the maximum clique in a proper interval completion of $G$, chosen to minimize the clique size.

:::

::: {#o34 .entry cue=term name="biclique"}

**biclique**

Synonym for [complete bipartite graph](wikipedia://en/525320) or complete bipartite subgraph; see complete.

:::

::: {#o35 .entry cue=term name="biconnected"}

**biconnected**

Usually a synonym for [$2$-vertex-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph), but sometimes includes *K*<sub>2</sub> though it is not 2-connected. See connected; for [biconnected components](wikipedia://en/4842394), see component.

:::

::: {#o36 .entry cue=term name="binding number"}

**binding number**

The smallest possible ratio of the number of neighbors of a proper subset of vertices to the size of the subset.[^o37]

:::

::: {#o38 .entry cue=term name="bipartite"}

**bipartite**

A [bipartite graph](wikipedia://en/244431) is a graph whose vertices can be divided into two disjoint sets such that the vertices in one set are not connected to each other, but may be connected to vertices in the other set. Put another way, a bipartite graph is a graph with no odd cycles; equivalently, it is a graph that may be properly colored with two colors. Bipartite graphs are often written $G = (U,V,E)$ where $U$ and $V$ are the subsets of vertices of each color. However, unless the graph is connected, it may not have a unique 2-coloring.

:::

::: {#o39 .entry cue=term name="biregular"}

**biregular**

A [biregular graph](wikipedia://en/36895088) is a bipartite graph in which there are only two different vertex degrees, one for each set of the vertex bipartition.

:::

::: {#o40 .entry cue=term name="block"}

**block**

A block of a graph $G$ is a maximal subgraph which is either an isolated vertex, a bridge edge, or a 2-connected subgraph. If a block is 2-connected, every pair of vertices in it belong to a common cycle. Every edge of a graph belongs in exactly one block.

The block graph of a graph $G$ is another graph whose vertices are the blocks of $G$, with an edge connecting two vertices when the corresponding blocks share an articulation point; that is, it is the intersection graph of the blocks of $G$. The block graph of any graph is a forest.

The block-cut (or block-cutpoint) graph of a graph $G$ is a bipartite graph where one partite set consists of the cut-vertices of $G$, and the other has a vertex $b_i$ for each block $B_i$ of $G$. When $G$ is connected, its block-cutpoint graph is a tree.

A [block graph](wikipedia://en/29106883) (also called a clique tree if connected, and sometimes erroneously called a Husimi tree) is a graph all of whose blocks are complete graphs. A forest is a block graph; so in particular the block graph of any graph is a block graph, and every block graph may be constructed as the block graph of a graph.

:::

::: {#o41 .entry cue=term name="bond"}

**bond**

A minimal cut-set: a set of edges whose removal disconnects the graph, for which no proper subset has the same property.

:::

::: {#o42 .entry cue=term name="book"}

**book**

A [book](wikipedia://en/2597784), book graph, or triangular book is a complete tripartite graph $K_{1,1,n}$; a collection of $n$ triangles joined at a shared edge.

Another type of graph, also called a book, or a quadrilateral book, is a collection of $4$-cycles joined at a shared edge; the Cartesian product of a star with an edge.

A [book embedding](wikipedia://en/3987703) is an embedding of a graph onto a topological book, a space formed by joining a collection of half-planes along a shared line. Usually, the vertices of the embedding are required to be on the line, which is called the spine of the embedding, and the edges of the embedding are required to lie within a single half-plane, one of the pages of the book.

:::

::: {#o43 .entry cue=term name="boundary"}

**boundary**

In a [graph embedding](wikipedia://en/8149170), a boundary walk is the subgraph containing all incident edges and vertices to a face.

:::

::: {#o44 .entry cue=term name="bramble"}

**bramble**

A [bramble](wikipedia://en/36601188) is a collection of mutually touching connected subgraphs, where two subgraphs touch if they share a vertex or each includes one endpoint of an edge. The order of a bramble is the smallest size of a set of vertices that has a nonempty intersection with all of the subgraphs. The treewidth of a graph is the maximum order of any of its brambles.

:::

::: {#o45 .entry cue=term name="branch"}

**branch**

A path of degree-two vertices, ending at vertices whose degree is unequal to two.[^o46]

:::

::: {#o47 .entry cue=term name="branch-decomposition"}

**branch-decomposition**

A [branch-decomposition](wikipedia://en/16823137) of $G$ is a hierarchical clustering of the edges of $G$, represented by an unrooted binary tree with its leaves labeled by the edges of $G$. The width of a branch-decomposition is the maximum, over edges $e$ of this binary tree, of the number of shared vertices between the subgraphs determined by the edges of $G$ in the two subtrees separated by $e$. The branchwidth of $G$ is the minimum width of any branch-decomposition of $G$.

:::

::: {#o48 .entry cue=term name="branchwidth"}

**branchwidth**

See branch-decomposition.

:::

::: {#o49 .entry cue=term name="bridge"}

**bridge**

A [bridge](wikipedia://en/1305071), isthmus, or cut edge is an edge whose removal would disconnect the graph. A bridgeless graph is one that has no bridges; equivalently, a 2-edge-connected graph.

A bridge of a subgraph *H* is a maximal connected subgraph separated from the rest of the graph by *H*. That is, it is a maximal subgraph that is edge-disjoint from *H* and in which each two vertices and edges belong to a path that is internally disjoint from *H*. *H* may be a set of vertices. A chord is a one-edge bridge. In [planarity testing](wikipedia://en/15972636), *H* is a cycle and a [peripheral cycle](wikipedia://en/12649450) is a cycle with at most one bridge; it must be a face boundary in any planar embedding of its graph.

A bridge of a cycle can also mean a path that connects two vertices of a cycle but is shorter than either of the paths in the cycle connecting the same two vertices. A [bridged graph](https://en.wikipedia.org/wiki/Bridged_graph) is a graph in which every cycle of four or more vertices has a bridge.

:::

::: {#o50 .entry cue=term name="bridgeless"}

**bridgeless**

A [bridgeless](https://en.wikipedia.org/wiki/Bridgeless_graph) or isthmus-free graph is a graph that has no bridge edges (i.e., isthmi); that is, each connected component is a [2-edge-connected graph](https://en.wikipedia.org/wiki/K-edge-connected_graph).

:::

::: {#o51 .entry cue=term name="butterfly"}

**butterfly**

The [butterfly graph](wikipedia://en/4372111) has five vertices and six edges; it is formed by two triangles that share a vertex.

The butterfly network is a graph used as a network architecture in distributed computing, closely related to the [cube-connected cycles](wikipedia://en/13379568).

:::

## C {#C}

::: {#o53 .entry cue=term name="C"}

**C**

$C_{n}$ is an $n$-vertex [cycle graph](wikipedia://en/878962); see cycle.

:::

::: {#o54 .entry cue=term name="cactus"}

**cactus**

A [cactus graph](wikipedia://en/9944209), cactus tree, cactus, or Husimi tree is a connected graph in which each edge belongs to at most one cycle. Its blocks are cycles or single edges. If, in addition, each vertex belongs to at most two blocks, then it is called a Christmas cactus.

:::

::: {#o55 .entry cue=term name="cage"}

**cage**

A [cage](wikipedia://en/7735022) is a regular graph with the smallest possible order for its girth.

:::

::: {#o56 .entry cue=term name="canonical"}

**canonical**

:::

::: {#o57 .entry cue=term name="canonization"}

**canonization**

A [canonical form](wikipedia://en/515096) of a graph is an invariant such that two graphs have equal invariants if and only if they are isomorphic. Canonical forms may also be called canonical invariants or complete invariants, and are sometimes defined only for the graphs within a particular family of graphs. [Graph canonization](wikipedia://en/20199287) is the process of computing a canonical form.

:::

::: {#o58 .entry cue=term name="card"}

**card**

A graph formed from a given graph by deleting one vertex, especially in the context of the [reconstruction conjecture](wikipedia://en/255594). See also deck, the multiset of all cards of a graph.

:::

::: {#o59 .entry cue=term name="carving width"}

**carving width**

Carving width is a notion of graph width analogous to branchwidth, but using hierarchical clusterings of vertices instead of hierarchical clusterings of edges.

:::

::: {#o60 .entry cue=term name="caterpillar"}

**caterpillar**

A [caterpillar tree](wikipedia://en/27258886) or caterpillar is a tree in which the internal nodes induce a path.

:::

::: {#o61 .entry cue=term name="center"}

**center**

The [center](wikipedia://en/10447275) of a graph is the set of vertices of minimum eccentricity.

:::

::: {#o62 .entry cue=term name="centroid"}

**centroid**

A [centroid](https://en.wikipedia.org/wiki/Centroid_%28graph_theory%29) of a tree is a vertex $v$ such that if rooted at $v$, no other vertex has subtree size greater than half the size of the tree.

:::

::: {#o63 .entry cue=term name="chain"}

**chain**

Synonym for walk.

When applying methods from [algebraic topology](wikipedia://en/38801) to graphs, an element of a [chain complex](wikipedia://en/138404), namely a set of vertices or a set of edges.

:::

::: {#o64 .entry cue=term name="Cheeger constant"}

**Cheeger constant**

See expansion.

:::

::: {#o65 .entry cue=term name="cherry"}

**cherry**

A cherry is a path on three vertices.[^o66]

:::

::: {#o67 .entry cue=term name="chi"}

**chi**

$\chi(G)$ (using the Greek letter chi) is the chromatic number of $G$ and $\chi\,'(G)$ is its chromatic index; see chromatic and coloring.

:::

::: {#o68 .entry cue=term name="child"}

**child**

In a rooted tree, a child of a vertex $v$ is a neighbor of $v$ along an outgoing edge, one that is directed away from the root.

:::

::: {#o69 .entry cue=term name="chord"}

**chord**

:::

::: {#o70 .entry cue=term name="chordal"}

**chordal**

A chord of a cycle is an edge that does not belong to the cycle, for which both endpoints belong to the cycle.

A [chordal graph](wikipedia://en/744165) is a graph in which every cycle of four or more vertices has a chord, so the only induced cycles are triangles.

A [strongly chordal graph](wikipedia://en/24809733) is a chordal graph in which every cycle of length six or more has an odd chord.

A [chordal bipartite graph](wikipedia://en/44355462) is not chordal (unless it is a forest); it is a bipartite graph in which every cycle of six or more vertices has a chord, so the only induced cycles are 4-cycles.

A [chord of a circle](wikipedia://en/297947) is a line segment connecting two points on the circle; the [intersection graph](wikipedia://en/7726759) of a collection of chords is called a [circle graph](wikipedia://en/1399873).

:::

::: {#o71 .entry cue=term name="chromatic"}

**chromatic**

Having to do with coloring; see color. Chromatic graph theory is the theory of graph coloring. The [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) $\chi(G)$ is the minimum number of colors needed in a proper coloring of $G$. $\chi\,'(G)$ is the [chromatic index](https://en.wikipedia.org/wiki/Chromatic_index) of $G$, the minimum number of colors needed in a proper [edge coloring](wikipedia://en/690647) of $G$.

:::

::: {#o72 .entry cue=term name="choosable"}

**choosable**

:::

::: {#o73 .entry cue=term name="choosability"}

**choosability**

A graph is $k$-choosable if it has a [list coloring](wikipedia://en/690669) whenever each vertex has a list of $k$ available colors. The choosability of the graph is the smallest $k$ for which it is $k$-choosable.

:::

::: {#o74 .entry cue=term name="circle"}

**circle**

A [circle graph](wikipedia://en/1399873) is the [intersection graph](wikipedia://en/7726759) of chords of a circle.

:::

::: {#o75 .entry cue=term name="circuit"}

**circuit**

A [circuit](wikipedia://en/168609) may refer to a closed trail or an element of the [cycle space](wikipedia://en/262243) (an Eulerian spanning subgraph). The [circuit rank](https://en.wikipedia.org/wiki/Circuit_rank) of a graph is the dimension of its cycle space.

:::

::: {#o76 .entry cue=term name="circumference"}

**circumference**

The [circumference](https://en.wikipedia.org/wiki/Circumference_%28graph_theory%29) of a graph is the length of its longest simple cycle. The graph is Hamiltonian if and only if its circumference equals its order.

:::

::: {#o77 .entry cue=term name="class"}

**class**

A [class](wikipedia://en/20696) of graphs or family of graphs is a (usually infinite) collection of graphs, often defined as the graphs having some specific property. The word "class" is used rather than "set" because, unless special restrictions are made (such as restricting the vertices to be drawn from a particular set, and defining edges to be sets of two vertices) classes of graphs are usually not sets when formalized using set theory.

A color class of a colored graph is the set of vertices or edges having one particular color.

In the context of [Vizing's theorem](wikipedia://en/5449464), on edge coloring simple graphs, a graph is said to be of class one if its chromatic index equals its maximum degree, and class two if its chromatic index equals one plus the degree. According to Vizing's theorem, all simple graphs are either of class one or class two.

:::

::: {#o78 .entry cue=term name="claw"}

**claw**

A [claw](https://en.wikipedia.org/wiki/Claw_%28graph_theory%29) is a tree with one internal vertex and three leaves, or equivalently the complete bipartite graph $K_{1,3}$. A [claw-free graph](wikipedia://en/12415907) is a graph that does not have an induced subgraph that is a claw.

:::

::: {#o79 .entry cue=term name="clique"}

**clique**

A [clique](wikipedia://en/524466) is a set of mutually adjacent vertices (or the complete subgraph induced by that set). Sometimes a clique is defined as a maximal set of mutually adjacent vertices (or maximal complete subgraph), one that is not part of any larger such set (or subgraph). A $k$-clique is a clique of order $k$. The [clique number](https://en.wikipedia.org/wiki/Clique_number) $\omega(G)$ of a graph $G$ is the order of its largest clique. The [clique graph](https://en.wikipedia.org/wiki/Clique_graph) of a graph *G* is the [intersection graph](wikipedia://en/7726759) of the maximal cliques in *G*. See also biclique, a complete bipartite subgraph.

:::

::: {#o80 .entry cue=term name="clique tree"}

**clique tree**

A synonym for a block graph.

:::

::: {#o81 .entry cue=term name="clique-width"}

**clique-width**

The [clique-width](wikipedia://en/16795502) of a graph $G$ is the minimum number of distinct labels needed to construct $G$ by operations that create a labeled vertex, form the disjoint union of two labeled graphs, add an edge connecting all pairs of vertices with given labels, or relabel all vertices with a given label. The graphs of clique-width at most $2$ are exactly the [cographs](wikipedia://en/1175666).

:::

::: {#o82 .entry cue=term name="closed"}

**closed**

A closed neighborhood is one that includes its central vertex; see neighbourhood.

A closed walk is one that starts and ends at the same vertex; see walk.

A graph is transitively closed if it equals its own transitive closure; see transitive.

A graph property is closed under some operation on graphs if, whenever the argument or arguments to the operation have the property, then so does the result. For instance, hereditary properties are closed under induced subgraphs; monotone properties are closed under subgraphs; and minor-closed properties are closed under minors.

:::

::: {#o83 .entry cue=term name="closure"}

**closure**

For the transitive closure of a directed graph, see transitive.

A closure of a directed graph is a set of vertices that have no outgoing edges to vertices outside the closure. For instance, a sink is a one-vertex closure. The [closure problem](https://en.wikipedia.org/wiki/Closure_problem) is the problem of finding a closure of minimum or maximum weight.

:::

::: {#o84 .entry cue=term name="co-"}

**co-**

This prefix has various meanings usually involving [complement graphs](wikipedia://en/1175649). For instance, a [cograph](wikipedia://en/1175666) is a graph produced by operations that include complementation; a [cocoloring](wikipedia://en/702837) is a coloring in which each vertex induces either an independent set (as in proper coloring) or a clique (as in a coloring of the complement).

:::

::: {#o85 .entry cue=term name="color"}

**color**

:::

::: {#o86 .entry cue=term name="coloring"}

**coloring**

A [graph coloring](wikipedia://en/426743) is a labeling of the vertices of a graph by elements from a given set of colors, or equivalently a partition of the vertices into subsets, called "color classes", each of which is associated with one of the colors.

Some authors use "coloring", without qualification, to mean a proper coloring, one that assigns different colors to the endpoints of each edge. In graph coloring, the goal is to find a proper coloring that uses as few colors as possible; for instance, [bipartite graphs](wikipedia://en/244431) are the graphs that have colorings with only two colors, and the [four color theorem](wikipedia://en/10949) states that every [planar graph](wikipedia://en/24314) can be colored with at most four colors. A graph is said to be $k$-colored if it has been (properly) colored with $k$ colors, and $k$-colorable or $k$-chromatic if this is possible.

Many variations of coloring have been studied, including [edge coloring](wikipedia://en/690647) (coloring edges so that no two edges with the same endpoint share a color), [list coloring](wikipedia://en/690669) (proper coloring with each vertex restricted to a subset of the available colors), [acyclic coloring](wikipedia://en/690769) (every 2-colored subgraph is acyclic), co-coloring (every color class induces an independent set or a clique), [complete coloring](wikipedia://en/690736) (every two color classes share an edge), and [total coloring](wikipedia://en/690702) (both edges and vertices are colored).

The coloring number of a graph is one plus the [degeneracy](wikipedia://en/27545816). It is so called because applying a greedy coloring algorithm to a degeneracy ordering of the graph uses at most this many colors.

:::

::: {#o87 .entry cue=term name="commuting graph"}

**commuting graph**

A [commuting graph](wikipedia://en/81460329) of a [group](wikipedia://en/19447) or more generally a [semigroup](wikipedia://en/27799) is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) in which the vertices are elements of the group/semigroup and there is an edge between any pair of elements that [commute](wikipedia://en/294390) (that is, there is an edge between vertices $x$ and $y$ if and only if $xy=yx$).

:::

::: {#o88 .entry cue=term name="comparability"}

**comparability**

An undirected graph is a [comparability graph](wikipedia://en/6978672) if its vertices are the elements of a [partially ordered set](wikipedia://en/23572) and two vertices are adjacent when they are comparable in the partial order. Equivalently, a comparability graph is a graph that has a transitive orientation. Many other classes of graphs can be defined as the comparability graphs of special types of partial order.

:::

::: {#o89 .entry cue=term name="complement"}

**complement**

The [complement graph](wikipedia://en/1175649) $\bar{G}$ of a simple graph $G$ is another graph on the same vertex set as $G$, with an edge for each two vertices that are not adjacent in $G$.

:::

::: {#o90 .entry cue=term name="complete"}

**complete**

A [complete graph](wikipedia://en/85816) is one in which every two vertices are adjacent: all edges that could exist are present. A complete graph with $n$ vertices is often denoted $K_{n}$. A [complete bipartite graph](wikipedia://en/525320) is one in which every two vertices on opposite sides of the partition of vertices are adjacent. A complete bipartite graph with $a$ vertices on one side of the partition and $b$ vertices on the other side is often denoted $K_{a,b}$. The same terminology and notation has also been extended to [complete multipartite graphs](https://en.wikipedia.org/wiki/Complete_multipartite_graph), graphs in which the vertices are divided into more than two subsets and every pair of vertices in different subsets are adjacent; if the numbers of vertices in the subsets are $a, b, c, ...$ then this graph is denoted $K_{a, b, c, ...}$.

A completion of a given graph is a supergraph that has some desired property. For instance, a [chordal completion](wikipedia://en/48088710) is a supergraph that is a chordal graph.

A complete matching is a synonym for a [perfect matching](wikipedia://en/44031); see matching.

A [complete coloring](wikipedia://en/690736) is a proper coloring in which each pairs of colors is used for the endpoints of at least one edge. Every coloring with a minimum number of colors is complete, but there may exist complete colorings with larger numbers of colors. The [achromatic number](https://en.wikipedia.org/wiki/Achromatic_number) of a graph is the maximum number of colors in a complete coloring.

A complete invariant of a graph is a synonym for a canonical form, an invariant that has different values for non-isomorphic graphs.

:::

::: {#o91 .entry cue=term name="component"}

**component**

A [connected component](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) of a graph is a maximal connected subgraph. The term is also used for maximal subgraphs or subsets of a graph's vertices that have some higher order of connectivity, including [biconnected components](wikipedia://en/4842394), [triconnected components](https://en.wikipedia.org/wiki/Triconnected_component), and [strongly connected components](wikipedia://en/684680).

:::

::: {#o92 .entry cue=term name="condensation"}

**condensation**

The [condensation](https://en.wikipedia.org/wiki/Condensation_%28graph_theory%29) of a directed graph $G$ is a directed acyclic graph with one vertex for each strongly connected component of $G$, and an edge connecting pairs of components that contain the two endpoints of at least one edge in $G$.

:::

::: {#o93 .entry cue=term name="cone"}

**cone**

A graph that contains a [universal vertex](wikipedia://en/51352780).

:::

::: {#o94 .entry cue=term name="connect"}

**connect**

Cause to be connected.

:::

::: {#o95 .entry cue=term name="connected"}

**connected**

A [connected graph](wikipedia://en/1614492) is one in which each pair of vertices forms the endpoints of a path. Higher forms of connectivity include strong connectivity in directed graphs (for each two vertices there are paths from one to the other in both directions), [$k$-vertex-connected graphs](https://en.wikipedia.org/wiki/K-vertex-connected_graph) (removing fewer than $k$ vertices cannot disconnect the graph), and [$k$-edge-connected graphs](https://en.wikipedia.org/wiki/K-edge-connected_graph) (removing fewer than $k$ edges cannot disconnect the graph).

:::

::: {#o96 .entry cue=term name="connected component"}

**connected component**

Synonym for component.

:::

::: {#o97 .entry cue=term name="contraction"}

**contraction**

[Edge contraction](wikipedia://en/3758115) is an elementary operation that removes an edge from a graph while merging the two vertices that it previously joined. Vertex contraction (sometimes called vertex identification) is similar, but the two vertices are not necessarily connected by an edge. Path contraction occurs upon the set of edges in a path that contract to form a single edge between the endpoints of the path. The inverse of edge contraction is vertex splitting.

:::

::: {#o98 .entry cue=term name="converse"}

**converse**

The converse graph is a synonym for the transpose graph; see transpose.

:::

::: {#o99 .entry cue=term name="core"}

**core**

A [$k$-core](https://en.wikipedia.org/wiki/K-core) is the induced subgraph formed by removing all vertices of degree less than $k$, and all vertices whose degree becomes less than $k$ after earlier removals. See degeneracy.

A [core](https://en.wikipedia.org/wiki/Core_%28graph_theory%29) is a graph $G$ such that every [graph homomorphism](wikipedia://en/676328) from $G$ to itself is an isomorphism.

The [core](https://en.wikipedia.org/wiki/Core_%28graph_theory%29) of a graph $G$ is a minimal graph $H$ such that there exist homomorphisms from $G$ to $H$ and vice versa. $H$ is unique up to isomorphism. It can be represented as an induced subgraph of $G$, and is a core in the sense that all of its self-homomorphisms are isomorphisms.

In the theory of graph matchings, the core of a graph is an aspect of its [Dulmage–Mendelsohn decomposition](wikipedia://en/2669524), formed as the union of all maximum matchings.

:::

::: {#o100 .entry cue=term name="cotree"}

**cotree**

The complement of a [spanning tree](wikipedia://en/455770).

A rooted tree structure used to describe a [cograph](wikipedia://en/1175666), in which each cograph vertex is a leaf of the tree, each internal node of the tree is labeled with 0 or 1, and two cograph vertices are adjacent if and only if their lowest common ancestor in the tree is labeled 1.

:::

::: {#o101 .entry cue=term name="cover"}

**cover**

A [vertex cover](wikipedia://en/562782) is a set of vertices incident to every edge in a graph. An [edge cover](wikipedia://en/4577392) is a set of edges incident to every vertex in a graph. A set of subgraphs of a graph covers that graph if its [union](wikipedia://en/9938244#Binary_operations) – taken vertex-wise and edge-wise – is equal to the graph.

:::

::: {#o102 .entry cue=term name="critical"}

**critical**

A critical graph for a given property is a graph that has the property but such that every subgraph formed by deleting a single vertex does not have the property. For instance, a [factor-critical graph](wikipedia://en/7684634) is one that has a perfect matching (a 1-factor) for every vertex deletion, but (because it has an odd number of vertices) has no perfect matching itself. Compare *hypo-*, used for graphs which do not have a property but for which every one-vertex deletion does.

:::

::: {#o103 .entry cue=term name="cube"}

**cube**

:::

::: {#o104 .entry cue=term name="cubic"}

**cubic**

[Cube graph](https://en.wikipedia.org/wiki/Cube_graph), the eight-vertex graph of the vertices and edges of a cube.

[Hypercube graph](wikipedia://en/6706815), a higher-dimensional generalization of the cube graph.

[Folded cube graph](https://en.wikipedia.org/wiki/Folded_cube_graph), formed from a hypercube by adding a matching connecting opposite vertices.

[Halved cube graph](wikipedia://en/39329236), the [half-square](https://en.wikipedia.org/wiki/Half-square) of a hypercube graph.

[Partial cube](wikipedia://en/30697444), a distance-preserving subgraph of a hypercube.

The cube of a graph $G$ is the [graph power](wikipedia://en/38618878) $G^{3}$.

[Cubic graph](wikipedia://en/980508), another name for a $3$-regular graph, one in which each vertex has three incident edges.

[Cube-connected cycles](wikipedia://en/13379568), a cubic graph formed by replacing each vertex of a hypercube by a cycle.

:::

::: {#o105 .entry cue=term name="cut"}

**cut**

:::

::: {#o106 .entry cue=term name="cut-set"}

**cut-set**

A [cut](wikipedia://en/2180494) is a partition of the vertices of a graph into two subsets, or the set (also known as a cut-set) of edges that span such a partition, if that set is non-empty. An edge is said to span the partition if it has endpoints in both subsets. Thus, the removal of a cut-set from a connected graph disconnects it.

:::

::: {#o107 .entry cue=term name="cut point"}

**cut point**

See articulation point.

:::

::: {#o108 .entry cue=term name="cut space"}

**cut space**

The [cut space](https://en.wikipedia.org/wiki/Cut_space) of a graph is a [GF(2)](wikipedia://en/11137263)-[vector space](wikipedia://en/32370) having the cut-sets of the graph as its elements and [symmetric difference](wikipedia://en/262288) of sets as its vector addition operation.

:::

::: {#o109 .entry cue=term name="cycle"}

**cycle**

A [cycle](wikipedia://en/168609) may be either a kind of graph or a kind of walk. As a walk it may be either be a closed walk (also called a tour) or more usually a closed walk without repeated vertices and consequently edges (also called a simple cycle). In the latter case it is usually regarded as a graph, i.e., the choices of first vertex and direction are usually considered unimportant; that is, [cyclic permutations](wikipedia://en/449166) and reversals of the walk produce the same cycle. Important special types of cycle include [Hamiltonian cycles](https://en.wikipedia.org/wiki/Hamiltonian_cycle), [induced cycles](https://en.wikipedia.org/wiki/Induced_cycle), [peripheral cycles](wikipedia://en/12649450), and the shortest cycle, which defines the [girth](wikipedia://en/12013) of a graph. A $k$-cycle is a cycle of length $k$; for instance a $2$-cycle is a [digon](wikipedia://en/5442728) and a $3$-cycle is a triangle. A [cycle graph](wikipedia://en/878962) is a graph that is itself a simple cycle; a cycle graph with $n$ vertices is commonly denoted $C_{n}$.

The [cycle space](wikipedia://en/262243) is a [vector space](wikipedia://en/32370) generated by the simple cycles in a graph, often over the field of 2 elements but also over other fields.

## D {#D}

::: {#o111 .entry cue=term name="DAG"}

**DAG**

Abbreviation for [directed acyclic graph](wikipedia://en/204002), a directed graph without any directed cycles.

:::

::: {#o112 .entry cue=term name="deck"}

**deck**

The multiset of graphs formed from a single graph $G$ by deleting a single vertex in all possible ways, especially in the context of the [reconstruction conjecture](wikipedia://en/255594). An edge-deck is formed in the same way by deleting a single edge in all possible ways. The graphs in a deck are also called *cards*. See also critical (graphs that have a property that is not held by any card) and hypo- (graphs that do not have a property that is held by all cards).

:::

::: {#o113 .entry cue=term name="decomposition"}

**decomposition**

See tree decomposition, path decomposition, or branch-decomposition.

:::

::: {#o114 .entry cue=term name="degenerate"}

**degenerate**

:::

::: {#o115 .entry cue=term name="degeneracy"}

**degeneracy**

A $k$-degenerate graph is an undirected graph in which every induced subgraph has minimum degree at most $k$. The [degeneracy](wikipedia://en/27545816) of a graph is the smallest $k$ for which it is $k$-degenerate. A degeneracy ordering is an ordering of the vertices such that each vertex has minimum degree in the induced subgraph of it and all later vertices; in a degeneracy ordering of a $k$-degenerate graph, every vertex has at most $k$ later neighbours. Degeneracy is also known as the $k$-core number, width, and linkage, and one plus the degeneracy is also called the coloring number or Szekeres–Wilf number. $k$-degenerate graphs have also been called $k$-inductive graphs.

:::

::: {#o116 .entry cue=term name="degree"}

**degree**

The [degree](wikipedia://en/1374448) of a vertex in a graph is its number of incident edges.[^o10] The degree of a graph $G$ (or its maximum degree) is the maximum of the degrees of its vertices, often denoted $\Delta(G)$; the minimum degree of $G$ is the minimum of its vertex degrees, often denoted $\delta(G)$. Degree is sometimes called *valency*; the degree of $v$ in $G$ may be denoted $d_{G}(v)$, $d(G)$, or $\deg(v)$. The total degree is the sum of the degrees of all vertices; by the [handshaking lemma](wikipedia://en/9607933) it is an even number. The [degree sequence](https://en.wikipedia.org/wiki/Degree_sequence) is the collection of degrees of all vertices, in sorted order from largest to smallest. In a directed graph, one may distinguish the in-degree (number of incoming edges) and out-degree (number of outgoing edges).[^o10]

The homomorphism degree of a graph is a synonym for its *Hadwiger number*, the order of the largest clique minor.

:::

::: {#o117 .entry cue=term name="delta"}

**delta**

$\Delta(G)$ (using the Greek letter delta) is the maximum degree of a vertex in $G$, and $\delta(G)$ is the minimum degree; see degree.

:::

::: {#o118 .entry cue=term name="density"}

**density**

In a graph of *n* nodes, the density is the ratio of the number of edges of the graph to the number of edges in a complete graph on *n* nodes. See [dense graph](wikipedia://en/2777098).

:::

::: {#o119 .entry cue=term name="depth"}

**depth**

The depth of a node in a rooted tree is the number of edges in the path from the root to the node. For instance, the depth of the root is 0 and the depth of any one of its adjacent nodes is 1. It is the level of a node minus one. Note, however, that some authors instead use *depth* as a synonym for the *level* of a node.[^o120]

:::

::: {#o121 .entry cue=term name="diameter"}

**diameter**

The [diameter](wikipedia://en/2979341) of a connected graph is the maximum length of a [shortest path](https://en.wikipedia.org/wiki/Shortest_path). That is, it is the maximum of the distances between pairs of vertices in the graph. If the graph has weights on its edges, then its weighted diameter measures path length by the sum of the edge weights along a path, while the unweighted diameter measures path length by the number of edges. For disconnected graphs, definitions vary: the diameter may be defined as infinite, or as the largest diameter of a connected component, or it may be undefined.

:::

::: {#o122 .entry cue=term name="diamond"}

**diamond**

The [diamond graph](wikipedia://en/20796238) is an undirected graph with four vertices and five edges.

:::

::: {#o123 .entry cue=term name="diconnected"}

**diconnected**

Strongly connected. (Not to be confused with disconnected)

:::

::: {#o124 .entry cue=term name="digon"}

**digon**

A [digon](wikipedia://en/5442728) is a simple cycle of length two in a directed graph or a multigraph. Digons cannot occur in [simple](https://en.wikipedia.org/wiki/Simple_graph) undirected graphs as they require repeating the same edge twice, which violates the definition of [simple](https://en.wikipedia.org/wiki/Simple_graph).

**digraph**

**direct successor**

The head of a directed edge whose tail is the given vertex.

::: {#o129 .entry cue=term name="directed"}

**directed**

A [directed graph](wikipedia://en/19721986) is one in which the edges have a distinguished direction, from one vertex to another.[^o10] In a [mixed graph](wikipedia://en/38713429), a directed edge is again one that has a distinguished direction; directed edges may also be called arcs or arrows.

**directed line**

**directed path**

A path in which all the *edges* have the same direction. If a directed path leads from vertex $x$ to vertex $y$, $x$ is a predecessor of $y$, $y$ is a successor of $x$, and $y$ is said to be reachable from $x$.

::: {#o134 .entry cue=term name="direction"}

**direction**

The [asymmetric relation](wikipedia://en/1229368) between two adjacent vertices in a graph, represented as an arrow.

The asymmetric relation between two vertices in a directed path.

**disconnected**

Not connected.

::: {#o137 .entry cue=term name="disjoint"}

**disjoint**

Two subgraphs are edge disjoint if they share no edges, and vertex disjoint if they share no vertices.

The disjoint union of two or more graphs is a graph whose vertex and edge sets are the [disjoint unions](wikipedia://en/188946) of the corresponding sets.

::: {#o138 .entry cue=term name="dissociation number"}

**dissociation number**

A subset of vertices in a graph *G* is called *dissociation* if it induces a [subgraph](wikipedia://en/325802#subgraph) with maximum [degree](wikipedia://en/1374448) 1.

::: {#o139 .entry cue=term name="distance"}

**distance**

The [distance](wikipedia://en/1020021) between any two vertices in a graph is the length of the shortest path having the two vertices as its endpoints.

:::

::: {#o140 .entry cue=term name="domatic"}

**domatic**

A domatic partition of a graph is a partition of the vertices into dominating sets. The [domatic number](wikipedia://en/1771980) of the graph is the maximum number of dominating sets in such a partition.

:::

::: {#o141 .entry cue=term name="dominating"}

**dominating**

A [dominating set](wikipedia://en/1747972) is a set of vertices that includes or is adjacent to every vertex in the graph; not to be confused with a vertex cover, a vertex set that is incident to all edges in the graph. Important special types of dominating sets include independent dominating sets (dominating sets that are also independent sets) and connected dominating sets (dominating sets that induced connected subgraphs). A single-vertex dominating set may also be called a universal vertex. The domination number of a graph is the number of vertices in the smallest dominating set.

::: {#o142 .entry cue=term name="dual"}

**dual**

A [dual graph](wikipedia://en/2536864) of a plane graph $G$ is a graph that has a vertex for each face of $G$.

## E {#E}

::: {#o144 .entry cue=term name="E"}

**E**

$E(G)$ is the edge set of $G$; see edge set.

:::

::: {#o145 .entry cue=term name="ear"}

**ear**

An ear of a graph is a path whose endpoints may coincide but in which otherwise there are no repetitions of vertices or edges.

:::

::: {#o146 .entry cue=term name="ear decomposition"}

**ear decomposition**

An [ear decomposition](wikipedia://en/32183016) is a partition of the edges of a graph into a sequence of ears, each of whose endpoints (after the first one) belong to a previous ear and each of whose interior points do not belong to any previous ear. An open ear is a simple path (an ear without repeated vertices), and an open ear decomposition is an ear decomposition in which each ear after the first is open; a graph has an open ear decomposition if and only if it is biconnected. An ear is odd if it has an odd number of edges, and an odd ear decomposition is an ear decomposition in which each ear is odd; a graph has an odd ear decomposition if and only if it is factor-critical.

:::

::: {#o147 .entry cue=term name="eccentricity"}

**eccentricity**

The eccentricity of a vertex is the farthest distance from it to any other vertex.

:::

::: {#o148 .entry cue=term name="edge"}

**edge**

An edge is (together with vertices) one of the two basic units out of which graphs are constructed. Each edge has two (or in hypergraphs, more) vertices to which it is attached, called its endpoints. Edges may be directed or undirected; undirected edges are also called lines and directed edges are also called arcs or arrows. In an undirected [simple graph](https://en.wikipedia.org/wiki/Simple_graph), an edge may be represented as the set of its vertices, and in a directed simple graph it may be represented as an ordered pair of its vertices. An edge that connects vertices $x$ and $y$ is sometimes written $xy$.

:::

::: {#o149 .entry cue=term name="edge cut"}

**edge cut**

A set of edges whose removal disconnects the graph. A one-edge cut is called a bridge, isthmus, or cut edge.

:::

::: {#o150 .entry cue=term name="edge set"}

**edge set**

The set of edges of a given graph $G$, sometimes denoted by $E(G)$.

:::

::: {#o151 .entry cue=term name="edgeless graph"}

**edgeless graph**

The [edgeless graph](https://en.wikipedia.org/wiki/Edgeless_graph) or totally disconnected graph on a given set of vertices is the graph that has no edges. It is sometimes called the empty graph, but this term can also refer to a graph with no vertices.

:::

::: {#o152 .entry cue=term name="embedding"}

**embedding**

A [graph embedding](wikipedia://en/8149170) is a topological representation of a graph as a subset of a topological space with each vertex represented as a point, each edge represented as a curve having the endpoints of the edge as endpoints of the curve, and no other intersections between vertices or edges. A [planar graph](wikipedia://en/24314) is a graph that has such an embedding onto the Euclidean plane, and a [toroidal graph](wikipedia://en/1633057) is a graph that has such an embedding onto a torus. The [genus](wikipedia://en/61891) of a graph is the minimum possible genus of a two-dimensional [manifold](wikipedia://en/2073470) onto which it can be embedded.

:::

::: {#o153 .entry cue=term name="empty graph"}

**empty graph**

An [edgeless graph](https://en.wikipedia.org/wiki/Edgeless_graph) on a nonempty set of vertices.

The [order-zero graph](https://en.wikipedia.org/wiki/Order-zero_graph), a graph with no vertices and no edges.

:::

::: {#o154 .entry cue=term name="end"}

**end**

An [end](wikipedia://en/33989041) of an infinite graph is an equivalence class of rays, where two rays are equivalent if there is a third ray that includes infinitely many vertices from both of them.

:::

::: {#o155 .entry cue=term name="endpoint"}

**endpoint**

One of the two vertices joined by a given edge, or one of the first or last vertex of a walk, trail or path. The first endpoint of a given directed edge is called the *tail* and the second endpoint is called the *head*.

:::

::: {#o156 .entry cue=term name="enumeration"}

**enumeration**

[Graph enumeration](wikipedia://en/9982439) is the problem of counting the graphs in a given class of graphs, as a function of their order. More generally, enumeration problems can refer either to problems of counting a certain class of combinatorial objects (such as cliques, independent sets, colorings, or spanning trees), or of algorithmically listing all such objects.

:::

::: {#o157 .entry cue=term name="Eulerian"}

**Eulerian**

An [Eulerian path](wikipedia://en/333219) is a walk that uses every edge of a graph exactly once. An Eulerian circuit (also called an Eulerian cycle or an Euler tour) is a closed walk that uses every edge exactly once. An Eulerian graph is a graph that has an Eulerian circuit. For an undirected graph, this means that the graph is connected and every vertex has even degree. For a directed graph, this means that the graph is strongly connected and every vertex has in-degree equal to the out-degree. In some cases, the connectivity requirement is loosened, and a graph meeting only the degree requirements is called Eulerian.

:::

::: {#o158 .entry cue=term name="even"}

**even**

Divisible by two; for instance, an even cycle is a cycle whose length is even.

:::

::: {#o159 .entry cue=term name="expander"}

**expander**

An [expander graph](wikipedia://en/9313) is a graph whose edge expansion, vertex expansion, or spectral expansion is bounded away from zero.

:::

::: {#o160 .entry cue=term name="expansion"}

**expansion**

The edge expansion, isoperimetric number, or [Cheeger constant](wikipedia://en/7762273) of a graph $G$ is the minimum ratio, over subsets $S$ of at most half of the vertices of $G$, of the number of edges leaving $S$ to the number of vertices in $S$.

The vertex expansion, vertex isoperimetric number, or magnification of a graph $G$ is the minimum ratio, over subsets $S$ of at most half of the vertices of $G$, of the number of vertices outside but adjacent to $S$ to the number of vertices in $S$.

The unique neighbor expansion of a graph $G$ is the minimum ratio, over subsets of at most half of the vertices of $G$, of the number of vertices outside $S$ but adjacent to a unique vertex in $S$ to the number of vertices in $S$.

The spectral expansion of a $d$-regular graph $G$ is the [spectral gap](wikipedia://en/7999250) between the largest eigenvalue $d$ of its adjacency matrix and the second-largest eigenvalue.

A family of graphs has [bounded expansion](wikipedia://en/47843724) if all its $r$-shallow minors have a ratio of edges to vertices bounded by a function of $r$, and polynomial expansion if the function of $r$ is a polynomial.

:::

## F {#F}

::: {#o162 .entry cue=term name="face"}

**face**

In a [plane graph](wikipedia://en/24314) or [graph embedding](wikipedia://en/8149170), a connected component of the subset of the plane or surface of the embedding that is disjoint from the graph. For an embedding in the plane, all but one face will be bounded; the one exceptional face that extends to infinity is called the outer (or infinite) face.

:::

::: {#o163 .entry cue=term name="factor"}

**factor**

A factor of a graph is a spanning subgraph: a subgraph that includes all of the vertices of the graph. The term is primarily used in the context of regular subgraphs: a $k$-factor is a factor that is $k$-regular. In particular, a $1$-factor is the same thing as a perfect matching. A [factor-critical graph](wikipedia://en/7684634) is a graph for which deleting any one vertex produces a graph with a $1$-factor.

:::

::: {#o164 .entry cue=term name="factorization"}

**factorization**

A [graph factorization](wikipedia://en/3298854) is a partition of the edges of the graph into factors; a $k$-factorization is a partition into $k$-factors. For instance a $1$-factorization is an edge coloring with the additional property that each vertex is incident to an edge of each color.

:::

::: {#o165 .entry cue=term name="family"}

**family**

A synonym for class.

:::

::: {#o166 .entry cue=term name="finite"}

**finite**

A graph is finite if it has a finite number of vertices and a finite number of edges. Many sources assume that all graphs are finite without explicitly saying so. A graph is locally finite if each vertex has a finite number of incident edges. An infinite graph is a graph that is not finite: it has infinitely many vertices, infinitely many edges, or both.

:::

::: {#o167 .entry cue=term name="first order"}

**first order**

The first order [logic of graphs](wikipedia://en/47857242) is a form of logic in which variables represent vertices of a graph, and there exists a binary predicate to test whether two vertices are adjacent. To be distinguished from second order logic, in which variables can also represent sets of vertices or edges.

:::

::: {#o168 .entry cue=term name="-flap"}

**\-flap**

For a set of vertices $X$, an $X$-flap is a connected component of the induced subgraph formed by deleting $X$. The flap terminology is commonly used in the context of *havens*, functions that map small sets of vertices to their flaps. See also the bridge of a cycle, which is either a flap of the cycle vertices or a chord of the cycle.

:::

::: {#o169 .entry cue=term name="forbidden"}

**forbidden**

A [forbidden graph characterization](wikipedia://en/13547826) is a characterization of a family of graphs as being the graphs that do not have certain other graphs as subgraphs, induced subgraphs, or minors. If $H$ is one of the graphs that does not occur as a subgraph, induced subgraph, or minor, then $H$ is said to be forbidden.

:::

::: {#o170 .entry cue=term name="forcing graph"}

**forcing graph**

A [forcing graph](wikipedia://en/69377880) is a graph $H$ such that evaluating the subgraph density of $H$ in the graphs of a graph sequence $G(n)$ is sufficient to test whether that sequence is quasi-random.

:::

::: {#o171 .entry cue=term name="forest"}

**forest**

A [forest](wikipedia://en/48560) is an undirected graph without cycles (a disjoint union of unrooted trees), or a directed graph formed as a disjoint union of rooted trees.

:::

::: {#o172 .entry cue=term name="free edge"}

**free edge**

An [edge](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) which is not in a [matching](wikipedia://en/581797).

:::

::: {#o173 .entry cue=term name="free vertex"}

**free vertex**

A [vertex](wikipedia://en/638899) not on a matched [edge](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) in a [matching](wikipedia://en/581797)

A vertex which has not been matched.

## H {#H}

::: {#o188 .entry cue=term name="H"}

**H**

A variable often used to denote a graph, especially when another graph has already been denoted by $G$.

:::

::: {#o189 .entry cue=term name="H-coloring"}

**H-coloring**

An $H$-coloring of a graph $G$ (where $H$ is also a graph) is a homomorphism from $H$ to $G$.

:::

::: {#o190 .entry cue=term name="H-tree"}

**H-tree**

A graph is $H$-free if it does not have an induced subgraph isomorphic to $H$, that is, if $H$ is a forbidden induced subgraph. The $H$-free graphs are the family of all graphs (or, often, all finite graphs) that are $H$-free.[^o191] For instance the [triangle-free graphs](wikipedia://en/7667996) are the graphs that do not have a [triangle graph](wikipedia://en/27071812) as a subgraph. The property of being $H$-free is always hereditary. A graph is $H$-minor-free if it does not have a minor isomorphic to $H$.

:::

::: {#o192 .entry cue=term name="Hadwiger"}

**Hadwiger**

[Hugo Hadwiger](wikipedia://en/630451)

The [Hadwiger number](wikipedia://en/1665366) of a graph is the order of the largest complete minor of the graph. It is also called the contraction clique number or the homomorphism degree.

The [Hadwiger conjecture](wikipedia://en/1657860) is the conjecture that the Hadwiger number is never less than the chromatic number.

:::

::: {#o193 .entry cue=term name="Hamiltonian"}

**Hamiltonian**

A [Hamiltonian path](wikipedia://en/244437) or Hamiltonian cycle is a simple spanning path or simple spanning cycle: it covers all of the vertices in the graph exactly once. A graph is Hamiltonian if it contains a Hamiltonian cycle, and traceable if it contains a Hamiltonian path.

:::

::: {#o194 .entry cue=term name="haven"}

**haven**

A $k$-[haven](wikipedia://en/5133456) is a function that maps every set $X$ of fewer than $k$ vertices to one of its flaps, often satisfying additional consistency conditions. The order of a haven is the number $k$. Havens can be used to characterize the treewidth of finite graphs and the ends and Hadwiger numbers of infinite graphs.

:::

::: {#o195 .entry cue=term name="height"}

**height**

The *height* of a node in a rooted tree is the number of edges in a longest path, going away from the root (i.e. its nodes have strictly increasing depth), that starts at that node and ends at a leaf.

The *height* of a rooted tree is the height of its root. That is, the *height* of a tree is the number of edges in a longest possible path, going away from the root, that starts at the root and ends at a leaf.

The *height* of a [directed acyclic graph](wikipedia://en/204002) is the maximum length of a directed path in this graph.

:::

::: {#o196 .entry cue=term name="hereditary"}

**hereditary**

A [hereditary property](wikipedia://en/13552465) of graphs is a property that is closed under induced subgraphs: if $G$ has a hereditary property, then so must every induced subgraph of $G$. Compare monotone (closed under all subgraphs) or *minor-closed* (closed under minors).

:::

::: {#o197 .entry cue=term name="hexagon"}

**[hexagon](wikipedia://en/59733)**

A simple cycle consisting of exactly six edges and six vertices.

:::

::: {#o198 .entry cue=term name="hole"}

**hole**

A hole is an induced cycle of length four or more. An odd hole is a hole of odd length. An anti-hole is an induced subgraph of order four whose complement is a cycle; equivalently, it is a hole in the complement graph. This terminology is mainly used in the context of perfect graphs, which are characterized by the [strong perfect graph theorem](wikipedia://en/744171) as being the graphs with no odd holes or odd anti-holes. The hole-free graphs are the same as the [chordal graphs](wikipedia://en/744165).

:::

::: {#o199 .entry cue=term name="homomorphic equivalence"}

**homomorphic equivalence**

Two graphs are [homomorphically equivalent](wikipedia://en/676328) if there exist two homomorphisms, one from each graph to the other graph.

:::

::: {#o200 .entry cue=term name="homomorphism"}

**homomorphism**

A [graph homomorphism](wikipedia://en/676328) is a mapping from the vertex set of one graph to the vertex set of another graph that maps adjacent vertices to adjacent vertices. This type of mapping between graphs is the one that is most commonly used in category-theoretic approaches to graph theory. A proper graph coloring can equivalently be described as a homomorphism to a complete graph.

The homomorphism degree of a graph is a synonym for its *Hadwiger number*, the order of the largest clique minor.

:::

::: {#o201 .entry cue=term name="hyperarc"}

**hyperarc**

A directed hyperedge having a source and target set.

:::

::: {#o202 .entry cue=term name="hyperedge"}

**hyperedge**

An edge in a hypergraph, having any number of endpoints, in contrast to the requirement that edges of graphs have exactly two endpoints.

:::

::: {#o203 .entry cue=term name="hypercube"}

**hypercube**

A [hypercube graph](wikipedia://en/6706815) is a graph formed from the vertices and edges of a geometric [hypercube](wikipedia://en/39783).

:::

::: {#o204 .entry cue=term name="hypergraph"}

**hypergraph**

A [hypergraph](wikipedia://en/232535) is a generalization of a graph in which each edge (called a hyperedge in this context) may have more than two endpoints.

:::

::: {#o205 .entry cue=term name="hypo-"}

**hypo-**

This prefix, in combination with a graph property, indicates a graph that does not have the property but such that every subgraph formed by deleting a single vertex does have the property. For instance, a [hypohamiltonian graph](wikipedia://en/18301304) is one that does not have a Hamiltonian cycle, but for which every one-vertex deletion produces a Hamiltonian subgraph. Compare critical, used for graphs which have a property but for which every one-vertex deletion does not.[^o206]

**internal**

A vertex of a path or tree is internal if it is not a leaf; that is, if its degree is greater than one. Two paths are internally disjoint (some people call it *independent*) if they do not have any vertex in common, except the first and last ones.

::: {#o219 .entry cue=term name="intersection"}

**intersection**

The intersection of two graphs is their largest common subgraph, the graph formed by the vertices and edges that belong to both graphs.

An [intersection graph](wikipedia://en/7726759) is a graph whose vertices correspond to sets or geometric objects, with an edge between two vertices exactly when the corresponding two sets or objects have a nonempty intersection. Several classes of graphs may be defined as the intersection graphs of certain types of objects, for instance [chordal graphs](wikipedia://en/744165) (intersection graphs of subtrees of a tree), [circle graphs](wikipedia://en/1399873) (intersection graphs of chords of a circle), [interval graphs](wikipedia://en/363423) (intersection graphs of intervals of a line), [line graphs](wikipedia://en/675231) (intersection graphs of the edges of a graph), and [clique graphs](https://en.wikipedia.org/wiki/Clique_graph) (intersection graphs of the maximal cliques of a graph). Every graph is an intersection graph for some family of sets, and this family is called an intersection representation of the graph. The [intersection number](wikipedia://en/31087478) of a graph $G$ is the minimum total number of elements in any intersection representation of $G$.

An [interval graph](wikipedia://en/363423) is an [intersection graph](wikipedia://en/7726759) of [intervals of a line](wikipedia://en/49172).

## L {#L}

**L**

::: {#o237 .entry cue=term name="label"}

**label**

Information associated with a vertex or edge of a graph. A labeled graph is a graph whose vertices or edges have labels. The terms *vertex-labeled* or *edge-labeled* may be used to specify which objects of a graph have labels. [Graph labeling](wikipedia://en/1609861) refers to several different problems of assigning labels to graphs subject to certain constraints. See also [graph coloring](wikipedia://en/426743), in which the labels are interpreted as colors.

In the context of [graph enumeration](wikipedia://en/9982439), the vertices of a graph are said to be labeled if they are all distinguishable from each other. For instance, this can be made to be true by fixing a one-to-one correspondence between the vertices and the integers from 1 to the order of the graph. When vertices are labeled, graphs that are isomorphic to each other (but with different vertex orderings) are counted as separate objects. In contrast, when the vertices are unlabeled, graphs that are isomorphic to each other are not counted separately.

A leaf vertex or pendant vertex (especially in a tree) is a vertex whose degree is $1$. A leaf edge or pendant edge is the edge connecting a leaf vertex to its single neighbour.

A [leaf power](wikipedia://en/49639194) of a tree is a graph whose vertices are the leaves of the tree and whose edges connect leaves whose distance in the tree is at most a given threshold.

**length**

In an unweighted graph, the length of a cycle, path, or walk is the number of edges it uses. In a weighted graph, it may instead be the sum of the weights of the edges that it uses. Length is used to define the [shortest path](https://en.wikipedia.org/wiki/Shortest_path), [girth](wikipedia://en/12013) (shortest cycle length), and [longest path](https://en.wikipedia.org/wiki/Longest_path) between two vertices in a graph.

**level**

This is the *depth* of a node plus 1, although some[^o241] define it instead to be synonym of *depth*. A node's level in a rooted tree is the number of nodes in the path from the root to the node. For instance, the root has level 1 and any one of its adjacent nodes has level 2.

A set of all node having the same level or depth.[^o241]

## M {#M}

::: {#o248 .entry cue=term name="magnification"}

**magnification**

Synonym for vertex expansion.

:::

::: {#o249 .entry cue=term name="matching"}

**matching**

A [matching](wikipedia://en/581797) is a set of edges in which no two share any vertex. A vertex is matched or saturated if it is one of the endpoints of an edge in the matching. A [perfect matching](wikipedia://en/44031) or complete matching is a matching that matches every vertex; it may also be called a 1-factor, and can only exist when the order is even. A near-perfect matching, in a graph with odd order, is one that saturates all but one vertex. A [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching) is a matching that uses as many edges as possible; the matching number $\alpha'(G)$ of a graph $G$ is the number of edges in a maximum matching. A [maximal matching](https://en.wikipedia.org/wiki/Maximal_matching) is a matching to which no additional edges can be added.

:::

::: {#o250 .entry cue=term name="maximal"}

**maximal**

A subgraph of given graph $G$ is maximal for a particular property if it has that property but no other supergraph of it that is also a subgraph of $G$ also has the same property. That is, it is a [maximal element](https://en.wikipedia.org/wiki/Maximal_element) of the subgraphs with the property. For instance, a [maximal clique](https://en.wikipedia.org/wiki/Maximal_clique) is a complete subgraph that cannot be expanded to a larger complete subgraph. The word "maximal" should be distinguished from "maximum": a maximum subgraph is always maximal, but not necessarily vice versa.

A simple graph with a given property is maximal for that property if it is not possible to add any more edges to it (keeping the vertex set unchanged) while preserving both the simplicity of the graph and the property. Thus, for instance, a [maximal planar graph](https://en.wikipedia.org/wiki/Maximal_planar_graph) is a planar graph such that adding any more edges to it would create a non-planar graph.

:::

::: {#o251 .entry cue=term name="maximum"}

**maximum**

A subgraph of a given graph $G$ is maximum for a particular property if it is the largest subgraph (by order or size) among all subgraphs with that property. For instance, a [maximum clique](https://en.wikipedia.org/wiki/Maximum_clique) is any of the largest cliques in a given graph.

:::

::: {#o252 .entry cue=term name="median"}

**median**

A median of a triple of vertices, a vertex that belongs to shortest paths between all pairs of vertices, especially in median graphs and [modular graphs](wikipedia://en/51807881).

A [median graph](wikipedia://en/16970848) is a graph in which every three vertices have a unique median.

:::

::: {#o253 .entry cue=term name="Meyniel"}

**Meyniel**

Henri Meyniel, French graph theorist.

A [Meyniel graph](wikipedia://en/744167) is a graph in which every odd cycle of length five or more has at least two chords.

:::

::: {#o254 .entry cue=term name="minimal"}

**minimal**

A subgraph of given graph is minimal for a particular property if it has that property but no proper subgraph of it also has the same property. That is, it is a [minimal element](https://en.wikipedia.org/wiki/Minimal_element) of the subgraphs with the property.

:::

::: {#o255 .entry cue=term name="minimum cut"}

**minimum cut**

A cut whose cut-set has minimum total weight, possibly restricted to cuts that separate a designated pair of vertices; they are characterized by the [max-flow min-cut theorem](wikipedia://en/78130).

:::

::: {#o256 .entry cue=term name="minor"}

**minor**

A graph $H$ is a [minor](wikipedia://en/353042) of another graph $G$ if $H$ can be obtained by deleting edges or vertices from $G$ and contracting edges in $G$. It is a [shallow minor](wikipedia://en/38768125) if it can be formed as a minor in such a way that the subgraphs of $G$ that were contracted to form vertices of $H$ all have small diameter. $H$ is a [topological minor](https://en.wikipedia.org/wiki/Topological_minor) of $G$ if $G$ has a subgraph that is a [subdivision](https://en.wikipedia.org/wiki/Subdivision_%28graph_theory%29) of $H$. A graph is $H$-minor-free if it does not have $H$ as a minor. A family of graphs is minor-closed if it is closed under minors; the [Robertson–Seymour theorem](wikipedia://en/351769) characterizes minor-closed families as having a finite set of forbidden minors.

:::

::: {#o257 .entry cue=term name="mixed"}

**mixed**

A [mixed graph](wikipedia://en/38713429) is a graph that may include both directed and undirected edges.

:::

::: {#o258 .entry cue=term name="modular"}

**modular**

[Modular graph](wikipedia://en/51807881), a graph in which each triple of vertices has at least one median vertex that belongs to shortest paths between all pairs of the triple.

[Modular decomposition](wikipedia://en/28310124), a decomposition of a graph into subgraphs within which all vertices connect to the rest of the graph in the same way.

[Modularity](wikipedia://en/18396728) of a graph clustering, the difference of the number of cross-cluster edges from its expected value.

:::

::: {#o259 .entry cue=term name="monotone"}

**monotone**

A monotone property of graphs is a property that is closed under subgraphs: if $G$ has a monotone property, then so must every subgraph of $G$. Compare hereditary (closed under induced subgraphs) or *minor-closed* (closed under minors).

:::

::: {#o260 .entry cue=term name="Moore graph"}

**Moore graph**

A [Moore graph](wikipedia://en/4112719) is a regular graph for which the Moore bound is met exactly. The Moore bound is an inequality relating the degree, diameter, and order of a graph, proved by [Edward F. Moore](https://en.wikipedia.org/wiki/Edward_F._Moore). Every Moore graph is a cage.

:::

::: {#o261 .entry cue=term name="multigraph"}

**multigraph**

A [multigraph](wikipedia://en/1774970) is a graph that allows multiple adjacencies (and, often, self-loops); a graph that is not required to be simple.

:::

::: {#o262 .entry cue=term name="multiple adjacency"}

**multiple adjacency**

A multiple adjacency or multiple edge is a set of more than one edge that all have the same endpoints (in the same direction, in the case of directed graphs). A graph with multiple edges is often called a multigraph.

:::

::: {#o263 .entry cue=term name="multiplicity"}

**multiplicity**

The multiplicity of an edge is the number of edges in a multiple adjacency. The multiplicity of a graph is the maximum multiplicity of any of its edges.

## O {#O}

::: {#o275 .entry cue=term name="odd"}

**odd**

An odd cycle is a cycle whose length is odd. The [odd girth](wikipedia://en/12013) of a non-bipartite graph is the length of its shortest odd cycle. An odd hole is a special case of an odd cycle: one that is induced and has four or more vertices.

An odd vertex is a vertex whose degree is odd. By the [handshaking lemma](wikipedia://en/9607933) every finite undirected graph has an even number of odd vertices.

An odd ear is a simple path or simple cycle with an odd number of edges, used in odd ear decompositions of factor-critical graphs; see ear.

An odd chord is an edge connecting two vertices that are an odd distance apart in an even cycle. Odd chords are used to define [strongly chordal graphs](wikipedia://en/24809733).

An [odd graph](https://en.wikipedia.org/wiki/Odd_graph) is a special case of a [Kneser graph](wikipedia://en/2724154), having one vertex for each $(n - 1)$-element subset of a $(2n - 1)$-element set, and an edge connecting two subsets when their corresponding sets are disjoint.

::: {#o277 .entry cue=term name="order"}

**order**

The order of a graph $G$ is the number of its vertices, $|V(G)|$. The variable $n$ is often used for this quantity. See also size, the number of edges.

A type of [logic of graphs](wikipedia://en/47857242); see first order and second order.

An order or ordering of a graph is an arrangement of its vertices into a sequence, especially in the context of [topological ordering](https://en.wikipedia.org/wiki/Topological_ordering) (an order of a directed acyclic graph in which every edge goes from an earlier vertex to a later vertex in the order) and [degeneracy ordering](wikipedia://en/27545816) (an order in which each vertex has minimum degree in the induced subgraph of it and all later vertices).

For the order of a haven or bramble, see haven and bramble.

::: {#o279 .entry cue=term name="oriented"}

**oriented**

An [orientation](wikipedia://en/36619818) of an undirected graph is an assignment of directions to its edges, making it into a directed graph. An oriented graph is one that has been assigned an orientation. So, for instance, a [polytree](wikipedia://en/1731488) is an oriented tree; it differs from a directed tree (an arborescence) in that there is no requirement of consistency in the directions of its edges. Other special types of orientation include [tournaments](wikipedia://en/1427502), orientations of complete graphs; [strong orientations](wikipedia://en/16678715), orientations that are strongly connected; [acyclic orientations](wikipedia://en/36619881), orientations that are acyclic; [Eulerian orientations](wikipedia://en/333219), orientations that are Eulerian; and [transitive orientations](https://en.wikipedia.org/wiki/Transitive_orientation), orientations that are transitively closed.

Oriented graph, used by some authors as a synonym for a [directed graph](wikipedia://en/19721986).

## P {#P}

::: {#o284 .entry cue=term name="parent"}

**parent**

In a rooted tree, a parent of a vertex $v$ is a neighbor of $v$ along the incoming edge, the one that is directed toward the root.

:::

::: {#o285 .entry cue=term name="path"}

**path**

A [path](wikipedia://en/638889) may either be a walk or a walk without repeated vertices and consequently edges (also called a simple path), depending on the source. Important special cases include [induced paths](wikipedia://en/7714430) and [shortest paths](https://en.wikipedia.org/wiki/Shortest_path).

:::

::: {#o286 .entry cue=term name="path decomposition"}

**path decomposition**

A [path decomposition](https://en.wikipedia.org/wiki/Path_decomposition) of a graph $G$ is a tree decomposition whose underlying tree is a path. Its width is defined in the same way as for tree decompositions, as one less than the size of the largest bag. The minimum width of any path decomposition of $G$ is the pathwidth of $G$.

:::

::: {#o287 .entry cue=term name="pathwidth"}

**pathwidth**

The [pathwidth](wikipedia://en/5133142) of a graph $G$ is the minimum width of a path decomposition of $G$. It may also be defined in terms of the clique number of an interval completion of $G$. It is always between the bandwidth and the treewidth of $G$. It is also known as interval thickness, vertex separation number, or node searching number.

::: {#o288 .entry cue=term name="pendant"}

**pendant**

See leaf.

:::

::: {#o289 .entry cue=term name="perfect"}

**perfect**

A [perfect graph](wikipedia://en/670531) is a graph in which, in every induced subgraph, the chromatic number equals the clique number. The [perfect graph theorem](wikipedia://en/670602) and [strong perfect graph theorem](wikipedia://en/744171) are two theorems about perfect graphs, the former proving that their complements are also perfect and the latter proving that they are exactly the graphs with no odd holes or anti-holes.

A [perfectly orderable graph](wikipedia://en/21051205) is a graph whose vertices can be ordered in such a way that a greedy coloring algorithm with this ordering optimally colors every induced subgraph. The perfectly orderable graphs are a subclass of the perfect graphs.

A [perfect matching](wikipedia://en/44031) is a matching that saturates every vertex; see matching.

A perfect [1-factorization](https://en.wikipedia.org/wiki/1-factorization) is a partition of the edges of a graph into perfect matchings so that each two matchings form a Hamiltonian cycle.

:::

::: {#o290 .entry cue=term name="peripheral"}

**peripheral**

A [peripheral cycle](wikipedia://en/12649450) or non-separating cycle is a cycle with at most one bridge.

A peripheral vertex is a vertex whose eccentricity is maximum. In a tree, this must be a leaf.

:::

::: {#o291 .entry cue=term name="Petersen"}

**Petersen**

[Julius Petersen](wikipedia://en/76861) (1839–1910), Danish graph theorist.

The [Petersen graph](wikipedia://en/194926), a 10-vertex 15-edge graph frequently used as a counterexample.

[Petersen's theorem](wikipedia://en/38481437) that every bridgeless cubic graph has a perfect matching.

:::

::: {#o292 .entry cue=term name="planar"}

**planar**

A [planar graph](wikipedia://en/24314) is a graph that has an [embedding](wikipedia://en/8149170) onto the Euclidean plane. A plane graph is a planar graph for which a particular embedding has already been fixed. A $k$-planar graph is one that can be drawn in the plane with at most $k$ crossings per edge.

:::

::: {#o293 .entry cue=term name="polytree"}

**polytree**

A [polytree](wikipedia://en/1731488) is an oriented tree; equivalently, a directed acyclic graph whose underlying undirected graph is a tree.

:::

::: {#o294 .entry cue=term name="power"}

**power**

A [graph power](wikipedia://en/38618878) $G^{k}$ of a graph $G$ is another graph on the same vertex set; two vertices are adjacent in $G^{k}$ when they are at distance at most $k$ in $G$. A [leaf power](wikipedia://en/49639194) is a closely related concept, derived from a power of a tree by taking the subgraph induced by the tree's leaves.

[Power graph analysis](https://en.wikipedia.org/wiki/Power_graph_analysis) is a method for analyzing complex networks by identifying cliques, bicliques, and stars within the network.

[Power laws](wikipedia://en/24522) in the [degree distributions](wikipedia://en/2129782) of [scale-free networks](wikipedia://en/227155) are a phenomenon in which the number of vertices of a given degree is proportional to a power of the degree.

:::

::: {#o295 .entry cue=term name="predecessor"}

**predecessor**

A vertex coming before a given vertex in a directed path.

:::

::: {#o296 .entry cue=term name="prime"}

**prime**

A [prime graph](https://en.wikipedia.org/wiki/Prime_graph) is defined from an algebraic [group](wikipedia://en/19447), with a vertex for each [prime number](wikipedia://en/23666) that divides the order of the group.

In the theory of [modular decomposition](wikipedia://en/28310124), a prime graph is a graph without any nontrivial modules.

In the theory of [splits](wikipedia://en/49923425), cuts whose cut-set is a complete bipartite graph, a prime graph is a graph without any splits. Every quotient graph of a maximal decomposition by splits is a prime graph, a star, or a complete graph.

A prime graph for the [Cartesian product of graphs](wikipedia://en/2856852) is a connected graph that is not itself a product. Every connected graph can be uniquely factored into a Cartesian product of prime graphs.

:::

::: {#o297 .entry cue=term name="proper"}

**proper**

A proper subgraph is a subgraph that removes at least one vertex or edge relative to the whole graph; for finite graphs, proper subgraphs are never isomorphic to the whole graph, but for infinite graphs they can be.

A proper coloring is an assignment of colors to the vertices of a graph (a coloring) that assigns different colors to the endpoints of each edge; see color.

A [proper interval graph](https://en.wikipedia.org/wiki/Proper_interval_graph) or proper circular arc graph is an intersection graph of a collection of intervals or circular arcs (respectively) such that no interval or arc contains another interval or arc. Proper interval graphs are also called unit interval graphs (because they can always be represented by unit intervals) or indifference graphs.

:::

::: {#o298 .entry cue=term name="property"}

**property**

A [graph property](wikipedia://en/1655142) is something that can be true of some graphs and false of others, and that depends only on the graph structure and not on incidental information such as labels. Graph properties may equivalently be described in terms of classes of graphs (the graphs that have a given property). More generally, a graph property may also be a function of graphs that is again independent of incidental information, such as the size, order, or degree sequence of a graph; this more general definition of a property is also called an invariant of the graph.

:::

::: {#o299 .entry cue=term name="pseudoforest"}

**pseudoforest**

A [pseudoforest](wikipedia://en/13511542) is an undirected graph in which each connected component has at most one cycle, or a directed graph in which each vertex has at most one outgoing edge.

:::

::: {#o300 .entry cue=term name="pseudograph"}

**pseudograph**

A pseudograph is a graph or multigraph that allows self-loops.

A quasi-line graph or locally co-bipartite graph is a graph in which the open neighborhood of every vertex can be partitioned into two cliques. A [quiver](wikipedia://en/355100) is a directed multigraph, as used in [category theory](wikipedia://en/5869). The edges of a quiver are called arrows.

## R {#R}

**radius**

::: {#o307 .entry cue=term name="Ramanujan"}

**Ramanujan**

A [Ramanujan graph](wikipedia://en/849412) is a graph whose spectral expansion is as large as possible. That is, it is a $d$-regular graph, such that the second-largest eigenvalue of its adjacency matrix is at most $2\sqrt{d-1}$.

**ray**

A ray, in an infinite graph, is an infinite simple path with exactly one endpoint. The [ends](wikipedia://en/33989041) of a graph are equivalence classes of rays.

::: {#o311 .entry cue=term name="recognizable"}

**recognizable**

In the context of the [reconstruction conjecture](wikipedia://en/255594), a graph property is recognizable if its truth can be determined from the deck of the graph. Many graph properties are known to be recognizable. If the reconstruction conjecture is true, all graph properties are recognizable.

::: {#o312 .entry cue=term name="reconstruction"}

**reconstruction**

The [reconstruction conjecture](wikipedia://en/255594) states that each undirected graph $G$ is uniquely determined by its *deck*, a multiset of graphs formed by removing one vertex from $G$ in all possible ways. In this context, reconstruction is the formation of a graph from its deck.

A graph is $d$-regular when all of its vertices have degree $d$. A [regular graph](wikipedia://en/85821) is a graph that is $d$-regular for some $d$.

**root**

The inverse operation to a [graph power](wikipedia://en/38618878): a $k$th root of a graph $G$ is another graph on the same vertex set such that two vertices are adjacent in $G$ if and only if they have distance at most $k$ in the root.

::: {#o327 .entry cue=term name="simple"}

**simple**

A [simple graph](https://en.wikipedia.org/wiki/Simple_graph) is a graph without loops and without multiple adjacencies. That is, each edge connects two distinct endpoints and no two edges have the same endpoints. A simple edge is an edge that is not part of a multiple adjacency. In many cases, graphs are assumed to be simple unless specified otherwise.

A simple path or a simple cycle is a path or cycle that has no repeated vertices and consequently no repeated edges.

::: {#o331 .entry cue=term name="small-world network"}

**small-world network**

A [small-world network](wikipedia://en/1457254) is a graph in which most nodes are not neighbors of one another, but most nodes can be reached from every other node by a small number of hops or steps. Specifically, a small-world network is defined to be a graph where the typical distance *L* between two randomly chosen nodes (the number of steps required) grows proportionally to the logarithm of the number of nodes *N* in the network[^o332]

**source**

A source, in a directed graph, is a vertex with no incoming edges (in-degree equals 0).

::: {#o335 .entry cue=term name="space"}

**space**

In [algebraic graph theory](wikipedia://en/1620216), several [vector spaces](https://en.wikipedia.org/wiki/Vector_spaces) over the [binary field](wikipedia://en/11137263) may be associated with a graph. Each has sets of edges or vertices for its vectors, and [symmetric difference](wikipedia://en/262288) of sets as its vector sum operation. The [edge space](https://en.wikipedia.org/wiki/Edge_space) is the space of all sets of edges, and the [vertex space](https://en.wikipedia.org/wiki/Vertex_space) is the space of all sets of vertices. The [cut space](https://en.wikipedia.org/wiki/Cut_space) is a subspace of the edge space that has the cut-sets of the graph as its elements. The [cycle space](wikipedia://en/262243) has the Eulerian spanning subgraphs as its elements.

:::

::: {#o336 .entry cue=term name="spanner"}

**spanner**

A spanner is a (usually sparse) graph whose shortest path distances approximate those in a dense graph or other metric space. Variations include [geometric spanners](wikipedia://en/11844294), graphs whose vertices are points in a geometric space; [tree spanners](wikipedia://en/3817255), spanning trees of a graph whose distances approximate the graph distances, and graph spanners, sparse subgraphs of a dense graph whose distances approximate the original graph's distances. A greedy spanner is a graph spanner constructed by a greedy algorithm, generally one that considers all edges from shortest to longest and keeps the ones that are needed to preserve the distance approximation.

:::

::: {#o337 .entry cue=term name="spanning"}

**spanning**

A subgraph is spanning when it includes all of the vertices of the given graph. Important cases include [spanning trees](wikipedia://en/455770) (spanning subgraphs that are trees) and [perfect matchings](wikipedia://en/44031) (spanning subgraphs that are matchings). A spanning subgraph may also be called a [factor](wikipedia://en/3298854), especially (but not only) when it is regular.

:::

::: {#o338 .entry cue=term name="sparse"}

**sparse**

A [sparse graph](https://en.wikipedia.org/wiki/Sparse_graph) is one that has few edges relative to its number of vertices. In some definitions the same property should also be true for all subgraphs of the given graph.

**spectral**

::: {#o340 .entry cue=term name="spectrum"}

**spectrum**

The spectrum of a graph is the collection of [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of its adjacency matrix. [Spectral graph theory](wikipedia://en/534914) is the branch of graph theory that uses spectra to analyze graphs. See also spectral expansion.

:::

::: {#o341 .entry cue=term name="split"}

**split**

A [split graph](wikipedia://en/9928681) is a graph whose vertices can be partitioned into a clique and an independent set. A related class of graphs, the double split graphs, are used in the proof of the strong perfect graph theorem.

A [split](wikipedia://en/49923425) of an arbitrary graph is a partition of its vertices into two nonempty subsets, such that the edges spanning this cut form a complete bipartite subgraph. The splits of a graph can be represented by a tree structure called its *split decomposition*. A split is called a strong split when it is not crossed by any other split. A split is called nontrivial when both of its sides have more than one vertex. A graph is called prime when it has no nontrivial splits.

[Vertex splitting](wikipedia://en/3758115#Vertex_cleaving) (sometimes called vertex cleaving) is an elementary graph operation that splits a vertex into two, where these two new vertices are adjacent to the vertices that the original vertex was adjacent to. The inverse of vertex splitting is vertex contraction.

::: {#o342 .entry cue=term name="square"}

**square**

The square of a graph $G$ is the [graph power](wikipedia://en/38618878) $G^{2}$; in the other direction, $G$ is the square root of $G^{2}$. The [half-square](https://en.wikipedia.org/wiki/Half-square) of a bipartite graph is the subgraph of its square induced by one side of the bipartition.

A [squaregraph](wikipedia://en/20741076) is a planar graph that can be drawn so that all bounded faces are 4-cycles and all vertices of degree ≤ 3 belong to the outer face.

A square grid graph is a [lattice graph](wikipedia://en/19635706) defined from points in the plane with integer coordinates connected by unit-length edges.

**star**

A [star](wikipedia://en/19310129) is a tree with one internal vertex; equivalently, it is a complete bipartite graph $K_{1,n}$ for some $n \ge 2$. The special case of a star with three leaves is called a claw.

:::

::: {#o345 .entry cue=term name="strength"}

**strength**

The [strength of a graph](wikipedia://en/23093011) is the minimum ratio of the number of edges removed from the graph to components created, over all possible removals; it is analogous to toughness, based on vertex removals.

:::

::: {#o346 .entry cue=term name="strong"}

**strong**

For strong connectivity and [strongly connected components](wikipedia://en/684680) of directed graphs, see connected and component. A [strong orientation](wikipedia://en/16678715) is an orientation that is strongly connected; see orientation.

For the [strong perfect graph theorem](wikipedia://en/744171), see perfect.

A [strongly regular graph](wikipedia://en/1399856) is a regular graph in which every two adjacent vertices have the same number of shared neighbours and every two non-adjacent vertices have the same number of shared neighbours.

A [strongly chordal graph](wikipedia://en/24809733) is a chordal graph in which every even cycle of length six or more has an odd chord.

A strongly perfect graph is a graph in which every induced subgraph has an independent set meeting all maximal cliques. The [Meyniel graphs](wikipedia://en/744167) are also called "very strongly perfect graphs" because in them, every vertex belongs to such an independent set.

::: {#o348 .entry cue=term name="subgraph"}

**subgraph**

A subgraph of a graph $G$ is another graph formed from a subset of the vertices and edges of $G$. The vertex subset must include all endpoints of the edge subset, but may also include additional vertices. A spanning subgraph is one that includes all vertices of the graph; an induced subgraph is one that includes all the edges whose endpoints belong to the vertex subset.

**subtree**

A subtree is a connected subgraph of a tree. Sometimes, for rooted trees, subtrees are defined to be a special type of connected subgraph, formed by all vertices and edges reachable from a chosen vertex.

**superconcentrator**

A superconcentrator is a graph with two designated and equal-sized subsets of vertices $I$ and $O$, such that for every two equal-sized subsets $S$ of $I$ and $T$ of $O$ there exists a family of disjoint paths connecting every vertex in $S$ to a vertex in $T$. Some sources require in addition that a superconcentrator be a directed acyclic graph, with $I$ as its sources and $O$ as its sinks.

**theta**

A theta graph is the union of three internally disjoint (simple) paths that have the same two distinct end vertices.[^o355]

The [theta graph](wikipedia://en/2472919) of a collection of points in the Euclidean plane is constructed by constructing a system of cones surrounding each point and adding one edge per cone, to the point whose projection onto a central ray of the cone is smallest.

The [Lovász number](wikipedia://en/28111101) or Lovász theta function of a graph is a graph invariant related to the clique number and chromatic number that can be computed in polynomial time by semidefinite programming.

**topological**

[Topological graph theory](wikipedia://en/1631772) is the study of graph embeddings.

[Topological sorting](wikipedia://en/897064) is the algorithmic problem of arranging a directed acyclic graph into a topological order, a vertex sequence such that each edge goes from an earlier vertex to a later vertex in the sequence.

**tournament**

A [tournament](wikipedia://en/1427502) is an orientation of a complete graph; that is, it is a directed graph such that every two vertices are connected by exactly one directed edge (going in only one of the two directions between the two vertices).

::: {#o363 .entry cue=term name="transitive"}

**transitive**

Having to do with the [transitive property](https://en.wikipedia.org/wiki/Transitive_property). The [transitive closure](wikipedia://en/292239) of a given directed graph is a graph on the same vertex set that has an edge from one vertex to another whenever the original graph has a path connecting the same two vertices. A [transitive reduction](wikipedia://en/3757117) of a graph is a minimal graph having the same transitive closure; directed acyclic graphs have a unique transitive reduction. A [transitive orientation](https://en.wikipedia.org/wiki/Transitive_orientation) is an orientation of a graph that is its own transitive closure; it exists only for [comparability graphs](wikipedia://en/6978672).

::: {#o364 .entry cue=term name="transpose"}

**transpose**

The [transpose graph](wikipedia://en/5966396) of a given directed graph is a graph on the same vertices, with each edge reversed in direction. It may also be called the converse or reverse of the graph.

::: {#o365 .entry cue=term name="tree"}

**tree**

A [tree](wikipedia://en/48560) is an undirected graph that is both connected and acyclic, or a directed graph in which there exists a unique walk from one vertex (the root of the tree) to all remaining vertices.

A [$k$-tree](wikipedia://en/31104438) is a graph formed by gluing $(k + 1)$-cliques together on shared $k$-cliques. A tree in the ordinary sense is a $1$-tree according to this definition.

:::

::: {#o366 .entry cue=term name="tree decomposition"}

**tree decomposition**

A [tree decomposition](wikipedia://en/159023) of a graph $G$ is a tree whose nodes are labeled with sets of vertices of $G$; these sets are called bags. For each vertex $v$, the bags that contain $v$ must induce a subtree of the tree, and for each edge $uv$ there must exist a bag that contains both $u$ and $v$. The width of a tree decomposition is one less than the maximum number of vertices in any of its bags; the treewidth of $G$ is the minimum width of any tree decomposition of $G$.

:::

::: {#o367 .entry cue=term name="treewidth"}

**treewidth**

The [treewidth](wikipedia://en/3987086) of a graph $G$ is the minimum width of a tree decomposition of $G$. It can also be defined in terms of the clique number of a [chordal completion](wikipedia://en/48088710) of $G$, the order of a [haven](wikipedia://en/5133456) of $G$, or the order of a [bramble](wikipedia://en/36601188) of $G$.

:::

::: {#o368 .entry cue=term name="triangle"}

**triangle**

A cycle of length three in a graph. A [triangle-free graph](wikipedia://en/7667996) is an undirected graph that does not have any triangle subgraphs.

:::

::: {#o369 .entry cue=term name="trivial"}

**trivial**

A trivial graph is a graph with 0 or 1 vertices.[^o370] A graph with 0 vertices is also called [null graph](wikipedia://en/1520758).

:::

::: {#o371 .entry cue=term name="Turán"}

**Turán**

[Pál Turán](wikipedia://en/614998)

A [Turán graph](wikipedia://en/360581) is a balanced complete multipartite graph.

[Turán's theorem](wikipedia://en/360601) states that Turán graphs have the maximum number of edges among all clique-free graphs of a given order.

[Turán's brick factory problem](wikipedia://en/22039971) asks for the minimum number of crossings in a drawing of a complete bipartite graph.

:::

::: {#o372 .entry cue=term name="twin"}

**twin**

Two vertices $u,v$ are true twins if they have the same closed neighborhood: $N_{G}[u] = N_{G}[v]$ (this implies $u$ and $v$ are neighbors), and they are false twins if they have the same open neighborhood: $N_{G}(u) = N_{G}(v))$ (this implies $u$ and $v$ are not neighbors).

:::

## U {#U}

::: {#o374 .entry cue=term name="unary vertex"}

**unary vertex**

In a rooted tree, a unary vertex is a vertex which has exactly one child vertex.

:::

::: {#o375 .entry cue=term name="undirected"}

**undirected**

An [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is a graph in which the two endpoints of each edge are not distinguished from each other. See also *directed* and *mixed*. In a [mixed graph](wikipedia://en/38713429), an undirected edge is again one in which the endpoints are not distinguished from each other.

:::

::: {#o376 .entry cue=term name="uniform"}

**uniform**

A hypergraph is $k$-uniform when all its edges have $k$ endpoints, and uniform when it is $k$-uniform for some $k$. For instance, ordinary graphs are the same as $2$-uniform hypergraphs.

:::

::: {#o377 .entry cue=term name="universal"}

**universal**

A [universal graph](wikipedia://en/1452141) is a graph that contains as subgraphs all graphs in a given family of graphs, or all graphs of a given size or order within a given family of graphs.

A [universal vertex](wikipedia://en/51352780) (also called an apex or dominating vertex) is a vertex that is adjacent to every other vertex in the graph. For instance, [wheel graphs](wikipedia://en/1655876) and connected [threshold graphs](wikipedia://en/11503485) always have a universal vertex.

In the [logic of graphs](wikipedia://en/47857242), a vertex that is [universally quantified](https://en.wikipedia.org/wiki/Universal_quantifier) in a formula may be called a universal vertex for that formula.

:::

::: {#o378 .entry cue=term name="unweighted graph"}

**unweighted graph**

A graph whose vertices and edges have not been assigned weights; the opposite of a weighted graph.

:::

::: {#o379 .entry cue=term name="utility graph"}

**utility graph**

The [utility graph](https://en.wikipedia.org/wiki/Utility_graph) is a name for the [complete bipartite graph](wikipedia://en/525320) $K_{3,3}$.

:::

## V {#V}

::: {#o381 .entry cue=term name="V"}

**V**

See *vertex set*.

:::

::: {#o382 .entry cue=term name="valency"}

**valency**

Synonym for *degree*.

:::

::: {#o383 .entry cue=term name="vertex"}

**vertex**

A [vertex](wikipedia://en/638899) (plural vertices) is (together with edges) one of the two basic units out of which graphs are constructed. Vertices of graphs are often considered to be atomic objects, with no internal structure.

:::

::: {#o384 .entry cue=term name="vertex cut"}

**vertex cut**

:::

::: {#o385 .entry cue=term name="separating set"}

**separating set**

A set of vertices whose removal disconnects the graph. A one-vertex cut is called an articulation point or cut vertex.

:::

::: {#o386 .entry cue=term name="vertex set"}

**vertex set**

The set of vertices of a given graph $G$, sometimes denoted by $V(G)$.

:::

::: {#o387 .entry cue=term name="vertices"}

**vertices**

See *vertex*.

:::

::: {#o388 .entry cue=term name="Vizing"}

**Vizing**

[Vadim G. Vizing](wikipedia://en/21749361)

[Vizing's theorem](wikipedia://en/5449464) that the chromatic index is at most one more than the maximum degree.

[Vizing's conjecture](wikipedia://en/8175877) on the domination number of Cartesian products of graphs.

:::

::: {#o389 .entry cue=term name="volume"}

**volume**

The sum of the degrees of a set of vertices.

:::

## W {#W}

::: {#o391 .entry cue=term name="W"}

**W**

The letter $W$ is used in notation for [wheel graphs](wikipedia://en/1655876) and [windmill graphs](wikipedia://en/24373456). The notation is not standardized.

:::

::: {#o392 .entry cue=term name="Wagner"}

**Wagner**

[Klaus Wagner](https://en.wikipedia.org/wiki/Klaus_Wagner)

The [Wagner graph](wikipedia://en/17598450), an eight-vertex Möbius ladder.

[Wagner's theorem](wikipedia://en/3126130) characterizing planar graphs by their forbidden minors.

Wagner's theorem characterizing the $K_{5}$-minor-free graphs.

:::

::: {#o393 .entry cue=term name="walk"}

**walk**

A [walk](wikipedia://en/638889#Walk,_trail,_path) is a finite or infinite [sequence](wikipedia://en/27838) of [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) which joins a sequence of [vertices](wikipedia://en/638899). Walks are also sometimes called *chains*.[^o394] A walk is *open* if its first and last vertices are distinct, and *closed* if they are repeated.

:::

::: {#o395 .entry cue=term name="weakly connected"}

**weakly connected**

A directed graph is called weakly connected if replacing all of its directed edges with undirected edges produces a connected (undirected) graph.

:::

::: {#o396 .entry cue=term name="weight"}

**weight**

A numerical value, assigned as a label to a vertex or edge of a graph. The weight of a subgraph is the sum of the weights of the vertices or edges within that subgraph.

:::

::: {#o397 .entry cue=term name="weighted graph"}

**weighted graph**

A graph whose vertices or edges have been assigned weights. A vertex-weighted graph has weights on its vertices and an edge-weighted graph has weights on its edges.

:::

::: {#o398 .entry cue=term name="well-colored"}

**well-colored**

A [well-colored graph](wikipedia://en/5224898) is a graph all of whose [greedy colorings](wikipedia://en/21051195) use the same number of colors.

:::

::: {#o399 .entry cue=term name="well-covered"}

**well-covered**

A [well-covered graph](wikipedia://en/32696387) is a graph all of whose maximal independent sets are the same size.

:::

::: {#o400 .entry cue=term name="wheel"}

**wheel**

A [wheel graph](wikipedia://en/1655876) is a graph formed by adding a [universal vertex](wikipedia://en/51352780) to a simple cycle.

:::

::: {#o401 .entry cue=term name="width"}

**width**

A synonym for degeneracy.

For other graph invariants known as width, see bandwidth, branchwidth, clique-width, pathwidth, and treewidth.

The width of a tree decomposition or path decomposition is one less than the maximum size of one of its bags, and may be used to define treewidth and pathwidth.

The width of a [directed acyclic graph](wikipedia://en/204002) is the maximum cardinality of an antichain.

:::

::: {#o402 .entry cue=term name="windmill"}

**windmill**

A [windmill graph](wikipedia://en/24373456) is the union of a collection of cliques, all of the same order as each other, with one shared vertex belonging to all the cliques and all other vertices and edges distinct.

:::
