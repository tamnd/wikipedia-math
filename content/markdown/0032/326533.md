# Ramsey cardinal

::: {#o1 .subject cue=lead name="Ramsey cardinal"}

In [mathematics](wikipedia://en/18831), a **Ramsey cardinal** is a certain kind of [large cardinal](wikipedia://en/383644) number introduced by (Erdős Hajnal 1962) and named after [Frank P. Ramsey](wikipedia://en/238285), whose theorem, called [Ramsey's theorem](wikipedia://en/184898) establishes that [ω](wikipedia://en/26547932#Ordinals_extend_the_natural_numbers) enjoys a certain property that Ramsey cardinals generalize to the [uncountable](https://en.wikipedia.org/wiki/Uncountable) case.

:::

Let \[*κ*\]<sup>\<ω</sup> denote the set of all finite subsets of *κ*. A [cardinal number](wikipedia://en/6173) *κ* is called Ramsey if, for every function

*f*: \[*κ*\]<sup>\<ω</sup> → {0, 1}

there is a set *A* of cardinality *κ* that is [homogeneous](https://en.wikipedia.org/wiki/Homogeneous_%28large_cardinal_property%29) for *f*. That is, for every *n*, the function *f* is [constant](wikipedia://en/320861) on the subsets of cardinality *n* from *A*. A cardinal *κ* is called **ineffably Ramsey** if *A* can be chosen to be a [stationary](wikipedia://en/1679067) subset of *κ*. A cardinal *κ* is called **virtually Ramsey** if for every function

*f*: \[*κ*\]<sup>\<ω</sup> → {0, 1}

there is *C*, a closed and unbounded subset of *κ*, so that for every *λ* in *C* of uncountable [cofinality](wikipedia://en/6693), there is an unbounded subset of *λ* that is homogenous for *f*; slightly weaker is the notion of **almost Ramsey** where homogenous sets for *f* are required of order type *λ*, for every *λ* \< *κ*.

The existence of any of these kinds of Ramsey cardinal is sufficient to prove the existence of [0<sup>\#</sup>](wikipedia://en/248085), or indeed that every set with [rank](https://en.wikipedia.org/wiki/Rank_%28set_theory%29) less than *κ* has a [sharp](https://en.wikipedia.org/wiki/Sharp_%28set_theory%29). This in turn implies the falsity of the [Axiom of Constructibility](wikipedia://en/696472) of [Kurt Gödel](wikipedia://en/16736).

Every [measurable cardinal](wikipedia://en/248102) is a Ramsey cardinal, and every Ramsey cardinal is a [Rowbottom cardinal](wikipedia://en/3317885).

A property intermediate in strength between Ramseyness and [measurability](wikipedia://en/248102) is existence of a *κ*-complete normal non-principal [ideal](wikipedia://en/12633368) *I* on *κ* such that for every *A* ∉ *I* and for every function

*f*: \[*κ*\]<sup>\<ω</sup> → {0, 1}

there is a set *B* ⊂ *A* not in *I* that is homogeneous for *f*. This is strictly stronger than *κ* being ineffably Ramsey.

## Definition by κ-models {#Definition_by_κ-models}

A regular cardinal *κ* is Ramsey if and only if[^o4] for any set *A* ⊂ *κ*, there is a transitive set *M* ⊨ ZFC<sup>−</sup> (i.e. [ZFC](https://en.wikipedia.org/wiki/ZFC) without the axiom of powerset) of size *κ* with *A* ∈ *M*, and a nonprincipal [ultrafilter](wikipedia://en/31911) *U* on the Boolean algebra *P(κ) ∩ M* such that:

- *U* is an *M-ultrafilter:* for any sequence ⟨*X<sub>β</sub>* : *β \< κ*⟩ ∈ *M* of members of *U*, the [diagonal intersection](wikipedia://en/1679121) Δ*X<sub>β</sub>* = {*α \< κ* : ∀*β \< α*(*α* ∈ *X<sub>β</sub>*)} ∈ *U*,
- *U* is *weakly amenable:* for any sequence ⟨*X<sub>β</sub>* : *β \< κ*⟩ ∈ *M* of subsets of *κ*, the set {*β \< κ* : *X<sub>β</sub>* ∈ *U*} ∈ *M*, and
- *U* is *σ-complete:* the intersection of any countable family of members of *U* is again in *U*.
