# Annihilator (ring theory)

::: {#o1 .subject cue=lead name="Annihilator"}

In [mathematics](wikipedia://en/18831), the **annihilator** of a [subset](wikipedia://en/27631) $S$ of a [module](wikipedia://en/276410) over a [ring](wikipedia://en/48404) is the [ideal](wikipedia://en/25977) formed by the elements of the ring that always give zero when multiplied by each element of $S$. For example, if $R$ is a commutative ring and $I$ is an ideal of $R$, we can consider the [quotient ring](wikipedia://en/184635) $R/I$ to be an $R$-module. Then, the annihilator of $R/I$ is the ideal $I$, since all of the $i \in I$ act via the zero map on $R/I$.

:::

Over an [integral domain](wikipedia://en/15462), a module that has a nonzero annihilator is a [torsion module](https://en.wikipedia.org/wiki/Torsion_module), and a [finitely generated](wikipedia://en/326430) torsion module has a nonzero annihilator.

The above definition applies also in the case of [noncommutative rings](wikipedia://en/24062516), a subset of a left module has a **left annihilator**, which is a left ideal, and a subset of a right module has a **right annihilator**, which is a right ideal. If $S$ is a module, then the annihilator is always a two-sided ideal, regardless of whether the module is a left module or a right module.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let *R* be a [ring](wikipedia://en/48404), and let *M* be a left *R*-[module](wikipedia://en/276410). Choose a [non-empty](wikipedia://en/9566) subset *S* of *M*. The *annihilator* of *S*, denoted Ann<sub>*R*</sub>(*S*), is the set of all elements *r* in *R* such that, for all *s* in *S*, *rs* = 0.[^o4] In set notation,

$\mathrm{Ann}_R(S)=\{r\in R\mid rs = 0$ for all $s\in S \}$

It is the set of all elements of *R* that "annihilate" *S* (the elements for which *S* is a torsion set). Subsets of right modules may be used as well, after the modification of "*sr* = 0" in the definition.

The annihilator of a single element *x* is usually written Ann<sub>*R*</sub>(*x*) instead of Ann<sub>*R*</sub>({*x*}). If the ring *R* can be understood from the context, the subscript *R* can be omitted.

Since *R* is a module over itself, *S* may be taken to be a subset of *R* itself, and since *R* is both a right and a left *R*-module, the notation must be modified slightly to indicate the left or right side. Usually $\ell.\!\mathrm{Ann}_R(S)\,$ and $r.\!\mathrm{Ann}_R(S)\,$ or some similar subscript scheme are used to distinguish the left and right annihilators, if necessary.

If *M* is an *R*-module and Ann<sub>*R*</sub>(*M*) = 0, then *M* is called a *faithful module*.

:::

## Properties {#Properties}

If *S* is a subset of a left *R*-module *M*, then Ann(*S*) is a left [ideal](wikipedia://en/25977#Definitions) of *R*.[^o7] If *S* is not just a subset but also a [submodule](wikipedia://en/276410#Submodules_and_homomorphisms) of *M*, then Ann<sub>*R*</sub>(*S*) is moreover a two-sided ideal: (*ac*)*s* = *a*(*cs*) = 0, since *cs* is another element of *S*.[^o8]

If *S* is a subset of *M* and *N* is the submodule of *M* generated by *S*, then in general Ann<sub>*R*</sub>(*N*) is a subset of Ann<sub>*R*</sub>(*S*), but they are not necessarily equal. If *R* is [commutative](wikipedia://en/61346), then the equality holds.

An *R*-module *M* may be also viewed as an *R*/Ann<sub>*R*</sub>(*M*)-module using the action $\overline{r}m:=rm\,$. It is not always possible to make an *R*-module into an *R*/*I*-module this way, but if the ideal *I* is a subset of the annihilator of *M*, then this action is well-defined. The module *M* is always faithful when considered as an *R*/Ann<sub>*R*</sub>(*M*)-module.

### For commutative rings {#For_commutative_rings}

Throughout this section, let $R$ be a commutative ring and $M$ an $R$-module.

#### Relation to support {#Relation_to_support}

The [support of a module](wikipedia://en/16073360) is defined as

$$\operatorname{Supp}M = \{ \mathfrak{p} \in \operatorname{Spec}R \mid M_\mathfrak{p} \neq 0 \}.$$

When the module is [finitely generated](wikipedia://en/326430), the support of $M$ is exactly the set of [prime ideals](wikipedia://en/24928) containing $\operatorname{Ann}_R(M)$.[^n1][^o12]

#### Short exact sequences {#Short_exact_sequences}

Given a [short exact sequence](https://en.wikipedia.org/wiki/Short_exact_sequence) of modules,

$$0 \to M' \to M \to M'' \to 0,$$

we have the relations

$$\operatorname{Ann}_R(M') \cap \operatorname{Ann}_R(M'') \supseteq \operatorname{Ann}_R(M) \supseteq \operatorname{Ann}_R(M') \operatorname{Ann}_R(M'').$$

If the sequence splits, so that $M \cong M' \oplus M''$, then the inequality on the left is always an equality. Indeed, this holds for arbitrary [direct sums](wikipedia://en/58899) of modules:

$$\operatorname{Ann}_R\left( \bigoplus_{i\in I} M_i \right) = \bigcap_{i\in I} \operatorname{Ann}_R(M_i).$$

In the special case that $M' = IM$ and $M'' = M/IM$ for some ideal $I \subset R$, we have the relation $\operatorname{Ann}_R(M/IM) \supseteq \operatorname{Ann}_R(M) + I$.

:::

## Examples {#Examples}

### Over the integers {#Over_the_integers}

Over $\mathbb{Z}$, any finitely generated module is completely classified, by the fundamental theorem of abelian groups, as a direct sum between its [free](wikipedia://en/326454) part and its torsion part. Therefore, if the annihilator of a finitely generated module is non-trivial, it must be exactly equal to the torsion part of the module. This is because

$$\text{Ann}_{\mathbb{Z}}(\mathbb{Z}^{\oplus k}) = \{ 0 \} = (0)$$

since the only element annihilating each of the $\mathbb{Z}$ is $0$. For example, the annihilator of $\mathbb{Z}/2 \oplus \mathbb{Z}/3$ is

$$\text{Ann}_\mathbb{Z}(\mathbb{Z}/2 \oplus \mathbb{Z}/3) = (6) = (\text{lcm}(2,3)),$$

the ideal generated by $(6)$. In fact the annihilator of a torsion module

$$M \cong \bigoplus_{i=1}^n (\mathbb{Z}/a_i)^{\oplus k_i}$$

is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the ideal generated by their [least common multiple](wikipedia://en/17961), $(\operatorname{lcm}(a_1, \ldots, a_n))$. This shows the annihilators can be easily classified over the integers.

### Over a commutative ring *R* {#Over_a_commutative_ring_R}

There is a similar computation that can be done for any [finitely presented module](https://en.wikipedia.org/wiki/Finitely_presented_module) over a commutative ring $R$. The definition of finite presentedness of $M$ implies there exists an exact sequence, called a presentation, given by

$$R^{\oplus l} \xrightarrow{\phi} R^{\oplus k} \to M \to 0$$

where $\phi$ is in $\text{Mat}_{k,l}(R)$. Writing $\phi$ explicitly as a [matrix](wikipedia://en/20556859) gives it as

$$\phi = \begin{bmatrix} \phi_{1,1} & \cdots & \phi_{1,l} \\ \vdots & & \vdots \\ \phi_{k,1} & \cdots & \phi_{k,l} \end{bmatrix};$$

hence $M$ has the direct sum decomposition

$$M = \bigoplus_{i=1}^k \frac{R}{(\phi_{i,1}(1), \ldots, \phi_{i,l}(1))}$$

If each of these ideals is written as

$$I_i = (\phi_{i,1}(1), \ldots, \phi_{i,l}(1))$$

then the ideal $I$ given by

$$V(I) = \bigcup^{k}_{i=1}V(I_i)$$

presents the annihilator.

### Over *k*\[*x*,*y*\] {#Over_k[x,y]}

Over the commutative ring $k[x,y]$ for a [field](wikipedia://en/10603) $k$, the annihilator of the module

$$M = \frac{k[x,y]}{(x^2 - y)} \oplus \frac{k[x,y]}{(y - 3)}$$

is given by the ideal

$$\text{Ann}_{k[x,y]}(M) = ((x^2 - y)(y - 3)).$$

:::

## Chain conditions on annihilator ideals {#Chain_conditions_on_annihilator_ideals}

The [lattice](wikipedia://en/469304) of ideals of the form $\ell.\!\mathrm{Ann}_R(S)$ where *S* is a subset of *R* is a [complete lattice](wikipedia://en/44777) when [partially ordered](https://en.wikipedia.org/wiki/Partially_ordered) by [inclusion](wikipedia://en/27631). There is interest in studying rings for which this lattice (or its right counterpart) satisfies the [ascending chain condition](wikipedia://en/3189) or [descending chain condition](https://en.wikipedia.org/wiki/Descending_chain_condition).

Denote the lattice of left annihilator ideals of *R* as $\mathcal{LA}\,$ and the lattice of right annihilator ideals of *R* as $\mathcal{RA}\,$. It is known that $\mathcal{LA}\,$ satisfies the ascending chain condition [if and only if](wikipedia://en/14922) $\mathcal{RA}\,$ satisfies the descending chain condition, and symmetrically $\mathcal{RA}\,$ satisfies the ascending chain condition if and only if $\mathcal{LA}\,$ satisfies the descending chain condition. If either lattice has either of these chain conditions, then *R* has no infinite pairwise orthogonal sets of [idempotents](wikipedia://en/361940). [^n2][^n3]

If *R* is a ring for which $\mathcal{LA}\,$ satisfies the A.C.C. and <sub>*R*</sub>*R* has finite [uniform dimension](wikipedia://en/31553078#Uniform_dimension_of_a_module), then *R* is called a left [Goldie ring](https://en.wikipedia.org/wiki/Goldie_ring).[^n3]

## Category-theoretic description for commutative rings {#Category-theoretic_description_for_commutative_rings}

When $R$ is commutative and $M$ is an $R$-module, we may describe $\mathrm{Ann}_R(M)$ as the [kernel](wikipedia://en/45240) of the action map $R\to\mathrm{End}_R(M)$ determined by the [adjunct map](https://en.wikipedia.org/wiki/Adjunction_%28category_theory%29) of the [identity](https://en.wikipedia.org/wiki/Identity_map) $M\to M$ along the [Hom-tensor adjunction](https://en.wikipedia.org/wiki/Hom-tensor_adjunction).

More generally, given a [bilinear map](wikipedia://en/4365) of modules $F\colon M \times N \to P$, the annihilator of a subset $S \subseteq M$ is the set of all elements in $N$ that annihilate $S$:

$$\operatorname{Ann}(S) := \{ n \in N \mid \forall s \in S: F(s,n) = 0 \} .$$

Conversely, given $T \subseteq N$, one can define an annihilator as a subset of $M$.

The annihilator gives a [Galois connection](wikipedia://en/156411) between subsets of $M$ and $N$, and the associated [closure operator](wikipedia://en/483120) is stronger than the span. In particular:

- annihilators are submodules
- $$\operatorname{Span}S \leq \operatorname{Ann}(\operatorname{Ann}(S))$$
- $$\operatorname{Ann}(\operatorname{Ann}(\operatorname{Ann}(S))) = \operatorname{Ann}(S)$$

An important special case is in the presence of a [nondegenerate form](https://en.wikipedia.org/wiki/Nondegenerate_form) on a [vector space](wikipedia://en/32370), particularly an [inner product](https://en.wikipedia.org/wiki/Inner_product): then the annihilator associated to the map $V \times V \to K$ is called the [orthogonal complement](wikipedia://en/1058833).

## Relations to other properties of rings {#Relations_to_other_properties_of_rings}

Given a module *M* over a [Noetherian](wikipedia://en/56129) commutative ring *R*, a prime ideal of *R* that is an annihilator of a nonzero element of *M* is called an [associated prime](wikipedia://en/17286442) of *M*.

- Annihilators are used to define left [Rickart rings](https://en.wikipedia.org/wiki/Rickart_ring) and [Baer rings](wikipedia://en/7455223).
- The set of (left) [zero divisors](wikipedia://en/51441) *D*<sub>*S*</sub> of *S* can be written as

$$D_S = \bigcup_{x \in S \setminus \{0\}}{\mathrm{Ann}_R(x)}.$$

(Here we allow zero to be a zero divisor.)

In particular *D<sub>R</sub>* is the set of (left) zero divisors of *R* taking *S* = *R* and *R* acting on itself as a left *R*-module.

- When *R* is commutative and Noetherian, the set $D_R$ is precisely equal to the [union](wikipedia://en/47949) of the [associated primes](wikipedia://en/17286442) of the *R*-module *R*.
