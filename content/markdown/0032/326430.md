# Finitely generated module

::: {#o1 .subject cue=lead name="Finitely generated module"}

In [mathematics](wikipedia://en/18831), a **finitely generated module** is a [module](wikipedia://en/276410) that has a [finite](wikipedia://en/11742) [generating set](wikipedia://en/50718738). A finitely generated module over a [ring](wikipedia://en/48404) *R* may also be called a **finite *R*-module**, **finite over *R***,[^o2] or a **module of finite type**.

:::

Related concepts include **finitely cogenerated modules**, **finitely presented modules**, **finitely related modules** and **coherent modules** all of which are defined below. Over a [Noetherian ring](wikipedia://en/56129) the concepts of finitely generated, finitely presented and coherent modules coincide.

A finitely generated module over a [field](wikipedia://en/10603) is simply a [finite-dimensional](wikipedia://en/38267) [vector space](wikipedia://en/32370), and a finitely generated module over the [integers](wikipedia://en/14563) is simply a [finitely generated abelian group](wikipedia://en/58527).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The left *R*-module *M* is finitely generated if there exist *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub> in *M* such that for any *x* in *M*, there exist *r*<sub>1</sub>, *r*<sub>2</sub>, ..., *r*<sub>*n*</sub> in *R* with *x* = *r*<sub>1</sub>*a*<sub>1</sub> + *r*<sub>2</sub>*a*<sub>2</sub> + ... + *r*<sub>*n*</sub>*a*<sub>*n*</sub>.

The [set](wikipedia://en/26691) {*a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub>} is referred to as a [generating set](wikipedia://en/50718738) of *M* in this case. A finite generating set need not be a basis, since it need not be linearly independent over *R*. What is true is: *M* is finitely generated if and only if there is a surjective [*R*-linear map](wikipedia://en/474118):

$$R^n \to M$$

for some *n*; in other words, *M* is a [quotient](wikipedia://en/364820) of a [free module](wikipedia://en/326454) of finite rank.

If a set *S* generates a module that is finitely generated, then there is a finite generating set that is included in *S*, since only finitely many elements in *S* are needed to express the generators in any finite generating set, and these finitely many elements form a generating set. However, it may occur that *S* does not contain any finite generating set of minimal [cardinality](wikipedia://en/6174). For example the set of the [prime numbers](wikipedia://en/23666) is a generating set of $\mathbb Z$ viewed as $\mathbb Z$-module, and a generating set formed from prime numbers has at least two elements, while the [singleton](wikipedia://en/381798)$\{1\}$ is also a generating set.

In the case where the [module](wikipedia://en/276410) *M* is a [vector space](wikipedia://en/32370) over a [field](wikipedia://en/10603) *R*, and the generating set is [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent), *n* is *well-defined* and is referred to as the [dimension](https://en.wikipedia.org/wiki/Dimension_of_a_vector_space) of *M* (*well-defined* means that any [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) generating set has *n* elements: this is the [dimension theorem for vector spaces](wikipedia://en/346992)).

Any module is the union of the [directed set](wikipedia://en/9165) of its finitely generated submodules.

A module *M* is finitely generated if and only if any increasing chain *M*<sub>*i*</sub> of submodules with union *M* stabilizes: i.e., there is some *i* such that *M*<sub>*i*</sub> = *M*. This fact with [Zorn's lemma](wikipedia://en/51442) implies that every nonzero finitely generated module admits [maximal submodules](https://en.wikipedia.org/wiki/Maximal_submodule). If any increasing chain of submodules stabilizes (i.e., any submodule is finitely generated), then the module *M* is called a [Noetherian module](wikipedia://en/542431).

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- If a module is generated by one element, it is called a [cyclic module](wikipedia://en/4128720).
- Let *R* be an [integral domain](wikipedia://en/15462) with *K* its [field of fractions](wikipedia://en/25271). Then every finitely generated *R*-submodule *I* of *K* is a [fractional ideal](wikipedia://en/460700): that is, there is some nonzero *r* in *R* such that *rI* is contained in *R*. Indeed, one can take *r* to be the product of the denominators of the generators of *I*. If *R* is Noetherian, then every fractional ideal arises in this way.
- Finitely generated modules over the ring of [integers](wikipedia://en/14563) **Z** coincide with the [finitely generated abelian groups](wikipedia://en/58527). (These are completely classified by [the structure theorem](wikipedia://en/9902787), taking **Z** as the [principal ideal domain](wikipedia://en/25039).)
- Finitely generated (say, left) modules over a [division ring](wikipedia://en/9067) are precisely finite dimensional vector spaces (over the division ring).

:::

## Some facts {#Some_facts}

Every [homomorphic image](wikipedia://en/474118) of a finitely generated module is finitely generated. In general, [submodules](https://en.wikipedia.org/wiki/Submodule) of finitely generated modules need not be finitely generated. As an example, consider the ring *R* = **Z**\[*X*<sub>1</sub>, *X*<sub>2</sub>, ...\] of all [polynomials](wikipedia://en/23000) in [countably many](https://en.wikipedia.org/wiki/Countable) variables. *R* itself is a finitely generated *R*-module (with {1} as generating set). Consider the submodule *K* consisting of all those polynomials with zero constant term. Since every polynomial contains only finitely many terms whose coefficients are non-zero, the *R*-module *K* is not finitely generated.

In general, a module is said to be [Noetherian](wikipedia://en/542431) if every submodule is finitely generated. A finitely generated module over a [Noetherian ring](wikipedia://en/56129) is a Noetherian module (and indeed this property characterizes Noetherian rings): A module over a Noetherian ring is finitely generated if and only if it is a Noetherian module. This resembles, but is not exactly [Hilbert's basis theorem](wikipedia://en/13733), which states that the polynomial ring *R*\[*X*\] over a Noetherian ring *R* is Noetherian. Both facts imply that a finitely generated commutative algebra over a Noetherian ring is again a Noetherian ring.

More generally, an algebra (e.g., ring) that is a finitely generated module is a [finitely generated algebra](wikipedia://en/11985661). Conversely, if a finitely generated algebra is integral (over the coefficient ring), then it is finitely generated module. (See [integral element](wikipedia://en/9478630) for more.)

Let 0 → *M*′ → *M* → *M*′′ → 0 be an [exact sequence](wikipedia://en/138215) of modules. Then *M* is finitely generated if *M*′, *M*′′ are finitely generated. There are some partial converses to this. If *M* is finitely generated and *M*′′ is finitely presented (which is stronger than finitely generated; see below), then *M*′ is finitely generated. Also, *M* is Noetherian (resp. Artinian) if and only if *M*′, *M*′′ are Noetherian (resp. Artinian).

Let *B* be a ring and *A* its subring such that *B* is a [faithfully flat](https://en.wikipedia.org/wiki/Faithfully_flat_module) right *A*-module. Then a left *A*-module *F* is finitely generated (resp. finitely presented) if and only if the *B*-module *B* ⊗<sub>*A*</sub> *F* is finitely generated (resp. finitely presented).[^n1]

## Finitely generated modules over a commutative ring {#Finitely_generated_modules_over_a_commutative_ring}

For finitely generated modules over a commutative ring *R*, [Nakayama's lemma](wikipedia://en/1835001) is fundamental. Sometimes, the lemma allows one to prove finite dimensional vector spaces phenomena for finitely generated modules. For example, if *f* : *M* → *M* is a [surjective](https://en.wikipedia.org/wiki/Surjective) *R*-endomorphism of a finitely generated module *M*, then *f* is also [injective](wikipedia://en/45196), and hence is an [automorphism](wikipedia://en/1160) of *M*.[^n2] This says simply that *M* is a [Hopfian module](https://en.wikipedia.org/wiki/Hopfian_module). Similarly, an [Artinian module](wikipedia://en/542336) *M* is [coHopfian](wikipedia://en/32290692): any injective endomorphism *f* is also a surjective endomorphism.[^n3] The [Forster–Swan theorem](wikipedia://en/78537564) gives an upper bound for the minimal number of generators of a finitely generated module *M* over a commutative Noetherian ring.

Any *R*-module is an [inductive limit](https://en.wikipedia.org/wiki/Inductive_limit) of finitely generated *R*-submodules. This is useful for weakening an assumption to the finite case (e.g., the [characterization of flatness](wikipedia://en/492616#Homological_algebra) with the [Tor functor](wikipedia://en/856347)).

An example of a link between finite generation and [integral elements](wikipedia://en/9478630) can be found in commutative algebras. To say that a commutative algebra *A* is a **finitely generated ring** over *R* means that there exists a set of elements *G* = $\{x_{1}, ..., x_{n}\}$ of *A* such that the smallest subring of *A* containing *G* and *R* is *A* itself. Because the ring product may be used to combine elements, more than just *R*-linear combinations of elements of *G* are generated. For example, a [polynomial ring](wikipedia://en/373065) *R*\[*x*\] is finitely generated by $\{1, x\}$ as a ring, *but not as a module*. If *A* is a commutative algebra (with unity) over *R*, then the following two statements are equivalent:[^n4]

- *A* is a finitely generated *R* module.
- *A* is both a finitely generated ring over *R* and an [integral extension](wikipedia://en/9478630) of *R*.

## Generic rank {#Generic_rank}

Let *M* be a finitely generated module over an integral domain *A* with the field of fractions *K*. Then the dimension $\operatorname{dim}_K (M \otimes_A K)$ is called the **generic rank** of *M* over *A*. This number is the same as the number of maximal *A*-linearly independent vectors in *M* or equivalently the rank of a maximal free submodule of *M* (*cf. [Rank of an abelian group](wikipedia://en/244541)*). Since $(M/F)_{(0)} = M_{(0)}/F_{(0)} = 0$, $M/F$ is a [torsion module](https://en.wikipedia.org/wiki/Torsion_module). When *A* is Noetherian, by [generic freeness](https://en.wikipedia.org/wiki/Generic_freeness), there is an element *f* (depending on *M*) such that $M[f^{-1}]$ is a free $A[f^{-1}]$-module. Then the rank of this free module is the generic rank of *M*.

Now suppose the integral domain *A* is an $\mathbb{N}$-[graded algebra](https://en.wikipedia.org/wiki/Graded_algebra) over a field *k* generated by finitely many homogeneous elements of degrees $d_i$. Suppose *M* is graded as well and let $P_M(t) = \sum (\operatorname{dim}_k M_n) t^n$ be the [Poincaré series](wikipedia://en/24146591) of *M*. By the [Hilbert–Serre theorem](https://en.wikipedia.org/wiki/Hilbert–Serre_theorem), there is a polynomial *F* such that $P_M(t) = F(t) \prod (1-t^{d_i})^{-1}$. Then $F(1)$ is the generic rank of *M*.[^o15]

A finitely generated module over a [principal ideal domain](wikipedia://en/25039) is [torsion-free](wikipedia://en/38400572) if and only if it is free. This is a consequence of the [structure theorem for finitely generated modules over a principal ideal domain](wikipedia://en/9902787), the basic form of which says a finitely generated module over a PID is a direct sum of a torsion module and a free module. But it can also be shown directly as follows: let *M* be a torsion-free finitely generated module over a PID *A* and *F* a maximal free submodule. Let *f* be in *A* such that $f M \subset F$. Then $fM$ is free since it is a submodule of a free module and *A* is a PID. But now $f: M \to fM$ is an isomorphism since *M* is torsion-free.

By the same argument as above, a finitely generated module over a [Dedekind domain](wikipedia://en/145132) *A* (or more generally a [semi-hereditary ring](https://en.wikipedia.org/wiki/Semi-hereditary_ring)) is torsion-free if and only if it is [projective](wikipedia://en/364488); consequently, a finitely generated module over *A* is a direct sum of a torsion module and a projective module. A finitely generated projective module over a Noetherian integral domain has constant rank and so the generic rank of a finitely generated module over *A* is the rank of its projective part.

:::

## Equivalent definitions and finitely cogenerated modules {#Equivalent_definitions_and_finitely_cogenerated_modules}

The following conditions are equivalent to *M* being finitely generated (f.g.):

- For any family of submodules {*N<sub>i</sub>* | *i* ∈ *I*} in *M*, if $\sum_{i\in I}N_i=M\,$, then $\sum_{i\in F}N_i=M\,$ for some finite [subset](wikipedia://en/27631) *F* of *I*.
- For any [chain](wikipedia://en/30330#Chains) of submodules {*N<sub>i</sub>* | *i* ∈ *I*} in *M*, if $\bigcup_{i\in I}N_i=M\,$, then *N<sub>i</sub>* = *M* for some *i* in *I*.
- If $\phi:\bigoplus_{i\in I}R\to M\,$ is an [epimorphism](wikipedia://en/59539), then the restriction $\phi:\bigoplus_{i\in F}R\to M\,$ is an epimorphism for some finite subset *F* of *I*.

From these conditions it is easy to see that being finitely generated is a property preserved by [Morita equivalence](wikipedia://en/3296134). The conditions are also convenient to define a [dual](wikipedia://en/609737) notion of a **finitely cogenerated module** *M*. The following conditions are equivalent to a module being finitely cogenerated (f.cog.):

- For any family of submodules {*N<sub>i</sub>* | *i* ∈ *I*} in *M*, if $\bigcap_{i\in I}N_i=\{0\}\,$, then $\bigcap_{i\in F}N_i=\{0\}\,$ for some finite subset *F* of *I*.
- For any chain of submodules {*N<sub>i</sub>* | *i* ∈ *I*} in *M*, if $\bigcap_{i\in I}N_i=\{0\}\,$, then *N<sub>i</sub>* = $\{0\}$ for some *i* in *I*.
- If $\phi:M\to \prod_{i\in I}N_i\,$ is a [monomorphism](wikipedia://en/59538), where each $N_i$ is an *R* module, then $\phi:M\to \prod_{i\in F}N_i\,$ is a monomorphism for some finite subset *F* of *I*.

Both f.g. modules and f.cog. modules have interesting relationships to Noetherian and Artinian modules, and the [Jacobson radical](wikipedia://en/57656) *J*(*M*) and [socle](wikipedia://en/3571350) soc(*M*) of a module. The following facts illustrate the duality between the two conditions. For a module *M*:

- *M* is Noetherian if and only if every submodule *N* of *M* is f.g.
- *M* is Artinian if and only if every quotient module *M*/*N* is f.cog.
- *M* is f.g. if and only if *J*(*M*) is a [superfluous submodule](https://en.wikipedia.org/wiki/Superfluous_submodule) of *M*, and *M*/*J*(*M*) is f.g.
- *M* is f.cog. if and only if soc(*M*) is an [essential submodule](https://en.wikipedia.org/wiki/Essential_submodule) of *M*, and soc(*M*) is f.g.
- If *M* is a [semisimple module](wikipedia://en/1001361) (such as soc(*N*) for any module *N*), it is f.g. if and only if f.cog.
- If *M* is f.g. and nonzero, then *M* has a [maximal submodule](https://en.wikipedia.org/wiki/Maximal_submodule) and any quotient module *M*/*N* is f.g.
- If *M* is f.cog. and nonzero, then *M* has a minimal submodule, and any submodule *N* of *M* is f.cog.
- If *N* and *M*/*N* are f.g. then so is *M*. The same is true if "f.g." is replaced with "f.cog."

Finitely cogenerated modules must have finite [uniform dimension](https://en.wikipedia.org/wiki/Uniform_dimension). This is easily seen by applying the characterization using the finitely generated essential socle. Somewhat asymmetrically, finitely generated modules *do not* necessarily have finite uniform dimension. For example, an infinite direct product of nonzero rings is a finitely generated (cyclic!) module over itself, however it clearly contains an infinite direct sum of nonzero submodules. Finitely generated modules *do not* necessarily have finite [co-uniform dimension](wikipedia://en/31553078#Hollow_modules_and_co-uniform_dimension) either: any ring *R* with unity such that *R*/*J*(*R*) is not a semisimple ring is a counterexample.

## Finitely presented, finitely related, and coherent modules {#Finitely_presented,_finitely_related,_and_coherent_modules}

Another formulation is this: a finitely generated module *M* is one for which there is an [epimorphism](wikipedia://en/59539) mapping *R<sup>k</sup>* onto *M* :

f : *R<sup>k</sup>* → *M*.

Suppose now there is an epimorphism,

*φ* : *F* → *M*.

for a module *M* and free module *F*.

- If the [kernel](wikipedia://en/45240) of *φ* is finitely generated, then *M* is called a **finitely related module**. Since *M* is isomorphic to *F*/ker(*φ*), this basically expresses that *M* is obtained by taking a free module and introducing finitely many relations within *F* (the generators of ker(*φ*)).
- If the kernel of *φ* is finitely generated and *F* has finite rank (i.e. *F* = *R*<sup>*k*</sup>), then *M* is said to be a **finitely presented module**. Here, *M* is specified using finitely many generators (the images of the *k* generators of *F* = *R*<sup>*k*</sup>) and finitely many relations (the generators of ker(*φ*)). See also: [free presentation](wikipedia://en/46394651). Finitely presented modules can be characterized by an abstract property within the [category of *R*-modules](wikipedia://en/11231812): they are precisely the [compact objects](wikipedia://en/57633087) in this category.
- A **coherent module** *M* is a finitely generated module whose finitely generated submodules are finitely presented.

Over any ring *R*, coherent modules are finitely presented, and finitely presented modules are both finitely generated and finitely related. For a [Noetherian ring](wikipedia://en/56129) *R*, finitely generated, finitely presented, and coherent are equivalent conditions on a module.

Some crossover occurs for projective or flat modules. A finitely generated projective module is finitely presented, and a finitely related flat module is projective.

It is true also that the following conditions are equivalent for a ring *R*:

1. *R* is a right [coherent ring](wikipedia://en/14777654).
1. The module *R*<sub>*R*</sub> is a coherent module.
1. Every finitely presented right *R* module is coherent.

Although coherence seems like a more cumbersome condition than finitely generated or finitely presented, it is nicer than them since the [category](wikipedia://en/53759) of coherent modules is an [abelian category](wikipedia://en/45063), while, in general, neither finitely generated nor finitely presented modules form an abelian category.
