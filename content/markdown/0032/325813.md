# Graph drawing

Network diagram

*Image: WorldWideWebAroundWikipedia.png.* Graphic representation of a minute fraction of the [WWW](https://en.wikipedia.org/wiki/WWW), demonstrating [hyperlinks](https://en.wikipedia.org/wiki/Hyperlink).

::: {#o1 .subject cue=lead name="Graph drawing"}

**Graph drawing** is an area of [mathematics](wikipedia://en/18831) and [computer science](https://en.wikipedia.org/wiki/Computer_science) combining methods from [geometric graph theory](wikipedia://en/3313527) and [information visualization](https://en.wikipedia.org/wiki/Information_visualization) to derive two-dimensional (or, sometimes, three-dimensional) depictions of [graphs](wikipedia://en/325806) arising from applications such as [social network analysis](wikipedia://en/325726), [cartography](https://en.wikipedia.org/wiki/Cartography), [linguistics](https://en.wikipedia.org/wiki/Linguistics), and [bioinformatics](wikipedia://en/4214).[^o2]

:::

A drawing of a graph or **network diagram** is a pictorial representation of the [vertices](wikipedia://en/638899) and [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) of a graph. This drawing should not be confused with the graph itself: very different layouts can correspond to the same graph.[^o3] In the abstract, all that matters is which pairs of vertices are connected by edges. In the concrete, however, the arrangement of these vertices and edges within a drawing affects its understandability, usability, fabrication cost, and [aesthetics](https://en.wikipedia.org/wiki/Aesthetics).[^o6] The problem gets worse if the graph changes over time by adding and deleting edges (dynamic graph drawing) and the goal is to preserve the user's mental map.[^n1]

## Graphical conventions {#Graphical_conventions}

*Image: 4node-digraph-natural.svg.* [Directed graph](wikipedia://en/19721986) with arrowheads showing edge directions

Graphs are frequently drawn as node–link diagrams in which the vertices are represented as disks, boxes, or textual labels and the edges are represented as [line segments](wikipedia://en/22634860), [polylines](wikipedia://en/12056032), or curves in the [Euclidean plane](wikipedia://en/15575410).[^o6] Node–link diagrams can be traced back to the 14th-16th century works of Pseudo-Lull which were published under the name of [Ramon Llull](wikipedia://en/69677), a 13th century polymath. Pseudo-Lull drew diagrams of this type for [complete graphs](wikipedia://en/85816) in order to analyze all pairwise combinations among sets of metaphysical concepts.[^n2]

In the case of [directed graphs](wikipedia://en/19721986), [arrowheads](wikipedia://en/4912832) form a commonly used graphical convention to show their [orientation](wikipedia://en/187446);[^o3] however, user studies have shown that other conventions such as tapering provide this information more effectively.[^o8] [Upward planar drawing](wikipedia://en/40148474) uses the convention that every edge is oriented from a lower vertex to a higher vertex, making arrowheads unnecessary.[^n3]

Alternative conventions to node–link diagrams include adjacency representations such as [circle packings](wikipedia://en/16648043), in which vertices are represented by disjoint regions in the plane and edges are represented by adjacencies between regions; [intersection representations](wikipedia://en/7726759) in which vertices are represented by non-disjoint geometric objects and edges are represented by their intersections; [visibility representations](wikipedia://en/1448291) in which vertices are represented by regions in the plane and edges are represented by regions that have an unobstructed line of sight to each other; confluent drawings, in which edges are represented as smooth curves within mathematical [train tracks](wikipedia://en/1277396); fabrics, in which nodes are represented as horizontal lines and edges as vertical lines;[^o10] and visualizations of the [adjacency matrix](wikipedia://en/244463) of the graph.

## Quality measures {#Quality_measures}

Many different quality measures have been defined for graph drawings, in an attempt to find objective means of evaluating their aesthetics and usability.[^o12] In addition to guiding the choice between different layout methods for the same graph, some layout methods attempt to directly optimize these measures.

*Image: 4node-digraph-embed.svg.* [Planar graph](wikipedia://en/24314) drawn without overlapping edges

- The [crossing number](wikipedia://en/18298594) of a drawing is the number of pairs of edges that cross each other. If the graph is [planar](wikipedia://en/24314), then it is often convenient to draw it without any edge intersections; that is, in this case, a graph drawing represents a [graph embedding](wikipedia://en/8149170). However, nonplanar graphs frequently arise in applications, so graph drawing algorithms must generally allow for edge crossings.[^o13]
- The [area](wikipedia://en/43176265) of a drawing is the size of its smallest [bounding box](https://en.wikipedia.org/wiki/Bounding_box), relative to the closest distance between any two vertices. Drawings with smaller area are generally preferable to those with larger area, because they allow the features of the drawing to be shown at greater size and therefore more legibly. The [aspect ratio](wikipedia://en/1021) of the bounding box may also be important.
- Symmetry display is the problem of finding [symmetry groups](wikipedia://en/15094186) within a given graph, and finding a drawing that displays as much of the symmetry as possible. Some layout methods automatically lead to symmetric drawings; alternatively, some drawing methods start by finding symmetries in the input graph and using them to construct a drawing.[^o14]
- It is important that edges have shapes that are as simple as possible, to make it easier for the eye to follow them. In polyline drawings, the complexity of an edge may be measured by its [number of bends](wikipedia://en/43176911), and many methods aim to provide drawings with few total bends or few bends per edge. Similarly for spline curves the complexity of an edge may be measured by the number of control points on the edge.
- Several commonly used quality measures concern lengths of edges: it is generally desirable to minimize the total length of the edges as well as the maximum length of any edge. Additionally, it may be preferable for the lengths of edges to be uniform rather than highly varied.
- [Angular resolution](wikipedia://en/33245450) is a measure of the sharpest angles in a graph drawing. If a graph has vertices with high [degree](wikipedia://en/1374448) then it necessarily will have small angular resolution, but the angular resolution can be bounded below by a function of the degree.[^n4]
- The [slope number](wikipedia://en/36545943) of a graph is the minimum number of distinct edge slopes needed in a drawing with straight line segment edges (allowing crossings). [Cubic graphs](wikipedia://en/980508) have slope number at most four, but graphs of degree five may have unbounded slope number; it remains open whether the slope number of degree-4 graphs is bounded.[^n4]

## Layout methods {#Layout_methods}

*Image: Social Network Analysis Visualization.png.* A force-based network visualization.[^n5]

*Image: Spectral graph drawing of small world graph.svg.* Spectral graph layout visualization.

There are many different graph layout strategies:

- In [force-based layout](https://en.wikipedia.org/wiki/Force-based_layout) systems, the graph drawing software modifies an initial vertex placement by continuously moving the vertices according to a system of forces based on physical metaphors related to systems of [springs](https://en.wikipedia.org/wiki/Spring_%28device%29) or [molecular mechanics](https://en.wikipedia.org/wiki/Molecular_mechanics). Typically, these systems combine attractive forces between adjacent vertices with repulsive forces between all pairs of vertices, in order to seek a layout in which edge lengths are small while vertices are well-separated. These systems may perform [gradient descent](wikipedia://en/201489) based minimization of an [energy function](https://en.wikipedia.org/wiki/Energy_function), or they may translate the forces directly into velocities or accelerations for the moving vertices.[^o19]
- [Spectral layout](wikipedia://en/18412684) methods use as coordinates the [eigenvectors](https://en.wikipedia.org/wiki/Eigenvector) of a [matrix](wikipedia://en/20556859) such as the [Laplacian](wikipedia://en/1394358) derived from the [adjacency matrix](wikipedia://en/244463) of the graph.[^o20]
- Orthogonal layout methods, which allow the edges of the graph to run horizontally or vertically, parallel to the coordinate axes of the layout. These methods were originally designed for [VLSI](https://en.wikipedia.org/wiki/VLSI) and [PCB](https://en.wikipedia.org/wiki/Printed_circuit_board) layout problems but they have also been adapted for graph drawing. They typically involve a multiphase approach in which an input graph is planarized by replacing crossing points by vertices, a topological embedding of the planarized graph is found, edge orientations are chosen to minimize bends, vertices are placed consistently with these orientations, and finally a layout compaction stage reduces the area of the drawing.[^o21]
- Tree layout algorithms these show a rooted [tree](https://en.wikipedia.org/wiki/Tree_structure)-like formation, suitable for [trees](wikipedia://en/48560). Often, in a technique called "balloon layout", the children of each node in the tree are drawn on a circle surrounding the node, with the radii of these circles diminishing at lower levels in the tree so that these circles do not overlap.[^o22]
- [Layered graph drawing](wikipedia://en/33211287) methods (often called Sugiyama-style drawing) are best suited for [directed acyclic graphs](wikipedia://en/204002) or graphs that are nearly acyclic, such as the graphs of dependencies between modules or functions in a software system. In these methods, the nodes of the graph are arranged into horizontal layers using methods such as the [Coffman–Graham algorithm](wikipedia://en/31501543), in such a way that most edges go downwards from one layer to the next; after this step, the nodes within each layer are arranged in order to minimize crossings.[^o23]

*Image: Goldner-Harary-linear.svg.* Arc diagram

- [Arc diagrams](wikipedia://en/38996336), a layout style dating back to the 1960s,[^o24] place vertices on a line; edges may be drawn as semicircles above or below the line, or as smooth curves linked together from multiple semicircles.
- [Circular layout](wikipedia://en/38903361) methods place the vertices of the graph on a circle, choosing carefully the ordering of the vertices around the circle to reduce crossings and place adjacent vertices close to each other. Edges may be drawn either as chords of the circle or as arcs inside or outside of the circle. In some cases, multiple circles may be used.[^o25]
- [Dominance drawing](wikipedia://en/40153860) places vertices in such a way that one vertex is upwards, rightwards, or both of another if and only if it is [reachable](wikipedia://en/2833097) from the other vertex. In this way, the layout style makes the reachability relation of the graph visually apparent.[^o26]

## Application-specific graph drawings {#Application-specific_graph_drawings}

Graphs and graph drawings arising in other areas of application include

- [Sociograms](https://en.wikipedia.org/wiki/Sociogram), drawings of a [social network](https://en.wikipedia.org/wiki/Social_network), as often offered by [social network analysis software](https://en.wikipedia.org/wiki/Social_network_analysis_software)[^o28]
- [Hasse diagrams](wikipedia://en/338199), a type of graph drawing specialized to [partial orders](https://en.wikipedia.org/wiki/Partial_order)[^o29]
- [Dessin d'enfants](wikipedia://en/1585922), a type of graph drawing used in [algebraic geometry](wikipedia://en/1997)[^n6]
- [State diagrams](wikipedia://en/187337), graphical representations of [finite-state machines](wikipedia://en/10931)[^n7]
- [Computer network diagrams](https://en.wikipedia.org/wiki/Computer_network_diagram), depictions of the nodes and connections in a [computer network](https://en.wikipedia.org/wiki/Computer_network)[^n8]
- [Flowcharts](https://en.wikipedia.org/wiki/Flowchart) and [drakon-charts](https://en.wikipedia.org/wiki/DRAKON), drawings in which the nodes represent the steps of an [algorithm](wikipedia://en/775) and the edges represent [control flow](wikipedia://en/45459) between steps.
- [Project network](https://en.wikipedia.org/wiki/Project_network), graphical depiction of the chronological order in which activities of a [project](https://en.wikipedia.org/wiki/Project_management) are to be completed.
- [Data-flow diagrams](https://en.wikipedia.org/wiki/Data-flow_diagram), drawings in which the nodes represent the components of an [information system](https://en.wikipedia.org/wiki/Information_system) and the edges represent the movement of information from one component to another.
- [Bioinformatics](wikipedia://en/4214) including [phylogenetic trees](wikipedia://en/149326), [protein–protein interaction](https://en.wikipedia.org/wiki/Protein–protein_interaction) networks, and [metabolic pathways](https://en.wikipedia.org/wiki/Metabolic_pathway).[^n9]

In addition, the [placement](https://en.wikipedia.org/wiki/Placement_%28electronic_design_automation%29) and [routing](https://en.wikipedia.org/wiki/Routing_%28electronic_design_automation%29) steps of [electronic design automation](https://en.wikipedia.org/wiki/Electronic_design_automation) (EDA) are similar in many ways to graph drawing, as is the problem of [greedy embedding](https://en.wikipedia.org/wiki/Greedy_embedding) in [distributed computing](https://en.wikipedia.org/wiki/Distributed_computing), and the graph drawing literature includes several results borrowed from the EDA literature. However, these problems also differ in several important ways: for instance, in EDA, area minimization and signal length are more important than aesthetics, and the routing problem in EDA may have more than two terminals per net while the analogous problem in graph drawing generally only involves pairs of vertices for each edge.

## Graph drawing algorithms {#Graph_drawing_algorithms}

There are many algorithms for graph drawing. Among them are:

- The Reingold-Tilford algorithm for tree drawing.[^n10]
- Kant's algorithm,[^n11] which constructs a polyline drawing of a 3-connected planar graph such that the size of the minimal angle among arcs is at least $\frac{1}{d}\pi$, where *d* is the maximal node degree; and its generaliztion, that also works well for other planar graphs, by Gutwenger and Mutzel.[^n12]
- Tamassia's algorithm for minimizing the number of bends in an orthogonal representation of a planar graph.[^n13]
- The Magnetic Spring Model by Sugiyama and Misue.[^n14]

## Software {#Software}

*Image: Gephi 0.9.1 Network Analysis and Visualization Software.png.* A graph drawing interface ([Gephi](https://en.wikipedia.org/wiki/Gephi) 0.9.1)

Software, systems, and providers of systems for drawing graphs include:

- [BioFabric](https://en.wikipedia.org/wiki/BioFabric) open-source software for visualizing large networks by drawing nodes as horizontal lines.
- [Cytoscape](https://en.wikipedia.org/wiki/Cytoscape), open-source software for visualizing molecular interaction networks
- [Gephi](https://en.wikipedia.org/wiki/Gephi), open-source network analysis and visualization software
- [graph-tool](wikipedia://en/29735189), a [free/libre](https://en.wikipedia.org/wiki/Free_Software) [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) library for analysis of graphs
- [Graphviz](https://en.wikipedia.org/wiki/Graphviz), an open-source graph drawing system from [AT&T Corporation](https://en.wikipedia.org/wiki/AT&T_Corporation)[^o43]
- [Linkurious](https://en.wikipedia.org/wiki/Linkurious), a commercial network analysis and visualization software for [graph databases](https://en.wikipedia.org/wiki/Graph_databases)
- [Mathematica](https://en.wikipedia.org/wiki/Mathematica), a general-purpose computation tool that includes 2D and 3D graph visualization and graph analysis tools.[^o44]
- [Microsoft Automatic Graph Layout](https://en.wikipedia.org/wiki/Microsoft_Automatic_Graph_Layout), open-source .NET library (formerly called GLEE) for laying out graphs[^o45]
- [NetworkX](wikipedia://en/26908549) is a Python library for studying graphs and networks.
- [Tulip](https://en.wikipedia.org/wiki/Tulip_%28software%29),[^o46] an open-source data visualization tool
- [yEd](https://en.wikipedia.org/wiki/YEd), a graph editor with graph layout functionality[^o47]
- [PGF/TikZ](https://en.wikipedia.org/wiki/PGF/TikZ) 3.0 with the `graphdrawing` package (requires [LuaTeX](https://en.wikipedia.org/wiki/LuaTeX)).[^o48]
- [LaNet-vi](https://en.wikipedia.org/wiki/LaNet-vi), an open-source large network visualization software
