# Continuous poset

::: {#o1 .subject cue=lead name="Continuous poset"}

In [order theory](wikipedia://en/361924), a **continuous poset** is a [partially ordered set](wikipedia://en/23572) in which every element is the [directed](wikipedia://en/9165) [supremum](https://en.wikipedia.org/wiki/Supremum) of elements approximating it.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $a,b\in P$ be two elements of a [preordered set](https://en.wikipedia.org/wiki/Preordered_set) $(P,\lesssim)$. Then we say that $a$ **approximates** $b$, or that $a$ is **way-below** $b$, if the following two equivalent conditions are satisfied.

- For any [directed set](wikipedia://en/9165) $D\subseteq P$ such that $b\lesssim\sup D$, there is a $d\in D$ such that $a\lesssim d$.
- For any [ideal](wikipedia://en/530559) $I\subseteq P$ such that $b\lesssim\sup I$, $a\in I$.

If $a$ approximates $b$, we write $a\ll b$. The approximation relation $\ll$ is a [transitive relation](wikipedia://en/200463) that is weaker than the original order, also [antisymmetric](wikipedia://en/1176) if $P$ is a [partially ordered set](wikipedia://en/23572), but not necessarily a [preorder](wikipedia://en/23582). It is a preorder if and only if $(P,\lesssim)$ satisfies the [ascending chain condition](wikipedia://en/3189).[^o4]

For any $a\in P$, let

$$\mathop\Uparrow a=\{b\in L\mid a\ll b\}$$

$$\mathop\Downarrow a=\{b\in L\mid b\ll a\}$$

Then $\mathop\Uparrow a$ is an [upper set](https://en.wikipedia.org/wiki/Upper_set), and $\mathop\Downarrow a$ a [lower set](https://en.wikipedia.org/wiki/Lower_set). If $P$ is an [upper-semilattice](https://en.wikipedia.org/wiki/Upper-semilattice), $\mathop\Downarrow a$ is a [directed set](wikipedia://en/9165) (that is, $b,c\ll a$ implies $b\vee c\ll a$), and therefore an [ideal](wikipedia://en/530559).

A [preordered set](https://en.wikipedia.org/wiki/Preordered_set) $(P,\lesssim)$ is called a **continuous preordered set** if for any $a\in P$, the subset $\mathop\Downarrow a$ is [directed](wikipedia://en/9165) and $a=\sup\mathop\Downarrow a$.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### The interpolation property {#The_interpolation_property}

For any two elements $a,b\in P$ of a continuous preordered set $(P,\lesssim)$, $a\ll b$ if and only if for any [directed set](wikipedia://en/9165) $D\subseteq P$ such that $b\lesssim\sup D$, there is a $d\in D$ such that $a\ll d$. From this follows the interpolation property of the continuous preordered set $(P,\lesssim)$: for any $a,b\in P$ such that $a\ll b$ there is a $c\in P$ such that $a\ll c\ll b$.

### Continuous dcpos {#Continuous_dcpos}

For any two elements $a,b\in P$ of a continuous [dcpo](https://en.wikipedia.org/wiki/Directed-complete_partially_ordered_set) $(P,\le)$, the following two conditions are equivalent.[^o4]

- $a\ll b$ and $a\ne b$.
- For any [directed set](wikipedia://en/9165) $D\subseteq P$ such that $b\le\sup D$, there is a $d\in D$ such that $a\ll d$ and $a\ne d$.

Using this it can be shown that the following stronger interpolation property is true for continuous dcpos. For any $a,b\in P$ such that $a\ll b$ and $a\ne b$, there is a $c\in P$ such that $a\ll c\ll b$ and $a\ne c$.[^o4]

For a [dcpo](https://en.wikipedia.org/wiki/Directed-complete_partially_ordered_set) $(P,\le)$, the following conditions are equivalent.[^o4]

- $P$ is continuous.
- The [supremum](https://en.wikipedia.org/wiki/Supremum) map $\sup \colon \operatorname{Ideal}(P)\to P$ from the [partially ordered set](wikipedia://en/23572) of [ideals](wikipedia://en/530559) of $P$ to $P$ has a [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint).

In this case, the actual left adjoint is

$${\Downarrow} \colon P\to\operatorname{Ideal}(P)$$

$$\mathord\Downarrow\dashv\sup$$

::: {#o10 .pointer-item cue=pointer name="Continuous lattice"}

### Continuous complete lattices {#Continuous_complete_lattices}

For any two elements $a,b\in L$ of a [complete lattice](wikipedia://en/44777) $L$, $a\ll b$ if and only if for any subset $A\subseteq L$ such that $b\le\sup A$, there is a [finite subset](https://en.wikipedia.org/wiki/Finite_subset) $F\subseteq A$ such that $a\le\sup F$.

Let $L$ be a [complete lattice](wikipedia://en/44777). Then the following conditions are equivalent.

- $L$ is continuous.
- The [supremum](https://en.wikipedia.org/wiki/Supremum) map $\sup \colon \operatorname{Ideal}(L)\to L$ from the [complete lattice](wikipedia://en/44777) of [ideals](wikipedia://en/530559) of $L$ to $L$ preserves arbitrary [infima](https://en.wikipedia.org/wiki/Infima).
- For any family $\mathcal D$ of [directed sets](wikipedia://en/9165) of $L$, $\textstyle\inf_{D\in\mathcal D}\sup D=\sup_{f\in\prod\mathcal D}\inf_{D\in\mathcal D}f(D)$.
- $L$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the [image](wikipedia://en/579311) of a [Scott-continuous](https://en.wikipedia.org/wiki/Scott-continuous) [idempotent map](https://en.wikipedia.org/wiki/Idempotent_map) $r \colon \{0,1\}^\kappa\to\{0,1\}^\kappa$ on the [direct power](wikipedia://en/8887) of arbitrarily many two-point lattices $\{0,1\}$.[^o11]

A continuous [complete lattice](wikipedia://en/44777) is often called a **continuous lattice**.

## Examples {#Examples}

### Lattices of open sets {#Lattices_of_open_sets}

For a [topological space](wikipedia://en/30450) $X$, the following conditions are equivalent.

- The [complete Heyting algebra](wikipedia://en/650751) $\operatorname{Open}(X)$ of open sets of $X$ is a continuous [complete Heyting algebra](wikipedia://en/650751).
- The [sobrification](https://en.wikipedia.org/wiki/Sobrification) of $X$ is a [locally compact space](wikipedia://en/48632) (in the sense that every point has a [compact](https://en.wikipedia.org/wiki/Compact_set) [local base](https://en.wikipedia.org/wiki/Local_base))
- $X$ is an [exponentiable object](https://en.wikipedia.org/wiki/Exponentiable_object) in the category $\operatorname{Top}$ of [topological spaces](wikipedia://en/30450).[^o4] That is, the [functor](wikipedia://en/10987) $(-)\times X\colon\operatorname{Top}\to\operatorname{Top}$ has a [right adjoint](https://en.wikipedia.org/wiki/Right_adjoint).
