# Fixed-point iteration

::: {#o1 .subject cue=lead name="Fixed-point iteration"}

In [numerical analysis](wikipedia://en/21506), **fixed-point iteration** is a method of computing [fixed points](wikipedia://en/449738) of a function.

:::

More specifically, given a function $f$ defined on the [real numbers](wikipedia://en/20646438) with real values and given a point $x_0$ in the [domain](wikipedia://en/50263) of $f$, the fixed-point iteration is

$$x_{n+1}=f(x_n), \, n=0, 1, 2, \dots$$

which gives rise to the [sequence](wikipedia://en/27838) $x_0, x_1, x_2, \dots$ of [iterated function](wikipedia://en/1448702) applications $x_0, f(x_0), f(f(x_0)), \dots$ which is hoped to [converge](wikipedia://en/26551602) to a point $x_\text{fix}$. If $f$ is continuous, then one can prove that the obtained $x_\text{fix}$ is a fixed point of $f$, i.e.,

$$f(x_\text{fix})=x_\text{fix} .$$

More generally, the function $f$ can be defined on any [metric space](wikipedia://en/20018) with values in that same space.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

*Image: Sine fixed point.svg.* The fixed-point iteration $x_{n+1} = \sin x_{n}$ with initial value $x_{0} = 2$ converges to 0. This example does not satisfy the assumptions of the [Banach fixed-point theorem](wikipedia://en/46676) and so its speed of convergence is very slow.

- A first simple and useful example is the [Babylonian method](https://en.wikipedia.org/wiki/Babylonian_method) for computing the [square root](wikipedia://en/29208) of $a > 0$, which consists in taking $f(x) = \frac 1 2 \left(\frac a x + x\right)$, i.e. the mean value of $x$ and $a/x$, to approach the limit $x = \sqrt a$ (from whatever starting point $x_0 \gg 0$). This is a special case of [Newton's method](wikipedia://en/22145) quoted below.
- The fixed-point iteration $x_{n+1} = \cos x_n\,$ converges to the unique fixed point of the function $f(x) = \cos x\,$ for any starting point $x_0.$ This example does satisfy (at the latest after the first iteration step) the assumptions of the [Banach fixed-point theorem](wikipedia://en/46676). Hence, the error after n steps satisfies $|x_n-x| \leq { q^n \over 1-q } | x_1 - x_0 | = C q^n$ (where we can take $q = 0.85$, if we start from $x_0=1$.) When the error is less than a multiple of $q^n$ for some constant $q$, we say that we have [linear convergence](https://en.wikipedia.org/wiki/Linear_convergence). The Banach fixed-point theorem allows one to obtain fixed-point iterations with linear convergence.
- The requirement that $f$ is continuous is important, as the following example shows. The iteration $$x_{n+1} = \begin{cases} \frac{x_n}{2}, & x_n \ne 0\\ 1, & x_n=0 \end{cases}$$ converges to 0 for all values of $x_0$. However, 0 is *not* a fixed point of the function $$f(x) = \begin{cases} \frac{x}{2}, & x \ne 0\\ 1, & x = 0 \end{cases}$$ as this function is *not* continuous at $x = 0$, and in fact has no fixed points.

:::

## Attracting fixed points {#Attracting_fixed_points}

*Image: Cosine fixed point.svg.* The [fixed point iteration](https://en.wikipedia.org/wiki/Fixed_point_iteration) $x_{n+1} = \cos x_{n}$ with initial value $x_{1} = -1$.

An *attracting fixed point* of a function $f$ is a [fixed point](wikipedia://en/449738) $x_{\operatorname{fix}}$ of $f$ with a [neighborhood](wikipedia://en/1529485) $U$ of "close enough" points around $x_{\operatorname{fix}}$ such that for any value of $x$ in $U$, the fixed-point iteration sequence

$$x,\ f(x),\ f(f(x)),\ f(f(f(x))), \dots$$

is contained in $U$ and [converges](wikipedia://en/285773) to $x_{\operatorname{fix}}$. The basin of attraction of $x_{\operatorname{fix}}$ is the largest such neighborhood $U$.[^o5]

The natural [cosine](https://en.wikipedia.org/wiki/Cosine) function ("natural" means in [radians](wikipedia://en/26003), not degrees or other units) has exactly one fixed point, and that fixed point is attracting. In this case, "close enough" is not a stringent criterion at all—to demonstrate this, start with *any* real number and repeatedly press the *cos* key on a calculator (checking first that the calculator is in "radians" mode). It eventually converges to the [Dottie number](wikipedia://en/54562671) (about 0.739085133), which is a fixed point. That is where the graph of the cosine function intersects the line $y = x$.[^o6]

Not all fixed points are attracting. For example, 0 is a fixed point of the function $f(x) = 2x$, but iteration of this function for any value other than zero rapidly diverges. We say that the fixed point of $f(x) = 2x$ is repelling.

An attracting fixed point is said to be a *stable fixed point* if it is also [Lyapunov stable](https://en.wikipedia.org/wiki/Lyapunov_stable).

A fixed point is said to be a *neutrally stable fixed point* if it is [Lyapunov stable](https://en.wikipedia.org/wiki/Lyapunov_stable) but not attracting. The center of a [linear homogeneous differential equation](wikipedia://en/379868#Homogeneous_equations_with_constant_coefficients) of the second order is an example of a neutrally stable fixed point.

Multiple attracting points can be collected in an *attracting fixed set*.

::: {#o8 .statement kind=statement/theorem cue=named-heading name="Banach fixed-point theorem"}

### Banach fixed-point theorem {#Banach_fixed-point_theorem}

The [Banach fixed-point theorem](wikipedia://en/46676) gives a sufficient condition for the existence of attracting fixed points. A [contraction mapping](wikipedia://en/6239) function $f$ defined on a [complete metric space](wikipedia://en/7832) has precisely one fixed point, and the fixed-point iteration is attracted towards that fixed point for any initial guess $x_0$ in the domain of the function. Common special cases are that (1) $f$ is defined on the real line with real values and is [Lipschitz continuous](wikipedia://en/51731) with Lipschitz constant $L < 1$, and (2) the function $f$ is continuously differentiable in an open neighbourhood of a fixed point $x_{\operatorname{fix}}$, and $|f'(x_\text{fix})| < 1$.

Although there are other [fixed-point theorems](https://en.wikipedia.org/wiki/Fixed-point_theorems), this one in particular is very useful because not all fixed-points are attractive. When constructing a fixed-point iteration, it is very important to make sure it converges to the fixed point. We can usually use the Banach fixed-point theorem to show that the fixed point is attractive.

:::

### Attractors {#Attractors}

Attracting fixed points are a special case of a wider mathematical concept of [attractors](wikipedia://en/191094). Fixed-point iterations are a discrete [dynamical system](wikipedia://en/9087) on one variable. [Bifurcation theory](wikipedia://en/2326042) studies dynamical systems and classifies various behaviors such as attracting fixed points, [periodic orbits](https://en.wikipedia.org/wiki/Periodic_orbits), or [strange attractors](https://en.wikipedia.org/wiki/Strange_attractor). An example system is the [logistic map](wikipedia://en/18137).

## Iterative methods {#Iterative_methods}

In computational mathematics, an iterative method is a mathematical procedure that uses an initial value to generate a sequence of improving approximate solutions for a class of problems, in which the n-th approximation is derived from the previous ones. Convergent fixed-point iterations are mathematically rigorous formalizations of iterative methods.

### Iterative method examples {#Iterative_method_examples}

[Newton's method](wikipedia://en/22145) is a [root-finding algorithm](wikipedia://en/153299) for finding roots of a given differentiable function $f(x)$. The iteration is $x_{n+1} = x_n-\frac{f(x_n)}{f'(x_n)}.$

If we write $g(x) = x - \frac{f(x)}{f'(x)}$, we may rewrite the Newton iteration as the fixed-point iteration $x_{n+1} = g(x_n)$.

If this iteration converges to a fixed point $x_\text{fix}$ of $g$, then $x_\text{fix} = g(x_\text{fix}) = x_\text{fix} - \frac{f(x_\text{fix})}{f'(x_\text{fix})}$, so $f(x_\text{fix}) / f'(x_\text{fix}) = 0 ,$ therefore $f(x_\text{fix}) = 0$, that is, $x_\text{fix}$ is a *root* of $f$. Under the assumptions of the [Banach fixed-point theorem](wikipedia://en/46676), the Newton iteration, framed as a fixed-point method, demonstrates at least [linear convergence](https://en.wikipedia.org/wiki/Linear_convergence). More detailed analysis shows [quadratic convergence](https://en.wikipedia.org/wiki/Quadratic_convergence), i.e., $|x_n - x_\text{fix}| < C q^{2^n}$, under certain circumstances.

### Convergence acceleration {#Convergence_acceleration}

The speed of convergence of the iteration sequence can be increased by using a [convergence acceleration](https://en.wikipedia.org/wiki/Convergence_acceleration) method such as [Anderson acceleration](wikipedia://en/64345820) and [Aitken's delta-squared process](wikipedia://en/7411694). The application of Aitken's method to fixed-point iteration is known as [Steffensen's method](wikipedia://en/12180274), and it can be shown that Steffensen's method yields a rate of convergence that is at least quadratic.

## Chaos game {#Chaos_game}

*Image: Sierpinski Chaos.gif.* Sierpinski triangle created using IFS, selecting all members at each iteration

The term *chaos game* refers to a method of generating the [fixed point](wikipedia://en/449738) of any [iterated function system](wikipedia://en/505225) (IFS). Starting with any point $x_{0}$, successive iterations are formed as $x_{k+1} = f_{r}(x_{k})$, where $f_{r}$ is a member of the given IFS randomly selected for each iteration. Hence the chaos game is a randomized fixed-point iteration. The chaos game allows plotting the general shape of a [fractal](wikipedia://en/10913) such as the [Sierpinski triangle](https://en.wikipedia.org/wiki/Sierpinski_triangle) by repeating the iterative process a large number of times. More mathematically, the iterations converge to the fixed point of the IFS. Whenever $x_{0}$ belongs to the attractor of the IFS, all iterations $x_{k}$ stay inside the attractor and, with probability 1, form a [dense set](wikipedia://en/23523594) in the latter.
