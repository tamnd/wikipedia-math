# Kendall's notation

::: {#o1 .subject cue=lead name="Kendall's notation"}

*Image: Waiting in line at Ottawa Station.jpg.* Waiting queue at [Ottawa station](https://en.wikipedia.org/wiki/Ottawa_station).

In [queueing theory](wikipedia://en/50578), a discipline within the mathematical [theory of probability](wikipedia://en/23542), **Kendall's notation** (or sometimes **Kendall notation**) is the standard system used to describe and classify a queueing node. [D. G. Kendall](wikipedia://en/4631370) proposed describing queueing models using three factors written A/S/*c* in 1953[^o2] where A denotes the time between arrivals to the queue, S the service time distribution and *c* the number of service channels open at the node. It has since been extended to A/S/*c*/*K*/*N*/D where *K* is the capacity of the queue, *N* is the size of the population of jobs to be served, and D is the [queueing discipline](https://en.wikipedia.org/wiki/Queueing_discipline).[^o3][^o4][^o5]

:::

When the final three parameters are not specified (e.g. [M/M/1 queue](wikipedia://en/14032611)), it is assumed *K* = ∞, *N* = ∞ and D = [FIFO](https://en.wikipedia.org/wiki/FIFO_%28computing_and_electronics%29).[^o6]

## First example: M/M/1 queue {#First_example:_M/M/1_queue}

*Image: Mm1 queue.svg.* An M/M/1 queueing node.

A [M/M/1 queue](wikipedia://en/14032611) means that the time between arrivals is Markovian (M), i.e. the inter-arrival time follows an [exponential distribution](wikipedia://en/45906) of parameter λ. The second M means that the service time is Markovian: it follows an exponential distribution of parameter μ. The last parameter is the number of service channel, which is one (1).

## Description of the parameters {#Description_of_the_parameters}

In this section, we describe the parameters A/S/*c*/*K*/*N*/D from left to right.

### A: The arrival process {#A:_The_arrival_process}

A code describing the arrival process. The codes used are:

::: {#o10 .table cue=table}

| Symbol | Name | Description | Examples |
|---|---|---|---|
| M | [Markovian](https://en.wikipedia.org/wiki/Markov_process) or memoryless[^o11] | [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) (or random) arrival process (i.e., [exponential](wikipedia://en/45906) inter-arrival times). | [M/M/1 queue](wikipedia://en/14032611) |
| M<sup>*X*</sup> | batch Markov | [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) with a random variable *X* for the number of arrivals at one time. | [M<sup>X</sup>/M<sup>Y</sup>/1 queue](https://en.wikipedia.org/wiki/MX/MY/1_queue) |
| MAP | [Markovian arrival process](https://en.wikipedia.org/wiki/Markovian_arrival_processes#Markov_arrival_process) | Generalisation of the Poisson process. |  |
| BMAP | [Batch Markovian arrival process](https://en.wikipedia.org/wiki/Markovian_arrival_processes#Batch_Markov_arrival_process) | Generalisation of the *MAP* with multiple arrivals |  |
| MMPP | [Markov modulated poisson process](https://en.wikipedia.org/wiki/Markovian_arrival_processes#Markov-modulated_Poisson_process) | Poisson process where arrivals are in "clusters". |  |
| D | [Degenerate distribution](wikipedia://en/101843) | A deterministic or fixed inter-arrival time. | [D/M/1 queue](wikipedia://en/38480284) |
| E<sub>*k*</sub> | [Erlang distribution](wikipedia://en/199028) | An Erlang distribution with *k* as the [shape parameter](wikipedia://en/9210865) (i.e., sum of *k* [i.i.d.](wikipedia://en/30876902) [exponential](wikipedia://en/45906) random variables). |  |
| G | General distribution | Although *G* usually refers to independent arrivals, some authors prefer to use *GI* to be explicit. |  |
| PH | [Phase-type distribution](wikipedia://en/3513151) | Some of the above distributions are special cases of the phase-type, often used in place of a general distribution. |  |

:::

### S: The service time distribution {#S:_The_service_time_distribution}

This gives the distribution of time of the service of a customer. Some common notations are:

::: {#o13 .table cue=table}

| Symbol | Name | Description | Examples |
|---|---|---|---|
| M | [Markovian](https://en.wikipedia.org/wiki/Poisson_process) or memoryless[^o11] | [Exponential](wikipedia://en/45906) service time. | [M/M/1 queue](wikipedia://en/14032611) |
| M<sup>*Y*</sup> | bulk Markov | [Exponential](wikipedia://en/45906) service time with a random variable *Y* for the size of the batch of entities serviced at one time. | [M<sup>X</sup>/M<sup>Y</sup>/1 queue](https://en.wikipedia.org/wiki/MX/MY/1_queue) |
| D | [Degenerate distribution](wikipedia://en/101843) | A deterministic or fixed service time. | [M/D/1 queue](wikipedia://en/37844292) |
| E<sub>*k*</sub> | [Erlang distribution](wikipedia://en/199028) | An Erlang distribution with *k* as the [shape parameter](wikipedia://en/9210865) (i.e., sum of *k* [i.i.d.](wikipedia://en/30876902) [exponential](wikipedia://en/45906) random variables). |  |
| G | General distribution | Although *G* usually refers to independent service time, some authors prefer to use *GI* to be explicit. | [M/G/1 queue](wikipedia://en/33378064) |
| PH | [Phase-type distribution](wikipedia://en/3513151) | Some of the above distributions are special cases of the phase-type, often used in place of a general distribution. |  |
| MMPP | [Markov modulated poisson process](https://en.wikipedia.org/wiki/Markovian_arrival_processes#Markov-modulated_Poisson_process) | [Exponential](wikipedia://en/45906) service time distributions, where the rate parameter is controlled by a Markov chain.[^o14] |  |

:::

### *c*: The number of servers {#c:_The_number_of_servers}

The number of service channels (or servers). The [M/M/1 queue](wikipedia://en/14032611) has a single server and the [M/M/c queue](wikipedia://en/23152853) *c* servers.

### K: The number of places in the queue {#K:_The_number_of_places_in_the_queue}

The capacity of queue, or the maximum number of customers allowed in the queue. When the number is at this maximum, further arrivals are turned away. If this number is omitted, the capacity is assumed to be unlimited, or infinite.

Note: This is sometimes denoted *c* + *K* where *K* is the buffer size, the number of places in the queue above the number of servers *c*.

### N: The calling population {#N:_The_calling_population}

The size of calling source. The size of the population from which the customers come. A small population will significantly affect the [effective](https://en.wikipedia.org/wiki/Effective_arrival_rate) [arrival rate](https://en.wikipedia.org/wiki/Arrival_rate), because, as more customers are in system, there are fewer free customers available to arrive into the system. If this number is omitted, the population is assumed to be unlimited, or infinite.

### D: The queue's discipline {#D:_The_queue's_discipline}

The Service Discipline or Priority order that jobs in the queue, or waiting line, are served:

::: {#o19 .table cue=table}

| Symbol | Name | Description |
|---|---|---|
| FIFO/FCFS | First In First Out/First Come First Served | The customers are served in the order they arrived in (used by default). |
| LIFO/LCFS | Last in First Out/Last Come First Served | The customers are served in the reverse order to the order they arrived in. |
| SIRO | Service In Random Order | The customers are served in a random order with no regard to arrival order. |
| PQ | Priority Queuing | There are several options: Preemptive Priority Queuing, Non Preemptive Queuing, Class Based Weighted Fair Queuing, Weighted Fair Queuing. |
| PS | Processor Sharing | The customers are served in the determine order with no regard of arrival order. |

:::

**Note**: An alternative notation practice is to record the queue discipline before the population and system capacity, with or without enclosing parenthesis. This does not normally cause confusion because the notation is different.
