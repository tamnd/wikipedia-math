# Linear matrix inequality

::: {#o1 .subject cue=lead name="Linear matrix inequality"}

In [convex optimization](wikipedia://en/1674411), a **linear matrix inequality** (**LMI**) is an expression of the form

:::

$$\operatorname{LMI}(y):=A_0+y_1A_1+y_2A_2+\cdots+y_m A_m\succeq 0\,$$

where

- $y=[y_i\,,~i\!=\!1,\dots, m]$ is a real vector,
- $A_0, A_1, A_2,\dots,A_m$ are $n\times n$ [symmetric matrices](wikipedia://en/126474) $\mathbb{S}^n$,
- $B\succeq0$ is a generalized inequality meaning $B$ is a [positive semidefinite matrix](https://en.wikipedia.org/wiki/Positive_semidefinite_matrix) belonging to the positive semidefinite cone $\mathbb{S}_+$ in the subspace of symmetric matrices $\mathbb{S}$.

This linear matrix inequality specifies a [convex](wikipedia://en/6292) constraint on $y$.

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

There are efficient numerical methods to determine whether an LMI is feasible (*e.g.*, whether there exists a vector *y* such that LMI(*y*) ≥ 0), or to solve a [convex optimization](wikipedia://en/1674411) problem with LMI constraints. Many optimization problems in [control theory](wikipedia://en/7039), [system identification](wikipedia://en/552466) and [signal processing](wikipedia://en/29324) can be formulated using LMIs. Also LMIs find application in [Polynomial Sum-Of-Squares](wikipedia://en/17001761). The prototypical primal and dual [semidefinite program](wikipedia://en/4993539) is a minimization of a real linear function respectively subject to the primal and [dual](https://en.wikipedia.org/wiki/Dual_cone) [convex cones](wikipedia://en/3558266) governing this LMI.

:::

## Solving LMIs {#Solving_LMIs}

A major breakthrough in convex optimization was the introduction of [interior-point methods](wikipedia://en/1622862). These methods were developed in a series of papers and became of true interest in the context of LMI problems in the work of [Yurii Nesterov](wikipedia://en/42967707) and [Arkadi Nemirovski](https://en.wikipedia.org/wiki/Arkadi_Nemirovski).
