# Final state conjecture

::: {#o1 .subject cue=lead name="Final state conjecture"}

The **final state conjecture** is that the [end state of the universe](https://en.wikipedia.org/wiki/End_state_of_the_universe) will consist of [black holes](wikipedia://en/4650) and [gravitational radiation](https://en.wikipedia.org/wiki/Gravitational_radiation).[^o2][^o3][^o4]

:::

It was originally proposed by [Roger Penrose](wikipedia://en/26193) in the 1980s, and is considered a central problem in mathematical [general relativity](wikipedia://en/12024).[^o5]
