# Strong partition cardinal

::: {#o1 .subject cue=lead name="Strong partition cardinal"}

In [Zermelo–Fraenkel set theory](wikipedia://en/152214) without the [axiom of choice](wikipedia://en/840), a **strong partition cardinal** is an [uncountable](https://en.wikipedia.org/wiki/Uncountable) [well-ordered](https://en.wikipedia.org/wiki/Well-ordered) [cardinal](wikipedia://en/6174) $k$ such that every [partition](https://en.wikipedia.org/wiki/Partition_%28set_theory%29) of the set $[k]^k$of size $k$ subsets of $k$ into less than $k$ pieces has a [homogeneous set](https://en.wikipedia.org/wiki/Homogeneous_%28large_cardinal_property%29) of size $k$.

:::

The existence of strong partition cardinals contradicts the axiom of choice. The [axiom of determinacy](wikipedia://en/1002300) implies that ℵ<sub>1</sub> is a strong partition cardinal.
