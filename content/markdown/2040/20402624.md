# Unitary element

::: {#o1 .subject cue=lead name="Unitary element"}

In [mathematics](wikipedia://en/18831), an [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of a [\*-algebra](wikipedia://en/293426) is called **unitary** if it is [invertible](wikipedia://en/45199) and its inverse element is the same as its adjoint element.[^n1]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{A}$ be a \*-algebra with [unit](wikipedia://en/14962) $e$. An element $a \in \mathcal{A}$ is called unitary if $aa^* = a^*a = e$. In other words, if $a$ is invertible and $a^{-1} = a^*$ holds, then $a$ is unitary.[^n1]

The [set](wikipedia://en/26691) of unitary elements is denoted by $\mathcal{A}_U$ or $U(\mathcal{A})$.

A special case from particular importance is the case where $\mathcal{A}$ is a [complete normed \*-algebra](wikipedia://en/4665#Banach_*-algebras). This algebra satisfies the C\*-identity ($\left\| a^*a \right\| = \left\| a \right\|^2 \ \forall a \in \mathcal{A}$) and is called a [C\*-algebra](wikipedia://en/7184).

:::

## Criteria {#Criteria}

- Let $\mathcal{A}$ be a [unital](wikipedia://en/191788#Unital_algebra) C\*-algebra and $a \in \mathcal{A}_N$ a [normal](wikipedia://en/21454688) element. Then, $a$ is unitary if the [spectrum](wikipedia://en/4665#Spectral_theory) $\sigma(a)$ consists only of elements of the [circle group](wikipedia://en/508177) $\mathbb{T}$, i.e. $\sigma(a) \subseteq \mathbb{T} = \{ \lambda \in \mathbb{C} \mid | \lambda | = 1 \}$.[^n2]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- The unit $e$ is unitary.[^n3]

Let $\mathcal{A}$ be a unital C\*-algebra, then:

- Every [projection](wikipedia://en/3909097), i.e. every element $a \in \mathcal{A}$ with $a = a^* = a^2$, is unitary. For the spectrum of a projection consists of at most $0$ and $1$, as follows from the [continuous functional calculus](wikipedia://en/784808).[^n4]
- If $a \in \mathcal{A}_{N}$ is a normal element of a C\*-algebra $\mathcal{A}$, then for every [continuous function](wikipedia://en/6122) $f$ on the spectrum $\sigma(a)$ the continuous functional calculus defines an unitary element $f(a)$, if $f(\sigma(a)) \subseteq \mathbb{T}$.[^n2]

:::

::: {#o14 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $\mathcal{A}$ be a unital \*-algebra and $a,b \in \mathcal{A}_U$. Then:

- The element $ab$ is unitary, since $((ab)^*)^{-1} = (b^*a^*)^{-1} = (a^*)^{-1} (b^*)^{-1} = ab$. In particular, $\mathcal{A}_U$ forms a [multiplicative group](wikipedia://en/1110742).[^n1]
- The element $a$ is normal.[^n3]
- The adjoint element $a^*$ is also unitary, since $a = (a^*)^*$ holds for the [involution](wikipedia://en/293450) \*.[^n1]
- If $\mathcal{A}$ is a C\*-algebra, $a$ has norm 1, i.e. $\left\| a \right \| = 1$.[^n5]

:::
