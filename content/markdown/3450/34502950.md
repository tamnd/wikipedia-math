# Nonparametric skew

::: {#o1 .subject cue=lead name="Nonparametric skew"}

In [statistics](wikipedia://en/26685) and [probability theory](wikipedia://en/23542), the **nonparametric skew** is a [statistic](wikipedia://en/26703) occasionally used with [random variables](wikipedia://en/25685) that take [real](wikipedia://en/20646438) values.[^o2][^o3] It is a measure of the [skewness](wikipedia://en/28212) of a random variable's [distribution](wikipedia://en/23543)—that is, the distribution's tendency to "lean" to one side or the other of the [mean](https://en.wikipedia.org/wiki/Mean). Its calculation does not require any knowledge of the form of the underlying distribution—hence the name [nonparametric](https://en.wikipedia.org/wiki/Non-parametric_statistics). It has some desirable properties: it is zero for any [symmetric distribution](https://en.wikipedia.org/wiki/Symmetric_distribution); it is unaffected by a [scale](wikipedia://en/769503) shift; and it reveals either left- or right-skewness equally well. In some [statistical samples](https://en.wikipedia.org/wiki/Sample_%28statistics%29) it has been shown to be less [powerful](https://en.wikipedia.org/wiki/Statistical_power)[^o4] than the usual measures of skewness in detecting departures of the [population](https://en.wikipedia.org/wiki/Population_%28statistics%29) from [normality](wikipedia://en/21462).[^o5]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

::: {#o9 .definition cue=heading name="Definition"}

### Definition {#Definition}

The nonparametric skew is defined as

$$S = \frac{ \mu - \nu } { \sigma }$$

where the [mean](https://en.wikipedia.org/wiki/Mean) (*μ*), [median](wikipedia://en/18837) (*ν*) and [standard deviation](wikipedia://en/27590) (*σ*) of the population have their usual meanings.

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

The nonparametric skew is one third of the [Pearson 2 skewness coefficient](wikipedia://en/28212#Pearson's_skewness_coefficients) and lies between −1 and +1 for any distribution.[^o12][^o13] This range is implied by the fact that the mean lies within one standard deviation of any median.[^o14]

Under an [affine transformation](wikipedia://en/38449) of the variable (*X*), the value of *S* does not change except for a possible change in sign. In symbols

$$S( aX + b ) = \operatorname{sign} (a)\, S(X)$$

where *a* ≠ 0 and *b* are constants and *S*( *X* ) is the nonparametric skew of the variable *X*.

:::

:::

## Sharper bounds {#Sharper_bounds}

The bounds of this statistic ( ±1 ) were sharpened by Majindar[^o16] who showed that its [absolute value](wikipedia://en/991) is bounded by

$$\frac{ 2 ( p q )^{ 1 / 2 } } { ( p + q )^{ 1 / 2 } }$$

with

$$p = \Pr( X > \operatorname{ E }( X ) )$$

and

$$q = \Pr( X < \operatorname{ E }( X ) ) ,$$

where *X* is a random variable with finite [variance](wikipedia://en/32344), *E*() is the expectation operator and *Pr*() is the probability of the event occurring.

When *p* = *q* = 0.5 the absolute value of this statistic is bounded by 1. With *p* = 0.1 and *p* = 0.01, the statistic's absolute value is bounded by 0.6 and 0.199 respectively.

::: {#o18 .statement kind=statement/generalization cue=heading name="Extensions"}

## Extensions {#Extensions}

It is also known that[^o19]

$$| \mu - \nu_0 | \le \operatorname{E} ( | X - \nu_0 | ) \le \operatorname{ E } ( | X - \mu | ) \le \sigma ,$$

where *ν*<sub>0</sub> is any median and *E*(.) is the [expectation operator](wikipedia://en/9653).

It has been shown that

$$\frac{ | \mu - x_q | }{ \sigma } \le \max\left( \sqrt{\frac{( 1 - q ) } { q }}, \sqrt{\frac{ q } { ( 1 - q ) } } \right)$$

where *x*<sub>*q*</sub> is the *q*<sup>th</sup> [quantile](wikipedia://en/10167616).[^o14] Quantiles lie between 0 and 1: the median (the 0.5 quantile) has *q* = 0.5. This inequality has also been used to define a measure of skewness.[^o20]

This latter inequality has been sharpened further.[^o21]

$$\mu -\sigma \sqrt{ \frac{ 1-q }{ q } } \le x_q \le \mu + \sigma \sqrt{ \frac{ q }{1- q } }$$

Another extension for a distribution with a finite mean has been published:[^o22]

$$\mu - \frac{ 1 }{ 2q } \operatorname{ E }| X - \mu | \le x_q \le \mu + \frac{ 1 }{ ( 2 - 2q ) } \operatorname{ E }| X - \mu |$$

The bounds in this last pair of inequalities are attained when $\Pr (X=a) = q$ and $\Pr (X=b) = 1-q$ for fixed numbers *a* \< *b*.

### Finite samples {#Finite_samples}

For a finite sample with sample size *n* ≥ 2 with *x*<sub>r</sub> is the *r*<sup>th</sup> [order statistic](wikipedia://en/160986), *m* the sample mean and *s* the [sample standard deviation](https://en.wikipedia.org/wiki/Sample_standard_deviation) corrected for degrees of freedom,[^o24]

$$\frac{ | m - x_r | }{ s } \le \text{max}\left[ \sqrt{ \frac{ ( n - 1 )( r - 1 ) } { n ( n - r + 1 ) } } , \sqrt{ \frac{ ( n - 1 )( n - r ) }{ nr } } \right]$$

Replacing *r* with *n* / 2 gives the result appropriate for the sample median:[^o25]

$$\frac{ | m - a | }{ s } \le \sqrt{ \frac{ n^2 - n }{ n^2 } } = \sqrt{ \frac{ n - 1 }{ n } }$$

where *a* is the sample median.

:::

## Statistical tests {#Statistical_tests}

Hotelling and Solomons considered the distribution of the test statistic[^o12]

$$D = \frac{ n ( m - a ) }{ s }$$

where *n* is the sample size, *m* is the sample mean, *a* is the sample median and *s* is the sample's standard deviation.

Statistical tests of *D* have assumed that the null hypothesis being tested is that the distribution is symmetric .

Gastwirth estimated the asymptotic [variance](wikipedia://en/32344) of *n*<sup>−1/2</sup>*D*.[^o27] If the distribution is unimodal and symmetric about 0, the asymptotic variance lies between 1/4 and 1. Assuming a conservative estimate (putting the variance equal to 1) can lead to a true level of significance well below the nominal level.

Assuming that the underlying distribution is symmetric Cabilio and Masaro have shown that the distribution of *S* is asymptotically normal.[^o28] The asymptotic variance depends on the underlying distribution: for the normal distribution, the asymptotic variance of *S*$\sqrt{n}$ is 0.5708...

Assuming that the underlying distribution is symmetric, by considering the distribution of values above and below the median Zheng and Gastwirth have argued that[^o29]

$$\sqrt{ 2n } \left( \frac{ m - a }{ s } \right)$$

where *n* is the sample size, is distributed as a [t distribution](wikipedia://en/105375).

## Related statistics {#Related_statistics}

[Antonietta Mira](wikipedia://en/70751604) studied the distribution of the difference between the mean and the median.[^o31]

$$\gamma_1 = 2 ( m - a ) ,$$

where *m* is the sample mean and *a* is the median. If the underlying distribution is symmetrical *γ*<sub>1</sub> itself is asymptotically normal. This statistic had been earlier suggested by Bonferroni.[^o32]

Assuming a symmetric underlying distribution, a modification of *S* was studied by Miao, [Gel](wikipedia://en/51060023) and Gastwirth who modified the standard deviation to create their statistic.[^o33]

$$J = \frac{ 1 }{ n } \sqrt { \frac{ \pi }{ 2 } } \sum{ | X_i -a | }$$

where *X*<sub>i</sub> are the sample values, || is the [absolute value](wikipedia://en/991) and the sum is taken over all *n* sample values.

The test statistic was

$$T = \frac{ m - a } { J } .$$

The scaled statistic *T*$\sqrt{n}$ is asymptotically normal with a mean of zero for a symmetric distribution. Its asymptotic variance depends on the underlying distribution: the limiting values are, for the normal distribution var(*T*$\sqrt{n}$) = 0.5708... and, for the [t distribution](wikipedia://en/105375) with three [degrees of freedom](wikipedia://en/176622), var(*T*$\sqrt{n}$) = 0.9689...[^o33]

## Values for individual distributions {#Values_for_individual_distributions}

### Symmetric distributions {#Symmetric_distributions}

For [symmetric probability distributions](wikipedia://en/39284103) the value of the nonparametric skew is 0.

### Asymmetric distributions {#Asymmetric_distributions}

It is positive for right skewed distributions and negative for left skewed distributions. Absolute values ≥ 0.2 indicate marked skewness.

It may be difficult to determine *S* for some distributions. This is usually because a closed form for the median is not known: examples of such distributions include the [gamma distribution](wikipedia://en/207079), [inverse-chi-squared distribution](wikipedia://en/1600924), the [inverse-gamma distribution](wikipedia://en/1653565) and the [scaled inverse chi-squared distribution](wikipedia://en/1653682).

The following values for *S* are known:

- [Beta distribution](wikipedia://en/207074): 1 \< *α* \< *β* where *α* and *β* are the parameters of the distribution, then to a good approximation[^o37]

$$S = \frac{ 1 }{ 3 }\frac{ ( \alpha - 2 \beta ) ( \alpha + \beta + 1 )^{ 1 / 2 } }{ ( \alpha + \beta - 2 / 3 ) ( \alpha \beta )^{ 1 / 2 } }$$

If 1 \< *β* \< *α* then the positions of *α* and *β* are reversed in the formula. *S* is always \< 0.

- [Binomial distribution](wikipedia://en/3876): varies. If the mean is an [integer](wikipedia://en/14563) then *S* = 0. If the mean is not an integer *S* may have either sign or be zero.[^o38] It is bounded by ±min{ max{ *p*, 1 − *p* }, log<sub>e</sub>2 } / *σ* where *σ* is the standard deviation of the binomial distribution.[^o39]
- [Burr distribution](wikipedia://en/12618582):
- [Birnbaum–Saunders distribution](wikipedia://en/15779815):

$$S = \frac{ 2 }{ \beta^2 ( 4 + 5 \alpha^2 ) }$$

where *α* is the shape parameter and *β* is the location parameter.

- [Cantor distribution](wikipedia://en/387941): despite the distribution being symmetric about its mean of $\tfrac12$, the median can be any value in $\left[\tfrac13,\tfrac23\right]$ as this central interval has zero probability

$$\frac{ -4 }{ 3 } \le S \le \frac{ 4 }{ 3 }$$

- [Chi square distribution](https://en.wikipedia.org/wiki/Chi_square_distribution): Although *S* ≥ 0 its value depends on the numbers of [degrees of freedom](wikipedia://en/176622) (*k*).

$$S \approx \frac{ 1 - ( 1 - \frac{ 2 }{ k } )^3 }{ 2 }$$

- [Dagum distribution](wikipedia://en/31102537):
- [Exponential distribution](wikipedia://en/45906):

$$S = 1 - \log_e( 2 ) \approx 0.31$$

- [Exponential distribution](wikipedia://en/45906) with two parameters:[^o40]

$$S = 1 - \log_e( 2 ) \approx 0.31$$

- [Exponential-logarithmic distribution](wikipedia://en/23990722)

$$S = - \frac{ polylog( 2, 1 - p ) + \ln( 1 + \sqrt{ p } ) \ln p }{ \sqrt{ -[2 polylog( 3, 1 - p ) + polylog^2( 2, 1 -p ) ] } }$$

Here *S* is always > 0.

- [Exponentially modified Gaussian distribution](wikipedia://en/34299105):

$$0 \le S \le 1 - \log_e( 2 )$$

- [F distribution](https://en.wikipedia.org/wiki/F_distribution) with *n* and *n* [degrees of freedom](wikipedia://en/176622) ( *n* > 4 ):[^o41]

$$S = n^{ -3 / 2 } \sqrt{ \frac{ n - 4 }{ n - 2 } } + O( n^{ -5 / 2 } )$$

- [Fréchet distribution](wikipedia://en/13808626): The variance of this distribution is defined only for *α* > 2.

$$S = \frac{ \Gamma \left( 1 - \frac{ 1 }{ \alpha } \right) - \frac{ 1 }{ \sqrt{\alpha} \log_e( 2 ) } } \sqrt { \Gamma \left( 1 - \frac{ 2 }{ \alpha } \right ) - \left( \Gamma \left( 1 - \frac{ 1 }{ \alpha } \right ) \right )^2 }$$

- [Gamma distribution](wikipedia://en/207079): The median can only be determined approximately for this distribution.[^o42] If the shape parameter *α* is ≥ 1 then

$$S \approx \frac{ \beta }{ 3 \alpha + 0.2 }$$

where *β* > 0 is the rate parameter. Here *S* is always > 0.

- [Generalized normal distribution](wikipedia://en/21736981) version 2

$$S = - \frac{ \exp( \frac {-k^2 } { 2 } ) - 1 }{ \sqrt{ \exp( \frac{ k^2 }{ 2 } ) - 1 } }$$

*S* is always \< 0.

- [Generalized Pareto distribution](wikipedia://en/8599355): *S* is defined only when the shape parameter ( *k* ) is \< 1/2. *S* is \< 0 for this distribution.

$$S = \left( \frac{ 2^k - 1 }{ k } - 2^k \right)( 1 - 2k )^{ 0.5 }$$

- [Gumbel distribution](wikipedia://en/270827):

$$\frac{ \sqrt{ 6 } [ \gamma + \log_e( \log_e( 2 ) ) ] }{ \pi } \approx 0.1643$$

where *γ* is [Euler's constant](wikipedia://en/148594).[^o43]

- [Half-normal distribution](wikipedia://en/15906455):[^o40]

$$S \approx \frac{ \sqrt{ 2 } - 0.6745 \sqrt{ \pi } }{ \sqrt{ \pi - 2 } } \approx 0.36279$$

- [Kumaraswamy distribution](wikipedia://en/2049583)
- [Log-logistic distribution](wikipedia://en/15657106) (Fisk distribution): Let *β* be the shape parameter. The variance and mean of this distribution are only defined when *β* > 2. To simplify the notation let *b* = *β* / $\pi$.

$$S = \frac{ b - \sin ( b ) }{ \sqrt{ b \tan ( b ) - b^2 } }$$

The standard deviation does not exist for values of *b* > 4.932 (approximately). For values for which the standard deviation is defined, *S* is > 0.

- [Log-normal distribution](wikipedia://en/102476): With mean ( *μ* ) and variance ( *σ*<sup>2</sup> )

$$S = \frac{ 1 }{ ( e^{ \frac{ \sigma^2 }{ 2 } } + 1 ) ( e^{ \mu + \sigma^2 } ) }$$

- [Log-Weibull distribution](https://en.wikipedia.org/wiki/Log-Weibull_distribution):[^o40]

$$S \approx \frac{ [ \log_e( \log_e( 2 ) ) - 0.5772 ] \sqrt{ 6 } }{ \pi } \approx -0.1643$$

- [Lomax distribution](wikipedia://en/32253318): *S* is defined only for *α* > 2

$$S = \frac{ ( \alpha - 1 )( \alpha - 2 )( 1 - ( \alpha - 1 )( 2^{ 1 / \alpha } - 1 ) ) }{ \alpha^{ 1/2 } }$$

- [Maxwell–Boltzmann distribution](wikipedia://en/19830):[^o40]

$$S \approx \frac{ \sqrt{ 2 } - 1.5382 \Gamma( \frac{ 3 }{ 2 } ) }{ \sqrt{ 2 ( \Gamma( \frac{ 5 }{ 2 } ) - \Gamma( \frac{ 3 }{ 2 } ) ) } } \approx 0.0854$$

- [Nakagami distribution](wikipedia://en/9492642)

$$S = -1$$

- [Pareto distribution](wikipedia://en/53057): for *α* > 2 where *α* is the shape parameter of the distribution,

$$S = ( \alpha - 2^{ 1 / \alpha }[ \alpha - 1 ] ) ( \frac{ \alpha - 2 }{ \alpha } )^{ 1 / 2 } ,$$

and *S* is always > 0.

- [Poisson distribution](wikipedia://en/23009144):

$$\frac{ -\log_e(2)} { \lambda^\frac{ 1 }{ 2 } } \le S \le \frac{ 1 }{ 3 \lambda^\frac{ 1 }{ 2 } }$$

where *λ* is the parameter of the distribution.[^o44]

- [Rayleigh distribution](wikipedia://en/262296):

$$S = \sqrt { \frac{ 2 }{ 4 - \pi } } [ ( \frac{ \pi }{ 2 } )^{ 0.5 } - \log_e( 4 ) ] \approx 0.1251$$

- [Weibull distribution](wikipedia://en/206948):

$$S = \frac{ \Gamma( 1 + 1 / k ) - \log_e( 2 )^{ 1 / k } }{ ( \Gamma( 1 + 2 / k ) - \Gamma( 1 + 1 / k ) )^{ 1 / 2 } },$$

where *k* is the shape parameter of the distribution. Here *S* is always > 0.

## History {#History}

In 1895 [Pearson](wikipedia://en/164695) first suggested measuring skewness by standardizing the difference between the mean and the [mode](wikipedia://en/1432127),[^o46] giving

$$\frac{ \mu - \theta } { \sigma } ,$$

where *μ*, *θ* and *σ* is the mean, mode and standard deviation of the distribution respectively. Estimates of the population mode from the sample data may be difficult but the difference between the mean and the mode for many distributions is approximately three times the difference between the mean and the median[^o47] which suggested to Pearson a second skewness coefficient:

$$\frac{ 3 ( \mu - \nu ) } { \sigma } ,$$

where *ν* is the median of the distribution. [Bowley](https://en.wikipedia.org/wiki/Arthur_Lyon_Bowley) dropped the factor 3 from this formula in 1901 leading to the nonparametric skew statistic.

The relationship between the median, the mean and the mode was first noted by Pearson when he was investigating his type III distributions.

## Relationships between the mean, median and mode {#Relationships_between_the_mean,_median_and_mode}

For an arbitrary distribution the mode, median and mean may appear in any order.[^o49][^o50][^o51]

Analyses have been made of some of the relationships between the mean, median, mode and standard deviation.[^o52] and these relationships place some restrictions on the sign and magnitude of the nonparametric skew.

A simple example illustrating these relationships is the [binomial distribution](wikipedia://en/3876) with *n* = 10 and *p* = 0.09.[^o53] This distribution when plotted has a long right tail. The mean (0.9) is to the left of the median (1) but the skew (0.906) as defined by the third standardized moment is positive. In contrast the nonparametric skew is -0.110.

### Pearson's rule {#Pearson's_rule}

The rule that for some distributions the difference between the mean and the mode is three times that between the mean and the median is due to Pearson who discovered it while investigating his Type 3 distributions. It is often applied to slightly asymmetric distributions that resemble a normal distribution but it is not always true.

In 1895 Pearson noted that for what is now known as the [gamma distribution](wikipedia://en/207079) that the relation[^o46]

$$\nu - \theta = 2( \mu - \nu )$$

where *θ*, *ν* and *μ* are the mode, median and mean of the distribution respectively was approximately true for distributions with a large shape parameter.

Doodson in 1917 proved that the median lies between the mode and the mean for moderately skewed distributions with finite fourth moments.[^o55] This relationship holds for all the [Pearson distributions](wikipedia://en/1804023) and all of these distributions have a positive nonparametric skew.

Doodson also noted that for this family of distributions to a good approximation,

$$\theta = 3 \nu - 2 \mu ,$$

where *θ*, *ν* and *μ* are the mode, median and mean of the distribution respectively. Doodson's approximation was further investigated and confirmed by [Haldane](https://en.wikipedia.org/wiki/J._B._S._Haldane).[^o56] Haldane noted that samples with identical and independent variates with a third [cumulant](wikipedia://en/359684) had sample means that obeyed Pearson's relationship for large sample sizes. Haldane required a number of conditions for this relationship to hold including the existence of an [Edgeworth expansion](https://en.wikipedia.org/wiki/Edgeworth_expansion) and the uniqueness of both the median and the mode. Under these conditions he found that mode and the median converged to 1/2 and 1/6 of the third moment respectively. This result was confirmed by Hall under weaker conditions using [characteristic functions](wikipedia://en/3229401).[^o57]

Doodson's relationship was studied by Kendall and Stuart in the [log-normal distribution](wikipedia://en/102476) for which they found an exact relationship close to it.[^o58]

Hall also showed that for a distribution with regularly varying tails and exponent *α* that[^o57]

$$\mu - \theta = \alpha ( \mu - \nu )$$

### Unimodal distributions {#Unimodal_distributions}

Gauss showed in 1823 that for a [unimodal distribution](https://en.wikipedia.org/wiki/Unimodal_distribution)[^o60]

$$\sigma \le \omega \le 2 \sigma$$

and

$$| \nu - \mu | \le \sqrt{ \frac{ 3 }{ 4 } } \omega ,$$

where *ω* is the root mean square deviation from the mode.

For a large class of unimodal distributions that are positively skewed the mode, median and mean fall in that order.[^o61] Conversely for a large class of unimodal distributions that are negatively skewed the mean is less than the median which in turn is less than the mode. In symbols for these positively skewed unimodal distributions

$$\theta \le \nu \le \mu$$

and for these negatively skewed unimodal distributions

$$\mu \le \nu \le \theta$$

This class includes the important F, beta and gamma distributions.

This rule does not hold for the unimodal Weibull distribution.[^o62]

For a unimodal distribution the following bounds are known and are sharp:[^o63]

$$\frac{| \theta - \mu |}{ \sigma } \le \sqrt{ 3 } ,$$

$$\frac{| \nu - \mu |}{ \sigma } \le \sqrt{ 0.6 } ,$$

$$\frac{| \theta - \nu |}{ \sigma } \le \sqrt{ 3 } ,$$

where *μ*,*ν* and *θ* are the mean, median and mode respectively.

The middle bound limits the nonparametric skew of a unimodal distribution to approximately ±0.775.

### van Zwet condition {#van_Zwet_condition}

The following inequality,

$$\theta \le \nu \le \mu ,$$

where *θ*, *ν* and *μ* is the mode, median and mean of the distribution respectively, holds if

$$F( \nu - x ) + F( \nu + x ) \ge 1 \text{ for all } x,$$

where *F* is the [cumulative distribution function](wikipedia://en/5793) of the distribution.[^o65] These conditions have since been generalised[^o51] and extended to discrete distributions.[^o66] Any distribution for which this holds has either a zero or a positive nonparametric skew.

## Notes {#Notes}

### Ordering of skewness {#Ordering_of_skewness}

In 1964 van Zwet proposed a series of axioms for ordering measures of skewness.[^o69] The nonparametric skew does not satisfy these axioms.

### Benford's law {#Benford's_law}

[Benford's law](wikipedia://en/36782) is an empirical law concerning the distribution of digits in a list of numbers. It has been suggested that random variates from distributions with a positive nonparametric skew will obey this law.[^o71]

### Relation to Bowley's coefficient {#Relation_to_Bowley's_coefficient}

This statistic is very similar to [Bowley's coefficient of skewness](wikipedia://en/28212#Quantile-based_measures)[^o73]

$$SK_2 = \frac{ Q_3 + Q_1 - 2 Q_2 }{ Q_3 - Q_1 }$$

where Q<sub>i</sub> is the ith quartile of the distribution.

Hinkley generalised this[^o74]

$$SK = \frac{ F^{-1}( 1 - \alpha ) + F^{-1}( \alpha ) - 2 Q_2 }{ Q_3 - Q_1 }$$

where $\alpha$ lies between 0 and 0.5. Bowley's coefficient is a special case with $\alpha$ equal to 0.25.

Groeneveld and Meeden[^o75] removed the dependence on $\alpha$ by integrating over it.

$$SK_3 = \frac{ \mu - Q_2 }{ E | y - Q_2 | }$$

The denominator is a measure of dispersion. Replacing the denominator with the standard deviation we obtain the nonparametric skew.
