# Second-generation wavelet transform

::: {#o1 .subject cue=lead name="Second-generation wavelet transform"}

In [signal processing](wikipedia://en/29324), the **second-generation wavelet transform (SGWT)** is a [wavelet](wikipedia://en/50903) transform where the [filters](https://en.wikipedia.org/wiki/Filter_%28signal_processing%29) (or even the represented wavelets) are not designed explicitly, but the transform consists of the application of the [Lifting scheme](wikipedia://en/4555411). Actually, the sequence of lifting steps could be converted to a regular [discrete wavelet transform](wikipedia://en/857564), but this is unnecessary because both design and application is made via the lifting scheme. This means that they are not designed in the [frequency domain](wikipedia://en/370346), as they are usually in the *classical* (so to speak *first generation*) transforms such as the [DWT](wikipedia://en/857564) and [CWT](wikipedia://en/679596)). The idea of moving away from the [Fourier](wikipedia://en/11659) domain was introduced independently by [David Donoho](wikipedia://en/26137723) and [Harten](https://en.wikipedia.org/wiki/Harten) in the early 1990s.

:::

## Calculating transform {#Calculating_transform}

The input signal $f$ is split into odd $\gamma _1$ and even $\lambda _1$ samples using shifting and [downsampling](https://en.wikipedia.org/wiki/Downsampling). The detail coefficients $\gamma _2$ are then interpolated using the values of $\gamma _1$ and the *prediction operator* on the even values:

$$\gamma _2 = \gamma _1 - P(\lambda _1 ) \,$$

The next stage (known as the *updating operator*) alters the approximation coefficients using the detailed ones:

$$\lambda _2 = \lambda _1 + U(\gamma _2 ) \,$$

*Image: Second generation wavelet transform.svg.*

The functions prediction operator $P$ and updating operator $U$ effectively define the wavelet used for decomposition. For certain wavelets the lifting steps (interpolating and updating) are repeated several times before the result is produced.

The idea can be expanded (as used in the DWT) to create a [filter bank](https://en.wikipedia.org/wiki/Filter_bank) with a number of levels. The variable tree used in [wavelet packet decomposition](wikipedia://en/2242975) can also be used.

## Advantages {#Advantages}

The SGWT has a number of advantages over the classical wavelet transform in that it is quicker to compute (by a factor of 2) and it can be used to generate a [multiresolution analysis](wikipedia://en/1963076) that does not fit a uniform grid. Using a priori information the grid can be designed to allow the best analysis of the signal to be made. The transform can be modified locally while preserving invertibility; it can even adapt to some extent to the transformed signal.
