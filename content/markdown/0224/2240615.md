# Comparison of SSH clients

::: {#o1 .subject cue=lead name="Comparison of SSH clients"}

An **SSH client** is a software program which uses the [secure shell](https://en.wikipedia.org/wiki/Secure_shell) protocol to connect to a [remote computer](https://en.wikipedia.org/wiki/Server_%28computing%29). This article compares a selection of notable clients.

:::
