# List of wavelet-related transforms

::: {#o1 .subject cue=lead name="List of wavelet-related transforms"}

A list of [wavelet](wikipedia://en/50903) related transforms:

:::

::: {#o2 .entry cue=list-entry name="Continuous wavelet transform"}

- [Continuous wavelet transform](wikipedia://en/679596) (CWT)

:::

::: {#o3 .entry cue=list-entry name="Discrete wavelet transform"}

- [Discrete wavelet transform](wikipedia://en/857564) (DWT)

:::

::: {#o4 .entry cue=list-entry name="Multiresolution analysis"}

- [Multiresolution analysis](wikipedia://en/1963076) (MRA)

:::

::: {#o5 .entry cue=list-entry name="Lifting scheme"}

- [Lifting scheme](wikipedia://en/4555411)

:::

::: {#o6 .entry cue=list-entry name="Binomial QMF"}

- [Binomial QMF](https://en.wikipedia.org/wiki/Binomial_QMF) (BQMF)

:::

::: {#o7 .entry cue=list-entry name="Fast wavelet transform"}

- [Fast wavelet transform](wikipedia://en/1558844) (FWT)

:::

::: {#o8 .entry cue=list-entry name="Complex wavelet transform"}

- [Complex wavelet transform](https://en.wikipedia.org/wiki/Complex_wavelet_transform)

:::

::: {#o9 .entry cue=list-entry name="Undecimated wavelet transform"}

- Non or [undecimated wavelet transform](https://en.wikipedia.org/wiki/Undecimated_wavelet_transform), the downsampling is omitted

:::

::: {#o10 .entry cue=list-entry name="Newland transform"}

- [Newland transform](https://en.wikipedia.org/wiki/Newland_transform), an orthonormal basis of wavelets is formed from appropriately constructed top-hat filters in frequency space

:::

::: {#o11 .entry cue=list-entry name="Wavelet packet decomposition"}

- [Wavelet packet decomposition](wikipedia://en/2242975) (WPD), detail coefficients are decomposed and a variable tree can be formed

:::

::: {#o12 .entry cue=list-entry name="Stationary wavelet transform"}

- [Stationary wavelet transform](https://en.wikipedia.org/wiki/Stationary_wavelet_transform) (SWT), no downsampling and the filters at each level are different

:::

::: {#o13 .entry cue=list-entry name="E-decimated discrete wavelet transform"}

- [e-decimated discrete wavelet transform](https://en.wikipedia.org/wiki/E-decimated_discrete_wavelet_transform), depends on if the even or odd coefficients are selected in the downsampling

:::

::: {#o14 .entry cue=list-entry name="Second generation wavelet transform"}

- [Second generation wavelet transform](https://en.wikipedia.org/wiki/Second_generation_wavelet_transform) (SGWT), filters and wavelets are not created in the frequency domain

:::

::: {#o15 .entry cue=list-entry name="Dual-tree complex wavelet transform"}

- [Dual-tree complex wavelet transform](https://en.wikipedia.org/wiki/Dual-tree_complex_wavelet_transform) (DTCWT), two trees are used for decomposion to produce the real and complex coefficients

:::

::: {#o16 .entry cue=list-entry name="bandelets"}

- [WITS: Where Is The Starlet](http://www.laurent-duval.eu/siva-wits-where-is-the-starlet.html), a collection of a hundredth of wavelet names in -let and associated multiscale, directional, geometric, representations, from activelets to x-lets through [bandelets](https://en.wikipedia.org/wiki/Bandelet_%28computer_science%29), [chirplets](wikipedia://en/1034358), [contourlets](wikipedia://en/15492132), [curvelets](wikipedia://en/16137869), [noiselets](https://en.wikipedia.org/wiki/Noiselet), wedgelets ...

:::
