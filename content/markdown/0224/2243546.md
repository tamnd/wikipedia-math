# Path cover

*Image: Path cover.svg.* Each vertex of the graph belongs to at least one path, including the blue vertex, which is a path of length 0. The set of such paths is a **path cover**. Additionally, because each vertex is in *exactly* one of these paths, it is also a **vertex-disjoint path cover**.

::: {#o1 .subject cue=lead name="Path cover"}

Given a [directed graph](wikipedia://en/19721986) *G* = (*V*, *E*), a **path cover** is a set of [directed paths](https://en.wikipedia.org/wiki/Directed_path) such that every vertex *v* ∈ *V* belongs to at least one path. Note that a path cover may include paths of length 0 (a single vertex).[^o2]

:::

A *path cover* may also refer to a **vertex-disjoint path cover**, i.e., a set of paths such that every vertex *v* ∈ *V* belongs to *exactly* one path.[^o3]

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

A theorem by Gallai and Milgram shows that the number of paths in a smallest path cover cannot be larger than the number of vertices in the largest [independent set](wikipedia://en/524501).[^o6] In particular, for any graph *G*, there is a path cover *P* and an independent set *I* such that *I* contains exactly one vertex from each path in *P*. [Dilworth's theorem](wikipedia://en/749033) follows as a corollary of this result.

:::

## Computational complexity {#Computational_complexity}

Given a directed graph *G*, the **minimum path cover** problem consists of finding a path cover for *G* having the fewest paths.

A minimum path cover consists of one path [if and only if](wikipedia://en/14922) there is a [Hamiltonian path](wikipedia://en/244437) in *G*. The [Hamiltonian path problem](wikipedia://en/149646) is [NP-complete](https://en.wikipedia.org/wiki/NP-complete), and hence the minimum path cover problem is [NP-hard](https://en.wikipedia.org/wiki/NP-hard). However, if the graph is acyclic, the problem is in complexity class [P](wikipedia://en/658550) and can therefore be solved in polynomial time by transforming it into a [matching](wikipedia://en/581797) problem, see https://walkccc.me/CLRS/Chap26/Problems/26-2/.

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

The applications of minimum path covers include software testing.[^o10] For example, if the graph *G* represents all possible execution sequences of a computer program, then a path cover is a set of test runs that covers each program statement at least once. Another application of minimum path covers problem is finding the minimum number of fleets and optimal dispatching of them to serve mobility demand in a city. [^o11]
