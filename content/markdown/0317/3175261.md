# Friedman test

::: {#o1 .subject cue=lead name="Friedman test"}

The **Friedman test** is a [non-parametric](https://en.wikipedia.org/wiki/Non-parametric_statistics) [statistical test](https://en.wikipedia.org/wiki/Statistical_test) developed by [Milton Friedman](https://en.wikipedia.org/wiki/Milton_Friedman).[^o2][^o3][^o4] Similar to the [parametric](wikipedia://en/223366) [repeated measures](https://en.wikipedia.org/wiki/Repeated_measures) [ANOVA](https://en.wikipedia.org/wiki/ANOVA), it is used to detect differences in treatments across multiple test attempts. The procedure involves [ranking](wikipedia://en/1482394) each row (or *block*) together, and then considering the values of ranks by columns. Applicable to [complete block designs](https://en.wikipedia.org/wiki/Complete_block_design), it is thus a special case of the [Durbin test](wikipedia://en/15913557).

:::

Classic examples of use are:

- $n$ wine judges each rate $k$ different wines. Are any of the $k$ wines ranked consistently higher or lower than the others?
- $n$ welders each use $k$ welding torches, and the ensuing welds were rated on quality. Do any of the $k$ torches produce consistently better or worse welds?

The Friedman test is used for one-way repeated measures analysis of variance by ranks. In its use of ranks it is similar to the [Kruskal–Wallis one-way analysis of variance](https://en.wikipedia.org/wiki/Kruskal–Wallis_one-way_analysis_of_variance) by ranks.

The Friedman test is widely supported by many [statistical software packages](wikipedia://en/6824243).

::: {#o6 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

1. Given data $\{x_{ij}\}_{n\times k}$, that is, a [matrix](wikipedia://en/20556859) with $n$ rows (the *blocks*), $k$ columns (the *treatments*) and a single observation at the intersection of each block and treatment, calculate the [ranks](https://en.wikipedia.org/wiki/Rank_statistics) *within* each block. If there are tied values, assign to each tied value the average of the ranks that would have been assigned without ties. Replace the data with a new matrix $\{r_{ij}\}_{n \times k}$ where the entry $r_{ij}$ is the rank of $x_{ij}$ within block $i$.
1. Find the values $\bar{r}_{\cdot j} = \frac{1}{n} \sum_{i=1}^n {r_{ij}}$
1. The test statistic is given by $Q = \frac{12n}{k(k+1)} \sum_{j=1}^k \left(\bar{r}_{\cdot j}-\frac{k+1}{2}\right)^2$. Note that the value of $Q$ does need to be adjusted for tied values in the data.[^o7]
1. Finally, when $n$ or $k$ is large (i.e. $n>15$ or $k> 4$), the [probability distribution](wikipedia://en/23543) of $Q$ can be approximated by that of a [chi-squared distribution](wikipedia://en/113424). In this case the [$p$-value](wikipedia://en/554994) is given by $\mathbf{P}(\chi^2_{k-1} \ge Q)$. If $n$ or $k$ is small, the approximation to chi-square becomes poor and the $p$-value should be obtained from tables of $Q$ specially prepared for the Friedman test. If the $p$-value is [significant](wikipedia://en/160995), appropriate post-hoc [multiple comparisons](https://en.wikipedia.org/wiki/Multiple_comparisons) tests would be performed.

:::

## Related tests {#Related_tests}

- When using this kind of design for a binary response, one instead uses the [Cochran's Q test](wikipedia://en/15918691).
- The [Sign test](wikipedia://en/3319766) (with a two-sided alternative) is equivalent to a Friedman test on two groups.
- [Kendall's W](wikipedia://en/6028339) is a normalization of the Friedman statistic between $0$ and $1$.
- The [Wilcoxon signed-rank test](wikipedia://en/1954987) is a nonparametric test of nonindependent data from only two groups.
- The [Skillings–Mack test](https://en.wikipedia.org/wiki/Skillings–Mack_test) is a general Friedman-type statistic that can be used in almost any block design with an arbitrary missing-data structure.
- The [Wittkowski test](https://en.wikipedia.org/wiki/Wittkowski_test) is a general Friedman-Type statistics similar to Skillings-Mack test. When the data do not contain any missing value, it gives the same result as Friedman test. But if the data contain missing values, it is both, more precise and sensitive than Skillings-Mack test.[^o9]

## Post hoc analysis {#Post_hoc_analysis}

[Post-hoc tests](https://en.wikipedia.org/wiki/Post-hoc_analysis) were proposed by Schaich and Hamerle (1984)[^o11] as well as Conover (1971, 1980)[^o12] in order to decide which groups are significantly different from each other, based upon the mean rank differences of the groups. These procedures are detailed in Bortz, Lienert and Boehnke (2000, p. 275).[^o13] Eisinga, Heskes, Pelzer and Te Grotenhuis (2017)[^o14] provide an exact test for pairwise comparison of Friedman rank sums, implemented in [R](wikipedia://en/376707). The [Eisinga c.s. exact test](https://en.wikipedia.org/wiki/Eisinga_c.s._exact_test) offers a substantial improvement over available approximate tests, especially if the number of groups ($k$) is large and the number of blocks ($n$) is small.

Not all statistical packages support post-hoc analysis for Friedman's test, but user-contributed code exists that provides these facilities (for example in [SPSS](wikipedia://en/179088),[^o15] and in [R](wikipedia://en/376707).[^o16]). The [R](wikipedia://en/376707) package titled PMCMRplus contains numerous non-parametric methods for post-hoc analysis after Friedman,[^o17] including support for the [Nemenyi test](wikipedia://en/32890500).
