# Torsionless module

::: {#o1 .subject cue=lead name="Torsionless module"}

In [abstract algebra](wikipedia://en/19616384), a [module](wikipedia://en/276410) *M* over a [ring](wikipedia://en/48404) *R* is called **torsionless** if it can be embedded into some [direct product](wikipedia://en/8887) *R*<sup>*I*</sup>. Equivalently, *M* is torsionless if each non-zero element of *M* has non-zero image under some *R*-linear functional *f*:

:::

$$f\in M^{\ast}=\operatorname{Hom}_R(M,R),\quad f(m)\ne 0.$$

This notion was introduced by [Hyman Bass](wikipedia://en/7085910).[^o2]

## Properties and examples {#Properties_and_examples}

A module is torsionless if and only if the canonical map into its double [dual](wikipedia://en/44902322),

$$M\to M^{\ast\ast}=\operatorname{Hom}_R(M^{\ast},R), \quad m\mapsto (f\mapsto f(m)), m\in M, f\in M^{\ast},$$

is [injective](https://en.wikipedia.org/wiki/Injective). If this map is bijective then the module is called **reflexive**. For this reason, torsionless modules are also known as **semi-reflexive**.

- A unital [free module](wikipedia://en/326454) is torsionless. More generally, a [direct sum](wikipedia://en/2084687) of torsionless modules is torsionless.
- A free module is reflexive if it is [finitely generated](wikipedia://en/326430), and for some rings there are also infinitely generated free modules that are reflexive. For instance, the direct sum of countably many copies of the integers is a reflexive module over the integers, see for instance.[^o4]
- A submodule of a torsionless module is torsionless. In particular, any [projective module](wikipedia://en/364488) over *R* is torsionless; any left ideal of *R* is a torsionless left module, and similarly for the right ideals.
- Any torsionless module over a [domain](wikipedia://en/487627) is a [torsion-free module](wikipedia://en/38400572), but the converse is not true, as **Q** is a torsion-free **Z**-module that is *not* torsionless.
- If *R* is a [commutative ring](wikipedia://en/61346) that is an [integral domain](wikipedia://en/15462) and *M* is a [finitely generated](wikipedia://en/326430) torsion-free module then *M* can be embedded into *R*<sup>*n*</sup>, and hence *M* is torsionless.
- Suppose that *N* is a right *R*-module, then its dual *N*<sup>∗</sup> has a structure of a left *R*-module. It turns out that any left *R*-module arising in this way is torsionless (similarly, any right *R*-module that is a dual of a left *R*-module is torsionless).
- Over a [Dedekind domain](wikipedia://en/145132), a finitely generated module is reflexive if and only if it is torsion-free.[^o5]
- Let *R* be a [Noetherian ring](wikipedia://en/56129) and *M* a reflexive finitely generated module over *R*. Then $M \otimes_R S$ is a reflexive module over *S* whenever *S* is [flat](wikipedia://en/492616) over *R*.[^o6]

## Relation with semihereditary rings {#Relation_with_semihereditary_rings}

Stephen Chase proved the following characterization of [semihereditary rings](https://en.wikipedia.org/wiki/Semihereditary_ring) in connection with torsionless modules:

For any ring *R*, the following conditions are equivalent:[^o8]

- *R* is left semihereditary.
- All torsionless right *R*-modules are [flat](wikipedia://en/492616).
- The ring *R* is left [coherent](wikipedia://en/14777654) and satisfies any of the four conditions that are known to be equivalent:
  - All right ideals of *R* are flat.
  - All left ideals of *R* are flat.
  - Submodules of all right flat *R*-modules are flat.
  - Submodules of all left flat *R*-modules are flat.

(The mixture of left/right adjectives in the statement is *not* a mistake.)
