# Lévy–Steinitz theorem

::: {#o1 .subject cue=lead name="Lévy–Steinitz theorem"}

In mathematics, the **Lévy–Steinitz theorem** identifies the set of values to which sums of rearrangements of an [infinite series](wikipedia://en/15287) of vectors in **R**<sup>*n*</sup> can converge. It was proved by [Paul Lévy](wikipedia://en/556462) in his first published paper when he was 19 years old.[^o2] In 1913 [Ernst Steinitz](wikipedia://en/3966685) filled in a gap in Lévy's proof and also proved the result by a different method.[^o3]

:::

In an expository article, [Peter Rosenthal](wikipedia://en/43370076) stated the theorem in the following way.[^o4]

The set of all sums of rearrangements of a given series of vectors in a finite-dimensional real Euclidean space is either the empty set or a translate of a linear subspace (i.e., a set of the form *v* + *M*, where *v* is a given vector and *M* is a linear subspace).
