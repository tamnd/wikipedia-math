# Locally finite poset

::: {#o1 .subject cue=lead name="Locally finite poset"}

In mathematics, a **locally finite poset** is a [partially ordered set](wikipedia://en/23572) *P* such that for all *x*, *y* ∈ *P*, the [interval](https://en.wikipedia.org/wiki/Poset#Intervals) \[*x*, *y*\] consists of [finitely](wikipedia://en/11742) many elements.

:::

Given a locally finite poset *P* we can define its *[incidence algebra](wikipedia://en/166980)*. Elements of the incidence algebra are functions *ƒ* that assign to each interval \[*x*, *y*\] of *P* a real number *ƒ*(*x*, *y*). These functions form an [associative algebra](wikipedia://en/2112) with a product defined by

$$(f * g)(x,y):=\sum_{x \leq z \leq y} f(x,z) g(z,y).$$

There is also a definition of *[incidence coalgebra](https://en.wikipedia.org/wiki/Incidence_coalgebra)*.

In [theoretical physics](wikipedia://en/19594028) a locally finite poset is also called a [causal set](https://en.wikipedia.org/wiki/Causal_set) and has been used as a model for [spacetime](wikipedia://en/28758).
