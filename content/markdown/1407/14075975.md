# Fuzzy mathematics

::: {#o1 .subject cue=lead name="Fuzzy mathematics"}

**Fuzzy mathematics** is a branch of [mathematics](wikipedia://en/18831) that extends classical set theory and logic to model reasoning under uncertainty. Initiated by [Lotfi Asker Zadeh](https://en.wikipedia.org/wiki/Lotfi_Asker_Zadeh) in 1965 with the introduction of fuzzy sets,[^o2] the field has since evolved to include [fuzzy set](wikipedia://en/56601) theory, [fuzzy logic](wikipedia://en/49180), and various fuzzy analogues of [traditional mathematic](https://en.wikipedia.org/wiki/Traditional_mathematics) structures.

:::

Unlike classical mathematics, which usually relies on [binary](wikipedia://en/238686) membership (an element either belongs to a set or it does not), fuzzy mathematics allows elements to partially belong to a set, with degrees of membership represented by values in the interval \[0, 1\]. This framework enables more flexible modeling of imprecise or vague concepts.

Fuzzy mathematics has found applications in numerous domains, including [control theory](wikipedia://en/7039), [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence), [decision theory](wikipedia://en/446216), [pattern recognition](wikipedia://en/126706), and [linguistics](https://en.wikipedia.org/wiki/Linguistics), where the modeling of gradations and uncertainty is essential.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **fuzzy subset** *A* of a [set](wikipedia://en/26691) *X* is defined by a [function](wikipedia://en/185427) *A*: *X* → *L*, where *L* is typically the [interval](wikipedia://en/49172) \[0, 1\]. This function is called the **membership function** of the fuzzy subset and assigns to each element *x* in *X* a degree of membership *A*(*x*) in the fuzzy set *A*.

In classical set theory, a subset of *X* can be represented by an [indicator function](wikipedia://en/240790) (also known as a [characteristic function](wikipedia://en/240790)), which maps elements to either 0 or 1, indicating non-membership or full membership, respectively. Fuzzy subsets generalize this concept by allowing any real value between 0 and 1, thereby enabling partial membership.

More generally, the codomain *L* of the membership function can be replaced with any [complete lattice](wikipedia://en/44777), resulting in the broader framework of **L-fuzzy sets**.[^o5]

:::

## Fuzzification {#Fuzzification}

The development of fuzzification in mathematics can be broadly divided into three historical stages:[^o7]

1. Initial, straightforward fuzzifications (1960s–1970s),
1. Expansion of generalization techniques (1980s),
1. Standardization, axiomatization, and *L*-fuzzification (1990s).

Fuzzification generally involves extending classical mathematical concepts from binary (crisp) logic, where membership is determined by characteristic functions, to fuzzy logic, where membership is expressed by values in the interval \[0, 1\] via membership functions.

Let *A* and *B* be fuzzy subsets of a set *X*. The fuzzy versions of set-theoretic operations are commonly defined as:

$$(A \cap B)(x) = \min(A(x), B(x))$$

$$(A \cup B)(x) = \max(A(x), B(x))$$

for all $x \in X$. These operations can be generalized using [t-norms](wikipedia://en/2099179) and [t-conorms](https://en.wikipedia.org/wiki/T-conorm), respectively.[^o8] For example, the minimum operation can be replaced by multiplication:

$$(A \cap B)(x) = A(x) \cdot B(x)$$

Fuzzification of algebraic structures often relies on generalizing the [closure property](https://en.wikipedia.org/wiki/Closure_property). Let $*$ be a binary operation on *X*, and let *A* be a fuzzy subset of *X*. Then *A* is said to satisfy fuzzy closure if:

$$A(x * y) \geq \min(A(x), A(y))$$

for all $x, y \in X$.

If $(G, *)$ is a [group](wikipedia://en/19447), then a fuzzy subset *A* of *G* is a **fuzzy subgroup** if:

$$A(x * y^{-1}) \geq \min(A(x), A(y^{-1}))$$

for all $x, y \in G$.

Similar generalizations apply to relational properties. For example, for example, for fuzzification of the [transitivity](wikipedia://en/200463) property, a fuzzy relation $R$ on $X$ (i.e., a fuzzy subset of $X \times X$) is said to be **fuzzy transitive** if:

$$R(x, z) \geq \min(R(x, y), R(y, z))$$

for all $x, y, z \in X$.

## Fuzzy analogues {#Fuzzy_analogues}

Fuzzy subgroupoids and fuzzy subgroups were introduced in 1971 by A. Rosenfeld.[^o10][^o11][^o12]

Analogues of other mathematical subjects have been translated to fuzzy mathematics, such as fuzzy field theory and fuzzy [Galois theory](wikipedia://en/61316),[^o13] fuzzy topology,[^o14][^o15] fuzzy geometry,[^o16][^o17][^o18][^o19] fuzzy orderings,[^o20] and fuzzy graphs.[^o21][^o22][^o23]
