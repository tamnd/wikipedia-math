# Indexed category

::: {#o1 .subject cue=lead name="Indexed category"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a *C*-**indexed category** is a [pseudofunctor](https://en.wikipedia.org/wiki/Pseudofunctor) from *C*<sup>*op*</sup> to **Cat**, where **Cat** is a [2-category](https://en.wikipedia.org/wiki/Strict_2-category) of categories. Any indexed category has an associated [Grothendieck construction](https://en.wikipedia.org/wiki/Grothendieck_construction), which gives rise to a [fibred category](wikipedia://en/2086749).

:::
