# Dense-in-itself

::: {#o1 .subject cue=lead name="Dense-in-itself"}

In [general topology](wikipedia://en/178649), a subset $A$ of a [topological space](wikipedia://en/30450) is said to be **dense-in-itself**[^o2][^o3] or **crowded**[^o4][^o5] if $A$ has no [isolated point](wikipedia://en/390557) of $A$. Equivalently, $A$ is dense-in-itself if every point of $A$ is a [limit point](https://en.wikipedia.org/wiki/Limit_point) of $A$. Thus $A$ is dense-in-itself if and only if $A\subseteq A'$, where $A'$ is the [derived set](wikipedia://en/1567335) of $A$.

:::

A dense-in-itself [closed set](wikipedia://en/47279) is called a [perfect set](wikipedia://en/5075551). (In other words, a perfect set is a closed set without isolated point.)

The property of being dense-in-itself depends only on the [subspace topology](wikipedia://en/910926) of $A$, namely, $A$ is a dense-in-itself subset of $X$ if and only if $A$ is a dense-in-itself subset of $A$. Some authors would say that $A$ is a perfect space in its subspace topology (note that the phrase *perfect space* is ambiguous).

The notion of [dense set](wikipedia://en/23523594) is distinct from *dense-in-itself*. This can sometimes be confusing, as "$X$ is dense in $X$" (always true) is not the same as "$X$ is dense-in-itself" (contains no isolated points).

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

A simple example of a set that is dense-in-itself but not closed (and hence not a perfect set) is the set of [irrational numbers](https://en.wikipedia.org/wiki/Irrational_numbers) (considered as a subset of the [real numbers](https://en.wikipedia.org/wiki/Real_numbers)). This set is dense-in-itself because every [neighborhood](wikipedia://en/1529485) of an irrational number $x$ contains at least one other irrational number $y \neq x$. On the other hand, the set of irrationals is not closed because every [rational number](wikipedia://en/19727024) lies in its [closure](wikipedia://en/42309). Similarly, the set of rational numbers is also dense-in-itself but not closed in the space of real numbers.

The above examples, the irrationals and the rationals, are also [dense sets](wikipedia://en/23523594) in their topological space, namely $\mathbb{R}$. As an example that is dense-in-itself but not dense in its topological space, consider $\mathbb{Q} \cap [0,1]$. This set is not dense in $\mathbb{R}$ but is dense-in-itself.

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

A [singleton](wikipedia://en/381798) is never dense-in-itself.

The dense-in-itself subsets of any space are closed under arbitrary [unions](https://en.wikipedia.org/wiki/Union_of_sets).[^o10] In a dense-in-itself space, they include all [open sets](wikipedia://en/39358).[^o11] In a dense-in-itself [T<sub>1</sub> space](wikipedia://en/148721) they include all [dense sets](wikipedia://en/23523594).[^o12] However, spaces that are not T<sub>1</sub> may have dense subsets that are not dense-in-itself: for example in the dense-in-itself space $X=\{a,b\}$ with the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology), the set $A=\{a\}$ is dense, but is not dense-in-itself.

The closure of any dense-in-itself set is a [perfect set](wikipedia://en/5075551).[^o13]

In general, the [intersection](wikipedia://en/41780044) of two dense-in-itself sets is not dense-in-itself. But the intersection of a dense-in-itself set and an open set is dense-in-itself.
