# Bernoulli's method

*Image: Excerpt from Observationes de Seriebvs.png.* Excerpt from Observations Concerning Series by [Daniel Bernoulli](wikipedia://en/46784) published in 1729.[^o1]

::: {#o2 .subject cue=lead name="Bernoulli's method"}

In [numerical analysis](wikipedia://en/21506), **Bernoulli's method**, named after [Daniel Bernoulli](wikipedia://en/46784), is a [root-finding algorithm](wikipedia://en/153299) which calculates the [root](wikipedia://en/23000) of largest [absolute value](wikipedia://en/991) of a [univariate polynomial](https://en.wikipedia.org/wiki/Univariate_polynomial).[^o3][^o4] The method works under the condition that there is only one root (possibly multiple) of maximal absolute value. The method computes the root of maximal absolute value as the [limit](wikipedia://en/26551602) of the [quotients](wikipedia://en/332640) of two successive terms of a [sequence](wikipedia://en/27838) defined by a [linear recurrence](https://en.wikipedia.org/wiki/Linear_recurrence) whose coefficients are those of the polynomial.

:::

Since the method converges with a [linear order](wikipedia://en/999701) only, it is less efficient than other methods, such as [Newton's method](wikipedia://en/22145). However, it can be useful for finding an initial guess ensuring that these other methods converge to the root of maximal absolute value.[^o5] Bernoulli's method holds [historical significance](https://en.wikipedia.org/wiki/Historical_significance) as an early approach to numerical root-finding and provides an elegant connection between [recurrence relations](wikipedia://en/146806) and polynomial roots.

## History {#History}

*Image: Lagrange on Bernoulli's method.png.* [Lagrange](wikipedia://en/87793) on Bernoulli's method.[^o7]

Bernoulli's method was first introduced by [Swiss](https://en.wikipedia.org/wiki/Switzerland)-[French](https://en.wikipedia.org/wiki/France) [mathematician](wikipedia://en/18902) and [physicist](https://en.wikipedia.org/wiki/Physicist) [Daniel Bernoulli](wikipedia://en/46784) (1700-1782) in 1728.[^o1][^o8] He noticed a trend from recurrent series created using polynomial coefficients growing by a ratio related to a root of the polynomial but did not prove why it worked.[^o8] In 1725, Bernoulli moved to [Saint Petersburg](https://en.wikipedia.org/wiki/Saint_Petersburg) with his brother [Nicolaus II Bernoulli](wikipedia://en/1150998), who unfortunately died of fever in 1726.[^o9] While there, he worked closely with [Leonhard Euler](wikipedia://en/17902), a student of [Johann Bernoulli](wikipedia://en/268886), and made many advancements in [harmonics](https://en.wikipedia.org/wiki/Harmonics), [mathematical economics](wikipedia://en/18967255) (see [St. Petersburg paradox](wikipedia://en/466277)), and [hydrodynamics](https://en.wikipedia.org/wiki/Hydrodynamics).[^o9] Euler called Bernoulli's method "frequently very useful" and gave a justification for why it works in 1748.[^o10][^o4] The mathematician [Joseph-Louis Lagrange](wikipedia://en/87793) expanded on this for the case of multiple roots in 1798.[^o7][^o4] Bernoulli's method predates other root-finding algorithms like [Graeffe's method](wikipedia://en/6134192) (1826 to Dandelin)[^o11][^o12] and is contemporary to [Halley's method](wikipedia://en/9053035) (1694).[^o13][^o14] Since then, it has influenced the development of more modern algorithms such as the QD method.[^o15][^o16]

::: {#o18 .definition kind=definition/construction cue=heading name="The method"}

## The method {#The_method}

Given a polynomial

$$p = a_{0}z^d + a_{1}z^{d-1} + \dots + a_d$$

of degree $d$ with [complex coefficients](wikipedia://en/5826). Choose $d$ starting values $x_{-d+1}, x_{-d}, \dots, x_{-1}, x_0,$ that are usually $0, 0, 0, \dots, 0, 1$.[^o19] Then, consider the sequence defined by the [recurrence relation](wikipedia://en/146806)[^o3]

$$x_n = -\frac{a_1 x_{n-1} + a_2 x_{n-2} + \dots + a_d x_{n-d}}{a_0} .$$

Let $q_n = \frac{x_{n+1}}{x_n}$ be the ratio of successive terms of the sequence. If there is only one complex root of maximal absolute value, then the sequence of the $q_n$ has a limit that is this root.[^o20]

If the coefficients of the polynomial are real then, via the [complex conjugate root theorem](wikipedia://en/9178245), each of the polynomial's roots must be either a [real number](wikipedia://en/20646438) or part of a [complex conjugate](wikipedia://en/173918) pair. Therefore, if the polynomial contains a single dominant complex root, then the coefficients must include a [complex number](wikipedia://en/5826), and so the sequence generated using the coefficients will contain complex numbers. Bernoulli's method will work to find a single dominant root, regardless of whether it is real or complex.[^o3] If a root is part of a [complex conjugate](wikipedia://en/173918) pair, then each root in the pair has the same maximal absolute value, and a modified form of Bernoulli's method is needed to calculate them.[^o4]

:::

## Derivation of the method {#Derivation_of_the_method}

The solutions of the $n-$th order [difference equation](https://en.wikipedia.org/wiki/Difference_equation)

$$a_n x_m + a_{n-1} x_{m-1} + \dots + a_0 x_{m-n} = 0$$

have the form

$$x_m = c_1(m)r_1^m + c_2(m) r_2^m + \dots + c_k(m) r_k^m ,$$

where the $r_i$ are the distinct complex roots of $p(z)$, and $c_i(m)$ is polynomial in $m$ of degree less than the multiplicity of $r_i$. For simple roots, $c_i$ is a constant. The coefficients $c_i$ can be determined from the first $n$ terms of the sequence $x_m$ by solving a linear system of equations. This system has always a unique solution since its matrix is a [Vandermonde matrix](wikipedia://en/348641) if the roots are simple, or a [confluent Vandermonde matrix](wikipedia://en/348641#Confluent_Vandermonde_matrices) otherwise.[^o22]

The quotient of two successive terms of the sequence is

$$\frac{x_{m+1}}{x_m} = \frac{c_1(m+1) r_1^{m+1} + c_2(m+1) r_2^{m+1} + \dots + c_k(m+1) r_k^{m+1}} {c_1(m) r_1^m + c_2(m) r_2^m + \dots + c_k(m) r_k^m}.$$

Factoring out $r_1$ gives

$$\frac{x_{m+1}}{x_m} = r_1 \cdot \frac{c_1(m+1) + c_2(m+1) \left( \frac{r_2}{r_1} \right)^{m+1} + \dots + c_k(m+1) \left( \frac{r_k}{r_1} \right)^{m+1}} {c_1(m) + c_2(m) \left( \frac{r_2}{r_1} \right)^m + \dots + c_k(m) \left( \frac{r_k}{r_1} \right)^m} .$$

Assuming $r_1$ is the dominant root, such that $|r_1| > |r_i|$ for $i>1$, each ratio $\frac{r_i}{r_1}$ has an absolute value less than 1. Thus as $m$ increases, $\left( \frac{r_i}{r_1} \right)^m$ approaches zero, so $\lim_{m \to \infty} c_i(m)\left( \frac{r_i}{r_1} \right)^m = 0,$ even for non-constant $c_i(m)$. Hence the limit of the fraction is the same as that of $\frac{c_1(m+1)}{c_1(m)},$ which is 1 if $c_i$ is a constant or a nonzero polynomial in $m$.

Hence

$$\lim_{m \to \infty} \frac{x_{m+1}}{x_m} = r_1$$

in all cases where there is only one root of maximal absolute value.[^o23]

This assumes $c_1 \neq 0,$ which is satisfied by using initial values of all zeros followed by a final 1.[^o19] Indeed, [Cramer's rule](wikipedia://en/166008) implies that $c_1$ is a signed quotient of two nonsingular Vandermonde matrices, if all roots are simple; in the case of multiple roots, the dominant coefficient of $c_1(m)$ is a signed quotient of two nonsingular confluent matrices.

::: {#o25 .statement kind=statement/generalization cue=heading name="Extensions"}

## Extensions {#Extensions}

*Image: Aitken-excerpt.png.* Excerpt by [Aitken](wikipedia://en/3348690) on his extension of Bernoulli's method.[^o27]

Bernoulli's method converges to the root of largest modulus of a polynomial with a linear [order of convergence](https://en.wikipedia.org/wiki/Order_of_convergence).[^o4] It does not converge when there are two distinct complex roots of the same largest modulus, but there are extensions of the method that work in this case.[^o3] For finding the root of smallest absolute value, one can apply the method on the [reciprocal polynomial](wikipedia://en/1106042) (polynomial obtained by reversing the order of the coefficients), and inverting the result. When using [root deflation](wikipedia://en/766014) with something like [Horner's method](wikipedia://en/14263), deflating from the smallest root is more [stable](wikipedia://en/233807).[^o26]

To speed convergence, [Alexander Aitken](wikipedia://en/3348690) developed his [Aitken delta-squared process](https://en.wikipedia.org/wiki/Aitken_delta-squared_process) as part of an improvement on his extension to Bernoulli's method, which also found all of the roots simultaneously.[^o27][^o28] Another extension of Bernoulli's method is the Quotient-Difference (QD) method, which also finds all roots simultaneously, even though it can be unstable.[^o4] Given the slow convergence of Bernoulli's method, and the instability of QD method, they can instead be used as reliable ways to find starting values for other root-finding algorithms, rather than iterated until tolerance.[^o29]

:::

## Example {#Example}

*Image: X^2-x-1.svg.* Plot of the example polynomial on a [Cartesian plane](wikipedia://en/7706) showing the dominant root at $\left(\frac{1+\sqrt{5}}{2}, 0\right)$.

*Image: Bernoulli Method Convergence Example.svg.* Bernoulli's method convergence on the root of $p(z)=z^2-z-1$.

The following example illustrates Bernoulli's method applied to a quadratic polynomial. Let $p(z) = z^2 - z - 1 = 0$. Then $a_0 = 1$, $a_1 = -1$, and $a_2 = -1$, so the recurrence becomes:

$$\begin{aligned} x_n &= -\frac{(-1)x_{n-1} + (-1)x_{n-2}}{1}\\ &= x_{n-1} + x_{n-2} \end{aligned}$$

Using the recommended initial values $x_{-1} = 0$, $x_0 = 1$ generates the following table:

::: {#o32 .table cue=table}

| $n$ | $x_{n}$ | $q_{n}$ | $\|q_{n} - \varphi\|$ | $\operatorname{order}$ |
|---|---|---|---|---|
| \-1 | 0 | − | − | − |
| 0 | 1 | 1 | \0.618033989 | − |
| 1 | 1 | 2 | \0.381966011 | \2.44042009 |
| 2 | 2 | \1.5 | \0.118033989 | \0.766784227 |
| 3 | 3 | \1.666 | \0.047966011 | \1.086347793 |
| 4 | 5 | \1.6 | \0.018033989 | \0.972379866 |
| 5 | 8 | \1.625 | \0.006966011 | \1.016299341 |
| 6 | 13 | \1.61538461538 | \0.002649373 | \0.993860956 |
| 7 | 21 | \1.61904761905 | \0.00101363 | \1.002357448 |
| 8 | 34 | \1.61764705882 | \0.00038693 | \0.999101399 |
| 9 | 55 | \1.61818181818 | \0.000147829 | \1.000343479 |

:::

This eventually converges on $\frac{1+\sqrt{5}}{2} \approx 1.618034$, also known as the [Golden ratio](wikipedia://en/12386), which is the largest root of the example polynomial. The sequence ${x_n}$ is also the well-known [Fibonacci sequence](wikipedia://en/10918). Bernoulli's method works even if the sequence used different starting values instead of 0 and 1; the limit of the quotient $q_n$ remains the same.

The example also shows the [absolute error](wikipedia://en/640422) approaching zero as the sequence continues. It is then possible to calculate the [order of convergence](wikipedia://en/999701) using three contiguous errors. This example demonstrates that Bernoulli's method converged linearly as it approaches the dominant root of the polynomial.

:::

## Comparison with other methods {#Comparison_with_other_methods}

Compared to other root-finding algorithms, Bernoulli's method offers distinct advantages and limitations. The following table summarizes several important differences of Bernoulli's method in comparison with other methods:

::: {#o34 .table cue=table}

| Method | Convergence Order | Initial Guess | Multiple Roots | Uses Derivatives |
|---|---|---|---|---|
| Bernoulli's method | Linear (1st) | No | No (largest) | No |
| [Secant method](wikipedia://en/640746) | Superlinear (1.618) | Yes (2 points) | No | No |
| [Bairstow's method](https://en.wikipedia.org/wiki/Bairstow's_method) | Quadratic (2nd) | Yes (quadratic) | Yes (pairs) | No |
| [Durand–Kerner method](wikipedia://en/3675893) | Quadratic (2nd) | Yes ($d$ points) | Yes ($d$ roots) | No |
| [Newton's method](wikipedia://en/22145) | Quadratic (2nd) | Yes (1 point) | No | Yes (1st) |
| [Halley's method](wikipedia://en/9053035) | Cubic (3rd) | Yes (1 point) | No | Yes (1st & 2nd) |

:::

### Advantages {#Advantages}

- No initial guess: [Newton's method](wikipedia://en/22145), [Secant method](wikipedia://en/640746), [Halley's method](wikipedia://en/9053035), and other similar approaches, all require one or more starting values.[^o41] Bernoulli's method requires only the polynomial coefficients, eliminating the need for an initial guess.
- No derivatives: Although derivatives of polynomials are straightforward with the [power rule](wikipedia://en/147912), this is a computation that is not required in Bernoulli's method.
- Naturally finds a dominant root: Normally, finding large roots is considered less stable, but substituting $z$ in $p$ with $\left(\frac{1}{z}\right)$, which reverses the order of coefficients, and then inverting the result of Bernoulli's method gives the smallest root of $p$, which is more stable.[^o10][^o26]

### Limitations {#Limitations}

- Slow convergence: Fröberg writes "As a rule, Bernoulli's method converges slowly, so instead, one ought to use, for example, the Newton-Raphson method."[^o43] This is in contrast to Jennings, who writes "The approximate zeros obtained by the Bernoulli method can be further improved by applying, say, the Newton-Raphson method".[^o5] One author argues for instead-of while the other promotes in-conjunction-with, due to the linear order of convergence. The slow convergence can be improved with [Aitken's delta-squared process](wikipedia://en/7411694).[^o27]
- Finds one root at a time: The standard version of Bernoulli's method finds a single root, requiring deflation to find another. When compared to algorithms such as [Durand–Kerner method](wikipedia://en/3675893), [Aberth method](wikipedia://en/7378088), [Bairstow's method](https://en.wikipedia.org/wiki/Bairstow's_method), and the "RPOLY" version of [Jenkins–Traub algorithm](wikipedia://en/12106314) they find multiple roots by default. One can overcome this limitation by applying an extension of Bernoulli's method such as the method by Aitken or QD method.[^o44]
- Issues with multiples: Multiplicity and multiple dominant roots, such as conjugate pairs, can exacerbate the slowness of Bernoulli's method, yet improvements can be made to counter this.[^o45][^o46]

## Modern applications {#Modern_applications}

*Image: EDSAC\_(19).jpg.* The Electronic Delay Storage Automatic Calculator ([EDSAC](https://en.wikipedia.org/wiki/EDSAC)) at the University of Cambridge Mathematical Laboratory in England, 1948

Bernoulli's method, despite its linear convergence, remains relevant in computational mathematics with finding initial values for [Polynomial root-finding](wikipedia://en/72719782) algorithms and extensions to more general mathematical domains.[^o5] It can also be used to find complex roots[^o3] yet the more sophisticated extensions of Bernoulli's method, such as the one by Aitken[^o27] and QD method,[^o3] are able to find complex roots while solving for all of the roots simultaneously. There are also variations on Bernoulli's method that improve stability and handle multiple roots.[^o45][^o46] A 2025 analysis of the QD method included an implementation in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29).[^o48]

In related applications, Bernoulli's method has been shown to be equivalent to [Power method](https://en.wikipedia.org/wiki/Power_method) on a [companion matrix](wikipedia://en/532542) for finding [eigenvalues](wikipedia://en/2161429).[^o49] Advancements in [systolic arrays](https://en.wikipedia.org/wiki/Systolic_array) have led to a parallelized version of Bernoulli's method.[^o50] The method has also been generalized to find [poles](wikipedia://en/81560) of [rational functions](wikipedia://en/361210), extending to the field of [complex analysis](wikipedia://en/5759).[^o51] An extension of Bernoulli's method was used for improving [linear multistep methods](wikipedia://en/2090865).[^o52] Another development of a modified Bernoulli's method builds a supplemental function using [Taylor](wikipedia://en/30448) and [Laurent](wikipedia://en/61213) series expansions to then solve for roots.[^o53][^o54] An implementation of Bernoulli's method is included with the CodeCogs [open source](https://en.wikipedia.org/wiki/Open_source) numerical methods library.[^o55] The method was also programmed on the [EDSAC](https://en.wikipedia.org/wiki/EDSAC), along with [Graeffe's method](wikipedia://en/6134192), but [Newton's method](wikipedia://en/22145) was preferred for being faster.[^o56]

## Code {#Code}

Bernoulli's method is implemented below in the [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) programming language.

```python3
def bernoulli_method(c, eps=1e-8, max_iter=60):
    """
    Bernoulli's method for finding the dominant root of a polynomial.

    Parameters
    ----------
    c : list
        List of polynomial coefficients in descending order of powers.
        For example, if p(x) = x^2 - x - 1, c = [1.0, -1.0, -1.0]
    eps : float, optional
        Convergence tolerance. Default is 1e-8.
    max_iter : int, optional
        Maximum number of iterations. Default is 60.

    Returns
    -------
    float or complex
        The dominant root of the polynomial if found, otherwise float('nan').

    Examples
    --------
    >>> bernoulli_method([1.0, -1.0, -1.0])  # Golden ratio example
    1.6180339901755971
    >>> bernoulli_method([1.0, -3.0, 2.0])   # x^2 - 3x + 2 = (x - 2)(x - 1)
    2.0000000074505806
    """
    n = len(c)
    x = [0.0] * (n - 2) + [1.0]  # Initialize with zeros and a 1.0
    q = []

    for i in range(n - 1, max_iter + n):
        # Apply the recurrence relation: x_n = -(a_1*x_{n-1} + ... + a_d*x_{n-d})/a_0
        x.append(-sum(c[k] * x[-k + i] for k in range(1, n)) / c[0])
        q.append(x[-1] / x[-2])  # Quotient of two successive x terms q_n = x_{n+1} / x_n

        # Check for convergence after two quotient values
        if len(q) >= 2 and abs(q[-1] - q[-2]) <= eps:
            return q[-1]  # Return the last computed quotient

    return float("nan")  # No convergence within max_iter
```

An efficiency improvement would be to normalize the coefficients by the leading coefficient at the beginning of the method (`c = [coef / c[0] for coef in c]`), eliminating the need for a division operation in the recurrence relation inside the main loop body (`x.append(-sum(c[k] * x[-k + i] for k in range(1, n)))`). This change does not impact the convergence order of the method. Implementing higher-order convergence would require [Aitken's delta-squared process](wikipedia://en/7411694).
