# Line-intercept sampling

::: {#o1 .subject cue=lead name="Line-intercept sampling"}

*Image: Linear transect sampling animation.svg.* Click to see animation of line-intercept sampling.

In [statistics](wikipedia://en/26685), more specifically in [biostatistics](wikipedia://en/3878), **line-intercept sampling (LIS)** is a method of sampling elements in a region whereby an element is sampled if a chosen line segment, called a “[transect](wikipedia://en/158826)”, intersects the element.[^o2]

:::

Line intercept sampling has proven to be a reliable, versatile, and easy to implement method to analyze an area containing various objects of interest.[^o3] It has recently also been applied to estimating variances during particulate material sampling.[^o4]
