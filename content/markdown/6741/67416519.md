# Ultrafilter on a set

*Image: Filter vs ultrafilter.svg.* The powerset lattice of the set {1,2,3,4}, with the [upper set](https://en.wikipedia.org/wiki/Upper_set) ↑{1,4} colored dark green. It is a principal filter, but not an ultrafilter, as it can be extended to the larger nontrivial filter ↑{1}, by including also the light green elements. Since ↑{1} cannot be extended any further, it is an ultrafilter.

::: {#o1 .subject cue=lead name="Ultrafilter on a set"}

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [set theory](wikipedia://en/27553), an **ultrafilter** on a [set](wikipedia://en/26691) $X$ is a *maximal filter* on the set $X.$ In other words, it is a collection of subsets of $X$ that satisfies the definition of a [filter](wikipedia://en/12646549) on $X$ and that is maximal with respect to inclusion, in the sense that there does not exist a strictly larger collection of subsets of $X$ that is also a filter. (In the above, by definition a filter on a set does not contain the empty set.) Equivalently, an ultrafilter on the set $X$ can also be characterized as a filter on $X$ with the property that for every [subset](wikipedia://en/27631) $A$ of $X$ either $A$ or its complement $X\setminus A$ belongs to the ultrafilter.

:::

Ultrafilters on sets are an important special instance of [ultrafilters on partially ordered sets](wikipedia://en/31911), where the [partially ordered set](wikipedia://en/23572) consists of the [power set](wikipedia://en/23799) $\mathcal{P}(X)$ and the partial order is [subset inclusion](https://en.wikipedia.org/wiki/Subset_inclusion) $\,\subseteq.$ This article deals specifically with ultrafilters on a set and does not cover the more general notion.

There are two types of ultrafilter on a set. A **principal ultrafilter** on $X$ is the collection of all subsets of $X$ that contain a fixed element $x \in X$. The ultrafilters that are not principal are the **free ultrafilters**. The existence of free ultrafilters on any infinite set is implied by the ultrafilter lemma, which can be proven in **[ZFC](https://en.wikipedia.org/wiki/ZFC)**. On the other hand, there exist models of **[ZF](wikipedia://en/152214)** where every ultrafilter on a set is principal.

Ultrafilters have many applications in set theory, [model theory](wikipedia://en/19858), and [topology](wikipedia://en/29954).[^o2] Usually, only free ultrafilters lead to non-trivial constructions. For example, an [ultraproduct](wikipedia://en/273642) modulo a principal ultrafilter is always isomorphic to one of the factors, while an ultraproduct modulo a free ultrafilter usually has a more complex structure.

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Given an arbitrary set $X,$ an **ultrafilter** on $X$ is a non-empty [family](wikipedia://en/723043) $U$ of subsets of $X$ such that:

1. Proper or non-degenerate: The empty set is not an element of $U.$
1. Upward closed in $X$: If $A \in U$ and if $B \subseteq X$ is any superset of $A$ (that is, if $A \subseteq B \subseteq X$) then $B \in U.$
1. [$\pi$−system](wikipedia://en/4050532): If $A$ and $B$ are elements of $U$ then so is their [intersection](wikipedia://en/23476429) $A \cap B.$
1. If $A \subseteq X$ then either $A$ or its complement $X \setminus A$ is an element of $U.$[^o5]

Properties (1), (2), and (3) are the defining properties of a filter on $X.$ Some authors do not include non-degeneracy (which is property (1) above) in their definition of "filter". However, the definition of "ultrafilter" (and also of "prefilter" and "filter subbase") always includes non-degeneracy as a defining condition. This article requires that all filters be proper although a filter might be described as "proper" for emphasis.

A **filter subbase** is a non-empty family of sets that has the [finite intersection property](wikipedia://en/365026) (i.e. all finite intersections are non-empty). Equivalently, a filter subbase is a non-empty family of sets that is contained in some (proper) filter. The smallest (relative to $\subseteq$) filter containing a given filter subbase is said to be **generated** by the filter subbase.

The **upward closure** in $X$ of a family of sets $P$ is the set

$$P^{\uparrow X} := \{S : A \subseteq S \subseteq X \text{ for some } A \in P\}.$$

A **prefilter** or **filter base** is a non-empty and proper (i.e. $\varnothing \not\in P$) family of sets $P$ that is **downward directed**, which means that if $B, C \in P$ then there exists some $A \in P$ such that $A \subseteq B \cap C.$ Equivalently, a prefilter is any family of sets $P$ whose upward closure $P^{\uparrow X}$ is a filter, in which case this filter is called the **filter generated by $P$** and $P$ is said to be **a filter base for $P^{\uparrow X}.$**

The **dual in $X$**[^n1] of a family of sets $P$ is the set $X \setminus P := \{X \setminus B : B \in P\}.$ For example, the dual of the [power set](wikipedia://en/23799) $\mathcal{P}(X)$ is itself: $X \setminus \mathcal{P}(X) = \mathcal{P}(X).$ A family of sets is a proper filter on $X$ if and only if its dual is a proper [ideal](wikipedia://en/12633368) on $X$ ("proper" means not equal to the power set).

:::

## Generalization to ultra prefilters {#Generalization_to_ultra_prefilters}

A family $U \neq \varnothing$ of subsets of $X$ is called **ultra** if $\varnothing \not\in U$ and any of the following equivalent conditions are satisfied:[^n1][^n2]

For every set $S \subseteq X$ there exists some set $B \in U$ such that $B \subseteq S$ or $B \subseteq X \setminus S$ (or equivalently, such that $B \cap S$ equals $B$ or $\varnothing$). For every set $S \subseteq {\textstyle\bigcup\limits_{B \in U}} B$ there exists some set $B \in U$ such that $B \cap S$ equals $B$ or $\varnothing.$

Here, ${\textstyle\bigcup\limits_{B \in U}} B$ is defined to be the union of all sets in $U.$

This characterization of "$U$ is ultra" does not depend on the set $X,$ so mentioning the set $X$ is optional when using the term "ultra." For every set $S$ (not necessarily even a subset of $X$) there exists some set $B \in U$ such that $B \cap S$ equals $B$ or $\varnothing.$

If $U$ satisfies this condition then so does every superset $V \supseteq U.$ In particular, a set $V$ is ultra if and only if $\varnothing \not\in V$ and $V$ contains as a subset some ultra family of sets.

A filter subbase that is ultra is necessarily a prefilter.[^o10]

The ultra property can now be used to define both ultrafilters and ultra prefilters:

An **ultra prefilter**[^n1][^n2] is a prefilter that is ultra. Equivalently, it is a filter subbase that is ultra.

An **ultrafilter**[^n1][^n2] on $X$ is a (proper) filter on $X$ that is ultra. Equivalently, it is any filter on $X$ that is generated by an ultra prefilter.

**Ultra prefilters as maximal prefilters**

To characterize ultra prefilters in terms of "maximality," the following relation is needed.

Given two families of sets $M$ and $N,$ the family $M$ is said to be **coarser**[^n3][^n4] than $N,$ and $N$ is **finer** than and **subordinate to** $M,$ written $M \leq N$ or $N \vdash M$, if for every $C \in M,$ there is some $F \in N$ such that $F \subseteq C.$ The families $M$ and $N$ are called **equivalent** if $M \leq N$ and $N \leq M.$ The families $M$ and $N$ are **comparable** if one of these sets is finer than the other.[^n3]

The subordination relationship, i.e. $\,\geq,\,$ is a [preorder](wikipedia://en/23582) so the above definition of "equivalent" does form an [equivalence relation](wikipedia://en/9259). If $M \subseteq N$ then $M \leq N$ but the converse does not hold in general. However, if $N$ is upward closed, such as a filter, then $M \leq N$ if and only if $M \subseteq N.$ Every prefilter is equivalent to the filter that it generates. This shows that it is possible for filters to be equivalent to sets that are not filters.

If two families of sets $M$ and $N$ are equivalent then either both $M$ and $N$ are ultra (resp. prefilters, filter subbases) or otherwise neither one of them is ultra (resp. a prefilter, a filter subbase). In particular, if a filter subbase is not also a prefilter, then it is not equivalent to the filter or prefilter that it generates. If $M$ and $N$ are both filters on $X$ then $M$ and $N$ are equivalent if and only if $M = N.$ If a proper filter (resp. ultrafilter) is equivalent to a family of sets $M$ then $M$ is necessarily a prefilter (resp. ultra prefilter). Using the following characterization, it is possible to define prefilters (resp. ultra prefilters) using only the concept of filters (resp. ultrafilters) and subordination:

An arbitrary family of sets is a prefilter if and only it is equivalent to a (proper) filter.

An arbitrary family of sets is an ultra prefilter if and only it is equivalent to an ultrafilter.

A **maximal prefilter on $X$**[^n1][^n2] is a prefilter $U \subseteq \mathcal{P}(X)$ that satisfies any of the following equivalent conditions:

$U$ is ultra.

$U$ is **maximal** on $\operatorname{Prefilters}(X)$ with respect to $\,\leq,$ meaning that if $P \in \operatorname{Prefilters}(X)$ satisfies $U \leq P$ then $P \leq U.$[^n2] There is no prefilter properly subordinate to $U.$[^n2] If a (proper) filter $F$ on $X$ satisfies $U \leq F$ then $F \leq U.$ The filter on $X$ generated by $U$ is ultra.

::: {#o23 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

There are no ultrafilters on the [empty set](wikipedia://en/9566), so it is henceforth assumed that $X$ is nonempty.

A filter subbase $U$ on $X$ is an ultrafilter on $X$ if and only if any of the following equivalent conditions hold:[^n1][^n2]

for any $S \subseteq X,$ either $S \in U$ or $X \setminus S \in U.$ $U$ is a maximal filter subbase on $X,$ meaning that if $F$ is any filter subbase on $X$ then $U \subseteq F$ implies $U = F.$[^n5]

A (proper) filter $U$ on $X$ is an ultrafilter on $X$ if and only if any of the following equivalent conditions hold:

$U$ is ultra; $U$ is generated by an ultra prefilter; For any subset $S \subseteq X,$ $S \in U$ or $X \setminus S \in U.$[^n5]

So an ultrafilter $U$ decides for every $S \subseteq X$ whether $S$ is "large" (i.e. $S \in U$) or "small" (i.e. $X \setminus S \in U$).[^o28] For each subset $A \subseteq X,$ either[^o5] $A$ is in $U$ or ($X \setminus A$) is. $U \cup (X \setminus U) = \mathcal{P}(X).$ This condition can be restated as: $\mathcal{P}(X)$ is partitioned by $U$ and its dual $X \setminus U.$

The sets $P$ and $X \setminus P$ are disjoint for all prefilters $P$ on $X.$ $\mathcal{P}(X) \setminus U = \left\{ S \in \mathcal{P}(X) : S \not\in U \right\}$ is an ideal on $X.$[^n5] For any finite family $S_1, \ldots, S_n$ of subsets of $X$ (where $n \geq 1$), if $S_1 \cup \cdots \cup S_n \in U$ then $S_i \in U$ for some index $i.$

In words, a "large" set cannot be a finite union of sets none of which is large.[^o30] For any $R, S \subseteq X,$ if $R \cup S = X$ then $R \in U$ or $S \in U.$ For any $R, S \subseteq X,$ if $R \cup S \in U$ then $R \in U$ or $S \in U$ (a filter with this property is called a **prime filter**). For any $R, S \subseteq X,$ if $R \cup S \in U$ and $R \cap S = \varnothing$ then either $R \in U$ or $S \in U.$ $U$ is a maximal filter; that is, if $F$ is a filter on $X$ such that $U \subseteq F$ then $U = F.$ Equivalently, $U$ is a maximal filter if there is no filter $F$ on $X$ that contains $U$ as a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) (that is, no filter is strictly [finer](wikipedia://en/19719#Filter_on_a_set) than $U$).[^n5]

### Grills and filter-grills {#Grills_and_filter-grills}

If $\mathcal{B} \subseteq \mathcal{P}(X)$ then its grill on $X$ is the family

$$\mathcal{B}^{\# X} := \{S \subseteq X ~:~ S \cap B \neq \varnothing \text{ for all } B \in \mathcal{B}\}$$

where $\mathcal{B}^{\#}$ may be written if $X$ is clear from context. If $\mathcal{F}$ is a filter then $\mathcal{F}^{\#}$ is the set of positive sets with respect to $\mathcal{F}$ and is usually written as $\mathcal{F}^{+}$. For example, $\varnothing^{\#} = \mathcal{P}(X)$ and if $\varnothing \in \mathcal{B}$ then $\mathcal{B}^{\#} = \varnothing.$ If $\mathcal{A} \subseteq \mathcal{B}$ then $\mathcal{B}^{\#} \subseteq \mathcal{A}^{\#}$ and moreover, if $\mathcal{B}$ is a filter subbase then $\mathcal{B} \subseteq \mathcal{B}^{\#}.$[^n6] The grill $\mathcal{B}^{\# X}$ is upward closed in $X$ if and only if $\varnothing \not\in \mathcal{B},$ which will henceforth be assumed. Moreover, $\mathcal{B}^{\#\#} = \mathcal{B}^{\uparrow X}$ so that $\mathcal{B}$ is upward closed in $X$ if and only if $\mathcal{B}^{\#\#} = \mathcal{B}.$

The grill of a filter on $X$ is called a filter-grill on $X.$[^n6] For any $\varnothing \neq \mathcal{B} \subseteq \mathcal{P}(X),$ $\mathcal{B}$ is a filter-grill on $X$ if and only if (1) $\mathcal{B}$ is upward closed in $X$ and (2) for all sets $R$ and $S,$ if $R \cup S \in \mathcal{B}$ then $R \in \mathcal{B}$ or $S \in \mathcal{B}.$ The grill operation $\mathcal{F} \mapsto \mathcal{F}^{\# X}$ induces a bijection

$${\bullet}^{\# X} ~:~ \operatorname{Filters}(X) \to \operatorname{FilterGrills}(X)$$

whose inverse is also given by $\mathcal{F} \mapsto \mathcal{F}^{\# X}.$[^n6] If $\mathcal{F} \in \operatorname{Filters}(X)$ then $\mathcal{F}$ is a filter-grill on $X$ if and only if $\mathcal{F} = \mathcal{F}^{\# X},$[^n6] or equivalently, if and only if $\mathcal{F}$ is an ultrafilter on $X.$[^n6] That is, a filter on $X$ is a filter-grill if and only if it is ultra. For any non-empty $\mathcal{F} \subseteq \mathcal{P}(X),$ $\mathcal{F}$ is both a filter on $X$ and a filter-grill on $X$ if and only if (1) $\varnothing \not\in \mathcal{F}$ and (2) for all $R, S \subseteq X,$ the following equivalences hold:

$R \cup S \in \mathcal{F}$ if and only if $R, S \in \mathcal{F}$ if and only if $R \cap S \in \mathcal{F}.$[^n6]

### Free or principal {#Free_or_principal}

If $P$ is any non-empty family of sets then the **[Kernel](wikipedia://en/330095) of $P$** is the intersection of all sets in $P:$[^n7]

$$\operatorname{ker} P := \bigcap_{B \in P} B.$$

A non-empty family of sets $P$ is called:

- **free** if $\operatorname{ker} P = \varnothing$ and **fixed** otherwise (that is, if $\operatorname{ker} P \neq \varnothing$).
- **principal** if $\operatorname{ker} P \in P.$
- **principal at a point** if $\operatorname{ker} P \in P$ and $\operatorname{ker} P$ is a singleton set; in this case, if $\operatorname{ker} P = \{x\}$ then $P$ is said to be **principal at $x.$**

If a family of sets $P$ is fixed then $P$ is ultra if and only if some element of $P$ is a singleton set, in which case $P$ will necessarily be a prefilter. Every principal prefilter is fixed, so a principal prefilter $P$ is ultra if and only if $\operatorname{ker} P$ is a singleton set. A singleton set is ultra if and only if its sole element is also a singleton set.

The next theorem shows that every ultrafilter falls into one of two categories: either it is free or else it is a principal filter generated by a single point.

::: {#o41 .statement kind=statement/proposition cue=math-theorem name="Proposition"}

**Proposition.**

If $U$ is an ultrafilter on $X$ then the following are equivalent:

$U$ is fixed, or equivalently, not free. $U$ is principal. Some element of $U$ is a finite set. Some element of $U$ is a singleton set. $U$ is principal at some point of $X,$ which means $\operatorname{ker} U = \{x\} \in U$ for some $x \in X.$ $U$ does not contain the [Fréchet filter](wikipedia://en/1586291) on $X$ as a subset. $U$ is sequential.[^n6]

:::

Every filter on $X$ that is principal at a single point is an ultrafilter, and if in addition $X$ is finite, then there are no ultrafilters on $X$ other than these.[^n7] In particular, if a set $X$ has finite cardinality $n < \infty,$ then there are exactly $n$ ultrafilters on $X$ and those are the ultrafilters generated by each singleton subset of $X.$ Consequently, free ultrafilters can only exist on an infinite set.

:::

## Examples, properties, and sufficient conditions {#Examples,_properties,_and_sufficient_conditions}

If $X$ is an infinite set then there are as many ultrafilters over $X$ as there are families of subsets of $X;$ explicitly, if $X$ has infinite cardinality $\kappa$ then the set of ultrafilters over $X$ has the same cardinality as $\mathcal{P}(\mathcal{P}(X));$ that cardinality being $2^{2^{\kappa}}.$[^o45]

If $U$ and $S$ are families of sets such that $U$ is ultra, $\varnothing \not\in S,$ and $U \leq S,$ then $S$ is necessarily ultra. A filter subbase $U$ that is not a prefilter cannot be ultra; but it is nevertheless still possible for the prefilter and filter generated by $U$ to be ultra.

Suppose $U \subseteq \mathcal{P}(X)$ is ultra and $Y$ is a set. The trace $U\vert_Y := \{B \cap Y : B \in U\}$ is ultra if and only if it does not contain the empty set. Furthermore, at least one of the sets $U\vert_Y \setminus \{\varnothing\}$ and $U\vert_{X \setminus Y} \setminus \{\varnothing\}$ will be ultra (this result extends to any finite partition of $X$). If $F_1, \ldots, F_n$ are filters on $X,$ $U$ is an ultrafilter on $X,$ and $F_1 \cap \cdots \cap F_n \leq U,$ then there is some $F_i$ that satisfies $F_i \leq U.$[^n8] This result is not necessarily true for an infinite family of filters.[^n8]

The image under a map $f : X \to Y$ of an ultra set $U \subseteq \mathcal{P}(X)$ is again ultra and if $U$ is an ultra prefilter then so is $f(U).$ The property of being ultra is preserved under bijections. However, the preimage of an ultrafilter is not necessarily ultra, not even if the map is surjective. For example, if $X$ has more than one point and if the range of $f : X \to Y$ consists of a single point $\{ y \}$ then $\{ y \}$ is an ultra prefilter on $Y$ but its preimage is not ultra. Alternatively, if $U$ is a principal filter generated by a point in $Y \setminus f(X)$ then the preimage of $U$ contains the empty set and so is not ultra.

The elementary filter induced by an infinite sequence, all of whose points are distinct, is not an ultrafilter.[^n8] If $n = 2,$ then $U_n$ denotes the set consisting all subsets of $X$ having cardinality $n,$ and if $X$ contains at least $2 n - 1$ ($=3$) distinct points, then $U_n$ is ultra but it is not contained in any prefilter. This example generalizes to any integer $n > 1$ and also to $n = 1$ if $X$ contains more than one element. Ultra sets that are not also prefilters are rarely used.

For every $S \subseteq X \times X$ and every $a \in X,$ let $S\big\vert_{\{a\} \times X} := \{y \in X ~:~ (a, y) \in S\}.$ If $\mathcal{U}$ is an ultrafilter on $X$ then the set of all $S \subseteq X \times X$ such that $\left\{a \in X ~:~ S\big\vert_{\{a\} \times X} \in \mathcal{U}\right\} \in \mathcal{U}$ is an ultrafilter on $X \times X.$[^n9]

### Monad structure {#Monad_structure}

The [functor](wikipedia://en/10987) associating to any set $X$ the set of $U(X)$ of all ultrafilters on $X$ forms a [monad](wikipedia://en/355140) called the Ultrafilter monad. The unit map

$$X \to U(X)$$

sends any element $x \in X$ to the principal ultrafilter given by $x.$

This [ultrafilter monad](https://en.wikipedia.org/wiki/Ultrafilter_monad) is the [codensity monad](wikipedia://en/61387397) of the inclusion of the [category of finite sets](wikipedia://en/25044975) into the [category of all sets](wikipedia://en/26829),[^o51] which gives a conceptual explanation of this monad.

Similarly, the [ultraproduct monad](https://en.wikipedia.org/wiki/Ultraproduct_monad) is the codensity monad of the inclusion of the category of finite [families of sets](wikipedia://en/723043) into the category of all families of set. So in this sense, [ultraproducts](wikipedia://en/273642) are categorically inevitable.[^o51]

## The ultrafilter lemma {#The_ultrafilter_lemma}

The ultrafilter lemma was first proved by [Alfred Tarski](wikipedia://en/59920) in 1930.[^n9]

::: {#o56 .statement kind=statement/theorem cue=math-theorem name="The /principle/theorem"}

**The ultrafilter lemma/principle/theorem[^n3].**

Every proper filter on a set $X$ is contained in some ultrafilter on $X.$

:::

The ultrafilter lemma is equivalent to each of the following statements:

1. For every prefilter on a set $X,$ there exists a maximal prefilter on $X$ subordinate to it.[^n1]
1. Every proper filter subbase on a set $X$ is contained in some ultrafilter on $X.$

A consequence of the ultrafilter lemma is that every filter is equal to the intersection of all ultrafilters containing it.[^n10][^o59]

The following results can be proven using the ultrafilter lemma. A free ultrafilter exists on a set $X$ if and only if $X$ is infinite. Every proper filter is equal to the intersection of all ultrafilters containing it.[^n3] Since there are filters that are not ultra, this shows that the intersection of a family of ultrafilters need not be ultra. A family of sets $\mathbb{F} \neq \varnothing$ can be extended to a free ultrafilter if and only if the intersection of any finite family of elements of $\mathbb{F}$ is infinite.

### Relationships to other statements under ZF {#Relationships_to_other_statements_under_ZF}

Throughout this section, **ZF** refers to [Zermelo–Fraenkel set theory](wikipedia://en/152214) and **ZFC** refers to **ZF** with the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice) (**AC**). The ultrafilter lemma is independent of **ZF**. That is, there exist [models](wikipedia://en/19858) in which the axioms of **ZF** hold but the ultrafilter lemma does not. There also exist models of **ZF** in which every ultrafilter is necessarily principal.

Every filter that contains a singleton set is necessarily an ultrafilter and given $x \in X,$ the definition of the discrete ultrafilter $\{S \subseteq X : x \in S\}$ does not require more than **ZF**. If $X$ is finite then every ultrafilter is a discrete filter at a point; consequently, free ultrafilters can only exist on infinite sets. In particular, if $X$ is finite then the ultrafilter lemma can be proven from the axioms **ZF**. The existence of free ultrafilter on infinite sets can be proven if the axiom of choice is assumed. More generally, the ultrafilter lemma can be proven by using the [axiom of choice](wikipedia://en/840), which in brief states that any [Cartesian product](wikipedia://en/24104095) of non-empty sets is non-empty. Under **ZF**, the axiom of choice is, in particular, [equivalent](wikipedia://en/840#Equivalents) to (a) [Zorn's lemma](wikipedia://en/51442), (b) [Tychonoff's theorem](wikipedia://en/82739), (c) the weak form of the vector basis theorem (which states that every vector space has a [basis](https://en.wikipedia.org/wiki/Hamel_basis)), (d) the strong form of the vector basis theorem, and other statements. However, the ultrafilter lemma is strictly weaker than the axiom of choice. While free ultrafilters can be proven to exist, it is not possible to construct an explicit example of a free ultrafilter (using only **ZF** and the ultrafilter lemma); that is, free ultrafilters are intangible.[^n11] [Alfred Tarski](wikipedia://en/59920) proved that under **ZFC**, the cardinality of the set of all free ultrafilters on an infinite set $X$ is equal to the cardinality of $\mathcal{P}(\mathcal{P}(X)),$ where $\mathcal{P}(X)$ denotes the power set of $X.$[^n12] Other authors attribute this discovery to Bedřich Pospíšil (following a combinatorial argument from [Fichtenholz](https://en.wikipedia.org/wiki/Grigorii_Fichtenholz), and [Kantorovitch](wikipedia://en/194660), improved by [Hausdorff](wikipedia://en/10989)).[^n13][^n14]

Under **ZF**, the [axiom of choice](wikipedia://en/840) can be used to prove both the ultrafilter lemma and the [Krein–Milman theorem](wikipedia://en/3206654); conversely, under **ZF**, the ultrafilter lemma together with the Krein–Milman theorem can prove the axiom of choice.[^o66]

#### Statements that cannot be deduced {#Statements_that_cannot_be_deduced}

The ultrafilter lemma is a relatively weak axiom. For example, each of the statements in the following list can not be deduced from **ZF** together with only the ultrafilter lemma:

A countable union of [countable sets](wikipedia://en/6026) is a countable set. The [axiom of countable choice](wikipedia://en/421086) (**ACC**). The [axiom of dependent choice](wikipedia://en/441950) (**ADC**).

#### Equivalent statements {#Equivalent_statements}

Under **ZF**, the ultrafilter lemma is equivalent to each of the following statements:[^n15]

The [Boolean prime ideal theorem](wikipedia://en/314919) (**BPIT**). [Stone's representation theorem for Boolean algebras](wikipedia://en/604111). Any product of [Boolean spaces](https://en.wikipedia.org/wiki/Boolean_space) is a Boolean space.[^n16] Boolean Prime Ideal Existence Theorem: Every nondegenerate [Boolean algebra](wikipedia://en/54476844) has a prime ideal.[^n17] [Tychonoff's theorem](wikipedia://en/82739) for [Hausdorff spaces](wikipedia://en/13637): Any [product](wikipedia://en/24910) of [compact](wikipedia://en/6042) [Hausdorff spaces](wikipedia://en/13637) is compact.[^n16] If $\{ 0, 1 \}$ is endowed with the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) then for any set $I,$ the [product space](https://en.wikipedia.org/wiki/Product_space) $\{0, 1\}^I$ is [compact](wikipedia://en/6042).[^n16] Each of the following versions of the [Banach-Alaoglu theorem](https://en.wikipedia.org/wiki/Banach-Alaoglu_theorem) is equivalent to the ultrafilter lemma:

Any [equicontinuous](https://en.wikipedia.org/wiki/Equicontinuous) set of scalar-valued maps on a [topological vector space](wikipedia://en/45752) (TVS) is relatively compact in the [weak-\* topology](https://en.wikipedia.org/wiki/Weak-*_topology) (that is, it is contained in some weak-\* compact set).[^n18] The [polar](wikipedia://en/1764022) of any neighborhood of the origin in a TVS $X$ is a weak-\* compact subset of its [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space).[^n18] The closed unit ball in the [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) of any [normed space](https://en.wikipedia.org/wiki/Normed_space) is weak-\* compact.[^n18]

If the normed space is separable then the ultrafilter lemma is sufficient but not necessary to prove this statement.

A topological space $X$ is compact if every ultrafilter on $X$ converges to some limit.[^n19] A topological space $X$ is compact if and only if every ultrafilter on $X$ converges to some limit.[^n19]

## Completeness {#Completeness}

The **completeness** of an ultrafilter $U$ on a powerset is the smallest [cardinal](wikipedia://en/6173) κ such that there are κ elements of $U$ whose intersection is not in $U.$ The definition of an ultrafilter implies that the completeness of any powerset ultrafilter is at least [$\aleph_0$](https://en.wikipedia.org/wiki/Aleph-naught). An ultrafilter whose completeness is greater than $\aleph_0$—that is, the intersection of any countable collection of elements of $U$ is still in $U$—is called **countably complete** or **σ-complete**.

The completeness of a countably complete nonprincipal ultrafilter on a powerset is always a [measurable cardinal](wikipedia://en/248102).

## Ordering on ultrafilters {#Ordering_on_ultrafilters}

The **Rudin–Keisler ordering** (named after [Mary Ellen Rudin](wikipedia://en/2976742) and [Howard Jerome Keisler](wikipedia://en/10962250)) is a [preorder](wikipedia://en/23582) on the class of powerset ultrafilters defined as follows: if $U$ is an ultrafilter on $\mathcal{P}(X),$ and $V$ an ultrafilter on $\mathcal{P}(Y),$ then $V \leq {}_{RK} U$ if there exists a function $f : X \to Y$ such that

$C \in V$ if and only if $f^{-1}[C] \in U$

for every subset $C \subseteq Y.$

Ultrafilters $U$ and $V$ are called **Rudin–Keisler equivalent**, denoted $U \equiv_{\operatorname{RK}} V$, if there exist sets $A \in U$ and $B \in V$ and a [bijection](wikipedia://en/3942) $f : A \to B$ that satisfies the condition above. (If $X$ and $Y$ have the same cardinality, the definition can be simplified by fixing $A = X,$ $B = Y.$)

It is known that ≡<sub>RK</sub> is the [kernel](wikipedia://en/330095) of ≤<sub>RK</sub>, i.e., that $U \equiv_{\operatorname{RK}} V$ if and only if $U \leq {}_{RK} V$ and $V \leq {}_{RK} U.$[^o94]

## Ultrafilters on 𝒫(ω) {#Ultrafilters_on_𝒫(ω)}

There are several special properties that an ultrafilter on $\mathcal{P}(\omega),$ where $\omega$ [extends the natural numbers](wikipedia://en/26547932#Ordinals_extend_the_natural_numbers), may possess, which prove useful in various areas of set theory and topology.

- A non-principal ultrafilter $U$ is called a **P-point** (or **weakly selective**) if for every [partition](wikipedia://en/340240) $\left\{ C_n : n < \omega \right\}$ of $\omega$ such that for all $n < \omega,$ $C_n \not\in U,$ there exists some $A \in U$ such that $A \cap C_n$ is a finite set for each $n.$
- A non-principal ultrafilter $U$ is called **Ramsey** (or **selective**) if for every partition $\left\{ C_n : n < \omega \right\}$ of $\omega$ such that for all $n < \omega,$ $C_n \not\in U,$ there exists some $A \in U$ such that $A \cap C_n$ is a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) for each $n.$

It is a trivial observation that all Ramsey ultrafilters are P-points. [Walter Rudin](wikipedia://en/5491766) proved that the [continuum hypothesis](wikipedia://en/5705) implies the existence of Ramsey ultrafilters.[^o96] In fact, many hypotheses imply the existence of Ramsey ultrafilters, including [Martin's axiom](wikipedia://en/1550783). [Saharon Shelah](wikipedia://en/331211) later showed that it is consistent that there are no P-point ultrafilters.[^o97] Therefore, the existence of these types of ultrafilters is [independent](wikipedia://en/1141208) of [ZFC](https://en.wikipedia.org/wiki/ZFC).

P-points are called as such because they are topological [P-points](https://en.wikipedia.org/wiki/P-point) in the usual topology of the space [βω \\ ω](wikipedia://en/52897) of non-principal ultrafilters. The name Ramsey comes from [Ramsey's theorem](wikipedia://en/184898). To see why, one can prove that an ultrafilter is Ramsey if and only if for every 2-coloring of $[\omega]^2$ there exists an element of the ultrafilter that has a homogeneous color.

An ultrafilter on $\mathcal{P}(\omega)$ is Ramsey if and only if it is [minimal](https://en.wikipedia.org/wiki/Minimal_element) in the Rudin–Keisler ordering of non-principal powerset ultrafilters.[^n21]
