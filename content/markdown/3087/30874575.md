# MuPAD

::: {#o1 .subject cue=lead name="MuPAD"}

**MuPAD** is a [computer algebra system](wikipedia://en/54427) (CAS). Originally developed by the MuPAD research group at the [University of Paderborn](https://en.wikipedia.org/wiki/University_of_Paderborn), [Germany](https://en.wikipedia.org/wiki/Germany), development was taken over by the company SciFace Software GmbH & Co. KG in cooperation with the MuPAD research group and partners from some other universities starting in 1997. MuPAD's graphics package was particularly successful, especially considering the era when it was developed.

:::

Until autumn 2005, the version "MuPAD Light" was offered for free for research and education, but as a result of the closure of the home institute of the MuPAD research group, only the version "MuPAD Pro" became available for purchase.

The MuPAD kernel is bundled with [Scientific Notebook](https://en.wikipedia.org/wiki/Scientific_Notebook) and [Scientific Workplace](https://en.wikipedia.org/wiki/Scientific_Workplace). Former versions of *MuPAD Pro* were bundled with [SciLab](https://en.wikipedia.org/wiki/SciLab). In [MathCAD](https://en.wikipedia.org/wiki/MathCAD)'s version 14 release MuPAD was adopted as the CAS engine.

In September 2008, SciFace was purchased by [MathWorks](https://en.wikipedia.org/wiki/MathWorks) and the MuPAD code was included in the Symbolic Math Toolbox add-on for [MATLAB](wikipedia://en/20412). On 28 September 2008, MuPAD was withdrawn from the market as a software product in its own right.[^o3] However, it is still available in the Symbolic Math Toolbox in MATLAB and can also be used as a stand-alone program by the command `mupad` entered into the MATLAB terminal.

The MuPAD notebook feature has been removed in [MATLAB](wikipedia://en/20412) R2020a. However, [MATLAB](wikipedia://en/20412)'s Symbolic Math Toolbox still uses the MuPAD language as part of its underlying computational engine. [MATLAB](wikipedia://en/20412) Live Editor is the recommended environment for performing, documenting, and sharing symbolic math computations.[^o4]

## Functionality {#Functionality}

MuPAD offers:

- a [computer algebra system](wikipedia://en/54427) to manipulate formulas symbolically;
- classic and verified [numerical analysis](wikipedia://en/21506) in discretionary accuracy;
- program packages for [linear algebra](wikipedia://en/18422), [differential equations](https://en.wikipedia.org/wiki/Differential_equations), [number theory](wikipedia://en/21527), [statistics](wikipedia://en/26685), and [functional programming](https://en.wikipedia.org/wiki/Functional_programming);
- an interactive graphic system that supports animations and transparent areas in 3D, and;
- a [programming language](wikipedia://en/23015) that supports [object-oriented programming](https://en.wikipedia.org/wiki/Object-oriented_programming) and functional programming.

Often used commands are accessible via menus. MuPAD offers a notebook concept similar to [word processing systems](https://en.wikipedia.org/wiki/Word_processor_program) that allows the formulation of mathematical problems as well as graphics visualization and explanations in formatted text.

MuPad does not follow the [NIST](https://en.wikipedia.org/wiki/National_Institute_of_Standards_and_Technology) 4.37 definition for [inverse hyperbolic cosine](https://en.wikipedia.org/wiki/Inverse_hyperbolic_cosine).

It is possible to extend MuPAD with [C++](https://en.wikipedia.org/wiki/C++) [routines](https://en.wikipedia.org/wiki/Function_%28computer_programming%29) to accelerate calculations. [Java code](https://en.wikipedia.org/wiki/Java_%28programming_language%29) can also be embedded.

MuPAD's syntax was modeled on that of the [Pascal programming language](https://en.wikipedia.org/wiki/Pascal_%28programming_language%29), and is similar to the one used in the [Maple computer algebra system](https://en.wikipedia.org/wiki/Maple_computer_algebra_system). An important difference between the two is that MuPAD provides support for [object-oriented programming](https://en.wikipedia.org/wiki/Object-oriented_programming). This means that each object "carries with itself" the methods allowed to be used on it. For example, after defining

```mupad
  A := matrix( [[1,2],[3,4]] )
```

all of the following are valid expressions and give the expected result:

```mupad
  A+A, -A, 2*A, A*A, A^-1, exp( A ), A.A, A^0, 0*A
```

where `A.A` is the [concatenated](https://en.wikipedia.org/wiki/Concatenate) 2×4 matrix, while all others, including the last two, are again 2×2 matrices.
