# Square-free element

::: {#o1 .subject cue=lead name="Square-free element"}

In [mathematics](wikipedia://en/18831), a **square-free element** is an element *r* of a [unique factorization domain](wikipedia://en/60546) *R* that is not [divisible](wikipedia://en/15462) by a non-trivial square. This means that every *s* such that $s^2\mid r$ is a [unit](https://en.wikipedia.org/wiki/Unit_%28algebra%29) of *R*.

:::

## Alternate characterizations {#Alternate_characterizations}

Square-free elements may be also characterized using their prime decomposition. The unique factorization property means that a non-zero non-unit *r* can be represented as a product of [prime elements](wikipedia://en/60692)

$$r=p_1p_2\cdots p_n$$

Then *r* is square-free if and only if the primes *p<sub>i</sub>* are pairwise [non-associated](https://en.wikipedia.org/wiki/Associated_element) (i.e. that it doesn't have two of the same prime as factors, which would make it divisible by a square number).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Common examples of square-free elements include [square-free integers](wikipedia://en/29525) and [square-free polynomials](wikipedia://en/3816655).

:::
