# Finite topology

::: {#o1 .subject cue=lead name="Finite topology"}

**Finite topology** is a mathematical concept which has several different meanings.

:::

## Finite topological space {#Finite_topological_space}

A [finite topological space](wikipedia://en/14682596) is a [topological space](wikipedia://en/30450), the underlying set of which is finite.

## In endomorphism rings and modules {#In_endomorphism_rings_and_modules}

If *A* and *B* are [abelian groups](wikipedia://en/2974) then the **finite topology** on the group of homomorphisms Hom(*A*, *B*) can be defined using the following [base](wikipedia://en/59220) of open neighbourhoods of zero.[^n1]

$$U_{x_1,x_2,\ldots,x_n}=\{f\in\operatorname{Hom}(A,B)\mid f(x_i)=0 \mbox{ for } i=1,2,\ldots,n\}$$

This concept finds applications especially in the study of [endomorphism rings](wikipedia://en/59623) where we have *A* = *B*. [^n2] Similarly, if *R* is a ring and *M* is a right *R*-[module](wikipedia://en/276410), then the finite topology on $\text{End}_R(M)$ is defined using the following system of neighborhoods of zero:[^n3]

$$U_X = \{f\in \text{End}_R(M) \mid f(X) = 0\}$$

## In vector spaces {#In_vector_spaces}

In a [vector space](wikipedia://en/32370) $V$, the **finite open** sets $U\subset V$ are defined as those sets whose intersections with all finite-dimensional subspaces $F\subset V$ are open. The **finite topology** on $V$ is defined by these open sets and is sometimes denoted $\tau_f(V)$. [^n4]

When *V* has uncountable dimension, this topology is not locally convex nor does it make *V* as [topological vector space](wikipedia://en/45752), but when *V* has countable dimension it coincides with both the finest vector space topology on *V* and the finest locally convex topology on *V*.[^n5]

## In manifolds {#In_manifolds}

A manifold *M* is sometimes said to have finite topology, or finite topological type, if it is homeomorphic to a compact [Riemann surface](wikipedia://en/173181) from which a finite number of points have been removed.[^n6]
