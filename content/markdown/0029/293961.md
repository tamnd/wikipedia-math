# Aleph number

*Image: Aleph0.svg.* Aleph-nought, aleph-zero, or aleph-null, the smallest infinite cardinal number

::: {#o1 .subject cue=lead name="Aleph number"}

In [mathematics](wikipedia://en/18831), particularly in [set theory](wikipedia://en/27553), the **aleph numbers** are a [sequence](wikipedia://en/27838) of numbers used to represent the [cardinality](wikipedia://en/6174) (or size) of [infinite sets](wikipedia://en/142679). They were introduced by the mathematician [Georg Cantor](wikipedia://en/12216)[^o2] and are named after the symbol he used to denote them, the Hebrew letter [aleph](https://en.wikipedia.org/wiki/Aleph) (ℵ).[^o3]

:::

The smallest cardinality of an infinite set is that of the [natural numbers](wikipedia://en/21474), denoted by $\aleph_0$ (read *aleph-nought*, *aleph-zero*, or *aleph-null*); the next larger cardinality of a [well-ordered](wikipedia://en/33456) set is $\aleph_1,$ then $\aleph_2,$ then $\aleph_3,$ and so on. Continuing in this manner, it is possible to define an infinite [cardinal number](wikipedia://en/6173) $\aleph_{\alpha}$ for every [ordinal number](wikipedia://en/26547932) $\alpha,$ as described below.

The concept and notation are due to [Georg Cantor](wikipedia://en/12216),[^o4] who defined the notion of cardinality and realized that [infinite sets can have different cardinalities](https://en.wikipedia.org/wiki/Georg_Cantor's_first_set_theory_article).

The aleph numbers differ from the [infinity](wikipedia://en/51698) ($\infty$) commonly found in algebra and calculus, in that the alephs measure the sizes of sets, while infinity is commonly defined either as an extreme [limit](wikipedia://en/26551602) of the [real number line](https://en.wikipedia.org/wiki/Real_number_line) (applied to a [function](wikipedia://en/185427) or [sequence](wikipedia://en/27838) that "[diverges](wikipedia://en/876428) to infinity" or "increases without bound"), or as an extreme point of the [extended real number line](wikipedia://en/51698).

::: {#o6 .pointer-item cue=pointer name="Aleph 0"}

## Aleph-zero {#Aleph-zero}

$\aleph_0$ (**aleph-nought**, **aleph-zero**, or **aleph-null**) is the cardinality of the set of all natural numbers, and is an [infinite cardinal](wikipedia://en/189734). The set of all finite [ordinals](wikipedia://en/26547932), called $\omega$ or $\omega_0$ (where $\omega$ is the lowercase Greek letter [omega](https://en.wikipedia.org/wiki/Omega)), also has cardinality $\aleph_0$. A set has cardinality $\aleph_0$ if and only if it is [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite), that is, there is a [bijection](wikipedia://en/3942) (one-to-one correspondence) between it and the natural numbers. Examples of such sets are:

- the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), irrespective of including or excluding zero,
- the set of all [integers](wikipedia://en/14563),
- any infinite subset of the integers, such as the set of all [square numbers](https://en.wikipedia.org/wiki/Square_numbers) or the set of all [prime numbers](https://en.wikipedia.org/wiki/Prime_numbers),
- the set of all [rational numbers](wikipedia://en/19727024),
- the set of all [constructible numbers](wikipedia://en/7439) (in the geometric sense),
- the set of all [algebraic numbers](wikipedia://en/1158),
- the set of all [computable numbers](wikipedia://en/6206),
- the set of all [computable functions](wikipedia://en/1139338),
- the set of all binary [strings](wikipedia://en/27701) of finite length, and
- the set of all finite [subsets](wikipedia://en/27631) of any given countably infinite set.

Among the countably infinite sets are certain infinite ordinals, including for example $\omega$, $\omega+1$, $\omega \cdot 2$, $\omega^2$, $\omega^\omega$, and [$\varepsilon_0$](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29).[^o7] For example, the sequence (with [order type](wikipedia://en/4499021) $\omega \cdot 2$) of all positive odd integers followed by all positive even integers $\{1, 3, 5, 7, 9, \cdots; 2, 4, 6, 8, 10, \cdots\}$ is a well-ordering of the set (with cardinality $\aleph_0$) of positive integers.

If the [axiom of countable choice](wikipedia://en/421086) (a weaker version of the [axiom of choice](wikipedia://en/840)) holds, then $\aleph_0$ is smaller than any other infinite cardinal.

## Aleph-one {#Aleph-one}

$\aleph_1$ is the cardinality of the set of all countable [ordinal numbers](wikipedia://en/26547932).[^o10] This set is denoted by $\omega_1$ (or sometimes Ω). The set $\omega_1$ is itself an ordinal number larger than all countable ones, so it is an [uncountable set](wikipedia://en/32248). Therefore, $\aleph_1$ is the smallest cardinality that is larger than $\aleph_0,$ the smallest infinite cardinality.

The definition of $\aleph_1$ implies (in ZF, [Zermelo–Fraenkel set theory](wikipedia://en/152214) *without* the axiom of choice) that no cardinal number is between $\aleph_0$ and $\aleph_1.$ If the [axiom of choice](wikipedia://en/840) is used, it can be further proved that the class of cardinal numbers is [totally ordered](https://en.wikipedia.org/wiki/Totally_ordered), and thus $\aleph_1$ is the second-smallest infinite cardinal number. One can show one of the most useful properties of the set $\omega_1$: Any countable subset of $\omega_1$ has an upper bound in $\omega_1$ (this follows from the fact that the union of a countable number of countable sets is itself countable). This fact is analogous to the situation in $\aleph_0$: Every finite set of natural numbers has a maximum, which is also a natural number, and [finite unions](https://en.wikipedia.org/wiki/Finite_unions) of finite sets are finite.

An example application of the ordinal $\omega_1$ is "closing" with respect to countable-[arity](wikipedia://en/42301) operations; e.g., trying to explicitly describe the [σ-algebra](wikipedia://en/29586) generated by an arbitrary collection of subsets (see e.g. [Borel hierarchy](wikipedia://en/5539282)). This is harder than most explicit descriptions of "generation" in algebra ([vector spaces](wikipedia://en/32370), [groups](wikipedia://en/41890), etc.) because in those cases we only have to close with respect to finite operations—sums, products, etc. The process involves defining, for each countable ordinal, via [transfinite induction](wikipedia://en/30461), a set by "throwing in" all possible *countable* unions and complements, and taking the union of all that over all of $\omega_1.$

:::

## Continuum hypothesis {#Continuum_hypothesis}

The [cardinality](wikipedia://en/6174) of the set of [real numbers](wikipedia://en/20646438) ([cardinality of the continuum](wikipedia://en/1574901)) is 2<sup>$\aleph_0$</sup>. It cannot be determined from [ZFC](https://en.wikipedia.org/wiki/ZFC) ([Zermelo–Fraenkel set theory](wikipedia://en/152214) augmented with the [axiom of choice](wikipedia://en/840)) where this number fits exactly in the aleph number hierarchy, but it follows from ZFC that the continuum hypothesis (CH) is equivalent to the identity

$2^{\aleph_0} = \aleph_1$.[^o13]

The CH states that there is no set whose cardinality is strictly between that of the natural numbers and the real numbers.[^o14] CH is independent of ZFC: It can be neither proven nor disproven within the context of that axiom system (provided that ZFC is [consistent](wikipedia://en/75802)). That CH is consistent with ZFC was demonstrated by [Kurt Gödel](wikipedia://en/16736) in 1940, when he showed that its negation is not a theorem of ZFC. That it is independent of ZFC was demonstrated by [Paul Cohen](wikipedia://en/22994) in 1963, when he showed conversely that the CH itself is not a theorem of ZFC, using the (then-novel) method of [forcing](wikipedia://en/152205).[^o13][^o15]

:::

## Aleph-omega {#Aleph-omega}

Aleph-omega is $\aleph_\omega = \aleph_n ^ {n \in \omega} = \aleph_n ^ {n \in \{0, 1, 2,\cdots\}}$ where the smallest infinite ordinal is denoted as $\omega$. That is, the cardinal number $\aleph_\omega$ is the [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) of $\aleph_n ^ {n \in \{0, 1, 2,\cdots\}}$.

Notably, $\aleph_\omega$ is the first uncountable cardinal number that can be demonstrated within Zermelo–Fraenkel set theory *not* to be equal to the cardinality of the set of all [real numbers](wikipedia://en/20646438) $2^{\aleph_0}$: For any natural number $n \ge 1$, we can consistently assume that $2^{\aleph_0} = \aleph_n$, and moreover it is possible to assume that $2^{\aleph_0}$ is at least as large as any cardinal number we like. The main restriction ZFC puts on the value of $2^{\aleph_0}$ is that it cannot equal certain special cardinals with [cofinality](wikipedia://en/6693) $\aleph_0$. An uncountably infinite cardinal $\kappa$ having cofinality $\aleph_0$ means that there is a (countable-length) sequence $\kappa_0 \le \kappa_1 \le \kappa_2 \le \cdots$ of cardinals $\kappa_i < \kappa$ whose limit (i.e. its least upper bound) is $\kappa$ (see [Easton's theorem](wikipedia://en/4691250)). As per the definition above, $\aleph_\omega$ is the limit of a countable-length sequence of smaller cardinals.

:::

## Aleph-*α* for general *α* {#Aleph-α_for_general_α}

To define $\aleph_\alpha$ for arbitrary ordinal number $\alpha$, we must define the [successor cardinal operation](wikipedia://en/375210), which assigns to any cardinal number $\rho$ the next larger [well-ordered](wikipedia://en/33456) cardinal $\rho^{+}$ (if the [axiom of choice](wikipedia://en/840) holds, this is the (unique) next larger cardinal).

We can then define the aleph numbers as follows:

$$\aleph_0 = \omega$$

$$\aleph_{\alpha+1} = (\aleph_{\alpha})^{+}$$

$\aleph_{\lambda} = \bigcup\{\aleph_\alpha | \alpha < \lambda\}$ for $\lambda$ an infinite [limit ordinal](wikipedia://en/373137),

The $\alpha$-th infinite [initial ordinal](https://en.wikipedia.org/wiki/Initial_ordinal) is written $\omega_\alpha$. Its cardinality is written $\aleph_\alpha$.

Alternatively, for every infinite cardinal $\kappa$ that can be well ordered, an index can be defined as the ordinal of the well ordered set of all infinite cardinals that precede $\kappa$. Then it can be proved by transfinite induction that if $\alpha$ in the index of $\kappa$ then $\kappa=\aleph_\alpha$

Informally, the **aleph function** $\aleph : \text{On} \rightarrow \text{Cd}$ is a bijection from the ordinals to the infinite cardinals that can be well ordered. Formally, in [ZFC](https://en.wikipedia.org/wiki/ZFC), $\aleph$ is *not a function*, but a function-like class, as it is not a set (due to the [Burali-Forti paradox](wikipedia://en/51653)).

:::

## Fixed points of omega {#Fixed_points_of_omega}

For any ordinal $\alpha$ we have $\alpha \le \omega_\alpha$.

In many cases $\omega_\alpha$ is strictly greater than *α*. For example, it is true for any successor [ordinal](wikipedia://en/26547932): $\alpha + 1 \le \omega_{\alpha} < \omega_{\alpha+1}$ holds. There are, however, some limit ordinals that are [fixed points](wikipedia://en/449738) of the omega function, because of the [fixed-point lemma for normal functions](wikipedia://en/404343). The first such is the limit of the sequence

$$\omega, \omega_{\omega}, \omega_{\omega_{\omega}}, \cdots$$

which is sometimes denoted $\omega_{\omega_{\ddots}}$.

Any [weakly inaccessible cardinal](wikipedia://en/248076) is also a fixed point of the aleph function.[^o21] This can be shown in ZFC as follows. Suppose $\kappa = \aleph_{\lambda}$ is a weakly inaccessible cardinal. If $\lambda$ were a [successor ordinal](wikipedia://en/375256), then $\aleph_{\lambda}$ would be a [successor cardinal](wikipedia://en/375210) and hence not weakly inaccessible. If $\lambda$ were a [limit ordinal](wikipedia://en/373137) less than $\kappa$ then its [cofinality](wikipedia://en/6693) (and thus the cofinality of $\aleph_\lambda$) would be less than $\kappa$ and so $\kappa$ would not be regular and thus not weakly inaccessible. Thus $\lambda \ge \kappa$ and consequently $\lambda = \kappa$, which makes it a fixed point.

::: {#o23 .statement kind=statement/axiom cue=named-heading name="Role of axiom of choice"}

## Role of axiom of choice {#Role_of_axiom_of_choice}

The cardinality of any infinite [ordinal number](wikipedia://en/26547932) is an aleph number. Every aleph is the cardinality of some ordinal. The least of these is its [initial ordinal](https://en.wikipedia.org/wiki/Initial_ordinal). Any set whose cardinality is an aleph is [equinumerous](https://en.wikipedia.org/wiki/Equinumerous) with an ordinal and is thus [well-orderable](wikipedia://en/33456).

Each [finite set](wikipedia://en/11742) is well-orderable, but does not have an aleph as its cardinality.

Over ZF, the assumption that the cardinality of each [infinite set](wikipedia://en/142679) is an aleph number is equivalent to the existence of a well-ordering of every set, which in turn is equivalent to the [axiom of choice](wikipedia://en/840). ZFC set theory, which includes the axiom of choice, implies that every infinite set has an aleph number as its cardinality (i.e. is equinumerous with its initial ordinal), and thus the initial ordinals of the aleph numbers serve as a class of representatives for all possible infinite cardinal numbers.

When cardinality is studied in ZF without the axiom of choice, it is no longer possible to prove that each infinite set has some aleph number as its cardinality; the sets whose cardinality is an aleph number are exactly the infinite sets that can be well-ordered. The method of [Scott's trick](wikipedia://en/22077085) is sometimes used as an alternative way to construct representatives for cardinal numbers in the setting of ZF. For example, one can define $\text{card}(S)$ to be the set of sets with the same cardinality as $S$ of minimum possible rank. This has the property that $\text{card}(S) = \text{card}(T)$ if and only if $S$ and $T$ have the same cardinality. (The set $\text{card}(S)$ does not have the same cardinality of $S$ in general, but all its elements do.)

:::
