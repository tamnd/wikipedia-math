# Seminorm

::: {#o1 .subject cue=lead name="Seminorm"}

In [mathematics](wikipedia://en/18831), particularly in [functional analysis](wikipedia://en/11180), a **seminorm** is like a [norm](wikipedia://en/990534) but need not be [positive definite](https://en.wikipedia.org/wiki/Positive_definite). Seminorms are intimately connected with [convex sets](wikipedia://en/6292): every seminorm is the [Minkowski functional](wikipedia://en/3510908) of some [absorbing](wikipedia://en/1728179) [disk](wikipedia://en/1734292) and, conversely, the Minkowski functional of any such set is a seminorm.

:::

A [topological vector space](wikipedia://en/45752) is locally convex if and only if its topology is induced by a family of seminorms.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a vector space over either the [real numbers](wikipedia://en/20646438) $\mathbb{R}$ or the [complex](wikipedia://en/5826) numbers $\mathbb{C}.$ A [real-valued function](wikipedia://en/22284647) $p : X \to \mathbb{R}$ is called a seminorm if it satisfies the following two conditions:

1. [Subadditivity](https://en.wikipedia.org/wiki/Subadditive_function)[^n1]/[Triangle inequality](wikipedia://en/53941): $p(x + y) \leq p(x) + p(y)$ for all $x, y \in X.$
1. [Absolute homogeneity](wikipedia://en/622844):[^n1] $p(s x) =|s|p(x)$ for all $x \in X$ and all scalars $s.$

These two conditions imply that $p(0) = 0$[^o6] and that every seminorm $p$ also has the following property:[^o7]

[Nonnegativity](https://en.wikipedia.org/wiki/Nonnegative):[^n1] $p(x) \geq 0$ for all $x \in X.$

Some authors include non-negativity as part of the definition of "seminorm" (and also sometimes of "norm"), although this is not necessary since it follows from the other two properties.

By definition, a [norm](wikipedia://en/990534) on $X$ is a seminorm that also separates points, meaning that it has the following additional property:

[Positive definite](https://en.wikipedia.org/wiki/Positive_definite)/Positive[^n1]/Point-separating: whenever $x \in X$ satisfies $p(x) = 0,$ then $x = 0.$

A seminormed space is a pair $(X, p)$ consisting of a vector space $X$ and a seminorm $p$ on $X.$ If the seminorm $p$ is also a norm then the seminormed space $(X, p)$ is called a [normed space](https://en.wikipedia.org/wiki/Normed_space).

Since absolute homogeneity implies positive homogeneity, every seminorm is a type of function called a [sublinear function](wikipedia://en/1750541). A map $p : X \to \mathbb{R}$ is called a [sublinear function](wikipedia://en/1750541) if it is subadditive and [positive homogeneous](https://en.wikipedia.org/wiki/Positive_homogeneous). Unlike a seminorm, a sublinear function is not necessarily nonnegative. Sublinear functions are often encountered in the context of the [Hahn–Banach theorem](wikipedia://en/13860). A real-valued function $p : X \to \mathbb{R}$ is a seminorm if and only if it is a [sublinear](wikipedia://en/1750541) and [balanced function](https://en.wikipedia.org/wiki/Balanced_function).

## Examples {#Examples}

The trivial seminorm on $X,$ which refers to the constant $0$ map on $X,$ induces the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology) on $X.$ Let $\mu$ be a measure on a space $\Omega$. For an arbitrary constant $c \geq 1$, let $X$ be the set of all functions $f: \Omega \rightarrow \mathbb{R}$ for which

$$\lVert f \rVert_c := \left( \int_{\Omega}| f |^c \, d\mu \right)^{1/c}$$

exists and is finite. It can be shown that $X$ is a vector space, and the functional $\lVert \cdot \rVert_c$ is a seminorm on $X$. However, it is not always a norm (e.g. if $\Omega = \mathbb{R}$ and $\mu$ is the [Lebesgue measure](wikipedia://en/18198)) because $\lVert h \rVert_c = 0$ does not always imply $h = 0$. To make $\lVert \cdot \rVert_c$ a norm, quotient $X$ by the closed subspace of functions $h$ with $\lVert h \rVert_c = 0$. The [resulting space](wikipedia://en/45194#Lp_spaces_and_Lebesgue_integrals), $L^c(\mu)$, has a norm induced by $\lVert \cdot \rVert_c$. If $f$ is any [linear form](wikipedia://en/214137) on a vector space then its [absolute value](wikipedia://en/991) $|f|,$ defined by $x \mapsto |f(x)|,$ is a seminorm. A [sublinear function](wikipedia://en/1750541) $f : X \to \mathbb{R}$ on a real vector space $X$ is a seminorm if and only if it is a symmetric function, meaning that $f(-x) = f(x)$ for all $x \in X.$ Every real-valued [sublinear function](wikipedia://en/1750541) $f : X \to \mathbb{R}$ on a real vector space $X$ induces a seminorm $p : X \to \mathbb{R}$ defined by $p(x) := \max \{f(x), f(-x)\}.$[^n2] Any finite sum of seminorms is a seminorm. The restriction of a seminorm (respectively, norm) to a [vector subspace](https://en.wikipedia.org/wiki/Vector_subspace) is once again a seminorm (respectively, norm). If $p : X \to \mathbb{R}$ and $q : Y \to \mathbb{R}$ are seminorms (respectively, norms) on $X$ and $Y$ then the map $r : X \times Y \to \mathbb{R}$ defined by $r(x, y) = p(x) + q(y)$ is a seminorm (respectively, a norm) on $X \times Y.$ In particular, the maps on $X \times Y$ defined by $(x, y) \mapsto p(x)$ and $(x, y) \mapsto q(y)$ are both seminorms on $X \times Y.$ If $p$ and $q$ are seminorms on $X$ then so are[^n3]

$$(p \vee q)(x) = \max \{p(x), q(x)\}$$

and

$$(p \wedge q)(x) := \inf \{p(y) + q(z) : x = y + z \text{ with } y, z \in X\}$$

where $p \wedge q \leq p$ and $p \wedge q \leq q.$[^n4]

The space of seminorms on $X$ is generally not a [distributive lattice](wikipedia://en/310883) with respect to the above operations. For example, over $\mathbb{R}^2$, $p(x, y) := \max(|x|, |y|), q(x, y) := 2|x|, r(x, y) := 2|y|$ are such that

$$((p \vee q) \wedge (p \vee r)) (x, y) = \inf \{\max(2|x_1|, |y_1|) + \max(|x_2|, 2|y_2|) : x = x_1 + x_2 \text{ and } y = y_1 + y_2\}$$

while $(p \vee q \wedge r) (x, y) := \max(|x|, |y|)$ If $L : X \to Y$ is a [linear map](wikipedia://en/18102) and $q : Y \to \mathbb{R}$ is a seminorm on $Y,$ then $q \circ L : X \to \mathbb{R}$ is a seminorm on $X.$ The seminorm $q \circ L$ will be a norm on $X$ if and only if $L$ is injective and the restriction $q\big\vert_{L(X)}$ is a norm on $L(X).$

:::

## Minkowski functionals and seminorms {#Minkowski_functionals_and_seminorms}

Seminorms on a vector space $X$ are intimately tied, via Minkowski functionals, to subsets of $X$ that are [convex](wikipedia://en/6292), [balanced](wikipedia://en/1734238), and [absorbing](wikipedia://en/1728179). Given such a subset $D$ of $X,$ the Minkowski functional of $D$ is a seminorm. Conversely, given a seminorm $p$ on $X,$ the sets$\{x \in X : p(x) < 1\}$ and $\{x \in X : p(x) \leq 1\}$ are convex, balanced, and absorbing and furthermore, the Minkowski functional of these two sets (as well as of any set lying "in between them") is $p.$[^n5]

::: {#o18 .statement kind=statement/fact cue=heading name="Algebraic properties"}

## Algebraic properties {#Algebraic_properties}

Every seminorm is a [sublinear function](wikipedia://en/1750541), and thus satisfies all [properties of a sublinear function](wikipedia://en/1750541#Properties), including [convexity](wikipedia://en/245568), $p(0) = 0,$ and for all vectors $x, y \in X$: the [reverse triangle inequality](https://en.wikipedia.org/wiki/Reverse_triangle_inequality): [^n6][^n7]

$$|p(x) - p(y)| \leq p(x - y)$$

and also $0 \leq \max \{p(x), p(-x)\}$ and $p(x) - p(y) \leq p(x - y).$[^n6][^n7]

For any vector $x \in X$ and positive real $r > 0:$[^n8]

$$x + \{y \in X : p(y) < r\} = \{y \in X : p(x - y) < r\}$$

and furthermore, $\{x \in X : p(x) < r\}$ is an [absorbing](wikipedia://en/1728179) [disk](wikipedia://en/1734292) in $X.$[^n3]

If $p$ is a sublinear function on a real vector space $X$ then there exists a linear functional $f$ on $X$ such that $f \leq p$[^n7] and furthermore, for any linear functional $g$ on $X,$ $g \leq p$ on $X$ if and only if $g^{-1}(1) \cap \{x \in X : p(x) < 1\} = \varnothing.$[^n7]

**Other properties of seminorms**

Every seminorm is a [balanced function](https://en.wikipedia.org/wiki/Balanced_function). A seminorm $p$ is a norm on $X$ if and only if $\{x \in X : p(x) < 1\}$ does not contain a non-trivial vector subspace.

If $p : X \to [0, \infty)$ is a seminorm on $X$ then $\ker p := p^{-1}(0)$ is a vector subspace of $X$ and for every $x \in X,$ $p$ is constant on the set $x + \ker p = \{x + k : p(k) = 0\}$ and equal to $p(x).$[^o27]

Furthermore, for any real $r > 0,$[^n3]

$$r \{x \in X : p(x) < 1\} = \{x \in X : p(x) < r\} = \left\{x \in X : \tfrac{1}{r} p(x) < 1 \right\}.$$

If $D$ is a set satisfying $\{x \in X : p(x) < 1\} \subseteq D \subseteq \{x \in X : p(x) \leq 1\}$ then $D$ is [absorbing](wikipedia://en/1728179) in $X$ and $p = p_D$ where $p_D$ denotes the [Minkowski functional](wikipedia://en/3510908) associated with $D$ (that is, the gauge of $D$).[^n5] In particular, if $D$ is as above and $q$ is any seminorm on $X,$ then $q = p$ if and only if $\{x \in X : q(x) < 1\} \subseteq D \subseteq \{x \in X : q(x) \leq\}.$[^n5]

If $(X, \|\,\cdot\,\|)$ is a normed space and $x, y \in X$ then $\|x - y\| = \|x - z\| + \|z - y\|$ for all $z$ in the interval $[x, y].$[^n9]

Every norm is a [convex function](wikipedia://en/245568) and consequently, finding a global maximum of a norm-based [objective function](https://en.wikipedia.org/wiki/Objective_function) is sometimes tractable.

### Relationship to other norm-like concepts {#Relationship_to_other_norm-like_concepts}

Let $p : X \to \mathbb{R}$ be a non-negative function. The following are equivalent:

$p$ is a seminorm. $p$ is a [convex](wikipedia://en/245568) [$F$-seminorm](https://en.wikipedia.org/wiki/F-seminorm). $p$ is a convex balanced [*G*-seminorm](wikipedia://en/64278078).[^n10]

If any of the above conditions hold, then the following are equivalent:

$p$ is a norm; $\{x \in X : p(x) < 1\}$ does not contain a non-trivial vector subspace.[^n11] There exists a [norm](wikipedia://en/21538) on $X,$ with respect to which, $\{x \in X : p(x) < 1\}$ is bounded.

If $p$ is a sublinear function on a real vector space $X$ then the following are equivalent:[^n7]

$p$ is a [linear functional](https://en.wikipedia.org/wiki/Linear_functional); $p(x) + p(-x) \leq 0 \text{ for every } x \in X$; $p(x) + p(-x) = 0 \text{ for every } x \in X$;

### Inequalities involving seminorms {#Inequalities_involving_seminorms}

If $p, q : X \to [0, \infty)$ are seminorms on $X$ then:

$p \leq q$ if and only if $q(x) \leq 1$ implies $p(x) \leq 1.$[^n12] If $a > 0$ and $b > 0$ are such that $p(x) < a$ implies $q(x) \leq b,$ then $a q(x) \leq b p(x)$ for all $x \in X.$ [^n13] Suppose $a$ and $b$ are positive real numbers and $q, p_1, \ldots, p_n$ are seminorms on $X$ such that for every $x \in X,$ if $\max \{p_1(x), \ldots, p_n(x)\} < a$ then $q(x) < b.$ Then $a q \leq b \left(p_1 + \cdots + p_n\right).$[^n11] If $X$ is a vector space over the reals and $f$ is a non-zero linear functional on $X,$ then $f \leq p$ if and only if $\varnothing = f^{-1}(1) \cap \{x \in X : p(x) < 1\}.$[^n12]

If $p$ is a seminorm on $X$ and $f$ is a linear functional on $X$ then:

$|f| \leq p$ on $X$ if and only if $\operatorname{Re} f \leq p$ on $X$ (see footnote for proof).[^o41][^n14] $f \leq p$ on $X$ if and only if $f^{-1}(1) \cap \{x \in X : p(x) < 1 = \varnothing\}.$[^n7][^n12] If $a > 0$ and $b > 0$ are such that $p(x) < a$ implies $f(x) \neq b,$ then $a |f(x)| \leq b p(x)$ for all $x \in X.$[^n13]

### Hahn–Banach theorem for seminorms {#Hahn–Banach_theorem_for_seminorms}

Seminorms offer a particularly clean formulation of the [Hahn–Banach theorem](wikipedia://en/13860):

If $M$ is a vector subspace of a seminormed space $(X, p)$ and if $f$ is a continuous linear functional on $M,$ then $f$ may be extended to a continuous linear functional $F$ on $X$ that has the same norm as $f.$[^n15]

A similar extension property also holds for seminorms:

::: {#o51 .statement kind=statement/theorem cue=math-theorem name="Theorem (Extending seminorms)"}

**Theorem[^n16][^n13] (Extending seminorms).**

If $M$ is a vector subspace of $X,$ $p$ is a seminorm on $M,$ and $q$ is a seminorm on $X$ such that $p \leq q\big\vert_M,$ then there exists a seminorm $P$ on $X$ such that $P\big\vert_M = p$ and $P \leq q.$

:::

**Proof**: Let $S$ be the [convex hull](wikipedia://en/40634) of $\{m \in M : p(m) \leq 1\} \cup \{x \in X : q(x) \leq 1\}.$ Then $S$ is an [absorbing](wikipedia://en/1728179) [disk](wikipedia://en/1734292) in $X$ and so the [Minkowski functional](wikipedia://en/3510908) $P$ of $S$ is a seminorm on $X.$ This seminorm satisfies $p = P$ on $M$ and $P \leq q$ on $X.$ $\blacksquare$

:::

## Topologies of seminormed spaces {#Topologies_of_seminormed_spaces}

### Pseudometrics and the induced topology {#Pseudometrics_and_the_induced_topology}

A seminorm $p$ on $X$ induces a topology, called the seminorm-induced topology, via the canonical [translation-invariant](https://en.wikipedia.org/wiki/Translation-invariant) [pseudometric](wikipedia://en/68503) $d_p : X \times X \to \mathbb{R}$; $d_p(x, y) := p(x - y) = p(y - x).$ This topology is [Hausdorff](wikipedia://en/13637) if and only if $d_p$ is a metric, which occurs if and only if $p$ is a [norm](wikipedia://en/990534).[^n4] This topology makes $X$ into a [locally convex](wikipedia://en/518844) [pseudometrizable](wikipedia://en/64278078) [topological vector space](wikipedia://en/45752) that has a [bounded](wikipedia://en/1789812) neighborhood of the origin and a [neighborhood basis](https://en.wikipedia.org/wiki/Neighborhood_basis) at the origin consisting of the following open balls (or the closed balls) centered at the origin:

$$\{x \in X : p(x) < r\} \quad \text{ or } \quad \{x \in X : p(x) \leq r\}$$

as $r > 0$ ranges over the positive reals. Every seminormed space $(X, p)$ should be assumed to be endowed with this topology unless indicated otherwise. A topological vector space whose topology is induced by some seminorm is called seminormable.

Equivalently, every vector space $X$ with seminorm $p$ induces a [vector space quotient](wikipedia://en/898784) $X / W,$ where $W$ is the subspace of $X$ consisting of all vectors $x \in X$ with $p(x) = 0.$ Then $X / W$ carries a norm defined by $p(x + W) = p(x).$ The resulting topology, [pulled back](wikipedia://en/9413508) to $X,$ is precisely the topology induced by $p.$

Any seminorm-induced topology makes $X$ [locally convex](wikipedia://en/518844), as follows. If $p$ is a seminorm on $X$ and $r \in \mathbb{R},$ call the set $\{x \in X : p(x) < r\}$ the open ball of radius $r$ about the origin; likewise the closed ball of radius $r$ is $\{x \in X : p(x) \leq r\}.$ The set of all open (resp. closed) $p$-balls at the origin forms a neighborhood basis of [convex](wikipedia://en/6292) [balanced](wikipedia://en/1734238) sets that are open (resp. closed) in the $p$-topology on $X.$

#### Stronger, weaker, and equivalent seminorms {#Stronger,_weaker,_and_equivalent_seminorms}

The notions of stronger and weaker seminorms are akin to the notions of stronger and weaker [norms](wikipedia://en/990534). If $p$ and $q$ are seminorms on $X,$ then we say that $q$ is stronger than $p$ and that $p$ is weaker than $q$ if any of the following equivalent conditions holds:

1. The topology on $X$ induced by $q$ is finer than the topology induced by $p.$
1. If $x_{\bullet} = \left(x_i\right)_{i=1}^{\infty}$ is a sequence in $X,$ then $q\left(x_{\bullet}\right) := \left(q\left(x_i\right)\right)_{i=1}^{\infty} \to 0$ in $\mathbb{R}$ implies $p\left(x_{\bullet}\right) \to 0$ in $\mathbb{R}.$[^n4]
1. If $x_{\bullet} = \left(x_i\right)_{i \in I}$ is a [net](wikipedia://en/22170) in $X,$ then $q\left(x_{\bullet}\right) := \left(q\left(x_i\right)\right)_{i \in I} \to 0$ in $\mathbb{R}$ implies $p\left(x_{\bullet}\right) \to 0$ in $\mathbb{R}.$
1. $p$ is bounded on $\{x \in X : q(x) < 1\}.$[^n4]
1. If $\inf{} \{q(x) : p(x) = 1, x \in X\} = 0$ then $p(x) = 0$ for all $x \in X.$[^n4]
1. There exists a real $K > 0$ such that $p \leq K q$ on $X.$[^n4]

The seminorms $p$ and $q$ are called equivalent if they are both weaker (or both stronger) than each other. This happens if they satisfy any of the following conditions:

The topology on $X$ induced by $q$ is the same as the topology induced by $p.$ $q$ is stronger than $p$ and $p$ is stronger than $q.$[^n4] If $x_{\bullet} = \left(x_i\right)_{i=1}^{\infty}$ is a sequence in $X$ then $q\left(x_{\bullet}\right) := \left(q\left(x_i\right)\right)_{i=1}^{\infty} \to 0$ if and only if $p\left(x_{\bullet}\right) \to 0.$ There exist positive real numbers $r > 0$ and $R > 0$ such that $r q \leq p \leq R q.$

### Normability and seminormability {#Normability_and_seminormability}

A topological vector space (TVS) is said to be a seminormable space (respectively, a normable space) if its topology is induced by a single seminorm (resp. a single norm). A TVS is normable if and only if it is seminormable and Hausdorff or equivalently, if and only if it is seminormable and [T<sub>1</sub>](wikipedia://en/148721) (because a TVS is Hausdorff if and only if it is a [T<sub>1</sub> space](wikipedia://en/148721)). A **locally bounded topological vector space** is a topological vector space that possesses a bounded neighborhood of the origin.

Normability of [topological vector spaces](wikipedia://en/45752) is characterized by [Kolmogorov's normability criterion](wikipedia://en/55284288). A TVS is seminormable if and only if it has a convex bounded neighborhood of the origin.[^n17] Thus a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) TVS is seminormable if and only if it has a non-empty bounded open set.[^n18] A TVS is normable if and only if it is a [T<sub>1</sub> space](wikipedia://en/148721) and admits a bounded convex neighborhood of the origin.

If $X$ is a Hausdorff [locally convex](https://en.wikipedia.org/wiki/Locally_convex) TVS then the following are equivalent:

$X$ is normable. $X$ is seminormable. $X$ has a bounded neighborhood of the origin. The [strong dual](https://en.wikipedia.org/wiki/Strong_dual) $X^{\prime}_b$ of $X$ is normable.[^n19] The strong dual $X^{\prime}_b$ of $X$ is [metrizable](wikipedia://en/64278078).[^n19]

Furthermore, $X$ is finite dimensional if and only if $X^{\prime}_{\sigma}$ is normable (here $X^{\prime}_{\sigma}$ denotes $X^{\prime}$ endowed with the [weak-\* topology](https://en.wikipedia.org/wiki/Weak-*_topology)).

The product of infinitely many seminormable space is again seminormable if and only if all but finitely many of these spaces trivial (that is, 0-dimensional).[^n20]

### Topological properties {#Topological_properties}

If $X$ is a TVS and $p$ is a continuous seminorm on $X,$ then the closure of $\{x \in X : p(x) < r\}$ in $X$ is equal to $\{x \in X : p(x) \leq r\}.$[^n3] The closure of $\{0\}$ in a locally convex space $X$ whose topology is defined by a family of continuous seminorms $\mathcal{P}$ is equal to $\bigcap_{p \in \mathcal{P}} p^{-1}(0).$[^n21] A subset $S$ in a seminormed space $(X, p)$ is [bounded](wikipedia://en/1789812) if and only if $p(S)$ is bounded.[^n22] If $(X, p)$ is a seminormed space then the locally convex topology that $p$ induces on $X$ makes $X$ into a [pseudometrizable TVS](wikipedia://en/64278078) with a canonical pseudometric given by $d(x, y) := p(x - y)$ for all $x, y \in X.$[^n23] The product of infinitely many seminormable spaces is again seminormable if and only if all but finitely many of these spaces are trivial (that is, 0-dimensional).[^n20]

### Continuity of seminorms {#Continuity_of_seminorms}

If $p$ is a seminorm on a topological vector space $X,$ then the following are equivalent:[^n5]

$p$ is continuous. $p$ is continuous at 0;[^n3] $\{x \in X : p(x) < 1\}$ is open in $X$;[^n3] $\{x \in X : p(x) \leq 1\}$ is closed neighborhood of 0 in $X$;[^n3] $p$ is uniformly continuous on $X$;[^n3] There exists a continuous seminorm $q$ on $X$ such that $p \leq q.$[^n3]

In particular, if $(X, p)$ is a seminormed space then a seminorm $q$ on $X$ is continuous if and only if $q$ is dominated by a positive scalar multiple of $p.$[^n3]

If $X$ is a real TVS, $f$ is a linear functional on $X,$ and $p$ is a continuous seminorm (or more generally, a sublinear function) on $X,$ then $f \leq p$ on $X$ implies that $f$ is continuous.[^n7]

### Continuity of linear maps {#Continuity_of_linear_maps}

If $F : (X, p) \to (Y, q)$ is a map between seminormed spaces then let[^n15]

$$\|F\|_{p,q} := \sup \{q(F(x)) : p(x) \leq 1, x \in X\}.$$

If $F : (X, p) \to (Y, q)$ is a linear map between seminormed spaces then the following are equivalent:

$F$ is continuous; $\|F\|_{p,q} < \infty$;[^n15] There exists a real $K \geq 0$ such that $p \leq K q$;[^n15]

In this case, $\|F\|_{p,q} \leq K.$

If $F$ is continuous then $q(F(x)) \leq \|F\|_{p,q} p(x)$ for all $x \in X.$[^n15]

The space of all continuous linear maps $F : (X, p) \to (Y, q)$ between seminormed spaces is itself a seminormed space under the seminorm $\|F\|_{p,q}.$ This seminorm is a norm if $q$ is a norm.[^n15]

## Generalizations {#Generalizations}

The concept of norm in [composition algebras](wikipedia://en/3861635) does not share the usual properties of a norm.

A composition algebra $(A, *, N)$ consists of an [algebra over a field](wikipedia://en/191788) $A,$ an [involution](wikipedia://en/293450) $\,*,$ and a [quadratic form](wikipedia://en/251478) $N,$ which is called the "norm". In several cases $N$ is an [isotropic quadratic form](wikipedia://en/10917170) so that $A$ has at least one [null vector](wikipedia://en/1453977), contrary to the separation of points required for the usual norm discussed in this article.

An ultraseminorm or a non-Archimedean seminorm is a seminorm $p : X \to \mathbb{R}$ that also satisfies $p(x + y) \leq \max \{p(x), p(y)\} \text{ for all } x, y \in X.$

**Weakening subadditivity: Quasi-seminorms**

A map $p : X \to \mathbb{R}$ is called a [quasi-seminorm](wikipedia://en/6652599) if it is (absolutely) homogeneous and there exists some $b \leq 1$ such that $p(x + y) \leq b p(p(x) + p(y)) \text{ for all } x, y \in X.$ The smallest value of $b$ for which this holds is called the multiplier of $p.$

A quasi-seminorm that separates points is called a quasi-norm on $X.$

**Weakening homogeneity - $k$-seminorms**

A map $p : X \to \mathbb{R}$ is called a $k$-seminorm if it is subadditive and there exists a $k$ such that $0 < k \leq 1$ and for all $x \in X$ and scalars $s,$

$$p(s x) = |s|^k p(x)$$

A $k$-seminorm that separates points is called a $k$-norm on $X.$
