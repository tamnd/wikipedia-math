# ISAAC (cipher)

::: {#o1 .subject cue=lead name="ISAAC"}

**ISAAC** (**indirection, shift, accumulate, add, and count**) is a [cryptographically secure pseudorandom number generator](wikipedia://en/182249) and a [stream cipher](wikipedia://en/49007) designed by [Robert J. Jenkins Jr.](https://en.wikipedia.org/wiki/Robert_John_Jenkins_Junior) in 1993.[^o2] The [reference implementation](https://en.wikipedia.org/wiki/Reference_implementation) [source code](https://en.wikipedia.org/wiki/Source_code) was dedicated to the [public domain](https://en.wikipedia.org/wiki/Public_domain).[^o3]

:::

"I developed (...) tests to break a generator, and I developed the generator to pass the tests. The generator is ISAAC."[^o4]

## Operation {#Operation}

The ISAAC [algorithm](wikipedia://en/775) has similarities with [RC4](wikipedia://en/25831). It uses an [array](https://en.wikipedia.org/wiki/Array_data_structure) of 256 four-octet [integers](https://en.wikipedia.org/wiki/Integer_%28computer_science%29) as the internal state, writing the results to another 256 four-octet integer array, from which they are read one at a time until empty, at which point they are recomputed. The computation consists of altering *i*-element with (*i*⊕128)-element, two elements of the state array found by indirection, an accumulator, and a counter, for all values of *i* from 0 to 255. Since it only takes about 19 32-bit operations for each 32-bit output word, it is very fast on 32-bit computers.

## Cryptanalysis {#Cryptanalysis}

[Cryptanalysis](wikipedia://en/5715) has been undertaken by Marina Pudovkina (2001).[^o7] Her attack can recover the initial state with a complexity that is approximated to be less than the time needed for searching through the square root of all possible initial states. In practice this means that the attack needs $4.67 \times 10^{1240}$ instead of $10^{2466}$. This result has had no practical impact on the security of ISAAC.[^o8]

In 2006 Jean-Philippe Aumasson discovered several sets of weak states.[^o9] The fourth presented (and smallest) set of weak states leads to a highly biased output for the first round of ISAAC and allows the derivation of the internal state, similar to a [weakness in RC4](wikipedia://en/10461532). It is not clear if an attacker can tell from just the output whether the generator is in one of these weak states or not. He also shows that a previous attack[^o10] is flawed, since the [Paul](https://en.wikipedia.org/wiki/Souradyuti_Paul)-[Preneel](wikipedia://en/1520490) attack is based on an erroneous algorithm rather than the real ISAAC. An improved version of ISAAC is proposed, called ISAAC+.[^o8]

## Usage outside cryptography {#Usage_outside_cryptography}

Many implementations of ISAAC are so fast that they can compete with other high speed PRNGs, even with those designed primarily for speed not for security. Only a few other generators of such high quality and speed exist in usage. ISAAC is used in the Unix tool [shred](https://en.wikipedia.org/wiki/Shred_%28Unix%29) to securely overwrite data.[^o12]

Also, ISAAC algorithm is implemented in Java Apache Commons Math library,[^o13] and in [NetHack](https://en.wikipedia.org/wiki/NetHack) for its RNG.[^o14]
