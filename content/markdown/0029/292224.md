# Topologist's sine curve

*Image: Topologist's sine curve.svg.* As *x* approaches zero from the right, the magnitude of the rate of change of 1/*x* increases. This is why the frequency of the sine wave increases as one moves to the left in the graph.

::: {#o1 .subject cue=lead name="Topologist's sine curve"}

In the branch of [mathematics](wikipedia://en/18831) known as [topology](wikipedia://en/29954), the **topologist's sine curve** or **Warsaw sine curve** is a [topological space](wikipedia://en/30450) with several interesting properties that make it an important textbook example.

:::

It can be defined as the [graph](wikipedia://en/87352) of the function $\sin \tfrac {1}{x}$ on the [half-open interval](https://en.wikipedia.org/wiki/Half-open_interval) $( 0 , 1 ]$, together with the origin, under the topology [induced](wikipedia://en/910926) from the [Euclidean plane](wikipedia://en/15575410):

$$T = \left\{ \left( x, \sin \tfrac{1}{x} \right ) : x \in (0,1] \right\} \cup \{(0,0)\}.$$

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The topologist's sine curve $T$ is [connected](wikipedia://en/6233) but neither [locally connected](wikipedia://en/6959754) nor [path connected](wikipedia://en/6233#Path_connectedness). This is because it includes the point $(0, 0)$ but there is no way to link the function to the origin so as to make a [path](wikipedia://en/1189553) since the oscillations increase at that point (i.e. the topologist's sine curve is discontinuous at $(0, 0)$).

The space $T$ is the continuous image of a [locally compact](https://en.wikipedia.org/wiki/Locally_compact) space (namely, let $V$ be the space $\{-1\} \cup (0, 1],$ and use the map $f : V \to T$ defined by $f(-1) = (0,0)$ and $f(x) = (x, \sin\tfrac{1}{x})$ for $x > 0$), but $T$ is not locally compact itself.

The [topological dimension](https://en.wikipedia.org/wiki/Topological_dimension) of $T$ is 1.

:::

::: {#o5 .statement kind=statement/generalization cue=heading name="Variants"}

## Variants {#Variants}

Two variants of the topologist's sine curve have other interesting properties:

- The *closed* topologist's sine curve can be defined by taking the topologist's sine curve and adding its set of [limit points](https://en.wikipedia.org/wiki/Limit_point), $\{(0,y)\mid y\in[-1,1]\}$; some texts define the topologist's sine curve itself as this closed version, as they prefer to use the term 'closed topologist's sine curve' to refer to another curve.[^o6] This space is closed and bounded and so [compact](wikipedia://en/6042) by the [Heine–Borel theorem](wikipedia://en/59595), but has similar properties to the topologist's sine curve—it too is connected but neither locally connected nor path-connected.
- The *extended* topologist's sine curve can be defined by taking the closed topologist's sine curve and adding to it the set $\{(x,1) \mid x\in[0,1]\}$. This variant is [arc connected](https://en.wikipedia.org/wiki/Arc_connected) but not [locally connected](wikipedia://en/6959754).

:::
