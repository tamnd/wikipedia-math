# P-adic analysis

::: {#o1 .subject cue=lead name="P-adic analysis"}

*Image: 3-adic integers with dual colorings.svg.* The 3-adic integers, with selected corresponding characters on their [Pontryagin dual](https://en.wikipedia.org/wiki/Pontryagin_dual) group

In [mathematics](wikipedia://en/18831), ***p*-adic analysis** is a branch of [number theory](wikipedia://en/21527) that studies functions of [*p*-adic numbers](wikipedia://en/51423). Along with the more classical fields of [real](wikipedia://en/26478) and [complex analysis](wikipedia://en/5759), which deal, respectively, with functions on the [real](https://en.wikipedia.org/wiki/Real_numbers) and [complex](https://en.wikipedia.org/wiki/Complex_numbers) numbers, it belongs to the discipline of [mathematical analysis](wikipedia://en/48396).

:::

The theory of complex-valued numerical functions on the *p*-adic numbers is part of the theory of [locally compact groups](wikipedia://en/1651204) ([abstract harmonic analysis](https://en.wikipedia.org/wiki/Abstract_harmonic_analysis)). The usual meaning taken for *p*-adic analysis is the theory of *p*-adic-valued functions on spaces of interest.

Applications of *p*-adic analysis have mainly been in [number theory](wikipedia://en/21527), where it has a significant role in [diophantine geometry](wikipedia://en/502205) and [diophantine approximation](wikipedia://en/251558). Some applications have required the development of *p*-adic [functional analysis](wikipedia://en/11180) and [spectral theory](wikipedia://en/506713). In many ways *p*-adic analysis is less subtle than [classical analysis](https://en.wikipedia.org/wiki/Classical_analysis), since the [ultrametric inequality](https://en.wikipedia.org/wiki/Ultrametric_inequality) means, for example, that [convergence](https://en.wikipedia.org/wiki/Convergent_Series) of [infinite series](https://en.wikipedia.org/wiki/Infinite_series) of *p*-adic numbers is much simpler. [Topological vector spaces](wikipedia://en/45752) over *p*-adic fields show distinctive features; for example aspects relating to [convexity](wikipedia://en/6292) and the [Hahn–Banach theorem](wikipedia://en/13860) are different.

## Important results {#Important_results}

::: {#o4 .statement kind=statement/theorem cue=named-heading name="Ostrowski's theorem"}

### Ostrowski's theorem {#Ostrowski's_theorem}

Ostrowski's theorem, due to [Alexander Ostrowski](wikipedia://en/5827091) (1916), states that every non-trivial [absolute value](wikipedia://en/5042667) on the [rational numbers](wikipedia://en/19727024) **Q** is equivalent to either the usual real absolute value or a [$p$-adic](wikipedia://en/51423) absolute value.[^o5]

:::

::: {#o7 .statement kind=statement/theorem cue=named-heading name="Mahler's theorem"}

### Mahler's theorem {#Mahler's_theorem}

**Mahler's theorem**, introduced by [Kurt Mahler](wikipedia://en/4421496),[^o8] expresses continuous *p*-adic functions in terms of polynomials.

In any [field](wikipedia://en/10603) of [characteristic](wikipedia://en/1066621) 0, one has the following result. Let

$$(\Delta f)(x)=f(x+1)-f(x)$$

be the forward [difference operator](https://en.wikipedia.org/wiki/Difference_operator). Then for [polynomial functions](https://en.wikipedia.org/wiki/Polynomial_function) *f* we have the [Newton series](https://en.wikipedia.org/wiki/Newton_series):

$$f(x)=\sum_{k=0}^\infty (\Delta^k f)(0){x \choose k},$$

where

$${x \choose k}=\frac{x(x-1)(x-2)\cdots(x-k+1)}{k!}$$

is the *k*th binomial coefficient polynomial.

Over the field of real numbers, the assumption that the function *f* is a polynomial can be weakened, but it cannot be weakened all the way down to mere [continuity](wikipedia://en/6122).

Mahler proved the following result:

**Mahler's theorem**: If *f* is a continuous [*p*-adic](wikipedia://en/51423)-valued function on the *p*-adic integers then the same identity holds.

:::

::: {#o10 .statement kind=statement/lemma cue=named-heading name="Hensel's lemma"}

### Hensel's lemma {#Hensel's_lemma}

Hensel's lemma, also known as Hensel's lifting lemma, named after [Kurt Hensel](wikipedia://en/2242565), is a result in [modular arithmetic](wikipedia://en/20087), stating that if a [polynomial equation](https://en.wikipedia.org/wiki/Polynomial_equation) has a [simple root](wikipedia://en/19211790#Multiplicity_of_a_root_of_a_polynomial) modulo a [prime number](wikipedia://en/23666) $p$, then this root corresponds to a unique root of the same equation modulo any higher power of $p$, which can be found by iteratively "[lifting](wikipedia://en/10504570)" the solution modulo successive powers of $p$. More generally it is used as a generic name for analogues for [complete](https://en.wikipedia.org/wiki/Completion_%28ring_theory%29) [commutative rings](wikipedia://en/61346) (including [*p*-adic fields](https://en.wikipedia.org/wiki/P-adic_field) in particular) of the [Newton method](https://en.wikipedia.org/wiki/Newton_method) for solving equations. Since *p*-adic analysis is in some ways simpler than [real analysis](wikipedia://en/26478), there are relatively easy criteria guaranteeing a root of a polynomial.

To state the result, let $f(x)$ be a [polynomial](wikipedia://en/23000) with [integer](wikipedia://en/14563) (or *p*-adic integer) coefficients, and let *m*,*k* be positive integers such that *m* ≤ *k*. If *r* is an integer such that

$f(r) \equiv 0 \pmod{p^k}$ and $f'(r) \not\equiv 0 \pmod{p}$

then there exists an integer *s* such that

$f(s) \equiv 0 \pmod{p^{k+m}}$ and $r \equiv s \pmod{p^{k}}.$

Furthermore, this *s* is unique modulo *p*<sup>*k*+m</sup>, and can be computed explicitly as

$s = r + tp^k$ where $t = - \frac{f(r)}{p^k} \cdot (f'(r)^{-1}).$

:::

## Applications {#Applications}

::: {#o14 .statement cue=named-heading name="Local–global principle"}

### Local–global principle {#Local–global_principle}

[Helmut Hasse](wikipedia://en/727118)'s local–global principle, also known as the Hasse principle, is the idea that one can find an [integer solution to an equation](wikipedia://en/9109) by using the [Chinese remainder theorem](wikipedia://en/7713) to piece together solutions [modulo](wikipedia://en/20087) powers of each different [prime number](wikipedia://en/23666). This is handled by examining the equation in the [completions](https://en.wikipedia.org/wiki/Completion_%28ring_theory%29) of the [rational numbers](wikipedia://en/19727024): the [real numbers](wikipedia://en/20646438) and the [*p*-adic numbers](wikipedia://en/51423). A more formal version of the Hasse principle states that certain types of equations have a rational solution [if and only if](wikipedia://en/14922) they have a solution in the [real numbers](wikipedia://en/20646438) *and* in the *p*-adic numbers for each prime *p*.
