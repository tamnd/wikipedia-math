# Locally constant function

::: {#o1 .subject cue=lead name="Locally constant function"}

*Image: Example of a locally constant function with sgn(x).svg.* The [signum function](https://en.wikipedia.org/wiki/Signum_function) restricted to the domain $\mathbb{R}\setminus\{0\}$ is locally constant.

In [mathematics](wikipedia://en/18831), a **locally constant function** is a [function](wikipedia://en/185427) from a [topological space](wikipedia://en/30450) into a [set](wikipedia://en/26691) with the property that around every point of its [domain](wikipedia://en/50263), there exists some [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of that point on which it [restricts](https://en.wikipedia.org/wiki/Restriction_of_a_function) to a [constant function](wikipedia://en/320861).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $f : X \to S$ be a function from a [topological space](wikipedia://en/30450) $X$ into a [set](wikipedia://en/26691) $S.$ If $x \in X$ then $f$ is said to be **locally constant at $x$** if there exists a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) $U \subseteq X$ of $x$ such that $f$ is constant on $U,$ which by definition means that $f(u) = f(v)$ for all $u, v \in U.$ The function $f : X \to S$ is called **locally constant** if it is locally constant at every point $x \in X$ in its domain.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Every [constant function](wikipedia://en/320861) is locally constant. The converse will hold if its [domain](wikipedia://en/50263) is a [connected space](wikipedia://en/6233).

Every locally constant function from the [real numbers](wikipedia://en/20646438) $\mathbb{R}$ to $\mathbb{R}$ is constant, by the [connectedness](wikipedia://en/6233) of $\mathbb{R}.$ But the function $f : \mathbb{Q} \to \mathbb{R}$ from the [rationals](wikipedia://en/19727024) $\mathbb{Q}$ to $\mathbb{R},$ defined by $f(x) = 0 \text{ for } x < \pi,$ and $f(x) = 1 \text{ for } x > \pi,$ is locally constant (this uses the fact that $\pi$ is [irrational](wikipedia://en/20647689) and that therefore the two sets $\{ x \in \mathbb{Q} : x < \pi \}$ and $\{ x \in \mathbb{Q} : x > \pi \}$ are both [open](wikipedia://en/39358) in $\mathbb{Q}$).

If $f : A \to B$ is locally constant, then it is constant on any [connected component](wikipedia://en/6233) of $A.$ The converse is true for [locally connected](https://en.wikipedia.org/wiki/Locally_connected) spaces, which are spaces whose connected components are open subsets.

Further examples include the following:

- Given a [covering map](https://en.wikipedia.org/wiki/Covering_map) $p : C \to X,$ then to each point $x \in X$ we can assign the [cardinality](wikipedia://en/6174) of the [fiber](wikipedia://en/6603892) $p^{-1}(x)$ over $x$; this assignment is locally constant.
- A map from a topological space $A$ to a [discrete space](wikipedia://en/56061) $B$ is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) if and only if it is locally constant.

:::

## Connection with sheaf theory {#Connection_with_sheaf_theory}

There are sheaves of locally constant functions on $X.$ To be more definite, the locally constant integer-valued functions on $X$ form a [sheaf](wikipedia://en/245466) in the sense that for each open set $U$ of $X$ we can form the functions of this kind; and then verify that the sheaf axioms hold for this construction, giving us a sheaf of [abelian groups](wikipedia://en/2974) (even [commutative rings](wikipedia://en/61346)).[^o7] This sheaf could be written $Z_X$; described by means of stalks we have stalk $Z_x,$ a copy of $Z$ at $x,$ for each $x \in X.$ This can be referred to a constant sheaf, meaning exactly sheaf of locally constant functions taking their values in the (same) group. The typical sheaf of course is not constant in this way; but the construction is useful in linking up [sheaf cohomology](wikipedia://en/1055357) with [homology theory](https://en.wikipedia.org/wiki/Homology_theory), and in logical applications of sheaves. The idea of [local coefficient system](https://en.wikipedia.org/wiki/Local_coefficient_system) is that we can have a theory of sheaves that locally look like such 'harmless' sheaves (near any $x$), but from a global point of view exhibit some 'twisting'.
