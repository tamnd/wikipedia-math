# Transcendental function

::: {#o1 .subject cue=lead name="Transcendental function"}

In [mathematics](wikipedia://en/18831), a **transcendental function** is an [analytic function](wikipedia://en/61478) that does not satisfy a [polynomial](wikipedia://en/23000) equation whose coefficients are functions of the independent variable that can be written using only the basic operations of addition, subtraction, multiplication, and division (without the need of taking limits). This is in contrast to an [algebraic function](wikipedia://en/974169).[^o2][^o3]

:::

The most familiar transcendental functions are the [exponential](wikipedia://en/9678), [trigonometric](https://en.wikipedia.org/wiki/Trigonometric_function), and [hyperbolic](https://en.wikipedia.org/wiki/Hyperbolic_function) functions, and their inverses, such as the [logarithm](wikipedia://en/17860) and [inverse trigonometric](wikipedia://en/374220) functions. All [special functions](wikipedia://en/23709110) such as the [gamma](wikipedia://en/12316), [error](wikipedia://en/177111), [bessel](wikipedia://en/4700), and [Riemann zeta](https://en.wikipedia.org/wiki/Zeta_function) functions are transcendental.

Equations including transcendental functions are [transcendental equations](wikipedia://en/6073963).

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, an [analytic function](wikipedia://en/61478) $f$ of one [real](wikipedia://en/20646438) or [complex](wikipedia://en/5826) variable is **transcendental** if it is [algebraically independent](https://en.wikipedia.org/wiki/Algebraically_independent) of that variable.[^o6] This means the function does not satisfy any polynomial equation. For example, the function $f$ given by

$f(x)=\frac{ax+b}{cx+d}$ for all $x \ne -\frac{d}{c}$

is not transcendental, but algebraic, because it satisfies the polynomial equation

$$(ax+b)-(cx+d)f(x)=0.$$

Similarly, the function $f$ that satisfies the equation

$f(x)^5+f(x)=x$ for all $x$

is not transcendental, but algebraic, even though it cannot be written as a finite expression involving the basic arithmetic operations.

This definition can be extended to [functions of several variables](wikipedia://en/39783039).

:::

## History {#History}

The transcendental functions [sine](https://en.wikipedia.org/wiki/Sine) and [cosine](https://en.wikipedia.org/wiki/Cosine) were [tabulated](https://en.wikipedia.org/wiki/Trigonometric_tables) from physical measurements in antiquity, as evidenced in Greece ([Hipparchus](wikipedia://en/13600)) and India ([jya](https://en.wikipedia.org/wiki/Jya) and [koti-jya](https://en.wikipedia.org/wiki/Koti-jya)). In describing [Ptolemy's table of chords](wikipedia://en/30684123), an equivalent to a table of sines, [Olaf Pedersen](https://en.wikipedia.org/wiki/Olaf_Pedersen) wrote:

The mathematical notion of continuity as an explicit concept is unknown to Ptolemy. That he, in fact, treats these functions as continuous appears from his unspoken presumption that it is possible to determine a value of the dependent variable corresponding to any value of the independent variable by the simple process of [linear interpolation](wikipedia://en/160010).[^o8]

A revolutionary understanding of these [circular functions](https://en.wikipedia.org/wiki/Circular_function) occurred in the 18th century and was explicated by [Leonhard Euler](wikipedia://en/17902) in 1748 in his [Introduction to the Analysis of the Infinite](https://en.wikipedia.org/wiki/Introduction_to_the_Analysis_of_the_Infinite). These ancient transcendental functions became known as [continuous functions](wikipedia://en/6122) through [quadrature](wikipedia://en/1618671) of the [rectangular hyperbola](https://en.wikipedia.org/wiki/Rectangular_hyperbola) $xy = 1$ by [Grégoire de Saint-Vincent](https://en.wikipedia.org/wiki/Grégoire_de_Saint-Vincent) in 1647, two millennia after [Archimedes](wikipedia://en/1844) had produced *[The Quadrature of the Parabola](https://en.wikipedia.org/wiki/The_Quadrature_of_the_Parabola)*.

The area under the [hyperbola](wikipedia://en/14052) was shown to have the scaling property of constant area for a constant ratio of bounds. The [hyperbolic logarithm](https://en.wikipedia.org/wiki/Hyperbolic_logarithm) function so described was of limited service until 1748 when [Leonhard Euler](wikipedia://en/17902) related it to functions where a constant is raised to a variable exponent, such as the [exponential function](wikipedia://en/9678) where the constant [base](https://en.wikipedia.org/wiki/Base_%28exponentiation%29) is [e](wikipedia://en/9633). By introducing these transcendental functions and noting the [bijection](wikipedia://en/3942) property that implies an [inverse function](wikipedia://en/14907), some facility was provided for algebraic manipulations of the [natural logarithm](wikipedia://en/21476) even if it is not an algebraic function.

The exponential function is written $\exp (x) = e^x$. Euler identified it with the [infinite series](https://en.wikipedia.org/wiki/Infinite_series) $\sum_{k=0} ^{\infty} x^k / k !$, where $k!$ denotes the [factorial](wikipedia://en/10606) of $k$.

The even and odd terms of this series provide sums denoting $\cosh(x)$ and $\sinh(x)$, so that $e^x = \cosh x + \sinh x.$ These transcendental [hyperbolic functions](https://en.wikipedia.org/wiki/Hyperbolic_function) can be converted into circular functions sine and cosine by introducing $(-1)^{k}$ into the series, resulting in [alternating series](wikipedia://en/494308). After Euler, mathematicians view the sine and cosine this way to relate the transcendence to logarithm and exponent functions, often through [Euler's formula](wikipedia://en/9613) in [complex number](wikipedia://en/5826) arithmetic.

## Examples {#Examples}

The following functions are transcendental:

$$\begin{aligned} f_1(x) &= x^\pi \\[2pt] f_2(x) &= e^x \\[2pt] f_3(x) &= \ln{x} \\[2pt] f_4(x) &= \cosh{x} \\ f_5(x) &= \sinh{x} \\ f_6(x) &= \tanh{x} \\ f_7(x) &= \sinh^{-1}{x} \\[2pt] f_8(x) &= \tanh^{-1}{x} \\[2pt] f_9(x) &= \cos{x} \\ f_{10}(x) &= \sin{x} \\ f_{11}(x) &= \tan{x} \\ f_{12}(x) &= \sin^{-1}{x} \\[2pt] f_{13}(x) &= \cos^{-1}{x} \\[2pt] f_{14}(x) &= \tan^{-1}{x} \\[2pt] f_{15}(x) &= x! \\ f_{16}(x) &= \frac1{x!} \\[2pt] f_{17}(x) &= x^x \\[2pt] \end{aligned}$$

For the first function $f_1(x)$, the exponent *$\pi$* can be replaced by any other irrational number, and the function will remain transcendental. For the second and third functions $f_2(x)$ and $f_3(x)$, the base *$e$* can be replaced by any other positive real number base not equaling 1, and the functions will remain transcendental. Functions 4-8 denote the hyperbolic trigonometric functions, while functions 9-14 denote the circular trigonometric functions. The fifteenth function $f_{15}(x)$ denotes the analytic extension of the factorial function via the [gamma function](wikipedia://en/12316), and $f_{16}(x)$ is its reciprocal, an [entire function](wikipedia://en/10372). Finally, in the last function $f_{17}(x)$, the exponent $x$ can be replaced by $kx$ for any nonzero real $k$, and the function will remain transcendental.

:::

## Algebraic and transcendental functions {#Algebraic_and_transcendental_functions}

The most familiar transcendental functions are the [logarithm](wikipedia://en/17860), the [exponential](wikipedia://en/9678) (with any non-trivial base), the [trigonometric](https://en.wikipedia.org/wiki/Trigonometric_function), and the [hyperbolic functions](wikipedia://en/56567), and the [inverses](wikipedia://en/14907) of all of these. Less familiar are the [special functions](wikipedia://en/23709110) of [analysis](wikipedia://en/48396), such as the [gamma](wikipedia://en/12316), [elliptic](wikipedia://en/69939), and [zeta functions](https://en.wikipedia.org/wiki/Zeta_function), all of which are transcendental. The [generalized hypergeometric](wikipedia://en/361184) and [Bessel](wikipedia://en/4700) functions are transcendental in general, but algebraic for some special parameter values.

Transcendental functions cannot be defined using only the operations of addition, subtraction, multiplication, division, and $n$th roots (where $n$ is any integer), without using some "limiting process".

A function that is not transcendental is **algebraic**. Simple examples of algebraic functions are the [rational functions](https://en.wikipedia.org/wiki/Rational_functions) and the [square root](wikipedia://en/29208) function, but in general, algebraic functions cannot be defined as finite formulas of the elementary functions, as shown by the example above with $f(x)^5+f(x)=x$ (see [Abel–Ruffini theorem](wikipedia://en/152518) and [Bring radical](wikipedia://en/3191883)).

The [indefinite integral](https://en.wikipedia.org/wiki/Indefinite_integral) of many algebraic functions is transcendental. For example, the integral $\int_{t=1}^x\frac{1}{t}dt$ turns out to equal the logarithm function $\ln(x)$. Similarly, the limit or the infinite sum of many algebraic function sequences is transcendental. For example, $\lim_{n\to \infty}\left(1+\frac xn\right)^n$ converges to the exponential function $e^x$, and the infinite sum $\sum_{n=0}^{\infty} \frac{x^{2n}}{(2n)!}$ turns out to equal the hyperbolic cosine function $\cosh x$. In fact, it is *impossible* to define any transcendental function in terms of algebraic functions without using some such "limiting procedure" (integrals, sequential limits, and infinite sums are just a few).

[Differential algebra](wikipedia://en/1816587) examines how integration frequently creates functions that are algebraically independent of some class, such as when one takes polynomials with trigonometric functions as variables.

## Transcendentally transcendental functions {#Transcendentally_transcendental_functions}

Most familiar transcendental functions, including the special functions of mathematical physics, are solutions of [algebraic differential equations](wikipedia://en/9501827). Those that are not, such as the [gamma](wikipedia://en/12316) and the [zeta](https://en.wikipedia.org/wiki/Zeta_function) functions, are called *transcendentally transcendental* or *[hypertranscendental](wikipedia://en/11017352)* functions.[^o13]

## Exceptional set {#Exceptional_set}

If $f$ is an algebraic function and $\alpha$ is an [algebraic number](wikipedia://en/1158) then $f (\alpha)$ is also an algebraic number. The converse is not true: there are [entire transcendental functions](wikipedia://en/10372) $f$ such that $f (\alpha)$ is an algebraic number for any algebraic $\alpha$.[^o15] For a given transcendental function the set of algebraic numbers giving algebraic results is called the **exceptional set** of that function.[^o16][^o17] Formally it is defined by:

$$\mathcal{E}(f)=\left \{\alpha\in\overline{\mathbb{Q}}\,:\,f(\alpha)\in\overline{\mathbb{Q}} \right \}.$$

In many instances the exceptional set is fairly small. For example, $\mathcal{E}(\exp) = \{0\};$ this was proved by [Lindemann](wikipedia://en/335736) in 1882 (see [Lindemann–Weierstrass theorem](wikipedia://en/348976)). In particular $\exp(1) = e$ is transcendental. Also, since $\exp(i\pi) = -1$ is algebraic we know that $i\pi$ cannot be algebraic. Since $i$ is algebraic this implies that $\pi$ is a [transcendental number](wikipedia://en/30325).

In general, finding the exceptional set of a function is a difficult problem, but if it can be calculated then it can often lead to results in [transcendental number theory](wikipedia://en/1157698). Here are some other known exceptional sets:

- Klein's [*j*-invariant](wikipedia://en/451988) $$\mathcal{E}(j) = \left\{\alpha\in\mathcal{H}\,:\,[\mathbb{Q}(\alpha): \mathbb{Q}] = 2 \right\},$$ where $\mathcal H$ is the [upper half-plane](wikipedia://en/287826), and $[\mathbb{Q}(\alpha): \mathbb{Q}]$ is the [degree](wikipedia://en/4382697) of the [number field](wikipedia://en/28730822) $\mathbb{Q}(\alpha).$ This result is due to [Theodor Schneider](wikipedia://en/10312621).[^o18]
- Exponential function in base 2: $$\mathcal{E}(2^x)=\mathbb{Q},$$ This result is a corollary of the [Gelfond–Schneider theorem](wikipedia://en/609487), which states that if $\alpha \neq 0,1$ is algebraic, and $\beta$ is algebraic and irrational then $\alpha^\beta$ is transcendental. Thus the function $2^{x}$ could be replaced by $c^{x}$ for any algebraic $c$ not equal to 0 or 1. Indeed, we have: $$\mathcal{E}(x^x) = \mathcal{E}\left(x^{\frac{1}{x}}\right)=\mathbb{Q}\setminus\{0\}.$$
- A consequence of [Schanuel's conjecture](wikipedia://en/2031353) in transcendental number theory would be that $\mathcal{E}\left(e^{e^x}\right)=\emptyset.$
- A function with empty exceptional set that does not require assuming Schanuel's conjecture is $f(x) = \exp(1 + \pi x).$

While calculating the exceptional set for a given function is not easy, it is known that given *any* subset of the algebraic numbers, say $A$, there is a transcendental function whose exceptional set is $A$.[^o19] The subset does not need to be proper, meaning that $A$ can be the set of algebraic numbers. This directly implies that there exist transcendental functions that produce transcendental numbers only when given transcendental numbers. [Alex Wilkie](wikipedia://en/10343119) also proved that there exist transcendental functions for which [first-order-logic](https://en.wikipedia.org/wiki/First-order-logic) proofs about their transcendence do not exist by providing an exemplary [analytic function](wikipedia://en/61478).[^o20]

## Dimensional analysis {#Dimensional_analysis}

In [dimensional analysis](wikipedia://en/8267), transcendental functions are notable because they make sense only when their argument is [dimensionless](https://en.wikipedia.org/wiki/Dimensionless_quantity) (possibly after algebraic reduction). Because of this, transcendental functions can be an easy-to-spot source of dimensional errors. For example, $\log(5 \operatorname{metres})$ is a nonsensical expression, unlike $\log(5 \operatorname{metres} / 3 \operatorname{metres})$ or $\log(3) \operatorname{metres}$. One could attempt to apply a [logarithmic](wikipedia://en/17860) identity to get $\log(5) + \log(\operatorname{metres})$, which highlights the problem: applying a non-algebraic operation to a dimension creates meaningless results.
