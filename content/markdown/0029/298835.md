# Affine combination

::: {#o1 .subject cue=lead name="Affine combination"}

In [mathematics](wikipedia://en/18831), an **affine combination** of $x_{1}, ..., x_{n}$ is a [linear combination](wikipedia://en/55632)

:::

$$\sum_{i=1}^{n}{\alpha_{i} \cdot x_{i}} = \alpha_{1} x_{1} + \alpha_{2} x_{2} + \cdots +\alpha_{n} x_{n},$$

such that

$$\sum_{i=1}^{n} {\alpha_{i}}=1.$$

Here, $x_{1}, ..., x_{n}$ can be elements ([vectors](https://en.wikipedia.org/wiki/Vector_%28mathematics%29)) of a [vector space](wikipedia://en/32370) over a [field](wikipedia://en/10603) $K$, and the coefficients $\alpha_{i}$ are elements of $K$.

The elements $x_{1}, ..., x_{n}$ can also be points of a [Euclidean space](wikipedia://en/9697), and, more generally, of an [affine space](wikipedia://en/298834) over a field $K$. In this case the $\alpha_{i}$ are elements of $K$ (or $\mathbb R$ for a Euclidean space), and the affine combination is also a point. See Affine space for the definition in this case.

This concept is fundamental in [Euclidean geometry](wikipedia://en/9417) and [affine geometry](wikipedia://en/243890), because the set of all affine combinations of a set of points forms the smallest affine space containing the points, exactly as the linear combinations of a set of vectors form their [linear span](wikipedia://en/56353).

The affine combinations commute with any [affine transformation](wikipedia://en/38449) $T$ in the sense that

$$T\sum_{i=1}^{n}{\alpha_{i} \cdot x_{i}} = \sum_{i=1}^{n}{\alpha_{i} \cdot Tx_{i}}.$$

In particular, any affine combination of the [fixed points](wikipedia://en/449738) of a given [affine transformation](wikipedia://en/38449) $T$ is also a fixed point of $T$, so the set of fixed points of $T$ forms an [affine space](wikipedia://en/298834) (in 3D: a line or a plane, and the trivial cases, a point or the whole space).

When a [stochastic matrix](wikipedia://en/217313), $A$, acts on a column vector, **b**, the result is a column vector whose entries are affine combinations of **b** with coefficients from the rows in $A$.
