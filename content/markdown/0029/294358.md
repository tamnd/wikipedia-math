# Anticommutative property

::: {#o1 .subject cue=lead name="Anticommutative property"}

In [mathematics](wikipedia://en/18831), **anticommutativity** is a specific property of some non-[commutative](https://en.wikipedia.org/wiki/Commutative) mathematical [operations](wikipedia://en/4140245). Swapping the position of [two arguments](wikipedia://en/3948) of an antisymmetric operation yields a result which is the *inverse* of the result with unswapped arguments. The notion *[inverse](wikipedia://en/45199)* refers to a [group structure](wikipedia://en/19447) on the operation's [codomain](wikipedia://en/50264), possibly with another operation. [Subtraction](wikipedia://en/74141) is an anticommutative operation because commuting the operands of $a-b$ gives $b-a=-(a-b)$; for example, $2-10=-(10-2)=-8$. Another prominent example of an anticommutative operation is the [Lie bracket](wikipedia://en/17944).

:::

In [mathematical physics](wikipedia://en/173416), where [symmetry](https://en.wikipedia.org/wiki/Symmetry_%28physics%29) is of central importance, or even just in [multilinear algebra](wikipedia://en/243946) these operations are mostly (multilinear with respect to some [vector structures](wikipedia://en/32370) and then) called **antisymmetric operations**, and when they are not already of [arity](wikipedia://en/42301) greater than two, extended in an [associative](https://en.wikipedia.org/wiki/Associative) setting to cover more than two [arguments](wikipedia://en/32842052).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $A, B$ are two [abelian groups](wikipedia://en/2974), a [bilinear map](wikipedia://en/4365) $f\colon A^2 \to B$ is **anticommutative** if for all $x, y \in A$ we have

$$f(x, y) = - f(y, x).$$

More generally, a [multilinear map](wikipedia://en/221525) $g : A^n \to B$ is anticommutative if for all $x_1, \dots x_n \in A$ we have

$$g(x_1,x_2, \dots x_n) = \text{sgn}(\sigma) g(x_{\sigma(1)},x_{\sigma(2)},\dots x_{\sigma(n)})$$

where $\text{sgn}(\sigma)$ is the [sign](wikipedia://en/49727) of the [permutation](wikipedia://en/44027) $\sigma$.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If the abelian group $B$ has no 2-[torsion](wikipedia://en/3039330), implying that if $x = -x$ then $x = 0$, then any anticommutative bilinear map $f\colon A^2 \to B$ satisfies

$$f(x, x) = 0.$$

More generally, by [transposing](https://en.wikipedia.org/wiki/Transposition_%28mathematics%29) two elements, any anticommutative multilinear map $g\colon A^n \to B$ satisfies

$$g(x_1, x_2, \dots x_n) = 0$$

if any of the $x_i$ are equal; such a map is said to be **[alternating](wikipedia://en/8200947)**. Conversely, using multilinearity, any alternating map is anticommutative. In the binary case this works as follows: if $f\colon A^2 \to B$ is alternating then by bilinearity we have

$$f(x+y, x+y) = f(x, x) + f(x, y) + f(y, x) + f(y, y) = f(x, y) + f(y, x) = 0$$

and the proof in the multilinear case is the same but in only two of the inputs.

If $e_i^2 = 1, \quad e_i e_j + e_j e_i = 0, i \ne j\ ,$ then $(\sum_{i=1}^n x_i e_i )^2 = \sum_{i=1}^n x_i^2 .$[^o6]

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of anticommutative binary operations include:

- [Cross product](wikipedia://en/157092)
- Lie bracket of a [Lie algebra](wikipedia://en/17944)
- Lie bracket of a [Lie ring](https://en.wikipedia.org/wiki/Lie_ring)
- [Subtraction](wikipedia://en/74141)
- Products of i, j, and k in [quaternions](wikipedia://en/51440)

:::
