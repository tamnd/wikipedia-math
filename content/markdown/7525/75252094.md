# Flip distance

::: {#o1 .subject cue=lead name="Flip distance"}

In [discrete mathematics](wikipedia://en/8492) and [theoretical computer science](wikipedia://en/323392), the **flip distance** between two [triangulations](wikipedia://en/1081285) of the same point set is the number of flips required to transform one triangulation into another. A flip removes an edge between two triangles in the triangulation and then adds the other [diagonal](wikipedia://en/349251) in the edge's enclosing [quadrilateral](wikipedia://en/25278), forming a different triangulation of the same point set.

:::

This problem is known to be [NP-hard](https://en.wikipedia.org/wiki/NP-hard), even in its special case of determining the flip distance between convex polygons. Computing the flip distance between convex polygon triangulations is also equivalent to [rotation distance](wikipedia://en/62539802), the number of [rotations](https://en.wikipedia.org/wiki/Tree_rotation) required to transform one [binary tree](wikipedia://en/4321) into another.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Flip graphs.svg.* The flip graphs of a quadrilateral, a pentagon, and a hexagon

Given a family of [triangulations](wikipedia://en/1440970) of some geometric object, a *flip* is an operation that transforms one triangulation to another by removing an edge between two triangles and adding the opposite diagonal to the resulting quadrilateral. The flip distance between two triangulations is the minimum number of flips needed to transform one triangulation into another.[^o33] It can also be described as the shortest path distance in a *[flip graph](wikipedia://en/47526601)*, a graph that has a vertex for each triangulation and an edge for each flip between two triangulations.[^o33] Flips and flip distances can be defined in this way for several different kinds of triangulations, including triangulations of sets of points in the [Euclidean plane](wikipedia://en/15575410), triangulations of [polygons](wikipedia://en/23621), and triangulations of abstract [manifolds](wikipedia://en/2073470).[^o14]

:::

## Feasibility {#Feasibility}

The flip distance is well-defined only if any triangulation can be converted to any other triangulation via a sequence of flips. An equivalent condition is that the [flip graph](wikipedia://en/47526601) must be connected.[^o18]

In 1936, [Klaus Wagner](https://en.wikipedia.org/wiki/Klaus_Wagner) showed that maximal planar graphs on a sphere can be transformed to any other maximal [planar graph](wikipedia://en/24314) with the same vertices through flipping.[^o13] [A. K. Dewdney](https://en.wikipedia.org/wiki/A._K._Dewdney) generalized this result to triangulations on the surface of a [torus](wikipedia://en/74800) while Charles Lawson to triangulations of a point set on a 2-dimensional plane.[^o14][^o16]

For triangulations of a point set in dimension 5 or above, there exists examples where the flip graph is disconnected and a triangulation cannot be obtained from other triangulations via flips.[^o17][^o18] Whether all flip graphs of finite 3- or 4-dimensional point sets are connected is an [open problem](wikipedia://en/1333335).[^o19]

## Diameter of the flip graph {#Diameter_of_the_flip_graph}

The maximum number of flips required to transform a triangulation into another is the [diameter](wikipedia://en/2979341) of the flip graph. The diameter of the flip graph of a convex $n$-gon has been obtained by [Daniel Sleator](https://en.wikipedia.org/wiki/Daniel_Sleator), [Robert Tarjan](https://en.wikipedia.org/wiki/Robert_Tarjan), and [William Thurston](wikipedia://en/39190)[^o25] when $n$ is sufficiently large and by Lionel Pournin for all $n$. This diameter is equal to $2n-10$ when $n\geq13$.[^o26]

The diameter of other flip graphs has been studied. For instance [Klaus Wagner](https://en.wikipedia.org/wiki/Klaus_Wagner) provided a quadratic upper bound on the diameter of the flip graph of a set of $n$ unmarked points on the sphere.[^o13] The current upper bound on the diameter is $5n-23$,[^o21] while the best-known lower bound is $7n/3+\Theta(1)$.[^o20] The diameter of the flip graphs of arbitrary topological surfaces with boundary has also been studied and their exact value is known in several cases.[^o22][^o23][^o24]

## Equivalence with other problems {#Equivalence_with_other_problems}

The flip distance between triangulations of a [convex polygon](wikipedia://en/660019) is equivalent to the [rotation distance](wikipedia://en/62539802) between two binary trees.[^o25]

## Computational complexity {#Computational_complexity}

::: {#o8 .problem cue=unsolved}

What is the complexity of computing the flip distance between two triangulations of a convex polygon?

:::

Computing the flip distance between triangulations of a point set is both [NP-complete](https://en.wikipedia.org/wiki/NP-complete) and [APX-hard](https://en.wikipedia.org/wiki/APX-hard).[^o27][^o28] However, it is [fixed-parameter tractable](https://en.wikipedia.org/wiki/Fixed-parameter_tractable) (FPT), and several FPT algorithms that run in exponential time have been proposed.[^o29][^o30]

Computing the flip distance between triangulations of a [simple polygon](wikipedia://en/1059530),[^o31] or of a [convex polygon](wikipedia://en/660019), are both [NP-hard](https://en.wikipedia.org/wiki/NP-hard).[^o15]

::: {#o10 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

Let $n$ be the number of points in the point set and $k$ be the flip distance. The current best FPT algorithm runs in $O(n + k \cdot 32^k)$.[^o29] A faster FPT algorithm exists for the flip distance between convex polygon triangulations; it has time complexity $O(3.82^k)$.[^o32]

If no five points of a point set form an empty pentagon, there exists a $O(n^2)$ algorithm for the flip distance between triangulations of this point set.[^o33]

:::
