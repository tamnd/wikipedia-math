# Bratteli–Vershik diagram

::: {#o1 .subject cue=lead name="Bratteli–Vershik diagram"}

In mathematics, a **Bratteli–Veršik diagram** is an ordered, essentially simple [Bratteli diagram](wikipedia://en/25337588) (*V*, *E*) with a [homeomorphism](wikipedia://en/13660) on the set of all infinite paths called the Veršhik transformation. It is named after [Ola Bratteli](https://en.wikipedia.org/wiki/Ola_Bratteli) and [Anatoly Vershik](wikipedia://en/9036441).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* = {(*e*<sub>1</sub>, *e*<sub>2</sub>, ...) | *e*<sub>*i*</sub> ∈ *E*<sub>*i*</sub> and *r*(*e*<sub>*i*</sub>) = *s*(*e*<sub>*i*+1</sub>)} be the set of all paths in the essentially simple [Bratteli diagram](wikipedia://en/25337588) (*V*, *E*). Let *E*<sub>min</sub> be the set of all minimal edges in *E*, similarly let *E*<sub>max</sub> be the set of all maximal edges. Let *y* be the unique infinite path in *E*<sub>max</sub>. (Diagrams which possess a unique infinite path are called "essentially simple".)

The Veršhik transformation is a homeomorphism φ : *X* → *X* defined such that φ(*x*) is the unique minimal path if *x* = *y*. Otherwise *x* = (*e*<sub>1</sub>, *e*<sub>2</sub>,...) | *e*<sub>*i*</sub> ∈ *E*<sub>*i*</sub> where at least one *e*<sub>*i*</sub> ∉ *E*<sub>max</sub>. Let *k* be the smallest such integer. Then φ(*x*) = (*f*<sub>1</sub>, *f*<sub>2</sub>, ..., *f*<sub>*k*−1</sub>, *e*<sub>*k*</sub> + 1, *e*<sub>*k*+1</sub>, ... ), where *e*<sub>*k*</sub> + 1 is the successor of *e*<sub>*k*</sub> in the total ordering of edges incident on *r*(*e*<sub>*k*</sub>) and (*f*<sub>1</sub>, *f*<sub>2</sub>, ..., *f*<sub>*k*−1</sub>) is the unique minimal path to *e*<sub>*k*</sub> + 1.

The Veršhik transformation allows us to construct a pointed topological system (*X*, *φ*, *y*) out of any given ordered, essentially simple Bratteli diagram. The reverse construction is also defined.

:::

## Equivalence {#Equivalence}

The notion of [graph minor](https://en.wikipedia.org/wiki/Minor_%28graph_theory%29) can be promoted from a [well-quasi-ordering](wikipedia://en/739775) to an [equivalence relation](wikipedia://en/9259) if we assume the relation is [symmetric](wikipedia://en/200459). This is the notion of equivalence used for Bratteli diagrams.

The major result in this field is that equivalent essentially simple ordered Bratteli diagrams correspond to [topologically conjugate](wikipedia://en/5506149) pointed [dynamical systems](wikipedia://en/9087). This allows us apply results from the former field into the latter and vice versa.[^o5]
