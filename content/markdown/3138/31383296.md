# MathMagic

::: {#o1 .subject cue=lead name="MathMagic"}

**MathMagic** is a mathematical [WYSIWYG](https://en.wikipedia.org/wiki/WYSIWYG) equation editor.

:::

## History {#History}

In June 2012, "*MathMagic Lite Edition*" was introduced for macOS platforms, with some limited features.[^o5]

In 2013, [Adobe](https://en.wikipedia.org/wiki/Adobe_Inc.) bundled a custom version of MathMagic to [Adobe Captivate](https://en.wikipedia.org/wiki/Adobe_Captivate) 7 for both macOS and Windows.[^o6]

In September 2014, "*MathMagic Lite for Windows*" was released.[^o7]

In 2022, the 64-bit versions of MathMagic for macOS were released in [Universal binary format](https://en.wikipedia.org/wiki/Universal_binary) for both Intel Macs and M1 Apple silicon Macs.

## Features {#Features}

MathMagic supports [MathML](wikipedia://en/52313), [LaTeX](https://en.wikipedia.org/wiki/LaTeX), [Plain TeX](https://en.wikipedia.org/wiki/TeX), [PDF](https://en.wikipedia.org/wiki/PDF), [SVG](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics), [MathType](wikipedia://en/3135565) equations, Equation to Speech, and others.

MathMagic does not support computation.

Its website supports the HTTP protocol, not the more secure HTTPS.
