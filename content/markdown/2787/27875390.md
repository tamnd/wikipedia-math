# Symbols for zero

::: {#o1 .subject cue=lead name="Symbols for zero"}

The modern numerical digit [0](https://en.wikipedia.org/wiki/0_%28number%29) is usually written as a circle, an ellipse or a rounded square or rectangle.

:::

## Glyphs {#Glyphs}

*Image: Text figures 036.svg.*

In most modern [typefaces](https://en.wikipedia.org/wiki/Typeface), the height of the 0 character is the same as the other digits. However, in typefaces with [text figures](https://en.wikipedia.org/wiki/Text_figures), the character is often shorter ([x-height](https://en.wikipedia.org/wiki/X-height)).

*Image: Zero o comparison.svg.* A comparison of the letter O and the number 0

Traditionally, many print typefaces made the capital letter [O](wikipedia://en/22314) more rounded than the narrower, elliptical digit 0.[^o7] [Typewriters](https://en.wikipedia.org/wiki/Typewriter) originally made no distinction in shape between O and 0; some models did not even have a separate key for the digit 0. The distinction came into prominence on modern character [displays](https://en.wikipedia.org/wiki/Visual_display_unit).[^o7]

The digit 0 with a dot in the centre seems to have originated as an option on [IBM 3270](https://en.wikipedia.org/wiki/IBM_3270) displays. Its appearance has continued with [Taligent](https://en.wikipedia.org/wiki/Taligent)'s command line typeface [Andalé Mono](https://en.wikipedia.org/wiki/Andalé_Mono).

An alternative, the [slashed zero](https://en.wikipedia.org/wiki/Slashed_zero) (looking similar to the letter O except for the slash), was primarily used in hand-written coding sheets before transcription to punched cards or tape, and is also used in old-style [ASCII](https://en.wikipedia.org/wiki/ASCII) graphic sets descended from the default typewheel on the [Teletype Model 33](https://en.wikipedia.org/wiki/Teletype_Model_33) ASR. This form is similar to the symbol $\emptyset$ representing the [empty set](wikipedia://en/9566) (2205), as well as to the letter $\langle \text{Ø}\rangle$ (00D8) used in several [Scandinavian languages](https://en.wikipedia.org/wiki/North_Germanic_languages). Some [Burroughs](https://en.wikipedia.org/wiki/Burroughs_Corporation)/[Unisys](https://en.wikipedia.org/wiki/Unisys) equipment displays a digit 0 with a *reversed* slash.

The opposing convention that has the letter O *with* a slash and the digit 0 *without* was advocated by [SHARE](https://en.wikipedia.org/wiki/SHARE_%28computing%29), a prominent [IBM](https://en.wikipedia.org/wiki/IBM) user group,[^o7] and recommended by IBM for writing [FORTRAN](https://en.wikipedia.org/wiki/Fortran) programs,[^o8] and by a few other early mainframe makers; this is even more problematic for Scandinavians because it means two of their letters collide. Others advocated the opposite convention,[^o7] including IBM for writing [Algol](https://en.wikipedia.org/wiki/Algol) programs.[^o8] Another convention used on some early [line printers](https://en.wikipedia.org/wiki/Line_printer) left digit 0 unornamented but added a tail or hook to the capital O so that it resembled an inverted letter $\langle Q\rangle$ ( Q ) or cursive capital letter-O ($\mathcal O$, 1D4AA).[^o7]

Some [computer fonts](https://en.wikipedia.org/wiki/Computer_fonts) made one of the capital-O more rounded and the digit-0 more angular (closer to a rectangle). The [TI-99/4A](https://en.wikipedia.org/wiki/TI-99/4A) computer has a more angular capital O and a more rounded digit 0, whereas others made the choice the other way around.

*Image: Deutsches Kfz-Kennzeichen für Behördenfahrzeuge (Nummernbereich 3).jpg.* German license plate with slit zeros

The typeface used on most European [vehicle registration plates](https://en.wikipedia.org/wiki/Vehicle_registration_plate) distinguishes the two symbols partially in this manner (having a more rectangular or wider shape for the capital O than the digit 0), but in several countries a further distinction is made by slitting open the digit 0 on the upper right side (as in [German plates](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Germany) using the *[fälschungserschwerende Schrift](https://en.wikipedia.org/wiki/FE-Schrift)*, "forgery-impeding typeface").

Sometimes the digit 0 is used either exclusively, or not at all, to avoid confusion altogether. For example, confirmation numbers[^o9] used by [Southwest Airlines](https://en.wikipedia.org/wiki/Southwest_Airlines) use only the capital letters O and I instead of the digits 0 and 1, while [Canadian postal codes](https://en.wikipedia.org/wiki/Canadian_postal_code) use only the digits 1 and 0 and never the capital letters O and I, although letters and numbers always alternate.

## Other {#Other}

On the [seven-segment displays](https://en.wikipedia.org/wiki/Seven-segment_display) of calculators, watches, and household appliances, 0 is usually shown with six line segments, though on some historical calculator models it was shown with four line segments.

The international maritime signal flag has five plus signs in an X arrangement.
