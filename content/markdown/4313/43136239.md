# Hausdorff gap

::: {#o1 .subject cue=lead name="Hausdorff gap"}

In [mathematics](wikipedia://en/18831), a **Hausdorff gap** consists roughly of two collections of sequences of [natural numbers](wikipedia://en/21474), such that there is no sequence lying between the two collections. The first example was found by (txt). The existence of Hausdorff gaps shows that the [partially ordered set](wikipedia://en/23572) of possible growth rates of sequences is not [complete](wikipedia://en/572352).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\omega^\omega$ be the set of all sequences of non-negative integers, and define $f<g$ to mean $\lim \left (g(n)-f(n)\right )=+\infty$.

If $X$ is a partially ordered set (poset) and $\kappa$ and $\lambda$ are [cardinals](wikipedia://en/6173), then a $(\kappa,\lambda)$-*pregap* in $X$ is a set of elements $f_\alpha$ for $\alpha\in\kappa$ and a set of elements $g_\beta$ for $\beta\in\lambda$ such that:

- The transfinite sequence $f$ is strictly increasing;
- The transfinite sequence $g$ is strictly decreasing;
- Every element of the sequence $f$ is less than every element of the sequence $g$.

A pregap is called a *gap* if it satisfies the additional condition:

- There is no element $h$ greater than all elements of $f$ and less than all elements of $g$.

A **Hausdorff gap** is a $(\omega_1,\omega_1)$-gap in $\omega^\omega$ such that for every [countable ordinal](https://en.wikipedia.org/wiki/Countable_ordinal) $\alpha$ (i.e. every $\alpha \in \omega_1$) and every natural number $n$ there are only a finite number of $\beta$ less than $\alpha$ such that for all $k>n$ we have $f_\alpha(k)<g_\beta(k)$.

There are some variations of these definitions, with the ordered set $\omega^\omega$ replaced by a similar set. For example, one can redefine $f<g$ to mean $f(n)<g(n)$ for all but finitely many $n$. Another variation introduced by (Hausdorff 1936) is to replace $\omega^\omega$ by the [power set](wikipedia://en/23799) of $\omega$, with the order given by $A<B$ if $A$ has only finitely many elements not in $B$ but $B$ has infinitely many elements not in $A$.

:::

## Existence {#Existence}

It is possible to [prove](wikipedia://en/82285) in [ZFC](https://en.wikipedia.org/wiki/ZFC) that there exist Hausdorff gaps and $(\mathfrak b,\omega)$-gaps where $\mathfrak b$ is the [cardinality](wikipedia://en/6174) of the smallest [unbounded set](https://en.wikipedia.org/wiki/Unbounded_set) in $\omega^\omega$, and that there are no $(\omega,\omega)$-gaps. The stronger [open coloring axiom](wikipedia://en/43173559) can rule out all types of gaps except Hausdorff gaps and those of type $(\kappa,\omega)$ with $\kappa \geq \omega_2$.
