# Problem of the Nile

::: {#o1 .subject cue=lead name="Problem of the Nile"}

The **problem of the Nile** is a mathematical problem related to equal partitions of [measures](wikipedia://en/19873). The problem was first presented by [Ronald Fisher](wikipedia://en/140824) in 1936–1938.[^o2] It is presented by Dubins and Spanier in the following words:[^o3]

> "Each year, the [Nile](https://en.wikipedia.org/wiki/Nile) would flood, thereby irrigating or perhaps devastating parts of the agricultural land of a [predynastic Egyptian](https://en.wikipedia.org/wiki/Prehistoric_Egypt) village. The value of different portions of the land would depend upon the height of the flood. In question was the possibility of giving to each of the *k* residents, piece of land whose value would be 1/*k* of the total land value, no matter what the height of the flood."

Formally, for each height *h*, there is a [nonatomic measure](https://en.wikipedia.org/wiki/Nonatomic_measure) *v<sub>h</sub>* on the land, which represents the land values when the height of the Nile is *h*.

:::

In general, there can be infinitely many different heights, and hence, infinitely many different measures. [William Feller](wikipedia://en/206644) showed in 1938 that a solution for the general case might not exist.[^o4]

When the number of different heights (= measures) is finite, a solution always exists. This was first noted by [Jerzy Neyman](wikipedia://en/2386106) in 1946, and proved as a corollary of the [Dubins–Spanier theorems](wikipedia://en/47101698) in 1961. The problem in this case is called the **[exact division](https://en.wikipedia.org/wiki/Exact_division)** or **consensus division** problem.

## Related problems {#Related_problems}

A related problem is the **problem of similar regions** studied by [Neyman](wikipedia://en/2386106) and [Pearson](wikipedia://en/1643759).[^o6] Here, instead of partitioning the land into *k* subsets, one only looks for a *single* subset, whose value for each measure *v<sub>h</sub>* is *r* times the total value (where *r* is a given constant in \[0,1\]). From existence perspective, the problem is equivalent to the problem of the Nile, as noted by [Georges Darmois](wikipedia://en/28719892).[^o7] However, they differ in the number of required cuts. The optimal number of required cuts for any *r* is described in the [Stromquist–Woodall theorem](wikipedia://en/61768338).
