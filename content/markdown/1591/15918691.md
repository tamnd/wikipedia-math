# Cochran's Q test

::: {#o1 .subject cue=lead name="Cochran's Q test"}

**Cochran's $Q$ test** is a [non-parametric](https://en.wikipedia.org/wiki/Non-parametric) [statistical test](https://en.wikipedia.org/wiki/Statistical_test) to verify whether *k* treatments have identical effects in the analysis of two-way [randomized block designs](https://en.wikipedia.org/wiki/Randomized_block_design) wherein the response variable is [binary](wikipedia://en/238686).[^o2][^o3][^o4] It is named after [William Gemmell Cochran](wikipedia://en/2223833). Cochran's Q test should not be confused with [Cochran's C test](wikipedia://en/33166191), which is a variance outlier test. Put in simple technical terms, Cochran's Q test requires that there only be a binary response (e.g. success/failure or 1/0) and that there be more than two groups of the same size. The test assesses whether the proportion of successes is the same between groups. Often it is used to assess if different observers of the same phenomenon have consistent results (interobserver variability).[^o5]

:::

## Background {#Background}

Cochran's Q test assumes that there are *k* > 2 experimental treatments and that the observations are arranged in *b* [blocks](wikipedia://en/1822339); that is,

::: {#o7 .table cue=table}

|  | Treatment 1 | Treatment 2 | $\cdots$ | Treatment *k* |
|---|---|---|---|---|
| Block 1 | *X*<sub>11</sub> | *X*<sub>12</sub> | $\cdots$ | *X*<sub>1*k*</sub> |
| Block 2 | *X*<sub>21</sub> | *X*<sub>22</sub> | $\cdots$ | *X*<sub>2*k*</sub> |
| Block 3 | *X*<sub>31</sub> | *X*<sub>32</sub> | $\cdots$ | *X*<sub>3*k*</sub> |
| $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ |
| Block *b* | *X*<sub>*b*1</sub> | *X*<sub>*b*2</sub> | $\cdots$ | *X*<sub>*b*k</sub> |

:::

The "blocks" here might be individual people or other organisms.[^o8] For example, if *b* respondents in a survey had each been asked *k* Yes/No questions, the Q test could be used to test the null hypothesis that all questions were equally likely to elicit the answer "Yes".

## Description {#Description}

Cochran's Q test is

Null hypothesis (H<sub>0</sub>): the treatments are equally effective.

Alternative hypothesis (H<sub>a</sub>): there is a difference in effectiveness between treatments.

The Cochran's Q test statistic is

$$T = k\left(k-1\right)\frac{\sum\limits_{j=1}^k \left(X_{\bullet j} - \frac{N}{k}\right)^2}{\sum\limits_{i=1}^b X_{i\bullet}\left(k-X_{i\bullet}\right)}$$

where

*k* is the number of treatments

*X<sub>• j</sub>* is the column total for the *j*<sup>th</sup> treatment

*b* is the number of blocks

*X<sub>i •</sub>* is the row total for the *i*<sup>th</sup> block

*N* is the grand total

## Critical region {#Critical_region}

For [significance level](https://en.wikipedia.org/wiki/Significance_level) α, the asymptotic critical region is

$$T > \chi^2_{1-\alpha,k-1}$$

where Χ<sup>2</sup><sub>1 − α,k − 1</sub> is the (1 − α)-[quantile](wikipedia://en/25184) of the [chi-squared distribution](wikipedia://en/113424) with *k* − 1 degrees of freedom. The null hypothesis is rejected if the test statistic is in the critical region. If the Cochran test rejects the null hypothesis of equally effective treatments, pairwise [multiple comparisons](https://en.wikipedia.org/wiki/Multiple_comparisons) can be made by applying Cochran's Q test on the two treatments of interest.

The exact distribution of the T statistic may be computed for small samples. This allows obtaining an exact critical region. A first algorithm had been suggested in 1975 by Patil[^o11] and a second one has been made available by Fahmy and Bellétoile[^o12] in 2017.

## Assumptions {#Assumptions}

Cochran's Q test is based on the following assumptions:

1. If the large sample approximation is used (and not the exact distribution), *b* is required to be "large".
1. The blocks were randomly selected from the population of all possible blocks.
1. The outcomes of the treatments can be coded as binary responses (i.e., a "0" or "1") in a way that is common to all treatments within each block.

## Related tests {#Related_tests}

- The [Friedman test](wikipedia://en/3175261) or [Durbin test](wikipedia://en/15913557) can be used when the response is not binary but ordinal or continuous.
- When there are exactly two treatments the Cochran Q test is equivalent to [McNemar's test](wikipedia://en/3305230), which is itself equivalent to a two-tailed [sign test](wikipedia://en/3319766).
