# Ridgeline plot

::: {#o1 .subject cue=lead name="Ridgeline plot"}

A **ridgeline plot** (also known as a **joyplot**[^o2][^o3]) is a series of line plots that are combined by vertical stacking to allow the easy visualization of changes through space or time. The plots are often overlapped slightly to allow the changes to be more clearly contrasted.[^o4][^o5][^o6][^o7]

*Image: Ridgelineplot.png.* An example of a ridgeline plot showing the distributions of wages for a sample of firms over a series of years from a panel data set
