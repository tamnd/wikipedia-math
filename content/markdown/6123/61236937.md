# List of things named after John Horton Conway

::: {#o1 .subject cue=lead name="List of things named after John Horton Conway"}

This is a list of things named after the English mathematician [John Horton Conway](wikipedia://en/15807) (1937–2020).

:::

::: {#o2 .entry cue=list-entry name="Conway algebra"}

- [Conway algebra](wikipedia://en/34977753) – an algebraic structure introduced by Paweł Traczyk and [Józef H. Przytycki](https://en.wikipedia.org/wiki/Józef_H._Przytycki)[^o3]

:::

::: {#o4 .entry cue=list-entry name="Conway's base 13 function"}

- [Conway's base 13 function](wikipedia://en/11151490) – a function used as a counterexample to the converse of the [intermediate value theorem](wikipedia://en/14884)[^o5]

:::

::: {#o6 .entry cue=list-entry name="Conway chained arrow notation"}

- [Conway chained arrow notation](wikipedia://en/305456) – a notation for expressing certain extremely large numbers[^o7]

:::

::: {#o8 .entry cue=list-entry name="Conway circle"}

- [Conway circle](https://en.wikipedia.org/wiki/Conway_circle) – a geometrical construction based on extending the sides of a triangle[^o9]

:::

::: {#o10 .entry cue=list-entry name="Conway criterion"}

- [Conway criterion](wikipedia://en/42806211) – a criterion for identifying [prototiles](wikipedia://en/39372) that admit a periodic tiling[^o11]

:::

::: {#o12 .entry cue=list-entry name="Conway group"}

- [Conway group](wikipedia://en/345511) – any of the groups [Co<sub>0</sub>](wikipedia://en/344919#Symmetries), [Co<sub>1</sub>](wikipedia://en/36237614), [Co<sub>2</sub>](wikipedia://en/36237532), or [Co<sub>3</sub>](wikipedia://en/36237581)[^o13]

:::

::: {#o14 .entry cue=list-entry name="Conway group Co1"}

- [Conway group Co<sub>1</sub>](wikipedia://en/36237614) – one of the [sporadic simple groups](https://en.wikipedia.org/wiki/Sporadic_simple_group) discovered by Conway in 1968[^o13]

:::

::: {#o15 .entry cue=list-entry name="Conway group Co2"}

- [Conway group Co<sub>2</sub>](wikipedia://en/36237532) – one of the sporadic simple groups discovered by Conway in 1968[^o13]

:::

::: {#o16 .entry cue=list-entry name="Conway group Co3"}

- [Conway group Co<sub>3</sub>](wikipedia://en/36237581) – one of the sporadic simple groups discovered by Conway in 1968[^o13]

:::

::: {#o17 .entry cue=list-entry name="Conway knot"}

- [Conway knot](wikipedia://en/3727038) – a curious knot having the same Alexander polynomial and Conway polynomial as the unknot

:::

::: {#o18 .entry cue=list-entry name="Conway notation (knot theory)"}

- [Conway notation (knot theory)](wikipedia://en/17066309) – a notation invented by Conway for describing knots in [knot theory](wikipedia://en/153008)[^o19]

:::

::: {#o20 .entry cue=list-entry name="Conway polyhedron notation"}

- [Conway polyhedron notation](wikipedia://en/5021705) – notation invented by Conway used to describe polyhedra[^o25]

:::

::: {#o21 .entry cue=list-entry name="Conway polynomial (finite fields)"}

- [Conway polynomial (finite fields)](wikipedia://en/30798197) – an irreducible polynomial used in finite field theory[^o25]

:::

::: {#o22 .entry cue=list-entry name="Conway puzzle"}

- [Conway puzzle](wikipedia://en/5745790) – a packing problem invented by Conway using rectangular blocks[^o34]

:::

::: {#o23 .entry cue=list-entry name="Conway sphere"}

- [Conway sphere](wikipedia://en/34978322) – a [2-sphere](wikipedia://en/39782) intersecting a given knot in the 3-sphere or [3-ball](wikipedia://en/160556) [transversely](https://en.wikipedia.org/wiki/Transversality_%28mathematics%29) in four points[^o19]

:::

::: {#o24 .entry cue=list-entry name="Conway triangle notation"}

- [Conway triangle notation](wikipedia://en/15910144) – notation which allows trigonometric functions of a triangle to be managed algebraically[^o25]

:::

::: {#o26 .entry cue=list-entry name="Conway's 99-graph problem"}

- [Conway's 99-graph problem](wikipedia://en/59939359) – a problem invented by Conway asking if a certain undirected graph exists[^o27]

:::

::: {#o28 .entry cue=list-entry name="Conway sequence"}

- [Conway sequence](https://en.wikipedia.org/wiki/Conway_sequence) – a self-referential sequence in which each term describes the digits of the previous term

:::

::: {#o29 .entry cue=list-entry name="Conway's constant"}

- [Conway's constant](https://en.wikipedia.org/wiki/Conway's_constant) – a constant used in the study of the [Look-and-say sequence](wikipedia://en/563980)[^o30]

:::

::: {#o31 .entry cue=list-entry name="Conway's dead fly problem"}

- [Conway's dead fly problem](https://en.wikipedia.org/wiki/Conway's_dead_fly_problem) – does there exist a [Danzer set](wikipedia://en/59958932) whose points are separated at a bounded distance from each other?[^o32]

:::

::: {#o33 .entry cue=list-entry name="Conway's Game of Life"}

- [Conway's Game of Life](wikipedia://en/37035) – a cellular automaton defined on the two-dimensional orthogonal grid of square cells[^o34]

:::

::: {#o35 .entry cue=list-entry name="Conway's Soldiers"}

- [Conway's Soldiers](wikipedia://en/2017897) – a one-person mathematical game resembling [peg solitaire](https://en.wikipedia.org/wiki/Peg_solitaire)[^o36]

:::

::: {#o37 .entry cue=list-entry name="Conway's thrackle conjecture"}

- [Conway's thrackle conjecture](https://en.wikipedia.org/wiki/Conway's_thrackle_conjecture) – In graph theory, the conjecture that no [thrackle](wikipedia://en/9797288) has more edges than vertices

:::

::: {#o38 .entry cue=list-entry name="Alexander–Conway polynomial"}

- [Alexander–Conway polynomial](https://en.wikipedia.org/wiki/Alexander–Conway_polynomial) – a knot invariant which assigns a polynomial to each knot type in [knot theory](wikipedia://en/153008)[^o19]

:::
