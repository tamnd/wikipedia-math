# Quasitopos

::: {#o1 .subject cue=lead name="Quasitopos"}

In [mathematics](wikipedia://en/18831), specifically [category theory](wikipedia://en/5869), a **quasitopos** is a generalization of a [topos](wikipedia://en/21391464). A topos has a [subobject classifier](wikipedia://en/366909) classifying all subobjects, but in a quasitopos, only strong subobjects are classified. Quasitoposes are also required to be [finitely cocomplete](wikipedia://en/62781) and locally cartesian closed.[^o2] A solid quasitopos is one for which 0 is a strong subobject of 1.[^o3]

:::
