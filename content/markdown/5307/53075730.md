# Michaelis–Menten–Monod kinetics

::: {#o1 .subject cue=lead name="Michaelis–Menten–Monod kinetics"}

**Michaelis–Menten–Monod** (**MMM**) **kinetics** involves the coupling of an enzyme-driven [chemical reaction](https://en.wikipedia.org/wiki/Chemical_reaction) of the [Michaelis–Menten](wikipedia://en/253272) type[^o2] with the [Monod](wikipedia://en/34476926) growth of an organism that performs the chemical reaction.[^o3] The enzyme-driven reaction can be conceptualized as the binding of an enzyme E with the substrate S to form an intermediate complex C, which releases the reaction product P and the unchanged enzyme E. During the metabolic consumption of S, biomass B is produced, which synthesizes the enzyme, thus feeding back to the chemical reaction. The two processes can be expressed as

:::

::: {#o4 .equation cue=numblk name="1"}

$$\ce{{S} + {E} <=>[{k}_{1}][{k}_{-1}] {C} ->[{k}] {P} + {E}} \tag{1}$$

:::

::: {#o5 .equation cue=numblk name="2"}

$$\ce{{S} ->[{Y}] {B} ->[{z}] {E}} \tag{2}$$

:::

where $k_1$ and $k_{-1}$ are the forward and backward equilibrium rate constants, $k$ is the [reaction rate constant](https://en.wikipedia.org/wiki/Reaction_rate_constant) for product release, $Y$ is the biomass yield coefficient, and $z$ is the enzyme yield coefficient.

## Transient kinetics {#Transient_kinetics}

The kinetic equations describing the reactions above can be derived from the [GEBIK](https://en.wikipedia.org/wiki/Transient_kinetic_isotope_fractionation) equations[^o7] and are written as

::: {#o8 .equation cue=numblk name="3a"}

$$\frac{\text{d}[S]}{\text{d}t} = -k_1[S][E] + k_{-1}[C], \tag{3a}$$

:::

::: {#o9 .equation cue=numblk name="3b"}

$$\frac{\text{d}[C]}{\text{d}t} = k_1[S][E] - k_{-1}[C] - k[C], \tag{3b}$$

:::

::: {#o10 .equation cue=numblk name="3c"}

$$\frac{\text{d}[P]}{\text{d}t} = k[C], \tag{3c}$$

:::

::: {#o11 .equation cue=numblk name="3d"}

$$\frac{\text{d}[B]}{\text{d}t} = - Y \frac{\text{d}[S]}{\text{d}t} - \mu_B [B], \tag{3d}$$

:::

::: {#o12 .equation cue=numblk name="3e"}

$$\frac{\text{d}[E]}{\text{d}t} = - zY \frac{\text{d}[S]}{\text{d}t} - \frac{\text{d}[C]}{\text{d}t} - \mu_E [E], \tag{3e}$$

:::

where $\mu_B$ is the biomass mortality rate and $\mu_E$ is the enzyme degradation rate. These equations describe the full transient kinetics, but cannot be normally constrained to experiments because the complex C is difficult to measure and there is no clear consensus on whether it actually exists.

## Quasi-steady-state kinetics {#Quasi-steady-state_kinetics}

Equations 3 can be simplified by using the quasi-steady-state (QSS) approximation, that is, for $\frac{\text{d}[C]}{\text{d}t} = 0$;[^o14] under the QSS, the kinetic equations describing the MMM problem become

::: {#o15 .equation cue=numblk name="4a"}

$$\frac{\text{d}[S]}{\text{d}t} = -k [E]\frac{[S]}{K+[S]} , \tag{4a}$$

:::

::: {#o16 .equation cue=numblk name="4b"}

$$\frac{\text{d}[P]}{\text{d}t} = -\frac{\text{d}[S]}{\text{d}t}, \tag{4b}$$

:::

::: {#o17 .equation cue=numblk name="4c"}

$$\frac{\text{d}[B]}{\text{d}t} = - Y \frac{\text{d}[S]}{\text{d}t} - \mu_B [B], \tag{4c}$$

:::

::: {#o18 .equation cue=numblk name="4d"}

$$\frac{\text{d}[E]}{\text{d}t} = - zY \frac{\text{d}[S]}{\text{d}t} - \mu_E [E], \tag{4d}$$

:::

where $K = (k_{-1} +k)/k_1$ is the [Michaelis–Menten constant](https://en.wikipedia.org/wiki/Michaelis–Menten_constant) (also known as the half-saturation concentration and affinity).

## Implicit analytic solution {#Implicit_analytic_solution}

If one hypothesizes that the enzyme is produced at a rate proportional to the biomass production and degrades at a rate proportional to the biomass mortality, then Eqs. 4 can be rewritten as

::: {#o20 .equation cue=numblk name="4a"}

$$\frac{\text{d}[P]}{\text{d}t} = k [E]\frac{[S]}{K+[S]} , \tag{4a}$$

:::

::: {#o21 .equation cue=numblk name="4b"}

$$\frac{\text{d}[S]}{\text{d}t} = -\frac{\text{d}[P]}{\text{d}t}, \tag{4b}$$

:::

::: {#o22 .equation cue=numblk name="4c"}

$$\frac{\text{d}[B]}{\text{d}t} = Y \frac{\text{d}[P]}{\text{d}t} - \mu_B [B], \tag{4c}$$

:::

::: {#o23 .equation cue=numblk name="4d"}

$$\frac{\text{d}[E]}{\text{d}t} = - z \frac{\text{d}[B]}{\text{d}t} , \tag{4d}$$

:::

where $S$, $P$, $E$, $B$ are explicit function of time $t$. Note that Eq. (4b) and (4d) are linearly dependent on Eqs. (4a) and (4c), which are the two differential equations that can be used to solve the MMM problem. An implicit analytic solution[^o24] can be obtained if $P$ is chosen as the independent variable and $t(P)$, $S(P)$, $E(P)$ and $B(P$) are rewritten as functions of $P$ so to obtain

::: {#o25 .equation cue=numblk name="5a"}

$$\frac{\text{d}t(P)}{\text{d}P} = \left(k z B(P)\frac{S_0 -P}{K +S_0 -P} \right)^{-1}, \tag{5a}$$

:::

::: {#o26 .equation cue=numblk name="5b"}

$$\frac{\text{d}B(P)}{\text{d}P} = Y - \mu_B B(P) \frac{\text{d}t(P)}{\text{d}P}, \tag{5b}$$

:::

where $S(t)$ has been substituted by $S(P)= S_0 -P$ as per mass balance $S_0 +P_0 = S+P$, with the initial value $S_0 = S(P)$ when $P=P_0=0$, and where $E(t)$ has been substituted by $zB(P)$ as per the linear relation $E = z B$ expressed by Eq. (4d). The analytic solution to Eq. (5b) is

::: {#o27 .equation cue=numblk name="6"}

$$B(P) = B_0+ \left(Y -\frac{\mu_B }{k z}\right) P + \frac{ \mu_BK }{k z}\ln\left( 1-\frac{P}{S_0} \right) , \tag{6}$$

:::

with the initial biomass concentration $B_0 = B(P)$ when $P=0$. To avoid the solution of a [transcendental function](wikipedia://en/297021), a polynomial Taylor expansion to the second-order in $P$ is used for $B(P)$ in Eq. (6) as

::: {#o28 .equation cue=numblk name="7"}

$$B(P) = B_0 + \left(Y -\frac{\mu_B }{zk} - \frac{\mu_B K}{zkS_0} \right)P - \frac{\mu_B K}{2 zk S_0^2 } P^2 +O(P^3) \tag{7}$$

:::

Substituting Eq. (7) into Eq. (5a} and solving for $t(P)$ with the initial value $t(P=0) = 0$, one obtains the implicit solution for $t(P)$ as

::: {#o29 .equation cue=numblk name="8"}

$$t(P) = -\frac{F'}{2} \ln \left( \frac{ \sqrt{Q}+2HP+M }{ \sqrt{Q}-2HP-M } \right) - \frac{ K }{ 2N'}\ln\left(\frac{(S_0-P)^2}{HP^2 +MP+N }\right) + \frac{F'}{2} \ln\left( \frac{ \sqrt{Q}+M }{ \sqrt{Q} -M } \right) - \frac{ K }{ 2N'}\ln\left(\frac{S_0^2}{N }\right). \tag{8}$$

:::

with the constants

::: {#o30 .equation cue=numblk name="9a"}

$$H = -\mu_B K/2S_0^2 < 0, \tag{9a}$$

:::

::: {#o31 .equation cue=numblk name="9b"}

$$M = k zY -\mu_B - \frac{\mu_B K}{S_0}, N = k z B_0 > 0, \tag{9b}$$

:::

::: {#o32 .equation cue=numblk name="9c"}

$$M' = -(M+2HS_0), N' = N + M S_0 + H S_0^2 \neq 0, \tag{9c}$$

:::

::: {#o33 .equation cue=numblk name="9d"}

$$-Q =4HN-M^2 \ne 0, \tag{9d}$$

:::

::: {#o34 .equation cue=numblk name="9e"}

$$F = \frac{2}{\sqrt{-Q}} - \frac{KM'}{N'\sqrt{-Q}}, F' = \frac{2}{\sqrt{Q}} - \frac{KM'}{N'\sqrt{Q}}, \tag{9e}$$

:::

For any chosen value of $P$, the biomass concentration can be calculated with Eq. (7) at a time $t(P)$ given by Eq. (8). The corresponding values of $S(P) = S_0-P$ and $E(P) = zB(P)$ can be determined using the mass balances introduced above.
