# Axiom of finite choice

::: {#o1 .subject cue=lead name="Axiom of finite choice"}

In [mathematics](wikipedia://en/18831), the **axiom of finite choice** is a weak version of the [axiom of choice](wikipedia://en/840) which asserts that if $(S_\alpha)_{\alpha \in A}$ is a family of [non-empty](wikipedia://en/9566) *[finite sets](wikipedia://en/11742)*, then

:::

$\prod_{\alpha \in A} S_\alpha \neq \emptyset$ ([set-theoretic product](wikipedia://en/24104095#Infinite_products)).[^o5]

If every set can be [linearly ordered](wikipedia://en/30330), the axiom of finite choice follows.[^o5]

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

An important application is that when $(\Omega, 2^\Omega, \nu)$ is a [measure space](wikipedia://en/45270) where $\nu$ is the [counting measure](wikipedia://en/191786) and $f: \Omega \to \mathbb R$ is a [function](wikipedia://en/185427) such that

$$\int_\Omega |f| d \nu < \infty,$$

then $f(\omega) \neq 0$ for at most [countably many](https://en.wikipedia.org/wiki/Countable) $\omega \in \Omega$.

:::
