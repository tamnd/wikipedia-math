# Meissel–Lehmer algorithm

::: {#o1 .subject cue=lead name="Meissel–Lehmer algorithm"}

The **Meissel–Lehmer algorithm** (after [Ernst Meissel](https://en.wikipedia.org/wiki/Ernst_Meissel) and [Derrick Henry Lehmer](https://en.wikipedia.org/wiki/Derrick_Henry_Lehmer)) is an [algorithm](wikipedia://en/775) that computes exact values of the [prime-counting function](wikipedia://en/331826).[^o11][^o12]

:::

## Description {#Description}

The problem of counting the exact number of primes less than or equal to *x*, without actually listing them all, dates from [Legendre](wikipedia://en/49695). He observed from the [Sieve of Eratosthenes](wikipedia://en/73415) that

$$\pi (x) - \pi (x^{1/2}) + 1 = \lfloor x \rfloor - \sum_{i} \lfloor x/p_i \rfloor + \sum_{i<j} \lfloor x/p_ip_j \rfloor - \ldots$$

where $\lfloor x\rfloor$ is the [floor function](wikipedia://en/54267), which denotes the greatest [integer](wikipedia://en/14563) less than or equal to $x$ and the $p_{i}$ run over all primes $\le \sqrt{x}$.[^o11][^o12]

Since the evaluation of this sum formula becomes more and more complex and confusing for large *$x$*, Meissel tried to simplify the counting of the numbers in the Sieve of Eratosthenes. He and Lehmer therefore introduced certain sieve functions, which are detailed below.

### Key functions {#Key_functions}

Let $p_{1}, p_{2}, \ldots, p_{n}$ be the first $n$ primes. For a [natural number](wikipedia://en/21474) $a \ge 1$, define

$$\varphi(x, a) := \left| \left \{ n \le x : p|n \implies p > p_a \right \} \right|,$$

which counts natural numbers no greater than *$x$* with all prime factors greater than $p_{a}$. Also define for a natural number $k$,

$$P_k(x, a) := \left| \left \{ n \le x : n = q_1 q_2 \cdots q_k, ~\text{with}~ q_1, \ldots, q_k > p_a \right \} \right|,$$

which counts natural numbers no greater than *$x$* with exactly *$k$* prime factors, all greater than $p_{a}$. With these, we have

$$\varphi(x, a) = \sum_{k=0}^\infty P_k(x, a),$$

where the sum only has finitely many nonzero terms because $P_{k}(x, a) = 0$ when $p^{k}_{a} > x$. Using the fact that $P_{0}(x, a) = 1$ and $P_{1}(x, a) = \pi(x) - a$, we get

$$\pi(x) = \varphi(x,a) + a - 1 - \sum_{k=2}^\infty P_k(x,a),$$

which proves that one may compute $\pi(x)$ by computing $\varphi(x,a)$ and $P_{k}(x, a)$ for $k \ge 2$. This is what the Meissel–Lehmer algorithm does.

::: {#o5 .statement cue=named-heading name="Formula for Pk(x, a)"}

### Formula for *P*<sub>*k*</sub>(*x*, *a*) {#Formula_for_Pk(x,_a)}

For $k = 2$, we get the following formula for $P_{k}(x, a)$:

$$\begin{aligned} P_2(x, a) & =\left| \left\{ n : n \le x,~ n = p_b p_c, ~\text{with}~ a < b \le c \right\} \right| \\ & = \sum_{b = a+1}^{\pi(x^{1/2})} \left| \left\{ n : n \le x,~ n = p_b p_c, ~\text{with}~ b \le c \le \pi \left( \frac{x}{p_b} \right) \right\} \right| \\ & = \sum_{b = a+1}^{\pi(x^{1/2})} \left( \pi\left( \frac{x}{p_b} \right) - (b-1) \right) \\ & = \binom{a}{2} - \binom{\pi(x^{1/2})}{2} + \sum_{b = a+1}^{\pi(x^{1/2})} \pi\left( \frac{x}{p_b} \right). \end{aligned}$$

For $k \ge 3$, the identities for $P_{k}(x, a)$ can be derived similarly.[^o11]

:::

### Expanding $\varphi(x, a)$ {#Expanding}

With the starting condition

$$\varphi(x, 0) = \lfloor x \rfloor,$$

and the recurrence

$$\varphi(x, a) = \varphi(x, a-1) - \varphi\left(\frac x {p_a}, a-1 \right),$$

each value for $\varphi(x,a)$ can be calculated recursively.

### Combining the terms {#Combining_the_terms}

The only thing that remains to be done is evaluating $\varphi(x,a)$ and $P_{k}(x, a)$ for $k \ge 2$, for certain values of $x$ and $a$. This can be done by direct sieving and using the above formulas.

## History {#History}

Meissel already found that for $k \ge 3$, $P_{k}(x, a) = 0$ if $a = \pi(x^{1/3})$. He used the resulting equation for calculations of $\pi(x)$ for big values of $x$. [^o11]

Meissel calculated $\pi(x)$ for values of *$x$* up to $10^{9}$, but he narrowly missed the correct result for the biggest value of *$x$*.[^o11]

Using his method and an [IBM 701](https://en.wikipedia.org/wiki/IBM_701), Lehmer was able to compute the correct value of $\pi(10^{9})$ and missed the correct value of $\pi(10^{10})$ by 1.[^o11]

## Extended algorithm {#Extended_algorithm}

[Jeffrey Lagarias](wikipedia://en/4327781), [Victor Miller](https://en.wikipedia.org/wiki/Victor_S._Miller) and [Andrew Odlyzko](wikipedia://en/1986042) published a realisation of the algorithm which computes $\pi(x)$ in time $O(x^{2/3+\varepsilon})$ and space $O(x^{1/3+\varepsilon})$ for any $\varepsilon > 0$.[^o12] Upon setting $a = \pi(x^{1/3})$, the tree of $\varphi(x,a)$ has $O(x^{2/3})$ leaf nodes.[^o12]

This extended Meissel-Lehmer algorithm needs less computing time than the algorithm developed by Meissel and Lehmer, especially for big values of *$x$*.

Further improvements of the algorithm are given by M. Deleglise and J. Rivat in 1996 and X. Gourdon in 2001 (unpublished).[^o13][^o14]
