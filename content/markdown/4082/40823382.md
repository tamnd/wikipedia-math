# Reshetnyak gluing theorem

::: {#o1 .subject cue=lead name="Reshetnyak gluing theorem"}

In [metric geometry](https://en.wikipedia.org/wiki/Metric_geometry), the **Reshetnyak gluing theorem** gives information on the structure of a geometric object built by using as building blocks other geometric objects, belonging to a well defined [class](https://en.wikipedia.org/wiki/Class_%28mathematics%29). Intuitively, it states that a space obtained by joining (i.e. "*gluing*") together, in a precisely defined way, other spaces having a given property inherit that very same property.

:::

The theorem was first stated and proved by [Yurii Reshetnyak](wikipedia://en/39391531) in 1968.[^o2]

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

::: {#o5 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** Let $X_i$ be [complete](wikipedia://en/7832) [locally compact](https://en.wikipedia.org/wiki/Locally_compact) [geodesic](wikipedia://en/91096#Metric_geometry) [metric spaces](wikipedia://en/20018) of [CAT curvature](wikipedia://en/12941912) $\leq \kappa$, and $C_i\subset X_i$ [convex subsets](wikipedia://en/6292) which are [isometric](wikipedia://en/254777). Then the [manifold](wikipedia://en/2073470) $X$, obtained by gluing all $X_i$ along all $C_i$, is also of CAT curvature $\leq \kappa$.

For an exposition and a proof of the Reshetnyak Gluing Theorem, see (Burago Burago Ivanov 2001, Theorem 9.1.21).

:::
