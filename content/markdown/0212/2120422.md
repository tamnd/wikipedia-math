# Parity P

::: {#o1 .subject cue=lead name="Parity P"}

In [computational complexity theory](wikipedia://en/7543), the [complexity class](wikipedia://en/502426) ⊕**P** (pronounced "parity P") is the class of [decision problems](wikipedia://en/8336) solvable by a [nondeterministic Turing machine](wikipedia://en/21935) in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), where the acceptance condition is that the number of accepting computation paths is odd. An example of a ⊕**P** problem is "does a given graph have an odd number of [perfect matchings](wikipedia://en/44031)?" The class was defined by [Papadimitriou](https://en.wikipedia.org/wiki/Christos_Papadimitriou) and [Zachos](https://en.wikipedia.org/wiki/Stathis_Zachos) in 1983.[^o2]

:::

An example of a ⊕**P**-complete problem (under polynomial-time [many-one reductions](wikipedia://en/362983)) is ⊕SAT: given a Boolean formula, is the number of its satisfying assignments odd? This follows from the proof of the [Cook–Levin theorem](wikipedia://en/663047) because the reduction used is [parsimonious](https://en.wikipedia.org/wiki/Parsimonious_reduction).[^o3]

⊕**P** is a counting class, and can be seen as finding the least significant bit of the answer to the corresponding **[\#P](https://en.wikipedia.org/wiki/Sharp-P)** problem. The problem of finding the most significant bit is in **[PP](wikipedia://en/659322)**. **PP** is believed to be a considerably harder class than ⊕**P**; for example, there is a relativized universe (see [oracle machine](wikipedia://en/22431)) where **P** = ⊕**P** ≠ **[NP](wikipedia://en/21562)** = **PP** = **[EXPTIME](wikipedia://en/54694)**, as shown by Beigel, [Buhrman](https://en.wikipedia.org/wiki/Harry_Buhrman), and [Fortnow](wikipedia://en/25303350) in 1998.[^o4]

While [Toda's theorem](wikipedia://en/18125091) shows that **P**<sup>**PP**</sup> contains **[PH](https://en.wikipedia.org/wiki/PH_%28complexity%29)**, the class **P**<sup>⊕**P**</sup> is not known to even contain **NP**. However, the first part of the proof of Toda's theorem shows that **[BPP](wikipedia://en/4079)**<sup>⊕**P**</sup> contains **PH**. Lance Fortnow has written a concise proof of this theorem.[^o5]

⊕**P** contains the [graph automorphism problem](https://en.wikipedia.org/wiki/Graph_automorphism_problem), and in fact this problem is [low](wikipedia://en/2006468) for ⊕**P**.[^o6] It also trivially contains **[UP](wikipedia://en/312240)**, since all solutions to problems in **UP** have either zero or one accepting paths. More generally, ⊕**P** is [low](wikipedia://en/2006468) for itself, meaning that such a machine gains no power from being able to solve any ⊕**P** problem instantly.

The ⊕ symbol in the name of the class may be a reference to use of the symbol ⊕ in [Boolean algebra](https://en.wikipedia.org/wiki/Boolean_algebra_%28logic%29) to refer the [exclusive disjunction](https://en.wikipedia.org/wiki/Exclusive_disjunction) operator. This makes sense because if we consider "accepts" to be 1 and "not accepts" to be 0, the result of the machine is the exclusive disjunction of the results of each computation path.
