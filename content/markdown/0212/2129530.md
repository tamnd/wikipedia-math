# Species discovery curve

::: {#o1 .subject cue=lead name="Species discovery curve"}

In [ecology](https://en.wikipedia.org/wiki/Ecology), the **species discovery curve** (also known as a **species accumulation curve** or **collector's curve**[^o2]) is a graph recording the cumulative number of [species](https://en.wikipedia.org/wiki/Species) of living things recorded in a particular environment as a function of the cumulative effort expended searching for them (usually measured in person-hours). It is related to, but not identical with, the [species-area curve](https://en.wikipedia.org/wiki/Species-area_curve).

:::

The species discovery curve will necessarily be increasing, and will normally be negatively accelerated (that is, its rate of increase will slow down). Plotting the curve gives a way of estimating the number of additional species that will be discovered with further effort. This is usually done by fitting some kind of functional form to the curve, either by eye or by using non-linear [regression](wikipedia://en/826997) techniques. Commonly used functional forms include the [logarithmic](wikipedia://en/17860) function and the negative [exponential function](wikipedia://en/9678). The advantage of the negative exponential function is that it tends to an [asymptote](wikipedia://en/3107) which equals the number of species that would be discovered if infinite effort is expended. However, some theoretical approaches imply that the logarithmic curve may be more appropriate, implying that though species discovery will slow down with increasing effort, it will never entirely cease, so there is no asymptote, and if infinite effort was expended, an infinite number of species would be discovered. An example in which one would not expect the function to asymptote is in the study of genetic sequences where new mutations and sequencing errors may lead to infinite variants.

The first theoretical investigation of the species-discovery process was in a classic paper by Fisher, Corbet and Williams (1943), which was based on a large collection of [butterflies](https://en.wikipedia.org/wiki/Butterfly) made in [Malaya](https://en.wikipedia.org/wiki/British_Malaya). Theoretical statistical work on the problem continues, see for example the recent paper by [Chao](wikipedia://en/55880292) and Shen (2004). The theory is linked to that of [Zipf's law](wikipedia://en/43218).

The same approach is used in many other fields. For example, in [ethology](https://en.wikipedia.org/wiki/Ethology), it can be applied to the number of distinct [fixed action patterns](https://en.wikipedia.org/wiki/Fixed_action_pattern) that will be discovered as a function of cumulative effort studying the behaviour of a species of animal; in [molecular genetics](https://en.wikipedia.org/wiki/Molecular_genetics) it is now being applied to the number of distinct [genes](https://en.wikipedia.org/wiki/Gene) that are discovered; and in literary studies, it can be used to estimate the total [vocabulary](https://en.wikipedia.org/wiki/Vocabulary) of a writer from the given sample of their recorded works.[^o3]
