# Pointcheval–Stern signature algorithm

::: {#o1 .subject cue=lead name="Pointcheval–Stern signature algorithm"}

In [cryptography](wikipedia://en/18934432), the **Pointcheval–Stern signature algorithm** is a [digital signature](wikipedia://en/59644) scheme based on the closely related [ElGamal signature scheme](wikipedia://en/2033473). It changes the ElGamal scheme slightly to produce an algorithm which has been proven secure in a strong sense against [adaptive chosen-message attacks](https://en.wikipedia.org/wiki/Adaptive_chosen-message_attack), assuming the [discrete logarithm problem](https://en.wikipedia.org/wiki/Discrete_logarithm_problem) is intractable in a strong sense.[^o2][^o3]

:::

[David Pointcheval](wikipedia://en/62511448) and [Jacques Stern](https://en.wikipedia.org/wiki/Jacques_Stern_%28cryptographer%29) developed the *[forking lemma](wikipedia://en/19075862)* technique in constructing their proof for this algorithm. It has been used in other security investigations of various cryptographic algorithms.
