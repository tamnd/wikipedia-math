# Erdős–Stone theorem

::: {#o1 .subject cue=lead name="Erdős–Stone theorem"}

In [extremal graph theory](wikipedia://en/529568), the **Erdős–Stone theorem** is an [asymptotic](https://en.wikipedia.org/wiki/Asymptotic) result generalising [Turán's theorem](wikipedia://en/360601) to bound the number of edges in an *H*-free graph for a non-[complete graph](wikipedia://en/85816) *H*. It is named after [Paul Erdős](wikipedia://en/601284) and [Arthur Stone](https://en.wikipedia.org/wiki/Arthur_Stone_%28mathematician%29), who proved it in 1946,[^o2] and it has been described as the “fundamental theorem of extremal graph theory”.[^o3]

:::

## Statement for Turán graphs {#Statement_for_Turán_graphs}

The *extremal number* ex(*n*; *H*) is defined to be the maximum number of edges in a graph with *n* vertices not containing a subgraph isomorphic to *H*; see the [Forbidden subgraph problem](wikipedia://en/21682838) for more examples of problems involving the extremal number. Turán's theorem says that ex(*n*; *K*<sub>*r*</sub>) = *t*<sub>*r* − 1</sub>(*n*), the number of edges of the [Turán graph](wikipedia://en/360581) *T*(*n*, r − 1), and that the Turán graph is the unique such extremal graph. The Erdős–Stone theorem extends this result to *H* = *K*<sub>*r*</sub>(*t*), the complete *r*-partite graph with *t* vertices in each class, which is the graph obtained by taking *K<sub>r</sub>* and replacing each vertex with *t* independent vertices:

$$\mbox{ex}(n; K_r(t)) = \left( \frac{r-2}{r-1} + o(1) \right){n\choose2}.$$

## Statement for arbitrary non-bipartite graphs {#Statement_for_arbitrary_non-bipartite_graphs}

If *H* is an arbitrary graph whose [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) is *r* > 2, then *H* is contained in *K*<sub>*r*</sub>(*t*) whenever *t* is at least as large as the largest color class in an *r*-coloring of *H*, but it is not contained in the Turán graph *T*(*n*,*r* − 1), as this graph and therefore each of its subgraphs can be colored with *r* − 1 colors. It follows that the extremal number for *H* is at least as large as the number of edges in *T*(*n*,*r* − 1), and at most equal to the extremal function for *K*<sub>*r*</sub>(*t*); that is,

$$\mbox{ex}(n; H) = \left( \frac{r-2}{r-1} + o(1) \right){n\choose2}.$$

For [bipartite graphs](wikipedia://en/244431) *H*, however, the theorem does not give a tight bound on the extremal function. It is known that, when *H* is bipartite, ex(*n*; *H*) = *o*(*n*<sup>2</sup>), and for general bipartite graphs little more is known. See [Zarankiewicz problem](wikipedia://en/3480707) for more on the extremal functions of bipartite graphs.

## Turán density {#Turán_density}

Another way of describing the Erdős–Stone theorem is using the Turán density of a graph $H$, which is defined by $\pi(H) = \lim_{n \to \infty}\frac{\text{ex}(n; H)}{n \choose 2}$. This determines the extremal number $\text{ex}(n; H)$ up to an additive $o(n^2)$ error term. It can also be thought of as follows: given a sequence of graphs $G_1, G_2, \dots$, each not containing $H$, such that the number of vertices goes to infinity, the Turán density is the maximum possible limit of their edge densities. The Erdős–Stone theorem determines the Turán density for all graphs, showing that any graph $H$ with chromatic number $r > 2$ has a Turán density of

> $$\pi(H) = \frac{r - 2}{r - 1}.$$

## Proofs {#Proofs}

### Saturation {#Saturation}

One proof of the Erdős–Stone theorem uses an extension of the [Kővári–Sós–Turán](https://en.wikipedia.org/wiki/Kövari-Sós-Turán_theorem) theorem to [hypergraphs](wikipedia://en/232535), as well as the [supersaturation theorem](wikipedia://en/21682838#Supersaturation), by creating a corresponding hypergraph for every graph that is $K_r(t)$-free and showing that the hypergraph has some bounded number of edges. The Kővári–Sós–Turán says, among other things, that the extremal number of $K_2(t)$, the complete bipartite graph with $t$ vertices in each part, is at most $\text{ex}(K_2(t); n) \leq Cn^{2 - 1/t}$ for a constant $C$. This can be extended to hypergraphs: defining $K_{s, \dots, s}^{(r)}$ to be the $r$-partite $r$-graph with $s$ vertices in each part, then $\text{ex}(K_{s, \dots, s}^{(r)}, n) \leq Cn^{r - s^{1-r}}$ for some constant $C$.

Now, for a given graph $H = K_r(t)$ with $r > 1, s \geq 1$, and some graph $G$ with $n$ vertices that does not contain a subgraph isomorphic to $H$, we define the $r$-graph $F$ with the same vertices as $G$ and a hyperedge between vertices in $F$ if they form a [clique](wikipedia://en/524466) in $G$. Note that if $F$ contains a copy of $K_{s, \dots, s}^{(r)}$, then the original graph $G$ contains a copy of $H$, as every pair of vertices in distinct parts must have an edge. Thus, $F$ contains no copies of $K_{s, \dots, s}^{(r)}$, and so it has $o(n^r)$ hyperedges, indicating that there are $o(n^r)$ copies of $K_r$ in $G$. By supersaturation, this means that the edge density of $G$ is within $o(1)$ of the Turán density of $K_{r}$, which is $\frac{r - 2}{r - 1}$ by [Turán's theorem](wikipedia://en/360601); thus, the edge density is bounded above by $\frac{r - 2}{r - 1}+ o(1)$.

On the other hand, we can achieve this bound by taking the [Turán graph](wikipedia://en/360581) $T(n, r-1)$, which contains no copies of $K_r(t)$ but has $\left( \frac{r - 2}{r - 1} - o(1) \right){n \choose 2}$ edges, showing that this value is the maximum and concluding the proof.

### Counting Paths {#Counting_Paths}

Another proof of the Erdős–Stone theorem works by generalising the proof of the [Kővári–Sós–Turán theorem](https://en.wikipedia.org/wiki/Kővári–Sós–Turán_theorem), counting paths of length two in a high minimum degree subgraph of the original graph $G$.[^o11] This starts with a lemma to find a subgraph with high minimum degree, then a lemma that finds an $r$-partite [Turán graph](wikipedia://en/360581) given a graph with high minimum degree, and finally the application of both lemmas to prove the Erdős–Stone theorem.

For purposes of notation, let $V(G)$ be the set of vertices of a graph $G$ and $e(G)$ be the number of edges of a graph $G$.

The first lemma states the following: consider some real number $c \in (0,1)$, let $\varepsilon > 0$ and let $G$ be a graph on $n$ vertices with $e(G)$ edges such that:

$$e(G) \geq c \cdot \binom{n}{2}$$

Then there is a subgraph $G'$ of $G$ with $n'$ vertices such that $n' \geq \varepsilon n$ and the minimum degree of $G'$ is greater than or equal to $(c - \varepsilon) n'$.

To prove this the idea is to continually remove vertices if they have a lower degree than what we want. Formally, consider a series of graphs $G = G_n \supset G_{n-1} \supset \cdots \supset G_t$ obtained by doing the following:

1. If there is a vertex $v_i \in V(G_i)$ that has degree $d_{G_i}(v_i) < (c - \varepsilon) v(G_i)$, then define $G_{i-1} = G_i - v_i$ (in the case there are multiple, pick an arbitrary vertex).
1. Otherwise, the minimum degree of $G_i$ is greater than or equal to $(c - \varepsilon) v(G_i)$, and therefore the process terminates at $t = i$.

To prove that this process ends at some $t \geq \varepsilon n$, we will use contradiction. Assuming that $t < \varepsilon n$ the following bounds can be obtained:

$$e(G) < \sum_{i = t+1}^n (c - \varepsilon)i + \binom{t}{2} \leq (c - \varepsilon)\binom{n}{2} + \varepsilon \binom{n}{2} = c \cdot \binom{n}{2}$$

This means that $e(G) < c \cdot \binom{n}{2}$, which contradicts the initial assumption that $e(G) \geq c \cdot \binom{n}{2}$. Therefore, the process must terminate at some $t \geq \varepsilon n$, and the subgraph $G'$ can be found.

The second lemma states the following: for any $r, t \in \mathbb{N}$ and $\varepsilon > 0$, there exists some $n_0 \in \mathbb{N}$ such that when given a graph $G$ with $n \geq n_0$ vertices and minimum degree greater than or equal to:

$$\left( 1 - \frac{1}{r} + \varepsilon \right) n$$

We can guarantee that the $(r+1)$-partite [Turán graph](wikipedia://en/360581) with components of size $t$ (referred to as $K_{r+1}(t)$) is a subgraph of $G$.

This can be proved by induction on $r$. The base case is equivalent to the [Kővári–Sós–Turán theorem](https://en.wikipedia.org/wiki/Kővári–Sós–Turán_theorem). For the inductive step, first find a copy of $K_r(q)$ with $q \geq \frac{t}{\varepsilon}$.

Now, define $A_1, A_2, \cdots, A_r$ the $r$ components of $K_r(q)$, with the vertices of $K_r(q)$ being $A$, define $B = V(G) / A$ and additionally define:

$$X = \bigcap_{i=1}^r \{v \in B : |N(v) \cap A_i| \geq t\}$$

Counting the number of edges between $A$ and $B$ it can be derived that:

$$e(A,B) \leq |X| \cdot qr + (|B| - |X|)(q(r-1) + t-1)$$

While the minimum degree condition will yield that:

$$e(A,B) \geq \left( 1 - \frac{1}{r} + \varepsilon \right) \cdot n \cdot qr - (qr)^2$$

After manipulating these two inequalities, using that $|B| \leq n$ it can be concluded that:

$$\varepsilon q r n \leq (t-1)n + |X| (q - t + 1) + (qr)^2$$

Then, since $q \geq \frac{t}{\varepsilon}$ we can conclude that $|X| \to \infty$ as $n \to \infty$. After this, using the infinite [pigeonhole principle](wikipedia://en/54217) it can be concluded that there must be a $K_{r+1}(t)$, finishing the induction.

Now, the theorem can be proved with these lemmas. Consider a fixed graph $H$ with $\chi(H) = r+1$ and a graph $G$ with a large enough number of vertices $n$ such that:

$$e(G) \geq \left( 1 - \frac{1}{r} + 2 \varepsilon \right) \binom{n}{2}$$

Then, by Lemma 1 there exists some subgraph $G'$ with $n' \geq \epsilon n$ vertices with that has minimum degree of at least:

$$\left( 1 - \frac{1}{r} + \varepsilon \right) n'$$

Now, let $t$ be the size of the largest independent set of vertices in $H$. By Lemma 2, given a large enough $\varepsilon n$ (which we can guarantee by increasing $n$) we can find some $K_{r+1}(t)$ in $G'$. But then, $H \subseteq K_{r+1}(t) \subset G' \subset G$, proving the Erdős–Stone theorem.

:::

## Quantitative results {#Quantitative_results}

Several versions of the theorem have been proved that more precisely characterise the relation of *n*, *r*, *t* and the [*o*(1)](https://en.wikipedia.org/wiki/Little-o_notation) term. Define the notation[^o13] *s*<sub>*r*,ε</sub>(*n*) (for 0 \< ε \< 1/(2(*r* − 1))) to be the greatest *t* such that every graph of order *n* and size

$$\left( \frac{r-2}{2(r-1)} + \varepsilon \right)n^2$$

contains a *K*<sub>*r*</sub>(*t*).

Erdős and Stone proved that

$$s_{r,\varepsilon}(n) \geq \left(\underbrace{\log\cdots\log}_{r-1} \, n\right)^{1/2}$$

for *n* sufficiently large. The correct order of *s*<sub>*r*,ε</sub>(*n*) in terms of *n* was found by Bollobás and Erdős:[^o14] for any given *r* and ε there are constants *c*<sub>1</sub>(*r*, ε) and *c*<sub>2</sub>(*r*, ε) such that *c*<sub>1</sub>(*r*, ε) log *n* \< *s*<sub>*r*,ε</sub>(*n*) \< *c*<sub>2</sub>(*r*, ε) log *n*. Chvátal and Szemerédi[^o15] then determined the nature of the dependence on *r* and ε, up to a constant:

$\frac{1}{500\log(1/\varepsilon)}\log n < s_{r,\varepsilon}(n) < \frac{5}{\log(1/\varepsilon)}\log n$ for sufficiently large *n*.
