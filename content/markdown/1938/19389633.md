# Tarski–Seidenberg theorem

::: {#o1 .subject cue=lead name="Tarski–Seidenberg theorem"}

In [mathematics](wikipedia://en/18831), the **Tarski–Seidenberg theorem** is a theorem on [semialgebraic sets](wikipedia://en/13329722), that is, subsets of [real coordinate spaces](wikipedia://en/1482083) that can be defined by a finite set of [polynomial equations](https://en.wikipedia.org/wiki/Polynomial_equation) and polynomial [inequalities](wikipedia://en/89489). This theorem was proved by [Alfred Tarski](wikipedia://en/59920) in 1930 in view of his proof that the theory of [real closed fields](wikipedia://en/1066093) is [complete](wikipedia://en/10086335) (every formula can be proved either as true or as false) and admits [quantifier elimination](wikipedia://en/2150441). The theorem was later discovered independently by [Abraham Seidenberg](https://en.wikipedia.org/wiki/Abraham_Seidenberg) in the context of [constructive mathematics](https://en.wikipedia.org/wiki/Constructive_mathematics).[^o2]

:::

The theorem states that, given a set $S$ in the $(n + 1)$-dimensional space, which is defined by polynomial equations and inequalities involving $(n + 1)$ variables, the projection eliminating one of the variables can be defined similarly. In other words, if $\mathcal F(y, x_1, \ldots, x_n)$ is the formula defining $S$, there exists a formula $\mathcal G(x_1, \ldots, x_n)$ that define the same set as $\exists y \mid \mathcal F(y,x_1, \ldots, x_n)$.

Although the original [proof](wikipedia://en/82285) of the theorem was [constructive](wikipedia://en/360113), the resulting algorithm is [galactic](wikipedia://en/60819045), that is, it has a [computational complexity](wikipedia://en/6511) that is far too high for using the method on a computer. [George E. Collins](wikipedia://en/41768958) introduced the algorithm of [cylindrical algebraic decomposition](wikipedia://en/12218154), which allows quantifier elimination over the reals in [double exponential time](https://en.wikipedia.org/wiki/Double_exponential_time). This complexity is optimal, as there are examples where the output has a double exponential number of connected components. Collins's algorithm is therefore fundamental and widely used in [computational algebraic geometry](https://en.wikipedia.org/wiki/Computational_algebraic_geometry).

## First order formulas {#First_order_formulas}

A *formula* of the [first-order theory](https://en.wikipedia.org/wiki/First-order_theory) of the [real numbers](wikipedia://en/20646438) is a [well-formed formula](wikipedia://en/404582) involved only the [quantifier](wikipedia://en/43507260) $\forall, \exists$, the [logical connectives](https://en.wikipedia.org/wiki/Logical_connectives) $\land, \lor, \lnot$, real numbers and [variables](wikipedia://en/3728109) representing real numbers, [equality](wikipedia://en/90446) and [inequality](wikipedia://en/89489) signs $=, <, \le$, and the basic [arithmetic operators](https://en.wikipedia.org/wiki/Arithmetic_operator) $+,-,\times, /$.

A formula is *quantifier free* if does not involve any quantifier. Two formulas are equivalent if they evaluate to the same [truth value](wikipedia://en/161711) for every choice of (real) values for the variables. In particular, a formula is true or false for every values of the variables if it is equivalent to $0=0$ or $1=0$

*Elimination of quantifiers* consists of providing an algorithm that, for every formula computes an equivalent quantifier-free formula. If quantifier elimination occurs, the theory is complete in the sense that one can decide whether a variable-free formula is true of false.

Tarski–Seidenberg theorem is that quantifier elimination is possible in the first-order theory of the real numbers, and thus that this theory is complete

:::

## Semialgebraic sets {#Semialgebraic_sets}

A *semialgebraic set* is a set defined by a quantifier-free formula of the first-order theory of the real numbers. By standard logical ([disjunctive normal form](wikipedia://en/73341)) and algebraic manipulations, it is straightforward to show that a semialgebraic set in **R**<sup>*n*</sup> is formed by taking a finite [union](wikipedia://en/47949) of *basic semialgebraic sets*. A basic semialgebraic set is the set of all points that simultaneously satisfy a finite number of polynomial equations and inequalities of the form

$$p(x_1,\ldots,x_n)=0\,$$

and

$$q(x_1,\ldots,x_n)>0\,$$

for [polynomials](wikipedia://en/23000) *p* and *q*.

For example, a basic semialgebraic set in $\mathbb{R}$ either consists of a finite number of points or is a finite union of [open intervals](https://en.wikipedia.org/wiki/Open_interval). Conversely a singleton formed by an algebraic number is a basic semialgebraic set, and every interval (open of not) is a semialgebraic set if its end points are algebraic numbers.

## Method of proof {#Method_of_proof}

All known proofs of the theorem work by recurrence on the number of variables. For this purpose, one considers a projection map $\pi : \mathbf{R}^{n+1} \to \mathbf{R}^{n}$ that sends the point $(x_{1}, ..., x_{n}, x_{n+1})$ to $(x_{1}, ..., x_{n})$.

The main step of the proof of the theorem is to prove the fundamental property that, if $Y$ is a semialgebraic set in $\mathbf{R}^{n+1}$ for some $n \ge 1$, then $X = \pi(Y)$ is a semialgebraic set in $\mathbf{R}^{n}$.

Moreover, given a semialgebraic decomposition of $X$ in disjoint basic semialgebraic sets $B_i$, one gets a decomposition of $Y$ into basic semialgebraic sets of the for $B_i\cap C_{i,j}$, where each $C_{i,j}$ is a basic semialgebraic set in the single variable $x_{n+1}$ that is either a point or an open interval.

In the case of one variable, every semialgebraic set is the union of semialgebraic sets that are reduced to a single point or an open interval (see [Real-root isolation](wikipedia://en/44012866)). Using this, one can recursively suppose that all involved polynomials have a constant sign ($+,-$ or $0$) on each basic semialgebraic set appearing in the decomposition. So, one can test the truth of a quantified formula by testing it on a finite number of sample points, one for each basic semialgebraic point of the decomposition. This allows proving the theorem.

## Failure with algebraic sets {#Failure_with_algebraic_sets}

If we only define sets using polynomial equations and not inequalities then we define [algebraic sets](https://en.wikipedia.org/wiki/Algebraic_set) rather than *semi*algebraic sets. For these sets the theorem fails, i.e. projections of algebraic sets need not be algebraic. As a simple example consider the [hyperbola](wikipedia://en/14052) in **R**<sup>2</sup> defined by the equation

$$xy-1=0.\,$$

This is a perfectly good algebraic set, but projecting it down by sending (*x*, *y*) in **R**<sup>2</sup> to *x* in **R** produces the set of points satisfying *x* ≠ 0. This is a semialgebraic set, but it is not an algebraic set as the algebraic sets in **R** are **R** itself, the [empty set](wikipedia://en/9566) and the finite sets.

This example shows also that, over the [complex numbers](wikipedia://en/5826), the projection of an algebraic set may be non-algebraic. Thus the existence of real algebraic sets with non-algebraic projections does not rely on the fact that the [field](wikipedia://en/10603) of real numbers is not [algebraically closed](https://en.wikipedia.org/wiki/Algebraically_closed).

However, one often define *quasialgebraic sets* similarly as semialgebraic sets, simply by replacing "real" with "complex" and $>$ with $\ne$. Everything that is said above on semialgebraic sets remains true for quasialgebraic set, with much simpler proofs. In particular, the first-order theory of complex numbers is complete and has quantifier elimination, the projection of a quasialgebraic set is quasialgebraic, etc.

Forexample consider the [hyperbola](wikipedia://en/14052) defined by the equation

$$xy-1=0.$$

Over the real numbers, its projection onto the $x$-axis is the union of the half lines $(0, \infty)$ and $(- \infty, 0)$, a semialgebraic set that is not an algebraic set. Over the complex, the projection is the complement of $0$, defined as $\{x\in \mathbb{C} \mid x\ne 0\}$, which is a quasialgebraic set but not an algebrraic set.

## Relation to structures {#Relation_to_structures}

This result confirmed that semialgebraic sets in **R**<sup>*n*</sup> form what is now known as an [o-minimal structure](https://en.wikipedia.org/wiki/O-minimal_structure) on **R**. These are collections of subsets *S*<sub>*n*</sub> of **R**<sup>*n*</sup> for each *n* ≥ 1 such that we can take finite unions and complements of the subsets in *S*<sub>*n*</sub> and the result will still be in *S*<sub>*n*</sub>, moreover the elements of *S*<sub>1</sub> are simply finite unions of [intervals](wikipedia://en/49172) and points. The final condition for such a collection to be an o-minimal structure is that the projection map on the first *n* coordinates from **R**<sup>*n*+1</sup> to **R**<sup>*n*</sup> must send subsets in *S*<sub>*n*+1</sub> to subsets in *S*<sub>*n*</sub>. The Tarski–Seidenberg theorem tells us that this holds if *S*<sub>*n*</sub> is the set of semialgebraic sets in **R**<sup>*n*</sup>.
