# List of implementations of differentially private analyses

::: {#o1 .subject cue=lead name="List of implementations of differentially private analyses"}

Lists Since the advent of [differential privacy](wikipedia://en/23473696), a number of systems supporting differentially private data analyses have been implemented and deployed. This article tracks real-world deployments, production software packages, and research prototypes.

:::

## Production software packages {#Production_software_packages}

These software packages purport to be usable in production systems. They are split in two categories: those focused on answering statistical queries with differential privacy, and those focused on training [machine learning](wikipedia://en/233488) models with differential privacy.

### Statistical analyses {#Statistical_analyses}

::: {#o23 .table cue=table}

| Name | Developer | Year Introduced | Notes | Still maintained? |
|---|---|---|---|---|
| Google's differential privacy libraries[^o24] | [Google](https://en.wikipedia.org/wiki/Google) | 2019 | Building block libraries in Go, C++, and Java; end-to-end framework in Go.[^o25] | Yes |
| OpenDP[^o26] | [Harvard](https://en.wikipedia.org/wiki/Harvard), [Microsoft](https://en.wikipedia.org/wiki/Microsoft) | 2020 | Core library in Rust,[^o27] [SDK](https://en.wikipedia.org/wiki/Software_development_kit) in Python with an SQL interface. | Yes |
| Tumult Analytics[^o28] | Tumult Labs[^o29] | 2022 | Python library, running on [Apache Spark](https://en.wikipedia.org/wiki/Apache_Spark). | Yes |
| PipelineDP[^o30] | [Google](https://en.wikipedia.org/wiki/Google), OpenMined[^o31] | 2022 | Python library, running on [Apache Spark](https://en.wikipedia.org/wiki/Apache_Spark), [Apache Beam](https://en.wikipedia.org/wiki/Apache_Beam), or locally. | Yes |
| PSI (Ψ): A **P**rivate data **S**haring **I**nterface | [Harvard University](https://en.wikipedia.org/wiki/Harvard_University) Privacy Tools Project.[^o32] | 2016 |  | No |
| TopDown Algorithm[^o33] | [United States Census Bureau](wikipedia://en/57070) | 2020 | Production code used in the [2020 US Census](https://en.wikipedia.org/wiki/2020_United_States_census). | No |

:::
