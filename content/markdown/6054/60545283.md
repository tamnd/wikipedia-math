# Ordered exponential field

::: {#o1 .subject cue=lead name="Ordered exponential field"}

In [mathematics](wikipedia://en/18831), an **ordered exponential field** is an [ordered field](wikipedia://en/22430) together with a function which generalises the idea of exponential functions on the ordered field of real numbers.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An exponential $E$ on an ordered field $K$ is a strictly increasing [isomorphism](wikipedia://en/12397) of the additive group of $K$ onto the multiplicative group of positive elements of $K$. The ordered field $K\,$ together with the additional function $E\,$ is called an ordered exponential field.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The canonical example for an ordered exponential field is the ordered field of real numbers **R** with any function of the form $a^x$ where $a$ is a real number greater than 1. One such function is the usual [exponential function](wikipedia://en/9678), that is *E*(*x*) = [*e*](wikipedia://en/9633)<sup>*x*</sup>. The ordered field **R** equipped with this function gives the ordered real exponential field, denoted by **R**<sub>exp</sub>. It was proved in the 1990s that **R**<sub>exp</sub> is [model complete](wikipedia://en/15931153), a result known as [Wilkie's theorem](wikipedia://en/22304328). This result, when combined with Khovanskiĭ's theorem on [pfaffian functions](wikipedia://en/14644287), proves that **R**<sub>exp</sub> is also [o-minimal](https://en.wikipedia.org/wiki/O-minimal).[^o6] [Alfred Tarski](wikipedia://en/59920) posed the question of the decidability of **R**<sub>exp</sub> and hence it is now known as [Tarski's exponential function problem](wikipedia://en/16073214). It is known that if the real version of [Schanuel's conjecture](wikipedia://en/2031353) is true then **R**<sub>exp</sub> is decidable.[^o7]
- The ordered field of [surreal numbers](wikipedia://en/51432) $\mathbf{No}$ admits an exponential which extends the exponential function exp on **R**. Since $\mathbf{No}$ does not have the [Archimedean property](wikipedia://en/264158), this is an example of a non-Archimedean ordered exponential field.
- The ordered field of [logarithmic-exponential transseries](wikipedia://en/58151408) $\mathbb{T}^{LE}$ is constructed specifically in a way such that it admits a canonical exponential.

:::

::: {#o9 .pointer-item cue=pointer name="Exponentially closed field"}

## Formally exponential fields {#Formally_exponential_fields}

A formally exponential field, also called an exponentially closed field, is an ordered field that can be equipped with an exponential $E$. For any formally exponential field $K$, one can choose an exponential $E$ on $K$ such that $1+1/n<E(1)<n$ for some natural number $n$.[^o10]

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every ordered exponential field $K$ is *root-closed*, i.e., every positive element of $K\,$ has an $n$-th root for all positive integers $n$ (or in other words the multiplicative group of positive elements of $K\,$ is [divisible](wikipedia://en/472147)). This is so because $E\left(\frac{1}{n}E^{-1}(a)\right)^n=E(E^{-1}(a))=a$ for all $a>0$.
- Consequently, every ordered exponential field is a [Euclidean field](wikipedia://en/12756005).
- Consequently, every ordered exponential field is an ordered [Pythagorean field](wikipedia://en/31032774).
- Not every [real-closed field](https://en.wikipedia.org/wiki/Real-closed_field) is a formally exponential field, e.g., the field of real [algebraic numbers](wikipedia://en/1158) does not admit an exponential. This is so because an exponential $E$ has to be of the form $E(x)=a^x\,$ for some $1<a\in K$ in every formally exponential subfield $K$ of the real numbers; however, $E(\sqrt{2})=a^\sqrt{2}$ is not algebraic if $1<a$ is algebraic by the [Gelfond–Schneider theorem](wikipedia://en/609487).
- Consequently, the class of formally exponential fields is not an [elementary class](wikipedia://en/1284226) since the field of real numbers and the field of real algebraic numbers are [elementarily equivalent](https://en.wikipedia.org/wiki/Elementarily_equivalent) structures.
- The class of formally exponential fields is a [pseudoelementary class](wikipedia://en/12747956). This is so since a field $K\,$ is exponentially closed if and only if there is a surjective function $E_2\colon K\rightarrow K^+$ such that $E_2(x+y)=E_2(x)E_2(y)$ and $E_2(1)=2$; and these properties of $E_2$ are axiomatizable.

:::
