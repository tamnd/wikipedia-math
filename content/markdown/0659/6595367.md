# Hewitt–Savage zero–one law

::: {#o1 .subject cue=lead name="Hewitt–Savage zero–one law"}

The **Hewitt–Savage zero–one law** is a [theorem](wikipedia://en/30977) in [probability theory](wikipedia://en/23542), similar to [Kolmogorov's zero–one law](wikipedia://en/191797) and the [Borel–Cantelli lemma](wikipedia://en/44987), that specifies that a certain type of event will either [almost surely](wikipedia://en/351908) happen or almost surely not happen. It is sometimes known as the **Savage-Hewitt law for symmetric events**. It is named after [Edwin Hewitt](wikipedia://en/7482590) and [Leonard Jimmie Savage](https://en.wikipedia.org/wiki/Leonard_Jimmie_Savage).[^o2]

:::

::: {#o4 .statement cue=named-heading name="Statement of the Hewitt-Savage zero-one law"}

## Statement of the Hewitt-Savage zero-one law {#Statement_of_the_Hewitt-Savage_zero-one_law}

Let $\left\{ X_n \right\}_{n = 1}^\infty$ be a [sequence](wikipedia://en/27838) of [independent and identically distributed random variables](wikipedia://en/30876902) taking values in a set $\mathbb{X}$. The Hewitt-Savage zero–one law says that any event whose occurrence or non-occurrence is determined by the values of these random variables and whose occurrence or non-occurrence is unchanged by finite [permutations](wikipedia://en/44027) of the indices, has [probability](wikipedia://en/22934) either 0 or 1 (a “finite” permutation is one that leaves all but finitely many of the indices fixed).

Somewhat more abstractly, define the [exchangeable sigma algebra](wikipedia://en/76015102#Exchangeable_sigma_algebra) or *sigma algebra of symmetric events* $\mathcal{E}$ to be the set of events (depending on the sequence of variables $\left\{ X_n \right\}_{n = 1}^\infty$) which are invariant under finite [permutations](wikipedia://en/44027) of the indices in the sequence $\left\{ X_n \right\}_{n = 1}^\infty$. Then $A \in \mathcal{E} \implies \mathbb{P} (A) \in \{ 0, 1 \}$.

Since any finite permutation can be written as a product of [transpositions](https://en.wikipedia.org/wiki/Transposition_%28mathematics%29), if we wish to check whether or not an event $A$ is symmetric (lies in $\mathcal{E}$), it is enough to check if its occurrence is unchanged by an arbitrary transposition $(i, j)$, $i, j \in \mathbb{N}$.

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

Let the sequence $\left\{ X_n \right\}_{n = 1}^\infty$ of independent and identically distributed random variables taking values in $\mathbb{R}$. Consider the random walk $S_N= \sum_{n = 1}^N X_n$. Then one of the following occurs with probability 1:

- $$S_N=0$$
- $$S_N\to\infty$$
- $$S_N\to-\infty$$
- $\liminf S_N = -\infty$ and $\limsup S_N = \infty$.

Since *S*<sub>*N*</sub> are not independent the [Kolmogorov's zero–one law](wikipedia://en/191797) is not directly applicable.

First consider the case when *X*<sub>*1*</sub> is a.s. constant. Then with probability 1 we have that either ($S_N=0$), ($S_N\to\infty$) or ($S_N\to-\infty$).

Now consider the case, when *X*<sub>*1*</sub> is not a.s. constant. Then for any $t\in[-\infty,\infty]$ the event $\left\{\limsup S_N\geq t \right\}$ is in the exchangeable sigma algebra. That is because [limit supremum](https://en.wikipedia.org/wiki/Limit_supremum) does not change with finite permutation of the indices. From Hewitt-Savage zero-one law we have that

$$\mathbb{P}\left(\limsup S_N\geq t \right) \in \{0,1\}.$$

There has to exist *t*, where probability switches from 0 to 1 i.e. exists $t^*\in[-\infty,\infty]$ such that $\limsup S_n = t^*$ almost surely. Similarly exists $t_*\in[-\infty,\infty]$ such that $\liminf S_n = t_*$ almost surely.

Since almost surely

$$t^*=\limsup S_N = X_1 + \limsup \sum_{n = 2}^N X_n=X_1+t^*$$

and *X*<sub>*1*</sub> is not a.s. 0, then $t^*$ is not finite. Similarly $t_*$ in not finite.

Therefore, with probability 1 either ($S_N\to\infty$), ($S_N\to-\infty$) or ($\liminf S_N = -\infty$ and $\limsup S_N = \infty$).[^o7]
