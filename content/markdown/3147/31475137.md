# Variable splitting

::: {#o1 .subject cue=lead name="Variable splitting"}

In [applied mathematics](wikipedia://en/24295969) and [computer science](https://en.wikipedia.org/wiki/Computer_science), **variable splitting** is a [decomposition](wikipedia://en/253873) method that [relaxes](https://en.wikipedia.org/wiki/Relaxation_technique_%28mathematics%29) a set of [constraints](wikipedia://en/7418540).[^o2]

:::

## Details {#Details}

When the variable $x$ appears in two sets of constraints, it is possible to substitute the new variables $x_1$ in the first constraints and $x_2$ in the second, and then join the two variables with a new "*linking*" constraint,[^o4] which requires that

$$x_1 = x_2$$

This new linking constraint can be [relaxed](wikipedia://en/6348084) with a [Lagrange multiplier](wikipedia://en/159974); in many applications, a Lagrange multiplier can be interpreted as the *[price](https://en.wikipedia.org/wiki/Price)* of equality between $x_1$ and $x_2$ in the new constraint.

For many problems, relaxing the equality of split variables allows the system to be broken down, enabling each subsystem to be solved separately. This significantly reduces computation time and memory usage. Solving the relaxed problem with variable splitting can give an approximate solution to the initial problem. Using an approximate solution as a "warm start" facilitates the iterative solving of the original problem with only the variable $x$.

This was first introduced by Jörnsten, Näsberg, and Smeds in 1985.[^o6] At the same time, M. Guignard and S. Kim introduced the same idea under the name "Lagrangean Decomposition" (their papers appeared in 1987).[^o7]
