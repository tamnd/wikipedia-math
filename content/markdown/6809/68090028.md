# Bochner's tube theorem

::: {#o1 .subject cue=lead name="Bochner's tube theorem"}

In [mathematics](wikipedia://en/18831), **Bochner's tube theorem** (named for [Salomon Bochner](wikipedia://en/987847)) shows that every function holomorphic on a [tube domain](wikipedia://en/30270129) in $\mathbb{C}^n$ can be extended to the [convex hull](wikipedia://en/40634) of this domain.

:::

::: {#o2 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** Let $\omega \subset \mathbb{R}^n$ be a connected [open set](wikipedia://en/39358). Then every function $f(z)$ holomorphic on the [tube domain](wikipedia://en/30270129) $\Omega = \omega+i \mathbb{R}^n$ can be extended to a function holomorphic on the convex hull $\operatorname{ch}(\Omega)$.

A classic reference is (Bochner Martin 1948)[^o4] (Theorem 9). See also (Hounie 2009)[^o6] and (Noguchi 2020)[^o8] for other proofs.

:::

::: {#o10 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

The generalized version of this theorem was first proved by Kazlow (1979),[^o11] also proved by Boivin and Dwilewicz (1998)[^o12] under more less complicated hypothese.

::: {#o13 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** Let $\omega$ be a connected [submanifold](wikipedia://en/525095) of $\mathbb{R}^n$ of [class](wikipedia://en/1408000)-$C^2$. Then every continuous [CR function](https://en.wikipedia.org/wiki/CR_function) on the tube domain $\Omega(\omega)$ can be continuously extended to a CR function on $\Omega(\text{ach}(\omega)).\ \left(\Omega(\omega) = \omega+i \mathbb{R}^n\subset\mathbb{C}^n\ \left(n\geq 2\right), \text{ach}(\omega):=\omega\cup \text{Int}\ \text{ch}(\omega)\right)$. By "Int ch(S)" we will mean the interior taken in the smallest dimensional space which contains "ch(S)".

:::
