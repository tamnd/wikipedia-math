# Boxicity

*Image: Boxicity.svg.* Example of an intersection graph of axis-parallel rectangles with boxicity two

::: {#o1 .subject cue=lead name="Boxicity"}

In the mathematical field of [graph theory](wikipedia://en/12401), the **boxicity** of a [graph](wikipedia://en/12401) is a [graph invariant](https://en.wikipedia.org/wiki/Graph_invariant) defined to be the minimum [dimension](wikipedia://en/8398) of [Euclidean space](wikipedia://en/9697) required to represent the graph as an [intersection graph](wikipedia://en/7726759) of axis-parallel [closed](wikipedia://en/47279) [boxes](https://en.wikipedia.org/wiki/Box_%28shape%29).[^o2][^o3] That is, there must exist a one-to-one correspondence between the [vertices](wikipedia://en/638899) of the graph and these boxes, such that two boxes intersect if and only if there is an edge connecting the corresponding vertices.

:::

Boxicity was introduced by [Fred S. Roberts](wikipedia://en/26225243) in 1969.[^o4]

This graph cannot be represented as an intersection graph of boxes in $0$-space = $\{0$}, so its boxicity is one.

## Relation to certain graph classes {#Relation_to_certain_graph_classes}

This article only considers [simple, finite, undirected graphs](wikipedia://en/325806).[^o8]

(Roberts 1969) showed that the graph with $2n$ vertices formed by removing a [perfect matching](wikipedia://en/44031) from a [complete graph](wikipedia://en/85816) on $2n$ vertices has boxicity exactly $n$: each pair of disconnected vertices must be represented by boxes that are separated in a different dimension than each other pair. A box representation of this graph with dimension exactly $n$ can be found by thickening each of the $2n$ facets — these are $(n-1)$-cubes — of an $n$-dimensional [hypercube](wikipedia://en/39783) into an $n$-box. Because of these results, this graph has been called the *Roberts graph*,[^o10] although it is better known as the **cocktail party graph** and it can also be understood as the [Turán graph](wikipedia://en/360581) $T(2n,n)$.

The boxicity of a complete graph is defined to be zero.[^o11] Moreover, $\operatorname{box}(G) = 0$ iff $G$ is complete.[^o12]

A graph has boxicity at most one if and only if it is an [interval graph](wikipedia://en/363423); the boxicity of an arbitrary graph $G$ is also the minimum number of interval graphs on the same set of vertices such that the intersection of the edge sets of the interval graphs is $G$. Every [outerplanar graph](wikipedia://en/352343) has boxicity at most two,[^o13] and every [planar graph](wikipedia://en/24314) has boxicity at most three.[^o14]

If a [bipartite graph](wikipedia://en/244431) has boxicity two, then it can be represented as an intersection graph of axis-parallel line segments in the plane (such a graph has *grid dimension* one).[^o15]

(Adiga Bhowmick Chandran 2011) proved that the boxicity of a bipartite graph $G$ is within a factor $2$ of the [order dimension](wikipedia://en/3121852) of the height-two [partially ordered set](wikipedia://en/23572) associated to $G$ as follows: the set of minimal elements corresponds to one partite set of $G$, the set of maximal elements corresponds to the second partite set of $G$, and two elements are comparable if the corresponding vertices are adjacent in $G$. Equivalently, the [order dimension](wikipedia://en/3121852) of a height-two [partially ordered set](wikipedia://en/23572) $P$ is within a factor $2$ of the boxicity of the [comparability graph](wikipedia://en/6978672) of $P$ (which is bipartite, since $P$ has height two).

## Algorithmic results {#Algorithmic_results}

Many graph problems can be solved or approximated more efficiently for graphs with bounded boxicity than they can for other graphs; for instance, the [maximum clique problem](https://en.wikipedia.org/wiki/Maximum_clique_problem) can be solved in polynomial time for graphs with bounded boxicity.[^o18] For some other graph problems, an efficient solution or approximation can be found if a low-dimensional box representation is known.[^o19] However, finding such a representation may be difficult: it is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) to test whether the boxicity of a given graph is at most some given value $K$, even for $K = 2$.[^o20] (Chandran Francis Sivadasan 2010) describe algorithms for finding representations of arbitrary graphs as intersection graphs of boxes, with a dimension that is within a [logarithmic](wikipedia://en/17860) factor of the [maximum degree](wikipedia://en/1374448) of the graph; this result provides an upper bound on the graph's boxicity.

Despite being hard for its natural parameter, boxicity is [fixed-parameter tractable](wikipedia://en/603026) when parameterized by the [vertex cover](wikipedia://en/562782) number of the input graph.[^o22]

## Bounds {#Bounds}

For any graph $G$, $~ \operatorname{box}(G) \le \operatorname{tw}(G) + 2$, where $\operatorname{tw}(G)$ denotes the [treewidth](wikipedia://en/3987086) of $G$.[^o24][^o25]

If a graph $G$ has $m$ edges, then $\operatorname{box}(G) = O \left( \sqrt{m \log m} \right)$.[^o26][^o27]

If a graph $G$ is $k$-[degenerate](wikipedia://en/27545816) (with $k \ge 2$) and has $n$ vertices, then $\operatorname{box}(G) \le (k+2) \lceil 2 \mathrm{e} \log n \rceil$,[^o28] where $\lceil \cdot \rceil$ denotes the [ceiling function](https://en.wikipedia.org/wiki/Ceiling_function).

If a graph $G$ has no complete graph on $t$ vertices as a [minor](wikipedia://en/353042), then $\operatorname{box}(G) = O(t^2 \log t)$,[^o29] while there are graphs with no complete graph on $t$ vertices as a minor, and with $\operatorname{box}(G) = \Omega \left( t \cdot \sqrt{\log t} \right)$.[^o30] In particular, any graph $G$ has $\operatorname{box}(G) = O \left( \mu(G)^2 \log \mu(G) \right)$, where $\mu(G)$ denotes the [Colin de Verdière invariant](https://en.wikipedia.org/wiki/Colin_de_Verdière_graph_invariant) of $G$.

## Related graph invariants {#Related_graph_invariants}

- [Cubicity](wikipedia://en/73506350) is defined in the same way as boxicity but with axis-parallel unit [hypercubes](wikipedia://en/39783) instead of axis-parallel hyperrectangles. Boxicity is a generalization of cubicity.
- [Sphericity](wikipedia://en/73506123) is defined in the same way as boxicity but with [congruent](wikipedia://en/39330) [spheres](wikipedia://en/27859).
