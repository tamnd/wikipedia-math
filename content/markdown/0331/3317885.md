# Rowbottom cardinal

::: {#o1 .subject cue=lead name="Rowbottom cardinal"}

In [set theory](wikipedia://en/27553), a **Rowbottom cardinal**, introduced by [Frederick Rowbottom](wikipedia://en/3889349),[^n1] is a certain kind of [large cardinal](wikipedia://en/383644) number.

:::

An [uncountable](wikipedia://en/32248) [cardinal number](wikipedia://en/6173) $\kappa$ is said to be ***$\lambda$-Rowbottom*** if for every function $f:[\kappa]^{<\omega}\to\lambda$ (where $\lambda < \kappa$) there is a set $H$ of order type $\kappa$ that is quasi-[homogeneous](https://en.wikipedia.org/wiki/Homogeneous_%28large_cardinal_property%29) for $f$, i.e., for every $n$, the $f$-image of the set of $n$-element subsets of $H$ has $<\lambda$ elements. $\kappa$ is simply ***Rowbottom*** if it is ***$\omega_{1}$-Rowbottom***.

Every [Ramsey cardinal](wikipedia://en/326533) is Rowbottom, and every Rowbottom cardinal is [Jónsson](wikipedia://en/3317988). By a theorem of Kleinberg, the theories ZFC + “there is a Rowbottom cardinal” and ZFC + “there is a Jónsson cardinal” are equiconsistent.

In general, Rowbottom cardinals need not be [large cardinals](wikipedia://en/383644) in the usual sense: Rowbottom cardinals could be [singular](https://en.wikipedia.org/wiki/Singular_cardinal). It is an open question whether ZFC + “$\aleph_{\omega}$ is Rowbottom” is consistent. If it is, it has much higher consistency strength than the existence of a Rowbottom cardinal. The [axiom of determinacy](wikipedia://en/1002300) does imply that $\aleph_{\omega}$ is Rowbottom (but contradicts the [axiom of choice](wikipedia://en/840)).
