# Jónsson cardinal

::: {#o1 .subject cue=lead name="Jónsson cardinal"}

In [set theory](wikipedia://en/27553), a **Jónsson cardinal**, named after [Bjarni Jónsson](wikipedia://en/3893573), is a certain kind of [large cardinal](wikipedia://en/383644) number.

:::

An [uncountable](wikipedia://en/32248) [cardinal number](wikipedia://en/6173) $\kappa$ is said to be ***Jónsson*** if for every function $f : [\kappa]^{<\omega} \to \kappa$ there is a set $H$ of order-type $\kappa$, such that for each $n$, $f$ restricted to $n$-element subsets of $H$ omits at least one value in $\kappa$.

Every [Rowbottom cardinal](wikipedia://en/3317885) is Jónsson. By a theorem of Kleinberg, the theories ZFC + “there is a [Rowbottom cardinal](wikipedia://en/3317885)” and ZFC + “there is a Jónsson cardinal” are equiconsistent. Mitchell proved, with the help of the Dodd-Jensen [core model](wikipedia://en/3781904), that the consistency of the existence of a Jónsson cardinal implies the consistency of the existence of a [Ramsey cardinal](wikipedia://en/326533), so that the existence of Jónsson cardinals and the existence of Ramsey cardinals are equiconsistent.[^n1]

In general, Jónsson cardinals need not be large cardinals in the usual sense: they can be [singular](https://en.wikipedia.org/wiki/Singular_cardinal). But the existence of a singular Jónsson cardinal is equiconsistent to the existence of a [measurable cardinal](wikipedia://en/248102). Using the [axiom of choice](wikipedia://en/840), a lot of small cardinals (the $\aleph_n$, for instance) can be proved to be not Jónsson. Results like this need the axiom of choice, however: The [axiom of determinacy](wikipedia://en/1002300) does imply that for every positive natural number $n$, the cardinal $\aleph_n$ is Jónsson.

A **Jónsson algebra** is an algebra with no proper subalgebras of the same cardinality. (They are unrelated to [Jónsson–Tarski algebras](wikipedia://en/43193940).) Here an algebra means a model for a language with a countable number of function symbols, in other words a set with a countable number of functions from finite products of the set to itself. A cardinal is a Jónsson cardinal if and only if there are no Jónsson algebras of that cardinality. The existence of [Jónsson functions](wikipedia://en/18455668) shows that if algebras are allowed to have infinitary operations, then there are no analogues of Jónsson cardinals.
