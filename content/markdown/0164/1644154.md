# IEEE P1363

::: {#o1 .subject cue=lead name="IEEE P1363"}

**IEEE P1363** is an [Institute of Electrical and Electronics Engineers](https://en.wikipedia.org/wiki/Institute_of_Electrical_and_Electronics_Engineers) (IEEE) standardization project for [public-key cryptography](wikipedia://en/24222). It includes specifications for:

:::

- Traditional public-key cryptography (IEEE Std 1363-2000 and 1363a-2004)
- Lattice-based public-key cryptography (IEEE Std 1363.1-2008)
- Password-based public-key cryptography (IEEE Std 1363.2-2008)
- Identity-based public-key cryptography using pairings (IEEE Std 1363.3-2013)

The chair of the working group as of October 2008 is [William Whyte](https://en.wikipedia.org/wiki/William_Whyte_%28cryptographer%29) of NTRU Cryptosystems, Inc., who has served since August 2001. Former chairs were [Ari Singer](https://en.wikipedia.org/wiki/Ari_Singer), also of NTRU (1999–2001), and [Burt Kaliski](wikipedia://en/9371879) of [RSA Security](wikipedia://en/301240) (1994–1999).

The IEEE Standard Association withdrew all of the 1363 standards except 1363.3-2013 on 7 November 2019.[^o2]

## Traditional public-key cryptography (IEEE Std 1363-2000 and 1363a-2004) {#Traditional_public-key_cryptography_(IEEE_Std_1363-2000_and_1363a-2004)}

This specification includes key agreement, signature, and encryption schemes using several mathematical approaches: [integer factorization](wikipedia://en/15491), [discrete logarithm](wikipedia://en/181334), and [elliptic curve discrete logarithm](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography).

### Key agreement schemes {#Key_agreement_schemes}

- **DL/ECKAS-DH1 and DL/ECKAS-DH2** (Discrete Logarithm/Elliptic Curve Key Agreement Scheme, [Diffie–Hellman](https://en.wikipedia.org/wiki/Diffie–Hellman) version): This includes both traditional [Diffie–Hellman](https://en.wikipedia.org/wiki/Diffie–Hellman) and [elliptic curve Diffie–Hellman](https://en.wikipedia.org/wiki/Elliptic_curve_Diffie–Hellman).
- **DL/ECKAS-MQV** (Discrete Logarithm/Elliptic Curve Key Agreement Scheme, [Menezes–Qu–Vanstone](wikipedia://en/1586447) version)

### Signature schemes {#Signature_schemes}

- **DL/ECSSA** (Discrete Logarithm/Elliptic Curve Signature Scheme with Appendix): Includes four main variants: [DSA](wikipedia://en/59470), [ECDSA](https://en.wikipedia.org/wiki/Elliptic_Curve_DSA), Nyberg-Rueppel, and Elliptic Curve Nyberg-Rueppel.
- **IFSSA** (Integer Factorization Signature Scheme with Appendix): Includes two variants of [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29), Rabin-Williams, and ESIGN, with several message encoding methods. "RSA1 with EMSA3" is essentially PKCS#1 v1.5 RSA signature; "RSA1 with EMSA4 encoding" is essentially [RSA-PSS](https://en.wikipedia.org/wiki/RSA-PSS); "RSA1 with EMSA2 encoding" is essentially ANSI X9.31 RSA signature.
- **DL/ECSSR** (Discrete Logarithm/Elliptic Curve Signature Scheme with Recovery)
- **DL/ECSSR-PV** (Discrete Logarithm/Elliptic Curve Signature Scheme with Recovery, Pintsov-Vanstone version)
- **IFSSR** (Integer Factorization Signature Scheme with Recovery)

### Encryption schemes {#Encryption_schemes}

- **IFES** (Integer Factorization Encryption Scheme): Essentially [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) encryption with [Optimal Asymmetric Encryption Padding](https://en.wikipedia.org/wiki/Optimal_Asymmetric_Encryption_Padding) (OAEP).
- **DL/ECIES** (Discrete Logarithm/Elliptic Curve [Integrated Encryption Scheme](wikipedia://en/3530076)): Essentially the "DHAES" variant of [ElGamal encryption](wikipedia://en/59458).
- **IFES-EPOC** (Integer Factorization Encryption Scheme, EPOC version)

- [NTRU encryption scheme](wikipedia://en/481582)

## Password-based public-key cryptography (IEEE Std 1363.2-2008) {#Password-based_public-key_cryptography_(IEEE_Std_1363.2-2008)}

This document includes a number of [password-authenticated key agreement](https://en.wikipedia.org/wiki/Password-authenticated_key_agreement) schemes, and a password-authenticated key retrieval scheme.

- **BPKAS-PAK** (Balanced Password-Authenticated Key Agreement Scheme, version PAK)
- **BPKAS-PPK** (version PPK)
- **BPKAS-SPEKE** (version [SPEKE](https://en.wikipedia.org/wiki/SPEKE_%28cryptography%29))
- **APKAS-AMP** (Augmented Password-Authenticated Key Agreement Scheme, version AMP)
- **APKAS-BSPEKE2** (version BSPEKE2)
- **APKAS-PAKZ** (version PAKZ)
- **APKAS-SRP3 and SRP6** (version [Secure Remote Password](https://en.wikipedia.org/wiki/Secure_Remote_Password_protocol) (SRP) 3 and 6)
- **APKAS-SRP5** (version [Secure Remote Password](https://en.wikipedia.org/wiki/Secure_Remote_Password_protocol) (SRP) 5)
- **APKAS-WSPEKE** (version WSPEKE)
- **PKRS-1** (Password Authenticated Key Retrieval Scheme, version 1)

::: {#o10 .statement cue=named-heading name="Identity-based public key cryptography based on pairings (IEEE Std 1363.3-2013)"}

## Identity-based public key cryptography based on pairings (IEEE Std 1363.3-2013) {#Identity-based_public_key_cryptography_based_on_pairings_(IEEE_Std_1363.3-2013)}

This standard was published on 15 November 2013. It includes techniques for identity-based encryption, signatures, signcryption, key agreement, and proxy re-encryption, all based on bilinear pairings.

:::
