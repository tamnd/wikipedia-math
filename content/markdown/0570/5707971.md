# Weierstrass product inequality

::: {#o1 .subject cue=lead name="Weierstrass product inequality"}

In [mathematics](wikipedia://en/18831), the **Weierstrass product inequality** states that for any real numbers 0 ≤ *x<sub>1</sub>*, *..., x<sub>n</sub>* ≤ 1 we have

:::

$$(1-x_1)(1-x_2)(1-x_3)(1-x_4)....(1-x_n) \geq 1-S_n,$$

and similarly, for 0 ≤ *x<sub>1</sub>*, *..., x<sub>n</sub>,*

$$(1+x_1)(1+x_2)(1+x_3)(1+x_4)....(1+x_n) \geq 1+S_n,$$

where $S_n=x_1+x_2+x_3+x_4+....+x_n.$

The inequality is named after the [German](https://en.wikipedia.org/wiki/Germany) [mathematician](wikipedia://en/18902) [Karl Weierstrass](wikipedia://en/93459).

::: {#o3 .proof cue=heading name="Proof"}

## Proof {#Proof}

The inequality with the subtractions can be proven easily via [mathematical induction](wikipedia://en/18881). The one with the additions is proven identically. We can choose $n = 1$ as the base case and see that for this value of $n$ we get

$$1 -x_1 \geq 1 - x_1$$

which is indeed true. Assuming now that the inequality holds for all natural numbers up to $n > 1$, for $n + 1$ we have:

$$\prod_{i=1}^{n+1}(1-x_i)\,\, = (1-x_{n+1})\prod_{i=1}^{n}(1-x_i)$$

$$\geq (1-x_{n+1})\left(1 - \sum_{i=1}^nx_i\right)$$

$$= 1 - \sum_{i=1}^nx_i - x_{n+1} + x_{n+1}\sum_{i=1}^nx_i$$

$$= 1 - \sum_{i=1}^{n+1}x_i + x_{n+1}\sum_{i=1}^nx_i$$

$$\geq 1 - \sum_{i=1}^{n+1}x_i$$

which concludes the proof.

:::
