# Linear–quadratic regulator

::: {#o1 .subject cue=lead name="Linear–quadratic regulator"}

The theory of [optimal control](wikipedia://en/362565) is concerned with operating a [dynamic system](https://en.wikipedia.org/wiki/Dynamic_system) at minimum cost. The case where the [system dynamics](wikipedia://en/153208) are described by a set of [linear differential equations](wikipedia://en/379868) and the cost is described by a [quadratic](https://en.wikipedia.org/wiki/Quadratic_polynomial) [function](wikipedia://en/1374948) is called the LQ problem. One of the main results in the theory is that the solution is provided by the **linear–quadratic regulator** (**LQR**), a feedback controller whose equations are given below.

:::

LQR controllers possess inherent robustness with guaranteed [gain](https://en.wikipedia.org/wiki/Gain_margin) and [phase margin](wikipedia://en/6768984),[^o2] and they also are part of the solution to the [LQG (linear–quadratic–Gaussian) problem](https://en.wikipedia.org/wiki/Linear-quadratic-Gaussian_control). Like the LQR problem itself, the LQG problem is one of the most fundamental problems in [control theory](wikipedia://en/7039).[^o3]

## General description {#General_description}

The settings of a (regulating) controller governing either a machine or process (like an airplane or [chemical reactor](https://en.wikipedia.org/wiki/Chemical_reactor)) are found by using a mathematical algorithm that minimizes a [cost function](wikipedia://en/442137) with weighting factors supplied by the operator. The cost function is often defined as a sum of the deviations of key measurements, like altitude or process temperature, from their desired values. The algorithm thus finds those controller settings that minimize undesired deviations. The magnitude of the control action itself may also be included in the cost function.

The LQR algorithm reduces the amount of work done by the control systems engineer to optimize the controller. However, the engineer still needs to specify the cost function parameters, and compare the results with the specified design goals. Often this means that controller construction will be an iterative process in which the engineer judges the "optimal" controllers produced through simulation and then adjusts the parameters to produce a controller more consistent with design goals.

The LQR algorithm is essentially an automated way of finding an appropriate [state-feedback controller](https://en.wikipedia.org/wiki/State_space_%28controls%29). As such, it is not uncommon for control engineers to prefer alternative methods, like [full state feedback](wikipedia://en/5425217), also known as pole placement, in which there is a clearer relationship between controller parameters and controller behavior. Difficulty in finding the right weighting factors limits the application of the LQR based controller synthesis.

## Versions {#Versions}

### Finite-horizon, continuous-time {#Finite-horizon,_continuous-time}

Consider a continuous-time linear system, defined on $t \in [t_0, t_1]$, described by

$$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u},$$

where $\mathbf{x} \in \mathbb{R}^n$ (that is, $\mathbf{x}$ is an $n$-dimensional real-valued vector) is the state of the system, and $\mathbf{u} \in \mathbb{R}^m$ is the control input. Given a quadratic cost function for the system, defined as

$$J = \mathbf{x}^\mathsf{T}\!(t_1) F(t_1) \mathbf{x}(t_1) + \int_{t_0}^{t_1} \left( \mathbf{x}^\mathsf{T} Q \mathbf{x} + \mathbf{u}^\mathsf{T} R \mathbf{u} + 2 \mathbf{x}^\mathsf{T} N \mathbf{u} \right) \,dt,$$

where $F$ is the terminal cost matrix, $Q$ is the state cost matrix, $R$ is the control cost matrix, and $N$ is the cross-term (control and state) cost matrix, the feedback control law that minimizes the value of the cost is

$$\mathbf{u} = -K \mathbf{x},$$

where $K$ is given by

$$K = R^{-1} \left(B^\mathsf{T} P(t) + N^\mathsf{T}\right),$$

and $P$ is found by solving the continuous-time [Riccati differential equation](https://en.wikipedia.org/wiki/Riccati_differential_equation)

$$A^\mathsf{T} P(t) + P(t) A - \left[P(t) B + N\right] R^{-1} \left[B^\mathsf{T} P(t) + N^\mathsf{T}\right] + Q = - \dot{P}(t)$$

with the boundary condition

$$P(t_1) = F(t_1).$$

The first-order conditions for $J_\min$ are:

1. State equation $$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}.$$
1. [Co-state equation](https://en.wikipedia.org/wiki/Costate_equations) $$-\dot{\boldsymbol\lambda} = Q\mathbf{x} + N\mathbf{u} + A^\mathsf{T} \boldsymbol\lambda.$$
1. Stationary equation $$\mathbf{0} = R \mathbf{u} + N^\mathsf{T} \mathbf{x} + B^\mathsf{T} \boldsymbol\lambda.$$
1. Boundary conditions $$\mathbf{x}(t_0) = \mathbf{x}_0$$ and $\boldsymbol\lambda(t_1) = F(t_1) \mathbf{x}(t_1).$

### Infinite-horizon, continuous-time {#Infinite-horizon,_continuous-time}

For a continuous-time linear system described by

$$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u},$$

with a cost function defined as

$$J = \int_0^\infty \left( \mathbf{x}^\mathsf{T} Q \mathbf{x} + \mathbf{u}^\mathsf{T} R \mathbf{u} + 2 \mathbf{x}^\mathsf{T} N \mathbf{u} \right) \,dt,$$

the feedback control law that minimizes the value of the cost is

$$\mathbf{u} = -K \mathbf{x},$$

where

$$K = R^{-1} \left(B^\mathsf{T} P + N^\mathsf{T}\right),$$

and $P$ is found by solving the continuous time [algebraic Riccati equation](wikipedia://en/16684054)

$$A^\mathsf{T} P + P A - (P B + N) R^{-1} \left(B^\mathsf{T} P + N^\mathsf{T}\right) + Q = 0.$$

This can be also written as

$$\mathcal A^\mathsf{T} P + P \mathcal A - P B R^{-1} B^\mathsf{T} P + \mathcal Q = 0$$

with

$$\mathcal A = A - B R^{-1} N^\mathsf{T}, \qquad \mathcal Q = Q - N R^{-1} N^\mathsf{T}.$$

### Finite-horizon, discrete-time {#Finite-horizon,_discrete-time}

For a discrete-time linear system described by[^o9]

$$\mathbf{x}_{k+1} = A \mathbf{x}_k + B \mathbf{u}_k,$$

with a performance index defined as

$$J = \mathbf{x}_{H_p}^\mathsf{T} Q_{H_p} \mathbf{x}_{H_p} + \sum_{k=0}^{H_p-1} \left( \mathbf{x}_k^\mathsf{T} Q \mathbf{x}_k + \mathbf{u}_k^\mathsf{T} R \mathbf{u}_k + 2 \mathbf{x}_k^\mathsf{T} N \mathbf{u}_k \right),$$

where $H_p$ is the [time horizon](https://en.wikipedia.org/wiki/Time_horizon), the optimal control sequence minimizing the performance index is given by

$$\mathbf{u}_k = -F_k \mathbf{x}_k,$$

where

$$F_k = \left(R + B^\mathsf{T} P_{k+1} B\right)^{-1} \left(B^\mathsf{T} P_{k+1} A + N^\mathsf{T}\right),$$

and $P_k$ is found iteratively backwards in time by the dynamic Riccati equation

$$P_{k-1} = A^\mathsf{T} P_k A - \left(A^\mathsf{T} P_k B + N\right) \left( R + B^\mathsf{T} P_k B \right)^{-1} \left(B^\mathsf{T} P_k A + N^\mathsf{T}\right) + Q$$

from terminal condition $P_{H_p} = Q_{H_p}$.[^o10] Note that $\mathbf{u}_{H_p}$ is not defined, since $x$ is driven to its final state $\mathbf{x}_{H_p}$ by $A \mathbf{x}_{H_p-1} + B \mathbf{u}_{H_p-1}$.

### Infinite-horizon, discrete-time {#Infinite-horizon,_discrete-time}

For a discrete-time linear system described by

$$\mathbf{x}_{k+1} = A \mathbf{x}_k + B \mathbf{u}_k,$$

with a performance index defined as

$$J = \sum_{k=0}^\infty \left( \mathbf{x}_k^\mathsf{T} Q \mathbf{x}_k + \mathbf{u}_k^\mathsf{T} R \mathbf{u}_k + 2 \mathbf{x}_k^\mathsf{T} N \mathbf{u}_k \right),$$

the optimal control sequence minimizing the performance index is given by

$$\mathbf{u}_k = -F \mathbf{x}_k,$$

where

$$F = \left(R + B^\mathsf{T} P B\right)^{-1} \left(B^\mathsf{T} P A + N^\mathsf{T}\right),$$

and $P$ is the unique positive definite solution to the discrete time [algebraic Riccati equation](wikipedia://en/16684054) (DARE)

$$P = A^\mathsf{T} P A - \left(A^\mathsf{T} P B + N\right) \left( R + B^\mathsf{T} P B \right)^{-1} \left(B^\mathsf{T} P A + N^\mathsf{T}\right) + Q .$$

This can be also written as

$$P = \mathcal A^\mathsf{T} P \mathcal A - \mathcal A^\mathsf{T} P B \left( R + B^\mathsf{T} P B \right)^{-1} B^\mathsf{T} P \mathcal A + \mathcal Q$$

with

$$\mathcal A = A - B R^{-1} N^\mathsf{T}, \qquad \mathcal Q = Q - N R^{-1} N^\mathsf{T}.$$

The algebraic Riccati equation can be solved by iterating the dynamic Riccati equation of the finite-horizon case until it converges.

## Constraints {#Constraints}

In practice, not all values of $\mathbf{x}_k$, $\mathbf{u}_k$ may be allowed. One common constraint is the linear one:

$$C \mathbf{x} + D\mathbf{u} \leq \mathbf{e}.$$

The finite-horizon version of this is a [convex optimization](wikipedia://en/1674411) problem, and so the problem is often solved repeatedly with a receding horizon. This is a form of [model predictive control](wikipedia://en/1100516).[^o13][^o14]

## Related controllers {#Related_controllers}

### Quadratic–quadratic regulator {#Quadratic–quadratic_regulator}

If the state equation is quadratic, then the problem is known as the quadratic–quadratic regulator (QQR). The [Al'Brekht algorithm](https://en.wikipedia.org/wiki/Al'Brekht_algorithm) can be applied to reduce this problem to one that can be solved efficiently using tensor-based linear solvers.[^o17]

### Polynomial–quadratic regulator {#Polynomial–quadratic_regulator}

If the state equation is [polynomial](wikipedia://en/23000), then the problem is known as the polynomial–quadratic regulator (PQR). Again, the Al'Brekht algorithm can be applied to reduce this problem to a large linear one, which can be solved with a generalization of the [Bartels–Stewart algorithm](wikipedia://en/58536963). This is feasible, provided that the degree of the polynomial is not too high.[^o19]

### Model predictive control {#Model_predictive_control}

Model predictive control#MPC vs. LQR [Model predictive control](wikipedia://en/1100516) (MPC) and linear–quadratic regulators are two types of optimal control methods that have distinct approaches for setting the optimization costs. In particular, when the LQR is run repeatedly with a receding horizon, it becomes a form of MPC. In general, however, MPC is not limited to linear system and can naturally incorporate constraints.
