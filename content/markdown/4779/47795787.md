# ZeroNet

::: {#o3 .subject cue=lead name="ZeroNet"}

**ZeroNet** is a [decentralized](https://en.wikipedia.org/wiki/Decentralized) [web](https://en.wikipedia.org/wiki/World_Wide_Web)-like [network](https://en.wikipedia.org/wiki/Computer_network) of [peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) users, created by Tamas Kocsis in 2015. The programming for the network was based in [Budapest](https://en.wikipedia.org/wiki/Budapest), Hungary. It is built in Python and fully [open source](https://en.wikipedia.org/wiki/Open_source_software).[^o4] Instead of having an [IP address](https://en.wikipedia.org/wiki/IP_address), sites are identified by a public key (specifically a bitcoin address). The private key allows the owner of a site to sign and publish changes, which propagate through the network. Sites can be accessed through an ordinary web browser when using the ZeroNet application, which acts as a local webhost for such pages.[^o4] In addition to using [bitcoin](wikipedia://en/28249265) [cryptography](wikipedia://en/18934432), ZeroNet uses trackers from the [BitTorrent](https://en.wikipedia.org/wiki/BitTorrent) network[^o5] to negotiate connections between peers.[^o4] ZeroNet is not anonymous by default, but it supports routing traffic through the [Tor network](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29).[^o6]

:::

The ZeroNet website and bittorrent tracker are blocked in mainland China.[^o7] Despite the censorship, however, it is still possible to access ZeroNet from behind the [Great Firewall of China](https://en.wikipedia.org/wiki/Great_Firewall_of_China), even over Tor, by [bootstrapping](https://en.wikipedia.org/wiki/Bootstrapping_%28electronics%29) over [Meek](https://en.wikipedia.org/wiki/Domain_fronting#Tor_Browser), and connecting to peers directly.

There is no way to take down a ZeroNet page which still has seeders,[^o4] thus making such pages immune to most third-party methods of taking them down, including [DMCA takedown](https://en.wikipedia.org/wiki/DMCA_takedown) notices.[^o8]

## Hiatus and forks {#Hiatus_and_forks}

Development has stopped for several months after stable release of v0.7.1 on GitHub.[^o10] The zeronet-conservancy fork maintains existing codebase and adds features aimed at gradually migrating to a new p2p network designed from scratch[^o11]

## Development of the network {#Development_of_the_network}

The feasibility of peer-to-peer online web-sites had been hypothesised for some time, with [The Pirate Bay](https://en.wikipedia.org/wiki/The_Pirate_Bay) suggesting they would build a network, as well as [BitTorrent Inc.](https://en.wikipedia.org/wiki/BitTorrent_Inc.) which created the closed-source [Project Maelstrom](https://en.wikipedia.org/wiki/Project_Maelstrom).[^o4]

Sites on ZeroNet are known as "zites" by its users.

ZeroNet supports [HTML](https://en.wikipedia.org/wiki/HTML), [CSS](https://en.wikipedia.org/wiki/CSS) and [JavaScript](https://en.wikipedia.org/wiki/JavaScript).

Server-side languages like [PHP](https://en.wikipedia.org/wiki/PHP) are not supported, although ZeroNet creates and gives API to interact with [SQLite](https://en.wikipedia.org/wiki/SQLite) databases, their data also distributed (as [JSON](https://en.wikipedia.org/wiki/JSON) files) via [P2P](https://en.wikipedia.org/wiki/Point-to-point_%28telecommunications%29).

By default, sites have a size limit of 10 megabytes, but users may grant a site permission to use more storage space if they wish.

With plugins and the ZeroFrame [API](https://en.wikipedia.org/wiki/API), sites can communicate with ZeroNet calling [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) by JavaScript.
