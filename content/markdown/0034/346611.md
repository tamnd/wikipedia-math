# Axiom of countability

::: {#o1 .subject cue=lead name="Axiom of countability"}

In [mathematics](wikipedia://en/18831), an **axiom of countability** is a property of certain [mathematical objects](wikipedia://en/19453961) that asserts the existence of a [countable set](https://en.wikipedia.org/wiki/Countable) with certain properties. Without such an axiom, such a set might not provably exist.

:::

## Important examples {#Important_examples}

Important countability axioms for [topological spaces](wikipedia://en/30450) include:[^o3]

- [sequential space](wikipedia://en/4668395): a set is closed if and only if every [convergent](wikipedia://en/285773) [sequence](wikipedia://en/27838) in the set has its limit point in the set
- [first-countable space](wikipedia://en/904940): every point has a countable [neighbourhood basis](wikipedia://en/1714290) (local base)
- [second-countable space](wikipedia://en/901459): the topology has a countable [base](wikipedia://en/59220)
- [separable space](wikipedia://en/27855): there exists a countable [dense](https://en.wikipedia.org/wiki/Dense_%28topology%29) subset
- [Lindelöf space](wikipedia://en/310480): every [open cover](https://en.wikipedia.org/wiki/Open_cover) has a countable [subcover](https://en.wikipedia.org/wiki/Subcover)
- [σ-compact space](wikipedia://en/346681): there exists a countable cover by compact spaces

## Relationships with each other {#Relationships_with_each_other}

These axioms are related to each other in the following ways:

- Every first-countable space is sequential.
- Every second-countable space is first countable, separable, and Lindelöf.
- Every σ-compact space is Lindelöf.
- Every [metric space](wikipedia://en/20018) is first countable.
- For metric spaces, second-countability, separability, and the Lindelöf property are all equivalent.

## Related concepts {#Related_concepts}

Other examples of mathematical objects obeying axioms of countability include [sigma-finite](https://en.wikipedia.org/wiki/Sigma-finite) [measure spaces](wikipedia://en/19873), and [lattices](wikipedia://en/469304) of [countable type](https://en.wikipedia.org/wiki/Countable_type).
