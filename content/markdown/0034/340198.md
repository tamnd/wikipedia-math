# Pointwise convergence

::: {#o1 .subject cue=lead name="Pointwise convergence"}

In [mathematics](wikipedia://en/18831), **pointwise convergence** is one of [various senses](https://en.wikipedia.org/wiki/Modes_of_convergence_%28annotated_index%29) in which a [sequence](wikipedia://en/27838) of [functions](wikipedia://en/185427) can [converge](wikipedia://en/26551602) to a particular function. It is weaker than [uniform convergence](wikipedia://en/50652), to which it is often compared.[^o2][^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Drini-nonuniformconvergence.png.* The pointwise limit of continuous functions does not have to be continuous: the continuous functions $\sin^n(x)$ (marked in green) converge pointwise to a discontinuous function (marked in red).

Suppose that $X$ is a set and $Y$ is a [topological space](wikipedia://en/30450), such as the [real](wikipedia://en/20646438) or [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers) or a [metric space](wikipedia://en/20018), for example. A [sequence](wikipedia://en/27838) of [functions](wikipedia://en/185427) $\left(f_n\right)$ all having the same domain $X$ and [codomain](wikipedia://en/50264) $Y$ is said to **converge pointwise** to a given function $f : X \to Y$ often written as

$$\lim_{n\to\infty} f_n = f\ \mbox{pointwise}$$

if (and only if) the [limit of the sequence](wikipedia://en/285773) $f_n(x)$ evaluated at each point $x$ in the domain of $f$ is equal to $f(x)$, written as

$$\forall x \in X, \lim_{n\to\infty} f_n(x) = f(x).$$

The function $f$ is said to be the **pointwise limit** function of the $\left(f_n\right).$

The definition easily generalizes from sequences to [nets](wikipedia://en/22170) $f_\bullet = \left(f_a\right)_{a \in A}$. We say $f_\bullet$ converges pointwise to $f$, written as

$$\lim_{a\in A} f_a = f\ \mbox{pointwise}$$

if (and only if) $f(x)$ is the unique accumulation point of the net $f_\bullet(x)$ evaluated at each point $x$ in the domain of $f$, written as

$$\forall x \in X, \lim_{a\in A} f_a(x) = f(x).$$

Sometimes, authors use the term **bounded pointwise convergence** when there is a constant $C$ such that $\forall n,x,\;|f_n(x)|<C$ .[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

This concept is often contrasted with [uniform convergence](wikipedia://en/50652). To say that

$$\lim_{n\to\infty} f_n = f\ \mbox{uniformly}$$

means that

$$\lim_{n\to\infty}\,\sup\{\,\left|f_n(x)-f(x)\right| : x \in A \,\}=0,$$

where $A$ is the common domain of $f$ and $f_n$, and $\sup$ stands for the [supremum](wikipedia://en/39382).[^o2] That is a stronger statement than the assertion of pointwise convergence: every uniformly convergent sequence is pointwise convergent, to the same limiting function, but some pointwise convergent sequences are not uniformly convergent. For example, if $f_n : [0,1) \to [0,1)$ is a sequence of functions defined by $f_n(x) = x^n,$ then $\lim_{n\to\infty} f_n(x) = 0$ pointwise on the interval $[0, 1),$ but not uniformly.

The pointwise limit of a sequence of [continuous functions](wikipedia://en/6122) may be a discontinuous function, but only if the convergence is not uniform. For example,

$$f(x) = \lim_{n\to\infty} \cos(\pi x)^{2n}$$

takes the value $1$ when $x$ is an [integer](wikipedia://en/14563) and $0$ when $x$ is not an integer, and so is discontinuous at every integer.

The values of the functions $f_n$ need not be real numbers, but may be in any [topological space](wikipedia://en/30450), in order that the concept of pointwise convergence make sense. Uniform convergence, on the other hand, does not make sense for functions taking values in topological spaces generally, but makes sense for functions taking values in [metric spaces](wikipedia://en/20018), and, more generally, in [uniform spaces](wikipedia://en/32339).

:::

## Topology {#Topology}

Let $Y^X$ denote the set of all functions from some given set $X$ into some [topological space](wikipedia://en/30450) $Y.$ As described in the article on [characterizations of the category of topological spaces](https://en.wikipedia.org/wiki/Characterizations_of_the_category_of_topological_spaces), if certain conditions are met then it is possible to define a unique topology on a set in terms of which [nets](wikipedia://en/22170) do and do not [converge](https://en.wikipedia.org/wiki/Convergent_net). The definition of pointwise convergence meets these conditions and so it induces a [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29), called **the topology of pointwise convergence**, on the set $Y^X$ of all functions of the form $X \to Y.$ A net in $Y^X$ converges in this topology [if and only if](wikipedia://en/14922) it converges pointwise.

The topology of pointwise convergence is the same as convergence in the [product topology](wikipedia://en/24910) on the space $Y^X,$ where $X$ is the domain and $Y$ is the codomain. Explicitly, if $\mathcal{F} \subseteq Y^X$ is a set of functions from some set $X$ into some topological space $Y$ then the topology of pointwise convergence on $\mathcal{F}$ is equal to the [subspace topology](wikipedia://en/910926) that it inherits from the [product space](https://en.wikipedia.org/wiki/Product_space) $\prod_{x \in X} Y$ when $\mathcal{F}$ is identified as a subset of this Cartesian product via the canonical inclusion map $\mathcal{F} \to \prod_{x \in X} Y$ defined by $f \mapsto (f(x))_{x \in X}.$

If the codomain $Y$ is [compact](https://en.wikipedia.org/wiki/Compact_set), then by [Tychonoff's theorem](wikipedia://en/82739), the space $Y^X$ is also compact.

## Almost everywhere convergence {#Almost_everywhere_convergence}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), one talks about *almost everywhere convergence* of a sequence of [measurable functions](wikipedia://en/44055) defined on a [measurable space](wikipedia://en/43333). That means pointwise convergence [almost everywhere](wikipedia://en/44688), that is, on a subset of the domain whose complement has measure zero. [Egorov's theorem](wikipedia://en/1767634) states that pointwise convergence almost everywhere on a set of finite measure implies uniform convergence on a slightly smaller set.

Almost everywhere pointwise convergence on the space of functions on a measure space does not define the structure of a [topology](wikipedia://en/30450) on the space of measurable functions on a [measure space](wikipedia://en/45270) (although it is a [convergence structure](wikipedia://en/66374616)). For in a topological space, when every subsequence of a sequence has itself a subsequence with the same [subsequential limit](wikipedia://en/553920), the sequence itself must converge to that limit.

But consider the sequence of so-called "galloping rectangles" functions (also known as the typewriter sequence), which are defined using the [floor function](https://en.wikipedia.org/wiki/Floor_function): let $N = \operatorname{floor}\left(\log_2 n\right)$ and $k = n$ [mod](https://en.wikipedia.org/wiki/Modulo_operation) $2^N,$ and let

$$f_n(x) = \begin{cases} 1, & \frac{k}{2^N} \leq x \leq \frac{k+1}{2^N} \\ 0, & \text{otherwise}. \end{cases}$$

Then any subsequence of the sequence $\left(f_n\right)_n$ has a sub-subsequence which itself converges almost everywhere to zero, for example, the subsequence of functions which do not vanish at $x = 0.$ But at no point does the original sequence converge pointwise to zero. Hence, unlike [convergence in measure](wikipedia://en/7996261) and [$L^p$ convergence](wikipedia://en/45194), pointwise convergence almost everywhere is not the convergence of any topology on the space of functions.
