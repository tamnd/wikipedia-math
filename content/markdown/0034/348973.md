# Antichain

::: {#o1 .subject cue=lead name="Antichain"}

In [mathematics](wikipedia://en/18831), in the area of [order theory](wikipedia://en/361924), an **antichain** is a subset of a [partially ordered set](wikipedia://en/23572) such that any two distinct elements in the subset are [incomparable](https://en.wikipedia.org/wiki/Incomparability).

:::

The size of the largest antichain in a finite partially ordered set is known as its [**width**](https://en.wikipedia.org/wiki/Width_%28partial_order%29). By [Dilworth's theorem](wikipedia://en/749033), this also equals the minimum number of chains (totally ordered subsets) into which the set can be partitioned. Dually, the **height** of the finite partially ordered set (the length of its longest chain) equals by [Mirsky's theorem](wikipedia://en/28848438) the minimum number of antichains into which the set can be partitioned.

The family of all antichains in a finite partially ordered set can be given [join and meet](wikipedia://en/3956618) operations, making them into a [distributive lattice](wikipedia://en/310883). For the partially ordered system of all subsets of a finite set, ordered by set inclusion, the antichains are called [Sperner families](wikipedia://en/748730) and their lattice is a [free distributive lattice](https://en.wikipedia.org/wiki/Free_distributive_lattice), with a [Dedekind number](wikipedia://en/21452705) of elements. More generally, counting the number of antichains of a finite partially ordered set is [\#P-complete](wikipedia://en/27925).

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $S$ be a partially ordered set. Two elements $a$ and $b$ of a partially ordered set are called [comparable](wikipedia://en/3834818) if $a \leq b$ or $b \leq a.$ If two elements are not comparable, they are called incomparable; that is, $x$ and $y$ are incomparable if neither $x \leq y$ nor $y \leq x.$

A chain in $S$ is a [subset](wikipedia://en/27631) $C \subseteq S$ in which each pair of elements is comparable; that is, $C$ is [totally ordered](wikipedia://en/30330). An antichain in $S$ is a [subset](wikipedia://en/27631) $A \subseteq S$ in which each pair of different elements is incomparable; that is, there is no order relation between any two different elements in $A.$ (However, some authors use the term "antichain" to mean [strong antichain](wikipedia://en/1550685), a subset such that there is no element of the [poset](wikipedia://en/23572) smaller than two distinct elements of the antichain.)

:::

## Height and width {#Height_and_width}

A **maximal antichain** is an antichain that is not a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of any other antichain. A **maximum antichain** is an antichain that has cardinality at least as large as every other antichain. The width of a partially ordered set is the cardinality of a maximum antichain. Any antichain can intersect any chain in at most one element, so, if we can partition the elements of an order into $k$ chains then the width of the order must be at most $k$ (if the antichain has more than $k$ elements, by the [pigeonhole principle](wikipedia://en/54217), there would be 2 of its elements belonging to the same chain, a contradiction). [Dilworth's theorem](wikipedia://en/749033) states that this bound can always be reached: there always exists an antichain, and a partition of the elements into chains, such that the number of chains equals the number of elements in the antichain, which must therefore also equal the width. Similarly, one can define the height of a partial order to be the maximum cardinality of a chain. [Mirsky's theorem](wikipedia://en/28848438) states that in any partial order of finite height, the height equals the smallest number of antichains into which the order may be partitioned.

:::

## Sperner families {#Sperner_families}

An antichain in the inclusion ordering of subsets of an $n$-element set is known as a [Sperner family](wikipedia://en/748730). The number of different Sperner families is counted by the [Dedekind numbers](wikipedia://en/21452705), the first few of which numbers are

2, 3, 6, 20, 168, 7581, 7828354, 2414682040998, 56130437228687557907788 .

Even the empty set has two antichains in its power set: one containing a single set (the empty set itself) and one containing no sets.

## Join and meet operations {#Join_and_meet_operations}

Any antichain $A$ corresponds to a [lower set](https://en.wikipedia.org/wiki/Lower_set)

$$L_A = \{x : \exists y \in A \mbox{ such that } x \leq y\}.$$

In a finite partial order (or more generally a partial order satisfying the [ascending chain condition](wikipedia://en/3189)) all lower sets have this form. The union of any two lower sets is another lower set, and the union operation corresponds in this way to a **join** operation on antichains:

$$A \vee B = \{ x \in A \cup B : \nexists y \in A \cup B \mbox{ such that } x < y\}.$$

Similarly, we can define a **meet** operation on antichains, corresponding to the intersection of lower sets:

$$A \wedge B = \{ x \in L_A \cap L_B : \nexists y \in L_A \cap L_B \mbox{ such that } x < y\}.$$

The join and meet operations on all finite antichains of finite subsets of a set $X$ define a [distributive lattice](wikipedia://en/310883), the free distributive lattice generated by $X.$ [Birkhoff's representation theorem](wikipedia://en/20489385) for distributive lattices states that every finite distributive lattice can be represented via join and meet operations on antichains of a finite partial order, or equivalently as union and intersection operations on the [lower sets](https://en.wikipedia.org/wiki/Lower_set) of the partial order.

## Computational complexity {#Computational_complexity}

In a finite partially ordered set, the maximum antichain (and its size, the width of a given partially ordered set) can be found in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time). Counting the number of antichains in a given partially ordered set is [\#P-complete](wikipedia://en/27925).
