# Arg max

*Image: Si\_sinc.svg.* As an example, both unnormalised and normalised [sinc](https://en.wikipedia.org/wiki/Sinc) functions above have $\operatorname{argmax}$ of {0} because both attain their global maximum value of 1 at *x* = 0.The unnormalised sinc function (red) has *arg min* of {−4.49, 4.49}, approximately, because it has 2 global minimum values of approximately −0.217 at *x* = ±4.49. However, the normalised sinc function (blue) has *arg min* of {−1.43, 1.43}, approximately, because their global minima occur at *x* = ±1.43, even though the minimum value is the same.[^o1]

::: {#o2 .subject cue=lead name="Arg max"}

In [mathematics](wikipedia://en/18831), the **arguments of the maxima** (abbreviated **arg max** or **argmax**) and **arguments of the minima** (abbreviated **arg min** or **argmin**) are the input points at which a [function](wikipedia://en/185427) output value is [maximized and minimized](https://en.wikipedia.org/wiki/Maxima_and_minima), respectively.[^o3] While the [arguments](wikipedia://en/32842052) are defined over the [domain of a function](wikipedia://en/50263), the output is part of its [codomain](wikipedia://en/50264).

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given an arbitrary [set](wikipedia://en/26691) $X$, a [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set) $Y$, and a function, $f\colon X \to Y$, the $\operatorname{argmax}$ over some subset $S$ of $X$ is defined by

$$\operatorname{argmax}_S f := \underset{x \in S}{\operatorname{arg\,max}}\, f(x) := \{x \in S ~:~ f(s) \leq f(x) \text{ for all } s \in S \}.$$

If $S = X$ or $S$ is clear from the context, then $S$ is often left out, as in $\underset{x}{\operatorname{arg\,max}}\, f(x) := \{ x ~:~ f(s) \leq f(x) \text{ for all } s \in X \}.$ In other words, $\operatorname{argmax}$ is the [set](wikipedia://en/26691) of points $x$ for which $f(x)$ attains the function's largest value (if it exists). $\operatorname{Argmax}$ may be the [empty set](wikipedia://en/9566), a [singleton](wikipedia://en/381798), or contain multiple elements.

In the fields of [convex analysis](wikipedia://en/3237201) and [variational analysis](wikipedia://en/40237498), a slightly different definition is used in the special case where $Y = [-\infty,\infty] = \mathbb{R} \cup \{ \pm\infty \}$ are the [extended real numbers](https://en.wikipedia.org/wiki/Extended_real_numbers).[^n1] In this case, if $f$ is identically equal to $\infty$ on $S$ then $\operatorname{argmax}_S f := \varnothing$ (that is, $\operatorname{argmax}_S \infty := \varnothing$) and otherwise $\operatorname{argmax}_S f$ is defined as above, where in this case $\operatorname{argmax}_S f$ can also be written as:

$$\operatorname{argmax}_S f := \left\{ x \in S ~:~ f(x) = \sup {}_S f \right\}$$

where it is emphasized that this equality involving $\sup {}_S f$ holds only when $f$ is not identically $\infty$ on $S$.[^n1]

::: {#o9 .pointer-item cue=pointer name="Arg min"}

### Arg min {#Arg_min}

The notion of $\operatorname{argmin}$ (or $\operatorname{arg\,min}$), which stands for **argument of the minimum**, is defined analogously. For instance,

$$\underset{x \in S}{\operatorname{arg\,min}} \, f(x) := \{ x \in S ~:~ f(s) \geq f(x) \text{ for all } s \in S \}$$

are points $x$ for which $f(x)$ attains its smallest value. It is the complementary operator of $\operatorname{arg\,max}$.

In the special case where $Y = [-\infty,\infty] = \mathbb{R} \cup \{ \pm\infty \}$ are the [extended real numbers](https://en.wikipedia.org/wiki/Extended_real_numbers), if $f$ is identically equal to $-\infty$ on $S$ then $\operatorname{argmin}_S f := \varnothing$ (that is, $\operatorname{argmin}_S -\infty := \varnothing$) and otherwise $\operatorname{argmin}_S f$ is defined as above and moreover, in this case (of $f$ not identically equal to $-\infty$) it also satisfies:

$\operatorname{argmin}_S f := \left\{ x \in S ~:~ f(x) = \inf {}_S f \right\}.$[^n1]

## Examples and properties {#Examples_and_properties}

For example, if $f(x)$ is $1 - |x|,$ then $f$ attains its maximum value of $1$ only at the point $x = 0.$ Thus

$$\underset{x}{\operatorname{arg\,max}}\, (1 - |x|) = \{ 0 \}.$$

The $\operatorname{argmax}$ operator is different from the $\max$ operator. The $\max$ operator, when given the same function, returns the [maximum value](https://en.wikipedia.org/wiki/Maxima_and_minima) of the function instead of the point or points that cause that function to reach that value; in other words

$\max_x f(x)$ is the element in $\{ f(x) ~:~ f(s) \leq f(x) \text{ for all } s \in S \}.$

Like $\operatorname{argmax},$ max may be the empty set (in which case the maximum is undefined) or a singleton, but unlike $\operatorname{argmax},$ $\operatorname{max}$ may not contain multiple elements:[^o12] for example, if $f(x)$ is $4 x^2 - x^4,$ then $\underset{x}{\operatorname{arg\,max}}\, \left( 4 x^2 - x^4 \right) = \left\{-\sqrt{2}, \sqrt{2}\right\},$ but $\underset{x}{\operatorname{max}}\, \left( 4 x^2 - x^4 \right) = \{ 4 \}$ because the function attains the same value at every element of $\operatorname{argmax}.$

Equivalently, if $M$ is the maximum of $f,$ then the $\operatorname{argmax}$ is the [level set](wikipedia://en/559622) of the maximum:

$$\underset{x}{\operatorname{arg\,max}} \, f(x) = \{ x ~:~ f(x) = M \} =: f^{-1}(M).$$

We can rearrange to give the simple identity[^o13]

$$f\left(\underset{x}{\operatorname{arg\,max}} \, f(x) \right) = \max_x f(x).$$

If the maximum is reached at a single point then this point is often referred to as the $\operatorname{argmax},$ and $\operatorname{argmax}$ is considered a point, not a set of points. So, for example,

$$\underset{x\in\mathbb{R}}{\operatorname{arg\,max}}\, (x(10 - x)) = 5$$

(rather than the [singleton](wikipedia://en/381798) set $\{ 5 \}$), since the maximum value of $x (10 - x)$ is $25,$ which occurs for $x = 5.$[^o14] However, in case the maximum is reached at many points, $\operatorname{argmax}$ needs to be considered a set of points.

For example

$$\underset{x \in [0, 4 \pi]}{\operatorname{arg\,max}}\, \cos(x) = \{ 0, 2 \pi, 4 \pi \}$$

because the maximum value of $\cos x$ is $1,$ which occurs on this interval for $x = 0, 2 \pi$ or $4 \pi.$ On the whole real line

$\underset{x \in \mathbb{R}}{\operatorname{arg\,max}}\, \cos(x) = \left\{ 2 k \pi ~:~ k \in \mathbb{Z} \right\},$ so an [infinite set](wikipedia://en/142679).

Functions need not in general attain a maximum value, and hence the $\operatorname{argmax}$ is sometimes the [empty set](wikipedia://en/9566); for example, $\underset{x\in\mathbb{R}}{\operatorname{arg\,max}}\, x^3 = \varnothing,$ since $x^3$ is [unbounded](wikipedia://en/311509) on the [real line](wikipedia://en/287188). As another example, $\underset{x \in \mathbb{R}}{\operatorname{arg\,max}}\, \arctan(x) = \varnothing,$ although [$\arctan$](https://en.wikipedia.org/wiki/Arc_tangent) is bounded by $\pm\pi/2.$ However, by the [extreme value theorem](wikipedia://en/276881), a continuous real-valued function on a [closed interval](wikipedia://en/49172) has a maximum, and thus a nonempty $\operatorname{argmax}.$
