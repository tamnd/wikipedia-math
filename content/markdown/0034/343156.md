# Schnirelmann density

::: {#o1 .subject cue=lead name="Schnirelmann density"}

In [additive number theory](wikipedia://en/4460333), the **Schnirelmann density** of a [sequence](wikipedia://en/27838) of numbers is a way to measure how "dense" the sequence is. It is named after [Soviet](https://en.wikipedia.org/wiki/Soviet_Union) [mathematician](wikipedia://en/18902) [Lev Schnirelmann](wikipedia://en/747223), who was the first to study it.[^o2][^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The **Schnirelmann density** of a set of [natural numbers](wikipedia://en/21474) *A* is defined as

$$\sigma A = \inf_{n \geq 1} \frac{A(n)}{n},$$

where *A*(*n*) denotes the number of elements of *A* not exceeding *n* and inf is [infimum](https://en.wikipedia.org/wiki/Infimum).[^o6]

The Schnirelmann density is well-defined even if the limit of *A*(*n*)/*n* as *n* → ∞ fails to exist (see [upper and lower asymptotic density](wikipedia://en/1819983#Definition)).

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

By definition, 0 ≤ *A*(*n*) ≤ n and *n* σ*A* ≤ *A*(*n*) for all *n*, and therefore 0 ≤ σ*A* ≤ 1, and σ*A* = 1 if and only if *A* = **N**. Furthermore,

$$\sigma A=0 \Rightarrow \forall \epsilon>0\ \exists n\ A(n) < \epsilon n.$$

### Sensitivity {#Sensitivity}

The Schnirelmann density is sensitive to the first values of a set:

$$\forall k \ k \notin A \Rightarrow \sigma A \le 1-1/k$$

In particular,

$$1 \notin A \Rightarrow \sigma A = 0$$

and

$$2 \notin A \Rightarrow \sigma A \le \frac{1}{2}.$$

Consequently, the Schnirelmann densities of the even numbers and the odd numbers, which one might expect to agree, are 0 and 1/2 respectively. Schnirelmann and [Yuri Linnik](https://en.wikipedia.org/wiki/Yuri_Linnik) exploited this sensitivity.

:::

::: {#o11 .statement kind=statement/theorem cue=named-heading name="Schnirelmann's theorems"}

## Schnirelmann's theorems {#Schnirelmann's_theorems}

If we set $\mathfrak{G}^2 = \{k^2\}_{k=1}^{\infty}$, then [Lagrange's four-square theorem](wikipedia://en/326395) can be restated as $\sigma(\mathfrak{G}^2 \oplus \mathfrak{G}^2 \oplus \mathfrak{G}^2 \oplus \mathfrak{G}^2) = 1$. (Here the symbol $A\oplus B$ denotes the [sumset](https://en.wikipedia.org/wiki/Sumset) of $A\cup\{0\}$ and $B\cup\{0\}$.) It is clear that $\sigma \mathfrak{G}^2 = 0$. In fact, we still have $\sigma(\mathfrak{G}^2 \oplus \mathfrak{G}^2) = 0$, and one might ask at what point the sumset attains Schnirelmann density 1 and how does it increase. It actually is the case that $\sigma(\mathfrak{G}^2 \oplus \mathfrak{G}^2 \oplus \mathfrak{G}^2) = 5/6$ and one sees that sumsetting $\mathfrak{G}^2$ once again yields a more populous set, namely all of $\mathbb{N}$. Schnirelmann further succeeded in developing these ideas into the following theorems, aiming towards Additive Number Theory, and proving them to be a novel resource (if not greatly powerful) to attack important problems, such as Waring's problem and [Goldbach's conjecture](wikipedia://en/44758).

> **Theorem.** Let $A$ and $B$ be subsets of $\mathbb{N}$. Then
>
> $$\sigma(A \oplus B) \ge \sigma A + \sigma B - \sigma A \cdot \sigma B.$$

Note that $\sigma A + \sigma B - \sigma A \cdot \sigma B = 1 - (1 - \sigma A)(1 - \sigma B)$. Inductively, we have the following generalization.

> **Corollary.** Let $A_i \subseteq \mathbb{N}$ be a finite family of subsets of $\mathbb{N}$. Then
>
> $$\sigma\left(\bigoplus_i A_i\right) \ge 1 - \prod_{i}\left(1 - \sigma A_i\right).$$

The theorem provides the first insights on how sumsets accumulate. It seems unfortunate that its conclusion stops short of showing $\sigma$ being [superadditive](https://en.wikipedia.org/wiki/Superadditive). Yet, Schnirelmann provided us with the following results, which sufficed for most of his purpose.

> **Theorem.** Let $A$ and $B$ be subsets of $\mathbb{N}$. If $\sigma A + \sigma B \ge 1$, then
>
> $$A \oplus B = \mathbb{N}.$$

> **Theorem.** (*Schnirelmann*) Let $A \subseteq \mathbb{N}$. If $\sigma A > 0$ then there exists $k$ such that
>
> $$\bigoplus^k_{i=1} A=\mathbb{N}.$$

:::

::: {#o13 .pointer-item cue=pointer name="Basis of finite order"}

## Additive bases {#Additive_bases}

A subset $A \subseteq \mathbb{N}$ with the property that $A \oplus A \oplus \cdots \oplus A = \mathbb{N}$ for a finite sum, is called an [additive basis](https://en.wikipedia.org/wiki/Additive_basis), and the least number of summands required is called the *degree* (sometimes *order*) of the basis. Thus, the last theorem states that any set with positive Schnirelmann density is an additive basis. In this terminology, the set of squares $\mathfrak{G}^2 = \{k^2\}_{k=1}^{\infty}$ is an additive basis of degree 4. (About an open problem for additive bases, see [Erdős–Turán conjecture on additive bases](wikipedia://en/31244492).)

:::

::: {#o15 .statement kind=statement/theorem cue=named-heading name="Mann's theorem"}

## Mann's theorem {#Mann's_theorem}

Historically the theorems above were pointers to the following result, at one time known as the $\alpha + \beta$ hypothesis. It was used by [Edmund Landau](wikipedia://en/222230) and was finally proved by [Henry Mann](wikipedia://en/30545778) in 1942.

> **Theorem.** (Mann 1942) Let $A$ and $B$ be subsets of $\mathbb{N}$. In case that $A \oplus B \ne \mathbb{N}$, we still have
>
> $$\sigma(A \oplus B) \ge \sigma A + \sigma B.$$

An analogue of this theorem for lower asymptotic density was obtained by Kneser.[^o17] At a later date, [E. Artin](wikipedia://en/245351) and P. Scherk simplified the proof of Mann's theorem.[^o18]

:::

## Waring's problem {#Waring's_problem}

Let $k$ and $N$ be natural numbers. Let $\mathfrak{G}^k = \{i^k\}_{i=1}^\infty$. Define $r_N^k(n)$ to be the number of non-negative integral solutions to the equation

$$x_1^k + x_2^k + \cdots + x_N^k = n$$

and $R_N^k(n)$ to be the number of non-negative integral solutions to the inequality

$$0 \le x_1^k + x_2^k + \cdots + x_N^k \le n,$$

in the variables $x_i$, respectively. Thus $R_N^k(n) = \sum_{i=0}^n r_N^k(i)$. We have

- $$r_N^k(n)>0 \leftrightarrow n \in N\mathfrak{G}^k,$$
- $$R_N^k(n) \ge \left(\frac{n}{N}\right)^{\frac{N}{k}}.$$

The volume of the $N$-dimensional body defined by $0 \le x_1^k + x_2^k + \cdots + x_N^k \le n$, is bounded by the volume of the hypercube of size $n^{1/k}$, hence $R_N^k(n) = \sum_{i=0}^n r_N^k(i) \leq n^{N/k}$. The hard part is to show that this bound still works on the average, i.e.,

> **Lemma.** (*Linnik*) For all $k \in \mathbb{N}$ there exists $N \in \mathbb{N}$ and a constant $c = c(k)$, depending only on $k$, such that for all $n \in \mathbb{N}$,
>
> $$r_N^k(m) < cn^{\frac{N}{k}-1}$$
>
> for all $0 \le m \le n.$

With this at hand, the following theorem can be elegantly proved.

> **Theorem.** For all $k$ there exists $N$ for which $\sigma(N\mathfrak{G}^k) > 0$.

We have thus established the general solution to Waring's Problem:

> **Corollary.** (Hilbert 1909) For all $k$ there exists $N$, depending only on $k$, such that every positive integer $n$ can be expressed as the sum of at most $N$ many $k$-th powers.

::: {#o22 .pointer-item cue=pointer name="Schnirelmann's constant"}

## Schnirelmann's constant {#Schnirelmann's_constant}

In 1930 Schnirelmann used these ideas in conjunction with the [Brun sieve](wikipedia://en/18731525) to prove **Schnirelmann's theorem**,[^o2][^o3] that any [natural number](wikipedia://en/21474) greater than 1 can be written as the sum of not more than *C* [prime numbers](https://en.wikipedia.org/wiki/Prime_numbers), where *C* is an effectively computable constant:[^o23] Schnirelmann obtained *C* \< 800000.[^o24] **Schnirelmann's constant** is the lowest number *C* with this property.[^o23]

[Olivier Ramaré](wikipedia://en/2916107) showed in (Ramaré 1995) that Schnirelmann's constant is at most 7,[^o23] improving the earlier upper bound of 19 obtained by [Hans Riesel](https://en.wikipedia.org/wiki/Hans_Riesel) and [R. C. Vaughan](https://en.wikipedia.org/wiki/Robert_Charles_Vaughan_%28mathematician%29).

Schnirelmann's constant is at least 3; [Goldbach's conjecture](wikipedia://en/44758) implies that this is the constant's actual value.[^o23]

In 2013, [Harald Helfgott](https://en.wikipedia.org/wiki/Harald_Helfgott) proved [Goldbach's weak conjecture](wikipedia://en/147164) for all odd numbers. Therefore, Schnirelmann's constant is at most 4.[^o26][^o27][^o28][^o29]

:::

::: {#o31 .pointer-item cue=pointer name="Essential component"}

## Essential components {#Essential_components}

[Khintchin](wikipedia://en/1029748) proved that the sequence of squares, though of zero Schnirelmann density, when added to a sequence of Schnirelmann density between 0 and 1, increases the density:

$$\sigma(A+\mathfrak{G}^2)>\sigma(A)\text{ for }0<\sigma(A)<1.$$

This was soon simplified and extended by [Erdős](wikipedia://en/601284), who showed, that if *A* is any sequence with Schnirelmann density α and *B* is an additive basis of order *k* then

$\sigma(A+B)\geq \alpha+ \frac{\alpha(1-\alpha)}{2k}\,,$[^o32]

and this was improved by Plünnecke to

$\sigma(A+B)\geq \alpha^{1-\frac{1}{k}}\ .$[^o33]

Sequences with this property, of increasing density less than one by addition, were named **essential components** by Khintchin. [Linnik](https://en.wikipedia.org/wiki/Yuri_Linnik) showed that an essential component need not be an additive basis[^o34] as he constructed an essential component that has *x*<sup>o(1)</sup> elements less than *x*. More precisely, the sequence has

$$e^{(\log x)^c}$$

elements less than *x* for some *c* \< 1. This was improved by [E. Wirsing](wikipedia://en/57927311) to

$$e^{\sqrt{\log x}\log\log x}.$$

For a while, it remained an open problem how many elements an essential component must have. Finally, [Ruzsa](https://en.wikipedia.org/wiki/Imre_Z._Ruzsa) determined that for every *ε* > 0 there is an essential component which has at most *c*(log *x*)<sup>1+*ε*</sup> elements up to *x*, but there is no essential component which has *c*(log *x*)<sup>1+*o*(1)</sup> elements up to *x*.[^o35][^o36]

:::
