# Betti number

::: {#o1 .subject cue=lead name="Betti number"}

In [algebraic topology](wikipedia://en/38801), the **Betti numbers** are used to distinguish [topological spaces](wikipedia://en/30450) based on the connectivity of *n*-dimensional [simplicial complexes](wikipedia://en/252686). For the most reasonable finite-dimensional [spaces](wikipedia://en/30450) (such as [compact manifolds](https://en.wikipedia.org/wiki/Compact_manifold), finite [simplicial complexes](https://en.wikipedia.org/wiki/Simplicial_complexes) or [CW complexes](https://en.wikipedia.org/wiki/CW_complexes)), the sequence of Betti numbers is 0 from some point onward (Betti numbers vanish above the dimension of a space), and they are all finite.

:::

The *n*th Betti number represents the [rank](wikipedia://en/18720088) of the *n*th [homology group](https://en.wikipedia.org/wiki/Homology_group), denoted *H*<sub>*n*</sub>, which tells us the maximum number of cuts that can be made before separating a surface into two pieces or 0-cycles, 1-cycles, etc.[^o2] For example, if $H_n(X) \cong 0$ then $b_n(X) = 0$, if $H_n(X) \cong \mathbb{Z}$ then $b_n(X) = 1$, if $H_n(X) \cong \mathbb{Z} \oplus \mathbb{Z}$ then $b_n(X) = 2$, if $H_n(X) \cong \mathbb{Z} \oplus \mathbb{Z}\oplus \mathbb{Z}$ then $b_n(X) = 3$, etc. Note that only the ranks of infinite groups are considered, so for example if $H_n(X) \cong \mathbb{Z}^k \oplus \mathbb{Z}/(2)$, where $\mathbb{Z}/(2)$ is the [finite cyclic group](https://en.wikipedia.org/wiki/Finite_cyclic_group) of order 2, then $b_n(X) = k$. These finite components of the homology groups are their [torsion subgroups](wikipedia://en/144052), and they are denoted by **torsion coefficients**.

The term "Betti number" was coined by [Henri Poincaré](wikipedia://en/48740) after [Enrico Betti](wikipedia://en/979158). The modern formulation is due to [Emmy Noether](wikipedia://en/149896#Second_epoch_%281920–1926%29:_Contributions_to_topology). Betti numbers are used today in fields such as [simplicial homology](wikipedia://en/1060236), [computer science](https://en.wikipedia.org/wiki/Computer_science) and [digital images](https://en.wikipedia.org/wiki/Digital_images).

## Geometric interpretation {#Geometric_interpretation}

*Image: Torus cycles.png.* For a torus, the first Betti number is *b*<sub>1</sub> = 2, which can be intuitively thought of as the number of circular "holes".

Informally, the *k*th Betti number refers to the number of *k*-dimensional *holes* on a topological surface. A "*k*-dimensional *hole*" is a *k*-dimensional cycle that is not a boundary of a (*k*+1)-dimensional object.

The first few Betti numbers have the following definitions for 0-dimensional, 1-dimensional, and 2-dimensional [simplicial complexes](wikipedia://en/252686):

- *b*<sub>0</sub> is the number of connected components;
- *b*<sub>1</sub> is the number of one-dimensional or "circular" holes;
- *b*<sub>2</sub> is the number of two-dimensional "voids" or "cavities".

Thus, for example, a torus has one connected surface component so *b*<sub>0</sub> = 1, two "circular" holes (one equatorial and one [meridional](https://en.wikipedia.org/wiki/Zonal_and_meridional)) so *b*<sub>1</sub> = 2, and a single cavity enclosed within the surface so *b*<sub>2</sub> = 1.

Another interpretation of *b*<sub>k</sub> is the maximum number of *k*-dimensional curves that can be removed while the object remains connected. For example, the torus remains connected after removing two 1-dimensional curves (equatorial and meridional) so *b*<sub>1</sub> = 2.[^o4]

The two-dimensional Betti numbers are easier to understand because we can see the world in 0, 1, 2, and 3-dimensions.

::: {#o6 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

For a non-negative [integer](wikipedia://en/14563) *k*, the *k*th Betti number *b*<sub>*k*</sub>(*X*) of the space *X* is defined as the [rank](wikipedia://en/244541) (number of linearly independent generators) of the [abelian group](wikipedia://en/2974) *H*<sub>*k*</sub>(*X*), the *k*th [homology group](https://en.wikipedia.org/wiki/Homology_group) of *X*. The *k*th homology group is $H_{k} = \ker \delta_{k} / \operatorname{Im} \delta_{k+1}$, the $\delta_{k}$s are the boundary maps of the [simplicial complex](wikipedia://en/252686) and the rank of H<sub>k</sub> is the *k*th Betti number. Equivalently, one can define it as the [vector space dimension](https://en.wikipedia.org/wiki/Vector_space_dimension) of *H*<sub>*k*</sub>(*X*; **Q**) since the homology group in this case is a vector space over **Q**. The [universal coefficient theorem](wikipedia://en/996107), in a very simple torsion-free case, shows that these definitions are the same.

More generally, given a [field](wikipedia://en/10603) *F* one can define *b*<sub>*k*</sub>(*X*, *F*), the *k*th Betti number with coefficients in *F*, as the vector space dimension of *H*<sub>*k*</sub>(*X*, *F*).

:::

## Poincaré polynomial {#Poincaré_polynomial}

The **Poincaré polynomial** of a surface is defined to be the [generating function](wikipedia://en/160993) of its Betti numbers. For example, the Betti numbers of the torus are 1, 2, and 1; thus its Poincaré polynomial is $1+2x+x^2$. The same definition applies to any topological space which has a finitely generated homology.

Given a topological space which has a finitely generated homology, the Poincaré polynomial is defined as the generating function of its Betti numbers, via the polynomial where the coefficient of $x^n$ is $b_n$.

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

### Betti numbers of a graph {#Betti_numbers_of_a_graph}

Consider a [topological graph](wikipedia://en/1631772) *G* in which the set of vertices is *V*, the set of edges is *E*, and the set of connected components is *C*. As explained in the page on [graph homology](wikipedia://en/64675441), its homology groups are given by:

$$H_k(G) = \begin{cases} \mathbb Z^{|C|} & k=0 \\ \mathbb Z^{|E|+|C|-|V|} & k=1 \\ \{0\} & \text{otherwise} \end{cases}$$

This may be proved straightforwardly by [mathematical induction](wikipedia://en/18881) on the number of edges. A new edge either increments the number of 1-cycles or decrements the number of connected components.

Therefore, the "zero-th" Betti number *b*<sub>0</sub>(*G*) equals |*C*|, which is simply the number of connected components.[^o11]

The first Betti number *b*<sub>1</sub>(*G*) equals |*E*| + |*C*| - |*V*|. It is also called the [cyclomatic number](wikipedia://en/1483049)—a term introduced by [Gustav Kirchhoff](https://en.wikipedia.org/wiki/Gustav_Kirchhoff) before Betti's paper.[^o12] See [cyclomatic complexity](https://en.wikipedia.org/wiki/Cyclomatic_complexity) for an application to [software engineering](https://en.wikipedia.org/wiki/Software_engineering).

All other Betti numbers are 0.

### Betti numbers of a simplicial complex {#Betti_numbers_of_a_simplicial_complex}

*Image: Simplicialexample.png.*

Consider a [simplicial complex](wikipedia://en/252686) with 0-simplices: a, b, c, and d, 1-simplices: E, F, G, H and I, and the only 2-simplex is J, which is the shaded region in the figure. There is one connected component in this figure (*b*<sub>0</sub>); one hole, which is the unshaded region (*b*<sub>1</sub>); and no "voids" or "cavities" (*b*<sub>2</sub>).

This means that the rank of $H_0$ is 1, the rank of $H_{1}$ is 1 and the rank of $H_2$ is 0.

The Betti number sequence for this figure is 1, 1, 0, 0, ...; the Poincaré polynomial is $1 + x\,$.

### Betti numbers of the projective plane {#Betti_numbers_of_the_projective_plane}

The homology groups of the [projective plane](wikipedia://en/24350) *P* are:

$$H_k(P) = \begin{cases} \mathbb Z & k=0 \\ \mathbb Z _ 2 & k=1 \\ \{0\} & \text{otherwise} \end{cases}$$

Here, **Z**<sub>2</sub> is the [cyclic group](wikipedia://en/52327) of order 2. The 0-th Betti number is again 1. However, the 1-st Betti number is 0. This is because *H*<sub>1</sub>(*P*) is a finite group - it does not have any infinite component. The finite component of the group is called the **torsion coefficient** of *P*. The (rational) Betti numbers *b*<sub>*k*</sub>(*X*) do not take into account any [torsion](wikipedia://en/144052) in the homology groups, but they are very useful basic topological invariants. In the most intuitive terms, they allow one to count the number of *holes* of different dimensions.

:::

## Properties {#Properties}

### Euler characteristic {#Euler_characteristic}

For a finite CW-complex *K* we have

$$\chi(K) = \sum_{i=0}^\infty(-1)^i b_i(K, F), \,$$

where $\chi(K)$ denotes [Euler characteristic](wikipedia://en/148420) of *K* and any field *F*.

### Cartesian product {#Cartesian_product}

For any two spaces *X* and *Y* we have

$$P_{X\times Y} = P_X P_Y ,$$

where $P_X$ denotes the **Poincaré polynomial** of *X*, (more generally, the [Hilbert–Poincaré series](wikipedia://en/17006296), for infinite-dimensional spaces), i.e., the [generating function](wikipedia://en/160993) of the Betti numbers of *X*:

$$P_X(z) = b_0(X) + b_1(X)z + b_2(X)z^2 + \cdots , \,\!$$

see [Künneth theorem](wikipedia://en/918047).

::: {#o20 .statement kind=statement/fact cue=heading name="Symmetry"}

### Symmetry {#Symmetry}

If *X* is *n*-dimensional manifold, there is symmetry interchanging $k$ and $n - k$, for any $k$:

$$b_k(X) = b_{n-k}(X),$$

under conditions (a *closed* and *oriented* manifold); see [Poincaré duality](wikipedia://en/540732).

:::

### Different coefficients {#Different_coefficients}

The dependence on the field *F* is only through its [characteristic](https://en.wikipedia.org/wiki/Characteristic_%28field%29). If the homology groups are [torsion-free](wikipedia://en/3039330), the Betti numbers are independent of *F*. The connection of *p*-torsion and the Betti number for [characteristic *p*](https://en.wikipedia.org/wiki/Characteristic_p), for *p* a prime number, is given in detail by the [universal coefficient theorem](wikipedia://en/996107) (based on [Tor functors](wikipedia://en/856347), but in a simple case).

:::

## More examples {#More_examples}

1. The Betti number sequence for a circle is 1, 1, 0, 0, 0, ...;

the Poincaré polynomial is

$$1 + x\,.$$

1. The Betti number sequence for a three-[torus](wikipedia://en/74800) is 1, 3, 3, 1, 0, 0, 0, ... .

the Poincaré polynomial is

$$(1 + x)^3 = 1 + 3x + 3x^2 + x^3\,.$$

1. Similarly, for an *n*-[torus](wikipedia://en/74800),

the Poincaré polynomial is

$(1 + x)^n \,$ (by the [Künneth theorem](wikipedia://en/918047)), so the Betti numbers are the [binomial coefficients](wikipedia://en/4668).

It is possible for spaces that are infinite-dimensional in an essential way to have an infinite sequence of non-zero Betti numbers. An example is the infinite-dimensional [complex projective space](wikipedia://en/762977), with sequence 1, 0, 1, 0, 1, ... that is periodic, with [period length](https://en.wikipedia.org/wiki/Period_length) 2. In this case the Poincaré function is not a polynomial but rather an infinite series

$$1 + x^2 + x^4 + \dotsb,$$

which, being a geometric series, can be expressed as the rational function

$$\frac{1}{1 - x^2}.$$

More generally, any sequence that is periodic can be expressed as a sum of geometric series, generalizing the above. For example $a,b,c,a,b,c,\dots,$ has the generating function

$$\left(a + bx + cx^2\right)/\left(1 - x^3\right) \,$$

and more generally [linear recursive sequences](https://en.wikipedia.org/wiki/Linear_recursive_sequence) are exactly the sequences generated by [rational functions](https://en.wikipedia.org/wiki/Rational_functions); thus the Poincaré series is expressible as a rational function if and only if the sequence of Betti numbers is a linear recursive sequence.

The Poincaré polynomials of the compact simple [Lie groups](https://en.wikipedia.org/wiki/Lie_groups) are:

$$\begin{aligned} P_{SU(n+1)}(x) &= \left(1 + x^3\right)\left(1 + x^5\right)\cdots\left(1 + x^{2n+1}\right) \\ P_{SO(2n+1)}(x) &= \left(1 + x^3\right)\left(1 + x^7\right)\cdots\left(1 + x^{4n-1}\right) \\ P_{Sp(n)}(x) &= \left(1 + x^3\right)\left(1 + x^7\right)\cdots\left(1 + x^{4n-1}\right) \\ P_{SO(2n)}(x) &= \left(1 + x^{2n-1}\right)\left(1 + x^3\right)\left(1 + x^7\right)\cdots\left(1 + x^{4n-5}\right) \\ P_{G_2}(x) &= \left(1 + x^3\right)\left(1 + x^{11}\right) \\ P_{F_4}(x) &= \left(1 + x^3\right)\left(1 + x^{11}\right)\left(1 + x^{15}\right)\left(1 + x^{23}\right) \\ P_{E_6}(x) &= \left(1 + x^3\right)\left(1 + x^{9}\right)\left(1 + x^{11}\right)\left(1 + x^{15}\right)\left(1 + x^{17}\right)\left(1 + x^{23}\right) \\ P_{E_7}(x) &= \left(1 + x^3\right)\left(1 + x^{11}\right)\left(1 + x^{15}\right)\left(1 + x^{19}\right)\left(1 + x^{23}\right)\left(1 + x^{27}\right)\left(1 + x^{35}\right) \\ P_{E_{8}}(x) &= \left(1 + x^3\right)\left(1 + x^{15}\right)\left(1 + x^{23}\right)\left(1 + x^{27}\right)\left(1 + x^{35}\right)\left(1 + x^{39}\right)\left(1 + x^{47}\right)\left(1 + x^{59}\right) \end{aligned}$$

## Relationship with dimensions of spaces of differential forms {#Relationship_with_dimensions_of_spaces_of_differential_forms}

In geometric situations when $X$ is a [closed manifold](wikipedia://en/669475), the importance of the Betti numbers may arise from a different direction, namely that they predict the dimensions of vector spaces of [closed differential forms](https://en.wikipedia.org/wiki/Closed_differential_form) *[modulo](wikipedia://en/898784)* [exact differential forms](https://en.wikipedia.org/wiki/Exact_differential_form). The connection with the definition given above is via three basic results, [de Rham's theorem](https://en.wikipedia.org/wiki/De_Rham's_theorem) and [Poincaré duality](wikipedia://en/540732) (when those apply), and the [universal coefficient theorem](wikipedia://en/996107) of [homology theory](https://en.wikipedia.org/wiki/Homology_theory).

There is an alternate reading, namely that the Betti numbers give the dimensions of spaces of [harmonic forms](https://en.wikipedia.org/wiki/Harmonic_form). This requires the use of some of the results of [Hodge theory](wikipedia://en/501590) on the [Hodge Laplacian](https://en.wikipedia.org/wiki/Hodge_Laplacian).

In this setting, [Morse theory](wikipedia://en/348560) gives a set of inequalities for alternating sums of Betti numbers in terms of a corresponding alternating sum of the number of [critical points](wikipedia://en/1951424) $N_i$ of a [Morse function](https://en.wikipedia.org/wiki/Morse_function) of a given [index](wikipedia://en/348560):

$$b_i(X) - b_{i-1} (X) + \cdots \le N _i - N_{i-1} + \cdots.$$

[Edward Witten](wikipedia://en/54894) gave an explanation of these inequalities by using the Morse function to modify the [exterior derivative](wikipedia://en/220782) in the [de Rham complex](https://en.wikipedia.org/wiki/De_Rham_complex).[^o24]
