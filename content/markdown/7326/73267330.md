# Ville's inequality

::: {#o1 .subject cue=lead name="Ville's inequality"}

In [probability theory](wikipedia://en/23542), **Ville's inequality** provides an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) on the [probability](wikipedia://en/22934) that a [supermartingale](https://en.wikipedia.org/wiki/Supermartingale) exceeds a certain value. The [inequality](wikipedia://en/89489) is named after [Jean Ville](wikipedia://en/56194638), who proved it in 1939.[^o2][^o3][^o4][^o5] [^o6] The inequality has applications in statistical testing.

:::

::: {#o8 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $X_0, X_1, X_2, \dots$ be a non-negative supermartingale. Then, for any [real number](wikipedia://en/20646438) $a > 0,$

$$\operatorname{P} \left[ \sup_{n \ge 0} X_n \ge a \right] \le \frac{\operatorname{E}[X_0]}{a} \ .$$

The inequality is a [generalization](wikipedia://en/12746) of [Markov's inequality](wikipedia://en/238232).

:::
