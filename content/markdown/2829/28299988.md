# List of topologies on the category of schemes

::: {#o1 .subject cue=lead name="List of topologies on the category of schemes"}

The most fundamental item of study in modern [algebraic geometry](wikipedia://en/1997) is the [category](wikipedia://en/53759) of [schemes](wikipedia://en/364754). This category admits many different [Grothendieck topologies](wikipedia://en/12910), each of which is well-suited for a different purpose. This is a list of some of the topologies on the category of schemes.

:::

::: {#o2 .entry cue=list-entry name="Zariski topology"}

- [Zariski topology](wikipedia://en/241744) Essentially equivalent to the "ordinary" Zariski topology.

:::

::: {#o3 .entry cue=list-entry name="Nisnevich topology"}

- [Nisnevich topology](wikipedia://en/14627005) Uses etale morphisms, but has an extra condition about isomorphisms between residue fields.

:::

::: {#o4 .entry cue=list-entry name="Étale topology"}

- [Étale topology](wikipedia://en/5707590) Uses etale morphisms.

:::

::: {#o5 .entry cue=list-entry name="Fppf topology"}

- [fppf topology](https://en.wikipedia.org/wiki/Fppf_topology) Faithfully flat of finite presentation

:::

::: {#o6 .entry cue=list-entry name="Fpqc topology"}

- [fpqc topology](https://en.wikipedia.org/wiki/Fpqc_topology) Faithfully flat quasicompact

:::

::: {#o7 .entry cue=list-entry name="Rh topology"}

- [rh topology](https://en.wikipedia.org/wiki/Rh_topology) A variation of the h topology used to have a good theory of cohomology with compact support

:::

::: {#o8 .entry cue=list-entry name="cdh topology"}

- [*cdh* topology](https://en.wikipedia.org/wiki/Cdh_topology) rh + Nisnevich

:::

::: {#o9 .entry cue=list-entry name="ldh topology"}

- [ldh topology](wikipedia://en/14627005) used to apply Gabber's theorem on alterations

:::

::: {#o10 .entry cue=list-entry name="h topology"}

- [*h* topology](wikipedia://en/28299952) Coverings are universal topological epimorphisms. Also, h = rh + fppf.

:::

::: {#o11 .entry cue=list-entry name="V-topology"}

- [v-topology](https://en.wikipedia.org/wiki/V-topology) (also called universally subtrusive topology): coverings are maps which admit liftings for extensions of valuation rings

:::

::: {#o12 .entry cue=list-entry name="qfh topology"}

- [*qfh* topology](https://en.wikipedia.org/wiki/Qfh_topology) Similar to the h topology with a quasifiniteness condition. Used to encode finite correspondences topologically.

:::

::: {#o13 .entry cue=list-entry name="Smooth topology"}

- [Smooth topology](wikipedia://en/41891595) Uses smooth morphisms, but is usually equivalent to the etale topology (at least for schemes).

:::

::: {#o14 .entry cue=list-entry name="Canonical topology"}

- [Canonical topology](https://en.wikipedia.org/wiki/Canonical_topology) The finest such that all representable functors are sheaves.

:::
