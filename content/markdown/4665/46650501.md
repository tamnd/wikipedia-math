# Master Password (algorithm)

::: {#o2 .subject cue=lead name="Master Password"}

**Master Password** is a type of [algorithm](wikipedia://en/775) first implemented by [Maarten Billemont](https://en.wikipedia.org/wiki/Maarten_Billemont) for creating unique [passwords](wikipedia://en/24304) in a reproducible manner. It differs from traditional [password managers](wikipedia://en/4696394) in that the passwords are not stored on disk or in the cloud, but are regenerated every time from information entered by the user: Their name, a [master password](https://en.wikipedia.org/wiki/Master_password), and a unique identifier for the service the password is intended for (usually the URL).[^o5]

:::

By not storing the passwords anywhere, this approach makes it harder for attackers to steal or intercept them. It also removes the need for synchronization between devices, backups of potential password databases and risks of [data breach](https://en.wikipedia.org/wiki/Data_breach). This is sometimes called *sync-less password management*.

::: {#o4 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

Billemont's implementation involves the following parameters:[^o5]

- **name**: The username, used as a [salt](wikipedia://en/701756). The user's full name is chosen as it provides a sufficiently high level of entropy while being unlikely to be forgotten.
- **master\_password**: The secret for generating the master key.
- **site\_name**: A unique name for the service the password is intended for. Usually the bare domain name.
- **counter**: An integer that can be incremented when the service requests a new password. By default, it is 1.
- **password\_type**: The password type defines the length and the constitution of the resulting password, see below.

### Master key generation {#Master_key_generation}

In Billemont's implementation, the master key is a global 64-byte secret key generated from the user's secret [master password](https://en.wikipedia.org/wiki/Master_password) and salted by their full name. The salt is used to avoid attacks based on [rainbow tables](https://en.wikipedia.org/wiki/Rainbow_tables). The [scrypt](https://en.wikipedia.org/wiki/Scrypt) algorithm, an intentionally slow [key derivation function](wikipedia://en/449781), is used for generating the master key to make a [brute-force attack](wikipedia://en/53784) infeasible.

```python
salt = "com.lyndir.masterpassword" + length(name) + name
master_key = scrypt(master_password, salt, 32768, 8, 2, 64)
```

### Template seed generation {#Template_seed_generation}

The template seed is a site-specific secret in binary form, generated from the master key, the site name and the counter using the [HMAC-SHA256](https://en.wikipedia.org/wiki/HMAC-SHA256) algorithm. It is later converted to a character string using the password templates. The template seed makes every password unique to the website and to the user.

```python
seed = hmac_sha256(master_key, "com.lyndir.masterpassword" + length(site_name) + site_name + counter)
```

### Password generation {#Password_generation}

The binary template seed is then converted to one of six available password types. The default type is the *Maximum Security Password*, others can be selected if the service's password policy does not allow passwords of that format:

- **Maximum Security Password** (20 [ASCII printable characters](https://en.wikipedia.org/wiki/ASCII_printable_characters))
- **Long Password** (14 ASCII printable characters)
- **Medium Password** (8 ASCII printable characters)
- **Short Password** (4 ASCII printable characters)
- **Basic Password** (8 alphanumeric characters)
- **PIN** (4 digits)

## Implementations {#Implementations}

Billemont also created multiple [free software](https://en.wikipedia.org/wiki/Free_software) implementations of the Master Password algorithm, licensed under the [GPLv3](https://en.wikipedia.org/wiki/GPLv3).:[^o11]

- An app for [iOS](https://en.wikipedia.org/wiki/IOS). The iOS implementation was first released in 2012.[^o12]
- An app for [Mac OS X](https://en.wikipedia.org/wiki/Mac_OS_X)
- An app for [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29)
- A Graphical desktop application written in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29)
- A [command-line application](https://en.wikipedia.org/wiki/Command-line_application) written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29)
- A [browser plugin](https://en.wikipedia.org/wiki/Browser_plugin) for [Firefox](https://en.wikipedia.org/wiki/Firefox) and [Chromium](https://en.wikipedia.org/wiki/Chromium_%28web_browser%29)-based browsers[^o13][^o14]
- A web client written in [JavaScript](https://en.wikipedia.org/wiki/JavaScript).[^o15]
