# Rado's theorem (Ramsey theory)

::: {#o1 .subject cue=lead name="Rado's theorem"}

**Rado's theorem** is a theorem from the branch of [mathematics](wikipedia://en/18831) known as [Ramsey theory](wikipedia://en/157175). It is named for the German mathematician [Richard Rado](wikipedia://en/614984). It was proved in his thesis, *Studien zur Kombinatorik*.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $A \mathbf{x} = \mathbf{0}$ be a [system of linear equations](wikipedia://en/113087), where $A$ is a matrix with integer entries. This system is said to be $r$*\-regular* if, for every $r$-coloring of the natural numbers 1, 2, 3, ..., the system has a monochromatic solution. A system is *regular* if it is *r-regular* for all *r* ≥ 1.

Rado's theorem states that a system $A \mathbf{x} = \mathbf{0}$ is regular if and only if the matrix *A* satisfies the *columns condition*. Let *c<sub>i</sub>* denote the *i*-th column of *A*. The matrix *A* satisfies the columns condition provided that there exists a partition *C*<sub>1</sub>, *C*<sub>2</sub>, ..., *C*<sub>*n*</sub> of the column indices such that if $s_i = \Sigma_{j \in C_i}c_j$, then

1. *s*<sub>1</sub> = 0
1. for all *i* ≥ 2, *s<sub>i</sub>* can be written as a rational[^o4] linear combination of the *c<sub>j</sub>**s in all the*****C<sub>k</sub>*with*k*\<*i*. This means that*s<sub>i</sub>*is in the linear subspace of***Q**<sup>m</sup>*spanned by the set of the*c<sub>j</sub>*'s.***

:::

## Special cases {#Special_cases}

[Folkman's theorem](wikipedia://en/29265641), the statement that there exist arbitrarily large sets of integers all of whose nonempty sums are monochromatic, may be seen as a special case of Rado's theorem concerning the regularity of the system of equations

$$x_T = \sum_{i\in T}x_{\{i\}},$$

where *T* ranges over each nonempty subset of the set {1, 2, ..., *x*}.[^o7]

Other special cases of Rado's theorem are [Schur's theorem](wikipedia://en/1522286#Ramsey_theory) and [Van der Waerden's theorem](wikipedia://en/157178). For proving the former apply Rado's theorem to the matrix $(1\ 1\ {-1})$. For Van der Waerden's theorem with *m* chosen to be length of the monochromatic [arithmetic progression](wikipedia://en/168389), one can for example consider the following matrix:

$$\left( \begin{matrix} 1&1&-1&0&\cdots&0&0\\ 1&2&0&-1&\cdots&0&0\\ \vdots&\vdots&\vdots&\vdots&\ddots&\vdots&\vdots \\1&m-1&0&0&\cdots&-1&0\\ 1&m&0&0&\cdots&0&-1 \end{matrix}\right)$$

:::

## Computability {#Computability}

Given a system of linear equations it is a priori unclear how to check computationally that it is regular. Fortunately, Rado's theorem provides a criterion which is testable in finite time. Instead of considering colourings (of infinitely many natural numbers), it must be checked that the given matrix satisfies the columns condition. Since the matrix consists only of finitely many columns, this property can be verified in finite time.

However, the [subset sum problem](wikipedia://en/36811) can be [reduced](wikipedia://en/848067) to the problem of computing the required partition *C*<sub>1</sub>, *C*<sub>2</sub>, ..., *C*<sub>*n*</sub> of columns: Given an input set *S* for the subset sum problem we can write the elements of *S* in a matrix of shape 1 × |*S*|. Then the elements of *S* corresponding to vectors in the partition *C*<sub>1</sub> sum to zero. The subset sum problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete). Hence, verifying that a system of linear equations is regular is also an NP-complete problem.
