# Van der Corput lemma (harmonic analysis)

::: {#o1 .subject cue=lead name="Van der Corput lemma"}

In [mathematics](wikipedia://en/18831), in the field of [harmonic analysis](wikipedia://en/14147), the **van der Corput lemma** is an estimate for [oscillatory integrals](wikipedia://en/3224242) named after the [Dutch](https://en.wikipedia.org/wiki/Netherlands) mathematician [J. G. van der Corput](wikipedia://en/3791412).

:::

The following result is stated by [E. Stein](wikipedia://en/418073):[^o2]

Suppose that a real-valued function $\phi(x)$ is smooth in an open interval $(a, b)$, and that $|\phi^{(k)}(x)|\ge 1$ for all $x \in (a, b)$. Assume that either $k \ge 2$, or that $k = 1$ and $\phi'(x)$ is monotone for $x \in \mathbb{R}$. Then there is a constant $c_k$, which does not depend on $\phi$, such that

$$\bigg|\int_a^b e^{i\lambda\phi(x)}\bigg| \le c_k\lambda^{-1/k}$$

for any $\lambda \in \mathbb{R}$.

## Sublevel set estimates {#Sublevel_set_estimates}

The van der Corput lemma is closely related to the [sublevel set](https://en.wikipedia.org/wiki/Sublevel_set) estimates,[^o4] which give the upper bound on the [measure](wikipedia://en/19873) of the set where a function takes values not larger than $\epsilon$.

Suppose that a real-valued function $\phi(x)$ is smooth on a finite or infinite interval $I \subset \mathbb{R}$, and that $|\phi^{(k)}(x)| \ge 1$ for all $x \in I$. There is a constant $c_k$, which does not depend on $\phi$, such that for any $\epsilon \ge 0$ the measure of the sublevel set $\{x \in I: |\phi(x)| \le \epsilon\}$ is bounded by $c_k\epsilon^{1/k}$.
