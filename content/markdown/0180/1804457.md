# Bornological space

::: {#o1 .subject cue=lead name="Bornological space"}

In [mathematics](wikipedia://en/18831), particularly in [functional analysis](wikipedia://en/11180), a **bornological space** is a type of space which, in some sense, possesses the minimum amount of structure needed to address questions of boundedness of [sets](wikipedia://en/1789812) and [linear maps](https://en.wikipedia.org/wiki/Bounded_linear_operator), in the same way that a [topological space](wikipedia://en/30450) possesses the minimum amount of structure needed to address questions of [continuity](https://en.wikipedia.org/wiki/Continuous_map_%28topology%29). Bornological spaces are distinguished by the property that a linear map from a bornological space into any [locally convex](wikipedia://en/518844) spaces is continuous if and only if it is a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator).

:::

Bornological spaces were first studied by [George Mackey](https://en.wikipedia.org/wiki/George_Mackey). The name was coined by [Bourbaki](wikipedia://en/167394) after fr, the French word for "[bounded](wikipedia://en/48258)".

## Bornologies and bounded maps {#Bornologies_and_bounded_maps}

A **bornology** on a set $X$ is a collection $\mathcal{B}$ of subsets of $X$ that satisfy all the following conditions:

$\mathcal{B}$ covers $X;$ that is, $X = \cup \mathcal{B}$; $\mathcal{B}$ is stable under inclusions; that is, if $B \in \mathcal{B}$ and $A \subseteq B,$ then $A \in \mathcal{B}$; $\mathcal{B}$ is stable under finite unions; that is, if $B_1, \ldots, B_n \in \mathcal{B}$ then $B_1 \cup \cdots \cup B_n \in \mathcal{B}$;

Elements of the collection $\mathcal{B}$ are called **$\mathcal{B}$-bounded** or simply **bounded sets** if $\mathcal{B}$ is understood.[^n1] The pair $(X, \mathcal{B})$ is called a **bounded structure** or a **bornological set**.[^n1]

A **base** or **fundamental system** of a bornology $\mathcal{B}$ is a subset $\mathcal{B}_0$ of $\mathcal{B}$ such that each element of $\mathcal{B}$ is a subset of some element of $\mathcal{B}_0.$ Given a collection $\mathcal{S}$ of subsets of $X,$ the smallest bornology containing $\mathcal{S}$ is called the **bornology generated by $\mathcal{S}.$**[^n2]

If $(X, \mathcal{B})$ and $(Y, \mathcal{C})$ are bornological sets then their **product bornology** on $X \times Y$ is the bornology having as a base the collection of all sets of the form $B \times C,$ where $B \in \mathcal{B}$ and $C \in \mathcal{C}.$[^n2] A subset of $X \times Y$ is bounded in the product bornology if and only if its image under the canonical projections onto $X$ and $Y$ are both bounded.

### Bounded maps {#Bounded_maps}

If $(X, \mathcal{B})$ and $(Y, \mathcal{C})$ are bornological sets then a function $f : X \to Y$ is said to be a **locally bounded map** or a **bounded map** (with respect to these bornologies) if it maps $\mathcal{B}$-bounded subsets of $X$ to $\mathcal{C}$-bounded subsets of $Y;$ that is, if $f(\mathcal{B}) \subseteq \mathcal{C}.$[^n2] If in addition $f$ is a bijection and $f^{-1}$ is also bounded then $f$ is called a **bornological isomorphism**.

## Vector bornologies {#Vector_bornologies}

Let $X$ be a vector space over a [field](wikipedia://en/10603) $\mathbb{K}$ where $\mathbb{K}$ has a bornology $\mathcal{B}_{\mathbb{K}}.$ A bornology $\mathcal{B}$ on $X$ is called a **vector bornology on $X$** if it is stable under vector addition, scalar multiplication, and the formation of [balanced hulls](https://en.wikipedia.org/wiki/Balanced_hull) (i.e. if the sum of two bounded sets is bounded, etc.).

If $X$ is a [topological vector space](wikipedia://en/45752) (TVS) and $\mathcal{B}$ is a bornology on $X,$ then the following are equivalent:

$\mathcal{B}$ is a vector bornology; Finite sums and balanced hulls of $\mathcal{B}$-bounded sets are $\mathcal{B}$-bounded;[^n2] The scalar multiplication map $\mathbb{K} \times X \to X$ defined by $(s, x) \mapsto sx$ and the addition map $X \times X \to X$ defined by $(x, y) \mapsto x + y,$ are both bounded when their domains carry their product bornologies (i.e. they map bounded subsets to bounded subsets).[^n2]

A vector bornology $\mathcal{B}$ is called a **convex vector bornology** if it is stable under the formation of [convex hulls](wikipedia://en/40634) (i.e. the convex hull of a bounded set is bounded) then $\mathcal{B}.$ And a vector bornology $\mathcal{B}$ is called **separated** if the only bounded vector subspace of $X$ is the 0-dimensional trivial space $\{ 0 \}.$

Usually, $\mathbb{K}$ is either the real or complex numbers, in which case a vector bornology $\mathcal{B}$ on $X$ will be called a **convex vector bornology** if $\mathcal{B}$ has a base consisting of [convex](wikipedia://en/6292) sets.

### Bornivorous subsets {#Bornivorous_subsets}

A subset $A$ of $X$ is called **[bornivorous](https://en.wikipedia.org/wiki/Bornivorous)** and a **bornivore** if it [absorbs](wikipedia://en/1728179) every bounded set.

In a vector bornology, $A$ is bornivorous if it absorbs every bounded balanced set and in a convex vector bornology $A$ is bornivorous if it absorbs every bounded disk.

Two TVS topologies on the same vector space have that same bounded subsets if and only if they have the same bornivores.[^n3]

Every bornivorous subset of a locally convex [metrizable topological vector space](wikipedia://en/64278078) is a neighborhood of the origin.[^n4]

::: {#o16 .pointer-item cue=pointer name="Mackey complete topological vector space"}

#### Mackey convergence {#Mackey_convergence}

A sequence $x_\bullet = (x_i)_{i=1}^\infty$ in a TVS $X$ is said to be **Mackey convergent** to $0$ if there exists a sequence of positive real numbers $r_\bullet = (r_i)_{i=1}^\infty$ diverging to $\infty$ such that $(r_i x_i)_{i=1}^\infty$ converges to $0$ in $X.$[^n5]

:::

### Bornology of a topological vector space {#Bornology_of_a_topological_vector_space}

Every [topological vector space](wikipedia://en/45752) $X,$ at least on a non discrete [valued field](https://en.wikipedia.org/wiki/Valued_field) gives a bornology on $X$ by defining a subset $B \subseteq X$ to be [bounded](wikipedia://en/1789812) (or von-Neumann bounded), if and only if for all open sets $U \subseteq X$ containing zero there exists a $r > 0$ with $B \subseteq rU.$ If $X$ is a [locally convex](wikipedia://en/518844) [topological vector space](wikipedia://en/45752) then $B \subseteq X$ is bounded if and only if all continuous semi-norms on $X$ are bounded on $B.$

The set of all [bounded](wikipedia://en/1789812) subsets of a topological vector space $X$ is called **the bornology** or **the von Neumann bornology** of $X.$

If $X$ is a [locally convex topological vector space](wikipedia://en/518844), then an [absorbing](wikipedia://en/1728179) [disk](wikipedia://en/1734292) $D$ in $X$ is bornivorous (resp. infrabornivorous) if and only if its [Minkowski functional](wikipedia://en/3510908) is locally bounded (resp. infrabounded).[^n4]

### Induced topology {#Induced_topology}

If $\mathcal{B}$ is a convex vector bornology on a vector space $X,$ then the collection $\mathcal{N}_{\mathcal{B}}(0)$ of all convex [balanced](wikipedia://en/1734238) subsets of $X$ that are bornivorous forms a [neighborhood basis](https://en.wikipedia.org/wiki/Neighborhood_basis) at the origin for a [locally convex](wikipedia://en/518844) topology on $X$ called the **topology induced by $\mathcal{B}$**.[^n4]

If $(X, \tau)$ is a TVS then the **bornological space associated with $X$** is the vector space $X$ endowed with the locally convex topology induced by the von Neumann bornology of $(X, \tau).$[^n4]

::: {#o24 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n4].**

Let $X$ and $Y$ be locally convex TVS and let $X_b$ denote $X$ endowed with the topology induced by von Neumann bornology of $X.$ Define $Y_b$ similarly. Then a linear map $L : X \to Y$ is a bounded linear operator if and only if $L : X_b \to Y$ is continuous.

Moreover, if $X$ is bornological, $Y$ is Hausdorff, and $L : X \to Y$ is continuous linear map then so is $L : X \to Y_b.$ If in addition $X$ is also ultrabornological, then the continuity of $L : X \to Y$ implies the continuity of $L : X \to Y_{ub},$ where $Y_{ub}$ is the ultrabornological space associated with $Y.$

:::

## Quasi-bornological spaces {#Quasi-bornological_spaces}

Quasi-bornological spaces where introduced by S. Iyahen in 1968.[^n6]

A [topological vector space](wikipedia://en/45752) (TVS) $(X, \tau)$ with a [continuous dual](https://en.wikipedia.org/wiki/Continuous_dual) $X^{\prime}$ is called a **quasi-bornological space**[^n6] if any of the following equivalent conditions holds:

Every [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) from $X$ into another TVS is [continuous](wikipedia://en/1802169).[^n6] Every bounded linear operator from $X$ into a [complete metrizable TVS](wikipedia://en/200440) is continuous.[^n6][^n7] Every knot in a bornivorous string is a neighborhood of the origin.[^n6]

Every [pseudometrizable TVS](wikipedia://en/64278078) is quasi-bornological. [^n6] A TVS $(X, \tau)$ in which every [bornivorous set](wikipedia://en/64267682) is a neighborhood of the origin is a quasi-bornological space.[^n8] If $X$ is a quasi-bornological TVS then the finest locally convex topology on $X$ that is coarser than $\tau$ makes $X$ into a locally convex bornological space.

### Bornological space {#Bornological_space}

In functional analysis, a [locally convex topological vector space](wikipedia://en/518844) is a bornological space if its topology can be recovered from its bornology in a natural way.

Every locally convex quasi-bornological space is bornological but there exist bornological spaces that are not quasi-bornological.[^n6]

A [topological vector space](wikipedia://en/45752) (TVS) $(X, \tau)$ with a [continuous dual](https://en.wikipedia.org/wiki/Continuous_dual) $X^{\prime}$ is called a **bornological space** if it is locally convex and any of the following equivalent conditions holds:

Every convex, balanced, and bornivorous set in $X$ is a neighborhood of zero.[^n4] Every [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) from $X$ into a locally convex TVS is [continuous](wikipedia://en/1802169).[^n4]

Recall that a linear map is bounded if and only if it maps any sequence converging to $0$ in the domain to a bounded subset of the codomain.[^n4] In particular, any linear map that is sequentially continuous at the origin is bounded. Every bounded linear operator from $X$ into a [seminormed space](https://en.wikipedia.org/wiki/Seminormed_space) is continuous.[^n4] Every bounded linear operator from $X$ into a [Banach space](wikipedia://en/3989) is continuous.[^n4]

If $X$ is a [Hausdorff](wikipedia://en/13637) [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space) then we may add to this list:[^n7]

The locally convex topology induced by the von Neumann bornology on $X$ is the same as $\tau,$ $X$'s given topology. Every bounded [seminorm](wikipedia://en/292067) on $X$ is continuous.[^n4] Any other Hausdorff locally convex topological vector space topology on $X$ that has the same (von Neumann) bornology as $(X, \tau)$ is necessarily coarser than $\tau.$ $X$ is the inductive limit of normed spaces.[^n4] $X$ is the inductive limit of the normed spaces $X_D$ as $D$ varies over the closed and bounded disks of $X$ (or as $D$ varies over the bounded disks of $X$).[^n4] $X$ carries the Mackey topology $\tau(X, X^{\prime})$ and all bounded linear functionals on $X$ are continuous.[^n4]

$X$ has both of the following properties:

$X$ is **convex-sequential** or **C-sequential**, which means that every convex sequentially open subset of $X$ is open,

$X$ is **sequentially bornological** or **S-bornological**, which means that every convex and bornivorous subset of $X$ is sequentially open. where a subset $A$ of $X$ is called **[sequentially open](wikipedia://en/4668395)** if every sequence converging to $0$ eventually belongs to $A.$

Every sequentially continuous linear operator from a locally convex bornological space into a locally convex TVS is continuous,[^n4] where recall that a linear operator is sequentially continuous if and only if it is sequentially continuous at the origin. Thus for linear maps from a bornological space into a locally convex space, continuity is equivalent to sequential continuity at the origin. More generally, we even have the following:

Any linear map $F : X \to Y$ from a locally convex bornological space into a locally convex space $Y$ that maps null sequences in $X$ to [bounded subsets](wikipedia://en/1789812) of $Y$ is necessarily continuous.

### Sufficient conditions {#Sufficient_conditions}

::: {#o49 .statement kind=statement/theorem cue=math-theorem name="Mackey–Ulam theorem"}

**Mackey–Ulam theorem[^n9].**

The product of a collection $X_\bullet = ( X_i)_{i \in I}$ locally convex bornological spaces is bornological if and only if $I$ does not admit an [Ulam measure](https://en.wikipedia.org/wiki/Ulam_measure).

:::

As a consequent of the Mackey–Ulam theorem, "for all practical purposes, the product of bornological spaces is bornological."[^n9]

The following topological vector spaces are all bornological:

Any locally convex [pseudometrizable TVS](wikipedia://en/64278078) is bornological.[^n4][^n10]

Thus every [normed space](https://en.wikipedia.org/wiki/Normed_space) and [Fréchet space](wikipedia://en/233801) is bornological. Any strict inductive limit of bornological spaces, in particular any [strict *LF*-space](wikipedia://en/2314852), is bornological.

This shows that there are bornological spaces that are not metrizable. A countable product of locally convex bornological spaces is bornological.[^n11][^n10] Quotients of Hausdorff locally convex bornological spaces are bornological.[^n10] The direct sum and inductive limit of Hausdorff locally convex bornological spaces is bornological.[^n10] [Fréchet](wikipedia://en/233801) [Montel](wikipedia://en/1796319) spaces have bornological [strong duals](wikipedia://en/63951372). The strong dual of every [reflexive](wikipedia://en/210091) [Fréchet space](wikipedia://en/233801) is bornological.[^n12] If the strong dual of a metrizable locally convex space is [separable](wikipedia://en/27855), then it is bornological.[^n12] A vector subspace of a Hausdorff locally convex bornological space $X$ that has finite codimension in $X$ is bornological.[^n4][^n10] The [finest locally convex topology](wikipedia://en/518844) on a vector space is bornological.[^n4]

**Counterexamples**

There exists a bornological [LB-space](wikipedia://en/63848931) whose strong bidual is not bornological.[^n13]

A closed vector subspace of a locally convex bornological space is not necessarily bornological.[^n4][^n14] There exists a closed vector subspace of a locally convex bornological space that is complete (and so sequentially complete) but neither barrelled nor bornological.[^n4]

Bornological spaces need not be [barrelled](wikipedia://en/1733592) and barrelled spaces need not be bornological.[^n4] Because every locally convex ultrabornological space is barrelled,[^n4] it follows that a bornological space is not necessarily ultrabornological.

::: {#o69 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

The [strong dual space](wikipedia://en/63951372) of a locally convex bornological space is [complete](wikipedia://en/53695856).[^n4] Every locally convex bornological space is [infrabarrelled](https://en.wikipedia.org/wiki/Infrabarreled_space).[^n4] Every Hausdorff sequentially complete bornological TVS is [ultrabornological](wikipedia://en/63904912).[^n4]

Thus every [complete](wikipedia://en/53695856) Hausdorff bornological space is ultrabornological.

In particular, every [Fréchet space](wikipedia://en/233801) is ultrabornological.[^n4] The finite product of locally convex ultrabornological spaces is ultrabornological.[^n4] Every Hausdorff bornological space is [quasi-barrelled](https://en.wikipedia.org/wiki/Quasi-barrelled).[^n15] Given a bornological space $X$ with [continuous dual](https://en.wikipedia.org/wiki/Continuous_dual) $X^{\prime},$ the topology of $X$ coincides with the [Mackey topology](wikipedia://en/1790627) $\tau(X, X^{\prime}).$

In particular, bornological spaces are [Mackey spaces](wikipedia://en/1804899). Every [quasi-complete](https://en.wikipedia.org/wiki/Quasi-complete) (i.e. all closed and bounded subsets are complete) bornological space is [barrelled](wikipedia://en/1733592). There exist, however, bornological spaces that are not barrelled. Every bornological space is the inductive limit of normed spaces (and Banach spaces if the space is also quasi-complete).

Let $X$ be a metrizable locally convex space with continuous dual $X^{\prime}.$ Then the following are equivalent:

$\beta(X^{\prime}, X)$ is bornological. $\beta(X^{\prime}, X)$ is [quasi-barrelled](wikipedia://en/1733592). $\beta(X^{\prime}, X)$ is [barrelled](wikipedia://en/1733592). $X$ is a [distinguished space](wikipedia://en/64266856).

If $L : X \to Y$ is a linear map between locally convex spaces and if $X$ is bornological, then the following are equivalent:

$L : X \to Y$ is continuous. $L : X \to Y$ is sequentially continuous.[^n4] For every set $B \subseteq X$ that's bounded in $X,$ $L(B)$ is bounded. If $x_{\bullet} = (x_i)_{i=1}^\infty$ is a null sequence in $X$ then $L \circ x_\bullet = (L(x_i))_{i=1}^\infty$ is a null sequence in $Y.$ If $x_\bullet = (x_i)_{i=1}^\infty$ is a Mackey convergent null sequence in $X$ then $L \circ x_\bullet = (L(x_i))_{i=1}^\infty$ is a bounded subset of $Y.$

Suppose that $X$ and $Y$ are [locally convex](https://en.wikipedia.org/wiki/Locally_convex) TVSs and that the space of continuous linear maps $L_b(X; Y)$ is endowed with the [topology of uniform convergence on bounded subsets](wikipedia://en/41677409) of $X.$ If $X$ is a bornological space and if $Y$ is [complete](wikipedia://en/53695856) then $L_b(X; Y)$ is a complete TVS.[^n4]

In particular, the strong dual of a locally convex bornological space is complete.[^n4] However, it need not be bornological.

**Subsets**

In a locally convex bornological space, every convex bornivorous set $B$ is a neighborhood of $0$ ($B$ is not required to be a disk).[^n4] Every bornivorous subset of a locally convex [metrizable topological vector space](wikipedia://en/64278078) is a neighborhood of the origin.[^n4] Closed vector subspaces of bornological space need not be bornological.[^n4]

:::

## Ultrabornological spaces {#Ultrabornological_spaces}

A disk in a topological vector space $X$ is called **infrabornivorous** if it absorbs all [Banach disks](https://en.wikipedia.org/wiki/Banach_disk).

If $X$ is locally convex and Hausdorff, then a disk is infrabornivorous if and only if it absorbs all compact disks.

A locally convex space is called **ultrabornological** if any of the following equivalent conditions hold:

Every infrabornivorous disk is a neighborhood of the origin. $X$ is the inductive limit of the spaces $X_D$ as $D$ varies over all compact disks in $X.$ A [seminorm](wikipedia://en/292067) on $X$ that is bounded on each Banach disk is necessarily continuous. For every locally convex space $Y$ and every linear map $u : X \to Y,$ if $u$ is bounded on each Banach disk then $u$ is continuous. For every Banach space $Y$ and every linear map $u : X \to Y,$ if $u$ is bounded on each Banach disk then $u$ is continuous.

::: {#o84 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

The finite product of ultrabornological spaces is ultrabornological. Inductive limits of ultrabornological spaces are ultrabornological.

:::
