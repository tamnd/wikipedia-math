# Stata

::: {#o3 .subject cue=lead name="Stata"}

**Stata** (,[^o4] , alternatively , occasionally stylized as STATA[^o5][^o6]) is a general-purpose [statistical](wikipedia://en/26685) software package developed by StataCorp for data manipulation, visualization, statistics, and automated reporting. It is used by researchers in many fields, including [biomedicine](https://en.wikipedia.org/wiki/Biomedicine), [economics](https://en.wikipedia.org/wiki/Economics), [epidemiology](wikipedia://en/66997), and [sociology](https://en.wikipedia.org/wiki/Sociology).[^o7]

:::

Stata was initially developed by Computing Resource Center in California and the first version was released in 1985.[^o8] In 1993, the company moved to [College Station, Texas](https://en.wikipedia.org/wiki/College_Station,_Texas) and was renamed Stata Corporation, now known as StataCorp.[^o2] A major release in 2003 included a new graphics system and dialog boxes for all commands.[^o8] Since then, a new version has been released once every two years.[^o9] The current version is Stata 19, released in April 2025.[^o10]

## Technical overview and terminology {#Technical_overview_and_terminology}

### User interface {#User_interface}

From its creation, Stata has always employed an integrated command-line interface. Starting with version 8.0, Stata has included a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) which uses [menus](https://en.wikipedia.org/wiki/Menu_%28computing%29) and [dialog boxes](https://en.wikipedia.org/wiki/Dialog_boxes) to give access to many built-in commands. The dataset can be viewed or edited in spreadsheet format. From version 11 on, other commands can be executed while the data browser or editor is opened.

### Data structure and storage {#Data_structure_and_storage}

Until the release of version 16,[^o14] Stata could only open a single [dataset](https://en.wikipedia.org/wiki/Dataset) at any one time. Stata allows for flexibility with assigning data types to data. Its `compress` command automatically reassigns data to data types that take up less memory without loss of information. Stata utilizes integer storage types which occupy only one or two bytes rather than four, and single-precision (4 bytes) rather than double-precision (8 bytes) is the default for [floating-point](https://en.wikipedia.org/wiki/Floating-point) numbers.

Stata's proprietary output language is known as SMCL, which stands for Stata Markup and Control Language and is pronounced "smickle".[^o15]

Stata's data format is always [tabular](https://en.wikipedia.org/wiki/Table_%28information%29) in format. Stata refers to the columns of tabular data as variables.

### Data format compatibility {#Data_format_compatibility}

Stata can import data in a variety of formats. This includes [ASCII](https://en.wikipedia.org/wiki/ASCII) data formats (such as [CSV](https://en.wikipedia.org/wiki/Comma-separated_value) or [databank](https://en.wikipedia.org/wiki/Databank_format) formats) and spreadsheet formats (including various [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel) formats).

Stata's proprietary [file formats](https://en.wikipedia.org/wiki/File_format) have changed over time, although not every Stata release includes a new dataset format. Every version of Stata can read all older dataset formats, and can write both the current and most recent previous dataset format, using the `saveold` command.[^o17] Thus, the current Stata release can always open datasets that were created with older versions, but older versions cannot read newer format datasets.

Stata can read and write SAS XPORT format datasets natively, using the *fdause* and *fdasave* commands.

Some other [econometric](wikipedia://en/10390) applications, including [gretl](wikipedia://en/1166251), can directly import Stata file formats.

## History {#History}

The development of Stata began in 1984, initially by William (Bill) Gould and later by Sean Becketti. The software was intended to compete with statistical programs for personal computers such as [SYSTAT](wikipedia://en/2197220) and [MicroTSP](wikipedia://en/3933682).[^o8] Written in the [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) programming language, Stata was released for [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS) in 1985 with 44 commands.[^o8] Since then, versions of Stata have been released for systems running [Unix](https://en.wikipedia.org/wiki/Unix) variants like [Linux](https://en.wikipedia.org/wiki/Linux) distributions, [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), and [MacOS](https://en.wikipedia.org/wiki/Macintosh_operating_systems).[^o8] All Stata files are platform-independent.

There have been 19 major releases of Stata between 1985 and 2025 and additional code and documentation updates between major releases.[^o9] In its early years, extra sets of Stata programs were sometimes sold as "kits" or distributed as Support Disks. With the release of Stata 6 in 1999, `update`s began to be delivered to users via the web.[^o8]

Hundreds of commands have been added to Stata in its 37-year history.[^o19][^o20] Certain developments have proved to be particularly important and continue to shape the [user experience](https://en.wikipedia.org/wiki/User_experience) today, including [extensibility](https://en.wikipedia.org/wiki/Extensibility), [platform independence](https://en.wikipedia.org/wiki/Cross-platform_software), and the active [user community](https://en.wikipedia.org/wiki/Virtual_community).[^o8]

### Extensibility {#Extensibility}

The `program` command was implemented in Stata 1.2, giving users the ability to add their own commands.[^o8][^o22] ado-files followed in Stata 2.1, allowing a user-written program to be automatically loaded into memory. Many user-written ado-files are submitted to the [Statistical Software Components Archive](https://en.wikipedia.org/wiki/Statistical_Software_Components_Archive) hosted by Boston College. StataCorp added an `ssc` command to allow community-contributed programs to be added directly within Stata.[^o23] More recent editions of Stata allow users to call Python scripts using commands, as well as allowing Python IDEs like Jupyter Notebooks to import Stata commands.[^o24] Although Stata does not support R natively, there are user-written extensions to use R scripts in Stata.[^o25]

### User community {#User_community}

A number of important developments were initiated by Stata's active user community.[^o8] The *Stata Technical Bulletin*, which often contains user-created commands, was introduced in 1991 and issued six times a year. It was relaunched in 2001 as the peer-reviewed *Stata Journal*, a quarterly publication containing descriptions of community-contributed commands and tips for the effective use of Stata. In 1994, a listserv began as a hub for users to collaboratively solve coding and technical issues; in 2014, it was converted into a web forum. In 1995, Statacorp began organizing user and developer conferences that meet annually. Only the annual Stata Conference held in the United States is hosted by StataCorp. Other user group meetings are held annually in the United States (the Stata Conference), the UK, Germany, and Italy, and less frequently in several other countries. Local Stata distributors host User Group meetings in their own countries.

## Software products {#Software_products}

There are four builds of Stata: Stata/MP, Stata/SE, Stata/BE, and Numerics by Stata.[^o29] Whereas Stata/MP allows for built-in parallel processing of certain commands, Stata/SE and Stata/BE are [bottlenecked](https://en.wikipedia.org/wiki/Bottleneck_%28software%29) and limit usage to only one single core.[^o30] Stata/MP runs certain commands about 2.4 times faster, roughly 60% of theoretical maximum efficiency, when running parallel processes on four CPU cores compared to SE or BE versions.[^o30] Numerics by Stata allows for web integration of Stata commands.

SE and BE versions differ in the amount of memory datasets may utilize. Though Stata/MP can store 10 to 20 billion observations and up to 120,000 variables, Stata/SE and Stata/BE store up to 2.14 billion observations and handle 32,767 variables and 2,048 variables respectively. The maximum number of independent variables in a model is 65,532 variables in Stata/MP, 10,998 variables in Stata/SE, and 798 variables in Stata/BE.[^o29]

The pricing and licensing of Stata depends on its intended use: business, government/nonprofit, education, or student. Single user licenses are either renewable annually or perpetual. Other license types include a single license for use by concurrent users, a site license, volume single user for bulk pricing, or a student lab.[^o31]

## Example code {#Example_code}

The following set of commands revolve around simple data management.[^o33]

```stata
sysuse auto                 // Open the included auto dataset
browse                      // Browse the dataset (opens the Data Editor window)

describe                    // Describes the dataset and associated variables
summarize                   // Summary information about numerical variables

codebook make foreign       // Summary information about the make (string) and foreign (numeric) variables

browse if missing(rep78)    // Browse only observations with missing data for variable rep78
list make if missing(rep78) // List makes of the cars with missing data for variable rep78
```

The next set of commands move onto descriptive statistics.

```stata
summarize price, detail          // Detailed summary statistics for variable price

tabulate foreign                 // One-way frequency table for variable foreign
tabulate rep78 foreign, row      // Two-way frequency table for variables rep78 and foreign

summarize mpg if foreign == 1    // Summary information about mpg if the car is foreign (the "==" sign tests for equality)
by foreign, sort: summarize mpg  // As above, but using the "by" prefix.
tabulate foreign, summarize(mpg) // As above, but using the tabulate command.
```

A simple hypothesis test:

```stata
ttest mpg, by(foreign) // T-test for difference in means for domestic vs. foreign cars
```

Graphing data:

```stata
twoway (scatter mpg weight)                     // Scatter plot showing relationship between mpg and weight
twoway (scatter mpg weight), by(foreign, total) // Three graphs for domestic, foreign, and all cars
```

Linear regression:

```stata
generate wtsq = weight^2                      // Create a new variable for weight squared
regress mpg weight wtsq foreign, vce(robust)  // Linear regression of mpg on weight, wtsq, and foreign
predict mpghat                                // Create a new variable contained the predicted values of mpg
twoway (scatter mpg weight) (line mpghat weight, sort), by(foreign) // Graph data and fitted line
```
