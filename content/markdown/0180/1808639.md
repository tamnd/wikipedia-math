# Membership function (mathematics)

::: {#o1 .subject cue=lead name="Membership function"}

In [mathematics](wikipedia://en/18831), the **membership function** of a [fuzzy set](wikipedia://en/56601) is a generalization of the [indicator function](wikipedia://en/240790) for classical [sets](wikipedia://en/26691). In [fuzzy logic](wikipedia://en/49180), it represents the [degree of truth](wikipedia://en/537311) as an extension of [valuation](wikipedia://en/17456938). Degrees of truth are often confused with [probabilities](wikipedia://en/22934), although they are conceptually distinct, because [fuzzy truth](wikipedia://en/49180) represents membership in vaguely defined sets, not likelihood of some event or condition. Membership functions were introduced by [Aliasker Zadeh](https://en.wikipedia.org/wiki/Lotfi_A._Zadeh) in the first paper on fuzzy sets (1965). Aliasker Zadeh, in his theory of fuzzy sets, proposed using a membership function (with a [range](wikipedia://en/275991) covering the [interval](wikipedia://en/49172) (0,1)) operating on the domain of all possible values.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

For any set $X$, a membership function on $X$ is any function from $X$ to the [real](wikipedia://en/20646438) [unit interval](wikipedia://en/49324) $[0,1]$.

Membership functions represent [fuzzy subsets](wikipedia://en/56601) of $X$. The membership function which represents a fuzzy set $\tilde A$ is usually denoted by $\mu_A.$ For an element $x$ of $X$, the value $\mu_A(x)$ is called the *membership degree* of $x$ in the fuzzy set $\tilde A.$ The membership degree $\mu_{A}(x)$ quantifies the grade of membership of the element $x$ to the fuzzy set $\tilde A.$ The value 0 means that $x$ is not a member of the fuzzy set; the value 1 means that $x$ is fully a member of the fuzzy set. The values between 0 and 1 characterize fuzzy members, which belong to the fuzzy set only partially.

Membership function of a fuzzy set

Sometimes,[^o4] a more general definition is used, where membership functions take values in an arbitrary fixed [algebra](wikipedia://en/106364) or [structure](wikipedia://en/4055928) $L$ ; usually it is required that $L$ be at least a [poset](https://en.wikipedia.org/wiki/Poset) or [lattice](wikipedia://en/469304). The usual membership functions with values in \[0, 1\] are then called \[0, 1\]-valued membership functions.

:::

## Capacity {#Capacity}

One application of membership functions is as capacities in [decision theory](wikipedia://en/446216).

In [decision theory](wikipedia://en/446216), a capacity is defined as a function, $\nu$ from **S**, the set of [subsets](wikipedia://en/27631) of some set, into $[0,1]$, such that $\nu$ is set-wise monotone and is normalized (i.e. $\nu(\emptyset) = 0, \nu(\Omega)=1).$ This is a generalization of the notion of a [probability measure](wikipedia://en/45437), where the [probability axiom](https://en.wikipedia.org/wiki/Probability_axiom) of countable additivity is weakened. A capacity is used as a subjective measure of the likelihood of an event, and the "[expected value](wikipedia://en/9653)" of an outcome given a certain capacity can be found by taking the [Choquet integral](wikipedia://en/10252066) over the capacity.
