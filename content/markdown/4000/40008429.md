# LIBSVM

::: {#o2 .subject cue=lead name="LIBSVM"}

**LIBSVM** and **LIBLINEAR** are two popular [open source](https://en.wikipedia.org/wiki/Open_source_software) [machine learning](wikipedia://en/233488) libraries, both developed at the [National Taiwan University](https://en.wikipedia.org/wiki/National_Taiwan_University) and both written in [C++](https://en.wikipedia.org/wiki/C++) though with a [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) API. LIBSVM implements the [sequential minimal optimization](https://en.wikipedia.org/wiki/Sequential_minimal_optimization) (SMO) algorithm for [kernelized](https://en.wikipedia.org/wiki/Kernel_trick) [support vector machines](wikipedia://en/65309) (SVMs), supporting [classification](wikipedia://en/1579244) and [regression](wikipedia://en/826997).[^o3] LIBLINEAR implements [linear](wikipedia://en/98974) SVMs and [logistic regression](wikipedia://en/226631) models trained using a [coordinate descent](wikipedia://en/33837524) algorithm.[^o4]

:::

The SVM learning code from both libraries is often reused in other open source machine learning toolkits, including [GATE](https://en.wikipedia.org/wiki/General_Architecture_for_Text_Engineering), [KNIME](https://en.wikipedia.org/wiki/KNIME), [Orange](https://en.wikipedia.org/wiki/Orange_%28software%29)[^o5] and [scikit-learn](https://en.wikipedia.org/wiki/Scikit-learn).[^o6] Bindings and ports exist for programming languages such as [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29), [MATLAB](wikipedia://en/20412), [R](wikipedia://en/376707), [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), and [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29). It is available in e1071 library in R and [scikit-learn](https://en.wikipedia.org/wiki/Scikit-learn) in Python.

Both libraries are [free software](https://en.wikipedia.org/wiki/Free_software) released under the 3-clause [BSD license](https://en.wikipedia.org/wiki/BSD_license).[^o7][^o8]
