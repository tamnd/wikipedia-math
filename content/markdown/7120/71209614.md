# BusKill

::: {#o5 .subject cue=lead name="BusKill"}

**BusKill** is a project that makes a physical cord intended to lock a computer when the user walks away.

:::

It is an [open-source hardware](https://en.wikipedia.org/wiki/Open-source_hardware) and [software](https://en.wikipedia.org/wiki/Open-source_software) project that designs computer [kill cords](https://en.wikipedia.org/wiki/Kill_cord) to protect the [confidentiality](wikipedia://en/15036#Confidentiality) of the system's data from physical [theft](https://en.wikipedia.org/wiki/Theft). The hardware designs are licensed [CC BY-SA](https://en.wikipedia.org/wiki/CC_BY-SA) and the software is licensed [GPLv3](https://en.wikipedia.org/wiki/GPLv3). BusKill cables are available commercially from the official website or through authorized distributors.

## History {#History}

*Image: buskill\_original\_cable\_2020.jpg.* The original BusKill prototype from 2017

*Image: buskill\_cable\_2022.jpg.* The BusKill Kit in 2022

The first computer kill cord was built by Michael Altfield in 2017.[^o7][^o8]

The term "BusKill" was coined by Altfield in January 2020 when publishing the first BusKill build and [udev](https://en.wikipedia.org/wiki/Udev) usage instructions (Linux-only),[^o9][^o10][^o11] and it was ported by cyberkryption from Linux to Windows a couple weeks later.[^o12][^o13] The name BusKill is an amalgamation of "Bus" from [USB](https://en.wikipedia.org/wiki/USB) and "Kill" from kill cord.[^o14]

The project's official website launched the following month in February 2020.[^o15]

The first macOS version of the BusKill app was released in May 2020[^o16] by Steven Johnson.

A cross-platform rewrite of the software based on [Kivy](https://en.wikipedia.org/wiki/Kivy_%28framework%29) was released in August 2020 with support for [Linux](https://en.wikipedia.org/wiki/Linux), [macOS](https://en.wikipedia.org/wiki/MacOS), and [Windows](https://en.wikipedia.org/wiki/Windows).[^o17]

In December 2021, [Alt Shift International OÜ](https://en.wikipedia.org/wiki/Alt_Shift_International_OÜ) ran a crowdfunding campaign to manufacture BusKill cables on [Crowd Supply](https://en.wikipedia.org/wiki/Crowd_Supply).[^o18][^o19][^o20] The campaign raised \$18,507 by January 2022.[^o21]

## Hardware {#Hardware}

The BusKill cable is a kill cord that physically tethers a user to their computer with a USB cable.[^o23][^o24]

One end of the cable plugs into a computer. The other end of the cable is a [carabiner](https://en.wikipedia.org/wiki/Carabiner) that attaches to the user.[^o25]

In the middle of the cable is a magnetic breakaway coupler, to allow the cable to be safely separated at any angle without physically damaging the computer or the user.[^o26][^o27]

A [3D-printable](https://en.wikipedia.org/wiki/3D_printing) hardware BusKill cable is currently under development.[^o28][^o29][^o30]

## Software {#Software}

The BusKill project maintains a cross-platform GUI app that can either [lock the screen](https://en.wikipedia.org/wiki/Lock_screen) or [shutdown](https://en.wikipedia.org/wiki/Shutdown_%28computing%29) the computer when the cable's connection to the computer is severed and the app is in the "armed" state.[^o23][^o32][^o33]

::: {#o35 .application cue=heading name="Use"}

## Use {#Use}

If the computer is separated from the user, then a magnetic breakaway in the cable causes a [USB hotplug removal](https://en.wikipedia.org/wiki/Libusb) event to execute a trigger in the app.[^o36]

The trigger executed by the BusKill cable's removal can lock the screen, shutdown, or securely erase the [LUKS](https://en.wikipedia.org/wiki/LUKS) header and [master encryption keys](wikipedia://en/53039) within a few seconds of the cable's separation.[^o37][^o38][^o39]

If combined with [full disk encryption](wikipedia://en/7066791#Full_disk_encryption), then these triggers can be used to ensure the [confidentiality](wikipedia://en/353859) of data or be used as a [counter-forensics](https://en.wikipedia.org/wiki/Anti-computer_forensics) device.

:::
