# Twisted polynomial ring

::: {#o1 .subject cue=lead name="Twisted polynomial ring"}

In [mathematics](wikipedia://en/18831), a **twisted polynomial**[^o2][^o3] is a [polynomial](wikipedia://en/23000) over a [field](wikipedia://en/10603) of [characteristic](wikipedia://en/1066621) $p$ in the variable $\tau$ representing the [Frobenius map](https://en.wikipedia.org/wiki/Frobenius_map) $x\mapsto x^p$. In contrast to normal polynomials, multiplication of these polynomials is not [commutative](https://en.wikipedia.org/wiki/Commutative), but satisfies the commutation rule

:::

$$\tau x=x^p \tau$$

for all $x$ in the base field.

Over an infinite field, the twisted polynomial ring is isomorphic to the ring of [additive polynomials](wikipedia://en/1374699), but where multiplication on the latter is given by composition rather than usual multiplication. However, it is often easier to compute in the twisted polynomial ring — this can be applied especially in the theory of [Drinfeld modules](wikipedia://en/5578871).

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $k$ be a field of characteristic $p$. The twisted polynomial ring $k\{\tau\}$ is defined as the set of polynomials in the variable $\tau$ and coefficients in $k$. It is endowed with a [ring](wikipedia://en/48404) structure with the usual addition, but with a non-commutative multiplication that can be summarized with the relation $\tau x=x^p\tau$ for $x\in k$. Repeated application of this relation yields a formula for the multiplication of any two twisted polynomials.[^o6]

As an example we perform such a multiplication

$$(a+b\tau)(c+d\tau)=a(c+d\tau)+b\tau(c+d\tau)=ac+ad\tau+bc^p\tau+bd^p\tau^2$$

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The morphism

$$k\{\tau\}\to k[x],\quad a_0+a_1\tau+\cdots+a_n\tau^n\mapsto a_0x+a_1x^p+\cdots+a_nx^{p^n}$$

defines a [ring homomorphism](wikipedia://en/26411) sending a twisted polynomial to an additive polynomial. Here, multiplication on the right hand side is given by composition of polynomials.[^o9] For example

$$(ax+bx^p)\circ (cx+dx^p)=a(cx+dx^p)+b(cx+dx^p)^p=acx+adx^p+bc^px^p+bd^px^{p^2},$$

using the fact that in characteristic $p$ we have the [Freshman's dream](wikipedia://en/17373539) $(x+y)^p=x^p+y^p$.

The homomorphism is clearly injective, but is surjective if and only if $k$ is infinite. The failure of surjectivity when $k$ is finite is due to the existence of non-zero polynomials which induce the zero function on $k$ (e.g. $x^q-x$ over the finite field with $q$ elements).

Even though this ring is not commutative, it still possesses (left and right) [division algorithms](wikipedia://en/679987).

:::
