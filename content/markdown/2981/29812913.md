# Min-plus matrix multiplication

::: {#o1 .subject cue=lead name="Min-plus matrix multiplication"}

**Min-plus matrix multiplication**, also known as **distance product**, is an operation on [matrices](wikipedia://en/20556859).

:::

Given two $n \times n$ matrices $A = (a_{ij})$ and $B = (b_{ij})$, their distance product $C = (c_{ij}) = A \star B$ is defined as an $n \times n$ matrix such that $c_{ij} = \min_{k=1}^n \{a_{ik} + b_{kj}\}$. This is standard matrix multiplication for the semi-ring of [tropical numbers](wikipedia://en/867041) in the min convention.

This operation is closely related to the [shortest path problem](wikipedia://en/41985). If $W$ is an $n \times n$ matrix containing the edge weights of a [graph](wikipedia://en/325806), then $W^k$ gives the distances between vertices using paths of length at most $k$ edges, and $W^n$ is the [distance matrix](wikipedia://en/831350) of the graph.
