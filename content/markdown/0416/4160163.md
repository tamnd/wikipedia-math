# List of random number generators

::: {#o1 .subject cue=lead name="List of random number generators"}

[Random number generators](wikipedia://en/2736939) are important in many kinds of technical applications, including [physics](wikipedia://en/22939), [engineering](https://en.wikipedia.org/wiki/Engineering) or [mathematical](wikipedia://en/18831) computer studies (e.g., [Monte Carlo](wikipedia://en/56098) simulations), [cryptography](wikipedia://en/18934432) and [gambling](wikipedia://en/11921) (on [game servers](https://en.wikipedia.org/wiki/Game_server)).

:::

This list includes many common types, regardless of quality or applicability to a given use case.

## Pseudorandom number generators (PRNGs) {#Pseudorandom_number_generators_(PRNGs)}

The following algorithms are [pseudorandom number generators](wikipedia://en/45524).

Similar to Philox in design but significantly faster. |
| \\|Collatz-Weyl Generators | 2023 | Tomasz R. Działa | [^o73] | A class of chaotic [counter-based](wikipedia://en/51367517) generators applying a broad class of non-invertible generalized [Collatz mappings](wikipedia://en/37895) and [Weyl sequences](wikipedia://en/56841538), enabling the generation of multiple independent streams. ## Cryptographic algorithms {#Cryptographic_algorithms}

[Cipher](wikipedia://en/5244) algorithms and [cryptographic hashes](https://en.wikipedia.org/wiki/Cryptographic_hash) can be used as very high-quality pseudorandom number generators. However, generally they are considerably slower (typically by a factor 2–10) than fast, non-cryptographic random number generators.

These include:

::: {#o75 .entry cue=list-entry name="Stream cipher"}

- [Stream ciphers](wikipedia://en/49007). Popular choices are [Salsa20](wikipedia://en/2701329) or [ChaCha](wikipedia://en/2701329#ChaCha_variant) (often with the number of rounds reduced to 8 for speed), [ISAAC](wikipedia://en/295564), [HC-128](https://en.wikipedia.org/wiki/HC-256) and [RC4](wikipedia://en/25831#Pseudo-random_generation_algorithm_%28PRGA%29).

:::

::: {#o76 .entry cue=list-entry name="Block cipher"}

- [Block ciphers](wikipedia://en/4594) in [counter mode](https://en.wikipedia.org/wiki/Block_cipher_modes_of_operation#Counter_%28CTR%29). Common choices are [AES](wikipedia://en/1260) (which is very fast on [systems supporting it in hardware](wikipedia://en/23095336)), [TwoFish](wikipedia://en/26508356), [Serpent](wikipedia://en/385154) and [Camellia](wikipedia://en/532475).

:::

::: {#o77 .entry cue=list-entry name="Cryptographic hash function"}

- [Cryptographic hash functions](wikipedia://en/439526)

:::

A few cryptographically secure pseudorandom number generators do not rely on cipher algorithms but try to link mathematically the difficulty of distinguishing their output from a \`true' random stream to a computationally difficult problem. These approaches are theoretically important but are too slow to be practical in most applications. They include:

::: {#o78 .entry cue=list-entry name="Blum–Micali algorithm"}

- [Blum–Micali algorithm](wikipedia://en/17739090) (1984)

:::

::: {#o79 .entry cue=list-entry name="Blum Blum Shub"}

- [Blum Blum Shub](wikipedia://en/39599) (1986)

:::

::: {#o80 .entry cue=list-entry name="Naor–Reingold pseudorandom function"}

- [Naor–Reingold pseudorandom function](wikipedia://en/30578523) (1997)

:::

## Random number generators that use external entropy {#Random_number_generators_that_use_external_entropy}

These approaches combine a pseudo-random number generator (often in the form of a block or stream cipher) with an external source of randomness (e.g., mouse movements, delay between keyboard presses etc.).

::: {#o82 .entry cue=list-entry name="Unix-like"}

- `[[Dev/random|/dev/random]]` – [Unix-like](https://en.wikipedia.org/wiki/Unix-like) systems

:::

::: {#o83 .entry cue=list-entry name="CryptGenRandom"}

- [CryptGenRandom](wikipedia://en/6109234) – [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows)

:::

::: {#o84 .entry cue=list-entry name="Fortuna"}

- [Fortuna](wikipedia://en/1627154)

:::

::: {#o85 .entry cue=list-entry name="RDRAND"}

- [RDRAND](https://en.wikipedia.org/wiki/RDRAND) instructions (called *Intel Secure Key* by [Intel](https://en.wikipedia.org/wiki/Intel)), available in Intel x86 CPUs since 2012. They use the AES generator built into the CPU, reseeding it periodically.

:::

::: {#o86 .entry cue=list-entry name="Yarrow"}

- [Yarrow](wikipedia://en/74416)

:::

::: {#o87 .entry cue=list-entry name="RANDOM.org"}

- [RANDOM.org](https://en.wikipedia.org/wiki/Random.org)

:::
