# Restricted isometry property

::: {#o1 .subject cue=lead name="Restricted isometry property"}

In [linear algebra](wikipedia://en/18422), the **restricted isometry property** (**RIP**) characterizes [matrices](wikipedia://en/20556859) which are nearly orthonormal, at least when operating on sparse vectors. The concept was introduced by [Emmanuel Candès](https://en.wikipedia.org/wiki/Emmanuel_Candès) and [Terence Tao](wikipedia://en/1118498)[^o2] and is used to prove many theorems in the field of [compressed sensing](wikipedia://en/11403316).[^o3] There are no known large matrices with bounded restricted isometry constants (computing these constants is [strongly NP-hard](https://en.wikipedia.org/wiki/Strongly_NP-hard),[^o4] and is hard to approximate as well[^o5]), but many [random matrices](wikipedia://en/1648765) have been shown to remain bounded. In particular, it has been shown that with exponentially high probability, random Gaussian, Bernoulli, and partial Fourier matrices satisfy the RIP with number of measurements nearly linear in the sparsity level.[^o6] The current smallest upper bounds for any large rectangular matrices are for those of Gaussian matrices.[^o7] Web forms to evaluate bounds for the Gaussian ensemble are available at the Edinburgh Compressed Sensing RIC page.[^o8]

:::

::: {#o10 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *A* be an *m* × *p* matrix and let *1* ≤ *s* ≤ *p* be an integer. Suppose that there exists a constant $\delta_s \in (0,1)$ such that, for every *m* × *s* submatrix *A*<sub>*s*</sub> of *A* and for every *s*-dimensional vector *y*,

$$(1-\delta_s)\|y\|_{2}^2 \le \|A_s y\|_{2}^2 \le (1+\delta_s)\|y\|_{2}^2. \,$$

Then, the matrix *A* is said to satisfy the *s*-restricted isometry property with restricted isometry constant $\delta_s$.

This condition is equivalent to the statement that for every *m* × *s* submatrix *A*<sub>*s*</sub> of *A* we have

$$\|A^*_sA_s - I_{s \times s}\|_{2\to2} \le \delta_s,$$

where $I_{s \times s}$ is the $s \times s$ [identity matrix](wikipedia://en/59718) and $\|X\|_{2\to2}$ is the [operator norm](wikipedia://en/246722). See for example [^o11] for a proof.

Finally this is equivalent to stating that all [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of $A^*_sA_s$ are in the interval $[1-\delta_s, 1+\delta_s]$.

:::

## Restricted Isometric Constant (RIC) {#Restricted_Isometric_Constant_(RIC)}

The RIC Constant is defined as the [infimum](wikipedia://en/39382) of all possible $\delta$ for a given $A \in \mathbb{R}^{n \times m}$.

$$\delta_K = \inf \left[ \delta : (1-\delta)\|y\|_2^2 \le \|A_s y\|_2^2 \le (1+\delta)\|y\|_2^2 \right],\ \forall |s| \le K, \forall y \in R^{|s|}$$

It is denoted as $\delta_K$.

## Eigenvalues {#Eigenvalues}

For any matrix that satisfies the RIP property with a RIC of $\delta_K$, the following condition holds:[^o2]

$$1 - \delta_K \le \lambda_{min} (A_\tau^*A_\tau) \le \lambda_{max}(A_\tau^*A_\tau) \le 1+\delta_K.$$

The tightest upper bound on the RIC can be computed for Gaussian matrices. This can be achieved by computing the exact probability that all the eigenvalues of Wishart matrices lie within an interval.
