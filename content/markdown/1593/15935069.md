# Sinusoidal model

::: {#o1 .subject cue=lead name="Sinusoidal model"}

In [statistics](wikipedia://en/26685), [signal processing](wikipedia://en/29324), and [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis), a **sinusoidal model** is used to approximate a sequence *$y_i$* to a [sine](https://en.wikipedia.org/wiki/Sine) function:

:::

$$y_i = c + \alpha\sin(\omega t_i + \varphi) + \varepsilon_i$$

where *$c$* is constant defining a [mean](https://en.wikipedia.org/wiki/Mean) level, $\alpha$ is an [amplitude](https://en.wikipedia.org/wiki/Amplitude) for the [sine](https://en.wikipedia.org/wiki/Sine), $\omega$ is the [angular frequency](https://en.wikipedia.org/wiki/Angular_frequency), *$t_i$* is a time variable, $\varphi$ is the [phase-shift](https://en.wikipedia.org/wiki/Phase-shift), and *$\varepsilon_i$* is the error sequence.

This sinusoidal model can be fit using [nonlinear least squares](https://en.wikipedia.org/wiki/Nonlinear_least_squares); to obtain a good fit, routines may require good starting values for the unknown parameters.[^o2] Fitting a model with a single sinusoid is a special case of [spectral density estimation](wikipedia://en/13070117) and [least-squares spectral analysis](wikipedia://en/13609399).

## Good starting values {#Good_starting_values}

### Good starting value for the mean {#Good_starting_value_for_the_mean}

A good starting value for *$c$* can be obtained by calculating the [mean](https://en.wikipedia.org/wiki/Mean) of the data. If the data show a [trend](https://en.wikipedia.org/wiki/Trend_estimation), i.e., the assumption of constant location is violated, one can replace *$c$* with a linear or quadratic [least squares](wikipedia://en/82359) fit. That is, the model becomes

$$y_i = (b_0 + b_1t_i) + \alpha\sin(\omega t_i + \varphi) + \varepsilon_i$$

or

$$y_i = (b_0 + b_1t_i+b_2t_i^2) + \alpha\sin(\omega t_i + \varphi) + \varepsilon_i$$

### Good starting value for frequency {#Good_starting_value_for_frequency}

The starting value for the frequency can be obtained from the dominant frequency in a [periodogram](wikipedia://en/485457). A [complex demodulation](https://en.wikipedia.org/wiki/Complex_demodulation) phase plot can be used to refine this initial estimate for the frequency.[^o6]

### Good starting values for amplitude {#Good_starting_values_for_amplitude}

The [root mean square](wikipedia://en/66819) of the detrended data can be scaled by the square root of two to obtain an estimate of the sinusoid amplitude. A complex demodulation amplitude plot can be used to find a good starting value for the amplitude. In addition, this plot can indicate whether or not the amplitude is constant over the entire range of the data or if it varies. If the plot is essentially flat, i.e., zero slope, then it is reasonable to assume a constant amplitude in the non-linear model. However, if the slope varies over the range of the plot, one may need to adjust the model to be:

$$y_i = c + (b_0 + b_1 t_i)\sin(\omega t_i + \phi) + \varepsilon_i$$

That is, one may replace α with a function of time. A linear fit is specified in the model above, but this can be replaced with a more elaborate function if needed.

## Model validation {#Model_validation}

As with any [statistical model](wikipedia://en/27576), the fit should be subjected to graphical and quantitative techniques of [model validation](https://en.wikipedia.org/wiki/Model_validation). For example, a [run sequence plot](https://en.wikipedia.org/wiki/Run_sequence_plot) to check for significant shifts in location, scale, start-up effects and [outliers](https://en.wikipedia.org/wiki/Outliers). A [lag plot](https://en.wikipedia.org/wiki/Lag_plot) can be used to verify the [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) are independent. The outliers also appear in the lag plot, and a [histogram](wikipedia://en/13266) and [normal probability plot](wikipedia://en/543119) to check for skewness or other non-[normality](wikipedia://en/21462) in the residuals.

## Extensions {#Extensions}

A different method consists in transforming the non-linear regression to a linear regression thanks to a convenient integral equation. Then, there is no need for initial guess and no need for iterative process : the fitting is directly obtained.[^o11]
