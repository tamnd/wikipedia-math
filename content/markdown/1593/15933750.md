# Forking extension

::: {#o1 .subject cue=lead name="Forking extension"}

In [model theory](wikipedia://en/19858), a **forking extension** of a type is an extension of that type that is not free whereas a **non-forking extension** is an extension that is as free as possible. This can be used to extend the notions of [linear](wikipedia://en/101863) or [algebraic independence](wikipedia://en/287808) to [stable theories](wikipedia://en/15828771). These concepts were introduced by [S. Shelah](https://en.wikipedia.org/wiki/S._Shelah).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Suppose that *A* and *B* are models of some complete ω-stable theory *T*. If *p* is a type of *A* and *q* is a type of *B* containing *p*, then *q* is called a **forking extension** of *p* if its [Morley rank](wikipedia://en/1401941) is smaller, and a **nonforking extension** if it has the same Morley rank.

:::

::: {#o5 .statement kind=statement/axiom cue=named-heading name="Axioms"}

## Axioms {#Axioms}

Let *T* be a stable complete theory. The non-forking relation ≤ for types over *T* is the unique relation that satisfies the following axioms:

1. If *p*≤*q* then *p*⊂*q*. If *f* is an elementary map then *p*≤*q* if and only if *fp*≤*fq*
1. If *p*⊂*q*⊂*r* then *p*≤*r* if and only if *p*≤*q* and *q*≤*r*
1. If *p* is a type of *A* and *A*⊂*B* then there is some type *q* of *B* with *p*≤*q*.
1. There is a cardinal κ such that if *p* is a type of *A* then there is a subset *A*<sub>0</sub> of *A* of cardinality less than *κ* so that (*p*|*A*<sub>0</sub>) ≤ *p*, where | stands for restriction.
1. For any *p* there is a cardinal λ such that there are at most λ non-contradictory types *q* with *p*≤*q*.

:::
