# ♯P

P

::: {#o1 .subject cue=lead name="♯P"}

In [computational complexity theory](wikipedia://en/7543), the complexity class **\#P** (pronounced "sharp P" or, sometimes "number P" or "hash P") is the set of the [counting problems](https://en.wikipedia.org/wiki/Counting_problem_%28complexity%29) associated with the [decision problems](wikipedia://en/8336) in the set **[NP](wikipedia://en/21562)**. More formally, **\#P** is the class of [function problems](wikipedia://en/663345) of the form "compute *f*(*x*)", where *f* is the number of accepting paths of a [nondeterministic Turing machine](wikipedia://en/21935) running in [polynomial time](wikipedia://en/405944#Polynomial_time). Unlike most well-known complexity classes, it is not a class of [decision problems](wikipedia://en/8336) but a class of [function problems](wikipedia://en/663345). The most difficult, representative problems of this class are [\#P-complete](wikipedia://en/27925).

:::

## Relation to decision problems {#Relation_to_decision_problems}

An **NP** decision problem can often be stated in the form "Are there any solutions that satisfy certain constraints?" For example:

- Are there any subsets of a list of integers that add up to zero? ([subset sum problem](wikipedia://en/36811))
- Are there any [Hamiltonian cycles](https://en.wikipedia.org/wiki/Hamiltonian_cycle) in a given [graph](wikipedia://en/12401) with cost less than 100? ([traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem))
- Are there any variable assignments that satisfy a given [CNF (conjunctive normal form)](wikipedia://en/73342) formula? ([Boolean satisfiability problem](wikipedia://en/4715) or SAT)
- Does a univariate real polynomial have any positive roots? ([root finding](https://en.wikipedia.org/wiki/Root_finding))

Corresponding **\#P** function problems ask "how many" rather than "are there any". For example:

- How many subsets of a list of integers add up to zero?
- How many Hamiltonian cycles in a given graph have cost less than 100?
- How many variable assignments satisfy a given CNF formula?
- How many roots of a univariate real polynomial are positive?

## Related complexity classes {#Related_complexity_classes}

Clearly, a **\#P** problem must be at least as hard as the corresponding **NP** problem. If it's easy to count answers, then it must be easy to tell whether there are any answers—just count them and see whether the count is greater than zero. Some of these problems, such as [root counting](https://en.wikipedia.org/wiki/Root_finding), are easy enough to be in [FP](wikipedia://en/663347), while others are [\#P-complete](wikipedia://en/27925).

One consequence of [Toda's theorem](wikipedia://en/18125091) is that a [polynomial-time](wikipedia://en/405944#Polynomial_time) machine with a **\#P** [oracle](wikipedia://en/22431) (**P**<sup>**\#P**</sup>) can solve all problems in **[PH](https://en.wikipedia.org/wiki/PH_%28complexity%29)**, the entire [polynomial hierarchy](wikipedia://en/658651). In fact, the polynomial-time machine only needs to make one **\#P** query to solve any problem in **PH**. This is an indication of the extreme difficulty of solving **\#P**-complete problems exactly.

Surprisingly, some **\#P** problems that are believed to be difficult correspond to easy (for example linear-time) **[P](wikipedia://en/658550)** problems. For more information on this, see [\#P-complete](https://en.wikipedia.org/wiki/Sharp-P-complete).

The closest decision problem class to **\#P** is **[PP](wikipedia://en/659322)**, which asks whether a majority (more than half) of the computation paths accept. This finds the most significant bit in the **\#P** problem answer. The decision problem class **[⊕P](wikipedia://en/2120422)** (pronounced "Parity-P") instead asks for the least significant bit of the **\#P** answer.

## Formal definitions {#Formal_definitions}

**\#P** is formally defined as follows:

**\#P** is the set of all functions $f:\{0,1\}^* \to \mathbb{N}$ such that there is a polynomial-time [nondeterministic Turing machine](wikipedia://en/21935) $M$ such that for all $x \in \{0,1\}^*$, $f(x)$ equals the number of accepting branches in $M$'s computation graph on $x$.[^o6]

**\#P** can also be equivalently defined in terms of a verifer. A decision problem is in **[NP](wikipedia://en/21562)** if there exists a polynomial-time checkable [certificate](wikipedia://en/14933760) to a given problem instance—that is, **NP** asks whether there exists a proof of membership for the input that can be checked for correctness in polynomial time. Questions in **\#P** ask *how many* certificates there exist for a problem instance that can be checked for correctness in polynomial time.[^o6] In this context, **\#P** is defined as follows:

**\#P** is the set of functions $f: \{0,1\}^* \to \mathbb{N}$ such that there exists a polynomial $p: \mathbb{N} \to \mathbb{N}$ and a polynomial-time [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) $V$, called the verifier, such that for every $x \in \{0,1\}^*$, $f(x)=\Big| \big \{y \in \{0,1\}^{p(|x|)} : V(x,y)=1 \big \} \Big|$.[^o7] (In other words, $f(x)$ equals the size of the set containing all of the polynomial-size certificates).

:::

## History {#History}

The complexity class **\#P** was first defined by [Leslie Valiant](https://en.wikipedia.org/wiki/Leslie_Valiant) in a 1979 article on the computation of the [permanent](wikipedia://en/215889) of a [square matrix](wikipedia://en/166022), in which he proved that [permanent is #P-complete](https://en.wikipedia.org/wiki/Permanent_is_sharp-P-complete).[^o9]

[Larry Stockmeyer](https://en.wikipedia.org/wiki/Larry_Stockmeyer) has proved that for every #P problem $P$ there exists a [randomized algorithm](wikipedia://en/495383) using an oracle for SAT, which given an instance $a$ of $P$ and $\epsilon > 0$ returns with high probability a number $x$ such that $(1-\epsilon) P(a) \leq x \leq (1+\epsilon) P(a)$.[^o10] The runtime of the algorithm is polynomial in $a$ and $1/ \epsilon$. The algorithm is based on the [leftover hash lemma](wikipedia://en/7006101).
