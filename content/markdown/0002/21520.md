# Null set

the set with no elements

*Image: Sierpinski triangle.svg.* The [Sierpiński triangle](wikipedia://en/29638) is an example of a null set of points in $\mathbb R^2$.

::: {#o1 .subject cue=lead name="Null set"}

In [mathematical analysis](wikipedia://en/48396), a **null set** in $\mathbb R$ is a [Lebesgue measurable set](https://en.wikipedia.org/wiki/Lebesgue_measurable_set) of real numbers that has **[measure](wikipedia://en/18198) zero**. This can be characterized as a set that can be [covered](wikipedia://en/317552) by a [countable](https://en.wikipedia.org/wiki/Countable) union of [intervals](wikipedia://en/49172) of arbitrarily small total length.

:::

A null set is not to be confused with the [empty set](wikipedia://en/9566) as defined in [set theory](wikipedia://en/27553). Although the empty set has [Lebesgue measure](wikipedia://en/18198) zero, there are also non-empty sets which are null. For example, any non-empty countable set of real numbers has Lebesgue measure zero and therefore is null.

More generally, on a given [measure space](wikipedia://en/45270) $M = (X, \Sigma, \mu)$ a null set is a set $S \in \Sigma$ such that $\mu(S) = 0.$

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Every finite or [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) subset of the [real numbers](https://en.wikipedia.org/wiki/Real_numbers) $\mathbb{R}$ is a null set. For example, the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $\mathbb{N}$, the set of [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) $\mathbb{Q}$ and the set of [algebraic numbers](https://en.wikipedia.org/wiki/Algebraic_numbers) $\mathbb A$ are all countably infinite and therefore are null sets when considered as subsets of the real numbers.

The [Cantor set](wikipedia://en/6172) is an example of an uncountable null set. It is uncountable because it contains all real numbers between 0 and 1 whose [ternary](wikipedia://en/62950) expansion can be written using only 0s and 2s (see [Cantor's diagonal argument](wikipedia://en/51426)), and it is null because it is constructed by beginning with the closed interval of real numbers from 0 to 1 and iteratively removing a third of the previous set, thereby multiplying the length by 2/3 with every step.

The set of [Liouville numbers](wikipedia://en/50964) is another example of an uncountable null set.

:::

## Definition for Lebesgue measure {#Definition_for_Lebesgue_measure}

The [Lebesgue measure](wikipedia://en/18198) is the standard way of assigning a [length](wikipedia://en/18542), [area](wikipedia://en/1209) or [volume](wikipedia://en/32498) to subsets of [Euclidean space](wikipedia://en/9697).

A subset $N$ of the [real line](https://en.wikipedia.org/wiki/Real_line) $\mathbb{R}$ has null Lebesgue measure and is considered to be a null set (also known as a set of zero-content) in $\mathbb{R}$ if and only if:

[Given any](https://en.wikipedia.org/wiki/Given_any) [positive number](https://en.wikipedia.org/wiki/Positive_number) $\varepsilon,$ [there is](wikipedia://en/91420) a [sequence](wikipedia://en/27838) $I_1, I_2, \ldots$ of [intervals](wikipedia://en/49172) in $\mathbb{R}$ (where interval $I_n = (a_n, b_n) \subseteq \mathbb{R}$ has length $\operatorname{length}(I_n) = b_n - a_n$) such that $N$ is contained in the union of the $I_1, I_2, \ldots$ and the total length of the union is less than $\varepsilon;$ i.e.,[^o5]

$$N \subseteq \bigcup_{n=1}^\infty I_n \ ~\textrm{and}~ \ \sum_{n=1}^\infty \operatorname{length}(I_n) < \varepsilon \,.$$

(In terminology of [mathematical analysis](wikipedia://en/48396), this definition requires that there be a [sequence](wikipedia://en/27838) of [open covers](https://en.wikipedia.org/wiki/Open_cover) of $A$ for which the [limit](wikipedia://en/285773) of the lengths of the covers is zero.)

This condition can be generalised to $\mathbb{R}^n,$ using $n$-[cubes](https://en.wikipedia.org/wiki/Cube_%28geometry%29) instead of intervals. In fact, the idea can be made to make sense on any [manifold](wikipedia://en/2073470), even if there is no Lebesgue measure there.

For instance:

- With respect to $\mathbb{R}^n,$ all [singleton sets](wikipedia://en/381798) are null, and therefore all [countable sets](wikipedia://en/6026) are null. In particular, the set $\mathbb{Q}$ of [rational numbers](wikipedia://en/19727024) is a null set, despite being [dense](https://en.wikipedia.org/wiki/Dense_%28topology%29) in $\mathbb{R}.$
- The standard construction of the [Cantor set](wikipedia://en/6172) is an example of a null [uncountable set](wikipedia://en/32248) in $\mathbb{R};$ however other constructions are possible which assign the Cantor set any measure whatsoever.
- All the subsets of $\mathbb{R}^n$ whose [dimension](wikipedia://en/8398) is smaller than $n$ have null Lebesgue measure in $\mathbb{R}^n.$ For instance straight lines or circles are null sets in $\mathbb{R}^2.$
- [Sard's lemma](https://en.wikipedia.org/wiki/Sard's_lemma): the set of **critical values** of a smooth function has measure zero.

If $\lambda$ is Lebesgue measure for $\mathbb{R}$ and π is Lebesgue measure for $\mathbb{R}^2$, then the [product measure](wikipedia://en/2986564) $\lambda \times \lambda = \pi.$ In terms of null sets, the following equivalence has been styled a [Fubini's theorem](wikipedia://en/255245):[^o6]

- For $A \subset \mathbb{R}^2$ and $A_x = \{y : (x , y) \in A\},$ $$\pi(A) = 0 \iff \lambda \left(\left\{x : \lambda\left(A_x\right) > 0\right\}\right) = 0.$$

## Measure-theoretic properties {#Measure-theoretic_properties}

Let $(X,\Sigma,\mu)$ be a [measure space](wikipedia://en/45270). We have:

- $\mu(\varnothing) = 0$ (by [definition](wikipedia://en/19873#Definition) of $\mu$).
- Any [countable](https://en.wikipedia.org/wiki/Countable) [union](wikipedia://en/47949) of null sets is itself a null set (by [countable subadditivity](wikipedia://en/19873#Countable_subadditivity) of $\mu$).
- Any (measurable) subset of a null set is itself a null set (by [monotonicity](wikipedia://en/19873#Monotonicity) of $\mu$).

Together, these facts show that the null sets of $(X,\Sigma,\mu)$ form a [𝜎-ideal](wikipedia://en/1567410) of the [𝜎-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) $\Sigma$. Accordingly, null sets may be interpreted as [negligible sets](wikipedia://en/195132), yielding a measure-theoretic notion of "[almost everywhere](wikipedia://en/44688)".

::: {#o9 .application cue=heading name="Uses"}

## Uses {#Uses}

Null sets play a key role in the definition of the [Lebesgue integral](https://en.wikipedia.org/wiki/Lebesgue_integration): if functions $f$ and $g$ are equal except on a null set, then $f$ is integrable if and only if $g$ is, and their integrals are equal. This motivates the formal definition of [$L^p$ spaces](wikipedia://en/45194) as sets of equivalence classes of functions which differ only on null sets.

A measure in which all subsets of null sets are measurable is *[complete](wikipedia://en/44775)*. Any non-complete measure can be completed to form a complete measure by asserting that subsets of null sets have measure zero. Lebesgue measure is an example of a complete measure; in some constructions, it is defined as the completion of a non-complete [Borel measure](wikipedia://en/4322).

### A subset of the Cantor set which is not Borel measurable {#A_subset_of_the_Cantor_set_which_is_not_Borel_measurable}

The Borel measure is not complete. One simple construction is to start with the standard [Cantor set](wikipedia://en/6172) $K,$ which is closed hence Borel measurable, and which has measure zero, and to find a subset $F$ of $K$ which is not Borel measurable. (Since the Lebesgue measure is complete, this $F$ is of course Lebesgue measurable.)

First, we have to know that every set of positive measure contains a nonmeasurable subset. Let $f$ be the [Cantor function](wikipedia://en/320819), a continuous function which is locally constant on $K^c,$ and monotonically increasing on $[0, 1],$ with $f(0) = 0$ and $f(1) = 1.$ Obviously, $f(K^c)$ is countable, since it contains one point per component of $K^c.$ Hence $f(K^c)$ has measure zero, so $f(K)$ has measure one. We need a strictly [monotonic function](wikipedia://en/48260), so consider $g(x) = f(x) + x.$ Since $g$ is strictly monotonic and continuous, it is a [homeomorphism](wikipedia://en/13660). Furthermore, $g(K)$ has measure one. Let $E \subseteq g(K)$ be non-measurable, and let $F = g^{-1}(E).$ Because $g$ is injective, we have that $F \subseteq K,$ and so $F$ is a null set. However, if it were Borel measurable, then $f(F)$ would also be Borel measurable (here we use the fact that the [preimage](wikipedia://en/579311) of a Borel set by a continuous function is measurable; $g(F) = (g^{-1})^{-1}(F)$ is the preimage of $F$ through the continuous function $h = g^{-1}$). Therefore $F$ is a null, but non-Borel measurable set.

:::

## Haar null sets {#Haar_null_sets}

In a [separable](wikipedia://en/27855) [Banach space](wikipedia://en/3989) $(X, \|\cdot\|),$ addition moves any subset $A \subseteq X$ to the translates $A + x$ for any $x \in X.$ When there is a [probability measure](wikipedia://en/45437) $\mu$ on the σ-algebra of [Borel subsets](https://en.wikipedia.org/wiki/Borel_subset) of $X,$ such that for all $x,$ $\mu(A + x) = 0,$ then $A$ is a **Haar null set**.[^o12]

The term refers to the null invariance of the measures of translates, associating it with the complete invariance found with [Haar measure](wikipedia://en/40645).

Some algebraic properties of [topological groups](wikipedia://en/42315) have been related to the size of subsets and Haar null sets.[^o13] Haar null sets have been used in [Polish groups](https://en.wikipedia.org/wiki/Polish_group) to show that when $A$ is not a [meagre set](wikipedia://en/226975) then $A^{-1} A$ contains an open neighborhood of the [identity element](wikipedia://en/14962).[^o14] This property is named for [Hugo Steinhaus](wikipedia://en/71735) since it is the conclusion of the [Steinhaus theorem](wikipedia://en/9175084).
