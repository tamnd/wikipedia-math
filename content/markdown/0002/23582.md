# Preorder

*Image: Preorder.png.* *x R y* defined by *x*[//](https://en.wikipedia.org/wiki/Integer_division)4≤*y*[//](https://en.wikipedia.org/wiki/Integer_division)4 is a preorder on the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers). It corresponds to the equivalence relation *x E y* defined by *x*//4=*y*//4. The set of equivalence classes is partially ordered, and thus can be shown as a [Hasse diagram](wikipedia://en/338199) (depicted).

::: {#o1 .subject cue=lead name="Preorder"}

In [mathematics](wikipedia://en/18831), in particular in [order theory](wikipedia://en/361924), a **preorder** or **quasiorder** is a [binary relation](wikipedia://en/3931) that is [reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200463). The name preorder is meant to suggest that preorders are *almost* [partial orders](https://en.wikipedia.org/wiki/Partial_order), but not quite, as they are not necessarily [antisymmetric](wikipedia://en/1176).

:::

A natural example of a preorder is the [divides relation](wikipedia://en/49492#Definition) "x divides y" between [integers](wikipedia://en/14563). This relation is reflexive as every integer divides itself. It is also transitive. But it is not antisymmetric, because e.g. $1$ divides $-1$ and $-1$ divides $1$, but $-1$ is not equal to $1$. It is to this preorder that "least" refers in the phrase "[least common multiple](wikipedia://en/17961)" (in contrast, using the natural order on integers, e.g. $4$ and $6$ have the common multiples $24$, $12$, $0$, $-12$, $-24$, ..., but no least one).

Preorders are closely related to [equivalence relations](wikipedia://en/9259) and (non-strict) partial orders. Both of these are special cases of a preorder: an antisymmetric preorder is a partial order, and a [symmetric](wikipedia://en/200459) preorder is an equivalence relation. Moreover, a preorder on a set $X$ can equivalently be defined as an equivalence relation on $X$, together with a partial order on the set of [equivalence class](wikipedia://en/9260), cf. picture. Like partial orders and equivalence relations, preorders (on a nonempty set) are never [asymmetric](wikipedia://en/1229368).

A preorder can be visualized as a [directed graph](wikipedia://en/19721986), with elements of the set corresponding to vertices, and the order relation between pairs of elements corresponding to the directed edges between vertices. The converse is not true: most directed graphs are neither reflexive nor transitive. A preorder that is antisymmetric no longer has cycles; it is a partial order, and corresponds to a [directed acyclic graph](wikipedia://en/204002). A preorder that is symmetric is an equivalence relation; it can be thought of as having lost the direction markers on the edges of the graph. In general, a preorder's corresponding directed graph may have many disconnected components.

A preorder is often denoted $\,\lesssim\,$ or $\,\leq\,$.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A binary relation $\,\lesssim\,$ on a [set](wikipedia://en/26691) $X$ is called a **preorder** or **quasiorder** if it is [reflexive](wikipedia://en/200458) and [transitive](wikipedia://en/200463); that is, if it satisfies:

1. [Reflexivity](wikipedia://en/200458): $a \lesssim a$ for all $a \in X,$ and
1. [Transitivity](wikipedia://en/200463): if $a \lesssim b \text{ and } b \lesssim c \text{ then } a \lesssim c$ for all $a, b, c \in X.$

A set that is equipped with a preorder is called a **preordered set** (or **proset**).[^o4]

:::

## Preorders as partial orders on partitions {#Preorders_as_partial_orders_on_partitions}

Given a preorder $\,\lesssim\,$ on $X$ one may define an [equivalence relation](wikipedia://en/9259) $\,\sim\,$ on $X$ by

$$a \sim b \quad \text{ if } \quad a \lesssim b \; \text{ and } \; b \lesssim a.$$

The resulting relation $\,\sim\,$ is reflexive since the preorder $\,\lesssim\,$ is reflexive; transitive by applying the transitivity of $\,\lesssim\,$ twice; and symmetric by definition.

Using this relation, it is possible to construct a partial order on the [quotient set](https://en.wikipedia.org/wiki/Quotient_set) $X / \sim$ of the equivalence, by defining $[x] \leq [y]$ if $x \lesssim y.$ That this is [well-defined](wikipedia://en/253456#Independence_of_representative), meaning that it does not depend on the particular choice of representatives $x$ and $y$, follows from the definition of $\,\sim\,$.

Conversely, from any partial order on a partition of a set $X,$ it is possible to construct a preorder on $X$ itself. There is a [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence) between preorders and pairs (partition, partial order).

Example: Let $X$ be the set of all (valid or invalid) [sentences](wikipedia://en/2129527) in some subfield of mathematics, like [geometry](wikipedia://en/18973446). Define $p \Leftarrow q$ if $p$ is a logical consequence of $q$. Then $\Leftarrow$ is a preorder on $X$: every sentence $p$ can be proven from itself (reflexivity), and if $p$ can be proven from $q$, and $q$ from $r$, then $p$ can also be proven from $r$ (transitivity). The corresponding equivalence relation is usually denoted $p \Leftrightarrow q$, and defined as $p \Leftarrow q$ and $q \Leftarrow p$; in this case $p$ and $q$ are called "[logically equivalent](https://en.wikipedia.org/wiki/Logically_equivalent)". The equivalence class of a sentence $p$ is the set of all sentences $q \in X$ that are logically equivalent to $p$; formally: $[p] = \{ q \mid p \Leftrightarrow q \}$. The preordered set $(X, \Leftarrow)$ is a [directed set](wikipedia://en/9165): given two sentences $p, q \in X$, their [logical conjunction](wikipedia://en/18152) $p \wedge q$, pronounced "both $p$ and $q$", is a common upper bound of them, since $p$ is a consequence of $p \wedge q$, and so is $q$. The partially ordered set $\left(X / \Leftrightarrow, \Leftarrow\right)$ is hence also a directed set. See [Lindenbaum–Tarski algebra](wikipedia://en/990343) for a related example.

## Relationship to strict partial orders {#Relationship_to_strict_partial_orders}

If reflexivity is replaced with [irreflexivity](https://en.wikipedia.org/wiki/Irreflexive_relation) (while keeping transitivity) then we get the definition of a [strict partial order](https://en.wikipedia.org/wiki/Strict_partial_order) on $X$. For this reason, the term **strict preorder** is sometimes used for a strict partial order. That is, this is a binary relation $\,<\,$ on $X$ that satisfies:

[Irreflexivity](https://en.wikipedia.org/wiki/Irreflexive_relation) or anti-reflexivity: not $a < a$ for all $a \in X;$ that is, $\,a < a$ is false for all $a \in X,$ and [Transitivity](wikipedia://en/200463): if $a < b \text{ and } b < c \text{ then } a < c$ for all $a, b, c \in X.$

### Strict partial order induced by a preorder {#Strict_partial_order_induced_by_a_preorder}

Any preorder $\,\lesssim\,$ gives rise to a strict partial order defined by $a < b$ if and only if $a \lesssim b$ and not $b \lesssim a$. Using the equivalence relation $\,\sim\,$ introduced above, $a < b$ if and only if $a \lesssim b \text{ and not } a \sim b;$ and so the following holds

$$a \lesssim b \quad \text{ if and only if } \quad a < b \; \text{ or } \; a \sim b.$$

The relation $\,<\,$ is a [strict partial order](https://en.wikipedia.org/wiki/Strict_partial_order) and every strict partial order can be constructed this way. If the preorder $\,\lesssim\,$ is [antisymmetric](wikipedia://en/1176) (and thus a partial order) then the equivalence $\,\sim\,$ is equality (that is, $a \sim b$ if and only if $a = b$) and so in this case, the definition of $\,<\,$ can be restated as:

$$a < b \quad \text{ if and only if } \quad a \lesssim b \; \text{ and } \; a \neq b \quad\quad (\text{assuming } \lesssim \text{ is antisymmetric}).$$

But importantly, this new condition is not used as (nor is it equivalent to) the general definition of the relation $\,<\,$ (that is, $\,<\,$ is not defined as: $a < b$ if and only if $a \lesssim b \text{ and } a \neq b$) because if the preorder $\,\lesssim\,$ is not antisymmetric then the resulting relation $\,<\,$ would not be transitive (consider how equivalent non-equal elements relate). This is the reason for using the symbol "$\lesssim$" instead of the "less than or equal to" symbol "$\leq$", which might cause confusion for a preorder that is not antisymmetric since it might misleadingly suggest that $a \leq b$ implies $a < b \text{ or } a = b.$

### Preorders induced by a strict partial order {#Preorders_induced_by_a_strict_partial_order}

Using the construction above, multiple non-strict preorders can produce the same strict preorder $\,<,\,$ so without more information about how $\,<\,$ was constructed (such as knowledge of the equivalence relation $\,\sim\,$ for instance), it might not be possible to reconstruct the original non-strict preorder from $\,<.\,$ Possible (non-strict) preorders that induce the given strict preorder $\,<\,$ include the following:

- Define $a \leq b$ as $a < b \text{ or } a = b$ (that is, take the reflexive closure of the relation). This gives the partial order associated with the strict partial order "$<$" through reflexive closure; in this case the equivalence is equality $\,=,$ so the symbols $\,\lesssim\,$ and $\,\sim\,$ are not needed.
- Define $a \lesssim b$ as "$\text{ not } b < a$" (that is, take the inverse complement of the relation), which corresponds to defining $a \sim b$ as "neither $a < b \text{ nor } b < a$"; these relations $\,\lesssim\,$ and $\,\sim\,$ are in general not transitive; however, if they are then $\,\sim\,$ is an equivalence; in that case "$<$" is a [strict weak order](https://en.wikipedia.org/wiki/Strict_weak_order). The resulting preorder is [connected](wikipedia://en/57495962) (formerly called total); that is, a [total preorder](https://en.wikipedia.org/wiki/Total_preorder).

If $a \leq b$ then $a \lesssim b.$ The converse holds (that is, $\,\lesssim\;\; = \;\;\leq\,$) if and only if whenever $a \neq b$ then $a < b$ or $b < a.$

## Examples {#Examples}

### Graph theory {#Graph_theory}

- The [reachability](wikipedia://en/2833097) relationship in any [directed graph](wikipedia://en/19721986) (possibly containing cycles) gives rise to a preorder, where $x \lesssim y$ in the preorder if and only if there is a path from *x* to *y* in the directed graph. Conversely, every preorder is the reachability relationship of a directed graph (for instance, the graph that has an edge from *x* to *y* for every pair (*x*, *y*) with $x \lesssim y$). However, many different graphs may have the same reachability preorder as each other. In the same way, reachability of [directed acyclic graphs](wikipedia://en/204002), directed graphs with no cycles, gives rise to [partially ordered sets](wikipedia://en/23572) (preorders satisfying an additional antisymmetry property).
- The [graph-minor](https://en.wikipedia.org/wiki/Graph-minor) relation is also a preorder.

### Computer science {#Computer_science}

In computer science, one can find examples of the following preorders.

- [Asymptotic order](wikipedia://en/44578) causes a preorder over functions $f: \mathbb{N} \to \mathbb{N}$. The corresponding equivalence relation is called [asymptotic equivalence](wikipedia://en/641995#Definition).
- [Polynomial-time](wikipedia://en/159695), [many-one (mapping)](wikipedia://en/362983) and [Turing reductions](wikipedia://en/1188375) are preorders on complexity classes.
- [Subtyping](wikipedia://en/213508) relations are usually preorders.[^o13]
- [Simulation preorders](https://en.wikipedia.org/wiki/Simulation_preorder) are preorders (hence the name).
- [Reduction relations](https://en.wikipedia.org/wiki/Reduction_relation) in [abstract rewriting systems](wikipedia://en/23947591).
- The [encompassment preorder](https://en.wikipedia.org/wiki/Encompassment_preorder) on the set of [terms](wikipedia://en/24885593), defined by $s \lesssim t$ if a [subterm](wikipedia://en/24885593#Operations_with_terms) of *t* is a [substitution instance](https://en.wikipedia.org/wiki/Substitution_instance) of *s*.
- [Theta-subsumption](https://en.wikipedia.org/wiki/Theta-subsumption),[^o14] which is when the literals in a disjunctive first-order formula are contained by another, after applying a [substitution](wikipedia://en/5438948) to the former.

### Category theory {#Category_theory}

- A [category](wikipedia://en/53759) with at most one [morphism](wikipedia://en/27716891) from any object *x* to any other object *y* is a preorder. Such categories are called [thin](wikipedia://en/31353487). Here the [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) correspond to the elements of $X,$ and there is one morphism for objects which are related, zero otherwise. In this sense, categories "generalize" preorders by allowing more than one relation between objects: each morphism is a distinct (named) preorder relation.
- Alternately, a preordered set can be understood as an [enriched category](wikipedia://en/142622), enriched over the category $2 = (0 \to 1).$

### Other {#Other}

Further examples:

- Every [finite topological space](wikipedia://en/14682596) gives rise to a preorder on its points by defining $x \lesssim y$ if and only if *x* belongs to every [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) of *y*. Every finite preorder can be formed as the [specialization preorder](https://en.wikipedia.org/wiki/Specialization_%28pre%29order) of a topological space in this way. That is, there is a [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence) between finite topologies and finite preorders. However, the relation between infinite topological spaces and their specialization preorders is not one-to-one.
- A [net](wikipedia://en/22170) is a [directed](wikipedia://en/9165) preorder, that is, each pair of elements has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound). The definition of convergence via nets is important in [topology](wikipedia://en/29954), where preorders cannot be replaced by [partially ordered sets](wikipedia://en/23572) without losing important features.
- The relation defined by $x \lesssim y$ if $f(x) \lesssim f(y),$ where *f* is a function into some preorder.
- The relation defined by $x \lesssim y$ if there exists some [injection](wikipedia://en/45196) from *x* to *y*. Injection may be replaced by [surjection](https://en.wikipedia.org/wiki/Surjection), or any type of structure-preserving function, such as [ring homomorphism](wikipedia://en/26411), or [permutation](wikipedia://en/44027).
- The [embedding](wikipedia://en/52119) relation for countable [total orderings](wikipedia://en/30330).

Example of a [total preorder](https://en.wikipedia.org/wiki/Strict_weak_ordering#Total_preorders):

- [Preference](https://en.wikipedia.org/wiki/Preference), according to common models.[^o17]

## Constructions {#Constructions}

Every binary relation $R$ on a set $X$ can be extended to a preorder on $X$ by taking the [transitive closure](wikipedia://en/292239) and [reflexive closure](wikipedia://en/22603618), $R^{+=}.$ The transitive closure indicates path connection in $R : x R^+ y$ if and only if there is an $R$-[path](wikipedia://en/638889) from $x$ to $y.$

**Left residual preorder induced by a binary relation**

Given a binary relation $R,$ the complemented composition $R \backslash R = \overline{R^\textsf{T} \circ \overline{R}}$ forms a preorder called the [left residual](https://en.wikipedia.org/wiki/Heterogeneous_relation#Preorder_R\R),[^o20] where $R^\textsf{T}$ denotes the [converse relation](wikipedia://en/3941020) of $R,$ and $\overline{R}$ denotes the [complement](wikipedia://en/54347) relation of $R,$ while $\circ$ denotes [relation composition](https://en.wikipedia.org/wiki/Relation_composition).

:::

## Related definitions {#Related_definitions}

If a preorder is also [antisymmetric](wikipedia://en/1176), that is, $a \lesssim b$ and $b \lesssim a$ implies $a = b,$ then it is a [partial order](wikipedia://en/23572).

On the other hand, if it is [symmetric](wikipedia://en/200459), that is, if $a \lesssim b$ implies $b \lesssim a,$ then it is an [equivalence relation](wikipedia://en/9259).

A preorder is [total](https://en.wikipedia.org/wiki/Total_preorder) if $a \lesssim b$ or $b \lesssim a$ for all $a, b \in X.$

A [preordered class](wikipedia://en/15366532) is a [class](https://en.wikipedia.org/wiki/Class_%28mathematics%29) equipped with a preorder. Every set is a class and so every preordered set is a preordered class.

::: {#o23 .application cue=heading name="Uses"}

## Uses {#Uses}

Preorders play a pivotal role in several situations:

- Every preorder can be given a topology, the [Alexandrov topology](wikipedia://en/542198); and indeed, every preorder on a set is in one-to-one correspondence with an Alexandrov topology on that set.
- Preorders may be used to define [interior algebras](wikipedia://en/990454).
- Preorders provide the [Kripke semantics](wikipedia://en/911960) for certain types of [modal logic](wikipedia://en/333365).
- Preorders are used in [forcing](wikipedia://en/152205) in [set theory](wikipedia://en/27553) to prove [consistency](wikipedia://en/75802) and [independence](wikipedia://en/1141208) results.[^o24]

:::

## Number of preorders {#Number_of_preorders}

As explained above, there is a 1-to-1 correspondence between preorders and pairs (partition, partial order). Thus the number of preorders is the sum of the number of partial orders on every partition. For example: for $n = 3:$ 1 partition of 3, giving 1 preorder 3 partitions of 2 + 1, giving $3 \times 3 = 9$ preorders 1 partition of 1 + 1 + 1, giving 19 preorders I.e., together, 29 preorders.; for $n = 4:$ 1 partition of 4, giving 1 preorder 7 partitions with two classes (4 of 3 + 1 and 3 of 2 + 2), giving $7 \times 3 = 21$ preorders 6 partitions of 2 + 1 + 1, giving $6 \times 19 = 114$ preorders 1 partition of 1 + 1 + 1 + 1, giving 219 preorders I.e., together, 355 preorders.

## Interval {#Interval}

For $a \lesssim b,$ the [interval](wikipedia://en/49172) $[a, b]$ is the set of points *x* satisfying $a \lesssim x$ and $x \lesssim b,$ also written $a \lesssim x \lesssim b.$ It contains at least the points *a* and *b*. One may choose to extend the definition to all pairs $(a, b)$. The extra intervals are all empty.

Using the corresponding strict relation "$<$", one can also define the interval $(a, b)$ as the set of points *x* satisfying $a < x$ and $x < b,$ also written $a < x < b.$ An open interval may be empty even if $a < b.$

Also $[a, b)$ and $(a, b]$ can be defined similarly.
