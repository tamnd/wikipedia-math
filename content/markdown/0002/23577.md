# Partial function

::: {#o1 .subject cue=lead name="Partial function"}

In [mathematics](wikipedia://en/18831), a **partial function** $f$ from a [set](wikipedia://en/26691) $X$ to a set $Y$ is a [function](wikipedia://en/185427) from a [subset](wikipedia://en/27631) $S$ of $X$ (possibly the whole $X$ itself) to $Y$. The subset $S$, that is, the *[domain](wikipedia://en/50263)* of $f$ viewed as a function, is called the **domain of definition** or **natural domain** of $f$. If $S$ equals $X$, that is, if $f$ is defined on every element in $X$, then $f$ is said to be a **total function**.

:::

In other words, a partial function is a [binary relation](wikipedia://en/3931) over two [sets](wikipedia://en/26691) that associates to every element of the first set *at most* one element of the second set; it is thus a [univalent relation](https://en.wikipedia.org/wiki/Univalent_relation). This generalizes the concept of a (total) [function](wikipedia://en/185427) by not requiring *every* element of the first set to be associated to an element of the second set.

A partial function is often used when its exact domain of definition is not known, or is difficult to specify. However, even when the exact domain of definition is known, partial functions are often used for simplicity or brevity. This is the case in [calculus](wikipedia://en/5176), where, for example, the [quotient](wikipedia://en/332640) of two functions is a partial function whose domain of definition cannot contain the [zeros](wikipedia://en/264210) of the denominator; in this context, a partial function is generally simply called a function.

In [computability theory](wikipedia://en/155414), a [general recursive function](wikipedia://en/26469) is a partial function from the integers to the integers; no [algorithm](wikipedia://en/775) can exist for deciding whether an arbitrary such function is in fact total.

When [arrow notation](wikipedia://en/185427#Arrow_notation) is used for functions, a partial function $f$ from $X$ to $Y$ is sometimes written as $f : X \rightharpoonup Y,$ $f : X \nrightarrow Y,$ or $f : X \hookrightarrow Y.$ However, there is no general convention, and the latter notation is more commonly used for [inclusion maps](wikipedia://en/492516) or [embeddings](wikipedia://en/52119).

Specifically, for a partial function $f : X \rightharpoonup Y,$ and any $x \in X,$ one has either:

- $f(x) = y \in Y$ (it is a single element in $Y$), or
- $f(x)$ is undefined.

For example, if $f$ is the [square root](wikipedia://en/29208) function restricted to the [integers](wikipedia://en/14563)

$$f : \mathbb{Z} \to \mathbb{N},$$

defined by: $f(n) = m$ if, and only if, $m^2 = n,$ $m \in \mathbb{N}, n \in \mathbb{Z},$

then $f(n)$ is only defined if $n$ is a [perfect square](wikipedia://en/213919) (that is, $0, 1, 4, 9, 16, \ldots$). So $f(25) = 5$ but $f(26)$ is undefined.

## Basic concepts {#Basic_concepts}

A partial function arises from the consideration of maps between two sets $X$ and $Y$ that may not be defined on the entire set $X$.[^o3] A common example is the square root operation on the real numbers $\mathbb{R}$: because negative real numbers do not have real square roots, the operation can be viewed as a partial function from $\mathbb{R}$ to $\mathbb{R}.$ The *domain of definition* of a partial function is the subset $S$ of $X$ on which the partial function is defined; in this case, the partial function may also be viewed as a function from $S$ to $Y$. In the example of the square root operation, the set $S$ consists of the nonnegative real numbers $[0, +\infty).$

The notion of partial function is particularly convenient when the exact domain of definition is unknown or even unknowable. For a computer-science example of the latter, see *[Halting problem](wikipedia://en/21391870)*.

In case the domain of definition $S$ is equal to the whole set $X$, the partial function is said to be *total*. Thus, total partial functions from $X$ to $Y$ coincide with functions from $X$ to $Y$.

Many properties of functions can be extended in an appropriate sense of partial functions. A partial function is said to be [injective](wikipedia://en/45196), [surjective](wikipedia://en/27873), or [bijective](wikipedia://en/3942) when the function given by the restriction of the partial function to its domain of definition is injective, surjective, or bijective, respectively.

Because a function is trivially surjective when restricted to its image, the term [partial bijection](https://en.wikipedia.org/wiki/Partial_bijection) denotes a partial function which is injective.[^o4]

An injective partial function may be inverted to an injective partial function, and a partial function which is both injective and surjective has an injective function as inverse. Furthermore, a function which is injective may be inverted to a bijective partial function.

The notion of [transformation](wikipedia://en/1904373) can be generalized to partial functions as well. A **partial transformation** is a function $f : A \rightharpoonup B,$ where both $A$ and $B$ are [subsets](wikipedia://en/27631) of some set $X.$[^o4]

## Function spaces {#Function_spaces}

For convenience, denote the set of all partial functions $f : X \rightharpoonup Y$ from a set $X$ to a set $Y$ by $[X \rightharpoonup Y].$ This set is the union of the sets of functions defined on subsets of $X$ with same codomain $Y$:

$$[X \rightharpoonup Y] = \bigcup_{D \subseteq X} [D \to Y],$$

the latter also written as $\bigcup_{D\subseteq{X}} Y^D.$ In finite case, its cardinality is

$$|[X \rightharpoonup Y]| = (|Y| + 1)^{|X|},$$

because any partial function can be extended to a function by any fixed value $c$ not contained in $Y,$ so that the codomain is $Y \cup \{ c \},$ an operation which is injective (unique and invertible by restriction).

:::

## Discussion and examples {#Discussion_and_examples}

The first diagram at the top of the article represents a partial function that is not a function since the element 1 in the left-hand set is not associated with anything in the right-hand set. Whereas, the second diagram represents a function since every element on the left-hand set is associated with exactly one element in the right hand set.

### Natural logarithm {#Natural_logarithm}

The [natural logarithm](wikipedia://en/21476) function mapping the [real numbers](wikipedia://en/20646438) to themselves is a partial function, but not a (total) function, since it is undefined for non-positive real inputs. If the domain is restricted to only include the [positive reals](https://en.wikipedia.org/wiki/Positive_reals) (that is, if the natural logarithm function is viewed as a function from the positive reals to the reals), then the natural logarithm is a function.

### Subtraction of natural numbers {#Subtraction_of_natural_numbers}

Subtraction of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) (in which $\mathbb{N}$ is the non-negative [integers](https://en.wikipedia.org/wiki/Integers)) is a partial function:

$$f : \mathbb{N} \times \mathbb{N} \rightharpoonup \mathbb{N}$$

$$f(x,y) = x - y.$$

It is defined only when $x \geq y.$

### Bottom element {#Bottom_element}

In [denotational semantics](wikipedia://en/55275) a partial function is considered as returning the [bottom element](https://en.wikipedia.org/wiki/Bottom_element) when it is undefined.

In [computer science](https://en.wikipedia.org/wiki/Computer_science) a partial function corresponds to a subroutine that raises an exception or loops forever. The [IEEE floating point](https://en.wikipedia.org/wiki/IEEE_floating_point) standard defines a [not-a-number](https://en.wikipedia.org/wiki/Not-a-number) value which is returned when a floating point operation is undefined and exceptions are suppressed, e.g. when the square root of a negative number is requested.

In a [programming language](wikipedia://en/23015) where function parameters are [statically typed](https://en.wikipedia.org/wiki/Statically_typed), a function may be defined as a partial function because the language's [type system](wikipedia://en/199701) cannot express the exact domain of the function, so the programmer instead gives it the smallest domain which is expressible as a type and contains the domain of definition of the function.

### In category theory {#In_category_theory}

In [category theory](wikipedia://en/5869), when considering the operation of [morphism](wikipedia://en/27716891) composition in [concrete categories](https://en.wikipedia.org/wiki/Concrete_categories), the composition operation $\circ \;:\; \hom(C) \times \hom(C) \to \hom(C)$ is a total function if and only if $\operatorname{ob}(C)$ has one element. The reason for this is that two morphisms $f : X \to Y$ and $g : U \to V$ can only be composed as $g \circ f$ if $Y = U,$ that is, the codomain of $f$ must equal the domain of $g.$

The category of sets and partial functions is [equivalent](wikipedia://en/379051) to but not [isomorphic](wikipedia://en/489935) with the category of [pointed sets](wikipedia://en/1242444) and point-preserving maps.[^o12] One textbook notes that "This formal completion of sets and partial maps by adding “improper,” “infinite” elements was reinvented many times, in particular, in topology ([one-point compactification](https://en.wikipedia.org/wiki/One-point_compactification)) and in [theoretical computer science](wikipedia://en/323392)."[^o13]

The category of sets and partial bijections is equivalent to its [dual](wikipedia://en/372399).[^o14] It is the prototypical [inverse category](https://en.wikipedia.org/wiki/Inverse_category).[^o15]

### In abstract algebra {#In_abstract_algebra}

[Partial algebra](wikipedia://en/43662761) generalizes the notion of [universal algebra](wikipedia://en/45200) to partial [operations](wikipedia://en/4140245). An example would be a [field](wikipedia://en/10603), in which the multiplicative inversion is the only proper partial operation (because [division by zero](wikipedia://en/185663) is not defined).[^o17]

The set of all partial functions (partial [transformations](wikipedia://en/1904373)) on a given base set, $X,$ forms a [regular semigroup](wikipedia://en/6797677) called the semigroup of all partial transformations (or the partial transformation semigroup on $X$), typically denoted by $\mathcal{PT}_X.$[^o18][^o19][^o20] The set of all partial bijections on $X$ forms the [symmetric inverse semigroup](wikipedia://en/18442482).[^o18][^o19]

### Charts and atlases for manifolds and fiber bundles {#Charts_and_atlases_for_manifolds_and_fiber_bundles}

Charts in the [atlases](wikipedia://en/47436) which specify the structure of [manifolds](wikipedia://en/2073470) and [fiber bundles](wikipedia://en/276526) are partial functions. In the case of manifolds, the domain is the point set of the manifold. In the case of fiber bundles, the domain is the space of the fiber bundle. In these applications, the most important construction is the [transition map](wikipedia://en/47436#Transition_maps), which is the composite of one chart with the inverse of another. The initial classification of manifolds and fiber bundles is largely expressed in terms of constraints on these transition maps.

The reason for the use of partial functions instead of functions is to permit general global topologies to be represented by stitching together local patches to describe the global structure. The "patches" are the domains where the charts are defined.
