# Power associativity

::: {#o1 .subject cue=lead name="Power associativity"}

In [mathematics](wikipedia://en/18831), specifically in [abstract algebra](wikipedia://en/19616384), **power associativity** is the property of a [binary operation](wikipedia://en/3948) that [integer powers](wikipedia://en/99491#Integer_powers_in_algebra) ($x^n$) are well-defined; it implies that $x^m * x^n = x^{m+n}$ for all positive integers $m, n$. It is a weak form of [associativity](https://en.wikipedia.org/wiki/Associativity).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An [algebra](wikipedia://en/191788) (or more generally a [magma](wikipedia://en/141916)) is power-associative if the [subalgebra](wikipedia://en/45239) generated by any element is associative. So any product of $n$ instances of an element $x$ has the same value, denoted $x^n$, regardless of parenthesization. For example, $x*(x*(x*x))=\,$$x*((x*x)*x)=\,$$(x*x)*(x*x)=\,$$(x*(x*x))*x=\,$$((x*x)*x)*x=\,$$(x*x)^2 =\,$$x^4$.

:::

## Examples and properties {#Examples_and_properties}

Every [associative algebra](wikipedia://en/2112) is power-associative, but so are all other [alternative algebras](wikipedia://en/3160) (like the [octonions](wikipedia://en/51436), which are non-associative) and even non-alternative [flexible algebras](wikipedia://en/36035264) like the [sedenions](wikipedia://en/51434), [trigintaduonions](wikipedia://en/25474499), and [Okubo algebras](wikipedia://en/39255698). Any [Jordan algebra](wikipedia://en/936371) is power-associative. Any algebra whose elements are [idempotent](https://en.wikipedia.org/wiki/Idempotent) is also power-associative.

[Exponentiation](wikipedia://en/99491) to the power of any [positive integer](https://en.wikipedia.org/wiki/Positive_integer) can be defined consistently whenever multiplication is power-associative. For example, there is no need to distinguish whether *x*<sup>3</sup> should be defined as (*xx*)*x* or as *x*(*xx*), since these are equal. Exponentiation to the power of zero can also be defined if the operation has an [identity element](wikipedia://en/14962), so the existence of identity elements is useful in power-associative contexts.

Over a [field](wikipedia://en/10603) of [characteristic](wikipedia://en/1066621) 0, an algebra is power-associative if and only if it satisfies $[x,x,x]=0$ and $[x^2,x,x]=0$, where $[x,y,z]:=(xy)z-x(yz)$ is the [associator](wikipedia://en/943321) (Albert 1948).

Over an infinite field of [prime](wikipedia://en/23666) characteristic $p>0$ there is no finite set of identities that characterizes power-associativity, but there are infinite independent sets, as described by Gainov (1970):

- For $p=2$: $[x,x^2,x]=0$ and $[x^{n-2},x,x]=0$ for $n=3,2^k$ ($k=2,3...)$
- For $p=3$: $[x^{n-2},x,x]=0$ for $n=4,5,3^k$ ($k=1,2...)$
- For $p=5$: $[x^{n-2},x,x]=0$ for $n=3,4,6,5^k$ ($k=1,2...)$
- For $p>5$: $[x^{n-2},x,x]=0$ for $n=3,4,p^k$ ($k=1,2...)$

A substitution law holds for [real](wikipedia://en/20646438) power-associative algebras with unit, which basically asserts that multiplication of [polynomials](wikipedia://en/23000) works as expected. For *f* a real polynomial in *x*, and for any *a* in such an algebra define *f*(*a*) to be the element of the algebra resulting from the obvious substitution of *a* into *f*. Then for any two such polynomials *f* and *g*, we have that (*fg*)(*a*) = *f*(*a*)*g*(*a*).
