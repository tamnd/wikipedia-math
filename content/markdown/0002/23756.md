# Presburger arithmetic

::: {#o1 .subject cue=lead name="Presburger arithmetic"}

**Presburger arithmetic** is the [first-order theory](https://en.wikipedia.org/wiki/First-order_predicate_calculus) of the [natural numbers](wikipedia://en/21474) with [addition](wikipedia://en/61338), named in honor of [Mojżesz Presburger](wikipedia://en/3968176), who introduced it in 1929. The [signature](https://en.wikipedia.org/wiki/Signature_%28mathematical_logic%29) of Presburger arithmetic contains only the addition operation and [equality](wikipedia://en/90446), omitting the [multiplication](wikipedia://en/20845) operation entirely. The theory is [computably](wikipedia://en/332264) axiomatizable; the axioms include a schema of [induction](wikipedia://en/18881).

:::

Presburger arithmetic is much weaker than [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), which includes both addition and multiplication operations. Unlike Peano arithmetic, Presburger arithmetic is a [decidable theory](wikipedia://en/913118). This means it is possible to algorithmically determine, for any sentence in the language of Presburger arithmetic, whether that sentence is provable from the axioms of Presburger arithmetic. The asymptotic running-time [computational complexity](wikipedia://en/2230) of this algorithm is at least [doubly exponential](wikipedia://en/8541166), however, as shown by (Fischer Rabin 1974).

## Overview {#Overview}

The language of Presburger arithmetic contains constants $0$ and $1$ and a binary function $+$, interpreted as addition.

In this language, the axioms of Presburger arithmetic are the [universal closures](https://en.wikipedia.org/wiki/Universal_closure) of the following:[^n1]

1. $\neg(0 = x + 1)$[^o5]
1. $$x + 1 = y + 1 \to x = y$$
1. $$x + 0 = x$$
1. $$x + (y + 1) = (x + y) + 1$$
1. Let $P(x)$ be a [first-order formula](https://en.wikipedia.org/wiki/First-order_formula) in the language of Presburger arithmetic with a free variable $x$ (and possibly other free variables). Then the following formula is an axiom:

$$(P(0) \land \forall x(P(x) \to P(x+1))) \to \forall y\, P(y).$$

(5) is an [axiom schema](wikipedia://en/764613) of [induction](https://en.wikipedia.org/wiki/Mathematical_Induction), representing infinitely many axioms. These cannot be replaced by any finite number of axioms, that is, Presburger arithmetic is not finitely axiomatizable in first-order logic.[^n2]

Presburger arithmetic can be viewed as a [first-order theory](wikipedia://en/10983#First-order_theories,_models,_and_elementary_classes) with equality containing precisely all consequences of the above axioms. Alternatively, it can be defined as the set of those sentences that are true in the [intended interpretation](wikipedia://en/14511671#Intended_interpretations): the structure of non-negative integers with constants $0$, $1$, and the addition of non-negative integers.

Presburger arithmetic is designed to be complete and decidable. Therefore, it cannot formalize concepts such as [divisibility](https://en.wikipedia.org/wiki/Divisibility) or [primality](https://en.wikipedia.org/wiki/Primality), or, more generally, any number concept leading to multiplication of variables. However, it can formulate individual instances of divisibility; for example, it proves $\forall x\, \exists y\; ((y + y = x) \lor (y + y + 1 = x)).$ This states that every number is either even or odd.

## Properties {#Properties}

(Presburger 1929) proved Presburger arithmetic to be:

- [consistent](https://en.wikipedia.org/wiki/Consistency_proof): There is no statement in Presburger arithmetic that can be deduced from the axioms such that its negation can also be deduced.
- [complete](wikipedia://en/31271451): For each statement in the language of Presburger arithmetic, either it is possible to deduce it from the axioms or it is possible to deduce its negation.
- [decidable](wikipedia://en/913118): There exists an [algorithm](wikipedia://en/775) that decides whether any given statement in Presburger arithmetic is a theorem or a nontheorem - note that a "nontheorem" is a formula that cannot be proved, not in general necessarily one whose negation can be proved, but in the case of a complete theory like here the two definitions are equivalent.

The decidability of Presburger arithmetic can be shown using [quantifier elimination](wikipedia://en/2150441), supplemented by reasoning about [arithmetical congruence](wikipedia://en/20087).[^n3][^n4][^n5][^n6][^n7][^n8] The steps used to justify a quantifier elimination algorithm can be used to define computable axiomatizations that do not necessarily contain the axiom schema of induction.[^n3][^n9]

In contrast, [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), which is Presburger arithmetic augmented with multiplication, is not decidable, as proved by Church alongside the negative answer to the [Entscheidungsproblem](wikipedia://en/9672). By [Gödel's incompleteness theorem](https://en.wikipedia.org/wiki/Gödel's_incompleteness_theorem), Peano arithmetic is incomplete and its consistency is not internally provable (but see [Gentzen's consistency proof](wikipedia://en/4076831)).

### Computational complexity {#Computational_complexity}

The decision problem for Presburger arithmetic is an interesting example in [computational complexity theory](wikipedia://en/7543) and [computation](wikipedia://en/5926). Let *n* be the length of a statement in Presburger arithmetic. Then (Fischer Rabin 1974) proved that, in the worst case, the proof of the statement in first-order logic has length at least $2^{2^{cn}}$, for some constant *c*>0. Hence, their decision algorithm for Presburger arithmetic has runtime at least exponential. Fischer and Rabin also proved that for any reasonable axiomatization (defined precisely in their paper), there exist theorems of length *n* that have [doubly exponential](wikipedia://en/8541166) length proofs. Fischer and Rabin's work also implies that Presburger arithmetic can be used to define formulas that correctly calculate any algorithm as long as the inputs are less than relatively large bounds. The bounds can be increased, but only by using new formulas.

Recent work has also considered functional synthesis problems over Presburger arithmetic, including the identification of restricted fragments with more efficient solution procedures.[^n10]

On the other hand, a triply exponential upper bound on a decision procedure for Presburger arithmetic was proved by Oppen.[^n11]

A more tight complexity bound was shown using alternating complexity classes by (Berman 1980). The set of true statements in Presburger arithmetic (PA) is shown complete for [TimeAlternations](https://en.wikipedia.org/wiki/Alternating_Turing_machine)(2<sup>2<sup>n<sup>O(1)</sup></sup></sup>, n). Thus, its complexity is between double exponential nondeterministic time (2-NEXP) and double exponential space (2-EXPSPACE). Completeness is under [Karp reductions](https://en.wikipedia.org/wiki/Karp_reduction). (Also, note that while Presburger arithmetic is commonly abbreviated PA, in mathematics in general PA usually means [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic).)

For a more fine-grained result, let PA(i) be the set of true Σ<sub>i</sub> PA statements, and PA(i, j) the set of true Σ<sub>i</sub> PA statements with each quantifier block limited to j variables. '\<' is considered to be quantifier-free; here, bounded quantifiers are counted as quantifiers. PA(1, j) is in P, while PA(1) is NP-complete.[^n12] For i > 0 and j > 2, PA(i + 1, j) is [Σ<sub>i</sub><sup>P</sup>-complete](wikipedia://en/658651). The hardness result only needs j>2 (as opposed to j=1) in the last quantifier block. For i>0, PA(i+1) is [Σ<sub>i</sub><sup>EXP</sup>-complete](wikipedia://en/665091).[^n13]

Short $\Sigma_n$ Presburger Arithmetic ($n>2$) is $\Sigma_{n-2}^P$ complete (and thus NP complete for $n=3$). Here, 'short' requires bounded (i.e. $O(1)$) sentence size except that integer constants are unbounded (but their number of bits in binary counts against input size). Also, $\Sigma_2$ two variable PA (without the restriction of being 'short') is NP-complete.[^n14] Short $\Pi_2$ (and thus $\Sigma_2$) PA is in P, and this extends to fixed-dimensional parametric integer linear programming.[^n15]

## Applications {#Applications}

Because Presburger arithmetic is decidable, [automatic theorem provers](https://en.wikipedia.org/wiki/Automatic_theorem_prover) for Presburger arithmetic exist. For example, the [Rocq](wikipedia://en/581974) and [Lean](wikipedia://en/62889984) proof assistant systems feature the tactic *omega* for Presburger arithmetic and the [Isabelle proof assistant](wikipedia://en/161886) contains a verified quantifier elimination procedure by (Nipkow 2010). The double exponential complexity of the theory makes it infeasible to use the theorem provers on complicated formulas, but this behavior occurs only in the presence of nested quantifiers: (Nelson Oppen 1978) describe an automatic theorem prover that uses the [simplex algorithm](wikipedia://en/349458) on an extended Presburger arithmetic without nested quantifiers to prove some of the instances of quantifier-free Presburger arithmetic formulas. More recent [satisfiability modulo theories](https://en.wikipedia.org/wiki/Satisfiability_modulo_theories) solvers use complete [integer programming](wikipedia://en/411215) techniques to handle quantifier-free fragment of Presburger arithmetic theory.[^n16]

Presburger arithmetic can express multiplication by constants, as an abbreviation for iterated addition:

$$cx = \underbrace{x + x + \cdots + x}_{c\text{ times}} .$$

Most array subscript calculations then fall within the region of decidable problems.[^o32] This approach is the basis of several proof-of-[correctness](https://en.wikipedia.org/wiki/Correctness_%28computer_science%29) systems for [computer programs](https://en.wikipedia.org/wiki/Computer_programs), beginning with the [Stanford Pascal Verifier](https://en.wikipedia.org/wiki/Stanford_Pascal_Verifier) in the late 1970s and continuing through to Microsoft's Spec# system of 2005. Languages influenced include [Rocq](wikipedia://en/581974) and [Lean (proof assistant)](wikipedia://en/62889984).

:::

## Presburger-definable integer relation {#Presburger-definable_integer_relation}

Some properties are now given about integer [relations](wikipedia://en/19509) definable in Presburger Arithmetic. For the sake of simplicity, all relations considered in this section are over non-negative integers.

A relation is Presburger-definable if and only if it is a [semilinear set](wikipedia://en/2628576).

A unary integer relation $R$, that is, a set of non-negative integers, is Presburger-definable if and only if it is ultimately periodic. That is, if there exists a threshold $t\in \mathbb{N}$ and a positive period $p\in\mathbb{N}^{>0}$ such that, for all integer $n$ such that $|n|\ge t$, $n\in R$ if and only if $n+p\in R$.

By the [Cobham–Semenov theorem](https://en.wikipedia.org/wiki/Cobham–Semenov_theorem), a relation is Presburger-definable if and only if it is definable in [Büchi arithmetic](wikipedia://en/36262566) of base $k$ for all $k\ge2$.[^n17][^n18] A relation definable in Büchi arithmetic of base $k$ and $k'$ for $k$ and $k'$ being [multiplicatively independent](wikipedia://en/50027042) integers is Presburger definable.

An integer relation $R$ is Presburger-definable if and only if all sets of integers that are definable in first-order logic with addition and $R$ (that is, Presburger arithmetic plus a predicate for $R$) are Presburger-definable.[^n19] Equivalently, for each relation $R$ that is not Presburger-definable, there exists a first-order formula with addition and $R$ that defines a set of integers that is not definable using only addition.

An integer function is Presburger-definable if and only if it is piecewise linear on a semilinear partition of its domain, with each linear piece having a periodic component.[^n20]

### Muchnik's characterization {#Muchnik's_characterization}

Presburger-definable relations admit another characterization: by Muchnik's theorem.[^n21] It is more complicated to state, but led to the proof of the two former characterizations. Before Muchnik's theorem can be stated, some additional definitions must be introduced.

Let $R\subseteq\mathbb{N}^d$ be a set, the section $x_i = j$ of $R$, for $i < d$ and $j \in \mathbb{N}$ is defined as

$$\left \{(x_0,\ldots,x_{i-1},x_{i+1},\ldots,x_{d-1})\in\mathbb{N}^{d-1}\mid(x_0,\ldots,x_{i-1},j,x_{i+1},\ldots,x_{d-1})\in R \right \}.$$

Given two sets $R,S\subseteq\mathbb{N}^d$ and a $d$-tuple of integers $(p_0,\ldots,p_{d-1})\in\mathbb{N}^d$, the set $R$ is called $(p_0,\dots,p_{d-1})$-periodic in $S$ if, for all $(x_0, \dots, x_{d-1}) \in S$ such that $(x_0+p_0,\dots,x_{d-1}+p_{d-1})\in S,$ then $(x_0,\ldots,x_{d-1})\in R$ if and only if $(x_0+p_0,\dots,x_{d-1}+p_{d-1})\in R$. For $s\in\mathbb{N}$, the set $R$ is said to be $s$-periodic in $S$ if it is $(p_0,\ldots,p_{d-1})$-periodic for some $(p_0,\dots,p_{d-1})\in\mathbb{Z}^d$ such that

$$\sum_{i=0}^{d-1}|p_i| < s.$$

Finally, for $k,x_0,\dots,x_{d-1}\in\mathbb{N}$ let

$$C(k,(x_0,\ldots,x_{d-1}))= \left \{(x_0+c_0,\dots,x_{d-1}+c_{d-1})\mid 0 \leq c_i < k \right \}$$

denote the cube of size $k$ whose lesser corner is $(x_0,\dots,x_{d-1})$.

::: {#o40 .statement kind=statement/theorem cue=math-theorem name="Muchnik's Theorem"}

**Muchnik's Theorem.**

$R\subseteq\mathbb{N}^d$ is Presburger-definable if and only if:

if $d > 1$ then all sections of $R$ are Presburger-definable and

there exists $s\in\mathbb{N}$ such that, for every $k\in\mathbb{N}$, there exists $t\in\mathbb{N}$ such that for all $(x_0,\dots,x_{d-1})\in\mathbb{N}^d$ with

$$\sum_{i=0}^{d-1}x_i>t,$$

$R$ is $s$-periodic in $C(k,(x_0,\dots,x_{d-1}))$.

:::

Intuitively, the integer $s$ represents the length of a shift, the integer $k$ is the size of the cubes and $t$ is the threshold before the periodicity. This result remains true when the condition

$$\sum_{i=0}^{d-1}x_i>t$$

is replaced either by $\min(x_0,\ldots,x_{d-1})>t$ or by $\max(x_0,\ldots,x_{d-1})>t$.

This characterization led to the so-called "definable criterion for definability in Presburger arithmetic", that is: there exists a first-order formula with addition and a $d$-ary predicate $R$ that holds if and only if $R$ is interpreted by a Presburger-definable relation. Muchnik's theorem also allows one to prove that it is decidable whether an [automatic sequence](wikipedia://en/7740302) accepts a Presburger-definable set.
