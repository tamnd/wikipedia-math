# Quartile

::: {#o1 .subject cue=lead name="Quartile"}

In [statistics](wikipedia://en/26685), **quartiles** are a type of [quantiles](wikipedia://en/25184) which divide the number of data points into four parts, or *quarters*, of more-or-less equal size. The data must be ordered from smallest to largest to compute quartiles; as such, quartiles are a form of [order statistic](wikipedia://en/160986). The three quartiles, resulting in four data divisions, are as follows:

*Image: Czech-wage-mode-median-mean-quantiles-percentiles.png.* Q1, Median and Q3[^o2]

:::

- The first quartile (*Q*<sub>1</sub>) is defined as the 25th [percentile](wikipedia://en/354907), where the lowest 25% data lies below this point. It is also known as the *lower* quartile.
- The second quartile (*Q*<sub>2</sub>) is the [median](wikipedia://en/18837) of a [data set](wikipedia://en/8495); thus 50% of the data lies below this point.
- The third quartile (*Q*<sub>3</sub>) is the 75th percentile, where the lowest 75% data lies below this point. It is also known as the *upper* quartile.[^o3]

Along with the minimum and maximum of the data (which are also quartiles), the three quartiles described above provide a [five-number summary](wikipedia://en/160963) of the data. This summary is important in statistics because it provides information about both the [center](https://en.wikipedia.org/wiki/Mean_%28Statistics%29) and the [spread](wikipedia://en/23773247) of the data. Knowing the lower and upper quartile provides information on how big the spread is and if the dataset is [skewed](wikipedia://en/28212) toward one side. Since quartiles divide the number of data points evenly, the [range](wikipedia://en/27588) is generally not the same between adjacent quartiles (i.e. usually (*Q*<sub>3</sub> - *Q*<sub>2</sub>) ≠ (*Q*<sub>2</sub> - *Q*<sub>1</sub>)). [Interquartile range](wikipedia://en/14812) (IQR) is defined as the difference between the 75th and 25th percentiles or *Q*<sub>3</sub> - *Q*<sub>1</sub>. While the maximum and minimum also show the spread of the data, the upper and lower quartiles can provide more detailed information on the location of specific data points, the presence of [outliers](wikipedia://en/160951) in the data, and the difference in spread between the middle 50% of the data and the outer data points.[^o4]

## Computing methods {#Computing_methods}

### Discrete distributions {#Discrete_distributions}

For discrete distributions, there is no universal agreement on selecting the quartile values.[^o10]

#### Method 1 {#Method_1}

1. Use the [median](wikipedia://en/18837) to divide the ordered data set into two halves. The median becomes the second quartile.
   - If there are an odd number of data points in the original ordered data set, **do not include** the median (the central value in the ordered list) in either half.
   - If there are an even number of data points in the original ordered data set, split this data set exactly in half.
1. The lower quartile value is the median of the lower half of the data. The upper quartile value is the median of the upper half of the data.

This rule is employed by the [TI-83](https://en.wikipedia.org/wiki/TI-83) calculator [boxplot](https://en.wikipedia.org/wiki/Boxplot) and "1-Var Stats" functions.

#### Method 2 {#Method_2}

1. Use the median to divide the ordered data set into two halves. The median becomes the second quartile.
   - If there are an odd number of data points in the original ordered data set, **include** the median (the central value in the ordered list) in both halves.
   - If there are an even number of data points in the original ordered data set, split this data set exactly in half.
1. The lower quartile value is the median of the lower half of the data. The upper quartile value is the median of the upper half of the data.

The values found by this method are also known as "[Tukey](wikipedia://en/415974)'s hinges";[^o13] see also [midhinge](wikipedia://en/12559595).

#### Method 3 {#Method_3}

1. Use the median to divide the ordered data set into two halves. The median becomes the second quartile.
   - If there are odd numbers of data points, then go to the next step.
   - If there are even numbers of data points, then the Method 3 starts off the same as the Method 1 or the Method 2 above and you can choose to include or not include the median as a new datapoint. If you choose to include the median as the new datapoint, then proceed to the step 2 or 3 below because you now have an odd number of datapoints. If you do not choose the median as the new data point, then continue the Method 1 or 2 where you have started.
1. If there are (4*n*+1) data points, then the lower quartile is 25% of the *n*th data value plus 75% of the (*n*+1)th data value; the upper quartile is 75% of the (3*n*+1)th data point plus 25% of the (3*n*+2)th data point.
1. If there are (4*n*+3) data points, then the lower quartile is 75% of the (*n*+1)th data value plus 25% of the (*n*+2)th data value; the upper quartile is 25% of the (3*n*+2)th data point plus 75% of the (3*n*+3)th data point.

#### Method 4 {#Method_4}

If we have an ordered dataset $x_1, x_2, ..., x_n$, then we can interpolate between data points to find the $p$th empirical [quantile](wikipedia://en/25184) if $x_i$ is in the $i/(n+1)$ quantile. If we denote the [integer](wikipedia://en/14563) part of a number $a$ by $\lfloor a \rfloor$, then the empirical quantile function is given by,

$$q(p/4) = x_{k} + \alpha(x_{k+1} - x_{k}),$$

$x_{k}$ is the last data point in quartile *p*, and $x_{k+1}$ is the first data point in quartile *p*+1.

$\alpha$ measures where the quartile falls between $x_{k}$ and $x_{k+1}$. If $\alpha$ = 0 then the quartile falls exactly on $x_{k}$. If $\alpha$ = 0.5 then the quartile falls exactly half way between $x_{k}$ and $x_{k+1}$.

$$q(p/4) = x_{k} + \alpha(x_{k+1} - x_{k}),$$

where $k = \lfloor p(n+1)/4 \rfloor$ and $\alpha = p(n+1)/4 - \lfloor p(n+1)/4 \rfloor$.[^o3]

To find the first, second, and third quartiles of the dataset we would evaluate $q(0.25)$, $q(0.5)$, and $q(0.75)$ respectively.

Another way to explain this method is that we are finding a rank within the data, which can then be used to determine the value of the first, second, or third quartile. The rank for the $p$th quartile is calculated using

rank $=p/4 * (n + 1)$.

The $p$th quartile is the value in the data set (when sorted from least to greatest) whose position equals the rank number. For example, a rank of 1 means the $p$th quartile is the smallest value in the data set. If the rank is not an integer, interpolate between the data points. So a rank of 1.5 means the $p$th quartile is the value halfway between the first and second data points.

#### Example 1 {#Example_1}

Ordered Data Set (of an odd number of data points): 6, 7, 15, 36, 39, **40**, 41, 42, 43, 47, 49.

The bold number (40) is the median splitting the data set into two halves with equal number of data points.

::: {#o17 .table cue=table}

|  | Method 1 | Method 2 | Method 3 | Method 4 |
|---|---|---|---|---|
| *Q*<sub>1</sub> | 15 | \25.5 | \20.25 | 15 |
| *Q*<sub>2</sub> | 40 | 40 | 40 | 40 |
| *Q*<sub>3</sub> | 43 | \42.5 | \42.75 | 43 |

:::

#### Example 2 {#Example_2}

Ordered Data Set (of an even number of data points): 7, 15, **36, 39**, 40, 41.

The bold numbers (36, 39) are used to calculate the median as their average. As there are an even number of data points, the first three methods all give the same results. (The Method 3 is executed such that the median is not chosen as a new data point and the Method 1 started.)

::: {#o19 .table cue=table}

|  | Method 1 | Method 2 | Method 3 | Method 4 |
|---|---|---|---|---|
| *Q*<sub>1</sub> | 15 | 15 | 15 | 13 |
| *Q*<sub>2</sub> | \37.5 | \37.5 | \37.5 | \37.5 |
| *Q*<sub>3</sub> | 40 | 40 | 40 | \40.25 |

:::

### Continuous probability distributions {#Continuous_probability_distributions}

*Image: NormalCDFQuartile3.svg.* Quartiles on a cumulative distribution function of a normal distribution

If we define a [continuous probability distributions](https://en.wikipedia.org/wiki/Continuous_probability_distribution) as $P(X)$ where $X$ is a [real valued](wikipedia://en/20646438) [random variable](wikipedia://en/25685), its [cumulative distribution function](wikipedia://en/5793) (CDF) is given by

$F_X(x) = P(X \leq x)$.[^o3]

The [CDF](wikipedia://en/5793) gives the probability that the random variable $X$ is less than or equal to the value $x$. Therefore, the first quartile is the value of $x$ when $F_X(x) = 0.25$, the second quartile is $x$ when $F_X(x) = 0.5$, and the third quartile is $x$ when $F_X(x) = 0.75$.[^o21] The values of $x$ can be found with the [quantile function](wikipedia://en/10167616) $Q(p)$ where $p = 0.25$ for the first quartile, $p = 0.5$ for the second quartile, and $p = 0.75$ for the third quartile. The quantile function is the inverse of the cumulative distribution function if the cumulative distribution function is [monotonically increasing](wikipedia://en/48260) because the [one-to-one correspondence](wikipedia://en/3942) between the input and output of the cumulative distribution function holds.

## Outliers {#Outliers}

There are methods by which to check for [outliers](https://en.wikipedia.org/wiki/Outliers) in the discipline of statistics and statistical analysis. Outliers could be a result from a shift in the location (mean) or in the scale (variability) of the process of interest.[^o23] Outliers could also be evidence of a sample population that has a non-normal distribution or of a contaminated population data set. Consequently, as is the basic idea of [descriptive statistics](wikipedia://en/8187), when encountering an [outlier](wikipedia://en/160951), we have to explain this value by further analysis of the cause or origin of the outlier. In cases of extreme observations, which are not an infrequent occurrence, the typical values must be analyzed. The [Interquartile Range](https://en.wikipedia.org/wiki/Interquartile_Range) (IQR), defined as the difference between the upper and lower quartiles ($Q_3 - Q_1$), may be used to characterize the data when there may be extremities that skew the data; the [interquartile range](wikipedia://en/14812) is a relatively [robust statistic](https://en.wikipedia.org/wiki/Robust_statistic) (also sometimes called "resistance") compared to the [range](wikipedia://en/27588) and [standard deviation](wikipedia://en/27590). There is also a mathematical method to check for outliers and determining "fences", upper and lower limits from which to check for outliers.

After determining the first (lower) and third (upper) quartiles ($Q_1$ and $Q_3$ respectively) and the interquartile range ($\textrm{IQR} = Q_3 - Q_1$) as outlined above, then fences are calculated using the following formula:

$$\text{Lower fence} = Q_1 - (1.5 \times \mathrm{IQR})$$

$$\text{Upper fence} = Q_3 + (1.5 \times \mathrm{IQR})$$

*Image: Boxplot outliers example.jpg.* Boxplot Diagram with Outliers

The lower fence is the "lower limit" and the upper fence is the "upper limit" of data, and any data lying outside these defined bounds can be considered an outlier. The fences provide a guideline by which to define an [outlier](wikipedia://en/160951), which may be defined in other ways. The fences define a "range" outside which an outlier exists; a way to picture this is a boundary of a fence. It is common for the lower and upper fences along with the outliers to be represented by a [boxplot](wikipedia://en/160960). For the boxplot shown on the right, only the vertical heights correspond to the visualized data set while horizontal width of the box is irrelevant. Outliers located outside the fences in a boxplot can be marked as any choice of symbol, such as an "x" or "o". The fences are sometimes also referred to as "whiskers" while the entire plot visual is called a "box-and-whisker" plot.

When spotting an outlier in the data set by calculating the interquartile ranges and boxplot features, it might be easy to mistakenly view it as evidence that the population is non-normal or that the sample is contaminated. However, this method should not take place of a [hypothesis test](https://en.wikipedia.org/wiki/Hypothesis_test) for determining normality of the population. The significance of the outliers varies depending on the sample size. If the sample is small, then it is more probable to get interquartile ranges that are unrepresentatively small, leading to narrower fences. Therefore, it would be more likely to find data that are marked as outliers.[^o24]

### Excel {#Excel}

The Excel function *QUARTILE.INC(array, quart)* provides the desired quartile value for a given array of data, using Method 3 from above. The *QUARTILE* function is a legacy function from Excel 2007 or earlier, giving the same output of the function *QUARTILE.INC*. In the function, *array* is the dataset of numbers that is being analyzed and *quart* is any of the following 5 values depending on which quartile is being calculated. [^o28]

::: {#o29 .table cue=table}

| Quart | Output QUARTILE Value |
|---|---|
| 0 | Minimum value |
| 1 | Lower Quartile (25th percentile) |
| 2 | Median |
| 3 | Upper Quartile (75th percentile) |
| 4 | Maximum value |

:::

### MATLAB {#MATLAB}

In order to calculate quartiles in [Matlab](wikipedia://en/20412), the function *quantile*(*A*,*p*) can be used. Where *A* is the vector of data being analyzed and *p* is the percentage that relates to the quartiles as stated below. [^o31]

::: {#o32 .table cue=table}

| p | Output QUARTILE Value |
|---|---|
| 0 | Minimum value |
| \0.25 | Lower Quartile (25th percentile) |
| \0.5 | Median |
| \0.75 | Upper Quartile (75th percentile) |
| 1 | Maximum value |

:::
