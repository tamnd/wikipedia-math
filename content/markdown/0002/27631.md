# Subset

*Image: Venn A subset B.svg.* [Euler diagram](wikipedia://en/2427526) showing *A* is a [subset](wikipedia://en/27631) of *B* (denoted $A \subseteq B$) and, conversely, *B* is a superset of *A* (denoted $B \supseteq A$)

::: {#o1 .subject cue=lead name="Subset"}

In mathematics, a [set](wikipedia://en/26691) *A* is a **subset** of a set *B* [if and only if](wikipedia://en/14922) all [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of *A* are also elements of *B*; *B* is then a **superset** of *A*. It is possible for *A* and *B* to be equal; if they are unequal, then *A* is a **proper subset** of *B*. The relationship of one set being a subset of another is called **inclusion** (or sometimes **containment**). *A* is a subset of *B* may also be expressed as *B* includes (or contains) *A* or *A* is included (or contained) in *B*. A ***k*-subset** is a subset with *k* elements.

:::

When quantified, $A \subseteq B$ is represented as $\forall x \left(x \in A \Rightarrow x \in B\right).$[^o2]

One can prove the statement $A \subseteq B$ by applying a proof technique known as the element argument[^o3]:

> Let sets *A* and *B* be given. To prove that $A \subseteq B,$
>
> **suppose** that *a* is a particular but arbitrarily chosen element of A
>
> **show** that *a* is an element of *B*.

The validity of this technique can be seen as a consequence of [universal generalization](wikipedia://en/939333): the technique shows $(c \in A) \Rightarrow (c \in B)$ for an arbitrarily chosen element *c*. Universal generalisation then implies $\forall x \left(x \in A \Rightarrow x \in B\right),$ which is equivalent to $A \subseteq B,$ as stated above.

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

If *A* and *B* are sets and every [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of *A* is also an element of *B*, then:

- *A* is a **subset** of *B*, denoted by $A \subseteq B$, or equivalently,
- *B* is a **superset** of *A*, denoted by $B \supseteq A.$

If *A* is a subset of *B*, but *A* is not [equal](https://en.wikipedia.org/wiki/Equal_%28math%29) to *B* (i.e. [there exists](https://en.wikipedia.org/wiki/There_exists) at least one element of B which is not an element of *A*), then:

- *A* is a **proper** (or **strict**) **subset** of *B*, denoted by $A \subsetneq B$, or equivalently,
- *B* is a **proper** (or **strict**) **superset** of *A*, denoted by $B \supsetneq A.$

The [empty set](wikipedia://en/9566), written $\{ \}$ or $\varnothing,$ has no elements, and therefore is [vacuously](wikipedia://en/51672) a subset of any set *X*.

:::

## Basic properties {#Basic_properties}

*Image: Subset with expansion.svg.* $A \subseteq B$ and $B \subseteq C$ implies $A \subseteq C.$

*Image: The\_11\_logical\_relations\_between\_two\_sets.svg.* Topological variety of proper subsets. While $A \subsetneq B$ is a single logical relation, it can be realized as a tangential or non-tangential containment, as shown in these 11 exhaustive cases.

- *[Reflexivity](wikipedia://en/200458)*: Given any set $A$, $A \subseteq A$[^o8]
- *[Transitivity](wikipedia://en/200463)*: If $A \subseteq B$ and $B \subseteq C$, then $A \subseteq C$
- *[Antisymmetry](wikipedia://en/1176)*: If $A \subseteq B$ and $B \subseteq A$, then $A = B$.

### Proper subset {#Proper_subset}

- *[Irreflexivity](wikipedia://en/200458)*: Given any set $A$, $A \subsetneq A$ is False.
- *[Transitivity](wikipedia://en/200463)*: If $A \subsetneq B$ and $B \subsetneq C$, then $A \subsetneq C$
- *[Asymmetry](wikipedia://en/1229368)*: If $A \subsetneq B$ then $B \subsetneq A$ is False.

:::

## ⊂ and ⊃ symbols {#⊂_and_⊃_symbols}

Some authors use the symbols $\subset$ and $\supset$ to indicate subset and superset respectively; that is, with the same meaning as and instead of the symbols $\subseteq$ and $\supseteq$.[^o12] For example, for these authors, it is true of every set *A* that $A \subset A.$ (a [reflexive relation](wikipedia://en/200458)).

Other authors prefer to use the symbols $\subset$ and $\supset$ to indicate proper (also called strict) subset and proper superset respectively; that is, with the same meaning as and instead of the symbols $\subsetneq$ and $\supsetneq.$[^o13] This usage makes $\subseteq$ and $\subset$ analogous to the [inequality](wikipedia://en/89489) symbols $\leq$ and $<.$ For example, if $x \leq y,$ then *x* may or may not equal *y*, but if $x < y,$ then *x* definitely does not equal *y*, and *is* less than *y* (an [irreflexive relation](https://en.wikipedia.org/wiki/Irreflexive_relation)). Similarly, using the convention that $\subset$ is proper subset, if $A \subseteq B,$ then *A* may or may not equal *B*, but if $A \subset B,$ then *A* definitely does not equal *B*.

:::

## Examples of subsets {#Examples_of_subsets}

*Image: PolygonsSet EN.svg.* The [regular polygons](wikipedia://en/333306) form a subset of the polygons.

- The set A = {1, 2} is a proper subset of B = {1, 2, 3}, thus both expressions $A \subseteq B$ and $A \subsetneq B$ are true.
- The set D = {1, 2, 3} is a subset (but not a proper subset) of E = {1, 2, 3}, thus $D \subseteq E$ is true, and $D \subsetneq E$ is not true (false).
- The set {*x*: *x* is a [prime number](wikipedia://en/23666) greater than 10} is a proper subset of {*x*: *x* is an odd number greater than 10}
- The set of [natural numbers](wikipedia://en/21474) is a proper subset of the set of [rational numbers](wikipedia://en/19727024); likewise, the set of points in a [line segment](wikipedia://en/22634860) is a proper subset of the set of points in a [line](https://en.wikipedia.org/wiki/Line_%28mathematics%29). These are two examples in which both the subset and the whole set are infinite, and the subset has the same [cardinality](wikipedia://en/6174#Infinite_sets) (the concept that corresponds to size, that is, the number of elements, of a finite set) as the whole; such cases can run counter to one's initial intuition.
- The set of [rational numbers](wikipedia://en/19727024) is a proper subset of the set of [real numbers](wikipedia://en/20646438). In this example, both sets are infinite, but the latter set has a larger cardinality (or power) than the former set.

## Power set {#Power_set}

The set of all subsets of $S$ is called its [power set](wikipedia://en/23799), and is denoted by $\mathcal{P}(S)$.[^o16]

The inclusion [relation](wikipedia://en/3931) $\subseteq$ is a [partial order](https://en.wikipedia.org/wiki/Partial_order) on the set $\mathcal{P}(S)$ defined by $A \leq B \iff A \subseteq B$. We may also partially order $\mathcal{P}(S)$ by reverse set inclusion by defining $A \leq B \text{ if and only if } B \subseteq A.$

For the power set $\operatorname{\mathcal{P}}(S)$ of a set *S*, the inclusion partial order is—up to an [order isomorphism](wikipedia://en/23916899)—the [Cartesian product](wikipedia://en/24104095) of $k = |S|$ (the [cardinality](wikipedia://en/6174) of *S*) copies of the partial order on $\{0, 1\}$ for which $0 < 1.$ This can be illustrated by enumerating $S = \left\{ s_1, s_2, \ldots, s_k \right\},$, and associating with each subset $T \subseteq S$ (i.e., each element of $2^S$) the *k*-tuple from $\{0, 1\}^k,$ of which the *i*th coordinate is 1 if and only if $s_i$ is a [member](https://en.wikipedia.org/wiki/Set_membership) of *T*.

The set of all $k$-subsets of $A$ is denoted by $\tbinom{A}{k}$, in analogue with the notation for [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficients), which count the number of $k$-subsets of an $n$-element set. In [set theory](wikipedia://en/27553), the notation $[A]^k$ is also common, especially when $k$ is a [transfinite](wikipedia://en/189734) [cardinal number](wikipedia://en/6173).

## Other properties of inclusion {#Other_properties_of_inclusion}

- A set *A* is a **subset** of *B* [if and only if](wikipedia://en/14922) their intersection is equal to A. Formally:

$$A \subseteq B \text{ if and only if } A \cap B = A.$$

- A set *A* is a **subset** of *B* if and only if their union is equal to B. Formally:

$$A \subseteq B \text{ if and only if } A \cup B = B.$$

- A **finite** set *A* is a **subset** of *B*, if and only if the [cardinality](wikipedia://en/6174) of their intersection is equal to the cardinality of A. Formally:

$$A \subseteq B \text{ if and only if } |A \cap B| = |A|.$$

- The subset relation defines a [partial order](https://en.wikipedia.org/wiki/Partial_order) on sets. In fact, the subsets of a given set form a [Boolean algebra](wikipedia://en/3959) under the subset relation, in which the [join and meet](wikipedia://en/3956618) are given by [intersection](wikipedia://en/23476429) and [union](wikipedia://en/47949), and the subset relation itself is the [Boolean inclusion relation](wikipedia://en/40153832).
- Inclusion is the canonical [partial order](https://en.wikipedia.org/wiki/Partial_order), in the sense that every partially ordered set $(X, \preceq)$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to some collection of sets ordered by inclusion. The [ordinal numbers](wikipedia://en/26547932) are a simple example: if each ordinal *n* is identified with the set $[n]$ of all ordinals less than or equal to *n*, then $a \leq b$ if and only if $[a] \subseteq [b].$
