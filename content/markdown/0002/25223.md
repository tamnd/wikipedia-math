# Quasigroup

*Image: Magma to group2.svg.* Algebraic structures between [magmas](wikipedia://en/141916) and [groups](wikipedia://en/19447): A *quasigroup* is a [magma](wikipedia://en/141916) with the type of [divisibility](wikipedia://en/53696#Abstract_algebra) given by the [Latin square property](wikipedia://en/25223#Algebra). A [loop](wikipedia://en/25223#Loops) is a *quasigroup* with an [identity element](wikipedia://en/14962).

::: {#o1 .subject cue=lead name="Quasigroup"}

In [mathematics](wikipedia://en/18831), especially in [abstract algebra](wikipedia://en/19616384), a **quasigroup** is an [algebraic structure](wikipedia://en/106364) that resembles a [group](wikipedia://en/19447) in the sense that "[division](wikipedia://en/53696)" is always possible. Quasigroups differ from groups mainly in that the [associative](https://en.wikipedia.org/wiki/Associative) and [identity element](wikipedia://en/14962) properties are optional. In fact, a [nonempty](wikipedia://en/9566) associative quasigroup is a group.[^o2][^o3]

:::

A quasigroup that has an identity element is called a **loop**.[^o4]

::: {#o6 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There are at least two structurally equivalent formal definitions of a quasigroup:

- One defines a quasigroup as a set with one [binary operation](wikipedia://en/3948).
- The other, from [universal algebra](wikipedia://en/45200), defines a quasigroup as having three primitive operations.

The [homomorphic](wikipedia://en/13564) [image](wikipedia://en/579311) of a quasigroup that is defined with a single binary operation, however, need not be a quasigroup, in contrast to a quasigroup as having three primitive operations.[^n1] We begin with the first definition.

::: {#o9 .pointer-item cue=pointer name="Latin square property"}

### Algebra {#Algebra}

A **quasigroup** $(Q, \ast)$ is a [set](wikipedia://en/26691) $Q$ with a binary operation $\ast$ (that is, a [magma](wikipedia://en/141916), indicating that a quasigroup has to satisfy the closure property), obeying the **Latin square property**. This states that, for each $a$ and $b$ in $Q$, there exist unique elements $x$ and $y$ in $Q$ such that both

$$a \ast x = b$$

$$y \ast a = b$$

hold. (In other words: Each element of the set occurs exactly once in each row and exactly once in each column of the quasigroup's multiplication table, or [Cayley table](wikipedia://en/1802723). This property ensures that the Cayley table of a finite quasigroup, and, in particular, a finite group, is a [Latin square](wikipedia://en/37447).) The requirement that $x$ and $y$ be unique can be replaced by the requirement that the magma be [cancellative](wikipedia://en/490646).[^n2]

The unique solutions to these equations are written $x = a \backslash b$ and $y = b / a$. The operations '$\backslash$' and '$/$' are called, respectively, [left division](https://en.wikipedia.org/wiki/Left_division) and [right division](https://en.wikipedia.org/wiki/Right_division). With regard to the Cayley table, the first equation (left division) means that the $b$ entry in the $a$ row is in the $x$ column while the second equation (right division) means that the $b$ entry in the $a$ column is in the $y$ row.

The [empty set](wikipedia://en/9566) equipped with the [empty binary operation](wikipedia://en/185427#Standard_functions) satisfies this definition of a quasigroup. Some authors accept the empty quasigroup, but others explicitly exclude it.[^n3][^n4]

:::

### Universal algebra {#Universal_algebra}

Given some [algebraic structure](wikipedia://en/106364), an [identity](https://en.wikipedia.org/wiki/Mathematical_identity) is an equation in which all variables are tacitly [universally quantified](https://en.wikipedia.org/wiki/Universal_quantifier), and in which all [operations](wikipedia://en/4140245) are among the primitive operations proper to the structure. Algebraic structures that satisfy axioms that are given solely by identities are called [varieties](wikipedia://en/1021753). Many standard results in [universal algebra](wikipedia://en/45200) hold only for varieties. Quasigroups form a variety if left and right division are taken as primitive.

A **right-quasigroup** $(Q, \ast, /)$ is a type (2, 2) algebra that satisfies the identities:

$$y = (y / x) \ast x$$

$$y = (y \ast x) / x$$

A **left-quasigroup** $(Q, \ast, \backslash)$ is a type (2, 2) algebra that satisfies the identities:

$$y = x \ast (x \backslash y)$$

$$y = x \backslash (x \ast y)$$

A **quasigroup** $(Q, \ast, \backslash, /)$ is a type (2, 2, 2) algebra (i.e., equipped with three binary operations) that satisfies the identities:

$$y = (y / x) \ast x$$

$$y = (y \ast x) / x$$

$$y = x \ast (x \backslash y)$$

$$y = x \backslash (x \ast y)$$

In other words: Multiplication and division in either order, one after the other, on the same side by the same element, have no net effect.

Hence if $(Q, \ast)$ is a quasigroup according to the definition of the previous section, then $(Q, \ast, \backslash, /)$ is the same quasigroup in the sense of universal algebra. And vice versa: if $(Q, \ast, \backslash, /)$ is a quasigroup according to the sense of universal algebra, then $(Q, \ast)$ is a quasigroup according to the first definition.

:::

## Loops {#Loops}

A **loop** is a quasigroup with an [identity element](wikipedia://en/14962); that is, an element, *e*, such that

*x* ∗ *e* = *x* and *e* ∗ *x* = *x* for all *x* in *Q*.

It follows that the identity element, *e*, is unique, and that every element of *Q* has unique [left](wikipedia://en/45199) and [right inverses](wikipedia://en/45199) (which need not be the same). Since the presence of an identity element is essential, a loop cannot be empty.

A quasigroup with an [idempotent element](https://en.wikipedia.org/wiki/Idempotent_element) is called a **pique** ("pointed idempotent quasigroup"); this is a weaker notion than a loop but common nonetheless because, for example, given an [abelian group](wikipedia://en/2974), (*A*, +), taking its subtraction operation as quasigroup multiplication yields a pique (*A*, −) with the group identity (zero) turned into a "pointed idempotent". (That is, there is a [principal isotopy](wikipedia://en/25223#Homotopy_and_isotopy) (*x*, *y*, *z*) ↦ (*x*, −*y*, *z*).)

A loop that is associative is a group. A group can have a strictly nonassociative pique isotope, but it cannot have a strictly nonassociative loop isotope.

There are weaker associativity properties that have been given special names.

For instance, a **[Bol loop](wikipedia://en/4741821)** is a loop that satisfies either:

*x* ∗ (*y* ∗ (*x* ∗ *z*)) = (*x* ∗ (*y* ∗ *x*)) ∗ *z* for each *x*, *y* and *z* in *Q* (a *left Bol loop*),

or else

((*z* ∗ *x*) ∗ *y*) ∗ *x* = *z* ∗ ((*x* ∗ *y*) ∗ *x*) for each *x*, *y* and *z* in *Q* (a *right Bol loop*).

A loop that is both a left and right Bol loop is a **[Moufang loop](wikipedia://en/755329)**. This is equivalent to any one of the following single Moufang identities holding for all *x*, *y*, *z*:

*x* ∗ (*y* ∗ (*x* ∗ *z*)) = ((*x* ∗ *y*) ∗ *x*) ∗ *z*

*z* ∗ (*x* ∗ (*y* ∗ *x*)) = ((*z* ∗ *x*) ∗ *y*) ∗ *x*

(*x* ∗ *y*) ∗ (*z* ∗ *x*) = *x* ∗ ((*y* ∗ *z*) ∗ *x*)

(*x* ∗ *y*) ∗ (*z* ∗ *x*) = (*x* ∗ (*y* ∗ *z*)) ∗ *x*.

According to Jonathan D. H. Smith, "loops" were named after the [Chicago Loop](https://en.wikipedia.org/wiki/Chicago_Loop), as their originators were studying quasigroups in Chicago at the time.[^o16]

:::

## Symmetries {#Symmetries}

(Smith 2007) names the following important properties and subclasses:

### Semisymmetry {#Semisymmetry}

A quasigroup is **semisymmetric** if any of the following equivalent identities hold for all *x*, *y*:

$$x \ast y = y / x$$

$$y \ast x = x \backslash y$$

$$x = (y \ast x) \ast y$$

$$x = y \ast (x \ast y).$$

Although this class may seem special, every quasigroup *Q* induces a semisymmetric quasigroup *Q*Δ on the direct product cube *Q*<sup>3</sup> via the following operation:

$$(x_{1}, x_{2}, x_{3}) \cdot (y_{1}, y_{2}, y_{3}) = (y_{3} / x_{2}, y_{1} \backslash x_{3}, x_{1} \ast y_{2}) = (x_{2} // y_{3}, x_{3} \backslash\backslash y_{1}, x_{1} \ast y_{2}),$$

where "$//$" and "$\backslash\backslash$" are the conjugate division operations given by $y // x = x / y$ and $y \backslash\backslash x = x \backslash y$.

### Triality {#Triality}

A quasigroup may exhibit semisymmetric [triality](wikipedia://en/683109).[^o22]

### Total symmetry {#Total_symmetry}

A narrower class is a **totally symmetric quasigroup** (sometimes abbreviated **TS-quasigroup**) in which all conjugates coincide as one operation: $x \ast y = x / y = x \backslash y$. Another way to define (the same notion of) totally symmetric quasigroup is as a semisymmetric quasigroup that is commutative, i.e. $x \ast y = y \ast x$.

Idempotent total symmetric quasigroups are precisely (i.e. in a bijection with) [Steiner triples](wikipedia://en/28016), so such a quasigroup is also called a **Steiner quasigroup**, and sometimes the latter is even abbreviated as **squag**. The term **sloop** refers to an analogue for loops, namely, totally symmetric loops that satisfy $x \ast x = 1$ instead of $x \ast x = x$. Without idempotency, total symmetric quasigroups correspond to the geometric notion of [extended Steiner triple](https://en.wikipedia.org/wiki/Extended_Steiner_triple), also called Generalized Elliptic Cubic Curve (GECC).

### Total antisymmetry {#Total_antisymmetry}

A quasigroup (*Q*, ∗) is called **weakly totally anti-symmetric** if for all *c*, *x*, *y* ∈ *Q*, the following implication holds.[^n5]

(*c* ∗ *x*) ∗ *y* = (*c* ∗ *y*) ∗ *x* implies that *x* = *y*.

A quasigroup (*Q*, ∗) is called **totally anti-symmetric** if, in addition, for all *x*, *y* ∈ *Q*, the following implication holds:[^n5]

*x* ∗ *y* = *y* ∗ *x* implies that *x* = *y*.

This property is required, for example, in the [Damm algorithm](wikipedia://en/37957721).

## Examples {#Examples}

- Every [group](wikipedia://en/19447) is a loop, because *a* ∗ *x* = *b* [if and only if](wikipedia://en/14922) *x* = *a*<sup>−1</sup> ∗ *b*, and *y* ∗ *a* = *b* if and only if *y* = *b* ∗ *a*<sup>−1</sup>.
- The [integers](wikipedia://en/14563) **Z** (or the [rationals](https://en.wikipedia.org/wiki/Rational_numbers) **Q** or the [reals](wikipedia://en/20646438) **R**) with [subtraction](wikipedia://en/74141) (−) form a quasigroup. These quasigroups are not loops because there is no identity element (0 is a right identity because *a* − 0 = *a*, but not a left identity because, in general, 0 − *a* ≠ *a*).
- The nonzero rationals **Q**<sup>×</sup> (or the nonzero reals **R**<sup>×</sup>) with [division](wikipedia://en/53696) (÷) form a quasigroup.
- Any [vector space](wikipedia://en/32370) over a [field](wikipedia://en/10603) of [characteristic](wikipedia://en/1066621) not equal to 2 forms an [idempotent](https://en.wikipedia.org/wiki/Idempotent), [commutative](https://en.wikipedia.org/wiki/Commutative) quasigroup under the operation *x* ∗ *y* = (*x* + *y*) / 2.
- Every [Steiner triple system](wikipedia://en/28016) defines an [idempotent](https://en.wikipedia.org/wiki/Idempotent), [commutative](https://en.wikipedia.org/wiki/Commutative) quasigroup: *a* ∗ *b* is the third element of the triple containing *a* and *b*. These quasigroups also satisfy (*x* ∗ *y*) ∗ *y* = *x* for all *x* and *y* in the quasigroup. These quasigroups are known as *Steiner quasigroups*.[^n6]
- The set $\{\pm1, \pm i, \pm j, \pm k\}$ where ii = jj = kk = +1 and with all other products as in the [quaternion group](wikipedia://en/153130) forms a nonassociative loop of order 8. See [hyperbolic quaternions](wikipedia://en/1071730#Historical_review) for its application. (The hyperbolic quaternions themselves do *not* form a loop or quasigroup.)
- The nonzero [octonions](https://en.wikipedia.org/wiki/Octonions) form a nonassociative loop under multiplication. The octonions are a special type of loop known as a [Moufang loop](wikipedia://en/755329).
- An associative quasigroup is either empty or is a group, since if there is at least one element, the [invertibility](wikipedia://en/25223#Inverse_properties) of the quasigroup binary operation combined with associativity implies the existence of an identity element, which then implies the existence of inverse elements, thus satisfying all three requirements of a group.
- The following construction is due to [Hans Zassenhaus](wikipedia://en/1376825). On the underlying set of the four-dimensional [vector space](wikipedia://en/32370) **F**<sup>4</sup> over the 3-element [Galois field](https://en.wikipedia.org/wiki/Galois_field) **F** = **Z**/3**Z** define

(*x*<sub>1</sub>, *x*<sub>2</sub>, *x*<sub>3</sub>, *x*<sub>4</sub>) ∗ (*y*<sub>1</sub>, *y*<sub>2</sub>, *y*<sub>3</sub>, *y*<sub>4</sub>) = (*x*<sub>1</sub>, *x*<sub>2</sub>, *x*<sub>3</sub>, *x*<sub>4</sub>) + (*y*<sub>1</sub>, *y*<sub>2</sub>, *y*<sub>3</sub>, *y*<sub>4</sub>) + (0, 0, 0, (*x*<sub>3</sub> − *y*<sub>3</sub>)(*x*<sub>1</sub>*y*<sub>2</sub> − *x*<sub>2</sub>*y*<sub>1</sub>)).

Then, (**F**<sup>4</sup>, ∗) is a [commutative](https://en.wikipedia.org/wiki/Commutative) [Moufang loop](wikipedia://en/755329) that is not a group.[^n7]

- More generally, the nonzero elements of any [division algebra](wikipedia://en/26549625) form a quasigroup with the operation of multiplication in the algebra.

:::

## Properties {#Properties}

In the remainder of the article we shall denote quasigroup [multiplication simply by juxtaposition](https://en.wikipedia.org/wiki/Multiplication_by_juxtaposition).

Quasigroups have the [cancellation property](wikipedia://en/490646): if $ab = ac$, then $b = c$. This follows from the uniqueness of left division of *ab* or *ac* by *a*. Similarly, if $ba = ca$, then $b = c$.

The Latin square property of quasigroups implies that, given any two of the three variables in $xy = z$, the third variable is uniquely determined.

### Multiplication operators {#Multiplication_operators}

The definition of a quasigroup can be treated as conditions on the left and right [multiplication operators](wikipedia://en/976642) $L_{x}, R_{x} : Q \to Q$, defined by

*L*<sub>*x*</sub>(*y*) = *xy*

*R*<sub>*x*</sub>(*y*) = *yx*

The definition says that both mappings are [bijections](wikipedia://en/3942) from *Q* to itself. A magma *Q* is a quasigroup precisely when all these operators, for every *x* in *Q*, are bijective. The inverse mappings are left and right division, that is,

$$L^{-1}_{x}(y) = x \backslash y$$

$$R^{-1}_{x}(y) = y / x$$

In this notation the identities among the quasigroup's multiplication and division operations (stated in the section on universal algebra) are

$$L_{x}L^{-1}_{x} = \operatorname{id} \ \operatorname{corresponding}\text{ to } \ x(x \backslash y) = y$$

$$L^{-1}_{x}L_{x} = \operatorname{id} \ \operatorname{corresponding}\text{ to } \ x \backslash (xy) = y$$

$$R_{x}R^{-1}_{x} = \operatorname{id} \ \operatorname{corresponding}\text{ to } \ (y / x)x = y$$

$$R^{-1}_{x}R_{x} = \operatorname{id} \ \operatorname{corresponding}\text{ to } \ (yx) / x = y$$

where $\operatorname{id}$ denotes the identity mapping on *Q*.

### Latin squares {#Latin_squares}

{| class="wikitable" style="text-align:center;font-weight:bold;width:275px;height:275px;outline:2px solid;" |+ A Latin square, the unbordered multiplication table for a quasigroup whose 10 elements are the digits 0–9. |0||4||8||2||3||9||6||7||1||5 |- |3||6||2||8||7||1||9||5||0||4 |- |8||9||3||1||0||6||4||2||5||7 |- |1||7||6||5||4||8||0||3||2||9 |- |2||1||9||0||6||7||5||8||4||3 |- |5||2||7||4||9||3||1||0||8||6 |- |4||3||0||6||1||5||2||9||7||8 |- |9||8||5||7||2||0||3||4||6||1 |- |7||0||1||9||5||4||8||6||3||2 |- |6||5||4||3||8||2||7||1||9||0 |}

The multiplication table of a finite quasigroup is a [Latin square](wikipedia://en/37447): an $n \times n$ table filled with *n* different symbols in such a way that each symbol occurs exactly once in each row and exactly once in each column.

Conversely, every Latin square can be taken as the multiplication table of a quasigroup in many ways: the border row (containing the column headers) and the border column (containing the row headers) can each be any permutation of the elements. See *[Small Latin squares and quasigroups](wikipedia://en/3224083)*.

#### Infinite quasigroups {#Infinite_quasigroups}

For a [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) quasigroup *Q*, it is possible to imagine an infinite array in which every row and every column corresponds to some element *q* of *Q*, and where the element $a \ast b$ is in the row corresponding to *a* and the column responding to *b*. In this situation too, the Latin square property says that each row and each column of the infinite array will contain every possible value precisely once.

For an [uncountably infinite](https://en.wikipedia.org/wiki/Uncountably_infinite) quasigroup, such as the group of non-zero [real numbers](wikipedia://en/20646438) under multiplication, the Latin square property still holds, although the name is somewhat unsatisfactory, as it is not possible to produce the array of combinations to which the above idea of an infinite array extends since the real numbers cannot all be written in a [sequence](wikipedia://en/27838). (This is somewhat misleading however, as the reals can be written in a sequence of length $\mathfrak{c}$, assuming the [well-ordering theorem](wikipedia://en/33458).)

### Inverse properties {#Inverse_properties}

The binary operation of a quasigroup is **invertible** in the sense that both *L*<sub>*x*</sub> and *R*<sub>*x*</sub>, the [left and right multiplication operators](wikipedia://en/25223#Multiplication_operators), are bijective, and hence [invertible](https://en.wikipedia.org/wiki/Invertible_function).

Every loop element has a unique left and right inverse given by

$$x^{\lambda} = e / x \ x^{\lambda}x = e$$

$$x^{\rho} = x \backslash e \ xx^{\rho} = e$$

A loop is said to have (*two-sided*) *inverses* if $x^{\lambda} = x^{\rho}$ for all *x*. In this case the inverse element is usually denoted by *x*<sup>−1</sup>.

There are some stronger notions of inverses in loops that are often useful:

- A loop has the *left inverse property* if $x^{\lambda}(xy) = y$ for all *x* and *y*. Equivalently, $L^{-1}_{x} = L_{x^{\lambda}}$ or $x \backslash y = x^{\lambda}y$.
- A loop has the *right inverse property* if $(yx)x^{\rho} = y$ for all *x* and *y*. Equivalently, $R^{-1}_{x} = R_{x^{\rho}}$ or $y / x = yx^{\rho}$.
- A loop has the *antiautomorphic inverse property* if $(xy)^{\lambda} = y^{\lambda}x^{\lambda}$ or, equivalently, if $(xy)^{\rho} = y^{\rho}x^{\rho}$.
- A loop has the *weak inverse property* when $(xy)z = e$ if and only if $x(yz) = e$. This may be stated in terms of inverses via $(xy)^{\lambda}x = y^{\lambda}$ or equivalently $x(yx)^{\rho} = y^{\rho}$.

A loop has the *inverse property* if it has both the left and right inverse properties. Inverse property loops also have the antiautomorphic and weak inverse properties. In fact, any loop that satisfies any two of the above four identities has the inverse property and therefore satisfies all four.

Any loop that satisfies the left, right, or antiautomorphic inverse properties automatically has two-sided inverses.

## Morphisms {#Morphisms}

A quasigroup or loop [homomorphism](wikipedia://en/13564) is a [map](wikipedia://en/516931) *f* : *Q* → *P* between two quasigroups such that *f*(*xy*) = *f*(*x*)*f*(*y*). Quasigroup homomorphisms necessarily preserve left and right division, as well as identity elements (if they exist).

### Homotopy and isotopy {#Homotopy_and_isotopy}

Let *Q* and *P* be quasigroups. A **quasigroup homotopy** from *Q* to *P* is a triple (*α*, *β*, *γ*) of maps from *Q* to *P* such that

*α*(*x*)*β*(*y*) = *γ*(*xy*)

for all *x*, *y* in *Q*. A quasigroup homomorphism is just a homotopy for which the three maps are equal.

An **isotopy** is a homotopy for which each of the three maps (*α*, *β*, *γ*) is a [bijection](wikipedia://en/3942). Two quasigroups are **isotopic** if there is an isotopy between them. In terms of Latin squares, an isotopy (*α*, *β*, *γ*) is given by a permutation of rows *α*, a permutation of columns *β*, and a permutation on the underlying element set *γ*.

An **autotopy** is an isotopy from a quasigroup to itself. The set of all autotopies of a quasigroup forms a group with the [automorphism group](wikipedia://en/56661772) as a subgroup.

Every quasigroup is isotopic to a loop. If a loop is isotopic to a group, then it is isomorphic to that group and thus is itself a group. However, a quasigroup that is isotopic to a group need not be a group. For example, the quasigroup on **R** with multiplication given by (*x*, *y*) ↦ (*x* + *y*)/2 is isotopic to the additive group (**R**, +), but is not itself a group as it has no identity element. Every [medial](wikipedia://en/502296) quasigroup is isotopic to an [abelian group](wikipedia://en/2974) by the [Bruck–Toyoda theorem](wikipedia://en/502296#Bruck–Murdoch–Toyoda_theorem).

### Conjugation (parastrophe) {#Conjugation_(parastrophe)}

Left and right division are examples of forming a quasigroup by permuting the variables in the defining equation. From the original operation ∗ (i.e., $x \ast y = z$) we can form five new operations: $x o y := y \ast x$ (the **opposite** operation), $/$ and $\backslash$, and their opposites. That makes a total of six quasigroup operations, which are called the **conjugates** or **parastrophes** of ∗. Any two of these operations are said to be "conjugate" or "parastrophic" to each other (and to themselves).

### Isostrophe (paratopy) {#Isostrophe_(paratopy)}

If the set *Q* has two quasigroup operations, ∗ and ·, and one of them is isotopic to a conjugate of the other, the operations are said to be **isostrophic** to each other. There are also many other names for this relation of "isostrophe", e.g., **paratopy**.

## Generalizations {#Generalizations}

::: {#o44 .pointer-item cue=pointer name="Multary quasigroup"}

### Polyadic or multiary quasigroups {#Polyadic_or_multiary_quasigroups}

An *n*-**ary quasigroup** is a set with an [*n*-ary operation](wikipedia://en/42301), $(Q, f)$ with $f : Q^{n} \to Q$, such that the equation $f(x_{1}, ..., x_{n}) = y$ has a unique solution for any one variable if all the other *n* variables are specified arbitrarily. **Polyadic** or **multiary** means *n*-ary for some nonnegative integer *n*.

A 0-ary, or **nullary**, quasigroup is just a constant element of *Q*. A 1-ary, or **unary**, quasigroup is a bijection of *Q* to itself. A **binary**, or 2-ary, quasigroup is an ordinary quasigroup.

An example of a multiary quasigroup is an iterated group operation, $y = x_{1} \cdot x_{2} \cdot \cdot\cdot\cdot \cdot x_{n}$; it is not necessary to use parentheses to specify the order of operations because the group is associative. One can also form a multiary quasigroup by carrying out any sequence of the same or different group or quasigroup operations, if the order of operations is specified.

There exist multiary quasigroups that cannot be represented in any of these ways. An *n*-ary quasigroup is **irreducible** if its operation cannot be factored into the composition of two operations in the following way:

*f*(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>) = *g*(*x*<sub>1</sub>, ..., *x*<sub>*i*−1</sub>, *h*(*x*<sub>*i*</sub>, ..., *x*<sub>*j*</sub>), *x*<sub>*j*+1</sub>, ..., *x*<sub>*n*</sub>),

where $1 \le i < j \le n$ and $(i, j) \ne (1, n)$. Finite irreducible *n*-ary quasigroups exist for all $n > 2$; see (Akivis Goldberg 2001) for details.

An *n*-ary quasigroup with an *n*-ary version of [associativity](https://en.wikipedia.org/wiki/Associativity) is called an [*n*-ary group](wikipedia://en/23340612).
