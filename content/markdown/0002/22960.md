# Elementary event

Basic outcome

::: {#o1 .subject cue=lead name="Elementary event"}

In [probability theory](wikipedia://en/23542), an **elementary event**, also called an **atomic event** or **sample point**, is an [event](wikipedia://en/22961) which contains only a single [outcome](wikipedia://en/39778851) in the [sample space](wikipedia://en/22958).[^o2] Using [set theory](wikipedia://en/27553) terminology, an elementary event is a [singleton](wikipedia://en/381798). Elementary events and their corresponding outcomes are often written interchangeably for simplicity, as such an event corresponding to precisely one outcome.

:::

The following are examples of elementary events:

- All sets $\{ k \},$ where $k \in \mathbb{N}$ if objects are being counted and the sample space is $S = \{ 1, 2, 3, \ldots \}$ (the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers)).
- $\{ HH \}, \{ HT \}, \{ TH \}, \text{ and } \{ TT \}$ if a coin is tossed twice. $S = \{ HH, HT, TH, TT \}$ where $H$ stands for heads and $T$ for tails.
- All sets $\{ x \},$ where $x$ is a [real number](wikipedia://en/20646438). Here $X$ is a [random variable](wikipedia://en/25685) with a [normal distribution](wikipedia://en/21462) and $S = (-\infty, + \infty).$ This example shows that, because the probability of each elementary event is zero, the probabilities assigned to elementary events do not determine a continuous [probability distribution](wikipedia://en/23543).

## Probability of an elementary event {#Probability_of_an_elementary_event}

Elementary events may occur with probabilities that are between zero and one (inclusively). In a [discrete](https://en.wikipedia.org/wiki/Discrete_random_variable) probability distribution whose sample space is finite, each elementary event is assigned a particular probability. In contrast, in a [continuous](https://en.wikipedia.org/wiki/Continuous_random_variable) distribution, individual elementary events must all have a probability of zero.

Some "mixed" distributions contain both stretches of continuous elementary events and some discrete elementary events; the discrete elementary events in such distributions can be called **atoms** or **atomic events** and can have non-zero probabilities.[^o4]

Under the [measure-theoretic](https://en.wikipedia.org/wiki/Measure_theory) definition of a [probability space](wikipedia://en/43325), the probability of an elementary event need not even be defined. In particular, the set of events on which probability is defined may be some [σ-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) on $S$ and not necessarily the full [power set](wikipedia://en/23799).
