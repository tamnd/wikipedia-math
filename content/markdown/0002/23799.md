# Power set

::: {#o1 .statement cue=infobox-mathematical-statement name="Power set"}

**Power set.**

The power set is the set that contains all subsets of a given set.

:::

::: {#o2 .subject cue=lead name="Power set"}

In [mathematics](wikipedia://en/18831), the **power set** (or **powerset**) of a [set](wikipedia://en/26691) $S$ is the set of all [subsets](wikipedia://en/27631) of $S$, including the [empty set](wikipedia://en/9566) and $S$ itself.[^n1] In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory) (as developed, for example, in the [ZFC](https://en.wikipedia.org/wiki/ZFC) axioms), the existence of the power set of any set is [postulated](https://en.wikipedia.org/wiki/Postulated) by the [axiom of power set](wikipedia://en/52552).[^n2] The powerset of $S$ is variously denoted as $P(S)$, $\text{𝒫}(S)$, $P(S)$, $\mathbb{P}(S)$, or $2^{S}$. Any subset of $P(S)$ is called a *[family of sets](wikipedia://en/723043)* over $S$.

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

If $S$ is the set $\{x, y, z\}$, then all the subsets of $S$ are

- $\{\}$ (the [empty set](wikipedia://en/9566), also denoted $\varnothing$ or $\emptyset$)
- $$\{x\}$$
- $$\{y\}$$
- $$\{z\}$$
- $$\{x, y\}$$
- $$\{x, z\}$$
- $$\{y, z\}$$
- $$\{x, y, z\}$$

and hence the power set of $S$ is $\{\{\}, \{x\}, \{y\}, \{z\}, \{x, y\}, \{x, z\}, \{y, z\}, \{x, y, z\}\}$.[^n3]

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $S$ is a finite set with the [cardinality](wikipedia://en/6174) $\lvert S\rvert = n$ (i.e., the number of all elements in the set $S$ is $n$), then the number of all the subsets of $S$ is $\lvert P(S)\rvert = 2^{n}$. This fact, as well as the reason for the notation $2^{S}$ denoting the power set $P(S)$, are demonstrated below.

An [indicator function](wikipedia://en/240790) or a characteristic function of a subset $A$ of a set $S$ with the cardinality $\lvert S\rvert = n$ is a function from $S$ to the two-element set $\{0, 1\}$, denoted as $I_{A} : S \to \{0, 1\}$, and it indicates whether an element of $S$ belongs to $A$ or not; If $x$ in $S$ belongs to $A$, then $I_{A}(x) = 1$, and $0$ otherwise. Each subset $A$ of $S$ is identified by or equivalent to the indicator function $I_{A}$, and $\{0,1\}^{S}$ as the set of all the functions from $S$ to $\{0, 1\}$ consists of all the indicator functions of all the subsets of $S$. In other words, $\{0, 1\}^{S}$ is equivalent or [bijective](wikipedia://en/3942) to the power set $P(S)$. Since each element in $S$ corresponds to either $0$ or $1$ under any function in $\{0, 1\}^{S}$, the number of all the functions in $\{0, 1\}^{S}$ is $2^{n}$. Since the number $2$ can be defined as $\{0, 1\}$ (see, for example, [von Neumann ordinals](https://en.wikipedia.org/wiki/Von_Neumann_ordinals)), the $P(S)$ is also denoted as $2^{S}$. Obviously $\lvert 2^{S}\rvert = 2^{\lvert S\rvert}$ holds. Generally speaking, $X^{Y}$ is the set of all functions from $Y$ to $X$ and $\lvert X^{Y}\rvert = \lvert X\rvert^{\lvert Y\rvert}$.

[Cantor's diagonal argument](wikipedia://en/51426#General_sets) shows that the power set of a set (whether infinite or not) always has strictly higher [cardinality](wikipedia://en/6174) than the set itself (or informally, the power set must be larger than the original set). In particular, [Cantor's theorem](wikipedia://en/341442) shows that the power set of a [countably infinite](wikipedia://en/6026) set is [uncountably](https://en.wikipedia.org/wiki/Uncountable) infinite. The power set of the set of [natural numbers](wikipedia://en/21474) can be put in a [one-to-one correspondence](wikipedia://en/3942) with the set of [real numbers](wikipedia://en/20646438) (see [Cardinality of the continuum](wikipedia://en/1574901)).

The power set of a set $S$, together with the operations of [union](wikipedia://en/47949), [intersection](wikipedia://en/23476429) and [complement](wikipedia://en/54347), is a [σ-algebra](wikipedia://en/29586) over $S$ and can be viewed as the prototypical example of a [Boolean algebra](wikipedia://en/3959). In fact, one can show that any *finite* Boolean algebra is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the Boolean algebra of the power set of a finite set. For *infinite* Boolean algebras, this is no longer true, but every infinite Boolean algebra can be represented as a [subalgebra](wikipedia://en/45239) of a power set Boolean algebra (see [Stone's representation theorem](https://en.wikipedia.org/wiki/Stone's_representation_theorem)).

The power set of a set $S$ forms an [abelian group](wikipedia://en/2974) when it is considered with the operation of [symmetric difference](wikipedia://en/262288) (with the empty set as the identity element and each set being its own inverse), and a [commutative](https://en.wikipedia.org/wiki/Commutative) [monoid](wikipedia://en/19652) when considered with the operation of intersection (with the entire set $S$ as the identity element). It can hence be shown, by proving the [distributive laws](wikipedia://en/103118), that the power set considered together with both of these operations forms a [Boolean ring](wikipedia://en/54356).

:::

## Representing subsets as functions {#Representing_subsets_as_functions}

In [set theory](wikipedia://en/27553), $X^{Y}$ is the notation representing the set of all [functions](wikipedia://en/185427) from $Y$ to $X$. As "$2$" can be defined as $\{0, 1\}$ (see, for example, [von Neumann ordinals](https://en.wikipedia.org/wiki/Von_Neumann_ordinals)), $2^{S}$ (i.e., $\{0, 1\}^{S}$) is the set of all [functions](wikipedia://en/185427) from $S$ to $\{0, 1\}$. As [shown above](wikipedia://en/23799#Properties), $2^{S}$ and the power set of $S$, $P(S)$, are considered identical set-theoretically.

This equivalence can be applied to the example [above](wikipedia://en/23799#Example), in which $S = \{x, y, z\}$, to get the [isomorphism](wikipedia://en/14828) with the binary representations of numbers from 0 to $2^{n} - 1$, with $n$ being the number of elements in the set $S$ or $\lvert S\rvert = n$. First, the enumerated set $\{(x, 1), (y, 2), (z, 3)\}$ is defined in which the number in each ordered pair represents the position of the paired element of $S$ in a sequence of binary digits such as $\{x, y\} = 011_{(2)}$; $x$ of $S$ is located at the first from the right of this sequence and $y$ is at the second from the right, and 1 in the sequence means the element of $S$ corresponding to the position of it in the sequence exists in the subset of $S$ for the sequence while 0 means it does not.

For the whole power set of $S$, we get:

*Elements of $P(S)$ where $S = \{x, y, z\}$*

::: {#o11 .table cue=table name="Elements of where"}

| Subset | Sequence of binary digits | Binary interpretation | Decimal equivalent |
|---|---|---|---|
| $\{\}$ | $0, 0, 0$ | $000_{(2)}$ | $0_{(10)}$ |
| $\{x\}$ | $0, 0, 1$ | $001_{(2)}$ | $1_{(10)}$ |
| $\{y\}$ | $0, 1, 0$ | $010_{(2)}$ | $2_{(10)}$ |
| $\{x, y\}$ | $0, 1, 1$ | $011_{(2)}$ | $3_{(10)}$ |
| $\{z\}$ | $1, 0, 0$ | $100_{(2)}$ | $4_{(10)}$ |
| $\{x, z\}$ | $1, 0, 1$ | $101_{(2)}$ | $5_{(10)}$ |
| $\{y, z\}$ | $1, 1, 0$ | $110_{(2)}$ | $6_{(10)}$ |
| $\{x, y, z\}$ | $1, 1, 1$ | $111_{(2)}$ | $7_{(10)}$ |

:::

Such an [injective mapping](wikipedia://en/45196) from $P(S)$ to integers is arbitrary, so this representation of all the subsets of $S$ is not unique, but the sort order of the enumerated set does not change its cardinality. (E.g., $\{(y, 1), (z, 2), (x, 3)\}$ can be used to construct another injective mapping from $P(S)$ to the integers without changing the number of one-to-one correspondences.)

However, such finite binary representation is only possible if $S$ can be enumerated. (In this example, $x$, $y$, and $z$ are enumerated with $1$, $2$, and $3$ respectively as the position of binary digit sequences.) The enumeration is possible even if $S$ has an infinite cardinality (i.e., the number of elements in $S$ is infinite), such as the set of integers or rationals, but not possible for example if $S$ is the set of real numbers, in which case we cannot enumerate all irrational numbers.

## Relation to binomial theorem {#Relation_to_binomial_theorem}

The [binomial theorem](wikipedia://en/4677) is closely related to the power set. A $k$–elements combination from some set is another name for a $k$–elements subset, so the number of [combinations](wikipedia://en/5308), denoted as $C(n, k)$ (also called [binomial coefficient](wikipedia://en/4668)) is a number of subsets with $k$ elements in a set with $n$ elements; in other words it's the number of sets with $k$ elements which are elements of the power set of a set with $n$ elements.

For example, the power set of a set with three elements, has:

- $C(3, 0) = 1$ subset with $0$ elements (the empty subset),
- $C(3, 1) = 3$ subsets with $1$ element (the singleton subsets),
- $C(3, 2) = 3$ subsets with $2$ elements (the complements of the singleton subsets),
- $C(3, 3) = 1$ subset with $3$ elements (the original set itself).

Using this relationship, we can compute $\lvert 2^{S}\rvert$ using the formula:

$$\left|2^S \right | = \sum_{k=0}^{|S|} \binom{|S|}{k}$$

Therefore, one can deduce the following identity, assuming $\lvert S\rvert = n$:

$$\left |2^S \right| = 2^n = \sum_{k=0}^{n} \binom{n}{k}$$

:::

## Recursive definition {#Recursive_definition}

If $S$ is a [finite set](wikipedia://en/11742), then a [recursive definition](wikipedia://en/1047605) of $P(S)$ proceeds as follows:

- If $S = \{\}$, then $P(S) = \{\{\}\}$.
- Otherwise, let $e \in S$ and $T = S \setminus \{e\}$; then $P(S) = P(T) \cup \{t \cup \{e\} : t \in P(T)\}$.

In words:

- The power set of the [empty set](wikipedia://en/9566) is a [singleton](wikipedia://en/381798) whose only element is the empty set.
- For a non-empty set $S$, let $e$ be any element of the set and $T$ its [relative complement](https://en.wikipedia.org/wiki/Relative_complement); then the power set of $S$ is a [union](wikipedia://en/47949) of a power set of $T$ and a power set of $T$ whose each element is expanded with the $e$ element.

## Subsets of limited cardinality {#Subsets_of_limited_cardinality}

The set of subsets of $S$ of [cardinality](wikipedia://en/6174) less than or equal to $\kappa$ is sometimes denoted by $P_{\kappa}(S)$ or $[S]^{\kappa}$, and the set of subsets with cardinality strictly less than $\kappa$ is sometimes denoted $P_{<\kappa}(S)$ or $[S]^{<\kappa}$. Similarly, the set of non-empty subsets of $S$ might be denoted by $P_{\ge1}(S)$ or $P^{+}(S)$.

## Power object {#Power_object}

section A set can be regarded as an [algebra](https://en.wikipedia.org/wiki/Algebra_%28universal_algebra%29) having no nontrivial operations or defining equations. From this perspective, the concept of the power set of $X$ as the set of all subsets of $X$ generalizes naturally to the set to all subalgebras of an [algebraic structure](wikipedia://en/106364) or algebra.[^o17][^o18]

The power set of a set, when ordered by inclusion, is always a complete atomic Boolean algebra, and every complete atomic Boolean algebra arises as the [lattice](wikipedia://en/469304) of all subsets of some set. The generalization to arbitrary algebras is that the set of subalgebras of an algebra, again ordered by inclusion, is always an [algebraic lattice](https://en.wikipedia.org/wiki/Algebraic_lattice), and every algebraic lattice arises as the lattice of subalgebras of some algebra.[^o19] So in that regard, subalgebras behave analogously to subsets.

However, there are two important properties of subsets that do not carry over to subalgebras in general. First, although the subsets of a set form a set (as well as a lattice), in some classes it may not be possible to organize the subalgebras of an algebra as itself an algebra in that class, although they can always be organized as a lattice. Secondly, whereas the subsets of a set are in bijection with the functions from that set to the set $\{0, 1\} = 2$, there is no guarantee that a class of algebras contains an algebra that can play the role of $2$ in this way.

Certain classes of algebras enjoy both of these properties. The first property is more common; the case of having both is relatively rare. One class that does have both is that of [multigraphs](wikipedia://en/1774970). Given two multigraphs $G$ and $H$, a [homomorphism](wikipedia://en/13564) $h : G \to H$ consists of two functions, one mapping vertices to vertices and the other mapping edges to edges. The set $H^{G}$ of homomorphisms from $G$ to $H$ can then be organized as the graph whose vertices and edges are respectively the vertex and edge functions appearing in that set. Furthermore, the subgraphs of a multigraph $G$ are in bijection with the graph homomorphisms from $G$ to the multigraph $\Omega$ definable as the [complete directed graph](wikipedia://en/85816) on two vertices (hence four edges, namely two self-loops and two more edges forming a cycle) augmented with a fifth edge, namely a second self-loop at one of the vertices. We can therefore organize the subgraphs of $G$ as the multigraph $\Omega^{G}$, called the **power object** of $G$.

What is special about a multigraph as an algebra is that its operations are unary. A multigraph has two sorts of elements forming a set $V$ of vertices and $E$ of edges, and has two unary operations $s, t : E \to V$ giving the source (start) and target (end) vertices of each edge. An algebra all of whose operations are unary is called a [presheaf](https://en.wikipedia.org/wiki/Presheaf). Every class of presheaves contains a presheaf $\Omega$ that plays the role for subalgebras that $2$ plays for subsets. Such a class is a special case of the more general notion of [elementary topos](wikipedia://en/815802) as a [category](wikipedia://en/53759) that is [closed](wikipedia://en/1397197) (and moreover [cartesian closed](wikipedia://en/237037)) and has an object $\Omega$, called a [subobject classifier](wikipedia://en/366909). Although the term "power object" is sometimes used synonymously with [exponential object](wikipedia://en/2237858) $Y^{X}$, in topos theory $Y$ is required to be $\Omega$. [^o20]

## Functors and quantifiers {#Functors_and_quantifiers}

There is both a covariant and contravariant power set [functor](wikipedia://en/10987), $P: \operatorname{Set} \to \operatorname{Set}$ and $P: \operatorname{Set}^{\operatorname{op}} \to \operatorname{Set}$. The covariant functor is defined more simply as the functor which sends a set $S$ to $P(S)$ and a morphism $f: S \to T$ (here, a function between sets) to the image morphism. That is, for $A = \{x_{1}, x_{2}, ...\} \in P(S), Pf (A) = \{f (x_{1}), f (x_{2}), ...\} \in P(T)$. Elsewhere in this article, the power set was defined as the set of functions of $S$ into the set with 2 elements. Formally, this defines a natural isomorphism $P \cong \operatorname{Set}(-,2)$. The contravariant power set functor is different from the covariant version in that it sends $f$ to the *pre*image morphism, so that if $f (A) = B \subseteq T, Pf (B) = A$. This is because a general functor $C(-,c)$ takes a morphism $h: a \to b$ to precomposition by *h*, so a function $h*: C(b,c) \to C(a,c)$, which takes morphisms from *b* to *c* and takes them to morphisms from *a* to *c*, through *b* via *h*.[^o23]

In [category theory](wikipedia://en/5869) and the theory of [elementary topoi](wikipedia://en/815802), the [universal quantifier](https://en.wikipedia.org/wiki/Universal_quantifier) can be understood as the [right adjoint](https://en.wikipedia.org/wiki/Right_adjoint) of a [functor](wikipedia://en/10987) between power sets, the [inverse image](https://en.wikipedia.org/wiki/Inverse_image) functor of a function between sets; likewise, the [existential quantifier](https://en.wikipedia.org/wiki/Existential_quantifier) is the [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint).[^n4]

:::
