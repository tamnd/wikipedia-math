# Surjective function

::: {#o1 .subject cue=lead name="Surjective function"}

In [mathematics](wikipedia://en/18831), a **surjective function** (also known as **surjection**, or **onto function** ) is a [function](wikipedia://en/185427) $f$ such that, for every element $y$ of the function's [codomain](wikipedia://en/50264), there exists at least one element $x$ in the function's [domain](wikipedia://en/50263) such that $f(x) = y$. In other words, for a function $f : X \to Y$, the codomain $Y$ is the [image](wikipedia://en/579311) of the function's domain $X$.[^o2][^o3] It is not required that $x$ be [unique](https://en.wikipedia.org/wiki/Unique_%28mathematics%29); the function $f$ may map one or more elements of $X$ to the same element of $Y$.

:::

The term *surjective* and the related terms *[injective](wikipedia://en/45196)* and *[bijective](https://en.wikipedia.org/wiki/Bijective_function)* were introduced by [Nicolas Bourbaki](wikipedia://en/167394),[^o4][^o5] a group of mainly [French](https://en.wikipedia.org/wiki/France) 20th-century [mathematicians](wikipedia://en/18902) who, under this pseudonym, wrote a series of books presenting an exposition of modern advanced mathematics, beginning in 1935. The French word *sur* means *over* or *above*, and relates to the fact that the [image](wikipedia://en/579311) of the domain of a surjective function completely covers the function's codomain.

Any function induces a surjection by [restricting](https://en.wikipedia.org/wiki/Restriction_of_a_function) its codomain to the image of its domain. Every surjective function has a [right inverse](wikipedia://en/14907#Left_and_right_inverses) assuming the [axiom of choice](wikipedia://en/840), and every function with a right inverse is necessarily a surjection. The [composition](wikipedia://en/195947) of surjective functions is always surjective. Any function can be decomposed into a surjection and an injection.

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **surjective function** is a [function](wikipedia://en/185427) whose [image](wikipedia://en/579311) is equal to its [codomain](wikipedia://en/50264). Equivalently, a function $f$ with [domain](wikipedia://en/50263) $X$ and codomain $Y$ is surjective if for every $y$ in $Y$ there exists at least one $x$ in $X$ with $f(x)=y$.[^o2] Surjections are sometimes denoted by a two-headed rightwards arrow (21A0),[^o8] as in $f\colon X\twoheadrightarrow Y$.

Symbolically,

If $f\colon X \rightarrow Y$, then $f$ is said to be surjective if

$\forall y \in Y, \, \exists x \in X, \;\; f(x)=y$.[^o3][^o9]

## Examples {#Examples}

*Image: Codomain2.SVG.* **A non-surjective function** from [domain](wikipedia://en/50263) *X* to [codomain](wikipedia://en/50264) *Y*. The smaller yellow oval inside *Y* is the [image](wikipedia://en/579311) (also called [range](wikipedia://en/275991)) of *f*. This function is **not** surjective, because the image does not fill the whole codomain. In other words, *Y* is colored in a two-step process: First, for every *x* in *X*, the point *f*(*x*) is colored yellow; Second, all the rest of the points in *Y*, that are not yellow, are colored blue. The function *f* would be surjective only if there were no blue points.

- For any set *X*, the [identity function](wikipedia://en/15069) id<sub>*X*</sub> on *X* is surjective.
- The function $f : \mathbf{Z} \to \{0, 1\}$ defined by *f*(*n*) = *n* **[mod](wikipedia://en/20087)** 2 (that is, [even](https://en.wikipedia.org/wiki/Even_number) [integers](wikipedia://en/14563) are mapped to 0 and [odd](https://en.wikipedia.org/wiki/Odd_number) integers to 1) is surjective.
- The function $f : \mathbf{R} \to \mathbf{R}$ defined by *f*(*x*) = 2*x* + 1 is surjective (and even [bijective](https://en.wikipedia.org/wiki/Bijective_function)), because for every [real number](wikipedia://en/20646438) *y*, we have an *x* such that *f*(*x*) = *y*: such an appropriate *x* is (*y* − 1)/2.
- The function $f : \mathbf{R} \to \mathbf{R}$ defined by *f*(*x*) = *x*<sup>3</sup> − 3*x* is surjective, because the pre-image of any [real number](wikipedia://en/20646438) *y* is the solution set of the cubic polynomial equation *x*<sup>3</sup> − 3*x* − *y* = 0, and every cubic polynomial with real coefficients has at least one real root. However, this function is not [injective](wikipedia://en/45196) (and hence not [bijective](https://en.wikipedia.org/wiki/Bijective_function)), since, for example, the pre-image of *y* = 2 is {*x* = −1, *x* = 2}. (In fact, the pre-image of this function for every *y*, −2 ≤ *y* ≤ 2 has more than one element.)
- The function $g : \mathbf{R} \to \mathbf{R}$ defined by *g*(*x*) = *x*<sup>2</sup> is *not* surjective, since there is no real number *x* such that *x*<sup>2</sup> = −1. However, the function $g : \mathbf{R} \to \mathbf{R}_{\ge0}$ defined by $g(x) = x^{2}$ (with the restricted codomain) *is* surjective, since for every *y* in the nonnegative real codomain *Y*, there is at least one *x* in the real domain *X* such that *x*<sup>2</sup> = *y*.
- The [natural logarithm](wikipedia://en/21476) function $\ln : (0, +\infty) \to \mathbf{R}$ is a surjective and even bijective (mapping from the set of positive real numbers to the set of all real numbers). Its inverse, the [exponential function](wikipedia://en/9678), if defined with the set of real numbers as the domain and the codomain, is not surjective (as its range is the set of positive real numbers).
- The [matrix exponential](wikipedia://en/672731) is not surjective when seen as a map from the space of all *n*×*n* [matrices](wikipedia://en/20556859) to itself. It is, however, usually defined as a map from the space of all *n*×*n* matrices to the [general linear group](wikipedia://en/113564) of degree *n* (that is, the [group](wikipedia://en/19447) of all *n*×*n* [invertible matrices](wikipedia://en/217122)). Under this definition, the matrix exponential is surjective for complex matrices, although still not surjective for real matrices.
- The [projection](wikipedia://en/3913145) from a [cartesian product](wikipedia://en/24104095) $A \times B$ to one of its factors is surjective, unless the other factor is empty.
- In a 3D video game, vectors are projected onto a 2D flat screen by means of a surjective function.

## Properties {#Properties}

A function is [bijective](https://en.wikipedia.org/wiki/Bijective_function) if and only if it is both surjective and [injective](wikipedia://en/45196).[^o14]

If (as is often done) a function is identified with its [graph](wikipedia://en/87352), then surjectivity is not a property of the function itself, but rather a property of the [mapping](wikipedia://en/516931).[^o15] This is, the function together with its codomain. Unlike injectivity, surjectivity cannot be read off of the graph of the function alone.

### Surjections as right invertible functions {#Surjections_as_right_invertible_functions}

The function *g* : *Y* → *X* is said to be a [right inverse](wikipedia://en/14907#Left_and_right_inverses) of the function *f* : *X* → *Y* if *f*(*g*(*y*)) = *y* for every *y* in *Y* (*g* can be undone by *f*). In other words, *g* is a right inverse of *f* if the [composition](wikipedia://en/195947) *f* o *g* of *g* and *f* in that order is the [identity function](wikipedia://en/15069) on the domain *Y* of *g*. The function *g* need not be a complete [inverse](wikipedia://en/14907) of *f* because the composition in the other order, *g* o *f*, may not be the identity function on the domain *X* of *f*. In other words, *f* can undo or "*reverse*" *g*, but cannot necessarily be reversed by it. For example, $f:\mathbb{R}^2\rightarrow\mathbb{R},(x,y)\mapsto x$ has right inverse $g:z\mapsto (z,0);$ the composition in the other order gives $g(f((x,y)))=(x,0)$, which equals $(x,y)$ only if $y=0$.

Every function with a right inverse is necessarily a surjection. The proposition that every surjective function has a right inverse is equivalent to the [axiom of choice](wikipedia://en/840).

If *f* : *X* → *Y* is surjective and *B* is a [subset](wikipedia://en/27631) of *Y*, then *f*(*f*<sup>−1</sup>(*B*)) = *B*. Thus, *B* can be recovered from its [preimage](https://en.wikipedia.org/wiki/Preimage) *f*<sup>−1</sup>(*B*).

For example, in the first illustration in the gallery, there is some function *g* such that *g*(*C*) = 4. There is also some function *f* such that *f*(4) = *C*. It doesn't matter that *g* is not unique (it would also work if *g*(*C*) equals 3); it only matters that *f* "reverses" *g*.

### Surjections as epimorphisms {#Surjections_as_epimorphisms}

A function *f* : *X* → *Y* is surjective if and only if it is [right-cancellative](https://en.wikipedia.org/wiki/Right-cancellative):[^o18][^o19] given any functions *g*,*h* : *Y* → *Z*, whenever *g* o *f* = *h* o *f*, then *g* = *h*. This property is formulated in terms of functions and their [composition](wikipedia://en/195947) and can be generalized to the more general notion of the [morphisms](wikipedia://en/27716891) of a [category](wikipedia://en/53759) and their composition. Right-cancellative morphisms are called [epimorphisms](wikipedia://en/59539). Specifically, surjective functions are precisely the epimorphisms in the [category of sets](wikipedia://en/26829). The prefix *epi* is derived from the Greek preposition *ἐπί* meaning *over*, *above*, *on*.

Any morphism with a right inverse is an epimorphism, but the converse is not true in general. A right inverse *g* of a morphism *f* is called a [section](wikipedia://en/10630303) of *f*. A morphism with a right inverse is called a [split epimorphism](https://en.wikipedia.org/wiki/Split_epimorphism).

### Surjections as binary relations {#Surjections_as_binary_relations}

Any function with domain *X* and codomain *Y* can be seen as a [left-total](https://en.wikipedia.org/wiki/Left-total_relation) and [right-unique](https://en.wikipedia.org/wiki/Right-unique_relation) binary relation between *X* and *Y* by identifying it with its [function graph](https://en.wikipedia.org/wiki/Function_graph). A surjective function with domain *X* and codomain *Y* is then a binary relation between *X* and *Y* that is right-unique and both left-total and [right-total](https://en.wikipedia.org/wiki/Right-total_relation).

### Cardinality of the domain of a surjection {#Cardinality_of_the_domain_of_a_surjection}

The [cardinality](wikipedia://en/6174) of the domain of a surjective function is greater than or equal to the cardinality of its codomain: If *f* : *X* → *Y* is a surjective function, then *X* has at least as many elements as *Y*, in the sense of [cardinal numbers](wikipedia://en/6173). (The proof appeals to the [axiom of choice](wikipedia://en/840) to show that a function *g* : *Y* → *X* satisfying *f*(*g*(*y*)) = *y* for all *y* in *Y* exists. *g* is easily seen to be injective, thus the [formal definition](wikipedia://en/6173#Formal_definition) of |*Y*| ≤ |*X*| is satisfied.)

Specifically, if both *X* and *Y* are [finite](wikipedia://en/11742) with the same number of elements, then *f* : *X* → *Y* is surjective if and only if *f* is [injective](https://en.wikipedia.org/wiki/Injective).

### Composition and decomposition {#Composition_and_decomposition}

The [composition](wikipedia://en/195947) of surjective functions is always surjective: If *f* and *g* are both surjective, and the codomain of *g* is equal to the domain of *f*, then *f* o *g* is surjective. Conversely, if *f* o *g* is surjective, then *f* is surjective (but *g*, the function applied first, need not be). These properties generalize from surjections in the [category of sets](wikipedia://en/26829) to any [epimorphisms](wikipedia://en/59539) in any [category](wikipedia://en/53759).

Any function can be decomposed into a surjection and an [injection](wikipedia://en/45196): For any function *h* : *X* → *Z* there exist a surjection *f* : *X* → *Y* and an injection *g* : *Y* → *Z* such that *h* = *g* o *f*. To see this, define *Y* to be the set of [preimages](https://en.wikipedia.org/wiki/Preimage) *h*<sup>−1</sup>(*z*) where *z* is in *h*(*X*). These preimages are [disjoint](wikipedia://en/39359) and [partition](wikipedia://en/340240) *X*. Then *f* carries each *x* to the element of *Y* which contains it, and *g* carries each element of *Y* to the point in *Z* to which *h* sends its points. Then *f* is surjective since it is a projection map, and *g* is injective by definition.

### Induced surjection and induced bijection {#Induced_surjection_and_induced_bijection}

Any function induces a surjection by restricting its codomain to its range. Any surjective function induces a bijection defined on a [quotient](https://en.wikipedia.org/wiki/Quotient_set) of its domain by collapsing all arguments mapping to a given fixed image. More precisely, every surjection *f* : *A* → *B* can be factored as a projection followed by a bijection as follows. Let *A*/~ be the [equivalence classes](wikipedia://en/9260) of *A* under the following [equivalence relation](wikipedia://en/9259): *x* ~ *y* if and only if *f*(*x*) = *f*(*y*). Equivalently, *A*/~ is the set of all preimages under *f*. Let *P*(~) : *A* → *A*/~ be the [projection map](https://en.wikipedia.org/wiki/Projection_map) which sends each *x* in *A* to its equivalence class \[*x*\]<sub>~</sub>, and let *f*<sub>*P*</sub> : *A*/~ → *B* be the well-defined function given by *f*<sub>*P*</sub>(\[*x*\]<sub>~</sub>) = *f*(*x*). Then *f* = *f*<sub>*P*</sub> o *P*(~).

## The set of surjections {#The_set_of_surjections}

Given fixed finite sets $A$ and $B$, one can form the set of surjections $A \twoheadrightarrow B$. The [cardinality](wikipedia://en/6174) of this set is one of the twelve aspects of Rota's [Twelvefold way](wikipedia://en/3290705), and is given by $|B|!\begin{Bmatrix}|A|\\|B|\end{Bmatrix}$, where $\begin{Bmatrix}|A|\\|B|\end{Bmatrix}$ denotes a [Stirling number of the second kind](wikipedia://en/2229292).
