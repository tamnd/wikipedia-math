# ♯P-complete

P-complete

::: {#o1 .subject cue=lead name="♯P-complete"}

The **\#P-complete** problems (pronounced "sharp P complete", "number P complete", or "hash P complete") form a [complexity class](wikipedia://en/502426) in [computational complexity theory](wikipedia://en/7543). The problems in this complexity class are defined by having the following two properties:

:::

- The problem is in [\#P](wikipedia://en/27924), the class of problems that can be defined as counting the number of accepting paths of a [polynomial-time](https://en.wikipedia.org/wiki/Polynomial-time) [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine).
- The problem is [\#P](wikipedia://en/27924)-hard, meaning that every other problem in #P has a polynomial-time [Turing reduction](wikipedia://en/1188375) or [polynomial-time counting reduction](https://en.wikipedia.org/wiki/Polynomial-time_counting_reduction) to it. A counting reduction is a pair of polynomial-time transformations from inputs of the other problem to inputs of the given problem and from outputs of the given problem to outputs of the other problem, allowing the other problem to be solved using any subroutine for the given problem. A polynomial-time Turing reduction is an algorithm for the other problem that makes a polynomial number of calls to a subroutine for the given problem and, outside of those calls, uses polynomial time. In some cases [parsimonious reductions](https://en.wikipedia.org/wiki/Parsimonious_reduction), a more specific type of reduction that preserves the exact number of solutions, are used.

\#P-complete problems are at least as hard as [NP-complete](https://en.wikipedia.org/wiki/NP-complete) problems.[^o2] A polynomial-time algorithm for solving a #P-complete problem, if it existed, would solve the [P versus NP problem](wikipedia://en/6115) by implying that P and NP are equal. No such algorithm is known, nor is a proof known that such an algorithm does not exist.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of #P-complete problems include:

- How many different variable assignments will satisfy a given general Boolean formula? ([\#SAT](https://en.wikipedia.org/wiki/Sharp-SAT))
- How many different variable assignments will satisfy a given [DNF](wikipedia://en/73341) formula?
- How many different variable assignments will satisfy a given [2-satisfiability](https://en.wikipedia.org/wiki/2-satisfiability) problem?
- How many [perfect matchings](wikipedia://en/44031) are there for a given [bipartite graph](wikipedia://en/244431)?
- What is the value of the [permanent](wikipedia://en/215889) of a given matrix whose entries are 0 or 1? (See [\#P-completeness of 01-permanent](wikipedia://en/20768719).)
- How many [graph colorings](wikipedia://en/426743) using *k* colors are there for a particular graph *G*?
- How many different [linear extensions](wikipedia://en/11726298) are there for a given [partially ordered set](wikipedia://en/23572), or, equivalently, how many different [topological orderings](wikipedia://en/897064) are there for a given [directed acyclic graph](wikipedia://en/204002)?[^o5]

These are all necessarily members of the class [\#P](wikipedia://en/27924) as well. As a non-example, consider the case of counting solutions to a [1-satisfiability](https://en.wikipedia.org/wiki/1-satisfiability) problem: a series of variables that are each individually constrained, but have no relationships with each other. The solutions can be efficiently counted, by multiplying the number of options for each variable in isolation. Thus, this problem is in [\#P](wikipedia://en/27924), but cannot be #P-complete unless [\#P](wikipedia://en/27924)=[FP](wikipedia://en/663347). This would be surprising, as it would imply that [P](wikipedia://en/658550)=[NP](wikipedia://en/21562)=[PH](https://en.wikipedia.org/wiki/PH_%28complexity%29).

:::

## Easy problems with hard counting versions {#Easy_problems_with_hard_counting_versions}

Some #P-complete problems correspond to easy ([polynomial time](wikipedia://en/658550)) problems. Determining the satisfiability of a Boolean formula in [disjunctive normal form](wikipedia://en/73341) is easy: such a formula is satisfiable if and only if it contains a satisfiable conjunction (one that does not contain a variable and its negation), whereas counting the number of satisfying assignments is #P-complete. Furthermore, deciding 2-satisfiability is easy compared to counting the number of satisfying assignments. [Topologically sorting](wikipedia://en/897064) is easy in contrast to counting the number of topological sortings. A single [perfect matching](wikipedia://en/581797) can be found in polynomial time, but counting all perfect matchings is #P-complete. The perfect matching counting problem was the first counting problem corresponding to an easy decision problem shown to be #P-complete, in a 1979 paper by [Leslie Valiant](https://en.wikipedia.org/wiki/Leslie_Valiant) that also defined the class #P and the #P-complete problems for the first time.[^o7]

## Approximation {#Approximation}

There are [probabilistic algorithms](https://en.wikipedia.org/wiki/Probabilistic_algorithm) that return good approximations to some #P-complete problems with high probability. This is one of the demonstrations of the power of probabilistic algorithms.

Many #P-complete problems have a [fully polynomial-time randomized approximation scheme](wikipedia://en/666431), or "FPRAS," which, informally, will produce with high probability an approximation to an arbitrary degree of accuracy, in time that is polynomial with respect to both the size of the problem and the degree of accuracy required. [Jerrum](https://en.wikipedia.org/wiki/Mark_Jerrum), [Valiant](https://en.wikipedia.org/wiki/Leslie_Valiant), and [Vazirani](https://en.wikipedia.org/wiki/Vijay_Vazirani) showed that every #P-complete problem either has an FPRAS, or is essentially impossible to approximate; if there is any polynomial-time algorithm that consistently produces an approximation of a #P-complete problem that is within a polynomial ratio in the size of the input of the exact answer, then that algorithm can be used to construct an FPRAS.[^o9]
