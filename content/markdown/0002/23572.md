# Partially ordered set

::: {#o1 .subject cue=lead name="Partially ordered set"}

*Image: Hasse diagram of powerset of 3.svg.* **Fig. 1** The [Hasse diagram](wikipedia://en/338199) of the [set of all subsets](wikipedia://en/23799) of a three-element set $\{x, y, z\},$ ordered by [inclusion](https://en.wikipedia.org/wiki/Set_inclusion). Sets connected by an upward path, like $\emptyset$ and $\{x,y\}$, are comparable, while e.g. $\{x\}$ and $\{y\}$ are not.

In [mathematics](wikipedia://en/18831), especially [order theory](wikipedia://en/361924), a **partial order** on a [set](wikipedia://en/26691) is an arrangement such that, for certain pairs of elements, one precedes the other. The word *partial* is used to indicate that not every pair of elements needs to be comparable; that is, there may be pairs for which neither element precedes the other. Partial orders thus generalize [total orders](wikipedia://en/30330), in which every pair is comparable.

:::

Formally, a partial order is a [homogeneous binary relation](https://en.wikipedia.org/wiki/Homogeneous_binary_relation) that is [reflexive](wikipedia://en/200458), [antisymmetric](wikipedia://en/1176), and [transitive](wikipedia://en/200463). A **partially ordered set** (**poset** for short) is an [ordered pair](wikipedia://en/22362) $P=(X,\leq)$ consisting of a set $X$ (called the *ground set* of $P$) and a partial order $\leq$ on $X$. When the meaning is clear from context and there is no ambiguity about the partial order, the set $X$ itself is sometimes called a poset.

## Partial order relations {#Partial_order_relations}

The term *partial order* usually refers to the reflexive partial order relations, referred to in this article as *non-strict* partial orders. However some authors use the term for the other common type of partial order relations, the irreflexive partial order relations, also called strict partial orders. Strict and non-strict partial orders can be put into a [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence), so for every strict partial order there is a unique corresponding non-strict partial order, and vice versa.

### Partial orders {#Partial_orders}

A **reflexive**, **weak**,[^o22] or **non-strict partial order**,[^o4] commonly referred to simply as a **partial order**, is a [homogeneous relation](wikipedia://en/12987179) ≤ on a [set](wikipedia://en/26691) $P$ that is [reflexive](wikipedia://en/200458), [antisymmetric](wikipedia://en/1176), and [transitive](wikipedia://en/200463). That is, for all $a, b, c \in P,$ it must satisfy:[^o22]

1. [Reflexivity](wikipedia://en/200458): $a \leq a$, i.e. every element is related to itself.
1. [Antisymmetry](wikipedia://en/1176): if $a \leq b$ and $b \leq a$ then $a = b$, i.e. no two distinct elements precede each other.
1. [Transitivity](wikipedia://en/200463): if $a \leq b$ and $b \leq c$ then $a \leq c$.

A non-strict partial order is also known as an antisymmetric [preorder](wikipedia://en/23582).

::: {#o6 .pointer-item cue=pointer name="Strict order"}

### Strict partial orders {#Strict_partial_orders}

An **irreflexive**, **strong**,[^o22] or **strict partial order** is a homogeneous relation \< on a set $P$ that is [irreflexive](https://en.wikipedia.org/wiki/Irreflexive_relation), [asymmetric](wikipedia://en/1229368) and [transitive](wikipedia://en/200463); that is, it satisfies the following conditions for all $a, b, c \in P:$

1. [Irreflexivity](https://en.wikipedia.org/wiki/Irreflexive_relation): $\neg\left( a < a \right)$, i.e. no element is related to itself (also called anti-reflexive).
1. [Asymmetry](wikipedia://en/1229368): if $a < b$ then not $b < a$.
1. [Transitivity](wikipedia://en/200463): if $a < b$ and $b < c$ then $a < c$.

A transitive relation is asymmetric if and only if it is irreflexive.[^o7] So the definition is the same if it omits either irreflexivity or asymmetry (but not both).

A strict partial order is also known as a [strict preorder](https://en.wikipedia.org/wiki/Strict_preorder).

:::

::: {#o9 .pointer-item cue=pointer name="Non-strict order"}

### Correspondence of strict and non-strict partial order relations {#Correspondence_of_strict_and_non-strict_partial_order_relations}

*Image: PartialOrders redundencies svg.svg.* **Fig. 2** [Commutative diagram](wikipedia://en/138484) about the connections between strict/non-strict relations and their duals, via the operations of reflexive closure (*cls*), irreflexive kernel (*ker*), and converse relation (*cnv*). Each relation is depicted by its [logical matrix](wikipedia://en/4109196) for the poset whose [Hasse diagram](wikipedia://en/338199) is depicted in the center. For example $3 \not\leq 4$ so row 3, column 4 of the bottom left matrix is empty.

Strict and non-strict partial orders on a set $P$ are closely related. A non-strict partial order $\leq$ may be converted to a strict partial order by removing all relationships of the form $a \leq a;$ that is, the strict partial order is the set $< \; := \ \leq\ \setminus \ \Delta_P$ where $\Delta_P := \{ (p, p) : p \in P \}$ is the [identity relation](https://en.wikipedia.org/wiki/Identity_relation) on $P \times P$ and $\;\setminus\;$ denotes [set subtraction](https://en.wikipedia.org/wiki/Set_subtraction). Conversely, a strict partial order \< on $P$ may be converted to a non-strict partial order by adjoining all relationships of that form; that is, $\leq\; := \;\Delta_P\; \cup \;<\;$ is a non-strict partial order. Thus, if $\leq$ is a non-strict partial order, then the corresponding strict partial order \< is the [irreflexive kernel](https://en.wikipedia.org/wiki/Irreflexive_kernel) given by

$$a < b \text{ if } a \leq b \text{ and } a \neq b.$$

Conversely, if \< is a strict partial order, then the corresponding non-strict partial order $\leq$ is the [reflexive closure](wikipedia://en/22603618) given by:

$$a \leq b \text{ if } a < b \text{ or } a = b.$$

:::

### Dual orders {#Dual_orders}

The *dual* (or *opposite*) $R^{\text{op}}$ of a partial order relation $R$ is defined by letting $R^{\text{op}}$ be the [converse relation](wikipedia://en/3941020) of $R$, i.e. $x R^{\text{op}} y$ if and only if $y R x$. The dual of a non-strict partial order is a non-strict partial order,[^n1] and the dual of a strict partial order is a strict partial order. The dual of a dual of a relation is the original relation.

::: {#o13 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

Given a set $P$ and a partial order relation, typically the non-strict partial order $\leq$, we may uniquely extend our notation to define four partial order relations $\leq,$ $<,$ $\geq,$ and $>$, where $\leq$ is a non-strict partial order relation on $P$, $<$ is the associated strict partial order relation on $P$ (the [irreflexive kernel](https://en.wikipedia.org/wiki/Irreflexive_kernel) of $\leq$), $\geq$ is the dual of $\leq$, and $>$ is the dual of $<$. Strictly speaking, the term *partially ordered set* refers to a set with all of these relations defined appropriately. But practically, one need only consider a single relation, $(P,\leq)$ or $(P,<)$, or, in rare instances, the non-strict and strict relations together, $(P,\leq,<)$.[^o14]

The term *ordered set* is sometimes used as a shorthand for *partially ordered set*, as long as it is clear from the context that no other kind of order is meant. In particular, [totally ordered sets](wikipedia://en/30330) can also be referred to as "ordered sets", especially in areas where these structures are more common than posets. Some authors use different symbols than $\leq$ such as $\sqsubseteq$[^o15] or $\preceq$[^o16] to distinguish partial orders from total orders.

When referring to partial orders, $\leq$ should not be taken as the [complement](https://en.wikipedia.org/wiki/Complementary_relation) of $>$. The relation $>$ is the converse of the irreflexive kernel of $\leq$, which is always a subset of the complement of $\leq$, but $>$ is equal to the complement of $\leq$ [if, and only if](https://en.wikipedia.org/wiki/If,_and_only_if), $\leq$ is a total order.

:::

::: {#o18 .definition cue=heading name="Alternative definitions"}

## Alternative definitions {#Alternative_definitions}

Another way of defining a partial order, found in [computer science](https://en.wikipedia.org/wiki/Computer_science), is via a notion of [comparison](wikipedia://en/3834818). Specifically, given $\leq, <, \geq, \text{ and } >$ as defined previously, it can be observed that two elements *x* and *y* may stand in any of four [mutually exclusive](https://en.wikipedia.org/wiki/Mutually_exclusive) relationships to each other: either *x* \< *y*, or *x* = *y*, or *x* > *y*, or *x* and *y* are *incomparable*. This can be represented by a function $\text{compare}: P \times P \to \{<,>,=,\vert \}$ that returns one of four codes when given two elements.[^o19][^o20] This definition is equivalent to a *partial order on a [setoid](wikipedia://en/769434)*, where equality is taken to be a defined [equivalence relation](wikipedia://en/9259) rather than set equality.[^o21]

Wallis defines a more general notion of a *partial order relation* as any [homogeneous relation](wikipedia://en/12987179) that is [transitive](wikipedia://en/200463) and [antisymmetric](wikipedia://en/1176). This includes both reflexive and irreflexive partial orders as subtypes.[^o22]

A finite poset can be visualized through its [Hasse diagram](wikipedia://en/338199).[^o23] Specifically, taking a strict partial order relation $(P,<)$, a [directed acyclic graph](wikipedia://en/204002) (DAG) may be constructed by taking each element of $P$ to be a node and each element of $<$ to be an edge. The [transitive reduction](wikipedia://en/3757117) of this DAG is then the Hasse diagram. Similarly this process can be reversed to construct strict partial orders from certain DAGs. In contrast, the graph associated to a non-strict partial order has self-loops at every node and therefore is not a DAG; when a non-strict order is said to be depicted by a Hasse diagram, actually the corresponding strict order is shown.

:::

## Examples {#Examples}

*Image: Division relation 4.svg.* **Fig. 3** Graph of the divisibility of numbers from 1 to 4. This set is partially, but not totally, ordered because there is a relationship from 1 to every other number, but there is no relationship from 2 to 3 or 3 to 4

Standard examples of posets arising in mathematics include:

- The [real numbers](wikipedia://en/20646438), or in general any totally ordered set, ordered by the standard *less-than-or-equal* relation ≤, is a partial order.
- On the real numbers $\mathbb{R}$, the usual [less than](https://en.wikipedia.org/wiki/Less_than) relation \< is a strict partial order. The same is also true of the usual [greater than](https://en.wikipedia.org/wiki/Greater_than) relation > on $\mathbb{R}$.
- By definition, every [strict weak order](https://en.wikipedia.org/wiki/Strict_weak_order) is a strict partial order.
- The set of [subsets](wikipedia://en/27631) of a given set (its [power set](wikipedia://en/23799)) ordered by [inclusion](wikipedia://en/27631) (see Fig. 1). Similarly, the set of [sequences](wikipedia://en/27838) ordered by [subsequence](wikipedia://en/236098), and the set of [strings](wikipedia://en/27701) ordered by [substring](https://en.wikipedia.org/wiki/Substring).
- The set of [natural numbers](wikipedia://en/21474) equipped with the relation of [divisibility](wikipedia://en/49492). (see Fig. 3 and Fig. 6)
- The vertex set of a [directed acyclic graph](wikipedia://en/204002) ordered by [reachability](wikipedia://en/2833097).
- The set of [subspaces](wikipedia://en/56357) of a [vector space](wikipedia://en/32370) ordered by inclusion.
- For a partially ordered set *P*, the [sequence space](wikipedia://en/1701075) containing all [sequences](wikipedia://en/27838) of elements from *P*, where sequence *a* precedes sequence *b* if every item in *a* precedes the corresponding item in *b*. Formally, $\left(a_n\right)_{n \in \mathbb{N}} \leq \left(b_n\right)_{n \in \mathbb{N}}$ if and only if $a_n \leq b_n$ for all $n \in \mathbb{N}$; that is, a [componentwise order](https://en.wikipedia.org/wiki/Componentwise_order).
- For a set *X* and a partially ordered set *P*, the [function space](wikipedia://en/340630) containing all functions from *X* to *P*, where *f* ≤ *g* if and only if *f*(*x*) ≤ *g*(*x*) for all $x \in X.$
- A [fence](wikipedia://en/21644788), a partially ordered set defined by an alternating sequence of order relations *a* \< *b* > *c* \< *d* ...
- The set of events in [special relativity](wikipedia://en/26962) and, in most cases, [general relativity](wikipedia://en/12024), where for two events *X* and *Y*, *X* ≤ *Y* if and only if *Y* is in the future [light cone](wikipedia://en/310474) of *X*. An event *Y* can be causally affected by *X* only if *X* ≤ *Y*.

One familiar example of a partially ordered set is a collection of people ordered by [genealogical](https://en.wikipedia.org/wiki/Genealogy) descendancy. Some pairs of people bear the descendant-ancestor relationship, but other pairs of people are incomparable, with neither being a descendant of the other.

### Orders on the Cartesian product of partially ordered sets {#Orders_on_the_Cartesian_product_of_partially_ordered_sets}

In order of increasing strength, i.e., decreasing sets of pairs, three of the possible partial orders on the [Cartesian product](wikipedia://en/24104095) of two partially ordered sets are (see Fig. 4):

- the [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order): (*a*, *b*) ≤ (*c*, *d*) if *a* \< *c* or (*a* = *c* and *b* ≤ *d*);
- the [product order](wikipedia://en/1956306): (*a*, *b*) ≤ (*c*, *d*) if *a* ≤ *c* and *b* ≤ *d*;
- the [reflexive closure](wikipedia://en/22603618) of the [direct product](wikipedia://en/8887#Direct_product_of_binary_relations) of the corresponding strict orders: (*a*, *b*) ≤ (*c*, *d*) if (*a* \< *c* and *b* \< *d*) or (*a* = *c* and *b* = *d*).

All three can similarly be defined for the Cartesian product of more than two sets.

Applied to [ordered vector spaces](wikipedia://en/8099221) over the same [field](wikipedia://en/10603), the result is in each case also an ordered vector space.

See also [orders on the Cartesian product of totally ordered sets](wikipedia://en/30330#Orders_on_the_Cartesian_product_of_totally_ordered_sets).

### Sums of partially ordered sets {#Sums_of_partially_ordered_sets}

Another way to combine two (disjoint) posets is the **ordinal sum**[^o28] (or **linear sum**),[^n2] *Z* = *X* ⊕ *Y*, defined on the union of the underlying sets *X* and *Y* by the order *a* ≤<sub>*Z*</sub> *b* if and only if:

- *a*, *b* ∈ *X* with *a* ≤<sub>*X*</sub> *b*, or
- *a*, *b* ∈ *Y* with *a* ≤<sub>*Y*</sub> *b*, or
- *a* ∈ *X* and *b* ∈ *Y*.

If two posets are [well-ordered](https://en.wikipedia.org/wiki/Well-ordered), then so is their ordinal sum.[^o30]

[Series-parallel partial orders](wikipedia://en/28826384) are formed from the ordinal sum operation (in this context called series composition) and another operation called parallel composition. Parallel composition is the [disjoint union](wikipedia://en/188946) of two partially ordered sets, with no order relation between elements of one set and elements of the other set.

:::

## Derived notions {#Derived_notions}

The examples use the poset $(\mathcal{P}(\{x, y, z\}),\subseteq)$ consisting of the [set of all subsets](wikipedia://en/23799) of a three-element set $\{x, y, z\},$ ordered by set inclusion (see Fig. 1).

- *a* is *related to* *b* when *a* ≤ *b*. This does not imply that *b* is also related to *a*, because the relation need not be [symmetric](wikipedia://en/200459). For example, $\{x\}$ is related to $\{x, y\},$ but not the reverse.
- *a* and *b* are *[comparable](wikipedia://en/3834818)* if *a* ≤ *b* or *b* ≤ *a*. Otherwise they are *incomparable*. For example, $\{x\}$ and $\{x, y, z\}$ are comparable, while $\{x\}$ and $\{y\}$ are not.
- A *[total order](https://en.wikipedia.org/wiki/Totally_ordered_set)* or *linear order* is a partial order under which every pair of elements is comparable, i.e. [trichotomy](https://en.wikipedia.org/wiki/Trichotomy_%28mathematics%29) holds. For example, the natural numbers with their standard order.
- A *[chain](https://en.wikipedia.org/wiki/Chain_%28order_theory%29)* is a subset of a poset that is a totally ordered set. For example, $\{ \{\,\}, \{x\}, \{x, y, z\} \}$ is a chain.
- An *[antichain](wikipedia://en/348973)* is a subset of a poset in which no two distinct elements are comparable. For example, the set of [singletons](wikipedia://en/381798) $\{\{x\}, \{y\}, \{z\}\}.$
- An element *a* is said to be *strictly less than* an element *b*, if *a* ≤ *b* and $a \neq b.$ For example, $\{x\}$ is strictly less than $\{x, y\}.$
- An element *a* is said to be *[covered](wikipedia://en/14835049)* by another element *b*, written *a* ⋖ *b* (or *a* \<: *b*), if *a* is strictly less than *b* and no third element *c* fits between them; formally: if both *a* ≤ *b* and $a \neq b$ are true, and *a* ≤ *c* ≤ *b* is false for each *c* with $a \neq c \neq b.$ Using the strict order \<, the relation *a* ⋖ *b* can be equivalently rephrased as "*a* \< *b* but not *a* \< *c* \< *b* for any *c*". For example, $\{x\}$ is covered by $\{x, z\},$ but is not covered by $\{x, y, z\}.$

### Extrema {#Extrema}

*Image: Hasse diagram of powerset of 3 no greatest or least.svg.* **Fig. 5** The figure above with the greatest and least elements removed. In this reduced poset, the top row of elements are all maximal elements, and the bottom row are all minimal elements, but there is no greatest and no least element.

There are several notions of "greatest" and "least" element in a poset $P,$ notably:

- [Greatest element](https://en.wikipedia.org/wiki/Greatest_element) and least element: An element $g \in P$ is a greatest element if $a \leq g$ for every element $a \in P.$ An element $m \in P$ is a least element if $m \leq a$ for every element $a \in P.$ A poset can only have one greatest or least element. In our running example, the set $\{x, y, z\}$ is the greatest element, and $\{\,\}$ is the least.
- [Maximal elements](https://en.wikipedia.org/wiki/Maximal_element) and minimal elements: An element $g \in P$ is a maximal element if there is no element $a \in P$ such that $a > g.$ Similarly, an element $m \in P$ is a minimal element if there is no element $a \in P$ such that $a < m.$ If a poset has a greatest element, it must be the unique maximal element, but otherwise there can be more than one maximal element, and similarly for least elements and minimal elements. In our running example, $\{x, y, z\}$ and $\{\,\}$ are the maximal and minimal elements. Removing these, there are 3 maximal elements and 3 minimal elements (see Fig. 5).
- [Upper and lower bounds](wikipedia://en/42693): For a subset *A* of *P*, an element *x* in *P* is an upper bound of *A* if *a* ≤ *x*, for each element *a* in *A*. In particular, *x* need not be in *A* to be an upper bound of *A*. Similarly, an element *x* in *P* is a lower bound of *A* if *a* ≥ *x*, for each element *a* in *A*. A greatest element of *P* is an upper bound of *P* itself, and a least element is a lower bound of *P*. In our example, the set $\{x, y\}$ is an upper bound for the collection of elements $\{\{x\}, \{y\}\}.$

*Image: Divisibility\_lattice.svg.* **Fig. 6** A portion of the lattice of [nonnegative integers](https://en.wikipedia.org/wiki/Nonnegative_integer) ordered by divisibility

As another example, consider the positive [integers](wikipedia://en/14563), ordered by divisibility: 1 is a least element, as it [divides](wikipedia://en/49492) all other elements; on the other hand this poset does not have a greatest element. This partially ordered set does not even have any maximal elements, since any *g* divides for instance 2*g*, which is distinct from it, so *g* is not maximal. If the number 1 is excluded, while keeping divisibility as ordering on the elements greater than 1, then the resulting poset does not have a least element, but any [prime number](wikipedia://en/23666) is a minimal element for it. In this poset, 60 is an upper bound (though not a least upper bound) of the subset $\{2, 3, 5, 10\},$ which does not have any lower bound (since 1 is not in the poset); on the other hand 2 is a lower bound of the subset of powers of 2, which does not have any upper bound. If the number 0 is included, this will be the greatest element, since this is a multiple of every integer (see Fig. 6).

## Mappings between partially ordered sets {#Mappings_between_partially_ordered_sets}

Given two partially ordered sets $(S, \le)$ and $(T, \preccurlyeq)$, a function $f : S \to T$ is called **[order-preserving](https://en.wikipedia.org/wiki/Order-preserving)**, or **[monotone](wikipedia://en/48260#In_order_theory)**, or **isotone**, if for all $x, y \in S,$ $x \leq y$ implies $f(x) \preccurlyeq f(y)$. If $(U, \lesssim)$ is also a partially ordered set, and both $f : S \to T$ and $g : T \to U$ are order-preserving, their [composition](wikipedia://en/195947) $g \circ f : S \to U$ is order-preserving, too. A function $f : S \to T$ is called **order-reflecting** if for all $x, y \in S,$ $f(x) \preccurlyeq f(y)$ implies $x \leq y.$ If $f$ is both order-preserving and order-reflecting, then it is called an **[order-embedding](https://en.wikipedia.org/wiki/Order-embedding)** of $(S, \le)$ into $(T, \preccurlyeq)$. In the latter case, $f$ is necessarily [injective](https://en.wikipedia.org/wiki/Injective), since $f(x) = f(y)$ implies $x \leq y \text{ and } y \leq x$ and in turn $x = y$ according to the antisymmetry of $\leq.$ If an order-embedding between two posets *S* and *T* exists, one says that *S* can be **embedded** into *T*. If an order-embedding $f : S \to T$ is [bijective](https://en.wikipedia.org/wiki/Bijective), it is called an **[order isomorphism](wikipedia://en/23916899)**, and the partial orders $(S, \le)$ and $(T, \preccurlyeq)$ are said to be **isomorphic**. Isomorphic orders have structurally similar [Hasse diagrams](wikipedia://en/338199) (see Fig. 7a). It can be shown that if order-preserving maps $f : S \to T$ and $g : T \to U$ exist such that $g \circ f$ and $f \circ g$ yields the [identity function](wikipedia://en/15069) on *S* and *T*, respectively, then *S* and *T* are order-isomorphic.[^n3]

For example, a mapping $f : \mathbb{N} \to \mathbb{P}(\mathbb{N})$ from the set of natural numbers (ordered by divisibility) to the [power set](wikipedia://en/23799) of natural numbers (ordered by set inclusion) can be defined by taking each number to the set of its [prime divisors](https://en.wikipedia.org/wiki/Prime_divisor). It is order-preserving: if $x$ divides $y$, then each prime divisor of $x$ is also a prime divisor of $y$. However, it is neither injective (since it maps both 12 and 6 to $\{2, 3\}$) nor order-reflecting (since 12 does not divide 6). Taking instead each number to the set of its [prime power](wikipedia://en/1630483) divisors defines a map $g : \mathbb{N} \to \mathbb{P}(\mathbb{N})$ that is order-preserving, order-reflecting, and hence an order-embedding. It is not an order-isomorphism (since it, for instance, does not map any number to the set $\{4\}$), but it can be made one by [restricting its codomain](wikipedia://en/45196#Injections_may_be_made_invertible) to $g(\mathbb{N}).$ Fig. 7b shows a subset of $\mathbb{N}$ and its isomorphic image under $g$. The construction of such an order-isomorphism into a power set can be generalized to a wide class of partial orders, called [distributive lattices](wikipedia://en/310883); see *[Birkhoff's representation theorem](wikipedia://en/20489385)*.

## Subposets {#Subposets}

A poset $P^*=(X^*, \leq^*)$ is called a **subposet** of another poset $P=(X, \leq)$ provided that $X^*$ is a [subset](wikipedia://en/27631) of $X$ and $\leq^*$ is a subset of $\leq$. The latter condition is equivalent to the requirement that for any $x$ and $y$ in $X^*$ (and thus also in $X$), if $x \leq^* y$ then $x \leq y$.

If $P^*$ is a subposet of $P$ and furthermore, for all $x$ and $y$ in $X^*$, whenever $x \leq y$ we also have $x \leq^* y$, then we call $P^*$ the subposet of $P$ **induced** by $X^*$, and write $P^* = P[X^*]$.

## Linear extension {#Linear_extension}

A partial order $\leq^*$ on a set $X$ is called an **extension** of another partial order $\leq$ on $X$ provided that for all elements $x, y \in X,$ whenever $x \leq y,$ it is also the case that $x \leq^* y.$ A [linear extension](wikipedia://en/11726298) is an extension that is also a linear (that is, total) order. As a classic example, the lexicographic order of totally ordered sets is a linear extension of their product order. Every partial order can be extended to a total order ([order-extension principle](https://en.wikipedia.org/wiki/Order-extension_principle)).[^o38]

In [computer science](https://en.wikipedia.org/wiki/Computer_science), algorithms for finding linear extensions of partial orders (represented as the [reachability](wikipedia://en/2833097) orders of [directed acyclic graphs](wikipedia://en/204002)) are called [topological sorting](wikipedia://en/897064).

## In category theory {#In_category_theory}

Every poset (and every [preordered set](wikipedia://en/23582)) may be considered as a [category](wikipedia://en/53759) where, for objects $x$ and $y,$ there is at most one [morphism](wikipedia://en/27716891) from $x$ to $y.$ More explicitly, let hom(*x*, *y*) = $\{(x, y)\}$ if *x* ≤ *y* (and otherwise the [empty set](wikipedia://en/9566)) and $(y, z) \circ (x, y) = (x, z).$ Such categories are sometimes called *[thin](wikipedia://en/31353487)*.

Posets are [equivalent](wikipedia://en/379051) to one another if and only if they are [isomorphic](wikipedia://en/489935). In a poset, the smallest element, if it exists, is an [initial object](https://en.wikipedia.org/wiki/Initial_object), and the largest element, if it exists, is a [terminal object](https://en.wikipedia.org/wiki/Terminal_object). Also, every preordered set is equivalent to a poset. Finally, every subcategory of a poset is [isomorphism-closed](https://en.wikipedia.org/wiki/Isomorphism-closed).

:::

## Partial orders in topological spaces {#Partial_orders_in_topological_spaces}

If $P$ is a partially ordered set that has also been given the structure of a [topological space](wikipedia://en/30450), then it is customary to assume that $\{ (a,b) : a \le b \}$ is a [closed](https://en.wikipedia.org/wiki/Closed_%28mathematics%29) subset of the topological [product space](https://en.wikipedia.org/wiki/Product_space) $P \times P.$ Under this assumption partial order relations are well behaved at [limits](wikipedia://en/285773) in the sense that if $\lim_{i \to \infty} a_i = a,$ and $\lim_{i \to \infty} b_i = b,$ and for all $i,$ $a_i \leq b_i,$ then $a \leq b.$[^o42]

## Intervals {#Intervals}

A **convex set** in a poset *P* is a subset $I$ of *P* with the property that, for any *x* and *y* in $I$ and any *z* in *P*, if *x* ≤ *z* ≤ *y*, then *z* is also in $I$. This definition generalizes the definition of [intervals](wikipedia://en/49172) of [real numbers](wikipedia://en/20646438). When there is possible confusion with [convex sets](wikipedia://en/6292) of [geometry](wikipedia://en/18973446), one uses **order-convex** instead of "convex".

A **convex sublattice** of a [lattice](https://en.wikipedia.org/wiki/Lattice_%28order_theory%29) *L* is a sublattice of *L* that is also a convex set of *L*. Every nonempty convex sublattice can be uniquely represented as the intersection of a [filter](wikipedia://en/19719) and an [ideal](wikipedia://en/530559) of *L*.

An **interval** in a poset *P* is a subset that can be defined with interval notation:

- For *a* ≤ *b*, the *closed interval* *a*, *b* is the set of elements *x* satisfying *a* ≤ *x* ≤ *b* (that is, *a* ≤ *x* and *x* ≤ *b*). It contains at least the elements *a* and *b*.
- Using the corresponding strict relation "\<", the *open interval* *a*, *b* is the set of elements *x* satisfying *a* \< *x* \< *b* (i.e. *a* \< *x* and *x* \< *b*). An open interval may be empty even if *a* \< *b*. For example, the open interval 0, 1 on the integers is empty since there is no integer $x$ such that $0 < x < 1$.
- The *half-open intervals* *a*, *b* and *a*, *b* are defined similarly.

Whenever *a* ≤ *b* does not hold, all these intervals are empty. Every interval is a convex set, but the converse does not hold; for example, in the poset of divisors of 120, ordered by divisibility (see Fig. 7b), the set $\{1, 2, 4, 5, 8\}$ is convex, but not an interval.

An interval $I$ is bounded if there exist elements $a, b \in P$ such that $I \subseteq [a, b]$. Every interval that can be represented in interval notation is obviously bounded, but the converse is not true. For example, let $P = (0, 1) \cup (1, 2) \cup (2, 3)$ as a subposet of the real numbers. The subset 1, 2 is a bounded interval, but it has no [infimum](https://en.wikipedia.org/wiki/Infimum) or [supremum](https://en.wikipedia.org/wiki/Supremum) in *P*, so it cannot be written in interval notation using elements of *P*.

A poset is called [locally finite](wikipedia://en/19357321) if every bounded interval is finite. For example, the integers are locally finite under their natural ordering. The lexicographical order on the cartesian product $\mathbb{N} \times \mathbb{N}$ is not locally finite, since $(1, 2) \le (1, 3) \le (1, 4) \le (1, 5) \le ... \le (2, 1)$. Using the interval notation, the property "*a* is covered by *b*" can be rephrased equivalently as $[a, b] = \{a, b\}.$

This concept of an interval in a partial order should not be confused with the particular class of partial orders known as the [interval orders](wikipedia://en/11680645).
