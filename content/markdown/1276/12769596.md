# Sparse language

::: {#o1 .subject cue=lead name="Sparse language"}

In [computational complexity theory](wikipedia://en/7543), a **sparse language** is a [formal language](wikipedia://en/10939) (a set of [strings](wikipedia://en/27701)) such that the [complexity function](https://en.wikipedia.org/wiki/Complexity_function), counting the number of strings of length *n* in the language, is bounded by a [polynomial](wikipedia://en/23000) function of *n*. They are used primarily in the study of the relationship of the complexity class **[NP](wikipedia://en/21562)** with other classes. The [complexity class](wikipedia://en/502426) of all sparse languages is called **SPARSE**.

:::

All [unary languages](wikipedia://en/12769341) are sparse, trivially. Consequently, the concept of sparse language is usually only used for languages with at least 2 letters.

Sparse languages are called *sparse* because over some finite alphabet $\Sigma$ there are ${|\Sigma|}^n$ strings of length *n*. So, when the language is not unary, the probability of a uniformly randomly sampled length-*n* string belongs to the language converges exponentially to 0

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

For any fixed integer *k*, Consider the set of binary strings containing exactly *k* repeats of the bit $1$. For each *n*, there are only [$\binom{n}{k} \lesssim n^k$](wikipedia://en/4668) strings in the language. Thus it is sparse.

:::

## Relationships to other complexity classes {#Relationships_to_other_complexity_classes}

- **SPARSE** contains **TALLY**, the class of [unary languages](wikipedia://en/12769341), since these have at most one string of any one length.
- **[E](wikipedia://en/663674)** ≠ **[NE](wikipedia://en/663673)** if and only if there exist sparse languages in **NP** that are not in **P**.[^o5]
- If any sparse language is NP-hard with respect to [Turing reductions](wikipedia://en/1188375), then [**PH**](wikipedia://en/658651) collapses to $\Delta^P_2$. This is a consequence of the [Karp–Lipton theorem](wikipedia://en/2855729).[^o6] This result was improved in 2005, showing that **PH** collapses further than $\Delta^P_2$.[^o7]

::: {#o9 .statement kind=statement/theorem cue=named-heading name="Mahaney's theorem"}

### Mahaney's theorem {#Mahaney's_theorem}

(Fortune, 1979) showed that if any sparse language is [**co-NP**-complete](wikipedia://en/54680), then [**P** = **NP**](https://en.wikipedia.org/wiki/P_=_NP_problem).[^o10] (Mahaney, 1982) used this to prove [Mahaney's theorem](wikipedia://en/47241003) that if any sparse language is [**NP**-complete](https://en.wikipedia.org/wiki/NP-complete), then **P** = **NP**.[^o11] Mahaney's argument does not actually require the sparse language to be in NP (because the existence of an NP-hard sparse set implies the existence of an NP-complete sparse set), so there is a sparse [**NP**-hard](https://en.wikipedia.org/wiki/NP-hard) set if and only if **P** = **NP**.[^o12]

(Ogihara and Watanabe, 1991) gives a simplified proof of Mahaney's theorem based on left-sets.[^o13]

(Jin-Yi Cai and D. Sivakumar, 1999), building on work by Ogihara, showed that, if there exists a sparse language that is [**P**-complete](wikipedia://en/54683) under [logspace (many-one) reduction](wikipedia://en/1174850), then **[L](wikipedia://en/1149999)** = **[P](wikipedia://en/658550)**.[^o14]

:::

### P/poly {#P/poly}

Although not all languages in [**P**/poly](wikipedia://en/2052415) are sparse, there is a [polynomial-time Turing reduction](https://en.wikipedia.org/wiki/Polynomial-time_Turing_reduction) from any language in **P**/poly to a sparse language.[^o16]

There is a [Turing reduction](wikipedia://en/1188375) (as opposed to the [Karp reduction](https://en.wikipedia.org/wiki/Karp_reduction) from Mahaney's theorem) from an **NP**-complete language to a sparse language if and only if $\textbf{NP}\subseteq \textbf{P}/\text{poly}$.
