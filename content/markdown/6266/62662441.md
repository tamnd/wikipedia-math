# Schwarz function

::: {#o1 .subject cue=lead name="Schwarz function"}

The **Schwarz function** of a curve in the [complex plane](wikipedia://en/217628) is an [analytic function](https://en.wikipedia.org/wiki/Complex_analytic_function) which maps the points of the curve to their [complex conjugates](wikipedia://en/173918). It can be used to generalize the [Schwarz reflection principle](wikipedia://en/3213223) to reflection across arbitrary [analytic curves](https://en.wikipedia.org/wiki/Analytic_curve), not just across the real axis.

:::

The Schwarz function exists for analytic curves. More precisely, for every non-singular, analytic [Jordan arc](https://en.wikipedia.org/wiki/Jordan_arc) $\Gamma$ in the complex plane, there is an [open neighborhood](https://en.wikipedia.org/wiki/Open_neighborhood) $\Omega$ of $\Gamma$ and a unique analytic function $S$ on $\Omega$ such that $S(z) = \overline{z}$ for every $z \in \Gamma$.[^o2]

The "Schwarz function" was named by [Philip J. Davis](wikipedia://en/3753768) and [Henry O. Pollak](wikipedia://en/19662367) (1958) in honor of [Hermann Schwarz](wikipedia://en/3165834),[^o3][^o4] who introduced the Schwarz reflection principle for analytic curves in 1870.[^o5] However, the Schwarz function does not explicitly appear in Schwarz's works.[^o6]

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

The unit circle is described by the equation $|z|^2 = 1$, or $\overline{z} = 1/z$. Thus, the Schwarz function of the unit circle is $S(z) = 1/z$.

A more complicated example is an [ellipse](wikipedia://en/9277) defined by $(x/a)^2 + (y/b)^2 = 1$. The Schwarz function can be found by substituting $\textstyle x = \frac{z + \overline{z}}{2}$ and $\textstyle y = \frac{z - \overline{z}}{2i}$ and solving for $\overline{z}$. The result is:[^o9]

$$S(z) = \frac{1}{a^2-b^2} \left( (a^2+b^2)z - 2ab\sqrt{z^2+b^2-a^2} \right).$$

This is analytic on the complex plane minus a [branch cut](https://en.wikipedia.org/wiki/Branch_cut) along the line segment between the [foci](wikipedia://en/1032607) $\pm \sqrt{a^2-b^2}$.

:::
