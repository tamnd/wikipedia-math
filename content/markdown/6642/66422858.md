# Alternative semantics

::: {#o1 .subject cue=lead name="Alternative semantics"}

**Alternative semantics** (or **Hamblin semantics**) is a framework in [formal semantics](wikipedia://en/31395652) and [logic](wikipedia://en/46426065). In alternative semantics, expressions [denote](https://en.wikipedia.org/wiki/Denotation) *alternative sets*, understood as sets of objects of the same [semantic type](wikipedia://en/40282). For instance, while the word "Lena" might denote Lena herself in a classical semantics, it would denote the singleton set containing Lena in alternative semantics. The framework was introduced by [Charles Leonard Hamblin](wikipedia://en/19501790) in 1973 as a way of extending [Montague grammar](wikipedia://en/709308) to provide an analysis for [questions](https://en.wikipedia.org/wiki/Questions). In this framework, a question denotes the set of its possible answers. Thus, if $P$ and $Q$ are [propositions](wikipedia://en/81094), then $\{P,Q\}$ is the denotation of the question whether $P$ or $Q$ is true. Since the 1970s, it has been extended and adapted to analyze phenomena including [focus](https://en.wikipedia.org/wiki/Focus_%28linguistics%29),[^o2] [scope](wikipedia://en/65142269), [disjunction](https://en.wikipedia.org/wiki/Disjunction),[^o3] [NPIs](https://en.wikipedia.org/wiki/Negative_polarity_item),[^o4][^o5] [presupposition](wikipedia://en/1965727), and [implicature](wikipedia://en/393671).[^o6][^o7]

:::
