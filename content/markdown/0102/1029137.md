# Eigenplane

::: {#o1 .subject cue=lead name="Eigenplane"}

In [mathematics](wikipedia://en/18831), an **eigenplane** is a two-dimensional [invariant subspace](wikipedia://en/585826) in a given [vector space](wikipedia://en/32370).[^o2] By analogy with the term *[eigenvector](https://en.wikipedia.org/wiki/Eigenvector)* for a vector which, when operated on by a [linear operator](https://en.wikipedia.org/wiki/Linear_transformation) is another vector which is a [scalar](wikipedia://en/3588331) multiple of itself, the term ***eigenplane*** can be used to describe a two-dimensional [plane](wikipedia://en/19469852) (a *2-plane*), such that the operation of a [linear operator](https://en.wikipedia.org/wiki/Linear_transformation) on a vector in the 2-plane always yields another vector in the same 2-plane.

:::

A particular case that has been studied is that in which the linear operator is an [isometry](wikipedia://en/254777) *M* of the [hypersphere](https://en.wikipedia.org/wiki/Hypersphere) (written *S<sup>3</sup>*) represented within four-dimensional [Euclidean space](wikipedia://en/9697):

$$M \; [ \mathbf{s} \; \mathbf{t} ] \; = \; [ \mathbf{s} \; \mathbf{t} ] \Lambda_\theta$$

where **s** and **t** are four-dimensional column vectors and Λ<sub>θ</sub> is a two-dimensional **eigenrotation** within the **eigenplane**.

In the usual [eigenvector](https://en.wikipedia.org/wiki/Eigenvector) problem, there is freedom to multiply an eigenvector by an arbitrary scalar; in this case there is freedom to multiply by an arbitrary non-zero [rotation](wikipedia://en/39789).

This case is potentially physically interesting in the case that the [shape of the universe](https://en.wikipedia.org/wiki/Shape_of_the_universe) is a [multiply connected](https://en.wikipedia.org/wiki/Multiply_connected) [3-manifold](wikipedia://en/1018257), since finding the [angles](wikipedia://en/1196) of the eigenrotations of a candidate isometry for [topological lensing](https://en.wikipedia.org/wiki/Shape_of_the_universe) is a way to [falsify](https://en.wikipedia.org/wiki/Scientific_method) such hypotheses.
