# Positive set theory

::: {#o1 .subject cue=lead name="Positive set theory"}

In [mathematical logic](wikipedia://en/19636), **positive set theory** is the name for a class of alternative [set theories](wikipedia://en/27553) in which the [axiom of comprehension](https://en.wikipedia.org/wiki/Axiom_of_comprehension) holds for at least the **positive formulas** $\phi$ (the smallest class of formulas containing atomic membership and equality formulas and closed under conjunction, disjunction, existential and [universal quantification](wikipedia://en/76174)).

:::

Typically, the motivation for these theories is topological: the sets are the classes which are closed under a certain [topology](wikipedia://en/29954). The closure conditions for the various constructions allowed in building positive formulas are readily motivated (and one can further justify the use of universal quantifiers bounded in sets to get **generalized positive comprehension**): the justification of the existential quantifier seems to require that the topology be [compact](https://en.wikipedia.org/wiki/Compact_spaces).

::: {#o3 .statement kind=statement/axiom cue=named-heading name="Axioms"}

## Axioms {#Axioms}

The set theory $\mathrm{GPK}^+_\infty$ of Olivier Esser consists of the following axioms:[^o4]

### [Extensionality](wikipedia://en/52376) {#Extensionality}

$$\forall x \forall y (\forall z (z \in x \leftrightarrow z \in y) \to x = y)$$

### Positive [comprehension](https://en.wikipedia.org/wiki/Axiom_of_comprehension) {#Positive_comprehension}

$$\exists x \forall y (y \in x \leftrightarrow \phi(y))$$

where $\phi$ is a *positive formula*. A positive formula uses only the [logical constants](https://en.wikipedia.org/wiki/Logical_constants) $\{\top, \bot, \land, \lor, \forall, \exists, =, \in\}$ but not $\{\to, \neg\}$.

### [Closure](https://en.wikipedia.org/wiki/Topological_closure) {#Closure}

$$\exists x \forall y (y \in x \leftrightarrow \forall z (\forall w (\phi(w) \rightarrow w \in z) \rightarrow y \in z))$$

where $\phi$ is a formula. That is, for every formula $\phi$, the intersection of all sets which contain every $x$ such that $\phi(x)$ exists. This is called the closure of $\{x \mid \phi(x)\}$ and is written in any of the various ways that topological closures can be presented. This can be put more briefly if class language is allowed (any condition on sets defining a class as in [NBG](wikipedia://en/528491)): for any class *C* there is a set which is the intersection of all sets which contain *C* as a subclass. This is a reasonable principle if the sets are understood as closed classes in a topology.

### [Infinity](wikipedia://en/246449) {#Infinity}

The [von Neumann](wikipedia://en/15942) [ordinal](wikipedia://en/26547932) $\omega$ exists. This is not an axiom of infinity in the usual sense; if Infinity does not hold, the closure of $\omega$ exists and has itself as its sole additional member (it is certainly infinite); the point of this axiom is that $\omega$ contains no additional elements at all, which boosts the theory from the strength of second order arithmetic to the strength of [Morse–Kelley set theory](wikipedia://en/2693655) with the [proper class](wikipedia://en/20696) ordinal a [weakly compact cardinal](wikipedia://en/272054).

:::

## Interesting properties {#Interesting_properties}

- The [universal set](wikipedia://en/303405) is a proper set in this theory.
- The sets of this theory are the collections of sets which are closed under a certain [topology](wikipedia://en/29954) on the classes.
- The theory can interpret [ZFC](https://en.wikipedia.org/wiki/ZFC) (by restricting oneself to the class of well-founded sets, which is not itself a set). It in fact interprets a stronger theory ([Morse–Kelley set theory](wikipedia://en/2693655) with the proper class ordinal a [weakly compact cardinal](wikipedia://en/272054)).
