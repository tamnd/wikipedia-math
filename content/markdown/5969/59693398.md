# Adiantum (cipher)

::: {#o2 .subject cue=lead name="Adiantum"}

**Adiantum** is a [cipher](wikipedia://en/5244) composition for [disk encryption](wikipedia://en/7066791). It uses a new cipher construction called HBSH (hash, block cipher, stream cipher, hash), specifically choosing [NH](wikipedia://en/2005331#NH), 256-bit [Advanced Encryption Standard](wikipedia://en/1260) (AES-256), (X)[ChaCha12](wikipedia://en/2701329#Reduced-round_ChaCha)/[ChaCha20](wikipedia://en/2701329#ChaCha_variant), [Poly1305](wikipedia://en/2017690) for the four elements.[^o8] The version in Linux kernel preferentially uses XChaCha12, xchacha12,aes-adiantum.[^o3]

:::

It was designed in 2018 by Paul Crowley and Eric Biggers at [Google](https://en.wikipedia.org/wiki/Google) specifically for low-powered mobile devices running [Android Go](https://en.wikipedia.org/wiki/Android_Go). It has been included in the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel) since version 5.0.[^o4] The construct is designed to be "wide-block", where any change in the plaintext causes the entire ciphertext to be unrecognizably changed.[^o5]

Adiantum is implemented in [Android 10](https://en.wikipedia.org/wiki/Android_10) as an alternative cipher for device encryption, particularly on low-end devices lacking hardware-accelerated support for AES. (Adiantum only invokes AES once per plaintext.) The company stated that Adiantum ran five times faster than AES-256-XTS on [ARM Cortex-A7](https://en.wikipedia.org/wiki/ARM_Cortex-A7) CPUs.[^o8] Google had previously exempted devices from mandatory device encryption if their specifications affected system performance if enabled. Due to the introduction of Adiantum, device encryption becomes mandatory on all Android devices beginning on Android 10.[^o6][^o7]

**HPolyC** is an earlier variant which does not use NH.[^o8]
