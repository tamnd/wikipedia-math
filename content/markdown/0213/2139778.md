# Ordination (statistics)

::: {#o1 .subject cue=lead name="Ordination"}

**Ordination** or **gradient analysis**, in [multivariate analysis](https://en.wikipedia.org/wiki/Multivariate_analysis), is a method complementary to [data clustering](wikipedia://en/669675), and used mainly in [exploratory data analysis](wikipedia://en/416589) (rather than in [hypothesis testing](wikipedia://en/30284)). In contrast to cluster analysis, ordination [orders](wikipedia://en/23572) quantities in a (usually lower-dimensional) latent space. In the ordination space, quantities that are near each other share attributes (i.e., are similar to some degree), and dissimilar objects are farther from each other. Such relationships between the objects, on each of several axes or [latent variables](wikipedia://en/2649330), are then characterized numerically and/or graphically in a [biplot](wikipedia://en/14306166).

:::

The first ordination method, [principal components analysis](https://en.wikipedia.org/wiki/Principal_components_analysis), was suggested by Karl Pearson in 1901.

::: {#o3 .definition kind=definition/construction cue=heading name="Methods"}

## Methods {#Methods}

Ordination methods can broadly be categorized in eigenvector-, algorithm-, or model-based methods. Many classical ordination techniques, including principal components analysis, [correspondence analysis](wikipedia://en/11594341) (CA) and its derivatives ([detrended correspondence analysis](wikipedia://en/18379199), canonical correspondence analysis, and [redundancy analysis](https://en.wikipedia.org/wiki/Redundancy_analysis), belong to the first group).

The second group includes some distance-based methods such as non-metric [multidimensional scaling](wikipedia://en/398786), and machine learning methods such as [T-distributed stochastic neighbor embedding](https://en.wikipedia.org/wiki/T-distributed_stochastic_neighbor_embedding) and [nonlinear dimensionality reduction](wikipedia://en/309261).

The third group includes model-based ordination methods, which can be considered as multivariate extensions of [Generalized Linear Models](wikipedia://en/747122).[^o4][^o5][^o6][^o7] Model-based ordination methods are more flexible in their application than classical ordination methods, so that it is for example possible to include random-effects.[^o8] Unlike in the aforementioned two groups, there is no (implicit or explicit) distance measure in the ordination. Instead, a distribution needs to be specified for the responses as is typical for statistical models. These and other assumptions, such as the assumed mean-variance relationship, can be validated with the use of residual diagnostics, unlike in other ordination methods.

:::

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

Ordination can be used on the analysis of any set of multivariate objects. It is frequently used in several environmental or ecological sciences, particularly plant [community ecology](https://en.wikipedia.org/wiki/Community_ecology). It is also used in [genetics](https://en.wikipedia.org/wiki/Genetics) and [systems biology](https://en.wikipedia.org/wiki/Systems_biology) for [microarray](https://en.wikipedia.org/wiki/Microarray) data analysis and in [psychometrics](wikipedia://en/24982).

:::
