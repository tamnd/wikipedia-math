# Prewellordering

::: {#o1 .subject cue=lead name="Prewellordering"}

In [set theory](wikipedia://en/27553), a **prewellordering** on a [set](wikipedia://en/26691) $X$ is a [preorder](wikipedia://en/23582) $\leq$ on $X$ (a [transitive](wikipedia://en/200463) and [reflexive](wikipedia://en/200458) relation on $X$) that is [strongly connected](https://en.wikipedia.org/wiki/Strongly_connected_relation) (meaning that any two points are comparable) and [well-founded](wikipedia://en/319712) in the sense that the induced relation $x < y$ defined by $x \leq y \text{ and } y \nleq x$ is a [well-founded relation](wikipedia://en/319712).

:::

## Prewellordering on a set {#Prewellordering_on_a_set}

A **prewellordering** on a [set](wikipedia://en/26691) $X$ is a [homogeneous binary relation](https://en.wikipedia.org/wiki/Homogeneous_binary_relation) $\,\leq\,$ on $X$ that satisfies the following conditions:[^n1]

[Reflexivity](wikipedia://en/200458): $x \leq x$ for all $x \in X.$ [Transitivity](wikipedia://en/200463): if $x < y$ and $y < z$ then $x < z$ for all $x, y, z \in X.$ [Total/Strongly connected](https://en.wikipedia.org/wiki/Strongly_connected_relation): $x \leq y$ or $y \leq x$ for all $x, y \in X.$ for every non-empty subset $S \subseteq X,$ there exists some $m \in S$ such that $m \leq s$ for all $s \in S.$

This condition is equivalent to the induced strict preorder $x < y$ defined by $x \leq y$ and $y \nleq x$ being a [well-founded relation](wikipedia://en/319712).

A [homogeneous binary relation](https://en.wikipedia.org/wiki/Homogeneous_binary_relation) $\,\leq\,$ on $X$ is a prewellordering if and only if there exists a [surjection](https://en.wikipedia.org/wiki/Surjection) $\pi : X \to Y$ into a [well-ordered set](https://en.wikipedia.org/wiki/Well-ordered_set) $(Y, \lesssim)$ such that for all $x, y \in X,$ $x \leq y$ if and only if $\pi(x) \lesssim \pi(y).$[^n1]

Given a set $A,$ the binary relation on the set $X := \operatorname{Finite}(A)$ of all finite subsets of $A$ defined by $S \leq T$ if and only if $|S| \leq |T|$ (where $|\cdot|$ denotes the set's [cardinality](wikipedia://en/6174)) is a prewellordering.[^n1]

### Properties {#Properties}

If $\leq$ is a prewellordering on $X,$ then the relation $\sim$ defined by

$$x \sim y \text{ if and only if } x \leq y \land y \leq x$$

is an [equivalence relation](wikipedia://en/9259) on $X,$ and $\leq$ induces a [wellordering](https://en.wikipedia.org/wiki/Wellordering) on the [quotient](https://en.wikipedia.org/wiki/Quotient_set) $X / {\sim}.$ The [order-type](https://en.wikipedia.org/wiki/Order-type) of this induced wellordering is an [ordinal](wikipedia://en/26547932), referred to as the **length** of the prewellordering.

A **norm** on a set $X$ is a map from $X$ into the ordinals. Every norm induces a prewellordering; if $\phi : X \to Ord$ is a norm, the associated prewellordering is given by

$$x \leq y \text{ if and only if } \phi(x) \leq \phi(y)$$

Conversely, every prewellordering is induced by a unique **regular norm** (a norm $\phi : X \to Ord$ is regular if, for any $x \in X$ and any $\alpha < \phi(x),$ there is $y \in X$ such that $\phi(y) = \alpha$).

:::

## Prewellordering property {#Prewellordering_property}

If $\boldsymbol{\Gamma}$ is a [pointclass](wikipedia://en/9304834) of subsets of some collection $\mathcal{F}$ of [Polish spaces](wikipedia://en/396622), $\mathcal{F}$ closed under [Cartesian product](wikipedia://en/24104095), and if $\leq$ is a prewellordering of some subset $P$ of some element $X$ of $\mathcal{F},$ then $\leq$ is said to be a $\boldsymbol{\Gamma}$-**prewellordering** of $P$ if the relations $<^*$ and $\leq^*$ are elements of $\boldsymbol{\Gamma},$ where for $x, y \in X,$

1. $$x <^* y \text{ if and only if } x \in P \land (y \notin P \lor (x \leq y \land y \not\leq x))$$
1. $$x \leq^* y \text{ if and only if } x \in P \land (y \notin P \lor x \leq y)$$

$\boldsymbol{\Gamma}$ is said to have the **prewellordering property** if every set in $\boldsymbol{\Gamma}$ admits a $\boldsymbol{\Gamma}$-prewellordering.

The prewellordering property is related to the stronger [scale property](https://en.wikipedia.org/wiki/Scale_property); in practice, many pointclasses having the prewellordering property also have the scale property, which allows drawing stronger conclusions.

::: {#o13 .example cue=heading name="Examples"}

### Examples {#Examples}

$\boldsymbol{\Pi}^1_1$ and $\boldsymbol{\Sigma}^1_2$ both have the prewellordering property; this is provable in [ZFC](wikipedia://en/152214) alone. Assuming sufficient [large cardinals](wikipedia://en/383644), for every $n \in \omega,$ $\boldsymbol{\Pi}^1_{2n+1}$ and $\boldsymbol{\Sigma}^1_{2n+2}$ have the prewellordering property.

:::

### Consequences {#Consequences}

#### Reduction {#Reduction}

If $\boldsymbol{\Gamma}$ is an [adequate pointclass](wikipedia://en/10192324) with the prewellordering property, then it also has the **reduction property**: For any space $X \in \mathcal{F}$ and any sets $A, B \subseteq X,$ $A$ and $B$ both in $\boldsymbol{\Gamma},$ the union $A \cup B$ may be partitioned into sets $A^*, B^*,$ both in $\boldsymbol{\Gamma},$ such that $A^* \subseteq A$ and $B^* \subseteq B.$

#### Separation {#Separation}

If $\boldsymbol{\Gamma}$ is an [adequate pointclass](wikipedia://en/10192324) whose [dual pointclass](https://en.wikipedia.org/wiki/Dual_pointclass) has the prewellordering property, then $\boldsymbol{\Gamma}$ has the **separation property**: For any space $X \in \mathcal{F}$ and any sets $A, B \subseteq X,$ $A$ and $B$ *disjoint* sets both in $\boldsymbol{\Gamma},$ there is a set $C \subseteq X$ such that both $C$ and its [complement](wikipedia://en/54347) $X \setminus C$ are in $\boldsymbol{\Gamma},$ with $A \subseteq C$ and $B \cap C = \varnothing.$

For example, $\boldsymbol{\Pi}^1_1$ has the prewellordering property, so $\boldsymbol{\Sigma}^1_1$ has the separation property. This means that if $A$ and $B$ are disjoint [analytic](wikipedia://en/634261) subsets of some Polish space $X,$ then there is a [Borel](wikipedia://en/43327) subset $C$ of $X$ such that $C$ includes $A$ and is disjoint from $B.$

:::
