# Finite morphism

::: {#o1 .subject cue=lead name="Finite morphism"}

In [algebraic geometry](wikipedia://en/1997), a **finite morphism** between two [affine varieties](wikipedia://en/320468) $X, Y$ is a dense [regular map](https://en.wikipedia.org/wiki/Regular_map_%28algebraic_geometry%29) which induces isomorphic inclusion $k\left[Y\right]\hookrightarrow k\left[X\right]$ between their [coordinate rings](https://en.wikipedia.org/wiki/Coordinate_ring), such that $k\left[X\right]$ is [integral over](https://en.wikipedia.org/wiki/Integral_over) $k\left[Y\right]$.[^n1] This definition can be extended to the [quasi-projective varieties](https://en.wikipedia.org/wiki/Quasi-projective_varieties), such that a [regular map](https://en.wikipedia.org/wiki/Regular_map_%28algebraic_geometry%29) $f\colon X\to Y$ between quasiprojective varieties is **finite** if any point $y\in Y$ has an affine neighbourhood V such that $U=f^{-1}(V)$ is affine and $f\colon U\to V$ is a finite map (in view of the previous definition, because it is between affine varieties).[^n2]

:::

## Definition by schemes {#Definition_by_schemes}

A morphism *f*: *X* → *Y* of [schemes](wikipedia://en/364754) is a finite morphism if *Y* has an [open cover](https://en.wikipedia.org/wiki/Open_cover) by [affine schemes](https://en.wikipedia.org/wiki/Affine_schemes)

$$V_i = \mbox{Spec} \; B_i$$

such that for each *i*,

$$f^{-1}(V_i) = U_i$$

is an open affine subscheme Spec *A*<sub>*i*</sub>, and the restriction of *f* to *U*<sub>*i*</sub>, which induces a [ring homomorphism](wikipedia://en/26411)

$$B_i \rightarrow A_i,$$

makes *A*<sub>*i*</sub> a [finitely generated module](wikipedia://en/326430) over *B*<sub>*i*</sub> (in other words, a [finite *B*<sub>*i*</sub>-algebra](wikipedia://en/62856263)).[^n3] One also says that *X* is **finite** over *Y*.

In fact, *f* is finite if and only if for *every* open affine subscheme *V* = Spec *B* in *Y*, the inverse image of *V* in *X* is affine, of the form Spec *A*, with *A* a finitely generated *B*-module.[^o6]

For example, for any [field](wikipedia://en/10603) *k*, $\text{Spec}(k[t,x]/(x^n-t)) \to \text{Spec}(k[t])$ is a finite morphism since $k[t,x]/(x^n-t) \cong k[t]\oplus k[t]\cdot x \oplus\cdots \oplus k[t]\cdot x^{n-1}$ as $k[t]$-modules. Geometrically, this is obviously finite since this is a ramified n-sheeted cover of the affine line which degenerates at the origin. By contrast, the inclusion of *A*<sup>1</sup> − 0 into *A*<sup>1</sup> is not finite. (Indeed, the [Laurent polynomial](wikipedia://en/61351) ring *k*\[*y*, *y*<sup>−1</sup>\] is not finitely generated as a module over *k*\[*y*\].) This restricts our geometric intuition to surjective families with finite [fibers](wikipedia://en/6603892).

## Properties of finite morphisms {#Properties_of_finite_morphisms}

- The composition of two finite morphisms is finite.
- Any [base change](wikipedia://en/56444110) of a finite morphism *f*: *X* → *Y* is finite. That is, if *g*: Z → *Y* is any morphism of schemes, then the resulting morphism *X* ×<sub>*Y*</sub> *Z* → *Z* is finite. This corresponds to the following algebraic statement: if *A* and *C* are (commutative) *B*-algebras, and *A* is finitely generated as a *B*-module, then the [tensor product](wikipedia://en/372395) *A* ⊗<sub>*B*</sub> *C* is finitely generated as a *C*-module. Indeed, the generators can be taken to be the elements *a*<sub>*i*</sub> ⊗ 1, where *a*<sub>*i*</sub> are the given generators of *A* as a *B*-module.
- [Closed immersions](wikipedia://en/1623986) are finite, as they are locally given by *A* → *A*/*I*, where *I* is the [ideal](wikipedia://en/25977) (section of the [ideal sheaf](wikipedia://en/9508138)) corresponding to the closed subscheme.
- Finite morphisms are closed, hence (because of their stability under base change) [proper](wikipedia://en/603782).[^o6] This follows from the [going up](wikipedia://en/2083445) theorem of Cohen-Seidenberg in commutative algebra.
- Finite morphisms have finite fibers (that is, they are [quasi-finite](wikipedia://en/2143056)).[^o6] This follows from the fact that for a field *k*, every finite *k*-algebra is an [Artinian ring](wikipedia://en/489273). A related statement is that for a finite surjective morphism *f*: *X* → *Y*, *X* and *Y* have the same [dimension](wikipedia://en/56079).
- By [Deligne](wikipedia://en/394544), a morphism of schemes is finite if and only if it is proper and quasi-finite.[^o8] This had been shown by [Grothendieck](wikipedia://en/2042) if the morphism *f*: *X* → *Y* is [locally of finite presentation](wikipedia://en/35457783#finite_presentation), which follows from the other assumptions if *Y* is [Noetherian](wikipedia://en/2783891).[^o9]
- Finite morphisms are both projective and [affine](wikipedia://en/35457783#affine).[^o6]
