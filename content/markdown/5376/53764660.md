# Crypto-shredding

::: {#o1 .subject cue=lead name="Crypto-shredding"}

**Crypto-shredding** or crypto erase (cryptographic erasure) is the practice of rendering encrypted [data](https://en.wikipedia.org/wiki/Data_%28computing%29) unusable by deliberately deleting or overwriting the [encryption](wikipedia://en/10294) keys: assuming the key is not later recovered and the encryption is not broken, the data should become irrecoverable, effectively permanently deleted or "shredded".[^o2] This requires that the data have been encrypted.

:::

Data may be considered to exist in three states: [data at rest](https://en.wikipedia.org/wiki/Data_at_rest), [data in transit](https://en.wikipedia.org/wiki/Data_in_transit) and [data in use](https://en.wikipedia.org/wiki/Data_in_use). General data security principles, such as in the [CIA triad](https://en.wikipedia.org/wiki/CIA_triad) of [confidentiality](wikipedia://en/353859), [integrity](https://en.wikipedia.org/wiki/Integrity), and [availability](https://en.wikipedia.org/wiki/Availability), require that all three states must be adequately protected. Deleting data at rest on storage media such as [backup](https://en.wikipedia.org/wiki/Backup) tapes, [data stored in the cloud](https://en.wikipedia.org/wiki/Cloud_storage#Potential_concerns), [computers](https://en.wikipedia.org/wiki/Computer_data_storage), phones, or [multi-function printers](https://en.wikipedia.org/wiki/Multi-function_printer#Security) can present challenges when confidentiality of information is of concern. When encryption is in place, data disposal is easier, as less data (only the key material) needs to be destroyed.

## Motivations for use {#Motivations_for_use}

There are various reasons for using crypto-shredding, including when the data is contained in defective or out-of-date systems, there is no further use for the data, the circumstances are such that there are no \[longer\] legal rights to use or retain the data, and other similar motivations. Legal obligations may also come from regulations such as the [right to be forgotten](https://en.wikipedia.org/wiki/Right_to_be_forgotten), the [General Data Protection Regulation](https://en.wikipedia.org/wiki/General_Data_Protection_Regulation), and others. Data security is largely influenced by [confidentiality](wikipedia://en/353859) and [privacy](https://en.wikipedia.org/wiki/Privacy) concerns.

::: {#o5 .application cue=heading name="Use"}

## Use {#Use}

In some cases all data storage is encrypted, such as encrypting entire [harddisks](https://en.wikipedia.org/wiki/Harddisk), [computer files](https://en.wikipedia.org/wiki/Computer_file), or [databases](https://en.wikipedia.org/wiki/Database). Alternatively only specific data may be encrypted, such as [passport](https://en.wikipedia.org/wiki/Passport) numbers, [social security numbers](https://en.wikipedia.org/wiki/Social_security_number), [bank account numbers](https://en.wikipedia.org/wiki/Bank_account_number), [person names](https://en.wikipedia.org/wiki/Person_name), or [record in a databases](https://en.wikipedia.org/wiki/Database_record). Additionally, data in one system may be encrypted with separate keys when that same data is contained in multiple systems. When [specific pieces of data are encrypted](https://en.wikipedia.org/wiki/Data-centric_security) (possibly with different keys) it allows for more specific data shredding. There is no need to have access to the data (like an encrypted backup tape), only the encryption keys need to be shredded.[^o6]

::: {#o8 .example cue=heading name="Example"}

### Example {#Example}

[iOS](https://en.wikipedia.org/wiki/IOS) devices and [Macintosh](https://en.wikipedia.org/wiki/Macintosh) computers with an [Apple silicon](https://en.wikipedia.org/wiki/Apple_silicon) chip use crypto-shredding when performing the "Erase all content and settings" action by discarding all the keys in "effaceable storage". This renders all user data on the device cryptographically inaccessible, in a very short amount of time.[^o9]
