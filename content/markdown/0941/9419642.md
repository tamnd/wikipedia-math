# Implication graph

*Image: Implication graph.svg.* An implication graph representing the [2-satisfiability](https://en.wikipedia.org/wiki/2-satisfiability) instance $\scriptscriptstyle (x_0\lor x_2)\land(x_0\lor\lnot x_3)\land(x_1\lor\lnot x_3)\land(x_1\lor\lnot x_4)\land(x_2\lor\lnot x_4)\land{}\atop\quad\scriptscriptstyle(x_0\lor\lnot x_5)\land (x_1\lor\lnot x_5)\land (x_2\lor\lnot x_5)\land (x_3\lor x_6)\land (x_4\lor x_6)\land (x_5\lor x_6).$

::: {#o1 .subject cue=lead name="Implication graph"}

In [mathematical logic](wikipedia://en/19636) and [graph theory](wikipedia://en/12401), an **implication graph** is a [skew-symmetric](wikipedia://en/17283742), [directed graph](wikipedia://en/19721986) $G = (V, E)$ composed of [vertex](wikipedia://en/638899) set $V$ and directed edge set $E$. Each vertex in $V$ represents the truth status of a [Boolean literal](https://en.wikipedia.org/wiki/Boolean_literal), and each directed edge from vertex $u$ to vertex $v$ represents the [material implication](wikipedia://en/658808) "If the literal $u$ is true then the literal $v$ is also true". Implication graphs were originally used for analyzing complex [Boolean expressions](wikipedia://en/3126968).

:::

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

A [2-satisfiability](https://en.wikipedia.org/wiki/2-satisfiability) instance in [conjunctive normal form](wikipedia://en/73342) can be transformed into an implication graph by replacing each of its [disjunctions](https://en.wikipedia.org/wiki/Disjunction) by a pair of implications. For example, the statement $(x_0\lor x_1)$ can be rewritten as $(\neg x_0 \rightarrow x_1)$, but $(\neg x_1 \rightarrow x_0)$ also works. An instance is satisfiable [if and only if](wikipedia://en/14922) no literal and its [negation](wikipedia://en/161019) belong to the same [strongly connected component](wikipedia://en/684680) of its implication graph; this characterization can be used to solve 2-satisfiability instances in [linear time](https://en.wikipedia.org/wiki/Linear_time).[^o4]

In [CDCL](https://en.wikipedia.org/wiki/CDCL) [SAT](wikipedia://en/4715)-solvers, [unit propagation](wikipedia://en/2730761) can be naturally associated with an implication graph that captures all possible ways of deriving all implied literals from decision literals,[^o5] which is then used for clause learning.
