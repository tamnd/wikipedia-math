# Oblivious HTTP

::: {#o2 .subject cue=lead name="Oblivious HTTP"}

**Oblivious HTTP** (**OHTTP**) is an [IETF](https://en.wikipedia.org/wiki/Internet_Engineering_Task_Force) [network protocol](https://en.wikipedia.org/wiki/Network_protocol) intended to enable anonymous [HTTP](https://en.wikipedia.org/wiki/HTTP) transactions over the [Internet](https://en.wikipedia.org/wiki/Internet).[^o3] Its goal is to allow a user to send an HTTP request to a [web server](https://en.wikipedia.org/wiki/Web_server) without allowing any single entity to see both the content of the request and the sender's [IP address](https://en.wikipedia.org/wiki/IP_address), since the IP address could be connected to the identity of the sender.[^o4] OHTTP is documented in 9458, published in January 2024 by authors affiliated with [Mozilla](https://en.wikipedia.org/wiki/Mozilla_Corporation) and [Cloudflare](https://en.wikipedia.org/wiki/Cloudflare).[^o5] The RFC says "Oblivious HTTP is simpler and less costly than more robust systems, like Q136346840 or [Tor](wikipedia://en/20556944), which can provide stronger guarantees at higher operational costs."[^o5]

:::

Some [technology companies](https://en.wikipedia.org/wiki/Technology_company) and other [online service providers](https://en.wikipedia.org/wiki/Online_service_provider) have implemented OHTTP to improve [Internet privacy](https://en.wikipedia.org/wiki/Internet_privacy) for users, typically for specific use cases such as collecting [software metrics](https://en.wikipedia.org/wiki/Software_metric) from client devices, collecting user data for [targeted advertising](https://en.wikipedia.org/wiki/Targeted_advertising), or processing client requests for use of [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) services. The privacy protections in the OHTTP protocol rely on two separate entities handling different aspects of each client request, so service providers interested in deploying OHTTP generally partner with a different company. For example, Cloudflare and [Fastly](https://en.wikipedia.org/wiki/Fastly) provide OHTTP relay services, and [Apple](https://en.wikipedia.org/wiki/Apple_Inc.), [Google](https://en.wikipedia.org/wiki/Google), [Meta](https://en.wikipedia.org/wiki/Meta_Platforms), and Mozilla partner with one or both relay services for their OHTTP implementations.

## Mechanism {#Mechanism}

HTTP is the foundation of communication for the [World Wide Web](https://en.wikipedia.org/wiki/World_Wide_Web). By default, HTTP exposes a website user's [IP address](https://en.wikipedia.org/wiki/IP_address) to the operator of the website, which may enable the operator to gather a [profile](wikipedia://en/21462612) of information about the user.[^o5] OHTTP is one of several protocols designed to protect the privacy of users making requests to web servers, using the principle of privacy partitioning (also called decoupling) to hide IP addresses.[^o7][^o8] OHTTP is designed for simple transactions, such as sending [web analytics](wikipedia://en/2475872) information, rather than general-purpose web browsing.[^o9][^o10] Most implementations of OHTTP involve an [application](https://en.wikipedia.org/wiki/Application_software), such as a [mobile app](https://en.wikipedia.org/wiki/Mobile_app), pre-configured to reach out to an OHTTP service for a particular type of transaction.[^o11]

*Image: Overview\_of\_Oblivious\_HTTP.png.* Figure 1 from 9458: Overview of Oblivious HTTP

OHTTP protects user privacy by combining message [encryption](wikipedia://en/10294) and specially-designed [proxy servers](https://en.wikipedia.org/wiki/Proxy_server). First, the client uses [hybrid public key encryption (HPKE)](wikipedia://en/11756462) to encapsulate the content of a HTTP request.[^o13] Then, the client sends the encrypted request to a relay, which can collect the client IP address but cannot decrypt the message.[^o5] The relay forwards the encrypted message to a gateway, which can decrypt the message but cannot find out the client IP address.[^o5] The gateway sends the decrypted request to a server for processing.[^o5] All traffic between the source, relay, gateway, and target server is sent over [HTTPS](wikipedia://en/13586) to prevent third parties from analysing or intercepting the message contents.[^o12]

Since neither the relay nor gateway knows both the source IP address and the content of a request, the relay and gateway would need to collude to cross-correlate messages and de-anonymize them.[^o13] If either of the operators is trustworthy, privacy is preserved. However, if both operators collude, they can compromise the privacy guarantees of OHTTP.[^o13] The gateway and target server are typically operated by the same organization, while the relay is typically operated by a different organization to prevent collusion.[^o30] An analysis by [NCC Group](https://en.wikipedia.org/wiki/NCC_Group) of an OHTTP implementation also noted that, to reduce risk of [traffic analysis](https://en.wikipedia.org/wiki/Traffic_analysis) and other attacks, "Deployment of OHTTP requires careful management of [key](wikipedia://en/53039) rotation, [rate limiting](https://en.wikipedia.org/wiki/Rate_limiting), and tolerances against network delays."[^o14]

Client applications configured to use OHTTP, such as applications designed to use OHTTP for certain [API](https://en.wikipedia.org/wiki/API) calls, do not need to try to find out whether OHTTP is available from a server.[^o11] In other cases, if a server operator wants to tell clients that a service supports OHTTP, 9540 (February 2024) defines an optional [DNS resource record](https://en.wikipedia.org/wiki/Domain_Name_System#Resource_records) parameter.[^o11] This mechanism enables a client to discover, after sending a DNS request, that they can send OHTTP requests, although the initial DNS request could expose the client's IP address to the server if not otherwise hidden.[^o11]

## Deployments {#Deployments}

[Cloudflare](https://en.wikipedia.org/wiki/Cloudflare) released an OHTTP relay service in 2022, called Privacy Gateway.[^o16][^o13] [Flo](https://en.wikipedia.org/wiki/Flo_%28app%29), an app for tracking [menstrual cycles](https://en.wikipedia.org/wiki/Menstrual_cycle), uses Cloudflare's OHTTP service to offer an "Anonymous Mode" that enables entering data into Flo without providing [personally identifying information](https://en.wikipedia.org/wiki/Personally_identifiable_information).[^o17]

[Google](https://en.wikipedia.org/wiki/Google) contracted with [Fastly](https://en.wikipedia.org/wiki/Fastly) in 2023 to provide Google with an OHTTP relay to implement its experimental anonymous advertising technology.[^o18][^o19] Specifically, Google used OHTTP to help ensure [*k*-anonymity](wikipedia://en/41698769) for its [Privacy Sandbox](https://en.wikipedia.org/wiki/Privacy_Sandbox) initiative.[^o20] Google also uses a Fastly OHTTP relay as part of its [Google Safe Browsing](https://en.wikipedia.org/wiki/Google_Safe_Browsing) service.[^o21][^o22] Google offers a Safe Browsing Oblivious HTTP Gateway API that enables client applications, such as [web browsers](https://en.wikipedia.org/wiki/Web_browser), to check whether a URL is on Google's list of unsafe websites without revealing the requester's IP address to Google.[^o23]

In 2023, [Mozilla](https://en.wikipedia.org/wiki/Mozilla_Corporation) started using Fastly's OHTTP relay service as part of collecting [Firefox](https://en.wikipedia.org/wiki/Firefox) performance metrics without collecting identifying information about individual users.[^o24][^o25]

As of 2024, [Apple](https://en.wikipedia.org/wiki/Apple_Inc.) uses OHTTP in its Private Cloud Compute platform to conceal IP addresses associated with requests to [Apple Intelligence](https://en.wikipedia.org/wiki/Apple_Intelligence) tools.[^o26] Apple published support for OHTTP for its [Swift](https://en.wikipedia.org/wiki/Swift_%28programming_language%29) programming language in 2024.[^o27] Apple said in 2025 that its Enhanced Visual Search uses OHTTP as part of its anonymization strategy.[^o28][^o29]

The [Internet Security Research Group](https://en.wikipedia.org/wiki/Internet_Security_Research_Group) includes an OHTTP gateway in [Divvi Up](https://en.wikipedia.org/wiki/Divvi_Up), a service that enables subscribers to collect [software metrics](https://en.wikipedia.org/wiki/Software_metric) from user devices while collecting minimal identifying information about users.[^o30]

As of 2025, [Meta Platforms](https://en.wikipedia.org/wiki/Meta_Platforms) uses OHTTP in its "Private Processing" functionality for [Meta AI](https://en.wikipedia.org/wiki/Meta_AI) tools, including to enable [WhatsApp](wikipedia://en/32058867) users to request summarization of messages without exposing the requester's IP address to Meta.[^o31] This uses Fastly's OHTTP relay service.[^o14]

## Related technologies {#Related_technologies}

An IETF working group, Oblivious HTTP Application Intermediation (OHAI), is responsible for working on OHTTP standards and collaborating with groups that work on related protocols.[^o3]

The [Oblivious DNS over HTTPS](https://en.wikipedia.org/wiki/Oblivious_DNS_over_HTTPS) (ODoH) protocol enables making [Domain Name System (DNS)](https://en.wikipedia.org/wiki/Domain_Name_System) requests using similar architectural principles as OHTTP (9230, June 2022).[^o12]

Some people use [virtual private network (VPN) services](https://en.wikipedia.org/wiki/VPN_service) to address privacy concerns, but this enables a single entity to see identifying information about the user and all of their activity that passes through the VPN.[^o7] [Tor](wikipedia://en/20556944) is a separate technology for protecting user privacy on the web by decoupling the sender from the receiver through at least three intermediate hops.[^o7]

[MASQUE](https://en.wikipedia.org/wiki/MASQUE_%28protocol%29) (Multiplexed Application Substrate over [QUIC](https://en.wikipedia.org/wiki/QUIC) Encryption) is a different set of protocols for improving the privacy of users making web requests.[^o33] It can be used for web browsing.[^o10] For example, Apple's [iCloud Private Relay](https://en.wikipedia.org/wiki/ICloud_Private_Relay) service uses MASQUE.[^o34]
