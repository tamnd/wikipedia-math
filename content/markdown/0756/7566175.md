# Vertex connectivity

*Image: 4-connected graph.svg.* A graph with connectivity 4 and not 5: The graph remains connected whichever 3 vertices are removed but removing all but 2 opposing vertices (i.e. removing 4) leaves a disconnected graph.

::: {#o1 .subject cue=lead name="Vertex connectivity"}

In [graph theory](wikipedia://en/12401), a connected [graph](wikipedia://en/325806) $G$ is said to be **$k$-vertex-connected** (or **$k$-connected**) if it has more than $k$ [vertices](wikipedia://en/638899) and remains [connected](wikipedia://en/1614492) whenever fewer than $k$ vertices are removed.

:::

The **vertex-connectivity**, or just **connectivity**, of a graph is the largest $k$ for which the graph is $k$-vertex-connected.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A graph (other than a [complete graph](wikipedia://en/85816)) has connectivity *k* if *k* is the size of the smallest subset of vertices such that the graph becomes disconnected if you delete them.[^o4] In [complete graphs](wikipedia://en/85816), there is no subset whose removal would disconnect the graph. Some sources modify the definition of connectivity to handle this case, by defining it as the size of the smallest subset of vertices whose deletion results in either a disconnected graph or a single vertex. For this variation, the connectivity of a complete graph $K_n$ is $n-1$.[^o5]

An equivalent definition is that a graph with at least two vertices is *k*-connected if, for every pair of its vertices, it is possible to find *k* vertex-independent [paths](wikipedia://en/638889) connecting these vertices; see [Menger's theorem](wikipedia://en/1155738) (Diestel 2005, 55). This definition produces the same answer, *n* − 1, for the connectivity of the complete graph *K*<sub>*n*</sub>.[^o4]

A *k*-connected graph is by definition [connected](https://en.wikipedia.org/wiki/Connected_graph); it is called [biconnected](wikipedia://en/4989397) for *k* ≥ 2 and triconnected for *k* ≥ 3.

:::

## Applications {#Applications}

### Components {#Components}

Every graph decomposes into a disjoint union of [1-connected components](wikipedia://en/246223). 1-connected graphs decompose into a tree of [biconnected components](wikipedia://en/4842394). 2-connected graphs decompose into a tree of [triconnected components](https://en.wikipedia.org/wiki/Triconnected_component).

### Polyhedral combinatorics {#Polyhedral_combinatorics}

The 1-[skeleton](https://en.wikipedia.org/wiki/Skeleton_%28topology%29) of any *k*-dimensional convex [polytope](wikipedia://en/23471) forms a *k*-vertex-connected graph ([Balinski's theorem](wikipedia://en/24732291)).[^o11] As a partial converse, [Steinitz's theorem](wikipedia://en/19762817) states that any 3-vertex-connected [planar graph](wikipedia://en/24314) forms the skeleton of a convex [polyhedron](wikipedia://en/23470).

:::

## Computational complexity {#Computational_complexity}

The vertex-connectivity of an input graph *G* can be computed in polynomial time in the following way[^o13] consider all possible pairs $(s, t)$ of nonadjacent nodes to disconnect, using [Menger's theorem](wikipedia://en/1155738) to justify that the minimal-size separator for $(s, t)$ is the number of pairwise vertex-independent paths between them, encode the input by doubling each vertex as an edge to reduce to a computation of the number of pairwise edge-independent paths, and compute the maximum number of such paths by computing the [maximum flow](https://en.wikipedia.org/wiki/Maximum_flow) in the graph between $s$ and $t$ with capacity 1 to each edge, noting that a flow of $k$ in this graph corresponds, by the [integral flow theorem](https://en.wikipedia.org/wiki/Integral_flow_theorem), to $k$ pairwise edge-independent paths from $s$ to $t$.

::: {#o15 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $k\ge2$.

- Every $k$-connected graph of order at least $2k$ contains a [cycle](wikipedia://en/168609) of length at least $2k$
- In a $k$-connected graph, any $k$ vertices in $G$ lie on a common [cycle](wikipedia://en/168609).[^o16]

The [cycle space](wikipedia://en/262243) of a $3$-connected graph is generated by its non-separating [induced cycles](wikipedia://en/7714430). [^o17]

:::

::: {#o19 .pointer-item cue=pointer name="K-linked graph"}

## *k*-linked graph {#k-linked_graph}

A graph with at least $2k$ vertices is called **$k$-linked** if there are $k$ disjoint paths for any sequences $a_1,\dots,a_k$ and $b_1,\dots, b_k$ of $2k$ distinct vertices. Every $k$-linked graph is $(2k-1)$-connected graph, but not necessarily $2k$-connected. [^o20]

If a graph is $2k$-connected and has average degree of at least $16k$, then it is $k$-linked. [^o21]

:::
