# Fisher's inequality

::: {#o1 .subject cue=lead name="Fisher's inequality"}

**Fisher's inequality** is a [necessary condition](wikipedia://en/169319) for the existence of a balanced incomplete [block design](wikipedia://en/1188184), that is, a system of subsets that satisfy certain prescribed conditions in [combinatorial](wikipedia://en/5170) [mathematics](wikipedia://en/18831). Outlined by [Ronald Fisher](wikipedia://en/140824), a [population geneticist](wikipedia://en/219268) and [statistician](wikipedia://en/26685), who was concerned with the [design of experiments](wikipedia://en/9541) such as studying the differences among several different [varieties](https://en.wikipedia.org/wiki/Variety_%28botany%29) of plants, under each of a number of different growing conditions, called *blocks*.

:::

Let:

- $v$ be the number of varieties of plants;
- $b$ be the number of blocks.

To be a balanced incomplete block design it is required that:

- $k$ different varieties are in each block, $1 \le k < v$; no variety occurs twice in any one block;
- any two varieties occur together in exactly $\lambda$ blocks;
- each variety occurs in exactly $r$ blocks.

Fisher's inequality states simply that

$$b \ge v.$$

::: {#o3 .proof cue=heading name="Proof"}

## Proof {#Proof}

Let the incidence matrix $\mathbf{M}$ be a $v \times b$ matrix defined so that $\mathbf{M}_{i,j}$ is 1 if element $i$ is in block $j$ and 0 otherwise. Then $\mathbf{B} = \mathbf{MM}^{T}$ is a $v \times v$ matrix such that $\mathbf{B}_{i,i} = r$ and $\mathbf{B}_{i,j} = \lambda$ for $i \ne j$. Since $r \ne \lambda$, $\det(\mathbf{B}) \ne 0$, so $\operatorname{rank}(\mathbf{B}) = v$; on the other hand, $\operatorname{rank}(\mathbf{B}) \le \operatorname{rank}(\mathbf{M}) \le b$, so $v \le b$.

:::

::: {#o5 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

Fisher's inequality is valid for more general classes of designs. A *pairwise balanced design* (or PBD) is a set $X$ together with a family of non-empty subsets of $X$ (which need not have the same size and may contain repeats) such that every pair of distinct elements of $X$ is contained in exactly $\lambda$ (a positive integer) subsets. The set $X$ is allowed to be one of the subsets, and if all the subsets are copies of $X$, the PBD is called "trivial". The size of $X$ is $v$ and the number of subsets in the family (counted with multiplicity) is $b$.

Theorem: For any non-trivial PBD, $v \le b$.[^o6]

This result also generalizes the [Erdős–De Bruijn theorem](wikipedia://en/26825148):

For a PBD with $\lambda = 1$ having no blocks of size 1 or size $v$, $v \le b$, with equality if and only if the PBD is a [projective plane](wikipedia://en/24350) or a near-pencil (meaning that exactly $n - 1$ of the points are [collinear](https://en.wikipedia.org/wiki/Collinear)).[^o7]

In another direction, [Ray-Chaudhuri](wikipedia://en/18064578) and [Wilson](wikipedia://en/22615301) proved in 1975 that in a $2s-(v, k, \lambda)$ design, the number of blocks is at least $\binom{v}{s}$.[^o8]

:::
