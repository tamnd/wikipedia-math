# BSSN formalism

::: {#o1 .subject cue=lead name="BSSN formalism"}

The **BSSN formalism** (Baumgarte, Shapiro, Shibata, Nakamura formalism) is a [formalism](wikipedia://en/1504486#In_modern_physics) of [general relativity](wikipedia://en/12024) that was developed by [Thomas W. Baumgarte](https://en.wikipedia.org/wiki/Thomas_W._Baumgarte), [Stuart L. Shapiro](https://en.wikipedia.org/wiki/Stuart_L._Shapiro), Masaru Shibata and Takashi Nakamura between 1987 and 1999. [^o2] [^o3] [^o4] It is a modification of the [ADM formalism](wikipedia://en/3839357) developed during the 1950s.

:::

The ADM formalism is a [Hamiltonian](wikipedia://en/198319) formalism that does not permit stable and long-term numerical simulations. In the BSSN formalism, the ADM equations are modified by introducing auxiliary variables. The formalism has been tested for a long-term evolution of linear gravitational waves and used for a variety of purposes such as simulating the non-linear evolution of [gravitational waves](wikipedia://en/8111079) or the evolution and collision of [black holes](wikipedia://en/4650).[^o5][^o6]

::: {#o8 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

Most references adopt notation in which four dimensional tensors are written in abstract index notation, and that Greek indices are spacetime indices taking values (0, 1, 2, 3) and Latin indices are spatial indices taking values (1, 2, 3).

The superscript (4) is prepended to quantities that typically have both a three-dimensional and a 4-dimensional version, such as the metric tensor for 3-dimensional slices $g_{ij}$ and the metric tensor for the full four-dimensional spacetime ${^{(4)}}g_{\mu \nu}$.

The text uses [Einstein notation](wikipedia://en/195407), where repeated indices indicate summation. For example, if $X \in T_p M$ is a [tangent vector](wikipedia://en/191999) on the manifold $M$, and we decompose it into its components, in Einstein notation this would be:

$$\begin{aligned} X &= \sum_{\mu} X^{\mu} \dfrac{\partial}{\partial x^{\mu}} \implies X^{\mu} \dfrac{\partial}{\partial x^{\mu}} \end{aligned}$$

The absolute value of the [determinant](wikipedia://en/8468) of the matrix of metric tensor coefficients is represented by $g$. Other tensor symbols written without indices represent the trace of the corresponding tensor such as $\pi = g^{ij}\pi_{ij}$.

:::

## Derivation {#Derivation}

### Vacuum Solutions {#Vacuum_Solutions}

Shibata and Nakamura[^o3] derived the equations for the vacuum solutions:

$$\begin{aligned} G_{ab} &= 0 \end{aligned}$$

#### ADM Formalism {#ADM_Formalism}

::: {#o12 .table cue=table}

| Variable | Definition |
|---|---|
| $\alpha$ | [lapse function](https://en.wikipedia.org/wiki/Lapse_function) |
| $\beta^i$ | [shift vector](https://en.wikipedia.org/wiki/Shift_vector) |
| $\gamma_{ij}$ | metric tensor on a 3D-hypersurface of the [foliation](wikipedia://en/371227) |
| $R$ | 3D [Ricci scalar](https://en.wikipedia.org/wiki/Ricci_scalar) |
| $K_{ij}$ | [extrinsic curvature](https://en.wikipedia.org/wiki/Extrinsic_curvature) |
| $D_i$ | 3D [covariant derivative](wikipedia://en/431848) |

:::

The derivation begins with the [ADM formalism](wikipedia://en/3839357). The ADM metric is given by:

$$\begin{aligned} ds^2 &= -(\alpha^2 - \beta_i \beta^i)dt^2 + 2 \beta_i dt dx^i + \gamma_{ij} dx^i dx^j \end{aligned}$$

The Hamiltonian constraint is given by:

$$\begin{aligned} R - K_{ij}K^{ij} + K^2 = 0 \end{aligned}$$

The momentum constraint is given by:

$$\begin{aligned} D_i K^i_j - D_j K &= 0 \end{aligned}$$

and the evolution equations are given by:

$$\begin{aligned} \dfrac{\partial}{\partial t} \gamma_{ij} &= -2\alpha K_{ij} + D_i \beta_j + D_j \beta_i \end{aligned}$$

$$\begin{aligned} \dfrac{\partial}{\partial t} K_{ij} &= \alpha(R_{ij} + K K_{ij} - 2 K_{ij}K^{\ell}_j) - D_i D_j \alpha + (D_j \beta^m)K_{mi} + (D_i \beta^m)K_{mj} + \beta_m D_m K_{ij} \end{aligned}$$
