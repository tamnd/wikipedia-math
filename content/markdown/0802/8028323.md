# Cryptlib

::: {#o1 .subject cue=lead name="Cryptlib"}

**cryptlib** is an [open-source](https://en.wikipedia.org/wiki/Open-source_software) [cross-platform](https://en.wikipedia.org/wiki/Cross-platform) software security toolkit library. It is distributed under the [Sleepycat License](https://en.wikipedia.org/wiki/Sleepycat_License),[^o3] a [free software license](https://en.wikipedia.org/wiki/Free_software_license) [compatible](https://en.wikipedia.org/wiki/License_compatibility) with the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License).[^o4] Alternatively, **cryptlib** is available under a proprietary license for those preferring to use it under proprietary terms.[^o5]

:::

## Features {#Features}

cryptlib is a security toolkit library that allows programmers to incorporate [encryption](wikipedia://en/10294) and authentication services to software. It provides a high-level interface, so that strong security capabilities can be added to an application without needing to know many of the low-level details of encryption or authentication [algorithms](wikipedia://en/775). Extensive documentation in the form of a 400+ page programming manual is available.[^o7]

At the highest level, cryptlib provides implementations of complete security services such as [S/MIME](https://en.wikipedia.org/wiki/S/MIME) and [PGP](wikipedia://en/23080)/[OpenPGP](https://en.wikipedia.org/wiki/OpenPGP) secure enveloping, [SSL/TLS](wikipedia://en/187813) and [SSH](wikipedia://en/28814) secure sessions, [CA](wikipedia://en/296370) services such as [CMP](wikipedia://en/13565028), [SCEP](https://en.wikipedia.org/wiki/Simple_Certificate_Enrollment_Protocol), [SCVP](https://en.wikipedia.org/wiki/SCVP), RTCS, [OCSP](https://en.wikipedia.org/wiki/Online_Certificate_Status_Protocol), and other security operations such as secure timestamping. Since cryptlib uses industry-standard [X.509](https://en.wikipedia.org/wiki/X.509), S/MIME, PGP/OpenPGP, and SSH/SSL/TLS data formats, the resulting encrypted or signed data can be easily transported to other systems and processed there, and cryptlib itself runs on many operating systems—all Windows versions and most [Unix](https://en.wikipedia.org/wiki/Unix)/[Linux](https://en.wikipedia.org/wiki/Linux) systems. This allows email, files, and EDI transactions to be authenticated with digital signatures and encrypted in an industry-standard format.

cryptlib provides other capabilities including full X.509/[PKIX](https://en.wikipedia.org/wiki/PKIX) certificate handling (all X.509 versions from X.509v1 to X.509v4) with support for [SET](https://en.wikipedia.org/wiki/Secure_Electronic_Transaction), Microsoft AuthentiCode, Identrus, SigG, S/MIME, SSL, and Qualified certificates, PKCS #7 certificate chains, handling of certification requests and CRLs (certificate revocation lists) including automated checking of certificates against CRLs and online checking using RTCS and OCSP, and issuing and revoking certificates using CMP and SCEP. It also implements a full range of certification authority (CA) functions provides complete CMP, SCEP, RTCS, and OCSP server implementations to handle online certificate enrolment/issue/revocation and certificate status checking. Alongside the certificate handling, it provides a sophisticated key storage interface that allows the use of a wide range of key database types ranging from PKCS #11 devices, PKCS #15 key files, and PGP/OpenPGP key rings to commercial-grade [RDBMS](https://en.wikipedia.org/wiki/Relational_database_management_system) and [LDAP](https://en.wikipedia.org/wiki/LDAP) directories with optional SSL protection.

cryptlib can make use of the cryptographic capabilities of a variety of external cryptographic devices such as hardware cryptographic accelerators, Fortezza cards, PKCS #11 devices, hardware security modules (HSMs), and cryptographic smart cards. It can be used with a variety of cryptography devices that have received FIPS 140 or ITSEC/Common Criteria certification. The cryptographic device interface also provides a general-purpose plug-in capability for adding new functionality that can be used by cryptlib.

cryptlib is written in C and supports [BeOS](https://en.wikipedia.org/wiki/BeOS), [DOS](https://en.wikipedia.org/wiki/DOS), [IBM](https://en.wikipedia.org/wiki/IBM) [MVS](https://en.wikipedia.org/wiki/MVS), [Mac OS X](https://en.wikipedia.org/wiki/Mac_OS_X), [OS/2](https://en.wikipedia.org/wiki/OS/2), Tandem, a variety of [Unix](https://en.wikipedia.org/wiki/Unix) versions (including [AIX](https://en.wikipedia.org/wiki/AIX), [Digital Unix](https://en.wikipedia.org/wiki/Digital_Unix), [DGUX](https://en.wikipedia.org/wiki/DGUX), [FreeBSD](https://en.wikipedia.org/wiki/FreeBSD)/[NetBSD](https://en.wikipedia.org/wiki/NetBSD)/[OpenBSD](https://en.wikipedia.org/wiki/OpenBSD), [HP-UX](https://en.wikipedia.org/wiki/HP-UX), [IRIX](https://en.wikipedia.org/wiki/IRIX), [Linux](https://en.wikipedia.org/wiki/Linux), MP-RAS, [OSF/1](https://en.wikipedia.org/wiki/OSF/1), [QNX](https://en.wikipedia.org/wiki/QNX), [SCO UnixWare](https://en.wikipedia.org/wiki/SCO_UnixWare), [Solaris](https://en.wikipedia.org/wiki/Oracle_Solaris), [SunOS](https://en.wikipedia.org/wiki/SunOS), [Ultrix](https://en.wikipedia.org/wiki/Ultrix), and UTS4), [VM/CMS](https://en.wikipedia.org/wiki/VM/CMS), [Windows 3.x](https://en.wikipedia.org/wiki/Windows_3.x), [Windows 95](https://en.wikipedia.org/wiki/Windows_95)/[98](https://en.wikipedia.org/wiki/Windows_98)/[ME](https://en.wikipedia.org/wiki/Windows_ME), [Windows CE](https://en.wikipedia.org/wiki/Windows_CE)/PocketPC/SmartPhone and Windows NT/2000/XP/Vista. It is designed to be portable to other [embedded system](https://en.wikipedia.org/wiki/Embedded_system) environments. It is available as a standard [DLL](https://en.wikipedia.org/wiki/Dynamic_link_library). Language bindings are available for [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) / [C++](https://en.wikipedia.org/wiki/C++), [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29) / [.NET](https://en.wikipedia.org/wiki/.NET_Framework), [Delphi](https://en.wikipedia.org/wiki/Delphi_%28programming_language%29),[^o8] [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29), [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), and [Visual Basic](https://en.wikipedia.org/wiki/Visual_Basic) (VB).
