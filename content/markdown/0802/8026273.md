# Factor base

::: {#o1 .subject cue=lead name="Factor base"}

In [computational number theory](wikipedia://en/511466), a **factor base** is a small set of prime numbers commonly used as a mathematical tool in algorithms involving extensive [sieving](wikipedia://en/1035915) for potential factors of a given integer.

:::

## Usage in factoring algorithms {#Usage_in_factoring_algorithms}

A factor base is a relatively small [set](wikipedia://en/27553) of distinct [prime numbers](wikipedia://en/23666) *P*, sometimes together with −1.[^o3] Suppose we want to factorize an integer *n*. We generate, in some way, a large number of integer pairs (*x*, *y*) for which $x \neq \pm y$, $x^2 \equiv y^2 \pmod{n}$, and $x^2 \pmod{n} \text{ and }y^2 \pmod{n}$ can be completely factorized over the chosen factor base—that is, all their prime factors are in *P*.

In practice, several integers *x* are found such that $x^2 \pmod{n}$ has all of its prime factors in the pre-chosen factor base. We represent each $x^2 \pmod{n}$ expression as a [vector](wikipedia://en/32370) of a [matrix](wikipedia://en/20556859) with integer entries being the exponents of factors in the factor base. Linear combinations of the rows corresponds to multiplication of these expressions. A linear dependence relation mod 2 among the rows leads to a desired congruence $x^2 \equiv y^2 \pmod{n}$.[^o4] This essentially reformulates the problem into a [system of linear equations](wikipedia://en/113087), which can be solved using numerous methods such as [Gaussian elimination](wikipedia://en/13035); in practice advanced methods like the [block Lanczos algorithm](https://en.wikipedia.org/wiki/Block_Lanczos_algorithm_for_nullspace_of_a_matrix_over_a_finite_field) are used, that take advantage of certain properties of the system.

This congruence may generate the trivial $\textstyle n = 1 \cdot n$; in this case we try to find another suitable congruence. If repeated attempts to factor fail we can try again using a different factor base.

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

Factor bases are used in, for example, [Dixon's factorization](wikipedia://en/1033877), the [quadratic sieve](wikipedia://en/582340), and the [number field sieve](wikipedia://en/152734). The difference between these algorithms is essentially the methods used to generate (*x*, *y*) candidates. Factor bases are also used in the [Index calculus algorithm](wikipedia://en/1549595) for computing discrete logarithms.[^o7]
