# Neyman Type A distribution

::: {#o1 .subject cue=lead name="Neyman Type A distribution"}

In [statistics](wikipedia://en/26685) and [probability](wikipedia://en/22934), the **Neyman Type A distribution** is a discrete probability distribution from the family of [compound Poisson distribution](wikipedia://en/949562). This distribution can be demonstrated with the following example explained in \*Univariate Discrete Distributions\*:[^o2] a statistical model is constructed for the distribution of larvae in a unit area of field (in a unit of habitat) by assuming that the variation in the number of clusters of eggs per unit area (per unit of habitat) could be represented by a [Poisson distribution](wikipedia://en/23009144) with parameter $\lambda$, while the number of larvae developing per cluster of eggs are assumed to have independent [Poisson distribution](wikipedia://en/23009144) all with the same parameter $\phi$. To determine the number of larvae, the [random variable](wikipedia://en/25685) *Y* is defined as the sum of the larvae hatched in each group (given *j* groups). Therefore, *Y* = *X*<sub>1</sub> + *X*<sub>2</sub> + ... *X* <sub>j</sub>, where *X*<sub>1</sub>,...,*X*<sub>j</sub> are independent Poisson variables with parameter $\lambda$ and $\phi$.

:::

## History {#History}

[Jerzy Neyman](wikipedia://en/2386106) was born in the [Russian Empire](https://en.wikipedia.org/wiki/Russian_Empire) on 16 April 1894. He was a Polish statistician who spent the first part of his career in Europe. In 1939 he developed the Neyman Type A distribution [^o2] to describe the distribution of larvae in experimental field plots. Above all, it is used to describe populations based on contagion, e.g., [entomology](https://en.wikipedia.org/wiki/Entomology) (Beall\[1940\],[^o4] Evans\[1953\][^o5]), accidents (Creswell i Froggatt \[1963\]),[^o6] and [bacteriology](https://en.wikipedia.org/wiki/Bacteriology).

The original derivation of this distribution was on the basis of a biological model and, presumably, it was expected that a good fit to the data would justify the hypothesized model. However, it is now known that it is possible to derive this distribution from different models ([William Feller](wikipedia://en/206644)\[1943\]),[^o7] and in view of this, Neyman's distribution derive as [Compound Poisson distribution](wikipedia://en/949562). This interpretation makes them suitable for modelling heterogeneous populations and renders them examples of apparent contagion.

Despite this, the difficulties in dealing with Neyman's Type A arise from the fact that its expressions for probabilities are highly complex. Even estimations of parameters through efficient methods, such as [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood), are tedious and not easy to understand equations.

## Definition {#Definition}

### Probability generating function {#Probability_generating_function}

The probability generating function (pgf) *G*<sub>1</sub>(*z*), which creates *N* independent X<sub>j</sub> random variables, is used to a branching process. Each X<sub>j</sub> produces a random number of individuals, where X<sub>1</sub>, X<sub>2</sub>,... have the same distribution as *X*, which is that of *X* with pgf *G*<sub>2</sub>(*z*). The total number of individuals is then the random variable,[^o2]

$$Y = SN = X_1 + X_2 + ... + X_N$$

The p.g.f. of the distribution of *SN* is :

$$E[z^{SN}] = E_N[E[z^{SN}|N]] = E_N[G_2(z)] = G_1(G_2(z))$$

One of the notations, which is particularly helpful, allows us to use a symbolic representation to refer to an F1 distribution that has been generalized by an F2 distribution is,

$$Y\sim F_1\bigwedge F_N$$

In this instance, it is written as,

$$Y\sim \operatorname{Pois(\lambda)}\bigwedge \operatorname{Pois(\phi)}$$

Finally, the [probability generating function](wikipedia://en/236841) is,

$$G_Y(z) = \exp(\lambda(e^{\phi (z-1)}-1))$$

From the generating function of probabilities we can calculate the [probability mass function](wikipedia://en/154725) explained below.

### Probability mass function {#Probability_mass_function}

Let *X*<sub>1</sub>,*X*<sub>2</sub>,...*X*<sub>j</sub> be Poisson [independent variables](https://en.wikipedia.org/wiki/Independent_variables). The [probability distribution](wikipedia://en/23543) of the [random variable](wikipedia://en/25685) *Y* = *X*<sub>1</sub> +*X*<sub>2</sub>+...*X*<sub>j</sub> is the Neyman's Type A distribution with parameters $\lambda$ and $\phi$.

$p_x = P(Y=x) = \frac{e^{-\lambda}\phi^x}{x!} \sum_{j=0}^{\infty} \frac{(\lambda e^{-\phi})^j j^x}{j!}~~$$~~x = 1,2,...$

Alternatively,

$$p_x = P(Y=x) = \frac{e^{-\lambda + \lambda e^{-\phi}}\phi^x}{x!} \sum_{j=0}^{x}S(x,j)\lambda^j e^{-\phi^j}$$

In order to see how the previous expression develops, we must bear in mind that the [probability mass function](wikipedia://en/154725) is calculated from the [probability generating function](wikipedia://en/236841), and use the property of Stirling Numbers. Let's see the development

$$G(z) = e^{-\lambda + \lambda e^{-\phi}}\sum_{j=0}^{\infty}\frac{\lambda^j e^{-j\phi}(e^{\phi z}-1)^j}{j|}$$

$$= e^{-\lambda + \lambda e^{-\phi}}\sum_{j=0}^{\infty} (\lambda e^{-\phi})^j \sum_{x=j}^{\infty}\frac{S(x,j)\phi^x z^x}{x!}$$

$$= \frac{e^{-\lambda + \lambda e^{-\phi}}\phi^x}{x!} \sum_{j=0}^{x}S(x,j)\lambda^j e^{-\phi^j}$$

Another form to estimate the probabilities is with recurring successions,[^o12]

$p_x = P(Y=x) = \frac{\lambda\phi e^{- \phi}}{x} \sum_{r=0}^{x-1} \frac{\phi^r}{r!} p_{x-r-1}~~$,$~~p_0 = \exp(-\lambda + \lambda e ^{- \phi})$

Although its length varies directly with *n*, this recurrence relation is only employed for numerical computation and is particularly useful for computer applications.

where

- *x* = 0, 1, 2, ... , except for probabilities of recurring successions, where *x* = 1, 2, 3, ...
- $$j \leq x$$
- $\lambda$, $\phi>0$.
- *x*! and *j*! are the [factorials](wikipedia://en/10606) of *x* and *j*, respectively.
- one of the properties of [Stirling numbers of the second kind](wikipedia://en/2229292) is as follows:[^o13]

$$(e^{\phi z} - 1)^j = j! \sum_{x=j}^\infty \frac{S(x,j){\phi z}^x}{x!}$$

## Properties {#Properties}

### Moment and cumulant generating functions {#Moment_and_cumulant_generating_functions}

The [moment generating function](wikipedia://en/194634) of a random variable *X* is defined as the expected value of *e*<sup>*t*</sup>, as a function of the real parameter *t*. For an $\operatorname{NA(\lambda,\phi)}$, the [moment generating function](wikipedia://en/194634) exists and is equal to

$$M(t) = G_Y(e^t) = \exp(\lambda(e^{\phi (e^t-1)}-1))$$

The [cumulant generating function](https://en.wikipedia.org/wiki/Cumulant_generating_function) is the [logarithm](wikipedia://en/17860) of the [moment generating function](wikipedia://en/194634) and is equal to [^o2]

$$K(t) = \log(M(t)) = \lambda(e^{\phi (e^t-1)}-1)$$

In the following table we can see the moments of the order from 1 to 4

::: {#o19 .table cue=table}

| Order | Moment | Cumulant |
|---|---|---|
| 1 | $\mu_1 = \lambda \phi$ | $\mu$ |
| 2 | $\mu_2 = \lambda \phi(1 + \phi)$ | $\sigma^2$ |
| 3 | $\mu_3 = \lambda \phi(1 + 3\phi + \phi^2)$ | $k_3$ |
| 4 | $\mu_4 = \lambda \phi(1 + 7\phi + 6\phi^2 + \phi^3) + 3\lambda^2\phi^2(1 + \phi)^2$ | $k_4 + 3\sigma^4$ |

:::

### Skewness {#Skewness}

The [skewness](wikipedia://en/28212) is the third moment centered around the [mean](https://en.wikipedia.org/wiki/Mean) divided by the 3/2 power of the [standard deviation](wikipedia://en/27590), and for the $\operatorname{NA}$ distribution is,

$$\gamma_1 = \frac{\mu_3}{\mu_2^{3/2}} = \frac{\lambda \phi(1 + 3\phi + \phi^2)}{(\lambda \phi(1 + \phi))^{3/2}}$$

### Kurtosis {#Kurtosis}

The [kurtosis](wikipedia://en/16848) is the fourth moment centered around the [mean](https://en.wikipedia.org/wiki/Mean), divided by the square of the [variance](wikipedia://en/32344), and for the $\operatorname{NA}$ distribution is,

$$\beta_2= \frac{\mu_4}{\mu_2^2} = \frac{\lambda \phi(1 + 7\phi + 6\phi^2 + \phi^3) + 3\lambda^2\phi^2(1 + \phi)^2}{\lambda^2 \phi^2(1 + \phi)^2} = \frac{1+7\phi+6\phi^2+\phi^3}{\phi\lambda (1+\phi)^2} + 3$$

The [excess kurtosis](https://en.wikipedia.org/wiki/Excess_kurtosis) is just a correction to make the kurtosis of the [normal distribution](wikipedia://en/21462) equal to zero, and it is the following,

$$\gamma_2= \frac{\mu_4}{\mu_2^2}-3 = \frac{1+7\phi+6\phi^2+\phi^3}{\phi\lambda (1+\phi)^2}$$

- Always $\beta_2 >3$, or $\gamma_2 >0$ the distribution has a high acute peak around the [mean](https://en.wikipedia.org/wiki/Mean) and fatter tails.

### Characteristic function {#Characteristic_function}

In a [discrete distribution](https://en.wikipedia.org/wiki/Discrete_distribution) the [characteristic function](https://en.wikipedia.org/wiki/Characteristic_function) of any real-valued random variable is defined as the [expected value](wikipedia://en/9653) of $e^{itX}$, where *i* is the imaginary unit and *t* ∈ *R*

$$\phi(t)= E[e^{itX}] = \sum_{j=0}^\infty e^{ijt}P[X=j]$$

This function is related to the [moment generating function](wikipedia://en/194634) via $\phi_x(t) = M_X(it)$. Hence for this distribution the [characteristic function](https://en.wikipedia.org/wiki/Characteristic_function) is,

$$\phi_x(t) = \exp(\lambda(e^{\phi (e^{it}-1)}-1))$$

- Note that the symbol $\phi_x$ is used to represent the characteristic function.

### Cumulative distribution function {#Cumulative_distribution_function}

The [cumulative distribution function](wikipedia://en/5793) is,

$$\begin{aligned} F(x;\lambda,\phi)& = P(Y \leq x)\\ &= e^{-\lambda} \sum_{i=0}^{x} \frac{\phi^i}{i!} \sum_{j=0}^{\infty} \frac{(\lambda e^{-\phi})^j j^i}{j!}\\ &= e^{-\lambda} \sum_{i=0}^{x} \sum_{j=0}^{\infty} \frac{\phi^i(\lambda e^{-\phi})^j j^i}{i!j!} \end{aligned}$$

### Other properties {#Other_properties}

- The [index of dispersion](wikipedia://en/16693606) is a normalized measure of the dispersion of a [probability distribution](wikipedia://en/23543). It is defined as the ratio of the [variance](wikipedia://en/32344) $\sigma^2$ to the [mean](https://en.wikipedia.org/wiki/Mean) $\mu$,[^o25]

$$d = \frac{\sigma^2}{\mu} = 1 + \phi$$

- From a sample of size *N*, where each random variable *Y*<sub>i</sub> comes from a $\operatorname{NA(\lambda,\phi)}$, where *Y*<sub>1</sub>, *Y*<sub>2</sub>, .., *Y*<sub>n</sub> are independent. This gives the MLE estimator as,[^o26]

$\sum_{i=1}^{N} \frac{x_i}{N} = \bar{x} = \bar{\lambda}\bar{\phi} ~~~$ where $\mu$ is the poblational mean of $\bar{x}$

- Between the two earlier expressions We are able to parametrize using $\mu$ and $d$,

$$\begin{cases} \mu = \lambda\phi \\ d = 1 + \phi \end{cases} \longrightarrow \quad\! \begin{aligned} \lambda = \frac{\mu}{d-1} \\ \phi = d -1 \end{aligned}$$

:::

## Parameter estimation {#Parameter_estimation}

### Method of moments {#Method_of_moments}

The [mean](https://en.wikipedia.org/wiki/Mean) and the [variance](wikipedia://en/32344) of the NA($\lambda,\phi$) are $\mu = \lambda\phi$ and $\lambda\phi(1 + \phi)$, respectively. So we have these two equations,[^o29]

$$\begin{cases} \bar{x} = \lambda\phi \\ s^2 = \lambda\phi(1 + \phi) \end{cases}$$

- $s^2$ and $\bar{x}$ are the mostral variance and mean respectively.

Solving these two equations we get the moment estimators $\hat{\lambda}$ and $\hat{\phi}$ of $\lambda$ and $\phi$.

$$\bar{\lambda} = \frac{\bar{x}^2}{s^2 - \bar{x}}$$

$$\bar{\phi} = \frac{s^2 - \bar{x}}{\bar{x}}$$

### Maximum likelihood {#Maximum_likelihood}

Calculating the maximum likelihood estimator of $\lambda$ and $\phi$ involves multiplying all the probabilities in the [probability mass function](wikipedia://en/154725) to obtain the expression $\mathcal{L}(\lambda,\phi;x_1,\ldots,x_n)$.

When we apply the parameterization adjustment defined in "Other Properties," we get $\mathcal{L}(\mu, d;X)$. We may define the [Maximum likelihood estimation](wikipedia://en/140806) based on a single parameter if we estimate the $\mu$ as the $\bar{x}$ (sample mean) given a sample *X* of size *N*. We can see it below.

$$\mathcal{L}(d;X)= \prod_{i=1}^n P(x_i;d)$$

- To estimate the probabilities, we will use the **p.m.f. of recurring successions**, so that the calculation is less complex.

## Testing Poisson assumption {#Testing_Poisson_assumption}

When $\operatorname{NA(\lambda,\phi)}$ is used to simulate a data sample it is important to see if the [Poisson distribution](wikipedia://en/23009144) fits the data well. For this, the following Hypothesis test is used:

$$\begin{cases} H_0: d=1 \\ H_1: d> 1 \end{cases}$$

### Likelihood-ratio test {#Likelihood-ratio_test}

The [likelihood-ratio test](wikipedia://en/45035) statistic for $\operatorname{NA}$ is,

$$W = 2(\mathcal{L}(X;\mu,d)-\mathcal{L}(X;\mu,1))$$

Where likelihood $\mathcal{L}()$ is the log-likelihood function. *W* does not have an asymptotic $\chi_1^2$ distribution as expected under the null hypothesis since *d* = 1 is at the parameter domain's edge. In the asymptotic distribution of *W,* it can be demonstrated that the constant 0 and $\chi_1^2$ have a 50:50 mixture. For this mixture, the $\alpha$ upper-tail percentage points are the same as the $2\alpha$ upper-tail percentage points for a $\chi_1^2$

## Related distributions {#Related_distributions}

The [poisson distribution](wikipedia://en/23009144) (on { 0, 1, 2, 3, ... }) is a special case of the Neyman Type A distribution, with

$$\operatorname{Pois}(\lambda) = \operatorname{NA}(\lambda,\, 0).\,$$

From moments of order 1 and 2 we can write the population mean and variance based on the parameters $\lambda$ and $\phi$.

$$\mu = \lambda\phi$$

$$\sigma^2 = \lambda\phi (1 + \phi)$$

In the dispersion index *d* we observe that by substituting $\mu$ for the parametrized equation of order 1 and $\sigma$ for the one of order 2, we obtain $d = 1 + \phi$. Our variable *Y* is therefore distributed as a Poisson of parameter $\lambda$ when *d* approaches to 1.

Then we have that,

$$\lim_{d\rightarrow 1}\operatorname{NA}(\lambda,\, \phi) \rightarrow \operatorname{Pois}(\lambda)$$

## Applications {#Applications}

### Usage History {#Usage_History}

When the Neyman's type A species' reproduction results in [clusters](wikipedia://en/5797), a distribution has been used to characterize the dispersion of plants. This typically occurs when a species develops from offspring of parent plants or from seeds that fall close to the parent plant. However, Archibald (1948\][^o37] observed that there is insufficient data to infer the kind of reproduction from the type of fitted distribution. While Neyman type A produced positive results for plant distributions, Evans (1953\][^o5] showed that [Negative binomial distribution](wikipedia://en/45177) produced positive results for insect distributions. Neyman type A distributions have also been studied in the context of [ecology](https://en.wikipedia.org/wiki/Ecology), and the results that unless the plant clusters are so compact as to not lie across the edge of the square used to pick sample locations, the distribution is unlikely to be applicable to plant populations. The compactness of the clusters is a hidden assumption in Neyman's original derivation of the distribution, according to Skellam (1958).[^o38] The results were shown to be significantly impacted by the square size selection.

In the context of bus driver accidents, Cresswell and Froggatt (1963) [^o6] derived the Neyman type A based on the following hypotheses:

1. Each driver is susceptible to "spells," the number of which is Poissonian for any given amount of time, with the same parameter $\lambda$ for all drivers.
1. A driver's performance during a spell is poor, and he is likely to experience a Poissonian number of collisions, with the same parameter $\phi$ for all drivers.
1. Each driver behaves independently.
1. No accidents can occur outside of a spell.

These assumptions lead to a Neyman type A distribution via the $\operatorname{Pois(\lambda)}$ and $\operatorname{Pois(\phi)}$ model. In contrast to their "short distribution," Cresswell and Froggatt called this one the "long distribution" because of its lengthy tail. According to Irwin(1964), a type A distribution can also be obtained by assuming that various drivers have different levels of proneness, or *K*. with probability:

$$\operatorname{P(K = k\phi)} = \frac{e^{-\lambda} \lambda^k}{k!}$$

- taking values $~ 0,~ \phi, ~ 2\phi, ~ 3\phi, ~ ...$

and that a driver with proneness *k*$\phi$ has *X* accidents where:

$$~\operatorname{P(X = x|k\phi)} = \frac{e^{-k\phi}(k\phi)^x}{x!}$$

This is the $~\operatorname{Pois(k\phi)} \wedge \operatorname{Pois(\lambda)}$ model with mixing over the values taken by *K*.

Distribution was also suggested in the application for the grouping of minority tents for food from 1965 to 1969. In this regard, it was predicted that only the clustering rates or the average number of entities per grouping needed to be approximated, rather than adjusting distributions on d very big data bases.
