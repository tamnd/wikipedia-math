# Buffer analysis

::: {#o1 .subject cue=lead name="Buffer analysis"}

Proximity analysis In [geographic information systems](https://en.wikipedia.org/wiki/Geographic_information_system) (GIS) and [spatial analysis](wikipedia://en/3190431), **buffer analysis** is the determination of a [zone](wikipedia://en/542465) around a [geographic feature](https://en.wikipedia.org/wiki/Geographic_feature) containing locations that are within a specified distance of that feature, the **buffer zone** (or just **buffer**).[^o2] A buffer is likely the most commonly used tool within the [proximity analysis](https://en.wikipedia.org/wiki/Proximity_analysis) methods.[^o3]

:::

## History {#History}

The buffer operation has been a core part of GIS functionality since the original integrated GIS software packages of the late 1970s and early 1980s, such as [ARC/INFO](https://en.wikipedia.org/wiki/ArcInfo), [Odyssey](https://en.wikipedia.org/wiki/Odyssey_GIS), and [MOSS](https://en.wikipedia.org/wiki/Map_Overlay_and_Statistical_System). Although it has been one of the most widely used GIS operations in subsequent years, in a wide variety of applications, there has been little published research on the tool itself, except for the occasional development of a more efficient algorithm.[^o5]

## Basic algorithm {#Basic_algorithm}

*Image: GIS Buffer.png.* Diagram showing the construction of a buffer (red) of a polyline feature (blue)

The fundamental method to create a buffer around a geographic feature stored in a [vector](https://en.wikipedia.org/wiki/Vector_graphics) data model, with a given radius *r* is as follows:[^o7]

- Single point: Create a circle around the point with radius *r*.
- Polyline, which consists of an ordered list of points (vertices) connected by straight lines. This is also used for the boundary of a polygon.

<!-- -->

1. Create a circle buffer around each vertex
1. Create a rectangle along each line segment by creating a duplicate line segment offset the distance *r* perpendicular to each side.
1. Merge or dissolve the rectangles and circles into a single polygon.

Software implementations of the buffer operation typically use alterations of this strategy to process more efficiently and accurately.

In Mathematics, GIS Buffer operation is a [Minkowski Sum](wikipedia://en/504105) (or difference) of a geometry and a disk. Other terms used: Offsetting a Polygon.[^o8]

### Planar vs. geodesic distance {#Planar_vs._geodesic_distance}

Traditional implementations assumed the buffer was being created on a planar [cartesian coordinate space](wikipedia://en/7706) (i.e., created by a [map projection](wikipedia://en/51784)) using [Euclidean geometry](wikipedia://en/9417), because the mathematics and computation involved is relatively simple, which was important given the computing power available in the late 1970s. Due to the inherent distortions caused by map projections, the buffer computed this way will not be identical to one drawn on the surface of the Earth; at a local scale, the difference is negligible, but at larger scales, the error can be significant.

Some current software, such as Esri [ArcGIS Pro](https://en.wikipedia.org/wiki/ArcGIS_Pro), offer the option to compute buffers using *geodesic distance*, using a similar algorithm but calculated using [spherical trigonometry](wikipedia://en/650405), including representing the lines between vertices as [great circles](wikipedia://en/48082).[^o7] Other implementations use a workaround by first reprojecting the feature to a projection that minimizes distortion in that location, then computing the planar buffer.[^o10]

### Options {#Options}

GIS software may offer variations on the basic algorithm, which may be useful in different applications:[^o2]

- Endcaps at the end of linear buffers are rounded by default, but may be squared off or a butt end (truncated at the final vertex).
- Side preference may be important, such as needing the buffer on only one side of a line, or on a polygon, selecting only the outer buffer or the inner buffer (sometimes called a *setback*).
- Variable width, in which the features in a layer may be buffered using different radii, usually given by an attribute.
- Common buffers, in which the buffers for each feature in a layer are dissolved into a single polygon. This is most commonly used when one is not concerned about which feature is near each point in space, only that a point is nearby some (anonymous) feature.
