# Partial residual plot

::: {#o1 .subject cue=lead name="Partial residual plot"}

In [applied statistics](https://en.wikipedia.org/wiki/Applied_statistics), a **partial residual plot** is a [graphical technique](https://en.wikipedia.org/wiki/Graphical_technique) that attempts to show the relationship between a given [independent variable](https://en.wikipedia.org/wiki/Independent_variable) and the [response variable](https://en.wikipedia.org/wiki/Response_variable) given that other independent variables are also in the [model](wikipedia://en/27576).

:::

## Background {#Background}

When performing a [linear regression](wikipedia://en/48758386) with a single [independent variable](https://en.wikipedia.org/wiki/Independent_variable), a [scatter plot](wikipedia://en/412544) of the [response variable](https://en.wikipedia.org/wiki/Response_variable) against the independent variable provides a good indication of the nature of the relationship. If there is more than one independent variable, things become more complicated. Although it can still be useful to generate scatter plots of the response variable against each of the independent variables, this does not take into account the effect of the other independent variables in the model.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Partial residual plots are formed as

$$\text{Residuals} + \hat{\beta}_iX_i \text{ versus } X_i,$$

where

Residuals = [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) from the [full model](https://en.wikipedia.org/wiki/Full_model),

$\hat{\beta}_i$ = regression coefficient from the *i*-th independent variable in the full model,

*X*<sub>i</sub> = the *i*-th independent variable.

Partial residual plots are widely discussed in the regression diagnostics literature (e.g., see the References section below). Although they can often be useful, they can also fail to indicate the proper relationship. In particular, if *X*<sub>i</sub> is highly correlated with any of the other independent variables, the variance indicated by the partial residual plot can be much less than the actual variance. These issues are discussed in more detail in the references given below.

:::

## CCPR plot {#CCPR_plot}

The CCPR (component and component-plus-residual) plot is a refinement of the partial residual plot, adding

$$\hat{\beta}_iX_i \mathrm{\ versus\ } X_i.$$

This is the "component" part of the plot and is intended to show where the "fitted line" would lie.
