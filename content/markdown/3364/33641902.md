# Inverted bell curve

::: {#o1 .subject cue=lead name="Inverted bell curve"}

In statistics, an **inverted bell curve** is a term used loosely or metaphorically to refer to a [bimodal distribution](wikipedia://en/1068378) that falls to a trough between two peaks, rather than (as in a standard [bell curve](wikipedia://en/21462)) rising to a single peak and then falling off on both sides.[^o2]

:::
