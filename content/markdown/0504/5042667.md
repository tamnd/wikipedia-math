# Absolute value (algebra)

::: {#o1 .subject cue=lead name="Absolute value"}

In [algebra](wikipedia://en/18716923), an **absolute value** is a [function](wikipedia://en/185427) that generalizes the usual [absolute value](wikipedia://en/991).[^o2] More precisely, if $D$ is a [field](wikipedia://en/10603) or (more generally) an [integral domain](wikipedia://en/15462), an *absolute value* on $D$ is a function, commonly denoted $|x|,$ from $D$ to the [real numbers](wikipedia://en/20646438) satisfying:

:::

|  | • | $\left\|x\right\|\geq0$ |  | (non-negativity) |
|---|---|---|---|---|
|  | • | $\left\|x\right\|=0$ if and only if $x=0$ |  | ([positive definiteness](wikipedia://en/649616)) |
|  | • | $\left\|xy\right\|=\left\|x\right\|\left\|y\right\|$ |  | (multiplicativity) |
|  | • | $\left\|x+y\right\|\leq\left\|x\right\|+\left\|y\right\|$ |  | ([triangle inequality](wikipedia://en/53941)) |

It follows from the axioms that $|1| = 1,$ $|-1| = 1,$ and $|-x|=|x|$ for every $x$. Furthermore, for every positive [integer](wikipedia://en/14563) $n$, $|n|\le n,$ where the leftmost $n$ denotes the sum of $n$ summands equal to the [identity element](wikipedia://en/14962) of $D$.

The classical [absolute value](wikipedia://en/991) and its [square root](wikipedia://en/29208) are examples of absolute values, but the square of the classical absolute value is not, as it does not fulfill the triangular inequality.

An absolute value induces a [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) (and thus a [topology](wikipedia://en/30450#Definitions)) on $D$ by setting $d(x,y) = |x - y|.$

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- The standard absolute value on the integers, the rationals and the real numbers: $|x|=x$ for $x\geq 0$ and $|x|=-x$ for $x<0$.
- The standard [absolute value](wikipedia://en/991#Complex_numbers) or modulus on the [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers): $|a+bi|=\sqrt{a^2+b^2}$ for $a,b\in\mathbb{R}$.
- The [*p*-adic absolute value](wikipedia://en/16047618#p-adic_absolute_value) on the [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers), where *p* is a fixed [prime](wikipedia://en/23666): $|0|_p=0$ and for $x\ne 0$ we set $|x|_p=p^{-n}$, where $n$ is the unique integer such that $x=p^n \frac{a}{b}$ and *a* and *b* are two integers [coprime](wikipedia://en/6556) with *p.*
- The *p*-adic absolute value on the [*p*-adic numbers](https://en.wikipedia.org/wiki/P-adic_numbers), arising from the completion (see #Completions below) of the rationals with the absolute value defined above.
- If $F(x)$ is the field of [rational fractions](https://en.wikipedia.org/wiki/Rational_fraction) over a field $F$ in the variable *x* and $P$ is a fixed [irreducible polynomial](wikipedia://en/188725) over $F$, the *$P$-adic* absolute value on $F(x)$ is defined as follows: $|0|_P=0$ and for $f\ne 0$ we set $|f|_P=2^{-n},$ where $n$ is the unique integer such that $f = P^n \frac{G}{H},$ where $G$ and $H$ are two polynomials, both [coprime](https://en.wikipedia.org/wiki/Coprime_polynomials) with $P$.
- Absolute values are used to define or characterize [global](wikipedia://en/288358) and [local](wikipedia://en/145375) fields.

:::

## Types of absolute value {#Types_of_absolute_value}

The **trivial** absolute value is the absolute value with |*x*| = 0 when *x* = 0 and |*x*| = 1 otherwise.[^o7] Every integral domain can carry at least the trivial absolute value. The trivial value is the only possible absolute value on a [finite field](wikipedia://en/11615) because any non-zero element can be raised to some power to yield 1.

If an absolute value satisfies the stronger property |*x* + *y*| ≤ max(|*x*|, |*y*|) for all *x* and *y*, then |*x*| is called an [ultrametric](https://en.wikipedia.org/wiki/Ultrametric) or **non-Archimedean absolute value**, and otherwise an **Archimedean absolute value**.

:::

## Places {#Places}

If |*x*|<sub>1</sub> and |*x*|<sub>2</sub> are two absolute values on the same integral domain *D*, then the two absolute values are *equivalent* if |*x*|<sub>1</sub> \< 1 [if and only if](wikipedia://en/14922) |*x*|<sub>2</sub> \< 1 for all *x*. If two nontrivial absolute values are equivalent, then for some exponent *e* we have |*x*|<sub>1</sub><sup>*e*</sup> = |*x*|<sub>2</sub> for all *x*. Raising an absolute value to a power less than 1 results in another absolute value, but raising to a power greater than 1 does not necessarily result in an absolute value. (For instance, squaring the usual absolute value on the real numbers yields a function which is not an absolute value because it violates the rule |*x*+*y*| ≤ |*x*|+|*y*|.) Absolute values up to equivalence, or in other words, an [equivalence class](wikipedia://en/9260) of absolute values, is called a **[place](wikipedia://en/174705#Places)**.

Since the ordinary absolute value and the *p*-adic absolute values are absolute values according to the definition above, these define places.

[Ostrowski's theorem](wikipedia://en/3360343) states that the nontrivial places of the [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) **Q** are the ordinary [absolute value](wikipedia://en/991) and the [*p*-adic absolute value](wikipedia://en/51423) for each prime *p*[^o10] (see the third example above).

:::

## Valuations {#Valuations}

If for some ultrametric absolute value and any base *b* > 1, we define *ν*(*x*) = −log<sub>*b*</sub>|*x*| for *x* ≠ 0 and *ν*(0) = ∞, where ∞ is ordered to be greater than all real numbers, then we obtain a function from *D* to **R** ∪ {∞}, with the following properties:

- *ν*(*x*) = ∞ ⇒ *x* = 0,
- *ν*(*xy*) = *ν*(*x*) + *ν*(*y*),
- *ν*(*x* + *y*) ≥ min(ν(*x*), *ν*(*y*)).

Such a function is known as a *[valuation](wikipedia://en/347049)* in the terminology of [Bourbaki](wikipedia://en/167394), but other authors use the term *valuation* for *absolute value* and then say *exponential valuation* instead of *valuation*.

## Completions {#Completions}

Given an integral domain *D* with an absolute value, we can define the [Cauchy sequences](wikipedia://en/6085) of elements of *D* with respect to the absolute value by requiring that for every ε > 0 there is a positive integer *N* such that for all integers *m*, *n* > *N* one has |*x*<sub>*m*</sub> − *x*<sub>*n*</sub>| \< ε. Cauchy sequences form a [ring](wikipedia://en/48404) under pointwise addition and multiplication. One can also define null sequences as sequences (*a*<sub>*n*</sub>) of elements of *D* such that |*a*<sub>*n*</sub>| converges to zero. Null sequences are a [prime ideal](wikipedia://en/24928) in the ring of Cauchy sequences, and the [quotient ring](wikipedia://en/184635) is therefore an integral domain. The domain *D* is [embedded](wikipedia://en/52119) in this quotient ring, called the [completion](wikipedia://en/7832) of *D* with respect to the absolute value |*x*|.

Since fields are integral domains, this is also a construction for the completion of a field with respect to an absolute value. To show that the result is a field, and not just an integral domain, we can either show that null sequences form a [maximal ideal](wikipedia://en/48164), or else construct the inverse directly. The latter can be easily done by taking, for all nonzero elements of the quotient ring, a sequence starting from a point beyond the last zero element of the sequence. Any nonzero element of the quotient ring will differ by a null sequence from such a sequence, and by taking pointwise inversion we can find a representative inverse element.

Another theorem of [Alexander Ostrowski](wikipedia://en/5827091) has it that any field complete with respect to an [Archimedean](wikipedia://en/1844) absolute value is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to either the real or the complex numbers, and the valuation is equivalent to the usual one.[^o13] The **Gelfand-Tornheim theorem** states that any field with an Archimedean valuation is isomorphic to a [subfield](wikipedia://en/11634) of **C**, the valuation being equivalent to the usual absolute value on **C**.[^o14]

## Fields and integral domains {#Fields_and_integral_domains}

If *D* is an integral domain with absolute value |*x*|, then we may extend the definition of the absolute value to the [field of fractions](wikipedia://en/25271) of *D* by setting

$$|x/y| = |x|/|y|.\,$$

On the other hand, if *F* is a field with ultrametric absolute value |*x*|, then the set of elements of *F* such that |*x*| ≤ 1 defines a [valuation ring](wikipedia://en/966856), which is a [subring](wikipedia://en/24873145) *D* of *F* such that for every nonzero element *x* of *F*, at least one of *x* or *x*<sup>−1</sup> belongs to *D*. Since *F* is a field, *D* has no [zero divisors](wikipedia://en/51441) and is an integral domain. It has a unique [maximal ideal](wikipedia://en/48164) consisting of all *x* such that |*x*| \< 1, and is therefore a [local ring](wikipedia://en/153391).
