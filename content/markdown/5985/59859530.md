# EP matrix

::: {#o1 .subject cue=lead name="EP matrix"}

In mathematics, an **EP matrix** (or **range-Hermitian matrix**[^o2] or **RPN matrix**[^o3]) is a square matrix *A* whose range is equal to the range of its [conjugate transpose](wikipedia://en/217548) *A*\*. Another equivalent characterization of EP matrices is that the range of *A* is orthogonal to the nullspace of *A*. Thus, EP matrices are also known as RPN (Range Perpendicular to Nullspace) matrices.

:::

EP matrices were introduced in 1950 by [Hans Schwerdtfeger](https://en.wikipedia.org/wiki/Hans_Schwerdtfeger),[^o2][^o4] and since then, many equivalent characterizations of EP matrices have been investigated through the literature.[^o5] The meaning of the EP abbreviation stands originally for *E*qual *P*rincipal, but it is widely believed that it stands for *Equal [Projectors](wikipedia://en/519182)* instead, since an equivalent characterization of EP matrices is based in terms of equality of the projectors *AA<sup>\+</sup>* and *A<sup>\+</sup>A*.[^o6]

The range of any matrix *A* is perpendicular to the null-space of *A*\*, but is not necessarily perpendicular to the null-space of *A*. When *A* is an EP matrix, the range of *A* is precisely perpendicular to the null-space of *A*.

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- An equivalent characterization of an EP matrix *A* is that *A* commutes with its [Moore-Penrose inverse](https://en.wikipedia.org/wiki/Moore-Penrose_inverse), that is, the projectors *AA<sup>\+</sup>* and *A<sup>\+</sup>A* are equal. This is similar to the characterization of normal matrices where *A* commutes with its conjugate transpose.[^o5] As a corollary, [nonsingular matrices](https://en.wikipedia.org/wiki/Nonsingular_matrix) are always EP matrices.
- The sum of EP matrices *A*<sub>i</sub> is an EP matrix if the null-space of the sum is contained in the null-space of each matrix *A*<sub>i</sub>.[^o9]
- To be an EP matrix is a necessary condition for normality: *A* is normal if and only if *A* is EP matrix and *AA*\**A*<sup>2</sup> = *A*<sup>2</sup>*A*\**A*.[^o5]
- When *A* is an EP matrix, the Moore-Penrose inverse of *A* is equal to the [group inverse](wikipedia://en/13079354) of *A*.[^o5]
- *A* is an EP matrix if and only if the Moore-Penrose inverse of *A* is an EP matrix.[^o5]

:::

## Decomposition {#Decomposition}

The [spectral theorem](wikipedia://en/123495) states that a matrix is normal if and only if it is [unitarily similar](https://en.wikipedia.org/wiki/Similar_matrix) to a [diagonal matrix](wikipedia://en/174080).

Weakening the normality condition to EPness, a similar statement is still valid. Precisely, a matrix *A* of rank *r* is an EP matrix if and only if it is unitarily similar to a core-nilpotent matrix,[^o3] that is,

$$A = U \begin{pmatrix} C & 0 \\ 0 & 0 \end{pmatrix} U^{*},$$

where *U* is an [orthogonal matrix](wikipedia://en/105620) and *C* is an *r* x *r* nonsingular matrix. Note that if *A* is full rank, then *A* = *UCU*<sup>\*</sup>.
