# Entropic vector

::: {#o1 .subject cue=lead name="Entropic vector"}

The **entropic vector** or **entropic function** is a concept arising in [information theory](wikipedia://en/14773). It represents the possible values of [Shannon](wikipedia://en/5693)'s [information entropy](https://en.wikipedia.org/wiki/Information_entropy) that subsets of one set of random variables may take. Understanding which vectors are entropic is a way to represent all possible inequalities between entropies of various subsets. For example, for any two random variables $X_1,X_2$, their joint entropy (the entropy of the random variable representing the pair $X_1,X_2$) is at most the sum of the entropies of $X_1$ and of $X_2$:

:::

$$H(X_1,X_2) \leq H(X_1) + H(X_2)$$

Other information-theoretic measures such as [conditional information](https://en.wikipedia.org/wiki/Conditional_information), [mutual information](wikipedia://en/427282), or [total correlation](wikipedia://en/6961430) can be expressed in terms of joint entropy and are thus related by the corresponding inequalities. Many inequalities satisfied by entropic vectors can be derived as linear combinations of a few basic ones, called *Shannon-type inequalities*. However, it has been proven that already for $n=4$ variables, no finite set of linear inequalities is sufficient to characterize all entropic vectors.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

[Shannon](wikipedia://en/5693)'s [information entropy](https://en.wikipedia.org/wiki/Information_entropy) of a random variable $X$ is denoted $H(X)$. For a tuple of random variables $X_1,X_2,\ldots,X_n$, we denote the [joint entropy](wikipedia://en/910967) of a subset $X_{i_1},X_{i_2},\dots,X_{i_k}$ as $H(X_{i_1},X_{i_2},\dots,X_{i_k})$, or more concisely as $H(X_I)$, where $I=\{i_1,i_2,\dots,i_k\}$. Here $X_I$ can be understood as the random variable representing the tuple $(X_{i_1},X_{i_2},\dots,X_{i_k})$. For the empty subset $I=\emptyset$, $X_I$ denotes a deterministic variable with entropy 0.

A vector *h* in $\mathbb{R}^{2^n}$ indexed by subsets of $\{1,2,\dots,n\}$ is called an *entropic vector* of order $n$ if there exists a tuple of random variables $X_1,X_2,\ldots,X_n$ such that $h(I)=H(X_I)$ for each subset $I \subseteq \{1,2,\dots,n\}$.

The set of all entropic vectors of order $n$ is denoted by $\Gamma_n^*$. Zhang and Yeung[^o4] proved that it is not closed (for $n \geq 3$), but its [closure](wikipedia://en/42309), $\bar{\Gamma_n^*}$, is a [convex](wikipedia://en/6292) [cone](wikipedia://en/3558266) and hence characterized by the (infinitely many) linear inequalities it satisfies. Describing the region $\bar{\Gamma_n^*}$ is thus equivalent to characterizing all possible inequalities on joint entropies.

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

Let *X*,*Y* be two independent random variables with [discrete uniform distribution](wikipedia://en/1699214) over the set $\{0,1\}$. Then

$$H(X) = H(Y) = 1$$

(since each is uniformly distributed over a two-element set), and

$$H(X,Y)= H(X) + H(Y) = 2$$

(since the two variables are independent, which means the pair $(X_1,X_2)$ is uniformly distributed over $(0,0),(0,1),(1,0),(1,1)$.) The corresponding entropic vector is thus:

$$v = (0,1,1,2)^{\mathsf T} \in \Gamma_2^*$$

On the other hand, the vector $(0,1,1,3)^{\mathsf T}$ is not entropic (that is, $(0,1,1,3)^{\mathsf T} \not\in \Gamma_2^*$), because any pair of random variables (independent or not) should satisfy $H(X,Y) \leq H(X) + H(Y)$.

:::

## Characterizing entropic vectors: the region Γ<sub>*n*</sub><sup>\*</sup> {#Characterizing_entropic_vectors:_the_region_&Gamma;n*}

### Shannon-type inequalities and Γ<sub>*n*</sub> {#Shannon-type_inequalities_and_&Gamma;n}

For a tuple of random variables $X_1,X_2,\ldots,X_n$, their entropies satisfy:

$$1) \quad H(X_\emptyset) = 0$$

$2) \quad H(X_I) \leq H(X_J)$, for any $I \subseteq J \subseteq \{1,\dots,n\}$

In particular, $H(X_I) \geq 0$, for any $I \subseteq \{1,\dots,n\}$.

The **Shannon inequality** says that an entropic vector is [submodular](https://en.wikipedia.org/wiki/Submodular):

$3) \quad H(X_I) + H(X_J) \geq H(X_{I\cup J}) + H(X_{I \cap J})$, for any $I,J \subseteq \{1,\dots,n\}$

It is equivalent to the inequality stating that the [conditional mutual information](wikipedia://en/18867510) is non-negative:

$$\begin{aligned} I(X;Y\mid Z) &= H(X\mid Z) - H(X\mid Y,Z) \\ &= H(X\mid Z)+H(Y\mid Z)-H(X,Y\mid Z)\\ &= H(X,Z) + H(Y,Z) - H(X,Y,Z) - H(Z)\\ &\geq 0 \end{aligned}$$

(For one direction, observe this the last form expresses Shannon's inequality for subsets $X,Z$ and $Y,Z$ of the tuple $X,Y,Z$; for the other direction, substitute $X=X_I$, $Y=X_J$, $Z=X_{I \cap J}$).

Many inequalities can be derived as linear combinations of Shannon inequalities; they are called **Shannon-type inequalities** or *basic information inequalities* of Shannon's information measures.[^o14] The set of vectors that satisfies them is called $\Gamma_n$; it contains $\Gamma_n^*$.

Software has been developed to automate the task of proving Shannon-type inequalities.[^o9][^o10] Given an inequality, such software is able to determine whether the given inequality is a valid Shannon-type inequality (i.e., whether it contains the cone $\Gamma_n$).

::: {#o12 .pointer-item cue=pointer name="Non-Shannon inequality"}

### Non-Shannon-type inequalities {#Non-Shannon-type_inequalities}

The question of whether Shannon-type inequalities are the only ones, that is, whether they completely characterize the region $\Gamma_n^*$, was first asked by Te Su Han in 1981[^o14] and more precisely by [Nicholas Pippenger](https://en.wikipedia.org/wiki/Nicholas_Pippenger) in 1986.[^o13] It is not hard to show that this is true for two variables, that is, $\Gamma_2^* = \Gamma_2$. For three variables, Zhang and Yeung[^o4] proved that $\Gamma_3^* \neq \Gamma_3$; however, it is still asymptotically true, meaning that the closure is equal: $\overline{\Gamma_3^*} = \Gamma_3$. In 1998, Zhang and Yeung[^o14][^o15] showed that $\overline{\Gamma_n^*} \neq \Gamma_n$ for all $n\geq 4$, by proving that the following inequality on four random variables (in terms of conditional mutual information) is true for any entropic vector, but is not Shannon-type:

$$2I(X_3;X_4) \leq I(X_1;X_2) + I(X_1;X_3,X_4) + 3I(X_3;X_4|X_1) + I(X_3;X_4| X_2)$$

Further inequalities and infinite families of inequalities have been found.[^o16][^o17][^o18][^o19] These inequalities provide outer bounds for $\overline{\Gamma_n^*}$ better than the Shannon-type bound $\Gamma_n$. In 2007, Matus proved that no finite set of linear inequalities is sufficient (to deduce all as linear combinations), for $n\geq 4$ variables. In other words, the region $\overline{\Gamma_4^*}$ is not polyhedral.[^o20] Whether they can be characterized in some other way (allowing to effectively decide whether a vector is entropic or not) remains an [open problem](wikipedia://en/1333335).

Analogous questions for [von Neumann entropy](wikipedia://en/2515425) in [quantum information theory](https://en.wikipedia.org/wiki/Quantum_information_theory) have been considered.[^o21]

:::

### Inner bounds {#Inner_bounds}

Some inner bounds of $\overline{\Gamma_n^*}$ are also known. One example is that $\overline{\Gamma_4^*}$ contains all vectors in $\Gamma_4$ which additionally satisfy the following inequality (and those obtained by permuting variables), known as **[Ingleton's inequality](wikipedia://en/39661138) for entropy**:[^o23]

$I(X_1;X_2)+I(X_3;X_4\mid X_1)+I(X_3;X_4\mid X_2)-I(X_3;X_4) \geq 0$[^o14]

## Entropy and groups {#Entropy_and_groups}

### Group-characterizable vectors and quasi-uniform distributions {#Group-characterizable_vectors_and_quasi-uniform_distributions}

Consider a [group](wikipedia://en/19447) $G$ and subgroups $G_1, G_2, \dots, G_n$ of $G$. Let $G_I$ denote $\bigcap_{i \in I} G_i$ for $I \subseteq \{1,\dots,n\}$; this is also a subgroup of $G$. It is possible to construct a probability distribution for $n$ random variables $X_1,\dots,X_n$ such that

$H(X_I) = \log \frac{|G|}{|G_I|}$.[^o26]

(The construction essentially takes an element $a$ of $G$ uniformly at random and lets $X_i$ be the corresponding [coset](wikipedia://en/98759) $aG_i$). Thus any information-theoretic inequality implies a group-theoretic one. For example, the basic inequality $H(X,Y) \leq H(X) + H(Y)$ implies that

$$|G| \cdot |G_1 \cap G_2| \geq |G_1| \cdot |G_2|.$$

It turns out the converse is essentially true. More precisely, a vector is said to be *group-characterizable* if it can be obtained from a tuple of subgroups as above. The set of group-characterizable vectors is denoted $\Upsilon^n$. As said above, $\Upsilon^n \subseteq \Gamma^*_n$. On the other hand, $\Gamma^*_n$ (and thus $\overline{\Gamma^*_n}$) is contained in the topological closure of the convex closure of $\Upsilon^n$.[^o27] In other words, a linear inequality holds for all entropic vectors if and only if it holds for all vectors $h$ of the form $h_I=\log \frac{|G|}{|G_I|}$, where $I$ goes over subsets of some tuple of subgroups $G_1, G_2, \dots, G_n$ in a group $G$.

Group-characterizable vectors that come from an [abelian group](wikipedia://en/2974) satisfy Ingleton's inequality.

## Kolmogorov complexity {#Kolmogorov_complexity}

[Kolmogorov complexity](wikipedia://en/1635) satisfies essentially the same inequalities as entropy. Namely, denote the Kolmogorov complexity of a finite string $x$ as $K(x)$ (that is, the length of the shortest program that outputs $x$). The joint complexity of two strings $x,y$, defined as the complexity of an encoding of the pair $\langle x,y\rangle$, can be denoted $K(x,y)$. Similarly, the [conditional complexity](wikipedia://en/1635#Conditional_versions) can be denoted $K(x|y)$ (the length of the shortest program that outputs $x$ given $y$). [Andrey Kolmogorov](wikipedia://en/91161) noticed these notions behave similarly to Shannon entropy, for example:

$$K(a)+K(b) \geq K(a,b) - O(\log |a| + \log |b|)$$

In 2000, Hammer et al.[^o29] proved that indeed an inequality holds for entropic vectors if and only if the corresponding inequality in terms of Kolmogorov complexity holds up to logarithmic terms for all tuples of strings.
