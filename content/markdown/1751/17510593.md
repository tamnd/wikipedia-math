# Hyperstability

::: {#o1 .subject cue=lead name="Hyperstability"}

In [stability theory](wikipedia://en/5493795), **hyperstability** is a property of a system that requires the [state vector](https://en.wikipedia.org/wiki/State_space_representation) to remain bounded if the inputs are restricted to belonging to a subset of the set of all possible inputs.[^o2]

:::

Definition:[^o3] A system is hyperstable if there are two constants $k_1 \ge 0, k_2 \ge 0$ such that any state trajectory of the system satisfies the inequality:

$$\| x(t) \| < k_1 \|x(0)\| + k_2, \, \forall t \ge 0$$
