# Additive model

::: {#o1 .subject cue=lead name="Additive model"}

In [statistics](wikipedia://en/26685), an **additive model** (**AM**) is a [nonparametric regression](wikipedia://en/4536068) method. It was suggested by [Jerome H. Friedman](wikipedia://en/40671069) and Werner Stuetzle (1981)[^o2] and is an essential part of the [ACE](wikipedia://en/56621706) algorithm. The *AM* uses a one-dimensional [smoother](wikipedia://en/4155662) to build a restricted class of nonparametric regression models. Because of this, it is less affected by the [curse of dimensionality](wikipedia://en/787776) than a *p*-dimensional smoother. Furthermore, the *AM* is more flexible than a [standard linear model](wikipedia://en/48758386), while being more interpretable than a general regression surface at the cost of approximation errors. Problems with *AM*, like many other machine-learning methods, include [model selection](wikipedia://en/3664073), [overfitting](wikipedia://en/173332), and [multicollinearity](wikipedia://en/1486691).

:::

## Description {#Description}

Given a [data](https://en.wikipedia.org/wiki/Data) set $\{y_i,\, x_{i1}, \ldots, x_{ip}\}_{i=1}^n$ of *n* [statistical units](wikipedia://en/27580), where $\{x_{i1}, \ldots, x_{ip}\}_{i=1}^n$ represent predictors and $y_i$ is the outcome, the *additive model* takes the form

$$\mathrm{E}[y_i|x_{i1}, \ldots, x_{ip}] = \beta_0+\sum_{j=1}^p f_j(x_{ij})$$

or

$$Y= \beta_0+\sum_{j=1}^p f_j(X_{j})+\varepsilon$$

Where $\mathrm{E}[ \epsilon ] = 0$, $\mathrm{Var}(\epsilon) = \sigma^2$ and $\mathrm{E}[ f_j(X_{j}) ] = 0$. The functions $f_j(x_{ij})$ are unknown [smooth functions](https://en.wikipedia.org/wiki/Smooth_function) fit from the data. Fitting the *AM* (i.e. the functions $f_j(x_{ij})$) can be done using the [backfitting algorithm](wikipedia://en/25099295) proposed by Andreas Buja, [Trevor Hastie](https://en.wikipedia.org/wiki/Trevor_Hastie) and [Robert Tibshirani](wikipedia://en/31404681) (1989).[^o4]
