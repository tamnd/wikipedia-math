# Tilted large deviation principle

::: {#o1 .subject cue=lead name="Tilted large deviation principle"}

In [mathematics](wikipedia://en/18831) — specifically, in [large deviations theory](wikipedia://en/3772909) — the **tilted large deviation principle** is a result that allows one to generate a new [large deviation principle](wikipedia://en/3772816) from an old one by [exponential tilting](wikipedia://en/49288169), i.e. [integration](wikipedia://en/15532) against an [exponential](wikipedia://en/9678) [functional](wikipedia://en/1374948). It can be seen as an alternative formulation of [Varadhan's lemma](wikipedia://en/13354070).

:::

::: {#o3 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let *X* be a [Polish space](wikipedia://en/396622) (i.e., a [separable](wikipedia://en/27855), [completely metrizable](wikipedia://en/7832) [topological space](wikipedia://en/30450)), and let (*μ*<sub>*ε*</sub>)<sub>*ε*>0</sub> be a family of [probability measures](wikipedia://en/43325) on *X* that satisfies the large deviation principle with [rate function](wikipedia://en/3772816) *I* : *X* → \[0, +∞\]. Let *F* : *X* → **R** be a [continuous function](wikipedia://en/6122) that is [bounded](wikipedia://en/311509) from above. For each Borel set *S* ⊆ *X*, let

$$J_{\varepsilon} (S) = \int_{S} e^{ F(x) / \varepsilon} \, \mathrm{d} \mu_{\varepsilon} (x)$$

and define a new family of probability measures (*ν*<sub>*ε*</sub>)<sub>*ε*>0</sub> on *X* by

$$\nu_{\varepsilon} (S) = \frac{J_{\varepsilon} (S)}{J_{\varepsilon} (X)}.$$

Then (*ν*<sub>*ε*</sub>)<sub>*ε*>0</sub> satisfies the large deviation principle on *X* with rate function *I*<sup>*F*</sup> : *X* → \[0, +∞\] given by

$$I^{F} (x) = \sup_{y \in X} \big[ F(y) - I(y) \big] - \big[ F(x) - I(x) \big].$$

:::
