# Webgraph

::: {#o1 .subject cue=lead name="Webgraph"}

A **webgraph** is a set of directed links between pages of the [World Wide Web](https://en.wikipedia.org/wiki/World_Wide_Web). A [graph](wikipedia://en/325806), in general, consists of several vertices, some pairs connected by edges. In a [directed graph](wikipedia://en/19721986), edges are directed lines or arcs. The webgraph is a directed graph, whose vertices correspond to the pages of the WWW, and a directed edge connects page X to page Y if there exists a [hyperlink](https://en.wikipedia.org/wiki/Hyperlink) on page X, referring to page Y.[^o2]

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The [degree distribution](wikipedia://en/2129782) of the webgraph strongly differs from the degree distribution of the classical random graph model, the [Erdős–Rényi model](wikipedia://en/10477221):[^o5] in the Erdős–Rényi model, there are very few large degree nodes, relative to the webgraph's degree distribution. The precise distribution is unclear,[^o6] however: it is relatively well described by a [lognormal](https://en.wikipedia.org/wiki/Lognormal) distribution, as well as the [Barabási–Albert model](wikipedia://en/8286726) for [power laws](https://en.wikipedia.org/wiki/Power_laws).[^o7][^o8]
- The webgraph is an example of a [scale-free network](wikipedia://en/227155).

:::

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

The webgraph is used for:

- computing the [PageRank](https://en.wikipedia.org/wiki/PageRank)[^o11] of the world wide web's pages;
- computing the personalized PageRank;[^o12]
- detecting webpages of similar topics, through graph-theoretical properties only, like co-citation;[^o13]
- and identifying hubs and authorities in the web for [HITS algorithm](https://en.wikipedia.org/wiki/HITS_algorithm).

:::
