# Cylindric numbering

::: {#o1 .subject cue=lead name="Cylindric numbering"}

In [computability theory](wikipedia://en/155414) a **cylindric numbering** is a special kind of [numbering](wikipedia://en/2399097) first introduced by [Yuri L. Ershov](https://en.wikipedia.org/wiki/Yuri_L._Ershov) in 1973.

:::

If a numbering $\nu$ is [reducible](https://en.wikipedia.org/wiki/Reducibility_%28numbering%29) to $\mu$ then there exists a computable function $f$ with $\nu = \mu \circ f$. Usually $f$ is not [injective](https://en.wikipedia.org/wiki/Injective), but if $\mu$ is a cylindric numbering we can always find an injective $f$.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A numbering $\nu$ is called **cylindric** if

$$\nu \equiv_1 c(\nu).$$

That is if it is [one-equivalent](https://en.wikipedia.org/wiki/One_equivalent_numbering) to its [cylindrification](wikipedia://en/2606696)

A set $S$ is called **cylindric** if its [indicator function](wikipedia://en/240790)

$$1_S: \mathbb{N} \to \{0,1\}$$

is a cylindric numbering.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [Gödel numbering](wikipedia://en/207790) is cylindric

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Cylindric numberings are [idempotent](https://en.wikipedia.org/wiki/Idempotent): $\nu \circ \nu = \nu$

:::
