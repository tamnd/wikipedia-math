# Complete numbering

::: {#o1 .subject cue=lead name="Complete numbering"}

In [computability theory](wikipedia://en/155414) **complete numberings** are generalizations of [Gödel numbering](wikipedia://en/2399097) first introduced by [A.I. Mal'tsev](https://en.wikipedia.org/wiki/A.I._Mal'tsev) in 1963. They are studied because several important results like the [Kleene's recursion theorem](wikipedia://en/155407) and [Rice's theorem](wikipedia://en/25852), which were originally proven for the Gödel-numbered set of [computable functions](wikipedia://en/1139338), still hold for arbitrary sets with complete numberings.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [numbering](wikipedia://en/2399097) $\nu$ of a set $A$ is called **complete** (with respect to an element $a \in A$) if for every [partial computable function](https://en.wikipedia.org/wiki/Partial_computable_function) $f$ there exists a [total computable function](https://en.wikipedia.org/wiki/Total_computable_function) $h$ so that (Ershov 1999:482):

$$\nu \circ h(i) = \begin{cases} \nu \circ f(i) & \mbox{if} ~ i \in \operatorname{dom}(f), \\ a & \mbox{otherwise}. \end{cases}$$

Ershov refers to the element *a* as a "special" element for the numbering. A numbering $\nu$ is called **precomplete** if the weaker property holds:

$$\nu \circ f(i) = \nu \circ h(i) \qquad i \in \operatorname{dom}(f).$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any numbering of a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) is complete
- The [identity function](wikipedia://en/15069) on the natural numbers is *not* complete
- A [Gödel numbering](wikipedia://en/2399097) is precomplete

:::
