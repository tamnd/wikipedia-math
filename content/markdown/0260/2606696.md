# Cylindrification

::: {#o1 .subject cue=lead name="Cylindrification"}

In [computability theory](wikipedia://en/155414) a **cylindrification** is a construction that associates a [cylindric numbering](wikipedia://en/2606907) to each [numbering](wikipedia://en/2399097). The concept was first introduced by [Yuri L. Ershov](https://en.wikipedia.org/wiki/Yuri_L._Ershov) in 1973.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a numbering $\nu$, the **cylindrification** $c(\nu)$ is defined as

$$\mathrm{Domain}(c(\nu)) := \{\langle n, k \rangle | n \in \mathrm{Domain}(\nu)\}$$

$$c(\nu)\langle n, k \rangle := \nu(n)$$

where $\langle n, k \rangle$ is the [Cantor pairing function](https://en.wikipedia.org/wiki/Cantor_pairing_function).

Note that the cylindrification operation increases the input arity by 1.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Given two numberings $\nu$ and $\mu$ then $\nu \le \mu \Leftrightarrow c(\nu) \le_1 c(\mu)$
- $$\nu \le_1 c(\nu)$$

:::
