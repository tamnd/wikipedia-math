# Creative and productive sets

::: {#o1 .subject cue=lead name="Creative and productive sets"}

In [computability theory](https://en.wikipedia.org/wiki/Recursion_theory), **productive sets** and **creative sets** are types of sets of [natural numbers](wikipedia://en/21474) that have important applications in [mathematical logic](wikipedia://en/19636). They are a standard topic in mathematical logic textbooks such as (Soare 1987) and (Rogers 1987).

:::

::: {#o5 .definition cue=heading name="Definition and example"}

## Definition and example {#Definition_and_example}

For the remainder of this article, assume that $\varphi_i$ is an [admissible numbering](https://en.wikipedia.org/wiki/Admissible_numbering) of the [computable functions](wikipedia://en/1139338) and *W*<sub>*i*</sub> the corresponding numbering of the [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable) sets.

A set *A* of natural numbers is called **productive** if there exists a [total](https://en.wikipedia.org/wiki/Total_function) recursive (computable) function $f$ so that for all $i \in \mathbb{N}$, if $W_i \subseteq A$ then $f(i) \in A \setminus W_i.$ The function $f$ is called the **productive function** for $A.$

A set *A* of natural numbers is called **creative** if *A* is recursively enumerable and its complement $\mathbb{N}\setminus A$ is productive. Not every productive set has a recursively enumerable complement, however, as illustrated below.

The archetypal creative set is $K = \{ i \mid i \in W_i \}$, the set representing the [halting problem](wikipedia://en/21391870). Its complement $\bar{K} = \{ i \mid i \not \in W_i \}$ is productive with productive function *f*(*i*) = *i* (the identity function).

To see this, we apply the definition of a productive function and show separately that $i \in \bar{K}$ and $i \not \in W_i$:

- $i \in \bar{K}$: suppose $i \in K$, then $i \in W_i$, now given that $W_i \subseteq \bar{K}$ we have $i \in \bar{K}$, this leads to a contradiction. So $i \in \bar{K}$.
- $i \not \in W_i$: in fact if $i \in W_i$, then it would be true that $i \in K$, but we have demonstrated the contrary in the previous point. So $i \not \in W_i$.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

No productive set *A* can be recursively enumerable, because whenever *A* contains every number in an r.e. set *W*<sub>*i*</sub> it contains other numbers, and moreover there is an effective procedure to produce an example of such a number from the index *i*. Similarly, no creative set can be [decidable](https://en.wikipedia.org/wiki/Decidable_set), because this would imply that its complement, a productive set, is recursively enumerable.

Any productive set has a productive function that is [injective](wikipedia://en/45196) and [total](https://en.wikipedia.org/wiki/Total_function).

The following theorems, due to Myhill (1955), show that in a sense all creative sets are like $K$ and all productive sets are like $\bar{K}$.[^o8]

::: {#o9 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Let *P* be a set of natural numbers. The following are equivalent:

- *P* is productive.
- $\bar{K}$ is [1-reducible](wikipedia://en/362983) to *P*.
- $\bar{K}$ is [m-reducible](wikipedia://en/362983) to *P*.

:::

::: {#o10 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Let *C* be a set of natural numbers. The following are equivalent:

- *C* is creative.
- *C* is [1-complete](wikipedia://en/362983)
- *C* is [recursively isomorphic](wikipedia://en/2611685) to *K*, that is, there is a total computable [bijection](https://en.wikipedia.org/wiki/Bijective_function) *f* on the natural numbers such that *f*(*C*) = *K*.

:::

:::

## Applications in mathematical logic {#Applications_in_mathematical_logic}

The set of all provable sentences in an effective [axiomatic system](wikipedia://en/188401) is always a [recursively enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set). If the system is suitably complex, like [first-order arithmetic](https://en.wikipedia.org/wiki/First-order_arithmetic), then the set *T* of [Gödel numbers](https://en.wikipedia.org/wiki/Gödel_number) of **true** sentences in the system will be a productive set, which means that whenever *W* is a recursively enumerable set of true sentences, there is at least one true sentence that is not in *W*. This can be used to give a rigorous proof of [Gödel's first incompleteness theorem](https://en.wikipedia.org/wiki/Gödel's_first_incompleteness_theorem), because no recursively enumerable set is productive. The complement of the set *T* will not be recursively enumerable, and thus *T* is an example of a productive set whose complement is not creative.

## History {#History}

The seminal paper of (Post 1944) defined the concept he called a Creative set. Reiterating, the set $K$ referenced above and defined as the domain of the function $d(x)=[[x]](x)+1$ that takes the diagonal of all enumerated 1-place computable partial functions and adds 1 to them is an example of a creative set.[^o14] Post gave a version of Gödel's Incompleteness Theorem using his creative sets, where originally Gödel had in some sense constructed a sentence that could be freely translated as saying "I am unprovable in this axiomatic theory." However, Gödel's proof did not work from the concept of true sentences, and rather used the concept of a consistent theory, which led to the [second incompleteness theorem](https://en.wikipedia.org/wiki/Second_incompleteness_theorem). After Post completed his version of incompleteness he then added the following:

"The conclusion is unescapable that even for such a fixed, well defined body of mathematical propositions, mathematical thinking is, and must remain, essentially creative."[^o14]

The usual creative set $K$ defined using the diagonal function $d(x)$ has its own historical development. [Alan Turing](wikipedia://en/1208) in a 1936 article on the [Turing machine](wikipedia://en/30403) showed the existence of a universal computer that computes the $\Phi$ function. The function $\Phi$ is defined such that $\Phi(w,x) =$ (*the result of applying the instructions coded by* $w$ *to the input* $x$ ), and is universal in the sense that any calculable partial function $f$ is given by $f(x)= \Phi(e,x)$ for all $x$ where $e$ codes the instructions for $f$. Using the above notation $\Phi(e,x)= [[e]](x)$, and the diagonal function arises quite naturally as $d(x) = [[x]](x)+1$. Ultimately, these ideas are connected to [Church's thesis](https://en.wikipedia.org/wiki/Church's_thesis) that says the mathematical notion of computable partial functions is the *correct* formalization of an effectively calculable partial function, which can neither be proved or disproved. Church used [lambda calculus](wikipedia://en/18203), Turing an idealized computer, and later Emil Post in his approach, all of which are equivalent.

(txt) formulated an analogous concept, [polynomial creativity](https://en.wikipedia.org/wiki/Polynomial_creativity), in [computational complexity theory](wikipedia://en/7543), and used it to provide potential counterexamples to the [Berman–Hartmanis conjecture](wikipedia://en/34917820) on isomorphism of [NP-complete](https://en.wikipedia.org/wiki/NP-complete) sets.
