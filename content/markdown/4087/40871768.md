# Markov reward model

::: {#o1 .subject cue=lead name="Markov reward model"}

In [probability theory](wikipedia://en/23542), a **Markov reward model** or **Markov reward process** is a stochastic process which extends either a [Markov chain](wikipedia://en/60876) or [continuous-time Markov chain](wikipedia://en/1125342) by adding a reward rate to each state. An additional variable records the reward accumulated up to the current time.[^o2] Features of interest in the model include expected reward at a given time and expected time to accumulate a given reward.[^o3] The model appears in [Ronald A. Howard](https://en.wikipedia.org/wiki/Ronald_A._Howard)'s book.[^o4] The models are often studied in the context of [Markov decision processes](wikipedia://en/1125883) where a decision strategy can impact the rewards received.

:::

The Markov Reward Model Checker tool can be used to numerically compute transient and stationary properties of Markov reward models.

## Continuous-time Markov chain {#Continuous-time_Markov_chain}

The accumulated reward at a time *t* can be computed numerically over the time domain or by evaluating the linear hyperbolic system of equations which describe the accumulated reward using transform methods or finite difference methods.[^o6]
