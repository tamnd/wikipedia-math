# Leaky integrator

::: {#o1 .subject cue=lead name="Leaky integrator"}

*Image: Leakyintegrator.png.* A graph of a solution to a leaky integrator; the input changes at T=5.

In [mathematics](wikipedia://en/18831), a **leaky integrator** equation is a specific [differential equation](wikipedia://en/1424309), used to describe a component or system that takes the [integral](wikipedia://en/15532) of an input, but gradually leaks a small amount of input over time. It appears commonly in [hydraulics](https://en.wikipedia.org/wiki/Hydraulics), [electronics](https://en.wikipedia.org/wiki/Electronics), and [neuroscience](https://en.wikipedia.org/wiki/Neuroscience) where it can represent either a single neuron or a local population of neurons.[^o2]

:::

## Equation {#Equation}

The equation is of the form

$$dx/dt = -Ax + C$$

where C is the input and A is the [rate of the 'leak'](https://en.wikipedia.org/wiki/Time_constant).

### General solution {#General_solution}

The equation is a nonhomogeneous first-order [linear differential equation](wikipedia://en/379868). For constant C its solution is

$$x(t) = ke^{-At} + \frac{C}{A}$$

where $k$ is a constant encoding the initial condition.
