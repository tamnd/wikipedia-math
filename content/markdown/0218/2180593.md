# Kirby–Siebenmann class

::: {#o1 .subject cue=lead name="Kirby–Siebenmann class"}

In [mathematics](wikipedia://en/18831), more specifically in [geometric topology](wikipedia://en/29954), the **Kirby–Siebenmann class** is an obstruction for topological manifolds to allow a *PL*-structure.[^o2]

:::

## The KS-class {#The_KS-class}

For a [topological manifold](wikipedia://en/2119193) *M*, the **Kirby–Siebenmann class** $\kappa(M) \in H^4(M;\mathbb{Z}/2)$ is an element of the fourth [cohomology group](https://en.wikipedia.org/wiki/Cohomology_group) of *M* that vanishes if *M* admits a [piecewise linear structure](https://en.wikipedia.org/wiki/Piecewise_linear_structure).

It is the only such obstruction, which can be phrased as the [weak equivalence](wikipedia://en/34615176) $TOP/PL \sim K(\mathbb Z/2,3)$ of *TOP/PL* with an [Eilenberg–MacLane space](wikipedia://en/1073230)..

The Kirby-Siebenmann class can be used to prove the existence of topological manifolds that do not admit a PL-structure.[^o4] Concrete examples of such manifolds are $E_8 \times T^n, n \geq 1$, where $E_8$ stands for [Freedman's](wikipedia://en/658970) [E8 manifold](wikipedia://en/6091657).[^o5]

The class is named after [Robion Kirby](wikipedia://en/2932424) and [Larry Siebenmann](https://en.wikipedia.org/wiki/Larry_Siebenmann), who developed the theory of topological and *PL*-manifolds.
