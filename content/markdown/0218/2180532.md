# Hauptvermutung

::: {#o1 .subject cue=lead name="Hauptvermutung"}

The ***Hauptvermutung*** of [geometric topology](wikipedia://en/621732) is a now refuted conjecture asking whether any two [triangulations](wikipedia://en/1440976) of a [triangulable space](https://en.wikipedia.org/wiki/Triangulable_space) have subdivisions that are combinatorially equivalent, i.e. the subdivided triangulations are built up in the same combinatorial pattern. It was originally formulated as a conjecture in 1908 by [Ernst Steinitz](wikipedia://en/3966685)[^o2] and [Heinrich Franz Friedrich Tietze](https://en.wikipedia.org/wiki/Heinrich_Franz_Friedrich_Tietze),[^o3] but it is now known to be false.

:::

## History {#History}

The non-[manifold](wikipedia://en/2073470) version was disproved by [John Milnor](wikipedia://en/61632) in 1961 using [Reidemeister torsion](wikipedia://en/14388042).[^o5]

The manifold version is true in [dimensions](wikipedia://en/8398) $m\le 3$. The cases $m = 2$ and $3$ were proved by [Tibor Radó](wikipedia://en/1490393) and [Edwin E. Moise](wikipedia://en/19236494) in the 1920s and 1950s, respectively.[^o6][^o7][^o8]

An obstruction to the manifold version was formulated by [Andrew Casson](https://en.wikipedia.org/wiki/Andrew_Casson) and [Dennis Sullivan](wikipedia://en/7349608) in 1967–69 (originally in the [simply-connected](https://en.wikipedia.org/wiki/Simply-connected) case), using the [Rochlin invariant](https://en.wikipedia.org/wiki/Rochlin_invariant) and the [cohomology group](https://en.wikipedia.org/wiki/Cohomology_group) $H^3(M;\mathbb{Z}/2\mathbb{Z})$.

In dimension $m \ge 5$, a [homeomorphism](wikipedia://en/13660) $f \colon N \to M$ of *m*-dimensional [piecewise linear manifolds](wikipedia://en/2174184) has an [invariant](https://en.wikipedia.org/wiki/Kirby-Siebenmann_class) $\kappa(f) \in H^3(M;\mathbb{Z}/2\mathbb{Z})$ such that $f$ is [isotopic](wikipedia://en/212250#Isotopy) to a piecewise linear (PL) homeomorphism [if and only if](wikipedia://en/14922) $\kappa(f) = 0$. In the simply-connected case and with $m \ge 5$, $f$ is [homotopic](https://en.wikipedia.org/wiki/Homotopic) to a PL homeomorphism if and only if $[\kappa(f)] = 0 \in [M,G/{\rm PL}]$.

This quantity $\kappa(f)$ is now seen as a relative version of the triangulation obstruction of [Robion Kirby](wikipedia://en/2932424) and [Laurent C. Siebenmann](wikipedia://en/13498931), obtained in 1970. The [Kirby–Siebenmann obstruction](https://en.wikipedia.org/wiki/Kirby–Siebenmann_obstruction) is defined for any [compact](wikipedia://en/6042) *m*-dimensional topological manifold *M*

$$\kappa(M)\in H^4(M;\mathbb{Z}/2\mathbb{Z})$$

again using the Rochlin invariant. For $m\ge 5$, the manifold *M* has a [PL structure](https://en.wikipedia.org/wiki/PL_structure) (i.e., it can be triangulated by a PL manifold) if and only if $\kappa(M) = 0$, and if this obstruction is 0, the PL structures are parametrized by $H^3(M;\mathbb{Z}/2\mathbb{Z})$. In particular there are only a finite number of essentially distinct PL structures on *M*.

For compact simply-connected manifolds of dimension 4, [Simon Donaldson](wikipedia://en/976305) found examples with an infinite number of inequivalent PL structures, and [Michael Freedman](wikipedia://en/658970) found the [E8 manifold](wikipedia://en/6091657) which not only has no PL structure, but (by work of Casson) is not even homeomorphic to a [simplicial complex](wikipedia://en/252686).[^o9]

In 2013, [Ciprian Manolescu](wikipedia://en/3034280) proved that there exist compact topological manifolds of dimension 5 (and hence of any dimension greater than 5) that are not homeomorphic to a simplicial complex.[^o10] Thus Casson's example illustrates a more general phenomenon that is not merely limited to dimension 4.
