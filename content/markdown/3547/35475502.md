# Acme Commodity and Phrase Code

::: {#o2 .subject cue=lead name="Acme Commodity and Phrase Code"}

***Acme Commodity and Phrase Code*** is a [codebook](wikipedia://en/530786) providing the general-purpose [commercial telegraph code](wikipedia://en/28739060) known as the *Acme Code*. It was published in 1923 by the Acme Code Company. The book provides a listing of condensed terms and [codes](https://en.wikipedia.org/wiki/Codes) used to shorten [telegrams](https://en.wikipedia.org/wiki/Telegrams) and save money. The book was extremely popular amongst businesses in the 1930s.[^o3] This code was one of the few telegram codes permitted by the Allied powers during the Second World War.[^o4]

:::

## Description {#Description}

The *Acme* code consists of one hundred thousand five letter codes each intended to stand in for a phrase. It was designed to be tolerant of [transposition errors](https://en.wikipedia.org/wiki/Transcription_error#Transposition_error); the author claims that "no transposition of any two adjoining letters will make another word in the book". However, as later discovered by J. Reeds, the code did not provide this level of error correction, containing at least eleven pairs of words differing only by the transposition of two letters.[^o6] Despite these errors, this code is a precursor to more modern [error correction codes](wikipedia://en/4237207).[^o7]
