# A-1 (code)

::: {#o1 .subject cue=lead name="A-1"}

**A-1** was the designation for a code used by the [United States Navy](https://en.wikipedia.org/wiki/United_States_Navy) during World War I that replaced the [Secret Code of 1887](https://en.wikipedia.org/wiki/Secret_Code_of_1887), [SIGCODE](https://en.wikipedia.org/wiki/SIGCODE) and another system designed for radio communication. The cryptographic system was developed by Lt. W.W. Smith in the [Office of Naval Operations](https://en.wikipedia.org/wiki/Office_of_Naval_Operations) by randomly associating key words with 5 letter patterns.[^o2]

:::
