# Dummy variable (statistics)

::: {#o1 .subject cue=lead name="Dummy variable"}

*Image: Graph\_showing\_Wage\_=\_α0\_+\_δ0female\_+\_α1education\_+\_U,\_δ0\_0.jpg.* A graph showing the gender wage gap

In [regression analysis](wikipedia://en/826997), a **dummy variable** (also known as **indicator variable** or just **dummy**) is one that takes a [binary value](https://en.wikipedia.org/wiki/Binary_data) (0 or 1) to indicate the absence or presence of some categorical effect that may be expected to shift the outcome.[^o2] In [machine learning](wikipedia://en/233488) this is known as [one-hot encoding](https://en.wikipedia.org/wiki/One-hot#Machine_learning_and_statistics).

:::

Dummy variables are commonly used in regression analysis to represent categorical variables that have more than two levels, such as education level or occupation. In this case, multiple dummy variables would be created to represent each level of the variable, and only one dummy variable would take on a value of 1 for each observation. Dummy variables are useful because they allow the use of categorical variables in our analysis, which would otherwise be difficult to include due to their non-numeric nature.

## Function and use {#Function_and_use}

A dummy variable is applied to a binary variable--for example, [sex](https://en.wikipedia.org/wiki/Biological_sex) may be encoded as a dummy variable by listing females as 0 and males as 1.

As with any addition of variables to a model, the addition of dummy variables will increase the within-sample model fit ([coefficient of determination](wikipedia://en/1500869)), but at a cost of fewer [degrees of freedom](wikipedia://en/2321606) and loss of generality of the model (out of sample model fit). Too many dummy variables result in a model that does not provide any general conclusions.

Dummy variables are useful in various cases. For example, in [econometric](wikipedia://en/10390) [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis), dummy variables may be used to indicate the occurrence of wars, or major [strikes](https://en.wikipedia.org/wiki/Strike_action). It could thus be thought of as a [Boolean](https://en.wikipedia.org/wiki/Boolean_data_type), i.e., a [truth value](wikipedia://en/161711) represented as the numerical value 0 or 1 (as is sometimes done in [computer programming](https://en.wikipedia.org/wiki/Computer_programming)).

Dummy variables may be extended to more complex cases. For example, seasonal effects may be captured by creating dummy variables for each of the seasons: D1=1 if the observation is for summer, and equals zero otherwise; D2=1 if and only if autumn, otherwise equals zero; D3=1 if and only if winter, otherwise equals zero; and D4=1 if and only if spring, otherwise equals zero. In the [panel data](wikipedia://en/2499813) [fixed effects estimator](https://en.wikipedia.org/wiki/Fixed_effects_estimator) dummies are created for each of the units in [cross-sectional data](wikipedia://en/3297700) (e.g. firms or countries) or periods in a [pooled time-series](https://en.wikipedia.org/wiki/Pooled_time-series).

In such regressions, either the [constant term](wikipedia://en/79861) or one of the dummies has to be removed making this the base category against which the others are assessed. This is because if dummy variables for all categories were included, their sum would equal 1 for all observations, which is identical to and hence perfectly correlated with the vector-of-ones variable whose coefficient is the constant term; if the vector-of-ones variable were also present, this would result in perfect [multicollinearity](wikipedia://en/1486691),[^o4] so that the matrix inversion in the estimation algorithm would be impossible. This is referred to as the dummy variable trap.
