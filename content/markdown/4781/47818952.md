# EnRUPT

::: {#o1 .subject cue=lead name="EnRUPT"}

**EnRUPT** is a block cipher and a family of cryptographic algorithms based on [XXTEA](wikipedia://en/10919454).[^o3][^o7] EnRUPT hash function was submitted to [SHA-3 competition](https://en.wikipedia.org/wiki/SHA-3_competition) but it wasn't selected to the second round.

:::
