# Mercy (cipher)

::: {#o2 .subject cue=lead name="Mercy"}

In [cryptography](wikipedia://en/18934432), **Mercy** is a tweakable [block cipher](wikipedia://en/4594) designed by Paul Crowley for [disk encryption](wikipedia://en/7066791).

:::

The [block size](wikipedia://en/294065) is 4096 bits—unusually large for a block cipher, but a standard [disk sector](https://en.wikipedia.org/wiki/Disk_sector) size. Mercy uses a 128-bit secret [key](wikipedia://en/53039), along with a 128-bit non-secret tweak for each block. In disk encryption, the sector number would be used as a tweak. Mercy uses a 6-round [Feistel network](https://en.wikipedia.org/wiki/Feistel_network) structure with partial [key whitening](wikipedia://en/2990178). The round function uses a key-dependent [state machine](https://en.wikipedia.org/wiki/State_machine) which borrows some structure from the [stream cipher](wikipedia://en/49007) [WAKE](wikipedia://en/599287), with key-dependent [S-boxes](wikipedia://en/240991) based on the [Nyberg](wikipedia://en/9413796) S-boxes also used in [AES](wikipedia://en/1260).

[Scott Fluhrer](https://en.wikipedia.org/wiki/Scott_Fluhrer) has discovered a [differential attack](https://en.wikipedia.org/wiki/Differential_attack) that works against the full 6 rounds of Mercy. This attack can even be extended to a seven-round variant.[^o5]
