# Topological semigroup

::: {#o1 .subject cue=lead name="Topological semigroup"}

In [mathematics](wikipedia://en/18831), a **topological semigroup** is a [semigroup](wikipedia://en/27799) that is simultaneously a [topological space](wikipedia://en/30450), and whose semigroup operation is [continuous](wikipedia://en/6122).[^o2]

:::

Every [topological group](wikipedia://en/42315) is a topological semigroup.
