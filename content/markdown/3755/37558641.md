# Johnson's SU-distribution

::: {#o1 .subject cue=lead name="Johnson's SU-distribution"}

The **Johnson's *S<sub>U</sub>*-distribution** is a four-parameter family of [probability distributions](wikipedia://en/23543) first investigated by [N. L. Johnson](wikipedia://en/2590640) in 1949.[^o2][^o3] Johnson proposed it as a transformation of the [normal distribution](wikipedia://en/21462):[^o2]

:::

$$z=\gamma+\delta \sinh^{-1} \left(\frac{x-\xi}{\lambda}\right)$$

where $z \sim \mathcal{N}(0,1)$.

## Generation of random variables {#Generation_of_random_variables}

Let *U* be a [random variable](wikipedia://en/25685) that is [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on the unit interval \[0, 1\]. Johnson's *S<sub>U</sub>* random variables can be generated from *U* as follows:

$$x = \lambda \sinh\left( \frac{ \Phi^{ -1 }( U ) - \gamma }{ \delta } \right) + \xi$$

where Φ is the [cumulative distribution function](wikipedia://en/5793) of the [normal distribution](wikipedia://en/21462).

## Johnson's *S<sub>B</sub>*-distribution {#Johnson's_SB-distribution}

[N. L. Johnson](wikipedia://en/2590640)[^o2] firstly proposes the transformation :

$$z=\gamma+\delta \log \left(\frac{x-\xi}{\xi+\lambda-x}\right)$$

where $z \sim \mathcal{N}(0,1)$.

Johnson's *S<sub>B</sub>* random variables can be generated from *U* as follows:

$$y={\left(1+{e}^{-\left(z-\gamma\right) /\delta }\right)}^{-1}$$

$$x=\lambda y +\xi$$

The *S<sub>B</sub>*-distribution is convenient to Platykurtic distributions ([Kurtosis](wikipedia://en/16848)). To simulate *S<sub>U</sub>*, sample of code for its [density](wikipedia://en/43487) and [cumulative distribution](wikipedia://en/5793) function is available [here](https://blogs.sas.com/content/iml/2020/01/20/johnson-sb-distribution.html)

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

Johnson's $S_{U}$-distribution has been used successfully to model asset returns for [portfolio management](https://en.wikipedia.org/wiki/Investment_management).[^o8] This comes as a superior alternative to using the [Normal distribution](wikipedia://en/21462) to model asset returns. An [R](wikipedia://en/376707) package, [JSUparameters](https://CRAN.R-project.org/package=JSUparameters), was developed in 2021 to aid in the estimation of the parameters of the best-fitting Johnson's $S_{U}$-distribution for a given dataset. Johnson distributions are also sometimes used in [option pricing](https://en.wikipedia.org/wiki/Option_pricing), so as to accommodate an observed [volatility smile](wikipedia://en/1533070); see [Johnson binomial tree](https://en.wikipedia.org/wiki/Johnson_binomial_tree).

An alternative to the Johnson system of distributions is the [quantile-parameterized distributions](wikipedia://en/65801270) (QPDs). QPDs can provide greater shape flexibility than the Johnson system. Instead of fitting moments, QPDs are typically fit to [empirical CDF data](wikipedia://en/2690455) with linear least squares.

Johnson's $S_{U}$-distribution is also used in the modelling of the [invariant mass](wikipedia://en/162321) of some heavy [mesons](https://en.wikipedia.org/wiki/Meson) in the field of [B-physics](https://en.wikipedia.org/wiki/B-physics).[^o9]
