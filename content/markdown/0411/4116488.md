# Initial algebra

::: {#o1 .subject cue=lead name="Initial algebra"}

In [mathematics](wikipedia://en/18831), an **initial algebra** is an [initial object](https://en.wikipedia.org/wiki/Initial_object) in the [category](wikipedia://en/53759) of [$F$-algebras](wikipedia://en/2168700) for a given [endofunctor](https://en.wikipedia.org/wiki/Endofunctor) $F$. This initiality provides a general framework for [induction](wikipedia://en/18881) and [recursion](wikipedia://en/25407).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

### Functor $1 + (-)$ {#Functor}

Consider the endofunctor $1 + (-)$, i.e. $F : \mathbf{Set} \to \mathbf{Set}$ sending $X$ to $1 + X$, where $1$ is a one-point ([singleton](wikipedia://en/381798)) [set](wikipedia://en/26691), a [terminal object](https://en.wikipedia.org/wiki/Terminal_object) in the category. An algebra for this endofunctor is a set $X$ (called the *carrier* of the algebra) together with a [function](wikipedia://en/185427) $f : (1 + X) \to X$. Defining such a function amounts to defining a point $x \in X$ and a function $X \to X$. Define

$$\begin{aligned} \operatorname{zero} \colon 1 &\longrightarrow\mathbf{N} \\ * &\longmapsto 0 \end{aligned}$$

and

$$\begin{aligned} \operatorname{succ}\colon \mathbf{N}&\longrightarrow\mathbf{N} \\ n &\longmapsto n + 1. \end{aligned}$$

Then the set $\mathbf{N}$ of natural numbers together with the function $[\operatorname{zero},\operatorname{succ}]: 1 + \mathbf{N} \to \mathbf{N}$ is an initial $F$-algebra. The initiality (the [universal property](wikipedia://en/32245) for this case) is not hard to establish; the unique [homomorphism](wikipedia://en/13564) to an arbitrary $F$-algebra $(A, [e, f])$, for $e: 1 \to A$ an element of $A$ and $f: A \to A$ a function on $A$, is the function sending the natural number $n$ to $f^{n}(e)$, that is, $f(f(\ldots(f(e))\ldots))$, the $n$-fold application of $f$ to $e$.

The set of [natural numbers](wikipedia://en/21474) is the carrier of an initial algebra for this functor: the point is zero and the function is the [successor function](wikipedia://en/325637).

### Functor $1 + N \times (-)$ {#Functor}

For a second example, consider the endofunctor $1 + \mathbf{N} \times (-)$ on the category of sets, where $\mathbf{N}$ is the set of natural numbers. An algebra for this endofunctor is a set $X$ together with a function $1 + \mathbf{N} \times X \to X$. To define such a function, we need a point $x \in X$ and a function $\mathbf{N} \times X \to X$. The set of finite [lists](https://en.wikipedia.org/wiki/List_%28computing%29) of natural numbers is an initial algebra for this functor. The point is the empty list, and the function is [cons](https://en.wikipedia.org/wiki/Cons), taking a number and a finite list, and returning a new finite list with the number at the head.

In categories with binary [coproducts](wikipedia://en/310889), the definitions just given are equivalent to the usual definitions of a [natural number object](https://en.wikipedia.org/wiki/Natural_number_object) and a [list object](wikipedia://en/56140139), respectively.

:::

## Final coalgebra {#Final_coalgebra}

[Dually](wikipedia://en/609737), a **final coalgebra** is a [terminal object](https://en.wikipedia.org/wiki/Terminal_object) in the category of [$F$-coalgebras](wikipedia://en/1983769). The finality provides a general framework for [coinduction](wikipedia://en/10904266) and [corecursion](https://en.wikipedia.org/wiki/Corecursion).

For example, using the same [functor](wikipedia://en/10987) $1 + (-)$ as before, a coalgebra is defined as a set $X$ together with a function $f : X \to (1 + X)$. Defining such a function amounts to defining a [partial function](wikipedia://en/23577) $f\boldsymbol{: X \text{⇸} X}$ whose [domain](wikipedia://en/50263) is formed by those $x \in X$ for which $f(x)$ does not belong to $1$. Having such a structure, we can define a chain of sets: $X_{0}$ being a subset of $X$ on which $f'$ is not defined, $X_{1}$ which elements map into $X_{0}$ by $f'$, $X_{2}$ which elements map into $X_{1}$ by $f'$, etc., and $X_{\omega}$ containing the remaining elements of $X$. With this in view, the set $\mathbf{N} \cup \{\omega\}$, consisting of the set of natural numbers extended with a new element $\omega$, is the carrier of the final coalgebra, where $f'$ is the predecessor function (the [inverse](wikipedia://en/14907) of the successor function) on the positive naturals, but acts like the [identity](wikipedia://en/15069) on the new element $\omega$: $f(n + 1) = n$, $f(\omega) = \omega$. This set $\mathbf{N} \cup \{\omega\}$ that is the carrier of the final coalgebra of $1 + (-)$ is known as the set of conatural numbers.

For a second example, consider the same functor $1 + \mathbf{N} \times (-)$ as before. In this case the carrier of the final coalgebra consists of all lists of natural numbers, finite as well as [infinite](https://en.wikipedia.org/wiki/Infinite_list). The operations are a test function testing whether a list is empty, and a deconstruction function defined on non-empty lists returning a pair consisting of the head and the tail of the input list.

:::

::: {#o9 .statement cue=heading name="Theorems"}

## Theorems {#Theorems}

- Initial algebras are minimal (i.e., have no proper subalgebra).
- Final coalgebras are [simple](https://en.wikipedia.org/wiki/Simple_algebra) (i.e., have no proper quotients).

:::

## Use in computer science {#Use_in_computer_science}

Various finite [data structures](https://en.wikipedia.org/wiki/Data_structures) used in [programming](https://en.wikipedia.org/wiki/Mathematical_programming), such as [lists](https://en.wikipedia.org/wiki/List_%28computing%29) and [trees](https://en.wikipedia.org/wiki/Tree_%28data_structure%29), can be obtained as initial algebras of specific endofunctors. While there may be several initial algebras for a given endofunctor, they are [unique](https://en.wikipedia.org/wiki/Unique_%28mathematics%29) [up to](wikipedia://en/44787) [isomorphism](wikipedia://en/14828), which informally means that the "observable" properties of a data structure can be adequately captured by defining it as an initial algebra.

To obtain the [type](https://en.wikipedia.org/wiki/Data_type) $\operatorname{List}(A)$ of lists whose elements are members of set $A$, consider that the list-forming operations are:

- $$\mathrm{nil}\colon 1 \to \mathrm{List}(A)$$
- $$\mathrm{cons}\colon A \times \mathrm{List}(A) \to \mathrm{List}(A)$$

Combined into one function, they give:

- $$[\mathrm{nil},\mathrm{cons}]\colon (1 + A \times \mathrm{List}(A))\to \mathrm{List}(A),$$

which makes this an $F$-algebra for the endofunctor $F$ sending $X$ to $1 + (A \times X)$. It is, in fact, *the* initial $F$-algebra. Initiality is established by the function known as *[foldr](https://en.wikipedia.org/wiki/Fold_%28higher-order_function%29)* in [functional](https://en.wikipedia.org/wiki/Functional_programming) [programming languages](wikipedia://en/23015) such as [Haskell](https://en.wikipedia.org/wiki/Haskell_%28programming_language%29) and [ML](https://en.wikipedia.org/wiki/ML_programming_language).

Likewise, [binary trees](wikipedia://en/4321) with elements at the leaves can be obtained as the initial algebra

- $$[\mathrm{tip},\mathrm{join}]\colon A + (\mathrm{Tree}(A) \times \mathrm{Tree}(A)) \to \mathrm{Tree}(A).$$

Types obtained this way are known as [algebraic data types](https://en.wikipedia.org/wiki/Algebraic_data_type).

Types defined by using [least fixed point](wikipedia://en/1211913) construct with functor $F$ can be regarded as an initial $F$-algebra, provided that [parametricity](wikipedia://en/9315395) holds for the type.[^o11]

In a dual way, similar relationship exists between notions of [greatest fixed point](https://en.wikipedia.org/wiki/Greatest_fixed_point) and terminal $F$-coalgebra, with applications to [coinductive](https://en.wikipedia.org/wiki/Coinductive) types. These can be used for allowing [potentially infinite](https://en.wikipedia.org/wiki/Actual_infinity) objects while maintaining [strong normalization property](https://en.wikipedia.org/wiki/Normalization_property_%28lambda-calculus%29).[^o11] In the strongly normalizing (each program terminates) Charity programming language, coinductive data types can be used for achieving surprising results, e.g. defining [lookup](https://en.wikipedia.org/wiki/Lookup_table) constructs to implement such [“strong”](https://en.wikipedia.org/wiki/Computability_theory_%28computer_science%29) functions like the [Ackermann function](wikipedia://en/2925).[^o12]
