# Cartan model

::: {#o1 .subject cue=lead name="Cartan model"}

In [mathematics](wikipedia://en/18831), the **Cartan model** is a [differential graded algebra](wikipedia://en/2415863) that computes the [equivariant cohomology](wikipedia://en/2976342) of a [space](wikipedia://en/30450).

:::
