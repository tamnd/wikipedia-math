# Cannonball problem

::: {#o1 .subject cue=lead name="Cannonball problem"}

*Image: Rye Castle, Rye, East Sussex, England-6April2011 (1).jpg.* A square pyramid of cannonballs in a square frame

In the mathematics of [figurate numbers](wikipedia://en/325260), the **cannonball problem** asks which numbers are both [square](wikipedia://en/213919) and [square pyramidal](wikipedia://en/542343). The problem can be stated as: given a square arrangement of cannonballs, for what size squares can these cannonballs also be arranged into a square pyramid? Equivalently, which squares can be represented as the sum of consecutive squares, starting from 1?

:::

## Formulation as a Diophantine equation {#Formulation_as_a_Diophantine_equation}

When cannonballs are stacked within a square frame, the number of balls is a square pyramidal number; [Thomas Harriot](wikipedia://en/780445) gave a formula for this number around 1587, answering a question posed to him by Sir [Walter Raleigh](https://en.wikipedia.org/wiki/Walter_Raleigh) on their expedition to America.[^o3] [Édouard Lucas](wikipedia://en/150102) formulated the cannonball problem as a [Diophantine equation](wikipedia://en/9109)

$$\sum_{n=1}^{N} n^2 = M^2$$

or

$$\frac{1}{6} N(N+1)(2N+1) = \frac{2N^3+3N^2+N}{6} = M^2.$$

## Solution {#Solution}

*Image: Cannonball\_problem.svg.* 4900 cannonballs can be arranged as either a square of side 70 or a square pyramid of side 24

Lucas conjectured that the only solutions are $(N,M) = (0,0)$, $(1,1)$, and $(24,70)$, using either 0, 1, or 4900 cannonballs. It was not until 1918 that [G. N. Watson](https://en.wikipedia.org/wiki/G._N._Watson) found a proof for this fact, using [elliptic functions](wikipedia://en/69939). More recently, [elementary proofs](wikipedia://en/9318685) have been published.[^o5][^o6]

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

The solution *N* = 24, *M* = 70 can be used for constructing the [Leech lattice](wikipedia://en/344919#Using_the_Lorentzian_lattice_II25,1). The result has relevance to the [bosonic string theory](https://en.wikipedia.org/wiki/Bosonic_string_theory) in 26 dimensions.[^o9]

Although it is possible to [tile a geometric square with unequal squares](wikipedia://en/67903), it is not possible to do so with a solution to the cannonball problem. The squares with side lengths from 1 to 24 have areas equal to the square with side length 70, but they cannot be arranged to tile it.

:::

## Related problems {#Related_problems}

A triangular-pyramid version of the cannonball problem, which is to yield a perfect square from the *N*<sup>th</sup> [tetrahedral number](https://en.wikipedia.org/wiki/Tetrahedral_number), would have *N* = 48. That means that the (24 × 2 = ) 48th tetrahedral number equals to (70<sup>2</sup> × 2<sup>2</sup> = 140<sup>2</sup> = ) 19600. This is comparable with the 24th square pyramid having a total of 70<sup>2</sup> cannonballs. This is because a [square pyramidal number](wikipedia://en/542343) is one-fourth of a larger tetrahedral number (meaning the points from four copies of the same square pyramid can be rearranged to form a single tetrahedron with twice as many points along each edge).[^o12]

Similarly, a pentagonal-pyramid version of the cannonball problem to produce a perfect square, would have *N* = 8, yielding a total of (14 × 14 = ) 196 cannonballs.

The only numbers that are simultaneously [triangular](wikipedia://en/213915) and square pyramidal are 1, 55, 91, and 208335.

There are no numbers (other than the trivial solution 1) that are both tetrahedral and square pyramidal.[^o15]
