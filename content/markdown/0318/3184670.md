# Pensim2

::: {#o1 .subject cue=lead name="Pensim2"}

**Pensim2** is a dynamic [microsimulation](https://en.wikipedia.org/wiki/Microsimulation) [model](https://en.wikipedia.org/wiki/Model_%28abstract%29) to simulate the [income](https://en.wikipedia.org/wiki/Income) of [pensioners](https://en.wikipedia.org/wiki/Pensioner), owned by the [British](https://en.wikipedia.org/wiki/United_Kingdom) [Department for Work and Pensions](https://en.wikipedia.org/wiki/Department_for_Work_and_Pensions).

:::

Pensim2 is the second version of Pensim which was developed by [Institute for Fiscal Studies](https://en.wikipedia.org/wiki/Institute_for_Fiscal_Studies) in the 1990s. The [time horizon](https://en.wikipedia.org/wiki/Time_horizon) of the model is 100 years, by which time today's school leavers will retire. Pensim2 uses a lot of external alignment figures.[^o2]

## Overview {#Overview}

Pensim2 uses aggregate and micro-level data from different data sources, e.g. [BHPS](https://en.wikipedia.org/wiki/BHPS), [LLMDB](https://en.wikipedia.org/wiki/LLMDB) and the [Family Resources Survey](https://en.wikipedia.org/wiki/Family_Resources_Survey). It simulate a very wide range of economic processes: earnings, [housing](https://en.wikipedia.org/wiki/Housing), [savings](https://en.wikipedia.org/wiki/Saving), [pensions](https://en.wikipedia.org/wiki/Pension), [taxes](https://en.wikipedia.org/wiki/Tax). It has the useful feature of allowing the user to specify certain parameters (for example the rate of return to the stock market).[^o2]
