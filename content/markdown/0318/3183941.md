# Super PI

::: {#o1 .subject cue=lead name="Super PI"}

*Image: Super PI Mod1.5 XS.png.* Super PI finishing a calculation of 1,048,576, or 2<sup>20</sup> digits of pi

**Super PI** is a [computer program](https://en.wikipedia.org/wiki/Computer_program) that calculates [pi](wikipedia://en/23601) to a specified number of digits after the decimal point—up to a maximum of 32 million. It uses the [Gauss–Legendre algorithm](wikipedia://en/12916) and is a [Windows](https://en.wikipedia.org/wiki/Windows) port of the program used by [Yasumasa Kanada](wikipedia://en/561940) in 1995 to compute pi to 2<sup>32</sup> digits.

:::

## Significance {#Significance}

Super PI is popular in the [overclocking](https://en.wikipedia.org/wiki/Overclocking) community, both as a [benchmark](https://en.wikipedia.org/wiki/Benchmark_%28computing%29) to test the performance of these systems[^o4][^o5] and as a [stress test](https://en.wikipedia.org/wiki/Stress_test_%28hardware%29) to check that they are still functioning correctly.[^o6]

## Credibility concerns {#Credibility_concerns}

The competitive nature of achieving the best Super PI calculation times led to fraudulent Super PI results, reporting calculation times faster than normal. Attempts to counter the fraudulent results resulted in a modified version of Super PI, with a [checksum](https://en.wikipedia.org/wiki/Checksum) to validate the results. However, other methods exist of producing inaccurate or fake time results, raising questions about the program's future as an overclocking benchmark.

Super PI utilizes [x87](https://en.wikipedia.org/wiki/X87) floating point instructions which are supported on all [x86](https://en.wikipedia.org/wiki/X86) and [x86-64](https://en.wikipedia.org/wiki/X86-64) processors, current versions which also support the lower precision [Streaming SIMD Extensions](wikipedia://en/55365) vector instructions.
