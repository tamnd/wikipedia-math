# Macaulay2

::: {#o2 .subject cue=lead name="Macaulay2"}

**Macaulay2** is a [free](https://en.wikipedia.org/wiki/Free_software) [computer algebra system](wikipedia://en/54427) created by Daniel Grayson (from the [University of Illinois at Urbana–Champaign](https://en.wikipedia.org/wiki/University_of_Illinois_at_Urbana–Champaign)) and [Michael Stillman](wikipedia://en/61705856) (from [Cornell University](https://en.wikipedia.org/wiki/Cornell_University)) for computation in [commutative algebra](wikipedia://en/245990) and [algebraic geometry](wikipedia://en/1997).

:::

## Overview {#Overview}

Macaulay2 is built around fast implementations of algorithms useful for computation in commutative algebra and algebraic geometry. This core functionality includes arithmetic on rings, modules, and matrices, as well as algorithms for [Gröbner bases](https://en.wikipedia.org/wiki/Gröbner_bases), [free resolutions](https://en.wikipedia.org/wiki/Free_resolution), [Hilbert series](https://en.wikipedia.org/wiki/Hilbert_series), [determinants](https://en.wikipedia.org/wiki/Determinants) and [Pfaffians](https://en.wikipedia.org/wiki/Pfaffians), [factoring](wikipedia://en/82341), and similar. In addition, the system has been extended by a large number of packages. Over 230 packages are included in the distribution of Macaulay2 as of 2026, and notable package authors include [Craig Huneke](wikipedia://en/41178067) and [Frank-Olaf Schreyer](wikipedia://en/61989099).[^o4] The [Journal of Software for Algebra and Geometry](https://en.wikipedia.org/wiki/Journal_of_Software_for_Algebra_and_Geometry) has published numerous packages and programs for Macaulay2.[^o5]

Macaulay2 has an interactive [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface) used from the terminal (see ). It can also use [emacs](https://en.wikipedia.org/wiki/Emacs) or [GNU TeXmacs](https://en.wikipedia.org/wiki/GNU_TeXmacs) as a user interface.[^o6]

Macaulay2 uses its own [interpreted](https://en.wikipedia.org/wiki/Interpreted_language) [high-level programming language](https://en.wikipedia.org/wiki/High-level_programming_language) both from the command line and in saved programs. This language is intended to be easy to use for mathematicians, and many parts of the system are indeed written in the Macaulay2 language. The algebraic algorithms that form the core functionality are written in [C++](https://en.wikipedia.org/wiki/C++) for speed. The interpreter itself is written in a custom type safety layer over [C](https://en.wikipedia.org/wiki/C_%28programming_language%29).[^o7] Both the system and the programming language are published under the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License) version 2 or 3.[^o8]

## History {#History}

Stillman, along with [Dave Bayer](wikipedia://en/1442686) had authored the predecessor system, **Macaulay**, beginning in 1983. They named Macaulay after [Francis Sowerby Macaulay](wikipedia://en/3592252), an English mathematician who made significant contributions to [algebraic geometry](wikipedia://en/1997). The Macaulay system showed that it was possible to solve actual problems in algebraic geometry using Gröbner basis techniques, but by the early 1990s, limitations in its architecture were becoming an obstruction. Using the experience with Macaulay, Grayson and Stillman began work on Macaulay2 in 1993. The Macaulay2 language and design has a number of improvements over that of Macaulay, allowing for infinite coefficient rings, new data types, and other useful features.[^o7]

Macaulay continued to be updated and used for some time after the 1993 introduction of Macaulay2. The last released version was 3.1, from August 2000. The Macaulay webpage currently recommends switching to Macaulay2.[^o11]

Macaulay2 has been updated regularly since its introduction.[^o12] [David Eisenbud](wikipedia://en/3649845) has been listed as a collaborator on the project since 2007.[^o13]

## Sample session {#Sample_session}

The following session defines a [polynomial ring](wikipedia://en/373065) $S$, an ideal $I$ inside $S$, and the [quotient ring](wikipedia://en/184635) $R = S/I$. The text `i1 :` is the 1st input prompt in a session, while `o1` is the corresponding output.

```macaulay2
i1 : S=QQ[a,b,c,d,e]

o1 = S

o1 : PolynomialRing

i2 : I=ideal(a^3-b^3, a+b+c+d+e)

             3    3
o2 = ideal (a  - b , a + b + c + d + e)

o2 : Ideal of S

i3 : R = S/I

o3 = R

o3 : QuotientRing
```

## Reception {#Reception}

In a 2006 interview, [Andrei Okounkov](wikipedia://en/6607318) cited Macaulay2 along with [TeX](https://en.wikipedia.org/wiki/TeX) as a successful [open-source](https://en.wikipedia.org/wiki/Open-source_software) project used in [mathematics](wikipedia://en/18831) and suggested that funding agencies look into and learn from these examples.[^o16]
