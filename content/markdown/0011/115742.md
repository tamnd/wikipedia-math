# Zeta distribution

::: {#o1 .subject cue=lead name="Zeta distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **zeta distribution** is a discrete [probability distribution](wikipedia://en/23543). If *X* is a zeta-distributed [random variable](wikipedia://en/25685) with parameter *s*, then the probability that *X* takes the positive integer value *k* is given by the [probability mass function](wikipedia://en/154725)

:::

$$f_s(k) = \frac{k^{-s}}{\zeta(s)}$$

where *ζ*(*s*) is the [Riemann zeta function](wikipedia://en/25809) (which is undefined for *s* = 1).

The multiplicities of distinct [prime factors](https://en.wikipedia.org/wiki/Prime_factor) of *X* are [independent](https://en.wikipedia.org/wiki/Statistical_independence) [random variables](wikipedia://en/25685).

The [Riemann zeta function](wikipedia://en/25809) being the sum of all terms $k^{-s}$ for positive integer *k*, it appears thus as the normalization of the [Zipf distribution](wikipedia://en/43218). The terms "Zipf distribution" and "zeta distribution" are often used interchangeably. But while the zeta distribution is a [probability distribution](wikipedia://en/23543) by itself, it is not associated with [Zipf's law](wikipedia://en/43218) with the same exponent.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The zeta distribution is defined for positive integers $k \geq 1$, and its probability mass function is given by

$$P(x=k) = \frac 1 {\zeta(s)} k^{-s},$$

where $s>1$ is the parameter, and $\zeta(s)$ is the [Riemann zeta function](wikipedia://en/25809).

The cumulative distribution function is given by

$$P(x \leq k) = \frac{H_{k,s}}{\zeta(s)},$$

where $H_{k,s}$ is the generalized [harmonic number](wikipedia://en/214729)

$$H_{k,s} = \sum_{i=1}^k \frac 1 {i^s}.$$

:::

## Moments {#Moments}

The *n*th raw [moment](wikipedia://en/368684) is defined as the expected value of *X*<sup>*n*</sup>:

$$m_n = E(X^n) = \frac{1}{\zeta(s)}\sum_{k=1}^\infty \frac{1}{k^{s-n}}$$

The series on the right is just a series representation of the Riemann zeta function, but it only converges for values of $s-n$ that are greater than unity. Thus:

$$m_n = \begin{cases} \zeta(s-n)/\zeta(s) & \text{for } n < s-1 \\ \infty & \text{for } n \ge s-1 \end{cases}$$

The ratio of the zeta functions is well-defined, even for *n* > *s* − 1 because the series representation of the zeta function can be [analytically continued](wikipedia://en/80842). This does not change the fact that the moments are specified by the series itself, and are therefore undefined for large *n*.

### Moment generating function {#Moment_generating_function}

The [moment generating function](wikipedia://en/194634) is defined as

$$M(t;s) = E(e^{tX}) = \frac{1}{\zeta(s)} \sum_{k=1}^\infty \frac{e^{tk}}{k^s}.$$

The series is just the definition of the [polylogarithm](wikipedia://en/482471), valid for $e^t<1$ so that

$$M(t;s) = \frac{\operatorname{Li}_s(e^t)}{\zeta(s)}\text{ for }t<0.$$

Since this does not converge on an open interval containing $t=0$, the moment generating function does not exist.

## The case *s* = 1 {#The_case_s_=_1}

*ζ*(1) is infinite as the [harmonic series](wikipedia://en/142488), and so the case when *s* = 1 is not meaningful. However, if *A* is any set of positive integers that has a density, i.e. if

$$\lim_{n\to\infty}\frac{N(A,n)}{n}$$

exists where *N*(*A*, *n*) is the number of members of *A* less than or equal to *n*, then

$$\lim_{s\to 1^+}P(X\in A)\,$$

is equal to that density.

The latter limit can also exist in some cases in which *A* does not have a density. For example, if *A* is the set of all positive integers whose first digit is *d*, then *A* has no density, but nonetheless, the second limit given above exists and is proportional to

$$\log(d+1) - \log(d) = \log\left(1+\frac{1}{d}\right),\,$$

which is [Benford's law](wikipedia://en/36782).

## Infinite divisibility {#Infinite_divisibility}

The zeta distribution can be constructed with a sequence of independent random variables with a [geometric distribution](wikipedia://en/45922). Let $p$ be a [prime number](wikipedia://en/23666) and $X(p^{-s})$ be a random variable with a geometric distribution of parameter $p^{-s}$, namely

$$\mathbb{P}\left( X(p^{-s}) = k \right) = p^{-ks } (1 - p^{-s} )$$

If the random variables $( X(p^{-s}) )_{p \in \mathcal{P} }$ are independent, then, the random variable $Z_s$ defined by

$$Z_s = \prod_{p \in \mathcal{P} } p^{ X(p^{-s}) }$$

has the zeta distribution: $\mathbb{P}\left( Z_s = n \right) = \frac{1}{ n^s \zeta(s) }$.

Stated differently, the random variable $\log(Z_s) = \sum_{p \in \mathcal{P} } X(p^{-s}) \, \log(p)$ is [infinitely divisible](https://en.wikipedia.org/wiki/Infinitely_divisible_distribution) with [Lévy measure](https://en.wikipedia.org/wiki/Lévy_measure) given by the following sum of [Dirac masses](wikipedia://en/1019002):

$$\Pi_s(dx) = \sum_{p \in \mathcal{P} } \sum_{k \geqslant 1 } \frac{p^{-k s}}{k} \delta_{k \log(p) }(dx)$$
