# FreeOTFE

::: {#o1 .subject cue=lead name="FreeOTFE"}

*Image: FreeOTFE4PDA.png.* FreeOTFE4PDA

**FreeOTFE** is a discontinued [open source](https://en.wikipedia.org/wiki/Open-source_software) computer program for [on-the-fly disk encryption](wikipedia://en/7066791) (OTFE). On [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), and [Windows Mobile](https://en.wikipedia.org/wiki/Windows_Mobile) (using FreeOTFE4PDA), it can create a [virtual drive](https://en.wikipedia.org/wiki/RAM_drive) within a file or [partition](https://en.wikipedia.org/wiki/Disk_partitioning), to which anything written is automatically encrypted before being stored on a computer's [hard](https://en.wikipedia.org/wiki/Hard_disk_drive) or [USB](https://en.wikipedia.org/wiki/USB_flash_drive) drive. It is similar in function to other disk encryption programs including [TrueCrypt](wikipedia://en/905962) and Microsoft's [BitLocker](https://en.wikipedia.org/wiki/BitLocker).[^o4]

:::

The author, Sarah Dean, went absent as of 2011. The FreeOTFE website is unreachable as of June 2013 and the domain name is now registered by a [domain squatter](https://en.wikipedia.org/wiki/Domain_squatter). The original program can be downloaded from [a mirror at Sourceforge](https://sourceforge.net/projects/freeotfe.mirror/). In June 2014, a [fork](https://en.wikipedia.org/wiki/Fork_%28software_development%29) of the project now named LibreCrypt appeared on [GitHub](https://en.wikipedia.org/wiki/GitHub).[^o5]

## Overview {#Overview}

*FreeOTFE* was initially released by Sarah Dean in 2004, and was the first open source code disk encryption system that provided a modular architecture allowing 3rd parties to implement additional algorithms if needed. Older FreeOTFE licensing required that any modification to the program be placed in the [public domain](https://en.wikipedia.org/wiki/Public_domain). This does not conform technically to section 3 of the [Open Source definition](https://en.wikipedia.org/wiki/Open_Source_definition). Newer program licensing omits this condition. The FreeOTFE license has not been approved by the [Open Source Initiative](https://en.wikipedia.org/wiki/Open_Source_Initiative) and is not certified to be labeled with the open-source certification mark.

This software is compatible with Linux encrypted volumes (e.g. [LUKS](https://en.wikipedia.org/wiki/LUKS), [cryptoloop](https://en.wikipedia.org/wiki/Cryptoloop), [dm-crypt](wikipedia://en/10782256)), allowing data encrypted under Linux to be read (and written) freely. It was the first open source transparent disk encryption system to support [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista) and PDAs.[^o7][^o8][^o9][^o10]

Optional [two-factor authentication](https://en.wikipedia.org/wiki/Two-factor_authentication) using [smart cards](https://en.wikipedia.org/wiki/Smart_card) and/or [hardware security modules](https://en.wikipedia.org/wiki/Hardware_security_module) (HSMs, also termed [security tokens](https://en.wikipedia.org/wiki/Security_tokens))[^o11] was introduced in v4.0, using the [PKCS#11](https://en.wikipedia.org/wiki/PKCS11) (Cryptoki) standard developed by [RSA Laboratories](https://en.wikipedia.org/wiki/RSA_Laboratories).

*FreeOTFE* also allows any number of "hidden volumes" to be created, giving [plausible deniability](https://en.wikipedia.org/wiki/Plausible_deniability) and [deniable encryption](wikipedia://en/1055437), and also has the option of encrypting full partitions or disks (but not the system partition).[^o12]

## Portable use {#Portable_use}

*Image: FreeOTFEExplorer.png.* FreeOTFE Explorer allows access to encrypted disks, without installing any drivers.

FreeOTFE can be used in "portable" (or "traveller") mode, which allows it to be kept on a [USB](https://en.wikipedia.org/wiki/USB) drive or other portable media, together with its encrypted data, and carried around. This allows it to be used under [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) without installation of the complete program to "mount" and access the encrypted data through a virtual disk.

The use of this mode requires installing [device drivers](https://en.wikipedia.org/wiki/Device_drivers) (at least temporarily) to create virtual disks, and as a consequence administrator rights are needed to start this traveller mode. As with most open source software that uses device drivers, the user must enable test signing[^o14] when running Windows Vista x64 and Windows 7 x64 systems.[^o15]

### Driverless operation {#Driverless_operation}

Packaged with FreeOTFE is another program called "FreeOTFE Explorer",[^o17] which provides a *driverless system* that allows encrypted disks to be used without administrator rights.

This allows FreeOTFE encrypted data to be used on (for example) public computers found in libraries or computer kiosks ([interactive kiosks](https://en.wikipedia.org/wiki/Interactive_kiosk)), where administrator rights are unavailable.

Unlike FreeOTFE, FreeOTFE Explorer does not provide on-the-fly encryption through a virtual drive.[^o17] Instead it lets files be stored and extracted from encrypted disk images, in a similar manner as [ZIP](https://en.wikipedia.org/wiki/ZIP_%28file_format%29) and [RAR](https://en.wikipedia.org/wiki/RAR_%28file_format%29) archives, by using a [Windows Explorer](https://en.wikipedia.org/wiki/Windows_Explorer) like interface.

## Algorithms implemented {#Algorithms_implemented}

Due to its architecture, FreeOTFE provides great flexibility to the user with its encryption options.

### Ciphers {#Ciphers}

FreeOTFE implements several ciphers, including:

- [AES](wikipedia://en/1260)
- [Blowfish](wikipedia://en/3940)
- [CAST5](https://en.wikipedia.org/wiki/CAST5) / [CAST6](https://en.wikipedia.org/wiki/CAST6)
- [DES](wikipedia://en/7978) / [Triple DES](wikipedia://en/48375)
- [MARS](https://en.wikipedia.org/wiki/MARS_%28cryptography%29)
- [RC6](wikipedia://en/160216)
- [Serpent](wikipedia://en/385154)
- [Twofish](wikipedia://en/26508356)

It includes all [National Institute of Standards and Technology](https://en.wikipedia.org/wiki/National_Institute_of_Standards_and_Technology) (NIST) [Advanced Encryption Standard](wikipedia://en/1260) (AES) finalists, and all ciphers can be used with multiple different keylengths.

#### Cipher modes {#Cipher_modes}

FreeOTFE originally offered encryption using [cipher-block chaining](https://en.wikipedia.org/wiki/Cipher-block_chaining) (CBC) with encrypted salt-sector initialization vector ([ESSIV](https://en.wikipedia.org/wiki/ESSIV)), though from v3.00 introduced [LRW](https://en.wikipedia.org/wiki/Liskov-Rivest-Wagner) and also the more secure [XTS](wikipedia://en/3395256#XTS) mode, which supersedes LRW in the [IEEE P1619](https://en.wikipedia.org/wiki/IEEE_P1619) standard for disk encryption.

### Hashes {#Hashes}

As with its cipher options, FreeOTFE offers many different hash algorithms:

- [MD2](https://en.wikipedia.org/wiki/MD2_%28cryptography%29)
- [MD4](wikipedia://en/578106)
- [MD5](wikipedia://en/18826)
- [RIPEMD-128](https://en.wikipedia.org/wiki/RIPEMD-160)
- [RIPEMD-160](https://en.wikipedia.org/wiki/RIPEMD-160)
- [RIPEMD-224](wikipedia://en/26363)
- [RIPEMD-320](wikipedia://en/26363)
- [SHA-1](wikipedia://en/26672)
- [SHA-224](https://en.wikipedia.org/wiki/SHA-224)
- [SHA-256](https://en.wikipedia.org/wiki/SHA-256)
- [SHA-384](https://en.wikipedia.org/wiki/SHA-384)
- [SHA-512](https://en.wikipedia.org/wiki/SHA-512)
- [Tiger](wikipedia://en/511596)
- [Whirlpool](https://en.wikipedia.org/wiki/WHIRLPOOL)
