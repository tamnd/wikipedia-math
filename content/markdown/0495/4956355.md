# Unknotting problem

::: {#o1 .problem cue=unsolved}

Can unknots be recognized in polynomial time?

:::

*Image: unknots.svg.* Two simple diagrams of the unknot

*Image: thistlethwaite unknot.svg.* A tricky unknot diagram by [Morwen Thistlethwaite](wikipedia://en/16705411)

::: {#o2 .subject cue=lead name="Unknotting problem"}

In [mathematics](wikipedia://en/18831), the **unknotting problem** is the problem of [algorithmically](wikipedia://en/775) recognizing the [unknot](wikipedia://en/60075), given some representation of a knot, e.g., a [knot diagram](https://en.wikipedia.org/wiki/Knot_diagram). There are several types of unknotting algorithms. A major unresolved challenge is to determine if the problem admits a [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) algorithm; that is, whether the problem lies in the complexity class [P](wikipedia://en/658550).

:::

## Computational complexity {#Computational_complexity}

First steps toward determining the computational complexity were undertaken in proving that the problem is in larger complexity classes, which contain the class P. By using [normal surfaces](wikipedia://en/3141418) to describe the [Seifert surfaces](wikipedia://en/1343951) of a given knot, (Hass Lagarias Pippenger 1999) showed that the unknotting problem is in the complexity class [NP](wikipedia://en/21562). (Hara Tani Yamamoto 2005) claimed the weaker result that unknotting is in [AM ∩ co-AM](https://en.wikipedia.org/wiki/Arthur&ndash;Merlin_protocol); however, later they retracted this claim.[^o6] In 2011, [Greg Kuperberg](wikipedia://en/16189453) proved that (assuming the [generalized Riemann hypothesis](wikipedia://en/152567)) the unknotting problem is in [co-NP](wikipedia://en/6184),[^o7] and in 2016, [Marc Lackenby](wikipedia://en/49182345) provided an unconditional proof of co-NP membership.[^o8]

In 2021, Lackenby announced an unknot recognition algorithm which he claimed ran in [quasi-polynomial time](wikipedia://en/25269049).[^o9] As of October 2025, the result has not been published in the peer-reviewed literature.

The unknotting problem has the same computational complexity as testing whether an embedding of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) in [Euclidean space](wikipedia://en/9697) is [linkless](wikipedia://en/772031).[^n1]

## Unknotting algorithms {#Unknotting_algorithms}

Several algorithms solving the unknotting problem are based on [Haken](wikipedia://en/311546)'s theory of [normal surfaces](wikipedia://en/3141418):

- [Haken's algorithm](https://en.wikipedia.org/wiki/Haken's_algorithm) uses the theory of normal surfaces to find a disk whose boundary is the knot. Haken originally used this algorithm to show that unknotting is decidable, but did not analyze its complexity in more detail.
- Hass, Lagarias, and Pippenger showed that the set of all normal surfaces may be represented by the integer points in a [polyhedral cone](https://en.wikipedia.org/wiki/Polyhedral_cone) and that a surface witnessing the unknottedness of a curve (if it exists) can always be found on one of the extreme rays of this cone. Therefore, [vertex enumeration methods](wikipedia://en/19558316) can be used to list all of the extreme rays and test whether any of them corresponds to a bounding disk of the knot. Hass, Lagarias, and Pippenger used this method to show that the unknottedness is in NP; later researchers such as (Burton 2011a) refined their analysis, showing that this algorithm can be useful (though not polynomial time), with its complexity being a low-order singly-exponential function of the number of crossings.
- The algorithm of (Birman Hirsch 1998) uses [braid foliations](https://en.wikipedia.org/wiki/Braid_foliation), a somewhat different type of structure than a normal surface. However to analyze its behavior they return to normal surface theory.

Other approaches include:

- The number of [Reidemeister moves](wikipedia://en/1152374) needed to change an unknot diagram to the standard unknot diagram is at most polynomial in the number of crossings.[^n2] Therefore, a brute force search for all sequences of Reidemeister moves can detect unknottedness in exponential time.
- Similarly, any two triangulations of the same [knot complement](wikipedia://en/1350120) may be connected by a sequence of [Pachner moves](wikipedia://en/27310823) of length at most doubly exponential in the number of crossings.[^o15] Therefore, it is possible to determine whether a knot is the unknot by testing all sequences of Pachner moves of this length, starting from the complement of the given knot, and determining whether any of them transforms the complement into a standard triangulation of a [solid torus](wikipedia://en/1251473). The time for this method would be triply exponential; however, experimental evidence suggests that this bound is very pessimistic and that many fewer Pachner moves are needed.[^o16]
- Any [arc-presentation](https://en.wikipedia.org/wiki/Arc-presentations_of_links) of an unknot can be monotonically simplified to a minimal one using elementary moves.[^o17] So a brute force search among all arc-presentations of not greater complexity gives a single-exponential algorithm for the unknotting problem.
- [Residual finiteness](https://en.wikipedia.org/wiki/Residually_finite) of the [knot group](wikipedia://en/1164126) (which follows from [geometrization](wikipedia://en/220642) of [Haken manifolds](wikipedia://en/236567)) gives an algorithm: check if the group has non-cyclic finite group quotient. This idea is used in Kuperberg's result that the unknotting problem is in co-NP.
- [Knot Floer homology](https://en.wikipedia.org/wiki/Heegaard_Floer_homology) of the knot detects the genus of the knot, which is 0 if and only if the knot is an unknot. A combinatorial version of knot Floer homology allows it to be computed (Manolescu Ozsváth Sarkar 2009).
- [Khovanov homology](wikipedia://en/2639906) detects the unknot according to a result of [Kronheimer](wikipedia://en/3845647) and [Mrowka](wikipedia://en/20652006).[^o19] The complexity of Khovanov homology at least as high as the [\#P-hard](https://en.wikipedia.org/wiki/Sharp-P-complete) problem of computing the [Jones polynomial](wikipedia://en/1107642), but it may be calculated in practice using an algorithm and program of (Bar-Natan 2007). Bar-Natan provides no rigorous analysis of his algorithm, but heuristically estimates it to be exponential in the [pathwidth](wikipedia://en/5133142) of a crossing diagram, which in turn is at most proportional to the square root of the number of crossings.

Understanding the complexity of these algorithms is an active field of study.
