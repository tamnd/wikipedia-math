# Primitive element (finite field)

::: {#o1 .subject cue=lead name="Primitive element"}

In [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29), a **primitive element** of a [finite field](wikipedia://en/11615) $\operatorname{GF}(q)$ is a [generator](wikipedia://en/99945) of the [multiplicative group](https://en.wikipedia.org/wiki/Group_of_units) of the field. In other words, $\alpha \in \operatorname{GF}(q)$ is called a primitive element if it is a [primitive $(q - 1)$th root of unity](https://en.wikipedia.org/wiki/Primitive_root_of_unity) in $\operatorname{GF}(q)$; this means that each non-zero element of $\operatorname{GF}(q)$ can be written as $\alpha^{i}$ for some [natural number](wikipedia://en/21474) $i$.

:::

If $q$ is a [prime number](wikipedia://en/23666), the elements of $\operatorname{GF}(q)$ can be identified with the [integers modulo $q$](https://en.wikipedia.org/wiki/Integers_modulo_n). In this case, a primitive element is also called a [primitive root modulo $q$](wikipedia://en/186864).

For example, 2 is a primitive element of the field $\operatorname{GF}(3)$ and $\operatorname{GF}(5)$, but not of $\operatorname{GF}(7)$ since it generates the cyclic subgroup $\{2, 4, 1\}$ of order 3; however, 3 is a primitive element of $\operatorname{GF}(7)$. The [minimal polynomial](wikipedia://en/9667106) of a primitive element is a [primitive polynomial](wikipedia://en/1029177).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Number of primitive elements {#Number_of_primitive_elements}

The number of primitive elements in a finite field $\operatorname{GF}(q)$ is $\varphi(q - 1)$, where $\varphi$ is [Euler's totient function](wikipedia://en/53452), which counts the number of elements less than or equal to $m$ that are [coprime](https://en.wikipedia.org/wiki/Coprime) to $m$. This can be proved by using the theorem that the multiplicative group of a finite field $\operatorname{GF}(q)$ is [cyclic](wikipedia://en/10603#Some_first_theorems) of order $q - 1$, and the fact that a finite cyclic group of order $m$ contains $\varphi(m)$ generators.

:::
