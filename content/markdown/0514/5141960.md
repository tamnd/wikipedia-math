# Neville's algorithm

::: {#o1 .subject cue=lead name="Neville's algorithm"}

In [mathematics](wikipedia://en/18831), **Neville's algorithm** is an algorithm used for [polynomial interpolation](wikipedia://en/203565) that was derived by the mathematician [Eric Harold Neville](wikipedia://en/27393555) in 1934. Given *n* + 1 points, there is a unique polynomial of degree *≤ n* which goes through the given points. Neville's algorithm evaluates this polynomial.

:::

Neville's algorithm is based on the [Newton form](wikipedia://en/216333) of the interpolating polynomial and the recursion relation for the [divided differences](wikipedia://en/976365). It is similar to [Aitken's algorithm](wikipedia://en/59511062) (named after [Alexander Aitken](wikipedia://en/3348690)), which is nowadays not used.

::: {#o3 .definition kind=definition/construction cue=heading name="The algorithm"}

## The algorithm {#The_algorithm}

Given a set of *n*+1 data points (*x*<sub>*i*</sub>, *y*<sub>*i*</sub>) where no two *x*<sub>*i*</sub> are the same, the interpolating polynomial is the polynomial *p* of degree at most *n* with the property

*p*(*x*<sub>*i*</sub>) = *y*<sub>*i*</sub> for all *i* = 0,...,*n*

This polynomial exists and it is unique. Neville's algorithm evaluates the polynomial at some point *x*.

Let *p*<sub>*i*,*j*</sub> denote the polynomial of degree *j* − *i* which goes through the points (*x*<sub>*k*</sub>, *y*<sub>*k*</sub>) for *k* = *i*, *i* + 1, ..., *j*. The *p*<sub>*i*,*j*</sub> satisfy the [recurrence relation](wikipedia://en/146806)

{|

\| $p_{i,i}(x) = y_i, \,$ || $0 \le i \le n, \,$ |- | $p_{i,j}(x) = \frac{(x-x_i)p_{i+1,j}(x) - (x-x_j)p_{i,j-1}(x)}{x_j-x_i}, \,$|| $0\le i < j \le n. \,$ |} This recurrence can calculate *p*<sub>0,*n*</sub>(*x*), which is the value being sought. This is Neville's algorithm.

For instance, for *n* = 4, one can use the recurrence to fill the triangular tableau below from the left to the right.

{|

\| $p_{0,0}(x) = y_0 \,$ |- | || $p_{0,1}(x) \,$ |- | $p_{1,1}(x) = y_1 \,$ || || $p_{0,2}(x) \,$ |- | || $p_{1,2}(x) \,$ || || $p_{0,3}(x) \,$ |- | $p_{2,2}(x) = y_2 \,$ || || $p_{1,3}(x) \,$ || || style="border: 1px solid;" | $p_{0,4}(x) \,$ |- | || $p_{2,3}(x) \,$ || || $p_{1,4}(x) \,$ |- | $p_{3,3}(x) = y_3 \,$ || || $p_{2,4}(x) \,$ |- | || $p_{3,4}(x) \,$ |- | $p_{4,4}(x) = y_4 \,$ |}

This process yields *p*<sub>0,4</sub>(*x*), the value of the polynomial going through the *n* + 1 data points (*x*<sub>*i*</sub>, *y*<sub>*i*</sub>) at the point *x*.

This algorithm needs [O](wikipedia://en/44578)(*n*<sup>2</sup>) floating point operations to interpolate a single point, and [O](wikipedia://en/44578)(*n*<sup>3</sup>) floating point operations to interpolate a polynomial of degree n.

The derivative of the polynomial can be obtained in the same manner, i.e.:

{|

\| $p'_{i,i}(x) = 0, \,$ || $0 \le i \le n, \,$ |- | $p'_{i,j}(x) = \frac{(x-x_i)p'_{i+1,j}(x) + p_{i+1,j}(x) - (x - x_j)p'_{i,j-1}(x) - p_{i,j-1}(x)}{x_j-x_i}, \,$ || $0\le i < j \le n. \,$ |}

:::

## Alternate notation easier for computer implementation {#Alternate_notation_easier_for_computer_implementation}

In the above formulae, if we take the degree of the successive interpolating polynomials *d* = *j* − *i* and change the notation to *p*<sub>*d*,*i*</sub>,

{|

\| $p_{0,i}(x) = y_i,$ || $d = 0$ |- | $p_{d,i}(x) = \frac{(x-x_i)p_{d-1,i+1}(x) - (x-x_{i+d})p_{d-1,i}(x)}{x_{i+d}-x_i},$ || $1 \le d \le n, 0 \le i \le n - d$ |}

The final value *p*<sub>*n*,0</sub> (in this notation) is the required interpolated value.

Since the number of computed items i.e. the range of *i* decreases with each successive *d*, a linear array can be used for memory efficiency with *p*<sub>*i*</sub> being overwritten and *d* being ignored. (For example: <https://github.com/gisalgs/geom/blob/master/neville.py>)

The derivative (using the [product rule](wikipedia://en/248988)) can be computed likewise as:

{|

\| $p'_{0,i}(x) = 0,$ || $d = 0$ |- | $p'_{d,i}(x) = \frac{(x-x_i)p'_{d-1,i+1}(x) + p_{d-1,i+1}(x) - (x - x_{i+d})p'_{d-1,i}(x) - p_{d-1,i}(x)}{x_{i+d}-x_i},$ || $1 \le d \le n, 0 \le i \le n - d$ |}

As before, *p*′<sub>*n*,0</sub> (in this notation) is the derivative.

As this depends on the successive computed values of *p* also for each *d*, it may be computed within the same loop. If linear arrays for *p* and *p′* are used for efficiency, the *p*′ values should be computed before the *p* values are overwritten.

## Application to numerical differentiation {#Application_to_numerical_differentiation}

Lyness and Moler showed in 1966 that using undetermined coefficients for the polynomials in Neville's algorithm, one can compute the Maclaurin expansion of the final interpolating polynomial, which yields numerical approximations for the derivatives of the function at the origin. While "this process requires more arithmetic operations than is required in finite difference methods", "the choice of points for function evaluation is not restricted in any way". They also show that their method can be applied directly to the solution of linear systems of the Vandermonde type.
