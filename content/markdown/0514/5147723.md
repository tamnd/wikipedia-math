# Birch's theorem

::: {#o1 .subject cue=lead name="Birch's theorem"}

In [mathematics](wikipedia://en/18831), **Birch's theorem**,[^o2] named for [Bryan John Birch](wikipedia://en/4949339), is a statement about the representability of zero by odd degree forms.

:::

::: {#o4 .statement cue=heading name="Statement of Birch's theorem"}

## Statement of Birch's theorem {#Statement_of_Birch's_theorem}

Let *K* be an [algebraic number field](wikipedia://en/28730822), *k*, *l* and *n* be [natural numbers](wikipedia://en/21474), *r*<sub>1</sub>, ..., *r*<sub>*k*</sub> be odd natural numbers, and *f*<sub>1</sub>, ..., *f*<sub>*k*</sub> be [homogeneous polynomials](wikipedia://en/1698977) with [coefficients](wikipedia://en/51203) in *K* of [degrees](wikipedia://en/5930652) *r*<sub>1</sub>, ..., *r*<sub>*k*</sub> respectively in *n* variables. Then there exists a number *ψ*(*r*<sub>1</sub>, ..., *r*<sub>*k*</sub>, *l*, *K*) such that if

$$n \ge \psi(r_1,\ldots,r_k,l,K)$$

then there exists an *l*-[dimensional](wikipedia://en/38267) [vector subspace](https://en.wikipedia.org/wiki/Vector_subspace) *V* of *K*<sup>*n*</sup> such that

$$f_1(x) = \cdots = f_k(x) = 0 \text{ for all } x \in V.$$

:::

## Remarks {#Remarks}

The [proof](wikipedia://en/82285) of the theorem is by [induction](wikipedia://en/18881) over the maximal degree of the forms *f*<sub>1</sub>, ..., *f*<sub>*k*</sub>. Essential to the proof is a special case, which can be proved by an application of the [Hardy–Littlewood circle method](https://en.wikipedia.org/wiki/Hardy–Littlewood_circle_method), of the theorem which states that if *n* is sufficiently large and *r* is odd, then the equation

$$c_1x_1^r+\cdots+c_nx_n^r=0,\quad c_i \in \mathbb{Z},\ i=1,\ldots,n$$

has a solution in [integers](wikipedia://en/14563) *x*<sub>1</sub>, ..., *x*<sub>*n*</sub>, not all of which are 0.

The restriction to odd *r* is necessary, since even degree forms, such as [positive definite quadratic forms](wikipedia://en/251478#Definiteness_of_a_quadratic_form), may take the value 0 only at the origin.
