# Recursive tree

::: {#o1 .subject cue=lead name="Recursive tree"}

In [graph theory](wikipedia://en/12401), a **recursive tree** (i.e., unordered tree) is a [labeled](wikipedia://en/1609861), rooted [tree](wikipedia://en/48560). A size-$n$ recursive tree's [vertices](wikipedia://en/638899) are labeled by distinct [positive integers](https://en.wikipedia.org/wiki/Positive_integer) $1, 2, \ldots, n$, where the labels are strictly increasing starting at the root labeled 1. Recursive trees are [non-planar](wikipedia://en/24314), which means that the children of a particular vertex are not ordered; for example, the following two size-3 recursive trees are equivalent: ${}_{3}/^{1}\backslash_{2} =_{2}/^{1}\backslash_{3}$.

:::

Recursive trees also appear in literature under the name *Increasing Cayley trees*.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The number of size-*n* recursive trees is given by

$$T_n= (n-1)!. \,$$

Hence the exponential [generating function](wikipedia://en/160993) *T*(*z*) of the sequence *T*<sub>*n*</sub> is given by

$$T(z)= \sum_{n\ge 1} T_n \frac{z^n}{n!}=\log\left(\frac{1}{1-z}\right).$$

Combinatorically, a recursive tree can be interpreted as a root followed by an unordered sequence of recursive trees. Let *F* denote the family of recursive trees. Then

$$F= \circ + \frac{1}{1!}\cdot \circ \times F + \frac{1}{2!}\cdot \circ \times F* F + \frac{1}{3!}\cdot \circ \times F* F* F * \cdots = \circ\times\exp(F),$$

where $\circ$ denotes the node labeled by 1, × the [Cartesian product](wikipedia://en/24104095) and $*$ the partition product for labeled objects.

By translation of the formal description one obtains the [differential equation](wikipedia://en/1424309) for *T*(*z*)

$$T'(z)= \exp(T(z)),$$

with *T*(0) = 0.

:::

## Bijections {#Bijections}

There are [bijective](wikipedia://en/3942) correspondences between recursive trees of size *n* and [permutations](wikipedia://en/44027) of size *n* − 1.

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

Recursive trees can be generated using a simple [stochastic process](wikipedia://en/47895). Such [random recursive trees](wikipedia://en/62951851) are used as simple models for epidemics.

:::
