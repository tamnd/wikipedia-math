# Maps to

::: {#o2 .subject cue=lead name="Maps to"}

The **maps to** symbol, ↦, is a rightward arrow protruding from a vertical bar. It is used in [mathematics](wikipedia://en/18831) and in [computer science](https://en.wikipedia.org/wiki/Computer_science)[^o3] to denote [functions](wikipedia://en/185427).

:::

- In [Z notation](https://en.wikipedia.org/wiki/Z_notation), a [specification language](https://en.wikipedia.org/wiki/Specification_language) used in software development,[^o4] this symbol is called the **maplet arrow** and the expression x ↦ y is called a **maplet**.
- In [separation logic](wikipedia://en/4273222) it denotes the contents of a specific cell of memory.

In the [Unicode](https://en.wikipedia.org/wiki/Unicode) character set, the symbol is code point U+21A6.[^o5]

## Other uses {#Other_uses}

The "Maps to" operator is useful when it is desirable to avoid assigning names to functions.

This can avoid possible misinterpretations due to poor naming conventions,[^o7] such as avoiding the following name conflict from these two functions existing in the same file or in the same mathematical proof:

- `func sqr:`$x \mapsto x*x$
  - Squares the input value
- `func sqr:`$x \mapsto (2*x)+(2*x)$.
  - Calculates the perimeter of a square when given an input side length.
