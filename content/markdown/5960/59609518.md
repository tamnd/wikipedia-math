# Parallel analysis

::: {#o1 .subject cue=lead name="Parallel analysis"}

**Parallel analysis**, also known as **Horn's parallel analysis**, is a statistical method used to determine the number of components to keep in a [principal component analysis](wikipedia://en/76340) or factors to keep in an [exploratory factor analysis](wikipedia://en/24688832). It is named after psychologist [John L. Horn](wikipedia://en/17885192), who created the method, publishing it in the journal *[Psychometrika](wikipedia://en/22991646)* in 1965.[^o2] The method compares the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) generated from the data matrix to the eigenvalues generated from a [Monte-Carlo simulated](https://en.wikipedia.org/wiki/Monte-Carlo_simulation) matrix created from random data of the same size.[^o3] Horn developed the method as a correction to the [Kaiser criterion](wikipedia://en/24688832#Kaiser_criterion), arguing that sampling error and least-squares capitalization inflate eigenvalues in sample data, causing the Kaiser rule to overestimate the number of factors to retain.[^o2]

:::

## Evaluation and comparison with alternatives {#Evaluation_and_comparison_with_alternatives}

Parallel analysis is regarded as one of the more accurate methods for determining the number of factors or components to retain. In particular, unlike early approaches to dimensionality estimation (such as examining scree plots), parallel analysis has the virtue of an objective decision criterion.[^o5] In a Monte Carlo simulation study across 96 conditions with known component structure, Zwick and Velicer found that parallel analysis and Velicer's MAP test[^o6] generally outperformed the other methods tested, while the Kaiser rule tended to severely overestimate the number of components.[^o5]

Since its original publication, multiple variations of parallel analysis have been proposed.[^o7][^o8] Other methods of determining the number of factors or components to retain in an analysis include the [scree plot](wikipedia://en/11233996), Kaiser rule, or Velicer's MAP test.[^o6]

[Anton Formann](wikipedia://en/31476948) provided both theoretical and empirical evidence that parallel analysis's application might not be appropriate in many cases since its performance is influenced by [sample size](https://en.wikipedia.org/wiki/Sample_size), [item discrimination](wikipedia://en/420159#The_item_response_function), and type of [correlation coefficient](wikipedia://en/29018709).[^o9]

An extensive 2022 simulation study by Haslbeck and van Bork[^o10] found that parallel analysis was among the best-performing existing methods, but was slightly outperformed by their proposed prediction error-based approach.

## Implementation {#Implementation}

Parallel analysis has been implemented in [JASP](https://en.wikipedia.org/wiki/JASP), [SPSS](wikipedia://en/179088), [SAS](wikipedia://en/990677), [STATA](https://en.wikipedia.org/wiki/STATA), and [MATLAB](wikipedia://en/20412)[^o13][^o14][^o15] and in multiple packages for the [R programming language](wikipedia://en/376707), including the *psych*[^o16][^o17] *multicon*,[^o18] *hornpa*,[^o19] and *paran* packages.[^o20][^o21] Parallel analysis can also be conducted in Mplus version 8.0 and forward.[^o22]
