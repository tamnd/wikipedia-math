# LOGCFL

::: {#o1 .subject cue=lead name="LOGCFL"}

In [computational complexity theory](wikipedia://en/7543), **LOGCFL** is the [complexity class](wikipedia://en/502426) that contains all [decision problems](wikipedia://en/8336) that can be reduced in [logarithmic space](https://en.wikipedia.org/wiki/Logarithmic_space) to a [context-free language](wikipedia://en/6867). This class is closed under complementation. It is situated between [NL](wikipedia://en/1145955) and [AC<sup>1</sup>](wikipedia://en/7401755), in the sense that it contains the former and is contained in the latter. Problems that are [complete](wikipedia://en/1176530) for LOGCFL include many problems that can be characterized by [acyclic](wikipedia://en/204002) [hypergraphs](wikipedia://en/232535):

:::

- evaluating acyclic [Boolean conjunctive queries](https://en.wikipedia.org/wiki/Boolean_conjunctive_query)
- checking the existence of a [homomorphism](wikipedia://en/13564) between two acyclic [relational structures](https://en.wikipedia.org/wiki/Relational_structure)
- checking the existence of solutions of acyclic [constraint satisfaction problems](wikipedia://en/211652)

LOGCFL is the set of decision problems solvable by [nondeterministic](wikipedia://en/653406) auxiliary [pushdown automata](wikipedia://en/24510) in [log space](wikipedia://en/338946) and [polynomial time](wikipedia://en/405944).[^o2]
