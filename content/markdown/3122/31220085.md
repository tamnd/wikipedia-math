# Super column

::: {#o1 .subject cue=lead name="Super column"}

*Image: SuperColumn (data store).png.* The super column consists of a (unique) super column name, and a number of columns.

A **super column** is a [tuple](wikipedia://en/132729) (a pair) with a binary super column name and a value that maps it to many columns.[^o2] They consist of a [key–value pairs](https://en.wikipedia.org/wiki/Attribute–value_pair), where the values are columns. Theoretically speaking, super columns are ([sorted](wikipedia://en/28442)) [associative array](https://en.wikipedia.org/wiki/Associative_array) of columns.[^o3] Similar to a regular [column family](https://en.wikipedia.org/wiki/Column_family) where a row is a sorted map of column names and column values, a row in a super column family is a sorted map of super column names that maps to column names and column values.

:::

A super column is part of a [keyspace](https://en.wikipedia.org/wiki/Keyspace_%28distributed_data_store%29) together with other super columns and column families, and columns.

## Code example {#Code_example}

Written in the [JSON](https://en.wikipedia.org/wiki/JSON)-like syntax, a super column definition can be like this:

```json
{
  "databases": {
    "Cassandra": {
      "age": 20,
      "name": {
        "firstName": "Cassandra",
        "lastName": "apache"
      }
    },
    "HBase": {
      "age": 20,
      "address": {
        "city": "Seoul",
        "postcode": "1234"
      }
    }
  }
}
```

Where:

"databases" are [keyspace](https://en.wikipedia.org/wiki/Keyspace_%28distributed_data_store%29);

"Cassandra" and "HBase" are rowKeys;

"name" and "address" are ***super column*** names;

"firstName", "city", "age", etc. are [column](https://en.wikipedia.org/wiki/Column_%28data_store%29) names.
