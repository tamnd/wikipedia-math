# De Bruijn factor

::: {#o1 .subject cue=lead name="De Bruijn factor"}

The **de Bruijn factor** is a measure of how much harder it is to write a [formal mathematical proof](wikipedia://en/1197184) instead of an [informal one](wikipedia://en/82285). It was created by the Dutch computer-proof pioneer [Nicolaas Govert de Bruijn](wikipedia://en/3166399).

:::

De Bruijn computed it as the size of the formal proof over the size of the informal proof.[^o2]

[Freek Wiedijk](https://en.wikipedia.org/wiki/Freek_Wiedijk) refined the definition to use the compressed size of the formal proof over the compressed size of the informal proof. He called this the "intrinsic de Bruijn Factor". The compression removes the effect that the length of identifiers in the proofs might have.[^o3]
