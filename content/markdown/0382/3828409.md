# Glivenko–Cantelli theorem

::: {#o1 .subject cue=lead name="Glivenko–Cantelli theorem"}

*Image: Donsker\_theorem\_for\_uniform\_distributions.gif.* The left diagram illustrates Glivenko–Cantelli theorem for uniform distributions. The right diagram illustrates the [Donsker–Skorokhod–Kolmogorov theorem](wikipedia://en/3828419)

*Image: Donsker\_theorem\_for\_normal\_distributions.gif.* The same diagram for normal distributions

In the [theory of probability](https://en.wikipedia.org/wiki/Theory_of_probability), the **Glivenko–Cantelli theorem** (sometimes referred to as the **fundamental theorem of statistics**), named after [Valery Ivanovich Glivenko](https://en.wikipedia.org/wiki/Valery_Ivanovich_Glivenko) and [Francesco Paolo Cantelli](wikipedia://en/3166906), describes the asymptotic behaviour of the [empirical distribution function](wikipedia://en/2690455) as the number of [independent and identically distributed](wikipedia://en/30876902) observations grows.[^o2] Specifically, the empirical distribution function [converges uniformly](wikipedia://en/50652) to the true distribution function [almost surely](wikipedia://en/351908).

:::

The uniform convergence of more general [empirical measures](wikipedia://en/5647670) becomes an important property of the **Glivenko–Cantelli classes** of functions or sets.[^o3] The Glivenko–Cantelli classes arise in [Vapnik–Chervonenkis theory](wikipedia://en/305843), with applications to [machine learning](wikipedia://en/233488). Applications can be found in [econometrics](wikipedia://en/10390) making use of [M-estimators](wikipedia://en/4225388).

::: {#o5 .statement cue=heading name="Statement"}

## Statement {#Statement}

Assume that $X_1,X_2,\dots$ are [independent and identically distributed random variables](wikipedia://en/30876902) in $\mathbb{R}$ with common [cumulative distribution function](wikipedia://en/5793) $F(x)$. The *[empirical distribution function](wikipedia://en/2690455)* for $X_1,\dots,X_n$ is defined by

$$F_n(x) = \frac{1}{n} \sum_{i=1}^n I_{(-\infty, x]}(X_i) = \frac{1}{n} \left|\left\{i \mid X_i \leq x, \ 1 \leq i \leq n \right\}\right|,$$

where $I_C$ is the [indicator function](wikipedia://en/240790) of the set $C.$ For every (fixed) $x,$ $F_n(x)$ is a sequence of random variables which converge to $F(x)$ [almost surely](wikipedia://en/50723#Almost_sure_convergence) by the strong [law of large numbers](wikipedia://en/157055). Glivenko and Cantelli strengthened this result by proving [uniform convergence](wikipedia://en/50652) of $F_n$ to $F.$

::: {#o7 .statement cue=heading name="Theorem"}

### Theorem {#Theorem}

$\|F_n - F\|_\infty = \sup_{x \in \mathbb{R}} \bigl|F_n(x) - F(x)\bigr| \longrightarrow 0$ almost surely.[^o8]p. 265

This theorem originates with [Valery Glivenko](https://en.wikipedia.org/wiki/Valery_Ivanovich_Glivenko)[^o9] and [Francesco Cantelli](wikipedia://en/3166906),[^o10] in 1933.

:::

### Remarks {#Remarks}

- If $X_n$ is a stationary [ergodic process](https://en.wikipedia.org/wiki/Ergodic_process), then $F_n(x)$ converges almost surely to $F(x) = \operatorname\mathbb{E} \bigl[ 1_{X_1 \le x} \bigr].$ The Glivenko–Cantelli theorem gives a stronger mode of convergence than this in the [iid](https://en.wikipedia.org/wiki/Iid) case.
- An even stronger uniform convergence result for the empirical distribution function is available in the form of an extended type of [law of the iterated logarithm](wikipedia://en/496558).[^o8]p. 268 See [asymptotic properties of the empirical distribution function](wikipedia://en/2690455#Asymptotic_properties) for this and related results.

:::

::: {#o13 .proof cue=heading name="Proof"}

## Proof {#Proof}

For simplicity, consider a case of continuous random variable $X$. Fix $-\infty =x_0<x_1<\cdots <x_{m-1}<x_m=\infty$ such that $F(x_j)-F(x_{j-1})=\frac{1}{m}$ for $j=1,\dots,m$. Now for all $x \in \mathbb{R}$ there exists $j \in \{1,\dots,m\}$ such that $x \in [x_{j-1},x_j]$.

$$\begin{aligned} F_n(x)-F(x) &\leq F_n(x_j)-F(x_{j-1}) = F_n(x_j)-F(x_j)+\frac1m,\\ F_n(x)-F(x) &\geq F_n(x_{j-1})-F(x_j) = F_n(x_{j-1})-F(x_{j-1})-\frac1m. \end{aligned}$$

Therefore,

$$\|F_n-F\|_\infty = \sup_{x\in \mathbb{R}}|F_n(x)-F(x)| \leq \max_{j\in\{1,\dots,m\}} |F_n(x_j)-F(x_j)| + \frac1m.$$

Since $\max_{j\in\{1,\dots,m\}} |F_n(x_j)-F(x_j)| \to 0 \text{ a.s.}$ by strong law of large numbers, we can guarantee that for any positive $\varepsilon$ and any integer $m$ such that $1/m<\varepsilon$, we can find $N$ such that for all $n \geq N$, we have $\max_{j\in\{1,\dots,m\}} |F_n(x_j)-F(x_j)|\leq \varepsilon-1/m \text{ a.s.}$. Combined with the above result, this further implies that $\|F_n-F\|_\infty \leq \varepsilon \text{ a.s.}$, which is the definition of almost sure convergence.

:::

## Empirical measures {#Empirical_measures}

One can generalize the *empirical distribution function* by replacing the set $(-\infty,x]$ by an arbitrary set *C* from a class of sets $\mathcal{C}$ to obtain an [empirical measure](wikipedia://en/5647670) indexed by sets $C \in \mathcal{C}.$

$$P_n(C)=\frac{1}{n} \sum_{i=1}^n I_C(X_i), C\in\mathcal{C}$$

Where $I_C(x)$ is the [indicator function](wikipedia://en/240790) of each set $C$.

Further generalization is the map induced by $P_n$ on measurable real-valued functions *f*, which is given by

$$f\mapsto P_nf=\int_Sf \, dP_n = \frac 1 n \sum_{i=1}^n f(X_i), f\in\mathcal{F}.$$

Then it becomes an important property of these classes whether the strong [law of large numbers](wikipedia://en/157055) holds uniformly on $\mathcal{F}$ or $\mathcal{C}$.

## Glivenko–Cantelli class {#Glivenko–Cantelli_class}

Consider a set $\ \mathcal{S}\$ with a [sigma algebra](wikipedia://en/29586) of [Borel subsets](wikipedia://en/43327) $A$ and a [probability measure](wikipedia://en/45437) $\ \mathbb{P} ~.$ For a class of subsets,

$$\mathcal{C} \subset \bigl\{ C: C \text{ is measurable subset of }\mathcal{S} \bigr\}$$

and a class of functions

$$\mathcal{F} \subset \bigl\{ f:\mathcal{S}\to \mathbb{R}, f \mbox{ is measurable}\ \bigr\}$$

define random variables

$$\bigl\| \mathbb{P}_n - \mathbb{P} \bigr\|_{\mathcal C} = \sup_{C \in {\mathcal C}} \bigl| \mathbb{P}_n(C) - \mathbb{P}(C) \bigr|$$

$$\bigl\| \mathbb{P}_n - \mathbb{P} \bigr\|_{\mathcal F} = \sup_{f \in {\mathcal F}} \bigl| \mathbb{P}_n f - \mathbb{P} f \bigr|$$

where $\ \mathbb{P}_n(C)\$ is the empirical measure, $\ \mathbb{P}_n f\$ is the corresponding map, and

$\ \mathbb{P} f = \int_\mathcal{S} f \ \mathrm{d}\mathbb{P}\ ,$ assuming that it exists.

**Definitions**

- A class $\ \mathcal C\$ is called a ***Glivenko–Cantelli class*** (or *GC class*, or sometimes *strong GC class*) with respect to a probability measure $P$ if

$\ \bigl\| \mathbb{P}_n - \mathbb{P} \bigr\|_\mathcal{C} \to 0\$ almost surely as $\ n \to \infty ~.$

- A class $\ \mathcal C\$ is a *weak Glivenko-Cantelli class* with respect to $P$ if it instead satisfies the weaker condition

$\ \bigl\| \mathbb{P}_n - \mathbb{P} \bigr\|_\mathcal{C} \to 0\$ in probability as $\ n \to \infty ~.$

- A class is called a *universal Glivenko–Cantelli class* if it is a GC class with respect to any probability measure $\mathbb{P}$ on $(\mathcal{S}, A)$.
- A class is a *weak uniform Glivenko–Cantelli class* if the convergence occurs uniformly over all probability measures $\mathbb{P}$ on $(\mathcal{S}, A)$: For every $\varepsilon > 0$,

$\ \sup_{\mathbb{P} \in \mathbb{P}(\mathcal{S},A)} \Pr\left(\bigl\| \mathbb{P}_n - \mathbb{P} \bigr\|_\mathcal{C} > \varepsilon\right) \to 0\$ as $\ n \to \infty ~.$

- A class is a (strong) *uniform Glivenko-Cantelli class* if it satisfies the stronger condition that for every $\varepsilon > 0$,

$\ \sup_{\mathbb{P} \in \mathbb{P}(\mathcal{S},A)} \Pr\left(\sup_{m \geq n} \bigl\| \mathbb{P}_m - \mathbb{P} \bigr\|_\mathcal{C} > \varepsilon\right) \to 0\$ as $\ n \to \infty ~.$

Glivenko–Cantelli classes of functions (as well as their uniform and universal forms) are defined similarly, replacing all instances of $\mathcal{C}$ with $\mathcal{F}$.

The weak and strong versions of the various Glivenko-Cantelli properties often coincide under certain regularity conditions. The following definition commonly appears in such regularity conditions:

- A class of functions $\mathcal{F}$ is *image-admissible Suslin* if there exists a [Suslin space](wikipedia://en/396622#Suslin_spaces) $\Omega$ and a surjection $T:\Omega \rightarrow \mathcal{F}$ such that the map $(x, y) \mapsto [T(y)](x)$ is measurable $\mathcal{X}\times\Omega$.
- A class of measurable sets $\mathcal{C}$ is image-admissible Suslin if the class of functions $\{\mathbf{1}_C \mid C\in\mathcal{C}\}$ is image-admissible Suslin, where $\mathbf{1}_C$ denotes the [indicator function](wikipedia://en/240790) for the set $C$.

**Theorems**

The following two theorems give sufficient conditions for the weak and strong versions of the Glivenko-Cantelli property to be equivalent.

::: {#o16 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** ([Talagrand](wikipedia://en/11091583), 1987)[^o17]

*Let $\mathcal{F}$ be a class of functions that is integrable $\mathbb{P}$, and define $\mathcal{F}_0 = \{f - \mathbb{P}f \mid f\in \mathcal{F}\}$. Then the following are equivalent:*

- *$\mathcal{F}$ is a weak Glivenko-Cantelli class and $\mathcal{F}_0$ is dominated by an integrable function*
- *$\mathcal{F}$ is a Glivenko-Cantelli class*

:::

::: {#o18 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** ([Dudley](wikipedia://en/3824977), Giné, and Zinn, 1991)[^o19]

*Suppose that a function class $\mathcal{F}$ is bounded. Also suppose that the set $\mathcal{F}_0 = \{f - \inf f \mid f\in \mathcal{F}\}$ is image-admissible Suslin. Then $\mathcal{F}$ is a weak uniform Glivenko-Cantelli class if and only if it is a strong uniform Glivenko-Cantelli class.*

The following theorem is central to statistical learning of [binary classification](wikipedia://en/205393) tasks.

:::

::: {#o20 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** ([Vapnik](https://en.wikipedia.org/wiki/Vladimir_Vapnik) and [Chervonenkis](wikipedia://en/305850), 1968)[^o21]

*Under certain consistency conditions, a universally measurable class of sets $\ \mathcal{C}\$ is a uniform Glivenko-Cantelli class if and only if it is a [Vapnik–Chervonenkis class](https://en.wikipedia.org/wiki/Shattering_%28machine_learning%29#Vapnik–Chervonenkis_class).*

There exist a variety of consistency conditions for the equivalence of uniform Glivenko-Cantelli and Vapnik-Chervonenkis classes. In particular, either of the following conditions for a class $\mathcal{C}$ suffice:[^o22]

- $\mathcal{C}$ is image-admissible Suslin.
- $\mathcal{C}$ is universally [separable](wikipedia://en/27855): There exists a countable subset $\mathcal{C_0}$ of $\mathcal{C}$ such that each set $C\in\mathcal{C}$ can be written as the pointwise limit of sets in $\mathcal{C}_0$.

:::

::: {#o24 .example cue=heading name="Examples"}

## Examples {#Examples}

- Let $S=\mathbb R$ and ${\mathcal C}=\{(-\infty,t]:t\in {\mathbb R}\}$. The classical Glivenko–Cantelli theorem implies that this class is a universal GC class. Furthermore, by [Kolmogorov's theorem](https://en.wikipedia.org/wiki/Kolmogorov-Smirnov_test),

$\sup_{P\in \mathcal{P}(S,A)}\|P_n-P\|_{\mathcal C} \sim n^{-1/2}$, that is $\mathcal{C}$ is uniformly Glivenko–Cantelli class.

- Let *P* be a [nonatomic](wikipedia://en/3058373) probability measure on *S* and $\mathcal{C}$ be a class of all finite subsets in *S*. Because $A_n=\{X_1,\ldots,X_n\}\in \mathcal{C}$, $P(A_n)=0$, $P_n(A_n)=1$, we have that $\|P_n-P\|_{\mathcal C}=1$ and so $\mathcal{C}$ is *not* a GC class with respect to *P*.

:::
