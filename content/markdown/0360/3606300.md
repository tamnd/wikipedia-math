# Kruskal's tree theorem

::: {#o1 .subject cue=lead name="Kruskal's tree theorem"}

In [mathematics](wikipedia://en/18831), **Kruskal's tree theorem** states that the set of finite [trees](wikipedia://en/48560) over a [well-quasi-ordered](wikipedia://en/739775) set of labels is itself well-quasi-ordered under [homeomorphic](wikipedia://en/353021) embedding.

:::

A [finitary](wikipedia://en/404456) application of the theorem gives the existence of a fast-growing **TREE function**. TREE(3) is one of the largest simply defined finite numbers, dwarfing other [large numbers](wikipedia://en/187750) such as [Graham's number](wikipedia://en/234232) and [googolplex](wikipedia://en/12365).[^o2]

## History {#History}

The [theorem](wikipedia://en/30977) was [conjectured](wikipedia://en/6138) by [Andrew Vázsonyi](https://en.wikipedia.org/wiki/Andrew_Vázsonyi) and [proved](wikipedia://en/82285) by (); a short proof was given by (). It has since become a prominent example in [reverse mathematics](wikipedia://en/326365) as a statement that cannot be proved in ATR<sub>0</sub> (a [second-order arithmetic](wikipedia://en/3542454) theory with a form of [arithmetical transfinite recursion](https://en.wikipedia.org/wiki/Arithmetical_transfinite_recursion)).

In 2004, the result was generalized from trees to [graphs](wikipedia://en/325806) as the [Robertson–Seymour theorem](wikipedia://en/351769), a result that has also proved important in reverse mathematics and leads to the even-faster-growing [SSCG function](wikipedia://en/46944668), which dwarfs TREE.

::: {#o7 .statement cue=heading name="Statement"}

## Statement {#Statement}

The version given here is that proven by Nash-Williams; Kruskal's formulation is somewhat stronger. All trees we consider are finite.

Given a tree $T$ with a [root](https://en.wikipedia.org/wiki/Rooted_tree), and given vertices $v$, $w$, call $w$ a *descendant* of $v$ if the unique path from the root to $w$ contains $v$, and call $w$ a *child* of $v$ if additionally the path from $v$ to $w$ contains no other vertex.

Take $(X, \le_X)$ to be a [partially ordered set](wikipedia://en/23572). If $T_1$, $T_2$ are rooted trees with vertices labeled in $X$, we say that $T_1$ is *inf-embeddable* in $T_2$ and write $T_1 \leq T_2$ if there is an [injective map](https://en.wikipedia.org/wiki/Injective_map) $F$ from the vertices of $T_1$ to the vertices of $T_2$ such that:

- For all vertices $v$ of $T_1$, the label of $v$ is $\le_X$ the label of $F(v)$;
- If $w$ is any descendant of $v$ in $T_1$, then $F(w)$ is a descendant of $F(v)$; and
- If $w_1$, $w_2$ are any two distinct children of $v$, then the path from $F(w_1)$ to $F(w_2)$ in $T_2$ contains $F(v)$ (equivalently, $F(w_1)$ and $F(w_2)$ lie in different subtrees of $v$).

Kruskal's tree theorem then states:

If $X$ is [well-quasi-ordered](wikipedia://en/739775), then the set of rooted trees with labels in $X$ is well-quasi-ordered under the inf-embeddable order defined above. That is to say, given any infinite sequence $T_1, T_2, \ldots$ of rooted trees labeled in $X$, there is some $i<j$ so that $T_i \leq T_j$.

:::

## Friedman's work {#Friedman's_work}

For a [countable](wikipedia://en/6026) label set $X$, Kruskal's tree theorem can be expressed and proven using [second-order arithmetic](wikipedia://en/3542454). However, like [Goodstein's theorem](wikipedia://en/150062) or the [Paris–Harrington theorem](wikipedia://en/3875355), some special cases and variants of the theorem can be expressed in subsystems of second-order arithmetic much weaker than the subsystems where they can be proved. This was first observed by [Harvey Friedman](wikipedia://en/3038108) in the early 1980s, an early success of the then-nascent field of reverse mathematics. In the case where the trees above are taken to be unlabeled (that is, in the case where $X$ has size one), Friedman found that the result was unprovable in [ATR<sub>0</sub>](https://en.wikipedia.org/wiki/Arithmetical_transfinite_recursion),[^o9] thus giving the first example of a [predicative](wikipedia://en/1930406) result with a provably impredicative proof.[^o10] This case of the theorem is still provable by Π${}^{1}_{1}$-CA<sub>0</sub>, but by adding a "gap condition"[^o11] to the definition of the order on trees above, he found a natural variation of the theorem unprovable in this system.[^o12][^o13] Much later, the Robertson–Seymour theorem would give another theorem unprovable by Π${}^{1}_{1}$-CA<sub>0</sub>.

[Ordinal analysis](wikipedia://en/16084282) confirms the strength of Kruskal's theorem, with the [proof-theoretic ordinal](https://en.wikipedia.org/wiki/Proof-theoretic_ordinal) of the theorem equaling the [small Veblen ordinal](wikipedia://en/16110499) (sometimes confused with the smaller [Ackermann ordinal](wikipedia://en/16137162)).[^n1] Kruskal's tree theorem itself proves that $\Gamma_0$, the [Feferman–Schütte ordinal](wikipedia://en/16084455), is [well-founded](https://en.wikipedia.org/wiki/Well-founded); in particular, the inf-embeddable ordering on a countable label set contains a well-ordered chain of order type $\Gamma_0$.[^o15]

## Weak tree function {#Weak_tree_function}

Suppose that $P(n)$ is the statement:

There is some $m$ such that if $T_1, \ldots, T_m$ is a finite sequence of unlabeled rooted trees where $T_i$ has $i+n$ vertices, then $T_i \leq T_j$ for some $i<j$.

All the statements $P(n)$ are true as a consequence of Kruskal's theorem and [Kőnig's lemma](wikipedia://en/153788). For each $n$, [Peano arithmetic](wikipedia://en/25005) can prove that $P(n)$ is true, but Peano arithmetic cannot prove the statement "$P(n)$ is true for all $n$".[^o17] Moreover, the length of the shortest [proof](wikipedia://en/1197184) of $P(n)$ in Peano arithmetic grows phenomenally fast as a function of $n$, far faster than any [primitive recursive function](wikipedia://en/24829) or the [Ackermann function](wikipedia://en/2925), for example. The least $m$ for which $P(n)$ holds similarly grows extremely quickly with $n$.

Friedman defined the following function, which is a weaker version of the TREE function below. For a positive [integer](wikipedia://en/14563) $n$, take $\text{FFF}(n)$ to be the largest $m$ so that we have the following:

There is a sequence $T_1, \ldots, T_m$ of rooted trees, where each $T_i$ has $i+n-1$ vertices, such that $T_i \leq T_j$ does not hold for any $i<j\leq m$.

Friedman computes the first few terms of this sequence as $\text{FFF}(1)=1$, $\text{FFF}(2)=2$, and $\text{FFF}(3)=5$. He also estimates $\text{FFF}(4)$ to be less than 100, while $\text{FFF}(5)$ suddenly explodes to a very large value. Any proof that $\text{FFF}(5)$ exists in Peano arithmetic requires at least $A(10)$ symbols, where $A(n)$ is the unary version of the [Ackermann function](wikipedia://en/2925), but it can be proved to exist in [ACA<sub>0</sub>](https://en.wikipedia.org/wiki/Arithmetical_comprehension) with at most 10,000 symbols.[^o18]

## TREE function {#TREE_function}

*Image: TREE(3) sequence.png.* A sequence of rooted trees labelled from a set of 3 labels (blue \< red \< green). The $n$th tree in the sequence contains at most $n$ vertices, and no tree is inf-embeddable within any later tree in the sequence. $\text{TREE}(3)$ is defined to be the longest possible length of such a sequence.

By incorporating labels, Friedman defined a far faster-growing function.[^o21] For a positive [integer](wikipedia://en/14563) $n$, take $\text{TREE}(n)$ to be the largest $m$ so that we have the following:

There is a sequence $T_1, \ldots, T_m$ of rooted trees labelled from a set of $n$ labels, where each $T_i$ has at most $i$ vertices, such that $T_i \leq T_j$ does not hold for any $i<j\leq m$.

Kruskal's theorem asserts that $\text{TREE}(n)$ is finite for all $n$. The TREE function eventually dominates every provably recursive function of the system ACA<sub>0</sub> + Π${}^{1}_{2}$-BI.[^o21] It grows far faster than $f_{\Gamma_0}(n)$ on the [fast-growing hierarchy](wikipedia://en/24947285); Friedman calculated the ordinal $\alpha$ where $\text{TREE}(n)$ and $f_\alpha(n)$ have similar growth rate (under [affine transformation](wikipedia://en/38449) of input variables).[^o22]

The sequence begins $\text{TREE}(1)=1$, $\text{TREE}(2)=3$; before $\text{TREE}(3)$ increases to a value so large that many other "large" combinatorial constants, such as Friedman's $n(4)$ and [Graham's number](wikipedia://en/234232), are surpassed by comparison. A [lower bound](https://en.wikipedia.org/wiki/Lower_bound) for $n(4)$, and, hence, an *extremely* weak lower bound for $\text{TREE}(3)$, is $A^{A(187196)}(1)$, where $A(x)$ is the single-argument version of [Ackermann's function](https://en.wikipedia.org/wiki/Ackermann's_function), defined as $A(x)=A(x,x)$.[^o21][^o23]

Friedman showed that $\text{TREE}(3)$ is greater than the halting time of any [Turing machine](wikipedia://en/30403) that can be proved to halt in ACA<sub>0</sub> + Π${}^{1}_{2}$-BI with at most $2\uparrow\uparrow1000$ symbols, where $\uparrow\uparrow$ denotes [tetration](wikipedia://en/482379).[^o21]

:::

## Notes {#Notes}

Friedman originally denoted this function by $\text{TR}[n]$.

$n(k)$ is defined as the length of the longest possible sequence that can be constructed with a $k$-letter alphabet such that no block of letters $x_i,\ldots,x_{2i}$ is a subsequence of any later block $x_j,\ldots,x_{2j}$.[^o26] For example $n(1) = 3$, $n(2) = 11$, and $n(3) > 2 \uparrow^{7197} 158386$.

The superscript indicates [iteration](wikipedia://en/68833). For example, $A^{3}(1)$ would mean computing $A(A(A(1)))$.

Friedman actually writes this as 2<sup>\[1000\]</sup>, which denotes an exponential stack of 2's of height 1000 using his notation.[^o27]
