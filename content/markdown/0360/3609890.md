# Baillie–PSW primality test

::: {#o1 .subject cue=lead name="Baillie–PSW primality test"}

::: {#o2 .problem cue=unsolved}

Is there a composite number that passes the Baillie–PSW primality test?

:::

The **Baillie–PSW primality test** is a [probabilistic](wikipedia://en/495383) or possibly deterministic [primality testing](wikipedia://en/183751) algorithm that determines whether a number is [composite](wikipedia://en/82289) or is a [probable prime](wikipedia://en/160560). It is named after Robert Baillie, [Carl Pomerance](wikipedia://en/2134159), [John Selfridge](wikipedia://en/995084), and [Samuel Wagstaff](https://en.wikipedia.org/wiki/Samuel_Wagstaff).

:::

The Baillie–PSW test is a combination of a [strong Fermat probable prime](wikipedia://en/1100422) test to base 2 and a standard or strong [Lucas probable prime](wikipedia://en/1055370) test. The Fermat and Lucas test each have their own list of pseudoprimes, that is, composite numbers that pass the test. For example, the first ten strong pseudoprimes to base 2 are

2047, 3277, 4033, 4681, 8321, 15841, 29341, 42799, 49141, and 52633 .

The first ten strong Lucas pseudoprimes (with Lucas parameters (*P*, *Q*) defined by Selfridge's Method A) are

5459, 5777, 10877, 16109, 18971, 22499, 24569, 25199, 40309, and 58519 .

There is no known overlap between these lists, and there is even evidence that the numbers tend to be of different kind, in fact even with standard and not strong Lucas test there is no known overlap. For example, Fermat pseudoprimes to base 2 tend to fall into the residue class 1 (mod *m*) for many small *m*, whereas Lucas pseudoprimes tend to fall into the residue class −1 (mod *m*).[^o3][^o4] As a result, a number that passes both a strong Fermat base 2 and a strong Lucas test is very likely to be prime. If a random base is chosen, there might be some composite n that passes both the Fermat and Lucas tests. For example, n=5777 is a strong psp base 76, and is also a strong Lucas pseudoprime.

No composite number below 2<sup>64</sup> (approximately 1.845·10<sup>19</sup>) passes the strong or standard Baillie–PSW test;[^o5] this result was also separately verified by Charles Greathouse in June 2011. Consequently, this test is a deterministic primality test on numbers below 2<sup>64</sup>. There are also no known composite numbers above that bound that pass the test; in other words, there are no known Baillie–PSW pseudoprimes.

In 1980, the authors Pomerance, Selfridge, and Wagstaff offered \$30 for the discovery of a counterexample, that is, a composite number that passed this test, or the production of a proof of this test's correctness.[^o3] A heuristic argument by Pomerance suggests that there are infinitely many counterexamples.[^o6] There is also a \$2000 bounty on a strengthened version of this test.[^o10]

## The test {#The_test}

Let *n* be the odd positive integer that we wish to test for primality.

1. Optionally, perform [trial division](wikipedia://en/557660) to check if *n* is divisible by a small [prime number](wikipedia://en/23666) less than some convenient limit.
1. Perform a base 2 [strong probable prime](wikipedia://en/1100422) test. If *n* is not a strong probable prime base 2, then *n* is composite; quit.
1. Find the first *D* in the sequence 5, −7, 9, −11, 13, −15, ... for which the [Jacobi symbol](wikipedia://en/97313) (*D*/*n*) is −1. Set *P* = 1 and *Q* = (1 − *D*) / 4 (method A).
   - If *D* = 5, the choice should be modified to *P* = *Q* = 5 instead of *P* = 1, *Q* = -1 for better strength (method A\*).[^o10]
1. Perform a strong [Lucas probable prime](wikipedia://en/1055370#Strong_Lucas_pseudoprimes) test on *n* using parameters *D*, *P*, and *Q*. If *n* is not a strong Lucas probable prime, then *n* is composite. Otherwise, *n* is almost certainly prime.

Remarks.

1. The first step is for efficiency only. The Baillie–PSW test works without this step, but if *n* has small prime factors, then the quickest way to show that *n* is composite is to find a factor by trial division.
1. Step 2 is, in effect, a single application of the [Miller–Rabin primality test](wikipedia://en/188999), but using the fixed base 2. There is nothing special about using base 2; pseudoprimes to different bases seem to have the same growth rate, so other bases might work just as well. However, much work has been done (see above) to verify that the combination of the base 2 strong probable prime test and a strong Lucas test does a good job of distinguishing primes from composites.
1. Baillie and Wagstaff proved in Theorem 9 on page 1413 of[^o4] that the average number of *D*s that must be tried is about 3.147755149.
1. If *n* is a perfect square, then step 3 will never yield a *D* with (*D*/*n*) = −1; this is not a problem because perfect squares are easy to detect using [Newton's method](wikipedia://en/22145) for square roots. If step 3 fails to produce a *D* quickly, one should check whether *n* is a perfect square.
1. Given *n*, there are other methods for choosing *D*, *P*, and *Q*. What is important is that the Jacobi symbol (*D*/*n*) be −1. Bressoud and Wagon explain why we want the Jacobi symbol to be −1, as well as why one gets more powerful primality tests if *Q* ≠ ±1.[^o8]

### Other changes {#Other_changes}

Section 6 of Baillie and Wagstaff (1980)[^o4] and Baillie, Fiori, and Wagstaff (2021)[^o10] recommend that a strengthened primality test should check two additional congruence conditions:

1. $V_{n+1} \equiv 2 Q \pmod {n}$, testing that n is a Lucas-V probable prime
1. $Q^{(n+1)/2} = Q \cdot Q^{(n-1)/2} \equiv Q \cdot \left(\tfrac{Q}{n}\right) \pmod {n}$, an [Euler–Jacobi probable prime](wikipedia://en/101334) in base Q.

These two congruences involve almost no extra computational cost, and are only rarely true if *n* is composite. Using the A\* method for picking D, P, and Q, there are only five odd, composite numbers (also called Dickson pseudoprimes of the second kind) less than 10<sup>15</sup> for which $V_{n+1} \equiv 2 Q \pmod {n}$. Baillie, Fiori, and Wagstaff (2021) offers a \$2000 reward for either correctness or a counter example on the test with these two congruence conditions.[^o10]

Di Iorio (2025) proposes a slight simplification of the strong probable prime part of the test by exploiting the fixed base of 2 used by the test.[^o11]

## Related tests {#Related_tests}

The original proposal of Baillie–PSW contained a second method of initializing the Lucas test:

- Find the first *D* in the sequence 5, 9, 13, 17, 21, ... for which the Jacobi symbol (*D*/*n*) is −1. Let P be the least odd number exceeding √*D* and let Q = (P<sup>2</sup>−D)/4.

This method is not used in practice as it's more complicated. It also seems to produce more Lucas pseudoprimes. The \$30 bounty also covers counterexamples using this test.[^o13]

There is a weaker [Selfridge primality test](https://en.wikipedia.org/wiki/Selfridge_primality_test) that replaces the Lucas test with a Fibonacci test. There is a \$620 prize for either proving the correctness or providing a counterexample for the Selfridge test. [Richard Guy](wikipedia://en/816308) confused this prize money with the Baillie-PSW prize money.[^o14] As of June 2014 the prize remains unclaimed. Exhaustive checks have been done for all composites below 2<sup>64</sup> and composites number with two or three prime divisors under 2<sup>80</sup>.[^o15] Chen and Greene[^o16][^o17] have constructed a set *S* of 1248 primes such that, among the nearly 2<sup>1248</sup> products of distinct primes in *S*, there may be about 740 counterexamples.

## The danger of relying only on Fermat tests {#The_danger_of_relying_only_on_Fermat_tests}

There is significant overlap among the lists of pseudoprimes to different bases.

Choose a base *a*. If *n* is a pseudoprime to base *a*, then *n* is likely to be one of those few numbers that is a pseudoprime to many bases.[^o19]

For example, *n* = 341 is a pseudoprime to base 2. It follows from Theorem 1 on page 1392 of[^o4] that there are 100 values of *a* (mod 341) for which 341 is a pseudoprime base *a*. (The first ten such *a* are 1, 2, 4, 8, 15, 16, 23, 27, 29, and 30). The proportion of such *a* compared to *n* is usually much smaller.

Therefore, if *n* is a pseudoprime to base *a*, then *n* is more likely than average to be a pseudoprime to some other base. For example, there are 21853 pseudoprimes to base 2 up to 25·10<sup>9</sup>. This is only about two out of every million odd integers in this range. However:

- 4709 of these 21853 numbers (over 21 percent) are also pseudoprimes to base 3;
- 2522 of *these* 4709 numbers (over 53 percent) are pseudoprimes to bases 2, 3, and 5;
- 1770 of *these* 2522 numbers (over 70 percent) are pseudoprimes to bases 2, 3, 5, and 7.

The number 29341 is the smallest pseudoprime to bases 2 through 12. All of this suggests that probable prime tests to different bases are not independent of each other, so that performing Fermat probable prime tests to more and more bases will give diminishing returns. On the other hand, the calculations in and the calculations up to 2<sup>64</sup> mentioned above suggest that Fermat and Lucas probable prime tests *are* independent, so that a *combination* of these types of tests would make a powerful primality test, especially if the *strong* forms of the tests are used.

Note that a number that is pseudoprime to all prime bases 2, ..., *p* is also pseudoprime to all bases that are [p-smooth](wikipedia://en/1035039).

There is also overlap among *strong* pseudoprimes to different bases. For example, 1373653 is the smallest strong pseudoprime to bases 2 through 4, and 3215031751 is the smallest strong pseudoprime to bases 2 through 10. Arnault [^o20] gives a 397-digit [Carmichael number](wikipedia://en/7723) *N* that is a *strong* pseudoprime to all *prime* bases less than 307. Because this *N* is a Carmichael number, *N* is also a (not necessarily strong) pseudoprime to all bases less than *p*, where *p* is the 131-digit smallest prime factor of *N*. A quick calculation shows that *N* is *not* a Lucas probable prime when *D*, *P*, and *Q* are chosen by the method described above, so this number would be correctly determined by the Baillie–PSW test to be composite.

## Applications of combined Fermat and Lucas primality tests {#Applications_of_combined_Fermat_and_Lucas_primality_tests}

The following computer algebra systems and software packages use some version of the Baillie–PSW primality test.

[Maple](https://en.wikipedia.org/wiki/Maple_%28software%29)'s `isprime` function,[^o22] [Mathematica](https://en.wikipedia.org/wiki/Mathematica)'s `PrimeQ` function (that already uses 2020's version of Baillie–PSW),[^o23] [PARI/GP](https://en.wikipedia.org/wiki/PARI/GP)'s `isprime` and `ispseudoprime` functions,[^o24] and [SageMath](https://en.wikipedia.org/wiki/SageMath)'s `is_pseudoprime` function[^o25] all use a combination of a Fermat strong probable prime test and a Lucas test. [Maxima](https://en.wikipedia.org/wiki/Maxima_%28software%29)'s `primep` function uses such a test for numbers greater than 341550071728321.[^o26]

The [FLINT](wikipedia://en/16415701) library has functions `n_is_probabprime` and `n_is_probabprime_BPSW` that use a combined test, as well as other functions that perform Fermat and Lucas tests separately.[^o27]

The `BigInteger` class in standard versions of [Java](https://en.wikipedia.org/wiki/Java_%28software_platform%29) and in open-source implementations like [OpenJDK](https://en.wikipedia.org/wiki/OpenJDK) has a method called `isProbablePrime`. This method does one or more Miller–Rabin tests with random bases. If *n*, the number being tested, has 100 bits or more, this method also does a *non-strong* Lucas test that checks whether *U<sub>n+1</sub>* is 0 (mod *n*).[^o28][^o29] The use of random bases in the Miller–Rabin tests has an advantage and a drawback compared to doing a single base 2 test as specified in the Baillie–PSW test. The advantage is that, with random bases, one can get a bound on the probability that *n* is composite. The drawback is that, unlike the Baillie–PSW test, one cannot say with certainty that if *n* is less than some fixed bound such as 2<sup>64</sup>, then *n* is prime.

In [Perl](https://en.wikipedia.org/wiki/Perl), the `Math::Primality`[^o30] and `Math::Prime::Util`[^o31][^o32] modules have functions to perform the strong Baillie–PSW test as well as separate functions for strong pseudoprime and strong Lucas tests. In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), the `NZMATH`[^o33] library has the strong pseudoprime and Lucas tests, but does not have a combined function. The [SymPy](https://en.wikipedia.org/wiki/SymPy)[^o34] library does implement this.

As of 6.2.0, [GNU Multiple Precision Arithmetic Library](https://en.wikipedia.org/wiki/GNU_Multiple_Precision_Arithmetic_Library)'s `mpz_probab_prime_p` function uses a Baillie-PSW test and a Miller–Rabin test; previous versions did not make use of Baillie–PSW and instead performed 24 more rounds of Miller-Rabin.[^o35] [Magma](https://en.wikipedia.org/wiki/Magma_computer_algebra_system)'s `IsProbablePrime` and `IsProbablyPrime` functions use 20 Miller–Rabin tests for numbers > 34·10<sup>13</sup>, but do not combine them with a Lucas probable prime test.[^o36]

Cryptographic libraries often have prime-testing functions. Albrecht et al. discuss the tests used in these libraries. Some use a combined Fermat and Lucas test; many do not.[^o37] For some of the latter, Albrecht, et al. were able to construct composite numbers that the libraries declared to be prime.
