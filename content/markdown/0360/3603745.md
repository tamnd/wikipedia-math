# Vertex configuration

::: {#o1 .subject cue=lead name="Vertex configuration"}

In [geometry](wikipedia://en/18973446), a **vertex configuration** is a shorthand notation for representing a [polyhedron](wikipedia://en/23470) or [tiling](wikipedia://en/321671) as the sequence of [faces](wikipedia://en/149926) around a [vertex](wikipedia://en/11308417). It has variously been called a **vertex description**,[^o2][^o3][^o4] **vertex type**,[^o5][^o6] **vertex symbol**,[^o7][^o8] **vertex arrangement**,[^o9] **vertex pattern**,[^o10] **face-vector,**[^o11] **vertex sequence.**[^o12] It is also called a **Cundy and Rollett symbol** for its usage for the [Archimedean solids](wikipedia://en/1847) in their 1952 book *[Mathematical Models](wikipedia://en/65273997)*.[^o13][^o14] For [uniform polyhedra](wikipedia://en/2537223), there is only one vertex type and therefore the vertex configuration fully defines the polyhedron. ([Chiral](wikipedia://en/1170160) polyhedra exist in mirror-image pairs with the same vertex configuration.)

:::

For example, "$3.5.3.5$" indicates a vertex belonging to 4 faces, alternating [triangles](wikipedia://en/30654) and [pentagons](wikipedia://en/20741014). This vertex configuration defines the [vertex-transitive](https://en.wikipedia.org/wiki/Vertex-transitive) [icosidodecahedron](wikipedia://en/15023). The notation is cyclic and therefore is equivalent with different starting points, so $3.5.3.5$ is the same as $5.3.5.3.$ The order is important, so $3.3.5.5$ is different from $3.5.3.5$ (the first has two triangles followed by two pentagons). Repeated elements can be collected as exponents so this example is also represented as $(3.5)^{2}$.

::: {#o16 .definition kind=definition/notation cue=heading name="Notation"}

A vertex configuration is written as one or more numbers separated by either dots or commas. Each number represents the number of sides in each face that meets at each vertex. An [icosidodecahedron](wikipedia://en/15023) is denoted as $3.5.3.5$ because there are four faces at each vertex, alternating between [triangles](wikipedia://en/30654) (with 3 sides) and [pentagons](wikipedia://en/20741014) (with 5 sides). This can also be written as $(3.5)^{2}$.

The vertex configuration can also be considered an expansive form of the simple [Schläfli symbol](wikipedia://en/489394) for [regular polyhedra](wikipedia://en/23905). The Schläfli notation has the form $\{p,q\}$, where $p$ is the number of sides in each face and $q$ is the number of faces that meet at each vertex. Hence, the Schläfli notation $\{p,q\}$ can be written as $p.p.p\bullet\bullet\bullet$ (where $p$ appears $q$ times), or simply $p^{q}$.

This notation applies to polygonal tilings as well as polyhedra. A planar vertex configuration denotes a uniform tiling just like a nonplanar vertex configuration denotes a uniform polyhedron.

The notation is ambiguous for [chiral](wikipedia://en/1170160) forms. For example, the [snub cube](wikipedia://en/180249) has clockwise and counterclockwise forms which are identical across mirror images. Both have a $3.3.3.3.4$ vertex configuration.

:::

## Star polygons {#Star_polygons}

The notation also applies for nonconvex regular faces, the [star polygons](wikipedia://en/313303). For example, a [pentagram](wikipedia://en/197544) has the symbol {5/2}, meaning it has 5 sides going around the centre twice.

For example, there are 4 regular star polyhedra with regular polygon or star polygon vertex figures. The [small stellated dodecahedron](wikipedia://en/3029843) has the [Schläfli symbol](wikipedia://en/489394) of {5/2,5} which expands to an explicit vertex configuration 5/2.5/2.5/2.5/2.5/2 or combined as (5/2)<sup>5</sup>. The [great stellated dodecahedron](wikipedia://en/3029878), {5/2,3} has a triangular vertex figure and configuration (5/2.5/2.5/2) or (5/2)<sup>3</sup>. The [great dodecahedron](wikipedia://en/2860441), {5,5/2} has a pentagrammic vertex figure, with *vertex configuration* is (5.5.5.5.5)/2 or (5<sup>5</sup>)/2. A [great icosahedron](wikipedia://en/3029898), {3,5/2} also has a pentagrammic vertex figure, with vertex configuration (3.3.3.3.3)/2 or (3<sup>5</sup>)/2.

## Inverted polygons {#Inverted_polygons}

Faces on a vertex figure are considered to progress in one direction. Some uniform polyhedra have vertex figures with inversions where the faces progress retrograde. A vertex figure represents this in the [star polygon](wikipedia://en/313303) notation of sides *p/q* such that *p*\<2*q*, where *p* is the number of sides and *q* the number of turns around a circle. For example, "3/2" means a triangle that has vertices that go around twice, which is the same as backwards once. Similarly "5/3" is a backwards pentagram 5/2.

## All uniform vertex configurations of regular convex polygons {#All_uniform_vertex_configurations_of_regular_convex_polygons}

[Semiregular polyhedra](wikipedia://en/1548894) have vertex configurations with positive [angle defect](https://en.wikipedia.org/wiki/Defect_%28geometry%29).

NOTE: The vertex figure can represent a regular or semiregular tiling on the plane if its defect is zero. It can represent a tiling of the hyperbolic plane if its defect is negative.

For uniform polyhedra, the angle defect can be used to compute the number of vertices. Descartes' theorem states that all the angle defects in a topological sphere must sum to 4*π* radians or 720 degrees.

Since uniform polyhedra have all identical vertices, this relation allows us to compute the number of vertices, which is 4*π*/*defect* or 720/*defect*.

Example: A [truncated cube](wikipedia://en/280529) $3.8.8$ has an angle defect of 30 degrees. Therefore, it has $720/30 = 24$ vertices.

In particular it follows that $\{a,b\}$ has the following number of vertices:

$$\frac{4}{2 - b(1 -2/a)}$$

Every enumerated vertex configuration potentially uniquely defines a semiregular polyhedron. However, not all configurations are possible.

Topological requirements limit existence. Specifically $p.q.r$ implies that a $p$-gon is surrounded by alternating $q$-gons and $r$-gons, so either $p$ is even or $q$ equals $r$. Similarly $q$ is even or $p$ equals $r$, and $r$ is even or $p$ equals $q$. Therefore, potentially possible triples are:

|---|---|---|---|---|
| $q = 3$ (∴ $p = r$) | $3.3.3$ |  |  |  |
| $q = 4$ | $3.4.4$ | $4.4.n$ ($n > 2$) |  |  |
| $q = 5$ (∴ $p = r$) |  |  | $5.5.5$ |  |
| $q = 6$ | $3.6.6$ | $4.6.6 4.6.8 4.6.10 4.6.12$ | $5.6.6$ | $6.6.6$ |
| $q = 8$ | $3.8.8$ | $4.8.8$ |  |  |

## Face configuration {#Face_configuration}

*Image: Rhombic dodecahedron v3434.png.* [Rhombic dodecahedron](wikipedia://en/607631)

The uniform dual or [Catalan solids](wikipedia://en/564393), including the [bipyramids](wikipedia://en/4153) and [trapezohedra](https://en.wikipedia.org/wiki/Trapezohedra), are *vertically-regular* ([face-transitive](https://en.wikipedia.org/wiki/Face-transitive)) and so they can be identified by a similar notation which is sometimes called **face configuration**.[^o28] Cundy and Rollett prefixed these dual symbols by a *V*. In contrast, *[Tilings and patterns](wikipedia://en/76301624)* uses square brackets around the symbol for isohedral tilings.

This notation represents a sequential count of the number of faces that exist at each [vertex](wikipedia://en/11308417) around a [face](wikipedia://en/149926). For example, V3.4.3.4 or V(3.4)<sup>2</sup> represents the [rhombic dodecahedron](wikipedia://en/607631) which is face-transitive: every face is a [rhombus](wikipedia://en/183884), and alternating vertices of the rhombus contain 3 or 4 faces each.

:::
