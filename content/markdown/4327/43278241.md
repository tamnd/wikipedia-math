# Knuth's Simpath algorithm

::: {#o1 .subject cue=lead name="Knuth's Simpath algorithm"}

**Simpath** is an [algorithm](wikipedia://en/775) introduced by [Donald Knuth](wikipedia://en/8095) that constructs a [zero-suppressed decision diagram](https://en.wikipedia.org/wiki/Zero-suppressed_decision_diagram) (ZDD) representing all simple paths between two vertices in a given graph.[^o2][^o3]

:::
