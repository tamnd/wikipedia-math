# Cryptomator

::: {#o4 .subject cue=lead name="Cryptomator"}

**Cryptomator** is [open source](https://en.wikipedia.org/wiki/Open_source) [encryption software](wikipedia://en/2285143) that provides encryption for [cloud drives](https://en.wikipedia.org/wiki/Cloud_storage). It provides transparent, [client-side encryption](wikipedia://en/46420317) for [personal cloud](https://en.wikipedia.org/wiki/Personal_cloud) storage. Cryptomator encrypts each file separately and then allows the user to sync files with a cloud or local storage of choice.[^o5] It is available for all major operating system including Android, iOS, Windows, Mac, Linux.[^o6]

:::

Cryptomator uses [AES-256](https://en.wikipedia.org/wiki/AES-256) standard encryption and [WebDAV](https://en.wikipedia.org/wiki/WebDAV) and relies on its open-source model for software verifiability, trust and bug fixing.[^o7] The software encrypts each file individually.[^o8]

## History {#History}

In 2017, [Cure53](https://en.wikipedia.org/wiki/Cure53) audited the software.[^o10][^o11] Cryptomator was lauded for its high degree of robustness in cryptographic implementation, but criticized use of AES in insecure [ECB mode](https://en.wikipedia.org/wiki/ECB_mode). Tobias Hagemann, however, said this was a [false positive](https://en.wikipedia.org/wiki/False_positive).[^o11]

In December 2021, Cryptomator 2.0 was released for iOS, which was rewritten in [Swift](https://en.wikipedia.org/wiki/Swift_%28programming_language%29) and integrated with the native iOS [Files](https://en.wikipedia.org/wiki/Files_%28Apple%29) app.[^o12][^o13]

In January 2022, an update was released for a bug that leaked file path to Apple, because of the integration with [Apple's file](https://en.wikipedia.org/wiki/Apple_File_System) and use of File Provider Extension API.[^o14]

## Reception {#Reception}

Cryptomator received the [CeBIT innovation award](https://en.wikipedia.org/wiki/CeBIT) in 2016 for "Usable Security and Privacy".[^o16][^o17]
