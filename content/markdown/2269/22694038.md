# Null semigroup

::: {#o1 .subject cue=lead name="Null semigroup"}

In [mathematics](wikipedia://en/18831), a **null semigroup** (also called a **zero semigroup**) is a [semigroup](wikipedia://en/27799) with an [absorbing element](wikipedia://en/14206224), called [zero](wikipedia://en/27799#Identity_and_zero), in which the product of any two elements is zero.[^o2] If every element of a semigroup is a [left zero](https://en.wikipedia.org/wiki/Left_zero) then the semigroup is called a **left zero semigroup**; a **right zero semigroup** is defined analogously.[^o3]

:::

According to [A. H. Clifford](https://en.wikipedia.org/wiki/A._H._Clifford) and [G. B. Preston](https://en.wikipedia.org/wiki/G._B._Preston), "In spite of their triviality, these semigroups arise naturally in a number of investigations."[^o2]

## Null semigroup {#Null_semigroup}

Let *S* be a semigroup with zero element 0. Then *S* is called a *null semigroup* if *xy* = 0 for all *x* and *y* in *S*.

### Cayley table for a null semigroup {#Cayley_table_for_a_null_semigroup}

Let *S* = {0, *a*, *b*, *c*} be (the underlying set of) a null semigroup. Then the [Cayley table](wikipedia://en/1802723) for *S* is as given below:

::: {#o6 .table cue=table}

|  | 0 | *a* | *b* | *c* |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 |
| *a* | 0 | 0 | 0 | 0 |
| *b* | 0 | 0 | 0 | 0 |
| *c* | 0 | 0 | 0 | 0 |

:::

## Left zero semigroup {#Left_zero_semigroup}

A semigroup in which every element is a [left zero](https://en.wikipedia.org/wiki/Left_zero) element is called a **left zero semigroup**. Thus a semigroup *S* is a left zero semigroup if *xy* = *x* for all *x* and *y* in *S*.

### Cayley table for a left zero semigroup {#Cayley_table_for_a_left_zero_semigroup}

Let *S* = {*a*, *b*, *c*} be a left zero semigroup. Then the Cayley table for *S* is as given below:

::: {#o9 .table cue=table}

|  | *a* | *b* | *c* |
|---|---|---|---|
| *a* | *a* | *a* | *a* |
| *b* | *b* | *b* | *b* |
| *c* | *c* | *c* | *c* |

:::

## Right zero semigroup {#Right_zero_semigroup}

A semigroup in which every element is a [right zero](https://en.wikipedia.org/wiki/Right_zero) element is called a **right zero semigroup**. Thus a semigroup *S* is a right zero semigroup if *xy* = *y* for all *x* and *y* in *S*.

### Cayley table for a right zero semigroup {#Cayley_table_for_a_right_zero_semigroup}

Let *S* = {*a*, *b*, *c*} be a right zero semigroup. Then the Cayley table for *S* is as given below:

::: {#o12 .table cue=table}

|  | *a* | *b* | *c* |
|---|---|---|---|
| *a* | *a* | *b* | *c* |
| *b* | *a* | *b* | *c* |
| *c* | *a* | *b* | *c* |

:::

## Properties {#Properties}

A non-trivial null (left/right zero) semigroup does not contain an [identity element](wikipedia://en/14962). It follows that the only null (left/right zero) [monoid](wikipedia://en/19652) is the trivial monoid. On the other hand, a null (left/right zero) semigroup with an identity *adjoined* is called a find-unique (find-first/find-last) monoid.

The class of null semigroups is:

- closed under taking [subsemigroups](wikipedia://en/27799#Subsemigroups_and_ideals)
- closed under taking [quotient](wikipedia://en/27799#Quotients_and_divisions) of subsemigroup
- closed under arbitrary [direct products](wikipedia://en/8887#Direct_product_in_universal_algebra).

It follows that the class of null (left/right zero) semigroups is a [variety of universal algebra](wikipedia://en/1021753), and thus a [variety of finite semigroups](wikipedia://en/57151064). The variety of finite null semigroups is defined by the identity *ab* = *cd*.
