# Odlyzko–Schönhage algorithm

::: {#o1 .subject cue=lead name="Odlyzko–Schönhage algorithm"}

In mathematics, the **Odlyzko–Schönhage algorithm** is a fast [algorithm](wikipedia://en/775) for evaluating the [Riemann zeta function](wikipedia://en/25809) at many points, introduced by (). The main point is the use of the [fast Fourier transform](wikipedia://en/11512) to speed up the evaluation of a finite [Dirichlet series](wikipedia://en/393258) of length *N* at O(*N*) equally spaced values from O(*N*<sup>2</sup>) to O(*N*<sup>1+ε</sup>) steps (at the cost of storing O(*N*<sup>1+ε</sup>) intermediate values). The [Riemann–Siegel formula](wikipedia://en/21485619) used for calculating the Riemann zeta function with imaginary part *T* uses a finite Dirichlet series with about *N* = *T*<sup>1/2</sup> terms, so when finding about *N* values of the Riemann zeta function it is sped up by a factor of about *T*<sup>1/2</sup>. This reduces the time to find the zeros of the zeta function with imaginary part at most *T* from about *T*<sup>3/2+ε</sup> steps to about *T*<sup>1+ε</sup> steps.

:::

The algorithm can be used not just for the Riemann zeta function, but also for many other functions given by Dirichlet series.

The algorithm was used by (Gourdon 2004) to verify the [Riemann hypothesis](wikipedia://en/19344125) for the first 10<sup>13</sup> zeros of the zeta function.
