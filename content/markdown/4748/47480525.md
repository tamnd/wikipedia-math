# Distinguishing coloring

::: {#o1 .subject cue=lead name="Distinguishing coloring"}

*Image: Distinguishing 4-hypercube.svg.* Distinguishing coloring of a 4-[hypercube graph](wikipedia://en/6706815)

In [graph theory](wikipedia://en/12401), a **distinguishing coloring** or **distinguishing labeling** of a graph is an [assignment of colors](wikipedia://en/426743) or labels to the [vertices](wikipedia://en/638899) of the graph that destroys all of the nontrivial [symmetries of the graph](wikipedia://en/15094186). The coloring does not need to be a [proper coloring](wikipedia://en/426743): adjacent vertices are allowed to be given the same color. For the colored graph, there should not exist any one-to-one mapping of the vertices to themselves that preserves both adjacency and coloring. The minimum number of colors in a distinguishing coloring is called the **distinguishing number** of the graph.

:::

Distinguishing colorings and distinguishing numbers were introduced by (Albertson Collins 1996), who provided the following motivating example, based on a puzzle previously formulated by Frank Rubin: "Suppose you have a ring of keys to different doors; each key only opens one door, but they all look indistinguishable to you. How few colors do you need, in order to color the handles of the keys in such a way that you can uniquely identify each key?"[^o3] This example is solved by using a distinguishing coloring for a [cycle graph](wikipedia://en/878962). With such a coloring, each key will be uniquely identified by its color and the sequence of colors surrounding it.[^o4]

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

*Image: Asym-graph.PNG.* Eight asymmetric graphs, each given a distinguishing coloring with only one color (red)

A graph has distinguishing number one [if and only if](wikipedia://en/14922) it is [asymmetric](wikipedia://en/20249418).[^o7] For instance, the [Frucht graph](wikipedia://en/23784721) has a distinguishing coloring with only one color.

In a [complete graph](wikipedia://en/85816), the only distinguishing colorings assign a different color to each vertex. For, if two vertices were assigned the same color, there would exist a symmetry that swapped those two vertices, leaving the rest in place. Therefore, the distinguishing number of the complete graph $K_{n}$ is $n$. However, the graph obtained from $K_{n}$ by attaching a degree-one vertex to each vertex of $K_{n}$ has a significantly smaller distinguishing number, despite having the same symmetry group: it has a distinguishing coloring with $\lceil\sqrt{n}\rceil$ colors, obtained by using a different [ordered pair](wikipedia://en/22362) of colors for each pair of a vertex $K_{n}$ and its attached neighbor.[^o4]

*Image: 6-key distinguishing coloring.jpg.* A distinguishing coloring of a ring of six keys, using two colors (red and unpainted)

For a [cycle graph](wikipedia://en/878962) of three, four, or five vertices, three colors are needed to construct a distinguishing coloring. For instance, every two-coloring of a five-cycle has a [reflection symmetry](wikipedia://en/1390873). In each of these cycles, assigning a unique color to each of two adjacent vertices and using the third color for all remaining vertices results in a three-color distinguishing coloring. However, cycles of six or more vertices have distinguishing colorings with only two colors. That is, Frank Rubin's keyring puzzle requires three colors for rings of three, four or five keys, but only two colors for six or more keys or for two keys.[^o4] For instance, in the ring of six keys shown, each key can be distinguished by its color and by the length or lengths of the adjacent blocks of oppositely-colored keys: there is only one key for each combination of key color and adjacent block lengths.

[Hypercube graphs](wikipedia://en/6706815) exhibit a similar phenomenon to cycle graphs. The two- and three-dimensional hypercube graphs (the 4-cycle and the graph of a cube, respectively) have distinguishing number three. However, every hypercube graph of higher dimension has distinguishing number only two.[^o8]

The [Petersen graph](wikipedia://en/194926) has distinguishing number 3. However other than this graph and the complete graphs, all [Kneser graphs](wikipedia://en/2724154) have distinguishing number 2.[^o9] Similarly, among the [generalized Petersen graphs](wikipedia://en/23716451), only the Petersen graph itself and the graph of the cube have distinguishing number 3; the rest have distinguishing number 2.[^o10]

:::

## Computational complexity {#Computational_complexity}

The distinguishing numbers of [trees](wikipedia://en/48560), [planar graphs](wikipedia://en/24314), and [interval graphs](wikipedia://en/363423) can be computed in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).[^o12][^o13][^o14]

The exact complexity of computing distinguishing numbers is unclear, because it is closely related to the still-unknown complexity of [graph isomorphism](wikipedia://en/247577). However, it has been shown to belong to the complexity class [AM](wikipedia://en/663203).[^o15] Additionally, testing whether the distinguishing chromatic number is at most three is [NP-hard](https://en.wikipedia.org/wiki/NP-hard),[^o14] and testing whether it is at most two is "at least as hard as graph automorphism, but no harder than graph isomorphism".[^o16]

## Additional properties {#Additional_properties}

A coloring of a given graph is distinguishing for that graph if and only if it is distinguishing for the [complement graph](wikipedia://en/1175649). Therefore, every graph has the same distinguishing number as its complement.[^o4]

For every graph $G$, the distinguishing number of $G$ is at most proportional to the [logarithm](wikipedia://en/17860) of the number of [automorphisms](wikipedia://en/15094186) of $G$. If the automorphisms form a nontrivial [abelian group](wikipedia://en/2974), the distinguishing number is two, and if it forms a [dihedral group](wikipedia://en/100267) then the distinguishing number is at most three.[^o4]

For every [finite group](wikipedia://en/323707), there exists a graph with that group as its group of automorphisms, with distinguishing number two.[^o4] This result extends [Frucht's theorem](wikipedia://en/26259599) that every finite group can be realized as the group of symmetries of a graph.

::: {#o19 .statement kind=statement/generalization cue=heading name="Variations"}

## Variations {#Variations}

A **proper distinguishing coloring** is a distinguishing coloring that is also a proper coloring: each two adjacent vertices have different colors. The minimum number of colors in a proper distinguishing coloring of a graph is called the **distinguishing chromatic number** of the graph.[^o20]

:::
