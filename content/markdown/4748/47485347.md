# Embedded analytics

::: {#o1 .subject cue=lead name="Embedded analytics"}

**Embedded analytics** enables organisations to integrate [analytics](wikipedia://en/487132) capabilities into their own, often [software as a service](https://en.wikipedia.org/wiki/Software_as_a_service), applications, portals, or websites. This differs from [embedded software](https://en.wikipedia.org/wiki/Embedded_software) and [web analytics](wikipedia://en/2475872) (also commonly known as product analytics).

:::

This integration typically provides contextual insights, quickly, easily and conveniently accessible since these insights should be present on the web page right next to the other, operational, parts of the host application. Insights are provided through interactive [data visualisations](wikipedia://en/3461736), such as [charts](https://en.wikipedia.org/wiki/Chart), [diagrams](https://en.wikipedia.org/wiki/Diagram), filters, gauges, maps and [tables](https://en.wikipedia.org/wiki/Table_%28information%29) often in combination as [dashboards](https://en.wikipedia.org/wiki/Dashboard_%28business%29) embedded within the system. This setup enables easier, in-depth data analysis without the need to switch and log in between multiple applications. Embedded analytics is also known as customer facing analytics.

Embedded analytics is the integration of analytic capabilities into a host, typically browser-based, [business-to-business](https://en.wikipedia.org/wiki/Business-to-business), [software as a service](https://en.wikipedia.org/wiki/Software_as_a_service), application. These analytic capabilities would typically be relevant and contextual to the use-case of the host application.

## History {#History}

The term "embedded analytics" was first used by Howard Dresner: consultant, author, former [Gartner](https://en.wikipedia.org/wiki/Gartner) analyst and inventor of the term "business intelligence" said Howard Dresner while he was working for [Hyperion Solutions](https://en.wikipedia.org/wiki/Hyperion_Solutions), a company that Oracle bought in 2007. Oracle started then to use the term "embedded analytics" at their press release for Oracle Rapid Planning on 2009 .

## Considerations with embedded analytics {#Considerations_with_embedded_analytics}

When evaluating embedding analytics, consideration would normally be given to integration at various levels, these would likely include: [security](https://en.wikipedia.org/wiki/Role-based_access_control) integration, [data](https://en.wikipedia.org/wiki/Data) integration, [application logic](https://en.wikipedia.org/wiki/Business_logic) integration, [business rules](https://en.wikipedia.org/wiki/Business_rule) integration, and [user experience](https://en.wikipedia.org/wiki/User_experience) integration.

*Image: Embedded Analytics.jpg.* The spectrum of options for embedded analytics

This is in contrast to traditional BI, which expects users to leave their workflow applications to look at data insights in a separate set of tools. This immediacy makes embedded analytics much more intuitive and likely to be valued by users. A December 2016 report from Nucleus Research found that using BI tools, which require toggling between applications, can take up as much as 1–2 hours of an employee's time each week, whereas embedded analytics eliminate the need to toggle between apps.
