# Centered polygonal number

::: {#o1 .subject cue=lead name="Centered polygonal number"}

*Image: visual\_proof\_centered\_polygonal\_numbers.svg.* [Proof without words](wikipedia://en/18045517) that each centered *k*-gonal number is *k* times the previous triangular number, plus 1

In [mathematics](wikipedia://en/18831), the **centered polygonal numbers** are a class of series of [figurate numbers](wikipedia://en/325260), each formed by a central dot, surrounded by polygonal layers of dots with a constant number of sides. Each side of a polygonal layer contains one more dot than each side in the previous layer; so starting from the second polygonal layer, each layer of a centered *k*-gonal number contains *k* more dots than the previous layer.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Each centered *k*-gonal number in the series is *k* times the previous [triangular number](wikipedia://en/213915), plus 1. This can be formalized by the expression $\frac{kn(n+1)}{2} +1$, where *n* is the series rank, starting with 0 for the initial 1. For example, each centered square number in the series is four times the previous triangular number, plus 1. This can be formalized by the expression $\frac{4n(n+1)}{2} +1$.

These series consist of the

- [centered triangular numbers](wikipedia://en/857110) 1, 4, 10, 19, 31, 46, 64, 85, 109, 136, 166, 199, ... (),
- [centered square numbers](wikipedia://en/723297) 1, 5, 13, 25, 41, 61, 85, 113, 145, 181, 221, 265, ... (), which are exactly the sum of consecutive squares, i.e., *n*<sup>2</sup> + (*n* − 1)<sup>2</sup>.
- [centered pentagonal numbers](https://en.wikipedia.org/wiki/Centered_pentagonal_number) 1, 6, 16, 31, 51, 76, 106, 141, 181, 226, 276, 331, ... (),
- [centered hexagonal numbers](wikipedia://en/497485) 1, 7, 19, 37, 61, 91, 127, 169, 217, 271, 331, 397, ... (), which are exactly the difference of consecutive cubes, i.e. *n*<sup>3</sup> − (*n* − 1)<sup>3</sup>,
- [centered heptagonal numbers](wikipedia://en/1215833) 1, 8, 22, 43, 71, 106, 148, 197, 253, 316, 386, 463, ... (),
- [centered octagonal numbers](wikipedia://en/1215851) 1, 9, 25, 49, 81, 121, 169, 225, 289, 361, 441, 529, ... (), which are exactly the [odd](https://en.wikipedia.org/wiki/Odd_number) [squares](wikipedia://en/213919),
- [centered nonagonal numbers](wikipedia://en/1216013) 1, 10, 28, 55, 91, 136, 190, 253, 325, 406, 496, 595, ... (), which include all even [perfect numbers](wikipedia://en/23670) except 6,
- [centered decagonal numbers](wikipedia://en/1216087) 1, 11, 31, 61, 101, 151, 211, 281, 361, 451, 551, 661, ... (),
- centered hendecagonal numbers 1, 12, 34, 67, 111, 166, 232, 309, 397, 496, 606, 727, ... (),
- centered dodecagonal numbers 1, 13, 37, 73, 121, 181, 253, 337, 433, 541, 661, 793, ... (), which are also the [star numbers](wikipedia://en/699772),

and so on.

## Formulas {#Formulas}

As can be seen in the above diagrams, the *n*th centered *k*-gonal number can be obtained by placing *k* copies of the (*n*−1)th triangular number around a central point; therefore, the *n*th centered *k*-gonal number is equal to

$$C_{k,n} =\frac{kn}{2}(n-1)+1.$$

The difference of the *n*-th and the (*n*+1)-th consecutive centered *k*-gonal numbers is *k*(2*n*+1).

The *n*-th centered *k*-gonal number is equal to the *n*-th regular *k*-gonal number plus (*n*−1)<sup>2</sup>.

Just as is the case with regular polygonal numbers, the first centered *k*-gonal number is 1. Thus, for any *k*, 1 is both *k*-gonal and centered *k*-gonal. The next number to be both *k*-gonal and centered *k*-gonal can be found using the formula:

$$\frac{k^2}{2}(k-1)+1$$

which tells us that 10 is both triangular and centered triangular, 25 is both square and centered square, etc.

Whereas a [prime number](wikipedia://en/23666) *p* cannot be a [polygonal number](wikipedia://en/213996) (except the trivial case, i.e. each *p* is the second *p*-gonal number), many centered polygonal numbers are primes. In fact, if *k* ≥ 3, *k* ≠ 8, *k* ≠ 9, then there are infinitely many centered *k*-gonal numbers which are primes (assuming the [Bunyakovsky conjecture](wikipedia://en/12511846)). Since all [centered octagonal numbers](wikipedia://en/1215851) are also [square numbers](wikipedia://en/213919), and all [centered nonagonal numbers](wikipedia://en/1216013) are also [triangular numbers](wikipedia://en/213915) (and not equal to 3), thus both of them cannot be prime numbers.

:::

## Sum of reciprocals {#Sum_of_reciprocals}

The [sum](wikipedia://en/246160) of [reciprocals](wikipedia://en/229940) for the centered *k*-gonal numbers is[^o9]

$\frac{2\pi}{k\sqrt{1-\frac{8}{k}}}\tan\left(\frac{\pi}{2}\sqrt{1-\frac{8}{k}}\right)$, if *k* ≠ 8

$\frac{\pi^2}{8}$, if *k* = 8
