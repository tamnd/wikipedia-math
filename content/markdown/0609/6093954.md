# Bernays–Schönfinkel class

::: {#o1 .subject cue=lead name="Bernays–Schönfinkel class"}

The **Bernays–Schönfinkel class** (also known as **Bernays–Schönfinkel–Ramsey class**) of formulas, named after [Paul Bernays](wikipedia://en/2556580), [Moses Schönfinkel](wikipedia://en/767234) and [Frank P. Ramsey](wikipedia://en/238285), is a fragment of [first-order logic](wikipedia://en/10983) formulas where [satisfiability](wikipedia://en/23401166) is [decidable](wikipedia://en/913118).

:::

It is the set of sentences that, when written in [prenex normal form](wikipedia://en/421068), have an $\exists^*\forall^*$ quantifier prefix and do not contain any [function symbols](wikipedia://en/174908).

Ramsey proved that, if $\phi$ is a formula in the Bernays–Schönfinkel class with one free variable, then either $\{x \in \mathbb{N} : \phi(x)\}$ is finite, or $\{x \in \mathbb{N} : \neg \phi(x)\}$ is finite.[^o2]

This class of logic formulas is also sometimes referred as **effectively propositional** (**EPR**) since it can be effectively translated into [propositional logic](wikipedia://en/18154) formulas by a process of grounding or instantiation.

The satisfiability problem for this class is [NEXPTIME](wikipedia://en/663657)-complete.[^o3]

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

Efficient algorithms for deciding satisfiability of EPR have been integrated into [SMT solvers](https://en.wikipedia.org/wiki/Satisfiability_modulo_theories).[^o6]

:::
