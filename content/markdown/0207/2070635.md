# Q-theta function

::: {#o1 .subject cue=lead name="Q-theta function"}

In [mathematics](wikipedia://en/18831), the ***q*-theta function** (or modified Jacobi theta function) is a type of [*q*-series](https://en.wikipedia.org/wiki/Q-series) which is used to define [elliptic hypergeometric series](wikipedia://en/19953217). [^o2][^o3] It is given by

:::

$$\theta(z;q):=\prod_{n=0}^\infty (1-q^nz)\left(1-q^{n+1}/z\right)$$

where one takes 0 ≤ |*q*| \< 1. It obeys the identities

$$\theta(z;q)=\theta\left(\frac{q}{z};q\right)=-z\theta\left(\frac{1}{z};q\right).$$

It may also be expressed as:

$$\theta(z;q)=(z;q)_\infty (q/z;q)_\infty$$

where $(\cdot \cdot )_\infty$ is the [q-Pochhammer symbol](wikipedia://en/11149717).
