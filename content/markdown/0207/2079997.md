# Statistica

::: {#o2 .subject cue=lead name="Statistica"}

**Statistica** is an advanced [analytics](wikipedia://en/487132) software package originally developed by [StatSoft](https://en.wikipedia.org/wiki/StatSoft) and currently maintained by [TIBCO Software](https://en.wikipedia.org/wiki/TIBCO_Software) Inc.[^o3] Statistica provides [data analysis](wikipedia://en/2720954), [data management](https://en.wikipedia.org/wiki/Data_management), [statistics](wikipedia://en/26685), [data mining](wikipedia://en/42253), [machine learning](wikipedia://en/233488), [text analytics](wikipedia://en/318439) and [data visualization](https://en.wikipedia.org/wiki/Data_visualization) procedures.

:::

## Overview {#Overview}

Statistica is a [suite](https://en.wikipedia.org/wiki/Application_suite) of analytics software originally developed by [StatSoft](https://en.wikipedia.org/wiki/StatSoft) and acquired by Dell in March 2014. The software includes an array of [data analysis](wikipedia://en/2720954), [data management](https://en.wikipedia.org/wiki/Data_management), [data visualization](https://en.wikipedia.org/wiki/Data_visualization), and [data mining](wikipedia://en/42253) procedures; as well as a variety of [predictive modeling](https://en.wikipedia.org/wiki/Predictive_modeling), clustering, classification, and exploratory techniques.[^o5] Additional techniques are available through integration with the free, open source [R](wikipedia://en/376707) programming environment.[^o6][^o7] Different packages of analytical techniques are available in six product lines.[^o8]

## History {#History}

Statistica originally derived from a set of software packages and add-ons that were initially developed during the mid-1980s by [StatSoft](https://en.wikipedia.org/wiki/StatSoft). Following the 1986 release of Complete Statistical System (CSS) and the 1988 release of Macintosh Statistical System (MacSS), the first [DOS](https://en.wikipedia.org/wiki/MS-DOS) version (trademarked in capitals as STATISTICA) was released in 1991. In 1992, the [Macintosh](https://en.wikipedia.org/wiki/Macintosh) version of Statistica was released.

Statistica 5.0 was released in 1995. It ran on both the new [32-bit](https://en.wikipedia.org/wiki/32-bit) [Windows 95](https://en.wikipedia.org/wiki/Windows_95)/[NT](https://en.wikipedia.org/wiki/Windows_NT) and the previous [16-bit](https://en.wikipedia.org/wiki/16-bit) version, [Windows 3.1](https://en.wikipedia.org/wiki/Windows_3.1). It featured many new statistics and graphics procedures, a word-processor-style output editor (combining tables and graphs), and a built-in development environment that enabled the user to easily design new procedures (e.g., via the included Statistica Basic language) and integrate them with the Statistica system.

Statistica 5.1 was released in 1996 followed by Statistica CA '97 and Statistica '98 editions.

In 2001, Statistica 6 was based on the [COM](https://en.wikipedia.org/wiki/COM_%28hardware_interface%29) architecture and it included multithreading and support for [distributed computing](https://en.wikipedia.org/wiki/Distributed_computing).

Statistica 9 was released in 2009, supporting 32-bit and [64-bit computing](https://en.wikipedia.org/wiki/64-bit_computing).

Statistica 10 was released in November 2010. This release featured further performance optimizations for the 64-bit CPU architecture, as well as [multithreading](https://en.wikipedia.org/wiki/Multithreading_%28computer_architecture%29) technologies, integration with Microsoft [SharePoint](https://en.wikipedia.org/wiki/SharePoint), [Microsoft Office](https://en.wikipedia.org/wiki/Microsoft_Office) 2010 and other applications, the ability to generate [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) and [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29) code, and other [GUI](https://en.wikipedia.org/wiki/GUI) and [kernel](https://en.wikipedia.org/wiki/Kernel_%28operating_system%29) improvements.[^o5]

Statistica 12 was released in April 2013 and features a new GUI, performance improvements when handling large amounts of data, a new visual analytic workspace, a new database query tool as well as several analytics enhancements.[^o5]

[Localized versions](https://en.wikipedia.org/wiki/Internationalization_and_localization) of Statistica (including the entire family of products) are available in Chinese (both [Traditional](https://en.wikipedia.org/wiki/Traditional_Chinese) and [Simplified](https://en.wikipedia.org/wiki/Simplified_Chinese)), Czech, English, French, German, Italian, Japanese, Polish, Russian, and Spanish. Documentation is available in Arabic, Chinese, Czech, English, French, German, Hungarian, Italian, Japanese, Korean, Polish, Portuguese, Russian, Spanish, and other languages.

### Acquisition history {#Acquisition_history}

Statistica was acquired by [Dell](https://en.wikipedia.org/wiki/Dell) in March 2014.[^o11] In November 2016, Dell sold off several pieces of its software group, and [Francisco Partners](https://en.wikipedia.org/wiki/Francisco_Partners) and [Elliott Management Corporation](https://en.wikipedia.org/wiki/Elliott_Management_Corporation) acquired Statistica as part of its purchase of [Quest Software](https://en.wikipedia.org/wiki/Quest_Software) from Dell.[^o12] On May 15, 2017, [TIBCO Software](https://en.wikipedia.org/wiki/TIBCO_Software) Inc. announced it entered into an agreement to acquire Statistica.[^o3]

## Graphics {#Graphics}

Statistica includes analytic and exploratory graphs in addition to standard 2- and 3-dimensional graphs. Brushing actions (interactive labeling, marking, and data exclusion) allow for investigation of [outliers](https://en.wikipedia.org/wiki/Outliers) and exploratory data analysis.

## User interface {#User_interface}

Operation of the software typically involves loading a table of data and applying statistical functions from [pull-down menus](https://en.wikipedia.org/wiki/Pull-down_menu) or (in versions starting from 9.0) from the [ribbon bar](https://en.wikipedia.org/wiki/Ribbon_%28computing%29). The menus then prompt for the variables to be included and the type of analysis required. It is not necessary to type command prompts. Each analysis may include graphical or tabular output and is stored in a separate workbook.
