# Rabinovich–Fabrikant equations

::: {#o1 .subject cue=lead name="Rabinovich–Fabrikant equations"}

*Image: A third numerical solution to the Rabinovich-Fabrikant system.jpg.* Trajectory of a solution with parameter values $\alpha=0.05$ and $\gamma=0.1$ and initial conditions $x_0=0.1$, $y_0=-0.1$, and $z_0=0.1$, using the default ODE solver in Mathematica. *Image: Another numerical solution to the Rabinovich-Fabrikant system.jpg.* A chaotic attractor found with parameter values $\alpha=1.1$ and $\gamma=0.87$ and initial conditions $x_0=-1$, $y_0=-0$, and $z_0=0.5$, using the default ODE solver in Mathematica. Colors vary from orange-red to magenta-red with time. Notice that colors do not follow any order, reflecting the chaotic dynamics of the solution.

The **Rabinovich–Fabrikant equations** are a set of three coupled [ordinary differential equations](https://en.wikipedia.org/wiki/Ordinary_differential_equations) exhibiting [chaotic](wikipedia://en/6295) behaviour for certain values of the [parameters](wikipedia://en/25065). They are named after [Mikhail Rabinovich](https://en.wikipedia.org/wiki/Mikhail_Rabinovich) and [Anatoly Fabrikant](https://en.wikipedia.org/wiki/Anatoly_Fabrikant), who described them in 1979.

:::

## System description {#System_description}

The equations are:[^o10]

$$\dot{x} = y (z - 1 + x^2) + \gamma x \,$$

$$\dot{y} = x (3z + 1 - x^2) + \gamma y \,$$

$$\dot{z} = -2z (\alpha + xy), \,$$

where *α*, *γ* are constants that control the evolution of the system. For some values of *α* and *γ*, the system is chaotic, but for others it tends to a stable periodic orbit.

Danca and Chen[^o13] note that the Rabinovich–Fabrikant system is difficult to analyse (due to the presence of quadratic and cubic terms) and that different attractors can be obtained for the same parameters by using different step sizes in the integration, see on the right an example of a solution obtained by two different solvers for the same parameter values and initial conditions. Also, recently, a [hidden attractor](https://en.wikipedia.org/wiki/Hidden_oscillation) was discovered in the Rabinovich–Fabrikant system.[^o3]

### Equilibrium points {#Equilibrium_points}

*Image: Rabinovich-Fabrikant equilibrium point existence regions.svg.* Graph of the regions for which equilibrium points $\tilde{\mathbf{x}}_{1,2,3,4}$ exist.

The Rabinovich–Fabrikant system has five hyperbolic [equilibrium points](https://en.wikipedia.org/wiki/Equilibrium_points), one at the origin and four dependent on the system parameters *α* and *γ*:[^o13]

$$\tilde{\mathbf{x}}_0 = (0,0,0)$$

$$\tilde{\mathbf{x}}_{1,2} = \left( \pm q_-, \mp \frac{\alpha}{q_-}, 1- \left(1-\frac{\gamma}{\alpha}\right)q_-^2 \right)$$

$$\tilde{\mathbf{x}}_{3,4} = \left( \pm q_+, \mp \frac{\alpha}{q_+}, 1- \left(1-\frac{\gamma}{\alpha}\right)q_+^2 \right)$$

where

$$q_{\pm} = \sqrt{ \frac{ 1 \pm \sqrt{ 1- \gamma \alpha \left( 1- \frac{3 \gamma}{4\alpha} \right) } }{2 \left(1- \frac{3\gamma}{4\alpha}\right) }}$$

These equilibrium points only exist for certain values of *α* and *γ* > 0.

### γ = 0.87, α = 1.1 {#γ_=_0.87,_α_=_1.1}

An example of chaotic behaviour is obtained for *γ* = 0.87 and *α* = 1.1 with initial conditions of (−1, 0, 0.5),[^o11] see trajectory on the right. The [correlation dimension](wikipedia://en/2075246) was found to be 2.19 ± 0.01.[^o9] The Lyapunov exponents, *λ* are approximately 0.1981, 0, −0.6581 and the [Kaplan–Yorke dimension](https://en.wikipedia.org/wiki/Kaplan–Yorke_dimension), *D*<sub>KY</sub> ≈ 2.3010[^o11]

### γ = 0.1 {#γ_=_0.1}

Danca and Romera[^o12] showed that for *γ* = 0.1, the system is chaotic for *α* = 0.98, but progresses on a stable [limit cycle](wikipedia://en/452950) for *α* = 0.14.
