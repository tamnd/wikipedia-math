# Baire space (set theory)

::: {#o1 .subject cue=lead name="Baire space"}

In [set theory](wikipedia://en/27553), the **Baire space** is the [set](wikipedia://en/26691) of all [infinite sequences](https://en.wikipedia.org/wiki/Infinite_sequence) of [natural numbers](wikipedia://en/21474). This space is commonly used in [descriptive set theory](wikipedia://en/396619), to the extent that its elements are often called "reals". It is denoted by $\mathbb{N}^{\mathbb{N}}$, or $^\omega\!\omega$, or sometimes by $\omega^\omega$ (not to be confused with the countable [ordinal](wikipedia://en/26547932) obtained by [ordinal exponentiation](wikipedia://en/2139226#Exponentiation)).

:::

The Baire space is defined to be the [product](wikipedia://en/24104095) of [countably infinitely](wikipedia://en/6026) many copies of the set of natural numbers, and is given the [product topology](wikipedia://en/24910) (where each copy of the set of natural numbers is given the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology)). The Baire space is often represented using the [tree](wikipedia://en/2190732) of [finite sequences](https://en.wikipedia.org/wiki/Finite_sequence) of natural numbers. It can be contrasted with the [Cantor space](wikipedia://en/352376), the set of infinite sequences of [binary digits](https://en.wikipedia.org/wiki/Binary_digit).

The Baire space should not be confused with the general concept of *a* [Baire space](wikipedia://en/200550), which is a certain kind of topological space.

## Topology and trees {#Topology_and_trees}

The [product topology](wikipedia://en/24910) used to define the Baire space can be described in one of two equivalent ways: in terms of a [basis](wikipedia://en/59220) consisting of cylinder sets, or of a basis of trees.

### Cylinder set basis {#Cylinder_set_basis}

The [basic open sets](wikipedia://en/59220) of the product topology are [cylinder sets](wikipedia://en/2613658). These can be characterized as:

If any finite set *I* of natural number coordinates is selected, and for each *i* in *I* a particular natural number value *v*<sub>*i*</sub> is selected, then the set of all infinite sequences of natural numbers that have value *v*<sub>*i*</sub> at position *i* is a basic open set. Every open set is the union of a [countable](wikipedia://en/6026) collection of these basic open sets.

Using more formal notation, one can define the individual cylinders as

$$C_n[v]= \{(a_1,a_2,\cdots) \in \omega^\omega : a_n = v \}$$

for a fixed integer location *n* and integer value *v*. The cylinders are then the generators for the cylinder sets: the cylinder sets consist of all intersections of a finite number of cylinders. That is, given any finite set of natural number coordinates $I\subseteq\omega$ and corresponding natural number values $v_i$ for each $i\in I$, one considers the intersection

$$\bigcap_{i\in I} C_i[v_i].$$

This intersection is called a *[cylinder set](wikipedia://en/2613658)*, and the set of all such cylinder sets is a basis for the [product topology](wikipedia://en/24910). Every open set is the union of (a countable collection of) such cylinder sets.

### Tree basis {#Tree_basis}

An alternative basis for the product topology can be given in terms of trees. The basic open sets can be characterized as:

If a finite sequence of natural numbers {*w*<sub>*i*</sub> : *i* \< *n*} is selected, then the set of all infinite sequences of natural numbers that have value *w*<sub>*i*</sub> at position *i* for all *i* \< *n* is a basic open set. Every open set is a countable union of a collection of these.

Thus a basic open set in the Baire space is the set of all infinite sequences of natural numbers extending a common finite initial segment *σ*. This leads to a representation of the Baire space as the set of all infinite paths passing through the full tree ω<sup>\<ω</sup> of finite sequences of natural numbers [ordered by extension](https://en.wikipedia.org/wiki/Shortlex). Each finite initial segment *σ* is a **node** of the tree of finite sequences. Each open set is determined by a countable union *S* of nodes of that tree. A point in Baire space is in an open set if and only if its path goes through one of the nodes in its determining union. Conversely, each open set corresponds to a subtree *S* of the full tree ω<sup>\<ω</sup>, consisting of at most a countable number of nodes.

The representation of the Baire space as paths through a tree also gives a characterization of closed sets as complements of subtrees defining the open sets. Every point in Baire space passes through a sequence of nodes of ω<sup>\<ω</sup>. Closed sets are complements of open sets. This defines a subtree *T* of the full tree ω<sup>\<ω</sup>, in which the nodes of *S* defining the open set are missing. The subtree *T* consists of all nodes in ω<sup>\<ω</sup> that are not in *S*. This subtree *T* defines a closed subset *C* of Baire space such that any point *x* is in *C* if and only if *x* is a path through *T*. Conversely, for any closed subset *C* of Baire space there is a subtree *T* which consists of all of ω<sup>\<ω</sup> with at most a countable number of nodes removed.

Since the full tree ω<sup>\<ω</sup> is itself countable, this implies the closed sets correspond to any subtree of the full tree, including finite subtrees. Thus, the topology consists of [clopen sets](wikipedia://en/233398). This implies that the Baire space is [zero-dimensional](https://en.wikipedia.org/wiki/Zero-dimensional) with respect to the small [inductive dimension](wikipedia://en/3173612) (as are all spaces whose base consists of clopen sets.)

The above definitions of open and closed sets provide the first two sets $\mathbf{\Sigma}^0_1$ and $\mathbf{\Pi}^0_1$ of the [boldface](wikipedia://en/9304834) [Borel hierarchy](wikipedia://en/5539282).

### Box topology {#Box_topology}

Cartesian products also have an alternate topology, the [box topology](wikipedia://en/954333). This topology is much finer than the product topology as it does not limit the indicator set $I=\{i \in \omega \}$ to be finite. Conventionally, Baire space does not refer to this topology; it only refers to the product topology.

## Weight {#Weight}

The above definition of the Baire space generalizes to one where the elements $x_i$ of the countably infinite sequence $(x_1,x_2,\cdots)$ are chosen from a set $D(\kappa)$ of [cardinality](wikipedia://en/6174) $\kappa$. Such a space is called a **Baire space of weight $\kappa$** and can be denoted as $B(\kappa)$.[^o7] With this definition, the Baire spaces of finite weight would correspond to the [Cantor space](wikipedia://en/352376). The first Baire space of infinite weight is then $B(\aleph_0)$; it is homeomorphic to $\omega^\omega$ defined above.

## Metric {#Metric}

Given two sequences $x=(x_1,x_2,\cdots)$ and $y=(y_1,y_2,\cdots)$, a [metric](wikipedia://en/20018) $\rho(x,y)$ may be defined as $\rho(x,y)=1/k$ where $k$ is the least integer such that $x_k\ne y_k.$ With this metric, the basic open sets of the tree basis are [balls](wikipedia://en/160556) of radius $1/k$.

A [metric space](wikipedia://en/20018) $X$ [embeds](wikipedia://en/52119) into the Baire space $B(\kappa)$ if and only if $X$ poses a [base](wikipedia://en/59220) $\mathcal{B}$ of clopen sets, where the cardinality of $\mathcal{B}$ is less than or equal to $\kappa$.[^o9][^o10]

## Properties {#Properties}

The Baire space has the following properties:

1. It is a [perfect](wikipedia://en/5075551) [Polish space](wikipedia://en/396622), which means it is a [completely metrizable](wikipedia://en/7832) [second countable](https://en.wikipedia.org/wiki/Second_countable) space with no [isolated points](wikipedia://en/390557). As such, it has the same [cardinality](wikipedia://en/6174) as the real line and is a [Baire space](wikipedia://en/200550) in the topological sense of the term.
1. It is [zero-dimensional](https://en.wikipedia.org/wiki/Zero-dimensional) and [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected).
1. It is not [locally compact](https://en.wikipedia.org/wiki/Locally_compact).
1. It is universal for Polish spaces in the sense that it can be mapped [continuously](wikipedia://en/6122) onto any non-empty Polish space. Moreover, any Polish space has a [dense](wikipedia://en/23523594) [G<sub>δ</sub>](wikipedia://en/252076) subspace [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to a G<sub>δ</sub> subspace of the Baire space.
1. The Baire space is homeomorphic to the product of any finite or countable number of copies of itself.
1. It is the [automorphism group](wikipedia://en/56661772) of a countably infinite [saturated model](wikipedia://en/535836) $M$ of some [complete theory](wikipedia://en/10086335) $T$.

:::

## Relation to the real line {#Relation_to_the_real_line}

The Baire space is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to the set of [irrational numbers](wikipedia://en/20647689) when they are given the [subspace topology](wikipedia://en/910926) inherited from the real line. A homeomorphism between the Baire space and the irrationals can be constructed using [continued fractions](wikipedia://en/739199): given a sequence of [natural numbers](wikipedia://en/21474) $(a_0,a_1,a_2, \cdots)\in \mathbb{N}^\mathbb{N}$, we can assign a corresponding irrational number greater than 1 by

$$x = 1+a_0+\frac{1}{1+a_1+\frac{1}{1+a_2+\cdots}} = [1+a_0;1+a_1,1+a_2,\cdots].$$

The map $x \mapsto 1/x$ is another homeomorphism from $\mathbb{N}^\mathbb{N}$ to the irrationals in the open [unit interval](wikipedia://en/49324) $(0,1)$, and we can do the same for the negative irrationals. Thus, the irrationals are the [disjoint union](wikipedia://en/1564380) of four spaces homeomorphic to the Baire space and are therefore also homeomorphic to the Baire space.

From the point of view of [descriptive set theory](wikipedia://en/396619), Baire spaces are more flexible than the [real line](https://en.wikipedia.org/wiki/Real_line) in the following sense. Because the [real line](https://en.wikipedia.org/wiki/Real_line) is path-connected, so is every continuous image of a real line. In contrast, every [Polish space](wikipedia://en/396622) is the continuous image of Baire space. This difference makes the real line "slightly awkward to use", despite the focus of descriptive set theory on sets of reals. Instead, it is often possible to prove results about arbitrary Polish spaces by showing that these properties hold for Baire space and are preserved by [continuous functions](https://en.wikipedia.org/wiki/Continuous_functions).[^o14]

$\mathbb{N}^\mathbb{N}$ is also of some interest in [real analysis](wikipedia://en/26478), where it is considered as a [uniform space](wikipedia://en/32339). However, the uniform structures of $\mathbb{N}^\mathbb{N}$ and the irrationals are different: $\mathbb{N}^\mathbb{N}$ is [complete](https://en.wikipedia.org/wiki/Complete_space) in its usual metric while the irrationals are not.

## Shift operator {#Shift_operator}

The [shift operator](wikipedia://en/467384) on the Baire space, when mapped to the [unit interval](wikipedia://en/49324) of the [reals](https://en.wikipedia.org/wiki/Real_numbers), becomes the [Gauss–Kuzmin–Wirsing operator](wikipedia://en/1360654) $h(x) = 1/x - \lfloor 1/x \rfloor$. That is, given a [sequence](wikipedia://en/27838) $(a_1, a_2, \cdots)$, the shift operator *T* returns $T(a_1, a_2, \cdots)=(a_2, \cdots)$. Likewise, given the continued fraction $x=[a_1, a_2, \cdots]$, the Gauss map returns $h(x)=[a_2, \cdots]$. The corresponding operator for functions from Baire space to the complex plane is the [Gauss–Kuzmin–Wirsing operator](wikipedia://en/1360654); it is the [transfer operator](wikipedia://en/1346096) of the Gauss map.[^o16] That is, one considers maps $\omega^\omega \to \mathbb{C}$ from Baire space to the [complex plane](wikipedia://en/217628) $\mathbb{C}$. This space of maps inherits a topology from the product topology on Baire space; for example, one may consider functions having [uniform convergence](wikipedia://en/50652). The shift map, acting on this space of functions, is then the GKW operator.

The [Haar measure](wikipedia://en/40645) of the shift operator, that is, a function that is invariant under shifts, is given by the [Minkowski measure](https://en.wikipedia.org/wiki/Minkowski's_question_mark_function) $(...)'$. That is, one has that $(TE)' = E'$, where *T* is the shift [^o17] and *E* any [measurable subset](https://en.wikipedia.org/wiki/Measurable_set) of ω<sup>ω</sup>.
