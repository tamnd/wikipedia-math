# Set estimation

::: {#o1 .subject cue=lead name="Set estimation"}

In [statistics](wikipedia://en/26685), a [random vector](https://en.wikipedia.org/wiki/Random_vector) $x$ is classically represented by a [probability density function](wikipedia://en/43487). In a **set-membership approach** or **set estimation**, $x$ is represented by a set $X$ to which $x$ is assumed to belong. This means that the [support](wikipedia://en/381013) of the [probability distribution](wikipedia://en/23543) function of $x$ is included inside $X$. On the one hand, representing random vectors by sets makes it possible to provide fewer assumptions on the random variables (such as [independence](wikipedia://en/27593)) and dealing with [nonlinearities](https://en.wikipedia.org/wiki/Nonlinearity) is easier. On the other hand, a probability distribution function provides a more accurate information than a set enclosing its support.

:::

## Set-membership estimation {#Set-membership_estimation}

Set membership estimation (or *set estimation* for short) is an [estimation approach](wikipedia://en/1565926) which considers that measurements are represented by a set $Y$ (most of the time a box of $\mathbb{R}^m,$ where $m$ is the number of measurements) of the measurement space. If $p$ is the parameter vector and $f$ is the model function, then the set of all feasible parameter vectors is

$$P = P_0 \cap f^{-1}(Y) ,$$

where $P_{0}$ is the prior set for the parameters. Characterizing $P$ corresponds to a [set-inversion problem](wikipedia://en/39157279).[^o3]

## Resolution {#Resolution}

When $f$ is linear the feasible set $P$ can be described by [linear inequalities](wikipedia://en/19575563) and can be approximated using [linear programming](wikipedia://en/43730) techniques.[^o5]

When $f$ is nonlinear, the resolution can be performed using [interval analysis](wikipedia://en/2176160). The [feasible set](wikipedia://en/9157119) $P$ is then approximated by an inner and an outer [subpavings](wikipedia://en/39210398). The main limitation of the method is its exponential complexity with respect to the number of parameters.[^o6]

## Example {#Example}

Consider the following model

$$\phi(p_1,p_2,t) = (t p_1)^2+t p_2^2+\sin(p_1 + t p_2),$$

where $p_{1}$ and $p_{2}$ are the two parameters to be estimated.

*Image: Wiki estim data.png.* Figure 1. Bounded-error data

Assume that at times $t_{1} = -1$, $t_{2} = 1$, $t_{3} = 2$, the following interval measurements have been collected:

$$\begin{array}{rclr} [y_1] &=& [-4, & -2], \\ {}[y_2] &=& [\quad\! 4, & 9], \\ {}[y_3] &=& [\quad\! 7, & 11], \end{array}$$

as illustrated by Figure 1. The corresponding measurement set (here a box) is

$$Y=[y_1] \times [y_2] \times [y_3].$$

The model function is defined by

$$f(p_1,p_2) = \begin{bmatrix} p_1^2-p_2^2+\sin(p_1-p_2) \\ p_1^2+p_2^2+\sin(p_1+p_2) \\ (2p_1)^2+2 p_2^2+\sin(p_1+2 p_2) \end{bmatrix}$$

The components of $f$ are obtained using the model for each time measurement. After solving the set inversion problem, we get the approximation depicted on Figure 2. Red boxes are inside the feasible set $P$ and blue boxes are outside $P$.

## Recursive case {#Recursive_case}

Set estimation can be used to estimate the state of a system described by state equations using a recursive implementation. When the system is linear, the corresponding feasible set for the state vector can be described by polytopes or by ellipsoids [^o10] .[^o11] When the system is nonlinear, the set can be enclosed by subpavings. [^o12]

## Robust case {#Robust_case}

When outliers occur, the set estimation method generally returns an empty set. This is due to the fact that the intersection between sets of parameter vectors that are consistent with the $i$th data bar is empty. To be robust with respect to outliers, we generally characterize the set of parameter vectors that are consistent with all data bars except $q$ of them. This is possible using the notion of $q$-[relaxed intersection](wikipedia://en/39414235).
