# Core-compact space

::: {#o1 .subject cue=lead name="Core-compact space"}

In [general topology](wikipedia://en/178649) and related branches of [mathematics](wikipedia://en/18831), a **core-compact** [topological space](wikipedia://en/30450) $X$ is a [topological space](wikipedia://en/30450) whose [partially ordered set](wikipedia://en/23572) of [open subsets](wikipedia://en/39358) is a [continuous poset](wikipedia://en/71369165).[^o2] Equivalently, $X$ is core-compact if it is [exponentiable](wikipedia://en/2237858) in the [category](wikipedia://en/53759) [Top](wikipedia://en/435051) of topological spaces.[^o2][^o3] This means that the functor $X\times - : \bf{Top} \to \bf{Top}$ has a [right adjoint](https://en.wikipedia.org/wiki/Right_adjoint). Equivalently, for each topological space $Y$, there exists a topology on the set of continuous functions $\mathcal{C}(X,Y)$ such that [function application](wikipedia://en/20576545) $X \times \mathcal{C}(X, Y) \to Y$ is continuous, and each continuous map $X\times Z \to Y$ may be curried to a continuous map $Z \to \mathcal{C}(X,Y)$. Note that this is the [Compact-open topology](wikipedia://en/726335) if (and only if)[^o5] $X$ is [locally compact](https://en.wikipedia.org/wiki/Locally_compact). (In this article locally compact means that every point has a neighborhood base of compact neighborhoods; this is definition (3) in the linked article.)

:::

Another equivalent concrete definition is that every open neighborhood $U$ of a point $x$ contains an open neighborhood $V$ of $x$ that is way-below $U$; $V$ is way-below (or relatively compact in) $U$ if and only if every open cover containing $U$ contains a finite subcover of $V$.[^o2] As a result, every locally compact space is core-compact. For [Hausdorff spaces](wikipedia://en/13637) (or more generally, [sober spaces](wikipedia://en/602490)[^o6]), core-compact space is equivalent to locally compact. In this sense the definition is a slight weakening of the definition of a locally compact space in the non-Hausdorff case.
