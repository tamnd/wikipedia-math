# Fractional graph isomorphism

::: {#o1 .subject cue=lead name="Fractional graph isomorphism"}

In [graph theory](wikipedia://en/12401), a **fractional isomorphism of [graphs](wikipedia://en/325806)** whose [adjacency matrices](wikipedia://en/244463) are denoted *A* and *B* is a [doubly stochastic matrix](wikipedia://en/2906180) *D* such that *DA* = *BD*. If the doubly stochastic matrix is a [permutation matrix](wikipedia://en/238849), then it constitutes a [graph isomorphism](wikipedia://en/247577). Fractional isomorphism is the coarsest of several different [relaxations](wikipedia://en/6347835) of [graph isomorphism](wikipedia://en/247577).

:::

## Computational complexity {#Computational_complexity}

Whereas the [graph isomorphism problem](wikipedia://en/1950766) is not known to be decidable in [polynomial time](wikipedia://en/405944#Polynomial_time) and not known to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete), the fractional graph isomorphism problem is decidable in polynomial time because it is a special case of the [linear programming](wikipedia://en/43730) problem, for which there is an efficient solution. More precisely, the conditions on matrix *D* that it be doubly stochastic and that *DA* = *BD* can be expressed as linear inequalities and equalities, respectively, so any such matrix *D* is a [feasible solution](wikipedia://en/58654129) of a linear program.

## Equivalence to coarsest equitable partition {#Equivalence_to_coarsest_equitable_partition}

Two graphs are also fractionally isomorphic if they have a common coarsest [equitable partition](wikipedia://en/82834746). A [partition](wikipedia://en/340240) of a graph is a collection of pairwise disjoint sets of vertices whose union is the vertex set of the graph. A partition is equitable if for any pair of vertices *u* and *v* in the same block of the partition and any block *B* of the partition, both *u* and *v* have the same number of neighbors in *B*. An equitable partition *P* is coarsest if each block in any other equitable partition is a subset of a block in *P*. Two coarsest equitable partitions *P* and *Q* are common if there is a [bijection](wikipedia://en/3942) *f* from the blocks of *P* to the blocks of *Q* such for any blocks *B* and *C* in *P*, the number of neighbors in *C* of any vertex in *B* equals the number of neighbors in *f(C)* of any vertex in *f(B)*.
