# Protocol composition logic

::: {#o1 .subject cue=lead name="Protocol composition logic"}

**Protocol Composition Logic** is a [formal method](https://en.wikipedia.org/wiki/Formal_methods) that can be used for proving security properties of [cryptographic protocols](wikipedia://en/591994) that use [symmetric-key](wikipedia://en/53042) and [public-key cryptography](wikipedia://en/24222). PCL is designed around a [process calculus](wikipedia://en/853240) with actions for various possible protocol steps (e.g. generating random numbers, performing encryption, decryption and [digital signature](wikipedia://en/59644) operations as well as sending and receiving messages).[^o2]

:::

Some problems with the logic have been found, implying that some currently claimed results cannot be proven within the logic.[^o3]
