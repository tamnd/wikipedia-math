# Affine root system

*Image: G2 affine chamber.svg.* The affine root system of type *G*<sub>2</sub>.

::: {#o1 .subject cue=lead name="Affine root system"}

In mathematics, an **affine root system** is a [root system](wikipedia://en/277087) of [affine-linear functions](https://en.wikipedia.org/wiki/Affine-linear_function) on a [Euclidean space](wikipedia://en/9697). They are used in the classification of [affine Lie algebras](wikipedia://en/1350865) and superalgebras, and semi-simple *p*-adic [algebraic groups](wikipedia://en/247924) and correspond to families of [Macdonald polynomials](wikipedia://en/10354285). The reduced affine root systems were used by Kac and Moody in their work on [Kac–Moody algebras](wikipedia://en/1146292). Possibly non-reduced affine root systems were introduced and classified by (Macdonald 1972) and (Bruhat Tits 1972) (except that both these papers accidentally omitted the [Dynkin diagram](wikipedia://en/277109) node).

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *E* be an [affine space](wikipedia://en/298834) and *V* the [vector space](wikipedia://en/32370) of its translations. Recall that *V* acts faithfully and transitively on *E*. In particular, if $u,v \in E$, then it is well defined an element in *V* denoted as $u-v$ which is the only element *w* such that $v+w=u$.

Now suppose we have a scalar product $(\cdot,\cdot)$ on *V*. This defines a metric on *E* as $d(u,v)=\vert(u-v,u-v)\vert$.

Consider the vector space *F* of [affine-linear functions](https://en.wikipedia.org/wiki/Affine-linear_function) $f\colon E\longrightarrow \mathbb{R}$. Having fixed a $x_0\in E$, every element in *F* can be written as $f(x)=Df(x-x_0)+f(x_0)$ with $Df$ a linear function on *V* that doesn't depend on the choice of $x_0$.

Now the dual of *V* can be identified with *V* thanks to the chosen scalar product, and we can define a product on *F* as $(f,g)=(Df,Dg)$. Set $f^\vee =\frac{2f}{(f,f)}$ and $v^\vee =\frac{2v}{(v,v)}$ for any $f\in F$ and $v\in V$ respectively. The identification let us define a reflection $w_f$ over *E* in the following way:

$$w_f(x)=x-f^\vee(x)Df.$$

By transposition $w_f$ acts also on *F* as

$$w_f(g)=g-(f^\vee,g)f.$$

An *affine root system* is a subset $S\subset F$ such that: S spans *F* and its elements are non-constant.; $w_a(S)=S$ for every $a\in S$.; $(a,b^\vee)\in\mathbb{Z}$ for every $a,b\in S$. The elements of *S* are called *affine roots*. Denote with $w(S)$ the group generated by the $w_a$ with $a\in S$. We also ask $w(S)$ as a discrete group acts properly on *E*. This means that for any two compacts $K,H\subseteq E$ the elements of $w(S)$ such that $w(K)\cap H\neq \varnothing$ are a finite number.

:::

## Classification {#Classification}

The affine roots systems *A*<sub>1</sub> = *B*<sub>1</sub> = *B*${}^{\lor}_{1}$ = *C*<sub>1</sub> = *C*${}^{\lor}_{1}$ are the same, as are the pairs *B*<sub>2</sub> = *C*<sub>2</sub>, *B*${}^{\lor}_{2}$ = *C*${}^{\lor}_{2}$, and *A*<sub>3</sub> = *D*<sub>3</sub>.

The number of orbits given in the table is the number of orbits of simple roots under the [Weyl group](wikipedia://en/296332). In the [Dynkin diagrams](wikipedia://en/277109), the non-reduced simple roots α (with 2α a root) are colored green. The first Dynkin diagram in a series sometimes does not follow the same rule as the others.

## Applications {#Applications}

- (Macdonald 1972) showed that the affine root systems index [Macdonald identities](wikipedia://en/5027268)
- (Bruhat Tits 1972) used affine root systems to study *p*-adic algebraic groups.
- Reduced affine root systems classify affine [Kac–Moody algebras](wikipedia://en/1146292), while the non-reduced affine root systems correspond to affine [Lie superalgebras](wikipedia://en/297501).
- (Macdonald 2003) showed that affine roots systems index families of [Macdonald polynomials](wikipedia://en/10354285).

:::
