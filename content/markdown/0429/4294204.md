# MedCalc

**MedCalc** is a statistical software package designed for the biomedical sciences.[^o4][^o5][^o6] The first version of MedCalc, for [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS), was released in April 1993, then a [Windows](https://en.wikipedia.org/wiki/Windows) version in November 1996.

It has an integrated spreadsheet for data input and can import files in several formats ([Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [SPSS](wikipedia://en/179088), [CSV](https://en.wikipedia.org/wiki/Comma-separated_values)).

MedCalc includes basic parametric and [non-parametric](https://en.wikipedia.org/wiki/Non-parametric) statistical procedures and graphs such as [descriptive statistics](wikipedia://en/8187), [ANOVA](https://en.wikipedia.org/wiki/ANOVA), [Mann–Whitney test](wikipedia://en/433164), [Wilcoxon test](wikipedia://en/1954987), [χ<sup>2</sup> test](wikipedia://en/113424), [correlation](wikipedia://en/157057), [linear](wikipedia://en/48758386) as well as [non-linear regression](wikipedia://en/1045012), [logistic regression](wikipedia://en/226631), and multivariate statistics.[^o7]

Survival analysis includes Cox regression ([Proportional hazards model](wikipedia://en/5352267)) and [Kaplan–Meier](wikipedia://en/3168650) survival analysis.

Procedures for method evaluation and method comparison include [ROC curve](https://en.wikipedia.org/wiki/ROC_curve) analysis,[^o8] [Bland–Altman plot](wikipedia://en/3146632),[^o9] as well as [Deming](wikipedia://en/251549) and [Passing–Bablok regression](wikipedia://en/48751704).[^o10]

The software also includes reference interval estimation,[^o11] [meta-analysis](wikipedia://en/62329) and sample size calculations.

Version 15.2 introduced a user-interface in English, Chinese (simplified and traditional), French, German, Italian, Japanese, Korean, Polish, Portuguese (Brazilian), Russian and Spanish.
