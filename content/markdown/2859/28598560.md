# Financial calculator

*Image: Financial Calculator Hewlett-Packard HP-12C built from 1981, this item produced 1988 (edited to remove background, warmer colours).jpg.* HP-12C financial calculator including functions to calculate depreciation and [net present value](https://en.wikipedia.org/wiki/Net_present_value).

*Image: Backside of Financial Calculator Hewlett-Packard HP-12C built from 1981, this item produced 1988.jpg.* Backside of the above HP-12C with some use cases with the respective keys to be pressed for frequent tasks from the field of finance

::: {#o1 .subject cue=lead name="Financial calculator"}

A **financial calculator** or **business calculator** is an [electronic calculator](https://en.wikipedia.org/wiki/Electronic_calculator) that performs financial functions commonly needed in business and commerce communities[^o2] (simple interest, compound interest, cash flow, amortization, conversion, cost/sell/margin, depreciation etc.). It has standalone keys for many financial calculations and functions, making such calculations more direct than on standard calculators.[^o3] It may be user programmable, allowing the user to add functions that the manufacturer has not provided by default.[^o4]

:::

Examples of financial calculators are the [HP 12C](wikipedia://en/952015), [HP-10B](wikipedia://en/740851) and the [TI BA II](https://en.wikipedia.org/wiki/TI_BA_II).[^o5]

A wide number of graphing calculators, like the Casio FX-9860GII, the Texas Instruments TI-89 Titanium, and the Hewlett Packard HP 48gII include complex financial calculations, as well as [spreadsheet](https://en.wikipedia.org/wiki/Spreadsheet) applications such as [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [LibreOffice Calc](https://en.wikipedia.org/wiki/LibreOffice_Calc), and [Google Sheets](https://en.wikipedia.org/wiki/Google_Sheets).
