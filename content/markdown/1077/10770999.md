# Variable-order Markov model

::: {#o1 .subject cue=lead name="Variable-order Markov model"}

In the mathematical theory of [stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes), **variable-order Markov (VOM) models** are an important class of models that extend the well known [Markov chain](wikipedia://en/60876) models. In contrast to the Markov chain models, where each [random variable](wikipedia://en/25685) in a sequence with a [Markov property](wikipedia://en/306422) depends on a fixed number of random variables, in VOM models this number of conditioning random variables may vary based on the specific observed realization.

:::

This realization sequence is often called the *context*; therefore the VOM models are also called *context trees*.[^o2] VOM models are nicely rendered by colorized probabilistic suffix trees (PST).[^o3] The flexibility in the number of conditioning random variables turns out to be of real advantage for many applications, such as [statistical analysis](https://en.wikipedia.org/wiki/Statistical_analysis), [classification](wikipedia://en/1579244) and [prediction](wikipedia://en/246066).[^o4][^o5][^o6]

::: {#o8 .example cue=heading name="Example"}

## Example {#Example}

Consider for example a sequence of [random variables](wikipedia://en/25685), each of which takes a value from the ternary [alphabet](https://en.wikipedia.org/wiki/Alphabet) $\{a, b, c\}$. Specifically, consider the string constructed from infinite concatenations of the sub-string $aaabc$: $aaabcaaabcaaabcaaabc\ldots aaabc$.

The VOM model of maximal order 2 can approximate the above string using *only* the following five [conditional probability](wikipedia://en/24104134) components: $\Pr(a | aa) = 0.5$, $\Pr(b | aa) = 0.5$, $\Pr(c | b) = 1.0$, $\Pr(a | c)= 1.0$, $\Pr(a | ca) = 1.0$.

In this example, $\Pr(c | ab) = \Pr(c | b) = 1.0$; therefore, the shorter context $b$ is sufficient to determine the next character. Similarly, the VOM model of maximal order 3 can generate the string exactly using only five conditional probability components, which are all equal to 1.0.

To construct the [Markov chain](wikipedia://en/60876) of order 1 for the next character in that string, one must estimate the following 9 conditional probability components: $\Pr(a | a)$, $\Pr(a | b)$, $\Pr(a | c)$, $\Pr(b | a)$, $\Pr(b | b)$, $\Pr(b | c)$, $\Pr(c | a)$, $\Pr(c | b)$, $\Pr(c | c)$. To construct the Markov chain of order 2 for the next character, one must estimate 27 conditional probability components: $\Pr(a | aa)$, $\Pr(a | ab)$, $\ldots$, $\Pr(c | cc)$. And to construct the Markov chain of order three for the next character one must estimate the following 81 conditional probability components: $\Pr(a | aaa)$, $\Pr(a | aab)$, $\ldots$, $\Pr(c | ccc)$.

In practical settings there is seldom sufficient data to accurately estimate the [exponentially increasing](wikipedia://en/191933) number of conditional probability components as the order of the Markov chain increases.

The variable-order Markov model assumes that in realistic settings, there are certain realizations of states (represented by contexts) in which some past states are independent from the future states; accordingly, "a great reduction in the number of model parameters can be achieved."[^o2]

:::

::: {#o10 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $A$ be a state space (finite [alphabet](wikipedia://en/4292269)) of size $|A|$.

Consider a sequence with the [Markov property](wikipedia://en/306422) $x_1^{n}=x_1x_2\dots x_n$ of $n$ realizations of [random variables](wikipedia://en/25685), where $x_i\in A$ is the state (symbol) at position $i$ $\scriptstyle (1 \le i \le n)$, and the concatenation of states $x_i$ and $x_{i+1}$ is denoted by $x_ix_{i+1}$.

Given a training set of observed states, $x_1^{n}$, the construction algorithm of the VOM models[^o4][^o5][^o6] learns a model $P$ that provides a [probability](wikipedia://en/22934) assignment for each state in the sequence given its past (previously observed symbols) or future states.

Specifically, the learner generates a [conditional probability distribution](https://en.wikipedia.org/wiki/Conditional_distribution) $P(x_i\mid s)$ for a symbol $x_i \in A$ given a context $s\in A^*$, where the \* sign represents a sequence of states of any length, including the empty context.

VOM models attempt to estimate [conditional distributions](https://en.wikipedia.org/wiki/Conditional_distribution) of the form $P(x_i\mid s)$ where the context length $|s| \le D$ varies depending on the available statistics. In contrast, conventional [Markov models](wikipedia://en/60876) attempt to estimate these [conditional distributions](https://en.wikipedia.org/wiki/Conditional_distribution) by assuming a fixed contexts' length $|s| = D$ and, hence, can be considered as special cases of the VOM models.

Effectively, for a given training sequence, the VOM models are found to obtain better model parameterization than the fixed-order [Markov models](wikipedia://en/60876) that leads to a better [variance](wikipedia://en/32344)-bias tradeoff of the learned models.[^o4][^o5][^o6]

:::

## Application areas {#Application_areas}

Various efficient algorithms have been devised for estimating the parameters of the VOM model.[^o5]

VOM models have been successfully applied to areas such as [machine learning](wikipedia://en/233488), [information theory](wikipedia://en/14773) and [bioinformatics](wikipedia://en/4214), including specific applications such as [coding](https://en.wikipedia.org/wiki/Code) and [data compression](wikipedia://en/8013),[^o2] document compression,[^o5] classification and identification of [DNA](https://en.wikipedia.org/wiki/DNA) and [protein sequences](https://en.wikipedia.org/wiki/Protein),[^o12] <http://www.eng.tau.ac.il/~bengal/VOMBAT.pdf>[^o4] [statistical process control](wikipedia://en/593680),[^o6] [spam filtering](https://en.wikipedia.org/wiki/Spam_filtering),[^o13] [haplotyping](https://en.wikipedia.org/wiki/Haplotyping),[^o14] speech recognition,[^o15] [sequence analysis in social sciences](https://en.wikipedia.org/wiki/Sequence_analysis_in_social_sciences),[^o3] and others.
