# Expectation propagation

::: {#o1 .subject cue=lead name="Expectation propagation"}

**Expectation propagation (EP)** is a technique in [Bayesian machine learning](wikipedia://en/49571).[^o2]

:::

EP finds approximations to a [probability distribution](wikipedia://en/23543).[^o2] It uses an [iterative](https://en.wikipedia.org/wiki/Iterative) approach that uses the factorization structure of the target distribution.[^o2] It differs from other Bayesian approximation approaches such as [variational Bayesian methods](wikipedia://en/1208480).[^o2]

More specifically, suppose we wish to approximate an intractable probability distribution $p(\mathbf{x})$ with a tractable distribution $q(\mathbf{x})$. Expectation propagation achieves this approximation by minimizing the [Kullback–Leibler divergence](wikipedia://en/1115052) $\mathrm{KL}(p||q)$.[^o2] Variational Bayesian methods minimize $\mathrm{KL}(q||p)$ instead.[^o2]

If $q(\mathbf{x})$ is a Gaussian $\mathcal{N}(\mathbf{x}|\mu, \Sigma)$, then $\mathrm{KL}(p||q)$ is minimized with $\mu$ and $\Sigma$ being equal to the [mean](https://en.wikipedia.org/wiki/Mean) of $p(\mathbf{x})$ and the [covariance](wikipedia://en/157059) of $p(\mathbf{x})$, respectively; this is called [moment matching](wikipedia://en/2175504).[^o2]

::: {#o4 .application cue=heading name="Applications"}

## Applications {#Applications}

Expectation propagation via moment matching plays a vital role in approximation for [indicator functions](https://en.wikipedia.org/wiki/Indicator_functions) that appear when deriving the [message passing equations](wikipedia://en/800010) for [TrueSkill](https://en.wikipedia.org/wiki/TrueSkill).

:::
