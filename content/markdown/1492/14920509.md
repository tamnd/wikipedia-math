# Markov's principle

::: {#o1 .subject cue=lead name="Markov's principle"}

**Markov's principle** (also known as the **Leningrad principle**[^o2]), named after [Andrey Markov Jr](https://en.wikipedia.org/wiki/Andrey_Markov_%28Soviet_mathematician%29), is a conditional existence statement for which there are many equivalent formulations, as discussed below. The principle is [logically valid](wikipedia://en/21304742) [classically](wikipedia://en/55868), but not in [intuitionistic](wikipedia://en/169262) [constructive](https://en.wikipedia.org/wiki/Constructivism_%28mathematics%29) mathematics. However, many particular instances of it are nevertheless provable in a constructive context as well.

:::

## History {#History}

The principle was first studied and adopted by the Russian school of constructivism, together with [choice principles](wikipedia://en/441950) and often with a [realizability](wikipedia://en/11009758) perspective on the notion of mathematical function.

## In computability theory {#In_computability_theory}

In the language of [computability theory](wikipedia://en/155414), Markov's principle is a formal expression of the claim that if it is impossible that an algorithm does not terminate, then for some input it does terminate. This is equivalent to the claim that if a set and its complement are both [computably enumerable](https://en.wikipedia.org/wiki/Computably_enumerable), then the set is [decidable](https://en.wikipedia.org/wiki/Recursive_set). These statements are provable in classical logic.

## In intuitionistic logic {#In_intuitionistic_logic}

In [predicate logic](https://en.wikipedia.org/wiki/Predicate_logic), a predicate *P* over some domain is called *decidable* if for every *x* in the domain, either *P*(*x*) holds, or the negation of *P*(*x*) holds. This is not trivially true constructively.

Markov's principle then states: For a decidable predicate *P* over the [natural numbers](wikipedia://en/21474), if *P* cannot be false for all natural numbers *n*, then it is true for some *n*. Written using [quantifiers](wikipedia://en/43507260):

$$\Big(\forall n \big(P(n) \vee \neg P(n)\big) \wedge \neg \forall n\, \neg P(n)\Big) \rightarrow \exists n\, P(n)$$

### Markov's rule {#Markov's_rule}

Markov's rule is the formulation of Markov's principle as a rule. It states that $\exists n\;P(n)$ is derivable as soon as $\neg \neg \exists n\;P(n)$ is, for $P$ decidable. Formally,

$$\forall n \big(P(n)\lor \neg P(n)\big),\ \neg \neg \exists n\;P(n)\ \ \vdash\ \ \exists n\;P(n)$$

[Anne Troelstra](wikipedia://en/15067195)[^o7] proved that it is an [admissible rule](wikipedia://en/1151794) in [Heyting arithmetic](wikipedia://en/2545815). Later, the logician [Harvey Friedman](wikipedia://en/3038108) showed that Markov's rule is an admissible rule in [first-order intuitionistic logic](wikipedia://en/169262), [Heyting arithmetic](wikipedia://en/2545815), and various other intuitionistic theories,[^o8] using the [Friedman translation](wikipedia://en/21775342).

## In Heyting arithmetic {#In_Heyting_arithmetic}

Markov's principle is equivalent in the language of [arithmetic](wikipedia://en/2545815) to:

$$\neg \neg \exists n\;f(n)=0 \rightarrow \exists n\;f(n)=0$$

for $f$ a [total recursive function](wikipedia://en/1139338) on the natural numbers.

In the presence of the [Church's thesis principle](wikipedia://en/15756448), Markov's principle is equivalent to its form for [primitive recursive functions](https://en.wikipedia.org/wiki/Primitive_recursive_functions). Using [Kleene's T predicate](wikipedia://en/14103273), the latter may be expressed as double-negation elimination for $\exists w\; T_1(e, x, w)$, i.e.

$$\forall e\;\forall x\;\big(\neg \neg \exists w\; T_1(e, x, w) \rightarrow \exists w\; T_1(e, x, w)\big)$$

### Realizability {#Realizability}

If constructive arithmetic is translated using [realizability](wikipedia://en/11009758) into a classical meta-theory that proves the [$\omega$-consistency](wikipedia://en/4066001) of the relevant classical theory (for example, Peano arithmetic if we are studying [Heyting arithmetic](wikipedia://en/2545815)), then Markov's principle is justified: a realizer is the constant function that takes a realization that $P$ is not everywhere false to the [unbounded search](https://en.wikipedia.org/wiki/Unbounded_search) that successively checks if $P(0), P(1), P(2),\dots$ is true. If $P$ is not everywhere false, then by $\omega$-consistency there must be a term for which $P$ holds, and each term will be checked by the search eventually. If however $P$ does not hold anywhere, then the domain of the constant function must be empty, so although the search does not halt it still holds vacuously that the function is a realizer. By the Law of the Excluded Middle (in our classical metatheory), $P$ must either hold nowhere or not hold nowhere, therefore this constant function is a realizer.

If instead the realizability interpretation is used in a constructive meta-theory, then it is not justified. Indeed, for [first-order arithmetic](https://en.wikipedia.org/wiki/First-order_arithmetic), Markov's principle exactly captures the difference between a constructive and classical meta-theory. Specifically, a statement is provable in [Heyting arithmetic](wikipedia://en/2545815) with [extended Church's thesis](wikipedia://en/15756448) if and only if there is a number that provably realizes it in [Heyting arithmetic](wikipedia://en/2545815); and it is provable in [Heyting arithmetic](wikipedia://en/2545815) with [extended Church's thesis](wikipedia://en/15756448) *and Markov's principle* if and only if there is a number that provably realizes it in [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic).

## In constructive analysis {#In_constructive_analysis}

Markov's principle is equivalent, in the language of [real analysis](wikipedia://en/26478), to the following principles:

- For each [real number](wikipedia://en/20646438) *x*, if it is contradictory that *x* is equal to 0, then there exists a [rational number](wikipedia://en/19727024) *y* such that 0 \< *y* \< |*x*|, often expressed by saying that *x* is [apart](wikipedia://en/7844336) from, or constructively unequal to, 0.
- For each real number *x*, if it is contradictory that *x* is equal to 0, then there exists a real number *y* such that *xy* = 1.

Modified [realizability](wikipedia://en/11009758) does not justify Markov's principle, even if classical logic is used in the meta-theory: there is no realizer in the language of [simply typed lambda calculus](wikipedia://en/1986011) as this language is not [Turing-complete](https://en.wikipedia.org/wiki/Turing-complete) and arbitrary loops cannot be defined in it.

### Weak Markov's principle {#Weak_Markov's_principle}

The weak Markov's principle is a weaker form of the principle. It may be stated in the language of analysis, as a conditional statement for the positivity of a real number:

$$\forall (x\in\mathbb{R})\, \Big(\forall(y\in\mathbb{R}) \big(\neg\neg(0 < y) \lor \neg\neg(y < x)\big)\Big) \,\to\, (0 < x).$$

This form can be justified by [Brouwer's](wikipedia://en/172896) [continuity principles](https://en.wikipedia.org/wiki/Brouwer's_continuity_principles), whereas the stronger form contradicts them. Thus the weak Markov principle can be derived from intuitionistic, realizability, and classical reasoning, in each case for different reasons, but it is not valid in the general constructive sense of [Bishop](wikipedia://en/321995),[^o14] nor provable in the [set theory ${\mathsf {IZF}}$](wikipedia://en/5042360).

To understand what the principle is about, it helps to inspect a stronger statement. The following expresses that any real number $x$, such that no non-positive $y$ is not below it, is positive:

$$\nexists(y \le 0)\, x \le y \,\to\, (0 < x),$$

where $x \leq y$ denotes the negation of $y < x$. This is a stronger implication because the antecedent is looser. Note that here a logically positive statement is concluded from a logically negative one. It is implied by the weak Markov's principle when elevating the [De Morgan's law](https://en.wikipedia.org/wiki/De_Morgan%27s_laws#In_intuitionistic_logic) for $\neg A\lor \neg B$ to an equivalence.

Assuming classical double-negation elimination, the weak Markov's principle becomes trivial, expressing that a number larger than all non-positive numbers is positive.

:::

### Extensionality of functions {#Extensionality_of_functions}

A function $f: X \to Y$ between [metric spaces](wikipedia://en/20018) is called *strongly extensional* if $d(f(x),f(y)) > 0$ implies $d(x,y) > 0$, which is classically just the [contraposition](wikipedia://en/8556497) of the function preserving equality. Markov's principle can be shown to be equivalent to the proposition that all functions between arbitrary metric spaces are strongly extensional, while the weak Markov's principle is equivalent to the proposition that all functions from [complete](wikipedia://en/7832) metric spaces to metric spaces are strongly extensional.
