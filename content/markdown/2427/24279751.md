# Base ten blocks

::: {#o1 .subject cue=lead name="Base ten blocks"}

*Image: Dienes Material (Dyskalkulie).jpg.* Wooden Dienes blocks in units of 1, 10, 100 and 1000

*Image: Dienes blocks used by a 8 year-old student.png.* Plastic Dienes blocks in use

**Base ten blocks**, also known as **Dienes blocks** after popularizer [Zoltán Dienes](https://en.wikipedia.org/wiki/Zoltán_Dienes) (), are a [mathematical manipulative](https://en.wikipedia.org/wiki/Mathematical_manipulative) used by students to practice [counting](wikipedia://en/275768) and [elementary arithmetic](wikipedia://en/1567386) and develop [number sense](wikipedia://en/4642495) in the context of the [decimal](wikipedia://en/8214) [place-value](https://en.wikipedia.org/wiki/Place_value) system as a more concrete and direct representation than written [Hindu–Arabic numerals](wikipedia://en/3393371). The three-dimensional blocks are made of a solid material such as plastic or wood and generally come in four sizes, each representing a [power of ten](https://en.wikipedia.org/wiki/Power_of_ten) used as a place in the decimal system: *units* (ones place), *longs* (tens place), *flats* (hundreds place) and *blocks* (thousands place).[^o2] There are also computer programs available that simulate base ten blocks.

:::

Base ten blocks were first described by [Catherine Stern](https://en.wikipedia.org/wiki/Catherine_Stern) in 1949,[^o3] though [Maria Montessori](https://en.wikipedia.org/wiki/Maria_Montessori) had earlier introduced a similar manipulative, the "golden beads", which were assembled into the same shapes as base ten blocks.[^o4] Dienes popularized the idea starting in the 1950s, recommending blocks for several [number bases](wikipedia://en/3933525) ([two](wikipedia://en/238686), [three](wikipedia://en/62950), etc.), called **multibase arithmetic blocks** (MAB), so students could concretely compare different number bases and learn about the decimal place-value system as one arbitrary choice among many possibilities.[^o5][^o6] Multibase blocks found support in the [New Math](wikipedia://en/404988) movement of the 1960s. Today, base ten blocks are widespread while blocks for other bases are rarely found.

## Use in mathematics instruction {#Use_in_mathematics_instruction}

*Image: ZR1000 (Dienes-Material).jpg.* The number 328 represented in base ten blocks

Base ten blocks are popular in [primary-school mathematics](wikipedia://en/1775329) instruction, especially with topics that students struggle with such as [multiplication](wikipedia://en/20845). They are used by teachers to model concepts, as well as by students to reinforce their own understanding. Physically manipulating objects is an important technique used in learning basic mathematic principles, particularly at the early stages of cognitive development. The use of base ten blocks, as with other [mathematical manipulatives](https://en.wikipedia.org/wiki/Mathematical_manipulative), usually decreases as students move into higher grades.[^o8]

The blocks can be used to teach carrying and borrowing in multi-digit arithmetic via "regrouping" (trading one block for ten of a smaller size, or vice versa). If the magnitude of the blocks is reinterpreted (for instance by taking the 1000-cube block to represent 1), then the blocks can be used to teach decimal fractions.
