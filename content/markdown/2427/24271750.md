# Étale group scheme

::: {#o1 .subject cue=lead name="Étale group scheme"}

In [mathematics](wikipedia://en/18831), more precisely in [algebra](wikipedia://en/18716923), an **étale group scheme** is a certain kind of [group scheme](wikipedia://en/510523).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A finite [group scheme](wikipedia://en/510523) $G$ over a [field](wikipedia://en/10603) $K$ is called an *étale group scheme* if it is represented by an [étale K-algebra](wikipedia://en/24271692) $\mathfrak{R}$, i.e. if $\mathfrak{R}\otimes _{K}\bar{K}$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to $\bar{K}\times ...\times\bar{K}$.

:::
