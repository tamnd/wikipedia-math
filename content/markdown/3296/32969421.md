# Forney algorithm

::: {#o1 .subject cue=lead name="Forney algorithm"}

In [coding theory](wikipedia://en/321869), the **Forney algorithm** (or **Forney's algorithm**) calculates the error values at known error locations. It is used as one of the steps in decoding [BCH codes](wikipedia://en/40779) and [Reed–Solomon codes](https://en.wikipedia.org/wiki/Reed&ndash;Solomon_error_correction) (a subclass of BCH codes). [George David Forney Jr.](https://en.wikipedia.org/wiki/Dave_Forney) developed the algorithm in 1965.[^o2]

:::

Code words look like polynomials. By design, the generator polynomial has consecutive roots α<sup>c</sup>, α<sup>*c*+1</sup>, ..., α<sup>*c*+*d*−2</sup>.

Syndromes

Error location polynomial[^o5]

$$\Lambda(x) = \prod_{i=1}^\nu (1- x \, X_i) = 1 + \sum_{i=1}^\nu \lambda_i \, x^i$$

The zeros of Λ(*x*) are *X*<sub>1</sub><sup>−1</sup>, ..., *X*<sub>*ν*</sub><sup>−1</sup>. The zeros are the reciprocals of the error locations $X_j = \alpha^{i_j}$.

Once the error locations are known, the next step is to determine the error values at those locations. The error values are then used to correct the received values at those locations to recover the original codeword.

In the more general case, the error weights $e_{j}$ can be determined by solving the linear system

$$s_0 = e_1 \alpha^{(c + 0)\,i_1} + e_2 \alpha^{(c + 0)\,i_2} + \cdots \,$$

$$s_1 = e_1 \alpha^{(c + 1)\,i_1} + e_2 \alpha^{(c + 1)\,i_2} + \cdots \,$$

$$\cdots \,$$

However, there is a more efficient method known as the Forney algorithm, which is based on [Lagrange interpolation](wikipedia://en/217523). First calculate the error evaluator polynomial[^o6]

$$\Omega(x) = S(x)\,\Lambda(x) \pmod{x^{2t}} \,$$

Where $S(x)$ is the partial syndrome polynomial:[^o7]

$$S(x) = s_0 x^0 + s_1 x^1 + s_2 x^2 + \cdots + s_{2t-1} x^{2t-1}.$$

Then evaluate the error values:[^o6]

$$e_j = - \frac{X_j^{1-c} \, \Omega(X_j^{-1})}{\Lambda'(X_j^{-1})} \,$$

The value $c$ is often called the "first consecutive root" or "fcr". Some codes select $c = 1$, so the expression simplifies to:

$$e_j = - \frac{\Omega(X_j^{-1})}{\Lambda'(X_j^{-1})}$$

:::

## Formal derivative {#Formal_derivative}

Λ'(*x*) is the [formal derivative](wikipedia://en/3832917) of the error locator polynomial Λ(*x*):[^o6]

$$\Lambda'(x) = \sum_{i=1}^{\nu} i \, \cdot \, \lambda_i \, x^{i-1}$$

In the above expression, note that *i* is an [integer](wikipedia://en/14563), and λ<sub>*i*</sub> would be an element of the [finite field](wikipedia://en/11615). The operator ⋅ represents ordinary multiplication (repeated addition in the finite field) which is the same as the finite field's [multiplication operator](wikipedia://en/976642), i.e.

$$i\lambda = (1+\ldots+1)\lambda=\lambda+\ldots+\lambda.$$

For instance, in characteristic 2, $i\lambda=0, \lambda$ according as *i* is even or odd.

## Erasures {#Erasures}

Define the erasure locator polynomial

$$\Gamma(x) = \prod (1- x \, \alpha^{j_i})$$

Where the erasure locations are given by *j<sub>i</sub>*. Apply the procedure described above, substituting Γ for Λ.

If both errors and erasures are present, use the error-and-erasure locator polynomial

$$\Psi(x) = \Lambda(x) \, \Gamma(x)$$
