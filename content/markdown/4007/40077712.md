# SMAWK algorithm

::: {#o1 .subject cue=lead name="SMAWK algorithm"}

The **SMAWK algorithm** is an [algorithm](wikipedia://en/775) for [finding the minimum value](wikipedia://en/298420) in each row of an implicitly defined totally monotone [matrix](wikipedia://en/20556859). It is named after the initials of its five inventors, [Peter Shor](wikipedia://en/68338), [Shlomo Moran](https://en.wikipedia.org/wiki/Shlomo_Moran), Alok Aggarwal, Robert Wilber, and [Maria Klawe](https://en.wikipedia.org/wiki/Maria_Klawe).[^o2]

:::

## Input {#Input}

For the purposes of this algorithm, a matrix is defined to be monotone if each row's minimum value occurs in a column which is equal to or greater than the column of the previous row's minimum. It is totally monotone if the same property is true for every submatrix (defined by an arbitrary subset of the rows and columns of the given matrix). Equivalently, a matrix is totally monotone if there does not exist a 2×2 submatrix whose row minima are in the top right and bottom left corners. Every [Monge array](https://en.wikipedia.org/wiki/Monge_array) is totally monotone, but not necessarily vice versa.

For the SMAWK algorithm, the matrix to be searched should be defined as a function, and this function is given as input to the algorithm (together with the dimensions of the matrix). The algorithm then evaluates the function whenever it needs to know the value of a particular matrix cell. If this evaluation takes *O*(*1*), then, for a matrix with *r* rows and *c* columns, the running time and number of function evaluations are both *O*(*c*(1 + log(*r*/*c*))). This is much faster than the *O*(*r* *c*) time of a naive algorithm that evaluates all matrix cells.

::: {#o5 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

The basic idea of the algorithm is to follow a [prune and search](wikipedia://en/26874356) strategy in which the problem to be solved is reduced to a single [recursive](wikipedia://en/4044867) subproblem of the same type whose size is smaller by a constant factor. To do so, the algorithm first preprocesses the matrix to remove some of its columns that cannot contain a row-minimum, using a [stack](https://en.wikipedia.org/wiki/Stack_%28data_structure%29)-based algorithm similar to the one in the [Graham scan](https://en.wikipedia.org/wiki/Graham_scan) and [all nearest smaller values](https://en.wikipedia.org/wiki/All_nearest_smaller_values) algorithms. After this phase of the algorithm, the number of remaining columns will at most equal the number of rows. Next, the algorithm calls itself recursively to find the row minima of the even-numbered rows of the matrix. Finally, by searching the columns between the positions of consecutive even-row minima, the algorithm fills out the remaining minima in the odd rows.

:::

## Applications {#Applications}

The main applications of this method presented in the original paper by Aggarwal et al. were in [computational geometry](wikipedia://en/176927), in finding the farthest point from each point of a convex polygon, and in finding optimal enclosing polygons. Subsequent research found applications of the same algorithm in [breaking paragraphs into lines](https://en.wikipedia.org/wiki/Word_wrap),[^o8] [RNA](https://en.wikipedia.org/wiki/RNA) [secondary structure](https://en.wikipedia.org/wiki/Nucleic_acid_secondary_structure) prediction,[^o9] [DNA](https://en.wikipedia.org/wiki/DNA) and [protein](https://en.wikipedia.org/wiki/Protein) [sequence alignment](wikipedia://en/149289),[^o10][^o11] the construction of [prefix codes](wikipedia://en/66193),[^o12] and [image thresholding](https://en.wikipedia.org/wiki/Thresholding_%28image_processing%29),[^o13] among others.

:::
