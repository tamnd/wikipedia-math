# Sphere packing in a sphere

::: {#o1 .subject cue=lead name="Sphere packing in a sphere"}

**Sphere packing in a sphere** is a three-dimensional [packing problem](https://en.wikipedia.org/wiki/Packing_problem) with the objective of packing a given number of equal spheres inside a [unit sphere](wikipedia://en/27033090). It is the three-dimensional equivalent of the [circle packing in a circle](wikipedia://en/31948706) problem in two dimensions.
