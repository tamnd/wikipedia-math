# Exploratory causal analysis

::: {#o1 .subject cue=lead name="Exploratory causal analysis"}

[Causal analysis](wikipedia://en/26923751) is the field of [experimental design](https://en.wikipedia.org/wiki/Experimental_design) and [statistical analysis](wikipedia://en/26685) pertaining to establishing cause and effect.[^o2][^o3] **Exploratory causal analysis** (**ECA**), also known as **data causality** or **causal discovery**[^o4] is the use of statistical [algorithms](https://en.wikipedia.org/wiki/Algorithms) to infer associations in observed data sets that are potentially causal under strict assumptions. ECA is a type of [causal inference](wikipedia://en/37103476) distinct from [causal modeling](wikipedia://en/6672748) and [treatment effects](wikipedia://en/14527587) in [randomized controlled trials](https://en.wikipedia.org/wiki/Randomized_controlled_trials).[^o5] It is [exploratory research](https://en.wikipedia.org/wiki/Exploratory_research) usually preceding more formal [causal research](wikipedia://en/44155493) in the same way [exploratory data analysis](wikipedia://en/416589) often precedes [statistical hypothesis testing](https://en.wikipedia.org/wiki/Confirmatory_data_analysis) in [data analysis](wikipedia://en/2720954)[^o6][^o7]

:::

## Motivation {#Motivation}

Data analysis is primarily concerned with causal questions.[^o4][^o5][^o9][^o10][^o11] For example, did the fertilizer cause the crops to grow?[^o12] Or, can a given sickness be prevented?[^o13] Or, why is my friend depressed?[^o14] The [potential outcomes](wikipedia://en/5700418) and [regression analysis](wikipedia://en/826997) techniques handle such queries when data is collected using designed experiments. Data collected in [observational](wikipedia://en/6326483) studies require different techniques for causal inference (because, for example, of issues such as [confounding](wikipedia://en/3105999)).[^o15] Causal inference techniques used with experimental data require additional assumptions to produce reasonable inferences with observation data.[^o16] The difficulty of causal inference under such circumstances is often summed up as "[correlation does not imply causation](wikipedia://en/39834)".

## Overview {#Overview}

ECA postulates that there exist [data analysis procedures](wikipedia://en/2720954) performed on specific subsets of [variables](wikipedia://en/437701) within a larger set whose outputs might be indicative of causality between those variables.[^o4] For example, if we assume every relevant [covariate](https://en.wikipedia.org/wiki/Covariate) in the data is observed, then [propensity score matching](wikipedia://en/16722927) can be used to find the causal effect between two observational variables.[^o5] [Granger causality](wikipedia://en/1648224) can also be used to find the causality between two observational variables under different, but similarly strict, assumptions.[^o18]

The two broad approaches to developing such procedures are using *operational definitions of causality*[^o6] or *verification by "truth"* (i.e., explicitly ignoring the problem of defining [causality](https://en.wikipedia.org/wiki/Causality) and showing that a given algorithm implies a causal relationship in scenarios when causal relationships are known to exist, e.g., using [synthetic data](wikipedia://en/25270778)[^o4]).

### Operational definitions of causality {#Operational_definitions_of_causality}

[Clive Granger](https://en.wikipedia.org/wiki/Clive_Granger) created the first [operational definition](https://en.wikipedia.org/wiki/Operational_definition) of causality in 1969.[^o20] Granger made the definition of [probabilistic causality](wikipedia://en/14474114) proposed by [Norbert Wiener](wikipedia://en/63185) operational as a comparison of variances.[^o21]

Some authors prefer using ECA techniques developed using operational definitions of causality because they believe it may help in the search for causal mechanisms.[^o6][^o22]

### Verification by "truth" {#Verification_by_"truth"}

[Peter Spirtes](https://en.wikipedia.org/wiki/Peter_Spirtes), [Clark Glymour](wikipedia://en/27821585), and [Richard Scheines](https://en.wikipedia.org/wiki/Richard_Scheines) introduced the idea of explicitly not providing a definition of causality.[^o4] Spirtes and Glymour introduced the PC algorithm for causal discovery in 1990.[^o24] Many recent causal discovery algorithms follow the Spirtes-Glymour approach to verification.[^o25]

## Techniques {#Techniques}

There are many surveys of causal discovery techniques.[^o4][^o6][^o25][^o28][^o29][^o30] This section lists the well-known techniques.

### Bivariate (or "pairwise") {#Bivariate_(or_"pairwise")}

- [Granger causality](wikipedia://en/1648224) (there is also the [Scholarpedia](https://en.wikipedia.org/wiki/Scholarpedia) entry <http://www.scholarpedia.org/article/Granger_causality>)
- [transfer entropy](wikipedia://en/39563860)
- [convergent cross mapping](wikipedia://en/37188661)

### Multivariate {#Multivariate}

- causation entropy[^o33]
- PC algorithm[^o4][^o34]
- FCI algorithm[^o4][^o35]
- LiNGAM[^o36] <https://sites.google.com/site/sshimizu06/lingam/>

Many of these techniques are discussed in the tutorials provided by the Center for Causal Discovery (CCD) <https://www.ccd.pitt.edu/video-tutorials/>.

## Use-case examples {#Use-case_examples}

### Social science {#Social_science}

The PC algorithm has been applied to several different [social science](https://en.wikipedia.org/wiki/Social_science) data sets.[^o4]

### Medicine {#Medicine}

The PC algorithm has been applied to medical data.[^o40] Granger causality has been applied to [fMRI](https://en.wikipedia.org/wiki/Functional_magnetic_resonance_imaging) data.[^o41] CCD tested their tools using biomedical data <https://www.ccd.pitt.edu/biomedical-science/>.

### Physics {#Physics}

ECA is used in physics to understand the physical causal mechanisms of the system, e.g., in geophysics using the PC-stable algorithm (a variant of the original PC algorithm)[^o43] and in dynamical systems using pairwise asymmetric inference (a variant of convergent cross mapping).[^o44]

## Criticism {#Criticism}

There is debate over whether or not the relationships between data found using causal discovery are actually causal.[^o4][^o34] [Judea Pearl](https://en.wikipedia.org/wiki/Judea_Pearl) has emphasized that causal inference requires a causal model developed by "intelligence" through an iterative process of testing assumptions and fitting data.[^o9]

Response to the criticism points out that assumptions used for developing ECA techniques may not hold for a given data set[^o4][^o16][^o46][^o47][^o48] and that any causal relationships discovered during ECA are contingent on these assumptions holding true[^o34][^o49]

## Software Packages {#Software_Packages}

### Comprehensive toolkits {#Comprehensive_toolkits}

- [Tetrad](https://cmu-phil.github.io/tetrad/manual/) is an open source GUI-based Java program that provides a collection of causal discovery algorithms.[^o52] The algorithm library used by Tetrad is also available as a [command-line](https://en.wikipedia.org/wiki/Command-line_interface) tool, [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) [API](https://en.wikipedia.org/wiki/Application_programming_interface), and [R](wikipedia://en/376707) wrapper.[^o53]
- [Java Information Dynamics Toolkit (JIDT)](https://jlizier.github.io/jidt/) is an open source Java library for performing information-theoretic causal discovery (i.e., transfer entropy, conditional transfer entropy, etc.)<https://github.com/jlizier/jidt/wiki/Documentation>. Examples of using the library in [MATLAB](wikipedia://en/20412), [GNU Octave](wikipedia://en/48707), [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [R](wikipedia://en/376707), [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29) and [Clojure](https://en.wikipedia.org/wiki/Clojure) are provided in the documentation <https://github.com/jlizier/jidt>.
- [pcalg](https://cran.r-project.org/web/packages/pcalg/index.html) is an [R](wikipedia://en/376707) package that provides some of the same causal discovery algorithms provided in Tetrad <https://cran.r-project.org/web/packages/pcalg/vignettes/pcalgDoc.pdf> (2017-07-20). <https://web.archive.org/web/20170720172611/https://cran.r-project.org/web/packages/pcalg/vignettes/pcalgDoc.pdf>.
