# List object

::: {#o1 .subject cue=lead name="List object"}

In [category theory](wikipedia://en/5869), an abstract branch of [mathematics](wikipedia://en/18831), and in its applications to [logic](wikipedia://en/46426065) and [theoretical computer science](wikipedia://en/323392), a **list object** is an abstract definition of a [list](https://en.wikipedia.org/wiki/List_%28abstract_data_type%29), that is, a [finite](wikipedia://en/11742) ordered [sequence](wikipedia://en/27838).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let **C** be a [category](wikipedia://en/53759) with finite [products](wikipedia://en/237868) and a [terminal object](wikipedia://en/59405) 1. A **list object** over an [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29) $A$ of **C** is:

1. an object $L$<sub>$A$</sub>,
1. a [morphism](wikipedia://en/27716891) $o$<sub>$A$</sub> : 1 → $L$<sub>$A$</sub>, and
1. a morphism $s$<sub>$A$</sub> : $A$ × $L$<sub>$A$</sub> → $L$<sub>$A$</sub>

such that for any object $B$ of **$C$** with maps $b$ : 1 → $B$ and $t$ : $A$ × $B$ → $B$, there exists a unique $f$ : $L$<sub>$A$</sub> → $B$ such that the following diagram [commutes](wikipedia://en/138484):

### Equivalent definitions {#Equivalent_definitions}

In a category with a terminal object 1, binary [coproducts](wikipedia://en/310889) (denoted by +), and binary products (denoted by ×), a list object over $A$ can be defined as the [initial algebra](wikipedia://en/4116488) of the [endofunctor](https://en.wikipedia.org/wiki/Endofunctor) that acts on objects by $X$ ↦ 1 + ($A$ × $X$) and on arrows by $f$ ↦ \[id<sub>1</sub>,〈id<sub>$A$</sub>, $f$〉\].[^o7]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- In **Set**, the [category of sets](wikipedia://en/26829), list objects over a set $A$ are simply finite lists with [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) drawn from $A$. In this case, $o$<sub>$A$</sub> picks out the empty list and $s$<sub>$A$</sub> corresponds to appending an element to the head of the list.
- In the [calculus of inductive constructions](wikipedia://en/613557) or similar [type theories](wikipedia://en/40282) with inductive types (or heuristically, even [strongly typed](https://en.wikipedia.org/wiki/Strong_and_weak_typing) [functional](https://en.wikipedia.org/wiki/Functional_programming) languages such as [Haskell](https://en.wikipedia.org/wiki/Haskell_%28programming_language%29)), lists are types defined by two constructors, **nil** and **cons**, which correspond to $o$<sub>$A$</sub> and $s$<sub>$A$</sub>, respectively. The recursion principle for lists guarantees they have the expected universal property.

:::

## Properties {#Properties}

Like all constructions defined by a [universal property](wikipedia://en/32245), lists over an object are unique up to [canonical isomorphism](https://en.wikipedia.org/wiki/Canonical_isomorphism).

The object $L$<sub>1</sub> (lists over the terminal object) has the universal property of a [natural number object](https://en.wikipedia.org/wiki/Natural_number_object). In any category with lists, one can define the **length** of a list $L$<sub>$A$</sub> to be the unique morphism $l$ : $L$<sub>$A$</sub> → $L$<sub>1</sub> which makes the following diagram commute:[^n2]
