# Linear programming decoding

::: {#o1 .subject cue=lead name="Linear programming decoding"}

In [information theory](wikipedia://en/14773) and [coding theory](wikipedia://en/321869), **linear programming decoding (LP decoding)** is a [decoding](wikipedia://en/1940782) method which uses concepts from [linear programming](wikipedia://en/43730) (LP) theory to solve decoding problems. This approach was first used by Jon Feldman *et al.*[^o2] They showed how the LP can be used to decode block codes.

:::

The basic idea behind LP decoding is to first represent the [maximum likelihood decoding](https://en.wikipedia.org/wiki/Maximum_likelihood_decoding#Maximum_likelihood_decoding) of a [linear code](wikipedia://en/1866743) as an [integer linear program](https://en.wikipedia.org/wiki/Integer_linear_programming), and then [relax](wikipedia://en/6368430) the integrality constraints on the variables into linear inequalities.
