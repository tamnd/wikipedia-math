# Feller-continuous process

::: {#o1 .subject cue=lead name="Feller-continuous process"}

In [mathematics](wikipedia://en/18831), a **Feller-continuous process** is a continuous-time [stochastic process](wikipedia://en/47895) for which the [expected value](wikipedia://en/9653) of suitable statistics of the process at a given time in the future depend continuously on the initial condition of the process. The concept is named after [Croatian](https://en.wikipedia.org/wiki/Croatia)-American [mathematician](wikipedia://en/18902) [William Feller](wikipedia://en/206644).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* : \[0, +∞) × Ω → **R**<sup>*n*</sup>, defined on a [probability space](wikipedia://en/43325) (Ω, Σ, **P**), be a stochastic process. For a point *x* ∈ **R**<sup>*n*</sup>, let **P**<sup>*x*</sup> denote the [law](https://en.wikipedia.org/wiki/Law_%28stochastic_processes%29) of *X* given initial value *X*<sub>0</sub> = *x*, and let **E**<sup>*x*</sup> denote expectation with respect to **P**<sup>*x*</sup>. Then *X* is said to be a **Feller-continuous process** if, for any fixed *t* ≥ 0 and any [bounded](wikipedia://en/311509), continuous and Σ-[measurable function](wikipedia://en/44055) *g* : **R**<sup>*n*</sup> → **R**, **E**<sup>*x*</sup>\[*g*(*X*<sub>*t*</sub>)\] depends continuously upon *x*.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every process *X* whose paths are [almost surely](wikipedia://en/351908) constant for all time is a Feller-continuous process, since then **E**<sup>*x*</sup>\[*g*(*X*<sub>*t*</sub>)\] is simply *g*(*x*), which, by hypothesis, depends continuously upon *x*.
- Every [Itô diffusion](wikipedia://en/12139922) with [Lipschitz-continuous](wikipedia://en/51731) drift and diffusion coefficients is a Feller-continuous process.

:::
