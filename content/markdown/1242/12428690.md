# Semi-elliptic operator

::: {#o1 .subject cue=lead name="Semi-elliptic operator"}

In [mathematics](wikipedia://en/18831) — specifically, in the theory of [partial differential equations](wikipedia://en/52564) — a **semi-elliptic operator** is a [partial differential operator](https://en.wikipedia.org/wiki/Partial_differential_operator) satisfying a positivity condition slightly weaker than that of being an [elliptic operator](wikipedia://en/550137). Every elliptic operator is also semi-elliptic, and semi-elliptic operators share many of the nice properties of elliptic operators: for example, much of the same existence and uniqueness theory is applicable, and semi-elliptic [Dirichlet problems](wikipedia://en/571109) can be solved using [the methods of stochastic analysis](wikipedia://en/12195613).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A second-order [partial differential operator](https://en.wikipedia.org/wiki/Partial_differential_operator) *P* defined on an [open subset](https://en.wikipedia.org/wiki/Open_subset) Ω of *n*-[dimensional](wikipedia://en/8398) [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup>, acting on suitable functions *f* by

$$P f(x) = \sum_{i, j = 1}^{n} a_{ij} (x) \frac{\partial^{2} f}{\partial x_{i} \, \partial x_{j}}(x) + \sum_{i = 1}^{n} b_{i} (x) \frac{\partial f}{\partial x_{i}} (x) + c(x) f(x),$$

is said to be **semi-elliptic** if all the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) *λ*<sub>*i*</sub>(*x*), 1 ≤ *i* ≤ *n*, of the [matrix](wikipedia://en/20556859) *a*(*x*) = (*a*<sub>*ij*</sub>(*x*)) are non-negative. (By way of contrast, *P* is said to be elliptic if *λ*<sub>*i*</sub>(*x*) > 0 for all *x* ∈ Ω and 1 ≤ *i* ≤ *n*, and uniformly elliptic if the eigenvalues are [uniformly bounded](https://en.wikipedia.org/wiki/Uniformly_bounded) away from zero, uniformly in *i* and *x*.) Equivalently, *P* is semi-elliptic if the matrix *a*(*x*) is [positive semi-definite](https://en.wikipedia.org/wiki/Definite_bilinear_form) for each *x* ∈ Ω.

:::
