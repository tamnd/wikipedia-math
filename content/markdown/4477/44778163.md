# Zak transform

::: {#o1 .subject cue=lead name="Zak transform"}

In [mathematics](wikipedia://en/18831), the **Zak transform**[^o2][^o3] (also known as the **[Gelfand](wikipedia://en/364643) mapping**) is a certain operation which takes as input a function of one variable and produces as output a function of two variables. The output function is called the Zak transform of the input function. The transform is defined as an [infinite series](https://en.wikipedia.org/wiki/Infinite_series) in which each term is a product of a [dilation](https://en.wikipedia.org/wiki/Dilation_%28affine_geometry%29) of a [translation](wikipedia://en/204682) by an [integer](wikipedia://en/14563) of the function and an [exponential function](wikipedia://en/9678). In applications of Zak transform to [signal processing](wikipedia://en/29324) the input function represents a [signal](https://en.wikipedia.org/wiki/Signal_%28electrical_engineering%29) and the transform will be a mixed [time](https://en.wikipedia.org/wiki/Time)–[frequency](wikipedia://en/10779) representation of the signal. The signal may be [real valued](wikipedia://en/20646438) or [complex-valued](wikipedia://en/5826), defined on a continuous set (for example, the real numbers) or a [discrete set](https://en.wikipedia.org/wiki/Discrete_set) (for example, the integers or a finite subset of integers). The Zak transform is a generalization of the [discrete Fourier transform](wikipedia://en/8811).[^o3]

:::

The Zak transform had been discovered by several people in different fields and was called by different names. It was called the "Gelfand mapping" because [Israel Gelfand](wikipedia://en/364643) introduced it in his work on [eigenfunction](wikipedia://en/228601) expansions. The transform was rediscovered independently by [Joshua Zak](https://en.wikipedia.org/wiki/Joshua_Zak) in 1967 who called it the "k-q representation". There seems to be a general consensus among experts in the field to call it the Zak transform, since Zak was the first to systematically study that transform in a more general setting and recognize its usefulness.[^o2][^o3]

## Continuous-time Zak transform: Definition {#Continuous-time_Zak_transform:_Definition}

In defining the continuous-time Zak transform, the input function is a [function of a real variable](wikipedia://en/1268958). So, let *f*(*t*) be a function of a real variable *t*. The continuous-time Zak transform of *f*(*t*) is a function of two real variables one of which is *t*. The other variable may be denoted by *w*. The continuous-time Zak transform has been defined variously.

### Definition 1 {#Definition_1}

Let *a* be a positive constant. The Zak transform of *f*(*t*), denoted by *Z*<sub>*a*</sub>\[*f*\], is a function of *t* and *w* defined by[^o2]

$$Z_a[f](t,w) = \sqrt{a}\sum_{k=-\infty}^{\infty}f(at + ak)e^{-2\pi kw i}.$$

### Definition 2 {#Definition_2}

The special case of Definition 1 obtained by taking *a* = 1 is sometimes taken as the definition of the Zak transform.[^o3] In this special case, the Zak transform of *f*(*t*) is denoted by *Z*\[*f*\].

$$Z[f](t,w) = \sum_{k=-\infty}^{\infty}f(t + k)e^{-2\pi kw i}.$$

### Definition 3 {#Definition_3}

The notation *Z*\[*f*\] is used to denote another form of the Zak transform. In this form, the Zak transform of *f*(*t*) is defined as follows:

$$Z[f](t,\nu) = \sum_{k=-\infty}^{\infty}f(t + k)e^{-k\nu i}.$$

### Definition 4 {#Definition_4}

Let *T* be a positive constant. The Zak transform of *f*(*t*), denoted by *Z*<sub>*T*</sub>\[*f*\], is a function of *t* and *w* defined by[^o3]

$$Z_T[f](t,w) = \sqrt{T}\sum_{k=-\infty}^{\infty}f(t + kT)e^{-2\pi kwT i}.$$

Here *t* and *w* are assumed to satisfy the conditions 0 ≤ *t* ≤ *T* and 0 ≤ *w* ≤ 1/*T*.

::: {#o10 .example cue=heading name="Example"}

## Example {#Example}

The Zak transform of the function

$$\phi(t)=\begin{cases}1,&0\le t<1 \\ 0, &\text{otherwise}\end{cases}$$

is given by

$$Z[\phi](t,w)=e^{-2\pi \lceil -t\rceil w i}$$

where $\lceil - t\rceil$ denotes the smallest integer not less than $-t$ (the [ceiling function](https://en.wikipedia.org/wiki/Ceiling_function)).

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties of the Zak transform"}

## Properties of the Zak transform {#Properties_of_the_Zak_transform}

In the following it will be assumed that the Zak transform is as given in Definition 2.

**\1. Linearity**

Let *a* and *b* be any real or complex numbers. Then

$$Z[af+bg](t,w)=aZ[f](t,w)+bZ[g](t,w)$$

**\2. Periodicity**

$$Z[f](t, w+1) = Z[f](t,w)$$

**\3. Quasi-periodicity**

$$Z[f](t+1, w)= e^{2\pi w i}Z[f](t,w)$$

**\4. Conjugation**

$$Z[\bar{f}](t,w)=\overline{Z[f]}(t,-w)$$

**\5. Symmetry**

If *f*(*t*) is even then $Z[f](t,w)=Z[f](-t,-w)$

If *f*(*t*) is odd then $Z[f](t,w)= -Z[f](-t,-w)$

**\6. Convolution**

Let $\star$ denote [convolution](wikipedia://en/7519) with respect to the variable *t*.

$$Z[f\star g](t,w)=Z[f](t,w)\star Z[g](t,w)$$

:::

::: {#o14 .statement cue=named-heading name="Inversion formula"}

## Inversion formula {#Inversion_formula}

Given the Zak transform of a function, the function can be reconstructed using the following formula:

$$f(t)= \int_0^1 Z[f](t,w)\, dw.$$

:::

## Discrete Zak transform: Definition {#Discrete_Zak_transform:_Definition}

Let $f(n)$ be a function of an integer variable $n \in \mathbb Z$ (a [sequence](wikipedia://en/27838)). The discrete Zak transform of $f(n)$ is a function of two real variables, one of which is the integer variable $n$. The other variable is a real variable which may be denoted by $w$. The discrete Zak transform has also been defined variously. However, only one of the definitions is given below.

::: {#o17 .definition cue=heading name="Definition"}

### Definition {#Definition}

The discrete Zak transform of the function $f(n)$ where $n$ is an integer variable, denoted by $Z[f]$, is defined by

$$Z[f](n,w)=\sum_{k=-\infty}^{\infty} f(n+k)e^{-2\pi k w i}.$$

:::

::: {#o19 .statement cue=named-heading name="Inversion formula"}

### Inversion formula {#Inversion_formula}

Given the discrete transform of a function $f(n)$, the function can be reconstructed using the following formula:

$$f(n)= \int_0^1 Z[f](n,w)\, dw.$$

:::

::: {#o21 .application cue=heading name="Applications"}

## Applications {#Applications}

The Zak transform has been successfully used in physics in [quantum field theory](wikipedia://en/25267),[^o22] in electrical engineering in [time-frequency representation](wikipedia://en/857710) of signals, and in digital data transmission. The Zak transform has also applications in mathematics. For example, it has been used in the Gabor representation problem.

:::
