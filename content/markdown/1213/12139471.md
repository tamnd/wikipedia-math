# Tanaka equation

::: {#o1 .subject cue=lead name="Tanaka equation"}

In [mathematics](wikipedia://en/18831), **Tanaka's equation** is an example of a [stochastic differential equation](wikipedia://en/1361454) which admits a [weak solution](wikipedia://en/3555416) but has no [strong solution](https://en.wikipedia.org/wiki/Strong_solution). It is named after the [Japanese](https://en.wikipedia.org/wiki/Japan) [mathematician](wikipedia://en/18902) Hiroshi Tanaka (Tanaka Hiroshi).

:::

Tanaka's equation is the one-dimensional stochastic differential equation

$$\mathrm{d} X_t = \operatorname{sgn} (X_t) \, \mathrm{d} B_t,$$

driven by canonical [Brownian motion](wikipedia://en/4436) *B*, with initial condition *X*<sub>0</sub> = 0, where sgn denotes the [sign function](wikipedia://en/505449)

$$\operatorname{sgn} (x) = \begin{cases} +1, & x \geq 0; \\ -1, & x < 0. \end{cases}$$

(Note the unconventional value for sgn(0).) The signum function does not satisfy the [Lipschitz continuity](wikipedia://en/51731) condition required for the usual theorems guaranteeing existence and uniqueness of strong solutions. The Tanaka equation has no strong solution, i.e. one for which the version *B* of Brownian motion is given in advance and the solution *X* is [adapted](wikipedia://en/6583420) to the [filtration](https://en.wikipedia.org/wiki/Filtration_%28abstract_algebra%29) generated by *B* and the initial conditions. However, the Tanaka equation does have a weak solution, one for which the process *X* and version of Brownian motion are both specified as part of the solution, rather than the Brownian motion being given *[a priori](wikipedia://en/472877)*. In this case, simply choose *X* to be any Brownian motion and define $\tilde{B}$ by

$$\tilde{B}_t = \int_0^t \operatorname{sgn} \big( X_s \big) \, \mathrm{d} X_s,$$

i.e.

$$\mathrm{d} \tilde{B}_t = \operatorname{sgn} (X_t) \, \mathrm{d} X_t.$$

Hence,

$$\mathrm{d} X_t = \operatorname{sgn} (X_t) \, \mathrm{d} \tilde{B}_{t},$$

and so *X* is a weak solution of the Tanaka equation. Furthermore, this solution is weakly unique, i.e. any other weak solution must have the same [law](https://en.wikipedia.org/wiki/Law_%28stochastic_processes%29).

Another counterexample of this type is [Tsirelson's stochastic differential equation](wikipedia://en/74281844).
