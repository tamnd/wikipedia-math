# Strongly monotone operator

::: {#o1 .subject cue=lead name="Strongly monotone operator"}

In [functional analysis](wikipedia://en/11180), a set-valued mapping $A:X\to 2^X$ where *X* is a real [Hilbert space](wikipedia://en/20598932) is said to be **strongly monotone** if

:::

$$\exists c > 0 \mbox{ s.t. } \langle u - v , x - y \rangle \geq c \|x - y\|^2 \quad \forall x,y\in X, u\in Ax, v\in Ay.$$

This is analogous to the notion of [strictly increasing](https://en.wikipedia.org/wiki/Strictly_increasing) for scalar-valued functions of one scalar argument.

Equivalently, a [binary relation](wikipedia://en/3931) $R \subseteq X^2$ is strongly monotone if

$$\exists c > 0 \mbox{ s.t. } \langle u - v, x - y \rangle \geq c \| x - y \|^2 \quad \forall \langle x, u \rangle, \langle y, v \rangle \in R.$$

A [function](wikipedia://en/185427) $f : X \to X$ is strongly monotone if

$$\exists c > 0 \mbox{ s.t. } \langle f(x) - f(y), x - y \rangle \geq c \| x - y \|^2 \quad \forall x, y \in X.$$
