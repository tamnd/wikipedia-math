# Distortion function

::: {#o1 .subject cue=lead name="Distortion function"}

A **distortion function** in [mathematics](wikipedia://en/18831) and [statistics](wikipedia://en/26685), for example, $g: [0,1] \to [0,1]$, is a [non-decreasing function](https://en.wikipedia.org/wiki/Non-decreasing_function) such that $g(0) = 0$ and $g(1) = 1$. The **dual distortion function** is $\tilde{g}(x) = 1 - g(1-x)$.[^o2][^o3] Distortion functions are used to define [distortion risk measures](https://en.wikipedia.org/wiki/Distortion_risk_measure).[^o3]

:::
