# Heinz mean

::: {#o1 .subject cue=lead name="Heinz mean"}

In mathematics, the **Heinz mean** (named after [E. Heinz](wikipedia://en/31696540)[^o2]) of two non-negative [real numbers](wikipedia://en/20646438) *A* and *B*, was defined by Bhatia[^o3] as:

:::

$$\operatorname{H}_x(A, B) = \frac{A^x B^{1-x} + A^{1-x} B^x}{2},$$

with 0 ≤ *x* ≤ $\tfrac{1}{2}$.

For different values of *x*, this Heinz mean interpolates between the [arithmetic](wikipedia://en/612) (*x* = 0) and [geometric](wikipedia://en/13046) (*x* = 1/2) means such that for 0 \< *x* \< $\tfrac{1}{2}$:

$$\sqrt{A B} = \operatorname{H}_\frac{1}{2}(A, B) < \operatorname{H}_x(A, B) < \operatorname{H}_0(A, B) = \frac{A + B}{2}.$$

The Heinz means appear naturally when symmetrizing $\alpha$-divergences.[^o4]

It may also be defined in the same way for [positive semidefinite matrices](https://en.wikipedia.org/wiki/Positive_semidefinite_matrix), and satisfies a similar interpolation formula.[^o5][^o6]
