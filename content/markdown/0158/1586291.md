# Fréchet filter

::: {#o1 .subject cue=lead name="Fréchet filter"}

In mathematics, the **Fréchet filter**, also called the **cofinite filter**, on a [set](wikipedia://en/26691) $X$ is a certain collection of subsets of $X$ (that is, it is a particular subset of the [power set](wikipedia://en/23799) of $X$). A subset $F$ of $X$ belongs to the Fréchet filter [if and only if](wikipedia://en/14922) the [complement](wikipedia://en/54347) of $F$ in $X$ is finite. Any such set $F$ is said to be [cofinite](wikipedia://en/382708) in $X$, which is why it is alternatively called the *cofinite filter* on $X$.

:::

The Fréchet filter is of interest in [topology](wikipedia://en/29954), where filters originated, and relates to [order](wikipedia://en/361924) and [lattice theory](wikipedia://en/469304) because a set's power set is a [partially ordered set](wikipedia://en/23572) under [set inclusion](wikipedia://en/27631) (more specifically, it forms a lattice). The Fréchet filter is named after the French mathematician [Maurice Fréchet](https://en.wikipedia.org/wiki/Maurice_Fréchet) (1878-1973), who worked in topology.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A subset $A$ of a set $X$ is said to be **cofinite in $X$** if its [complement](wikipedia://en/54347) in $X$ (that is, the set $X \setminus A$) is [finite](wikipedia://en/11742). The **Fréchet filter on $X$**, denoted by $F$ is the set of all cofinite subsets of $X$. That is:[^o4]

$$F = \{A \subseteq X : X \setminus A \; \text{ is finite }\}.$$

This makes $F$ a [filter](wikipedia://en/19719) on the lattice $(\mathcal{P}(X), \subseteq),$ the [power set](wikipedia://en/23799) $\mathcal{P}(X)$ of $X$ with set inclusion.

Letting $S^{\operatorname{c}}$ denote the complement of a set $S$ in $X,$ the following two conditions hold:

**Intersection condition**

If two sets are finitely complemented in $X$, then so is their intersection, since $(A \cap B)^{\operatorname{c}} = A^{\operatorname{c}} \cup B^{\operatorname{c}},$ and

**Upper-set condition**

If a set is finitely complemented in $X$, then so are its supersets in $X$.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If the base set $X$ is finite, then $F = \mathcal{P}(X)$ since every subset of $X$, and in particular every complement, is then finite. This case is sometimes excluded by definition or else called the **improper filter** on $X.$[^o7] Allowing $X$ to be finite creates a single exception to the Fréchet filter’s being [free](wikipedia://en/19719#Examples) and [non-principal](wikipedia://en/19719#General_definition) since a filter on a finite set cannot be free and a non-principal filter cannot contain any singletons as members.

If $X$ is infinite, then every member of $F$ is infinite since it is simply $X$ minus finitely many of its members. Additionally, $F$ is infinite since one of its subsets is the set of all $\{x\}^{\operatorname{C}},$ where $x \in X.$

The Fréchet filter is both free and non-principal, excepting the finite case mentioned above, and is included in every free filter. It is also the [dual](wikipedia://en/609737) filter of the [ideal](wikipedia://en/530559) of all finite subsets of (infinite) $X$.

The Fréchet filter is not necessarily an [ultrafilter](wikipedia://en/67416519) (or maximal proper filter). Consider the power set $\mathcal{P}(\mathbb{N}),$ where $\mathbb{N}$ is the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers). The set of even numbers is the complement of the set of odd numbers. Since neither of these sets is finite, neither set is in the Fréchet filter on $\mathbb{N}.$ However, an [ultrafilter](wikipedia://en/67416519) (and any other non-degenerate filter) is free if and only if it includes the Fréchet filter. The [ultrafilter lemma](https://en.wikipedia.org/wiki/Ultrafilter_lemma) states that every non-degenerate filter is contained in some ultrafilter. The existence of free ultrafilters was established by Tarski in 1930, relying on a theorem equivalent to the axiom of choice, and is used in the construction of the [hyperreals](wikipedia://en/51429) in [nonstandard analysis](https://en.wikipedia.org/wiki/Non-standard_analysis).[^o8]

:::

::: {#o10 .example cue=heading name="Examples"}

## Examples {#Examples}

On the set $\mathbb{N}$ of [natural numbers](wikipedia://en/21474), the set of infinite intervals $B = \{(n, \infty) : n \in \mathbb{N}\}$ is a Fréchet [filter base](https://en.wikipedia.org/wiki/Filter_base), that is, the Fréchet filter on $\mathbb{N}$ consists of all supersets of elements of $B$.

:::
