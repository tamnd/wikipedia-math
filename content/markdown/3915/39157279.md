# Set inversion

::: {#o1 .subject cue=lead name="Set inversion"}

In [mathematics](wikipedia://en/18831), **set inversion** is the problem of characterizing the [preimage](https://en.wikipedia.org/wiki/Inverse_image) *X* of a [set](wikipedia://en/26691) *Y* by a [function](wikipedia://en/185427) *f*, i.e., *X* = *f*<sup>−1</sup>(*Y* ) = {*x* ∈ **R**<sup>*n*</sup> | *f*(*x*) ∈ *Y* }. It can also be viewed as the problem of describing the solution set of the quantified constraint "*Y*(*f*(*x*))", where *Y*(*y*) is a constraint, e.g. an [inequality](wikipedia://en/89489), describing the set *Y*.

:::

In most applications, *f* is a function from **R**<sup>*n*</sup> to **R**<sup>*p*</sup> and the set *Y* is a box of **R**<sup>*p*</sup> (i.e. a [Cartesian product](wikipedia://en/24104095) of *p* [intervals](wikipedia://en/49172) of **R**).

When *f* is nonlinear the set inversion problem can be solved[^o2] using [interval analysis](https://en.wikipedia.org/wiki/Interval_analysis) combined with a [branch-and-bound](wikipedia://en/456580) algorithm.[^o3]

The main idea consists in building a paving of **R**<sup>*p*</sup> made with non-overlapping boxes. For each box \[*x*\], we perform the following tests:

1. if *f*(\[*x*\]) ⊂ *Y* we conclude that \[*x*\] ⊂ *X*;
1. if *f*(\[*x*\]) ∩ *Y* = [∅](wikipedia://en/9566) we conclude that \[*x*\] ∩ *X* = ∅;
1. Otherwise, the box \[*x*\] the box is bisected except if its width is smaller than a given precision.

To check the two first tests, we need an [interval extension](wikipedia://en/2176160) (or an inclusion function) \[*f* \] for *f*. Classified boxes are stored into [subpavings](wikipedia://en/39210398), i.e., [union](wikipedia://en/47949) of non-overlapping boxes. The algorithm can be made more efficient by replacing the inclusion tests by [contractors](wikipedia://en/39293339).

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

The set *X* = *f*<sup>−1</sup>(\[4,9\]) where *f*(*x*<sub>1</sub>, *x*<sub>2</sub>) = *x*${}^{2}_{1}$ + *x*${}^{2}_{2}$ is represented on the figure.

For instance, since \[−2,1\]<sup>2</sup> + \[4,5\]<sup>2</sup> = \[0,4\] + \[16,25\] = \[16,29\] does not [intersect](wikipedia://en/23476429) the interval \[4,9\], we conclude that the box \[−2,1\] × \[4,5\] is outside *X*. Since \[−1,1\]<sup>2</sup> + \[2,$\sqrt{5}$\]<sup>2</sup> = \[0,1\] + \[4,5\] = \[4,6\] is inside \[4,9\], we conclude that the whole box \[−1,1\] × \[2,$\sqrt{5}$\] is inside *X*.

## Application {#Application}

Set inversion is mainly used for [path planning](https://en.wikipedia.org/wiki/Motion_planning), for nonlinear parameter [set estimation](wikipedia://en/39284847),[^o8][^o9] for localization[^o10][^o11] or for the characterization of stability domains of [linear dynamical systems](wikipedia://en/4786318).[^o12]

:::
