# Compatible system of ℓ-adic representations

::: {#o1 .subject cue=lead name="Compatible system of ℓ-adic representations"}

In [number theory](wikipedia://en/21527), a **compatible system of ℓ-adic representations** is an abstraction of certain important families of ℓ-adic [Galois representations](wikipedia://en/486929), indexed by [prime numbers](wikipedia://en/23666) ℓ, that have compatibility properties for [almost all](wikipedia://en/1309) ℓ.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Prototypical examples include the [cyclotomic character](wikipedia://en/18846136) and the [Tate module](wikipedia://en/3094921) of an [abelian variety](wikipedia://en/247152).

:::

::: {#o5 .statement kind=statement/generalization cue=heading name="Variations"}

## Variations {#Variations}

A slightly more restrictive notion is that of a ***strictly* compatible system of ℓ-adic representations** which offers more control on the compatibility properties. More recently, some authors[^o6] have started requiring more compatibility related to [*p*-adic Hodge theory](wikipedia://en/26086853).

:::

## Importance {#Importance}

Compatible systems of ℓ-adic representations are a fundamental concept in contemporary [algebraic number theory](wikipedia://en/174705).
