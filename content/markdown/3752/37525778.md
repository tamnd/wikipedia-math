# Mittag-Leffler summation

::: {#o1 .subject cue=lead name="Mittag-Leffler summation"}

In mathematics, **Mittag-Leffler summation** is any of several variations of the [Borel summation](wikipedia://en/2357705) method for summing possibly [divergent](wikipedia://en/876428) [formal power series](wikipedia://en/60012), introduced by (txt)

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let

$$y(z) = \sum_{k = 0}^\infty y_kz^k$$

be a [formal power series](wikipedia://en/60012) in *z*.

Define the transform $\mathcal{B}_\alpha y$ of $y$ by

$$\mathcal{B}_\alpha y(t) \equiv \sum_{k=0}^\infty \frac{y_k}{\Gamma(1+\alpha k)}t^k$$

Then the **Mittag-Leffler sum** of *y* is given by

$$\lim_{\alpha\rightarrow 0}\mathcal{B}_\alpha y( z)$$

if each sum converges and the limit exists.

A closely related summation method, also called Mittag-Leffler summation, is given as follows (Sansone Gerretsen 1960). Suppose that the Borel transform $\mathcal{B}_1 y(z)$ converges to an [analytic function](wikipedia://en/61478) near 0 that can be [analytically continued](wikipedia://en/80842) along the [positive real axis](https://en.wikipedia.org/wiki/Positive_real_axis) to a function growing sufficiently slowly that the following integral is well defined (as an improper integral). Then the **Mittag-Leffler sum** of *y* is given by

$$\int_0^\infty e^{-t} \mathcal{B}_\alpha y(t^\alpha z) \, dt$$

When *α* = 1 this is the same as [Borel summation](wikipedia://en/2357705).
