# Trudinger's theorem

::: {#o1 .subject cue=lead name="Trudinger's theorem"}

In [mathematical analysis](wikipedia://en/48396), **Trudinger's theorem** or the **Trudinger inequality** (also sometimes called the **Moser–Trudinger inequality**) is a result of [functional analysis](wikipedia://en/11180) on [Sobolev spaces](wikipedia://en/611964). It is named after [Neil Trudinger](wikipedia://en/15173259) (and [Jürgen Moser](wikipedia://en/1752316)).

:::

It provides an inequality between a certain [Sobolev space](wikipedia://en/611964) norm and an [Orlicz space](wikipedia://en/17686010) norm of a function. The inequality is a [limiting case](wikipedia://en/40400729) of Sobolev embedding and can be stated as the following theorem:

Let $\Omega$ be a bounded domain in $\mathbb{R}^n$ satisfying the [cone condition](wikipedia://en/49932318). Let $mp=n$ and $p>1$. Set

$$A(t)=\exp\left( t^{n/(n-m)} \right)-1.$$

Then there exists the embedding

$$W^{m,p}(\Omega)\hookrightarrow L_A(\Omega)$$

where

$$L_A(\Omega)=\left\{ u\in M_f(\Omega):\|u\|_{A,\Omega}=\inf\{ k>0:\int_\Omega A\left( \frac{|u(x)|}{k} \right)~dx\leq 1 \}<\infty \right\}.$$

The space

$$L_A(\Omega)$$

is an example of an [Orlicz space](wikipedia://en/17686010).
