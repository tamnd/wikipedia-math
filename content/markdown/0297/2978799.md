# Hartogs's theorem on separate holomorphicity

::: {#o1 .subject cue=lead name="Hartogs's theorem on separate holomorphicity"}

In [mathematics](wikipedia://en/18831), **Hartogs's theorem** is a fundamental result of [Friedrich Hartogs](wikipedia://en/2977779) in the theory of [several complex variables](wikipedia://en/360243). Roughly speaking, it states that a 'separately analytic' function is continuous. More precisely, if $F:{\textbf{C}}^n \to {\textbf{C}}$ is a function which is [analytic](wikipedia://en/61478) in each variable *z*<sub>*i*</sub>, 1 ≤ *i* ≤ *n*, while the other variables are held constant, then *F* is a [continuous function](wikipedia://en/6122).

:::

A [corollary](wikipedia://en/168865) is that the function *F* is then in fact an analytic function in the *n*-variable sense (i.e. that locally it has a [Taylor expansion](https://en.wikipedia.org/wiki/Taylor_expansion)). Therefore, 'separate analyticity' and 'analyticity' are coincident notions, in the theory of several complex variables.

Starting with the extra hypothesis that the function is continuous (or bounded), the theorem is much easier to prove and in this form is known as [Osgood's lemma](wikipedia://en/37707528).

There is no analogue of this [theorem](wikipedia://en/30977) for [real variables](wikipedia://en/39783039). If we assume that a function $f \colon {\textbf{R}}^n \to {\textbf{R}}$ is [differentiable](wikipedia://en/330206) (or even [analytic](wikipedia://en/61478)) in each variable separately, it is not true that $f$ will necessarily be continuous. A counterexample in two dimensions is given by

$$f(x,y) = \frac{xy}{x^2+y^2}.$$

If in addition we define $f(0,0)=0$, this function has well-defined [partial derivatives](wikipedia://en/52565) in $x$ and $y$ at the origin, but it is not [continuous](wikipedia://en/6122) at origin. (Indeed, the [limits](wikipedia://en/285759) along the lines $x=y$ and $x=-y$ are not equal, so there is no way to extend the definition of $f$ to include the origin and have the function be continuous there.)
