# Hartogs number

::: {#o1 .subject cue=lead name="Hartogs number"}

In [mathematics](wikipedia://en/18831), specifically in [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **Hartogs number** of a [set](wikipedia://en/26691) $X$ is the least [ordinal number](wikipedia://en/26547932) $\alpha$ such that there is no [injection](wikipedia://en/45196) from $\alpha$ into $X$. In other words, $\alpha$ is the least ordinal such that $|\alpha| \not \le |X|$ (where $\lvert A\rvert$ denotes the [cardinality](wikipedia://en/6174) of a set $A$). The existence of the Hartogs number of any $X$ can be proved in [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZF) without relying on the [axiom of choice](wikipedia://en/840). The [map](wikipedia://en/516931) taking $X$ to $\alpha$ is sometimes called **Hartogs's function**.

:::

If $X$ can be [well-ordered](https://en.wikipedia.org/wiki/Well-ordered), then $\lvert \alpha\rvert > \lvert X\rvert$, since the cardinalities of two well-ordered sets are always [comparable](wikipedia://en/3834818). In fact, $\lvert \alpha\rvert$ is the [successor cardinal](wikipedia://en/375210) of $\lvert X\rvert$. Hartogs's function thus plays a role in constructing the [aleph numbers](wikipedia://en/293961), which are all the cardinal numbers of infinite well-orderable sets.

If $X$ cannot be well-ordered, then there cannot be an injection from $X$ to $\alpha$, so $\lvert \alpha\rvert > \lvert X\rvert$ cannot be true, and thus $\lvert \alpha\rvert$ is incomparable to $\lvert X\rvert$. Conversely, [trichotomy](https://en.wikipedia.org/wiki/Trichotomy_%28mathematics%29) for cardinal numbers (the statement that any two cardinal numbers are comparable) thus implies that [every set can be well-ordered](wikipedia://en/33458), and hence implies the axiom of choice.

The existence of the Hartogs number was proved by [Friedrich Hartogs](wikipedia://en/2977779) in 1915, using [Zermelo set theory](wikipedia://en/322623) alone (that is, without using the [axiom of choice](wikipedia://en/840) or the later-introduced [replacement schema](wikipedia://en/52387) of ZF). Since Zermelo set theory does not have canonical representatives for ordinal numbers, in Hartogs's result $\alpha$ is allowed to be any well-ordered set with the appropriate order type, and this result can be proved without the replacement schema. In the usual ZF formalization, the replacement schema is needed to convert this well-ordered set to its [von Neumann ordinal](https://en.wikipedia.org/wiki/Von_Neumann_ordinal).

::: {#o3 .statement kind=statement/theorem cue=named-heading name="Hartogs's theorem"}

## Hartogs's theorem {#Hartogs's_theorem}

Hartogs's theorem states that for any set $X$, there exists an ordinal $\alpha$ such that $|\alpha| \not \le |X|$; that is, such that there is no injection from $\alpha$ to $X$ as sets. As ordinals are well-ordered, this immediately implies the existence of a Hartogs number for any set $X$, namely the least ordinal with that property. Furthermore, the proof is constructive and yields the Hartogs number of $X$.

Intuitively, the Hartogs number of $X$ is exactly the order type of all ordinals $\beta$ such that there is an injection from $\beta$ to $X$, so it suffices to show that such $\beta$ form a set (as opposed to a [proper class](https://en.wikipedia.org/wiki/Proper_class)). Importantly, an injection from $\beta$ to $X$ is also a bijection from $\beta$ to a subset of $X$, meaning that $\beta$ is the order type of some [well-ordering](https://en.wikipedia.org/wiki/Well-ordering) of that subset. Since a well-ordering is just a special [binary relation](wikipedia://en/3931), the set of all possible well-orderings of subsets of $X$ can be constructed with standard techniques, and the set of all $\beta$ can then be represented in Z as a set of equivalence classes with respect to order isomorphism, without resort to Fraenkel's [Axiom schema of replacement](wikipedia://en/52387).

::: {#o5 .proof cue=heading name="Proof"}

### Proof {#Proof}

See (Goldrei 1996).

Let $\alpha = \{\beta \in \textrm{Ord} \mid \exists i: \beta \hookrightarrow X\}$ be the [class](wikipedia://en/20696) of all [ordinal numbers](wikipedia://en/26547932) *β* for which an [injective function](wikipedia://en/45196) exists from *β* into *X*.

First, we verify that *α* is a set.

1. *X* × *X* is a set, as can be seen in the article [Axiom of power set](wikipedia://en/52552#Consequences).
1. The [power set](wikipedia://en/23799) of *X* × *X* is a set, by the axiom of power set.
1. The class *W* of all [reflexive](wikipedia://en/200458) well-orderings of subsets of *X* is a definable subclass of the preceding set, so it is a set by the [axiom schema of separation](https://en.wikipedia.org/wiki/Axiom_schema_of_separation).
1. The class of all [order types](wikipedia://en/4499021) of well-orderings in *W* is a set by the [axiom schema of replacement](wikipedia://en/52387), as (Domain(*w*), *w*) $\cong$ (*β*, ≤) can be described by a simple formula.

But this last set is exactly *α*. Now, because a [transitive set](wikipedia://en/2462396) of ordinals is again an ordinal, *α* is an ordinal. Furthermore, there is no injection from *α* into *X*, because if there were, then we would get the contradiction that *α* ∈ *α*. And finally, *α* is the least such ordinal with no injection into *X*. This is true because, since *α* is an ordinal, for any *β* \< *α*, *β* ∈ *α* so there is an injection from *β* into *X*.

## Historical remark {#Historical_remark}

In 1915, Hartogs could use neither [von Neumann-ordinals](wikipedia://en/26547932#Von_Neumann_definition_of_ordinals) nor the [replacement axiom](https://en.wikipedia.org/wiki/Replacement_axiom), and so his result is one of Zermelo set theory and looks rather different from the modern exposition above. Instead, he considered the set of isomorphism classes of well-ordered subsets of *X* and the relation in which the class of *A* precedes that of *B* if *A* is [isomorphic](wikipedia://en/23916899) with a proper initial segment of *B*. Hartogs showed this to be a well-ordering greater than any well-ordered subset of *X*. However, the main purpose of his contribution was to show that trichotomy for cardinal numbers implies the (then 11 year old) [well-ordering theorem](wikipedia://en/33458) (and, hence, the axiom of choice).
