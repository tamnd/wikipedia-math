# Welfare maximization

::: {#o1 .subject cue=lead name="Welfare maximization"}

The **welfare maximization** problem is an [optimization problem](wikipedia://en/1126536) studied in [economics](https://en.wikipedia.org/wiki/Economics) and [computer science](https://en.wikipedia.org/wiki/Computer_science). Its goal is to partition a set of items among agents with different [utility functions](wikipedia://en/46241959), such that the welfare – defined as the sum of the agents' utilities – is as high as possible. In other words, the goal is to find an item allocation satisfying the [utilitarian rule](https://en.wikipedia.org/wiki/Utilitarian_rule).[^o25]

:::

An equivalent problem in the context of [combinatorial auctions](https://en.wikipedia.org/wiki/Combinatorial_auction) is called the **winner determination problem**. In this context, each agent submits a list of bids on sets of items, and the goal is to determine what bid or bids should win, such that the sum of the winning bids is maximum.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There is a set *M* of *m* items, and a set *N* of *n* agents. Each agent *i* in *N* has a **utility function** $u_i: 2^M \to \mathbb{R}$. The function assigns a real value to every possible subset of items. It is usually assumed that the utility functions are [monotone set functions](https://en.wikipedia.org/wiki/Monotone_set_function), that is, $Z_1\supseteq Z_2$ implies $u_i(Z_1) \geq u_i(Z_2)$. It is also assumed that $u_i(\emptyset)=0$. Together with monotonicity, this implies that all utilities are non-negative.

An **allocation** is an ordered partition of the items into *n* disjoint subsets, one subset per agent, denoted $\mathbf{X} = (X_1, \ldots, X_n)$, such that $M = X_1\sqcup \cdots \sqcup X_n$.The **welfare** of an allocation is the sum of agents' utilities: $W(\mathbf{X}) := \sum_{i\in N} u_i(X_i)$.

The **welfare maximization problem** is: find an allocation **X** that maximizes *W*(**X**).

The welfare maximization problem has many variants, depending on the type of allowed utility functions, the way by which the algorithm can access the utility functions, and whether there are additional constraints on the allowed allocations.

:::

## Additive agents {#Additive_agents}

An additive agent has a utility function that is an [additive set function](https://en.wikipedia.org/wiki/Additive_set_function): for every additive agent *i* and item *j*, there is a value $v_{i,j}$, such that $u_i(Z) = \sum_{j\in X_i} v_{i,j}$ for every set *Z* of items. When all agents are additive, welfare maximization can be done by a simple [polynomial-time](https://en.wikipedia.org/wiki/Polynomial-time) algorithm: give each item *j* to an agent for whom $v_{i,j}$ is maximum (breaking ties arbitrarily). The problem becomes more challenging when there are additional constraints on the allocation.

### Fairness constraints {#Fairness_constraints}

One may want to maximize the welfare among all allocations that are [*fair*](wikipedia://en/46974282), for example, [envy-free](wikipedia://en/51991437) up to one item (EF1), [proportional](https://en.wikipedia.org/wiki/Proportional_item_allocation) up to one item (PROP1), or [equitable](https://en.wikipedia.org/wiki/Equitable_division) up to one item (EQ1). This problem is strongly NP-hard when *n* is variable. For any fixed *n ≥ 2,* the problem is weakly NP-hard,[^o6][^o7] and has a [pseudo-polynomial time](wikipedia://en/3149636) algorithm based on [dynamic programming](wikipedia://en/125297).[^o6] For *n = 2*, the problem has a [fully polynomial-time approximation scheme](wikipedia://en/2047521).[^o8]

There are algorithms for solving this problem in polynomial time when there are few agent types, few item types or small value levels.[^o9] The problem can also be solved in polynomial time when the agents' additive utilities are *binary* (the value of every item is either 0 or 1), as well as for a more general class of utilities called *generalized binary*.[^o10]

### Matroid constraints {#Matroid_constraints}

Another constraint on the allocation is that the bundles must be independent sets of a [matroid](wikipedia://en/244321). For example, every bundle must contain at most *k* items, where *k* is a fixed integer (this corresponds to a [uniform matroid](wikipedia://en/27967069)). Or, the items may be partitioned into categories, and each bundle must contain at most *k<sub>c</sub>* items from each category *c* (this corresponds to a [partition matroid](wikipedia://en/36780298)). In general, there may be a different matroid for each agent, and the allocation must give each agent *i* a subset *X<sub>i</sub>* that is an independent set of their own matroid.

Welfare maximization with additive utilities under heterogeneous matroid constraints can be done in polynomial time, by reduction to the [weighted matroid intersection](wikipedia://en/23258067) problem.[^o12]

## Gross-substitute agents {#Gross-substitute_agents}

[Gross-substitute utilities](https://en.wikipedia.org/wiki/Gross_substitutes_%28indivisible_items%29) are more general than additive utilities. Welfare maximization with gross-substitute agents can be done in polynomial time. This is because, with gross-substitute agents, a [Walrasian equilibrium](https://en.wikipedia.org/wiki/Walrasian_equilibrium) always exists, and it maximizes the sum of utilities.[^o14] A Walrasian equilibrium can be found in polynomial time.

## Submodular agents {#Submodular_agents}

A submodular agent has a utility function that is a [submodular set function](wikipedia://en/33273315). This means that the agent's utility has [decreasing marginals](https://en.wikipedia.org/wiki/Decreasing_marginal_return). Submodular utilities are more general than gross-substitute utilities.

### Hardness {#Hardness}

Welfare maximization with submodular agents is NP-hard.[^o17] Moreover, it cannot be approximated to a factor better than (1-1/e)≈0.632 unless P=NP.[^o18] Moreover, a better than (1-1/e) approximation would require an exponential number of queries to a [value oracle](https://en.wikipedia.org/wiki/Value_oracle), regardless of whether P=NP.[^o19]

### Greedy algorithm {#Greedy_algorithm}

The maximum welfare can be approximated by the following polynomial-time [greedy algorithm](wikipedia://en/89247):

- Initialize *X*<sub>1</sub> = *X*<sub>2</sub> = ... = *X<sub>n</sub>* = empty.
- For every item *g* (in an arbitrary order):
  - Compute, for each agent *i*, his *[marginal utility](https://en.wikipedia.org/wiki/Marginal_utility)* for *g*, defined as: *u<sub>i</sub>*(*X<sub>i</sub>*+*g*) - *u<sub>i</sub>*(*X<sub>i</sub>*).
  - Give item *g* to an agent with the largest marginal utility.

Lehman, Lehman and Nisan[^o17] prove that the greedy algorithm finds a 1/2-factor approximation (they note that this result follows from a result of Fisher, Nemhauser and Wolsey[^o21] regarding the maximization of a single submodular valuation over a matroid). The proof idea is as follows. Suppose the algorithm allocates an item *g* to some agent *i*. This contributes to the welfare some amount *v*, which is marginal utility of *g* for *i* at that point. Suppose that, in the optimal solution, *g* should be given to another agent, say *k.* Consider how the welfare changes if we move *g* from i to *k*:

- The utility of *k* increases by his marginal utility of *g*, which at most *v* by the greedy selection.
- The marginal utility of the *remaining* bundle of *i* increases by at most *v*. This follows from submodularity: the marginal utility of *g*, when added to the remaining bundle, cannot be higher than its marginal utility when the algorithm processed it.

So, for every contribution of *v* to the algorithm welfare, the potential contribution to the optimal welfare could be at most 2*v*. Therefore, the optimal welfare is at most 2 times the algorithm welfare. The factor of 2 is tight for the greedy algorithm. For example, suppose there are two items x,y and the valuations are:

::: {#o22 .table cue=table}

|  | {} | {x} | {y} | {x,y} |
|---|---|---|---|---|
| Alice | 0 | 1 | 1 | 1 |
| George | 0 | 1 | 0 | 1 |

:::

The optimal allocation is Alice: {y}, George: {x}, with welfare 2. But if the greedy algorithm allocates x first, it might allocate it to Alice. Then, regardless of how y is allocated, the welfare is only 1.

### Algorithms using a value oracle {#Algorithms_using_a_value_oracle}

A **[value oracle](https://en.wikipedia.org/wiki/Value_oracle)** is an oracle that, given a set of items, returns the agent's value to this set. In this model:

- Dobzinski and Schapira[^o24] present a polytime $n/(2n-1)$-approximation algorithm, and an (1-1/e)≈0.632-approximation algorithm for the special case in which the agents' utilities are set-coverage functions.
- [Vondrak](wikipedia://en/71954772)[^o25] and Calinescu, Chekuri, Pal and Vondrak[^o26] present a randomized polytime algorithm that finds a (1-1/e)-approximation [with high probability](https://en.wikipedia.org/wiki/With_high_probability). Their algorithm uses a continuous-greedy algorithm - an algorithm that extends a *fractional* bundle (a bundle that contains a fraction *p<sub>j</sub>* of each item *j*) in a greedy direction (similarly to [gradient descent](wikipedia://en/201489)). Their algorithm needs to compute the value of fractional bundles, defined as the expected value of the bundle attained when each item *j* is selected independently with probability *p<sub>j</sub>*. In general, computing the value of a fractional bundle might require 2<sup>*m*</sup> calls to a value oracle; however, it can be computed approximately [with high probability](https://en.wikipedia.org/wiki/With_high_probability) by [random sampling](https://en.wikipedia.org/wiki/Random_sampling). This leads to a [randomized algorithm](wikipedia://en/495383) that attains a (1-1/e)-approximation with high probability. In cases when fractional bundles can be evaluated efficiently (e.g. when utility functions are set-coverage functions), the algorithm can be made deterministic.[^o26] For general monotone submodular functions, Buchbinder and Feldman[^o27] described a different local search based algorithm that is deterministic and guarantees $(1-1/e-\epsilon)$-approximation in polynomial time for any constant $\epsilon > 0$.

The welfare maximization problem (with *n* different submodular functions) can be reduced to the problem of maximizing a *single* submodular set function subject to a [matroid](wikipedia://en/244321) constraint:[^o17][^o25][^o26] given an instance with *m* items and *n* agents, construct an instance with *m*\**n* (agent,item) pairs, where each pair represents the assignment of an item to an agent. Construct a single function that assigns, to each set of pairs, the total welfare of the corresponding allocation. It can be shown that, if all utilities are submodular, then this welfare function is also submodular. This function should be maximized subject to a [partition matroid](wikipedia://en/36780298) constraint, ensuring that each item is allocated to at most one agent.

### Algorithms using a demand oracle {#Algorithms_using_a_demand_oracle}

Another way to access the agents' utilities is using a **[demand oracle](https://en.wikipedia.org/wiki/Demand_oracle)** (an oracle that, given a price-vector, returns the agent's most desired bundle). In this model:

- Dobzinski and Schapira[^o24] present a polytime (1-1/e)-approximation algorithm.
- [Feige](wikipedia://en/24734804) and [Vondrak](wikipedia://en/71954772)[^o29] improve this to (1-1/e+ε) for some small positive ε (this does not contradict the above hardness result, since the hardness result uses only a value oracle; in the hardness examples, the demand oracle itself would require exponentially many queries).

## Subadditive agents {#Subadditive_agents}

When agents' utilities are [subadditive set functions](wikipedia://en/37998626) (more general than submodular), a $\frac{1}{m^{1/2-\epsilon}}$ approximation would require an exponential number of value queries.[^o19]

Feige[^o31] presents a way of rounding any fractional solution to an LP relaxation to this problem to a feasible solution with welfare at least 1/2 the value of the fractional solution. This gives a 1/2-approximation for general subadditive agents, and (1-1/e)-approximation for the special case of [fractionally-subadditive](https://en.wikipedia.org/wiki/Fractionally-subadditive_valuation) valuations.

## Superadditive agents {#Superadditive_agents}

When agents' utilities are [superadditive set functions](wikipedia://en/47899922) (more general than supermodular), a $\frac{(\log m)^{1+\epsilon}}{m}$ approximation would require a super-polynomial number of value queries.[^o19]

## Single-minded agents {#Single-minded_agents}

A [single-minded agent](https://en.wikipedia.org/wiki/Single-minded_agent) wants only a specific set of items. For every single-minded agent *i*, there is a demanded set *D<sub>i</sub>*, and a value *V<sub>i</sub>* > 0, such that $u_i(Z) = \begin{cases} V_i & Z\supseteq D_i \\ 0 & \text{otherwise} \end{cases}$. That is, the agent receives a fixed positive utility [if and only if](wikipedia://en/14922) their bundle contains their demanded set.

Welfare maximization with single-minded agents is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) even when $V_i=1$ for all *i*. In this case, the problem is equivalent to [set packing](wikipedia://en/2017636), which is known to be NP hard. Moreover, it cannot be approximated within any constant factor (in contrast to the case of submodular agents).[^o34] The best known algorithm approximates it within a factor of $O(\sqrt{m})$.[^o35]

## General agents {#General_agents}

When agents can have arbitrary monotone utility functions (including [complementary items](https://en.wikipedia.org/wiki/Complementary_good)), welfare maximization is hard to approximate within a factor of $O(n^{1/2-\epsilon})$ for any $\epsilon>0$.[^o37] However, there are algorithms based on [state space search](https://en.wikipedia.org/wiki/State_space_search) that work very well in practice.[^o38]
