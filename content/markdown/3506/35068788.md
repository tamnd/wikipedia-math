# Reversed compound agent theorem

::: {#o1 .subject cue=lead name="Reversed compound agent theorem"}

In [probability theory](wikipedia://en/23542), the **reversed compound agent theorem** (**RCAT**) is a set of [sufficient](https://en.wikipedia.org/wiki/Sufficient) conditions for a [stochastic process](wikipedia://en/47895) expressed in any formalism to have a [product form stationary distribution](https://en.wikipedia.org/wiki/Product_form_stationary_distribution)[^o2] (assuming that the process is stationary[^o3][^o2]). The theorem shows that product form solutions in [Jackson's theorem](https://en.wikipedia.org/wiki/Jackson's_theorem_%28queueing_theory%29),[^o2] the [BCMP theorem](https://en.wikipedia.org/wiki/BCMP_theorem)[^o4] and [G-networks](wikipedia://en/10046651) are based on the same fundamental mechanisms.[^o5]

:::

The theorem identifies a reversed process using [Kelly's lemma](wikipedia://en/38477955), from which the stationary distribution can be computed.[^o2]
