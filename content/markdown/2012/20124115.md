# StatXact

::: {#o2 .subject cue=lead name="StatXact"}

**StatXact** is a [statistical software](https://en.wikipedia.org/wiki/Statistical_software) package for analyzing data using [exact statistics](wikipedia://en/19510610). It calculates exact [p-values](wikipedia://en/554994) and [confidence intervals](wikipedia://en/280911) for [contingency tables](wikipedia://en/935515) and [non-parametric procedures](https://en.wikipedia.org/wiki/Non-parametric_statistics). It is marketed by [Cytel](https://en.wikipedia.org/wiki/Cytel) Inc.

:::
