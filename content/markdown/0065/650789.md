# Star (game theory)

::: {#o1 .subject cue=lead name="Star"}

In [combinatorial game theory](wikipedia://en/292231), **star**, written as **$\ast$** or **$\ast1$**, is the value given to the game where both players have only the option of moving to the [zero game](https://en.wikipedia.org/wiki/Zero_game). Star may also be denoted as the [surreal form](https://en.wikipedia.org/wiki/Surreal_form) **$\{0|0\}$**. This game is an unconditional first-player win.

:::

Star, as defined by [John Conway](wikipedia://en/15807) in *[Winning Ways for your Mathematical Plays](https://en.wikipedia.org/wiki/Winning_Ways_for_your_Mathematical_Plays)*, is a value, but not a [number](wikipedia://en/21690) in the traditional sense. Star is not zero, but neither [positive](https://en.wikipedia.org/wiki/Positive_number) nor [negative](wikipedia://en/154616), and is therefore said to be [*fuzzy*](https://en.wikipedia.org/wiki/Fuzzy_game) and *confused with* (a fourth alternative that means neither "less than", "equal to", nor "greater than") 0. It is less than all positive [rational numbers](wikipedia://en/19727024), and greater than all negative rationals.

Games other than {0 | 0} may have value ∗. For example, the game $*2 + *3$, where the values are [nimbers](https://en.wikipedia.org/wiki/Nimbers), has value ∗ despite each player having more options than simply moving to 0.

## Why ∗ ≠ 0 {#Why_&lowast;_≠_0}

A [combinatorial game](https://en.wikipedia.org/wiki/Combinatorial_game) has a positive and negative player; which player moves first is left ambiguous. The combinatorial game [0](https://en.wikipedia.org/wiki/Zero_%28game%29), or **{ | }**, leaves no options and is a second-player win. Likewise, a combinatorial game is won (assuming optimal play) by the second player [if and only if](wikipedia://en/14922) its value is 0. Therefore, a game of value ∗, which is a first-player win, is neither positive nor negative. However, ∗ is not the only possible value for a first-player win game (see [nimbers](wikipedia://en/164501)).

Star does have the property that the [sum](https://en.wikipedia.org/wiki/Sum_of_combinatorial_games) ∗ + ∗, has value 0, because the first-player's only move is to the game ∗, which the second-player will win.

## Example of a value-∗ game {#Example_of_a_value-&lowast;_game}

[Nim](wikipedia://en/21885), with one pile and one piece, has value ∗. The first player will remove the piece, and the second player will lose. A single-pile Nim game with one pile of *n* pieces (also a first-player win) is defined to have value ∗*n*. The numbers ∗*z* for [integers](wikipedia://en/14563) *z* form an infinite [field](wikipedia://en/10603) of [characteristic](wikipedia://en/1066621) 2, when addition is defined in the context of combinatorial games and multiplication is given a more complex definition.
