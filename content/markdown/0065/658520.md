# DSPACE

::: {#o1 .subject cue=lead name="DSPACE"}

In [computational complexity theory](wikipedia://en/7543), **DSPACE** or **SPACE** is the [computational resource](wikipedia://en/4628222) describing the resource of [memory space](https://en.wikipedia.org/wiki/Memory_space_%28computational_resource%29) for a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine). It represents the total amount of memory space that a "normal" physical computer would need to solve a given [computational problem](https://en.wikipedia.org/wiki/Computational_problem) with a given [algorithm](wikipedia://en/775).

:::

## Complexity classes {#Complexity_classes}

The measure **DSPACE** is used to define [complexity classes](wikipedia://en/502426), sets of all of the [decision problems](wikipedia://en/8336) that can be solved using a certain amount of memory space. For each function *f*(*n*), there is a [complexity class](wikipedia://en/502426) SPACE(*f*(*n*)), the set of [decision problems](wikipedia://en/8336) that can be solved by a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) using space *O*(*f*(*n*)). There is no restriction on the amount of [computation time](https://en.wikipedia.org/wiki/Computation_time) that can be used, though there may be restrictions on some other complexity measures (like [alternation](https://en.wikipedia.org/wiki/Alternation_%28complexity%29)).

Several important complexity classes are defined in terms of **DSPACE**. These include:

- [REG](wikipedia://en/25723) = DSPACE(*O*(1)), where **REG** is the class of [regular languages](wikipedia://en/25723). In fact, REG = DSPACE(*o*(log log *n*)) (that is, $\Omega(\log \log n)$ space is required to recognize any non-regular language).[^o3][^o4]

*Proof:* Suppose that there exists a non-regular language *L* ∈ DSPACE(*s*(*n*)), for *s*(*n*) = *o*(log log *n*). Let *M* be a [Turing machine](wikipedia://en/30403) deciding *L* in space *s*(*n*). By our assumption *L* ∉ DSPACE(*O*(1)); thus, for any arbitrary $k \in \mathbb{N}$, there exists an input of *M* requiring more space than *k*.

Let *x* be an input of smallest size, denoted by n, that requires more space than *k*, and $\mathcal{C}$ be the set of all [configurations](wikipedia://en/30403) of *M* on input *x*. Because *M* ∈ DSPACE(*s*(*n*)), then $|\mathcal{C}| \le 2^{c \cdot s(n)} = o(\log n)$, where *c* is a constant depending on *M*.

Let *S* denote the set of all possible [crossing sequences](wikipedia://en/25362523) of *M* on *x*. Note that the length of a crossing sequence of *M* on *x* is at most $|\mathcal{C}|$: if it is longer than that, then some configuration will repeat, and *M* will go into an infinite loop. There are also at most $|\mathcal{C}|$ possibilities for every element of a crossing sequence, so the number of different crossing sequences of *M* on *x* is

$$|S|\le|\mathcal{C}|^{|\mathcal{C}|} \le (2^{c \cdot s(n)})^{2^{c \cdot s(n)}}= 2^{c \cdot s(n) \cdot 2^{c \cdot s(n)}}< 2^{2^{2c \cdot s(n)}}=2^{2^{o(\log \log n)}} = o(n)$$

According to [pigeonhole principle](wikipedia://en/54217), there exist indexes *i* \< *j* such that $\mathcal{C}_i(x)=\mathcal{C}_j(x)$, where $\mathcal{C}_i(x)$ and $\mathcal{C}_j(x)$ are the crossing sequences at boundary *i* and *j*, respectively.

Let $x'$ be the string obtained from $x$ by removing all cells from *i* + 1 to *j*. The machine $M$ still behaves exactly the same way on input $x'$ as on input $x$, so it needs the same space to compute $x'$ as to compute $x$. However, $|x' | < |x|$, contradicting the definition of $x$. Hence, there does not exist such a language $L$ as assumed. □

The above theorem implies the necessity of the [space-constructible function](https://en.wikipedia.org/wiki/Space-constructible_function) assumption in the [space hierarchy theorem](wikipedia://en/663050).

- [L](wikipedia://en/1149999) = DSPACE(*O*(log *n*))
- [PSPACE](wikipedia://en/39351) = $\bigcup_{k\in\mathbb{N}} \mathsf{DSPACE}(n^k)$
- [EXPSPACE](wikipedia://en/54703) = $\bigcup_{k\in\mathbb{N}} \mathsf{DSPACE}(2^{n^k})$

## Machine models {#Machine_models}

**DSPACE** is traditionally measured on a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine). Several important space complexity classes are [sublinear](https://en.wikipedia.org/wiki/Sublinear_convergence), that is, smaller than the size of the input. Thus, "charging" the algorithm for the size of the input, or for the size of the output, would not truly capture the memory space used. This is solved by defining the [multi-tape Turing machine with input and output](https://en.wikipedia.org/wiki/Multi-tape_Turing_machine_with_input_and_output), which is a standard multi-tape Turing machine, except that the input tape may never be written-to, and the output tape may never be read from. This allows smaller space classes, such as [L](wikipedia://en/1149999) (logarithmic space), to be defined in terms of the amount of space used by all of the work tapes (excluding the special input and output tapes).

Since many symbols might be packed into one by taking a suitable power of the alphabet, for all *c* ≥ 1 and *f* such that *f*(*n*) ≥ *1*, the class of languages recognizable in *cf*(*n*) space is the same as the class of languages recognizable in *f*(*n*) space. This justifies usage of [big O notation](wikipedia://en/44578) in the definition.

:::

## Hierarchy theorem {#Hierarchy_theorem}

The [space hierarchy theorem](wikipedia://en/663050) shows that, for every [space-constructible function](https://en.wikipedia.org/wiki/Space-constructible_function) $f: \mathbb{N} \to \mathbb{N}$, there exists some language *L* that is decidable in space $O(f(n))$ but not in space $o(f(n))$.

:::

## Relation with other complexity classes {#Relation_with_other_complexity_classes}

**DSPACE** is the deterministic counterpart of **[NSPACE](wikipedia://en/658518)**, the class of [memory space](https://en.wikipedia.org/wiki/Memory_space_%28computational_resource%29) on a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine). By [Savitch's theorem](wikipedia://en/658501),[^o10] we have that

$$\mathsf{DSPACE}(s(n)) \subseteq \mathsf{NSPACE}(s(n)) \subseteq \mathsf{DSPACE}\bigl((s(n))^2\bigr).$$

**[NTIME](wikipedia://en/658539)** is related to DSPACE in the following way. For any [time constructible](https://en.wikipedia.org/wiki/Time_constructible) function *t*(*n*), we have

$$\mathsf{NTIME}(t(n)) \subseteq \mathsf{DSPACE}(t(n)).$$

A much better simulation is known for [deterministic time](wikipedia://en/658538): if $t(n)\ge n$,

$$\mathsf{DTIME}(t(n))\subseteq\mathsf{DSPACE}\left(\sqrt{t(n)\log t(n)}\right)$$

by a result of [Williams](https://en.wikipedia.org/wiki/Ryan_Williams_%28computer_scientist%29),[^o11] improving an older bound of $O(t/ \log t)$ by [Hopcroft](https://en.wikipedia.org/wiki/John_Hopcroft), Paul, and [Valiant](https://en.wikipedia.org/wiki/Leslie_Valiant).[^o12]

On the other hand, for any function $s(n)\ge\log n$,

$$\mathsf{DSPACE}(s(n))\subseteq\mathsf{DTIME}\bigl(2^{O(s(n))}\bigr).$$
