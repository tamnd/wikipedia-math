# Polynomial hierarchy

::: {#o1 .subject cue=lead name="Polynomial hierarchy"}

In [computational complexity theory](wikipedia://en/7543), the **polynomial hierarchy** (sometimes called the **polynomial-time hierarchy**) is a [hierarchy](wikipedia://en/3612259) of [complexity classes](wikipedia://en/502426) that generalize the classes **[NP](wikipedia://en/21562)** and **[co-NP](wikipedia://en/6184)**.[^o2] Each class in the hierarchy is contained within **[PSPACE](wikipedia://en/39351)**. The hierarchy can be defined using [oracle machines](wikipedia://en/22431) or [alternating Turing machines](https://en.wikipedia.org/wiki/Alternating_Turing_machine). It is a resource-bounded counterpart to the [arithmetical hierarchy](wikipedia://en/186475) and [analytical hierarchy](wikipedia://en/634233) from [mathematical logic](wikipedia://en/19636). The union of the classes in the hierarchy is denoted **PH**.

:::

Classes within the hierarchy have [complete](wikipedia://en/1176530) problems (with respect to [polynomial-time reductions](wikipedia://en/159695)) that ask if [quantified Boolean formulae](https://en.wikipedia.org/wiki/Quantified_Boolean_formula) hold, for formulae with restrictions on the quantifier order. It is known that equality between classes on the same level or consecutive levels in the hierarchy would imply a "collapse" of the hierarchy to that level.

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There are multiple equivalent definitions of the classes of the polynomial hierarchy.

### Oracle definition {#Oracle_definition}

For the oracle definition of the polynomial hierarchy, define

$$\Delta_0^\mathrm{P} := \Sigma_0^\mathrm{P} := \Pi_0^\mathrm{P} := \mathrm{P},$$

where [P](wikipedia://en/658550) is the set of [decision problems](wikipedia://en/8336) solvable in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time). Then for i^n ≥ 0 define

$$\Delta_{i+1}^\mathrm{P} := \mathrm{P}^{\Sigma_i^\mathrm{P}}$$

$$\Sigma_{i+1}^\mathrm{P} := \mathrm{NP}^{\Sigma_i^\mathrm{P}}$$

$$\Pi_{i+1}^\mathrm{P} := \mathrm{coNP}^{\Sigma_i^\mathrm{P}}$$

where $\mathrm{P}^{\rm A}$ is the set of [decision problems](wikipedia://en/8336) solvable in polynomial time by a [Turing machine](wikipedia://en/30403) augmented by an [oracle](wikipedia://en/22431) for some complete problem in class A; the classes $\mathrm{NP}^{\rm A}$ and $\mathrm{coNP}^{\rm A}$ are defined analogously. For example, $\Sigma_1^\mathrm{P} = \mathrm{NP}, \Pi_1^\mathrm{P} = \mathrm{coNP}$, and $\Delta_2^\mathrm{P} = \mathrm{P^{NP}}$ is the class of problems solvable in polynomial time by a deterministic Turing machine with an oracle for some NP-complete problem.[^o6]

### Quantified Boolean formulae definition {#Quantified_Boolean_formulae_definition}

For the existential/universal definition of the polynomial hierarchy, let $L$ be a [language](wikipedia://en/10939) (i.e. a [decision problem](wikipedia://en/8336), a subset of {0,1}<sup>\*</sup>), let $p$ be a [polynomial](wikipedia://en/23000), and define

$$\exists^p L := \left\{ x \in \{0,1\}^* \ \left| \ \left( \exists w \in \{0,1\}^{\leq p(|x|)} \right) \langle x,w \rangle \in L \right. \right\},$$

where $\langle x,w \rangle \in \{0,1\}^*$ is some standard encoding of the pair of binary strings *x* and *w* as a single binary string. The language *L* represents a set of ordered pairs of strings, where the first string *x* is a member of $\exists^p L$, and the second string *w* is a "short" ($|w| \leq p(|x|)$) witness testifying that *x* is a member of $\exists^p L$. In other words, $x \in \exists^p L$ if and only if there exists a short witness *w* such that $\langle x,w \rangle \in L$. Similarly, define

$$\forall^p L := \left\{ x \in \{0,1\}^* \ \left| \ \left( \forall w \in \{0,1\}^{\leq p(|x|)} \right) \langle x,w \rangle \in L \right. \right\}$$

Note that [De Morgan's laws](wikipedia://en/64669) hold: $\left( \exists^p L \right)^{\rm c} = \forall^p L^{\rm c}$ and $\left( \forall^p L \right)^{\rm c} = \exists^p L^{\rm c}$, where *L*<sup>c</sup> is the complement of *L*.

Let C be a class of languages. Extend these operators to work on whole classes of languages by the definition

$$\exists^\mathrm{P} \mathcal{C} := \left\{\exists^p L \ | \ p \text{ is a polynomial and } L \in \mathcal{C} \right\}$$

$$\forall^\mathrm{P} \mathcal{C} := \left\{\forall^p L \ | \ p \text{ is a polynomial and } L \in \mathcal{C} \right\}$$

Again, De Morgan's laws hold: $\mathrm{co} \exists^\mathrm{P} \mathcal{C} = \forall^\mathrm{P} \mathrm{co} \mathcal{C}$ and $\mathrm{co} \forall^\mathrm{P} \mathcal{C} = \exists^\mathrm{P} \mathrm{co} \mathcal{C}$, where $\mathrm{co}\mathcal{C} = \left\{ L^c | L \in \mathcal{C} \right\}$.

The classes **[NP](wikipedia://en/21562)** and **[co-NP](wikipedia://en/6184)** can be defined as $\mathrm{NP} = \exists^\mathrm{P} \mathrm{P}$, and $\mathrm{coNP} = \forall^\mathrm{P} \mathrm{P}$, where **[P](wikipedia://en/658550)** is the class of all feasibly (polynomial-time) decidable languages. The polynomial hierarchy can be defined recursively as

$$\Sigma_0^\mathrm{P} := \Pi_0^\mathrm{P} := \mathrm{P}$$

$$\Sigma_{k+1}^\mathrm{P} := \exists^\mathrm{P} \Pi_k^\mathrm{P}$$

$$\Pi_{k+1}^\mathrm{P} := \forall^\mathrm{P} \Sigma_k^\mathrm{P}$$

Note that $\mathrm{NP} = \Sigma_1^\mathrm{P}$, and $\mathrm{coNP} = \Pi_1^\mathrm{P}$.

This definition reflects the close connection between the polynomial hierarchy and the [arithmetical hierarchy](wikipedia://en/186475), where **[R](https://en.wikipedia.org/wiki/Decidable_language)** and **[RE](wikipedia://en/54789)** play roles analogous to **[P](wikipedia://en/658550)** and **[NP](wikipedia://en/21562)**, respectively. The [analytic hierarchy](https://en.wikipedia.org/wiki/Analytic_hierarchy) is also defined in a similar way to give a hierarchy of subsets of the [real numbers](wikipedia://en/2078245).

### Alternating Turing machines definition {#Alternating_Turing_machines_definition}

An [alternating Turing machine](https://en.wikipedia.org/wiki/Alternating_Turing_machine) is a non-deterministic Turing machine with non-final states partitioned into existential and universal states. It is eventually accepting from its current configuration if: it is in an existential state and can transition into some eventually accepting configuration; or, it is in a universal state and every transition is into some eventually accepting configuration; or, it is in an accepting state.[^o9]

We define $\Sigma_k^\mathrm{P}$ to be the class of languages accepted by an alternating Turing machine in polynomial time such that the initial state is an existential state and every path the machine can take swaps at most *k* – 1 times between existential and universal states. We define $\Pi_k^\mathrm{P}$ similarly, except that the initial state is a universal state.[^o10]

If we omit the requirement of at most *k* – 1 swaps between the existential and universal states, so that we only require that our alternating Turing machine runs in polynomial time, then we have the definition of the class **AP**, which is equal to **[PSPACE](wikipedia://en/39351)**.[^o11]

:::

## Relations between classes in the polynomial hierarchy {#Relations_between_classes_in_the_polynomial_hierarchy}

*Image: Polynomial time hierarchy.svg.* Commutative diagram equivalent to the polynomial time hierarchy. The arrows denote inclusion.

The union of all classes in the polynomial hierarchy is the complexity class **PH**.

The definitions imply the relations:

$$\Sigma_i^\mathrm{P} \subseteq \Delta_{i+1}^\mathrm{P} \subseteq \Sigma_{i+1}^\mathrm{P}$$

$$\Pi_i^\mathrm{P} \subseteq \Delta_{i+1}^\mathrm{P} \subseteq \Pi_{i+1}^\mathrm{P}$$

$$\Sigma_i^\mathrm{P} = \mathrm{co}\Pi_{i}^\mathrm{P}$$

Unlike the arithmetic and analytic hierarchies, whose inclusions are known to be proper, it is an open question whether any of these inclusions are proper, though it is widely believed that they all are. If any $\Sigma_k^\mathrm{P} = \Sigma_{k+1}^\mathrm{P}$, or if any $\Sigma_k^\mathrm{P} = \Pi_{k}^\mathrm{P}$, then the hierarchy *collapses to level k*: for all $i > k$, $\Sigma_i^\mathrm{P} = \Sigma_k^\mathrm{P}$.[^o13] In particular, we have the following implications involving unsolved problems:

- [**P** = **NP**](wikipedia://en/6115) if and only if **P** = **PH**.[^o14]
- If **NP** = **[co-NP](wikipedia://en/6184)** then **NP** = **PH**. (**co-NP** is $\Pi_1^\mathrm{P}$.)

The case in which **NP** = **PH** is also termed as a *collapse* of the **PH** to *the second level*. The case **P** = **NP** corresponds to a collapse of **PH** to **P**.

::: {#o15 .problem cue=unsolved}

$$\mathrm{P} \overset{?}{=} \mathrm{NP}$$

:::

The question of collapse to the first level is generally thought to be extremely difficult. Most researchers do not believe in a collapse, even to the second level.

## Relationships to other classes {#Relationships_to_other_classes}

::: {#o17 .problem cue=unsolved}

$$\mathrm{PH} \overset{?}{=} \mathrm{PSPACE}$$

:::

*Image: Complexity-classes-polynomial.svg.* [Hasse diagram](wikipedia://en/338199) of complexity classes including [P](wikipedia://en/658550), [NP](wikipedia://en/21562), [co-NP](wikipedia://en/6184), [BPP](wikipedia://en/4079), [P/poly](wikipedia://en/2052415), PH, and [PSPACE](wikipedia://en/39351)

The polynomial hierarchy is an analogue (at much lower complexity) of the [exponential hierarchy](wikipedia://en/665091) and [arithmetical hierarchy](wikipedia://en/186475).

It is known that PH is contained within [PSPACE](wikipedia://en/39351), but it is not known whether the two classes are equal. One useful reformulation of this problem is that PH = PSPACE if and only if [second-order logic over finite structures](https://en.wikipedia.org/wiki/SO_%28complexity%29) gains no additional power from the addition of a [transitive closure](wikipedia://en/292239) operator over relations of relations (i.e., over the second-order variables).[^o18]

If the polynomial hierarchy has any [complete problems](https://en.wikipedia.org/wiki/Complete_problem), then it has only finitely many distinct levels. Since there are [PSPACE-complete](wikipedia://en/54685) problems, we know that if PSPACE = PH, then the polynomial hierarchy must collapse, since a PSPACE-complete problem would be a $\Sigma_{k}^\mathrm{P}$-complete problem for some *k*.[^o19]

Each class in the polynomial hierarchy contains $\leq_{\rm m}^\mathrm{P}$-complete problems (problems complete under polynomial-time many-one reductions). Furthermore, each class in the polynomial hierarchy is *closed under $\leq_{\rm m}^\mathrm{P}$-reductions*: meaning that for a class C in the hierarchy and a language $L \in \mathcal{C}$, if $A \leq_{\rm m}^\mathrm{P} L$, then $A \in \mathcal{C}$ as well. These two facts together imply that if $K_i$ is a complete problem for $\Sigma_{i}^\mathrm{P}$, then $\Sigma_{i+1}^\mathrm{P} = \mathrm{NP}^{K_i}$, and $\Pi_{i+1}^\mathrm{P} = \mathrm{coNP}^{K_i}$. For instance, $\Sigma_{2}^\mathrm{P} = \mathrm{NP}^\mathrm{SAT}$. In other words, if a language is defined based on some oracle in C, then we can assume that it is defined based on a complete problem for C. Complete problems therefore act as "representatives" of the class for which they are complete.

- [Sipser–Lautemann theorem](wikipedia://en/2921620): $\mathrm{BPP} \subset \Sigma_2^\mathrm{P} \cap \Pi_2^\mathrm{P}$.
- [Kannan's theorem](wikipedia://en/2855729): $\forall k, \Sigma_2 \not\subset \mathrm{SIZE}(n^k)$. It is an open question whether $\Sigma_2 \not\subset \bigcup_k \mathrm{SIZE}(n^k) = \mathrm{P/poly}$.
- [Toda's theorem](wikipedia://en/18125091): $\mathrm{PH} \subset \mathrm{P}^{\mathrm{\#P}}$.

There is some evidence that [BQP](wikipedia://en/4080), the class of problems solvable in polynomial time by a [quantum computer](https://en.wikipedia.org/wiki/Quantum_computer), is not contained in PH; however, it is also believed that PH is not contained in BQP.[^o20][^o21]
