# NSPACE

::: {#o1 .subject cue=lead name="NSPACE"}

In [computational complexity theory](wikipedia://en/7543), non-deterministic space or **NSPACE** is the [computational resource](wikipedia://en/4628222) describing the [memory space](https://en.wikipedia.org/wiki/Memory_space_%28computational_resource%29) for a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine). It is the non-deterministic counterpart of [DSPACE](wikipedia://en/658520).

:::

## Complexity classes {#Complexity_classes}

The measure NSPACE is used to define the [complexity class](wikipedia://en/502426) whose solutions can be determined by a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine). The [complexity class](wikipedia://en/502426) NSPACE(*f*(*n*)) is the set of [decision problems](wikipedia://en/8336) that can be solved by a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine), *M*, using space *O*(*f*(*n*)), where *n* is the length of the input.[^o3]

Several important complexity classes can be defined in terms of *NSPACE*. These include:

- [REG](wikipedia://en/25723) = DSPACE(*O*(1)) = NSPACE(*O*(1)), where REG is the class of [regular languages](wikipedia://en/25723) (nondeterminism does not add power in constant space).
- [NL](wikipedia://en/1145955) = NSPACE(*O*(log *n*))
- [CSL](wikipedia://en/6212) = NSPACE(*O*(*n*)), where CSL is the class of [context-sensitive languages](wikipedia://en/6212).
- [PSPACE](wikipedia://en/39351) = NPSPACE = $\bigcup_{k\in\mathbb{N}} \mathsf{NSPACE}(n^k)$
- [EXPSPACE](wikipedia://en/54703) = NEXPSPACE = $\bigcup_{k\in\mathbb{N}} \mathsf{NSPACE}(2^{n^k})$

The [Immerman–Szelepcsényi theorem](wikipedia://en/2827371) states that NSPACE(*s*(*n*)) is closed under [complement](wikipedia://en/1929955) for every function $s(n) \ge \log n.$

A further generalization is ASPACE, defined with [alternating Turing machines](https://en.wikipedia.org/wiki/Alternation_%28complexity%29).

## Relation with other complexity classes {#Relation_with_other_complexity_classes}

### DSPACE {#DSPACE}

NSPACE is the non-deterministic counterpart of [DSPACE](wikipedia://en/658520), the class of [memory space](https://en.wikipedia.org/wiki/Memory_space_%28computational_resource%29) on a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine). First by definition, then by [Savitch's theorem](wikipedia://en/658501), we have that:

> $$\mathsf{DSPACE}[s(n)] \subseteq \mathsf{NSPACE}[s(n)] \subseteq \mathsf{DSPACE}[(s(n))^2].$$

### Time {#Time}

NSPACE can also be used to bound the [deterministic](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) time complexity of a problem, by the following theorem:

> If a language *L* is decided in space *S*(*n*) (where *S*(*n*) ≥ log *n*) by a non-deterministic Turing machine, then there exists a constant *C* such that *L* is decided in time *O*(*C*<sup>*S*(*n*)</sup>) by a deterministic one.[^o7]

## Limitations {#Limitations}

The measure of [space complexity](wikipedia://en/338946) in terms of [DSPACE](wikipedia://en/658520) is useful because it represents the total amount of memory that an actual computer would need to solve a given [computational problem](https://en.wikipedia.org/wiki/Computational_problem) with a given [algorithm](wikipedia://en/775). The reason is that DSPACE describes the space complexity used by [deterministic Turing machines](https://en.wikipedia.org/wiki/Deterministic_Turing_machine), which can represent actual computers. On the other hand, NSPACE describes the space complexity of [non-deterministic Turing machines](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine), which are not useful when trying to represent actual computers. For this reason, NSPACE is limited in its usefulness to real-world applications.
