# NTIME

::: {#o1 .subject cue=lead name="NTIME"}

In [computational complexity theory](wikipedia://en/7543), the [complexity class](wikipedia://en/502426) **NTIME(*f*(*n*))** is the set of [decision problems](wikipedia://en/8336) that can be solved by a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine) that runs in time *O*(*f*(*n*)), where *O* is the [big *O* notation](wikipedia://en/44578), *f* is some function, and *n* is the size of the input (for which the problem is to be decided).

:::

## Meaning {#Meaning}

This means that there is a non-deterministic machine that, for a given input of size *n*, will, for all computation paths, run in time *O*(*f*(*n*)) (i.e. within a fixed constant multiple of *f*(*n*), for *n* greater than some value), and will always "reject" the input if the answer to the decision problem is "no" for that input, while if the answer is "yes" the machine will "accept" that input for at least one computation path. Equivalently, there is a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) *M* that runs in time *O*(*f*(*n*)) and is able to check an *O*(*f*(*n*))-length certificate for an input; if the input is a "yes" instance, then at least one certificate is accepted, if the input is a "no" instance, no certificate can make the machine accept.

## Space constraints {#Space_constraints}

The space available to the machine is not limited, although it cannot exceed *O*(*f*(*n*)), because the time available limits how much of the tape is reachable.

## Relation to other complexity classes {#Relation_to_other_complexity_classes}

The well-known complexity class [NP](wikipedia://en/21562) can be defined in terms of NTIME as follows:

$$\mathsf{NP} = \bigcup_{k\in\mathbb{N}} \mathsf{NTIME}(n^k)$$

Similarly, the class [NEXP](https://en.wikipedia.org/wiki/NEXP) is defined in terms of NTIME:

$$\mathsf{NEXP} = \bigcup_{k\in\mathbb{N}} \mathsf{NTIME}(2^{n^k})$$

The non-deterministic [time hierarchy theorem](wikipedia://en/184120) says that nondeterministic machines can solve more problems in asymptotically more time.

NTIME is also related to [DSPACE](wikipedia://en/658520) in the following way. For any [time constructible](https://en.wikipedia.org/wiki/Time_constructible) function *t*(*n*), we have

$$\mathsf{NTIME}(t(n)) \subseteq \mathsf{DSPACE}(t(n)).$$

A generalization of **NTIME** is **ATIME**, defined with [alternating Turing machines](https://en.wikipedia.org/wiki/Alternation_%28complexity%29). It turns out that

$$\mathsf{NTIME}(t(n)) \subseteq \mathsf{ATIME}(t(n)) \subseteq \mathsf{DSPACE}(t(n)).$$
