# Inequality (mathematics)

*Image: Linear Programming Feasible Region.svg.* The [feasible regions](wikipedia://en/9157119) of [linear programming](wikipedia://en/43730) are defined by a set of inequalities.

::: {#o1 .subject cue=lead name="Inequality"}

In [mathematics](wikipedia://en/18831), an **inequality** is a relation which makes a non-equal comparison between two numbers or other mathematical expressions.[^o2] It is used most often to compare two numbers on the [number line](wikipedia://en/287188) by their size. The main types of inequality are **less than** and **greater than** (denoted by \< and >, respectively the [less-than](wikipedia://en/11033535) and [greater-than](wikipedia://en/11033536) signs).

:::

::: {#o4 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

There are several different notations used to represent different kinds of inequalities:

- The notation *a* \< *b* means that *a* is **less than** *b*.
- The notation *a* > *b* means that *a* is **greater than** *b*.

In either case, *a* is not equal to *b*. These relations are known as **strict inequalities**,[^o2] meaning that *a* is strictly less than or strictly greater than *b*. Equality is excluded.

In contrast to strict inequalities, there are two types of inequality relations that are not strict:

- The notation *a* ≤ *b* or *a* ⩽ *b* or *a* ≦ *b* means that *a* is **less than or equal to** *b* (or, equivalently, at most *b*).
- The notation *a* ≥ *b* or *a* ⩾ *b* or *a* ≧ *b* means that *a* is **greater than or equal to** *b* (or, equivalently, at least *b*).

In the 17th and 18th centuries, personal notations or typewriting signs were used to signal inequalities.[^o5] For example, In 1670, [John Wallis](wikipedia://en/239290) used a single horizontal bar *above* rather than below the \< and >. Later in 1734, ≦ and ≧, known as "less than (greater-than) over equal to" or "less than (greater than) or equal to with double horizontal bars", first appeared in [Pierre Bouguer](https://en.wikipedia.org/wiki/Pierre_Bouguer)'s work .[^o6] After that, mathematicians simplified Bouguer's symbol to "less than (greater than) or equal to with one horizontal bar" (≤), or "less than (greater than) or slanted equal to" (⩽).

The relation **not greater than** can also be represented by $a \ngtr b,$ the symbol for "greater than" bisected by a slash, "not". The same is true for **not less than**, $a \nless b.$

The notation *a* ≠ *b* means that *a* is not equal to *b*; this *[inequation](wikipedia://en/89486)* sometimes is considered a form of strict inequality.[^o7] It does not say that one is greater than the other; it does not even require *a* and *b* to be a member of an [ordered set](https://en.wikipedia.org/wiki/Ordered_set).

In engineering sciences, less formal use of the notation is to state that one quantity is "much greater" than another,[^o8] normally by several [orders of magnitude](wikipedia://en/22657).

- The notation *a* ≪ *b* means that *a* is **much less than** *b*.[^o9]
- The notation *a* ≫ *b* means that *a* is **much greater than** *b*.[^o10]

This implies that the lesser value can be neglected with little effect on the accuracy of an [approximation](wikipedia://en/336271) (such as the case of [ultrarelativistic limit](https://en.wikipedia.org/wiki/Ultrarelativistic_limit) in physics).

In all of the cases above, any two symbols mirroring each other are symmetrical; *a* \< *b* and *b* > *a* are equivalent, etc.

:::

### Applying a function to both sides {#Applying_a_function_to_both_sides}

*Image: Log.svg.* The graph of *y* = ln *x*

Any [monotonically](wikipedia://en/48260) increasing [function](wikipedia://en/185427), by its definition,[^o21] may be applied to both sides of an inequality without breaking the inequality relation (provided that both expressions are in the [domain](wikipedia://en/50263) of that function). However, applying a monotonically decreasing function to both sides of an inequality means the inequality relation would be reversed. The rules for the additive inverse, and the multiplicative inverse for positive numbers, are both examples of applying a monotonically decreasing function.

If the inequality is strict (*a* \< *b*, *a* > *b*) *and* the function is strictly monotonic, then the inequality remains strict. If only one of these conditions is strict, then the resultant inequality is non-strict. In fact, the rules for additive and multiplicative inverses are both examples of applying a *strictly* monotonically decreasing function.

## Formal definitions and generalizations {#Formal_definitions_and_generalizations}

A (non-strict) **partial order** is a [binary relation](wikipedia://en/3931) ≤ over a [set](wikipedia://en/26691) *P* which is [reflexive](wikipedia://en/200458), [antisymmetric](wikipedia://en/1176), and [transitive](wikipedia://en/200463).[^o23] That is, for all *a*, *b*, and *c* in *P*, it must satisfy the three following clauses:

- *a* ≤ *a* ([reflexivity](wikipedia://en/200458))
- if *a* ≤ *b* and *b* ≤ *a*, then *a* = *b* ([antisymmetry](wikipedia://en/1176))
- if *a* ≤ *b* and *b* ≤ *c*, then *a* ≤ *c* ([transitivity](wikipedia://en/200463))

A set with a partial order is called a **[partially ordered set](wikipedia://en/23572)**.[^o24] Those are the very basic axioms that every kind of order has to satisfy.

A strict partial order is a relation \< that satisfies

- *a* ≮ *a* ([irreflexivity](wikipedia://en/200458#irreflexive)),
- if *a* \< *b*, then *b* ≮ *a* ([asymmetry](wikipedia://en/1229368)),
- if *a* \< *b* and *b* \< *c*, then *a* \< *c* ([transitivity](wikipedia://en/200463)),

where ≮ means that \< does not hold.

Some types of partial orders are specified by adding further axioms, such as:

- [Total order](wikipedia://en/30330): For every *a* and *b* in *P*, *a* ≤ *b* or *b* ≤ *a* .
- [Dense order](wikipedia://en/6320997): For all *a* and *b* in *P* for which *a* \< *b*, there is a *c* in *P* such that *a* \< *c* \< *b*.
- [Least-upper-bound property](wikipedia://en/22038671): Every non-empty [subset](wikipedia://en/26691) of *P* with an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) has a [*least* upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) (supremum) in *P*.

### Ordered fields {#Ordered_fields}

If (*F*, +, ×) is a [field](wikipedia://en/10603) and ≤ is a [total order](wikipedia://en/30330) on *F*, then (*F*, +, ×, ≤) is called an **[ordered field](wikipedia://en/22430)** if and only if:

- *a* ≤ *b* implies *a* + *c* ≤ *b* + *c*;
- 0 ≤ *a* and 0 ≤ *b* implies 0 ≤ *a* × *b*.

Both $(\mathbb Q, +, \times, \leq)$ and $(\mathbb R, +, \times, \leq)$ are [ordered fields](wikipedia://en/22430), but $\le$ cannot be defined in order to make $(\mathbb C, +, \times, \leq)$ an [ordered field](wikipedia://en/22430),[^o26] because −1 is the square of *i* and would therefore be positive.

Besides being an ordered field, **R** also has the [Least-upper-bound property](wikipedia://en/22038671). In fact, **R** can be defined as the only ordered field with that quality.[^o27]

## Chained notation {#Chained_notation}

The notation ***a* \< *b* \< *c*** stands for "*a* \< *b* and *b* \< *c*", from which, by the transitivity property above, it also follows that *a* \< *c*. By the above laws, one can add or subtract the same number to all three terms, or multiply or divide all three terms by same nonzero number and reverse all inequalities if that number is negative. Hence, for example, *a* \< *b* + *e* \< *c* is equivalent to *a* − *e* \< *b* \< *c* − *e*.

This notation can be generalized to any number of terms: for instance, ***a*<sub>1</sub> ≤ *a*<sub>2</sub> ≤ ... ≤ *a*<sub>*n*</sub>** means that *a*<sub>*i*</sub> ≤ *a*<sub>*i*+1</sub> for *i* = 1, 2, ..., *n* − 1. By transitivity, this condition is equivalent to *a*<sub>*i*</sub> ≤ *a*<sub>*j*</sub> for any 1 ≤ *i* ≤ *j* ≤ *n*.

When solving inequalities using chained notation, it is possible and sometimes necessary to evaluate the terms independently. For instance, to solve the inequality 4*x* \< 2*x* + 1 ≤ 3*x* + 2, it is not possible to isolate *x* in any one part of the inequality through addition or subtraction. Instead, the inequalities must be solved independently, yielding *x* \< $\tfrac{1}{2}$ and *x* ≥ −1 respectively, which can be combined into the final solution −1 ≤ *x* \< $\tfrac{1}{2}$.

Occasionally, chained notation is used with inequalities in different directions, in which case the meaning is the [logical conjunction](wikipedia://en/18152) of the inequalities between adjacent terms. For example, the defining condition of a [zigzag poset](https://en.wikipedia.org/wiki/Zigzag_poset) is written as *a*<sub>1</sub> \< *a*<sub>2</sub> > *a*<sub>3</sub> \< *a*<sub>4</sub> > *a*<sub>5</sub> \< *a*<sub>6</sub> > ... . Mixed chained notation is used more often with compatible relations, like \<, =, ≤. For instance, *a* \< *b* = *c* ≤ *d* means that *a* \< *b*, *b* = *c*, and *c* ≤ *d*. This notation exists in a few [programming languages](wikipedia://en/23015) such as [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29). In contrast, in programming languages that provide an ordering on the type of comparison results, such as [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), even homogeneous chains may have a completely different meaning.[^o29]

## Sharp inequalities {#Sharp_inequalities}

An inequality is said to be *sharp* if it cannot be *relaxed* and still be valid in general. Formally, a [universally quantified](https://en.wikipedia.org/wiki/Universally_quantified) inequality *φ* is called sharp if, for every valid universally quantified inequality *ψ*, if *ψ* [⇒](wikipedia://en/658808) *φ* holds, then *ψ* [⇔](https://en.wikipedia.org/wiki/Equivalence_%28logic%29) *φ* also holds. For instance, the inequality [∀](wikipedia://en/76174)*a* ∈ [**R**](wikipedia://en/20646438). *a*<sup>2</sup> ≥ 0 is sharp, whereas the inequality ∀*a* ∈ **R**. *a*<sup>2</sup> ≥ −1 is not sharp.

:::

## Inequalities between means {#Inequalities_between_means}

There are many inequalities between means. For example, for any positive numbers *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub> we have

$$H\le G\le A\le Q,$$

where they represent the following means of the sequence:

- [Harmonic mean](wikipedia://en/14463) : $H = \frac{n}{\frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_n}}$
- [Geometric mean](wikipedia://en/13046) : $G = \sqrt[n]{a_1 \cdot a_2 \cdots a_n}$
- [Arithmetic mean](wikipedia://en/612) : $A = \frac{a_1 + a_2 + \cdots + a_n}{n}$
- [Quadratic mean](wikipedia://en/66819) : $Q = \sqrt{\frac{a_1^2 + a_2^2 + \cdots + a_n^2}{n}}$

::: {#o34 .statement cue=named-heading name="Cauchy–Schwarz inequality"}

## Cauchy–Schwarz inequality {#Cauchy–Schwarz_inequality}

The Cauchy–Schwarz inequality states that for all vectors *u* and *v* of an [inner product space](wikipedia://en/14856) it is true that

$$|\langle \mathbf{u},\mathbf{v}\rangle| ^2 \leq \langle \mathbf{u},\mathbf{u}\rangle \cdot \langle \mathbf{v},\mathbf{v}\rangle,$$

where $\langle\cdot,\cdot\rangle$ is the [inner product](https://en.wikipedia.org/wiki/Inner_product). Examples of inner products include the real and complex [dot product](wikipedia://en/157093); In [Euclidean space](wikipedia://en/9697) *R*<sup>*n*</sup> with the standard inner product, the Cauchy–Schwarz inequality is

$$\biggl(\sum_{i=1}^n u_i v_i\biggr)^2\leq \biggl(\sum_{i=1}^n u_i^2\biggr) \biggl(\sum_{i=1}^n v_i^2\biggr).$$

:::

## Power inequalities {#Power_inequalities}

A **power inequality** is an inequality containing terms of the form *a*<sup>*b*</sup>, where *a* and *b* are real positive numbers or variable expressions. They often appear in [mathematical olympiads](https://en.wikipedia.org/wiki/Mathematical_olympiads) exercises.

Examples:

- For any real *x*, $$e^x \ge 1+x.$$
- If *x* > 0 and *p* > 0, then $$\frac1p\left(x^p - 1\right) \ge \ln(x) \ge \frac1p\left(1 - \frac{1}{x^p}\right).$$ In the limit of *p* → 0, the upper and lower bounds converge to ln(*x*).
- If *x* > 0, then $$x^x \ge \left( \frac{1}{e}\right)^\frac{1}{e}.$$
- If *x* > 0, then $$x^{x^x} \ge x.$$
- If *x*, *y*, *z* > 0, then $$\left(x+y\right)^z + \left(x+z\right)^y + \left(y+z\right)^x > 2.$$
- For any real distinct numbers *a* and *b*, $$\frac{e^b-e^a}{b-a} > e^\frac{a+b}{2}.$$
- If *x*, *y* > 0 and 0 \< *p* \< 1, then $$x^p+y^p > \left(x+y\right)^p.$$
- If *x*, *y*, *z* > 0, then $$x^x y^y z^z \ge \left(xyz\right)^\frac{x+y+z}{3}.$$
- If *a*, *b* > 0, then[^o37] $$a^a + b^b \ge a^b + b^a.$$
- If *a*, *b* > 0, then[^o38] $$a^{ea} + b^{eb} \ge a^{eb} + b^{ea}.$$
- If *a*, *b*, *c* > 0, then $$a^{2a} + b^{2b} + c^{2c} \ge a^{2b} + b^{2c} + c^{2a}.$$
- If *a*, *b* > 0, then $$a^b + b^a > 1.$$

:::

## Complex numbers and inequalities {#Complex_numbers_and_inequalities}

The set of [complex numbers](wikipedia://en/5826) $\mathbb{C}$ with its operations of [addition](wikipedia://en/61338) and [multiplication](wikipedia://en/20845) is a [field](wikipedia://en/10603), but it is impossible to define any relation $\le$ so that $(\mathbb{C}, +, \times, \leq)$ becomes an [ordered field](wikipedia://en/22430). To make $(\mathbb{C}, +, \times, \leq)$ an [ordered field](wikipedia://en/22430), it would have to satisfy the following two properties:

- if *a* ≤ *b*, then *a* + *c* ≤ *b* + *c*;
- if 0 ≤ *a* and 0 ≤ *b*, then 0 ≤ *ab*.

Because ≤ is a [total order](wikipedia://en/30330), for any number *a*, either 0 ≤ *a* or *a* ≤ 0 (in which case the first property above implies that 0 ≤ −*a*). In either case 0 ≤ *a*<sup>2</sup>; this means that *i*<sup>2</sup> > 0 and 1<sup>2</sup> > 0; so −1 > 0 and 1 > 0, which means (−1 + 1) > 0; contradiction.

However, an operation ≤ can be defined so as to satisfy only the first property (namely, "if *a* ≤ *b*, then *a* + *c* ≤ *b* + *c*"). Sometimes the [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order) definition is used:

- *a* ≤ *b*, if
  - Re(*a*) \< Re(*b*), or
  - Re(*a*) = Re(*b*) and Im(*a*) ≤ Im(*b*)

It can easily be proven that for this definition *a* ≤ *b* implies *a* + *c* ≤ *b* + *c*.

## Systems of inequalities {#Systems_of_inequalities}

Systems of [linear inequalities](https://en.wikipedia.org/wiki/Linear_inequalities) can be simplified by [Fourier–Motzkin elimination](wikipedia://en/9203671).

The [cylindrical algebraic decomposition](wikipedia://en/12218154) is an algorithm that allows testing whether a system of polynomial equations and inequalities has solutions, and, if solutions exist, describing them. The complexity of this algorithm is [doubly exponential](wikipedia://en/8541166) in the number of variables. It is an active research domain to design algorithms that are more efficient in specific cases.
