# Greedy algorithm

::: {#o1 .subject cue=lead name="Greedy algorithm"}

A **greedy algorithm** is an [algorithm](wikipedia://en/775) which, at each step, makes the choice that is locally optimal, and subsequently does not reconsider past choices. Greedy algorithms are often used to solve [combinatorial optimization](wikipedia://en/420555) problems. If an optimization problem only depends on the partial solution of solving it for one subproblem, we can solve this problem by "greedily" considering only the locally optimal subproblem. In this sense, a greedy algorithm is a special case of a [dynamic programming](wikipedia://en/125297) algorithm. [Uriel Feige](wikipedia://en/24734804)[^o2] notes that:

> \[Greedy algorithms\] may be viewed as the ultimate form of dynamic programming, in which only one partial solution is maintained. The problem needs to have much more structure for this approach to work.

In many cases, a greedy algorithm does not produce an exact solution, but can yield solutions that [approximate](wikipedia://en/563105) an exact solution in a reasonable amount of time.[^o3]

:::

An example of a problem which admits an exact greedy solution, the [activity selection problem](wikipedia://en/24598717). Given a collection of tasks which can be done between allotted time intervals, the problem is to determine the maximum number of tasks that can be done. A greedy algorithm in $O(n\log(n))$ which solves this problem sorts the tasks by the end time and then repeatedly chooses the first task that begins after the last task ended.

*Image: SimpleLightningSimulation.webm.* A procedural lightning simulation utilizing a greedy pathfinding algorithm. The path is generated by making locally optimal decisions at each step based on a surrounding noise grid (prioritising darker cells), without planning for a globally optimal route

Many classic algorithms in computer science such as the [Huffman coding algorithm](wikipedia://en/13883), [Prim's algorithm](wikipedia://en/53783), [Kruskal's algorithm](wikipedia://en/53776), and [Dijkstra's algorithm](wikipedia://en/45809) all use greedy properties in their design. Mathematicians frequently use *greedy strategies* in proofs as well. A classic example is what [Raphael Yuster](wikipedia://en/79944748) refers to as the greedy proof[^o4] that every [tournament](wikipedia://en/1427502) contains a [Hamiltonian path](wikipedia://en/244437).

## Characterizations {#Characterizations}

Since there is no formal definition of what a greedy algorithm is,[^o7] a complete characterization of when a problem admits a greedy algorithm as a solution is not known. However, special cases have been identified. [Jack Edmonds](wikipedia://en/3625459) showed that a greedy algorithm can be used to solve a class of linear combinatorial optimization problems with a [matroid structure.](wikipedia://en/244321)[^o8]

Later [Bernhard Korte](wikipedia://en/23541073) and [László Lovász](wikipedia://en/1623938) characterized a broader class of optimization problems by introducing the notion of a [greedoid](wikipedia://en/666526). This allowed, for example, a proof of the optimality of [Prim's algorithm](wikipedia://en/53783).

Algorithms which undo past steps are not greedy. For example, the [Gale-Shapley](wikipedia://en/26978338) algorithm is not a greedy algorithm since although it constructs a solution by choosing the current best pairing, in the process, existing solutions may be modified.

:::

## Correctness {#Correctness}

One technique used to prove the optimality of greedy algorithms is an exchange argument.[^o10] The exchange argument demonstrates that any solution different from the greedy solution is at most as good as the greedy solution. This proof pattern typically follows these steps:

1. Assume there exists an optimal solution different from the greedy solution.
1. Consider the first point where the optimal and greedy solutions differ.
1. Prove that exchanging the optimal choice for the greedy choice at this point cannot worsen the optimal solution.
1. Conclude by induction that the greedy solution is optimal.

## Further examples {#Further_examples}

- In the [fractional knapsack problem](https://en.wikipedia.org/wiki/Continuous_knapsack_problem), one is given a list of items with weights and values. The goal is to choose fractional amounts of each item such that the total value is maximised, and the weight is below a fixed constraint. Unlike the [knapsack problem](wikipedia://en/16974), which is known to be [NP-hard](wikipedia://en/54681), the fractional knapsack problem admits a polynomial time greedy algorithm.
- Instances of the [Frobenius coin problem](wikipedia://en/2302444) admit greedy solutions. However, in some cases the greedy algorithm does not yield an optimal solution.[^o13]
- The [matching pursuit](wikipedia://en/5534001) is an example of a greedy algorithm applied on signal approximation.
- A greedy algorithm finds the optimal solution to [Malfatti's problem](wikipedia://en/1475894) of finding three disjoint circles within a given triangle that maximize the total area of the circles; it is conjectured that the same greedy algorithm is optimal for any number of circles.
- In [decision tree learning](wikipedia://en/577003), greedy algorithms are commonly used, however they are not guaranteed to find the optimal solution.
  - One popular such algorithm is the [ID3 algorithm](https://en.wikipedia.org/wiki/ID3_algorithm) for decision tree construction.
- A greedy algorithm constructs the [Zeckendorf representation](wikipedia://en/1377405) (or Fibonacci coding) of a natural number. Subtracting the largest Fibonacci number less than or equal to the natural number repeatedly gives its Zecekndorf representation. The greedy algorithm is extracted from the existence proof of the Zeckendorf representation. The uniqueness of the Zeckendorf representation guarantees that no other non-consecutive Fibonacci sum can give a different output.
- [Fibonacci](wikipedia://en/17949) described [a greedy algorithm for computing Egyptian fractions](wikipedia://en/7277012).
- Greedy algorithms appear in network [routing](https://en.wikipedia.org/wiki/Routing). Using greedy routing, a message is forwarded to the neighbouring node which is "closest" to the destination. The notion of a node's location (and hence "closeness") may be determined by its physical location, as in [geographic routing](https://en.wikipedia.org/wiki/Geographic_routing) used by [ad hoc networks](https://en.wikipedia.org/wiki/Ad_hoc_network). Location may also be an entirely artificial construct as in [small world routing](https://en.wikipedia.org/wiki/Small_world_routing) and [distributed hash table](https://en.wikipedia.org/wiki/Distributed_hash_table).

:::

## Greedy algorithms on graphs {#Greedy_algorithms_on_graphs}

Graph theory is a rich source of greedy algorithms. Computing scientists frequently use greedy algorithms to compute graph invariants.

- [Dijkstra's algorithm](wikipedia://en/45809) and the related [A\* search algorithm](wikipedia://en/100558) are verifiably optimal greedy algorithms for [graph search](https://en.wikipedia.org/wiki/Graph_search) and [shortest path finding](wikipedia://en/41985).
  - A\* search is conditionally optimal, requiring an "[admissible heuristic](https://en.wikipedia.org/wiki/Admissible_heuristic)" that will not overestimate path costs.
- [Kruskal's algorithm](wikipedia://en/53776) and [Prim's algorithm](wikipedia://en/53783) are greedy algorithms for constructing [minimum spanning trees](wikipedia://en/41795) of a given [connected graph](https://en.wikipedia.org/wiki/Connected_graph). They always find an optimal solution, which may not be unique in general.
- A greedy algorithm constructs a Huffman tree in [Huffman coding](wikipedia://en/13883).
- The [Sequitur](https://en.wikipedia.org/wiki/Sequitur_algorithm) and [Lempel-Ziv-Welch](https://en.wikipedia.org/wiki/Lempel-Ziv-Welch_algorithm) algorithms are [greedy algorithms for grammar induction](https://en.wikipedia.org/wiki/Grammar_induction#Grammatical_inference_by_greedy_algorithms).
- A greedy algorithm finds the maximum independent set in a tree.

Greedy algorithms are also used to find upper bounds for the [chromatic numbers](wikipedia://en/426743)[^o15]. A simple example is the bound $\chi(G) \leq \Delta(G) + 1$ obtained by a greedy algorithm.[^o16] We begin by taking a vertex that has not been colored. Since it has at most $\Delta(G)$ neighbours, at most $\Delta(G)$ colors are used in adjacent vertices, leaving a color free for the vertex under consideration.

## Greedy approximation algorithms {#Greedy_approximation_algorithms}

A solution to the [NP-complete](wikipedia://en/23385892) [travelling salesman problem](wikipedia://en/31248) can be approximated by starting from an empty edge set and then adding the next cheapest edge which is a subgraph of a complete tour. This greedy algorithm has been proven to yield at most $\Theta (\log n)$ times longer than the optimal tour.[^o18]

Another example is that a solution for the [0-1 knapsack problem](wikipedia://en/16974) can be approximated by using the greedy algorithm for the [fractional knapsack problem](https://en.wikipedia.org/wiki/Continuous_knapsack_problem). This greedy algorithm has been proven to yield a solution at least half the value of the optimal solution.[^o19]

Solutions for [submodular maximization](https://en.wikipedia.org/wiki/Submodular_maximization) are approximated using a greedy algorithm which yields a solution at least half the value of the optimal solution.[^o20]

Problems for which greedy algorithms are used to provide approximation algorithms include the [set cover](wikipedia://en/870399#Greedy_algorithm)[, load balancing](https://en.wikipedia.org/wiki/Load_balancing_%28computing%29), [Steiner tree](wikipedia://en/498304) and [independent set](wikipedia://en/524501#Approximation_algorithms)[^o21] problem.
