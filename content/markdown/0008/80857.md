# Meromorphic function

::: {#o1 .subject cue=lead name="Meromorphic function"}

In the mathematical field of [complex analysis](wikipedia://en/5759), a **meromorphic function** on an [open subset](wikipedia://en/39358) $D$ of the [complex plane](wikipedia://en/217628) is a [function](wikipedia://en/185427) that is [holomorphic](wikipedia://en/14110) on all of $D$ except for a set of [isolated points](wikipedia://en/390557), which are [*poles*](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) of the function.[^o2] The term comes from the [Greek](https://en.wikipedia.org/wiki/Greek_language) grc (grc), meaning part.

:::

Every meromorphic function on $D$ can be expressed as the ratio between two [holomorphic functions](wikipedia://en/14110) (with the denominator not constant 0) defined on $D$: any pole must coincide with a zero of the denominator.

*Image: Gamma abs 3D.png.* The [gamma function](wikipedia://en/12316) is meromorphic in the whole complex plane.

## Heuristic description {#Heuristic_description}

Intuitively, a meromorphic function is a ratio of two well-behaved (holomorphic) functions. Such a function will still be well-behaved, except possibly at the points where the denominator of the fraction is zero. If the denominator has a zero at $z$ and the numerator does not, then the value of the function will approach infinity; if both parts have a zero at $z$, then one must compare the [multiplicity](wikipedia://en/19211790#Multiplicity_of_a_root_of_a_polynomial) of these zeros.

From an algebraic point of view, if the function's domain is [connected](https://en.wikipedia.org/wiki/Connected_set), then the set of meromorphic functions is the [field of fractions](wikipedia://en/25271) of the [integral domain](wikipedia://en/15462) of the set of holomorphic functions. This is analogous to the relationship between the [rational numbers](wikipedia://en/19727024) and the [integers](wikipedia://en/14563).

## Terminology {#Terminology}

The terms *[holomorphic](wikipedia://en/14110)* and *meromorphic* were introduced in 1875 by [Charles Briot](wikipedia://en/33375467) and [Jean-Claude Bouquet](https://en.wikipedia.org/wiki/Jean-Claude_Bouquet), two of [Augustin-Louis Cauchy](wikipedia://en/1842)'s students. *Holomorphic* derives from the Greek ὅλος (*hólos*) meaning "whole", and μορφή (*morphḗ*) meaning "form" or "appearance" or "type", while *meromorphic* derives from μέρος (*méros*) meaning "part". A holomorphic function resembles an [entire function](wikipedia://en/10372) ("whole") in a [domain](wikipedia://en/16796643) of the complex plane while a meromorphic function, resembles a rational fraction ("part") of entire functions in a domain of the complex plane.[^o6]

In the 1930s, in [group theory](wikipedia://en/41890), the term *meromorphic function* (or *meromorph*) was used in a different sense: it meant a function from a [group](wikipedia://en/19447) into itself that preserved the group operation.[^o7] This language is obsolete, and the term *[endomorphism](wikipedia://en/9569)* is now used for such a function.

## Properties {#Properties}

Since poles are isolated, there are at most [countably](https://en.wikipedia.org/wiki/Countable) many for a meromorphic function.[^o13] The set of poles can be infinite, as exemplified by the function

$$f(z) = \csc z = \frac{1}{\sin z}.$$

By using [analytic continuation](wikipedia://en/80842) to eliminate [removable singularities](wikipedia://en/81644), meromorphic functions can be added, subtracted, multiplied, and the quotient $f/g$ can be formed unless $g(z) = 0$ on a [connected component](wikipedia://en/6233) of *D*. Thus, if *D* is connected, the meromorphic functions form a [field](wikipedia://en/10603), in fact a [field extension](wikipedia://en/11634) of the [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers).

### Higher dimensions {#Higher_dimensions}

In [several complex variables](https://en.wikipedia.org/wiki/Several_complex_variables), a meromorphic function is defined to be locally a quotient of two holomorphic functions. For example, $f(z_1, z_2) = z_1 / z_2$ is a meromorphic function on the two-dimensional complex affine space. Here it is no longer true that every meromorphic function can be regarded as a holomorphic function with values in the [Riemann sphere](wikipedia://en/30876799): There is a set of "indeterminacy" of [codimension](wikipedia://en/525149) two (in the given example this set consists of the origin $(0, 0)$).

Unlike in dimension one, in higher dimensions there do exist compact [complex manifolds](wikipedia://en/509742) on which there are no non-constant meromorphic functions, for example, most [complex tori](wikipedia://en/3055042).

## Examples {#Examples}

- All [rational functions](wikipedia://en/361210),[^o13] for example $$f(z) = \frac{z^3 - 2z + 10}{z^5 + 3z - 1},$$ are meromorphic on the whole complex plane. Furthermore, they are the only meromorphic functions on the [extended complex plane](wikipedia://en/30876799).
- The functions $$f(z) = \frac{e^z}{z} \quad\text{and}\quad f(z) = \frac{\sin{z}}{(z-1)^2}$$ as well as the [gamma function](wikipedia://en/12316) and the [Riemann zeta function](wikipedia://en/25809) are meromorphic on the whole complex plane.[^o13]
- The function $$f(z) = e^\frac{1}{z}$$ is defined in the whole complex plane except for the origin, 0. However, 0 is not a pole of this function, rather an [essential singularity](wikipedia://en/80862). Thus, this function is not meromorphic in the whole complex plane. However, it is meromorphic (even holomorphic) on $\mathbb{C} \setminus \{0\}$.
- The [complex logarithm](wikipedia://en/4870290) function $$f(z) = \ln(z)$$ is not meromorphic on the whole complex plane, as it cannot be defined on the whole complex plane while only excluding a set of isolated points.[^o13]
- The function $$f(z) = \csc\frac{1}{z} = \frac1{\sin\left(\frac{1}{z}\right)}$$ is not meromorphic in the whole plane, since the point $z = 0$ is an [accumulation point](wikipedia://en/226505) of poles and is thus not an [isolated singularity](wikipedia://en/334325).[^o13]
- The function $$f(z) = \sin \frac 1 z$$ is not meromorphic either, as it has an essential singularity at 0.

:::

## On Riemann surfaces {#On_Riemann_surfaces}

On a [Riemann surface](wikipedia://en/173181), every point admits an open neighborhood which is [biholomorphic](wikipedia://en/6077963) to an open subset of the complex plane. Thereby the notion of a meromorphic function can be defined for every Riemann surface.

When *D* is the entire [Riemann sphere](wikipedia://en/30876799), the field of meromorphic functions is simply the field of rational functions in one variable over the complex field, since one can prove that any meromorphic function on the sphere is rational. (This is a special case of the so-called [GAGA](https://en.wikipedia.org/wiki/GAGA) principle.)

For every [Riemann surface](wikipedia://en/173181), a meromorphic function is the same as a holomorphic function that maps to the Riemann sphere and which is not the constant function equal to ∞. The poles correspond to those complex numbers which are mapped to ∞.

On a non-compact [Riemann surface](wikipedia://en/173181), every meromorphic function can be realized as a quotient of two (globally defined) holomorphic functions. In contrast, on a compact Riemann surface, every holomorphic function is constant, while there always exist non-constant meromorphic functions.
