# Graph of a function

*Image: Polynomial of degree three.svg.* Graph of the function $f(x)=\frac{x^3+3x^2-6x-8}{4}$.

::: {#o1 .subject cue=lead name="Graph of a function"}

In [mathematics](wikipedia://en/18831), the **graph of a function** $f$ is the set of [ordered pairs](wikipedia://en/22362) $(x, y)$, where $f(x) = y.$ In the common case where $x$ and $f(x)$ are [real numbers](wikipedia://en/20646438), these pairs are [Cartesian coordinates](https://en.wikipedia.org/wiki/Cartesian_coordinates) of points in a [plane](https://en.wikipedia.org/wiki/Plane_%28geometry%29) and often form a [curve](wikipedia://en/971691). The graphical representation of the graph of a [function](wikipedia://en/185427) is also known as a *[plot](wikipedia://en/19774918)*.

:::

In the case of [functions of two variables](https://en.wikipedia.org/wiki/Bivariate_function) – that is, functions whose [domain](wikipedia://en/50263) consists of pairs $(x, y)$ –, the graph usually refers to the set of [ordered triples](https://en.wikipedia.org/wiki/Ordered_triple) $(x, y, z)$ where $f(x,y) = z$. This is a subset of [three-dimensional space](wikipedia://en/3054853); for a continuous [real-valued function](wikipedia://en/22284647) of two real variables, its graph forms a [surface](wikipedia://en/4342970), which can be visualized as a *[surface plot](https://en.wikipedia.org/wiki/Surface_plot_%28graphics%29)*.

In [science](https://en.wikipedia.org/wiki/Science), [engineering](https://en.wikipedia.org/wiki/Engineering), [technology](https://en.wikipedia.org/wiki/Technology), [finance](https://en.wikipedia.org/wiki/Finance), and other areas, graphs are tools used for many purposes. In the simplest case one variable is plotted as a function of another, typically using [rectangular axes](https://en.wikipedia.org/wiki/Rectangular_coordinate_system); see *[Plot (graphics)](wikipedia://en/19774918)* for details.

A graph of a function is a special case of a [relation](wikipedia://en/22517558). In the modern [foundations of mathematics](wikipedia://en/169358), and, typically, in [set theory](wikipedia://en/27553), a function is actually equal to its graph.[^o2] However, it is often useful to see functions as [mappings](wikipedia://en/516931),[^o3] which consist not only of the relation between input and output, but also which set is the domain, and which set is the [codomain](wikipedia://en/50264). For example, to say that a function is onto ([surjective](wikipedia://en/27873)) or not the codomain should be taken into account. The graph of a function on its own does not determine the codomain. It is common[^o4] to use both terms *function* and *graph of a function* since even if considered the same object, they indicate viewing it from a different perspective.

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a [function](wikipedia://en/185427) $f : X \to Y$ from a set $X$ (the [domain](wikipedia://en/50263)) to a set $Y$ (the [codomain](wikipedia://en/50264)), the graph of the function is the set[^o7]

$$G(f) = \{(x,f(x)) : x \in X\},$$

which is a subset of the [Cartesian product](wikipedia://en/24104095) $X\times Y$. In the definition of a function in terms of [set theory](wikipedia://en/27553), it is common to identify a function with its graph, although, formally, a function is formed by the triple consisting of its domain, its codomain and its graph.

:::

## Examples {#Examples}

### Functions of one variable {#Functions_of_one_variable}

*Image: X^4 - 4^x.PNG.* Graph of the function $f(x) = x^4 - 4^x$ over the [interval](wikipedia://en/49172) \[−2,+3\]. Also shown are the two real roots and the local minimum that are in the interval.

The graph of the function $f : \{1,2,3\} \to \{a,b,c,d\}$ defined by

$$f(x)= \begin{cases} a, & \text{if }x=1, \\ d, & \text{if }x=2, \\ c, & \text{if }x=3, \end{cases}$$

is the subset of the set $\{1,2,3\} \times \{a,b,c,d\}$

$$G(f) = \{ (1,a), (2,d), (3,c) \}.$$

From the graph, the domain $\{1,2,3\}$ is recovered as the set of first component of each pair in the graph $\{1,2,3\} = \{x :\ \exists y,\text{ such that }(x,y) \in G(f)\}$. Similarly, the [range](wikipedia://en/275991) can be recovered as $\{a,c,d\} = \{y : \exists x,\text{ such that }(x,y)\in G(f)\}$. The codomain $\{a,b,c,d\}$, however, cannot be determined from the graph alone.

The graph of the cubic polynomial on the [real line](https://en.wikipedia.org/wiki/Real_line)

$$f(x) = x^3 - 9x$$

is

$$\{ (x, x^3 - 9x) : x \text{ is a real number} \}.$$

If this set is plotted on a [Cartesian plane](https://en.wikipedia.org/wiki/Cartesian_plane), the result is a curve (see figure).

### Functions of two variables {#Functions_of_two_variables}

*Image: F(x,y)=−((cosx)^2 + (cosy)^2)^2.PNG.* Plot of the graph of $f(x, y) = - \left(\cos\left(x^2\right) + \cos\left(y^2\right)\right)^2$, also showing its [gradient](wikipedia://en/12461) projected on the bottom plane

The graph of the [trigonometric function](https://en.wikipedia.org/wiki/Trigonometric_function)

$$f(x,y) = \sin(x^2)\cos(y^2)$$

is

$$\{ (x, y, \sin(x^2) \cos(y^2)) : x \text{ and } y \text{ are real numbers} \}.$$

If this set is plotted on a [three dimensional Cartesian coordinate system](wikipedia://en/7706#Cartesian_coordinates_in_three_dimensions), the result is a surface (see figure).

Oftentimes it is helpful to show with the graph, the [gradient](wikipedia://en/12461) of the function and several level curves. The level curves can be mapped on the function surface or can be projected on the bottom plane. The second figure shows such a drawing of the graph of the function:

$$f(x, y) = -(\cos(x^2) + \cos(y^2))^2.$$
