# Unit doublet

::: {#o1 .subject cue=lead name="Unit doublet"}

*Image: UnitDoubletApproximationHighQuality.gif.* Approximation of a unit doublet with two rectangles of width k as k goes to zero.

In mathematics, the **unit doublet** is a [generalized function](wikipedia://en/1580246), the derivative of the [Dirac delta function](wikipedia://en/37021). It can be used to differentiate [signals](https://en.wikipedia.org/wiki/Signal_%28electronics%29) in [electrical engineering](https://en.wikipedia.org/wiki/Electrical_engineering): If *u*<sub>1</sub> is the unit doublet, then

:::

$$(x * u_1)(t) = \frac{dx(t)}{dt}$$

where $*$ is the [convolution](wikipedia://en/7519) operator.[^o2]

The function is zero for all values except zero, where its behaviour is interesting. Its integral over any interval enclosing zero is zero. However, the integral of its absolute value over any region enclosing zero goes to infinity. The function can be thought of as the [limiting case](wikipedia://en/40400729) of two rectangles, one in the second [quadrant](wikipedia://en/7706#Quadrants_and_octants), and the other in the fourth. The width of each rectangle is *k*, whereas the height of each is 1/*k*<sup>2</sup>, in the limit as *k* approaches zero.
