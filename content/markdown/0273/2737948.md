# Hessian form of an elliptic curve

::: {#o1 .subject cue=lead name="Hessian form of an elliptic curve"}

In [geometry](wikipedia://en/18973446), a **Hessian curve** is a [cubic plane curve](https://en.wikipedia.org/wiki/Cubic_plane_curve) similar to the [folium of Descartes](wikipedia://en/2737940) that belongs to the [Hesse pencil](wikipedia://en/35283082). It is named after the German mathematician [Otto Hesse](wikipedia://en/740995). In [projective coordinates](https://en.wikipedia.org/wiki/Projective_coordinates), the projective equation of a Hessian curve is

$$X^3+Y^3+Z^3-kXYZ =0.$$

:::

For every nonsingular cubic plane curve there is a change of projective coordinates that transforms the equation of the curve into the above **Hessian form**.

Theses curves are used in [elliptic curve cryptography](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography), because arithmetic in this curve representation is faster and needs less memory than arithmetic in standard [Weierstrass form](https://en.wikipedia.org/wiki/Elliptic_curves).[^o2]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Hessian curve.svg.* A Hessian curve of equation $x^3+y^3+1=0.3xy$

Let $K$ be a [field](wikipedia://en/10603) and consider an [elliptic curve](wikipedia://en/10225) $E$ in the following special case of [Weierstrass form](https://en.wikipedia.org/wiki/Weierstrass_form) over $K$:

$$Y^2+a_1 XY+a_3 Y=X^3$$

where the curve has [discriminant](wikipedia://en/55607) $\Delta = \left(a_3^3 \left(a_1^3 - 27a_3\right)\right) = a_3^3 \delta.$ Then the point $P=(0,0)$ has order 3.

To prove that $P=(0,0)$ has order 3, note that the tangent to $E$ at $P$ is the line $Y=0$ which intersects $E$ with multiplicity 3 at $P$.

Conversely, given a point $P$ of order 3 on an elliptic curve $E$ both defined over a field $K$ one can put the curve into Weierstrass form with $P=(0,0)$ so that the tangent at $P$ is the line $Y = 0$. Then the equation of the curve is $Y^2+a_1 XY+a_3 Y=X^3$ with $a_1,a_3\in K$.

To obtain the Hessian curve, it is necessary to do the following [transformation](wikipedia://en/516931):

First let $\mu$ denote a [root](wikipedia://en/537048) of the polynomial

$$T^3-\delta T^2+{\delta^2\over3}T+ a_3\delta^2=0.$$

Then

$$\mu={\delta-a_1\delta^{2/3}\over 3}.$$

Note that if $K$ has a finite field of order $q \equiv 2 \pmod{3}$, then every element of $K$ has a unique [cube root](wikipedia://en/292506); in general, $\mu$ lies in an [extension field](wikipedia://en/11634) of *K*.

Now by defining the following value $D=\frac{(\mu-\delta)}{\mu}$ another curve, C, is obtained, that is [birationally equivalent](wikipedia://en/382733) to E:

$$C : x^3 + y^3 + z^3= 3Dxyz$$

which is called *cubic Hessian form* (in [projective coordinates](wikipedia://en/242135))

$$C : x^3 + y^3 + 1= 3Dxy$$

in the *affine plane* (satisfying $x=\frac{X}{Z}$ and $y=\frac{Y}{Z}$).

Furthermore, $D^3\ne1$ (otherwise, the curve would be [singular](wikipedia://en/981915)).

Starting from the Hessian curve, a [birationally equivalent](https://en.wikipedia.org/wiki/Birationally_equivalent) [Weierstrass equation](https://en.wikipedia.org/wiki/Weierstrass_equation) is given by

$$v^2 = u^3 - 27D\left(D^3 + 8\right)u + 54\left(D^6 - 20 D^3 - 8\right),$$

under the transformations:

$$(x,y) = \left(\eta \left(u + 9D^2\right), - 1 + \eta\left(3D^3 - Dx -12\right)\right)$$

and

$$(u,v) = \left(-9D^2 + \varepsilon x, 3\varepsilon\left(y - 1\right)\right)$$

where:

$$\eta = \frac{6\left(D^3 - 1\right)\left(v + 9D^3 - 3Du - 36\right)}{\left(u + 9D^2\right)^3 + \left(3D^3 - Du - 12\right)^3}$$

and

$$\varepsilon = \frac{12\left(D^3 - 1\right)}{Dx + y + 1}$$

:::

## Group law {#Group_law}

It is interesting to analyze the [group law](wikipedia://en/10225#The_group_law) of the elliptic curve, defining the addition and doubling formulas (because the [SPA](wikipedia://en/754362#Simple_power_analysis) and [DPA](wikipedia://en/754362#Differential_power_analysis) attacks are based on the running time of these operations). Furthermore, in this case, we only need to use the same procedure to compute the addition, doubling or [subtraction](wikipedia://en/74141) of points to get efficient results, as said above. In general, the group law is defined in the following way: *if three points lie in the same line then they sum up to zero*. So, by this property, the group laws are different for every curve.

In this case, the correct way is to use the Cauchy-Desboves´ formulas, obtaining the point at infinity $\theta = (1 : -1 : 0)$, that is, the [neutral element](wikipedia://en/14962) (the inverse of $\theta$ is $\theta$ again). Let $P = (x_{1}, y_{1})$ be a point on the curve. The line $y = -x + (x_1+y_1)$ contains the point $P$ and the point at infinity $\theta$. Therefore, $-P$ is the third point of the intersection of this line with the curve. Intersecting the elliptic curve with the line, the following condition is obtained $x_2-(x_1+y_1)\cdot x + x_1\cdot y_1=\theta$

Since $x_1+y_1+D$ is non zero (because $D^{3}$ is distinct to 1), the $x$-coordinate of $-P$ is $y_{1}$ and the $y$-coordinate of $-P$ is $x_{1}$ , i.e., $-P = (y_1,x_1)$ or in projective coordinates $-P = (Y_1:X_1:Z_1)$.

In some application of [elliptic curve cryptography](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography) and the elliptic curve method of factorization ([ECM](https://en.wikipedia.org/wiki/Lenstra_elliptic_curve_factorization)) it is necessary to compute the scalar multiplications of $P$, say $[n]P$ for some [integer](wikipedia://en/14563) $n$, and they are based on the [double-and-add method](wikipedia://en/10237); these operations need the addition and doubling formulas.

**Doubling**

Now, if $P = (X_1:Y_1:Z_1)$ is a point on the elliptic curve, it is possible to define a "doubling" operation using Cauchy-Desboves´ formulae:

$$[2]P=\left(Y_1 \cdot \left(X_1^3-Z_1^3\right) : X_1 \cdot \left(Z_1^3-Y_1^3\right) : Z_1 \cdot \left(Y_1^3-X_1^3\right)\right)$$

**Addition**

In the same way, for two different points, say $P=(X_1 : Y_1 : Z_1)$ and $Q=(X_2 : Y_2 : Z_2)$, it is possible to define the addition formula. Let $R$ denote the sum of these points, $R = P + Q$, then its coordinates are given by:

$$R=\left(Y_1^2\cdot X_2\cdot Z_2-Y_2^2\cdot X_1\cdot Z_1 : X_1^2\cdot Y_2\cdot Z_2-X_2^2\cdot Y_1\cdot Z_1 : Z_1^2\cdot X_2\cdot Y_2-Z_2^2\cdot X_1\cdot Y_1\right)$$

:::

## Algorithms and examples {#Algorithms_and_examples}

There is one [algorithm](https://en.wikipedia.org/wiki/Algorithms) that can be used to add two different points or to double; it is given by [Joye](https://en.wikipedia.org/wiki/Marc_Joye) and [Quisquater](https://en.wikipedia.org/wiki/Jean-Jacques_Quisquater). Then, the following result gives the possibility the obtain the doubling operation by the addition:

::: {#o8 .statement kind=statement/proposition cue=inline-head name="Proposition"}

**Proposition**. Let $P = (X,Y,Z)$ be a point on a Hessian elliptic curve $E(K)$. Then:

::: {#o9 .equation cue=numblk name="2"}

$$2(X:Y:Z) = (Z:X:Y) + (Y:Z:X) \tag{2}$$

:::

Furthermore, we have $(Z:X:Y) \ne (Y:Z:X)$.

Finally, contrary to other [parameterizations](wikipedia://en/453198), there is no subtraction to compute the negation of a point. Hence, this addition algorithm can also be used for subtracting two points $P = (X_{1}:Y_{1}:Z_{1})$ and $Q = (X_{2}:Y_{2}:Z_{2})$ on a Hessian elliptic curve:

::: {#o10 .equation cue=numblk name="3"}

$$( X_1:Y_1:Z_1) - ( X_2:Y_2:Z_2) = ( X_1:Y_1:Z_1) + ( Y_2:X_2:Z_2) \tag{3}$$

:::

To sum up, by adapting the order of the inputs according to equation (2) or (3), the addition algorithm presented above can be used indifferently for: Adding 2 (diff.) points, Doubling a point and Subtracting 2 points with only 12 multiplications and 7 auxiliary variables including the 3 result variables. Before the invention of [Edwards curves](https://en.wikipedia.org/wiki/Edwards_curves), these results represent the fastest known method for implementing the elliptic curve [scalar multiplication](wikipedia://en/244373) towards resistance against [side-channel attacks](wikipedia://en/667678).

For some [algorithms](https://en.wikipedia.org/wiki/Algorithms) protection against side-channel attacks is not necessary. So, for these doublings can be faster. Since there are many algorithms, only the best for the addition and doubling formulas is given here, with one example for each one:

:::

### Addition {#Addition}

Let $P_{1} = (X_{1}:Y_{1}:Z_{1})$ and $P_{2} = (X_{2}:Y_{2}:Z_{2})$ be two points distinct to $\theta$. Assuming that $Z_{1} = Z_{2} = 1$ then the algorithm is given by:

$$A = X_{1} Y_{2}$$

$$B = Y_{1} X_{2}$$

$$X_{3} = B Y_{1}-Y_{2} A$$

$$Y_{3} = X_{1} A-B X_{2}$$

$$Z_{3} = Y_{2} X_{2}-X_{1} Y_{1}$$

The cost needed is 8 multiplications and 3 additions readdition cost of 7 multiplications and 3 additions, depending on the first point.

::: {#o12 .example cue=inline-head name="Example"}

**Example**

Given the following points in the curve for $d = -1 P_{1} = (1:0:-1)$ and $P_{2} = (0:-1:1)$, then if $P_{3} = P_{1} + P_{2}$ we have:

$$X_{3} = 0 - 1 = -1$$

$$Y_{3} = -1-0 = -1$$

$$Z_{3} = 0 - 0 = 0$$

Then: $P_{3} = (-1:-1:0)$

:::

### Doubling {#Doubling}

Let $P = (X_{1} : Y_{1} : Z_{1})$ be a point, then the doubling formula is given by:

- $$A = X_{1}^{2}$$
- $$B = Y_{1}^{2}$$
- $$D = A + B$$
- $$G = (X_{1} + Y_{1})^{2} - D$$
- $$X_{3} = (2Y_{1} - G) \times (X_{1} + A + 1)$$
- $$Y_{3} = (G - 2X_{1}) \times (Y_{1} + B + 1)$$
- $$Z_{3} = (X_{1} - Y_{1}) \times (G + 2D)$$

The cost of this algorithm is three multiplications + three squarings + 11 additions + 3×2.

::: {#o14 .example cue=inline-head name="Example"}

**Example**

If $P=(-1:-1:1)$ is a point over the Hessian curve with parameter $d = -1$, then the coordinates of $2P=(X:Y:Z)$ are given by:

$$X = (2 . (-1) - 2) (-1 + 1 + 1) = -4$$

$$Y = (-4 - 2 . (-1)) ((-1) + 1 + 1) = -2$$

$$Z = (-1 - (-1)) ((-4) + 2 . 2) = 0$$

That is, $2P=(-4:-2:0)$

:::

## Extended coordinates {#Extended_coordinates}

There is another coordinates system with which a Hessian curve can be represented; these new coordinates are called **extended coordinates**. They can speed up the addition and doubling. To have more information about operations with the extended coordinates see:

http://hyperelliptic.org/EFD/g1p/auto-hessian-extended.html#addition-add-20080225-hwcd

$x$ and $y$ are represented by $X , Y , Z , XX , YY , ZZ , XY , YZ , XZ$ satisfying the following equations:

- $$x=X/Z$$
- $$y=Y/Z$$
- $$XX=X\cdot X$$
- $$YY=Y\cdot Y$$
- $$ZZ=Z\cdot Z$$
- $$XY=2\cdot X\cdot Y$$
- $$YZ=2\cdot Y\cdot Z$$
- $$XZ=2\cdot X\cdot Z$$
