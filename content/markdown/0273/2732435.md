# Davis–Putnam algorithm

::: {#o1 .subject cue=lead name="Davis–Putnam algorithm"}

In [logic](wikipedia://en/46426065) and [computer science](https://en.wikipedia.org/wiki/Computer_science), the **Davis–Putnam algorithm** was developed by [Martin Davis](wikipedia://en/953041) and [Hilary Putnam](wikipedia://en/75233) for checking the validity of a [first-order logic](wikipedia://en/10983) formula using a [resolution](wikipedia://en/2724082)-based decision procedure for [propositional logic](wikipedia://en/18154). Since the set of valid first-order formulas is [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable) but not [recursive](https://en.wikipedia.org/wiki/Recursive_set), there exists no general algorithm to solve this problem. Therefore, the Davis–Putnam algorithm only terminates on valid formulas. Today, the term "Davis–Putnam algorithm" is often used synonymously with the resolution-based propositional decision procedure (**Davis–Putnam procedure**) that is actually only one of the steps of the original algorithm.

:::

## Overview {#Overview}

*Image: Resolution.png.* Two runs of the Davis-Putnam procedure on example propositional ground instances. *Top to bottom, Left:* Starting from the formula $(a \lor b \lor c) \land (b \lor \lnot c \lor \lnot f) \land (\lnot b \lor e)$, the algorithm resolves on $b$, and then on $c$. Since no further resolution is possible, the algorithm stops; since the [empty clause](https://en.wikipedia.org/wiki/Empty_clause) couldn't be derived, the result is "*satisfiable*". *Right:* Resolving the given formula on $b$, then on $a$, then on $c$ yields the empty clause; hence the algorithm returns "*unsatisfiable*".

The procedure is based on [Herbrand's theorem](wikipedia://en/2518328), which implies that an [unsatisfiable](https://en.wikipedia.org/wiki/Satisfiable) formula has an unsatisfiable [ground instance](https://en.wikipedia.org/wiki/Ground_instance), and on the fact that a formula is valid if and only if its negation is unsatisfiable. Taken together, these facts imply that to prove the validity of *φ* it is enough to prove that a ground instance of *¬φ* is unsatisfiable. If *φ* is not valid, then the search for an unsatisfiable ground instance will not terminate.

The procedure for checking validity of a formula *φ* roughly consists of these three parts:

- put the formula *¬φ* in [prenex](https://en.wikipedia.org/wiki/Prenex) form and eliminate quantifiers
- generate all propositional ground instances, one by one
- check if each instance is satisfiable.
  - If some instance is unsatisfiable, then return that *φ* is valid. Else continue checking.

The last part is a [SAT solver](https://en.wikipedia.org/wiki/SAT_solver) based on [resolution](wikipedia://en/2724082) (as seen on the illustration), with an eager use of [unit propagation](wikipedia://en/2730761) and pure literal elimination (elimination of clauses with variables that occur only positively or only negatively in the formula).

Input: A set of clauses Φ. Output: A Truth Value: true if Φ can be satisfied, false otherwise.

**function** DP-SAT(Φ) **repeat** // *unit propagation:* **while** Φ contains a unit clause {*l*} **do** **for every** clause *c* in Φ that contains *l* **do** Φ ← *remove-from-formula*(*c*, Φ); **for every** clause *c* in Φ that contains ¬*l* **do** Φ ← *remove-from-formula*(*c*, Φ); Φ ← *add-to-formula*(*c* \\ {¬*l*}, Φ); // *eliminate clauses not in normal form:* **for every** clause *c* in Φ that contains both a literal *l* and its negation ¬*l* **do** Φ ← *remove-from-formula*(*c*, Φ); // *pure literal elimination:* **while** there is a literal *l* all of which occurrences in Φ have the same polarity **do** **for every** clause *c* in Φ that contains *l* **do** Φ ← *remove-from-formula*(*c*, Φ); // *stopping conditions:* **if** Φ is empty **then** **return** true; **if** Φ contains an empty clause **then** **return** false; // *Davis-Putnam procedure:* pick a literal *l* that occurs with both polarities in Φ **for every** clause *c* in Φ containing *l* and every clause *n* in Φ containing its negation ¬*l* **do** // *resolve c with n:* *r* ← (*c* \\ {*l*}) ∪ (*n* \\ {¬*l*}); Φ ← *add-to-formula*(*r*, Φ); **for every** clause *c* that contains *l* or ¬*l* **do** Φ ← *remove-from-formula*(*c*, Φ);

At each step of the SAT solver, the intermediate formula generated is [equisatisfiable](https://en.wikipedia.org/wiki/Equisatisfiable), but possibly not [equivalent](wikipedia://en/169324), to the original formula. The resolution step leads to a worst-case exponential blow-up in the size of the formula.

The [Davis–Putnam–Logemann–Loveland algorithm](https://en.wikipedia.org/wiki/Davis–Putnam–Logemann–Loveland_algorithm) is a 1962 refinement of the propositional satisfiability step of the Davis–Putnam procedure which requires only a linear amount of memory in the worst case. It eschews the resolution for *the splitting rule*: a backtracking algorithm that chooses a literal *l*, and then recursively checks if a simplified formula with *l* assigned a true value is satisfiable or if a simplified formula with *l* assigned false is. It still forms the basis for today's (as of 2015) most efficient complete [SAT solvers](https://en.wikipedia.org/wiki/SAT_solver).
