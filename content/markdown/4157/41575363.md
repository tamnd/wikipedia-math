# Spherical contact distribution function

::: {#o1 .subject cue=lead name="Spherical contact distribution function"}

In probability and statistics, a **spherical contact distribution function**, **first contact distribution function**,[^o2] or **empty space function**[^o3] is a [mathematical function](https://en.wikipedia.org/wiki/Mathematical_function) that is defined in relation to [mathematical objects](https://en.wikipedia.org/wiki/Mathematical_objects) known as [point processes](wikipedia://en/2147685), which are types of [stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes) often used as [mathematical models](wikipedia://en/20590) of physical phenomena representable as [randomly](https://en.wikipedia.org/wiki/Random) positioned [points](wikipedia://en/593693) in time, [space](wikipedia://en/27667) or both.[^o2][^o4] More specifically, a spherical contact distribution function is defined as [probability distribution](wikipedia://en/23543) of the radius of a sphere when it first encounters or makes contact with a point in a point process. This function can be contrasted with the [nearest neighbour function](https://en.wikipedia.org/wiki/Nearest_neighbour_function), which is defined in relation to some point in the point process as being the probability distribution of the distance from that point to its nearest neighbouring point in the same point process.

:::

The spherical contact function is also referred to as the **contact distribution function**,[^o3] but some authors[^o2] define the contact distribution function in relation to a more general set, and not simply a sphere as in the case of the spherical contact distribution function.

Spherical contact distribution functions are used in the study of point processes[^o3][^o4][^o5] as well as the related fields of [stochastic geometry](wikipedia://en/22037813)[^o2] and [spatial statistics](wikipedia://en/9467349),[^o3][^o6] which are applied in various [scientific](https://en.wikipedia.org/wiki/Scientific) and [engineering](https://en.wikipedia.org/wiki/Engineering) disciplines such as [biology](https://en.wikipedia.org/wiki/Biology), [geology](https://en.wikipedia.org/wiki/Geology), [physics](wikipedia://en/22939), and [telecommunications](https://en.wikipedia.org/wiki/Telecommunications).[^o2][^o4][^o7][^o8]

## Point process notation {#Point_process_notation}

Point processes are mathematical objects that are defined on some underlying [mathematical space](https://en.wikipedia.org/wiki/Mathematical_space). Since these processes are often used to represent collections of points randomly scattered in space, time or both, the underlying space is usually *d*-dimensional [Euclidean space](wikipedia://en/9697) denoted here by $\textstyle \textbf{R}^{ d}$, but they can be defined on more [abstract](wikipedia://en/454446) mathematical spaces.[^o5]

Point processes have a number of interpretations, which is reflected by the various types of [point process notation](wikipedia://en/40765261).[^o2][^o8] For example, if a point $\textstyle x$ belongs to or is a member of a point process, denoted by $\textstyle {N}$, then this can be written as:[^o2]

$$\textstyle x\in {N},$$

and represents the point process being interpreted as a random [set](wikipedia://en/26691). Alternatively, the number of points of $\textstyle {N}$ located in some [Borel set](wikipedia://en/43327) $\textstyle B$ is often written as:[^o2][^o6][^o7]

$$\textstyle {N}(B),$$

which reflects a [random measure](wikipedia://en/10040846) interpretation for point processes. These two notations are often used in parallel or interchangeably.[^o2][^o6][^o7]

## Definitions {#Definitions}

### Spherical contact distribution function {#Spherical_contact_distribution_function}

The **spherical contact distribution function** is defined as:

$$H_s(r)=1-P({N}(b(o,r))=0).$$

where *b(o,r)* is a [ball](wikipedia://en/160556) with radius *r* centered at the origin *o*. In other words, spherical contact distribution function is the probability there are no points from the point process located in a hyper-sphere of radius *r*.

### Contact distribution function {#Contact_distribution_function}

The spherical contact distribution function can be generalized for sets other than the (hyper-)sphere in $\textstyle \textbf{R}^{ d}$. For some Borel set $\textstyle B$ with positive volume (or more specifically, [Lebesgue measure](wikipedia://en/18198)), the *contact distribution function* (*with respect to* $\textstyle B$) for $\textstyle r\geq0$ is defined by the equation:[^o2]

$$H_B(r)=P({N}(rB)=0).$$

:::

::: {#o15 .example cue=heading name="Examples"}

## Examples {#Examples}

### Poisson point process {#Poisson_point_process}

For a [Poisson point process](wikipedia://en/41597450) $\textstyle {N}$ on $\textstyle \textbf{R}^d$ with intensity measure $\textstyle \Lambda$ this becomes

$$H_s(r)=1-e^{-\Lambda(b(o,r))},$$

which for the homogeneous case becomes

$$H_s(r)=1-e^{-\lambda |b(o,r)|},$$

where $\textstyle |b(o,r)|$ denotes the volume (or more specifically, the Lebesgue measure) of the ball of radius $\textstyle r$. In the plane $\textstyle \textbf{R}^2$, this expression simplifies to

$$H_s(r)=1-e^{-\lambda \pi r^2}.$$

:::

## Relationship to other functions {#Relationship_to_other_functions}

### Nearest neighbour function {#Nearest_neighbour_function}

In general, the spherical contact distribution function and the corresponding [nearest neighbour function](https://en.wikipedia.org/wiki/Nearest_neighbour_function) are not equal. However, these two functions are identical for Poisson point processes.[^o2] In fact, this characteristic is due to a unique property of Poisson processes and their [Palm distributions](https://en.wikipedia.org/wiki/Palm_distribution), which forms part of the result known as the *Slivnyak-Mecke*[^o7] or *Slivnyak's theorem*.[^o3]

### $J$-function {#-function}

The fact that the spherical distribution function $H_{s}(r)$ and nearest neighbour function $D_{o}(r)$ are identical for the Poisson point process can be used to statistically test if point process data appears to be that of a Poisson point process. For example, in spatial statistics the $J$-function is defined for all $r$ ≥ 0 as:[^o2]

$$J(r)=\frac{1-D_o(r)}{1-H_s(r)}$$

For a Poisson point process, the $J$ function is simply $J(r)$=1, hence why it is used as a [non-parametric](https://en.wikipedia.org/wiki/Non-parametric_statistics) test for whether data behaves as though it were from a Poisson process. It is, however, thought possible to construct non-Poisson point processes for which $J(r)$=1,[^o20] but such counterexamples are viewed as somewhat 'artificial' by some and exist for other statistical tests.[^o21]

More generally, $J$-function serves as one way (others include using [factorial moment measures](wikipedia://en/40990955)[^o3]) to measure the interaction between points in a point process.[^o2]
