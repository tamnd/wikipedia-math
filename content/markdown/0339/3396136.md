# 2-bridge knot

*Image: 2-bridge-knot.jpg.* Schematic picture of a 2-bridge knot.

::: {#o1 .subject cue=lead name="2-bridge knot"}

In the mathematical field of knot theory, a **2-bridge knot** is a [knot](wikipedia://en/366808) which can be [regular isotoped](wikipedia://en/7404505) so that the natural height function given by the *z*-coordinate has only two maxima and two minima as critical points. Equivalently, these are the knots with [bridge number](wikipedia://en/10041975) 2, the smallest possible bridge number for a nontrivial knot. Every nontrivial knot with up to seven crossings is a 2-bridge knot. The simplest knots with a bridge number of 3 have eight crossings. Of the 1,701,936 knots with up to sixteen crossings, 5,546 are 2-bridge knots.[^o2]

:::

Other names for 2-bridge knots are **rational knots**, **4-plats**, and de. 2-bridge links are defined similarly as above, but each component will have one min and max. 2-bridge knots were classified by [Horst Schubert](wikipedia://en/38487829), using the fact that the 2-sheeted branched cover of the 3-sphere over the knot is a lens space.

## Schubert normal form {#Schubert_normal_form}

The names **rational knot** and **rational link** were coined by [John Conway](wikipedia://en/15807) who defined them as arising from numerator closures of rational tangles. This definition can be used to give a bijection between the set of 2-bridge links and the set of rational numbers; the rational number associated to a given link is called the **Schubert normal form** of the link (as this invariant was first defined by Schubert[^o4]), and is precisely the fraction associated to the [rational tangle](wikipedia://en/30858815#Rational_and_algebraic_tangles) whose numerator closure gives the link.[^o5]
