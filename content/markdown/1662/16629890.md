# S-finite measure

::: {#o1 .subject cue=lead name="S-finite measure"}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), a branch of mathematics that studies generalized notions of volumes, an **s-finite measure** is a special type of [measure](wikipedia://en/19873). An s-finite measure is more general than a finite measure, but allows one to generalize certain proofs for finite measures.

:::

The s-finite measures should not be confused with the [σ-finite (sigma-finite) measures](wikipedia://en/4316174).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(X, \mathcal A )$ be a [measurable space](wikipedia://en/43333) and $\mu$ a measure on this measurable space. The measure $\mu$ is called an s-finite measure, if it can be written as a [countable](https://en.wikipedia.org/wiki/Countably_many) sum of [finite measures](wikipedia://en/4316185) $\nu_n$ ($n \in \mathbb{N}$),[^o11]

:::
