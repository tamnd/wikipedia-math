# Carathéodory's criterion

::: {#o1 .subject cue=lead name="Carathéodory's criterion"}

**Carathéodory's criterion** is a result in [measure theory](https://en.wikipedia.org/wiki/Measure_theory) that was formulated by Greek [mathematician](wikipedia://en/18902) [Constantin Carathéodory](wikipedia://en/470625) that characterizes when a set is [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

**Carathéodory's criterion**: Let $\lambda^* : {\mathcal P}(\mathbb{R}^n) \to [0, \infty]$ denote the [Lebesgue](wikipedia://en/18198) [outer measure](wikipedia://en/488605) on $\mathbb{R}^n,$ where ${\mathcal P}(\mathbb{R}^n)$ denotes the [power set](wikipedia://en/23799) of $\mathbb{R}^n,$ and let $M \subseteq \mathbb{R}^n.$ Then $M$ is [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable) if and only if $\lambda^*(S) = \lambda^*(S \cap M) + \lambda^*\left(S \cap M^c\right)$ for every $S \subseteq \mathbb{R}^n,$ where $M^c$ denotes the [complement](wikipedia://en/54347) of $M.$ Notice that $S$ is not required to be a measurable set.[^o4]

:::

::: {#o6 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

The Carathéodory criterion is of considerable importance because, in contrast to Lebesgue's original formulation of measurability, which relies on certain topological properties of $\mathbb{R},$ this criterion readily generalizes to a characterization of measurability in abstract spaces. Indeed, in the generalization to abstract measures, this theorem is sometimes extended to a *definition* of measurability.[^o4] Thus, we have the following definition: If $\mu^* : {\mathcal P}(\Omega) \to [0, \infty]$ is an [outer measure](wikipedia://en/488605) on a set $\Omega,$ where ${\mathcal P}(\Omega)$ denotes the [power set](wikipedia://en/23799) of $\Omega,$ then a subset $M \subseteq \Omega$ is called **$\mu^*$–measurable** or **Carathéodory-measurable** if for every $S \subseteq \Omega,$ the equality

$$\mu^*(S) = \mu^*(S \cap M) + \mu^*\left(S \cap M^c\right)$$

holds where $M^c := \Omega \setminus M$ is the [complement](wikipedia://en/54347) of $M.$

The family of all $\mu^*$–measurable subsets is a [σ-algebra](wikipedia://en/29586) (so for instance, the complement of a $\mu^*$–measurable set is $\mu^*$–measurable, and the same is true of countable intersections and unions of $\mu^*$–measurable sets) and the [restriction](wikipedia://en/1589032) of the outer measure $\mu^*$ to this family is a [measure](wikipedia://en/19873).

:::
