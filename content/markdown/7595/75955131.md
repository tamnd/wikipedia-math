# N-dimensional polyhedron

::: {#o1 .subject cue=lead name="N-dimensional polyhedron"}

An ***n*-dimensional polyhedron** is a geometric object that generalizes the 3-dimensional [polyhedron](wikipedia://en/23470) to an [*n*-dimensional space](https://en.wikipedia.org/wiki/Multi-dimensional_space). It is defined as a set of points in [real](wikipedia://en/20646438) [affine](wikipedia://en/298834) (or [Euclidean](wikipedia://en/9697)) space of any [dimension](wikipedia://en/8398) *n*, that has flat sides. It may alternatively be defined as the intersection of finitely many [half-spaces](wikipedia://en/647297). Unlike a 3-dimensional polyhedron, it may be bounded or unbounded. In this terminology, a bounded polyhedron is called a *[polytope](wikipedia://en/23471)*.[^o2][^o3]

:::

Analytically, a convex polyhedron is expressed as the solution set for a system of linear inequalities, *a<sub>i</sub>*<sup>T</sup>*x* ≤ *b<sub>i</sub>*, where *a<sub>i</sub>* are vectors in **R**<sup>*n*</sup> and *b<sub>i</sub>* are scalars. This definition of polyhedra is particularly important as it provides a geometric perspective for problems in [linear programming](wikipedia://en/43730).p. 9

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

Many traditional polyhedral forms are n-dimensional polyhedra. Other examples include:

- A [half-space](wikipedia://en/647297) is a polyhedron defined by a single linear inequality, *a<sub>1</sub>*<sup>T</sup>*x* ≤ *b<sub>1</sub>*.
- A [hyperplane](wikipedia://en/99862) is a polyhedron defined by two inequalities, *a<sub>1</sub>*<sup>T</sup>*x* ≤ *b<sub>1</sub>* and *a<sub>1</sub>*<sup>T</sup>*x* ≥ *b<sub>1</sub>* (which is equivalent to *\-a<sub>1</sub>*<sup>T</sup>*x* ≤ -*b<sub>1</sub>*).
- A quadrant in the plane. For instance, the region of the cartesian plane consisting of all points above the horizontal axis and to the right of the vertical axis: $\{ ( x, y ) : x \ge 0, y \ge 0$}. Its sides are the two positive axes, and it is otherwise unbounded.
- An octant in Euclidean 3-space, $\{ ( x, y, z ) : x \ge 0, y \ge 0, z \ge 0$}.
- A prism of infinite extent. For instance a doubly infinite square prism in 3-space, consisting of a square in the *xy*-plane swept along the *z*-axis: $\{ ( x, y, z ) : 0 \le x \le 1, 0 \le y \le 1$}.
- Each [cell](https://en.wikipedia.org/wiki/Cell_%28geometry%29) in a [Voronoi tessellation](wikipedia://en/177668) is a polyhedron. In the Voronoi tessellation of a set *S*, the cell *A* corresponding to a point $c \in S$ is bounded (hence a traditional polyhedron) when *c* lies in the [interior](wikipedia://en/55610) of the [convex hull](wikipedia://en/40634) of *S*, and otherwise (when *c* lies on the [boundary](wikipedia://en/72824) of the convex hull of *S*) *A* is unbounded.

:::

## Faces and vertices {#Faces_and_vertices}

A non-empty subset *F* of a polyhedron *P* is called a **face** of *P* if *F=P* or there is a halfspace *H* (defined by some inequality *a<sub>1</sub>*<sup>T</sup>*x* ≤ *b<sub>1</sub>*) such that *H* contains *P* and *F* is the intersection of the boundary of *H* and *P*.[^o8]

- If a face contains a single point {*v*}, then *v* is called a **vertex** of *P*.
- If a face *F* is *n*-1 dimensional, then *F* is called a **facet** of *P*.

Suppose *P* is a polyhedron defined by *Ax* ≤ *b*, where *A* has full column rank. Then, *v* is a vertex of *P* if and only if *v* is a [basic feasible solution](wikipedia://en/58654129) of the linear system *Ax* ≤ *b*.[^o4]p. 10

## Standard representation {#Standard_representation}

The representation of a polyhedron by a set of linear inequalities is not unique. It is common to define a **standard representation** for each polyhedron *P*:[^o4]p. 9

- If *P* is full-dimensional, then its standard representation is a set of inequalities such that each inequality *a<sub>i</sub>*<sup>T</sup>*x* ≤ *b<sub>i</sub>* defines exactly one facet of *P*, and moreover, the inequalities are normalized such that $\| a_i \|_{\infty} = 1$ for all *i*.
- If *P* is not full-dimensional, then it is contained in its [affine hull](wikipedia://en/3416209), which is defined by a set of linear equations *C*x=*d*. It is possible to choose *C* such that *C* = (*I*, *C*'), where *I* is an [identity matrix](wikipedia://en/59718). The standard representation of *P* contains this set *C*x=*d* and a set of inequalities such that each inequality *a<sub>i</sub>*<sup>T</sup>*x* ≤ *b<sub>i</sub>* defines exactly one facet of *P*, the inequalities are normalized such that $\| a_i \|_{\infty} = 1$ for all *i*, and each *a<sub>i</sub>* is orthogonal to each row of *C*. This representation is unique up to the choice of columns of the identity matrix.

## Representation by cones and convex hulls {#Representation_by_cones_and_convex_hulls}

If *P* is a polytope (a bounded polyhedron), then it can be represented by its set of vertices *V*, as *P* is simply the [convex hull](wikipedia://en/40634) of *V*: *P* = conv(*V*).

If *P* is a general (possibly unbounded) polyhedron, then it can be represented as: P = conv(V) + cone(E), where *V* is (as before) the set of vertices of *P*, and *E* is another finite set, and cone denotes the [conic hull](https://en.wikipedia.org/wiki/Conic_hull). The set cone(E) is also called the **[recession cone](wikipedia://en/34978152)** of *P*.[^o4]p. 10

[Carathéodory's theorem](wikipedia://en/892014) states that, if *P* is a *d*-dimensional polytope, then every point in *P* can be written as a convex combination of at most *d*+1 affinely-independent vertices of *P*. The theorem can be generalized: if *P* is any *d*-dimensional polyhedron, then every point in *P* can be written as a convex combination of points *v*<sub>1</sub>,...,*v<sub>s</sub>*, *v*<sub>1</sub>+*e*<sub>1</sub>,...,*v*<sub>1</sub>+*e<sub>t</sub>* with *s*+*t* ≤ *d*+1, such that *v*<sub>1</sub>,...,*v<sub>s</sub>* are elements of minimal nonempty faces of *P* and *e*<sub>1</sub>,...,*e<sub>t</sub>* are elements of the minimal nonzero faces of the recession cone of *P*.[^o4]p. 10

## Complexity of representation {#Complexity_of_representation}

When solving algorithmic problems on polyhedra, it is important to know whether a certain polyhedron can be represented by an encoding with a small number of bits. There are several measures to the representation complexity of a polyhedron *P*:[^o4]p. 163

- *P* has **facet complexity** **at most *f***, if *P* can be represented by a system of linear inequalities with rational coefficients, such that the encoding length of each inequality (i.e., the binary encoding length of all rational numbers appearing as coefficients in the inequality) is at most *f*. Note that *f ≥ n*+1, since there are n+1 coefficients in each inequality.
- P has **vertex complexity at most *v***, if *P* can be represented as conv(*V*)+cone(*E*), where *V* and *E* are finite sets, such that each point in V or E has encoding length at most *v*. Note that *v ≥ n*, since there are *n* coefficients in each vector.

These two kinds of complexity are closely related:[^o4]

- If *P* has facet complexity at most *f*, then P has vertex complexity at most 4 *n*<sup>2</sup> *f*.
- If *P* has vertex complexity at most *v*, then P has facet complexity at most 3 *n*<sup>2</sup> *v*.

A polyhedron *P* is called **well-described** if we know *n* (the number of dimensions) and *f* (an upper bound on the facet complexity). This is equivalent to requiring that we know *n* and *v* (an upper bound on the vertex complexity).

In some cases, we know an upper bound on the facet complexity of a polyhedron *P*, but we do not know the specific inequalities that attain this upper bound. However, it can be proved that the encoding length in any standard representation of *P* is at most 35 *n*<sup>2</sup> *f*.[^o4]

The complexity of representation of *P* implies upper and lower bounds on the volume of *P*:[^o4]p. 165

- If *P* has vertex complexity at most *v*, then trivially, all vertices of *P* are contained in the ball of radius 2<sup>v</sup> around the origin. This means that, if *P* is a polytope, then P itself is circumscribed in that ball.
- If *P* is a full-dimensional polyhedron with facet complexity at most *f*, then *P* contains a ball with radius $2^{-7 n^3 f}$. Moreover, this ball is contained in the ball of radius $2^{5 n^2 f}$ around the origin.

Small representation complexity is useful for "rounding" approximate solutions to exact solutions. Specifically:[^o4]p. 166

- If *P* is a polyhedron with facet complexity at most *f*, and *y* is a rational vector whose entries have common denominator at most *q*, and the distance from *y* to *P* is at most 2<sup>\-2*f*</sup>/*q*, then *y* is in fact in *P*.
- If *P* is a polyhedron with vertex complexity at most *v*, and *P* satisfies the inequality *a*<sup>T</sup>*x* ≤ *b + 2<sup>\-v-1</sup>,* then *P* also satisfies the inequality *a*<sup>T</sup>*x* ≤ *b.*
- If *P* is a polyhedron with facet complexity at most *f*, and *v* is a rational vector with distance from *P* of at most 2<sup>\-6n*f*</sup>, and *q* and *w* are integer vectors satisfying $\| qv-w \| < 2^{-3f}, 0<q<2^{4 n f}$, then the point *w*/*q* is contained in *P*. The number *q* and the vector *w* can be found in polytime using [simultaneous diophantine approximation](https://en.wikipedia.org/wiki/Simultaneous_diophantine_approximation).
- If *P* is a polyhedron with vertex complexity at most *v*, and *P* satisfies the inequality *a*<sup>T</sup>*x* ≤ *b + 2<sup>\-6nv</sup>,* and q,c,d are integer vectors satisfying $\| qa-c \| + |qb-d| < 2^{-3v}, 0<q<2^{4 n v}$, then *P* satisfies the inequality c<sup>T</sup>*x* ≤ *d*. The numbers *q,d* and the vector *c* can be found in polytime using [simultaneous diophantine approximation](https://en.wikipedia.org/wiki/Simultaneous_diophantine_approximation).
