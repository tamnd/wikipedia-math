# Ekeland's variational principle

::: {#o1 .subject cue=lead name="Ekeland's variational principle"}

In [mathematical analysis](wikipedia://en/48396), **Ekeland's variational principle**, discovered by [Ivar Ekeland](wikipedia://en/31377247),[^o2][^o3][^o4] is a theorem that asserts that there exist nearly optimal solutions to some [optimization problems](wikipedia://en/1126536).

:::

Ekeland's principle can be used when the lower [level set](wikipedia://en/559622) of a minimization problems is not [compact](https://en.wikipedia.org/wiki/Compactness_%28topology%29), so that the [Bolzano&ndash;Weierstrass theorem](https://en.wikipedia.org/wiki/Bolzano&ndash;Weierstrass_theorem) cannot be applied. The principle relies on the [completeness](wikipedia://en/7832) of the [metric space](wikipedia://en/20018).[^o6]

The principle has been shown to be equivalent to completeness of metric spaces.[^o5] In [proof theory](wikipedia://en/183478), it is equivalent to [Π${}^{1}_{1}$CA<sub>0</sub> over RCA<sub>0</sub>](wikipedia://en/326365#Π11_comprehension_Π11-CA0), i.e. relatively strong.

It also leads to a quick proof of the [Caristi fixed point theorem](https://en.wikipedia.org/wiki/Caristi_fixed_point_theorem).[^o6][^o7]

## History {#History}

Ekeland was associated with the [Paris Dauphine University](https://en.wikipedia.org/wiki/Paris_Dauphine_University) when he proposed this theorem.[^o2]

## Ekeland's variational principle {#Ekeland's_variational_principle}

### Preliminary definitions {#Preliminary_definitions}

A function $f : X \to \mathbb{R} \cup \{-\infty, +\infty\}$ valued in the [extended real numbers](https://en.wikipedia.org/wiki/Extended_real_numbers) $\mathbb{R} \cup \{-\infty, +\infty\} = [-\infty, +\infty]$ is said to be **bounded below** if $\inf_{} f(X) = \inf_{x \in X} f(x) > -\infty$ and it is called **[proper map](wikipedia://en/630360)** if it has a non-empty **[effective domain](wikipedia://en/33466771)**, which by definition is the set

$$\operatorname{dom} f ~\stackrel{\scriptscriptstyle\text{def}}{=}~ \{x \in X : f(x) \neq +\infty\},$$

and it is never equal to $-\infty.$ In other words, a map is proper if is valued in $\mathbb{R} \cup \{+\infty\}$ and not identically $+\infty.$ The map $f$ is proper and bounded below if and only if $-\infty < \inf_{} f(X) \neq +\infty,$ or equivalently, if and only if $\inf_{} f(X) \in \mathbb{R}.$

A function $f :X \to [-\infty, +\infty]$ is [lower semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous) at a given $x_0 \in X$ if for every real $y < f\left(x_0\right)$ there exists a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) $U$ of $x_0$ such that $f(u) > y$ for all $u \in U.$ A function is called [lower semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous) if it is lower semicontinuous at every point of $X,$ which happens if and only if $\{x \in X : ~f(x) > y\}$ is an [open set](wikipedia://en/39358) for every $y \in \mathbb{R},$ or equivalently, if and only if all of its lower [level sets](wikipedia://en/559622) $\{x \in X : ~f(x) \leq y\}$ are [closed](wikipedia://en/47279).

### Statement of the theorem {#Statement_of_the_theorem}

::: {#o15 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**EVP[^n1].**

Let $(X, d)$ be a [complete metric space](wikipedia://en/7832) and let $f : X \to \mathbb{R} \cup \{+\infty\}$ be a proper [lower semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous) function that is bounded below (so $\inf_{} f(X) \in \mathbb{R}$). Pick $x_0 \in X$ such that $f(x_0) \in \mathbb{R}$ (or equivalently, $f(x_0) \neq +\infty$) and fix any real $\varepsilon > 0.$ There exists some $v \in X$ such that

$$f(v) ~\leq~ f\left(x_0\right) - \varepsilon \; d \left(x_0, v\right)$$

and for every $x \in X$ other than $v$ (that is, $x \neq v$),

$$f(v) ~<~ f(x) + \varepsilon \; d(v, x).$$

:::

::: {#o16 .proof cue=math-proof}

Define a function $G : X \times X \to \mathbb{R} \cup \{+\infty\}$ by

$$G(x, y) ~\stackrel{\scriptscriptstyle\text{def}}{=}~ f(x) + \varepsilon \; d(x, y)$$

which is lower semicontinuous because it is the sum of the lower semicontinuous function $f$ and the continuous function $(x, y) \mapsto \varepsilon \; d(x, y).$ Given $z \in X,$ denote the functions with one coordinate fixed at $z$ by

$$G_z ~\stackrel{\scriptscriptstyle\text{def}}{=}~ G(z, \cdot) : X \to \mathbb{R} \cup \{+\infty\} \; \text{ and }$$

$$G^z~ \stackrel{\scriptscriptstyle\text{def}}{=}~ G(\cdot, z) : X \to \mathbb{R} \cup \{+\infty\}$$

and define the set

$$F(z) ~\stackrel{\scriptscriptstyle\text{def}}{=}~ \left\{y \in X : G^z(y) \leq f(z)\right\} ~=~ \{y \in X : f(y) + \varepsilon \; d(y, z) \leq f(z)\},$$

which is not empty since $z \in F(z).$ An element $v \in X$ satisfies the conclusion of this theorem if and only if $F(v) = \{v\}.$ It remains to find such an element.

It may be verified that for every $x \in X,$

$F(x)$ is closed (because $G^x \,\stackrel{\scriptscriptstyle\text{def}}{=}\, G(\cdot,x) : X \to \mathbb{R} \cup \{+\infty\}$ is lower semicontinuous);

if $x \notin \operatorname{dom} f$ then $F(x) = X;$

if $x \in \operatorname{dom} f$ then $x \in F(x) \subseteq \operatorname{dom} f;$ in particular, $x_0 \in F\left(x_0\right) \subseteq \operatorname{dom} f;$

if $y \in F(x)$ then $F(y) \subseteq F(x).$

Let $s_0 = \inf_{x \in F\left(x_0\right)} f(x),$ which is a real number because $f$ was assumed to be bounded below. Pick $x_1 \in F\left(x_0\right)$ such that $f\left(x_1\right) < s_0 + 2^{-1}.$ Having defined $s_{n-1}$ and $x_n,$ let

$$s_n ~\stackrel{\scriptscriptstyle\text{def}}{=}~ \inf_{x \in F\left(x_n\right)} f(x)$$

and pick $x_{n+1} \in F\left(x_n\right)$ such that $f\left(x_{n+1}\right) < s_n + 2^{-(n+1)}.$ For any $n \geq 0,$ $x_{n+1} \in F\left(x_n\right)$ guarantees that $s_n \leq f\left(x_{n+1}\right)$ and $F\left(x_{n+1}\right) \subseteq F\left(x_n\right),$ which in turn implies $s_{n+1} \geq s_n$ and thus also

$$f\left(x_{n+2}\right) \geq s_{n+1} \geq s_n.$$

So if $n \geq 1$ then $x_{n+1} \in F\left(x_n\right) \stackrel{\scriptscriptstyle\text{def}}{=} \left\{y \in X : f(y) + \varepsilon \; d\left(y, x_n\right) \leq f\left(x_n\right)\right\}$ and $f\left(x_{n+1}\right) \geq s_{n-1},$ which guarantee

$$\varepsilon \; d\left(x_{n+1}, x_n\right) ~\leq~ f\left(x_n\right) - f\left(x_{n+1}\right) ~\leq~ f\left(x_n\right) - s_{n-1} ~<~ \frac{1}{2^n}.$$

It follows that for all positive integers $n, p \geq 1,$

$$d\left(x_{n+p}, x_n\right) ~\leq~ 2 \; \frac{\varepsilon^{-1}}{2^n},$$

which proves that $x_\bullet := \left(x_n\right)_{n=0}^\infty$ is a Cauchy sequence. Because $X$ is a complete metric space, there exists some $v \in X$ such that $x_\bullet$ converges to $v.$ For any $n \geq 0,$ since $F\left(x_n\right)$ is a closed set that contain the sequence $x_n, x_{n+1}, x_{n+2}, \ldots,$ it must also contain this sequence's limit, which is $v;$ thus $v \in F\left(x_n\right)$ and in particular, $v \in F\left(x_0\right).$

The theorem will follow once it is shown that $F(v) = \{v\}.$ So let $x \in F(v)$ and it remains to show $x = v.$ Because $x \in F\left(x_n\right)$ for all $n \geq 0,$ it follows as above that $\varepsilon \; d\left(x, x_n\right) \leq 2^{-n},$ which implies that $x_{\bullet}$ converges to $x.$ Because $x_\bullet$ also converges to $v$ and limits in metric spaces are unique, $x = v.$ $\blacksquare$ [Q.E.D.](wikipedia://en/25228)

:::

For example, if $f$ and $(X, d)$ are as in the theorem's statement and if $x_0 \in X$ happens to be a global minimum point of $f,$ then the vector $v$ from the theorem's conclusion is $v := x_0.$

:::

### Corollaries {#Corollaries}

::: {#o19 .statement kind=statement/corollary cue=math-theorem name="Corollary"}

**Corollary[^n2].**

Let $(X, d)$ be a [complete metric space](wikipedia://en/7832), and let $f : X \to \mathbb{R} \cup \{+\infty\}$ be a [lower semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous) functional on $X$ that is bounded below and not identically equal to $+\infty.$ Fix $\varepsilon > 0$ and a point $x_0 \in X$ such that

$$f\left(x_0\right) ~\leq~ \varepsilon + \inf_{x \in X} f(x).$$

Then, for every $\lambda > 0,$ there exists a point $v \in X$ such that

$$f(v) ~\leq~ f\left(x_0\right),$$

$$d\left(x_0, v\right) ~\leq~ \lambda,$$

and, for all $x \neq v,$

$$f(x)+ \frac{\varepsilon}{\lambda} d(v, x) ~>~ f(v) .$$

:::

The principle could be thought of as follows: For any point $x_0$ which nearly realizes the infimum, there exists another point $v$, which is at least as good as $x_0$, it is close to $x_0$ and the perturbed function, $f(x)+\frac{\varepsilon}{\lambda} d(v, x)$, has unique minimum at $v$. A good compromise is to take $\lambda := \sqrt{\varepsilon}$ in the preceding result.[^n2]

:::
