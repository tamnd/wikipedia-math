# Constant strain triangle element

::: {#o1 .subject cue=lead name="Constant strain triangle element"}

In [numerical mathematics](https://en.wikipedia.org/wiki/Numerical_mathematics), the **constant strain triangle element**, also known as the **CST element** or **T3 element**, is a type of element used in [finite element analysis](https://en.wikipedia.org/wiki/Finite_element_analysis) which is used to provide an approximate solution in a 2D domain to the exact solution of a given [differential equation](wikipedia://en/1424309).

:::

The name of this element reflects how the [partial derivatives](wikipedia://en/52565) of this element's shape function are [linear functions](wikipedia://en/152111). When applied to [plane stress](wikipedia://en/6517456) and [plane strain](https://en.wikipedia.org/wiki/Plane_strain) problems, this means that the approximate solution obtained for the stress and strain fields are constant throughout the element's domain.[^o2]

The element provides an approximation for the exact solution of a partial differential equation which is parametrized [barycentric coordinate system (mathematics)](https://en.wikipedia.org/wiki/Barycentric_coordinate_system_%28mathematics%29)
