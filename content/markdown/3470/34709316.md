# Denjoy–Young–Saks theorem

::: {#o1 .subject cue=lead name="Denjoy–Young–Saks theorem"}

In [mathematics](wikipedia://en/18831), the **Denjoy–Young–Saks theorem** gives some possibilities for the [Dini derivatives](wikipedia://en/2163404) of a function that hold [almost everywhere](wikipedia://en/44688). (txt) proved the theorem for [continuous functions](wikipedia://en/6122), (txt) extended it to [measurable functions](wikipedia://en/44055), and (txt) extended it to arbitrary functions. (Saks 1937, Chapter IX, section 4) and (Bruckner 1978, chapter IV, theorem 4.4) give historical accounts of the theorem.

:::

::: {#o8 .statement cue=heading name="Statement"}

## Statement {#Statement}

If *f* is a real-valued function defined on an interval, then with the possible exception of a set of measure 0 on the interval, the [Dini derivatives](wikipedia://en/2163404) of *f* satisfy one of the following four conditions at each point:

- *f* has a finite derivative
- *D*<sup>\+</sup>*f* = *D*<sub>–</sub>*f* is finite, *D*<sup>−</sup>*f* = ∞, *D*<sub>\+</sub>*f* = –∞.
- *D*<sup>−</sup>*f* = *D*<sub>\+</sub>*f* is finite, *D*<sup>\+</sup>*f* = ∞, *D*<sub>–</sub>*f* = –∞.
- *D*<sup>−</sup>*f* = *D*<sup>\+</sup>*f* = ∞, *D*<sub>–</sub>*f* = *D*<sub>\+</sub>*f* = –∞.

:::
