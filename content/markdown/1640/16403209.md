# Perfect measure

::: {#o1 .subject cue=lead name="Perfect measure"}

In [mathematics](wikipedia://en/18831) — specifically, in [measure theory](https://en.wikipedia.org/wiki/Measure_theory) — a **perfect measure** (or, more accurately, a **perfect measure space**) is one that is "[well-behaved](https://en.wikipedia.org/wiki/Well-behaved)" in some sense. Intuitively, a perfect measure *μ* is one for which, if we consider the [pushforward measure](wikipedia://en/9412979) on the [real line](https://en.wikipedia.org/wiki/Real_line) **R**, then every [measurable set](https://en.wikipedia.org/wiki/Measurable_set) is "*μ*-approximately a [Borel set](wikipedia://en/43327)". The notion of perfectness is closely related to [tightness of measures](wikipedia://en/6553354): indeed, in [metric spaces](wikipedia://en/20018), tight measures are always perfect.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [measure space](wikipedia://en/45270) (*X*, Σ, *μ*) is said to be **perfect** if, for every Σ-measurable function *f* : *X* → **R** and every *A* ⊆ **R** with *f*<sup>−1</sup>(*A*) ∈ Σ, there exist Borel subsets *A*<sub>1</sub> and *A*<sub>2</sub> of **R** such that

$$A_{1} \subseteq A \subseteq A_{2} \mbox{ and } \mu \big( f^{-1} ( A_{2} \setminus A_{1} ) \big) = 0.$$

:::

## Results concerning perfect measures {#Results_concerning_perfect_measures}

- If *X* is any metric space and *μ* is an [inner regular](https://en.wikipedia.org/wiki/Inner_regular_measure) (or [tight](wikipedia://en/6553354)) measure on *X*, then (*X*, *B*<sub>*X*</sub>, *μ*) is a perfect measure space, where *B*<sub>*X*</sub> denotes the [Borel *σ*-algebra](https://en.wikipedia.org/wiki/Borel_sigma_algebra) on *X*.
