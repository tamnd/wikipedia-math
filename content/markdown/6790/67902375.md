# Self-supervised learning

::: {#o1 .subject cue=lead name="Self-supervised learning"}

Paradigms **Self-supervised learning** (**SSL**) is a paradigm in [machine learning](wikipedia://en/233488) where a model is trained on a task using the data itself to generate supervisory signals, rather than relying on externally-provided labels. In the context of [neural networks](wikipedia://en/21523), self-supervised learning aims to leverage inherent structures or relationships within the input data to create meaningful training signals. SSL tasks are designed so that solving them requires capturing essential [features](https://en.wikipedia.org/wiki/Feature_%28machine_learning%29) or relationships in the data. The input data is typically augmented or transformed in a way that creates pairs of related samples, where one sample serves as the input, and the other is used to formulate the supervisory signal. This augmentation can involve introducing noise, cropping, rotation, or other transformations. Self-supervised learning more closely imitates the way humans learn to classify objects.[^o2]

:::

During SSL, the model learns in two steps. First, the task is solved based on an auxiliary or pretext classification task using pseudo-labels, which help to initialize the model [parameters](wikipedia://en/25065#Artificial_intelligence).[^o3][^o4] Next, the actual task is performed with [supervised](wikipedia://en/20926) or [unsupervised learning](wikipedia://en/233497).[^o5][^o6][^o7]

Self-supervised learning has produced promising results in recent years, and has found practical application in fields such as [audio processing](https://en.wikipedia.org/wiki/Audio_signal_processing), and is being used by [Facebook](https://en.wikipedia.org/wiki/Facebook) and others for [speech recognition](https://en.wikipedia.org/wiki/Speech_recognition).[^o8]

## Pseudo-labels {#Pseudo-labels}

Pseudo-labels are automatically generated labels that a model assigns to unlabeled data based on its own predictions. They are widely used in self-supervised and semi-supervised learning, where ground-truth annotations are limited or unavailable. By treating predicted labels as surrogate ground truth, learning algorithms can make use of large quantities of unlabeled data in the training process.[^o10]

Pseudo-labeling also plays an important role in systems that must adapt to [concept drift](wikipedia://en/3118600), where the statistical properties of the data change over time. In these scenarios, the model may detect that an incoming instance deviates from previously learned behavior. The system then generates a classification result for that instance, and this predicted class is used as a pseudo-label for updating or retraining model components that are becoming outdated. This approach enables continuous adaptation in dynamic environments without requiring manual annotation.[^o11][^o12]

In many [adaptive learning](https://en.wikipedia.org/wiki/Adaptive_learning) pipelines, pseudo-labels are chosen when the classifier produces sufficiently confident predictions, reducing the risk of propagating errors. These pseudo-labeled instances are then incorporated into training to refresh or evolve the model's understanding of emerging data patterns, particularly when existing components show signs of “aging” due to drift or distributional shifts. This strategy reduces reliance on manual labeling while helping maintain long-term model performance.

## Types {#Types}

::: {#o15 .pointer-item cue=pointer name="Autoassociative self-supervised learning"}

### Autoassociative self-supervised learning {#Autoassociative_self-supervised_learning}

Autoassociative self-supervised learning is a specific category of self-supervised learning where a neural network is trained to reproduce or reconstruct its own input data.[^o16] In other words, the model is tasked with learning a representation of the data that captures its essential features or structure, allowing it to regenerate the original input.

The term "autoassociative" comes from the fact that the model is essentially associating the input data with itself. This is often achieved using [autoencoders](https://en.wikipedia.org/wiki/Autoencoders), which are a type of neural network architecture used for representation learning. Autoencoders consist of an *encoder* network that maps the input data to a lower-dimensional representation (latent space), and a *decoder* network that reconstructs the input from this representation.

The training process involves presenting the model with input data and requiring it to reconstruct the same data as closely as possible. The [loss function](wikipedia://en/442137) used during training typically penalizes the difference between the original input and the reconstructed output (e.g. [mean squared error](wikipedia://en/201816)). By minimizing this reconstruction error, the autoencoder learns a meaningful representation of the data in its [latent space](wikipedia://en/62176441).

:::

::: {#o18 .pointer-item cue=pointer name="Contrastive self-supervised learning"}

### Contrastive self-supervised learning {#Contrastive_self-supervised_learning}

For a [binary classification](wikipedia://en/205393) task, [training data](wikipedia://en/1514392) can be divided into positive examples and negative examples. Positive examples are those that match the target. For example, if training a classifier to identify birds, the positive training data would include images that contain birds. Negative examples would be images that do not.[^o19] Contrastive self-supervised learning uses both positive and negative examples. The loss function in contrastive learning is used to minimize the distance between positive sample pairs, while maximizing the distance between negative sample pairs.[^o19]

An early example uses a pair of 1-dimensional [convolutional neural networks](https://en.wikipedia.org/wiki/Convolutional_neural_network) to process a pair of images and maximize their agreement.[^o20]

[Contrastive Language-Image Pre-training](https://en.wikipedia.org/wiki/Contrastive_Language-Image_Pre-training) (CLIP) allows joint pretraining of a text encoder and an image encoder, such that a matching image-text pair have image encoding vector and text encoding vector that span a small angle (having a large [cosine similarity](https://en.wikipedia.org/wiki/Cosine_similarity)).

InfoNCE (Noise-Contrastive Estimation)[^o21] is a method to optimize two models jointly, based on Noise Contrastive Estimation (NCE).[^o22] Given a set $X=\left\{x_1, \ldots x_N\right\}$ of $N$ random samples containing one positive sample from $p\left(x_{t+k} \mid c_t\right)$ and $N-1$ negative samples from the 'proposal' distribution $p\left(x_{t+k}\right)$, it minimizes the following loss function:

$$\mathcal{L}_{\mathrm{N}}=-\mathbb{E}_{X} \left[\log \frac{f_k\left(x_{t+k}, c_t\right)}{\sum_{x_j \in X} f_k\left(x_j, c_t\right)}\right]$$

:::

### Non-contrastive self-supervised learning {#Non-contrastive_self-supervised_learning}

Non-contrastive self-supervised learning (NCSSL) uses only positive examples. Counterintuitively, NCSSL converges on a useful local minimum rather than reaching a trivial solution, with zero loss. For the example of binary classification, it would trivially learn to classify each example as positive. Effective NCSSL requires an extra predictor on the online side that does not [back-propagate](https://en.wikipedia.org/wiki/Backpropagation) on the target side.[^o19]

::: {#o25 .pointer-item cue=pointer name="Joint Embedding Predictive Architecture"}

### Joint-Embedding and Predictive Architectures {#Joint-Embedding_and_Predictive_Architectures}

A major class of self-supervised learning moves beyond contrastive pairs, instead maximizing the agreement between views while preventing collapse through statistical constraints. Rooted in Deep Canonical Correlation Analysis (Deep CCA),[^o26] this approach includes Joint-Embedding Architectures (JEA) like Barlow Twins[^o27] and VICReg,[^o28] which enforce covariance constraints to learn invariant representations without negative sampling. Deep Latent Variable Path Modelling (DLVPM)[^o29] generalizes this to multimodal systems, using path models to enforce correlation and orthogonality across diverse data types.

In 2022 [Yann LeCun](https://en.wikipedia.org/wiki/Yann_LeCun) introduced Joint-Embedding Predictive Architectures (JEPA) as a step towards decision making, reasoning, and autonomous human intelligence in machines, including self-improvement through autonomous learning. Founded in representation learning, LeCun included the concept of a “[world model](https://en.wikipedia.org/wiki/World_model_%28artificial_intelligence%29)” in JEPA which aims to enable machines to replicate human intellect by providing machines with a concept for the world in which they exist.[^o30]

Unlike autoencoders, JEPAs operate entirely in latent space, avoiding pixel-level noise to focus on semantic structure. Rather than just learning invariance, JEPAs learn by predicting masked latent representations from visible context.[^o31] JEPA has been applied to domains such as image analysis,[^o32] audio processing,[^o33] and motion in images and video.[^o34]

:::

## Comparison with other forms of machine learning {#Comparison_with_other_forms_of_machine_learning}

SSL belongs to supervised learning methods insofar as the goal is to generate a classified output from the input. At the same time, however, it does not require the explicit use of labeled input-output pairs. Instead, correlations, metadata embedded in the data, or [domain knowledge](https://en.wikipedia.org/wiki/Domain_knowledge) present in the input are implicitly and autonomously extracted from the data. These supervisory signals, extracted from the data, can then be used for training.[^o2]

SSL is similar to unsupervised learning in that it does not require labels in the sample data. Unlike unsupervised learning, however, learning is not done using inherent data structures.

[Semi-supervised learning](https://en.wikipedia.org/wiki/Semi-supervised_learning) combines supervised and unsupervised learning, requiring only a small portion of the learning data be [labeled](https://en.wikipedia.org/wiki/Labeled_data).[^o4]

In [transfer learning](https://en.wikipedia.org/wiki/Transfer_learning), a model designed for one task is reused on a different task.[^o36]

Training an [autoencoder](https://en.wikipedia.org/wiki/Autoencoder) intrinsically constitutes a self-supervised process, because the output pattern needs to become an optimal reconstruction of the input pattern itself. However, in current jargon, the term 'self-supervised' often refers to tasks based on a pretext-task training setup. This involves the (human) design of such pretext task(s), unlike the case of fully self-contained autoencoder training.[^o16]

In [reinforcement learning](wikipedia://en/66294), self-supervising learning from a combination of losses can create abstract representations where only the most important information about the state are kept in a compressed way.[^o37]

## Examples {#Examples}

Self-supervised learning is particularly suitable for speech recognition. For example, [Facebook](https://en.wikipedia.org/wiki/Facebook) developed *wav2vec*, a self-supervised algorithm, to perform speech recognition using two deep [convolutional neural networks](https://en.wikipedia.org/wiki/Convolutional_neural_networks) that build on each other.[^o8]

[Google](https://en.wikipedia.org/wiki/Google)'s [Bidirectional Encoder Representations from Transformers](https://en.wikipedia.org/wiki/BERT_%28language_model%29) (BERT) model is used to better understand the context of search queries.[^o40]

[OpenAI](https://en.wikipedia.org/wiki/OpenAI)'s [GPT-3](https://en.wikipedia.org/wiki/GPT-3) is an autoregressive [language model](wikipedia://en/1911810) that can be used in language processing. It can be used to translate texts or answer questions, among other things.[^o41]

*Bootstrap Your Own Latent* (BYOL) is a NCSSL that produced excellent results on [ImageNet](https://en.wikipedia.org/wiki/ImageNet) and on transfer and semi-supervised benchmarks.[^o42]

The [Yarowsky algorithm](https://en.wikipedia.org/wiki/Yarowsky_algorithm) is an example of self-supervised learning in [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing). From a small number of labeled examples, it learns to predict which [word sense](https://en.wikipedia.org/wiki/Word_sense_disambiguation) of a [polysemous](https://en.wikipedia.org/wiki/Polysemy) word is being used at a given point in text.

DirectPred is a NCSSL that directly sets the predictor weights instead of learning it via typical [gradient descent](wikipedia://en/201489).[^o19]

Self-GenomeNet is an example of self-supervised learning in genomics.[^o43]

SelfAPR is an example of self-supervised learning applied to [automated program repair](https://en.wikipedia.org/wiki/Automatic_bug_fixing), where a neural model is trained on perturbations of a previous version of the program under repair and uses test execution diagnostics to synthesize patches.[^o44]

Self-supervised learning continues to gain prominence as a new approach across diverse fields. Its ability to leverage unlabeled data effectively opens new possibilities for advancement in machine learning, especially in data-driven application domains.

:::
