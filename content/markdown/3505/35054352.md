# Polygraph (mathematics)

*Image: Polygraph (mathematics).svg.* A polygraph with 0-cells (vertices), 1-cells (gray edges), 2-cells (red edges), and 3-cells (blue edges). The red shading indicates a path of two 1-cells (*a*, *b*) that together form the source of a 2-cell. This can be done for the source and/or target of any dimension (where applicable, 0-cells can't be connected, and so 0 and 1-cells can't show this property), as long as the set is a path (tip-to-tail) such as cells *a* and *b*.

::: {#o1 .subject cue=lead name="Polygraph"}

In [mathematics](wikipedia://en/18831), and particularly in [category theory](wikipedia://en/5869), a **polygraph** is a generalisation of a [directed graph](wikipedia://en/19721986). It is also known as a **computad**. They were introduced as "polygraphs" by [Albert Burroni](https://en.wikipedia.org/wiki/Albert_Burroni)[^o2] and as "computads" by [Ross Street](wikipedia://en/41038878).[^o3]

:::

In the same way that a [directed multigraph](wikipedia://en/1774970#Directed_multigraph_%28edges_without_own_identity%29) can [freely](wikipedia://en/333835) generate a [category](wikipedia://en/53759), an *n*-computad is the "most general" structure which can generate a free [n-category](https://en.wikipedia.org/wiki/N-category).

In the context of a graph, each dimension is represented as a set of **$k$-cells**. Vertices would make up the 0-cells, edges connecting vertices would be 1-cells, and then each dimension higher connects groups of the dimension beneath it. For 2-cells and up, which connect edges themselves, a source or target may consist of *multiple* edges of the dimension below it, as long as each set of elements are **composites**, i.e., are paths connected tip-to-tail.[^o4]

A [globular set](wikipedia://en/56062096) can be seen as a specific instance of a polygraph. In a polygraph, a source or target of a $k$-cell may consist of an entire path of elements of ($k$-1)-cells, but a globular set restricts this to singular elements of ($k$-1)-cells.[^o4]
