# Berkeley cardinal

::: {#o1 .subject cue=lead name="Berkeley cardinal"}

In [set theory](wikipedia://en/27553), **Berkeley cardinals** are certain [large cardinals](wikipedia://en/383644) suggested by [Hugh Woodin](https://en.wikipedia.org/wiki/Hugh_Woodin) in a seminar at the [University of California, Berkeley](https://en.wikipedia.org/wiki/University_of_California,_Berkeley) in about 1992.

:::

A Berkeley cardinal is a cardinal *κ* in a model of [Zermelo–Fraenkel set theory](wikipedia://en/152214) with the property that for every [transitive set](wikipedia://en/2462396) *M* that includes *κ* and α \< κ, there is a nontrivial [elementary embedding](wikipedia://en/972601) of *M* into *M* with α \< [critical point](wikipedia://en/4888510) \< *κ*.[^o2] Berkeley cardinals are a strictly stronger cardinal axiom than [Reinhardt cardinals](wikipedia://en/4687321), implying that they are not compatible with the [axiom of choice](wikipedia://en/840).

A weakening of being a Berkeley cardinal is that for every binary relation *R* on *V*<sub>*κ*</sub>, there is a nontrivial elementary embedding of (*V*<sub>*κ*</sub>, *R*) into itself. This implies that we have elementary

*j*<sub>1</sub>, *j*<sub>2</sub>, *j*<sub>3</sub>, ...

*j*<sub>1</sub>: (*V*<sub>*κ*</sub>, ∈) → (*V*<sub>*κ*</sub>, ∈),

*j*<sub>2</sub>: (*V*<sub>*κ*</sub>, ∈, *j*<sub>1</sub>) → (*V*<sub>*κ*</sub>, ∈, *j*<sub>1</sub>),

*j*<sub>3</sub>: (*V*<sub>*κ*</sub>, ∈, *j*<sub>1</sub>, *j*<sub>2</sub>) → (*V*<sub>*κ*</sub>, ∈, *j*<sub>1</sub>, *j*<sub>2</sub>),

and so on. This can be continued any finite number of times, and to the extent that the model has dependent choice, transfinitely. Thus, plausibly, this notion can be strengthened simply by asserting more dependent choice.

While all these notions are incompatible with Zermelo–Fraenkel set theory (ZFC), their $\Pi^V_2$ consequences do not appear to be false. There is no known inconsistency with ZFC in asserting that, for example: For every ordinal λ, there is a transitive model of ZF + Berkeley cardinal that is closed under λ sequences.
