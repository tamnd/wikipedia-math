# BEAR and LION ciphers

::: {#o1 .subject cue=lead name="BEAR and LION ciphers"}

The **BEAR** and **LION** [block ciphers](wikipedia://en/4594) were invented by [Ross Anderson](wikipedia://en/61571) and [Eli Biham](wikipedia://en/348920) by combining a [stream cipher](wikipedia://en/49007) and a [cryptographic hash function](wikipedia://en/439526). The algorithms use a very large variable [block size](wikipedia://en/294065), on the order of 2<sup>13</sup> to 2<sup>23</sup> bits or more. Both are 3-round generalized (alternating) [Feistel ciphers](wikipedia://en/352709),[^o2] using the hash function and the stream cipher as round functions. BEAR uses the hash function twice with independent [keys](wikipedia://en/53039), and the stream cipher once. LION uses the stream cipher twice and the hash function once. The inventors proved that an attack on either BEAR or LION that recovers the key would break both the stream cipher and the hash.

:::
