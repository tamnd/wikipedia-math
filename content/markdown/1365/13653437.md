# Integration by parts operator

::: {#o1 .subject cue=lead name="Integration by parts operator"}

In [mathematics](wikipedia://en/18831), an **integration by parts operator** is a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) used to formulate [integration by parts](wikipedia://en/147252) formulae; the most interesting examples of integration by parts operators occur in [infinite-dimensional](https://en.wikipedia.org/wiki/Infinite-dimensional) settings and find uses in [stochastic analysis](https://en.wikipedia.org/wiki/Stochastic_analysis) and its applications.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *E* be a [Banach space](wikipedia://en/3989) such that both *E* and its [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) *E*<sup>∗</sup> are [separable spaces](wikipedia://en/27855); let *μ* be a [Borel measure](wikipedia://en/4322) on *E*. Let *S* be any (fixed) [subset](wikipedia://en/27631) of the class of functions defined on *E*. A linear operator *A* : *S* → *L*<sup>2</sup>(*E*, *μ*; **R**) is said to be an **integration by parts operator** for *μ* if

$$\int_{E} \mathrm{D} \varphi(x) h(x) \, \mathrm{d} \mu(x) = \int_{E} \varphi(x) (A h)(x) \, \mathrm{d} \mu(x)$$

for every [*C*<sup>1</sup> function](https://en.wikipedia.org/wiki/Smooth_function) *φ* : *E* → **R** and all *h* ∈ *S* for which either side of the above equality makes sense. In the above, D*φ*(*x*) denotes the [Fréchet derivative](wikipedia://en/2735727) of *φ* at *x*.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Consider an [abstract Wiener space](wikipedia://en/6592746) *i* : *H* → *E* with abstract Wiener measure *γ*. Take *S* to be the set of all *C*<sup>1</sup> functions from *E* into *E*<sup>∗</sup>; *E*<sup>∗</sup> can be thought of as a subspace of *E* in view of the inclusions

$$E^{*} \xrightarrow{i^{*}} H^{*} \cong H \xrightarrow{i} E.$$

For *h* ∈ *S*, define *Ah* by

$$(A h)(x) = h(x) x - \mathrm{trace}_{H} \mathrm{D} h(x).$$

This operator *A* is an integration by parts operator, also known as the [divergence](wikipedia://en/8328) operator; a proof can be found in Elworthy (1974).

- The [classical Wiener space](wikipedia://en/6810363) *C*<sub>0</sub> of [continuous paths](wikipedia://en/6122) in **R**<sup>*n*</sup> starting at zero and defined on the [unit interval](wikipedia://en/49172) \[0, 1\] has another integration by parts operator. Let *S* be the collection

$$S = \left\{ \left. h \colon C_{0} \to L_{0}^{2, 1} \right| h \mbox{ is bounded and non-anticipating} \right\},$$

i.e., all [bounded](wikipedia://en/311509), [adapted](wikipedia://en/6583420) processes with [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) sample paths. Let *φ* : *C*<sub>0</sub> → **R** be any *C*<sup>1</sup> function such that both *φ* and D*φ* are bounded. For *h* ∈ *S* and *λ* ∈ **R**, the [Girsanov theorem](wikipedia://en/336940) implies that

$$\int_{C_{0}} \varphi (x + \lambda h(x)) \, \mathrm{d} \gamma(x) = \int_{C_{0}} \varphi(x) \exp \left( \lambda \int_{0}^{1} \dot{h}_{s} \cdot \mathrm{d} x_{s} - \frac{\lambda^{2}}{2} \int_{0}^{1} | \dot{h}_{s} |^{2} \, \mathrm{d} s \right) \, \mathrm{d} \gamma(x).$$

Differentiating with respect to *λ* and setting *λ* = 0 gives

$$\int_{C_{0}} \mathrm{D} \varphi(x) h(x) \, \mathrm{d} \gamma(x) = \int_{C_{0}} \varphi(x) (A h) (x) \, \mathrm{d} \gamma(x),$$

where (*Ah*)(*x*) is the [Itō integral](https://en.wikipedia.org/wiki/Itō_integral)

$$\int_{0}^{1} \dot{h}_{s} \cdot \mathrm{d} x_{s}.$$

The same relation holds for more general *φ* by an approximation argument; thus, the Itō integral is an integration by parts operator and can be seen as an infinite-dimensional divergence operator. This is the same result as the [integration by parts formula derived from the Clark-Ocone theorem](https://en.wikipedia.org/wiki/Clark-Ocone_theorem#Integration_by_parts_on_Wiener_space).

:::
