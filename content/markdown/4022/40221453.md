# Foias constant

::: {#o1 .subject cue=lead name="Foias constant"}

*Image: Foias constant sequence.png.* Evolution of the sequence $x_{n+1} = (1 + 1/x_n)^n$ for several values of $x_1$, around the Foias constant $\alpha$. Evolution for $x_1 = \alpha$ is in green. Other initial values lead to two accumulation points, 1 and $\infty$. A [logarithmic scale](wikipedia://en/164055) is used.

In [mathematical analysis](wikipedia://en/48396), the **Foias constant** is a [real number](wikipedia://en/20646438) named after [Ciprian Foias](wikipedia://en/28465086).

:::

It is defined in the following way: [for every](https://en.wikipedia.org/wiki/For_every) real number *x*<sub>1</sub> > 0, there is a [sequence](wikipedia://en/27838) defined by the [recurrence relation](wikipedia://en/146806)

$$x_{n+1} = \left( 1 + \frac{1}{x_n} \right)^n$$

for *n* = 1, 2, 3, .... The Foias constant is the unique choice *α* such that if *x*<sub>1</sub> = *α* then the sequence [diverges](https://en.wikipedia.org/wiki/Divergent_sequence) to infinity. For all other values of *x*<sub>1</sub>, the sequence is divergent as well, but it has two [accumulation points](wikipedia://en/226505): 1 and infinity.[^o2] Numerically, it is

$$\alpha = 1.187452351126501\ldots.$$

The constant can be computed by solving backwards: $x_{n} = \frac{1}{\sqrt[n]{x_{n+1}} - 1}$

This recursion converges for any starting value $x_n\ne 0$[^o3].

When *x*<sub>1</sub> = *α* then the growth rate of the sequence (*x*<sub>*n*</sub>) is given by the [limit](wikipedia://en/285773)

$$\lim_{n\to\infty} x_n \frac{\log n}n = 1,$$

where "log" denotes the [natural logarithm](wikipedia://en/21476).[^o2]

The same methods used in the proof of the uniqueness of the Foias constant may also be applied to other similar recursive sequences.[^o4]
