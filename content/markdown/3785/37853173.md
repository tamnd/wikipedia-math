# Trace inequality

::: {#o1 .subject cue=lead name="Trace inequality"}

In [mathematics](wikipedia://en/18831), there are many kinds of [inequalities](wikipedia://en/89489) involving [matrices](wikipedia://en/20556859) and [linear operators](https://en.wikipedia.org/wiki/Linear_operator) on [Hilbert spaces](wikipedia://en/20598932). This article covers some important operator inequalities connected with [traces](wikipedia://en/43270) of matrices.[^o2][^o3][^o4][^o5]

:::

## Basic definitions {#Basic_definitions}

Let $\mathbf{H}_n$ denote the space of [Hermitian](wikipedia://en/189682) $n \times n$ matrices, $\mathbf{H}_n^+$ denote the set consisting of [positive semi-definite](https://en.wikipedia.org/wiki/Positive-definite_matrix#Negative-definite,_semidefinite_and_indefinite_matrices) $n \times n$ Hermitian matrices and $\mathbf{H}_n^{++}$ denote the set of [positive definite](https://en.wikipedia.org/wiki/Positive-definite_matrix#Negative-definite,_semidefinite_and_indefinite_matrices) Hermitian matrices. For operators on an infinite dimensional Hilbert space we require that they be [trace class](wikipedia://en/192266) and [self-adjoint](wikipedia://en/187408), in which case similar definitions apply, but we discuss only matrices, for simplicity.

For any [real-valued function](wikipedia://en/22284647) $f$ on an interval $I \subseteq \mathbb{R},$ one may define a [matrix function](https://en.wikipedia.org/wiki/Matrix_function) $f(A)$ for any operator $A \in \mathbf{H}_n$ with [eigenvalues](wikipedia://en/2161429) $\lambda$ in $I$ by defining it on the eigenvalues and corresponding [projectors](wikipedia://en/519182) $P$ as

$$f(A) \equiv \sum_j f(\lambda_j)P_j ~,$$

given the [spectral decomposition](wikipedia://en/123495) $A = \sum_j \lambda_j P_j.$

### Operator monotone {#Operator_monotone}

A function $f : I \to \mathbb{R}$ defined on an interval $I \subseteq \mathbb{R}$ is said to be **operator monotone** if for all $n,$ and all $A, B \in \mathbf{H}_n$ with eigenvalues in $I,$ the following holds,

$$A \geq B \implies f(A) \geq f(B),$$

where the inequality $A \geq B$ means that the operator $A - B \geq 0$ is positive semi-definite. One may check that $f(A) = A^2$ is, in fact, *not* operator monotone!

### Operator convex {#Operator_convex}

A function $f : I \to \mathbb{R}$ is said to be **operator convex** if for all $n$ and all $A, B \in \mathbf{H}_n$ with eigenvalues in $I,$ and $0 < \lambda < 1$, the following holds

$$f(\lambda A + (1-\lambda)B) \leq \lambda f(A) + (1 -\lambda)f(B).$$

Note that the operator $\lambda A + (1-\lambda)B$ has eigenvalues in $I,$ since $A$ and $B$ have eigenvalues in $I.$

A function $f$ is **operator concave** if $-f$ is operator convex; that is, the inequality above for $f$ is reversed.

### Joint convexity {#Joint_convexity}

A function $g : I \times J \to \mathbb{R},$ defined on intervals $I, J \subseteq \mathbb{R}$ is said to be **jointly convex** if for all $n$ and all $A_1, A_2 \in \mathbf{H}_n$ with eigenvalues in $I$ and all $B_1, B_2 \in \mathbf{H}_n$ with eigenvalues in $J,$ and any $0 \leq \lambda \leq 1$ the following holds

$$g(\lambda A_1 + (1-\lambda) A_2, \lambda B_1 + (1-\lambda) B_2) ~\leq~ \lambda g(A_1, B_1) + (1 -\lambda) g(A_2, B_2).$$

A function $g$ is **jointly concave** if −$g$ is jointly convex, i.e. the inequality above for $g$ is reversed.

### Trace function {#Trace_function}

Given a function $f : \mathbb{R} \to \mathbb{R},$ the associated **trace function** on $\mathbf{H}_n$ is given by

$$A \mapsto \operatorname{Tr} f(A) = \sum_j f(\lambda_j),$$

where $A$ has eigenvalues $\lambda$ and $\operatorname{Tr}$ stands for a [trace](wikipedia://en/43270) of the operator.

## Convexity and monotonicity of the trace function {#Convexity_and_monotonicity_of_the_trace_function}

Let $f: \mathbb{R} \rightarrow \mathbb{R}$ be continuous, and let $n$ be any [integer](wikipedia://en/14563). Then, if $t\mapsto f(t)$ is monotone increasing, so is $A \mapsto \operatorname{Tr} f(A)$ on **H**<sub>*n*</sub>.

Likewise, if $t \mapsto f(t)$ is [convex](wikipedia://en/245568), so is $A \mapsto \operatorname{Tr} f(A)$ on **H**<sub>*n*</sub>, and it is strictly convex if $f$ is strictly convex.

See proof and discussion in,[^o2] for example.

::: {#o13 .statement kind=statement/theorem cue=named-heading name="Löwner–Heinz theorem"}

## Löwner–Heinz theorem {#Löwner–Heinz_theorem}

For $-1\leq p \leq 0$, the function $f(t) = -t^p$ is operator monotone and operator concave.

For $0 \leq p \leq 1$, the function $f(t) = t^p$ is operator monotone and operator concave.

For $1 \leq p \leq 2$, the function $f(t) = t^p$ is operator convex. Furthermore,

$f(t) = \log(t)$ is operator concave and operator monotone, while

$f(t) = t \log(t)$ is operator convex.

The original proof of this theorem is due to [K. Löwner](https://en.wikipedia.org/wiki/Karl_Löwner) who gave a necessary and sufficient condition for $f$ to be operator monotone.[^o14] An [elementary proof](wikipedia://en/9318685) of the theorem is discussed in [^o2] and a more general version of it in.[^o15]

:::

::: {#o17 .statement cue=named-heading name="Klein's inequality"}

## Klein's inequality {#Klein's_inequality}

For all Hermitian $n$×$n$ matrices $A$ and $B$ and all differentiable [convex functions](wikipedia://en/245568) $f: \mathbb{R} \rightarrow \mathbb{R}$ with [derivative](wikipedia://en/7921) $f'$, or for all positive-definite Hermitian $n$×$n$ matrices $A$ and $B$, and all differentiable convex functions $f$:(0,∞) → $\mathbb{R}$, the following inequality holds,

In either case, if $f$ is strictly convex, equality holds if and only if $A$ = $B$. A popular choice in applications is $f(t) = t \log t$, see below.

::: {#o20 .proof cue=heading name="Proof"}

### Proof {#Proof}

Let $C=A-B$ so that, for $t\in (0,1)$,

$$B + tC = (1 -t)B + tA,$$

varies from $B$ to $A$.

Define

$$F(t) = \operatorname{Tr}[f(B + tC)].$$

By convexity and monotonicity of trace functions, $F(t)$ is convex, and so for all $t\in (0,1)$,

$$F(0) + t(F(1)-F(0))\geq F(t),$$

which is,

$$F(1) - F(0) \geq \frac{F(t)-F(0)}{t},$$

and, in fact, the right hand side is monotone decreasing in $t$.

Taking the limit $t\to 0$ yields,

$$F(1) - F(0) \geq F'(0),$$

which with rearrangement and substitution is Klein's inequality:

$$\mathrm{tr}[f(A)-f(B)-(A-B)f'(B)] \geq 0$$

Note that if $f(t)$ is strictly convex and $C\neq 0$, then $F(t)$ is strictly convex. The final assertion follows from this and the fact that $\tfrac{F(t) -F(0)}{t}$ is monotone decreasing in $t$.

:::

::: {#o22 .statement cue=named-heading name="Golden–Thompson inequality"}

## Golden–Thompson inequality {#Golden–Thompson_inequality}

In 1965, S. Golden [^o23] and C.J. Thompson [^o24] independently discovered that

For any matrices $A, B\in\mathbf{H}_n$,

$$\operatorname{Tr} e^{A+B}\leq \operatorname{Tr} e^A e^B.$$

This inequality can be generalized for three operators:[^o25] for non-negative operators $A, B, C\in\mathbf{H}_n^+$,

$$\operatorname{Tr} e^{\ln A -\ln B+\ln C}\leq \int_0^\infty \operatorname{Tr} A(B+t)^{-1}C(B+t)^{-1}\,\operatorname{d}t.$$

:::

::: {#o27 .statement cue=named-heading name="Peierls–Bogoliubov inequality"}

## Peierls–Bogoliubov inequality {#Peierls–Bogoliubov_inequality}

Let $R, F\in \mathbf{H}_n$ be such that Tr e<sup>*R*</sup> = 1. Defining $g = \operatorname{Tr} Fe^{R}$, we have

$$\operatorname{Tr} e^F e^R \geq \operatorname{Tr} e^{F+R}\geq e^g.$$

The proof of this inequality follows from the above combined with Klein's inequality. Take $f(x) = \exp(x), A=R + F,\text{ and } B = R + gI$.[^o28]

:::

::: {#o30 .statement cue=named-heading name="Gibbs variational principle"}

## Gibbs variational principle {#Gibbs_variational_principle}

Let $H$ be a self-adjoint operator such that $e^{-H}$ is [trace class](wikipedia://en/192266). Then for any $\gamma\geq 0$ with $\operatorname{Tr}\gamma=1,$

$$\operatorname{Tr}\gamma H+\operatorname{Tr}\gamma\ln\gamma\geq -\ln \operatorname{Tr} e^{-H},$$

with equality if and only if $\gamma=\exp(-H)/\operatorname{Tr} \exp(-H).$

:::

::: {#o32 .statement kind=statement/theorem cue=named-heading name="Lieb's concavity theorem"}

## Lieb's concavity theorem {#Lieb's_concavity_theorem}

The following theorem was proved by [E. H. Lieb](https://en.wikipedia.org/wiki/Elliott_Lieb) in.[^o25] It proves and generalizes a conjecture of [E. P. Wigner](wikipedia://en/10101), [M. M. Yanase](https://en.wikipedia.org/wiki/Mutsuo_Yanase), and [Freeman Dyson](wikipedia://en/11397).[^o33] Six years later other proofs were given by T. Ando [^o34] and B. Simon,[^o4] and several more have been given since then.

For all $m\times n$ matrices $K$, and all $q$ and $r$ such that $0 \leq q\leq 1$ and $0\leq r \leq 1$, with $q + r \leq 1$ the real valued map on $\mathbf{H}^+_m \times \mathbf{H}^+_n$ given by

$$F(A,B,K) = \operatorname{Tr}(K^*A^qKB^r)$$

- is jointly concave in $(A,B)$
- is convex in $K$.

Here $K^*$ stands for the [adjoint operator](wikipedia://en/667175) of $K.$

:::

::: {#o36 .statement kind=statement/theorem cue=named-heading name="Lieb's theorem"}

## Lieb's theorem {#Lieb's_theorem}

For a fixed Hermitian matrix $L\in\mathbf{H}_n$, the function

$$f(A)=\operatorname{Tr} \exp\{L+\ln A\}$$

is concave on $\mathbf{H}_n^{++}$.

The theorem and proof are due to E. H. Lieb,[^o25] Thm 6, where he obtains this theorem as a corollary of Lieb's concavity Theorem. The most direct proof is due to H. Epstein;[^o37] see [M.B. Ruskai](wikipedia://en/42290270) papers,[^o38][^o39] for a review of this argument.

:::

::: {#o41 .statement kind=statement/theorem cue=named-heading name="Ando's convexity theorem"}

## Ando's convexity theorem {#Ando's_convexity_theorem}

T. Ando's proof [^o34] of Lieb's concavity theorem led to the following significant complement to it:

For all $m \times n$ matrices $K$, and all $1 \leq q \leq 2$ and $0 \leq r \leq 1$ with $q-r \geq 1$, the real valued map on $\mathbf{H}^{++}_m \times \mathbf{H}^{++}_n$ given by

$$(A,B) \mapsto \operatorname{Tr}(K^*A^qKB^{-r})$$

is convex.

:::

## Joint convexity of relative entropy {#Joint_convexity_of_relative_entropy}

For two operators $A, B\in\mathbf{H}^{++}_n$ define the following map

$$R(A\parallel B):= \operatorname{Tr}(A\log A) - \operatorname{Tr}(A\log B).$$

For [density matrices](wikipedia://en/62844) $\rho$ and $\sigma$, the map $R(\rho\parallel\sigma)=S(\rho\parallel\sigma)$ is the Umegaki's [quantum relative entropy](wikipedia://en/5993806).

Note that the non-negativity of $R(A\parallel B)$ follows from Klein's inequality with $f(t)=t\log t$.

::: {#o44 .statement cue=heading name="Statement"}

### Statement {#Statement}

The map $R(A\parallel B): \mathbf{H}^{++}_n \times \mathbf{H}^{++}_n \rightarrow \mathbf{R}$ is jointly convex.

:::

::: {#o46 .proof cue=heading name="Proof"}

### Proof {#Proof}

For all $0 < p < 1$, $(A,B) \mapsto \operatorname{Tr}(B^{1-p}A^p)$ is jointly concave, by Lieb's concavity theorem, and thus

$$(A,B)\mapsto \frac{1}{p-1}(\operatorname{Tr}(B^{1-p}A^p)-\operatorname{Tr}A)$$

is convex. But

$$\lim_{p\rightarrow 1}\frac{1}{p-1}(\operatorname{Tr}(B^{1-p}A^p)-\operatorname{Tr}A)=R(A\parallel B),$$

and convexity is preserved in the limit.

The proof is due to G. Lindblad.[^o47]

:::

## Jensen's operator and trace inequalities {#Jensen's_operator_and_trace_inequalities}

The operator version of [Jensen's inequality](wikipedia://en/297811) is due to C. Davis.[^o49]

A continuous, real function $f$ on an interval $I$ satisfies **Jensen's Operator Inequality** if the following holds

$$f\left(\sum_kA_k^*X_kA_k\right)\leq\sum_k A_k^*f(X_k)A_k,$$

for operators $\{A_k\}_k$ with $\sum_k A^*_kA_k=1$ and for [self-adjoint operators](wikipedia://en/187408) $\{X_k\}_k$ with [spectrum](wikipedia://en/206137) on $I$.

See,[^o49][^o50] for the proof of the following two theorems.

::: {#o52 .statement cue=named-heading name="Jensen's trace inequality"}

### Jensen's trace inequality {#Jensen's_trace_inequality}

Let $f$ be a [continuous function](wikipedia://en/6122) defined on an interval $I$ and let $m$ and $n$ be natural numbers. If $f$ is convex, we then have the inequality

$$\operatorname{Tr}\Bigl(f\Bigl(\sum_{k=1}^nA_k^*X_kA_k\Bigr)\Bigr)\leq \operatorname{Tr}\Bigl(\sum_{k=1}^n A_k^*f(X_k)A_k\Bigr),$$

for all ($X$<sub>1</sub>, ... , $X$<sub>*n*</sub>) self-adjoint $m$ × $m$ matrices with spectra contained in $I$ and all ($A$<sub>1</sub>, ... , $A$<sub>*n*</sub>) of $m$ × $m$ matrices with

$$\sum_{k=1}^nA_k^*A_k=1.$$

Conversely, if the above inequality is satisfied for some $n$ and $m$, where $n$ > 1, then $f$ is convex.

:::

::: {#o54 .statement cue=named-heading name="Jensen's operator inequality"}

### Jensen's operator inequality {#Jensen's_operator_inequality}

For a continuous function $f$ defined on an interval $I$ the following conditions are equivalent:

- $f$ is operator convex.
- For each natural number $n$ we have the inequality

$$f\Bigl(\sum_{k=1}^nA_k^*X_kA_k\Bigr)\leq\sum_{k=1}^n A_k^*f(X_k)A_k,$$

for all $(X_1, \ldots , X_n)$ bounded, self-adjoint operators on an arbitrary [Hilbert space](wikipedia://en/20598932) $\mathcal{H}$ with spectra contained in $I$ and all $(A_1, \ldots , A_n)$ on $\mathcal{H}$ with $\sum_{k=1}^n A^*_kA_k=1.$

- $f(V^*XV) \leq V^*f(X)V$ for each isometry $V$ on an infinite-dimensional Hilbert space $\mathcal{H}$ and

every self-adjoint operator $X$ with spectrum in $I$.

- $Pf(PXP + \lambda(1 -P))P \leq Pf(X)P$ for each projection $P$ on an infinite-dimensional Hilbert space $\mathcal{H}$, every self-adjoint operator $X$ with spectrum in $I$ and every $\lambda$ in $I$.

:::

::: {#o56 .statement cue=named-heading name="Araki–Lieb–Thirring inequality"}

## Araki–Lieb–Thirring inequality {#Araki–Lieb–Thirring_inequality}

E. H. Lieb and W. E. Thirring proved the following inequality in [^o57] 1976: For any $A \geq 0,$ $B \geq 0$ and $r \geq 1,$

$$\operatorname{Tr} ((BAB)^r) ~\leq~ \operatorname{Tr} (B^r A^r B^r).$$

In 1990 [^o58] H. Araki generalized the above inequality to the following one: For any $A \geq 0,$ $B \geq 0$ and $q \geq 0,$

$$\operatorname{Tr}((BAB)^{rq}) ~\leq~ \operatorname{Tr}((B^r A^r B^r)^q),$$

for $r \geq 1,$ and

$$\operatorname{Tr}((B^r A^r B^r)^q) ~\leq~ \operatorname{Tr}((BAB)^{rq}),$$

for $0 \leq r \leq 1.$

There are several other inequalities close to the Lieb–Thirring inequality, such as the following:[^o59] for any $A \geq 0,$ $B \geq 0$ and $\alpha \in [0, 1],$

$$\operatorname{Tr} (B A^\alpha B B A^{1-\alpha} B) ~\leq~ \operatorname{Tr} (B^2 A B^2),$$

and even more generally:[^o60] for any $A \geq 0,$ $B \geq 0,$ $r \geq 1/2$ and $c \geq 0,$

$$\operatorname{Tr}((B A B^{2c} A B)^r) ~\leq~ \operatorname{Tr}((B^{c+1} A^2 B^{c+1})^r).$$

The above inequality generalizes the previous one, as can be seen by exchanging $A$ by $B^2$ and $B$ by $A^{(1-\alpha)/2}$ with $\alpha = 2 c / (2 c + 2)$ and using the cyclicity of the trace, leading to

$$\operatorname{Tr}((B A^\alpha B B A^{1-\alpha} B)^r) ~\leq~ \operatorname{Tr}((B^2 A B^2)^r).$$

Additionally, building upon the Lieb–Thirring inequality the following inequality was derived: [^o61] For any $A,B\in \mathbf{H}_n, T\in \mathbb{C}^{n\times n}$ and all $1\leq p,q\leq \infty$ with $1/p+1/q = 1$, it holds that

$$|\operatorname{Tr}(TAT^*B)| ~\leq~ \operatorname{Tr}(T^*T|A|^p)^\frac{1}{p}\operatorname{Tr}(TT^*|B|^q)^\frac{1}{q}.$$

:::

::: {#o63 .statement kind=statement/theorem cue=named-heading name="Effros's theorem and its extension"}

## Effros's theorem and its extension {#Effros's_theorem_and_its_extension}

E. Effros in [^o64] proved the following theorem.

If $f(x)$ is an operator convex function, and $L$ and $R$ are commuting bounded linear operators, i.e. the commutator $[L,R]=LR-RL=0$, the *perspective*

$$g(L, R):=f(LR^{-1})R$$

is jointly convex, i.e. if $L=\lambda L_1+(1-\lambda)L_2$ and $R=\lambda R_1+(1-\lambda)R_2$ with $[L_i, R_i]=0$ (i=1,2), $0\leq\lambda\leq 1$,

$$g(L,R)\leq \lambda g(L_1,R_1)+(1-\lambda)g(L_2,R_2).$$

Ebadian et al. later extended the inequality to the case where $L$ and $R$ do not commute .[^o65]

:::

::: {#o67 .statement cue=named-heading name="Von Neumann's trace inequality and related results"}

## Von Neumann's trace inequality and related results {#Von_Neumann's_trace_inequality_and_related_results}

Von Neumann's trace inequality, named after its originator [John von Neumann](wikipedia://en/15942), states that for any $n \times n$ complex matrices $A$ and $B$ with [singular values](wikipedia://en/709116) $\alpha_1 \geq \alpha_2 \geq \cdots \geq \alpha_n$ and $\beta_1 \geq \beta_2 \geq \cdots \geq \beta_n$ respectively,[^o68]

$$|\operatorname{Tr}(A B)| ~\leq~ \sum_{i=1}^n \alpha_i \beta_i\,,$$

with equality if and only if $A$ and $B^{\dagger}$ share singular vectors.[^o69]

A simple corollary to this is the following result:[^o70] For [Hermitian](wikipedia://en/189682) $n \times n$ positive semi-definite complex matrices $A$ and $B$ where now the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) are sorted decreasingly ($a_1 \geq a_2 \geq \cdots \geq a_n$ and $b_1 \geq b_2 \geq \cdots \geq b_n,$ respectively),

$$\sum_{i=1}^n a_i b_{n-i+1} ~\leq~ \operatorname{Tr}(A B) ~\leq~ \sum_{i=1}^n a_i b_i\,.$$

:::
