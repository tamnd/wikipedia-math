# Gammoid

*Image: Gammoid.svg.* A **gammoid** of the graph $G$. Each independent set made of elements in $T$ can be reached by disjoint paths that start in $S$. Notably, the independent set $\{4, 5, 6\}$ is possible because of a 0-length path, a path with no edges consisting of only a single vertex, valid due to vertex 4 being in both $S$ and $T$.

::: {#o1 .subject cue=lead name="Gammoid"}

In [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory), a field within mathematics, a **gammoid** is a certain kind of matroid, describing sets of [vertices](https://en.wikipedia.org/wiki/Vertices_%28graph_theory%29) that can be reached by vertex-disjoint [paths](wikipedia://en/638889) in a [directed graph](wikipedia://en/19721986).

:::

The concept of a gammoid was introduced and shown to be a matroid by (txt), based on considerations related to [Menger's theorem](wikipedia://en/1155738) characterizing the obstacles to the existence of systems of disjoint paths.[^o3] Gammoids were given their name by (Pym 1969)[^o5] and studied in more detail by (Mason 1972).[^o7]

::: {#o9 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G$ be a directed graph, $S$ be a set of starting vertices, and $T$ be a set of destination vertices (not necessarily disjoint from $S$). The gammoid $\Gamma$ derived from this data has $T$ as its set of elements. A subset $I$ of $T$ is independent in $\Gamma$ if there exists a set of vertex-disjoint paths whose starting points all belong to $S$ and whose ending points are exactly $I$.[^o10]

A **strict gammoid** is a gammoid in which the set $T$ of destination vertices consists of every vertex in $G$. Thus, a gammoid is a restriction of a strict gammoid, to a subset of its elements.[^o10][^o11]

:::

::: {#o13 .example cue=heading name="Example"}

## Example {#Example}

Consider the [uniform matroid](wikipedia://en/27967069) $U{}^r_n$ on a set of $n$ elements, in which every set of $r$ or fewer elements is independent. One way to represent this matroid as a gammoid would be to form a [complete bipartite graph](wikipedia://en/525320) $K_{r,n}$ with a set $S$ of $r$ vertices on one side of the bipartition, with a set $T$ of $n$ vertices on the other side of the bipartition, and with every edge directed from $S$ to $T.$ In this graph, a subset of $T$ is the set of endpoints of a set of disjoint paths [if and only if](wikipedia://en/14922) it has $r$ or fewer vertices, because otherwise there are too few vertices in $S$ to start the paths. The special structure of this graph shows that the uniform matroid is a [transversal matroid](https://en.wikipedia.org/wiki/Transversal_matroid) as well as being a gammoid.[^o14]

Alternatively, the same uniform matroid $U{}^r_n$ may be represented as a gammoid on a smaller graph, with only $n$ vertices, by choosing a subset $S$ of $r$ vertices and connecting each of the chosen vertices to every other vertex in the graph. Again, a subset of the vertices of the graph can be endpoints of disjoint paths if and only if it has $r$ or fewer vertices, because otherwise there are not enough vertices that can be starts of paths. In this graph, every vertex corresponds to an element of the matroid, showing that the uniform matroid is a strict gammoid.[^o15]

:::

::: {#o17 .statement kind=statement/theorem cue=named-heading name="Menger's theorem and gammoid rank"}

## Menger's theorem and gammoid rank {#Menger's_theorem_and_gammoid_rank}

The rank of a set $X\subset T$ in a gammoid defined from a graph $G$ and vertex subsets $S$ and $T$ is, by definition, the maximum number of vertex-disjoint paths from $S$ to $X$. By [Menger's theorem](wikipedia://en/1155738), it also equals the minimum cardinality of a set $Y$ that intersects every path from $S$ to $X$.[^o10]

:::

## Relation to transversal matroids {#Relation_to_transversal_matroids}

A transversal [matroid](wikipedia://en/244321) is defined from a [family of sets](wikipedia://en/723043): its elements are the elements of the sets, and a set $X$ of these elements is independent whenever there exists a one-to-one matching of the elements of $X$ to [disjoint sets](wikipedia://en/39359) containing them, called a [system of distinct representatives](https://en.wikipedia.org/wiki/System_of_distinct_representatives). Equivalently, a transversal matroid may be represented by a special kind of gammoid, defined from a directed [bipartite graph](wikipedia://en/244431) $(S,T,E)$ that has a vertex in $S$ for each set, a vertex in $T$ for each element, and an edge from each set to each element contained in it.

Less trivially, the strict gammoids are exactly the [dual matroids](wikipedia://en/23515837) of the transversal matroids. To see that every strict gammoid is dual to a transversal matroid, let $\gamma$ be a strict gammoid defined from a directed graph $G$ and starting vertex set $S$, and consider the transversal matroid for the family of sets $N_v$ for each vertex $v\in V(G)\setminus S$, where vertex $u$ belongs to $N_v$ if it equals $v$ or it has an edge to $v$. Any basis of the strict gammoid, consisting of the endpoints of some set of $|S|$ disjoint paths from $S$, is the complement of a basis of the transversal matroid, matching each $N_v$ to the vertex $u$ such that $uv$ is a path edge (or $v$ itself, if $v$ does not participate in one of the paths). Conversely every basis of the transversal matroid, consisting of a representative $u_v$ for each $N_v$, gives rise to a complementary basis of the strict gammoid, consisting of the endpoints of the paths formed by the set of edges $u_vv$. This result is due to [Ingleton](https://en.wikipedia.org/wiki/Aubrey_Ingleton) and [Piff](https://en.wikipedia.org/wiki/Mike_Piff).[^o10][^o19]

To see, conversely, that every transversal matroid is dual to a strict gammoid, find a subfamily of the sets defining the matroid such that the subfamily has a system of distinct representatives and defines the same matroid. Form a graph that has the union of the sets as its vertices and that has an edge to the representative element of each set from the other members of the same set. Then the sets $N_v$ formed as above for each representative element $v$ are exactly the sets defining the original transversal matroid, so the strict gammoid formed by this graph and by the set of representative elements is dual to the given transversal matroid.[^o10][^o19]

As an easy consequence of the Ingleton–Piff Theorem, every gammoid is a [contraction](wikipedia://en/36749660) of a transversal matroid. The gammoids are the smallest class of matroids that includes the transversal matroids and is closed under duality and taking [minors](wikipedia://en/36749660).[^o10][^o20][^o21]

## Representability {#Representability}

It is not true that every gammoid is [regular](wikipedia://en/13415343), i.e., [representable](wikipedia://en/37165960) over every field. In particular, the uniform matroid $U{}^2_4$ is not a [binary matroid](wikipedia://en/36848165), and more generally the $n$-point line $U{}^2_n$ can only be represented over fields with $n-1$ or more elements. However, every gammoid may be represented over almost every [finite field](wikipedia://en/11615).[^o7][^o10] More specifically, a gammoid with element set $S$ may be represented over every [field](wikipedia://en/10603) that has at least $2^{|S|}$ elements.[^o10][^o23][^o24]
