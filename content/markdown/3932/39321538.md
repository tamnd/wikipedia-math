# Diophantine quintuple

::: {#o1 .subject cue=lead name="Diophantine quintuple"}

In [number theory](wikipedia://en/21527), a **diophantine $m$-tuple** is a [set](wikipedia://en/26691) of $m$ [positive integers](wikipedia://en/21474) $\{a_1, a_2, a_3, a_4,\ldots, a_m\}$ such that $a_i a_j + 1$ is a [perfect square](wikipedia://en/213919) for any $1\le i < j \le m.$[^o3] A set of $m$ positive [rational numbers](wikipedia://en/19727024) with the similar property that the [product](wikipedia://en/24977) of any two is one less than a [rational square](https://en.wikipedia.org/wiki/Rational_square) is known as a **rational diophantine $m$-tuple**.

:::

## Diophantine *m*-tuples {#Diophantine_m-tuples}

The first diophantine quadruple was found by [Fermat](wikipedia://en/7576966): $\{1,3, 8, 120\}.$[^o3] It was proved in 1969 by Baker and Davenport [^o3] that a fifth positive integer cannot be added to this set. However, [Euler](wikipedia://en/17902) was able to extend this set by adding the rational number $\tfrac{777480}{8288641}.$[^o3]

The question of existence of ([integer](wikipedia://en/14563)) diophantine quintuples was one of the oldest outstanding unsolved problems in [number theory](wikipedia://en/21527). In 2004 [Andrej Dujella](https://en.wikipedia.org/wiki/Andrej_Dujella) showed that at most a finite number of diophantine quintuples exist.[^o3] In 2016 it was shown that no such quintuples exist by He, Togbé and Ziegler.[^o4]

As Euler proved, every Diophantine pair can be extended to a Diophantine quadruple. The same is true for every Diophantine triple. In both of these types of extension, as for Fermat's quadruple, it is possible to add a fifth rational number rather than an integer.[^o5]

## The rational case {#The_rational_case}

[Diophantus](wikipedia://en/9110) himself found the rational diophantine quadruple $\left\{\tfrac1{16}, \tfrac{33}{16}, \tfrac{17}4, \tfrac{105}{16}\right\}.$[^o3] More recently, Philip Gibbs found sets of six positive rationals with the property.[^o7] It is not known whether any larger rational diophantine *m*-tuples exist or even if there is an upper bound, but it is known that no infinite set of rationals with the property exists.[^o8]
