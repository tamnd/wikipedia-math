# Descent algebra

::: {#o1 .subject cue=lead name="Descent algebra"}

In algebra, Solomon's **descent algebra** of a [Coxeter group](wikipedia://en/297004) is a subalgebra of the [integral group ring](https://en.wikipedia.org/wiki/Integral_group_ring) of the Coxeter group, introduced by (Solomon 1976).

:::

## The descent algebra of the symmetric group {#The_descent_algebra_of_the_symmetric_group}

In the special case of the [symmetric group](wikipedia://en/28901) *S*<sub>*n*</sub>, the descent algebra is given by the elements of the group ring such that permutations with the same descent set have the same coefficients. (The descent set of a permutation σ consists of the indices *i* such that σ(*i*) > σ(*i*+1).) The descent algebra of the symmetric group *S*<sub>*n*</sub> has dimension 2<sup>*n-1*</sup>. It contains the [peak algebra](wikipedia://en/42452013) as a [left ideal](https://en.wikipedia.org/wiki/Left_ideal).
