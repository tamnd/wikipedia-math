# Aczel's anti-foundation axiom

::: {#o1 .subject cue=lead name="Aczel's anti-foundation axiom"}

In the [foundations of mathematics](wikipedia://en/169358), **Aczel's anti-foundation axiom** is an [axiom](wikipedia://en/928) set forth by (txt), as an alternative to the [axiom of foundation](https://en.wikipedia.org/wiki/Axiom_of_foundation) in [Zermelo–Fraenkel set theory](wikipedia://en/152214). It states that every [accessible pointed directed graph](https://en.wikipedia.org/wiki/Accessible_pointed_graph) corresponds to exactly one [set](wikipedia://en/26691). In particular, according to this axiom, the graph consisting of a single vertex with a loop corresponds to a set that contains only itself as element, i.e. a [Quine atom](https://en.wikipedia.org/wiki/Quine_atom). A set theory obeying this axiom is necessarily a [non-well-founded set theory](wikipedia://en/1091767).

:::

## Accessible pointed graphs {#Accessible_pointed_graphs}

An [accessible pointed graph](https://en.wikipedia.org/wiki/Accessible_pointed_graph) is a [directed graph](wikipedia://en/19721986) with a distinguished [vertex](wikipedia://en/638899) (the "root") such that for any node in the graph there is at least one [path](wikipedia://en/638889) in the directed graph from the root to that node.

The anti-foundation axiom postulates that each such directed graph corresponds to the membership structure of exactly one set. For example, the directed graph with only one node and an edge from that node to itself corresponds to a set of the form *x* = {*x*}.
