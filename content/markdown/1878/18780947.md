# Inherent zero

::: {#o1 .subject cue=lead name="Inherent zero"}

In statistics, an **inherent zero** is a reference point used to describe data sets which are indicative of magnitude of an absolute or relative nature. Inherent zeros are used in the ["ratio level" of "levels of measurement"](wikipedia://en/821148#Ratio_scale) and imply "none".[^o2]

:::
