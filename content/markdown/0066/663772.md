# Strict conditional

::: {#o1 .subject cue=lead name="Strict conditional"}

In [logic](wikipedia://en/46426065), a **strict conditional** (symbol: $\Box$, or ⥽) is a conditional governed by a [modal operator](wikipedia://en/3832714), that is, a [logical connective](wikipedia://en/18153) of [modal logic](wikipedia://en/333365). It is [logically equivalent](wikipedia://en/169324) to the [material conditional](wikipedia://en/658808) of [classical logic](wikipedia://en/55868), combined with the [necessity](wikipedia://en/3986852) operator from [modal logic](wikipedia://en/333365). For any two [propositions](wikipedia://en/81094) *p* and *q*, the [formula](wikipedia://en/404582) *p* → *q* says that *p* [materially implies](wikipedia://en/658808) *q* while $\Box (p \rightarrow q)$ says that *p* [strictly implies](wikipedia://en/37531624) *q*.[^o2] Strict conditionals are the result of [Clarence Irving Lewis](wikipedia://en/433707)'s attempt to find a conditional for logic that can adequately express [indicative conditionals](wikipedia://en/228776) in natural language.[^o3][^o4] They have also been used in studying [Molinist](https://en.wikipedia.org/wiki/Molinism) theology.[^o5]

:::

## Avoiding paradoxes {#Avoiding_paradoxes}

The strict conditionals may avoid [paradoxes of material implication](wikipedia://en/12857474). The following statement, for example, is not correctly formalized by material implication:

If Bill Gates graduated in medicine, then Elvis never died.

This condition should clearly be false: the degree of Bill Gates has nothing to do with whether Elvis is still alive. However, the direct encoding of this formula in [classical logic](wikipedia://en/55868) using material implication leads to:

Bill Gates graduated in medicine → Elvis never died.

This formula is true because whenever the antecedent *A* is false, a formula *A* → *B* is true. Hence, this formula is not an adequate translation of the original sentence. An encoding using the strict conditional is:

$\Box$ (Bill Gates graduated in medicine → Elvis never died).

In modal logic, this formula means (roughly) that, in every possible world in which Bill Gates graduated in medicine, Elvis never died. Since one can easily imagine a world where Bill Gates is a medicine graduate and Elvis is dead, this formula is false. Hence, this formula seems to be a correct translation of the original sentence.

## Problems {#Problems}

Although the strict conditional is much closer to being able to express natural language conditionals than the material conditional, it has its own problems with [consequents](wikipedia://en/804778) that are [necessarily true](wikipedia://en/3986852) (such as 2 + 2 = 4) or antecedents that are necessarily false.[^o8] The following sentence, for example, is not correctly formalized by a strict conditional:

If Bill Gates graduated in medicine, then 2 + 2 = 4.

Using strict conditionals, this sentence is expressed as:

$\Box$ (Bill Gates graduated in medicine → 2 + 2 = 4)

In modal logic, this formula means that, in every possible world where Bill Gates graduated in medicine, it holds that 2 + 2 = 4. Since 2 + 2 is equal to 4 in all possible worlds, this formula is true, although it does not seem that the original sentence should be. A similar situation arises with 2 + 2 = 5, which is necessarily false:

If 2 + 2 = 5, then Bill Gates graduated in medicine.

Some logicians view this situation as indicating that the strict conditional is still unsatisfactory. Others have noted that the strict conditional cannot adequately express [counterfactual conditionals](wikipedia://en/491578),[^o9] and that it does not satisfy certain logical properties.[^o10] In particular, the strict conditional is [transitive](wikipedia://en/200463), while the counterfactual conditional is not.[^o11]

Some logicians, such as [Paul Grice](https://en.wikipedia.org/wiki/Paul_Grice), have used [conversational implicature](https://en.wikipedia.org/wiki/Conversational_implicature) to argue that, despite apparent difficulties, the material conditional is just fine as a translation for the natural language 'if...then...'. Others still have turned to [relevance logic](wikipedia://en/185076) to supply a connection between the antecedent and consequent of provable conditionals.

## Constructive logic {#Constructive_logic}

In a [constructive](https://en.wikipedia.org/wiki/Constructive_logic) setting, the symmetry between ⥽ and $\Box$ is broken, and the two connectives can be studied independently. Constructive strict implication can be used to investigate [interpretability](wikipedia://en/621176) of [Heyting arithmetic](wikipedia://en/2545815) and to model [arrows](https://en.wikipedia.org/wiki/Arrow_%28computer_science%29) and guarded [recursion](wikipedia://en/4044867) in computer science.[^o13]
