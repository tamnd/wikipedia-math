# ESPACE

::: {#o1 .subject cue=lead name="ESPACE"}

In [computational complexity theory](wikipedia://en/7543), the [complexity class](wikipedia://en/502426) **ESPACE** is the set of [decision problems](wikipedia://en/8336) that can be solved by a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) in space 2<sup>[O](wikipedia://en/44578)(n)</sup>.

:::

See also **[EXPSPACE](wikipedia://en/54703)**.
