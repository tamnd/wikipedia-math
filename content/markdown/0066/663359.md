# List of complexity classes

::: {#o1 .subject cue=lead name="List of complexity classes"}

*Image: Complexity subsets pspace.svg.* A representation of the relation among complexity classes

This is a list of [complexity classes](wikipedia://en/502426) in [computational complexity theory](wikipedia://en/7543). For other computational and complexity subjects, see [list of computability and complexity topics](wikipedia://en/353748).

:::

Many of these classes have a 'co' partner which consists of the [complements](wikipedia://en/1929955) of all languages in the original class. For example, if a language L is in NP then the complement of L is in co-NP. (This does not mean that the complement of NP is co-NP—there are languages which are known to be in both, and other languages which are known to be in neither.)

"The hardest problems" of a class refer to problems which belong to the class such that every other problem of that class can be reduced to it.

| [\#P](https://en.wikipedia.org/wiki/Sharp-P) | Count solutions to an NP problem |
|---|---|
| [\#P-complete](https://en.wikipedia.org/wiki/Sharp-P-complete) | The hardest problems in #P |
| [2-EXPTIME](wikipedia://en/11387202) | Solvable in doubly exponential time |
| [AC<sup>0</sup>](wikipedia://en/7400698) | A circuit complexity class of bounded depth |
| [ACC<sup>0</sup>](wikipedia://en/7729684) | A circuit complexity class of bounded depth and counting gates |
| [AC](wikipedia://en/7401755) | A circuit complexity class |
| [AH](https://en.wikipedia.org/wiki/AH_%28complexity%29) | The arithmetic hierarchy |
| [AP](https://en.wikipedia.org/wiki/AP_%28complexity%29) | The class of problems [alternating Turing machines](https://en.wikipedia.org/wiki/Alternating_Turing_machine) can solve in polynomial time.[^o2] |
| [APX](wikipedia://en/2018925) | [Optimization problems](wikipedia://en/1126536) that have approximation algorithms with constant approximation ratio[^o2] |
| [AM](wikipedia://en/663203) | Solvable in polynomial time by an [Arthur–Merlin protocol](wikipedia://en/663203)[^o2] |
| [BPP](wikipedia://en/4079) | Solvable in polynomial time by [randomized algorithms](wikipedia://en/495383) (answer is probably right) |
| [BPL](wikipedia://en/18449708) | problems solvable in [logarithmic space](https://en.wikipedia.org/wiki/Logarithmic_space) and [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) with [probabilistic Turing machines](wikipedia://en/197812) with [two-sided error](https://en.wikipedia.org/wiki/Two-sided_error) |
| [BQP](wikipedia://en/4080) | Solvable in polynomial time on a [quantum computer](https://en.wikipedia.org/wiki/Quantum_computer) (answer is probably right) |
| [co-NP](wikipedia://en/6184) | "NO" answers checkable in polynomial time by a non-deterministic machine |
| [co-NP-complete](wikipedia://en/54680) | The hardest problems in co-NP |
| [DLIN](https://en.wikipedia.org/wiki/DLIN) | Solvable by a deterministic multitape Turing machine in time *O*(*n*). |
| [DSPACE(*f*(*n*))](wikipedia://en/658520) | Solvable by a deterministic machine with space *O*(*f*(*n*)). |
| [DTIME(*f*(*n*))](wikipedia://en/658538) | Solvable by a deterministic machine in time *O*(*f*(*n*)). |
| [E](wikipedia://en/663674) | Solvable in exponential time with linear exponent |
| [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY) | The union of the classes in the [exponential hierarchy](wikipedia://en/665091) |
| [ESPACE](wikipedia://en/663649) | Solvable with exponential space with linear exponent |
| [EXP](https://en.wikipedia.org/wiki/EXP) | Same as EXPTIME |
| [EXPSPACE](wikipedia://en/54703) | Solvable with exponential space |
| [EXPTIME](wikipedia://en/54694) | Solvable in exponential time |
| [FNP](wikipedia://en/663351) | The analogue of NP for [function problems](wikipedia://en/663345) |
| [FP](wikipedia://en/663347) | The analogue of P for function problems |
| FP<sup>NP</sup> | The analogue of P<sup>NP</sup> for function problems; the home of the [traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem) |
| [FPT](https://en.wikipedia.org/wiki/Fixed-parameter_tractable) | Fixed-parameter tractable |
| GapL | Logspace-reducible to computing the integer determinant of a matrix |
| [IP](wikipedia://en/160255) | Solvable in polynomial time by an [interactive proof system](wikipedia://en/160255) |
| [L](wikipedia://en/1149999) | Solvable with logarithmic (small) space |
| [LOGCFL](wikipedia://en/4734121) | Logspace-reducible to a [context-free language](wikipedia://en/6867) |
| [MA](wikipedia://en/663203) | Solvable in polynomial time by a [Merlin–Arthur protocol](wikipedia://en/663203) |
| [NC](wikipedia://en/22073) | Solvable efficiently (in polylogarithmic time) on parallel computers |
| [NE](wikipedia://en/663673) | Solvable by a non-deterministic machine in exponential time with linear exponent |
| [NESPACE](https://en.wikipedia.org/wiki/NESPACE) | Solvable by a non-deterministic machine with exponential space with linear exponent |
| [NEXP](https://en.wikipedia.org/wiki/NEXP) | Same as NEXPTIME |
| [NEXPSPACE](https://en.wikipedia.org/wiki/NEXPSPACE) | Solvable by a non-deterministic machine with exponential space |
| [NEXPTIME](wikipedia://en/663657) | Solvable by a non-deterministic machine in exponential time |
| [NL](wikipedia://en/1145955) | "YES" answers checkable with logarithmic space |
| [NLIN](https://en.wikipedia.org/wiki/NLIN) | Solvable by a nondeterministic multitape Turing machine in time *O*(*n*). |
| [NONELEMENTARY](https://en.wikipedia.org/wiki/NONELEMENTARY) | Complement of [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY). |
| [NP](wikipedia://en/21562) | "YES" answers checkable in polynomial time (see [complexity classes P and NP](https://en.wikipedia.org/wiki/P_=_NP_problem)) |
| [NP-complete](https://en.wikipedia.org/wiki/NP-complete) | The hardest or most expressive problems in NP |
| [NP-easy](wikipedia://en/54688) | Analogue to P<sup>NP</sup> for [function problems](wikipedia://en/663345); another name for FP<sup>NP</sup> |
| [NP-equivalent](https://en.wikipedia.org/wiki/NP-equivalent) | The hardest problems in FP<sup>NP</sup> |
| [NP-hard](https://en.wikipedia.org/wiki/NP-hard) | At least as hard as every problem in NP but not known to be in the same complexity class |
| [NSPACE(*f*(*n*))](wikipedia://en/658518) | Solvable by a non-deterministic machine with space *O*(*f*(*n*)). |
| [NTIME(*f*(*n*))](wikipedia://en/658539) | Solvable by a non-deterministic machine in time *O*(*f*(*n*)). |
| [P](wikipedia://en/658550) | Solvable in polynomial time |
| [P-complete](wikipedia://en/54683) | The hardest problems in P to solve on parallel computers |
| [P/poly](wikipedia://en/2052415) | Solvable in polynomial time given an "advice string" depending only on the input size |
| [PCP](wikipedia://en/504509) | Probabilistically Checkable Proof |
| [PH](https://en.wikipedia.org/wiki/PH_%28complexity%29) | The union of the classes in the [polynomial hierarchy](wikipedia://en/658651) |
| [PL](wikipedia://en/48561286) | solvable in polynomial time with a logarithmic space randomized machine with probability > <sup>1</sup>⁄<sub>2</sub> |
| P<sup>NP</sup> | Solvable in polynomial time with an [oracle](wikipedia://en/22431) for a problem in NP; also known as Δ<sub>2</sub>P |
| [PP](wikipedia://en/659322) | Probabilistically Polynomial (answer is right with probability slightly more than 1/2) |
| [PPAD](wikipedia://en/9192019) | Polynomial Parity Arguments on Directed graphs |
| [PR](wikipedia://en/3106897) | Solvable by recursively building up arithmetic functions. |
| [PSPACE](wikipedia://en/39351) | Solvable with polynomial space. |
| [PSPACE-complete](wikipedia://en/54685) | The hardest problems in PSPACE. |
| [PTAS](wikipedia://en/666431) | Polynomial-time approximation scheme (a subclass of APX). |
| [QIP](wikipedia://en/25608560) | Solvable in polynomial time by a quantum interactive proof system. |
| [QMA](wikipedia://en/23545978) | Quantum analog of [NP](wikipedia://en/21562). |
| [R](wikipedia://en/3106763) | Solvable in a finite amount of time. |
| [RE](wikipedia://en/3106703) | Problems to which we can answer "YES" in a finite amount of time, but a "NO" answer might never come. |
| [RL](wikipedia://en/1176581) | Solvable with logarithmic space by randomized algorithms (NO answer is probably right, YES is certainly right) |
| [RP](wikipedia://en/54771) | Solvable in polynomial time by randomized algorithms (NO answer is probably right, YES is certainly right) |
| [SL](wikipedia://en/1174919) | Problems log-space reducible to determining if a path exist between given vertices in an undirected graph. In October 2004 it was discovered that this class is in fact equal to [L](wikipedia://en/1149999). |
| [S<sub>2</sub>P](https://en.wikipedia.org/wiki/S2P_%28complexity%29) | one round games with simultaneous moves refereed deterministically in polynomial time[^o3] |
| [TFNP](wikipedia://en/4668618) | Total function problems solvable in non-deterministic polynomial time. A problem in this class has the property that *every* input has an output whose validity may be checked efficiently, and the computational challenge is to find a valid output. |
| [UP](wikipedia://en/312240) | Unambiguous Non-Deterministic Polytime functions. |
| [ZPL](https://en.wikipedia.org/wiki/ZPL_%28complexity%29) | Solvable by randomized algorithms (answer is always right, average space usage is logarithmic) |
| [ZPP](wikipedia://en/54772) | Solvable by randomized algorithms (answer is always right, average running time is polynomial) |
