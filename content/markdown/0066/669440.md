# Fundamental class

::: {#o1 .subject cue=lead name="Fundamental class"}

In [mathematics](wikipedia://en/18831), the **fundamental class** is a [homology](wikipedia://en/142432) class \[*M*\] associated to a [connected](wikipedia://en/6233) [orientable](https://en.wikipedia.org/wiki/Orientable) [compact manifold](wikipedia://en/669475) of dimension *n*, which corresponds to the generator of the homology group $H_n(M,\partial M;\mathbb{Z})\cong\mathbb{Z}$ . The fundamental class can be thought of as the orientation of the top-dimensional [simplices](wikipedia://en/39781) of a suitable triangulation of the manifold.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Closed, orientable {#Closed,_orientable}

When *M* is a [connected](wikipedia://en/6233) [orientable](https://en.wikipedia.org/wiki/Orientable) [closed manifold](wikipedia://en/669475) of dimension *n*, the top homology group is [infinite cyclic](https://en.wikipedia.org/wiki/Infinite_cyclic): $H_n(M;\mathbb{Z}) \cong \mathbb{Z}$, and an orientation is a choice of generator, a choice of isomorphism $\mathbb{Z} \to H_n(M;\mathbb{Z})$. The generator is called the **fundamental class**.

If *M* is disconnected (but still orientable), a fundamental class is the direct sum of the fundamental classes for each connected component (corresponding to an orientation for each component).

In relation with [de Rham cohomology](wikipedia://en/221530) it represents *integration over M*; namely for *M* a smooth manifold, an [*n*-form](wikipedia://en/221519) ω can be paired with the fundamental class as

$$\langle\omega, [M]\rangle = \int_M \omega\ ,$$

which is the integral of ω over *M*, and depends only on the cohomology class of ω.

### Stiefel–Whitney class {#Stiefel–Whitney_class}

If *M* is not orientable, $H_n(M;\mathbb{Z}) \ncong \mathbb{Z}$, and so one cannot define a fundamental class *M* living inside the integers. However, every closed manifold is $\mathbb{Z}_2$-orientable, and $H_n(M;\mathbb{Z}_2)=\mathbb{Z}_2$ (for *M* connected). Thus, every closed manifold is $\mathbb{Z}_2$-oriented (not just orient*able*: there is no ambiguity in choice of orientation), and has a $\mathbb{Z}_2$-fundamental class.

This $\mathbb{Z}_2$-fundamental class is used in defining [Stiefel–Whitney class](wikipedia://en/877761).

### With boundary {#With_boundary}

If *M* is a compact orientable manifold with boundary, then the top [relative homology](wikipedia://en/1248647) group is again infinite cyclic $H_n(M,\partial M)\cong \mathbb{Z}$, and so the notion of the fundamental class can be extended to the manifold with boundary case.

:::

## Poincaré duality {#Poincaré_duality}

The Poincaré duality theorem relates the homology and cohomology groups of *n*-dimensional oriented closed manifolds: if *R* is a [commutative ring](wikipedia://en/61346) and *M* is an *n*-dimensional *R*-orientable closed manifold with fundamental class *\[M\]*, then for all *k*, the map

$$H^k(M;R) \to H_{n-k}(M;R)$$

given by the [cap product](wikipedia://en/5230810)

$$\alpha \mapsto [M] \frown \alpha$$

is an isomorphism.[^o8]

Using the notion of fundamental class for manifolds with boundary, we can extend Poincaré duality to that case too (see [Lefschetz duality](wikipedia://en/16481963)). In fact, the cap product with a fundamental class gives a stronger duality result saying that we have isomorphisms $H^q(M, A;R) \cong H_{n-q}(M, B;R)$, assuming we have that $A, B$ are $(n-1)$-dimensional manifolds with $\partial A=\partial B= A\cap B$ and $\partial M=A\cup B$.[^o8]

See also [Twisted Poincaré duality](wikipedia://en/32182870)

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

In the [Bruhat decomposition](wikipedia://en/1139142) of the [flag variety](https://en.wikipedia.org/wiki/Flag_variety) of a [Lie group](wikipedia://en/17945), the fundamental class corresponds to the top-dimension [Schubert cell](https://en.wikipedia.org/wiki/Schubert_cell), or equivalently the [longest element of a Coxeter group](wikipedia://en/5355571).

:::
