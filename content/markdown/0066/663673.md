# NE (complexity)

::: {#o1 .subject cue=lead name="NE"}

In [computational complexity theory](wikipedia://en/7543), the [complexity class](wikipedia://en/502426) **NE** is the set of [decision problems](wikipedia://en/8336) that can be solved by a [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine) in time $2^{O(n)}$.[^o2] It is similar to **[NEXPTIME](wikipedia://en/663657)**, the set of decision problems that can be solved by a non-deterministic Turing machine in time $2^{n^O(1)}$. By definition, it is contained in **NEXPTIME**.

:::

**NE**, unlike **[NEXPTIME](wikipedia://en/663657)**, is not closed under [polynomial-time](wikipedia://en/159695) [many-one reductions](wikipedia://en/362983).
