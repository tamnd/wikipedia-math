# Triclinic crystal system

*Image: Microcline.jpeg.* [Microcline](https://en.wikipedia.org/wiki/Microcline), an example of the triclinic crystal system

*Image: Triclinic.svg.* Triclinic (a ≠ b ≠ c ≠ a and α, β, γ, 90° pairwise different)

::: {#o1 .subject cue=lead name="Triclinic crystal system"}

In [crystallography](https://en.wikipedia.org/wiki/Crystallography), the **triclinic** (or **anorthic**) **crystal system** is one of the seven [crystal systems](wikipedia://en/456410). A crystal system is described by three basis [vectors](https://en.wikipedia.org/wiki/Vector_%28geometric%29). In the triclinic system, the [crystal](https://en.wikipedia.org/wiki/Crystal) is described by vectors of unequal length, as in the [orthorhombic](https://en.wikipedia.org/wiki/Orthorhombic) system. In addition, the angles between these vectors must all be different and may not include 90°.

:::

The triclinic lattice is the least symmetric of the 14 three-dimensional [Bravais lattices](wikipedia://en/661808). It has (itself) the minimum symmetry all lattices have: points of inversion at each lattice point and at 7 more points for each lattice point: at the midpoints of the edges and the faces, and at the center points. It is the only lattice type that itself has no mirror planes.

::: {#o3 .pointer-item cue=pointer name="1 (crystal class)"}

## Crystal classes {#Crystal_classes}

The triclinic crystal system class names, examples, [Schönflies notation](https://en.wikipedia.org/wiki/Schönflies_notation), [Hermann-Mauguin notation](https://en.wikipedia.org/wiki/Hermann-Mauguin_notation), point groups, International Tables for Crystallography space group number,[^o4] [orbifold](wikipedia://en/293504), type, and [space groups](wikipedia://en/463721) are listed in the table below. There are a total of 2 space groups.

::: {#o5 .table cue=table}

| \# | Point group |  |  |  |  | Type | Example | [Space group](wikipedia://en/463721) |  |  |  |  |  |  |  |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  | Name[^o6] | [Schönflies](https://en.wikipedia.org/wiki/Schoenflies_notation) | [Intl](https://en.wikipedia.org/wiki/Hermann-Mauguin_notation) | [orbifold](wikipedia://en/293504) | [Coxeter](wikipedia://en/32088502) |  |  |  |  |  |  |  |  |  |  |
| 1 | Pedial | C<sub>1</sub> | 1 | 11 | \[ \]<sup>\+</sup> | [enantiomorphic](https://en.wikipedia.org/wiki/Enantiomorphic) [polar](wikipedia://en/41321254) | [Tantite](https://en.wikipedia.org/wiki/Tantite) | P1 |  |  |  |  |  |  |  |
| 2 | Pinacoidal | C<sub>i</sub> (S<sub>2</sub>) | $\overline{1}$ | 1× | \[2<sup>\+</sup>,2<sup>\+</sup>\] | [centrosymmetric](https://en.wikipedia.org/wiki/Centrosymmetric) | [Wollastonite](https://en.wikipedia.org/wiki/Wollastonite) | P$\overline{1}$ |  |  |  |  |  |  |  |

:::

With each only one space group is associated. Pinacoidal is also known as triclinic normal. Pedial is also triclinic hemihedral.

[Mineral](https://en.wikipedia.org/wiki/Mineral) examples include [plagioclase](https://en.wikipedia.org/wiki/Plagioclase), [microcline](https://en.wikipedia.org/wiki/Microcline), [rhodonite](https://en.wikipedia.org/wiki/Rhodonite), [turquoise](https://en.wikipedia.org/wiki/Turquoise), [wollastonite](https://en.wikipedia.org/wiki/Wollastonite) and [amblygonite](https://en.wikipedia.org/wiki/Amblygonite), all in triclinic normal ($\overline{1}$).

:::
