# Closed manifold

Classification of manifolds#Point-set

::: {#o1 .subject cue=lead name="Closed manifold"}

In [mathematics](wikipedia://en/18831), a **closed manifold** is a [manifold](wikipedia://en/2073470) [without boundary](https://en.wikipedia.org/wiki/Manifold_with_boundary) that is [compact](wikipedia://en/6042). In comparison, an **open manifold** is a manifold without boundary that has only *non-compact* components.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

The only [connected](wikipedia://en/6233) one-dimensional example is a [circle](wikipedia://en/6220). The [sphere](wikipedia://en/27859), [torus](wikipedia://en/74800), and the [Klein bottle](wikipedia://en/17412) are all closed two-dimensional manifolds. The [real projective space](wikipedia://en/1014694) **RP**<sup>*n*</sup> is a closed *n*-dimensional manifold. The [complex projective space](wikipedia://en/762977) **CP**<sup>*n*</sup> is a closed 2*n*-dimensional manifold.[^o4] A [line](https://en.wikipedia.org/wiki/Real_line) is not closed because it is not compact. A [closed disk](https://en.wikipedia.org/wiki/Closed_disk) is a compact two-dimensional manifold, but it is not closed because it has a boundary.

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every closed manifold is a Euclidean neighborhood retract and thus has finitely generated homology groups.[^o7]

If $M$ is a closed connected n-manifold, the n-th homology group $H_{n}(M;\mathbb{Z})$ is $\mathbb{Z}$ or 0 depending on whether $M$ is [orientable](wikipedia://en/187446) or not.[^o8] Moreover, the torsion subgroup of the (n-1)-th homology group $H_{n-1}(M;\mathbb{Z})$ is 0 or $\mathbb{Z}_2$ depending on whether $M$ is orientable or not. This follows from an application of the [universal coefficient theorem](wikipedia://en/996107).[^o9]

Let $R$ be a commutative ring. For $R$-orientable $M$ with fundamental class $[M]\in H_{n}(M;R)$, the map $D: H^k(M;R) \to H_{n-k}(M;R)$ defined by $D(\alpha)=[M]\cap\alpha$ is an isomorphism for all k. This is the [Poincaré duality](wikipedia://en/540732).[^o10] In particular, every closed manifold is $\mathbb{Z}_2$-orientable. So there is always an isomorphism $H^k(M;\mathbb{Z}_2) \cong H_{n-k}(M;\mathbb{Z}_2)$.

:::

## Open manifolds {#Open_manifolds}

For a connected manifold, "open" is equivalent to "without boundary and non-compact", but for a disconnected manifold, open is stronger. For instance, the disjoint union of a circle and a line is non-compact since a line is non-compact, but this is not an open manifold since the circle (one of its components) is compact.

## Abuse of language {#Abuse_of_language}

Most books generally define a manifold as a space that is, locally, [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to [Euclidean space](wikipedia://en/9697) (along with some other technical conditions), thus by this definition a manifold does not include its boundary when it is embedded in a larger space. However, this definition doesn’t cover some basic objects such as a [closed disk](https://en.wikipedia.org/wiki/Closed_disk), so authors sometimes define a [manifold with boundary](https://en.wikipedia.org/wiki/Manifold_with_boundary) and abusively say *manifold* without reference to the boundary. But normally, a **compact manifold** (compact with respect to its underlying topology) can synonymously be used for **closed manifold** if the usual definition for manifold is used.

The notion of a closed manifold is unrelated to that of a [closed set](wikipedia://en/47279). A line is a closed subset of the plane, and it is a manifold, but not a closed manifold.

## Use in physics {#Use_in_physics}

The notion of a "[closed universe](https://en.wikipedia.org/wiki/Shape_of_the_universe)" can refer to the universe being a closed manifold but more likely refers to the universe being a manifold of constant positive [Ricci curvature](wikipedia://en/276582).
