# Exponential integrator

::: {#o1 .subject cue=lead name="Exponential integrator"}

**Exponential integrators** are a class of [numerical methods](wikipedia://en/1678715) for the solution of [ordinary differential equations](https://en.wikipedia.org/wiki/Ordinary_differential_equations), specifically [initial value problems](wikipedia://en/498383). This large class of methods from [numerical analysis](wikipedia://en/21506) is based on the exact integration of the [linear](wikipedia://en/722503) part of the initial value problem. Because the linear part is [integrated](wikipedia://en/15532) exactly, this can help to mitigate the [stiffness](wikipedia://en/2091823) of a differential equation. Exponential integrators can be constructed to be [explicit or implicit](wikipedia://en/3652485) for [numerical ordinary differential equations](wikipedia://en/272829) or serve as the [time integrator](wikipedia://en/1047173) for [numerical partial differential equations](https://en.wikipedia.org/wiki/Numerical_partial_differential_equations).

:::

## Background {#Background}

Dating back to at least the 1960s, these methods were recognized by Certaine[^o3] and Pope.[^o4] As of late exponential integrators have become an active area of research, see [Hochbruck](wikipedia://en/59734385) and Ostermann (2010).[^o8] Originally developed for solving [stiff differential equations](wikipedia://en/2091823), the methods have been used to solve [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations) including [hyperbolic](https://en.wikipedia.org/wiki/Hyperbolic_partial_differential_equations) as well as [parabolic](wikipedia://en/7466971) problems[^o5] such as the [heat equation](wikipedia://en/166415).

## Introduction {#Introduction}

We consider [initial value problems](wikipedia://en/498383) of the form,

::: {#o7 .equation cue=numblk name="1"}

$$u'(t) = L u(t) + N(u(t) ), \qquad u(t_0)=u_0, \tag{1}$$

:::

where $L$ is composed of [linear terms](wikipedia://en/722503), and $N$ is composed of the [non-linear](wikipedia://en/146103) terms. These problems can come from a more typical initial value problem

$$u'(t) = f(u(t)), \qquad u(t_0)=u_0,$$

after linearizing locally about a fixed or local state $u^*$:

$$L = \frac{\partial f}{\partial u}(u^*); \qquad N = f(u) - L u.$$

Here, $\frac{\partial f}{\partial u}$ refers to the [partial derivative](wikipedia://en/52565) of $f$ with respect to $u$ (the Jacobian of *f*).

Exact integration of this problem from time 0 to a later time $t$ can be performed using [matrix exponentials](wikipedia://en/672731) to define an [integral equation](wikipedia://en/474234) for the exact solution:[^o8]

::: {#o9 .equation cue=numblk name="2"}

$$u(t) = e^{L t } u_0 + \int_0^t e^{ L (t-\tau) } N{\left( u{\left( \tau \right)} \right)}\, d\tau. \tag{2}$$

:::

This is similar to the exact integral used in the [Picard–Lindelöf theorem](wikipedia://en/666177). In the case of $N \equiv 0$, this formulation is the exact solution to the [linear differential equation](wikipedia://en/379868).

Numerical methods require a [discretization](wikipedia://en/330017) of equation (2). They can be based on [Runge-Kutta](https://en.wikipedia.org/wiki/Runge-kutta_method) discretizations,[^o10][^o11][^o12] [linear multistep methods](wikipedia://en/2090865) or a variety of other options.

## Exponential Rosenbrock methods {#Exponential_Rosenbrock_methods}

Exponential Rosenbrock methods were shown to be very efficient in solving large systems of stiff ordinary differential equations, usually resulted from spatial discretization of time dependent (parabolic) PDEs. These integrators are constructed based on a continuous linearization of (1) along the numerical solution $u_n$

::: {#o14 .equation cue=numblk name="3"}

$$u'(t) = L_n u(t)+ N_n(u(t)), \qquad u(t_0)=u_0, \tag{3}$$

:::

where $L_n = \frac{\partial f}{\partial u}(u_n)$, $N_n (u)=f(u)-L_n u$. This procedure enjoys the advantage, in each step, that $\frac{\partial N_n}{\partial u}(u_n)= 0.$ This considerably simplifies the derivation of the order conditions and improves the stability when integrating the nonlinearity $N(u(t))$. Again, applying the variation-of-constants formula (2) gives the exact solution at time $t_{n+1}$ as

::: {#o15 .equation cue=numblk name="4"}

$$u(t_{n+1})= e^{h_n L_n}u(t_n) + \int_0^{h_n} e^{(h_n-\tau) L_n} N_n ( u(t_n+\tau )) d\tau. \tag{4}$$

:::

The idea now is to approximate the integral in (4) by some quadrature rule with nodes $c_i$ and weights $b_i(h_n L_n)$ ($1\leq i\leq s$). This yields the following class of $s$-stage explicit exponential Rosenbrock methods, see Hochbruck and Ostermann (2006), Hochbruck, Ostermann and Schweitzer (2009):

$$\begin{aligned} U_{ni} &= e^{c_i h_n L_n}u_n + h_n \sum_{j=1}^{i-1}a_{ij}(h_n L_n) N_n( U_{nj}), \\ u_{n+1} &= e^{h_n L_n} u_n + h_n \sum_{i=1}^s b_i(h_n L_n) N_n(U_{ni}) \end{aligned}$$

with $u_n \approx u(t_n)$, $U_{ni}\approx u(t_n +c_i h_n)$, $h_n = t_{n+1}-t_n$. The coefficients $a_{ij}(z), b_i (z)$ are usually chosen as linear combinations of the entire functions $\varphi_k(c_i z), \varphi_k(z)$, respectively, where

$$\varphi_0(z) = e^z,\quad \varphi _k(z)=\int_0^1 e^{(1-\theta )z} \frac{\theta ^{k-1}}{(k-1)!} d\theta , \quad k\geq 1.$$

These functions satisfy the recursion relation

$$\varphi _{k+1}(z)=\frac{\varphi _k(z)-\varphi_k(0)}{z}, \ k\geq 0.$$

By introducing the difference $D_{ni}=N_n (U_{ni})-N_n (u_n)$, they can be reformulated in a more efficient way for implementation (see also [^o8]) as

$$\begin{aligned} U_{ni} &= u_n + c_i h_n \varphi _1 ( c_i h_n L_n)f(u_n) +h_n \sum_{j=2}^{i-1}a_{ij}(h_n L_n) D_{nj}, \\ u_{n+1}&= u_n + h_n \varphi _1 ( h_n L_n)f(u_n) + h_n \sum_{i=2}^s b_i(h_n L_n) D_{ni}. \end{aligned}$$

In order to implement this scheme with adaptive step size, one can consider, for the purpose of local error estimation, the following embedded methods

$$\bar{u}_{n+1}= u_n + h_n \varphi _1 ( h_n L_n)f(u_n) + h_n \sum_{i=2}^s \bar{b}_i(h_n L_n) D_{ni},$$

which use the same stages $U_{ni}$ but with weights $\bar{b}_i$.

For convenience, the coefficients of the explicit exponential Rosenbrock methods together with their embedded methods can be represented by using the so-called reduced Butcher tableau as follows:

| $c_2$ |  |  |  |  |  |
|---|---|---|---|---|---|
| $c_3$ | $a_{32}$ |  |  |  |  |
| $\vdots$ | $\vdots$ |  | $\ddots$ |  |  |
| $c_s$ | $a_{s2}$ | $a_{s3}$ | $\cdots$ | $a_{s,s-1}$ |  |
|  | $b_2$ | $b_3$ | $\cdots$ | $b_{s-1}$ | $b_s$ |
|  | $\bar{b}_2$ | $\bar{b}_3$ | $\cdots$ | $\bar{b}_{s-1}$ | $\bar{b}_s$ |

### Stiff order conditions {#Stiff_order_conditions}

Moreover, it is shown in Luan and Ostermann (2014a)[^o17] that the reformulation approach offers a new and simple way to analyze the local errors and thus to derive the stiff order conditions for exponential Rosenbrock methods up to order 5. With the help of this new technique together with an extension of the B-series concept, a theory for deriving the stiff order conditions for exponential Rosenbrock integrators of arbitrary order has been finally given in Luan and Ostermann (2013).[^o18] As an example, in that work the stiff order conditions for exponential Rosenbrock methods up to order 6 have been derived, which are stated in the following table:

::: {#o19 .table cue=table}

| No. | Stiff order condition | Order |
|---|---|---|
| 1 | $\sum_{i=2}^s b_i (Z)c^2_i=2\varphi_3 (Z)$ | 3 |
| 2 | $\sum_{i=2}^s b_i (Z)c^3_i=6\varphi_4 (Z)$ | 4 |
| 3 | $\sum_{i=2}^s b_i (Z)c^4_i=24\varphi_5 (Z)$ | 5 |
| 4 | $\sum_{i=2}^s b_i (Z)c_i K \psi _{3,i}(Z)=0$ |  |
| 5 | $\sum_{i=2}^s b_i (Z)c_i K \psi _{3,i}(Z)=0$ | 6 |
| 6 | $\sum_{i=2}^s b_i (Z) c_i^2 M \psi_{3,i}(Z)=0$ |  |
| 7 | $\sum_{i=2}^s b_i (Z) c_i K \psi_{4,i}(Z)=0$ |  |

:::

Here $Z$, $K$, and $M$ denote arbitrary square matrices.

### Convergence analysis {#Convergence_analysis}

The stability and convergence results for exponential Rosenbrock methods are proved in the framework of strongly continuous semigroups in some Banach space.

### Examples {#Examples}

All the schemes presented below fulfill the stiff order conditions and thus are also suitable for solving stiff problems.

#### Second-order method {#Second-order_method}

The simplest exponential Rosenbrock method is the exponential Rosenbrock–Euler scheme, which has order 2, see, for example Hochbruck et al. (2009):

$$u_{n+1} = u_n + h_n \ \varphi_1(h_n L_n) f(u_n).$$

#### Third-order methods {#Third-order_methods}

A class of third-order exponential Rosenbrock methods was derived in Hochbruck et al. (2009), named as exprb32, is given as:

exprb32:

| 1 |  |  |
|---|---|---|
|  | $2\varphi_3$ |  |
|  | 0 |  |

which reads as

$$\begin{aligned} U_{n2} &= u_n + h_n \ \varphi_1( h_n L_n) f(u_n), \\[1ex] u_{n+1} &= u_n + h_n \ \varphi_1(h_n L_n) f(u_n)+ h_n \ 2\varphi_3(h_n L_n) D_{n2}, \end{aligned}$$

where $D_{n2}=N_n (U_{n2})-N_n (u_n).$

For a variable step size implementation of this scheme, one can embed it with the exponential Rosenbrock–Euler:

$$\hat{u}_{n+1} =u_n + h_n \ \varphi_1(h_n L_n) f(u_n).$$

:::

## Fourth-order ETDRK4 method of Cox and Matthews {#Fourth-order_ETDRK4_method_of_Cox_and_Matthews}

Cox and Matthews[^o10] describe a fourth-order method exponential time differencing (ETD) method that they used [Maple](https://en.wikipedia.org/wiki/Maple_%28software%29) to derive.

We use their notation, and assume that the unknown function is $u$, and that we have a known solution $u_n$ at time $t_n$. Furthermore, we'll make explicit use of a possibly time dependent right hand side: $\mathcal{N} = \mathcal{N}( t, u )$.

Three stage values are first constructed:

$$\begin{aligned} a_n &= e^{ L h / 2 } u_n + L^{-1} \left( e^{Lh/2} - I \right) \mathcal{N}( t_n, u_n ) \\ b_n &= e^{ L h / 2 } u_n + L^{-1} \left( e^{Lh/2} - I \right) \mathcal{N}( t_n{+}\tfrac{h}{2}, a_n ) \\ c_n &= e^{ L h / 2 } a_n + L^{-1} \left( e^{Lh/2} - I \right) \left( 2 \mathcal{N}( t_n{+}\tfrac{h}{2}, b_n ) - \mathcal{N}(t_n,u_n) \right) \end{aligned}$$

The final update is given by,

$$\begin{aligned} u_{n+1} = e^{L h} u_n + h^{-2} L^{-3} \Bigl\{ \hphantom{{}+2} &\left[ -4 - Lh + e^{Lh} \left( 4 - 3 L h + (L h)^2 \right) \right] \mathcal{N}( t_n, u_n ) \\ {}+ 2&\left[ 2 + L h + e^{Lh} \left( -2 + L h \right) \right] \left[ \mathcal{N}( t_n{+}\tfrac{h}{2}, a_n ) + \mathcal{N}( t_n{+}\tfrac{h}{2}, b_n ) \right] \\ {}+\hphantom{2} &\left[ -4 - 3L h - (Lh)^2 + e^{Lh} \left(4 - Lh \right) \right] \mathcal{N}( t_n{+}h, c_n ) \Bigr\}. \end{aligned}$$

If implemented naively, the above algorithm suffers from numerical instabilities due to [floating point](https://en.wikipedia.org/wiki/Floating_point) round-off errors.[^o26] To see why, consider the first function,

$$\varphi_1( z ) = \frac{ e^z-1 }{ z },$$

which is present in the first-order Euler method, as well as all three stages of ETDRK4. For small values of $z$, this function suffers from numerical cancellation errors. However, these numerical issues can be avoided by evaluating the $\varphi_1$ function via a contour integral approach [^o26] or by a [Padé approximant](wikipedia://en/3090820).[^o27]

::: {#o29 .application cue=heading name="Applications"}

## Applications {#Applications}

Exponential integrators are used for the simulation of stiff scenarios in [scientific](wikipedia://en/1181008) and [visual](https://en.wikipedia.org/wiki/Visual_computing) computing, for example in [molecular dynamics](wikipedia://en/198608),[^o30] for [VLSI](https://en.wikipedia.org/wiki/Very-large-scale_integration) circuit simulation,[^o31][^o32] and in [computer graphics](https://en.wikipedia.org/wiki/Computer_graphics).[^o33] They are also applied in the context of [hybrid monte carlo](https://en.wikipedia.org/wiki/Hybrid_Monte_Carlo) methods.[^o34] In these applications, exponential integrators show the advantage of large time stepping capability and high accuracy. To accelerate the evaluation of matrix functions in such complex scenarios, exponential integrators are often combined with Krylov subspace projection methods.

:::
