# Parthasarathy's theorem

::: {#o1 .subject cue=lead name="Parthasarathy's theorem"}

In [mathematics](wikipedia://en/18831) – and in particular the study of games on the unit square – **Parthasarathy's theorem** is a generalization of [Von Neumann's minimax theorem](wikipedia://en/645602). It states that a particular class of games has a mixed value, provided that at least one of the players has a [strategy](https://en.wikipedia.org/wiki/Strategy) that is restricted to absolutely continuous distributions with respect to the [Lebesgue measure](wikipedia://en/18198) (in other words, one of the players is forbidden to use a [pure strategy](https://en.wikipedia.org/wiki/Pure_strategy)).

:::

The theorem is attributed to [Thiruvenkatachari Parthasarathy](wikipedia://en/18795039).

::: {#o3 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

Let $X$ and $Y$ stand for the [unit interval](wikipedia://en/49324) $[0,1]$; $\mathcal M_X$ denote the set of [probability distributions](wikipedia://en/23543) on $X$ (with $\mathcal M_Y$ defined similarly); and $A_X$ denote the set of [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) distributions on $X$ (with $A_Y$ defined similarly).

Suppose that $k(x,y)$ is bounded on the unit square $X \times Y = \{(x,y) : 0\leq x,y\leq 1\}$ and that $k(x,y)$ is [continuous](wikipedia://en/6122) except possibly on a finite number of curves of the form $y=\phi_k(x)$ (with $k=1,2,\ldots,n$) where the $\phi_k(x)$ are continuous functions. For $\mu \in M_X, \lambda \in M_Y$, define

$$k(\mu,\lambda)=\int_{y=0}^1\int_{x=0}^1 k(x,y)\,d\mu(x)\,d\lambda(y)= \int_{x=0}^1\int_{y=0}^1 k(x,y)\,d\lambda(y)\,d\mu(x).$$

Then

$$\max_{\mu\in{\mathcal M}_X}\,\inf_{\lambda\in A_Y}k(\mu,\lambda)= \inf_{\lambda\in A_Y}\,\max_{\mu\in{\mathcal M}_X} k(\mu,\lambda).$$

This is equivalent to the statement that the game induced by $k(\cdot,\cdot)$ has a value. Note that one player ([WLOG](wikipedia://en/296000) $Y$) is forbidden from using a pure strategy.

Parthasarathy goes on to exhibit a game in which

$$\max_{\mu\in{\mathcal M}_X}\,\inf_{\lambda\in{\mathcal M}_Y}k(\mu,\lambda)\neq \inf_{\lambda\in{\mathcal M}_Y}\,\max_{\mu\in{\mathcal M}_X} k(\mu,\lambda)$$

which thus has no value. There is no contradiction because in this case neither player is restricted to absolutely continuous distributions (and the demonstration that the game has no value requires both players to use pure strategies).

:::
