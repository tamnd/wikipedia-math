# Popov criterion

::: {#o1 .subject cue=lead name="Popov criterion"}

In nonlinear control and stability theory, the **Popov criterion** is a [stability criterion](https://en.wikipedia.org/wiki/Stability_criterion) discovered by [Vasile M. Popov](https://en.wikipedia.org/wiki/Vasile_M._Popov) for the absolute stability of a class of nonlinear systems whose nonlinearity must satisfy an open-sector condition. While the [circle criterion](wikipedia://en/18305300) can be applied to nonlinear time-varying systems, the Popov criterion is applicable only to autonomous (that is, [time invariant](https://en.wikipedia.org/wiki/Time_invariant)) systems.

:::

## System description {#System_description}

The sub-class of Lur'e systems studied by [Popov](https://en.wikipedia.org/wiki/Vasile_M_Popov) is described by:

$$\begin{aligned} \dot{x} & = Ax+bu \\ \dot{\xi} & = u \\ y & = cx+d\xi \end{aligned}$$

$$\begin{matrix} u = -\varphi (y) \end{matrix}$$

where *x* ∈ **R**<sup>*n*</sup>, *ξ*,*u*,*y* are scalars, and *A*,*b*,*c* and *d* have commensurate dimensions. The nonlinear element Φ: **R** → **R** is a time-invariant nonlinearity belonging to *open sector* (0, ∞), that is, Φ(0) = 0 and *y*Φ(*y*) > 0 for all *y* not equal to 0.

Note that the system studied by Popov has a pole at the origin and there is no direct pass-through from input to output, and the transfer function from *u* to *y* is given by

$$H(s) = \frac{d}{s} + c(sI-A)^{-1}b$$

::: {#o4 .statement cue=named-heading name="Criterion"}

## Criterion {#Criterion}

Consider the system described above and suppose

1. *A* is [Hurwitz](https://en.wikipedia.org/wiki/Routh_Hurwitz_stability_criterion)
1. (*A*,*b*) is controllable
1. (*A*,*c*) is observable
1. *d* > 0 and
1. Φ ∈ (0,∞)

then the system is [globally asymptotically stable](https://en.wikipedia.org/wiki/Globally_asymptotically_stable) if there exists a number *r* > 0 such that $\inf_{\omega\,\in\,\mathbb R} \operatorname{Re} \left[ (1+j\omega r) H(j\omega)\right] > 0.$

:::
