# Classification of discontinuities

::: {#o1 .subject cue=lead name="Classification of discontinuities"}

While [continuous functions](wikipedia://en/6122) are important in [mathematics](wikipedia://en/18831), not all [functions](wikipedia://en/185427) are continuous. If a function is not continuous at a [limit point](https://en.wikipedia.org/wiki/Limit_point) (also called an "accumulation point" or "cluster point") of its [domain](wikipedia://en/50263), it has a **discontinuity** there. The [set](wikipedia://en/26691) of all points of discontinuity of a function may be a [discrete set](https://en.wikipedia.org/wiki/Discrete_set), a [dense set](wikipedia://en/23523594), or even the entire domain of the function.

:::

In elementary [real analysis](wikipedia://en/26478), discontinuities of real functions of one real variable are often distinguished according to the behavior of one-sided limits. While a classification is not entirely standard, a common division is between discontinuities of the first kind, where the relevant one-sided limits exist, and discontinuities of the second kind, where at least one one-sided limit fails to exist or is infinite. Special cases include [removable discontinuities](https://en.wikipedia.org/wiki/Removable_discontinuity) and [jump discontinuities](https://en.wikipedia.org/wiki/Jump_discontinuity).

## Classification {#Classification}

For each of the following, consider a [real valued function](wikipedia://en/22284647) $f$ of a real variable $x,$ defined in a neighborhood of the point $x_0$ at which $f$ is discontinuous.

::: {#o4 .pointer-item cue=pointer name="Removable discontinuity"}

### Removable discontinuity {#Removable_discontinuity}

*Image: Discontinuity removable.eps.png.* The function in example 1, a removable discontinuity

Consider the [piecewise](https://en.wikipedia.org/wiki/Piecewise) function

$$f(x) = \begin{cases} x^2 & \text{ for } x < 1 \\ 0 & \text{ for } x = 1 \\ 2-x & \text{ for } x > 1 \end{cases}$$

The point $x_0 = 1$ is a *removable [discontinuity](wikipedia://en/6122)*. For this kind of discontinuity:

The [one-sided limit](wikipedia://en/379840) from the negative direction:

$$L^- = \lim_{x\to x_0^-} f(x)$$

and the one-sided limit from the positive direction:

$$L^+ = \lim_{x\to x_0^+} f(x)$$

at $x_0$ *both* exist, are finite, and are equal to $L = L^- = L^+.$ In other words, since the two one-sided limits exist and are equal, the limit $L$ of $f(x)$ as $x$ approaches $x_0$ exists and is equal to this same value. If the actual value of $f\left(x_0\right)$ is *not* equal to $L,$ then $x_0$ is called a **removable discontinuity**. This discontinuity can be removed to make $f$ continuous at $x_0,$ or more precisely, the function

$$g(x) = \begin{cases} f(x) & x \neq x_0 \\ L & x = x_0 \end{cases}$$

is continuous at $x = x_0.$

The term *removable discontinuity* is sometimes broadened to include a [removable singularity](wikipedia://en/81644), in which the limits in both directions exist and are equal, while the function is [undefined](https://en.wikipedia.org/wiki/Defined_and_undefined) at the point $x_0.$ This use is an [abuse of terminology](https://en.wikipedia.org/wiki/Abuse_of_terminology) because [continuity](wikipedia://en/6122) and discontinuity of a function are concepts defined only for points in the function's domain.

:::

::: {#o6 .pointer-item cue=pointer name="Jump discontinuities"}

### Jump discontinuity {#Jump_discontinuity}

*Image: Discontinuity jump.eps.png.* The function in example 2, a jump discontinuity

Consider the function

$$f(x) = \begin{cases} x^2 & \mbox{ for } x < 1 \\ 0 & \mbox{ for } x = 1 \\ 2 - (x-1)^2 & \mbox{ for } x > 1 \end{cases}$$

Then, the point $x_0 = 1$ is a *jump discontinuity*.

In this case, a single limit does not exist because the one-sided limits, $L^-$ and $L^+$ exist and are finite, but are **not** equal: since, $L^- \neq L^+,$ the limit $L$ does not exist. Then, $x_0$ is called a *jump discontinuity*, *step discontinuity*, or *discontinuity of the first kind*. For this type of discontinuity, the function $f$ may have any value at $x_0.$

:::

::: {#o8 .pointer-item cue=pointer name="Essential discontinuity"}

### Essential discontinuity {#Essential_discontinuity}

*Image: Discontinuity essential.svg.* The function in example 3, an essential discontinuity

For an essential discontinuity, at least one of the two one-sided limits does not exist in $\mathbb{R}$. (Notice that one or both one-sided limits can be $\pm\infty$).

Consider the function

$$f(x) = \begin{cases} \sin\frac{5}{x-1} & \text{ for } x < 1 \\ 0 & \text{ for } x = 1 \\ \frac{1}{x-1} & \text{ for } x > 1. \end{cases}$$

Then, the point $x_0 = 1$ is an *essential discontinuity*.

In this example, both $L^-$ and $L^+$ do not exist in $\mathbb{R}$, thus satisfying the condition of essential discontinuity. So $x_0$ is an essential discontinuity, infinite discontinuity, or discontinuity of the second kind. (This is distinct from an [essential singularity](wikipedia://en/80862), which is often used when studying [functions of complex variables](wikipedia://en/5759)).

:::

## Counting discontinuities of a function {#Counting_discontinuities_of_a_function}

Supposing that $f$ is a function defined on an interval $I \subseteq \mathbb{R},$ we will denote by $D$ the set of all discontinuities of $f$ on $I.$ By $R$ we will mean the set of all $x_0\in I$ such that $f$ has a *removable* discontinuity at $x_0.$ Analogously by $J$ we denote the set constituted by all $x_0\in I$ such that $f$ has a *jump* discontinuity at $x_0.$ The set of all $x_0\in I$ such that $f$ has an *essential* discontinuity at $x_0$ will be denoted by $E.$ Of course then $D = R \cup J \cup E.$

The two following properties of the set $D$ are relevant in the literature.

- The set $D$ is an [$F_{\sigma}$ set](https://en.wikipedia.org/wiki/F-sigma_set). The set of points at which a function is continuous is always a [$G_{\delta}$ set](https://en.wikipedia.org/wiki/G-delta_set) (see[^o10]).
- If on the interval $I,$ $f$ is monotone then $D$ is [at most countable](https://en.wikipedia.org/wiki/Countable) and $D = J.$ This is [Froda's theorem](https://en.wikipedia.org/wiki/Froda's_theorem).

Tom Apostol[^o11] follows partially the classification above by considering only removable and jump discontinuities. His objective is to study the discontinuities of monotone functions, mainly to prove Froda’s theorem. With the same purpose, Walter Rudin[^o12] and Karl R. Stromberg[^o13] study also removable and jump discontinuities by using different terminologies. However, furtherly, both authors state that $R \cup J$ is always a countable set (see[^o14][^o15]).

The term *essential discontinuity* has evidence of use in mathematical context as early as 1889.[^o16] However, the earliest use of the term alongside a mathematical definition seems to have been given in the work by John Klippert.[^o17] Therein, Klippert also classified essential discontinuities themselves by subdividing the set $E$ into the three following sets:

$$\begin{aligned} E_1 &= \Bigl\{x_0\in I : \lim_{x\to x_0^-} f(x) \text{ and } \lim_{x\to x_0^+} f(x) \text{ do not exist in }\mathbb{R} \Bigr\}, \\[5pt] E_2 &= \Bigl\{x_0\in I : \ \lim_{x\to x_0^-} f(x) \text{ exists in } \mathbb{R}\text { and } \lim_{x\to x_0^+} f(x) \text{ does not exist in } \mathbb{R}\Bigr\}, \\[5pt] E_3 &= \Bigl\{x_0\in I : \ \lim_{x\to x_0^-} f(x) \text{ does not exist in } \mathbb{R}\text { and } \lim_{x\to x_0^+} f(x) \text{ exists in }\mathbb{R}\Bigr\}. \end{aligned}$$

Of course $E=E_1 \cup E_2 \cup E_3.$ Whenever $x_0\in E_1,$ $x_0$ is called an *essential discontinuity of first kind*. Any $x_0 \in E_2 \cup E_3$ is said an *essential discontinuity of second kind.* Hence he enlarges the set $R \cup J$ without losing its characteristic of being countable, by stating the following:

- The set $R \cup J \cup E_2 \cup E_3$ is countable.

::: {#o19 .statement kind=statement/theorem cue=named-heading name="Rewriting Lebesgue's theorem"}

## Rewriting Lebesgue's theorem {#Rewriting_Lebesgue's_theorem}

When $I=[a,b]$ and $f$ is a [bounded function](wikipedia://en/311509), it is well-known of the importance of the set $D$ in the regard of the Riemann [integrability](wikipedia://en/26390#Integrability) of $f.$ In fact, [Lebesgue's theorem (also named Lebesgue-Vitali theorem)](wikipedia://en/26390#Integrability) states that $f$ is Riemann integrable on $I = [a,b]$ if and only if $D$ is a set with Lebesgue's measure zero.

In this theorem seems that all type of discontinuities have the same weight on the obstruction that a bounded function $f$ be Riemann integrable on $[a,b].$ Since countable sets are sets of Lebesgue's measure zero and a countable union of sets with Lebesgue's measure zero is still a set of Lebesgue's measure zero, we are seeing now that this is not the case. In fact, the discontinuities in the set $R \cup J \cup E_2 \cup E_3$ are absolutely neutral in the regard of the Riemann integrability of $f.$ The main discontinuities for that purpose are the essential discontinuities of first kind and consequently the Lebesgue-Vitali theorem can be rewritten as follows:

- A bounded function, $f,$ is Riemann integrable on $[a,b]$ [if and only if](wikipedia://en/14922) the correspondent set $E_1$ of all essential discontinuities of first kind of $f$ has Lebesgue's measure zero.

The case where $E_1 = \varnothing$ correspond to the following well-known classical complementary situations of Riemann integrability of a bounded function $f : [a, b] \to \mathbb{R}$:

- If $f$ has right-hand limit at each point of $[a, b[$ then $f$ is Riemann integrable on $[a, b]$ (see[^o20])
- If $f$ has left-hand limit at each point of $]a, b]$ then $f$ is Riemann integrable on $[a, b].$
- If $f$ is a [regulated function](wikipedia://en/9776617) on $[a, b]$ then $f$ is [Riemann integrable](wikipedia://en/9776617#Properties_of_regulated_functions) on $[a, b].$

::: {#o22 .example cue=heading name="Examples"}

### Examples {#Examples}

[Thomae's function](wikipedia://en/3397404) is discontinuous at every non-zero [rational point](wikipedia://en/2960200), but continuous at every [irrational](wikipedia://en/20647689) point. One easily sees that those discontinuities are all removable. By the first paragraph, there does not exist a function that is continuous at every [rational](wikipedia://en/19727024) point, but discontinuous at every irrational point.

The [indicator function](wikipedia://en/240790) of the rationals, also known as the [Dirichlet function](wikipedia://en/630005), is [discontinuous everywhere](https://en.wikipedia.org/wiki/Nowhere_continuous). These discontinuities are all essential of the first kind too.

Consider now the ternary [Cantor set](wikipedia://en/6172) $\mathcal{C} \subset [0,1]$ and its indicator (or characteristic) function

$$\mathbf 1_\mathcal{C}(x) = \begin{cases} 1 & x \in \mathcal{C} \\ 0 & x \in [0,1] \setminus \mathcal{C}. \end{cases}$$

[One way to construct](wikipedia://en/6172#Construction_and_formula_of_the_ternary_set) the Cantor set $\mathcal{C}$ is given by $\mathcal{C} := \bigcap_{n=0}^\infty C_n$ where the sets $C_n$ are obtained by recurrence according to

$$C_n = \frac{C_{n-1}} 3 \cup \left(\frac 2 {3} + \frac{C_{n-1}} 3\right) \text{ for } n \geq 1, \text{ and } C_0 = [0, 1].$$

In view of the discontinuities of the function $\mathbf 1_\mathcal{C}(x),$ let's assume a point $x_0\not\in\mathcal{C}.$

Therefore there exists a set $C_n,$ used in the [formulation of $\mathcal{C}$](wikipedia://en/6172), which does not contain $x_0.$ That is, $x_0$ belongs to one of the open intervals which were removed in the construction of $C_n.$ This way, $x_0$ has a neighbourhood with no points of $\mathcal{C}.$ (In another way, the same conclusion follows taking into account that [$\mathcal{C}$](wikipedia://en/6172) is a [closed set](wikipedia://en/47279) and so its complementary with respect to $[0, 1]$ is open). Therefore $\mathbf 1_\mathcal{C}$ only assumes the value zero in some neighbourhood of $x_0.$ Hence $\mathbf 1_\mathcal{C}$ is continuous at $x_0.$

This means that the set $D$ of all discontinuities of $\mathbf 1_\mathcal{C}$ on the interval $[0, 1]$ is a subset of $\mathcal{C}.$ Since $\mathcal{C}$ is an [uncountable set with null Lebesgue measure](wikipedia://en/6172#Measure_and_probability), also $D$ is a null Lebesgue measure set and so in the regard of [Lebesgue-Vitali theorem](wikipedia://en/26390#Integrability) $\mathbf 1_\mathcal{C}$ is a Riemann integrable function.

More precisely one has $D = \mathcal{C}.$ In fact, since $\mathcal{C}$ is a nonwhere dense set, if $x_0\in\mathcal{C}$ then no [neighbourhood](wikipedia://en/1529485) $\left(x_0-\varepsilon, x_0+\varepsilon\right)$ of $x_0,$ can be contained in $\mathcal{C}.$ This way, any neighbourhood of $x_0\in\mathcal{C}$ contains points of $\mathcal{C}$ and points which are not of $\mathcal{C}.$ In terms of the function $\mathbf 1_\mathcal{C}$ this means that both $\lim_{x\to x_0^-} \mathbf 1_\mathcal{C}(x)$ and $\lim_{x\to x_0^+} 1_\mathcal{C}(x)$ do not exist. That is, $D = E_1,$ where by $E_1,$ as before, we denote the set of all essential discontinuities of first kind of the function $\mathbf 1_\mathcal{C}.$ Clearly $\int_0^1 \mathbf 1_\mathcal{C}(x)dx = 0.$

:::

## Discontinuities of derivatives {#Discontinuities_of_derivatives}

Let $I \subseteq \mathbb{R}$ an open interval, let $F:I\to\mathbb{R}$ be differentiable on $I,$ and let $f:I\to\mathbb{R}$ be the derivative of $F.$ That is, $F'(x)=f(x)$ for every $x\in I$. According to [Darboux's theorem](wikipedia://en/4130888), the derivative function $f: I \to \mathbb{R}$ satisfies the intermediate value property. The function $f$ can, of course, be continuous on the interval $I,$ in which case [Bolzano's theorem](wikipedia://en/14884) also applies. Recall that Bolzano's theorem asserts that every continuous function satisfies the intermediate value property. On the other hand, the converse is false: Darboux's theorem does not assume $f$ to be continuous and the intermediate value property does not imply $f$ is continuous on $I.$

Darboux's theorem does, however, have an immediate consequence on the type of discontinuities that $f$ can have. On the other hand, a new type of discontinuity with respect to any function $f:I\to\mathbb{R}$ can be introduced: an essential discontinuity, $x_0 \in I$, of the function $f$, is said to be a *fundamental essential discontinuity* of $f$ if

$$\lim_{x\to x_0^-} f(x)\neq\pm\infty$$

and

$$\lim_{x\to x_0^+} f(x)\neq\pm\infty.$$

Therefore if $x_0\in I$ is a discontinuity of a derivative function $f:I\to\mathbb{R}$, then necessarily $x_0$ is a fundamental essential discontinuity of $f$.

Notice also that when $I=[a,b]$ and $f:I\to\mathbb{R}$ is a bounded function, as in the assumptions of Lebesgue's theorem, we have for all $x_0\in (a,b)$:

$$\lim_{x\to x_0^\pm} f(x)\neq\pm\infty ,$$

$$\lim_{x\to a^+} f(x)\neq\pm\infty,$$

and

$$\lim_{x\to b^-} f(x)\neq\pm\infty.$$

Therefore any essential discontinuity of $f$ is a fundamental one.
