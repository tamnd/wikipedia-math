# Lowest common divisor

::: {#o1 .subject cue=lead name="Lowest common divisor"}

The **lowest common divisor** is a term mistakenly used to refer to:[^o2]

:::

- [Lowest common denominator](wikipedia://en/378200), the lowest common multiple of the denominators of a set of fractions
- [Greatest common divisor](wikipedia://en/12354), the largest positive integer that divides each of the integers
