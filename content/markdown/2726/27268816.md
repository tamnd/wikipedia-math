# Cycle decomposition (graph theory)

*Image: Cycle decomposition.svg.* A **cycle decomposition** of a graph. The edges are partitioned into two sets (blue and orange) where each set forms a [cycle](wikipedia://en/168609).

::: {#o1 .subject cue=lead name="Cycle decomposition"}

In [graph theory](wikipedia://en/12401), a **cycle decomposition** is a decomposition (a [partitioning](wikipedia://en/340240) of a graph's edges) into [cycles](wikipedia://en/168609). Every vertex in a graph that has a cycle decomposition must have even degree.

:::

## Cycle decomposition of *K<sub>n</sub>* and *K<sub>n</sub>* − *I* {#Cycle_decomposition_of_Kn_and_Kn_−_I}

[Brian Alspach](wikipedia://en/42451632) and Heather Gavlas established necessary and sufficient conditions for the existence of a decomposition of a [complete graph](wikipedia://en/85816) of even order minus a [1-factor](wikipedia://en/3298854) (a [perfect matching](wikipedia://en/44031)) into even cycles and a complete graph of odd order into odd cycles.[^o3] Their proof relies on [Cayley graphs](wikipedia://en/358277), in particular, [circulant graphs](wikipedia://en/3498787), and many of their decompositions come from the action of a [permutation](wikipedia://en/44027) on a fixed subgraph.

They proved that for positive even integers $m$ and $n$ with $4\leq m\leq n$, the graph $K_n-I$ (where $I$ is a 1-factor) can be decomposed into cycles of length $m$ if and only if the number of edges in $K_n-I$ is a multiple of $m$. Also, for positive odd integers $m$ and $n$ with $3\leq m\leq n$, the graph $K_n$ can be decomposed into cycles of length $m$ if and only if the number of edges in $K_n$ is a multiple of $m$.

## Computational complexity {#Computational_complexity}

The problem of decomposing an [Eulerian graph](https://en.wikipedia.org/wiki/Eulerian_graph) into a minimum number of edge-disjoint cycles is [NP-complete](https://en.wikipedia.org/wiki/NP-complete), as is the corresponding problem of decomposing into a maximum number of cycles.[^o5]

An Eulerian graph has a unique number of cycles in all of its cycle decompositions if and only if no two edge-disjoint cycles in the graph share more than two vertices. This property can be decided in polynomial time: there exists an algorithm running in time $\mathcal{O}(n(n+m))$ that determines whether the cycle number of a given Eulerian graph is unique, where $n$ is the number of vertices and $m$ is the number of edges.[^o5]

## Algorithms {#Algorithms}

Several approaches have been developed for finding optimal cycle decompositions. For the Maximum Eulerian Cycle Decomposition problem, [column generation](wikipedia://en/744589) techniques can be applied to an [integer linear programming](https://en.wikipedia.org/wiki/Integer_linear_programming) model with an exponential number of variables.[^o8]

[Heuristic approaches](wikipedia://en/14220429) include [greedy algorithms](wikipedia://en/89247) that iteratively find minimum-sized cycles starting from random vertices, and **ILP-based heuristics** that solve restricted versions of the integer programming model using only a subset of possible cycles. These methods provide practical solutions for large instances where exact algorithms become computationally infeasible.[^o8]

## Applications {#Applications}

### Network analysis {#Network_analysis}

Cycle decompositions can be applied to [Markov processes](wikipedia://en/60876) on finite state spaces for analyzing [directed networks](wikipedia://en/19721986). Given an ergodic Markov chain with transition matrix $P$ and stationary distribution $\pi$, the probability flow can be decomposed into cycles with positive weights. A stochastic decomposition approach yields a unique cycle decomposition where the weight $w(\gamma)$ of each cycle $\gamma$ equals the mean number of times a random walk passes through that cycle per time step.[^o12]

This approach can reveal modular structures in directed networks based on information flow rather than link density alone, providing insights that traditional methods may miss.[^o12]

### Genome rearrangement {#Genome_rearrangement}

In [comparative genomics](https://en.wikipedia.org/wiki/Comparative_genomics), cycle decompositions of [breakpoint graphs](https://en.wikipedia.org/wiki/Breakpoint_graph) are used to compute genome rearrangement distances. The Maximum Breakpoint Graph Decomposition problem can be reduced to the Maximum Eulerian Cycle Decomposition problem in polynomial time.[^o8]
