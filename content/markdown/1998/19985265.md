# Red auxiliary number

::: {#o1 .subject cue=lead name="Red auxiliary number"}

In the study of [ancient Egyptian mathematics](wikipedia://en/1180105), **red auxiliary numbers** are numbers written in red ink in the [Rhind Mathematical Papyrus](wikipedia://en/9210114), apparently used as aids for arithmetic computations involving [fractions](https://en.wikipedia.org/wiki/Fraction_%28mathematics%29). It is considered to be the first examples of method that uses [least common multiples](wikipedia://en/17961).

:::
