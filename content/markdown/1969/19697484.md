# Axis-aligned object

::: {#o1 .subject cue=lead name="Axis-aligned object"}

In [geometry](wikipedia://en/18973446), an **axis-aligned object** (**axis-parallel**, **axis-oriented**) is an object in *n*-dimensional space whose shape is aligned with the [coordinate axes](https://en.wikipedia.org/wiki/Coordinate_axes) of the space.

:::

Examples are [axis-aligned rectangles](https://en.wikipedia.org/wiki/Axis-aligned_rectangle) (or [hyperrectangles](wikipedia://en/1688550)), the ones with edges parallel to the coordinate axes. [Minimum bounding boxes](wikipedia://en/12087300) are often implicitly assumed to be axis-aligned. A more general case is [rectilinear polygons](wikipedia://en/8779182), the ones with all sides parallel to coordinate axes or rectilinear polyhedra.

Many problems in [computational geometry](wikipedia://en/176927) allow for faster algorithms when restricted to (collections of) axis-oriented objects, such as axis-aligned rectangles or axis-aligned line segments.[^o2]

A different kind of example are axis-aligned ellipsoids, i.e., the [ellipsoids](wikipedia://en/145381) with principal axes parallel to the coordinate axes.
