# Vector measure

::: {#o1 .subject cue=lead name="Vector measure"}

In [mathematics](wikipedia://en/18831), a **vector measure** is a [function](wikipedia://en/185427) defined on a [family of sets](wikipedia://en/723043) and taking [vector](wikipedia://en/32370) values satisfying certain properties. It is a generalization of the concept of finite [measure](wikipedia://en/19873), which takes [nonnegative](https://en.wikipedia.org/wiki/Nonnegative) [real](wikipedia://en/20646438) values only.

:::

## Definitions and first consequences {#Definitions_and_first_consequences}

Given a [field of sets](wikipedia://en/1018676) $(\Omega, \mathcal F)$ and a [Banach space](wikipedia://en/3989) $X,$ a **finitely additive vector measure** (or **measure**, for short) is a function $\mu:\mathcal {F} \to X$ such that for any two [disjoint sets](https://en.wikipedia.org/wiki/Disjoint_set) $A$ and $B$ in $\mathcal{F}$ one has

$$\mu(A\cup B) =\mu(A) + \mu (B).$$

A vector measure $\mu$ is called **countably additive** if for any [sequence](wikipedia://en/27838) $(A_i)_{i=1}^{\infty}$ of disjoint sets in $\mathcal F$ such that their union is in $\mathcal F$ it holds that

$$\mu{\left(\bigcup_{i=1}^\infty A_i\right)} = \sum_{i=1}^{\infty}\mu(A_i)$$

with the [series](wikipedia://en/15287) on the right-hand side convergent in the [norm](wikipedia://en/990534) of the Banach space $X.$

It can be proved that an additive vector measure $\mu$ is countably additive if and only if for any sequence $(A_i)_{i=1}^{\infty}$ as above one has

::: {#o3 .equation cue=numblk name="<nowiki>*</nowiki>"}

$$\lim_{n\to\infty} \left\|\mu{\left(\bigcup_{i=n}^\infty A_i\right)}\right\| = 0, \tag{*}$$

:::

where $\|\cdot\|$ is the norm on $X.$

Countably additive vector measures defined on [sigma-algebras](https://en.wikipedia.org/wiki/Sigma-algebra) are more general than finite [measures](wikipedia://en/19873), finite [signed measures](wikipedia://en/2985811), and [complex measures](wikipedia://en/3057532), which are [countably additive functions](https://en.wikipedia.org/wiki/Countably_additive_function) taking values respectively on the real interval $[0, \infty),$ the set of [real numbers](wikipedia://en/20646438), and the set of [complex numbers](wikipedia://en/5826).

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Consider the field of sets made up of the interval $[0, 1]$ together with the family $\mathcal F$ of all [Lebesgue measurable sets](https://en.wikipedia.org/wiki/Lebesgue_measurable_set) contained in this interval. For any such set $A,$ define

$$\mu(A) = \chi_A$$

where $\chi_A$ is the [indicator function](wikipedia://en/240790) of $A.$ Depending on where $\mu$ is declared to take values, two different outcomes are observed.

- $\mu,$ viewed as a function from $\mathcal F$ to the [$L^p$-space](wikipedia://en/45194) $L^\infty([0, 1]),$ is a vector measure which is not countably-additive.
- $\mu,$ viewed as a function from $\mathcal F$ to the $L^p$-space $L^1([0, 1]),$ is a countably-additive vector measure.

Both of these statements follow quite easily from the criterion ((*)) stated above.

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="The variation of a vector measure"}

## The variation of a vector measure {#The_variation_of_a_vector_measure}

Given a vector measure $\mu : \mathcal{F} \to X,$ the **variation** $|\mu|$ of $\mu$ is defined as

$$|\mu|(A)=\sup \sum_{i=1}^n \|\mu(A_i)\|$$

where the [supremum](https://en.wikipedia.org/wiki/Supremum) is taken over all the [partitions](wikipedia://en/340240)

$$A = \bigcup_{i=1}^n A_i$$

of $A$ into a finite number of disjoint sets, for all $A$ in $\mathcal{F}.$ Here, $\|\cdot\|$ is the norm on $X.$

The variation of $\mu$ is a finitely additive function taking values in $[0, \infty].$ It holds that

$$\|\mu(A)\| \leq |\mu|(A)$$

for any $A$ in $\mathcal{F}.$ If $|\mu|(\Omega)$ is finite, the measure $\mu$ is said to be of **bounded variation**. One can prove that if $\mu$ is a vector measure of bounded variation, then $\mu$ is countably additive if and only if $|\mu|$ is countably additive.

:::

::: {#o9 .statement kind=statement/theorem cue=named-heading name="Lyapunov's theorem"}

## Lyapunov's theorem {#Lyapunov's_theorem}

In the theory of vector measures, *[Lyapunov](wikipedia://en/14655582)'s theorem* states that the range of a ([non-atomic](wikipedia://en/3058373)) finite-dimensional vector measure is [closed](wikipedia://en/47279) and [convex](wikipedia://en/6292).[^o10][^o11][^o12] In fact, the range of a non-atomic vector measure is a [zonoid](wikipedia://en/30539568) (the closed and convex set that is the limit of a convergent sequence of [zonotopes](wikipedia://en/669406)).[^o11] It is used in [economics](wikipedia://en/18967255),[^o13][^o14][^o15] in (["bang–bang"](wikipedia://en/5971657)) [control theory](wikipedia://en/7039),[^o10][^o12][^o16][^o17] and in [statistical theory](wikipedia://en/27579).[^o17] Lyapunov's theorem has been proved by using the [Shapley–Folkman lemma](wikipedia://en/29237460),[^o18] which has been viewed as a [discrete](wikipedia://en/330017) [analogue](wikipedia://en/8492#Discrete_analogues_of_continuous_mathematics) of Lyapunov's theorem.[^o17][^o19][^o20]
