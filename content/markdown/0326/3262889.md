# Omega-regular language

::: {#o1 .subject cue=lead name="Omega-regular language"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science) and [formal language theory](https://en.wikipedia.org/wiki/Formal_language_theory), the **ω-regular languages** are a class of [ω-languages](wikipedia://en/3983826) that generalize the definition of [regular languages](wikipedia://en/25723) to infinite words. As regular languages accept finite strings (such as strings beginning in an *a*, or strings alternating between *a* and *b*), ω-regular languages accept infinite words (such as, infinite sequences beginning in an *a*, or infinite sequences alternating between *a* and *b*).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let *A* be a [language](wikipedia://en/10939). Denote by *A*<sup>ω</sup> the set whose elements are obtained by concatenating words from *A* infinitely many times, i.e the set of functions $\omega \to A$.

The class of ω-regular ω-languages is defined inductively as follows

- *A*<sup>ω</sup>, where *A* is a regular language not containing the empty string, is ω-regular;
- *AB*, the concatenation of a regular language *A* and an ω-regular language *B* (Note that *BA* is *not* well-defined), is ω-regular;
- *A* ∪ *B*, where *A* and *B* are ω-regular languages (this rule can only be applied finitely many times), is ω-regular.

Note that if *A* is regular, *A*<sup>ω</sup> is not necessarily ω-regular, since *A* could be for example {ε}, the set containing only the [empty string](wikipedia://en/835827), in which case *A*<sup>ω</sup>=*A*, which is not an ω-language and therefore not an ω-regular language.

It is a straightforward consequence of the definition that the ω-regular languages are precisely the ω-languages of the form *A*<sub>1</sub>*B*<sub>1</sub><sup>ω</sup> ∪ ... ∪ *A*<sub>*n*</sub>*B*<sub>*n*</sub><sup>ω</sup> for some *n*, where the *A*<sub>*i*</sub>s and *B*<sub>*i*</sub>s are regular languages and the *B*<sub>*i*</sub>s do not contain the empty string.

:::

## Equivalence to Büchi automaton {#Equivalence_to_Büchi_automaton}

::: {#o5 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

An ω-language is recognized by a [Büchi automaton](wikipedia://en/344912) if and only if it is an ω-regular language.

:::

::: {#o6 .proof cue=math-proof}

Every ω-regular language is recognized by a nondeterministic Büchi automaton; the translation is constructive. Using the [closure properties of Büchi automata](https://en.wikipedia.org/wiki/Büchi_automata#Closure_properties) and structural induction over the definition of ω-regular language, it can be easily shown that a Büchi automaton can be constructed for any given ω-regular language.

:::

Conversely, for a given Büchi automaton $A = (Q, \Sigma, \delta, I, F)$, we construct an ω-regular language and then we will show that this language is recognized by *A*. For an *ω*-word *w* = *a*<sub>1</sub>*a*<sub>2</sub>... let *w*(*i*,*j*) be the finite segment *a*<sub>*i*+1</sub>...*a*<sub>*j*−1</sub>*a*<sub>*j*</sub> of *w*. For every $q, q' \in Q$, we define a [regular language](wikipedia://en/25723) *L<sub>q,q'</sub>* that is accepted by the finite automaton $(Q, \Sigma, \delta, q, \{q'\})$.

::: {#o7 .statement kind=statement/lemma cue=math-theorem name="Lemma"}

**Lemma.**

We claim that the Büchi automaton *A* recognizes the language $\bigcup_{q\in I,q'\in F} L_{q,q'} (L_{q',q'} - \{\varepsilon\} )^{\omega}.$

:::

::: {#o8 .proof cue=math-proof}

Let's suppose word $w \in L(A)$ and *q*<sub>0</sub>,*q*<sub>1</sub>,*q*<sub>2</sub>,... is an accepting run of *A* on *w*. Therefore, *q*<sub>0</sub> is in $I$ and there must be a state $q'$ in *F* such that $q'$ occurs infinitely often in the accepting run. Let's pick the strictly increasing infinite sequence of indexes *i*<sub>0</sub>,*i*<sub>1</sub>,*i*<sub>2</sub>... such that, for all *k*≥0, $q_{i_{k}}$ is $q'$. Therefore, $w(0,i_{0})\in L_{q_{0},q'}$ and, for all $k\ge0, w(i_{k},i_{k+1})\in L_{q',q'} .$ Therefore, $w \in L_{q_{0},q'} (L_{q',q'} )^{\omega}.$

Conversely, suppose $w \in L_{q,q'} (L_{q',q'} - \{\varepsilon\} )^{\omega}$ for some $q\in I$ and $q'\in F.$ Therefore, there is an infinite and strictly increasing sequence *i*<sub>0</sub>,*i*<sub>1</sub>,*i*<sub>2</sub>... such that $w(0,i_{0}) \in L_{q,q'}$ and, for all $k\ge0, w(i_{k},i_{k+1})\in L_{q',q'} .$ By definition of *L<sub>q,q'</sub>*, there is a finite run of $A$ from $q$ to $q'$ on word *w*(0,*i*<sub>0</sub>). For all *k*≥0, there is a finite run of $A$ from $q'$ to $q'$ on word *w*(*i<sub>k</sub>*,*i*<sub>*k*+1</sub>). By this construction, there is a run of *A*, which starts from $q$ and in which $q'$ occurs infinitely often. Hence, $w \in L(A)$.

:::

## Equivalence to Monadic second-order logic {#Equivalence_to_Monadic_second-order_logic}

[Büchi](wikipedia://en/6736044) showed in 1962 that ω-regular languages are precisely the ones definable in a particular [monadic second-order logic](wikipedia://en/14650395) called S1S.
