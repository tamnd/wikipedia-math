# Pépin's test

::: {#o1 .subject cue=lead name="Pépin's test"}

In [mathematics](wikipedia://en/18831), **Pépin's test** is a [primality test](wikipedia://en/183751), which can be used to determine whether a [Fermat number](wikipedia://en/91127) is [prime](wikipedia://en/23666). It is a variant of [Proth's test](wikipedia://en/3225985). The test is named after a French mathematician, [Théophile Pépin](wikipedia://en/31285564).

:::

## Description of the test {#Description_of_the_test}

Let $F_n=2^{2^n}+1$ be the *n*th Fermat number. Pépin's test states that for *n* > 0,

$F_n$ is prime if and only if $3^{(F_n-1)/2}\equiv-1\pmod{F_n}.$

The expression $3^{(F_n-1)/2}$ can be evaluated modulo $F_n$ by [repeated squaring](wikipedia://en/10237). This makes the test a fast [polynomial-time](https://en.wikipedia.org/wiki/Polynomial-time) algorithm. However, Fermat numbers grow so rapidly that only a handful of Fermat numbers can be tested in a reasonable amount of time and space.

Other bases may be used in place of 3. These bases are:

3, 5, 6, 7, 10, 12, 14, 20, 24, 27, 28, 39, 40, 41, 45, 48, 51, 54, 56, 63, 65, 75, 78, 80, 82, 85, 90, 91, 96, 102, 105, 108, 112, 119, 125, 126, 130, 147, 150, 156, 160, ... .

The primes in the above sequence are called **Elite primes**, they are:

3, 5, 7, 41, 15361, 23041, 26881, 61441, 87041, 163841, 544001, 604801, 6684673, 14172161, 159318017, 446960641, 1151139841, 3208642561, 38126223361, 108905103361, 171727482881, 318093312001, 443069456129, 912680550401, ...

For integer *b* > 1, base *b* may be used if and only if only a finite number of Fermat numbers *F<sub>n</sub>* satisfies that $\left(\frac{b}{F_n}\right)=1$, where $\left(\frac{b}{F_n}\right)$ is the [Jacobi symbol](wikipedia://en/97313).

In fact, Pépin's test is the same as the [Euler-Jacobi test](https://en.wikipedia.org/wiki/Euler-Jacobi_pseudoprime) for Fermat numbers, since the Jacobi symbol $\left(\frac{b}{F_n}\right)$ is −1, i.e. there are no Fermat numbers which are Euler-Jacobi pseudoprimes to these bases listed above.

::: {#o4 .proof cue=heading name="Proof of correctness"}

## Proof of correctness {#Proof_of_correctness}

**Sufficiency:** assume that the congruence

$$3^{(F_n-1)/2}\equiv-1\pmod{F_n}$$

holds. Then $3^{F_n-1}\equiv1\pmod{F_n}$, thus the [multiplicative order](wikipedia://en/344542) of 3 modulo $F_n$ divides $F_n-1=2^{2^n}$, which is a power of two. On the other hand, the order does not divide $(F_n-1)/2$, and therefore it must be equal to $F_n-1$. In particular, there are at least $F_n-1$ numbers below $F_n$ coprime to $F_n$, and this can happen only if $F_n$ is prime.

**Necessity:** assume that $F_n$ is prime. By [Euler's criterion](wikipedia://en/105622),

$$3^{(F_n-1)/2}\equiv\left(\frac3{F_n}\right)\pmod{F_n},$$

where $\left(\frac3{F_n}\right)$ is the [Legendre symbol](wikipedia://en/18567). By repeated squaring, we find that $2^{2^n}\equiv1\pmod3$, thus $F_n\equiv2\pmod3$, and $\left(\frac{F_n}3\right)=-1$. As $F_n\equiv1\pmod4$, we conclude $\left(\frac3{F_n}\right)=-1$ from the [law of quadratic reciprocity](https://en.wikipedia.org/wiki/Law_of_quadratic_reciprocity).

:::

## Historical Pépin tests {#Historical_Pépin_tests}

Because of the sparsity of the Fermat numbers, the Pépin test has only been run eight times (on Fermat numbers whose primality statuses were not already known).[^o6][^o7][^o8] Mayer, Papadopoulos and Crandall speculate that in fact, because of the size of the still undetermined Fermat numbers, it will take considerable advances in technology before any more Pépin tests can be run in a reasonable amount of time.[^o9]

::: {#o10 .table cue=table}

| Year | Provers | Fermat number | Pépin test result | Factor found later? |
|---|---|---|---|---|
| 1905 | [Morehead](https://en.wikipedia.org/wiki/James_C._Morehead) & [Western](https://en.wikipedia.org/wiki/Alfred_Western) | $F_{7}$ | composite | Yes (1970) |
| 1909 | Morehead & Western | $F_{8}$ | composite | Yes (1980) |
| 1952 | [Robinson](wikipedia://en/693495) | $F_{10}$ | composite | Yes (1953) |
| 1960 | [Paxson](https://en.wikipedia.org/wiki/G._A._Paxson) | $F_{13}$ | composite | Yes (1974) |
| 1961 | [Selfridge](wikipedia://en/995084) & Hurwitz | $F_{14}$ | composite | Yes (2010) |
| 1987 | [Buell](https://en.wikipedia.org/wiki/Duncan_Buell) & [Young](https://en.wikipedia.org/wiki/Jeffrey_Young_%28psychologist%29) | $F_{20}$ | composite | No |
| 1993 | [Crandall](wikipedia://en/9210048), Doenias, Norrie & Young | $F_{22}$ | composite | Yes (2010) |
| 1999 | Mayer, Papadopoulos & Crandall | $F_{24}$ | composite | No |

:::
