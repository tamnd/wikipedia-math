# Goss zeta function

::: {#o1 .subject cue=lead name="Goss zeta function"}

In [mathematics](wikipedia://en/18831), the **Goss zeta function,** named after [David Goss](https://en.wikipedia.org/wiki/David_Goss), is an analogue of the [Riemann zeta function](wikipedia://en/25809) for [function fields](wikipedia://en/2783843). Sheats proved that it satisfies an analogue of the [Riemann hypothesis](wikipedia://en/19344125).[^n1] [Kapranov](wikipedia://en/62272076) proved results for a higher-dimensional generalization of the Goss zeta function.[^n2]

:::
