# Size function

::: {#o1 .subject cue=lead name="Size function"}

**Size functions** are shape descriptors, in a geometrical/topological sense. They are functions from the half-plane $x<y$ to the natural numbers, counting certain [connected components](https://en.wikipedia.org/wiki/Connected_component_%28topology%29) of a [topological space](wikipedia://en/30450). They are used in [pattern recognition](wikipedia://en/126706) and [topology](wikipedia://en/29954).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

In [size theory](wikipedia://en/22016239), the **size function** $\ell_{(M,\varphi)}:\Delta^+=\{(x,y)\in \mathbb{R}^2:x<y\}\to \mathbb{N}$ associated with the [size pair](https://en.wikipedia.org/wiki/Size_pair) $(M,\varphi:M\to \mathbb{R})$ is defined in the following way. For every $(x,y)\in \Delta^+$, $\ell_{(M,\varphi)}(x,y)$ is equal to the number of connected components of the set $\{p\in M:\varphi(p)\le y\}$ that contain at least one point at which the measuring function (a [continuous function](wikipedia://en/6122) from a [topological space](wikipedia://en/30450) $M$ to $\mathbb{R}^k$[^o4][^o5]) $\varphi$ takes a value smaller than or equal to $x$.[^o6] The concept of size function can be easily extended to the case of a measuring function $\varphi:M\to \mathbb{R}^k$, where $\mathbb{R}^k$ is endowed with the usual partial order.[^o7] A survey about size functions (and [size theory](wikipedia://en/22016239)) can be found in.[^o8]

*Image: SFesWiki.PNG.* *An example of size function. (A) A size pair $(M,\varphi:M\to\mathbb{R})$, where $M$ is the blue curve and $\varphi:M\to \mathbb{R}$ is the height function. (B) The set $\{p\in M:\varphi(p)\le b\}$ is depicted in green. (C) The set of points at which the [measuring function](https://en.wikipedia.org/wiki/Measuring_function) $\varphi$ takes a value smaller than or equal to $a$, that is, $\{p\in M:\varphi(p)\le a\}$, is depicted in red. (D) Two connected components of the set $\{p\in M:\varphi(p)\le b\}$ contain at least one point in $\{p\in M:\varphi(p)\le a\}$, that is, at least one point where the [measuring function](https://en.wikipedia.org/wiki/Measuring_function) $\varphi$ takes a value smaller than or equal to $a$. (E) The value of the size function $\ell_{(M,\varphi)}$ in the point $(a,b)$ is equal to $2$.*

## History and applications {#History_and_applications}

Size functions were introduced in[^o10] for the particular case of $M$ equal to the topological space of all piecewise $C^1$ closed paths in a $C^\infty$ [closed manifold](wikipedia://en/669475) embedded in a [Euclidean space](wikipedia://en/9697). Here the topology on $M$ is induced by the $C^0$-norm, while the [measuring function](https://en.wikipedia.org/wiki/Measuring_function) $\varphi$ takes each path $\gamma\in M$ to its length. In[^o11] the case of $M$ equal to the topological space of all ordered $k$-tuples of points in a [submanifold](wikipedia://en/525095) of a Euclidean space is considered. Here the topology on $M$ is induced by the metric $d((P_1,\ldots,P_k),(Q_1\ldots,Q_k))=\max_{1\le i\le k}\|P_i-Q_i\|$.

An extension of the concept of size function to [algebraic topology](wikipedia://en/38801) was made in [^o5] where the concept of [size homotopy group](wikipedia://en/16683017) was introduced. Here [measuring functions](https://en.wikipedia.org/wiki/Measuring_function) taking values in $\mathbb{R}^k$ are allowed. An extension to [homology theory](https://en.wikipedia.org/wiki/Homology_theory) (the [size functor](wikipedia://en/16845636)) was introduced in.[^o12] The concepts of [size homotopy group](wikipedia://en/16683017) and [size functor](wikipedia://en/16845636) are strictly related to the concept of persistent homology group[^o13] studied in [persistent homology](wikipedia://en/31069689). It is worth to point out that the size function is the rank of the $0$-th [persistent homology group](wikipedia://en/73493845), while the relation between the persistent homology group and the size homotopy group is analogous to the one existing between [homology groups](https://en.wikipedia.org/wiki/Homology_group) and [homotopy groups](wikipedia://en/297506).

Size functions have been initially introduced as a mathematical tool for shape comparison in [computer vision](https://en.wikipedia.org/wiki/Computer_vision) and [pattern recognition](wikipedia://en/126706), and have constituted the seed of [size theory](wikipedia://en/22016239).[^o6][^o14][^o15][^o16][^o17][^o18][^o19][^o20][^o21] The main point is that size functions are invariant for every transformation preserving the [measuring function](https://en.wikipedia.org/wiki/Measuring_function). Hence, they can be adapted to many different applications, by simply changing the [measuring function](https://en.wikipedia.org/wiki/Measuring_function) in order to get the wanted invariance. Moreover, size functions show properties of relative resistance to noise, depending on the fact that they distribute the information all over the half-plane $\Delta^+$.

## Main properties {#Main_properties}

Assume that $M$ is a compact [locally connected](https://en.wikipedia.org/wiki/Locally_connected) [Hausdorff space](wikipedia://en/13637). The following statements hold:

- every size function $\ell_{(M,\varphi)}(x,y)$ is a [non-decreasing function](https://en.wikipedia.org/wiki/Non-decreasing_function) in the variable $x$ and a [non-increasing function](https://en.wikipedia.org/wiki/Nonincreasing_function) in the variable $y$.
- every size function $\ell_{(M,\varphi)}(x,y)$ is locally right-constant in both its variables.
- for every $x<y$, $\ell_{(M,\varphi)}(x,y)$ is finite.
- for every $x<\min \varphi$ and every $y>x$, $\ell_{(M,\varphi)}(x,y)=0$.
- for every $y\ge\max \varphi$ and every $x<y$, $\ell_{(M,\varphi)}(x,y)$ equals the number of connected components of $M$ on which the minimum value of $\varphi$ is smaller than or equal to $x$.

If we also assume that $M$ is a smooth [closed manifold](wikipedia://en/669475) and $\varphi$ is a $C^1$-function, the following useful property holds:

- in order that $(x,y)$ is a discontinuity point for $\ell_{(M,\varphi)}$ it is necessary that either $x$ or $y$ or both are critical values for $\varphi$.[^o23]

A strong link between the concept of size function and the concept of [natural pseudodistance](https://en.wikipedia.org/wiki/Natural_pseudodistance) $d((M,\varphi),(N,\psi))$ between the size pairs $(M,\varphi),\ (N,\psi)$ exists.[^o4][^o24]

- if $\ell_{(N,\psi)}(\bar x,\bar y)>\ell_{(M,\varphi)}(\tilde x,\tilde y)$ then $d((M,\varphi),(N,\psi))\ge \min\{\tilde x-\bar x,\bar y-\tilde y\}$.

The previous result gives an easy way to get lower bounds for the [natural pseudodistance](https://en.wikipedia.org/wiki/Natural_pseudodistance) and is one of the main motivation to introduce the concept of size function.

## Representation by formal series {#Representation_by_formal_series}

An algebraic representation of size functions in terms of collections of points and lines in the real plane with multiplicities, i.e. as particular formal series, was furnished in.[^o4][^o26][^o27] The points (called *cornerpoints*) and lines (called *cornerlines*) of such formal series encode the information about discontinuities of the corresponding size functions, while their multiplicities contain the information about the values taken by the size function.

Formally:

- *cornerpoints* are defined as those points $p=(x,y)$, with $x<y$, such that the number

$$\mu (p){\stackrel{{\rm def}}{=}}\min _{\alpha >0 ,\beta>0} \ell _{({M},\varphi )}(x+\alpha ,y- \beta)-\ell _{({ M},\varphi )} (x+\alpha ,y+\beta )- \ell_{({ M},\varphi )} (x-\alpha ,y-\beta )+\ell _{({ M} ,\varphi )} (x-\alpha ,y+\beta )$$

is positive. The number $\mu (p)$ is said to be the *multiplicity* of $p$.

- *cornerlines* and are defined as those lines $r:x=k$ such that

$$\mu (r){\stackrel{\rm def}{=}}\min _{\alpha >0 ,k+\alpha <y}\ell _{({ M},\varphi )}(k+\alpha ,y)- \ell _{({ M},\varphi )}(k-\alpha ,y)>0.$$

The number $\mu (r)$ is sad to be the*multiplicity* of $r$.

- *Representation Theorem*: For every ${\bar x}<{\bar y}$, it holds

$$\ell _{({M},\varphi )}({\bar x},{\bar y})=\sum _{p=(x,y)\atop x\le {\bar x}, y>\bar y }\mu\big(p\big)+\sum _{r:x=k\atop k\le {\bar x} }\mu\big(r\big).$$

This representation contains the same amount of information about the shape under study as the original size function does, but is much more concise.

This algebraic approach to size functions leads to the definition of new similarity measures between shapes, by translating the problem of comparing size functions into the problem of comparing formal series. The most studied among these metrics between size function is the [matching distance](wikipedia://en/16842914).[^o6]
