# Names for the number 0

::: {#o1 .subject cue=lead name="Names for the number 0"}

There are several **names for the [number 0](wikipedia://en/34513)** in different languages.

:::

::: {#o2 .table cue=table}

| Language | Name and pronunciation or transliteration | Notes |
|---|---|---|
| [Arabic](https://en.wikipedia.org/wiki/Arabic) | صفر (sifr) |  |
| [Chinese](https://en.wikipedia.org/wiki/Chinese_language) | 零 | The character 零 ([pinyin](https://en.wikipedia.org/wiki/Pinyin): líng) means "zero" in Chinese, although 〇 is also common. Etymologically 零 is an [onomatopoeic](https://en.wikipedia.org/wiki/Onomatopoeia) word for "light rain". The upper part of the character is 雨, meaning "rain", and the lower part is 令 (lìng), for the sound.[^o5] |
| [Czech](https://en.wikipedia.org/wiki/Czech_language) | nula |  |
| [Dutch](https://en.wikipedia.org/wiki/Dutch_language) | nul /nyl/ |  |
| [English](https://en.wikipedia.org/wiki/English_language) | [zero](https://en.wikipedia.org/wiki/Zero) | There are many [other names](https://en.wikipedia.org/wiki/Names_for_the_number_0_in_English) |
| [French](https://en.wikipedia.org/wiki/French_language) | zéro /zeʁo/ |  |
| [German](https://en.wikipedia.org/wiki/German_language) | Null/null | Whether or not the first letter of number names is capitalized – like all nouns are – depends on the sense in which they are used.[^o11] |
| [Greek](https://en.wikipedia.org/wiki/Greek_language) | μηδέν /miːðɛn/ | Literally meaning "not even one" |
| [Gujarati](https://en.wikipedia.org/wiki/Gujarati_language) | શૂન્ય (Śūn'ya) |  |
| [Haitian Creole](https://en.wikipedia.org/wiki/Haitian_Creole) | zewo |  |
| [Hindi](https://en.wikipedia.org/wiki/Hindi) | शून्य |  |
| [Hebrew](https://en.wikipedia.org/wiki/Hebrew_language) | אֶפֶס (*efes*) |  |
| [Indonesian](https://en.wikipedia.org/wiki/Indonesian_language) | nol /nɔl/ | Adopted from the Dutch word ***nul***. In addition, people often pronounce it as "kosong" /kɔsɔŋ/, literally meaning 'empty', when spelling telephone numbers. |
| [Italian](https://en.wikipedia.org/wiki/Italian_language) | zero /'dzɛro/ |  |
| [Japanese](https://en.wikipedia.org/wiki/Japanese_language) | 零 (read *rei*) | The character 零 (read *rei*) means "zero" in Japanese, although 〇 is also common. However, in common usage, ゼロ/ぜろ (read *zero*) is preferred, as it is a direct adaptation of the English equivalent. |
| [Kannada](https://en.wikipedia.org/wiki/Kannada_language) | ಸೊನ್ನ (sonne) |  |
| [Korean](https://en.wikipedia.org/wiki/Korean_language) | 영 or 공 |  |
| [Lojban](https://en.wikipedia.org/wiki/Lojban) | no |  |
| [Malayalam](https://en.wikipedia.org/wiki/Malayalam) | പൂജ്യം (poojyam) |  |
| [Polish](https://en.wikipedia.org/wiki/Polish_language) | zero /'zɛɾɔ/ |  |
| [Portuguese](https://en.wikipedia.org/wiki/Portuguese_language) | zero /zɛɾu/ |  |
| [Romanian](https://en.wikipedia.org/wiki/Romanian_language) | zero |  |
| [Russian](https://en.wikipedia.org/wiki/Russian_language) | ноль (nol') |  |
| [Spanish](https://en.wikipedia.org/wiki/Spanish_language) | cero |  |
| [Tamil](https://en.wikipedia.org/wiki/Tamil_language) | சுழியம் (sūḻiyam), பூஜ்ஜியம் (poojyam), or சைவர் (saivar) |  |
| [Telugu](https://en.wikipedia.org/wiki/Telugu_language) | సున్న or ౦ (sunna) |  |
