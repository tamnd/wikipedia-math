# Catalan pseudoprime

::: {#o1 .subject cue=lead name="Catalan pseudoprime"}

In [mathematics](wikipedia://en/18831), a **Catalan pseudoprime** is an odd [composite number](wikipedia://en/82289) *n* satisfying the congruence

:::

$$(-1)^{\frac{n-1}{2}} \cdot C_{\frac{n-1}{2}} \equiv 2 \pmod n,$$

where *C<sub>m</sub>* denotes the *m*-th [Catalan number](wikipedia://en/216488).

The above congruence holds for every odd [prime number](wikipedia://en/23666) *n*, so any composite *n* that satisfies it is [pseudoprime](wikipedia://en/28787420).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The only known Catalan pseudoprimes are: 5907, 1194649, and 12327121 with the latter two being squares of [Wieferich primes](wikipedia://en/323631). In general, if *p* is a Wieferich prime, then *p*<sup>2</sup> is a Catalan pseudoprime.

:::
