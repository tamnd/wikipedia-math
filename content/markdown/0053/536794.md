# Bit-flipping attack

::: {#o1 .subject cue=lead name="Bit-flipping attack"}

A **bit-flipping attack** is an attack on a [cryptographic](wikipedia://en/18934432) [cipher](wikipedia://en/5244) in which the [attacker](wikipedia://en/789126) can change the [ciphertext](wikipedia://en/175560) in such a way as to result in a predictable change of the [plaintext](wikipedia://en/157935), although the attacker is not able to learn the plaintext itself. Note that this type of attack is not—directly—against the cipher itself (as [cryptanalysis](wikipedia://en/5715) of it would be), but against a particular message or series of messages. In the extreme, this could become a [Denial of service attack](https://en.wikipedia.org/wiki/Denial_of_service_attack) against all messages on a particular channel using that cipher.[^o2]

:::

The attack is especially dangerous when the attacker knows the format of the message. In such a situation, the attacker can turn it into a similar message but one in which some important information is altered. For example, a change in the destination address might alter the message route in a way that will force re-encryption with a weaker cipher, thus possibly making it easier for an attacker to decipher the message.[^o3]

When applied to [digital signatures](wikipedia://en/59644), the attacker might be able to change a [promissory note](https://en.wikipedia.org/wiki/Promissory_note) stating "I owe you \$10.00" into one stating "I owe you \$10,000".[^o4]

[Stream ciphers](wikipedia://en/49007), such as [RC4](https://en.wikipedia.org/wiki/RC4_%28cipher%29), are vulnerable to a bit-flipping attack, as are some [block cipher](wikipedia://en/4594) modes of operation. *See* [stream cipher attack](https://en.wikipedia.org/wiki/Stream_cipher_attack). A keyed [message authentication code](wikipedia://en/567523), [digital signature](wikipedia://en/59644), or other authentication mechanism allows the recipient to detect if any bits were flipped in transit.[^o5]
