# Reduced ring

::: {#o1 .subject cue=lead name="Reduced ring"}

In [ring theory](wikipedia://en/250424), a branch of [mathematics](wikipedia://en/18831), a [ring](wikipedia://en/48404) is called a **reduced ring** if it has no non-zero [nilpotent](wikipedia://en/252235) elements. Equivalently, a ring is reduced if it has no non-zero elements with [square](wikipedia://en/659942) zero, that is, *x*<sup>2</sup> = 0 implies *x* = 0. A commutative [algebra](https://en.wikipedia.org/wiki/Algebra_over_a_ring) over a [commutative ring](wikipedia://en/61346) is called a **reduced algebra** if its underlying ring is reduced.

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The nilpotent elements of a commutative ring *R* form an [ideal](wikipedia://en/25977) of *R*, called the [nilradical](wikipedia://en/289636) of *R*; therefore a commutative ring is reduced [if and only if](wikipedia://en/14922) its nilradical is [zero](https://en.wikipedia.org/wiki/Zero_ideal). Moreover, a commutative ring is reduced if and only if the only element contained in all [prime ideals](wikipedia://en/24928) is zero.

A [quotient ring](wikipedia://en/184635) *R*/*I* is reduced if and only if *I* is a [radical ideal](https://en.wikipedia.org/wiki/Radical_ideal).

Let $\mathfrak{N}_R$ denote the nilradical of a commutative ring $R$. There is a [functor](wikipedia://en/10987) $R \mapsto R/\mathfrak{N}_R$ of the [category of commutative rings](https://en.wikipedia.org/wiki/Category_of_commutative_rings) $\textsf{CRing}$ into the [category](wikipedia://en/53759) of reduced rings $\textsf{Red}$ and it is [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint) to the inclusion functor $I$ of $\textsf{Red}$ into $\textsf{CRing}$, making $\textsf{Red}$ a [reflective subcategory](wikipedia://en/3967424) of $\textsf{CRing}$. The natural [bijection](wikipedia://en/3942) $\text{Hom}_{\textsf{Red}}(R/\mathfrak{N}_R,S)\cong\text{Hom}_{\textsf{CRing}}(R,I(S))$ is induced from the [universal property](wikipedia://en/32245) of quotient rings.

Let *D* be the set of all [zero-divisors](https://en.wikipedia.org/wiki/Zero-divisor) in a reduced ring *R*. Then *D* is the [union](wikipedia://en/47949) of all [minimal prime ideals](wikipedia://en/16143832).[^o4]

Over a [Noetherian ring](wikipedia://en/56129) *R*, we say a [finitely generated](wikipedia://en/326430) [module](wikipedia://en/276410) *M* has locally constant rank if $\mathfrak{p} \mapsto \operatorname{dim}_{k(\mathfrak{p})}(M \otimes k(\mathfrak{p}))$ is a locally constant (or equivalently continuous) function on [Spec](wikipedia://en/37291) *R*. Then *R* is reduced if and only if every finitely generated module of locally constant rank is [projective](wikipedia://en/364488).[^o5]

:::

## Examples and non-examples {#Examples_and_non-examples}

- [Subrings](wikipedia://en/24873145), [products](wikipedia://en/25063), and [localizations](https://en.wikipedia.org/wiki/Localization_of_a_ring) of reduced rings are again reduced rings.
- The ring of [integers](wikipedia://en/14563#Algebraic_properties) **Z** is a reduced ring. Every [field](wikipedia://en/10603) and every [polynomial ring](wikipedia://en/373065) over a field (in arbitrarily many variables) is a reduced ring.
- More generally, every [integral domain](wikipedia://en/15462) is a reduced ring since a nilpotent element is a fortiori a [zero-divisor](https://en.wikipedia.org/wiki/Zero-divisor). On the other hand, not every reduced ring is an integral domain; for example, the ring **Z**\[*x*, *y*\]/(*xy*) contains *x* + (*xy*) and *y* + (*xy*) as zero-divisors, but no non-zero nilpotent elements. As another example, the ring **Z** × **Z** contains (1, 0) and (0, 1) as zero-divisors, but contains no non-zero nilpotent elements.
- The ring **Z**/6**Z** is reduced, however **Z**/4**Z** is not reduced: the class 2 + 4**Z** is nilpotent. In general, **Z**/*n***Z** is reduced if and only if *n* = 0 or *n* is [square-free](wikipedia://en/29525).
- If *R* is a commutative ring and *N* is its [nilradical](wikipedia://en/289636), then the quotient ring *R*/*N* is reduced.
- A commutative ring *R* of [prime](wikipedia://en/23666) [characteristic](wikipedia://en/1066621) *p* is reduced if and only if its [Frobenius endomorphism](wikipedia://en/1088270) is [injective](https://en.wikipedia.org/wiki/Injective) (cf. [Perfect field](wikipedia://en/505088).)

## Generalizations {#Generalizations}

Reduced rings play an elementary role in [algebraic geometry](wikipedia://en/1997), where this concept is generalized to the notion of a [reduced scheme](https://en.wikipedia.org/wiki/Reduced_scheme).
