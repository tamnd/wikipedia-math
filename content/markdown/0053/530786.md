# Codebook

*Image: State Department code book 1899, open to title page, at NMC.agr.jpg.* U.S. State Department code book issued in 1899, an example of a one-part code, at the [National Cryptologic Museum](wikipedia://en/734289)

*Image: State Department code book 1899, code page 187.agr.jpg.* Page 187 of the State Department 1899 code book, a one-part code with a choice of code word or numeric ciphertext. Numeric codes are prefixed by the page number.

::: {#o1 .subject cue=lead name="Codebook"}

A **codebook** is a type of document used for gathering and storing [cryptography codes](https://en.wikipedia.org/wiki/Cryptography_code). Originally, codebooks were often literally [books](https://en.wikipedia.org/wiki/Books), but today "codebook" is a byword for the complete record of a series of codes, regardless of physical format.

:::

## Cryptography {#Cryptography}

In [cryptography](wikipedia://en/18934432), a codebook is a document used for implementing a [code](wikipedia://en/838989). A codebook contains a [lookup table](https://en.wikipedia.org/wiki/Lookup_table) for coding and decoding; each word or phrase has one or more strings which replace it. To decipher messages written in code, corresponding copies of the codebook must be available at either end. The distribution and [physical security](https://en.wikipedia.org/wiki/Physical_security) of codebooks presents a special difficulty in the use of codes compared to the secret information used in [ciphers](wikipedia://en/5244), the [key](https://en.wikipedia.org/wiki/Cryptographic_key), which is typically much shorter.

The United States [National Security Agency](wikipedia://en/21939) documents sometimes use *codebook* to refer to [block ciphers](wikipedia://en/4594); compare their use of *combiner-type algorithm* to refer to [stream ciphers](wikipedia://en/49007).

Codebooks come in two forms, one-part or two-part:

- In one-part codes, the plaintext words and phrases and the corresponding code words are in the same alphabetical order. They are organized similar to a standard dictionary. Such codes are half the size of two-part codes but are more vulnerable since an attacker who recovers some code word meanings can often infer the meaning of nearby code words. One-part codes may be used simply to shorten messages for transmission or have their security enhanced with [superencryption](https://en.wikipedia.org/wiki/Superencryption) methods, such as adding a secret number to numeric code words.[^o3]
- In two-part codes, one part is for converting plaintext to ciphertext, the other for the opposite purpose. They are usually organized similarly to a language translation dictionary, with plaintext words (in the first part) and ciphertext words (in the second part) presented like dictionary headwords.

The earliest known use of a codebook system was by Gabriele de Lavinde in 1379 working for the [Antipope Clement VII](https://en.wikipedia.org/wiki/Antipope_Clement_VII).[^o3]

Two-part codebooks go back as least as far as [Antoine Rossignol](https://en.wikipedia.org/wiki/Antoine_Rossignol) in the 1800s.[^o3]

From the 15th century until the middle of the 19th century, [nomenclators](https://en.wikipedia.org/wiki/Nomenclator_cipher) were the most used cryptographic method.[^o4]

Codebooks with superencryption were the most used cryptographic method of World War I.[^o3]

The [JN-25](https://en.wikipedia.org/wiki/JN-25) code used in World War II used a codebook of 30,000 code groups superencrypted with 30,000 random additives.

The book used in a [book cipher](wikipedia://en/449363) or the book used in a [running key cipher](wikipedia://en/450657) can be any book shared by sender and receiver and is different from a cryptographic codebook.

## Social sciences {#Social_sciences}

In social sciences, a codebook is a document containing a list of the codes used in a set of data to refer to variables and their values, for example locations, occupations, or clinical diagnoses.

## Data compression {#Data_compression}

Codebooks were also used in 19th- and 20th-century [commercial codes](wikipedia://en/28739060) for the non-cryptographic purpose of data compression.

Codebooks are used in relation to [precoding](https://en.wikipedia.org/wiki/Precoding) and [beamforming](https://en.wikipedia.org/wiki/Beamforming) in mobile networks such as [5G](https://en.wikipedia.org/wiki/5G) and [LTE](https://en.wikipedia.org/wiki/LTE_%28telecommunication%29). The usage is standardized by [3GPP](https://en.wikipedia.org/wiki/3GPP), for example in the document [TS 38.331](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=3197), NR; Radio Resource Control (RRC); Protocol specification.
