# Langford pairing

::: {#o1 .subject cue=lead name="Langford pairing"}

*Image: Langford pairing.svg.* A Langford pairing for *n* = 4.

In [combinatorial](wikipedia://en/5170) [mathematics](wikipedia://en/18831), a **Langford pairing**, also called a **Langford sequence**, is a [permutation](wikipedia://en/44027) of the sequence of 2*n* numbers 1, 1, 2, 2, ..., *n*, *n* in which the two 1s are one unit apart, the two 2s are two units apart, and more generally the two copies of each number *k* are *k* units apart. Langford pairings are named after C. Dudley Langford, who posed the problem of constructing them in 1958.

:::

**Langford's problem** is the task of finding Langford pairings for a given value of *n*.[^o2]

The closely related concept of a **Skolem sequence**[^o3] is defined in the same way, but instead permutes the sequence 0, 0, 1, 1, ..., *n* − 1, *n* − 1.

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

A Langford pairing for *n* = 3 is given by the sequence 2, 3, 1, 2, 1, 3.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Langford pairings exist only when *n* is [congruent](wikipedia://en/20087) to 0 or 3 modulo 4; for instance, there is no Langford pairing when *n* = 1, 2, or 5.

The numbers of different Langford pairings for *n* = 1, 2, …, counting any sequence as being the same as its reversal, are

0, 0, 1, 1, 0, 0, 26, 150, 0, 0, 17792, 108144, 0, 0, 39809640, 326721800, 0, 0, 256814891280, 2636337861200, 0, 0, … .

As (Knuth 2008) describes, the problem of listing all Langford pairings for a given *n* can be solved as an instance of the [exact cover problem](https://en.wikipedia.org/wiki/Exact_cover_problem), but for large *n* the number of solutions can be calculated more efficiently by algebraic methods.

:::

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

(Skolem 1957) used Skolem sequences to construct [Steiner triple systems](https://en.wikipedia.org/wiki/Steiner_triple_system).

In the 1960s, E. J. Groth used Langford pairings to construct circuits for integer [multiplication](wikipedia://en/20845).[^o12]

:::
