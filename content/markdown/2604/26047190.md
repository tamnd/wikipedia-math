# Regular extension

::: {#o1 .subject cue=lead name="Regular extension"}

In [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29), a branch of algebra, a [field extension](wikipedia://en/11634) $L/k$ is said to be **regular** if *k* is [algebraically closed](https://en.wikipedia.org/wiki/Algebraically_closed) in *L* (i.e., $k = \hat k$ where $\hat k$ is the set of elements in *L* algebraic over *k*) and *L* is [separable](wikipedia://en/363340) over *k*, or equivalently, $L \otimes_k \overline{k}$ is an integral domain when $\overline{k}$ is the algebraic closure of $k$ (that is, to say, $L, \overline{k}$ are [linearly disjoint](https://en.wikipedia.org/wiki/Linearly_disjoint) over *k*).[^o2][^o3]

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Regularity is transitive: if *F*/*E* and *E*/*K* are regular then so is *F*/*K*.[^o6]
- If *F*/*K* is regular then so is *E*/*K* for any *E* between *F* and *K*.[^o6]
- The extension *L*/*k* is regular if and only if every subfield of *L* finitely generated over *k* is regular over *k*.[^o3]
- Any extension of an algebraically closed field is regular.[^o6][^o7]
- An extension is regular if and only if it is separable and [primary](wikipedia://en/30505550).[^o8]
- A [purely transcendental extension](https://en.wikipedia.org/wiki/Purely_transcendental_extension) of a field is regular.

:::

::: {#o10 .pointer-item cue=pointer name="Self-regular extension"}

## Self-regular extension {#Self-regular_extension}

There is also a similar notion: a field extension $L / k$ is said to be **self-regular** if $L \otimes_k L$ is an integral domain. A self-regular extension is relatively algebraically closed in *k*.[^o11] However, a self-regular extension is not necessarily regular.

:::
