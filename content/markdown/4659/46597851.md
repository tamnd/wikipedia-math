# Strict initial object

::: {#o1 .subject cue=lead name="Strict initial object"}

In the mathematical discipline of [category theory](wikipedia://en/5869), a **strict initial object** is an [initial object](https://en.wikipedia.org/wiki/Initial_object) 0 of a [category](wikipedia://en/53759) *C* with the property that every [morphism](wikipedia://en/27716891) in *C* with [codomain](wikipedia://en/50264) 0 is an [isomorphism](https://en.wikipedia.org/wiki/Isomorphism_%28category_theory%29). In a [Cartesian closed category](wikipedia://en/237037), every initial object is strict.[^o2] Also, if *C* is a [distributive](wikipedia://en/6053993) or [extensive category](wikipedia://en/57025458), then the initial object 0 of *C* is strict.[^o3]

:::
