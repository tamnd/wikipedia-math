# Takeuti–Feferman–Buchholz ordinal

::: {#o1 .subject cue=lead name="Takeuti–Feferman–Buchholz ordinal"}

In the mathematical fields of [set theory](wikipedia://en/27553) and [proof theory](wikipedia://en/183478), the **Takeuti–Feferman–Buchholz ordinal (TFBO)** is a [large countable ordinal](wikipedia://en/4376814), which acts as the limit of the range of [Buchholz's psi function](wikipedia://en/54183426) and Feferman's theta function.[^o2][^o3] It was named by David Madore,[^o3] after [Gaisi Takeuti](wikipedia://en/2593847), [Solomon Feferman](wikipedia://en/355401) and Wilfried Buchholz. It is written as $\psi_0(\varepsilon_{\Omega_\omega + 1})$ using Buchholz's psi function,[^o4] an [ordinal collapsing function](wikipedia://en/16968563) invented by Wilfried Buchholz,[^o5][^o6][^o7] and $\theta_{\varepsilon_{\Omega_\omega + 1}}(0)$ in Feferman's theta function, an ordinal collapsing function invented by Solomon Feferman.[^o8][^o9] It is the proof-theoretic ordinal of several formal theories:

:::

- $\Pi_1^1\textsf{-CA} + \textsf{BI}$,[^o10] a subsystem of [second-order arithmetic](wikipedia://en/3542454)
- $\Pi_1^1$-comprehension + transfinite induction[^o4]
- [ID<sub>ω</sub>](https://en.wikipedia.org/wiki/Buchholz's_ID_hierarchy), the system of ω-times iterated inductive definitions[^o11]

::: {#o13 .definition cue=heading name="Definition"}

## Definition {#Definition}

the definition of the Takeuti-Feferman-Buchholz ordinal

- Let $\Omega_\alpha$ represent the smallest [uncountable](wikipedia://en/32248) ordinal with [cardinality](wikipedia://en/6174) $\aleph_\alpha$.
- Let $\varepsilon_\beta$ represent the $\beta$th [epsilon number](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), equal to the $1+\beta$th fixed point of $\alpha \mapsto \omega^\alpha$
- Let $\psi$ represent [Buchholz's psi function](wikipedia://en/54183426)
