# Positive element

::: {#o1 .subject cue=lead name="Positive element"}

In [mathematics](wikipedia://en/18831), an [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of a [\*-algebra](wikipedia://en/293426) is called **positive** if it is the [sum](wikipedia://en/246160) of elements of the form $a^*a$.[^n1]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{A}$ be a \*-algebra. An element $a \in \mathcal{A}$ is called positive if there are [finitely many](wikipedia://en/11742) elements $a_k \in \mathcal{A} \; (k = 1,2,\ldots,n)$, so that $a = \sum_{k=1}^n a_k^*a_k$ holds.[^n1] This is also denoted by $a \geq 0$.[^n2]

The [set](wikipedia://en/26691) of positive elements is denoted by $\mathcal{A}_+$.

A special case from particular importance is the case where $\mathcal{A}$ is a [complete normed \*-algebra](wikipedia://en/4665#Banach_*-algebras), that satisfies the C\*-identity ($\left\| a^*a \right\| = \left\| a \right\|^2 \ \forall a \in \mathcal{A}$), which is called a [C\*-algebra](wikipedia://en/7184).

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [unit](wikipedia://en/14962) element $e$ of an [unital](wikipedia://en/191788#Unital_algebra) \*-algebra is positive.
- For each element $a \in \mathcal{A}$, the elements $a^* a$ and $aa^*$ are positive by definition.[^n1]

In case $\mathcal{A}$ is a C\*-algebra, the following holds:

- Let $a \in \mathcal{A}_N$ be a [normal element](wikipedia://en/21454688), then for every positive [function](wikipedia://en/185427) $f \geq 0$ which is [continuous](wikipedia://en/6122) on the [spectrum](wikipedia://en/4665#Spectral_theory) of $a$ the [continuous functional calculus](wikipedia://en/784808) defines a positive element $f(a)$.[^n3]
- Every [projection](wikipedia://en/3909097), i.e. every element $a \in \mathcal{A}$ for which $a = a^* = a^2$ holds, is positive. For the spectrum $\sigma(a)$ of such an [idempotent](wikipedia://en/361940) element, $\sigma(a) \subseteq \{ 0, 1 \}$ holds, as can be seen from the continuous functional calculus.[^n3]

:::

## Criteria {#Criteria}

Let $\mathcal{A}$ be a C\*-algebra and $a \in \mathcal{A}$. Then the following are equivalent:[^n4]

- For the spectrum $\sigma(a) \subseteq [0, \infty)$ holds and $a$ is a normal element.
- There exists an element $b \in \mathcal{A}$, such that $a = bb^*$.
- There exists a (unique) [self-adjoint element](https://en.wikipedia.org/wiki/Self-adjoint) $c \in \mathcal{A}_{sa}$ such that $a = c^2$.

If $\mathcal{A}$ is a unital \*-algebra with unit element $e$, then in addition the following statements are equivalent:[^n5]

- $\left\| te - a \right\| \leq t$ for every $t \geq \left\| a \right\|$ and $a$ is a self-adjoint element.
- $\left\| te - a \right\| \leq t$ for some $t \geq \left\| a \right\|$ and $a$ is a self-adjoint element.

::: {#o16 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### In \*-algebras {#In_*-algebras}

Let $\mathcal{A}$ be a \*-algebra. Then:

- If $a \in \mathcal{A}_+$ is a positive element, then $a$ is self-adjoint.[^n6]
- The set of positive elements $\mathcal{A}_+$ is a [convex cone](wikipedia://en/3558266) in the real [vector space](wikipedia://en/32370) of the self-adjoint elements $\mathcal{A}_{sa}$. This means that $\alpha a, a+b \in \mathcal{A}_+$ holds for all $a,b \in \mathcal{A}$ and $\alpha \in [0, \infty)$.[^n6]
- If $a \in \mathcal{A}_+$ is a positive element, then $b^*ab$ is also positive for every element $b \in \mathcal{A}$.[^n7]
- For the [linear span](wikipedia://en/56353) of $\mathcal{A}_+$ the following holds: $\langle \mathcal{A}_+ \rangle = \mathcal{A}^2$ and $\mathcal{A}_+ - \mathcal{A}_+ = \mathcal{A}_{sa} \cap \mathcal{A}^2$.[^n8]

### In C\*-algebras {#In_C*-algebras}

Let $\mathcal{A}$ be a C\*-algebra. Then:

- Using the continuous functional calculus, for every $a \in \mathcal{A}_+$ and $n \in \mathbb{N}$ there is a uniquely determined $b \in \mathcal{A}_+$ that satisfies $b^n = a$, i.e. a unique $n$[\-th root](wikipedia://en/235029). In particular, a [square root](wikipedia://en/29208) exists for every positive element. Since for every $b \in \mathcal{A}$ the element $b^*b$ is positive, this allows the definition of a unique [absolute value](wikipedia://en/991): $|b| = (b^*b)^\frac{1}{2}$.[^n9]
- For every [real number](wikipedia://en/20646438) $\alpha \geq 0$ there is a positive element $a^\alpha \in \mathcal{A}_+$ for which $a^\alpha a^\beta = a^{\alpha + \beta}$ holds for all $\beta \in [0, \infty)$. The mapping $\alpha \mapsto a^\alpha$ is continuous. Negative values for $\alpha$ are also possible for [invertible elements](wikipedia://en/45199) $a$.[^n7]
- [Products](wikipedia://en/24977) of positive [commutative](wikipedia://en/294390) elements are also positive. So if $ab = ba$ holds for positive $a,b \in \mathcal{A}_+$, then $ab \in \mathcal{A}_+$.[^n5]
- Each element $a \in \mathcal{A}$ can be uniquely represented as a [linear combination](wikipedia://en/55632) of four positive elements. To do this, $a$ is first decomposed into the self-adjoint [real and imaginary parts](https://en.wikipedia.org/wiki/Real_and_imaginary_parts) and these are then decomposed into [positive and negative parts](wikipedia://en/3344921) using the continuous functional calculus.[^n10] For it holds that $\mathcal{A}_{sa} = \mathcal{A}_+ - \mathcal{A}_+$, since $\mathcal{A}^2 = \mathcal{A}$.[^n8]
- If both $a$ and $-a$ are positive $a = 0$ holds.[^n5]
- If $\mathcal{B}$ is a C\*-subalgebra of $\mathcal{A}$, then $\mathcal{B}_+ = \mathcal{B} \cap \mathcal{A}_+$.[^n5]
- If $\mathcal{B}$ is another C\*-algebra and $\Phi$ is a \*-homomorphism from $\mathcal{A}$ to $\mathcal{B}$, then $\Phi(\mathcal{A}_+) = \Phi(\mathcal{A}) \cap \mathcal{B}_+$ holds.[^n11]
- If $a,b \in \mathcal{A}_+$ are positive elements for which $ab = 0$, they commutate and $\left\| a + b \right\| = \max(\left\| a \right\|, \left\| b \right\|)$ holds. Such elements are called [orthogonal](wikipedia://en/102221) and one writes $a \bot b$.[^n12]

:::

## Partial order {#Partial_order}

Let $\mathcal{A}$ be a \*-algebra. The property of being a positive element defines a [translation invariant](https://en.wikipedia.org/wiki/Translational_symmetry) [partial order](wikipedia://en/23572#Partial_orders) on the set of self-adjoint elements $\mathcal{A}_{sa}$. If $b - a \in \mathcal{A}_+$ holds for $a,b \in \mathcal{A}$, one writes $a \leq b$ or $b \geq a$.[^n13]

This partial order fulfills the properties $ta \leq tb$ and $a + c \leq b + c$ for all $a,b,c \in \mathcal{A}_{sa}$ with $a \leq b$ and $t \in [0, \infty)$.[^n8]

If $\mathcal{A}$ is a C\*-algebra, the partial order also has the following properties for $a,b \in \mathcal{A}$:

- If $a \leq b$ holds, then $c^*ac \leq c^*bc$ is true for every $c \in \mathcal{A}$. For every $c \in \mathcal{A}_+$ that commutes with $a$ and $b$ even $ac \leq bc$ holds.[^n14]
- If $-b \leq a \leq b$ holds, then $\left\| a \right\| \leq \left\| b \right\|$.[^n15]
- If $0 \leq a \leq b$ holds, then $a^\alpha \leq b^\alpha$ holds for all real numbers $0 < \alpha \leq 1$.[^n16]
- If $a$ is invertible and $0 \leq a \leq b$ holds, then $b$ is invertible and for the inverses $b^{-1} \leq a^{-1}$ holds.[^n15]
