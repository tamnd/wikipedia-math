# Inner model

::: {#o1 .subject cue=lead name="Inner model"}

In [set theory](wikipedia://en/27553), a branch of [mathematical logic](wikipedia://en/19636), an **inner model**[^o2] for a [theory](wikipedia://en/3512103) *T* is a [substructure](wikipedia://en/2057747) of a [model](https://en.wikipedia.org/wiki/Model_%28mathematical_logic%29) *M* of a [set theory](wikipedia://en/27553) that is both a model for *T* and contains all the ordinals of *M*.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $L = \langle\in\rangle$ be the language of set theory. Let *S* be a particular set theory, for example the [ZFC](https://en.wikipedia.org/wiki/ZFC) axioms and let *T* (possibly the same as *S*) also be a theory in *L.*

If *M* is a model for *S,* and *N* is an *L*-structure such that

1. *N* is a substructure of *M,* i.e. the [interpretation](wikipedia://en/17135554) $\in_{N}$ of $\in$ in *N* is $\in_{M} \cap N^{2}$
1. *N* is a model of *T*
1. the domain of *N* is a [transitive class](https://en.wikipedia.org/wiki/Transitive_class) of *M*
1. *N* contains all [ordinals](wikipedia://en/26547932) in *M*

then we say that *N* is an **inner model** of *T* (in *M*).[^o5] Usually *T* will equal (or subsume) *S*, so that *N* is a model for *S* 'inside' the model *M* of *S*.

If only conditions 1 and 2 hold, *N* is called a [standard model](wikipedia://en/18391755) of *T* (in *M*), a *standard submodel* of *T* if ($S = T$ and) *N* is a *set* in *M*. A model *N* of *T* in *M* is called *transitive* when it is standard and condition 3 holds. If the [axiom of foundation](https://en.wikipedia.org/wiki/Axiom_of_foundation) is not assumed (that is, is not in *S*) all three of these concepts are given the additional condition that *N* be [well-founded](https://en.wikipedia.org/wiki/Well-founded_set). Hence inner models are transitive, transitive models are standard, and standard models are well-founded.

The assumption that there exists a standard submodel of [ZFC](https://en.wikipedia.org/wiki/ZFC) (in a given universe) is stronger than the assumption that there exists a model. In fact, if there is a standard submodel, then there is a smallest standard submodel called the *[minimal model](wikipedia://en/18374778)* contained in all standard submodels. The minimal submodel contains no standard submodel (as it is minimal) but (assuming the [consistency](wikipedia://en/75802) of ZFC) it contains some model of ZFC by the [Gödel completeness theorem](https://en.wikipedia.org/wiki/Gödel_completeness_theorem). This model is necessarily not well-founded otherwise its [Mostowski collapse](https://en.wikipedia.org/wiki/Mostowski_collapse) would be a standard submodel. (It is not well-founded as a relation in the universe, though it satisfies the [axiom of foundation](https://en.wikipedia.org/wiki/Axiom_of_foundation) so is "internally" well-founded. Being well-founded is not an absolute property.[^o6]) In particular in the minimal submodel there is a model of ZFC but there is no standard submodel of ZFC.

:::

::: {#o8 .application cue=heading name="Use"}

## Use {#Use}

Usually when one talks about inner models of a theory, the theory one is discussing is [ZFC](https://en.wikipedia.org/wiki/ZFC) or some extension of ZFC (like ZFC + "a [measurable cardinal](wikipedia://en/248102) exists"). When no theory is mentioned, it is usually assumed that the model under discussion is an inner model of ZFC. However, it is not uncommon to talk about inner models of [subtheories](https://en.wikipedia.org/wiki/Subtheories) of ZFC (like [ZF](https://en.wikipedia.org/wiki/Zermelo–Frankel_set_theory) or [KP](wikipedia://en/1124695)) as well.

:::

## Related ideas {#Related_ideas}

[Kurt Gödel](https://en.wikipedia.org/wiki/Gödel) proved that any model of ZF has a least inner model of ZF, the [constructible universe](wikipedia://en/343335), which is also an inner model of ZFC + [GCH](https://en.wikipedia.org/wiki/Generalized_Continuum_Hypothesis).

There is a branch of set theory called [inner model theory](wikipedia://en/3796621) that studies ways of constructing least inner models of theories extending ZF. Inner model theory has led to the discovery of the exact [consistency strength](https://en.wikipedia.org/wiki/Consistency_strength) of many important set theoretical properties.
