# Dirichlet distribution

::: {#o1 .subject cue=lead name="Dirichlet distribution"}

In [probability](wikipedia://en/22934) and [statistics](wikipedia://en/26685), the **Dirichlet distribution** (after [Peter Gustav Lejeune Dirichlet](wikipedia://en/240002)), often denoted $\operatorname{Dir}(\boldsymbol\alpha)$, is a family of [continuous](https://en.wikipedia.org/wiki/Continuous_probability_distribution) [multivariate](wikipedia://en/49821) [probability distributions](wikipedia://en/23543) parameterized by a vector $\mathbf{\alpha}$ of positive [reals](wikipedia://en/20646438). It is a multivariate generalization of the [beta distribution](wikipedia://en/207074),[^o2] hence its alternative name of **multivariate beta distribution** (**MBD**).[^o3] Dirichlet distributions are commonly used as [prior distributions](https://en.wikipedia.org/wiki/Prior_distribution) in [Bayesian statistics](wikipedia://en/404412), and in fact, the Dirichlet distribution is the [conjugate prior](wikipedia://en/846412) of the [categorical distribution](wikipedia://en/10072717) and [multinomial distribution](wikipedia://en/1045553).

:::

The infinite-dimensional generalization of the Dirichlet distribution is the *[Dirichlet process](wikipedia://en/8330403)*.

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

### Probability density function {#Probability_density_function}

*Image: LogDirichletDensity-alpha 0.3 to alpha 2.0.gif.* Illustrating how the log of the density function changes when $K = 3$ as we change the vector $\boldsymbol\alpha$ from $\boldsymbol\alpha = (0.3, 0.3, 0.3)$ to $(2.0, 2.0, 2.0)$, keeping all the individual $\alpha_i$'s equal to each other.

The Dirichlet distribution of order $K \geq 2$ with parameters $\alpha_1, \ldots, \alpha_K > 0$ has a [probability density function](wikipedia://en/43487) given by

$$f \left(x_1,\ldots, x_{K}; \alpha_1,\ldots, \alpha_K \right) = \frac{1}{\mathrm{B}(\boldsymbol\alpha)} \prod_{i=1}^K x_i^{\alpha_i - 1}$$

where

$$x_i \in \left[0,1\right] \mbox{ for all } i \in \{1,\dots,K\} \mbox{ and } \sum_{i=1}^{K} x_i = 1\,.$$

That is, the probability density function is defined on the standard $K-1$ [simplex](wikipedia://en/39781) embedded in $K$-dimensional [Euclidean space](wikipedia://en/9697), $\mathbb{R}^{K}$.

The [normalizing constant](wikipedia://en/398189) is the multivariate [beta function](wikipedia://en/245660), which can be expressed in terms of the [gamma function](wikipedia://en/12316):

$$\mathrm{B}(\boldsymbol\alpha) = \frac{\prod\limits_{i=1}^K \Gamma(\alpha_i)}{\Gamma\left(\sum\limits_{i=1}^K \alpha_i\right)},\qquad\boldsymbol{\alpha}=(\alpha_1,\ldots,\alpha_K).$$

### Support {#Support}

The [support](wikipedia://en/381013) of the Dirichlet distribution is the set of $K$-dimensional vectors $\mathbf{x}$ whose entries are real numbers in the interval \[0,1\] such that $\|\boldsymbol x\|_1 = 1$, i.e. the sum of the coordinates is equal to 1. These can be viewed as the probabilities of a $K$-way [categorical](wikipedia://en/10072717) event. Another way to express this is that the domain of the Dirichlet distribution is itself a set of [probability distributions](wikipedia://en/23543), specifically the set of $K$-dimensional [discrete distributions](https://en.wikipedia.org/wiki/Discrete_distribution). The technical term for the set of points in the support of a $K$-dimensional Dirichlet distribution is the [open](wikipedia://en/39358) [standard $(K - 1)$-simplex](https://en.wikipedia.org/wiki/Standard_simplex),[^o8] which is a generalization of a [triangle](wikipedia://en/30654), embedded in the next-higher dimension. For example, with $K = 3$, the support is an [equilateral triangle](wikipedia://en/173285) embedded in a downward-angle fashion in three-dimensional space, with vertices at (1,0,0), (0,1,0) and (0,0,1), i.e. touching each of the coordinate axes at a point 1 unit away from the origin.

### Symmetric cases {#Symmetric_cases}

A common special case is the **symmetric Dirichlet distribution**, where all of the elements making up the parameter vector $\mathbf{\alpha}$ have the same value. The symmetric case might be useful, for example, when a Dirichlet prior over components is called for, but there is no prior knowledge favoring one component over another. Since all elements of the parameter vector have the same value, the symmetric Dirichlet distribution can be parametrized by a single scalar value $\alpha$, called the [concentration parameter](wikipedia://en/28962480). In terms of $\alpha$, the density function has the form

$$f(x_1,\dots, x_{K}; \alpha) = \frac{\Gamma(\alpha K)}{\Gamma(\alpha)^K} \prod_{i=1}^K x_i^{\alpha - 1}.$$

When $\alpha = 1$, the symmetric Dirichlet distribution is equivalent to a uniform distribution over the open [standard $(K-1)$-simplex](https://en.wikipedia.org/wiki/Standard_simplex), i.e. it is uniform over all points in its [support](wikipedia://en/381013). This particular distribution is known as the **flat Dirichlet distribution**. Values of the concentration parameter above 1 prefer [variates](https://en.wikipedia.org/wiki/Random_variate) that are dense, evenly distributed distributions, i.e. all the values within a single sample are similar to each other. Values of the concentration parameter below 1 prefer sparse distributions, i.e. most of the values within a single sample will be close to 0, and the vast majority of the mass will be concentrated in a few of the values.

When $\alpha = 1/2$, the distribution is the same as would be obtained by choosing a point uniformly at random from the $(K-1)$-dimensional [unit hypersphere](https://en.wikipedia.org/wiki/Unit_hypersphere), which is the surface of a $K$-dimensional [unit hyperball](wikipedia://en/160556), and squaring each coordinate. The $\alpha = 1/2$ distribution is the [Jeffreys prior](wikipedia://en/1901158) for the Dirichlet distribution.

### With specified expectations {#With_specified_expectations}

Instead of specifying the vector of concentration parameters $\boldsymbol \alpha$, one may wish to specify the expected probability distribution

$$\operatorname{E}_i = \frac{\alpha_i}{\alpha_0} \;\;\mbox{ where }\;\; \alpha_0 = \sum_{j=1}^K \alpha_j$$

such that the concentration parameters are written as the product $\,\boldsymbol \alpha = W\, \boldsymbol \operatorname{E}\,$ of the ([scalar](wikipedia://en/3588331)) concentration weight $W$ and the expected probability distribution $\boldsymbol \operatorname{E}$ whose components are non-negative and sum up to 1. The concentration weight in this case is larger by a factor of $K$ than the concentration parameter for a symmetric Dirichlet distribution described above. This construction ties in with concept of a base measure when discussing [Dirichlet processes](wikipedia://en/8330403) and is often used in the topic modelling literature.

*Image: Plot-noninformative-prior-weight.jpg.* 3D curve plot of the noninformative prior weight, with the convergence constant $C_W = 2$

When the dimension of the Dirichlet distribution is large, [Jeffreys prior](wikipedia://en/1901158) produces a correspondingly high prior concentration weight. For example when $K = 100$, the prior concentration weight becomes $W = K/2 = 50$, which creates a relatively stiff prior probability distribution $\boldsymbol \operatorname{E}^{\ast}$ where initially the posterior probability distribution $\boldsymbol \operatorname{E}$ hardly changes in the presence of observed data, even in the case of e.g. 10 observations where all observations indicate the same category $X_i$, which naturally and intuitively should produce an expected probability $\operatorname{E}_i$ close to 1. A way to avoid the misbehaviour of the stiff prior is to use the noninformative prior weight $W$ from [subjective logic](wikipedia://en/12413580), where the concentration parameters $\alpha_i$ are expressed as a function of the observations $r_i$ according to $\alpha_i = r_i + W \operatorname{E}^{\ast}_i$.[^o11] The noninformative prior concentration weight $W$ is a function of the number of observations $r_0 = \sum r_i$, expressed as

$$W = \frac{K(1 + C_{W} r_0)}{1 + K r_0}$$

where $C_W$ is a convergence constant, normally chosen to be equal to 2. The choice of $C_W = 2$ ensures that the Dirichlet distribution of any dimension has the same sensitivity to new observations as the Beta distribution with prior concentration parameters $\alpha + \beta = 2$ (or the uniform $\alpha = \beta = 1$). In the case of a uniform prior probability distribution $\boldsymbol \operatorname{E}^{\ast}$, the noninformative prior weight $W$ also ensures a uniform prior Dirichlet distribution for any dimension $K$. A 3D plot of $W$ is illustrated in the figure.

## Properties {#Properties}

### Moments {#Moments}

Let $X = (X_1, \ldots, X_K)\sim\operatorname{Dir}(\boldsymbol\alpha)$.

Let

$$\alpha_0 = \sum_{i=1}^K \alpha_i.$$

Then[^o15][^o16]

$$\operatorname{E}[X_i] = \frac{\alpha_i}{\alpha_0},$$

$$\operatorname{Var}[X_i] = \frac{\alpha_i (\alpha_0-\alpha_i)}{\alpha_0^2 (\alpha_0+1)}.$$

Furthermore, if $i\neq j$

$$\operatorname{Cov}[X_i,X_j] = \frac{- \alpha_i \alpha_j}{\alpha_0^2 (\alpha_0+1)}.$$

The covariance matrix is [singular](wikipedia://en/217122).

More generally, moments of Dirichlet-distributed random variables can be expressed in the following way. For $\boldsymbol{t}=(t_1,\dotsc,t_K) \in \mathbb{R}^K$, denote by $\boldsymbol{t}^{\circ i} = (t_1^i,\dotsc,t_K^i)$ its $i$-th [Hadamard power](wikipedia://en/34260496#Analogous_operations). Then,[^o17]

$$\operatorname{E}\left[ (\boldsymbol{t} \cdot \boldsymbol{X})^n \right] = \frac{n! \, \Gamma ( \alpha_0 )}{\Gamma (\alpha_0+n)} \sum \frac{{t_1}^{k_1} \cdots {t_K}^{k_K}}{k_1! \cdots k_K!} \prod_{i=1}^K \frac{\Gamma(\alpha_i + k_i)}{\Gamma(\alpha_i)} = \frac{n! \, \Gamma ( \alpha_0 )}{\Gamma (\alpha_0+n)} Z_n(\boldsymbol{t}^{\circ 1} \cdot \boldsymbol{\alpha}, \cdots, \boldsymbol{t}^{\circ n} \cdot \boldsymbol{\alpha}),$$

where the sum is over non-negative integers $k_1,\ldots,k_K$ with $n=k_1+\cdots+k_K$, and $Z_n$ is the [cycle index polynomial](wikipedia://en/4720804#Symmetric_group_Sn) of the [Symmetric group](wikipedia://en/28901) of degree $n$.

We have the special case $\operatorname{E}\left[ \boldsymbol{t} \cdot \boldsymbol{X} \right] = \frac{\boldsymbol{t} \cdot \boldsymbol{\alpha}}{\alpha_0}.$

The multivariate analogue $\operatorname{E}\left[ (\boldsymbol{t}_1 \cdot \boldsymbol{X})^{n_1} \cdots (\boldsymbol{t}_q \cdot \boldsymbol{X})^{n_q} \right]$ for vectors $\boldsymbol{t}_1, \dotsc, \boldsymbol{t}_q \in \mathbb{R}^K$ can be expressed[^o18] in terms of a color pattern of the exponents $n_1, \dotsc, n_q$ in the sense of the [Pólya enumeration theorem](wikipedia://en/4396962).

Particular cases include the simple computation[^o19]

$$\operatorname{E}\left[\prod_{i=1}^K X_i^{\beta_i}\right] = \frac{B\left(\boldsymbol{\alpha} + \boldsymbol{\beta}\right)}{B\left(\boldsymbol{\alpha}\right)} = \frac{\Gamma\left(\sum\limits_{i=1}^K \alpha_{i}\right)}{\Gamma\left[\sum\limits_{i=1}^K (\alpha_i+\beta_i)\right]}\times\prod_{i=1}^K \frac{\Gamma(\alpha_i+\beta_i)}{\Gamma(\alpha_i)}.$$

### Mode {#Mode}

The [mode](wikipedia://en/1432127) of the distribution is[^o21] the vector $(x_{1}, ..., x_{K})$ with

$$x_i = \frac{\alpha_i - 1}{\alpha_0 - K}, \qquad \alpha_i > 1.$$

### Marginal distributions {#Marginal_distributions}

The [marginal distributions](wikipedia://en/506077) are [beta distributions](wikipedia://en/207074):[^o23]

$$X_i \sim \operatorname{Beta} (\alpha_i, \alpha_0 - \alpha_i).$$

Also see below.

### Conjugate to categorical or multinomial {#Conjugate_to_categorical_or_multinomial}

The Dirichlet distribution is the [conjugate prior](wikipedia://en/846412) distribution of the [categorical distribution](wikipedia://en/10072717) (a generic [discrete probability distribution](https://en.wikipedia.org/wiki/Discrete_probability_distribution) with a given number of possible outcomes) and [multinomial distribution](wikipedia://en/1045553) (the distribution over observed counts of each possible category in a set of categorically distributed observations). This means that if a data point has either a categorical or multinomial distribution, and the [prior distribution](https://en.wikipedia.org/wiki/Prior_distribution) of the distribution's parameter (the vector of probabilities that generates the data point) is distributed as a Dirichlet, then the [posterior distribution](https://en.wikipedia.org/wiki/Posterior_distribution) of the parameter is also a Dirichlet. Intuitively, in such a case, starting from what we know about the parameter prior to observing the data point, we then can update our knowledge based on the data point and end up with a new distribution of the same form as the old one. This means that we can successively update our knowledge of a parameter by incorporating new observations one at a time, without running into mathematical difficulties.

Formally, this can be expressed as follows. Given a model

$$\begin{array}{rcccl} \boldsymbol\alpha &=& \left(\alpha_1, \ldots, \alpha_K \right) &=& \text{concentration hyperparameter} \\ \mathbf{p}\mid\boldsymbol\alpha &=& \left(p_1, \ldots, p_K \right ) &\sim& \operatorname{Dir}(K, \boldsymbol\alpha) \\ \mathbb{X}\mid\mathbf{p} &=& \left(\mathbf{x}_1, \ldots, \mathbf{x}_K \right ) &\sim& \operatorname{Cat}(K,\mathbf{p}) \end{array}$$

then the following holds:

$$\begin{array}{rcccl} \mathbf{c} &=& \left(c_1, \ldots, c_K \right ) &=& \text{number of occurrences of category }i \\ \mathbf{p} \mid \mathbb{X},\boldsymbol\alpha &\sim& \operatorname{Dir}(K,\mathbf{c}+\boldsymbol\alpha) &=& \operatorname{Dir} \left (K,c_1+\alpha_1,\ldots,c_K+\alpha_K \right) \end{array}$$

This relationship is used in [Bayesian statistics](wikipedia://en/404412) to estimate the underlying parameter $\mathbf{p}$ of a [categorical distribution](wikipedia://en/10072717) given a collection of $N$ samples. Intuitively, we can view the [hyperprior](wikipedia://en/21761858) vector $\mathbf{\alpha}$ as [pseudocounts](https://en.wikipedia.org/wiki/Pseudocount), i.e. as representing the number of observations in each category that we have already seen. Then we simply add in the counts for all the new observations (the vector $\mathbf{c}$) in order to derive the posterior distribution.

In Bayesian [mixture models](wikipedia://en/871681) and other [hierarchical Bayesian models](https://en.wikipedia.org/wiki/Hierarchical_Bayesian_model) with mixture components, Dirichlet distributions are commonly used as the prior distributions for the [categorical variables](wikipedia://en/10072717) appearing in the models. See the section on applications below for more information.

### Relation to Dirichlet-multinomial distribution {#Relation_to_Dirichlet-multinomial_distribution}

In a model where a Dirichlet prior distribution is placed over a set of [categorical-valued](wikipedia://en/10072717) observations, the [marginal](wikipedia://en/506077) [joint distribution](https://en.wikipedia.org/wiki/Joint_distribution) of the observations (i.e. the joint distribution of the observations, with the prior parameter [marginalized out](https://en.wikipedia.org/wiki/Marginalized_out)) is a [Dirichlet-multinomial distribution](wikipedia://en/9169137). This distribution plays an important role in [hierarchical Bayesian models](https://en.wikipedia.org/wiki/Hierarchical_Bayesian_model), because when doing [inference](wikipedia://en/27577) over such models using methods such as [Gibbs sampling](wikipedia://en/509709) or [variational Bayes](https://en.wikipedia.org/wiki/Variational_Bayes), Dirichlet prior distributions are often marginalized out. See the [article on this distribution](wikipedia://en/9169137) for more details.

### Entropy {#Entropy}

If $X$ is a $\operatorname{Dir}(\boldsymbol\alpha)$ random variable, the [differential entropy](wikipedia://en/3504168) of $X$ (in [nat units](wikipedia://en/3070481)) is[^o27]

$$h(\boldsymbol X) = \operatorname{E}[- \ln f(\boldsymbol X)] = \ln \operatorname{B}(\boldsymbol\alpha) + (\alpha_0-K)\psi(\alpha_0) - \sum_{j=1}^K (\alpha_j-1)\psi(\alpha_j)$$

where $\psi$ is the [digamma function](wikipedia://en/406935).

The following formula for $\operatorname{E}[\ln(X_i)]$ can be used to derive the differential [entropy](https://en.wikipedia.org/wiki/Information_entropy) above. Since the functions $\ln(X_i)$ are the sufficient statistics of the Dirichlet distribution, the [exponential family differential identities](wikipedia://en/339174#Moments_and_cumulants_of_the_sufficient_statistic) can be used to get an analytic expression for the expectation of $\ln(X_i)$ (see equation (2.62) in [^o28]) and its associated covariance matrix:

$$\operatorname{E}[\ln(X_i)] = \psi(\alpha_i)-\psi(\alpha_0)$$

and

$$\operatorname{Cov}[\ln(X_i),\ln(X_j)] = \psi'(\alpha_i) \delta_{ij} - \psi'(\alpha_0)$$

where $\psi$ is the [digamma function](wikipedia://en/406935), $\psi'$ is the [trigamma function](wikipedia://en/2036750), and $\delta_{ij}$ is the [Kronecker delta](wikipedia://en/182890).

The spectrum of [Rényi information](wikipedia://en/1731689) for values other than $\lambda = 1$ is given by[^o29]

$$F_R(\lambda) = (1-\lambda)^{-1} \left( - \lambda \log \mathrm{B}(\boldsymbol\alpha) + \sum_{i=1}^K \log \Gamma(\lambda(\alpha_i - 1) + 1) - \log \Gamma(\lambda (\alpha_0 - K) + K ) \right)$$

and the information entropy is the limit as $\lambda$ goes to 1.

Another related interesting measure is the entropy of a discrete categorical (one-of-K binary) vector $\mathbf{Z}$ with probability-mass distribution $\mathbf{X}$, i.e., $P(Z_i=1, Z_{j\ne i} = 0 | \boldsymbol X) = X_i$. The conditional [information entropy](https://en.wikipedia.org/wiki/Information_entropy) of $\mathbf{Z}$, given $\mathbf{X}$ is

$$S(\boldsymbol X) = H(\boldsymbol Z | \boldsymbol X) = \operatorname{E}_{\boldsymbol Z}[- \log P(\boldsymbol Z | \boldsymbol X ) ] = \sum_{i=1}^K - X_i \log X_i$$

This function of $\mathbf{X}$ is a scalar random variable. If $\mathbf{X}$ has a symmetric Dirichlet distribution with all $\alpha_i = \alpha$, the expected value of the entropy (in [nat units](wikipedia://en/3070481)) is[^o30]

$$\operatorname{E}[S(\boldsymbol X)] = \sum_{i=1}^K \operatorname{E}[- X_i \ln X_i] = \psi(K\alpha + 1) - \psi(\alpha + 1)$$

### Kullback–Leibler divergence {#Kullback–Leibler_divergence}

The [Kullback–Leibler (KL) divergence](https://en.wikipedia.org/wiki/KL_divergence) between two Dirichlet distributions, $\text{Dir}(\boldsymbol\alpha)$ and $\text{Dir}(\boldsymbol{\beta})$, over the same simplex is:[^o32]

$$\begin{aligned} D_{\mathrm{KL}}\big(\mathrm{Dir}(\boldsymbol{\alpha}) \,\|\, \mathrm{Dir}(\boldsymbol{\beta})\big) &= \log \frac{\Gamma\left(\sum_{i=1}^K \alpha_i\right)}{\Gamma\left(\sum_{i=1}^K \beta_i\right)} + \sum_{i=1}^K \left[ \log \frac{\Gamma(\beta_i)}{\Gamma(\alpha_i)} + (\alpha_i - \beta_i) \left( \psi(\alpha_i) - \psi\left(\sum_{j=1}^K \alpha_j\right) \right) \right] \end{aligned}$$

### Aggregation {#Aggregation}

If

$$X = (X_1, \ldots, X_K)\sim\operatorname{Dir}(\alpha_1,\ldots,\alpha_K)$$

then, if the random variables with subscripts $i$ and $j$ are dropped from the vector and replaced by their sum,

$$X' = (X_1, \ldots, X_i + X_j, \ldots, X_K)\sim\operatorname{Dir} (\alpha_1, \ldots, \alpha_i + \alpha_j, \ldots, \alpha_K).$$

This aggregation property may be used to derive the marginal distribution of $X_i$ mentioned above.

### Neutrality {#Neutrality}

If $X = (X_1, \ldots, X_K)\sim\operatorname{Dir}(\boldsymbol\alpha)$, then the vector $X$ is said to be *neutral*[^o35] in the sense that *X${}_{K}$* is independent of $X^{(-K)}$[^o8] where

$$X^{(-K)}=\left(\frac{X_1}{1-X_K},\frac{X_2}{1-X_K},\ldots,\frac{X_{K-1}}{1-X_K} \right),$$

and similarly for removing any of $X_2,\ldots,X_{K-1}$. Observe that any permutation of $X$ is also neutral (a property not possessed by samples drawn from a [generalized Dirichlet distribution](wikipedia://en/12648537)).[^o36]

Combining this with the property of aggregation it follows that $X_{j} + ... + X_{K}$ is independent of $\left(\frac{X_1}{X_1+\cdots +X_{j-1}},\frac{X_2}{X_1+\cdots +X_{j-1}},\ldots,\frac{X_{j-1}}{X_1+\cdots +X_{j-1}} \right)$. In fact it is true, further, for the Dirichlet distribution, that for $3\le j\le K-1$, the pair $\left(X_1+\cdots +X_{j-1}, X_j+\cdots +X_K\right)$, and the two vectors $\left(\frac{X_1}{X_1+\cdots +X_{j-1}},\frac{X_2}{X_1+\cdots +X_{j-1}},\ldots,\frac{X_{j-1}}{X_1+\cdots +X_{j-1}} \right)$ and $\left(\frac{X_j}{X_j+\cdots +X_K},\frac{X_{j+1}}{X_j+\cdots +X_K},\ldots,\frac{X_K}{X_j+\cdots +X_K} \right)$, viewed as triple of normalised random vectors, are [mutually independent](wikipedia://en/27593#More_than_two_random_variables). The analogous result is true for partition of the indices $\{1, 2, ..., K\}$ into any other pair of non-singleton subsets.

### Characteristic function {#Characteristic_function}

The characteristic function of the Dirichlet distribution is a [confluent](wikipedia://en/1516095) form of the [Lauricella hypergeometric series](wikipedia://en/4016820). It is given by [Phillips](https://en.wikipedia.org/wiki/Peter_C._B._Phillips) as[^o38]

$$CF\left(s_1,\ldots,s_{K-1}\right) = \operatorname{E}\left(e^{i\left(s_1X_1+\cdots+s_{K-1}X_{K-1} \right)} \right)= \Psi^{\left[K-1\right]} (\alpha_1,\ldots,\alpha_{K-1};\alpha_0;is_1,\ldots, is_{K-1})$$

where

$$\Psi^{[m]} (a_1,\ldots,a_m;c;z_1,\ldots z_m) = \sum\frac{(a_1)_{k_1} \cdots (a_m)_{k_m} \, z_1^{k_1} \cdots z_m^{k_m}}{(c)_k\,k_1!\cdots k_m!}.$$

The sum is over non-negative integers $k_1,\ldots,k_m$ and $k=k_1+\cdots+k_m$. Phillips goes on to state that this form is "inconvenient for numerical calculation" and gives an alternative in terms of a [complex path integral](https://en.wikipedia.org/wiki/Methods_of_contour_integration):

$$\Psi^{[m]} = \frac{\Gamma(c)}{2\pi i}\int_L e^t\,t^{a_1+\cdots+a_m-c}\,\prod_{j=1}^m (t-z_j)^{-a_j} \, dt$$

where $L$ denotes any path in the complex plane originating at $-\infty$, encircling in the positive direction all the singularities of the integrand and returning to $-\infty$.

### Inequality {#Inequality}

Probability density function $f \left(x_1,\ldots, x_{K-1}; \alpha_1,\ldots, \alpha_K \right)$ plays a key role in a multifunctional inequality which implies various bounds for the Dirichlet distribution.[^o41]

Another inequality relates the moment-generating function of the Dirichlet distribution to the convex conjugate of the scaled reversed Kullback-Leibler divergence:[^o42]

$$\log \operatorname{E}\left(\exp{\sum_{i=1}^K s_i X_i } \right) \leq \sup_p \sum_{i=1}^K \left(p_i s_i - \alpha_i\log\left(\frac{\alpha_i}{\alpha_0 p_i} \right)\right),$$

where the supremum is taken over $p$ spanning the $(K - 1)$-simplex.

## Related distributions {#Related_distributions}

When $\boldsymbol X=(X_1, \ldots,X_K)\sim \operatorname{Dir}\left(\alpha_1, \ldots, \alpha_K \right)$, the marginal distribution of each component $X_i \sim \operatorname{Beta}(\alpha_i, \alpha_0-\alpha_i)$, a [Beta distribution](wikipedia://en/207074). In particular, if $K = 2$ then $X_1 \sim \operatorname{Beta}(\alpha_1, \alpha_2)$ is equivalent to $\boldsymbol X=(X_1,1-X_1) \sim \operatorname{Dir}\left(\alpha_1, \alpha_2 \right)$.

For $K$ independently distributed [Gamma distributions](wikipedia://en/207079):

$$Y_1 \sim \operatorname{Gamma}(\alpha_1, 1), \ldots, Y_K \sim \operatorname{Gamma}(\alpha_K, 1)$$

we have writing $\alpha_0 := \sum_{i=1}^K \limits \alpha_i$:[^o44]

$$V=\sum_{i=1}^K Y_i\sim\operatorname{Gamma} \left(\alpha_0, 1 \right ),$$

$$X = (X_1, \ldots, X_K) = \left(\frac{Y_1}{V}, \ldots, \frac{Y_K}{V} \right)\sim \operatorname{Dir}\left (\alpha_1, \ldots, \alpha_K \right).$$

Although the *X${}_{i}$*s are not independent from one another, they can be seen to be generated from a set of $K$ independent [gamma](wikipedia://en/207079) random variables.[^o44] Unfortunately, since the sum $V$ is lost in forming $X$ (in fact it can be shown that $V$ is stochastically independent of $X$), it is not possible to recover the original gamma random variables from these values alone. Nevertheless, because independent random variables are simpler to work with, this reparametrization can still be useful for proofs about properties of the Dirichlet distribution.

### Conjugate prior of the Dirichlet distribution {#Conjugate_prior_of_the_Dirichlet_distribution}

Because the Dirichlet distribution is an [exponential family distribution](wikipedia://en/339174) it has a conjugate prior. The conjugate prior is of the form:[^o46]

$$\operatorname{CD}(\boldsymbol\alpha \mid \boldsymbol{v},\eta) \propto \left(\frac{1}{\operatorname{B}(\boldsymbol\alpha)}\right)^\eta \exp\left(-\sum_k v_k \alpha_k\right).$$

Here $\boldsymbol{v}$ is a $K$-dimensional real vector and $\eta$ is a scalar parameter. The domain of $(\boldsymbol{v},\eta)$ is restricted to the set of parameters for which the above unnormalized density function can be normalized. The (necessary and sufficient) condition is:[^o47]

$$\forall k\;\;v_k>0\;\;\;\;\text{ and } \;\;\;\;\eta>-1 \;\;\;\;\text{ and } \;\;\;\;(\eta\leq0\;\;\;\;\text{ or }\;\;\;\;\sum_k \exp-\frac{v_k} \eta < 1)$$

The conjugation property can be expressed as

if \[*prior*: $\boldsymbol{\alpha}\sim\operatorname{CD}(\cdot \mid \boldsymbol{v},\eta)$\] and \[*observation*: $\boldsymbol{x}\mid\boldsymbol{\alpha}\sim\operatorname{Dirichlet}(\cdot \mid \boldsymbol{\alpha})$\] then \[*posterior*: $\boldsymbol{\alpha}\mid\boldsymbol{x}\sim\operatorname{CD}(\cdot \mid \boldsymbol{v}-\log \boldsymbol{x}, \eta+1)$\].

In the published literature there is no practical algorithm to efficiently generate samples from $\operatorname{CD}(\boldsymbol{\alpha} \mid \boldsymbol{v},\eta)$.

### Generalization by scaling and translation of log-probabilities {#Generalization_by_scaling_and_translation_of_log-probabilities}

As noted above, Dirichlet variates can be generated by normalizing independent [gamma](wikipedia://en/207079) variates. If instead one normalizes [generalized gamma](wikipedia://en/24553589) variates, one obtains variates from the simplicial generalized beta distribution (SGB).[^o49] On the other hand, SGB variates can also be obtained by applying the [softmax function](wikipedia://en/6152185) to scaled and translated logarithms of Dirichlet variates. Specifically, let $\mathbf x = (x_1, \ldots, x_K)\sim\operatorname{Dir}(\boldsymbol\alpha)$ and let $\mathbf y = (y_1, \ldots, y_K)$, where applying the logarithm elementwise:

$$\mathbf y = \operatorname{softmax}(a^{-1}\log\mathbf x + \log\mathbf b)\;\iff\;\mathbf x = \operatorname{softmax}(a\log\mathbf y - a\log\mathbf b)$$

or

$$y_k = \frac{b_kx_k^{1/a}}{\sum_{i=1}^Kb_ix_i^{1/a}}\; \iff\; x_k = \frac{(y_k/b_k)^a}{\sum_{i=1}^K(y_i/b_i)^a}$$

where $a>0$ and $\mathbf b = (b_1, \ldots, b_K)$, with all $b_k>0$, then $\mathbf y\sim\operatorname{SGB}(a, \mathbf b, \boldsymbol\alpha)$. The SGB density function can be derived by noting that the transformation $\mathbf x\mapsto\mathbf y$, which is a [bijection](wikipedia://en/3942) from the simplex to itself, induces a [differential volume change factor](wikipedia://en/67064736#Differential_volume_ratio)[^o50] of:

$$R(\mathbf y, a,\mathbf b) = a^{1-K}\prod_{k=1}^K\frac{y_k}{x_k}$$

where it is understood that $\mathbf x$ is recovered as a function of $\mathbf y$, as shown above. This facilitates writing the SGB density in terms of the Dirichlet density, as:

$$f_{\text{SGB}}(\mathbf y\mid a, \mathbf b, \boldsymbol\alpha) = \frac{f_{\text{Dir}}(\mathbf x\mid\boldsymbol\alpha)}{R(\mathbf y,a,\mathbf b)}$$

This generalization of the Dirichlet density, via a [change of variables](wikipedia://en/2146848), is closely related to a [normalizing flow](https://en.wikipedia.org/wiki/Normalizing_flow), while the differential volume change is not given by the [Jacobian determinant](https://en.wikipedia.org/wiki/Jacobian_determinant) of $\mathbf x\mapsto\mathbf y:\mathbb R^K\to\mathbb R^K$ which is zero, but by the Jacobian determinant of $(x_1,\ldots,x_{K-1})\mapsto\mathbf (y_1,\ldots,y_{K-1})$, as explained in more detail at [Normalizing flow § Simplex flow](wikipedia://en/67064736#Simplex_flow).

For further insight into the interaction between the Dirichlet shape parameters $\boldsymbol\alpha$, and the transformation parameters $a, \mathbf b$, it may be helpful to consider the logarithmic marginals, $\log\frac{x_k}{1-x_k}$, which follow the [logistic-beta distribution](https://en.wikipedia.org/wiki/Logistic-beta_distribution), $B_\sigma(\alpha_k,\sum_{i\ne k} \alpha_i)$. See in particular the sections on [tail behaviour](wikipedia://en/15841869#Tail_behaviour) and [generalization with location and scale parameters](wikipedia://en/15841869#Generalization_with_location_and_scale_parameters).

::: {#o52 .application cue=heading name="Application"}

#### Application {#Application}

When $b_1=b_2=\cdots=b_K$, then the transformation simplifies to $\mathbf x\mapsto\operatorname{softmax}(a^{-1}\log\mathbf x)$, which is known as [temperature scaling](https://en.wikipedia.org/wiki/Platt_scaling#Analysis) in [machine learning](wikipedia://en/233488), where it is used as a calibration transform for multiclass probabilistic classifiers.[^o53] Traditionally the temperature parameter ($a$ here) is learnt [discriminatively](wikipedia://en/12155912) by minimizing multiclass [cross-entropy](wikipedia://en/1735250) over a supervised calibration data set with known class labels. But the above PDF transformation mechanism can be used to facilitate also the design of [generatively trained](wikipedia://en/1222578) calibration models with a temperature scaling component.

:::

## Occurrence and applications {#Occurrence_and_applications}

### Bayesian models {#Bayesian_models}

Dirichlet distributions are most commonly used as the [prior distribution](https://en.wikipedia.org/wiki/Prior_distribution) of [categorical variables](wikipedia://en/10072717) or [multinomial variables](wikipedia://en/1045553) in Bayesian [mixture models](wikipedia://en/871681) and other [hierarchical Bayesian models](https://en.wikipedia.org/wiki/Hierarchical_Bayesian_model). (In many fields, such as in [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing), categorical variables are often imprecisely called "multinomial variables". Such a usage is unlikely to cause confusion, just as when [Bernoulli distributions](wikipedia://en/199189) and [binomial distributions](wikipedia://en/3876) are commonly conflated.)

Inference over hierarchical Bayesian models is often done using [Gibbs sampling](wikipedia://en/509709), and in such a case, instances of the Dirichlet distribution are typically [marginalized out](wikipedia://en/506077) of the model by integrating out the Dirichlet [random variable](wikipedia://en/25685). This causes the various categorical variables drawn from the same Dirichlet random variable to become correlated, and the joint distribution over them assumes a [Dirichlet-multinomial distribution](wikipedia://en/9169137), conditioned on the hyperparameters of the Dirichlet distribution (the [concentration parameters](wikipedia://en/28962480)). One of the reasons for doing this is that Gibbs sampling of the [Dirichlet-multinomial distribution](wikipedia://en/9169137) is extremely easy; see that article for more information.

### Intuitive interpretations of the parameters {#Intuitive_interpretations_of_the_parameters}

#### The concentration parameter {#The_concentration_parameter}

Dirichlet distributions are very often used as [prior distributions](https://en.wikipedia.org/wiki/Prior_distribution) in [Bayesian inference](wikipedia://en/49571). The simplest and perhaps most common type of Dirichlet prior is the symmetric Dirichlet distribution, where all parameters are equal. This corresponds to the case where you have no prior information to favor one component over any other. As described above, the single value $\alpha$ to which all parameters are set is called the [concentration parameter](wikipedia://en/28962480). If the sample space of the Dirichlet distribution is interpreted as a [discrete probability distribution](https://en.wikipedia.org/wiki/Discrete_probability_distribution), then intuitively the concentration parameter can be thought of as determining how "concentrated" the probability mass of the Dirichlet distribution to its center, leading to samples with mass dispersed almost equally among all components, i.e., with a value much less than 1, the mass will be highly concentrated in a few components, and all the rest will have almost no mass, and with a value much greater than 1, the mass will be dispersed almost equally among all the components. See the article on the [concentration parameter](wikipedia://en/28962480) for further discussion.

#### String cutting {#String_cutting}

One example use of the Dirichlet distribution is if one wanted to cut strings (each of initial length 1.0) into $K$ pieces with different lengths, where each piece had a designated average length, but allowing some variation in the relative sizes of the pieces. Recall that $\alpha_0 = \sum_{i=1}^K \alpha_i.$ The $\alpha_i/\alpha_0$ values specify the mean lengths of the cut pieces of string resulting from the distribution. The variance around this mean varies inversely with $\alpha_0$.

*Image: Dirichlet example.png.* Example of Dirichlet(1/2,1/3,1/6) distribution

#### [Pólya's urn](wikipedia://en/28955783) {#Pólya's_urn}

Consider an urn containing balls of $K$ different colors. Initially, the urn contains $\alpha_{1}$ balls of color 1, $\alpha_{2}$ balls of color 2, and so on. Now perform $N$ draws from the urn, where after each draw, the ball is placed back into the urn with an additional ball of the same color. In the limit as $N$ approaches infinity, the proportions of different colored balls in the urn will be distributed as $\operatorname{Dir}(\alpha_{1}, ..., \alpha_{K})$.[^o60]

For a formal proof, note that the proportions of the different colored balls form a bounded $[0,1]K$-valued [martingale](wikipedia://en/274536), hence by the [martingale convergence theorem](https://en.wikipedia.org/wiki/Martingale_convergence_theorem), these proportions converge [almost surely](https://en.wikipedia.org/wiki/Almost_sure_convergence) and [in mean](https://en.wikipedia.org/wiki/Convergence_in_mean) to a limiting random vector. To see that this limiting vector has the above Dirichlet distribution, check that all mixed [moments](wikipedia://en/368684) agree.

Each draw from the urn modifies the probability of drawing a ball of any one color from the urn in the future. This modification diminishes with the number of draws, since the relative effect of adding a new ball to the urn diminishes as the urn accumulates increasing numbers of balls.

## Random variate generation {#Random_variate_generation}

### From gamma distribution {#From_gamma_distribution}

With a source of Gamma-distributed random variates, one can easily sample a random vector $x=(x_1, \ldots, x_K)$ from the $K$-dimensional Dirichlet distribution with parameters $(\alpha_1, \ldots, \alpha_K)$ . First, draw $K$ independent random samples $y_1, \ldots, y_K$ from [Gamma distributions](wikipedia://en/207079) each with density

$$\operatorname{Gamma}(\alpha_i, 1) = \frac{y_i^{\alpha_i-1} \; e^{-y_i}}{\Gamma (\alpha_i)}, \!$$

and then set

$$x_i = \frac{y_i}{\sum_{j=1}^K y_j}.$$

::: {#o63 .proof cue=collapse name="[Proof]"}

The joint distribution of the independently sampled gamma variates, $\{y_{i}\}$, is given by the product:

$$e^{-\sum_{i}y_{i}} \prod _{i=1}^{K} \frac{y_{i}^{\alpha _{i}-1}}{\Gamma (\alpha _{i})}$$

Next, one uses a change of variables, parametrising $\{y_{i}\}$ in terms of $y_{1}, y_{2}, \ldots , y_{K-1}$ and $\sum _{i=1}^{K}y_{i}$ , and performs a change of variables from $y \to x$ such that $\bar x = \textstyle\sum_{i=1}^{K}y_{i}, x_{1} = \frac{y_{1}}{\bar x}, x_{2} = \frac{y_{2}}{\bar x}, \ldots , x_{K-1} = \frac{y_{K-1}}{\bar x}$. Each of the variables $0 \leq x_{1}, x_{2}, \ldots , x_{k-1} \leq 1$ and likewise $0 \leq \textstyle\sum _{i=1}^{K-1}x_{i} \leq 1$. One must then use the change of variables formula, $P(x) = P(y(x))\bigg|\frac{\partial y}{\partial x}\bigg|$ in which $\bigg|\frac{\partial y}{\partial x}\bigg|$ is the transformation Jacobian. Writing y explicitly as a function of x, one obtains $y_{1} = \bar xx_{1}, y_{2} = \bar xx_{2} \ldots y_{K-1} = \bar xx_{K-1}, y_{K} = \bar x(1-\textstyle\sum_{i=1}^{K-1}x_{i})$ The Jacobian now looks like

$$\begin{vmatrix}\bar x & 0 & \ldots & x_{1} \\ 0 & \bar x & \ldots & x_{2} \\ \vdots & \vdots & \ddots & \vdots \\ -\bar x & -\bar x & \ldots & 1-\sum_{i=1}^{K-1}x_{i} \end{vmatrix}$$

The determinant can be evaluated by noting that it remains unchanged if multiples of a row are added to another row, and adding each of the first K-1 rows to the bottom row to obtain

$$\begin{vmatrix}\bar x & 0 & \ldots & x_{1} \\ 0 & \bar x & \ldots & x_{2} \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \ldots & 1 \end{vmatrix}$$

which can be expanded about the bottom row to obtain the determinant value $\bar x^{K-1}$. Substituting for x in the joint pdf and including the Jacobian determinant, one obtains:

$$\begin{aligned} &\frac{\left[\prod _{i=1}^{K-1}(\bar xx_{i})^{\alpha _{i}-1} \right] \left[\bar x(1-\sum_{i=1}^{K-1}x_{i})\right]^{\alpha_{K}-1}}{\prod _{i=1}^{K}\Gamma (\alpha _{i})}\bar x^{K-1}e^{-\bar x} \\ =&\frac{\Gamma(\bar\alpha)\left[\prod _{i=1}^{K-1}(x_{i})^{\alpha _{i}-1} \right] \left[1-\sum_{i=1}^{K-1}x_{i}\right]^{\alpha_{K}-1}}{\prod _{i=1}^{K}\Gamma (\alpha _{i})}\times\frac{\bar x^{\bar\alpha-1}e^{-\bar x}}{\Gamma(\bar\alpha)} \end{aligned}$$

where $\bar\alpha=\textstyle\sum_{i=1}^K\alpha_i$. The right-hand side can be recognized as the product of a Dirichlet pdf for the $x_i$ and a gamma pdf for $\bar x$. The product form shows the Dirichlet and gamma variables are independent, so the latter can be integrated out by simply omitting it, to obtain:

$$x_{1}, x_{2}, \ldots, x_{K-1} \sim \frac{(1-\sum_{i=1}^{K-1}x_{i})^{\alpha _{K}-1}\prod _{i=1}^{K-1}x_{i}^{\alpha _{i} -1}}{B(\boldsymbol{\alpha})}$$

Which is equivalent to

$$\frac{\prod _{i=1}^{K} x_{i}^{\alpha_{i}-1}}{B(\boldsymbol{\alpha})}$$

with support $\sum_{i=1}^{K}x_{i}=1$

:::

Below is example Python code to draw the sample:

```python
params = [a1, a2, ..., ak]
sample = [random.gammavariate(a, 1) for a in params]
sample = [v / sum(sample) for v in sample]
```

This formulation is correct regardless of how the Gamma distributions are parameterized (shape/scale vs. shape/rate) because they are equivalent when scale and rate equal 1.0.

### From marginal beta distributions {#From_marginal_beta_distributions}

A less efficient algorithm[^o65] relies on the univariate marginal and conditional distributions being beta and proceeds as follows. Simulate $x_1$ from

$$\textrm{Beta}\left(\alpha_1, \sum_{i=2}^K \alpha_i \right)$$

Then simulate $x_2, \ldots, x_{K-1}$ in order, as follows. For $j=2, \ldots, K-1$, simulate $\phi_j$ from

$$\textrm{Beta} \left(\alpha_j, \sum_{i=j+1}^K \alpha_i \right ),$$

and let

$$x_j= \left(1-\sum_{i=1}^{j-1} x_i \right )\phi_j.$$

Finally, set

$$x_K=1-\sum_{i=1}^{K-1} x_i.$$

This iterative procedure corresponds closely to the "string cutting" intuition described above.

Below is example Python code to draw the sample:

```python
params = [a1, a2, ..., ak]
xs = [random.betavariate(params[0], sum(params[1:]))]
for j in range(1, len(params) - 1):
    phi = random.betavariate(params[j], sum(params[j + 1 :]))
    xs.append((1 - sum(xs)) * phi)
xs.append(1 - sum(xs))
```

### When each alpha is 1 {#When_each_alpha_is_1}

When $\alpha_{1} = ... = \alpha_{K} = 1$, a sample from the distribution can be found by randomly drawing a set of $K - 1$ values independently and uniformly from the interval $[0, 1]$, adding the values $0$ and $1$ to the set to make it have $K + 1$ values, sorting the set, and computing the difference between each pair of order-adjacent values, to give $x_{1}$, ..., $x_{K}$.

### When each alpha is 1/2 and relationship to the hypersphere {#When_each_alpha_is_1/2_and_relationship_to_the_hypersphere}

When $\alpha_{1} = ... = \alpha_{K} = 1/2$, a sample from the distribution can be found by randomly drawing $K$ values independently from the standard normal distribution, squaring these values, and normalizing them by dividing by their sum, to give $x_{1}$, ..., $x_{K}$.

A point $(x_{1}$, ..., $x_{K})$ can be drawn uniformly at random from the ($K-1$)-dimensional unit hypersphere (which is the surface of a $K$-dimensional [hyperball](wikipedia://en/160556)) via a similar procedure. Randomly draw $K$ values independently from the standard normal distribution and normalize these coordinate values by dividing each by the constant that is the square root of the sum of their squares.
