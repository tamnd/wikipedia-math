# Unordered pair

::: {#o1 .subject cue=lead name="Unordered pair"}

In [mathematics](wikipedia://en/18831), an **unordered pair** or **pair set** is a [set](wikipedia://en/26691) of the form {*a*, *b*}, i.e. a set having two elements *a* and *b* with no particular relation between them, where {*a*, *b*} = {*b*, *a*}. In contrast, an [ordered pair](wikipedia://en/22362) (*a*, *b*) has *a* as its first element and *b* as its second element, which means (*a*, *b*) ≠ (*b*, *a*) unless *a*=*b*.

:::

While the two elements of an ordered pair (*a*, *b*) need not be distinct, modern authors only call {*a*, *b*} an unordered pair if *a* ≠ *b*.[^o2][^o3][^o4][^o5] But for a few authors a [singleton](wikipedia://en/381798) is also considered an unordered pair. It is typical to use the term unordered pair even in the situation where the elements a and b could be equal, as long as this equality has not yet been established.

A set with precisely two elements is also called a [2-set](wikipedia://en/11742) or (rarely) a **binary set**.

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the existence of unordered pairs is required by an axiom, the [axiom of pairing](wikipedia://en/52385).

More generally, an **unordered***n***\-tuple** is a set of the form {*a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a<sub>n</sub>*}.[^o6][^o7][^o8]
