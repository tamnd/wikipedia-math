# Canon Palmtronic LE-80M

*Image: Canon palmtronic 17o06.jpg.* Canon Palmtronic LE-80M calculator (on 5cm squares)

::: {#o1 .subject cue=lead name="Canon Palmtronic LE-80M"}

The **Canon Palmtronic LE-80M** is an early hand-held [calculator](wikipedia://en/7593). It was manufactured by [Canon inc](https://en.wikipedia.org/wiki/Canon_%28company%29). Unlike other models which used a processing chip manufactured by [Texas Instruments](https://en.wikipedia.org/wiki/Texas_Instruments) the LE-80M used a [Hitachi](https://en.wikipedia.org/wiki/Hitachi) HD3553 chip.[^o2] When first released in 1973, it retailed for \$138.45.[^o3]
