# Algebraically compact module

::: {#o1 .subject cue=lead name="Algebraically compact module"}

In [mathematics](wikipedia://en/18831), **algebraically compact modules**, also called **pure-injective modules**, are [modules](wikipedia://en/276410) that have a certain "nice" property which allows the solution of infinite systems of equations in the module by [finitary](wikipedia://en/404456) means. The solutions to these systems allow the extension of certain kinds of [module homomorphisms](wikipedia://en/474118). These algebraically compact modules are analogous to [injective modules](wikipedia://en/473775), where one can extend all module homomorphisms. All injective modules are algebraically compact, and the analogy between the two is made quite precise by a category embedding.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $R$ be a [ring](wikipedia://en/48404), and $M$ a left $R$-module. Consider a system of infinitely many linear equations

$$\sum_{j\in J} r_{i,j}x_j = m_i,$$

where both sets $I$ and $J$ may be infinite, $m_i\in M,$ and for each $i$ the number of nonzero $r_{i,j}\in R$ is finite.

The goal is to decide whether such a system has a *solution*, that is whether there exist elements $x_{j}$ of $M$ such that all the equations of the system are simultaneously satisfied. (It is not required that only finitely many $x_{j}$ are non-zero.)

The module *M* is **algebraically compact** if, for all such systems, if every subsystem formed by a finite number of the equations has a solution, then the whole system has a solution. (The solutions to the various subsystems may be different.)

On the other hand, a [module homomorphism](wikipedia://en/474118) $M \to K$ is a *pure embedding* if the [induced homomorphism](wikipedia://en/17018463) between the [tensor products](wikipedia://en/30844) $C \otimes M \to C \otimes K$ is [injective](https://en.wikipedia.org/wiki/Injective) for every right $R$-module $C$. The module $M$ is **pure-injective** if any pure injective homomorphism $j : M \to K$ [splits](https://en.wikipedia.org/wiki/Split_short_exact_sequence) (that is, there exists $f : K \to M$ with $f\circ j=1_M$).

It turns out that a module is algebraically compact [if and only if](wikipedia://en/14922) it is pure-injective.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

All modules with finitely many elements are algebraically compact.

Every [vector space](wikipedia://en/32370) is algebraically compact (since it is pure-injective). More generally, every [injective module](wikipedia://en/473775) is algebraically compact, for the same reason.

If *R* is an [associative algebra](wikipedia://en/2112) with 1 over some [field](wikipedia://en/10603) *k*, then every *R*-module with finite *k*-[dimension](https://en.wikipedia.org/wiki/Dimension_of_a_vector_space) is algebraically compact. This, together with the fact that all finite modules are algebraically compact, gives rise to the intuition that algebraically compact modules are those (possibly "large") modules which share the nice properties of "small" modules.

The [Prüfer groups](wikipedia://en/4885031) are algebraically compact [abelian groups](wikipedia://en/2974) (i.e. **Z**-modules). The ring of [*p*-adic integers](wikipedia://en/51423) for each prime *p* is algebraically compact as both a module over itself and a module over **Z**. The [rational numbers](wikipedia://en/19727024) are algebraically compact as a **Z**-module. Together with the [indecomposable](wikipedia://en/810549) finite modules over **Z**, this is a complete list of indecomposable algebraically compact modules.

Many algebraically compact modules can be produced using the [injective cogenerator](https://en.wikipedia.org/wiki/Injective_cogenerator) **Q**/**Z** of abelian groups. If *H* is a *right* module over the ring *R*, one forms the (algebraic) character module *H*\* consisting of all [group homomorphisms](wikipedia://en/12396) from *H* to **Q**/**Z**. This is then a left *R*-module, and the \*-operation yields a [faithful](https://en.wikipedia.org/wiki/Faithful_functor) contravariant [functor](wikipedia://en/10987) from right *R*-modules to left *R*-modules. Every module of the form *H*\* is algebraically compact. Furthermore, there are pure injective homomorphisms *H* → *H*\*\*, [natural](wikipedia://en/45022) in *H*. One can often simplify a problem by first applying the \*-functor, since algebraically compact modules are easier to deal with.

:::

## Facts {#Facts}

The following condition is equivalent to *M* being algebraically compact:

- For every index set *I*, the addition map *M<sup>(I)</sup>* → *M* can be extended to a module homomorphism *M<sup>I</sup>* → *M* (here *M<sup>(I)</sup>* denotes the [direct sum](wikipedia://en/58899) of copies of *M*, one for each element of *I*; *M<sup>I</sup>* denotes the [product](wikipedia://en/237868) of copies of *M*, one for each element of *I*).

Every [indecomposable](wikipedia://en/810549) algebraically compact module has a [local](wikipedia://en/153391) [endomorphism ring](wikipedia://en/59623).

Algebraically compact modules share many other properties with injective objects because of the following: there exists an embedding of *R*-Mod into a [Grothendieck category](wikipedia://en/30051538) *G* under which the algebraically compact *R*-modules precisely correspond to the injective objects in *G*.

Every *R*-module is [elementary equivalent](wikipedia://en/972601) to an algebraically compact *R*-module and to a direct sum of [indecomposable](wikipedia://en/810549) algebraically compact *R*-modules.[^o8]
