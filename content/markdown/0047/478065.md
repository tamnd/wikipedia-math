# Pancake sorting

*Image: Pancake sort operation.png.* Demonstration of the primary operation. The spatula is flipping over the top three pancakes, with the result seen below. In the burnt pancake problem, their top sides would now be burnt instead of their bottom sides!

::: {#o1 .subject cue=lead name="Pancake sorting"}

**Pancake sorting** is the mathematical problem of sorting a disordered stack of pancakes in order of size when a [spatula](https://en.wikipedia.org/wiki/Spatula) can be inserted at any point in the stack and used to flip all pancakes above it. A *pancake number* is the minimum number of flips required for a given number of pancakes. In this form, the problem was first discussed by American geometer [Jacob E. Goodman](https://en.wikipedia.org/wiki/Jacob_E._Goodman).[^o2] A variant of the problem is concerned with *burnt* pancakes, where each pancake has a burnt side and all pancakes must, in addition, end up with the burnt side on the bottom.

:::

All sorting methods require pairs of elements to be compared. For the traditional [sorting problem](https://en.wikipedia.org/wiki/Sorting_problem), the usual problem studied is to minimize the [number of comparisons required to sort a list](wikipedia://en/3189304#Number_of_comparisons_required_to_sort_a_list). The number of actual operations, such as swapping two elements, is then irrelevant. For pancake sorting problems, in contrast, the aim is to minimize the number of operations, where the only allowed operations are reversals of the elements of some *[prefix](https://en.wikipedia.org/wiki/Prefix_%28computer_science%29)* of the sequence. Now, the number of comparisons is irrelevant.

## The pancake problems {#The_pancake_problems}

### The original pancake problem {#The_original_pancake_problem}

The minimum number of flips required to sort any stack of $n$ pancakes has been shown to lie between $\tfrac{15}{14}n$ and $\tfrac{18}{11}n$ (approximately 1.07*n* and 1.64*n*), but the exact value is not known.[^o5]

The simplest pancake sorting algorithm performs at most $2n - 3$ flips. In this algorithm, a kind of [selection sort](https://en.wikipedia.org/wiki/Selection_sort), we bring the largest pancake not yet sorted to the top with one flip; take it down to its final position with one more flip; and repeat this process for the remaining pancakes.

In 1979, [Bill Gates](https://en.wikipedia.org/wiki/Bill_Gates) and [Christos Papadimitriou](https://en.wikipedia.org/wiki/Christos_Papadimitriou)[^o17] gave a lower bound of $\tfrac{17}{16}n$ (approximately 1.06*n*) flips and an upper bound of $\tfrac{(5n+5)}{3}$. The upper bound was improved, thirty years later, to $\tfrac{18}{11}n$ by a team of researchers at the [University of Texas at Dallas](https://en.wikipedia.org/wiki/University_of_Texas_at_Dallas), led by Founders Professor [Hal Sudborough](https://en.wikipedia.org/wiki/Hal_Sudborough).[^o6][^o7]

In 2011, Laurent Bulteau, Guillaume Fertin, and Irena Rusu[^o8] proved that the problem of finding the shortest sequence of flips for a given stack of pancakes is [NP-hard](https://en.wikipedia.org/wiki/NP-hard), thereby answering a question that had been open for over three decades.

### The burnt pancake problem {#The_burnt_pancake_problem}

In a variation called the **burnt pancake problem**, the bottom of each pancake in the pile is burnt, and the sort must be completed with the burnt side of every pancake down. It is a *signed permutation*, and if a pancake *i* is "burnt side up" a negative element *i\`* is put in place of *i* in the permutation. In 2008, a group of undergraduates built a [bacterial computer](https://en.wikipedia.org/wiki/DNA_computing) that can solve a simple example of the burnt pancake problem by programming *[E. coli](https://en.wikipedia.org/wiki/Escherichia_coli)* to flip segments of DNA which are analogous to burnt pancakes. DNA has an orientation (5' and 3') and an order (promoter before coding). Even though the processing power expressed by DNA flips is low, the high number of bacteria in a culture provides a large [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing) platform. The bacteria report when they have solved the problem by becoming antibiotic resistant.[^o10]

## The pancake problem on strings {#The_pancake_problem_on_strings}

The discussion above presumes that each pancake is unique, that is, the sequence on which the prefix reversals are performed is a *[permutation](wikipedia://en/44027)*. However, "strings" are sequences in which a symbol can repeat, and this repetition may reduce the number of prefix reversals required to sort. Chitturi and Sudborough (2010) and Hurkens et al. (2007) independently showed that the complexity of transforming a compatible string into another with the minimum number of prefix reversals is [NP-complete](https://en.wikipedia.org/wiki/NP-complete). They also gave bounds for the same. Hurkens et al. gave an exact algorithm to sort binary and ternary strings. Chitturi[^o12] (2011) proved that the complexity of transforming a compatible signed string into another with the minimum number of signed prefix reversals—the burnt pancake problem on strings—is NP-complete.

## History {#History}

The pancake sorting problem was first posed by [Jacob E. Goodman](https://en.wikipedia.org/wiki/Jacob_E._Goodman), writing under the pseudonym "Harry Dweighter" ("harried waiter").[^o14]

Although seen more often as an educational device, pancake sorting also appears in applications in parallel processor networks, in which it can provide an effective routing algorithm between processors.[^o15][^o16]

The problem is notable as the topic of the only well-known mathematics paper by [Microsoft](https://en.wikipedia.org/wiki/Microsoft) founder [Bill Gates](https://en.wikipedia.org/wiki/Bill_Gates) (as William Gates), entitled "Bounds for Sorting by Prefix Reversal" and co-authored with [Christos Papadimitriou](https://en.wikipedia.org/wiki/Christos_Papadimitriou). Published in 1979, it describes an efficient algorithm for pancake sorting.[^o17] In addition, the most notable paper published by *[Futurama](https://en.wikipedia.org/wiki/Futurama)* co-creator [David X. Cohen](https://en.wikipedia.org/wiki/David_X._Cohen) (as David S. Cohen), co-authored with [Manuel Blum](https://en.wikipedia.org/wiki/Manuel_Blum), concerned the burnt pancake problem.[^o18]

The connected problems of signed sorting by reversals and sorting by reversals were also studied more recently. Whereas efficient exact algorithms have been found for the signed sorting by reversals,[^o19] the problem of sorting by reversals has been proven to be hard even to approximate to within certain constant factor,[^o20] and also proven to be approximable in polynomial time to within the approximation factor 1.375.[^o21]

## Pancake graphs {#Pancake_graphs}

*Image: Pancake graph g3.svg.* The pancake graph P<sub>3</sub>

*Image: Pancake graph g4.svg.* The pancake graph P<sub>4</sub> can be constructed recursively from 4 copies of P<sub>3</sub> by assigning a different element from the set {1, 2, 3, 4} as a suffix to each copy.

An ***n*-pancake graph** is a graph whose vertices are the permutations of *n* symbols from 1 to *n* and its edges are given between permutations transitive by prefix reversals. It is a [regular graph](wikipedia://en/85821) with n! vertices, its degree is n−1. The pancake sorting problem and the problem to obtain the [diameter](wikipedia://en/2979341) of the pancake graph are equivalent.[^o23]

The pancake graph of dimension *n*, P<sub>n</sub> can be constructed recursively from n copies of P<sub>n−1</sub>, by assigning a different element from the set {1, 2, …, n} as a suffix to each copy.

Their [girth](wikipedia://en/12013):

$$g(P_n) = 6 \text{, if } n>2.$$

The γ(P<sub>n</sub>) [genus](wikipedia://en/8149170) of P<sub>n</sub> is:[^o24]

$$n!\left( \frac{n-4}{6} \right)+1 \le \gamma(P_n) \le n!\left( \frac{n-3}{4} \right)-\frac{n}{2}+1$$

Since pancake graphs have many interesting properties such as symmetric and recursive structures, small degrees and diameters compared against the size of the graph, much attention is paid to them as a model of interconnection networks for parallel computers.[^o25][^o26][^o27] When we regard the pancake graphs as the model of the interconnection networks, the diameter of the graph is a measure that represents the delay of communication.[^o28][^o29]

The pancake graphs are [Cayley graphs](wikipedia://en/358277) (thus are [vertex-transitive](wikipedia://en/581175)) and are especially attractive for parallel processing. They have sublogarithmic degree and diameter, and are relatively [sparse](wikipedia://en/2777098) (compared to e.g. [hypercubes](wikipedia://en/6706815)).[^o24]

## Algorithm {#Algorithm}

An example of the pancake sorting algorithm is given below in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29). The code is similar to [bubble sort](https://en.wikipedia.org/wiki/Bubble_sort) or [selection sort](https://en.wikipedia.org/wiki/Selection_sort).

```python3
def flip(arr, k: int) -> None:
    left = 0
    while left < k:
        arr[left], arr[k] = arr[k], arr[left]
        k -= 1
        left += 1

def max_index(arr, k: int) -> int:
    index = 0
    for i in range(k):
        if arr[i] > arr[index]:
            index = i
    return index

def pancake_sort(arr) -> None:
    n = len(arr)
    while n > 1:
        maxidx = max_index(arr, n)
        if maxidx != n - 1:
            if maxidx != 0:
                flip(arr, maxidx)
            flip(arr, n - 1)
        n -= 1

arr = [15, 8, 9, 1, 78, 30, 69, 4, 10]
pancake_sort(arr)
print(arr)
```
