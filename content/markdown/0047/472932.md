# Kirszbraun theorem

::: {#o1 .subject cue=lead name="Kirszbraun theorem"}

In [mathematics](wikipedia://en/18831), specifically [real analysis](wikipedia://en/26478) and [functional analysis](wikipedia://en/11180), the **Kirszbraun theorem** states that if $U$ is a [subset](wikipedia://en/27631) of some [Hilbert space](wikipedia://en/20598932) $H_{1}$, and $H_{2}$ is another Hilbert space, and

:::

$$f: U \rightarrow H_2$$

is a [Lipschitz-continuous](wikipedia://en/51731) map, then there is a Lipschitz-continuous map

$$F: H_1 \rightarrow H_2$$

that extends $f$ and has the same Lipschitz constant as $f$.

Note that this result in particular applies when $H_1$ and $H_2$ are [Euclidean spaces](wikipedia://en/9697), and it was in this form that Kirszbraun originally formulated and proved the theorem.[^o2] The version for Hilbert spaces can for example be found in (Schwartz 1969, p. 21).[^o3] If $H_{1}$ is a [separable space](wikipedia://en/27855) (in particular, if it is a Euclidean space) the result is true in [Zermelo–Fraenkel set theory](wikipedia://en/152214); for the fully general case, it appears to need some form of the axiom of choice; the [Boolean prime ideal theorem](wikipedia://en/314919) is known to be sufficient.[^o4]

The proof of the theorem uses geometric features of Hilbert spaces; the corresponding statement for [Banach spaces](wikipedia://en/3989) is not true in general, not even for finite-dimensional Banach spaces. It is for instance possible to construct counterexamples where the domain is a subset of $\mathbb{R}^n$ with the [maximum norm](wikipedia://en/349755) and $\mathbb{R}^m$ carries the Euclidean norm.[^o5] More generally, the theorem fails for $\mathbb{R}^m$ equipped with any $\ell_p$ norm ($p \neq 2$) (Schwartz 1969, p. 20).[^o3]

::: {#o7 .statement cue=named-heading name="Explicit formulas"}

## Explicit formulas {#Explicit_formulas}

For an $\mathbb{R}$-valued function the extension is provided by

$$\tilde f(x):=\inf_{u\in U}\big(f(u)+\text{Lip}(f)\cdot d(x,u)\big),$$

where $\text{Lip}(f)$ is the Lipschitz constant of $f$ on $U$.[^o8]

In general, an extension can also be written for $\mathbb{R}^{m}$-valued functions as

$$\tilde f(x):= \nabla_{y}(\textrm{conv}(g(x,y))(x,0),$$

where

$$g(x,y):=\inf_{u\in U}\left\{\langle f(u),y \rangle +\frac{\text{Lip}(f)}{2}\|x-u\|^{2}\right\}+\frac{\text{Lip}(f)}{2} \|x\|^{2}+\text{Lip}(f)\|y\|^{2}$$

and conv(*g*) is the lower convex envelope of *g*.[^o9]

:::

## History {#History}

The theorem was proved by [Mojżesz David Kirszbraun](wikipedia://en/29383270) (1934),[^o2] and later it was reproved by [Frederick Valentine](https://en.wikipedia.org/wiki/Frederick_Valentine) (1945),[^o11] who first proved it for the Euclidean plane.[^o12] Sometimes this theorem is also called **Kirszbraun–Valentine theorem**. An explicit formula for Lipschitz extension was given by E. J. McShane in 1934.[^o8]
