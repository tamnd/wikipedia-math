# Syskey

*Image: Syskey screenshot.png.* Screenshot of the Syskey utility on the [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1) operating system requesting the user to enter a password

::: {#o1 .subject cue=lead name="Syskey"}

The **SAM Lock Tool**, better known as **Syskey** (the name of its [executable file](https://en.wikipedia.org/wiki/Executable_file)), is a discontinued component of [Windows NT](https://en.wikipedia.org/wiki/Windows_NT) that [encrypts](wikipedia://en/10294) the [Security Account Manager](https://en.wikipedia.org/wiki/Security_Account_Manager) (SAM) [database](https://en.wikipedia.org/wiki/Database) using a 128-bit [RC4](wikipedia://en/25831) [encryption key](https://en.wikipedia.org/wiki/Encryption_key).[^o2]

:::

Introduced in the Q143475 hotfix for [Windows NT 4.0](https://en.wikipedia.org/wiki/Windows_NT_4.0) SP3, the tool was removed in [Windows 10](https://en.wikipedia.org/wiki/Windows_10)'s Fall Creators Update in 2017 because its method of [cryptography](wikipedia://en/18934432) is considered insecure by modern standards and the fact that the tool has been widely employed in scams as a form of [ransomware](https://en.wikipedia.org/wiki/Ransomware). Microsoft officially recommended use of [BitLocker](https://en.wikipedia.org/wiki/BitLocker) [disk encryption](wikipedia://en/7066791) as an alternative.[^o3][^o4]

## History {#History}

Introduced in the Q143475 hotfix included in [Windows NT 4.0](https://en.wikipedia.org/wiki/Windows_NT_4.0) SP3,[^o10] Syskey was intended to protect against [offline](https://en.wikipedia.org/wiki/Offline) [password cracking](wikipedia://en/477981) attacks by preventing the possessor of an unauthorized copy of the SAM file from extracting useful information from it.[^o10]

Syskey can optionally be configured to require the user to enter the key during [boot](https://en.wikipedia.org/wiki/Booting) (as a startup password) or to load the key onto removable storage media (e.g., a [floppy disk](https://en.wikipedia.org/wiki/Floppy_disk) or [USB flash drive](https://en.wikipedia.org/wiki/USB_flash_drive)).[^o6]

In mid-2017, Microsoft announced the removal of syskey.exe from Windows 10 and Server, versions 1709 and Windows Server 2019.[^o7] Microsoft suggests the use of [BitLocker](https://en.wikipedia.org/wiki/BitLocker) as a more secure alternative to syskey.exe.

## Security issues {#Security_issues}

### The "Syskey Bug" {#The_"Syskey_Bug"}

In December 1999, a security team from [BindView](https://en.wikipedia.org/wiki/BindView) found a security hole in Syskey that indicated that a certain form of offline [cryptanalytic](wikipedia://en/5715) attack is possible, making a [brute force attack](https://en.wikipedia.org/wiki/Brute_force_attack) appear to be possible.[^o10] Microsoft later issued a fix for the problem (dubbed the "Syskey Bug").[^o11] The bug affected both Windows NT 4.0 and pre-RC3 versions of [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000).[^o10]

### Use as ransomware {#Use_as_ransomware}

Syskey is commonly abused by [technical support scammers](https://en.wikipedia.org/wiki/Technical_support_scam) to lock victims out of their own computers in order to coerce them into paying a ransom.[^o13][^o14] It is also used against such scammers by [scambaiters](https://en.wikipedia.org/wiki/Scam_baiting) as a way to disrupt their fraudulent operations.
