# Low-discrepancy sequence

::: {#o1 .subject cue=lead name="Low-discrepancy sequence"}

In [mathematics](wikipedia://en/18831), a **low-discrepancy sequence** is a [sequence](wikipedia://en/27838) with the property that for all values of $N$, its subsequence $x_1, \ldots, x_N$ has a low [discrepancy](https://en.wikipedia.org/wiki/Discrepancy_of_a_sequence).

:::

Roughly speaking, the discrepancy of a sequence is low if the proportion of points in the sequence falling into an arbitrary set *B* is close to proportional to the [measure](wikipedia://en/19873) of *B*, as would happen on average (but not for particular samples) in the case of an [equidistributed sequence](wikipedia://en/1030420). Specific definitions of discrepancy differ regarding the choice of *B* ([hyperspheres](https://en.wikipedia.org/wiki/Hyperspheres), [hypercubes](wikipedia://en/39783), etc.) and how the discrepancy for every B is computed (usually normalized) and combined (usually by taking the worst value).

Low-discrepancy sequences are also called **quasirandom** sequences, due to their common use as a replacement of uniformly distributed [random numbers](wikipedia://en/48256). The "quasi" modifier is used to denote more clearly that the values of a low-discrepancy sequence are neither random nor [pseudorandom](https://en.wikipedia.org/wiki/Pseudorandom), but such sequences share some properties of random variables and in certain applications such as the [quasi-Monte Carlo method](wikipedia://en/487599) their lower discrepancy is an important advantage.

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

*Image: Subrandom Kurtosis.gif.* Error in estimated kurtosis as a function of number of datapoints. 'Additive quasirandom' gives the maximum error when *c* = ($\sqrt{5}$ − 1)/2. 'Random' gives the average error over six runs of random numbers, where the average is taken to reduce the magnitude of the wild fluctuations

Quasirandom numbers have an advantage over pure random numbers in that they cover the domain of interest quickly and evenly.

Two useful applications are in finding the [characteristic function](wikipedia://en/3229401) of a [probability density function](wikipedia://en/43487), and in finding the [derivative](wikipedia://en/7921) function of a deterministic function with a small amount of noise. Quasirandom numbers allow higher-order [moments](wikipedia://en/368684) to be calculated to high accuracy very quickly.

Applications that don't involve sorting would be in finding the [mean](https://en.wikipedia.org/wiki/Mean), [standard deviation](wikipedia://en/27590), [skewness](wikipedia://en/28212) and [kurtosis](wikipedia://en/16848) of a statistical distribution, and in finding the [integral](wikipedia://en/15532) and global [maxima and minima](https://en.wikipedia.org/wiki/Maxima_and_minima) of difficult deterministic functions. Quasirandom numbers can also be used for providing starting points for deterministic algorithms that only work locally, such as [Newton–Raphson iteration](https://en.wikipedia.org/wiki/Newton–Raphson_iteration).

Quasirandom numbers can also be combined with search algorithms. With a [search algorithm](https://en.wikipedia.org/wiki/Search_algorithm), quasirandom numbers can be used to find the [mode](wikipedia://en/1432127), [median](wikipedia://en/18837), [confidence intervals](https://en.wikipedia.org/wiki/Confidence_intervals) and [cumulative distribution](wikipedia://en/5793) of a statistical distribution, and all [local minima](https://en.wikipedia.org/wiki/Local_minima) and all solutions of deterministic functions.

### Low-discrepancy sequences in numerical integration {#Low-discrepancy_sequences_in_numerical_integration}

Various methods of [numerical integration](wikipedia://en/170089) can be phrased as approximating the integral of a function $f$ in some interval, e.g. \[0,1\], as the average of the function evaluated at a set $\{x_1, \dots, x_N }\$ in that interval:

$$\int_0^1 f(u)\,du \approx \frac{1}{N}\,\sum_{i=1}^N f(x_i).$$

If the points are chosen as $x_i = i/N$, this is the *rectangle rule*. If the points are chosen to be randomly (or [pseudorandomly](https://en.wikipedia.org/wiki/Pseudorandom)) distributed, this is the *[Monte Carlo method](wikipedia://en/56098)*. If the points are chosen as elements of a low-discrepancy sequence, this is the *quasi-Monte Carlo method*. A remarkable result, the **Koksma–Hlawka inequality** (stated below), shows that the error of such a method can be bounded by the product of two terms, one of which depends only on $f$, and the other one is the discrepancy of the set $\{x_1, \dots, x_N }\$.

It is convenient to construct the set $\{x_1, \dots, x_N }\$ in such a way that if a set with $N+1$ elements is constructed, the previous $N$ elements need not be recomputed. The rectangle rule uses point sets which have low discrepancy, but in general the elements must be recomputed if $N$ is increased. Elements need not be recomputed in the random Monte Carlo method if $N$ is increased, but the point sets do not have minimal discrepancy. By using low-discrepancy sequences we aim for low discrepancy and no need for recomputations, but actually low-discrepancy sequences can only be incrementally good on discrepancy if we allow no recomputation.

:::

## Definition of discrepancy {#Definition_of_discrepancy}

The *discrepancy* of a set $P = \{x_1, \dots, x_N }\$ is defined, using [Niederreiter's](wikipedia://en/47275252) notation, as

$$D_N(P) = \sup_{B\in J} \left| \frac{A(B;P)}{N} - \lambda_s(B) \right|$$

where $\lambda_s$ is the $s$-dimensional [Lebesgue measure](wikipedia://en/18198), $A(B;P)$ is the number of points in $P$ that fall into $B$, and $J$ is the set of $s$-dimensional intervals or boxes of the form

$$\prod_{i=1}^s [a_i, b_i) = \{ \mathbf{x} \in \mathbf{R}^s : a_i \le x_i < b_i \} \,$$

where $0 \le a_i < b_i \le 1$.

The *star-discrepancy* $D^*_N(P)$ is defined similarly, except that the [supremum](wikipedia://en/39382) is taken over the set $J^*$ of rectangular boxes of the form

$$\prod_{i=1}^s [0, u_i)$$

where $u_i$ is in the half-open interval \[0, 1).

The two are related by

$$D^*_N \le D_N \le 2^s D^*_N . \,$$

*Note*: With these definitions, discrepancy represents the worst-case or maximum point density deviation of a uniform set. However, also other error measures are meaningful, leading to other definitions and variation measures. For instance, $L^2$-discrepancy or modified centered $L^2$-discrepancy are also used intensively to compare the quality of uniform point sets. Both are much easier to calculate for large $N$ and $s$.

::: {#o7 .statement cue=named-heading name="The Koksma–Hlawka inequality"}

## The Koksma–Hlawka inequality {#The_Koksma–Hlawka_inequality}

Let $\overline{I}^s$ be the $s$-dimensional [unit cube](wikipedia://en/407763), $\overline{I}^s = [0, 1] \times \cdots \times [0, 1]$. Let $f$ have [bounded variation](wikipedia://en/330673) $V(f)$ on $\overline{I}^s$ in the sense of [Hardy](wikipedia://en/87599) and Krause. Then for any $x_1, \ldots, x_N$ in $I^s = [0, 1)^s = [0, 1) \times \cdots \times [0, 1)$,

$$\left| \frac{1}{N} \sum_{i=1}^N f(x_i) - \int_{\bar I^s} f(u)\,du \right| \le V(f)\, D_N^* (x_1,\ldots,x_N).$$

The [Koksma](wikipedia://en/13283214)–[Hlawka](wikipedia://en/5442007) inequality is sharp in the following sense: For any point set $\{x_1,\ldots,x_N\}$ in $I^s$ and any $\varepsilon>0$, there is a function $f$ with bounded variation and $V(f) = 1$ such that

$$\left| \frac{1}{N} \sum_{i=1}^N f(x_i) - \int_{\bar I^s} f(u)\,du \right|>D_{N}^{*}(x_1,\ldots,x_N)-\varepsilon.$$

Therefore, the quality of a numerical integration rule depends only on the discrepancy $D^*_N(x_1,\ldots,x_N)$.

:::

::: {#o9 .statement cue=named-heading name="The formula of Hlawka–Zaremba"}

## The formula of Hlawka–Zaremba {#The_formula_of_Hlawka–Zaremba}

Let $D = \{1,2,\ldots,d\}$. For $\emptyset\neq u\subseteq D$ we write

$$dx_u := \prod_{j\in u} dx_j$$

and denote by $(x_u,1)$ the point obtained from *x* by replacing the coordinates not in *u* by $1$. Then

$$\frac{1}{N} \sum_{i=1}^N f(x_i) - \int_{\bar I^s} f(u)\,du= \sum_{\emptyset\neq u\subseteq D}(-1)^{|u|} \int_{[0,1]^{|u|}} \operatorname{disc}(x_u,1)\frac{\partial^{|u|}}{\partial x_u}f(x_u,1) \, dx_u,$$

where $\operatorname{disc}(z)= \frac{1}{N}\sum_{i=1}^N \prod_{j=1}^d 1_{[0,z_j)}(x_{i,j}) - \prod_{j=1}^d z_i$ is the discrepancy function.

:::

::: {#o11 .statement cue=named-heading name="The L2 version of the Koksma–Hlawka inequality"}

## The *L<sup>2</sup>* version of the Koksma–Hlawka inequality {#The_L2_version_of_the_Koksma–Hlawka_inequality}

Applying the [Cauchy–Schwarz inequality](wikipedia://en/38128) for integrals and sums to the Hlawka–Zaremba identity, we obtain an $L^2$ version of the Koksma–Hlawka inequality:

$$\left|\frac{1}{N} \sum_{i=1}^N f(x_i) - \int_{\bar I^s} f(u)\,du\right|\le \|f\|_d \operatorname{disc}_d (\{t_i\}),$$

where

$$\operatorname{disc}_d(\{t_i\})=\left(\sum_{\emptyset\neq u\subseteq D} \int_{[0,1]^{|u|}} \operatorname{disc}(x_u,1)^2 \, dx_u\right)^{1/2}$$

and

$$\|f\|_d = \left(\sum_{u\subseteq D} \int_{[0,1]^{|u|}} \left|\frac{\partial^{|u|}}{\partial x_u} f(x_u,1)\right|^2 dx_u\right)^{1/2}.$$

$L^2$ discrepancy has a high practical importance because fast explicit calculations are possible for a given point set. This way it is easy to create point set optimizers using $L^2$ discrepancy as criteria.

:::

::: {#o13 .statement cue=named-heading name="The Erdős–Turán–Koksma inequality"}

## The Erdős–Turán–Koksma inequality {#The_Erdős–Turán–Koksma_inequality}

It is computationally hard to find the exact value of the discrepancy of large point sets. The [Erdős](wikipedia://en/601284)–[Turán](https://en.wikipedia.org/wiki/Turán)–[Koksma](wikipedia://en/13283214) inequality provides an upper bound.

Let $x_1,\ldots,x_N$ be points in $I^s$ and $H$ be an arbitrary positive integer. Then

$$D_{N}^{*}(x_1,\ldots,x_N)\leq \left(\frac{3}{2}\right)^s \left( \frac{2}{H+1}+ \sum_{0<\|h\|_{\infty}\leq H}\frac{1}{r(h)} \left| \frac{1}{N} \sum_{n=1}^{N} e^{2\pi i\langle h,x_n\rangle} \right| \right)$$

where

$$r(h) = \prod_{i=1}^s\max\{1,|h_i|\}\quad\text{for}\quad h=(h_1,\ldots,h_s)\in\mathbb{Z}^s.$$

:::

::: {#o15 .statement kind=statement/conjecture cue=named-heading name="The main conjectures"}

## The main conjectures {#The_main_conjectures}

::: {#o16 .statement kind=statement/conjecture cue=inline-head name="Conjecture 1"}

**Conjecture 1.** There is a constant $c_s$ depending only on the dimension $s$, such that

$$D_{N}^{*}(x_1,\ldots,x_N)\geq c_s\frac{(\ln N)^{s-1}}{N}$$

for any finite point set ${x_1,\ldots,x_N}$.

:::

::: {#o17 .statement kind=statement/conjecture cue=inline-head name="Conjecture 2"}

**Conjecture 2.** There is a constant $c'_s$ depending only on :$s$, such that:$D_{N}^{*}(x_1,\ldots,x_N)\geq c'_s\frac{(\ln N)^{s}}{N}$

for infinite number of $N$ for any infinite sequence $x_1,x_2,x_3,\ldots$.

These conjectures are equivalent. They have been proved for $s \leq 2$ by [W. M. Schmidt](https://en.wikipedia.org/wiki/Wolfgang_M._Schmidt). In higher dimensions, the corresponding problem is still open. The best-known lower bounds are due to [Michael Lacey](wikipedia://en/6508239) and collaborators.

:::

:::

## Lower bounds {#Lower_bounds}

Let $s = 1$. Then

$$D_N^*(x_1,\ldots,x_N)\geq\frac{1}{2N}$$

for any finite point set $\{x_1, \dots, x_N }\$.

Let $s = 2$. [W. M. Schmidt](https://en.wikipedia.org/wiki/Wolfgang_M._Schmidt) proved that for any finite point set $\{x_1, \dots, x_N }\$,

$$D_N^*(x_1,\ldots,x_N)\geq C\frac{\log N}{N}$$

where

$$C = \max_{a\geq3}\frac{1}{16}\frac{a-2}{a\log a}=0.023335\dots.$$

For arbitrary dimensions $s > 1$, [K. F. Roth](wikipedia://en/787827) proved that

$$D_N^*(x_1,\ldots,x_N)\geq\frac{1}{2^{4s}}\frac{1}{((s-1)\log2)^\frac{s-1}{2}}\frac{\log^{\frac{s-1}{2}}N}{N}$$

for any finite point set $\{x_1, \dots, x_N }\$. Jozef Beck [^o19] established a double log improvement of this result in three dimensions. This was improved by D. Bilyk and [M. T. Lacey](wikipedia://en/6508239) to a power of a single logarithm. The best known bound for *s* > 2 is due D. Bilyk and [M. T. Lacey](wikipedia://en/6508239) and A. Vagharshakyan.[^o20] There exists a $t>0$ depending on *s* so that

$$D_N^*(x_1,\ldots,x_N)\geq t \frac{\log^{\frac{s-1}{2}+t}N}{N}$$

for any finite point set $\{x_1, \dots, x_N }\$.

A general lower bound on the average local discrepancy, $\sum_{i\leq N} |x_i-i/N|$, of the sequence $\{x_1, \dots, x_N }\$ in the unit interval can be computed using only the minimum gap size, $g_{\rm min}$, and the gap sizes above the average gap, $g_i>1/N$ [^o21],

$$\sum_{i\leq N} |x_i-i/N| \geq \frac{1}{4} \sum_{i=1}^{M}\frac{(g_i-g_{\rm min})^2}{1/N-g_{\rm min}} -\frac{M}{4}(1/N-g_{\rm min}) \, ,$$

where $M$ is the number of gaps larger than $1/N$.

## Construction of low-discrepancy sequences {#Construction_of_low-discrepancy_sequences}

Because any distribution of random numbers can be mapped onto a uniform distribution, and quasirandom numbers are mapped in the same way, this article only concerns generation of quasirandom numbers on a multidimensional uniform distribution.

There are constructions of sequences known such that

$$D_N^{*}(x_1,\ldots,x_N)\leq C\frac{(\ln N)^{s}}{N}.$$

where $C$ is a certain constant, depending on the sequence. After Conjecture 2, these sequences are believed to have the best possible order of convergence. Examples below are the [van der Corput sequence](https://en.wikipedia.org/wiki/Van_der_Corput_sequence), the [Halton sequences](wikipedia://en/631188), and the [Sobol’ sequences](wikipedia://en/1358959). One general limitation is that construction methods can usually only guarantee the order of convergence. Practically, low discrepancy can be only achieved if $N$ is large enough, and for large given s this minimum $N$ can be very large. This means running a Monte-Carlo analysis with e.g. $s=20$ variables and $N=1000$ points from a low-discrepancy sequence generator may offer only a very minor accuracy improvement .

### Random numbers {#Random_numbers}

Sequences of quasirandom numbers can be generated from random numbers by imposing a negative correlation on those random numbers. One way to do this is to start with a set of random numbers $r_i$ on $[0,0.5)$ and construct quasirandom numbers $s_i$ which are uniform on $[0,1)$ using:

$s_i = r_i$ for $i$ odd and $s_i = 0.5 + r_i$ for $i$ even.

A second way to do it with the starting random numbers is to construct a random walk with offset 0.5 as in:

$$s_i = s_{i-1} + 0.5+ r_i \pmod 1. \,$$

That is, take the previous quasirandom number, add 0.5 and the random number, and take the result [modulo](wikipedia://en/20087) 1.

For more than one dimension, [Latin squares](https://en.wikipedia.org/wiki/Latin_squares) of the appropriate dimension can be used to provide offsets to ensure that the whole domain is covered evenly.

### Additive recurrence {#Additive_recurrence}

For any irrational $\alpha$, the sequence

$$s_n = \{s_0 + n\alpha\}$$

has discrepancy tending to $1/N$. Note that the sequence can be defined recursively by

$$s_{n+1} = (s_n + \alpha)\bmod 1 \;.$$

A good value of $\alpha$ gives lower discrepancy than a sequence of independent uniform random numbers.

The discrepancy can be bounded by the [approximation exponent](https://en.wikipedia.org/wiki/Approximation_exponent) of $\alpha$. If the approximation exponent is $\mu$, then for any $\varepsilon>0$, the following bound holds:[^o25]

$$D_N((s_n)) = O_\varepsilon (N^{-1/(\mu-1)+\varepsilon}).$$

By the [Thue–Siegel–Roth theorem](https://en.wikipedia.org/wiki/Thue–Siegel–Roth_theorem), the approximation exponent of any irrational [algebraic number](wikipedia://en/1158) is 2, giving a bound of $N^{-1+\varepsilon}$ above.

The [recurrence relation](wikipedia://en/146806) above is similar to the recurrence relation used by a [linear congruential generator](wikipedia://en/45527), a poor-quality pseudorandom number generator:[^o26]

$$r_i = (a r_{i-1} + c) \bmod m$$

For the low discrepancy additive recurrence above, *a* and *m* are chosen to be 1. Note, however, that this will not generate independent random numbers, so should not be used for purposes requiring independence.

The value of $c$ with lowest discrepancy is the [fractional part](wikipedia://en/501532) of the [golden ratio](wikipedia://en/12386):[^o27]

$$c = \frac{\sqrt{5}-1}{2} = \varphi - 1 \approx 0.618034.$$

Another value that is nearly as good is the fractional part of the [silver ratio](wikipedia://en/920526), which is the fractional part of the [square root of 2](wikipedia://en/341682):

$$c = \sqrt{2}-1 \approx 0.414214. \,$$

In more than one dimension, separate quasirandom numbers are needed for each dimension. A convenient set of values that are used, is the square roots of [primes](https://en.wikipedia.org/wiki/Primes) from two up, all taken modulo 1:

$$c = \sqrt{2}, \sqrt{3}, \sqrt{5}, \sqrt{7}, \sqrt{11}, \ldots \,$$

However, a set of values based on the generalised golden ratio has been shown to produce more evenly distributed points. [^o28]

The [list of pseudorandom number generators](https://en.wikipedia.org/wiki/List_of_pseudorandom_number_generators) lists methods for generating independent pseudorandom numbers. *Note*: In few dimensions, recursive recurrence leads to uniform sets of good quality, but for larger $s$ (like $s>8$) other point set generators can offer much lower discrepancies.

### van der Corput sequence {#van_der_Corput_sequence}

Let

$$n=\sum_{k=0}^{L-1}d_k(n)b^k$$

be the $b$-ary representation of the positive integer $n \geq 1$, i.e. $0 \leq d_k(n) < b$. Set

$$g_b(n)=\sum_{k=0}^{L-1}d_k(n)b^{-k-1}.$$

Then there is a constant $C$ depending only on $b$ such that $(g_b(n))_{n \geq 1}$ satisfies

$$D^*_N(g_b(1),\dots,g_b(N))\leq C\frac{\log N}{N},$$

where $D^*_N$ is the **star discrepancy**.

### Halton sequence {#Halton_sequence}

*Image: Halton sequence 2D.svg.* First 256 points of the (2,3) Halton sequence

The Halton sequence is a natural generalization of the van der Corput sequence to higher dimensions. Let *s* be an arbitrary dimension and *b*<sub>1</sub>, ..., *b*<sub>*s*</sub> be arbitrary [coprime](https://en.wikipedia.org/wiki/Coprime) integers greater than 1. Define

$$x(n)=(g_{b_1}(n),\dots,g_{b_s}(n)).$$

Then there is a constant *C* depending only on *b*<sub>1</sub>, ..., *b*<sub>*s*</sub>, such that sequence {*x*(*n*)}<sub>*n*≥1</sub> is a *s*-dimensional sequence with

$$D^*_N(x(1),\dots,x(N))\leq C'\frac{(\log N)^s}{N}.$$

::: {#o32 .pointer-item cue=pointer name="Hammersley set"}

### Hammersley set {#Hammersley_set}

*Image: Hammersley set 2D.svg.* 2D Hammersley set of size 256

Let $b_1,\ldots,b_{s-1}$ be [coprime](https://en.wikipedia.org/wiki/Coprime) positive integers greater than 1. For given $s$ and $N$, the $s$-dimensional [Hammersley](wikipedia://en/656531) set of size $N$ is defined by[^o33]

$$x(n)=\left(g_{b_1}(n),\dots,g_{b_{s-1}}(n),\frac{n}{N}\right)$$

for $n = 1, \ldots, N$. Then

$$D^*_N(x(1),\dots,x(N))\leq C\frac{(\log N)^{s-1}}{N}$$

where $C$ is a constant depending only on $b_1, \ldots, b_{s-1}$.

*Note*: The formulas show that the Hammersley set is actually the Halton sequence, but we get one more dimension for free by adding a linear sweep. This is only possible if $N$ is known upfront. A linear set is also the set with lowest possible one-dimensional discrepancy in general. Unfortunately, for higher dimensions, no such "discrepancy record sets" are known. For $s=2$, most low-discrepancy point set generators deliver at least near-optimum discrepancies.

:::

### Sobol sequence {#Sobol_sequence}

The Antonov–Saleev variant of the Sobol’ sequence generates numbers between zero and one directly as binary fractions of length $w,$ from a set of $w$ special binary fractions, $V_i, i = 1, 2, \dots, w$ called direction numbers. The bits of the [Gray code](wikipedia://en/50564) of $i$, $G(i)$, are used to select direction numbers. To get the Sobol’ sequence value $s_i$ take the [exclusive or](wikipedia://en/105979) of the binary value of the Gray code of $i$ with the appropriate direction number. The number of dimensions required affects the choice of $V_i$.

### Poisson disk sampling {#Poisson_disk_sampling}

[Poisson disk sampling](https://en.wikipedia.org/wiki/Supersampling#Poisson_disk) is popular in video games to rapidly place objects in a way that appears random-looking but guarantees that every two points are separated by at least the specified minimum distance.[^o36] This does not guarantee low discrepancy (as e. g. Sobol’), but at least a significantly lower discrepancy than pure random sampling. The goal of these sampling patterns is based on [frequency analysis](wikipedia://en/157934) rather than discrepancy, a type of so-called "blue noise" patterns.
