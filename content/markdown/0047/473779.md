# Injective object

::: {#o1 .subject cue=lead name="Injective object"}

In [mathematics](wikipedia://en/18831), especially in the field of [category theory](wikipedia://en/5869), the concept of **injective object**[^o2] is a generalization of the concept of [injective module](wikipedia://en/473775). This concept is important in [cohomology](wikipedia://en/194060), in [homotopy theory](wikipedia://en/61994831) and in the theory of [model categories](wikipedia://en/2895304). The dual notion is that of a [projective object](wikipedia://en/3017382).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Diagrammadefinizionemoduloiniettivo.png.* An object $Q$ is injective if, given a monomorphism $f$ : $X$ → $Y$, any $g$ : $X$ → $Q$ can be extended to $Y$.

An [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29) $Q$ in a [category](wikipedia://en/53759) $\mathbf{C}$ is said to be **injective** if for every [monomorphism](wikipedia://en/59538) $f: X \to Y$ and every [morphism](wikipedia://en/27716891) $g: X \to Q$ there exists a morphism $h: Y \to Q$ extending $g$ to $Y$, i.e. such that $h \circ f = g$.[^o5]

That is, every morphism $X \to Q$ factors through every monomorphism $X \hookrightarrow Y$.

The morphism $h$ in the above definition is not required to be uniquely determined by $f$ and $g$.

In a [locally small](wikipedia://en/53759#Small_and_large_categories) category, it is equivalent to require that the [hom functor](wikipedia://en/2741037) $\operatorname{Hom}_{\mathbf{C}}(-,Q)$ carries monomorphisms in $\mathbf{C}$ to [surjective](https://en.wikipedia.org/wiki/Surjective) set maps.

:::

## In Abelian categories {#In_Abelian_categories}

The notion of injectivity was first formulated for [abelian categories](wikipedia://en/45063), and this is still one of its primary areas of application. When $\mathbf{C}$ is an abelian category, an object *Q* of $\mathbf{C}$ is injective [if and only if](wikipedia://en/14922) its [hom functor](wikipedia://en/2741037) Hom<sub>**C**</sub>(–,*Q*) is [exact](wikipedia://en/453945).

If $0 \to Q \to U \to V \to 0$ is an [exact sequence](wikipedia://en/138215) in $\mathbf{C}$ such that *Q* is injective, then the [sequence splits](wikipedia://en/138378).

::: {#o8 .pointer-item cue=pointer name="Enough injectives"}

## Enough injectives and injective hulls {#Enough_injectives_and_injective_hulls}

The category $\mathbf{C}$ is said to *have enough injectives* if for every object *X* of $\mathbf{C}$, there exists a monomorphism from *X* to an injective object.

A monomorphism *g* in $\mathbf{C}$ is called an [essential monomorphism](wikipedia://en/47451366) if for any morphism *f*, the composite *fg* is a monomorphism only if *f* is a monomorphism.

If *g* is an essential monomorphism with domain *X* and an injective codomain *G*, then *G* is called an **injective hull** of *X*. The injective hull is then uniquely determined by *X* [up to](wikipedia://en/44787) a non-canonical isomorphism.[^o5]

:::

::: {#o10 .example cue=heading name="Examples"}

## Examples {#Examples}

- In the category of [abelian groups](wikipedia://en/2974) and [group homomorphisms](wikipedia://en/12396), **Ab**, an injective object is necessarily a [divisible group](wikipedia://en/472147). Assuming the axiom of choice, the notions are equivalent.
- In the category of (left) [modules](wikipedia://en/276410) and [module homomorphisms](wikipedia://en/474118), *R*-**Mod**, an injective object is an [injective module](wikipedia://en/473775). *R*-**Mod** has [injective hulls](wikipedia://en/665821) (as a consequence, *R*-**Mod** has enough injectives).
- In the [category of metric spaces](wikipedia://en/535617), **Met**, an injective object is an [injective metric space](wikipedia://en/7840768), and the injective hull of a metric space is its [tight span](https://en.wikipedia.org/wiki/Tight_span).
- In the category of [T<sub>0</sub> spaces](https://en.wikipedia.org/wiki/T0_space) and [continuous mappings](https://en.wikipedia.org/wiki/Continuous_mapping), an injective object is always a [Scott topology](https://en.wikipedia.org/wiki/Scott_topology) on a [continuous lattice](https://en.wikipedia.org/wiki/Continuous_lattice), and therefore it is always [sober](wikipedia://en/602490) and [locally compact](https://en.wikipedia.org/wiki/Locally_compact).

:::

::: {#o12 .application cue=heading name="Uses"}

## Uses {#Uses}

If an abelian category has enough injectives, we can form [injective resolutions](https://en.wikipedia.org/wiki/Injective_resolution), i.e. for a given object *X* we can form a long exact sequence

$$0\to X \to Q^0 \to Q^1 \to Q^2 \to \cdots$$

and one can then define the [derived functors](wikipedia://en/433875) of a given functor *F* by applying *F* to this sequence and computing the homology of the resulting (not necessarily exact) sequence. This approach is used to define [Ext](wikipedia://en/840758), and [Tor](wikipedia://en/856347) functors and also the various [cohomology](wikipedia://en/194060) theories in [group theory](wikipedia://en/41890), [algebraic topology](wikipedia://en/38801) and [algebraic geometry](wikipedia://en/1997). The categories being used are typically [functor categories](wikipedia://en/407039) or categories of [sheaves of *O*<sub>*X*</sub> modules](wikipedia://en/44887605) over some [ringed space](wikipedia://en/248014) (*X*, *O*<sub>*X*</sub>) or, more generally, any [Grothendieck category](wikipedia://en/30051538).

:::

::: {#o14 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

*Image: Injective object.svg.* An object $Q$ is $H$-injective if, given $h$ : $A$ → $B$ in $H$, any $f$ : $A$ → $Q$ [factors through](https://en.wikipedia.org/wiki/List_of_mathematical_jargon#factor_through) $h$.

Let $\mathbf{C}$ be a category and let $\mathcal{H}$ be a [class](wikipedia://en/20696) of morphisms of $\mathbf{C}$.

An object $Q$ of $\mathbf{C}$ is said to be ***$\mathcal{H}$*-injective** if for every morphism $f: A \to Q$ and every morphism $h: A \to B$ in $\mathcal{H}$ there exists a morphism $g: B \to Q$ with $g \circ h = f$.

If $\mathcal{H}$ is the class of [monomorphisms](wikipedia://en/59538), we are back to the injective objects that were treated above.

The category $\mathbf{C}$ is said to *have enough $\mathcal{H}$-injectives* if for every object *X* of $\mathbf{C}$, there exists an *$\mathcal{H}$*-morphism from *X* to an *$\mathcal{H}$*-injective object.

A *$\mathcal{H}$*-morphism *g* in $\mathbf{C}$ is called ***$\mathcal{H}$*-essential** if for any morphism *f*, the composite *fg* is in *$\mathcal{H}$* only if *f* is in *$\mathcal{H}$*.

If *g* is a *$\mathcal{H}$*-essential morphism with domain *X* and an *$\mathcal{H}$*-injective codomain *G*, then *G* is called an **$\mathcal{H}$-injective hull** of *X*.[^o5]

### Examples of $H$-injective objects {#Examples_of_-injective_objects}

- In the category of [simplicial sets](wikipedia://en/1027784), the injective objects with respect to the class *$\mathcal{H}$* of anodyne extensions are [Kan complexes](https://en.wikipedia.org/wiki/Kan_complex).
- In the category of [partially ordered sets](wikipedia://en/23572) and [monotone maps](https://en.wikipedia.org/wiki/Monotone_map), the [complete lattices](wikipedia://en/44777) form the injective objects for the class *$\mathcal{H}$* of [order-embeddings](https://en.wikipedia.org/wiki/Order-embedding), and the [Dedekind–MacNeille completion](wikipedia://en/16667323) of a partially ordered set is its *$\mathcal{H}$*-injective hull.
