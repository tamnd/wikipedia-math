# Aitken interpolation

::: {#o1 .subject cue=lead name="Aitken interpolation"}

**Aitken interpolation** is an algorithm used for [polynomial interpolation](wikipedia://en/203565) that was derived by the mathematician [Alexander Aitken](wikipedia://en/3348690). It is similar to [Neville's algorithm](wikipedia://en/5141960).

:::

See also [Aitken's delta-squared process](wikipedia://en/7411694) or [Aitken extrapolation](https://en.wikipedia.org/wiki/Aitken_extrapolation).
