# Bregman method

::: {#o1 .subject cue=lead name="Bregman method"}

The **Bregman method** is an [iterative algorithm](https://en.wikipedia.org/wiki/Iterative_algorithm) to solve certain [convex optimization](wikipedia://en/1674411) problems involving [regularization](wikipedia://en/2009061).[^o2] The original version is due to [Lev M. Bregman](wikipedia://en/39180704), who published it in 1967.[^o3]

:::

The algorithm is a [row-action method](https://en.wikipedia.org/wiki/Row-action_method) accessing [constraint functions](https://en.wikipedia.org/wiki/Constraint_function) one by one and the method is particularly suited for large optimization problems where constraints can be efficiently enumerated. The algorithm works particularly well for [regularizers](wikipedia://en/2009061) such as the $\ell_1$ norm, where it converges very quickly because of an error-cancellation effect.[^o4]

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

In order to be able to use the Bregman method, one must frame the problem of interest as finding $\min_u J(u) + f(u)$, where $J$ is a regularizing function such as $\ell_1$.[^o4]

The *Bregman distance* is defined as $D^p(u, v) := J(u) - (J(v) + \langle p, u - v\rangle)$ where $p$ belongs to the [subdifferential](wikipedia://en/3462862) of $J$ at $u$ (which we denoted $\partial J(u)$).[^o4][^o7] One performs the iteration $u_{k + 1}:= \min_u(\alpha D(u, u_k) + f(u))$, with $\alpha$ a constant to be chosen by the user (and the minimization performed by an ordinary convex optimization algorithm),[^o4] or $u_{k + 1}:= \min_u(D^{p_k}(u, u_k) + f(u))$, with $p_k$ chosen each time to be a member of $\partial J(u_k)$.[^o7]

The algorithm starts with a pair of primal and dual variables. Then, for each constraint a [generalized projection](wikipedia://en/4491248) onto its feasible set is performed, updating both the constraint's dual variable and all primal variables for which there are non-zero coefficients in the constraint functions gradient. In case the objective is strictly convex and all constraint functions are convex, the limit of this iterative projection converges to the optimal primal dual pair.

In the case of a [basis pursuit](wikipedia://en/29276125)-type problem $\min_{x: Ax = b}(|x|_1 + \frac{1}{2\alpha}|x|_2^2)$, the Bregman method is equivalent to ordinary [gradient descent](wikipedia://en/201489) on the dual problem $\min_y (-b^t y + \frac{\alpha}{2}|A^t y - \text{Proj}_{[-1, 1]^n}(A^t y)|^2)$.[^o8] An exact regularization-type effect also occurs in this case; if $\alpha$ exceeds a certain threshold, the optimum value of $x$ is precisely the optimum solution of $\min_{x: Ax = b}|x|_1$.[^o4][^o8]

:::

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

The Bregman method or its generalizations can be applied to:

- [Image deblurring](https://en.wikipedia.org/wiki/Image_deblurring) or [denoising](https://en.wikipedia.org/wiki/Image_denoising)[^o4] (including [total variation denoising](wikipedia://en/26792343)[^o7])
- MR image reconstruction[^o4]
- [Magnetic resonance imaging](https://en.wikipedia.org/wiki/Magnetic_resonance_imaging)[^o2][^o11]
- [Radar](https://en.wikipedia.org/wiki/Radar)[^o2]
- [Hyperspectral imaging](https://en.wikipedia.org/wiki/Hyperspectral_image)[^o16]
- [Compressed sensing](wikipedia://en/11403316)[^o8]
- [Least absolute deviations](wikipedia://en/19048902) or $\ell_1$-regularized linear regression[^o12]
- Covariance selection (learning a sparse covariance matrix)[^o12]
- [Matrix completion](wikipedia://en/35683165)[^o13]
- [Structural risk minimization](https://en.wikipedia.org/wiki/Structural_risk_minimization)[^o12]

:::

## Generalizations and drawbacks {#Generalizations_and_drawbacks}

The method has links to the [method of multipliers](https://en.wikipedia.org/wiki/Method_of_multipliers) and [dual ascent method](https://en.wikipedia.org/wiki/Dual_ascent_method) (through the so-called *Bregman alternating direction method of multipliers*,[^o15][^o16] generalizing the *alternating direction method of multipliers*[^o12]) and multiple generalizations exist.

One drawback of the method is that it is only provably convergent if the objective function is *strictly* convex. In case this can not be ensured, as for [linear programs](https://en.wikipedia.org/wiki/Linear_program) or non-strictly convex quadratic programs, additional methods such as [proximal gradient methods](wikipedia://en/39587805) have been developed. In the case of the [Rudin-Osher-Fatemi model](wikipedia://en/26792343#Rudin–Osher–Fatemi_PDE) of image denoising, the Bregman method provably converges.[^o17]

Some generalizations of the Bregman method include:

- Inverse [scale space](https://en.wikipedia.org/wiki/Scale_space) method[^o4]
- Linearized Bregman[^o4]
- Logistic Bregman[^o4]
- Split Bregman[^o4]

### Linearized Bregman {#Linearized_Bregman}

In the Linearized Bregman method, one linearizes the intermediate objective functions $D^p(u, u_k) + f(u)$ by replacing the second term with $f(u_k) + \langle f'(u_k), u - u_k\rangle$ (which approximates the second term near $u_k$) and adding the penalty term $\frac{1}{2\delta}|u - u_k|_2^2$ for a constant $\delta$. The result is much more computationally tractable, especially in [basis pursuit](wikipedia://en/29276125)-type problems.[^o7][^o8] In the case of a generic basis pursuit problem $\min \mu|u|_1 + \frac{1}{2}|Au - f|_2^2$, one can express the iteration as $v_{k + 1} := v_k + A^t(f - Au_k), u_{k + 1, i} := \delta~\text{shrink}(v_{k, i}, \mu)$ for each component $i$, where we define $\text{shrink}(y, a) := \begin{cases} y - a, & y\in(a,\infty) \\ 0, &y\in[-a, a]\\ y + a, & y\in(-\infty, -a) \end{cases}$.[^o7]

Sometimes, when running the Linearized Bregman method, there are periods of "stagnation" where the residual is almost constant. To alleviate this issue, one can use the Linearized Bregman method with *kicking*, where one essentially detects the beginning of a stagnation period, then predicts and skips to the end of it.[^o7][^o8]

Since Linearized Bregman is mathematically equivalent to gradient descent, it can be accelerated with methods to accelerate gradient descent, such as [line search](wikipedia://en/1537058), [L-BGFS](https://en.wikipedia.org/wiki/Limited-memory_BFGS), [Barzilai-Borwein](https://en.wikipedia.org/wiki/Barzilai-Borwein_method) steps, or the [Nesterov method](https://en.wikipedia.org/wiki/Nesterov_method); the last has been proposed as the *accelerated linearized Bregman method*.[^o8][^o13]

### Split Bregman {#Split_Bregman}

The Split Bregman method solves problems of the form $\min_u |\Phi(u)|_1 + H(u)$, where $\Phi$ and $H$ are both convex,[^o7] particularly problems of the form $\min_u |\Phi u|_1 + |Ku - f|^2$.[^o11] We start by rewriting it as the [constrained optimization](wikipedia://en/4171950) problem $\min_{u: d = \Phi(u)} |d|_1 + H(u)$, then relax it into $\min_{u, d} |d|_1 + H(u) + \frac{\lambda}{2}|d - \Phi(u)|_2^2$ where $\lambda$ is a constant. By defining $J(u, d) := |d| + H(u)$, one reduces the problem to one that can be solved with the ordinary Bregman algorithm.[^o7][^o11]

The Split Bregman method has been generalized to optimization over [complex numbers](wikipedia://en/5826) using [Wirtinger derivatives](wikipedia://en/28479408).[^o2]
