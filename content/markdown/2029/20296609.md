# XYZ inequality

::: {#o1 .subject cue=lead name="XYZ inequality"}

In [combinatorial](wikipedia://en/5170) mathematics, the **XYZ inequality**, also called the **Fishburn–Shepp inequality**, is an inequality for the number of [linear extensions](wikipedia://en/11726298) of finite [partial orders](https://en.wikipedia.org/wiki/Partial_order). The inequality was conjectured by [Ivan Rival](wikipedia://en/28784080) and Bill Sands in 1981. It was proved by [Lawrence Shepp](https://en.wikipedia.org/wiki/Lawrence_Shepp) in (Shepp 1982). An extension was given by [Peter Fishburn](wikipedia://en/1787186) in (Fishburn 1984).

:::

It states that if *x*, *y*, and *z* are incomparable elements of a finite [poset](https://en.wikipedia.org/wiki/Poset), then

$$P(x\prec y)P(x\prec z) \leqslant P((x\prec y) \wedge (x\prec z)),$$

where *P*(A) is the probability that a linear order extending the partial order $\prec$ has the property A.

In other words, the probability that $x\prec z$ increases if one adds the condition that $x\prec y$. In the language of [conditional probability](wikipedia://en/24104134),

$$P(x \prec z) \leqslant P(x \prec z \mid x \prec y).$$

The proof uses the [Ahlswede–Daykin inequality](wikipedia://en/20295062).
