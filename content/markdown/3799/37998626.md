# Subadditive set function

::: {#o1 .subject cue=lead name="Subadditive set function"}

In mathematics, a **subadditive set function** is a [set function](wikipedia://en/25911217) whose value, informally, has the property that the value of function on the union of two sets is at most the sum of values of the function on each of the sets. This is thematically related to the [subadditivity](wikipedia://en/745789) property of real-valued functions.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\Omega$ be a [set](wikipedia://en/26691) and $f \colon 2^{\Omega} \rightarrow \mathbb{R}$ be a [set function](wikipedia://en/25911217), where $2^\Omega$ denotes the [power set](wikipedia://en/23799#Representing_subsets_as_functions) of $\Omega$. The function *f* is *subadditive* if for each subset $S$ and $T$ of $\Omega$, we have $f(S) + f(T) \geq f(S \cup T)$.[^o7][^o8] Note that by substitution of $T=S$ into the defining equation, it follows that $f(S) \ge 0$ for all $S$.

:::

## Examples of subadditive functions {#Examples_of_subadditive_functions}

*Image: Principle of sigma-subadditivity.svg.* Everyday example of sigma sub-additivity: when sand is mixed with water, the [bulk volume](https://en.wikipedia.org/wiki/Bulk_volume) of the mixture is smaller than the sum of the individual volumes, as the water can lodge in the spaces between the sand grains. A similar situation with a different mechanism occurs when ethanol is mixed with water, see [apparent molar property](https://en.wikipedia.org/wiki/Apparent_molar_property).

Every non-negative [submodular set function](wikipedia://en/33273315) is subadditive (the family of non-negative submodular functions is strictly contained in the family of subadditive functions).

The function that counts the number of sets required to [cover](https://en.wikipedia.org/wiki/Set_cover) a given set is subadditive. Let $T_1, \dotsc, T_m \subseteq \Omega$ such that $\cup_{i=1}^m T_i=\Omega$. Define $f$ as the minimum number of subsets required to cover a given set. Formally, $f(S)$ is the minimum number $t$ such that there are sets $T_{i_1}, \dotsc, T_{i_t}$ satisfying $S\subseteq \cup_{j=1}^t T_{i_j}$. Then $f$ is subadditive.

The [maximum](https://en.wikipedia.org/wiki/Maximum) of [additive set functions](wikipedia://en/22473529) is subadditive (dually, the [minimum](https://en.wikipedia.org/wiki/Minimum) of additive functions is [superadditive](https://en.wikipedia.org/wiki/Superadditive)). Formally, for each $i \in \{1, \dotsc, m\}$, let $a_i \colon \Omega \to \mathbb{R}$ be additive set functions. Then $f(S)=\max_{i} a_i(S)$ is a subadditive set function.

Fractionally subadditive set functions are a generalization of submodular functions and a special case of subadditive functions. A subadditive function $f$ is furthermore fractionally subadditive if it satisfies the following definition.[^o7] For every $S \subseteq \Omega$, every $X_1, \dotsc, X_n \subseteq \Omega$, and every $\alpha_1, \dotsc, \alpha_n \in [0, 1]$, if $1_S \leq \sum_{i=1}^n \alpha_i 1_{X_i}$, then $f(S) \leq \sum_{i=1}^n \alpha_i f(X_i)$. The set of fractionally subadditive functions equals the set of functions that can be expressed as the maximum of additive functions, as in the example in the previous paragraph.[^o7]
