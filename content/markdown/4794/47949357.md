# Karma Police (surveillance programme)

::: {#o1 .subject cue=lead name="Karma Police"}

*Image: GCHQ-aerial.jpg.* An aerial image of the Government Communications Headquarters (GCHQ) in Cheltenham, Gloucestershire.

**Karma Police** (usually capitalised as **KARMA POLICE**) is the [code name](https://en.wikipedia.org/wiki/Code_name) for an Internet [mass surveillance](https://en.wikipedia.org/wiki/Mass_surveillance) and data collection programme operated by the [United Kingdom](https://en.wikipedia.org/wiki/United_Kingdom)'s [Government Communications Headquarters](https://en.wikipedia.org/wiki/Government_Communications_Headquarters) (GCHQ).

:::

In 2015, documents obtained by *[The Intercept](https://en.wikipedia.org/wiki/The_Intercept)* from U.S. [National Security Agency](wikipedia://en/21939) whistleblower [Edward Snowden](https://en.wikipedia.org/wiki/Edward_Snowden) revealed that GCHQ had carried out the KARMA POLICE operation since about 2008.[^o2] The KARMA POLICE operation swept up the [IP address](https://en.wikipedia.org/wiki/Internet_Protocol_address) of Internet users visiting websites. The program was established with no public scrutiny or oversight. KARMA POLICE is a powerful spying tool in conjunction with other GCHQ programs, because IP addresses could be cross-referenced with other data.[^o2] The goal of the program, according to the documents, was "either (a) a web browsing profile for every visible user on the internet, or (b) a user profile for every visible website on the internet."[^o2]

Karma Police was apparently named after the [Radiohead](https://en.wikipedia.org/wiki/Radiohead) song "[Karma Police](https://en.wikipedia.org/wiki/Karma_Police)", which includes the lyric "This is what you’ll get when you mess with us".[^o2][^o3]
