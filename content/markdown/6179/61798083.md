# Lepage test

::: {#o1 .subject cue=lead name="Lepage test"}

In statistics, the **Lepage test** is an exact distribution-free test ([nonparametric test](https://en.wikipedia.org/wiki/Nonparametric_test)) for jointly monitoring the location ([central tendency](https://en.wikipedia.org/wiki/Central_tendency)) and scale ([variability](https://en.wikipedia.org/wiki/Statistical_variability)) in two-sample treatment versus control comparisons. It is a [rank test](https://en.wikipedia.org/wiki/Rank_test) for the [two-sample location-scale problem](https://en.wikipedia.org/wiki/Two-sample_location-scale_problem). The Lepage test statistic is the squared [Euclidean distance](wikipedia://en/53932) of the standardized [Wilcoxon rank-sum](https://en.wikipedia.org/wiki/Wilcoxon_rank-sum) test for location and the standardized [Ansari–Bradley test](https://en.wikipedia.org/wiki/Ansari–Bradley_test) for scale. The Lepage test was first introduced by [Yves Lepage](https://en.wikipedia.org/wiki/Yves_Lepage) in 1971 in a paper in *Biometrika*.[^o2] A large number of Lepage-type tests exists in statistical literature for simultaneously testing location and scale shifts in case-control studies. The details may be found in the book: *Nonparametric statistical tests: A computational approach*.[^o3] Wolfgang Kössler[^o4] in 2006 also introduced various Lepage type tests using some alternative score functions optimal for various distributions. Amitava Mukherjee and Marco Marozzi introduced a class of percentile modified versions of the Lepage test.[^o5] An alternative to the Lepage-type tests is known as the [Cucconi test](wikipedia://en/52595978) proposed by Odoardo Cucconi in 1968.[^o6]

:::

## Conducting the Lepage test with R {#Conducting_the_Lepage_test_with_R}

Practitioners can apply the Lepage test using the pLepage function of the contributory package NSM3,[^o8] built under [R software](wikipedia://en/376707). Andreas Schulz and Markus Neuhäuser also provided detailed R code for computation of test statistic and p-value of the Lepage test[^o9] for the users.

## Application in statistical process monitoring {#Application_in_statistical_process_monitoring}

In recent years, the Lepage statistic is a widely used statistical process for monitoring and quality control. In 2012, Amitava Mukherjee and Subhabrata Chakraborti introduced a distribution-free [Shewhart](wikipedia://en/433679)-type Phase-II monitoring scheme[^o11] ([control chart](wikipedia://en/435754)) for simultaneously monitoring of location and scale parameter of a process using a test sample of fixed size, when a reference sample of sufficiently large size is available from an in-control population. Later in 2015, the same statisticians along with Shovan Chowdhury, proposed a distribution-free [CUSUM](wikipedia://en/15191637)-type Phase-II monitoring scheme[^o12] based on the Lepage statistic. In 2017, Mukherjee further designed an EWMA-type distribution-free Phase-II monitoring scheme[^o13] for joint monitoring of location and scale. In the same year, Mukherjee, with Marco Marozzi, known for promoting the Cucconi test, came together to design the Circular-Grid Lepage chart – a new type of joint monitoring scheme.[^o14]

## Multisample version of the Lepage test {#Multisample_version_of_the_Lepage_test}

In 2005, František Rublìk introduced the multisample version of the original two-sample Lepage test.[^o16]
