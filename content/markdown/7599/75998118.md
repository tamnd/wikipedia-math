# Giry monad

::: {#o1 .subject cue=lead name="Giry monad"}

In [mathematics](wikipedia://en/18831), the **Giry monad** is a construction that assigns to a [measurable space](wikipedia://en/43333) a space of [probability measures](wikipedia://en/45437) over it, equipped with a canonical [sigma-algebra](https://en.wikipedia.org/wiki/Sigma-algebra).[^o2][^o3][^o4][^o5][^o6] It is one of the main examples of a [probability monad](https://en.wikipedia.org/wiki/Probability_monad).

:::

It is implicitly used in [probability theory](wikipedia://en/23542) whenever one considers [probability measures](wikipedia://en/45437) which depend [measurably](wikipedia://en/44055) on a parameter (giving rise to [Markov kernels](wikipedia://en/21180014)), or when one has *probability measures over probability measures* (such as in [de Finetti's theorem](wikipedia://en/180835)).

Like many iterable constructions, it has the [category-theoretic](wikipedia://en/5869) structure of a [monad](wikipedia://en/355140), on the [category of measurable spaces](wikipedia://en/75966255).

::: {#o8 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

The Giry monad, like every [monad](wikipedia://en/355140), consists of three structures:[^o9][^o10][^o11]

- A [functorial](wikipedia://en/10987) assignment, which in this case assigns to a measurable space $X$ a space of probability measures $PX$ over it;
- A [natural map](wikipedia://en/45022) $\delta_X:X\to PX$ called the *unit*, which in this case assigns to each element of a space the [Dirac measure](wikipedia://en/1019002) over it;
- A [natural map](wikipedia://en/45022) $\mathcal{E}_X:PPX\to PX$ called the *multiplication*, which in this case assigns to each *probability measure over probability measures* its [expected value](wikipedia://en/9653).

### The space of probability measures {#The_space_of_probability_measures}

Let $(X, \mathcal{F})$ be a [measurable space](wikipedia://en/43333). Denote by $PX$ the set of [probability measures](wikipedia://en/45437) over $(X, \mathcal{F})$. We equip the set $PX$ with a [sigma-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) as follows. First of all, for every measurable set $A\in \mathcal{F}$, define the map $\varepsilon_A:PX\to\mathbb{R}$ by $p\longmapsto p(A)$. We then define the sigma algebra $\mathcal{PF}$ on $PX$ to be the smallest sigma-algebra which makes the maps $\varepsilon_A$ measurable, for all $A\in\mathcal{F}$ (where $\mathbb{R}$ is assumed equipped with the [Borel sigma-algebra](https://en.wikipedia.org/wiki/Borel_sigma-algebra)). [^o9]

Equivalently, $\mathcal{PF}$ can be defined as the smallest sigma-algebra on $PX$ which makes the maps

$$p\longmapsto\int_X f \,dp$$

measurable for all bounded measurable $f:X\to\mathbb{R}$.[^o13]

The assignment $(X,\mathcal{F})\mapsto (PX,\mathcal {PF})$ is part of an [endofunctor](https://en.wikipedia.org/wiki/Endofunctor) on the [category of measurable spaces](wikipedia://en/75966255), usually denoted again by $P$. Its action on [morphisms](https://en.wikipedia.org/wiki/Morphisms), i.e. on [measurable maps](https://en.wikipedia.org/wiki/Measurable_map), is via the [pushforward of measures](wikipedia://en/9412979). Namely, given a measurable map $f:(X,\mathcal{F})\to(Y,\mathcal{G})$, one assigns to $f$ the map $f_*:(PX,\mathcal {PF})\to(PY,\mathcal {PG})$ defined by

$$f_*p\,(B)=p(f^{-1}(B))$$

for all $p\in PX$ and all measurable sets $B\in\mathcal{G}$. [^o9]

### The Dirac delta map {#The_Dirac_delta_map}

Given a measurable space $(X,\mathcal{F})$, the map $\delta:(X,\mathcal{F})\to(PX,\mathcal{PF})$ maps an element $x\in X$ to the [Dirac measure](wikipedia://en/1019002) $\delta_x\in PX$, defined on measurable subsets $A\in\mathcal{F}$ by[^o9]

$$\delta_x(A) = 1_A(x) = \begin{cases} 1 & \text{if }x\in A, \\ 0 & \text{if }x\notin A. \end{cases}$$

### The expectation map {#The_expectation_map}

Let $\mu\in PPX$, i.e. a probability measure over the probability measures over $(X,\mathcal{F})$. We define the probability measure $\mathcal{E}\mu\in PX$ by

$$\mathcal{E}\mu(A) = \int_{PX} p(A)\,\mu(dp)$$

for all measurable $A\in\mathcal{F}$. This gives a measurable, [natural](wikipedia://en/45022) map $\mathcal{E}:(PPX,\mathcal{PPF})\to(PX,\mathcal{PF})$.[^o9]

#### Example: mixture distributions {#Example:_mixture_distributions}

A [mixture distribution](wikipedia://en/708242), or more generally a [compound distribution](https://en.wikipedia.org/wiki/Compound_distribution), can be seen as an application of the map $\mathcal{E}$. Let's see this for the case of a finite mixture. Let $p_1,\dots,p_n$ be probability measures on $(X,\mathcal{F})$, and consider the probability measure $q$ given by the mixture

$$q(A) = \sum_{i=1}^n w_i\,p_i(A)$$

for all measurable $A\in\mathcal{F}$, for some weights $w_i\ge 0$ satisfying $w_1+\dots+w_n=1$. We can view the mixture $q$ as the average $q=\mathcal{E}\mu$, where the measure on measures $\mu\in PPX$, which in this case is discrete, is given by

$$\mu = \sum_{i=1}^n w_i\,\delta_{p_i} .$$

More generally, the map $\mathcal{E}:PPX\to PX$ can be seen as the most general, non-parametric way to form arbitrary [mixture](wikipedia://en/708242) or [compound distributions](https://en.wikipedia.org/wiki/Compound_distribution).

The triple $(P,\delta,\mathcal{E})$ is called the **Giry monad**.[^o2][^o3][^o4][^o5][^o6]

:::

## Relationship with Markov kernels {#Relationship_with_Markov_kernels}

One of the properties of the [sigma-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) $\mathcal{PF}$ is that given [measurable spaces](wikipedia://en/43333) $(X,\mathcal{F})$ and $(Y,\mathcal{G})$, we have a [bijective correspondence](wikipedia://en/3942) between [measurable functions](wikipedia://en/44055) $(X,\mathcal{F})\to(PY,\mathcal{PG})$ and [Markov kernels](wikipedia://en/21180014) $(X,\mathcal{F})\to(Y,\mathcal{G})$. This allows to view a Markov kernel, equivalently, as a measurably parametrized probability measure.[^o18]

In more detail, given a measurable function $f:(X,\mathcal{F})\to(PY,\mathcal{PG})$, one can obtain the Markov kernel $f^\flat:(X,\mathcal{F})\to(Y,\mathcal{G})$ as follows,

$$f^\flat(B|x) = f(x)(B)$$

for every $x\in X$ and every measurable $B\in\mathcal{G}$ (note that $f(x)\in PY$ is a probability measure). Conversely, given a Markov kernel $k:(X,\mathcal{F})\to(Y,\mathcal{G})$, one can form the measurable function $k^\sharp:(X,\mathcal{F})\to(PY,\mathcal{PG})$ mapping $x\in X$ to the probability measure $k^\sharp(x)\in PY$ defined by

$$k^\sharp(x)(B) = k(B|x)$$

for every measurable $B\in\mathcal{G}$. The two assignments are mutually inverse.

From the point of view of [category theory](wikipedia://en/5869), we can interpret this correspondence as an [adjunction](https://en.wikipedia.org/wiki/Adjunction_%28category_theory%29)

$$\mathrm{Hom}_\mathrm{Meas} (X,PY) \cong \mathrm{Hom}_\mathrm{Stoch} (X,Y)$$

between the [category of measurable spaces](wikipedia://en/75966255) and the [category of Markov kernels](wikipedia://en/75969668). In particular, the category of Markov kernels can be seen as the [Kleisli category](wikipedia://en/3957200) of the Giry monad.[^o4][^o5][^o6]

## Product distributions {#Product_distributions}

Given [measurable spaces](wikipedia://en/43333) $(X,\mathcal{F})$ and $(Y,\mathcal{G})$, one can form the measurable space $(PX,\mathcal{PX})\times (PY,\mathcal{PY})=(X\times Y, \mathcal{F}\times\mathcal{G})$ with the [product sigma-algebra](https://en.wikipedia.org/wiki/Product_sigma-algebra), which is the [product](wikipedia://en/237868) in the [category of measurable spaces](wikipedia://en/75966255). Given [probability measures](wikipedia://en/45437) $p\in PX$ and $q\in PY$, one can form the [product measure](wikipedia://en/2986564) $p\otimes q$ on $(X\times Y, \mathcal{F}\times\mathcal{G})$. This gives a [natural](wikipedia://en/45022), [measurable map](https://en.wikipedia.org/wiki/Measurable_map)

$$(PX,\mathcal{PF})\times (PY,\mathcal{PG})\to \big(P(X\times Y), \mathcal{P(F\times G)}\big)$$

usually denoted by $\nabla$ or by $\otimes$.[^o5]

The map $\nabla:PX\times PY\to P(X\times Y)$ is in general not an isomorphism, since there are probability measures on $X\times Y$ which are not product distributions, for example in case of [correlation](wikipedia://en/157057). However, the maps $\nabla:PX\times PY\to P(X\times Y)$ and the isomorphism $1\cong P1$ make the Giry monad a [monoidal monad](wikipedia://en/4585564), and so in particular a commutative [strong monad](https://en.wikipedia.org/wiki/Strong_monad).[^o5]

## Further properties {#Further_properties}

- If a measurable space $(X,\mathcal{F})$ is [standard Borel](wikipedia://en/29819325), so is $(PX,\mathcal{PF})$. Therefore, the Giry monad restricts to the [full subcategory](https://en.wikipedia.org/wiki/Full_subcategory) of standard Borel spaces.[^o2][^o5]
- The [algebras](https://en.wikipedia.org/wiki/Algebra_for_a_monad) for the Giry monad include [compact](https://en.wikipedia.org/wiki/Compact_topological_space) [convex](wikipedia://en/6292) subsets of [Euclidean spaces](wikipedia://en/9697), as well as the extended positive real line $[0,\infty]$, with the algebra structure map given by taking [expected values](https://en.wikipedia.org/wiki/Expected_values).[^o21] For example, for $[0,\infty]$, the structure map $e:P[0,\infty]\to [0,\infty]$ is given by

$$p \longmapsto \int_{[0,\infty)} x\,p(dx)$$

whenever $p$ is supported on $[0,\infty)$ and has finite expected value, and $e(p)=\infty$ otherwise.

## Finitary variant {#Finitary_variant}

There is a finitary version of the Giry monad, here denoted $F$ which maps a set $S$ to the set of [convex combinations](https://en.wikipedia.org/wiki/Convex_combinations) on $S.$ Thus, for example, if $S = \{a, b, c\}$, the formal combination $0.2a + 0.2b + 0.6c$ would be contained in $FS$.
