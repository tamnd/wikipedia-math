# Quantum singular value transformation

::: {#o1 .subject cue=lead name="Quantum singular value transformation"}

**Quantum singular value transformation** is a framework for designing [quantum algorithms](https://en.wikipedia.org/wiki/Quantum_algorithm). It encompasses a variety of quantum algorithms for problems that can be solved with [linear algebra](wikipedia://en/18422), including [Hamiltonian simulation](wikipedia://en/60663582), [search problems](wikipedia://en/58498), and [linear system solving](wikipedia://en/42676762).[^o2][^o3][^o4] It was introduced in 2018 by András Gilyén, Yuan Su, Guang Hao Low, and Nathan Wiebe, generalizing algorithms for Hamiltonian simulation of Guang Hao Low and [Isaac Chuang](https://en.wikipedia.org/wiki/Isaac_Chuang) inspired by signal processing.[^o5]

:::

## High-level description {#High-level_description}

The basic primitive of quantum singular value transformation is the block-encoding. A [quantum circuit](wikipedia://en/707404) is a block-encoding of a matrix *A* if it implements a [unitary matrix](wikipedia://en/129222) *U* such that *U* contains *A* in a specified sub-matrix. For example, if $(\langle 0 | \otimes I) U (|0\rangle \otimes|\phi\rangle) = A|\phi\rangle$, then *U* is a block-encoding of *A*.

The fundamental algorithm of QSVT is one that converts a block-encoding of *A* to a block-encoding of $p(A, A^\dagger)$, where *p* is a polynomial of degree *d* and $A^\dagger$ denotes the [conjugate transpose](wikipedia://en/217548), with only *d* applications of the circuit and one ancilla qubit. This can be done for a large class of polynomials *p* which correspond to applying a polynomial to the [singular values](wikipedia://en/709116) of *A*, giving a "singular value transformation".

A variant of this algorithm can also be performed when *A* is [Hermitian](wikipedia://en/189682), corresponding to an "eigenvalue transformation". That is, given a block-encoding of *A* with [eigendecomposition of a matrix](https://en.wikipedia.org/wiki/Eigendecomposition) $A = \sum \lambda_i u_iu_i^\dagger$, one can get a block-encoding for $\sum p(\lambda_i) u_iu_i^\dagger$, provided *p* is bounded.[^o5]

## Algorithm {#Algorithm}

*Input*: A matrix $A$ whose [singular value decomposition](wikipedia://en/142207) is $A = W\Sigma V^{\dagger}$ where $\Sigma$ are the singular values of A

*Input*: A polynomial $P$

*Output*: A unitary where $P$ has been applied to the singular values of $A$: $\begin{bmatrix}WP(\Sigma) V^{\dagger} & . \\. & . \end{bmatrix}$

1. Prepare a unitary $U$ that encodes $A$ on the top left side of $U$, that is $U = \begin{bmatrix}A & . \\. & . \end{bmatrix}$
1. Initialize an $n$ qubit state $|0\rangle^{\otimes n}$
1. If the polynomial is odd, apply $\tilde{\Pi}_{\phi_{1}} U \prod_{k=1}^{\frac{d-1}{2}} \Pi_{\phi_{2k}}U^{\dagger}\tilde{\Pi}_{\phi_{2k+1}} U$ to $|0\rangle^{\otimes n}$
1. If the polynomial is even apply $\prod_{k=1}^{\frac{d}{2}} \Pi_{\phi_{2k}-1}U^{\dagger}\tilde{\Pi}_{\phi_{2k}} U$ to $|0\rangle^{\otimes n}$
