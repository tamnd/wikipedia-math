# Difference hierarchy

::: {#o1 .subject cue=lead name="Difference hierarchy"}

In [set theory](wikipedia://en/27553), a branch of mathematics, the **difference hierarchy** over a [pointclass](wikipedia://en/9304834) is a [hierarchy](wikipedia://en/3612259) of larger pointclasses generated by taking [differences](wikipedia://en/54347) of sets. If Γ is a pointclass, then the set of differences in Γ is $\{A:\exists C,D\in\Gamma ( A = C\setminus D)\}$. In usual notation, this set is denoted by 2-Γ. The next level of the hierarchy is denoted by 3-Γ and consists of differences of three sets: $\{A : \exists C,D,E\in\Gamma ( A=C\setminus(D\setminus E))\}$. This definition can be extended recursively into the [transfinite](wikipedia://en/189734) to *α*-Γ for some [ordinal](wikipedia://en/26547932) *α*.[^o2]

:::

In the [Borel](https://en.wikipedia.org/wiki/Borel_sets) hierarchy, [Felix Hausdorff](wikipedia://en/10989) and [Kazimierz Kuratowski](wikipedia://en/46075) proved that the [countable](https://en.wikipedia.org/wiki/Countable) levels of the difference hierarchy over Π<sup>0</sup><sub>*γ*</sub> give Δ<sup>0</sup><sub>*γ*+1</sub>.[^o3]
