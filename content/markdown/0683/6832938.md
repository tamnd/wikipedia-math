# Non-integer base of numeration

::: {#o1 .subject cue=lead name="Non-integer base of numeration"}

A **non-integer representation** uses non-[integer](wikipedia://en/14563) numbers as the [radix](wikipedia://en/701207), or base, of a [positional numeral system](wikipedia://en/437052). For a non-integer radix *β* > 1, the value of

:::

$$x = d_n \dots d_2d_1d_0.d_{-1}d_{-2}\dots d_{-m}$$

is

$$\begin{aligned} x &= \beta^nd_n + \cdots + \beta^2d_2 + \beta d_1 + d_0 \\ &\qquad + \beta^{-1}d_{-1} + \beta^{-2}d_{-2} + \cdots + \beta^{-m}d_{-m}. \end{aligned}$$

The numbers *d*<sub>*i*</sub> are non-negative integers less than *β*. This is also known as a ***β*-expansion**, a notion introduced by (Rényi 1957) and first studied in detail by (Parry 1960). Every [real number](wikipedia://en/20646438) has at least one (possibly infinite) *β*-expansion. The [set](wikipedia://en/26691) of all *β*-expansions that have a finite representation is a [subset](wikipedia://en/27631) of the [ring](wikipedia://en/48404) **Z**\[*β*, *β*<sup>−1</sup>\].

There are applications of *β*-expansions in [coding theory](wikipedia://en/321869)[^o4] and models of [quasicrystals](wikipedia://en/25350).[^o5]

::: {#o7 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

*β*-expansions are a generalization of [decimal expansions](https://en.wikipedia.org/wiki/Decimal_expansion). While infinite decimal expansions are not unique (for example, 1.000... = [0.999...](wikipedia://en/1849799)), all finite decimal expansions are unique. However, even finite *β*-expansions are not necessarily unique, for example *φ* + 1 = *φ*<sup>2</sup> for *β* = *φ*, the [golden ratio](wikipedia://en/12386). A canonical choice for the *β*-expansion of a given real number can be determined by the following [greedy algorithm](wikipedia://en/89247), essentially due to (Rényi 1957) and formulated as given here by (Frougny 1992).

Let $\beta > 1$ be the base and *x* a non-negative real number. Denote by $\lfloor x\rfloor$ the [floor function](https://en.wikipedia.org/wiki/Floor_function) of *x* (that is, the greatest integer less than or equal to *x*) and let $\{x\} = x - \lfloor x\rfloor$ be the fractional part of *x*. [There exists](https://en.wikipedia.org/wiki/There_exists) an integer *k* such that $\beta^{k} \le x < \beta^{k+1}$. Set

$$d_k = \lfloor x/\beta^k\rfloor$$

and

$$r_k = \{x/\beta^k\}.\,$$

For $k - 1 \ge \,j > -\infty$, put

$$d_j = \lfloor\beta r_{j+1}\rfloor, \quad r_j = \{\beta r_{j+1}\}.$$

In other words, the canonical *β*-expansion of *x* is defined by choosing the largest *d*<sub>*k*</sub> such that $\beta^{k}d_{k} \le x$, then choosing the largest *d*<sub>*k*−1</sub> such that $\beta^{k}d_{k} + \beta^{k-1}d_{k-1} \le x$, and so on. Thus it chooses the [lexicographically](https://en.wikipedia.org/wiki/Lexicographical_order) largest string representing *x*.

With an integer base, this defines the usual radix expansion for the number *x*. This construction extends the usual algorithm to possibly non-integer values of *β*.

### Conversion {#Conversion}

Following the steps above, we can create a *β*-expansion for a real number $n \geq 0$ (the steps are identical for an $n < 0$, although $n$ must first be multiplied by \-1 to make it positive, then the result must be multiplied by \-1 to make it negative again).

First, we must define our $k$ value (the exponent of the nearest power of $\beta$ greater than $n$, as well as the amount of digits in $\lfloor n_\beta \rfloor$, where $n_\beta$ is $n$ written in base $\beta$). The $k$ value for $n$ and $\beta$ can be written as:

$$k = \lfloor \log_\beta(n) \rfloor + 1$$

After a $k$ value is found, $n_\beta$ can be written as $d$, where

$$d_j = \lfloor (n/\beta^j) \bmod \beta \rfloor, \quad n = n-d_j*\beta^j$$

for $k - 1 \ge \,j > -\infty$. The first $k$ values of $d$ appear to the left of the decimal place.

This can also be written in the following [pseudocode](https://en.wikipedia.org/wiki/Pseudocode):[^o11]

```javascript
function toBase(n, b) {
	k = floor(log(b, n)) + 1
	precision = 8
	result = ""

	for (i = k - 1, i > -precision-1, i--) {
		if (result.length == k) result += "."
		
		digit = floor((n / b^i) mod b)
		n -= digit * b^i
		result += digit
	}

	return result
}
```

Note that the above code is only valid for $1 < \beta \leq 10$ and $n \geq 0$, as it does not convert each digits to their correct symbols or correct negative numbers. For example, if a digit's value is 10, it will be represented as 10 instead of $A$.

### Example implementation code {#Example_implementation_code}

#### To base $\pi$ {#To_base}

- [JavaScript](https://en.wikipedia.org/wiki/JavaScript):[^o11] ```javascript
function toBasePI(num, precision = 8) {    
    let k = Math.floor(Math.log(num)/Math.log(Math.PI)) + 1;
    if (k < 0) k = 0;

    let digits = [];

    for (let i = k-1; i > (-1*precision)-1; i--) {
        let digit = Math.floor((num / Math.pow(Math.PI, i)) % Math.PI);
        num -= digit * Math.pow(Math.PI, i);
        digits.push(digit);

        if (num < 0.1**(precision+1) && i <= 0)
            break;
    }

    if (digits.length > k)
        digits.splice(k, 0, ".");

    return digits.join("");
}
```

#### From base $\pi$ {#From_base}

- JavaScript:[^o11] ```javascript
function fromBasePI(num) {
    let numberSplit = num.split(/\./g);
    let numberLength = numberSplit[0].length;

    let output = 0;
    let digits = numberSplit.join("");

    for (let i = 0; i < digits.length; i++) {
        output += digits[i] * Math.pow(Math.PI, numberLength-i-1);
    }

    return output;
}
```

## Examples {#Examples}

### Base $\sqrt{2}$ {#Base}

Base [$\sqrt{2}$](wikipedia://en/341682) behaves in a very similar way to [base 2](https://en.wikipedia.org/wiki/Binary_numeral_system) as all one has to do to convert a number from [binary](https://en.wikipedia.org/wiki/Binary_numeral_system) into base $\sqrt{2}$ is put a zero digit in between every binary digit; for example, 1911<sub>10</sub> = 11101110111<sub>2</sub> becomes 101010001010100010101<sub>$\sqrt{2}$</sub> and 5118<sub>10</sub> = 1001111111110<sub>2</sub> becomes 1000001010101010101010100<sub>$\sqrt{2}$</sub>. This means that every integer can be expressed in base $\sqrt{2}$ without the need of a radix point. The base can also be used to show the relationship between the [side](wikipedia://en/12158034) of a [square](https://en.wikipedia.org/wiki/Square_%28geometry%29) to its [diagonal](wikipedia://en/349251) as a square with a side length of 1<sub>$\sqrt{2}$</sub> will have a diagonal of 10<sub>$\sqrt{2}$</sub> and a square with a side length of 10<sub>$\sqrt{2}$</sub> will have a diagonal of 100<sub>$\sqrt{2}$</sub>. Another use of the base is to show the [silver ratio](wikipedia://en/920526) as its representation in base $\sqrt{2}$ is simply 11<sub>$\sqrt{2}$</sub>. In addition, the area of a [regular octagon](https://en.wikipedia.org/wiki/Regular_octagon) with side length 1<sub>$\sqrt{2}$</sub> is 1100<sub>$\sqrt{2}$</sub>, the area of a regular octagon with side length 10<sub>$\sqrt{2}$</sub> is 110000<sub>$\sqrt{2}$</sub>, the area of a regular octagon with side length 100<sub>$\sqrt{2}$</sub> is 11000000<sub>$\sqrt{2}$</sub>, etc...

### Golden base {#Golden_base}

In the golden base, some numbers have more than one decimal base equivalent: they are **ambiguous**. For example, 11<sub>φ</sub> = 100<sub>φ</sub>, since φ² = φ + 1.

### Base ψ {#Base_ψ}

There are some numbers in base [ψ, the supergolden ratio](wikipedia://en/58128086), that are also ambiguous. For example, 101<sub>ψ</sub> = 1000<sub>ψ</sub>, since ψ³ = ψ² + 1.

### Base *e* {#Base_e}

With base [*e*](wikipedia://en/9633) the [natural logarithm](wikipedia://en/21476) behaves like the [common logarithm](wikipedia://en/174482) in base 10, as ln(1<sub>*e*</sub>) = 0, ln(10<sub>*e*</sub>) = 1, ln(100<sub>*e*</sub>) = 2 and ln(1000<sub>*e*</sub>) = 3 (or more precisely the representation in base *e* of 3, which is a non-terminating number). This means that the integer part of the natural logarithm of a number in base *e* counts the number of digits before the separating point in that number, minus one.

The base *e* is the most economical choice of radix *β* > 1,[^o21] where the [radix economy](https://en.wikipedia.org/wiki/Radix_economy) is measured as the product of the radix and the length of the string of symbols needed to express a given range of values. A binary number uses only two different digits, but it needs a lot of digits for representing a number; base 10 writes shorter numbers, but it needs 10 different digits to write them. The balance between those is base *e*, which therefore would store numbers optimally.

### Base π {#Base_π}

Base [π](wikipedia://en/23601) can be used to more easily show the relationship between the [diameter](wikipedia://en/8007) of a [circle](wikipedia://en/6220) to its [circumference](wikipedia://en/5916), which corresponds to its [perimeter](wikipedia://en/23636); since circumference = diameter × π, a circle with a diameter 1<sub>π</sub> will have a circumference of 10<sub>π</sub>, a circle with a diameter 10<sub>π</sub> will have a circumference of 100<sub>π</sub>, etc. Furthermore, since the [area](wikipedia://en/1209) = π × [radius](wikipedia://en/1780815)<sup>2</sup>, a circle with a radius of 1<sub>π</sub> will have an area of 10<sub>π</sub>, a circle with a radius of 10<sub>π</sub> will have an area of 1000<sub>π</sub> and a circle with a radius of 100<sub>π</sub> will have an area of 100000<sub>π</sub>.[^o23]

## Properties {#Properties}

In every positional number system, not all numbers are expressed uniquely. For example, in base 10, the number 1 has two representations: 1.000... and [0.999...](wikipedia://en/1849799). The set of numbers with two different representations is [dense](wikipedia://en/23523594) in the reals,[^o26] but the question of classifying real numbers with unique *β*-expansions is considerably more subtle than that of integer bases.[^o27]

Another problem is to classify the real numbers whose *β*-expansions are periodic. Let *β* > 1, and **Q**(*β*) be the smallest [field extension](wikipedia://en/11634) of the [rationals](wikipedia://en/19727024) containing *β*. Then any real number in \[0,1) having a periodic *β*-expansion must lie in **Q**(*β*). On the other hand, the [converse](wikipedia://en/155941) need not be true. The converse does hold if *β* is a [Pisot number](https://en.wikipedia.org/wiki/Pisot_number),[^o28] although necessary and sufficient conditions are not known.
