# Bilinear program

::: {#o1 .subject cue=lead name="Bilinear program"}

In mathematics, a **bilinear program** is a [nonlinear optimization](https://en.wikipedia.org/wiki/Nonlinear_optimization) problem whose objective or constraint functions are [bilinear](wikipedia://en/449477). An example is the [pooling problem](https://en.wikipedia.org/wiki/Pooling_problem).

:::
