# Nested dissection

::: {#o1 .subject cue=lead name="Nested dissection"}

In [numerical analysis](wikipedia://en/21506), **nested dissection** is a [divide and conquer](https://en.wikipedia.org/wiki/Divide_and_conquer_algorithm) [heuristic](https://en.wikipedia.org/wiki/Heuristic) for the solution of [sparse](wikipedia://en/341015) [symmetric](wikipedia://en/126474) [systems of linear equations](wikipedia://en/113087) based on [graph partitioning](https://en.wikipedia.org/wiki/Graph_partitioning). Nested dissection was introduced by (George 1973); the name was suggested by [Garrett Birkhoff](wikipedia://en/1180916).[^o3]

:::

Nested dissection consists of the following steps:

- Form an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) in which the vertices represent rows and columns of the system of linear equations, and an edge represents a nonzero entry in the [sparse matrix](wikipedia://en/341015) representing the system.
- [Recursively](wikipedia://en/25407) partition the graph into [subgraphs](wikipedia://en/325802#Subgraphs) using [separators](wikipedia://en/18978005), small subsets of vertices the removal of which allows the graph to be partitioned into subgraphs with at most a constant fraction of the number of vertices.
- Perform [Cholesky decomposition](wikipedia://en/134433) (a variant of [Gaussian elimination](wikipedia://en/13035) for symmetric matrices), ordering the elimination of the variables by the recursive structure of the partition: each of the two subgraphs formed by removing the separator is eliminated first, and then the separator vertices are eliminated.

As a consequence of this algorithm, the fill-in (the set of nonzero matrix entries created in the Cholesky decomposition that are not part of the input matrix structure) is limited to at most the square of the separator size at each level of the recursive partition. In particular, for planar graphs (frequently arising in the solution of sparse linear systems derived from two-dimensional [finite element method](wikipedia://en/18233581) meshes) the resulting matrix has O(*n* log *n*) nonzeros, due to the [planar separator theorem](wikipedia://en/18978005) guaranteeing separators of size O($\sqrt{n}$).[^o4] For arbitrary graphs there is a nested dissection that guarantees fill-in within a $O(\min\{\sqrt{d}\log^4 n, m^{1/4}\log^{3.5} n\})$ factor of optimal, where *d* is the maximum degree and *m* is the number of non-zeros. [^o5]
