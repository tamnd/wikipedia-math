# Evolutionary data mining

::: {#o1 .subject cue=lead name="Evolutionary data mining"}

**Evolutionary data mining**, or **genetic data mining** is an [umbrella term](https://en.wikipedia.org/wiki/Umbrella_term) for any [data mining](wikipedia://en/42253) using [evolutionary algorithms](https://en.wikipedia.org/wiki/Evolutionary_algorithm). While it can be used for mining data from [DNA sequences](https://en.wikipedia.org/wiki/DNA_sequence),[^o2] it is not limited to biological contexts and can be used in any classification-based prediction scenario, which helps "predict the value ... of a user-specified goal attribute based on the values of other attributes."[^o3] For instance, a banking institution might want to predict whether a customer's [credit](https://en.wikipedia.org/wiki/Credit_%28finance%29) would be "good" or "bad" based on their age, income and current savings.[^o3] Evolutionary algorithms for data mining work by creating a series of [random](https://en.wikipedia.org/wiki/Random) rules to be checked against a training [dataset](https://en.wikipedia.org/wiki/Dataset).[^o6] The rules which most closely fit the data are selected and are [mutated](https://en.wikipedia.org/wiki/Mutated).[^o6] The process is [iterated](wikipedia://en/68833) many times and eventually, a rule will arise that approaches 100% similarity with the training data.[^o3] This rule is then checked against a test dataset, which was previously invisible to the genetic algorithm.[^o3]

:::

## Process {#Process}

### Data preparation {#Data_preparation}

Before [databases](https://en.wikipedia.org/wiki/Database) can be mined for data using evolutionary algorithms, it first has to be cleaned,[^o3] which means incomplete, noisy or inconsistent data should be repaired. It is imperative that this be done before the mining takes place, as it will help the algorithms produce more accurate results.[^o6]

If data comes from more than one database, they can be integrated, or combined, at this point.[^o6] When dealing with large datasets, it might be beneficial to also reduce the amount of data being handled.[^o6] One common method of data reduction works by getting a [normalized](wikipedia://en/2978513) sample of data from the database, resulting in much faster, yet statistically equivalent results.[^o6]

At this point, the data is split into two equal but mutually exclusive elements, a test and a training dataset.[^o3] The training dataset will be used to let rules evolve which match it closely.[^o3] The test dataset will then either confirm or deny these rules.[^o3]

### Data mining {#Data_mining}

Evolutionary algorithms work by trying to emulate natural [evolution](https://en.wikipedia.org/wiki/Evolution).[^o6] First, a random series of "rules" are set on the training dataset, which try to generalize the data into formulas.[^o6] The rules are checked, and the ones that fit the data best are kept, the rules that do not fit the data are discarded.[^o6] The rules that were kept are then mutated, and multiplied to create new rules.[^o6]

This process iterates as necessary in order to produce a rule that matches the dataset as closely as possible.[^o6] When this rule is obtained, it is then checked against the test dataset.[^o3] If the rule still matches the data, then the rule is valid and is kept.[^o3] If it does not match the data, then it is discarded and the process begins by selecting random rules again.[^o3]
