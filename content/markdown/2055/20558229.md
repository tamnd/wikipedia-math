# FTCS scheme

::: {#o1 .subject cue=lead name="FTCS scheme"}

In [numerical analysis](wikipedia://en/21506), the **FTCS** (**forward time-centered space**) method is a [finite difference method](wikipedia://en/6054681) used for numerically solving the [heat equation](wikipedia://en/166415) and similar [parabolic partial differential equations](wikipedia://en/7466971).[^o2] It is a first-order method in time, [explicit](wikipedia://en/3652485) in time, and is [conditionally stable](wikipedia://en/233807) when applied to the heat equation. When used as a method for [advection equations](wikipedia://en/166377), or more generally [hyperbolic partial differential equations](wikipedia://en/1575825), it is unstable unless artificial viscosity is included. The abbreviation FTCS was first used by Patrick Roache.[^o3][^o4]

:::

::: {#o6 .definition kind=definition/construction cue=heading name="The method"}

## The method {#The_method}

The FTCS method is based on the [forward Euler method](https://en.wikipedia.org/wiki/Forward_Euler_method) in time (hence "forward time") and [central difference](https://en.wikipedia.org/wiki/Central_difference) in space (hence "centered space"), giving first-order convergence in time and second-order convergence in space. For example, in one dimension, if the [partial differential equation](wikipedia://en/52564) is

$$\frac{\partial u}{\partial t} = F\left(u, x, t, \frac{\partial^2 u}{\partial x^2}\right)$$

then, letting $u(i \,\Delta x, n\, \Delta t) = u_{i}^{n}\,$, the forward Euler method is given by:

$$\frac{u_{i}^{n + 1} - u_{i}^{n}}{\Delta t} = F_{i}^{n}\left(u, x, t, \frac{\partial^2 u}{\partial x^2}\right)$$

The function $F$ must be discretized spatially with a [central difference](https://en.wikipedia.org/wiki/Central_difference) scheme. This is an [explicit method](wikipedia://en/3652485) which means that, $u_{i}^{n+1}$ can be explicitly computed (no need of solving a system of algebraic equations) if values of $u$ at previous time level $(n)$ are known. FTCS method is computationally inexpensive since the method is explicit.

:::

## Illustration: one-dimensional heat equation {#Illustration:_one-dimensional_heat_equation}

The FTCS method is often applied to [diffusion](https://en.wikipedia.org/wiki/Diffusion) problems. As an example, for 1D [heat equation](wikipedia://en/166415),

$$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$$

the FTCS scheme is given by:

$$\frac{u_{i}^{n + 1} - u_{i}^{n}}{\Delta t} = \alpha \frac{u_{i + 1}^{n} - 2 u_{i}^{n} + u_{i - 1}^{n} }{\Delta x^2}$$

or, letting $r = \frac{\alpha\, \Delta t}{\Delta x^2}$:

$$u_{i}^{n + 1} = u_{i}^{n} + r \left(u_{i + 1}^{n} - 2 u_{i}^{n} + u_{i - 1}^{n} \right)$$

## Stability {#Stability}

As derived using [von Neumann stability analysis](wikipedia://en/20625645), the FTCS method for the one-dimensional heat equation is [numerically stable](wikipedia://en/233807) if and only if the following condition is satisfied:

$$\Delta t \leq \frac{\Delta x^2}{2 \alpha}.$$

Which is to say that the choice of $\Delta x$ and $\Delta t$ must satisfy the above condition for the FTCS scheme to be stable. In two-dimensions, the condition becomes

$$\Delta t \leq \frac{1}{2 \alpha\left(\frac{1}{\Delta x^2} + \frac{1}{\Delta y^2}\right)}.$$

If we choose $h = \Delta x = \Delta y = \Delta z$, then the stability conditions become $\Delta t \leq h^2/(2\alpha)$, $\Delta t \leq h^2/(4\alpha)$, and $\Delta t \leq h^2/(6\alpha)$ for one-, two-, and three-dimensional applications, respectively.[^o9]

A major drawback of the FTCS method is that for problems with large diffusivity $\alpha$, satisfactory step sizes can be too small to be practical.

For [hyperbolic partial differential equations](https://en.wikipedia.org/wiki/Hyperbolic_partial_differential_equations), the [linear test problem](wikipedia://en/379868) is the constant coefficient [advection equation](wikipedia://en/166377), as opposed to the [heat equation](wikipedia://en/166415) (or [diffusion equation](wikipedia://en/645335)), which is the correct choice for a [parabolic differential equation](https://en.wikipedia.org/wiki/Parabolic_differential_equation). It is well known that for these [hyperbolic problems](https://en.wikipedia.org/wiki/Hyperbolic_partial_differential_equations), *any* choice of $\Delta t$ results in an unstable scheme.[^o10]
