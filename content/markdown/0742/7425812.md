# BV4.1 (software)

::: {#o1 .subject cue=lead name="BV4.1"}

**BV4.1** is a retired[^o3] [application software](https://en.wikipedia.org/wiki/Application_software) tool for [decomposing](https://en.wikipedia.org/wiki/Decomposing_of_time_series) and [seasonally adjusting](wikipedia://en/7579959) monthly or quarterly economic [time series](wikipedia://en/406624)[^o4] by version 4.1 of the [Berlin procedure](wikipedia://en/7484008) developed by the [Federal Statistical Office of Germany](wikipedia://en/7516079). The software is released as [freeware](https://en.wikipedia.org/wiki/Freeware) for non-commercial purposes.

:::

## Features {#Features}

The essential features of the BV4.1 software are:

- System requirements: Windows PC ([Windows NT 4.0](https://en.wikipedia.org/wiki/Windows_NT_4.0) / [Windows 98](https://en.wikipedia.org/wiki/Windows_98) up to [Windows XP](https://en.wikipedia.org/wiki/Windows_XP)).
- Support of the file formats [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [Microsoft Access](https://en.wikipedia.org/wiki/Microsoft_Access), [SQL Server](https://en.wikipedia.org/wiki/Microsoft_SQL_Server) and [CSV](https://en.wikipedia.org/wiki/Comma-separated_values).
- User-friendly graphical user interface.
- Analyses of monthly and quarterly time series.
- Possibility of mass production of time series decompositions and seasonal adjustments.
- Various possibilities of graphic evaluations of analysis results.
- Possibility to execute "successive analyses": analyses where the analysis spans are extended gradually by one additional period. This option is useful for examining such revisions of analysis results originating from the BV4.1 procedure itself.
