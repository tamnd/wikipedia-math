# Zermelo's categoricity theorem

::: {#o1 .subject cue=lead name="Zermelo's categoricity theorem"}

In mathematical [set theory](wikipedia://en/27553), **Zermelo's categoricity theorem** was proved by [Ernst Zermelo](wikipedia://en/178655) in 1930. It states that all models of a certain [second-order](wikipedia://en/341428) version of the [Zermelo–Fraenkel axioms of set theory](https://en.wikipedia.org/wiki/ZFC) are isomorphic to a member of a certain [class](wikipedia://en/20696) of sets.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $\mathrm{ZFC}^2$ denote Zermelo–Fraenkel set theory, but with a second-order version of the axiom of replacement formulated as follows:[^o4]

$$\forall F\forall x\exists y\forall z(z\in y \iff \exists w(w\in x\land z = F(w)))$$

, namely the second-order universal closure of the [axiom schema](wikipedia://en/764613) of replacement.[^o5]<sup>p. 289</sup> Then every model of $\mathrm{ZFC}^2$ is isomorphic to a set $V_\kappa$ in the [von Neumann hierarchy](https://en.wikipedia.org/wiki/Von_Neumann_hierarchy), for some [strongly inaccessible cardinal](https://en.wikipedia.org/wiki/Strongly_inaccessible_cardinal) $\kappa$.[^o6]

:::

## Original presentation {#Original_presentation}

Zermelo originally considered a version of $\mathrm{ZFC}^2$ with [urelements](wikipedia://en/643648). Rather than using the modern satisfaction relation $\vDash$, he defines a "normal domain" to be a collection of sets along with the true $\in$ relation that satisfies $\mathrm{ZFC}^2$.[^o8]<sup>p. 9</sup>

::: {#o10 .statement kind=statement/generalization cue=heading name="Related results"}

## Related results {#Related_results}

[Dedekind](https://en.wikipedia.org/wiki/Dedekind) proved that the second-order [Peano axioms](wikipedia://en/25005) hold in a model if and only if the model is isomorphic to the true natural numbers.[^o8]<sup>pp. 5–6</sup>[^o6]<sup>p. 1</sup> Uzquiano proved that when removing replacement from $\mathsf{ZFC}^2$ and considering a second-order version of [Zermelo set theory](wikipedia://en/322623) with a second-order version of [separation](wikipedia://en/52386), there exist models not isomorphic to any $V_\delta$ for a [limit ordinal](wikipedia://en/373137) $\delta>\omega$.[^o11]<sup>p. 396</sup>

:::
