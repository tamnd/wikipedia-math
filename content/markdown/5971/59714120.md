# Simultaneous Authentication of Equals

::: {#o1 .subject cue=lead name="Simultaneous Authentication of Equals"}

In [cryptography](wikipedia://en/18934432), **Simultaneous Authentication of Equals** (**SAE**) is a [password](wikipedia://en/24304)-based authentication and [password-authenticated key agreement](https://en.wikipedia.org/wiki/Password-authenticated_key_agreement) method.[^o4]

:::

## Authentication {#Authentication}

SAE is a variant of the [Dragonfly Key Exchange](https://en.wikipedia.org/wiki/Dragonfly_Key_Exchange) defined in 7664,[^o3] based on [Diffie–Hellman key exchange](wikipedia://en/7903) using [finite cyclic groups](wikipedia://en/52327) which can be a [primary cyclic group](wikipedia://en/4814080) or an [elliptic curve](https://en.wikipedia.org/wiki/Elliptic_curve_Diffie–Hellman).[^o4] The problem of using Diffie–Hellman key exchange is that it does not have an authentication mechanism. So the resulting key is influenced by a [pre-shared key](wikipedia://en/4934057) and the [MAC addresses](https://en.wikipedia.org/wiki/MAC_address) of both peers to solve the [authentication problem](wikipedia://en/7903#Security_and_practical_considerations).

::: {#o6 .application cue=heading name="Use"}

## Use {#Use}

### IEEE 802.11s {#IEEE_802.11s}

SAE was originally implemented for use between [peers](https://en.wikipedia.org/wiki/Peer_%28networking%29) in [IEEE 802.11s](https://en.wikipedia.org/wiki/IEEE_802.11s).[^o4] When peers discover each other (and security is enabled) they take part in an SAE exchange. If SAE completes successfully, each peer knows the other party possesses the mesh password and, as a by-product of the SAE exchange, the two peers establish a cryptographically strong key. This key is used with the "Authenticated Mesh Peering Exchange" (AMPE) to establish a secure peering and derive a session key to protect mesh traffic, including routing traffic.

### WPA3 {#WPA3}

In January 2018, the [Wi-Fi Alliance](https://en.wikipedia.org/wiki/Wi-Fi_Alliance) announced [WPA3](https://en.wikipedia.org/wiki/WPA3) as a replacement to [WPA2](https://en.wikipedia.org/wiki/WPA2).[^o9][^o10] The new standard uses 128-bit encryption in WPA3-Personal mode (192-bit in WPA3-Enterprise)[^o11] and [forward secrecy](wikipedia://en/2191130).[^o12] The WPA3 standard also replaces the [pre-shared key](wikipedia://en/4934057) (PSK) exchange with Simultaneous Authentication of Equals as defined in [IEEE 802.11-2016](https://en.wikipedia.org/wiki/IEEE_802.11-2016) resulting in a more secure initial key exchange in personal mode.[^o13][^o14] The Wi-Fi Alliance also claims that WPA3 will mitigate security issues posed by weak passwords and simplify the process of setting up devices with no display interface.[^o15]

:::

## Security {#Security}

In 2019 Eyal Ronen and Mathy Vanhoef (co-author of the [KRACK](https://en.wikipedia.org/wiki/KRACK) attack) released an analysis of WPA3's Dragonfly handshake and found that "an attacker within range of a victim can still recover the password" and the bugs found "allow an adversary to impersonate any user, and thereby access the Wi-Fi network, without knowing the user's password."[^o17][^o18]
