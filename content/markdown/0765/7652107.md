# Suslin cardinal

::: {#o1 .subject cue=lead name="Suslin cardinal"}

In [mathematics](wikipedia://en/18831), a [cardinal](wikipedia://en/6173) λ \< [Θ](https://en.wikipedia.org/wiki/Θ_%28set_theory%29) is a **Suslin cardinal** if there exists a set P ⊂ 2<sup>ω</sup> such that P is [λ-Suslin](https://en.wikipedia.org/wiki/Λ-Suslin) but P is not λ'-Suslin for any λ' \< λ. It is named after the [Russian](https://en.wikipedia.org/wiki/Russia) [mathematician](wikipedia://en/18902) [Mikhail Yakovlevich Suslin](https://en.wikipedia.org/wiki/Mikhail_Yakovlevich_Suslin) (1894–1919).[^o2]

:::
