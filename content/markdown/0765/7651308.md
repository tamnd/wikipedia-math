# Honest leftmost branch

::: {#o1 .subject cue=lead name="Honest leftmost branch"}

In [set theory](wikipedia://en/27553), an **honest leftmost branch** of a [tree](wikipedia://en/704160) *T* on ω × γ is a branch ([maximal](https://en.wikipedia.org/wiki/Maximal_element) [chain](https://en.wikipedia.org/wiki/Chain_%28order_theory%29)) *ƒ* ∈ \[*T*\] such that for each branch *g* ∈ \[*T*\], one has ∀ *n* ∈ ω : *ƒ*(*n*) ≤ *g*(*n*). Here, \[*T*\] denotes the set of branches of maximal length of *T*, ω is the smallest infinite [ordinal](wikipedia://en/26547932) (represented by the [natural numbers](wikipedia://en/21474) **N**), and γ is some other ordinal.

:::
