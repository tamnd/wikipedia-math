# Suslin representation

::: {#o1 .subject cue=lead name="Suslin representation"}

In [mathematics](wikipedia://en/18831), a **Suslin representation** of a set of [reals](wikipedia://en/20646438) (more precisely, elements of [Baire space](wikipedia://en/2078245)) is a [tree](wikipedia://en/2190732) whose projection is that set of reals. More generally, a subset *A* of *κ*<sup>ω</sup> is ***λ*-Suslin** if there is a [tree](wikipedia://en/2190732) *T* on *κ* × *λ* such that *A* = p\[*T*\][^o2].

:::

By a tree on *κ* × *λ* we mean a subset *T* ⊆ ⋃<sub>*n*\<ω</sub>(*κ*<sup>*n*</sup> × *λ*<sup>*n*</sup>) closed under initial segments, and p\[*T*\] = { *f*∈*κ*<sup>ω</sup> | ∃*g*∈*λ*<sup>ω</sup> : (*f*,*g*) ∈ \[*T*\] } is the projection of *T*, where \[*T*\] = { (*f*, *g* )∈*κ*<sup>ω</sup> × *λ*<sup>ω</sup> | ∀*n* \< ω : (*f* |*n*, *g* |*n*) ∈ *T* } is the set of [branches](wikipedia://en/2190732#Branches_and_bodies) through *T*.

Since \[*T*\] is a closed set for the [product topology](wikipedia://en/24910) on *κ*<sup>ω</sup> × *λ*<sup>ω</sup> where *κ* and *λ* are equipped with the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) (and all closed sets in *κ*<sup>ω</sup> × *λ*<sup>ω</sup> come in this way from some tree on *κ* × *λ*), *λ*-Suslin subsets of *κ*<sup>ω</sup> are projections of closed subsets in *κ*<sup>ω</sup> × *λ*<sup>ω</sup>.

When one talks of *Suslin sets* without specifying the space, then one usually means Suslin subsets of **R**, which [descriptive set theorists](wikipedia://en/396619) usually take to be the set ω<sup>ω</sup>.
