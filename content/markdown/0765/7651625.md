# Diagram (category theory)

::: {#o1 .subject cue=lead name="Diagram"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **diagram** is the categorical analogue of an [indexed family](wikipedia://en/23624339) in [set theory](wikipedia://en/27553). The primary difference is that in the categorical setting one has [morphisms](wikipedia://en/27716891) that also need indexing. An indexed [family of sets](wikipedia://en/723043) is a collection of sets, indexed by a fixed set; equivalently, a *function* from a fixed index *set* to the class of *sets*. A diagram is a collection of objects and morphisms, indexed by a fixed category; equivalently, a *functor* from a fixed index *category* to some *category*.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, a **diagram** of type *J* in a [category](wikipedia://en/53759) *C* is a ([covariant](https://en.wikipedia.org/wiki/Covariance_and_contravariance_of_functors)) [functor](wikipedia://en/10987) *D* : *J* → *C.* The category *J* is called the **index category** or the **scheme** of the diagram *D*; the functor is sometimes called a ***J*-shaped diagram**.[^o4] The actual objects and morphisms in *J* are largely irrelevant; only the way in which they are interrelated matters. The diagram *D* is thought of as indexing a collection of objects and morphisms in *C* patterned on *J*.

Although, technically, there is no difference between an individual *diagram* and a *functor* or between a *scheme* and a *category*, the change in terminology reflects a change in perspective, just as in the set theoretic case: one fixes the index category, and allows the functor (and, secondarily, the target category) to vary.

One is most often interested in the case where the scheme *J* is a [small](https://en.wikipedia.org/wiki/Small_category) or even [finite](wikipedia://en/11742) category. A diagram is said to be **small** or **finite** whenever *J* is.

A morphism of diagrams of type *J* in a category *C* is a [natural transformation](wikipedia://en/45022) between functors. One can then interpret the **category of diagrams** of type *J* in *C* as the [functor category](wikipedia://en/407039) *C*<sup>*J*</sup>, and a diagram is then an object in this category.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- Given any object *A* in *C*, one has the **constant diagram**, which is the diagram that maps all objects in *J* to *A*, and all morphisms of *J* to the identity morphism on *A*. Notationally, one often uses an underbar to denote the constant diagram: thus, for any object $A$ in *C*, one has the constant diagram $\underline A$.
- If *J* is a (small) [discrete category](wikipedia://en/808519), then a diagram of type *J* is essentially just an [indexed family](wikipedia://en/23624339) of objects in *C* (indexed by *J*). When used in the construction of the [limit](wikipedia://en/39248), the result is the [product](wikipedia://en/237868); for the colimit, one gets the [coproduct](wikipedia://en/310889). So, for example, when *J* is the discrete category with two objects, the resulting limit is just the binary product.
- If *J* = −1 ← 0 → +1, then a diagram of type *J* (*A* ← *B* → *C*) is a [span](wikipedia://en/10318351), and its colimit is a [pushout](wikipedia://en/582024). If one were to "forget" that the diagram had object *B* and the two arrows *B* → *A*, *B* → *C*, the resulting diagram would simply be the discrete category with the two objects *A* and *C*, and the colimit would simply be the binary coproduct. Thus, this example shows an important way in which the idea of the diagram generalizes that of the [index set](wikipedia://en/393055) in set theory: by including the morphisms *B* → *A*, *B* → *C*, one discovers additional structure in constructions built from the diagram, structure that would not be evident if one only had an index set with no relations between the objects in the index.
- [Dual](wikipedia://en/310885) to the above, if *J* = −1 → 0 ← +1, then a diagram of type *J* (*A* → *B* ← *C*) is a [cospan](https://en.wikipedia.org/wiki/Cospan), and its limit is a [pullback](wikipedia://en/841689).
- The index $J = 0 \rightrightarrows 1$ is called "two parallel morphisms", or sometimes the [free quiver](https://en.wikipedia.org/wiki/Free_quiver) or the [walking quiver](https://en.wikipedia.org/wiki/Walking_quiver). A diagram of type $J$ $(f,g\colon X \to Y)$ is then a [quiver](wikipedia://en/355100); its limit is an [equalizer](wikipedia://en/310767), and its colimit is a [coequalizer](wikipedia://en/431940).
- If *J* is a [poset category](https://en.wikipedia.org/wiki/Poset_category), then a diagram of type *J* is a family of objects *D*<sub>*i*</sub> together with a unique morphism *f*<sub>*ij*</sub> : *D*<sub>*i*</sub> → *D*<sub>*j*</sub> whenever *i* ≤ *j*. If *J* is [directed](wikipedia://en/9165) then a diagram of type *J* is called a [direct system](https://en.wikipedia.org/wiki/Direct_system_%28mathematics%29) of objects and morphisms. If the diagram is [contravariant](https://en.wikipedia.org/wiki/Contravariant_functor) then it is called an [inverse system](https://en.wikipedia.org/wiki/Inverse_system).

:::

## Cones and limits {#Cones_and_limits}

A [cone](wikipedia://en/7533645) with vertex *N* of a diagram *D* : *J* → *C* is a morphism from the constant diagram Δ(*N*) to *D*. The constant diagram is the diagram which sends every object of *J* to an object *N* of *C* and every morphism to the identity morphism on *N*.

The [limit](wikipedia://en/39248) of a diagram *D* is a [universal cone](https://en.wikipedia.org/wiki/Universal_cone) to *D*. That is, a cone through which all other cones uniquely factor. If the limit exists in a category *C* for all diagrams of type *J* one obtains a functor lim : *C*<sup>*J*</sup> → *C* which sends each diagram to its limit.

Dually, the [colimit](https://en.wikipedia.org/wiki/Colimit) of diagram *D* is a universal cone from *D*. If the colimit exists for all diagrams of type *J* one has a functor colim : *C*<sup>*J*</sup> → *C* which sends each diagram to its colimit.

The universal functor of a diagram is the [diagonal functor](wikipedia://en/4606683); its [right adjoint](wikipedia://en/53991) is the limit and its left adjoint is the colimit.[^o8] A cone can be thought of as a [natural transformation](wikipedia://en/45022) from the diagonal functor to some arbitrary diagram.

## Commutative diagrams {#Commutative_diagrams}

Diagrams and functor categories are often visualized by [commutative diagrams](https://en.wikipedia.org/wiki/Commutative_diagrams), particularly if the index category is a finite [poset category](https://en.wikipedia.org/wiki/Poset_category) with few elements: one draws a commutative diagram with a node for every object in the index category, and an arrow for a generating set of morphisms, omitting identity maps and morphisms that can be expressed as compositions. The commutativity corresponds to the uniqueness of a map between two objects in a poset category. Conversely, every commutative diagram represents a diagram (a functor from a poset index category) in this way.

Not every diagram commutes, as not every index category is a poset category: most simply, the diagram of a single object with an endomorphism ($f\colon X \to X$), or with two parallel arrows ($\bullet \rightrightarrows \bullet$; $f,g\colon X \to Y$) need not commute. Further, diagrams may be impossible to draw (because they are infinite) or simply messy (because there are too many objects or morphisms); however, schematic commutative diagrams (for subcategories of the index category, or with ellipses, such as for a directed system) are used to clarify such complex diagrams.
