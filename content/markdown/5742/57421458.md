# Binomial process

::: {#o1 .subject cue=lead name="Binomial process"}

A **binomial process** is a special [point process](wikipedia://en/2147685) in [probability theory](wikipedia://en/23542).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $P$ be a [probability distribution](wikipedia://en/23543) and $n$ be a fixed natural number. Let $X_1, X_2, \dots, X_n$ be [i.i.d.](https://en.wikipedia.org/wiki/I.i.d.) random variables with distribution $P$, so $X_i \sim P$ for all $i \in \{1, 2, \dots, n \}$.

Then the binomial process based on *n* and *P* is the [random measure](wikipedia://en/10040846)

$$\xi= \sum_{i=1}^n \delta_{X_i},$$

where $\delta_{X_i(A)}=\begin{cases}1, &\text{if }X_i\in A,\\ 0, &\text{otherwise}.\end{cases}$

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Name {#Name}

The name of a binomial process is derived from the fact that for all measurable sets $A$ the [random variable](wikipedia://en/25685) $\xi(A)$ follows a [binomial distribution](wikipedia://en/3876) with parameters $P(A)$ and $n$:

$$\xi(A) \sim \operatorname{Bin}(n,P(A)).$$

### Laplace-transform {#Laplace-transform}

The [Laplace transform](wikipedia://en/18610) of a binomial process is given by

$$\mathcal L_{P,n}(f)= \left[ \int \exp(-f(x)) \mathrm P(dx) \right]^n$$

for all positive measurable functions $f$.

### Intensity measure {#Intensity_measure}

The [intensity measure](wikipedia://en/56214154) $\operatorname{E}\xi$ of a binomial process $\xi$ is given by

$$\operatorname{E}\xi =n P.$$

:::

::: {#o10 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

A generalization of binomial processes are [mixed binomial processes](wikipedia://en/57907267). In these point processes, the number of points is not deterministic like it is with binomial processes, but is determined by a random variable $K$. Therefore, mixed binomial processes conditioned on $K=n$ are binomial process based on $n$ and $P$.

:::
