# Completely uniformizable space

::: {#o1 .subject cue=lead name="Completely uniformizable space"}

In [mathematics](wikipedia://en/18831), a [topological space](wikipedia://en/30450) (*X*, *T*) is called **completely uniformizable**[^o2] (or **Dieudonné complete**[^o3]) if there exists at least one [complete uniformity](wikipedia://en/32339) that induces the topology *T*. Some authors[^o4] additionally require *X* to be [Hausdorff](wikipedia://en/13637). Some authors have called these spaces **topologically complete**,[^o5] although that term has also been used in other meanings like *[completely metrizable](https://en.wikipedia.org/wiki/Completely_metrizable)*, which is a stronger property than *completely uniformizable*.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every completely uniformizable space is [uniformizable](https://en.wikipedia.org/wiki/Uniformizable) and thus [completely regular](https://en.wikipedia.org/wiki/Completely_regular).
- A completely regular space *X* is completely uniformizable if and only if the [fine uniformity](https://en.wikipedia.org/wiki/Fine_uniformity) on *X* is complete.[^o8]
- Every [regular](wikipedia://en/53058) [paracompact](https://en.wikipedia.org/wiki/Paracompact) space (in particular, every Hausdorff paracompact space) is completely uniformizable.[^o9][^o10]
- (Shirota's theorem) A completely regular Hausdorff space is [realcompact](https://en.wikipedia.org/wiki/Realcompact) if and only if it is completely uniformizable and contains no closed discrete subspace of [measurable cardinality](wikipedia://en/248102).[^o11]

Every [metrizable space](wikipedia://en/19738) is paracompact, hence completely uniformizable. As there exist metrizable spaces that are not [completely metrizable](https://en.wikipedia.org/wiki/Completely_metrizable), complete uniformizability is a strictly weaker condition than complete metrizability.

:::
