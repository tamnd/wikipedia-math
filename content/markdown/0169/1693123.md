# Triple bar

::: {#o3 .subject cue=lead name="Triple bar"}

The **triple bar** or **tribar**, **≡**, is a symbol with multiple, context-dependent meanings indicating equivalence of two different things. Its main uses are in mathematics and logic. It has the appearance of an [equals sign](wikipedia://en/501828) $\langle =\rangle$ with a third line.

:::

## Encoding {#Encoding}

The triple bar character in [Unicode](https://en.wikipedia.org/wiki/Unicode) is code point 2261.[^o5] The closely related code point 2262 is the same symbol with a slash through it, indicating the negation of its mathematical meaning.[^o5]

In [LaTeX](https://en.wikipedia.org/wiki/LaTeX) mathematical formulas, the code `\equiv` produces the triple bar symbol and `\not\equiv` produces the negated triple bar symbol $\not\equiv$ as output.[^o6]

::: {#o8 .application cue=heading name="Uses"}

## Uses {#Uses}

### Mathematics and philosophy {#Mathematics_and_philosophy}

In [logic](wikipedia://en/46426065), it is used with two different but related meanings. It can refer to the [if and only if](wikipedia://en/14922) connective, also called material equivalence.[^o10] This is a [binary operation](wikipedia://en/3948) whose value is true when its two arguments have the same value as each other.[^o11] Alternatively, in some texts ⇔ is used with this meaning, while ≡ is used for the higher-level [metalogical](wikipedia://en/387934) notion of [logical equivalence](wikipedia://en/169324), according to which two formulas are logically equivalent when all [models](https://en.wikipedia.org/wiki/Model_%28logic%29) give them the same value.[^o12] [Gottlob Frege](wikipedia://en/48416) used a triple bar for a more philosophical notion of identity, in which two statements (not necessarily in mathematics or formal logic) are identical if they can be freely substituted for each other without change of meaning.[^o13]

In mathematics, the triple bar is sometimes used as a symbol of [identity](wikipedia://en/298428) or an [equivalence relation](wikipedia://en/9259) (although not the only one; other common choices include ~ and ≈).[^o14][^o15] Particularly, in [geometry](wikipedia://en/18973446), it may be used either to show that two figures are [congruent](wikipedia://en/39330) or that they are identical.[^o16] In number theory, it has been used beginning with [Carl Friedrich Gauss](wikipedia://en/6125) (who first used it with this meaning in 1801) to mean [modular congruence](wikipedia://en/20087): $a \equiv b \pmod N$ if *N* divides *a* − *b*.[^o17][^o18]

In [category theory](wikipedia://en/5869), triple bars may be used to connect objects in a [commutative diagram](wikipedia://en/138484), indicating that they are actually the same object rather than being connected by an arrow of the category.[^o19]

This symbol is also sometimes used in place of an equal sign for equations that define the symbol on the [left-hand side](https://en.wikipedia.org/wiki/Left-hand_side) of the equation, to contrast them with equations in which the terms on both sides of the equation were already defined.[^o20] An alternative notation for this usage is to typeset the letters "def" above an ordinary equality sign, $a\mathrel{\stackrel{\scriptscriptstyle \mathrm{def}}{=}}b$.[^o21] Similarly, another alternative notation for this usage is to precede the equals sign with a colon, $a:=b$. The colon notation has the advantage that it reflects the inherent asymmetry in the definition of one object from already defined objects.

### Science {#Science}

In [botanical nomenclature](https://en.wikipedia.org/wiki/Botanical_nomenclature), the triple bar denotes homotypic [synonyms](https://en.wikipedia.org/wiki/Synonym_%28taxonomy%29) (those based on the same [type specimen](https://en.wikipedia.org/wiki/Type_specimen)), to distinguish them from heterotypic synonyms (those based on different type specimens), which are marked with an [equals sign](wikipedia://en/501828).[^o23]

In [chemistry](https://en.wikipedia.org/wiki/Chemistry), the triple bar can be used to represent a [triple bond](https://en.wikipedia.org/wiki/Triple_bond) between atoms. For example, HC≡CH is a common shorthand for [acetylene](https://en.wikipedia.org/wiki/Acetylene)[^o24] (systematic name: ethyne).

### Programming {#Programming}

In the [APL](https://en.wikipedia.org/wiki/APL_%28programming_language%29) programming language, the `≡` and `≢` symbols are used to compare to two arrays for equality and inequality respectively. This is in contrast to the symbols `=` and `≠` which compares the individual elements in an order array with the elements of another array.

### Application design {#Application_design}

In [mobile](https://en.wikipedia.org/wiki/Mobile_app), [web](https://en.wikipedia.org/wiki/Website), and general [application](https://en.wikipedia.org/wiki/Application_software) design, a similar symbol is sometimes used as an interface element, where it is called a [hamburger icon](https://en.wikipedia.org/wiki/Hamburger_button). The element typically indicates that a [navigation menu](https://en.wikipedia.org/wiki/Web_navigation) can be accessed when the element is activated; the bars of the symbol may be seen as stylized menu items, and some variations of this symbols add more bars, or bullet points to each bar, to enhance this visual similarity.[^o27] Usage of this symbol dates back to the early computer interfaces developed at [Xerox PARC](https://en.wikipedia.org/wiki/Xerox_PARC) in the 1980s.[^o28] It is also similar to the icon frequently used to indicate [justified text alignment](https://en.wikipedia.org/wiki/Text_justification). It is an oft-used component of [Google](https://en.wikipedia.org/wiki/Google)'s [Material Design](https://en.wikipedia.org/wiki/Material_Design) guidelines and many [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29) apps and web apps that follow these guidelines make use of the hamburger menu.
