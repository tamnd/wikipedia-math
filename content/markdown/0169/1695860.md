# Authentication and Key Agreement

::: {#o1 .subject cue=lead name="Authentication and Key Agreement"}

**Authentication and Key Agreement** (**AKA**) is a [security protocol](https://en.wikipedia.org/wiki/Security_protocol) used in [3G](https://en.wikipedia.org/wiki/3G) networks. AKA is also used for [one-time password](wikipedia://en/1190077) generation mechanism for [digest access authentication](wikipedia://en/1381205). AKA is a [challenge–response](https://en.wikipedia.org/wiki/Challenge–response) based mechanism that uses [symmetric cryptography](wikipedia://en/53042).

:::

## AKA in CDMA {#AKA_in_CDMA}

AKA – Authentication and Key Agreement a.k.a. 3G Authentication, Enhanced Subscriber Authorization (ESA).

The basis for the 3G authentication mechanism, defined as a successor to [CAVE-based authentication](https://en.wikipedia.org/wiki/CAVE-based_authentication), AKA provides procedures for [mutual authentication](wikipedia://en/3064285) of the Mobile Station ([MS](https://en.wikipedia.org/wiki/Station_%28networking%29)) and serving system. The successful execution of AKA results in the establishment of a security association (i.e., set of security data) between the MS and serving system that enables a set of security services to be provided.

Major advantages of AKA over CAVE-based authentication include:

- Larger authentication keys (128-bit )
- Stronger hash function ([SHA-1](wikipedia://en/26672))
- Support for mutual authentication
- Support for signaling message data integrity
- Support for signaling information encryption
- Support for user data encryption
- Protection from rogue MS when dealing with [R-UIM](https://en.wikipedia.org/wiki/Removable_User_Identity_Module)

AKA is not yet implemented in [CDMA2000](wikipedia://en/481213) networks, although it is expected to be used for [IMS](https://en.wikipedia.org/wiki/IP_Multimedia_Subsystem). To ensure interoperability with current devices and partner networks, support for AKA in CDMA networks and handsets will likely be in addition to CAVE-based authentication.

Air interface support for AKA is included in all releases following CDMA2000 Rev C.

TIA-41 MAP support for AKA was defined in TIA-945 ([3GPP2](https://en.wikipedia.org/wiki/3GPP2) X.S0006), which has been integrated into TIA-41 (3GPP2 X.S0004).

For information on AKA in roaming, see CDG Reference Document #138.

## AKA in UMTS {#AKA_in_UMTS}

AKA a mechanism which performs authentication and session key distribution in [Universal Mobile Telecommunications System](https://en.wikipedia.org/wiki/Universal_Mobile_Telecommunications_System) (UMTS) networks. AKA is a challenge–response based mechanism that uses [symmetric cryptography](https://en.wikipedia.org/wiki/Symmetric_cryptography). AKA is typically run in a UMTS [IP Multimedia Services Identity Module](https://en.wikipedia.org/wiki/IP_Multimedia_Services_Identity_Module) (ISIM), which is an application on a [UICC](https://en.wikipedia.org/wiki/Universal_integrated_circuit_card) (Universal Integrated Circuit Card). AKA is defined in RFC 3310.
