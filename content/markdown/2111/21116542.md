# Generalized map

::: {#o1 .subject cue=lead name="Generalized map"}

In mathematics, a **generalized map** is a [topological](wikipedia://en/29954) model which allows one to represent and to handle subdivided objects. This model was defined starting from [combinatorial maps](wikipedia://en/21105530) in order to represent non-orientable and open subdivisions, which is not possible with combinatorial maps. The main advantage of generalized map is the homogeneity of one-to-one mappings in any dimensions, which simplifies definitions and algorithms comparing to combinatorial maps. For this reason, generalized maps are sometimes used instead of combinatorial maps, even to represent orientable closed partitions.

:::

Like combinatorial maps, generalized maps are used as efficient data structure in image representation and processing, in geometrical modeling, they are related to [simplicial set](wikipedia://en/1027784) and to [combinatorial topology](wikipedia://en/363400), and this is a [boundary representation](https://en.wikipedia.org/wiki/Boundary_representation) model (B-rep or BREP), i.e. it represents object by its boundaries.

::: {#o3 .definition cue=heading name="General definition"}

## General definition {#General_definition}

The definition of generalized map in any dimension is given in [^o4] and:[^o5]

A *n*D generalized map (or *n*G-map) is an (*n* + 2)-tuple *G* = (*D*, *α*<sub>0</sub>, ..., *α*<sub>*n*</sub>) such that:

- *D* is a finite set of darts;
- *α*<sub>0</sub>, ..., *α*<sub>*n*</sub> are [involutions](wikipedia://en/293450) on *D*;
- *α*<sub>*i*</sub> o *α*<sub>*j*</sub> is an involution if *i* + 2 ≤ *j* (*i*, *j* ∈ { 0, ,..., *n* }).

An *n*D generalized map represents the subdivision of an open or closed orientable or not *n*D space.

:::
