# Cyclomatic number

::: {#o1 .subject cue=lead name="Cyclomatic number"}

*Image: 6n-graf.svg.* This graph has cyclomatic number $r = 2$ because it can be made into a tree by removing two edges, for instance the edges 1–2 and 2–3, but removing any one edge leaves a cycle in the graph.

In [graph theory](wikipedia://en/12401), a branch of [mathematics](wikipedia://en/18831), the **cyclomatic number**, **circuit rank**, **cycle rank**, **corank** or **nullity** of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is the minimum number of edges that must be removed from the graph to break all its [cycles](wikipedia://en/168609), making it into a [tree](wikipedia://en/48560) or [forest](https://en.wikipedia.org/wiki/Forest_%28graph_theory%29).

:::

The concept was introduced and called the cyclomatic number by [Gustav Kirchhoff](https://en.wikipedia.org/wiki/Gustav_Kirchhoff).[^o2][^o3]

::: {#o5 .statement cue=named-heading name="Formula"}

## Formula {#Formula}

The cyclomatic number of a graph equals the number of independent cycles in the graph, the size of a [cycle basis](wikipedia://en/24778911). Unlike the corresponding [feedback arc set](wikipedia://en/1860374) problem for [directed graphs](wikipedia://en/19721986), the cyclomatic number $r$ is easily computed using the formula:

$$r = e - v + c,$$

where $e$ is the number of edges in the given graph, $v$ is the number of [vertices](wikipedia://en/638899), and $c$ is the number of [connected components](wikipedia://en/246223). [^o6]

It is possible to construct a minimum-size set of edges that breaks all cycles efficiently, either using a [greedy algorithm](wikipedia://en/89247) or by complementing a [spanning forest](https://en.wikipedia.org/wiki/Spanning_forest).

The cyclomatic number can be explained in terms of [algebraic graph theory](wikipedia://en/1620216) as the [dimension](wikipedia://en/38267) of the [cycle space](wikipedia://en/262243) of the graph, in terms of [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory) as the dual rank of its [graphic matroid](wikipedia://en/745714), and in terms of [topology](wikipedia://en/29954) as one of the [Betti numbers](wikipedia://en/346262) of a [topological space](wikipedia://en/30450) derived from the graph. It counts the ears in an [ear decomposition](wikipedia://en/32183016) of the graph, forms the basis of [parameterized complexity](wikipedia://en/603026) on almost-trees, and has been applied in [software metrics](https://en.wikipedia.org/wiki/Software_metric) as part of the definition of [cyclomatic complexity](https://en.wikipedia.org/wiki/Cyclomatic_complexity) of a piece of code.

:::

## For hypergraphs {#For_hypergraphs}

The cyclomatic number of a [hypergraph](wikipedia://en/232535) can be derived by its [Levi graph](wikipedia://en/1396888), with the same cyclomatic number but reduced to a simple graph. It is

$$r = g - (v + e) + c,$$

where $g$ is the [degree sum](wikipedia://en/9607933) (and the number of edges in the Levi graph), $e$ is the number of hyperedges in the given hypergraph, $v$ is the number of [vertices](wikipedia://en/638899), and $c$ is the number of [connected components](wikipedia://en/246223).

The *degree sum* of a hypergraph is the sum of the degrees of all the vertices, reducing to $2e$ for a simple graph, or $ke$ for a $k$-uniform hypergraph. This formula is symmetric between vertices and edges which demonstrates a hypergraph and its dual hypergraph have the same cyclomatic number.

## Matroid rank and construction of a minimum feedback edge set {#Matroid_rank_and_construction_of_a_minimum_feedback_edge_set}

The cyclomatic number of a graph $G$ may be described using [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory) as the [dual rank](wikipedia://en/37123010) of the [graphic matroid](wikipedia://en/745714) of $G$.[^o9] Using the greedy property of matroids, this means that one can find a minimum set of edges that breaks all cycles using a [greedy algorithm](wikipedia://en/89247) that at each step chooses an edge that belongs to at least one cycle of the remaining graph.

Alternatively, a minimum set of edges that breaks all cycles can be found by constructing a maximal [forest](https://en.wikipedia.org/wiki/Forest) of $G$ and choosing the [complementary](wikipedia://en/54347) set of edges that do not belong to the maximal forest.

## The number of independent cycles {#The_number_of_independent_cycles}

In [algebraic graph theory](wikipedia://en/1620216), the cyclomatic number is also the dimension of the [cycle space](wikipedia://en/262243) of $G$. Intuitively, this can be explained as meaning that the cyclomatic number counts the number of independent cycles in the graph, where a collection of cycles is independent if it is not possible to form one of the cycles as the [symmetric difference](wikipedia://en/262288) of some subset of the others.[^o6]

This count of independent cycles can also be explained using [homology theory](https://en.wikipedia.org/wiki/Homology_theory), a branch of topology. Any graph $G$ may be viewed as an example of a 1-dimensional [simplicial complex](wikipedia://en/252686), a type of topological space formed by representing each graph edge by a [line segment](wikipedia://en/22634860) and gluing these line segments together at their endpoints. The cyclomatic number is the [rank](wikipedia://en/244541) of the first ([integer](wikipedia://en/14563)) [homology group](https://en.wikipedia.org/wiki/Homology_group) of this complex,[^o11]

$$r = \operatorname{rank}\left[H_1(G,\mathbb{Z})\right].$$

Because of this topological connection, the cyclomatic number of a graph $G$ is also called the **first [Betti number](wikipedia://en/346262)** of $G$.[^o12] More generally, the first Betti number of any topological space, defined in the same way, counts the number of independent cycles in the space.

## Applications {#Applications}

### Meshedness coefficient {#Meshedness_coefficient}

A variant of the cyclomatic number for [planar graphs](wikipedia://en/24314), normalized by dividing by the maximum possible cyclomatic number of any planar graph with the same vertex set, is called the [meshedness coefficient](wikipedia://en/44403623). For a connected planar graph with $m$ edges and $n$ vertices, the meshedness coefficient can be computed by the formula[^o16]

$$\frac{m-n+1}{2n-5}.$$

Here, the numerator $m-n+1$ of the formula is the cyclomatic number of the given graph, and the denominator $2n-5$ is the largest possible cyclomatic number of an $n$-vertex planar graph. The meshedness coefficient ranges between 0 for trees and 1 for [maximal planar graphs](https://en.wikipedia.org/wiki/Maximal_planar_graph).

### Ear decomposition {#Ear_decomposition}

The cyclomatic number controls the number of ears in an [ear decomposition](wikipedia://en/32183016) of a graph, a partition of the edges of the graph into paths and cycles that is useful in many graph algorithms. In particular, a graph is [2-vertex-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph) if and only if it has an open ear decomposition. This is a sequence of subgraphs, where the first subgraph is a simple cycle, the remaining subgraphs are all simple paths, each path starts and ends on vertices that belong to previous subgraphs, and each internal vertex of a path appears for the first time in that path. In any biconnected graph with circuit rank $r$, every open ear decomposition has exactly $r$ ears.[^o18]

### Almost-trees {#Almost-trees}

A graph with cyclomatic number $r$ is also called an $r$*\-almost-tree*, because only $r$ edges need to be removed from the graph to make it into a tree or forest. A 1-almost-tree is a *near-tree*, and a connected near-tree is a [pseudotree](wikipedia://en/13511542), a cycle with a (possibly trivial) tree rooted at each vertex.[^o20]

Several authors have studied the [parameterized complexity](wikipedia://en/603026) of graph algorithms on $r$-near-trees, parameterized by $r$.[^o21][^o22]

### Generalizations to directed graphs {#Generalizations_to_directed_graphs}

The [cycle rank](wikipedia://en/25646409) is an invariant of [directed graphs](wikipedia://en/19721986) that measures the level of nesting of cycles in the graph. It has a more complicated definition than cyclomatic number (closely related to the definition of [tree-depth](https://en.wikipedia.org/wiki/Tree-depth) for undirected graphs) and is more difficult to compute. Another problem for directed graphs related to the cyclomatic number is the minimum [feedback arc set](wikipedia://en/1860374), the smallest set of edges whose removal breaks all directed cycles. Both cycle rank and the minimum feedback arc set are [NP-hard](https://en.wikipedia.org/wiki/NP-hard) to compute.

It is also possible to compute a simpler invariant of directed graphs by ignoring the directions of the edges and computing the circuit rank of the underlying undirected graph. This principle forms the basis of the definition of [cyclomatic complexity](https://en.wikipedia.org/wiki/Cyclomatic_complexity), a software metric for estimating how complicated a piece of computer code is.

::: {#o25 .pointer-item cue=pointer name="Frerejacque number"}

### Computational chemistry {#Computational_chemistry}

In the fields of [chemistry](https://en.wikipedia.org/wiki/Chemistry) and [cheminformatics](https://en.wikipedia.org/wiki/Cheminformatics), the cyclomatic number of a [molecular graph](https://en.wikipedia.org/wiki/Molecular_graph) (the number of [rings](https://en.wikipedia.org/wiki/Ring_%28chemistry%29) in the [smallest set of smallest rings](https://en.wikipedia.org/wiki/Smallest_set_of_smallest_rings)) is sometimes referred to as the **Frèrejacque number**.[^o26][^o27][^o28]

:::

### Parametrized complexity {#Parametrized_complexity}

Some computational problems on graphs are NP-hard in general, but can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) for graphs with a small cyclomatic number. An example is the path reconfiguration problem.[^o30]

:::

## Related concepts {#Related_concepts}

Other numbers defined in terms of deleting things from graphs are:

- [Edge connectivity](wikipedia://en/4593774) - the minimum number of edges to delete in order to disconnect the graph;
- [Matching preclusion](wikipedia://en/27970912) - the minimum number of edges to delete in order to prevent the existence of a [perfect matching](wikipedia://en/44031);
- [Feedback vertex set](wikipedia://en/1860368) number - the minimum number of vertices to delete in order to make the graph acyclic;
- [Feedback arc set](wikipedia://en/1860374) - the minimum number of arcs to delete from a directed graph, in order to make it acyclic.
