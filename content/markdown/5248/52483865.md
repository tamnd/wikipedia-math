# Erdős–Ulam problem

::: {#o1 .subject cue=lead name="Erdős–Ulam problem"}

::: {#o2 .problem cue=unsolved}

Is there a [dense set](wikipedia://en/23523594) of points in the plane at rational distances from each other?

:::

In [mathematics](wikipedia://en/18831), the **Erdős–Ulam problem** asks whether the plane contains a [dense set](wikipedia://en/23523594) of points whose [Euclidean distances](wikipedia://en/53932) are all [rational numbers](wikipedia://en/19727024). It is named after [Paul Erdős](wikipedia://en/601284) and [Stanislaw Ulam](https://en.wikipedia.org/wiki/Stanislaw_Ulam).

:::

## Large point sets with rational distances {#Large_point_sets_with_rational_distances}

The [Erdős–Anning theorem](wikipedia://en/12600251) states that a set of points with [integer](wikipedia://en/14563) distances must either be [finite](wikipedia://en/11742) or lie on a single line.[^o4] However, there are other infinite sets of points with rational distances. For instance, on the [unit circle](wikipedia://en/27072071), let *S* be the set of points

$$(\cos\theta,\sin\theta)$$

where $\theta$ is restricted to values that cause $\tan\tfrac{\theta}{4}$ to be a rational number. For each such point, both $\sin\tfrac{\theta}{2}$ and $\cos\tfrac\theta 2$ are themselves both rational, and if $\theta$ and $\varphi$ define two points in *S*, then their distance is the rational number

$$\left| 2\sin\frac \theta 2 \cos\frac \varphi 2 -2\sin\frac \varphi 2 \cos\frac \theta 2 \right|.$$

More generally, a circle with [radius](wikipedia://en/1780815) $\rho$ contains a dense set of points at rational distances to each other [if and only if](wikipedia://en/14922) $\rho^2$ is rational.[^o5] However, these sets are only dense on their circle, not dense on the whole plane.

## History and partial results {#History_and_partial_results}

In 1946, [Stanislaw Ulam](https://en.wikipedia.org/wiki/Stanislaw_Ulam) asked whether there exists a set of points at rational distances from each other that forms a [dense subset](wikipedia://en/23523594) of the [Euclidean plane](wikipedia://en/15575410).[^o5] While the answer to this question is still [open](wikipedia://en/1333335), [József Solymosi](https://en.wikipedia.org/wiki/József_Solymosi) and Frank de Zeeuw showed that the only irreducible [algebraic curves](wikipedia://en/253260) that contain infinitely many points at rational distances are lines and circles.[^o7] [Terence Tao](wikipedia://en/1118498) and Jafar Shaffaf independently observed that, if the [Bombieri–Lang conjecture](wikipedia://en/3142105) is true, the same methods would show that there is no infinite dense set of points at rational distances in the plane.[^o8][^o9] Using different methods, [Hector Pasten](https://en.wikipedia.org/wiki/Hector_Pasten) [proved](wikipedia://en/82285) that the [abc conjecture](wikipedia://en/174108) also implies a negative solution to the Erdős–Ulam problem.[^o10]

## Consequences {#Consequences}

If the Erdős–Ulam problem has a positive solution, it would provide a [counterexample](wikipedia://en/143151) to the Bombieri–Lang[^o8][^o9] conjecture and to the abc conjecture.[^o10] It would also solve [Harborth's conjecture](wikipedia://en/44342842), on the existence of drawings of [planar graphs](wikipedia://en/24314) in which all distances are integers. If a dense rational-distance set exists, any straight-line drawing of a planar graph could be perturbed by a small amount (without introducing crossings) to use points from this set as its vertices, and then scaled to make the distances integers. However, like the Erdős–Ulam problem, Harborth's conjecture remains unproven.
