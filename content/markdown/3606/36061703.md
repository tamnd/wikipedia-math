# Elongated pyramid

::: {#o2 .subject cue=lead name="Elongated pyramid"}

In [geometry](wikipedia://en/18973446), the **elongated pyramids** are an infinite set of [polyhedra](https://en.wikipedia.org/wiki/Polyhedra), constructed by adjoining an $n$-gonal [pyramid](wikipedia://en/3307045) to an $n$-gonal [prism](wikipedia://en/283007). Along with the set of pyramids, these figures are topologically [self-dual](https://en.wikipedia.org/wiki/Self-dual_polyhedron).

:::

There are three *elongated pyramids* that are [Johnson solids](wikipedia://en/16034):

- [Elongated triangular pyramid](wikipedia://en/1177937) ($J_{7}$),
- [Elongated square pyramid](wikipedia://en/1177939) ($J_{8}$), and
- [Elongated pentagonal pyramid](wikipedia://en/1123547) ($J_{9}$).

Higher forms can be constructed with [isosceles triangles](wikipedia://en/315428).
