# Lefschetz theorem on (1,1)-classes

::: {#o1 .subject cue=lead name="Lefschetz theorem on (1,1)-classes"}

In [algebraic geometry](wikipedia://en/1997), a branch of [mathematics](wikipedia://en/18831), the **Lefschetz theorem on (1,1)-classes**, named after [Solomon Lefschetz](wikipedia://en/384384), is a classical statement relating holomorphic [line bundles](wikipedia://en/361366) on a [compact](wikipedia://en/6042) [Kähler manifold](wikipedia://en/390538) to classes in its integral [cohomology](wikipedia://en/194060). It is the only case of the [Hodge conjecture](wikipedia://en/244518) which has been proved for all Kähler manifolds.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let *X* be a compact Kähler manifold. The first [Chern class](wikipedia://en/294349) *c*<sub>1</sub> gives a map from holomorphic line bundles to *H*<sup>2</sup>(*X*, **Z**). By [Hodge theory](wikipedia://en/501590), the [de Rham cohomology](wikipedia://en/221530) group *H*<sup>2</sup>(*X*, **C**) decomposes as a direct sum *H*<sup>0,2</sup>(*X*) ⊕ *H*<sup>1,1</sup>(*X*) ⊕ *H*<sup>2,0</sup>(*X*), and it can be proven that the image of *c*<sub>1</sub> lies in *H*<sup>1,1</sup>(*X*). The theorem says that the map to *H*<sup>2</sup>(*X*, **Z**) ∩ *H*<sup>1,1</sup>(*X*) is surjective.

In the special case where *X* is a [projective variety](wikipedia://en/320469), holomorphic line bundles are in bijection with linear equivalences class of [divisors](wikipedia://en/1693055), and given a divisor *D* on *X* with associated line bundle *O(D)*, the class *c*<sub>1</sub>(*O(D)*) is Poincaré dual to the homology class given by *D*. Thus, this establishes the usual formulation of the Hodge conjecture for divisors in projective varieties.

:::

::: {#o6 .proof cue=heading name="Proof using normal functions"}

## Proof using normal functions {#Proof_using_normal_functions}

Lefschetz's original proof[^o7] worked on projective surfaces and used normal functions, which were introduced by Poincaré. Suppose that *C*<sub>*t*</sub> is a pencil of curves on *X*. Each of these curves has a [Jacobian variety](wikipedia://en/489734) *JC*<sub>*t*</sub> (if a curve is singular, there is an appropriate generalized Jacobian variety). These can be assembled into a family $\mathcal{J}$, the Jacobian of the pencil, which comes with a projection map π to the base *T* of the pencil. A **normal function** is a (holomorphic) section of π.

Fix an embedding of *X* in **P**<sup>*N*</sup>, and choose a pencil of curves *C*<sub>*t*</sub> on *X*. For a fixed curve Γ on *X*, the intersection of Γ and *C*<sub>*t*</sub> is a divisor *p*<sub>1</sub>(*t*) + ... + *p*<sub>*d*</sub>(*t*) on *C*<sub>*t*</sub>, where *d* is the degree of *X*. Fix a base point *p*<sub>0</sub> of the pencil. Then the divisor *p*<sub>1</sub>(*t*) + ... + *p*<sub>*d*</sub>(*t*) − *dp*<sub>0</sub> is a divisor of degree zero, and consequently it determines a class ν<sub>Γ</sub>(*t*) in the Jacobian *JC*<sub>*t*</sub> for all *t*. The map from *t* to ν<sub>Γ</sub>(*t*) is a normal function.

[Henri Poincaré](wikipedia://en/48740) proved that for a general pencil of curves, all normal functions arose as ν<sub>Γ</sub>(*t*) for some choice of Γ. Lefschetz proved that any normal function determined a class in *H*<sup>2</sup>(*X*, **Z**) and that the class of ν<sub>Γ</sub> is the fundamental class of Γ. Furthermore, he proved that a class in *H*<sup>2</sup>(*X*, **Z**) is the class of a normal function if and only if it lies in *H*<sup>1,1</sup>. Together with Poincaré's existence theorem, this proves the theorem on (1,1)-classes.

:::

::: {#o9 .proof cue=heading name="Proof using sheaf cohomology"}

## Proof using sheaf cohomology {#Proof_using_sheaf_cohomology}

Because *X* is a complex manifold, it admits an [exponential sheaf sequence](wikipedia://en/1881339)[^o10]

$$0 \to \underline{\mathbf{Z}} \stackrel{2\pi i}{\longrightarrow} \mathcal{O}_X \stackrel{\operatorname{exp}}{\longrightarrow} \mathcal{O}_X^\times \to 0.$$

Taking [sheaf cohomology](wikipedia://en/1055357) of this exact sequence gives maps

$$H^1(X, \mathcal{O}_X^\times) \stackrel{c_1}{\to} H^2(X, \mathbf{Z}) \stackrel{i_*}{\to} H^2(X, \mathcal{O}_X).$$

The group Pic *X* of [line bundles](wikipedia://en/361366) on *X* is isomorphic to $H^1(X, \mathcal{O}_X^\times)$. The first Chern class map is *c*<sub>1</sub> by definition, so it suffices to show that $i_*$ is zero on *H*<sup>2</sup>(*X*, **Z**) ∩ *H*<sup>1,1</sup>(*X*).

Because *X* is Kähler, [Hodge theory](wikipedia://en/501590) implies that $H^2(X, \mathcal{O}_X) \cong H^{0,2}(X)$. However, $i_*$ factors through the map from *H*<sup>2</sup>(*X*, **Z**) to *H*<sup>2</sup>(*X*, **C**), and on *H*<sup>2</sup>(*X*, **C**), $i_*$ is the restriction of the projection onto *H*<sup>0,2</sup>(*X*). It follows that it is zero on *H*<sup>2</sup>(*X*, **Z**) ∩ *H*<sup>1,1</sup>(*X*), and consequently that the cycle class map is surjective.[^o11]

:::
