# Kuratowski's free set theorem

::: {#o1 .subject cue=lead name="Kuratowski's free set theorem"}

**Kuratowski's free set theorem**, named after [Kazimierz Kuratowski](wikipedia://en/46075), is a result of [set theory](wikipedia://en/27553), an area of [mathematics](wikipedia://en/18831). It was largely forgotten for decades, but has been applied recently in solving several [lattice theory](https://en.wikipedia.org/wiki/Lattice_theory) problems, such as the [congruence lattice problem](wikipedia://en/9755564).

:::

Denote by $[X]^{<\omega}$ the [set](wikipedia://en/26691) of all [finite subsets](wikipedia://en/11742) of a set $X$. Likewise, for a [positive integer](https://en.wikipedia.org/wiki/Positive_integer) $n$, denote by $[X]^n$ the set of all $n$-elements subsets of $X$. For a [mapping](wikipedia://en/516931) $\Phi\colon[X]^n\to[X]^{<\omega}$, we say that a [subset](wikipedia://en/27631) $U$ of $X$ is *free* (with respect to $\Phi$), if for any $n$-element subset $V$ of $U$ and any $u\in U\setminus V$, $u\notin\Phi(V)$. [Kuratowski](https://en.wikipedia.org/wiki/Kuratowski) published in 1951 the following result, which characterizes the [infinite](wikipedia://en/20110824) [cardinals](wikipedia://en/6173) of the form $\aleph_n$.

The theorem states the following. Let $n$ be a positive integer and let $X$ be a set. Then the [cardinality](wikipedia://en/6174) of $X$ is greater than or equal to $\aleph_n$ if and only if for every mapping $\Phi$ from $[X]^n$ to $[X]^{<\omega}$, there exists an $(n+1)$-element free subset of $X$ with respect to $\Phi$.

For $n=1$, Kuratowski's free set theorem is superseded by [Hajnal's set mapping theorem](https://en.wikipedia.org/wiki/Hajnal's_set_mapping_theorem).
