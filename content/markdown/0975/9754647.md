# Distributive homomorphism

::: {#o1 .subject cue=lead name="Distributive homomorphism"}

A [congruence](wikipedia://en/48167) θ of a [join-semilattice](wikipedia://en/755647) *S* is *monomial*, if the θ-[equivalence class](wikipedia://en/9260) of any element of *S* has a largest element. We say that θ is *distributive*, if it is a [join](https://en.wikipedia.org/wiki/Join_%28mathematics%29), in the [congruence lattice](wikipedia://en/680261) Con *S* of *S*, of monomial join-congruences of *S*.

:::

The following definition originates in Schmidt's 1968 work and was subsequently adjusted by Wehrung.

::: {#o2 .definition cue=inline-head name="Definition (weakly distributive homomorphisms)"}

**Definition (weakly distributive homomorphisms).** A homomorphism *μ* : *S* → *T* between join-semilattices *S* and *T* is *weakly distributive*, if for all *a, b* in *S* and all *c* in *T* such that *μ*(*c*) ≤ *a* ∨ *b*, there are elements *x* and *y* of *S* such that *c* ≤ *x* ∨ *y*, *μ*(*x*) ≤ *a*, and *μ*(*y*) ≤ *b*.

**Examples:**

(1) For an [algebra](wikipedia://en/45200) *B* and a *reduct* *A* of *B* (that is, an algebra with same underlying set as *B* but whose set of operations is a subset of the one of *B*), the canonical (∨, 0)-homomorphism from Con<sub>c</sub> *A* to Con<sub>c</sub> *B* is weakly distributive. Here, Con<sub>c</sub> *A* denotes the (∨, 0)-semilattice of all [compact congruences](wikipedia://en/680261) of *A*.

(2) For a [convex sublattice](wikipedia://en/469304) *K* of a lattice *L*, the canonical (∨, 0)-homomorphism from Con<sub>c</sub> *K* to Con<sub>c</sub> *L* is weakly distributive.

:::
