# Independence system

::: {#o1 .subject cue=lead name="Independence system"}

In [combinatorial](wikipedia://en/5170) [mathematics](wikipedia://en/18831), an **independence system** $S$ is a pair $(V, \mathcal{I})$, where $V$ is a finite [set](wikipedia://en/26691) and $\mathcal{I}$ is a collection of [subsets](wikipedia://en/27631) of $V$ (called the **independent sets** or **feasible sets**) with the following properties:

:::

1. The [empty set](wikipedia://en/9566) is independent, i.e., $\emptyset\in\mathcal{I}$. (Alternatively, at least one subset of $V$ is independent, i.e., $\mathcal{I}\neq\emptyset$.)
1. Every subset of an independent set is independent, i.e., for each $Y\subseteq X$, we have $X\in\mathcal{I}\Rightarrow Y\in\mathcal{I}$. This is sometimes called the **hereditary property**, or **downward-closedness**.

Another term for an independence system is an [abstract simplicial complex](wikipedia://en/723105).

## Relation to other concepts {#Relation_to_other_concepts}

- A pair $(V, \mathcal{I})$, where $V$ is a finite [set](wikipedia://en/26691) and $\mathcal{I}$ is a collection of [subsets](wikipedia://en/27631) of $V$, is also called a **[hypergraph](wikipedia://en/232535)**. When using this terminology, the elements in the set $V$ are called **vertices** and elements in the family $\mathcal{I}$ are called **hyperedges**. So an independence system can be defined shortly as a downward-closed hypergraph.
- An independence system with an additional property called the **[augmentation property](wikipedia://en/244321#Definition)** or the **independent set exchange property** yields a **[matroid](wikipedia://en/244321)**. The following expression summarizes the relations between the terms:HYPERGRAPHS $\supset$ INDEPENDENCE-SYSTEMS $=$ ABSTRACT-SIMPLICIAL-COMPLEXES $\supset$ MATROIDS.
