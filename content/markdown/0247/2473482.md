# Unit root test

::: {#o1 .subject cue=lead name="Unit root test"}

In [statistics](wikipedia://en/26685), a **unit root test** tests whether a [time series](wikipedia://en/406624) variable is non-stationary and possesses a [unit root](wikipedia://en/2398969). The null hypothesis is generally defined as the presence of a unit root and the alternative hypothesis is either [stationarity](wikipedia://en/329898), [trend stationarity](wikipedia://en/1512988) or explosive root depending on the test used.

:::

## General approach {#General_approach}

In general, the approach to unit root testing implicitly assumes that the time series to be tested $[y_t]_{t=1}^T$ can be written as,

$$y_t = D_t + z_t + \varepsilon_t$$

where,

- $D_t$ is the deterministic component (trend, seasonal component, etc.)
- $z_t$ is the stochastic component.
- $\varepsilon_t$ is the stationary error process.

The task of the test is to determine whether the stochastic component contains a unit root or is stationary.[^o3]

## Main tests {#Main_tests}

Other popular tests include:

- [augmented Dickey–Fuller test](wikipedia://en/3767048)[^o5]

this is valid in large samples.

- [Phillips–Perron test](wikipedia://en/24590400)
- [KPSS test](wikipedia://en/23453383)

here the null hypothesis is [trend stationarity](wikipedia://en/1512988) rather than the presence of a [unit root](wikipedia://en/329898).

- [ADF-GLS test](wikipedia://en/37048590)

Unit root tests are closely linked to [serial correlation](wikipedia://en/2724) tests. However, while all processes with a unit root will exhibit serial correlation, not all serially correlated time series will have a unit root. Popular serial correlation tests include:

- [Breusch–Godfrey test](wikipedia://en/17097662)
- [Ljung–Box test](wikipedia://en/6534294)
- [Durbin–Watson test](wikipedia://en/4864529)
