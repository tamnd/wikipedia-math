# Bayesian information criterion

::: {#o1 .subject cue=lead name="Bayesian information criterion"}

In [statistics](wikipedia://en/26685), the **Bayesian information criterion** (**BIC**) or **Schwarz information criterion** (also **SIC**, **SBC**, **SBIC**) is a criterion for [model selection](wikipedia://en/3664073) among a finite set of models; models with lower BIC are generally preferred. It is based, in part, on the [likelihood function](wikipedia://en/44968) and it is closely related to the [Akaike information criterion](wikipedia://en/690512) (AIC).

:::

When fitting models, it is possible to increase the maximum likelihood by adding parameters, but doing so may result in [overfitting](wikipedia://en/173332). Both BIC and AIC attempt to resolve this problem by introducing a penalty term for the number of parameters in the model; the penalty term is larger in BIC than in AIC for sample sizes greater than 7.[^o2]

The BIC was developed by Gideon E. Schwarz and published in a 1978 paper,[^o3] as a large-sample approximation to the [Bayes factor](wikipedia://en/824552).

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The BIC is formally defined as[^o6]

$$\mathrm{BIC} = k\ln(n) - 2\ln(\widehat L). \$$

where

- $\hat L$ = the maximized value of the [likelihood function](wikipedia://en/44968) of the model $M$, i.e. $\hat L=p(x\mid\widehat\theta,M)$, where $\{\widehat\theta\}$ are the parameter values that maximize the likelihood function and $x$ is the observed data;
- $n$ = the number of data points in $x$, the number of [observations](https://en.wikipedia.org/wiki/Observation), or equivalently, the sample size;
- $k$ = the number of [parameters](wikipedia://en/25065) estimated by the model. For example, in [multiple linear regression](wikipedia://en/5477568), the estimated parameters are the intercept, the $q$ slope parameters, and the constant variance of the errors; thus, $k = q + 2$.

:::

## Derivation {#Derivation}

The BIC can be derived by integrating out the parameters of the model using [Laplace's method](wikipedia://en/642006), starting with the following [model evidence](wikipedia://en/979771):[^o8][^o9]

$$p(x\mid M) = \int p(x\mid\theta,M) \pi(\theta\mid M) \, d\theta$$

where $\pi(\theta\mid M)$ is the prior for $\theta$ under model $M$.

The log-likelihood, $\ln(p(x\mid\theta,M))$, is then expanded to a second order [Taylor series](wikipedia://en/30448) about the [MLE](wikipedia://en/140806), $\widehat\theta$, assuming it is twice differentiable as follows:

$$\ln(p(x\mid\theta,M)) = \ln(\widehat L) - \frac{n}{2} (\theta - \widehat\theta)^{\operatorname{T}} \mathcal{I}(\widehat\theta) (\theta - \widehat\theta) + R(x, \theta),$$

where $\mathcal{I}(\theta)$ is the average [observed information per observation](wikipedia://en/9991540), and $R(x, \theta)$ denotes the residual term. To the extent that $R(x, \theta)$ is negligible and $\pi(\theta\mid M)$ is relatively linear near $\widehat\theta$, we can integrate out $\theta$ to get the following:

$$p(x\mid M) \approx \hat L {\left(\frac{2\pi}{n}\right)}^\frac{k}{2} |\mathcal{I}(\widehat\theta)|^{-\frac{1}{2}} \pi(\widehat\theta)$$

As $n$ increases, we can ignore $|\mathcal{I}(\widehat\theta)|$ and $\pi(\widehat\theta)$ as they are [$O(1)$](wikipedia://en/44578). Thus,

$$p(x\mid M) = \exp\left(\ln\widehat L - \frac{k}{2} \ln(n) + O(1)\right) = \exp\left(-\frac{\mathrm{BIC}}{2} + O(1)\right),$$

where BIC is defined as above, and $\widehat L$ either (a) is the Bayesian posterior mode or (b) uses the MLE and the prior $\pi(\theta\mid M)$ has nonzero slope at the MLE. Then the posterior

$$p(M\mid x) \propto p(x\mid M) p(M) \approx \exp\left(-\frac{\mathrm{BIC}}{2}\right) p(M)$$

The above arguments are heuristic, but can be made mathematically rigorous under the technical assumptions of [Lipschitz continuity](wikipedia://en/51731) and [strong convexity](https://en.wikipedia.org/wiki/Strong_convexity), as follows.

::: {#o10 .statement kind=statement/lemma cue=inline-head name="Lemma"}

**Lemma.** (Lemma 2.82 [^o11]) Define $\ell_n(\theta)=-\ln(p(x\mid\theta,M)\pi(\theta\mid M))/n$. If the sequence of gradients $\{\nabla\ell_n(\theta)\}$ is Lipschitz continuous, uniformly in $n$, and every $\ell_n(\theta)$ is strongly convex with a common parameter $m>0$ (independent of $n$), then as $n\rightarrow\infty$:

$$\ln p(x\mid M)=\ln(p(x\mid\bar\theta_n,M)\pi(\bar\theta_n\mid M))-\frac{k}{2}\ln(n)+O(1),$$

where $\bar\theta_n=\arg\min_{\theta}\ell_n(\theta)$ is the [maximum a posteriori](https://en.wikipedia.org/wiki/Maximum_a_posteriori) (MAP) estimate of $\theta$.

Note that it is always possible to select a prior density $\pi(\theta\mid M)$ such that every $\ell_n(\theta)$ is strongly convex (with the same parameter $m$). Such a prior ensures that the MAP estimate $\bar\theta_n$ exists, even in cases where the [MLE](wikipedia://en/140806) estimate $\hat\theta$ itself does not exist.

:::

::: {#o13 .application cue=heading name="Use"}

## Use {#Use}

When picking from several models, ones with lower BIC values are generally preferred. The BIC is an increasing [function](wikipedia://en/185427) of the error variance $\sigma_e^2$ and an increasing function of *k*. That is, unexplained variation in the [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable) and the number of explanatory variables increase the value of BIC. However, a lower BIC does not necessarily indicate one model is better than another. Because it involves approximations, the BIC is merely a heuristic. In particular, differences in BIC should never be treated like transformed Bayes factors.

It is important to keep in mind that the BIC can be used to compare estimated models only when the numerical values of the dependent variable are identical for all models being compared. The models being compared need not be [nested](wikipedia://en/27576#Nested_models), unlike the case when models are being compared using an [F-test](https://en.wikipedia.org/wiki/F_test) or a [likelihood ratio test](https://en.wikipedia.org/wiki/Likelihood_ratio_test).

To compare two different models, simply compute the BIC for each model and compare according to the table below:

! *ΔBIC* !! Evidence Against higher BIC |- | 0 to 2 || Barely worth mentioning |- | 2 to 6 || Positive |- | 6 to 10 || Strong |- | >10 || Very Strong |}

:::

## Limitations {#Limitations}

The BIC suffers from two main limitations:[^o15]

1. the above approximation is only valid for sample size $n$ much larger than the number $k$ of parameters in the model.
1. the BIC cannot handle complex collections of models as in the variable selection (or [feature selection](wikipedia://en/1179950)) problem in high-dimension.[^o15]

## Gaussian special case {#Gaussian_special_case}

Under the assumption that the model errors or disturbances are independent and identically distributed according to a [normal distribution](wikipedia://en/21462) and the boundary condition that the derivative of the [log likelihood](https://en.wikipedia.org/wiki/Log_likelihood) with respect to the true variance is zero, this becomes (*up to an additive constant*, which depends only on *n* and not on the model):[^o17]

$$\mathrm{BIC} = n \ln(\widehat{\sigma_e^2}) + k \ln(n) \$$

where $\widehat{\sigma_e^2}$ is the error variance. The error variance in this case is defined as

$$\widehat{\sigma_e^2} = \frac{1}{n} \sum_{i=1}^n (x_i-\widehat{x}_i)^2.$$

which [is a biased estimator for the true variance](wikipedia://en/32344#Sample_variance).

In terms of the [residual sum of squares (RSS)](wikipedia://en/1651906#Estimation) the BIC is

$$\mathrm{BIC} = n \ln(\text{RSS}/n) + k \ln(n) \$$

When testing multiple linear models against a saturated model, the BIC can be rewritten in terms of the [deviance](wikipedia://en/432609) $\chi^2$ as:[^o18]

$$\mathrm{BIC}= \chi^2 + k \ln(n)$$

where $k$ is the number of model parameters in the test.
