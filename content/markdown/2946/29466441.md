# System on TPTP

::: {#o1 .subject cue=lead name="System on TPTP"}

Web **System on TPTP** is an online interface to several [automated theorem proving](wikipedia://en/2546) systems and other [automated reasoning](wikipedia://en/2884728) tools. It allows users to run the systems either on problems from the latest releases from the [TPTP](wikipedia://en/2546) problem library or on user-supplied problems in the TPTP syntax.

:::

The system is maintained by [Geoff Sutcliffe](wikipedia://en/19336649) at the [University of Miami](https://en.wikipedia.org/wiki/University_of_Miami). In November 2010, it featured more than 50 systems, including both theorem provers and model finders.[^o2] System on TPTP can either run user-selected systems, or pick systems automatically based on problem features, and run them in parallel.[^o3]
