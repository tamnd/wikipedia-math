# Conjugate index

::: {#o1 .subject cue=lead name="Conjugate index"}

In [mathematics](wikipedia://en/18831), two [real numbers](wikipedia://en/20646438) $p, q>1$ are called **conjugate indices** (or **Hölder conjugates**) if

:::

$$\frac{1}{p} + \frac{1}{q} = 1.$$

Formally, we also define $q = \infty$ as conjugate to $p=1$ and [vice versa](https://en.wikipedia.org/wiki/List_of_Latin_phrases:_V#vice_versa).

Conjugate indices are used in [Hölder's inequality](wikipedia://en/191538), as well as [Young's inequality for products](wikipedia://en/54477872); the latter can be used to prove the former. If $p, q>1$ are conjugate indices, the spaces *L*<sup>*p*</sup> and *L*<sup>*q*</sup> are [dual](wikipedia://en/7988) to each other (see [*L*<sup>*p*</sup> space](wikipedia://en/45194)).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The following are equivalent characterizations of Hölder conjugates:

- $$\frac{1}{p} + \frac{1}{q} = 1,$$
- $$pq = p + q,$$
- $$\frac{p}{q} = p - 1,$$
- $$\frac{q}{p} = q - 1.$$

:::
