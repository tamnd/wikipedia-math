# Bregman Lagrangian

::: {#o1 .subject cue=lead name="Bregman Lagrangian"}

The [Bregman](wikipedia://en/21410975)-[Lagrangian](wikipedia://en/87793) framework permits a systematic understanding of the matching rates associated with higher-order [gradient methods](wikipedia://en/15094152) in discrete and continuous time.[^o2] Based on [Bregman divergence](wikipedia://en/4491248), the Lagrangian is a continuous time dynamical system whose [Euler-Lagrange equations](https://en.wikipedia.org/wiki/Euler-Lagrange_equation) can be linked to [Nesterov's accelerated gradient](wikipedia://en/1180641#Momentum) method for gradient-based optimization.[^o3] The associated Bregman [Hamiltonian](wikipedia://en/198319) allows for practical implementation of numerical discretizations.[^o4] The approach has been generalized to optimization on [Riemannian manifolds](https://en.wikipedia.org/wiki/Riemannian_manifolds).[^o5]

:::
