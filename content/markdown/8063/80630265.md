# Sender Keys

::: {#o1 .subject cue=lead name="Sender Keys"}

In [cryptography](wikipedia://en/18934432), **Sender Keys** is a variant of the [Signal Protocol](wikipedia://en/50607084)[^n1] used in [end-to-end encryption](wikipedia://en/1065362) used in [instant messaging](https://en.wikipedia.org/wiki/Instant_messaging). Sender Keys is used for [group chats](https://en.wikipedia.org/wiki/Group_chat).[^n1] Applications using it have included [Signal](wikipedia://en/45210316), [Matrix](wikipedia://en/46246817), [WhatsApp](wikipedia://en/32058867), [Session](wikipedia://en/68972830), and [Facebook Messenger](https://en.wikipedia.org/wiki/Facebook_Messenger).[^o9][^o10][^o11][^o13][^o14][^o12]

:::

In order to scale to large groups, the protocol takes advantage of server-side [fan-out](https://en.wikipedia.org/wiki/Fan-out_%28software%29#Message-oriented_middleware) and avoids computing a shared [group key](https://en.wikipedia.org/wiki/Group_key).[^o9][^o10][^o12] The algorithm relies upon secure pairwise communication channels between peers that provide confidentiality and [authentication](wikipedia://en/47967). For example, an [Authenticated Key Exchange](wikipedia://en/36103897) algorithm such as [Extended Triple Diffie-Hellman (X3DH)](wikipedia://en/7903#Extended_Triple_Diffie–Hellman_%28X3DH%29) may be combined with the [Double Ratchet Algorithm](wikipedia://en/49111333) to construct such a channel in practice, as is the case with [WhatsApp](wikipedia://en/32058867).[^o15][^o9]

The protocol was described in a whitepaper from WhatsApp,[^o9] and it is also related to the [Messaging Layer Security](https://en.wikipedia.org/wiki/Messaging_Layer_Security) standard.[^o4]

## Functioning {#Functioning}

In Sender Keys, users within a group are assumed to maintain secure pairwise communication channels with each other user. Each user constructs a session that consists of a [symmetric key](https://en.wikipedia.org/wiki/Symmetric_key) and an [asymmetric signing key pair](wikipedia://en/24222); each user sends their session's symmetric key and the signing key pair's public key to each other user through the respective pairwise secure channels.[^o9]

To send a message, a user "ratchets" their symmetric key forward by applying a [cryptographic hash function](wikipedia://en/439526), encrypts their message with the newly hashed symmetric key, and constructs a [digital signature](wikipedia://en/59644) protecting the encrypted message with the private signing key. The sender forwards the encrypted message to the server, who then fans it out to all receivers. Each receiver checks the signature with public signing key, hashes their symmetric key to match the sender, and decrypts the message.

Users regenerate and re-transmit sessions periodically, or whenever a user leaves or joins the group.[^o9][^o10][^o12]

## Security properties {#Security_properties}

Security properties of Sender Keys include message confidentiality, message integrity, message authentication, [forward secrecy](wikipedia://en/2191130), post-compromise security, scalability, and asynchronicity.[^o13][^o14]
