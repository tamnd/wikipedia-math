# Interlocking interval topology

::: {#o1 .subject cue=lead name="Interlocking interval topology"}

In mathematics, and especially [general topology](wikipedia://en/178649), the **interlocking interval topology** is an example of a [topology](wikipedia://en/29954) on the set *S* := **R**<sup>\+</sup> \\ **Z**<sup>\+</sup>, i.e. the set of all positive [real numbers](wikipedia://en/20646438) that are not positive [whole numbers](wikipedia://en/21474).[^o2]

:::

::: {#o4 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

The open sets in this topology are taken to be the whole set *S*, the empty set ∅, and the sets generated by

$$X_n := \left(0,\frac{1}{n}\right) \cup (n,n+1) = \left\{ x \in {\mathbf R}^+ : 0 < x < \frac{1}{n} \ \text{ or } \ n < x < n+1 \right\}.$$

The sets generated by *X<sub>n</sub>* will be formed by all possible unions of finite intersections of the *X<sub>n</sub>*.[^o5]

:::
