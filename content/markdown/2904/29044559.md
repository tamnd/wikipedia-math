# Lexicographic order topology on the unit square

::: {#o1 .subject cue=lead name="Lexicographic order topology on the unit square"}

In [general topology](wikipedia://en/178649), the **lexicographic ordering on the unit square** (sometimes the **dictionary order on the unit square**[^o2]) is a [topology](wikipedia://en/30450) on the [unit square](wikipedia://en/285301) *S*, i.e. on the set of points (*x*,*y*) in the [plane](https://en.wikipedia.org/wiki/Plane_%28geometry%29) such that 0 ≤ *x* ≤ 1 and 0 ≤ *y* ≤ 1.[^n1]

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

The [lexicographical ordering](https://en.wikipedia.org/wiki/Lexicographical_order) gives a total ordering $\prec$ on the points in the unit square: if (*x*,*y*) and (*u*,*v*) are two points in the square, (*x*,*y*) $\scriptstyle\prec$ (*u*,*v*) if and only if either *x* \< *u* or **both** *x* = *u* **and** *y* \< *v*. Stated symbolically,

$$(x,y)\prec (u,v)\iff (x<u) \lor (x=u\land y<v)$$

The lexicographic order topology on the unit square is the [order topology](wikipedia://en/213650) induced by this ordering.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The order topology makes *S* into a [completely normal](https://en.wikipedia.org/wiki/Completely_normal_space) [Hausdorff space](wikipedia://en/13637).[^n2] Since the lexicographical order on *S* can be proven to be [complete](wikipedia://en/549445), this topology makes *S* into a [compact space](wikipedia://en/6042). At the same time, *S* contains an [uncountable](https://en.wikipedia.org/wiki/Uncountable) number of [pairwise disjoint](https://en.wikipedia.org/wiki/Pairwise_disjoint) open intervals, each [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to the [real line](https://en.wikipedia.org/wiki/Real_line), for example the intervals $U_x=\{(x,y):1/4<y<1/2\}$ for $0\le x\le 1$. So *S* is not [separable](wikipedia://en/27855), since any dense subset has to contain at least one point in each $U_x$. Hence *S* is not [metrizable](wikipedia://en/19738) (since any [compact metric space](https://en.wikipedia.org/wiki/Compact_metric_space) is separable); however, it is [first countable](wikipedia://en/904940). Also, S is connected and locally connected, but not path connected and not locally path connected.[^o2] Its [fundamental group](wikipedia://en/11004) is trivial.[^n1]

:::
