# Zodiac (cipher)

::: {#o2 .subject cue=lead name="Zodiac"}

In [cryptography](wikipedia://en/18934432), **Zodiac** is a [block cipher](wikipedia://en/4594) designed in 2000 by Chang-Hyi Lee for the Korean firm SoftForum.

:::

Zodiac uses a 16-round [Feistel network](wikipedia://en/352709) structure with [key whitening](wikipedia://en/2990178). The round function uses only [XORs](https://en.wikipedia.org/wiki/XOR) and [S-box](https://en.wikipedia.org/wiki/Substitution_box) lookups. There are two 8×8-bit S-boxes: one based on the discrete [exponentiation](wikipedia://en/99491) 45<sup>*x*</sup> as in [SAFER](wikipedia://en/630497), the other using the [multiplicative inverse](wikipedia://en/229940) in the [finite field](wikipedia://en/11615) GF(2<sup>8</sup>), as introduced by [SHARK](wikipedia://en/619666).

Zodiac is theoretically vulnerable to [impossible differential cryptanalysis](wikipedia://en/3329225), which can recover a 128-bit key in 2<sup>119</sup> encryptions.
