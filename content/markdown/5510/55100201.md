# Olech theorem

::: {#o1 .subject cue=lead name="Olech theorem"}

In [dynamical systems theory](wikipedia://en/990632), the **Olech theorem** establishes [sufficient](wikipedia://en/169319) conditions for global [asymptotic stability](wikipedia://en/363360) of a two-equation system of non-linear [differential equations](wikipedia://en/1424309). The result was established by [Czesław Olech](wikipedia://en/31633829) in 1963,[^o2] based on joint work with [Philip Hartman](wikipedia://en/35263118).[^o3]

:::

::: {#o5 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

The differential equations $\mathbf{\dot{x}} = f ( \mathbf{x} )$, $\mathbf{x} = [ x_1 \, x_2]^{\mathsf{T}} \in \mathbb{R}^2$, where $f(\mathbf{x}) = \begin{bmatrix} f^1 (\mathbf{x}) & f^2 (\mathbf{x}) \end{bmatrix}^{\mathsf{T}}$, for which $\mathbf{x}^\ast = \mathbf{0}$ is an [equilibrium point](https://en.wikipedia.org/wiki/Equilibrium_point), is uniformly globally asymptotically stable if:

(a) the [trace](wikipedia://en/43270) of the [Jacobian matrix](wikipedia://en/195351) is negative, $\operatorname{tr} \mathbf{J}_f (\mathbf{x}) < 0$ for all $\mathbf{x} \in \mathbb{R}^2$,

(b) the Jacobian determinant is positive, $\left| \mathbf{J}_{f} (\mathbf{x}) \right| > 0$ for all $\mathbf{x} \in \mathbb{R}^{2}$, and

(c) the system is coupled everywhere with either

$$\frac{\partial f^1}{\partial x_1} \frac{\partial f^2}{\partial x_2} \neq 0, \text{ or } \frac{\partial f^1}{\partial x_2} \frac{\partial f^2}{\partial x_1} \neq 0 \text{ for all } \mathbf{x} \in \mathbb{R}^2.$$

:::
