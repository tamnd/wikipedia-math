# Computable set

::: {#o1 .subject cue=lead name="Computable set"}

In [computability theory](wikipedia://en/155414), a [set](wikipedia://en/26691) of [natural numbers](wikipedia://en/21474) is **computable** (or **decidable** or **recursive**) if there is an [algorithm](wikipedia://en/775) that computes the membership of every natural number in a finite number of steps.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A subset $S$ of the [natural numbers](wikipedia://en/21474) is **computable** if there exists a [total](https://en.wikipedia.org/wiki/Total_function) [computable function](wikipedia://en/1139338) $f$ such that:

$f(x)=1$ if $x\in S$

$f(x)=0$ if $x\notin S$.

In other words, the set $S$ is computable [if and only if](wikipedia://en/14922) the [indicator function](wikipedia://en/240790) $\mathbb{1}_{S}$ is [computable](wikipedia://en/1139338).

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [recursive language](wikipedia://en/23290990) is computable.
- Every finite or [cofinite](https://en.wikipedia.org/wiki/Cofinite) subset of the natural numbers is computable.
  - The [empty set](wikipedia://en/9566) is computable.
  - The entire set of natural numbers is computable.
  - Every natural number is computable.[^o13]
- The subset of [prime numbers](wikipedia://en/23666) is computable.
- The set of Gödel numbers is computable.[^o14]

::: {#o7 .example kind=example/counterexample cue=heading name="Non-examples"}

### Non-examples {#Non-examples}

- The set of [Turing machines that halt](wikipedia://en/21391870) is not computable.
- The set of pairs of [homeomorphic](wikipedia://en/13660) finite [simplicial complexes](wikipedia://en/252686) is not computable.[^o8]
- The set of [busy beaver champions](wikipedia://en/67911#Non-computability) is not computable.
- [Hilbert's tenth problem](wikipedia://en/101851) is not computable.

:::

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Both *A*, *B* are sets in this section.

- If *A* is computable then the [complement](wikipedia://en/54347) of *A* is computable.
- If *A* and *B* are computable then:
  - *A* ∩ *B* is computable.
  - *A* ∪ *B* is computable.
  - The image of *A* × *B* under the [Cantor pairing function](https://en.wikipedia.org/wiki/Cantor_pairing_function) is computable.

In general, the image of a computable set under a computable function is computably enumerable, but possibly not computable.

- *A* is computable [if and only if](wikipedia://en/14922) *A* and the [complement](wikipedia://en/54347) of *A* are both [computably enumerable(c.e.)](https://en.wikipedia.org/wiki/Computably_enumerable).
- The [preimage](https://en.wikipedia.org/wiki/Preimage) of a computable set under a [total](https://en.wikipedia.org/wiki/Total_function) [computable function](wikipedia://en/1139338) is computable.
- The image of a computable set under a total computable [bijection](wikipedia://en/3942) is computable.

*A* is computable if and only if it is at level $\Delta^0_1$ of the [arithmetical hierarchy](wikipedia://en/186475).

*A* is computable if and only if it is either the image (or range) of a nondecreasing total computable function, or the empty set.
