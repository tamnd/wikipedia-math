### [Limits](wikipedia://en/26551602) {#Limits}

::: {#o4 .entry cue=list-entry name="Limit of a sequence"}

:::

  - [Subsequential limit](wikipedia://en/553920) – the limit of some subsequence

::: {#o5 .entry cue=list-entry name="Limit of a function"}

- [Limit of a function](wikipedia://en/285759) (*see [List of limits](wikipedia://en/5646277) for a list of limits of common functions*)

:::

  - [One-sided limit](wikipedia://en/379840) – either of the two limits of functions of real variables x, as x approaches a point from above or below

(*see also [list of mathematical series](wikipedia://en/18814960)*)

::: {#o7 .entry cue=list-entry name="Arithmetic progression"}

- [Arithmetic progression](wikipedia://en/168389) – a sequence of numbers such that the difference between the consecutive terms is constant

:::

  - [Generalized arithmetic progression](wikipedia://en/2240347) – a sequence of numbers such that the difference between consecutive terms can be one of several possible constants

::: {#o8 .entry cue=list-entry name="Geometric progression"}

- [Geometric progression](wikipedia://en/23474670) – a sequence of numbers such that each consecutive term is found by multiplying the previous one by a fixed non-zero number

:::

::: {#o9 .entry cue=list-entry name="Harmonic progression"}

- [Harmonic progression](wikipedia://en/24307466) – a sequence formed by taking the reciprocals of the terms of an arithmetic progression

  - [Cauchy sequence](wikipedia://en/6085) – a sequence whose elements become arbitrarily close to each other as the sequence progresses

::: {#o14 .entry cue=list-entry name="Convergent series"}

::: {#o15 .entry cue=list-entry name="Divergent series"}

- [Divergent series](wikipedia://en/876428) – a series whose sequence of partial sums diverges

:::

::: {#o16 .entry cue=list-entry name="Power series"}

- [Power series](wikipedia://en/59958) – a series of the form $f(x) = \sum_{n=0}^\infty a_n \left( x-c \right)^n = a_0 + a_1 (x-c)^1 + a_2 (x-c)^2 + a_3 (x-c)^3 + \cdots$

:::

  - [Taylor series](wikipedia://en/30448) – a series of the form $f(a)+\frac {f'(a)}{1!} (x-a)+ \frac{f''(a)}{2!} (x-a)^2+\frac{f^{(3)}(a)}{3!}(x-a)^3+ \cdots.$
    - **Maclaurin series** – *see [Taylor series](wikipedia://en/30448)*
      - [Binomial series](wikipedia://en/696619) – the Maclaurin series of the function *f* given by *f*(*x*) *\=* (1 + *x*)<sup>*α*</sup>

## Fundamental theorems {#Fundamental_theorems}

::: {#o115 .entry cue=list-entry name="Monotone convergence theorem"}

- **[Monotone convergence theorem](wikipedia://en/146263)** – relates monotonicity with convergence

:::

::: {#o116 .entry cue=list-entry name="Intermediate value theorem"}

- **[Intermediate value theorem](wikipedia://en/14884)** – states that for each value between the least upper bound and greatest lower bound of the image of a continuous function there is at least one point in its domain that the function maps to that value

:::

::: {#o117 .entry cue=list-entry name="Rolle's theorem"}

- **[Rolle's theorem](wikipedia://en/200305)** – essentially states that a differentiable function which attains equal values at two distinct points must have a point somewhere between them where the first derivative is zero

:::

::: {#o118 .entry cue=list-entry name="Mean value theorem"}

- **[Mean value theorem](wikipedia://en/19662)** – that given an arc of a differentiable curve, there is at least one point on that arc at which the derivative of the curve is equal to the "average" derivative of the arc

:::

::: {#o119 .entry cue=list-entry name="Taylor's theorem"}

- **[Taylor's theorem](wikipedia://en/51714)** – gives an approximation of a $k$ times differentiable function around a given point by a $k$-th order Taylor-polynomial.

:::

::: {#o120 .entry cue=list-entry name="L'Hôpital's rule"}

- **[L'Hôpital's rule](wikipedia://en/18531)** – uses derivatives to help evaluate limits involving indeterminate forms

:::

::: {#o121 .entry cue=list-entry name="Abel's theorem"}

- **[Abel's theorem](wikipedia://en/237305)** – relates the limit of a power series to the sum of its coefficients

:::

::: {#o122 .entry cue=list-entry name="Lagrange inversion theorem"}

- **[Lagrange inversion theorem](wikipedia://en/94158)** – gives the Taylor series of the inverse of an analytic function

:::

::: {#o123 .entry cue=list-entry name="Darboux's theorem"}

- **[Darboux's theorem](wikipedia://en/4130888)** – states that all functions that result from the differentiation of other functions have the intermediate value property: the image of an interval is also an interval

:::

::: {#o124 .entry cue=list-entry name="Heine–Borel theorem"}

- **[Heine–Borel theorem](wikipedia://en/59595)** – sometimes used as the defining property of compactness

:::

::: {#o125 .entry cue=list-entry name="Bolzano–Weierstrass theorem"}

- **[Bolzano–Weierstrass theorem](wikipedia://en/31211)** – states that each bounded sequence in $\mathbb{R}^{n}$ has a convergent subsequence

:::

::: {#o126 .entry cue=list-entry name="Extreme value theorem"}

- **[Extreme value theorem](wikipedia://en/276881)** - states that if a function $f$ is continuous in the closed and bounded interval $[a,b]$, then it must attain a maximum and a minimum

:::
