# Differentiable function

::: {#o1 .subject cue=lead name="Differentiable function"}

*Image: Polynomialdeg3.svg.* A differentiable function

In [mathematical analysis](wikipedia://en/48396), a [real](wikipedia://en/20646438) or [complex](wikipedia://en/5826) [function](wikipedia://en/185427) of a single variable is **differentiable** if its [derivative](wikipedia://en/7921) exists at each point in its [domain](wikipedia://en/50263). For real-valued functions of a real variable, the [graph](wikipedia://en/87352) of a differentiable function has a non-[vertical](wikipedia://en/5120956) [tangent line](https://en.wikipedia.org/wiki/Tangent_line) at each interior point in its domain. A differentiable function is [locally](wikipedia://en/1529485) approximable by a [linear function](wikipedia://en/152111) at each interior point, and does not contain any [break](wikipedia://en/2661487), angle, or [cusp](wikipedia://en/6851758).

:::

If $x_{0}$ is an interior point in the domain of a real function $f$, then $f$ is said to be *differentiable at* $x_{0}$ if there exists an $L\in\mathbb{R}$ such that for all $\epsilon>0$, there exists a $\delta>0$ such that for all $x\in(x_{0}-\delta,x_{0})\cup(x_{0},x_{0}+\delta)$, $\frac{f(x)-f(x_{0})}{x-x_{0}}\in(L-\epsilon,L+\epsilon)$. In other words, the graph of $f$ has a non-vertical tangent line at the point $(x_{0},f(x_{0}))$. $f$ is said to be differentiable on a subset $U\subseteq\mathbb{R}$ if it is differentiable at every point in $U$. $f$ is said to be *[continuously differentiable](https://en.wikipedia.org/wiki/Continuously_differentiable_function)* if its derivative is also a continuous function over the domain of $f$.

Continuous functions may be nowhere differentiable in their domain, such as the [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function). Taking successive antiderivatives of such a function allows one to obtain a function that is differentiable only a finite number of times, the finite number being any positive integer. Given a positive integer $k$, $f$ is said to be of class $C^k$ if its first $k$ derivatives $f^{\prime}, f^{\prime\prime}, \ldots, f^{(k)}$ exist and are continuous over the domain of $f$.

For a multivariable function, as shown here, the differentiability of it is something more complex than the existence of the partial derivatives of it. However, the essence is the same; a function that is locally approximable by a [linear map](wikipedia://en/18102) at $\mathbf{X_0}$ is said to be differentiable at this point.

## Differentiability of real functions of one variable {#Differentiability_of_real_functions_of_one_variable}

A function $f:U\to\mathbb{R}$, defined on an [open set](wikipedia://en/39358) $U\subset\mathbb{R}$, is said to be *differentiable* at $a\in U$ if the derivative

$$f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}{h}=\lim_{x\to a}\frac{f(x)-f(a)}{x-a}$$

exists. This implies that the function is [continuous](wikipedia://en/6122) at $a$.

This function $f$ is said to be *differentiable* on $U$ if it is differentiable at every point of $U$. In this case, the derivative of $f$ is thus a function from $U$ into $\mathbb R.$

A continuous function is not necessarily differentiable, but a differentiable function is necessarily [continuous](wikipedia://en/6122) (at every point where it is differentiable) as is shown below (in the section [Differentiability and continuity](wikipedia://en/330206#Differentiability_and_continuity)). A function is said to be *continuously differentiable* if its derivative is also a continuous function; there exist functions that are differentiable but not continuously differentiable (an example is given in the section [Differentiability classes](wikipedia://en/330206#Differentiability_classes)).

### Semi-differentiability {#Semi-differentiability}

The above definition can be extended to define the derivative at [boundary points](wikipedia://en/72824) of the domain that also belong to the domain. The derivative of a function $f:A\to \mathbb{R}$ defined on a closed subset $A\subsetneq \mathbb{R}$ of the real numbers, evaluated at a boundary point $c$, can be defined as the following one-sided limit, where the argument $x$ approaches $c$ such that it is always within $A$:

$$f'(c)=\lim_{{\scriptstyle x\to c\atop\scriptstyle x\in A}}\frac{f(x)-f(c)}{x-c}.$$

For $x$ to remain within $A$, which is a subset of the reals, it follows that this limit will be defined as either

$$f'(c)=\lim_{x\to c^+}\frac{f(x)-f(c)}{x-c} \quad \text{or} \quad f'(c)=\lim_{x\to c^-}\frac{f(x)-f(c)}{x-c}.$$

## Differentiability and continuity {#Differentiability_and_continuity}

*Image: Absolute value.svg.* The [absolute value](wikipedia://en/991) function is continuous (i.e. it has no gaps). It is differentiable everywhere *except* at the point $x$ = 0, where it makes a sharp turn as it crosses the $y$-axis.

*Image: Cusp at (0,0.5).svg.* A [cusp](wikipedia://en/6851758) on the graph of a continuous function. At zero, the function is continuous but not differentiable.

If $f$ is differentiable at a point $x_{0}$, then $f$ must also be [continuous](wikipedia://en/6122) at $x_{0}$. In particular, any differentiable function must be continuous at every point in its domain. *The converse does not hold*: a continuous function need not be differentiable. For example, a function with a bend, [cusp](wikipedia://en/6851758), or [vertical tangent](wikipedia://en/5120956) may be continuous, but fails to be differentiable at the location of the anomaly.

Most functions that occur in practice have derivatives at all points or at [almost every](wikipedia://en/44688) point. However, a result of [Stefan Banach](wikipedia://en/29646) states that the set of functions that have a derivative at some point is a [meagre set](wikipedia://en/226975) in the space of all continuous functions.[^o6] Informally, this means that differentiable functions are very atypical among continuous functions. The first known example of a function that is continuous everywhere but differentiable nowhere is the [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function).

## Differentiability classes {#Differentiability_classes}

*Image: Approximation of cos with linear functions without numbers.svg.* Differentiable functions can be locally approximated by linear functions.

*Image: The function x^2\*sin(1 over x).svg.* The function $f : \mathbb{R} \to \mathbb{R}$ with $f(x) = x^2\sin\left(\tfrac 1x\right)$ for $x \neq 0$ and $f(0) = 0$ is differentiable. However, this function is not continuously differentiable.

A function $f$ is said to be [continuously differentiable](https://en.wikipedia.org/wiki/Continuously_differentiable_function) if the derivative $f^{\prime}(x)$ exists and is itself a continuous function. Although the derivative of a differentiable function never has a [jump discontinuity](https://en.wikipedia.org/wiki/Jump_discontinuity), it is possible for the derivative to have an [essential discontinuity](wikipedia://en/2661487#Essential_discontinuity). For example, the function

$$f(x) \;=\; \begin{cases} x^2 \sin(1/x) & \text{ if }x \neq 0 \\ 0 & \text{ if } x = 0\end{cases}$$

is differentiable at 0, since

$$f'(0) = \lim_{\varepsilon \to 0} \left(\frac{\varepsilon^2\sin(1/\varepsilon)-0}{\varepsilon}\right) = 0$$

exists. However, for $x \neq 0,$ [differentiation rules](wikipedia://en/10308785) imply

$$f'(x) = 2x\sin(1/x) - \cos(1/x)\;,$$

which has no limit as $x \to 0.$ Thus, this example shows the existence of a function that is differentiable but not continuously differentiable (i.e., the derivative is not a continuous function). Nevertheless, [Darboux's theorem](wikipedia://en/4130888) implies that the derivative of any function satisfies the conclusion of the [intermediate value theorem](wikipedia://en/14884).

Similarly to how [continuous functions](wikipedia://en/6122) are said to be of class $C^0,$ continuously differentiable functions are sometimes said to be of class $C^1$. A function is of class $C^2$ if the first and [second derivative](wikipedia://en/3224219) of the function both exist and are continuous. More generally, a function is said to be of class $C^k$ if the first $k$ derivatives $f^{\prime}(x), f^{\prime\prime}(x), \ldots, f^{(k)}(x)$ all exist and are continuous. If derivatives $f^{(n)}$ exist for all positive integers $n,$ the function is [smooth](https://en.wikipedia.org/wiki/Smooth_function) or equivalently, of class $C^{\infty}.$

## Differentiability in higher dimensions {#Differentiability_in_higher_dimensions}

A [function of several real variables](wikipedia://en/39783039) $\mathbf{f}: \mathbf{R}^{m} \to \mathbf{R}^{n}$ is said to be differentiable at a point $\mathbf{x}_{0}$ if there exists a [linear map](wikipedia://en/18102) $\mathbf{M}: \mathbf{R}^{m} \to \mathbf{R}^{n}$[^o10] such that

$$\lim_{\mathbf{h}\to \mathbf{0}} \frac{\|\mathbf{f}(\mathbf{x_0}+\mathbf{h}) - \mathbf{f}(\mathbf{x_0}) - \mathbf{M}\mathbf{(h)}\|_{\mathbf{R}^{n}}}{\| \mathbf{h} \|_{\mathbf{R}^{m}}} = 0,$$

where $||\mathbf{v}||$ for a vector $\mathbf{v}$ is the [norm](wikipedia://en/990534) of it. If a function is differentiable at $\mathbf{x}_{0}$, then all of the [partial derivatives](wikipedia://en/52565) exist at $\mathbf{x}_{0}$, and the linear map $\mathbf{M}$ is given by $\mathbf{J}_{\mathbf{f}} \cdot \mathbf{h}$, where $\mathbf{J}_{\mathbf{f}}$, the [Jacobian matrix](https://en.wikipedia.org/wiki/Jacobian_matrix) for $\mathbf{f}$ evaluated at $\mathbf{x}_{0}$ (an *n* × *m* matrix in this case), is left-multiplied to a vector $\mathbf{h}$ in $\mathbf{R}^{m}$. A similar formulation of the higher-dimensional derivative is provided by the [fundamental increment lemma](https://en.wikipedia.org/wiki/Fundamental_increment_lemma).

If all the partial derivatives of a function exist in a [neighborhood](wikipedia://en/1529485) of a point $\mathbf{x}_{0}$ and are continuous at the point $\mathbf{x}_{0}$[^o11], then the function is differentiable at that point $\mathbf{x}_{0}$;[^o12] The existence of the partial derivatives (or even of all the [directional derivatives](wikipedia://en/487859)) does not guarantee that a function is differentiable at a point. For example, the function $f: \mathbf{R}^{2} \to \mathbf{R}$ defined by

$$f(x,y) = \begin{cases}x & \text{if }y \ne x^2 \\ 0 & \text{if }y = x^2\end{cases}$$

is not differentiable at $(0, 0)$ while all of the partial derivatives and directional derivatives exist at this point. For a continuous example, the function

$$f(x,y) = \begin{cases}y^3/(x^2+y^2) & \text{if }(x,y) \ne (0,0) \\ 0 & \text{if }(x,y) = (0,0)\end{cases}$$

is not differentiable at $(0, 0)$, while again, all of the partial derivatives and directional derivatives exist.

## Differentiability in complex analysis {#Differentiability_in_complex_analysis}

In [complex analysis](wikipedia://en/5759), complex-differentiability is defined using the same definition as single-variable real functions. This is allowed because a [complex number](wikipedia://en/5826) (typically expressed as $z = x + iy$) can be divided by a complex number. So, a function $f:\mathbb{C}\to\mathbb{C}$ is said to be differentiable at $x=a$ when

$$f'(a)=\lim_{\underset{h\in\mathbb C}{h\to 0}}\frac{f(a+h)-f(a)}{h}.$$

This limit exists only if the limit is same regardless of a choice of direction of approaching to $a$. Although this definition looks similar to the differentiability of single-variable real functions, it is a more restrictive condition. A function $f:\mathbb{C}\to\mathbb{C}$ that is complex-differentiable at a point $x=a$ is automatically differentiable at that point when viewed as a function $f:\mathbb{R}^2\to\mathbb{R}^2$. [^o14] This is because complex differentiability implies

$$\lim_{\underset{h\in\mathbb C}{h\to 0}}\frac{\|f(a+h)-f(a)-f'(a)h\|}{\|h\|} = \lim_{\underset{h\in\mathbb C}{h\to 0}}\frac{|f(a+h)-f(a)-f'(a)h|}{|h|} = 0,$$

where $f'(a)h$ is a linear map $\mathbf{M}(\mathbf{h})$ as in the definition of the differentiability of higher dimensional spaces [above](wikipedia://en/330206#Differentiability_in_higher_dimensions), and the [absolute-value norm](wikipedia://en/990534#Absolute-value_norm) is used. However, a function $f:\mathbb{C}\to\mathbb{C}$ that is differentiable as a multi-variable function may not be complex-differentiable, since not every linear map $\mathbb{R}^2\to\mathbb{R}^2$ is expressible as multiplication by a complex number.

For example, the complex function $f(z)=\frac{z+\overline{z}}{2}$ corresponds to the 2-variable [real function](wikipedia://en/22284647) $f(x,y)=x$, which is differentiable at every point. This function is not complex-differentiable at any point, since the limit

$$f'(z)=\lim_{\underset{h\in\mathbb C}{h\to 0}}\frac{f(z+h)-f(z)}{h} = \lim_{\underset{h\in\mathbb C}{h\to 0}}\frac{h+\bar h}{2h}$$

is different depending on the path of $h$. A path $h = x$ along the real axis gives $f'(z)= \lim_{x \to 0} \frac{2x}{2x} = 1$, while a path $h = iy$ along the imaginary axis gives $f'(z)= \lim_{y \to 0} \frac{0}{2iy} = 0$.

A function that is complex-differentiable in a neighborhood of a point is called [holomorphic](wikipedia://en/14110) at that point. Such a function is necessarily [analytic](wikipedia://en/61478) at that point. Conversely, any function that is analytic at a point is also holomorphic at that point.

## Differentiable functions on manifolds {#Differentiable_functions_on_manifolds}

If *M* is a [differentiable manifold](wikipedia://en/2119219), a real or complex-valued function *f* on *M* is said to be differentiable at a point *p* if it is differentiable with respect to some (or any) coordinate chart defined around *p*. If *M* and *N* are differentiable manifolds, a function *f*: *M* → *N* is said to be differentiable at a point *p* if it is differentiable with respect to some (or any) coordinate charts defined around *p* and *f*(*p*).
