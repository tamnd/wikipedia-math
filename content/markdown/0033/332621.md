# Hereditarily finite set

::: {#o1 .subject cue=lead name="Hereditarily finite set"}

In [mathematics](wikipedia://en/18831), specifically [set theory](wikipedia://en/27553), **hereditarily finite sets** are defined as [finite sets](wikipedia://en/11742) whose elements are all hereditarily finite sets. In other words, the set itself is finite and all of its elements are finite sets, recursively down to the [empty set](wikipedia://en/9566).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A [recursive](https://en.wikipedia.org/wiki/Recursive) definition of [well-founded](https://en.wikipedia.org/wiki/Well-foundedness) hereditarily finite sets is as follows:

*Base case*: the empty set is a hereditarily finite set.

*Recursion rule*: if $a_1,\dots a_k$ are hereditarily finite sets, then so is $\{a_1,\dots a_k\}$.

Only sets that can be built by a finite number of applications of these two rules are hereditarily finite.

::: {#o5 .definition kind=definition/notation cue=heading name="Representation"}

### Representation {#Representation}

This class of sets is naturally ranked by the number of bracket pairs necessary to represent the sets:

- One bracket pair: $\{\}=\varnothing$ (the ordinal "0").
- Two bracket pairs: $\{\{\}\}=\{\varnothing\}=\{0\}$ (the ordinal "1").
- Three bracket pairs: $\{\{\{\}\}\}$.
- Four bracket pairs: $\{\{\{\{\}\}\}\}$ and also $\{\{\},\{\{\}\}\}=\{0,\{0\}\}=\{0,1\}$ (the ordinal "2").
- Five bracket pairs: $\{\{\{\{\{\}\}\}\}\}$, also $\{\{\{\},\{\{\}\}\}\}$ as well as $\{\{\},\{\{\{\}\}\}\}$.
- Six bracket pairs, such as $\{\{\{\{\{\{\}\}\}\}\}\}$. There are six such sets.
- Seven bracket pairs, such as $\{\{\{\{\{\{\{\}\}\}\}\}\}\}$. There are twelve such sets.
- Eight bracket pairs, such as $\{\{\{\{\{\{\{\{\}\}\}\}\}\}\}\}$ or $\{\{\}, \{\{\}\}, \{\{\},\{\{\}\}\}\}=\{0, 1, \{0,1\}\}=\{0,1,2\}$ (the ordinal "3").

The number of sets with $n$ bracket pairs is

$$1, 1, 1, 2, 3, 6, 12, 25, 52, 113, 247, 548, 1226, 2770, 6299, 14426, \dots$$

.

:::

:::

## Discussion {#Discussion}

Not every finite set is hereditarily finite. For example, $\{7, {\mathbb{N}}\}$ is not hereditarily finite since it contains an infinite set as an element, the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $\mathbb{N} = \{0,1,2,\dots\}$.

The class of all hereditarily finite sets is denoted by $H_{\aleph_0}$, meaning that the cardinality of each member is smaller than $\aleph_0$. (Analogously, the class of [hereditarily *countable* sets](wikipedia://en/5126046) is denoted by $H_{\aleph_1}$.) It can also be denoted by $V_\omega$, which denotes the $\omega$th stage of the [von Neumann universe](wikipedia://en/445980).[^o7]

$H_{\aleph_0}$ is in bijective correspondence with $\aleph_0$. Any theory that can prove $H_{\aleph_0}$ to be a set can also prove it to be [countable](wikipedia://en/6026).

## Models {#Models}

::: {#o10 .pointer-item cue=pointer name="Ackermann coding"}

### Ackermann coding {#Ackermann_coding}

In 1937, [Wilhelm Ackermann](wikipedia://en/62727) introduced an encoding of hereditarily finite sets as natural numbers. It is defined by a function $f: H_{\aleph_0} \to \mathbb{N}$ that maps each hereditarily finite set to a natural number, given by the following recursive definition:[^n1][^n2][^n3]

$$f(a) = \sum_{b \in a} 2^{f(b)}$$

For example, the empty set $\{\}$ contains no members, and is therefore mapped to an [empty sum](wikipedia://en/209748), that is, the number [zero](https://en.wikipedia.org/wiki/Zero). On the other hand, a set with distinct members $a, b, c, \dots$ is mapped to $2^{f(a)} + 2^{f(b)} + 2^{f(c)} + \ldots$

The inverse $f^{-1}:\mathbb{N} \to H_{\aleph_0}$ of this function is given by

$$f^{-1}(i) = \{f^{-1}(j) \mid \text{BIT}(i, j) = 1\}$$

where BIT denotes the [BIT predicate](wikipedia://en/7639504).

The Ackermann coding can be used to construct a model of finitary set theory in the natural numbers. More precisely, $(\mathbb{N}, \text{BIT}^\top)$ (where $\text{BIT}^\top$ is the [converse relation](wikipedia://en/3941020) of $\text{BIT}$, swapping its two arguments) models [Zermelo–Fraenkel set theory](wikipedia://en/152214) without the [axiom of infinity](wikipedia://en/246449). Here, each natural number models a set, and the $\text{BIT}$ relation models the membership relation between sets.

:::

### Graph models {#Graph_models}

The class $H_{\aleph_0}$ can be seen to be in exact correspondence with a class of [rooted trees](wikipedia://en/48560#Rooted_tree), namely those without non-trivial symmetries (i.e. whose only [automorphism](wikipedia://en/15094186) is the identity). The root vertex corresponds to the top level bracket $\{\dots\}$ and each [edge](wikipedia://en/638899) leads to an element (another such set) that can act as a root vertex in its own right. No automorphism of this graph exists, corresponding to the fact that equal branches are identified (e.g. $\{t,t,s\}=\{t,s\}$, trivializing the permutation of the two subgraphs of shape $t$). This graph model enables an implementation of ZF without infinity as data types and thus an interpretation of set theory in expressive [type theories](wikipedia://en/40282).

Graph [models](wikipedia://en/19858) exist for ZF and also set theories different from Zermelo set theory, such as [non-well founded](wikipedia://en/8933657) theories. Such models have more intricate edge structure.

In [graph theory](wikipedia://en/12401), the graph whose vertices correspond to hereditarily finite sets and edges correspond to set membership is the [Rado graph](wikipedia://en/7785594) or random graph.

## Axiomatizations {#Axiomatizations}

### Theories of finite sets {#Theories_of_finite_sets}

In common axiomatic set theory approaches, the empty set $\{\}$ also represents the first von Neumann [ordinal number](wikipedia://en/26547932), denoted $0$. All finite von Neumann ordinals are indeed hereditarily finite and, thus, so is every set in the class of sets representing the natural numbers. In other words, $H_{\aleph_0}$ includes each element in the [standard model of natural numbers](wikipedia://en/428484) and so a set theory expressing $H_{\aleph_0}$ must necessarily contain them as well.

[Robinson arithmetic](wikipedia://en/2544440) can be interpreted in [ST](wikipedia://en/9373204), the very small sub-theory of [Zermelo set theory](wikipedia://en/322623) with only the [axioms](https://en.wikipedia.org/wiki/Axioms) of [extensionality](https://en.wikipedia.org/wiki/Axiom_of_Extensionality), empty set and [adjunction](wikipedia://en/9373204). All of $H_{\aleph_0}$ has a [constructive axiomatization](wikipedia://en/5042360) involving these axioms and, for example, the axioms of [set induction](https://en.wikipedia.org/wiki/Epsilon_induction) and [replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement).

Axiomatically characterizing the theory of hereditarily finite sets, the negation of the [axiom of infinity](wikipedia://en/246449) may be added. As the theory validates the other axioms of ZF, this establishes that the axiom of infinity is not a consequence of these other ZF axioms.

### ZF {#ZF}

*Image: Nested\_set\_V4.svg.* $~V_4~$ represented with circles in place of [curly brackets](wikipedia://en/11219603#Sets_and_groups) *Image: Loupe light.svg.*

The hereditarily finite sets are a subclass of the [Von Neumann universe](wikipedia://en/445980). Here, the class of all well-founded hereditarily finite sets is denoted $V_{\omega}$. Note that this is also a set in this context.

If we denote by $\mathcal{P}(S)$ the [power set](wikipedia://en/23799) of $S$, and by $V_0$ the empty set, then $V_{\omega}$ can be obtained by setting $V_{i+1}=\mathcal{P}(V_i)$ for each $i\geq 0$. Thus, $V_{\omega}$ can be expressed as

$$V_\omega = \bigcup_{k=0}^\infty V_k$$

and all its elements are finite.

This formulation shows, again, that there are only [countably](https://en.wikipedia.org/wiki/Countably) many hereditarily finite sets: $V_n$ is finite for any finite $n$, its [cardinality](wikipedia://en/6174) is $2\uparrow\uparrow (n-1)$ in [Knuth's up-arrow notation](wikipedia://en/258733) (a tower of $n-1$ powers of two), and the union of countably many finite sets is countable.

Equivalently, a set is hereditarily finite if and only if its [transitive closure](wikipedia://en/2462396) is finite.
