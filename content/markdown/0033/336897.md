# Function approximation

::: {#o1 .subject cue=lead name="Function approximation"}

*Image: Step function approximation.png.* Several progressively more accurate approximations of the [step function](wikipedia://en/170939)

*Image: Regression pic gaussien dissymetrique bruite.svg.* An asymmetrical [Gaussian function](wikipedia://en/245552) fit to a noisy curve using regression

In general, a **function approximation** problem asks us to select a [function](wikipedia://en/185427) that closely matches ("approximates") a function in a task-specific way.[^o2] The need for function approximations arises, for example, predicting the growth of microbes in [microbiology](https://en.wikipedia.org/wiki/Microbiology).[^o3] Function approximations are used where theoretical models are unavailable or hard to compute.[^o3]

:::

First, for known target functions [approximation theory](wikipedia://en/1092713) is the branch of [numerical analysis](wikipedia://en/21506) that investigates how certain known functions (for example, [special functions](https://en.wikipedia.org/wiki/Special_function)) can be approximated by a specific class of functions (for example, [polynomials](wikipedia://en/23000) or [rational functions](wikipedia://en/361210)) that often have desirable properties (inexpensive computation, continuity, integral and limit values, etc.).[^o4]

Secondly, for example, if *g* is an operation on the [real numbers](wikipedia://en/20646438), techniques of [interpolation](wikipedia://en/14569), [extrapolation](wikipedia://en/546415), [regression analysis](wikipedia://en/826997), and [curve fitting](wikipedia://en/555425) can be used. If the [codomain](wikipedia://en/50264) (range or target set) of *g* is a finite set, one is dealing with a [classification](wikipedia://en/1579244) problem instead.[^o5]
