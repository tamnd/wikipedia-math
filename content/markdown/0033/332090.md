# Computably enumerable set

::: {#o1 .subject cue=lead name="Computably enumerable set"}

In [computability theory](wikipedia://en/155414), a set *S* of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) is called **computably enumerable (c.e.)**, **recursively enumerable (r.e.)**, **semidecidable**, **partially decidable**, **listable**, **provable** or **Turing-recognizable** if:

:::

- There is an [algorithm](wikipedia://en/775) such that the set of input numbers for which the algorithm halts is exactly *S*.

Or, equivalently,

- There is an [algorithm that enumerates](https://en.wikipedia.org/wiki/Enumeration_algorithm) the members of *S*. That means that its output is a list of all the members of *S*: *s*<sub>1</sub>, *s*<sub>2</sub>, *s*<sub>3</sub>, ... . If *S* is infinite, this algorithm will run forever, but each element of S will be returned after a finite amount of time. Note that these elements do not have to be listed in a particular way, say from smallest to largest.

The first condition suggests why the term *semidecidable* is sometimes used. More precisely, if a number is in the set, one can *decide* this by running the algorithm, but if the number is not in the set, the algorithm can run forever, and no information is returned. A set that is "completely decidable" is a [computable set](wikipedia://en/332264). The second condition suggests why *computably enumerable* is used. The abbreviations **c.e.** and **r.e.** are often used, even in print, instead of the full phrase.

In [computational complexity theory](wikipedia://en/7543), the [complexity class](wikipedia://en/502426) containing all computably enumerable sets is [RE](wikipedia://en/3106703). In recursion theory, the [lattice](wikipedia://en/469304) of c.e. sets under inclusion is denoted $\mathcal{E}$.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A set *S* of natural numbers is called **computably enumerable** if there is a [partial computable function](wikipedia://en/1139338) whose [domain](wikipedia://en/50263) is exactly *S*, meaning that the function is defined if and only if its input is a member of *S*.

:::

## Equivalent formulations {#Equivalent_formulations}

The following are all equivalent properties of a set *S* of natural numbers:

**Semidecidability:**

- The set *S* is computably enumerable. That is, *S* is the domain (co-range) of a partial computable function.
- The set *S* is $\Sigma^0_1$ (referring to the [arithmetical hierarchy](wikipedia://en/186475)).[^o5]
- There is a partial computable function *f* such that: $$f(x) = \begin{cases} 1 &\mbox{if}\ x \in S \\ \mbox{undefined/does not halt}\ &\mbox{if}\ x \notin S \end{cases}$$

**Enumerability:**

- The set *S* is the range of a partial computable function.
- The set *S* is the range of a total computable function, or empty. If *S* is infinite, the function can be chosen to be [injective](https://en.wikipedia.org/wiki/Injective).
- The set *S* is the range of a [primitive recursive function](wikipedia://en/24829) or empty. Even if *S* is infinite, repetition of values may be necessary in this case.

**Diophantine:**

- There is a polynomial *p* with integer coefficients and variables $x,a_1,a_2,a_3,\dots,a_9$ ranging over the natural numbers such that $$x \in S \Leftrightarrow \exists a_1,a_2,a_3,\dots,a_9 \ ( p(x,a_1,a_2,a_3,\dots,a_9) = 0).$$ (The number of bound variables in this definition is the best known so far; it might be that a lower number can be used to define all Diophantine sets.)
- There is a polynomial from the integers to the integers such that the set *S* contains exactly the non-negative numbers in its range.

The equivalence of semidecidability and enumerability can be obtained by the technique of [dovetailing](https://en.wikipedia.org/wiki/Dovetailing_%28computer_science%29).

The Diophantine characterizations of a computably enumerable set, while not as straightforward or intuitive as the first definitions, were found by [Yuri Matiyasevich](wikipedia://en/2627712) as part of the negative solution to [Hilbert's Tenth Problem](wikipedia://en/101851). Diophantine sets predate recursion theory and are therefore historically the first way to describe these sets (although this equivalence was only remarked more than three decades after the introduction of computably enumerable sets).[^o6]

## Examples {#Examples}

- Every [computable set](wikipedia://en/332264) is computably enumerable, but it is not true that every computably enumerable set is computable. For computable sets, the algorithm must also say if an input is *not* in the set – this is not required of computably enumerable sets.
- A [recursively enumerable language](wikipedia://en/54789) is a computably enumerable subset of a [formal language](wikipedia://en/10939).
- The set of all provable sentences in an effectively presented axiomatic system is a computably enumerable set.
- [Matiyasevich's theorem](https://en.wikipedia.org/wiki/Matiyasevich's_theorem) states that every computably enumerable set is a [Diophantine set](wikipedia://en/101700) (the converse is trivially true).
- The [simple sets](wikipedia://en/2451294) are computably enumerable but not computable.
- The [creative sets](https://en.wikipedia.org/wiki/Creative_set) are computably enumerable but not computable.
- Any [productive set](https://en.wikipedia.org/wiki/Productive_set) is **not** computably enumerable.
- Given a [Gödel numbering](wikipedia://en/207790) $\phi$ of the computable functions, the set $\{\langle i,x \rangle \mid \phi_i(x) \downarrow \}$ (where $\langle i,x \rangle$ is the [Cantor pairing function](https://en.wikipedia.org/wiki/Cantor_pairing_function) and $\phi_i(x)\downarrow$ indicates $\phi_i(x)$ is defined) is computably enumerable (cf. picture for a fixed *x*). This set encodes the [halting problem](wikipedia://en/21391870) as it describes the input parameters for which each [Turing machine](wikipedia://en/30403) halts.
- Given a Gödel numbering $\phi$ of the computable functions, the set $\{ \left \langle x, y, z \right \rangle \mid \phi_x(y) = z \}$ is computably enumerable. This set encodes the problem of deciding a function value.
- Given a partial function *f* from the natural numbers into the natural numbers, *f* is a partial computable function if and only if the graph of *f*, that is, the set of all pairs $\langle x,f(x)\rangle$ such that *f*(*x*) is defined, is computably enumerable.

:::

## Properties {#Properties}

If *A* and *B* are computably enumerable sets then *A* ∩ *B*, *A* ∪ *B* and *A* × *B* (with the ordered pair of natural numbers mapped to a single natural number with the [Cantor pairing function](https://en.wikipedia.org/wiki/Cantor_pairing_function)) are computably enumerable sets. The [preimage](https://en.wikipedia.org/wiki/Preimage) of a computably enumerable set under a partial computable function is a computably enumerable set.

A set $T$ is called **co-computably-enumerable** or **co-c.e.** if its [complement](wikipedia://en/54347) $\mathbb{N} \setminus T$ is computably enumerable. Equivalently, a set is co-r.e. if and only if it is at level $\Pi^0_1$ of the arithmetical hierarchy. The complexity class of co-computably-enumerable sets is denoted co-RE.

A set *A* is [computable](wikipedia://en/332264) if and only if both *A* and the complement of *A* are computably enumerable.

Some pairs of computably enumerable sets are [effectively separable](https://en.wikipedia.org/wiki/Effectively_separable) and some are not.

:::

## The lattice of recursively enumerable sets {#The_lattice_of_recursively_enumerable_sets}

The set of all recursively enumerable subsets of the natural numbers can be made into a [poset](https://en.wikipedia.org/wiki/Poset) under [set inclusion](https://en.wikipedia.org/wiki/Set_inclusion); this poset is a [lattice](wikipedia://en/469304).[^o12] The theory of this lattice is known to be an [undecidable problem](wikipedia://en/15631055).[^o12] Similarly, the set of all computably enumerable [vector spaces](https://en.wikipedia.org/wiki/Vector_spaces) also forms a lattice.[^o13] In fact, one can generalize this even further to the lattice *L(Q)*, which is defined to consist of all recursively enumerable [filters](wikipedia://en/19719), where *Q* is some [free Boolean algebra](wikipedia://en/3058220) without any [atoms](wikipedia://en/998824).[^o14] These lattices are closely tied to the study of recursively enumerable [Pi-0-1](https://en.wikipedia.org/wiki/Pi-0-1_sentence) classes.[^o14]

### Intervals {#Intervals}

The [intervals](https://en.wikipedia.org/wiki/Interval_%28order_theory%29) of this lattice are either [boolean algebras](https://en.wikipedia.org/wiki/Boolean_algebras), or their first-order theory is also undecidable.[^o12] The possible structure of intervals of this lattice is not very well understood.[^o12]

### Maximal recursively enumerable sets {#Maximal_recursively_enumerable_sets}

The complement of the function which enumerates any maximal recursively enumerable set dominates every [general recursive function](wikipedia://en/26469).[^o17] There exists maximal recursively enumerable set of [Turing degree](wikipedia://en/764405) at most **0′**.[^o17] For any two maximal recursively enumerable sets *A* and *B*, there exists an [order automorphism](https://en.wikipedia.org/wiki/Order_automorphism) of the lattice of recursively enumerable sets that maps *A* to *B*; this automorphism, however, may not always be computable.[^o18]

## Remarks {#Remarks}

According to the [Church–Turing thesis](wikipedia://en/6854), any effectively calculable function is calculable by a [Turing machine](wikipedia://en/30403), and thus a set *S* is computably enumerable if and only if there is some [algorithm](wikipedia://en/775) which yields an enumeration of *S*. This cannot be taken as a formal definition, however, because the Church–Turing thesis is an informal conjecture rather than a formal axiom.[^o20]

The definition of a computably enumerable set as the *domain* of a partial function, rather than the *range* of a total computable function, is common in contemporary texts. This choice is motivated by the fact that in generalized recursion theories, such as [α-recursion theory](wikipedia://en/12008116), the definition corresponding to domains has been found to be more natural. Other texts use the definition in terms of enumerations, which is equivalent for computably enumerable sets.
