# Nowhere continuous function

::: {#o1 .subject cue=lead name="Nowhere continuous function"}

In [mathematics](wikipedia://en/18831), a **nowhere continuous function**, also called an **everywhere discontinuous function**, is a [function](wikipedia://en/185427) that is not [continuous](wikipedia://en/6122) at any point of its [domain](wikipedia://en/50263). If $f$ is a function from [real numbers](wikipedia://en/20646438) to real numbers, then $f$ is nowhere continuous if for each point $x$ there is some $\varepsilon > 0$ such that for every $\delta > 0,$ we can find a point $y$ such that $|x - y| < \delta$ and $|f(x) - f(y)| \geq \varepsilon$. Therefore, no matter how close it gets to any fixed point, there are even closer points at which the function takes not-nearby values.

:::

More general definitions of this kind of function can be obtained, by replacing the [absolute value](wikipedia://en/991) by the distance function in a [metric space](wikipedia://en/20018), or by using the definition of continuity in a [topological space](wikipedia://en/30450).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

### Dirichlet function {#Dirichlet_function}

One example of such a function is the [indicator function](wikipedia://en/240790) of the [rational numbers](wikipedia://en/19727024), also known as the [Dirichlet function](wikipedia://en/630005). This function is denoted as $\mathbf{1}_\mathbb{Q}$ and has [domain](wikipedia://en/50263) and [codomain](wikipedia://en/50264) both equal to the [real numbers](wikipedia://en/20646438). By definition, $\mathbf{1}_\mathbb{Q}(x)$ is equal to $1$ if $x$ is a [rational number](wikipedia://en/19727024) and it is $0$ otherwise.

More generally, if $E$ is any subset of a [topological space](wikipedia://en/30450) $X$ such that both $E$ and the complement of $E$ are dense in $X,$ then the real-valued function which takes the value $1$ on $E$ and $0$ on the complement of $E$ will be nowhere continuous. Functions of this type were originally investigated by [Peter Gustav Lejeune Dirichlet](wikipedia://en/240002).[^o5]

### Non-trivial additive functions {#Non-trivial_additive_functions}

A function $f : \mathbb{R} \to \mathbb{R}$ is called an [additive function](wikipedia://en/22473529) if it satisfies [Cauchy's functional equation](wikipedia://en/5270898):

$$f(x + y) = f(x) + f(y) \quad \text{ for all } x, y \in \mathbb{R}.$$

For example, every map of form $x \mapsto c x,$ where $c \in \mathbb{R}$ is some constant, is additive (in fact, it is [linear](wikipedia://en/18102) and continuous). Furthermore, every linear map $L : \mathbb{R} \to \mathbb{R}$ is of this form (by taking $c := L(1)$).

Although every [linear map](wikipedia://en/18102) is additive, not all additive maps are linear. An additive map $f : \mathbb{R} \to \mathbb{R}$ is linear if and only if there exists a point at which it is continuous, in which case it is continuous everywhere. Consequently, every non-linear additive function $\mathbb{R} \to \mathbb{R}$ is discontinuous at every point of its domain. Nevertheless, the restriction of any additive function $f : \mathbb{R} \to \mathbb{R}$ to any real scalar multiple of the rational numbers $\mathbb{Q}$ is continuous; explicitly, this means that for every real $r \in \mathbb{R},$ the restriction $f\big\vert_{r \mathbb{Q}} : r \, \mathbb{Q} \to \mathbb{R}$ to the set $r \, \mathbb{Q} := \{r q : q \in \mathbb{Q}\}$ is a continuous function. Thus if $f : \mathbb{R} \to \mathbb{R}$ is a non-linear additive function then for every point $x \in \mathbb{R},$ $f$ is discontinuous at $x$ but $x$ is also contained in some [dense subset](wikipedia://en/23523594) $D \subseteq \mathbb{R}$ on which $f$'s restriction $f\vert_D : D \to \mathbb{R}$ is continuous (specifically, take $D := x \, \mathbb{Q}$ if $x \neq 0,$ and take $D := \mathbb{Q}$ if $x = 0$).

### Discontinuous linear maps {#Discontinuous_linear_maps}

A [linear map](wikipedia://en/18102) between two [topological vector spaces](wikipedia://en/45752), such as [normed spaces](https://en.wikipedia.org/wiki/Normed_space) for example, is continuous (everywhere) if and only if there exists a point at which it is continuous, in which case it is even [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous). Consequently, every linear map is either continuous everywhere or else continuous nowhere. Every [linear functional](https://en.wikipedia.org/wiki/Linear_functional) is a [linear map](wikipedia://en/18102) and on every infinite-dimensional normed space, there exists some [discontinuous linear functional](https://en.wikipedia.org/wiki/Discontinuous_linear_functional).

### Other functions {#Other_functions}

[Conway's base 13 function](wikipedia://en/11151490) is discontinuous at every point.

## Hyperreal characterisation {#Hyperreal_characterisation}

A real function $f$ is nowhere continuous if its natural [hyperreal](wikipedia://en/51429) extension has the property that every $x$ is infinitely close to a $y$ such that the difference $f(x) - f(y)$ is appreciable (that is, not [infinitesimal](wikipedia://en/160990)).

## See also {#See_also}

- [Blumberg theorem](wikipedia://en/63849351) – even if a real function $f : \mathbb{R} \to \mathbb{R}$ is nowhere continuous, there is a dense subset $D$ of $\mathbb{R}$ such that the restriction of $f$ to $D$ is continuous.
- [Thomae's function](wikipedia://en/3397404) (also known as the popcorn function) – a function that is continuous at all irrational numbers and discontinuous at all rational numbers.
- [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function) – a function *continuous* everywhere (inside its domain) and *differentiable* nowhere.
