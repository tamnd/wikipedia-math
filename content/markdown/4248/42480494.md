# En-ring

::: {#o1 .subject cue=lead name="En-ring"}

In [mathematics](wikipedia://en/18831), an **$\mathcal{E}_n$-algebra** in a [symmetric monoidal](wikipedia://en/3865249) [infinity category](https://en.wikipedia.org/wiki/Infinity_category) *C* consists of the following data:

:::

- An [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29) $A(U)$ for any [open subset](https://en.wikipedia.org/wiki/Open_subset) *U* of **R**<sup>n</sup> [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to an *n*-disk.
- A multiplication map:

$$\mu: A(U_1) \otimes \cdots \otimes A(U_m) \to A(V)$$

for any [disjoint](wikipedia://en/39359) open disks $U_j$ contained in some open disk *V*

subject to the requirements that the multiplication maps are compatible with composition, and that $\mu$ is an equivalence if $m=1$. An equivalent definition is that *A* is an [algebra](https://en.wikipedia.org/wiki/Algebra_over_an_operad) in *C* over the little *n*-disks [operad](wikipedia://en/3126358).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- An $\mathcal{E}_n$-algebra in [vector spaces](wikipedia://en/32370) over a [field](wikipedia://en/10603) is a [unital associative algebra](https://en.wikipedia.org/wiki/Unital_associative_algebra) if *n* = 1, and a unital [commutative associative algebra](wikipedia://en/245990) if *n* ≥ 2.
- An $\mathcal{E}_n$-algebra in [categories](wikipedia://en/53759) is a [monoidal category](wikipedia://en/330604) if *n* = 1, a [braided monoidal category](wikipedia://en/1470466) if *n* = 2, and a [symmetric monoidal category](wikipedia://en/3865249) if *n* ≥ 3.
- If Λ is a [commutative ring](wikipedia://en/61346), then $X \mapsto C_*(\Omega^n X; \Lambda)$ defines an $\mathcal{E}_n$-algebra in the infinity category of [chain complexes](wikipedia://en/138404) of $\Lambda$-[modules](wikipedia://en/276410).

:::
