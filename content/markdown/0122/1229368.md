# Asymmetric relation

::: {#o1 .subject cue=lead name="Asymmetric relation"}

In [mathematics](wikipedia://en/18831), an **asymmetric relation** is a [binary relation](wikipedia://en/3931) $R$ on a [set](wikipedia://en/26691) $X$ where for all $a, b \in X,$ if $a$ is related to $b$ then $b$ is *not* related to $a.$[^o2]

:::

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

### Preliminaries {#Preliminaries}

A binary relation on $X$ is any subset $R$ of $X \times X.$ Given $a, b \in X,$ write $a R b$ if and only if $(a, b) \in R,$ which means that $a R b$ is shorthand for $(a, b) \in R.$ The expression $a R b$ is read as "$a$ is related to $b$ by $R.$"

::: {#o7 .definition cue=heading name="Definition"}

### Definition {#Definition}

The binary relation $R$ is called **asymmetric** if for all $a, b \in X,$ if $a R b$ is true then $b R a$ is false; that is, if $(a, b) \in R$ then $(b, a) \not\in R.$ This can be written in the notation of [first-order logic](wikipedia://en/10983) as

$$\forall a, b \in X: a R b \implies \lnot(b R a).$$

A [logically equivalent](wikipedia://en/169324) definition is:

for all $a, b \in X,$ at least one of $a R b$ and $b R a$ is false,

which in first-order logic can be written as:

$$\forall a, b \in X: \lnot(a R b \wedge b R a).$$

A relation is asymmetric if and only if it is both [antisymmetric](wikipedia://en/1176) and [irreflexive](wikipedia://en/200458),[^o8] so this may also be taken as a definition.

:::

:::

::: {#o10 .example cue=heading name="Examples"}

## Examples {#Examples}

An example of an asymmetric relation is the "[less than](https://en.wikipedia.org/wiki/Less_than)" relation $\,<\,$ between [real numbers](wikipedia://en/20646438): if $x < y$ then necessarily $y$ is not less than $x.$ More generally, any strict partial order is an asymmetric relation. Not all asymmetric relations are strict partial orders. An example of an asymmetric non-transitive, even [antitransitive](https://en.wikipedia.org/wiki/Antitransitive) relation is the [rock paper scissors](https://en.wikipedia.org/wiki/Rock_paper_scissors) relation: if $X$ beats $Y,$ then $Y$ does not beat $X;$ and if $X$ beats $Y$ and $Y$ beats $Z,$ then $X$ does not beat $Z.$

[Restrictions](wikipedia://en/3931#Restriction) and [converses](wikipedia://en/3941020) of asymmetric relations are also asymmetric. For example, the restriction of $\,<\,$ from the reals to the integers is still asymmetric, and the converse or dual $\,>\,$ of $\,<\,$ is also asymmetric.

An asymmetric relation need not have the [connex property](https://en.wikipedia.org/wiki/Connex_relation). For example, the [strict subset](https://en.wikipedia.org/wiki/Strict_subset) relation $\,\subsetneq\,$ is asymmetric, and neither of the sets $\{1, 2\}$ and $\{3, 4\}$ is a strict subset of the other. A relation is connex if and only if its complement is asymmetric.

A non-example is the "less than or equal" relation $\leq$. This is not asymmetric, because reversing for example, $x \leq x$ produces $x \leq x$ and both are true. The less-than-or-equal relation is an example of a relation that is neither symmetric nor asymmetric, showing that asymmetry is not the same thing as "not [symmetric](wikipedia://en/200459)".

The [empty relation](https://en.wikipedia.org/wiki/Empty_relation) is the only relation that is ([vacuously](wikipedia://en/51672)) both symmetric and asymmetric.

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The following conditions are sufficient for a relation $R$ to be asymmetric:[^o13]

- $R$ is irreflexive and anti-symmetric (this is also necessary)
- $R$ is irreflexive and transitive. A [transitive relation](wikipedia://en/200463) is asymmetric if and only if it is irreflexive:[^o14] if $aRb$ and $bRa,$ transitivity gives $aRa,$ contradicting irreflexivity. Such a relation is a [strict partial order](https://en.wikipedia.org/wiki/Strict_partial_order).
- $R$ is irreflexive and satisfies [semiorder](wikipedia://en/28771796) property 1 (there do not exist two mutually incomparable two-point linear orders)
- $R$ is antitransitive and anti-symmetric
- $R$ is antitransitive and transitive
- $R$ is antitransitive and satisfies semi-order property 1
