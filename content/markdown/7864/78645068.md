# Extreme set

*Image: Extremenotexposed.png.* The two distinguished points are examples of extreme points of a convex set that are not exposed points. Therefore, not every convex face of a convex set is an exposed face.

::: {#o1 .subject cue=lead name="Extreme set"}

In [mathematics](wikipedia://en/18831), most commonly in [convex geometry](wikipedia://en/4165882), an **extreme set** or **face** of a set $C\subseteq V$ in a [vector space](wikipedia://en/32370) $V$ is a subset $F\subseteq C$ with the property that if for any two points $x,y\in C$ some in-between point $z=\theta x + (1-\theta) y,\theta\in[0,1]$ lies in $F$, then we must have had $x,y\in F$.[^n1]

:::

An **[extreme point](wikipedia://en/454968)** of $C$ is a point $p\in C$ for which $\{p\}$ is a face.[^n1]

An **exposed face** of $C$ is the subset of points of $C$ where a linear functional achieves its minimum on $C$. Thus, if $f$ is a linear functional on $V$ and $\alpha =\inf\{ f(c)\ \colon c\in C\}>-\infty$, then $\{c\in C\ \colon f(c)=\alpha\}$ is an exposed face of $C$. $\{c\in V\ \colon f(c)=\alpha\}$ is called a [supporting hyperplane](wikipedia://en/4165181) of $C$.

An **[exposed point](wikipedia://en/45357429)** of $C$ is a point $p\in C$ such that $\{p\}$ is an exposed face. That is, $f(p) > f(c)$ for all $c\in C\setminus\{p\}$.

An exposed face is a face, but the converse is not true (see the figure). An exposed face of $C$ is convex if $C$ is convex. If $F$ is a face of $C\subseteq V$, then $E\subseteq F$ is a face of $F$ if and only if $E$ is a face of $C$.

## Competing definitions {#Competing_definitions}

Some authors do not include $C$ and/or $\varnothing$ among the (exposed) faces. Some authors require $F$ and/or $C$ to be [convex](wikipedia://en/6292) (else the boundary of a disc is a face of the disc, as well as any subset of the boundary) or closed. Some authors require the functional $f$ to be continuous in a given [vector topology](https://en.wikipedia.org/wiki/Vector_topology).
