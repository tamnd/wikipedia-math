# Sierpiński set

::: {#o1 .subject cue=lead name="Sierpiński set"}

In mathematics, a **Sierpiński set** is an [uncountable](https://en.wikipedia.org/wiki/Uncountable) subset of a [real vector space](https://en.wikipedia.org/wiki/Real_vector_space) whose intersection with every [measure-zero set](https://en.wikipedia.org/wiki/Measure-zero_set) is countable. The existence of Sierpiński sets is independent of the axioms of [ZFC](https://en.wikipedia.org/wiki/ZFC). (txt) showed that they exist if the [continuum hypothesis](wikipedia://en/5705) is true. On the other hand, they do not exist if [Martin's axiom](wikipedia://en/1550783) for ℵ<sub>1</sub> is true. Sierpiński sets are weakly Luzin sets but are not [Luzin sets](https://en.wikipedia.org/wiki/Luzin_set) (Kunen 2011, p. 376).

:::

::: {#o5 .example cue=heading name="Example of a Sierpiński set"}

## Example of a Sierpiński set {#Example_of_a_Sierpiński_set}

Choose a collection of 2<sup>ℵ<sub>0</sub></sup> measure-0 subsets of **R** such that every measure-0 subset is contained in one of them. By the continuum hypothesis, it is possible to enumerate them as *S*<sub>*α*</sub> for countable ordinals *α*. For each countable ordinal *β* choose a real number *x*<sub>*β*</sub> that is not in any of the sets *S*<sub>*α*</sub> for *α* \< *β*, which is possible as the union of these sets has measure 0 so is not the whole of **R**. Then the uncountable set *X* of all these real numbers *x*<sub>*β*</sub> has only a countable number of elements in each set *S*<sub>*α*</sub>, so is a Sierpiński set.

It is possible for a Sierpiński set to be a [subgroup](wikipedia://en/28011) under addition. For this one modifies the construction above by choosing a real number *x*<sub>*β*</sub> that is not in any of the countable number of sets of the form (*S*<sub>*α*</sub> + *X*)/*n* for *α* \< *β*, where *n* is a positive integer and *X* is an integral linear combination of the numbers *x*<sub>*α*</sub> for *α* \< *β*. Then the group generated by these numbers is a Sierpiński set and a group under addition. More complicated variations of this construction produce examples of Sierpiński sets that are [subfields](wikipedia://en/11634) or [real-closed subfields](https://en.wikipedia.org/wiki/Real-closed_field) of the real numbers.

:::
