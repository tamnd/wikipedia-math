# Whitney extension theorem

::: {#o1 .subject cue=lead name="Whitney extension theorem"}

In [mathematics](wikipedia://en/18831), in particular in [mathematical analysis](wikipedia://en/48396), the **Whitney extension theorem** is a partial converse to [Taylor's theorem](wikipedia://en/51714). Roughly speaking, the theorem asserts that if *A* is a [closed subset](https://en.wikipedia.org/wiki/Closed_subset) of a [Euclidean space](wikipedia://en/9697), then it is possible to extend a given function of *A* in such a way as to have prescribed derivatives at the points of *A*. It is a result of [Hassler Whitney](wikipedia://en/391794).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

A precise statement of the theorem requires careful consideration of what it means to prescribe the derivative of a function on a closed set. One difficulty, for instance, is that closed subsets of Euclidean space in general lack a [differentiable structure](https://en.wikipedia.org/wiki/Differentiable_structure). The starting point, then, is an examination of the statement of Taylor's theorem.

Given a real-valued *C*<sup>*m*</sup> function *f*(**x**) on **R**<sup>*n*</sup>, Taylor's theorem asserts that for each **a**, **x**, **y** ∈ **R**<sup>*n*</sup>, there is a function *R*<sub>*α*</sub>(**x**,**y**) approaching 0 uniformly as **x**,**y** → **a** such that

::: {#o4 .equation cue=numblk name="1"}

$$f({\mathbf x}) = \sum_{|\alpha|\le m} \frac{D^\alpha f({\mathbf y})}{\alpha!}\cdot ({\mathbf x}-{\mathbf y})^{\alpha}+\sum_{|\alpha|=m} R_\alpha({\mathbf x},{\mathbf y})\frac{({\mathbf x}-{\mathbf y})^\alpha}{\alpha!} \tag{1}$$

:::

where the sum is over [multi-indices](https://en.wikipedia.org/wiki/Multi-index) *α*.

Let *f*<sub>*α*</sub> = *D*<sup>*α*</sup>*f* for each multi-index *α*. Differentiating (1) with respect to **x**, and possibly replacing *R* as needed, yields

::: {#o5 .equation cue=numblk name="2"}

$$f_\alpha({\mathbf x})=\sum_{|\beta|\le m-|\alpha|}\frac{f_{\alpha+\beta}({\mathbf y})}{\beta!}({\mathbf x}-{\mathbf y})^{\beta}+R_\alpha({\mathbf x},{\mathbf y}) \tag{2}$$

:::

where *R*<sub>*α*</sub> is *o*(|**x** − **y**|<sup>*m*−|*α*|</sup>) uniformly as **x**,**y** → **a**.

Note that ((2)) may be regarded as purely a compatibility condition between the functions *f*<sub>α</sub> which must be satisfied in order for these functions to be the coefficients of the [Taylor series](wikipedia://en/30448) of the function *f*. It is this insight which facilitates the following statement:

::: {#o6 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Suppose that *f*<sub>*α*</sub> are a collection of functions on a closed subset *A* of **R**<sup>*n*</sup> for all multi-indices α with $|\alpha|\le m$ satisfying the compatibility condition ((2)) at all points *x*, *y*, and *a* of *A*. Then there exists a function *F*(**x**) of class *C*<sup>*m*</sup> such that:

1. *F* = *f*<sub>0</sub> on *A*.
1. *D*<sup>*α*</sup>*F* = *f*<sub>*α*</sub> on *A*.
1. *F* is real-analytic at every point of **R**<sup>*n*</sup> − *A*.

Proofs are given in the original paper of (Whitney 1934), and in (Malgrange 1967), (Bierstone 1980) and (Hörmander 1990).

:::

## Extension in a half space {#Extension_in_a_half_space}

(Seeley 1964) proved a sharpening of the Whitney extension theorem in the special case of a half space. A [smooth function](wikipedia://en/1408000) on a half space **R**<sup>*n*,+</sup> of points where *x*<sub>*n*</sub> ≥ 0 is a smooth function *f* on the interior *x*<sub>*n*</sub> for which the derivatives ∂<sup>α</sup> *f* [extend to continuous functions](https://en.wikipedia.org/wiki/Continuous_extension) on the half space. On the boundary *x*<sub>*n*</sub> = 0, *f* restricts to smooth function. By [Borel's lemma](wikipedia://en/1461105), *f* can be extended to a smooth function on the whole of **R**<sup>*n*</sup>. Since Borel's lemma is local in nature, the same argument shows that if $\Omega$ is a (bounded or unbounded) domain in **R**<sup>*n*</sup> with smooth boundary, then any smooth function on the closure of $\Omega$ can be extended to a smooth function on **R**<sup>*n*</sup>.

Seeley's result for a half line gives a uniform extension map

$$\displaystyle{E:C^\infty(\mathbf{R}^+)\rightarrow C^\infty(\mathbf{R}),}$$

which is linear, continuous (for the [topology of uniform convergence](wikipedia://en/41677409) of functions and their derivatives on compacta) and takes functions supported in \[0,*R*\] into functions supported in \[−*R*,*R*\]

To define $E,$ set[^o14]

$$\displaystyle{E(f)(x)=\sum_{m=1}^\infty a_m f(-b_mx)\varphi(-b_mx) \,\,\, (x < 0),}$$

where φ is a smooth function of compact support on *R* equal to 1 near 0 and the sequences (*a*<sub>*m*</sub>), (*b*<sub>*m*</sub>) satisfy:

- $b_m > 0$ tends to $\infty$;
- $\sum a_m b_m^j = (-1)^j$ for $j \geq 0$ with the sum absolutely convergent.

A solution to this system of equations can be obtained by taking $b_n = 2^n$ and seeking an [entire function](wikipedia://en/10372)

$$g(z)=\sum_{m=1}^\infty a_m z^m$$

such that $g\left(2^j\right) = (-1)^j.$ That such a function can be constructed follows from the [Weierstrass theorem](wikipedia://en/1585155) and [Mittag-Leffler theorem](https://en.wikipedia.org/wiki/Mittag-Leffler_theorem).[^o15]

It can be seen directly by setting[^o16]

$$W(z)=\prod_{j \ge 1} (1-z/2^j),$$

an entire function with simple zeros at $2^j.$ The derivatives *W* '(2<sup>*j*</sup>) are bounded above and below. Similarly the function

$$M(z)=\sum_{j \ge 1} {(-1)^j\over W^\prime(2^j) (z-2^j)}$$

meromorphic with simple poles and prescribed residues at $2^j.$

By construction

$$\displaystyle{g(z)=W(z)M(z)}$$

is an entire function with the required properties.

The definition for a half space in **R**<sup>*n*</sup> by applying the operator *E* to the last variable *x*<sub>*n*</sub>. Similarly, using a smooth [partition of unity](wikipedia://en/48636) and a local change of variables, the result for a half space implies the existence of an analogous extending map

$$\displaystyle{C^\infty(\overline{\Omega}) \rightarrow C^\infty(\mathbf{R}^n)}$$

for any domain $\Omega$ in **R**<sup>*n*</sup> with smooth boundary.
