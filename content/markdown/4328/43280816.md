# Orthodox semigroup

::: {#o1 .subject cue=lead name="Orthodox semigroup"}

In [mathematics](wikipedia://en/18831), an **orthodox semigroup** is a [regular semigroup](wikipedia://en/6797677) whose set of [idempotents](https://en.wikipedia.org/wiki/Idempotent) forms a [subsemigroup](https://en.wikipedia.org/wiki/Subsemigroup). In more recent terminology, an orthodox semigroup is a regular [*E*-semigroup](wikipedia://en/43724607).[^o2] The term *orthodox semigroup* was coined by T. E. Hall and presented in a paper published in 1969.[^o3][^o4] Certain special classes of orthodox semigroups had been studied earlier. For example, semigroups that are also unions of groups, in which the sets of idempotents form subsemigroups were studied by P. H. H. Fantham in 1960.[^o5]

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- Consider the [binary operation](wikipedia://en/3948) on the set *S* = { *a*, *b*, *c*, *x* } defined by the following [Cayley table](wikipedia://en/1802723) :

::: {#o8 .table cue=table}

|  | *a* | *b* | *c* | *x* |
|---|---|---|---|---|
| *a* | *a* | *b* | *c* | *x* |
| *b* | *b* | *b* | *b* | *b* |
| *c* | *c* | *c* | *c* | *c* |
| *x* | *x* | *c* | *b* | *a* |

:::

Then *S* is an orthodox semigroup under this operation, the subsemigroup of idempotents being { *a*, *b*, *c* }.[^o11]

- [Inverse semigroups](wikipedia://en/1757814) and [bands](https://en.wikipedia.org/wiki/Band_%28mathematics%29) are examples of orthodox semigroups.[^o9]

:::

## Some elementary properties {#Some_elementary_properties}

The set of idempotents in an orthodox semigroup has several interesting properties. Let *S* be a regular semigroup and for any *a* in *S* let *V*(*a*) denote the set of inverses of *a*. Then the following are equivalent:[^o11]

- *S* is orthodox.
- If *a* and *b* are in *S* and if *x* is in *V*(*a*) and *y* is in *V*(*b*) then *yx* is in *V*(*ab*).
- If *e* is an idempotent in *S* then every inverse of *e* is also an idempotent.
- For every *a*, *b* in *S*, if *V*(*a*) ∩ *V*(*b*) ≠ ∅ then *V*(*a*) = *V*(*b*).

## Structure {#Structure}

The structure of orthodox semigroups have been determined in terms of bands and inverse semigroups. The Hall–Yamada pullback theorem describes this construction. The construction requires the concepts of [pullbacks](wikipedia://en/9413508) (in the [category](wikipedia://en/5869) of semigroups) and [Nambooripad](wikipedia://en/23534956) representation of a fundamental regular semigroup.[^o9]
