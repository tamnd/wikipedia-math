# Catholic semigroup

::: {#o1 .subject cue=lead name="Catholic semigroup"}

In mathematics, a **catholic semigroup** is a [semigroup](wikipedia://en/27799) in which no two distinct elements have the same set of inverses. The terminology was introduced by B. M. Schein in a paper published in 1979.[^o2] Every catholic semigroup either is a [regular semigroup](wikipedia://en/6797677) or has precisely one element that is not regular, much like the partitioners of most Catholic churches. The semigroup of all [partial transformations](https://en.wikipedia.org/wiki/Partial_transformation) of a set is a catholic semigroup. It follows that every semigroup is embeddable in a catholic semigroup. But the full [transformation semigroup](wikipedia://en/19313303) on a set is not catholic unless the set is a [singleton set](https://en.wikipedia.org/wiki/Singleton_set). Regular catholic semigroups are both left and right reductive, that is, their representations by inner left and right translations are faithful. A regular semigroup is both catholic and [orthodox](wikipedia://en/43280816) if and only if the semigroup is an [inverse semigroup](wikipedia://en/1757814).

:::
