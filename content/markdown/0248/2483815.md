# MV-algebra

::: {#o1 .subject cue=lead name="MV-algebra"}

In [abstract algebra](wikipedia://en/19616384), a branch of pure [mathematics](wikipedia://en/18831), an **MV-algebra** is an [algebraic structure](wikipedia://en/106364) with a [binary operation](wikipedia://en/3948) $\oplus$, a [unary operation](wikipedia://en/161006) $\neg$, and the constant $0$, satisfying certain axioms. MV-algebras are the [algebraic semantics](wikipedia://en/2848519) of [Łukasiewicz logic](wikipedia://en/11001950); the letters MV refer to the [*many-valued* logic](wikipedia://en/38024) of [Łukasiewicz](wikipedia://en/305064). MV-algebras coincide with the class of bounded [commutative](wikipedia://en/16046999#BCK_algebra) [BCK algebras](wikipedia://en/16046999).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

An **MV-algebra** is an [algebraic structure](wikipedia://en/106364) $\langle A, \oplus, \lnot, 0\rangle,$ consisting of

- a [non-empty](wikipedia://en/9566) [set](wikipedia://en/26691) $A,$
- a [binary operation](wikipedia://en/3948) $\oplus$ on $A,$
- a [unary operation](wikipedia://en/161006) $\lnot$ on $A,$ and
- a constant $0$ denoting a fixed [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of $A,$

which satisfies the following [identities](wikipedia://en/298428):

- $$(x \oplus y) \oplus z = x \oplus (y \oplus z),$$
- $$x \oplus 0 = x,$$
- $$x \oplus y = y \oplus x,$$
- $$\lnot \lnot x = x,$$
- $x \oplus \lnot 0 = \lnot 0,$ and
- $$\lnot ( \lnot x \oplus y)\oplus y = \lnot ( \lnot y \oplus x) \oplus x.$$

By virtue of the first three axioms, $\langle A, \oplus, 0 \rangle$ is a commutative [monoid](wikipedia://en/19652). Being defined by identities, MV-algebras form a [variety](wikipedia://en/1021753) of algebras. The variety of MV-algebras is a subvariety of the variety of [BL](wikipedia://en/16991824)-algebras and contains all [Boolean algebras](wikipedia://en/3959).

An MV-algebra can equivalently be defined ([Hájek](https://en.wikipedia.org/wiki/Petr_Hájek) 1998) as a prelinear commutative bounded integral [residuated lattice](wikipedia://en/2483542) $\langle L, \wedge, \vee, \otimes, \rightarrow, 0, 1 \rangle$ satisfying the additional identity $x \vee y = (x \rightarrow y) \rightarrow y.$

:::

## Examples of MV-algebras {#Examples_of_MV-algebras}

A simple numerical example is $A=[0,1],$ with operations $x \oplus y = \min(x + y, 1)$ and $\lnot x = 1 - x.$ In mathematical [fuzzy logic](wikipedia://en/49180), this MV-algebra is called the *standard MV-algebra*, as it forms the standard real-valued semantics of [Łukasiewicz logic](wikipedia://en/11001950).

The *trivial* MV-algebra has the only element 0 and the operations defined in the only possible way, $0\oplus0=0$ and $\lnot0=0.$

The *two-element* MV-algebra is actually the [two-element Boolean algebra](wikipedia://en/2584449) $\{0,1\},$ with $\oplus$ coinciding with Boolean disjunction and $\lnot$ with Boolean negation. In fact adding the axiom $x \oplus x = x$ to the axioms defining an MV-algebra results in an axiomatization of Boolean algebras.

If instead the axiom added is $x \oplus x \oplus x = x \oplus x$, then the axioms define the MV<sub>3</sub> algebra corresponding to the three-valued Łukasiewicz logic Ł<sub>3</sub>. Other finite linearly ordered MV-algebras are obtained by restricting the universe and operations of the standard MV-algebra to the set of $n$ equidistant real numbers between 0 and 1 (both included), that is, the set $\{0,1/(n-1),2/(n-1),\dots,1\},$ which is closed under the operations $\oplus$ and $\lnot$ of the standard MV-algebra; these algebras are usually denoted MV<sub>*n*</sub>.

Another important example is *[Chang](https://en.wikipedia.org/wiki/C._C._Chang)'s MV-algebra*, consisting just of [infinitesimals](wikipedia://en/160990) (with the [order type](wikipedia://en/4499021) ω) and their co-infinitesimals.

Chang also constructed an MV-algebra from an arbitrary [totally ordered abelian group](wikipedia://en/349014) *G* by fixing a positive element *u* and defining the segment \[0, *u*\] as { *x* ∈ *G* | 0 ≤ *x* ≤ *u* }, which becomes an MV-algebra with *x* ⊕ *y* = min(*u*, *x* + *y*) and ¬*x* = *u* − *x*. Furthermore, Chang showed that every linearly ordered MV-algebra is isomorphic to an MV-algebra constructed from a group in this way.

Daniele Mundici extended the above construction to abelian [lattice-ordered groups](https://en.wikipedia.org/wiki/Lattice-ordered_group). If *G* is such a group with strong (order) unit *u*, then the "[unit interval](wikipedia://en/49324)" { *x* ∈ *G* | 0 ≤ *x* ≤ *u* } can be equipped with ¬*x* = *u* − *x*, *x* ⊕ *y* = *u* ∧<sub>G</sub> (x + y), and *x* ⊗ *y* = 0 ∨<sub>G</sub> (*x* + *y* − *u*). This construction establishes a [categorical equivalence](https://en.wikipedia.org/wiki/Categorical_equivalence) between lattice-ordered abelian groups with strong unit and MV-algebras.

An [effect algebra](wikipedia://en/49447339) that is lattice-ordered and has the [Riesz decomposition property](wikipedia://en/17936142) is an MV-algebra. Conversely, any MV-algebra is a lattice-ordered effect algebra with the Riesz decomposition property.[^o5]

## Relation to Łukasiewicz logic {#Relation_to_Łukasiewicz_logic}

[C. C. Chang](https://en.wikipedia.org/wiki/C._C._Chang) devised MV-algebras to study [many-valued logics](wikipedia://en/38024), introduced by [Jan Łukasiewicz](wikipedia://en/305064) in 1920. In particular, MV-algebras form the [algebraic semantics](wikipedia://en/2848519) of [Łukasiewicz logic](wikipedia://en/11001950), as described below.

Given an MV-algebra *A*, an *A*-[valuation](wikipedia://en/17456938) is a [homomorphism](wikipedia://en/13564) from the algebra of [propositional formulas](wikipedia://en/1557634) (in the language consisting of $\oplus,\lnot,$ and 0) into *A*. Formulas mapped to 1 (that is, to $\lnot$0) for all *A*-valuations are called *A*-[tautologies](wikipedia://en/4495335). If the standard MV-algebra over \[0,1\] is employed, the set of all \[0,1\]-tautologies determines so-called infinite-valued [Łukasiewicz logic](wikipedia://en/11001950).

Chang's (1958, 1959) completeness theorem states that any MV-algebra equation holding in the standard MV-algebra over the interval \[0,1\] will hold in every MV-algebra. Algebraically, this means that the standard MV-algebra generates the variety of all MV-algebras. Equivalently, Chang's completeness theorem says that MV-algebras characterize infinite-valued [Łukasiewicz logic](wikipedia://en/11001950), defined as the set of \[0,1\]-tautologies.

The way the \[0,1\] MV-algebra characterizes all possible MV-algebras parallels the well-known fact that identities holding in the [two-element Boolean algebra](wikipedia://en/2584449) hold in all possible Boolean algebras. Moreover, MV-algebras characterize infinite-valued [Łukasiewicz logic](wikipedia://en/11001950) in a manner analogous to the way that [Boolean algebras](https://en.wikipedia.org/wiki/Boolean_algebras) characterize classical [bivalent logic](wikipedia://en/2584449) (see [Lindenbaum–Tarski algebra](wikipedia://en/990343)).

In 1984, Font, Rodriguez and Torrens introduced the [Wajsberg algebra](https://en.wikipedia.org/wiki/Wajsberg_algebra) as an alternative model for the infinite-valued Łukasiewicz logic. Wajsberg algebras and MV-algebras are term-equivalent.[^o7]

### MV<sub>*n*</sub>-algebras {#MVn-algebras}

In the 1940s, [Grigore Moisil](wikipedia://en/4000394) introduced his [Łukasiewicz–Moisil algebras](wikipedia://en/43613625) (LM<sub>*n*</sub>-algebras) in the hope of giving [algebraic semantics](wikipedia://en/2848519) for the (finitely) *n*-valued [Łukasiewicz logic](wikipedia://en/11001950). However, in 1956, Alan Rose discovered that for *n* ≥ 5, the Łukasiewicz–Moisil algebra does not [model](https://en.wikipedia.org/wiki/Model_%28mathematical_logic%29) the Łukasiewicz *n*-valued logic. Although C. C. Chang published his MV-algebra in 1958, it is a faithful model only for the ℵ<sub>0</sub>-valued (infinitely-many-valued) [Łukasiewicz–Tarski logic](https://en.wikipedia.org/wiki/Łukasiewicz–Tarski_logic). For the axiomatically more complicated (finitely) *n*-valued Łukasiewicz logics, suitable algebras were published in 1977 by [Revaz Grigolia](https://en.wikipedia.org/wiki/Revaz_Grigolia) and called MV<sub>*n*</sub>-algebras.[^o9] MV<sub>*n*</sub>-algebras are a subclass of LM<sub>*n*</sub>-algebras; the inclusion is strict for *n* ≥ 5.[^o10]

The MV<sub>*n*</sub>-algebras are MV-algebras that satisfy some additional axioms, just like the *n*-valued Łukasiewicz logics have additional axioms added to the ℵ<sub>0</sub>-valued logic.

In 1982, [Roberto Cignoli](https://en.wikipedia.org/wiki/Roberto_Cignoli) published some additional constraints that added to LM<sub>*n*</sub>-algebras yield proper models for *n*-valued Łukasiewicz logic; Cignoli called his discovery *proper n-valued Łukasiewicz algebras*.[^o11] The LM<sub>*n*</sub>-algebras that are also MV<sub>*n*</sub>-algebras are precisely Cignoli's proper *n*-valued Łukasiewicz algebras.[^o12]

## Relation to functional analysis {#Relation_to_functional_analysis}

MV-algebras were related by [Daniele Mundici](https://en.wikipedia.org/wiki/Daniele_Mundici) to [approximately finite-dimensional C\*-algebras](wikipedia://en/17936142) by establishing a bijective correspondence between all isomorphism classes of approximately finite-dimensional C\*-algebras with lattice-ordered dimension group and all isomorphism classes of countable MV algebras. Some instances of this correspondence include:

::: {#o14 .table cue=table}

| Countable MV algebra | approximately finite-dimensional C\*-algebra |
|---|---|
| {0, 1} | $\mathbb{C}$ |
| {0, 1/*n*, ..., 1 } | $M_n (\mathbb{C})$, i.e. *n*×*n* complex matrices |
| finite | finite-dimensional |
| Boolean | commutative |

:::

## In software {#In_software}

There are multiple frameworks implementing fuzzy logic (type II), and most of them implement what has been called a **multi-adjoint logic**. This is no more than the implementation of an MV-algebra.
