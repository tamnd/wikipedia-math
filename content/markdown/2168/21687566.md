# Pseudoideal

::: {#o1 .subject cue=lead name="Pseudoideal"}

In the theory of [partially ordered sets](wikipedia://en/23572), a **pseudoideal** is a subset characterized by a bounding operator LU.

:::

## Basic definitions {#Basic_definitions}

LU(*A*) is the set of all [lower bounds](https://en.wikipedia.org/wiki/Lower_bound) of the set of all [upper bounds](https://en.wikipedia.org/wiki/Upper_bound) of the subset *A* of a [partially ordered set](wikipedia://en/23572).

A subset *I* of a partially ordered set (*P*, ≤) is a **Doyle pseudoideal**, if the following condition holds:

For every finite subset *S* of *P* that has a [supremum](https://en.wikipedia.org/wiki/Supremum) in *P*, if $S\subseteq I$ then $\operatorname{LU}(S)\subseteq I$.

A subset *I* of a partially ordered set (*P*, ≤) is a **pseudoideal**, if the following condition holds:

For every subset *S* of *P* having at most two elements that has a [supremum](https://en.wikipedia.org/wiki/Supremum) in *P*, if *S* $\subseteq$ *I* then LU(*S*) $\subseteq$ *I*.

## Remarks {#Remarks}

1. Every [Frink ideal](wikipedia://en/21687353) *I* is a Doyle pseudoideal.
1. A subset *I* of a lattice (*P*, ≤) is a Doyle pseudoideal [if and only if](wikipedia://en/14922) it is a lower set that is closed under finite joins ([suprema](https://en.wikipedia.org/wiki/Suprema)).
