# Frink ideal

::: {#o1 .subject cue=lead name="Frink ideal"}

In [mathematics](wikipedia://en/18831), a **Frink ideal**, introduced by [Orrin Frink](wikipedia://en/38498178), is a certain kind of subset of a [partially ordered set](wikipedia://en/23572).

:::

## Basic definitions {#Basic_definitions}

LU(*A*) is the set of all common [lower bounds](https://en.wikipedia.org/wiki/Lower_bound) of the set of all common [upper bounds](https://en.wikipedia.org/wiki/Upper_bound) of the subset *A* of a [partially ordered set](wikipedia://en/23572).

A subset *I* of a partially ordered set (*P*, ≤) is a **Frink ideal**, if the following condition holds:

For every finite subset *S* of *I*, we have LU(*S*) $\subseteq$ *I*.

A subset *I* of a partially ordered set (*P*, ≤) is a **normal ideal** or a **cut** if LU(*I*) $\subseteq$ *I*.

## Remarks {#Remarks}

1. Every Frink ideal *I* is a [lower set](https://en.wikipedia.org/wiki/Lower_set).
1. A subset *I* of a [lattice](wikipedia://en/469304) (*P*, ≤) is a Frink ideal [if and only if](wikipedia://en/14922) it is a lower set that is closed under finite joins ([suprema](https://en.wikipedia.org/wiki/Suprema)).
1. Every normal ideal is a Frink ideal.
