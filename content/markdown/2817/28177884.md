# Analyst's traveling salesman theorem

::: {#o1 .subject cue=lead name="Analyst's traveling salesman theorem"}

The **analyst's traveling salesman problem** is an analog of the [traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem) in [combinatorial optimization](wikipedia://en/420555). In its simplest and original form, it asks which plane sets are subsets of [rectifiable curves](wikipedia://en/89246) of finite length. Whereas the original traveling salesman problem asks for the shortest way to visit every vertex in a [finite set](wikipedia://en/11742) with a discrete path, this analytical version may require the curve to visit infinitely many points.

:::

## β-numbers {#β-numbers}

A rectifiable curve has [tangents](wikipedia://en/31482) at almost all of its points, where in this case "almost all" means all but a subset whose one-dimensional [Hausdorff measure](wikipedia://en/504109) is zero. Accordingly, if a set is contained in a rectifiable curve, the set must look *flat* when zooming in on almost all of its points. This suggests that testing us whether a set could be contained in a rectifiable curve must somehow incorporate information about how flat it is when one zooms in on its points at different scales.

This discussion motivates the definition of the following quantity, for a plane set $E\subset\mathbb{R}^2$: $\beta_{E}(Q)=\frac{1}{l(Q)}\inf\{\delta:{}$there is a line $L$ so that for every $x\in E\cap Q,$ dist$(x,L)<\delta\},$

where $E$ is the set that is to be contained in a rectifiable curve, $Q$ is any square, $l(Q)$ is the side length of $Q$, and dist$(x,L)$ measures the distance from $x$ to the line $L$. Intuitively, $2\beta_E(Q)l(Q)$ is the width of the smallest rectangle containing the portion of $E$ inside $Q$, and hence $\beta_E(Q)$ gives a scale invariant notion of *flatness*.

::: {#o4 .statement kind=statement/theorem cue=named-heading name="Jones' traveling salesman theorem in R2"}

## Jones' traveling salesman theorem in R<sup>2</sup> {#Jones'_traveling_salesman_theorem_in_R2}

Let Δ denote the collection of dyadic squares, that is,

$$\Delta=\{[i2^{k},(i+1)2^{k}]\times[j2^{k},(j+1)2^{k}]: i,j,k\in\mathbb{Z}\},$$

where $\mathbb{Z}$ denotes the set of integers. For a set $E\subseteq\mathbb{R}^2$, define

$$\beta(E)=\text{diam} E+ \sum_{Q\in\Delta}\beta_{E}(3Q)^2 l(Q)$$

where diam *E* is the [diameter](wikipedia://en/8007) of *E* and $3Q$ is the square with same center as $Q$ with side length $3 l(Q)$. Then [Peter Jones](wikipedia://en/1604461)'s[^o5] analyst's traveling salesman theorem may be stated as follows:

- There is a number *C* > 0 such that whenever *E* is a set such that *β*(*E*) \< ∞, *E* can be contained in a curve with length no more than *Cβ*(*E*).
- Conversely (and substantially more difficult to prove), if Γ is a rectifiable curve, then *β*(Γ) \< CH<sup>1</sup>(Γ), where H<sup>1</sup> is the [Hausdorff 1-measure](wikipedia://en/504109)

:::

## Generalizations and Menger curvature {#Generalizations_and_Menger_curvature}

### Euclidean space and Hilbert space {#Euclidean_space_and_Hilbert_space}

The Traveling Salesman Theorem was shown to hold in general Euclidean spaces by [Kate Okikiolu](wikipedia://en/42212260),[^o8] that is, the same theorem above holds for sets $E\subseteq\mathbb{R}^d$, *d* > 1, where Δ is now the collection of dyadic cubes in $\mathbb{R}^d$ defined in a similar way as dyadic squares. In her proof, the constant *C* grows exponentially with the dimension *d*.

With some slight modifications to the definition of *β*(*E*), Raanan Schul[^o9] showed Traveling Salesman Theorem also holds for sets *E* that lie in any [Hilbert Space](https://en.wikipedia.org/wiki/Hilbert_Space), and in particular, implies the theorems of Jones and Okikiolu, where now the constant *C* is independent of dimension. (In particular, this involves using *β*-numbers of balls instead of cubes).

### Menger curvature and metric spaces {#Menger_curvature_and_metric_spaces}

Hahlomaa[^o11] further adjusted the definition of *β*(*E*) to get a condition for when a set *E* of an arbitrary [metric space](wikipedia://en/20018) may be contained in the [Lipschitz](wikipedia://en/51731)-image of a subset $A\subseteq\mathbb{R}$ of positive measure. For this, he had to redefine the definition of the *β*-numbers using [Menger curvature](wikipedia://en/11830372) (since in a metric space there isn't necessarily a notion of a cube or a straight line).

[Menger curvature](wikipedia://en/11830372), as in the previous example, can be used to give numerical estimates that determine whether a set contains a rectifiable subset, and the proofs of these results frequently depend on *β*-numbers.

::: {#o13 .statement kind=statement/theorem cue=named-heading name="Denjoy–Riesz theorem"}

### Denjoy–Riesz theorem {#Denjoy–Riesz_theorem}

The [Denjoy–Riesz theorem](wikipedia://en/48130890) gives general conditions under which a point set can be covered by the homeomorphic image of a curve. This is true, in particular, for every compact [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected) subset of the [Euclidean plane](wikipedia://en/15575410). However, it may be necessary for such an arc to have infinite length, failing to meet the conditions of the analyst's traveling salesman theorem.

:::
