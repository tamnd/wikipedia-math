# Prune and search

::: {#o1 .subject cue=lead name="Prune and search"}

**Prune and search** is a method of solving [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) problems suggested by [Nimrod Megiddo](https://en.wikipedia.org/wiki/Nimrod_Megiddo) in 1983.[^o2]

:::

The basic idea of the method is a recursive procedure in which at each step the input size is reduced ("pruned") by a constant factor $0 < p < 1$. As such, it is a form of [decrease and conquer algorithm](https://en.wikipedia.org/wiki/Decrease_and_conquer_algorithm), where at each step the decrease is by a constant factor. Let $n$ be the input size, $T(n)$ be the [time complexity](wikipedia://en/405944) of the whole prune-and-search algorithm, and $S(n)$ be the time complexity of the pruning step. Then $T(n)$ obeys the following [recurrence relation](wikipedia://en/146806):

$$T(n) = S(n) + T(n(1-p)).$$

This resembles the recurrence for [binary search](wikipedia://en/4266) but has a larger $S(n)$ term than the constant term of binary search. In prune and search algorithms S(n) is typically at least linear (since the whole input must be processed). With this assumption, the recurrence has the solution $T(n) = O(S(n))$. This can be seen either by applying the [master theorem for divide-and-conquer recurrences](wikipedia://en/561585) or by observing that the times for the recursive subproblems decrease in a [geometric series](wikipedia://en/12630).

In particular, Megiddo himself used this approach in his [linear time](https://en.wikipedia.org/wiki/Linear_time) algorithm for the [linear programming](wikipedia://en/43730) problem when the dimension is fixed[^o3] and for the [minimal enclosing sphere](https://en.wikipedia.org/wiki/Minimal_enclosing_sphere) problem for a set of points in space.[^o2]
