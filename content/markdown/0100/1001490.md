# Convex conjugate

::: {#o1 .subject cue=lead name="Convex conjugate"}

In [mathematics](wikipedia://en/18831) and [mathematical optimization](wikipedia://en/52033), the **convex conjugate** of a function is a generalization of the [Legendre transformation](wikipedia://en/390273) which applies to non-convex functions. It is also known as **Legendre–Fenchel transformation**, **Fenchel transformation**, or **Fenchel conjugate** (after [Adrien-Marie Legendre](wikipedia://en/49695) and [Werner Fenchel](wikipedia://en/4784468)). The convex conjugate is widely used for constructing the [dual problem](wikipedia://en/3372717) in [optimization theory](https://en.wikipedia.org/wiki/Optimization_theory), thus generalizing [Lagrangian duality](wikipedia://en/3372717#Lagrange_duality).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [real](wikipedia://en/20646438) [topological vector space](wikipedia://en/45752) and let $X^{*}$ be the [dual space](wikipedia://en/7988) to $X$. Denote by

$$\langle \cdot , \cdot \rangle : X^{*} \times X \to \mathbb{R}$$

the canonical [dual pairing](https://en.wikipedia.org/wiki/Dual_pair), which is defined by $\left\langle x^*, x \right\rangle = x^* (x).$

For a function $f : X \to \mathbb{R} \cup \{ - \infty, + \infty \}$ taking values on the [extended real number line](wikipedia://en/51698), its **convex conjugate** is the function

$$f^{*} : X^{*} \to \mathbb{R} \cup \{ - \infty, + \infty \}$$

whose value at $x^* \in X^{*}$ is defined to be the [supremum](https://en.wikipedia.org/wiki/Supremum):

$$f^{*} \left( x^{*} \right) := \sup \left\{ \left\langle x^{*}, x \right\rangle - f (x) ~\colon~ x \in X \right\},$$

or, equivalently, in terms of the [infimum](https://en.wikipedia.org/wiki/Infimum):

$$f^{*} \left( x^{*} \right) := - \inf \left\{ f (x) - \left\langle x^{*}, x \right\rangle ~\colon~ x \in X \right\}.$$

This definition can be interpreted as an encoding of the [convex hull](wikipedia://en/40634) of the function's [epigraph](wikipedia://en/5744061) in terms of its [supporting hyperplanes](wikipedia://en/4165181).[^o4]

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

For more examples, see .

- The convex conjugate of an [affine function](https://en.wikipedia.org/wiki/Affine_function) $f(x) = \left\langle a, x \right\rangle - b$ is $$f^{*}\left(x^{*} \right) = \begin{cases} b, & x^{*} = a \\ +\infty, & x^{*} \ne a. \end{cases}$$
- The convex conjugate of a [power function](https://en.wikipedia.org/wiki/Power_function) $f(x) = \frac{1}{p}|x|^p, 1 < p < \infty$ is $$f^{*}\left(x^{*} \right) = \frac{1}{q}|x^{*}|^q, 1<q<\infty, \text{where} \tfrac{1}{p} + \tfrac{1}{q} = 1.$$
- The convex conjugate of the [absolute value](wikipedia://en/991) function $f(x) = \left| x \right|$ is $$f^{*}\left(x^{*} \right) = \begin{cases} 0, & \left|x^{*} \right| \le 1 \\ \infty, & \left|x^{*} \right| > 1. \end{cases}$$
- The convex conjugate of the [exponential function](wikipedia://en/9678) $f(x)= e^x$ is $$f^{*}\left(x^{*} \right) = \begin{cases} x^{*} \ln x^{*} - x^{*} , & x^{*} > 0 \\ 0 , & x^{*} = 0 \\ \infty , & x^{*} < 0. \end{cases}$$

The convex conjugate and Legendre transform of the exponential function agree except that the [domain](wikipedia://en/50263) of the convex conjugate is strictly larger as the Legendre transform is only defined for [positive real numbers](wikipedia://en/47172571).

### Connection with expected shortfall (average value at risk) {#Connection_with_expected_shortfall_(average_value_at_risk)}

See [this article for example.](https://link.springer.com/article/10.1007/s10107-014-0801-1)

Let *F* denote a [cumulative distribution function](wikipedia://en/5793) of a [random variable](wikipedia://en/25685) *X*. Then ([integrating by parts](wikipedia://en/147252)),

$$f(x):= \int_{-\infty}^x F(u) \, du = \operatorname{E}\left[\max(0,x-X)\right] = x-\operatorname{E} \left[\min(x,X)\right]$$

has the convex conjugate

$$f^{*}(p)= \int_0^p F^{-1}(q) \, dq = (p-1)F^{-1}(p)+\operatorname{E}\left[\min(F^{-1}(p),X)\right] = p F^{-1}(p)-\operatorname{E}\left[\max(0,F^{-1}(p)-X)\right].$$

### Ordering {#Ordering}

A particular interpretation has the transform

$$f^\text{inc}(x):= \arg \sup_t t\cdot x-\int_0^1 \max\{t-f(u),0\} \, du,$$

as this is a nondecreasing rearrangement of the initial function *f*; in particular, $f^\text{inc}= f$ for *f* nondecreasing.

## Properties {#Properties}

The convex conjugate of a [closed convex function](wikipedia://en/1010712) is again a closed convex function. The convex conjugate of a [polyhedral convex function](https://en.wikipedia.org/wiki/Polyhedral_convex_function) (a convex function with [polyhedral](wikipedia://en/23470) [epigraph](wikipedia://en/5744061)) is again a polyhedral convex function.

### Order reversing {#Order_reversing}

Declare that $f \le g$ if and only if $f(x) \le g(x)$ for all $x.$ Then convex-conjugation is [order-reversing](wikipedia://en/361924), which by definition means that if $f \le g$ then $f^* \ge g^*.$

For a family of functions $\left(f_\alpha\right)_\alpha$ it follows from the fact that supremums may be interchanged that

$$\left(\inf_\alpha f_\alpha\right)^*(x^*) = \sup_\alpha f_\alpha^*(x^*),$$

and from the [max–min inequality](wikipedia://en/32244285) that

$$\left(\sup_\alpha f_\alpha\right)^*(x^*) \le \inf_\alpha f_\alpha^*(x^*).$$

::: {#o13 .pointer-item cue=pointer name="Biconjugate"}

### Biconjugate {#Biconjugate}

The convex conjugate of a function is always [lower semi-continuous](https://en.wikipedia.org/wiki/Lower_semi-continuous). The **biconjugate** $f^{**}$ (the convex conjugate of the convex conjugate) is also the [lower convex envelope](wikipedia://en/3165509), i.e. the largest [lower semi-continuous](https://en.wikipedia.org/wiki/Lower_semi-continuous) convex function with $f^{**} \le f.$ For [proper functions](wikipedia://en/630360) $f,$

$f = f^{**}$ [if and only if](wikipedia://en/14922) $f$ is convex and lower semi-continuous, by the [Fenchel–Moreau theorem](wikipedia://en/35099255).

The Fenchel inequality (below) implies $f^{**}\leq f$. More precisely, $f^{**}$ is the greatest lower semicontinuous convex function not exceeding $f$, often described as the closed convex envelope of $f$. In particular, by the [Fenchel–Moreau theorem](wikipedia://en/35099255), a proper function is equal to its biconjugate if and only if it is convex and lower semicontinuous.[^n1][^n2]

:::

::: {#o17 .statement cue=named-heading name="Fenchel's inequality"}

### Fenchel's inequality {#Fenchel's_inequality}

For any function $f$ and its convex conjugate $f *$, **Fenchel's inequality** (also known as the **Fenchel–Young inequality**) holds for every $x \in X$ and $p \in X^{*}$:

$$\left\langle p,x \right\rangle \le f(x) + f^*(p).$$

Furthermore, the equality holds only when $p \in \partial f(x)$, where $\partial f(x)$ is the [subgradient](https://en.wikipedia.org/wiki/Subgradient). The proof follows from the definition of convex conjugate: $f^*(p) = \sup_{\tilde x} \left\{ \langle p,\tilde x \rangle - f(\tilde x) \right\} \ge \langle p,x \rangle - f(x).$

:::

### Convexity {#Convexity}

For two functions $f_0$ and $f_1$ and a number $0 \le \lambda \le 1$ the convexity relation

$$\left((1-\lambda) f_0 + \lambda f_1\right)^{*} \le (1-\lambda) f_0^{*} + \lambda f_1^{*}$$

holds. The ${*}$ operation is a convex mapping itself.

::: {#o20 .pointer-item cue=pointer name="Infimal convolute"}

### Infimal convolution {#Infimal_convolution}

The **infimal convolution** (or epi-sum) of two functions $f$ and $g$ is defined as

$$\left( f \operatorname{\Box} g \right)(x) = \inf \left\{ f(x-y) + g(y) \mid y \in \mathbb{R}^n \right\}.$$

The operation $\operatorname{\Box}$ is symmetric (commutative) and associative, i.e.

$$f \Box g = g \Box f, \qquad (f \Box g) \Box h = f \Box (g \Box h).$$

Let $f_1, \ldots, f_{m}$ be [proper](wikipedia://en/630360), convex and [lower semicontinuous](wikipedia://en/57824) functions on $\mathbb{R}^{n}.$ Then the infimal convolution is convex and lower semicontinuous (but not necessarily proper),[^o21] and satisfies

$$\left( f_1 \operatorname{\Box} \cdots \operatorname{\Box} f_m \right)^{*} = f_1^{*} + \cdots + f_m^{*},$$

or, equivalently,

$$\left( f_1 + \cdots + f_m \right)^{*} = f_1^{*} \operatorname{\Box} \cdots \operatorname{\Box} f_m^{*},$$

which expresses the behaviour of convex conjugation with respect to sums of functions.

The infimal convolution of two functions has a geometric interpretation: The (strict) [epigraph](wikipedia://en/5744061) of the infimal convolution of two functions is the [Minkowski sum](https://en.wikipedia.org/wiki/Minkowski_sum) of the (strict) epigraphs of those functions.[^o22]

:::

### Maximizing argument {#Maximizing_argument}

If the function $f$ is differentiable, then its derivative is the maximizing argument in the computation of the convex conjugate:

$f^\prime(x) = x^*(x):= \arg\sup_{x^{*}} {\langle x, x^{*}\rangle} -f^{*}\left( x^{*} \right)$ and

$$f^{{*}\prime}\left( x^{*} \right) = x\left( x^{*} \right):= \arg\sup_x {\langle x, x^{*}\rangle} - f(x);$$

hence

$$x = \nabla f^{{*}}\left( \nabla f(x) \right),$$

$$x^{*} = \nabla f\left( \nabla f^{{*}}\left( x^{*} \right)\right),$$

and moreover

$$f^{\prime\prime}(x) \cdot f^{{*}\prime\prime}\left( x^{*}(x) \right) = 1,$$

$$f^{{*}\prime\prime}\left( x^{*} \right) \cdot f^{\prime\prime}\left( x(x^{*}) \right) = 1.$$

### Scaling properties {#Scaling_properties}

If for some $\gamma>0,$ $g(x) = \alpha + \beta x + \gamma \cdot f\left( \lambda x + \delta \right)$, then

$$g^{*}\left( x^{*} \right)= - \alpha - \delta\frac{x^{*}-\beta} \lambda + \gamma \cdot f^{*}\left(\frac {x^{*}-\beta}{\lambda \gamma}\right).$$

### Behavior under linear transformations {#Behavior_under_linear_transformations}

Let $A : X \to Y$ be a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator). For any convex function $f$ on $X,$

$$\left(A f\right)^{*} = f^{*} A^{*}$$

where

$$(A f)(y) = \inf\{ f(x) : x \in X , A x = y \}$$

is the preimage of $f$ with respect to $A$ and $A^{*}$ is the [adjoint operator](https://en.wikipedia.org/wiki/Adjoint_operator) of $A.$[^o26]

A closed convex function $f$ is symmetric with respect to a given set $G$ of [orthogonal linear transformations](wikipedia://en/105620),

$f(A x) = f(x)$ for all $x$ and all $A \in G$

if and only if its convex conjugate $f^{*}$ is symmetric with respect to $G.$

:::
