# Independent dominating set

*Image: Independent dominating.svg.* A graph with a minimum **independent dominating set** in red. There are 3 vertices in the set, and therefore the **independent domination number** $i(G)=3$ (which is greater than the [domination number](https://en.wikipedia.org/wiki/Domination_number) $\gamma(G)=2$).

::: {#o1 .subject cue=lead name="Independent dominating set"}

In [graph theory](wikipedia://en/12401), an **independent dominating set** for a [graph](wikipedia://en/325806) $G = (V, E)$ is a [subset](wikipedia://en/27631) $D \subseteq V$ that is both a [dominating set](wikipedia://en/1747972) and an [independent set](wikipedia://en/524501); equivalently, it is a [maximal independent set](wikipedia://en/1793590).[^o2]

:::

The **independent domination number** $i(G)$ of a graph $G$ is the size of the smallest independent dominating set (equivalently, the smallest maximal independent set).[^o2] The notation $i(G)$ was introduced by Cockayne and Hedetniemi.[^o3][^o4]

## History {#History}

The concept of an independent dominating set arose from [chess problems](https://en.wikipedia.org/wiki/Chess_problem). In 1862, de Jaenisch posed the problem of finding the minimum number of mutually non-attacking [queens](https://en.wikipedia.org/wiki/Queen_%28chess%29) that can be placed on a chessboard so that every square is attacked by at least one queen.[^o6] Modelling the chessboard as a [queen's graph](wikipedia://en/70073990) $G$, this minimum is the independent domination number $i(G)$. For the standard 8×8 queens graph, $\alpha(G) = 8$, $i(G) = 7$, and $\gamma(G) = 5$.[^o2]

The theory of independent domination was formalized by [Berge](wikipedia://en/5893760) and [Ore](https://en.wikipedia.org/wiki/Oystein_Ore) in 1962.[^o7][^o8] Berge observed that an independent set is maximal independent if and only if it is dominating, and that every maximal independent set is a [minimal dominating set](wikipedia://en/1747972#Minimal_dominating_sets).[^o7]

## Bounds {#Bounds}

### General bounds {#General_bounds}

Berge established basic bounds in terms of the [order](https://en.wikipedia.org/wiki/Order_%28graph_theory%29) $n$ and maximum [degree](https://en.wikipedia.org/wiki/Degree_%28graph%29) $\Delta$ of a graph:[^o11]

$$\left\lceil \frac{n}{1+\Delta} \right\rceil \leq i(G) \leq n - \Delta$$

For graphs without isolated vertices:[^o12]

$$i(G) \leq n + 2 - 2\sqrt{n}$$

and this bound is sharp. For a graph with minimum degree at least $\delta$:[^o13]

$$i(G) \leq n + 2\delta - 2\sqrt{\delta n}$$

confirming an earlier conjecture of Favaron.[^o12]

### Graph families {#Graph_families}

For [claw-free graphs](wikipedia://en/12415907):[^o15]

$$i(G) = \gamma(G)$$

More generally, for $K_{1,k}$-free ([star](wikipedia://en/19310129)-free) graphs where $k \geq 3$:[^o16]

$$i(G) \leq (k-2)\gamma(G) - (k-3)$$

For any [bipartite graph](wikipedia://en/244431) without isolated vertices on $n$ vertices:[^o2]

$$i(G) \leq n/2$$

For [trees](wikipedia://en/48560), if a tree has $n$ vertices and $\ell$ leaves:[^o17]

$$i(G) \leq (n + \ell)/3$$

If $G$ is an $r$-[regular graph](wikipedia://en/85821) on $n$ vertices with no isolated vertex, then:[^o18]

$$i(G) \leq \alpha(G) \leq n/2$$

For [connected](wikipedia://en/1614492) [cubic graphs](wikipedia://en/980508) other than $K_{3,3}$:[^o19]

$$i(G) \leq 2n/5$$

It has been conjectured that the bound can be improved to $3n/8$ for all connected cubic graphs of order more than 10.[^o2]

Regarding the ratio between domination and independent domination in connected cubic graphs other than $K_{3,3}$:[^o20]

$$i(G)/\gamma(G) \leq 4/3$$

For any [planar graph](wikipedia://en/24314) on $n$ vertices:[^o21]

$$i(G) \leq 3n/4 - 2$$

For planar graphs of [diameter](wikipedia://en/1020021) 2, the bound can be improved:[^o21]

$$i(G) \leq \lceil n/3 \rceil$$

### Relation to line graphs and edge domination {#Relation_to_line_graphs_and_edge_domination}

For any graph $G$, its [line graph](wikipedia://en/675231) $L(G)$ is claw-free, and hence a minimum maximal independent set in $L(G)$ is also a minimum dominating set in $L(G)$. An independent set in $L(G)$ corresponds to a [matching](wikipedia://en/581797) in $G$, and a dominating set in $L(G)$ corresponds to an [edge dominating set](wikipedia://en/21689422) in $G$. Therefore a [minimum maximal matching](https://en.wikipedia.org/wiki/Minimum_maximal_matching) has the same size as a minimum edge dominating set.

### Relation to other domination parameters {#Relation_to_other_domination_parameters}

Because the minimum is taken over fewer sets (only the independent dominating sets are considered), $\gamma(G) \leq i(G)$ for all graphs $G$. Similarly, since every maximal independent set is an independent set, $i(G) \leq \alpha(G)$, where $\alpha(G)$ is the [independence number](https://en.wikipedia.org/wiki/Independence_number). Furthermore, since every maximal independent set is a minimal dominating set, $\alpha(G) \leq \Gamma(G)$, where $\Gamma(G)$ is the [upper domination number](https://en.wikipedia.org/wiki/Upper_dominating_set) (the maximum size of a minimal dominating set). This yields the **domination chain**:[^o24]

$$\gamma(G) \leq i(G) \leq \alpha(G) \leq \Gamma(G).$$

The inequality can be strict; there are graphs $G$ for which $\gamma(G) < i(G)$. For example, let $G$ be the *double star graph* consisting of vertices $x_1, \ldots, x_p, a, b, y_1, \ldots, y_q$, where $p, q > 1$. The edges of $G$ are defined as follows: each $x_i$ is adjacent to $a$, $a$ is adjacent to $b$, and $b$ is adjacent to each $y_j$. Then $\gamma(G) = 2$ since $\{a, b\}$ is a smallest dominating set. If $p \leq q$, then $i(G) = p + 1$ since $\{x_1, \ldots, x_p, b\}$ is a smallest dominating set that is also independent (it is a smallest maximal independent set).

However, the bounds $\gamma(G) \leq i(G) \leq \alpha(G)$ are simultaneously sharp for the [corona](wikipedia://en/79527671) $H \circ K_1$ of any graph $H$, which satisfies $\gamma(G) = i(G) = \alpha(G) = |V(H)|$.[^o2]

Cockayne and Mynhardt characterized which sequences of values are achievable:[^o25] A sequence $(s_1, s_2, s_3, s_4)$ of integers is realizable as $(\gamma(G), i(G), \alpha(G), \Gamma(G))$ for some graph $G$ if and only if $1 \leq s_1 \leq s_2 \leq s_3 \leq s_4$, $s_1 = 1$ implies $s_2 = 1$, and $s_3 = 1$ implies $s_4 = 1$.

## Computational complexity {#Computational_complexity}

Determining whether $i(G) \leq k$ for a given graph $G$ and integer $k$ is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) in general,[^o27] and remains NP-complete even when restricted to [bipartite graphs](wikipedia://en/244431), [line graphs](wikipedia://en/675231), [circle graphs](wikipedia://en/1399873), [unit disk graphs](wikipedia://en/3686677), or [planar](wikipedia://en/24314) [cubic graphs](wikipedia://en/980508).[^o2] Furthermore, Irving showed that there is no polynomial-time algorithm to approximate the independent domination number within a constant factor unless [P = NP](wikipedia://en/6115).[^o28]

On the other hand, the independent domination number can be computed in linear time for [trees](wikipedia://en/48560)[^o29] and in polynomial time for [chordal graphs](wikipedia://en/744165)[^o30] and [cocomparability graphs](https://en.wikipedia.org/wiki/Cocomparability_graph).[^o31]

## Domination-perfect graphs {#Domination-perfect_graphs}

A graph $G$ is called a **domination-perfect graph** if $\gamma(H) = i(H)$ in every [induced subgraph](wikipedia://en/1655188) $H$ of $G$.[^o33] Since an induced subgraph of a claw-free graph is claw-free, it follows that every claw-free graph is also domination-perfect.[^o34]

By a result of Sumner and Moore, a graph is domination perfect if and only if $\gamma(H) = i(H)$ for every induced subgraph $H$ with $\gamma(H) = 2$.[^o33] Zverovich and Zverovich gave a complete characterization: a graph is domination perfect if and only if it contains none of seventeen specific graphs as an induced subgraph.[^o35]

## Well-covered graphs {#Well-covered_graphs}

A graph is [well-covered](wikipedia://en/32696387) if $i(G) = \alpha(G)$, that is, every maximal independent set is a maximum independent set. The concept was introduced by Plummer.[^o37] Ravindra characterized the well-covered bipartite graphs: a connected bipartite graph is well-covered if and only if it contains a [perfect matching](wikipedia://en/44031) $M$ such that for every edge $uv \in M$, the subgraph induced by $N[u] \cup N[v]$ is a [complete bipartite graph](wikipedia://en/525320).[^o38] As a consequence, a tree is well-covered if and only if it is $K_1$ or the [corona](wikipedia://en/79527671) of a tree.[^o2]
