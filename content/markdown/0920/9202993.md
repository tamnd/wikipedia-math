::: {#o1 .subject cue=lead name="List of PSPACE-complete problems"}

## Graph theory {#Graph_theory}

::: {#o111 .entry cue=list-entry name="Binary decision diagram"}

- Succinct versions of many graph problems, with graphs represented as Boolean circuits,[^o112] ordered [binary decision diagrams](wikipedia://en/576855)[^o113] or other related representations:

:::

  - s-t reachability problem for succinct graphs. This is essentially the same as the simplest plan existence problem in [automated planning and scheduling](wikipedia://en/1505641).
  - planarity of succinct graphs
  - acyclicity of succinct graphs
  - connectedness of succinct graphs
  - existence of Eulerian paths in a succinct graph
- Bounded two-player Constraint Logic[^o27]

::: {#o114 .entry cue=list-entry name="Canadian traveller problem"}

- [Canadian traveller problem](wikipedia://en/18210373).[^o115]

:::

::: {#o116 .entry cue=list-entry name="Border Gateway Protocol"}

- Determining whether routes selected by the [Border Gateway Protocol](https://en.wikipedia.org/wiki/Border_Gateway_Protocol) will eventually converge to a stable state for a given set of path preferences[^o117]

:::

::: {#o118 .entry cue=list-entry name="Constraint logic"}

- Deterministic [constraint logic](https://en.wikipedia.org/wiki/Constraint_logic) (unbounded)[^o119]

:::

- Dynamic graph reliability.[^o62]

::: {#o120 .entry cue=list-entry name="Graph coloring game"}

- [Graph coloring game](wikipedia://en/42960994)[^o121]

:::

::: {#o122 .entry cue=list-entry name="Node Kayles game and clique-forming game"}

- [Node Kayles game and clique-forming game](wikipedia://en/18869317):[^o123] two players alternately select vertices and the induced subgraph must be an independent set (resp. clique). The last to play wins.

:::

- Nondeterministic Constraint Logic (unbounded)[^o27]

## Others {#Others}

- Finite horizon POMDPs (Partially Observable Markov Decision Processes).[^o125]
- Hidden Model MDPs (hmMDPs).[^o126]
- Dynamic Markov process.[^o62]
- Detection of inclusion dependencies in a relational database[^o127]
- Computation of any [Nash equilibrium](wikipedia://en/45337) of a 2-player [normal-form game](wikipedia://en/1863612), that may be obtained via the [Lemke–Howson algorithm](wikipedia://en/38282904).[^o128]
- The Corridor Tiling Problem: given a set of [Wang tiles](wikipedia://en/65798), a chosen tile $T_0$ and a width $n$ given in unary notation, is there any height $m$ such that an $n\times m$ rectangle can be tiled such that all the border tiles are $T_0$?[^o129][^o130]
