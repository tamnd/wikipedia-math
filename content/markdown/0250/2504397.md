# Banach manifold

::: {#o1 .subject cue=lead name="Banach manifold"}

In [mathematics](wikipedia://en/18831), a **Banach manifold** is a [manifold](wikipedia://en/2073470) modeled on [Banach spaces](https://en.wikipedia.org/wiki/Banach_spaces). Thus it is a [topological space](wikipedia://en/30450) in which each point has a [neighbourhood](wikipedia://en/1529485) [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to an [open set](wikipedia://en/39358) in a Banach space (a more involved and formal definition is given below). Banach manifolds are one possibility of extending manifolds to [infinite](wikipedia://en/20110824) [dimensions](wikipedia://en/8398).

:::

A further generalisation is to [Fréchet manifolds](wikipedia://en/3873038), replacing Banach spaces by [Fréchet spaces](wikipedia://en/233801). On the other hand, a [Hilbert manifold](wikipedia://en/2504412) is a special case of a Banach manifold in which the manifold is locally modeled on [Hilbert spaces](wikipedia://en/20598932).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [set](wikipedia://en/26691). An **[atlas](wikipedia://en/47436) of class** $C^r,$ $r \geq 0,$ on $X$ is a collection of pairs (called **[charts](wikipedia://en/47436#Charts)**) $\left(U_i, \varphi_i\right),$ $i \in I,$ such that

1. each $U_i$ is a [subset](wikipedia://en/27631) of $X$ and the [union](wikipedia://en/47949) of the $U_i$ is the whole of $X$;
1. each $\varphi_i$ is a [bijection](wikipedia://en/3942) from $U_i$ onto an [open subset](https://en.wikipedia.org/wiki/Open_subset) $\varphi_i\left(U_i\right)$ of some Banach space $E_i,$ and for any indices $i \text{ and } j,$ $\varphi_i\left(U_i \cap U_j\right)$ is open in $E_i;$
1. the crossover map $$\varphi_j \circ \varphi_i^{-1} : \varphi_i\left(U_i \cap U_j\right) \to \varphi_j\left(U_i \cap U_j\right)$$ is an [$r$-times continuously differentiable](https://en.wikipedia.org/wiki/Smooth_function) function for every $i, j \in I;$ that is, the $r$th [Fréchet derivative](wikipedia://en/2735727) $$\mathrm{d}^r\left(\varphi_j \circ \varphi_i^{-1}\right) : \varphi_i\left(U_i \cap U_j\right) \to \mathrm{Lin}\left(E_i^r; E_j\right)$$ exists and is a [continuous function](wikipedia://en/6122) with respect to the $E_i$-[norm](wikipedia://en/990534) [topology](wikipedia://en/29954) on subsets of $E_i$ and the [operator norm](wikipedia://en/246722) topology on $\operatorname{Lin}\left(E_i^r; E_j\right).$

One can then show that there is a unique [topology](wikipedia://en/29954) on $X$ such that each $U_i$ is open and each $\varphi_i$ is a [homeomorphism](wikipedia://en/13660). Very often, this topological space is assumed to be a [Hausdorff space](wikipedia://en/13637), but this is not necessary from the point of view of the formal definition.

If all the Banach spaces $E_i$ are equal to the same space $E,$ the atlas is called an $E$**\-atlas**. However, it is not *a priori* necessary that the Banach spaces $E_i$ be the same space, or even [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) as [topological vector spaces](wikipedia://en/45752). However, if two charts $\left(U_i, \varphi_i\right)$ and $\left(U_j, \varphi_j\right)$ are such that $U_i$ and $U_j$ have a non-empty [intersection](wikipedia://en/23476429), a quick examination of the [derivative](https://en.wikipedia.org/wiki/Derivative_%28generalizations%29) of the crossover map

$$\varphi_j \circ \varphi_i^{-1} : \varphi_i\left(U_i \cap U_j\right) \to \varphi_j\left(U_i \cap U_j\right)$$

shows that $E_i$ and $E_j$ must indeed be isomorphic as topological vector spaces. Furthermore, the set of points $x \in X$ for which there is a chart $\left(U_i, \varphi_i\right)$ with $x$ in $U_i$ and $E_i$ isomorphic to a given Banach space $E$ is both open and [closed](https://en.wikipedia.org/wiki/Closed_subset). Hence, one can without loss of generality assume that, on each [connected component](wikipedia://en/6233) of $X,$ the atlas is an $E$-atlas for some fixed $E.$

A new chart $(U, \varphi)$ is called **compatible** with a given atlas $\left\{\left(U_i, \varphi_i\right) : i \in I\right\}$ if the crossover map

$$\varphi_i \circ \varphi^{-1} : \varphi\left(U \cap U_i\right) \to \varphi_i\left(U \cap U_i\right)$$

is an $r$-times continuously differentiable function for every $i \in I.$ Two atlases are called compatible if every chart in one is compatible with the other atlas. Compatibility defines an [equivalence relation](wikipedia://en/9259) on the class of all possible atlases on $X.$

A $C^r$**\-manifold** structure on $X$ is then defined to be a choice of equivalence class of atlases on $X$ of class $C^r.$ If all the Banach spaces $E_i$ are isomorphic as topological vector spaces (which is guaranteed to be the case if $X$ is [connected](wikipedia://en/6233)), then an equivalent atlas can be found for which they are all equal to some Banach space $E.$ $X$ is then called an $E$**\-manifold**, or one says that $X$ is **modeled** on $E.$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Every Banach space can be canonically identified as a Banach manifold. If $(X, \|\,\cdot\,\|)$ is a Banach space, then $X$ is a Banach manifold with an atlas containing a single, globally defined chart (the [identity map](wikipedia://en/15069)).

Similarly, if $U$ is an open subset of some Banach space then $U$ is a Banach manifold. (See the [classification theorem](wikipedia://en/4576710) below.)

:::

## Classification up to homeomorphism {#Classification_up_to_homeomorphism}

It is by no means true that a finite-dimensional manifold of dimension $n$ is globally homeomorphic to $\mathbb{R}^n,$ or even an open subset of $\mathbb{R}^n.$ However, in an infinite-dimensional setting, it is possible to classify "[well-behaved](https://en.wikipedia.org/wiki/Well-behaved)" Banach manifolds up to homeomorphism quite nicely. A 1969 theorem of [David Henderson](wikipedia://en/49367356)[^n1] states that every infinite-dimensional, [separable](wikipedia://en/27855), [metric](wikipedia://en/20018) Banach manifold $X$ can be [embedded](wikipedia://en/52119) as an open subset of the infinite-dimensional, separable Hilbert space, $H$ (up to linear isomorphism, there is only one such space, usually identified with $\ell^2$). In fact, Henderson's result is stronger: the same conclusion holds for any metric manifold modeled on a separable infinite-dimensional [Fréchet space](wikipedia://en/233801).

The embedding homeomorphism can be used as a global chart for $X.$ Thus, in the infinite-dimensional, separable, metric case, the "only" Banach manifolds are the open subsets of Hilbert space.
