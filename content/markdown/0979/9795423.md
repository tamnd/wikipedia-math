# No-wandering-domain theorem

::: {#o1 .subject cue=lead name="No-wandering-domain theorem"}

In [mathematics](wikipedia://en/18831), the **no-wandering-domain theorem** is a result on [dynamical systems](wikipedia://en/9087), proven by [Dennis Sullivan](wikipedia://en/7349608) in 1985.

:::

The theorem states that a [rational map](wikipedia://en/361210) *f* : **Ĉ** → **Ĉ** with deg(*f*) ≥ 2 does not have a [wandering domain](wikipedia://en/2870010#Wandering_sets_and_dissipative_systems), where **Ĉ** denotes the [Riemann sphere](wikipedia://en/30876799). More precisely, for every [component](wikipedia://en/6233) *U* in the [Fatou set](https://en.wikipedia.org/wiki/Fatou_set) of *f*, the sequence

$$U,f(U),f(f(U)),\dots,f^n(U), \dots$$

will eventually become periodic. Here, *f*<sup>*n*</sup> denotes the [*n*-fold iteration](https://en.wikipedia.org/wiki/Function_iteration) of *f*, that is,

$$f^n = \underbrace{f \circ f\circ \cdots \circ f}_n .$$

*Image: Wandering domains for the entire function f(z)=z+2πsin(z).png.* This image illustrates the dynamics of $f(z)=z+2\pi\sin(z)$; the Fatou set (consisting entirely of wandering domains) is shown in white, while the Julia set is shown in tones of gray.

The theorem does not hold for arbitrary maps; for example, the [transcendental map](wikipedia://en/297021) $f(z)=z+2\pi\sin(z)$ has wandering domains. However, the result can be generalized to many situations where the functions naturally belong to a finite-dimensional parameter space, most notably to transcendental entire and meromorphic functions with a finite number of singular values.
