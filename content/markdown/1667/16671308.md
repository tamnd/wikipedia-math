# DAP (software)

::: {#o3 .subject cue=lead name="DAP"}

**DAP** is a [statistics](wikipedia://en/26685) and [graphics](https://en.wikipedia.org/wiki/Graphics) program based on the [C programming language](https://en.wikipedia.org/wiki/C_programming_language) that performs data management, analysis, and C-style graphical visualization tasks without requiring complex syntax. Its name is an acronym for Data Analysis and Presentation.

:::

DAP was written to be a free replacement for [SAS](https://en.wikipedia.org/wiki/SAS_System), but users are assumed to have a basic familiarity with the [C programming language](https://en.wikipedia.org/wiki/C_programming_language) in order to permit greater flexibility.

It has been designed to be used on large data sets and is primarily used in statistical consulting practices.

However, even with its clear benefits, DAP hasn't been updated since 2014 and hasn't seen widespread use when compared to other statistical analysis programs.

## Features {#Features}

DAP is a command line driven program. Below are various features that DAP can perform.

DAP can compute [means](https://en.wikipedia.org/wiki/Mean) and [percentiles](https://en.wikipedia.org/wiki/Percentiles), [correlation](wikipedia://en/157057), & ANOVA from data sets. This includes Unbalanced as well as Crossed, Nested [ANOVA.](wikipedia://en/13371195) It can also be used to create [scatterplots](https://en.wikipedia.org/wiki/Scatterplot), [line graphs](wikipedia://en/675231) and [histograms](https://en.wikipedia.org/wiki/Histograms) of data. This can include [split plots](https://en.wikipedia.org/wiki/Split_plot), treatment combinations, as well as [latin squares](wikipedia://en/37447).

DAP can perform [linear regression](wikipedia://en/48758386) and can utilize regressions to build [linear models](wikipedia://en/17904). In addition to linear regression, DAP can also perform [logistic regression](wikipedia://en/226631) analysis as well. There's a variety of other analysis that DAP can do as well including building [loglinear models](wikipedia://en/15689191) as well as Logit models for linear-by-linear association.

In terms of models, DAP can create mixed balanced and unbalanced models as well as random unbalanced models.

It has been designed so as to cope with very large data sets; even when the size of the data exceeds the size of the computer's [memory](https://en.wikipedia.org/wiki/Computer_data_storage) because the program processes files one line at a time rather than reading entire files into memory.
