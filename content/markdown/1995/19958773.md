# Permutation box

::: {#o1 .subject cue=lead name="Permutation box"}

In [cryptography](wikipedia://en/18934432), a **permutation box** (or **P-box**) is a [method](https://en.wikipedia.org/wiki/Methodology) of bit-shuffling used to [permute](wikipedia://en/44027) or [transpose](wikipedia://en/48358) bits across [S-boxes](https://en.wikipedia.org/wiki/Substitution_box) inputs, creating [diffusion](wikipedia://en/537555) while transposing.[^n1]

:::

*Image: Link between S-Boxes.gif.* An example of a 64-bit "expansion" P-box which spreads the input S-boxes to as many output S-boxes as possible.

In [block ciphers](wikipedia://en/4594) based on [substitution-permutation network](https://en.wikipedia.org/wiki/Substitution-permutation_network), the P-boxes, together with the "substitution" [S-boxes](wikipedia://en/240991) are used to make the relation between the [plaintext](wikipedia://en/157935) and the [ciphertext](wikipedia://en/175560) difficult to understand (see Shannon's [Confusion and diffusion](wikipedia://en/537555)). P-boxes are typically classified as *compression*, *expansion*, and *straight*, depending on whether the number of output bits is less than, greater than, or equal to the number of input bits, respectively. Only straight P-boxes are invertible.
