# Functional completeness

::: {#o1 .subject cue=lead name="Functional completeness"}

In [logic](wikipedia://en/19636), a **functionally complete** set of [logical connectives](wikipedia://en/18153) or [Boolean operators](wikipedia://en/753349) is one that can be used to express all possible [truth tables](wikipedia://en/25512250) by combining members of the [set](wikipedia://en/26691) into a [Boolean expression](wikipedia://en/3126968).[^o2][^o3] A well-known complete set of connectives is $\{\operatorname{AND}, \operatorname{NOT}\}$. Each of the [singleton](wikipedia://en/381798) sets $\{\operatorname{NAND}\}$ and $\{\operatorname{NOR}\}$ is functionally complete. However, the set $\{\operatorname{AND}, \operatorname{OR}\}$ is incomplete, due to its inability to express NOT.

:::

A gate (or set of gates) that is functionally complete can also be called a universal gate (or a universal set of gates).

In a context of [propositional logic](wikipedia://en/18154), functionally complete sets of connectives are also called (*expressively*) *adequate*.[^o4]

From the point of view of [digital electronics](https://en.wikipedia.org/wiki/Digital_electronics), functional completeness means that every possible [logic gate](https://en.wikipedia.org/wiki/Logic_gate) can be realized as a network of gates of the types prescribed by the set. In particular, all logic gates can be assembled from either only binary [NAND gates](https://en.wikipedia.org/wiki/NAND_gate), or only binary [NOR gates](https://en.wikipedia.org/wiki/NOR_gate).

## Introduction {#Introduction}

Modern texts on logic typically take as primitive some subset of the connectives: [conjunction](wikipedia://en/18152) ($\land$); [disjunction](wikipedia://en/7962) ($\lor$); [negation](wikipedia://en/161019) ($\neg$); [material conditional](wikipedia://en/658808) ($\to$); and possibly the [biconditional](wikipedia://en/228783) ($\leftrightarrow$). Further connectives can be defined, if so desired, by defining them in terms of these primitives. For example, NOR (the negation of the disjunction, sometimes denoted $\downarrow$) can be expressed as conjunction of two negations:

$$A \downarrow B := \neg A \land \neg B$$

Similarly, the negation of the conjunction, NAND (sometimes denoted as $\uparrow$), can be defined in terms of disjunction and negation. Every binary connective can be defined in terms of $\{ \neg, \land, \lor, \to, \leftrightarrow \}$, which means that set is functionally complete. However, it contains redundancy: this set is not a *minimal* functionally complete set, because the conditional and biconditional can be defined in terms of the other connectives as

$$\begin{aligned} A \to B &:= \neg A \lor B\\ A \leftrightarrow B &:= (A \to B) \land (B \to A). \end{aligned}$$

It follows that the smaller set $\{\neg, \land, \lor\}$ is also functionally complete. (Its functional completeness is also proved by the [Disjunctive Normal Form Theorem](https://en.wikipedia.org/wiki/Disjunctive_Normal_Form_Theorem).)[^o6] But this is still not minimal, as $\lor$ can be defined as

$$A \lor B := \neg(\neg A \land \neg B).$$

Alternatively, $\land$ may be defined in terms of $\lor$ in a similar manner, or $\lor$ may be defined in terms of $\rightarrow$:

$$\ A \vee B := \neg A \rightarrow B.$$

No further simplifications are possible. Hence, every two-element set of connectives containing $\neg$ and one of $\{\land, \lor, \rightarrow\}$ is a minimal functionally complete [subset](wikipedia://en/27631) of $\{\neg, \land, \lor, \to, \leftrightarrow\}$.

## Formal definition {#Formal_definition}

Given the [Boolean domain](wikipedia://en/3954077) **B** = $\{0, 1\}$, a set *F* of Boolean functions *f*<sub>*i*</sub> : **B**<sup>*n*<sub>*i*</sub></sup> → **B** is *functionally complete* if the [clone](wikipedia://en/15535840) on **B** generated by the basic functions *f*<sub>*i*</sub> contains all functions *f* : **B**<sup>*n*</sup> → **B**, for all *strictly positive* integers *n* ≥ 1. In other words, the set is functionally complete if every Boolean function that takes at least one variable can be expressed in terms of the functions *f*<sub>*i*</sub>. Since every Boolean function of at least one variable can be expressed in terms of binary Boolean functions, *F* is functionally complete if and only if every binary Boolean function can be expressed in terms of the functions in *F*.

A more natural condition would be that the clone generated by *F* consist of all functions *f* : **B**<sup>*n*</sup> → **B**, for all integers *n* ≥ 0. However, the examples given above are not functionally complete in this stronger sense because it is not possible to write a [nullary](wikipedia://en/42301) function, i.e. a constant expression, in terms of *F* if *F* itself does not contain at least one nullary function. With this stronger definition, the smallest functionally complete sets would have 2 elements.

Another natural condition would be that the clone generated by *F* together with the two nullary constant functions be functionally complete or, equivalently, functionally complete in the strong sense of the previous paragraph. The example of the Boolean function given by *S*(*x*, *y*, *z*) = *z* if *x* = *y* and *S*(*x*, *y*, *z*) = *x* otherwise shows that this condition is strictly weaker than functional completeness.[^o9][^o10][^o11]

:::

## Characterization of functional completeness {#Characterization_of_functional_completeness}

[Emil Post](wikipedia://en/362382) proved that a set of logical connectives is functionally complete if and only if it is not a subset of any of the following sets of connectives:

- The [monotonic](https://en.wikipedia.org/wiki/Monotonic) connectives; changing the truth value of any connected variables from **F** to **T** without changing any from **T** to **F** never makes these connectives change their return value from **T** to **F**, e.g. $\vee, \wedge, \top, \bot$.
- The [affine](wikipedia://en/38449) connectives, such that each connected variable either always or never affects the truth value these connectives return, e.g. $\neg, \top, \bot, \leftrightarrow, \nleftrightarrow$.
- The *self-dual* connectives, which are equal to their own [de Morgan dual](https://en.wikipedia.org/wiki/De_Morgan_dual); if the truth values of all variables are reversed, so is the truth value these connectives return, e.g. $\neg$, [maj](wikipedia://en/20823)(*p*, *q*, *r*).
- The *truth-preserving* connectives; they return the [truth value](wikipedia://en/161711) **T** under any interpretation that assigns **T** to all variables, e.g. $\vee, \wedge, \top, \rightarrow, \leftrightarrow$.
- The *falsity-preserving* connectives; they return the truth value **F** under any interpretation that assigns **F** to all variables, e.g. $\vee, \wedge, \bot, \nrightarrow, \nleftrightarrow$.

Post gave a complete description of the [lattice](wikipedia://en/469304) of all [clones](wikipedia://en/15535840) (sets of operations closed under composition and containing all projections) on the two-element set $\{\mathbf{T}, \mathbf{F}\}$, nowadays called [Post's lattice](wikipedia://en/15536340), which implies the above result as a simple corollary: the five mentioned sets of connectives are exactly the maximal nontrivial clones.[^o14]

## Minimal functionally complete operator sets {#Minimal_functionally_complete_operator_sets}

When a single logical connective or Boolean operator is functionally complete by itself, it is called a *Sheffer function*[^o17] or sometimes a **sole sufficient operator**. There are no [unary](wikipedia://en/161006) operators with this property. [NAND](https://en.wikipedia.org/wiki/Logical_NAND) and [NOR](wikipedia://en/209154), which are [dual to each other](wikipedia://en/54476844#Duality_principle), are the only two binary Sheffer functions. These were discovered, but not published, by [Charles Sanders Peirce](wikipedia://en/6117) around 1880, and rediscovered independently and published by [Henry M. Sheffer](wikipedia://en/2993325) in 1913.[^o18] In digital electronics terminology, the binary [NAND gate](https://en.wikipedia.org/wiki/NAND_gate) (↑) and the binary [NOR gate](https://en.wikipedia.org/wiki/NOR_gate) (↓) are the only binary [universal logic gates](https://en.wikipedia.org/wiki/Universal_logic_gate).

The following are the minimal functionally complete sets of logical connectives with [arity](wikipedia://en/42301) ≤ 2:[^o19]

**One element**

{↑}, {↓}.

**Two elements**

$\{\vee, \neg\}$, $\{\wedge, \neg\}$, $\{\to, \neg\}$, $\{\gets, \neg\}$, $\{\to, \bot\}$, $\{\gets, \bot\}$, $\{\to, \nleftrightarrow\}$, $\{\gets, \nleftrightarrow\}$, $\{\to, \nrightarrow\}$, $\{\to, \nleftarrow\}$, $\{\gets, \nrightarrow\}$, $\{\gets, \nleftarrow\}$, $\{\nrightarrow, \neg\}$, $\{\nleftarrow, \neg\}$, $\{\nrightarrow, \top\}$, $\{\nleftarrow, \top\}$, $\{\nrightarrow, \leftrightarrow\}$, $\{\nleftarrow, \leftrightarrow\}.$

**Three elements**

$\{\lor, \leftrightarrow, \bot\}$, $\{\lor, \leftrightarrow, \nleftrightarrow\}$, $\{\lor, \nleftrightarrow, \top\}$, $\{\land, \leftrightarrow, \bot\}$, $\{\land, \leftrightarrow, \nleftrightarrow\}$, $\{\land, \nleftrightarrow, \top\}.$

There are no minimal functionally complete sets of more than three at most binary logical connectives.[^o19] In order to keep the lists above readable, operators that ignore one or more inputs have been omitted. For example, an operator that ignores the first input and outputs the negation of the second can be replaced by a unary negation.

[Alfred Tarski](wikipedia://en/59920)'s paper "On the Primitive Term of Logistic" proved that $\{\leftrightarrow\}$ is functionally complete,[^o20] but this only works if quantification over propositions (a device from [second-order logic](wikipedia://en/341428)) is used, so it doesn't count for the above list.

## Examples {#Examples}

- Examples of using the `NAND` (↑) completeness. As illustrated by,[^o23]
  - ¬*A* ≡ *A* ↑ *A*
  - *A* ∧ *B* ≡ ¬(*A* ↑ *B*) ≡ (*A* ↑ *B*) ↑ (*A* ↑ *B*)
  - *A* ∨ *B* ≡ (¬*A*) ↑ (¬*B*) ≡ (*A* ↑ *A*) ↑ (*B* ↑ *B*)
- Examples of using the `NOR` (↓) completeness. As illustrated by,[^o24]
  - ¬*A* ≡ *A* ↓ *A*
  - *A* ∨ *B* ≡ ¬(*A* ↓ *B*) ≡ (*A* ↓ *B*) ↓ (*A* ↓ *B*)
  - *A* ∧ *B* ≡ (¬*A*) ↓ (¬*B*) ≡ (*A* ↓ *A*) ↓ (*B* ↓ *B*)

Note that an electronic circuit or a software function can be optimized by reuse, to reduce the number of gates. For instance, the "*A* ∧ *B*" operation, when expressed by ↑ gates, is implemented with the reuse of "A ↑ B",

*X* ≡ (*A* ↑ *B*); *A* ∧ *B* ≡ *X* ↑ *X*

:::

## In other domains {#In_other_domains}

Apart from logical connectives (Boolean operators), functional completeness can be introduced in other domains. For example, a set of [reversible](https://en.wikipedia.org/wiki/Reversible_computation) gates is called functionally complete, if it can express every reversible operator.

The 3-input [Fredkin gate](https://en.wikipedia.org/wiki/Fredkin_gate) is functionally complete reversible gate by itself – a sole sufficient operator. There are many other three-input universal logic gates, such as the [Toffoli gate](https://en.wikipedia.org/wiki/Toffoli_gate).

In [quantum computing](wikipedia://en/25220), the [Hadamard gate](https://en.wikipedia.org/wiki/Hadamard_gate), [CNOT](https://en.wikipedia.org/wiki/CNOT) and the [T gate](https://en.wikipedia.org/wiki/T_gate) are universal, albeit with a [slightly more restrictive definition](wikipedia://en/888587#Universal_quantum_gates) than that of functional completeness.

## Set theory {#Set_theory}

There is an [isomorphism](wikipedia://en/14828) between the [algebra of sets](wikipedia://en/961805) and the [Boolean algebra](wikipedia://en/54476844), that is, they have the same [structure](wikipedia://en/3959). Then, if we map Boolean operators into set operators, the "translated" above text are valid also for sets: there are many "minimal complete set of set-theory operators" that can generate any other set relations. The more popular "Minimal complete operator sets" are $\{\neg, \cap\}$ and $\{\neg, \cup\}$. If the [universal set](wikipedia://en/303405) [is forbidden](https://en.wikipedia.org/wiki/Russell's_Paradox), set operators are restricted to being falsity (Ø) preserving, and cannot be equivalent to functionally complete Boolean algebra.
