# Binary entropy function

*Image: Binary entropy plot.svg.* Entropy of a [Bernoulli trial](wikipedia://en/102653) (in [shannons](https://en.wikipedia.org/wiki/Shannon_%28unit%29)) as a function of binary outcome probability, called the **binary entropy function**.

::: {#o1 .subject cue=lead name="Binary entropy function"}

In [information theory](wikipedia://en/14773), the **binary entropy function**, denoted $\operatorname H(p)$ or $\operatorname H_\text{b}(p)$, is defined as the [entropy](wikipedia://en/15445) of a [Bernoulli process](wikipedia://en/102651) ([i.i.d.](https://en.wikipedia.org/wiki/I.i.d.) [binary variable](https://en.wikipedia.org/wiki/Binary_variable)) $X$ with [probability](wikipedia://en/22934) $p$ of one of two values, and is given by the formula:

:::

$$\operatorname H(X) = -p \log p - (1 - p) \log (1 - p).$$

The base of the logarithm corresponds to the choice of [units of information](wikipedia://en/18075548); base $e$ ([natural logarithm](wikipedia://en/21476)) corresponds to [nats](wikipedia://en/3070481) and is mathematically convenient, while base 2 ([binary logarithm](wikipedia://en/249992)) corresponds to [shannons](https://en.wikipedia.org/wiki/Shannon_%28unit%29) and is conventional (as shown in the graph); explicitly:

$$\operatorname H(X) = -p \log_2 p - (1 - p) \log_2 (1 - p).$$

Note that the values at 0 and 1 are given by the limit $\textstyle 0 \log 0 := \lim_{x \to 0^+} x \log x = 0$ (by [L'Hôpital's rule](wikipedia://en/18531)); and that "binary" refers to two possible values for the variable, not the units of information.

When $p = 1/2$, the binary entropy function attains its maximum value of 1 shannon (1 binary unit of information); this is the case of an [unbiased coin flip](wikipedia://en/9597100). When $p = 0$ or $p = 1$, the binary entropy is 0 (regardless of the unit), corresponding to no information, since there is no uncertainty in the variable.

::: {#o3 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

Binary entropy $\operatorname H_\mathrm{b}(p)$ is a special case of $\mathrm{H}(X)$, the [entropy function](https://en.wikipedia.org/wiki/Information_entropy). $\operatorname H_\mathrm{b}(p)$ is distinguished from the general [entropy function](https://en.wikipedia.org/wiki/Information_entropy) $\mathrm{H}(X)$ in that the former takes a single real number as a [parameter](wikipedia://en/25065) whereas the latter takes a distribution or random variable as a parameter. Thus the binary entropy (of $p$) is the entropy of the particular distribution $X \sim \operatorname{Ber}(p)$, so $\operatorname H_\mathrm{b}(p) = \mathrm{H}\bigl(\operatorname{Ber}(p)\bigr)$.

Writing the probability of each of the two values being $p$ and $q$, so $p + q = 1$ and $q = 1 - p$, this corresponds to

$$\operatorname H(X) = -p \log p - (1 - p) \log (1 - p) = -p \log p - q \log q = - \sum_{x \in X} \operatorname{Pr}(X=x) \cdot \log \operatorname{Pr}(X=x) = \mathrm{H}\bigl(\operatorname{Ber}(p)\bigr).$$

Sometimes the binary entropy function is also written as $\operatorname H_2(p)$. However, it is different from and should not be confused with the [Rényi entropy](wikipedia://en/1731689), which is also denoted as $\mathrm{H}_2(X)$.

:::

## Explanation {#Explanation}

In terms of information theory, *entropy* is considered to be a measure of the uncertainty in a message. To put it intuitively, suppose $p=0$. At this probability, the event is certain never to occur, and so there is no uncertainty at all, leading to an entropy of 0. If $p=1$, the result is again certain, so the entropy is 0 here as well. When $p=1/2$, the uncertainty is at a maximum; if one were to place a fair bet on the outcome in this case, there is no advantage to be gained with prior knowledge of the probabilities. In this case, the entropy is maximum at a value of 1 bit. Intermediate values fall between these cases; for instance, if $p=1/4$, there is still a measure of uncertainty on the outcome, but one can still predict the outcome correctly more often than not, so the uncertainty measure, or entropy, is less than 1 full bit.

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Derivative {#Derivative}

The [derivative](wikipedia://en/7921) of the **binary entropy function** may be expressed as the negative of the [logit](wikipedia://en/172068) function:

$${d \over dp} \operatorname H_\text{b}(p) = - \operatorname{logit}_a(p) = -\log_a\left( \frac{p}{1-p} \right).$$

$${d^2 \over dp^2} \operatorname H_\text{b}(p) = - \frac{1}{p(1-p) \ln a}\, ,$$

where $a$ denotes the given base of the logarithm.

### Convex conjugate {#Convex_conjugate}

The [convex conjugate](wikipedia://en/1001490) (specifically, the [Legendre transform](https://en.wikipedia.org/wiki/Legendre_transform)) of the binary entropy (with base $e$) is the negative [softplus](wikipedia://en/37862957) function. This is because (following the definition of the Legendre transform: the derivatives are inverse functions) the derivative of negative binary entropy is the logit, whose inverse function is the [logistic function](wikipedia://en/84563), which is the derivative of softplus.

Softplus can be interpreted as [logistic loss](https://en.wikipedia.org/wiki/Logistic_loss), so by [duality](wikipedia://en/3372717), minimizing logistic loss corresponds to maximizing entropy. This justifies the [principle of maximum entropy](wikipedia://en/201718) as loss minimization.

### Taylor series {#Taylor_series}

The [Taylor series](wikipedia://en/30448) of the binary entropy function at 1/2 is

$$\operatorname H_\text{b}(p) = 1 - \frac{1}{2\ln 2} \sum^{\infty}_{n=1} \frac{(1-2p)^{2n}}{n(2n-1)}$$

which converges to the binary entropy function for all values $0\le p\le 1$.

### Bounds {#Bounds}

The following bounds hold for $0 < p < 1$:[^o11]

$$\ln(2) \cdot \log_2(p) \cdot \log_2(1-p) \leq H_\text{b}(p) \leq \log_2(p) \cdot \log_2(1-p)$$

and

$$4p(1-p) \leq H_\text{b}(p) \leq (4p(1-p))^{(1/\ln 4)}$$

where $\ln$ denotes natural logarithm.
