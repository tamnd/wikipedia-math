# Pseudo-ring

::: {#o1 .subject cue=lead name="Pseudo-ring"}

In [mathematics](wikipedia://en/18831), and more specifically in [abstract algebra](wikipedia://en/19616384), a **pseudo-ring** is one of the following variants of a [ring](wikipedia://en/48404):

:::

- A [rng](wikipedia://en/3405004), i.e., a structure satisfying all the [axioms](wikipedia://en/928) of a ring except for the existence of a [multiplicative identity](https://en.wikipedia.org/wiki/Multiplicative_identity).[^o2]
- A set *R* with two [binary operations](wikipedia://en/3948) + and ⋅ such that (*R*, +) is an [abelian group](wikipedia://en/2974) with [identity](wikipedia://en/4178225) 0, and *a*(*b* + *c*) + *a*0 = *ab* + *ac* and (*b* + *c*)*a* + 0*a* = *ba* + *ca* for all *a*, *b*, *c* in *R*.[^o3]
- An abelian group (*A*, +) equipped with a [subgroup](wikipedia://en/28011) *B* and a multiplication *B* × *A* → *A* making *B* a ring and *A* a *B*-[module](wikipedia://en/276410).[^o4]

None of these definitions are equivalent, so it is best to avoid the term "pseudo-ring" or to clarify which meaning is intended.
