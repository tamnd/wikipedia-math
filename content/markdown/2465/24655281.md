# Euler's differential equation

::: {#o1 .subject cue=lead name="Euler's differential equation"}

In [mathematics](wikipedia://en/18831), **Euler's differential equation** is a first-order [non-linear](https://en.wikipedia.org/wiki/Non-linear) [ordinary differential equation](wikipedia://en/32742753), named after [Leonhard Euler](wikipedia://en/17902). It is given by:[^o2]

:::

$$\frac{dy}{dx} + \frac{\sqrt{a_0+a_1y +a_2 y^2 + a_3 y^3 + a_4 y^4}}{\sqrt{a_0+a_1x +a_2 x^2 + a_3 x^3 + a_4 x^4}} = 0$$

This is a separable equation and the solution is given by the following integral equation:

$$\int \frac{dy}{\sqrt{a_0+a_1 y + a_2 y^2 + a_3 y^3 + a_4 y^4}} + \int \frac{dx}{\sqrt{a_0+a_1 x + a_2 x^2 + a_3 x^3 + a_4 x^4}} = c$$
