# Star of David theorem

*Image: Star-of-david-thm.svg.* The *Star of David theorem* (the rows of the Pascal triangle are shown as columns here).

::: {#o1 .subject cue=lead name="Star of David theorem"}

The **Star of David theorem** is a mathematical result on [arithmetic](wikipedia://en/3118) properties of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficients). It was discovered by [Henry W. Gould](wikipedia://en/38149527) in 1972.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

The [greatest common divisors](wikipedia://en/12354) of the binomial coefficients forming each of the two triangles in the [Star of David](https://en.wikipedia.org/wiki/Star_of_David) shape in [Pascal's triangle](wikipedia://en/49497) are equal:

$$\begin{aligned} & \gcd\left\{ \binom{n-1}{k-1}, \binom{n}{k+1}, \binom{n+1}{k}\right\} \\[8pt] = {} & \gcd\left\{ \binom{n-1}{k}, \binom{n}{k-1}, \binom{n+1}{k+1}\right\}. \end{aligned}$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Rows 8, 9, and 10 of Pascal's triangle are

|  |  |  | 1 |  | 8 |  | **28** |  | **56** |  | 70 |  | 56 |  | *28* |  | *8* |  | 1 |  |  |  |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  | 1 |  | 9 |  | **36** |  | **84** |  | **126** |  | 126 |  | *84* |  | *36* |  | *9* |  | 1 |  |  |
|  | 1 |  | 10 |  | 45 |  | **120** |  | **210** |  | 252 |  | 210 |  | *120* |  | *45* |  | 10 |  | 1 |  |

For *n*=9, *k*=3 or *n*=9, *k*=6, the element 84 (circled bold) is surrounded by, in sequence, the elements 28, 56, 126, 210, 120 and 36 (bold). Taking alternating values, we have gcd(28, 126, 120) = 2 = gcd(56, 210, 36).

The element 36 (circled italics) is surrounded by the sequence 8, 28, 84, 120, 45 and 9 (italics), and taking alternating values we have gcd(8, 84, 45) = 1 = gcd(28, 120, 9).

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

The above greatest common divisor also equals $\gcd \left({n-1 \choose k-2}, {n-1 \choose k-1}, {n-1 \choose k}, {n-1 \choose k+1}\right).$[^o8] Thus in the above example for the element 84 (in its rightmost appearance), we also have gcd(70, 56, 28, 8) = 2. This result in turn has further generalizations.

:::

::: {#o10 .statement kind=statement/generalization cue=heading name="Related results"}

## Related results {#Related_results}

The two sets of three numbers which the Star of David theorem says have equal greatest common divisors also have equal products.[^o8] For example, again observing that the element 84 is surrounded by, in sequence, the elements 28, 56, 126, 210, 120, 36, and again taking alternating values, we have 28×126×120 = 2<sup>6</sup>×3<sup>3</sup>×5×7<sup>2</sup> = 56×210×36. This result can be confirmed by writing out each binomial coefficient in factorial form, using

$${a \choose b}=\frac{a!}{(a-b)!b!}.$$

:::
