# Block Lanczos algorithm

::: {#o1 .subject cue=lead name="Block Lanczos algorithm"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), the **block Lanczos algorithm** is an [algorithm](wikipedia://en/775) for finding the [nullspace](https://en.wikipedia.org/wiki/Nullspace) of a [matrix](wikipedia://en/20556859) over a [finite field](wikipedia://en/11615), using only multiplication of the matrix by long, thin matrices. Such matrices are considered as vectors of [tuples](wikipedia://en/132729) of finite-field entries, and so tend to be called 'vectors' in descriptions of the algorithm.

:::

The block Lanczos algorithm is amongst the most efficient methods known for finding nullspaces, which is the final stage in [integer factorization](wikipedia://en/15491) algorithms such as the [quadratic sieve](wikipedia://en/582340) and [number field sieve](wikipedia://en/152734), and its development has been entirely driven by this application.

It is based on, and bears a strong resemblance to, the [Lanczos algorithm](wikipedia://en/2593852) for finding [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of large sparse real matrices.[^o2]

## Parallelization issues {#Parallelization_issues}

The algorithm is essentially not parallel: it is of course possible to distribute the matrix–'vector' multiplication, but the whole vector must be available for the combination step at the end of each iteration, so all the machines involved in the calculation must be on the same fast network. In particular, it is not possible to widen the vectors and distribute slices of vectors to different independent machines.

The [block Wiedemann algorithm](wikipedia://en/17911717) is more useful in contexts where several systems each large enough to hold the entire matrix are available, since in that algorithm the systems can run independently until a final stage at the end.

## Applications in physics {#Applications_in_physics}

The block Lanczos algorithm has been evoked[^o5] in the context of Krylov complexity program in [quantum physics](https://en.wikipedia.org/wiki/Quantum_physics).
