# Rees matrix semigroup

::: {#o1 .subject cue=lead name="Rees matrix semigroup"}

In [mathematics](wikipedia://en/18831), the **Rees matrix semigroups** are a special [class](wikipedia://en/20696) of [semigroups](wikipedia://en/27799) introduced by [David Rees](wikipedia://en/15398568) in 1940.[^n1] They are of fundamental importance in [semigroup theory](https://en.wikipedia.org/wiki/Semigroup_theory) because they are used to classify certain classes of [simple](wikipedia://en/3875683) semigroups.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *S* be a semigroup, *I* and *Λ* [non-empty](wikipedia://en/9566) [sets](wikipedia://en/26691) and *P* a [matrix](wikipedia://en/20556859) indexed by *I* and *Λ* with entries *p*<sub>*λ*,*i*</sub> taken from *S*. Then the Rees matrix semigroup *M*(*S*; *I*, *Λ*; *P*) is the set *I*×*S*×*Λ* together with the product formula

*(i, s, λ)(j, t, μ) = (i, sp<sub>λ,j</sub> t, μ)*.

Rees matrix semigroups are an important technique for building new semigroups out of old ones.

:::

::: {#o6 .statement kind=statement/theorem cue=named-heading name="Rees' theorem"}

## Rees' theorem {#Rees'_theorem}

In his 1940 paper Rees proved the following theorem characterising [completely simple semigroups](https://en.wikipedia.org/wiki/Completely_simple_semigroup):

A semigroup is completely simple if and only if it is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to a Rees matrix semigroup over a [group](wikipedia://en/19447).

That is, every completely simple semigroup is isomorphic to a semigroup of the form *M*(*G*; *I*, *Λ*; *P*) for some group *G*. Moreover, Rees proved that if *G* is a group and *G*<sup>0</sup> is the semigroup obtained from *G* by attaching a [zero element](wikipedia://en/27799#Identity_and_zero), then *M*(*G*<sup>0</sup>; *I*, *Λ*; *P*) is a [regular semigroup](wikipedia://en/6797677) if and only if every row and column of the matrix *P* contains an element that is not 0. If such an *M*(*G*<sup>0</sup>; *I*, *Λ*; *P*) is regular, then it is also [completely 0-simple](https://en.wikipedia.org/wiki/Completely_simple_semigroup).
