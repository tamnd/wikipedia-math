# Circular algebraic curve

::: {#o1 .subject cue=lead name="Circular algebraic curve"}

In [geometry](wikipedia://en/18973446), a **circular algebraic curve** is a type of [plane algebraic curve](https://en.wikipedia.org/wiki/Plane_algebraic_curve) determined by an equation *F*(*x*, *y*) = 0, where *F* is a [polynomial](wikipedia://en/23000) with real coefficients and the highest-order terms of *F* form a polynomial divisible by *x*<sup>2</sup> + *y*<sup>2</sup>. More precisely, if *F* = *F*<sub>*n*</sub> + *F*<sub>*n*−1</sub> + ... + *F*<sub>1</sub> + *F*<sub>0</sub>, where each *F*<sub>*i*</sub> is [homogeneous](wikipedia://en/622844) of degree *i*, then the curve *F*(*x*, *y*) = 0 is circular if and only if *F*<sub>*n*</sub> is divisible by *x*<sup>2</sup> + *y*<sup>2</sup>.

:::

Equivalently, if the curve is determined in [homogeneous coordinates](wikipedia://en/243316) by *G*(*x*, *y*, *z*) = 0, where *G* is a homogeneous polynomial, then the curve is circular if and only if *G*(1, *i*, 0) = *G*(1, −*i*, 0) = 0. In other words, the curve is circular if it contains the [circular points at infinity](wikipedia://en/8088700), (1, *i*, 0) and (1, −*i*, 0), when considered as a curve in the [complex projective plane](wikipedia://en/737155).

## Multicircular algebraic curves {#Multicircular_algebraic_curves}

An algebraic curve is called ***p*-circular** if it contains the points (1, *i*, 0) and (1, −*i*, 0) when considered as a curve in the complex projective plane, and these points are singularities of order at least *p*. The terms *bicircular*, *tricircular*, etc. apply when *p* = 2, 3, etc. In terms of the polynomial *F* given above, the curve *F*(*x*, *y*) = 0 is *p*-circular if *F*<sub>*n*−*i*</sub> is divisible by (*x*<sup>2</sup> + *y*<sup>2</sup>)<sup>*p*−*i*</sup> when *i* \< *p*. When *p* = 1 this reduces to the definition of a circular curve. The set of *p*-circular curves is invariant under [Euclidean transformations](wikipedia://en/652164). Note that a *p*-circular curve must have degree at least 2*p*.

The set of *p*-circular curves of degree *p* + *k*, where *p* may vary but *k* is a fixed positive integer, is invariant under [inversion](wikipedia://en/295844). When *k* is 1 this says that the set of lines (0-circular curves of degree 1) together with the set of circles (1-circular curves of degree 2) form a set which is invariant under inversion.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [circle](wikipedia://en/6220) is the only circular conic.
- [Conchoids of de Sluze](wikipedia://en/898316) (which include several well-known cubic curves) are circular cubics.
- [Cassini ovals](wikipedia://en/2040906) (including the [lemniscate of Bernoulli](wikipedia://en/250908)), [toric sections](wikipedia://en/5350369) and [limaçons](wikipedia://en/641715) (including the [cardioid](wikipedia://en/642101)) are bicircular quartics.
- [Watt's curve](wikipedia://en/2738105) is a tricircular sextic.
