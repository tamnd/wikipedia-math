# Extended finite element method

*Image: Example of 2D mesh.png.* 2D [FEM](wikipedia://en/18233581) [mesh](https://en.wikipedia.org/wiki/Mesh), the triangles are the elements, the [vertices](wikipedia://en/638899) are the [nodes](https://en.wikipedia.org/wiki/Node_%28graph_theory%29). The [finite element method](wikipedia://en/18233581) ([FEM](wikipedia://en/18233581)) has been the tool of choice since civil engineer [Ray W. Clough](https://en.wikipedia.org/wiki/Ray_W._Clough) in 1940 derived the stiffness matrix of a 3-node triangular finite element (and coined the name). The precursors of FEM were elements built-up from bars ([Hrennikoff](https://en.wikipedia.org/wiki/Alexander_Hrennikoff), [Argyris](https://en.wikipedia.org/wiki/John_Argyris), Turner) and a conceptual variation approach suggested by R. [Courant](wikipedia://en/715238). Today, the [FEM](wikipedia://en/18233581) is used to model a much wider range of physical phenomena.

::: {#o1 .subject cue=lead name="Extended finite element method"}

The **extended finite element method** (**XFEM**), is a numerical technique based on the **generalized finite element method** (**GFEM**) and the **[partition of unity method](wikipedia://en/48636)** (**PUM**). It extends the classical [finite element method](wikipedia://en/18233581) (FEM) approach by enriching the solution space for solutions to [differential equations](wikipedia://en/1424309) with discontinuous functions.

:::

## History {#History}

The extended finite element method (XFEM) was developed in 1999 by [Ted Belytschko](https://en.wikipedia.org/wiki/Ted_Belytschko) and collaborators,[^o3] to help alleviate shortcomings of the finite element method and has been used to model the propagation of various discontinuities: strong ([cracks](https://en.wikipedia.org/wiki/Fracture)) and weak (material interfaces). The idea behind XFEM is to retain most advantages of meshfree methods while alleviating their negative sides.

## Rationale {#Rationale}

The extended finite element method was developed to ease difficulties in solving problems with localized features that are not efficiently resolved by mesh refinement. One of the initial applications was the modelling of [fractures](https://en.wikipedia.org/wiki/Fracture) in a material. In this original implementation, discontinuous basis functions are added to standard polynomial basis functions for nodes that belonged to elements that are intersected by a crack to provide a basis that included crack opening displacements. A key advantage of XFEM is that in such problems the finite element mesh does not need to be updated to track the crack path. Subsequent research has illustrated the more general use of the method for problems involving [singularities](https://en.wikipedia.org/wiki/Mathematical_singularity), material interfaces, regular meshing of microstructural features such as voids, and other problems where a localized feature can be described by an appropriate set of basis functions.

::: {#o6 .statement cue=named-heading name="Principle"}

## Principle {#Principle}

Enriched finite element methods extend, or enrich, the approximation space so that it is able to naturally reproduce the challenging feature associated with the problem of interest: the discontinuity, [singularity](https://en.wikipedia.org/wiki/Mathematical_singularity), [boundary layer](wikipedia://en/224301), etc. It was shown that for some problems, such an embedding of the problem's feature into the approximation space can significantly improve convergence rates and accuracy. Moreover, treating problems with discontinuities with eXtended Finite Element Methods suppresses the need to mesh and remesh the discontinuity surfaces, thus alleviating the computational costs and projection errors associated with conventional finite element methods, at the cost of restricting the discontinuities to mesh edges.

:::

## Existing XFEM codes {#Existing_XFEM_codes}

There exists several research codes implementing this technique to various degrees.

- [GetFEM++](https://en.wikipedia.org/wiki/GetFEM++)
- xfem++
- openxfem++
- [Dynaflow](https://blogs.princeton.edu/prevost/dynaflow/dynaflow-description/)
- [eXlibris](https://git.gem.ec-nantes.fr/)
- [ngsxfem](https://github.com/ngsxfem/ngsxfem)

XFEM has also been implemented in code like **Altair [Radioss](https://en.wikipedia.org/wiki/Radioss)**, ASTER, Morfeo, and [Abaqus](https://en.wikipedia.org/wiki/Abaqus). It is increasingly being adopted by other commercial finite element software, with a few plugins and actual core implementations available ([ANSYS](https://en.wikipedia.org/wiki/ANSYS), [SAMCEF](https://en.wikipedia.org/wiki/SAMCEF), [OOFELIE](https://en.wikipedia.org/wiki/OOFELIE), etc.).
