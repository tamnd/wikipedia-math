# Square class

::: {#o1 .subject cue=lead name="Square class"}

In mathematics, specifically [abstract algebra](wikipedia://en/19616384), a **square class** of a [field](wikipedia://en/10603) $F$ is an element of the **square class group**, the [quotient group](wikipedia://en/11526) $F^\times/ F^{\times 2}$ of the [multiplicative group](wikipedia://en/1110742) of nonzero elements in the field modulo the [square](wikipedia://en/659942) elements of the field. Each square class is a [subset](wikipedia://en/27631) of the nonzero elements (a [coset](wikipedia://en/98759) of the multiplicative group) consisting of the elements of the form *xy*<sup>2</sup> where *x* is some particular fixed element and *y* ranges over all nonzero field elements.[^o2]

:::

For instance, if $F=\mathbb{R}$, the field of [real numbers](wikipedia://en/20646438), then $F^\times$ is just the group of all nonzero real numbers (with the multiplication operation) and $F^{\times 2}$ is the [subgroup](wikipedia://en/28011) of [positive numbers](https://en.wikipedia.org/wiki/Positive_number) (as every positive number has a real [square root](wikipedia://en/29208)). The quotient of these two groups is a group with two elements, corresponding to two [cosets](wikipedia://en/98759): the set of positive numbers and the set of negative numbers. Thus, the real numbers have two square classes, the positive numbers and the negative numbers.[^o2]

Square classes are frequently studied in relation to the theory of [quadratic forms](wikipedia://en/251478).[^o3] The reason is that if $V$ is an $F$-[vector space](wikipedia://en/32370) and $q:V \to F$ is a quadratic form and $v$ is an element of $V$ such that $q(v) = a \in F^\times$, then for all $u \in F^\times$, $q(uv) = au^2$ and thus it is sometimes more convenient to talk about the square classes which the quadratic form represents.

Every element of the square class group is an [involution](wikipedia://en/293450). It follows that, if the number of square classes of a field is finite, it must be a [power of two](wikipedia://en/376948).[^o3]
