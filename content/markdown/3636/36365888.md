# Topological complexity

::: {#o1 .subject cue=lead name="Topological complexity"}

In mathematics, **topological complexity** of a [topological space](wikipedia://en/30450) *X* (also denoted by TC(*X*)) is a [topological invariant](https://en.wikipedia.org/wiki/Topological_invariant) closely connected to the [motion planning](https://en.wikipedia.org/wiki/Motion_planning) problem, introduced by Michael Farber in 2003.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* be a topological space and $PX=\{\gamma: [0,1]\,\to\,X\}$ be the space of all continuous paths in *X*. Define the projection $\pi: PX\to\,X\times X$ by $\pi(\gamma)=(\gamma(0), \gamma(1))$. The topological complexity is the minimal number *k* such that

- there exists an [open cover](https://en.wikipedia.org/wiki/Open_cover) $\{U_i\}_{i=1}^k$ of $X\times X$,
- for each $i=1,\ldots,k$, there exists a [local section](wikipedia://en/367621) $s_i:\,U_i\to\, PX.$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- The topological complexity: TC(*X*) = 1 if and only if *X* is [contractible](wikipedia://en/1752414).
- The topological complexity of the [sphere](wikipedia://en/39782) $S^n$ is 2 for *n* odd and 3 for *n* even. For example, in the case of the [circle](wikipedia://en/6220) $S^1$, we may define a path between two points to be the [geodesic](https://en.wikipedia.org/wiki/Geodesics) between the points, if it is unique. Any pair of [antipodal points](https://en.wikipedia.org/wiki/Antipodal_points) can be connected by a counter-clockwise path.
- If $F(\mathbb{R}^m,n)$ is the [configuration space](wikipedia://en/54981574) of *n* distinct points in the Euclidean *m*-space, then

$$TC(F(\mathbb{R}^m,n))=\begin{cases} 2n-1 & \mathrm{for\,\, {\it m}\,\, odd} \\ 2n-2 & \mathrm{for\,\, {\it m}\,\, even.} \end{cases}$$

- The topological complexity of the [Klein bottle](wikipedia://en/17412) is 5.[^o6]

:::
