# Mcrypt

::: {#o1 .subject cue=lead name="Mcrypt"}

**mcrypt** is a replacement for the popular [Unix](https://en.wikipedia.org/wiki/Unix) [crypt](wikipedia://en/4179924) command. crypt was a file encryption tool that used an [algorithm](wikipedia://en/775) very close to the [World War&nbsp;II](https://en.wikipedia.org/wiki/World_War&nbsp;II) [Enigma](wikipedia://en/9256) cipher. Mcrypt provides the same functionality but uses several modern algorithms such as [AES](wikipedia://en/1260). Libmcrypt, Mcrypt's companion, is a library of code that contains the actual encryption functions and provides an easy method for use. The last update to libmcrypt was in 2007,[^o2] despite years of unmerged patches.[^o3] Maintained alternatives include [ccrypt](https://en.wikipedia.org/wiki/Ccrypt), [libressl](https://en.wikipedia.org/wiki/Libressl), and others.[^o4]

:::

Examples of mcrypt usage in a Linux command-line environment:

```bash
 mcrypt --list                           # See available encryption algorithms.           
 mcrypt -a blowfish myfilename           # Encrypts myfilename to myfilename.nc           
                                         # using the Blowfish encryption algorithm.       
                                         # You are prompted two times for a passphrase.   
 mcrypt -d mytextfile.txt.nc             # Decrypts mytextfile.txt.nc to mytextfile.txt.  
 mcrypt -V -d -a enigma -o scrypt --bare # Can en/decrypt files crypted with SunOS crypt. 
 mcrypt --help
```

It implements numerous [cryptographic](wikipedia://en/18934432) algorithms, mostly [block ciphers](wikipedia://en/4594) and [stream ciphers](wikipedia://en/49007), some of which fall under [export restrictions](wikipedia://en/25872370) in the [United States](https://en.wikipedia.org/wiki/United_States). Algorithms include [DES](wikipedia://en/7978), [Blowfish](wikipedia://en/3940), [ARCFOUR](wikipedia://en/25831), Enigma, [GOST](wikipedia://en/487471), [LOKI97](wikipedia://en/611984), [RC2](wikipedia://en/632592), [Serpent](wikipedia://en/385154), [3-Way](wikipedia://en/294099), [Twofish](wikipedia://en/26508356), [WAKE](wikipedia://en/599287), and [XTEA](wikipedia://en/530334).
