# GIT quotient

::: {#o1 .subject cue=lead name="GIT quotient"}

In [algebraic geometry](wikipedia://en/1997), an affine **GIT quotient**, or affine **geometric invariant theory quotient**, of an affine scheme $X = \operatorname{Spec} A$ with an [action](wikipedia://en/56600253) by a [group scheme](wikipedia://en/510523) *G* is the affine scheme $\operatorname{Spec}(A^G)$, the [prime spectrum](https://en.wikipedia.org/wiki/Prime_spectrum) of the [ring of invariants](https://en.wikipedia.org/wiki/Ring_of_invariants) of *A*, and is denoted by $X /\!/ G$. A GIT quotient is a [categorical quotient](wikipedia://en/39561038): any invariant morphism uniquely factors through it.

:::

Taking [Proj](wikipedia://en/2285000) (of a [graded ring](wikipedia://en/103094)) instead of $\operatorname{Spec}$, one obtains a projective GIT quotient (which is a quotient of the set of [semistable points](https://en.wikipedia.org/wiki/Semistable_point).)

A GIT quotient is a categorical quotient of the locus of semistable points; i.e., "the" quotient of the semistable locus. Since the categorical quotient is unique, if there is a [geometric quotient](wikipedia://en/39544418), then the two notions coincide: for example, one has

$$G / H = G /\!/ H = \operatorname{Spec}\!\big(k[G]^H\big)$$

for an [algebraic group](wikipedia://en/247924) *G* over a field *k* and closed subgroup *H*.

If *X* is a complex [smooth](https://en.wikipedia.org/wiki/Smooth_variety) [projective variety](wikipedia://en/320469) and if *G* is a reductive [complex Lie group](wikipedia://en/2187847), then the GIT quotient of *X* by *G* is homeomorphic to the [symplectic quotient](https://en.wikipedia.org/wiki/Symplectic_quotient) of *X* by a [maximal compact subgroup](wikipedia://en/1496726) of *G* ([Kempf–Ness theorem](wikipedia://en/37702763)).

::: {#o3 .definition kind=definition/construction cue=heading name="Construction of a GIT quotient"}

## Construction of a GIT quotient {#Construction_of_a_GIT_quotient}

Let *G* be a [reductive group](wikipedia://en/1088386) acting on a quasi-projective scheme *X* over a field and *L* a [linearized ample line bundle](https://en.wikipedia.org/wiki/Linearized_line_bundle) on *X*. Let

$$R = \bigoplus_{n \ge 0} \Gamma(X, L^{\otimes n})$$

be the section ring. By definition, the semistable locus $X^{ss}$ is the complement of the zero set $V(R_+^G)$ in *X*; in other words, it is the union of all open subsets $U_s = \{ s \ne 0 \}$ for global sections *s* of $(L^{\otimes n})^G$, *n* large. By ampleness, each $U_s$ is affine; say $U_s = \operatorname{Spec}(A_s)$ and so we can form the affine GIT quotient

$$\pi_s\colon U_s \to U_s /\!/ G = \operatorname{Spec}(A_s^G).$$

Note that $U_s /\!/ G$ is of finite type by [Hilbert's theorem on the ring of invariants](wikipedia://en/363762#Hilbert's_theorems). By universal property of [categorical quotients](wikipedia://en/39561038), these affine quotients glue and result in

$$\pi\colon X^{ss} \to X /\!/_L G,$$

which is the GIT quotient of *X* with respect to *L*. Note that if *X* is projective; i.e., it is the Proj of *R*, then the quotient $X /\!/_L G$ is given simply as the Proj of the [ring of invariants](https://en.wikipedia.org/wiki/Ring_of_invariants) $R^G$.

The most interesting case is when the stable locus[^o4] $X^s$ is nonempty; $X^s$ is the [open set](wikipedia://en/39358) of semistable points that have finite stabilizers and orbits that are closed in $X^{ss}$. In such a case, the GIT quotient restricts to

$$\pi^s\colon X^s \to X^s/\!/G,$$

which has the property: every fiber is an orbit. That is to say, $\pi^s$ is a genuine quotient (i.e., [geometric quotient](wikipedia://en/39544418)) and one writes $X^s/G = X^s/\!/G$. Because of this, when $X^s$ is nonempty, the GIT quotient $\pi$ is often referred to as a "compactification" of a geometric quotient of an open subset of *X*.

A difficult and seemingly open question is: which geometric quotient arises in the above GIT fashion? The question is of a great interest since the GIT approach produces an *explicit* quotient, as opposed to an abstract quotient, which is hard to compute. One known partial answer to this question is the following:[^o5] let $X$ be a [locally factorial](https://en.wikipedia.org/wiki/Locally_factorial_scheme) algebraic variety (for example, a smooth variety) with an action of $G$. Suppose there are an open subset $U \subset X$ as well as a geometric quotient $\pi\colon U \to U/G$ such that (1) $\pi$ is an [affine morphism](https://en.wikipedia.org/wiki/Affine_morphism) and (2) $U/G$ is quasi-projective. Then $U \subset X^s(L)$ for some linearlized line bundle *L* on *X*. (An analogous question is to determine which subring is the ring of invariants in some manner.)

## Examples {#Examples}

### Finite group action by $\mathbb{Z}/2\mathbb{Z}$ {#Finite_group_action_by_\Z/2\Z}

A simple example of a GIT quotient is given by the $\mathbb{Z}/2\mathbb{Z}$-action on $\mathbb{C}[x,y]$ sending

$$\begin{aligned} x \mapsto (-x) && y \mapsto (-y) \end{aligned}$$

Notice that the monomials $x^2,xy,y^2$ generate the ring $\mathbb{C}[x,y]^{\mathbb{Z}/2\mathbb{Z}}$. Hence we can write the ring of invariants as

$$\mathbb{C}[x,y]^{\mathbb{Z}/2\mathbb{Z}} = \mathbb{C}[x^2,xy,y^2] = \frac{\mathbb{C}[a,b,c]}{(ac - b^2)}$$

Scheme theoretically, we get the morphism

$$\mathbb{A}^2 \to \text{Spec}\left(\frac{\mathbb{C}[a,b,c]}{(ac - b^2)}\right) =: \mathbb{A}^2/(\mathbb{Z}/2\mathbb{Z})$$

which is a singular subvariety of $\mathbb{A}^3$ with [isolated singularity](wikipedia://en/334325) at $(0,0,0)$. This can be checked using the differentials, which are

$$df = \begin{bmatrix} c & -2b & a \end{bmatrix}$$

hence the only point where the differential and the polynomial $f$ both vanish is at the origin. The quotient obtained is a [conical surface](wikipedia://en/706244) with an [ordinary double point](wikipedia://en/22921783) at the origin.

### Torus action on plane {#Torus_action_on_plane}

Consider the torus action of $\mathbb{G}_m$ on $X = \mathbb{A}^2$ by $t\cdot (x,y) = (tx,t^{-1}y)$. Note this action has a few orbits: the origin $(0,0)$, the punctured axes, $\{(x,0) : x \neq 0\}, \{(0,y) : y \neq 0\}$, and the affine conics given by $xy = a$ for some $a \in \mathbb{C}^*$. Then, the GIT quotient $X//\mathbb{G}_m$ has structure sheaf $\mathcal{O}_{\mathbb{A}^2}^{\mathbb{G}_m}$ which is the subring of polynomials $\mathbb{C}[xy]$, hence it is isomorphic to $\mathbb{A}^1$. This gives the GIT quotient

> $$\pi\colon \mathbb{A}^2 \to \mathbb{A}^2//\mathbb{G}_m$$

Notice the inverse image of the point $(0)$ is given by the orbits $(0,0), \{(x,0) : x \neq 0\}, \{(0,y) : y \neq 0 \}$, showing the GIT quotient isn't necessarily an orbit space. If it were, there would be three origins, a non-separated space.[^o10]
