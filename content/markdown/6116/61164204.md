# Large number of rare events

::: {#o1 .subject cue=lead name="Large number of rare events"}

In [statistics](wikipedia://en/26685), **large number of rare events** (**LNRE**) modeling summarizes methods that allow improvements in [frequency distribution](https://en.wikipedia.org/wiki/Frequency_distribution) estimation over the [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimation when "[rare events](https://en.wikipedia.org/wiki/Rare_event) are common".[^o2]

:::

It can be applied to problems in linguistics (see [Zipf distribution](https://en.wikipedia.org/wiki/Zipf_distribution)), in various [natural phenomena](https://en.wikipedia.org/wiki/Natural_phenomena), in chemistry, in [demography](wikipedia://en/45642) and in [bibliography](https://en.wikipedia.org/wiki/Bibliography), amongst others.[^o3]
