# Gras conjecture

::: {#o1 .subject cue=lead name="Gras conjecture"}

In [algebraic number theory](wikipedia://en/174705), the **Gras conjecture** (Gras 1977) relates the *p*-parts of the Galois eigenspaces of an [ideal class group](wikipedia://en/150907) to the group of global units modulo [cyclotomic units](wikipedia://en/5991396). It was proved by (Mazur Wiles 1984) as a corollary of their work on the [main conjecture of Iwasawa theory](wikipedia://en/22091332). (Kolyvagin 1990) later gave a simpler proof using [Euler systems](wikipedia://en/1052176). A version of the Gras conjecture applying to [ray class groups](https://en.wikipedia.org/wiki/Ray_class_groups) was later proven by Timothy All.

:::
