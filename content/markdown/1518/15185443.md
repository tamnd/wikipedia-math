# Korn's inequality

::: {#o1 .subject cue=lead name="Korn's inequality"}

In [mathematical analysis](wikipedia://en/48396), **Korn's inequality** is an inequality concerning the [gradient](wikipedia://en/12461) of a [vector field](wikipedia://en/62641) that generalizes the following classical theorem: if the gradient of a vector field is [skew-symmetric](wikipedia://en/174055) at every point, then the gradient must be equal to a constant skew-symmetric matrix. Korn's theorem is a quantitative version of this statement, which intuitively says that if the gradient of a vector field is on average not far from the space of skew-symmetric matrices, then the gradient must not be far from a *particular* skew-symmetric matrix. The statement that Korn's inequality generalizes thus arises as a special case of [rigidity](wikipedia://en/1458875).

:::

In ([linear](wikipedia://en/301429)) [elasticity theory](https://en.wikipedia.org/wiki/Elasticity_theory), the symmetric part of the gradient is a measure of the [strain](https://en.wikipedia.org/wiki/Deformation_%28mechanics%29) that an elastic body experiences when it is deformed by a given vector-valued function. The inequality is therefore an important tool as an [a priori estimate](wikipedia://en/30669047) in linear elasticity theory.

::: {#o3 .statement cue=named-heading name="Statement of the inequality"}

## Statement of the inequality {#Statement_of_the_inequality}

Let $\Omega$ be an [open](wikipedia://en/39358), [connected](wikipedia://en/6233) domain in $n$-[dimensional](wikipedia://en/8398) [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$, $n\ge 2$. Let $H^1(\Omega)$ be the [Sobolev space](wikipedia://en/611964) of all [vector fields](wikipedia://en/62641) $v=(v^1,\dots,v^n)$ on $\Omega$ that, together with their first weak derivatives, lie in the [Lebesgue space](wikipedia://en/45194) $L^2(\Omega)$. Denoting the [partial derivative](wikipedia://en/52565) with respect to the $i$-th coordinate by $\partial_i$, the norm in $H^1(\Omega)$ is given by

$$\|v\|_{H^{1}(\Omega)} :=\left( \int_{\Omega}\sum_{i=1}^{n}|v^{i}(x)|^{2}\,\mathrm{d}x +\int_{\Omega}\sum_{i,j=1}^{n}|\partial_{j}v^{i}(x)|^{2}\,\mathrm{d}x \right)^{1/2}.$$

Then there is a (minimal) constant $C\ge 0$, called the **Korn constant** of $\Omega$, such that for all $v\in H^{1}(\Omega)$ the following inequality holds:

::: {#o4 .equation cue=numblk name="1"}

$$\| v \|_{H^{1} (\Omega)}^{2} \leq C \int_{\Omega} \sum_{i, j = 1}^{n} \left( | v^{i} (x) |^{2} + | (e_{ij} v) (x) |^{2} \right) \, \mathrm{d} x \tag{1}$$

:::

where $e$ denotes the symmetrized gradient given by

$$e_{ij} v = \frac1{2} ( \partial_{i} v^{j} + \partial_{j} v^{i} ).$$

Inequality ((1)) is known as **Korn's inequality**.

:::
