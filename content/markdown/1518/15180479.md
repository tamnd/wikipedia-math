# Projection matrix

::: {#o1 .subject cue=lead name="Projection matrix"}

In [statistics](wikipedia://en/26685), the **projection matrix** $(\mathbf{P})$,[^o2] sometimes also called the **influence matrix**[^o3] or **hat matrix** $(\mathbf{H})$, maps the vector of [response values](https://en.wikipedia.org/wiki/Response_variable) (dependent variable values) to the vector of [fitted values](https://en.wikipedia.org/wiki/Fitted_value) (or predicted values). It describes the [influence](https://en.wikipedia.org/wiki/Influence_function_%28statistics%29) each response value has on each fitted value.[^o4][^o5] The diagonal elements of the projection matrix are the [leverages](wikipedia://en/20742677), which describe the influence each response value has on the fitted value for that same observation.

:::

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

If the vector of [response values](https://en.wikipedia.org/wiki/Response_variable) is denoted by $\mathbf{y}$ and the vector of fitted values by $\mathbf{\hat{y}}$,

$$\mathbf{\hat{y}} = \mathbf{P} \mathbf{y}.$$

As $\mathbf{\hat{y}}$ is usually pronounced "y-hat", the projection matrix $\mathbf{P}$ is also named *hat matrix* as it "puts a [hat](https://en.wikipedia.org/wiki/Circumflex) on $\mathbf{y}$".

:::

::: {#o9 .pointer-item cue=pointer name="Annihilator matrix"}

## Application for residuals {#Application_for_residuals}

The formula for the vector of [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) $\mathbf{r}$ can also be expressed compactly using the projection matrix:

$$\mathbf{r} = \mathbf{y} - \mathbf{\hat{y}} = \mathbf{y} - \mathbf{P} \mathbf{y} = \left( \mathbf{I} - \mathbf{P} \right) \mathbf{y}.$$

where $\mathbf{I}$ is the [identity matrix](wikipedia://en/59718). The matrix $\mathbf{M} := \mathbf{I} - \mathbf{P}$ is sometimes referred to as the **residual maker matrix** or the **annihilator matrix**.

The [covariance matrix](wikipedia://en/191752) of the residuals $\mathbf{r}$, by [error propagation](https://en.wikipedia.org/wiki/Error_propagation), equals

$$\mathbf{\Sigma}_\mathbf{r} = \left( \mathbf{I} - \mathbf{P} \right)^\textsf{T} \mathbf{\Sigma} \left( \mathbf{I}-\mathbf{P} \right),$$

where $\mathbf{\Sigma}$ is the [covariance matrix](wikipedia://en/191752) of the error vector (and by extension, the response vector as well). For the case of linear models with [independent and identically distributed](https://en.wikipedia.org/wiki/Independent_and_identically_distributed) errors in which $\mathbf{\Sigma} = \sigma^{2} \mathbf{I}$, this reduces to:[^o4]

$$\mathbf{\Sigma}_\mathbf{r} = \left( \mathbf{I} - \mathbf{P} \right) \sigma^{2}.$$

:::

## Intuition {#Intuition}

*Image: Projection of a vector onto the column space of a matrix.svg.* A matrix, $\mathbf{A}$ has its column space depicted as the green line. The projection of some vector $\mathbf{b}$ onto the column space of $\mathbf{A}$ is the vector $\mathbf{x}$

From the figure, it is clear that the closest point from the vector $\mathbf{b}$ onto the column space of $\mathbf{A}$, is $\mathbf{Ax}$, and is one where we can draw a line orthogonal to the column space of $\mathbf{A}$. A vector that is orthogonal to the column space of a matrix is in the [nullspace](https://en.wikipedia.org/wiki/Nullspace) of the matrix transpose, so

$$\mathbf{A}^\textsf{T}(\mathbf{b}-\mathbf{Ax}) = 0.$$

From there, one rearranges, so

$$\begin{aligned} && \mathbf{A}^\textsf{T}\mathbf{b} &- \mathbf{A}^\textsf{T}\mathbf{Ax} = 0 \\ \Rightarrow && \mathbf{A}^\textsf{T}\mathbf{b} &= \mathbf{A}^\textsf{T}\mathbf{Ax} \\ \Rightarrow && \mathbf{x} &= \left(\mathbf{A}^\textsf{T}\mathbf{A}\right)^{-1}\mathbf{A}^\textsf{T}\mathbf{b} \end{aligned}.$$

Therefore, since $\mathbf{Ax}$ is on the column space of $\mathbf{A}$, the projection matrix, which maps $\mathbf{b}$ onto $\mathbf{A}\mathbf{x}$, is $\mathbf{A}\left(\mathbf{A}^\textsf{T}\mathbf{A}\right)^{-1}\mathbf{A}^\textsf{T}$.

## Linear model {#Linear_model}

Suppose that we wish to estimate a linear model using linear least squares. The model can be written as

$$\mathbf{y} = \mathbf{X} \boldsymbol\beta + \boldsymbol\varepsilon,$$

where $\mathbf{X}$ is a matrix of [explanatory variables](https://en.wikipedia.org/wiki/Explanatory_variable) (the [design matrix](wikipedia://en/949189)), ***β*** is a vector of unknown parameters to be estimated, and ***ε*** is the error vector.

Many types of models and techniques are subject to this formulation. A few examples are [linear least squares](https://en.wikipedia.org/wiki/Linear_least_squares_%28mathematics%29), [smoothing splines](https://en.wikipedia.org/wiki/Smoothing_splines), [regression splines](https://en.wikipedia.org/wiki/Regression_splines), [local regression](wikipedia://en/4146592), [kernel regression](wikipedia://en/8771825), and [linear filtering](https://en.wikipedia.org/wiki/Linear_filter).

### Ordinary least squares {#Ordinary_least_squares}

When the weights for each observation are identical and the [errors](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) are uncorrelated, the estimated parameters are

$$\hat{\boldsymbol\beta} = \left( \mathbf{X}^\textsf{T} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T} \mathbf{y},$$

so the fitted values are

$$\hat{\mathbf{y}} = \mathbf{X} \hat{\boldsymbol \beta} = \mathbf{X} \left( \mathbf{X}^\textsf{T} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T} \mathbf{y}.$$

Therefore, the projection matrix (and hat matrix) is given by

$$\mathbf{P} := \mathbf{X} \left(\mathbf{X}^\textsf{T} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T}.$$

### Weighted and generalized least squares {#Weighted_and_generalized_least_squares}

The above may be generalized to the cases where the weights are not identical and/or the errors are correlated. Suppose that the [covariance matrix](wikipedia://en/191752) of the errors is **Σ**. Then since

$$\hat{\mathbf\beta}_{\text{GLS}}= \left( \mathbf{X}^\textsf{T} \mathbf{\Sigma}^{-1} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T} \mathbf{\Sigma}^{-1}\mathbf{y}.$$

the hat matrix is thus

$$\mathbf{H} = \mathbf{X}\left( \mathbf{X}^\textsf{T} \mathbf{\Sigma}^{-1} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T} \mathbf{\Sigma}^{-1}$$

and again it may be seen that $H^2 = H\cdot H = H$, though now it is no longer symmetric.

::: {#o15 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The projection matrix has a number of useful algebraic properties.[^o16][^o17] In the language of [linear algebra](wikipedia://en/18422), the projection matrix is the [orthogonal projection](https://en.wikipedia.org/wiki/Orthogonal_projection) onto the [column space](https://en.wikipedia.org/wiki/Column_space) of the design matrix $\mathbf{X}$.[^o5] (Note that $\left( \mathbf{X}^\textsf{T} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T}$ is the [pseudoinverse of X](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse#Full_rank).) Some facts of the projection matrix in this setting are summarized as follows:[^o5]

- $\mathbf{u} = (\mathbf{I} - \mathbf{P})\mathbf{y},$ and $\mathbf{u} = \mathbf{y} - \mathbf{P} \mathbf{y} \perp \mathbf{X}.$
- $\mathbf{P}$ is symmetric, and so is $\mathbf{M} := \mathbf{I} - \mathbf{P}$.
- $\mathbf{P}$ is idempotent: $\mathbf{P}^2 = \mathbf{P}$, and so is $\mathbf{M}$.
- If $\mathbf{X}$ is an *n* × *r* matrix with $\operatorname{rank}(\mathbf{X}) = r$, then $\operatorname{rank}(\mathbf{P}) = r$
- The [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of $\mathbf{P}$ consist of *r* ones and *n* − *r* zeros, while the eigenvalues of $\mathbf{M}$ consist of *n* − *r* ones and *r* zeros.[^o18]
- $\mathbf{X}$ is invariant under $\mathbf{P}$ : $\mathbf{P X} = \mathbf{X},$ hence $\left( \mathbf{I} - \mathbf{P} \right) \mathbf{X} = \mathbf{0}$.
- $$\left( \mathbf{I} - \mathbf{P} \right) \mathbf{P} = \mathbf{P} \left( \mathbf{I} - \mathbf{P} \right) = \mathbf{0}.$$
- $\mathbf{P}$ is unique for certain subspaces.

The projection matrix corresponding to a [linear model](wikipedia://en/17904) is [symmetric](wikipedia://en/126474) and [idempotent](wikipedia://en/2974863), that is, $\mathbf{P}^2 = \mathbf{P}$. However, this is not always the case; in [locally weighted scatterplot smoothing (LOESS)](wikipedia://en/4146592), for example, the hat matrix is in general neither symmetric nor idempotent.

For [linear models](https://en.wikipedia.org/wiki/Linear_models), the [trace](wikipedia://en/43270) of the projection matrix is equal to the [rank](wikipedia://en/26561) of $\mathbf{X}$, which is the number of independent parameters of the linear model.[^o19] For other models such as LOESS that are still linear in the observations $\mathbf{y}$, the projection matrix can be used to define the [effective degrees of freedom](wikipedia://en/2321606#Effective_degrees_of_freedom) of the model.

Practical applications of the projection matrix in regression analysis include [leverage](wikipedia://en/20742677) and [Cook's distance](wikipedia://en/4473885), which are concerned with identifying [influential observations](wikipedia://en/38818738), i.e. observations which have a large effect on the results of a regression.

:::

## Blockwise formula {#Blockwise_formula}

Suppose the design matrix $\mathbf{X}$ can be decomposed by columns as $\mathbf{X} = \begin{bmatrix} \mathbf{A} & \mathbf{B} \end{bmatrix}$. Define the hat or projection operator as $\mathbf{P}[\mathbf{X}] := \mathbf{X} \left(\mathbf{X}^\textsf{T} \mathbf{X} \right)^{-1} \mathbf{X}^\textsf{T}$. Similarly, define the residual operator as $\mathbf{M}[\mathbf{X}] := \mathbf{I} - \mathbf{P}[\mathbf{X}]$. Then the projection matrix can be decomposed as follows:[^o22]

$$\mathbf{P}[\mathbf{X}] = \mathbf{P}[\mathbf{A}] + \mathbf{P}\big[\mathbf{M}[\mathbf{A}] \mathbf{B}\big],$$

where, e.g., $\mathbf{P}[\mathbf{A}] = \mathbf{A} \left(\mathbf{A}^\textsf{T} \mathbf{A} \right)^{-1} \mathbf{A}^\textsf{T}$ and $\mathbf{M}[\mathbf{A}] = \mathbf{I} - \mathbf{P}[\mathbf{A}]$. There are a number of applications of such a decomposition. In the classical application $\mathbf{A}$ is a column of all ones, which allows one to analyze the effects of adding an intercept term to a regression. Another use is in the [fixed effects model](wikipedia://en/4434344), where $\mathbf{A}$ is a large [sparse matrix](wikipedia://en/341015) of the dummy variables for the fixed effect terms. One can use this partition to compute the hat matrix of $\mathbf{X}$ without explicitly forming the matrix $\mathbf{X}$, which might be too large to fit into computer memory.

:::

## History {#History}

The hat matrix was introduced by John Wilder in 1972. An article by Hoaglin, D.C. and Welsch, R.E. (1978) gives the properties of the matrix and also many examples of its application.
