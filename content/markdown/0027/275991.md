# Range of a function

*Image: Codomain2.SVG.* $f$ is a function from [domain](wikipedia://en/50263) ***X*** to [codomain](wikipedia://en/50264) ***Y***. The yellow oval inside ***Y*** is the [image](wikipedia://en/579311) of $f$. Sometimes "range" refers to the image and sometimes to the codomain.

::: {#o1 .subject cue=lead name="Range of a function"}

In [mathematics](wikipedia://en/18831), the **range of a function** may refer to either of two closely related concepts:

:::

- the [codomain](wikipedia://en/50264) of the [function](wikipedia://en/185427), or
- the [image](wikipedia://en/579311) of the function.

In some cases the codomain and the image of a function are the same set; such a function is called *[surjective](wikipedia://en/27873)* or *onto*. For any non-surjective function $f: X \to Y,$ the codomain $Y$ and the image $\tilde Y$ are different; however, a new function can be defined with the original function's image as its codomain, $\tilde{f}: X \to \tilde{Y}$ where $\tilde{f}(x) = f(x).$ This new function is surjective.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Given two [sets](wikipedia://en/26691) $X$ and $Y$, a [binary relation](wikipedia://en/3931) $f$ between $X$ and $Y$ is a function (from $X$ to $Y$) if for every [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) $x$ in $X$ there is exactly one $y$ in $Y$ such that $f$ relates $x$ to $y$. The sets $X$ and $Y$ are called the *[domain](wikipedia://en/50263)* and *codomain* of $f$, respectively. The *image* of the function $f$ is the [subset](wikipedia://en/27631) of $Y$ consisting of only those elements $y$ of $Y$ such that there is at least one $x$ in $X$ with $f(x) = y$.

:::

## Usage {#Usage}

As the term "range" can have different meanings, it is considered a good practice to define it the first time it is used in a textbook or article. Older books, when they use the word "range", tend to use it to mean what is now called the [codomain](wikipedia://en/50264). More modern books, if they use the word "range" at all, generally use it to mean what is now called the [image](wikipedia://en/579311).[^n1] To avoid any confusion, a number of modern books don't use the word "range" at all.[^n2]

## Elaboration and example {#Elaboration_and_example}

Given a function

$$f \colon X \to Y$$

with [domain](wikipedia://en/50263) $X$, the range of $f$, sometimes denoted $\operatorname{ran}(f)$ or $\operatorname{Range}(f)$,[^o8] may refer to the codomain or target set $Y$ (i.e., the set into which all of the output of $f$ is constrained to fall), or to $f(X)$, the image of the domain of $f$ under $f$ (i.e., the subset of $Y$ consisting of all actual outputs of $f$). The image of a function is always a subset of the codomain of the function.[^o9]

As an example of the two different usages, consider the function $f(x) = x^2$ as it is used in [real analysis](wikipedia://en/26478) (that is, as a function that inputs a [real number](wikipedia://en/20646438) and outputs its square). In this case, its codomain is the set of real numbers $\mathbb{R}$, but its image is the set of non-negative real numbers $\mathbb{R}^+$, since $x^2$ is never negative if $x$ is real. For this function, if we use "range" to mean *codomain*, it refers to $\mathbb{{\displaystyle \mathbb {R} ^{}}}$; if we use "range" to mean *image*, it refers to $\mathbb{R}^+$.

For some functions, the image and the codomain coincide; these functions are called *[surjective](wikipedia://en/27873)* or *onto*. For example, consider the function $f(x) = 2x,$ which inputs a real number and outputs its double. For this function, both the codomain and the image are the set of all real numbers, so the word *range* is unambiguous.

Even in cases where the image and codomain of a function are different, a new function can be uniquely defined with its codomain as the image of the original function. For example, as a function from the [integers](wikipedia://en/14563) to the integers, the doubling function $f(n) = 2n$ is not surjective because only the [even integers](https://en.wikipedia.org/wiki/Even_integers) are part of the image. However, a new function $\tilde{f}(n) = 2n$ whose domain is the integers and whose codomain is the even integers *is* surjective. For $\tilde{f},$ the word *range* is unambiguous.
