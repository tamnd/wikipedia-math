# Jacobi set

::: {#o1 .subject cue=lead name="Jacobi set"}

In [Morse theory](wikipedia://en/348560), a mathematical discipline, **Jacobi sets** provide a method of studying the relationship between two or more [Morse functions](https://en.wikipedia.org/wiki/Morse_function).

:::

For two Morse functions, the Jacobi set is defined as the set of critical points of the restriction of one function to the level sets of the other function.[^o2]

The Jacobi set can also be defined as the set of points where the [gradients](https://en.wikipedia.org/wiki/Gradients) of the two functions are parallel.

If both the functions are generic, the Jacobi set is a smoothly embedded 1-manifold.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Consider two generic Morse functions $f, g: M \to \mathbb{R}$ defined on a smooth $d$-manifold. Let the restriction of $f$ to the level set $g^{-1}(t)$ for $t \in \mathbb{R}$ a regular value, be called $f_t: g^{-1}(t) \to \mathbb{R}$; it is a Morse function. Then the Jacobi set $J$ of $f$ and $g$ is $J = cl{\{x \in M \mid x \mbox{ is critical point of } f_t \}}$,

Alternatively, the Jacobi set is the collection of points where the gradients of the functions align with each other or one of the gradients vanish (cite?), for some $\lambda \in \mathbb{R}$, $J = \{x \in M \mid \nabla{f(x)} + \lambda \nabla{g(x)} = 0 \mbox{ or } \lambda \nabla{f(x)} + \nabla{g(x)} = 0\}.$

Equivalently, the Jacobi set can be described as the collection of critical points of the family of functions $f+ \lambda g$, for some $\lambda \in \mathbb{R}$, $J = \{x \in M \mid x \mbox{ is a critical point of } f + \lambda g \mbox{ or } \lambda f + g\}.$

:::
