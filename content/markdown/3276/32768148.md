# Bessel–Maitland function

::: {#o1 .subject cue=lead name="Bessel–Maitland function"}

In [mathematics](wikipedia://en/18831), the **Bessel–Maitland function**, or **Wright generalized Bessel function**, is a [generalization](wikipedia://en/12746) of the [Bessel function](wikipedia://en/4700), introduced by (txt). It allows to model more complex phenomena by providing solutions to a broader class of [fractional-order](wikipedia://en/39605149) [differential equations](wikipedia://en/1424309) than possible with standard Bessel functions.

:::

## Etymology {#Etymology}

The name "Bessel–Maitland function" contains a historical misnomer—"Maitland" appears in the function's name due to a confusion between Edward Maitland Wright's middle name and surname. While Wright is correctly recognized as the mathematician who generalized Johann Friedrich Bessel's original work, this nomenclature error has persisted in the mathematical literature.

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The function is given by

$$J^{\mu,\nu}(z) = \sum_{k\ge 0} \frac{(-z)^k}{\Gamma(k\mu+\nu+1)k!}.$$

:::
