# Secure file transfer program

::: {#o1 .subject cue=lead name="Secure file transfer program"}

**sftp** is a [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface) client [program](https://en.wikipedia.org/wiki/Computer_program) to transfer files using the [SSH File Transfer Protocol](wikipedia://en/428987) (SFTP), which runs inside the encrypted [Secure Shell](wikipedia://en/28814) connection.

:::

It provides an interactive interface similar to that of traditional command-line [FTP](https://en.wikipedia.org/wiki/File_Transfer_Protocol) clients.

One common implementation of sftp is part of the [OpenSSH](wikipedia://en/25490426) project.[^o3] There are other command-line SFTP clients that use different names, such as [lftp](https://en.wikipedia.org/wiki/Lftp), PSFTP and PSCP (from [PuTTY](https://en.wikipedia.org/wiki/PuTTY) package) and [WinSCP](https://en.wikipedia.org/wiki/WinSCP).
