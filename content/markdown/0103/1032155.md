# All one polynomial

::: {#o1 .subject cue=lead name="All one polynomial"}

In [mathematics](wikipedia://en/18831), an **all one polynomial** (AOP) is a [polynomial](wikipedia://en/23000) in which all [coefficients](wikipedia://en/51203) are one. Over the [finite field of order two](wikipedia://en/11137263), conditions for the AOP to be [irreducible](wikipedia://en/188725) are known, which allow this polynomial to be used to define efficient algorithms and circuits for [multiplication](wikipedia://en/20845) in [finite fields](wikipedia://en/11615) of [characteristic](wikipedia://en/1066621) two.[^o2] The AOP is a 1-[equally spaced polynomial](wikipedia://en/1032170).[^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

An AOP of [degree](wikipedia://en/5930652) *m* has all terms from *x*<sup>*m*</sup> to *x*<sup>0</sup> with coefficients of 1, and can be written as

$$AOP_m(x) = \sum_{i=0}^{m} x^i$$

or

$$AOP_m(x) = x^m + x^{m-1} + \cdots + x + 1$$

or

$$AOP_m(x) = {x^{m+1} - 1\over{x-1}}.$$

Thus the [roots](https://en.wikipedia.org/wiki/Root_of_a_polynomial) of the **all one polynomial** of degree *m* are all (*m*+1)th [roots of unity](https://en.wikipedia.org/wiki/Roots_of_unity) other than unity itself.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Over [GF(2)](wikipedia://en/11137263) the AOP has many interesting properties, including:

- The [Hamming weight](wikipedia://en/1127884) of the AOP is *m* + 1, the maximum possible for its degree[^o8]
- The AOP is [irreducible](wikipedia://en/188725) [if and only if](wikipedia://en/14922) *m* + 1 is [prime](wikipedia://en/23666) and 2 is a [primitive root](wikipedia://en/186864) modulo *m* + 1[^o2] (over GF(*p*) with prime *p*, it is irreducible if and only if *m* + 1 is prime and *p* is a primitive root modulo *m* + 1)
- The only AOP that is a [primitive polynomial](wikipedia://en/1029177) is *x*<sup>2</sup> + *x* + 1.

Despite the fact that the Hamming weight is large, because of the ease of representation and other improvements there are efficient implementations in areas such as [coding theory](wikipedia://en/321869) and [cryptography](wikipedia://en/18934432).[^o2]

Over $\mathbb{Q}$, the AOP is irreducible whenever *m* + 1 is a prime *p*, and therefore in these cases, the *p*th [cyclotomic polynomial](wikipedia://en/171992).[^o9]
