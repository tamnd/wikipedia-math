# Key generator

::: {#o1 .subject cue=lead name="Key generator"}

A **key generator**[^o2][^o3][^o4] is a protocol or algorithm that is used in many [cryptographic](wikipedia://en/18934432) [protocols](https://en.wikipedia.org/wiki/Protocol_%28computing%29) to generate a sequence with many [pseudo-random](https://en.wikipedia.org/wiki/Pseudo-random) characteristics. This sequence is used as an [encryption](wikipedia://en/10294) key at one end of communication, and as a decryption key at the other. One can implement a key generator in a system that aims to generate, distribute, and authenticate[^o5] keys in a way that without the private key, one cannot access the information in the public end.[^o6]

:::

Examples of key generators include [linear-feedback shift registers](wikipedia://en/58992) (LFSR) and the [Solitaire](wikipedia://en/1708364) (or Pontifex) cipher.
