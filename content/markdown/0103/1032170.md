# Equally spaced polynomial

::: {#o1 .subject cue=lead name="Equally spaced polynomial"}

An **equally spaced polynomial** (ESP) is a [polynomial](wikipedia://en/23000) used in [finite fields](wikipedia://en/11615), specifically [GF(2)](wikipedia://en/11137263) ([binary](https://en.wikipedia.org/wiki/Binary_numeral_system)).

:::

An *s*-ESP of degree *sm* can be written as:

$ESP(x) = \sum_{i=0}^{m} x^{si}$ for $i = 0, 1, \ldots, m$

or

$$ESP(x) = x^{sm} + x^{s(m-1)} + \cdots + x^s + 1.$$

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Over GF(2) the ESP - which then can be referred to as all one polynomial (AOP) - has many interesting properties, including:

- The [Hamming weight](wikipedia://en/1127884) of the ESP is *m* + 1.

A 1-ESP is known as an [all one polynomial](wikipedia://en/1032155) (AOP) and has additional properties including the above.[^o4]

:::
