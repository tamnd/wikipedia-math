# Just another Gibbs sampler

::: {#o2 .subject cue=lead name="Just another Gibbs sampler"}

**Just another Gibbs sampler** (**JAGS**) is a program for simulation from [Bayesian hierarchical models](wikipedia://en/42734031) using [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC), developed by Martyn Plummer. JAGS has been employed for statistical work in many fields, for example ecology, management, and genetics.[^o3][^o4][^o5]

:::

JAGS aims for compatibility with [WinBUGS](wikipedia://en/10794084)/[OpenBUGS](wikipedia://en/3578854) through the use of a dialect of the same modeling language (informally, BUGS), but it provides no GUI for model building and MCMC sample postprocessing, which must therefore be treated in a separate program (for example calling JAGS from [R](wikipedia://en/376707) through a library such as rjags and post-processing MCMC output in R).[^o6]

The main advantage of JAGS in comparison to the members of the original BUGS family ([WinBUGS](wikipedia://en/10794084) and [OpenBUGS](wikipedia://en/3578854)) is its platform independence. It is written in C++, while the BUGS family is written in [Component Pascal](https://en.wikipedia.org/wiki/Component_Pascal), a less widely known programming language.[^o7][^o8] In addition, JAGS is already part of many repositories of Linux distributions such as Ubuntu. It can also be compiled as a 64-bit application on 64-bit platforms, thus making all the addressable space available to BUGS models.

JAGS can be used via the command line or run in batch mode through script files. This means that there is no need to redo the settings with every run and that the program can be called and controlled from within another program (e.g. from [R](wikipedia://en/376707) via rjags as outlined above).
