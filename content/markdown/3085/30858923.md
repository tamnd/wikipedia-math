# KeePass

::: {#o2 .subject cue=lead name="KeePass"}

**KeePass Password Safe** is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source) [password manager](wikipedia://en/4696394) primarily for [Windows](https://en.wikipedia.org/wiki/Windows). It officially supports [macOS](https://en.wikipedia.org/wiki/MacOS) and [Linux](https://en.wikipedia.org/wiki/Linux) [operating systems](https://en.wikipedia.org/wiki/Operating_system) through the use of [Mono](https://en.wikipedia.org/wiki/Mono_%28software%29).[^o3] Additionally, there are several unofficial [ports](https://en.wikipedia.org/wiki/Porting) for [Windows Phone](https://en.wikipedia.org/wiki/Windows_Phone), [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29), [iOS](https://en.wikipedia.org/wiki/IOS), and [BlackBerry](https://en.wikipedia.org/wiki/BlackBerry) devices, which normally work with the same copied or shared (remote) password [database](https://en.wikipedia.org/wiki/Database).[^o4][^o5][^o6][^o7][^o8] KeePass stores usernames, passwords, and other fields, including free-form notes and file attachments, in an encrypted [file](https://en.wikipedia.org/wiki/Computer_file). This file can be protected by any combination of a [master password](https://en.wikipedia.org/wiki/Master_password), a key file, and the current Windows account details. By default, the KeePass database is stored on a local [file system](https://en.wikipedia.org/wiki/File_system) (as opposed to [cloud storage](https://en.wikipedia.org/wiki/Cloud_storage)).[^o9]

:::

KeePass comes in two different variants: KeePass 1.x and KeePass 2.x. Although the 1.x variant is the former variant it is supported indefinitely: Dominik Reichl: "2.x isn't the successor of 1.x, and 1.x isn't dead".[^o10] KeePass 2.x has a different software basis in [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29) instead of the former [C++](https://en.wikipedia.org/wiki/C++). Mainly [communication](https://en.wikipedia.org/wiki/Data_communication) features are extended in KeePass 2.x: authentication with the [Windows](https://en.wikipedia.org/wiki/Windows) [user account](https://en.wikipedia.org/wiki/User_account), [remote](https://en.wikipedia.org/wiki/Remote_access_service) and shared database editing as well as many plugins allowing communication and authentication with different [web browsers](https://en.wikipedia.org/wiki/Web_browser), [databases](https://en.wikipedia.org/wiki/Database) and more.[^o11][^o12]

KeePass 1.x and 2.x support a number of [plugins](https://en.wikipedia.org/wiki/Plug-in_%28computing%29), although 2.x allows more plugins.[^o12] It has a [password generator](https://en.wikipedia.org/wiki/Random_password_generator) and synchronization function, supports [two-factor authentication](https://en.wikipedia.org/wiki/Two-factor_authentication), and has a *Secure Desktop* mode. It can use a two-channel auto-type obfuscation feature to offer additional protection against [keyloggers](https://en.wikipedia.org/wiki/Keystroke_logging).[^o13] KeePass can import from over 30 other most commonly used password managers.[^o13]

A 2017 [Consumer Reports](https://en.wikipedia.org/wiki/Consumer_Reports) article described KeePass as one of the four most widely used password managers (alongside [1Password](https://en.wikipedia.org/wiki/1Password), [Dashlane](https://en.wikipedia.org/wiki/Dashlane) and [LastPass](https://en.wikipedia.org/wiki/LastPass)), being "popular among tech enthusiasts" and offering the same level of security as non-free competitors.[^o14]

A 2019 Independent Security Evaluators study described KeePass as well as other widely used password managers as being unable to control [Windows 10](https://en.wikipedia.org/wiki/Windows_10)'s tendency to leave passwords in cleartext in RAM after they are displayed using Windows controlled GUI.[^o15] In addition, several GitHub projects (KeeFarce, KeeThief, Lazanga) specifically attack a running KeePass to steal all data when the host is compromised. KeePass cannot prevent password theft and, as Dominik Reichl, the administrator of KeePass, states, "neither KeePass nor any other password manager can magically run securely in a spyware-infected, insecure environment."[^o16]

## Overview {#Overview}

### Import and export {#Import_and_export}

The password list is saved by default as a `.kdbx` file, but it can be exported to [.txt](https://en.wikipedia.org/wiki/.txt), [HTML](https://en.wikipedia.org/wiki/HTML), [XML](https://en.wikipedia.org/wiki/Extensible_Markup_Language) and [CSV](https://en.wikipedia.org/wiki/Comma-separated_values).[^o19] The XML output can be used in other applications and re-imported into KeePass using a plugin. The CSV output is compatible with many other password safes like the commercial closed-source Password Keeper and the closed-source Password Agent. Also, the CSVs can be imported by spreadsheet applications like Microsoft Excel or [OpenOffice](https://en.wikipedia.org/wiki/OpenOffice.org_Calc)/[LibreOffice Calc](https://en.wikipedia.org/wiki/LibreOffice_Calc).

KeePass 2.x has import support for several popular formats built-in. File format support can be expanded through the use of KeePass plugins.[^o20]

### Multi-user support {#Multi-user_support}

KeePass supports simultaneous access and simultaneous changes to a shared password file by multiple computers (often by using a shared network drive), however there is no provisioning of access per-group or per-entry.[^o22] As of May 2014, there are no plugins available to add provisioned multi-user support, but there exists a [proprietary](https://en.wikipedia.org/wiki/Proprietary_software) password server (now titled Keepass Hub, formerly known as [Pleasant Password Server](https://en.wikipedia.org/wiki/Pleasant_Password_Server)) that is compatible with the KeePass client and includes provisioning.[^o23]

### Auto-type and drag and drop {#Auto-type_and_drag_and_drop}

*Image: Keepass-autotype.gif.* An example of KeePass's auto-type function, which is triggered by a global hotkey

KeePass can minimize itself and type the information of the currently selected entry into dialogs, webforms, etc. KeePass has a global auto-type hot key. When KeePass is running in the background (with an unlocked database) and user presses down the hotkey, it looks up the selected (or correct) entry and enters every login and/or password characters sequence.[^o25] All fields, such as title, username, password, URL, and notes, can be [drag and dropped](https://en.wikipedia.org/wiki/Drag_and_drop) into other windows.

Windows [clipboard](https://en.wikipedia.org/wiki/Clipboard_%28software%29) handling allows double-clicking on any field of the password list to copy its value to the Windows clipboard.

KeePass may be configured to randomize characters' input sequence to make it harder to [log keystrokes](https://en.wikipedia.org/wiki/Keystroke_logging). The features is called Two-Channel Auto-Type Obfuscation (TCATO).[^o26]

### Clipboard reset {#Clipboard_reset}

KeePass automatically clears the clipboard some time after the user has copied one of their passwords into it. KeePass features protection against clipboard monitors (other applications will not get notifications that the clipboard content has been changed).

KeePass at one time had a paste-once functionality, where after a single paste operation, the clipboard would be cleared automatically, but this was removed in version 2.x due to incompatibility and insufficient effectiveness.[^o28]

### Browser support {#Browser_support}

The auto-type functionality works with all windows, and consequently with all browsers. The KeeForm extension fills in user details into website form fields automatically. It is available for [Mozilla Firefox](https://en.wikipedia.org/wiki/Mozilla_Firefox), Google Chrome, and Microsoft Edge. Internet Explorer also has a browser integration [toolbar](https://en.wikipedia.org/wiki/Toolbar) available.[^o30]

### Built-in password generator {#Built-in_password_generator}

*Image: KeePass random password.png.* User Interface of the password generator

KeePass features a built-in [password generator](https://en.wikipedia.org/wiki/Random_password_generator) that generates random passwords. Random seeding can be done through user input (mouse movement and random keyboard input).[^o25]

### Plugins {#Plugins}

KeePass has a plugin architecture. There are various plugins available from the KeePass website (such as import/export from/to various other formats, database backup, integration, automation, etc.). Note that plugins may compromise the security of KeePass, because they are written by independent authors and have full access to the KeePass database.[^o12]

### Wrapper {#Wrapper}

KeePass has an opensource wrapper, QuicKeepass, that allows the use of KeePass more efficiently on Linux.[^o34]

## Cryptography {#Cryptography}

### Runtime security {#Runtime_security}

*Image: KeePass add entry.png.* "Add Entry" dialog in KeePass

According to the utility's author, KeePass was one of the first password management utilities to use security-enhanced password edit controls, in this case one called CSecureEditEx.[^o37] The author makes several claims regarding the security of the control and its resistance to password revealing utilities; however, the author does not cite or make any references to any third-party testing of the control to corroborate the claims of its security.[^o38]

Passwords are protected in memory while KeePass is running. On Windows Vista and later versions, passwords are encrypted in process memory using Windows [Data Protection API](https://en.wikipedia.org/wiki/Data_Protection_API), which allows storing the key for memory protection in a secure, non-swappable memory area. On previous Windows systems, KeePass falls back to using the [ARC4](https://en.wikipedia.org/wiki/ARC4) cipher with a temporary, random session key.[^o39]

### Offline security {#Offline_security}

*Image: KeePass master key.png.* Create master key

Access to the database is restricted by a master password or a key file. Both methods may be combined to create a "composite master key". If both methods are used, then both must be present to access the password database. KeePass version 2.x introduces a third option—dependency upon the current Windows user.[^o41] KeePass encrypts the database with the [AES](wikipedia://en/1260), [Twofish](wikipedia://en/26508356) or [ChaCha20](https://en.wikipedia.org/wiki/ChaCha20) symmetric cipher, where the first two are used in CBC/PKCS7 mode. AES is the default option in both KeePass editions, Twofish is available in KeePass 1.x, ChaCha20 is available only in KeePass 2.35 and higher.[^o42] However, a separate plugin provides Twofish as an encryption algorithm in KeePass 2.x. In KeePass 1.x (KDB database format), the integrity of the data is checked using a SHA-256 hash of the plaintext, whereas in KeePass 2.x (KDBX database format), the [authenticity](wikipedia://en/2244296) of the data is ensured using a HMAC-SHA-256 hash of the ciphertext (Encrypt-then-MAC construction).[^o43]

## Notable KeePass derivatives {#Notable_KeePass_derivatives}

- [KeePassDX](https://en.wikipedia.org/wiki/KeePassDX), a fork of KeePass designed for [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29)
- [KeePassX](https://en.wikipedia.org/wiki/KeePassX), a multi-platform open source KeePass clone for Linux and macOS, built using the [Qt libraries](https://en.wikipedia.org/wiki/Qt_%28toolkit%29).[^o45] As of December 2021, KeePassX is no longer actively maintained.[^o46]
- [KeePassXC](wikipedia://en/53645358) (KeePass Cross-Platform Community Edition) is a fork of KeePassX written in [C++](https://en.wikipedia.org/wiki/C++).[^o47]
- [KeeWeb](wikipedia://en/63510139), a cross-platform [JavaScript](https://en.wikipedia.org/wiki/JavaScript) web application using the KeePass database format, desktop version built with [Electron](https://en.wikipedia.org/wiki/Electron_%28software_framework%29).
- KyPass, developed by [Miguel Vanhove](https://en.wikipedia.org/wiki/Miguel_Vanhove), compatible with Apple platforms[^o48] and offering native support for [Dropbox](https://en.wikipedia.org/wiki/Dropbox), [OneDrive](https://en.wikipedia.org/wiki/OneDrive) and other online backup services.

## Reception {#Reception}

In 2006[^o50] and 2016[^o51], [Der Standard](https://en.wikipedia.org/wiki/Der_Standard) highlighted KeePass to its readers as an effective tool for managing and organizing passwords.
