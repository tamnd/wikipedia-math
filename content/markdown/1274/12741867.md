# Steffensen's inequality

::: {#o1 .subject cue=lead name="Steffensen's inequality"}

**Steffensen's inequality** is an equation in [mathematics](wikipedia://en/18831) named after [Johan Frederik Steffensen](wikipedia://en/13980221).[^o2]

:::

It is an [integral](wikipedia://en/15532) [inequality](wikipedia://en/89489) in real analysis, stating:

If ƒ : \[*a*, *b*\] → **R** is a non-negative, [monotonically decreasing](wikipedia://en/48260), [integrable function](https://en.wikipedia.org/wiki/Integrable_function)

and *g* : \[*a*, *b*\] → \[0, 1\] is another integrable function, then

$$\int_{b - k}^{b} f(x) \, dx \leq \int_{a}^{b} f(x) g(x) \, dx \leq \int_{a}^{a + k} f(x) \, dx,$$

where

$$k = \int_{a}^{b} g(x) \, dx.$$
