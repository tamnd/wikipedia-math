# Quasi-identity

::: {#o1 .subject cue=lead name="Quasi-identity"}

In [universal algebra](wikipedia://en/45200), a **quasi-identity** is an implication of the form

:::

*s*<sub>1</sub> = *t*<sub>1</sub> ∧ … ∧ *s*<sub>*n*</sub> = *t*<sub>*n*</sub> → *s* = *t*

where *s*<sub>1</sub>, ..., *s*<sub>*n*</sub>, *t*<sub>1</sub>, ..., *t*<sub>*n*</sub>, *s*, and *t* are [terms](wikipedia://en/24885593) built up from variables using the operation symbols of the specified [signature](wikipedia://en/7788156).

A quasi-identity amounts to a conditional equation for which the conditions themselves are equations. Alternatively, it can be seen as a disjunction of inequations and one equation *s*<sub>1</sub> ≠ *t*<sub>1</sub> ∨ ... ∨ *s*<sub>*n*</sub> ≠ *t*<sub>*n*</sub> ∨ *s* = *t*—that is, as a definite [Horn clause](wikipedia://en/333824). A quasi-identity with *n* = 0 is an ordinary [identity](wikipedia://en/298428) or equation, so quasi-identities are a generalization of identities.
