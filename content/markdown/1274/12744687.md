# Right half-plane

::: {#o1 .subject cue=lead name="Right half-plane"}

In [complex analysis](wikipedia://en/5759), the **(open) right half-plane** is the set of all points in the [complex plane](wikipedia://en/217628) whose [real part](https://en.wikipedia.org/wiki/Real_part) is strictly positive, that is, the set $\{z \in \mathbb{C}\, :\, \mbox{Re}(z) > 0\}$.

:::
