# Doubly linked face list

::: {#o1 .subject cue=lead name="Doubly linked face list"}

In [applied mathematics](wikipedia://en/24295969), a **doubly linked face list** (**DLFL**) is an efficient [data structure](wikipedia://en/8519) for storing [2-manifold](wikipedia://en/2119193) mesh data. The structure stores [linked lists](https://en.wikipedia.org/wiki/Linked_list) for a 3D mesh's faces, edges, vertices, and corners. The structure guarantees the preservation of the [manifold](wikipedia://en/2073470) property.[^o2][^o3]

:::
