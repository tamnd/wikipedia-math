# Lusin's theorem

::: {#o1 .subject cue=lead name="Lusin's theorem"}

In the [mathematical](wikipedia://en/18831) field of [mathematical analysis](wikipedia://en/48396), **Lusin's theorem** (or **Luzin's theorem**, named for [Nikolai Luzin](wikipedia://en/576228)) or **Lusin's criterion** states that an [almost-everywhere](wikipedia://en/44688) finite function is [measurable](wikipedia://en/44055) if and only if it is a [continuous function](wikipedia://en/6122) on nearly all its domain. In the [informal formulation](https://en.wikipedia.org/wiki/Littlewood's_second_principle) of [J. E. Littlewood](https://en.wikipedia.org/wiki/J._E._Littlewood), "every measurable function is nearly continuous".

:::

## Classical statement {#Classical_statement}

For an interval \[*a*, *b*\], let

$$f:[a,b]\rightarrow \mathbb{C}$$

be a measurable function. Then, for every *ε* > 0, there exists a compact *E* ⊆ \[*a*, *b*\] such that *f* restricted to *E* is continuous and

$$\mu ( E ) > b - a - \varepsilon.$$

Note that *E* inherits the [subspace topology](wikipedia://en/910926) from \[*a*, *b*\]; continuity of *f* restricted to *E* is defined using this topology.

Also for any function *f*, defined on the interval \[*a, b*\] and almost-everywhere finite, if for any *ε > 0* there is a function *ϕ*, continuous on \[*a, b*\], such that the measure of the set

$$\{x\in[a,b]:f(x) \neq \phi(x)\}$$

is less than *ε*, then *f* is measurable.[^o3]

## General form {#General_form}

Let $(X,\Sigma,\mu)$ be a [Radon measure](wikipedia://en/521933) space and *Y* be a [second-countable](https://en.wikipedia.org/wiki/Second-countable) topological space equipped with a [Borel algebra](https://en.wikipedia.org/wiki/Borel_algebra), and let $f: X \rightarrow Y$ be a measurable function. Given $\varepsilon>0$, for every $A\in\Sigma$ of finite measure there is a closed set $E$ with $\mu(A\setminus E) <\varepsilon$ such that $f$ restricted to $E$ is continuous.

(If $A$ is [locally compact](https://en.wikipedia.org/wiki/Locally_compact) and $Y=\mathbb{R}^d$, we can choose $E$ to be compact and even find a continuous function $f_\varepsilon: X \rightarrow \mathbb{R}^d$ with compact support that coincides with $f$ on $E$ and such that

$\ \sup_{x\in X} | f_\varepsilon (x) | \leq \sup_{x\in X} | f(x) |$.)

Informally, measurable functions into spaces with countable base can be approximated by continuous functions on arbitrarily large portion of their domain.

::: {#o6 .proof cue=heading name="On the proof"}

## On the proof {#On_the_proof}

The proof of Lusin's theorem can be found in many classical books. Intuitively, one expects it as a consequence of [Egorov's theorem](wikipedia://en/1767634) and density of smooth functions. Egorov's theorem states that [pointwise convergence](wikipedia://en/340198) is nearly uniform, and [uniform convergence](wikipedia://en/50652) preserves continuity.

:::

::: {#o8 .example cue=heading name="Example"}

## Example {#Example}

The strength of Lusin's theorem might not be readily apparent, as can be demonstrated by example. Consider [Dirichlet function](wikipedia://en/630005), that is the [indicator function](wikipedia://en/240790) $1_\mathbb{Q}:[0,1]\to \{0,1\}$ on the unit interval $[0,1]$ taking the value of one on the rationals, and zero, otherwise. Clearly the measure of this function should be zero, but how can one find regions that are continuous, given that the rationals are [dense](wikipedia://en/23523594) in the reals? The requirements for Lusin's theorem can be satisfied with the following construction of a set $E.$

Let $\{x_n; n=1,2,\dots\}$ be any enumeration of $\mathbb{Q}$. Set

$$G_n=(x_n-\varepsilon/2^n,x_n+\varepsilon/2^n)$$

and

$$E:=[0,1]\setminus\bigcup_{n=1}^\infty G_n.$$

Then the sequence of open sets $G_n$ "knocks out" all of the rationals, leaving behind a compact, closed set $E$ which contains no rationals, and has a measure of more than $1-2\varepsilon$.

:::
