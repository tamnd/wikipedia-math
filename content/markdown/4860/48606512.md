# Lagrange stability

::: {#o1 .subject cue=lead name="Lagrange stability"}

**Lagrange stability** is a concept in the [stability theory](wikipedia://en/5493795) of [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems), named after [Joseph-Louis Lagrange](wikipedia://en/87793).

:::

For any point in the state space, $x \in M$ in a real continuous [dynamical system](https://en.wikipedia.org/wiki/Dynamical_system_%28definition%29) $(T,M,\Phi)$, where $T$ is $\mathbb{R}$, the **motion** $\Phi(t,x)$ is said to be *positively Lagrange stable* if the [positive semi-orbit](wikipedia://en/252250) $\gamma_x^+$ is [compact](https://en.wikipedia.org/wiki/Compact_set). If the [negative semi-orbit](wikipedia://en/252250) $\gamma_x^-$ is [compact](https://en.wikipedia.org/wiki/Compact_set), then the motion is said to be *negatively Lagrange stable*. The motion through $x$ is said to be *Lagrange stable* if it is both positively and negatively Lagrange stable. If the state space $M$ is the [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$, then the above definitions are equivalent to $\gamma_x^+, \gamma_x^-$ and $\gamma_x$ being [bounded](wikipedia://en/48258), respectively.

A **dynamical system** is said to be positively-/negatively-/Lagrange stable if *for each* $x \in M$, the motion $\Phi(t,x)$ is positively-/negatively-/Lagrange stable, respectively.
