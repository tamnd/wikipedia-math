# Valuation (logic)

::: {#o1 .subject cue=lead name="Valuation"}

In [logic](wikipedia://en/46426065) and [model theory](wikipedia://en/19858), a **valuation** can be:

:::

- In [propositional logic](wikipedia://en/18154), an assignment of [truth values](wikipedia://en/161711) to [propositional variables](wikipedia://en/1557562), with a corresponding assignment of truth values to all [propositional formulas](wikipedia://en/1557634) with those variables.
- In [first-order logic](wikipedia://en/10983) and higher-order logics, a [structure](wikipedia://en/4055928), (the [interpretation](wikipedia://en/14511671)) and the corresponding assignment of a truth value to each sentence in the language for that structure (the valuation proper). The interpretation must be a [homomorphism](wikipedia://en/13564), while valuation is simply a [function](wikipedia://en/185427).

## Mathematical logic {#Mathematical_logic}

In mathematical logic (especially model theory), a valuation is an assignment of truth values to formal sentences that follows a [truth schema](wikipedia://en/1063436). Valuations are also called truth assignments.

In propositional logic, there are no quantifiers, and formulas are built from propositional variables using logical connectives. In this context, a valuation begins with an assignment of a truth value to each propositional variable. This assignment can be uniquely extended to an assignment of truth values to all propositional formulas.

In first-order logic, a language consists of a collection of constant symbols, a collection of function symbols, and a collection of relation symbols. Formulas are built out of [atomic formulas](wikipedia://en/4472066) using logical connectives and quantifiers. A [structure](wikipedia://en/4055928) consists of a set ([domain of discourse](wikipedia://en/229180)) that determines the range of the quantifiers, along with interpretations of the constant, function, and relation symbols in the language. Corresponding to each structure is a unique truth assignment for all [sentences](wikipedia://en/2129527) (formulas with no [free variables](https://en.wikipedia.org/wiki/Free_variables)) in the language.

::: {#o4 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

If $v$ is a valuation, that is, a mapping from the atoms to the set $\{ t, f \}$, then the double-bracket notation is commonly used to denote a valuation; that is, $[\![\phi]\!]_v = v(\phi)$ for a propositional formula $\phi$.[^o5]

:::
