# Count data

::: {#o1 .subject cue=lead name="Count data"}

In [statistics](wikipedia://en/26685), **count data** is a [statistical data type](wikipedia://en/35269346) describing *[countable quantities](https://en.wikipedia.org/wiki/Countable_quantity)*, [data](https://en.wikipedia.org/wiki/Data) which can take only the *[counting numbers](https://en.wikipedia.org/wiki/Counting_number)*, non-negative [integer](wikipedia://en/14563) values {0, 1, 2, 3, ...}, and where these integers arise from *[counting](wikipedia://en/275768)* rather than [ranking](wikipedia://en/1482394). The statistical treatment of count data is distinct from that of [binary data](https://en.wikipedia.org/wiki/Binary_data), in which the observations can take only two values, usually represented by 0 and 1, and from [ordinal data](wikipedia://en/52904244), which may also consist of integers but where the individual values fall on an arbitrary scale and only the relative ranking is important.

:::

## Count variables {#Count_variables}

An individual piece of count data is often termed a **count variable**. When such a variable is treated as a [random variable](wikipedia://en/25685), the [Poisson](wikipedia://en/23009144), [binomial](wikipedia://en/3876) and [negative binomial](wikipedia://en/45177) distributions are commonly used to represent its distribution.

## Graphical examination {#Graphical_examination}

Graphical examination of count data may be aided by the use of [data transformations](wikipedia://en/10056274) chosen to have the property of stabilising the sample variance. In particular, the [square root](wikipedia://en/29208) transformation might be used when data can be approximated by a [Poisson distribution](wikipedia://en/23009144) (although other transformation have modestly improved properties), while an inverse sine transformation is available when a [binomial distribution](wikipedia://en/3876) is preferred.

## Relating count data to other variables {#Relating_count_data_to_other_variables}

Here the count variable would be treated as a [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable). Statistical methods such as [least squares](wikipedia://en/82359) and [analysis of variance](wikipedia://en/634) are designed to deal with continuous dependent variables. These can be adapted to deal with count data by using [data transformations](wikipedia://en/10056274) such as the [square root](wikipedia://en/29208) transformation, but such methods have several drawbacks; they are approximate at best and estimate [parameters](wikipedia://en/25065) that are often hard to interpret.

The [Poisson distribution](wikipedia://en/23009144) can form the basis for some analyses of count data and in this case [Poisson regression](wikipedia://en/2708102) may be used. This is a special case of the class of [generalized linear models](wikipedia://en/747122) which also contains specific forms of model capable of using the [binomial distribution](wikipedia://en/3876) ([binomial regression](wikipedia://en/4916857), [logistic regression](wikipedia://en/226631)) or the [negative binomial distribution](wikipedia://en/45177) where the assumptions of the Poisson model are violated, in particular when the range of count values is limited or when [overdispersion](wikipedia://en/4190350) is present.
