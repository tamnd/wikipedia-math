# Diaconescu

::: {#o1 .subject cue=lead name="Diaconescu"}

- [Camelia Diaconescu](https://en.wikipedia.org/wiki/Camelia_Diaconescu) (b. 1963), rower
- [Cristian Diaconescu](https://en.wikipedia.org/wiki/Cristian_Diaconescu) (b. 1959), diplomat and politician
- [Dan Diaconescu](https://en.wikipedia.org/wiki/Dan_Diaconescu) (b. 1967), politician, media tycoon, television presenter
- [Grigoraș Diaconescu](https://en.wikipedia.org/wiki/Grigoraș_Diaconescu) (b.1982), football player
- [Ioana Diaconescu](https://en.wikipedia.org/wiki/Ioana_Diaconescu) (b. 1979), swimmer
- [Ion Diaconescu](https://en.wikipedia.org/wiki/Ion_Diaconescu) (1917–2011), dissident and politician
- [Mircea Diaconescu](https://en.wikipedia.org/wiki/Mircea_Diaconescu) (b. 1929), composer
