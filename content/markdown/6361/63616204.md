# Node2vec

::: {#o1 .subject cue=lead name="Node2vec"}

**node2vec** is an algorithm to generate vector representations of nodes on a [graph.](wikipedia://en/12401) The *node2vec* framework learns low-dimensional representations for nodes in a graph through the use of [random walks](wikipedia://en/235451) through a graph starting at a target node. It is useful for a variety of [machine learning](wikipedia://en/233488) applications. *node2vec* follows the intuition that random walks through a graph can be treated like sentences in a corpus. Each node in a graph is treated like an individual word, and a random walk is treated as a sentence. By feeding these "sentences" into a [skip-gram](https://en.wikipedia.org/wiki/N-gram), or by using the [continuous bag of words](https://en.wikipedia.org/wiki/Bag-of-words_model) model, paths found by random walks can be treated as sentences, and traditional data-mining techniques for documents can be used. The algorithm generalizes prior work which is based on rigid notions of network neighborhoods, and argues that the added flexibility in exploring neighborhoods is the key to learning richer representations of nodes in graphs.[^o2] The algorithm is considered one of the best graph classifiers.[^o3]

:::
