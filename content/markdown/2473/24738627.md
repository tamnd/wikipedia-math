# Lyapunov–Malkin theorem

::: {#o1 .subject cue=lead name="Lyapunov–Malkin theorem"}

The **Lyapunov–Malkin theorem** (named for [Aleksandr Lyapunov](https://en.wikipedia.org/wiki/Aleksandr_Mikhailovich_Lyapunov) and Ioel Malkin) is a mathematical theorem detailing stability of nonlinear systems.[^o2][^o3]

:::

::: {#o5 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

In the system of [differential equations](wikipedia://en/1424309),

$$\dot x = Ax + X(x,y),\quad\dot y = Y(x,y)$$

where $x \in \mathbb{R}^m$ and $y \in \mathbb{R}^n$ are components of the system state, $A \in \mathbb{R}^{m\times m}$ is a [matrix](wikipedia://en/20556859) that represents the linear dynamics of $x$, and $X : \mathbb{R}^m\times \mathbb{R}^n \to \mathbb{R}^m$ and $Y : \mathbb{R}^m\times \mathbb{R}^n \to \mathbb{R}^n$ represent higher-order nonlinear terms. If all [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of the matrix $A$ have negative real parts, and *X*(*x*, *y*), *Y*(*x*, *y*) vanish when *x* = 0, then the solution *x* = 0, *y* = 0 of this system is stable with respect to (*x*, *y*) and asymptotically stable with respect to *x*. If a solution (*x*(*t*), *y*(*t*)) is close enough to the solution *x* = 0, *y* = 0, then

$$\lim_{t \to \infty}x(t) = 0,\quad \lim_{t \to \infty}y(t) = c.$$

:::

::: {#o7 .example cue=heading name="Example"}

## Example {#Example}

Consider the vector field given by

$$\dot x = -x + x^2y, \quad\dot y = xy^2$$

In this case, *A* = -1 and *X*(0, *y*) = *Y*(0, *y*) = 0 for all *y*, so this system satisfy the hypothesis of Lyapunov-Malkin theorem.
