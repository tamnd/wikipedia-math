# Logistic model tree

::: {#o1 .subject cue=lead name="Logistic model tree"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), a **logistic model tree** (**LMT**) is a [classification](wikipedia://en/1579244) model with an associated [supervised training](wikipedia://en/20926) [algorithm](wikipedia://en/775) that combines [logistic regression](wikipedia://en/226631) (LR) and [decision tree learning](wikipedia://en/577003).[^o2][^o3]

:::

Logistic model trees are based on the earlier idea of a model tree: a decision tree that has [linear regression](wikipedia://en/48758386) models at its leaves to provide a [piecewise linear](wikipedia://en/444224) regression model (where ordinary decision trees with constants at their leaves would produce a piecewise constant model).[^o2] In the logistic variant, the [LogitBoost](https://en.wikipedia.org/wiki/LogitBoost) algorithm is used to produce an LR model at every node in the tree; the node is then split using the [C4.5](https://en.wikipedia.org/wiki/C4.5_algorithm) criterion. Each LogitBoost invocation is warm-started from its results in the parent node. Finally, the tree is pruned.[^o4]

The basic LMT induction algorithm uses [cross-validation](wikipedia://en/416612) to find a number of LogitBoost iterations that does not [overfit](wikipedia://en/173332) the training data. A faster version has been proposed that uses the [Akaike information criterion](wikipedia://en/690512) to control LogitBoost stopping.[^o4]
