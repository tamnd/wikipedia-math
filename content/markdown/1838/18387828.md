# Semantic mapping (statistics)

::: {#o1 .subject cue=lead name="Semantic mapping"}

**Semantic mapping** (**SM**) is a [statistical](wikipedia://en/26703) method for [dimensionality reduction](wikipedia://en/579867) (the transformation of data from a high-dimensional space into a low-dimensional space). SM can be used in a set of multidimensional vectors of features to extract a few new features that preserves the main data characteristics.

:::

SM performs dimensionality reduction by [clustering](wikipedia://en/669675) the original features in semantic clusters and combining features mapped in the same cluster to generate an extracted feature. Given a [data set](wikipedia://en/8495), this method constructs a [projection matrix](wikipedia://en/15180479) that can be used to map a [data element](https://en.wikipedia.org/wiki/Data_element) from a [high-dimensional space](https://en.wikipedia.org/wiki/High-dimensional_space) into a reduced dimensional space.

SM can be applied in construction of [text mining](wikipedia://en/318439) and [information retrieval](https://en.wikipedia.org/wiki/Information_retrieval) systems, as well as systems managing [vectors](wikipedia://en/32533) of high dimensionality. **SM** is an alternative to [random mapping](https://en.wikipedia.org/wiki/Random_mapping), [principal components analysis](https://en.wikipedia.org/wiki/Principal_components_analysis) and [latent semantic indexing](https://en.wikipedia.org/wiki/Latent_semantic_indexing) methods.
