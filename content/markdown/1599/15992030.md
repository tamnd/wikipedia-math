# Gregory number

::: {#o1 .subject cue=lead name="Gregory number"}

In [mathematics](wikipedia://en/18831), a **Gregory number**, named after [James Gregory](https://en.wikipedia.org/wiki/James_Gregory_%28astronomer_and_mathematician%29), is a [real number](wikipedia://en/20646438) of the form:[^o2]

:::

$$G_x = \sum_{i = 0}^\infty (-1)^i \frac{1}{(2i + 1)x^{2i + 1}}$$

where *x* is any rational number greater or equal to 1. Considering the [power series](wikipedia://en/59958) expansion for [arctangent](https://en.wikipedia.org/wiki/Arctangent), we have

$$G_x = \arctan\frac{1}{x}.$$

Setting *x* = 1 gives the well-known [Leibniz formula for pi](https://en.wikipedia.org/wiki/Leibniz_formula_for_pi). Thus, in particular,

$$\frac{\pi}{4}=\arctan 1$$

is a Gregory number.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- $$G_{-x}=-(G_x)$$
- $$\tan(G_x)= \frac{1}{x}$$

:::
