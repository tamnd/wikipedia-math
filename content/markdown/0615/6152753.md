# Landau set

::: {#o1 .subject cue=lead name="Landau set"}

In the study of [electoral systems](https://en.wikipedia.org/wiki/Voting_system), the **uncovered set** (also called the **Landau set** or the **[Fishburn](https://en.wikipedia.org/wiki/Peter_Fishburn) set**) is a set of candidates that generalizes the notion of a [Condorcet winner](https://en.wikipedia.org/wiki/Condorcet_winner_criterion) whenever there is a [Condorcet paradox](wikipedia://en/32718).[^o2] The Landau set can be thought of as the [Pareto frontier](https://en.wikipedia.org/wiki/Pareto_front) for a set of candidates, when the frontier is determined by pairwise victories.[^o3]

:::

The Landau set is a nonempty subset of the [Smith set](https://en.wikipedia.org/wiki/Smith_set). It was first discovered by Nicholas Miller.[^o3]

The Landau set consists of all *undominated* or *uncovered* candidates*.* One candidate (the *Fishburn winner*) is said to *cover* another (the *Fishburn loser*) if they would win any matchup the Fishburn loser would win. Thus, the Fishburn winner has all the pairwise victories of the Fishburn loser, and also at least one other pairwise victory.
