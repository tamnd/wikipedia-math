# Grothendieck trace theorem

::: {#o1 .subject cue=lead name="Grothendieck trace theorem"}

In [functional analysis](wikipedia://en/11180), the **Grothendieck trace theorem** is an extension of [Lidskii's theorem](wikipedia://en/192266#Lidskii's_theorem) about the [trace](wikipedia://en/43270) and the [determinant](wikipedia://en/8468) of a certain class of [nuclear operators](wikipedia://en/63684284) on [Banach spaces](wikipedia://en/3989), the so-called **$\tfrac{2}{3}$-nuclear operators**.[^o2] The theorem was proven in 1955 by [Alexander Grothendieck](wikipedia://en/2042).[^o3] Lidskii's theorem does not hold in general for Banach spaces.

:::

The theorem should not be confused with the [Grothendieck trace formula](wikipedia://en/37680847) from [algebraic geometry](wikipedia://en/1997).

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Grothendieck trace theorem"}

## Grothendieck trace theorem {#Grothendieck_trace_theorem}

Given a Banach space $(B,\|\cdot\|)$ with the [approximation property](wikipedia://en/628962) and denote its [dual](wikipedia://en/7988) as $B'$.

### 2/3-nuclear operators {#2/3-nuclear_operators}

Let $A$ be a [nuclear operator](wikipedia://en/63684284) on $B$, then $A$ is a *$\tfrac{2}{3}$-nuclear operator* if it has a decomposition of the form

$$A = \sum\limits_{k=1}^{\infty}\varphi_k \otimes f_k$$

where $\varphi_k \in B$ and $f_k \in B'$ and

$$\sum\limits_{k=1}^{\infty}\|\varphi_k\|^{2/3} \|f_k\|^{2/3} < \infty.$$

::: {#o8 .statement kind=statement/theorem cue=named-heading name="Grothendieck's trace theorem"}

### Grothendieck's trace theorem {#Grothendieck's_trace_theorem}

Let $\lambda_j(A)$ denote the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of a *$\tfrac{2}{3}$-nuclear operator* $A$ counted with their algebraic multiplicities. If

$$\sum\limits_j |\lambda_j(A)| < \infty$$

then the following equalities hold:

$$\operatorname{tr}A = \sum\limits_j |\lambda_j(A)|$$

and for the [Fredholm determinant](wikipedia://en/2685562)

$$\operatorname{det}(I+A) = \prod\limits_j (1+\lambda_j(A)).$$
