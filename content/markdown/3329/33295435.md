# Slater's condition

::: {#o1 .subject cue=lead name="Slater's condition"}

In [mathematics](wikipedia://en/18831), **Slater's condition** (or **Slater condition**) is a [sufficient condition](https://en.wikipedia.org/wiki/Sufficient_condition) for [strong duality](wikipedia://en/34390810) to hold for a [convex optimization problem](wikipedia://en/1674411), named after Morton L. Slater.[^o2] Informally, Slater's condition states that the [feasible region](wikipedia://en/9157119) must have an [interior point](wikipedia://en/55610) (see technical details below).

:::

Slater's condition is a specific example of a [constraint qualification](https://en.wikipedia.org/wiki/Constraint_qualification).[^o3] In particular, if Slater's condition holds for the [primal problem](https://en.wikipedia.org/wiki/Primal_problem), then the [duality gap](wikipedia://en/33328430) is zero, and if the dual value is finite then it is attained.

::: {#o5 .definition cue=heading name="Formulation"}

## Formulation {#Formulation}

Let $f_1,\ldots,f_m$ be real-valued functions on some subset $D$ of $\mathbb{R}^n$. We say that the functions satisfy the **Slater condition** if there exists some $x$ in the [relative interior](wikipedia://en/8612907) of $D$, for which $f_i(x) < 0$ for all $i$ in $1,\ldots,m$. We say that the functions satisfy the **relaxed Slater condition** if:[^o6]

- Some $k$ functions (say $f_1,\ldots,f_k$) are [affine](https://en.wikipedia.org/wiki/Affine_function);
- There exists $x \in \operatorname{relint} D$ such that $f_i(x) \le 0$ for all $i=1,\ldots,k$, and $f_i(x) < 0$ for all $i=k+1,\ldots,m$.

:::

## Application to convex optimization {#Application_to_convex_optimization}

Consider the [optimization problem](wikipedia://en/52033)

$$\text{Minimize }\; f_0(x)$$

$$\text{subject to: }\$$

$$f_i(x) \le 0 , i = 1,\ldots,m$$

$$Ax = b$$

where $f_0,\ldots,f_m$ are [convex functions](wikipedia://en/245568). This is an instance of [convex programming](wikipedia://en/1674411). Slater's condition for convex programming states that there exists an $x^*$ that is strictly [feasible](wikipedia://en/9157119#Candidate_solution), that is, all *m* constraints are satisfied, and the nonlinear constraints are satisfied with strict inequalities.

If a convex program satisfies Slater's condition (or relaxed condition), and it is bounded from below, then [strong duality](wikipedia://en/34390810) holds. Mathematically, this states that strong duality holds if there exists an $x^* \in \operatorname{relint}(D)$ (where relint denotes the [relative interior](wikipedia://en/8612907) of the convex set $D := \cap_{i = 0}^m \operatorname{dom}(f_i)$) such that

$f_i(x^*) < 0, i = 1,\ldots,m,$ (the convex, nonlinear constraints)

$Ax^* = b.\,$[^o8]

## Generalized Inequalities {#Generalized_Inequalities}

Given the problem

$$\text{Minimize }\; f_0(x)$$

$$\text{subject to: }\$$

$$f_i(x) \le_{K_i} 0 , i = 1,\ldots,m$$

$$Ax = b$$

where $f_0$ is convex and $f_i$ is $K_i$-convex for each $i$. Then Slater's condition says that if there exists an $x^* \in \operatorname{relint}(D)$ such that

$f_i(x^*) <_{K_i} 0, i = 1,\ldots,m$ and

$$Ax^* = b$$

then strong duality holds.[^o8]
