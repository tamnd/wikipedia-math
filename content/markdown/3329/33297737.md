# Radial set

::: {#o1 .subject cue=lead name="Radial set"}

In [mathematics](wikipedia://en/18831), a subset $A \subseteq X$ of a [linear space](https://en.wikipedia.org/wiki/Linear_space) $X$ is **radial** at a given point $a_0 \in A$ if for every $x \in X$ there exists a real $t_x > 0$ such that for every $t \in [0, t_x],$ $a_0 + t x \in A.$[^n1] Geometrically, this means $A$ is radial at $a_0$ if for every $x \in X,$ there is some (non-degenerate) line segment (depend on $x$) emanating from $a_0$ in the direction of $x$ that lies entirely in $A.$

:::

## Relation to the algebraic interior {#Relation_to_the_algebraic_interior}

The points at which a set is radial are called internal points.[^n2][^o5] The set of all points at which $A \subseteq X$ is radial is equal to the [algebraic interior](wikipedia://en/30823252).[^n1][^o7]

## Relation to absorbing sets {#Relation_to_absorbing_sets}

Every [absorbing subset](wikipedia://en/1728179) is radial at the origin $a_0 = 0,$ and if the vector space is real then the converse also holds. That is, a subset of a real vector space is [absorbing](wikipedia://en/1728179) if and only if it is radial at the origin. Some authors use the term *radial* as a synonym for *[absorbing](wikipedia://en/1728179)*.[^n3]
