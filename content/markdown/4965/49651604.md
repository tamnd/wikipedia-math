# Subterminal object

::: {#o1 .subject cue=lead name="Subterminal object"}

In [category theory](wikipedia://en/5869), a branch of mathematics, a **subterminal object** is an object *X* of a [category](wikipedia://en/53759) *C* with the property that every object of *C* has at most one [morphism](wikipedia://en/27716891) into *X*.[^o2] If *X* is subterminal, then the pair of identity morphisms (1<sub>*X*</sub>, 1<sub>*X*</sub>) makes *X* into the [product](wikipedia://en/237868) of *X* and *X*. If *C* has a [terminal object](https://en.wikipedia.org/wiki/Terminal_object) 1, then an object *X* is subterminal if and only if it is a [subobject](wikipedia://en/540476) of 1, hence the name.[^o3] The category of categories with subterminal objects and [functors](wikipedia://en/10987) preserving them is not [accessible](wikipedia://en/15311782).[^o4]

:::
