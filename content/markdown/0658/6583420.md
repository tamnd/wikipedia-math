# Adapted process

::: {#o1 .subject cue=lead name="Adapted process"}

In the study of [stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes), a stochastic process is **adapted** (also referred to as a **non-anticipating** or **non-anticipative process**) if information about the value of the process at a given time is available at that same time. An informal interpretation[^o2] is that *X* is adapted if and only if, for every realisation and every *n*, *X<sub>n</sub>* is known at time *n*. The concept of an adapted process is essential, for instance, in the definition of the [Itō integral](https://en.wikipedia.org/wiki/Itō_integral), which only makes sense if the [integrand](https://en.wikipedia.org/wiki/Integrand) is an adapted process.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let

- $(\Omega, \mathcal{F}, \mathbb{P})$ be a [probability space](wikipedia://en/43325);
- $I$ be an index set with a total order $\leq$ (often, $I$ is $\mathbb{N}$, $\mathbb{N}_0$, $[0, T]$ or $[0, +\infty)$);
- $\left(\mathcal{F}_i\right)_{i \in I}$ be a [filtration](wikipedia://en/57854817) of the [sigma algebra](https://en.wikipedia.org/wiki/Sigma_algebra) $\mathcal{F}$;
- $(S,\Sigma)$ be a [measurable space](wikipedia://en/43333), the *state space*;
- $X_i: I \times \Omega \to S$ be a [stochastic process](wikipedia://en/47895).

The stochastic process $(X_i)_{i\in I}$ is said to be **adapted to the filtration** $\left(\mathcal{F}_i\right)_{i \in I}$ if the [random variable](wikipedia://en/25685) $X_i: \Omega \to S$ is a $(\mathcal{F}_i, \Sigma)$-[measurable function](wikipedia://en/44055) for each $i \in I$.[^o5]

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

Consider a stochastic process *X* : \[0, *T*\] × Ω → **R**, and equip the [real line](https://en.wikipedia.org/wiki/Real_line) **R** with its usual [Borel sigma algebra](https://en.wikipedia.org/wiki/Borel_sigma_algebra) generated by the [open sets](https://en.wikipedia.org/wiki/Open_sets).

- If we take the [natural filtration](wikipedia://en/5864648) *F*<sub>•</sub><sup>*X*</sup>, where *F*<sub>*t*</sub><sup>*X*</sup> is the *σ*-algebra generated by the pre-images *X*<sub>*s*</sub><sup>−1</sup>(*B*) for Borel subsets *B* of **R** and times 0 ≤ *s* ≤ *t*, then *X* is automatically *F*<sub>•</sub><sup>*X*</sup>-adapted. Intuitively, the natural filtration *F*<sub>•</sub><sup>*X*</sup> contains "total information" about the behaviour of *X* up to time *t*.
- This offers a simple example of a non-adapted process *X* : \[0, 2\] × Ω → **R**: set *F*<sub>*t*</sub> to be the trivial *σ*-algebra {∅, Ω} for times 0 ≤ *t* \< 1, and *F*<sub>*t*</sub> = *F*<sub>*t*</sub><sup>*X*</sup> for times 1 ≤ *t* ≤ 2. Since the only way that a function can be measurable with respect to the trivial *σ*-algebra is to be constant, any process *X* that is non-constant on \[0, 1\] will fail to be *F*<sub>•</sub>-adapted. The non-constant nature of such a process "uses information" from the more refined "future" *σ*-algebras *F*<sub>*t*</sub>, 1 ≤ *t* ≤ 2.

:::
