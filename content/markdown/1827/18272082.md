# Residuated mapping

::: {#o1 .subject cue=lead name="Residuated mapping"}

In mathematics, the concept of a **residuated mapping** arises in the theory of [partially ordered sets](wikipedia://en/23572). It refines the concept of a [monotone function](wikipedia://en/48260).

:::

If *A*, *B* are [posets](https://en.wikipedia.org/wiki/Partially_ordered_sets), a function *f*: *A* → *B* is defined to be monotone if it is order-preserving: that is, if *x* ≤ *y* implies *f*(*x*) ≤ *f*(*y*). This is equivalent to the condition that the [preimage](https://en.wikipedia.org/wiki/Preimage) under *f* of every [down-set](https://en.wikipedia.org/wiki/Down-set) of *B* is a down-set of *A*. We define a [principal down-set](https://en.wikipedia.org/wiki/Principal_down-set) to be one of the form ↓{*b*} = { *b*' ∈ *B* : *b*' ≤ *b* }. In general the preimage under *f* of a principal down-set need not be a principal down-set. If all of them are, *f* is called **residuated**.

The notion of a residuated map can be generalized to a [binary operator](https://en.wikipedia.org/wiki/Binary_operator) (or any higher [arity](wikipedia://en/42301)) via component-wise residuation. This approach gives rise to notions of left and right division in a partially ordered [magma](wikipedia://en/141916), additionally endowing it with a [quasigroup](wikipedia://en/25223) structure. (One speaks only of residuated algebra for higher arities). A binary (or higher arity) residuated map is usually *not* residuated as a unary map.[^o2]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

If *A*, *B* are posets, a function *f*: *A* → *B* is **residuated** if and only if the preimage under *f* of every principal down-set of *B* is a principal down-set of *A*.

:::

## Consequences {#Consequences}

If *B* is a poset, the set of functions *A* → *B* can be ordered by the [pointwise order](https://en.wikipedia.org/wiki/Pointwise_order) *f* ≤ *g* ↔ (∀*x* ∈ A) *f*(*x*) ≤ *g*(*x*).

It can be shown that a monotone function *f* is residuated if and only if there exists a (necessarily unique) monotone function *f*<sup>\+</sup>: *B* → *A* such that *f* o *f*<sup>\+</sup> ≤ id<sub>B</sub> and *f*<sup>\+</sup> o *f* ≥ id<sub>A</sub>, where id is the [identity function](wikipedia://en/15069). The function *f*<sup>\+</sup> is the **residual** of *f*. A residuated function and its residual form a [Galois connection](wikipedia://en/156411) under the (more recent) monotone definition of that concept, and for every (monotone) Galois connection the lower adjoint is residuated with the residual being the upper adjoint.[^o6] Therefore, the notions of monotone Galois connection and residuated mapping essentially coincide.

Additionally, we have *f*<sup>\-1</sup>(↓{*b*}) = ↓{*f*<sup>\+</sup>(*b*)}.

If *B*° denotes the [dual order](wikipedia://en/600618) (opposite poset) to *B* then *f* : *A* → *B* is a residuated mapping if and only if there exists an *f*<sup>\*</sup> such that *f* : *A* → *B*° and *f*<sup>\*</sup>: *B*° → *A* form a [Galois connection](wikipedia://en/156411) under the original [antitone](https://en.wikipedia.org/wiki/Antitone) definition of this notion.

If *f* : *A* → *B* and *g* : *B* → *C* are residuated mappings, then so is the [function composition](wikipedia://en/195947) *gf* : *A* → *C*, with residual (*gf*)<sup>\+</sup> = *f*<sup>\+</sup>*g*<sup>\+</sup>. The antitone Galois connections do not share this property.

The set of monotone transformations (functions) over a poset is an [ordered monoid](https://en.wikipedia.org/wiki/Ordered_monoid) with the pointwise order, and so is the set of residuated transformations.[^o7]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [ceiling function](https://en.wikipedia.org/wiki/Ceiling_function) $x \mapsto \lceil x \rceil$ from **R** to **Z** (with the usual order in each case) is residuated, with residual mapping the natural embedding of **Z** into **R**.
- The embedding of **Z** into **R** is also residuated. Its residual is the [floor function](https://en.wikipedia.org/wiki/Floor_function) $x \mapsto \lfloor x \rfloor$.

:::

## Residuated binary operators {#Residuated_binary_operators}

If • : *P* × *Q* → *R* is a binary map and *P*, *Q*, and *R* are posets, then one may define residuation component-wise for the left and right translations, i.e. multiplication by a fixed element. For an element *x* in *P* define *<sub>x</sub>λ*(*y*) = *x* • *y*, and for *x* in *Q* define *λ<sub>x</sub>*(*y*) = *y* • *x*. Then • is said to be residuated if and only if *<sub>x</sub>λ* and *λ<sub>x</sub>* are residuated for all *x* (in *P* and respectively *Q*). Left (and respectively right) division are defined by taking the residuals of the left (and respectively right) translations: *x*\\*y* = (*<sub>x</sub>λ*)<sup>\+</sup>(*y*) and *x*/*y* = (*λ<sub>x</sub>*)<sup>\+</sup>(*y*)

For example, every [ordered group](https://en.wikipedia.org/wiki/Ordered_group) is residuated, and the division defined by the above coincides with notion of [division in a group](wikipedia://en/19447#Division). A less trivial example is the set Mat<sub>*n*</sub>(***B***) of [square matrices](https://en.wikipedia.org/wiki/Square_matrices) over a [boolean algebra](wikipedia://en/3959) ***B***, where the matrices are ordered [pointwise](wikipedia://en/4786797). The pointwise order endows Mat<sub>*n*</sub>(***B***) with pointwise meets, joins and complements. [Matrix multiplication](wikipedia://en/125280) is defined in the usual manner with the "product" being a meet, and the "sum" a join. It can be shown[^o11] that $X\backslash Y = (Y^{t}X')'$ and $X/Y = (X'Y^{t})'$, where *X ′* is the complement of *X*, and *Y* <sup>t</sup> is the [transposed matrix](https://en.wikipedia.org/wiki/Transposed_matrix)).
