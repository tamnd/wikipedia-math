# I-spline

::: {#o1 .subject cue=lead name="I-spline"}

In the [mathematical](wikipedia://en/18831) subfield of [numerical analysis](wikipedia://en/21506), an **I-spline**[^o2][^o3] is a [monotone](wikipedia://en/48260) [spline](wikipedia://en/457680) function.

:::

*Image: Ispline order3.svg.* An *I-spline* family of order three with four interior knots.

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

A family of *I-spline* functions of degree *k* with *n* free parameters is defined in terms of the [M-splines](wikipedia://en/23124209) *M*<sub>*i*</sub>(*x*|*k*, *t*)

$$I_i(x|k,t) = \int_L^x M_i(u|k,t)du,$$

where *L* is the lower limit of the domain of the splines.

Since M-splines are non-negative, *I-splines* are monotonically non-decreasing.

:::

::: {#o7 .definition kind=definition/construction cue=heading name="Computation"}

## Computation {#Computation}

Let *j* be the index such that *t*<sub>*j*</sub> ≤ *x* \< *t*<sub>*j*+1</sub>. Then *I*<sub>*i*</sub>(*x*|*k*, *t*) is zero if *i* > *j*, and equals one if *j* − *k* + 1 > *i*. Otherwise,

$$I_i(x|k,t) = \sum_{m=i}^j (t_{m+k+1}-t_m)M_m(x|k+1,t)/(k+1).$$

:::

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

*I-splines* can be used as basis splines for regression analysis and [data transformation](wikipedia://en/10056274) when monotonicity is desired (constraining the regression coefficients to be non-negative for a non-decreasing fit, and non-positive for a non-increasing fit).

:::
