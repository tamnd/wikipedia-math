# M-spline

::: {#o1 .subject cue=lead name="M-spline"}

In the [mathematical](wikipedia://en/18831) subfield of [numerical analysis](wikipedia://en/21506), an **M-spline**[^o2][^o3] is a non-negative [spline](wikipedia://en/457680) function.

:::

*Image: Mspline order3.svg.* An *M-spline* family of order three with four interior knots.

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

A family of *M-spline* functions of order *k* with *n* free parameters is defined by a set of knots *t*<sub>1</sub> ≤ *t*<sub>2</sub> ≤ ... ≤ *t*<sub>*n*+*k*</sub> such that

- *t*<sub>1</sub> = ... = *t*<sub>*k*</sub>
- *t*<sub>*n*+1</sub> = ... = *t*<sub>*n*+*k*</sub>
- *t*<sub>*i*</sub> \< *t*<sub>*i*+*k*</sub> for all *i*

The family includes *n* members indexed by *i* = 1,...,*n*.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

An *M-spline* *M*<sub>*i*</sub>(*x*|*k*, *t*) has the following mathematical properties

- *M*<sub>*i*</sub>(*x*|*k*, *t*) is non-negative
- *M*<sub>*i*</sub>(*x*|*k*, *t*) is zero unless *t*<sub>*i*</sub> ≤ *x* \< *t*<sub>*i*+*k*</sub>
- *M*<sub>*i*</sub>(*x*|*k*, *t*) has *k* − 2 continuous derivatives at interior knots *t*<sub>*k*+1</sub>, ..., *t*<sub>*n*−1</sub>
- *M*<sub>*i*</sub>(*x*|*k*, *t*) integrates to 1

:::

::: {#o9 .definition kind=definition/construction cue=heading name="Computation"}

## Computation {#Computation}

*M-splines* can be efficiently and stably computed using the following recursions:

For *k* = 1,

$$M_i(x|1,t) = \frac{1}{t_{i+1}-t_i}$$

if *t*<sub>*i*</sub> ≤ *x* \< *t*<sub>*i*+1</sub>, and *M*<sub>*i*</sub>(*x*|1,*t*) = 0 otherwise.

For *k* > 1,

$$M_i(x|k,t) = \frac{k\left[(x-t_i)M_i(x|k-1,t) + (t_{i+k}-x)M_{i+1}(x|k-1,t)\right]}{(k-1)(t_{i+k}-t_i)}.$$

:::

::: {#o11 .application cue=heading name="Applications"}

## Applications {#Applications}

*M-splines* can be integrated to produce a family of monotone splines called [I-splines](wikipedia://en/23124520). *M-splines* can also be used directly as basis splines for regression analysis involving positive response data (constraining the regression coefficients to be non-negative).

:::
