# Base36

::: {#o1 .subject cue=lead name="Base36"}

**Base36** is a [binary-to-text encoding](https://en.wikipedia.org/wiki/Binary-to-text_encoding) that represents [binary data](https://en.wikipedia.org/wiki/Binary_data) in an [ASCII](https://en.wikipedia.org/wiki/ASCII) string format by translating it into a [radix](wikipedia://en/701207)-36 representation. The choice of 36 is convenient in that the digits can be represented using the [numerals](wikipedia://en/1786) 0–9 and the [letters](https://en.wikipedia.org/wiki/Latin_alphabet) a-z[^o2] (the lowercase [ISO basic Latin alphabet](https://en.wikipedia.org/wiki/ISO_basic_Latin_alphabet)).

:::

Each Base36 digit contains log<sub>2</sub>(36) ≈ 5.17 bits of information, so six bits is sufficient to represent each digit. Base36 numbers can also be expanded to pairs of [senary](wikipedia://en/29652) (base 6) digits.

## Conversion {#Conversion}

Signed [32](https://en.wikipedia.org/wiki/32-bit_computing)- and [64](https://en.wikipedia.org/wiki/64-bit_computing)-[bit](wikipedia://en/264399) [integers](wikipedia://en/14563) will only hold at most 6 or 13 base-36 digits, respectively (that many base-36 digits can overflow the 32- and 64-bit integers). For example, the 64-bit signed integer maximum value of "[9223372036854775807](https://en.wikipedia.org/wiki/9223372036854775807)" is "1Y2P0IJ32E8E7" in base-36. Similarly, the 32-bit signed integer maximum value of "[2147483647](https://en.wikipedia.org/wiki/2147483647)" is "ZIK0ZJ" in base-36.

### Standard implementations {#Standard_implementations}

[The C standard library](https://en.wikipedia.org/wiki/The_C_standard_library) since C89 supports base36 numbers via the strtol and strtoul functions[^o5]

In the [Common Lisp](https://en.wikipedia.org/wiki/Common_Lisp) standard (ANSI INCITS 226-1994), functions like `parse-integer` support a radix of 2 to 36.[^o6]

[Java SE](https://en.wikipedia.org/wiki/Java_SE) supports conversion from/to String to different bases from 2 up to 36. For example, <https://docs.oracle.com/javase/8/docs/api/java/lang/Character.html#digit-char-int-> and <https://docs.oracle.com/javase/8/docs/api/java/math/BigInteger.html#BigInteger-java.lang.String-int->

Just like [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29), [JavaScript](https://en.wikipedia.org/wiki/JavaScript) also supports conversion from/to String to different bases from 2 up to 36. <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/toString>

[PHP](https://en.wikipedia.org/wiki/PHP), like Java, supports conversion from/to String to different bases from 2 up to 36 using the [base\_convert](https://secure.php.net/manual/en/function.base-convert.php) function, available since PHP 4.

[Go](https://en.wikipedia.org/wiki/Go_%28programming_language%29) supports conversion to string to different bases from 2 up to 36 using the built-in `strconv.FormatInt()`, and `strconv.FormatUint()` functions,[^o7][^o8] and conversions from string encoded in different bases from 2 up to 36 using the built-in `strconv.ParseInt()`, and `strconv.ParseUint()` functions.[^o9][^o10]

[Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) allows conversions of strings from base 2 to base 36.[^o11]

[Raku](https://en.wikipedia.org/wiki/Raku_%28programming_language%29) supports base2 to base36 for all its real numeric types with its builtins: `base`[^o12] and `parse-base`.[^o13]
