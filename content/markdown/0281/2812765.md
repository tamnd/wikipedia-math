# Seemingly unrelated regressions

::: {#o1 .subject cue=lead name="Seemingly unrelated regressions"}

In [econometrics](wikipedia://en/10390), the **seemingly unrelated regressions** (**SUR**)[^o2][^o3][^o4] or **seemingly unrelated regression equations** (**SURE**)[^o5][^o6] model, proposed by [Arnold Zellner](https://en.wikipedia.org/wiki/Arnold_Zellner) in (1962), is a generalization of a [linear regression model](https://en.wikipedia.org/wiki/Linear_regression_model) that consists of several regression equations, each having its own dependent variable and potentially different sets of exogenous explanatory variables. Each equation is a valid linear regression on its own and can be estimated separately, which is why the system is called *seemingly unrelated*,[^o4] although some authors suggest that the term *seemingly related* would be more appropriate,[^o2] since the [error terms](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) are assumed to be correlated across the equations.

:::

The model can be estimated equation-by-equation using standard [ordinary least squares](wikipedia://en/1651906) (OLS). Such estimates are [consistent](wikipedia://en/1497569), however generally not as [efficient](wikipedia://en/27250866) as the SUR method, which amounts to [feasible generalized least squares](https://en.wikipedia.org/wiki/Feasible_generalized_least_squares) with a specific form of the variance-covariance matrix. Two important cases when SUR is in fact equivalent to OLS are when the error terms are in fact uncorrelated between the equations (so that they are truly unrelated) and when each equation contains exactly the same set of regressors on the right-hand-side.

The SUR model can be viewed as either the simplification of the [general linear model](wikipedia://en/877698) where certain coefficients in matrix $\mathrm{B}$ are restricted to be equal to zero, or as the generalization of the [general linear model](wikipedia://en/877698) where the regressors on the right-hand-side are allowed to be different in each equation. The SUR model can be further generalized into the [simultaneous equations model](wikipedia://en/250436), where the right-hand side regressors are allowed to be the endogenous variables as well.

## The model {#The_model}

Suppose there are *m* regression equations

$$y_{ir} = x_{ir}^\mathsf{T}\;\!\beta_i + \varepsilon_{ir}, \quad i=1,\ldots,m.$$

Here *i* represents the equation number, *r* = 1, …, *R* is the individual observation, and we are taking the transpose of the $x_{ir}$ column vector. The number of observations *R* is assumed to be large, so that in the analysis we take *R* → $\infty$, whereas the number of equations *m* remains fixed.

Each equation *i* has a single response variable *y*<sub>*ir*</sub>, and a *k*<sub>*i*</sub>-dimensional vector of regressors *x*<sub>*ir*</sub>. If we stack observations corresponding to the *i*-th equation into *R*-dimensional vectors and matrices, then the model can be written in vector form as

$$y_i = X_i\beta_i + \varepsilon_i, \quad i=1,\ldots,m,$$

where *y*<sub>*i*</sub> and *ε*<sub>*i*</sub> are *R*×1 vectors, *X*<sub>*i*</sub> is a *R*×*k*<sub>*i*</sub> matrix, and *β*<sub>*i*</sub> is a *k*<sub>*i*</sub>×1 vector.

Finally, if we stack these *m* vector equations on top of each other, the system will take the form [^o5]

::: {#o8 .equation cue=numblk name="1"}

$$\begin{pmatrix}y_1 \\ y_2 \\ \vdots \\ y_m \end{pmatrix} = \begin{pmatrix}X_1&0&\ldots&0 \\ 0&X_2&\ldots&0 \\ \vdots&\vdots&\ddots&\vdots \\ 0&0&\ldots&X_m \end{pmatrix} \begin{pmatrix}\beta_1 \\ \beta_2 \\ \vdots \\ \beta_m \end{pmatrix} + \begin{pmatrix}\varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_m \end{pmatrix} = X\beta + \varepsilon\,. \tag{1}$$

:::

The assumption of the model is that error terms *ε*<sub>*ir*</sub> are independent across observations, but may have cross-equation correlations within observations. Thus, we assume that E\[ *ε<sub>ir</sub> ε<sub>is</sub>* | *X* \] = 0 whenever *r ≠ s*, whereas E\[ *ε*<sub>*ir*</sub> *ε*<sub>*jr*</sub> | *X* \] = *σ<sub>ij</sub>*. Denoting Σ = \[*σ*<sub>*ij*</sub>\] the *m×m* skedasticity matrix of each observation, the covariance matrix of the stacked error terms *ε* will be equal to [^o5][^o4]

$$\Omega \equiv \operatorname{E}[\,\varepsilon\varepsilon^\mathsf{T}\,|X\,] = \Sigma \otimes I_R,$$

where *I*<sub>*R*</sub> is the *R*-dimensional [identity matrix](wikipedia://en/59718) and ⊗ denotes the matrix [Kronecker product](wikipedia://en/712430).

## Estimation {#Estimation}

The SUR model is usually estimated using the [feasible generalized least squares](https://en.wikipedia.org/wiki/Feasible_generalized_least_squares) (FGLS) method. This is a two-step method where in the first step we run [ordinary least squares](wikipedia://en/1651906) regression for ((1)). The residuals from this regression are used to estimate the elements of matrix $\Sigma$:[^o14]

$$\hat\sigma_{ij} = \frac1R\, \hat\varepsilon_i^\mathsf{T} \hat\varepsilon_j .$$

In the second step we run [generalized least squares](wikipedia://en/4504135) regression for ((1)) using the variance matrix $\scriptstyle\hat\Omega\;=\;\hat\Sigma\,\otimes\,I_R$:

$$\hat\beta = \Big( X^\mathsf{T}(\hat\Sigma^{-1}\otimes I_R) X \Big)^{\!-1} X^\mathsf{T}(\hat\Sigma^{-1}\otimes I_R)\,y .$$

This estimator is [unbiased](wikipedia://en/8450479) in small samples assuming the error terms *ε<sub>ir</sub>* have symmetric distribution; in large samples it is [consistent](wikipedia://en/1497569) and [asymptotically normal](wikipedia://en/3001287) with limiting distribution[^o14]

$$\sqrt{R}(\hat\beta - \beta) \ \xrightarrow{d}\ \mathcal{N}\Big(\,0,\; \Big(\tfrac1R X^\mathsf{T}(\Sigma^{-1}\otimes I_R) X \Big)^{\!-1}\,\Big) .$$

Other estimation techniques besides FGLS were suggested for SUR model:[^o10] the [maximum likelihood (ML)](wikipedia://en/140806) method under the assumption that the errors are normally distributed; the iterative generalized least squares (IGLS), where the residuals from the second step of FGLS are used to recalculate the matrix $\scriptstyle\hat\Sigma$, then estimate $\scriptstyle\hat\beta$ again using GLS, and so on, until convergence is achieved; the iterative ordinary least squares (IOLS) scheme, where estimation is performed on equation-by-equation basis, but every equation includes as additional regressors the residuals from the previously estimated equations in order to account for the cross-equation correlations, the estimation is run iteratively until convergence is achieved. Kmenta and Gilbert (1968) ran a Monte-Carlo study and established that all three methods—IGLS, IOLS and ML—yield numerically equivalent results, they also found that the asymptotic distribution of these estimators is the same as the distribution of the FGLS estimator, whereas in small samples neither of the estimators was more superior than the others.[^o11] Zellner and Ando (2010) developed a direct [Monte Carlo method](wikipedia://en/56098) for the Bayesian analysis of SUR model.[^o12]

## Equivalence to OLS {#Equivalence_to_OLS}

There are two important cases when the SUR estimates turn out to be equivalent to the equation-by-equation OLS. These cases are:

1. When the matrix Σ is known to be diagonal, that is, there are no cross-equation correlations between the error terms. In this case the system becomes not seemingly but truly unrelated.
1. When each equation contains exactly the same set of regressors, that is *X*<sub>1</sub> = *X*<sub>2</sub> = … = *X<sub>m</sub>*. That the estimates turn out to be numerically identical to OLS estimates follows from [Kruskal's tree theorem](wikipedia://en/3606300),[^o2] or can be shown via the direct calculation.[^o14]

## Statistical packages {#Statistical_packages}

- In [R](wikipedia://en/376707), SUR can be estimated using the package “systemfit”.[^o16][^o17][^o18][^o19]
- In [SAS](wikipedia://en/990677), SUR can be estimated using the `syslin` procedure.[^o20]
- In [Stata](wikipedia://en/1809002), SUR can be estimated using the `sureg` and `suest` commands.[^o21][^o22][^o23]
- In [Limdep](https://en.wikipedia.org/wiki/Limdep), SUR can be estimated using the `sure` command [^o24]
- In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), SUR can be estimated using the command `SUR` in the “linearmodels” package.[^o25]
- In [gretl](wikipedia://en/1166251), SUR can be estimated using the `system` command.
