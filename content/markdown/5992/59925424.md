# Sudoku graph

::: {#o1 .subject cue=lead name="Sudoku graph"}

*Image: 4x4 Sudoku graph.svg.* $4\times 4$ Sudoku graph

In the [mathematics of Sudoku](wikipedia://en/2912292), the **Sudoku graph** is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) whose [vertices](wikipedia://en/638899) represent the cells of a (blank) Sudoku puzzle and whose [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) represent pairs of cells that belong to the same row, column, or block of the puzzle. The problem of solving a Sudoku puzzle can be represented as [precoloring extension](wikipedia://en/54337393) on this graph. It is an [integral](wikipedia://en/24845923) [Cayley graph](wikipedia://en/358277).

:::

## Basic properties and examples {#Basic_properties_and_examples}

*Image: 9x9 Sudoku graph neighbors (really fixed).svg.* Counting neighbors of a cell on a $9\times 9$ Sudoku graph ($n = 3$)

On a Sudoku board of size $n^2\times n^2$, the Sudoku graph has $n^4$ [vertices](wikipedia://en/638899), each with exactly $3n^2-2n-1$ neighbors. Therefore, it is a [regular graph](wikipedia://en/85821). The total number of edges is $n^4(3n^2-2n-1)/2$. For instance, the graph shown in the figure above, for a $4\times 4$ board, has 16 vertices and 56 edges, and is 7-regular. For the most common form of Sudoku, on a $9\times 9$ board, the Sudoku graph is a 20-regular graph with 81 vertices and 810 edges. The second figure shows how to count the neighbors of each cell in a $9\times 9$ board.

## Puzzle solutions and graph coloring {#Puzzle_solutions_and_graph_coloring}

Each row, column, or block of the Sudoku puzzle forms a [clique](wikipedia://en/524466) in the Sudoku graph, whose size equals the number of symbols used to solve the puzzle. A [graph coloring](wikipedia://en/426743) of the Sudoku graph using this number of colors (the minimum possible number of colors for this graph) can be interpreted as a solution to the puzzle. The usual form of a Sudoku puzzle, in which some cells are filled in with symbols and the rest must be filled in by the person solving the puzzle, corresponds to the [precoloring extension](wikipedia://en/54337393) problem on this graph.

## Algebraic properties {#Algebraic_properties}

For any $n$, the Sudoku graph of an $n^2\times n^2$ Sudoku board is an [integral graph](wikipedia://en/24845923), meaning that the [spectrum](wikipedia://en/534914) of its [adjacency matrix](wikipedia://en/244463) consists only of integers. More precisely, its spectrum consists of the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue)

- $3n^2-2n-1$, with multiplicity $1$,
- $2n^2-2n-1$, with multiplicity $2(n-1)$,
- $n^2-n-1$, with multiplicity $2n(n-1)$,
- $n^2-2n-1$, with multiplicity $(n-1)^2$,
- $-1$, with multiplicity $n^2(n-1)^2$, and
- $-n-1$, with multiplicity $2n(n-1)^2$.

It can be represented as a [Cayley graph](wikipedia://en/358277) of the [abelian group](wikipedia://en/2974) $Z_n^4$.

:::

## Related graphs {#Related_graphs}

The Sudoku graph contains as a subgraph the [rook's graph](wikipedia://en/7324959), which is defined in the same way using only the rows and columns (but not the blocks) of the Sudoku board.

The 20-regular 81-vertex Sudoku graph should be distinguished from a different 20-regular graph on 81 vertices, the [Brouwer–Haemers graph](wikipedia://en/28189558), which has smaller cliques (of size 3) and requires fewer colors (7 instead of 9).
