# Besov space

::: {#o1 .subject cue=lead name="Besov space"}

In [mathematics](wikipedia://en/18831), the **Besov space** (named after [Oleg Vladimirovich Besov](https://en.wikipedia.org/wiki/Oleg_Vladimirovich_Besov)) $B^s_{p,q}(\mathbf{R})$ is a [complete](wikipedia://en/7832) [quasinormed](wikipedia://en/6652599) space which is a [Banach space](wikipedia://en/3989) when $1 \le p, q \le \infty$. These spaces, as well as the similarly defined [Triebel–Lizorkin spaces](wikipedia://en/26732419), serve to generalize more elementary [function spaces](wikipedia://en/340630) such as [Sobolev spaces](wikipedia://en/611964) and are effective at measuring regularity properties of functions.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Several equivalent definitions exist. One of them is given below. This definition is quite limited because it does not extend to the range $s \le 0$.

Let

$$\Delta_h f(x) = f(x-h) - f(x)$$

and define the [modulus of continuity](wikipedia://en/964161) by

$$\omega^2_p(f,t) = \sup_{|h| \le t} \left \| \Delta^2_h f \right \|_p$$

Let $n$ be a non-negative integer and define: $s = n + \alpha$ with $0 < \alpha \le 1$. The Besov space $B^s_{p,q}(\mathbf{R})$ contains all functions $f$ such that

$$f \in W^{n, p}(\mathbf{R}), \qquad \int_0^\infty \left|\frac{ \omega^2_p \left ( f^{(n)},t \right ) } {t^{\alpha} }\right|^q \frac{dt}{t} < \infty.$$

:::

## Norm {#Norm}

The Besov space $B^s_{p,q}(\mathbf{R})$ is equipped with the norm

$$\left \|f \right \|_{B^s_{p,q}(\mathbf{R})} = \left( \|f\|_{W^{n, p} (\mathbf{R})}^q + \int_0^\infty \left|\frac{ \omega^2_p \left ( f^{(n)}, t \right ) } {t^{\alpha} }\right|^q \frac{dt}{t} \right)^{\frac{1}{q}}$$

The Besov spaces $B^s_{2,2}(\mathbf{R})$ coincide with the more classical [Sobolev spaces](https://en.wikipedia.org/wiki/Sobolev_spaces) $H^s(\mathbf{R})$.

If $p=q$ and $s$ is not an integer, then $B^s_{p,p}(\mathbf{R}) =\bar W^{s,p}( \mathbf{R})$, where $\bar W^{s,p}( \mathbf{R})$ denotes the [Sobolev–Slobodeckij space](wikipedia://en/611964#Sobolev–Slobodeckij_spaces).
