# 100,000,000,000

::: {#o1 .subject cue=lead name="100,000,000,000"}

**100,000,000,000** (**one hundred billion**) is the natural number following 99,999,999,999 and preceding 100,000,000,001.

:::

In [scientific notation](wikipedia://en/59715), it is written as 10<sup>11</sup>.
