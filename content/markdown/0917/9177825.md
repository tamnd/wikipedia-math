# Dini's theorem

::: {#o1 .subject cue=lead name="Dini's theorem"}

In the [mathematical](wikipedia://en/18831) field of [analysis](wikipedia://en/48396), **Dini's theorem** says that if a monotone sequence of [continuous functions](https://en.wikipedia.org/wiki/Continuous_functions) converges pointwise on a compact space and if the limit function is also continuous, then the convergence is uniform.[^o2] The theorem is named after [Ulisse Dini](https://en.wikipedia.org/wiki/Ulisse_Dini).[^o3]

:::

::: {#o5 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

If $X$ is a [compact](wikipedia://en/6042) [topological space](wikipedia://en/30450), and $(f_n)_{n\in\mathbb{N}}$ is a [monotonically increasing](https://en.wikipedia.org/wiki/Monotonically_increasing) [sequence](wikipedia://en/27838) (meaning $f_n(x)\leq f_{n+1}(x)$ for all $n\in\mathbb{N}$ and $x\in X$) of [continuous](wikipedia://en/6122) [real-valued functions](wikipedia://en/22284647) on $X$ which converges [pointwise](wikipedia://en/340198) to a continuous function $f\colon X\to \mathbb{R}$, then the convergence is [uniform](wikipedia://en/50652). The same conclusion holds if $(f_n)_{n\in\mathbb{N}}$ is monotonically decreasing instead of increasing.

This is one of the few situations in mathematics where pointwise convergence implies uniform convergence; the key is the greater control implied by the monotonicity. The limit function must be continuous, since a uniform limit of continuous functions is necessarily continuous. The continuity of the limit function cannot be inferred from the other hypothesis (consider $x^n$ in $[0,1]$.)

:::

::: {#o7 .proof cue=heading name="Proof"}

## Proof {#Proof}

Let $\varepsilon > 0$ be given. For each $n\in\mathbb{N}$, let $g_n=f-f_n$, and let $E_n$ be the set of those $x\in X$ such that $g_n(x)<\varepsilon$. Each $g_n$ is continuous, and so each $E_n$ is open (because each $E_n$ is the [preimage](https://en.wikipedia.org/wiki/Preimage) of the open set $(-\infty, \varepsilon)$ under $g_n$, a continuous function). Since $(f_n)_{n\in\mathbb{N}}$ is monotonically increasing, $(g_n)_{n\in\mathbb{N}}$ is monotonically decreasing, it follows that the sequence $E_n$ is ascending (i.e. $E_n\subset E_{n+1}$ for all $n\in\mathbb{N}$). Since $(f_n)_{n\in\mathbb{N}}$ converges pointwise to $f$, it follows that the collection $(E_n)_{n\in\mathbb{N}}$ is an [open cover](https://en.wikipedia.org/wiki/Open_cover) of $X$. By compactness, there is a finite subcover, and since $E_n$ are ascending the largest of these is a cover too. Thus we obtain that there is some positive integer $N$ such that $E_N=X$. That is, if $n>N$ and $x$ is a point in $X$, then $|f(x)-f_n(x)|<\varepsilon$, as desired.

:::
