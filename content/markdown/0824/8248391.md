# Dendrite (mathematics)

::: {#o1 .subject cue=lead name="Dendrite"}

In mathematics, a **dendrite** is a certain type of [topological space](wikipedia://en/30450) that may be characterized either as a [locally connected](https://en.wikipedia.org/wiki/Locally_connected) [dendroid](wikipedia://en/8248350) or equivalently as a locally connected [continuum](wikipedia://en/24758520) that contains no simple closed curves.[^o2]

:::

*Image: Dendrite julia.png.* Dendrite Julia set

## Importance {#Importance}

Dendrites may be used to model certain types of [Julia set](wikipedia://en/56434).[^o4] For example, if 0 is pre-periodic, but not periodic, under the function $f(z) = z^2 + c$, then the Julia set of $f$ is a dendrite: connected, without interior.[^o5]
