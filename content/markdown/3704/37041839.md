# Ruelle zeta function

::: {#o1 .subject cue=lead name="Ruelle zeta function"}

In [mathematics](wikipedia://en/18831), the **Ruelle zeta function** is a [zeta function](https://en.wikipedia.org/wiki/Zeta_function) associated with a [dynamical system](wikipedia://en/9087). It is named after mathematical physicist [David Ruelle](https://en.wikipedia.org/wiki/David_Ruelle).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let *f* be a function defined on a [manifold](wikipedia://en/2073470) *M*, such that the set of [fixed points](wikipedia://en/449738) Fix(*f*<sup>*n*</sup>) is finite for all *n* > 1. Further let *φ* be a function on *M* with values in *d* × *d* complex matrices. The zeta function of the first kind is[^o4]

$$\zeta(z) = \exp\left( \sum_{m\ge1} \frac{z^m}{m} \sum_{x\in\operatorname{Fix}(f^m)} \operatorname{Tr} \left( \prod_{k=0}^{m-1} \varphi(f^k(x)) \right) \right)$$

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

In the special case *d* = 1, *φ* = 1, we have[^o4]

$$\zeta(z) = \exp\left( \sum_{m\ge1} \frac{z^m} m \left|\operatorname{Fix}(f^m)\right| \right)$$

which is the [Artin–Mazur zeta function](wikipedia://en/1342156).

The [Ihara zeta function](wikipedia://en/1342362) is an example of a Ruelle zeta function.[^o7]

:::
