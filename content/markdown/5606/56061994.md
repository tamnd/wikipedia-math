# Xuong tree

::: {#o1 .subject cue=lead name="Xuong tree"}

*Image: Xuong tree.svg.* A Xuong tree. Only one component of the non-tree edges (the red component) has an odd number of edges, the minimum possible for this graph.

In [graph theory](wikipedia://en/12401), a **Xuong tree** is a [spanning tree](wikipedia://en/455770) $T$ of a given graph $G$ with the property that, in the remaining graph $G-T$, the number of [connected components](https://en.wikipedia.org/wiki/Connected_component_%28graph_theory%29) with an odd number of edges is as small as possible. They are named after Nguyen Huy Xuong, who used them to characterize the [cellular embeddings](wikipedia://en/8149170) of a given graph having the largest possible [genus](wikipedia://en/61891).

:::

According to Xuong's results, if $T$ is a Xuong tree and the numbers of edges in the components of $G-T$ are $m_1,m_2,\dots, m_k$, then the maximum genus of an embedding of $G$ is $\textstyle\sum_{i=1}^k\lfloor m_i/2\rfloor$. Any one of these components, having $m_i$ edges, can be partitioned into $\lfloor m_i/2\rfloor$ edge-disjoint two-edge paths, with possibly one additional left-over edge. An embedding of maximum genus may be obtained from a planar embedding of the Xuong tree by adding each two-edge path to the embedding in such a way that it increases the genus by one.

A Xuong tree, and a maximum-genus embedding derived from it, may be found in any graph in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), by a transformation to a more general computational problem on [matroids](wikipedia://en/244321), the [matroid parity problem](wikipedia://en/56069479) for [linear matroids](https://en.wikipedia.org/wiki/Linear_matroid).
