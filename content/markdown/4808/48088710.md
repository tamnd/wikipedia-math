# Chordal completion

::: {#o1 .subject cue=lead name="Chordal completion"}

*Image: Chordal completion.svg.* The graph $G$ (excluding red edges) is a subgraph of the chordal graph $H$ (including red edges) which shares the same vertex set, making $H$ a chordal completion of $G$. Removing any of the newly added red edges causes the graph to no longer be chordal, making it a **minimal** chordal completion. There were 9 edges added to $G$ to make $H$, the lowest amount possible for $G$ to become a chordal graph, making it a **minimum** chordal completion.

In [graph theory](wikipedia://en/12401), a branch of mathematics, a **chordal completion** of a given [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) $G$ is a [chordal graph](wikipedia://en/744165), on the same vertex set, that has $G$ as a subgraph. A **minimal chordal completion** is a chordal completion such that any graph formed by removing an edge would no longer be a chordal completion. A **minimum chordal completion** is a chordal completion with as few edges as possible.

:::

A different type of chordal completion, one that minimizes the size of the [maximum clique](https://en.wikipedia.org/wiki/Maximum_clique) in the resulting [chordal graph](wikipedia://en/744165), can be used to define the [treewidth](wikipedia://en/3987086) of $G$. Chordal completions can also be used to characterize several other graph classes including AT-free graphs, [claw-free](wikipedia://en/12415907) AT-free graphs, and [cographs](wikipedia://en/1175666).

The minimum chordal completion was one of twelve computational problems whose complexity was listed as open in the 1979 book *[Computers and Intractability](https://en.wikipedia.org/wiki/Computers_and_Intractability)*. Applications of chordal completion include modeling the problem of minimizing fill-in when performing [Gaussian elimination](wikipedia://en/13035) on [sparse](wikipedia://en/341015) [symmetric matrices](https://en.wikipedia.org/wiki/Symmetric_matrices), and reconstructing [phylogenetic trees](wikipedia://en/149326).

Chordal completions of a graph are sometimes called triangulations,[^o3] but this term is ambiguous even in the context of graph theory, as it can also refer to maximal [planar graphs](wikipedia://en/24314).

## Related graph families {#Related_graph_families}

A graph $G$ is an [AT-free graph](https://en.wikipedia.org/wiki/Asteroidal_triple-free_graph) if and only if all of its minimal chordal completions are [interval graphs](wikipedia://en/363423). $G$ is a [claw-free](wikipedia://en/12415907) AT-free graph if and only if all of its minimal chordal completions are proper interval graphs. And $G$ is a [cograph](wikipedia://en/1175666) if and only if all of its minimal chordal completions are [trivially perfect graphs](wikipedia://en/18033364).[^o3]

A graph $G$ has [treewidth](wikipedia://en/3987086) at most $k$ if and only if $G$ has at least one chordal completion whose [maximum clique](https://en.wikipedia.org/wiki/Maximum_clique) size is at most $k + 1$. It has [pathwidth](wikipedia://en/5133142) at most $k$ if and only if $G$ has at least one chordal completion that is an interval graph with maximum clique size at most $k + 1$. It has [bandwidth](wikipedia://en/27414778) at most $k$ if and only if $G$ has at least one chordal completion that is a proper interval graph with maximum clique size at most $k + 1$.[^o4] And it has [tree-depth](https://en.wikipedia.org/wiki/Tree-depth) $k$ if and only if it has at least one chordal completion that is a trivially perfect graph with maximum clique size at most $k$.[^o5]

## Applications {#Applications}

The original application of chordal completion described in *[Computers and Intractability](https://en.wikipedia.org/wiki/Computers_and_Intractability)* involves [Gaussian elimination](wikipedia://en/13035) for [sparse matrices](wikipedia://en/341015). During the process of Gaussian elimination, one wishes to minimize fill-in, coefficients of the matrix that were initially zero but later become nonzero, because the need to calculate the values of these coefficients slows down the algorithm. The pattern of nonzeros in a sparse [symmetric matrix](wikipedia://en/126474) can be described by an undirected graph (having the matrix as its [adjacency matrix](wikipedia://en/244463)); the pattern of nonzeros in the filled-in matrix is always a chordal graph, any minimal chordal completion corresponds to a fill-in pattern in this way. If a chordal completion of a graph is given, a sequence of steps in which to perform Gaussian elimination to achieve this fill-in pattern can be found by computing an elimination ordering of the resulting chordal graph. In this way, the minimum fill-in problem can be seen as equivalent to the minimum chordal completion problem.[^o8] In this application, [planar graphs](wikipedia://en/24314) may arise in the solution of two-dimensional finite element systems; it follows from the [planar separator theorem](wikipedia://en/18978005) that every planar graph with $n$ vertices has a chordal completion with at most $O(n \log n)$ edges.[^o9]

Another application comes from [phylogeny](https://en.wikipedia.org/wiki/Phylogeny), the problem of reconstructing evolutionary trees, for instance trees of organisms subject to genetic mutations or trees of sets of ancient manuscripts copied one from another subject to scribal errors. If one assumes that each genetic mutation or scribal error happens only once, one obtains a [perfect phylogeny](https://en.wikipedia.org/wiki/Perfect_phylogeny), a tree in which the species or manuscripts having any particular characteristic always form a connected subtree. As (Buneman 1974) describes, the existence of a perfect phylogeny can be modeled as a chordal completion problem. One draws an "overlap graph" $G$ in which the vertices are attribute values (specific choices for some characteristic of a species or manuscript) and the edges represent pairs of attribute values that are shared by at least one species. The vertices of the graph can be [colored](wikipedia://en/426743) by the identities of the characteristics that each attribute value comes from, so that the total number of colors equals the number of characteristics used to derive the phylogeny. Then a perfect phylogeny exists if and only if $G$ has a chordal completion that respects the coloring.[^o11]

:::

## Computational complexity {#Computational_complexity}

Although listed as an [open problem](wikipedia://en/1333335) in the 1979 book *[Computers and Intractability](https://en.wikipedia.org/wiki/Computers_and_Intractability)*,[^o13] the computational complexity of the minimum chordal completion problem (also called the **minimum fill-in** problem) was quickly resolved: (Yannakakis 1981) showed it to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete).[^o15] If the minimum chordal completion adds $k$ edges to a graph $G$, then it is possible to find a chordal completion using at most $8k^{2}$ added edges, in polynomial time.[^o16] The problem of finding the optimal set of $k$ edges to add can also be solved by a [fixed-parameter tractable algorithm](wikipedia://en/603026), in time polynomial in the graph size and subexponential in $k$.[^o17]

The [treewidth](wikipedia://en/3987086) (minimum clique size of a chordal completion) and related parameters including pathwidth and tree-depth are also NP-complete to compute, and (unless P=NP) cannot be approximated in polynomial time to within a constant factor of their optimum values; however, [approximation algorithms](wikipedia://en/563105) with logarithmic approximation ratios are known for them.[^o18]

Both the minimum fill-in and treewidth problems can be solved in [exponential time](https://en.wikipedia.org/wiki/Exponential_time). More precisely, for an $n$-vertex graph, the time is $O(1.9601^{n})$.[^o19]
