# Metric projection

::: {#o1 .subject cue=lead name="Metric projection"}

In mathematics, a **metric projection** is a function that maps each element of a [metric space](wikipedia://en/20018) to the set of points nearest to that element in some fixed sub-space.[^o2][^o3]

:::

::: {#o5 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Formally, let *X* be a [metric space](wikipedia://en/20018) with [distance](wikipedia://en/39378) metric *d*, and let *M* be a fixed subset of *X*. Then the metric projection associated with *M*, denoted *p<sub>M</sub>*, is the following [set-valued function](wikipedia://en/12506030) from *X* to *M*:

> $$p_M(x) = \arg\min_{y\in M} d(x,y)$$

Equivalently:

> $$p_M(x) = \{y \in M : d(x,y) \leq d(x,y') \forall y'\in M \} = \{y \in M : d(x,y) = d(x,M) \}$$

The elements in the set $\arg\min_{y\in M} d(x,y)$ are also called **elements of best approximation**. This term comes from [constrained optimization](wikipedia://en/4171950): we want to find an element nearer to *x*, under the constraint that the solution must be a subset of *M*. The function *p<sub>M</sub>* is also called an **operator of best approximation**.

:::

## Chebyshev sets {#Chebyshev_sets}

In general, *p<sub>M</sub>* is set-valued, as for every *x*, there may be many elements in *M* that have the same nearest distance to *x*. In the special case in which *p<sub>M</sub>* is single-valued, the set *M* is called a **Chebyshev set**. As an example, if (*X*,*d*) is a [Euclidean space](wikipedia://en/9697) (R<sup>n</sup> with the [Euclidean distance](wikipedia://en/53932)), then a set *M* is a Chebyshev set if and only if it is [closed](wikipedia://en/47279) and [convex](wikipedia://en/6292).[^o7]

::: {#o9 .statement kind=statement/fact cue=heading name="Continuity"}

## Continuity {#Continuity}

If *M* is non-empty [compact set](https://en.wikipedia.org/wiki/Compact_set), then the metric projection *p<sub>M</sub>* is [upper semi-continuous](https://en.wikipedia.org/wiki/Upper_semi-continuous), but might not be lower semi-continuous. But if *X* is a [normed space](https://en.wikipedia.org/wiki/Normed_space) and *M* is a finite-dimensional Chebyshev set, then *p<sub>M</sub>* is continuous.

Moreover, if X is a [Hilbert space](wikipedia://en/20598932) and M is closed and convex, then *p<sub>M</sub>* is [Lipschitz continuous](https://en.wikipedia.org/wiki/Lipschitz_continuous) with Lipschitz constant 1.

:::

::: {#o11 .application cue=heading name="Applications"}

## Applications {#Applications}

Metric projections are used both to investigate theoretical questions in [functional analysis](wikipedia://en/11180) and for practical approximation methods.[^o12] They are also used in [constrained optimization](wikipedia://en/4171950).[^o13]

:::
