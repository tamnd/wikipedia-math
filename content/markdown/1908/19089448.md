# Laver function

::: {#o1 .subject cue=lead name="Laver function"}

In [set theory](wikipedia://en/27553), a **Laver function** (or **Laver diamond**, named after its inventor, [Richard Laver](wikipedia://en/22280145)) is a function connected with [supercompact cardinals](wikipedia://en/248116).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If κ is a supercompact cardinal, a Laver function is a function *ƒ*:κ → *V*<sub>κ</sub> such that for every set *x* and every cardinal λ ≥ |TC(*x*)| + κ there is a supercompact measure *U* on \[λ\]<sup>\<κ</sup> such that if *j*<sub>*U*</sub> is the associated elementary embedding then *j*<sub>*U*</sub>(*ƒ*)(κ) = *x*. (Here *V*<sub>κ</sub> denotes the κ-th level of the [cumulative hierarchy](wikipedia://en/7393195), TC(*x*) is the [transitive closure](wikipedia://en/2462396) of *x*)

:::

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

The original application of Laver functions was the following theorem of Laver. If κ is supercompact, there is a κ-c.c. [forcing](wikipedia://en/152205) notion (*P*, ≤) such after forcing with (*P*, ≤) the following holds: κ is supercompact and remains supercompact after forcing with any κ-directed closed forcing.

There are many other applications, for example the proof of the consistency of the [proper forcing axiom](wikipedia://en/6250799).

:::
