# Data processing inequality

::: {#o1 .subject cue=lead name="Data processing inequality"}

The **data processing inequality** is an [information theoretic](wikipedia://en/14773) concept that states that the information content of a signal cannot be increased via a local physical operation. This can be expressed concisely as 'post-processing cannot increase information'.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let three random variables form the [Markov chain](wikipedia://en/60876) $X \rightarrow Y \rightarrow Z$, implying that the conditional distribution of $Z$ depends only on $Y$ and is [conditionally independent](wikipedia://en/801135) of $X$. Specifically, we have such a Markov chain if the joint probability mass function can be written as

$$p(x,y,z) = p(x)p(y|x)p(z|y)=p(y)p(x|y)p(z|y)$$

In this setting, no processing of $Y$, deterministic or random, can increase the information that $Y$ contains about $X$. Using the [mutual information](wikipedia://en/427282), this can be written as :

$$I(X;Y) \geqslant I(X;Z),$$

with the equality $I(X;Y) = I(X;Z)$ if and only if $I(X;Y\mid Z)=0$. That is, $Z$ and $Y$ contain the same information about $X$, and $X \rightarrow Z \rightarrow Y$ also forms a Markov chain.[^o5]

:::

::: {#o7 .proof cue=heading name="Proof"}

## Proof {#Proof}

One can apply the [chain rule for mutual information](wikipedia://en/18867510#Chain_rule_for_mutual_information_chain_rule_for_mutual_information) to obtain two different decompositions of $I(X;Y,Z)$:

$$I(X;Z) + I(X;Y\mid Z) = I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y)$$

By the relationship $X \rightarrow Y \rightarrow Z$, we know that $X$ and $Z$ are conditionally independent, given $Y$, which means the [conditional mutual information](wikipedia://en/18867510), $I(X;Z\mid Y)=0$. The data processing inequality then follows from the non-negativity of $I(X;Y\mid Z)\ge0$.

:::
