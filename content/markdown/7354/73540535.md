# Bricklayer function

::: {#o1 .subject cue=lead name="Bricklayer function"}

*Image: AES-SubBytes.svg.* The SubBytes transformation of the [Advanced Encryption Standard](wikipedia://en/1260) is a notable[^n1] example of a bricklayer function: each 8-bit bundle of the 128-bit state is undergoing the same [S-box](wikipedia://en/240991) transformation independently

In [cryptography](wikipedia://en/18934432), the **bricklayer function** is a part of a [round function](wikipedia://en/73297602) that can be decomposed into identical independent Boolean operations on the partitioned pieces of its input data,[^n2] so called **bundles**.[^n3] The term was introduced by [Daemen](https://en.wikipedia.org/wiki/Joan_Daemen) and [Rijmen](https://en.wikipedia.org/wiki/Vincent_Rijmen) in 2001.[^n1]

:::

If the underlying function transforming the bundle is nonlinear, it is traditionally called an [S-box](wikipedia://en/240991). If the function is linear, Daemen and Rijmen use for it the term **D-box** (after [**d**iffusion](wikipedia://en/537555)).[^n2]
