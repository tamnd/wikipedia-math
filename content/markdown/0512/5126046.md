# Hereditarily countable set

::: {#o1 .subject cue=lead name="Hereditarily countable set"}

In [set theory](wikipedia://en/27553), a set is called **hereditarily countable** if it is a [countable set](wikipedia://en/6026) of [hereditarily](wikipedia://en/13552465) countable sets.

:::

::: {#o3 .statement cue=heading name="Results"}

## Results {#Results}

The [inductive definition](https://en.wikipedia.org/wiki/Inductive_definition) above is [well-founded](https://en.wikipedia.org/wiki/Well-founded) and can be expressed in the language of [first-order](wikipedia://en/10983) set theory.

### Equivalent properties {#Equivalent_properties}

A set is hereditarily countable if and only if it is countable, and every element of its [transitive closure](wikipedia://en/2462396) is countable.[^o5]

### The collection of all hereditarily countable sets {#The_collection_of_all_hereditarily_countable_sets}

The [class](wikipedia://en/20696) of all hereditarily countable sets can be proven to be a set from the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZF) and is set is designated $H_{\aleph_1}$. In particular, the existence does not require any form of the [axiom of choice](wikipedia://en/840). [Constructive Zermelo–Fraenkel](wikipedia://en/5042360) (CZF) does not prove the class to be a set.

The set $H_{\aleph_1}$ is included in the set $V_{\omega_1}$ from the [von Neumann hierarchy](https://en.wikipedia.org/wiki/Von_Neumann_hierarchy), that is, $H_{\aleph_1} \subseteq V_{\omega_1}$. Every [hereditarily finite set](wikipedia://en/332621) is hereditarily countable, so $H_{\aleph_1} \supseteq \mathrm{HF} = V_{\omega}$. Since $V_{\omega}$ is countable, we in fact have $H_{\aleph_1} \supseteq V_{\omega+1}$.

An [ordinal](wikipedia://en/26547932) is hereditarily countable if and only if it is countable.

#### Model theory {#Model_theory}

This class is a model of [Kripke–Platek set theory](wikipedia://en/1124695) with the [axiom of infinity](wikipedia://en/246449) (KPI), if the axiom of countable choice is assumed in the [metatheory](wikipedia://en/4823199).

If $x \in H_{\aleph_1}$, then $L_{\omega_1}(x) \subseteq H_{\aleph_1}$.

:::

::: {#o9 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

More generally, a set is **hereditarily of cardinality less than *κ*** if it is of [cardinality](wikipedia://en/6174) less than *κ*, and all its elements are hereditarily of cardinality less than *κ*. The class of all such sets can also be proven to be a set from the axioms of ZF, and is designated $H_\kappa \!$. If the axiom of choice holds and the cardinal *κ* is [regular](wikipedia://en/374128), then a set is hereditarily of cardinality less than *κ* if and only if its transitive closure is of cardinality less than *κ*.

:::
