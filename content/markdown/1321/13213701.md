# Kōmura's theorem

::: {#o1 .subject cue=lead name="Kōmura's theorem"}

In [mathematics](wikipedia://en/18831), **Kōmura's theorem** is a result on the [differentiability](wikipedia://en/7921) of [absolutely continuous](wikipedia://en/252670) [Banach space](wikipedia://en/3989)-valued functions, and is a substantial generalization of Lebesgue's theorem on the differentiability of the [indefinite integral](https://en.wikipedia.org/wiki/Indefinite_integral), which is that Φ : \[0, *T*\] → **R** given by

:::

$$\Phi(t) = \int_{0}^{t} \varphi(s) \, \mathrm{d} s,$$

is differentiable at *t* for [almost every](wikipedia://en/44688) 0 \< *t* \< *T* when *φ* : \[0, *T*\] → **R** lies in the [*L*<sup>*p*</sup> space](wikipedia://en/45194) *L*<sup>1</sup>(\[0, *T*\]; **R**).

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let (*X*, || ||) be a [reflexive](wikipedia://en/210091) Banach space and let *φ* : \[0, *T*\] → *X* be absolutely continuous. Then *φ* is (strongly) differentiable almost everywhere, the derivative *φ*′ lies in the [Bochner space](wikipedia://en/6751583) *L*<sup>1</sup>(\[0, *T*\]; *X*), and, for all 0 ≤ *t* ≤ *T*,

$$\varphi(t) = \varphi(0) + \int_{0}^{t} \varphi'(s) \, \mathrm{d} s.$$

:::
