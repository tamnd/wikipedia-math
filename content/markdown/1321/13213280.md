# Kachurovskii's theorem

::: {#o1 .subject cue=lead name="Kachurovskii's theorem"}

In [mathematics](wikipedia://en/18831), **Kachurovskii's theorem** is a theorem relating the [convexity](wikipedia://en/245568) of a function on a [Banach space](wikipedia://en/3989) to the [monotonicity](https://en.wikipedia.org/wiki/Monotone_operator) of its [Fréchet derivative](wikipedia://en/2735727).

:::

::: {#o3 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let *K* be a [convex subset](wikipedia://en/6292) of a Banach space *V* and let *f* : *K* → **R** ∪ {+∞} be an [extended real-valued function](wikipedia://en/51698) that is Fréchet differentiable with derivative d*f*(*x*) : *V* → **R** at each point *x* in *K*. (In fact, d*f*(*x*) is an element of the [continuous dual space](https://en.wikipedia.org/wiki/Continuous_dual_space) *V*<sup>∗</sup>.) Then the following are equivalent:

- *f* is a convex function;
- for all *x* and *y* in *K*,

$$\mathrm{d} f(x) (y - x) \leq f(y) - f(x);$$

- d*f* is an (increasing) monotone operator, i.e., for all *x* and *y* in *K*,

$$\big( \mathrm{d} f(x) - \mathrm{d} f(y) \big) (x - y) \geq 0.$$

:::
