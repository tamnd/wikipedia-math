# Key whitening

::: {#o1 .subject cue=lead name="Key whitening"}

In [cryptography](wikipedia://en/18934432), **key whitening** is a technique intended to increase the security of an [iterated block cipher](wikipedia://en/4594). It consists of steps that combine the data with portions of the [key](wikipedia://en/53039).

:::

## Details {#Details}

*Image: Xor Encrypt Xor.svg.* Key whitening using the xor-encrypt-xor technique: a (short) Key is made longer with Key1 and Key2 parts

The most common form of key whitening is [xor–encrypt–xor](wikipedia://en/42194234) – using a simple [XOR](https://en.wikipedia.org/wiki/XOR) before the first round and after the last round of [encryption](wikipedia://en/10294).

The first block cipher to use a form of key whitening is [DES-X](wikipedia://en/619801), which simply uses two extra 64-bit keys for whitening, beyond the normal 56-bit key of [DES](wikipedia://en/7978). This is intended to increase the complexity of a [brute-force attack](wikipedia://en/53784), increasing the effective size of the key without major changes in the algorithm. DES-X's inventor, [Ron Rivest](https://en.wikipedia.org/wiki/Ron_Rivest), named the technique *whitening*.

The cipher [FEAL](wikipedia://en/592532) (followed by [Khufu and Khafre](wikipedia://en/634695)) introduced the practice of key whitening using portions of the same key used in the rest of the cipher. This offers no additional protection from brute-force attacks, but it can make other attacks more difficult. In a [Feistel cipher](wikipedia://en/352709) or similar algorithm, key whitening can increase security by concealing the specific inputs to the first and last round functions. In particular, it is not susceptible to a [meet-in-the-middle attack](wikipedia://en/423418). This form of key whitening has been adopted as a feature of many later block ciphers, including [AES](wikipedia://en/1260), [MARS](https://en.wikipedia.org/wiki/MARS_%28cryptography%29), [RC6](wikipedia://en/160216), and [Twofish](wikipedia://en/26508356).
