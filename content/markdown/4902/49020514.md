# Unambiguous Turing machine

::: {#o1 .subject cue=lead name="Unambiguous Turing machine"}

In [theoretical computer science](wikipedia://en/323392), an **unambiguous Turing machine** is a theoretical model of computation whose power (under [resource restrictions](wikipedia://en/6511)) is between that of ordinary Turing machines and [nondeterministic Turing machines](wikipedia://en/21935). An unambiguous Turing machine is defined as a nondeterministic Turing machine with the property that for every input, there is at most one accepting computation path.[^o2]

:::

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A [nondeterministic Turing machine](wikipedia://en/21935) is represented formally by a [6-tuple](https://en.wikipedia.org/wiki/N-tuple), $M=(Q, \Sigma, \iota, \sqcup, A, \delta)$, as explained in the aforementioned linked article.[^o5]p. 178

An *unambiguous Turing machine* is a nondeterministic Turing machine $M$ such that for any input $w$, $M$ has at most one accepting computation on $w$.[^o2] That is, for every input $w$, there exists at most one sequence of configurations $c_0,c_1,\ldots,c_m$ with the following conditions:

1. $c_0$ is the initial configuration with input $w$
1. $c_{i+1}$ is a successor of $c_i$ and
1. $c_m$ is an accepting configuration.[^o5]p. 168–169

:::

## Expressivity {#Expressivity}

The *language* of an unambiguous Turing machine is defined to be the same language that is accepted by the nondeterministic Turing machine. A language of strings *L* can be defined to be *unambiguously recognizable* if it is recognizable by an unambiguous Turing machine.

The class of unambiguously recognizable languages is exactly the same as the class of [recursively enumerable languages](wikipedia://en/54789) (RE). Indeed, every deterministic Turing machine is an unambiguous Turing machine, as for each input, there is exactly one computation possible. Therefore, all recursively enumerable languages are unambiguously recognizable. Conversely, every unambiguously recognizable language is recognizable by a nondeterministic Turing machine, and hence is recursively enumerable.

The complexity class [UP](wikipedia://en/312240) is defined as the class of languages that can be decided in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) by an unambiguous Turing machine.
