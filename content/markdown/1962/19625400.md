# Residual property (mathematics)

::: {#o1 .subject cue=lead name="Residual property"}

In the [mathematical](wikipedia://en/18831) field of [group theory](wikipedia://en/41890), a group is **residually *X*** (where *X* is some property of groups) if it "can be recovered from groups with property *X*".

:::

Formally, a group *G* is residually *X* if for every non-trivial element *g* there is a [homomorphism](wikipedia://en/12396) *h* from *G* to a group with property *X* such that $h(g)\neq e$.

More [categorically](wikipedia://en/5869), a group is residually *X* if it embeds into its pro-*X* completion (see [profinite group](wikipedia://en/24266), [pro-p group](wikipedia://en/1842075)), that is, the [inverse limit](wikipedia://en/15109) of the [inverse system](https://en.wikipedia.org/wiki/Inverse_system) consisting of all morphisms $\phi\colon G \to H$ from *G* to some group *H* with property *X*.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Important examples include:

- [Residually finite](wikipedia://en/5780875)
- Residually [nilpotent](wikipedia://en/144569)
- Residually [solvable](wikipedia://en/105012)
- Residually [free](wikipedia://en/59735)

:::
