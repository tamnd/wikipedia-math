# Cyclic (mathematics)

::: {#o1 .subject cue=lead name="Cyclic"}

There are many terms in mathematics that begin with **cyclic**:

:::

- [Cyclic chain rule](https://en.wikipedia.org/wiki/Cyclic_chain_rule), for derivatives, used in thermodynamics
- [Cyclic code](wikipedia://en/4706825), linear codes closed under cyclic permutations
- [Cyclic convolution](https://en.wikipedia.org/wiki/Cyclic_convolution), a method of combining periodic functions
- [Cycle decomposition (graph theory)](wikipedia://en/27268816)
- [Cycle decomposition (group theory)](https://en.wikipedia.org/wiki/Cycle_decomposition_%28group_theory%29)
- [Cyclic extension](https://en.wikipedia.org/wiki/Cyclic_extension), a field extension with cyclic Galois group
- Graph theory:
- [Cyclic function](https://en.wikipedia.org/wiki/Cyclic_function), a periodic function
  - [Cycle graph](wikipedia://en/878962), a connected, 2-regular graph
  - [Cycle graph (algebra)](wikipedia://en/1681010), a diagram representing the cycles determined by taking powers of group elements
  - [Circulant graph](wikipedia://en/3498787), a graph with cyclic symmetry
  - [Cycle (graph theory)](wikipedia://en/168609), a nontrivial path in some graph from a node to itself
  - [Cyclic graph](wikipedia://en/3498846), a graph containing at least one graph cycle
- [Cyclic group](wikipedia://en/52327), a group generated by a single element
- [Cyclic homology](wikipedia://en/1460172), an approximation of K-theory used in non-commutative differential geometry
- [Cyclic module](wikipedia://en/4128720), a module generated by a single element
- [Cyclic notation](https://en.wikipedia.org/wiki/Cyclic_notation), a way of writing permutations
- [Cyclic number](wikipedia://en/1672489), a number such that cyclic permutations of the digits are successive multiples of the number
- [Cyclic order](wikipedia://en/434673), a ternary relation defining a way to arrange a set of objects in a circle
- [Cyclic permutation](wikipedia://en/449166), a permutation with one nontrivial orbit
- [Cyclic polygon](https://en.wikipedia.org/wiki/Cyclic_polygon), a polygon which can be given a circumscribed circle
- [Cyclic shift](https://en.wikipedia.org/wiki/Cyclic_shift), also known as circular shift
- [Cyclic symmetry](https://en.wikipedia.org/wiki/Cyclic_symmetry), n-fold rotational symmetry of 3-dimensional space
