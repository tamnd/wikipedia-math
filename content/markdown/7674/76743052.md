# CLRg property

::: {#o1 .subject cue=lead name="CLRg property"}

In mathematics, the notion of *"common limit in the range"* property denoted by **CLRg property**[^o2][^o3][^o4] is a theorem that unifies, generalizes, and extends the [contractive mappings](https://en.wikipedia.org/wiki/Contractive_mapping) in [fuzzy metric spaces](https://en.wikipedia.org/wiki/Fuzzy_metric_spaces), where the range of the [mappings](wikipedia://en/516931) does not necessarily need to be a [closed](wikipedia://en/47279) [subspace](https://en.wikipedia.org/wiki/Closed_subspace_%28topology%29) of a non-empty [set](wikipedia://en/26691) $X$.

:::

Suppose $X$ is a non-empty set, and $d$ is a distance metric; thus, $(X, d)$ is a metric space. Now suppose we have self [mappings](wikipedia://en/516931) $f,g : X \to X.$ These [mappings](wikipedia://en/516931) are said to fulfil **CLRg property** if

$$\lim_{k \to \infty} f x_{k} = \lim_{k \to \infty} g x_{k} = gx,$$

for some $x \in X.$

Next, we give some examples that satisfy the **CLRg property**.

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

Source:[^o2]

### Example 1 {#Example_1}

Suppose $(X,d)$ is a usual metric space, with $X=[0,\infty).$ Now, if the [mappings](wikipedia://en/516931) $f,g: X \to X$ are defined respectively as follows:

- $$fx = \frac{x}{4}$$
- $$gx = \frac{3x}{4}$$

for all $x\in X.$ Now, if the following sequence $\{x_k\}=\{1/k\}$ is considered. We can see that

$$\lim_{k\to \infty}fx_{k} = \lim_{k\to \infty}gx_{k} = g0 = 0,$$

thus, the [mappings](wikipedia://en/516931) $f$ and $g$ fulfilled the **CLRg property**.

Another example that shades more light to this CLRg property is given below

### Example 2 {#Example_2}

Let $(X,d)$ is a usual metric space, with $X=[0,\infty).$ Now, if the [mappings](wikipedia://en/516931) $f,g: X \to X$ are defined respectively as follows:

- $$fx = x+1$$
- $$gx = 2x$$

for all $x\in X.$ Now, if the following sequence $\{x_k\}=\{1+1/k \}$ is considered. We can easily see that

$$\lim_{k\to \infty}fx_{k} = \lim_{k\to \infty}gx_{k} = g1 = 2,$$

hence, the [mappings](wikipedia://en/516931) $f$ and $g$ fulfilled the **CLRg property**.
