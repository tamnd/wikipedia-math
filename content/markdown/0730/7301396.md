# Tetracategory

::: {#o1 .subject cue=lead name="Tetracategory"}

In [category theory](wikipedia://en/5869), a **tetracategory** is a weakened definition of a [4-category](https://en.wikipedia.org/wiki/4-category). The definition of tetracategory and its [coherence conditions](https://en.wikipedia.org/wiki/Coherence_condition) were introduced by Trimble. The formal definition of Trimble's tetracategory is given using the coherence theorem for [tricategories](https://en.wikipedia.org/wiki/Tricategory). There is no coherence theorem for tetracategories yet.[^n1] Hoffnung says that, a [monoidal](wikipedia://en/330604) tricategory is a one-object tetracategory in the sense of Trimble.[^n2]

:::
