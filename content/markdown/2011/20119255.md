# Foster's theorem

Mathematics

::: {#o1 .subject cue=lead name="Foster's theorem"}

In [probability theory](wikipedia://en/23542), **Foster's theorem**, named after [Gordon Foster](https://en.wikipedia.org/wiki/Gordon_Foster),[^o2] is used to draw conclusions about the positive recurrence of [Markov chains](https://en.wikipedia.org/wiki/Markov_chains) with [countable](https://en.wikipedia.org/wiki/Countable) state spaces. It uses the fact that positive recurrent Markov chains exhibit a notion of "[Lyapunov stability](wikipedia://en/363360)" in terms of returning to any state while starting from it within a finite time interval.

:::

::: {#o4 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

Consider an irreducible discrete-time Markov chain on a countable state space $S$ having a [transition probability matrix](wikipedia://en/217313) $P$ with elements $p_{ij}$ for pairs $i$, $j$ in $S$. Foster's theorem states that the Markov chain is positive recurrent if and only if there exists a [Lyapunov function](wikipedia://en/352267) $V: S \to \mathbb{R}$, such that $V(i) \geq 0 \text{ } \forall \text{ } i \in S$ and

1. $\sum_{j \in S}p_{ij}V(j) < {\infty}$ for $i \in F$
1. $\sum_{j \in S}p_{ij}V(j) \leq V(i) - \varepsilon$ for all $i \notin F$

for some finite set $F$ and strictly positive $\varepsilon$.[^o5]

:::
