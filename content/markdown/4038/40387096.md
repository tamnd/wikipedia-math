# PKCS 8

::: {#o1 .subject cue=lead name="PKCS 8"}

In [cryptography](wikipedia://en/18934432), **PKCS #8** is a standard syntax for storing [private key](https://en.wikipedia.org/wiki/Private_key) information. PKCS #8 is one of the family of standards called [Public-Key Cryptography Standards (PKCS)](wikipedia://en/616418) created by [RSA Laboratories](https://en.wikipedia.org/wiki/RSA_Laboratories). The latest version, 1.2, is available as RFC 5208.[^o2]

:::

The PKCS #8 private key may be encrypted with a [passphrase](https://en.wikipedia.org/wiki/Passphrase) using one of the PKCS #5 standards defined in RFC 2898,[^o3] which supports multiple encryption schemes.

A new version 2 was proposed by S. Turner in 2010 as RFC 5958 [^o4] and might obsolete RFC 5208 someday in the future.

PKCS #8 private keys are typically exchanged in the [PEM](https://en.wikipedia.org/wiki/Privacy-enhanced_Electronic_Mail) [base64](https://en.wikipedia.org/wiki/Base64)-encoded format, for example:
