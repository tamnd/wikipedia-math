# Eigenform

::: {#o1 .subject cue=lead name="Eigenform"}

In mathematics, an **eigenform** (meaning simultaneous Hecke eigenform with modular group SL(2,**Z**)) is a [modular form](wikipedia://en/286000) that is an [eigenvector](https://en.wikipedia.org/wiki/Eigenvector) for all [Hecke operators](wikipedia://en/521837) *T<sub>m</sub>*, *m* = 1, 2, 3, ....

:::

Eigenforms fall into the realm of [number theory](wikipedia://en/21527), but can be found in other areas of math and science such as [analysis](wikipedia://en/1134), [combinatorics](wikipedia://en/5170), and [physics](wikipedia://en/22939). Common examples of eigenforms, and the only non-cuspidal eigenforms, are those of the [Eisenstein series](wikipedia://en/1270458). Another example is the [Δ function](https://en.wikipedia.org/wiki/Weierstrass's_elliptic_functions#Modular_discriminant).

## Normalization {#Normalization}

There are two different normalizations for an eigenform (or for a modular form in general).

### Algebraic normalization {#Algebraic_normalization}

An eigenform is said to be **normalized** when scaled so that the *q*-coefficient in its [Fourier series](wikipedia://en/59038) is one:

$$f = a_0 + q + \sum_{i=2}^\infty a_i q^i$$

where *q* = *e*<sup>2*πiz*</sup>. As the function *f* is also an eigenvector under each Hecke operator *T<sub>i</sub>*, it has a corresponding eigenvalue. More specifically *a*<sub>*i*</sub>, *i* ≥ 1 turns out to be the eigenvalue of *f* corresponding to the Hecke operator *T<sub>i</sub>*. In the case when *f* is not a cusp form, the eigenvalues can be given explicitly.[^o4]

### Analytic normalization {#Analytic_normalization}

An eigenform which is cuspidal can be normalized with respect to its [inner product](wikipedia://en/4028987):

$$\langle f, f \rangle = 1\,$$

## Existence {#Existence}

The existence of eigenforms is a nontrivial result, but does come directly from the fact that the [Hecke algebra](wikipedia://en/521837#Hecke_algebras) is commutative.

## Higher levels {#Higher_levels}

In the case that the [modular group](wikipedia://en/325019) is not the full SL(2,**Z**), there is not a Hecke operator for each *n* ∈ **Z**, and as such the definition of an eigenform is changed accordingly: an eigenform is a modular form which is a simultaneous eigenvector for all Hecke operators that act on the space.
