# Number Scrabble

::: {#o1 .subject cue=lead name="Number Scrabble"}

**Number Scrabble** (also known as **Pick15**[^o2][^o3][^o4] or **3 to 15**[^o5]) is a mathematical game where players take turns to select numbers from 1 to 9 without repeating any numbers previously used, and the first player with a sum of exactly 15 using any three of their number selections wins the game.[^o6][^o7] The game is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to [tic-tac-toe](https://en.wikipedia.org/wiki/Tic-tac-toe), as can be seen if the game is mapped onto a [magic square](wikipedia://en/52202).[^o7]

:::

## Play {#Play}

*Image: Magicsquareexample.svg.* A 3x3 magic square of the numbers 1 through 9

Number Scrabble is played with the list of numbers between 1 and 9. Each player takes turns picking a number from the list. Once a number has been picked, it cannot be picked again. If a player has picked three numbers that add up to 15, that player wins the game.[^o6][^o7][^o9] However, if all the numbers are used and no player gets exactly 15, the game is a draw.[^o6][^o7]

The game is identical to tic-tac-toe, as can be seen by reference to a 3x3 [magic square](wikipedia://en/52202): if a player has selected three numbers which can be found in a line on a magic square, they will add up to 15. If they have selected any other three numbers, they will not.[^o10]

::: {#o12 .example cue=heading name="Example"}

## Example {#Example}

As an example game between player A and player B:

1. A picks 9.
1. B picks 8.
1. A picks 2.
1. B has no choice but to pick 4 (otherwise, A could get 9+2+4=15).
1. A has no choice but to pick 3 (otherwise, B could get 8+4+3=15).
1. B picks 6, and thereby threatens to win by either picking 1 (8+6+1=15) or 5 (4+6+5=15).
1. At this point, A has lost because the second pick (2) was a mistake, A should not pick 1, 2, 3, or 7 as second pick, or A must lose.

:::
