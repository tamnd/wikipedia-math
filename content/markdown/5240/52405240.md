# Two-Track-MAC

Two-Track-MAC

::: {#o1 .subject cue=lead name="Two-Track-MAC"}

**Two-Track-MAC** is a [message authentication code](wikipedia://en/567523) submitted to the [NESSIE](wikipedia://en/497430) project in 2000 by Bart Van Rompay (KU Leuven) and Bert den Boer (debis AG).[^o2] It is based on a dual-track hashing structure derived from [RIPEMD](wikipedia://en/26363), in which two [parallel computation](https://en.wikipedia.org/wiki/Parallel_computing) paths are combined to produce the final MAC.[^o3]

:::

It uses a dual-track structure derived from RIPEMD, in which two parallel computation paths are combined. This is superficially similar to constructions such as [MDC-2](wikipedia://en/2642062), which also employ parallel processing, though the underlying designs differ significantly.[^o3]
