# End extension

::: {#o1 .subject cue=lead name="End extension"}

In [model theory](wikipedia://en/19858) and [set theory](wikipedia://en/27553), a model $\mathfrak{B}=\langle B, F\rangle$ of some axiom system of [set theory](wikipedia://en/27553) $T$ in the language of set theory is an **end extension** of $\mathfrak{A}=\langle A, E\rangle$, in symbols $\mathfrak{A}\subseteq_\text{end}\mathfrak{B}$, if

:::

1. $\mathfrak{A}$ is a [substructure](wikipedia://en/2057747) of $\mathfrak{B}$, (i.e., $A \subseteq B$ and $E = F|_A$), and
1. $b\in A$ whenever $a\in A$ and $bFa$ hold, i.e., no new elements are added by $\mathfrak{B}$ to the elements of $A$.[^o2]

The second condition can be equivalently written as $\{b\in A : b E a\}=\{b\in B : b F a\}$ for all $a\in A$.

For example, $\langle B, \in\rangle$ is an end extension of $\langle A, \in\rangle$ if $A$ and $B$ are [transitive sets](wikipedia://en/2462396), and $A\subseteq B$.

A related concept is that of a **top extension** (also known as rank extension), where a model $\mathfrak{B}=\langle B, F\rangle$ is a top extension of a model $\mathfrak{A}=\langle A, E\rangle$ if $\mathfrak{A}\subseteq_\text{end}\mathfrak{B}$ and for all $a \in A$ and $b \in B\setminus A$, we have $\operatorname{rank}(b) > \operatorname{rank}(a)$, where $\operatorname{rank}(\cdot)$ denotes the [rank](https://en.wikipedia.org/wiki/Rank_%28set_theory%29) of a set.

## Existence {#Existence}

[Keisler](wikipedia://en/10962250) and [Morley](wikipedia://en/2921675) showed that every countable model of ZF has an end extension which is also an [elementary extension](https://en.wikipedia.org/wiki/Elementary_substructure).[^o4] If the elementarity requirement is weakened to being elementary for formulae that are $\Sigma_n$ on the [Lévy hierarchy](wikipedia://en/25129404), every countable structure in which $\Sigma_n$-collection holds has a $\Sigma_n$-elementary end extension.[^o5]
