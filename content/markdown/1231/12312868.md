# Hilbert–Schmidt theorem

::: {#o1 .subject cue=lead name="Hilbert–Schmidt theorem"}

In [mathematical analysis](wikipedia://en/48396), the **Hilbert–Schmidt theorem**, also known as the **[eigenfunction](wikipedia://en/228601) expansion theorem**, is a fundamental result concerning [compact](wikipedia://en/577441), [self-adjoint operators](wikipedia://en/187408) on [Hilbert spaces](wikipedia://en/20598932). In the theory of [partial differential equations](wikipedia://en/52564), it is very useful in solving [elliptic](wikipedia://en/550137) [boundary value problems](wikipedia://en/436779).

:::

::: {#o3 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let (*H*, ⟨ , ⟩) be a [real](wikipedia://en/20646438) or [complex](wikipedia://en/5826) Hilbert space and let *A* : *H* → *H* be a [bounded](https://en.wikipedia.org/wiki/Bounded_linear_operator), compact, self-adjoint operator. Then there is a sequence of non-zero real [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) *λ*<sub>*i*</sub>, *i* = 1, …, *N*, with *N* equal to the [rank](wikipedia://en/26561) of *A*, such that |*λ*<sub>*i*</sub>| is [monotonically non-increasing](https://en.wikipedia.org/wiki/Monotone_sequence) and, if *N* = +∞,

$$\lim_{i \to + \infty} \lambda_{i} = 0.$$

Furthermore, if each eigenvalue of *A* is repeated in the sequence according to its [multiplicity](wikipedia://en/19211790), then there exists an [orthonormal](https://en.wikipedia.org/wiki/Orthonormal) set *φ*<sub>*i*</sub>, *i* = 1, …, *N*, of corresponding eigenfunctions, i.e.,

$$A \varphi_{i} = \lambda_{i} \varphi_{i} \mbox{ for } i = 1, \dots, N.$$

Moreover, the functions *φ*<sub>*i*</sub> form an [orthonormal basis](wikipedia://en/195063) for the [range](wikipedia://en/275991) of *A* and *A* can be written as

$$A u = \sum_{i = 1}^{N} \lambda_{i} \langle \varphi_{i}, u \rangle \varphi_{i} \mbox{ for all } u \in H.$$

:::
