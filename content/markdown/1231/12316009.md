# Nemytskii operator

::: {#o1 .subject cue=lead name="Nemytskii operator"}

In [mathematics](wikipedia://en/18831), **Nemytskii operators** are a class of [nonlinear operators](https://en.wikipedia.org/wiki/Nonlinear_operator) on [*L*<sup>*p*</sup> spaces](wikipedia://en/45194) with good [continuity](wikipedia://en/6122) and [boundedness](wikipedia://en/311509) properties. They take their name from the [mathematician](wikipedia://en/18902) [Viktor Vladimirovich Nemytskii](https://en.wikipedia.org/wiki/Viktor_Vladimirovich_Nemytskii).

:::

## General definition of Superposition operator {#General_definition_of_Superposition_operator}

Let $\mathbb{X},\ \mathbb{Y},\ \mathbb{Z} \neq \varnothing$ be non-empty sets. Let $\mathbb{Y}^ \mathbb{X},\ \mathbb{Z}^\mathbb{X}$ denote the sets of mappings from $\mathbb{X}$ to $\mathbb{Y}$ and $\mathbb{Z}$ respectively. Let $h\ \colon \mathbb{X} \times \mathbb{Y} \to \mathbb{Z}$.

Then the **Nemytskii superposition operator** $H\ \colon \mathbb{Y}^\mathbb{X} \to \mathbb{Z}^\mathbb{X}$ induced by $h$ is the map taking any map $\varphi \in \mathbb{Y}^\mathbb{X}$ to the map $H\varphi \in \mathbb{Z}^\mathbb{X}$ defined by

$$(H\varphi)(x) = h(x, \varphi(x)) \in \mathbb{Z}, \quad \mbox{for all}\ x\in \mathbb{X}.$$

The function $h$ is called the **generator** of the Nemytskii operator $H$.

::: {#o4 .definition cue=heading name="Definition of Nemytskii operator"}

## Definition of Nemytskii operator {#Definition_of_Nemytskii_operator}

Let Ω be a domain (an [open](wikipedia://en/39358) and [connected set](wikipedia://en/6233)) in *n*-dimensional [Euclidean space](wikipedia://en/9697). A function *f* : Ω × **R**<sup>*m*</sup> → **R** is said to satisfy the **Carathéodory conditions** if

- *f*(*x*, *u*) is a continuous function of *u* for [almost all](wikipedia://en/1309) *x* ∈ Ω;
- *f*(*x*, *u*) is a [measurable function](wikipedia://en/44055) of *x* for all *u* ∈ **R**<sup>*m*</sup>.

Given a function *f* satisfying the Carathéodory conditions and a function *u* : Ω → **R**<sup>*m*</sup>, define a new function *F*(*u*) : Ω → **R** by

$$F(u)(x) = f \big( x, u(x) \big).$$

The function *F* is called a **Nemytskii operator**.

:::

## Theorem on Lipschitzian Operators {#Theorem_on_Lipschitzian_Operators}

Suppose that $h: [a, b] \times \mathbb{R} \to \mathbb{R}$, $X = \text{Lip} [a, b]$ and

$$H: \text{Lip} [a, b] \to \text{Lip} [a, b]$$

where the operator $H$ is defined as $\left( Hf \right) \left(x\right)$ $= h(x, f(x))$ for any function $f : [a,b] \to \mathbb{R}$ and any $x \in [a,b]$. Under these conditions the operator $H$ is [Lipschitz continuous](https://en.wikipedia.org/wiki/Lipschitz_continuous) if and only if there exist functions $G, H \in \text{Lip} [a, b]$ such that

$$h(x, y) = G(x)y + H(x), \quad x \in [a, b], \quad y \in \mathbb{R}.$$

:::

::: {#o8 .statement kind=statement/theorem cue=named-heading name="Boundedness theorem"}

## Boundedness theorem {#Boundedness_theorem}

Let Ω be a domain, let 1 \< *p* \< +∞ and let *g* ∈ *L*<sup>*q*</sup>(Ω; **R**), with

$$\frac1{p} + \frac1{q} = 1.$$

Suppose that *f* satisfies the Carathéodory conditions and that, for some constant *C* and all *x* and *u*,

$$\big| f(x, u) \big| \leq C | u |^{p - 1} + g(x).$$

Then the Nemytskii operator *F* as defined above is a bounded and continuous map from *L*<sup>*p*</sup>(Ω; **R**<sup>*m*</sup>) into *L*<sup>*q*</sup>(Ω; **R**).

:::
