# Almost convergent sequence

::: {#o1 .subject cue=lead name="Almost convergent sequence"}

A [bounded](https://en.wikipedia.org/wiki/Bounded_sequence) [real](wikipedia://en/20646438) [sequence](wikipedia://en/27838) $(x_n)$ is said to be *almost convergent* to $L$ if each [Banach limit](wikipedia://en/2591539) assigns the same value $L$ to the sequence $(x_n)$.

:::

Lorentz proved that $(x_n)$ is almost convergent if and only if

$$\lim\limits_{p\to\infty} \frac{x_{n}+\ldots+x_{n+p-1}}p=L$$

uniformly in $n$.

The above limit can be rewritten in detail as

$$\forall \varepsilon>0 : \exists p_0 : \forall p>p_0 : \forall n : \left|\frac{x_{n}+\ldots+x_{n+p-1}}p-L\right|<\varepsilon.$$

Almost convergence is studied in [summability theory](https://en.wikipedia.org/wiki/Summability_theory). It is an example of a summability method which cannot be represented as a matrix method.[^o2]
