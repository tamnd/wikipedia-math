# Axiom of global choice

::: {#o1 .subject cue=lead name="Axiom of global choice"}

In [mathematics](wikipedia://en/18831), specifically in [class theories](wikipedia://en/20696), the **axiom of global choice** is a stronger variant of the [axiom of choice](wikipedia://en/840) that applies to [proper classes](https://en.wikipedia.org/wiki/Proper_classes) of [sets](wikipedia://en/26691) as well as sets of sets. Informally it states that one can simultaneously choose an element from every [non-empty](wikipedia://en/9566) set.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

The axiom of global choice states that there is a [global choice function](wikipedia://en/1432664#Bourbaki_tau_function) τ, meaning a function such that for every non-empty set *z*, τ(*z*) is an element of *z*.

The axiom of global choice cannot be stated directly in the language of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZF) with the [axiom of choice](wikipedia://en/840) (AC), known as ZFC, as the choice function τ is a proper class and in ZFC one cannot quantify over classes. It can be stated by adding a new function symbol τ to the language of ZFC, with the property that τ is a global choice function. This is a [conservative extension](wikipedia://en/1840214) of ZFC: every provable statement of this extended theory that can be stated in the language of ZFC is already provable in ZFC (Fraenkel Bar-Hillel Levy 1973, p.72). Alternatively, [Gödel](wikipedia://en/16736) showed that given the [axiom of constructibility](wikipedia://en/696472) one can write down an explicit (though somewhat complicated) choice function τ in the language of ZFC, so in some sense the axiom of constructibility implies global choice (in fact, \[ZFC proves that\] in the language extended by the unary function symbol τ, the axiom of constructibility implies that if τ is said explicitly definable function, then this τ is a global choice function. And then global choice morally holds, with τ as a [witness](wikipedia://en/24879634)).

In the language of [von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) (NBG) and [Morse–Kelley set theory](wikipedia://en/2693655), the axiom of global choice can be stated directly (Fraenkel Bar-Hillel Levy 1973, p.133), and is equivalent to various other statements:

- Every class of nonempty sets has a [choice function](wikipedia://en/1432664).
- **V** \\ {∅} has a choice function (where **V** is the [class of all sets](wikipedia://en/445980)).
- There is a [well-ordering](https://en.wikipedia.org/wiki/Well-ordering) of **V**.
- There is a [bijection](wikipedia://en/3942) between **V** and the class of all [ordinal numbers](wikipedia://en/26547932).

In von Neumann–Bernays–Gödel set theory, global choice does not add any consequence about *sets* (not proper classes) beyond what could have been deduced from the ordinary axiom of choice.

Global choice is a consequence of the [axiom of limitation of size](wikipedia://en/5322450).
