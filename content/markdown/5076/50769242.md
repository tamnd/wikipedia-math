# Clean ring

::: {#o1 .subject cue=lead name="Clean ring"}

In [mathematics](wikipedia://en/18831), a **clean ring** is a [ring](wikipedia://en/48404) in which every element can be written as the sum of a [unit](wikipedia://en/289666) and an [idempotent](https://en.wikipedia.org/wiki/Idempotent_element_%28ring_theory%29). A ring is a [local ring](wikipedia://en/153391) if and only if it is clean and has no idempotents other than 0 and 1. The [endomorphism ring](wikipedia://en/59623) of a [continuous module](wikipedia://en/50319816) is a clean ring.[^o2] Every clean ring is an [exchange ring](https://en.wikipedia.org/wiki/Exchange_ring).[^o3] A [matrix ring](wikipedia://en/487541) over a clean ring is itself clean.[^o4] Every [Boolean ring](wikipedia://en/54356) is trivially a clean ring, since every element is idempotent.

:::
