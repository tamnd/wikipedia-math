# PMAC (cryptography)

::: {#o1 .subject cue=lead name="PMAC"}

**PMAC**, which stands for **parallelizable MAC**, is a [message authentication code](wikipedia://en/567523) algorithm. It was created by [Phillip Rogaway](https://en.wikipedia.org/wiki/Phillip_Rogaway). PMAC is a method of taking a [block cipher](wikipedia://en/4594) and creating an efficient message authentication code that is reducible in security to the underlying block cipher.

:::

PMAC is similar in functionality to the [OMAC](https://en.wikipedia.org/wiki/OMAC_%28cryptography%29) algorithm.

## Patents {#Patents}

PMAC is no longer patented and can be used royalty-free. It was originally patented by [Phillip Rogaway](https://en.wikipedia.org/wiki/Phillip_Rogaway), but he has since abandoned his patent filings.[^o3]
