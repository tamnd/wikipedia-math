# Nested interval topology

::: {#o1 .subject cue=lead name="Nested interval topology"}

In [mathematics](wikipedia://en/18831), more specifically [general topology](wikipedia://en/178649), the **nested interval topology** is an example of a topology given to the [open interval](https://en.wikipedia.org/wiki/Open_interval) (0,1), i.e. the [set](wikipedia://en/26691) of all [real numbers](wikipedia://en/20646438) *x* such that 0 \< *x* \< 1. The open interval (0,1) is the set of all real numbers *between* 0 and 1; but *not including* either 0 or 1.

:::

To give the set (0,1) a topology means to say which [subsets](wikipedia://en/27631) of (0,1) are "open", and to do so in a way that the following [axioms](wikipedia://en/928) are met:[^o2]

1. The [union](https://en.wikipedia.org/wiki/Union_%28mathematics%29) of open sets is an open set.
1. The finite [intersection](https://en.wikipedia.org/wiki/Intersection_%28mathematics%29) of open sets is an open set.
1. The set (0,1) and the [empty set](wikipedia://en/9566) ∅ are open sets.

::: {#o4 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

The set (0,1) and the empty set ∅ are required to be open sets, and so we define (0,1) and ∅ to be open sets in this topology. The other open sets in this topology are all of the form (0,1 − 1/*n*) where *n* is a positive [whole number](wikipedia://en/21474) greater than or equal to two i.e. *n* = 2, 3, 4, 5, ....[^o2]

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The nested interval topology is neither [Hausdorff](https://en.wikipedia.org/wiki/Hausdorff_topology) nor [T1](wikipedia://en/148721). In fact, if *x* is an element of (0,1), then the [closure](wikipedia://en/42309) of the [singleton set](https://en.wikipedia.org/wiki/Singleton_set) {*x*} is the [half-open interval](wikipedia://en/49172#Including_or_excluding_endpoints) \[1 − 1/*n*,1), where *n* is maximal such that *n* ≤ (1 − *x*)<sup>−1</sup>.[^o2]
- The nested interval topology is not [compact](wikipedia://en/6042). It is, however, [strongly Lindelöf](https://en.wikipedia.org/wiki/Lindelof_space) since there are only countably many open sets.[^o2]
- The nested interval topology is [hyperconnected](https://en.wikipedia.org/wiki/Irreducible_space) and hence [connected](wikipedia://en/6233).[^o2]
- The nested interval topology is [Alexandrov](wikipedia://en/542198).[^o2]

:::
