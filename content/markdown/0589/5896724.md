# Row equivalence

::: {#o1 .subject cue=lead name="Row equivalence"}

In [linear algebra](wikipedia://en/18422), two [matrices](wikipedia://en/20556859) are **row equivalent** if one can be changed to the other by a sequence of [elementary row operations](https://en.wikipedia.org/wiki/Elementary_row_operations). Alternatively, two *m* × *n* matrices are row equivalent if and only if they have the same [row space](https://en.wikipedia.org/wiki/Row_space). The concept is most commonly applied to matrices that represent [systems of linear equations](https://en.wikipedia.org/wiki/Systems_of_linear_equations), in which case two matrices of the same size are row equivalent if and only if the corresponding [homogeneous](https://en.wikipedia.org/wiki/Systems_of_linear_equations#Homogeneous_systems) systems have the same set of solutions, or equivalently the matrices have the same [null space](https://en.wikipedia.org/wiki/Null_space).

:::

Because elementary row operations are reversible, row equivalence is an [equivalence relation](wikipedia://en/9259). It is commonly denoted by a [tilde](wikipedia://en/212390) (~).[^o2]

There is a similar notion of **column equivalence**, defined by elementary column operations; two matrices are column equivalent if and only if their transpose matrices are row equivalent. Two rectangular matrices that can be converted into one another allowing both elementary row and column operations are called simply [equivalent](wikipedia://en/7838569).

## Elementary row operations {#Elementary_row_operations}

An [elementary row operation](https://en.wikipedia.org/wiki/Elementary_row_operations) is any one of the following moves:

1. **Swap:** Swap two rows of a matrix.
1. **Scale:** Multiply a row of a matrix by a nonzero constant.
1. **Pivot:** Add a multiple of one row of a matrix to another row.

Two matrices *A* and *B* are **row equivalent** if it is possible to transform *A* into *B* by a sequence of elementary row operations.

## Row space {#Row_space}

The row space of a matrix is the set of all possible [linear combinations](wikipedia://en/55632) of its row vectors. If the rows of the matrix represent a [system of linear equations](wikipedia://en/113087), then the row space consists of all linear equations that can be deduced algebraically from those in the system. Two *m* × *n* matrices are row equivalent if and only if they have the same row space.

For example, the matrices

$$\begin{pmatrix}1 & 0 & 0 \\ 0 & 1 & 1\end{pmatrix} \;\;\;\;\text{and}\;\;\;\; \begin{pmatrix}1 & 0 & 0 \\ 1 & 1 & 1\end{pmatrix}$$

are row equivalent, the row space being all vectors of the form $\begin{pmatrix}a & b & b\end{pmatrix}$. The corresponding systems of homogeneous equations convey the same information:

$$\begin{matrix}x = 0 \\ y+z=0\end{matrix}\;\;\;\;\text{and}\;\;\;\;\begin{matrix} x=0 \\ x+y+z=0.\end{matrix}$$

In particular, both of these systems imply every equation of the form $ax+by+bz=0.\,$

## Equivalence of the definitions {#Equivalence_of_the_definitions}

The fact that two matrices are row equivalent if and only if they have the same row space is an important theorem in linear algebra. The proof is based on the following observations:

1. Elementary row operations do not affect the row space of a matrix. In particular, any two row equivalent matrices have the same row space.
1. Any matrix can be [reduced](https://en.wikipedia.org/wiki/Row_reduction) by elementary row operations to a matrix in [reduced row echelon form](https://en.wikipedia.org/wiki/Reduced_row_echelon_form).
1. Two matrices in reduced row echelon form have the same row space if and only if they are equal.

This line of reasoning also proves that every matrix is row equivalent to a unique matrix with reduced row echelon form.

## Additional properties {#Additional_properties}

- Because the [null space](https://en.wikipedia.org/wiki/Null_space) of a matrix is the [orthogonal complement](wikipedia://en/1058833) of the [row space](https://en.wikipedia.org/wiki/Row_space), two matrices are row equivalent if and only if they have the same null space.
- The [rank](wikipedia://en/26561) of a matrix is equal to the [dimension](wikipedia://en/8398) of the row space, so row equivalent matrices must have the same rank. This is equal to the number of [pivots](wikipedia://en/9811503) in the reduced row echelon form.
- A matrix is [invertible](wikipedia://en/217122) if and only if it is row equivalent to the [identity matrix](wikipedia://en/59718).
- Matrices *A* and *B* are row equivalent if and only if there exists an invertible matrix *P* such that *A=PB*.[^o7]
