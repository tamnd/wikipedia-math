# Pósa's theorem

::: {#o1 .subject cue=lead name="Pósa's theorem"}

**Pósa's theorem**, in [graph theory](wikipedia://en/12401), is a [sufficient condition](https://en.wikipedia.org/wiki/Sufficient_condition) for the existence of a [Hamiltonian cycle](wikipedia://en/244437) based on the [degrees](wikipedia://en/1374448) of the [vertices](wikipedia://en/638899) in an undirected graph. It implies two other degree-based sufficient conditions, [Dirac's theorem on Hamiltonian cycles](https://en.wikipedia.org/wiki/Dirac's_theorem_on_Hamiltonian_cycles) and [Ore's theorem](wikipedia://en/3100586). Unlike those conditions, it can be applied to graphs with a small number of low-degree vertices. It is named after [Lajos Pósa](wikipedia://en/22874054), a protégé of [Paul Erdős](wikipedia://en/601284) born in 1947, who discovered this theorem in 1962.

:::

The Pósa condition for a finite undirected graph $G$ having $n$ vertices requires that, if the degrees of the $n$ vertices in increasing order as

$$d_{1} \leq d_{2} \leq ... \leq d_{n},$$

then for each index $k < n/2$ the inequality $k < d_{k}$ is satisfied.

Pósa's theorem states that if a finite undirected graph satisfies the Pósa condition, then that graph has a Hamiltonian cycle in it.
