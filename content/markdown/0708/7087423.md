# Boolean circuit

*Image: Three input boolean circuit.svg.* Example Boolean circuit. The ∧ nodes are AND gates, the ∨ nodes are OR gates, and the ¬ nodes are NOT gates.

::: {#o1 .subject cue=lead name="Boolean circuit"}

In [computational complexity theory](wikipedia://en/7543) and [circuit complexity](wikipedia://en/7641969), a **Boolean circuit** is a mathematical [model](wikipedia://en/1773278) for [combinational](wikipedia://en/89371) [digital logic circuits](https://en.wikipedia.org/wiki/Digital_electronics). A [formal language](wikipedia://en/10939) can be decided by a family of Boolean circuits, one circuit for each possible input length.

:::

Boolean circuits are defined in terms of the [logic gates](https://en.wikipedia.org/wiki/Logic_gate) they contain. For example, a circuit might contain [binary](wikipedia://en/3943) [AND](https://en.wikipedia.org/wiki/AND_gate) and [OR gates](https://en.wikipedia.org/wiki/OR_gate) and [unary](wikipedia://en/161006) [NOT gates](https://en.wikipedia.org/wiki/NOT_gate), or be entirely described by binary [NAND gates](https://en.wikipedia.org/wiki/NAND_gate). Each gate corresponds to some [Boolean function](wikipedia://en/753349) that takes a fixed number of [bits](https://en.wikipedia.org/wiki/Bit) as input and outputs a single bit.

Boolean circuits provide a model for many digital components used in [computer engineering](https://en.wikipedia.org/wiki/Computer_engineering), including [multiplexers](https://en.wikipedia.org/wiki/Multiplexer), [adders](https://en.wikipedia.org/wiki/Adder_%28electronics%29), and [arithmetic logic units](https://en.wikipedia.org/wiki/Arithmetic_logic_unit), but they exclude [sequential logic](https://en.wikipedia.org/wiki/Sequential_logic). They are an abstraction that omits many aspects relevant to designing real digital logic circuits, such as [metastability](https://en.wikipedia.org/wiki/Metastability_%28electronics%29), [fanout](https://en.wikipedia.org/wiki/Fanout), [glitches](https://en.wikipedia.org/wiki/Hazard_%28logic%29), [power consumption](https://en.wikipedia.org/wiki/Power_optimization_%28EDA%29), and [propagation delay](https://en.wikipedia.org/wiki/Propagation_delay) variability.

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

In giving a formal definition of Boolean circuits, [Vollmer](https://en.wikipedia.org/wiki/Heribert_Vollmer) starts by defining a basis as set *B* of Boolean functions, corresponding to the gates allowable in the circuit model. A Boolean circuit over a basis *B*, with *n* inputs and *m* outputs, is then defined as a finite [directed acyclic graph](wikipedia://en/204002). Each vertex corresponds to either a basis function or one of the inputs, and there is a set of exactly *m* nodes which are labeled as the outputs.[^o4] The edges must also have some ordering, to distinguish between different arguments to the same Boolean function.[^o4]

As a special case, a [propositional formula](wikipedia://en/1557634) or [Boolean expression](wikipedia://en/3126968) is a Boolean circuit with a single output node in which every other node has [fan-out](https://en.wikipedia.org/wiki/Fan-out) of 1. Thus, a Boolean circuit can be regarded as a generalization that allows shared subformulas and multiple outputs.

A common basis for Boolean circuits is the set {[AND](https://en.wikipedia.org/wiki/AND_gate), [OR](https://en.wikipedia.org/wiki/OR_gate), [NOT](https://en.wikipedia.org/wiki/NOT_gate)}, which is [functionally complete](wikipedia://en/5279259), i.e. from which all other Boolean functions can be constructed.

## Computational complexity {#Computational_complexity}

### Background {#Background}

A particular circuit acts only on inputs of fixed size. However, [formal languages](wikipedia://en/10939) (the [string-based](wikipedia://en/27701) representations of [decision problems](wikipedia://en/8336)) contain strings of different lengths, so languages cannot be fully captured by a single circuit (in contrast to the Turing machine model, in which a language is fully described by a single Turing machine). A language is instead represented by a *circuit family*. A circuit family is an infinite list of circuits $(C_0,C_1,C_2,...)$, where $C_n$ has $n$ input variables. A circuit family is said to decide a language $L$ if, for every string $w$, $w$ is in the language $L$ if and only if $C_n(w)=1$, where $n$ is the length of $w$. In other words, a language is the set of strings which, when applied to the circuits corresponding to their lengths, evaluate to 1.[^o8]

### Complexity measures {#Complexity_measures}

Several important [complexity measures](wikipedia://en/7543) can be defined on Boolean circuits, including circuit depth, circuit size, and the number of alternations between AND gates and OR gates. For example, the size complexity of a Boolean circuit is the number of gates in the circuit.

There is a natural connection between circuit size complexity and [time complexity](wikipedia://en/405944).[^o8] Intuitively, a language with small time complexity (that is, requires relatively few sequential operations on a [Turing machine](wikipedia://en/30403)), also has a small circuit complexity (that is, requires relatively few Boolean operations). Formally, it can be shown that if a language is in $\mathsf{TIME}(t(n))$, where $t$ is a function $t:\mathbb{N} \to \mathbb{N}$, then it has circuit size complexity $O(t^2(n))$.

### Complexity classes {#Complexity_classes}

Several important complexity classes are defined in terms of Boolean circuits. The most general of these is [P/poly](wikipedia://en/2052415), the set of languages that are decidable by polynomial-size circuit families. It follows directly from the fact that languages in $\mathsf{TIME}(t(n))$ have circuit complexity $O(t^2(n))$ that [P](wikipedia://en/658550)$\subseteq$P/poly. In other words, any problem that can be computed in polynomial time by a deterministic Turing machine can also be computed by a polynomial-size circuit family. It is further the case that the inclusion is proper (i.e. P$\subsetneq$P/poly) because there are undecidable problems that are in P/poly. P/poly turns out to have a number of properties that make it highly useful in the study of the relationships between complexity classes. In particular, it is helpful in investigating problems related to [P versus NP](https://en.wikipedia.org/wiki/P_versus_NP). For example, if there is any language in NP that is not in P/poly then P$\neq$NP.[^o11] P/poly also helps to investigate properties of the [polynomial hierarchy](wikipedia://en/658651). For example, if [NP](wikipedia://en/21562) ⊆ P/poly, then PH collapses to $\Sigma_2^{\mathsf P}$. A full description of the relations between P/poly and other complexity classes is available at "[Importance of P/poly](wikipedia://en/2052415#Importance_of_P/poly)". P/poly also has the interesting feature that it can be equivalently defined as the class of languages recognized by a polynomial-time Turing machine with a polynomial-bounded [advice function](wikipedia://en/665843).

Two subclasses of P/poly that have interesting properties in their own right are [NC](wikipedia://en/22073) and [AC](wikipedia://en/7401755). These classes are defined not only in terms of their circuit size but also in terms of their *depth*. The depth of a circuit is the length of the longest [directed path](https://en.wikipedia.org/wiki/Directed_path) from an input node to the output node. The class NC is the set of languages that can be solved by circuit families that are restricted not only to having polynomial-size but also to having [polylogarithmic](https://en.wikipedia.org/wiki/Polylogarithmic) depth. The class AC is defined similarly to NC, however gates are allowed to have unbounded fan-in (that is, the AND and OR gates can be applied to more than two bits). NC is an important class because it turns out that it represents the class of languages that have efficient [parallel algorithms](https://en.wikipedia.org/wiki/Parallel_algorithm).

### Circuit evaluation {#Circuit_evaluation}

The [circuit value problem](https://en.wikipedia.org/wiki/Circuit_value_problem) — the problem of computing the output of a given Boolean circuit on a given input [string](https://en.wikipedia.org/wiki/Binary_string) — is a [P-complete](wikipedia://en/54683) [decision problem](wikipedia://en/8336).[^o11] Therefore, this problem is considered to be "inherently sequential" in the sense that there is likely no efficient, highly parallel algorithm that solves the problem.

### Completeness {#Completeness}

Logic circuits are physical representation of simple logic operations, AND, OR and NOT (and their combinations, such as non-sequential flip-flops or circuit networks), that form a mathematical structure known as [Boolean algebra](wikipedia://en/54476844). They are complete in sense that they can perform any deterministic algorithm. However, it just happens that this is not all there is. In the physical world we also encounter randomness, notable in small systems governed by quantization effects, which is described by theory of [quantum mechanics](wikipedia://en/25202). Logic circuits cannot produce any randomness, and in that sense they form an incomplete logic set. Remedy to that is found in adding an ad-hoc random bit generator to logic networks, or computers, such as in [probabilistic Turing machine](wikipedia://en/197812). A recent work[^o14] has introduced a theoretical concept of an inherently random logic circuit named *random flip-flop*, which completes the set. It conveniently packs randomness and is inter-operable with deterministic Boolean logic circuits. However, an algebraic structure equivalent of Boolean algebra and associated methods of circuit construction and reduction for the extended set is yet unknown.
