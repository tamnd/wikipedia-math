# Omnitruncation

::: {#o1 .subject cue=lead name="Omnitruncation"}

In [geometry](wikipedia://en/18973446), an **omnitruncation** of a [convex polytope](wikipedia://en/1817885) is a [simple polytope](wikipedia://en/8853286) of the same dimension, having a vertex for each [flag](wikipedia://en/9352497) of the original polytope and a [facet](wikipedia://en/7186647) for each face of any dimension of the original polytope. Omnitruncation is the [dual](wikipedia://en/8815) operation to [barycentric subdivision](wikipedia://en/583651).[^o2] Because the barycentric subdivision of any polytope can be realized as another polytope,[^o3] the same is true for the omnitruncation of any polytope.

:::

When omnitruncation is applied to a [regular polytope](wikipedia://en/518693) (or [honeycomb](wikipedia://en/6008654)) it can be described geometrically as a [Wythoff construction](wikipedia://en/2950777) that creates a maximum number of [facets](wikipedia://en/7186647). It is represented in a [Coxeter–Dynkin diagram](wikipedia://en/5358554) with all nodes ringed.

It is a *shortcut* term which has a different meaning in progressively-higher-dimensional polytopes:

- [Uniform polytope truncation operators](wikipedia://en/6842392#Truncation_operators)
  - For [regular polygons](wikipedia://en/333306): [An ordinary truncation](wikipedia://en/4224429), $t_{0,1}\{ p \} = t\{ p\} = \{ 2p\}$.
    - [Coxeter-Dynkin diagram](https://en.wikipedia.org/wiki/Coxeter-Dynkin_diagram)
  - For [uniform polyhedra](wikipedia://en/2537223) (3-polytopes): [A cantitruncation](wikipedia://en/2537223#Definition_of_operations), $t_{0,1,2}\{ p,q \} = tr\{ p,q\}$. (Application of both [cantellation](https://en.wikipedia.org/wiki/Cantellation) and truncation operations)
    - Coxeter-Dynkin diagram:
  - For [uniform polychora](wikipedia://en/1645899): [A runcicantitruncation](wikipedia://en/1645899#Geometric_derivations_for_46_nonprismatic_Wythoffian_uniform_4-polytopes), $t_{0,1,2,3}\{ p,q,r \}$. (Application of [runcination](https://en.wikipedia.org/wiki/Runcination), cantellation, and truncation operations)
    - Coxeter-Dynkin diagram: , ,
  - For [uniform polytera](wikipedia://en/14415338) (5-polytopes): [A steriruncicantitruncation](wikipedia://en/14415338#Notes_on_the_Wythoff_construction_for_the_uniform_5-polytopes), t<sub>0,1,2,3,4</sub>{p,q,r,s}. $t_{0,1,2,3,4}\{ p,q,r,s \}$. (Application of [sterication](https://en.wikipedia.org/wiki/Sterication), runcination, cantellation, and truncation operations)
    - Coxeter-Dynkin diagram: , ,
  - For [uniform n-polytopes](wikipedia://en/6842392): $t_{0,1,...,n-1}\{ p_1, p_2,...,p_n \}$.
