# Cardinality of the continuum

::: {#o1 .subject cue=lead name="Cardinality of the continuum"}

In [set theory](wikipedia://en/27553), the **cardinality of the continuum** is the [cardinality](wikipedia://en/6174) or "size" of the [set](wikipedia://en/26691) of [real numbers](https://en.wikipedia.org/wiki/Real_numbers) $\mathbb R$, sometimes called the [continuum](wikipedia://en/24758677). It is an [infinite](wikipedia://en/142679) [cardinal number](wikipedia://en/6173) and is denoted by $\mathbf\mathfrak c$ (lowercase [Fraktur](https://en.wikipedia.org/wiki/Fraktur) "**c**") or $\mathbf|\mathbf\mathbb R\mathbf|.$[^o2]

:::

The real numbers $\mathbb R$ are more numerous than the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $\mathbb N$. Moreover, $\mathbb R$ has the same number of elements as the [power set](wikipedia://en/23799) of $\mathbb N$. Symbolically, if the cardinality of $\mathbb N$ is denoted as [$\aleph_0$](wikipedia://en/293961#Aleph-nought), the cardinality of the continuum is $\mathfrak c = 2^{\aleph_0} > \aleph_0.$ This was proven by [Georg Cantor](wikipedia://en/12216) in his [uncountability proof](https://en.wikipedia.org/wiki/Cantor's_first_uncountability_proof) of 1874, part of his groundbreaking study of different infinities. The inequality was later stated more simply in his [diagonal argument](wikipedia://en/51426) in 1891. Cantor defined cardinality in terms of [bijective functions](https://en.wikipedia.org/wiki/Bijective_function): two sets have the same cardinality if, and only if, there exists a bijective function between them.

Between any two real numbers *a* \< *b*, no matter how close they are to each other, there are always infinitely many other real numbers, and Cantor showed that they are as many as those contained in the whole set of real numbers. In other words, the [open interval](https://en.wikipedia.org/wiki/Open_interval) (*a*,*b*) is [equinumerous](https://en.wikipedia.org/wiki/Equinumerous) with $\mathbb R$, as well as with several other infinite sets, such as any *n*-dimensional [Euclidean space](wikipedia://en/9697) $\mathbb R^n$ (see [space filling curve](https://en.wikipedia.org/wiki/Space_filling_curve)). That is, $|(a,b)| = |\mathbb R| = |\mathbb R^n|.$

The smallest infinite cardinal number is $\aleph_0$ ([aleph-null](wikipedia://en/293961#Aleph-nought)). The second smallest is $\aleph_1$ ([aleph-one](wikipedia://en/293961#Aleph-one)). The [continuum hypothesis](wikipedia://en/5705), which asserts that there are no sets whose cardinality is strictly between $\aleph_0$ and $\mathfrak c$, means that $\mathfrak c = \aleph_1$.[^o3] This hypothesis is [independent](https://en.wikipedia.org/wiki/Logical_independence) of the widely used [Zermelo–Fraenkel set theory](wikipedia://en/152214) with axiom of choice (ZFC); that is, ZFC can neither prove that it is true nor that it is false.

## Properties {#Properties}

### Uncountability {#Uncountability}

[Georg Cantor](wikipedia://en/12216) introduced the concept of [cardinality](wikipedia://en/6174) to compare the sizes of infinite sets. He famously showed that the set of real numbers is [uncountably infinite](https://en.wikipedia.org/wiki/Uncountably_infinite). That is, ${\mathfrak c}$ is strictly greater than the cardinality of the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), $\aleph_0$: $\aleph_0 < \mathfrak c.$ In practice, this means that there are strictly more real numbers than there are integers. Cantor proved this statement in several different ways. For more information on this topic, see [Cantor's first uncountability proof](https://en.wikipedia.org/wiki/Cantor's_first_uncountability_proof) and [Cantor's diagonal argument](wikipedia://en/51426).

### Cardinal equalities {#Cardinal_equalities}

A variation of Cantor's diagonal argument can be used to prove [Cantor's theorem](wikipedia://en/341442), which states that the cardinality of any set is strictly less than that of its [power set](wikipedia://en/23799). That is, $|A| < 2^{|A|}$ (and so that the power set $\wp(\mathbb N)$ of the [natural numbers](wikipedia://en/21474) $\mathbb N$ is uncountable). In fact, the cardinality of $\wp(\mathbb N)$, by definition $2^{\aleph_0}$, is equal to ${\mathfrak c}$. This can be shown by providing one-to-one mappings in both directions between subsets of a countably infinite set and real numbers, and applying the [Cantor–Bernstein–Schroeder theorem](https://en.wikipedia.org/wiki/Cantor–Bernstein–Schroeder_theorem) according to which two sets with one-to-one mappings in both directions have the same cardinality.[^o9][^o10] In one direction, reals can be equated with [Dedekind cuts](wikipedia://en/45569), sets of rational numbers,[^o9] or with their [binary expansions](https://en.wikipedia.org/wiki/Binary_expansion).[^o10] In the other direction, the binary expansions of numbers in the half-open interval $[0,1)$, viewed as sets of positions where the expansion is one, almost give a one-to-one mapping from subsets of a countable set (the set of positions in the expansions) to real numbers, but it fails to be one-to-one for numbers with terminating binary expansions, which can also be represented by a non-terminating expansion that ends in a repeating sequence of 1s. This can be made into a one-to-one mapping by that adds one to the non-terminating repeating-1 expansions, mapping them into $[1,2)$.[^o10] Thus, we conclude that[^o9][^o10] $\mathfrak c = |\wp(\mathbb{N})| = 2^{\aleph_0}.$

The cardinal equality $\mathfrak{c}^2 = \mathfrak{c}$ can be demonstrated using [cardinal arithmetic](https://en.wikipedia.org/wiki/Cardinal_arithmetic): $\mathfrak{c}^2 = (2^{\aleph_0})^2 = 2^{2\times{\aleph_0}} = 2^{\aleph_0} = \mathfrak{c}.$

By using the rules of cardinal arithmetic, one can also show that

$$\mathfrak c^{\aleph_0} = {\aleph_0}^{\aleph_0} = n^{\aleph_0} = \mathfrak c^n = \aleph_0 \mathfrak c = n \mathfrak c = \mathfrak c$$

where *n* is any finite cardinal ≥ 2 and

$$\mathfrak c ^{\mathfrak c} = (2^{\aleph_0})^{\mathfrak c} = 2^{\mathfrak c\times\aleph_0} = 2^{\mathfrak c}$$

where $2 ^{\mathfrak c}$ is the cardinality of the power set of **R**, and $2 ^{\mathfrak c} > \mathfrak c$.

### Alternative explanation for 𝔠 = 2<sup>א<sub>‎0</sub></sup> {#Alternative_explanation_for}

Every real number has at least one infinite [decimal expansion](https://en.wikipedia.org/wiki/Decimal_expansion). For example, 1/2 = 0.50000... 1/3 = 0.33333... π = 3.14159.... (This is true even in the case the expansion repeats, as in the first two examples.)

In any given case, the number of decimal places is [countable](wikipedia://en/6026) since they can be put into a [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence) with the set of natural numbers $\mathbb{N}$. This makes it sensible to talk about, say, the first, the one-hundredth, or the millionth decimal place of π. Since the natural numbers have cardinality $\aleph_0,$ each real number has $\aleph_0$ digits in its expansion.

Since each real number can be broken into an integer part and a decimal fraction, we get: ${\mathfrak c} \leq \aleph_0 \cdot 10^{\aleph_0} \leq 2^{\aleph_0} \cdot {(2^4)}^{\aleph_0} = 2^{\aleph_0 + 4 \cdot \aleph_0} = 2^{\aleph_0}$

where we used the fact that

$$\aleph_0 + 4 \cdot \aleph_0 = \aleph_0 \,.$$

On the other hand, if we map $2 = \{0, 1\}$ to $\{3, 7\}$ and consider that decimal fractions containing only 3 or 7 are only a part of the real numbers, then we get

$$2^{\aleph_0} \leq {\mathfrak c} \,$$

and thus ${\mathfrak c} = 2^{\aleph_0} \,.$

## Beth numbers {#Beth_numbers}

The sequence of beth numbers is defined by setting $\beth_0 = \aleph_0$ and $\beth_{k+1} = 2^{\beth_k}$. So ${\mathfrak c}$ is the second beth number, **beth-one**: $\mathfrak c = \beth_1.$ The third beth number, **beth-two**, is the cardinality of the power set of $\mathbb{R}$ (i.e. the set of all subsets of the [real line](https://en.wikipedia.org/wiki/Real_line)): $2^\mathfrak c = \beth_2.$

:::

::: {#o15 .statement kind=statement/conjecture cue=named-heading name="The continuum hypothesis"}

## The continuum hypothesis {#The_continuum_hypothesis}

The continuum hypothesis asserts that ${\mathfrak c}$ is also the second [aleph number](wikipedia://en/293961), $\aleph_1$.[^o3] In other words, the continuum hypothesis states that there is no set $A$ whose cardinality lies strictly between $\aleph_0$ and ${\mathfrak c}$ $\nexists A \quad:\quad \aleph_0 < |A| < \mathfrak c.$ This statement is now known to be independent of the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214) with the axiom of choice (ZFC), as shown by [Kurt Gödel](wikipedia://en/16736) and [Paul Cohen](wikipedia://en/22994).[^o16][^o17][^o18] That is, both the hypothesis and its negation are consistent with these axioms. In fact, for every nonzero [natural number](wikipedia://en/21474) *n*, the equality ${\mathfrak c}$ = $\aleph_n$ is independent of ZFC (case $n=1$ being the continuum hypothesis). The same is true for most other alephs, although in some cases, equality can be ruled out by [König's theorem](https://en.wikipedia.org/wiki/König's_theorem_%28set_theory%29) on the grounds of [cofinality](wikipedia://en/6693) (e.g. $\mathfrak{c}\neq\aleph_\omega$). In particular, $\mathfrak{c}$ could be either $\aleph_1$ or $\aleph_{\omega_1}$, where $\omega_1$ is the [first uncountable ordinal](wikipedia://en/20860540), so it could be either a [successor cardinal](wikipedia://en/375210) or a [limit cardinal](wikipedia://en/374002), and either a [regular cardinal](wikipedia://en/374128) or a [singular cardinal](https://en.wikipedia.org/wiki/Singular_cardinal).

:::

## Sets with cardinality of the continuum {#Sets_with_cardinality_of_the_continuum}

A great many sets studied in mathematics have cardinality equal to ${\mathfrak c}$. Some common examples are the following:

the [real numbers](wikipedia://en/20646438) $\mathbb{R}$; any ([nondegenerate](wikipedia://en/232952)) closed or open [interval](wikipedia://en/49172) in $\mathbb{R}$ (such as the [unit interval](wikipedia://en/49324) $[0,1]$); the [irrational numbers](wikipedia://en/20647689); the [transcendental numbers](https://en.wikipedia.org/wiki/Transcendental_numbers) The set of real [algebraic numbers](wikipedia://en/1158) is countably infinite (assign to each formula its [Gödel number](wikipedia://en/207790).) So the cardinality of the real algebraic numbers is $\aleph_0$. Furthermore, the real algebraic numbers and the real transcendental numbers are disjoint sets whose union is $\mathbb R$. Thus, since the cardinality of $\mathbb R$ is $\mathfrak c$, the cardinality of the real transcendental numbers is $\mathfrak c - \aleph_0 = \mathfrak c$. A similar result follows for complex transcendental numbers, once we have proved that $\left\vert \mathbb{C} \right\vert = \mathfrak c$.; the [Cantor set](wikipedia://en/6172); [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$[^o20]; the [complex numbers](wikipedia://en/5826) $\mathbb{C}$ Per Cantor's proof of the cardinality of Euclidean space,[^o20] $\left\vert \mathbb{R}^2 \right\vert = \mathfrak c$. By definition, any $c\in \mathbb{C}$ can be uniquely expressed as $a + bi$ for some $a,b \in \mathbb{R}$. We therefore define the bijection $\begin{aligned} f\colon \mathbb{R}^2 &\to \mathbb{C}\\ (a,b) &\mapsto a+bi \end{aligned}$; the [power set](wikipedia://en/23799) of the [natural numbers](wikipedia://en/21474) $\mathcal{P}(\mathbb{N})$ (the set of all subsets of the natural numbers); the set of [sequences](https://en.wikipedia.org/wiki/Sequences) of integers (i.e. all functions $\mathbb{N} \rightarrow \mathbb{Z}$, often denoted $\mathbb{Z}^\mathbb{N}$); the set of sequences of real numbers, $\mathbb{R}^\mathbb{N}$; the set of all [continuous](wikipedia://en/6122) functions from $\mathbb{R}$ to $\mathbb{R}$; the [Euclidean topology](wikipedia://en/1482085) on $\mathbb{R}^n$ (i.e. the set of all [open sets](wikipedia://en/39358) in $\mathbb{R}^n$); the [Borel σ-algebra](https://en.wikipedia.org/wiki/Borel_algebra) on $\mathbb{R}$ (i.e. the set of all [Borel sets](wikipedia://en/43327) in $\mathbb{R}$).; the abelian quotient group $\mathbb{R}/\mathbb{Q}$, assuming the Axiom of Choice

## Sets with greater cardinality {#Sets_with_greater_cardinality}

Sets with cardinality greater than ${\mathfrak c}$ include:

- the set of all subsets of $\mathbb{R}$ (i.e., power set $\mathcal{P}(\mathbb{R})$)
- the set [2<sup>**R**</sup>](wikipedia://en/23799#Representing_subsets_as_functions) of [indicator functions](wikipedia://en/240790) defined on subsets of the reals (the set $2^{\mathbb{R}}$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to $\mathcal{P}(\mathbb{R})$ – the indicator function chooses elements of each subset to include)
- the set $\mathbb{R}^\mathbb{R}$ of all functions from $\mathbb{R}$ to $\mathbb{R}$
- the [Lebesgue σ-algebra](wikipedia://en/18198) of $\mathbb{R}$, i.e., the set of all [Lebesgue measurable](https://en.wikipedia.org/wiki/Lebesgue_measurable) sets in $\mathbb{R}$.
- the set of all [Lebesgue-integrable](https://en.wikipedia.org/wiki/Lebesgue_integration) functions from $\mathbb{R}$ to $\mathbb{R}$
- the set of all [Lebesgue-measurable](wikipedia://en/44055) functions from $\mathbb{R}$ to $\mathbb{R}$
- the [Stone–Čech compactifications](wikipedia://en/52897) of $\mathbb{N}$, $\mathbb{Q}$, and $\mathbb{R}$
- the set of all automorphisms of the (discrete) field of complex numbers.

These all have cardinality $2^\mathfrak c = \beth_2$ ([beth two](wikipedia://en/393359#Beth_two)).
