# Elbow method (clustering)

::: {#o1 .subject cue=lead name="Elbow method"}

*Image: DataClustering ElbowCriterion.JPG.* Explained variance. The "elbow" is indicated by the red circle. The number of clusters chosen should therefore be 4.

In [cluster analysis](wikipedia://en/669675), the **elbow method** is a [heuristic](https://en.wikipedia.org/wiki/Heuristic) used in [determining the number of clusters in a data set](wikipedia://en/22324566). The method consists of plotting the [explained variation](wikipedia://en/14921993) as a function of the number of clusters and picking the [elbow of the curve](https://en.wikipedia.org/wiki/Elbow_of_the_curve) as the number of clusters to use. The same method can be used to choose the number of parameters in other data-driven models, such as the number of [principal components](https://en.wikipedia.org/wiki/Principal_component) to describe a data set.

:::

The method can be traced to speculation by [Robert L. Thorndike](https://en.wikipedia.org/wiki/Robert_L._Thorndike) in 1953.[^o2]

## Intuition {#Intuition}

Using the "elbow" or "[knee of a curve](wikipedia://en/63699886)" as a cutoff point is a common heuristic in [mathematical optimization](wikipedia://en/52033) to choose a point where [diminishing returns](https://en.wikipedia.org/wiki/Diminishing_returns) are no longer worth the additional cost. In clustering, this means one should choose a number of clusters so that adding another cluster doesn't give much better modeling of the data.

The intuition is that increasing the number of clusters will naturally improve the fit (explain more of the variation), since there are more parameters (more clusters) to use, but that at some point this is [over-fitting](https://en.wikipedia.org/wiki/Over-fitting), and the elbow reflects this. For example, given data that actually consist of *k* labeled groups – for example, *k* points sampled with noise – clustering with more than *k* clusters will "explain" more of the variation (since it can use smaller, tighter clusters), but this is over-fitting, since it is subdividing the labeled groups into multiple clusters. The idea is that the first clusters will add much information (explain a lot of variation), since the data actually consist of that many groups (so these clusters are necessary), but once the number of clusters exceeds the actual number of groups in the data, the added information will drop sharply, because it is just subdividing the actual groups. Assuming this happens, there will be a sharp elbow in the graph of explained variation versus clusters: increasing rapidly up to *k* ([under-fitting](https://en.wikipedia.org/wiki/Under-fitting) region), and then increasing slowly after *k* (over-fitting region).

## Criticism {#Criticism}

The elbow method is considered both subjective and unreliable. In many practical applications, the choice of an "elbow" is highly ambiguous as the plot does not contain a sharp elbow.[^o5] This can even hold in cases where all other methods for [determining the number of clusters in a data set](wikipedia://en/22324566) (as mentioned in that article) agree on the number of clusters.

*Image: Elbow in Inertia on uniform data.png.* The typical "elbow" pattern used for choosing the number of clusters emerges even for uniform data.

Even on uniform random data with no meaningful clusters, the curve follows the ratio *1/k*, causing users to see an "elbow" to mistakenly choose some "optimal" number of clusters.[^o6] Because the number of clusters and the remaining variance have no semantic relationship, various attempt to capture the elbow by "slope" are ill-defined and sensitive to the parameter range.[^o6]

## Measures of variation {#Measures_of_variation}

There are various measures of "[explained variation](wikipedia://en/14921993)" used in the elbow method. Most commonly, variation is quantified by *[variance](wikipedia://en/32344)*, and the ratio used is the ratio of between-group variance to the total variance. Alternatively, one uses the ratio of between-group variance to within-group variance, which is the one-way [ANOVA](https://en.wikipedia.org/wiki/ANOVA) [*F*-test statistic](https://en.wikipedia.org/wiki/F-test_statistic).[^o8]
