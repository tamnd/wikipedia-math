# Real element

::: {#o1 .subject cue=lead name="Real element"}

In [group theory](wikipedia://en/41890), a discipline within modern algebra, an element $x$ of a [group](wikipedia://en/19447) $G$ is called a **real element** of $G$ if it belongs to the same [conjugacy class](wikipedia://en/49176) as its [inverse](wikipedia://en/45199) $x^{-1}$, that is, if there is a $g$ in $G$ with $x^g = x^{-1}$, where $x^g$ is defined as $g^{-1} \cdot x \cdot g$.[^n1] An element $x$ of a group $G$ is called **strongly real** if there is an [involution](https://en.wikipedia.org/wiki/Involution_%28group_theory%29) $t$ with $x^t = x^{-1}$.[^n2]

:::

An element $x$ of a group $G$ is real if and only if for all [representations](wikipedia://en/12695) $\rho$ of $G$, the [trace](wikipedia://en/43270) $\mathrm{Tr}(\rho(g))$ of the corresponding matrix is a [real number](wikipedia://en/20646438). In other words, an element $x$ of a group $G$ is real if and only if $\chi(x)$ is a real number for all [characters](wikipedia://en/691741) $\chi$ of $G$.[^n3]

A group with every element real is called an [ambivalent group](https://en.wikipedia.org/wiki/Ambivalent_group). Every ambivalent group has a real [character table](wikipedia://en/911520). The [symmetric group](wikipedia://en/28901) $S_n$ of any degree $n$ is ambivalent.

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

A group with real elements other than the identity element necessarily is of even [order](wikipedia://en/493527).[^n3]

For a real element $x$ of a group $G$, the number of group elements $g$ with $x^g = x^{-1}$ is equal to $\left|C_G(x)\right|$,[^n1] where $C_G(x)$ is the [centralizer](https://en.wikipedia.org/wiki/Centralizer) of $x$,

$$\mathrm{C}_G(x) = \{ g \in G\mid x^g = x \}.$$

Every involution is strongly real. Furthermore, every element that is the product of two involutions is strongly real. Conversely, every strongly real element is the product of two involutions.

If $x \ne e$ and $x$ is real in $G$ and $\left|C_G(x)\right|$ is odd, then $x$ is strongly real in $G$.

:::

## Extended centralizer {#Extended_centralizer}

The **extended centralizer** of an element $x$ of a group $G$ is defined as

$$\mathrm{C}^*_G(x) = \{ g \in G\mid x^g = x \lor x^g = x^{-1} \},$$

making the extended centralizer of an element $x$ equal to the [normalizer](https://en.wikipedia.org/wiki/Normalizer) of the set $\left\{x, x^{-1}\right\}$.[^n4]

The extended centralizer of an element of a group $G$ is always a subgroup of $G$. For involutions or non-real elements, centralizer and extended centralizer are equal.[^n1] For a real element $x$ of a group $G$ that is not an involution,

$$\left|\mathrm{C}^*_G(x):\mathrm{C}_G(x)\right| = 2.$$
