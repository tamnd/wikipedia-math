# Elementary theory of the category of sets

::: {#o1 .subject cue=lead name="Elementary theory of the category of sets"}

In mathematics, the **elementary theory of the category of sets** or **ETCS** is a set of [axioms](wikipedia://en/928) for [set theory](wikipedia://en/27553) proposed by [William Lawvere](wikipedia://en/872760) in 1964.[^o2] Although it was originally stated in the language of [category theory](wikipedia://en/5869), as [Tom Leinster](wikipedia://en/78103499) pointed out, the axioms can be stated without references to category theory.

:::

ETCS is a basic example of [structural set theory](wikipedia://en/78527273), an approach to set theory that emphasizes sets as abstract structures (as opposed to collections of elements).

::: {#o4 .statement kind=statement/axiom cue=named-heading name="Axioms"}

## Axioms {#Axioms}

The real message is this: simply by writing down a few mundane, uncontroversial statements about sets and functions, we arrive at an axiomatization that reflects how sets are used in everyday mathematics.

Informally, the axioms are as follows: (here, set, function and composition of functions are primitives)[^o6]

1. Composition of functions is associative and has identities.
1. There is a set with exactly one element.
1. There is an empty set.
1. A function is determined by its effect on elements.
1. A Cartesian product exists for a pair of sets.
1. Given sets $X$ and $Y$, there is a set of all functions from $X$ to $Y$.
1. Given $f : X \to Y$ and an element $y \in Y$, the pre-image $f^{-1}(y)$ is defined.
1. The subsets of a set $X$ correspond to the functions $X \to \{0, 1\}$.
1. The natural numbers form a set.
1. (weak [axiom of choice](wikipedia://en/840)) Every surjection has a right inverse (i.e., a section).

The resulting theory is weaker than [ZFC](https://en.wikipedia.org/wiki/ZFC). If the [axiom schema of replacement](wikipedia://en/52387) is added as another axiom, the resulting theory is equivalent to ZFC.[^n1]

:::
