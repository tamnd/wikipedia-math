# SXAL/MBAL

::: {#o1 .subject cue=lead name="SXAL/MBAL"}

In [cryptography](wikipedia://en/18934432), **SXAL** (substitution xor algorithm, sometimes called **SXAL8**) is a [block cipher](wikipedia://en/4594) designed in 1993 by [Yokohama](https://en.wikipedia.org/wiki/Yokohama)-based [Laurel Intelligent Systems](https://en.wikipedia.org/wiki/Laurel_Intelligent_Systems). It is normally used in a special [mode of operation](https://en.wikipedia.org/wiki/Block_cipher_modes_of_operation) called **MBAL** (multi-block algorithm). SXAL/MBAL has been used for encryption in a number of Japanese [PC cards](https://en.wikipedia.org/wiki/PC_card) and [smart cards](https://en.wikipedia.org/wiki/Smart_card).

:::

SXAL is an 8-round [substitution–permutation network](https://en.wikipedia.org/wiki/Substitution–permutation_network) with [block size](wikipedia://en/294065) and [key size](wikipedia://en/5749) of 64 bits each. All operations are byte-oriented. The algorithm uses a single 8×8-bit [S-box](https://en.wikipedia.org/wiki/Substitution_box) *K*, designed so that both K(X) and X [XOR](https://en.wikipedia.org/wiki/XOR) K(X) are [injective functions](wikipedia://en/45196). In each round, the bytes of the block are first permuted. Then each byte is XORed with a key byte and an earlier [ciphertext byte](wikipedia://en/175560), processed through the S-box, and XORed with the previous plaintext byte.

The [key schedule](wikipedia://en/609603) is rather complex, processing the [key](wikipedia://en/53039) with SXAL itself, beginning with a null key and using permuted intermediate results as later keys.

## MBAL {#MBAL}

MBAL is an encryption algorithm built using SXAL that can be applied to messages any number of bytes in length (at least 8). It uses two 64-bit extended keys for [key whitening](wikipedia://en/2990178) on the first 64 bits. The algorithm consists of 9 steps:

1. Pre-whitening
1. F<sub>m</sub>: An expanded version of SXAL applied to the entire message
1. SXAL the block consisting of the first 4 and last 4 bytes
1. Reverse the byte order of the entire message
1. F<sub>m</sub>
1. Reverse
1. SXAL the ends
1. F<sub>m</sub>
1. Post-whitening

MBAL has been shown to be susceptible to both [differential cryptanalysis](wikipedia://en/8536) and [linear cryptanalysis](wikipedia://en/59469).[^o3]
