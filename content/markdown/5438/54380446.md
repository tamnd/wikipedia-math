# Euler–Boole summation

::: {#o1 .subject cue=lead name="Euler–Boole summation"}

In [mathematics](wikipedia://en/18831), **Euler–Boole summation** is a method for summing [alternating series](wikipedia://en/494308). The concept is named after [Leonhard Euler](wikipedia://en/17902) and [George Boole](wikipedia://en/38298). Boole published this summation method, using [Euler's polynomials](https://en.wikipedia.org/wiki/Euler's_polynomials), but the method itself was likely already known to Euler.
