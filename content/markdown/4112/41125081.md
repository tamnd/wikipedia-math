# Connective spectrum

::: {#o1 .subject cue=lead name="Connective spectrum"}

In [algebraic topology](wikipedia://en/38801), a branch of [mathematics](wikipedia://en/18831), a **connective spectrum** is a [spectrum](wikipedia://en/1033697) whose [homotopy](wikipedia://en/212250) sets $\pi_k$ of negative degrees are zero.[^o2]

:::
