# Hyper-Erlang distribution

::: {#o1 .subject cue=lead name="Hyper-Erlang distribution"}

*Image: Hyper-Erlang distribution.svg.* Diagram showing queueing system equivalent of a hyper-Erlang distribution

In [probability theory](wikipedia://en/23542), a **hyper-Erlang distribution** is a [continuous probability distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution) which takes a particular [Erlang distribution](wikipedia://en/199028) E<sub>*i*</sub> with probability *p*<sub>*i*</sub>. A hyper-Erlang distributed random variable *X* has a [probability density function](wikipedia://en/43487) given by

:::

$$A(x) = \sum_{i=1}^n p_i E_{l_i}(x)$$

where each *p*<sub>*i*</sub> > 0 with the *p*<sub>*i*</sub> summing to 1 and each of the E<sub>*l*<sub>*i*</sub></sub> being an [Erlang distribution](wikipedia://en/199028) with *l*<sub>*i*</sub> stages each of which has parameter *λ*<sub>*i*</sub>.[^o2][^o3][^o4]
