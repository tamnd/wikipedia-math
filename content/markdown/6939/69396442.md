# Lp solve

::: {#o2 .subject cue=lead name="Lp solve"}

**lp\_solve** is a [free software](https://en.wikipedia.org/wiki/Free_software) [command line utility](https://en.wikipedia.org/wiki/Command_line_utility) and [library](https://en.wikipedia.org/wiki/Library_%28computing%29) for solving [linear programming](wikipedia://en/43730) and [mixed integer programming](https://en.wikipedia.org/wiki/Mixed_integer_programming) problems. It ships with support for two file formats, [MPS](https://en.wikipedia.org/wiki/MPS_%28format%29) and lp\_solve's own LP format.[^o3] User-defined formats are supported via its "eXternal Language Interface" (XLI)[^o4] lp\_solve also supports translating between model formats using the -w series of command line switches[^o5]

:::

lp\_solve uses the [simplex method](wikipedia://en/349458) for linear programs, and [branch-and-bound](wikipedia://en/456580) for mixed integer programs. Multiple pivoting strategies are supported, including [devex](wikipedia://en/40129720). lp\_solve also features a pre-solver that can remove redundant variables and remove or tighten constraints.

The lp\_solve project also features an [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) called LPSolve IDE, for [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows).
