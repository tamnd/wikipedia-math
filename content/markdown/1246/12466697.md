# Continuous-time stochastic process

::: {#o1 .subject cue=lead name="Continuous-time stochastic process"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), a **continuous-time stochastic process**, or a **continuous-space-time stochastic process** is a [stochastic process](wikipedia://en/47895) for which the index variable takes a continuous set of values, as contrasted with a [discrete-time process](https://en.wikipedia.org/wiki/Discrete-time_signal) for which the index variable takes only distinct values. An alternative terminology uses **continuous parameter** as being more inclusive.[^o2]

:::

A more restricted class of processes are the [continuous stochastic processes](wikipedia://en/12442391); here the term often (but not always[^o3]) implies both that the index variable is continuous and that sample paths of the process are continuous. Given the possible confusion, caution is needed.[^o3]

Continuous-time stochastic processes that are constructed from discrete-time processes via a waiting time distribution are called [continuous-time random walks](wikipedia://en/43391843).[^o4]

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

An example of a continuous-time stochastic process for which sample paths are not continuous is a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process). An example with continuous paths is the [Ornstein–Uhlenbeck process](wikipedia://en/2183186).

:::
