# Cohen's cryptosystem

::: {#o1 .subject cue=lead name="Cohen's cryptosystem"}

**Cohen's cryptosystem**[^o2] is a [public-key cryptosystem](https://en.wikipedia.org/wiki/Public-key_cryptosystem) proposed in 1998 by [Bram Cohen](https://en.wikipedia.org/wiki/Bram_Cohen).

:::

## Key generation {#Key_generation}

In Cohen's cryptosystem, a [private key](https://en.wikipedia.org/wiki/Private_key) is a [positive integer](wikipedia://en/21474) $p$.

The [algorithm](wikipedia://en/775) uses $k$ public-keys $w_0,\ldots,w_{k-1}$ defined as follows:

Generate $k$ random [integers](wikipedia://en/14563) $u_0,\ldots,u_{k-1}$ chosen randomly and uniformly between $-B$ and $B$. Where $B$ is some bound.

Let $A=\lfloor\frac{p}{2k}\rfloor$ and generate $k$ random integers $v_0,\ldots,v_{k-1}$ chosen randomly and uniformly between $0$ and $A$.

Define $w_i=(u_i p+v_i)$.

## Encrypting a bit {#Encrypting_a_bit}

To encrypt a bit $m$ Alice randomly adds $\frac{k}{2}$ public keys and multiplies the result by either 1 (if she wishes to send a 0) or by −1 (if she wishes to send a 1) to obtain the [ciphertext](wikipedia://en/175560) $c=(-1)^{m} \sum w_i$.

## De-cryption {#De-cryption}

To de-crypt, Bob computes $h= c \mod p = (-1)^{m} \sum v_i$

It is easy to see that if $m=0$ then $0<h<p/2$. However, if $m=1$ then $p>h>p/2$. Hence Bob can read the bit sent by Alice on the most significant bit of h.
