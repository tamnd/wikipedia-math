# Carotid–Kundalini function

::: {#o1 .subject cue=lead name="Carotid–Kundalini function"}

*Image: Carotid Fractal.png.* Carotid-Kundalini function

The **Carotid–Kundalini [function](wikipedia://en/185427)** is closely associated with **Carotid-Kundalini [fractals](https://en.wikipedia.org/wiki/Fractals)[^o2]** coined by popular science columnist [Clifford A. Pickover](https://en.wikipedia.org/wiki/Clifford_A._Pickover) and it is defined as follows:[^o3]

:::

$$CK(n,x)=\cos(nx\arccos(x))$$
