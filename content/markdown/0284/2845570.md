# Data Authentication Algorithm

::: {#o1 .subject cue=lead name="Data Authentication Algorithm"}

The **Data Authentication Algorithm** (**DAA**) is a former [U.S. government standard](https://en.wikipedia.org/wiki/Federal_Information_Processing_Standard) for producing cryptographic [message authentication codes](wikipedia://en/567523). DAA is defined in FIPS PUB 113,[^o2] which was withdrawn on September 1, 2008. The algorithm is not considered secure by today's standards. According to the standard, a code produced by the DAA is called a **Data Authentication Code** (**DAC**). The algorithm [chain encrypts](wikipedia://en/160202#Cipher_block_chaining_%28CBC%29) the data, with the last cipher block truncated and used as the DAC.

:::

The DAA is equivalent to [ISO/IEC 9797-1](https://en.wikipedia.org/wiki/ISO/IEC_9797-1) MAC algorithm 1, or [CBC-MAC](wikipedia://en/2840574), with [DES](wikipedia://en/7978) as the underlying cipher, truncated to between 24 and 56 bits (inclusive).
