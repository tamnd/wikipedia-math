# Abstract logic

::: {#o1 .subject cue=lead name="Abstract logic"}

In [mathematical logic](wikipedia://en/19636), an **abstract logic** is a [formal system](wikipedia://en/396102) consisting of a class of [sentences](wikipedia://en/2129527) and a [satisfaction relation](https://en.wikipedia.org/wiki/Satisfaction_relation) with specific properties related to occurrence, expansion, isomorphism, renaming and quantification.[^o2]

:::

Based on [Lindström](https://en.wikipedia.org/wiki/Per_Lindström_%28logician%29)'s characterization, [first-order logic](wikipedia://en/10983) is, up to equivalence, the only abstract logic that is [countably compact](https://en.wikipedia.org/wiki/Countably_compact) and has [Löwenheim number](wikipedia://en/28877484) ω.[^o3]
