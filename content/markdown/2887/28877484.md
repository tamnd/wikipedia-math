# Löwenheim number

::: {#o1 .subject cue=lead name="Löwenheim number"}

In [mathematical logic](wikipedia://en/19636) the **Löwenheim number** of an [abstract logic](wikipedia://en/28877379) is the smallest [cardinal number](wikipedia://en/6173) for which a weak downward [Löwenheim–Skolem theorem](wikipedia://en/341482) holds.[^o2] They are named after [Leopold Löwenheim](wikipedia://en/755668), who proved that these exist for a very broad class of logics.

:::

## Abstract logic {#Abstract_logic}

An abstract logic, for the purpose of Löwenheim numbers, consists of:

- A collection of "sentences";
- A collection of "models", each of which is assigned a cardinality;
- A relation between sentences and models that says that a certain sentence is "satisfied" by a particular model.

The theorem does not require any particular properties of the sentences or models, or of the satisfaction relation, and they may not be the same as in ordinary [first-order logic](wikipedia://en/10983). It thus applies to a very broad collection of logics, including [first-order logic](wikipedia://en/10983), [higher-order logics](wikipedia://en/562883), and [infinitary logics](wikipedia://en/630478).

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The **Löwenheim number** of a logic *L* is the smallest cardinal *κ* such that if an arbitrary sentence of *L* has any model, the sentence has a model of cardinality no larger than *κ*.

Löwenheim proved the existence of this cardinal for any logic in which the collection of sentences forms a [set](wikipedia://en/26691), using the following argument. Given such a logic, for each sentence *φ*, let *κ*<sub>*φ*</sub> be the smallest cardinality of a model of *φ*, if *φ* has any model, and let *κ*<sub>*φ*</sub> be 0 otherwise. Then the set of cardinals

{ *κ*<sub>*φ*</sub> : *φ* is a sentence in *L* }

exists by the [axiom of replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement). The [supremum](https://en.wikipedia.org/wiki/Supremum) of this set, by construction, is the Löwenheim number of *L*. This argument is non-constructive: it proves the existence of the Löwenheim number, but does not provide an immediate way to calculate it.

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="Extensions"}

## Extensions {#Extensions}

Two extensions of the definition have been considered:[^o8]

- The **Löwenheim–Skolem number** of an abstract logic *L* is the smallest cardinal *κ* such that if any set of sentences *T* ⊆ *L* has a model then it has a model of size no larger than max(|*T*|, *κ*).
- The **Löwenheim–Skolem–Tarski number** of *L* is the smallest cardinal such that if *A* is any structure for *L* there is an [elementary substructure](https://en.wikipedia.org/wiki/Elementary_substructure) of *A* of size no more than *κ*. This requires that the logic have a suitable notion of "elementary substructure", for example by using the normal definition of a "structure" from predicate logic.

For any logic for which the numbers exist, the Löwenheim–Skolem–Tarski number will be no less than the Löwenheim–Skolem number, which in turn will be no less than the Löwenheim number.

Note that versions of these definitions replacing "has a model of size no larger than" with "has a model smaller than" are sometimes used, as this yields a more fine-grained classification.[^o8]

:::

::: {#o10 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [Löwenheim–Skolem theorem](wikipedia://en/341482) shows that the Löwenheim–Skolem–Tarski number of first-order logic (with countable signatures) is ℵ<sub>0</sub>. This means, in particular, that if a sentence of first-order logic is satisfiable, then the sentence is satisfiable in a countable model.
- It is known that the Löwenheim–Skolem number of [second-order logic](wikipedia://en/341428) is larger than the first [measurable cardinal](wikipedia://en/248102), if there is a measurable cardinal.[^o8] (And the same holds for its [Hanf number](https://en.wikipedia.org/wiki/Hanf_number).) The Löwenheim number of the universal (fragment of) second-order logic however is less than the first [supercompact cardinal](wikipedia://en/248116) (assuming it exists).
- The Löwenheim–Skolem–Tarski number of second-order logic is the supremum of all ordinals definable by a $\Pi_2$ formula.[^o11]<sup>Corollary 4.7</sup>

:::
