# Strength (mathematical logic)

::: {#o1 .subject cue=lead name="Strength"}

The relative **strength** of two systems of [formal logic](https://en.wikipedia.org/wiki/Formal_logic) can be defined via [model theory](wikipedia://en/19858). Specifically, a logic $\alpha$ is said to be as strong as a logic $\beta$ if every [elementary class](wikipedia://en/1284226) in $\beta$ is an elementary class in $\alpha$.[^o2]

:::
