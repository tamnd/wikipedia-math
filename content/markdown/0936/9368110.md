# Logarithmically concave measure

::: {#o1 .subject cue=lead name="Logarithmically concave measure"}

In [mathematics](wikipedia://en/18831), a [Borel measure](wikipedia://en/4322) *μ* on *n*-[dimensional](wikipedia://en/8398) [Euclidean space](wikipedia://en/9697) $\mathbb{R}^{n}$ is called **logarithmically concave** (or **log-concave** for short) if, for any [compact subsets](https://en.wikipedia.org/wiki/Compact_set) *A* and *B* of $\mathbb{R}^{n}$ and 0 \< *λ* \< 1, one has

:::

$$\mu(\lambda A + (1-\lambda) B) \geq \mu(A)^\lambda \mu(B)^{1-\lambda},$$

where *λ* *A* + (1 − *λ*) *B* denotes the [Minkowski sum](https://en.wikipedia.org/wiki/Minkowski_sum) of *λ* *A* and (1 − *λ*) *B*.[^o2]

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

The [Brunn–Minkowski inequality](wikipedia://en/7500545) asserts that the [Lebesgue measure](wikipedia://en/18198) is log-concave. The restriction of the Lebesgue measure to any [convex set](wikipedia://en/6292) is also log-concave.

By a theorem of Borell,[^o5] a probability measure on R^d is log-concave if and only if it has a density with respect to the Lebesgue measure on some affine hyperplane, and this density is a [logarithmically concave function](wikipedia://en/1508442). Thus, any [Gaussian measure](wikipedia://en/6572909) is log-concave.

The [Prékopa–Leindler inequality](wikipedia://en/10570298) shows that a [convolution](wikipedia://en/7519) of log-concave measures is log-concave.
