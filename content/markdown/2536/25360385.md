# Primal ideal

::: {#o1 .subject cue=lead name="Primal ideal"}

In [mathematics](wikipedia://en/18831), an element *a* of a [commutative ring](wikipedia://en/61346) *R* is called **(relatively) prime** to an [ideal](https://en.wikipedia.org/wiki/Ideal_of_a_ring) *I* if whenever *ab* is an element of *I* then *b* is also an element of *I*.

:::

A proper [ideal](wikipedia://en/25977) *I* of a [commutative ring](wikipedia://en/61346) *A* is said to be **primal** if the elements that are not prime to it form an ideal.
