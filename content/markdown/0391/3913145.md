# Projection (set theory)

::: {#o1 .subject cue=lead name="Projection"}

In [set theory](wikipedia://en/27553), a **projection** is one of two closely related types of [functions](wikipedia://en/185427) or operations, namely:

:::

- A [set-theoretic](wikipedia://en/27553) operation typified by the $j$<sup>th</sup> projection map, written $\mathrm{proj}_j,$ that takes an element $\vec{x} = (x_1,\ \dots,\ x_j,\ \dots,\ x_k)$ of the [Cartesian product](wikipedia://en/24104095) $(X_1 \times \cdots \times X_j \times \cdots \times X_k)$ to the value $\mathrm{proj}_j(\vec{x}) = x_j.$[^o2]
- A function that sends an element $x$ to its [equivalence class](wikipedia://en/9260) under a specified [equivalence relation](wikipedia://en/9259) $E,$[^o3] or, equivalently, a [surjection](https://en.wikipedia.org/wiki/Surjection) from a set to another set.[^o4] The function from elements to equivalence classes is a surjection, and every surjection corresponds to an equivalence relation under which two elements are equivalent when they have the same image. The result of the mapping is written as $[x]$ when $E$ is understood, or written as $[x]_E$ when it is necessary to make $E$ explicit.
