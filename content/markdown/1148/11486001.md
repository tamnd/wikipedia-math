# Hopfian group

::: {#o1 .subject cue=lead name="Hopfian group"}

In [mathematics](wikipedia://en/18831), a **Hopfian group** is a [group](wikipedia://en/19447) *G* for which every [surjective](wikipedia://en/27873)[homomorphism](wikipedia://en/12396) *G* → *G* is an [isomorphism](wikipedia://en/14828). Equivalently, a group is Hopfian if and only if it is not isomorphic to any of its proper [quotients](wikipedia://en/11526).[^n1]

:::

A group *G* is [co-Hopfian](wikipedia://en/55228538) if every [injective](wikipedia://en/45196) homomorphism *G* → *G* is an isomorphism. Equivalently, *G* is not isomorphic to any of its proper [subgroups](wikipedia://en/28011).

Hopfian groups are named after [Heinz Hopf](wikipedia://en/543082).

## Examples of Hopfian groups {#Examples_of_Hopfian_groups}

- Every [finite group](wikipedia://en/323707), by an elementary counting argument.
- More generally, every [polycyclic-by-finite group](https://en.wikipedia.org/wiki/Polycyclic-by-finite_group).
- Any [finitely generated](wikipedia://en/963042) [free group](wikipedia://en/59735).
- The additive group $\mathbb{Q}$ of [rationals](wikipedia://en/19727024).
- Any [finitely generated](wikipedia://en/963042) [residually finite group](wikipedia://en/5780875).
- Any [word-hyperbolic group](https://en.wikipedia.org/wiki/Word-hyperbolic_group).

## Examples of non-Hopfian groups {#Examples_of_non-Hopfian_groups}

- [Quasicyclic groups](https://en.wikipedia.org/wiki/Quasicyclic_group).
- The additive group $\mathbb{R}$ of [real numbers](wikipedia://en/20646438).[^n2]
- The [Baumslag–Solitar group](wikipedia://en/11485892) $B(2,3)$. In general $B(m,n)$ is non-Hopfian if and only if there exists primes $p$ and $q$ with $p\mid m$, $q\mid n$ and $p\nmid n$, $q\nmid m$.[^n3]

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

It was shown by Collins that it is an [undecidable problem](wikipedia://en/15631055) to determine, given a [finite presentation](wikipedia://en/99494#finitely_presented) of a group, whether the group is Hopfian.[^n4] Unlike the undecidability of many properties of groups, this is not a consequence of the [Adian–Rabin theorem](wikipedia://en/51425733) because Hopficity is not a [Markov property](wikipedia://en/51425733#Markov_property).[^n5]

:::
