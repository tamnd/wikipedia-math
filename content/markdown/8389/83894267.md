# 9801 (number)

::: {#o2 .subject cue=lead name="9801"}

**9801** (**nine thousand eight hundred \[and\] one**) is the [natural number](wikipedia://en/21474) following 9800 and preceding 9802.

:::

## In mathematics {#In_mathematics}

9801 is most notable for being the third, and only 4-digit [square pentagonal number](https://en.wikipedia.org/wiki/Square_pentagonal_number),[^o5] since 9801 is a [square number](wikipedia://en/213919), which can be written as: $99^2$, and it is also a [pentagonal number](wikipedia://en/504786), since it can also be written as: $\frac{81\cdot(3\cdot81-1)}{2} = \frac{81\cdot242}{2}$.[^o6] 9801 is also the number that is below [10,000](wikipedia://en/493491) which are [integral multiples of their reversals](wikipedia://en/52684628). The only other number which has this property is 8712.[^o7][^o8] 9801 is the sixth number such as the [binomial coefficient](wikipedia://en/4668) is a [perfect square](wikipedia://en/213919).[^o10] 9801 is a part of one of the first few pairs of consecutive [powerful numbers](https://en.wikipedia.org/wiki/Powerful_numbers) with 9800. (9800, 9801)[^o11][^o12]
