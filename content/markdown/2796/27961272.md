# Weighted product model

::: {#o1 .subject cue=lead name="Weighted product model"}

The **weighted product model** (**WPM**) is a [multi-criteria decision analysis](https://en.wikipedia.org/wiki/Multi-criteria_decision_analysis) (MCDA) method used in [operations research](wikipedia://en/43476) and [decision theory](wikipedia://en/446216) for evaluating and ranking alternatives based on multiple conflicting criteria.

:::

The method calculates a score for each alternative by multiplying together all the criteria values, where each value is raised to a power that reflects the importance ([weight](https://en.wikipedia.org/wiki/Weight_%28mathematics%29)) of that criterion. This multiplicative approach distinguishes it from additive methods like the [weighted sum model](wikipedia://en/27914444) (WSM), providing the crucial advantage of dimensional consistency—effectively resolving the problem of "adding apples and oranges" that occurs when combining [measurements](wikipedia://en/19022) expressed in different [units](https://en.wikipedia.org/wiki/Units_of_measurement).

Unlike the weighted sum model, which requires extensive [data normalization](https://en.wikipedia.org/wiki/Data_normalization) procedures that can significantly influence final rankings, the WPM's multiplicative structure eliminates the need for normalization entirely. This characteristic makes it particularly robust for applications involving [heterogeneous](https://en.wikipedia.org/wiki/Heterogeneous) data sets and reduces the potential for [bias](wikipedia://en/40786) introduced through normalization choices. The method has found widespread application in fields such as [engineering design](https://en.wikipedia.org/wiki/Engineering_design), [supplier selection](https://en.wikipedia.org/wiki/Supplier_selection), [project management](https://en.wikipedia.org/wiki/Project_management), and [strategic planning](https://en.wikipedia.org/wiki/Strategic_planning), where decision-makers must simultaneously consider multiple, often competing objectives.

The WPM is closely related to other MCDA methods including the [Analytic Hierarchy Process](https://en.wikipedia.org/wiki/Analytic_Hierarchy_Process) (AHP), [TOPSIS](wikipedia://en/36351340), and [ELECTRE](https://en.wikipedia.org/wiki/ELECTRE), and is sometimes used in conjunction with these techniques in hybrid decision-making frameworks.

## Description {#Description}

As with all MCDA / MCDM methods, given is a finite set of decision alternatives described in terms of a number of decision criteria. Each decision alternative is compared with the others by multiplying a number of ratios, one for each decision criterion. Each ratio is raised to the power equivalent to the relative weight of the corresponding criterion.

Suppose that a given [MCDA](https://en.wikipedia.org/wiki/MCDA) problem is defined on *m* alternatives and *n* decision criteria. Furthermore, let us assume that all the criteria are benefit criteria. That is, the higher the values are, the better it is. Next suppose that *w<sub>j</sub>* denotes the relative weight of importance of the criterion *C<sub>j</sub>* and *a<sub>ij</sub>* is the performance value of alternative *A<sub>i</sub>* when it is evaluated in terms of criterion *C<sub>j</sub>*. Then, if one wishes to compare the two alternatives *A<sub>K</sub>* and *A<sub>L</sub>* (where *m* ≥ *K*, *L* ≥ 1) then, the following product has to be calculated:[^o15]

$$P( A_K / A_L ) = \prod_{j=1}^n ( a_{Kj} / a_{Lj} ) ^{w_j}, \text{ for }K, L = 1, 2, 3,\dots, m.$$

If the ratio *P*(*A*<sub>*K*</sub>/*A*<sub>*L*</sub>) is greater than or equal to the value 1, then it indicates that alternative *A<sub>K</sub>* is more desirable than alternative *A<sub>L</sub>* (in the maximization case). If we are interested in determining the best alternative, then the best alternative is the one that is better than or at least equal to all other alternatives.

The WPM is often called **dimensionless analysis** because its mathematical structure eliminates any units of measure.[^o15][^o3]

Therefore, the WPM can be used in single- and multi-dimensional [MCDA](https://en.wikipedia.org/wiki/MCDA) / [MCDM](https://en.wikipedia.org/wiki/MCDM) problems. That is, on decision problems where the alternatives are described in terms that use different units of measurement. An advantage of this method is that instead of the actual values it can use relative ones.

The following is a simple numerical example which illustrates how the calculations for this method can be carried out. As data we use the same numerical values as in the numerical example described for the [weighted sum model](wikipedia://en/27914444). These numerical data are repeated next for easier reference.

## Example {#Example}

This simple decision problem is based on three alternatives denoted as *A*<sub>1</sub>, *A*<sub>2</sub>, and *A*<sub>3</sub> each described in terms of four criteria *C*<sub>1</sub>, *C*<sub>2</sub>, *C*<sub>3</sub> and *C*<sub>4</sub>. Next, let the numerical data for this problem be as in the following decision matrix:

::: {#o6 .table cue=table}

|  | *C*<sub>1</sub> | *C*<sub>2</sub> | *C*<sub>3</sub> | *C*<sub>4</sub> |
|---|---|---|---|---|
| **Alts.** | \0.20 | \0.15 | \0.40 | \0.25 |
| *A*<sub>1</sub> | 25 | 20 | 15 | 30 |
| *A*<sub>2</sub> | 10 | 30 | 20 | 30 |
| *A*<sub>3</sub> | 30 | 10 | 30 | 10 |

:::

The above table specifies that the relative weight of the first criterion is 0.20, the relative weight for the second criterion is 0.15 and so on. Similarly, the value of the first alternative (i.e., *A*<sub>1</sub>) in terms of the first criterion is equal to 25, the value of the same alternative in terms of the second criterion is equal to 20 and so on. However, now the restriction to express all criteria in terms of the same measurement unit is not needed. That is, the numbers under each criterion may be expressed in different units.

When the WPM is applied on the previous data, then the following values are derived:

$$P( A_1 / A_2 ) = (25/10) ^{0.20} \times (20/30) ^{0.15} \times (15/20) ^{0.40} \times (30/30) ^{0.25} = 1.007 > 1.$$

Similarly, we also get:

$$P( A_1 / A_3) = 1.067 > 1,\text{ and } P( A_2 / A_3) = 1.059 > 1. \,$$

Therefore, the best alternative is *A*<sub>1</sub>, since it is superior to all the other alternatives. Furthermore, the following ranking of all three alternatives is as follows: *A*<sub>1</sub> > *A*<sub>2</sub> > *A*<sub>3</sub> (where the symbol ">" stands for "better than").

An alternative approach with the WPM method is for the decision maker to use only products without the previous ratios.[^o15][^o3] That is, to use the following variant of main formula given earlier:

$$P( A_K ) = \prod_{j=1}^n ( a_{Kj} ) ^{w_j}, \text{ for } K = 1, 2, 3, \dots , m.$$

In the previous expression the term *P*(*A*<sub>*K*</sub>) denotes the total performance value (i.e., not a relative one) of alternative *A*<sub>*K*</sub> when all the criteria are considered simultaneously under the WPM model. Then, when the previous data are used, exactly the same ranking is derived. Some interesting properties of this method are discussed in the 2000 book by Triantaphyllou on [MCDA](https://en.wikipedia.org/wiki/MCDA) / [MCDM](https://en.wikipedia.org/wiki/MCDM).[^o15]

An illustrative application is provided by Watters and Tofallis.[^o7]

:::

## Choosing the weights {#Choosing_the_weights}

The choice of values for the weights is usually difficult. The simple default of equal weighting is sometimes used. Scoring methods such as WSM and WPM may be used for rankings (universities, countries, consumer products etc.), and the weights will determine the order in which these entities are placed. There is often much argument about the appropriateness of the chosen weights, and whether they are biased or display favouritism. One approach for overcoming this issue is to automatically generate the weights from the data. [^o9] This has the advantage of avoiding personal input and so is more objective. The so-called Automatic Democratic Method for weight generation has two key steps:

(1) For each alternative, identify the weights which will maximize its score, subject to the condition that these weights do not lead to any of the alternatives exceeding a score of 100%.

(2) Fit an equation to these optimal scores using regression so that the regression equation predicts these scores as closely as possible using the criteria data as explanatory variables. The regression coefficients then provide the final weights.
