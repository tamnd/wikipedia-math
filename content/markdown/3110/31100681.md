# Benktander type I distribution

::: {#o2 .subject cue=lead name="Benktander type I distribution"}

The **Benktander type I distribution** is one of two distributions introduced by Gunnar (txt) to model heavy-tailed losses commonly found in non-life/casualty [actuarial science](wikipedia://en/189373), using various forms of mean excess functions (Benktander Segerdahl 1960). The distribution of the first type is "close" to the [log-normal distribution](wikipedia://en/102476) (Kleiber Kotz 2003).

:::
