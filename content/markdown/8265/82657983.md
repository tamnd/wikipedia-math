# Sphere function

::: {#o1 .subject cue=lead name="Sphere function"}

In [mathematical optimization](wikipedia://en/52033), the **sphere function** is a [convex function](wikipedia://en/245568) used as a performance test problem for [optimization algorithms](https://en.wikipedia.org/wiki/Optimization_algorithm). The sphere function was proposed by [Kenneth A. De Jong](https://en.wikipedia.org/wiki/Kenneth_A_De_Jong) in 1975 as the first item of a series of computational test sets.[^o2] Because of this, the sphere function is also collectively referred to as **De Jong's function** or **De Jong's first function**.[^o3]

:::

On a $n$-dimensional domain it is defined by

$$f((x_1, x_2, \dots, x_n))=\sum_{i=1}^{n}x_{i}^{2}.$$

The function is typically evaluated on the domain $x_{i} \in [-5.12,5.12]$ for all $1 \leq i \leq n$.[^o3]

It has a [global minimum](https://en.wikipedia.org/wiki/Global_minimum) of zero at $x_{i}=0.$ It is a [separable function](https://en.wikipedia.org/wiki/Separable_function); that is, it can be expressed as a product of functions in one variable.[^o4]

The sphere function is used as a benchmark problem to measure algorithms' precision, [convergence rate](wikipedia://en/999701), and [robustness](wikipedia://en/2885691), specifically over how well the algorithm handles the function's smooth nature. Several variants of the sphere function are also used, including the [Rastrigin function](wikipedia://en/27300280).[^o3][^o5]
