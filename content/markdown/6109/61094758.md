# Natural element method

::: {#o1 .subject cue=lead name="Natural element method"}

*Image: Euclidean Voronoi diagram.svg.* 20 points and their Voronoi cells

The **natural element method (NEM)**[^o2][^o3][^o4] is a [meshless method](https://en.wikipedia.org/wiki/Meshless_method) to solve [partial differential equation](wikipedia://en/52564), where the *elements* do not have a predefined shape as in the [finite element method](wikipedia://en/18233581), but depend on the geometry.[^o5][^o6][^o7]

:::

A [Voronoi diagram](wikipedia://en/177668) partitioning the space is used to create each of these elements.

[Natural neighbor interpolation functions](https://en.wikipedia.org/wiki/Natural_neighbor_interpolation) are then used to model the unknown function within each element.

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

When the simulation is dynamic, this method prevents the elements to be ill-formed, having the possibility to easily redefine them at each time step depending on the geometry.

:::
