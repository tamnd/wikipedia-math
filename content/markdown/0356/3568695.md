# Torsion group

::: {#o1 .subject cue=lead name="Torsion group"}

In [group theory](wikipedia://en/41890), a branch of [mathematics](wikipedia://en/18831), a **torsion group** or a **periodic group** is a [group](wikipedia://en/19447) in which every [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) has [finite order](https://en.wikipedia.org/wiki/Finite_order). The **exponent** of such a group, if it exists, is the [least common multiple](wikipedia://en/17961) of the orders of the elements.

:::

For example, it follows from [Lagrange's theorem](wikipedia://en/31150) that every finite group is periodic and it has an exponent that divides its order.

## Infinite examples {#Infinite_examples}

Examples of infinite periodic groups include the additive group of the ring of polynomials over a finite field, and the quotient group of the rationals by the integers, as well as their direct summands, the [Prüfer groups](wikipedia://en/4885031). Another example is the direct sum of all [dihedral groups](wikipedia://en/100267). None of these examples has a finite generating set. Explicit examples of finitely generated infinite periodic groups were constructed by Golod,[^o3] based on joint work with Shafarevich (see *[Golod–Shafarevich theorem](wikipedia://en/8845470)*), and by Aleshin[^o4] and [Grigorchuk](wikipedia://en/18697527)[^o5] using [automata](wikipedia://en/103356). These groups have infinite exponent; examples with finite exponent are given for instance by [Tarski monster groups](wikipedia://en/727196) constructed by Olshanskii.[^o6]

## Burnside's problem {#Burnside's_problem}

Burnside's problem is a classical question that deals with the relationship between periodic groups and [finite groups](wikipedia://en/323707), when only [finitely generated groups](wikipedia://en/963042) are considered: Does specifying an exponent force finiteness? The existence of infinite, finitely generated periodic groups as in the previous paragraph shows that the answer is "no" for an arbitrary exponent. Though much more is known about which exponents can occur for infinite finitely generated groups there are still some for which the problem is open.

For some classes of groups, for instance [linear groups](wikipedia://en/3983656), the answer to Burnside's problem restricted to the class is positive.

## Mathematical logic {#Mathematical_logic}

An interesting property of periodic groups is that the definition cannot be formalized in terms of [first-order logic](wikipedia://en/10983). This is because doing so would require an axiom of the form

$$\forall x,\big((x = e) \lor (x\circ x=e) \lor ((x\circ x)\circ x=e) \lor \cdots\big) ,$$

which contains an infinite [disjunction](wikipedia://en/7962) and is therefore inadmissible: first order logic permits quantifiers over the sort(s) of individuals and cannot capture properties or "subsets" of that sort. It is also not possible to get around this infinite disjunction by using an infinite set of axioms: the [compactness theorem](wikipedia://en/152207) implies that no set of first-order formulae can characterize the periodic groups.[^o9]

## Related notions {#Related_notions}

The [torsion subgroup](wikipedia://en/144052) of an [abelian group](wikipedia://en/2974) *A* is the subgroup of *A* that consists of all elements that have finite order. A [torsion abelian group](wikipedia://en/46340931) is an abelian group in which every element has finite order. A [torsion-free abelian group](wikipedia://en/11630973) is an abelian group in which the identity element is the only element with finite order.
