# Trace zero cryptography

::: {#o1 .subject cue=lead name="Trace zero cryptography"}

First proposed by [Gerhard Frey](wikipedia://en/1021312) in 1998, **trace zero cryptography** refers to the use of **trace zero varieties** (TZV) for cryptographic purpose. Trace zero varieties are [subgroups](wikipedia://en/28011) of the divisor class group on a low genus [hyperelliptic curve](wikipedia://en/561913) defined over a [finite field](wikipedia://en/11615). These groups can be used to establish [asymmetric cryptography](wikipedia://en/24222) using the [discrete logarithm](wikipedia://en/181334) problem as [cryptographic primitive](wikipedia://en/4928985).

:::

Trace zero varieties feature a better [scalar multiplication](wikipedia://en/244373) performance than [elliptic curves](wikipedia://en/9966). This allows fast arithmetic in these groups, which can speed up the calculations with a factor 3 compared with elliptic curves and hence speed up the [cryptosystem](wikipedia://en/506383).

Another advantage is that for groups of cryptographically relevant size, the order of the group can simply be calculated using the [characteristic polynomial](wikipedia://en/218268) of the [Frobenius endomorphism](wikipedia://en/1088270). This is not the case, for example, in [elliptic curve cryptography](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography) when the group of points of an elliptic curve over a prime field is used for cryptographic purpose.

However, to represent an element of the trace zero variety more bits are needed compared with elements of elliptic or hyperelliptic curves. Another disadvantage is the fact that it is possible to reduce the security of the TZV of <sup>1</sup>/<sub>6</sub><sup>th</sup> of the bit length using cover attack.

## Mathematical background {#Mathematical_background}

A [hyperelliptic curve](wikipedia://en/499361) *C* of genus *g* over a prime field $\mathbb{F}_q$ where *q* = *p*<sup>*n*</sup> (*p* prime) of odd characteristic is defined as

$$C:~y^2 + h(x)y = f(x),$$

where *f* monic, deg(*f*) = 2*g* + 1 and deg(*h*) ≤ g. The curve has at least one $\mathbb{F}_q$-rational Weierstraßpoint.

The [Jacobian variety](wikipedia://en/489734) $J_C(\mathbb{F}_{q^n})$ of *C* is for all finite extension $\mathbb{F}_{q^n}$ isomorphic to the ideal class group $\operatorname{Cl}(C/\mathbb{F}_{q^n})$. With the *Mumford's representation* it is possible to represent the elements of $J_C(\mathbb{F}_{q^n})$ with a pair of polynomials *\[u, v\]*, where *u*, *v* ∈ $\mathbb{F}_{q^n}[x]$.

The *Frobenius endomorphism* σ is used on an element *\[u, v\]* of $J_C(\mathbb{F}_{q^n})$ to raise the power of each coefficient of that element to *q*: σ(*\[u, v\]*) = \[*u*<sup>q</sup>(x), v<sup>q</sup>(x)\]. The characteristic polynomial of this endomorphism has the following form:

$$\chi(T) = T^{2g} + a_1T^{2g-1} + \cdots + a_gT^g + \cdots + a_1q^{g-1}T + q^g,$$

where a<sub>i</sub> in $\mathbb{Z}$

With the *Hasse–Weil theorem* it is possible to receive the group order of any extension field $\mathbb{F}_{q^n}$ by using the complex roots τ<sub>i</sub> of χ(*T*):

$$|J_C(\mathbb{F}_{q^n})| = \prod_{i=1}^{2g} (1 - \tau_i^n)$$

Let *D* be an element of the $J_C(\mathbb{F}_{q^n})$ of *C*, then it is possible to define an endomorphism of $J_C(\mathbb{F}_{q^n})$, the so-called *trace of D*:

$$\operatorname{Tr}(D) = \sum_{i=0}^{n-1} \sigma^i(D) = D + \sigma(D) + \cdots + \sigma^{n-1}(D)$$

Based on this endomorphism one can reduce the Jacobian variety to a subgroup *G* with the property, that every element is of trace zero:

$$G = \{ D \in J_C(\mathbb{F}_{q^n})~|~\text{Tr}(D) = \textbf{0} \}, ~~~(\textbf{0} \text{ neutral element in } J_C(\mathbb{F}_{q^n})$$

*G* is the kernel of the trace endomorphism and thus *G* is a group, the so-called **trace zero (sub)variety** (TZV) of $J_C(\mathbb{F}_{q^n})$.

The intersection of *G* and $J_C(\mathbb{F}_{q})$ is produced by the *n*-torsion elements of $J_C(\mathbb{F}_{q})$. If the greatest common divisor $\gcd(n, |J_C(\mathbb{F}_q)|) = 1$ the intersection is empty and one can compute the group order of *G*:

$$|G| = \dfrac{|J_C(\mathbb{F}_{q^n})|}{|J_C(\mathbb{F}_q)|} = \dfrac{\prod_{i=1}^{2g} (1 - \tau_i^n)}{ \prod_{i=1}^{2g} (1 - \tau_i)}$$

The actual group used in cryptographic applications is a subgroup *G<sub>0</sub>* of *G* of a large prime order *l*. This group may be *G* itself.[^o3][^o4]

There exist three different cases of cryptographical relevance for TZV:[^o5]

- *g* = 1, *n* = 3
- *g* = 1, *n* = 5
- *g* = 2, *n* = 3

## Arithmetic {#Arithmetic}

The arithmetic used in the TZV group *G<sub>0</sub>* based on the arithmetic for the whole group $J_C(\mathbb{F}_{q^n})$, But it is possible to use the *Frobenius endomorphism* σ to speed up the scalar multiplication. This can be archived if *G<sub>0</sub>* is generated by *D* of order *l* then *σ(D) = sD*, for some integers *s*. For the given cases of TZV *s* can be computed as follows, where *a*<sub>i</sub> come from the characteristic polynomial of the Frobenius endomorphism :

- For *g* = 1, *n* = 3: $s = \dfrac {q-1} {1 - a_1} \bmod{\ell}$
- For *g* = 1, *n* = 5: $s = \dfrac {q^2-q-a_1^2q+a_1q+1} {q-2a_1q+a_1^3-a_1^2+a_1-1} \bmod{\ell}$
- For *g* = 2, *n* = 3: $s = - \dfrac {q^2-a_2+a_1} {a_1q-a_2+1} \bmod{\ell}$

Knowing this, it is possible to replace any scalar multiplication *mD (|m| ≤ l/2)* with:

$$m_0D + m_1\sigma(D) + \cdots + m_{n-1}\sigma^{n-1}(D), ~~~~\text{where }m_i = O(\ell^{1/(n-1)}) = O(q^g)$$

With this trick the multiple scalar product can be reduced to about 1/(*n* − 1)<sup>th</sup> of doublings necessary for calculating *mD*, if the implied constants are small enough.[^o5][^o4]

## Security {#Security}

The security of cryptographic systems based on trace zero subvarieties according to the results of the papers[^o4][^o5] comparable to the security of hyper-elliptic curves of low genus *g'* over $\mathbb{F}_{p'}$, where *p'* ~ (*n* − 1)(*g/g'*) for *\|G|* ~128 bits.

For the cases where *n* = 3, *g* = 2 and *n* = 5, *g* = 1 it is possible to reduce the security for at most 6 bits, where *\|G|* ~ 2<sup>256</sup>, because one can not be sure that *G* is contained in a Jacobian of a curve of genus 6. The security of curves of genus 4 for similar fields are far less secure.

## Cover attack on a trace zero crypto-system {#Cover_attack_on_a_trace_zero_crypto-system}

The attack published in[^o9] shows, that the DLP in trace zero groups of genus 2 over finite fields of characteristic diverse than 2 or 3 and a [field extension](wikipedia://en/11634) of degree 3 can be transformed into a DLP in a class group of degree 0 with genus of at most 6 over the base field. In this new class group the DLP can be attacked with the index calculus methods. This leads to a reduction of the bit length <sup>1</sup>/<sub>6</sub><sup>th</sup>.
