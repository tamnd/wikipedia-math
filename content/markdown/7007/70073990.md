# Queen's graph

::: {#o1 .subject cue=lead name="Queen's graph"}

In mathematics, a **queen's graph** is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) that represents all legal moves of the [queen](https://en.wikipedia.org/wiki/Queen_%28chess%29)—a [chess piece](https://en.wikipedia.org/wiki/Chess_piece)—on a [chessboard](https://en.wikipedia.org/wiki/Chessboard). In the graph, each [vertex](wikipedia://en/638899) represents a square on a chessboard, and each [edge](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) is a legal move the queen can make; that is, a horizontal, vertical or diagonal move by any number of squares. If the chessboard has dimensions $m\times n$, then the induced graph is called the $m\times n$ queen's graph.

:::

[Independent sets](wikipedia://en/524501) of the graphs correspond to placements of multiple queens where no two queens are attacking each other. They are studied in the [eight queens puzzle](wikipedia://en/10474), where eight non-attacking queens are placed on a standard $8\times 8$ chessboard. [Dominating sets](wikipedia://en/1747972) represent arrangements of queens where every square is attacked or occupied by a queen; five queens, but no fewer, can dominate the $8\times 8$ chessboard.

[Colourings](wikipedia://en/426743) of the graphs represent ways to colour each square so that a queen cannot move between any two squares of the same colour; at least *n* colours are needed for an $n\times n$ chessboard, but 9 colours are needed for the $8\times 8$ board.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

There is a [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle) for each queen's graph, and the graphs are [biconnected](wikipedia://en/4989397) (they remain [connected](wikipedia://en/1614492) if any single vertex is removed). The special cases of the $1\times n$ and $2\times 2$ queen's graphs are [complete](wikipedia://en/85816).

:::

## Independence {#Independence}

floatright

An [independent set](wikipedia://en/524501) of the graph corresponds to a placement of several queens on a chessboard such that no two queens are attacking each other. In an $n\times n$ chessboard, the largest independent set contains at most *n* vertices, as no two queens can be in the same row or column.[^o7] This upper bound can be achieved for all *n* except *n*=2 and *n*=3.[^o8] In the case of n=8, this is the traditional eight queens puzzle.[^o7]

## Domination {#Domination}

A [dominating set](wikipedia://en/1747972) of the queen's graph corresponds to a placement of queens such that every square on the chessboard is either attacked or occupied by a queen. On an $8\times 8$ chessboard, five queens can dominate, and this is the minimum number possible[^o12] (four queens leave at least two squares unattacked). There are 4,860 such placements of five queens, including ones where the queens control also all occupied squares, i.e. they attack respectively protect each other. In this subgroup, there are also positions where the queens occupy squares on the main diagonal only[^o12] (e.g. from a1 to h8), or all on a subdiagonal (e.g. from a2 to g8).[^o10][^o11]

Modifying the graph by replacing the non-looping rectangular $8\times 8$ chessboard with a [torus](wikipedia://en/74800) or [cylinder](wikipedia://en/859283) reduces the minimum dominating set size to four.[^o12]

floatright

The $3\times 3$ queen's graph is dominated by the single vertex at the centre of the board. The centre vertex of the $5\times 5$ queen's graph is [adjacent](https://en.wikipedia.org/wiki/Adjacency_%28graph_theory%29) to all but 8 vertices: those vertices that are adjacent to the centre vertex of the $5\times 5$ [knight's graph](https://en.wikipedia.org/wiki/Knight's_graph).[^o12]

### Domination numbers {#Domination_numbers}

Define the domination number *d*(*n*) of an $n\times n$ queen's graph to be the size of the smallest dominating set, and the diagonal domination number *dd*(*n*) to be the size of the smallest dominating set that is a subset of the long diagonal. Note that $d(n)\le dd(n)$ for all *n*. The bound is attained for $d(8)=dd(8)=5$, but not for $d(11)=5,dd(11)=7$.[^o12]

The domination number is linear in *n*, with bounds given by:[^o12]

$$\frac{n-1}{2} \le d(n)\le n-\left \lfloor \frac{n}{3}\right \rfloor.$$

Initial values of *d*(*n*), for $n=1,2,3,\dots$, are 1, 1, 1, 2, 3, 3, 4, 5, 5, 5, 5 .

Let *K<sub>n</sub>* be the maximum size of a subset of $\{1,2,3,\dots,n\}$ such that every number has the same [parity](wikipedia://en/143135) and no three numbers form an [arithmetic progression](wikipedia://en/168389) (the set is "midpoint-free"). The diagonal domination number of an $n\times n$ queen's graph is $n-K_n$.[^o12]

Define the independent domination number *ID*(*n*) to be the size of the smallest independent, dominant set in an $n\times n$ queen's graph. It is known that $ID(n)<0.705n+0.895$.[^o14]

## Colouring {#Colouring}

*Image: Queen's graph colouring.jpg.* A 9-[colouring](wikipedia://en/426743) of the $8\times 8$ queen's graph.[^o16] Notice that each pair of squares with the same colour are not on the same rank, file or diagonal, so a queen could not move directly between the squares.

A [colouring](wikipedia://en/426743) of the queen's graph is an assignment of colours to each vertex such that no two adjacent vertices are given the same colour. For instance, if a8 is coloured red, then no other square on the a-[file](https://en.wikipedia.org/wiki/File_%28chess%29), eighth [rank](https://en.wikipedia.org/wiki/Rank_%28chess%29) or long diagonal can be coloured red, as a queen can move from a8 to any of these squares. The chromatic number of the graph is the smallest number of colours that can be used to colour it.

In the case of an $n\times n$ queen's graph, at least *n* colours are required, as each square in a rank or file needs a different colour (i.e. the rows and columns are [cliques](wikipedia://en/524466)).[^o5] The chromatic number is exactly *n* if $n\equiv 1,5 \pmod 6$ (i.e. *n* is one more or one less than a multiple of 6).[^o17]

The chromatic number of an $8\times 8$ queen's graph is 9.[^o18]

## Irredundance {#Irredundance}

A set of vertices is irredundant if removing any vertex from the set changes the [neighbourhood](wikipedia://en/7309251) of the set i.e. for each vertex, there is an adjacent vertex that is not adjacent to any other vertex in the set. This corresponds to a set of queens which each uniquely control at least one square. The maximum size *IR*(*n*) of an irredundant set on the $n\times n$ queen's graph is difficult to characterise; known values include $IR(5)=5,IR(6)=7,IR(7)=9,IR(8)=11.$[^o12]

## Pursuit–evasion game {#Pursuit–evasion_game}

Consider the [pursuit–evasion](wikipedia://en/3857398) game on an $8\times 8$ queen's graph played according to the following rules: a white queen starts in one corner and a black queen in the opposite corner. Players alternate moves, which consist of moving the queen to an adjacent vertex that can be reached without passing over (horizontally, vertically or diagonally) or landing on a vertex that is adjacent to the opposite queen. This game can be won by white with a [pairing strategy](wikipedia://en/59222107).[^n1]
