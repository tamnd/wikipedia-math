# Weber's theorem (algebraic curves)

::: {#o1 .subject cue=lead name="Weber's theorem"}

In [mathematics](wikipedia://en/18831), **Weber's theorem**, named after [Heinrich Martin Weber](wikipedia://en/2643615), is a result on [algebraic curves](wikipedia://en/253260). It states the following.

:::

Consider two non-singular curves *C* and *C* having the same [genus](wikipedia://en/61891) *g* > 1. If there is a rational correspondence φ between *C* and *C*, then φ is a [birational transformation](https://en.wikipedia.org/wiki/Birational_transformation).
