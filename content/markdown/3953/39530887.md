# Elliptic pseudoprime

::: {#o1 .subject cue=lead name="Elliptic pseudoprime"}

In [number theory](wikipedia://en/21527), a [pseudoprime](wikipedia://en/28787420) is called an **elliptic pseudoprime** for (*E*, *P*), where *E* is an [elliptic curve](wikipedia://en/10225) defined over the [field](wikipedia://en/10603) of [rational numbers](wikipedia://en/19727024) with [complex multiplication](wikipedia://en/537183) by an [order](wikipedia://en/1114171) in $\mathbb{Q} \big(\sqrt{- d} \big)$, having equation *y*<sup>2</sup> = *x*<sup>3</sup> + *ax* + *b* with *a*, *b* [integers](wikipedia://en/14563), *P* being a point on *E* and *n* a [natural number](wikipedia://en/21474) such that the [Jacobi symbol](wikipedia://en/97313) (−*d* | *n*) = −1, if (*n* + 1)*P* ≡ 0 (mod *n*).

:::

The number of elliptic pseudoprimes less than *X* is bounded above, for large *X*, by

$$X / \exp((1/3)\log X \log\log\log X /\log\log X) \ .$$
