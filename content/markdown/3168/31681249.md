# TLS-SRP

::: {#o1 .subject cue=lead name="TLS-SRP"}

**Transport Layer Security Secure Remote Password (TLS-SRP) ciphersuites** are a set of [cryptographic protocols](wikipedia://en/591994) that provide [secure](https://en.wikipedia.org/wiki/Security) communication based on [passwords](wikipedia://en/24304), using an [SRP](https://en.wikipedia.org/wiki/Secure_Remote_Password_protocol) [password-authenticated key exchange](https://en.wikipedia.org/wiki/PAKE).

:::

There are two classes of TLS-SRP ciphersuites: The first class of cipher suites uses only [SRP](https://en.wikipedia.org/wiki/Secure_Remote_Password_protocol) authentication. The second class uses [SRP](https://en.wikipedia.org/wiki/Secure_Remote_Password_protocol) authentication and [public key certificates](wikipedia://en/223796) together for added security.

Usually, TLS uses only [public key certificates](wikipedia://en/223796) for authentication. TLS-SRP uses a value derived from a password (the [SRP](https://en.wikipedia.org/wiki/Secure_Remote_Password_protocol) verifier) and a salt, shared in advance among the communicating parties, to establish a TLS connection. There are several possible reasons one may choose to use TLS-SRP:

- Using password-based authentication does not require reliance on [certificate authorities](wikipedia://en/296370).
- The end user does not need to check the URL being certified. If the server does not know data derived from the password then the connection simply cannot be made. This prevents some kinds of [Phishing](https://en.wikipedia.org/wiki/Phishing).
- Password authentication is less prone than certificate authentication to certain types of configuration mistakes, such as expired certificates or mismatched common name fields.
- TLS-SRP provides mutual authentication (the client and server both authenticate each other), while [TLS](https://en.wikipedia.org/wiki/Transport_layer_security) with server certificates only authenticates the server to the client. [Client certificates](wikipedia://en/223796#Client_certificates) can authenticate the client to the server, but it may be easier for a user to remember a password than to install a certificate.

## Implementations {#Implementations}

TLS-SRP is implemented in [GnuTLS](wikipedia://en/949758),[^o4] OpenSSL as of release 1.0.1,[^o5] Apache mod\_gnutls[^o6] and [mod\_ssl](https://en.wikipedia.org/wiki/Mod_ssl), [cURL](https://en.wikipedia.org/wiki/CURL), TLS Lite[^o7] SecureBlackbox[^o8] and [wolfSSL](https://en.wikipedia.org/wiki/WolfSSL).[^o9]

:::
