# Mean value theorem (divided differences)

::: {#o1 .subject cue=lead name="Mean value theorem"}

In [mathematical analysis](wikipedia://en/48396), the **mean value theorem for divided differences** generalizes the [mean value theorem](wikipedia://en/19662) to higher derivatives.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

For any *n* + 1 pairwise distinct points *x*<sub>0</sub>, ..., *x*<sub>*n*</sub> in the domain of an *n*-times differentiable function *f* there exists an interior point

$$\xi \in (\min\{x_0,\dots,x_n\},\max\{x_0,\dots,x_n\}) \,$$

where the *n*th derivative of *f* equals *n*! times the *n*th [divided difference](https://en.wikipedia.org/wiki/Divided_difference) at these points:

$$f[x_0,\dots,x_n] = \frac{f^{(n)}(\xi)}{n!}.$$

For *n* = 1, that is two function points, one obtains the simple [mean value theorem](wikipedia://en/19662).

:::

::: {#o6 .proof cue=heading name="Proof"}

## Proof {#Proof}

Let $P$ be the [Lagrange interpolation polynomial](https://en.wikipedia.org/wiki/Lagrange_interpolation_polynomial) for *f* at *x*<sub>0</sub>, ..., *x*<sub>*n*</sub>. Then it follows from the [Newton form](wikipedia://en/216333) of $P$ that the highest order term of $P$ is $f[x_0,\dots,x_n]x^n$.

Let $g$ be the remainder of the interpolation, defined by $g = f - P$. Then $g$ has $n+1$ zeros: *x*<sub>0</sub>, ..., *x*<sub>*n*</sub>. By applying [Rolle's theorem](wikipedia://en/200305) first to $g$, then to $g'$, and so on until $g^{(n-1)}$, we find that $g^{(n)}$ has a zero $\xi$. This means that

$$0 = g^{(n)}(\xi) = f^{(n)}(\xi) - f[x_0,\dots,x_n] n!,$$

$$f[x_0,\dots,x_n] = \frac{f^{(n)}(\xi)}{n!}.$$

:::

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

The theorem can be used to generalise the [Stolarsky mean](wikipedia://en/7423338) to more than two variables.

:::
