# Nuprl

::: {#o1 .subject cue=lead name="Nuprl"}

**Nuprl** is a proof development system, providing computer-mediated analysis and [proofs](wikipedia://en/1197184) of formal mathematical statements, and tools for [software verification](https://en.wikipedia.org/wiki/Software_verification) and optimization. Originally developed in the 1980s by [Robert Lee Constable](https://en.wikipedia.org/wiki/Robert_Lee_Constable) and others, the system is now maintained by the PRL Project at [Cornell University](https://en.wikipedia.org/wiki/Cornell_University). The currently supported version, Nuprl 5, is also known as FDL (Formal Digital Library). Nuprl functions as an [automated theorem proving](wikipedia://en/2546) system and can also be used to provide [proof assistance](wikipedia://en/1258607).

:::

## Design {#Design}

Nuprl uses a [type system](wikipedia://en/199701) based on [Martin-Löf](https://en.wikipedia.org/wiki/Martin-Löf) [intuitionistic type theory](wikipedia://en/345023) to model mathematical statements in a [digital library](https://en.wikipedia.org/wiki/Digital_library). Mathematical theories can be constructed and analyzed with a variety of editors, including a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface), a web-based editor, and an [Emacs](https://en.wikipedia.org/wiki/Emacs) mode. A variety of evaluators and inference engines can operate on the statements in the library. Translators also allow statements to be manipulated with [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) and [OCaml](https://en.wikipedia.org/wiki/OCaml) programs.[^o3] The overall system is controlled with a variant of [ML](https://en.wikipedia.org/wiki/ML_%28programming_language%29).

Nuprl 5's architecture is described as a "distributed [open architecture](https://en.wikipedia.org/wiki/Open_architecture)",[^o3] and Nuprl 5 is intended primarily to be used as a [web service](https://en.wikipedia.org/wiki/Web_service) rather than as standalone software.

## History {#History}

Nuprl was first released in 1984, and was first described in detail in the book *Implementing Mathematics with the Nuprl Proof Development System*,[^o5] published in 1986. Nuprl 2 was the first [Unix](https://en.wikipedia.org/wiki/Unix) version. Nuprl 3 provided machine proof for mathematical problems related to [Girard's paradox](wikipedia://en/17870536) and [Higman's lemma](wikipedia://en/4187137). Nuprl 4, the first version developed for the [World Wide Web](https://en.wikipedia.org/wiki/World_Wide_Web), was used to verify cache coherency protocols and other computer systems.[^o6]

The current system architecture, implemented in Nuprl 5, was first proposed in a 2000 [conference paper](https://en.wikipedia.org/wiki/Conference_paper). A reference manual for Nuprl 5 was published in 2002.[^o7] Nuprl has been the subject of many [computer science](https://en.wikipedia.org/wiki/Computer_science) publications.

## Successors {#Successors}

Both the [JonPRL](https://github.com/jonsterling/JonPRL) and [RedPRL](http://www.redprl.org) systems are also based on computational type theory.[^o9] RedPRL is explicitly "inspired by Nuprl".[^o10]
