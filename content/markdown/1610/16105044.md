# Kleene's O

::: {#o1 .subject cue=lead name="Kleene's O"}

In [set theory](wikipedia://en/27553) and [computability theory](wikipedia://en/155414), **[Kleene](wikipedia://en/28805)'s $\mathcal{O}$** is a canonical subset of the [natural numbers](wikipedia://en/21474) when regarded as [ordinal notations](https://en.wikipedia.org/wiki/Ordinal_notations). It contains [ordinal notations](wikipedia://en/6108552) for every [computable ordinal](https://en.wikipedia.org/wiki/Recursive_ordinal), that is, ordinals below [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Church–Kleene_ordinal), $\omega_1^{\text{CK}}$. Since $\omega_1^{\text{CK}}$ is the first ordinal not representable in a computable system of ordinal notations the elements of $\mathcal{O}$ can be regarded as the canonical ordinal notations.

:::

Kleene (1938) described a system of notation for all computable ordinals (those less than the [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Church–Kleene_ordinal)). It uses a subset of the [natural numbers](wikipedia://en/21474) instead of finite strings of symbols. Unfortunately, there is in general no [effective](wikipedia://en/1139338) way to tell whether some natural number represents an ordinal, or whether two numbers represent the same ordinal. However, one can effectively find notations that represent the ordinal sum, product, and power (see [ordinal arithmetic](wikipedia://en/2139226)) of any two given notations in Kleene's $\mathcal{O}$; and given any notation for an ordinal, there is a [computably enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set) of notations that contains one element for each smaller ordinal and is effectively ordered.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The basic idea of Kleene's system of ordinal notations is to build up ordinals in an effective manner. For members $p$ of $\mathcal{O}$, the ordinal for which $p$ is a notation is $| p |$. $\mathcal{O}$ and $<_\mathcal{O}$ (a [partial ordering](https://en.wikipedia.org/wiki/Partial_order) of Kleene's $\mathcal{O}$) are the smallest sets such that the following holds.

- $$0 \in \mathcal{O} \land |0| = 0.$$
- $$i \in {\mathcal{O}} \land |i| = \alpha \rightarrow 2^i \in {\mathcal{O}} \land |2^i|= \alpha + 1 \land i < _{\mathcal {O}}2^{i}$$
- Suppose $\{ e \}$ is the $e$-th [partial computable function](https://en.wikipedia.org/wiki/Partial_computable_function). If $e$ is total and $\textrm{range}(\{e\}) \subseteq \mathcal {O} \land \forall n(\{e\}(n)<_{\mathcal{O}}\{e\}(n+1))$, then $3\cdot 5^{e} \in {\mathcal{O}} \land \forall n, \{e\}(n) <_{\mathcal {O}} 3 \cdot 5^{e} \land |3\cdot 5^{e}|=\lim_{k} | \{e\}(k) |$
- $$p<_{\mathcal{O}}q \land q<_{\mathcal{O}}r \rightarrow p<_{\mathcal {O}}r$$

This definition has the advantages that one can computably enumerate the predecessors of a given ordinal (though not in the $<_\mathcal{O}$ ordering) and that the notations are downward closed, i.e., if there is a notation for $\gamma$ and $\alpha < \gamma$ then there is a notation for $\alpha$. There are alternate definitions, such as the set of indices of (partial) well-orderings of the natural numbers.[^o4]

:::

## Explanation {#Explanation}

A member $p$ of Kleene's $\mathcal{O}$ is called a **notation** and is meant to give a definition of the ordinal $|p|$.

The successor notations are those such that $|p|$ is a successor ordinal $\alpha + 1$. In Kleene's $\mathcal{O}$, a [successor ordinal](wikipedia://en/375256) is defined in terms of a notation for the ordinal immediately preceding it. Specifically, a successor notation $p$ is of the form $2^q$ for some other notation $q$, so that $|p| = |q| + 1$.

The limit notations are those such that $|p|$ is a [limit ordinal](wikipedia://en/373137). In Kleene's $\mathcal{O}$, a notation for a limit ordinal $\beta$ amounts to a computable sequence of notations for smaller ordinals limiting to $\beta$. Any limit notation $p$ is of the form $3\cdot 5^e$ where the $e$'th partial computable function $\{e\}:\mathbb{N}\rightarrow\mathbb{N}$ is a total function listing an infinite sequence $\langle q_0, q_1...\rangle$ of notations that are strictly increasing under the order $<_\mathcal{O}$. The limit of the sequence of ordinals $\langle |q_0|, |q_1|...\rangle$ is $|p|$.

Although $q <_{\mathcal{O}} p$ implies $|q| < |p|$, $|q| < |p|$ does *not* imply $q <_{\mathcal{O}} p$.

In order for $q <_{\mathcal{O}} p$, $q$ must be reachable from $p$ by repeatedly applying the operations $2^n\mapsto n$ and $3\cdot 5^e\mapsto\{e\}(i)$ for $i\in\mathbb{N}$. In other words, $q <_{\mathcal{O}} p$ when $q$ is eventually referenced in the definition of $|p|$ given by $p$.

### A computably enumerable order extending the Kleene order {#A_computably_enumerable_order_extending_the_Kleene_order}

For arbitrary $p, q\in\mathbb{N}$, say that $q\prec p$ when $q$ is reachable from $p$ by repeatedly applying the operations $2^n\mapsto n$ and $3\cdot 5^e\mapsto\{e\}(i)$ for $i\in dom(\{e\})$. The relation $\prec$ agrees with $<_{\mathcal{O}}$ on $\mathcal{O}$, but $\prec$ is [computably enumerable](https://en.wikipedia.org/wiki/Computably_enumerable): if $q\prec p$, then a computer program will eventually find a proof of this fact.

For any notation $p\in\mathcal{O}$, all $q\prec p$ are themselves notations in $\mathcal{O}$.

For $p\in\mathbb{N}$, $p$ is a notation of $\mathcal{O}$ only when all of the criteria below are met:

- For all $q\preceq p$, $q$ is either $0$, a power of $2$, or $3\cdot 5^e$ for some $e\in\mathbb{N}$.
- For any $q\preceq p$, if $q=3\cdot 5^e$ then $\{e\}$ is total and strictly increasing under $\prec$; i.e. $\{e\}(i)\prec\{e\}(i+1)$ for any $i\in\mathbb{N}$.
- The set $\{q\in\mathbb{N} : q\prec p\}$ is [well-founded](https://en.wikipedia.org/wiki/Well-founded), so that there are no infinite descending sequences $...\prec q_1\prec q_0\prec p$.

## Basic properties of \<<sub>O</sub> {#Basic_properties_of_<O}

- If $|i| = \alpha$ and $|j| = \beta$ and $i <_{\mathcal{O}} j \,,$ then $\alpha < \beta$; but the converse may fail to hold.
- $<_\mathcal{O}$ induces a tree structure on $\mathcal{O}$, so $\mathcal{O}$ is [well-founded](wikipedia://en/319712).
- $\mathcal{O}$ only branches at limit ordinals; and at each notation of a limit ordinal, $\mathcal{O}$ is infinitely branching.
- Since every computable function has countably many indices, each infinite ordinal receives countably many notations; the finite ordinals have unique notations, $n$ usually denoted $n_\mathcal{O}$.
- The first ordinal that doesn't receive a notation is called the [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Church–Kleene_ordinal) and is denoted by $\omega^{\text{CK}}_1$. Since there are only countably many computable functions, the ordinal $\omega^{\text{CK}}_1$ is evidently countable.
- The ordinals with a notation in Kleene's $\mathcal{O}$ are exactly the [computable ordinals](https://en.wikipedia.org/wiki/Recursive_ordinal). (The fact that every computable ordinal has a notation follows from the closure of this system of ordinal notations under successor and effective limits.)
- $<_\mathcal{O}$ is not [computably enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable_set), but there is a computably enumerable relation that agrees with $<_\mathcal{O}$ precisely on members of $\mathcal{O}$.
- For any notation $p$, the set $\lbrace q \mid q <_{\mathcal{O}} p \rbrace$ of notations below $p$ is computably enumerable. However, Kleene's $\mathcal{O}$, when taken as a whole, is $\Pi^1_1$ (see [analytical hierarchy](wikipedia://en/634233)) and not arithmetical because of the following:
- $\mathcal{O}$ is $\Pi^1_1$-complete (i.e. $\mathcal{O}$ is $\Pi^1_1$ and every $\Pi^1_1$ set is Turing reducible to it)[^o8] and every $\Sigma^1_1$ subset of $\mathcal{O}$ is effectively bounded in $\mathcal{O}$ (a result of Spector).
- In fact, any $\Pi^1_1$ set is [many-one reducible](https://en.wikipedia.org/wiki/Many-one_reducible) to $\mathcal{O}$.[^o8]
- $\mathcal{O}$ is the universal system of ordinal notations in the sense that any specific set of ordinal notations can be mapped into it in a straightforward way. More precisely, there is a computable function $f$ such that if $e$ is an index for a computable well-ordering, then $f(e)$ is a member of $\mathcal{O}$ and $<_e$ is order-isomorphic to an initial segment of the set $\{ p \mid p <_\mathcal{O} f(e) \}$.
- There is a computable function $+_\mathcal{O}$, which, for members of $\mathcal{O}$, mimics ordinal addition and has the property that $\max \{ p,q \} \leq p +_\mathcal{O} q$. (Jockusch)

## Properties of paths in \<<sub>O</sub> {#Properties_of_paths_in_<O}

A path in $\mathcal{O}$ is a subset $\mathcal{P}$ of $\mathcal{O}$ that is totally ordered by $<_\mathcal{O}$ and is closed under predecessors, i.e. if $p$ is a member of a path $\mathcal{P}$ and $q <_\mathcal{O} p$ then $q$ is also a member of $\mathcal{P}$. A path $\mathcal{P}$ is maximal if there is no element of $\mathcal{O}$ that is above (in the sense of $<_\mathcal{O}$) every member of $\mathcal{P}$, otherwise $\mathcal{P}$ is non-maximal.

- A path $\mathcal{P}$ is non-maximal if and only if $\mathcal{P}$ is computably enumerable (c.e.). It follows by remarks above that every element $p$ of $\mathcal{O}$ determines a non-maximal path $\mathcal{P}$; and every non-maximal path is so determined.
- There are $2^{\aleph_0}$ maximal paths through $\mathcal{O}$; since they are maximal, they are non-c.e.
- In fact, there are $2^{\aleph_0}$ maximal paths *within* $\mathcal{O}$ of length $\omega^2$. (Crossley, Schütte)
- For every non-zero ordinal $\lambda < \omega_1^{CK}$, there are $2^{\aleph_0}$ maximal paths within $\mathcal{O}$ of length $\omega^2 \cdot \lambda$. (Aczel)
- Further, if $\mathcal{P}$ is a path whose length is *not* a multiple of $\omega^2$ then $\mathcal{P}$ is not maximal. (Aczel)
- For each c.e. degree $d$, there is a member $e_d$ of $\mathcal{O}$ such that the path $\mathcal{P} = \lbrace p \mid p <_{\mathcal{O}} e_d \rbrace$ has many-one degree $d$. In fact, for each computable ordinal $\alpha \geq \omega^2$, a notation $e_d$ exists with $|e_d| = \alpha$. (Jockusch)
- There exist $\aleph_0$ paths through $\mathcal{O}$ that are $\Pi_1^1$. Given a progression of computably enumerable theories based on iterating Uniform Reflection, each such path is incomplete with respect to the set of true $\Pi_1^0$ sentences. (Feferman & Spector)
- There exist $\Pi^1_1$ paths through $\mathcal{O}$ each initial segment of which is not merely c.e., but computable. (Jockusch)
- Various other paths in $\mathcal{O}$ have been shown to exist, each with specific kinds of reducibility properties. (See references below)
