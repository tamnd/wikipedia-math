# Taguette

::: {#o1 .subject cue=lead name="Taguette"}

**Taguette** is a free and [open-source](https://en.wikipedia.org/wiki/Open_source) tool for textual [qualitative data analysis](https://en.wikipedia.org/wiki/Qualitative_data_analysis).[^o3] It allows users to import textual data, highlight and tag/code the data and export the results. The software is used in a wide range of fields such as anthropology,[^o4] education,[^o5] nursing,[^o6] psychology,[^o7] sociology[^o8] and marketing.[^o9]

:::

## Features {#Features}

Taguette is intended to help users analyse unstructured textural data such as: observations, interviews, documents and audiovisual materials.[^o3] The software can import PDFs, Word Docs, Text files, HTML, EPUB, MOBI, Open Documents and Rich Text Files.

The software allows users to highlight words, sentences, or paragraphs and tag them with the codes either as an individual researcher, or as part of a team when the software is installed on a server.[^o11]

Users report that there is a low learning curve[^o12] and the collaborative nature of the software is highlighted.[^o13] The lack of nested codes has been identified as a limitation by some users,[^o14] however the developers state that the software allows users to nest codes, but currently they are not visually displayed in a tree.[^o15]

## History {#History}

According to the developers, the motivation for creating Taguette was a lack of functional free software to undertake qualitative research.[^o3] Initially created around late 2018, the release of version 1.0.0 in mid-2021 formalised its stable baseline. Since then, incremental updates have extended functionality, improved stability and support for more import formats.[^o17]
