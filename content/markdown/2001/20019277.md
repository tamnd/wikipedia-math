# Threefish

::: {#o1 .subject cue=lead name="Threefish"}

**Threefish** is a [symmetric-key](wikipedia://en/53042) [tweakable block cipher](https://en.wikipedia.org/wiki/Tweakable_block_cipher) designed as part of the [Skein hash function](https://en.wikipedia.org/wiki/Skein_hash_function), an entry in the [NIST hash function competition](wikipedia://en/20051952). Threefish uses no [S-boxes](wikipedia://en/240991) or other table lookups in order to avoid cache [timing attacks](wikipedia://en/481813);[^o3] its nonlinearity comes from alternating additions with [exclusive ORs](https://en.wikipedia.org/wiki/Exclusive_OR). In that respect, it is similar to [Salsa20](wikipedia://en/2701329), [TEA](wikipedia://en/528720), and the SHA-3 candidates [CubeHash](wikipedia://en/20394410) and [BLAKE](wikipedia://en/30054589).

:::

Threefish and the Skein hash function were designed by [Bruce Schneier](wikipedia://en/36732), [Niels Ferguson](wikipedia://en/204933), [Stefan Lucks](https://en.wikipedia.org/wiki/Stefan_Lucks), Doug Whiting, [Mihir Bellare](https://en.wikipedia.org/wiki/Mihir_Bellare), Tadayoshi Kohno, [Jon Callas](https://en.wikipedia.org/wiki/Jon_Callas), and Jesse Walker. "Threefish is unpatented, and the source code is uncopyrighted and license-free; it is free for all uses."[^o4]

## Description of the cipher {#Description_of_the_cipher}

Threefish works on words of 64 [bits](https://en.wikipedia.org/wiki/Bit) (unsigned [Little endian](https://en.wikipedia.org/wiki/Little_endian) [integers](wikipedia://en/14563)). $w \in \{4,8,16\}$ is the number of plaintext words and also of key words. The tweak consists of two words. All additions and subtractions are defined modulo $2^{64}$.

### Key schedule {#Key_schedule}

Threefish encrypts in $r$ rounds and uses $\frac{r}{4} + 1$ different round keys. After every four rounds, and before the first, $w$ round key words are added to the $w$ data words. To calculate the round keys an additional key word $k_w$ is appended to the original key words $k_0, k_1, \dots, k_{w - 1}$. Also, an additional tweak word $t_2$ is appended to the tweak words $t_0, t_1$.

$$k_w = C \oplus k_0 \oplus k_1 \oplus \dots \oplus k_{w - 1}; \quad C = \text{0x1BD11BDAA9FC1A22}$$

$$t_2 = t_0 \oplus t_1$$

The purpose of the seemingly arbitrary constant $C$ is to frustrate some attacks that take advantage of the relationship between $k_w$ and the other keywords.

The round key words $k_{s, i}$ are now defined like this:

$$k_{s, i} = \begin{cases} k_{(s+i) \bmod (w + 1)} & i = 0, \dots, w - 4 \\ k_{(s+i) \bmod (w + 1)} + t_{s \bmod 3} & i = w - 3 \\ k_{(s+i) \bmod (w + 1)} + t_{(s + 1) \bmod 3} & i = w - 2 \\ k_{(s+i) \bmod (w + 1)} + s & i = w - 1 \end{cases}$$

Here $s = 0, 1, \dots , r/4$, where $4s$ is the number of the round in which the round key word $k_{s,i}$ is used.

### Mix function {#Mix_function}

*Image: Skein Mix Function.png.* Threefish Mix Function

The mix function takes a [tuple](wikipedia://en/132729) of words $(x_0, x_1)$ and returns another tuple of words $(y_0, y_1)$. The function is defined like this:

$$y_0 = (x_0 + x_1) \bmod 2^{64}$$

$$y_1 = (x_1 \lll R_{(d \bmod 8), j}) \oplus y_0$$

$R_{d, j}$ is a fixed set of rotation constants chosen to achieve quick [diffusion](wikipedia://en/537555).

### Permute {#Permute}

The permutation step swaps the positions of the words according to a constant pattern. Bit-level permutation is not achieved in this step, but this is not necessary since the MIX functions provides bit-level permutations in the form of bitwise rotations. The Permute step and rotation constants in the MIX functions are chosen in such a way that the overall effect is complete diffusion of all the bits in a data block.

Because this permutation is fixed and independent of the key, the time needed to compute it does not provide information about the key or plaintext. This is important because on most modern microprocessors performance optimisations can make the time taken to compute an array operation dependent on where the data is stored in memory. In ciphers where array lookup depends on either the key or plaintext (as is the case for the substitution step in AES), it can make the cipher vulnerable to [timing attacks](wikipedia://en/481813) by examining the time required for encryption. The permutation is therefore deliberately designed to ensure that it should execute in the same fashion independent of the key being used or the data encrypted.

### A full Threefish round {#A_full_Threefish_round}

- if $d\;\bmod\;4 = 0$ the round key $k_{d/4,i}$ is added to word $i$
- the mix function is applied to pairs of words, the rotation widths $R_{d \bmod 8,j}$ depend on round number $d$ and word pair $j\in\{0,\cdots,w/2-1\}$
- the words are permutated using a permutation independent from the round number

Threefish256 and Threefish512 apply this round $r=72$ times ($d=0,1, \dots,71$). Threefish1024 applies it 80 times ($d=0,1, \dots,79$).

### Final operations {#Final_operations}

After all rounds are applied, the last round key words $k_{r/4,i}$ are added to the words and the words are converted back to a string of bytes.

## Security {#Security}

In October 2010, an attack that combines [rotational cryptanalysis](wikipedia://en/26122724) with the [rebound attack](https://en.wikipedia.org/wiki/Rebound_attack) was published. The attack mounts a [known-key distinguisher](https://en.wikipedia.org/wiki/Known-key_distinguisher) against 53 of 72 rounds in Threefish-256, and 57 of 72 rounds in Threefish-512. It also affects the [Skein](wikipedia://en/20007592) hash function.[^o12] This is a follow-up to the earlier attack published in February, which breaks 39 and 42 rounds respectively.[^o13] In response to this attack, the Skein team tweaked the rotation constants used in Threefish and thereby the [key schedule](wikipedia://en/609603) constants for round 3 of the NIST hash function competition.[^o3]

In 2009, a related key [boomerang attack](wikipedia://en/2137332) against a reduced round Threefish version was published. For the 32-round version, the time complexity is $2^{226}$ and the memory complexity is $2^{12}$; for the 33-round version, the time complexity is $2^{352.17}$ with a negligible memory usage. The attacks also work against the tweaked version of Threefish: for the 32-round version, the time complexity is $2^{222}$ and the memory complexity is $2^{12}$; for the 33-round version, the time complexity is $2^{355.5}$ with a negligible memory usage.[^o14]
