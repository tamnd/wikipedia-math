# Sub-group hiding

::: {#o1 .subject cue=lead name="Sub-group hiding"}

The **sub-group hiding** assumption is a computational hardness assumption used in [elliptic curve cryptography](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography) and [pairing-based cryptography](wikipedia://en/8605953).

:::

It was first introduced to build a [2-DNF](wikipedia://en/73341) [homomorphic encryption](wikipedia://en/4939073) scheme.[^o2]
