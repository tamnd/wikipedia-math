# Polar set (potential theory)

::: {#o1 .subject cue=lead name="Polar set"}

In [mathematics](wikipedia://en/18831), in the area of classical [potential theory](wikipedia://en/1431342), **polar sets** are the "negligible sets", similar to the way in which sets of measure zero are the [negligible sets](wikipedia://en/195132) in [measure theory](https://en.wikipedia.org/wiki/Measure_theory).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A set $Z$ in $\mathbb{R}^n$ (where $n\ge 2$) is a polar set if there is a non-constant [subharmonic function](wikipedia://en/3237359)

$u$ on $\mathbb{R}^n$

such that

$$Z \subseteq \{x \in \mathbb{R}^n: u(x) = -\infty\}.$$

Note that there are other (equivalent) ways in which polar sets may be defined, such as by replacing "subharmonic" by "superharmonic", and $-\infty$ by $\infty$ in the definition above.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The most important properties of polar sets are:

- A singleton set in $\mathbb{R}^n$ is polar.
- A countable set in $\mathbb{R}^n$ is polar.
- The union of a countable collection of polar sets is polar.
- A polar set has Lebesgue measure zero in $\mathbb{R}^n.$

:::

::: {#o7 .pointer-item cue=pointer name="Nearly everywhere"}

## Nearly everywhere {#Nearly_everywhere}

A property holds **nearly everywhere** in a set *S* if it holds on *S*−*E* where *E* is a Borel polar set. If *P* holds nearly everywhere then it holds [almost everywhere](wikipedia://en/44688).[^o8]

:::
