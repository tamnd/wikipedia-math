# Bobkov's inequality

::: {#o1 .subject cue=lead name="Bobkov's inequality"}

In [probability theory](wikipedia://en/23542), **Bobkov's inequality** is a [functional](wikipedia://en/1374948) [isoperimetric inequality](wikipedia://en/326182) for the canonical [Gaussian measure](wikipedia://en/6572909). It generalizes the [Gaussian isoperimetric inequality](wikipedia://en/9082215). The equation was proven in 1997 by the [Russian](https://en.wikipedia.org/wiki/Russia) mathematician [Sergey Bobkov](wikipedia://en/42666668).[^o2]

:::

::: {#o4 .statement cue=named-heading name="Bobkov's inequality"}

## Bobkov's inequality {#Bobkov's_inequality}

**Notation:**

Let

- $\gamma^n(dx)=(2\pi)^{-n/2}e^{-\|x\|^2/2}d^nx$ be the canonical Gaussian measure on $\mathbb{R}^n$ with respect to the [Lebesgue measure](wikipedia://en/18198),
- $\phi(x)=(2\pi)^{-1/2}e^{-x^2/2}$ be the one dimensional canonical Gaussian density
- $\Phi(t)=\gamma^1[-\infty,t]$ the cumulative distribution function
- $I(t):=\phi(\Phi^{-1}(t))$ be a function $I(t):[0,1]\to [0,1]$ that vanishes at the end points $\lim\limits_{t\to 0} I(t)=\lim\limits_{t\to 1} I(t)=0.$

::: {#o6 .statement cue=heading name="Statement"}

### Statement {#Statement}

For every [locally Lipschitz continuous](wikipedia://en/51731) (or [smooth](https://en.wikipedia.org/wiki/Smooth_function)) function $f:\mathbb{R}^n\to[0,1]$ the following inequality holds[^o7][^o8]

$$I\left( \int_{\mathbb{R}^n} f d\gamma^n(dx)\right)\leq \int_{\mathbb{R}^n} \sqrt{I(f)^2+|\nabla f|^2}d\gamma^n(dx).$$

:::

## Generalizations {#Generalizations}
