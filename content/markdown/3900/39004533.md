# Quadratic Frobenius test

::: {#o1 .subject cue=lead name="Quadratic Frobenius test"}

The **quadratic Frobenius test** (**QFT**) is a [probabilistic](https://en.wikipedia.org/wiki/Probabilistic_algorithm) [primality test](wikipedia://en/183751) to determine whether a number is a [probable prime](wikipedia://en/160560). It is named after [Ferdinand Georg Frobenius](wikipedia://en/341048). The test uses the concepts of [quadratic polynomials](https://en.wikipedia.org/wiki/Quadratic_polynomial) and the [Frobenius automorphism](https://en.wikipedia.org/wiki/Frobenius_automorphism). It should not be confused with the more general [Frobenius test](wikipedia://en/2246360) using a quadratic polynomial – the QFT restricts the polynomials allowed based on the input, and also has other conditions that must be met. A [composite](wikipedia://en/82289) passing this test is a [Frobenius pseudoprime](wikipedia://en/2246360), but the converse is not necessarily true.

:::

## Concept {#Concept}

Grantham's stated goal when developing the algorithm was to provide a test that primes would always pass and composites would pass with a probability of less than 1/7710.[^o3]

The test was later extended by [Damgård](https://en.wikipedia.org/wiki/Ivan_Damgård) and Frandsen to a test called *extended quadratic Frobenius test* (EQFT).[^o4]

## Algorithm {#Algorithm}

Let $n$ be a positive integer such that $n$ is odd, and let *b* and *c* be integers such that $\left(\frac{b^2+4c}{n}\right) = -1$ and $\left(\frac{-c}{n}\right) = 1$, where $\left(\frac{\cdot}{\cdot}\right)$ denotes the [Jacobi symbol](wikipedia://en/97313). Set $B = 50000$. Then a *QFT* on $n$ with parameters ($b$, $c$) works as follows:

**(1)** Test whether any of the primes less than or equal to $\min(B, \sqrt{n})$ divides $n$. If yes, then stop: $n$ is composite.

**(2)** Test whether $\sqrt{n} \in \mathbb{Z}$. If yes, then stop: $n$ is composite.

**(3)** Compute $x^{n+1 \over 2}\,\bmod\,\big(n,x^2-bx-c)$. If $x^{n+1 \over 2} \notin \mathbb{Z} \big / n \mathbb{Z}$, then stop: $n$ is composite.

**(4)** Compute $x^{n+1}\,\bmod\,\big(n,x^2-bx-c)$. If $x^{n+1} \not\equiv -c$, then stop: $n$ is composite.

**(5)** Let $n^2-1=2^{r}s$ with $s$ odd. If $x^s \not\equiv 1 \bmod\,\big(n,x^2-bx-c)$, and $x^{2^{j}s} \not\equiv -1 \bmod\,\big(n,x^2-bx-c)$ for all $0 \leq j \leq r-2$, then stop: $n$ is composite.

If the *QFT* does not stop in steps (1)–(5), then $n$ is a probable prime.

(The notation $A \equiv B \bmod \, (n, \, f(x))$ means that $A - B = H(x) \cdot n + K(x) \cdot f(x)$, where H and K are polynomials.)
