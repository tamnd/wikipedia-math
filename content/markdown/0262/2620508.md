# Unconditional convergence

::: {#o1 .subject cue=lead name="Unconditional convergence"}

In [mathematics](wikipedia://en/18831), specifically [functional analysis](wikipedia://en/11180), a series is **unconditionally convergent** if all reorderings of the series converge to the same value. In contrast, a series is [conditionally convergent](wikipedia://en/1198956) if it converges but different orderings do not all converge to that same value. Unconditional convergence is equivalent to [absolute convergence](wikipedia://en/61532) in [finite-dimensional](wikipedia://en/38267) [vector spaces](wikipedia://en/32370), but is a weaker property in infinite dimensions.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [topological vector space](wikipedia://en/45752). Let $I$ be an [index set](wikipedia://en/393055) and $x_i \in X$ for all $i \in I.$

The series $\textstyle \sum_{i \in I} x_i$ is called **unconditionally convergent** to $x \in X,$ if

- the indexing set $I_0 := \left\{i \in I : x_i \neq 0\right\}$ is [countable](https://en.wikipedia.org/wiki/Countable), and
- for every [permutation](wikipedia://en/44027) ([bijection](wikipedia://en/3942)) $\sigma : I_0 \to I_0$ of $I_0 = \left\{i_k\right\}_{k=1}^\infty$ the following relation holds: $\sum_{k=1}^\infty x_{\sigma\left(i_k\right)} = x.$

:::

::: {#o5 .definition cue=heading name="Alternative definition"}

## Alternative definition {#Alternative_definition}

Unconditional convergence is often defined in an equivalent way: A series is unconditionally convergent if for every sequence $\left(\varepsilon_n\right)_{n=1}^\infty,$ with $\varepsilon_n \in \{-1, +1\},$ the series

$$\sum_{n=1}^\infty \varepsilon_n x_n$$

converges.

If $X$ is a [Banach space](wikipedia://en/3989), every [absolutely convergent](wikipedia://en/61532) series is unconditionally convergent, but the [converse](wikipedia://en/155941) implication does not hold in general. Indeed, if $X$ is an infinite-dimensional Banach space, then by [Dvoretzky–Rogers theorem](wikipedia://en/61532#Rearrangements_and_unconditional_convergence) there always exists an unconditionally convergent series in this space that is not absolutely convergent. However, when $X = \mathbb{R}^n,$ by the [Riemann series theorem](wikipedia://en/1895800), the series $\sum_n x_n$ is unconditionally convergent if and only if it is absolutely convergent.

:::
