# Crystal Ball function

*Image: CrystalBallFunction.svg.* Examples of the Crystal Ball function.

::: {#o1 .subject cue=lead name="Crystal Ball function"}

The **Crystal Ball function**, named after the [Crystal Ball](https://en.wikipedia.org/wiki/Crystal_Ball_%28detector%29) Collaboration (hence the capitalized initial letters), is a [probability density function](wikipedia://en/43487) (PDF) commonly used to model various lossy processes in [high-energy physics](https://en.wikipedia.org/wiki/High-energy_physics) such as [Bremsstrahlung](wikipedia://en/54147) by electrons. It consists of a [Gaussian](wikipedia://en/245552) core portion and a [power-law](https://en.wikipedia.org/wiki/Power-law) low-end tail, below a certain threshold. The function itself and its first [derivative](wikipedia://en/7921) are both [continuous](wikipedia://en/6122).

:::

The Crystal Ball function is given by:

$$f(x;\alpha,n,\bar x,\sigma) = N \cdot \begin{cases} \exp(- \frac{(x - \bar x)^2}{2 \sigma^2}), & \mbox{for }\frac{x - \bar x}{\sigma} > -\alpha \\ A \cdot (B - \frac{x - \bar x}{\sigma})^{-n}, & \mbox{for }\frac{x - \bar x}{\sigma} \leqslant -\alpha \end{cases} ,$$

where

$$A = \left(\frac{n}{\left| \alpha \right|}\right)^n \cdot \exp\left(- \frac {\left| \alpha \right|^2}{2}\right),$$

$$B = \frac{n}{\left| \alpha \right|} - \left| \alpha \right|,$$

$$N = \frac{1}{\sigma (C + D)},$$

$$C = \frac{n}{\left| \alpha \right|} \cdot \frac{1}{n-1} \cdot \exp\left(- \frac {\left| \alpha \right|^2}{2}\right),$$

$$D = \sqrt{\frac{\pi}{2}} \left(1 + \operatorname{erf}\left(\frac{\left| \alpha \right|}{\sqrt 2}\right)\right),$$

with the [error function](wikipedia://en/177111) erf.

The parameters of the function (that are usually determined by a fit) are:

- $N$ is a normalization factor (Skwarnicki 1986)
- $\alpha>0$ defines the point where the PDF changes from a power-law to a Gaussian distribution
- $n>1$ is the power of the power-law tail
- $\bar x$ and $\sigma$ are the [mean](https://en.wikipedia.org/wiki/Mean) and the [standard deviation](wikipedia://en/27590) of the Gaussian
