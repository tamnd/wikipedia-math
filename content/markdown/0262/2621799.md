# Condensed detachment

::: {#o1 .subject cue=lead name="Condensed detachment"}

**Condensed detachment** (Rule D) is a method of finding the most general possible conclusion given two formal logical statements. It was developed by the Irish [logician](https://en.wikipedia.org/wiki/Logician) [Carew Meredith](https://en.wikipedia.org/wiki/Carew_Meredith) in the 1950s and inspired by the work of [Łukasiewicz](wikipedia://en/305064).[^o4]

:::

## Informal description {#Informal_description}

A rule of detachment (often referred to as [modus ponens](wikipedia://en/18900)) says: "Given that $p$ implies $q$, and given $p$, infer $q$."

The condensed detachment goes a step further and says: "Given that $p$ implies $q$, and given an $r$, use a [unifier](wikipedia://en/54432#Syntactic_unification_of_first-order_terms) of $p$ and $r$ to make $p$ and $r$ the same, then use a standard rule of detachment."

A [substitution](wikipedia://en/5438948) *A* that when applied to $p$ produces $t$, and substitution *B* that when applied to $r$ produces $t$, are called unifiers of $p$ and $r$.

Various unifiers may produce expressions with varying numbers of [free variables](https://en.wikipedia.org/wiki/Free_variable). Some possible unifying expressions are [substitution instances](https://en.wikipedia.org/wiki/Substitution_instance) of others. If one expression is a substitution instance of another (and not just a variable renaming), then that other is called "more general".

If the most general unifier is used in condensed detachment, then the logical result is the most general conclusion that can be made in the given inference with the given second expression. Since any weaker inference you can get is a substitution instance of the most general one, nothing less than the most general unifier is ever used in practice.

Some logics, such as classical [propositional calculus](https://en.wikipedia.org/wiki/Propositional_calculus), have a set of defining axioms with the "D-completeness" property. If a set of axioms is D-Complete, then any valid theorem of the system, including all of its substitution instances (up to variable renaming), can be generated by condensed detachment alone. For example, if $p \rightarrow p$ is a theorem of a D-complete system, condensed detachment can prove not only that theorem but also its substitution instance $( p \rightarrow p ) \rightarrow ( p \rightarrow p )$ by using a longer proof. Note that "D-completeness" is a property of an axiomatic basis for a system, not an intrinsic property of a logic system itself.[^o3]

J. A. Kalman proved that any conclusion that can be generated by a sequence of uniform substitution (all instances of a variable are replaced with the same content) and *[modus ponens](wikipedia://en/18900)* steps can either be generated by condensed detachment alone, or is a substitution instance of something that can be generated by condensed detachment alone.[^o4] This makes condensed detachment useful for any logic system that has *[modus ponens](wikipedia://en/18900)* and substitution, regardless of whether or not it is D-complete.

## D-notation {#D-notation}

Since a given major premise and a given minor premise uniquely determine the conclusion (up to variable renaming), [Meredith](https://en.wikipedia.org/wiki/Carew_Meredith) observed that it was only necessary to note which two statements were involved and that the condensed detachment can be used without any other notation required. This led to the "D-notation" for [proofs](wikipedia://en/82285). This notation uses the "D" operator to mean condensed detachment, and takes 2 arguments, in a standard [prefix notation](https://en.wikipedia.org/wiki/Prefix_notation) string. For example, if you have four axioms a typical proof in D-notation might look like: DD12D34 which shows a condensed detachment step using the result of two prior condensed detachment steps, the first of which used axioms 1 and 2, and the second of which used axioms 3 and 4.

This notation, besides being used in some automated theorem provers, sometimes appears in catalogs of proofs. For example, the "shortest known proofs" database of [Metamath](wikipedia://en/6023946)'s mmsolitaire project features 196 theorems with such proofs.[^o6]

Condensed detachment's use of unification predates the [resolution](wikipedia://en/2724082) technique of [automated theorem proving](wikipedia://en/2546) which was introduced in 1965.[^o7][^o8]

## Advantages {#Advantages}

For automated theorem proving condensed detachment has a number of advantages over raw *[modus ponens](wikipedia://en/18900)* and uniform substitution.

At a proof using modus ponens and substitution you have an infinite number of choices for what you can substitute for variables. This means that you have an infinite number of possible next steps. With condensed detachment there are only a finite number of possible next steps in a proof, namely the most general variants of combined previous steps or axioms.

The D-notation for complete condensed detachment proofs allows easy description of proofs for cataloging and search. A typical complete 15-step proof is only 15 characters long in D-notation (excluding the statement of the axioms). It can slightly increase by referencing more than nine axioms or theorems, e.g. one could write DD2.10D11DD5.6D9D35.3 using dots to separate multi-digit numbers (but also DD2aDbDD56D9Dz3 for the same proof for up to 35 reference numbers).
