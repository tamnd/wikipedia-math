# Weak coloring

::: {#o1 .subject cue=lead name="Weak coloring"}

*Image: Weak-2-coloring.svg.* Weak 2-coloring.

In [graph theory](wikipedia://en/12401), a **weak coloring** is a special case of a [graph labeling](wikipedia://en/1609861). A weak $k$-coloring of a graph $G = (V, E)$ assigns a color $c(v) \in \{1, 2, ..., k$} to each vertex $v \in V$, such that each non-[isolated vertex](https://en.wikipedia.org/wiki/Isolated_vertex) is adjacent to at least one vertex with different color. In notation, for each non-isolated $v \in V$, there is a vertex $u \in V$ with $\{u, v\} \in E$ and $c(u) \ne c(v)$.

:::

The figure on the right shows a weak 2-coloring of a graph. Each dark vertex (color 1) is adjacent to at least one light vertex (color 2) and vice versa.

*Image: Weak-2-coloring-construct.svg.* Constructing a weak 2-coloring.

## Properties {#Properties}

A graph [vertex coloring](https://en.wikipedia.org/wiki/Vertex_coloring) is a weak coloring, but not necessarily vice versa.

Every graph has a weak 2-coloring. The figure on the right illustrates a simple algorithm for constructing a weak 2-coloring in an arbitrary graph. Part (a) shows the original graph. Part (b) shows a [breadth-first search](wikipedia://en/97026) tree of the same graph. Part (c) shows how to color the tree: starting from the root, the layers of the tree are colored alternatingly with colors 1 (dark) and 2 (light).

If there is no [isolated vertex](https://en.wikipedia.org/wiki/Isolated_vertex) in the graph $G$, then a weak 2-coloring determines a [domatic partition](https://en.wikipedia.org/wiki/Domatic_partition): the set of the nodes with $c(v) = 1$ is a [dominating set](wikipedia://en/1747972), and the set of the nodes with $c(v) = 2$ is another dominating set.

:::

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

Historically, weak coloring served as the first non-trivial example of a graph problem that can be solved with a [local algorithm](https://en.wikipedia.org/wiki/Local_algorithm) (a [distributed algorithm](https://en.wikipedia.org/wiki/Distributed_algorithm) that runs in a constant number of synchronous communication rounds). More precisely, if the [degree](wikipedia://en/1374448) of each node is odd and bounded by a constant, then there is a constant-time distributed algorithm for weak 2-coloring.[^o6]

This is different from (non-weak) [vertex coloring](https://en.wikipedia.org/wiki/Vertex_coloring): there is no constant-time distributed algorithm for vertex coloring; the best possible algorithms (for finding a minimal but not necessarily minimum coloring) require $O( |V|)$ communication rounds.[^o6][^o7][^o8] Here $x$ is the [iterated logarithm](wikipedia://en/1038048) of $x$.

:::
