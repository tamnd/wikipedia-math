# Lüroth's theorem

::: {#o1 .subject cue=lead name="Lüroth's theorem"}

In [mathematics](wikipedia://en/18831), **Lüroth's theorem** asserts that every [field](wikipedia://en/10603) that lies between a field *K* and the [rational function field](https://en.wikipedia.org/wiki/Rational_function_field) *K*(*X*) must be generated as an [extension](wikipedia://en/11634) of *K* by a single element of *K*(*X*). This result is named after [Jacob Lüroth](wikipedia://en/33271640), who proved it in 1876.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $K$ be a field and $M$ be an intermediate field between $K$ and $K(X)$, for some indeterminate *X*. Then there exists a [rational function](wikipedia://en/361210) $f(X)\in K(X)$ such that $M=K(f(X))$. In other words, every intermediate extension between $K$ and $K(X)$ is a [simple extension](wikipedia://en/4771726).

:::

::: {#o6 .proof cue=heading name="Proofs"}

## Proofs {#Proofs}

The proof of Lüroth's theorem can be derived easily from the theory of [rational curves](https://en.wikipedia.org/wiki/Rational_curve), using the [geometric genus](wikipedia://en/3115807).[^o7] This method is non-elementary, but several short proofs using only the basics of [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29) have long been known, mainly using the concept of [transcendence degree](https://en.wikipedia.org/wiki/Transcendence_degree).[^o8] Many of these simple proofs use [Gauss's lemma on primitive polynomials](https://en.wikipedia.org/wiki/Gauss's_lemma_%28polynomial%29) as a main step.[^o9]

:::
