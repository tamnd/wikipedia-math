# Nilpotent operator

::: {#o1 .subject cue=lead name="Nilpotent operator"}

In [operator theory](wikipedia://en/712675), a [bounded operator](wikipedia://en/455961) *T* on a [Banach space](wikipedia://en/3989) is said to be **[nilpotent](wikipedia://en/252235)** if *T<sup>n</sup>* = 0 for some positive integer *n*.[^o2] It is said to be **quasinilpotent** or **topologically nilpotent** if its [spectrum](wikipedia://en/206137) *σ*(*T*) = {0}.

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

In the finite-dimensional case, i.e. when *T* is a square matrix ([Nilpotent matrix](wikipedia://en/1167800)) with complex entries, *σ*(*T*) = {0} if and only if *T* is similar to a matrix whose only nonzero entries are on the superdiagonal[^o5](this fact is used to prove the existence of [Jordan canonical form](https://en.wikipedia.org/wiki/Jordan_canonical_form)). In turn this is equivalent to *T<sup>n</sup>* = 0 for some *n*. Therefore, for matrices, quasinilpotency coincides with nilpotency.

This is not true when *H* is infinite-dimensional. Consider the [Volterra operator](wikipedia://en/3654902), defined as follows: consider the unit square *X* = \[0,1\] × \[0,1\] ⊂ **R**<sup>2</sup>, with the [Lebesgue measure](wikipedia://en/18198) *m*. On *X*, define the [kernel function](https://en.wikipedia.org/wiki/Integral_kernel) *K* by

$$K(x,y) = \left\{ \begin{matrix} 1, & \mbox{if} \; x \geq y\\ 0, & \mbox{otherwise}. \end{matrix} \right.$$

The Volterra operator is the corresponding [integral operator](wikipedia://en/2649421) *T* on the Hilbert space *L*<sup>2</sup>(0,1) given by

$$T f(x) = \int_0 ^1 K(x,y) f(y) dy.$$

The operator *T* is not nilpotent: take *f* to be the function that is 1 everywhere and direct calculation shows that *T<sup>n</sup> f* ≠ 0 (in the sense of *L*<sup>2</sup>) for all *n*. However, *T* is quasinilpotent. First notice that *K* is in *L*<sup>2</sup>(*X*, *m*), therefore *T* is [compact](wikipedia://en/6690773). By the spectral properties of compact operators, any nonzero *λ* in *σ*(*T*) is an eigenvalue. But it can be shown that *T* has no nonzero eigenvalues, therefore *T* is quasinilpotent.

:::
