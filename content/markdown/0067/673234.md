# Prefix grammar

::: {#o1 .subject cue=lead name="Prefix grammar"}

In [theoretical computer science](wikipedia://en/323392) and [formal language theory](https://en.wikipedia.org/wiki/Formal_language_theory), a **prefix grammar** is a type of [string rewriting system](https://en.wikipedia.org/wiki/String_rewriting_system), consisting of a set of [string](wikipedia://en/27701) [rewriting](wikipedia://en/415847) rules, and similar to a [formal grammar](wikipedia://en/18020716) or a [semi-Thue system](wikipedia://en/2452154). What is specific about prefix grammars is not the shape of their rules, but the way in which they are applied: only [prefixes](https://en.wikipedia.org/wiki/Prefix_%28computer_science%29) are rewritten. The prefix grammars describe exactly all [regular languages](wikipedia://en/25723).[^o2]

:::

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A prefix grammar *G* is a [3-tuple](https://en.wikipedia.org/wiki/N-tuple), (Σ, *S*, *P*), where

- Σ is a finite alphabet
- *S* is a finite set of base strings over Σ
- *P* is a finite set of production rules of the form *u* → *v* where *u* and *v* are strings over Σ

For strings *x*, *y*, we write *x* →<sub>*G*</sub> *y* (and say: *G* can derive *y* from *x* in one step) if there are strings *u, v, w* such that $x = vu, y = wu$, and *v* → *w* is in *P*. Note that $\to_{G}$ is a [binary relation](wikipedia://en/3931) on the strings of Σ.

The *language* of *G*, denoted $L(G)$, is the set of strings derivable from *S* in zero or more steps: formally, the set of strings *w* such that for some *s* in *S*, *s R w*, where *R* is the [transitive closure](wikipedia://en/292239) of $\to_{G}$.

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

The prefix grammar

- Σ = {0, 1}
- *S* = {01, 10}
- *P* = {0 → 010, 10 → 100}

describes the language defined by the [regular expression](wikipedia://en/25717)

$$01(01)^* \cup 100^*$$

:::
