# Polygon triangulation

Triangulation (geometry)

*Image: Триангуляция.svg.* Polygon triangulation

::: {#o1 .subject cue=lead name="Polygon triangulation"}

In [computational geometry](wikipedia://en/176927), **polygon triangulation** is the [partition](wikipedia://en/48191322) of a [polygonal area](https://en.wikipedia.org/wiki/Polygonal_area) ([simple polygon](wikipedia://en/1059530)) $P$ into a set of [triangles](https://en.wikipedia.org/wiki/Triangles),[^o2] i.e., finding a set of triangles with pairwise non-intersecting interiors whose [union](wikipedia://en/47949) is $P$.

:::

Triangulations may be viewed as special cases of [planar straight-line graphs](wikipedia://en/12015517). When there are no holes or added points, triangulations form [maximal outerplanar graphs](wikipedia://en/352343).

## Polygon triangulation without extra vertices {#Polygon_triangulation_without_extra_vertices}

Over time, a number of algorithms have been proposed to triangulate a polygon.

### Convex polygon triangulation {#Convex_polygon_triangulation}

*Image: Polygon Triangulations (heptagon).svg.* The 42 possible triangulations for a [convex](https://en.wikipedia.org/wiki/Convex_region) [heptagon](wikipedia://en/365349) (7-sided convex polygon). This number is given by the 5th [Catalan number](wikipedia://en/216488).

It is trivial to triangulate any [convex polygon](wikipedia://en/660019) in [linear time](https://en.wikipedia.org/wiki/Linear_time) into a [fan triangulation](https://en.wikipedia.org/wiki/Fan_triangulation), by adding diagonals from one vertex to all other non-nearest neighbor vertices.

The total number of ways to triangulate a convex [*n*-gon](wikipedia://en/23621) by non-intersecting diagonals is the (*n*−2)nd [Catalan number](wikipedia://en/216488), which equals

$$\frac{n(n+1)...(2n-4)}{(n-2)!},$$

a formula found by [Leonhard Euler](wikipedia://en/17902).[^o5]

### Ear clipping method {#Ear_clipping_method}

*Image: Polygon-ear.png.* A triangulated polygon, with one ear shaded

One way to triangulate a [simple polygon](wikipedia://en/1059530) is based on the [two ears theorem](wikipedia://en/48898634), as the fact that any simple polygon with at least 4 vertices without holes has at least two "[ears](https://en.wikipedia.org/wiki/Ear_%28mathematics%29)", which are triangles with two sides being the edges of the polygon and the third one completely inside it.[^o7] The algorithm then consists of finding such an ear, removing it from the polygon (which results in a new polygon that still meets the conditions) and repeating until there is only one triangle left.

This algorithm is easy to implement, but slower than some other algorithms, and it only works on polygons without holes. An implementation that keeps separate lists of convex and concave vertices will run in $O(n^{2})$ time. This method is known as *ear clipping* and sometimes *ear trimming*. An efficient algorithm for cutting off ears was discovered by Hossam ElGindy, Hazel Everett, and [Godfried Toussaint](https://en.wikipedia.org/wiki/Godfried_Toussaint).[^o8]

### Monotone polygon triangulation {#Monotone_polygon_triangulation}

A simple polygon is monotone with respect to a line $L$, if any line orthogonal to $L$ intersects the polygon at most twice. A [monotone polygon](wikipedia://en/12003237) can be split into two monotone *chains*. A polygon that is monotone with respect to the y-axis is called *y-monotone*. A monotone polygon with $n$ vertices can be triangulated in $O(n)$ time. Assuming a given polygon is y-monotone, the [greedy algorithm](wikipedia://en/89247) begins by walking on one chain of the polygon from top to bottom while adding diagonals whenever it is possible.[^o2] It is easy to see that the algorithm can be applied to any monotone polygon.

A monotone polygon can be triangulated in linear time with either the algorithm of [A. Fournier](https://en.wikipedia.org/wiki/Alain_Fournier_%28academic%29) and D.Y. Montuno,[^o10] or the algorithm of [Godfried Toussaint](https://en.wikipedia.org/wiki/Godfried_Toussaint).[^o11]

### Triangulating a non-monotone polygon {#Triangulating_a_non-monotone_polygon}

*Image: Polygon-to-monotone.png.* Breaking a polygon into monotone polygons

If a polygon is not monotone, it can be partitioned into monotone subpolygons in $O(n \log n)$ time using a [sweep-line approach](wikipedia://en/8700856). The algorithm does not require the polygon to be simple, thus it can be applied to [polygons with holes](wikipedia://en/67194923). Generally, this algorithm can triangulate a planar subdivision with $n$ vertices in $O(n \log n)$ time using $O(n)$ space.[^o2]

### Dual graph of a triangulation {#Dual_graph_of_a_triangulation}

A useful graph that is often associated with a triangulation of a polygon $P$ is the [dual graph](wikipedia://en/2536864). Given a triangulation $T_{P}$ of $P$, one defines the graph $G(T_{P})$ as the graph whose vertex set are the triangles of $T_{P}$, two vertices (triangles) being adjacent if and only if they share a diagonal. It is easy to observe that $G(T_{P})$ is a [tree](wikipedia://en/48560) with maximum degree 3.

### Computational complexity {#Computational_complexity}

Until 1988, whether a [simple polygon](wikipedia://en/1059530) can be triangulated faster than $O(n \log n)$ time was an open problem in computational geometry.[^o2] Then, (Tarjan Van Wyk 1988) discovered an $O(n \log \log n)$-time algorithm for triangulation,[^o17] later simplified by (Kirkpatrick Klawe Tarjan 1992).[^o19] Several improved methods with complexity $O(n \log^{*} n)$ (in practice, indistinguishable from [linear time](https://en.wikipedia.org/wiki/Linear_time)) followed.[^o20][^o21][^o22]

[Bernard Chazelle](https://en.wikipedia.org/wiki/Bernard_Chazelle) showed in 1991 that any simple polygon can be triangulated in linear time, though the proposed algorithm is very complex.[^o23] A simpler randomized algorithm with linear expected time is also known.[^o24]

The [time complexity](wikipedia://en/405944) of triangulation of an $n$-vertex polygon *with* holes has an $\Omega(n \log n)$ [lower bound](https://en.wikipedia.org/wiki/Lower_bound), in algebraic [computation tree](https://en.wikipedia.org/wiki/Computation_tree) models of computation.[^o2] It is possible to compute the number of distinct triangulations of a simple polygon in polynomial time using [dynamic programming](wikipedia://en/125297), and (based on this counting algorithm) to generate [uniformly random](wikipedia://en/1699214) triangulations in polynomial time.[^o25] However, counting the triangulations of a polygon with holes is [\#P-complete](wikipedia://en/27925), making it unlikely that it can be done in polynomial time.[^o26]

:::

## Related objects and problems {#Related_objects_and_problems}

- Both triangulation problems are a special case of [triangulation (geometry)](wikipedia://en/1440970) and a special case of [polygon partition](wikipedia://en/48191322).
- [Minimum-weight triangulation](wikipedia://en/22231180) is a triangulation in which the goal is to minimize the total edge length.
- A [point-set triangulation](wikipedia://en/1081285) is a polygon triangulation of the convex hull of a set of points. A [Delaunay triangulation](wikipedia://en/8864) is another way to create a triangulation based on a set of points.
- The [associahedron](wikipedia://en/19698446) is a polytope whose vertices correspond to the triangulations of a convex polygon.
- [Polygon triangle covering](wikipedia://en/43043289#Covering_a_polygon_with_triangles), in which the triangles may overlap.
- [Tiling by polygons](wikipedia://en/1548669), where the goal is to cover the entire plane with polygons of pre-specified shapes.
