# QMA

::: {#o1 .subject cue=lead name="QMA"}

**QMA**, as an abbreviation for **Quantum Merlin Arthur,** refers to a [complexity class](wikipedia://en/502426) in [computational complexity theory](wikipedia://en/7543). It is the set of all [formal languages](wikipedia://en/10939) that satisfy the following properties:

:::

1. If a [string](wikipedia://en/27701) is in the language, then there is a polynomial-size quantum proof (representable as a [quantum state](wikipedia://en/30876419)) that convinces a [polynomial-time](https://en.wikipedia.org/wiki/Polynomial-time) quantum verifier (running on a [quantum computer](https://en.wikipedia.org/wiki/Quantum_computer)) of this fact with high probability.
1. If a string is *not* in the language, every polynomial-size quantum state is rejected by the verifier with high probability.

The relationship between QMA and [BQP](wikipedia://en/4080) is analogous to the relationship between the complexity classes [NP](wikipedia://en/21562) and [P](wikipedia://en/658550). It is also analogous to the relationship between the probabilistic complexity classes [MA](wikipedia://en/663203) and [BPP](wikipedia://en/4079).

**QAM** is a related complexity class, in which fictional agents Arthur and Merlin carry out the sequence: Arthur generates a random string, Merlin answers with a quantum [certificate](wikipedia://en/14933760) and Arthur verifies it as a BQP machine.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A language *L* is in $\mathsf{QMA}(c,s)$ if there exists a polynomial time quantum verifier *V* and a polynomial $p(x)$ such that:[^o4][^o5][^o6]

- $\forall x \in L$, there exists a quantum state $|\psi\rangle$ such that the probability that *V* accepts the input $(|x\rangle, |\psi\rangle)$ is greater than $c$.
- $\forall x \notin L$, and for all quantum states $|\psi\rangle$ with at most $p(|x|)$ [qubits](wikipedia://en/25284), the probability that *V* accepts the input $(|x\rangle, |\psi\rangle)$ is less than $s$.

The complexity class $\mathsf{QMA}$ is defined to be equal to $\mathsf{QMA}({2}/{3},1/3)$. However, the constants are not too important since the class remains unchanged if $c$ and $s$ are set to any constants such that $c$ is greater than $s$. Moreover, for any polynomials $q(n)$ and $r(n)$, we have

$$\mathsf{QMA}\left(\frac{2}{3},\frac{1}{3}\right) =\mathsf{QMA}\left(\frac{1}{2}+\frac{1}{q(n)},\frac{1}{2}-\frac{1}{q(n)}\right)=\mathsf{QMA}(1-2^{-r(n)},2^{-r(n)}).$$

:::

## Problems in QMA {#Problems_in_QMA}

Since many interesting classes are contained in QMA, such as P, BQP and NP, all problems in those classes are also in QMA. However, there are problems that are in QMA but not known to be in NP or BQP. Some such well known problems are discussed below.

A problem is said to be QMA-hard, analogous to [NP-hard](https://en.wikipedia.org/wiki/NP-hard), if every problem in QMA can be [reduced](wikipedia://en/848067) to it. A problem is said to be QMA-[complete](wikipedia://en/1176530) if it is QMA-hard and in QMA.

### The local Hamiltonian problem {#The_local_Hamiltonian_problem}

A *k*-local [Hamiltonian (quantum mechanics)](wikipedia://en/14381) $H$ is a [Hermitian matrix](wikipedia://en/189682) acting on n qubits which can be represented as the sum of $m$ Hamiltonian Terms acting upon at most $k$ qubits each.

$$H = \sum_{i=1}^m H_i$$

The general *k*-local Hamiltonian problem is, given a *k*-local Hamiltonian $H$, to find the smallest eigenvalue $\lambda$ of $H$.[^o9] $\lambda$ is also called the ground state energy of the Hamiltonian.

The decision version of the *k*-local Hamiltonian problem is a type of [promise problem](wikipedia://en/1471429) and is defined as, given a *k*-local Hamiltonian and $\alpha, \beta$ where $\alpha > \beta$, to decide if there exists a quantum eigenstate $|\psi\rangle$ of $H$ with associated eigenvalue $\lambda$, such that $\lambda \leq \beta$ or if $\lambda \geq \alpha$.

The local Hamiltonian problem is the quantum analogue of [MAX-SAT](https://en.wikipedia.org/wiki/Maximum_satisfiability_problem). The *k*-local Hamiltonian problem is QMA-complete for k ≥ 2.[^o10]

The 2-local Hamiltonian problem restricted to act on a two dimensional grid of [qubits](https://en.wikipedia.org/wiki/Qubits), is also QMA-complete.[^o11] It has been shown that the *k*-local Hamiltonian problem is still QMA-hard even for Hamiltonians representing a 1-dimensional line of particles with nearest-neighbor interactions with 12 states per particle.[^o12] If the system is translationally-invariant, its local Hamiltonian problem becomes QMA<sub>EXP</sub>-complete (as the problem input is encoded in the system size, the verifier now has exponential runtime while maintaining the same promise gap).[^o13][^o14]

QMA-hardness results are known for simple [lattice models](https://en.wikipedia.org/wiki/Lattice_models) of [qubits](https://en.wikipedia.org/wiki/Qubits) such as the ZX Hamiltonian [^o15] $H_{ZX} = \sum_{i}h_i Z_i + \sum_{i} \Delta_i X_i + \sum_{i<j}J^{ij}Z_iZ_j + \sum_{i<j}K^{ij}X_iX_j$ where $Z, X$ represent the [Pauli matrices](wikipedia://en/24868) $\sigma_z, \sigma_x$. Such models are applicable to universal [adiabatic quantum computation](wikipedia://en/14436313).

*k*-local Hamiltonians problems are analogous to classical [Constraint Satisfaction Problems](https://en.wikipedia.org/wiki/Constraint_Satisfaction_Problems).[^o16] The following table illustrates the analogous gadgets between classical CSPs and Hamiltonians.

::: {#o17 .table cue=table}

| Classical | Quantum | Notes |
|---|---|---|
| Constraint Satisfaction Problem | Hamiltonian |  |
| Variable | Qubit |  |
| Constraint | Hamiltonian Term |  |
| Variable Assignment | Quantum state |  |
| Number of constraints satisfied | Hamiltonian's energy term |  |
| Optimal Solution | Hamiltonian's ground state | The most possible constraints satisfied |

:::

## Related classes {#Related_classes}

**QCMA** (or **MQA**[^o5]), which stands for Quantum Classical Merlin Arthur (or Merlin Quantum Arthur), is similar to QMA, but the proof has to be a classical string. It is not known whether QMA equals QCMA, although QCMA is clearly contained in QMA.

**QIP(k)**, which stands for [Quantum Interactive Polynomial time](https://en.wikipedia.org/wiki/Quantum_Interactive_Polynomial_time) (k messages), is a generalization of QMA where Merlin and Arthur can interact for k rounds. QMA is QIP(1). QIP(2) is known to be in PSPACE.[^o21]

**[QIP](wikipedia://en/25608560)** is QIP(k) where k is allowed to be polynomial in the number of qubits. It is known that QIP(3) = QIP.[^o22] It is also known that QIP = [IP](wikipedia://en/2197070) = [PSPACE](wikipedia://en/39351).[^o23]

:::

## Relationship to other classes {#Relationship_to_other_classes}

QMA is related to other known [complexity classes](https://en.wikipedia.org/wiki/Complexity_classes) by the following relations:

$$\mathsf{P} \subseteq \mathsf{NP} \subseteq \mathsf{MA} \subseteq \mathsf{QCMA} \subseteq \mathsf{QMA}\subseteq \mathsf{PP} \subseteq \mathsf{PSPACE}$$

The first inclusion follows from the definition of [NP](wikipedia://en/21562). The next two inclusions follow from the fact that the verifier is being made more powerful in each case. QCMA is contained in QMA since the verifier can force the prover to send a classical proof by measuring proofs as soon as they are received. The fact that QMA is contained in [PP](wikipedia://en/659322) was shown by [Alexei Kitaev](https://en.wikipedia.org/wiki/Alexei_Kitaev) and [John Watrous](wikipedia://en/25613997). PP is also easily shown to be in [PSPACE](wikipedia://en/39351).

It is unknown if any of these inclusions is unconditionally strict, as it is not even known whether P is strictly contained in PSPACE or P = PSPACE. However, the currently best known upper bounds on QMA are[^o25][^o26]

$\mathsf{QMA}\subseteq\mathsf{A_0PP}$ and $\mathsf{QMA}\subseteq\mathsf{P^{QMA[log]}}$,

where both $\mathsf{A_0PP}$ and $\mathsf{P^{QMA[log]}}$ are contained in $\mathsf{PP}$. It is unlikely that $\mathsf{QMA}$ equals $\mathsf{P^{QMA[log]}}$, as this would imply $\mathsf{QMA}=\mathsf{co}$-$\mathsf{QMA}$. It is unknown whether $\mathsf{P^{QMA[log]}}\subseteq\mathsf{A_0PP}$ or vice versa.
