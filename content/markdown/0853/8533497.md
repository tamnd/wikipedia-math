# Composite field (mathematics)

::: {#o1 .subject cue=lead name="Composite field"}

A **composite field** or **compositum of fields** is an object of study in [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29). Let *K* be a [field](wikipedia://en/10603), and let $E_1$, $E_2$ be [subfields](https://en.wikipedia.org/wiki/Subfield_%28mathematics%29) of *K*. Then the (internal) composite[^o2] of $E_1$ and $E_2$ is the field defined as the intersection of all subfields of *K* containing both $E_1$ and $E_2$. The composite is commonly denoted $E_1E_2$.

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Equivalently to intersections we can define the composite $E_1E_2$ to be *[the smallest](wikipedia://en/303398#Greatest_and_smallest_elements)* subfield[^o5] of *K* that contains both $E_1$ and $E_2$. While for the definition via intersection, well-definedness hinges only on the property that intersections of fields are themselves fields, here two auxiliary assertions are included. Firstly, that there exist *[minimal](wikipedia://en/303398)* subfields of *K* that include $E_1$ and $E_2$ and secondly, that such *a minimal* subfield is unique and therefore justly called *the smallest*.

It also can be defined using [field of fractions](wikipedia://en/25271)

$$E_1E_2=E_1(E_2)=E_2(E_1),$$

where $F(S)$ is the set of all $F$-rational expressions in finitely many elements of $S$.[^o6]

Let $L\subseteq E_1\cap E_2$ be a common subfield and $E_1/L$ a [Galois extension](wikipedia://en/457064) then $E_1E_2/E_2$ and $E_1/(E_1\cap E_2)$ are both also Galois and there is an isomorphism given by restriction

$$\text{Gal}(E_1E_2/E_2)\rightarrow\text{Gal}(E_1/(E_1\cap E_2)), \sigma\mapsto\sigma|_{E_1}.$$

For finite [field extension](wikipedia://en/11634) this can be explicitly found in Milne[^o7] and for infinite extensions this follows since infinite Galois extensions are precisely those extensions that are unions of an (infinite) set of finite Galois extensions.[^o8]

If additionally $E_2/L$ is a Galois extension then $E_1E_2/L$ and $(E_1\cap E_2)/L$ are both also Galois and the map

$$\psi:\text{Gal}(E_1E_2/L)\rightarrow\text{Gal}(E_1/L)\times\text{Gal}(E_2/L), \sigma\mapsto(\sigma|_{E_1},\sigma|_{E_2})$$

is a group homomorphism which is an isomorphism onto the subgroup

$$H=\{(\sigma_1,\sigma_2):\sigma_1|_{E_1\cap E_2}=\sigma_2|_{E_1\cap E_2}\}=\text{Gal}(E_1/L)\times_{\text{Gal}((E_1\cap E_2)/L)}\text{Gal}(E_2/L)\subseteq\text{Gal}(E_1/L)\times\text{Gal}(E_2/L).$$

See Milne.[^o9]

Both properties are particularly useful for $L=E_1\cap E_2$ and their statements simplify accordingly in this special case. In particular $\psi$ is always an isomorphism in this case.

:::

## External composite {#External_composite}

When $E_1$ and $E_2$ are not regarded as subfields of a common field then the (external) composite is defined using the [tensor product of fields](wikipedia://en/372240). Note that some care has to be taken for the choice of the common subfield over which this tensor product is performed, otherwise the tensor product might come out to be only an algebra which is not a field.

::: {#o13 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

If $\mathcal{E}=\left\{E_i:i\in I\right\}$ is a set of subfields of a fixed field *K* indexed by the set *I*, the generalized composite field[^o14] can be defined via the intersection

$$\bigvee_{i\in I}E_i = \bigcap_{F\subseteq K\text{ s.t. }\forall i \in I: E_i\subseteq F}F.$$

:::
