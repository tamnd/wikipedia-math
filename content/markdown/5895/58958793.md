# Beraha constants

::: {#o1 .subject cue=lead name="Beraha constants"}

The **Beraha constants** are a series of [mathematical constants](wikipedia://en/48779551) by which the $n\text{th}$ Beraha constant is given by

:::

$$B (n) = 2 + 2 \cos \left ( \frac{2\pi}{n} \right ).$$

Notable examples of Beraha constants include $B (5)$ is $\varphi + 1$, where $\varphi$ is the [golden ratio](wikipedia://en/12386), $B (7)$ is the **silver constant**[^o2] (also known as the **silver root**),[^o3] and $B (10) = \varphi + 2$.

The following table summarizes the first ten Beraha constants.

::: {#o4 .table cue=table}

| $n$ | $B(n)$ | **Approximately** |
|---|---|---|
| 1 | 4 |  |
| 2 | 0 |  |
| 3 | 1 |  |
| 4 | 2 |  |
| 5 | $\frac{1}{2}(3+\sqrt{5})$ | \2.618 |
| 6 | 3 |  |
| 7 | $2 + 2 \cos (\tfrac{2}{7}\pi)$ | \3.247 |
| 8 | $2 + \sqrt{2}$ | \3.414 |
| 9 | $2 + 2 \cos (\tfrac{2}{9}\pi)$ | \3.532 |
| 10 | $\frac{1}{2}(5+\sqrt{5})$ | \3.618 |

:::
