# Acid Cryptofiler

::: {#o2 .subject cue=lead name="Acid Cryptofiler"}

**Acid Cryptofiler** is a cryptographic software program designed by the department for "control of information" (Centre d'Electronique de l'Armement) of the French General Directorate of Armament ([Direction générale de l'armement](https://en.wikipedia.org/wiki/Direction_générale_de_l'armement)).[^o3][^o4][^o5] It is an online storage service.[^o6] The software is now manufactured by ACID Technologies (France).[^o4]

:::

## History {#History}

Acid Cryptofiler is on a list of cryptographic software approved for usage by the [European Union](https://en.wikipedia.org/wiki/European_Union) and by the [North Atlantic Treaty Organization](https://en.wikipedia.org/wiki/North_Atlantic_Treaty_Organization),[^o4][^o8] and is known to have been used by those organizations as well as by the [European Parliament](https://en.wikipedia.org/wiki/European_Parliament) and [European Commission](https://en.wikipedia.org/wiki/European_Commission) since the summer of 2011.[^o9] It was approved for usage in the EU, in version V7, on 29 September 2011.[^o4]

In January 2013, as the [Red October](https://en.wikipedia.org/wiki/Red_October_%28malware%29) campaign was being discovered, researchers noted that the malware particularly targeted documents with *.acid* extensions, referring to documents processed by Acid Cryptofiler,[^o4][^o9][^o6] including the file extensions *acidcsa, acidsca, aciddsk, acidpvr, acidppr,* and *acidssa*.[^o10]

## Overview {#Overview}

Acid Cryptofiler is based on the integration of government cryptographic libraries, including a CCSD [API](https://en.wikipedia.org/wiki/Application_programming_interface) (CCSD means "Defense Security Cryptographic Layers"). It offers the following functions:

- Asymmetric encryption (cf. [public-key cryptography](wikipedia://en/24222)) in archive format (multi-file, multi-recipient) called Acid Archives.
- Volume encryption (containers) in symmetric mode and asymmetric mode.

Acid Cryptofiler is delivered with a directory function to file public keys, that is compliant with [LDAP](https://en.wikipedia.org/wiki/LDAP) and [Active Directory](wikipedia://en/2807).

A bunch file contains all public keys held by a user. A user can belong to different cryptographic domains (a domain is a CCSD library and a set of cryptographic parameters). Private keys are also stored in a bunch file.

The keys are generated by a centralized office under the responsibility of the [chief information security officer](https://en.wikipedia.org/wiki/Chief_information_security_officer). Before a user is given a key (or a pair of keys), he/she must be trusted by the centralized office. In France, Acid Cryptofiler does not fit for defense classified information.[^o5]

Acid Cryptofiler was designed and developed by the [Direction générale de l'armement](https://en.wikipedia.org/wiki/Direction_générale_de_l'armement).[^o5] . It runs on [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows).[^o5] The software is classified.[^o12]

According to a book by [Gérald Bronner](https://en.wikipedia.org/wiki/Gérald_Bronner), Acid Cryptofiler was so slow that sending an email took 10 minutes.[^o13]
