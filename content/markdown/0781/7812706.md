# Paradoxical set

::: {#o1 .subject cue=lead name="Paradoxical set"}

*Image: Banach-Tarski Paradox.svg.* The [Banach–Tarski paradox](wikipedia://en/19759220) is that a ball can be decomposed into a finite number of point sets and reassembled into two balls identical to the original.

In [set theory](wikipedia://en/27553), a **paradoxical set** is a set that has a **paradoxical decomposition**. A paradoxical decomposition of a set is two families of disjoint subsets, along with appropriate [group actions](https://en.wikipedia.org/wiki/Group_actions) that act on some [universe](wikipedia://en/296838) (of which the set in question is a subset), such that each partition can be mapped back onto the entire set using only finitely many distinct functions (or compositions thereof) to accomplish the mapping. A set that admits such a paradoxical decomposition where the actions belong to a group $G$ is called $G$-paradoxical or paradoxical with respect to $G$.

:::

Paradoxical sets exist as a consequence of the [Axiom of Infinity](https://en.wikipedia.org/wiki/Axiom_of_Infinity). Admitting infinite classes as sets is sufficient to allow paradoxical sets.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Suppose a group $G$ acts on a set $A$. Then $A$ is $G$-paradoxical if there exist some disjoint subsets $A_1,...,A_n,B_1,...,B_m \subseteq A$ and some group elements $g_1,...,g_n,h_1,...,h_m \in G$ such that:[^o4]

$A = \bigcup_{i=1}^n g_i(A_i)$ and $A = \bigcup_{i=1}^m h_i(B_i)$

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

### Free group {#Free_group}

The [Free group](wikipedia://en/59735) *F* on two generators *a,b* has the decomposition $F = \{e\} \cup X(a) \cup X(a^{-1}) \cup X(b) \cup X(b^{-1})$ where *e* is the identity word and $X(i)$ is the collection of all (reduced) words that start with the letter *i*. This is a paradoxical decomposition because $X(a) \cup aX(a^{-1}) = F = X(b) \cup bX(b^{-1}).$

::: {#o9 .statement cue=named-heading name="Banach–Tarski paradox"}

### Banach–Tarski paradox {#Banach–Tarski_paradox}

The most famous example of paradoxical sets is the [Banach–Tarski paradox](wikipedia://en/19759220), which divides the sphere into paradoxical sets for the [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group). This result depends on the [axiom of choice](wikipedia://en/840).
