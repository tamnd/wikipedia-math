# Quasi-unmixed ring

::: {#o1 .subject cue=lead name="Quasi-unmixed ring"}

In algebra, specifically in the theory of [commutative rings](wikipedia://en/61346), a **quasi-unmixed ring** (also called a **formally equidimensional ring** in EGA[^o2]) is a [Noetherian ring](wikipedia://en/56129) $A$ such that for each [prime ideal](wikipedia://en/24928) *p*, the [completion](wikipedia://en/9477975) of the [localization](https://en.wikipedia.org/wiki/Localization_of_a_ring_and_a_module) *A<sub>p</sub>* is [equidimensional](https://en.wikipedia.org/wiki/Equidimensional_ring), i.e. for each [minimal prime ideal](wikipedia://en/16143832) *q* in the completion $\widehat{A_p}$, $\dim \widehat{A_p}/q = \dim A_p$ = the [Krull dimension](wikipedia://en/56079) of *A<sub>p</sub>*.[^o3]

:::

## Equivalent conditions {#Equivalent_conditions}

A Noetherian [integral domain](wikipedia://en/15462) is quasi-unmixed if and only if it satisfies [Nagata's altitude formula](https://en.wikipedia.org/wiki/Nagata's_altitude_formula).[^o5] (See also: #formally catenary ring below.)

Precisely, a quasi-unmixed ring is a ring in which the [unmixed theorem](https://en.wikipedia.org/wiki/Unmixed_theorem), which characterizes a [Cohen–Macaulay ring](wikipedia://en/497407), holds for integral closure of an ideal; specifically, for a Noetherian ring $A$, the following are equivalent:[^o6][^o7]

- $A$ is quasi-unmixed.
- For each ideal *I* generated by a number of elements equal to its height, the integral closure $\overline{I}$ is [unmixed](https://en.wikipedia.org/wiki/Unmixed_ideal) in height (each prime divisor has the same height as the others).
- For each ideal *I* generated by a number of elements equal to its height and for each integer *n* > 0, $\overline{I^n}$ is unmixed.

::: {#o9 .pointer-item cue=pointer name="Formally catenary ring"}

## Formally catenary ring {#Formally_catenary_ring}

A Noetherian local ring $A$ is said to be **formally catenary** if for every prime ideal $\mathfrak{p}$, $A/\mathfrak{p}$ is quasi-unmixed.[^o10] As it turns out, this notion is redundant: Ratliff has shown that a Noetherian local ring is formally catenary if and only if it is [universally catenary](https://en.wikipedia.org/wiki/Universally_catenary).[^o11]

:::
