# Euler function

*Image: Euler function.png.* [Domain coloring](wikipedia://en/5280990) plot of ϕ on the [complex plane](wikipedia://en/217628)

*Image: Euler function phi(x).svg.* Euler function $\phi(x)$.

::: {#o1 .subject cue=lead name="Euler function"}

In [mathematics](wikipedia://en/18831), the **Euler function** is given by

:::

$$\phi(q)=\prod_{k=1}^\infty (1-q^k),\quad |q|<1.$$

Named after [Leonhard Euler](wikipedia://en/17902), it is a model example of a [*q*-series](https://en.wikipedia.org/wiki/Q-series) and provides the prototypical example of a relation between [combinatorics](wikipedia://en/5170) and [complex analysis](wikipedia://en/5759).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The [coefficient](wikipedia://en/51203) $p(k)$ in the [formal power series](wikipedia://en/60012) expansion for $1/\phi(q)$ gives the number of [partitions](https://en.wikipedia.org/wiki/Partition_of_an_integer) of *k*. That is,

$$\frac{1}{\phi(q)}=\sum_{k=0}^\infty p(k) q^k$$

where $p$ is the [partition function](wikipedia://en/312250).

The **Euler identity**, also known as the [Pentagonal number theorem](wikipedia://en/340294), is

$$\phi(q)=\sum_{n=-\infty}^\infty (-1)^n q^{(3n^2-n)/2}.$$

$(3n^2-n)/2$ is a [pentagonal number](wikipedia://en/504786).

The Euler function is related to the [Dedekind eta function](wikipedia://en/447020) as

$$\phi (e^{2\pi i\tau})= e^{-\pi i\tau/12} \eta(\tau).$$

The Euler function may be expressed as a [*q*-Pochhammer symbol](wikipedia://en/11149717):

$$\phi(q) = (q;q)_{\infty}.$$

The [logarithm](wikipedia://en/17860) of the Euler function is the sum of the logarithms in the product expression, each of which may be expanded about *q* = 0, yielding

$$\ln(\phi(q)) = -\sum_{n=1}^\infty\frac{1}{n}\,\frac{q^n}{1-q^n},$$

which is a [Lambert series](wikipedia://en/1367040) with coefficients -1/*n*. The logarithm of the Euler function may therefore be expressed as

$$\ln(\phi(q)) = \sum_{n=1}^\infty b_n q^n$$

where $b_n=-\sum_{d|n}\frac{1}{d}=$ -\[1/1, 3/2, 4/3, 7/4, 6/5, 12/6, 8/7, 15/8, 13/9, 18/10, ...\] (see [OEIS](https://en.wikipedia.org/wiki/OEIS) [A000203](http://oeis.org/A000203/table))

On account of the identity $\sigma(n) = \sum_{d|n} d = \sum_{d|n} \frac{n}{d}$ , where $\sigma(n)$ is the [sum-of-divisors function](wikipedia://en/407249), this may also be written as

$$\ln(\phi(q)) = -\sum_{n=1}^\infty \frac{\sigma(n)}{n}\ q^n.$$

Also if $a,b\in\mathbb{R}^+$ and $ab=\pi ^2$, then[^o4]

$$a^{1/4}e^{-a/12}\phi (e^{-2a})=b^{1/4}e^{-b/12}\phi (e^{-2b}).$$

:::

## Special values {#Special_values}

The next identities come from [Ramanujan](wikipedia://en/47717)'s Notebooks:[^o6]

$$\phi(e^{-\pi})=\frac{e^{\pi/24}\Gamma\left(\frac14\right)}{2^{7/8}\pi^{3/4}}$$

$$\phi(e^{-2\pi})=\frac{e^{\pi/12}\Gamma\left(\frac14\right)}{2\pi^{3/4}}$$

$$\phi(e^{-4\pi})=\frac{e^{\pi/6}\Gamma\left(\frac14\right)}{2^{{11}/8}\pi^{3/4}}$$

$$\phi(e^{-8\pi})=\frac{e^{\pi/3}\Gamma\left(\frac14\right)}{2^{29/16}\pi^{3/4}}(\sqrt{2}-1)^{1/4}$$

Using the [Pentagonal number theorem](wikipedia://en/340294), exchanging sum and [integral](wikipedia://en/15532), and then invoking complex-analytic methods, one derives

$$\int_0^1\phi(q)\,\mathrm{d}q = \frac{8 \sqrt{\frac{3}{23}} \pi \sinh \left(\frac{\sqrt{23} \pi }{6}\right)}{2 \cosh \left(\frac{\sqrt{23} \pi }{3}\right)-1}.$$
