# Perkel graph

::: {#o1 .subject cue=lead name="Perkel graph"}

In mathematics, the **Perkel graph**, named after Manley Perkel, is a 6-[regular graph](wikipedia://en/85821) with 57 vertices and 171 edges. It is the unique [distance-regular graph](wikipedia://en/7768943) with intersection array (6, 5, 2; 1, 1, 3).[^o3] The Perkel graph is also [distance-transitive](wikipedia://en/7768222).

:::

It is also the [skeleton](wikipedia://en/2977910) of an [abstract regular polytope](https://en.wikipedia.org/wiki/Abstract_regular_polytope), the [57-cell](wikipedia://en/948622).

The vertex set is $Z_{3} \times Z_{19}$ where $(i,j)$ is joined to $(i+1,k)$ when $(k-j)^{3}$ = $2^{6i}$.
