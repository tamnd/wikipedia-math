# Hua's identity

::: {#o1 .subject cue=lead name="Hua's identity"}

In algebra, **[Hua](wikipedia://en/2337582)'s identity**[^o2] named after [Hua Luogeng](wikipedia://en/2337582), states that for any elements *a*, *b* in a [division ring](wikipedia://en/9067),

$$a - \left(a^{-1} + \left(b^{-1} - a\right)^{-1}\right)^{-1} = aba$$

whenever $ab \ne 0, 1$. Replacing $b$ with $-b^{-1}$ gives another equivalent form of the identity:

$$\left(a + ab^{-1}a\right)^{-1} + (a + b)^{-1} = a^{-1}.$$

:::

::: {#o4 .statement kind=statement/theorem cue=named-heading name="Hua's theorem"}

## Hua's theorem {#Hua's_theorem}

The identity is used in a proof of **Hua's theorem**,[^o5] which states that if $\sigma$ is a [function](wikipedia://en/185427) between division rings satisfying

$$\sigma(a + b) = \sigma(a) + \sigma(b), \quad \sigma(1) = 1, \quad \sigma(a^{-1}) = \sigma(a)^{-1},$$

then $\sigma$ is a [homomorphism](wikipedia://en/26411) or an [antihomomorphism](wikipedia://en/706374). This theorem is connected to the [fundamental theorem of projective geometry](https://en.wikipedia.org/wiki/Fundamental_theorem_of_projective_geometry).

:::

::: {#o7 .proof cue=heading name="Proof of the identity"}

## Proof of the identity {#Proof_of_the_identity}

One has

$$(a - aba)\left(a^{-1} + \left(b^{-1} - a\right)^{-1}\right) = 1 - ab + ab\left(b^{-1} - a\right)\left(b^{-1} - a\right)^{-1} = 1.$$

The proof is valid in any ring as long as $a, b, ab - 1$ are [units](wikipedia://en/289666).[^o8]

:::
