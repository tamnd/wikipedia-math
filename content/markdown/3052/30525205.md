# Constructible topology

::: {#o1 .subject cue=lead name="Constructible topology"}

In [commutative algebra](wikipedia://en/245990), the **constructible topology** on the [spectrum](wikipedia://en/37291) $\operatorname{Spec}(A)$ of a [commutative ring](wikipedia://en/61346) $A$ is a [topology](wikipedia://en/29954) where each [closed set](wikipedia://en/47279) is the [image](wikipedia://en/579311) of $\operatorname{Spec} (B)$ in $\operatorname{Spec}(A)$ for some [algebra](https://en.wikipedia.org/wiki/Algebra_%28ring_theory%29) *B* over *A*. An important feature of this construction is that the map $\operatorname{Spec}(B) \to \operatorname{Spec}(A)$ is a [closed map](https://en.wikipedia.org/wiki/Closed_map) with respect to the constructible topology.

:::

With respect to this topology, $\operatorname{Spec}(A)$ is a [compact](https://en.wikipedia.org/wiki/Compact_set#Definition),[^o2] [Hausdorff](wikipedia://en/13637), and [totally disconnected](wikipedia://en/303356) [topological space](wikipedia://en/30450) (i.e., a [Stone space](wikipedia://en/380219)). In general, the constructible topology is a [finer topology](https://en.wikipedia.org/wiki/Finer_topology) than the [Zariski topology](wikipedia://en/241744), and the two topologies coincide if and only if $A / \operatorname{nil}(A)$ is a [von Neumann regular ring](wikipedia://en/907524), where $\operatorname{nil}(A)$ is the [nilradical](wikipedia://en/289636) of *A*.[^o3]

Despite the terminology being similar, the constructible topology is not the same as the set of all [constructible sets](wikipedia://en/23234121).[^o4]
