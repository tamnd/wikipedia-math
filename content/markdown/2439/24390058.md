# Adaptive estimator

::: {#o1 .subject cue=lead name="Adaptive estimator"}

In [statistics](wikipedia://en/26685), an **adaptive estimator** is an [estimator](wikipedia://en/10043) in a [parametric](wikipedia://en/2883137) or [semiparametric](wikipedia://en/4415208) model with [nuisance parameters](wikipedia://en/979528) such that the presence of these nuisance parameters does not affect [efficiency of estimation](wikipedia://en/27250866).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, let parameter *θ* in a parametric model consists of two parts: the parameter of interest *ν* ∈ *N* ⊆ **R**<sup>*k*</sup>, and the nuisance parameter *η* ∈ *H* ⊆ **R**<sup>*m*</sup>. Thus *θ* = (*ν,η*) ∈ *N×H* ⊆ **R**<sup>*k+m*</sup>. Then we will say that $\scriptstyle\hat\nu_n$ is an **adaptive estimator** of *ν* in the presence of *η* if this estimator is [regular](https://en.wikipedia.org/wiki/Regular_estimator), and efficient for each of the submodels[^o4]

$$\mathcal{P}_\nu(\eta_0) = \big\{ P_\theta: \nu\in N,\, \eta=\eta_0\big\}.$$

Adaptive estimator estimates the parameter of interest equally well regardless whether the value of the nuisance parameter is known or not.

The necessary condition for a [regular parametric model](https://en.wikipedia.org/wiki/Regular_parametric_model) to have an adaptive estimator is that

$$I_{\nu\eta}(\theta) = \operatorname{E}[\, z_\nu z_\eta' \,] = 0 \quad \text{for all }\theta,$$

where *z*<sub>*ν*</sub> and *z*<sub>*η*</sub> are components of the [score function](https://en.wikipedia.org/wiki/Score_%28statistics%29) corresponding to parameters *ν* and *η* respectively, and thus *I*<sub>*νη*</sub> is the top-right *k×m* block of the [Fisher information matrix](https://en.wikipedia.org/wiki/Fisher_information_matrix) *I*(*θ*).

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

Suppose $\scriptstyle\mathcal{P}$ is the [normal](wikipedia://en/21462) [location-scale family](https://en.wikipedia.org/wiki/Location-scale_family):

$$\mathcal{P} = \Big\{\ f_\theta(x) = \tfrac{1}{\sqrt{2\pi}\sigma} e^{ -\frac{1}{2\sigma^2}(x-\mu)^2 }\ \Big|\ \mu\in\mathbb{R}, \sigma>0 \ \Big\}.$$

Then the usual estimator $\hat\mu\,=\,\bar{x}$ is adaptive: we can estimate the mean equally well whether we know the variance or not.

:::
