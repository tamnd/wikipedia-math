# Bhargava factorial

::: {#o1 .subject cue=lead name="Bhargava factorial"}

In [mathematics](wikipedia://en/18831), **Bhargava's factorial function**, or simply the **Bhargava factorial**, is a generalization of the [factorial](wikipedia://en/10606) function developed by [Manjul Bhargava](wikipedia://en/5102088) as part of his bachelor's thesis at [Harvard University](https://en.wikipedia.org/wiki/Harvard_University) in 1996. Bhargava subsequently published a revised version in *[The American Mathematical Monthly](wikipedia://en/1179483)* in 2000. The Bhargava factorial has the property that many [number-theoretic](wikipedia://en/21527) results involving the ordinary factorials remain true even when the factorials are replaced by the Bhargava factorials. Using an arbitrary [infinite subset](wikipedia://en/142679) *S* of the set $\mathbb{Z}$ of integers, Bhargava associated a positive integer with every positive integer *k*, which he denoted by *k* !<sub>*S*</sub>, with the property that if one takes *S* = $\mathbb{Z}$ itself, then the integer associated with *k*, that is *k* !<sub>$\mathbb{Z}$</sub>, would turn out to be the ordinary factorial of *k*.[^o2]

:::

## Motivation for the generalization {#Motivation_for_the_generalization}

The [factorial](wikipedia://en/10606) of a [non-negative integer](https://en.wikipedia.org/wiki/Non-negative_integer) *n*, denoted by *n*!, is the product of all positive integers less than or equal to *n*. For example, 5! = 5×4×3×2×1 = 120. By convention, the value of 0! is defined as 1. This classical factorial function appears prominently in many theorems in [number theory](wikipedia://en/21527). The following are a few of these theorems.[^o2]

1. For any positive integers *m* and *n*, (*m* + *n*)! is a multiple of *m*! *n*!.
1. Let *f*(*x*) be a primitive [integer polynomial](https://en.wikipedia.org/wiki/Integer_polynomial), that is, a polynomial in which the coefficients are integers and are [relatively prime](https://en.wikipedia.org/wiki/Relatively_prime) to each other. If the degree of *f*(*x*) is *k* then the [greatest common divisor](wikipedia://en/12354) of the set of values of *f*(*x*) for integer values of *x* is a [divisor](wikipedia://en/49492) of *k*!.
1. Let *a*<sub>0</sub>, *a*<sub>1</sub>, *a*<sub>2</sub>, ... , *a*<sub>*n*</sub> be any *n* + 1 integers. Then the product of their pairwise differences is a multiple of 0! 1! ... *n*!.
1. Let $\mathbb{Z}$ be the set of integers and *n* any integer. Then the number of [polynomial functions](https://en.wikipedia.org/wiki/Polynomial_function) from the [ring of integers](wikipedia://en/460613) $\mathbb{Z}$ to the [quotient ring](wikipedia://en/184635) $\mathbb{Z}/n\mathbb{Z}$ is given by $\prod_{k=0}^{n-1} \frac{n}{\gcd(n,k!)}$.

Bhargava posed to himself the following problem and obtained an affirmative answer: In the above theorems, can one replace the set of integers by some other set *S* (a subset of $\mathbb{Z}$, or a subset of some [ring](wikipedia://en/48404)) and define a function depending on *S* which assigns a value to each non-negative integer *k*, denoted by *k*!<sub>*S*</sub>, such that the statements obtained from the theorems given earlier by replacing *k*! by *k*!<sub>*S*</sub> remain true?

## The generalisation {#The_generalisation}

- Let *S* be an arbitrary infinite subset of the set *Z* of integers.
- Choose a prime number *p*.
- Construct an ordered sequence {*a*<sub>0</sub>, *a*<sub>1</sub>, *a*<sub>2</sub>, ... } of numbers chosen from *S* as follows (such a sequence is called a *p*-ordering of *S*):
  1. *a*<sub>0</sub> is any arbitrary element of *S*.
  1. *a*<sub>1</sub> is any arbitrary element of *S* such that the highest power of *p* that divides *a*<sub>1</sub> − *a*<sub>0</sub> is minimum.
  1. *a*<sub>2</sub> is any arbitrary element of *S* such that the highest power of *p* that divides (*a*<sub>2</sub> − *a*<sub>0</sub>)(*a*<sub>2</sub> − *a*<sub>1</sub>) is minimum.
  1. *a*<sub>3</sub> is any arbitrary element of *S* such that the highest power of *p* that divides (*a*<sub>3</sub> − *a*<sub>0</sub>)(*a*<sub>3</sub> − *a*<sub>1</sub>)(*a*<sub>3</sub> − *a*<sub>2</sub>) is minimum.
  1. ... and so on.
- Construct a *p*-ordering of *S* for each prime number *p*. (For a given prime number *p*, the *p*-ordering of *S* is not unique.)
- For each non-negative integer *k*, let *v*<sub>*k*</sub>(*S*, *p*) be the highest power of *p* that divides (*a*<sub>*k*</sub> − *a*<sub>0</sub>)(*a*<sub>*k*</sub> − *a*<sub>1</sub>)(*a*<sub>*k*</sub> − *a*<sub>2</sub>) ... (*a*<sub>*k*</sub> − *a*<sub>*k* − 1</sub>). The sequence {*v*<sub>0</sub>(*S*, *p*), *v*<sub>1</sub>(*S*, *p*), *v*<sub>2</sub>(*S*, *p*), *v*<sub>3</sub>(*S*, *p*), ... } is called the associated *p*-sequence of *S*. This is independent of any particular choice of *p*-ordering of *S*. (We assume that *v*<sub>0</sub>(*S*, *p*) = 1 always.)
- The factorial of the integer *k*, associated with the infinite set *S*, is defined as $k!_{S}=\prod_p v_k(S,p)$, where the product is taken over all prime numbers *p*.

## Example: Factorials using set of prime numbers {#Example:_Factorials_using_set_of_prime_numbers}

Let *S* be the set of all prime numbers *P* = {2, 3, 5, 7, 11, ... }.

- Choose *p* = 2 and form a *p*-ordering of *P*.
  - Choose *a*<sub>0</sub> = 19 arbitrarily from *P*.
  - To choose *a*<sub>1</sub>:
    - The highest power of *p* that divides 2 − *a*<sub>0</sub> = −17 is 2<sup>0</sup> = 1. Also, for any *a* ≠ 2 in P, *a* − *a*<sub>0</sub> is divisible by 2. Hence, the highest power of *p* that divides (*a*<sub>1</sub> − *a*<sub>0</sub>) is minimum when *a*<sub>1</sub> = 2 and the minimum power is 1. Thus *a*<sub>1</sub> is chosen as 2 and *v*<sub>1</sub>(*P*, 2) = 1.
  - To choose *a*<sub>2</sub>:
    - It can be seen that for each element *a* in *P*, the product *x* = (*a* − *a*<sub>0</sub>)(*a* − *a*<sub>1</sub>) = (*a* − 19)(*a* − 2) is divisible by 2. Also, when *a* = 5, *x* is divisible 2 and it is not divisible by any higher power of 2. So, *a*<sub>2</sub> may be chosen as 5. We have *v*<sub>2</sub>(*P*, 2) = 2.
  - To choose *a*<sub>3</sub>:
    - It can be seen that for each element *a* in *P*, the product *x* = (*a* − *a*<sub>0</sub>)(*a* − *a*<sub>1</sub>)(*a* − *a*<sub>2</sub>) = (*a* − 19)(*a* − 2)(*a* − 5) is divisible by 2<sup>3</sup> = 8. Also, when *a* = 17, *x* is divisible by 8 and it is not divisible by any higher power of 2. Choose *a*<sub>3</sub> = 17. Also we have *v*<sub>3</sub>(*P*,2) = 8.
  - To choose *a*<sub>4</sub>:
    - It can be seen that for each element *a* in *P*, the product *x* = (*a* − *a*<sub>0</sub>)(*a* − *a*<sub>1</sub>)(*a* − *a*<sub>2</sub>)(*a* − *a*<sub>3</sub>) = (*a* − 19)(*a* − 2)(*a* − 5)(*a* − 17) is divisible by 2<sup>4</sup> = 16. Also, when *a* = 23, *x* is divisible 16 and it is not divisible by any higher power of 2. Choose *a*<sub>4</sub> = 23. Also we have *v*<sub>4</sub>(*P*,2) = 16.
  - To choose *a*<sub>5</sub>:
    - It can be seen that for each element *a* in *P*, the product *x* = (*a* − *a*<sub>0</sub>)(*a* − *a*<sub>1</sub>)(*a* − *a*<sub>2</sub>)(*a* − *a*<sub>3</sub>)(*a* − *a*<sub>4</sub>) = (*a* − 19)(*a* − 2)(*a* − 5)(*a* − 17)(*a* − 23) is divisible by 2<sup>7</sup> = 128. Also, when *a* = 31, *x* is divisible 128 and it is not divisible by any higher power of 2. Choose *a*<sub>5</sub> = 31. Also we have *v*<sub>5</sub>(*P*,2) = 128.
  - The process is continued. Thus a 2-ordering of P is {19, 2, 5, 17, 23, 31, ... } and the associated 2-sequence is {1, 1, 2, 8, 16, 128, ... }, assuming that *v*<sub>0</sub>(*P*, 2) = 1.
- For *p* = 3, one possible *p*-ordering of *P* is the sequence {2, 3, 7, 5, 13, 17, 19, ... } and the associated *p*-sequence of *P* is {1, 1, 1, 3, 3, 9, ... }.
- For *p* = 5, one possible *p*-ordering of *P* is the sequence {2, 3, 5, 19, 11, 7, 13, ... } and the associated *p*-sequence is {1, 1, 1, 1, 1, 5, ...}.
- It can be shown that for *p* ≥ 7, the first few elements of the associated *p*-sequences are {1, 1, 1, 1, 1, 1, ... }.

## Example: Factorials using the set of natural numbers {#Example:_Factorials_using_the_set_of_natural_numbers}

Let *S* be the set of integers $\mathbb{Z}$.

- For *p* = 2, the associated *p*-sequence is {1, 1, 2, 2, 8, 8, 16, 16, 128, 128, 256, 256, ... }.
- For *p* = 3, the associated *p*-sequence is {1, 1, 1, 3, 3, 3, 9, 9, 9, 27, 27, 27, 81, 81, 81, ... }.
- For *p* = 5, the associated *p*-sequence is {1, 1, 1, 1, 1, 5, 5, 5, 5, 5, 25, 25, 25, 25, 25, ... }.
- For *p* = 7, the associated *p*-sequence is {1, 1, 1, 1, 1, 1, 1, 7, 7, 7, 7, 7, 7, 7, ... }.
- ... and so on.

Thus the first few factorials using the integers are

- 0!<sub>$\mathbb{Z}$</sub> = 1×1×1×1×1×... = 1.
- 1!<sub>$\mathbb{Z}$</sub> = 1×1×1×1×1×... = 1.
- 2!<sub>$\mathbb{Z}$</sub> = 2×1×1×1×1×... = 2.
- 3!<sub>$\mathbb{Z}$</sub> = 2×3×1×1×1×... = 6.
- 4!<sub>$\mathbb{Z}$</sub> = 8×3×1×1×1×... = 24.
- 5!<sub>$\mathbb{Z}$</sub> = 8×3×5×1×1×... = 120.
- 6!<sub>$\mathbb{Z}$</sub> = 16×9×5×1×1×... = 720.

## Examples: Some general expressions {#Examples:_Some_general_expressions}

The following table contains the general expressions for *k*!<sub>*S*</sub> for some special cases of *S*.[^o2]

::: {#o8 .table cue=table}

| Sl. No. | Set *S* | *k*!<sub>*S*</sub> |
|---|---|---|
| 1 | Set of integers | *k*! |
| 2 | Set of even integers | 2<sup>*k*</sup>×*k*! |
| 3 | Set of integers of the form *an* + *b* | *a*<sup>*k*</sup>×*k*! |
| 4 | Set of integers of the form 2<sup>*n*</sup> | (2<sup>*k*</sup> − 1)(2<sup>*k*</sup> − 2) ... (2<sup>*k*</sup> − 2<sup>*k* − 1</sup>) |
| 5 | Set of integers of the form *q*<sup>*n*</sup> for some prime *q* | (*q*<sup>*k*</sup> − 1)(*q*<sup>*k*</sup> − *q*) ... (*q*<sup>*k*</sup> − *q*<sup>*k* − 1</sup>) |
| 6 | Set of squares of integers | (2*k*)!/2 |

:::
