# Perfect ring

::: {#o1 .subject cue=lead name="Perfect ring"}

In the area of [abstract algebra](wikipedia://en/19616384) known as [ring theory](wikipedia://en/250424), a **left perfect ring** is a type of [ring](wikipedia://en/48404) over which all left [modules](wikipedia://en/276410) have [projective covers](wikipedia://en/10273917). The right case is defined by analogy, and the condition is not left-right symmetric; that is, there exist rings which are perfect on one side but not the other. Perfect rings were introduced in [Bass](wikipedia://en/7085910)'s book.[^n1]

:::

A **semiperfect ring** is a ring over which every [finitely generated](wikipedia://en/326430) left module has a projective cover. This property is left-right symmetric.

## Perfect ring {#Perfect_ring}

::: {#o5 .definition cue=heading name="Definitions"}

### Definitions {#Definitions}

The following equivalent definitions of a left perfect ring *R* are found in Anderson and Fuller:[^n2]

- Every left *R*-module has a projective cover.
- *R*/J(*R*) is [semisimple](wikipedia://en/1001361) and J(*R*) is **left T-nilpotent** (that is, for every infinite sequence of elements of J(*R*) there is an *n* such that the product of first *n* terms are zero), where J(*R*) is the [Jacobson radical](wikipedia://en/57656) of *R*.
- (**Bass' Theorem P**) *R* satisfies the [descending chain condition](https://en.wikipedia.org/wiki/Descending_chain_condition) on [principal right ideals](wikipedia://en/145126). (There is no mistake; this condition on *right* principal ideals is equivalent to the ring being *left* perfect.)
- Every [flat](wikipedia://en/492616) left *R*-module is [projective](wikipedia://en/364488).
- *R*/J(*R*) is semisimple and every [non-zero](https://en.wikipedia.org/wiki/Zero_module) left *R*-module contains a [maximal submodule](https://en.wikipedia.org/wiki/Maximal_submodule).
- *R* contains no infinite [orthogonal](wikipedia://en/361940#Types_of_ring_idempotents) set of [idempotents](wikipedia://en/361940), and every non-zero right *R*-module contains a [minimal submodule](https://en.wikipedia.org/wiki/Minimal_submodule).

:::

::: {#o8 .example cue=heading name="Examples"}

### Examples {#Examples}

- Right or left [Artinian rings](wikipedia://en/489273), and [semiprimary rings](wikipedia://en/29435296) are known to be right-and-left perfect.
- The following is an example (due to Bass) of a [local ring](wikipedia://en/153391) which is right but not left perfect. Let *F* be a [field](wikipedia://en/10603), and consider a certain ring of [infinite matrices](wikipedia://en/20556859#Infinite_matrices) over *F*.

Take the set of infinite matrices with entries indexed by $\mathbb{N} \times \mathbb{N}$, and which have only finitely many nonzero entries, all of them above the diagonal, and denote this set by $J$. Also take the matrix $I\,$ with all 1's on the diagonal, and form the set

$$R = \{f\cdot I+j\mid f\in F, j\in J \}\,$$

It can be shown that *R* is a ring with identity, whose Jacobson radical is *J*. Furthermore *R*/*J* is a field, so that *R* is local, and *R* is right but not left perfect.[^n3]

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

For a left perfect ring *R*:

- From the equivalences above, every left *R*-module has a maximal submodule and a projective cover, and the flat left *R*-modules coincide with the projective left modules.
- An analogue of the [Baer's criterion](wikipedia://en/473775#Baer's_criterion) holds for projective modules.

:::

## Semiperfect ring {#Semiperfect_ring}

::: {#o14 .definition cue=heading name="Definition"}

### Definition {#Definition}

Let *R* be a ring. Then *R* is semiperfect if any of the following equivalent conditions hold:

- *R*/J(*R*) is [semisimple](wikipedia://en/1001361) and [idempotents](wikipedia://en/361940) [lift](wikipedia://en/361940#Types_of_ring_idempotents) modulo J(*R*), where J(*R*) is the [Jacobson radical](wikipedia://en/57656) of *R*.
- *R* has a complete orthogonal set *e*<sub>1</sub>, ..., *e*<sub>*n*</sub> of idempotents with each *e<sub>i</sub>Re<sub>i</sub>* a [local ring](wikipedia://en/153391).
- Every [simple](wikipedia://en/29430) left (right) *R*-module has a [projective cover](wikipedia://en/10273917).
- Every [finitely generated](wikipedia://en/326430) left (right) *R*-module has a projective cover.
- The [category](wikipedia://en/53759) of finitely generated [projective](wikipedia://en/364488) $R$-modules is [Krull-Schmidt](https://en.wikipedia.org/wiki/Krull-Schmidt_category).

:::

::: {#o16 .example cue=heading name="Examples"}

### Examples {#Examples}

Examples of semiperfect rings include:

- Left (right) perfect rings.
- Local rings.
- Left (right) [Artinian rings](wikipedia://en/489273).
- [Finite dimensional](wikipedia://en/38267) *k*-[algebras](wikipedia://en/191788).

:::

::: {#o18 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

Since a ring *R* is semiperfect iff every simple left *R*-module has a projective cover, every ring [Morita equivalent](wikipedia://en/3296134) to a semiperfect ring is also semiperfect.

:::

### Basic ring {#Basic_ring}

For a fixed semiperfect ring *R*, there is (up to a ring isomorphism) a canonical representative of the class of rings Morita equivalent to *R* called a **basic ring for *R*.** A semiperfect ring is basic if and only if *R*/J(*R*) is a direct product of division rings.

Given a complete orthogonal set *e*<sub>1</sub>, ..., *e*<sub>*n*</sub> of local idempotents, we can assume ordering of this set in such a way that the for some *i≤n* the right modules *e*<sub>1</sub>R, ..., *e*<sub>*i*</sub>R form a complete set of finitely generated projective right modules. The idempotent *e*=*e*<sub>1</sub>+ ... + *e*<sub>*i*</sub> is then called a basic idempotent and the corner ring *B:=eRe* isomorphic to *End*<sub>R</sub>(*e*<sub>1</sub>R + ...+ *e*<sub>*i*</sub> *R*) is the basic ring for *R*.

The map *I*→*IR* defines embedding of the lattice of right ideals of *B* into that of *R*. The map *I*→*RIR* defines an isomorphism of the lattice of ideals of *B* and the lattice of ideals of *R*. This isomorphism respects multiplication of ideals. [^n4]
