# Nonnegative matrix

::: {#o1 .subject cue=lead name="Nonnegative matrix"}

In [mathematics](wikipedia://en/18831), a **nonnegative matrix**, written

:::

$$\mathbf{X} \geq 0,$$

is a [matrix](wikipedia://en/20556859) in which all the elements are equal to or greater than zero, that is,

$$x_{ij} \geq 0\qquad \forall {i,j}.$$

A **positive matrix** is a matrix in which all the elements are strictly greater than zero. The set of positive matrices is the interior of the set of all non-negative matrices. While such matrices are commonly found, the term "positive matrix" is only occasionally used due to the possible confusion with [positive-definite matrices](https://en.wikipedia.org/wiki/Positive-definite_matrix), which are different. A matrix which is both non-negative and is positive semidefinite is called a **doubly non-negative matrix**.

A rectangular non-negative matrix can be approximated by a decomposition with two other non-negative matrices via [non-negative matrix factorization](wikipedia://en/3681279).

Eigenvalues and eigenvectors of square positive matrices are described by the [Perron–Frobenius theorem](wikipedia://en/1540333).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The [trace](wikipedia://en/43270) and every row and column sum/product of a nonnegative matrix is nonnegative.

:::

## Inversion {#Inversion}

The inverse of any [non-singular](wikipedia://en/217122) [M-matrix](wikipedia://en/7939066) is a non-negative matrix. If the non-singular M-matrix is also symmetric then it is called a [Stieltjes matrix](wikipedia://en/8098498).

The inverse of a non-negative matrix is usually not non-negative. The exception is the non-negative [monomial matrices](https://en.wikipedia.org/wiki/Monomial_matrices): a non-negative matrix has non-negative inverse if and only if it is a (non-negative) monomial matrix. Note that thus the inverse of a positive matrix is not positive or even non-negative, as positive matrices are not monomial, for dimension $n > 1$.

## Specializations {#Specializations}

There are a number of groups of matrices that form specializations of non-negative matrices, e.g. [stochastic matrix](wikipedia://en/217313); [doubly stochastic matrix](wikipedia://en/2906180); [symmetric](wikipedia://en/126474) non-negative matrix.
