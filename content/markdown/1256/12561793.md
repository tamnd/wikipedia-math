# CAPICOM

::: {#o1 .subject cue=lead name="CAPICOM"}

**CAPICOM** is a discontinued [ActiveX](https://en.wikipedia.org/wiki/ActiveX) control created by [Microsoft](https://en.wikipedia.org/wiki/Microsoft) to help expose a select set of Microsoft [Cryptographic Application Programming Interface](https://en.wikipedia.org/wiki/Cryptographic_Application_Programming_Interface) (CryptoAPI) functions through Microsoft [Component Object Model](https://en.wikipedia.org/wiki/Component_Object_Model) (COM). It was intended to enable every environment that supports ActiveX to use Microsoft Cryptographic technologies, including web pages that are opened with Microsoft [Internet Explorer](https://en.wikipedia.org/wiki/Internet_Explorer) or any other web browser that supports ActiveX.[^o2]

:::

CAPICOM can be used to digitally sign data, display and inspect their [digital certificate](https://en.wikipedia.org/wiki/Digital_certificate), verify the validity of their [digital signature](wikipedia://en/59644), add or remove certificates to or from the certificate stores, and encrypt or decrypt data.[^o2]

CAPICOM Version 2.1.0.3, the latest and last version of CAPICOM, is officially supported on Windows Vista.[^o3][^o4][^o5] However, Microsoft has announced that CAPICOM is discontinued and is no longer being developed. Microsoft suggests replacing CAPICOM with [.NET Framework](https://en.wikipedia.org/wiki/.NET_Framework)'s X509 Cryptographic Classes and, in a handful of cases, with [Windows API](https://en.wikipedia.org/wiki/Windows_API) functions.[^o6]

CAPICOM was not included in [Windows SDK](https://en.wikipedia.org/wiki/Windows_SDK) for [Windows 7](https://en.wikipedia.org/wiki/Windows_7).[^o7]
