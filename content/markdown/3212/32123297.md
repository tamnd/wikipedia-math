# Ordinal logic

::: {#o1 .subject cue=lead name="Ordinal logic"}

In [mathematics](wikipedia://en/18831), **ordinal logic** is a logic associated with an [ordinal number](wikipedia://en/26547932) by recursively adding elements to a sequence of previous logics.[^o2][^o3] The concept was introduced in 1938 by [Alan Turing](wikipedia://en/1208) in [his PhD dissertation](wikipedia://en/32122937) at [Princeton](https://en.wikipedia.org/wiki/Princeton) in view of [Gödel's incompleteness theorems](wikipedia://en/58863).[^o4][^o2]

:::

While [Gödel](https://en.wikipedia.org/wiki/Gödel) showed that every [recursively enumerable](wikipedia://en/332090) [axiomatic system](wikipedia://en/188401) that can interpret basic arithmetic suffers from some form of incompleteness, Turing focused on a method so that a complete system of logic may be constructed from a given system of logic. By repeating the process, a sequence L1, L2, … of logic is obtained, each more complete than the previous one. A logic L can then be constructed in which the provable theorems are the totality of theorems provable with the help of the L1, L2, … etc. Thus Turing showed how one can associate logic with any [constructive ordinal](https://en.wikipedia.org/wiki/Constructive_ordinal).[^o4]
