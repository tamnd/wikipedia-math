# Systems of Logic Based on Ordinals

::: {#o1 .subject cue=lead name="Systems of Logic Based on Ordinals"}

***Systems of Logic Based on Ordinals*** was the PhD dissertation of the [mathematician](wikipedia://en/18902) [Alan Turing](wikipedia://en/1208).[^o2]

:::

The thesis was completed at [Princeton](https://en.wikipedia.org/wiki/Princeton) under [Alonzo Church](wikipedia://en/49731) and was a classic work in mathematics that introduced the concept of [ordinal logic](wikipedia://en/32123297).[^o3]

The thesis is an exploration of formal mathematical systems after [Gödel's theorem](wikipedia://en/58863). Gödel showed that for any formal system *S* powerful enough to represent arithmetic, there is a theorem *G* that is true but the system is unable to prove. *G* could be added as an additional axiom to the system in place of a proof. However this would create a new system *S'* with its own unprovable true theorem *G**, and so on. Turing's thesis looks at what happens if you simply iterate this process repeatedly, generating an infinite set of new axioms to add to the original theory, and even goes one step further in using [transfinite recursion](wikipedia://en/30461#Transfinite_recursion) to go "past infinity", yielding a set of new theories*****G<sub>α</sub>*, one for each [ordinal number](wikipedia://en/26547932)*α*.***

Turing's thesis is not about a new type of [formal logic](https://en.wikipedia.org/wiki/Formal_logic), nor was he interested in so-called "ranked logic" systems derived from ordinal or relative numbering, in which comparisons can be made between truth-states on the basis of relative veracity. Instead, Turing investigated the possibility of resolving the [Gödelian](wikipedia://en/16736) incompleteness condition using [Cantor](wikipedia://en/12216)'s method of infinites.

[Martin Davis](wikipedia://en/953041) states that although Turing's use of a [computing oracle](wikipedia://en/22431) is not a major focus of the dissertation, it has proven to be highly influential in [theoretical computer science](wikipedia://en/323392), e.g. in the [polynomial-time hierarchy](https://en.wikipedia.org/wiki/Polynomial-time_hierarchy).[^o4]
