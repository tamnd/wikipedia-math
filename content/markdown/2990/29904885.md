# Double origin topology

::: {#o1 .subject cue=lead name="Double origin topology"}

In mathematics, more specifically [general topology](wikipedia://en/178649), the **double origin topology** is an example of a [topology](wikipedia://en/29954) given to the plane $\mathbf{R}^{2}$ with an extra point, say $0*$, added. In this case, the double origin topology gives a topology on the set $X = \mathbf{R}^{2} \sqcup \{0*\}$, where $\sqcup$ denotes the [disjoint union](wikipedia://en/188946).

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

Given a point $x$ belonging to $X$, such that $x \ne 0$ and $x \ne 0*$, the [neighbourhoods](wikipedia://en/1529485) of $x$ are those given by the standard [metric topology](https://en.wikipedia.org/wiki/Metric_topology) on $\mathbf{R}^{2}-\{0\}.$[^o4] We define a [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) [basis](wikipedia://en/59220) of neighbourhoods about the point 0 and about the additional point $0*$. For the point $0$, the basis, [indexed](wikipedia://en/23624339) by $n$, is defined to be:[^o4]

$$\ N(0,n) = \{ (x,y) \in {\mathbf R}^2 : x^2 + y^2 < 1/n^2, \ y > 0\} \cup \{0\} .$$

In a similar way, the basis of neighbourhoods of $0*$ is defined to be:[^o4]

$$N(0^*,n) = \{ (x,y) \in {\mathbf R}^2 : x^2 + y^2 < 1/n^2, \ y < 0\} \cup \{0^*\} .$$

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The space $\mathbf{R}^{2} \sqcup \{0*\}$, along with the double origin topology is an example of a [Hausdorff space](wikipedia://en/13637), although it is not [completely Hausdorff](https://en.wikipedia.org/wiki/Completely_Hausdorff). Since it has a base of [regular open sets](wikipedia://en/47306), it is an example of a [semiregular space](wikipedia://en/1885104) that is not [regular](wikipedia://en/53058). In terms of compactness, the space $\mathbf{R}^{2} \sqcup \{0*\}$, along with the double origin topology fails to be either [compact](https://en.wikipedia.org/wiki/Compact_%28topology%29), [paracompact](https://en.wikipedia.org/wiki/Paracompact) or [locally compact](https://en.wikipedia.org/wiki/Locally_compact), however, $X$ is [second countable](https://en.wikipedia.org/wiki/Second_countable). Finally, it is an example of an [arc connected](wikipedia://en/6233#Arc_connectedness) space.[^o7]

:::
