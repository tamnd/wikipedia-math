# Mironenko reflecting function

::: {#o1 .subject cue=lead name="Mironenko reflecting function"}

In applied mathematics, the **reflecting function** $\,F(t,x)$ of a [differential system](https://en.wikipedia.org/wiki/Differential_system) $\dot x=X(t,x)$ connects the past state $\,x(-t)$ of the system with the future state $\,x(t)$ of the system by the formula $\,x(-t)=F(t,x(t)).$ The concept of the reflecting function was introduced by [Uladzimir Ivanavich Mironenka](https://en.wikipedia.org/wiki/Vladimir_Mironenko).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

For the [differential system](https://en.wikipedia.org/wiki/Differential_system) $\dot x=X(t,x)$ with the [general solution](https://en.wikipedia.org/wiki/General_solution) $\varphi(t;t_0,x)$ in [Cauchy](https://en.wikipedia.org/wiki/Cauchy) form, the Reflecting Function of the system is defined by the formula $F(t,x)=\varphi(-t;t,x).$

:::

::: {#o5 .application cue=heading name="Application"}

## Application {#Application}

If a vector-function $X(t,x)$ is $\,2\omega$-periodic with respect to $\,t$, then $\,F(-\omega,x)$ is the in-period $\,[-\omega;\omega]$ transformation ([Poincaré map](wikipedia://en/876732)) of the differential system $\dot x=X(t,x).$ Therefore the knowledge of the Reflecting Function give us the opportunity to find out the initial dates $\,(\omega,x_0)$ of [periodic solutions](https://en.wikipedia.org/wiki/Periodic_solution) of the differential system $\dot x=X(t,x)$ and investigate the [stability](wikipedia://en/363360) of those solutions.

For the Reflecting Function $\,F(t,x)$ of the system $\dot x=X(t,x)$ the basic relation

$$\,F_t+F_x X+X(-t,F)=0,\qquad F(0,x)=x.$$

is holding.

Therefore we have an opportunity sometimes to find Poincaré map of the non-integrable in [quadrature](wikipedia://en/170089) systems even in [elementary functions](https://en.wikipedia.org/wiki/Elementary_functions).

:::
