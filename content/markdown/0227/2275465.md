# CS-Cipher

::: {#o2 .subject cue=lead name="CS-Cipher"}

In [cryptography](wikipedia://en/18934432), **CS-Cipher** (for *Chiffrement Symétrique*) is a [block cipher](wikipedia://en/4594) invented by [Jacques Stern](https://en.wikipedia.org/wiki/Jacques_Stern_%28cryptographer%29) and [Serge Vaudenay](https://en.wikipedia.org/wiki/Serge_Vaudenay) in 1998. It was submitted to the [NESSIE](wikipedia://en/497430) project, but was not selected.

:::

The algorithm uses a key length between 0 and 128 bits (length must be a multiple of 8 bits). By default, the cipher uses 128 bits. It operates on blocks of 64 bits using an 8-round [Feistel network](https://en.wikipedia.org/wiki/Feistel_network) and is optimized for 8-bit [processors](https://en.wikipedia.org/wiki/Central_processing_unit). The round function is based on the [fast Fourier transform](wikipedia://en/11512) and uses the binary expansion of [e](wikipedia://en/9633) as a source of "[nothing up my sleeve numbers](https://en.wikipedia.org/wiki/Nothing_up_my_sleeve_number)".
