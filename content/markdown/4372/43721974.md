# E-dense semigroup

::: {#o1 .subject cue=lead name="E-dense semigroup"}

In [abstract algebra](wikipedia://en/19616384), an ***E*-dense semigroup** (also called an ***E*-inversive semigroup**) is a [semigroup](wikipedia://en/27799) in which every element *a* has at least one **[weak inverse](wikipedia://en/22797782)** *x*, meaning that *xax* = *x*.[^o2] The notion of weak inverse is (as the name suggests) weaker than the notion of inverse used in a [regular semigroup](wikipedia://en/6797677) (which requires that *axa*=*a*).

:::

The above definition of an *E*-inversive semigroup *S* is equivalent with any of the following:[^o2]

- for every element *a* ∈ *S* there exists another element *b* ∈ *S* such that *ab* is an [idempotent](https://en.wikipedia.org/wiki/Idempotent).
- for every element *a* ∈ *S* there exists another element *c* ∈ *S* such that *ca* is an idempotent.

This explains the name of the notion as the set of idempotents of a semigroup *S* is typically denoted by *E*(*S*).[^o2]

The concept of *E*-inversive semigroup was introduced by [Gabriel Thierrin](https://en.wikipedia.org/wiki/Gabriel_Thierrin) in 1955.[^o3][^o4][^o5] Some authors use *E*-dense to refer only to *E*-inversive semigroups in which the idempotents commute.[^o6]

More generally, a [subsemigroup](https://en.wikipedia.org/wiki/Subsemigroup) *T* of *S* is said **dense** in *S* if, for all *x* ∈ *S*, there exists *y* ∈ *S* such that both *xy* ∈ *T* and *yx* ∈ *T*.

A [semigroup with zero](https://en.wikipedia.org/wiki/Semigroup_with_zero) is said to be an ***E*\*-dense semigroup** if every element other than the zero has at least one non-zero weak inverse. Semigroups in this class have also been called **0-inversive semigroups.**[^o7]

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any [regular semigroup](wikipedia://en/6797677) is *E*-dense (but not vice versa).[^o2]
- Any [eventually regular semigroup](https://en.wikipedia.org/wiki/Eventually_regular_semigroup) is *E*-dense.[^o2]
- Any [periodic semigroup](https://en.wikipedia.org/wiki/Periodic_semigroup) (and in particular, any [finite semigroup](https://en.wikipedia.org/wiki/Finite_semigroup)) is *E*-dense.[^o2]
