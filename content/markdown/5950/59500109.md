# Correlation function

::: {#o1 .subject cue=lead name="Correlation function"}

*Image: Comparison\_convolution\_correlation.svg.* Visual comparison of [convolution](wikipedia://en/7519), [cross-correlation](wikipedia://en/714163) and [autocorrelation](wikipedia://en/2724).

A **correlation function** is a [function](wikipedia://en/185427) that gives the statistical [correlation](wikipedia://en/157057) between [random variables](wikipedia://en/25685), contingent on the spatial or temporal distance between those variables.[^o2] If one considers the correlation function between random variables representing the same quantity measured at two different points, then this is often referred to as an [autocorrelation function](https://en.wikipedia.org/wiki/Autocorrelation_function), which is made up of [autocorrelations](wikipedia://en/2724). Correlation functions of different random variables are sometimes called **cross-correlation functions** to emphasize that different variables are being considered and because they are made up of [cross-correlations](wikipedia://en/714163).

:::

Correlation functions are a useful indicator of dependencies as a function of distance in time or space, and they can be used to assess the distance required between sample points for the values to be effectively uncorrelated. In addition, they can form the basis of rules for interpolating values at points for which there are no observations.

Correlation functions used in [astronomy](wikipedia://en/294866), [financial analysis](https://en.wikipedia.org/wiki/Financial_analysis), [econometrics](wikipedia://en/10390), and [statistical mechanics](wikipedia://en/28481) differ only in the particular stochastic processes they are applied to. In [quantum field theory](wikipedia://en/25267) there are [correlation functions over quantum distributions](https://en.wikipedia.org/wiki/Correlation_function_%28quantum_field_theory%29).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For possibly distinct random variables *X*(*s*) and *Y*(*t*) at different points *s* and *t* of some space, the correlation function is

$$C(s,t) = \operatorname{corr} ( X(s), Y(t) ) ,$$

where $\operatorname{corr}$ is described in the article on [correlation](wikipedia://en/157057). In this definition, it has been assumed that the stochastic variables are scalar-valued. If they are not, then more complicated correlation functions can be defined. For example, if *X*(*s*) is a [random vector](https://en.wikipedia.org/wiki/Random_vector) with *n* elements and *Y*(t) is a vector with *q* elements, then an *n*×*q* matrix of correlation functions is defined with $i,j$ element

$$C_{ij}(s,t) = \operatorname{corr}( X_i(s), Y_j(t) ).$$

When *n*=*q*, sometimes the [trace](https://en.wikipedia.org/wiki/Trace_%28matrix%29) of this matrix is focused on. If the [probability distributions](wikipedia://en/23543) have any target space symmetries, i.e. symmetries in the value space of the stochastic variable (also called **internal symmetries**), then the correlation matrix will have induced symmetries. Similarly, if there are symmetries of the space (or time) domain in which the random variables exist (also called **[spacetime symmetries](https://en.wikipedia.org/wiki/Spacetime_symmetries)**), then the correlation function will have corresponding space or time symmetries. Examples of important spacetime symmetries are —

- **translational symmetry** yields *C*(*s*,*s*') = *C*(*s* − *s*') where *s* and *s*' are to be interpreted as vectors giving coordinates of the points
- **rotational symmetry** in addition to the above gives *C*(*s*, *s*') = *C*(|*s* − *s*'|) where |*x*| denotes the norm of the vector *x* (for actual rotations this is the Euclidean or 2-norm).

Higher order correlation functions are often defined. A typical correlation function of order *n* is (the angle brackets represent the [expectation value](https://en.wikipedia.org/wiki/Expectation_value))

$$C_{i_1i_2\cdots i_n}(s_1,s_2,\cdots,s_n) = \langle X_{i_1}(s_1) X_{i_2}(s_2) \cdots X_{i_n}(s_n)\rangle.$$

If the random vector has only one component variable, then the indices $i,j$ are redundant. If there are symmetries, then the correlation function can be broken up into [irreducible representations](wikipedia://en/385982) of the symmetries — both internal and spacetime.

:::

## Properties of probability distributions {#Properties_of_probability_distributions}

With these definitions, the study of correlation functions is similar to the study of [probability distributions](https://en.wikipedia.org/wiki/Probability_distributions). Many stochastic processes can be completely characterized by their correlation functions; the most notable example is the class of [Gaussian processes](https://en.wikipedia.org/wiki/Gaussian_processes).

Probability distributions defined on a finite number of points can always be normalized, but when these are defined over continuous spaces, then extra care is called for. The study of such distributions started with the study of [random walks](wikipedia://en/235451) and led to the notion of the [Itō calculus](https://en.wikipedia.org/wiki/Itō_calculus).

The Feynman [path integral](https://en.wikipedia.org/wiki/Path_integral_formulation) in Euclidean space generalizes this to other problems of interest to [statistical mechanics](wikipedia://en/28481). Any probability distribution which obeys a condition on correlation functions called [reflection positivity](https://en.wikipedia.org/wiki/Reflection_positivity) leads to a local [quantum field theory](wikipedia://en/25267) after [Wick rotation](wikipedia://en/293629) to [Minkowski spacetime](wikipedia://en/230488) (see [Osterwalder-Schrader axioms](https://en.wikipedia.org/wiki/Osterwalder-Schrader_axioms)). The operation of [renormalization](wikipedia://en/291453) is a specified set of mappings from the space of probability distributions to itself. A [quantum field theory](wikipedia://en/25267) is called renormalizable if this mapping has a fixed point which gives a quantum field theory.
