# Yao's test

::: {#o1 .subject cue=lead name="Yao's test"}

In [cryptography](wikipedia://en/18934432) and the [theory of computation](wikipedia://en/30402), **Yao's test** is a test defined by [Andrew Chi-Chih Yao](https://en.wikipedia.org/wiki/Andrew_Chi-Chih_Yao) in 1982,[^o2] against pseudo-random sequences. A sequence of words passes Yao's test if an attacker with reasonable computational power cannot distinguish it from a sequence generated uniformly at random.

:::

::: {#o4 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

### Boolean circuits {#Boolean_circuits}

Let $P$ be a polynomial, and $S=\{S_k\}_k$ be a collection of sets $S_k$ of $P(k)$-bit long sequences, and for each $k$, let $\mu_k$ be a [probability distribution](wikipedia://en/23543) on $S_k$, and $P_C$ be a polynomial. A predicting collection $C=\{C_k\}$ is a collection of [boolean circuits](https://en.wikipedia.org/wiki/Boolean_circuits) of size less than $P_C(k)$. Let $p_{k,S}^C$ be the probability that on input $s$, a string randomly selected in $S_k$ with probability $\mu(s)$, $C_k(s)=1$, i.e.

$$p_{k,S}^C={\mathcal P}[C_k(s)=1 | s\in S_k\text{ with probability }\mu_k(s)]$$

Moreover, let $p_{k,U}^C$ be the probability that $C_k(s)=1$ on input $s$ a $P(k)$-bit long sequence selected [uniformly at random](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29) in $\{0,1\}^{P(k)}$. We say that $S$ passes Yao's test if for all predicting collection $C$, for all but finitely many $k$, for all polynomial $Q$ :

$$|p_{k,S}^C-p_{k,U}^C|<\frac{1}{Q(k)}$$

### Probabilistic formulation {#Probabilistic_formulation}

As in the case of the [next-bit test](wikipedia://en/1289913), the predicting collection used in the above definition can be replaced by a probabilistic Turing machine, working in polynomial time. This also yields a strictly stronger definition of Yao's test (see [Adleman's theorem](wikipedia://en/2052415#Adleman's_theorem)). Indeed, one could decide [undecidable](wikipedia://en/15631055) properties of the pseudo-random sequence with the non-uniform circuits described above, whereas [BPP](https://en.wikipedia.org/wiki/Bounded-error_probabilistic_polynomial) machines can always be simulated by exponential-time [deterministic Turing machines](https://en.wikipedia.org/wiki/Turing_machines).

:::
