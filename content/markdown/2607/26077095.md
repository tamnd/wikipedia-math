# Dyadic distribution

::: {#o1 .subject cue=lead name="Dyadic distribution"}

A **dyadic** (or **2-*adic***) **distribution** is a specific type of discrete [probability distribution](wikipedia://en/23543) that is of some theoretical importance in [data compression](wikipedia://en/8013).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A dyadic distribution is a [probability distribution](wikipedia://en/23543) whose [probability mass function](wikipedia://en/154725) is

$$f(i) = 2^{-x_i}$$

where $x_i$ is some whole number.

It is possible to find a binary code defined on this distribution, which has an average code length that is equal to the [entropy](wikipedia://en/9891).[^o4]

:::
