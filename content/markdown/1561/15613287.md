# Parker vector

::: {#o1 .subject cue=lead name="Parker vector"}

In [mathematics](wikipedia://en/18831), especially the field of [group theory](wikipedia://en/41890), the **Parker vector** is an [integer](wikipedia://en/14563) [vector](https://en.wikipedia.org/wiki/Column_vector) that describes a [permutation group](wikipedia://en/24634) in terms of the cycle structure of its elements, defined by [Richard A. Parker](wikipedia://en/4582441).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Parker vector *P* of a permutation group *G* acting on a set of size *n*, is the vector whose *k*th component for *k* = 1, ..., *n* is given by:

$P_k = \frac{k}{|G|} \sum_{g \in G} c_k(g)$ where *c*<sub>*k*</sub>(*g*) is the number of *k*-cycles in the cycle decomposition of *g*.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

For the group of even permutations on three elements, the Parker vector is (1,0,2). The group of all permutations on three elements has Parker vector (1,1,1). For any of the subgroups of the above with just two elements, the Parker vector is (2,1,0).The trivial subgroup has Parker vector (3,0,0).

:::
