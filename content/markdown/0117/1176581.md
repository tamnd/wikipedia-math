# RL (complexity)

::: {#o1 .subject cue=lead name="RL"}

**Randomized Logarithmic-space** (**RL**),[^o2] sometimes called **RLP** (Randomized Logarithmic-space Polynomial-time),[^o3] is the [complexity class](wikipedia://en/502426) of [computational complexity theory](wikipedia://en/7543) problems solvable in [logarithmic space](https://en.wikipedia.org/wiki/Logarithmic_space) and [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) with [probabilistic Turing machines](wikipedia://en/197812) with [one-sided error](https://en.wikipedia.org/wiki/One-sided_error). It is named in analogy with [RP](wikipedia://en/54771), which is similar but has no logarithmic space restriction.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

**RL** never accept incorrectly but are allowed to reject incorrectly less than 1/3 of the time; this is called *one-sided error*. The constant 1/3 is arbitrary; any *x* with 0 \< *x* \< 1 would suffice. This error can be made 2<sup>−*p*(*x*)</sup> times smaller for any polynomial *p*(*x*) without using more than polynomial time or logarithmic space by running the algorithm repeatedly.

:::

## Relation to other complexity classes {#Relation_to_other_complexity_classes}

Sometimes the name **RL** is reserved for the class of problems solvable by logarithmic-space probabilistic machines in *unbounded* time. However, this class can be shown to be equal to **[NL](wikipedia://en/1145955)** using a probabilistic counter, and so is usually referred to as **NL** instead; this also shows that **RL** is contained in **NL**. **RL** is contained in **[BPL](wikipedia://en/18449708)**, which is similar but allows two-sided error (incorrect accepts). **RL** contains **[L](wikipedia://en/1149999)**, the problems solvable by [deterministic Turing machines](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) in log space, since its definition is just more general.

[Noam Nisan](https://en.wikipedia.org/wiki/Noam_Nisan) showed in 1992 the weak [derandomization](https://en.wikipedia.org/wiki/Derandomization) result that **RL** is contained in **[SC](wikipedia://en/18449916)**,[^o7] the class of problems solvable in polynomial time and polylogarithmic space on a deterministic Turing machine; in other words, given *polylogarithmic* space, a deterministic machine can simulate *logarithmic* space probabilistic algorithms.

It is believed that **RL** is equal to **L**, that is, that polynomial-time logspace computation can be completely derandomized; major evidence for this was presented by Reingold et al. in 2005.[^o8] A proof of this is the holy grail of the efforts in the field of unconditional derandomization of complexity classes. A major step forward was Omer Reingold's proof that **[SL](wikipedia://en/1174919)** is equal to **L**.
