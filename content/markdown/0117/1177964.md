# Pentagonal orthobicupola

::: {#o2 .subject cue=lead name="Pentagonal orthobicupola"}

In [geometry](wikipedia://en/18973446), the **pentagonal orthobicupola** is one of the [Johnson solids](wikipedia://en/16034) ($J_{30}$). As the name suggests, it can be constructed by joining two [pentagonal cupolae](wikipedia://en/1131073) ($J_{5}$) along their [decagonal](wikipedia://en/327393) bases, matching like faces. A 36-degree rotation of one cupola before the joining yields a [pentagonal gyrobicupola](wikipedia://en/1177965) ($J_{31}$).

:::

The *pentagonal orthobicupola* is the third in an infinite set of [orthobicupolae](https://en.wikipedia.org/wiki/Bicupola_%28geometry%29).

## Formulae {#Formulae}

The following [formulae](wikipedia://en/164040) for [volume](wikipedia://en/32498) and [surface area](wikipedia://en/27725) can be used if all [faces](wikipedia://en/149926) are [regular](wikipedia://en/333306), with edge length *a*:[^o4]

$$V=\frac{1}{3}\left(5+4\sqrt{5}\right)a^3\approx4.64809...a^3$$

$$A=\left(10+\sqrt{\frac{5}{2}\left(10+\sqrt{5}+\sqrt{75+30\sqrt{5}}\right)}\right)a^2\approx17.7711...a^2$$
