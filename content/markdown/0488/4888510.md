# Critical point (set theory)

::: {#o1 .subject cue=lead name="Critical point"}

In [set theory](wikipedia://en/27553), the **critical point** of an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) of a [transitive class](https://en.wikipedia.org/wiki/Transitive_class) into another transitive class is the smallest [ordinal](wikipedia://en/26547932) which is not mapped to itself.[^o2]

:::

Suppose that *j*: *N* → *M* is an elementary embedding where *N* and *M* are transitive classes and *j* is definable in *N* by a formula of set theory with parameters from *N.* Then *j* must take ordinals to ordinals and *j* must be strictly increasing. Also *j*(ω) = ω. If *j*(*α*) = *α* for all *α* \< *κ* and *j*(*κ*) > *κ,* then *κ* is said to be the *critical point* of *j.*

If *N* is *[V](wikipedia://en/445980)*, then *κ* (the critical point of *j*) is always a [measurable cardinal](wikipedia://en/248102), i.e. an uncountable [cardinal number](wikipedia://en/6173) *κ* such that there exists a *κ*-complete, non-principal [ultrafilter](wikipedia://en/31911) over *κ.* Specifically, one may take the filter to be {{{nnbsp}}A ⊆ κ | κ ∈ *j*(*A*)}, which defines a bijection between elementary embeddings and ultrafilters.[^o3] Generally, there will be many other \<*κ*-complete, non-principal ultrafilters over *κ.* However, *j* might be different from the [ultrapowers](https://en.wikipedia.org/wiki/Ultrapower) arising from such filters.

If *N* and *M* are the same and *j* is the identity function on *N,* then *j* is called *trivial.* If the transitive class *N* is an [inner model](wikipedia://en/1118686) of [ZFC](https://en.wikipedia.org/wiki/ZFC) and *j* has no critical point, i.e. every ordinal maps to itself, then *j* is trivial.[^o3]
