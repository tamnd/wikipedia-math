# Admissible ordinal

::: {#o1 .subject cue=lead name="Admissible ordinal"}

In [set theory](wikipedia://en/27553), an [ordinal number](wikipedia://en/26547932) *α* is an **admissible ordinal** if [L<sub>*α*</sub>](wikipedia://en/343335) is an [admissible set](wikipedia://en/5138993) (that is, a [transitive model](wikipedia://en/1118686) of [Kripke–Platek set theory](wikipedia://en/1124695)); in other words, *α* is admissible when *α* is a [limit ordinal](wikipedia://en/373137) and L<sub>*α*</sub> ⊧ Σ<sub>0</sub>-collection.[^o2][^o3] The term was coined by Richard Platek in 1966.[^o4]

:::

The first two admissible ordinals are ω and $\omega_1^{\mathrm{CK}}$ (the least [nonrecursive ordinal](wikipedia://en/16084368), also called the [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Church–Kleene_ordinal)).[^o3] Any [regular](wikipedia://en/374128) [uncountable](https://en.wikipedia.org/wiki/Uncountable) [cardinal](wikipedia://en/6173) is an admissible ordinal.

By a theorem of [Sacks](wikipedia://en/3050504), the [countable](wikipedia://en/6026) admissible ordinals are exactly those constructed in a manner similar to the Church–Kleene ordinal, but for [Turing machines](wikipedia://en/30403) with [oracles](wikipedia://en/22431).[^o2] One sometimes writes $\omega_\alpha^{\mathrm{CK}}$ for the $\alpha$-th ordinal that is either admissible or a limit of admissibles; an ordinal that is both is called *recursively inaccessible*.[^o5] There exists a theory of large ordinals in this manner that is highly parallel to that of (small) [large cardinals](https://en.wikipedia.org/wiki/Large_cardinal_property) (one can define recursively [Mahlo](wikipedia://en/248081) ordinals, for example).[^o6] But all these ordinals are still countable. Therefore, admissible ordinals seem to be the recursive analogue of regular [cardinal numbers](wikipedia://en/6173).

Notice that *α* is an admissible ordinal if and only if *α* is a [limit ordinal](wikipedia://en/373137) and there does not exist a *γ* \< *α* for which there is a Σ<sub>1</sub>(L<sub>*α*</sub>) mapping from *γ* onto *α*.[^o7] $\alpha$ is an admissible ordinal if and only if there is a standard model $M$ of KP whose set of ordinals is $\alpha$, in fact this may be take as the definition of admissibility.[^o8][^o9] The $\alpha$th admissible ordinal is sometimes denoted by $\tau_\alpha$[^o10][^o9]<sup>p. 174</sup> or $\tau^0_\alpha$.[^o11]

The Friedman–Jensen–Sacks theorem states that a countable $\alpha$ is admissible if and only if there exists some $A\subseteq\omega$ such that $\alpha$ is the least ordinal not recursive in $A$.[^o12] Equivalently, for any countable admissible $\alpha$, there is an $A\subseteq\mathbb N$ making $\alpha$ minimal such that $\langle L_\alpha, \in, A\rangle$ is an admissible structure.[^o13]<sup>p. 264</sup>
