# NP-intermediate

::: {#o1 .subject cue=lead name="NP-intermediate"}

In [computational complexity](wikipedia://en/7543), problems that are in the [complexity class](wikipedia://en/502426) [NP](wikipedia://en/21562) but are neither in the class [P](wikipedia://en/658550) nor [NP-complete](https://en.wikipedia.org/wiki/NP-complete) are called **NP-intermediate**, and the class of such problems is called **NPI**. **Ladner's theorem**, shown in 1975 by [Richard E. Ladner](https://en.wikipedia.org/wiki/Richard_E._Ladner),[^o2] is a result asserting that, if [P ≠ NP](wikipedia://en/6115), then NPI is not empty; that is, NP contains problems that are neither in P nor NP-complete. Since it is also true that if NPI problems exist, then P ≠ NP, it follows that P = NP if and only if NPI is empty.

:::

Under the assumption that P ≠ NP, Ladner explicitly constructs a problem in NPI, although this problem is artificial and otherwise uninteresting. It is an open question whether any "natural" problem has the same property: [Schaefer's dichotomy theorem](wikipedia://en/4638322) provides conditions under which classes of constrained Boolean satisfiability problems cannot be in NPI.[^o3][^o4] Some problems that are considered good candidates for being NP-intermediate are the [graph isomorphism problem](wikipedia://en/1950766), and [decision versions](wikipedia://en/8336) of [factoring](wikipedia://en/15491) and the [discrete logarithm](wikipedia://en/181334).

Under the [exponential time hypothesis](wikipedia://en/26434552), there exist natural problems that require [quasi-polynomial time](wikipedia://en/25269049), and can be solved in that time, including finding a large disjoint set of [unit disks](wikipedia://en/252738) from a given set of disks in the [hyperbolic plane](https://en.wikipedia.org/wiki/Hyperbolic_plane),[^o5] and finding a graph with few vertices that is not an [induced subgraph](wikipedia://en/1655188) of a given graph.[^o6] The exponential time hypothesis also implies that no quasi-polynomial-time problem can be NP-complete, so under this assumption these problems must be NP-intermediate.

## List of problems that might be NP-intermediate {#List_of_problems_that_might_be_NP-intermediate}

### Algebra and number theory {#Algebra_and_number_theory}

- A decision version of [factoring integers](https://en.wikipedia.org/wiki/Factoring_integers): for input $n$ and $k$, does $n$ have a factor in the interval $[2,k]$?
- Decision versions of the [discrete logarithm problem](https://en.wikipedia.org/wiki/Discrete_logarithm_problem) and others related to cryptographic assumptions
- Linear divisibility: given integers $x$ and $y$, does $y$ have a divisor congruent to 1 modulo $x$?[^o9][^o10]

### Boolean logic {#Boolean_logic}

- IMSAT, the [Boolean satisfiability problem](wikipedia://en/4715) for "intersecting monotone CNF": [conjunctive normal form](wikipedia://en/73342), with each clause containing only positive or only negative terms, and each positive clause having a variable in common with each negative clause[^o12]
- [Minimum circuit size problem](https://en.wikipedia.org/wiki/Circuit_minimization_for_Boolean_functions): given the truth table of a Boolean function and positive integer $s$, does there exist a circuit of size at most $s$ for this function?[^o13]
- [Monotone dualization](wikipedia://en/75122486): given CNF and DNF formulas for monotone Boolean functions, do they represent the same function?[^o14]
- Monotone self-duality: given a CNF formula for a Boolean function, is the function invariant under a transformation that negates all of its variables and then negates the output value?[^o14]

### Computational geometry and computational topology {#Computational_geometry_and_computational_topology}

- Determining whether the [rotation distance](wikipedia://en/62539802)[^o16] between two [binary trees](wikipedia://en/4321) or the flip distance between two triangulations of the same convex polygon is below a given threshold
- The turnpike problem of reconstructing points on line from their distance multiset[^o17]
- The [cutting stock problem](wikipedia://en/826868) with a constant number of object lengths[^o18]
- [Knot triviality](wikipedia://en/4956355)[^o19]
- Finding a [simple closed quasigeodesic](wikipedia://en/48445265) on a convex polyhedron[^o20]

### Game theory {#Game_theory}

- Determining the winner in [parity games](https://en.wikipedia.org/wiki/Parity_game), in which graph vertices are labeled by which player chooses the next step, and the winner is determined by the parity of the highest-priority vertex reached[^o22]
- Determining the winner for stochastic graph games, in which graph vertices are labeled by which player chooses the next step, or whether it is chosen randomly, and the winner is determined by reaching a designated sink vertex.[^o23]

### Graph algorithms {#Graph_algorithms}

- [Graph isomorphism problem](wikipedia://en/1950766)[^o25]
- Finding a [graph's automorphism group](wikipedia://en/15094186)[^o26]
- Finding the number of [graph automorphisms](wikipedia://en/15094186)[^o26]
- Planar [minimum bisection](wikipedia://en/11973947)[^o27]
- Deciding whether a graph admits a [graceful labeling](wikipedia://en/8978968)[^o28]
- Recognizing [leaf powers](wikipedia://en/49639194) and $k$-leaf powers[^o29]
- Recognizing graphs of bounded [clique-width](wikipedia://en/16795502)[^o30]
- Testing the existence of a [simultaneous embedding](wikipedia://en/47904387) with fixed edges[^o31]

### Miscellaneous {#Miscellaneous}

- Testing whether the [Vapnik–Chervonenkis dimension](wikipedia://en/305846) of a given family of sets is below a given bound[^o33]
