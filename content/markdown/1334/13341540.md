# Asymmetric norm

::: {#o1 .subject cue=lead name="Asymmetric norm"}

In [mathematics](wikipedia://en/18831), an **asymmetric norm** on a [vector space](wikipedia://en/32370) is a generalization of the concept of a [norm](wikipedia://en/990534).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An **asymmetric norm** on a [real](wikipedia://en/20646438) [vector space](wikipedia://en/32370) $X$ is a [function](wikipedia://en/185427) $p : X \to [0, +\infty)$ that has the following properties:

- **[Subadditivity](wikipedia://en/745789)**, or the [triangle inequality](wikipedia://en/53941): $p(x + y) \leq p(x) + p(y) \text{ for all } x, y \in X.$
- **[Nonnegative homogeneity](https://en.wikipedia.org/wiki/Nonnegative_homogeneity)**: $p(rx) = r p(x) \text{ for all } x \in X$ and every non-negative real number $r \geq 0.$
- **[Positive definiteness](wikipedia://en/649616)**: $p(x) > 0 \text{ unless } x = 0$

Asymmetric norms differ from [norms](wikipedia://en/990534) in that they need not satisfy the equality $p(-x) = p(x).$

If the condition of positive definiteness is omitted, then $p$ is an **asymmetric seminorm**. A weaker condition than positive definiteness is **non-degeneracy**: that for $x \neq 0,$ at least one of the two numbers $p(x)$ and $p(-x)$ is not zero.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

On the [real line](https://en.wikipedia.org/wiki/Real_line) $\mathbb{R},$ the function $p$ given by

$$p(x) = \begin{cases}|x|, & x \leq 0; \\ 2 |x|, & x \geq 0; \end{cases}$$

is an asymmetric norm but not a norm.

In a real vector space $X,$ the [Minkowski functional](wikipedia://en/3510908) $p_B$ of a convex subset $B\subseteq X$ that contains the origin is defined by the formula

$$p_B(x) = \inf \left\{r \geq 0: x \in r B \right\}\,$$

for $x \in X$. This functional is an asymmetric seminorm if $B$ is an absorbing set, which means that $\bigcup_{r \geq 0} r B = X,$ and ensures that $p(x)$ is finite for each $x \in X.$

:::

## Corresponce between asymmetric seminorms and convex subsets of the dual space {#Corresponce_between_asymmetric_seminorms_and_convex_subsets_of_the_dual_space}

If $B^* \subseteq \mathbb{R}^n$ is a [convex set](wikipedia://en/6292) that contains the origin, then an asymmetric seminorm $p$ can be defined on $\mathbb{R}^n$ by the formula

$$p(x) = \max_{\varphi \in B^*} \langle\varphi, x \rangle.$$

For instance, if $B^* \subseteq \mathbb{R}^2$ is the square with vertices $(\pm 1,\pm 1),$ then $p$ is the [taxicab norm](https://en.wikipedia.org/wiki/Taxicab_norm) $x = \left(x_0, x_1\right) \mapsto \left|x_0\right| + \left|x_1\right|.$ Different convex sets yield different seminorms, and every asymmetric seminorm on $\mathbb{R}^n$ can be obtained from some convex set, called its **dual unit ball**. Therefore, asymmetric seminorms are in [one-to-one correspondence](wikipedia://en/3942) with convex sets that contain the origin. The seminorm $p$ is

- positive definite if and only if $B^*$ contains the origin in its [topological interior](https://en.wikipedia.org/wiki/Interior_%28mathematics%29),
- degenerate if and only if $B^*$ is contained in a [linear subspace](wikipedia://en/56357) of dimension less than $n,$ and
- symmetric if and only if $B^* = -B^*.$

More generally, if $X$ is a [finite-dimensional](https://en.wikipedia.org/wiki/Finite-dimensional) real vector space and $B^* \subseteq X^*$ is a compact convex subset of the [dual space](wikipedia://en/7988) $X^*$ that contains the origin, then $p(x) = \max_{\varphi \in B^*} \varphi(x)$ is an asymmetric seminorm on $X.$
