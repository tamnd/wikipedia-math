# Robbins lemma

::: {#o1 .subject cue=lead name="Robbins lemma"}

In [statistics](wikipedia://en/26685), the **Robbins lemma**, named after [Herbert Robbins](wikipedia://en/745193), states that if *X* is a [random variable](wikipedia://en/25685) having a [Poisson distribution](wikipedia://en/23009144) with parameter *λ*, and *f* is any function for which the [expected value](wikipedia://en/9653) E(*f*(*X*)) exists, then[^o2]

:::

$$\operatorname{E}(X f(X - 1)) = \lambda \operatorname{E}(f(X)).$$

Robbins introduced this proposition while developing [empirical Bayes methods](wikipedia://en/744988).
