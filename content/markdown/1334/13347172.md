# Luminosity function (astronomy)

::: {#o1 .subject cue=lead name="Luminosity function"}

In [astronomy](https://en.wikipedia.org/wiki/Astronomy), a **luminosity function** gives the number of [stars](https://en.wikipedia.org/wiki/Star) or [galaxies](https://en.wikipedia.org/wiki/Galaxy) per [luminosity](https://en.wikipedia.org/wiki/Luminosity) interval.[^o2] Luminosity functions are used to study the properties of large groups or classes of objects, such as the [stars](https://en.wikipedia.org/wiki/Star) in [clusters](https://en.wikipedia.org/wiki/Star_cluster) or the [galaxies](https://en.wikipedia.org/wiki/Galaxy) in the [Local Group](https://en.wikipedia.org/wiki/Local_Group).

:::

Note that the term "function" is slightly misleading, and the luminosity function might better be described as a luminosity *distribution*. Given a luminosity as input, the luminosity function essentially returns the abundance of objects with that luminosity (specifically, number density per luminosity interval).

## Main sequence luminosity function {#Main_sequence_luminosity_function}

The main sequence luminosity function maps the distribution of [main sequence](https://en.wikipedia.org/wiki/Main_sequence) stars according to their luminosity. It is used to compare star formation and death rates, and [evolutionary models](https://en.wikipedia.org/wiki/Stellar_evolution), with observations. Main sequence luminosity functions vary depending on their host galaxy and on selection criteria for the stars, for example in the [Solar neighbourhood](https://en.wikipedia.org/wiki/Solar_neighbourhood) or the [Small Magellanic Cloud](https://en.wikipedia.org/wiki/Small_Magellanic_Cloud).[^o4]

::: {#o6 .pointer-item cue=pointer name="White dwarf luminosity function"}

## White dwarf luminosity function {#White_dwarf_luminosity_function}

The **white dwarf luminosity function** (**WDLF**) gives the number of [white dwarf](https://en.wikipedia.org/wiki/White_dwarf) stars with a given luminosity. As this is determined by the rates at which these stars form and cool, it is of interest for the information it gives about the [physics](wikipedia://en/22939) of white dwarf cooling and the age and history of the [Galaxy](https://en.wikipedia.org/wiki/Milky_Way).[^o7][^o8]

:::

## Schechter luminosity function {#Schechter_luminosity_function}

The **Schechter luminosity function**[^o11] $\phi$ provides an approximation of the abundance of galaxies in a luminosity interval $[L+dL]$. The luminosity function has units of a number density $n$ per unit luminosity and is given by a power law with an exponential cut-off at high luminosity

$$dn(L) = \phi~ dL = \phi^* \left(\frac{L}{L^*}\right)^\alpha \mathrm{e}^{-L/L^*} d\left(\frac{L}{L^*}\right),$$

where $L^*$ is a characteristic galaxy luminosity controlling the cut-off, and the normalization $\,\!\phi^*$ has units of number density.

Equivalently, this equation can be expressed in terms of log-quantities[^o12] with

$$dn(L) = \ln(10) \phi^* \left(\frac{L}{L^*}\right)^{\alpha+1} \mathrm{e}^{-L/L^*} d\left(\log_{10}L\right).$$

The galaxy luminosity function may have different parameters for different populations and environments; it is not a universal function. One measurement from field galaxies is $\alpha=-1.25,\ \phi^* = 1.2 \times 10^{-2} \ h^3 \ \mathrm{Mpc}^{-3}$.[^o13]

It is often more convenient to rewrite the Schechter function in terms of [magnitudes](https://en.wikipedia.org/wiki/Magnitude_%28astronomy%29), rather than luminosities. In this case, the Schechter function becomes:

$$n(M)~ dM = (0.4 \ \ln 10) \ \phi^* \ [ 10^{ 0.4 ( M^* - M ) } ]^{ \alpha + 1} \exp [ -10^{ 0.4 ( M^* - M ) } ] ~ dM .$$

Note that because the magnitude system is logarithmic, the power law has logarithmic slope $\alpha + 1$. This is why a Schechter function with $\alpha = -1$ is said to be flat.

Integrals of the Schechter function can be expressed via the [incomplete gamma function](wikipedia://en/456050)

$$\int_a^b \left(\frac{L}{L^*}\right)^\alpha e^{-\left(\frac{L}{L^*}\right)} d \left(\frac{L}{L^*}\right)=\Gamma(\alpha+1,a)-\Gamma(\alpha+1,b)$$

Historically, the Schechter luminosity function was inspired by the [Press–Schechter model](wikipedia://en/23944162). [^o14] However, the connection between the two is not straight forward. If one assumes that every [dark matter halo](https://en.wikipedia.org/wiki/Dark_matter_halo) hosts one galaxy, then the Press-Schechter model yields a slope $\alpha\sim-3.5$ for galaxies instead of the value given above which is closer to -1. The reason for this failure is that large halos tend to have a large host galaxy and many smaller satellites, and small halos may not host any galaxies with stars. See, e.g., [halo occupation distribution](https://en.wikipedia.org/wiki/Halo_occupation_distribution), for a more-detailed description of the halo-galaxy connection.
