# Kullback–Leibler Upper Confidence Bound

*Image: UCB-type run.gif.* Behaviour of an UCB algorithm on a bandit run

::: {#o1 .subject cue=lead name="Kullback–Leibler Upper Confidence Bound"}

In [multi-armed bandit problems](https://en.wikipedia.org/wiki/Multi-armed_bandit_problem), **KL-UCB** (for *Kullback–Leibler Upper Confidence Bound*)[^o24] is a UCB-type algorithm that is asymptotically optimal, in the sense that its regret matches the problem-dependent [Lai-Robbins lower bound](https://en.wikipedia.org/wiki/Lai-Robbins_lower_bound).[^o28]

:::

## Multi-armed bandit problem {#Multi-armed_bandit_problem}

The [Multi-armed bandit problem](https://en.wikipedia.org/wiki/Multi-armed_bandit_problem) is a [sequential game](https://en.wikipedia.org/wiki/Sequential_game) where one player has to choose at each turn between $K$ actions (arms). Behind every arm $a$ there is an unknown distribution $\nu_a$ that lies in a set $\mathcal{D}$ known by the player (for example, $\mathcal{D}$ can be the set of [Gaussian distributions](wikipedia://en/21462) or [Bernoulli distributions](wikipedia://en/199189)).

At each turn $t$ the player chooses (pulls) an arm $a_t$, he then gets an observation $X_t$ of the distribution $\nu_{a_t}$.

### Regret minimization {#Regret_minimization}

The goal is to minimize the regret at time $T$ that is defined as

$$R_T := \sum_{a=1}^K \Delta_a \mathbb{E}[N_a(T)]$$

where

- $\mu_a := \mathbb{E}[\nu_a]$ is the mean of arm $a$
- $\mu^* := \max_a \mu_a$ is the highest mean
- $$\Delta_a := \mu^* - \mu_a$$
- $N_a(t)$ is the number of pulls of arm $a$ up to turn $t$

The player has to find an algorithm that chooses at each turn $t$ which arm to pull based on the previous actions and observations $(a_s,X_s)_{s < t}$ to minimize the regret $R_T$.

This is a trade-off problem between exploration to find the best arm (the arm with the highest mean) and exploitation to play as much as possible the arm that we think is the best arm.[^o23]

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

Multi-armed bandit algorithms are used in a variety of fields; for example, they have applications in clinical trials, recommender systems, telecommunications[^o22], and precision agriculture.[^o21]

:::

## Algorithm KL-UCB {#Algorithm_KL-UCB}

The algorithm is a UCB-type algorithm based on optimism, which means that at each turn $t$ we compute an upper confidence bound (UCB) for the mean of each arm $a$; we then pull the arm with the highest UCB.

The difference with KL-UCB is that it uses an estimation of the lower bound of [Lai](wikipedia://en/63735520)–[Robbins](wikipedia://en/745193)[^o28] to make the upper confidence bound.[^o24]

### History {#History}

The algorithm was first introduced in 2011 for [Bernoulli distribution](wikipedia://en/199189).[^o24] It was then extended to one-dimensional [exponential families](wikipedia://en/339174) and bounded distributions in 2013.[^o25] An adaptation called KL-UCB-Switch, which uses a mix of MOSS[^o20] and KL-UCB, was developed to obtain both the problem-dependent and problem-independent asymptotic lower bounds in 2022.[^o26] The algorithm was also extended to Lipschitz bandits in 2014.[^o27]

### Formal algorithm {#Formal_algorithm}

*Image: Kl ucb index.png.* The index of an arm a at turn t for KL UCB

At first, the algorithm pulls all the arms once. Then, for each turn $t \geq K+1$, for each arm $a$, we compute:

$$U_a(t) := \max\left\{ \mu \ | \ N_a(t)\mathcal{K}_{inf}(\hat \nu_a(t),\mu,\mathcal{D}) \leq \delta_t \right\}$$

where

- $$\mathcal{K}_{inf}(\nu,\mu,\mathcal{D}) := \inf\left\{\mathrm{KL}(\nu,\tilde\nu) \ | \ \tilde \nu \in \mathcal{D}, \ \mathbb{E}[\tilde \nu] > \mu \right\}$$
- $\mathrm{KL}$ is the [Kullback–Leibler divergence](wikipedia://en/1115052)
- $\hat \nu_a(t)$ is the [empirical distribution](wikipedia://en/5647670) of arm $a$ at turn $t$
- $\delta_t$ is a well-chosen sequence of positive numbers, often equal to $\ln t + c \ln \ln t$ with $c > 0$.[^o25]

Then we choose the arm $a_t$ with the highest index:

$$a_t := \arg \max_a U_a(t)$$

We note that the algorithm does not require knowledge of $T$.

::: {#o10 .example cue=heading name="Example"}

### Example {#Example}

In the special case of [Gaussian distribution](wikipedia://en/21462) with fixed variance $\sigma^2$, we have:

$$U_a(t) = \hat \mu_a(t) + \sqrt{\frac{2 \sigma^2 \delta_t}{N_a(t)}}$$

with $\hat \mu_a(t)$ being the [empirical mean](wikipedia://en/10005756) of arm $a$ at turn $t$.

:::

## Theoretical results {#Theoretical_results}

In the multi-armed bandit problem we have the [Lai](wikipedia://en/63735520)–[Robbins](wikipedia://en/745193)[^o28] asymptotic lower bound on regret. The algorithm KL-UCB matches this lower bound for one-dimensional exponential families with $\delta_t := \ln t + 3 \ln \ln t$ and for distributions bounded in $[0,1]$ with $\delta_t := \ln t + \ln \ln t$.[^o25]

### Lai–Robbins lower bound {#Lai–Robbins_lower_bound}

In 1985 [Lai](wikipedia://en/63735520) and [Robbins](wikipedia://en/745193) proved an asymptotic, problem-dependent lower bound on regret.

It states that for every consistent algorithm on the set $\mathcal{D}$ — that is, an algorithm for which, for every $(\nu_1,\dots,\nu_K)\in\mathcal{D}^K$, the regret $R_T$ is subpolynomial (i.e. $R_T = o_{T\to+\infty}(T^\alpha)$ for all $\alpha>0$) — we have:

$$R_T \geq \left(\sum_{a : \mu_a < \mu^*} \frac{\Delta_a}{\mathcal{K}_{\inf}(\nu_a,\mu^*,\mathcal{D})} \right)\ln T + o_{T\to+\infty}(\ln T).$$

This bound is asymptotic (as $T \to +\infty$) and gives a first-order lower bound of order $\ln T$ with the optimal constant in front of it.

### Regret bound for KL-UCB {#Regret_bound_for_KL-UCB}

The algorithm matches the [Lai](wikipedia://en/63735520)–[Robbins](wikipedia://en/745193)[^o28] lower bound for one-dimensional exponential-family distributions and for distributions bounded in $[0,1]$.[^o25]

#### One-dimensional exponential family {#One-dimensional_exponential_family}

For $\mathcal{D}$ being the set of one-dimensional exponential families, with $\delta_t := \ln t + 3 \ln \ln t$ we have the following upper bound on the regret of KL-UCB:[^o25]

$$R_T \leq \left(\sum_{a : \mu_a < \mu^*} \frac{\Delta_a}{\mathcal{K}_{\inf}(\nu_a,\mu^*,\mathcal{D})} \right)\ln T + O_{T}(\sqrt{\ln T}).$$

#### Bounded distributions in \[0,1\] {#Bounded_distributions_in_[0,1]}

For $\mathcal{D} = \mathcal{P}([0,1])$ (the set of distributions supported on $[0,1]$), and for $\delta_t := \ln t + \ln \ln t$, we have the following upper bound on the regret of KL-UCB:[^o25]

$$R_T \leq \left(\sum_{a : \mu_a < \mu^*} \frac{\Delta_a}{\mathcal{K}_{\inf}(\nu_a,\mu^*,\mathcal{D})} \right)\ln T + O_{T}\big((\ln T)^{4/5} \ln \ln T\big).$$

### Runtime {#Runtime}

For $\mathcal{D} = \mathcal{P}([0,1])$, the runtime needed per step and for an arm $k$ with $n$ observations is $\mathcal{O}\big(n(\ln n)^2\big)$.[^o32] This is higher than that of other optimal algorithms, such as NPTS[^o29] with $\mathcal{O}(n)$.[^o32] MED[^o31] with $\mathcal{O}(n \ln n)$.[^o32] and [IMED](wikipedia://en/82983461)[^o30] with $\mathcal{O}(n \ln n)$.[^o32]

The high runtime of KL-UCB is due to a two-level optimisation: for each arm and candidate mean $\mu$, the algorithm evaluates $\mathcal{K}_{\inf}(\hat\nu_a(t),\mu,\mathcal{D})$ and then maximises $\mu$ subject to $N_a(t)\,\mathcal{K}_{\inf}(\hat\nu_a(t),\mu,\mathcal{D}) \le \delta_t$. For distributions bounded in $[0,1]$ the inner problem has no closed form and must be solved numerically, which increases the per-step cost.[^o31][^o25]
