# CDMF

::: {#o1 .subject cue=lead name="CDMF"}

In [cryptography](wikipedia://en/18934432), **CDMF** (**Commercial Data Masking Facility**) is an algorithm developed at [IBM](https://en.wikipedia.org/wiki/IBM) in 1992 to reduce the [security strength](https://en.wikipedia.org/wiki/Security_strength) of the [56-bit](wikipedia://en/33020823) [DES](wikipedia://en/7978) cipher to that of [40-bit encryption](wikipedia://en/487403), at the time a requirement of U.S. restrictions on [export of cryptography](wikipedia://en/25872370). Rather than a separate cipher from DES, CDMF constitutes a [key generation](https://en.wikipedia.org/wiki/Key_generation) algorithm, called *key shortening*. It is one of the cryptographic algorithms supported by [S-HTTP](https://en.wikipedia.org/wiki/S-HTTP).

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

Like DES, CDMF accepts a 64-bit input [key](wikipedia://en/53039), but not all bits are used. The algorithm consists of the following steps:

1. Clear bits 8, 16, 24, 32, 40, 48, 56, 64 (ignoring these bits as DES does).
1. [XOR](https://en.wikipedia.org/wiki/XOR) the result with its encryption under DES using the key 0xC408B0540BA1E0AE.
1. Clear bits 1, 2, 3, 4, 8, 16, 17, 18, 19, 20, 24, 32, 33, 34, 35, 36, 40, 48, 49, 50, 51, 52, 56, 64.
1. Encrypt the result under DES using the key 0xEF2C041CE6382FE6.

The resulting 64-bit data is to be used as a DES key. Due to step 3, a [brute force attack](https://en.wikipedia.org/wiki/Brute_force_attack) needs to test only 2<sup>40</sup> possible keys.
