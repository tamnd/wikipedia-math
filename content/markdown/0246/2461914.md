# Fundamental lemma of the calculus of variations

::: {#o1 .subject cue=lead name="Fundamental lemma of the calculus of variations"}

In [mathematics](wikipedia://en/18831), specifically in the [calculus of variations](wikipedia://en/171882), a variation $\delta f$ of a [function](wikipedia://en/185427) $f$ can be concentrated on an arbitrarily small interval, but not a single point. Accordingly, the [necessary condition](wikipedia://en/169319) of extremum ([functional derivative](wikipedia://en/301504) equal zero) appears in a [weak formulation](wikipedia://en/3368981) (variational form) integrated with an arbitrary function $\delta f$. The **fundamental lemma of the calculus of variations** is typically used to transform this weak formulation into the strong formulation ([differential equation](wikipedia://en/1424309)), free of the integration with arbitrary function. The proof usually exploits the possibility to choose $\delta f$ concentrated on an interval on which $f$ keeps sign (positive or negative). Several versions of the lemma are in use. Basic versions are easy to formulate and prove. More powerful versions are used when needed.

:::

## Basic version {#Basic_version}

If a continuous function $f$ on an open interval $(a,b)$ satisfies the equality

$$\int_a^b f(x)h(x)\,\mathrm{d}x = 0$$

for all [compactly supported](https://en.wikipedia.org/wiki/Compactly_supported) [smooth functions](https://en.wikipedia.org/wiki/Smooth_function) $h$ on $(a,b)$, then $f$ is identically zero.[^o3][^o4]

Here "smooth" may be interpreted as "infinitely differentiable",[^o3] but often is interpreted as "twice continuously differentiable" or "continuously differentiable" or even just "continuous",[^o4] since these weaker statements may be strong enough for a given task. "Compactly supported" means "vanishes outside $[c,d]$ for some $c$, $d$ such that $a<c<d<b$";[^o3] but often a weaker statement suffices, assuming only that $h$ (or $h$ and a number of its derivatives) vanishes at the endpoints $a$, $b$;[^o4] in this case the closed interval $[a,b]$ is used.

::: {#o6 .proof cue=heading name="Proof"}

## Proof {#Proof}

Suppose $f(\bar{x}) \neq 0$ for some $\bar{x} \in (a, b)$. Since $f$ is continuous, it is nonzero with the same sign for some $c,d$ such that $a < c < \bar{x} < d < b$. [Without loss of generality](wikipedia://en/296000), assume $f(\bar{x}) > 0$. Then take an $h$ that is positive on $(c, d)$ and zero elsewhere, for example

$$h(x) = \begin{cases} \exp\left(-\frac{1}{(x-c)(d-x)}\right),& c < x < d \\ 0,& \mathrm{otherwise} \end{cases}.$$

Note this [bump function](wikipedia://en/815799) satisfies the properties in the statement, including $C^\infty$. Since

$$\int_a^b f(x)h(x) dx > 0,$$

we reach a contradiction.[^o7]

:::

## Version for two given functions {#Version_for_two_given_functions}

If a pair of continuous functions *f*, *g* on an interval (*a*,*b*) satisfies the equality

$$\int_a^b ( f(x) \, h(x) + g(x) \, h'(x) ) \, \mathrm{d}x = 0$$

for all compactly supported smooth functions *h* on (*a*,*b*), then *g* is differentiable, and *g**\=*****f*everywhere.[^o9][^o10]***

The special case for *g* = 0 is just the basic version.

Here is the special case for *f* = 0 (often sufficient).

If a continuous function *g* on an interval (*a*,*b*) satisfies the equality

$$\int_a^b g(x) \, h'(x) \, \mathrm{d}x = 0$$

for all smooth functions *h* on (*a*,*b*) such that $h(a)=h(b)=0$, then *g* is [constant](wikipedia://en/320861).[^o11][^o12]

If, in addition, [continuous differentiability](https://en.wikipedia.org/wiki/Continuously_differentiable) of *g* is assumed, then [integration by parts](wikipedia://en/147252) reduces both statements to the basic version; this case is attributed to [Joseph-Louis Lagrange](wikipedia://en/87793), while the proof of differentiability of *g* is due to [Paul du Bois-Reymond](wikipedia://en/7457861).

## Versions for discontinuous functions {#Versions_for_discontinuous_functions}

The given functions (*f*, *g*) may be discontinuous, provided that they are [locally integrable](https://en.wikipedia.org/wiki/Locally_integrable) (on the given interval). In this case, [Lebesgue integration](https://en.wikipedia.org/wiki/Lebesgue_integration) is meant, the conclusions hold [almost everywhere](wikipedia://en/44688) (thus, in all continuity points), and differentiability of *g* is interpreted as local [absolute continuity](wikipedia://en/252670) (rather than continuous differentiability).[^o14][^o15] Sometimes the given functions are assumed to be [piecewise continuous](https://en.wikipedia.org/wiki/Piecewise_continuous), in which case [Riemann integration](https://en.wikipedia.org/wiki/Riemann_integration) suffices, and the conclusions are stated everywhere except the finite set of discontinuity points.[^o10]

## Higher derivatives {#Higher_derivatives}

If a tuple of continuous functions $f_0,f_1,\dots,f_n$ on an interval (*a*,*b*) satisfies the equality

$$\int_a^b ( f_0(x) \, h(x) + f_1(x) \, h'(x) + \dots + f_n(x) \, h^{(n)}(x) ) \, \mathrm{d}x = 0$$

for all compactly supported smooth functions *h* on (*a*,*b*), then there exist continuously differentiable functions $u_0,u_1,\dots,u_{n-1}$ on (*a*,*b*) such that

$$\begin{aligned} f_0 &= u'_0, \\ f_1 &= u_0 + u'_1, \\ f_2 &= u_1 + u'_2 \\ \vdots \\ f_{n-1} &= u_{n-2} + u'_{n-1}, \\ f_n &= u_{n-1} \end{aligned}$$

everywhere.[^o17]

This necessary condition is also sufficient, since the integrand becomes $(u_0 h)' + (u_1 h')' + \dots + (u_{n-1} h^{(n-1)})'.$

The case *n* = 1 is just the version for two given functions, since $f=f_0=u'_0$ and $f_1=u_0,$ thus, $f_0-f'_1 = 0.$

In contrast, the case *n*=2 does not lead to the relation $f_0 - f'_1 + f''_2 = 0,$ since the function $f_2 = u_1$ need not be differentiable twice. The sufficient condition $f_0 - f'_1 + f''_2 = 0$ is not necessary. Rather, the necessary and sufficient condition may be written as $f_0 - (f_1 - f'_2)' = 0$ for *n*=2, $f_0 - (f_1 - (f_2-f'_3)')' = 0$ for *n*=3, and so on; in general, the brackets cannot be opened because of non-differentiability.

## Vector-valued functions {#Vector-valued_functions}

Generalization to [vector-valued functions](https://en.wikipedia.org/wiki/Vector-valued_functions) $(a,b)\to\mathbb{R}^d$ is straightforward; one applies the results for scalar functions to each coordinate separately,[^o19] or treats the vector-valued case from the beginning.[^o20]

## Multivariable functions {#Multivariable_functions}

If a continuous [multivariable function](wikipedia://en/39783039) *f* on an open set $\Omega\subset\mathbb{R}^d$ satisfies the equality

$$\int_\Omega f(x) \, h(x) \, \mathrm{d}x = 0$$

for all compactly supported smooth functions *h* on Ω, then *f* is identically zero.

Similarly to the basic version, one may consider a continuous function *f* on the closure of Ω, assuming that *h* vanishes on the boundary of Ω (rather than compactly supported).[^o22]

Here is a version for discontinuous multivariable functions.

Let $\Omega\subset\mathbb{R}^d$ be an open set, and $f\in L^2(\Omega)$ satisfy the equality

$$\int_\Omega f(x) \, h(x) \, \mathrm{d}x = 0$$

for all compactly supported smooth functions *h* on Ω. Then *f*=0 (in *L*<sup>2</sup>, that is, almost everywhere).[^o23]

::: {#o25 .application cue=heading name="Applications"}

## Applications {#Applications}

This lemma is used to prove that [extrema](https://en.wikipedia.org/wiki/Maxima_and_minima) of the [functional](wikipedia://en/1374948)

$$J[y] = \int_{x_0}^{x_1} L(t,y(t),\dot y(t)) \, \mathrm{d}t$$

are [weak solutions](wikipedia://en/3555416) $y:[x_0,x_1]\to V$ (for an appropriate vector space $V$) of the [Euler–Lagrange equation](wikipedia://en/294995)

$${\partial L(t,y(t),\dot y(t)) \over \partial y} = {\mathrm{d} \over \mathrm{d}t} {\partial L(t,y(t),\dot y(t)) \over \partial \dot y} .$$

The Euler–Lagrange equation plays a prominent role in [classical mechanics](wikipedia://en/19555586) and [differential geometry](wikipedia://en/8625).

:::
