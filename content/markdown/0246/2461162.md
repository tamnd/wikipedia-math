# Goldwasser–Micali cryptosystem

::: {#o1 .subject cue=lead name="Goldwasser–Micali cryptosystem"}

The **Goldwasser–Micali (GM) cryptosystem** is an [asymmetric key encryption algorithm](https://en.wikipedia.org/wiki/Asymmetric_key_encryption_algorithm) developed by [Shafi Goldwasser](wikipedia://en/842178) and [Silvio Micali](https://en.wikipedia.org/wiki/Silvio_Micali) in 1982. GM has the distinction of being the first [probabilistic](wikipedia://en/1051442) public-key encryption scheme which is [provably secure](https://en.wikipedia.org/wiki/Provably_secure) under standard cryptographic assumptions. However, it is not an efficient cryptosystem, as ciphertexts may be several hundred times larger than the initial plaintext. To prove the security properties of the cryptosystem, Goldwasser and Micali proposed the widely used definition of [semantic security](wikipedia://en/960585).

:::

## Basis {#Basis}

The GM cryptosystem is [semantically secure](wikipedia://en/960585) based on the assumed intractability of the [quadratic residuosity problem](wikipedia://en/1183041) modulo a composite *N* = *pq* where *p, q* are large [primes](wikipedia://en/23666). This assumption states that given (*x*, *N*) it is difficult to determine whether *x* is a quadratic residue modulo *N* (i.e., *x* = *y*<sup>2</sup> mod *N* for some *y*), when the [Jacobi symbol](wikipedia://en/97313) for *x* is +1. The quadratic residue problem is easily solved given the factorization of *N*, while new quadratic residues may be generated by any party, even without knowledge of this factorization. The GM cryptosystem leverages this asymmetry by encrypting individual plaintext bits as either random quadratic residues or non-residues modulo *N*, all with quadratic residue symbol +1. Recipients use the factorization of *N* as a [secret key](https://en.wikipedia.org/wiki/Secret_key), and decrypt the message by testing the quadratic residuosity of the received ciphertext values.

Because Goldwasser–Micali produces a value of size approximately |*N*| to encrypt every single bit of a plaintext, GM encryption results in substantial [ciphertext expansion](wikipedia://en/2467473). To prevent [factorization](wikipedia://en/82341) attacks, it is recommended that |*N*| be several hundred bits or more. Thus, the scheme serves mainly as a proof of concept, and more efficient provably-secure schemes such as [ElGamal](wikipedia://en/59458) have been developed since.

Because encryption is performed using a probabilistic algorithm, a given plaintext may produce very different ciphertexts each time it is encrypted. This has significant advantages, as it prevents an adversary from recognizing intercepted messages by comparing them to a dictionary of known ciphertexts.

## Scheme definition {#Scheme_definition}

Goldwasser–Micali consists of three algorithms: a probabilistic key generation algorithm which produces a public and a private key, a probabilistic encryption algorithm, and a deterministic decryption algorithm.

The scheme relies on deciding whether a given value *x* is a square mod *N*, given the factorization (*p*, *q*) of *N*. This can be accomplished using the following procedure:

1. Compute *x<sub>p</sub>* = *x* mod *p*, *x<sub>q</sub>* = *x* mod *q*.
1. If $x_p^{(p-1)/2} \equiv 1\pmod{p}$ and $x_q^{(q-1)/2} \equiv 1\pmod{q}$, then *x* is a quadratic residue mod *N*.

### Key generation {#Key_generation}

The modulus used in GM encryption is generated in the same manner as in the [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) cryptosystem. (See [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29), key generation for details.)

1. Alice generates two distinct large [prime numbers](wikipedia://en/23666) *p* and *q*, randomly and independently of each other.
1. Alice computes *N* = *p q*.
1. She then finds some non-residue *x* such that the [Legendre symbols](wikipedia://en/18567) satisfy $\left(\frac{x}{p}\right)=\left(\frac{x}{q}\right)=-1$ and hence the [Jacobi symbol](wikipedia://en/97313) $\left(\frac{x}{N}\right)$ is +1. The value *x* can for example be found by selecting random values and testing the two Legendre symbols. If *p*, *q* = 3 mod 4 (i.e., *N* is a [Blum integer](wikipedia://en/2218352)), then the value *N* − 1 is guaranteed to have the required property.

The *public key* consists of (*x*, *N*). The secret key is the factorization (*p*, *q*).

### Message encryption {#Message_encryption}

Suppose Bob wishes to send a message *m* to Alice:

1. Bob first encodes *m* as a string of bits (*m*<sub>1</sub>, ..., *m<sub>n</sub>*).
1. For every bit *$m_i$*, Bob generates a random value *$y_i$* from the group of units modulo *N*, or *$\gcd(y_i,N) = 1$*. He outputs the value $c_i = y_i^2 x^{m_i}\pmod{N}$.

Bob sends the ciphertext (*c*<sub>1</sub>, ..., *c*<sub>*n*</sub>).

### Message decryption {#Message_decryption}

Alice receives (*c*<sub>1</sub>, ..., *c*<sub>*n*</sub>). She can recover *m* using the following procedure:

1. For each *i*, using the prime factorization (*p*, *q*), Alice determines whether the value *c*<sub>*i*</sub> is a quadratic residue; if so, *m*<sub>*i*</sub> = 0, otherwise *m*<sub>*i*</sub> = 1.

Alice outputs the message *m* = (*m*<sub>1</sub>, ..., *m*<sub>*n*</sub>).

### Security properties {#Security_properties}

There is a simple [reduction](wikipedia://en/848067) from breaking this cryptosystem to the problem of determining whether a random value modulo *N* with Jacobi symbol *\+1* is a quadratic residue. If an algorithm *A* breaks the cryptosystem, then to determine if a given value *x* is a quadratic residue modulo *N*, we test *A* to see if it can break the cryptosystem using (*x*,*N*) as a public key. If *x* is a non-residue, then *A* should work properly. However, if *x* is a residue, then every "ciphertext" will simply be a random quadratic residue, so *A* cannot be correct more than half of the time. Furthermore, this problem is [random self-reducible](wikipedia://en/3087266), which ensures that for a given *N*, every public key is just as secure as every other public key.

The GM cryptosystem has [homomorphic properties](wikipedia://en/4939073), in the sense that if *c*<sub>0</sub>, *c*<sub>1</sub> are the encryptions of bits *m*<sub>0</sub>, *m*<sub>1</sub>, then *c*<sub>0</sub>*c*<sub>1</sub> mod *N* will be an encryption of $m_0 \oplus m_1$. For this reason, the GM cryptosystem is sometimes used in more complex cryptographic primitives.
