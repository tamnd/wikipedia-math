# Transitive set

::: {#o1 .subject cue=lead name="Transitive set"}

In [set theory](wikipedia://en/27553), a branch of [mathematics](wikipedia://en/18831), a [set](wikipedia://en/26691) $A$ is called **transitive** if either of the following equivalent conditions holds:

:::

- whenever $x \in A$, and $y \in x$, then $y \in A$.
- whenever $x \in A$, and $x$ is not an [urelement](wikipedia://en/643648), then $x$ is a [subset](wikipedia://en/27631) of $A$.

Similarly, a [class](wikipedia://en/20696) $M$ is transitive if every element of $M$ is a subset of $M$.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Using the definition of [ordinal numbers](wikipedia://en/26547932) suggested by [John von Neumann](wikipedia://en/15942), ordinal numbers are defined as [hereditarily](wikipedia://en/13552465) transitive sets: an ordinal number is a transitive set whose members are also transitive (and thus ordinals). The class of all ordinals is a transitive class.

Any of the stages $V_\alpha$ and $L_\alpha$ leading to the construction of the [von Neumann universe](wikipedia://en/445980) $V$ and [Gödel's constructible universe](https://en.wikipedia.org/wiki/Gödel's_constructible_universe) $L$ are transitive sets. The [universes](wikipedia://en/296838) $V$ and $L$ themselves are transitive classes.

## Properties {#Properties}

A set $X$ is transitive if and only if $\textstyle\bigcup X \subseteq X$, where $\textstyle\bigcup X$ is the [union](wikipedia://en/47949#Arbitrary_unions) of all elements of $X$ that are sets; formally,

$$\bigcup X = \{y \mid \exists x \in X: y \in x\}.$$

Moreover, if $X$ is transitive, then $\textstyle\bigcup X$ is transitive.

If $X$ and $Y$ are transitive, then $X\cup Y$ and $X \cup Y \cup \{X,Y\}$ are transitive. In general, if $Z$ is a class all of whose elements are transitive sets, then $\bigcup Z$ and $Z\cup\bigcup Z$ are transitive. (The first sentence in this paragraph is the case of $Z=\{X,Y\}$.)

A set $X$ that does not contain urelements is transitive if and only if it is a subset of its own [power set](wikipedia://en/23799), $X \subseteq \mathcal{P}(X)$. The power set of a transitive set without urelements is transitive.

:::

## Transitive closure {#Transitive_closure}

The **transitive closure** of a set $X$, denoted $\operatorname{TC}(X)$, is the smallest (with respect to inclusion) transitive set that includes $X$.[^n1] The transitive closure of $X$ can be equivalently defined as

$$\operatorname{TC}(X) = \bigcup \left\{ X,\; \bigcup X,\; \bigcup\bigcup X,\; \bigcup\bigcup\bigcup X,\; \bigcup\bigcup\bigcup\bigcup X, \ldots\right\}.$$

*Proof*. Denote $X_0 = X$ and $X_{n+1} = \textstyle\bigcup X_n$. Then we claim that the set

$$T = \operatorname{TC}(X) = \bigcup_{n=0}^\infty X_n$$

is transitive, and whenever $T_1$ is a transitive set including $X$ then $T \subseteq T_1$.

Assume $y \in x \in T$. Then $x \in X_n$ for some $n$ and so $y \in \textstyle\bigcup X_n = X_{n+1}$. Since $X_{n+1} \subseteq T$, $y \in T$. Thus $T$ is transitive.

Now let $T_1$ be as above. We prove by induction that $X_n \subseteq T_1$ for all $n$, thus proving that $T \subseteq T_1$. The base case holds since $X_0 = X \subseteq T_1$. Now assume $X_n \subseteq T_1$. Then $X_{n+1} = \textstyle\bigcup X_n \subseteq \bigcup T_1$. But $T_1$ is transitive so $\textstyle\bigcup T_1 \subseteq T_1$, hence $X_{n+1} \subseteq T_1$. This completes the proof.

Note that this is the set of all of the objects related to $X$ by the [transitive closure](wikipedia://en/292239) of the membership relation, since the union of a set can be expressed in terms of the [relative product](wikipedia://en/7472170) of the membership relation with itself.

:::

## Transitive models of set theory {#Transitive_models_of_set_theory}

Transitive classes are often used for construction of [interpretations](https://en.wikipedia.org/wiki/Relative_interpretation) of set theory in itself, usually called [inner models](wikipedia://en/1118686). The reason is that properties defined by [bounded formulas](wikipedia://en/5824808) are [absolute](https://en.wikipedia.org/wiki/Absoluteness_%28mathematical_logic%29) for transitive classes.[^n2]

A transitive set (or class) that is a model of a [formal system](wikipedia://en/3512103) of set theory is called a *transitive model* of the system (provided that the element relation of the model is the restriction of the true element relation to the universe of the model). Transitivity is an important factor in determining the absoluteness of formulas.

In the superstructure approach to [non-standard analysis](https://en.wikipedia.org/wiki/Non-standard_analysis), the non-standard universes satisfy *strong transitivity*. Here, a class $\mathcal{C}$ is defined to be strongly transitive if, for each set $S\in\mathcal{C}$, there exists a transitive superset $T$ with $S\subseteq T\subseteq\mathcal{C}$. A strongly transitive class is automatically transitive. This strengthened transitivity assumption allows one to conclude, for instance, that $\mathcal{C}$ contains the domain of every [binary relation](wikipedia://en/3931) in $\mathcal{C}$.[^n3]
