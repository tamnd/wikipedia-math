# Internet censorship circumvention

::: {#o1 .subject cue=lead name="Internet censorship circumvention"}

**Internet censorship circumvention** is the use of various methods and tools by technically skilled users to bypass [Internet censorship](https://en.wikipedia.org/wiki/Internet_censorship)—the legal control or suppression of access to, publication of, or viewing of content on the [Internet](https://en.wikipedia.org/wiki/Internet). Commonly used software tools include [Lantern](https://en.wikipedia.org/wiki/Lantern_%28software%29) and [Psiphon](https://en.wikipedia.org/wiki/Psiphon), which can bypass multiple types of restrictions. Some methods evade less sophisticated blocking tools by using alternate [Domain Name System](https://en.wikipedia.org/wiki/Domain_Name_System) (DNS) servers, false [IP addresses](https://en.wikipedia.org/wiki/IP_address), or address lookup systems.[^o9][^o10] However, such methods become ineffective if censors block not only the DNS but also the IP addresses of restricted domains, thereby rendering a potential bypass ineffective. Other tools can tunnel the network traffic to [proxy servers](https://en.wikipedia.org/wiki/Proxy_servers) in jurisdictions that don't have censorship. Through pluggable transports, traffic obscuration, [website mirrors](https://en.wikipedia.org/wiki/Website_mirroring), or [archive sites](https://en.wikipedia.org/wiki/Archive_site), users can access copies of websites even in areas with Internet censorship.[^o2][^o19]

:::

An "[arms race](https://en.wikipedia.org/wiki/Arms_race)" (or competition) has developed between censors and developers of circumvention software. This competition leads to two types of innovation: more sophisticated blocking techniques by censors, and less detectable tools by circumvention developers.[^o29] While estimates of user adoption for circumvention tools vary, it is widely accepted that tens of millions of people use them each month.[^o42][^o3][^o4][^o50] Barriers to adoption include usability issues; difficulty in finding reliable information on circumvention; limited motivation to access censored content; and risks from breaking the law.[^o5][^o55][^o6][^o19]

## Circumvention methods {#Circumvention_methods}

Major circumvention methods include alternate names and addresses; mirrors, caches, and copies; alternative platforms; proxying; and traffic obfuscation.

### Alternate names and addresses {#Alternate_names_and_addresses}

Censorship filters may block specific domain names, using either [DNS hijacking](https://en.wikipedia.org/wiki/DNS_hijacking) or URL filtering. Websites can sometimes be accessed through alternate names and addresses that may not be blocked.[^o9]

Some websites offer the same content across multiple pages or domains.[^o10]

If a website's DNS resolution is disrupted, but the site is not otherwise blocked, it may be possible to access the site directly by its IP address or by modifying a computer's [`hosts`](https://en.wikipedia.org/wiki/Hosts_%28file%29) file. It may be possible to bypass DNS-based blocking by using alternative DNS servers or [public recursive name servers](https://en.wikipedia.org/wiki/Public_recursive_name_server) (especially via an encrypted DNS client).[^o9]

Censors may block specific IP addresses. Depending on how such filtering is implemented, it may be possible to use different forms of a blocked IP address, for example, by specifying the address in a different [numeral system](wikipedia://en/21170).[^o11] For example, the following URLs all access the same site, but only some browsers will recognize all forms of the URL:

- `http://192.0.33.8/` (dotted decimal)
- `http://3221233928/` (decimal)
- `http://0300.0000.0041.0010/` (dotted octal)
- `http://0xc0002108/` (hexadecimal)
- `http://0xc0.0x00.0x21.0x08/` (dotted hexadecimal)

The [Blockchain](wikipedia://en/44065971) project [Namecoin](https://en.wikipedia.org/wiki/Namecoin) is an attempt to decentralize Internet namespaces beyond the control of any single entity.[^o12][^o13] Decentralized namespaces enable domains to resist censorship. Discussion of the project began in 2010 with a desire to achieve names that are decentralized, secure, and human-readable.[^o14]

### Mirrors, caches, and copies {#Mirrors,_caches,_and_copies}

Certain online services allow users to access content that is blocked on the Internet through cached or mirrored copies:

- *Cached pages:* Some search engines retain copies of previously indexed webpages, or [cached pages](https://en.wikipedia.org/wiki/Web_cache), which are often hosted by search engines; these may not be blocked.[^o19]
- *Mirror and archive sites*: Copies of websites or pages may be available at [mirror](https://en.wikipedia.org/wiki/Website_mirror) or [archive](https://en.wikipedia.org/wiki/Archive_site) sites such as [Wayback Machine](https://en.wikipedia.org/wiki/Wayback_Machine) (by the [Internet Archive](https://en.wikipedia.org/wiki/Internet_Archive)) or [Archive.today](https://en.wikipedia.org/wiki/Archive.today). The [Docker](https://en.wikipedia.org/wiki/Docker_%28software%29) registry image repository is an [HTTP](https://en.wikipedia.org/wiki/Hypertext_Transfer_Protocol) public service that has centralized storage, is application stateless, and is [node](https://en.wikipedia.org/wiki/Node_%28networking%29) scalable; the service has a performance bottleneck in the scenario of multinational uploading and downloading. The decentralized Docker registry (DDR) avoids this disadvantage of centralization. DDR uses a [network-structured](https://en.wikipedia.org/wiki/Telecommunications_network) [P2P network](https://en.wikipedia.org/wiki/P2P_network) to store and query the mirror [manifest file](https://en.wikipedia.org/wiki/Manifest_file) and blob routing; each node serves as an independent mirror repository to provide mirror uploading and downloading for the entire network.[^o16][^o17][^o18]
- *RSS aggregators*: [RSS](https://en.wikipedia.org/wiki/RSS) aggregators such as [Feedly](https://en.wikipedia.org/wiki/Feedly) may be able to receive and then forward RSS feeds that are blocked if accessed directly.[^o19]

### Alternative platforms {#Alternative_platforms}

Alternative types of Internet hosting platform can provide options for circumventing Internet censorship. Such alternatives include decentralized hosting, anonymity networks, federated platforms, providers with different policies, and [darknets](https://en.wikipedia.org/wiki/Darknet#Active):

- *Decentralized hosting*: Content creators may publish to an alternative platform that is willing to host this content. [Napster](https://en.wikipedia.org/wiki/Napster) was the earliest [peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) (P2P) platform, but it was closed because of vulnerabilities with centralized [bootstrapping](https://en.wikipedia.org/wiki/Bootstrapping). [Gnutella](https://en.wikipedia.org/wiki/Gnutella) was the first sustainable P2P platform that featured hosting by decentralization. The motto of the [Freenet](https://en.wikipedia.org/wiki/Freenet) P2P platform is that "true freedom requires true anonymity." Later, the [BitTorrent](https://en.wikipedia.org/wiki/BitTorrent) P2P protocol was developed to allocate resources with high performance and fairness.[^o21] [ZeroNet](wikipedia://en/47795787) P2P web hosting was the first [distributed hash table](https://en.wikipedia.org/wiki/Distributed_hash_table) (DHT) system to support dynamic and updatable webpages. The [YaCy](https://en.wikipedia.org/wiki/YaCy) P2P search engine is the leading distributed search. [GNUnet](wikipedia://en/293685) is rebuilding the internet framework from the ground up for resilience technologically idealized.
- *Anonymity networks*: The [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29#Onion_services) and [Invisible Internet Project](wikipedia://en/538434) (I2P) networks result in increased willingness to host content that would otherwise be censored. However, hosting implementation and server location may cause challenges, and the content is still hosted by a single entity that can be controlled.
- *Federated*: Semi-decentralized, federated platforms such as [Nextcloud](https://en.wikipedia.org/wiki/Nextcloud) and [PeerTube](https://en.wikipedia.org/wiki/PeerTube) make it easier for users to find an instance where they are welcome.
- *Providers with different policies*: Some platforms that rely on [cloud computing](https://en.wikipedia.org/wiki/Cloud_computing) may have laxer [terms of service](https://en.wikipedia.org/wiki/Terms_of_service) (TOS). However, cloud computing does not, in principle, innovate fundamental laxness.

### Proxying {#Proxying}

A variety of techniques support a user in leveraging technical proxies to circumvent Internet censorship:

- *Web proxy server*: A Web [proxy server](https://en.wikipedia.org/wiki/Proxy_server) (or web proxy) allows users to load external web pages through a server that makes and receives requests on behalf of the user, rather than directly from the blocked original server (or source).[^o19] Depending on how a proxy is configured, a censor may be able to determine if a user is accessing the proxy, and if so, which pages the user loads.[^o10]
  - *Example*: The mobile [Opera Mini](https://en.wikipedia.org/wiki/Opera_Mini) browser uses proxies that employ encryption and compression to accelerate downloads. This process has the side effect of circumventing several approaches to Internet censorship. In 2009, this situation led the Chinese government to ban all versions of the Opera Mini browser except for a special Chinese version.[^o23]
- *Domain fronting*: [Domain fronting](https://en.wikipedia.org/wiki/Domain_fronting) hides the destination of a network connection by passing initial requests through a [content delivery network](https://en.wikipedia.org/wiki/Content_delivery_network) or other popular site that censors may be unwilling to block.[^o24] This technique was used by messaging applications such as [Signal](wikipedia://en/45210316) and [Telegram](wikipedia://en/41501305). Similarly, Tor's `meek` system uses [Microsoft's Azure cloud.](https://en.wikipedia.org/wiki/Microsoft_Azure) However, large cloud providers such as [Amazon Web Services](https://en.wikipedia.org/wiki/Amazon_Web_Services) and [Google Cloud](https://en.wikipedia.org/wiki/Google_Cloud_Platform) no longer support `meek`.[^o25] As another option, a website owner can create a free account to use a [Cloudflare](https://en.wikipedia.org/wiki/Cloudflare) domain for fronting.[^o26][^o27]
- *Tunneling protocol*: By employing a [tunneling protocol](https://en.wikipedia.org/wiki/Tunneling_protocol) such as [Secure Shell](wikipedia://en/28814) (SSH), a user can forward all of their traffic over an encrypted channel; as a result, both outgoing requests to blocked sites and incoming responses from those sites are hidden from censors, for whom it appears as unreadable SSH traffic.[^o28]
- *Virtual private network (VPN)*: Through a [virtual private network](wikipedia://en/147130) (VPN), a user can create secure connections to more permissive countries, letting users browse as if they were located in one of those countries.[^o9] Some VPN services are offered for a monthly fee; others are supported by advertising. According to [GWI](https://en.wikipedia.org/wiki/GlobalWebIndex), an audience research company, there were more than 400 million people using VPNs to circumvent censorship or obtain increased privacy in 2014 (although this number cannot be verified).[^o50]
- *Tor anonymity network*: A more advanced tool such as the [Tor anonymity network](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29) routes encrypted traffic through multiple servers to make the source and destination of this traffic less traceable. In some cases, Tor can be used to avoid censorship, especially when it is configured to use traffic obfuscation techniques.[^o29]

### Traffic obfuscation {#Traffic_obfuscation}

A censor may be able to detect and block the use of circumvention tools through [deep packet inspection](https://en.wikipedia.org/wiki/Deep_packet_inspection).[^o31] Ongoing work aims to make circumvention tools less detectable in several ways: randomizing the traffic; attempting to mimic a whitelisted protocol; or tunneling traffic through a whitelisted site by using domain fronting or Tor's `meek` system.[^o29] Tor and other circumvention tools have adopted multiple obfuscation techniques that users can employ, depending on the nature of their network connection; these techniques are sometimes called *pluggable transports*.[^o32]

## Internet alternatives {#Internet_alternatives}

Functionality desired by users may overlap with that of services that are not based on the Internet, such as postal [mail](https://en.wikipedia.org/wiki/Mail), [Bluetooth](https://en.wikipedia.org/wiki/Bluetooth)-based data exchange, or [walkie-talkie](https://en.wikipedia.org/wiki/Walkie-talkie) devices. The following are some detailed examples:

- *Alternative data transport*: [Datacasting](https://en.wikipedia.org/wiki/Datacasting) allows transmission of Web pages and other information via satellite broadcast channels, bypassing the Internet entirely. This process requires a satellite dish and suitable receiver hardware, but it provides a powerful means of avoiding censorship. Because the user only receives data through this process but transmits no data, a suitably [air-gapped](https://en.wikipedia.org/wiki/Air_gap_%28networking%29) computer can be impossible to detect.[^o35]
- *Sneakernets*: A [sneakernet](https://en.wikipedia.org/wiki/Sneakernet) is the transfer of electronic information, especially computer files, by physically carrying data on [storage media](wikipedia://en/28174) from one place to another. A sneakernet can move data regardless of network restrictions, simply by avoiding the network entirely.[^o36] One example of a widely adopted sneakernet is [El Paquete Semanal](https://en.wikipedia.org/wiki/El_Paquete_Semanal), an underground content market in Cuba.[^o37]

## Adoption of tools {#Adoption_of_tools}

Circumvention tools have undergone spikes in adoption rates in response to high-profile attempts to block the Internet.[^o39][^o40][^o41] Nevertheless, mixed results have been reported by studies that measure the adoption of circumvention tools in countries with persistent and widespread censorship.[^o42] Knowledge of and comfort with using censorship circumvention tools varies widely and depends on factors such as the local censorship environment, public awareness of circumvention alternatives, language accessibility, usability, and legal risks.[^o43][^o44][^o45] Such tools can include VPNs, international [SIM cards](https://en.wikipedia.org/wiki/SIM_card), [Short Message Service](https://en.wikipedia.org/wiki/SMS) (SMS), Bluetooth-based communication apps, and [mesh networking](https://en.wikipedia.org/wiki/Mesh_networking) applications.[^o46] In some contexts, individuals may be aware of circumvention tools but reluctant to use them due to the risk of severe legal penalties.[^o45]

### In response to persistent censorship {#In_response_to_persistent_censorship}

Measures and estimates of circumvention tool adoption have varied widely. A 2010 study by Harvard University estimated that few users employ tools for censorship circumvention—likely less than 3% of users, even in countries that consistently implement widespread censorship.[^o42] Other studies have reported substantially larger rates, but these have been disputed.[^o3][^o4]

In China, anecdotal reports suggest that adoption of circumvention tools is particularly high in certain communities, such as universities; a survey by the research institute [Freedom House](https://en.wikipedia.org/wiki/Freedom_House) found that users generally did not find circumvention tools to be difficult to use.[^o48][^o49][^o9] Market research firm [GlobalWebIndex](https://en.wikipedia.org/wiki/GlobalWebIndex) reported more than 35 million Twitter users and 63 million Facebook users in China (where both services are blocked).[^o3] However, these estimates have been disputed;[^o50] Facebook's advertising platform estimates 1 million users in China,[^o4] and other reports of Twitter adoption estimate 10 million users.[^o51] Other studies have found that efforts to block circumvention tools in China have reduced adoption of those tools; the Tor network previously had more than 30,000 users connecting from China, but as of 2014, the network had only about 3,000 Chinese users.[^o52]

A 2013 study of 1,175 Chinese Internet users found that participants primarily circumvented censorship to access search engines, social media platforms, and blocked news sources. The study reported that users tended to rely on services that were easy to use and economically costly for authorities to block. For example, the most widely used tool operated through Google’s cloud hosting infrastructure, which also supported a range of other services. A smaller subset of users, consisting mainly of journalists and activists, cited privacy as their primary motivation for using a tool.[^o53]

In [Thailand](https://en.wikipedia.org/wiki/Internet_censorship_in_Thailand), Internet censorship has occurred since 2002, through sporadic and inconsistent filtering.[^o54] In a small-scale survey of 229 Thai Internet users, a research group at the University of Washington found that 63% of surveyed users attempted to use circumvention tools, and 90% were successful in using those tools. Users often made on-the-spot decisions about the use of circumvention tools on the basis of limited or unreliable information; these users had a variety of perceived threats, some more abstract and others based on personal experience.[^o55]

### In response to blocking events {#In_response_to_blocking_events}

In response to the blocking of Twitter in [Turkey](https://en.wikipedia.org/wiki/Turkey) during 2014, information about alternate [DNS servers](https://en.wikipedia.org/wiki/Dns_server) was widely shared, since using another DNS server (such as [Google Public DNS](https://en.wikipedia.org/wiki/Google_Public_DNS)) allowed users to access Twitter.[^o57] The day after the block was imposed, the total number of posts made in Turkey had increased by 138%, according to [Brandwatch](https://en.wikipedia.org/wiki/Brandwatch), an Internet measurement firm.[^o39]

After the ban on the [Telegram](wikipedia://en/41501305) messaging app in Iran during April 2018, web searches for VPN and other circumvention software increased by as much as 48 times for some search terms, but there was evidence that users were downloading unsafe software. As many as a third of Iranian Internet users used the [Psiphon](https://en.wikipedia.org/wiki/Psiphon) tool in the days immediately following the block; in June 2018, as many as 3.5 million Iranian users continued to use the tool.[^o40]

## Anonymity, risks, and trust {#Anonymity,_risks,_and_trust}

Systems for circumvention and [anonymity](https://en.wikipedia.org/wiki/Anonymity) are different. Circumvention systems are designed to bypass Internet blocking, but they do not usually protect user identities. Anonymous systems protect a user's identity, but while they can contribute to censorship circumvention, this is not their primary function. Public proxy sites do not provide anonymity, since they can view and record the location of computers making requests, in addition to the websites accessed.[^o19]

In many jurisdictions, accessing blocked content is a serious [crime](https://en.wikipedia.org/wiki/Crime), particularly for content that is considered to be [child pornography](https://en.wikipedia.org/wiki/Child_pornography), a threat to [national security](https://en.wikipedia.org/wiki/National_security), or an incitement to violence. For this reason, it is important to understand circumvention technologies—and the protections that they do (or do not) provide—and to use only tools that are appropriate in a particular context. Significant care must be taken to install, configure, and use circumvention tools properly. People associated with [dissident](https://en.wikipedia.org/wiki/Dissident), protest, or reform groups, or high-profile rights organizations, should take extra precautions to protect their online identities.[^o19]

Circumvention sites and tools should be provided and operated by trusted third parties, located outside the censoring jurisdiction, who do not collect identities and other personal information. Trusted family and friends known personally by the circumventor are best; but when family and friends are unavailable, sites and tools provided by individuals or organizations that are known only by their reputations, or through recommendations and endorsements by other people, may need to be used. Commercial circumvention services may provide anonymity during Internet surfing, but these services could be legally compelled to make their records and users' personal information available to law enforcement authorities.[^o19]

## Software {#Software}

There are five general types of software for circumventing Internet censorship:

- *[CGI proxies](https://en.wikipedia.org/wiki/Proxy_server)*: A [Common Gateway Interface](https://en.wikipedia.org/wiki/Common_Gateway_Interface) (CGI) proxy server uses a script running on a [web server](https://en.wikipedia.org/wiki/Web_server) to provide proxying functionality. A CGI proxy client (typically the user's computer) sends a requested web address or [URL](https://en.wikipedia.org/wiki/URL), embedded within the data of [HTTP](https://en.wikipedia.org/wiki/HTTP) protocol requests, to the CGI proxy server. The CGI proxy server sends its own HTTP request to the ultimate destination server, and then the proxy server returns the result to the proxy client. A CGI proxy tool's security can be trusted to the extent that the operator of the proxy server is trustworthy. CGI proxy tools do not require a user to manually configure a web browser or install client software, but they do require the user to use an alternative, potentially confusing user interface within the existing web browser.
- *[HTTP proxies](https://en.wikipedia.org/wiki/Proxy_server)*: HTTP proxies send HTTP requests through an intermediate proxying server. When a client (typically the user's computer) is connecting through an HTTP proxy, this client sends exactly the same HTTP request to the proxy as it would send to the destination server if unproxied. The HTTP proxy parses the HTTP request; this proxy sends its own HTTP request to the ultimate destination server; and then the proxy server returns the response back to the proxy client. An HTTP proxy tool's security can be trusted to the extent that the operator of the proxy server is trustworthy. To employ an HTTP proxy tool, a user must either manually configure the web browser or install client-side software that performs this configuration. Once configured, an HTTP proxy tool allows the user to transparently use their browser's normal user interface.
- *Application proxies*: Application proxies are similar to HTTP proxies but support a wider range of online applications.
- *[Peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) systems*: Peer-to-peer systems store content across a number of participating volunteer servers; this storage is combined with techniques such as rerouting, to reduce the level of reliance placed on volunteer servers or social networks to establish trust relationships between servers and clients. A peer-to-peer system can be trusted to the extent that the operators of participating servers are trustworthy, or that its architecture limits the information available to any single server—provided that server operators do not collude to combine their knowledge.
- *Rerouting systems*: Rerouting systems send requests and responses through a series of proxying servers, re-encrypting the data at each proxy, so that a given proxy knows at most either the source or the destination of the data, but not both. This approach decreases the amount of trust required of the individual proxy hosts.
