# Dynamic lot-size model

::: {#o1 .subject cue=lead name="Dynamic lot-size model"}

The **dynamic lot-size model** in [inventory theory](wikipedia://en/21749554), is a generalization of the [economic order quantity](wikipedia://en/849762) model that takes into account that demand for the product varies over time. The model was introduced by [Harvey M. Wagner](https://en.wikipedia.org/wiki/Harvey_M._Wagner) and [Thomson M. Whitin](https://en.wikipedia.org/wiki/Thomson_M._Whitin) in 1958.[^o2][^o3]

:::

## Problem setup {#Problem_setup}

We have available a [forecast of product demand](wikipedia://en/17873973) $d_{t}$ over a relevant time horizon t=1,2,...,N (for example we might know how many [widgets](https://en.wikipedia.org/wiki/Widget_%28economics%29) will be needed each week for the next 52 weeks). There is a [setup cost](https://en.wikipedia.org/wiki/Setup_cost) $s_{t}$ incurred for each order and there is an inventory [holding cost](https://en.wikipedia.org/wiki/Holding_cost) $i_{t}$ per item per period ($s_{t}$ and $i_{t}$ can also vary with time if desired). The problem is how many units $x_{t}$ to order now to minimize the sum of setup cost and inventory cost. Let us denote [inventory](https://en.wikipedia.org/wiki/Inventory):

$$I=I_{0}+\sum_{j=1}^{t-1}x_{j}-\sum_{j=1}^{t-1}d_{j}\geq0$$

The functional equation representing minimal cost policy is:

$$f_{t}(I)=\underset{x_{t}\geq 0 \atop I+x_{t}\geq d_{t}}{\min}\left[ i_{t-1}I+H(x_{t})s_{t}+f_{t+1}\left( I+x_{t}-d_{t} \right) \right]$$

Where H() is the [Heaviside step function](wikipedia://en/87299). Wagner and Whitin[^o2] proved the following four theorems:

- There exists an optimal program such that I$x_{t}$=0; ∀t
- There exists an optimal program such that ∀t: either $x_{t}$=0 or $x_{t}=\textstyle \sum_{j=t}^{k} d_{j}$ for some k (t≤k≤N)
- There exists an optimal program such that if $d_{t*}$ is satisfied by some $x_{t**}$, t\*\*\<t\*, then $d_{t}$, t=t\*\*+1,...,t\*-1, is also satisfied by $x_{t**}$
- Given that I = 0 for period t, it is optimal to consider periods 1 through t - 1 by themselves

::: {#o6 .statement kind=statement/theorem cue=named-heading name="Planning Horizon Theorem"}

## Planning Horizon Theorem {#Planning_Horizon_Theorem}

The precedent theorems are used in the proof of the Planning Horizon Theorem.[^o2] Let

$$F(t)= \min\left[ {\underset{1\leq j < t}{\min}\left[ s_{j}+ \sum_{h=j}^{t-1}\sum_{k=h+1}^{t}i_{h}d_{k}+F(j-1) \right] \atop s_{t}+F(t-1)} \right]$$

denote the minimal cost program for periods 1 to t. If at period t\* the minimum in F(t) occurs for j = t\*\* ≤ t\*, then in periods t > t\* it is sufficient to consider only t\*\* ≤ j ≤ t. In particular, if t\* = t\*\*, then it is sufficient to consider programs such that $x_{t*}$ > 0.

:::

::: {#o8 .definition kind=definition/construction cue=heading name="The algorithm"}

## The algorithm {#The_algorithm}

Wagner and Whitin gave an [algorithm](wikipedia://en/775) for finding the optimal solution by [dynamic programming](wikipedia://en/125297).[^o2] Start with t\*=1:

1. Consider the policies of ordering at period t\*\*, t\*\* = 1, 2, ... , t\*, and filling demands $d_{t}$ , t = t\*\*, t\*\* + 1, ... , t\*, by this order
1. Add H($x_{t**}$)$s_{t**}$+$i_{t**}$$I_{t**}$ to the costs of acting optimally for periods 1 to t\*\*-1 determined in the previous iteration of the algorithm
1. From these t\* alternatives, select the minimum cost policy for periods 1 through t\*
1. Proceed to period t\*+1 (or stop if t\*=N)

Because this method was perceived by some as [too complex](wikipedia://en/7543), a number of authors also developed approximate [heuristics](https://en.wikipedia.org/wiki/Heuristics) (e.g., the [Silver-Meal heuristic](https://en.wikipedia.org/wiki/Silver-Meal_heuristic)[^o9]) for the problem.

:::
