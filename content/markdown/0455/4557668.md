# Essentially surjective functor

::: {#o1 .subject cue=lead name="Essentially surjective functor"}

In [mathematics](wikipedia://en/18831), specifically in [category theory](wikipedia://en/5869), a [functor](wikipedia://en/10987)

:::

$$F:C\to D$$

is **essentially surjective** if each object $d$ of $D$ is isomorphic to an object of the form $Fc$ for some object $c$ of $C$.

Any functor that is part of an [equivalence of categories](wikipedia://en/379051) is essentially surjective. As a partial converse, any [full and faithful functor](https://en.wikipedia.org/wiki/Full_and_faithful_functor) that is essentially surjective is part of an equivalence of categories.[^o2]
