# Constrained least squares

::: {#o1 .subject cue=lead name="Constrained least squares"}

In **constrained least squares** one solves a [linear least squares](https://en.wikipedia.org/wiki/Linear_least_squares_%28mathematics%29) problem with an additional [constraint](wikipedia://en/7418540) on the solution.[^o2][^o3] This means, the unconstrained equation $\mathbf {X} \boldsymbol {\beta} = \mathbf {y}$ must be fit as closely as possible (in the least squares sense) while ensuring that some other property of $\boldsymbol {\beta}$ is maintained.

:::

There are often special-purpose algorithms for solving such problems efficiently. Some examples of constraints are given below:

- [Equality constrained](wikipedia://en/16817400) least squares: the elements of $\boldsymbol {\beta}$ must exactly satisfy $\mathbf {L} \boldsymbol {\beta} = \mathbf {d}$ (see [Ordinary least squares](wikipedia://en/1651906#Constrained_estimation)).
- Stochastic (linearly) constrained least squares: the elements of $\boldsymbol {\beta}$ must satisfy $\mathbf {L} \boldsymbol {\beta} = \mathbf {d} + \mathbf {\nu}$, where $\mathbf {\nu}$ is a vector of random variables such that $\operatorname{E}(\mathbf {\nu}) = \mathbf{0}$ and $\operatorname{E}(\mathbf {\nu} \mathbf {\nu}^{\rm T}) = \tau^{2}\mathbf{I}$. This effectively imposes a [prior distribution](https://en.wikipedia.org/wiki/Prior_distribution) for $\boldsymbol {\beta}$ and is therefore equivalent to [Bayesian linear regression](wikipedia://en/7519917).[^o4]
- [Regularized](https://en.wikipedia.org/wiki/Tikhonov_regularization) least squares: the elements of $\boldsymbol {\beta}$ must satisfy $\| \mathbf {L} \boldsymbol {\beta} - \mathbf {y} \| \le \alpha$ (choosing $\alpha$ in proportion to the noise [standard deviation](wikipedia://en/27590) of **y** prevents over-fitting).
- The special case of equality with known standard deviation corresponds to the **Discrepancy Principle** for automatic regularization.
- [Non-negative least squares](wikipedia://en/41740999) (NNLS): The vector $\boldsymbol {\beta}$ must satisfy the [vector inequality](wikipedia://en/8099221) $\boldsymbol {\beta} \geq \boldsymbol{0}$ defined componentwise—that is, each component must be either positive or zero.
- Box-constrained least squares: The vector $\boldsymbol {\beta}$ must satisfy the [vector inequalities](wikipedia://en/8099221) $\boldsymbol{b}_\ell \leq \boldsymbol{\beta} \leq \boldsymbol{b}_u$, each of which is defined componentwise.
- Integer-constrained least squares: all elements of $\boldsymbol {\beta}$ must be [integers](wikipedia://en/14563) (instead of [real numbers](wikipedia://en/20646438)).
- Phase-constrained least squares: all elements of $\boldsymbol {\beta}$ must be real numbers, or multiplied by the same complex number of unit modulus.

If the constraint only applies to some of the variables, the mixed problem may be solved using **separable least squares**[^o5] by letting $\mathbf {X} = [\mathbf {X_1} \mathbf {X_2} ]$ and $\mathbf {\beta}^{\rm T} = [\mathbf {\beta_1}^{\rm T} \mathbf {\beta_2}^{\rm T}]$ represent the unconstrained (1) and constrained (2) components. Then substituting the least-squares solution for $\mathbf {\beta_1}$, i.e.

$$\hat{\boldsymbol {\beta}}_1 = \mathbf {X}_1^+ (\mathbf {y} - \mathbf {X}_2 \boldsymbol {\beta}_2)$$

(where <sup>\+</sup> indicates the [Moore–Penrose pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse)) back into the original expression gives (following some rearrangement) an equation that can be solved as a purely constrained problem in $\mathbf {\beta}_2$.

$$\mathbf{P} \mathbf {X}_2 \boldsymbol {\beta}_2 = \mathbf{P}\mathbf {y},$$

where $\mathbf{P}:=\mathbf{I}-\mathbf {X}_1 \mathbf {X}_1^+$ is a [projection matrix](wikipedia://en/15180479). Following the constrained estimation of $\hat{\boldsymbol \beta}_2$ the vector $\hat{\boldsymbol {\beta}}_1$ is obtained from the expression above.
