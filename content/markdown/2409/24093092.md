# Gomory–Hu tree

::: {#o1 .subject cue=lead name="Gomory–Hu tree"}

In [combinatorial optimization](wikipedia://en/420555), the **Gomory–Hu tree**[^o2] of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) with capacities is a weighted [tree](wikipedia://en/48560) that represents the minimum [*s*-*t* cuts](wikipedia://en/2180494) for all *s*-*t* pairs in the graph. The Gomory–Hu tree can be constructed in $\lvert V\rvert - 1$ [maximum flow](wikipedia://en/403165) computations. It is named for [Ralph E. Gomory](https://en.wikipedia.org/wiki/Ralph_E._Gomory) and [T. C. Hu](https://en.wikipedia.org/wiki/T._C._Hu).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G = (V_G, E_G, c)$ be an undirected graph with $c(u,v)$ being the capacity of the edge $(u,v)$ respectively.

Denote the minimum capacity of an $s$-$t$ cut by $\lambda_{st}$ for each $s, t \in V_G$.

Let $T = (V_G, E_T)$ be a tree, and denote the set of edges in an $s$-$t$ path by $P_{st}$ for each $s,t \in V_G$.

Then $T$ is said to be a **Gomory–Hu tree** of $G$, if for each $s, t \in V_G$

$$\lambda_{st} = \min_{e\in P_{st}} c(S_e, T_e),$$

where

1. $S_e, T_e \subseteq V_G$ are the two connected components of $T \setminus \{e\}$, and thus $(S_e, T_e)$ forms an $s$-$t$ cut in $G$.
1. $c(S_e, T_e)$ is the capacity of the $(S_e,T_e)$ cut in $G$.

:::

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

**Gomory–Hu Algorithm**

*Input*: A weighted undirected graph $G = ((V_G,E_G), c)$

*Output*: A Gomory–Hu Tree $T = (V_T, E_T).$

1. Set $V_T = \{V_G\}, \ E_T = \emptyset.$
1. Choose some $X \in V_T$ with $\lvert X\rvert \ge 2$ if such $X$ exists. Otherwise, go to step 6.
1. For each connected component $C = (V_C,E_C) \in T \setminus X,$ let $S_C = \bigcup_{v_T \in V_C} v_T.$

Let $S = \{ S_C \mid C \text{ is a connected component in } T \setminus X \}.$

Contract the components to form $G' = ((V_{G'}, E_{G'}), c'),$ where:

$$\begin{aligned} V_{G'} &= X \cup S \\[2pt] E_{G'} &= E_G|_{X \times X} \cup \{(u, S_C) \in X \times S \mid (u,v) \in E_G \text{ for some } v \in S_C \} \\[2pt] & \qquad \qquad \quad\! \cup \{(S_{C1}, S_{C2}) \in S \times S \mid (u,v) \in E_G \text{ for some } u \in S_{C1} \text{ and } v \in S_{C2} \} \end{aligned}$$

$c':V_{G'} \times V_{G'} \to R^+$ is the capacity function, defined as:

$$\begin{aligned} &\text{if }\ (u,S_C) \in E_G|_{X \times S}: &&c'(u,S_C) = \!\!\! \sum_{\begin{smallmatrix} v \in S_C : \\ (u,v) \in E_G \end{smallmatrix}} \!\!\! c(u,v) \\[4pt] &\text{if }\ (S_{C1},S_{C2}) \in E_G|_{S \times S}: &&c'(S_{C1},S_{C2}) = \!\!\!\!\!\!\! \sum_{\begin{smallmatrix} (u,v) \in E_G : \\ u \in S_{C1} \, \land \, v \in S_{C2} \end{smallmatrix}} \!\!\!\!\! c(u,v) \\[4pt] &\text{otherwise}: &&c'(u,v) = c(u,v) \end{aligned}$$

1. Choose two vertices $s, t \in X$ and find a minimum $s-t$ cut $(A', B')$ in $G'$.

Set $A = \Biggl(\bigcup_{S_C \in A' \cap S} \!\!\! S_C \! \Biggr) \cup (A' \cap X),\$$B = \Biggl(\bigcup_{S_C \in B' \cap S} \!\!\! S_C \! \Biggr) \cup (B' \cap X).$

1. Set $V_T = (V_T \setminus X) \cup \{A \cap X, B \cap X \}.$

For each $e = (X, Y) \in E_T$ do:

   1. Set $e' = (A \cap X,Y)$ if $Y \subset A,$ otherwise set $e' = (B \cap X,Y).$
   1. Set $E_T = (E_T \setminus \{e\}) \cup \{e'\}.$
   1. Set $w(e') = w(e).$

Set $E_T = E_T \cup \{(A \cap X,\ B \cap X) \}.$

Set $w((A \cap X, B \cap X)) = c'(A', B').$

Go to step 2.

1. Replace each $\{v\} \in V_T$ by $v$ and each $(\{u\},\{v\}) \in E_T$ by $(u, v)$. Output $T$.

:::

## Analysis {#Analysis}

Using the [submodular](https://en.wikipedia.org/wiki/Submodular) property of the capacity function $c$, one has

$$c(X) + c(Y) \ge c(X \cap Y) + c(X \cup Y).$$

Then it can be shown that the minimum $s-t$ cut in $G'$ is also a minimum $s-t$ cut in $G$ for any $s, t \in X$.

To show that for all $(P,Q) \in E_T,$ $w(P,Q) = \lambda_{pq}$ for some $p \in P$, $q \in Q$ throughout the algorithm, one makes use of the following lemma,

For any $i, j, k$ in $V_{G}$, $\lambda_{ik} \ge \min(\lambda_{ij}, \lambda_{jk}).$

The lemma can be used again repeatedly to show that the output $T$ satisfies the properties of a Gomory–Hu Tree.

## Implementations: Sequential and Parallel {#Implementations:_Sequential_and_Parallel}

Gusfield's algorithm can be used to find a Gomory–Hu tree without any vertex contraction in the same [running time-complexity](wikipedia://en/405944), which simplifies the implementation of constructing a Gomory–Hu Tree.[^o12]

[Andrew V. Goldberg](https://en.wikipedia.org/wiki/Andrew_V._Goldberg) and K. Tsioutsiouliklis implemented the Gomory-Hu algorithm and Gusfield algorithm, and performed an experimental evaluation and comparison.[^o13]

Cohen et al. report results on two parallel implementations of Gusfield's algorithm using OpenMP and MPI, respectively.[^o14]

## Related concepts {#Related_concepts}

In [planar graphs](wikipedia://en/24314), the Gomory–Hu tree is dual to the minimum weight [cycle basis](wikipedia://en/24778911), in the sense that the cuts of the Gomory–Hu tree are dual to a collection of cycles in the [dual graph](wikipedia://en/2536864) that form a minimum-weight cycle basis.[^o16]
