# Analytic polyhedron

::: {#o1 .subject cue=lead name="Analytic polyhedron"}

In [mathematics](wikipedia://en/18831), especially [several complex variables](wikipedia://en/360243), an **analytic polyhedron** is a subset of the [complex space](wikipedia://en/39125683) $\mathbf{C}^{n}$ of the form

:::

$$P = \{ z \in D : |f_j(z)| < 1, \;\; 1 \le j \le N \}$$

where $D$ is a bounded connected open subset of $\mathbf{C}^{n}$, $f_j$ are [holomorphic](wikipedia://en/14110) on $D$ and $P$ is assumed to be [relatively compact](https://en.wikipedia.org/wiki/Relatively_compact) in $D$.[^o2] If $f_j$ above are polynomials, then the set is called a **polynomial polyhedron**. Every analytic polyhedron is a [domain of holomorphy](wikipedia://en/3236377) and it is thus [pseudo-convex](https://en.wikipedia.org/wiki/Pseudoconvex_set).

The boundary of an analytic polyhedron is contained in the union of the set of hypersurfaces

$$\sigma_j = \{ z \in D : |f_j(z)| = 1 \}, \; 1 \le j \le N.$$

An analytic polyhedron is a *Weil polyhedron*, or [Weil domain](https://en.wikipedia.org/wiki/Weil_domain) if the intersection of any $k$ of the above hypersurfaces has dimension no greater than $2n-k$.[^o3]
