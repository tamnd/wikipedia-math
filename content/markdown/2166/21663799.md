# Behnke–Stein theorem

::: {#o1 .subject cue=lead name="Behnke–Stein theorem"}

Behnke–Stein theorem on Stein manifolds In mathematics, especially [several complex variables](wikipedia://en/360243), the **Behnke–Stein theorem** states that a union of an increasing sequence $G_k \subset \mathbb{C}^n$ (i.e., $G_k \subset G_{k + 1}$) of [domains of holomorphy](wikipedia://en/3236377) is again a domain of holomorphy. It was proved by [Heinrich Behnke](wikipedia://en/22922678) and [Karl Stein](wikipedia://en/7218529) in 1938.[^o2]

:::

This is related to the fact that an increasing union of [pseudoconvex domains](https://en.wikipedia.org/wiki/Pseudoconvex_domain) is pseudoconvex and so it can be proven using that fact and the solution of the [Levi problem](https://en.wikipedia.org/wiki/Levi_problem). Though historically this theorem was in fact used to solve the Levi problem, and the theorem itself was proved using the [Oka–Weil theorem](wikipedia://en/66786706). This theorem again holds for Stein manifolds, but it is not known if it holds for Stein space.[^o3]
