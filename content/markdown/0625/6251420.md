# Non-standard model of arithmetic

::: {#o1 .subject cue=lead name="Non-standard model of arithmetic"}

In [mathematical logic](wikipedia://en/19636), a **non-standard model of arithmetic** is a model of [first-order Peano arithmetic](wikipedia://en/25005#Peano_arithmetic_as_first-order_theory) that contains non-standard numbers. The term **standard model of arithmetic** refers to the standard [natural numbers](wikipedia://en/21474) 0, 1, 2, …. The elements of any model of Peano arithmetic are [linearly ordered](https://en.wikipedia.org/wiki/Linearly_ordered) and possess an [initial segment](https://en.wikipedia.org/wiki/Initial_segment) [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the standard natural numbers. A non-standard model is one that has additional elements outside this initial segment. The construction of such models is due to [Thoralf Skolem](wikipedia://en/453765) (1934).

:::

Non-standard models of arithmetic exist only for the first-order formulation of the [Peano axioms](wikipedia://en/25005); for the original [second-order](wikipedia://en/341428) formulation, there is, up to isomorphism, only one model: the natural numbers themselves.[^n1]

## Existence {#Existence}

There are several methods that can be used to prove the existence of non-standard models of arithmetic.

::: {#o5 .statement kind=statement/theorem cue=named-heading name="From the compactness theorem"}

### From the compactness theorem {#From_the_compactness_theorem}

The existence of non-standard models of arithmetic can be demonstrated by an application of the [compactness theorem](wikipedia://en/152207). To do this, a set of axioms *P*\* is defined in a language including the language of Peano arithmetic together with a new constant symbol *c*. The axioms consist of the axioms of Peano arithmetic *P* together with another infinite set of axioms: for each standard natural number *n*, the axiom *c* > *n* is included. Any finite subset of these axioms is satisfied by a model consisting of the standard model of arithmetic plus the constant *c* interpreted as some number larger than any numeral mentioned in the finite subset of *P*\*. Thus by the compactness theorem there is a model satisfying all the axioms *P*\*. Since any model of *P*\* is a model of *P* (since a model of a set of axioms is obviously also a model of any subset of that set of axioms), we have that our extended model is also a model of the Peano axioms. The element of this model corresponding to *c* cannot be a standard number, because as indicated it is larger than any standard number.

Using more complex methods, it is possible to build non-standard models that possess more complicated properties. For example, there are models of Peano arithmetic in which [Goodstein's theorem](wikipedia://en/150062) fails. It can be proved in [Zermelo–Fraenkel set theory](wikipedia://en/152214) that Goodstein's theorem holds in the standard model, so a model where Goodstein's theorem fails must be non-standard.

:::

::: {#o7 .statement kind=statement/theorem cue=named-heading name="From the incompleteness theorems"}

### From the incompleteness theorems {#From_the_incompleteness_theorems}

[Gödel's incompleteness theorems](wikipedia://en/58863) also imply the existence of non-standard models of arithmetic. The incompleteness theorems show that a particular sentence *G*, the Gödel sentence of Peano arithmetic, is neither provable nor disprovable in Peano arithmetic. By the [completeness theorem](wikipedia://en/12450), this means that *G* is false in some model of Peano arithmetic. However, *G* is true in the standard model of arithmetic, and therefore any model in which *G* is false must be a non-standard model. Thus satisfying ~*G* is a sufficient condition for a model to be nonstandard. It is not a necessary condition, however; for any Gödel sentence *G* and any infinite [cardinality](wikipedia://en/6174) there is a model of arithmetic with *G* true and of that cardinality.

#### Arithmetic unsoundness for models with ~*G* true {#Arithmetic_unsoundness_for_models_with_~G_true}

Assuming that arithmetic is consistent, arithmetic with ~*G* is also consistent. However, since ~*G* states that arithmetic is inconsistent, arithmetic with ~*G* will not be [ω-consistent](https://en.wikipedia.org/wiki/Ω-consistent) (because ~*G* is false and this violates ω-consistency).

:::

### From an ultraproduct {#From_an_ultraproduct}

Another method for constructing a non-standard model of arithmetic is via an [ultraproduct](wikipedia://en/273642). A typical construction uses the set of all sequences of natural numbers, $\mathbb{N}^{\mathbb{N}}$. Choose a [free ultrafilter](wikipedia://en/67416519) on $\mathbb{N}$, then identify two sequences whenever they have equal values on positions that form a member of the ultrafilter (this requires that they agree on infinitely many positions, but the condition is stronger than this as ultrafilters resemble axiom-of-choice-like maximal extensions of the [Fréchet filter](wikipedia://en/1586291)). The resulting [semiring](wikipedia://en/371468) is a non-standard model of arithmetic. It can be identified with the [hypernatural](https://en.wikipedia.org/wiki/Hypernatural) numbers.[^n2]

## Structure of countable non-standard models {#Structure_of_countable_non-standard_models}

The [ultraproduct](wikipedia://en/273642) models are uncountable. One way to see this is to construct an injection from the infinite product $\mathbb{N}^\mathbb{N}$ into the ultraproduct. However, by the [Löwenheim–Skolem theorem](wikipedia://en/341482) there must exist countable non-standard models of arithmetic. One way to define such a model is to use [Henkin semantics](wikipedia://en/341428#Semantics).

Any [countable](https://en.wikipedia.org/wiki/Countable) non-standard model of arithmetic has [order type](wikipedia://en/4499021) ω + (ω\* + ω) ⋅ η, where ω is the order type of the standard natural numbers, ω\* is the dual order (an infinite decreasing sequence) and η is the order type of the [rational numbers](wikipedia://en/19727024). In other words, a countable non-standard model begins with an infinite increasing sequence (the standard elements of the model). This is followed by a collection of "blocks", each of order type ω\* + ω, the order type of the integers. These blocks are in turn densely ordered with the order type of the rationals. The result follows fairly easily because it is easy to see that the ordering of the collection of blocks of non-standard numbers has to be [dense](wikipedia://en/6320997) and linearly ordered without endpoints, and the order type of the rationals is the only countable dense linear order without endpoints (see [Cantor's isomorphism theorem](wikipedia://en/68245955)).[^n3][^n4]

So, the order type of the countable non-standard models is known. However, the arithmetical operations are much more complicated.

It is easy to see that the arithmetical structure differs from ω + (ω\* + ω) ⋅ η. For instance if a nonstandard (non-finite) element *u* is in the model, then so is *m* ⋅ *u* for any *m* in the initial segment **N**, yet *u*<sup>2</sup> is larger than *m* ⋅ *u* for any standard finite *m*.

Also one can define "square roots" such as the least *v* such that *v*<sup>2</sup> > 2 ⋅ *u*. These cannot be within a standard finite number of any rational multiple of *u*. By analogous methods to [non-standard analysis](https://en.wikipedia.org/wiki/Non-standard_analysis) one can also use Peano arithmetic to define close approximations to irrational multiples of a non-standard number *u* such as the least *v* with *v* > $\pi$ ⋅ *u* (these can be defined in Peano arithmetic using non-standard finite [rational approximations of $\pi$](https://en.wikipedia.org/wiki/Approximations_of_π) even though $\pi$ itself cannot be). Once more, *v* − (*m*/*n*) ⋅ (*u*/*n*) has to be larger than any standard finite number for any standard finite *m*, *n*.

This shows that the arithmetical structure of a countable non-standard model is more complex than the structure of the rationals. There is more to it than that though: [Tennenbaum's theorem](wikipedia://en/13392068) shows that for any countable non-standard model of Peano arithmetic there is no way to code the elements of the model as (standard) natural numbers such that either the addition or multiplication operation of the model is [computable](https://en.wikipedia.org/wiki/Recursion_theory) on the codes. This result was first obtained by [Stanley Tennenbaum](wikipedia://en/33807699) in 1959.
