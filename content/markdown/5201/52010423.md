# Maximum agreement subtree problem

::: {#o1 .subject cue=lead name="Maximum agreement subtree problem"}

The **maximum agreement subtree problem** is any of several closely related problems in [graph theory](wikipedia://en/12401) and [computer science](https://en.wikipedia.org/wiki/Computer_science). In all of these problems one is given a collection of [trees](wikipedia://en/48560) $T_1,\ldots, T_m$ each containing $n$ leaves. The leaves of these trees are given labels from some set $L$ with $|L|=n$ so that no pair of leaves in the same tree sharing the same label, within the same tree the labelling for each leaf is distinct. In this problem one would like to find the largest subset $L'\subset L$ such that the [minimal spanning subtrees](wikipedia://en/41795) containing the leaves in $L'$, of $T_1\mid S,\ldots, T_m\mid S$ are the "same" while preserving the labelling.

:::

::: {#o3 .definition cue=heading name="Formulations"}

## Formulations {#Formulations}

### Maximum homeomorphic agreement subtree {#Maximum_homeomorphic_agreement_subtree}

Source:[^o5]

This version requires that the subtrees $T_1\mid S,\ldots, T_m\mid S$ are [homeomorphic](wikipedia://en/353021) to one another.

#### Rooted maximum homeomorphic agreement subtree {#Rooted_maximum_homeomorphic_agreement_subtree}

This version is the same as the *maximum homeomorphic agreement subtree*, but we further assume that $T_1,\ldots,T_m$ are rooted and that the subtrees $T_1\mid S,\ldots, T_m\mid S$ contain the root node. This version of the maximum agreement subtree problem is used for the study of [phylogenetic trees](https://en.wikipedia.org/wiki/Phylogenetic_trees).[^o5] Because of its close ties with phylogeny this formulation is often what is mean when one refers to the "maximum agreement subtree" problem.

### Other variants {#Other_variants}

There exits other formulations for example the *(rooted) maximum isomorphic agreement subtree*[^o5] where we require the subtrees to be [isomorphic](wikipedia://en/247577) to one another.
