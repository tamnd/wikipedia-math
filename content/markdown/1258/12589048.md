# Tychonoff plank

::: {#o1 .subject cue=lead name="Tychonoff plank"}

In [topology](wikipedia://en/29954), the **Tychonoff plank** is a [topological space](wikipedia://en/30450) defined using [ordinal spaces](https://en.wikipedia.org/wiki/Ordinal_space) that is a [counterexample](wikipedia://en/143151) to several plausible-sounding [conjectures](wikipedia://en/6138). It is defined as the [topological product](https://en.wikipedia.org/wiki/Topological_product) of the two [ordinal spaces](https://en.wikipedia.org/wiki/Ordinal_space) $[0,\omega_1]$ and $[0,\omega]$, where $\omega$ is the [first infinite ordinal](https://en.wikipedia.org/wiki/First_infinite_ordinal) and $\omega_1$ the [first uncountable ordinal](wikipedia://en/20860540). The **deleted Tychonoff plank** is obtained by deleting the point $\infty = (\omega_1,\omega)$.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\Omega$ be the set of [ordinals](wikipedia://en/26547932) which are less than or equal to $\omega$ and $\Omega_1$ the set of ordinals less than or equal to $\omega_1$. The *Tychonoff plank* is defined as the set $\Omega \times \Omega_1$ with the [product topology](wikipedia://en/24910).[^o5]

The *deleted Tychonoff plank* is the subset $S = \Omega \times \Omega_1 \setminus \{ (\omega,\omega_1) \}$, where $S$ is the plank with a corner removed.[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The Tychonoff plank is a [compact Hausdorff space](https://en.wikipedia.org/wiki/Compact_Hausdorff_space) and is therefore a [normal space](wikipedia://en/48629). However, the deleted Tychonoff plank is non-normal.[^n1] Therefore the Tychonoff plank is not [completely normal](https://en.wikipedia.org/wiki/Completely_normal). This shows that a subspace of a normal space need not be normal. The Tychonoff plank is not [perfectly normal](https://en.wikipedia.org/wiki/Perfectly_normal_space) because it is not a [G<sub>δ</sub> space](wikipedia://en/17993945): the singleton $\{\infty\}$ is closed but not a [G<sub>δ</sub> set](wikipedia://en/252076).[^o10]

The [Stone–Čech compactification](wikipedia://en/52897) of the deleted Tychonoff plank is the Tychonoff plank.[^o11]
