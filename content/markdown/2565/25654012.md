# Ω-automaton

::: {#o1 .subject cue=lead name="Ω-automaton"}

In [automata theory](wikipedia://en/103356), a branch of [theoretical computer science](wikipedia://en/323392), an **[ω](wikipedia://en/26547932)-automaton** (or **stream automaton**) is a variation of a [finite automaton](https://en.wikipedia.org/wiki/Finite_automaton) that runs on infinite, rather than finite, strings as input. Since ω-automata do not stop, they have a variety of acceptance conditions rather than simply a set of accepting states.

:::

ω-automata are useful for specifying behavior of systems that are not expected to terminate, such as hardware, [operating systems](https://en.wikipedia.org/wiki/Operating_systems) and [control systems](https://en.wikipedia.org/wiki/Control_systems). For such systems, one may want to specify a property such as "for every request, an acknowledge eventually follows", or its negation "there is a request that is not followed by an acknowledge". The former is a property of infinite words: one cannot say of a finite sequence that it satisfies this property.

Classes of ω-automata include the [Büchi automata](wikipedia://en/344912), Rabin automata, Streett automata, parity automata and [Muller automata](https://en.wikipedia.org/wiki/Muller_automaton), each deterministic or non-deterministic. These classes of ω-automata differ only in terms of [acceptance condition](wikipedia://en/25654012#Acceptance_conditions). They all recognize precisely the [regular ω-languages](wikipedia://en/3262889) except for the deterministic Büchi automata, which is strictly weaker than all the others. Although all these types of automata recognize the same set of [ω-languages](https://en.wikipedia.org/wiki/Ω-language), they nonetheless differ in succinctness of representation for a given ω-language.

## Deterministic ω-automata {#Deterministic_ω-automata}

Formally, a **deterministic ω-automaton** is a [tuple](wikipedia://en/132729) $A = (Q,\Sigma,\delta,Q_0,A_{acc})$, that consists of the following components:

- $Q$, is a [finite set](wikipedia://en/11742). The elements of $Q$ are called the *states* of $A$.
- $\Sigma$, is a finite set called the *alphabet* of $A$.
- $\delta \colon Q \times \Sigma \rightarrow Q$ is a function, called the *transition function* of $A$.
- $Q_0$ is an element of $Q$, called the initial state.
- $A_{acc}$ is a set of *accepting* states of $A$, formally a subset of $Q^\omega$.

An *input* for $A$ is an infinite string over the alphabet $\Sigma$, i.e. it is an infinite sequence $\alpha = (a_1, a_2, a_3, \ldots)$. The *run* of $A$ on such an input is an infinite sequence $\rho = (r_0, r_1, r_2, \ldots)$ of states, defined as follows:

- $$r_0 = q_0.$$
- $$r_1 = \delta(r_0, a_1).$$
- $$r_2 = \delta(r_1, a_2).$$

...

- that is, for every $i$: $r_i = \delta(r_{i-1}, a_i)$.

The main purpose of an ω-automaton is to define a subset of the set of all inputs: The set of *accepted* inputs. Whereas in the case of an ordinary finite automaton every run ends with a state $r_n$ and the input is accepted if and only if $r_n$ is an accepting state, the definition of the set of accepted inputs is more complicated for ω-automata. Here we must look at the entire run $\rho$. The input is accepted if the corresponding run is in $\text{Acc}$. The set of accepted input ω-words is called the *recognized ω-language* by the automaton, which is denoted as $L(A)$.

The definition of $\text{Acc}$ as a subset of $Q^\omega$ is purely formal and not suitable for practice because normally such sets are infinite. The difference between various types of ω-automata (Büchi, Rabin etc.) consists in how they encode certain subsets $\text{Acc}$ of $Q^\omega$ as finite sets, and therefore in which such subsets they can encode.

## Nondeterministic ω-automata {#Nondeterministic_ω-automata}

Formally, a **nondeterministic ω-automaton** is a tuple $A = (Q, \Sigma, \Delta, Q_0, \text{Acc})$ that consists of the following components:

- $Q$ is a [finite set](wikipedia://en/11742). The elements of $Q$ are called the *states* of $A$.
- $\Sigma$ is a finite set called the *alphabet* of $A$.
- $\Delta$ is a subset of $Q \times \Sigma \times Q$ and is called the *transition relation* of $A$.
- $Q_0$ is a subset of $Q$, called the initial set of states.
- $\text{Acc}$ is the *acceptance condition*, a subset of $Q^\omega$.

Unlike a deterministic ω-automaton, which has a transition function $\delta$, the non-deterministic version has a transition relation $\Delta$. Note that $\Delta$ can be regarded as a function $Q \times \Sigma \rightarrow \mathcal{P}(Q)$ from $Q \times \Sigma$ to the [power set](wikipedia://en/23799) $\mathcal{P}(Q)$. Thus, given a state $q_n$ and a symbol $a_n$, the next state $q_{n+1}$ is not necessarily determined uniquely, rather there is a set of possible next states.

A *run* of $A$ on the input $\alpha = (a_1, a_2, a_3, \ldots)$ is any infinite sequence $\rho = (r_0, r_1, r_2, \ldots)$ of states that satisfies the following conditions:

- $r_0$ is an element of $Q_0$.
- $r_1$ is an element of $\Delta(r_0, a_1)$.
- $r_2$ is an element of $\Delta(r_1, a_2)$.

...

- that is, for every $i$: $r_i$ is an element of $\Delta(r_{i-1}, a_i)$.

A nondeterministic ω-automaton may admit many different runs on any given input, or none at all. The input is accepted if at least one of the possible runs is accepting. Whether a run is accepting depends only on $\text{Acc}$, as for deterministic ω-automata. Every deterministic ω-automaton can be regarded as a nondeterministic ω-automaton by taking $\Delta$ to be the graph of $\delta$. The definitions of runs and acceptance for deterministic ω-automata are then special cases of the nondeterministic cases.

## Acceptance conditions {#Acceptance_conditions}

Acceptance conditions may be infinite sets of ω-words. However, people mostly study acceptance conditions that are finitely representable. The following lists a variety of popular acceptance conditions.

Before discussing the list, let's make the following observation. In the case of infinitely running systems, one is often interested in whether certain behavior is repeated infinitely often. For example, if a network card receives infinitely many ping requests, then it may fail to respond to some of the requests but should respond to an infinite subset of received ping requests. This motivates the following definition: For any run $\rho$, let $\text{Inf}(\rho)$ be the set of states that occur infinitely often in $\rho$. This notion of certain states being visited infinitely often will be helpful in defining the following acceptance conditions.

- A [Büchi automaton](wikipedia://en/344912) is an ω-automaton $A$ that uses the following acceptance condition, for some subset $F$ of $Q$:

**Büchi condition**

$A$ accepts exactly those runs $\rho$ for which $\text{Inf}(\rho) \cap F \neq \emptyset$, i.e. there is an accepting state that occurs infinitely often in $\rho$.

- A **Rabin automaton** is an ω-automaton $A$ that uses the following acceptance condition, for some set $\Omega$ of pairs $(B_i, G_i)$ of sets of states:

**Rabin condition**

$A$ accepts exactly those runs $\rho$ for which there exists a pair $(B_i, G_i)$ in $\Omega$ such that $B_i \cap \text{Inf}(\rho) = \emptyset$ and $G_i \cap \text{Inf}(\rho) \neq \emptyset$.

- A **Streett automaton** is an ω-automaton $A$ that uses the following acceptance condition, for some set $\Omega$ of pairs $(B_i, G_i)$ of sets of states:

**Streett condition**

$A$ accepts exactly those runs $\rho$ such that for all pairs $(B_i, G_i)$ in $\Omega$, $B_i \cap \text{Inf}(\rho) \neq \emptyset$ or $G_i \cap \text{Inf}(\rho) = \emptyset$.

- A **parity automaton** is an automaton $A$ whose set of states is $Q = \{0, 1, 2, \ldots, k\}$ for some natural number $k$, and that has the following acceptance condition:

**Parity condition**

$A$ accepts $\rho$ [if and only if](wikipedia://en/14922) the smallest number in $\text{Inf}(\rho)$ is even.

- A [Muller automaton](https://en.wikipedia.org/wiki/Muller_automaton) is an ω-automaton $A$ that uses the following acceptance condition, for a subset $\mathbf{F}$ of $\mathcal{P}(Q)$ (the [power set](wikipedia://en/23799) of $Q$):

**Muller condition**

$A$ accepts exactly those runs $\rho$ for which $\text{Inf}(\rho) \in \mathbf{F}$.

Every Büchi automaton can be regarded as a Muller automaton. It suffices to replace $F$ by $\mathbf{F}'$ consisting of all subsets of $Q$ that contain at least one element of $F$. Similarly every Rabin, Streett or parity automaton can also be regarded as a Muller automaton.

## Example {#Example}

*Image: Buchi non deterministic example.svg.* A non-deterministic Büchi automaton that recognizes (0∪1)\*0<sup>ω</sup>

The following ω-language $L$ over the alphabet $\Sigma = \{0, 1\}$, which can be recognized by a nondeterministic Büchi automaton: $L$ consists of all ω-words in $\Sigma^\omega$ in which 1 occurs only finitely many times. A non-deterministic Büchi automaton recognizing $L$ needs only two states $q_0$ (the initial state) and $q_1$. $\Delta$ consists of the triples $(q_0, 0, q_0)$, $(q_0, 1, q_0)$, $(q_0, 0, q_1)$ and $(q_1, 0, q_1)$. $F = \{q_1\}$. For any input $\alpha$ in which 1 occurs only finitely many times, there is a run that stays in state $q_0$ as long as there are 1s to read, and goes to state $q_1$ afterwards. This run is successful. If there are infinitely many 1s, then there is only one possible run: the one that always stays in state $q_0$. (Once the machine has left $q_0$ and reached $q_1$, it cannot return. If another 1 is read, there is no successor state.)

Notice that above language cannot be recognized by a deterministic [Büchi automaton](wikipedia://en/344912), which is [strictly less expressive](wikipedia://en/344912#Recognizable_languages) than its non-deterministic counterpart.

:::

## Expressive power of ω-automata {#Expressive_power_of_ω-automata}

An ω-language over a finite alphabet $\Sigma$ is a set of ω-words over $\Sigma$, i.e. it is a subset of $\Sigma^\omega$. An ω-language over $\Sigma$ is said to be recognized by an ω-automaton $A$ (with the same alphabet) if it is the set of all ω-words accepted by $A$. The expressive power of a class of ω-automata is measured by the class of all ω-languages that can be recognized by some automaton in the class.

The nondeterministic Büchi, parity, Rabin, Streett, and Muller automata, respectively, all recognize exactly the same class of ω-languages.[^o9] These are known as the *ω-Kleene closure of the regular languages* or as the [regular ω-languages](wikipedia://en/3262889). Using different proofs it can also be shown that the deterministic parity, Rabin, Streett, and Muller automata all recognize the regular ω-languages. It follows from this that the class of regular ω-languages is closed under complementation. However, the example above shows that the class of deterministic Büchi automata is strictly weaker.

## Conversion between ω-automata {#Conversion_between_ω-automata}

Because nondeterministic Muller, Rabin, Streett, parity, and Büchi automata are equally expressive, they can be translated to each other. Let us use the following abbreviation $\{N,D\}\times\{M,R,S,P,B\}$: for example, *NB* stands for nondeterministic Büchi ω-automaton, while *DP* stands for deterministic parity ω-automaton. Then the following holds.

- Clearly, any [deterministic automaton](https://en.wikipedia.org/wiki/Deterministic_automaton) can be viewed as a nondeterministic one.
- $NB \rightarrow NR/NS/NP$ with no blow-up in the state space.
- $NR \rightarrow NB$ with a polynomial blow-up in the state space, i.e., the number of states in the resulting *NB* is $2nm+1$, where $n$ is the number of states in the *NB* and $m$ is the number of Rabin acceptance pairs (see, for example,[^o11]).
- $NS/NM/NP \rightarrow NB$ with exponential blow-up in the state space.
- $NB \rightarrow DR/DP$ with exponential blow-up in the state space. This determinization result uses [Safra's construction](https://en.wikipedia.org/wiki/Safra's_construction).

A comprehensive overview of translations can be found on the referenced web source.[^o12]

## Applications to decidability {#Applications_to_decidability}

ω-automata can be used to prove decidability of S1S, the [monadic second-order](wikipedia://en/14650395) (MSO) theory of natural numbers under successor. [Infinite-tree automata](https://en.wikipedia.org/wiki/Infinite-tree_automaton) extend ω-automata to infinite trees and can be used to prove decidability of [S2S](wikipedia://en/72252525), the MSO theory with two successors, and this can be extended to the MSO theory of graphs with bounded (given a fixed bound) [treewidth](wikipedia://en/3987086).
