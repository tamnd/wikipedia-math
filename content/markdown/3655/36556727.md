# Ternary commutator

::: {#o1 .subject cue=lead name="Ternary commutator"}

In [mathematical physics](wikipedia://en/173416), the **ternary commutator** is an additional [ternary operation](wikipedia://en/459413) on a [triple system](wikipedia://en/19287276) defined by

:::

$$[a,b,c] = abc-acb-bac+bca+cab-cba. \,$$

Also called the **ternutator** or **alternating ternary sum**, it is a special case of the [*n*-commutator](https://en.wikipedia.org/wiki/N-commutator) for *n* = 3, whereas the 2-commutator is the ordinary [commutator](wikipedia://en/7193).

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- When one or more of *a*, *b*, *c* is equal to 0, \[*a*, *b*, *c*\] is also 0. This statement makes 0 the [absorbing element](wikipedia://en/14206224) of the ternary commutator.
  - The same happens when *a* = *b* = *c*.

:::
