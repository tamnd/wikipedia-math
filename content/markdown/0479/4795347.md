# Balian–Low theorem

::: {#o1 .subject cue=lead name="Balian–Low theorem"}

In [mathematics](wikipedia://en/18831), the **Balian–Low theorem** in [Fourier analysis](wikipedia://en/11659) is named for [Roger Balian](https://en.wikipedia.org/wiki/Roger_Balian) and [Francis E. Low](https://en.wikipedia.org/wiki/Francis_E._Low). The theorem states that there is no well-localized [window function](wikipedia://en/244097) (or [Gabor atom](wikipedia://en/6765164)) *g* either in time or frequency for an exact Gabor [frame](https://en.wikipedia.org/wiki/Frame_of_a_vector_space) (Riesz Basis).

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Suppose *g* is a [square-integrable function](wikipedia://en/28680558) on the [real line](https://en.wikipedia.org/wiki/Real_line), and consider the so-called [Gabor system](https://en.wikipedia.org/wiki/Dennis_Gabor)

$$g_{m,n}(x) = e^{2\pi i m b x} g(x - n a),$$

for integers *m* and *n*, and *a,b>0* satisfying *ab=1*. The Balian–Low theorem states that if

$$\{g_{m,n}: m, n \in \mathbb{Z}\}$$

is an [orthonormal basis](wikipedia://en/195063) for the [Hilbert space](wikipedia://en/20598932)

$$L^2(\mathbb{R}),$$

then either

$$\int_{-\infty}^\infty x^2 | g(x)|^2\; dx = \infty \quad \textrm{or} \quad \int_{-\infty}^\infty \xi^2|\hat{g}(\xi)|^2\; d\xi = \infty.$$

:::

::: {#o5 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

The Balian–Low theorem has been extended to exact Gabor [frames](https://en.wikipedia.org/wiki/Frame_of_a_vector_space).

:::
