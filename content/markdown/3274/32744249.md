# Matheass

::: {#o1 .subject cue=lead name="Matheass"}

**MatheAss** (former **Math-Assist**) is a [computer program](https://en.wikipedia.org/wiki/Computer_program) for [numerical](wikipedia://en/21506) solutions in school mathematics and functions in some points similar to [Microsoft Mathematics](https://en.wikipedia.org/wiki/Microsoft_Mathematics).[^o3] MatheAss is common in math classes throughout Germany, and schools in the German federal state of [Hessen](https://en.wikipedia.org/wiki/Hessen) possess a state license which allows all secondary schools to use MatheAss.[^o4][^o5]

:::

Its functionality is limited compared to other numerical programs, for example, MatheAss has no [script language](https://en.wikipedia.org/wiki/Scripting_language) and does no [symbolic computation](https://en.wikipedia.org/wiki/Symbolic_computation). On the other side it is easy to use and offers the user fully worked out solutions, in which only the necessary quantities need to be entered. MatheAss covers the topics algebra, geometry, analysis, stochastics, and linear algebra.[^o6]

After a precursor for the [home computers](https://en.wikipedia.org/wiki/Home_computer), usual around 1980, MatheAss appeared in 1983 as a shareware version for the PC, so it was one of the first [shareware](https://en.wikipedia.org/wiki/Shareware) programs on the German market. MatheAss is available on the manufacturer's website for download for various versions of the [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) operating system.[^o7]

MatheAss offers a context-sensitive help, which was supplemented in many places by showing mathematical examples and background information.[^o8] The MatheAss help file can also be viewed online.[^o9]

MatheAss is freeware, which means: For private use, the program is free of charge. For use in schools or for commercial purposes, you must register.[^o10]
