# Pantelides algorithm

::: {#o1 .subject cue=lead name="Pantelides algorithm"}

**Pantelides algorithm** in [mathematics](wikipedia://en/18831) is a systematic method for reducing high-index systems of [differential-algebraic equations](https://en.wikipedia.org/wiki/Differential_algebraic_equation) to lower index. This is accomplished by selectively adding differentiated forms of the equations already present in the system.[^o2][^o3][^o4] It is possible for the [algorithm](wikipedia://en/775) to fail in some instances.

:::

Pantelides algorithm is implemented in several significant equation-based simulation programs such as gPROMS, [Modelica](https://en.wikipedia.org/wiki/Modelica) and [EMSO](https://en.wikipedia.org/wiki/EMSO_simulator).[^o5][^o6][^o7]
