# Generic flatness

::: {#o1 .subject cue=lead name="Generic flatness"}

In [algebraic geometry](wikipedia://en/1997) and [commutative algebra](wikipedia://en/245990), the theorems of **generic flatness** and **generic freeness** state that under certain hypotheses, a [sheaf](wikipedia://en/245466) of [modules](wikipedia://en/276410) on a [scheme](wikipedia://en/364754) is [flat](wikipedia://en/542520) or [free](wikipedia://en/326454). They are due to [Alexander Grothendieck](wikipedia://en/2042).

:::

Generic flatness states that if *Y* is an integral [locally noetherian scheme](https://en.wikipedia.org/wiki/Locally_noetherian_scheme), *u* : *X* → *Y* is a [finite type](wikipedia://en/70728366) [morphism of schemes](wikipedia://en/7482797), and *F* is a [coherent](wikipedia://en/603780) *O*<sub>*X*</sub>-module, then there is a non-empty open subset *U* of *Y* such that the restriction of *F* to *u*<sup>−1</sup>(*U*) is flat over *U*.[^o2]

Because *Y* is integral, *U* is a dense open subset of *Y*. This can be applied to deduce a variant of generic flatness which is true when the base is not integral.[^o3] Suppose that *S* is a noetherian scheme, *u* : *X* → *S* is a finite type morphism, and *F* is a coherent *O*<sub>*X*</sub>-module. Then there exists a partition of *S* into locally closed subsets *S*<sub>1</sub>, ..., *S*<sub>*n*</sub> with the following property: Give each *S*<sub>*i*</sub> its reduced scheme structure, denote by *X*<sub>*i*</sub> the [fiber product](wikipedia://en/56444110) *X* ×<sub>*S*</sub> *S*<sub>*i*</sub>, and denote by *F*<sub>*i*</sub> the restriction *F* ⊗<sub>*O*<sub>*S*</sub></sub> *O*<sub>*S*<sub>*i*</sub></sub>; then each *F*<sub>*i*</sub> is flat.

## Generic freeness {#Generic_freeness}

Generic flatness is a consequence of the generic freeness lemma. Generic freeness states that if *A* is a [noetherian](wikipedia://en/56129) [integral domain](wikipedia://en/15462), *B* is a [finite type](https://en.wikipedia.org/wiki/Algebra_of_finite_type) *A*-algebra, and *M* is a finite type *B*-module, then there exists a non-zero element *f* of *A* such that *M*<sub>*f*</sub> is a free *A*<sub>*f*</sub>-module.[^o5] Generic freeness can be extended to the [graded](wikipedia://en/103094) situation: If *B* is graded by the natural numbers, *A* acts in degree zero, and *M* is a graded *B*-module, then *f* may be chosen such that each graded component of *M*<sub>*f*</sub> is free.[^o6]

Generic freeness is proved using Grothendieck's technique of [dévissage](wikipedia://en/26377503). Another version of generic freeness can be proved using [Noether's normalization lemma](https://en.wikipedia.org/wiki/Noether's_normalization_lemma#Illustrative_application:_generic_freeness).
