# Nowhere-zero flow

::: {#o1 .subject cue=lead name="Nowhere-zero flow"}

In [graph theory](wikipedia://en/12401), a **nowhere-zero flow** or **NZ flow** is a [network flow](wikipedia://en/645676) that is nowhere zero. It is intimately connected (by duality) to [coloring](wikipedia://en/426743) [planar graphs](https://en.wikipedia.org/wiki/Planar_graphs).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let *G* = (*V*,*E*) be a [digraph](wikipedia://en/19721986) and let *M* be an [abelian group](wikipedia://en/2974). A map *φ*: *E* → *M* is an ***M*-circulation** if for every [vertex](wikipedia://en/638899) *v* ∈ *V*

$$\sum_{e \in \delta^+(v)} \varphi(e) = \sum_{e \in \delta^-(v)} \varphi(e),$$

where *δ*<sup>\+</sup>(*v*) denotes the set of edges out of *v* and *δ*<sup>−</sup>(*v*) denotes the set of edges into *v*. Sometimes, this condition is referred to as [Kirchhoff's law](https://en.wikipedia.org/wiki/Kirchhoff's_circuit_laws).

If *φ*(*e*) ≠ 0 for every *e* ∈ *E*, we call *φ* a **nowhere-zero flow,** an ***M*-flow,** or an **NZ-flow.** If *k* is an integer and 0 \< |*φ*(*e*)| \< *k* then *φ* is a ***k*-flow.**[^o4]

### Other notions {#Other_notions}

Let *G* = (*V*,*E*) be an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph). An orientation of *E* is a **modular** *k*-**flow** if for every vertex *v* ∈ *V* we have:

$$|\delta^+(v)| \equiv |\delta^-(v)| \bmod k.$$

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The set of *M*-flows does not necessarily form a group as the sum of two flows on one edge may add to 0.
- (Tutte 1950) A graph *G* has an *M*-flow if and only if it has a |*M*|-flow. As a consequence, a $\mathbb{Z}_k$ flow exists if and only if a *k*-flow exists.[^o4] As a consequence if *G* admits a *k*-flow then it admits an *h*-flow where $h \geq k$.
- Orientation independence. Modify a nowhere-zero flow *φ* on a graph *G* by choosing an edge *e*, reversing it, and then replacing *φ*(*e*) with −*φ*(*e*). After this adjustment, *φ* is still a nowhere-zero flow. Furthermore, if *φ* was originally a *k*-flow, then the resulting *φ* is also a *k*-flow. Thus, the existence of a nowhere-zero *M*-flow or a nowhere-zero *k*-flow is independent of the orientation of the graph. Thus, an undirected graph *G* is said to have a nowhere-zero *M*-flow or nowhere-zero *k*-flow if some (and thus every) orientation of *G* has such a flow.

:::

## Flow polynomial {#Flow_polynomial}

Let $N_M(G)$ be the number of *M*-flows on *G*. It satisfies the [deletion–contraction formula](wikipedia://en/60656372):[^o4]

$$N_M(G) = N_M(G/ e) - N_M(G\setminus e).$$

Combining this with induction we can show $N_M(G)$ is a polynomial in $|M|-1$ where $|M|$ is the [order](wikipedia://en/493527) of the group *M*. We call $N_M(G)$ the **[flow polynomial](https://en.wikipedia.org/wiki/Flow_polynomial)** of *G* and abelian group *M*.

The above implies that two groups of equal order have an equal number of NZ flows. The order is the only group parameter that matters, not the structure of *M*. In particular $N_{M_1}(G) = N_{M_2}(G)$ if $|M_1| = |M_2|.$

The above results were proved by [Tutte](https://en.wikipedia.org/wiki/Tutte) in 1953 when he was studying the [Tutte polynomial](wikipedia://en/3892303), a generalization of the flow polynomial.[^o9]

## Flow-coloring duality {#Flow-coloring_duality}

### Bridgeless Planar Graphs {#Bridgeless_Planar_Graphs}

There is a duality between *k*-face [colorings](wikipedia://en/426743) and *k*-flows for [bridgeless](wikipedia://en/1305071) [planar graphs](wikipedia://en/24314). To see this, let *G* be a directed bridgeless planar graph with a proper *k*-face-coloring with colors $\{0, 1, \ldots, k-1\}.$ Construct a map

$$\phi: E(G)\to \{-(k-1), \ldots, -1, 0, 1, \ldots, k-1\}$$

by the following rule: if the edge *e* has a face of color *x* to the left and a face of color *y* to the right, then let *φ*(*e*) = *x* – *y*. Then *φ* is a (NZ) *k*-flow since *x* and *y* must be different colors.

So if *G* and *G\** are planar [dual graphs](wikipedia://en/2536864) and *G\** is *k*-colorable (there is a coloring of the faces of *G*), then *G* has an NZ *k*-flow. Using induction on |*E*(*G*)| Tutte proved the converse is also true. This can be expressed concisely as:[^o4]

$$\chi(G^*) = \phi(G),$$

where the RHS is the **flow number**, the smallest *k* for which *G* permits a *k*-flow.

### General Graphs {#General_Graphs}

The duality is true for general *M*-flows as well:

- Let $c$ be the face-coloring function with values in *M*.
- Define $\phi_c(e) = c(r_1) - c(r_2)$ where *r*<sub>1</sub> is the face to the left of *e* and *r*<sub>2</sub> is to the right.
- For every *M*-circulation $\phi$ there is a coloring function *c* such that $\phi = \phi_c$ (proven by induction).
- *c* is a |*E*(*G*)|-face-coloring if and only if $\phi_c$ is an NZ *M*-flow (straightforward).

The duality follows by combining the last two points. We can specialize to $M = \mathbb{Z}_k$ to obtain the similar results for *k*-flows discussed above. Given this duality between NZ flows and colorings, and since we can define NZ flows for arbitrary graphs (not just planar), we can use this to extend face-colorings to non-planar graphs.[^o4]

::: {#o14 .application cue=heading name="Applications"}

## Applications {#Applications}

- *G* is 2-face-colorable if and only if every vertex has even degree (consider NZ 2-flows).[^o4]
- Let $K = \mathbb{Z}_2 \times \mathbb{Z}_2$ be the [Klein-4 group](https://en.wikipedia.org/wiki/Klein-4_group). Then a [cubic graph](wikipedia://en/980508) has a *K*-flow if and only if it is 3-[edge-colorable](wikipedia://en/690647). As a corollary a cubic graph that is 3-edge colorable is 4-face colorable.[^o4]
- A graph is 4-face colorable if and only if it permits an NZ 4-flow (see [Four color theorem](wikipedia://en/10949)). The [Petersen graph](wikipedia://en/194926) does not have an NZ 4-flow, and this led to the 4-flow conjecture (see below).
- If *G* is a triangulation then *G* is 3-(vertex) colorable if and only if every vertex has even degree. By the first bullet, the dual graph *G*\* is 2-colorable and thus [bipartite](wikipedia://en/244431) and planar cubic. So *G*\* has an NZ 3-flow and is thus 3-face colorable, making *G* 3-vertex colorable.[^o4]
- Just as no graph with a [loop](wikipedia://en/325802) edge has a proper vertex coloring, no graph with a [bridge](wikipedia://en/325802) can have an NZ *M*-flow for any group *M*. Conversely, every [bridgeless graph](https://en.wikipedia.org/wiki/Bridgeless_graph) has an NZ $\mathbb{Z}$-flow (a form of [Robbins' theorem](wikipedia://en/36633800)).[^o15]

:::

## Existence of *k*-flows {#Existence_of_k-flows}

::: {#o17 .problem cue=unsolved}

Does every bridgeless graph have a nowhere zero 5-flow? Does every bridgeless graph that does not have the Petersen graph as a minor have a nowhere zero 4-flow?

:::

Interesting questions arise when trying to find nowhere-zero *k*-flows for small values of *k*. The following have been proven:

**Jaeger's 4-flow Theorem.** Every 4-[edge-connected](wikipedia://en/325802) graph has a 4-flow.[^o18]

**[Seymour](wikipedia://en/1575708)'s 6-flow Theorem.** Every bridgeless graph has a 6-flow.[^o19]

::: {#o21 .statement kind=statement/conjecture cue=named-heading name="3-flow, 4-flow and 5-flow conjectures"}

### 3-flow, 4-flow and 5-flow conjectures {#3-flow,_4-flow_and_5-flow_conjectures}

As of 2026, the following are currently unsolved (due to [Tutte](wikipedia://en/52021)):

**3-flow Conjecture.** Every 4-edge-connected graph has a nowhere-zero 3-flow.[^o22]

**4-flow Conjecture.** Every bridgeless graph that does not have the [Petersen graph](wikipedia://en/194926) as a [minor](https://en.wikipedia.org/wiki/Minor_%28graph_theory%29) has a nowhere-zero 4-flow.[^o23]

**5-flow Conjecture.** Every bridgeless graph has a nowhere-zero 5-flow.[^o24]

The converse of the 4-flow Conjecture does not hold since the [complete graph](wikipedia://en/85816) *K*<sub>11</sub> contains a Petersen graph *and* a 4-flow.[^o4] For bridgeless [cubic graphs](wikipedia://en/980508) with no Petersen minor, 4-flows exist by the [snark theorem](wikipedia://en/727811) (Seymour, et al. 1998, not yet published). The [four color theorem](wikipedia://en/10949) is equivalent to the statement that no snark is planar.[^o4]

:::
