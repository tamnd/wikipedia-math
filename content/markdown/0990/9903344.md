# Orientation character

::: {#o1 .subject cue=lead name="Orientation character"}

In [algebraic topology](wikipedia://en/38801), a branch of [mathematics](wikipedia://en/18831), an **orientation character** on a [group](wikipedia://en/19447) $\pi$ is a [group homomorphism](wikipedia://en/12396) to the group of two elements

:::

$$\omega\colon \pi \to \left\{\pm 1\right\},$$

where typically $\pi$ is the [fundamental group](wikipedia://en/11004) of a manifold. This notion is of particular significance in [surgery theory](wikipedia://en/5961115).

## Motivation {#Motivation}

Given a [manifold](wikipedia://en/2073470) *M*, one takes $\pi=\pi_1( M)$ (the fundamental group), and then $\omega$ sends an element of $\pi$ to $-1$ if and only if the class it represents is orientation-reversing.

This map $\omega$ is trivial if and only if *M* is [orientable](https://en.wikipedia.org/wiki/Orientable).

The orientation character is an algebraic structure on the fundamental group of a manifold, which captures which loops are orientation reversing and which are orientation preserving.

## Twisted group algebra {#Twisted_group_algebra}

The orientation character defines a twisted involution ([\*-ring](https://en.wikipedia.org/wiki/*-ring) structure) on the [group ring](wikipedia://en/349223) $\mathbf{Z}[\pi]$, by $g \mapsto \omega(g)g^{-1}$ (i.e., $\pm g^{-1}$, accordingly as $g$ is orientation preserving or reversing). This is denoted $\mathbf{Z}[\pi]^\omega$.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- In [real projective spaces](wikipedia://en/1014694), the orientation character evaluates trivially on loops if the dimension is odd, and assigns -1 to noncontractible loops in even dimension.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The orientation character is either trivial or has as its [kernel](https://en.wikipedia.org/wiki/Kernel_%28group_theory%29) an index 2 subgroup, which determines the map completely.

:::
