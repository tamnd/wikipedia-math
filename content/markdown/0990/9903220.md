# Complete set of invariants

::: {#o1 .subject cue=lead name="Complete set of invariants"}

In [mathematics](wikipedia://en/18831), a complete set of [invariants](wikipedia://en/1126638) for a [classification problem](https://en.wikipedia.org/wiki/Classification_theorems) is a collection of maps

:::

$$f_i : X \to Y_i$$

(where $X$ is the collection of objects being classified, up to some equivalence relation $\sim$, and the $Y_i$ are some sets), such that $x \sim x'$ if and only if $f_i(x) = f_i(x')$ for all $i$. In words, such that two objects are equivalent if and only if all invariants are equal.[^o2]

Symbolically, a complete set of invariants is a collection of maps such that

$$\left( \prod f_i \right) : (X/\sim) \to \left( \prod Y_i \right)$$

is [injective](https://en.wikipedia.org/wiki/Injective).

As invariants are, by definition, equal on equivalent objects, equality of invariants is a *necessary* condition for equivalence; a *complete* set of invariants is a set such that equality of these is also *sufficient* for equivalence. In the context of a group action, this may be stated as: invariants are functions of [coinvariants](https://en.wikipedia.org/wiki/Coinvariant) (equivalence classes, orbits), and a complete set of invariants characterizes the coinvariants (is a set of defining equations for the coinvariants).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- In the [classification of two-dimensional closed manifolds](https://en.wikipedia.org/wiki/Classification_of_two-dimensional_closed_manifolds), [Euler characteristic](wikipedia://en/148420) (or [genus](wikipedia://en/61891)) and [orientability](wikipedia://en/187446) are a complete set of invariants.
- The [Jordan normal form](wikipedia://en/312877) of a matrix is a complete invariant for matrices over a field up to conjugation ([similarity](wikipedia://en/341149)), but [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) (with multiplicities) are not.
- The [elementary divisors](wikipedia://en/4577402) are a complete invariant for matrices over a [principal ideal domain](wikipedia://en/25039) up to conjugation (or for [finitely generated modules](wikipedia://en/326430) over a PID up to isomorphism).
- The [signature](https://en.wikipedia.org/wiki/Signature_%28matrix%29) and rank of a matrix are a complete set of invariants for real [symmetric matrices](https://en.wikipedia.org/wiki/Symmetric_matrices) up to [congruence](wikipedia://en/2383040) (or for real [quadratic forms](wikipedia://en/251478) up to equivalence), by [Sylvester's law of inertia](wikipedia://en/1127460).

:::

## Realizability of invariants {#Realizability_of_invariants}

A complete set of invariants does not immediately yield a [classification theorem](wikipedia://en/4576710): not all combinations of invariants may be realized. Symbolically, one must also determine the image of

$$\prod f_i : X \to \prod Y_i.$$
