# Transversality condition

::: {#o1 .subject cue=lead name="Transversality condition"}

In [optimal control theory](https://en.wikipedia.org/wiki/Optimal_control_theory), a **transversality condition** is a [boundary condition](wikipedia://en/436779) for the terminal values of the [costate variables](wikipedia://en/347128). They are one of the [necessary conditions](https://en.wikipedia.org/wiki/Necessary_condition) for optimality infinite-horizon [optimal control](wikipedia://en/362565) problems without an endpoint [constraint](wikipedia://en/7418540) on the [state variables](https://en.wikipedia.org/wiki/State_variable).

:::
