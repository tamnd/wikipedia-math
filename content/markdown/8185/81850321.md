# Global dominating set

*Image: Global dominating set.svg.* Two [complementary](wikipedia://en/1175649) graphs, with a minimum **global dominating set** colored red in each

::: {#o1 .subject cue=lead name="Global dominating set"}

In [graph theory](wikipedia://en/12401), a **global dominating set** is a [dominating set](wikipedia://en/1747972) $S$ of a graph $G$ that is also a dominating set of the [complement graph](wikipedia://en/1175649) $\bar{G}$. The **global domination number** $\gamma_g(G)$ is the minimum cardinality of a global dominating set of $G$. The concept was introduced by E. Sampathkumar in 1989.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G = (V, E)$ be a graph with vertex set $V$ and edge set $E$. A set $S \subseteq V$ is a **dominating set** of $G$ if every vertex in $V - S$ is adjacent to at least one vertex in $S$. A dominating set $S$ is called a **global dominating set** (or **g.d. set**) if $S$ is also a dominating set of the complement $\bar{G}$.[^o2]

Equivalently, a dominating set $S$ of $G$ is a global dominating set if and only if for each vertex $v \in V - S$, there exists a vertex $u \in S$ such that $u$ is not adjacent to $v$ in $G$.[^o2]

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The following properties hold for any graph $G$:[^o2]

- $$\gamma_g(G) = \gamma_g(\bar{G})$$
- $\gamma(G) \leq \gamma_g(G)$, where $\gamma(G)$ is the [domination number](https://en.wikipedia.org/wiki/Domination_number) of $G$
- $\bar{\gamma}(G) \leq \gamma_g(G)$, where $\bar{\gamma}(G) = \gamma(\bar{G})$
- $$\frac{\gamma(G) + \bar{\gamma}(G)}{2} \leq \gamma_g(G) \leq \gamma(G) + \bar{\gamma}(G)$$

For a graph $G$ of [order](https://en.wikipedia.org/wiki/Order_%28graph_theory%29) $p$ without isolated vertices:[^o2]

- $$\gamma(G) + \gamma_g(G) \leq p + 1$$
- $\gamma_g(G) \leq \max\{\chi(G), \chi(\bar{G})\}$, where $\chi(G)$ is the [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) of $G$

The global domination number exhibits invariance under certain [graph operations](wikipedia://en/9938244). For example, for cycles $C_n$ (with $n \neq 3, n \neq 5$), the global domination number remains unchanged under the operation of edge duplication, and similarly for wheels $W_n$.[^o9]

### Bounds {#Bounds}

For a connected graph $G$ of order $n$ with maximum degree $\Delta(G)$, diameter $d(G)$, radius $r(G)$, and the set of [support vertices](https://en.wikipedia.org/wiki/Support_vertices) (vertices adjacent to vertices with degree $1$) $Supp(G)$, the following lower bound holds:[^o13]

$$L = \max\left\{\frac{n}{\Delta(G)+1}, \frac{2r(G)}{3}, \frac{d(G)+1}{3}, |Supp(G)|\right\} \leq \gamma_g(G)$$

Upper bounds have also been established:[^o13]

- $$\gamma_g(G) \leq \min\{\Delta(G), \Delta(\bar{G})\} + 1$$
- $\gamma_g(G) \leq \max\{\delta(G), \delta(\bar{G})\} + 1$ when $\delta(G) = \delta(\bar{G}) > 2$, where $\delta(G)$ is the minimum degree

:::

## Known graphs {#Known_graphs}

For specific families of graphs, the global domination number has been determined:[^o2][^o9]

- For a [complete graph](wikipedia://en/85816) $K_p$ or its complement $\bar{K}_p$: $\gamma_g(G) = p$
- For a [complete bipartite graph](wikipedia://en/525320) $K_{m,n}$ with $2 \leq m \leq n$: $\gamma_g(K_{m,n}) = n$
- For a [cycle](wikipedia://en/878962) $C_n$ with $n \neq 3$ and $n \neq 5$: $\gamma_g(C_n) = \lceil n/3 \rceil$
- For a [path](wikipedia://en/4587190) $P_n$ with $n \geq 4$: $\gamma_g(P_n) = \lceil n/3 \rceil$
- For a [wheel](wikipedia://en/1655876) $W_n$: $\gamma_g(W_n) = 4$ if $n = 4$, and $\gamma_g(W_n) = 3$ otherwise

## Global domatic number {#Global_domatic_number}

The **global domatic number** $d_g(G)$ is the maximum order of a partition of the vertex set $V$ into global dominating sets. Analogous to the relationship between the [domination number](https://en.wikipedia.org/wiki/Domination_number) and [domatic number](wikipedia://en/1771980), we have $d_g(G) = d_g(\bar{G})$ and $d_g(G) \leq d(G) \leq \delta(G) + 1$, where $d(G)$ is the domatic number and $\delta(G)$ is the minimum degree of $G$.[^o2]

## Computational complexity {#Computational_complexity}

The problem of finding a minimum global dominating set is [NP-hard](https://en.wikipedia.org/wiki/NP-hard). This was established by Brigham and Dutton (1990) through a reduction from the [dominating set problem](https://en.wikipedia.org/wiki/Dominating_set_problem), which is known to be NP-hard.[^o13][^o12]

The problem remains NP-hard even for restricted graph classes, including [planar graphs](wikipedia://en/24314) and [split graphs](wikipedia://en/9928681). For split graphs, any global dominating set is formed either by the dominating set of the graph or by the dominating set augmented with vertices from the independent set.[^o13]

::: {#o15 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

Both exact and heuristic algorithms have been developed for the global domination problem:[^o13]

**Exact algorithms:**

- An [integer linear programming](https://en.wikipedia.org/wiki/Integer_linear_programming) (ILP) formulation using $2n$ constraints to ensure domination in both $G$ and $\bar{G}$
- An implicit enumeration algorithm using binary search over feasible solution sizes, guided by lower and upper bounds

**Heuristic algorithms:**

- [Greedy algorithms](wikipedia://en/89247) that iteratively select vertices maximizing the number of newly dominated vertices in both the graph and its complement
- A purification procedure that reduces the size of a global dominating set by removing redundant vertices while maintaining the domination property

:::

::: {#o17 .application cue=heading name="Applications"}

## Applications {#Applications}

Global dominating sets arise naturally in network reliability contexts. Consider a graph representing a network of roads connecting various locations, where some locations have supply stations. If the primary links (edges of $G$) may fail, maintaining supply requires that stations can reach all locations through alternative links (edges of $\bar{G}$). A global dominating set represents the minimum set of supply stations needed to maintain service regardless of which network (primary or backup) is operational.[^o2]

In [social network analysis](wikipedia://en/325726), when modeling individuals with certain social behaviors, a standard dominating set identifies influential individuals, but does not account for potential changes in influence relationships. A global dominating set ensures coverage even if the influence network changes to its complement, providing resilience against dynamic network changes.[^o13]

:::
