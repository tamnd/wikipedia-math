# Η set

::: {#o1 .subject cue=lead name="Η set"}

In mathematics, an **[*η*](https://en.wikipedia.org/wiki/Eta) set** (*eta set*) is a type of [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set) introduced by (txt) that generalizes the [order type](wikipedia://en/4499021) *η* of the rational numbers.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $\alpha$ is an ordinal then an $\eta_\alpha$ set is a totally ordered set in which for any two subsets $X$ and $Y$ of [cardinality](wikipedia://en/6174) less than $\aleph_\alpha$, if every element of $X$ is less than every element of $Y$ then there is some element greater than all elements of $X$ and less than all elements of $Y$.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

The only non-empty countable *η*<sub>0</sub> set (up to isomorphism) is the ordered set of rational numbers.

Suppose that *κ* = ℵ<sub>*α*</sub> is a [regular cardinal](wikipedia://en/374128) and let *X* be the set of all functions *f* from *κ* to {−1,0,1} such that if *f*(*α*) = 0 then *f*(*β*) = 0 for all *β* > *α*, ordered [lexicographically](wikipedia://en/567667). Then *X* is a *η*<sub>*α*</sub> set. The direct limit of all these orders is isomorphic to the class of [surreal numbers](wikipedia://en/51432).

A dense totally ordered set without endpoints is an *η*<sub>*α*</sub> set [if and only if](wikipedia://en/14922) it is [ℵ<sub>*α*</sub> saturated](wikipedia://en/535836).

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Any *η*<sub>*α*</sub> set *X* is universal for totally ordered sets of cardinality at most ℵ<sub>*α*</sub>, meaning that any such set can be embedded into *X*.

For any given ordinal *α*, any two *η*<sub>*α*</sub> sets of cardinality ℵ<sub>*α*</sub> are isomorphic (as ordered sets). An *η*<sub>*α*</sub> set of cardinality ℵ<sub>*α*</sub> exists if ℵ<sub>*α*</sub> is regular and Σ<sub>*β*\<*α*</sub> 2<sup>ℵ<sub>*β*</sub></sup> ≤ ℵ<sub>*α*</sub>.

:::
