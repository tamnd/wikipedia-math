# Glossary of set theory

::: {#o1 .subject cue=lead name="Glossary of set theory"}

This is a glossary of terms and definitions related to the topic of [set theory](wikipedia://en/27553).

:::

## Greek {#Greek}

::: {#o3 .entry cue=term name="α"}

**α**

Often used for an ordinal.

:::

::: {#o4 .entry cue=term name="β"}

**β**

$\beta$$X$ is the [Stone–Čech compactification](wikipedia://en/52897) of $X$.

An ordinal.

:::

::: {#o5 .entry cue=term name="γ"}

**γ**

A [gamma number](wikipedia://en/17202420), an [ordinal](wikipedia://en/26547932) of the form $\omega^{\alpha}$.

:::

::: {#o6 .entry cue=term name="Γ"}

**Γ**

The [Gamma function of ordinals](wikipedia://en/16124925). In particular $\Gamma_{0}$ is the [Feferman–Schütte ordinal](wikipedia://en/16084455).

:::

::: {#o7 .entry cue=term name="δ"}

**δ**

A [delta number](https://en.wikipedia.org/wiki/Delta_number) is an ordinal of the form $\omega^{\omega^{\alpha}}$.

A limit ordinal.

:::

::: {#o8 .entry cue=term name="Δ"}

**Δ**

A set of formulas in the [Lévy hierarchy](wikipedia://en/25129404).

A [delta system](https://en.wikipedia.org/wiki/Delta_system)

:::

::: {#o9 .entry cue=term name="ε"}

**ε**

An [epsilon number](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), an ordinal with $\omega^{\varepsilon}=\varepsilon$.

:::

::: {#o10 .entry cue=term name="η"}

**η**

The [order type](wikipedia://en/4499021) of the [rational numbers](wikipedia://en/19727024).

An [eta set](https://en.wikipedia.org/wiki/Eta_set), a type of ordered set.

$\eta_{\alpha}$ is an [Erdős cardinal](wikipedia://en/326540).

:::

::: {#o11 .entry cue=term name="θ"}

**θ**

The [order type](wikipedia://en/4499021) of the [real numbers](wikipedia://en/20646438).

:::

::: {#o12 .entry cue=term name="Θ"}

**Θ**

The supremum of the ordinals that are the image of a function from ${}^{\omega}\omega$ (usually in models where the axiom of choice is not assumed).

:::

::: {#o13 .entry cue=term name="κ"}

**κ**

Often used for a [cardinal](wikipedia://en/6173), especially the critical point of an elementary embedding.

The [Erdős cardinal](wikipedia://en/326540) $\kappa(\alpha)$ is the smallest cardinal such that $\kappa(\alpha) \to (\alpha)^{< \omega}$.

:::

::: {#o14 .entry cue=term name="λ"}

**λ**

Often used for a cardinal.

The order type of the [real numbers](wikipedia://en/20646438).

:::

::: {#o15 .entry cue=term name="μ"}

**μ**

A [measure](wikipedia://en/19873).

:::

::: {#o16 .entry cue=term name="Π"}

**Π**

A product of cardinals.

A set of formulas in the [Lévy hierarchy](wikipedia://en/25129404).

:::

::: {#o17 .entry cue=term name="ρ"}

**ρ**

The [rank of a set](https://en.wikipedia.org/wiki/Rank_of_a_set).

:::

::: {#o18 .entry cue=term name="σ"}

**σ**

countable, as in [σ-compact](https://en.wikipedia.org/wiki/Σ-compact), σ-complete and so on.

:::

::: {#o19 .entry cue=term name="Σ"}

**Σ**

A sum of cardinals.

A set of formulas in the [Lévy hierarchy](wikipedia://en/25129404).

:::

::: {#o20 .entry cue=term name="φ"}

**φ**

A [Veblen function](wikipedia://en/16124925).

:::

::: {#o21 .entry cue=term name="ω"}

**ω**

The smallest infinite ordinal.

$\omega_{\alpha}$ is an alternative name for $\aleph_{\alpha}$, used when it is considered as an ordinal number rather than a cardinal number.

:::

::: {#o22 .entry cue=term name="Ω"}

**Ω**

The class of all ordinals, related to [Cantor's absolute](https://en.wikipedia.org/wiki/Cantor's_absolute).

[Ω-logic](wikipedia://en/13772472) is a form of logic introduced by Hugh Woodin.

## !\$@ {#!$@}

::: {#o24 .entry cue=term name="∈, =, ⊆, ⊇, ⊃, ⊂, ∪, ∩, ∅"}

**∈, =, ⊆, ⊇, ⊃, ⊂, ∪, ∩, ∅**

Standard first-order set theoretical symbols with their usual definitions, ([is a member of](https://en.wikipedia.org/wiki/Element_%28mathematics%29), equals, [is a subset of](wikipedia://en/27631), [is a superset of](https://en.wikipedia.org/wiki/Superset), [is a proper superset of](https://en.wikipedia.org/wiki/Superset), [is a proper subset of](wikipedia://en/27631), union, intersection, empty set)

:::

::: {#o25 .entry cue=term name="∧ ∨ → ↔ ¬ ∀ ∃"}

**∧ ∨ → ↔ ¬ ∀ ∃**

Standard [logical symbols](wikipedia://en/2498388) with their usual definitions; and (conjunction), or (inclusive disjunction), implies (conditional), is equivalent to (biconditional), not (negation), for all (universal quantifier), there exists (existential quantifier).

:::

::: {#o26 .entry cue=term name="≡"}

**≡**

An equivalence, or congruence relation.

:::

::: {#o27 .entry cue=term name="↾"}

**↾**

no 1

$f\text{↾}X$ once denoted the corestriction of a relation, or mapping, but in modern mathematics is the restriction of a relation, or mapping f, to some set X, as-in,

no 2

\1.) $f\text{↾}X\coloneqq\{(x,y):x\in X\text{ and } y\in X$} — the restriction, and corestriction — for a relation $f$ to $X$.

no 3

\2.) $f\text{↾}X\coloneqq\{f(x):x\in X$} — the restriction of the domain — for a mapping $f$ to $X$.

:::

::: {#o28 .entry cue=term name="↿"}

**↿**

$f\text{↿}X$ is the restriction of a relation or mapping $f$, to some set $X$.

:::

::: {#o29 .entry cue=term name="△"}

**△**

For $X\triangle Y$, the symmetric difference of sets X, and Y, as-in, $X\triangle Y\coloneqq\{x:x\in X-Y\text{ or } x\in Y-X$}.

A [diagonal intersection](wikipedia://en/1679121).

:::

::: {#o30 .entry cue=term name="◊"}

**◊**

The [diamond principle](wikipedia://en/691736).

:::

::: {#o31 .entry cue=term name="♣"}

**♣**

A [clubsuit](https://en.wikipedia.org/wiki/Clubsuit) principle.

:::

::: {#o32 .entry cue=term name="□"}

**□**

The [square principle](wikipedia://en/2292730), or Q.E.D. — quod erat demonstrandum — that which was to be demonstrated.

:::

::: {#o33 .entry cue=term name="∘"}

**∘**

The [composition of functions](wikipedia://en/195947)

:::

::: {#o34 .entry cue=term name="⁀"}

**⁀**

$\alpha\text{⁀}b$ is the extension of a sequence $a$, by an element $b$, as-in,

For an α-sequence, $a$, $a\text{⁀}b\coloneqq a\text{⨿}\{b$} such that b is the α-th element of $a$.

:::

::: {#o35 .entry cue=term name="+"}

**\+**

[Addition of ordinals](wikipedia://en/2139226#Addition).

[Addition of cardinals](wikipedia://en/6173#Cardinal_addition).

α<sup>\+</sup> is the successor cardinal, or the least cardinal greater than α.

B<sup>\+</sup> is the poset of nonzero elements of a Boolean algebra B.

The inclusive or operation in a Boolean algebra (in ring theory it is used for the exclusive or operation).

:::

::: {#o36 .entry cue=term name="~"}

**~**

For sets $a$, and $b$, $a\sim b$ is the set of elements of $a$ not in $b$, called the difference of, $a$ and $b$, as-in,

$a\sim b\coloneqq\{\alpha:\alpha\in a\text{ and } \alpha\notin b$}.

An equivalence relation.

:::

::: {#o37 .entry cue=term name="&setminus;"}

**∖**

Synonym of ~.

:::

::: {#o38 .entry cue=term name="−"}

**−**

Synonym of ~.

:::

::: {#o39 .entry cue=term name="≈"}

**≈**

Has the [same cardinality](https://en.wikipedia.org/wiki/Equinumerosity) as.

:::

::: {#o40 .entry cue=term name="×"}

**×**

For sets $a$, and $b$, $a\times b\coloneqq\{(c,d):c\in a\text{ and } d\in b$}, called the [product of sets](https://en.wikipedia.org/wiki/Product_of_sets) $a$, and $b$.

:::

::: {#o41 .entry cue=term name="/"}

**/**

For a set $a$, and an equivalence relation $\sim$, $a/\sim\coloneqq\{b/\sim:b\in a$}, called the quotient of a set by an [equivalence relation](wikipedia://en/9259) ~.

:::

::: {#o42 .entry cue=term name="×"}

**×**

For ordinals $a$, and $b$, $a\times b\coloneqq\text{𝙾}\text{𝚛}\text{𝚍}(a\times b)$ called the ordinal product of ordinals $a$, and $b$.

:::

::: {#o43 .entry cue=term name="⊗"}

**⊗**

For cardinals $a$, and $b$, $a\otimes b\coloneqq\text{𝙲}\text{𝚛}\text{𝚍}(a\times b)$, called the cardinal product of cardinals $a$, and $b$.

:::

::: {#o44 .entry cue=term name="*"}

**\**

An operation that takes a forcing poset and a name for a forcing poset and produces a new forcing poset.

:::

::: {#o45 .entry cue=term name="∞"}

**∞**

The class of all ordinals, or at least something larger than all ordinals

:::

::: {#o46 .entry cue=term name="\\alpha^\\beta"}

**$\alpha^\beta$**

Cardinal exponentiation

Ordinal exponentiation

:::

::: {#o47 .entry cue=term name="{}^\\beta\\alpha"}

**${}^\beta\alpha$**

The set of functions from *β* to *α*

:::

::: {#o48 .entry cue=term name="→"}

**→**

Implies

$f: X \to Y$ means *f* is a function from *X* to *Y*.

The [ordinary partition symbol](https://en.wikipedia.org/wiki/Ordinary_partition_symbol), where $\kappa\to(\lambda)^{n}_{m}$ means that for every coloring of the *n*-element subsets of $\kappa$ with *m* colors there is a subset of size λ all of whose *n*-element subsets are the same color.

:::

::: {#o49 .entry cue=term name="f&prime;x"}

**f*′*x**

If there is a unique *y* such that ⟨*x*,*y*⟩ is in *f* then $fx$ is *y*, otherwise it is the empty set. So if *f* is a function and *x* is in its domain, then $fx$ is *f*(*x*).

:::

::: {#o50 .entry cue=term name="fX"}

**f**X**

$fX$ is the image of a set *X* by *f*. If *f* is a function whose domain contains *X* this is $\{f(x):x\in X\}$

:::

::: {#o51 .entry cue=term name="[ ]"}

**\[ \]**

*M*\[*G*\] is the smallest model of ZF containing *G* and all elements of *M*.

\[*α*\]<sup>*β*</sup> is the set of all subsets of a set *α* of cardinality *β*, or of an ordered set *α* of order type *β*

\[*x*\] is the equivalence class of *x*

:::

::: {#o52 .entry cue=term name="{ }"}

**{ }**

{*a*, *b*, ...} is the set with elements *a*, *b*, ...

{*x* : *φ*(*x*)} is the set of *x* such that *φ*(*x*)

:::

::: {#o53 .entry cue=term name="⟨ ⟩"}

**⟨ ⟩**

⟨*a*,*b*⟩ is an [ordered pair](wikipedia://en/22362), and similarly for ordered *n*-tuples

:::

::: {#o54 .entry cue=term name="|X|"}

**$|X|$**

The cardinality of a set *X*

:::

::: {#o55 .entry cue=term name="\\|\\varphi\\|"}

**$\|\varphi\|$**

The value of a formula *φ* in some Boolean algebra

:::

::: {#o56 .entry cue=term name="⌜φ⌝"}

**⌜*φ*⌝**

⌜*φ*⌝ ([Quine quotes](https://en.wikipedia.org/wiki/Quine_quotes), unicode U+231C, U+231D) is the [Gödel number](https://en.wikipedia.org/wiki/Gödel_number) of a formula *φ*

**⊦**

::: {#o58 .entry cue=term name="⊧"}

**⊧**

$A\text{⊧}\varphi$ means that the formula *φ* holds in the [model](wikipedia://en/19858) *A*

::: {#o59 .entry cue=term name="⊩"}

**⊩**

::: {#o60 .entry cue=term name="≺"}

**≺**

:::

::: {#o61 .entry cue=term name="⊥"}

**⊥**

The [false](wikipedia://en/229823) symbol

*p*⊥*q* means that *p* and *q* are incompatible elements of a partial order

::: {#o62 .entry cue=term name="0#"}

## A {#A}

::: {#o69 .entry cue=term name="𝔞"}

::: {#o70 .entry cue=term name="A"}

**A**

The [Suslin operation](https://en.wikipedia.org/wiki/Suslin_operation)

:::

::: {#o71 .entry cue=term name="absolute"}

**absolute**

A statement is called [absolute](wikipedia://en/12374236) if its truth in some model implies its truth in certain related models

Cantor's absolute is a somewhat unclear concept sometimes used to mean the class of all sets

Cantor's [Absolute infinite](wikipedia://en/3231) Ω is a somewhat unclear concept related to the class of all ordinals

:::

::: {#o72 .entry cue=term name="AC"}

**AC**

AC is the [Axiom of choice](wikipedia://en/840)

AC<sub>*ω*</sub> is the [Axiom of countable choice](wikipedia://en/421086)

:::

::: {#o73 .entry cue=term name="AD"}

**AD**

The [axiom of determinacy](wikipedia://en/1002300)

:::

::: {#o74 .entry cue=term name="add"}

**add**

:::

::: {#o75 .entry cue=term name="additivity"}

**additivity**

The additivity $\operatorname{add}(I)$ of $I$ is the smallest number of sets of $I$ with union not in $I$

:::

::: {#o76 .entry cue=term name="additively"}

**additively**

An ordinal is called [additively indecomposable](https://en.wikipedia.org/wiki/Additively_indecomposable) if it is not the sum of a finite number of smaller ordinals. These are the same as [gamma numbers](wikipedia://en/17202420) or powers of *ω*.

:::

::: {#o77 .entry cue=term name="admissible"}

**admissible**

An [admissible set](wikipedia://en/5138993) is a model of Kripke–Platek set theory, and an [admissible ordinal](wikipedia://en/4635859) is an ordinal α such that *L*<sub>*α*</sub> is an admissible set

:::

::: {#o78 .entry cue=term name="AH"}

**AH**

The [generalized continuum hypothesis](https://en.wikipedia.org/wiki/Generalized_continuum_hypothesis) states that 2<sup>ℵ<sub>*α*</sub></sup> = ℵ<sub>*α*+1</sub>

:::

::: {#o79 .entry cue=term name="aleph"}

**aleph**

The Hebrew letter [ℵ](https://en.wikipedia.org/wiki/Aleph)

An infinite cardinal

The [aleph function](https://en.wikipedia.org/wiki/Aleph_function) taking ordinals to infinite cardinals

The [aleph hypothesis](https://en.wikipedia.org/wiki/Aleph_hypothesis) is a form of the generalized continuum hypothesis

:::

::: {#o80 .entry cue=term name="almost universal"}

**almost universal**

A class is called [almost universal](https://en.wikipedia.org/wiki/Almost_universal) if every subset of it is contained in some member of it

:::

::: {#o81 .entry cue=term name="amenable"}

**amenable**

An [amenable set](https://en.wikipedia.org/wiki/Amenable_set) is a set that is a model of Kripke–Platek set theory without the axiom of collection

:::

::: {#o82 .entry cue=term name="analytic"}

**analytic**

An [analytic set](wikipedia://en/634261) is the continuous image of a Polish space. (This is not the same as an analytical set)

:::

::: {#o83 .entry cue=term name="analytical"}

**analytical**

The [analytical hierarchy](wikipedia://en/634233) is a hierarchy of subsets of an effective Polish space (such as *ω*). They are definable by a second-order formula without parameters, and an analytical set is a set in the analytical hierarchy. (This is not the same as an analytic set)

:::

::: {#o84 .entry cue=term name="antichain"}

**antichain**

An [antichain](wikipedia://en/348973) is a set of pairwise incompatible elements of a poset

:::

::: {#o85 .entry cue=term name="anti-foundation axiom"}

**[anti-foundation axiom](wikipedia://en/8933657)**

An axiom in set theory that allows for the existence of non-well-founded sets, in contrast to the traditional [foundation axiom](wikipedia://en/2113) which prohibits such sets.

:::

::: {#o86 .entry cue=term name="antinomy"}

**antinomy**

paradox

:::

::: {#o87 .entry cue=term name="arithmetic"}

**arithmetic**

The [ordinal arithmetic](wikipedia://en/2139226) is arithmetic on [ordinal numbers](wikipedia://en/26547932)

The [cardinal arithmetic](https://en.wikipedia.org/wiki/Cardinal_arithmetic) is arithmetic on [cardinal numbers](wikipedia://en/6173)

:::

::: {#o88 .entry cue=term name="arithmetical"}

**arithmetical**

The [arithmetical hierarchy](wikipedia://en/186475) is a hierarchy of subsets of a Polish space that can be defined by first-order formulas

:::

::: {#o89 .entry cue=term name="Aronszajn"}

**Aronszajn**

[Nachman Aronszajn](wikipedia://en/13496987)

An [Aronszajn tree](wikipedia://en/12774077) is an uncountable tree such that all branches and levels are countable. More generally a *κ*-[Aronszajn tree](wikipedia://en/12774077) is a tree of cardinality *κ* such that all branches and levels have cardinality less than *κ*

:::

::: {#o90 .entry cue=term name="atom"}

**atom**

An [urelement](wikipedia://en/643648), something that is not a set but allowed to be an element of a set

An element of a poset such that any two elements smaller than it are compatible.

A set of positive measure such that every measurable subset has the same measure or measure 0

:::

::: {#o91 .entry cue=term name="atomic"}

**atomic**

An atomic formula (in set theory) is one of the form *x*=*y* or *x*∈*y*

:::

::: {#o92 .entry cue=term name="axiom"}

**axiom**

[Aczel's anti-foundation axiom](wikipedia://en/8933657) states that every accessible pointed directed graph corresponds to a unique set

[AD+](wikipedia://en/2818935) An extension of the axiom of determinacy

[Axiom F](https://en.wikipedia.org/wiki/Axiom_F) states that the class of all ordinals is Mahlo

[Axiom of adjunction](wikipedia://en/43548952) Adjoining a set to another set produces a set

[Axiom of amalgamation](https://en.wikipedia.org/wiki/Axiom_of_amalgamation) The union of all elements of a set is a set. Same as axiom of union

[Axiom of choice](wikipedia://en/840) The product of any set of non-empty sets is non-empty

[Axiom of collection](https://en.wikipedia.org/wiki/Axiom_of_collection) This can mean either the axiom of replacement or the axiom of separation

[Axiom of comprehension](https://en.wikipedia.org/wiki/Axiom_of_comprehension) The class of all sets with a given property is a set. Usually contradictory.

[Axiom of constructibility](wikipedia://en/696472) Any set is constructible, often abbreviated as *V*=*L*

[Axiom of countability](wikipedia://en/346611) Every set is hereditarily countable

[Axiom of countable choice](wikipedia://en/421086) The product of a countable number of non-empty sets is non-empty

[Axiom of dependent choice](wikipedia://en/441950) A weak form of the axiom of choice

[Axiom of determinacy](wikipedia://en/1002300) Certain games are determined, in other words one player has a winning strategy

[Axiom of elementary sets](https://en.wikipedia.org/wiki/Axiom_of_elementary_sets) describes the sets with 0, 1, or 2 elements

[Axiom of empty set](wikipedia://en/52534) The empty set exists

[Axiom of extensionality](wikipedia://en/52376) or axiom of extent

[Axiom of finite choice](wikipedia://en/53055349) Any product of non-empty finite sets is non-empty

[Axiom of foundation](https://en.wikipedia.org/wiki/Axiom_of_foundation) Same as axiom of regularity

[Axiom of global choice](wikipedia://en/5322320) There is a global choice function

[Axiom of heredity](https://en.wikipedia.org/wiki/Axiom_of_heredity) (any member of a set is a set; used in Ackermann's system.)

[Axiom of infinity](wikipedia://en/246449) There is an infinite set

[Axiom of limitation of size](wikipedia://en/5322450) A class is a set if and only if it has smaller cardinality than the class of all sets

[Axiom of pairing](wikipedia://en/52385) Unordered pairs of sets are sets

[Axiom of power set](wikipedia://en/52552) The powerset of any set is a set

[Axiom of projective determinacy](https://en.wikipedia.org/wiki/Axiom_of_projective_determinacy) Certain games given by projective set are determined, in other words one player has a winning strategy

[Axiom of real determinacy](wikipedia://en/1121647) Certain games are determined, in other words one player has a winning strategy

[Axiom of regularity](wikipedia://en/2113) Sets are well founded

[Axiom of replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement) The image of a set under a function is a set. Same as axiom of substitution

[Axiom of subsets](https://en.wikipedia.org/wiki/Axiom_of_subsets) The powerset of a set is a set. Same as axiom of powersets

[Axiom of substitution](https://en.wikipedia.org/wiki/Axiom_of_substitution) The image of a set under a function is a set

[Axiom of union](wikipedia://en/52553) The union of all elements of a set is a set

[Axiom schema of predicative separation](wikipedia://en/17773501) Axiom of separation for formulas whose quantifiers are bounded

[Axiom schema of replacement](wikipedia://en/52387) The image of a set under a function is a set

[Axiom schema of separation](https://en.wikipedia.org/wiki/Axiom_schema_of_separation) The elements of a set with some property form a set

[Axiom schema of specification](wikipedia://en/52386) The elements of a set with some property form a set. Same as axiom schema of separation

[Freiling's axiom of symmetry](wikipedia://en/162267) is equivalent to the negation of the continuum hypothesis

[Martin's axiom](wikipedia://en/1550783) states very roughly that cardinals less than the cardinality of the continuum behave like ℵ<sub>0</sub>.

The [proper forcing axiom](wikipedia://en/6250799) is a strengthening of Martin's axiom

**[stratified](wikipedia://en/571280)**

A formula of set theory is stratified if and only if there is a function $\sigma$ which sends each variable appearing in $\phi$ (considered as an item of syntax) to a natural number (this works equally well if all integers are used) in such a way that any atomic formula $x \in y$ appearing in $\phi$ satisfies $\sigma(x)+1 = \sigma(y)$ and any [atomic formula](wikipedia://en/4472066) $x = y$ appearing in $\phi$ satisfies $\sigma(x) = \sigma(y)$.

::: {#o487 .entry cue=term name="Suslin"}

**Suslin**

[Mikhail Yakovlevich Suslin](https://en.wikipedia.org/wiki/Mikhail_Yakovlevich_Suslin) (sometimes written Souslin)

A [Suslin cardinal](wikipedia://en/7652107) is a cardinal *λ* such that there exists a set *P* ⊂ 2<sup>*ω*</sup> such that *P* is *λ*-Suslin but *P* is not *λ*′-Suslin for any *λ*′ \< *λ*.

The [Suslin hypothesis](https://en.wikipedia.org/wiki/Suslin_hypothesis) says that Suslin lines do not exist

A [Suslin line](https://en.wikipedia.org/wiki/Suslin_line) is a complete dense unbounded totally ordered set satisfying the countable chain condition

The [Suslin number](https://en.wikipedia.org/wiki/Suslin_number) is the supremum of the cardinalities of families of disjoint open non-empty sets

The [Suslin operation](https://en.wikipedia.org/wiki/Suslin_operation), usually denoted by *A*, is an operation that constructs a set from a Suslin scheme

The [Suslin problem](https://en.wikipedia.org/wiki/Suslin_problem) asks whether Suslin lines exist

The [Suslin property](https://en.wikipedia.org/wiki/Suslin_property) states that there is no uncountable family of pairwise disjoint non-empty open subsets

A [Suslin representation](wikipedia://en/7652984) of a set of reals is a tree whose projection is that set of reals

A [Suslin scheme](https://en.wikipedia.org/wiki/Suslin_scheme) is a function with domain the finite sequences of positive integers

A [Suslin set](https://en.wikipedia.org/wiki/Suslin_set) is a set that is the image of a tree under a certain projection

A [Suslin space](https://en.wikipedia.org/wiki/Suslin_space) is the image of a Polish space under a continuous mapping

A [Suslin subset](https://en.wikipedia.org/wiki/Suslin_subset) is a subset that is the image of a tree under a certain projection

The [Suslin theorem](wikipedia://en/634261) about analytic sets states that a set that is analytic and coanalytic is Borel

A [Suslin tree](wikipedia://en/5028195) is a tree of height ω<sub>1</sub> such that every branch and every antichain is at most countable.
