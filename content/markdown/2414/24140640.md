# Smoothness (probability theory)

::: {#o1 .subject cue=lead name="Smoothness"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), **smoothness** of a [density function](https://en.wikipedia.org/wiki/Density_function) is a measure which determines how many times the density function can be differentiated, or equivalently the limiting behavior of distribution’s [characteristic function](wikipedia://en/3229401).

:::

Formally, we call the distribution of a [random variable](wikipedia://en/25685) *X* **ordinary smooth** of order *β* [^o2] if its [characteristic function](wikipedia://en/3229401) satisfies

$$d_0 |t|^{-\beta} \leq |\varphi_X(t)| \leq d_1 |t|^{-\beta} \quad \text{as } t\to\infty$$

for some positive constants *d*<sub>0</sub>, *d*<sub>1</sub>, *β*. The examples of such distributions are [gamma](wikipedia://en/207079), [exponential](wikipedia://en/45906), [uniform](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29), etc.

The distribution is called **supersmooth** of order *β* [^o2] if its characteristic function satisfies

$$d_0 |t|^{\beta_0}\exp\big(-|t|^\beta/\gamma\big) \leq |\varphi_X(t)| \leq d_1 |t|^{\beta_1}\exp\big(-|t|^\beta/\gamma\big) \quad \text{as } t\to\infty$$

for some positive constants *d*<sub>0</sub>, *d*<sub>1</sub>, *β*, *γ* and constants *β*<sub>0</sub>, *β*<sub>1</sub>. Such supersmooth distributions have derivatives of all orders. Examples: [normal](wikipedia://en/21462), [Cauchy](wikipedia://en/7003), mixture normal.
