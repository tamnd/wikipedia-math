# Semitopological group

::: {#o1 .subject cue=lead name="Semitopological group"}

In [mathematics](wikipedia://en/18831), a **semitopological group** is a [topological space](wikipedia://en/30450) with a [group operation](wikipedia://en/19447) that is [continuous](wikipedia://en/6122#Continuous_functions_between_topological_spaces) with respect to each variable considered separately. It is a weakening of the concept of a [topological group](wikipedia://en/42315); all topological groups are semitopological groups but the [converse](wikipedia://en/155941) does not hold.

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A semitopological group $G$ is a topological space that is also a [group](wikipedia://en/19447) such that

$$g_1: G \times G \to G : (x,y)\mapsto xy$$

is continuous with respect to both $x$ and $y$. (Note that a topological group is continuous with reference to both variables simultaneously, and $g_2: G\to G : x \mapsto x^{-1}$ is also required to be continuous. Here $G \times G$ is viewed as a topological space with the [product topology](wikipedia://en/24910).)[^o4]

Clearly, every topological group is a semitopological group. To see that the converse does not hold, consider the [real line](https://en.wikipedia.org/wiki/Real_line) $(\mathbb{R},+)$ with its usual structure as an additive [abelian group](wikipedia://en/2974). Apply the [lower limit topology](wikipedia://en/310517) to $\mathbb{R}$ with [topological basis](https://en.wikipedia.org/wiki/Topological_basis) the family $\{[a,b):-\infty < a < b < \infty \}$. Then $g_1$ is continuous, but $g_2$ is not continuous at 0: $[0,b)$ is an [open neighbourhood](https://en.wikipedia.org/wiki/Open_neighbourhood) of 0 but there is no neighbourhood of 0 contained in $g_2^{-1}([0,b))$.

It is known that any [locally compact](https://en.wikipedia.org/wiki/Locally_compact) Hausdorff semitopological group is a topological group.[^o5] Other similar results are also known.[^o6]
