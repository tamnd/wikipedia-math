# Tame manifold

::: {#o1 .subject cue=lead name="Tame manifold"}

Tame topology In [geometry](wikipedia://en/18973446), a **tame manifold** is a [manifold](wikipedia://en/2073470) with a well-behaved [compactification](wikipedia://en/6617). More precisely, a manifold $M$ is called tame if it is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to a [compact manifold](https://en.wikipedia.org/wiki/Compact_manifold) with a [closed subset](wikipedia://en/47279) of the boundary removed.

:::

The [Whitehead manifold](wikipedia://en/1192013) is an example of a contractible manifold that is not tame.
