# Hamiltonian simulation

::: {#o1 .subject cue=lead name="Hamiltonian simulation"}

Quantum simulator **Hamiltonian simulation** (also referred to as **quantum simulation**) is a problem in [quantum information science](https://en.wikipedia.org/wiki/Quantum_information_science) that attempts to find the [computational complexity](wikipedia://en/6511) and [quantum algorithms](https://en.wikipedia.org/wiki/Quantum_algorithm) needed for simulating quantum systems. Hamiltonian simulation is a problem that demands algorithms which implement the evolution of a [quantum state](wikipedia://en/30876419) efficiently. The Hamiltonian simulation problem was proposed by [Richard Feynman](wikipedia://en/25523) in 1982, where he proposed a [quantum computer](https://en.wikipedia.org/wiki/Quantum_computer) as a possible solution since the simulation of general Hamiltonians seem to grow exponentially with respect to the system size.[^o2]

:::

## Problem statement {#Problem_statement}

In the Hamiltonian simulation problem, given a [Hamiltonian](wikipedia://en/14381) $H$ ($2^n \times 2^n$ [hermitian matrix](wikipedia://en/189682) acting on $n$ qubits), a time $t$ and maximum simulation error $\epsilon$, the goal is to find an algorithm that approximates $U$ such that $||U - e^{-iHt} || \leq \epsilon$, where $e^{-iHt}$ is the ideal evolution and $||\cdot||$ is the [spectral norm](https://en.wikipedia.org/wiki/Spectral_norm). A special case of the Hamiltonian simulation problem is the local Hamiltonian simulation problem. This is when $H$ is a k-local Hamiltonian on $n$ qubits where $H = \sum_{j \mathop =1}^m H_j$ and $H_j$ acts [non-trivially](wikipedia://en/193053) on at most $k$ qubits instead of $n$ qubits.[^o4] The local Hamiltonian simulation problem is important because most Hamiltonians that occur in nature are k-local.[^o4]

## Techniques {#Techniques}

::: {#o7 .statement cue=named-heading name="Product formulas"}

### Product formulas {#Product_formulas}

Also known as [Trotter formulas](wikipedia://en/19680272) or Trotter–Suzuki decompositions, Product formulas simulate the sum-of-terms of a Hamiltonian by simulating each one separately for a small time slice.[^o8][^o9] If $H = A + B + C$, then $U = e^{-i(A + B + C)t}$ is well-approximated by $(e^{-iAt/r}e^{-iBt/r}e^{-iCt/r})^r$ for a large $r$; where $r$ is the number of time steps to simulate for. The larger the $r$, the more accurate the simulation.

If the Hamiltonian is represented as a [Sparse matrix](wikipedia://en/341015), the distributed [edge coloring](wikipedia://en/690647) algorithm can be used to decompose it into a sum of terms; which can then be simulated by a Trotter–Suzuki algorithm.[^o19]

:::

### Taylor series {#Taylor_series}

$e^{-iHt} = \sum_{n \mathop = 0}^ \infty \frac{(-iHt)^{n}}{n!} = I - iHt - \frac{H^{2}t^{2}}{2} + \frac{iH^{3}t^{3}}{6} + \cdots$ by the [Taylor series](wikipedia://en/30448) expansion.[^o11] This says that during the evolution of a quantum state, the Hamiltonian is applied over and over again to the system with a various number of repetitions. The first term is the [identity matrix](wikipedia://en/59718) so the system doesn't change when it is applied, but in the second term the Hamiltonian is applied once. For practical implementations, the series has to be truncated $\left( \sum_{n \mathop = 0}^N \frac{(-iHt)^{n}}{n!} \right)$, where the bigger the $N$, the more accurate the simulation.[^o17] This truncated expansion is then implemented via the [linear combination](wikipedia://en/55632) of unitaries (LCU) technique for Hamiltonian simulation.[^o11] Namely, one decomposes the Hamiltonian $H = \sum_{\ell=1}^L \alpha_\ell H_\ell$ such that each $H_\ell$ is unitary (for instance, the Pauli operators always provide such a basis), and so each $H^n = \sum_{\ell_1,\ldots,\ell_n=1}^L \alpha_{\ell_1} \cdots \alpha_{\ell_n} H_{\ell_1} \cdots H_{\ell_n}$ is also a linear combination of unitaries.

### Quantum walk {#Quantum_walk}

In the [quantum walk](wikipedia://en/12485744), a unitary operation whose spectrum is related to the Hamiltonian is implemented then the [Quantum phase estimation algorithm](wikipedia://en/28615265) is used to adjust the eigenvalues. This makes it unnecessary to decompose the Hamiltonian into a sum-of-terms like the Trotter-Suzuki methods.[^o11]

### Quantum signal processing {#Quantum_signal_processing}

The quantum signal processing algorithm works by transducing the eigenvalues of the Hamiltonian into an ancilla qubit, transforming the eigenvalues with single qubit rotations and finally projecting the ancilla.[^o14] It has been proved to be optimal in query complexity when it comes to Hamiltonian simulation.[^o14]

## Complexity {#Complexity}

The table of the complexities of the Hamiltonian simulation algorithms mentioned above. The Hamiltonian simulation can be studied in two ways. This depends on how the Hamiltonian is given. If it is given explicitly, then gate complexity matters more than query complexity. If the Hamiltonian is described as an Oracle ([black box](https://en.wikipedia.org/wiki/Black_box)) then the number of queries to the oracle is more important than the gate count of the circuit. The following table shows the gate and query complexity of the previously mentioned techniques.

::: {#o16 .table cue=table}

| Technique | Gate complexity | Query complexity |
|---|---|---|
| Product formula 1st order | $O\left(\frac{t^{2}}{\epsilon}\right)$[^o17] | $O\left(d^{3} t \left(\frac{dt}{\epsilon}\right)^{\frac{1}{2}k}\right)$[^o18] |
| Taylor series | $O\left(\frac{t \log^{2}\left(\frac{t}{\epsilon}\right)}{\log \log \frac{t}{\epsilon}}\right)$[^o17] | $O\left(\frac{d^{2} \|\|H\|\|_{\rm max} \log{\frac{d^{2} \|\|H\|\|_{max}}{\epsilon}}}{\log \log{\frac{d^{2} \|\|H\|\|_{\rm max}}{\epsilon}}}\right)$[^o11] |
| Quantum walk | $O\left(\frac{t}{\sqrt{\epsilon}}\right)$[^o17] | $O\left(d \|\| H\|\|_{\rm max} \frac{t}{\sqrt{\epsilon}}\right)$[^o19] |
| Quantum signal processing | $O\left(t + \log{\frac{1}{\epsilon}}\right)$[^o17] | $O\left(t d \|\| H\|\|_{\rm max} + \frac{\log{\frac{1}{\epsilon}}}{\log \log {\frac{1}{\epsilon}}}\right)$[^o14] |

:::

Where $||H||_{\rm max}$ is the largest entry of $H$.
