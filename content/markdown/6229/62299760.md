# Order polytope

::: {#o1 .subject cue=lead name="Order polytope"}

In mathematics, the **order polytope** of a finite [partially ordered set](wikipedia://en/23572) is a [convex polytope](wikipedia://en/1817885) defined from the set. The points of the order polytope are the [monotonic functions](wikipedia://en/48260) from the given set to the [unit interval](wikipedia://en/49324), its vertices correspond to the [upper sets](https://en.wikipedia.org/wiki/Upper_set) of the partial order, and its dimension is the number of elements in the partial order. The order polytope is a [distributive polytope](wikipedia://en/62299758), meaning that coordinatewise minima and maxima of pairs of its points remain within the polytope.

:::

The order polytope of a partial order should be distinguished from the *linear ordering polytope*, a polytope defined from a number $n$ as the [convex hull](wikipedia://en/40634) of [indicator vectors](wikipedia://en/41904209) of the sets of edges of $n$-vertex [transitive tournaments](https://en.wikipedia.org/wiki/Transitive_tournament).

::: {#o3 .definition cue=heading name="Definition and example"}

## Definition and example {#Definition_and_example}

A [partially ordered set](wikipedia://en/23572) is a pair $(S,\le)$ where $S$ is an arbitrary set and $\le$ is a [binary relation](wikipedia://en/3931) on pairs of elements of $S$ that is reflexive (for all $x\in S$, $x\le x$), antisymmetric (for all $x,y\in S$ with $x\ne y$ at most one of $x\le y$ and $y\le x$ can be true), and transitive (for all $x,y,z\in S$, if $x\le y$ and $y\le z$ then $x\le z$).

A partially ordered set $(S,\le)$ is said to be finite when $S$ is a [finite set](wikipedia://en/11742). In this case, the collection of all functions $f$ that map $S$ to the [real numbers](wikipedia://en/20646438) forms a finite-dimensional [vector space](wikipedia://en/32370), with [pointwise addition](https://en.wikipedia.org/wiki/Pointwise_addition) of functions as the vector sum operation. The dimension of the space is just the number of elements of $S$. The order polytope is defined to be the subset of this space consisting of functions $f$ with the following two properties:

- For every $x\in S$, $0\le f(x)\le 1$. That is, $f$ maps the elements of $S$ to the [unit interval](wikipedia://en/49324).
- For every $x,y\in S$ with $x\le y$, $f(x)\le f(y)$. That is, $f$ is a [monotonic function](wikipedia://en/48260)

For example, for a partially ordered set consisting of two elements $x$ and $y$, with $x \le y$ in the partial order, the functions $f$ from these points to real numbers can be identified with points $(f(x),f(y))$ in the [Cartesian plane](https://en.wikipedia.org/wiki/Cartesian_plane). For this example, the order polytope consists of all points in the $(x,y)$-plane with $0\le x\le y \le 1$. This is an [isosceles right triangle](https://en.wikipedia.org/wiki/Isosceles_right_triangle) with vertices at (0,0), (0,1), and (1,1).

:::

## Vertices and facets {#Vertices_and_facets}

The vertices of the order polytope consist of monotonic functions from $S$ to $\{0,1\}$. That is, the order polytope is an [integral polytope](wikipedia://en/25293116); it has no vertices with [fractional coordinates](https://en.wikipedia.org/wiki/Fractional_coordinates). These functions are exactly the [indicator functions](wikipedia://en/240790) of [upper sets](https://en.wikipedia.org/wiki/Upper_set) of the partial order. Therefore, the number of vertices equals the number of upper sets.

The [facets](wikipedia://en/7186647) of the order polytope are of three types:

- Inequalities $0\le f(x)$ for each minimal element $x$ of the partially ordered set,
- Inequalities $f(y)\le 1$ for each maximal element $y$ of the partially ordered set, and
- Inequalities $f(x)\le f(y)$ for each two distinct elements $x,y$ that do not have a third distinct element $z$ between them; that is, for each pair $(x,y)$ in the [covering relation](wikipedia://en/14835049) of the partially ordered set.

The facets can be considered in a more symmetric way by introducing special elements $\bot$ below all elements in the partial order and $\top$ above all elements, mapped by $f$ to 0 and 1 respectively, and keeping only inequalities of the third type for the resulting augmented partially ordered set.

More generally, with the same augmentation by $\bot$ and $\top$, the faces of all dimensions of the order polytope correspond 1-to-1 with quotients of the partial order. Each face is congruent to the order polytope of the corresponding quotient partial order.

## Volume and Ehrhart polynomial {#Volume_and_Ehrhart_polynomial}

The order polytope of a [linear order](https://en.wikipedia.org/wiki/Linear_order) is a special type of [simplex](wikipedia://en/39781) called an **order simplex** or [orthoscheme](wikipedia://en/20740340). Each point of the [unit cube](wikipedia://en/407763) whose coordinates are all distinct lies in a unique one of these orthoschemes, the order simplex for the linear order of its coordinates. Because these order simplices are all [congruent](wikipedia://en/39330) to each other and (for orders on $n$ elements) there are $n!$ different linear orders, the [volume](wikipedia://en/32498) of each order simplex is $1/n!$. More generally, an order polytope can be partitioned into order simplices in a canonical way, with one simplex for each [linear extension](wikipedia://en/11726298) of the corresponding partially ordered set. Therefore, the volume of any order polytope is $1/n!$ multiplied by the number of linear extensions of the corresponding partially ordered set. This connection between the number of linear extensions and volume can be used to approximate the number of linear extensions of any partial order efficiently (despite the fact that computing this number exactly is [\#P-complete](wikipedia://en/27925)) by applying a [randomized polynomial-time approximation scheme](wikipedia://en/666431#Randomized) for polytope volume.

The [Ehrhart polynomial](wikipedia://en/316904) of the order polytope is a polynomial whose values at [integer](wikipedia://en/14563) values $x$ give the number of integer points in a copy of the polytope scaled by a factor of $x$. For the order polytope, the Ehrhart polynomial equals (after a minor change of variables) the [order polynomial](wikipedia://en/49666935) of the corresponding partially ordered set. This polynomial encodes several pieces of information about the polytope including its volume (the leading coefficient of the polynomial and its number of vertices (the sum of coefficients).

## Continuous lattice {#Continuous_lattice}

By [Birkhoff's representation theorem](wikipedia://en/20489385) for finite [distributive lattices](wikipedia://en/310883), the [upper sets](https://en.wikipedia.org/wiki/Upper_set) of any partially ordered set form a finite distributive lattice, and every finite distributive lattice can be represented in this way. The upper sets correspond to the vertices of the order polytope, so the mapping from upper sets to vertices provides a geometric representation of any finite distributive lattice. Under this representation, the edges of the polytope connect comparable elements of the lattice.

If two functions $p$ and $q$ both belong to the order polytope of a partially ordered set $(S,\le)$, then the function $p\wedge q$ that maps $x$ to $\min(p(x),q(x))$, and the function $p\vee q$ that maps $x$ to $\max(p(x),q(x))$ both also belong to the order polytope. The two operations $\wedge$ and $\vee$ give the order polytope the structure of a continuous [distributive lattice](wikipedia://en/310883), within which the finite distributive lattice of Birkhoff's theorem is embedded. That is, every order polytope is a [distributive polytope](wikipedia://en/62299758). The distributive polytopes with all vertex coordinates equal to 0 or 1 are exactly the order polytopes.
