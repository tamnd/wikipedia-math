# Set-theoretic definition of natural numbers

::: {#o1 .subject cue=lead name="Set-theoretic definition of natural numbers"}

In [set theory](wikipedia://en/27553), several ways have been proposed to construct the [natural numbers](wikipedia://en/21474). These include the representation via [von Neumann ordinals](https://en.wikipedia.org/wiki/Von_Neumann_ordinal), commonly employed in [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), and a system based on [equinumerosity](https://en.wikipedia.org/wiki/Equinumerosity) that was proposed by [Gottlob Frege](wikipedia://en/48416) and by [Bertrand Russell](wikipedia://en/4163).

:::

## Definition as von Neumann ordinals {#Definition_as_von_Neumann_ordinals}

In [Zermelo–Fraenkel (ZF) set theory](wikipedia://en/152214), the natural numbers are defined [recursively](https://en.wikipedia.org/wiki/Recursively) by letting 0 = {} be the [empty set](wikipedia://en/9566) and *n* + 1 (the successor function) = *n* ∪ {*n*} for each *n*. In this way *n* = {0, 1, …, *n* − 1} for each natural number *n*. This definition has the property that *n* is a [set](wikipedia://en/26691) with *n* elements. The first few numbers defined this way are: (Goldrei 1996)

$$\begin{alignedat}{2} 0 & {} = \{\} && {} = \varnothing,\\ 1 & {} = \{0\} && {} = \{\varnothing\},\\ 2 & {} = \{0,1\} && {} = \{\varnothing,\{\varnothing\}\},\\ 3 & {} = \{0,1,2\} && {} = \{\varnothing,\{\varnothing\},\{\varnothing,\{\varnothing\}\}\}. \end{alignedat}$$

The set *N* of natural numbers is defined in this system as the smallest set containing 0 and closed under the [successor function](wikipedia://en/325637) *S* defined by *S*(*n*) = *n* ∪ {*n*}. The [structure](wikipedia://en/4055928) ⟨*N*, 0, *S*⟩ is a model of the [Peano axioms](wikipedia://en/25005) (Goldrei 1996). The existence of the set *N* is equivalent to the [axiom of infinity](wikipedia://en/246449) in ZF set theory.

The set *N* and its elements, when constructed this way, are an initial part of the von Neumann ordinals. [W. V. O. Quine](https://en.wikipedia.org/wiki/W._V._O._Quine) refers to these sets as "counter sets".[^o5]

## Frege and Russell {#Frege_and_Russell}

Gottlob Frege and Bertrand Russell each proposed defining a natural number *n* as the collection of all sets with *n* elements. More formally, a natural number is an [equivalence class](wikipedia://en/9260) of finite sets under the [equivalence relation](wikipedia://en/9259) of [equinumerosity](https://en.wikipedia.org/wiki/Equinumerosity). This definition may appear circular, but it is not, because equinumerosity can be defined in alternate ways, for instance by saying that two sets are equinumerous if they can be put into [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence)—this is sometimes known as [Hume's principle](wikipedia://en/314743).

This definition works in [type theory](wikipedia://en/40282), and in set theories that grew out of type theory, such as [New Foundations](wikipedia://en/945957) and related systems. However, it does not work in the axiomatic set theory [ZFC](https://en.wikipedia.org/wiki/ZFC) nor in certain related systems, because in such systems the equivalence classes under equinumerosity are [proper classes](https://en.wikipedia.org/wiki/Proper_class) rather than sets. However, cardinals can be defined in ZF using [Scott's trick](wikipedia://en/22077085).

For enabling natural numbers to form a set, equinumerous classes are replaced by special sets, named [cardinal](wikipedia://en/6173). The simplest way to introduce cardinals is to add a primitive notion, Card(), and an axiom of cardinality to ZF set theory (without axiom of choice).[^n1]

Axiom of cardinality: The sets A and B are equinumerous if and only if Card(A) = Card(B)

Definition: the sum of cardinals K and L such as K= Card(A) and L = Card(B) where the sets A and B are disjoint, is Card (A ∪ B).

The definition of a finite set is given independently of natural numbers:[^n2]

Definition: A set is finite if and only if any non empty family of its subsets has a minimal element for the inclusion order.

Definition: a cardinal n is a natural number if and only if there exists a finite set of which the cardinal is n.

0 = Card (∅)

1 = Card({A}) = Card({∅})

Definition: the successor of a cardinal K is the cardinal K + 1

Theorem: the natural numbers satisfy Peano’s axioms

## Hatcher {#Hatcher}

[William S. Hatcher](https://en.wikipedia.org/wiki/William_S._Hatcher) (1982) derives Peano's axioms from several foundational systems, including [ZFC](https://en.wikipedia.org/wiki/ZFC) and [category theory](wikipedia://en/5869), and from the system of Frege's *Grundgesetze der Arithmetik* using modern notation and [natural deduction](wikipedia://en/51072). The [Russell paradox](https://en.wikipedia.org/wiki/Russell_paradox) proved this system inconsistent, but [George Boolos](wikipedia://en/340621) (1998) and David J. Anderson and [Edward Zalta](https://en.wikipedia.org/wiki/Edward_Zalta) (2004) show how to repair it.
