# Axiom of countable choice

::: {#o1 .subject cue=lead name="Axiom of countable choice"}

*Image: Axiom of countable choice.svg.* Each set in the [countable](https://en.wikipedia.org/wiki/Countable) [sequence](wikipedia://en/27838) of sets (S<sub>*i*</sub>) = S<sub>1</sub>, S<sub>2</sub>, S<sub>3</sub>, ... contains a non-zero, and possibly infinite (or even [uncountably infinite](https://en.wikipedia.org/wiki/Uncountable)), number of elements. The axiom of countable choice allows us to arbitrarily select a single element from each set, forming a corresponding sequence of elements (*x*<sub>*i*</sub>) = *x*<sub>1</sub>, *x*<sub>2</sub>, *x*<sub>3</sub>, ...

The **axiom of countable choice** or **axiom of denumerable choice**, denoted **AC<sub>ω</sub>**, is an [axiom](wikipedia://en/928) of [set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory) that states that every [countable](https://en.wikipedia.org/wiki/Countable) collection of [non-empty](wikipedia://en/9566) [sets](wikipedia://en/26691) must have a [choice function](wikipedia://en/1432664). That is, given a [function](wikipedia://en/185427) $A$ with [domain](wikipedia://en/50263) $\mathbb{N}$ (where $\mathbb{N}$ denotes the set of [natural numbers](wikipedia://en/21474)) such that $A(n)$ is a non-empty set for every $n\in\mathbb{N}$, there exists a function $f$ with domain $\mathbb{N}$ such that $f(n)\in A(n)$ for every $n\in\mathbb{N}$.

:::

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

AC<sub>ω</sub> is particularly useful for the development of [mathematical analysis](wikipedia://en/48396), where many results depend on having a choice function for a countable collection of sets of [real numbers](wikipedia://en/20646438). For instance, in order to prove that every [accumulation point](wikipedia://en/226505) $x$ of a set $S\subseteq\mathbb{R}$ is the [limit](wikipedia://en/26551602) of some [sequence](wikipedia://en/27838) of elements of $S\setminus\{x\}$, one needs (a weak form of) the axiom of countable choice. When formulated for accumulation points of arbitrary [metric spaces](wikipedia://en/20018), the statement becomes equivalent to AC<sub>ω</sub>.

The ability to perform analysis using countable choice has led to the inclusion of AC<sub>ω</sub> as an axiom in some forms of [constructive mathematics](https://en.wikipedia.org/wiki/Constructive_mathematics), despite its assertion that a choice function exists without constructing it.

### Example: infinite implies Dedekind-infinite {#Example:_infinite_implies_Dedekind-infinite}

As an example of an application of AC<sub>ω</sub>, here is a proof (from [ZF](wikipedia://en/152214) + AC<sub>ω</sub>) that every infinite set is [Dedekind-infinite](wikipedia://en/1074742):[^n1]

Let $X$ be infinite. For each natural number $n$, let $A_n$ be the set of all $n$-tuples of distinct elements of $X$. Since $X$ is infinite, each $A_n$ is non-empty. Application of AC<sub>ω</sub> yields a sequence $(B_n)_{n\in\mathbb{N}}$ where each $B_n$ is an $n$-tuple. One can then concatenate these tuples into a single sequence $(b_n)_{n\in\mathbb{N}}$ of elements of $X$, possibly with repeating elements. This $i$ exists, because when selecting $c_n$ it is not possible for all elements of $B_{n+1}$ to be among the $n$ elements selected previously. So $X$ contains a countable set. The function that maps each $c_n$ to $c_{n+1}$ (and leaves all other elements of $X$ fixed) is a one-to-one map from $X$ into $X$ which is not onto, proving that $X$ is Dedekind-infinite.[^n1]

## Relation to other axioms {#Relation_to_other_axioms}

### Stronger and independent systems {#Stronger_and_independent_systems}

The axiom of countable choice (AC<sub>ω</sub>) is strictly weaker than the [axiom of dependent choice](wikipedia://en/441950) (DC), which in turn is weaker than the [axiom of choice](wikipedia://en/840) (AC). DC, and therefore also AC<sub>ω</sub>, hold in the [Solovay model](wikipedia://en/25274967), constructed in 1970 by [Robert M. Solovay](wikipedia://en/3160110) as a model of set theory without the full axiom of choice, in which all sets of real numbers are measurable.

[Urysohn's lemma](wikipedia://en/49253) (UL) and the [Tietze extension theorem](wikipedia://en/31404) (TET) are independent of ZF+AC<sub>ω</sub>: there exist models of ZF+AC<sub>ω</sub> in which UL and TET are true, and models in which they are false. Both UL and TET are implied by DC.

### Weaker systems {#Weaker_systems}

[Paul Cohen](https://en.wikipedia.org/wiki/Paul_Cohen_%28mathematician%29) showed that AC<sub>ω</sub> is not provable in [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZF) without the axiom of choice. However, some countably infinite sets of non-empty sets can be proven to have a [choice function](wikipedia://en/1432664) in ZF without *any* form of the axiom of choice. For example, $V_{\omega}\setminus\{\emptyset\}$ has a choice function, where $V_{\omega}$ is the set of [hereditarily finite sets](wikipedia://en/332621), i.e. the first set of non-finite rank in the [Von Neumann universe](wikipedia://en/445980). The choice function is: { ⟨*W*<sub>*n*</sub>,*W*<sub>*k*</sub>⟩ : k \< n \< ω ∧ *W*<sub>*k*</sub> ∈ *W*<sub>*n*</sub> ∧ ∀ *j* \< *k* ( *W*<sub>*j*</sub> ∉ *W*<sub>*n*</sub> ) } where *W*<sub>*n*</sub> = {*W*<sub>*k*</sub> : *k*\<*n* ∧ (*n* mod 2<sup>*k*+1</sup>) ≥ 2<sup>*k*</sup>} for *n*\<ω. *W* lists every hereditarily finite set exactly once and is based on the [binary numeral](https://en.wikipedia.org/wiki/Binary_numeral) for *n* which has a 1 in each place corresponding to a *k* with *W*<sub>*k*</sub> ∈ *W*<sub>*n*</sub>. Another example is the set of proper and bounded [open intervals](https://en.wikipedia.org/wiki/Open_interval) of real numbers with rational endpoints.

ZF+AC<sub>ω</sub> suffices to prove that the union of countably many countable sets is countable. These statements are not equivalent: *[Cohen](wikipedia://en/22994)'s First Model* supplies an example where countable unions of countable sets are countable, but where AC<sub>ω</sub> does not hold.

### Equivalent forms {#Equivalent_forms}

There are many equivalent forms to the axiom of countable choice, in the sense that any one of them can be proven in ZF assuming any other of them. They include the following:

- Every countable collection of non-empty sets has a choice function.
- Every infinite collection of non-empty sets has an infinite sub-collection with a choice function.
- Every [σ-compact space](wikipedia://en/346681) (the union of countably many [compact spaces](wikipedia://en/6042)) is a [Lindelöf space](wikipedia://en/310480) (every open cover has a countable subcover). A [metric space](wikipedia://en/20018) is σ-compact if and only if it is Lindelöf.
- Every [second-countable space](wikipedia://en/901459) (it has a countable base of open sets) is a [separable space](wikipedia://en/27855) (it has a countable dense subset). A metric space is separable if and only if it is σ-compact.
- Every [sequentially continuous](https://en.wikipedia.org/wiki/Sequentially_continuous) real-valued function in a metric space is a [continuous function](wikipedia://en/6122).
- Every [accumulation point](wikipedia://en/226505) of a subset of a metric space is a [limit](wikipedia://en/26551602) of a sequence of points from the subset.
- The [Rasiowa–Sikorski lemma](wikipedia://en/30864999) MA$(\aleph_0)$, a countable form of [Martin's axiom](wikipedia://en/1550783): in a [preorder](wikipedia://en/23582) with the [countable chain condition](wikipedia://en/1550771), every countable family of dense subsets has a [filter](wikipedia://en/19719) intersecting all the subsets. (In this context, a set is called dense if every element of the preorder has a lower bound in the set.)
