# Continuous optimization

::: {#o1 .subject cue=lead name="Continuous optimization"}

**Continuous optimization** is a branch of [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) in [applied mathematics](wikipedia://en/24295969).[^o2]

:::

As opposed to [discrete optimization](wikipedia://en/420567), the [variables](wikipedia://en/3728109) used in the [objective function](https://en.wikipedia.org/wiki/Objective_function) are required to be [continuous variables](https://en.wikipedia.org/wiki/Continuous_variable)—that is, to be chosen from a set of [real](wikipedia://en/20646438) values between which there are no gaps (values from [intervals](wikipedia://en/49172) of the [real line](https://en.wikipedia.org/wiki/Real_line)). Because of this [continuity](https://en.wikipedia.org/wiki/Continuity_%28mathematics%29) assumption, continuous optimization allows the use of [calculus](wikipedia://en/5176) techniques.
