# Vector potential

::: {#o1 .subject cue=lead name="Vector potential"}

In [vector calculus](wikipedia://en/32640), a **vector potential** is a [vector field](wikipedia://en/62641) whose [curl](wikipedia://en/6123) is a given vector field. This is analogous to a *[scalar potential](wikipedia://en/461654)*, which is a scalar field whose [gradient](wikipedia://en/12461) is a given vector field.

:::

Formally, given a vector field $\mathbf{v}$, a *vector potential* is a $C^2$ vector field $\mathbf{A}$ such that

$$\mathbf{v} = \nabla \times \mathbf{A}.$$

## Consequence {#Consequence}

If a vector field $\mathbf{v}$ admits a vector potential $\mathbf{A}$, then from the equality

$$\nabla \cdot (\nabla \times \mathbf{A}) = 0$$

([divergence](wikipedia://en/8328) of the [curl](wikipedia://en/6123) is zero) one obtains

$$\nabla \cdot \mathbf{v} = \nabla \cdot (\nabla \times \mathbf{A}) = 0,$$

which implies that $\mathbf{v}$ must be a [solenoidal vector field](wikipedia://en/419444).

::: {#o4 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

Let

$$\mathbf{v} : \mathbb{R}^3 \to \mathbb{R}^3$$

be a [solenoidal vector field](wikipedia://en/419444) which is twice [continuously differentiable](https://en.wikipedia.org/wiki/Smooth_function). Assume that $\mathbf{v}(\mathbf{x})$ decreases at least as fast as $1/\|\mathbf{x}\|$ for $\| \mathbf{x}\| \to \infty$. Define

$$\mathbf{A} (\mathbf{x}) = \frac{1}{4 \pi} \int_{\mathbb R^3} \frac{ \nabla_\mathbf{s} \times \mathbf{v} (\mathbf{s})}{\left\|\mathbf{x} -\mathbf{s} \right\|} \, d^3\mathbf{s}$$

where $\nabla_\mathbf{s} \times$ denotes curl with respect to variable $\mathbf{s}$. Then $\mathbf{A}$ is a vector potential for $\mathbf{v}$. That is,

$$\nabla \times \mathbf{A} =\mathbf{v}.$$

The integral domain can be restricted to any simply connected region $\Omega$. That is, $\mathbf{A'}$ also is a vector potential of $\mathbf{v}$, where

$$\mathbf{A'} (\mathbf{x}) = \frac{1}{4 \pi} \int_{\Omega} \frac{ \nabla_\mathbf{s} \times \mathbf{v} (\mathbf{s})}{\left\|\mathbf{x} -\mathbf{s} \right\|} \, d^3\mathbf{s}.$$

A generalization of this theorem is the [Helmholtz decomposition](wikipedia://en/820253) theorem, which states that any vector field can be decomposed as a sum of a solenoidal vector field and an [irrotational vector field](https://en.wikipedia.org/wiki/Irrotational_vector_field).

By [analogy](wikipedia://en/103533) with the [Biot–Savart law](wikipedia://en/75110), $\mathbf{A''}(\mathbf{x})$ also qualifies as a vector potential for $\mathbf{v}$, where

$$\mathbf{A''}(\mathbf{x}) = \int_\Omega \frac{\mathbf{v}(\mathbf{s}) \times (\mathbf{x} - \mathbf{s})}{4 \pi \left|\mathbf{x} - \mathbf{s}\right|^3} d^3 \mathbf{s}$$

Substituting $\mathbf{j}$ ([current density](https://en.wikipedia.org/wiki/Current_density)) for $\mathbf{v}$ and $\mathbf{H}$ ([H-field](https://en.wikipedia.org/wiki/H-field)) for $\mathbf{A}$, yields the Biot–Savart law.

Let $\Omega$ be a [star domain](wikipedia://en/5983414) centered at the point $\mathbf{p}$, where $\mathbf{p}\in \mathbb{R}^3$. Applying [Poincaré's lemma](https://en.wikipedia.org/wiki/Poincaré's_lemma) for [differential forms](https://en.wikipedia.org/wiki/Differential_forms) to vector fields, then $\mathbf{A'''}(\mathbf{x})$ also is a vector potential for $\mathbf{v}$, where

$$\mathbf{A'''}(\mathbf{x}) =\int_0^1 s \left[(\mathbf{x}-\mathbf{p})\times \mathbf{v}( s \mathbf{x} + (1{-}s) \mathbf{p})\right] ds$$

:::

## Nonuniqueness {#Nonuniqueness}

The vector potential admitted by a solenoidal field is not unique. If $\mathbf{A}$ is a vector potential for $\mathbf{v}$, then so is

$$\mathbf{A} + \nabla f,$$

where $f$ is any continuously differentiable scalar function. This follows from the fact that the curl of the gradient is zero.

This nonuniqueness leads to a degree of freedom in the formulation of electrodynamics, or gauge freedom, and requires [choosing a gauge](wikipedia://en/2000736).
