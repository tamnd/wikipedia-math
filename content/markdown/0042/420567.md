# Discrete optimization

::: {#o1 .subject cue=lead name="Discrete optimization"}

**Discrete optimization** is a branch of [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) in [applied mathematics](wikipedia://en/24295969) and [computer science](https://en.wikipedia.org/wiki/Computer_science). As opposed to [continuous optimization](wikipedia://en/420577), some or all of the [variables](wikipedia://en/3728109) used in a discrete optimization problem are restricted to be [discrete variables](https://en.wikipedia.org/wiki/Discrete_variable)—that is, to assume only a [discrete](wikipedia://en/8492) set of values, such as the [integers](wikipedia://en/14563).[^o2]

:::

## Branches {#Branches}

Three notable branches of discrete optimization are:[^o4]

- [combinatorial optimization](wikipedia://en/420555), which refers to problems on [graphs](wikipedia://en/325806), [matroids](wikipedia://en/244321) and other discrete structures
- [integer programming](wikipedia://en/411215)
- [constraint programming](https://en.wikipedia.org/wiki/Constraint_programming)

These branches are all closely intertwined however, since many combinatorial optimization problems can be modeled as integer programs (e.g. [shortest path](https://en.wikipedia.org/wiki/Shortest_path#Linear_programming_formulation)) or constraint programs, any constraint program can be formulated as an integer program and vice versa, and constraint and integer programs can often be given a combinatorial interpretation.
