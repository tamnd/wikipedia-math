# HP-22S

::: {#o2 .subject cue=lead name="HP-22S"}

The **HP-22S** is an [electronic calculator](https://en.wikipedia.org/wiki/Electronic_calculator) from the [Hewlett-Packard](https://en.wikipedia.org/wiki/Hewlett-Packard) company which is [algebraic](https://en.wikipedia.org/wiki/Algebraic_calculator) and scientific. This calculator is comparable to the HP-32S. A solver was included instead of programming. It had the same constraints as the 32S, lacking enough [RAM](https://en.wikipedia.org/wiki/RAM) for serious use. Functions available include TVM and unit conversions. Only single letter variable names are allowed. Marketed as a student calculator, the 22S uses [infix notation](wikipedia://en/199014) rather than the reverse polish notation used on some higher-end HP calculators of the same era.

:::

## Features {#Features}

The HP-22S includes many of the typical features found in most scientific calculators:

- Trigonometric and hyperbolic functions
- Polar/rectangular coordinate conversion
- Probability functions and statistical calculators (mean and standard deviation, weighted mean, linear regression)
- Unit and base conversions

## Hardware {#Hardware}

The 22S has the same physical form factor and 37-key keypad as other models in the Pioneer series. Introduced simultaneously with the [HP-32S](wikipedia://en/898457),[^o5] it is based on the same hardware, with a single line character-based dot matrix display that can display both numerical and alphabetical characters. The CPU is an [HP Saturn](https://en.wikipedia.org/wiki/HP_Saturn) *Sacajawea* chip clocked at 640 kHz, making it slower than its higher-spec cousin, the [HP-27S](https://en.wikipedia.org/wiki/HP-27S).[^o6]

## Equation solving and equation library {#Equation_solving_and_equation_library}

HP's advertising for the 22S emphasized the equation solver and library of built-in equations.[^o8] This feature allows a multi-variable equation to be entered by the user, and the equation solved for a particular unknown variable given the value of other variables.

For convenience the 22S includes a set of common mathematical and scientific formulae, including:

- [Quadratic roots](wikipedia://en/25175)
- [Kinetic energy](wikipedia://en/17327#Newtonian_kinetic_energy)
- [Ideal gas law](wikipedia://en/59881)
- [Fluid pressure](https://en.wikipedia.org/wiki/Pressure#Fluid_pressure)
- [Radioactive decay](https://en.wikipedia.org/wiki/Radioactive_decay)
- [Time value of money](https://en.wikipedia.org/wiki/Time_value_of_money)
