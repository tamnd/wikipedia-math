# Superformula

::: {#o1 .subject cue=lead name="Superformula"}

The **superformula** is a generalization of the [superellipse](wikipedia://en/52211) and was proposed by [Johan Gielis](https://en.wikipedia.org/wiki/Johan_Gielis_%28Mathematician%29) in 2003.[^o2] Gielis suggested that the formula can be used to describe many complex shapes and curves that are found in nature. Gielis has filed a patent application related to the synthesis of patterns generated by the superformula, which expired effective 2020-05-10.[^o3]

:::

In [polar coordinates](https://en.wikipedia.org/wiki/Polar_coordinates), with $r$ the radius and $\varphi$ the angle, the superformula is:

$$r\left(\varphi\right) = \left( \left| \frac{\cos\left(\frac{m\varphi}{4}\right)}{a} \right| ^{n_2} + \left| \frac{\sin\left(\frac{m\varphi}{4}\right)}{b} \right| ^{n_3} \right) ^{-\frac{1}{n_{1}}}.$$

By choosing different values for the parameters $a, b, m, n_1, n_2,$ and $n_3,$ different shapes can be generated.

The formula was obtained by generalizing the superellipse, named and popularized by [Piet Hein](https://en.wikipedia.org/wiki/Piet_Hein_%28scientist%29), a [Danish](https://en.wikipedia.org/wiki/Denmark) [mathematician](wikipedia://en/18902).

## 2D plots {#2D_plots}

In the following examples the values shown above each figure should be *m*, *n*<sub>1</sub>, *n*<sub>2</sub> and *n*<sub>3</sub>.

*Image: Sf2d.png.*

A [GNU Octave](wikipedia://en/48707) program for generating these figures

```matlab
function sf2d(n, a)
  u = [0:.001:2 * pi];
  raux = abs(1 / a(1) .* abs(cos(n(1) * u / 4))) .^ n(3) + abs(1 / a(2) .* abs(sin(n(1) * u / 4))) .^ n(4);
  r = abs(raux) .^ (- 1 / n(2));
  x = r .* cos(u);
  y = r .* sin(u);
  plot(x, y);
end
```

## Extension to higher dimensions {#Extension_to_higher_dimensions}

It is possible to extend the formula to 3, 4, or *n* dimensions, by means of the [spherical product](https://en.wikipedia.org/wiki/Spherical_product) of superformulas. For example, the [3D](wikipedia://en/8398) [parametric surface](wikipedia://en/3400953) is obtained by multiplying two superformulas *r*<sub>1</sub> and *r*<sub>2</sub>. The coordinates are defined by the relations:

$$x = r_1(\theta)\cos\theta \cdot r_2(\phi)\cos\phi,$$

$$y = r_1(\theta)\sin\theta \cdot r_2(\phi)\cos\phi,$$

$$z = r_2(\phi)\sin\phi,$$

where $\phi$ ([latitude](wikipedia://en/17616)) varies between −*π*/2 and *π*/2 and *θ* ([longitude](https://en.wikipedia.org/wiki/Longitude)) between −*π* and *π*.

## 3D plots {#3D_plots}

3D superformula: *a* = *b* = 1; *m*, *n*<sub>1</sub>, *n*<sub>2</sub> and *n*<sub>3</sub> are shown in the pictures.

A [GNU Octave](wikipedia://en/48707) program for generating these figures:

```matlab
function sf3d(n, a)
  u = [- pi:.05:pi];
  v = [- pi / 2:.05:pi / 2];
  nu = length(u);
  nv = length(v);
  for i = 1:nu
    for j = 1:nv
      raux1 = abs(1 / a(1) * abs(cos(n(1) .* u(i) / 4))) .^ n(3) + abs(1 / a(2) * abs(sin(n(1) * u(i) / 4))) .^ n(4);
      r1 = abs(raux1) .^ (- 1 / n(2));
      raux2 = abs(1 / a(1) * abs(cos(n(1) * v(j) / 4))) .^ n(3) + abs(1 / a(2) * abs(sin(n(1) * v(j) / 4))) .^ n(4);
      r2 = abs(raux2) .^ (- 1 / n(2));
      x(i, j) = r1 * cos(u(i)) * r2 * cos(v(j));
      y(i, j) = r1 * sin(u(i)) * r2 * cos(v(j));
      z(i, j) = r2 * sin(v(j));
    endfor;
  endfor;
  mesh(x, y, z);
endfunction;
```

## Generalization {#Generalization}

The superformula can be generalized by allowing distinct *m* parameters in the two terms of the superformula. By replacing the first parameter $m$ with *y* and second parameter $m$ with *z*:[^o9]

$$r\left(\varphi\right) = \left( \left| \frac{\cos\left(\frac{y\varphi}{4}\right)}{a} \right| ^{n_2} + \left| \frac{\sin\left(\frac{z\varphi}{4}\right)}{b} \right| ^{n_3} \right) ^{-\frac{1}{n_{1}}}$$
