# Model of computation

::: {#o1 .subject cue=lead name="Model of computation"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), and more specifically in [computability theory](https://en.wikipedia.org/wiki/Computability_theory_%28computer_science%29) and [computational complexity theory](wikipedia://en/7543), a **model of computation** is a model that describes how an output of a [mathematical function](wikipedia://en/185427) is computed given an input. A model of computation describes how units of computations, memories, and communications are organized.[^o2] The [computational complexity](wikipedia://en/6511) of an [algorithm](wikipedia://en/775) can be measured given a model of computation. Using a model allows studying the performance of algorithms independently of the variations that are specific to particular [implementations](https://en.wikipedia.org/wiki/Implementation) and specific technology.

:::

## Categories {#Categories}

Models of computation can be classified into three categories: sequential models, functional models, and concurrent models.

### Sequential models {#Sequential_models}

Sequential models include:

- [Finite-state machines](wikipedia://en/10931)
- Post machines ([Post–Turing machines](wikipedia://en/3688147) and [tag machines](https://en.wikipedia.org/wiki/Tag_system)).
- [Pushdown automata](https://en.wikipedia.org/wiki/Pushdown_automata)
- [Register machines](wikipedia://en/505218)
  - [Random-access machines](wikipedia://en/544227)
- [Turing machines](wikipedia://en/30403)
- [Decision tree model](wikipedia://en/22684368)
- [External memory model](https://en.wikipedia.org/wiki/External_memory_model)

### Functional models {#Functional_models}

Functional models include:

- [Abstract rewriting systems](wikipedia://en/23947591)
- [Combinatory logic](wikipedia://en/149848)
- [General recursive functions](wikipedia://en/26469)
- [Lambda calculus](wikipedia://en/18203)

### Concurrent models {#Concurrent_models}

Concurrent models include:

- [Actor model](https://en.wikipedia.org/wiki/Actor_model)
- [Cellular automaton](wikipedia://en/54342)
- [Interaction nets](https://en.wikipedia.org/wiki/Interaction_nets)
- [Kahn process networks](https://en.wikipedia.org/wiki/Kahn_process_networks)
- [Logic gates](https://en.wikipedia.org/wiki/Logic_gate) and [digital circuits](https://en.wikipedia.org/wiki/Circuit_%28computer_science%29)
- [Petri nets](https://en.wikipedia.org/wiki/Petri_nets)
- [Process calculus](wikipedia://en/853240)
- [Synchronous Data Flow](https://en.wikipedia.org/wiki/Synchronous_Data_Flow)

Some of these models have both [deterministic](https://en.wikipedia.org/wiki/Deterministic_model#In_computer_science) and [nondeterministic](https://en.wikipedia.org/wiki/Nondeterministic_model_of_computation) variants. Nondeterministic models are used in the study of [computational complexity](wikipedia://en/6511) of algorithms.

Models differ in their expressive power; for example, each function that can be computed by a *finite-state machine* can also be computed by a *Turing machine*, but not vice versa.

::: {#o8 .application cue=heading name="Uses"}

## Uses {#Uses}

In the field of runtime [analysis of algorithms](wikipedia://en/2230), it is common to specify a computational model in terms of *primitive operations* allowed which have unit cost, or simply **unit-cost operations**. A commonly used example is the [random-access machine](wikipedia://en/544227), which has unit cost for read and write access to all of its memory cells. In this respect, it differs from the above-mentioned Turing machine model.

:::
