# Argument of a function

::: {#o1 .subject cue=lead name="Argument of a function"}

In [mathematics](wikipedia://en/18831), an **argument** of a [function](wikipedia://en/185427) is a value provided to obtain the function's result. It is also called an [independent variable](wikipedia://en/437701).[^o2]

:::

For example, the [binary function](wikipedia://en/3943) $f(x,y) = x^2 + y^2$ has two arguments, $x$ and $y$, in an [ordered pair](wikipedia://en/22362) $(x, y)$. The [hypergeometric function](wikipedia://en/2055223) is an example of a four-argument function. The number of arguments that a function takes is called the *[arity](wikipedia://en/42301)* of the function. A function that takes a single argument as input, such as $f(x) = x^2$, is called a [unary function](wikipedia://en/1514907). A function of two or more variables is considered to have a [domain](wikipedia://en/50263) consisting of ordered pairs or [tuples](wikipedia://en/132729) of argument values. The argument of a [circular function](https://en.wikipedia.org/wiki/Circular_function) is an [angle](wikipedia://en/1196). The argument of a [hyperbolic function](https://en.wikipedia.org/wiki/Hyperbolic_function) is a [hyperbolic angle](wikipedia://en/1139981).

A mathematical function has one or more arguments in the form of independent variables designated in the definition, which can also contain [parameters](wikipedia://en/25065#Mathematical_functions). The independent variables are mentioned in the list of arguments that the function takes, whereas the parameters are not. For example, in the [logarithmic function](https://en.wikipedia.org/wiki/Logarithmic_function) $f(x) = \log_b(x),$ the [base](https://en.wikipedia.org/wiki/Base_of_a_logarithm) $b$ is considered a parameter.

Sometimes, [subscripts](https://en.wikipedia.org/wiki/Subscript) can be used to denote arguments. For example, we can use subscripts to denote the arguments with respect to which [partial derivatives](wikipedia://en/52565) are taken.[^o3]

The use of the term "argument" in this sense developed from [astronomy](https://en.wikipedia.org/wiki/Astronomy), which historically used tables to determine the spatial positions of planets from their positions in the sky ([ephemerides](https://en.wikipedia.org/wiki/Ephemerides)). These tables were organized according to measured angles called arguments, literally "that which elucidates something else."[^o4][^o5]
