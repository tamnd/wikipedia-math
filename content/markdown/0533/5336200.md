# Particular point topology

::: {#o1 .subject cue=lead name="Particular point topology"}

In [mathematics](wikipedia://en/18831), the **particular point topology** (or **included point topology**) is a [topology](wikipedia://en/30450) where a [set](wikipedia://en/26691) is [open](wikipedia://en/39358) if it contains a particular point of the [topological space](wikipedia://en/30450). Formally, let *X* be any non-empty set and *p* ∈ *X*. The collection

:::

$$T = \{S \subseteq X \mid p \in S \} \cup \{\emptyset\}$$

of [subsets](wikipedia://en/27631) of *X* is the particular point topology on *X*. There are a variety of cases that are individually named:

- If *X* has two points, the particular point topology on *X* is the [Sierpiński space](wikipedia://en/387651).
- If *X* is [finite](wikipedia://en/11742) (with at least 3 points), the topology on *X* is called the **finite particular point topology**.
- If *X* is [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite), the topology on *X* is called the **countable particular point topology**.
- If *X* is [uncountable](https://en.wikipedia.org/wiki/Uncountable), the topology on *X* is called the **uncountable particular point topology**.

A generalization of the particular point topology is the [closed extension topology](https://en.wikipedia.org/wiki/Closed_extension_topology). In the case when *X* \\ {*p*} has the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology), the closed extension topology is the same as the particular point topology.

This topology is used to provide interesting examples and counterexamples.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

**Closed sets have empty interior**

Given a nonempty open set $A \subseteq X$ every $x \ne p$ is a [limit point](https://en.wikipedia.org/wiki/Limit_point) of *A*. So the [closure](wikipedia://en/42309) of any open set other than $\emptyset$ is $X$. No [closed set](wikipedia://en/47279) other than $X$ contains *p* so the [interior](wikipedia://en/55610) of every closed set other than $X$ is $\emptyset$.

### Connectedness {#Connectedness}

**Path and locally connected but not [arc connected](wikipedia://en/6233#Arc_connectedness)**

For any *x*, *y* ∈ *X*, the [function](wikipedia://en/185427) *f*: \[0, 1\] → *X* given by

$$f(t) = \begin{cases} x & t=0 \\ p & t\in(0,1) \\ y & t=1 \end{cases}$$

is a path. However, since *p* is open, the [preimage](https://en.wikipedia.org/wiki/Preimage) of *p* under a [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) [injection](https://en.wikipedia.org/wiki/Injective) from \[0,1\] would be an open single point of \[0,1\], which is a contradiction.

**Dispersion point, example of a set with**

*p* is a **[dispersion point](wikipedia://en/7588072)** for *X*. That is *X* \\ {*p*} is [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected).

**Hyperconnected but not ultraconnected**

Every [non-empty](wikipedia://en/9566) open set contains *p*, and hence *X* is [hyperconnected](https://en.wikipedia.org/wiki/Hyperconnected). But if *a* and *b* are in *X* such that *p*, *a*, and *b* are three distinct points, then {*a*} and {*b*} are [disjoint](wikipedia://en/39359) closed sets and thus *X* is not [ultraconnected](https://en.wikipedia.org/wiki/Ultraconnected). Note that if *X* is the Sierpiński space then no such *a* and *b* exist and *X* is in fact ultraconnected.

### Compactness {#Compactness}

**Compact only if finite. Lindelöf only if countable.**

If *X* is finite, it is [compact](wikipedia://en/6042); and if *X* is infinite, it is not compact, since the family of all open sets $\{p,x\}\;(x\in X)$ forms an [open cover](wikipedia://en/317552#Cover_in_topology) with no finite subcover.

For similar reasons, if *X* is countable, it is a [Lindelöf space](wikipedia://en/310480); and if *X* is uncountable, it is not Lindelöf.

**Closure of compact not compact**

The set {*p*} is compact. However its [closure](wikipedia://en/42309) (the closure of a compact set) is the entire space *X*, and if *X* is infinite this is not compact. For similar reasons if *X* is uncountable then we have an example where the closure of a compact set is not a Lindelöf space.

**Pseudocompact but not weakly countably compact**

First there are no disjoint non-empty open sets (since all open sets contain *p*). Hence every continuous function to the [real line](https://en.wikipedia.org/wiki/Real_line) must be [constant](wikipedia://en/320861), and hence bounded, proving that *X* is a [pseudocompact space](wikipedia://en/5075659). Any set not containing *p* does not have a limit point thus if *X* if infinite it is not [weakly countably compact](https://en.wikipedia.org/wiki/Weakly_countably_compact).

**Locally compact but not locally relatively compact.**

If $x\in X$, then the set $\{x,p\}$ is a compact [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) of *x*. However the closure of this neighborhood is all of *X*, and hence if *X* is infinite, *x* does not have a closed compact neighborhood, and *X* is not [locally relatively compact](https://en.wikipedia.org/wiki/Locally_relatively_compact).

### Limit-related {#Limit-related}

**Accumulation points of sets**

If $Y\subseteq X$ does not contain *p*, *Y* has no accumulation point (because *Y* is closed in *X* and discrete in the subspace topology).

If $Y\subseteq X$ contains *p*, every point $x\ne p$ is an accumulation point of *Y*, since $\{x,p\}$ (the smallest neighborhood of $x$) meets *Y*. *Y* has no [ω-accumulation point](https://en.wikipedia.org/wiki/Ω-accumulation_point). Note that *p* is never an accumulation point of any set, as it is [isolated](wikipedia://en/390557) in *X*.

**Accumulation point as a set but not as a sequence**

Take a sequence $(a_n)_n$ of distinct elements that also contains *p*. The underlying set $\{a_n\}$ has any $x\ne p$ as an accumulation point. However the sequence itself has no [accumulation point as a sequence](wikipedia://en/226505#For_sequences_and_nets), as the neighbourhood $\{y,p\}$ of any *y* cannot contain infinitely many of the distinct $a_n$.

### Separation-related {#Separation-related}

**T<sub>0</sub>**

*X* is [T<sub>0</sub>](wikipedia://en/68121) (since {*x*, *p*} is open for each *x*) but satisfies no higher [separation axioms](wikipedia://en/40117302) (because all non-empty open sets must contain *p*).

**Not regular**

Since every non-empty open set contains *p*, no closed set not containing *p* (such as *X* \\ {*p*}) can be [separated by neighbourhoods](https://en.wikipedia.org/wiki/Separated_set) from {*p*}, and thus *X* is not [regular](wikipedia://en/53058). Since [complete regularity](wikipedia://en/30554) implies regularity, *X* is not completely regular.

**Not normal**

Since every non-empty open set contains *p*, no non-empty closed sets can be [separated by neighbourhoods](https://en.wikipedia.org/wiki/Separated_set) from each other, and thus *X* is not [normal](wikipedia://en/48629). Exception: the [Sierpiński topology](https://en.wikipedia.org/wiki/Sierpinski_topology) is normal, and even completely normal, since it contains no nontrivial separated sets.

### Other properties {#Other_properties}

**Separability**

{*p*} is [dense](wikipedia://en/23523594) and hence *X* is a [separable space](wikipedia://en/27855). However if *X* is [uncountable](wikipedia://en/32248) then *X* \\ {*p*} is not separable. This is an example of a [subspace](wikipedia://en/910926) of a separable space not being separable.

**Countability (first but not second)**

If *X* is uncountable then *X* is [first countable](wikipedia://en/904940) but not [second countable](wikipedia://en/901459).

**Alexandrov-discrete**

The topology is an [Alexandrov topology](wikipedia://en/542198). The smallest neighbourhood of a point $x$ is $\{x,p\}.$

**Comparable (Homeomorphic topologies on the same set that are not comparable)**

Let $p, q \in X$ with $p \ne q$. Let $t_p = \{S \subseteq X \mid p\in S\}$ and $t_q = \{S \subseteq X \mid q\in S\}$. That is *t*<sub>*q*</sub> is the particular point topology on *X* with *q* being the distinguished point. Then (*X*,*t*<sub>*p*</sub>) and (*X*,*t*<sub>*q*</sub>) are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) [incomparable topologies](wikipedia://en/393069) on the same set.

**No nonempty [dense-in-itself](wikipedia://en/8327127) subset**

Let *S* be a nonempty subset of *X*. If *S* contains *p*, then *p* is isolated in *S* (since it is an isolated point of *X*). If *S* does not contain *p*, any *x* in *S* is isolated in *S*.

**Not first category**

Any set containing *p* is dense in *X*. Hence *X* is not a [union](wikipedia://en/47949) of [nowhere dense subsets](wikipedia://en/200550).

**Subspaces**

Every subspace of a set given the particular point topology that doesn't contain the particular point, has the discrete topology.
