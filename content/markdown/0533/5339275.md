# Kemeny method

::: {#o1 .subject cue=lead name="Kemeny method"}

The **Kemeny method** is an [electoral system](wikipedia://en/29066482) that uses [ranked ballots](https://en.wikipedia.org/wiki/Ranked_ballots) and [pairwise comparison](https://en.wikipedia.org/wiki/Round-robin_voting) counts to identify the most popular choices in an election. It is a [Condorcet method](wikipedia://en/44446) because if there is a Condorcet winner, it will always be ranked as the most popular choice.

:::

This method assigns a score for each possible sequence, where each sequence considers which choice might be most popular, which choice might be second-most popular, which choice might be third-most popular, and so on down to which choice might be least-popular. The sequence that has the highest score is the winning sequence, and the first choice in the winning sequence is the most popular choice. (As explained below, ties can occur at any ranking level.)

The Kemeny method is also known as the **Kemeny-Young rule**, **VoteFair popularity ranking**, the **[maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) method**, and the **median relation**.

## Description {#Description}

The Kemeny method uses [preferential ballots](https://en.wikipedia.org/wiki/Preferential_ballot) on which voters rank choices according to their order of preference. A voter is allowed to rank more than one choice at the same preference level. Unranked choices are usually interpreted as least-preferred.

Kemeny calculations are usually done in two steps. The first step is to create a matrix or table that counts pairwise voter preferences. The second step is to test all possible [rankings](wikipedia://en/30330), calculate a score for each such ranking, and compare the scores. Each ranking score equals the sum of the pairwise counts that apply to that ranking.

The ranking that has the largest score is identified as the overall ranking. (If more than one ranking has the same largest score, all these possible rankings are tied, and typically the overall ranking involves one or more ties.)

Another way to view the ordering is that it is the one which minimizes the sum of the [Kendall tau distances](wikipedia://en/7276069) ([bubble sort](https://en.wikipedia.org/wiki/Bubble_sort) distance) to the voters' lists.

In order to demonstrate how an individual preference order is converted into a tally table, it is worth considering the following example. Suppose that a single voter has a choice among four candidates (i.e. Elliot, Meredith, Roland, and Selden) and has the following preference order:

::: {#o3 .table cue=table}

| Preference order | Choice |
|---|---|
| First | Elliot |
| Second | Roland |
| Third | Meredith or Selden (equal preference) |

:::

These preferences can be expressed in a tally table. A tally table, which arranges all the pairwise counts in three columns, is useful for counting (tallying) ballot preferences and calculating ranking scores. The center column tracks when a voter indicates more than one choice at the same preference level. The above preference order can be expressed as the following tally table:

::: {#o4 .table cue=table}

| All possible pairs of choice names | Number of votes with indicated preference |  |  |
|---|---|---|---|
|  | Prefer X over Y | Equal preference | Prefer Y over X |
| X = Selden Y = Meredith | 0 | \+1 vote | 0 |
| X = Selden Y = Elliot | 0 | 0 | \+1 vote |
| X = Selden Y = Roland | 0 | 0 | \+1 vote |
| X = Meredith Y = Elliot | 0 | 0 | \+1 vote |
| X = Meredith Y = Roland | 0 | 0 | \+1 vote |
| X = Elliot Y = Roland | \+1 vote | 0 | 0 |

:::

Now suppose that multiple voters had voted on those four candidates. After all ballots have been counted, the same type of tally table can be used to summarize all the preferences of all the voters. Here is an example for a case that has 100 voters:

::: {#o5 .table cue=table}

| All possible pairs of choice names | Number of votes with indicated preference |  |  |
|---|---|---|---|
|  | Prefer X over Y | Equal preference | Prefer Y over X |
| X = Selden Y = Meredith | 50 | 10 | 40 |
| X = Selden Y = Elliot | 40 | 0 | 60 |
| X = Selden Y = Roland | 40 | 0 | 60 |
| X = Meredith Y = Elliot | 40 | 0 | 60 |
| X = Meredith Y = Roland | 30 | 0 | 70 |
| X = Elliot Y = Roland | 30 | 0 | 70 |

:::

The sum of the counts in each row must equal the total number of votes.

After the tally table has been completed, each possible ranking of choices is examined in turn, and its ranking score is calculated by adding the appropriate number from each row of the tally table. For example, the possible ranking:

1. Elliot
1. Roland
1. Meredith
1. Selden

satisfies the preferences Elliot > Roland, Elliot > Meredith, Elliot > Selden, Roland > Meredith, Roland > Selden, and Meredith > Selden. The respective scores, taken from the table, are

- Elliot > Roland: 30
- Elliot > Meredith: 60
- Elliot > Selden: 60
- Roland > Meredith: 70
- Roland > Selden: 60
- Meredith > Selden: 40

giving a total ranking score of 30 + 60 + 60 + 70 + 60 + 40 = 320.

### Calculating the overall ranking {#Calculating_the_overall_ranking}

After the scores for every possible ranking have been calculated, the ranking that has the largest score can be identified, and becomes the overall ranking. In this case, the overall ranking is:

1. Roland
1. Elliot
1. Selden
1. Meredith

with a ranking score of 370.

If there are cycles or ties, more than one possible ranking can have the same largest score. Cycles are resolved by producing a single overall ranking where some of the choices are tied.

### Summary matrix {#Summary_matrix}

After the overall ranking has been calculated, the pairwise comparison counts can be arranged in a summary matrix, as shown below, in which the choices appear in the winning order from most popular (top and left) to least popular (bottom and right). This matrix layout does not include the equal-preference pairwise counts that appear in the tally table:[^o8]

::: {#o9 .table cue=table}

|  | ... over **Roland** | ... over **Elliot** | ... over **Selden** | ... over **Meredith** |
|---|---|---|---|---|
| Prefer **Roland** ... | \- | **70** | **60** | **70** |
| Prefer **Elliot** ... | 30 | \- | **60** | **60** |
| Prefer **Selden** ... | 40 | 40 | \- | **50** |
| Prefer **Meredith** ... | 30 | 40 | 40 | \- |

:::

In this summary matrix, the largest ranking score equals the sum of the counts in the upper-right, triangular half of the matrix (shown here in bold, with a green background). No other possible ranking can have a summary matrix that yields a higher sum of numbers in the upper-right, triangular half. (If it did, that would be the overall ranking.)

In this summary matrix, the sum of the numbers in the lower-left, triangular half of the matrix (shown here with a red background) are a minimum. The academic papers by [John Kemeny](https://en.wikipedia.org/wiki/John_G._Kemeny) and Peyton Young[^o38][^o39] refer to finding this minimum sum, which is called the Kemeny score, and which is based on how many voters oppose (rather than support) each pairwise order:

::: {#o10 .table cue=table}

| Method | First-place winner |
|---|---|
| Kemeny | Roland |
| [Condorcet](wikipedia://en/44446) | Roland |
| [Instant runoff voting](https://en.wikipedia.org/wiki/Instant-runoff_voting) | Elliot or Selden (depending on how the second-round tie is handled) |
| [Plurality](https://en.wikipedia.org/wiki/Plurality_voting_system) | Selden |

:::

## Characteristics {#Characteristics}

In all cases that do not result in an exact tie, the Kemeny method identifies a most-popular choice, second-most popular choice, and so on.

A tie can occur at any preference level. Except in some cases where [circular ambiguities](wikipedia://en/44446#Circular_ambiguities) are involved, the Kemeny method only produces a tie at a preference level when the number of voters with one preference exactly matches the number of voters with the opposite preference.

### Satisfied criteria for all Condorcet methods {#Satisfied_criteria_for_all_Condorcet_methods}

All Condorcet methods, including the Kemeny method, satisfy these criteria:

**[Non-imposition](wikipedia://en/89425#Statement)**

There are voter preferences that can yield every possible overall order-of-preference result, including ties at any combination of preference levels.

**[Condorcet criterion](https://en.wikipedia.org/wiki/Condorcet_criterion)**

If there is a choice that wins all pairwise contests, then this choice wins.

**[Majority criterion](https://en.wikipedia.org/wiki/Majority_favorite_criterion)**

If a majority of voters strictly prefer choice X to every other choice, then choice X is identified as the most popular.

**[Non-dictatorship](https://en.wikipedia.org/wiki/Non-dictatorship)**

A single voter cannot control the outcome in all cases.

### Additional satisfied criteria {#Additional_satisfied_criteria}

The Kemeny method also satisfies these criteria:

**[Unrestricted domain](https://en.wikipedia.org/wiki/Unrestricted_domain)**

Identifies the overall order of preference for all the choices. The method does this for all possible sets of voter preferences and always produces the same result for the same set of voter preferences.

**[Pareto efficiency](wikipedia://en/45468)**

Any pairwise preference expressed by every voter results in the preferred choice being ranked higher than the less-preferred choice.

**[Monotonicity](https://en.wikipedia.org/wiki/Monotonicity_criterion)**

If voters increase a choice's preference level, the ranking result either does not change or the promoted choice increases in overall popularity.

**[Smith criterion](https://en.wikipedia.org/wiki/Smith_criterion)**

The most popular choice is a member of the [Smith set](https://en.wikipedia.org/wiki/Smith_set), which is the smallest nonempty set of choices such that every member of the set is pairwise preferred to every choice not in the Smith set.

**[Independence of Smith-dominated alternatives](https://en.wikipedia.org/wiki/Independence_of_Smith-dominated_alternatives)**

If choice X is not in the [Smith set](https://en.wikipedia.org/wiki/Smith_set), adding or withdrawing choice X does not change a result in which choice Y is identified as most popular.

**Reinforcement**

If all the ballots are divided into separate races and the overall ranking for the separate races are the same, then the same ranking occurs when all the ballots are combined.[^o24]

**[Reversal symmetry](https://en.wikipedia.org/wiki/Reversal_symmetry)**

If the preferences on every ballot are inverted, then the previously most popular choice must not remain the most popular choice.

### Failed criteria for all Condorcet methods {#Failed_criteria_for_all_Condorcet_methods}

In common with all Condorcet methods, the Kemeny method **fails** these criteria (which means the described criteria do not apply to the Kemeny method):

**[Independence of irrelevant alternatives](wikipedia://en/259105)**

Adding or withdrawing choice X does not change a result in which choice Y is identified as most popular.

**[Invulnerability to burying](https://en.wikipedia.org/wiki/Tactical_voting#Types_of_tactical_voting)**

A voter cannot displace a choice from most popular by giving the choice an insincerely low ranking.

**[Invulnerability to compromising](https://en.wikipedia.org/wiki/Tactical_voting#Types_of_tactical_voting)**

A voter cannot cause a choice to become the most popular by giving the choice an insincerely high ranking.

**[Participation](wikipedia://en/1133956)**

Adding ballots that rank choice X over choice Y never cause choice Y, instead of choice X, to become most popular.

**[Later-no-harm](https://en.wikipedia.org/wiki/Later-no-harm_criterion)**

Ranking an additional choice (that was otherwise unranked) cannot displace a choice from being identified as the most popular.

**[Consistency](wikipedia://en/1792861)**

If all the ballots are divided into separate races and choice X is identified as the most popular in every such race, then choice X is the most popular when all the ballots are combined.

**[Sincere favorite criterion](wikipedia://en/65155658)**

The optimal voting strategy for an individual should always include giving their favorite candidate maximum support.

### Additional failed criteria {#Additional_failed_criteria}

The Kemeny method also **fails** these criteria (which means the described criteria do not apply to the Kemeny method):

**[Independence of clones](https://en.wikipedia.org/wiki/Independence_of_clones_criterion)**

Offering a larger number of similar choices, instead of offering only a single such choice, does not change the probability that one of these choices is identified as most popular.

**[Invulnerability to push-over](https://en.wikipedia.org/wiki/Tactical_voting#Push-over)**

A voter cannot cause choice X to become the most popular by giving choice Y an insincerely high ranking.

**[Schwartz](https://en.wikipedia.org/wiki/Schwartz_set)**

The choice identified as most popular is a member of the Schwartz set.

**[Polynomial runtime](https://en.wikipedia.org/wiki/Polynomial_time)[^o27]**

An algorithm is known to determine the winner using this method in a runtime that is polynomial in the number of choices.

## Calculation methods and computational complexity {#Calculation_methods_and_computational_complexity}

An algorithm for computing a Kemeny ranking in time polynomial in the number of candidates is not known, and unlikely to exist since the problem is [NP-hard](https://en.wikipedia.org/wiki/NP-hard)[^o27] even if there are just 4 voters (even)[^o29][^o30] or 7 voters (odd).[^o31]

It has been reported[^o32] that calculation methods based on [integer programming](wikipedia://en/411215) sometimes allowed the computation of full rankings for votes on as many as 40 candidates in seconds. However, certain 40-candidate 5-voter Kemeny elections generated at random were not solvable on a 3 GHz Pentium computer in a useful time bound in 2006.[^o32]

The Kemeny method can be formulated as an instance of a more abstract problem, of finding weighted [feedback arc sets](wikipedia://en/1860374) in [tournament graphs](https://en.wikipedia.org/wiki/Tournament_graph).[^o36] As such, many methods for the computation of feedback arc sets can be applied to this problem, including a variant of the [Held–Karp algorithm](wikipedia://en/45036001) that can compute the Kemeny–Young ranking of $n$ candidates in time $O(n2^n)$, significantly faster for many candidates than the factorial time of testing all rankings.[^o33][^o34] There exists a [polynomial-time approximation scheme](wikipedia://en/666431) for computing a Kemeny ranking,[^o35] and there also exists a parameterized subexponential-time algorithm with running time O<sup>\*</sup>(2<sup>O($\sqrt{\operatorname{OPT}}$)</sup>) for computing such a ranking.[^o36]

## History {#History}

The Kemeny method was developed by [John Kemeny](https://en.wikipedia.org/wiki/John_George_Kemeny) in 1959.[^o38]

In 1978, [Peyton Young](https://en.wikipedia.org/wiki/Peyton_Young) and Arthur Levenglick axiomatically characterized the method, showing that it is the unique neutral method satisfying [consistency](wikipedia://en/1792861) and the so-called quasi-Condorcet criterion.[^o39] It can also be characterized using consistency and a monotonicity property.[^o40] In other papers,[^o41] [^o42] [^o43] [^o44] Young adopted an [epistemic](https://en.wikipedia.org/wiki/Epistemology) approach to preference aggregation: he supposed that there was an objectively 'correct', but unknown preference order over the alternatives, and voters receive noisy signals of this true preference order (cf. [Condorcet's jury theorem](wikipedia://en/2707511).) Using a simple probabilistic model for these noisy signals, Young showed that the Kemeny method was the [maximum likelihood estimator](https://en.wikipedia.org/wiki/Maximum_likelihood_estimator) of the true preference order. Young further argues that [Condorcet](wikipedia://en/37749) himself was aware of the Kemeny rule and its maximum-likelihood interpretation, but was unable to clearly express his ideas.

In the papers by John Kemeny and Peyton Young, the Kemeny scores use counts of how many voters oppose, rather than support, each pairwise preference,[^o38][^o39] but the smallest such score identifies the same overall ranking.

Since 1991 the method has been promoted under the name "VoteFair popularity ranking" by Richard Fobes.[^o45]
