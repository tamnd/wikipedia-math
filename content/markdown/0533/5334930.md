# Partition topology

::: {#o1 .subject cue=lead name="Partition topology"}

In [mathematics](wikipedia://en/18831), a **partition topology** is a [topology](wikipedia://en/30450) that can be induced on any set $X$ by [partitioning](wikipedia://en/340240) $X$ into disjoint subsets $P;$ these subsets form the [basis](https://en.wikipedia.org/wiki/Basis_%28topology%29) for the topology. There are two important examples which have their own names:

:::

- The **odd–even topology** is the topology where $X = \mathbb{N}$ and $P = {\left\{~\{2k-1, 2k\} : k \in \mathbb{N}\right\} }.$ Equivalently, $P = \{~ \{1,2\}, \{3,4\},\{5,6\}, \ldots\}.$
- The **deleted integer topology** is defined by letting $X = \begin{matrix} \bigcup_{n \in \mathbb{N}} (n-1,n) \subseteq \mathbb{R} \end{matrix}$ and $P = {\left\{(0,1), (1,2), (2,3), \ldots\right\} }.$

The trivial partitions yield the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) (each point of $X$ is a set in $P,$ so $P = \{~ \{x\} ~ : ~ x \in X ~\}$) or [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology) (the entire set $X$ is in $P,$ so $P = \{X\}$).

Any set $X$ with a partition topology generated by a partition $P$ can be viewed as a [pseudometric space](wikipedia://en/68503) with a pseudometric given by:

$$d(x, y) = \begin{cases} 0 & \text{if } x \text{ and } y \text{ are in the same partition element} \\ 1 & \text{otherwise}. \end{cases}$$

This is not a [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) unless $P$ yields the discrete topology.

The partition topology provides an important example of the independence of various [separation axioms](https://en.wikipedia.org/wiki/Separation_axioms). Unless $P$ is trivial, at least one set in $P$ contains more than one point, and the elements of this set are [topologically indistinguishable](https://en.wikipedia.org/wiki/Topologically_indistinguishable): the topology does not separate points. Hence $X$ is not a [Kolmogorov space](wikipedia://en/68121), nor a [T<sub>1</sub> space](wikipedia://en/148721), a [Hausdorff space](wikipedia://en/13637) or an [Urysohn space](wikipedia://en/327166). In a partition topology the complement of every open set is also open, and therefore a set is open if and only if it is closed. Therefore, $X$ is [regular](wikipedia://en/53058), [completely regular](https://en.wikipedia.org/wiki/Completely_regular_space), [normal](wikipedia://en/48629) and [completely normal](https://en.wikipedia.org/wiki/Completely_normal_space). $X / P$ is the discrete topology.
