# Calcpad

::: {#o2 .subject cue=lead name="Calcpad"}

**Calcpad** is a [free](https://en.wikipedia.org/wiki/Free_software) and [open source](https://en.wikipedia.org/wiki/Open_source) mathematical software, created by PhD Eng. Nedelcho Ganchovski[^o3] in 2014. It is primarily designed to perform [engineering](https://en.wikipedia.org/wiki/Engineering) calculations and document the results into calculation notes/reports in [HTML](https://en.wikipedia.org/wiki/HTML), [PDF](https://en.wikipedia.org/wiki/PDF) or [Microsoft Word](https://en.wikipedia.org/wiki/Microsoft_Word) format. Calcpad employs its own [programming language](wikipedia://en/23015) with simplified syntax, suitable for engineers with minimal programming experience.

:::

## Features {#Features}

The math engine offers a range of features, including calculation with real and [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers), [units of measurement](https://en.wikipedia.org/wiki/Units_of_measurement), custom variables, functions and macros, [numerical methods](https://en.wikipedia.org/wiki/Numerical_methods) for [interpolation](wikipedia://en/14569), [root finding](https://en.wikipedia.org/wiki/Root_finding)[^o5][^o6], [function extrema](wikipedia://en/298420), [numerical differentiation](wikipedia://en/1254566) and [integration](wikipedia://en/170089), [vector](wikipedia://en/23218956) and [matrix](wikipedia://en/20556859) calculations, plotting etc.[^o7] It supports reading and writing external data from and to text and [CSV](https://en.wikipedia.org/wiki/Comma-separated_values) files and [Excel](https://en.wikipedia.org/wiki/Excel) [spreadsheets](https://en.wikipedia.org/wiki/Spreadsheets). Calcpad is widely used in practical engineering[^o8][^o9][^o10] and education.[^o11][^o12][^o13][^o14]

The programming language is [interpreted](https://en.wikipedia.org/wiki/Interpreted_language) with partial [compilation](https://en.wikipedia.org/wiki/Compiler) (to [IL](https://en.wikipedia.org/wiki/Common_Intermediate_Language)) of repeatedly executed code, like functions and loop bodies. It includes simple [program flow control](wikipedia://en/45459) structures like [conditions](https://en.wikipedia.org/wiki/Conditional_%28computer_programming%29) and [loops](https://en.wikipedia.org/wiki/Loop_%28statement%29). The program code can be organized across multiple files (modules). Calcpad can interact with [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) through a dedicated [programming interface](https://en.wikipedia.org/wiki/Programming_interface).[^o15] With the help of an extra plugin, developed by Damian Pacheco in 2025, the Calcpad language can be used inside [Grasshopper](https://en.wikipedia.org/wiki/Grasshopper_3D)/[Rhino](https://en.wikipedia.org/wiki/Rhinoceros_3D).[^o16]

Calcpad allows generation of [HTML](https://en.wikipedia.org/wiki/HTML) forms for data input. Text entries in code must be enclosed in quotes, and everything outside is assumed to be math equations. Text formatting can be performed by either [Markdown](https://en.wikipedia.org/wiki/Markdown) or HTML/[CSS](https://en.wikipedia.org/wiki/CSS). The results are automatically documented into HTML reports. With the help of [JavaScript](https://en.wikipedia.org/wiki/JavaScript) the report content can be made dynamic and interactive. Users can also create parametric vector drawings and even animations, by plugging Calcpad variables into the coordinates of [SVG](https://en.wikipedia.org/wiki/SVG) elements. The output can be exported also to [PDF](https://en.wikipedia.org/wiki/PDF) or [DOCX](https://en.wikipedia.org/wiki/Office_Open_XML) files for [Microsoft Word](https://en.wikipedia.org/wiki/Microsoft_Word).

## Code examples {#Code_examples}

[Source code](https://en.wikipedia.org/wiki/Source_code) of a sample [computer program](https://en.wikipedia.org/wiki/Computer_program) for analysis of a simply supported [beam](https://en.wikipedia.org/wiki/Beam_%28structure%29):

```text
"Analysis of a simply supported beam"
'Length -'L = 6m
#if L ≤ 0m
    '<p class="err">Invalid value:'L'</p>
    #break
#end if
'Load -'q = 10kN/m^2
'<!--'PlotHeight = 100'-->
'Shear force -'V_0 = q*L/2
V(x) = V_0 - q*x
$Plot{V(x) @ x = 0m : L}
'Bending -'M_max = q*L^2/8
M(x) = V_0*x - q*x^2/2
$Plot{-M(x) @ x = 0m : L}
```
