# Porous set

::: {#o1 .subject cue=lead name="Porous set"}

In [mathematics](wikipedia://en/18831), a **porous set** is a concept in the study of [metric spaces](wikipedia://en/20018). Like the concepts of [meagre](wikipedia://en/226975) and [measure zero](https://en.wikipedia.org/wiki/Measure_zero) sets, a porous set can be considered "sparse" or "lacking bulk"; however, porous sets are not equivalent to either meagre sets or measure zero sets, as shown below.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let (*X*, *d*) be a [complete metric space](wikipedia://en/7832) and let *E* be a subset of *X*. Let *B*(*x*, *r*) denote the [closed ball](https://en.wikipedia.org/wiki/Closed_ball) in (*X*, *d*) with centre *x* ∈ *X* and radius *r* > 0. *E* is said to be **porous** if there exist constants 0 \< *α* \< 1 and *r*<sub>0</sub> > 0 such that, for every 0 \< *r* ≤ *r*<sub>0</sub> and every *x* ∈ *X*, there is some point *y* ∈ *X* with

$$B(y, \alpha r) \subseteq B(x, r) \setminus E.$$

A subset of *X* is called ***σ*-porous** if it is a [countable](wikipedia://en/6026) [union](wikipedia://en/47949) of porous subsets of *X*.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Any porous set is [nowhere dense](https://en.wikipedia.org/wiki/Nowhere_dense). Hence, all *σ*-porous sets are meagre sets (or of the [first category](https://en.wikipedia.org/wiki/First_category)).
- If *X* is a finite-dimensional [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup>, then porous subsets are sets of [Lebesgue measure](wikipedia://en/18198) [zero](https://en.wikipedia.org/wiki/Measure_zero).
- However, there does exist a non-*σ*-porous subset *P* of **R**<sup>*n*</sup> which is of the first category and of Lebesgue measure zero. This is known as **Zajíček's theorem**.
- The relationship between porosity and being nowhere dense can be illustrated as follows: if *E* is nowhere dense, then for *x* ∈ *X* and *r* > 0, there is a point *y* ∈ *X* and *s* > 0 such that

$$B(y, s) \subseteq B(x, r) \setminus E.$$

However, if *E* is also porous, then it is possible to take *s* = *αr* (at least for small enough *r*), where 0 \< *α* \< 1 is a constant that depends only on *E*.

:::
