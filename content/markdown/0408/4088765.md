# Comparison function

::: {#o1 .subject cue=lead name="Comparison function"}

In [applied mathematics](wikipedia://en/24295969), **comparison functions** are several classes of [continuous functions](wikipedia://en/6122), which are used in [stability theory](wikipedia://en/5493795) to characterize the stability properties of control systems as [Lyapunov stability](wikipedia://en/363360), uniform asymptotic stability etc.

:::

Let $C(X,Y)$ be a space of continuous functions acting from $X$ to $Y$. The most important classes of comparison functions are:

$$\begin{aligned} \mathcal{P} &:= \left\{\gamma \in C({\mathbb{R}}_+,{\mathbb{R}}_+): \gamma(0)=0 \text{ and } \gamma(r)>0 \text{ for } r>0 \right\} \\[4pt] \mathcal{K} &:= \left\{\gamma \in {\mathcal{P}}: \gamma \text{ is strictly increasing} \right\}\\[4pt] \mathcal{K}_\infty &:=\left\{\gamma\in{\mathcal{K}}: \gamma\text{ is unbounded}\right\}\\[4pt] \mathcal{L} &:=\{\gamma\in C({\mathbb{R}}_+,{\mathbb{R}}_+): \gamma\text{ is strictly decreasing with } \lim_{t\rightarrow\infty}\gamma(t)=0 \}\\[4pt] \mathcal{KL} &:= \left\{\beta \in C({\mathbb{R}}_+\times{\mathbb{R}}_+,{\mathbb{R}}_+): \beta \text{ is continuous, } \beta(\cdot,t)\in{{\mathcal{K}}},\ \forall t \geq 0, \ \beta(r,\cdot)\in {{\mathcal{L}}},\ \forall r > 0\right\} \end{aligned}$$

Functions of class ${\mathcal{P}}$ are also called [*positive-definite functions*](wikipedia://en/649616).

One of the most important properties of comparison functions is given by Sontag’s ${\mathcal{KL}}$-Lemma,[^o2] named after [Eduardo Sontag](https://en.wikipedia.org/wiki/Eduardo_Sontag). It says that for each $\beta \in {\mathcal{KL}}$ and any $\lambda>0$ there exist $\alpha_1,\alpha_2 \in {\mathcal{K_\infty}}$:

::: {#o3 .equation cue=numblk name="1"}

$$\alpha_1(\beta(s,t)) \leq \alpha_2(s) e^{-\lambda t}, \quad t,s \in \mathbb{R}_+. \tag{1}$$

:::

Many further useful properties of comparison functions can be found in.[^o4][^o5]

Comparison functions are primarily used to obtain quantitative restatements of stability properties as Lyapunov stability, uniform asymptotic stability, etc. These restatements are often more useful than the qualitative definitions of stability properties given in $\varepsilon\text{-}\delta$ language.

As an example, consider an [ordinary differential equation](wikipedia://en/32742753)

::: {#o6 .equation cue=numblk name="2"}

$$\dot{x} = f(x), \tag{2}$$

:::

where $f:{\mathbb{R}}^n\to{\mathbb{R}}^n$ is [locally Lipschitz](wikipedia://en/51731). Then:

- ((2)) is [globally stable](wikipedia://en/363360) if and only if there is a $\sigma\in{\mathcal{K_\infty}}$ so that for any [initial condition](wikipedia://en/1186804) $x_0 \in{\mathbb{R}}^n$ and for any $t\geq 0$ it holds that

::: {#o7 .equation cue=numblk name="3"}

$$|x(t)| \leq \sigma(|x_0|). \tag{3}$$

:::

- ((2)) is [globally asymptotically stable](wikipedia://en/363360) if and only if there is a $\beta\in{\mathcal{KL}}$ so that for any initial condition $x_0 \in{\mathbb{R}}^n$ and for any $t\geq 0$ it holds that

::: {#o8 .equation cue=numblk name="4"}

$$|x(t)| \leq \beta(|x_0|,t). \tag{4}$$

:::

The comparison-functions formalism is widely used in [input-to-state stability](wikipedia://en/39711468) theory.
