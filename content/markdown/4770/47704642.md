# St-planar graph

*Image: St-planar graph.svg.* A [bipolar oriented](wikipedia://en/40147217) [planar graph](wikipedia://en/24314) with its source (blue) and sink (red) on the outer face is an **st-planar graph**

::: {#o1 .subject cue=lead name="St-planar graph"}

In [graph theory](wikipedia://en/12401), an ***st*-planar graph** is a [bipolar orientation](wikipedia://en/40147217) of a [plane graph](wikipedia://en/24314) for which both the source and the sink of the orientation are on the outer face of the graph. That is, it is a directed graph drawn without crossings in the plane, in such a way that there are no directed cycles in the graph, exactly one graph vertex has no incoming edges, exactly one graph vertex has no outgoing edges, and these two special vertices both lie on the outer face of the graph.[^o2]

:::

Within the drawing, each face of the graph must have the same structure: there is one vertex that acts as the source of the face, one vertex that acts as the sink of the face, and all edges within the face are directed along two paths from the source to the sink. If one draws an additional edge from the sink of an *st*-planar graph back to the source, through the outer face, and then constructs the [dual graph](wikipedia://en/2536864) (oriented each dual edge clockwise with respect to its primal edge) then the result is again an *st*-planar graph, augmented with an extra edge in the same way.[^o2]

## Order theory {#Order_theory}

These graphs are closely related to [partially ordered sets](wikipedia://en/23572) and [lattices](wikipedia://en/469304). The [Hasse diagram](wikipedia://en/338199) of a partially ordered set is a directed acyclic graph whose vertices are the set elements, with an edge from *x* to *y* for each pair *x*, *y* of elements for which *x* ≤ *y* in the partial order but for which there does not exist *z* with *x* ≤ *y* ≤ *z*. A partially ordered set forms a complete lattice if and only if every subset of elements has a unique greatest lower bound and a unique least upper bound, and the [order dimension](wikipedia://en/3121852) of a partially ordered set is the least number of [total orders](wikipedia://en/30330) on the same set of elements whose intersection is the given partial order. If the vertices of an *st*-planar graph are partially ordered by reachability, then this ordering always forms a two-dimensional complete lattice, whose Hasse diagram is the [transitive reduction](wikipedia://en/3757117) of the given graph. Conversely, the Hasse diagram of every two-dimensional complete lattice is always an *st*-planar graph.[^o4]

## Graph drawing {#Graph_drawing}

Based on this two-dimensional partial order property, every *st*-planar graph can be given a [dominance drawing](wikipedia://en/40153860), in which for every two vertices *u* and *v* there exists a path from *u* to *v* if and only if both coordinates of *u* are smaller than the corresponding coordinates of *v*.[^o6] The coordinates of such a drawing may also be used as a [data structure](wikipedia://en/8519) that can be used to test whether one vertex of an *st*-planar graph can reach another in [constant time](https://en.wikipedia.org/wiki/Constant_time) per query. Rotating such a drawing by 45° gives an [upward planar drawing](wikipedia://en/40148474) of the graph. A directed acyclic graph *G* has an [upward planar drawing](wikipedia://en/40148474) if and only if *G* is a subgraph of an *st*-planar graph.[^o7]
