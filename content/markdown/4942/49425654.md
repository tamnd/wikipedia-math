# Hadamard's gamma function

*Image: Hadamards gamma function plot.png.* Hadamard's gamma function plotted over part of the real axis. Unlike the classical gamma function, it is holomorphic; there are no poles.

::: {#o1 .subject cue=lead name="Hadamard's gamma function"}

In [mathematics](wikipedia://en/18831), **Hadamard's gamma function**, named after [Jacques Hadamard](wikipedia://en/312675), is an extension of the [factorial](wikipedia://en/10606) [function](wikipedia://en/185427), different from the classical [gamma function](wikipedia://en/12316) (it is an instance of a [pseudogamma function](wikipedia://en/72828889)). This function, with its [argument](wikipedia://en/32842052) shifted down by 1, interpolates the factorial and extends it to [real](wikipedia://en/20646438) and [complex numbers](wikipedia://en/5826) in a different way from Euler's gamma function. It is defined as:

:::

$$H(x) = \frac{1}{\Gamma (1-x)}\,\dfrac{d}{dx} \left \{ \ln \left ( \frac{\Gamma ( \frac{1}{2}-\frac{x}{2})}{\Gamma (1-\frac{x}{2})}\right ) \right \},$$

where $\Gamma(x)$ denotes the classical gamma function. If $n$ is a positive integer, then:

$$H(n) = \Gamma(n) = (n-1)!$$

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Unlike the classical gamma function, Hadamard's gamma function $H(x)$ is an [entire function](wikipedia://en/10372), i.e., it is defined and analytic at all complex numbers. It satisfies the [functional equation](wikipedia://en/364377)

$$H(x+1) = xH(x) + \frac{1}{\Gamma(1-x)},$$

with the understanding that $\tfrac{1}{\Gamma(1-x)}$ is taken to be $0$ for positive integer values of $x$.

The Hadamard's gamma function has a superadditive property:

$$H(x)+H(y)\leq H(x+y) ,$$

for all $x,y \geq \alpha$, where $\alpha=1.5031...$ is the unique solution to the equation $H(2t)=2H(t)$ in the interval $[1.5, \infty)$.[^o4]

:::

::: {#o6 .definition kind=definition/notation cue=heading name="Representations"}

## Representations {#Representations}

Hadamard's gamma can also be expressed as

$$H(x)=\frac{\psi\left ( 1 - \frac{x}{2}\right )-\psi\left ( \frac{1}{2} - \frac{x}{2}\right )}{2\Gamma (1-x)} = \frac{L\left(-1, 1, -x\right)}{\Gamma(-x)},$$

and also as

$$H(x) = \Gamma(x) \left [ 1 + \frac{\sin (\pi x)}{2\pi} \left \{ \psi \left ( \dfrac{x}{2} \right ) - \psi \left ( \dfrac{x+1}{2} \right ) \right \} \right ],$$

where $\psi(x)$ denotes the [digamma function](wikipedia://en/406935), and $L$ denotes the [Lerch zeta function](https://en.wikipedia.org/wiki/Lerch_zeta_function).

:::
