# Quotient by an equivalence relation

::: {#o1 .subject cue=lead name="Quotient by an equivalence relation"}

In [mathematics](wikipedia://en/18831), given a [category](wikipedia://en/53759) *C*, a **quotient** of an [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29) *X* **by an equivalence relation** $f: R \to X \times X$ is a [coequalizer](wikipedia://en/431940) for the pair of maps

:::

$$R \ \overset{f}{\to}\ X \times X \ \overset{\operatorname{pr}_i}{\to}\ X,\ \ i = 1,2,$$

where *R* is an object in *C* and "*f* is an equivalence relation" means that, for any object *T* in *C*, the image (which is a [set](wikipedia://en/26691)) of $f: R(T) = \operatorname{Mor}(T, R) \to X(T) \times X(T)$ is an [equivalence relation](wikipedia://en/9259); that is, a [reflexive](wikipedia://en/200458), [symmetric](wikipedia://en/200459) and [transitive](wikipedia://en/200463) [relation](wikipedia://en/3931).

The basic case in practice is when *C* is the category of all [schemes](wikipedia://en/364754) over some scheme *S*. But the notion is flexible and one can also take *C* to be the category of [sheaves](wikipedia://en/245466).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- Let *X* be a set and consider some equivalence relation on it. Let *Q* be the set of all [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes) in *X*. Then the map $q: X \to Q$ that sends an element *x* to the equivalence class to which *x* belongs is a quotient.
- In the above example, *Q* is a [subset](wikipedia://en/27631) of the [power set](wikipedia://en/23799) *H* of *X*. In [algebraic geometry](wikipedia://en/1997), one might replace *H* by a [Hilbert scheme](wikipedia://en/6612581) or disjoint union of Hilbert schemes. In fact, [Grothendieck](https://en.wikipedia.org/wiki/Grothendieck) constructed a relative [Picard scheme](https://en.wikipedia.org/wiki/Picard_scheme) of a [flat](wikipedia://en/542520) projective scheme *X*[^o4] as a quotient *Q* (of the scheme *Z* parametrizing [relative effective divisors](https://en.wikipedia.org/wiki/Relative_effective_divisor) on *X*) that is a closed scheme of a Hilbert scheme *H*. The quotient map $q: Z \to Q$ can then be thought of as a relative version of the [Abel map](https://en.wikipedia.org/wiki/Abel_map).
