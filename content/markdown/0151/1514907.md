# Unary function

::: {#o1 .subject cue=lead name="Unary function"}

In [mathematics](wikipedia://en/18831), a **unary function** is a [function](wikipedia://en/185427) that takes one [argument](wikipedia://en/42301). A [unary operation](wikipedia://en/161006) is a special kind of unary function, whose [codomain](wikipedia://en/50264) coincides with its [domain](wikipedia://en/50263).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

The [successor function](wikipedia://en/325637) is a unary function. More specifically, it is a unary operation on the set of [natural numbers](wikipedia://en/21474).

Many of the [elementary functions](wikipedia://en/10412) are unary functions, including the [trigonometric functions](wikipedia://en/30367), [logarithm](wikipedia://en/17860) with a specified base, [exponentiation](wikipedia://en/99491) to a particular power or base, and [hyperbolic functions](https://en.wikipedia.org/wiki/Hyperbolic_function).

:::
