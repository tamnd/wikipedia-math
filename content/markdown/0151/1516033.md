# Kummer's function

::: {#o1 .subject cue=lead name="Kummer's function"}

In [mathematics](wikipedia://en/18831), **Kummer's function**, named after [Ernst Kummer](wikipedia://en/319117), is a [complex function](wikipedia://en/5759) related to the [polylogarithm](wikipedia://en/482471). It is defined by[^n1]

:::

$$\Lambda_n(z)=\int_0^z \frac{\log^{n-1}|t|}{1+t}\;dt.$$

Its [duplication formula](https://en.wikipedia.org/wiki/Duplication_formula) is

$$\Lambda_n(z)+\Lambda_n(-z)= 2^{1-n}\Lambda_n(-z^2).$$

Compare this to the duplication formula for the polylogarithm:

$$\operatorname{Li}_n(z)+\operatorname{Li}_n(-z)= 2^{1-n}\operatorname{Li}_n(z^2).$$

An explicit link to the polylogarithm is given by

$$\operatorname{Li}_n(z)=\operatorname{Li}_n(1)\;\;+\;\; \sum_{k=1}^{n-1} (-1)^{k-1} \;\frac{\log^k |z|} {k!} \;\operatorname{Li}_{n-k} (z) \;\;+\;\; \frac{(-1)^{n-1}}{(n-1)!} \;\left[ \Lambda_n(-1) - \Lambda_n(-z) \right].$$
