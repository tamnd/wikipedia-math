# Connected category

::: {#o1 .subject cue=lead name="Connected category"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **connected category** is a [category](https://en.wikipedia.org/wiki/Category_%28category_theory%29) in which, for every two objects *X* and *Y* there is a [finite sequence](https://en.wikipedia.org/wiki/Finite_sequence) of objects

:::

$$X = X_0, X_1, \ldots, X_{n-1}, X_n = Y$$

with morphisms

$$f_i : X_i \to X_{i+1}$$

or

$$f_i : X_{i+1} \to X_i$$

for each 0 ≤ *i* \< *n* (both directions are allowed in the same sequence). Equivalently, a category *J* is connected if each [functor](wikipedia://en/10987) from *J* to a [discrete category](wikipedia://en/808519) is constant. In some cases it is convenient to not consider the empty category to be connected.

A stronger notion of connectivity would be to require at least one morphism *f* between any pair of objects *X* and *Y*. Any category with this property is connected in the above sense.

A [small category](https://en.wikipedia.org/wiki/Small_category) is connected [if and only if](wikipedia://en/14922) its underlying graph is [weakly connected](https://en.wikipedia.org/wiki/Connected_graph), meaning that it is connected if one disregards the direction of the arrows.

Each category *J* can be written as a disjoint union (or [coproduct](wikipedia://en/310889)) of a collection of connected categories, which are called the **connected components** of *J*. Each connected component is a [full subcategory](https://en.wikipedia.org/wiki/Full_subcategory) of *J*.
