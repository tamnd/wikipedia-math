# Riemann–Siegel theta function

::: {#o1 .subject cue=lead name="Riemann–Siegel theta function"}

In [mathematics](wikipedia://en/18831), the **Riemann–Siegel theta function** is defined in terms of the [gamma function](wikipedia://en/12316) as

:::

$$\theta(t) = \arg \left( \Gamma\left(\frac{1}{4}+\frac{it}{2}\right) \right) - \frac{\log \pi}{2} t$$

for real values of *t*. Here the [argument](wikipedia://en/14699765) is chosen in such a way that a continuous function is obtained and $\theta(0)=0$ holds, i.e., in the same way that the [principal branch](https://en.wikipedia.org/wiki/Principal_branch) of the [log-gamma](wikipedia://en/12316#The_log-gamma_function) function is defined.

It has an [asymptotic expansion](wikipedia://en/642090)

$$\theta(t) \sim \frac{t}{2}\log \frac{t}{2\pi} - \frac{t}{2} - \frac{\pi}{8}+\frac{1}{48t}+ \frac{7}{5760t^3}+\cdots$$

which is not convergent, but whose first few terms give a good approximation for $t \gg 1$. Its Taylor-series at 0 which converges for $|t| < 1/2$ is

$$\theta(t) = -\frac{t}{2} \log \pi + \sum_{k=0}^{\infty} \frac{(-1)^k \psi^{(2k)}\left(\frac{1}{4}\right) }{(2k+1)!} \left(\frac{t}{2}\right)^{2k+1}$$

where $\psi^{(2k)}$ denotes the [polygamma function](wikipedia://en/406932) of order $2k$. The Riemann–Siegel theta function is of interest in studying the [Riemann zeta function](wikipedia://en/25809), since it can rotate the Riemann zeta function such that it becomes the totally real valued [Z function](wikipedia://en/1415146) on the [critical line](https://en.wikipedia.org/wiki/Critical_line_%28mathematics%29) $s = 1/2 + i t$ .

## Curve discussion {#Curve_discussion}

The Riemann–Siegel theta function is an odd [real analytic function](https://en.wikipedia.org/wiki/Real_analytic_function) for real values of $t$ with three roots at $0$ and $\pm 17.8455995405\ldots$. It is an increasing function for $|t| > 6.29$, and has local extrema at $\pm 6.289835988\ldots$, with value $\mp 3.530972829\ldots$. It has a single inflection point at $t=0$ with $\theta^\prime(0)= -\frac{\ln \pi + \gamma + \pi/2 + 3 \ln 2}{2} = -2.6860917\ldots$, which is the minimum of its derivative.

## Theta as a function of a complex variable {#Theta_as_a_function_of_a_complex_variable}

We have an infinite series expression for the [log-gamma](wikipedia://en/12316#The_log-gamma_function) function

$$\log \Gamma \left(z\right) = -\gamma z -\log z + \sum_{n=1}^\infty \left(\frac{z}{n} - \log \left(1+\frac{z}{n}\right)\right),$$

where *γ* is [Euler's constant](https://en.wikipedia.org/wiki/Euler–Mascheroni_constant). Substituting $(2it+1)/4$ for *z* and taking the imaginary part termwise gives the following series for *θ*(*t*)

$$\theta(t) = -\frac{\gamma + \log \pi}{2}t - \arctan 2t + \sum_{n=1}^\infty \left(\frac{t}{2n} - \arctan\left(\frac{2t}{4n+1}\right)\right).$$

For values with imaginary part between −1 and 1, the arctangent function is [holomorphic](wikipedia://en/14110), and it is easily seen that the series converges uniformly on compact sets in the region with imaginary part between −1/2 and 1/2, leading to a holomorphic function on this domain. It follows that the [Z function](wikipedia://en/1415146) is also holomorphic in this region, which is the critical strip.

We may use the identities

$$\arg z = \frac{\log z - \log\bar z}{2i}\quad\text{and}\quad\overline{\Gamma(z)}=\Gamma(\bar z)$$

to obtain the closed-form expression

$$\theta(t) = \frac{\log\Gamma\left(\frac{2it+1}{4}\right)-\log\Gamma\left(\frac{-2it+1}{4}\right)}{2i} - \frac{\log \pi}{2} t=- \frac{i}{2} \left( \ln \Gamma \left( \frac{1}{4} + \frac{i t}{2} \right) - \ln \Gamma \left( \frac{1}{4} - \frac{i t}{2} \right) \right) - \frac{\ln (\pi) t}{2}$$

which extends our original definition to a holomorphic function of *t*. Since the principal branch of log Γ has a single branch cut along the negative real axis, *θ*(*t*) in this definition inherits branch cuts along the imaginary axis above *i*/2 and below −*i*/2.

## Gram points {#Gram_points}

The Riemann zeta function on the critical line can be written

$$\zeta\left(\frac{1}{2}+it\right) = e^{-i \theta(t)}Z(t),$$

$$Z(t) = e^{i \theta(t)} \zeta\left(\frac{1}{2}+it\right).$$

If $t$ is a [real number](wikipedia://en/20646438), then the [Z function](wikipedia://en/1415146) $Z(t)$ returns *real* values.

Hence the zeta function on the critical line will be *real* either at a zero, corresponding to $Z(t)=0$, or when $\sin\left(\theta(t)\right)=0$. Positive real values of **$t$** where the latter case occurs are called **Gram points**, after [J. P. Gram](wikipedia://en/851232), and can of course also be described as the points where $\frac{\theta(t)}{\pi}$ is an integer.

A Gram point is a solution $g_n$ of

$$\theta(g_n) = n\pi.$$

These solutions are approximated by the sequence:

$$g'_n = \frac{2 \pi \left(n + 1 - \frac{7}{8}\right)}{W\left(\frac{1}{e} \left(n + 1 - \frac{7}{8}\right) \right)},$$

where $W$ is the [Lambert W function](wikipedia://en/92465).

The choice of the index *n* is a bit crude. It is historically chosen in such a way that the index is 0 at the first value which is larger than the smallest positive zero (at imaginary part 14.13472514 ...) of the Riemann zeta function on the critical line. Notice, this $\theta$-function oscillates for absolute-small real arguments and therefore is not uniquely invertible in the interval \[−24,24\]. Thus the [odd](https://en.wikipedia.org/wiki/Odd_function) theta-function has its symmetric Gram point with value 0 at index −3. Gram points are useful when computing the zeros of $Z\left(t\right)$. At a Gram point $g_n,$

$$\zeta\left(\frac{1}{2}+ig_n\right) = \cos(\theta(g_n))Z(g_n) = (-1)^n Z(g_n),$$

and if this is *positive* at *two* successive Gram points, $Z(t)$ must have a zero in the interval.

According to **Gram’s law**, the [real part](https://en.wikipedia.org/wiki/Real_part) is *usually* positive while the [imaginary part](https://en.wikipedia.org/wiki/Imaginary_part) alternates with the Gram points, between *positive* and *negative* values at somewhat regular intervals.

$$(-1)^n Z(g_n) > 0$$

The number of roots, $N(T)$, in the strip from 0 to *T*, can be found by

$$N(T) = \frac{\theta(T)}{\pi} + 1+S(T),$$

where $S(T)$ is an error term which grows asymptotically like $\log T$.

If $g_n$ obeyed Gram’s law, then finding the number of roots in the strip would amount to

$$N(g_n) = n + 1.$$

Today we know that, in the long run, Gram's law fails for about 1/4 of all Gram-intervals to contain exactly 1 zero of the Riemann zeta function. Gram was afraid that it may fail for larger indices (the first miss is at index 126 before the 127th zero) and thus claimed this only for not-too-high indices. Later Hutchinson coined the phrase *Gram's law* for the (false) statement that all zeroes on the critical line would be separated by Gram points.
