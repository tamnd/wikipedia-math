# Centered octagonal number

*Image: Centered octagonal number.svg.*

::: {#o1 .subject cue=lead name="Centered octagonal number"}

A **centered octagonal number** is a [centered](https://en.wikipedia.org/wiki/Centered_number) [figurate number](wikipedia://en/325260) that represents an [octagon](wikipedia://en/314575) with a dot in the center and all other dots surrounding the center dot in successive octagonal layers.[^o2] The centered octagonal numbers are the same as the [odd](https://en.wikipedia.org/wiki/Odd_number) [square numbers](wikipedia://en/213919).[^o3] Thus, the *n*th odd square number and *t*th centered octagonal number is given by

:::

$$O_n = (2n-1)^2 = 4n^2-4n+1$$

*Image: visual\_proof\_centered\_octagonal\_numbers\_are\_odd\_squares.svg.* [Proof without words](wikipedia://en/18045517) that all centered octagonal numbers are odd squares

The first few centered octagonal numbers are

[1](https://en.wikipedia.org/wiki/1_%28number%29), [9](https://en.wikipedia.org/wiki/9_%28number%29), [25](wikipedia://en/362204), [49](https://en.wikipedia.org/wiki/49_%28number%29), [81](https://en.wikipedia.org/wiki/81_%28number%29), [121](https://en.wikipedia.org/wiki/121_%28number%29), [169](https://en.wikipedia.org/wiki/169_%28number%29), 225, 289, 361, 441, 529, 625, 729, 841, 961, [1089](https://en.wikipedia.org/wiki/1089_%28number%29), 1225

Calculating [Ramanujan's tau function](https://en.wikipedia.org/wiki/Ramanujan's_tau_function) on a centered octagonal number yields an odd number, whereas for any other number the function yields an even number.[^o3]

$O_n$ is the number of $2 \times 2$ matrices with elements from $0$ to $n$ whose [determinant](wikipedia://en/8468) and [permanent](wikipedia://en/215889) are both zero, i.e. that have an either a row or column that is identically zero.
