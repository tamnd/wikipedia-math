# Descriptive complexity theory

::: {#o1 .subject cue=lead name="Descriptive complexity theory"}

**Descriptive complexity** is a branch of [computational complexity theory](wikipedia://en/7543) and of [finite model theory](wikipedia://en/1773596) that characterizes [complexity classes](wikipedia://en/502426) by the type of [logic](wikipedia://en/46426065) needed to express the [languages](wikipedia://en/10939) in them.[^n1] For example, [PH](https://en.wikipedia.org/wiki/PH_%28complexity%29), the union of all complexity classes in the polynomial hierarchy, is precisely the class of languages expressible by statements of [second-order logic](wikipedia://en/341428). This connection between complexity and the logic of finite structures allows results to be transferred easily from one area to the other, facilitating new proof methods and providing additional evidence that the main complexity classes are somehow "natural" and not tied to the specific [abstract machines](wikipedia://en/60492) used to define them. That is, it provides a machine-independent approach to complexity theory.

:::

Specifically, each [logical system](https://en.wikipedia.org/wiki/Logical_system) produces a set of [queries](wikipedia://en/7726870) expressible in it. The queries – when restricted to finite structures – correspond to the [computational problems](https://en.wikipedia.org/wiki/Computational_problem) of traditional complexity theory.

The first main result of descriptive complexity was [Fagin's theorem](wikipedia://en/3122050), shown by [Ronald Fagin](https://en.wikipedia.org/wiki/Ronald_Fagin) in 1974. It established that [NP](wikipedia://en/21562) is precisely the set of languages expressible by sentences of existential [second-order logic](wikipedia://en/341428); that is, second-order logic excluding [universal quantification](wikipedia://en/76174) over [relations](wikipedia://en/22517558), [functions](wikipedia://en/185427), and [subsets](wikipedia://en/27631). Many other classes were later characterized in such a manner.

## The setting {#The_setting}

When we use the logic formalism to describe a computational problem, the input is a finite structure, and the elements of that structure are the [domain of discourse](wikipedia://en/229180). Usually the input is either a string (of bits or over an alphabet) and the elements of the logical structure represent positions of the string, or the input is a graph and the elements of the logical structure represent its vertices. The length of the input will be measured by the size of the respective structure. Whatever the structure is, we can assume that there are relations that can be tested, for example "$E(x,y)$ is true if and only if there is an edge from $x$ to $y$" (in case of the structure being a graph), or "$P(n)$ is true if and only if the $n$th letter of the string is 1." These relations are the predicates for the first-order logic system. We also have constants, which are special elements of the respective structure, for example if we want to check reachability in a graph, we will have to choose two constants *s* (start) and *t* (terminal).

In descriptive complexity theory we often assume that there is a [total order](wikipedia://en/30330) over the elements and that we can check equality between elements. This lets us consider elements as numbers: the element $x$ represents the number $n$ if and only if there are $(n-1)$ elements $y$ with $y<x$. Thanks to this we also may have the primitive predicate "bit", where $bit(x,k)$ is true if only the $k$th bit of the binary expansion of $x$ is 1. (We can replace addition and multiplication by ternary relations such that $plus(x,y,z)$ is true if and only if $x+y=z$ and $times(x,y,z)$ is true if and only if $x*y=z$).

## Overview of characterisations of complexity classes {#Overview_of_characterisations_of_complexity_classes}

If we restrict ourselves to ordered structures with a successor relation and basic arithmetical predicates, then we get the following characterisations:

- [First-order logic](wikipedia://en/10983) defines the class of [logspace-uniform](https://en.wikipedia.org/wiki/Logspace_uniform) [AC<sup>0</sup>](wikipedia://en/7400698), the languages recognized by polynomial-size circuits of bounded depth, which equals the languages recognized by a [concurrent random access machine](https://en.wikipedia.org/wiki/Concurrent_random_access_machine) in constant time.[^n2]
- First-order logic augmented with majority operators yield logspace-uniform [TC<sup>0</sup>](wikipedia://en/7399828).[^n3]
- First-order logic augmented with symmetric or deterministic [transitive closure](wikipedia://en/292239) operators yield [L](wikipedia://en/1149999), problems solvable in logarithmic space.[^n4]
- First-order logic with a [transitive closure](wikipedia://en/292239) operator yields [NL](wikipedia://en/1145955), the problems solvable in nondeterministic logarithmic space.[^n5]
- First-order logic with a [least fixed point](wikipedia://en/1211913) operator gives [P](wikipedia://en/658550), the problems solvable in deterministic polynomial time, **but uniquely on ordered structures**.[^n5]
- [Fagin's theorem](wikipedia://en/3122050): Existential second-order logic yields [NP](wikipedia://en/21562).[^n5]
- Universal second-order logic (excluding existential second-order quantification) yields [co-NP](wikipedia://en/6184).[^n6]
- [Second-order](https://en.wikipedia.org/wiki/SO_%28complexity%29) logic corresponds to [the polynomial hierarchy PH](https://en.wikipedia.org/wiki/PH_%28complexity%29).[^n5]
- Second-order logic with a [transitive closure](wikipedia://en/292239) operator (commutative or not) yields [PSPACE](wikipedia://en/39351), the problems solvable in polynomial space.[^n7]
- Second-order logic with a [least fixed point](wikipedia://en/1211913) operator gives [EXPTIME](wikipedia://en/54694), the problems solvable in exponential time.[^n8]
- [HO](https://en.wikipedia.org/wiki/HO_%28complexity%29), the complexity class defined by [higher-order logic](wikipedia://en/562883), is equal to [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY)[^n9]

## Sub-polynomial time {#Sub-polynomial_time}

### FO without any operators {#FO_without_any_operators}

In [circuit complexity](wikipedia://en/7641969), first-order logic with arbitrary predicates can be shown to be equal to [AC<sup>0</sup>](wikipedia://en/7400698), the first class in the [AC](wikipedia://en/7401755) hierarchy. Indeed, there is a natural translation from FO's symbols to nodes of circuits, with $\forall, \exists$ being $\land$ and $\lor$ of size $n$. First-order logic in a signature with arithmetical predicates characterises the restriction of the AC<sup>0</sup> family of circuits to those constructible in [alternating logarithmic time](https://en.wikipedia.org/wiki/LH_%28complexity%29).[^n2] First-order logic in a signature with only the order relation corresponds to the set of [star-free languages](wikipedia://en/4922792).[^n10][^n11]

### Transitive closure logic {#Transitive_closure_logic}

First-order logic gains substantially in expressive power when it is augmented with an operator that computes the transitive closure of a binary relation. The resulting [transitive closure logic](https://en.wikipedia.org/wiki/Transitive_closure_logic) is known to characterise [non-deterministic logarithmic space (NL)](wikipedia://en/1145955) on ordered structures. This was used by [Immerman](https://en.wikipedia.org/wiki/Neil_Immerman) to show that NL is closed under complement (i. e. that NL = co-NL).[^n12]

When restricting the transitive closure operator to [deterministic transitive closure](wikipedia://en/50026488#Deterministic_transitive_closure_logic), the resulting logic exactly characterises [logarithmic space](wikipedia://en/1149999) on ordered structures.

### Second-order Krom formulae {#Second-order_Krom_formulae}

On structures that have a successor function, NL can also be characterised by second-order [Krom formulae](https://en.wikipedia.org/wiki/Krom_formula).

SO-Krom is the set of Boolean queries definable with second-order formulae in [conjunctive normal form](wikipedia://en/73342) such that the first-order quantifiers are universal and the quantifier-free part of the formula is in Krom form, which means that the first-order formula is a conjunction of disjunctions, and in each "disjunction" there are at most two variables. Every second-order Krom formula is equivalent to an existential second-order Krom formula.

SO-Krom characterises NL on structures with a successor function.[^n13]

## Polynomial time {#Polynomial_time}

On ordered structures, first-order [least fixed-point logic](https://en.wikipedia.org/wiki/Least_fixed-point_logic) captures [PTIME](https://en.wikipedia.org/wiki/PTIME):

::: {#o27 .pointer-item cue=pointer name="Immerman-Vardi theorem"}

### First-order least fixed-point logic {#First-order_least_fixed-point_logic}

FO\[LFP\] is the extension of first-order logic by a least fixed-point operator, which expresses the fixed-point of a monotone expression. This augments first-order logic with the ability to express recursion. The Immerman–Vardi theorem, shown independently by [Immerman](https://en.wikipedia.org/wiki/Neil_Immerman) and [Vardi](https://en.wikipedia.org/wiki/Moshe_Vardi), shows that FO\[LFP\] characterises PTIME on ordered structures.[^n14][^n15]

, it is still open whether there is a natural logic characterising PTIME on unordered structures.

The [Abiteboul–Vianu theorem](https://en.wikipedia.org/wiki/Abiteboul–Vianu_theorem) states that FO\[LFP\]=FO\[PFP\] on all structures if and only if FO\[LFP\]=FO\[PFP\]; hence if and only if P=PSPACE. This result has been extended to other fixpoints.[^n8]

:::

### Second-order Horn formulae {#Second-order_Horn_formulae}

In the presence of a successor function, PTIME can also be characterised by second-order Horn formulae.

SO-Horn is the set of Boolean queries definable with SO formulae in [disjunctive normal form](wikipedia://en/73341) such that the first-order quantifiers are all universal and the quantifier-free part of the formula is in [Horn](wikipedia://en/333824) form, which means that it is a big AND of OR, and in each "OR" every variable except possibly one are negated.

This class is equal to [P](wikipedia://en/658550) on structures with a successor function.[^n16]

Those formulae can be transformed to prenex formulas in existential second-order Horn logic.[^n13]

## Non-deterministic polynomial time {#Non-deterministic_polynomial_time}

::: {#o36 .statement kind=statement/theorem cue=named-heading name="Fagin's theorem"}

### Fagin's theorem {#Fagin's_theorem}

Ronald Fagin's 1974 proof that the complexity class NP was characterised exactly by those classes of structures axiomatizable in existential second-order logic was the starting point of descriptive complexity theory.[^n6][^n17]

Since the complement of an existential formula is a universal formula, it follows immediately that co-NP is characterized by universal second-order logic.[^n6]

SO, unrestricted second-order logic, is equal to the [Polynomial hierarchy PH](wikipedia://en/658651). More precisely, we have the following generalisation of Fagin's theorem: The set of formulae in prenex normal form where existential and universal quantifiers of second order alternate *k* times characterise the *k*th level of the polynomial hierarchy.[^n18]

Unlike most other characterisations of complexity classes, Fagin's theorem and its generalisation do not presuppose a total ordering on the structures. This is because existential second-order logic is itself sufficiently expressive to refer to the possible total orders on a structure using second-order variables.[^n19]

:::

## Beyond NP {#Beyond_NP}

### Partial fixed point is PSPACE {#Partial_fixed_point_is_PSPACE}

The class of all problems computable in polynomial space, [PSPACE](wikipedia://en/39351), can be characterised by augmenting first-order logic with a more expressive partial fixed-point operator.

[Partial fixed-point logic](https://en.wikipedia.org/wiki/Partial_fixed-point_logic), FO\[PFP\], is the extension of first-order logic with a partial fixed-point operator, which expresses the fixed-point of a formula if there is one and returns 'false' otherwise.

Partial fixed-point logic characterises [PSPACE](wikipedia://en/39351) on ordered structures.[^n20]

### Transitive closure is PSPACE {#Transitive_closure_is_PSPACE}

Second-order logic can be extended by a transitive closure operator in the same way as first-order logic, resulting in SO\[TC\]. The TC operator can now also take second-order variables as argument. SO\[TC\] characterises [PSPACE](wikipedia://en/39351). Since ordering can be referenced in second-order logic, this characterisation does not presuppose ordered structures.[^n21]

## Elementary functions {#Elementary_functions}

The [time complexity](wikipedia://en/405944) class [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY) of elementary functions can be characterised by **HO**, the [complexity class](wikipedia://en/502426) of structures that can be recognized by formulas of [higher-order logic](wikipedia://en/562883). Higher-order logic is an extension of [first-order logic](wikipedia://en/10983) and [second-order logic](wikipedia://en/341428) with higher-order quantifiers. There is a relation between the $i$th order and non-deterministic algorithms the time of which is bounded by $i-1$ levels of exponentials.[^n9]

::: {#o50 .definition cue=heading name="Definition"}

### Definition {#Definition}

We define higher-order variables. A variable of order $i>1$ has an arity $k$ and represents any set of $k$-[tuples](wikipedia://en/132729) of elements of order $i-1$. They are usually written in upper-case and with a [natural number](wikipedia://en/21474) as exponent to indicate the order. Higher-order logic is the set of first-order formulae where we add quantification over higher-order variables; hence we will use the terms defined in the [FO](https://en.wikipedia.org/wiki/FO_%28complexity%29) article without defining them again.

HO$^i$ is the set of formulae with variables of order at most $i$. HO$^i_j$ is the subset of formulae of the form $\phi=\exists \overline{X^i_1}\forall\overline{X_2^i}\dots Q \overline{X_j^i}\psi$, where $Q$ is a quantifier and $Q \overline{X^i}$ means that $\overline{X^i}$ is a tuple of variable of order $i$ with the same quantification. So HO$^i_j$ is the set of formulae with $j$ alternations of quantifiers of order $i$, beginning with $\exists$, followed by a formula of order $i-1$.

Using the standard notation of the [tetration](wikipedia://en/482379#Notation), $\exp_2^0(x)=x$ and $\exp_2^{i+1}(x)=2^{\exp_2^{i}(x)}$. $\exp_2^{i+1}(x)=2^{2^{2^{2^{\dots^{2^{x}}}}}}$ with $i$ times $2$

:::

### Normal form {#Normal_form}

Every formula of order $i$th is equivalent to a formula in prenex normal form, where we first write quantification over variable of $i$th order and then a formula of order $i-1$ in normal form.

### Relation to complexity classes {#Relation_to_complexity_classes}

HO is equal to the class [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY) of elementary functions. To be more precise, $\mathsf{HO}^i_0 = \mathsf{NTIME}(\exp_2^{i-2}(n^{O(1)}))$, meaning a tower of $(i-2)$ 2s, ending with $n^c$, where $c$ is a constant. A special case of this is that [$\exists\mathsf{SO}=\mathsf{HO}^2_0=\mathsf{NTIME}(n^{O(1)})={\color{Blue}\mathsf{NP}}$](wikipedia://en/21562), which is exactly [Fagin's theorem](wikipedia://en/3122050). Using [oracle machines](wikipedia://en/22431) in the [polynomial hierarchy](wikipedia://en/658651), [$\mathsf{HO}^i_j={\color{Blue}\mathsf{NTIME}}(\exp_2^{i-2}(n^{O(1)})^{\Sigma_j^{\mathsf P}})$](wikipedia://en/658539)
