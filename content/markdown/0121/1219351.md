# Vojta

::: {#o1 .subject cue=lead name="Vojta"}

**Vojta** (feminine: **Vojtová**) is a [Czech surname](https://en.wikipedia.org/wiki/Czech_surname). It is a [pet name](https://en.wikipedia.org/wiki/Hypocorism) of the given name [Vojtěch](https://en.wikipedia.org/wiki/Vojtěch). Notable people with the surname include:

:::

- [Andreas Vojta](https://en.wikipedia.org/wiki/Andreas_Vojta) (born 1989), Austrian distance runner
- [Jakub Vojta (footballer)](https://en.wikipedia.org/wiki/Jakub_Vojta_%28footballer%29) (born 1991), Czech footballer
- [Jakub Vojta (ice hockey)](https://en.wikipedia.org/wiki/Jakub_Vojta_%28ice_hockey%29) (born 1987), Czech ice hockey player
- [Jan Ignác František Vojta](https://en.wikipedia.org/wiki/Jan_Ignác_František_Vojta) (c. 1657–1701), Czech composer
- [Jaroslav Vojta](https://en.wikipedia.org/wiki/Jaroslav_Vojta) (1888–1970), Czech film actor
- [Josef Vojta](https://en.wikipedia.org/wiki/Josef_Vojta) (1935–2023), Czech footballer
- [Linda Vojtová](https://en.wikipedia.org/wiki/Linda_Vojtová) (born 1985), Czech model
- [Matyáš Vojta](https://en.wikipedia.org/wiki/Matyáš_Vojta) (born 2004), Czech footballer
- [Paul Vojta](wikipedia://en/1802312) (born 1957), American mathematician
- [Přemysl Vojta](https://en.wikipedia.org/wiki/Přemysl_Vojta) (born 1983), Czech horn player
- [Rudolf Vojta](https://en.wikipedia.org/wiki/Rudolf_Vojta) (1912–1984), Austrian ice hockey player
- [Václav Vojta](https://en.wikipedia.org/wiki/Václav_Vojta) (1917–2000), Czech doctor
- [Veronika Vojtová](https://en.wikipedia.org/wiki/Veronika_Vojtová) (born 1990), Czech slalom canoeist
