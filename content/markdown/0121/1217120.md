# Algebra of random variables

::: {#o1 .subject cue=lead name="Algebra of random variables"}

In [statistics](wikipedia://en/26685), the **algebra of random variables** provides rules for the [symbolic manipulation](https://en.wikipedia.org/wiki/Symbolic_computation) of [random variables](wikipedia://en/25685), while avoiding delving too deeply into the mathematically sophisticated ideas of [probability theory](wikipedia://en/23542). Its symbolism allows the treatment of sums, products, ratios and general functions of random variables, as well as dealing with operations such as finding the [probability distributions](wikipedia://en/23543) and the [expectations](https://en.wikipedia.org/wiki/Expected_values) (or expected values), [variances](wikipedia://en/32344) and [covariances](wikipedia://en/157059) of such combinations.

:::

In principle, the [elementary algebra](wikipedia://en/9710) of random variables is equivalent to that of conventional non-random (or deterministic) variables. However, the changes occurring on the probability distribution of a random variable obtained after performing [algebraic operations](wikipedia://en/5438924) are not straightforward. Therefore, the behavior of the different operators of the probability distribution, such as expected values, variances, covariances, and [moments](wikipedia://en/368684), may be different from that observed for the random variable using symbolic algebra. It is possible to identify some key rules for each of those operators, resulting in different types of algebra for random variables, apart from the elementary symbolic algebra: Expectation algebra, Variance algebra, Covariance algebra, Moment algebra, etc.

## Elementary symbolic algebra of random variables {#Elementary_symbolic_algebra_of_random_variables}

Considering two random variables $X$ and $Y$, the following algebraic operations are possible:

- [Addition](wikipedia://en/61338): $Z = X + Y = Y + X$
- [Subtraction](wikipedia://en/74141): $Z = X - Y = - Y + X$
- [Multiplication](wikipedia://en/20845): $Z = X Y = Y X$
- [Division](wikipedia://en/53696): Suppose $Y \neq 0$, $Z = X / Y = X \cdot (1/Y) = (1/Y) \cdot X$.
- [Exponentiation](wikipedia://en/99491): $Z = X^Y = e^{Y\ln(X)}$

In all cases, the variable $Z$ resulting from each operation is also a random variable. All [commutative](wikipedia://en/294390) and [associative](wikipedia://en/1335) properties of conventional algebraic operations are also valid for random variables. If any of the random variables is replaced by a deterministic variable or by a constant value, all the previous properties remain valid.

## Expectation algebra for random variables {#Expectation_algebra_for_random_variables}

The expected value $\operatorname{E}[Z]$ of the random variable $Z$ resulting from an algebraic operation between two random variables can be calculated using the following set of rules:

- [Addition](wikipedia://en/61338): $\operatorname{E}[Z] = \operatorname{E}[X+Y] = \operatorname{E}[X] + \operatorname{E}[Y] = \operatorname{E}[Y] + \operatorname{E}[X]$
- [Subtraction](wikipedia://en/74141): $\operatorname{E}[Z] = \operatorname{E}[X-Y] = \operatorname{E}[X] - \operatorname{E}[Y] = -\operatorname{E}[Y] + \operatorname{E}[X]$
- [Multiplication](wikipedia://en/20845): $\operatorname{E}[Z] = \operatorname{E}[X Y] = \operatorname{E}[YX]$. Particularly, if $X$ and $Y$ are [independent](wikipedia://en/27593) from each other, then: $\operatorname{E}[X Y] = \operatorname{E}[X] \cdot \operatorname{E}[Y] = \operatorname{E}[Y] \cdot \operatorname{E}[X]$.
- [Division](wikipedia://en/53696): $\operatorname{E}[Z] = \operatorname{E}[X/Y] = \operatorname{E}[X \cdot (1/Y)] = \operatorname{E}[(1/Y) \cdot X]$. Particularly, if $X$ and $Y$ are independent from each other, then: $\operatorname{E}[X/Y] = \operatorname{E}[X] \cdot \operatorname{E}[1/Y] = \operatorname{E}[1/Y] \cdot \operatorname{E}[X]$.
- [Exponentiation](wikipedia://en/99491): $\operatorname{E}[Z] = \operatorname{E}[X^Y] = \operatorname{E}[e^{Y\ln(X)}]$

If any of the random variables is replaced by a deterministic variable or by a constant value ($k$), the previous properties remain valid considering that $\Pr(X = k) = 1$ and, therefore, $\operatorname{E}[X] = k$.

If $Z$ is defined as a general non-linear algebraic function $f$ of a random variable $X$, then:

$$\operatorname{E}[Z] = \operatorname{E}[f(X)] \neq f(\operatorname{E}[X])$$

Some examples of this property include:

- $$\operatorname{E}[X^2] \neq \operatorname{E}[X]^2$$
- $$\operatorname{E}[1/X] \neq 1/\operatorname{E}[X]$$
- $$\operatorname{E}[e^X] \neq e^{\operatorname{E}[X]}$$
- $$\operatorname{E}[\ln(X)] \neq \ln(\operatorname{E}[X])$$

The exact value of the expectation of the non-linear function will depend on the particular probability distribution of the random variable $X$.

## Variance algebra for random variables {#Variance_algebra_for_random_variables}

The variance $\operatorname{Var}[Z]$ of the random variable $Z$ resulting from an algebraic operation between random variables can be calculated using the following set of rules:

- [Addition](wikipedia://en/61338): $$\operatorname{Var}[Z] = \operatorname{Var}[X+Y] = \operatorname{Var}[X] + 2 \operatorname{Cov}[X,Y] + \operatorname{Var}[Y].$$ Particularly, if $X$ and $Y$ are [independent](wikipedia://en/27593) from each other, then: $$\operatorname{Var}[X+Y] = \operatorname{Var}[X] + \operatorname{Var}[Y].$$
- [Subtraction](wikipedia://en/74141): $$\operatorname{Var}[Z] = \operatorname{Var}[X-Y] = \operatorname{Var}[X] - 2 \operatorname{Cov}[X,Y] + \operatorname{Var}[Y].$$ Particularly, if $X$ and $Y$ are independent from each other, then: $$\operatorname{Var}[X-Y] = \operatorname{Var}[X] + \operatorname{Var}[Y].$$ That is, for [independent random variables](https://en.wikipedia.org/wiki/Independent_random_variables) the variance is the same for additions and subtractions: $$\operatorname{Var}[X+Y] = \operatorname{Var}[X-Y] = \operatorname{Var}[Y-X] = \operatorname{Var}[-X-Y].$$
- [Multiplication](wikipedia://en/20845): $$\operatorname{Var}[Z] = \operatorname{Var}[XY] = \operatorname{Var}[YX].$$ Particularly, if $X$ and $Y$ are independent from each other, then: $$\begin{aligned} \operatorname{Var}[XY] &= \operatorname{E}[X^2] \cdot \operatorname{E}[Y^2] - {\left(\operatorname{E}[X] \cdot \operatorname{E}[Y]\right)}^2 \\[2pt] &= \operatorname{Var}[X] \cdot \operatorname{Var}[Y] + \operatorname{Var}[X] \cdot {\left(\operatorname{E}[Y]\right)}^2 + \operatorname{Var}[Y] \cdot {\left(\operatorname{E}[X]\right)}^2. \end{aligned}$$
- [Division](wikipedia://en/53696): $$\operatorname{Var}[Z] = \operatorname{Var}[X/Y] = \operatorname{Var}[X \cdot (1/Y)] = \operatorname{Var}[(1/Y) \cdot X].$$ Particularly, if $X$ and $Y$ are independent from each other, then: $$\begin{aligned} \operatorname{Var}[X/Y] &= \operatorname{E}[X^2] \cdot \operatorname{E}[1/Y^2] - {\left(\operatorname{E}[X] \cdot \operatorname{E}[1/Y]\right)}^2 \\[2pt] &= \operatorname{Var}[X] \cdot \operatorname{Var}[1/Y] + \operatorname{Var}[X] \cdot {\left(\operatorname{E}[1/Y]\right)}^2 + \operatorname{Var}[1/Y] \cdot {\left(\operatorname{E}[X]\right)}^2. \end{aligned}$$
- [Exponentiation](wikipedia://en/99491): $$\operatorname{Var}[Z] = \operatorname{Var}[X^Y] = \operatorname{Var}[e^{Y\ln(X)}]$$

where $\operatorname{Cov}[X,Y] = \operatorname{Cov}[Y,X]$ represents the [covariance operator](wikipedia://en/33447667) between random variables $X$ and $Y$.

The variance of a random variable can also be expressed directly in terms of the covariance or in terms of the expected value:

$$\operatorname{Var}[X] = \operatorname{Cov}(X,X) = \operatorname{E}[X^2] - \operatorname{E}[X]^2$$

If any of the random variables is replaced by a deterministic variable or by a constant value ($k$), the previous properties remain valid considering that $\Pr(X = k) = 1$ and $\operatorname{E}[X] = k$, $\operatorname{Var}[X] = 0$ and $\operatorname{Cov}[Y,k] = 0$. Special cases are the addition and multiplication of a random variable with a deterministic variable or a constant, where:

- $$\operatorname{Var}[k+Y] = \operatorname{Var}[Y]$$
- $$\operatorname{Var}[kY] = k^2 \operatorname{Var}[Y]$$

If $Z$ is defined as a general non-linear algebraic function $f$ of a random variable $X$, then:

$$\operatorname{Var}[Z] = \operatorname{Var}[f(X)] \neq f(\operatorname{Var}[X])$$

The exact value of the variance of the non-linear function will depend on the particular probability distribution of the random variable $X$.

## Covariance algebra for random variables {#Covariance_algebra_for_random_variables}

The covariance ($\operatorname{Cov}[Z,X]$) between the random variable $Z$ resulting from an algebraic operation and the random variable $X$ can be calculated using the following set of rules:

- [Addition](wikipedia://en/61338): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[X+Y,X] = \operatorname{Var}[X] + \operatorname{Cov}[X,Y].$$ If $X$ and $Y$ are [independent](wikipedia://en/27593) from each other, then: $$\operatorname{Cov}[X+Y,X] = \operatorname{Var}[X].$$
- [Subtraction](wikipedia://en/74141): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[X-Y,X] = \operatorname{Var}[X] - \operatorname{Cov}[X,Y].$$ If $X$ and $Y$ are independent from each other, then: $$\operatorname{Cov}[X-Y,X] = \operatorname{Var}[X].$$
- [Multiplication](wikipedia://en/20845): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[XY,X] = \operatorname{E}[X^2Y] - \operatorname{E}[XY] \operatorname{E}[X].$$ If $X$ and $Y$ are independent from each other, then: $$\operatorname{Cov}[XY,X] = \operatorname{Var}[X] \cdot \operatorname{E}[Y].$$
- [Division](wikipedia://en/53696) (covariance with respect to the numerator): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[X/Y,X] = \operatorname{E}[X^2/Y] - \operatorname{E}[X/Y] \operatorname{E}[X].$$ If $X$ and $Y$ are independent from each other, then: $$\operatorname{Cov}[X/Y,X] = \operatorname{Var}[X] \cdot \operatorname{E}[1/Y].$$
- [Division](wikipedia://en/53696) (covariance with respect to the denominator): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[Y/X,X] = \operatorname{E}[Y] - \operatorname{E}[Y/X] \operatorname{E}[X].$$ If $X$ and $Y$ are independent from each other, then: $$\operatorname{Cov}[Y/X,X] = \operatorname{E}[Y] \cdot (1-\operatorname{E}[X] \cdot \operatorname{E}[1/X]).$$
- [Exponentiation](wikipedia://en/99491) (covariance with respect to the base): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[X^Y,X] = \operatorname{E}[X^{Y+1}]-\operatorname{E}[X^Y] \operatorname{E}[X].$$
- [Exponentiation](wikipedia://en/99491) (covariance with respect to the power): $$\operatorname{Cov}[Z,X] = \operatorname{Cov}[Y^X,X] = \operatorname{E}[XY^X]-\operatorname{E}[Y^X] \operatorname{E}[X].$$

The covariance of a random variable can also be expressed directly in terms of the expected value:

$$\operatorname{Cov}(X,Y) = \operatorname{E}[XY] - \operatorname{E}[X]\operatorname{E}[Y]$$

If any of the random variables is replaced by a deterministic variable or by a constant value ($k$), the previous properties remain valid considering that $\operatorname{E}[k] = k$, $\operatorname{Var}[k] = 0$ and $\operatorname{Cov}[X,k]=0$.

If $Z$ is defined as a general non-linear algebraic function $f$ of a random variable $X$, then:

$$\operatorname{Cov}[Z,X] = \operatorname{Cov}[f(X),X] = \operatorname{E}[Xf(X)] - \operatorname{E}[f(X)] \operatorname{E}[X]$$

The exact value of the covariance of the non-linear function will depend on the particular probability distribution of the random variable $X$.

## Approximations by Taylor series expansions of moments {#Approximations_by_Taylor_series_expansions_of_moments}

If the [moments](wikipedia://en/368684) of a certain random variable $X$ are known (or can be determined by integration if the [probability density function](wikipedia://en/43487) is known), then it is possible to approximate the expected value of any general non-linear function $f(X)$ as a [Taylor series expansion of the moments](wikipedia://en/3973645), as follows:

$$f(X) = \sum_{n=0}^\infty \frac{1}{n!} \left(\frac{d^n f}{dX^n}\right)_{X=\mu} {\left(X - \mu\right)}^n,$$

where $\mu = \operatorname{E}[X]$ is the mean value of $X$.

$$\begin{aligned} \operatorname{E}[f(X)] &= \operatorname{E}\left[ \sum_{n=0}^\infty \frac{1}{n!}\left({d^nf \over dX^n}\right)_{X=\mu} {\left(X-\mu\right)}^n\right] \\ &= \sum_{n=0}^\infty \frac{1}{n!}\left(\frac{d^n f}{dX^n}\right)_{X=\mu} \operatorname{E}\left[{\left(X - \mu\right)}^n\right] \\ &= \sum_{n=0}^\infty \frac{1}{n!}\left({d^nf \over dX^n}\right)_{X=\mu}\mu_n(X), \end{aligned}$$

where $\mu_n(X) = \operatorname{E}[(X-\mu)^n]$ is the *n*-th moment of $X$ about its mean. Note that by their definition, $\mu_0(X)=1$ and $\mu_1(X)=0$. The first order term always vanishes but was kept to obtain a closed form expression.

Then,

$$\operatorname{E}[f(X)] \approx \sum_{n=0}^{n_{\max}} \frac{1}{n!} \left(\frac{d^nf}{dX^n}\right)_{X=\mu}\mu_n(X),$$

where the Taylor expansion is truncated after the $n_{\max}$-th moment.

Particularly for functions of [normal random variables](https://en.wikipedia.org/wiki/Normal_random_variable), it is possible to obtain a Taylor expansion in terms of the [standard normal distribution](https://en.wikipedia.org/wiki/Standard_normal_distribution):[^o7]

$$f(X) = \sum_{n=0}^\infty \frac{\sigma^n}{n!} \left(\frac{d^n f}{dX^n}\right)_{X=\mu} \mu_n(Z),$$

where $X \sim N(\mu,\sigma ^2)$ is a normal random variable, and $Z\sim N(0,1)$ is the standard normal distribution. Thus,

$$\operatorname{E}[f(X)]\approx \sum_{n=0}^{n_{\max}} {\sigma ^n \over n!} \left({d^nf \over dX^n}\right)_{X=\mu} \mu_n(Z) ,$$

where the moments of the standard normal distribution are given by:

$$\mu_n(Z) = \begin{cases} \prod_{i=1}^{n/2}(2i-1), & \text{if } n \text{ is even} \\ 0, & \text{if }n\text{ is odd} \end{cases}$$

Similarly for normal random variables, it is also possible to approximate the variance of the non-linear function as a Taylor series expansion as:

$$\operatorname{Var}[f(X)] \approx \sum_{n=1}^{n_{\max}} \left({\sigma^n \over n!} \left({d^nf \over dX^n}\right)_{X=\mu}\right)^2 \operatorname{Var}[Z^n] + \sum_{n=1}^{n_{\max}} \sum_{m \neq n} \frac{\sigma^{n+m}}{{n!m!}} \left({d^nf \over dX^n}\right)_{X=\mu} \left({d^mf \over dX^m}\right)_{X=\mu} \operatorname{Cov}[Z^n,Z^m],$$

where

$$\operatorname{Var}[Z^n] = \begin{cases} \prod_{i=1}^{n}(2i-1) -\prod_{i=1}^{n/2}(2i-1)^2, & \text{if }n\text{ is even} \\ \prod_{i=1}^{n}(2i-1), & \text{if }n\text{ is odd}, \end{cases}$$

and

$$\operatorname{Cov}[Z^n,Z^m] = \begin{cases} \prod_{i=1}^{(n+m)/2}(2i-1) -\prod_{i=1}^{n/2}(2i-1) \prod_{j=1}^{m/2}(2j-1), & \text{if }n\text{ and }m \text{ are even} \\ \prod_{i=1}^{(n+m)/2}(2i-1), & \text{if }n\text{ and }m\text{ are odd} \\ 0, & \text{otherwise} \end{cases}$$

## Algebra of complex random variables {#Algebra_of_complex_random_variables}

In the [algebraic](wikipedia://en/18716923) [axiomatization](wikipedia://en/928) of [probability theory](wikipedia://en/23542), the primary concept is not that of probability of an event, but rather that of a [random variable](wikipedia://en/25685). [Probability distributions](wikipedia://en/23543) are determined by assigning an [expectation](wikipedia://en/9653) to each random variable. The [measurable space](wikipedia://en/19873) and the probability measure arise from the random variables and expectations by means of well-known [representation theorems](wikipedia://en/4783135) of analysis. One of the important features of the algebraic approach is that apparently infinite-dimensional probability distributions are not harder to formalize than finite-dimensional ones.

Random variables are assumed to have the following properties:

1. [complex](wikipedia://en/5826) constants are possible [realizations](wikipedia://en/10354022) of a random variable;
1. the sum of two random variables is a random variable;
1. the product of two random variables is a random variable;
1. addition and multiplication of random variables are both [commutative](https://en.wikipedia.org/wiki/Commutative); and
1. there is a notion of conjugation of random variables, satisfying $(XY)^{*} = Y^{*}X^{*}$ and $X^{**} = X$ for all random variables $X,Y$ and coinciding with [complex conjugation](wikipedia://en/173918) if $X$ is a constant.

This means that random variables form complex commutative [\*-algebras](wikipedia://en/293426). If $X = X^{*}$ then the random variable $X$ is called "real".

An expectation $E$ on an algebra $A$ of random variables is a normalized, positive [linear functional](https://en.wikipedia.org/wiki/Linear_functional). What this means is that

1. $E[k] = k$ where $k$ is a constant;
1. $E[X^{*}X] \ge 0$ for all random variables $X$;
1. $E[X + Y] = E[X] + E[Y]$ for all random variables $X$ and $Y$; and
1. $E[kX] = kE[X]$ if $k$ is a constant.

One may generalize this setup, allowing the algebra to be noncommutative. This leads to other areas of noncommutative probability such as [quantum probability](https://en.wikipedia.org/wiki/Quantum_probability), [random matrix theory](https://en.wikipedia.org/wiki/Random_matrix_theory), and [free probability](wikipedia://en/679696).
