# PreCICE (software)

::: {#o2 .subject cue=lead name="PreCICE"}

**preCICE** is a [free/open-source](https://en.wikipedia.org/wiki/Free_software) coupling [library](https://en.wikipedia.org/wiki/Library_%28computing%29) for partitioned [multi-physics simulations](https://en.wikipedia.org/wiki/Multiphysics_simulation). preCICE is not specific to particular applications or tools, but instead couples independent codes capable of simulating a subpart of the complete physics involved in a simulation.

:::

A coupled simulation consists on multiple simulation codes calling the preCICE API and a shared configuration file describing the simulation setup. Once launched, the preCICE library establishes connections between the individual simulation codes and coordinates their progression in time until a configured end condition is fulfilled.[^o16]

preCICE supports nodal data on [unstructured meshes](wikipedia://en/3772072), a wide range of [interpolation schemes](wikipedia://en/14569) between non-conforming meshes and in time, implicit schemes with various convergence acceleration methods, and support for solvers using [MPI parallelization](https://en.wikipedia.org/wiki/Message_Passing_Interface), partially overlapping with features offered by other coupling tools.[^o23]

The preCICE API is available in [C++](https://en.wikipedia.org/wiki/C++), with [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) and [Fortran](https://en.wikipedia.org/wiki/Fortran) bindings provided as part of the library. External support includes [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [Rust](https://en.wikipedia.org/wiki/Rust_%28programming_language%29), [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), and [Matlab](https://en.wikipedia.org/wiki/Matlab).[^o17]

The software originates from a [fluid-structure interaction](wikipedia://en/6061729) on [High-performance computing](https://en.wikipedia.org/wiki/High-performance_computing) context.[^o22] Other common applications include studies of [conjugate heat transfer](https://en.wikipedia.org/wiki/Conjugate_convective_heat_transfer), [hemodynamics](https://en.wikipedia.org/wiki/Hemodynamics), [muscle-tendon systems](https://en.wikipedia.org/wiki/Muscle_contraction), [geothermal energy](https://en.wikipedia.org/wiki/Geothermal_energy), [porous media flow](https://en.wikipedia.org/wiki/Fluid_flow_through_porous_media), and more[^o17]).

## History {#History}

### Early years {#Early_years}

The name "preCICE" (*precise code interaction coupling environment*) appears in literature first in 2010.[^o14] preCICE is a direct successor of FSI\*ce, developed at the [Technical University of Munich](https://en.wikipedia.org/wiki/Technical_University_of_Munich), which mainly targeted [fluid-structure interaction](https://en.wikipedia.org/wiki/Fluid-structure_interaction) simulations.[^o15] FSI\*ce was a result of a [German Research Foundation](https://en.wikipedia.org/wiki/German_Research_Foundation) project in the Research Group Fluid-Structure Interaction: Modelling, Simulation, Optimisation (FOR493).[^o5]

### preCICE v1 {#preCICE_v1}

In May 2015, the development of preCICE was moved to its own organization on GitHub. The first stable version v1.0.0 of the core library was released in November 2017.

preCICE v1 included a variety of coupling schemes (explicit and implicit, [Aitken underrelaxation](wikipedia://en/7411694), [Anderson](wikipedia://en/64345820) and [Broyden](wikipedia://en/10971756) [quasi-Newton](wikipedia://en/7883127) acceleration algorithms), data mapping methods ([nearest-neighbor](https://en.wikipedia.org/wiki/Nearest-neighbor_interpolation), nearest-projection, [RBF](wikipedia://en/60415297)), and communication methods ([TCP/IP sockets](https://en.wikipedia.org/wiki/Network_socket), [MPI](https://en.wikipedia.org/wiki/Message_Passing_Interface) ports).[^o16]

The v1.x release cycle saw releases until v1.6.1, in September 2019.

### preCICE v2 {#preCICE_v2}

By 2020, the preCICE project saw development in different directions: extensive refactoring and testing of the core library, large expansion of the available documentation, development of several new adapters and several community building measures.[^o17] Several of these changes are connected to the acceptance of preCICE into the extreme-scale scientific software development kit (xSDK). Due to increased number of components, the preCICE distribution was introduced as a citable bundle of components working together.

The v2.x release cycle saw releases until v2.5.1, in January 2024.

### preCICE v3 {#preCICE_v3}

preCICE v3.0.0 was released in February 2024. Notable changes of v3 include simplifications in the API and configuration, multirate and higher-order time stepping,[^o21] and faster RBF mapping based on a [partition of unity](wikipedia://en/48636) approach.

At the time of the v3 release cycle, the project has expanded from targeting mainly surface coupling to also targeting volume coupling (overlapping domains, see [domain decomposition methods](wikipedia://en/16230272)), geometric multiscale mapping, system codes implementing the [Functional Mock-up Interface](https://en.wikipedia.org/wiki/Functional_Mock-up_Interface).,[^o19] and [multiscale simulations](wikipedia://en/4003614)[^o20]

## Coupled codes {#Coupled_codes}

While preCICE is a software library with an [API](https://en.wikipedia.org/wiki/API) that can be used by programmers to couple their own code, there exist several integrations with several simulation codes, making preCICE more accessible to end users that are not primarily programmers (such as applied mathematicians, mechanical engineers, or climate scientists).

In the terminology used by preCICE, the integrations to simulation codes are called adapters[^o17] and can be maintained by the preCICE developers or third parties.

Example codes that preCICE integrates with via adapters include,[^o18] among others:

- [CalculiX](https://en.wikipedia.org/wiki/Calculix)
- [deal.II](wikipedia://en/36639312)
- [DUNE](wikipedia://en/14854086)
- [Elmer](https://en.wikipedia.org/wiki/Elmer_FEM_solver)
- [FEBio](https://en.wikipedia.org/wiki/FEBio)
- [FEniCS](https://en.wikipedia.org/wiki/FEniCS_Project)
- [OpenFOAM](https://en.wikipedia.org/wiki/OpenFOAM)
- [SU2](https://en.wikipedia.org/wiki/SU2_code)

The community has also coupled[^o17] CAMRAD II, DLR TAU, DUST, DuMuX, Rhoxyz, Ateles, XDEM, FLEXI, MBDyn, OpenFAST, LS-DYNA, and G+Smo.
