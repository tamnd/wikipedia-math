# Hurwitz-stable matrix

::: {#o1 .subject cue=lead name="Hurwitz-stable matrix"}

In [mathematics](wikipedia://en/18831), a **Hurwitz-stable matrix**,[^o2] or more commonly simply **Hurwitz matrix**,[^o3] is a [square matrix](wikipedia://en/166022) whose eigenvalues all have strictly negative real part. Some authors also use the term **stability matrix**.[^o3] Such matrices play an important role in [control theory](wikipedia://en/7039).

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [square matrix](wikipedia://en/166022) $A$ is called a Hurwitz matrix if every [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue) of $A$ has strictly negative [real part](https://en.wikipedia.org/wiki/Real_part), that is,

$$\operatorname{Re}[\lambda_i] < 0\,$$

for each eigenvalue $\lambda_i$. $A$ is also called a **stable matrix**, because then the [differential equation](wikipedia://en/32742753)

$$\dot x = A x$$

is [asymptotically stable](wikipedia://en/5493795), that is, $x(t)\to 0$ as $t\to\infty.$

If $G(s)$ is a (matrix-valued) [transfer function](wikipedia://en/31146), then $G$ is called Hurwitz if the [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) of all elements of $G$ have negative real part. Note that it is not necessary that $G(s),$ for a specific argument $s,$ be a Hurwitz matrix — it need not even be square. The connection is that if $A$ is a Hurwitz matrix, then the [dynamical system](wikipedia://en/9087)

$$\dot x(t)=A x(t) + B u(t)$$

$$y(t)=C x(t) + D u(t)\,$$

has a Hurwitz transfer function.

Any hyperbolic [fixed point](wikipedia://en/449738) (or [equilibrium point](https://en.wikipedia.org/wiki/Equilibrium_point)) of a continuous [dynamical system](https://en.wikipedia.org/wiki/Dynamical_system_%28definition%29) is locally [asymptotically stable](https://en.wikipedia.org/wiki/Asymptotic_stability) if and only if the [Jacobian](wikipedia://en/195351) of the dynamical system is Hurwitz stable at the fixed point.

The Hurwitz stability matrix is a crucial part of [control theory](wikipedia://en/7039). A system is *stable* if its control matrix is a Hurwitz matrix. The negative real components of the eigenvalues of the matrix represent [negative feedback](https://en.wikipedia.org/wiki/Negative_feedback). Similarly, a system is inherently *unstable* if any of the eigenvalues have positive real components, representing [positive feedback](https://en.wikipedia.org/wiki/Positive_feedback).
