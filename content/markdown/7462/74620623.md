# Kerr–Newman–de–Sitter metric

::: {#o1 .subject cue=lead name="Kerr–Newman–de–Sitter metric"}

The **Kerr–Newman–de–Sitter metric** (KNdS)[^o2][^o3] is one of the most general [stationary solutions](https://en.wikipedia.org/wiki/Stationary_spacetime) of the [Einstein–Maxwell equations](https://en.wikipedia.org/wiki/Einstein's_field_equation#Einstein–Maxwell_equations) in [general relativity](wikipedia://en/12024) that describes the spacetime geometry in the region surrounding an electrically charged, rotating mass embedded in an expanding universe. It generalizes the [Kerr–Newman metric](wikipedia://en/1447904) by taking into account the [cosmological constant](wikipedia://en/38992) $\Lambda$.

:::

## Boyer–Lindquist coordinates {#Boyer–Lindquist_coordinates}

In those coordinates the local clocks and rulers are at constant $\rm r$ and have no local orbital angular momentum $\rm (L_z=0)$, therefore they are corotating with the [frame-dragging](wikipedia://en/27086745) velocity relative to the fixed stars. In (+, −, −, −) [signature](wikipedia://en/463225) and in [natural units](https://en.wikipedia.org/wiki/Nondimensionalization) of $\rm G=M=c=k_e=1$ the KNdS metric is[^o5][^o6][^o7][^o8]

$$g_{\rm tt}= \rm -\frac{3 \ [ a^2 \ \sin^2 \theta \left(a^2 \ \Lambda \ \cos^2 \theta +3\right)+a^2 \left(\Lambda \ r^2-3\right)+\Lambda \ r^4-3 \ r^2+6 \ r-3 \mho^2 ] }{\left(a^2 \ \Lambda +3\right)^2 \left(a^2 \cos^2 \theta +r^2\right)}$$

$$g_{\rm rr}= \rm -\frac{a^2 \ \cos^2 \theta +r^2}{\left(a^2+r^2\right) \left(1-\frac{\Lambda \ r^2}{3}\right)-2 \ r+\mho^2}$$

$$g_{\rm \theta \theta}= \rm -\frac{3 \left(a^2 \ \cos^2 \theta +r^2\right)}{a^2 \ \Lambda \ \cos^2 \theta +3}$$

$$g_{\rm \phi \phi}= \rm\frac{9 \ \{ \frac{1}{3} \left(a^2+r^2\right)^2 \sin^2 \theta \left(a^2 \ \Lambda \cos^2 \theta +3\right)-a^2 \sin^4 \theta \ [ \left(a^2+r^2\right) \left(1-\Lambda \ r^2/3\right)-2 \ r+\mho ^2 ] \} }{-\left(a^2 \ \Lambda +3\right)^2 \left(a^2 \cos^2 \theta +r^2\right)}$$

$$g_{\rm t \phi}= \rm \frac{3 \ a \ \sin^2 \theta \ [ a^2 \ \Lambda \left(a^2+r^2\right) \cos^2 \theta +a^2 \ \Lambda \ r^2+\Lambda \ r^4+6 \ r-3 \ \mho^2 ] }{\left(a^2 \ \Lambda +3\right)^2 \left(a^2 \ \cos^2 \theta +r^2\right)}$$

with all the other metric tensor components $g_{\mu \nu}=0$, where $\rm a$ is the black hole's spin parameter, $\rm \mho$ its electric charge, and $\rm \Lambda=3 H^2$[^o9] the cosmological constant with $\rm H$ as the time-independent [Hubble parameter](wikipedia://en/336254#Mathematical_expression). The [electromagnetic 4-potential](https://en.wikipedia.org/wiki/Electromagnetic_potential) is

$$\rm A_{\mu } = \left\{\frac{3 \ r \ \mho }{\left(a^2 \ \Lambda +3\right) \left(a^2 \ \cos^2 \theta +r^2\right)}, \ 0, \ 0, \ -\frac{3 \ a \ r \ \mho \ \sin ^2 \theta }{\left(a^2 \ \Lambda +3\right) \left(a^2 \ \cos^2 \theta +r^2\right)}\right\}$$

The frame-dragging angular velocity is

$$\omega = \frac{\rm d\phi}{\rm d t}= -\frac{g_{\rm t \phi}}{g_{\rm \phi \phi}}= \rm \frac{a \ [ a^2 \ \Lambda \left(a^2+r^2\right) \cos^2 \theta +a^2 \ \Lambda \ r^2+6 \ r+\Lambda \ r^4-3 \ \mho^2 ] }{a^2 \ \sin^2 \theta \ [ a^2 \left(\Lambda \ r^2-3\right)+6 \ r+\Lambda \ r^4-3 \ r^2-3 \ \mho^2 ] +a^2 \ \Lambda \ \left(a^2+r^2\right)^2 \cos^2 \theta +3 \ \left(a^2+r^2\right)^2}$$

and the local frame-dragging velocity relative to constant $\rm \{r, \theta, \phi \}$ positions (the speed of light at the [ergosphere](wikipedia://en/1508445))

$$\nu = \sqrt{g_{\rm t \phi} \ g^{\rm t \phi}} = \rm \sqrt{-\frac{a^2 \ \sin^2 \theta \ [ a^2 \ \Lambda \left(a^2+r^2\right) \cos^2 \theta +a^2 \Lambda \ r^2+6 \ r+\Lambda \ r^4-3 \ \mho^2 ] ^2}{\left(a^2 \ \Lambda \ \cos^2 \theta +3\right) \left(a^2+r^2-a^2 \sin^2 \theta \right)^2 [ a^2 \left(\Lambda \ r^2-3\right)+6 \ r+\Lambda \ r^4-3 \ r^2-3 \ \mho^2 ] }}$$

The escape velocity (the speed of light at the horizons) relative to the local corotating zero-angular momentum observer is

$${\rm v} = \sqrt{ 1 - 1/g^{\rm tt} } = \rm \sqrt{\frac{3 \left(a^2 \Lambda \cos^2 \theta +3\right) \left(a^2+r^2-a^2 \sin^2 \theta \right)^2 \left[a^2 \left(\Lambda r^2-3\right)+\Lambda r^4-3 r^2+6 r-3 \mho ^2\right]}{\left(a^2 \Lambda +3\right)^2 \left( a^2 \cos^2 \theta +r^2\right) \{ a^2 \Lambda \left( a^2+r^2 \right)^2 \cos^2 \theta +3 \left( a^2+r^2 \right)^2+a^2 \sin^2 \theta \left[a^2 \left(\Lambda r^2-3\right)+\Lambda r^4-3 r^2+6 r-3 \mho ^2 \right] \} }+1}$$

The conserved quantities in the equations of motion

$${\rm \ddot{x}^{\mu} = -\sum_{\alpha, \beta} \ ( \Gamma^{\mu}_{\alpha \beta} \ \dot{x}^{\alpha} \ \dot{x}^{\beta} + q \ { \rm F}^{\mu \beta} \ {\rm \dot{x}}^{\alpha}} \ g_{\alpha \beta})$$

where $\rm \dot{x}$ is the [four velocity](https://en.wikipedia.org/wiki/Four_velocity), $\rm q$ is the test particle's [specific charge](https://en.wikipedia.org/wiki/Specific_charge) and $\rm F$ the [Maxwell–Faraday tensor](wikipedia://en/1912367)

$$\rm { \ F}_{\mu \nu}=\frac{\partial A_{\mu}}{\partial x^{\nu}}-\frac{\partial A_{\nu}}{\partial x^{\mu}}$$

are the total energy

$${\rm E = -p_t}=g_{\rm tt} {\rm \dot{t}}+g_{\rm t \phi} {\rm \dot{\phi}} + \rm q \ A_{t}$$

and the covariant axial [angular momentum](wikipedia://en/39139834)

$${\rm L_z = p_{\phi}}=-g_{\rm \phi \phi} {\rm \dot{\phi}}-g_{\rm t \phi} {\rm \dot{t}} - \rm q \ A_{\phi}$$

The [overdot](wikipedia://en/10265555) stands for differentiation by the testparticle's [proper time](wikipedia://en/494418) $\tau$ or the photon's [affine parameter](https://en.wikipedia.org/wiki/Affine_parameter), so $\rm \dot{x}=dx/d\tau , \ \ddot{x}=d^2x/d\tau^2$.

## Null coordinates {#Null_coordinates}

To get $g_{\rm rr}=0$ coordinates we apply the transformation

$$\rm dt=du-\frac{dr \left(a^2 \ \Lambda / 3 +1\right) \left(a^2+r^2\right)}{\left(a^2+r^2\right) \left(1-\Lambda \ r^2 / 3 \right)-2 \ r+\mho ^2}$$

$$\rm d \phi = d \varphi-\frac{a \ dr \left(a^2 \ \Lambda / 3 +1\right)}{\left(a^2+r^2\right) \left(1-\Lambda \ r^2 / 3 \right)-2 \ r+ \mho ^2}$$

and get the metric coefficients

$$g_{\rm ur}=\rm -\frac{3}{a^2 \ \Lambda +3}$$

$$g_{\rm r\varphi}=\rm \frac{3 \ a \sin^2 \theta }{a^2 \ \Lambda +3}$$

$$g_{\rm uu}=g_{\rm tt} \ , \ \ g_{\theta \theta}=g_{\theta \theta} \ , \ \ g_{\rm \varphi \varphi}=g_{\rm \phi \phi} \ , \ \ g_{\rm u \varphi}=g_{\rm t \phi}$$

and all the other $g_{\mu \nu}=0$, with the electromagnetic [vector potential](wikipedia://en/422936)

$$\rm A_{\mu}=\left\{\frac{3 \ r \ \mho }{\left(a^2 \ \Lambda +3\right) \left(a^2 \cos^2 \theta +r^2\right)},\frac{3 \ r \ \mho }{a^2 \left(\Lambda \ r^2-3\right)+6 \ r+\Lambda \ r^4-3 \left(r^2+\mho ^2\right)}, \ 0, \ -\frac{3 \ a \ r \ \mho \sin ^2 \theta }{\left(a^2 \ \Lambda +3\right) \left(a^2 \cos^2 \theta +r^2\right)}\right\}$$

Defining $\rm \bar{t}=u-r$ ingoing lightlike worldlines give a $45^{\circ}$ light cone on a $\{ \rm \bar{t}, \ r \}$ [spacetime diagram](wikipedia://en/11647860).

## Horizons and ergospheres {#Horizons_and_ergospheres}

*Image: Kerr\_Newman\_De\_Sitter\_(KNdS)\_Horizons\_&\_Ergospheres.gif.* Horizons and ergosheres in the KNdS metric for different M:Λ ratios. The black hole related surfaces are color coded as in here.

*Image: Kerr Newman De Sitter (KNdS) Horizons vs Ergospheres.png.* Left: horizons, right: ergosheres for M=1, a=9/10, ℧=2/5, Λ=1/9. At this point the black hole's outer ergosphere has joined the cosmic one to form two domes around the black hole.

*Image: Orbit in the Kerr Newman De Sitter Spacetime.png.* Unstable orbit at r=2 with the black hole and cosmic parameters as in the image above.

The horizons are at $g^{\rm rr}=0$ and the ergospheres at $g_{\rm tt}||g_{\rm uu}=0$. This can be solved numerically or analytically. Like in the [Kerr](wikipedia://en/456715) and [Kerr–Newman](wikipedia://en/1447904) metrics, the horizons have constant Boyer–Lindquist $\rm r$, while the ergospheres' radii also depend on the polar angle $\theta$.

This gives 3 positive solutions each (including the black hole's inner and outer horizons and ergospheres as well as the cosmic ones) and a negative solution for the space at $\rm r<0$ in the [antiverse](https://en.wikipedia.org/wiki/Multiverse#Twin-world_models)[^o12][^o13] behind the [ring singularity](https://en.wikipedia.org/wiki/Ring_singularity), which is part of the probably unphysical extended solution of the metric.

With a negative $\Lambda$ (the [anti–de–Sitter](wikipedia://en/301670) variant with an attractive cosmological constant), there are no cosmic horizon and ergosphere, only the black hole-related ones.

In the Nariai limit[^o14] the black hole's outer horizon and ergosphere coincide with the cosmic ones (in the [Schwarzschild–de–Sitter metric](https://en.wikipedia.org/wiki/De_Sitter–Schwarzschild_metric) to which the KNdS reduces with $\rm a= \mho =0$ that would be the case when $\Lambda=1/9$).
