# Carleson measure

::: {#o1 .subject cue=lead name="Carleson measure"}

In [mathematics](wikipedia://en/18831), a **Carleson measure** is a type of [measure](wikipedia://en/19873) on [subsets](wikipedia://en/27631) of *n*-[dimensional](wikipedia://en/8398) [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup>. Roughly speaking, a Carleson measure on a domain Ω is a measure that does not vanish at the [boundary](wikipedia://en/72824) of Ω when compared to the [surface measure](https://en.wikipedia.org/wiki/Surface_measure) on the [boundary](wikipedia://en/72824) of Ω.

:::

Carleson measures have many applications in [harmonic analysis](wikipedia://en/14147) and the theory of [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations), for instance in the solution of [Dirichlet problems](wikipedia://en/571109) with "rough" boundary. The Carleson condition is closely related to the [boundedness](https://en.wikipedia.org/wiki/Bounded_linear_operator) of the [Poisson operator](wikipedia://en/2214583). Carleson measures are named after the Swedish mathematician [Lennart Carleson](wikipedia://en/1669541).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *n* ∈ **N** and let Ω ⊂ **R**<sup>*n*</sup> be an [open](wikipedia://en/39358) (and hence [measurable](https://en.wikipedia.org/wiki/Measurable_set)) set with non-empty boundary ∂Ω. Let *μ* be a [Borel measure](wikipedia://en/4322) on Ω, and let *σ* denote the surface measure on ∂Ω. The measure *μ* is said to be a **Carleson measure** if there exists a constant *C* > 0 such that, for every point *p* ∈ ∂Ω and every radius *r* > 0,

$$\mu \left( \Omega \cap \mathbb{B}_{r} (p) \right) \leq C \sigma \left( \partial \Omega \cap \mathbb{B}_{r} (p) \right),$$

where

$$\mathbb{B}_{r} (p) := \left\{ x \in \mathbb{R}^{n} \left| \| x - p \|_{\mathbb{R}^{n}} < r \right. \right\}$$

denotes the [open ball](https://en.wikipedia.org/wiki/Open_ball) of radius *r* about *p*.

:::

## Carleson's theorem on the Poisson operator {#Carleson's_theorem_on_the_Poisson_operator}

Let *D* denote the [unit disc](https://en.wikipedia.org/wiki/Unit_disc) in the complex plane **C**, equipped with some Borel measure *μ*. For 1 ≤ *p* \< +∞, let *H*<sup>*p*</sup>(∂*D*) denote the [Hardy space](wikipedia://en/314780) on the boundary of *D* and let *L*<sup>*p*</sup>(*D*, *μ*) denote the [*L*<sup>*p*</sup> space](wikipedia://en/45194) on *D* with respect to the measure *μ*. Define the Poisson operator

$$P : H^{p} (\partial D) \to L^{p} (D, \mu)$$

by

$$P(f) (z) = \frac{1}{2 \pi} \int_{0}^{2 \pi} \mathrm{Re} \frac{e^{i t} + z}{e^{i t} - z} f(e^{i t}) \, \mathrm{d} \mu(t).$$

Then *P* is a bounded linear operator [if and only if](wikipedia://en/14922) the measure *μ* is Carleson.

:::

## Other related concepts {#Other_related_concepts}

The [infimum](https://en.wikipedia.org/wiki/Infimum) of the set of constants *C* > 0 for which the Carleson condition

$$\forall r > 0, \forall p \in \partial \Omega, \mu \left( \Omega \cap \mathbb{B}_{r} (p) \right) \leq C \sigma \left( \partial \Omega \cap \mathbb{B}_{r} (p) \right)$$

holds is known as the **Carleson norm** of the measure *μ*.

If *C*(*R*) is defined to be the infimum of the set of all constants *C* > 0 for which the restricted Carleson condition

$$\forall r \in (0, R), \forall p \in \partial \Omega, \mu \left( \Omega \cap \mathbb{B}_{r} (p) \right) \leq C \sigma \left( \partial \Omega \cap \mathbb{B}_{r} (p) \right)$$

holds, then the measure *μ* is said to satisfy the **vanishing Carleson condition** if *C*(*R*) → 0 as *R* → 0.
