# Deductive closure

::: {#o1 .subject cue=lead name="Deductive closure"}

In [mathematical logic](wikipedia://en/19636), a set $\mathcal{T}$ of [logical formulae](wikipedia://en/404582) is **deductively closed** if it contains every formula $\varphi$ that can be [logically deduced](wikipedia://en/61093) from $\mathcal{T}$; formally, if $\mathcal{T} \vdash \varphi$ always implies $\varphi \in \mathcal{T}$. If $T$ is a set of formulae, the **deductive closure** of $T$ is its smallest [superset](https://en.wikipedia.org/wiki/Superset) that is deductively closed.

:::

The deductive closure of a [theory](wikipedia://en/3512103) $\mathcal{T}$ is often denoted $\operatorname{Ded}(\mathcal{T})$ or $\operatorname{Th}(\mathcal{T})$. Some authors do not define a theory as deductively closed (thus, a theory is defined as any set of [sentences](https://en.wikipedia.org/wiki/Sentence_%28logic%29)), but such theories can always be 'extended' to a deductively closed set. A theory may be referred to as a *deductively closed theory* to emphasize it is defined as a deductively closed set.

Deductive closure is a special case of the more general mathematical concept of [closure](wikipedia://en/293802#Closure_operator) — in particular, the deductive closure of $\mathcal{T}$ is exactly the closure of $\mathcal{T}$ with respect to the operation of [logical consequence](wikipedia://en/37531624) ($\vdash$).

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

In [propositional logic](https://en.wikipedia.org/wiki/Propositional_calculus), the set of all true propositions is deductively closed. This is to say that only true statements are derivable from other true statements.

:::

## Epistemic closure {#Epistemic_closure}

In [epistemology](https://en.wikipedia.org/wiki/Epistemology), many philosophers have and continue to debate whether particular subsets of [propositions](wikipedia://en/81094)—especially ones ascribing [knowledge](https://en.wikipedia.org/wiki/Knowledge) or [justification](https://en.wikipedia.org/wiki/Theory_of_justification) of a [belief](https://en.wikipedia.org/wiki/Belief) to a subject—are closed under deduction.
