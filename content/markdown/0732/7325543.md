# Stochastic optimization

::: {#o1 .subject cue=lead name="Stochastic optimization"}

**Stochastic optimization** (**SO**) are [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) [methods](wikipedia://en/15237) that generate and use [random variables](wikipedia://en/25685). For [stochastic](wikipedia://en/292222) optimization problems, the [objective functions](https://en.wikipedia.org/wiki/Objective_function) or [constraints](wikipedia://en/7418540) are random. Stochastic optimization also include methods with random [iterates](wikipedia://en/15237). Some hybrid methods use random iterates to solve stochastic problems, combining both meanings of stochastic optimization.[^o2] Stochastic optimization methods generalize [deterministic](https://en.wikipedia.org/wiki/Deterministic_system_%28mathematics%29) methods for deterministic problems.

:::

## Methods for stochastic functions {#Methods_for_stochastic_functions}

Partly random input data arise in such areas as real-time estimation and control, simulation-based optimization where [Monte Carlo simulations](wikipedia://en/56098) are run as estimates of an actual system,[^o4][^o5] and problems where there is experimental (random) error in the measurements of the criterion. In such cases, knowledge that the function values are contaminated by random "noise" leads naturally to algorithms that use [statistical inference](wikipedia://en/26685) tools to estimate the "true" values of the function and/or make statistically optimal decisions about the next steps. Methods of this class include:

- [stochastic approximation](wikipedia://en/8979437) (SA), by [Robbins](wikipedia://en/745193) and Monro (1951)[^o6]
- [stochastic gradient descent](wikipedia://en/1180641)
- [finite-difference SA](https://en.wikipedia.org/wiki/Finite-difference_stochastic_approximation) by [Kiefer](https://en.wikipedia.org/wiki/Jack_Kiefer_%28mathematician%29) and [Wolfowitz](https://en.wikipedia.org/wiki/Jacob_Wolfowitz) (1952)[^o7]
- [simultaneous perturbation SA](wikipedia://en/24464148) by Spall (1992)[^o8]
- [scenario optimization](wikipedia://en/24686102)

## Randomized search methods {#Randomized_search_methods}

On the other hand, even when the [data set](wikipedia://en/8495) consists of precise measurements, some methods introduce randomness into the search-process to accelerate progress.[^o10] Such randomness can also make the method less sensitive to modeling errors. Another advantage is that randomness into the search-process can be used for obtaining interval estimates of the minimum of a function via extreme value statistics.[^o11][^o12] Further, the injected randomness may enable the method to escape a local optimum and eventually to approach a global optimum. Indeed, this [randomization](wikipedia://en/495383) principle is known to be a simple and effective way to obtain algorithms with *almost certain* good performance uniformly across many data sets, for many sorts of problems. Stochastic optimization methods of this kind include:

- [simulated annealing](wikipedia://en/172244) by S. Kirkpatrick, C. D. Gelatt and M. P. Vecchi (1983)[^o13]
- [quantum annealing](wikipedia://en/5219389)
- [Probability Collectives](https://en.wikipedia.org/wiki/Probability_Collectives) by D.H. Wolpert, S.R. Bieniawski and D.G. Rajnarayan (2011)[^o14]
- [reactive search optimization (RSO)](https://en.wikipedia.org/wiki/Reactive_Search_Optimization) by [Roberto Battiti](https://en.wikipedia.org/wiki/Roberto_Battiti), G. Tecchiolli (1994),[^o15] recently reviewed in the reference book [^o16]
- [cross-entropy method](wikipedia://en/5767980) by [Rubinstein](https://en.wikipedia.org/wiki/Reuven_Rubinstein) and [Kroese](wikipedia://en/62003512) (2004)[^o17]
- [random search](wikipedia://en/27340816) by [Anatoly Zhigljavsky](https://en.wikipedia.org/wiki/Anatoly_Zhigljavsky) (1991)[^o18]
- Informational search [^o19]
- [stochastic tunneling](wikipedia://en/563897)[^o20]
- [parallel tempering](wikipedia://en/1459075) a.k.a. replica exchange[^o21]
- [stochastic hill climbing](https://en.wikipedia.org/wiki/Stochastic_hill_climbing)
- [swarm algorithms](https://en.wikipedia.org/wiki/Swarm_intelligence)
- [evolutionary algorithms](https://en.wikipedia.org/wiki/Evolutionary_algorithms)
  - [genetic algorithms](https://en.wikipedia.org/wiki/Genetic_algorithms) by Holland (1975)[^o22]
  - [evolution strategies](https://en.wikipedia.org/wiki/Evolution_strategies)
- cascade object optimization & modification algorithm (2016)[^o23]

In contrast, some authors have argued that randomization can only improve a deterministic algorithm if the deterministic algorithm was poorly designed in the first place.[^o24] [Fred W. Glover](https://en.wikipedia.org/wiki/Fred_W._Glover)[^o25] argues that reliance on random elements may prevent the development of more intelligent and better deterministic components. The way in which results of stochastic optimization algorithms are usually presented (e.g., presenting only the average, or even the best, out of N runs without any mention of the spread), may also result in a positive bias towards randomness.
