# Partial equivalence relation

::: {#o1 .subject cue=lead name="Partial equivalence relation"}

In [mathematics](wikipedia://en/18831), a **partial equivalence relation** (often abbreviated as **PER**, in older literature also called **restricted equivalence relation**[^o2]) is a [homogeneous binary relation](https://en.wikipedia.org/wiki/Homogeneous_binary_relation) that is [symmetric](wikipedia://en/200459) and [transitive](wikipedia://en/200463). If the relation is also [reflexive](wikipedia://en/200458), then the relation is an [equivalence relation](wikipedia://en/9259).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, a relation $R$ on a set $X$ is a PER if it holds for all $a, b, c \in X$ that:

1. if $a R b$, then $b R a$ (symmetry)
1. if $a R b$ and $b R c$, then $a R c$ (transitivity)

Another definition for a partial equivalence relation is that $R$ on a set $X$ is a PER if there is some subset $Y$ of $X$ such that $R \subseteq Y \times Y$ and $R$ is an [equivalence relation](wikipedia://en/9259) on $Y$. The two definitions are seen to be equivalent by taking $Y = \{ x \in X \mid x\,R\,x\}$.[^o5]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties and applications"}

## Properties and applications {#Properties_and_applications}

The following properties hold for a partial equivalence relation $R$ on a set $X$:

- $R$ is an equivalence relation on the subset $Y = \{ x \in X \mid x\,R\,x\} \subseteq X$.[^o8]
- $R$ is [difunctional](https://en.wikipedia.org/wiki/Difunctional_relation): the relation is the set $\{(a,b) \mid f a = g b \}$ for two [partial functions](wikipedia://en/23577) $f,g : X \rightharpoonup Y$ and some indicator set $Y$
- $R$ is right [Euclidean](wikipedia://en/11613832): For $a,b,c \in X$, $a R b$ and $a R c$ implies $b R c$
- $R$ is left Euclidean: For $a,b,c \in X$, $b R a$ and $c R a$ imply $b R c$
- $R$ is [quasi-reflexive](https://en.wikipedia.org/wiki/Quasi-reflexive_relation): If $x, y \in X$ and $x R y$, then $x R x$ and $y R y$.[^o9][^o10]

None of these properties alone is sufficient to imply that the relation is a PER.[^o11] If $R$ is both left *and* right Euclidean, then $R$ is an equivalence relation, and hence a PER.

### In non-set-theory settings {#In_non-set-theory_settings}

In [type theory](wikipedia://en/40282), [constructive mathematics](https://en.wikipedia.org/wiki/Constructive_mathematics) and their applications to [computer science](https://en.wikipedia.org/wiki/Computer_science), constructing analogues of subsets is often problematic[^o13]—in these contexts PERs are therefore more commonly used, particularly to define [setoids](wikipedia://en/769434), sometimes called partial setoids. Forming a partial setoid from a type and a PER is analogous to forming subsets and quotients in classical set-theoretic mathematics.

The algebraic notion of [congruence](wikipedia://en/48167) can also be generalized to partial equivalences, yielding the notion of [subcongruence](https://en.wikipedia.org/wiki/Subcongruence), i.e. a [homomorphic relation](https://en.wikipedia.org/wiki/Homomorphic_relation) that is symmetric and transitive, but not necessarily reflexive.[^o14]

:::

::: {#o16 .example cue=heading name="Examples"}

## Examples {#Examples}

A simple example of a PER that is *not* an equivalence relation is the [empty relation](https://en.wikipedia.org/wiki/Empty_relation) $R=\emptyset$, if $X$ is not empty.

### Kernels of partial functions {#Kernels_of_partial_functions}

If $f$ is a [partial function](wikipedia://en/23577) on a set $A$, then the relation $\approx$ defined by

$x \approx y$ if $f$ is defined at $x$, $f$ is defined at $y$, and $f(x) = f(y)$

is a partial equivalence relation, since it is clearly symmetric and transitive.

If $f$ is undefined on some elements, then $\approx$ is not an equivalence relation. It is not reflexive since if $f(x)$ is not defined then $x \not\approx x$ — in fact, for such an $x$ there is no $y \in A$ such that $x \approx y$. It follows immediately that the largest subset of $A$ on which $\approx$ is an equivalence relation is precisely the subset on which $f$ is defined.

### Functions respecting equivalence relations {#Functions_respecting_equivalence_relations}

Let *X* and *Y* be sets equipped with equivalence relations (or PERs) $\approx_X, \approx_Y$. For $f,g : X \to Y$, define $f \approx g$ to mean:

$$\forall x_0 \; x_1, \quad x_0 \approx_X x_1 \Rightarrow f(x_0) \approx_Y g(x_1)$$

then $f \approx f$ means that *f* induces a well-defined function of the quotients $X / {\approx_X} \; \to \; Y / {\approx_Y}$. Thus, the PER $\approx$ captures both the idea of *definedness* on the quotients and of two functions inducing the same function on the quotient.

### Equality of IEEE floating point values {#Equality_of_IEEE_floating_point_values}

The [IEEE 754:2008](wikipedia://en/405039) standard for [floating-point numbers](https://en.wikipedia.org/wiki/Floating-point_numbers) defines an "EQ" relation for floating point values. This predicate is symmetric and transitive, but is not reflexive because of the presence of [NaN](https://en.wikipedia.org/wiki/NaN) values that are not EQ to themselves.[^o20]
