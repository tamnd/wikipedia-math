# SHARK

::: {#o2 .subject cue=lead name="SHARK"}

In [cryptography](wikipedia://en/18934432), **SHARK** is a [block cipher](wikipedia://en/4594) identified as one of the predecessors of [Rijndael](https://en.wikipedia.org/wiki/Rijndael) (the [Advanced Encryption Standard](wikipedia://en/1260)).

:::

SHARK has a 64-bit [block size](wikipedia://en/294065) and a 128-bit [key size](wikipedia://en/5749). It is a six-round [SP-network](https://en.wikipedia.org/wiki/Substitution–permutation_network) which alternates a [key](wikipedia://en/53039) mixing stage with linear and non-linear transformation layers. The linear transformation uses an [MDS matrix](wikipedia://en/8288796) representing a [Reed–Solomon](wikipedia://en/45600) [error correcting code](https://en.wikipedia.org/wiki/Error_correcting_code) in order to guarantee good [diffusion](wikipedia://en/537555). The nonlinear layer is composed of eight 8×8-bit [S-boxes](wikipedia://en/240991) based on the function *F(x) = x<sup>−1</sup>* over *GF(2<sup>8</sup>)*.

Five rounds of a modified version of SHARK can be broken using an [interpolation attack](wikipedia://en/3329538) (Jakobsen and Knudsen, 1997).
