# Hadamard's inequality

::: {#o1 .subject cue=lead name="Hadamard's inequality"}

In [mathematics](wikipedia://en/18831), **Hadamard's inequality** (also known as **Hadamard's theorem on determinants**[^o2]) is a result first published by [Jacques Hadamard](wikipedia://en/312675) in 1893.[^o3] It is a [bound](wikipedia://en/42693) on the [determinant](wikipedia://en/8468) of a [matrix](wikipedia://en/20556859) whose entries are [complex numbers](wikipedia://en/5826) in terms of the lengths of its column vectors. In [geometrical](wikipedia://en/18973446) terms, when restricted to [real numbers](wikipedia://en/20646438), it bounds the [volume](wikipedia://en/32498) in [Euclidean space](wikipedia://en/9697) of *n* dimensions marked out by *n* vectors *v<sub>i</sub>* for 1 ≤ *i* ≤ *n* in terms of the lengths of these vectors ||*v<sub>i</sub>*||.

:::

Specifically, Hadamard's inequality states that if *N* is the matrix having columns[^o4] *v<sub>i</sub>*, then

$$\left| \det(N) \right| \le \prod_{i=1}^n \|v_i\|.$$

If the *n* vectors are non-zero, equality in Hadamard's inequality is achieved [if and only if](wikipedia://en/14922) the vectors are [orthogonal](https://en.wikipedia.org/wiki/Orthogonal).

## Alternate forms and corollaries {#Alternate_forms_and_corollaries}

A [corollary](wikipedia://en/168865) is that if the entries of an *n* by *n* matrix *N* are bounded by *B*, so |*N<sub>ij</sub>*| ≤ *B* for all *i* and *j*, then

$$\left| \det(N) \right| \le B^n n^{n/2}.$$

In particular, if the entries of *N* are +1 and −1 only then[^o6]

$$\left| \det(N) \right| \le n^{n/2}.$$

In [combinatorics](wikipedia://en/5170), matrices *N* for which equality holds, i.e. those with orthogonal columns, are called [Hadamard matrices](https://en.wikipedia.org/wiki/Hadamard_matrices).

More generally, suppose that *N* is a [complex](wikipedia://en/5826) matrix of order *n*, whose entries are bounded by |*N<sub>ij</sub>*| ≤ 1, for each *i*, *j* between 1 and *n*. Then Hadamard's inequality states that

$$|\operatorname{det}(N)| \leq n^{n/2}.$$

Equality in this bound is attained for a real matrix *N* [if and only if](wikipedia://en/14922) *N* is a Hadamard matrix.

A [positive-semidefinite matrix](https://en.wikipedia.org/wiki/Positive-semidefinite_matrix) *P* can be written as *N*<sup>\*</sup>*N*, where *N*<sup>\*</sup> denotes the [conjugate transpose](wikipedia://en/217548) of *N* (see [Decomposition of a semidefinite matrix](wikipedia://en/40326#Decomposition)). Then

$$\det(P)=\det(N)^2 \le \prod_{i=1}^n \|v_i\|^2 = \prod_{i=1}^n p_{ii}.$$

So, the determinant of a [positive definite matrix](https://en.wikipedia.org/wiki/Positive_definite_matrix) is less than or equal to the product of its diagonal entries. Sometimes this is also known as Hadamard's inequality.[^o3][^o7]

::: {#o9 .proof cue=heading name="Proof"}

## Proof {#Proof}

The result is trivial if the matrix *N* is [singular](wikipedia://en/245528), so assume the columns of *N* are [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent). By dividing each column by its Euclidean norm, it can be seen that the result is equivalent to the special case where each column has norm 1, in other words if *e<sub>i</sub>* are [unit vectors](wikipedia://en/167053) and *M* is the matrix having the *e<sub>i</sub>* as columns then

::: {#o10 .equation cue=numblk name="1"}

$$\left| \det M \right| \le 1, \tag{1}$$

:::

and equality is achieved if and only if the vectors are an [orthogonal set](https://en.wikipedia.org/wiki/Orthogonal_set). The general result now follows:

$$\left| \det N \right| = \bigg (\prod_{i=1}^n \|v_i\| \bigg) \left|\det M\right| \leq \prod_{i=1}^n \|v_i\|.$$

To [prove](wikipedia://en/82285) **(1)**, consider *P* =*M<sup>\*</sup>M* where *M<sup>\*</sup>* is the conjugate transpose of *M*, and let the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of *P* be λ<sub>1</sub>, λ<sub>2</sub>, … λ<sub>*n*</sub>. Since the length of each column of *M* is 1, each entry in the diagonal of *P* is 1, so the [trace](wikipedia://en/43270) of *P* is *n*. Applying the [inequality of arithmetic and geometric means](https://en.wikipedia.org/wiki/Inequality_of_arithmetic_and_geometric_means),

$$\det P = \prod_{i=1}^n \lambda_i \le \left({1 \over n}\sum_{i=1}^n \lambda_i\right)^n = \left({1 \over n} \operatorname{tr} P \right)^n = 1^n = 1,$$

so

$$\left| \det M \right| = \sqrt{\det P} \le 1.$$

If there is equality then each of the *λ*<sub>*i*</sub>'s must all be equal and their sum is *n*, so they must all be 1. The matrix *P* is [Hermitian](wikipedia://en/189682), therefore [diagonalizable](https://en.wikipedia.org/wiki/Diagonalizable), so it is the [identity matrix](wikipedia://en/59718)—in other words the columns of *M* are an orthonormal set and the columns of *N* are an orthogonal set.[^o11] Many other proofs can be found in the literature.

:::
