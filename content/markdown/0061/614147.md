# Knuth–Bendix completion algorithm

::: {#o1 .subject cue=lead name="Knuth–Bendix completion algorithm"}

The **Knuth–Bendix completion algorithm** (named after [Donald Knuth](https://en.wikipedia.org/wiki/Donald_E._Knuth) and Peter Bendix[^o2]) is a [semi-decision](https://en.wikipedia.org/wiki/Semidecidable)[^o3][^o4] [algorithm](wikipedia://en/775) for transforming a set of [equations](wikipedia://en/9284) (over [terms](wikipedia://en/24885593)) into a [confluent](https://en.wikipedia.org/wiki/Confluence_%28term_rewriting%29) [term rewriting system](https://en.wikipedia.org/wiki/Term_rewriting_system). When the algorithm succeeds, it effectively solves the [word problem](wikipedia://en/3852079) for the specified [algebra](wikipedia://en/18716923).

:::

[Buchberger's algorithm](wikipedia://en/696317) for computing [Gröbner bases](wikipedia://en/357328) is a very similar algorithm. Although developed independently, it may also be seen as the instantiation of Knuth–Bendix algorithm in the theory of [polynomial rings](wikipedia://en/373065).

## Introduction {#Introduction}

For a set *E* of equations, its **deductive closure** (⟷) is the set of all equations that can be derived by applying equations from *E* in any order. Formally, *E* is considered a [binary relation](wikipedia://en/3931), (*E*) is its [rewrite closure](https://en.wikipedia.org/wiki/Rewrite_closure), and (⟷) is the [equivalence closure](https://en.wikipedia.org/wiki/Equivalence_closure) of (*E*). For a set *R* of rewrite rules, its **deductive closure** (⟶ ∘ ⟵) is the set of all equations that can be confirmed by applying rules from *R* left-to-right to both sides until they are literally equal. Formally, *R* is again viewed as a binary relation, (*R*) is its rewrite closure, (*R*) is its [converse](wikipedia://en/3941020), and (⟶ ∘ ⟵) is the [relation composition](https://en.wikipedia.org/wiki/Relation_composition) of their [reflexive transitive closures](https://en.wikipedia.org/wiki/Reflexive_transitive_closure) (⟶ and ⟵).

For example, if $E = \{1\cdot x = x, x^{-1}\cdot x = 1, (x\cdot y)\cdot z = x\cdot(y\cdot z)\}$ are the [group](wikipedia://en/19447) axioms, the derivation chain

$$a^{-1}\cdot(a\cdot b) \longleftrightarrow (a^{-1}\cdot a)\cdot b \longleftrightarrow 1\cdot b \longleftrightarrow b$$

demonstrates that *a*<sup>−1</sup>⋅(*a*⋅*b*) ⟷ *b* is a member of *E**s deductive closure.*** If $R = \{1\cdot x \to x, x^{-1}\cdot x \to 1, (x\cdot y)\cdot z \to x\cdot(y\cdot z)\}$ is a "rewrite rule" version of *E*, the derivation chains

$$(a^{-1}\cdot a)\cdot b \longrightarrow 1\cdot b \longrightarrow b\text{ and } b \longleftarrow b$$

demonstrate that (*a*<sup>−1</sup>⋅*a*)⋅*b* ⟶∘⟵ *b* is a member of *R**s deductive closure.*** However, there is no way to derive *a*<sup>−1</sup>⋅(*a*⋅*b*) ⟶∘⟵ *b* similar to above, since a right-to-left application of the rule $(x\cdot y)\cdot z \to x\cdot(y\cdot z)$ is not allowed.

The Knuth–Bendix algorithm takes a set *E* of equations between [terms](wikipedia://en/24885593), and a [reduction ordering](https://en.wikipedia.org/wiki/Reduction_ordering) (>) on the set of all terms, and attempts to construct a confluent and terminating term rewriting system *R* that has the same deductive closure as *E*. While proving consequences from *E* often requires human intuition, proving consequences from *R* does not. For more details, see [Confluence (abstract rewriting)#Motivating examples](wikipedia://en/3755377#Motivating_examples), which gives an example proof from group theory, performed both using *E* and using *R*.

## Rules {#Rules}

Given a set *E* of equations between [terms](wikipedia://en/24885593), the following inference rules can be used to transform it into an equivalent [convergent term rewrite system](https://en.wikipedia.org/wiki/Convergent_term_rewrite_system) (if possible):[^o7][^o8] They are based on a user-given [reduction ordering](https://en.wikipedia.org/wiki/Reduction_ordering) (>) on the set of all terms; it is lifted to a well-founded ordering (▻) on the set of rewrite rules by defining $(s \to t) \text{▻} (l \to r)$ if

- $s e l$ in the [encompassment ordering](wikipedia://en/42964077), or
- $s$ and $l$ are [literally similar](https://en.wikipedia.org/wiki/Variant_%28logic%29) and $t > r$.
| **Delete** | ‹ *E*∪{*s* = *s*} | , *R* › | ⊢ | ‹ *E* | , *R* › |  |
|---|---|---|---|---|---|---|
| **Compose** | ‹ *E* | , *R*∪{*s* → *t*} › | ⊢ | ‹ *E* | , *R*∪{*s* → *u*} › | if $t R u$ |
| **Simplify** | ‹ *E*∪{*s* = *t*} | , *R* › | ⊢ | ‹ *E*∪{*s* = *u*} | , *R* › | if $t R u$ |
| **Orient** | ‹ *E*∪{*s* = *t*} | , *R* › | ⊢ | ‹ *E* | , *R*∪{*s* → *t*} › | if $s > t$ |
| **Collapse** | ‹ *E* | , *R*∪{*s* → *t*} › | ⊢ | ‹ *E*∪{*u* = *t*} | , *R* › | if $s R u$ by $l \to r$ with $(s \to t) \text{▻} (l \to r)$ |
| **Deduce** | ‹ *E* | , *R* › | ⊢ | ‹ *E*∪{*s* = *t*} | , *R* › | if $(s,t)$ is a [critical pair](https://en.wikipedia.org/wiki/Critical_pair_%28logic%29) of *R* |

## String rewriting systems in group theory {#String_rewriting_systems_in_group_theory}

An important case in [computational group theory](wikipedia://en/618584) is string rewriting systems which can be used to give canonical labels to elements or [cosets](wikipedia://en/98759) of a [finitely presented group](https://en.wikipedia.org/wiki/Finitely_presented_group) as products of the [generators](wikipedia://en/99945). This special case is the focus of this section.

### Motivation in group theory {#Motivation_in_group_theory}

The [critical pair lemma](https://en.wikipedia.org/wiki/Critical_pair_lemma) states that a term rewriting system is [locally confluent](https://en.wikipedia.org/wiki/Confluence_%28term_rewriting%29) (or weakly confluent) if and only if all its [critical pairs](https://en.wikipedia.org/wiki/Critical_pair_%28logic%29) are convergent. Furthermore, we have [Newman's lemma](wikipedia://en/6038529) which states that if an (abstract) rewriting system is [strongly normalizing](wikipedia://en/5085531) and weakly confluent, then the rewriting system is confluent. So, if we can add rules to the term rewriting system in order to force all critical pairs to be convergent while maintaining the strong normalizing property, then this will force the resultant rewriting system to be confluent.

Consider a [finitely presented monoid](https://en.wikipedia.org/wiki/Finitely_presented_monoid) $M = \langle X \mid R \rangle$ where X is a finite set of generators and R is a set of defining relations on X. Let X<sup>\*</sup> be the set of all words in X (i.e. the free monoid generated by X). Since the relations R generate an equivalence relation on X\*, one can consider elements of M to be the equivalence classes of X<sup>\*</sup> under R. For each class *{w<sub>1</sub>, w<sub>2</sub>, ... }* it is desirable to choose a standard representative *w<sub>k</sub>*. This representative is called the **canonical** or **normal form** for each word *w<sub>k</sub>* in the class. If there is a computable method to determine for each *w<sub>k</sub>* its normal form *w<sub>i</sub>* then the word problem is easily solved. A confluent rewriting system allows one to do precisely this.

Although the choice of a canonical form can theoretically be made in an arbitrary fashion this approach is generally not computable. (Consider that an equivalence relation on a language can produce an infinite number of infinite classes.) If the language is [well-ordered](https://en.wikipedia.org/wiki/Well-ordered) then the order \< gives a consistent method for defining minimal representatives, however computing these representatives may still not be possible. In particular, if a rewriting system is used to calculate minimal representatives then the order \< should also have the property:

A \< B → XAY \< XBY for all words A,B,X,Y

This property is called **translation invariance**. An order that is both translation-invariant and a well-order is called a **reduction order**.

From the presentation of the monoid it is possible to define a rewriting system given by the relations R. If A x B is in R then either A \< B in which case B → A is a rule in the rewriting system, otherwise A > B and A → B. Since \< is a reduction order a given word W can be reduced W > W\_1 > ... > W\_n where W\_n is irreducible under the rewriting system. However, depending on the rules that are applied at each W<sub>i</sub> → W<sub>i+1</sub> it is possible to end up with two different irreducible reductions W<sub>n</sub> ≠ W'<sub>m</sub> of W. However, if the rewriting system given by the relations is converted to a confluent rewriting system via the Knuth–Bendix algorithm, then all reductions are guaranteed to produce the same irreducible word, namely the normal form for that word.

### Description of the algorithm for finitely presented monoids {#Description_of_the_algorithm_for_finitely_presented_monoids}

Suppose we are given a [presentation](wikipedia://en/99494) $\langle X \mid R \rangle$, where $X$ is a set of [generators](wikipedia://en/99945) and $R$ is a set of [relations](wikipedia://en/22517558) giving the rewriting system. Suppose further that we have a reduction ordering $<$ among the words generated by $X$ (e.g., [shortlex order](wikipedia://en/2660383)). For each relation $P_i = Q_i$ in $R$, suppose $Q_i < P_i$. Thus we begin with the set of reductions $P_i \rightarrow Q_i$.

First, if any relation $P_i = Q_i$ can be reduced, replace $P_i$ and $Q_i$ with the reductions.

Next, we add more reductions (that is, rewriting rules) to eliminate possible exceptions of confluence. Suppose that $P_i$ and $P_j$ overlap.

1. Case 1: either the prefix of $P_i$ equals the suffix of $P_j$, or vice versa. In the former case, we can write $P_i = BC$ and $P_j = AB$; in the latter case, $P_i = AB$ and $P_j = BC$.
1. Case 2: either $P_i$ is completely contained in (surrounded by) $P_j$, or vice versa. In the former case, we can write $P_i = B$ and $P_j = ABC$; in the latter case, $P_i = ABC$ and $P_j = B$.

Reduce the word $ABC$ using $P_i$ first, then using $P_j$ first. Call the results $r_1, r_2$, respectively. If $r_1 \neq r_2$, then we have an instance where confluence could fail. Hence, add the reduction $\max r_1, r_2 \rightarrow \min r_1, r_2$ to $R$.

After adding a rule to $R$, remove any rules in $R$ that might have reducible left sides (after checking if such rules have critical pairs with other rules).

Repeat the procedure until all overlapping left sides have been checked.

::: {#o16 .example cue=heading name="Examples"}

### Examples {#Examples}

#### A terminating example {#A_terminating_example}

Consider the monoid:

$$\langle x, y \mid x^3 = y^3 = (xy)^3 = 1 \rangle.$$

We use the [shortlex order](wikipedia://en/2660383). This is an infinite monoid but nevertheless, the Knuth–Bendix algorithm is able to solve the word problem.

Our beginning three reductions are therefore

::: {#o18 .equation cue=numblk name="1"}

$$x^3 \rightarrow 1 \tag{1}$$

:::

::: {#o19 .equation cue=numblk name="2"}

$$y^3 \rightarrow 1 \tag{2}$$

:::

::: {#o20 .equation cue=numblk name="3"}

$$(xy)^3 \rightarrow 1. \tag{3}$$

:::

A suffix of $x^3$ (namely $x$) is a prefix of $(xy)^3=xyxyxy$, so consider the word $x^3yxyxy$. Reducing using ((1)), we get $yxyxy$. Reducing using ((3)), we get $x^2$. Hence, we get $yxyxy = x^2$, giving the reduction rule

::: {#o21 .equation cue=numblk name="4"}

$$yxyxy \rightarrow x^2. \tag{4}$$

:::

Similarly, using $xyxyxy^3$ and reducing using ((2)) and ((3)), we get $xyxyx = y^2$. Hence the reduction

::: {#o22 .equation cue=numblk name="5"}

$$xyxyx \rightarrow y^2. \tag{5}$$

:::

Both of these rules obsolete ((3)), so we remove it.

Next, consider $x^3yxyx$ by overlapping ((1)) and ((5)). Reducing we get $yxyx = x^2y^2$, so we add the rule

::: {#o23 .equation cue=numblk name="6"}

$$yxyx \rightarrow x^2y^2. \tag{6}$$

:::

Considering $xyxyx^3$ by overlapping ((1)) and ((5)), we get $xyxy = y^2x^2$, so we add the rule

::: {#o24 .equation cue=numblk name="7"}

$$y^2x^2 \rightarrow xyxy. \tag{7}$$

:::

These obsolete rules ((4)) and ((5)), so we remove them.

Now, we are left with the rewriting system

::: {#o25 .equation cue=numblk name="1"}

$$x^3 \rightarrow 1 \tag{1}$$

:::

::: {#o26 .equation cue=numblk name="2"}

$$y^3 \rightarrow 1 \tag{2}$$

:::

::: {#o27 .equation cue=numblk name="6"}

$$yxyx \rightarrow x^2y^2 \tag{6}$$

:::

::: {#o28 .equation cue=numblk name="7"}

$$y^2 x^2 \rightarrow xyxy. \tag{7}$$

:::

Checking the overlaps of these rules, we find no potential failures of confluence. Therefore, we have a confluent rewriting system, and the algorithm terminates successfully.

#### A non-terminating example {#A_non-terminating_example}

The order of the generators may crucially affect whether the Knuth–Bendix completion terminates. As an example, consider the [free Abelian group](https://en.wikipedia.org/wiki/Free_Abelian_group) by the monoid presentation:

$$\langle x, y, x^{-1}, y^{-1}\, |\, xy=yx, xx^{-1} = x^{-1}x = yy^{-1} = y^{-1}y = 1 \rangle .$$

The Knuth–Bendix completion with respect to lexicographic order $x < x^{-1} < y < y^ {-1}$ finishes with a convergent system, however considering the length-lexicographic order $x < y < x^{-1} < y^{-1}$ it does not finish for there are no finite convergent systems compatible with this latter order.[^o30]

:::

## Generalizations {#Generalizations}

If Knuth–Bendix does not succeed, it will either run forever and produce successive approximations to an infinite complete system, or fail when it encounters an unorientable equation (i.e. an equation that it cannot turn into a rewrite rule). An enhanced version will not fail on unorientable equations and produces a [ground confluent](https://en.wikipedia.org/wiki/Ground_confluent) system, providing a [semi-algorithm](https://en.wikipedia.org/wiki/Semi-algorithm) for the word problem.[^o33]

The notion of [logged rewriting](https://en.wikipedia.org/wiki/Logged_rewriting) discussed in the paper by Heyworth and Wensley listed below allows some recording or logging of the rewriting process as it proceeds. This is useful for computing identities among relations for presentations of groups.

:::
