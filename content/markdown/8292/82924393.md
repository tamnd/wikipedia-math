# Markowsky's theorem

::: {#o1 .subject cue=lead name="Markowsky's theorem"}

In mathematics, **Markowsky's theorem** states: every [chain-complete](https://en.wikipedia.org/wiki/Chain-complete) [poset](https://en.wikipedia.org/wiki/Poset) is a [dcpo](https://en.wikipedia.org/wiki/Directed_complete_partial_order) where

:::

- a poset is *chain-complete* if each chain in it has a least upper bound.
- a poset is a *dcpo* if each directed set in it has a least upper bound.

Since a dcpo is chain-complete (as a chain is directed), the converse of the theorem is trivial.

A known proof uses [Iwamura's lemma](https://en.wikipedia.org/wiki/Iwamura's_lemma) and [ordinals](wikipedia://en/26547932).[^o2]
