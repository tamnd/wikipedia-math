# Graph Modelling Language

::: {#o1 .subject cue=lead name="Graph Modelling Language"}

**Graph Modeling Language** (GML) is a hierarchical [ASCII](https://en.wikipedia.org/wiki/ASCII)-based file format for describing [graphs](wikipedia://en/325806). It has been also named *Graph Meta Language*.

:::

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

A simple graph in GML format:

```
graph [
	comment "This is a sample graph"
	directed 1
	id 42
	label "Hello, I am a graph"
	node [
		id 1
		label "node 1"
		thisIsASampleAttribute 42
	]
	node [
		id 2
		label "node 2"
		thisIsASampleAttribute 43
	]
	node [
		id 3
		label "node 3"
		thisIsASampleAttribute 44
	]
	edge [
		source 1
		target 2
		label "Edge from node 1 to node 2"
	]
	edge [
		source 2
		target 3
		label "Edge from node 2 to node 3"
	]
	edge [
		source 3
		target 1
		label "Edge from node 3 to node 1"
	]
]
```

:::

## Applications supporting GML {#Applications_supporting_GML}

- [Cytoscape](https://en.wikipedia.org/wiki/Cytoscape), an [open source](https://en.wikipedia.org/wiki/Open-source_license) [bioinformatics software](https://en.wikipedia.org/wiki/List_of_bioinformatics_software) platform for visualizing molecular interaction networks, loads and save previously-constructed interaction networks in GML.
- [igraph](https://en.wikipedia.org/wiki/Igraph), an [open source](https://en.wikipedia.org/wiki/Open-source_license) network analysis library with interfaces to multiple programming languages.
- [Gephi](https://en.wikipedia.org/wiki/Gephi), an [open source](https://en.wikipedia.org/wiki/Open-source_license) graph visualization and manipulation software.
- [Graph-tool](wikipedia://en/29735189), a [free](https://en.wikipedia.org/wiki/Free_software) Python module for manipulation and statistical analysis of graphs.
- [NetworkX](wikipedia://en/26908549), an [open source](https://en.wikipedia.org/wiki/Open-source_license) [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) library for studying complex graphs.
- [Tulip (software)](https://en.wikipedia.org/wiki/Tulip_%28software%29) is a free software in the domain of [information visualisation](https://en.wikipedia.org/wiki/Information_visualisation) capable of manipulating huge graphs (with more than 1.000.000 elements).
- [yEd](https://en.wikipedia.org/wiki/YEd), a free Java-based graph editor, supports import from and export to GML.
- The [Graphviz](https://en.wikipedia.org/wiki/Graphviz) project includes two command-line tools (gml2gv and gv2gml) that can convert to and from the [DOT](wikipedia://en/571341) file format.
- [Wolfram Language](https://en.wikipedia.org/wiki/Wolfram_Language), a general very high-level programming language, supports [GML import and export](https://reference.wolfram.com/language/ref/format/Graphlet.html).
