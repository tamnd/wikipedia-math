# Process function

::: {#o1 .subject cue=lead name="Process function"}

In [thermodynamics](wikipedia://en/29952), a [quantity](wikipedia://en/691277) that is well defined so as to describe the path of a process through the [equilibrium state](https://en.wikipedia.org/wiki/Equilibrium_state) space of a [thermodynamic system](wikipedia://en/425850) is termed a **process function**,[^o2] or, alternatively, a **process quantity**, or a **path function**. As an example, [mechanical work](https://en.wikipedia.org/wiki/Mechanical_work) and [heat](wikipedia://en/19593167) are process functions because they describe quantitatively the transition between equilibrium states of a thermodynamic system.

:::

## Path functions {#Path_functions}

Path functions depend on the path taken to reach one state from another. Different routes give different quantities. Examples of path functions include [work](wikipedia://en/3616613), [heat](wikipedia://en/19593167) and [arc length](wikipedia://en/1898401). In contrast to path functions, [state functions](wikipedia://en/341436) are independent of the path taken. Thermodynamic [state variables](wikipedia://en/341436) are point functions, differing from path functions. For a given state, considered as a point, there is a definite value for each state variable and state function.

## Differentials {#Differentials}

Infinitesimal changes in a process function $X$ are often indicated by $\delta X$ to distinguish them from infinitesimal changes in a state function $Y$ which is written $dY$. The quantity $dY$ is an [exact differential](wikipedia://en/405737), while $\delta X$ is not, it is an [inexact differential](https://en.wikipedia.org/wiki/Inexact_differential). Infinitesimal changes in a process function may be integrated, but the integral between two states depends on the particular path taken between the two states, whereas the integral of a state function is simply the difference of the state functions at the two points, independent of the path taken.

## Holonomic or non-holonomic {#Holonomic_or_non-holonomic}

In general, a process function $X$ may be either [holonomic](wikipedia://en/9777067) or non-holonomic. For a holonomic process function, an auxiliary state function (or integrating factor) $\lambda$ may be defined such that $Y = \lambda X$ is a state function. For a non-holonomic process function, no such function may be defined. In other words, for a holonomic process function, $\lambda$ may be defined such that $dY = \lambda\delta X$ is an exact differential. For example, thermodynamic work is a holonomic process function since the integrating factor $\lambda = \tfrac{1}{p}$ (where $p$ is pressure) will yield exact differential of the volume state function $dV = \tfrac{\delta W}{p}$. The [second law of thermodynamics](wikipedia://en/133017) as stated by [Carathéodory](https://en.wikipedia.org/wiki/Carathéodory) essentially amounts to the statement that heat is a holonomic process function since the integrating factor $\lambda = \tfrac{1}{T}$ (where $T$ is temperature) will yield the exact differential of an entropy state function $\operatorname{dS} = \tfrac{\delta Q}{T}$.[^o2]
