# Overlapping interval topology

::: {#o1 .subject cue=lead name="Overlapping interval topology"}

In [mathematics](wikipedia://en/18831), the **overlapping interval topology** is a [topology](wikipedia://en/29954) which is used to illustrate various topological principles.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given the [closed interval](https://en.wikipedia.org/wiki/Closed_interval) $[-1,1]$ of the [real number line](https://en.wikipedia.org/wiki/Real_number_line), the [open sets](wikipedia://en/39358) of the topology are [generated](wikipedia://en/395395) from the half-open intervals $(a,1]$ with $a < 0$ and $[-1,b)$ with $b > 0$. The topology therefore consists of intervals of the form $[-1,b)$, $(a,b)$, and $(a,1]$ with $a < 0 < b$, together with $[-1,1]$ itself and the empty set.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Any two [distinct](https://en.wikipedia.org/wiki/Distinct_%28mathematics%29) points in $[-1,1]$ are [topologically distinguishable](https://en.wikipedia.org/wiki/Topologically_distinguishable) under the overlapping interval topology as one can always find an open set containing one but not the other point. However, every non-empty open set contains the point 0 which can therefore not be [separated](https://en.wikipedia.org/wiki/Separated_set) from any other point in $[-1,1]$, making $[-1,1]$ with the overlapping interval topology an example of a [T<sub>0</sub> space](https://en.wikipedia.org/wiki/T0_space) that is not a [T<sub>1</sub> space](wikipedia://en/148721).

The overlapping interval topology is [second countable](https://en.wikipedia.org/wiki/Second_countable), with a countable basis being given by the intervals $[-1,s)$, $(r,s)$ and $(r,1]$ with $r < 0 < s$ and *r* and *s* rational.

:::
