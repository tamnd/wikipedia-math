# Blum–Micali algorithm

::: {#o1 .subject cue=lead name="Blum–Micali algorithm"}

The **Blum–Micali algorithm** is a [cryptographically secure pseudorandom number generator](wikipedia://en/182249). The algorithm gets its security from the difficulty of computing [discrete logarithms](https://en.wikipedia.org/wiki/Discrete_logarithms).[^o2]

:::

Let $p$ be an odd prime, and let $g$ be a [primitive root](wikipedia://en/186864) modulo $p$. Let $x_0$ be a seed, and let

$$x_{i+1} = g^{x_i}\ \bmod{\ p}.$$

The $i$th output of the algorithm is 1 if $x_i \leq \frac{p-1}{2}$. Otherwise the output is 0. This is equivalent to using one bit of $x_i$ as the random number. It has been shown that $n - c - 1$ bits of $x_i$ can be used if solving the discrete log problem is infeasible even for exponents with as few as $c$ bits.[^o3]

In order for this generator to be secure, the prime number $p$ needs to be large enough so that computing discrete logarithms modulo $p$ is infeasible.[^o2] To be more precise, any method that predicts the numbers generated will lead to an algorithm that solves the discrete logarithm problem for that prime.[^o4]

There is a paper discussing possible examples of the quantum permanent compromise attack to the Blum–Micali construction. This attacks illustrate how a previous attack to the Blum–Micali generator can be extended to the whole Blum–Micali construction, including the [Blum Blum Shub](wikipedia://en/39599) and [Kaliski](https://en.wikipedia.org/wiki/Kaliski_generator) generators.[^o5]
