# Minimum polynomial extrapolation

::: {#o1 .subject cue=lead name="Minimum polynomial extrapolation"}

In [mathematics](wikipedia://en/18831), **minimum polynomial extrapolation** is a [sequence transformation](wikipedia://en/2293999) used for [convergence acceleration](https://en.wikipedia.org/wiki/Convergence_acceleration) of vector sequences, due to Cabay and Jackson.[^o2]

:::

While [Aitken's method](https://en.wikipedia.org/wiki/Aitken's_method) is the most famous, it often fails for vector sequences. An effective method for vector sequences is the minimum polynomial extrapolation. It is usually phrased in terms of the [fixed point iteration](https://en.wikipedia.org/wiki/Fixed_point_iteration):

$$x_{k+1}=f(x_k).$$

Given iterates $x_1, x_2, ..., x_k$ in $\mathbb R^n$, one constructs the $n \times (k-1)$ matrix $U=(x_2-x_1, x_3-x_2, ..., x_k-x_{k-1})$ whose columns are the $k-1$ differences. Then, one computes the vector $c=-U^+ (x_{k+1}-x_k)$ where $U^+$ denotes the Moore–Penrose [pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse) of $U$. The number 1 is then appended to the end of $c$, and the extrapolated limit is

$$s={ X c \over \sum_{i=1}^k c_i },$$

where $X=(x_2, x_3, ..., x_{k+1})$ is the matrix whose columns are the $k$ iterates starting at 2.

The following 4 line MATLAB code segment implements the MPE algorithm:

```matlab
U = x(:, 2:end - 1) - x(:, 1:end - 2);
c = - pinv(U) * (x(:, end) - x(:, end - 1));
c(end + 1, 1) = 1;
s = (x(:, 2:end) * c) / sum(c);
```
