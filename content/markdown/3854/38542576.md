# Young's convolution inequality

::: {#o1 .subject cue=lead name="Young's convolution inequality"}

In [mathematics](wikipedia://en/18831), **Young's convolution inequality** is a [mathematical inequality](wikipedia://en/89489) about the [convolution](wikipedia://en/7519) of two functions,[^o2] named after [William Henry Young](https://en.wikipedia.org/wiki/William_Henry_Young).

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

### Euclidean space {#Euclidean_space}

In [real analysis](wikipedia://en/26478), the following result is called Young's convolution inequality:[^o6]

Suppose $f$ is in the [Lebesgue space](wikipedia://en/45194) $L^p(\mathbb{R}^d)$ and $g$ is in $L^q(\mathbb{R}^d)$ and

$$\frac{1}{p} + \frac{1}{q} = \frac{1}{r} + 1$$

with $1 \leq p, q, r \leq \infty.$ Then

$$\|f * g\|_r \leq \|f\|_p \|g\|_q.$$

Here the star denotes [convolution](wikipedia://en/7519), $L^p$ is [Lebesgue space](wikipedia://en/45194), and

$$\|f\|_p = \Bigl(\int_{\mathbb{R}^d} |f(x)|^p\,dx \Bigr)^{1/p}$$

denotes the usual $L^p$ norm.

Equivalently, if $p, q, r \geq 1$ and $\frac{1}{p} + \frac{1}{q} + \frac{1}{r} = 2$ then

$$\left|\int_{\mathbb{R}^d} \int_{\mathbb{R}^d} f(x) g(x - y) h(y) \,\mathrm{d}x \,\mathrm{d}y\right| \leq \left(\int_{\mathbb{R}^d} \vert f\vert^p\right)^\frac{1}{p} \left(\int_{\mathbb{R}^d} \vert g\vert^q\right)^\frac{1}{q} \left(\int_{\mathbb{R}^d} \vert h\vert^r\right)^\frac{1}{r}$$

::: {#o8 .statement kind=statement/generalization cue=heading name="Generalizations"}

### Generalizations {#Generalizations}

Young's convolution inequality has a natural generalization in which we replace $\mathbb{R}^d$ by a $\sigma$-compact [unimodular group](https://en.wikipedia.org/wiki/Unimodular_group) $G.$ If we let $\mu$ be a bi-invariant [Haar measure](wikipedia://en/40645) on $G$ and we let $f, g : G \to\mathbb{R}$ or $\mathbb{C}$ be integrable functions, then we define $f * g$ by

$$f*g(x) = \int_G f(y)g(y^{-1}x)\,\mathrm{d}\mu(y).$$

Then in this case, Young's inequality states that for $f\in L^p(G,\mu)$ and $g\in L^q(G,\mu)$ and $p, q, r \in [1,\infty]$ such that

$$\frac{1}{p} + \frac{1}{q} = \frac{1}{r} + 1$$

we have a bound

$$\lVert f*g \rVert_r \leq \lVert f \rVert_p \lVert g \rVert_q.$$

Equivalently, if $p, q, r \ge 1$ and $\frac{1}{p} + \frac{1}{q} + \frac{1}{r} = 2$ then

$$\left|\int_G \int_G f(x) g(y^{-1}x) h (y) \,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y)\right| \leq \left(\int_G \vert f\vert^p\right)^\frac{1}{p} \left(\int_G \vert g\vert^q\right)^\frac{1}{q} \left(\int_G \vert h\vert^r\right)^\frac{1}{r}.$$

Since $\mathbb{R}^d$ is in fact a [locally compact abelian group](wikipedia://en/454325) (and therefore unimodular) with the [Lebesgue measure](wikipedia://en/18198) the desired Haar measure, this is in fact a generalization.

This generalization may be refined. Let $G$ and $\mu$ be as before and assume $1 < p, q, r < \infty$ satisfy $\tfrac{1}{p} + \tfrac{1}{q} = \tfrac{1}{r} + 1.$ Then there exists a constant $C$ such that for any $f \in L^p(G,\mu)$ and any measurable function $g$ on $G$ that belongs to the [weak $L^q$ space](wikipedia://en/45194#Weak_Lp) $L^{q,w}(G, \mu),$ which by definition means that the following [supremum](https://en.wikipedia.org/wiki/Supremum)

$$\|g\|_{q,w}^q ~:=~ \sup_{t > 0} \, t^q \mu(|g| > t)$$

is finite, we have $f * g \in L^r(G, \mu)$ and[^n1]

$$\|f * g\|_r ~\leq~ C \, \|f\|_p \, \|g\|_{q,w}.$$

:::

## Applications {#Applications}

An example application is that Young's inequality can be used to show that the [heat semigroup](wikipedia://en/17467553) is a contracting semigroup using the $L^2$ norm (that is, the [Weierstrass transform](wikipedia://en/17467553) does not enlarge the $L^2$ norm).

:::

## Proof {#Proof}

::: {#o15 .proof cue=heading name="Proof by Hölder's inequality"}

### Proof by Hölder's inequality {#Proof_by_Hölder's_inequality}

Young's inequality has an [elementary proof](wikipedia://en/9318685) with the non-optimal constant 1.[^o16]

We assume that the functions $f, g, h : G \to \mathbb{R}$ are nonnegative and integrable, where $G$ is a $\sigma$-compact unimodular group endowed with a bi-invariant $\sigma$-finite Haar measure $\mu.$ We use the fact that $\mu(S)=\mu(S^{-1})$ for any measurable $S \subseteq G.$ Since $p(2 - \tfrac{1}{q} - \tfrac{1}{r}) = q(2 - \tfrac{1}{p} - \tfrac{1}{r}) = r(2 - \tfrac{1}{p} - \tfrac{1}{q}) = 1$

$$\begin{aligned} &\int_G \int_G f(x) g(y^{-1}x) h(y) \,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y) \\ ={}& \int_G \int_G \left(f(x)^p g(y^{-1}x)^q\right)^{1 - \frac{1}{r}} \left(f(x)^p h(y)^r\right)^{1 - \frac{1}{q}} \left(g(y^{-1}x)^q h(y)^r\right)^{1 - \frac{1}{p}}\,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y) \end{aligned}$$

By the [Hölder inequality](https://en.wikipedia.org/wiki/Hölder_inequality) for three functions we deduce that

$$\begin{aligned} &\int_G \int_G f (x) g (y^{-1}x) h(y) \,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y) \\ &\leq \left(\int_G \int_G f(x)^p g(y^{-1}x)^q \,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y)\right)^{1 - \frac{1}{r}} \left(\int_G \int_G f(x)^p h(y)^r \,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y)\right)^{1 - \frac{1}{q}} \left(\int_G \int_G g(y^{-1}x)^q h(y)^r \,\mathrm{d}\mu(x) \,\mathrm{d}\mu(y)\right)^{1 - \frac{1}{p}}. \end{aligned}$$

The conclusion follows then by left-invariance of the Haar measure, the fact that integrals are preserved by inversion of the domain, and by [Fubini's theorem](wikipedia://en/255245).

:::

## Sharp constant {#Sharp_constant}

In case $p, q > 1,$ Young's inequality can be strengthened to a sharp form, via

$$\|f*g\|_r \leq c_{p,q} \|f\|_p \|g\|_q.$$

where the constant $c_{p,q} < 1.$[^o20][^o21][^o22] When this optimal constant is achieved, the function $f$ and $g$ are [multidimensional Gaussian functions](wikipedia://en/245552).
