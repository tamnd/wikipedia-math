# Nd game

::: {#o1 .subject cue=lead name="Nd game"}

A ***n*<sup>*d*</sup> game** (or ***n*<sup>*k*</sup> game**) is a [generalization](wikipedia://en/12746) of the combinatorial game [tic-tac-toe](https://en.wikipedia.org/wiki/Tic-tac-toe) to higher dimensions.[^o2][^o3][^o4] It is a game played on a *n*<sup>*d*</sup> [hypercube](wikipedia://en/39783) with 2 players.[^o2][^o3][^o5][^o6] If one player creates a line of length *n* of their symbol (X or O) they win the game. However, if all *n*<sup>*d*</sup> spaces are filled then the game is a draw.[^o5] Tic-tac-toe is the game where *n* equals 3 and *d* equals 2 (3, 2).[^o5] [Qubic](https://en.wikipedia.org/wiki/3D_tic-tac-toe) is the (4, 3) game.[^o5] The (*n* > 0, 0) or (1, 1) games are trivially won by the first player as there is only one space (*n*<sup>0</sup> = 1 and 1<sup>1</sup> = 1). A game with *d* = 1 and *n* > 1 cannot be won if both players are playing well as an opponent's piece will block the one-dimensional line.[^o6]

:::

## Game theory {#Game_theory}

::: {#o8 .problem cue=unsolved}

Given a width of tic-tac-toe board, what is the smallest dimension such that X is guaranteed a winning strategy?

:::

An *n<sup>d</sup>* game is a [symmetric](https://en.wikipedia.org/wiki/Symmetric_game) [combinatorial game](wikipedia://en/292231).

There are a total of $\frac{\left(n+2\right)^d-n^d}{2}$ winning lines in a *n*<sup>*d*</sup> game.[^o3][^o9]

For any width *n*, at some dimension *d* (thanks to the [Hales-Jewett theorem](https://en.wikipedia.org/wiki/Hales-Jewett_theorem)), there will always be a winning strategy for player X. There will never be a winning strategy for player O because of the [Strategy-stealing argument](wikipedia://en/709783) since an n<sup>d</sup> game is [symmetric](https://en.wikipedia.org/wiki/Symmetric_game).
