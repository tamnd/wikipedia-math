# Non-separable wavelet

::: {#o1 .subject cue=lead name="Non-separable wavelet"}

**Non-separable wavelets** are multi-dimensional [wavelets](wikipedia://en/50903) that are not directly implemented as [tensor products](wikipedia://en/30844) of wavelets on some lower-dimensional space. They have been studied since 1992.[^o2] They offer a few important advantages. Notably, using non-separable filters leads to more parameters in design, and consequently better filters.[^o3] The main difference, when compared to the one-dimensional wavelets, is that [multi-dimensional sampling](https://en.wikipedia.org/wiki/Multidimensional_sampling) requires the use of [lattices](wikipedia://en/469246) (e.g., the quincunx lattice). The wavelet filters themselves can be separable or non-separable regardless of the sampling lattice. Thus, in some cases, the non-separable wavelets can be implemented in a separable fashion. Unlike separable wavelet, the non-separable wavelets are capable of detecting structures that are not only horizontal, vertical or diagonal (show less [anisotropy](https://en.wikipedia.org/wiki/Anisotropy)).

:::

## Examples {#Examples}

- Red-black wavelets[^o6]
- [Contourlets](wikipedia://en/15492132)[^o7]
- [Shearlets](wikipedia://en/41918927)[^o8]
- Directionlets[^o9]
- [Steerable pyramids](https://en.wikipedia.org/wiki/Pyramid_%28image_processing%29#Steerable_pyramid)[^o10]
- Non-separable schemes for tensor-product wavelets[^o11]
