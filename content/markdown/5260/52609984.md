# Anytime A\*

::: {#o1 .subject cue=lead name="Anytime A*"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), **anytime A\*** is a family of variants of the [A\* search algorithm](wikipedia://en/100558). Like other [anytime algorithms](https://en.wikipedia.org/wiki/Anytime_algorithm), it has a flexible time cost, can return a valid solution to a [pathfinding](https://en.wikipedia.org/wiki/Pathfinding) or [graph traversal](wikipedia://en/6263731) problem even if it is interrupted before it ends, by generating a fast, non-optimal solution before progressively optimizing it. This ability to quickly generate solutions has made it attractive to Search-base sites and [AI](https://en.wikipedia.org/wiki/Artificial_intelligence) designs.

:::

## Background and history {#Background_and_history}

Running the optimal A\* algorithm to completion is too expensive for many purposes. A\*'s optimality can be sacrificed in order to reduce the execution time by inflating the heuristic, as in **weighted A\*** from 1970.[^o3] Iteratively reducing the degree the heuristic is "inflated" provides a naive anytime algorithm (ATA\*, 2002), but this repeats previous work.[^o4] A more efficient and error-bounded version that reuses results, **Anytime Repairing A\*** (**ARA\***), was reported in 2003.[^o5][^o10] A dynamic (in the sense of [D\*](https://en.wikipedia.org/wiki/D*)) modification of ARA\*, **Anytime Dynamic A\*** (**ADA\***) was published in 2005. It combines aspects of D\* Lite and ARA\*.[^o6] **Anytime Weighted A\*** (1997, 2007) is similar to weighted A\*, except that it continues the search after finding the first solution. It finds better solutions iteratively and ultimately finds the optimal solution without repeating previous work and also provides error bounds throughout the search.[^o7][^o8] **Randomized Weighted A\*** (2021) introduced randomization into Anytime Weighted A\* and demonstrated better empirical performance.[^o11]

## Difference from A\* {#Difference_from_A*}

*Image: Weighted A star with eps 5.gif.* Weighted A\* search that uses a heuristic that is $w$ = 5.0 times a [consistent heuristic](https://en.wikipedia.org/wiki/Consistent_heuristic) and obtains a suboptimal path.

[A\* search algorithm](wikipedia://en/100558) can be presented by the function of $f(n) = g(n) + h(n)$, where $n$ is the last node on the path, $g(n)$ is the cost of the path from the start node to $n$, and $h(n)$ is a heuristic that estimates the cost of the cheapest path from $n$ to the goal. Different than the A\* algorithm, the most important function of Anytime A\* algorithm is that, they can be stopped and then can be restarted at any time. Anytime A\* family of algorithms typically build upon the weighted version of the A\* search: where one uses $f_{w}(n) = g(n) + w \times h(n)$, $w > 1$, and performs the A\* search as usual, which eventually happens faster since fewer nodes are expanded.[^o3]

ATA\* involves running weighted A\* multiple times with $w$ gradually lowering each time until $w$=1 when the search just becomes plain A\*. Although this *could* work by calling A\* repeatedly and discarding all previous memory, ARA\* does this by introducing a way of updating the path.[^o10] The initial value of $w$ determines the minimal (first-time) runtime of ATA\*.

Anytime weighted A\* turns weighted A\* into an anytime algorithm as follows.[^o7][^o8] Each goal test is done at node generation instead of node expansion, and the current solution becomes the best goal node so far. Unless the algorithm is interrupted, the search continues until the optimal solution is found. During the search, the error bound is the cost of the current solution $c$ minus the least f-value in the open list. The optimal solution is detected when no more nodes with $f(n) \le c$ remain open, and at that point the algorithm terminates with $c$ as the cost of optimal solution. In 2021, it was discovered that given a search time-limit, Anytime weighted A\* yields better solutions on average by simply switching the weight randomly after each node expansion than by using a fine-tuned static weight or by gradually lowering the weight after each solution.[^o11]
