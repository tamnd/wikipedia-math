# Joyal's extension and lifting theorems

::: {#o1 .subject cue=lead name="Joyal's extension and lifting theorems"}

In mathematics, **Joyal's theorem** is a theorem in [homotopy theory](wikipedia://en/61994831) that provides necessary and sufficient conditions for the solvability of a certain lifting problem involving [simplicial sets](wikipedia://en/1027784). In particular, in [higher category theory](wikipedia://en/5274013), it proves the statement "an [∞-groupoid](wikipedia://en/40965675) is a [Kan complex](https://en.wikipedia.org/wiki/Kan_complex)",[^o2] which is a version of the [homotopy hypothesis](wikipedia://en/40965653).[^o3]

:::

The theorem was introduced by [André Joyal](wikipedia://en/9157736).

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Joyal's extension theorem"}

## Joyal's extension theorem {#Joyal's_extension_theorem}

Let $C$ be [quasicategory](https://en.wikipedia.org/wiki/Quasicategory) and let $u:X \rightarrow Y$ be a [morphism](wikipedia://en/27716891) of $C$. The following conditions are equivalent:[^o6][^o7][^o8][^o9]

(1) The morphism $u$ is an [isomorphism](wikipedia://en/14828).

(2) Let $n \geq 2$ and let $\sigma_0 : \Lambda^n_0 \to C$ be a morphism of simplicial sets for which the initial edge

$$\Delta^1 \cong N_{\bullet }( \{ 0 < 1\} ) \rightarrow \Lambda^n_ 0 \xrightarrow {\sigma _0} C$$

is equal to $u$. Then $\sigma_0$ can be extended to an [*n*-simplex](wikipedia://en/8992759#Definition_of_the_standard_n-simplex) $\sigma : \Delta^n \to C$.

(3) Let $n \geq 2$ and let $\sigma_0 : \Lambda^n_n \rightarrow C$ be a morphism of simplicial sets for which the initial edge

$$\Delta^1 \cong N_{\bullet }( \{ n-1 < n\} ) \rightarrow \Lambda^n_ n \xrightarrow {\sigma _0} C$$

is equal to $u$. Then $\sigma_0$ can be extended to an *n*-simplex $\sigma : \Delta^n \to C$.

:::
