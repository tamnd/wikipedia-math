# IP set

::: {#o1 .subject cue=lead name="IP set"}

In [mathematics](wikipedia://en/18831), an **IP set** is a set of [natural numbers](wikipedia://en/21474) which contains all **finite sums** of some [infinite set](wikipedia://en/142679).

:::

The finite sums of a set *D* of natural numbers are all those numbers that can be obtained by adding up the elements of some finite [nonempty](wikipedia://en/9566) [subset](wikipedia://en/27631) of *D*. The set of all finite sums over *D* is often denoted as FS(*D*). Slightly more generally, for a [sequence](wikipedia://en/27838) of natural numbers (*n<sub>i</sub>*), one can consider the set of finite sums FS((*n<sub>i</sub>*)), consisting of the sums of all finite length subsequences of (*n<sub>i</sub>*).

A set *A* of natural numbers is an IP set if there exists an infinite set *D* such that FS(*D*) is a subset of *A*. Equivalently, one may require that *A* contains all finite sums FS((*n<sub>i</sub>*)) of a sequence (*n<sub>i</sub>*).

Some authors give a slightly different definition of IP sets: They require that FS(*D*) equal *A* instead of just being a subset.

The term IP set was coined by [Hillel Furstenberg](wikipedia://en/6450152) and [Benjamin Weiss](wikipedia://en/40423267)[^o2][^o3] to abbreviate "**i**nfinite-dimensional [**p**arallelepiped](wikipedia://en/23975)". Serendipitously, the abbreviation IP can also be expanded to "**i**dem**p**otent"[^o4] (a set is an IP if and only if it is a member of an idempotent [ultrafilter](wikipedia://en/31911)).

::: {#o6 .statement kind=statement/theorem cue=named-heading name="Hindman's theorem"}

## Hindman's theorem {#Hindman's_theorem}

If $S$ is an IP set and $S = C_1 \cup C_2 \cup \cdots \cup C_n$, then at least one $C_i$ is an IP set. This is known as *Hindman's theorem* or the *finite sums theorem*.[^o7][^o8] In different terms, Hindman's theorem states that the class of IP sets is [partition regular](https://en.wikipedia.org/wiki/Partition_regular).

Since the set of natural numbers itself is an IP set and partitions can also be seen as colorings, one can reformulate a special case of Hindman's theorem in more familiar terms: Suppose the natural numbers are "colored" with *n* different colors; each natural number gets one and only one color. Then there exists a color *c* and an infinite set *D* of natural numbers, all colored with *c*, such that every finite sum over *D* also has color *c*.

Hindman's theorem is named for mathematician [Neil Hindman](wikipedia://en/76179196), who [proved](wikipedia://en/82285) it in 1974.[^o7] The [Milliken–Taylor theorem](wikipedia://en/4277566) is a common generalisation of Hindman's theorem and [Ramsey's theorem](wikipedia://en/184898).

:::

## Semigroups {#Semigroups}

The definition of being IP has been extended from subsets of the special [semigroup](wikipedia://en/27799) of natural numbers with addition to subsets of semigroups and partial semigroups in general. A variant of Hindman's theorem is true for arbitrary semigroups.[^o10][^o11]
