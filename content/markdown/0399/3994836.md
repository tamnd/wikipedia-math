# Piecewise syndetic set

::: {#o1 .subject cue=lead name="Piecewise syndetic set"}

In [mathematics](wikipedia://en/18831), **piecewise syndeticity** is a notion of largeness of [subsets](wikipedia://en/27631) of the [natural numbers](wikipedia://en/21474).

:::

A set $S \subset \mathbb{N}$ is called *piecewise syndetic* if there exists a [finite](wikipedia://en/11742) subset *G* of $\mathbb{N}$ such that for every finite subset *F* of $\mathbb{N}$ there exists an $x \in \mathbb{N}$ such that

$$x+F \subset \bigcup_{n \in G} (S-n)$$

where $S-n = \{m \in \mathbb{N}: m+n \in S \}$. Equivalently, *S* is piecewise syndetic if there is a constant *b* such that there are arbitrarily long [intervals](wikipedia://en/49172) of $\mathbb{N}$ where the gaps in *S* are bounded by *b*.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A set is piecewise syndetic if and only if it is the [intersection](wikipedia://en/23476429) of a [syndetic set](https://en.wikipedia.org/wiki/Syndetic_set) and a [thick set](https://en.wikipedia.org/wiki/Thick_set).
- If *S* is piecewise syndetic then *S* contains arbitrarily long [arithmetic progressions](wikipedia://en/168389).
- A set *S* is piecewise syndetic if and only if there exists some [ultrafilter](wikipedia://en/31911) *U* which contains *S* and *U* is in the smallest two-sided ideal of $\beta \mathbb{N}$, the [Stone–Čech compactification](wikipedia://en/52897) of the natural numbers.
- [Partition regularity](https://en.wikipedia.org/wiki/Partition_regular): if $S$ is piecewise syndetic and $S = C_1 \cup C_2 \cup \dots \cup C_n$, then for some $i \leq n$, $C_i$ contains a piecewise syndetic set. (Brown, 1968)
- If *A* and *B* are subsets of $\mathbb{N}$ with positive [upper Banach density](wikipedia://en/1819983), then $A+B=\{a+b : a \in A,\, b \in B\}$ is piecewise syndetic.[^o4]

:::

## Other notions of largeness {#Other_notions_of_largeness}

There are many alternative definitions of largeness that also usefully distinguish subsets of natural numbers:

- [Cofiniteness](wikipedia://en/382708)
- [IP set](wikipedia://en/3999498)
- member of a nonprincipal [ultrafilter](wikipedia://en/31911)
- positive [upper density](https://en.wikipedia.org/wiki/Upper_density)
- [syndetic set](https://en.wikipedia.org/wiki/Syndetic_set)
- [thick set](https://en.wikipedia.org/wiki/Thick_set)
