# Vopěnka's principle

::: {#o1 .subject cue=lead name="Vopěnka's principle"}

In [mathematics](wikipedia://en/18831), **Vopěnka's principle** is a [large cardinal](wikipedia://en/383644) axiom. The intuition behind the axiom is that the set-theoretical universe is so large that in every [proper class](https://en.wikipedia.org/wiki/Proper_class), some members are similar to others, with this similarity formalized through [elementary embeddings](https://en.wikipedia.org/wiki/Elementary_embedding).

:::

Vopěnka's principle was first introduced by [Petr Vopěnka](wikipedia://en/3105466) and independently considered by [H. Jerome Keisler](https://en.wikipedia.org/wiki/H._Jerome_Keisler), and was written up by (Solovay Reinhardt Kanamori 1978). According to (Pudlák 2013, p. 204), Vopěnka's principle was originally intended as a joke: Vopěnka was apparently unenthusiastic about large cardinals and introduced his principle as a bogus large cardinal property, planning to show later that it was not consistent. However, before publishing his inconsistency proof he found a flaw in it.

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Vopěnka's principle asserts that for every [proper class](https://en.wikipedia.org/wiki/Proper_class) of [binary relations](wikipedia://en/3931) (each with set-sized domain), there is one [elementarily embeddable](https://en.wikipedia.org/wiki/Elementary_embedding) into another. This cannot be stated as a single sentence of [ZFC](wikipedia://en/152214) as it involves a quantification over classes. A cardinal κ is called a **Vopěnka cardinal** if it is [inaccessible](wikipedia://en/248076) and Vopěnka's principle holds in the rank *V*<sub>κ</sub> (allowing arbitrary *S* ⊂ *V*<sub>κ</sub> as "classes"). [^o6]

Many equivalent formulations are possible. For example, Vopěnka's principle is equivalent to each of the following statements.

- For every proper class of [simple directed graphs](wikipedia://en/19721986), there are two members of the class with a homomorphism between them.[^o7]
- For any [signature](wikipedia://en/7788156) *Σ* and any proper class of *Σ*-structures, there are two members of the class with an elementary embedding between them.[^o6][^o7]
- For every predicate *P* and proper class *S* of [ordinals](wikipedia://en/26547932), there is a non-trivial elementary embedding *j*:(*V*<sub>κ</sub>, ∈, *P*) → (V<sub>λ</sub>, ∈, *P*) for some κ and λ in *S*.[^o6]
- The [category](wikipedia://en/53759) of ordinals cannot be fully embedded in the category of graphs.[^o7]
- Every subfunctor of an [accessible functor](wikipedia://en/15311782) is accessible.[^o7]
- (In a definable classes setting) For every natural number *n*, there exists a [*C<sup>(n)</sup>*-extendible cardinal](wikipedia://en/325950#Variants_and_relation_to_other_cardinals).[^o8]

:::

## Strength {#Strength}

Even when restricted to predicates and proper classes definable in first order set theory, the principle implies existence of Σ<sub>n</sub> correct [extendible cardinals](wikipedia://en/325950) for every *n*.

If κ is an [almost huge cardinal](wikipedia://en/248117), then a strong form of Vopěnka's principle holds in *V*<sub>κ</sub>:

There is a κ-complete [ultrafilter](https://en.wikipedia.org/wiki/Ultrafilter_%28set_theory%29) *U* such that for every {*R*<sub>*i*</sub>: *i* \< κ} where each *R*<sub>*i*</sub> is a binary relation and *R*<sub>*i*</sub> ∈ *V*<sub>κ</sub>, there is *S* ∈ *U* and a non-trivial elementary embedding *j*: *R*<sub>*a*</sub> → *R*<sub>*b*</sub> for every *a* \< *b* in *S*.
