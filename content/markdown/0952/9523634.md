# Kaplansky density theorem

::: {#o1 .subject cue=lead name="Kaplansky density theorem"}

In the theory of [von Neumann algebras](wikipedia://en/294185), the **Kaplansky density theorem**, due to [Irving Kaplansky](https://en.wikipedia.org/wiki/Irving_Kaplansky), is a fundamental approximation theorem. The importance and ubiquity of this technical tool led [Gert Pedersen](https://en.wikipedia.org/wiki/Gert_Pedersen) to comment in one of his books[^o2] that,

:::

*The density theorem is Kaplansky's great gift to mankind. It can be used every day, and twice on Sundays.*

::: {#o4 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

Let *K*<sup>−</sup> denote the [strong-operator closure](wikipedia://en/458699) of a set *K* in *B(H)*, the set of bounded operators on the Hilbert space *H*, and let (*K*)<sub>1</sub> denote the intersection of *K* with the unit ball of *B(H)*.

**Kaplansky density theorem**.[^o5] If $A$ is a self-adjoint algebra of operators in $B(H)$, then each element $a$ in the unit ball of the strong-operator closure of $A$ is in the strong-operator closure of the unit ball of $A$. In other words, $(A)_1^{-} = (A^{-})_1$. If $h$ is a self-adjoint operator in $(A^{-})_1$, then $h$ is in the strong-operator closure of the set of self-adjoint operators in $(A)_1$.

The Kaplansky density theorem can be used to formulate some approximations with respect to the [strong operator topology](wikipedia://en/458699).

\1) If *h* is a positive operator in (*A*<sup>−</sup>)<sub>1</sub>, then *h* is in the strong-operator closure of the set of self-adjoint operators in (*A*<sup>\+</sup>)<sub>1</sub>, where *A*<sup>\+</sup> denotes the set of positive operators in *A*.

\2) If *A* is a [C\*-algebra](wikipedia://en/7184) acting on the Hilbert space *H* and *u* is a unitary operator in A<sup>−</sup>, then *u* is in the strong-operator closure of the set of unitary operators in *A*.

In the density theorem and 1) above, the results also hold if one considers a ball of radius *r* > *0*, instead of the unit ball.

:::

::: {#o7 .proof cue=heading name="Proof"}

## Proof {#Proof}

The standard proof uses the fact that a bounded continuous real-valued function *f* is strong-operator continuous. In other words, for a [net](wikipedia://en/22170) {*a<sub>α</sub>*} of [self-adjoint operators](wikipedia://en/187408) in *A*, the [continuous functional calculus](wikipedia://en/784808) *a* → *f*(*a*) satisfies,

$$\lim f(a_{\alpha}) = f (\lim a_{\alpha})$$

in the [strong operator topology](wikipedia://en/458699). This shows that self-adjoint part of the unit ball in *A*<sup>−</sup> can be approximated strongly by self-adjoint elements in *A*. A matrix computation in *M*<sub>2</sub>(*A*) considering the self-adjoint operator with entries *0* on the diagonal and *a* and *a*<sup>\*</sup> at the other positions, then removes the self-adjointness restriction and proves the theorem.

:::
