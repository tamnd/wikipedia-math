# Dirichlet's test

Series

::: {#o1 .subject cue=lead name="Dirichlet's test"}

In [mathematics](wikipedia://en/18831), **Dirichlet's test** is a method of testing for the [convergence](wikipedia://en/1743431) of a [series](wikipedia://en/15287) that is especially useful for proving [conditional convergence](wikipedia://en/1198956). It is named after its author [Peter Gustav Lejeune Dirichlet](wikipedia://en/240002), and was published posthumously in the *[Journal de Mathématiques Pures et Appliquées](https://en.wikipedia.org/wiki/Journal_de_Mathématiques_Pures_et_Appliquées)* in 1862.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

The test states that if $(a_n)$ is a monotonic [sequence](wikipedia://en/27838) of [real numbers](wikipedia://en/20646438) with $\lim_{n \to \infty} a_n = 0$ and $(b_n)$ is a sequence of real numbers or [complex numbers](wikipedia://en/5826) with bounded partial sums, then the series

$$\sum_{n=1}^{\infty} a_n b_n$$

converges.[^o5][^o6][^o7]

:::

::: {#o9 .proof cue=heading name="Proof"}

## Proof {#Proof}

Let $S_n = \sum_{k=1}^n a_k b_k$ and $B_n = \sum_{k=1}^n b_k$.

From [summation by parts](wikipedia://en/246188), we have that $S_n = a_{n} B_n + \sum_{k=1}^{n-1} B_k (a_k - a_{k+1})$. Since the magnitudes of the partial sums $B_n$ are [bounded](wikipedia://en/311509) by some *M* and $a_n \to 0$ as $n\to\infty$, the first of these terms approaches zero: $|a_{n} B_n| \leq |a_{n} M| \to 0$ as $n\to\infty$.

Furthermore, for each *k*, $|B_k (a_k - a_{k+1})| \leq M|a_k - a_{k+1}|$.

Since $(a_n)$ is monotone, it is either decreasing or increasing:

If $(a_n)$ is decreasing,

$$\sum_{k=1}^n M|a_k - a_{k+1}| = \sum_{k=1}^n M(a_k - a_{k+1}) = M\sum_{k=1}^n (a_k - a_{k+1}),$$

which is a [telescoping sum](https://en.wikipedia.org/wiki/Telescoping_sum) that equals $M(a_1 - a_{n+1})$ and therefore approaches $Ma_1$ as $n \to \infty$. Thus, $\sum_{k=1}^\infty M|a_k - a_{k+1}|$ converges.

If $(a_n)$ is increasing,

$$\sum_{k=1}^n M|a_k - a_{k+1}| = -\sum_{k=1}^n M(a_k - a_{k+1}) = -M\sum_{k=1}^n (a_k - a_{k+1}),$$

which is again a telescoping sum that equals $-M(a_1 - a_{n+1})$ and therefore approaches $-Ma_1$ as $n\to\infty$. Thus, again, $\sum_{k=1}^\infty M|a_k - a_{k+1}|$ converges.

So, the series $\sum_{k=1}^\infty B_k(a_k - a_{k+1})$ converges by the [direct comparison test](wikipedia://en/1601407) to $\sum_{k=1}^\infty M|a_k - a_{k+1}|$. Hence $S_n$ converges.[^o5][^o7]

:::

::: {#o11 .application cue=heading name="Applications"}

## Applications {#Applications}

A particular case of Dirichlet's test is the more commonly used [alternating series test](wikipedia://en/1598759) for the case[^o5][^o12]

$$b_n = (-1)^n \Longrightarrow\left|\sum_{n=1}^N b_n\right| \leq 1.$$

Another [corollary](wikipedia://en/168865) is that $\sum_{n=1}^\infty a_n \sin n$ converges whenever $(a_n)$ is a decreasing sequence that tends to zero. To see that $\sum_{n=1}^N \sin n$ is bounded, we can use the summation formula[^o13]

$$\sum_{n=1}^N\sin n=\sum_{n=1}^N\frac{e^{in}-e^{-in}}{2i}=\frac{\sum_{n=1}^N (e^{i})^n-\sum_{n=1}^N (e^{-i})^n}{2i}=\frac{\sin 1 +\sin N-\sin (N+1)}{2- 2\cos 1}.$$

:::

## Improper integrals {#Improper_integrals}

An analogous statement for convergence of [improper integrals](wikipedia://en/346030) is [proven](wikipedia://en/82285) using [integration by parts](wikipedia://en/147252). If the [integral](wikipedia://en/15532) of a function *f* is uniformly bounded over all [intervals](wikipedia://en/49172), and *g* is a bounded non-negative [monotonically decreasing function](wikipedia://en/48260), then the integral of *fg* is a convergent improper integral.
