# Positive definiteness

::: {#o1 .subject cue=lead name="Positive definiteness"}

In [mathematics](wikipedia://en/18831), **positive definiteness** is a property of any object to which a [bilinear form](wikipedia://en/449477) or a [sesquilinear form](wikipedia://en/860138) may be naturally associated, which is [positive-definite](https://en.wikipedia.org/wiki/Positive-definite_bilinear_form). See, in particular:

:::

- [Positive-definite bilinear form](https://en.wikipedia.org/wiki/Positive-definite_bilinear_form)
- [Positive-definite function](wikipedia://en/649616)
- [Positive-definite function on a group](wikipedia://en/10640474)
- [Positive-definite functional](https://en.wikipedia.org/wiki/Positive-definite_functional)
- [Positive-definite kernel](wikipedia://en/10273855)
- [Positive-definite matrix](https://en.wikipedia.org/wiki/Positive-definite_matrix)
- [Positive-definite operator](https://en.wikipedia.org/wiki/Positive-definite_operator)
- [Positive-definite quadratic form](https://en.wikipedia.org/wiki/Positive-definite_quadratic_form)
