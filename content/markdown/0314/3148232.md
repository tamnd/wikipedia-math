# Semimodule

::: {#o1 .subject cue=lead name="Semimodule"}

In [mathematics](wikipedia://en/18831), a **semimodule** over a [semiring](wikipedia://en/371468) *R* is an [algebraic structure](wikipedia://en/106364) analogous to a [module over a ring](wikipedia://en/276410), with the exception that it forms only a [commutative monoid](https://en.wikipedia.org/wiki/Commutative_monoid) with respect to its addition operation, as opposed to an [abelian group](wikipedia://en/2974).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, a **left** *R*-**semimodule** consists of an additively-written commutative monoid *M* and a map from $R \times M$ to *M* satisfying the following [axioms](wikipedia://en/928):

1. $$r (m + n) = rm + rn$$
1. $$(r + s) m = rm + sm$$
1. $$(rs)m = r(sm)$$
1. $$1m = m$$
1. $$0_R m = r 0_M = 0_M.$$

A right *R*-semimodule can be defined similarly. For modules over a ring, the last axiom follows from the others. This is not the case with semimodules.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

If *R* is a [ring](wikipedia://en/48404), then any *R*-module is an *R*-semimodule. Conversely, it follows from the second, fourth, and last axioms that (−1)*m* is an [additive inverse](wikipedia://en/228312) of *m* for all $m \in M$, so any semimodule over a ring is in fact a module.

Any semiring is a left and right semimodule over itself in the same way that a ring is a left and right module over itself. Every commutative monoid is uniquely an $\mathbb{N}$-semimodule in the same way that an abelian group is a $\mathbb{Z}$-module.

:::
