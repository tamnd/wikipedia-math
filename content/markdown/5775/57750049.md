# Induction-induction

::: {#o1 .subject cue=lead name="Induction-induction"}

In [intuitionistic type theory](wikipedia://en/345023) (ITT), a discipline within [mathematical logic](wikipedia://en/19636), **induction-induction** is for simultaneously declaring some inductive type and some inductive predicate over this type.

:::

An [inductive definition](https://en.wikipedia.org/wiki/Inductive_definition) is given by rules for generating elements of some type. One can then define some predicate on that type by providing constructors for forming the elements of the predicate, such inductively on the way the elements of the type are generated. Induction-induction generalizes this situation since one can *simultaneously* define the type and the predicate, because **the rules for generating elements of the type** $A : \mathsf{Type}$ **are allowed to refer to the predicate** $B : A \to \mathsf{Type}$.

Induction-induction can be used to define larger types including various universe constructions in type theory.[^o2] and limit constructions in category/topos theory.

## Example 1 {#Example_1}

Present the type $A$ as having the following constructors, note the early reference to the predicate $B$ :

- $$aa : A$$
- $$\ell\ell : \sum_{x : A} B(x) \to A;$$

and-simultaneously present the predicate $B$ as having the following constructors :

- $$\mathsf{Tru} : B(aa)$$
- $$\mathsf{Fal} : B(aa)$$
- if $x : A$ and $y : B(x)$ then $\mathsf{Zer} : B(\ell\ell(x,y))$
- if $x : A$ and $y : B(x)$ and $z : B(\ell\ell(x,y))$ then $\mathsf{Suc}(z) : B(\ell\ell(x,y))$.

## Example 2 {#Example_2}

A simple common example is the Universe à la Tarski type former. It creates some inductive type $U : \mathsf{Type}$ and some inductive predicate $T : U \to \mathsf{Type}$. For every type in the type theory (except $U$ itself!), there will be some element of $U$ which may be seen as some code for this corresponding type; The predicate $T$ inductively encodes each possible type to the corresponding element of $U$; and constructing new codes in $U$ will require referring to the decoding-as-type of earlier codes, via the predicate $T$.
