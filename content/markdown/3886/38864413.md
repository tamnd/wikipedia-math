# Universal point set

::: {#o1 .subject cue=lead name="Universal point set"}

::: {#o2 .problem cue=unsolved}

Do planar graphs have universal point sets of subquadratic size?

:::

In [graph drawing](wikipedia://en/325813), a **universal point set** of order *n* is a set *S* of points in the [Euclidean plane](wikipedia://en/15575410) with the property that every *n*-vertex [planar graph](wikipedia://en/24314) has a [straight-line drawing](wikipedia://en/6805386) in which the vertices are all placed at points of *S*.

:::

## Bounds on the size of universal point sets {#Bounds_on_the_size_of_universal_point_sets}

*Image: Nested triangle graph grid.svg.* Grid drawing of a nested triangles graph. In any drawing of this graph, at least half of the triangles must form a nested chain, which requires a bounding box of size at least *n*/3 × *n*/3. The layout shown here comes close to this, using size approximately *n*/3 × *n*/2

When *n* ≤ 10, there exist universal point sets with exactly *n* points, but for all *n* ≥ 15 additional points are required.[^o4]

Several authors have shown that subsets of the [integer lattice](wikipedia://en/3333402) of size *O*(*n*) × *O*(*n*) are universal. In particular, (de Fraysseix Pach Pollack 1988) showed that a grid of (2*n* − 3) × (*n* − 1) points is universal, and (Schnyder 1990) reduced this to a triangular subset of an (*n* − 1) × (*n* − 1) grid, with *n*<sup>2</sup>/2 − *O*(*n*) points. By modifying the method of de Fraysseix et al., (Brandenburg 2008) found an embedding of any planar graph into a triangular subset of the grid consisting of 4*n*<sup>2</sup>/9 points. A universal point set in the form of a rectangular grid must have size at least *n*/3 × *n*/3[^o8] but this does not rule out the possibility of smaller universal point sets of other types. The smallest known universal point sets are not based on grids, but are instead constructed from [superpatterns](wikipedia://en/7371807) ([permutations](wikipedia://en/44027) that contain all [permutation patterns](wikipedia://en/24360911) of a given size); the universal point sets constructed in this way have size *n*<sup>2</sup>/4 − *Θ*(*n*).[^o9]

(de Fraysseix Pach Pollack 1988) [proved](wikipedia://en/82285) the first nontrivial lower bound on the size of a universal point set, with a bound of the form *n* + Ω(√*n*), and (Chrobak Karloff 1989) showed that universal point sets must contain at least 1.098*n* − *o*(*n*) points. (Kurowski 2004) stated an even stronger bound of 1.235*n* − *o*(*n*),[^o13] which was further improved by (Scheucher Schrezenmaier Steiner 2018) to 1.293*n* − *o*(*n*).

Closing the gap between the known linear lower bounds and quadratic upper bounds remains an [open problem](wikipedia://en/1333335).[^o15]

## Special classes of graphs {#Special_classes_of_graphs}

Subclasses of the planar graphs may, in general, have smaller universal sets (sets of points that allow straight-line drawings of all *n*-vertex graphs in the subclass) than the full class of planar graphs, and in many cases universal point sets of exactly *n* points are possible. For instance, it is not hard to see that every set of *n* points in [convex position](wikipedia://en/40079283) (forming the vertices of a [convex polygon](wikipedia://en/660019)) is universal for the *n*-vertex [outerplanar graphs](wikipedia://en/352343), and in particular for [trees](wikipedia://en/48560). Less obviously, every set of *n* points in [general position](wikipedia://en/383736) (no three [collinear](https://en.wikipedia.org/wiki/Collinear)) remains universal for outerplanar graphs.[^o17]

Planar graphs that can be partitioned into nested cycles, 2-outerplanar graphs and planar graphs of bounded [pathwidth](wikipedia://en/5133142), have universal point sets of nearly-linear size.[^o18] [Planar 3-trees](wikipedia://en/31104610) have universal point sets of size *O*(*n*<sup>3/2</sup> log *n*); the same bound also applies to [series–parallel graphs](wikipedia://en/9938559).[^o19]

## Other drawing styles {#Other_drawing_styles}

*Image: Goldner-Harary-linear.svg.* An arc diagram

As well as for straight-line graph drawing, universal point sets have been studied for other drawing styles; in many of these cases, universal point sets with exactly *n* points exist, based on a topological [book embedding](wikipedia://en/3987703) in which the vertices are placed along a line in the plane and the edges are drawn as curves that cross this line at most once. For instance, every set of *n* collinear points is universal for an [arc diagram](wikipedia://en/38996336) in which each edge is represented as either a single [semicircle](wikipedia://en/617831) or a smooth curve formed from two semicircles.[^o21]

By using a similar layout, every strictly [convex curve](wikipedia://en/29747989) in the plane can be shown to contain an *n*-point subset that is universal for [polyline](wikipedia://en/12056032) drawing with at most [one bend per edge](wikipedia://en/43176911).[^o22] This set contains only the vertices of the drawing, not the bends; larger sets are known that can be used for polyline drawing with all vertices and all bends placed within the set.[^o23]
