# Ostrowski numeration

::: {#o1 .subject cue=lead name="Ostrowski numeration"}

In mathematics, **Ostrowski numeration**, named after [Alexander Ostrowski](wikipedia://en/5827091), is either of two related numeration systems based on [continued fractions](wikipedia://en/739199): a [non-standard positional numeral system](https://en.wikipedia.org/wiki/Non-standard_positional_numeral_system) for integers and a [non-integer representation](https://en.wikipedia.org/wiki/Non-integer_representation) of [real numbers](wikipedia://en/20646438).

:::

Fix a positive [irrational number](wikipedia://en/20647689) *α* with [continued fraction](wikipedia://en/739199) expansion \[*a*<sub>0</sub>; *a*<sub>1</sub>, *a*<sub>2</sub>, ...\]. Let (*q*<sub>*n*</sub>) be the sequence of denominators of the convergents *p*<sub>*n*</sub>/*q*<sub>*n*</sub> to α: so *q*<sub>*n*</sub> = *a*<sub>*n*</sub>*q*<sub>*n*−1</sub> + *q*<sub>*n*−2</sub>. Let *α*<sub>*n*</sub> denote *T*<sup>*n*</sup>(*α*) where *T* is the [Gauss map](wikipedia://en/1360654#The_Gauss_map) *T*(*x*) = {1/*x*}, and write *β*<sub>*n*</sub> = (−1)<sup>*n*+1</sup> *α*<sub>0</sub> *α*<sub>1</sub> ... *α*<sub>*n*</sub>: we have *β*<sub>*n*</sub> = *a*<sub>*n*</sub>*β*<sub>*n*−1</sub> + *β*<sub>*n*−2</sub>.

## Real number representations {#Real_number_representations}

Every positive real *x* can be written as

$$x = \sum_{n=1}^\infty b_n \beta_n \$$

where the integer coefficients 0 ≤ *b*<sub>*n*</sub> ≤ *a*<sub>*n*</sub> and if *b*<sub>*n*</sub> = *a*<sub>*n*</sub> then *b*<sub>*n*−1</sub> = 0.

## Integer representations {#Integer_representations}

Every positive integer *N* can be written uniquely as

$$N = \sum_{n=1}^k b_n q_n \$$

where the integer coefficients 0 ≤ *b*<sub>*n*</sub> ≤ *a*<sub>*n*</sub> and if *b*<sub>*n*</sub> = *a*<sub>*n*</sub> then *b*<sub>*n*−1</sub> = 0.

If *α* is the [golden ratio](wikipedia://en/12386), then all the partial quotients *a*<sub>*n*</sub> are equal to 1, the denominators *q*<sub>*n*</sub> are the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_numbers) and we recover [Zeckendorf's theorem](wikipedia://en/1377405) on the [Fibonacci representation](https://en.wikipedia.org/wiki/Fibonacci_representation) of positive integers as a sum of distinct non-consecutive Fibonacci numbers.
