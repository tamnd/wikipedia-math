# Orders of magnitude (numbers)

::: {#o1 .subject cue=lead name="Orders of magnitude"}

*Image: Logarithmic scale.svg.* The logarithmic scale can compactly represent the relationships between variously sized numbers.

This list contains selected [positive numbers](https://en.wikipedia.org/wiki/Positive_number) in increasing [order of magnitude](wikipedia://en/22657), including counts of things, [dimensionless quantities](https://en.wikipedia.org/wiki/Dimensionless_quantity), and [probabilities](wikipedia://en/22934). Each number is given a name in the [short scale](https://en.wikipedia.org/wiki/Long_and_short_scales), which is used in English-speaking countries, as well as a name in the [long scale](https://en.wikipedia.org/wiki/Long_and_short_scales), which is used in some of the countries that do not have English as their national language.

:::
