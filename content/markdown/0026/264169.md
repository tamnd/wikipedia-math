# Archimedean group

::: {#o1 .subject cue=lead name="Archimedean group"}

In [abstract algebra](wikipedia://en/19616384), a branch of [mathematics](wikipedia://en/18831), an **Archimedean group** is a [linearly ordered group](wikipedia://en/349014) for which the [Archimedean property](wikipedia://en/264158) holds: every two positive group elements are bounded by [integer](wikipedia://en/14563) multiples of each other. The set **R** of [real numbers](wikipedia://en/20646438) together with the [operation](wikipedia://en/4140245) of addition and the usual ordering relation between pairs of numbers is an Archimedean group. By a result of [Otto Hölder](wikipedia://en/191652), every Archimedean group is [isomorphic](wikipedia://en/12397) to a [subgroup](wikipedia://en/28011) of this group. The name "Archimedean" comes from [Otto Stolz](https://en.wikipedia.org/wiki/Otto_Stolz), who named the Archimedean property after its appearance in the works of [Archimedes](wikipedia://en/1844).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

An [additive group](wikipedia://en/19447) consists of a set of elements, an [associative](https://en.wikipedia.org/wiki/Associativity) addition operation that combines pairs of elements and returns a single element, an [identity element](wikipedia://en/14962) (or zero element) whose sum with any other element is the other element, and an [additive inverse](wikipedia://en/45199) operation such that the sum of any element and its inverse is zero.[^o5] A group is a [linearly ordered group](wikipedia://en/349014) when, in addition, its elements can be [linearly ordered](https://en.wikipedia.org/wiki/Linear_order) in a way that is compatible with the group operation: for all elements *x*, *y*, and *z*, if *x* ≤ *y* then *x* + *z* ≤ *y* + *z* and *z* + *x* ≤ *z* + *y*.

The notation *na* (where *n* is a [natural number](wikipedia://en/21474)) stands for the group sum of *n* copies of *a*. An **Archimedean group** (*G*, +, ≤) is a linearly ordered group subject to the following additional condition, the Archimedean property: For every *a* and *b* in *G* which are greater than 0, it is possible to find a natural number *n* for which the inequality *b* ≤ *na* holds.[^o6]

An equivalent definition is that an Archimedean group is a linearly ordered group without any bounded [cyclic](wikipedia://en/52327) [subgroups](wikipedia://en/28011): there does not exist a cyclic subgroup *S* and an element *x* with *x* greater than all elements in *S*.[^o7] It is straightforward to see that this is equivalent to the other definition: the Archimedean property for a pair of elements *a* and *b* is just the statement that the cyclic subgroup generated by *a* is not bounded by *b*.

:::

## Examples of Archimedean groups {#Examples_of_Archimedean_groups}

The sets of the integers, the [rational numbers](wikipedia://en/19727024), and the real numbers, together with the operation of addition and the usual ordering (≤), are Archimedean groups. Every subgroup of an Archimedean group is itself Archimedean, so it follows that every subgroup of these groups, such as the additive group of the [even numbers](https://en.wikipedia.org/wiki/Even_number) or of the [dyadic rationals](wikipedia://en/56263), also forms an Archimedean group.

[Conversely](wikipedia://en/155941), as [Otto Hölder](wikipedia://en/191652) showed, every Archimedean group is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) (as an ordered group) to a [subgroup](wikipedia://en/28011) of the real numbers.[^o9][^o10][^o11][^o12] It follows from this that every Archimedean group is necessarily an [abelian group](wikipedia://en/2974): its addition operation must be [commutative](wikipedia://en/294390).[^o9]

## Examples of non-Archimedean groups {#Examples_of_non-Archimedean_groups}

Groups that cannot be linearly ordered, such as the [finite groups](wikipedia://en/323707), are not Archimedean. For another example, see the [*p*-adic numbers](wikipedia://en/51423), a system of numbers generalizing the rational numbers in a different way to the real numbers.

Non-Archimedean ordered groups also exist; the ordered group (*G*, +, ≤) defined as follows is not Archimedean. Let the elements of *G* be the points of the [Euclidean plane](wikipedia://en/15575410), given by their [Cartesian coordinates](https://en.wikipedia.org/wiki/Cartesian_coordinate): pairs (*x*, *y*) of real numbers. Let the group addition operation be [pointwise](wikipedia://en/4786797) (vector) addition, and order these points in [lexicographic order](wikipedia://en/567667): if *a* = (*u*, *v*) and *b* = (*x*, *y*), then *a* + *b* = (*u* + *x*, *v* + *y*), and *a* ≤ *b* exactly when either *v* \< *y* or *v* = *y* and *u* ≤ *x*. Then this gives an ordered group, but one that is not Archimedean. To see this, consider the elements (1, 0) and (0, 1), both of which are greater than the zero element of the group (the [origin](wikipedia://en/1313432)). For every natural number *n*, it follows from these definitions that *n*(1, 0) = (*n*, 0) \< (0, 1), so there is no *n* that satisfies the Archimedean property.[^o14] This group can be thought of as the additive group of pairs of a real number and an [infinitesimal](wikipedia://en/160990), $(x, y) = x \epsilon + y,$ where $\epsilon$ is a unit infinitesimal: $\epsilon > 0$ but $\epsilon < y$ for any positive real number $y > 0$. [Non-Archimedean ordered fields](wikipedia://en/31046646) can be defined similarly, and their additive groups are non-Archimedean ordered groups. These are used in [non-standard analysis](https://en.wikipedia.org/wiki/Non-standard_analysis), and include the [hyperreal numbers](wikipedia://en/51429) and [surreal numbers](wikipedia://en/51432).

While non-Archimedean ordered groups cannot be [embedded](wikipedia://en/52119) in the real numbers, they can be embedded in a power of the real numbers, with lexicographic order, by the [Hahn embedding theorem](wikipedia://en/1075596); the example above is the 2-dimensional case.

## Additional properties {#Additional_properties}

Every Archimedean group has the property that, for every [Dedekind cut](wikipedia://en/45569) of the group, and every group element ε > 0, there exists another group element *x* with *x* on the lower side of the cut and *x* + ε on the upper side of the cut. However, there exist non-Archimedean ordered groups with the same property. The fact that Archimedean groups are abelian can be generalized: every ordered group with this property is abelian.[^o16]

::: {#o18 .pointer-item cue=pointer name="Archimedean monoid"}

## Generalisations {#Generalisations}

Archimedean groups can be generalised to **Archimedean monoids**, [linearly ordered](https://en.wikipedia.org/wiki/Linear_order) [monoids](wikipedia://en/19652) that obey the [Archimedean property](wikipedia://en/264158). Examples include the natural numbers, the non-negative rational numbers, and the non-negative real numbers, with the usual [binary operation](wikipedia://en/3948) $+$ and order $<$. Through a similar [proof](wikipedia://en/82285) as for Archimedean groups, Archimedean monoids can be shown to be [commutative](https://en.wikipedia.org/wiki/Commutative_monoid).

:::
