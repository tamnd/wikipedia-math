# Concave function

::: {#o1 .subject cue=lead name="Concave function"}

In [mathematics](wikipedia://en/18831), a **concave function** is one for which the function value at any convex combination of elements in the domain is greater than or equal to that convex combination of those domain elements. Equivalently, a concave function is any function for which the [hypograph](wikipedia://en/18048054) is convex. The class of concave functions is in a sense the opposite of the class of [convex functions](wikipedia://en/245568). A concave function is also [synonymously](https://en.wikipedia.org/wiki/Synonym) called **concave downwards**, **concave down**, **convex upwards**, **convex cap**, or **upper convex**.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A real-valued [function](wikipedia://en/185427) $f$ on an [interval](wikipedia://en/49172) (or, more generally, a [convex set](wikipedia://en/6292) in [vector space](wikipedia://en/32370)) is said to be *concave* if, for any $x$ and $y$ in the interval and for any $\alpha \in [0,1]$,[^o4]

$$f((1-\alpha )x+\alpha y)\geq (1-\alpha ) f(x)+\alpha f(y)$$

A function is called *strictly concave* if

$$f((1-\alpha )x+\alpha y) > (1-\alpha ) f(x)+\alpha f(y)$$

for any $\alpha \in (0,1)$ and $x \neq y$.

For a function $f: \mathbb{R} \to \mathbb{R}$, this second definition merely states that for every $z$ strictly between $x$ and $y$, the point $(z, f(z))$ on the graph of $f$ is above the straight line joining the points $(x, f(x))$ and $(y, f(y))$.

*Image: ConcaveDef.png.*

A function $f$ is [quasiconcave](wikipedia://en/5781226) if the upper contour sets of the function $S(a)=\{x: f(x)\geq a\}$ are convex sets.[^o5]

## Properties {#Properties}

*Image: cubic\_graph\_special\_points\_repeated.svg.* A cubic function is concave (left half) when its first derivative (red) is monotonically decreasing i.e. its second derivative (orange) is negative, and convex (right half) when its first derivative is monotonically increasing i.e. its second derivative is positive

### Functions of a single variable {#Functions_of_a_single_variable}

1. A [differentiable function](wikipedia://en/330206) $f$ is (strictly) concave on an [interval](wikipedia://en/49172) if and only if its [derivative](wikipedia://en/7921) function $f'$ is (strictly) [monotonically decreasing](https://en.wikipedia.org/wiki/Monotonically_decreasing) on that interval, that is, a concave function has a non-increasing (decreasing) [slope](wikipedia://en/29368).[^o9][^o10]
1. [Points](wikipedia://en/593693) where concavity changes (between concave and [convex](wikipedia://en/245568)) are [inflection points](wikipedia://en/379845).[^o11]
1. If $f$ is twice-[differentiable](wikipedia://en/330206), then $f$ is concave [if and only if](wikipedia://en/14922) $f''$ is [non-positive](https://en.wikipedia.org/wiki/Non-positive) (or, informally, if the "[acceleration](wikipedia://en/2443)" is non-positive). If $f''$ is [negative](https://en.wikipedia.org/wiki/Negative_numbers) then $f$ is strictly concave, but the converse is not true, as shown by $f(x) = -x^{4}$.
1. If $f$ is concave and differentiable, then it is bounded above by its first-order [Taylor approximation](https://en.wikipedia.org/wiki/Taylor_approximation):[^o5] $$f(y) \leq f(x) + f'(x)[y-x]$$
1. A [Lebesgue measurable function](https://en.wikipedia.org/wiki/Lebesgue_measurable_function) on an interval $\mathbf{C}$ is concave [if and only if](wikipedia://en/14922) it is midpoint concave, that is, for any $x$ and $y$ in $\mathbf{C}$ $$f\left( \frac{x+y}2 \right) \ge \frac{f(x) + f(y)}2$$
1. If a function $f$ is concave, and $f(0) \ge 0$, then $f$ is [subadditive](wikipedia://en/745789) on $[0,\infty)$. Proof:
   - Since $f$ is concave and $1 \ge t \ge 0$, letting $y = 0$ we have $$f(tx) = f(tx+(1-t)\cdot 0) \ge t f(x)+(1-t)f(0) \ge t f(x) .$$
   - For $a,b\in[0,\infty)$: $$f(a) + f(b) = f \left((a+b) \frac{a}{a+b} \right) + f \left((a+b) \frac{b}{a+b} \right) \ge \frac{a}{a+b} f(a+b) + \frac{b}{a+b} f(a+b) = f(a+b)$$

### Functions of *n* variables {#Functions_of_n_variables}

1. A function $f$ is concave over a convex set [if and only if](wikipedia://en/14922) the function $-f$ is a [convex function](wikipedia://en/245568) over the set.
1. The sum of two concave functions is itself concave and so is the [pointwise minimum](https://en.wikipedia.org/wiki/Pointwise_minimum) of two concave functions, i.e. the set of concave functions on a given domain form a [semifield](wikipedia://en/10417428).
1. Near a strict [local maximum](https://en.wikipedia.org/wiki/Local_maximum) in the interior of the domain of a function, the function must be concave; as a partial converse, if the derivative of a strictly concave function is zero at some point, then that point is a local maximum.
1. Any [local maximum](https://en.wikipedia.org/wiki/Local_maximum) of a concave function is also a [global maximum](https://en.wikipedia.org/wiki/Global_maximum). A *strictly* concave function will have at most one global maximum.

## Examples {#Examples}

- The functions $f(x)=-x^2$ and $g(x)=\sqrt{x}$ are concave on their domains, as their second derivatives $f''(x) = -2$ and $g''(x) =-\frac{1}{4 x^{3/2}}$ are always negative.
- The [logarithm](wikipedia://en/17860) function $f(x) = \log{x}$ is concave on its domain $(0,\infty)$, as its derivative $\frac{1}{x}$ is a strictly decreasing function.
- Any [affine function](https://en.wikipedia.org/wiki/Affine_function) $f(x)=ax+b$ is both concave and convex, but neither strictly-concave nor strictly-convex.
- The [sine](https://en.wikipedia.org/wiki/Sine) function is concave on the interval $[0, \pi]$.
- The function $f(B) = \log |B|$, where $|B|$ is the [determinant](wikipedia://en/8468) of a [nonnegative-definite matrix](https://en.wikipedia.org/wiki/Nonnegative-definite_matrix) *B*, is concave.[^o15]

::: {#o17 .application cue=heading name="Applications"}

## Applications {#Applications}

- Rays bending in the [computation of radiowave attenuation in the atmosphere](https://en.wikipedia.org/wiki/Computation_of_radiowave_attenuation_in_the_atmosphere) involve concave functions.
- In [expected utility](https://en.wikipedia.org/wiki/Expected_utility) theory for [choice under uncertainty](https://en.wikipedia.org/wiki/Choice_under_uncertainty), [cardinal utility](https://en.wikipedia.org/wiki/Cardinal_utility) functions of [risk averse](wikipedia://en/177700) decision makers are concave.
- In [microeconomic theory](https://en.wikipedia.org/wiki/Microeconomic_theory), [production functions](https://en.wikipedia.org/wiki/Production_function) are usually assumed to be concave over some or all of their domains, resulting in [diminishing returns](https://en.wikipedia.org/wiki/Diminishing_returns) to input factors.[^o18]
- In [thermodynamics](wikipedia://en/29952) and [information theory](wikipedia://en/14773), [entropy](wikipedia://en/15445) is a concave function. In the case of thermodynamic entropy, without phase transition, entropy as a function of extensive variables is strictly concave. If the system can undergo phase transition, and if it is allowed to split into two subsystems of different phase ([phase separation](https://en.wikipedia.org/wiki/Phase_separation), e.g. boiling), the entropy-maximal parameters of the subsystems will result in a combined entropy precisely on the straight line between the two phases. This means that the "effective entropy" of a system with phase transition is the [convex envelope](https://en.wikipedia.org/wiki/Convex_envelope) of entropy without phase separation; therefore, the entropy of a system including phase separation will be non-strictly concave.[^o19]
