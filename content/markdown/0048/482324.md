# S-1 block cipher

::: {#o1 .subject cue=lead name="S-1 block cipher"}

In [cryptography](wikipedia://en/18934432), the **S-1 block cipher** was a [block cipher](wikipedia://en/4594) posted in [source code](https://en.wikipedia.org/wiki/Source_code) form on [Usenet](https://en.wikipedia.org/wiki/Usenet) on 11 August 1995.[^o2] Although incorrect security markings immediately indicated a [hoax](https://en.wikipedia.org/wiki/Hoax), there were several features of the code which suggested it might be leaked source code for the [Skipjack](wikipedia://en/474702) cipher, which was still [classified](https://en.wikipedia.org/wiki/Classified_information) at the time.

:::

However once [David Wagner](wikipedia://en/298253) had discovered a severe[^o3] [design flaw](https://en.wikipedia.org/wiki/Product_defect), involving the [key schedule](wikipedia://en/609603) but not the underlying round function, it was generally accepted as being a hoax—but one with an astonishing amount of work behind it. [Bruce Schneier](wikipedia://en/36732) noted that S-1 contained a feature never seen before in the open literature; a G-table that results in key and data dependent rotation of S-boxes to use in a given round.[^o4] When Skipjack was eventually declassified in 1998, it was indeed found to be totally unlike S-1.
