# Branch point

::: {#o1 .subject cue=lead name="Branch point"}

In the [mathematical](wikipedia://en/18831) field of [complex analysis](wikipedia://en/5759), a **branch point** of a [multivalued function](wikipedia://en/222367) is a point such that if the function is $n$-valued (has $n$ values) at that point, all of its neighborhoods contain a point that has more than $n$ values.[^o2] Multi-valued functions are rigorously studied using [Riemann surfaces](wikipedia://en/173181), and the formal definition of branch points employs this concept.

:::

Branch points fall into three broad categories: algebraic branch points, transcendental branch points, and logarithmic branch points. Algebraic branch points most commonly arise from functions in which there is an ambiguity in the extraction of a root, such as solving the equation $w^2=z$ for $w$ as a function of $z$. Here the branch point is the origin, because the [analytic continuation](wikipedia://en/80842) of any solution around a closed loop containing the origin will result in a different function: there is non-trivial [monodromy](wikipedia://en/251250). Despite the algebraic branch point, the function $w$ is well-defined as a multiple-valued function and, in an appropriate sense, is continuous at the origin. This is in contrast to transcendental and logarithmic branch points, that is, points at which a multiple-valued function has nontrivial [monodromy](wikipedia://en/251250) and an [essential singularity](wikipedia://en/80862). In [geometric function theory](wikipedia://en/5458932), unqualified use of the term *branch point* typically means the former more restrictive kind: the algebraic branch points.[^o3] In other areas of complex analysis, the unqualified term may also refer to the more general branch points of transcendental type.

## Algebraic branch points {#Algebraic_branch_points}

Let $\Omega$ be a connected [open set](wikipedia://en/39358) in the [complex plane](wikipedia://en/217628) $\mathbb{C}$ and $f:\Omega\to\mathbb{C}$ a [holomorphic function](wikipedia://en/14110). If $f$ is not constant, then the set of the [critical points](wikipedia://en/1951424) of $f$, that is, the zeros of the derivative $f'(z)$, has no [limit point](https://en.wikipedia.org/wiki/Limit_point) in $\Omega$. So each critical point $z_0$ of $f$ lies at the center of a disc $B(z_0,r)$ containing no other critical point of $f$ in its closure.

Let $\gamma$ be the boundary of $B(z_0,r)$, taken with its positive orientation. The [winding number](wikipedia://en/86113) of $f(\gamma)$ with respect to the point $f(z_0)$ is a positive integer called the **[ramification](wikipedia://en/384644) index** of $z_0$. If $z_0$ is a critical point of an analytic function, then its ramification index is greater than 1, so $z_0$ is also called a **ramification point** of $f$, and the corresponding [critical value](https://en.wikipedia.org/wiki/Critical_value_%28critical_point%29) $f(z_0)$ is called an (algebraic) **branch point**. Equivalently, $z_0$ is a ramification point if there exists a holomorphic function $\phi$ defined in a neighborhood of $z_0$ such that $f(z) = \phi(z)(z-z_0)^k + f(z_0)$ for integer $k>1$. This is always true if $z_0$ is a critical point of an analytic function.

Typically, one is not interested in $f$ itself, but in its [inverse function](wikipedia://en/14907). However, the inverse of a holomorphic function in the neighborhood of a ramification point does not properly exist, and so one is forced to define it in a multiple-valued sense as a [global analytic function](wikipedia://en/17211428). It is common to [abuse language](https://en.wikipedia.org/wiki/Abuse_of_terminology) and refer to a branch point $w_0 = f(z_0)$ of $f$ as a branch point of the global analytic function $f^{-1}$. More general definitions of branch points are possible for other kinds of multiple-valued global analytic functions, such as those that are defined [implicitly](wikipedia://en/250896). A unifying framework for dealing with such examples is supplied in the language of [Riemann surfaces](wikipedia://en/173181) below. In particular, in this more general picture, [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) of order greater than 1 can also be considered ramification points.

In terms of the inverse global analytic function $f^{-1}$, branch points are those points around which there is nontrivial monodromy. For example, the function $f(z) = z^2$ has a ramification point at $z_0 = 0$. The inverse function is the square root $f^{-1}(w) = w^{1/2}$, which has a branch point at $w_0 = 0$. Indeed, going around the closed loop $w = e^{i\theta}$, one starts at $\theta = 0$ and $e^{i0/2} = 1$. But after going around the loop to $\theta = 2\pi$, one has $e^{2\pi i/2} = -1$. Thus there is monodromy around this loop enclosing the origin.

## Transcendental and logarithmic branch points {#Transcendental_and_logarithmic_branch_points}

Suppose that *g* is a global analytic function defined on a [punctured disc](wikipedia://en/356158) around *z*<sub>0</sub>. Then *g* has a **transcendental branch point** if *z*<sub>0</sub> is an [essential singularity](wikipedia://en/80862) of *g* such that [analytic continuation](wikipedia://en/80842) of a function element once around some simple closed curve surrounding the point *z*<sub>0</sub> produces a different function element.[^o7]

An example of a transcendental branch point is the origin for the multi-valued function

$$g(z) = \exp \left( z^{-1/k}\right)\,$$

for some integer *k* > 1. Here the [monodromy](wikipedia://en/251250) group for a circuit around the origin is finite. Analytic continuation around *k* full circuits brings the function back to the original.

If the monodromy group is infinite, that is, it is impossible to return to the original function element by analytic continuation along a curve with nonzero winding number about *z*<sub>0</sub>, then the point *z*<sub>0</sub> is called a **logarithmic branch point**.[^o8] This is so called because the typical example of this phenomenon is the branch point of the [complex logarithm](wikipedia://en/4870290) at the origin. Going once counterclockwise around a simple closed curve encircling the origin, the complex logarithm is incremented by 2$\pi$*i*. Encircling a loop with winding number *w*, the logarithm is incremented by 2$\pi$*i w* and the monodromy group is the infinite [cyclic group](wikipedia://en/52327) $\mathbb{Z}$.

Logarithmic branch points are special cases of transcendental branch points.

There is no corresponding notion of ramification for transcendental and logarithmic branch points since the associated covering Riemann surface cannot be analytically continued to a cover of the branch point itself. Such covers are therefore always unramified.

## Examples {#Examples}

- 0 is a branch point of the [square root](wikipedia://en/29208) function. Suppose *w* = *z*<sup>1/2</sup>, and *z* starts at 4 and moves along a [circle](wikipedia://en/6220) of [radius](wikipedia://en/1780815) 4 in the [complex plane](wikipedia://en/217628) centered at 0. The dependent variable *w* changes while depending on *z* in a continuous manner. When *z* has made one full circle, going from 4 back to 4 again, *w* will have made one half-circle, going from the positive square root of 4, i.e., from 2, to the negative square root of 4, i.e., −2.
- 0 is also a branch point of the [natural logarithm](wikipedia://en/21476). Since *e*<sup>0</sup> is the same as *e*<sup>2$\pi$*i*</sup>, both 0 and 2$\pi$*i* are among the multiple values of ln(1). As *z* moves along a circle of radius 1 centered at 0, *w* = ln(*z*) goes from 0 to 2$\pi$*i*.
- In [trigonometry](wikipedia://en/18717261), since tan($\pi$/4) and tan (5$\pi$/4) are both equal to 1, the two numbers $\pi$/4 and 5$\pi$/4 are among the multiple values of arctan(1). The imaginary units *i* and −*i* are branch points of the arctangent function arctan(*z*) = (1/2*i*)log\[(*i* − *z*)/(*i* + *z*)\]. This may be seen by observing that the derivative (*d*/*dz*) arctan(*z*) = 1/(1 + *z*<sup>2</sup>) has simple [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) at those two points, since the denominator is zero at those points.
- If the derivative *ƒ* ' of a function *ƒ* has a simple [pole](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) at a point *a*, then *ƒ* has a logarithmic branch point at *a*. The converse is not true, since the function *ƒ*(*z*) = *z*<sup>α</sup> for irrational α has a logarithmic branch point, and its derivative is singular without being a pole.

## Branch cuts {#Branch_cuts}

Roughly speaking, branch points are the points where the various sheets of a multivalued function come together. The branches of the function are the various sheets of the function. For example, the function *w* = *z*<sup>1/2</sup> has two branches: one where the square root comes in with a plus sign, and the other with a minus sign. A **branch cut** is a curve in the complex plane such that it is possible to define a single analytic branch of a multi-valued function on the plane minus that curve. Branch cuts are usually, but not always, taken between pairs of branch points.

Branch cuts allow one to work with a collection of single-valued functions, "glued" together along the branch cut instead of a multivalued function. For example, to make the function

$$F(z) = \sqrt{z} \sqrt{1-z}\,$$

single-valued, one makes a branch cut along the interval \[0, 1\] on the real axis, connecting the two branch points of the function. The same idea can be applied to the function $\sqrt{z}$; but in that case one has to perceive that the *point at infinity* is the appropriate 'other' branch point to connect to from 0, for example along the whole negative real axis.

The branch cut device may appear arbitrary (and it is); but it is very useful, for example in the theory of [special functions](wikipedia://en/23709110). An invariant explanation of the branch phenomenon is developed in [Riemann surface](wikipedia://en/173181) theory (of which it is historically the origin), and more generally in the ramification and [monodromy](wikipedia://en/251250) theory of [algebraic functions](wikipedia://en/974169) and [differential equations](wikipedia://en/1424309).

### Complex logarithm {#Complex_logarithm}

*Image: Riemann surface log.svg.* A plot of the multi-valued imaginary part of the complex logarithm function, which shows the branches. As a complex number *z* goes around the origin, the imaginary part of the logarithm goes up or down. This makes the origin a *branch point* of the function.

The typical example of a branch cut is the complex logarithm. If a [complex number](wikipedia://en/5826) is represented in polar form *z* = *r*e<sup>i*θ*</sup>, then the logarithm of *z* is

$$\ln z = \ln r + i\theta.\,$$

However, there is an obvious ambiguity in defining the angle *θ*: adding to *θ* any integer multiple of 2$\pi$ will yield another possible angle. A branch of the logarithm is a [continuous function](wikipedia://en/6122) *L*(*z*) giving a logarithm of *z* for all *z* in a connected open set in the complex plane. In particular, a branch of the logarithm exists in the complement of any ray from the origin to infinity: a *branch cut*. A common choice of branch cut is the negative real axis, although the choice is largely a matter of convenience.

The logarithm has a jump discontinuity of 2$\pi$i when crossing the branch cut. The logarithm can be made continuous by gluing together [countably](wikipedia://en/6026) many copies, called *sheets*, of the complex plane along the branch cut. On each sheet, the value of the log differs from its principal value by a multiple of 2$\pi$i. These surfaces are glued to each other along the branch cut in the unique way to make the logarithm continuous. Each time the variable goes around the origin, the logarithm moves to a different branch.

### Continuum of poles {#Continuum_of_poles}

One reason that branch cuts are common features of complex analysis is that a branch cut can be thought of as a sum of infinitely many poles arranged along a line in the complex plane with [infinitesimal](wikipedia://en/160990) residues. For example,

$$f_a(z) = {1\over z-a}$$

is a function with a simple pole at *z* = *a*. Integrating over the location of the pole:

$$u(z) = \int_{a=-1}^{a=1} f_a(z) \,da = \int_{a=-1}^{a=1} {1\over z-a} \,da = \log \left({z+1\over z-1}\right)$$

defines a function *u*(*z*) with a cut from −1 to 1. The branch cut can be moved around, since the integration line can be shifted without altering the value of the integral so long as the line does not pass across the point *z*.

## Riemann surfaces {#Riemann_surfaces}

The concept of a branch point is defined for a holomorphic function ƒ:*X* → *Y* from a compact connected [Riemann surface](wikipedia://en/173181) *X* to a compact Riemann surface *Y* (usually the [Riemann sphere](wikipedia://en/30876799)). Unless it is constant, the function ƒ will be a [covering map](wikipedia://en/250323) onto its image at all but a finite number of points. The points of *X* where ƒ fails to be a cover are the ramification points of ƒ, and the image of a ramification point under ƒ is called a branch point.

For any point *P* ∈ *X* and *Q* = ƒ(*P*) ∈ *Y*, there are holomorphic [local coordinates](wikipedia://en/304139) *z* for *X* near *P* and *w* for *Y* near *Q* in terms of which the function ƒ(*z*) is given by

$$w = z^k$$

for some integer *k*. This integer is called the ramification index of *P*. Usually the ramification index is one. But if the ramification index is not equal to one, then *P* is by definition a ramification point, and *Q* is a branch point.

If *Y* is just the Riemann sphere, and *Q* is in the finite part of *Y*, then there is no need to select special coordinates. The ramification index can be calculated explicitly from [Cauchy's integral formula](wikipedia://en/72827). Let γ be a simple rectifiable loop in *X* around *P*. The ramification index of ƒ at *P* is

$$e_P = \frac{1}{2\pi i}\int_\gamma \frac{f'(z)}{f(z)-f(P)}\,dz.$$

This integral is the number of times ƒ(γ) winds around the point *Q*. As above, *P* is a ramification point and *Q* is a branch point if *e*<sub>*P*</sub> > 1.

## Algebraic geometry {#Algebraic_geometry}

In the context of [algebraic geometry](wikipedia://en/1997), the notion of branch points can be generalized to mappings between arbitrary [algebraic curves](wikipedia://en/253260). Let ƒ:*X* → *Y* be a morphism of algebraic curves. By pulling back rational functions on *Y* to rational functions on *X*, *K*(*X*) is a [field extension](wikipedia://en/11634) of *K*(*Y*). The degree of ƒ is defined to be the degree of this field extension \[*K*(*X*):*K*(*Y*)\], and ƒ is said to be finite if the degree is finite.

Assume that ƒ is finite. For a point *P* ∈ *X*, the ramification index *e*<sub>*P*</sub> is defined as follows. Let *Q* = ƒ(*P*) and let *t* be a [local uniformizing parameter](wikipedia://en/21309351) at *P*; that is, *t* is a regular function defined in a neighborhood of *Q* with *t*(*Q*) = 0 whose differential is nonzero. Pulling back *t* by ƒ defines a regular function on *X*. Then

$$e_P = v_P(t\circ f)$$

where *v*<sub>*P*</sub> is the [valuation](wikipedia://en/966856) in the [local ring](wikipedia://en/153391) of regular functions at *P*. That is, *e*<sub>*P*</sub> is the order to which $t\circ f$ vanishes at *P*. If *e*<sub>*P*</sub> > 1, then ƒ is said to be ramified at *P*. In that case, *Q* is called a branch point.
