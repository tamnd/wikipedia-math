# Keith number

::: {#o1 .subject cue=lead name="Keith number"}

In [recreational mathematics](wikipedia://en/26446), a **Keith number** or **repfigit number** (short for **rep**etitive [**F**ibonacci-like](wikipedia://en/10918) d**igit**) is a [natural number](wikipedia://en/21474) $n$ in a given [number base](https://en.wikipedia.org/wiki/Number_base) $b$ with $k$ digits such that when a sequence is created such that the first $k$ terms are the $k$ digits of $n$ and each subsequent term is the sum of the previous $k$ terms, $n$ is part of the sequence. Keith numbers were introduced by [Mike Keith](wikipedia://en/5286832) in 1987.[^o2] They are computationally very challenging to find, with only about 125 known.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $n$ be a natural number, let $k = \lfloor \log_{b}{n} \rfloor + 1$ be the number of digits of $n$ in base $b$, and let

$$d_i = \frac{n \bmod b^{i + 1} - n \bmod b^{i}}{b^{i}}$$

be the value of each digit of $n$.

We define the sequence $S(i)$ by a [linear recurrence relation](https://en.wikipedia.org/wiki/Linear_recurrence_relation). For $0 \leq i < k$,

$$S(i) = d_{k - i - 1}$$

and for $i \geq k$

$$S(i) = \sum_{j = 0}^{k} S(i - k + j)$$

If there exists an $i$ such that $S(i) = n$, then $n$ is said to be a **Keith number**.

For example, 88 is a Keith number in [base 6](https://en.wikipedia.org/wiki/Base_6), as

$$S(0) = d_{3 - 0 - 1} = d_2 = \frac{88 \bmod 6^{2 + 1} - 88 \bmod 6^{2}}{6^{2}} = \frac{88 \bmod 216 - 88 \bmod 36}{36} = \frac{88 - 16}{36} = \frac{72}{36} = 2$$

$$S(1) = d_{3 - 1 - 1} = d_1 = \frac{88 \bmod 6^{1 + 1} - 88 \bmod 6^{1}}{6^{1}} = \frac{88 \bmod 36 - 88 \bmod 6}{6} = \frac{16 - 4}{6} = \frac{12}{6} = 2$$

$$S(2) = d_{3 - 2 - 1} = d_0 = \frac{88 \bmod 6^{0 + 1} - 88 \bmod 6^{0}}{6^{0}} = \frac{88 \bmod 6 - 88 \bmod 1}{1} = \frac{4 - 0}{1} = \frac{4}{1} = 4$$

and the entire sequence

$$S(i) = \{2, 2, 4, 8, 14, 26, 48, 88, 162, \ldots\}$$

and $S(7) = 88$.

### Finding Keith numbers {#Finding_Keith_numbers}

Whether or not there are infinitely many Keith numbers in a particular base $b$ is currently a matter of speculation. Keith numbers are rare and hard to find. They can be found by exhaustive search, and no more efficient algorithm is known.[^o6] According to Keith, in [base 10](https://en.wikipedia.org/wiki/Base_10), on average $\textstyle\frac{9}{10}\log_2{10}\approx 2.99$ Keith numbers are expected between successive [powers of 10](wikipedia://en/1161104).[^o7] Known results seem to support this.

## Keith clusters {#Keith_clusters}

A Keith cluster is a related set of Keith numbers such that one is a multiple of another. For example, in [base 10](https://en.wikipedia.org/wiki/Base_10), $\{14, 28\}$, $\{1104, 2208\}$, and $\{31331, 62662, 93993\}$ are all Keith clusters. These are possibly the only three examples of a Keith cluster in [base 10](https://en.wikipedia.org/wiki/Base_10).[^o13]

## Programming example {#Programming_example}

The example below implements the sequence defined above in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) to determine if a number in a particular base is a Keith number:

```python
def is_repfigit(x: int, b: int) -> bool:
    """Determine if a number in a particular base is a Keith number."""
    if x == 0:
        return True

    sequence = []
    y = x

    while y > 0:
        sequence.append(y % b)
        y = y // b

    digit_count = len(sequence)
    sequence.reverse()

    while sequence[len(sequence) - 1] < x:
        n = 0
        for i in range(0, digit_count):
            n = n + sequence[len(sequence) - digit_count + i]
        sequence.append(n)

    return sequence[len(sequence) - 1] == x
```
