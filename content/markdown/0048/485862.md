# Primitive ring

::: {#o1 .subject cue=lead name="Primitive ring"}

In the branch of [abstract algebra](wikipedia://en/19616384) known as [ring theory](wikipedia://en/250424), a **left primitive ring** is a [ring](wikipedia://en/48404) which has a [faithful](https://en.wikipedia.org/wiki/Faithful_module) [simple](wikipedia://en/29430) left [module](wikipedia://en/276410). Well known examples include [endomorphism rings](wikipedia://en/59623) of [vector spaces](https://en.wikipedia.org/wiki/Vector_spaces) and [Weyl algebras](wikipedia://en/491095) over [fields](wikipedia://en/10603) of [characteristic](wikipedia://en/1066621) zero.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A ring *R* is said to be a **left primitive ring** if it has a [faithful](https://en.wikipedia.org/wiki/Faithful_module) [simple](wikipedia://en/29430) left [*R*-module](wikipedia://en/276410). A **right primitive ring** is defined similarly with right *R*-modules. There are rings which are primitive on one side but not on the other. The first example was constructed by [George M. Bergman](wikipedia://en/41052556) in (Bergman 1964). Another example found by Jategaonkar showing the distinction can be found in (Rowen 1988, 159).

An internal characterization of left primitive rings is as follows: a ring is left primitive if and only if there is a [maximal left ideal](wikipedia://en/48164) containing no nonzero two-sided [ideals](wikipedia://en/25977). The analogous definition for right primitive rings is also valid.

The structure of left primitive rings is completely determined by the [Jacobson density theorem](wikipedia://en/488391): A ring is left primitive if and only if it is [isomorphic](wikipedia://en/26411) to a [dense](wikipedia://en/488391#Topological_characterization) [subring](wikipedia://en/24873145) of the [ring of endomorphisms](https://en.wikipedia.org/wiki/Ring_of_endomorphisms) of a [left vector space](wikipedia://en/9067#Relation_to_fields_and_linear_algebra) over a [division ring](wikipedia://en/9067).

Another equivalent definition states that a ring is left primitive if and only if it is a [prime ring](wikipedia://en/487540) with a faithful left module of [finite length](wikipedia://en/816070) ((Lam 2001), [Ex. 11.19, p. 191](https://books.google.com/books?id=2T5DAAAAQBAJ&pg=PA191)).

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

One-sided primitive rings are both [semiprimitive rings](wikipedia://en/485855) and [prime rings](wikipedia://en/487540). Since the [product ring](https://en.wikipedia.org/wiki/Product_ring) of two or more nonzero rings is not prime, it is clear that the product of primitive rings is never primitive.

For a left [Artinian ring](wikipedia://en/489273), it is known that the conditions "left primitive", "right primitive", "prime", and "[simple](wikipedia://en/443387)" are all equivalent, and in this case it is a [semisimple ring](https://en.wikipedia.org/wiki/Semisimple_ring) isomorphic to a square [matrix ring](wikipedia://en/487541) over a division ring. More generally, in any ring with a minimal one sided ideal, "left primitive" = "right primitive" = "prime".

A [commutative ring](wikipedia://en/61346) is left primitive if and only if it is a [field](wikipedia://en/10603).

Being left primitive is a [Morita invariant property](wikipedia://en/3296134).

:::

## Examples {#Examples}

Every [simple ring](wikipedia://en/443387) *R* with unity is both left and right primitive. (However, a simple non-unital ring may not be primitive.) This follows from the fact that [*R* has a maximal left ideal](wikipedia://en/48164#Properties) *M*, and the fact that the [quotient module](wikipedia://en/364820) *R*/*M* is a simple left *R*-module, and that its [annihilator](wikipedia://en/328684) is a proper two-sided ideal in *R*. Since *R* is a simple ring, this annihilator is {0} and therefore *R*/*M* is a faithful left *R*-module.

[Weyl algebras](wikipedia://en/491095) over fields of [characteristic](wikipedia://en/1066621) zero are primitive, and since they are [domains](wikipedia://en/487627), they are examples without minimal one-sided ideals.

::: {#o12 .pointer-item cue=pointer name="Full linear ring"}

### Full linear rings {#Full_linear_rings}

A special case of primitive rings is that of *full linear rings*. A **left full linear ring** is the ring of *all* [linear transformations](https://en.wikipedia.org/wiki/Linear_transformation) of an infinite-dimensional left vector space over a division ring. (A **right full linear ring** differs by using a right vector space instead.) In symbols, $R=\mathrm{End}(_D V)$ where *V* is a vector space over a division ring *D*. It is known that *R* is a left full linear ring if and only if *R* is [von Neumann regular](https://en.wikipedia.org/wiki/Von_Neumann_regular), [left self-injective](wikipedia://en/473775#Self-injective_rings) with [socle](wikipedia://en/3571350) soc(<sub>*R*</sub>*R*) ≠ {0}.[^n1] Through [linear algebra](wikipedia://en/18422) arguments, it can be shown that $\mathrm{End}(_D V)\,$ is isomorphic to the ring of [row finite matrices](wikipedia://en/487541#Examples) $\mathbb{RFM}_I(D)\,$, where *I* is an index set whose size is the dimension of *V* over *D*. Likewise right full linear rings can be realized as column finite matrices over *D*.

Using this we can see that there are non-simple left primitive rings. By the Jacobson Density characterization, a left full linear ring *R* is always left primitive. When dim<sub>*D*</sub>*V* is finite *R* is a square matrix ring over *D*, but when dim<sub>*D*</sub>*V* is infinite, the set of finite rank linear transformations is a proper two-sided ideal of *R*, and hence *R* is not simple.
