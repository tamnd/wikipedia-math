# Semiprimitive ring

::: {#o1 .subject cue=lead name="Semiprimitive ring"}

In [algebra](wikipedia://en/18716923), a **semiprimitive ring** or **Jacobson semisimple ring** or **J-semisimple ring** is a [ring](wikipedia://en/48404) whose [Jacobson radical](wikipedia://en/57656) is [zero](https://en.wikipedia.org/wiki/Zero_ideal). This is a type of ring more general than a [semisimple ring](https://en.wikipedia.org/wiki/Semisimple_ring), but where [simple modules](wikipedia://en/29430) still provide enough information about the ring. Rings such as the ring of [integers](wikipedia://en/14563#Algebraic_properties) are semiprimitive, and an [artinian](wikipedia://en/489273) semiprimitive ring is just a [semisimple ring](https://en.wikipedia.org/wiki/Semisimple_ring). Semiprimitive rings can be understood as (possibly infinite) [subdirect products](wikipedia://en/17395221) of [primitive rings](wikipedia://en/485862), which are described by the [Jacobson density theorem](wikipedia://en/488391).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A ring is called **semiprimitive** or **Jacobson semisimple** if its Jacobson radical is the zero [ideal](wikipedia://en/25977).

A ring is semiprimitive if and only if it has a [faithful](https://en.wikipedia.org/wiki/Faithful_module) [semisimple left module](wikipedia://en/1001361). The semiprimitive property is left-right symmetric, and so a ring is semiprimitive if and only if it has a faithful semisimple right module.

A ring is semiprimitive if and only if it is a subdirect product of left primitive rings.

A [commutative ring](wikipedia://en/61346) is semiprimitive if and only if it is a subdirect product of [fields](wikipedia://en/10603), (Lam 1995, 137).

A left [artinian ring](wikipedia://en/489273) is semiprimitive if and only if it is [semisimple](https://en.wikipedia.org/wiki/Semisimple_ring), (Lam 2001, 54). Such rings are sometimes called [semisimple Artinian](https://en.wikipedia.org/wiki/Semisimple_Artinian), (Kelarev 2002, 13).

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- The ring of integers is semiprimitive, but not semisimple.
- Every primitive ring is semiprimitive.
- The [product](https://en.wikipedia.org/wiki/Product_ring) of two fields is semiprimitive but not primitive.
- Every [von Neumann regular ring](wikipedia://en/907524) is semiprimitive.

[Jacobson](https://en.wikipedia.org/wiki/Nathan_Jacobson) himself has defined a ring to be "semisimple" if and only if it is a subdirect product of [simple rings](wikipedia://en/443387), (Jacobson 1989, 203). However, this is a stricter notion, since the [endomorphism ring](wikipedia://en/59623) of a [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) [dimensional](wikipedia://en/38267) [vector space](wikipedia://en/32370) is semiprimitive, but not a subdirect product of simple rings, (Lam 1995, 42).
