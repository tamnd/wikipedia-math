# Linear graph grammar

::: {#o1 .subject cue=lead name="Linear graph grammar"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), a **linear graph grammar** (also a **connection graph reduction system** or a **port graph grammar**[^o2]) is a class of [graph grammar](https://en.wikipedia.org/wiki/Graph_grammar) on which nodes have a number of ports connected together by edges and edges connect exactly two ports together. [Interaction nets](https://en.wikipedia.org/wiki/Interaction_net) are a special subclass of linear graph grammars in which [rewriting](wikipedia://en/415847) is [confluent](wikipedia://en/3755377).

:::

::: {#o4 .definition kind=definition/construction cue=heading name="Implementations"}

## Implementations {#Implementations}

Bawden introduces linear graphs in the context of a compiler for a fragment of the [Scheme programming language](https://en.wikipedia.org/wiki/Scheme_programming_language).[^o5] Bawden and Mairson (1998) describe the design of a distributed implementation in which the linear graph is spread across many computing nodes and may freely migrate in order to make rewrites possible.

:::
