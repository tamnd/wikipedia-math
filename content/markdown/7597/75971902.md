# Datasaurus dozen

::: {#o1 .subject cue=lead name="Datasaurus dozen"}

The **Datasaurus dozen** comprises [thirteen](https://en.wikipedia.org/wiki/Baker's_dozen) [data sets](wikipedia://en/8495) that have nearly identical simple [descriptive statistics](wikipedia://en/8187) to two decimal places, yet have very different [distributions](wikipedia://en/23543) and appear very different when [graphed](wikipedia://en/19774918).[^o2] It was inspired by the smaller [Anscombe's quartet](wikipedia://en/10019241) that was created in 1973.

:::

The thirteen data sets were labeled as the following:

- away
- bullseye
- circle
- dino
- dots
- h\_lines
- high\_lines
- slant\_down
- slant\_up
- star
- v\_line
- wide\_lines
- x\_shape

Similar to [Anscombe's quartet](wikipedia://en/10019241), the Datasaurus dozen was designed to further illustrate the importance of looking at a set of data graphically before starting to analyze according to a particular type of relationship, and the inadequacy of basic statistic properties for describing realistic data sets.[^o10][^o11][^o12][^o13][^o2][^o14]

## Creation {#Creation}

*Image: Datasaurus.png.* The dinosaur data set created by [Alberto Cairo](https://en.wikipedia.org/wiki/Alberto_Cairo) that inspired the creation of the Datasaurus Dozen

The first data set, in the shape of a [Tyrannosaurus](https://en.wikipedia.org/wiki/Tyrannosaurus), that inspired the rest of the "datasaurus" data set was constructed in 2016 by [Alberto Cairo](https://en.wikipedia.org/wiki/Alberto_Cairo).[^o16][^o17] It was proposed by Maarten Lambrechts that this data set also be called "Anscombosaurus".[^o16]

This data set was then accompanied by twelve other data sets that were created by Justin Matejka and George Fitzmaurice at [Autodesk](https://en.wikipedia.org/wiki/Autodesk). Unlike Anscombe's quartet, where it is not known how the data set was generated,[^o18] the authors used [simulated annealing](wikipedia://en/172244) to make these data sets. They made small, random, and biased changes to each point towards the desired shape. Each shape took 200,000 iterations of perturbations to complete.[^o2]

The [pseudocode](https://en.wikipedia.org/wiki/Pseudocode) for this algorithm is as follows:

```text
current_ds ← initial_ds
for x iterations, do:
    test_ds ← perturb(current_ds, temp)
    if similar_enough(test_ds, initial_ds):
        current_ds ← test_ds

function perturb(ds, temp):
    loop:
        test ← move_random_points(ds)
        if fit(test) > fit(ds) or temp > random():
            return test
```

where

- `initial_ds` is the seed data set
- `current_ds` is the latest version of the data set
- `fit()` is a function used to check whether moving the points gets closer to the desired shape
- `temp` is the temperature of the simulated annealing algorithm
- `similar_enough()` is a function that checks whether the statistics for the two given data sets are similar enough
- `move_random_points()` is a function that randomly moves data points
