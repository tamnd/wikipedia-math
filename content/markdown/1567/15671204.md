# Grubbs's test

::: {#o1 .subject cue=lead name="Grubbs's test"}

In statistics, **Grubbs's test** or the **Grubbs test** (named after [Frank E. Grubbs](wikipedia://en/60047778), who published the test in 1950[^o2]), also known as the **maximum normalized [residual](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) test** or **extreme studentized deviate test**, is a [test](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing) used to detect [outliers](wikipedia://en/160951) in a [univariate](wikipedia://en/2398982) [data set](wikipedia://en/8495) assumed to come from a [normally distributed](wikipedia://en/21462) population.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Grubbs's test is based on the assumption of [normality](wikipedia://en/21462). That is, one should first verify that the data can be reasonably approximated by a normal distribution before applying the Grubbs test.[^o5]

Grubbs's test detects one outlier at a time. This outlier is expunged from the dataset and the test is iterated until no outliers are detected. However, multiple iterations change the probabilities of detection, and the test should not be used for sample sizes of six or fewer since it frequently tags most of the points as outliers.[^o6]

Grubbs's test is defined for the following [hypotheses](https://en.wikipedia.org/wiki/Statistical_hypothesis):

H<sub>0</sub>: There are no outliers in the data set

H<sub>a</sub>: There is exactly one outlier in the data set

The Grubbs [test statistic](wikipedia://en/1416975) is defined as

$$G = \frac{\displaystyle\max_{i=1,\ldots, n}\left \vert Y_i - \bar{Y}\right\vert}{s}$$

with n, $\overline{Y}$, and $s$ denoting the number of measurements in the sample, [sample mean](https://en.wikipedia.org/wiki/Sample_mean), and [standard deviation](wikipedia://en/27590), respectively. The Grubbs test statistic is the largest [absolute deviation](wikipedia://en/9252911) from the sample mean in units of the sample standard deviation.

This is the [two-sided test](https://en.wikipedia.org/wiki/Two-sided_test), for which the hypothesis of no outliers is rejected at [significance level](https://en.wikipedia.org/wiki/Significance_level) α if

$$G > \frac{n-1}{\sqrt{n}} \sqrt{\frac{t_{\alpha/(2n),n-2}^2}{n - 2 + t_{\alpha/(2n),n-2}^2}}$$

with *t*<sub>α/(2n),n−2</sub> denoting the upper [critical value](https://en.wikipedia.org/wiki/Critical_value_%28statistics%29) of the [t-distribution](wikipedia://en/105375) with *n* − 2 [degrees of freedom](wikipedia://en/2321606) and a significance level of α/(2*n*).

### One-sided case {#One-sided_case}

Grubbs's test can also be defined as a one-sided test, replacing α/(2*n*) with α/*n*. To test whether the minimum value is an outlier, the test statistic is

$$G = \frac{\bar{Y}-Y_\min}{s}$$

with *Y*<sub>min</sub> denoting the minimum value. To test whether the maximum value is an outlier, the test statistic is

$$G = \frac{Y_\max - \bar{Y}}{s}$$

with *Y*<sub>max</sub> denoting the maximum value.

:::

## Related techniques {#Related_techniques}

Several [graphical techniques](https://en.wikipedia.org/wiki/Graphical_technique) can be used to detect outliers. A simple [run sequence plot](https://en.wikipedia.org/wiki/Run_sequence_plot), a [box plot](wikipedia://en/160960), or a [histogram](wikipedia://en/13266) should show any obviously outlying points. A [normal probability plot](wikipedia://en/543119) may also be useful.
