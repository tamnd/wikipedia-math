# Exponential dispersion model

::: {#o1 .subject cue=lead name="Exponential dispersion model"}

In [probability](https://en.wikipedia.org/wiki/Theory_of_probability) and [statistics](wikipedia://en/26685), the class of **exponential dispersion models** (**EDM**), also called **exponential dispersion family** (**EDF**), is a set of [probability distributions](wikipedia://en/23543) that represents a generalisation of the [natural exponential family](wikipedia://en/9413032).[^o2][^o3][^o4] Exponential dispersion models play an important role in [statistical theory](wikipedia://en/27579), in particular in [generalized linear models](wikipedia://en/747122) because they have a special structure which enables deductions to be made about appropriate [statistical inference](wikipedia://en/27577).

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Univariate case {#Univariate_case}

There are two versions to formulate an exponential dispersion model.

#### Additive exponential dispersion model {#Additive_exponential_dispersion_model}

In the univariate case, a real-valued random variable $X$ belongs to the **additive exponential dispersion model** with canonical parameter $\theta$ and index parameter $\lambda$, $X \sim \mathrm{ED}^*(\theta, \lambda)$, if its [probability density function](wikipedia://en/43487) can be written as

$$f_X(x\mid\theta, \lambda) = h^*(\lambda,x) \exp\left(\theta x - \lambda A(\theta)\right) \,\! .$$

#### Reproductive exponential dispersion model {#Reproductive_exponential_dispersion_model}

The distribution of the transformed random variable $Y=\frac{X}{\lambda}$ is called **reproductive exponential dispersion model**, $Y \sim \mathrm{ED}(\mu, \sigma^2)$, and is given by

$$f_Y(y\mid\mu, \sigma^2) = h(\sigma^2,y) \exp\left(\frac{\theta y - A(\theta)}{\sigma^2}\right) \,\! ,$$

with $\sigma^2 = \frac{1}{\lambda}$ and $\mu = A'(\theta)$, implying $\theta = (A')^{-1}(\mu)$. The terminology *dispersion model* stems from interpreting $\sigma^2$ as *dispersion parameter*. For fixed parameter $\sigma^2$, the $\mathrm{ED}(\mu, \sigma^2)$ is a [natural exponential family](wikipedia://en/9413032).

### Multivariate case {#Multivariate_case}

In the multivariate case, the *n*-dimensional random variable $\mathbf{X}$ has a probability density function of the following form[^o2]

$$f_{\mathbf{X}}(\mathbf{x}|\boldsymbol{\theta}, \lambda) = h(\lambda,\mathbf{x}) \exp\left(\lambda(\boldsymbol\theta^\top \mathbf{x} - A(\boldsymbol\theta))\right) \,\!,$$

where the parameter $\boldsymbol\theta$ has the same dimension as $\mathbf{X}$.

:::

## Properties {#Properties}

### Cumulant-generating function {#Cumulant-generating_function}

The [cumulant-generating function](https://en.wikipedia.org/wiki/Cumulant-generating_function) of $Y\sim\mathrm{ED}(\mu,\sigma^2)$ is given by

$$K(t;\mu,\sigma^2) = \log\operatorname{E}[e^{tY}] = \frac{A(\theta+\sigma^2 t)-A(\theta)}{\sigma^2}\,\! ,$$

with $\theta = (A')^{-1}(\mu)$

### Mean and variance {#Mean_and_variance}

Mean and variance of $Y\sim\mathrm{ED}(\mu,\sigma^2)$ are given by

$$\operatorname{E}[Y]= \mu = A'(\theta) \,, \quad \operatorname{Var}[Y] = \sigma^2 A''(\theta) = \sigma^2 V(\mu)\,\! ,$$

with unit variance function $V(\mu) = A''((A')^{-1}(\mu))$.

### Reproductive {#Reproductive}

If $Y_1,\ldots, Y_n$ are [i.i.d.](https://en.wikipedia.org/wiki/I.i.d.) with $Y_i\sim\mathrm{ED}\left(\mu,\frac{\sigma^2}{w_i}\right)$, i.e. same mean $\mu$ and different weights $w_i$, the weighted mean is again an $\mathrm{ED}$ with

$$\sum_{i=1}^n \frac{w_i Y_i}{w_{\bullet}} \sim \mathrm{ED}\left(\mu, \frac{\sigma^2}{w_\bullet}\right) \,\! ,$$

with $w_\bullet = \sum_{i=1}^n w_i$. Therefore $Y_i$ are called *reproductive*.

### Unit deviance {#Unit_deviance}

The [probability density function](wikipedia://en/43487) of an $\mathrm{ED}(\mu, \sigma^2)$ can also be expressed in terms of the **unit [deviance](wikipedia://en/432609)** $d(y,\mu)$ as

$$f_Y(y\mid\mu, \sigma^2) = \tilde{h}(\sigma^2,y) \exp\left(-\frac{d(y,\mu)}{2\sigma^2}\right) \,\! ,$$

where the unit deviance takes the special form $d(y,\mu) = y f(\mu) + g(\mu) + h(y)$ or in terms of the unit variance function as $d(y,\mu) = 2 \int_\mu^y\! \frac{y-t}{V(t)} \,dt$.

:::

## Examples {#Examples}

Many very common probability distributions belong to the class of EDMs, among them are: [normal distribution](wikipedia://en/21462), [binomial distribution](wikipedia://en/3876), [Poisson distribution](wikipedia://en/23009144), [negative binomial distribution](wikipedia://en/45177), [gamma distribution](wikipedia://en/207079), [inverse Gaussian distribution](wikipedia://en/5246161), and [Tweedie distribution](wikipedia://en/15204099).

:::
