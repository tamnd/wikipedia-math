# Kurepa tree

::: {#o1 .subject cue=lead name="Kurepa tree"}

In [set theory](wikipedia://en/27553), a **Kurepa tree** is a [tree](wikipedia://en/704160) $(T, <)$ of height [$\omega_1$](wikipedia://en/20860540), each of whose levels is [countable](https://en.wikipedia.org/wiki/Countable), which has at least [$\aleph_2$](wikipedia://en/293961) many branches. This concept was introduced by (txt). The existence of a Kurepa tree (known as the **Kurepa hypothesis**, though Kurepa originally conjectured that such trees do not exist) is [consistent](https://en.wikipedia.org/wiki/Relative_consistency) with the axioms of [ZFC](https://en.wikipedia.org/wiki/ZFC): [Solovay](wikipedia://en/3160110) showed in unpublished work that there are Kurepa trees in [Gödel](wikipedia://en/16736)'s [constructible universe](wikipedia://en/343335) (Jech 1971). More precisely, the existence of Kurepa trees follows from the [diamond plus principle](wikipedia://en/691736), which holds in the constructible universe. On the other hand, (txt) showed that if a [strongly inaccessible cardinal](https://en.wikipedia.org/wiki/Strongly_inaccessible_cardinal) is [Lévy collapsed](wikipedia://en/15550368#Levy_collapsing) to $\omega_2$ then, in the resulting model, there are no Kurepa trees. The existence of an inaccessible cardinal is in fact equiconsistent with the failure of the Kurepa hypothesis, because if the Kurepa hypothesis is false then the cardinal ω<sub>2</sub> is inaccessible in the constructible universe.

:::

A Kurepa tree with fewer than $2^{\aleph_1}$ branches is known as a [Jech–Kunen tree](wikipedia://en/43031336).

More generally if $\kappa$ is an infinite cardinal, then a $\kappa$-Kurepa tree is a tree of height $\kappa$ with more than $\kappa$ branches but at most $|\alpha|$ elements of each infinite level $\alpha < \kappa$, and the Kurepa hypothesis for $\kappa$ is the statement that there is a $\kappa$-Kurepa tree. Sometimes the tree is also assumed to be binary. The existence of a binary $\kappa$-Kurepa tree is equivalent to the existence of a **Kurepa family**: a set of more than $\kappa$ subsets of $\kappa$ such that their intersections with any infinite [ordinal](wikipedia://en/26547932) $\alpha < \kappa$ form a set of cardinality at most $\alpha$. The Kurepa hypothesis is false if $\kappa$ is an [ineffable cardinal](wikipedia://en/270005), and conversely [Jensen](wikipedia://en/3785996) showed that in the constructible universe for any uncountable [regular cardinal](wikipedia://en/374128) $\kappa$ there is a $\kappa$-Kurepa tree unless $\kappa$ is ineffable.

## Specializing a Kurepa tree {#Specializing_a_Kurepa_tree}

A Kurepa tree can be "killed" by [forcing](wikipedia://en/152205) the existence of a function whose value on any non-root node is an ordinal less than the rank of the node, such that whenever three nodes, one of which is a lower bound for the other two, are mapped to the same ordinal, then the three nodes are comparable. This can be done without [collapsing](wikipedia://en/16968563) $\aleph_1$, and results in a tree with exactly $\aleph_1$ branches.
