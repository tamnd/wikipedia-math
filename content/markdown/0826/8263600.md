# GESMES/TS

::: {#o1 .subject cue=lead name="GESMES/TS"}

**GESMES/TS** (**generic statistical message for time series**) is a [data model](wikipedia://en/82871) and message format appropriate for performing standardised exchange of [statistical data](wikipedia://en/26685) and related [metadata](https://en.wikipedia.org/wiki/Metadata). It is based on the GESMES message (a [UN/CEFACT](https://en.wikipedia.org/wiki/UN/CEFACT) standard using the [EDIFACT](https://en.wikipedia.org/wiki/EDIFACT) syntax). Its most common use is in the exchange of official statistics.

:::

The data model is optimised to represent multi-dimensional arrays of [floating point](https://en.wikipedia.org/wiki/Floating_point) numerical data where one dimension is time. The essential [design pattern](https://en.wikipedia.org/wiki/Design_pattern_%28computer_science%29) resembles a [star schema](https://en.wikipedia.org/wiki/Star_schema). GESMES/TS promotes automation by its ability to explicitly declare the [dimensions](https://en.wikipedia.org/wiki/Dimension_%28data_warehouse%29) and allowable [metadata](https://en.wikipedia.org/wiki/Metadata) fields in a standardised way. Software can then translate these declarations into a [database schema](https://en.wikipedia.org/wiki/Database_schema) suitable to hold the multi-dimensional data. This mechanism makes GESMES/TS versatile enough for efficient use in many domains.

The initial name of GESMES/TS was GESMES/CB (generic statistical message for central banks), but has been changed in order to reflect its wider application. The model and format are maintained under the auspices of the [SDMX](wikipedia://en/8263841) initiative. In this context, GESMES/TS is known as *SDMX-EDI*.
