# Lax–Wendroff theorem

::: {#o1 .subject cue=lead name="Lax–Wendroff theorem"}

In [computational mathematics](wikipedia://en/10433833), the **Lax–Wendroff theorem**, named after [Peter Lax](wikipedia://en/486365) and [Burton Wendroff](wikipedia://en/26640724), states that if a [conservative](https://en.wikipedia.org/wiki/Conservation_law_%28physics%29) [numerical scheme](wikipedia://en/21506) for a [hyperbolic system](wikipedia://en/1575825) of [conservation laws](https://en.wikipedia.org/wiki/Conservation_law_%28physics%29) converges, then it converges towards a [weak solution](wikipedia://en/3555416).

:::
