# Numberlink

::: {#o1 .subject cue=lead name="Numberlink"}

**Numberlink** is a type of [logic puzzle](wikipedia://en/101595) involving finding paths to connect numbers in a grid.

:::

## Rules {#Rules}

The player has to pair up all the matching numbers on the grid with single continuous lines (or paths). The lines cannot branch off or cross over each other, and the numbers have to fall at the end of each line (i.e., not in the middle).

It is considered that a problem is well-designed only if it has a unique solution[^o3] and all the cells in the grid are filled, although some Numberlink designers do not stipulate this.[^o18]

Another rule that is included in some versions of the puzzle is that a path cannot have any U-turns, as these would allow it to be shortened without changing the other paths.[^o18]

## History {#History}

In 1897, a slightly different form of the puzzle was printed in the *Brooklyn Daily Eagle*, in a column by [Sam Loyd](https://en.wikipedia.org/wiki/Sam_Loyd).[^o5] Another early, printed version of *Number Link* can be found in [Henry Ernest Dudeney](https://en.wikipedia.org/wiki/Henry_Ernest_Dudeney)'s book *Amusements in mathematics* (1917) as *a puzzle for motorists* (puzzle no. 252).[^o6] This puzzle type was popularized in Japan by [Nikoli](https://en.wikipedia.org/wiki/Nikoli_%28publisher%29) as *Arukone* (アルコネ, *Alphabet Connection*) and *Nanbarinku* (ナンバーリンク, *Number Link*). The only difference between Arukone and Nanbarinku is that in Arukone the clues are letter pairs (as in Dudeney's puzzle), while in Nanbarinku the clues are number pairs.

Versions of this known as Wire Storm, [Flow Free](https://en.wikipedia.org/wiki/Flow_Free) and Alphabet Connection have been released as apps for [iOS](https://en.wikipedia.org/wiki/IOS), [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29), [Web](https://en.wikipedia.org/wiki/World_Wide_Web) and [Windows Phone](https://en.wikipedia.org/wiki/Windows_Phone).[^o7][^o8][^o9][^o10][^o11][^o12][^o13]

## Computational complexity {#Computational_complexity}

As a [computational problem](https://en.wikipedia.org/wiki/Computational_problem), finding a solution to a given Numberlink puzzle is [NP-complete](https://en.wikipedia.org/wiki/NP-complete), for the versions in which the problem is only to connect all of the pairs of numbers,[^o15][^o16] for paths without U-turns that must cover all squares of the grid,[^o17] and for the "zig-zag" version in which all squares must be covered but U-turns are allowed.[^o18]

These hardness results require the number of pairs of numbers to grow with the size of the puzzle. For fixed numbers of pairs, even on arbitrarily large grids, connecting all pairs (without necessarily filling the grid) can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) as an instance of the vertex-disjoint paths problem on undirected graphs.[^o19]
