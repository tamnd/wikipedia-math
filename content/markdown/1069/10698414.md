# Operator system

::: {#o1 .subject cue=lead name="Operator system"}

Given a [unital](https://en.wikipedia.org/wiki/Unital_algebra) [C\*-algebra](wikipedia://en/7184) $\mathcal{A}$, a [\*-closed](wikipedia://en/7184) [subspace](wikipedia://en/56357) *S* containing *1* is called an **operator system**. One can associate to each subspace $\mathcal{M} \subseteq \mathcal{A}$ of a unital C\*-algebra an operator system via $S:= \mathcal{M}+\mathcal{M}^* +\mathbb{C} 1$.

:::

The appropriate morphisms between operator systems are [completely positive maps](wikipedia://en/6083511).

By a theorem of Choi and Effros, operator systems can be characterized as \*-vector spaces equipped with an Archimedean matrix order.[^o2]
