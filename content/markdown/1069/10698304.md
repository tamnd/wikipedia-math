# Schatten class operator

::: {#o1 .subject cue=lead name="Schatten class operator"}

In [mathematics](wikipedia://en/18831), specifically [functional analysis](wikipedia://en/11180), a ***p*th Schatten-class operator** is a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) on a [Hilbert space](wikipedia://en/20598932) with finite *p*th [Schatten norm](wikipedia://en/10687767). The space of *p*th Schatten-class operators is a [Banach space](wikipedia://en/3989) with respect to the Schatten norm.[^o2]

:::

Via [polar decomposition](wikipedia://en/1369241), one can prove that the space of *p*th Schatten class operators is an ideal in *B(H)*. Furthermore, the [Schatten norm](wikipedia://en/10687767) satisfies a type of [Hölder inequality](https://en.wikipedia.org/wiki/Hölder_inequality):

$$\| S T\| _{S_1} \leq \| S\| _{S_p} \| T\| _{S_q} \ \mbox{if} \ S \in S_p , \ T\in S_q \mbox{ and } 1/p+1/q=1.$$

If we denote by $S_\infty$ the Banach space of [compact operators](wikipedia://en/577441) on *H* with respect to the [operator norm](wikipedia://en/246722), the above Hölder-type inequality even holds for $p \in [1,\infty]$. From this it follows that $\phi : S_p \rightarrow S_q '$, $T \mapsto \mathrm{tr}(T\cdot )$ is a well-defined contraction. (Here the prime denotes (topological) dual.)

Observe that the *2*nd Schatten class is in fact the Hilbert space of [Hilbert–Schmidt operators](wikipedia://en/976673). Moreover, the *1*st Schatten class is the space of [trace class](wikipedia://en/192266) operators.
