# 0/1-polytope

::: {#o1 .subject cue=lead name="0/1-polytope"}

A **0/1-polytope** is a [convex polytope](wikipedia://en/1817885) generated by the [convex hull](wikipedia://en/40634) of a subset of $d$ coordinates value 0 or 1, $\{0,1\}^{d}$. The full domain is the unit [hypercube](wikipedia://en/39783) with cut [hyperplanes](wikipedia://en/99862) passing through these coordinates. A $d$-polytope requires at least $d + 1$ vertices, and can't be all in the same hyperplanes.

:::

*n*-[simplex](wikipedia://en/39781) polytopes for example can be generated $n + 1$ vertices, using the origin, and one vertex along each primary axis, $(1,0....)$, etc. Every [simple](wikipedia://en/8853286) 0/1-polytope is a [Cartesian product](wikipedia://en/27882423) of 0/1 simplexes.
