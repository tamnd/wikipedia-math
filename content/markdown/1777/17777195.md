# Lommel polynomial

::: {#o1 .subject cue=lead name="Lommel polynomial"}

A **Lommel polynomial** *R*<sub>*m*,ν</sub>(*z*) is a polynomial in 1/*z* giving the [recurrence relation](wikipedia://en/146806)

:::

$$\displaystyle J_{m+\nu}(z) = J_\nu(z)R_{m,\nu}(z) - J_{\nu-1}(z)R_{m-1,\nu+1}(z)$$

where *J*<sub>ν</sub>(*z*) is a [Bessel function](wikipedia://en/4700) of the first kind.[^o2]

They are given explicitly by

$$R_{m,\nu}(z) = \sum_{n=0}^{[m/2]}\frac{(-1)^n(m-n)!\Gamma(\nu+m-n)}{n!(m-2n)!\Gamma(\nu+n)}(z/2)^{2n-m}.$$
