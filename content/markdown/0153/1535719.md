# Similarity invariance

::: {#o1 .subject cue=lead name="Similarity invariance"}

In [linear algebra](wikipedia://en/18422), **similarity invariance** is a property exhibited by a function whose value is unchanged under similarities of its domain. That is, $f$ is invariant under similarities if $f(A) = f(B^{-1}AB)$ where $B^{-1}AB$ is a [matrix](wikipedia://en/20556859) [similar](wikipedia://en/341149) to *A*. Examples of such functions include the [trace](wikipedia://en/43270), [determinant](wikipedia://en/8468), [characteristic polynomial](wikipedia://en/218268), and the [minimal polynomial](wikipedia://en/9667107).

:::

A more colloquial phrase that means the same thing as similarity invariance is "basis independence", since a matrix can be regarded as a [linear operator](https://en.wikipedia.org/wiki/Linear_operator), written in a certain [basis](wikipedia://en/18420), and the same operator in a new basis is related to one in the old basis by the conjugation $B^{-1}AB$, where $B$ is the [transformation matrix](wikipedia://en/692458) to the new basis.
