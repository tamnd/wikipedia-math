# Kruskal–Katona theorem

::: {#o1 .subject cue=lead name="Kruskal–Katona theorem"}

In [algebraic combinatorics](wikipedia://en/14835582), the **Kruskal–Katona theorem** gives a complete characterization of the *f*-vectors of [abstract simplicial complexes](wikipedia://en/723105). It includes as a special case the [Erdős–Ko–Rado theorem](wikipedia://en/296188) and can be restated in terms of [uniform hypergraphs](wikipedia://en/232535). It is named after [Joseph Kruskal](https://en.wikipedia.org/wiki/Joseph_Kruskal) and [Gyula O. H. Katona](wikipedia://en/9211532), but has been independently discovered by several others.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Given two positive integers *N* and *i*, there is a unique way to expand *N* as a sum of [binomial coefficients](wikipedia://en/4668) as follows:

$$N=\binom{n_i}{i}+\binom{n_{i-1}}{i-1}+\ldots+\binom{n_j}{j},\quad n_i > n_{i-1} > \ldots > n_j \geq j\geq 1.$$

This expansion can be constructed by applying the [greedy algorithm](wikipedia://en/89247): set *n*<sub>*i*</sub> to be the maximal *n* such that $N\geq \binom{n}{i},$ replace *N* with the difference, *i* with *i* − 1, and repeat until the difference becomes zero. Define

$$N^{(i-1)}=\binom{n_i}{i-1}+\binom{n_{i-1}}{i-2}+\ldots+\binom{n_j}{j-1}.$$

### Statement for simplicial complexes {#Statement_for_simplicial_complexes}

An integral vector $(f_0, f_1, ..., f_{d-1})$ is the [*f*-vector](https://en.wikipedia.org/wiki/F-vector) of some $(d-1)$-dimensional simplicial complex if and only if

$$0 \leq f_{i}^{(i)} \leq f_{i-1},\quad 1\leq i\leq d-1.$$

### Statement for uniform hypergraphs {#Statement_for_uniform_hypergraphs}

Let *A* be a set consisting of *N* distinct *i*-element subsets of a fixed set *U* ("the universe") and *B* be the set of all $(i-r)$-element subsets of the sets in *A*. Expand *N* as above. Then the cardinality of *B* is bounded below as follows:

$$|B| \geq \binom{n_i}{i-r}+\binom{n_{i-1}}{i-r-1}+\ldots+\binom{n_j}{j-r}.$$

### Lovász' simplified formulation {#Lovász'_simplified_formulation}

The following weaker but useful form is due to (txt, 13.31b). Let *A* be a set of *i*-element subsets of a fixed set *U* ("the universe") and *B* be the set of all $(i-r)$-element subsets of the sets in *A*. If $|A| = \binom{x}{i}$ then $|B| \geq \binom{x}{i-r}$.

In this formulation, *x* need not be an integer. The value of the binomial expression is $\binom{x}{i} = \frac{x(x-1)\dots(x-i+1)}{i!}$.

:::

## Ingredients of the proof {#Ingredients_of_the_proof}

For every positive *i*, list all *i*-element subsets *a*<sub>1</sub> \< *a*<sub>2</sub> \< … *a*<sub>*i*</sub> of the set **N** of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) in the [colexicographical order](https://en.wikipedia.org/wiki/Colexicographical_order). For example, for *i* = 3, the list begins

$$123, 124, 134, 234, 125, 135, 235, 145, 245, 345, \ldots.$$

Given a vector $f = (f_0, f_1, ..., f_{d-1})$ with positive integer components, let *Δ*<sub>*f*</sub> be the subset of the [power set](wikipedia://en/23799) 2<sup>**N**</sup> consisting of the empty set together with the first $f_{i-1}$ *i*-element subsets of **N** in the list for *i* = 1, …, *d*. Then the following conditions are equivalent:

1. Vector *f* is the *f*-vector of a simplicial complex *Δ*.
1. *Δ*<sub>*f*</sub> is a simplicial complex.
1. $$f_{i}^{(i)} \leq f_{i-1},\quad 1\leq i\leq d-1.$$

The difficult implication is 1 ⇒ 2.

## History {#History}

The theorem is named after [Joseph Kruskal](https://en.wikipedia.org/wiki/Joseph_Kruskal) and [Gyula O. H. Katona](wikipedia://en/9211532), who published it in 1963 and 1968 respectively. According to (Le Römer 2019), it was discovered independently by (Kruskal 1963), (Katona 1968), (txt), (Harper 1966), and (Clements Lindström 1969). (txt) writes that the earliest of these references, by Schützenberger, has an incomplete proof.
