# Ω-consistent theory

::: {#o1 .subject cue=lead name="Ω-consistent theory"}

In [mathematical logic](wikipedia://en/19636), an **ω-consistent** (or **omega-consistent**, or **numerically segregative**)[^o2] **theory** is a [theory](wikipedia://en/3512103) (collection of [sentences](wikipedia://en/2129527)) that is not only (syntactically) [consistent](wikipedia://en/3512103#Consistency_and_completeness)[^o3][^o4] (that is, does not prove a [contradiction](wikipedia://en/75807)), but also avoids proving certain infinite combinations of sentences that are intuitively contradictory. The name is due to [Kurt Gödel](wikipedia://en/16736), who introduced the concept in the course of proving the [incompleteness theorem](wikipedia://en/58863).[^o5]

:::

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

A theory *T* is said to [interpret](wikipedia://en/621176) the [language](wikipedia://en/10939) of arithmetic if there is a translation of formulas of arithmetic into the language of *T* so that *T* is able to prove the basic axioms of the [natural numbers](wikipedia://en/21474) under this translation.

A *T* that interprets arithmetic is **ω-inconsistent** if, for some property *P* of natural numbers (defined by a formula in the language of *T*), *T* proves *P*(0), *P*(1), *P*(2), and so on (that is, for every standard natural number *n*, *T* proves that *P*(*n*) holds), but *T* also proves that there is some natural number *n* such that *P*(*n*) *fails*.[^o3] This may not generate a contradiction within *T* because *T* may not be able to prove for any *specific* value of *n* that *P*(*n*) fails, only that there *is* such an *n*. In particular, such *n* is necessarily a [nonstandard integer](wikipedia://en/6251420) in any [model](https://en.wikipedia.org/wiki/Model_%28logic%29) for *T* ([Quine](wikipedia://en/33833) has thus called such theories "numerically insegregative").[^o8]

*T* is **ω-consistent** if it is *not* ω-inconsistent.

There is a weaker but closely related property of Σ<sub>1</sub>-soundness. A theory *T* is **Σ<sub>1</sub>-sound** (or **1-consistent**, in another terminology)[^o9] if every Σ0-sentenceA Σ0 formula is a [first-order formula](https://en.wikipedia.org/wiki/First-order_formula) (one in which variables range only over the [universe of discourse](wikipedia://en/296838), e.g. natural numbers, and not [predicates](wikipedia://en/285109)) that begins with some [existential quantifiers](https://en.wikipedia.org/wiki/Existential_quantifier) and alternates *n* − 1 times between series of existential and [universal quantifiers](https://en.wikipedia.org/wiki/Universal_quantifier), or one that is equivalent to such a formula. For the full definition, see [Arithmetical hierarchy](wikipedia://en/186475). provable in *T* is true in the standard model of arithmetic **N** (i.e., the structure of the usual natural numbers with addition and multiplication). If *T* is strong enough to formalize a reasonable model of [computation](wikipedia://en/30402), Σ<sub>1</sub>-soundness is equivalent to demanding that whenever *T* proves that a [Turing machine](wikipedia://en/30403) *C* halts, then *C* actually halts. Every ω-consistent theory is Σ<sub>1</sub>-sound, but not vice versa.

More generally, we can define an analogous concept for higher levels of the [arithmetical hierarchy](wikipedia://en/186475). If Γ is a set of arithmetical sentences (typically Σ0 for some *n*), a theory *T* is **Γ-sound** if every Γ-sentence provable in *T* is true in the standard model. When Γ is the set of all arithmetical formulas, Γ-soundness is called just (arithmetical) [soundness](wikipedia://en/26819). If the language of *T* consists *only* of the language of arithmetic (as opposed to, for example, [set theory](wikipedia://en/27553)), then a sound system is one whose model can be thought of as the set ω, the usual set of mathematical natural numbers. The case of general *T* is different; see ω-logic below.

Σ<sub>*n*</sub>-soundness has the following computational interpretation: if the theory proves that a program *C* using a Σ<sub>*n*−1</sub>-[oracle](wikipedia://en/22431) halts, then *C* actually halts.

## Examples {#Examples}

### Consistent, ω-inconsistent theories {#Consistent,_&omega;-inconsistent_theories}

Write PA for the theory [Peano arithmetic](wikipedia://en/25005), and Con(PA) for the statement of arithmetic that formalizes the claim "PA is consistent". Con(PA) could be of the form "No natural number *n* is the [Gödel number](https://en.wikipedia.org/wiki/Gödel_number) of a proof in PA that 0=1".This formulation uses 0=1 instead of a direct contradiction; that gives the same result, because PA certainly proves ¬0=1, so if it proved 0=1 as well we would have a contradiction, and on the other hand, if PA proves a contradiction, [then it proves anything](wikipedia://en/591394), including 0=1. Now, the consistency of PA implies the consistency of PA + ¬Con(PA). Indeed, if PA + ¬Con(PA) was inconsistent, then PA alone would prove ¬Con(PA)→0=1, and a [reductio ad absurdum](wikipedia://en/22456146) in PA would produce a proof of Con(PA). By [Gödel's second incompleteness theorem](https://en.wikipedia.org/wiki/Gödel's_second_incompleteness_theorem), PA would be inconsistent.

Therefore, assuming that PA is consistent, PA + ¬Con(PA) is consistent too. However, it would *not* be ω-consistent. This is because, for any particular *n*, PA, and hence PA + ¬Con(PA), proves that *n* is not the Gödel number of a proof that 0=1. However, PA + ¬Con(PA) proves that, for *some* natural number *n*, *n* *is* the Gödel number of such a proof (this is just a direct restatement of the claim ¬Con(PA)).

In this example, the axiom ¬Con(PA) is Σ<sub>1</sub>, hence the system PA + ¬Con(PA) is in fact Σ<sub>1</sub>-unsound, not just ω-inconsistent.

### Arithmetically sound, ω-inconsistent theories {#Arithmetically_sound,_&omega;-inconsistent_theories}

Let *T* be PA together with the axioms *c* ≠ *n* for each natural number *n*, where *c* is a new constant added to the language. Then *T* is arithmetically sound (as any nonstandard model of PA can be expanded to a model of *T*), but ω-inconsistent (as it proves $\exists x\,c=x$, and *c* ≠ *n* for every number *n*).

Σ<sub>1</sub>-sound ω-inconsistent theories using only the language of arithmetic can be constructed as follows. Let *I*Σ<sub>*n*</sub> be the subtheory of PA with the induction schema restricted to Σ<sub>*n*</sub>-formulas, for any *n* > 0. The theory *I*Σ<sub>*n* + 1</sub> is finitely axiomatizable, let thus *A* be its single axiom, and consider the theory *T* = *I*Σ<sub>*n*</sub> + ¬*A*. We can assume that *A* is an instance of the induction schema, which has the form

$$\forall w\,[B(0,w)\land\forall x\,(B(x,w)\to B(x+1,w))\to\forall x\,B(x,w)].$$

If we denote the formula

$$\forall w\,[B(0,w)\land\forall x\,(B(x,w)\to B(x+1,w))\to B(n,w)]$$

by *P*(*n*), then for every natural number *n*, the theory *T* (actually, even the pure predicate calculus) proves *P*(*n*). On the other hand, *T* proves the formula $\exists x\,\neg P(x)$, because it is [logically equivalent](wikipedia://en/169324) to the axiom ¬*A*. Therefore, *T* is ω-inconsistent.

It is possible to show that *T* is Π<sub>*n* + 3</sub>-sound. In fact, it is Π<sub>*n* + 3</sub>-[conservative](wikipedia://en/1840214) over the (obviously sound) theory *I*Σ<sub>*n*</sub>. The argument is more complicated (it relies on the provability of the Σ<sub>*n* + 2</sub>-[reflection principle](wikipedia://en/3225574) for *I*Σ<sub>*n*</sub> in *I*Σ<sub>*n* + 1</sub>).

### Arithmetically unsound, ω-consistent theories {#Arithmetically_unsound,_&omega;-consistent_theories}

Let ω-Con(PA) be the arithmetical sentence formalizing the statement "PA is ω-consistent". Then the theory PA + ¬ω-Con(PA) is unsound (Σ<sub>3</sub>-unsound, to be precise), but ω-consistent. The argument is similar to the first example: a suitable version of the [Hilbert–Bernays–Löb derivability conditions](https://en.wikipedia.org/wiki/Hilbert–Bernays-Löb_provability_conditions) holds for the "provability predicate" ω-Prov(*A*) = ¬ω-Con(PA + ¬*A*), hence it satisfies an analogue of Gödel's second incompleteness theorem.

:::

## ω-logic {#ω-logic}

The concept of theories of arithmetic whose integers are the true mathematical integers is captured by **ω-logic**.ω-logic in Barwise[^o17] is defined as a two-sorted first-order logic, with a fixed interpretation of the second sort as the natural numbers (§5.2, p.42); whereas this article discusses the single sorted internalization via a unary predicate N (also discussed in §5.1). Let *T* be a theory in a [countable](https://en.wikipedia.org/wiki/Countable) language that includes a unary predicate symbol *N* intended to hold just of the natural numbers, as well as specified names 0, 1, 2, ..., one for each (standard) natural number (which may be separate constants, or constant terms such as 0, 1, 1+1, 1+1+1, ..., etc.). Note that *T* itself could be referring to more general objects, such as [real numbers](wikipedia://en/20646438) or sets; thus in a model of *T* the objects satisfying *N*(*x*) are those that *T* interprets as natural numbers, not all of which need be named by one of the specified names.

The system of ω-logic includes all axioms and rules of the usual [first-order predicate](wikipedia://en/11344) logic, together with, for each *T*-formula *P*(*x*) with a specified free variable *x*, an [infinitary](wikipedia://en/630478) **ω-rule** of the form:

From $P(0),P(1),P(2),\ldots$ infer $\forall x\,(N(x)\to P(x))$.

That is, if the theory asserts (i.e. proves) *P*(*n*) separately for each natural number *n* given by its specified name, then it also asserts *P* collectively for all natural numbers at once via the evident finite universally quantified counterpart of the infinitely many antecedents of the rule. For a theory of arithmetic, meaning one with intended domain the natural numbers such as [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), the predicate *N* is redundant and may be omitted from the language, with the consequent of the rule for each *P* simplifying to $\forall x\,P(x)$.

An ω-model of *T* is a model of *T* whose domain includes the natural numbers and whose specified names and symbol *N* are standardly interpreted, respectively as those numbers and the predicate having just those numbers as its domain (whence there are no nonstandard numbers). If *N* is absent from the language then what would have been the domain of *N* is required to be that of the model, i.e. the model contains only the natural numbers. (Other models of *T* may interpret these symbols nonstandardly; the domain of *N* need not even be countable, for example.) These requirements make the ω-rule sound in every ω-model. As a corollary to the [omitting types theorem](https://en.wikipedia.org/wiki/Omitting_types_theorem), the converse also holds: the theory *T* has an ω-model if and only if it is consistent in ω-logic.

There is a close connection of ω-logic to ω-consistency. A theory consistent in ω-logic is also ω-consistent (and arithmetically sound). The converse is false, as consistency in ω-logic is a much stronger notion than ω-consistency. However, the following characterization holds: a theory is ω-consistent if and only if its closure under *unnested* applications of the ω-rule is consistent.

:::

## Relation to other consistency principles {#Relation_to_other_consistency_principles}

If the theory *T* is [recursively axiomatizable](https://en.wikipedia.org/wiki/Recursively_enumerable), ω-consistency has the following characterization, due to [Craig Smoryński](https://en.wikipedia.org/wiki/Craig_Smoryński):[^o20]

*T* is ω-consistent if and only if $T+\mathrm{RFN}_T+\mathrm{Th}_{\Pi^0_2}(\mathbb N)$ is consistent.

Here, $\mathrm{Th}_{\Pi^0_2}(\mathbb N)$ is the set of all $\Pi^0_2$-sentences valid in the standard model of arithmetic, and $\mathrm{RFN}_T$ is the [uniform reflection principle](wikipedia://en/3225574) for *T*, which consists of the axioms

$$\forall x\,(\mathrm{Prov}_T(\ulcorner\varphi(\dot x)\urcorner)\to\varphi(x))$$

for every formula $\varphi$ with one free variable. In particular, a finitely axiomatizable theory *T* in the language of arithmetic is ω-consistent if and only if *T* + PA is $\Sigma^0_2$-sound.

:::
