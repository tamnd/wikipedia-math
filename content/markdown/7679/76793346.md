# Attribute blocks

::: {#o1 .subject cue=lead name="Attribute blocks"}

*Image: Attribute blocks.png.* A set of 60 attribute blocks

**Attribute blocks**, also called **logic blocks**, are [mathematical manipulatives](wikipedia://en/6791734) used to teach [logic](wikipedia://en/46426065). Each [block](https://en.wikipedia.org/wiki/Toy_block) in a set has a unique combination of four attributes, namely size, color, shape, and thickness.[^o3]

:::
