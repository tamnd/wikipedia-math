# Łoś–Vaught test

::: {#o1 .subject cue=lead name="Łoś–Vaught test"}

In [model theory](wikipedia://en/19858), a branch of [mathematical logic](wikipedia://en/19636), the **Łoś–Vaught test** is a criterion for a [theory](wikipedia://en/3512103) to be [complete](wikipedia://en/10086335), unable to be augmented without becoming inconsistent. For theories in [classical logic](wikipedia://en/55868), this means that for every [sentence](wikipedia://en/2129527), the theory contains either the sentence or its negation but not both.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

A theory $T$ with [signature](wikipedia://en/7788156) *σ* is [$\kappa$-categorical](https://en.wikipedia.org/wiki/Κ-categorical) for an [infinite cardinal](https://en.wikipedia.org/wiki/Infinite_cardinal) $\kappa$ if $T$ has exactly one model (up to isomorphism) of cardinality $\kappa.$

The **Łoś–Vaught test** states that if a first-order satisfiable theory is $\kappa$-categorical for some $\kappa \geq |\sigma|$ and has no finite model, then it is complete.

This theorem was proved independently by (txt) and (txt), after whom it is named.

:::

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

The Łoś–Vaught test is used to prove that the theory of closed [first-order logic](wikipedia://en/10983) formulas true on the [Rado graph](wikipedia://en/7785594) is complete.[^o8]

:::
