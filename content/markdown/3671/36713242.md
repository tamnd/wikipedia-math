# Partial differential algebraic equation

::: {#o1 .subject cue=lead name="Partial differential algebraic equation"}

In [mathematics](wikipedia://en/18831) a **partial differential algebraic equation (PDAE)** set is an incomplete system of [partial differential equations](wikipedia://en/52564) that is closed with a set of [algebraic equations](wikipedia://en/404001).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A general PDAE is defined as:

$$0 = \mathbf F \left( \mathbf x, \mathbf y, \frac{\partial y_i}{\partial x_j}, \frac{\partial^2 y_i}{\partial x_j \partial x_k}, \ldots, \mathbf z \right),$$

where:

- **F** is a set of arbitrary functions;
- **x** is a set of independent variables;
- **y** is a set of dependent variables for which partial derivatives are defined; and
- **z** is a set of dependent variables for which no partial derivatives are defined.

The relationship between a PDAE and a [partial differential equation](wikipedia://en/52564) (PDE) is analogous to the relationship between an [ordinary differential equation](wikipedia://en/32742753) (ODE) and a [differential algebraic equation](https://en.wikipedia.org/wiki/Differential_algebraic_equation) (DAE).

PDAEs of this general form are challenging to solve. Simplified forms are studied in more detail in the literature.[^o4][^o5][^o6] Even as recently as 2000, the term "PDAE" has been handled as unfamiliar by those in related fields.[^o7]

:::

## Solution methods {#Solution_methods}

[Semi-discretization](https://en.wikipedia.org/wiki/Semi-discretization) is a common method for solving PDAEs whose independent variables are those of [time](https://en.wikipedia.org/wiki/Time) and [space](wikipedia://en/27667), and has been used for decades.[^o9][^o10] This method involves removing the spatial variables using a [discretization](wikipedia://en/330017) method, such as the [finite volume method](wikipedia://en/345017), and incorporating the resulting linear equations as part of the algebraic relations. This reduces the system to a [DAE](https://en.wikipedia.org/wiki/Differential_algebraic_equation), for which conventional solution methods can be employed.
