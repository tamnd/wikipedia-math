# Freyd cover

::: {#o1 .subject cue=lead name="Freyd cover"}

In the mathematical discipline of [category theory](wikipedia://en/5869), the **Freyd cover** or **scone category** is a construction that yields a set-like construction out of a given category. The only requirement is that the original category has a terminal object. The scone category inherits almost any categorical construct the original category has. Scones can be used to generally describe proofs that use [logical relations](https://en.wikipedia.org/wiki/Logical_relations).

:::

The Freyd cover is named after [Peter Freyd](https://en.wikipedia.org/wiki/Peter_Freyd). The other name, "scone", is intended to suggest that it is like a [cone](wikipedia://en/782162), but with the [Sierpiński space](wikipedia://en/387651) in place of the [unit interval](wikipedia://en/49324).[^o4]

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, the scone of a category *C* with a terminal object 1 is the [comma category](wikipedia://en/840950) $1_\text{Set} \downarrow \operatorname{Hom}_C(1,-)$.

:::
