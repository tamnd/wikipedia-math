# Torsion abelian group

::: {#o1 .subject cue=lead name="Torsion abelian group"}

In [abstract algebra](wikipedia://en/19616384), a **torsion abelian group** is an [abelian group](wikipedia://en/2974) in which every [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) has [finite order](https://en.wikipedia.org/wiki/Finite_order).[^o2] For example, the [torsion subgroup](wikipedia://en/144052) of an abelian group is a torsion abelian group.

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### Finite Cyclic {#Finite_Cyclic}

A finite [cyclic group](wikipedia://en/52327) is a torsion abelian group.

### Finitely Generated Abelian Group {#Finitely_Generated_Abelian_Group}

A [finitely generated abelian group](wikipedia://en/58527) is torsion iff it is finite, see [Finitely generated abelian group#Classification](wikipedia://en/58527#Classification)

### Infinite Torsion Abelian Group {#Infinite_Torsion_Abelian_Group}

A torsion abelian group is not necessarily finite. For instance, the group $\mathbb{Q}$/ $\mathbb{Z}$
