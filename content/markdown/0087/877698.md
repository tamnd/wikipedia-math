# General linear model

::: {#o1 .subject cue=lead name="General linear model"}

The **general linear model** or **general multivariate regression model** is a compact way of simultaneously writing several [multiple linear regression](wikipedia://en/5477568) models. In that sense it is not a separate statistical [linear model](wikipedia://en/17904). The various multiple linear regression models may be compactly written as[^o2]

:::

$$\mathbf{Y} = \mathbf{X}\mathbf{B} + \mathbf{U},$$

where **Y** is a [matrix](wikipedia://en/20556859) with series of multivariate measurements (each column being a set of measurements on one of the [dependent variables](https://en.wikipedia.org/wiki/Dependent_variable)), **X** is a matrix of observations on [independent variables](https://en.wikipedia.org/wiki/Independent_variable) that might be a [design matrix](wikipedia://en/949189) (each column being a set of observations on one of the independent variables), **B** is a matrix containing parameters that are usually to be estimated and **U** is a matrix containing [errors](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) (noise). The errors are usually assumed to be uncorrelated across measurements, and follow a [multivariate normal distribution](wikipedia://en/50347). If the errors do not follow a multivariate normal distribution, [generalized linear models](wikipedia://en/747122) may be used to relax assumptions about **Y** and **U**.

The general linear model (GLM) encompasses several statistical models, including [ANOVA](wikipedia://en/634), [ANCOVA](wikipedia://en/404926), [MANOVA](wikipedia://en/682847), [MANCOVA](wikipedia://en/16849908), and ordinary [linear regression](wikipedia://en/48758386). Within this framework, both the [*t*-test](https://en.wikipedia.org/wiki/T-test) and the [*F*-test](wikipedia://en/318976) can be applied. The general linear model is a generalization of multiple linear regression to the case of more than one dependent variable. If **Y**, **B**, and **U** were [column vectors](https://en.wikipedia.org/wiki/Column_vector), the matrix equation above would represent multiple linear regression.

Hypothesis tests with the general linear model can be made in two ways: [multivariate](wikipedia://en/19384) or as several independent [univariate](wikipedia://en/2398982) tests. In multivariate tests the columns of **Y** are tested together, whereas in univariate tests the columns of **Y** are tested independently, i.e., as multiple univariate tests with the same design matrix.

## Comparison to multiple linear regression {#Comparison_to_multiple_linear_regression}

Multiple linear regression is a generalization of [simple linear regression](wikipedia://en/2593771) to the case of more than one independent variable, and a [special case](wikipedia://en/31308010) of general linear models, restricted to one dependent variable. The basic model for multiple linear regression is

$Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \ldots + \beta_p X_{ip} + \epsilon_i$ or more compactly $Y_i = \beta_0 + \sum \limits_{k=1}^{p} {\beta_k X_{ik}} + \epsilon_i$

for each observation *i* = 1, ... , *n*.

In the formula above we consider *n* observations of one dependent variable and *p* independent variables. Thus, *Y*<sub>*i*</sub> is the *i*<sup>th</sup> observation of the dependent variable, *X*<sub>*ik*</sub> is *i*<sup>th</sup> observation of the *k*<sup>th</sup> independent variable, *k* = 1, 2, ..., *p*. The values *βk* represent parameters to be estimated, and *ε*<sub>*i*</sub> is the *i*<sup>th</sup> independent identically distributed normal error.

In the more general multivariate linear regression, there is one equation of the above form for each of *m* > 1 dependent variables that share the same set of explanatory variables and hence are estimated simultaneously with each other:

$Y_{ij} = \beta_{0j} + \beta_{1j} X_{i1} + \beta_{2j}X_{i2} + \ldots + \beta_{pj} X_{ip} + \epsilon_{ij}$ or more compactly $Y_{ij} = \beta_{0j} + \sum \limits_{k=1}^{p} { \beta_{kj} X_{ik}} + \epsilon_{ij}$

for all observations indexed as *i* = 1, ... , *n* and for all dependent variables indexed as *j = 1*, *...* , *m*.

Note that, since each dependent variable has its own set of regression parameters to be fitted, from a computational point of view the general multivariate regression is simply a sequence of standard multiple linear regressions using the same explanatory variables.

## Comparison to generalized linear model {#Comparison_to_generalized_linear_model}

The general linear model and the [generalized linear model](wikipedia://en/747122) (GLM)[^o5][^o6] are two commonly used families of [statistical methods](wikipedia://en/26685) to relate some number of continuous and/or categorical [predictors](wikipedia://en/437701) to a single [outcome variable](wikipedia://en/437701).

The main difference between the two approaches is that the general linear model strictly assumes that the [residuals](wikipedia://en/461509) will follow a [conditionally](wikipedia://en/504458) [normal distribution](wikipedia://en/21462),[^o7] while the GLM loosens this assumption and allows for a variety of other [distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) from the [exponential family](wikipedia://en/339174) for the residuals.[^o5] The general linear model is a special case of the GLM in which the distribution of the residuals follow a conditionally normal distribution.

The distribution of the residuals largely depends on the type and distribution of the outcome variable; different types of outcome variables lead to the variety of models within the GLM family. Commonly used models in the GLM family include [binary logistic regression](wikipedia://en/226631)[^o8] for binary or dichotomous outcomes, [Poisson regression](wikipedia://en/2708102)[^o9] for count outcomes, and [linear regression](wikipedia://en/48758386) for continuous, normally distributed outcomes. This means that GLM may be spoken of as a general family of statistical models or as specific models for specific outcome types.

## Applications {#Applications}

An application of the general linear model appears in the analysis of multiple [brain scans](https://en.wikipedia.org/wiki/Brain_scan) in scientific experiments where $Y$ contains data from brain scanners, $X$ contains experimental design variables and confounds. It is usually tested in a univariate way (usually referred to a *mass-univariate* in this setting) and is often referred to as [statistical parametric mapping](wikipedia://en/878481).[^o25]
