# Cycle graph

::: {#o3 .subject cue=lead name="Cycle graph"}

In [graph theory](wikipedia://en/12401), a **cycle graph** or **circular graph** is a [graph](wikipedia://en/325806) that consists of a single [cycle](wikipedia://en/168609), or in other words, some number of [vertices](wikipedia://en/638899) (at least 3, if the graph is [simple](https://en.wikipedia.org/wiki/Simple_graph)) connected in a closed chain. The cycle graph with $n$ vertices is called $C_{n}$.[^o4] The number of vertices in $C_{n}$ equals the number of [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29), and every vertex has [degree](wikipedia://en/1374448) 2; that is, every vertex has exactly two edges incident with it.

:::

Cycle graph $C_1$ is an isolated [loop](wikipedia://en/1449083). Cycle graph $C_3$ is the same as [complete graph](wikipedia://en/85816) $K_3$.

::: {#o6 .definition kind=definition/notation cue=heading name="Terminology"}

## Terminology {#Terminology}

There are many [synonyms](https://en.wikipedia.org/wiki/Synonym) for "cycle graph". These include **simple cycle graph** and **cyclic graph**, although the latter term is less often used, because it can also refer to graphs which are merely not [acyclic](wikipedia://en/204002). Among graph theorists, **cycle**, **polygon**, or ***n*-gon** are also often used. The term ***n*-cycle** is sometimes used in other settings.[^o7]

A cycle with an even number of vertices is called an **even cycle**; a cycle with an odd number of vertices is called an **odd cycle**.

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

A cycle graph is:

- [2-edge colorable](https://en.wikipedia.org/wiki/K-edge_colorable), if and only if it has an even number of vertices
- [2-regular](wikipedia://en/85821)
- [2-vertex colorable](wikipedia://en/244431), if and only if it has an even number of vertices. More generally, a graph is bipartite [if and only if](wikipedia://en/14922) it has no odd cycles ([Kőnig](wikipedia://en/1327120), 1936).
- [Connected](https://en.wikipedia.org/wiki/Connected_graph)
- [Eulerian](https://en.wikipedia.org/wiki/Eulerian_graph)
- [Hamiltonian](https://en.wikipedia.org/wiki/Hamiltonian_graph)
- A [unit distance graph](wikipedia://en/7158665)

In addition:

- As cycle graphs can be [drawn](wikipedia://en/325813) as [regular polygons](wikipedia://en/333306), the [symmetries](wikipedia://en/56661772) of an *n*-cycle are the same as those of a regular polygon with *n* sides, the [dihedral group](wikipedia://en/100267) of order 2*n*. In particular, there exist symmetries taking any vertex to any other vertex, and any edge to any other edge, so the *n*-cycle is a [symmetric graph](wikipedia://en/1577896).

Similarly to the [Platonic graphs](https://en.wikipedia.org/wiki/Platonic_graph), the cycle graphs form the skeletons of the [dihedra](wikipedia://en/6109457). Their duals are the [dipole graphs](wikipedia://en/6412575), which form the skeletons of the [hosohedra](wikipedia://en/2316192).

:::

::: {#o11 .pointer-item cue=pointer name="Directed cycle graph"}

## Directed cycle graph {#Directed_cycle_graph}

*Image: DC8.png.* A directed cycle graph of length 8

A **directed cycle graph** is a directed version of a cycle graph, with all the edges being oriented in the same direction.

In a [directed graph](wikipedia://en/19721986), a set of edges which contains at least one edge (or *arc*) from each directed cycle is called a [feedback arc set](wikipedia://en/1860374). Similarly, a set of vertices containing at least one vertex from each directed cycle is called a [feedback vertex set](wikipedia://en/1860368).

A directed cycle graph has uniform in-degree 1 and uniform out-degree 1.

Directed cycle graphs are [Cayley graphs](wikipedia://en/358277) for [cyclic groups](wikipedia://en/52327) (see e.g. Trevisan).
