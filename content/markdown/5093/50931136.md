# Cluster graph

*Image: Equivalentie.svg.* A cluster graph with clusters (complete subgraphs) of sizes 1, 2, 3, 4, 4, 5, and 6

::: {#o1 .subject cue=lead name="Cluster graph"}

In [graph theory](wikipedia://en/12401), a branch of [mathematics](wikipedia://en/18831), a **cluster graph** is a [graph](wikipedia://en/325806) formed from the [disjoint union](wikipedia://en/9938459) of [complete graphs](wikipedia://en/85816). Equivalently, a graph is a cluster graph [if and only if](wikipedia://en/14922) it has no three-vertex [induced path](wikipedia://en/7714430); for this reason, the cluster graphs are also called **$P_{3}$-free graphs**. They are the [complement graphs](wikipedia://en/1175649) of the complete [multipartite graphs](wikipedia://en/39469099)[^o2] and the [2-leaf powers](wikipedia://en/49639194).[^o3] The cluster graphs are [transitively closed](wikipedia://en/292239), and every transitively closed undirected graph is a cluster graph.[^o4]

:::

The cluster graphs are the graphs for which the relation "being equal or adjacent" is an [equivalence relation](wikipedia://en/9259), and their connected components are the [equivalence classes](wikipedia://en/9260) for this relation.

## Related graph classes {#Related_graph_classes}

Every cluster graph is a [block graph](wikipedia://en/29106883), a [cograph](wikipedia://en/1175666), and a [claw-free graph](wikipedia://en/12415907).[^o2] Every [maximal independent set](wikipedia://en/1793590) in a cluster graph chooses a single vertex from each cluster, so the size of such a set always equals the number of clusters; because all maximal independent sets have the same size, cluster graphs are [well-covered](wikipedia://en/32696387). The [Turán graphs](wikipedia://en/360581) are [complement graphs](wikipedia://en/1175649) of cluster graphs, with all complete subgraphs of equal or nearly-equal size. The locally clustered graph (graphs in which every [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28graph_theory%29) is a cluster graph) are the [diamond-free graphs](https://en.wikipedia.org/wiki/Diamond-free_graph), another family of graphs that contains the cluster graphs.

When a cluster graph is formed from cliques that are all the same size, the overall graph is a [homogeneous graph](https://en.wikipedia.org/wiki/Homogeneous_graph), meaning that every [isomorphism](wikipedia://en/247577) between two of its [induced subgraphs](wikipedia://en/1655188) can be extended to an [automorphism](wikipedia://en/15094186) of the whole graph. With only two exceptions, the cluster graphs and their complements are the only finite homogeneous graphs,[^o6] and infinite cluster graphs also form one of only a small number of different types of [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite) homogeneous graphs.[^o7]

## Computational problems {#Computational_problems}

A [subcoloring](wikipedia://en/702867) of a graph is a partition of its vertices into [induced](wikipedia://en/1655188) cluster graphs. Thus, the cluster graphs are exactly the graphs of subchromatic number 1.[^o9]

The computational problem of finding a small set of edges to add or remove from a graph to transform it into a cluster graph is called [cluster editing](https://en.wikipedia.org/wiki/Cluster_editing). It is [NP-complete](https://en.wikipedia.org/wiki/NP-complete)[^o10] but [fixed-parameter tractable](wikipedia://en/603026).[^o11]

Given a complete graph with edge costs (positive and negative) the [clique partitioning](https://en.wikipedia.org/wiki/Clique_partitioning) problem asks for a subgraph that is a cluster graph such that the sum of the costs of the edges of the cluster graph is minimal.[^o12] This problem is closely related to the [correlation clustering](wikipedia://en/21417820) problem.
