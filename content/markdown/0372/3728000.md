# Hidden subgroup problem

::: {#o1 .subject cue=lead name="Hidden subgroup problem"}

The **hidden subgroup problem** (**HSP**) is a topic of research in [mathematics](wikipedia://en/18831) and [theoretical computer science](wikipedia://en/323392). It is a generalization of problems including [factoring](wikipedia://en/15491), [discrete logarithm](wikipedia://en/181334), [graph isomorphism](wikipedia://en/1950766), and the [shortest vector problem](https://en.wikipedia.org/wiki/Shortest_vector_problem). This makes it especially important in the theory of [quantum computing](wikipedia://en/25220) because [Shor's algorithms](wikipedia://en/42674) for factoring and finding discrete logarithms in [quantum computing](wikipedia://en/25220) are instances of the hidden subgroup problem for [finite abelian groups](https://en.wikipedia.org/wiki/Finite_abelian_group), while the other problems correspond to [finite groups](wikipedia://en/323707) that are not abelian.

:::

## Problem statement {#Problem_statement}

Given a [group](wikipedia://en/19447) $G$, a [subgroup](wikipedia://en/28011) $H \leq G$, and a set $X$, we say a function $f : G \to X$ **hides** the subgroup $H$ if for all $g_1, g_2 \in G, f(g_1) = f(g_2)$ if and only if $g_1 H = g_2 H$. Equivalently, $f$ is constant on each [coset](wikipedia://en/98759) of *H*, while it is different between the different cosets of *H*.

**Hidden subgroup problem**: Let $G$ be a group, $X$ a finite set, and $f : G \to X$ a function that hides a subgroup $H \leq G$. The function $f$ is given via an [oracle](wikipedia://en/22431), which uses $O(\log |G| + \log |X|)$ bits. Using information gained from evaluations of $f$ via its oracle, determine a [generating set](wikipedia://en/3171371) for $H$.

A special case is when $X$ is a group and $f$ is a [group homomorphism](wikipedia://en/12396) in which case $H$ corresponds to the [kernel](wikipedia://en/45240) of $f$.

## Motivation {#Motivation}

The hidden subgroup problem is especially important in the theory of [quantum computing](https://en.wikipedia.org/wiki/Quantum_computer) for the following reasons.

- [Shor's algorithm](wikipedia://en/42674) for factoring and for finding [discrete logarithms](wikipedia://en/181334) (as well as several of its extensions) relies on the ability of quantum computers to solve the HSP for [finite abelian groups](https://en.wikipedia.org/wiki/Finite_abelian_group).
- The existence of efficient [quantum algorithms](https://en.wikipedia.org/wiki/Quantum_algorithm) for HSPs for certain [non-abelian groups](wikipedia://en/4791400) would imply efficient quantum algorithms for two major problems: the [graph isomorphism problem](wikipedia://en/1950766) and certain [shortest vector problems](https://en.wikipedia.org/wiki/Shortest_vector_problem) (SVPs) in lattices. More precisely, an efficient quantum algorithm for the HSP for the [symmetric group](wikipedia://en/28901) would give a quantum algorithm for the graph isomorphism.[^o4] An efficient quantum algorithm for the HSP for the [dihedral group](wikipedia://en/100267) would give a quantum algorithm for the $\operatorname{poly}(n)$ unique SVP.[^o5]

## Quantum algorithms {#Quantum_algorithms}

There is an efficient [quantum algorithm](https://en.wikipedia.org/wiki/Quantum_algorithm) for solving HSP over finite [abelian groups](wikipedia://en/2974) in time polynomial in $\log|G|$. For arbitrary groups, it is known that the hidden subgroup problem is solvable using a polynomial number of evaluations of the oracle.[^o7] However, the circuits that implement this may be exponential in $\log|G|$, making the algorithm not efficient overall; efficient algorithms must be polynomial in the number of oracle evaluations and running time. The existence of such an algorithm for arbitrary groups is open. Quantum polynomial time algorithms exist for certain subclasses of groups, such as semi-direct products of some [abelian groups](wikipedia://en/2974).

### Algorithm for abelian groups {#Algorithm_for_abelian_groups}

The algorithm for abelian groups uses [representations](wikipedia://en/19378200), i.e. homomorphisms from $G$ to $\mathrm{GL}_k(\mathbb{C})$, the [general linear group](wikipedia://en/113564) over the [complex numbers](wikipedia://en/5826). A representation is irreducible if it cannot be expressed as the [direct product](wikipedia://en/8887) of two or more representations of $G$. For an abelian group, all the [irreducible representations](wikipedia://en/385982) are the [characters](wikipedia://en/691741), which are the representations of dimension one; there are no irreducible representations of larger dimension for abelian groups.

#### Defining the quantum fourier transform {#Defining_the_quantum_fourier_transform}

The [quantum fourier transform](wikipedia://en/30872292) can be defined in terms of $\mathrm{Z}_N$, the additive [cyclic group](wikipedia://en/52327) of order $N$. Introducing the character

$$\chi_j(k) = \omega^{jk}_N = e^{2\pi i \frac{jk}{N}},$$

the quantum fourier transform has the definition of

$$F_N |j\rangle = \frac{1}{\sqrt{N}} \sum_{k = 0}^{N-1} \chi_j(k) |k\rangle.$$

Furthermore, we define $|\chi_j\rangle = F_N |j\rangle$. Any finite abelian group can be written as the direct product of multiple cyclic groups $\mathrm{Z}_{N_1} \times \mathrm{Z}_{N_2} \times \ldots \times \mathrm{Z}_{N_m}$. On a quantum computer, this is represented as the tensor product of multiple registers of dimensions $N_1, N_2, \ldots, N_m$ respectively, and the overall quantum fourier transform is $F_{N_1} \otimes F_{N_2} \otimes \ldots \otimes F_{N_m}$.

::: {#o11 .definition kind=definition/construction cue=heading name="Procedure"}

#### Procedure {#Procedure}

The set of characters of $G$ forms a group $\widehat{G}$ called the [dual group](wikipedia://en/366136) of $G$. We also have a subgroup $H^\perp \leq \widehat{G}$ of size $|G|/|H|$ defined by

$$H^\perp = \{\chi_g : \chi_g(h) = 1\text{ for all }h \in H\}$$

For each iteration of the algorithm, the quantum circuit outputs an element $g \in G$ corresponding to a character $\chi_g \in H^\perp$, and since $\chi_g(h) = {1}$ for all $h \in H$, it helps to pin down what $H$ is.

The algorithm is as follows:

1. Start with the state $|0\rangle |0\rangle$, where the left register's basis states are each element of $G$, and the right register's basis states are each element of $X$.
1. Create a superposition among the basis states of $G$ in the left register, leaving the state $\frac{1}{\sqrt{|G|}} \sum_{g \in G} |g\rangle |0\rangle$.
1. Query the function $f$. The state afterwards is $\frac{1}{\sqrt{|G|}} \sum_{g \in G} |g\rangle |f(g)\rangle$.
1. Measure the output register. This gives some $f(s)$ for some $s \in G$, and collapses the state to $\frac{1}{\sqrt{|H|}} \sum_{h \in H} |s + h\rangle |f(s)\rangle$ because $f$ has the same value for each element of the coset $s + {H}$. We discard the output register to get $\frac{1}{\sqrt{|H|}} \sum_{h \in H} |s + h\rangle$.
1. Perform the quantum fourier transform, getting the state $\frac{1}{\sqrt{|H|}} \sum_{h\in H} |\chi_{s + h}\rangle$.
1. This state is equal to $\sqrt{\frac{|H|}{|G|}} \sum_{\chi_g \in H^\perp} \chi_g(s) |g\rangle$, which can be measured to learn information about $H$.
1. Repeat until $H$ (or a generating set for $H$) is determined.

The state in step 5 is equal to the state in step 6 because of the following:

$$\begin{aligned} \frac{1}{\sqrt{|H|}} \sum_{h \in H} |\chi_{s + h}\rangle &=\frac{1}{\sqrt{|H||G|}} \sum_{h \in H} \sum_{g \in G} \chi_{s + h}(g)|g\rangle \\ &=\frac{1}{\sqrt{|H||G|}} \sum_{g \in G} \chi_s(g) \sum_{h \in H} \chi_h(g)|g\rangle \\ &=\frac{1}{\sqrt{|H||G|}} \sum_{g \in G} \chi_g(s) \left(\sum_{h \in H} \chi_g(h)\right) |g\rangle \\ &=\sqrt{\frac{|H|}{|G|}} \sum_{\chi_g \in H^\perp} \chi_g(s) |g\rangle \end{aligned}$$

For the last equality, we use the following identity:

::: {#o12 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

$$\sum_{h \in H} \chi_g(h) = \begin{cases} |H| & \chi_g \in H^\perp \\ 0 & \chi_g \notin H^\perp \end{cases}$$

:::

::: {#o13 .proof cue=math-proof}

This can be derived from the orthogonality of characters. The characters of $G$ form an orthonormal basis for $H$ when restricted to it:

$$\frac{1}{\vert H\vert}\sum_{h \in H} \chi_g(h)\chi_{g'}(h) = \begin{cases} 1 & g' = g^{-1} \text{ on } H \\ 0 & g' \neq g^{-1} \text{ on } H \end{cases}$$

We let $\chi_{g'}$ be the trivial representation, which maps all inputs to $1$, to get

$$\sum_{h \in H} \chi_g(h) = \begin{cases} \vert H\vert & g\text{ is trivial} \\ 0 & g\text{ is not trivial}\end{cases}$$

Since the summation is done over $H$, $\chi_{g}$ also being trivial only matters for if it is trivial over $H$; that is, if $\chi_{g} \in H^\perp$. Thus, we know that the summation will result in $\vert H\vert$ if $\chi_g \in H^\perp$ and will result in $0$ if $\chi_g \notin H^\perp$.

:::

Each measurement of the final state will result in some information gained about $H$ since we know that $\chi_g(h) = 1$ for all $h \in H$. $H$, or a generating set for $H$, will be found after a polynomial number of measurements. The size of a generating set will be logarithmically small compared to the size of $G$. Let $T$ denote a generating set for $H$, meaning $\langle T\rangle = H$. The size of the subgroup generated by $T$ will at least be doubled when a new element $t \notin T$ is added to it, because $H$ and $t + H$ are disjoint and because $H \cup t+H \subseteq \langle \{t\}\cup T\rangle$. Therefore, the size of a generating set $|T|$ satisfies

$$|T| \leq \log|H| \leq \log|G|$$

Thus a generating set for $H$ will be able to be obtained in polynomial time even if $G$ is exponential in size.

:::

### Instances {#Instances}

Many algorithms where quantum speedups occur in quantum computing are instances of the hidden subgroup problem. The following list outlines important instances of the HSP, and whether or not they are solvable.

::: {#o15 .table cue=table}

| Problem | Quantum Algorithm | Abelian? | Polynomial time solution? |
|---|---|---|---|
| [Deutsch's problem](https://en.wikipedia.org/wiki/Deutsch–Jozsa_algorithm) | Deutsch's algorithm; Deutsch-Jozsa algorithm | Yes | Yes |
| [Simon's problem](https://en.wikipedia.org/wiki/Simon's_problem) | Simon's algorithm | Yes | Yes |
| Order finding | Shor's order finding algorithm | Yes | Yes |
| Discrete logarithm | Shor's algorithm | Yes | Yes |
| Period finding | Shor's algorithm | Yes | Yes |
| Abelian stabilizer | Kitaev's algorithm[^o18] | Yes | Yes |
| Graph Isomorphism | None | No | No |
| Shortest vector problem | None | No | No |

:::
