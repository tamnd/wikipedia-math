# Dual module

::: {#o1 .subject cue=lead name="Dual module"}

In [mathematics](wikipedia://en/18831), the **dual module** of a left (respectively right) [module](wikipedia://en/276410) *M* over a [ring](wikipedia://en/48404) *R* is the [set](wikipedia://en/26691) of [left (respectively right) *R*-module homomorphisms](wikipedia://en/474118) from *M* to *R* with the [pointwise](wikipedia://en/4786797) right (respectively left) module structure.[^o2][^o3] The dual module is typically denoted *M*<sup>∗</sup> or Hom<sub>*R*</sub>(*M*, *R*).

:::

If the base ring *R* is a [field](wikipedia://en/10603), then a dual module is a [dual vector space](https://en.wikipedia.org/wiki/Dual_vector_space).

Every module has a [canonical homomorphism](https://en.wikipedia.org/wiki/Canonical_homomorphism) to the dual of its dual (called the **double dual**). A [reflexive module](https://en.wikipedia.org/wiki/Reflexive_module) is one for which the canonical homomorphism is an [isomorphism](wikipedia://en/14828). A [torsionless module](wikipedia://en/27481586) is one for which the canonical homomorphism is [injective](wikipedia://en/45196).

::: {#o4 .example cue=inline-head name="Example"}

**Example**: If $G = \operatorname{Spec}(A)$ is a finite commutative [group scheme](wikipedia://en/510523) represented by a [Hopf algebra](wikipedia://en/325714) *A* over a [commutative ring](wikipedia://en/61346) *R*, then the [Cartier dual](https://en.wikipedia.org/wiki/Cartier_dual) $G^D$ is the Spec of the dual *R*-module of *A*.

:::
