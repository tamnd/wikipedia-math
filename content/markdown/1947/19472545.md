# Condensation point

::: {#o1 .subject cue=lead name="Condensation point"}

In [mathematics](wikipedia://en/18831), a **condensation point** *p* of a [subset](wikipedia://en/27631) *S* of a [topological space](wikipedia://en/30450) is any point *p* such that every [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) of *p* contains [uncountably many](https://en.wikipedia.org/wiki/Uncountably_many) points of *S*. Thus "condensation point" is synonymous with "$\aleph_1$-[accumulation point](wikipedia://en/226505)".[^o3]

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *S* = (0,1) is the open unit [interval](wikipedia://en/49172), a subset of the [real numbers](https://en.wikipedia.org/wiki/Real_numbers), then 0 is a condensation point of *S*.
- If *S* is an uncountable subset of a [set](wikipedia://en/26691) *X* endowed with the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology), then any point *p* of *X* is a condensation point of *X* as the only neighborhood of *p* is *X* itself.

:::
