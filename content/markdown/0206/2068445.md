# Costas array

::: {#o1 .subject cue=lead name="Costas array"}

*Image: HuitRois.png.*

In [mathematics](wikipedia://en/18831), a **Costas array** can be regarded [geometrically](wikipedia://en/18973446) as a set of *n* points, each at the center of a [square](wikipedia://en/659939) in an *n*×*n* [square tiling](wikipedia://en/2863809) such that each row or column contains only one point, and all of the *n*(*n* − 1)/2 [displacement](https://en.wikipedia.org/wiki/Displacement_%28vector%29) [vectors](wikipedia://en/32533) between each pair of dots are distinct. This results in an ideal "thumbtack" auto-[ambiguity function](wikipedia://en/1135333), making the arrays useful in applications such as [sonar](https://en.wikipedia.org/wiki/Sonar) and [radar](https://en.wikipedia.org/wiki/Radar). Costas arrays can be regarded as two-dimensional cousins of the one-dimensional [Golomb ruler](wikipedia://en/48211) construction, and, as well as being of mathematical interest, have similar applications in [experimental design](https://en.wikipedia.org/wiki/Experimental_design) and [phased array](https://en.wikipedia.org/wiki/Phased_array) radar engineering.

:::

Costas arrays are named after [John P. Costas](https://en.wikipedia.org/wiki/John_P._Costas_%28engineer%29), who first wrote about them in a 1965 technical report. Independently, [Edgar Gilbert](wikipedia://en/30980291) also wrote about them in the same year, publishing what is now known as the logarithmic Welch method of constructing Costas arrays.[^o2] The general enumeration of Costas arrays is an [open problem](wikipedia://en/1333335) in [computer science](https://en.wikipedia.org/wiki/Computer_science) and finding an algorithm that can solve it in [polynomial time](wikipedia://en/405944) is an [open research](https://en.wikipedia.org/wiki/Open_research) question.

## Numerical representation {#Numerical_representation}

A Costas array may be represented numerically as an *n*×*n* array of numbers, where each entry is either 1, for a point, or 0, for the absence of a point. When interpreted as [binary matrices](wikipedia://en/4109196), these arrays of numbers have the property that, since each row and column has the constraint that it only has one point on it, they are therefore also [permutation matrices](wikipedia://en/238849). Thus, the Costas arrays for any given *n* are a subset of the permutation matrices of order *n*.

Arrays are usually described as a series of indices specifying the column for any row. Since it is given that any column has only one point, it is possible to represent an array one-dimensionally. For instance, the following is a valid Costas array of order *N* = 4:

$\begin{array}{|c|c|c|c|}\hline0&0&0&1\\\hline0&0&1&0\\\hline1&0&0&0\\\hline0&1&0&0\\\hline\end{array}$ or simply $\begin{array}{|c|c|c|c|}\hline&&&\bullet\\\hline&&\bullet&\\\hline\bullet&&&\\\hline&\bullet&&\\\hline\end{array}$

There are dots at coordinates: (1,2), (2,1), (3,3), (4,4)

Since the *x*-coordinate increases linearly, we can write this in shorthand as the set of all *y*-coordinates. The position in the set would then be the *x*-coordinate. Observe: {2,1,3,4} would describe the aforementioned array. This defines a permutation. This makes it easy to communicate the arrays for a given order of *N*.

Enumeration of known Costas arrays to order 200,[^n1] order 500[^n2] and to order 1030[^o8] are available. Although these lists and databases of these Costas arrays are likely near complete, other Costas arrays with orders above 29 that are not in these lists may exist. In general, the currently best known upper bound on the number $C(n)$ of Costas arrays of order $n$ is of asymptotic form $C(n)/n! \le e^{-\Theta(n)}$.[^n3]

## Constructions {#Constructions}

Several constructions exist for systematically producing Costas arrays for arbitrarily large $n$. However, they only produce Costas arrays for some $n$, and they do not produce all possible Costas arrays.

::: {#o13 .pointer-item cue=pointer name="Welch-Costas array"}

### Welch {#Welch}

A **Welch–Costas array**, or just Welch array, is a Costas array generated using the following method, first discovered by [Edgar Gilbert](wikipedia://en/30980291) in 1965 and rediscovered in 1982 by [Lloyd R. Welch](https://en.wikipedia.org/wiki/Lloyd_R._Welch). The Welch–Costas array is constructed by taking a [primitive root](wikipedia://en/186864) *g* of a [prime number](wikipedia://en/23666) *p* and defining the array *A* by $A_{i,j} = 1$ if $j \equiv g^i \bmod p$, otherwise 0. The result is a Costas array of size *p* − 1.

Example:

3 is a primitive element modulo 5.

3<sup>1</sup> = 3 ≡ 3 (mod 5)

3<sup>2</sup> = 9 ≡ 4 (mod 5)

3<sup>3</sup> = 27 ≡ 2 (mod 5)

3<sup>4</sup> = 81 ≡ 1 (mod 5)

Therefore, \[3 4 2 1\] is a Costas permutation. More specifically, this is an exponential Welch array. The transposition of the array is a logarithmic Welch array.

The number of Welch–Costas arrays which exist for a given size depends on the [totient function](wikipedia://en/53452).

:::

### Lempel–Golomb {#Lempel–Golomb}

The Lempel–Golomb construction, introduced by [Abraham Lempel](https://en.wikipedia.org/wiki/Abraham_Lempel) and [Solomon W. Golomb](wikipedia://en/1860707), takes α and β to be [primitive elements](wikipedia://en/19127149) of the [finite field](wikipedia://en/11615) GF(*q*) and similarly defines $A_{i,j} = 1$ if $\alpha^i + \beta^j = 1$, otherwise 0. The result is a Costas array of size *q* − 2. If *α* + *β* = 1 then the first row and column may be deleted to form another Costas array of size *q* − 3: such a pair of primitive elements exists for every [prime power](wikipedia://en/1630483) *q>2*.

### Extensions by Taylor, Lempel, and Golomb {#Extensions_by_Taylor,_Lempel,_and_Golomb}

Generation of new Costas arrays by adding or subtracting a row/column or two with a 1 or a pair of 1's in a corner were published in a paper focused on generation methods[^n4] and in Golomb and Taylor's landmark 1984 paper.[^n5]

More sophisticated methods of generating new Costas arrays by deleting rows and columns of existing Costas arrays that were generated by the Welch, Lempel or Golomb generators were published in 1992.[^n6] There is no upper limit on the order for which these generators will produce Costas arrays.

### Other methods {#Other_methods}

Two methods that found Costas arrays up to order 52 using more complicated methods of adding or deleting rows and columns were published in 2004[^n7] and 2007.[^n8]

:::

::: {#o23 .statement kind=statement/generalization cue=heading name="Variants"}

## Variants {#Variants}

Costas arrays on a [hexagonal lattice](wikipedia://en/2868762) are known as *honeycomb arrays*. It has been shown that there are only finitely many such arrays, which must have an odd number of elements, arranged in the shape of a hexagon. Currently, 12 such arrays (up to symmetry) are known, which has been conjectured to be the total number.[^o24]

Golomb and Taylor noted that a small number of Costas arrays have the property that no two points are diagonally adjacent to each other.[^n5] These are known as *non-attacking kings Costas arrays* (NAKCAs), since placing a [chess](https://en.wikipedia.org/wiki/Chess) [king](https://en.wikipedia.org/wiki/King_%28chess%29) at each point results in a configuration where no two kings attack each other. A subset of NAKCAs are generated systematically using a variant of the Lempel–Golomb construction. A stronger condition defines the *non-attacking queens Costas arrays* (NAQCAs), which are Costas arrays which are also solutions to the [*n* queens problem](wikipedia://en/10474). The only known NAQCA is the trivial 1×1 Costas array, and it is conjectured that no others exist.[^o26]

:::
