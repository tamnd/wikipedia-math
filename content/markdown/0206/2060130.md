# K-function

::: {#o1 .subject cue=lead name="K-function"}

In [mathematics](wikipedia://en/18831), the **$K$-function**, typically denoted *K*(*z*), is a generalization of the [hyperfactorial](wikipedia://en/507209) to [complex numbers](wikipedia://en/5826), similar to the generalization of the [factorial](wikipedia://en/10606) to the [gamma function](wikipedia://en/12316).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

There are multiple equivalent definitions of the $K$-function.

The direct definition:

$$K(z)=(2\pi)^{-\frac{z-1}2} \exp\left[\binom{z}{2}+\int_0^{z-1} \ln \Gamma(t + 1)\,dt\right].$$

Definition via

$$K(z)=\exp\bigl[\zeta'(-1,z)-\zeta'(-1)\bigr]$$

where $\zeta'(z)$ denotes the [derivative](wikipedia://en/7921) of the [Riemann zeta function](wikipedia://en/25809), $\zeta(a,z)$ denotes the [Hurwitz zeta function](wikipedia://en/406952) and

$$\zeta'(a,z)\ \stackrel{\mathrm{def}}{=}\ \left.\frac{\partial\zeta(s,z)}{\partial s}\right|_{s=a},\ \ \zeta(s,q) = \sum_{k=0}^\infty (k+q)^{-s}$$

Definition via [polygamma function](wikipedia://en/406932):[^o4]

$$K(z)=\exp\left[\psi^{(-2)}(z)+\frac{z^2-z}{2}-\frac {z}{2} \ln 2\pi \right]$$

Definition via [balanced generalization of the polygamma function](https://en.wikipedia.org/wiki/Generalized_polygamma_function):[^o5]

$$K(z)=A \exp\left[\psi(-2,z)+\frac{z^2-z}{2}\right]$$

where $A$ is the [Glaisher constant](https://en.wikipedia.org/wiki/Glaisher_constant).

It can be defined via unique characterization, similar to how the [gamma function](wikipedia://en/12316) can be uniquely characterized by the [Bohr-Mollerup Theorem](wikipedia://en/780918):

> Let $f: (0, \infty) \to \mathbb{R}$ be a solution to the [functional equation](wikipedia://en/364377) $f(x+1) - f(x)=x\ln x$, such that there exists some $M > 0$, such that given any distinct $x_0, x_1, x_2, x_3 \in (M, \infty)$, the [divided difference](wikipedia://en/976365) $f[x_0, x_1, x_2, x_3] \geq 0$.
>
> Such functions are precisely $f = \ln K + C$, where $C$ is an arbitrary constant.[^o6]

:::

## Properties {#Properties}

For $\alpha > 0$:

$$\int_\alpha^{\alpha+1}\ln K(x)\,dx-\int_0^1\ln K(x)\,dx=\tfrac{1}{2}\alpha^2\left(\ln\alpha-\tfrac{1}{2}\right)$$

::: {#o9 .proof cue=collapse name="Proof"}

::: {#o10 .proof cue=math-proof name="Proof"}

**Proof.**

Let $f(\alpha)=\int_\alpha^{\alpha+1}\ln K(x)\,dx$

Differentiating this identity now with respect to $\alpha$ yields:

$$f'(\alpha)=\ln K(\alpha+1)-\ln K(\alpha)$$

Applying the logarithm rule we get

$$f'(\alpha)=\ln\frac{K(\alpha+1)}{K(\alpha)}$$

By the definition of the $K$-function we write

$$f'(\alpha)=\alpha\ln\alpha$$

And so

$$f(\alpha)=\tfrac12\alpha^2\left(\ln\alpha-\tfrac12\right)+C$$

Setting $\alpha = 0$ we have

$$\int_0^1 \ln K(x)\,dx=\lim_{t\rightarrow0}\left[\tfrac12 t^2\left(\ln t-\tfrac12\right)\right]+C \ =C$$

:::

### Functional equations {#Functional_equations}

The $K$-function is closely related to the [gamma function](wikipedia://en/12316) and the [Barnes $G$-function](wikipedia://en/2060183). For all complex $z$,

$$K(z) G(z)=e^{(z-1) \ln \Gamma(z)}$$

::: {#o13 .statement cue=named-heading name="Multiplication formula"}

### Multiplication formula {#Multiplication_formula}

Similar to the [multiplication formula for the gamma function](wikipedia://en/4239318#Products):

$$\prod_{j=1}^{n-1}\Gamma\left(\frac jn \right) = \sqrt{\frac{(2\pi)^{n-1}}{n}}$$

there exists a multiplication formula for the K-Function involving [Glaisher's constant](wikipedia://en/2076831):[^o14]

$$\prod_{j=1}^{n-1}K\left(\frac jn \right) = A^{\frac{n^2-1}{n}}n^{-\frac{1}{12n}}e^{\frac{1-n^2}{12n}}$$

:::

### Integer values {#Integer_values}

For all non-negative integers,

$$K(n+1)=1^1 \cdot 2^2 \cdot 3^3 \cdots n^n = H(n)$$

where $H$ is the [hyperfactorial](wikipedia://en/507209).

The first values are

1, 4, 108, 27648, 86400000, 4031078400000, 3319766398771200000, ... .
