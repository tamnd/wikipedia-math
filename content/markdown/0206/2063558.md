# Symplectic integrator

::: {#o1 .subject cue=lead name="Symplectic integrator"}

In [mathematics](wikipedia://en/18831), a **symplectic integrator** (**SI**) is a [numerical integration scheme](https://en.wikipedia.org/wiki/Numerical_ordinary_differential_equations) for [Hamiltonian systems](wikipedia://en/1197531). Symplectic integrators form the subclass of [geometric integrators](wikipedia://en/2208188) which, by definition, are [canonical transformations](wikipedia://en/514534). They are widely used in [nonlinear dynamics](https://en.wikipedia.org/wiki/Nonlinear_dynamics), [molecular dynamics](wikipedia://en/198608), [discrete element methods](wikipedia://en/63473), [accelerator physics](https://en.wikipedia.org/wiki/Particle_accelerator), [plasma physics](https://en.wikipedia.org/wiki/Plasma_physics), [quantum physics](https://en.wikipedia.org/wiki/Quantum_physics), and [celestial mechanics](wikipedia://en/102182).

:::

## Introduction {#Introduction}

Symplectic integrators are designed for the numerical solution of [Hamilton's equations](https://en.wikipedia.org/wiki/Hamilton's_equations), which read

$$\dot p = -\frac{\partial H}{\partial q} \quad\mbox{and}\quad \dot q = \frac{\partial H}{\partial p},$$

where $q$ denotes the position coordinates, $p$ the momentum coordinates, and $H$ is the Hamiltonian. The set of position and momentum coordinates $(q,p)$ are called [canonical coordinates](wikipedia://en/706311). (See [Hamiltonian mechanics](wikipedia://en/198319) for more background.)

The [time evolution](wikipedia://en/937739) of [Hamilton's equations](https://en.wikipedia.org/wiki/Hamilton's_equations) is a [symplectomorphism](wikipedia://en/312304), meaning that it conserves the symplectic [2-form](https://en.wikipedia.org/wiki/2-form) $dp \wedge dq$. A numerical scheme is a symplectic integrator if it also conserves this 2-form.

Symplectic integrators possess, as a conserved quantity, a Hamiltonian which is slightly [perturbed](wikipedia://en/102140) from the original one.[^o3] By virtue of these advantages, the SI scheme has been widely applied to the calculations of long-term evolution of chaotic Hamiltonian systems ranging from the [Kepler problem](wikipedia://en/2410571) to the classical and semi-classical simulations in [molecular dynamics](wikipedia://en/198608).

Most of the usual numerical methods, such as the primitive [Euler scheme](https://en.wikipedia.org/wiki/Euler_integration) and the classical [Runge–Kutta scheme](wikipedia://en/213671), are not symplectic integrators.

## Methods for constructing symplectic algorithms {#Methods_for_constructing_symplectic_algorithms}

### Splitting methods for separable Hamiltonians {#Splitting_methods_for_separable_Hamiltonians}

A widely used class of symplectic integrators is formed by the splitting methods.

Assume that the Hamiltonian is separable, meaning that it can be written in the form

::: {#o6 .equation cue=numblk name="1"}

$$H(p,q) = T(p) + V(q). \tag{1}$$

:::

This happens frequently in Hamiltonian mechanics, with $T$ being the [kinetic energy](wikipedia://en/17327) and $V$ the [potential energy](wikipedia://en/23703).

For the notational simplicity, let us introduce the symbol $z=(q,p)$ to denote the canonical coordinates including both the position and momentum coordinates. Then, the set of the Hamilton's equations given in the introduction can be expressed in a single expression as

::: {#o7 .equation cue=numblk name="2"}

$$\dot{z} = \{z,H(z)\}, \tag{2}$$

:::

where $\{\cdot, \cdot\}$ is a [Poisson bracket](wikipedia://en/294340). Furthermore, by introducing an operator $D_H \cdot = \{\cdot, H\}$, which returns a [Poisson bracket](wikipedia://en/294340) of the operand with the [Hamiltonian](wikipedia://en/198319#Mathematical_formalism), the expression of the Hamilton's equation can be further simplified to

$$\dot{z} = D_H z.$$

The formal solution of this set of equations at time $t$ is given as a [matrix exponential](wikipedia://en/672731):

::: {#o8 .equation cue=numblk name="3"}

$$z(t) = \exp(t D_H) \, z(0). \tag{3}$$

:::

Note the positivity of $t D_H$ in the matrix exponential.

When the Hamiltonian has the form of equation ((1)), the solution ((3)) is equivalent to

::: {#o9 .equation cue=numblk name="4"}

$$z(t) = \exp\left[t (D_T + D_V)\right] \, z(0). \tag{4}$$

:::

The SI scheme approximates the time-evolution operator $\exp[t (D_T + D_V)]$ in the formal solution ((4)) by a product of operators as

::: {#o10 .equation cue=numblk name="5"}

$$\begin{aligned} \exp[t (D_T + D_V)] & = \prod_{i=k, \dots, 1} \exp(t d_i D_T) \exp(t c_i D_V) + O(t^{k+1}) \\ &= \exp(t d_k D_T) \exp(t c_k D_V) \cdots \exp(t d_1 D_T) \exp(t c_1 D_V) + O(t^{k+1}), \end{aligned} \tag{5}$$

:::

where $c_i$ and $d_i$ are real numbers, $k$ is an integer, which is called the order of the integrator, and where $\sum_{i=1}^k c_i = \sum_{i=1}^k d_i = 1$. Note that each of the operators $\exp(t c_i D_V)$ and $\exp(t d_i D_T)$ provides a [symplectic map](wikipedia://en/312304), so their product appearing in the right-hand side of ((5)) also constitutes a symplectic map.

Since $D_T^2 z = \{\{z,T\},T\} = \{(\dot{q}, 0),T\} = (0,0)$ for all $z$, we can conclude that

::: {#o11 .equation cue=numblk name="6"}

$$D_T^2 = 0. \tag{6}$$

:::

By using a [Taylor series](wikipedia://en/30448), $\exp(a D_T)$ can be expressed as

::: {#o12 .equation cue=numblk name="7"}

$$\exp(a D_T) = \sum_{n=0}^\infty \frac{{\left(a D_T\right)}^n}{n!}, \tag{7}$$

:::

where $a$ is an arbitrary [real number](wikipedia://en/20646438). Combining ((6)) and ((7)), and by using the same reasoning for $D_V$ as we have used for $D_T$, we get

::: {#o13 .equation cue=numblk name="8"}

$$\begin{cases} \exp(a D_V) = 1 + a D_V, \\[2pt] \exp(a D_T) = 1 + a D_T. \end{cases} \tag{8}$$

:::

In concrete terms, $\exp(t c_i D_V)$ gives the mapping

$$\begin{pmatrix} q \\ p \end{pmatrix} \mapsto \begin{pmatrix} q \\ p - t c_i \frac{\partial V}{\partial q}(q) \end{pmatrix},$$

and $\exp(t d_i D_T)$ gives

$$\begin{pmatrix} q \\ p \end{pmatrix} \mapsto \begin{pmatrix} q + t d_i \frac{\partial T}{\partial p}(p) \\ p \end{pmatrix}.$$

Note that both of these maps are practically computable.

::: {#o15 .definition kind=definition/construction cue=heading name="Algorithm"}

#### Algorithm {#Algorithm}

In each time step, the general algorithm for this class of symplectic integrators maps some initial state $(q_0, p_0)$ to the state $(q_k, p_k)$ one timestep $t$ later. This is done through the sequence of substeps $(q_0, p_0) \mapsto (q_1, p_1) \mapsto \dots \mapsto (q_{k-1}, p_{k-1}) \mapsto (q_k, p_k)$. For every $i = 1, \dots, k$, the following equations are used to compute the substep $(q_{i-1}, p_{i-1}) \mapsto (q_i, p_i)$:

$$\begin{aligned} p_i &= p_{i-1} + t c_i F(q_{i-1}) \\[1ex] q_i &= q_{i-1} + t d_i \frac{p_i}{m} \end{aligned}$$

where $q$ is the position, $p$ is the momentum, $F(q) = -\tfrac{\partial V}{\partial q}(q)$ is the force vector at $q$, and $m$ is the scalar quantity of mass.

Equivalently, after converting into Lagrangian coordinates, each substep becomes

$$\begin{aligned} v_i &= v_{i-1} + t c_i a(x_{i-1}) \\[1ex] x_i &= x_{i-1} + t d_i v_i \end{aligned}$$

where $x$ is the position, $v$ is the velocity, and $a(x)$ is the acceleration vector at $x$.

Several symplectic integrators are given below.

:::

#### A first-order example {#A_first-order_example}

The [symplectic Euler method](https://en.wikipedia.org/wiki/Symplectic_Euler_method) is the first-order integrator with $k=1$ and coefficients

$$c_1 = d_1 = 1.$$

Note that the algorithm above does not work if time-reversibility is needed. The algorithm has to be implemented in two parts, one for positive time steps, one for negative time steps.

#### A second-order example {#A_second-order_example}

The [Verlet method](wikipedia://en/825735) is the second-order symplectic integrator with $k=2$ and coefficients

$$c_1 = \tfrac{1}{2}, \qquad d_1 = 1, \qquad c_2 = \tfrac{1}{2}, \qquad d_2 = 0.$$

Note that the coefficients

$$c_1 = 0, \qquad d_1 = \tfrac{1}{2}, \qquad c_2 = 1, \qquad d_2 = \tfrac{1}{2}$$

also form a second-order symplectic integrator[^o22][^o23], which is the Verlet method but shifted by half a time step $t$.

Since $d_2 = 0$ in the first set of coefficients and $c_1 = 0$ in the second set of coefficients, in both algorithms above one update can be ignored. There are thus only 3 steps to the algorithm, and step 1 and 3 are exactly the same, leading to the algorithm being symmetric in time, so the positive time version can also be used for negative time.

#### A third-order example {#A_third-order_example}

A third-order symplectic integrator (with $k=3$) was discovered by Ronald Ruth in 1983.[^o19] One of the many solutions is given by

$$\begin{aligned} c_1 &= \tfrac{7}{24}, & c_2 &= \tfrac{3}{4}, & c_3 &= -\tfrac{1}{24}, \\[1ex] d_1 &= \tfrac{2}{3}, & d_2 &= -\tfrac{2}{3}, & d_3 &= 1. \end{aligned}$$

#### A fourth-order example {#A_fourth-order_example}

A fourth-order integrator (with $k=4$) was also discovered by Ruth in 1983 and distributed privately to the particle-accelerator community at that time. This was described in a lively review article by Forest.[^o21] This fourth-order integrator was published in 1990 by Forest and Ruth and also independently discovered by two other groups around that same time:[^o22][^o23][^o24]

$$\begin{aligned} c_1 &= c_4 = \frac{1}{2 \left(2-2^{1/3}\right)}, & c_2 &= c_3 = \frac{1 - 2^{1/3}}{2\left(2 - 2^{1/3}\right)}, \\[1ex] d_1 &= d_3 = \frac{1}{2-2^{1/3}}, & d_2 &= -\frac{2^{1/3}}{2-2^{1/3}}, \qquad d_4 = 0, \end{aligned}$$

or alternatively,

$$\begin{aligned} c_1 &= 0, \qquad c_3 = -\frac{2^{1/3}}{2-2^{1/3}}, & c_2 &= c_4 = \frac{1}{2-2^{1/3}}, \\[1ex] d_1 &= d_4 = \frac{1}{2 \left(2-2^{1/3}\right)}, & d_2 &= d_3 = \frac{1 - 2^{1/3}}{2\left(2 - 2^{1/3}\right)}. \end{aligned}$$

To determine these coefficients, the [Baker–Campbell–Hausdorff formula](wikipedia://en/285422) can be used. [Yoshida](https://en.wikipedia.org/wiki/Haruo_Yoshida), in particular, gives an elegant derivation of coefficients for [higher-order integrators](wikipedia://en/15066189#Yoshida_algorithms).[^o23] Later on, Blanes and Moan[^o25] further developed partitioned [Runge–Kutta methods](wikipedia://en/213671) for the integration of systems with separable Hamiltonians with very small error constants. [Numerov%27s method](https://en.wikipedia.org/wiki/Numerov%27s_method), developed by the Russian astronomer [Boris Vasil'evich Numerov](https://en.wikipedia.org/wiki/Boris_Vasil'evich_Numerov) in 1924, is also a fourth-order symplectic integrator.[^o26]

### Splitting methods for general nonseparable Hamiltonians {#Splitting_methods_for_general_nonseparable_Hamiltonians}

General nonseparable Hamiltonians can also be explicitly and symplectically integrated.

To do so, Tao introduced a restraint that binds two copies of phase space together to enable an explicit splitting of such systems.[^o28] The idea is, instead of $H(Q,P)$, one simulates

$$\bar{H}(q,p,x,y) = H(q,y) + H(x,p) + \omega \left( \tfrac{1}{2} {\left\|q-x\right\|}_2^2 + \tfrac{1}{2} {\left\|p-y\right\|}_2^2\right),$$

whose solution agrees with that of $H(Q,P)$ in the sense that $q(t) = x(t) = Q(t)$, $p(t) = y(t) = P(t)$.

The new Hamiltonian is advantageous for explicit symplectic integration, because it can be split into the sum of three sub-Hamiltonians, $H_A = H(q,y)$, $H_B=H(x,p)$, and $H_C = \omega \left(\frac{1}{2}\left\|q-x\right\|_2^2 + \frac{1}{2} \left\|p-y\right\|_2^2\right)$. Exact solutions of all three sub-Hamiltonians can be explicitly obtained: both $H_A, H_B$ solutions correspond to shifts of mismatched position and momentum, and $H_C$ corresponds to a linear transformation. To symplectically simulate the system, one simply composes these solution maps.

## Applications {#Applications}

### In plasma physics {#In_plasma_physics}

In recent decades symplectic integrator in plasma physics has become an active research topic,[^o32] because straightforward applications of the standard symplectic methods do not suit the need of large-scale plasma simulations enabled by the peta- to exa-scale computing hardware. Special symplectic algorithms need to be customarily designed, tapping into the special structures of the physics problem under investigation. One such example is the [charged particle](https://en.wikipedia.org/wiki/Charged_particle) dynamics in an [electromagnetic field](https://en.wikipedia.org/wiki/Electromagnetic_field). With the canonical symplectic structure, the Hamiltonian of the dynamics is

$$H(\boldsymbol{p},\boldsymbol{x}) = \tfrac{1}{2} \left(\boldsymbol{p}-\boldsymbol{A}\right)^2 + \phi,$$

whose $\boldsymbol{p}$-dependence and $\boldsymbol{x}$-dependence are not separable, and standard explicit symplectic methods do not apply. For large-scale simulations on massively parallel clusters, however, explicit methods are preferred. To overcome this difficulty, we can explore the specific way that the $\boldsymbol{p}$-dependence and $\boldsymbol{x}$-dependence are entangled in this Hamiltonian, and try to design a symplectic algorithm just for this or this type of problem. First, we note that the $\boldsymbol{p}$-dependence is quadratic, therefore the first order symplectic Euler method implicit in $\boldsymbol{p}$ is actually explicit. This is what is used in the canonical symplectic [particle-in-cell](https://en.wikipedia.org/wiki/Particle-in-cell) (PIC) algorithm.[^o33] To build high order explicit methods, we further note that the $\boldsymbol{p}$-dependence and $\boldsymbol{x}$-dependence in this $H(\boldsymbol{p},\boldsymbol{x})$ are product-separable, 2nd and 3rd order explicit symplectic algorithms can be constructed using generating functions,[^o34] and arbitrarily high-order explicit symplectic integrators for time-dependent electromagnetic fields can also be constructed using Runge-Kutta techniques.[^o35]

A more elegant and versatile alternative is to look at the following non-canonical symplectic structure of the problem,

$$\begin{aligned} i_{(\dot{\boldsymbol{x}},\dot{\boldsymbol{v}})} \Omega &= -dH, \\ \Omega &= d(\boldsymbol{v}+\boldsymbol{A}) \wedge d\boldsymbol{x}, \\[1ex] H &= \tfrac{1}{2}\boldsymbol{v}^{2}+\phi. \end{aligned}$$

Here $\Omega$ is a non-constant non-canonical symplectic form. General symplectic integrator for non-constant non-canonical symplectic structure, explicit or implicit, is not known to exist. However, for this specific problem, a family of high-order explicit non-canonical symplectic integrators can be constructed using the He splitting method.[^o36] Splitting $H$ into 4 parts,

$$H = H_x + H_y + H_z + H_\phi,$$

$$\begin{aligned} H_x &= \tfrac{1}{2} v_x^2, & H_y &= \tfrac{1}{2} v_y^2, \\[2pt] H_z &= \tfrac{1}{2} v_z^2, & H_\phi &= \phi, \end{aligned}$$

we find serendipitously that for each subsystem, e.g.,

$$i_{(\dot{\boldsymbol{x}},\dot{\boldsymbol{v}})}\Omega=-dH_{x}$$

and

$$i_{(\dot{\boldsymbol{x}},\dot{\boldsymbol{v}})} \Omega = -dH_{\phi},$$

the solution map can be written down explicitly and calculated exactly. Then explicit high-order non-canonical symplectic algorithms can be constructed using different compositions. Let $\Theta_{x},\Theta_{y},\Theta_{z}$ and $\Theta_{\phi}$ denote the exact solution maps for the 4 subsystems. A 1st-order symplectic scheme is

$$\begin{aligned} \Theta_1{\left(\Delta\tau\right)} = \Theta_x{\left(\Delta\tau\right)} \, \Theta_y{\left(\Delta\tau\right)} \, \Theta_z{\left(\Delta\tau\right)} \, \Theta_\phi{\left(\Delta\tau\right)} \,. \end{aligned}$$

A symmetric 2nd-order symplectic scheme is,

$$\begin{aligned} \Theta_2{\left(\Delta\tau\right)} = {} & \Theta_x{\left(\tfrac{\Delta\tau}{2}\right)} \, \Theta_y{\left(\tfrac{\Delta\tau}{2}\right)} \, \Theta_z{\left(\tfrac{\Delta\tau}{2}\right)} \, \Theta_\phi{\left(\Delta\tau\right)} \\ & \Theta_z{\left(\tfrac{\Delta t}{2}\right)} \, \Theta_y{\left(\tfrac{\Delta t}{2}\right)} \, \Theta_x{\left(\tfrac{\Delta t}{2}\right)}, \end{aligned}$$

which is a customarily modified [Strang splitting](wikipedia://en/44583545). A $2(\ell+1)$-th order scheme can be constructed from a $2\ell$-th order scheme using the method of triple jump,

$$\Theta_{2(\ell+1)}(\Delta\tau) = \Theta_{2\ell}(\alpha_{\ell}\Delta\tau) \, \Theta_{2\ell}(\beta_{\ell}\Delta\tau) \, \Theta_{2\ell}(\alpha_{\ell}\Delta\tau) \, ,$$

$$\begin{aligned} \alpha_{\ell} & = \frac{1}{2-2^{1/(2\ell+1)}}, & \beta_{\ell} & = 1 - 2\alpha_{\ell}\,. \end{aligned}$$

The He splitting method is one of key techniques used in the structure-preserving geometric [particle-in-cell](https://en.wikipedia.org/wiki/Particle-in-cell) (PIC) algorithms.[^o37][^o38][^o39][^o40]
