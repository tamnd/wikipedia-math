# Lebesgue's lemma

::: {#o1 .subject cue=lead name="Lebesgue's lemma"}

In [mathematics](wikipedia://en/18831), **Lebesgue's lemma** is an important statement in [approximation theory](wikipedia://en/1092713). It provides a bound for the projection error, controlling the error of approximation by a linear subspace based on a linear projection relative to the optimal error together with the [operator norm](wikipedia://en/246722) of the projection.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $(V, ||\cdot||)$ be a [normed vector space](wikipedia://en/21538), $U$ a subspace of $V$, and $P$ a [linear projector](wikipedia://en/519182) on $U$. Then for each $v$ in $V$:

$$\|v-Pv\|\leq (1+\|P\|)\inf_{u\in U}\|v-u\|.$$

The proof is a one-line application of the [triangle inequality](wikipedia://en/53941): for any $u$ in $U$, by writing $v - Pv$ as $(v - u) + (u - Pu) + P(u - v)$, it follows that

$$\|v-Pv\|\leq\|v-u\|+\|u-Pu\|+\|P(u-v)\|\leq(1+\|P\|)\|u-v\|$$

where the last inequality uses the fact that $u = Pu$ together with the definition of the [operator norm](wikipedia://en/246722) $||P||$.

:::
