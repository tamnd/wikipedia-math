# Tent map

::: {#o1 .subject cue=lead name="Tent map"}

*Image: Tent map 2.png.* Graph of tent map function

*Image: Tent map.gif.* Example of iterating the initial condition *x*<sub>0</sub> = 0.4 over the tent map with μ = 1.9.

In [mathematics](wikipedia://en/18831), the **tent map** with parameter μ is the [real](wikipedia://en/20646438)-valued [function](wikipedia://en/185427) *f*<sub>μ</sub> defined by

:::

$$f_\mu(x) := \mu\min\{x,\,1-x\},$$

the name being due to the [tent](https://en.wikipedia.org/wiki/Tent)-like shape of the [graph](wikipedia://en/87352) of *f*<sub>μ</sub>. For the values of the parameter μ within 0 and 2, *f*<sub>μ</sub> [maps](wikipedia://en/579311) the [unit interval](wikipedia://en/49324) \[0, 1\] into itself, thus defining a [discrete-time](https://en.wikipedia.org/wiki/Discrete-time) [dynamical system](wikipedia://en/9087) on it (equivalently, a [recurrence relation](wikipedia://en/146806)). In particular, [iterating](wikipedia://en/1448702) a point *x*<sub>0</sub> in \[0, 1\] gives rise to a sequence $x_n$:

$$x_{n+1} = f_\mu(x_n) = \begin{cases} \mu x_n & \mathrm{for}~~ x_n < \frac{1}{2} \\ \mu (1-x_n) & \mathrm{for}~~ \frac{1}{2} \le x_n \end{cases}$$

where μ is a positive real constant. Choosing for instance the parameter μ = 2, the effect of the function *f*<sub>μ</sub> may be viewed as the result of the operation of folding the unit interval in two, then stretching the resulting [interval](wikipedia://en/49172) \[0, 1/2\] to get again the interval \[0, 1\]. Iterating the procedure, any point *x*<sub>0</sub> of the interval assumes new subsequent positions as described above, generating a sequence *x*<sub>*n*</sub> in \[0, 1\].

The $\mu=2$ case of the tent map is a non-linear transformation of both the [bit shift map](https://en.wikipedia.org/wiki/Bit_shift_map) and the *r* = 4 case of the [logistic map](wikipedia://en/18137).

## Behaviour {#Behaviour}

*Image: Tent-map.png.* Orbits of unit-height tent map

*Image: TentMap BifurcationDiagram.png.* Bifurcation diagram for the tent map. Higher density indicates increased probability of the *x* variable acquiring that value for the given value of the μ parameter.

The tent map with parameter μ = 2 and the [logistic map](wikipedia://en/18137) with parameter *r* = 4 are [topologically conjugate](https://en.wikipedia.org/wiki/Topologically_conjugate),[^o3] and thus the behaviours of the two maps are in this sense identical under iteration.

Depending on the value of μ, the tent map demonstrates a range of dynamical behaviour ranging from predictable to chaotic.

- If μ is less than 1 the point *x* = 0 is an [attractive](wikipedia://en/191094) [fixed point](wikipedia://en/449738) of the system for all initial values of *x* i.e. the system will converge towards *x* = 0 from any initial value of *x*.
- If μ is 1 all values of *x* less than or equal to 1/2 are fixed points of the system.
- If μ is greater than 1 the system has two fixed points, one at 0, and the other at μ/(μ + 1). Both fixed points are unstable, i.e. a value of *x* close to either fixed point will move away from it, rather than towards it. For example, when μ is 1.5 there is a fixed point at *x* = 0.6 (since 1.5(1 − 0.6) = 0.6) but starting at *x* = 0.61 we get

$$0.61 \to 0.585 \to 0.6225 \to 0.56625 \to 0.650625 \ldots$$

- If μ is between 1 and the [square root of 2](wikipedia://en/341682) the system maps a set of intervals between μ − μ<sup>2</sup>/2 and μ/2 to themselves. This set of intervals is the [Julia set](wikipedia://en/56434) of the map – that is, it is the smallest invariant subset of the real line under this map. If μ is greater than the square root of 2, these intervals merge, and the Julia set is the whole interval from μ − μ<sup>2</sup>/2 to μ/2 (see bifurcation diagram).
- If μ is between 1 and 2 the interval \[μ − μ<sup>2</sup>/2, μ/2\] contains both periodic and non-periodic points, although all of the [orbits](wikipedia://en/252250) are unstable (i.e. nearby points move away from the orbits rather than towards them). Orbits with longer lengths appear as μ increases. For example:

$$\frac{\mu}{\mu^2+1} \to \frac{\mu^2}{\mu^2+1} \to \frac{\mu}{\mu^2+1} \mbox{ appears at } \mu=1$$

$$\frac{\mu}{\mu^3+1} \to \frac{\mu^2}{\mu^3+1} \to \frac{\mu^3}{\mu^3+1} \to \frac{\mu}{\mu^3+1} \mbox{ appears at } \mu=\frac{1+\sqrt{5}}{2}$$

$$\frac{\mu}{\mu^4+1} \to \frac{\mu^2}{\mu^4+1} \to \frac{\mu^3}{\mu^4+1} \to \frac{\mu^4}{\mu^4+1} \to \frac{\mu}{\mu^4+1} \mbox{ appears at } \mu \approx 1.8393$$

- If μ equals 2 the system maps the interval \[0, 1\] onto itself. There are now periodic points with every orbit length within this interval, as well as non-periodic points. The periodic points are [dense](wikipedia://en/23523594) in \[0, 1\], so the map has become [chaotic](wikipedia://en/6295). In fact, the dynamics will be non-periodic [if and only if](wikipedia://en/14922) $x_0$ is [irrational](wikipedia://en/20647689). This can be seen by noting what the map does when $x_n$ is expressed in [binary](wikipedia://en/238686) notation: It shifts the binary point one place to the right; then, if what appears to the left of the binary point is a "one" it changes all ones to zeroes and vice versa (with the exception of the final bit "one" in the case of a finite binary expansion); starting from an irrational number, this process goes on forever without repeating itself. The invariant measure for *x* is the uniform density over the unit interval.[^o4] The [autocorrelation function](https://en.wikipedia.org/wiki/Autocorrelation_function) for a sufficiently long sequence {$x_n$} will show zero autocorrelation at all non-zero lags.[^o5] Thus $x_n$ cannot be distinguished from [white noise](wikipedia://en/46182) using the autocorrelation function. Note that the *r* = 4 case of the [logistic map](wikipedia://en/18137) and the $\mu = 2$ case of the tent map are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to each other: Denoting the logistically evolving variable as $y_n$, the homeomorphism is

$$x_n = \tfrac{2}{\pi}\sin^{-1}(y_{n}^{1/2}).$$

- If μ is greater than 2 the map's Julia set becomes disconnected, and breaks up into a [Cantor set](wikipedia://en/6172) within the interval \[0, 1\]. The Julia set still contains an infinite number of both non-periodic and periodic points (including orbits for any orbit length) but [almost every](wikipedia://en/44688) point within \[0, 1\] will now eventually diverge towards infinity. The canonical [Cantor set](wikipedia://en/6172) (obtained by successively deleting middle thirds from subsets of the unit line) is the Julia set of the tent map for μ = 3.

## Asymmetric tent map {#Asymmetric_tent_map}

The asymmetric tent map is essentially a distorted, but still [piecewise linear](wikipedia://en/444224), version of the $\mu = 2$ case of the tent map. It is defined by

$$v_{n+1}=\begin{cases} v_n/a &\mathrm{for}~~ v_n \in [0,a] \\ (1-v_n)/(1-a) &\mathrm{for}~~ v_n \in [a,1] \end{cases}$$

for parameter $a \in [0,1]$. The $\mu = 2$ case of the tent map is the present case of $a= \tfrac{1}{2}$. A sequence {$v_n$} will have the same autocorrelation function[^o5] as will data from the first-order [autoregressive process](https://en.wikipedia.org/wiki/Autoregressive_process) $w_{n+1} = (2a-1)w_n + u_{n+1}$ with {$u_n$} [independently and identically distributed](https://en.wikipedia.org/wiki/Independent_and_identically-distributed_random_variables). Thus data from an asymmetric tent map cannot be distinguished, using the autocorrelation function, from data generated by a first-order autoregressive process.

## Applications {#Applications}

The tent map has found applications in social cognitive optimization,[^o11] chaos in economics,[^o12][^o13] image encryption,[^o14] on risk and market sentiments for pricing,[^o15] etc.
