# List of convexity topics

::: {#o1 .subject cue=lead name="List of convexity topics"}

This is a **list of convexity topics**, by Wikipedia page.

:::

::: {#o2 .entry cue=list-entry name="Alpha blending"}

- [Alpha blending](https://en.wikipedia.org/wiki/Alpha_blending) - the process of combining a translucent foreground color with a background color, thereby producing a new blended color. This is a convex combination of two colors allowing for transparency effects in computer graphics.

:::

::: {#o3 .entry cue=list-entry name="Barycentric coordinates"}

- [Barycentric coordinates](https://en.wikipedia.org/wiki/Barycentric_coordinate_system_%28mathematics%29) - a coordinate system in which the location of a point of a simplex (a triangle, tetrahedron, etc.) is specified as the center of mass, or barycenter, of masses placed at its vertices. The coordinates are non-negative for points in the convex hull.

:::

::: {#o4 .entry cue=list-entry name="Borsuk's conjecture"}

- [Borsuk's conjecture](wikipedia://en/7765817) - a conjecture about the number of pieces required to cover a body with a larger diameter. Solved by Hadwiger for the case of smooth convex bodies.

:::

::: {#o5 .entry cue=list-entry name="Bond convexity"}

- [Bond convexity](https://en.wikipedia.org/wiki/Bond_convexity) - a measure of the non-linear relationship between price and yield duration of a bond to changes in interest rates, the second derivative of the price of the bond with respect to interest rates. A basic form of convexity in finance.

:::

::: {#o6 .entry cue=list-entry name="Carathéodory's theorem (convex hull)"}

- [Carathéodory's theorem (convex hull)](wikipedia://en/892014) - If a point *x* of R<sup>*d*</sup> lies in the convex hull of a set *P*, there is a subset of *P* with *d*+1 or fewer points such that *x* lies in its convex hull.

:::

::: {#o7 .entry cue=list-entry name="Choquet theory"}

- [Choquet theory](wikipedia://en/3655598) - an area of functional analysis and convex analysis concerned with measures with support on the extreme points of a convex set *C*. Roughly speaking, all vectors of *C* should appear as "averages" of extreme points.

:::

::: {#o8 .entry cue=list-entry name="Complex convexity"}

- [Complex convexity](wikipedia://en/1761690) — extends the notion of convexity to [complex numbers](wikipedia://en/5826).

:::

::: {#o9 .entry cue=list-entry name="Convex analysis"}

- [Convex analysis](wikipedia://en/3237201) - the branch of mathematics devoted to the study of properties of convex functions and convex sets, often with applications in convex minimization.

:::

::: {#o10 .entry cue=list-entry name="Convex combination"}

- [Convex combination](wikipedia://en/794534) - a linear combination of points where all coefficients are non-negative and sum to 1. All convex combinations are within the convex hull of the given points.

:::

::: {#o11 .entry cue=list-entry name="Convex and Concave"}

- *[Convex and Concave](https://en.wikipedia.org/wiki/Convex_and_Concave)* - a print by Escher in which many of the structure's features can be seen as both convex shapes and concave impressions.

:::

::: {#o12 .entry cue=list-entry name="Convex body"}

- [Convex body](wikipedia://en/8652020) - a compact convex set in a Euclidean space whose interior is non-empty.

:::

::: {#o13 .entry cue=list-entry name="Convex conjugate"}

- [Convex conjugate](wikipedia://en/1001490) - a dual of a real functional in a vector space. Can be interpreted as an encoding of the convex hull of the function's epigraph in terms of its supporting hyperplanes.

:::

::: {#o14 .entry cue=list-entry name="Convex curve"}

- [Convex curve](wikipedia://en/29747989) - a plane curve that lies entirely on one side of each of its supporting lines. The interior of a closed convex curve is a convex set.

:::

::: {#o15 .entry cue=list-entry name="Convex function"}

- [Convex function](wikipedia://en/245568) - a function in which the line segment between any two points on the graph of the function lies above the graph.

:::

  - [Closed convex function](wikipedia://en/1010712) - a convex function all of whose sublevel sets are closed sets.
  - [Proper convex function](wikipedia://en/630360) - a convex function whose effective domain is nonempty and it never attains minus infinity.
  - [Concave function](wikipedia://en/263321) - the negative of a convex function.

::: {#o16 .entry cue=list-entry name="Convex geometry"}

- [Convex geometry](wikipedia://en/4165882) - the branch of geometry studying convex sets, mainly in Euclidean space. Contains three sub-branches: general convexity, polytopes and polyhedra, and discrete geometry.

:::

::: {#o17 .entry cue=list-entry name="Convex hull"}

- [Convex hull](wikipedia://en/40634) (aka *convex envelope*) - the smallest convex set that contains a given set of points in Euclidean space.

:::

::: {#o18 .entry cue=list-entry name="Convex lens"}

- [Convex lens](https://en.wikipedia.org/wiki/Convex_lens) - a lens in which one or two sides is curved or bowed outwards. Light passing through the lens is converged (or focused) to a spot behind the lens.

:::

::: {#o19 .entry cue=list-entry name="Convex optimization"}

- [Convex optimization](wikipedia://en/1674411) - a subfield of optimization, studies the problem of minimizing convex functions over convex sets. The convexity property can make optimization in some sense "easier" than the general case - for example, any local minimum must be a global minimum.

:::

::: {#o20 .entry cue=list-entry name="Convex polygon"}

- [Convex polygon](wikipedia://en/660019) - a 2-dimensional polygon whose interior is a convex set in the Euclidean plane.

:::

::: {#o21 .entry cue=list-entry name="Convex polytope"}

- [Convex polytope](wikipedia://en/1817885) - an *n*-dimensional polytope which is also a convex set in the Euclidean *n*-dimensional space.

:::

::: {#o22 .entry cue=list-entry name="Convex set"}

- [Convex set](wikipedia://en/6292) - a set in Euclidean space in which contains every segment between every two of its points.

:::

::: {#o23 .entry cue=list-entry name="Convexity (finance)"}

- [Convexity (finance)](https://en.wikipedia.org/wiki/Convexity_%28finance%29) - refers to non-linearities in a financial model. When the price of an underlying variable changes, the price of an output does not change linearly, but depends on the higher-order derivatives of the modeling function. Geometrically, the model is no longer flat but curved, and the degree of curvature is called the convexity.

:::

::: {#o25 .entry cue=list-entry name="Epigraph (mathematics)"}

- [Epigraph (mathematics)](wikipedia://en/5744061) - for a function *f* : **R**n→**R**, the set of points lying on or above its graph

:::

::: {#o26 .entry cue=list-entry name="Extreme point"}

- [Extreme point](wikipedia://en/454968) - for a convex set *S* in a real vector space, a point in S which does not lie in any open line segment joining two points of *S*.

- [Hadwiger conjecture (combinatorial geometry)](wikipedia://en/21851601) - any convex body in *n*-dimensional Euclidean space can be covered by 2<sup>*n*</sup> or fewer smaller bodies homothetic with the original body.
