# Closed convex function

::: {#o1 .subject cue=lead name="Closed convex function"}

In [mathematics](wikipedia://en/18831), a [function](wikipedia://en/185427) $f: \mathbb{R}^n \rightarrow \mathbb{R}$ is said to be **closed** if for each $\alpha \in \mathbb{R}$, the [sublevel set](wikipedia://en/559622) $\{ x \in \mbox{dom} f \vert f(x) \leq \alpha \}$ is a [closed set](wikipedia://en/47279).

:::

Equivalently, if the [epigraph](wikipedia://en/5744061) defined by $\mbox{epi} f = \{ (x,t) \in \mathbb{R}^{n+1} \vert x \in \mbox{dom} f,\; f(x) \leq t\}$ is closed, then the function $f$ is closed.

This definition is valid for any function, but most used for [convex functions](wikipedia://en/245568). A [proper convex function](wikipedia://en/630360) is closed [if and only if](wikipedia://en/14922) it is [lower semi-continuous](https://en.wikipedia.org/wiki/Lower_semi-continuous).[^o2]

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If $f: \mathbb{R}^n \rightarrow \mathbb{R}$ is a [continuous function](wikipedia://en/6122) and $\mbox{dom} f$ is closed, then $f$ is closed.
- If $f: \mathbb R^n \rightarrow \mathbb R$ is a [continuous function](wikipedia://en/6122) and $\mbox{dom} f$ is open, then $f$ is closed [if and only if](wikipedia://en/14922) it converges to $\infty$ along every sequence converging to a [boundary](wikipedia://en/72824) point of $\mbox{dom} f$.[^o5]
- A closed proper convex function *f* is the pointwise [supremum](https://en.wikipedia.org/wiki/Supremum) of the collection of all [affine functions](https://en.wikipedia.org/wiki/Affine_function) *h* such that *h* ≤ *f* (called the affine minorants of *f*).

:::
