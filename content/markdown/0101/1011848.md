# Fixed-point theorem

::: {#o1 .subject cue=lead name="Fixed-point theorem"}

In [mathematics](wikipedia://en/18831), a **fixed-point theorem** is a result saying that a [function](wikipedia://en/185427) *F* will have at least one [fixed point](wikipedia://en/449738) (a point *x* for which *F*(*x*) = *x*), under some conditions on *F* that can be stated in general terms.[^o2]

:::

## In mathematical analysis {#In_mathematical_analysis}

The [Banach fixed-point theorem](wikipedia://en/46676) (1922) gives a general criterion guaranteeing that, if it is satisfied, the procedure of [iterating](wikipedia://en/68833) a function yields a fixed point.[^o4]

By contrast, the [Brouwer fixed-point theorem](wikipedia://en/4101) (1911) is a non-[constructive result](https://en.wikipedia.org/wiki/Constructivism_%28mathematics%29): it says that any [continuous function](wikipedia://en/6122) from the closed [unit ball](https://en.wikipedia.org/wiki/Unit_ball) in *n*-dimensional [Euclidean space](wikipedia://en/9697) to itself must have a fixed point,[^o5] but it does not describe how to find the fixed point (see also [Sperner's lemma](wikipedia://en/465067)).

For example, the [cosine](https://en.wikipedia.org/wiki/Cosine) function is continuous in \[−1, 1\] and maps it into \[−1, 1\], and thus must have a fixed point. This is clear when examining a sketched graph of the cosine function; the fixed point occurs where the cosine curve *y* = cos(*x*) intersects the line *y* = *x*. Numerically, the fixed point (known as the [Dottie number](wikipedia://en/54562671)) is approximately *x* = 0.73908513321516 (thus *x* = cos(*x*) for this value of *x*).

The [Lefschetz fixed-point theorem](wikipedia://en/582530)[^o6] (and the [Nielsen fixed-point theorem](wikipedia://en/3603035))[^o7] from [algebraic topology](wikipedia://en/38801) is notable because it gives, in some sense, a way to count fixed points.

There are a number of generalisations to [Banach fixed-point theorem](wikipedia://en/46676) and further; these are applied in [PDE](wikipedia://en/52564) theory. See [fixed-point theorems in infinite-dimensional spaces](wikipedia://en/638186).

The [collage theorem](wikipedia://en/20967247) in [fractal compression](wikipedia://en/60022) proves that, for many images, there exists a relatively small description of a function that, when iteratively applied to any starting image, rapidly converges on the desired image.[^o8]

## In algebra and discrete mathematics {#In_algebra_and_discrete_mathematics}

The [Knaster&ndash;Tarski theorem](https://en.wikipedia.org/wiki/Knaster&ndash;Tarski_theorem) states that any [order-preserving function](https://en.wikipedia.org/wiki/Monotonic) on a [complete lattice](wikipedia://en/44777) has a fixed point, and indeed a *smallest* fixed point.[^o10] See also [Bourbaki&ndash;Witt theorem](https://en.wikipedia.org/wiki/Bourbaki&ndash;Witt_theorem).

The theorem has applications in [abstract interpretation](https://en.wikipedia.org/wiki/Abstract_interpretation), a form of [static program analysis](https://en.wikipedia.org/wiki/Static_program_analysis).

A common theme in [lambda calculus](wikipedia://en/18203) is to find fixed points of given lambda expressions. Every lambda expression has a fixed point, and a [fixed-point combinator](wikipedia://en/150287) is a "function" which takes as input a lambda expression and produces as output a fixed point of that expression.[^o11] An important fixed-point combinator is the [Y combinator](wikipedia://en/150287#Y_combinator) used to give [recursive](wikipedia://en/4044867) definitions.

In [denotational semantics](wikipedia://en/55275) of programming languages, a special case of the Knaster–Tarski theorem is used to establish the semantics of recursive definitions. While the fixed-point theorem is applied to the "same" function (from a logical point of view), the development of the theory is quite different.

The same definition of recursive function can be given, in [computability theory](wikipedia://en/155414), by applying [Kleene's recursion theorem](wikipedia://en/155407).[^o12] These results are not equivalent theorems; the Knaster–Tarski theorem is a much stronger result than what is used in denotational semantics.[^o13] However, in light of the [Church&ndash;Turing thesis](https://en.wikipedia.org/wiki/Church&ndash;Turing_thesis) their intuitive meaning is the same: a recursive function can be described as the least fixed point of a certain functional, mapping functions to functions.

The above technique of iterating a function to find a fixed point can also be used in [set theory](wikipedia://en/27553); the [fixed-point lemma for normal functions](wikipedia://en/404343) states that any continuous strictly increasing function from [ordinals](wikipedia://en/26547932) to ordinals has one (and indeed many) fixed points.

Every [closure operator](wikipedia://en/483120) on a [poset](https://en.wikipedia.org/wiki/Poset) has many fixed points; these are the "closed elements" with respect to the closure operator, and they are the main reason the closure operator was defined in the first place.

Every [involution](wikipedia://en/293450) on a [finite set](wikipedia://en/11742) with an odd number of elements has a fixed point; more generally, for every involution on a finite set of elements, the number of elements and the number of fixed points have the same [parity](wikipedia://en/143135). [Don Zagier](wikipedia://en/1408557) used these observations to give a one-sentence proof of [Fermat's theorem on sums of two squares](wikipedia://en/1850216), by describing two involutions on the same set of triples of integers, one of which can easily be shown to have only one fixed point and the other of which has a fixed point for each representation of a given prime (congruent to 1 mod 4) as a sum of two squares. Since the first involution has an odd number of fixed points, so does the second, and therefore there always exists a representation of the desired form.[^o14]
