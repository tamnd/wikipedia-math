# Monadic Boolean algebra

::: {#o1 .subject cue=lead name="Monadic Boolean algebra"}

In [abstract algebra](wikipedia://en/19616384), a **monadic Boolean algebra** is an [algebraic structure](wikipedia://en/106364) *A* with [signature](wikipedia://en/7788156)

:::

$\langle\cdot, +,', 0, 1, \exists\rangle$ of [type](wikipedia://en/7788156) ⟨2,2,1,0,0,1⟩,

where ⟨*A*, ·, +, ', 0, 1⟩ is a [Boolean algebra](wikipedia://en/3959).

The [monadic](https://en.wikipedia.org/wiki/Monadic_%28arity%29)/[unary operator](https://en.wikipedia.org/wiki/Unary_operator) ∃ denotes the [existential quantifier](https://en.wikipedia.org/wiki/Existential_quantifier), which satisfies the identities (using the received [prefix](https://en.wikipedia.org/wiki/Prefix) notation for ∃):

- $$\exists0 = 0$$
- $$\exists x \ge x$$
- $$\exists(x + y) = \exists x + \exists y$$
- $$\exists x\exists y = \exists(x\exists y).$$

$\exists x$ is the *existential closure* of *x*. [Dual](wikipedia://en/600618) to ∃ is the [unary operator](https://en.wikipedia.org/wiki/Unary_operator) ∀, the [universal quantifier](https://en.wikipedia.org/wiki/Universal_quantifier), defined as $\forall x := (\exists x)$.

A monadic Boolean algebra has a dual definition and notation that take ∀ as primitive and ∃ as defined, so that $\exists x := (\forall x)$. (Compare this with the definition of the [dual](wikipedia://en/600618) Boolean algebra.) Hence, with this notation, an algebra *A* has signature $\langle\cdot, +,', 0, 1, \forall\rangle$, with ⟨*A*, ·, +, ', 0, 1⟩ a Boolean algebra, as before. Moreover, ∀ satisfies the following [dualized](wikipedia://en/600618) version of the above identities:

1. $$\forall1 = 1$$
1. $$\forall x \le x$$
1. $$\forall(xy) = \forall x\forall y$$
1. $$\forall x + \forall y = \forall(x + \forall y).$$

$\forall x$ is the *universal closure* of *x*.

## Discussion {#Discussion}

Monadic Boolean algebras have an important connection to [topology](wikipedia://en/29954). If ∀ is interpreted as the [interior operator](https://en.wikipedia.org/wiki/Interior_operator) of topology, (1)–(3) above plus the axiom ∀(∀*x*) = ∀*x* make up the axioms for an [interior algebra](wikipedia://en/990454). But ∀(∀*x*) = ∀*x* can be proved from (1)–(4). Moreover, an alternative axiomatization of monadic Boolean algebras consists of the (reinterpreted) axioms for an [interior algebra](wikipedia://en/990454), plus ∀(∀*x*)' = (∀*x*)' (Halmos 1962: 22). Hence monadic Boolean algebras are the [semisimple](wikipedia://en/3876151) interior/[closure algebras](https://en.wikipedia.org/wiki/Closure_algebra) such that:

- The universal (dually, existential) quantifier interprets the [interior](https://en.wikipedia.org/wiki/Interior_operator) ([closure](wikipedia://en/483120)) operator;
- All open (or closed) elements are also [clopen](wikipedia://en/233398).

A more concise axiomatization of monadic Boolean algebra is (1) and (2) above, plus ∀(*x*∨∀*y*) = ∀*x*∨∀*y* (Halmos 1962: 21). This axiomatization obscures the connection to topology.

Monadic Boolean algebras form a [variety](wikipedia://en/1021753). They are to [monadic predicate logic](https://en.wikipedia.org/wiki/Monadic_logic) what [Boolean algebras](wikipedia://en/990343) are to [propositional logic](wikipedia://en/18154), and what [polyadic algebras](wikipedia://en/22737733) are to [first-order logic](wikipedia://en/10983). [Paul Halmos](wikipedia://en/318598) discovered monadic Boolean algebras while working on polyadic algebras; Halmos (1962) reprints the relevant papers. Halmos and Givant (1998) includes an undergraduate treatment of monadic Boolean algebra.

Monadic Boolean algebras also have an important connection to [modal logic](wikipedia://en/333365). Monadic Boolean algebras are models of the modal logic **S5** in the same way that interior algebras are models of the modal logic **S4**. That is, monadic Boolean algebras supply the algebraic semantics for **S5**. Hence **S5-algebra** is a [synonym](https://en.wikipedia.org/wiki/Synonym) for monadic Boolean algebra.
