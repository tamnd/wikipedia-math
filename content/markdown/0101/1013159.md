# Multidimensional analysis

::: {#o1 .subject cue=lead name="Multidimensional analysis"}

In [statistics](wikipedia://en/26685), [econometrics](wikipedia://en/10390) and related fields, **multidimensional analysis** (**MDA**) is a [data analysis](wikipedia://en/2720954) process that groups data into two categories: [data dimensions](https://en.wikipedia.org/wiki/Data_dimension) and measurements. For example, a [data set](wikipedia://en/8495) consisting of the number of wins for a single football team at each of several years is a single-dimensional (in this case, longitudinal) data set. A data set consisting of the number of wins for several football teams in a single year is also a single-dimensional (in this case, cross-sectional) data set. A data set consisting of the number of wins for several football teams over several years is a two-dimensional data set.

:::

## Higher dimensions {#Higher_dimensions}

In many disciplines, two-dimensional data sets are also called [panel data](wikipedia://en/2499813).[^o3] While, strictly speaking, two- and higher-dimensional data sets are "multi-dimensional", the term "multidimensional" tends to be applied only to data sets with three or more dimensions.[^o4] For example, some forecast data sets provide forecasts for multiple target periods, conducted by multiple forecasters, and made at multiple horizons. The three dimensions provide more information than can be gleaned from two-dimensional panel data sets.

## Software {#Software}

Computer software for MDA include [Online analytical processing](wikipedia://en/189239) (OLAP) for data in [relational databases](https://en.wikipedia.org/wiki/Relational_database), [pivot tables](https://en.wikipedia.org/wiki/Pivot_table) for data in [spreadsheets](https://en.wikipedia.org/wiki/Spreadsheet), and [Array DBMSs](https://en.wikipedia.org/wiki/Array_DBMSs) for general multi-dimensional data (such as [raster data](https://en.wikipedia.org/wiki/Raster_data)) in science, engineering, and business.
