# Cuthill–McKee algorithm

*Image: Can 73 cm.svg.* Cuthill-McKee ordering of a matrix

*Image: Can 73 rcm.svg.* RCM ordering of the same matrix

::: {#o1 .subject cue=lead name="Cuthill–McKee algorithm"}

In [numerical linear algebra](wikipedia://en/7330660), the **Cuthill–McKee algorithm** (**CM**), named after [Elizabeth Cuthill](wikipedia://en/67390381) and James McKee,[^o2] is an [algorithm](wikipedia://en/775) to permute a [sparse matrix](wikipedia://en/341015) that has a [symmetric](wikipedia://en/126474) sparsity pattern into a [band matrix](wikipedia://en/1451476) form with a small [bandwidth](https://en.wikipedia.org/wiki/Bandwidth_%28matrix_theory%29). The **reverse Cuthill–McKee algorithm** (**RCM**) due to Alan George and Joseph Liu is the same algorithm but with the resulting index numbers reversed.[^o3] In practice this generally results in less [fill-in](wikipedia://en/341015#Reducing_fill-in) than the CM ordering when Gaussian elimination is applied.[^o4]

:::

The Cuthill McKee algorithm is a variant of the standard [breadth-first search](wikipedia://en/97026) algorithm used in graph algorithms. It starts with a peripheral node and then generates [levels](https://en.wikipedia.org/wiki/Level_structure) $R_i$ for $i=1, 2,..$ until all nodes are exhausted. The set $R_{i+1}$ is created from set $R_i$ by listing all vertices adjacent to all nodes in $R_i$. These nodes are ordered according to predecessors and degree.

::: {#o6 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

Given a symmetric $n\times n$ matrix we visualize the matrix as the [adjacency matrix](wikipedia://en/244463) of a [graph](wikipedia://en/325806). The Cuthill–McKee algorithm is then a relabeling of the [vertices](wikipedia://en/638899) of the graph to reduce the bandwidth of the adjacency matrix.

The algorithm produces an ordered [*n*-tuple](https://en.wikipedia.org/wiki/N-tuple) $R$ of vertices which is the new order of the vertices.

First we choose a [peripheral vertex](https://en.wikipedia.org/wiki/Peripheral_vertex) (the vertex with the lowest [degree](wikipedia://en/1374448)) $x$ and set $R := ( \{ x \})$.

Then for $i = 1,2,\dots$ we iterate the following steps while $|R| < n$

- Construct the adjacency set $A_i$ of $R_i$ (with $R_i$ the *i*-th component of $R$) and exclude the vertices we already have in $R$

$$A_i := \operatorname{Adj}(R_i) \setminus R$$

- Sort $A_i$ ascending by minimum predecessor (the already-visited neighbor with the earliest position in R), and as a tiebreak ascending by [vertex degree](wikipedia://en/1374448).[^o7]
- Append $A_i$ to the Result set $R$.

In other words, number the vertices according to a particular [level structure](https://en.wikipedia.org/wiki/Level_structure) (computed by [breadth-first search](wikipedia://en/97026)) where the vertices in each level are visited in order of their predecessor's numbering from lowest to highest. Where the predecessors are the same, vertices are distinguished by degree (again ordered from lowest to highest).

:::
