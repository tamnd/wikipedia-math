# Curve448

::: {#o1 .subject cue=lead name="Curve448"}

In [cryptography](wikipedia://en/18934432), **Curve448** or **Curve448-Goldilocks** is an [elliptic curve](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography) potentially offering 224 bits of security and designed for use with the [elliptic-curve Diffie–Hellman](wikipedia://en/3357958) (ECDH) key agreement scheme.

:::

## History {#History}

Developed by Mike Hamburg of [Rambus](https://en.wikipedia.org/wiki/Rambus) Cryptography Research, Curve448 allows fast performance compared with other proposed curves with comparable security.[^o3] The [reference implementation](https://en.wikipedia.org/wiki/Reference_implementation) is available under an [MIT license](https://en.wikipedia.org/wiki/MIT_license).[^o4] The curve was favored by the [Internet Research Task Force](https://en.wikipedia.org/wiki/Internet_Research_Task_Force) Crypto Forum Research Group (IRTF CFRG) for inclusion in [Transport Layer Security](wikipedia://en/187813) (TLS) standards along with [Curve25519](wikipedia://en/17935444).

In 2017, NIST announced that Curve25519 and Curve448 would be added to "Special Publication 800-186", which specifies approved [elliptic curves](https://en.wikipedia.org/wiki/Elliptic_curves) for use by the [US Federal Government](https://en.wikipedia.org/wiki/US_Federal_Government),[^o5] and in 2023 it was approved for use in FIPS 186-5.[^o6] Both are described in 7748. The name **X448** is used for the DH function. X448 support was added to [OpenSSL](wikipedia://en/438819) in version 1.1.1 (released on 11 September 2018).[^o7]

## Mathematical properties {#Mathematical_properties}

Hamburg chose the [Solinas trinomial prime](wikipedia://en/24257463) base *p* = 2<sup>448</sup> − 2<sup>224</sup> − 1, calling it a "Goldilocks" prime "because its form defines the golden ratio *φ* ≡ 2<sup>224</sup>". The main advantage of a [golden-ratio](https://en.wikipedia.org/wiki/Golden-ratio) prime is fast [Karatsuba multiplication](https://en.wikipedia.org/wiki/Karatsuba_multiplication).[^o9]

The curve Hamburg used is an untwisted [Edwards curve](wikipedia://en/25505011) E<sub>*d*</sub>: $y^{2} + x^{2} = 1 - 39081x^{2}y^{2}$. The constant *d* = −39081 was chosen as the smallest absolute value that had the required mathematical properties, thus a [nothing-up-my-sleeve number](wikipedia://en/1249296).

Curve448 is constructed such that it avoids many potential [implementation](https://en.wikipedia.org/wiki/Software) pitfalls.[^o10]
