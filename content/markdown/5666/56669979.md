# Rudin's conjecture

::: {#o1 .subject cue=lead name="Rudin's conjecture"}

::: {#o2 .problem cue=unsolved}

What is the upper bound for the number of squares in finite arithmetic progressions?

:::

**Rudin's conjecture** is a mathematical conjecture in [additive combinatorics](wikipedia://en/18243392) and [elementary number theory](https://en.wikipedia.org/wiki/Elementary_number_theory) about an upper bound for the number of squares in finite [arithmetic progressions](wikipedia://en/168389). The conjecture, which has applications in the theory of [trigonometric series](wikipedia://en/4099125), was first stated by [Walter Rudin](wikipedia://en/5491766) in his 1960 paper *Trigonometric series with gaps*.[^o3][^o4][^o5]

:::

For positive integers $N, q, a$ define the expression $Q(N; q, a)$ to be the number of [perfect squares](wikipedia://en/213919) in the arithmetic progression $qn + a$, for $n = 0, 1, \ldots, N-1$, and define $Q(N)$ to be the maximum of the set $\{Q(N; q, a) : q, a \ge 1\}$. The conjecture asserts (in [big O notation](wikipedia://en/44578)) that $Q(N) = O(\sqrt { N })$ and in its stronger form that, if $N > 6$, $Q(N) = Q(N; 24, 1)$.[^o5] This progression begins with $1, 25, 49, 73, 97, 121, ...$ and its square terms correspond to indices that are generalized [pentagonal numbers](wikipedia://en/504786). For $N = 5$, the arithmetic progression $120n + 49$ contains four squares $(49, 169, 289, 529)$, so $Q(5)=4$, whereas $24n+1$ only contains three squares in its first five terms.

## Background and partial results {#Background_and_partial_results}

The problem of finding squares in arithmetic progressions is famously connected to [Fermat](https://en.wikipedia.org/wiki/Fermat), who proved that no four squares can be in a non-constant arithmetic progression. This result is equivalent to stating that $Q(4) = 3$. The general question of bounding the number of squares led to a conjecture by [Paul Erdős](wikipedia://en/601284) that for any arithmetic progression of length $N$, the number of squares must be $o(N)$ ([little-o notation](https://en.wikipedia.org/wiki/Little-o_notation)). This was proven by [Endre Szemerédi](wikipedia://en/663489) as a consequence of [Szemerédi's theorem](wikipedia://en/591703) on arithmetic progressions.[^o5]

Following Szemerédi's result, the upper bound for $Q(N)$ was progressively improved. Bombieri, Granville, and Pintz established a bound of $O\!\left(N^{\tfrac{2}{3}+o(1)}\right)$.[^o7] This was later refined by Bombieri and Zannier to $O\!\left(N^{\tfrac{3}{5}+o(1)}\right)$.[^o8]

Enrique Gonzalez-Jimenez and Xavier Xarles verified in 2014 that the Strong Rudin's Conjecture holds for all $6 \le N \le 52$. Based on this evidence, they proposed a "*Super-Strong Rudin's Conjecture*", which states that for specific values of $N$ where $Q(N)$ is expected to increase (specifically when $N = GP_k + 1 \ge 8$, where $GP_k$ is the $k$-th generalized pentagonal number), the arithmetic progression $24n+1$ is the only one, up to equivalence, that achieves the maximum number of squares.[^o5]
