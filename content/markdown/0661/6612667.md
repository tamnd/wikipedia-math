# Equivalence (measure theory)

::: {#o1 .subject cue=lead name="Equivalence"}

In [mathematics](wikipedia://en/18831), and specifically in [measure theory](https://en.wikipedia.org/wiki/Measure_theory), **equivalence** is a notion of two [measures](wikipedia://en/19873) being qualitatively similar. Specifically, the two measures agree on which events have measure zero.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mu$ and $\nu$ be two [measures](wikipedia://en/19873) on the measurable space $(X, \mathcal A),$ and let

$$\mathcal{N}_\mu := \{A \in \mathcal{A} \mid \mu(A) = 0\}$$

and

$$\mathcal{N}_\nu := \{A \in \mathcal{A} \mid \nu(A) = 0\}$$

be the sets of $\mu$-[null sets](wikipedia://en/21520) and $\nu$-null sets, respectively. Then the measure $\nu$ is said to be [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous_measure) in reference to $\mu$ if and only if $\mathcal N_\nu \supseteq \mathcal N_\mu.$ This is denoted as $\nu \ll \mu.$

The two measures are called equivalent if and only if $\mu \ll \nu$ and $\nu \ll \mu,$[^o4] which is denoted as $\mu \sim \nu.$ That is, two measures are equivalent if they satisfy $\mathcal N_\mu = \mathcal N_\nu.$

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

### On the real line {#On_the_real_line}

Define the two measures on the [real line](https://en.wikipedia.org/wiki/Real_line) as

$$\mu(A)= \int_A \mathbf 1_{[0,1]}(x) \mathrm dx$$

$$\nu(A)= \int_A x^2 \mathbf 1_{[0,1]}(x) \mathrm dx$$

for all [Borel sets](wikipedia://en/43327) $A.$ Then $\mu$ and $\nu$ are equivalent, since all sets outside of $[0,1]$ have $\mu$ and $\nu$ measure zero, and a set inside $[0,1]$ is a $\mu$-null set or a $\nu$-null set exactly when it is a null set with respect to [Lebesgue measure](wikipedia://en/18198).

### Abstract measure space {#Abstract_measure_space}

Look at some measurable space $(X, \mathcal A)$ and let $\mu$ be the [counting measure](wikipedia://en/191786), so

$$\mu(A) = |A|,$$

where $|A|$ is the [cardinality](wikipedia://en/6174) of the set a. So the counting measure has only one null set, which is the [empty set](wikipedia://en/9566). That is, $\mathcal N_\mu = \{\varnothing\}.$ So by the second definition, any other measure $\nu$ is equivalent to the counting measure if and only if it also has just the empty set as the only $\nu$-null set.

:::

## Supporting measures {#Supporting_measures}

A measure $\mu$ is called a **supporting measure** of a measure $\nu$ if $\mu$ is [$\sigma$-finite](https://en.wikipedia.org/wiki/Sigma-finite) and $\nu$ is equivalent to $\mu.$[^o10]
