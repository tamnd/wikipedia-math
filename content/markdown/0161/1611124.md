# Linear probability model

::: {#o1 .subject cue=lead name="Linear probability model"}

In [statistics](wikipedia://en/26685), a **linear probability model** (**LPM**) is a special case of a [binary regression](wikipedia://en/60567021) model. Here the [dependent variable](wikipedia://en/437701) for each observation takes values which are either 0 or 1. The probability of observing a 0 or 1 in any one case is treated as depending on one or more [explanatory variables](wikipedia://en/437701). For the "linear probability model", this relationship is a particularly simple one, and allows the model to be fitted by [linear regression](wikipedia://en/48758386).

:::

The model assumes that, for a binary outcome ([Bernoulli trial](wikipedia://en/102653)), $Y$, and its associated vector of explanatory variables, $X$,[^o2]

$$\Pr(Y=1 | X=x) = x'\beta .$$

For this model,

$$E[Y|X] = 0\cdot \Pr(Y=0|X) +1\cdot \Pr(Y=1|X) = \Pr(Y=1|X) =x'\beta,$$

and hence the vector of parameters β can be estimated using [least squares](wikipedia://en/82359). This method of fitting would be inefficient,[^o2] and can be improved by adopting an iterative scheme based on [weighted least squares](wikipedia://en/2407860),[^o2] in which the model from the previous iteration is used to supply estimates of the conditional variances, $\operatorname{Var}(Y|X=x)$, which would vary between observations. This approach can be related to fitting the model by [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood).[^o2]

A drawback of this model is that, unless restrictions are placed on $\beta$, the estimated coefficients can imply probabilities outside the [unit interval](wikipedia://en/49324) $[0,1]$. For this reason, models such as the [logit model](https://en.wikipedia.org/wiki/Logit_model) or the [probit model](wikipedia://en/1611247) are more commonly used.

## Latent-variable formulation {#Latent-variable_formulation}

More formally, the LPM can arise from a latent-variable formulation (usually to be found in the [econometrics](wikipedia://en/10390) literature[^o4]), as follows: assume the following regression model with a latent (unobservable) dependent variable:

$$y^* = b_0+ \mathbf x'\mathbf b + \varepsilon,\;\; \varepsilon\mid \mathbf x\sim U(-a,a).$$

The critical assumption here is that the error term of this regression is a symmetric around zero [uniform](wikipedia://en/1699223) [random variable](wikipedia://en/25685), and hence, of mean zero. The cumulative distribution function of $\varepsilon$ here is $F_{\varepsilon|\mathbf x}(\varepsilon\mid \mathbf x) = \frac {\varepsilon + a}{2a}.$

Define the indicator variable $y = 1$ if $y^* >0$, and zero otherwise, and consider the [conditional probability](wikipedia://en/24104134)

$$\begin{aligned} {\rm Pr}(y =1\mid \mathbf x ) &= {\rm Pr}(y^* > 0\mid \mathbf x) = {\rm Pr}(b_0+ \mathbf x'\mathbf b + \varepsilon>0\mid \mathbf x) \\ &= {\rm Pr}(\varepsilon >- b_0- \mathbf x'\mathbf b\mid \mathbf x) = 1- {\rm Pr}(\varepsilon \leq - b_0- \mathbf x'\mathbf b\mid \mathbf x) \\ &= 1- F_{\varepsilon|\mathbf x}(- b_0- \mathbf x'\mathbf b\mid \mathbf x) =1- \frac {- b_0- \mathbf x'\mathbf b + a}{2a} = \frac {b_0+a}{2a}+\frac {\mathbf x'\mathbf b}{2a}. \\ \end{aligned}$$

But this is the linear probability model

$$P(y =1\mid \mathbf x )= \beta_0 + \mathbf x'\beta$$

with the mapping

$$\beta_0 = \frac {b_0+a}{2a},\;\; \beta=\frac{\mathbf b}{2a}.$$

This method is a general device to obtain a conditional probability model of a binary variable: if we assume that the distribution of the error term is logistic, we obtain the [logit model](https://en.wikipedia.org/wiki/Logit_model), while if we assume that it is the normal, we obtain the [probit model](wikipedia://en/1611247) and, if we assume that it is the logarithm of a [Weibull distribution](wikipedia://en/206948), the [complementary log-log model](wikipedia://en/747122).
