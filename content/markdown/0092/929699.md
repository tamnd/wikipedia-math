# Friedman number

::: {#o1 .subject cue=lead name="Friedman number"}

A **Friedman number** is an [integer](wikipedia://en/14563), which [represented](https://en.wikipedia.org/wiki/Code) in a given [numeral system](wikipedia://en/21170), is the result of a non-trivial expression using all its own [digits](wikipedia://en/280582) in combination with any of the four basic [arithmetic operators](https://en.wikipedia.org/wiki/Arithmetic_operator) (+, −, ×, ÷), [additive inverses](wikipedia://en/228312), parentheses, [exponentiation](wikipedia://en/99491), and [concatenation](wikipedia://en/64474). Here, non-trivial means that at least one operation besides concatenation is used. Leading zeros cannot be used, since that would also result in trivial Friedman numbers, such as 024 = 20 + 4. For example, 347 is a Friedman number in the [decimal numeral system](https://en.wikipedia.org/wiki/Decimal_numeral_system), since 347 = 7<sup>3</sup> + 4. The decimal Friedman numbers are:

:::

[25](wikipedia://en/362204), [121](https://en.wikipedia.org/wiki/121_%28number%29), [125](https://en.wikipedia.org/wiki/125_%28number%29), [126](https://en.wikipedia.org/wiki/126_%28number%29), [127](https://en.wikipedia.org/wiki/127_%28number%29), [128](https://en.wikipedia.org/wiki/128_%28number%29), [153](https://en.wikipedia.org/wiki/153_%28number%29), [216](https://en.wikipedia.org/wiki/216_%28number%29), [289](wikipedia://en/75057181), [343](https://en.wikipedia.org/wiki/343_%28number%29), [347](https://en.wikipedia.org/wiki/347_%28number%29), 625, 688, 736, 1022, [1024](https://en.wikipedia.org/wiki/1024_%28number%29), 1206, 1255, 1260, 1285, 1296, 1395, 1435, 1503, 1530, 1792, 1827, 2048, 2187, 2349, 2500, 2501, 2502, 2503, 2504, 2505, 2506, 2507, 2508, 2509, 2592, 2737, 2916, ... .

Friedman numbers are named after Erich Friedman, a now-retired mathematics professor at [Stetson University](https://en.wikipedia.org/wiki/Stetson_University) and recreational mathematics enthusiast.

A **Friedman prime** is a Friedman number that is also [prime](wikipedia://en/23666). The decimal Friedman primes are:

[127](https://en.wikipedia.org/wiki/127_%28number%29), [347](https://en.wikipedia.org/wiki/347_%28number%29), 2503, 12101, 12107, 12109, 15629, 15641, 15661, 15667, 15679, 16381, 16447, 16759, 16879, 19739, 21943, 27653, 28547, 28559, 29527, 29531, 32771, 32783, 35933, 36457, 39313, 39343, 43691, 45361, 46619, 46633, 46643, 46649, 46663, 46691, 48751, 48757, 49277, 58921, 59051, 59053, 59263, 59273, 64513, 74353, 74897, 78163, 83357, ... .

A **nice** Friedman number is a Friedman number where the digits in the expression can be arranged to be in the same order as in the number itself. For example, we can arrange 127 = 2<sup>7</sup> − 1 as 127 = −1 + 2<sup>7</sup>. The first nice Friedman numbers are:

[127](https://en.wikipedia.org/wiki/127_%28number%29), [343](https://en.wikipedia.org/wiki/343_%28number%29), 736, 1285, 2187, 2502, 2592, 2737, 3125, 3685, 3864, 3972, 4096, 6455, 11264, 11664, 12850, 13825, 14641, 15552, 15585, 15612, 15613, 15617, 15618, 15621, 15622, 15623, 15624, 15626, 15632, 15633, 15642, 15645, 15655, 15656, 15662, 15667, 15688, 16377, 16384, 16447, 16875, 17536, 18432, 19453, 19683, 19739 .

A **nice** Friedman prime is a **nice** Friedman number that's also prime. The first nice Friedman primes are:

[127](https://en.wikipedia.org/wiki/127_%28number%29), 15667, 16447, 19739, 28559, 32771, 39343, 46633, 46663, 117619, 117643, 117763, 125003, 131071, 137791, 147419, 156253, 156257, 156259, 229373, 248839, 262139, 262147, 279967, 294829, 295247, 326617, 466553, 466561, 466567, 585643, 592763, 649529, 728993, 759359, 786433, 937577 .

Michael Brand proved that the density of Friedman numbers among the naturals is 1,[^o4] which is to say that the probability of a number chosen randomly and uniformly between 1 and *n* to be a Friedman number tends to 1 as *n* tends to infinity. This result extends to Friedman numbers under any base of representation. He also proved that the same is true also for binary, ternary and quaternary nice Friedman numbers.[^o5] The case of base-10 nice Friedman numbers is still open.

[Vampire numbers](wikipedia://en/924973) are a subset of Friedman numbers where the only operation is a multiplication of two numbers with the same number of digits, for example 1260 = 21 × 60.

## Finding 2-digit Friedman numbers {#Finding_2-digit_Friedman_numbers}

There usually are fewer 2-digit Friedman numbers than 3-digit and more in any given base, but the 2-digit ones are easier to find. If we represent a 2-digit number as *mb* + *n*, where *b* is the base and *m*, *n* are integers from 0 to *b*−1, we need only check each possible combination of *m* and *n* against the equalities *mb* + *n* = *m*<sup>*n*</sup>, and *mb* + *n* = *n*<sup>*m*</sup> to see which ones are true. We need not concern ourselves with *m* + *n* or *m* × *n*, since these will always be smaller than *mb* + *n* when *n* \< *b*. The same clearly holds for *m* − *n* and *m* / *n*.

### General results {#General_results}

In base $b = mk - m$,

$$b^2 + mb + k = (mk - m + m)b + k = mbk + k = k(mb + 1)$$

is a Friedman number (written in base $b$ as 1*mk* = *k* × *m*1).[^o11]

In base $b > 2$,

$${(b^n + 1)}^2 = b^{2n} + 2{b^n} + 1$$

is a Friedman number (written in base $b$ as 100...00200...001 = 100..001<sup>2</sup>, with $n - 1$ zeroes between each nonzero number).[^o11]

In base $b = \frac{k(k - 1)}{2}$,

$$2b + k = 2\left(\frac{k(k - 1)}{2}\right) + k = k^2 - k + k = k^2$$

is a Friedman number (written in base $b$ as 2*k* = *k*<sup>2</sup>). From the observation that all numbers of the form 2*k* × b<sup>2*n*</sup> can be written as *k*000...000<sup>2</sup> with *n* 0's, we can find sequences of consecutive Friedman numbers which are arbitrarily long. For example, for $k = 5$, or in [base 10](https://en.wikipedia.org/wiki/Base_10), 250068 = 500<sup>2</sup> + 68, from which we can easily deduce the range of consecutive Friedman numbers from 250000 to 250099 in [base 10](https://en.wikipedia.org/wiki/Base_10).[^o11]

[Repdigit](wikipedia://en/216551) Friedman numbers:

- The smallest repdigit in any base that is a Friedman number is found in [base 8](https://en.wikipedia.org/wiki/Base_8), and is 33 = 3<sup>3</sup>.
- The smallest repdigit in [base 10](https://en.wikipedia.org/wiki/Base_10) that is known to be a Friedman number is 99999999 = (9 + 9/9)<sup>9−9/9</sup> − 9/9. All base 10 Friedman numbers with 7 or fewer digits have been computed.[^o11]
- It has been proven that [repdigits](wikipedia://en/216551) with at least 22 digits are nice Friedman numbers.[^o11]

There are an infinite number of prime Friedman numbers in all bases, because for base $2 \leq b \leq 6$ the numbers

$n \times 10^{1111} + 11111111 = n \times 10^{1111} + 10^{1000} - 1 + 0 + 0$ in base 2

$n \times 10^{102} + 1101221 = n \times 10^{102} + 2^{101} + 0 + 0$ in base 3

$n \times 10^{20} + 310233 = n \times 10^{20} + 33^{3} + 0$ in base 4

$n \times 10^{13} + 2443111 = n \times 10^{4 + 4} + (2 \times 3)^{11}$ in base 5

$n \times 10^{13} + 25352411 = n \times 10^{2 \times 5 - 1} + (5 + 2)^{(3 + 4)}$ in base 6

for base $7 \leq b \leq 10$ the numbers

$n \times 10^{60} + 164351 = n \times 10^{60} + (10 + 4 - 3)^5 + 0 + 0 + \ldots$ in base 7,

$n \times 10^{60} + 163251 = n \times 10^{60} + (10 + 3 - 2)^5 + 0 + 0 + \ldots$ in base 8,

$n \times 10^{60} + 162151 = n \times 10^{60} + (10 + 2 - 1)^5 + 0 + 0 + \ldots$ in base 9,

$n \times 10^{60} + 161051 = n \times 10^{60} + (10 + 1 - 0)^5 + 0 + 0 + \ldots$ in base 10,

and for base $b > 10$

$$n \times 10^{50} + \text{15AA51} = n \times 10^{50} + (10 + \text{A}/\text{A})^5 + 0 + 0 + \ldots$$

are Friedman numbers for all $n$. The numbers of this form are an arithmetic sequence $pn + q$, where $p$ and $q$ are relatively prime regardless of base as $b$ and $b + 1$ are always relatively prime, and therefore, by [Dirichlet's theorem on arithmetic progressions](wikipedia://en/101453), the sequence contains an infinite number of primes.

## Using Roman numerals {#Using_Roman_numerals}

In a trivial sense, all [Roman numerals](https://en.wikipedia.org/wiki/Roman_numeral) with more than one symbol are Friedman numbers. The expression is created by simply inserting + signs into the numeral, and occasionally the − sign with slight rearrangement of the order of the symbols.

Some research into Roman numeral Friedman numbers for which the expression uses some of the other operators has been done. The first such nice Roman numeral Friedman number discovered was 8, since VIII = (V - I) × II. Other such nontrivial examples have been found.

The difficulty of finding nontrivial Friedman numbers in Roman numerals increases not with the size of the number (as is the case with [positional notation](wikipedia://en/437052) numbering systems) but with the numbers of symbols it has. For example, it is much tougher to figure out whether 147 (CXLVII) is a Friedman number in Roman numerals than it is to make the same determination for 1001 (MI). With Roman numerals, one can at least derive quite a few Friedman expressions from any new expression one discovers. Since 8 is a nice nontrivial nice Roman numeral Friedman number, it follows that any number ending in VIII is also such a Friedman number.
