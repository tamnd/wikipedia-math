# Centered cube number

::: {#o1 .subject cue=lead name="Centered cube number"}

A **centered cube number** is a [centered](https://en.wikipedia.org/wiki/Centered_number) [figurate number](wikipedia://en/325260) that counts the points in a three-dimensional pattern formed by a point surrounded by concentric [cubical](wikipedia://en/6285) layers of points, with $i^{2}$ points on the square faces of the $i$th layer. Equivalently, it is the number of points in a [body-centered cubic](https://en.wikipedia.org/wiki/Body-centered_cubic) pattern within a cube that has $n + 1$ points along each of its edges.

:::

The first few centered cube numbers are

[1](https://en.wikipedia.org/wiki/1_%28number%29), [9](https://en.wikipedia.org/wiki/9_%28number%29), [35](https://en.wikipedia.org/wiki/35_%28number%29), [91](https://en.wikipedia.org/wiki/91_%28number%29), [189](https://en.wikipedia.org/wiki/189_%28number%29), 341, 559, 855, 1241, [1729](wikipedia://en/512549), 2331, 3059, 3925, 4941, 6119, 7471, 9009, ... .

::: {#o4 .statement cue=named-heading name="Formulas"}

## Formulas {#Formulas}

The centered cube number for a pattern with $n$ concentric layers around the central point is given by the formula[^o5]

$$n^3 + (n + 1)^3 = (2n+1)\left(n^2+n+1\right).$$

The same number can also be expressed as a [trapezoidal number](https://en.wikipedia.org/wiki/Trapezoidal_number) (difference of two [triangular numbers](wikipedia://en/213915)), or a sum of consecutive numbers, as[^o6]

$$\binom{(n+1)^2+1}{2}-\binom{n^2+1}{2} = (n^2+1)+(n^2+2)+\cdots+(n+1)^2.$$

:::

## Properties {#Properties}

Because of the factorization $(2n + 1)(n^{2} + n + 1)$, it is impossible for a centered cube number to be a [prime number](wikipedia://en/23666). The only centered cube numbers which are also the [square numbers](wikipedia://en/213919) are 1 and 9,[^o10][^o11] which can be shown by solving $x^{2} = y^{3} + 3y$, the only integer solutions being (x,y) from {(0,0), (1,2), (3,6), (12,42)}, By substituting a=(x-1)/2 and b=y/2, we obtain x^2=2y^3+3y^2+3y+1. This gives only (a,b) from {(-1/2,0), (0,1), (1,3), (11/2,21)} where a,b are half-integers.

:::
