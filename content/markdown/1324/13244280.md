# Multiple discriminant analysis

::: {#o1 .subject cue=lead name="Multiple discriminant analysis"}

**Multiple Discriminant Analysis** (MDA) is a multivariate [dimensionality reduction](wikipedia://en/579867) technique. It has been used to predict signals as diverse as [neural](https://en.wikipedia.org/wiki/Neural) memory traces and corporate failure.[^o2]

:::

MDA is not directly used to perform classification. It merely supports [classification](wikipedia://en/1579244) by yielding a [compressed signal](wikipedia://en/8013) amenable to classification. The method described in Duda et al. (2001) §3.8.3 projects the multivariate signal down to an *M*−1 dimensional space where *M* is the number of categories.

MDA is useful because most classifiers are strongly affected by the [curse of dimensionality](wikipedia://en/787776). In other words, when signals are represented in very-high-dimensional spaces, the classifier's performance is catastrophically impaired by the [overfitting](wikipedia://en/173332) problem. This problem is reduced by compressing the signal down to a lower-dimensional space as MDA does.

MDA has been used to reveal [neural codes](https://en.wikipedia.org/wiki/Neural_coding).[^o3][^o4]
