# Danzer's configuration

::: {#o1 .subject cue=lead name="Danzer's configuration"}

*Image: danzer\_graph.svg.* The [Levi graph](wikipedia://en/1396888) of Danzer's configuration as [unit distance graph](wikipedia://en/7158665)

In mathematics, **Danzer's configuration** is a self-dual [configuration](wikipedia://en/7200539) of 35 lines and 35 points, having 4 points on each line and 4 lines through each point. It is named after the German geometer [Ludwig Danzer](wikipedia://en/55861929) and was popularised by [Branko Grünbaum](wikipedia://en/1731976).[^n1] The [Levi graph](wikipedia://en/1396888) of the configuration is the [Kronecker cover](wikipedia://en/21241712) of the [odd graph](https://en.wikipedia.org/wiki/Odd_graph) O<sub>4</sub>,[^n2] and is isomorphic to the [middle layer graph](https://en.wikipedia.org/wiki/Middle_layer_graph) of the seven-dimensional [hypercube graph](wikipedia://en/6706815) Q<sub>7</sub>. The middle layer graph of an odd-dimensional hypercube graph Q<sub>2n+1</sub>(n,n+1) is a subgraph whose vertex set consists of all binary strings of length 2n + 1 that have exactly n or n + 1 entries equal to 1, with an edge between any two vertices for which the corresponding binary strings differ in exactly one bit. Every middle layer graph is Hamiltonian.[^n3]

:::

Danzer's configuration DCD(4) is the fourth term of an infinite series of $(\tbinom {2n-1}{n}_n)$ configurations DCD(n), where DCD(1) is the trivial configuration (1<sub>1</sub>), DCD(2) is the trilateral (3<sub>2</sub>) and DCD(3) is the [Desargues configuration](wikipedia://en/7209841) (10<sub>3</sub>). In [^n4] configurations DCD(n) were further generalized to the unbalanced $(\tbinom {n}{d}_d, \tbinom {n}{d-1}_{n-d+1})$ configuration DCD(n,d) by introducing parameter d with connection DCD(n) = DCD(2n-1,n). DCD stands for Desargues-Cayley-Danzer. Each DCD(2n,d) configuration is a subconfiguration of the $(2^{2n}_{2n+1})$ [Clifford configuration](https://en.wikipedia.org/wiki/Clifford_configuration). While each DCD(n,d) admits a realisation as a geometric point-line configuration, the Clifford configuration can only be realised as a point-circle configuration and depicts the [Clifford's circle theorems](wikipedia://en/19335333).
