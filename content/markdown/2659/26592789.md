# Saturated set

::: {#o1 .subject cue=lead name="Saturated set"}

In [mathematics](wikipedia://en/18831), particularly in the subfields of [set theory](wikipedia://en/27553) and [topology](wikipedia://en/29954), a set $C$ is said to be **saturated** with respect to a function $f : X \to Y$ if $C$ is a subset of $f$'s [domain](wikipedia://en/50263) $X$ and if whenever $f$ sends two points $c \in C$ and $x \in X$ to the same value then $x$ belongs to $C$ (that is, if $f(x) = f(c)$ then $x \in C$). Said more succinctly, the set $C$ is called saturated if $C = f^{-1}(f(C)).$

:::

In [topology](wikipedia://en/29954), a [subset](wikipedia://en/27631) of a [topological space](wikipedia://en/30450) $(X, \tau)$ is **saturated** if it is equal to an [intersection](wikipedia://en/23476429) of [open subsets](wikipedia://en/39358) of $X.$ In a [T<sub>1</sub> space](wikipedia://en/148721) every set is saturated.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### Preliminaries {#Preliminaries}

Let $f : X \to Y$ be a map. Given any subset $S\subseteq X,$ define its [image](wikipedia://en/579311) under $f$ to be the set:

$$f(S) := \{f(s) ~:~ s \in S\}$$

and define its [preimage](https://en.wikipedia.org/wiki/Preimage) or [inverse image](https://en.wikipedia.org/wiki/Inverse_image) under $f$ to be the set:

$$f^{-1}(S) := \{x \in X ~:~ f(x) \in S\}.$$

Given $y \in Y,$ the [fiber](wikipedia://en/6603892) of $f$ over $y$ is defined to be the preimage:

$$f^{-1}(y) := f^{-1}(\{y\}) = \{x \in X ~:~ f(x) = y\}.$$

Any preimage of a single point in $f$'s codomain $Y$ is referred to as **a** fiber of $f.$

### Saturated sets {#Saturated_sets}

A set $C$ is called **$f$-saturated** and is said to be **saturated** with respect to $f$ if $C$ is a subset of $f$'s domain $X$ and if any of the following equivalent conditions are satisfied:[^n1]

1. $$C = f^{-1}(f(C)).$$
1. There exists a set $S$ such that $C = f^{-1}(S).$
   - Any such set $S$ necessarily contains $f(C)$ as a subset and moreover, it will also necessarily satisfy the equality $f(C) = S \cap \operatorname{Im} f,$ where $\operatorname{Im} f := f(X)$ denotes the [image](wikipedia://en/579311) of $f.$
1. If $c \in C$ and $x \in X$ satisfy $f(x) = f(c),$ then $x \in C.$
1. If $y \in Y$ is such that the fiber $f^{-1}(y)$ intersects $C$ (that is, if $f^{-1}(y) \cap C \neq \varnothing$), then this entire fiber is necessarily a subset of $C$ (that is, $f^{-1}(y) \subseteq C$).
1. For every $y \in Y,$ the intersection $C \cap f^{-1}(y)$ is equal to the [empty set](wikipedia://en/9566) $\varnothing$ or to $f^{-1}(y).$

Related to [computability theory](wikipedia://en/155414), this notion can be extended to programs. Here, considering a subset $A \subseteq \mathbb{N}$, this can be considered **saturated** (or **extensional**) if $\forall m, n \in \mathbb{N}, m \in A, \vee \phi_m = \phi_n \Rightarrow n \in A$. In words, given two programs, if the first program is in the set of programs satisfying the property and two programs are computing the same thing, then also the second program satisfies the property. This means that if one program with a certain property is in the set, all programs computing the same function must also be in the set).

In this context, this notion can extend [Rice's theorem](wikipedia://en/25852), stating that:

Let $A$ be a subset such that $A \neq \emptyset, A \neq \mathbb{N}, A \subseteq N$. If $A$ is saturated, then $A$ is not recursive.

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

Let $f : X \to Y$ be any function. If $S$ is any set then its preimage $C:= f^{-1}(S)$ under $f$ is necessarily an $f$-saturated set. In particular, every fiber of a map $f$ is an $f$-saturated set.

The [empty set](wikipedia://en/9566) $\varnothing = f^{-1}(\varnothing)$ and the domain $X = f^{-1}(Y)$ are always saturated. Arbitrary [unions](https://en.wikipedia.org/wiki/Union_%28mathematics%29) of saturated sets are saturated, as are arbitrary [intersections](wikipedia://en/41780044) of saturated sets.

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $S$ and $T$ be any sets and let $f : X \to Y$ be any function.

If $S$ **or** $T$ is $f$-saturated then

$$f(S \cap T) ~=~ f(S) \cap f(T).$$

If $T$ is $f$-saturated then

$$f(S \setminus T) ~=~ f(S) \setminus f(T)$$

where note, in particular, that no requirements or conditions were placed on the set $S.$

If $\tau$ is a [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29) on $X$ and $f : X \to Y$ is any map then set $\tau_f$ of all $U \in \tau$ that are $f$-saturated subsets of $X$ forms a topology on $X.$ If $Y$ is also a topological space then $f : (X, \tau) \to Y$ is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) (respectively, a [quotient map](https://en.wikipedia.org/wiki/Quotient_map_%28topology%29)) if and only if the same is true of $f : \left(X, \tau_f\right) \to Y.$

:::
