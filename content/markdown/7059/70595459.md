# Jamovi

::: {#o2 .subject cue=lead name="Jamovi"}

**jamovi** (stylised in all lower-case) is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source_software) computer program for [data analysis](wikipedia://en/2720954) and performing [statistical](wikipedia://en/26685) tests. The core developers of jamovi are Jonathon Love, Damian Dropmann, and Ravi Selker, who were developers for the [JASP](https://en.wikipedia.org/wiki/JASP) project.[^o3]

:::

## Software {#Software}

jamovi is an open source [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) for the [R programming language](wikipedia://en/376707).[^o5] It is used in statistical research, especially as a tool for [ANOVA (analysis of variance)](wikipedia://en/634) and to understand [statistical inference](wikipedia://en/27577).[^o6][^o7] It also can be used for [linear regression](wikipedia://en/48758386),[^o8] [mixed models](wikipedia://en/5431921) and [Bayesian models](https://en.wikipedia.org/wiki/Bayesian_models).[^o9]

Data is entered into a spreadsheet interface[^o10] that can be imported into jamovi. If data are changed, all calculations and analyses affected by the change are automatically updated.[^o8] The software includes a [multinomial test](wikipedia://en/16093546) to determine whether observed data differs from researchers' predictions.[^o11]

## Extendibility {#Extendibility}

jamovi comes with a basic library of statistical and graphical procedures. In addition, users can install modules from a library of community created open source add-on modules to extend the package's capabilities.[^o13][^o14] These modules are written in the [R programming language](wikipedia://en/376707) and make use of the jmv[^o15] and jmvtools[^o16] libraries to create the interface and display code. Numerous modules exist and can be accessed in the curated library within jamovi. Over 40 modules[^o17] have been created by the jamovi community and extend the functionality of the program. These additional analyses include agreement and reliability analyses[^o18] [mediation models](wikipedia://en/7072682),[^o19][^o20] [meta-analysis](wikipedia://en/62329),[^o17] [power analysis](https://en.wikipedia.org/wiki/Statistical_power),[^o21] [psychometrics](wikipedia://en/24982),[^o22] [structural equation models](https://en.wikipedia.org/wiki/Structural_equation_models),[^o23] [survival analysis](wikipedia://en/419259),[^o24] and [likelihood/evidential analyses](wikipedia://en/60224882).[^o25][^o26]

## Documentation {#Documentation}

A detailed user manual is available for jamovi. Third party learning resources are also available including free books and video tutorials in multiple languages including Chinese, Hindi, Spanish, Korean, and Malayalam [^o28]

## Evaluating Accuracy {#Evaluating_Accuracy}

One paper compared the results of frequencies, means, correlations and regression from a number of free to use menu driven statistical packages, including jamovi, and found all of the packages produced about the same results.[^o30]
