# Fedosov manifold

::: {#o1 .subject cue=lead name="Fedosov manifold"}

In mathematics, a **Fedosov manifold** is a [symplectic manifold](wikipedia://en/28356) with a compatible torsion-free [connection](wikipedia://en/308815), that is, a triple (*M*, ω, ∇), where (*M*, ω) is a [symplectic manifold](wikipedia://en/28356) (that is, $\omega$ is a [symplectic form](wikipedia://en/28356), a non-degenerate closed exterior 2-form, on a $C^{\infty}$-manifold *M*), and ∇ is a symplectic torsion-free connection on $M.$[^o2] (A connection ∇ is called **compatible** or **symplectic** if *X* ⋅ ω(*Y,Z*) = ω(∇<sub>*X*</sub>*Y*,*Z*) + ω(*Y*,∇<sub>*X*</sub>*Z*) for all vector fields *X,Y,Z* ∈ Γ(T*M*). In other words, the symplectic form is parallel with respect to the connection, i.e., its [covariant derivative](wikipedia://en/431848) vanishes.) Note that every symplectic manifold admits a symplectic torsion-free connection. Cover the manifold with [Darboux charts](https://en.wikipedia.org/wiki/Darboux_chart) and on each chart define a connection ∇ with Christoffel symbol $\Gamma^i_{jk}=0$. Then choose a [partition of unity](wikipedia://en/48636) (subordinate to the cover) and glue the local connections together to a global connection which still preserves the symplectic form. The famous result of [Boris Vasilievich Fedosov](https://en.wikipedia.org/wiki/Boris_Fedosov) gives a canonical [deformation quantization](wikipedia://en/4278245) of a Fedosov manifold.[^o3]

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

For example, $\mathbb{R}^{2n}$ with the standard symplectic form $dx_i \wedge dy_i$ has the symplectic connection given by the exterior derivative $d.$ Hence, $\left(\mathbb{R}^{2n}, \omega, d\right)$ is a Fedosov manifold.
