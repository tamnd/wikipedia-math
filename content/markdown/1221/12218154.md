# Cylindrical algebraic decomposition

::: {#o1 .subject cue=lead name="Cylindrical algebraic decomposition"}

In [mathematics](wikipedia://en/18831), **cylindrical algebraic decomposition** (**CAD**) is a notion, along with an [algorithm](wikipedia://en/775) to compute it, that is fundamental for [computer algebra](wikipedia://en/23659805) and [real algebraic geometry](wikipedia://en/7252198). Given a set *S* of polynomials in **R**<sup>*n*</sup>, a cylindrical algebraic decomposition is a decomposition of **R**<sup>*n*</sup> into connected [semialgebraic sets](wikipedia://en/13329722) called *cells*, on which each polynomial has constant sign, either +, − or 0. To be *cylindrical*, this decomposition must satisfy the following condition: If 1 ≤ *k* \< *n* and *π* is the projection from **R**<sup>*n*</sup> onto **R**<sup>*n*−*k*</sup> consisting in removing the last *k* coordinates, then for every pair of cells *c* and *d*, one has either *π*(*c*) = *π*(*d*) or *π*(*c*) ∩ *π*(*d*) = ∅. This implies that the images by *π* of the cells define a cylindrical decomposition of **R**<sup>*n*−*k*</sup>.

:::

The notion was introduced by [George E. Collins](wikipedia://en/41768958) in 1975, together with an [algorithm](wikipedia://en/775) for computing it.

Collins' algorithm has a [computational complexity](wikipedia://en/2230) that is [double exponential](wikipedia://en/8541166) in *n*. This is an upper bound, which is reached on most entries. There are also examples for which the minimal number of cells is doubly exponential, showing that every general algorithm for cylindrical algebraic decomposition has a double exponential complexity.

CAD provides an effective version of [quantifier elimination](wikipedia://en/2150441) over the reals that has a much better computational complexity than that resulting from the original proof of [Tarski–Seidenberg theorem](wikipedia://en/19389633). It is efficient enough to be implemented on a computer. It is one of the most important algorithms of computational [real algebraic geometry](wikipedia://en/7252198). Searching to improve Collins' algorithm, or to provide algorithms that have a better complexity for subproblems of general interest, is an active field of research.
