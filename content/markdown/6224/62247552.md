# Go First Dice

::: {#o1 .subject cue=lead name="Go First Dice"}

**Go First Dice** are a set of [dice](https://en.wikipedia.org/wiki/Dice) in which, when rolled together, each die has an equal chance of showing the highest number, the second highest number, and so on.[^o2][^o3]

:::

The dice are intended for fairly deciding the order of play in, for example, a board game. The number on each side is unique among the set, so that no ties can be formed.

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

There are three properties of fairness, with increasing strength:[^o2]

- **Go-first-fair** - Each player has an equal chance of rolling the highest number (going first).
- **Place-fair** - When all the rolls are ranked in order, each player has an equal chance of receiving each rank.
- **Permutation-fair** - Every possible ordering of players has an equal probability, which also ensures it is "place-fair".

It is also desired that any subset of dice taken from the set and rolled together should also have the same properties, so they can be used for fewer players as well.

Configurations where all dice have the same number of sides are presented here, but alternative configurations might instead choose mismatched dice to minimize the number of sides, or minimize the largest number of sides on a single die.

Sets may be optimized for smallest [least common multiple](wikipedia://en/17961), fewest total sides, or fewest sides on the largest die. Optimal results in each of these categories have been proven by exhaustion for up to 4 dice.[^o2]

:::

## Configurations {#Configurations}

### Two players {#Two_players}

The two player case is somewhat trivial. Two coins (2-sided dice) can be used:

|---|---|---|
| Die 2 | 2 | 3 |

### Three players {#Three_players}

An optimal and permutation-fair solution for three 6-sided dice was found by Robert Ford in 2010.[^o2] There are several optimal alternatives using mismatched dice.

### Five players {#Five_players}

Several candidates exist for a set of five dice, but none is known to be optimal.

A not-permutation-fair solution for five 60-sided dice was found by James Grime and Brian Pollock. A permutation-fair solution for a mixed set of one 36-sided die, two 48-sided dice, one 54-sided die, and one 20-sided die was found by [Eric Harshbarger](wikipedia://en/6327878) in 2023.[^o14] Note that some of these dice would not be able to have more than one rotation axis of order more than 2 (as regular polyhedra have)see [Point groups in three dimensions](wikipedia://en/2694525).

A permutation-fair solution for five 60-sided dice was found by Paul Meyer in 2023.[^o15]
