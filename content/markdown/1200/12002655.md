# Star-shaped polygon

*Image: Star-kernel.svg.* A star-shaped polygon (top). Its kernel is shown at the bottom in red.

::: {#o1 .subject cue=lead name="Star-shaped polygon"}

In [geometry](wikipedia://en/18973446), a **star-shaped polygon** is a [polygonal region](https://en.wikipedia.org/wiki/Polygonal_region) in the [euclidean plane](wikipedia://en/9697) which is a [star domain](wikipedia://en/5983414), that is, a polygon that contains a point from which the entire polygon boundary is [visible](wikipedia://en/12003132).

:::

Formally, a polygon $P$ is star-shaped if there exists a point $z$ such that for each point $p$ of $P$ the segment $\overline{zp}$ lies entirely within $P$.[^o2] The [set](wikipedia://en/26691) of all points $z$ with this property (that is, the set of points from which all of $P$ is visible) is called the **kernel** of $P$.

If a star-shaped polygon is [convex](wikipedia://en/660019), the [link distance](wikipedia://en/50761879) between any two of its points (the minimum number of sequential line segments sufficient to connect those points) is 1, and so the polygon's link diameter (the maximum link distance over all pairs of points) is 1. If a star-shaped polygon is not convex, the link distance between a point in the kernel and any other point in the polygon is 1, while the link distance between any two points that are in the polygon but outside the kernel is either 1 or 2; in this case the maximum link distance is 2.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

[Convex polygons](wikipedia://en/660019) are star shaped, and a convex polygon coincides with its own kernel.

[Visibility polygons](wikipedia://en/12003132) are star-shaped as every point within them must be visible to the center by definition.

:::

## Algorithms {#Algorithms}

Testing whether a polygon is star-shaped, and finding a single point in the kernel, may be solved in [linear time](https://en.wikipedia.org/wiki/Linear_time) by formulating the problem as a [linear program](https://en.wikipedia.org/wiki/Linear_program) and applying techniques for low-dimensional linear programming (see http://www.inf.ethz.ch/personal/emo/PublFiles/SubexLinProg\_ALG16\_96.pdf, page 16).

Each edge of a polygon defines an **interior [half-plane](https://en.wikipedia.org/wiki/Half-plane)**, the half-plane whose boundary lies on the line containing the edge and that contains the points of the polygon in a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of any interior point of the edge. The kernel of a polygon is the intersection of all its interior half-planes. The intersection of an arbitrary set of *N* half-planes may be found in [Θ](wikipedia://en/44578)(*N* log *N*) time using the [divide and conquer approach](https://en.wikipedia.org/wiki/Divide_and_conquer_approach).[^o2] However, for the case of kernels of polygons, a faster method is possible: (Lee Preparata 1979)[^o8] presented an algorithm to construct the kernel in linear time.
