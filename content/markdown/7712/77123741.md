# Wu manifold

::: {#o1 .subject cue=lead name="Wu manifold"}

In mathematics, the **Wu manifold** is a [5-manifold](wikipedia://en/7763362) defined as a quotient space of [Lie groups](wikipedia://en/17945) appearing in the mathematical area of [Lie theory](wikipedia://en/1595681). Due to its special properties it is of interest in [algebraic topology](wikipedia://en/38801), [cobordism theory](https://en.wikipedia.org/wiki/Cobordism_theory) and [spin geometry](wikipedia://en/32013990). The manifold was first studied and named after [Wu Wenjun](https://en.wikipedia.org/wiki/Wu_Wenjun).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group) $\operatorname{SO}(n)$ embeds canonically in the [special unitary group](wikipedia://en/173997) $\operatorname{SU}(n)$. The [orbit space](https://en.wikipedia.org/wiki/Orbit_space):

$$W:=\operatorname{SU}(3)/\operatorname{SO}(3)$$

is the Wu manifold.[^o4][^o10]

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- $W$ is a [simply connected](wikipedia://en/523879) [rational homology sphere](https://en.wikipedia.org/wiki/Rational_homology_sphere) (with non-trivial [homology groups](https://en.wikipedia.org/wiki/Homology_groups) $H_0(W)\cong\mathbb{Z}$, $H_2(W)\cong\mathbb{Z}_2$[^o7] and $H_5(W)\cong\mathbb{Z}$), which is not a [sphere](wikipedia://en/27859). Since in four or lower dimensions, every simply connected rational homology sphere is in fact a sphere, $W$ provides a counterexample of lowest possible dimension.[^o8][^o9]
- $W$ has the [cohomology groups](https://en.wikipedia.org/wiki/Cohomology_groups):[^o4]

$$H^0(W;\mathbb{Z}_2) =\mathbb{Z}_2$$

$$H^1(W;\mathbb{Z}_2) =1$$

$$H^2(W;\mathbb{Z}_2) =\mathbb{Z}_2$$

$$H^3(W;\mathbb{Z}_2) =\mathbb{Z}_2$$

$$H^4(W;\mathbb{Z}_2) =1$$

$$H^5(W;\mathbb{Z}_2) =\mathbb{Z}_2$$

- $W$ is a generator of the [oriented cobordism](https://en.wikipedia.org/wiki/Oriented_cobordism) group $\Omega_5^{\operatorname{SO}}\cong\mathbb{Z}_2$.[^o4][^o10] This can be detected using the [de Rham invariant](wikipedia://en/25901631), a particular [Stiefel–Whitney number](wikipedia://en/877761), which describes an [isomorphism](wikipedia://en/14828) $w_2w_3\colon\Omega_5^\mathrm{SO}\rightarrow\mathbb{Z}_2$. Since the first Stiefel-Whitney class vanishes due to orientability, all other Stiefel-Whitney numbers automatically vanish. As a consequence, any orientable 5-manifold with non-vanishing de Rham invariant is orientable bordant to $W$, which for example includes the [Dold manifold](wikipedia://en/31337422) $P(2,1)=(S^1\times\mathbb{C}P^2)/\mathbb{Z}_2$. Both yield to each other under [surgery](wikipedia://en/5961115) for [embeddings](wikipedia://en/52119) $S^2\times D^3\hookrightarrow W$ and $S^1\times D^4\hookrightarrow P(2,1)$ with common [boundary](wikipedia://en/72824) $S^2\times S^3$. An oriented bordism is then given by the [cartesian product](wikipedia://en/24104095) of one manifold with the [unit interval](wikipedia://en/49324) and then the corresponding surgery on one end.
- $W$ has a non-vanishing second and third [Stiefel–Whitney class](wikipedia://en/877761) as well as a non-vanishing third integral Stiefel–Whitney class:[^o11]

$$w_2(W)\neq 0;$$

$$w_3(W)\neq 0;$$

$$W_3(W)\neq 0.$$

- $W$ can be [immersed](wikipedia://en/6993953) in $\mathbb{R}^8$, but not in $\mathbb{R}^7$. This is because all simply connected 5-manifolds can be immersed in $\mathbb{R}^8$ with the third integral Stiefel-Whitney class vanishing [if and only if](wikipedia://en/14922) it can be reduced to $\mathbb{R}^7$ and the second Stiefel-Whitney class vanishing if and only if it can be further reduced to $\mathbb{R}^6$. Both isn't the case due to the previous property.[^o12]
- $W$ is a [spin<sup>h</sup> manifold](https://en.wikipedia.org/wiki/Spinh_manifold) which doesn't allow a [spin<sup>c</sup> structure](wikipedia://en/79367906). The latter property comes from the fact that a spin<sup>c</sup> structure implies a vanishing third Stiefel-Whitney class, which isn't the case here.
