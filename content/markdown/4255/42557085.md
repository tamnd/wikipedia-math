# Quasi-commutative property

::: {#o1 .subject cue=lead name="Quasi-commutative property"}

In [mathematics](wikipedia://en/18831), the **quasi-commutative property** is an extension or generalization of the general [commutative property](wikipedia://en/294390). This property is used in specific applications with various definitions.

:::

## Applied to matrices {#Applied_to_matrices}

Two [matrices](wikipedia://en/20556859) $p$ and $q$ are said to have the [commutative property](wikipedia://en/294390) whenever

$$pq = qp$$

The quasi-commutative property in matrices is defined[^o3] as follows. Given two non-commutable matrices $x$ and $y$

$$xy - yx = z$$

satisfy the quasi-commutative property whenever $z$ satisfies the following properties:

$$\begin{aligned} xz &= zx \\ yz &= zy \end{aligned}$$

An example is found in the [matrix mechanics](https://en.wikipedia.org/wiki/Matrix_mechanics) introduced by [Heisenberg](https://en.wikipedia.org/wiki/Werner_Heisenberg) as a version of [quantum mechanics](wikipedia://en/25202). In this mechanics, *p* and *q* are infinite matrices corresponding respectively to the momentum and position variables of a particle.[^o3] These matrices are written out at [Matrix mechanics#Harmonic oscillator](https://en.wikipedia.org/wiki/Matrix_mechanics#Harmonic_oscillator), and z = iħ times the infinite [unit matrix](wikipedia://en/59718), where ħ is the [reduced Planck constant](https://en.wikipedia.org/wiki/Reduced_Planck_constant).

## Applied to functions {#Applied_to_functions}

A function $f : X \times Y \to X$ is said to be **quasi-commutative**[^o5] if

$$f\left(f\left(x, y_1\right), y_2\right) = f\left(f\left(x, y_2\right), y_1\right) \qquad \text{ for all } x \in X, \; y_1, y_2 \in Y.$$

If $f(x, y)$ is instead denoted by $x \ast y$ then this can be rewritten as:

$$(x \ast y) \ast y_2 = \left(x \ast y_2\right) \ast y \qquad \text{ for all } x \in X, \; y, y_2 \in Y.$$
