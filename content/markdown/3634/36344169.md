# Linear forest

*Image: Linear forest.svg.* A linear forest

::: {#o1 .subject cue=lead name="Linear forest"}

In [graph theory](wikipedia://en/12401), a branch of [mathematics](wikipedia://en/18831), a **linear forest** is a kind of [forest](https://en.wikipedia.org/wiki/Forest_%28graph_theory%29) where each [component](wikipedia://en/246223) is a [path graph](wikipedia://en/4587190),[^o2] or a [disjoint union](wikipedia://en/9938459) of nontrivial paths.[^o3] Equivalently, it is an [acyclic](wikipedia://en/168609) and [claw-free](wikipedia://en/12415907) [graph](wikipedia://en/325806).[^o4] An acyclic graph where every [vertex](wikipedia://en/638899) has [degree](wikipedia://en/1374448) 0, 1, or 2 is a linear forest.[^o5][^o6] An [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) has [Colin de Verdière graph invariant](https://en.wikipedia.org/wiki/Colin_de_Verdière_graph_invariant) at most 1 [if and only if](wikipedia://en/14922) it is a (node-)disjoint union of paths, i.e. it is linear.[^o7][^o8] Any linear forest is a subgraph of the path graph with the same number of vertices.[^o9]

:::

## Extensions to the notation {#Extensions_to_the_notation}

According to Habib and Peroche, a *k*-linear forest consists of paths of *k* or fewer nodes each.[^o11]

According to Burr and Roberts, an (*n*, *j*)-linear forest has *n* vertices and *j* of its component paths have an [odd](wikipedia://en/143135) number of vertices.[^o3]

According to Faudree et al., a (*k*, *t*)-linear or (*k*, *t*, *s*)-linear forest has *k* [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29), and *t* components of which *s* are single vertices; *s* is omitted if its value is not critical.[^o12]

## Derived concepts {#Derived_concepts}

The [linear arboricity](wikipedia://en/36344163) of a graph is the minimum number of linear forests into which the graph can be partitioned. For a graph of maximum degree $\Delta$, the linear arboricity is always at least $\lceil\Delta/2\rceil$, and it is [conjectured](wikipedia://en/6138) that it is always at most $\lfloor(\Delta+1)/2\rfloor$.[^o14]

A linear coloring of a graph is a proper [graph coloring](wikipedia://en/426743) in which the [induced subgraph](wikipedia://en/1655188) formed by each two colors is a linear forest. The linear chromatic number of a graph is the smallest number of colors used by any linear coloring. The linear chromatic number is at most proportional to $\Delta^{3/2}$, and there exist graphs for which it is at least proportional to this quantity.[^o15]
