# Markov–Krein theorem

::: {#o1 .subject cue=lead name="Markov–Krein theorem"}

In [probability theory](wikipedia://en/23542), the **Markov–Krein theorem** gives the best upper and lower bounds on the expected values of certain functions of a random variable where only the first moments of the random variable are known.[^o2][^o3][^o4][^o5] The result is named after [Andrey Markov](wikipedia://en/915) and [Mark Krein](wikipedia://en/1190470).[^o6]

:::

The theorem can be used to bound average response times in the [M/G/k queueing](wikipedia://en/33986587) system.[^o7]
