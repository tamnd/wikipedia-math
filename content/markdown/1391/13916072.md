# Symplectization

::: {#o1 .subject cue=lead name="Symplectization"}

In [mathematics](wikipedia://en/18831), the **symplectization** (or **symplectification**) of a [contact manifold](https://en.wikipedia.org/wiki/Contact_manifold) is a [symplectic manifold](wikipedia://en/28356) which naturally corresponds to it.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(V,\xi)$ be a contact manifold, and let $x \in V$. Consider the set

$$S_xV = \{\beta \in T^*_xV - \{ 0 \} \mid \ker \beta = \xi_x\} \subset T^*_xV$$

of all nonzero [1-forms](https://en.wikipedia.org/wiki/1-form) at $x$, which have the contact plane $\xi_x$ as their kernel. The union

$$SV = \bigcup_{x \in V}S_xV \subset T^*V$$

is a [symplectic submanifold](https://en.wikipedia.org/wiki/Symplectic_submanifold) of the [cotangent bundle](wikipedia://en/221600) of $V$, and thus possesses a natural symplectic structure.

The [projection](wikipedia://en/3909097) $\pi : SV \to V$ supplies the symplectization with the structure of a [principal bundle](wikipedia://en/310950) over $V$ with [structure group](wikipedia://en/310950) $\mathbb{R}^* \equiv \mathbb{R} - \{0\}$.

:::

## The coorientable case {#The_coorientable_case}

When the [contact structure](https://en.wikipedia.org/wiki/Contact_structure) $\xi$ is [cooriented](https://en.wikipedia.org/wiki/Coorientation) by means of a [contact form](https://en.wikipedia.org/wiki/Contact_form) $\alpha$, there is another version of symplectization, in which only forms giving the same coorientation to $\xi$ as $\alpha$ are considered:

$$S^+_xV = \{\beta \in T^*_xV - \{0\} \,|\, \beta = \lambda\alpha,\,\lambda > 0\} \subset T^*_xV,$$

$$S^+V = \bigcup_{x \in V}S^+_xV \subset T^*V.$$

Note that $\xi$ is coorientable if and only if the bundle $\pi : SV \to V$ is [trivial](https://en.wikipedia.org/wiki/Trivial_bundle). Any [section](wikipedia://en/367621) of this bundle is a coorienting form for the contact structure.
