# Superincreasing sequence

::: {#o1 .subject cue=lead name="Superincreasing sequence"}

In [mathematics](wikipedia://en/18831), a [sequence](wikipedia://en/27838) of positive [real numbers](wikipedia://en/20646438) $(s_1, s_2, ...)$ is called **superincreasing** if every element of the sequence is greater than the sum of all previous elements in the sequence.[^o2][^o3]

:::

Formally, this condition can be written as

$$s_{n+1} > \sum_{j=1}^n s_j$$

for all *n* ≥ 1.

## Program {#Program}

The following [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) source code tests a sequence of numbers to determine if it is superincreasing:

```python
def is_superincreasing_sequence(sequence) -> bool:
    """Tests if a sequence is superincreasing."""
    total = 0
    result = True
    for n in sequence:
        print("Sum: ", total, "Element: ", n)
        if n <= total:
            result = False
            break
        total += n
    return result

sequence = [1, 3, 6, 13, 27, 52]
result = is_superincreasing_sequence(sequence)
print("Is it a superincreasing sequence? ", result)
```

This produces the following output:

Sum: 0 Element: 1 Sum: 1 Element: 3 Sum: 4 Element: 6 Sum: 10 Element: 13 Sum: 23 Element: 27 Sum: 50 Element: 52 Is it a superincreasing sequence? True

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- (1, 3, 6, 13, 27, 52) is a **superincreasing sequence**, but (1, 3, 4, 9, 15, 25) is not.[^o3]
- The series a^x for a>=2

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Multiplying a superincreasing sequence by a positive real constant keeps it superincreasing.

:::
