# Antecedent variable

::: {#o1 .subject cue=lead name="Antecedent variable"}

In [statistics](wikipedia://en/26685) and [social sciences](https://en.wikipedia.org/wiki/Social_sciences), an **antecedent variable** is a [variable](wikipedia://en/3728109) that cannot help to explain the apparent relationship (or part of the relationship) between other variables that are nominally in a [cause and effect](https://en.wikipedia.org/wiki/Causality) relationship. In a [regression analysis](wikipedia://en/826997), an antecedent variable would be one that influences both the [independent variable](https://en.wikipedia.org/wiki/Independent_variable) and the [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable).

:::
