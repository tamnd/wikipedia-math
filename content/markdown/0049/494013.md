# Hexagonal number

::: {#o1 .subject cue=lead name="Hexagonal number"}

*Image: hexagonal\_number\_visual\_proof.svg.* [Proof without words](wikipedia://en/18045517) that a hexagonal number (middle column) can be rearranged as rectangular and odd-sided triangular numbers

A **hexagonal number** is a [figurate number](wikipedia://en/325260). The *n*th hexagonal number *h*<sub>*n*</sub> is the number of *distinct* dots in a pattern of dots consisting of the *outlines* of regular hexagons with sides up to n dots, when the hexagons are overlaid so that they share one [vertex](wikipedia://en/11308417).

*Image: Hexagonal\_numbers.svg.* The first four hexagonal numbers.

The formula for the *n*th hexagonal number

:::

$$h_n= 2n^2-n = n(2n-1) = \frac{2n(2n-1)}{2}.$$

The first few hexagonal numbers are:

[1](https://en.wikipedia.org/wiki/1_%28number%29), [6](https://en.wikipedia.org/wiki/6_%28number%29), [15](wikipedia://en/208252), [28](wikipedia://en/362213), [45](https://en.wikipedia.org/wiki/45_%28number%29), [66](https://en.wikipedia.org/wiki/66_%28number%29), [91](https://en.wikipedia.org/wiki/91_%28number%29), [120](https://en.wikipedia.org/wiki/120_%28number%29), [153](https://en.wikipedia.org/wiki/153_%28number%29), [190](https://en.wikipedia.org/wiki/190_%28number%29), [231](https://en.wikipedia.org/wiki/231_%28number%29), [276](https://en.wikipedia.org/wiki/276_%28number%29), [325](https://en.wikipedia.org/wiki/325_%28number%29), 378, 435, [496](https://en.wikipedia.org/wiki/496_%28number%29), 561, 630, 703, 780, 861, 946...

Every hexagonal number is a [triangular number](wikipedia://en/213915), but only every *other* triangular number (the 1st, 3rd, 5th, 7th, etc.) is a hexagonal number. Like a triangular number, the [digital root](wikipedia://en/8286632) in base 10 of a hexagonal number can only be 1, 3, 6, or 9. The digital root pattern, repeating every nine terms, is "1 6 6 1 9 3 1 3 9".

Every even [perfect number](wikipedia://en/23670) is hexagonal, given by the formula

$$M_p 2^{p-1} = M_p \frac{M_p + 1}{2} = h_{(M_p+1)/2}=h_{2^{p-1}}$$

where *M*<sub>*p*</sub> is a [Mersenne prime](wikipedia://en/18908). No odd perfect numbers are known, hence all known perfect numbers are hexagonal.

For example, the 2nd hexagonal number is 2×3 = 6; the 4th is 4×7 = 28; the 16th is 16×31 = 496; and the 64th is 64×127 = 8128.

The largest number that cannot be written as a sum of at most four hexagonal numbers is [130](https://en.wikipedia.org/wiki/130_%28number%29). [Adrien-Marie Legendre](wikipedia://en/49695) proved in 1830 that any [integer](wikipedia://en/14563) greater than 1791 can be expressed in this way.

In addition, only two integers cannot be expressed using five hexagonal numbers (but can be with six), those being 11 and 26.

Hexagonal numbers should not be confused with [centered hexagonal numbers](wikipedia://en/497485), which model the packing of [Vienna sausages](https://en.wikipedia.org/wiki/Vienna_sausage) found in North American canned varieties of the product. To avoid ambiguity, hexagonal numbers are sometimes called "cornered hexagonal numbers".

## Test for hexagonal numbers {#Test_for_hexagonal_numbers}

One can efficiently test whether a positive integer *x* is a hexagonal number by computing

$$n = \frac{\sqrt{8x+1}+1}{4}.$$

If *n* is an integer, then *x* is the *n*th hexagonal number. If *n* is not an integer, then *x* is not hexagonal.

## Congruence relations {#Congruence_relations}

- $$h_n \equiv n \pmod{4}$$
- $$h_{3n}+h_{2n}+h_{n} \equiv 0 \pmod{2}$$

## Other properties {#Other_properties}

### Expression using sigma notation {#Expression_using_sigma_notation}

The *n*th number of the hexagonal sequence can also be expressed by using [sigma notation](https://en.wikipedia.org/wiki/Sigma_notation) as

$$h_n = \sum_{k=0}^{n-1}{(4k+1)}$$

where the [empty sum](wikipedia://en/209748) is taken to be 0.

### Sum of the reciprocal hexagonal numbers {#Sum_of_the_reciprocal_hexagonal_numbers}

The sum of the reciprocal hexagonal numbers is $2\ln(2)$, where $\ln$ denotes [natural logarithm](wikipedia://en/21476).

$$\begin{aligned} \sum_{k=1}^{\infty} \frac{1}{k(2k-1)} &= \lim_{n \to \infty}2\sum_{k=1}^{n} \left(\frac{1}{2k-1} - \frac{1}{2k} \right)\\ &= \lim_{n \to \infty}2\sum_{k=1}^{n} \left(\frac{1}{2k-1} + \frac{1}{2k} - \frac{1}{k} \right)\\ &= 2 \lim_{n \to \infty}\left(\sum_{k=1}^{2n}\frac{1}{k} - \sum_{k=1}^{n}\frac{1}{k}\right)\\ &= 2 \lim_{n \to \infty}\sum_{k=1}^{n}\frac{1}{n+k} \\ &= 2 \lim_{n \to \infty}\frac{1}{n}\sum_{k=1}^{n}\frac{1}{1+\frac{k}{n}}\\ &= 2 \int_{0}^{1}\frac{1}{1+x}dx \\ &= 2 [ \ln(1+x) ]_{0}^{1} \\ &= 2 \ln{2}\\ & \approx{1.386294} \end{aligned}$$

### Multiplying the index {#Multiplying_the_index}

Using rearrangement, the next set of formulas is given:

$$h_{2n} = 4h_n+2n$$

$$h_{3n} = 9h_n+6n$$

$$...$$

$$h_{m*n} = m^{2}h_n+(m^{2}-m)n$$

### Ratio relation {#Ratio_relation}

Using the final formula from before with respect to *m* and then *n*, and then some reducing and moving, one can get to the following equation:

$$\frac{h_{m}+m}{h_{n}+n}=\left(\frac{m}{n}\right)^2$$

### Numbers of divisors of powers of certain natural numbers {#Numbers_of_divisors_of_powers_of_certain_natural_numbers}

$12^{n-1}$ for *n*>0 has $h_n$ divisors.

Likewise, for any natural number of the form $r = p^2 q$ where *p* and *q* are distinct prime numbers, $r^{n-1}$ for *n*>0 has $h_n$ divisors.

*Proof.* $r^{n-1} = (p^2 q)^{n-1} = p^{2(n-1)} q^{n-1}$ has divisors of the form $p^k q^l$, for *k* = 0 ... 2(*n* − 1), *l* = 0 ... n − 1. Each combination of *k* and *l* yields a distinct divisor, so $r^{n-1}$ has $[2(n - 1) + 1] [(n - 1) + 1]$ divisors, i.e. $(2n - 1) n = h_n$ divisors. ∎
