# Thue–Morse sequence

::: {#o1 .subject cue=lead name="Thue–Morse sequence"}

*Image: Morse-Thue sequence.gif.* This graphic demonstrates the repeating and complementary makeup of the Thue–Morse sequence.

In [mathematics](wikipedia://en/18831), the **Thue–Morse** or **Prouhet–Thue–Morse sequence** is the [binary sequence](https://en.wikipedia.org/wiki/Binary_sequence) (an infinite sequence of $0$s and $1$s) that can be obtained by starting with $0$ and successively appending the [Boolean complement](wikipedia://en/54476844) of the sequence obtained thus far. It is sometimes called the **fair share sequence** because of its applications to [fair division](wikipedia://en/669899) or **parity sequence**. The first few steps of this procedure yield the strings $0$, $01$, $0110$, $01101001$, $0110100110010110$, and so on, which are the [prefixes](https://en.wikipedia.org/wiki/Substring#Prefix) of the Thue–Morse sequence. The full sequence begins:

:::

$01101001100101101001011001101001...$[^o2]

The sequence is named after [Axel Thue](wikipedia://en/635533), [Marston Morse](wikipedia://en/856523) and (in its extended form) Eugène Prouhet.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

There are several equivalent ways of defining the Thue–Morse sequence.

### Direct definition {#Direct_definition}

*Image: Thue-Morse binary digit sum.svg.* When counting in binary, the digit sum modulo 2 is the Thue–Morse sequence

To compute the $n$th element $t_{n}$, write the number $n$ in [binary](wikipedia://en/238686). If the [number of ones](wikipedia://en/1127884) in this binary expansion is odd then $t_{n} = 1$, if even then $t_{n} = 0$.[^o6] That is, $t_{n}$ is the [even parity bit](wikipedia://en/194467) for $n$. [John Conway](wikipedia://en/15807) *et al*. deemed numbers $n$ satisfying $t_{n} = 1$ to be *odious* (intended to be similar to *odd*) numbers, and numbers for which $t_{n} = 0$ to be *evil* (similar to *even*) numbers.

### Fast sequence generation {#Fast_sequence_generation}

This method leads to a fast method for computing the Thue–Morse sequence: start with $t_{0} = 0$, and then, for each $n$, find the highest-order bit in the binary representation of $n$ that is different from the same bit in the representation of $n - 1$. If this bit is at an even index, $t_{n}$ differs from $t_{n-1}$, and otherwise it is the same as $t_{n-1}$.

In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29):

```python
from typing import Iterator

def generate_sequence(seq_length: int) -> Iterator[int]:
    """Thue–Morse sequence."""
    value: int = 1
    for n in range(seq_length):
        # Note: assumes that (-1).bit_length() gives 1
        x: int = (n ^ (n - 1)).bit_length() + 1
        if x & 1 == 0:
            # Bit index is even, so toggle value
            value = 1 - value
        yield value
```

The resulting algorithm takes constant time to generate each sequence element, using only a [logarithmic number of bits](wikipedia://en/1149999) (constant number of words) of memory.[^n1]

### Recurrence relation {#Recurrence_relation}

The Thue–Morse sequence is the sequence $t_{n}$ satisfying the [recurrence relation](wikipedia://en/146806)

$$\begin{aligned} t_0 &= 0,\\ t_{2n} &= t_n,\\ t_{2n+1} &= 1 - t_n, \end{aligned}$$

for all non-negative integers $n$.[^o6]

### L-system {#L-system}

*Image: Thue-Morse L-System.svg.* Thue–Morse sequence generated by an L-System

The Thue–Morse sequence is a [morphic word](wikipedia://en/37432570):[^o11] it is the output of the following [Lindenmayer system](wikipedia://en/46565):

::: {#o12 .table cue=table}

| Variables | $0$, $1$ |
|---|---|
| Constants | none |
| Start | $0$ |
| Rules | $(0 \to 01)$, $(1 \to 10)$ |

:::

### Characterization using bitwise negation {#Characterization_using_bitwise_negation}

The Thue–Morse sequence in the form given above, as a sequence of [bits](https://en.wikipedia.org/wiki/Bit), can be defined [recursively](wikipedia://en/25407) using the operation of [bitwise negation](https://en.wikipedia.org/wiki/Bitwise_negation). The first element is $0$. Once the first $2^{n}$ elements have been specified, forming a string $s$, then the next $2^{n}$ elements must form the bitwise negation of $s$. Now we have defined the first $2^{n+1}$ elements, and we recurse.

Spelling out the first few steps in detail:

- We start with $0$.
- The bitwise negation of $0$ is $1$.
- Combining these, the first 2 elements are $01$.
- The bitwise negation of $01$ is $10$.
- Combining these, the first 4 elements are $0110$.
- The bitwise negation of $0110$ is $1001$.
- Combining these, the first 8 elements are $01101001$.
- And so on.

So

- $$T_{0} = 0.$$
- $$T_{1} = 01.$$
- $$T_{2} = 0110.$$
- $$T_{3} = 01101001.$$
- $$T_{4} = 0110100110010110.$$
- $$T_{5} = 01101001100101101001011001101001.$$
- $$T_{6} = 0110100110010110100101100110100110010110011010010110100110010110.$$
- And so on.

In [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29):

```python
def thue_morse_bits(n: int) -> int:
	"""Return an int containing the first 2**n bits of the Thue–Morse sequence, low-order bit 1st."""
	bits = 0
    for i in range(n):
        bits |= ((1 << (1 << i)) - 1 - bits) << (1 << i)
    return bits
```

Which can then be converted to a (reversed) string as follows:

```python
n = 7
print(f"{thue_morse_bits(n):0{1<<n}b}")
```

### Generating function {#Generating_function}

A [generating function](wikipedia://en/160993) for the sequence can be defined by:

$$\prod_{i=0}^{\infty} \left(1 - x^{2^i}\right) = \sum_{j=0}^{\infty} (-1)^{t_j} x^j,$$

where $t_{j}$ is the $j$th element if we start at $j = 0$.

## Properties {#Properties}

The Thue–Morse sequence contains many *squares*: instances of the string $XX$, where $X$ denotes the string $A$, $\overline{A}$, $A\overline{A}A$, or $\overline{A}A\overline{A}$, where $A = T_{k}$ for some $k \ge 0$ and $\overline{A}$ is the bitwise negation of $A$.[^n2] For instance, if $k = 0$, then $A = T_{0} = 0$. The square $A\overline{A}AA\overline{A}A = 010010$ appears in $T$ starting at the 16th bit. Since all squares in $T$ are obtained by repeating one of these 4 strings, they all have length $2^{n}$ or $3 \cdot 2^{n}$ for some $n \ge 0$. $T$ contains no *cubes*: instances of $XXX$ for any $X$. There are also no *overlapping squares*: instances of $0X0X0$ or $1X1X1$.[^o18][^o19] The [critical exponent](wikipedia://en/37525024) of $T$ is $2$.[^n3]

The Thue–Morse sequence is a [uniformly recurrent word](https://en.wikipedia.org/wiki/Uniformly_recurrent_word): given any finite string $X$ in the sequence, there is some length $n_{X}$ (often much longer than the length of $X$) such that $X$ appears in *every* block of length $n_{X}$.[^o21][^n4] Notably, the Thue–Morse sequence is uniformly recurrent *without* being either [periodic](wikipedia://en/810250) or eventually periodic (i.e., periodic after some initial nonperiodic segment).[^o23]

The sequence $T_{2n}$ is a [palindrome](wikipedia://en/105956) for any $n$. Furthermore, let $q_{n}$ be a word obtained by counting the ones between consecutive zeros in $T_{2n}$ . For instance, $q_{1} = 2$ and $q_{2} = 2102012$. Since $T_{n}$ does not contain *overlapping squares*, the words $q_{n}$ are palindromic [squarefree words](https://en.wikipedia.org/wiki/Squarefree_word).

The **Thue–Morse [morphism](https://en.wikipedia.org/wiki/Monoid_morphism)** $\mu$ is defined on alphabet $\{0, 1\}$ by the substitution map $\mu(0) = 01$, $\mu(1) = 10$: every $0$ in a sequence is replaced with $01$ and every $1$ with $10$.[^o24] If $T$ is the Thue–Morse sequence, then $\mu(T)$ is also $T$. Thus, $T$ is a [fixed point](wikipedia://en/449738) of $\mu$. The morphism $\mu$ is a [prolongable morphism](https://en.wikipedia.org/wiki/Prolongable_morphism) on the [free monoid](wikipedia://en/523166) $\{0, 1\}^{*}$ with $T$ as fixed point: $T$ is essentially the *only* fixed point of $\mu$; the only other fixed point is the bitwise negation of $T$, which is simply the Thue–Morse sequence on $(1, 0)$ instead of on $(0, 1)$. This property may be generalized to the concept of an [automatic sequence](wikipedia://en/7740302).

In the Thue–Morse sequence, the symbols $0$ and $1$ can be replaced with the variables $a$ and $b$ to obtain a *generalized Thue–Morse sequence*. If $a$ and $b$ are distinct positive integers, then the resulting sequence can be taken to be the terms of a [simple continued fraction](wikipedia://en/46802). The resulting *Thue–Morse [continued fraction](wikipedia://en/739199)*,

$$[a;b,b,a,b,a,a,b,\ldots]=a+\dfrac{1}{b+\dfrac{1}{b+\dfrac{1}{a+\dfrac{1}{b+\dfrac{1}{a+\dfrac{1}{a+\dfrac{1}{b+\ddots}}}}}}},$$

is [transcendental](wikipedia://en/30325).[^o25]

### In combinatorial game theory {#In_combinatorial_game_theory}

The set of *evil numbers* (numbers $n$ with $t_{n} = 0$) forms a subspace of the nonnegative integers under [nim-addition](https://en.wikipedia.org/wiki/Nim-addition) ([bitwise](wikipedia://en/264399) [exclusive or](wikipedia://en/105979)). For the game of [Kayles](wikipedia://en/18869317), evil [nim-values](https://en.wikipedia.org/wiki/Nim-value) occur for few (finitely many) positions in the game, with all remaining positions having odious nim-values.

### Prouhet–Tarry–Escott problem {#Prouhet–Tarry–Escott_problem}

The [Prouhet–Tarry–Escott problem](wikipedia://en/16400356) can be defined as: given a positive integer $N$ and a non-negative integer $k$, [partition](wikipedia://en/340240) the set $S = \{0, 1, ..., N - 1\}$ into two [disjoint](wikipedia://en/39359) subsets $S_{0}$ and $S_{1}$ that have equal sums of powers up to $k$, that is:

$\sum_{x \in S_0} x^i = \sum_{x \in S_1} x^i$ for all integers $i$ from $1$ to $k$.

This has a solution if $N$ is a multiple of $2^{k+1}$, given by:

- $S_{0}$ consists of the integers $n$ in $S$ for which $t_{n} = 0$,
- $S_{1}$ consists of the integers $n$ in $S$ for which $t_{n} = 1$.

For example, for $N = 8$ and $k = 2$,

$$0 + 3 + 5 + 6 = 1 + 2 + 4 + 7,$$

$$0^{2} + 3^{2} + 5^{2} + 6^{2} = 1^{2} + 2^{2} + 4^{2} + 7^{2}.$$

The condition requiring that $N$ be a multiple of $2^{k+1}$ is not strictly necessary: there are some further cases for which a solution exists. However, it guarantees a stronger property: if the condition is satisfied, then the set of $k$th powers of any set of $N$ numbers in [arithmetic progression](wikipedia://en/168389) can be partitioned into two sets with equal sums. This follows directly from the expansion given by the [binomial theorem](wikipedia://en/4677) applied to the binomial representing the $n$th element of an arithmetic progression.

For generalizations of the Thue–Morse sequence and the Prouhet–Tarry–Escott problem to partitions into more than two parts, see Bolker, Offner, Richman and Zara, "The Prouhet–Tarry–Escott problem and generalized Thue–Morse sequences".[^n5]

### Fractals and turtle graphics {#Fractals_and_turtle_graphics}

Using [turtle graphics](https://en.wikipedia.org/wiki/Turtle_graphics), a curve can be generated if an automaton is programmed with a sequence. Using the Thue–Morse sequence, the rules

- If $t(n) = 0$, move ahead by one unit,
- If $t(n) = 1$, rotate by an angle of $\pi/3$ [radians](wikipedia://en/26003) (60°)

generate a curve that converges to the [Koch curve](wikipedia://en/46959), a [fractal curve](wikipedia://en/4972605) of infinite length containing a finite area. This illustrates the fractal nature of the Thue–Morse Sequence.[^n6]

It is also possible to draw the curve precisely using the following instructions:[^o31]

- If $t(n) = 0$, rotate by an angle of $\pi$ radians (180°),
- If $t(n) = 1$, move ahead by one unit, then rotate by an angle of $\pi/3$ radians.

### Equitable sequencing {#Equitable_sequencing}

In their book on the problem of [fair division](wikipedia://en/669899), [Steven Brams](https://en.wikipedia.org/wiki/Steven_Brams) and [Alan Taylor](https://en.wikipedia.org/wiki/Alan_D._Taylor) invoked the Thue–Morse sequence but did not identify it as such. When allocating a contested pile of items between two parties who agree on the items' relative values, Brams and Taylor suggested a method they called *balanced alternation*, or *taking turns taking turns taking turns ...*, as a way to circumvent the favoritism inherent when one party chooses before the other. An example showed how a divorcing couple might reach a fair settlement in the distribution of jointly owned items. The parties would take turns to be the first chooser at different points in the selection process: Ann chooses one item, then Ben does, then Ben chooses one item, then Ann does.[^n7]

[Lionel Levine](https://en.wikipedia.org/wiki/Lionel_Levine) and [Katherine E. Stange](wikipedia://en/66319247), in their discussion of how to fairly apportion a shared meal such as an [Ethiopian dinner](https://en.wikipedia.org/wiki/Ethiopian_cuisine), proposed the Thue–Morse sequence as a way to reduce the advantage of moving first. They suggested that "it would be interesting to quantify the intuition that the Thue–Morse order tends to produce a fair outcome".[^n8]

Robert Richman addressed this problem, but he too did not identify the Thue–Morse sequence as such at the time of publication.[^o36] He presented the sequences $T_{n}$ as [step functions](wikipedia://en/170939) on the interval $[0, 1]$ and described their relationship to the [Walsh](wikipedia://en/380839) and [Rademacher](wikipedia://en/1864916) functions. He showed that the $n$th [derivative](wikipedia://en/7921) can be expressed in terms of $T_{n}$. As a consequence, the step function arising from $T_{n}$ is [orthogonal](wikipedia://en/102221) to [polynomials](wikipedia://en/23000) of [order](wikipedia://en/5930652) $n - 1$. A consequence of this result is that a resource whose value is expressed as a [monotonically](wikipedia://en/48260) decreasing [continuous function](wikipedia://en/6122) is most fairly allocated using a sequence that converges to Thue–Morse as the function becomes [flatter](wikipedia://en/27005472). An example showed how to pour cups of [coffee](https://en.wikipedia.org/wiki/Drip_brew) of equal strength from a carafe with a [nonlinear](wikipedia://en/146103) [concentration](https://en.wikipedia.org/wiki/Concentration) [gradient](wikipedia://en/12461), prompting a whimsical article in the popular press.[^n9]

Joshua Cooper and Aaron Dutle showed why the Thue–Morse order provides a fair outcome for discrete events.[^o38] They considered the fairest way to stage a [Galois](wikipedia://en/9815) duel, in which each of the shooters has equally poor shooting skills. Cooper and Dutle postulated that each dueler would demand a chance to fire as soon as the other's [*a priori* probability](https://en.wikipedia.org/wiki/A_priori_probability) of winning exceeded their own. They proved that, as the duelers' hitting probability approaches zero, the firing sequence converges to the Thue–Morse sequence. In so doing, they demonstrated that the Thue–Morse order produces a fair outcome not only for sequences $T_{n}$ of length $2^{n}$, but for sequences of any length.

Thus the mathematics supports using the Thue–Morse sequence instead of alternating turns when the goal is fairness but earlier turns differ monotonically from later turns in some meaningful quality, whether that quality varies continuously[^o36] or discretely.[^o38]

Sports competitions form an important class of equitable sequencing problems, because strict alternation often gives an unfair advantage to one team. [Ignacio Palacios-Huerta](https://en.wikipedia.org/wiki/Ignacio_Palacios-Huerta) proposed changing the sequential order to Thue–Morse to improve the *[ex post](https://en.wikipedia.org/wiki/Ex_post)* fairness of various tournament competitions, such as the kicking sequence of a [penalty shoot-out](https://en.wikipedia.org/wiki/Penalty_shoot-out_%28association_football%29#Procedure) in soccer.[^n10] He did a set of field experiments with pro players and found that the team kicking first won 60% of games using ABAB (or $T_{1}$), 54% using ABBA (or $T_{2}$), and 51% using full Thue–Morse (or $T_{n}$). As a result, ABBA is undergoing [extensive trials](https://en.wikipedia.org/wiki/Penalty_shoot-out_%28association_football%29#Advantage_to_team_kicking_first?) in [FIFA (European and World Championships)](https://en.wikipedia.org/wiki/FIFA#FIFA_competitions) and English Federation professional soccer ([EFL Cup](https://en.wikipedia.org/wiki/EFL_Cup)).[^n11] An ABBA serving pattern has also been found to improve the fairness of [tennis tie-breaks](https://en.wikipedia.org/wiki/Tennis_scoring_system#Scoring_a_tiebreak_game).[^n12] In [competitive rowing](https://en.wikipedia.org/wiki/Rowing_%28sport%29), $T_{2}$ is the only arrangement of [port- and starboard-rowing](https://en.wikipedia.org/wiki/Port_and_starboard) crew members that eliminates transverse forces (and hence sideways wiggle) on a four-membered coxless racing boat, while $T_{3}$ is one of only four [rigs](https://en.wikipedia.org/wiki/Boat_rigging) to avoid wiggle on an eight-membered boat.[^n13]

Fairness is especially important in [player drafts](https://en.wikipedia.org/wiki/Draft_%28sports%29). Many professional sports leagues attempt to achieve [competitive parity](https://en.wikipedia.org/wiki/Parity_%28sports%29) by giving earlier selections in each round to weaker teams. By contrast, [fantasy football leagues](https://en.wikipedia.org/wiki/Fantasy_football_%28American%29) have no pre-existing imbalance to correct, so they often use a "snake" draft (forward, backward, etc.; or $T_{1}$).[^o43] Ian Allan argued that a "third-round reversal" (forward, backward, backward, forward, etc.; or $T_{2}$) would be even more fair.[^o44] Richman suggested that the fairest way for "captain A" and "captain B" to choose sides for a [pick-up game of basketball](https://en.wikipedia.org/wiki/Streetball) mirrors $T_{3}$: captain A has the first, fourth, sixth, and seventh choices, while captain B has the second, third, fifth, and eighth choices.[^o36]

### Hash collisions {#Hash_collisions}

The initial $2^{k}$ bits of the Thue–Morse sequence are mapped to $0$ by a wide class of polynomial [hash functions](https://en.wikipedia.org/wiki/Hash_function) modulo a [power of two](wikipedia://en/376948), which can lead to [hash collisions](https://en.wikipedia.org/wiki/Hash_collision).[^o46]

### Riemann zeta function {#Riemann_zeta_function}

Certain linear combinations of Dirichlet series whose coefficients are terms of the Thue–Morse sequence give rise to identities involving the Riemann Zeta function (Tóth, 2022[^o48]). For instance:

$$\begin{aligned} \sum_{n\geq1} \frac{5 t_{n-1} + 3 t_n}{n^2} &= 4 \zeta(2) = \frac{2 \pi^2}{3}, \\ \sum_{n\geq1} \frac{9 t_{n-1} + 7 t_n}{n^3} &= 8 \zeta(3),\end{aligned}$$

where $(t_{n})_{n\ge0}$ is the $n$th term of the Thue–Morse sequence. In fact, for all $s$ with real part greater than $1$, we have

$$(2^s+1) \sum_{n\geq1} \frac{t_{n-1}}{n^s} + (2^s-1) \sum_{n\geq1} \frac{t_{n}}{n^s} = 2^s \zeta(s).$$

:::

## History {#History}

The Thue–Morse sequence was first studied by Eugène Prouhet in 1851,[^o50] who applied it to [number theory](wikipedia://en/21527). However, Prouhet did not mention the sequence explicitly; this was left to [Axel Thue](wikipedia://en/635533) in 1906, who used it to found the study of [combinatorics on words](wikipedia://en/20913490). The sequence was only brought to worldwide attention with the work of [Marston Morse](wikipedia://en/856523) in 1921, when he applied it to [differential geometry](wikipedia://en/8625). The sequence has been [discovered independently](https://en.wikipedia.org/wiki/Multiple_discovery) many times, not always by professional research mathematicians; for example, [Max Euwe](https://en.wikipedia.org/wiki/Max_Euwe), a [chess grandmaster](https://en.wikipedia.org/wiki/Grandmaster_%28chess%29) and mathematics [teacher](https://en.wikipedia.org/wiki/Teacher), discovered it in 1929 in an application to [chess](https://en.wikipedia.org/wiki/Chess): by using its cube-free property (see above), he showed how to circumvent the [threefold repetition](https://en.wikipedia.org/wiki/Threefold_repetition) rule aimed at preventing infinitely protracted games by declaring repetition of moves a draw. At the time, consecutive identical board states were required to trigger the rule; the rule was later amended to the same board position reoccurring three times at any point, as the sequence shows that the consecutive criterion can be evaded forever.
