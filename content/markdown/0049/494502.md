# SSE3

::: {#o1 .subject cue=lead name="SSE3"}

**SSE3**, **Streaming SIMD Extensions 3**, also known by its [Intel](https://en.wikipedia.org/wiki/Intel) code name **Prescott New Instructions** (**PNI**),[^o2] is the third iteration of the [SSE](wikipedia://en/55365) instruction set for the [IA-32](https://en.wikipedia.org/wiki/IA-32) (x86) architecture. Intel introduced SSE3 in 2004 with the [Prescott](https://en.wikipedia.org/wiki/Pentium_4#Prescott) revision of their [Pentium 4](https://en.wikipedia.org/wiki/Pentium_4) and [Celeron D](https://en.wikipedia.org/wiki/Celeron#Prescott-256) CPUs.[^o2] In April 2005, [AMD](https://en.wikipedia.org/wiki/AMD) introduced a subset of SSE3 in revision E (Venice and San Diego) of their [Athlon 64](https://en.wikipedia.org/wiki/Athlon_64) CPUs.[^o3] The earlier [SIMD](https://en.wikipedia.org/wiki/SIMD) instruction sets on the [x86](https://en.wikipedia.org/wiki/X86) platform, from oldest to newest, are [MMX](wikipedia://en/55364), [3DNow!](wikipedia://en/211551) (developed by AMD, no longer supported on newer CPUs), [SSE](wikipedia://en/55365), and [SSE2](wikipedia://en/311203).

:::

SSE3 contains 13 new instructions over [SSE2](wikipedia://en/311203).[^o4]

## Changes {#Changes}

The most notable change is the capability to work horizontally in a register, as opposed to the more or less strictly vertical operation of all previous SSE instructions. More specifically, instructions to add and subtract the multiple values stored within a single register have been added.[^o6] These instructions can be used to speed up the implementation of a number of [DSP](https://en.wikipedia.org/wiki/Digital_signal_processing) and [3D](https://en.wikipedia.org/wiki/3D_computer_graphics) operations. There is also a new instruction to convert floating point values to integers without having to change the global rounding mode, thus avoiding costly [pipeline](https://en.wikipedia.org/wiki/Instruction_pipeline) stalls. Finally, the extension adds `LDDQU`, an alternative misaligned integer vector load that has better performance on [NetBurst](https://en.wikipedia.org/wiki/NetBurst) based platforms for loads that cross cacheline boundaries.[^o7]

## New instructions {#New_instructions}

### Common instructions {#Common_instructions}

#### Arithmetic {#Arithmetic}

**`ADDSUBPD`**

*Add-Subtract-Packed-Double*[^o14]

- Input: { A0, A1 }, { B0, B1 }
- Output: { A0 − B0, A1 + B1 }

**`ADDSUBPS`**

*Add-Subtract-Packed-Single*[^o14]

- Input: { A0, A1, A2, A3 }, { B0, B1, B2, B3 }
- Output: { A0 − B0, A1 + B1, A2 − B2, A3 + B3 }

#### AOS ( Array Of Structures ) {#AOS_(_Array_Of_Structures_)}

**`HADDPD`**

*Horizontal-Add-Packed-Double*[^o14]

- Input: { A0, A1 }, { B0, B1 }
- Output: { A0 + A1, B0 + B1 }

**`HADDPS`**

*Horizontal-Add-Packed-Single*[^o14]

- Input: { A0, A1, A2, A3 }, { B0, B1, B2, B3 }
- Output: { A0 + A1, A2 + A3, B0 + B1, B2 + B3 }

**`HSUBPD`**

*Horizontal-Subtract-Packed-Double*[^o14]

- Input: { A0, A1 }, { B0, B1 }
- Output: { A0 − A1, B0 − B1 }

**`HSUBPS`**

*Horizontal-Subtract-Packed-Single*[^o14]

- Input: { A0, A1, A2, A3 }, { B0, B1, B2, B3 }
- Output: { A0 − A1, A2 − A3, B0 − B1, B2 − B3 }

**`LDDQU`**

As stated above, this is an alternative misaligned integer vector load.[^o14] It can be helpful for video compression tasks.

**`[[MOVDDUP]]`, `MOVSHDUP`, `MOVSLDUP`[^o6]**

These are useful for complex numbers and wave calculation like sound.

**`FISTTP`**

Like the older x87 `FISTP` instruction, but ignores the floating point control register's rounding mode settings and uses the "chop" (truncate) mode instead.[^o6] Allows omission of the expensive loading and re-loading of the control register in languages such as C where float-to-int conversion requires truncate behaviour by standard.

### Other instructions {#Other_instructions}

**`MONITOR`, `MWAIT`**

The `MONITOR` instruction is used to specify a memory address for monitoring, while the `MWAIT` instruction puts the processor into a low-power state and waits for a write event to the monitored address.[^o6]
