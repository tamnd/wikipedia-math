# Finger binary

::: {#o1 .subject cue=lead name="Finger binary"}

*Image: I love you in Sign Language or the number 19 in Finger Binary.jpg.* 19 in finger binary: the pinkie finger is 16, added to the 2 of the index finger and the 1 of the thumb

**Finger binary** is a system for [counting](https://en.wikipedia.org/wiki/Finger_counting) and displaying [binary numbers](https://en.wikipedia.org/wiki/Binary_numeral_system) on the [fingers](https://en.wikipedia.org/wiki/Finger) of either or both [hands](https://en.wikipedia.org/wiki/Hand). Each finger represents one binary digit or [bit](https://en.wikipedia.org/wiki/Bit). This allows counting from zero to 31 using the fingers of one hand, or 1023 using both: that is, up to 2<sup>5</sup>−1 or 2<sup>10</sup>−1 respectively.

:::

Modern computers typically store values as some whole number of 8-[bit](https://en.wikipedia.org/wiki/Bit) [bytes](https://en.wikipedia.org/wiki/Byte), making the fingers of both hands together equivalent to 1$\tfrac{1}{4}$ bytes of storage—‌in contrast to less than half a byte when using ten fingers to count up to 10.[^o2]

## Mechanics {#Mechanics}

In the binary number system, each [numerical digit](wikipedia://en/280582) has two possible states (0 or 1) and each successive digit represents an increasing [power of two](wikipedia://en/376948).

What follows is but one of several possible schemes for assigning the values 1, 2, 4, 8, 16, *etc.*, to fingers, and is not necessarily being conveyed as the best one (see below). The rightmost digit represents two to the [zeroth power](https://en.wikipedia.org/wiki/Zeroth_power) (*i.e.*, it is the *ones* digit), the digit to its left represents two to the first power (the *twos* digit), the next digit to the left represents two to the second power (the *fours* digit), and so on (the [decimal number system](wikipedia://en/8214) works the same way only using consecutive sequential powers of ten rather than two).

It is possible to use [anatomical digits](https://en.wikipedia.org/wiki/Digit_%28anatomy%29) to represent [numerical digits](wikipedia://en/280582) by using a raised finger to represent a binary digit in the "1" state and a lowered finger to represent it in the "0" state. Each successive finger represents a higher power of two.

With palms oriented toward the counter's face, the values for when only the right hand is used are:

| Value | 512 | 256 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

The values of each raised finger are added together to arrive at a total number. In the one-handed version, all fingers raised is thus **31** (16 + 8 + 4 + 2 + 1), and all fingers lowered (a fist) is 0. In the two-handed system, all fingers raised is **1,023** (512 + 256 + 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1) and two fists (no fingers raised) represents 0.

It is also possible to have each hand represent an independent number between 0 and 31; this can be used to represent various types of paired numbers, such as [month](https://en.wikipedia.org/wiki/Month) and [day](https://en.wikipedia.org/wiki/Day), X-Y [coordinates](https://en.wikipedia.org/wiki/Coordinate), or sports scores (such as for [table tennis](https://en.wikipedia.org/wiki/Table_tennis) or [baseball](https://en.wikipedia.org/wiki/Baseball)). Showing the time as hours and minutes is possible using 10 fingers, with the hour using 4 fingers (1-12) and the minutes using 6 fingers (0-59).

## Negative numbers and non-integers {#Negative_numbers_and_non-integers}

Just as fractional and negative numbers can be represented in binary, they can be represented in finger binary.

### Negative numbers {#Negative_numbers}

Representing negative numbers is extremely simple, by using the leftmost finger as a [sign bit](https://en.wikipedia.org/wiki/Sign_bit): raised means the number is negative, in a [sign-magnitude](https://en.wikipedia.org/wiki/Sign-magnitude) system. Anywhere between -511 and +511 can be represented this way, using two hands. Note that, in this system, both a positive and a negative zero may be represented.

If a convention were reached on palm up/palm down or fingers pointing up/down representing positive/negative, you could maintain 2<sup>10</sup> −1 in both positive and negative numbers (-1023 to +1023, with positive and negative zero still represented).

### Fractions {#Fractions}

#### Dyadic fractions {#Dyadic_fractions}

Fractions can be stored natively in a binary format by having each finger represent a fractional power of two: $\tfrac{1}{2^x}$. (These are known as [dyadic fractions](https://en.wikipedia.org/wiki/Dyadic_fraction).)

Using the left hand only:

::: {#o16 .table cue=table}

|  | Pinky | Ring | Middle | Index | Thumb |
|---|---|---|---|---|---|
| Value | 1/2 | 1/4 | 1/8 | 1/16 | 1/32 |

:::

Using two hands:

::: {#o17 .table cue=table}

| Left hand |  |  |  |  | Right hand |  |  |  |  |
|---|---|---|---|---|---|---|---|---|---|
| Pinky | Ring | Middle | Index | Thumb | Thumb | Index | Middle | Ring | Pinky |
| 1/2 | 1/4 | 1/8 | 1/16 | 1/32 | 1/64 | 1/128 | 1/256 | 1/512 | 1/1024 |

:::

*Image: Chinesische.Zahl.Acht.jpg.* 3/4, in fractional finger binary

The total is calculated by adding all the values in the same way as regular (non-fractional) finger binary, then dividing by the largest fractional power being used (32 for one-handed fractional binary, 1024 for two-handed), and [simplifying the fraction](https://en.wikipedia.org/wiki/Equivalent_fractions) as necessary.

For example, with thumb and index finger raised on the left hand and no fingers raised on the right hand, this is (512 + 256)/1024 = 768/1024 = 3/4. If using only one hand (left or right), it would be (16 + 8)/32 = 24/32 = 3/4 also.

The simplification process can itself be greatly simplified by performing a [bit shift](https://en.wikipedia.org/wiki/Bit_shift) operation: all digits to the right of the rightmost raised finger (i.e., all trailing zeros) are discarded and the rightmost raised finger is treated as the ones digit. The digits are added together using their now-shifted values to determine the [numerator](https://en.wikipedia.org/wiki/Numerator) and the rightmost finger's original value is used to determine the [denominator](https://en.wikipedia.org/wiki/Denominator).

For instance, if the thumb and index finger on the left hand are the only raised digits, the rightmost raised finger (the index finger) becomes "1". The thumb, to its immediate left, is now the 2s digit; added together, they equal 3. The index finger's original value (1/4) determines the denominator: the result is 3/4.

#### Rational numbers {#Rational_numbers}

Combined [integer](wikipedia://en/14563) and fractional values (i.e., [rational numbers](wikipedia://en/19727024)) can be represented by setting a [radix point](https://en.wikipedia.org/wiki/Radix_point) somewhere between two fingers (for instance, between the left and right pinkies). All digits to the left of the radix point are integers; those to the right are fractional.

### Decimal fractions and vulgar fractions {#Decimal_fractions_and_vulgar_fractions}

[Dyadic fractions](https://en.wikipedia.org/wiki/Dyadic_fraction), explained above, have limited use in a society based around decimal figures. A simple non-dyadic fraction such as 1/3 can be approximated as 341/1024 (0.3330078125), but the conversion between dyadic and [decimal](https://en.wikipedia.org/wiki/Decimal_fraction) (0.333) or [vulgar](https://en.wikipedia.org/wiki/Vulgar_fraction) (1/3) forms is complicated.

Instead, either decimal or vulgar fractions can be represented natively in finger binary. Decimal fractions can be represented by using regular integer binary methods and dividing the result by 10, 100, 1000, or some other power of ten. Numbers between 0 and 102.3, 10.23, 1.023, etc. can be represented this way, in increments of 0.1, 0.01, 0.001, etc.

[Vulgar fractions](https://en.wikipedia.org/wiki/Vulgar_fraction) can be represented by using one hand to represent the [numerator](https://en.wikipedia.org/wiki/Numerator) and one hand to represent the [denominator](https://en.wikipedia.org/wiki/Denominator); a spectrum of rational numbers can be represented this way, ranging from 1/31 to 31/1 (as well as 0).

## Finger ternary {#Finger_ternary}

In theory, it is possible to use other positions of the fingers to represent more than two states (0 and 1); for instance, a [ternary numeral system](wikipedia://en/62950) ([base](https://en.wikipedia.org/wiki/Number_base) 3) could be used by having a fully raised finger represent 2, fully lowered represent 0, and "curled" (half-lowered) represent 1. This would make it possible to count up to 242 (3<sup>5</sup>−1) on one hand or 59,048 (3<sup>10</sup>−1) on two hands. In practice, however, many people will find it difficult to hold all fingers independently (especially the middle and ring fingers) in more than two distinct positions.

:::
