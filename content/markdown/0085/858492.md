# OpenVPN

::: {#o11 .subject cue=lead name="OpenVPN"}

**OpenVPN** is a [virtual private network](wikipedia://en/147130) (VPN) system that implements techniques to create secure point-to-point or site-to-site connections in routed or bridged configurations and remote access facilities. It implements both [client and server](https://en.wikipedia.org/wiki/Client-server_architecture) applications.

:::

OpenVPN allows [peers](https://en.wikipedia.org/wiki/Peer-to-peer) to [authenticate](wikipedia://en/47967) each other using [pre-shared secret keys](wikipedia://en/4934057), [certificates](wikipedia://en/223796) or [username](https://en.wikipedia.org/wiki/User_%28computing%29)/[password](wikipedia://en/24304). When used in a multiclient-server configuration, it allows the server to release an authentication certificate for every client, using [signatures](wikipedia://en/59644) and [certificate authority](wikipedia://en/296370).

It uses the [OpenSSL](wikipedia://en/438819) encryption [library](https://en.wikipedia.org/wiki/Library_%28computing%29) extensively, as well as the [TLS](wikipedia://en/187813) protocol, and contains many security and control features. As it uses a custom security protocol[^o12] that utilizes [SSL/TLS](wikipedia://en/187813) for key exchange. It is capable of traversing [network address translators](https://en.wikipedia.org/wiki/Network_address_translator) (NATs) and [firewalls](https://en.wikipedia.org/wiki/Firewall_%28computing%29).[^o13]

OpenVPN has been ported and embedded on several systems. For example, [DD-WRT](https://en.wikipedia.org/wiki/DD-WRT) has the OpenVPN server function. [SoftEther VPN](https://en.wikipedia.org/wiki/SoftEther_VPN), a multi-protocol VPN server, also has an implementation of the OpenVPN protocol.[^o14]

It was written by James Yonan and is [free software](https://en.wikipedia.org/wiki/Free_software), released under the terms of the [GNU General Public License version 2](https://en.wikipedia.org/wiki/GNU_General_Public_License_version_2) (GPLv2).[^o15] Additionally, commercial licenses are available.[^o16]

## Architecture {#Architecture}

### Encryption {#Encryption}

OpenVPN uses the [OpenSSL](wikipedia://en/438819) library to provide [encryption](wikipedia://en/10294) of both the data and control channels. It lets OpenSSL do all the encryption and authentication work, allowing OpenVPN to use all the ciphers available in the OpenSSL package. It can also use the [HMAC](wikipedia://en/17112) packet authentication feature to add an additional layer of security to the connection (referred to as an "HMAC Firewall" by the creator). It can also use hardware acceleration to get better encryption performance.[^o19][^o20] Support for [mbed TLS](https://en.wikipedia.org/wiki/Mbed_TLS) is available starting from version 2.3.[^o21]

### Authentication {#Authentication}

OpenVPN has several ways to [authenticate](wikipedia://en/47967) peers with each other. OpenVPN offers [pre-shared keys](wikipedia://en/4934057), certificate-based, and username/password-based authentication. Preshared secret key is the easiest, and certificate-based is the most robust and [feature-rich](https://en.wikipedia.org/wiki/Feature-rich). In version 2.0, username/password authentications can be enabled, both with or without certificates. However, to make use of username/password authentications, OpenVPN depends on third-party modules.

### Networking {#Networking}

OpenVPN can run over [User Datagram Protocol](https://en.wikipedia.org/wiki/User_Datagram_Protocol) (UDP) or [Transmission Control Protocol](https://en.wikipedia.org/wiki/Transmission_Control_Protocol) (TCP) transports, multiplexing created SSL tunnels on a single TCP/UDP port[^o24] (RFC 3948 for UDP).[^o25]

From 2.3.x series on, OpenVPN fully supports IPv6 as a protocol of the virtual network inside a tunnel and the OpenVPN applications can also establish connections via IPv6.[^o26] It has the ability to work through most [proxy servers](https://en.wikipedia.org/wiki/Proxy_servers) (including [HTTP](https://en.wikipedia.org/wiki/HTTP)) and is good at working through [network address translation](https://en.wikipedia.org/wiki/Network_address_translation) (NAT) and getting out through firewalls. The server configuration can "push" certain network configuration options to the clients. These include IP addresses, routing commands, and a few connection options. OpenVPN offers two types of interfaces for networking via the [Universal TUN/TAP driver](https://en.wikipedia.org/wiki/TUN/TAP). It can create either a [layer-3](https://en.wikipedia.org/wiki/OSI_model#Layer_3:_Network_layer) based IP tunnel (TUN), or a [layer-2](https://en.wikipedia.org/wiki/OSI_model#Layer_2:_Data_link_layer) based Ethernet TAP that can carry any type of Ethernet traffic. OpenVPN can optionally use the [LZO](https://en.wikipedia.org/wiki/Lempel–Ziv–Oberhumer) compression library to compress the data stream. Port 1194 is the official [IANA](https://en.wikipedia.org/wiki/Internet_Assigned_Numbers_Authority) assigned port number for OpenVPN. Newer versions of the program now default to that port. A feature in the 2.0 version allows for one process to manage several simultaneous tunnels, as opposed to the original "one tunnel per process" restriction on the 1.x series.

OpenVPN's use of common network protocols (TCP and UDP) makes it a desirable alternative to [IPsec](https://en.wikipedia.org/wiki/IPsec) in situations where an [ISP](https://en.wikipedia.org/wiki/Internet_service_provider) may block specific [VPN](wikipedia://en/147130) protocols in order to force users to subscribe to a higher-priced, "business grade" service tier. For example, [Comcast](https://en.wikipedia.org/wiki/Comcast) previously declared that their @Home product was, and had always been, designated as a residential service and did not allow the use of commercial applications. Their argument was that conducting [remote work](https://en.wikipedia.org/wiki/Remote_work) via a VPN can adversely affect the network performance of their regular residential subscribers. They offered an alternative, @Home Professional, which would cost more than the @Home product. So, anyone wishing to use a VPN would have to subscribe to a higher-priced, business-grade service tier.[^o27]

When OpenVPN uses [Transmission Control Protocol](https://en.wikipedia.org/wiki/Transmission_Control_Protocol) (TCP) transports to establish a tunnel, performance will be acceptable only as long as there is sufficient excess bandwidth on the un-tunneled network link to guarantee that the tunneled TCP timers do not expire.[^o28] If this becomes untrue, performance falls off dramatically due to the [TCP meltdown problem](https://en.wikipedia.org/wiki/TCP_meltdown_problem).[^o29][^o30]

### Security {#Security}

OpenVPN offers various internal security features. It has up to [256-bit](https://en.wikipedia.org/wiki/256-bit) encryption through the [OpenSSL](wikipedia://en/438819) library, although some service providers may offer lower rates, effectively providing some of the fastest VPN available to consumers. OpenVPN also supports [Perfect Forward Secrecy (PFS)](wikipedia://en/2191130), which regenerates encryption keys at set intervals, ensuring that even if one key is compromised, previous and future data remains secure. Additionally, OpenVPN can be configured with various encryption ciphers, such as ChaCha20 and AES-256.[^o32] It runs in [userspace](https://en.wikipedia.org/wiki/Userspace) instead of requiring IP stack (therefore kernel) operation. OpenVPN has the ability to [drop root privileges](https://en.wikipedia.org/wiki/Privilege_separation), use mlockall to prevent swapping sensitive data to disk, enter a [chroot jail](https://en.wikipedia.org/wiki/Chroot) after initialization, and apply a [SELinux](https://en.wikipedia.org/wiki/Selinux) context after initialization.

OpenVPN runs a custom security protocol based on SSL and TLS,[^o12] rather than supporting IKE, IPsec, L2TP or [PPTP](https://en.wikipedia.org/wiki/Point-to-Point_Tunneling_Protocol).

OpenVPN supports the use of [smart cards](https://en.wikipedia.org/wiki/Smart_card) via [PKCS#11](https://en.wikipedia.org/wiki/PKCS11)-based cryptographic tokens.

### Extensibility {#Extensibility}

OpenVPN can be extended with third-party [plug-ins](https://en.wikipedia.org/wiki/Plug-in_%28computing%29) or scripts, which can be called at defined entry points.[^o34][^o35] The purpose of this is often to extend OpenVPN with more advanced logging, enhanced authentication with username and passwords, dynamic firewall updates, [RADIUS](https://en.wikipedia.org/wiki/RADIUS) integration and so on. The plug-ins are dynamically loadable modules, usually written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), while the scripts interface can execute any scripts or binaries available to OpenVPN. In the OpenVPN source code[^o36] there are some examples of such plug-ins, including a [PAM](https://en.wikipedia.org/wiki/Pluggable_authentication_module) authentication plug-in. Several third-party plug-ins also exist to authenticate against [LDAP](https://en.wikipedia.org/wiki/Lightweight_Directory_Access_Protocol) or SQL databases such as [SQLite](https://en.wikipedia.org/wiki/SQLite) and [MySQL](https://en.wikipedia.org/wiki/MySQL).[^o37]

## Platforms {#Platforms}

It is available on [Solaris](https://en.wikipedia.org/wiki/Solaris_%28operating_system%29), [Linux](https://en.wikipedia.org/wiki/Linux), [OpenBSD](https://en.wikipedia.org/wiki/OpenBSD), [FreeBSD](https://en.wikipedia.org/wiki/FreeBSD), [NetBSD](https://en.wikipedia.org/wiki/NetBSD), [QNX](https://en.wikipedia.org/wiki/QNX), [macOS](https://en.wikipedia.org/wiki/MacOS) and [Windows XP and later](https://en.wikipedia.org/wiki/Comparison_of_Microsoft_Windows_versions).[^o42] OpenVPN is available for [mobile operating systems](https://en.wikipedia.org/wiki/Mobile_operating_system) including [Maemo](https://en.wikipedia.org/wiki/Maemo),[^o43] [Windows Mobile](https://en.wikipedia.org/wiki/Windows_Mobile) 6.5 and below,[^o44] [iOS](https://en.wikipedia.org/wiki/IOS) 3GS+ devices,[^o45] [jailbroken](https://en.wikipedia.org/wiki/IOS_jailbreaking) iOS 3.1.2+ devices,[^o46] [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29) 4.0+ devices, and Android devices that have had the [Cyanogenmod](https://en.wikipedia.org/wiki/Cyanogenmod) aftermarket firmware flashed[^o47] or have the correct kernel module installed.[^o48] It is not compatible with some mobile phone OSes, including [Palm OS](https://en.wikipedia.org/wiki/Palm_OS). It is not a "web-based" VPN shown as a web page such as [Citrix](https://en.wikipedia.org/wiki/Citrix) or [Terminal Services Web access](https://en.wikipedia.org/wiki/Remote_Desktop_Services); the program is installed independently and configured by editing text files manually, rather than through a GUI-based wizard. OpenVPN is not compatible with VPN clients that use the [IPsec](https://en.wikipedia.org/wiki/IPsec) over [L2TP](https://en.wikipedia.org/wiki/L2TP) or [PPTP](https://en.wikipedia.org/wiki/PPTP) protocols. The entire package consists of one [binary](https://en.wikipedia.org/wiki/Binary_file) for both [client](https://en.wikipedia.org/wiki/Client_%28computing%29) and [server](https://en.wikipedia.org/wiki/Server_%28computing%29) connections, an optional [configuration file](https://en.wikipedia.org/wiki/Configuration_file), and one or more key files depending on the authentication method used.

### Firmware implementations {#Firmware_implementations}

OpenVPN has been integrated into several [router](https://en.wikipedia.org/wiki/Router_%28computing%29) firmware packages allowing users to run OpenVPN in client or server mode from their network routers. A router running OpenVPN in client mode, for example, allows any device on a network to access a VPN without needing the capability to install OpenVPN.

### Software implementations {#Software_implementations}

OpenVPN has been integrated into [SoftEther VPN](https://en.wikipedia.org/wiki/SoftEther_VPN), an open-source multi-protocol VPN server, to allow users to connect to the VPN server from existing OpenVPN clients.

OpenVPN is also integrated into [Vyos](https://en.wikipedia.org/wiki/VyOS), an open-source routing [operating system](https://en.wikipedia.org/wiki/Operating_system) forked from the [Vyatta](https://en.wikipedia.org/wiki/Vyatta) software router.

## Licensing {#Licensing}

OpenVPN is available in two versions:

- OpenVPN Community Edition, which is a free and open-source version
- OpenVPN Access Server (OpenVPN-AS) is based on the Community Edition, but provides additional paid and proprietary features like LDAP integration, SMB server, Web UI management and provides a set of installation and configuration tools that are reported to simplify the rapid deployment of a VPN remote-access solution.[^o67][^o68] The Access Server edition relies heavily on [iptables](https://en.wikipedia.org/wiki/Iptables) for [load balancing](https://en.wikipedia.org/wiki/Load_balancing_%28computing%29) and it has never been available on Windows for this reason. This version is also able to dynamically create client ("OpenVPN Connect") installers, which include a client profile for connecting to a particular Access Server instance.[^o69] However, the user does not need to have an Access Server client in order to connect to the Access Server instance; the client from the OpenVPN Community Edition can be used.[^o70]

## Detectability {#Detectability}

OpenVPN connections can be easily detected using deep packet inspection,[^o72][^o73][^o74] based on known header data of the transmitted packets, regardless of the protocol or port used. While deep packet inspection does not allow determining the contents of the encrypted tunnel, it can be used to block the connection, identify communication participants, and log related data. This is particularly important when the use of VPN connections is prohibited in certain environments, for example, in countries where encrypted connections are banned, or under civil legislation when circumventing network blocks in corporate networks.[^o75][^o76][^o77][^o78][^o79]
