# Bonse's inequality

::: {#o1 .subject cue=lead name="Bonse's inequality"}

In [number theory](wikipedia://en/21527), **Bonse's inequality**, named after H. Bonse,[^o2] relates the size of a [primorial](wikipedia://en/422786) to the smallest prime that does not appear in its [prime factorization](https://en.wikipedia.org/wiki/Prime_factorization). It states that for all $n\geq 4$, if $p_1,\dots,p_n,p_{n+1}$ are the first $n+1$ [prime numbers](wikipedia://en/23666), then

:::

$$p_n\# = \prod_{i=1}^n p_i > p_{n+1}^2.$$

Barkley Rosser showed an upper bound where $n\#\leq 2.83^n$.[^o3]
