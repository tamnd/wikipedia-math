# Hypertopology

::: {#o1 .subject cue=lead name="Hypertopology"}

In the [mathematical branch](wikipedia://en/18831) of [topology](wikipedia://en/29954), a **hyperspace** (or a space equipped with a hypertopology) is a [topological space](wikipedia://en/30450), which consists of the set *CL(X)* of all non-empty [closed](wikipedia://en/47279) subsets of another topological space *X*, equipped with a topology so that the [canonical map](wikipedia://en/23335649)

:::

$$i : x \mapsto \overline{\{x\}},$$

is a [homeomorphism](wikipedia://en/13660) onto its image. As a consequence, a copy of the original space *X* lives inside its hyperspace *CL(X)*.[^o2] [^o3]

Early examples of hypertopology include the [Hausdorff metric](wikipedia://en/429296)[^o4] and Vietoris topology.[^o5]

::: {#o7 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

Various notation is used by different authors to denote the set of all closed subsets of a topological space *X*, including *CL(X)*, $\mathcal{F}(X)$ and $2^X$.

:::

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

### Vietoris topology {#Vietoris_topology}

Let $F$ be a closed subset and $U_1,\ldots,U_n$ be a finite collection of open subsets of *X*. Define

$$V(F,U_1,\ldots,U_n) = \{ Y \subseteq X \text{ closed} \mid Y \cap F = \emptyset \text{ and } Y\cap U_i \neq \emptyset \text{ for every }1\leq i\leq n \}.$$

These sets form a basis for a topology on *CL(X)*, called the Vietoris or finite topology, named for [Leopold Vietoris](wikipedia://en/105043).[^o11]

::: {#o13 .pointer-item cue=pointer name="Fell topology"}

### Fell topology {#Fell_topology}

A variant on the Vietoris topology is to allow only the sets $V(C,U_1,\ldots,U_n)$ where *C* is a [compact subset](wikipedia://en/6042) of *X* and $U_1,\ldots,U_n$ a finite collection of open subsets. This is again a base for a topology on *CL(X)* called the Fell topology or the *H*-topology.[^o14] Note, though, that the canonical map $i:x \mapsto \overline{\{x\}}$ is a homeomorphism onto its image if and only if *X* is Hausdorff,[^o15] so for non-Hausdorff *X*, the Fell topology is not a hypertopology in the sense of this article.

The Vietoris and Fell topologies coincide if *X* is a compact space, but have quite different properties if not. For instance, the Fell topology is always compact and it is compact Hausdorff whenever if *X* is locally compact.[^o16] On the other hand, the Vietoris topology is compact if and only if *X* is compact and Hausdorff if and only if *X* is [regular](wikipedia://en/53058).[^o17]

:::

### Other constructions {#Other_constructions}

The [Hausdorff distance](wikipedia://en/429296) on the closed subsets of a bounded metric space *X* induces a topology on *CL(X)*. If *X* is a compact [metric space](wikipedia://en/20018), this agrees with the Vietoris and Fell topologies.

The [Chabauty topology](wikipedia://en/7683674) on the closed subsets of a [locally compact group](wikipedia://en/1651204) coincides with the Fell topology.

:::
