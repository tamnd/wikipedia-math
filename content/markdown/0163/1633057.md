# Toroidal graph

*Image: Toroidal graph sample.gif.* A [cubic graph](wikipedia://en/980508) with 14 vertices embedded on a [torus](wikipedia://en/74800)

*Image: Heawood graph and map on torus.png.* The [Heawood graph](wikipedia://en/1396870) and associated map embedded in the torus.

::: {#o1 .subject cue=lead name="Toroidal graph"}

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [graph theory](wikipedia://en/12401), a **toroidal graph** is a [graph](wikipedia://en/325806) that can be [embedded](wikipedia://en/8149170) on a [torus](wikipedia://en/74800). In other words, the graph's [vertices](wikipedia://en/638899) and [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) can be placed on a torus such that no edges intersect except at a vertex that belongs to both.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Any graph that can be embedded in a plane can also be embedded in a torus, so every [planar graph](wikipedia://en/24314) is also a toroidal graph. A toroidal graph that cannot be embedded in a plane is said to have [genus](wikipedia://en/61891) 1.

The [Heawood graph](wikipedia://en/1396870), the [complete graph](wikipedia://en/85816) K<sub>7</sub> (and hence K<sub>5</sub> and K<sub>6</sub>), the [Petersen graph](wikipedia://en/194926) (and hence the [complete bipartite graph](wikipedia://en/525320) K<sub>3,3</sub>, since the Petersen graph contains a subdivision of it), one of the [Blanuša snarks](wikipedia://en/24054041),[^n1] and all [Möbius ladders](wikipedia://en/7355278) are toroidal. More generally, any graph with [crossing number](wikipedia://en/18298594) 1 is toroidal. Some graphs with greater crossing numbers are also toroidal: the [Möbius–Kantor graph](wikipedia://en/13396591), for example, has crossing number 4 and is toroidal.[^n2]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Any toroidal graph has [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) at most 7.[^n3] The [complete graph](wikipedia://en/85816) K<sub>7</sub> provides an example of a toroidal graph with chromatic number 7.[^n4]

Any [triangle-free](wikipedia://en/7667996) toroidal graph has chromatic number at most 4.[^n5]

By a result analogous to [Fáry's theorem](wikipedia://en/6805386), any toroidal graph may be [drawn](wikipedia://en/325813) with straight edges in a rectangle with [periodic boundary conditions](wikipedia://en/9667552).[^n6] Furthermore, the analogue of [Tutte's spring theorem](https://en.wikipedia.org/wiki/Tutte's_spring_theorem) applies in this case.[^n7] Toroidal graphs also have [book embeddings](wikipedia://en/3987703) with at most 7 pages.[^n8]

:::

## Obstructions {#Obstructions}

By the [Robertson–Seymour theorem](wikipedia://en/351769), there exists a finite set *H* of minimal non-toroidal graphs, such that a graph is toroidal if and only if it has no [graph minor](wikipedia://en/353042) in *H*. That is, *H* forms the set of [forbidden minors](wikipedia://en/13547826) for the toroidal graphs. The complete set *H* is not known, but it has at least 17,523 graphs. Alternatively, there are at least 250,815 non-toroidal graphs that are minimal in the [topological minor](https://en.wikipedia.org/wiki/Topological_minor) ordering. A graph is toroidal if and only if it has none of these graphs as a topological minor.[^n9]
