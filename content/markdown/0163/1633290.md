# Cofinal (mathematics)

::: {#o1 .subject cue=lead name="Cofinal"}

In [mathematics](wikipedia://en/18831), a [subset](wikipedia://en/27631) $B \subseteq A$ of a [preordered set](https://en.wikipedia.org/wiki/Preordered_set) $(A, \leq)$ is said to be **cofinal** or **frequent**[^n1] in $A$ if for every $a \in A,$ it is possible to find an element $b$ in $B$ that dominates $a$ (formally, $a\leq b$).

:::

Cofinal subsets are very important in the theory of [directed sets](wikipedia://en/9165) and [nets](wikipedia://en/22170), where “[cofinal subnet](wikipedia://en/12687840)” is the appropriate generalization of "[subsequence](wikipedia://en/236098)". They are also important in [order theory](wikipedia://en/361924), including the theory of [cardinal numbers](https://en.wikipedia.org/wiki/Cardinal_numbers), where the minimum possible [cardinality](wikipedia://en/6174) of a cofinal subset of $A$ is referred to as the [cofinality](wikipedia://en/6693) of $A.$

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $\,\leq\,$ be a [homogeneous binary relation](https://en.wikipedia.org/wiki/Homogeneous_binary_relation) on a set $A.$ A subset $B \subseteq A$ is said to be cofinal or frequent[^n1] with respect to $\,\leq\,$ if it satisfies the following condition:

For every $a \in A,$ there exists some $b \in B$ that $a \leq b.$

A subset that is not frequent is called infrequent.[^n1] This definition is most commonly applied when $(A, \leq)$ is a [directed set](wikipedia://en/9165), which is a [preordered set](https://en.wikipedia.org/wiki/Preordered_set) with additional properties.

**Final functions**

A [map](wikipedia://en/185427) $f : X \to A$ between two directed sets is said to be final[^o7] if the [image](https://en.wikipedia.org/wiki/Image_of_a_function) $f(X)$ of $f$ is a cofinal subset of $A.$

**Coinitial subsets**

A subset $B \subseteq A$ is said to be coinitial (or dense in the sense of [forcing](wikipedia://en/152205)) if it satisfies the following condition:

For every $a \in A,$ there exists some $b \in B$ such that $b \leq a.$

This is the [order-theoretic dual](wikipedia://en/600618) to the notion of cofinal subset. Cofinal (respectively coinitial) subsets are precisely the [dense sets](wikipedia://en/23523594) with respect to the right (respectively left) [order topology](wikipedia://en/213650#Left_and_right_order_topologies).

:::

## Properties {#Properties}

The cofinal relation over partially ordered sets ("[posets](wikipedia://en/23572)") is [reflexive](wikipedia://en/200458): every poset is cofinal in itself. It is also [transitive](wikipedia://en/200463): if $B$ is a cofinal subset of a poset $A,$ and $C$ is a cofinal subset of $B$ (with the partial ordering of $A$ applied to $B$), then $C$ is also a cofinal subset of $A.$

For a partially ordered set with [maximal elements](https://en.wikipedia.org/wiki/Maximal_element), every cofinal subset must contain all [maximal elements](https://en.wikipedia.org/wiki/Maximal_element), otherwise a maximal element that is not in the subset would fail to be less than or equal to any element of the subset, violating the definition of cofinal. For a partially ordered set with a [greatest element](https://en.wikipedia.org/wiki/Greatest_element), a subset is cofinal if and only if it contains that greatest element (this follows, since a greatest element is necessarily a maximal element). Partially ordered sets without greatest element or maximal elements admit disjoint cofinal subsets. For example, the even and odd [natural numbers](wikipedia://en/21474) form disjoint cofinal subsets of the set of all natural numbers.

If a partially ordered set $A$ admits a [totally ordered](https://en.wikipedia.org/wiki/Totally_ordered) cofinal subset, then we can find a subset $B$ that is [well-ordered](https://en.wikipedia.org/wiki/Well-ordered) and cofinal in $A.$

If $(A, \leq)$ is a [directed set](wikipedia://en/9165) and if $B \subseteq A$ is a cofinal subset of $A$ then $(B, \leq)$ is also a directed set.[^n1]

:::

## Examples and sufficient conditions {#Examples_and_sufficient_conditions}

Any superset of a cofinal subset is itself cofinal.[^n1]

If $(A, \leq)$ is a directed set and if some union of (one or more) finitely many subsets $S_1 \cup \cdots \cup S_n$ is cofinal then at least one of the set $S_1, \ldots, S_n$ is cofinal.[^n1] This property is not true in general without the hypothesis that $(A, \leq)$ is directed.

**Subset relations and neighborhood bases**

Let $X$ be a [topological space](wikipedia://en/30450) and let $\mathcal{N}_x$ denote the [neighborhood filter](https://en.wikipedia.org/wiki/Neighborhood_filter) at a point $x \in X.$ The [superset](https://en.wikipedia.org/wiki/Superset) relation $\,\supseteq\,$ is a [partial order](https://en.wikipedia.org/wiki/Partial_order) on $\mathcal{N}_x$: explicitly, for any sets $S$ and $T,$ declare that $S \leq T$ if and only if $S \supseteq T$ (so in essence, $\,\leq\,$ is equal to $\,\supseteq\,$). A subset $\mathcal{B} \subseteq \mathcal{N}_x$ is called a [neighborhood base](https://en.wikipedia.org/wiki/Neighborhood_base) at $x$ if (and only if) $\mathcal{B}$ is a cofinal subset of $\left(\mathcal{N}_x, \supseteq\right);$ that is, if and only if for every $N \in \mathcal{N}_x$ there exists some $B \in \mathcal{B}$ such that $N \supseteq B.$ (I.e. such that $N \leq B$.)

**Cofinal subsets of the real numbers**

For any $- \infty < x < \infty,$ the interval $(x, \infty)$ is a cofinal subset of $(\mathbb{R}, \leq)$ but it is not a cofinal subset of $(\mathbb{R}, \geq).$ The set $\mathbb{N}$ of [natural numbers](wikipedia://en/21474) (consisting of positive integers) is a cofinal subset of $(\mathbb{R}, \leq)$ but this is not true of the set of negative integers $- \mathbb{N} := \{ -1, -2, -3, \ldots \}.$

Similarly, for any $-\infty < y < \infty,$ the interval $(- \infty, y)$ is a cofinal subset of $(\mathbb{R}, \geq)$ but it is not a cofinal subset of $(\mathbb{R}, \leq).$ The set $- \mathbb{N}$ of negative integers is a cofinal subset of $(\mathbb{R}, \geq)$ but this is not true of the natural numbers $\mathbb{N}.$ The set $\mathbb{Z}$ of all [integers](wikipedia://en/14563) is a cofinal subset of $(\mathbb{R}, \leq)$ and also a cofinal subset of $(\mathbb{R}, \geq)$; the same is true of the set $\mathbb{Q}.$

## Cofinal set of subsets {#Cofinal_set_of_subsets}

A particular but important case is given if $A$ is a subset of the [power set](wikipedia://en/23799) $\wp(E)$ of some set $E,$ ordered by reverse inclusion $\,\supseteq.$ Given this ordering of $A,$ a subset $B \subseteq A$ is cofinal in $A$ if for every $a \in A$ there is a $b \in B$ such that $a \supseteq b.$

For example, let $E$ be a [group](wikipedia://en/19447) and let $A$ be the set of [normal subgroups](wikipedia://en/21918) of finite [index](wikipedia://en/230581). The [profinite completion](wikipedia://en/24266) of $E$ is defined to be the [inverse limit](wikipedia://en/15109) of the [inverse system](https://en.wikipedia.org/wiki/Inverse_system) of finite [quotients](https://en.wikipedia.org/wiki/Quotient_%28group_theory%29) of $E$ (which are parametrized by the set $A$). In this situation, every cofinal subset of $A$ is sufficient to construct and describe the profinite completion of $E.$
