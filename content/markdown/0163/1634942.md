# List of alternative set theories

::: {#o1 .subject cue=lead name="List of alternative set theories"}

In [mathematical logic](wikipedia://en/19636), an **alternative set theory** is any of the alternative mathematical approaches to the concept of [set](wikipedia://en/26691) and any alternative to the de facto standard set theory described in [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory) by the axioms of [Zermelo–Fraenkel set theory](wikipedia://en/152214).

:::
