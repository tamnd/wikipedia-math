# Do-calculus

::: {#o1 .subject cue=lead name="Do-calculus"}

***Do*-calculus** is a set of mathematical rules devised by [Judea Pearl](https://en.wikipedia.org/wiki/Judea_Pearl) in 1995 to determine whether [causal effects](https://en.wikipedia.org/wiki/Causality) can be identified from observational data under specific assumptions encoded in a [causal graph](wikipedia://en/44239711). It provides a systematic method for transforming expressions involving the *do*-operator (representing interventions) into expressions involving only observable probabilities, enabling the identification of causal relationships.

:::

## Definition and purpose {#Definition_and_purpose}

Causal queries involving interventions (e.g., $P(y \mid \mathrm{do}(x))$) are considered *[identifiable](https://en.wikipedia.org/wiki/Identifiable)* if they can be expressed using observational data alone, independent of unmeasured parameters. The *do*-calculus achieves this by leveraging graphical criteria from [directed acyclic graphs](https://en.wikipedia.org/wiki/Directed_acyclic_graphs) (DAGs) to remove *do*-operators through algebraic manipulations.[^o3]

## The three rules of *Do*-calculus {#The_three_rules_of_Do-calculus}

The rules[^o5] apply to a causal graph $\mathcal{G}$ and assume the [Markov condition](https://en.wikipedia.org/wiki/Markov_condition) holds:

### Rule 1: Insertion/deletion of observations {#Rule_1:_Insertion/deletion_of_observations}

$$P(y \mid \mathrm{do}(x), z, w) = P(y \mid \mathrm{do}(x), w) \quad \text{if } Y \perp\!\!\!\perp Z \mid X, W \text{ in } \mathcal{G}_{\overline{X}}$$

This rule allows the removal of irrelevant observations ($Z$) if they are *d*-separated from $Y$ given $X$ and $W$ in the graph where incoming edges to $X$ are removed.

### Rule 2: Action/observation exchange {#Rule_2:_Action/observation_exchange}

$$P(y \mid \mathrm{do}(x), \mathrm{do}(z), w) = P(y \mid \mathrm{do}(x), z, w) \quad \text{if } Y \perp\!\!\!\perp Z \mid X, W \text{ in } \mathcal{G}_{\overline{X}\, \underline{Z}}$$

This rule permits replacing an intervention ($\mathrm{do}(z)$) with an observation ($z$) if $Y$ and $Z$ are *d*-separated in the graph where outgoing edges from $Z$ and incoming edges to $X$ are removed.

### Rule 3: Insertion/deletion of interventions {#Rule_3:_Insertion/deletion_of_interventions}

$$P(y \mid \mathrm{do}(x), \mathrm{do}(z), w) = P(y \mid \mathrm{do}(x), w) \quad \text{if } Y \perp\!\!\!\perp Z \mid X, W \text{ in } \mathcal{G}_{\overline{X}\, \overline{Z(W)}}$$

This rule removes irrelevant interventions ($\mathrm{do}(z)$) if $Y$ and $Z$ are *d*-separated in a graph modified to block paths through $Z$.

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

*Do*-calculus can be applied to various domains within [causal inference](wikipedia://en/37103476) such as [mediation analysis](wikipedia://en/7072682) in decomposing direct and indirect effects.[^o11][^o12] It can be used for meta-synthesis to combine the results from heterogeneous studies.[^o11][^o13]

:::

## Completeness {#Completeness}

The *do*-calculus is considered [complete](wikipedia://en/31271451): if repeated application of the rules cannot eliminate the *do*-operator, the causal effect is not identifiable. This result was formalized in 2006 by Huang, Valtorta, Shpitser, and Pearl.[^o15]

## Criticism {#Criticism}

Critics have pointed out that other frameworks, such as [structural equation modeling](wikipedia://en/2007748) (SEM) or [Bayesian networks](wikipedia://en/203996), may offer more intuitive approaches to causal inference for certain applications. These methods often emphasize parameter estimation rather than identifiability, which can be more relevant for applied research.[^o17]
