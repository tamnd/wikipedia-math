# Tall cardinal

::: {#o1 .subject cue=lead name="Tall cardinal"}

In mathematics, a **tall cardinal** is a [large cardinal](wikipedia://en/383644) *κ* that is *θ*-tall for all ordinals *θ*, where a cardinal is called *θ*-tall if there is an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* : *V* → *M* with critical point *κ* such that *j*(*κ*) > θ and *M*<sup>*κ*</sup> ⊆ M.

:::

Tall cardinals are [equiconsistent](https://en.wikipedia.org/wiki/Equiconsistent) with [strong cardinals](wikipedia://en/248104).
