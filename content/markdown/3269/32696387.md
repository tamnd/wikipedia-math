# Well-covered graph

::: {#o1 .subject cue=lead name="Well-covered graph"}

*Image: Well-covered graph.svg.* A well-covered graph, the [intersection graph](wikipedia://en/7726759) of the nine diagonals of a [hexagon](wikipedia://en/59733). The three red vertices form one of its 14 equal-sized maximal independent sets, and the six blue vertices form the complementary minimal vertex cover.

In [graph theory](wikipedia://en/12401), a **well-covered graph** is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) in which the minimal vertex covers all have the same size. Here, a [vertex cover](wikipedia://en/562782) is a set of vertices that touches all edges, and it is [minimal](https://en.wikipedia.org/wiki/Minimal_element) if removing any vertex from it would leave some edge uncovered. Equivalently, well-covered graphs are the graphs in which all [maximal independent sets](wikipedia://en/1793590) have equal size. Well-covered graphs were defined and first studied by [Michael D. Plummer](https://en.wikipedia.org/wiki/Michael_D._Plummer) in 1970.

:::

The well-covered graphs include all [complete graphs](wikipedia://en/85816), balanced [complete bipartite graphs](wikipedia://en/525320), and the [rook's graphs](wikipedia://en/7324959) whose vertices represent squares of a chessboard and edges represent moves of a chess rook. Known characterizations of the well-covered [cubic graphs](wikipedia://en/980508), well-covered [claw-free graphs](wikipedia://en/12415907), and well-covered graphs of high [girth](wikipedia://en/12013) allow these graphs to be recognized in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), but testing whether other kinds of graph are well-covered is a [coNP-complete](https://en.wikipedia.org/wiki/CoNP-complete) problem.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A vertex cover in an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is a set of vertices that touches every edge in the graph. A vertex cover is minimal, or irredundant, if removing any vertex from it would destroy the covering property: the removal would cause some edge to become uncovered. It is minimum if there is no other vertex cover with fewer vertices. A well-covered graph is one in which every minimal cover is also minimum. In the original paper defining well-covered graphs, Plummer writes that this is "obviously equivalent" to the property that every two minimal covers have the same number of vertices as each other.[^o4]

An [independent set](wikipedia://en/524501) in a graph is a set of vertices no two of which are adjacent to each other. If $C$ is a vertex cover in a graph $G$, the [complement](wikipedia://en/54347) of $C$ must be an independent set, and vice versa. $C$ is a minimal vertex cover if and only if its complement $I$ is a maximal independent set, and $C$ is a minimum vertex cover if and only if its complement is a maximum independent set. Therefore, a well-covered graph is, equivalently, a graph in which every maximal independent set has the same size, or a graph in which every maximal independent set is maximum.[^n1]

In the original paper defining well-covered graphs, these definitions were restricted to [connected graphs](wikipedia://en/1614492),[^n2] although they are meaningful for disconnected graphs as well. Some later authors have replaced the connectivity requirement with the weaker requirement that a well-covered graph must not have any isolated vertices.[^n3] For both connected well-covered graphs and well-covered graphs without isolated vertices, there can be no *essential vertices*, vertices which belong to every minimum vertex cover. Additionally, every well-covered graph is a [critical graph](wikipedia://en/680672) for vertex covering in the sense that, for every vertex $v$, deleting $v$ from the graph produces a graph with a smaller minimum vertex cover.[^n2]

The [independence complex](wikipedia://en/20751674) of a graph $G$ is the [simplicial complex](wikipedia://en/252686) having a simplex for each independent set in $G$. A simplicial complex is said to be pure if all its maximal simplices have the same [cardinality](wikipedia://en/6174), so a well-covered graph is equivalently a graph with a pure independence complex.[^o9]

## Examples {#Examples}

floatright

A [cycle graph](wikipedia://en/878962) of length four or five is well-covered: in each case, every maximal independent set has size two. A cycle of length seven, and a path of length three, are also well-covered.[^n4] Every [complete graph](wikipedia://en/85816) is well-covered: every maximal independent set consists of a single vertex. Similarly, every [cluster graph](wikipedia://en/50931136) (a [disjoint union](wikipedia://en/188946) of complete graphs) is well-covered.[^n5] A [complete bipartite graph](wikipedia://en/525320) is well-covered if the two sides of its bipartition have equal numbers of vertices, for these are its only two maximal independent sets. The [complement graph](wikipedia://en/1175649) of a [triangle-free graph](wikipedia://en/7667996) with no [isolated vertices](https://en.wikipedia.org/wiki/Isolated_vertex) is well-covered: it has no independent sets larger than two, and every single vertex can be extended to a two-vertex independent set.[^n4]

A [rook's graph](wikipedia://en/7324959) is well-covered: if one places any set of [rooks](https://en.wikipedia.org/wiki/Rook_%28chess%29) on a [chessboard](https://en.wikipedia.org/wiki/Chessboard) so that no two rooks are attacking each other, it is always possible to continue placing more non-attacking rooks until there is one on every row and column of the chessboard.[^o15] The graph whose vertices are the diagonals of a [simple polygon](wikipedia://en/1059530) and whose edges connect pairs of diagonals that cross each other is well-covered, because its maximal independent sets are triangulations of the polygon and all triangulations have the same number of edges.[^n6]

If $G$ is any $n$-vertex graph, then the [rooted product](wikipedia://en/1373338) of $G$ with a one-edge graph (that is, the graph $H$ formed by adding $n$ new vertices to $G$, each of degree one and each adjacent to a distinct vertex in $G$) is well-covered. For, a maximal independent set in $H$ must consist of an arbitrary independent set in $G$ together with the degree-one neighbors of the complementary set, and must therefore have size $n$.[^o17] More generally, given any graph $G$ together with a [clique cover](wikipedia://en/17113364) (a partition $p$ of the vertices of $G$ into cliques), the graph $G^{p}$ formed by adding another vertex to each clique is well-covered; the rooted product is the special case of this construction when $p$ consists of $n$ one-vertex cliques.[^o18] Thus, every graph is an [induced subgraph](wikipedia://en/1655188) of a well-covered graph.

## Bipartiteness, very well covered graphs, and girth {#Bipartiteness,_very_well_covered_graphs,_and_girth}

(Favaron 1982) defines a **very well covered graph** to be a well-covered graph (possibly disconnected, but with no isolated vertices) in which each maximal independent set (and therefore also each minimal vertex cover) contains exactly half of the vertices. This definition includes the rooted products of a graph $G$ and a one-edge graph. It also includes, for instance, the bipartite well-covered graphs studied by (Ravindra 1977) and (Berge 1981): in a bipartite graph without isolated vertices, both sides of any bipartition form maximal independent sets (and minimal vertex covers), so if the graph is well-covered both sides must have equally many vertices. In a well-covered graph with $n$ vertices, without isolated vertices, the size of a maximum independent set is at most $n/2$, so very well covered graphs are the well covered graphs in which the maximum independent set size is as large as possible.[^n7]

A bipartite graph $G$ is well-covered if and only if it has a [perfect matching](wikipedia://en/44031) $M$ with the property that, for every edge $uv$ in $M$, the [induced subgraph](wikipedia://en/1655188) of the neighbors of $u$ and $v$ forms a [complete bipartite graph](wikipedia://en/525320).[^o25] The characterization in terms of matchings can be extended from bipartite graphs to very well covered graphs: a graph $G$ is very well covered if and only if it has a perfect matching $M$ with the following two properties:

1. No edge of $M$ belongs to a triangle in $G$, and
1. If an edge of $M$ is the central edge of a three-edge path in $G$, then the two endpoints of the path must be adjacent.

Moreover, if $G$ is very well covered, then every perfect matching in $G$ satisfies these properties.[^o26]

Trees are a special case of bipartite graphs, and testing whether a tree is well-covered can be handled as a much simpler special case of the characterization of well-covered bipartite graphs: if $G$ is a tree with more than two vertices, it is well-covered if and only if each non-leaf node of the tree is adjacent to exactly one leaf.[^o25] The same characterization applies to graphs that are locally tree-like, in the sense that low-diameter neighborhoods of every vertex are acyclic: if a graph has [girth](wikipedia://en/12013) eight or more (so that, for every vertex $v$, the subgraph of vertices within distance three of $v$ is acyclic) then it is well-covered if and only if every vertex of [degree](wikipedia://en/1374448) greater than one has exactly one neighbor of degree one.[^o27] A closely related but more complex characterization applies to well-covered graphs of girth five or more.[^o28]

## Regularity and planarity {#Regularity_and_planarity}

*Image: 3r3c well-covered.svg.* The seven cubic 3-connected well-covered graphs

*Image: 3r1c well-covered.svg.* A cubic 1-connected well-covered graph, formed by replacing each node of a six-node path by one of three fragments

*Image: Snub disphenoid.png.* The [snub disphenoid](wikipedia://en/1133565), one of four well-covered 4-connected 3-dimensional simplicial polyhedra.

The [cubic](wikipedia://en/980508) ([3-regular](wikipedia://en/85821)) well-covered graphs have been classified: they consist of seven [3-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph) examples, together with three infinite families of cubic graphs with lesser connectivity.[^o33]

The seven 3-connected cubic well-covered graphs are the [complete graph](wikipedia://en/85816) $K_{4}$, the graphs of the [triangular prism](wikipedia://en/2859584) and the [pentagonal prism](wikipedia://en/2859659), the [Dürer graph](wikipedia://en/23453065), the [utility graph](https://en.wikipedia.org/wiki/Utility_graph) $K_{3,3}$, an eight-vertex graph obtained from the utility graph by a [Y-Δ transform](wikipedia://en/74743071), and the 14-vertex [generalized Petersen graph](wikipedia://en/23716451) $G(7,2)$.[^o30] Of these graphs, the first four are [planar graphs](wikipedia://en/24314). They are the only four cubic [polyhedral graphs](wikipedia://en/24656270) (graphs of [simple](wikipedia://en/8853286) [convex polyhedra](https://en.wikipedia.org/wiki/Convex_polyhedron)) that are well-covered.[^n8] Four of the graphs (the two prisms, the Dürer graph, and $G(7,2)$) are generalized Petersen graphs.

The 1- and 2-connected cubic well-covered graphs are all formed by replacing the nodes of a path or cycle by three fragments of graphs which (Plummer 1993) labels $A$, $B$, and $C$. Fragments $A$ or $B$ may be used to replace the nodes of a cycle or the interior nodes of a path, while fragment $C$ is used to replace the two end nodes of a path. Fragment $A$ contains a [bridge](wikipedia://en/1305071), so the result of performing this replacement process on a path and using fragment $A$ to replace some of the path nodes (and the other two fragments for the remaining nodes) is a 1-vertex-connected cubic well-covered graph. All 1-vertex-connected cubic well-covered graphs have this form, and all such graphs are planar.[^o33]

There are two types of 2-vertex-connected cubic well-covered graphs. One of these two families is formed by replacing the nodes of a cycle by fragments $A$ and $B$, with at least two of the fragments being of type $A$; a graph of this type is planar if and only if it does not contain any fragments of type $B$. The other family is formed by replacing the nodes of a path by fragments of type $B$ and $C$; all such graphs are planar.[^o33]

Complementing the characterization of well-covered simple polyhedra in three dimensions, researchers have also considered the well-covered [simplicial polyhedra](wikipedia://en/8853373), or equivalently the well-covered maximal planar graphs. Every maximal planar graph with five or more vertices has vertex connectivity 3, 4, or 5.[^o34] There are no well-covered 5-connected maximal planar graphs, and there are only four 4-connected well-covered maximal planar graphs: the graphs of the [regular octahedron](wikipedia://en/22458), the [pentagonal dipyramid](https://en.wikipedia.org/wiki/Pentagonal_dipyramid), the [snub disphenoid](wikipedia://en/1133565), and an irregular polyhedron (a nonconvex [deltahedron](wikipedia://en/493995)) with 12 vertices, 30 edges, and 20 triangular faces. However, there are infinitely many 3-connected well-covered maximal planar graphs.[^o35] For instance, if a $3t$-vertex maximal planar graph has $t$ disjoint triangle faces, then these faces will form a clique cover. Therefore, the clique cover construction, which for these graphs consists of subdividing each of these $t$ triangles into three new triangles meeting at a central vertex, produces a well-covered maximal planar graph.[^o36]

## Complexity {#Complexity}

Testing whether a graph contains two maximal independent sets of different sizes is [NP-complete](https://en.wikipedia.org/wiki/NP-complete); that is, complementarily, testing whether a graph is well-covered is coNP-complete.[^o39] Although it is easy to find maximum independent sets in graphs that are known to be well-covered, it is also NP-hard for an algorithm to produce as output, on all graphs, either a maximum independent set or a guarantee that the input is not well-covered.[^o40]

In contrast, it is possible to test whether a given graph $G$ is very well covered in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time). To do so, find the subgraph $H$ of $G$ consisting of the edges that satisfy the two properties of a matched edge in a very well covered graph, and then use a matching algorithm to test whether $H$ has a perfect matching.[^o26] Some problems that are NP-complete for arbitrary graphs, such as the problem of finding a [Hamiltonian cycle](https://en.wikipedia.org/wiki/Hamiltonian_cycle), may also be solved in polynomial time for very well covered graphs.[^o41]

A graph is said to be **equimatchable** if every [maximal matching](https://en.wikipedia.org/wiki/Maximal_matching) is maximum; that is, it is equimatchable if its [line graph](wikipedia://en/675231) is well-covered.[^n9] More strongly it is called **randomly matchable** if every maximal matching is a [perfect matching](wikipedia://en/44031). The only connected randomly matchable graphs are the complete graphs and the balanced complete bipartite graphs.[^n10] It is possible to test whether a line graph, or more generally a [claw-free graph](wikipedia://en/12415907), is well-covered in polynomial time.[^o44]

The characterizations of well-covered graphs with girth five or more, and of well-covered graphs that are 3-regular, also lead to efficient polynomial time algorithms to recognize these graphs.[^o45]
