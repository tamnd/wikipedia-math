# Metric differential

::: {#o1 .subject cue=lead name="Metric differential"}

In [mathematical analysis](wikipedia://en/48396), a **metric differential** is a generalization of a [derivative](wikipedia://en/7921) for a [Lipschitz continuous function](wikipedia://en/51731) defined on a [Euclidean space](wikipedia://en/9697) and taking values in an arbitrary [metric space](wikipedia://en/20018). With this definition of a derivative, one can generalize [Rademacher's theorem](wikipedia://en/7764195) to metric space-valued Lipschitz functions.

:::

## Discussion {#Discussion}

[Rademacher's theorem](wikipedia://en/7764195) states that a Lipschitz map *f* : **R**<sup>*n*</sup> → **R**<sup>*m*</sup> is differentiable [almost everywhere](wikipedia://en/44688) in **R**<sup>*n*</sup>; in other words, for almost every *x*, *f* is approximately linear in any sufficiently small range of *x*. If *f* is a function from a Euclidean space **R**<sup>*n*</sup> that takes values instead in a [metric space](wikipedia://en/20018) *X*, it doesn't immediately make sense to talk about differentiability since *X* has no linear structure a priori. Even if you assume that *X* is a [Banach space](wikipedia://en/3989) and ask whether a [Fréchet derivative](wikipedia://en/2735727) exists almost everywhere, this does not hold. For example, consider the function *f* : \[0,1\] → *L*<sup>1</sup>(\[0,1\]), mapping the unit interval into the [space of integrable functions](wikipedia://en/45194), defined by *f*(*x*) = *χ*<sub>\[0,*x*\]</sub>, this function is Lipschitz (and in fact, an [isometry](wikipedia://en/254777)) since, if 0 ≤ *x* ≤ *y*≤ 1, then

$$|f(x)-f(y)|=\int_0^1 |\chi_{[0,x]}(t)-\chi_{[0,y]}(t)|\,dt = \int_x^y \, dt = |x-y|,$$

but one can verify that lim<sub>*h*→0</sub>(*f*(*x* + *h*) − *f*(*x*))/*h* does not converge to an *L*<sup>1</sup> function for any *x* in \[0,1\], so it is not differentiable anywhere.

However, if you look at Rademacher's theorem as a statement about how a Lipschitz function stabilizes as you zoom in on almost every point, then such a theorem exists but is stated in terms of the metric properties of *f* instead of its linear properties.

## Definition and existence of the metric differential {#Definition_and_existence_of_the_metric_differential}

A substitute for a derivative of *f*:**R**<sup>n</sup> → *X* is the metric differential of *f* at a point *z* in **R**<sup>*n*</sup> which is a function on **R**<sup>*n*</sup> defined by the limit

$$MD(f,z)(x)=\lim_{r\rightarrow 0} \frac{d_{X}(f(z+rx),f(z))}{r}$$

whenever the limit exists (here *d*<sub>*X*</sub> denotes the metric on *X*).

A theorem due to Bernd Kirchheim[^o4] states that a Rademacher theorem in terms of metric differentials holds: for almost every *z* in **R**<sup>*n*</sup>, MD(*f*, *z*) is a [seminorm](wikipedia://en/292067) and

$$d_X(f(x),f(y)) - MD(f,z)(x-y) = o(|x-z|+|y-z|).$$

The [little-o notation](https://en.wikipedia.org/wiki/Little_o_notation#Little-o_notation) employed here means that, at values very close to *z*, the function *f* is approximately an [isometry](wikipedia://en/254777) from **R**<sup>*n*</sup> with respect to the seminorm MD(*f*, *z*) into the metric space *X*.
