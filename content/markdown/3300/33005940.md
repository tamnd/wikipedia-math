# XUDA

::: {#o1 .subject cue=lead name="XUDA"}

**XUDA** (**Xcert Universal Database API**) is a [library](https://en.wikipedia.org/wiki/Library_%28computing%29) that is used and integrated in many [public key infrastructure](wikipedia://en/194112) (PKI) products of different vendors like the KEON CA of RSA LABS.

:::

XUDA is an [Application programming interface](https://en.wikipedia.org/wiki/Application_programming_interface) (API) that enables programmers to develop PKI applications. XUDA is best seen as a toolkit or library of programs that isolates applications from the complexities of PKI. It encapsulates secure database access and strong authentication via public key certificates, and employs [SSL](wikipedia://en/187813)–[LDAP](https://en.wikipedia.org/wiki/Lightweight_Directory_Access_Protocol) to query remote databases using certificates presented during an SSL transaction. XUDA was built to use the cryptography of other vendors. This allows vendors to provide customers with the cryptography of their choice, including all [PKCS#11](https://en.wikipedia.org/wiki/PKCS11) compliant smart cards and hardware tokens.

XCert is a privately held company that developed and delivered digital certificate-based products for securing e-business transactions. In February 2001 the company was acquired by [RSA Labs](https://en.wikipedia.org/wiki/RSA_Labs).[^o2]
