# Integer points in convex polyhedra

::: {#o1 .subject cue=lead name="Integer points in convex polyhedra"}

*Image: IP polytope with LP relaxation.svg.* The red dots are the integer lattice points within the blue polygon, the latter representing a two-dimensional [linear program](https://en.wikipedia.org/wiki/Linear_program)

The study of **integer points in convex polyhedra**[^o2] is motivated by questions such as "how many nonnegative [integer](wikipedia://en/14563)-valued solutions does a [system of linear equations](wikipedia://en/113087) with nonnegative coefficients have" or "how many solutions does an [integer linear program](https://en.wikipedia.org/wiki/Integer_linear_program) have". Counting integer points in [convex polyhedra](https://en.wikipedia.org/wiki/Convex_polyhedra) or other questions about them arise in [representation theory](wikipedia://en/19378200), [commutative algebra](wikipedia://en/245990), [algebraic geometry](wikipedia://en/1997), [statistics](wikipedia://en/26685), and [computer science](https://en.wikipedia.org/wiki/Computer_science).[^o3]

:::

The set of integer points, or, more generally, the set of points of an [affine lattice](https://en.wikipedia.org/wiki/Affine_lattice), in a polyhedron is called **Z-polyhedron**,[^o4] from the mathematical notation $\mathbb{Z}$ or **Z** for the set of integer numbers.[^o5]

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

For a [lattice](wikipedia://en/469246) Λ, [Minkowski's theorem](wikipedia://en/53455) relates the number d(Λ) (the volume of a fundamental parallelepiped of the lattice) and the volume of a given symmetric [convex set](wikipedia://en/6292) *S* to the number of lattice points contained in *S*.

The number of lattice points contained in a [polytope](wikipedia://en/23471) all of whose vertices are elements of the lattice is described by the polytope's [Ehrhart polynomial](wikipedia://en/316904). Formulas for some of the coefficients of this polynomial involve d(Λ) as well.

:::

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

### Loop optimization {#Loop_optimization}

In certain approaches to [loop optimization](https://en.wikipedia.org/wiki/Loop_optimization), the set of the executions of the loop body is viewed as the set of integer points in a polyhedron defined by loop constraints.
