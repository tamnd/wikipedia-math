# Multicover bifiltration

::: {#o1 .subject cue=lead name="Multicover bifiltration"}

*Image: Example\_of\_the\_Multicover\_Bifiltration.webp.* The 2- and 3-fold covers of 7 points in the plane with respect to a particular scale parameter.

The **multicover bifiltration** is a two-parameter sequence of nested [topological spaces](wikipedia://en/30450) derived from the covering of a [finite set](wikipedia://en/11742) in a [metric space](wikipedia://en/20018) by growing [metric balls](wikipedia://en/160556). It is a multidimensional extension of the [offset filtration](https://en.wikipedia.org/wiki/Offset_Filtration) that captures density information about the underlying data set by filtering the points of the offsets at each index according to how many balls cover each point.[^o2] The multicover bifiltration has been an object of study within multidimensional [persistent homology](wikipedia://en/31069689) and [topological data analysis](wikipedia://en/17740009).[^o3][^o4][^o5][^o6][^o7][^o8]

:::

::: {#o10 .definition cue=heading name="Definition"}

## Definition {#Definition}

Following the notation of Corbet et al. (2022), given a finite set $A\subset \mathbb R^d$, the **multicover bifiltration** on $A$ is a two-parameter filtration indexed by $\mathbb R \times \mathbb N^{\text{op}}$ defined index-wise as $\operatorname{Cov}_{r,k} := \{b \in \mathbb R^d : ||b-a|| \leq r \text{ for at least } k \text{ points } a\in A\}$, where $\mathbb N$ denotes the non-negative integers.[^o11] Note that when $k=1$ is fixed we recover the [Offset Filtration](https://en.wikipedia.org/wiki/Offset_Filtration).

:::

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The multicover bifiltration admits a topologically equivalent polytopal model of polynomial size, called the "[rhomboid](https://en.wikipedia.org/wiki/Rhomboid) bifiltration."[^o11] The rhomboid bifiltration is an extension of the rhomboid [tiling](https://en.wikipedia.org/wiki/Tiling_%28geometry%29) introduced by Edelsbrunner and Osang in 2021 for computing the [persistent homology](wikipedia://en/31069689) of the multicover bifiltration along one axis of the indexing set.[^o3] The rhomboid bifiltration on a set of $n$ points in a [Euclidean space](wikipedia://en/9697) can be computed in polynomial time.[^o11]

*Image: Rhomboid\_Tiling.webp.* An example of the rhomboid tiling on a set of five points.

The multicover bifiltration is also topologically equivalent to a multicover nerve construction due to Sheehy called the [subdivision-Čech bifiltration](wikipedia://en/73390595), which considers the [barycentric subdivision](wikipedia://en/583651) on the nerve of the offsets.[^o14] In particular, the subdivision-Čech and multicover bifiltrations are [weakly equivalent](wikipedia://en/34615176), and hence have [isomorphic](wikipedia://en/14828) [homology](wikipedia://en/142432) modules in all dimensions.[^o5] However, the subdivision-Čech bifiltration has an exponential number of simplices in the size of the data set, and hence is not amenable to efficient direct computations.[^o11]

:::
