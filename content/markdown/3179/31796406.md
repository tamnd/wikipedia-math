# Chebyshev's bias

::: {#o1 .subject cue=lead name="Chebyshev's bias"}

*Image: Chebyshev bias.svg.* Plot of the function $\pi(x;4,3)-\pi(x;4,1)$ for *n* ≤ 30000

In [number theory](wikipedia://en/21527), **Chebyshev's bias** is the phenomenon that most of the time, there are more [primes](wikipedia://en/23666) of the form 4*k* + 3 than of the form 4*k* + 1, up to the same limit. This phenomenon was first observed by Russian mathematician [Pafnuty Chebyshev](wikipedia://en/149568) in 1853.

:::

## Description {#Description}

Let $\pi$(*x*; *n*, *m*) denote the number of primes of the form *nk* + *m* up to *x*. By the [prime number theorem](wikipedia://en/23692) (extended to [arithmetic progressions](wikipedia://en/23692#Prime_number_theorem_for_arithmetic_progressions)),

$$\pi(x;4,1)\sim\pi(x;4,3)\sim \frac{1}{2}\frac{x}{\ln x}.$$

That is, half of the primes are of the form 4*k* + 1, and half of the form 4*k* + 3. A reasonable guess would be that $\pi$(*x*; 4, 1) > $\pi$(*x*; 4, 3) and $\pi$(*x*; 4, 1) \< $\pi$(*x*; 4, 3) each also occur 50% of the time. This, however, is not supported by numerical evidence — in fact, $\pi$(*x*; 4, 3) > $\pi$(*x*; 4, 1) occurs much more frequently. For example, this inequality holds for all primes *x* \< 26833 except 5, 17, 41 and 461, for which $\pi$(*x*; 4, 1) = $\pi$(*x*; 4, 3). The first *x* such that $\pi$(*x*; 4, 1) > $\pi$(*x*; 4, 3) is 26861, that is, $\pi$(*x*; 4, 3) ≥ $\pi$(*x*; 4, 1) for all *x* \< 26861.

In general, if 0 \< *a*, *b* \< *n* are integers, [gcd](wikipedia://en/12354)(*a*, *n*) = gcd(*b*, *n*) = 1, *a* is a [quadratic residue](wikipedia://en/200091) [mod](wikipedia://en/20087) *n*, *b* is a quadratic nonresidue mod *n*, then $\pi$(*x*; *n*, *b*) > $\pi$(*x*; *n*, *a*) occurs more often than not. This has been proved only by assuming strong forms of the [Riemann hypothesis](wikipedia://en/19344125). The stronger conjecture of [Knapowski](wikipedia://en/59573298) and [Turán](wikipedia://en/614998), that the [density](wikipedia://en/1819983) of the numbers *x* for which $\pi$(*x*; 4, 3) > $\pi$(*x*; 4, 1) holds is 1 (that is, it holds for [almost all](wikipedia://en/1309) *x*), turned out to be false. They, however, do have a [logarithmic density](https://en.wikipedia.org/wiki/Logarithmic_density), which is approximately 0.9959....[^o3]

## Extension to higher power residue {#Extension_to_higher_power_residue}

Let *m* and *n* be integers such that *m* ≥ 0, *n* > 0, gcd(*m*, *n*) = 1, define a [function](wikipedia://en/185427)

$$f(m,n)=\sum_{p \text{ is prime, } p\,\mid\,\varphi(n),\ x^p \,\equiv\, m \pmod n \text{ has a solution }} \left(\frac{1}{p}\right),$$

where $\varphi$ is the [Euler's totient function](wikipedia://en/53452).

For example, *f*(1, 5) = *f*(4, 5) = 1/2, *f*(2, 5) = *f*(3, 5) = 0, *f*(1, 6) = 1/2, *f*(5, 6) = 0, *f*(1, 7) = 5/6, *f*(2, 7) = *f*(4, 7) = 1/2, *f*(3, 7) = *f*(5, 7) = 0, *f*(6, 7) = 1/3, *f*(1, 8) = 1/2, *f*(3, 8) = *f*(5, 8) = *f*(7, 8) = 0, *f*(1, 9) = 5/6, *f*(2, 9) = *f*(5, 9) = 0, *f*(4, 9) = *f*(7, 9) = 1/2, *f*(8, 9) = 1/3.

It is conjectured that if 0 \< *a*, *b* \< *n* are integers, gcd(*a*, *n*) = gcd(*b*, *n*) = 1, *f*(*a*, *n*) > *f*(*b*, *n*), then $\pi$(*x*; *n*, *b*) > $\pi$(*x*; *n*, *a*) occurs more often than not.
