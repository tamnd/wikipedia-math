# Homological connectivity

::: {#o1 .subject cue=lead name="Homological connectivity"}

In [algebraic topology](wikipedia://en/38801), **homological connectivity** is a property describing a [topological space](wikipedia://en/30450) based on its [homology groups](https://en.wikipedia.org/wiki/Homology_groups).[^o11]

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

### Background {#Background}

*X* is *homologically-connected* if its 0-th homology group equals **Z**, i.e. $H_0(X)\cong \mathbb{Z}$, or equivalently, its 0-th [reduced homology](wikipedia://en/3110036) group is [trivial](wikipedia://en/193059): $\tilde{H_0}(X)\cong 0$.

- For example, when *X* is a graph and its set of [connected components](wikipedia://en/246223) is *C*, $H_0(X)\cong \mathbb{Z}^{|C|}$ and $\tilde{H_0}(X)\cong \mathbb{Z}^{|C|-1}$ (see [graph homology](wikipedia://en/64675441)). Therefore, homological connectivity is equivalent to the graph having a single connected component, which is equivalent to [graph connectivity](https://en.wikipedia.org/wiki/Graph_connectivity). It is similar to the notion of a [connected space](wikipedia://en/6233).

*X* is *homologically 1-connected* if it is homologically connected, and additionally, its 1-th homology group is trivial, i.e. $H_1(X)\cong 0$.[^o11]

- For example, when *X* is a connected graph with vertex-set *V* and edge-set *E*, $H_1(X) \cong \mathbb{Z}^{|E|-|V|+1}$. Therefore, homological 1-connectivity is equivalent to the graph being a [tree](wikipedia://en/48560). Informally, it corresponds to *X* having no "holes" with a 1-dimensional boundary, which is similar to the notion of a [simply connected space](wikipedia://en/523879).

In general, for any integer *k*, *X* is *homologically k-connected* if its reduced homology groups of order 0, 1, ..., *k* are all trivial. Note that the reduced homology group equals the homology group for 1,..., *k* (only the 0-th reduced homology group is different).

### Connectivity {#Connectivity}

The *homological connectivity* of *X*, denoted **conn<sub>H</sub>(X)**, is the largest *k* ≥ 0 for which *X* is homologically *k*-connected. Examples:

- If all reduced homology groups of *X* are trivial, then **conn<sub>H</sub>(X) = infinity**. This holds, for example, for any [ball](wikipedia://en/160556).
- If the 0th group is trivial but the 1th group is not, then **conn<sub>H</sub>(X) = 0**. This holds, for example, for a connected graph with a cycle.
- If all reduced homology groups are non-trivial, then **conn<sub>H</sub>(X) = -1**. This holds for any disconnected space.
- The connectivity of the empty space is, by convention, **conn<sub>H</sub>(X) = -2**.

Some computations become simpler if the connectivity is defined with an offset of 2, that is, $\eta_H(X) := \text{conn}_H(X) + 2$.[^o6] The eta of the empty space is 0, which is its smallest possible value. The eta of any disconnected space is 1.

:::

## Dependence on the field of coefficients {#Dependence_on_the_field_of_coefficients}

The basic definition considers homology groups with integer coefficients. Considering homology groups with other coefficients leads to other definitions of connectivity. For example, *X* is *F<sub>2</sub>-homologically 1-connected* if its 1st homology group with coefficients from F<sub>2</sub> (the cyclic field of size 2) is trivial, i.e.: $H_1(X; \mathbb{F}_2)\cong 0$.

## Homological connectivity in specific spaces {#Homological_connectivity_in_specific_spaces}

For homological connectivity of simplicial complexes, see [simplicial homology](wikipedia://en/1060236). Homological connectivity was calculated for various spaces, including:

- The [independence complex](wikipedia://en/64659151) of a graph;[^o9][^o10]
- A random 2-dimensional [simplicial complex](wikipedia://en/252686);[^o11]
- A random *k*-dimensional simplicial complex;[^o12]
- A random [hypergraph](wikipedia://en/232535);[^o13]
- A random [Čech complex](wikipedia://en/53325526).[^o14]

## Relation with homotopical connectivity {#Relation_with_homotopical_connectivity}

[Hurewicz theorem](wikipedia://en/591587) relates the homological connectivity **$\text{conn}_H(X)$** to the [homotopical connectivity](wikipedia://en/6519310), denoted by **$\text{conn}_{\pi}(X)$**.

For any *X* that is simply-connected, that is, **$\text{conn}_{\pi}(X)\geq 1$**, the connectivities are the same:

$$\text{conn}_H(X) = \text{conn}_{\pi}(X)$$

If *X* is not simply-connected (**$\text{conn}_{\pi}(X)\leq 0$**), then inequality holds:

$$\text{conn}_H(X)\geq \text{conn}_{\pi}(X)$$

but it may be strict. See [Homotopical connectivity](wikipedia://en/6519310#homology).

## See also {#See_also}

**[Meshulam's game](wikipedia://en/65171548)** is a game played on a graph *G*, that can be used to calculate a lower bound on the homological connectivity of the independence complex of *G*.
