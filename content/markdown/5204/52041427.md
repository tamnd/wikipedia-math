# G\*Power

*Image: G\*Power\_screenshot.PNG.* Screenshot

::: {#o1 .subject cue=lead name="G*Power"}

**G\*Power** is a free-to use software used to calculate [statistical power](https://en.wikipedia.org/wiki/Statistical_power). The program offers the ability to calculate power for a wide variety of [statistical tests](https://en.wikipedia.org/wiki/Statistical_tests) including [t-tests](https://en.wikipedia.org/wiki/T-tests), [F-tests](wikipedia://en/318976), and [chi-square-tests](wikipedia://en/226680), among others. Additionally, the user must determine which of the many contexts this test is being used, such as a [one-way ANOVA](https://en.wikipedia.org/wiki/One-way_ANOVA) versus a [multi-way ANOVA](wikipedia://en/682847). In order to calculate power, the user must know four of five variables: either number of groups, number of observations, [effect size](wikipedia://en/437276), [significance level](https://en.wikipedia.org/wiki/Significance_level) (α), or power (1-β). G\*Power has a built-in tool for determining effect size if it cannot be estimated from prior literature or is not easily calculable.

*Image: GPower Analyses Table.jpg.* The table lists all possible analyses that the updated G\*Power 3.1 can perform for various functions. A priori analyses are one of the most commonly used analyses in research and calculate the needed sample size in order to achieve a sufficient power level and requires inputted values for alpha and effect size. Compromise analyses find implied power based on the beta/alpha ratio, or q, and inputted values for effect size and sample size. Criterion analyses calculate the required alpha value based on the inputted power, effect size, and sample size. Post hoc analyses find actual power based on the inputted alpha, sample size, and effect size. Lastly, sensitivity analyses find the needed effect size given the alpha value, power, and sample size.

:::
