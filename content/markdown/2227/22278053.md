# Discontinuities of monotone functions

::: {#o1 .subject cue=lead name="Discontinuities of monotone functions"}

In the [mathematical](wikipedia://en/18831) field of [analysis](wikipedia://en/48396), a well-known theorem describes the set of [discontinuities](https://en.wikipedia.org/wiki/Discontinuity_%28mathematics%29) of a [monotone](wikipedia://en/48260#Monotonicity_in_calculus_and_analysis) [real-valued function](wikipedia://en/22284647) of a real variable; all discontinuities of such a (monotone) function are necessarily [jump discontinuities](https://en.wikipedia.org/wiki/Jump_discontinuity) and there are at most [countably many](wikipedia://en/6026) of them.

:::

Usually, this theorem appears in literature without a name. It is called **Froda's theorem** in some recent works; in his 1929 dissertation, [Alexandru Froda](wikipedia://en/22289393) stated that the result was previously well-known and had provided his own [elementary proof](wikipedia://en/9318685) for the sake of convenience.[^o2] Prior work on discontinuities had already been discussed in the 1875 memoir of the French mathematician [Jean Gaston Darboux](wikipedia://en/1142530).[^o3]

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Denote the [limit from the left](https://en.wikipedia.org/wiki/Limit_from_the_left) by

$$f\left(x^-\right) := \lim_{z \nearrow x} f(z) = \lim_{\stackrel{h \to 0}{h > 0}} f(x-h)$$

and denote the [limit from the right](https://en.wikipedia.org/wiki/Limit_from_the_right) by

$$f\left(x^+\right) := \lim_{z \searrow x} f(z) = \lim_{\stackrel{h \to 0}{h > 0}} f(x+h).$$

If $f\left(x^+\right)$ and $f\left(x^-\right)$ exist and are finite then the difference $f\left(x^+\right) - f\left(x^-\right)$ is called the **jump**[^n1] of $f$ at $x.$

Consider a real-valued function $f$ of real variable $x$ defined in a neighborhood of a point $x.$ If $f$ is discontinuous at the point $x$ then the discontinuity will be a **[removable discontinuity](https://en.wikipedia.org/wiki/Removable_discontinuity)**, or an **[essential discontinuity](https://en.wikipedia.org/wiki/Essential_discontinuity)**, or a **[jump discontinuity](https://en.wikipedia.org/wiki/Jump_discontinuity)** (also called a **discontinuity of the first kind**).[^n2] If the function is continuous at $x$ then the jump at $x$ is zero. Moreover, if $f$ is not continuous at $x,$ the jump can be zero at $x$ if $f\left(x^+\right) = f\left(x^-\right) \neq f(x).$

:::

::: {#o9 .statement cue=heading name="Precise statement"}

## Precise statement {#Precise_statement}

Let $f$ be a real-valued [monotone](wikipedia://en/48260#Monotonicity_in_calculus_and_analysis) function defined on an [interval](wikipedia://en/49172#Notations_for_intervals) $I.$ Then the set of discontinuities of the first kind is [at most countable](wikipedia://en/6026).

One can prove[^n3][^n1] that all points of discontinuity of a monotone real-valued function defined on an interval are jump discontinuities and hence, by our definition, of the first kind. With this remark the theorem takes the stronger form:

Let $f$ be a monotone function defined on an interval $I.$ Then the set of discontinuities is at most countable.

:::

::: {#o13 .proof cue=heading name="Proofs"}

## Proofs {#Proofs}

This proof starts by proving the special case where the function's domain is a closed and bounded interval $[a, b].$[^n4][^n5] The proof of the general case follows from this special case.

::: {#o17 .proof cue=heading name="Proof when the domain is closed and bounded"}

### Proof when the domain is closed and bounded {#Proof_when_the_domain_is_closed_and_bounded}

Two proofs of this special case are given.

::: {#o19 .proof cue=heading name="Proof 1"}

#### Proof 1 {#Proof_1}

Let $I := [a, b]$ be an interval and let $f : I \to \mathbb{R}$ be a non-decreasing function (such as an [increasing](wikipedia://en/48260) function). Then for any $a < x < b,$

$$f(a) ~\leq~ f\left(a^+\right) ~\leq~ f\left(x^-\right) ~\leq~ f\left(x^+\right) ~\leq~ f\left(b^-\right) ~\leq~ f(b).$$

Let $\alpha > 0$ and let $x_1 < x_2 < \cdots < x_n$ be $n$ points inside $I$ at which the jump of $f$ is greater or equal to $\alpha$:

$$f\left(x_i^+\right) - f\left(x_i^-\right) \geq \alpha,\ i=1,2,\ldots,n$$

For any $i=1,2,\ldots,n,$ $f\left(x_i^+\right) \leq f\left(x_{i+1}^-\right)$ so that $f\left(x_{i+1}^-\right) - f\left(x_i^+\right) \geq 0.$ Consequently,

$$\begin{alignedat}{9} f(b) - f(a) &\geq f\left(x_n^+\right) - f\left(x_1^-\right) \\ &= \sum_{i=1}^n \left[f\left(x_i^+\right) - f\left(x_i^-\right)\right] + \sum_{i=1}^{n-1} \left[f\left(x_{i+1}^-\right) - f\left(x_i^+\right)\right] \\ &\geq \sum_{i=1}^n \left[f\left(x_i^+\right) - f\left(x_i^-\right)\right] \\ &\geq n \alpha \end{alignedat}$$

and hence $n \leq \frac{f(b) - f(a)}{\alpha}.$

Since $f(b) - f(a) < \infty$ we have that the number of points at which the jump is greater than $\alpha$ is finite (possibly even zero).

Define the following sets:

$$S_1: = \left\{x : x \in I, f\left(x^+\right) - f\left(x^-\right) \geq 1\right\},$$

$$S_n: = \left\{x : x \in I, \frac{1}{n} \leq f\left(x^+\right) - f\left(x^-\right) < \frac{1}{n-1}\right\},\ n\geq 2.$$

Each set $S_n$ is finite or the [empty set](wikipedia://en/9566). The union $S = \bigcup_{n=1}^\infty S_n$ contains all points at which the jump is positive and hence contains all points of discontinuity. Since every $S_i,\ i=1,2,\ldots$ is at most countable, their union $S$ is also at most countable.

If $f$ is non-increasing (or [decreasing](wikipedia://en/48260)) then the proof is similar. This completes the proof of the special case where the function's domain is a closed and bounded interval. $\blacksquare$

:::

::: {#o21 .proof cue=heading name="Proof 2"}

#### Proof 2 {#Proof_2}

For a monotone function $f$, let $f\nearrow$ mean that $f$ is monotonically non-decreasing and let $f\searrow$ mean that $f$ is monotonically non-increasing. Let $f : [a, b] \to \mathbb{R}$ is a monotone function and let $D$ denote the set of all points $d \in [a, b]$ in the domain of $f$ at which $f$ is discontinuous (which is necessarily a jump discontinuity).

Because $f$ has a jump discontinuity at $d \in D,$ $f\left(d^-\right) \neq f\left(d^+\right)$ so there exists some [rational number](wikipedia://en/19727024) $y_d \in \mathbb{Q}$ that lies strictly in between $f\left(d^-\right) \text{ and } f\left(d^+\right)$ (specifically, if $f \nearrow$ then pick $y_d \in \mathbb{Q}$ so that $f\left(d^-\right) < y_d < f\left(d^+\right)$ while if $f \searrow$ then pick $y_d \in \mathbb{Q}$ so that $f\left(d^-\right) > y_d > f\left(d^+\right)$ holds).

It will now be shown that if $d, e \in D$ are distinct, say with $d < e,$ then $y_d \neq y_e.$ If $f \nearrow$ then $d < e$ implies $f\left(d^+\right) \leq f\left(e^-\right)$ so that $y_d < f\left(d^+\right) \leq f\left(e^-\right) < y_e.$ If on the other hand $f \searrow$ then $d < e$ implies $f\left(d^+\right) \geq f\left(e^-\right)$ so that $y_d > f\left(d^+\right) \geq f\left(e^-\right) > y_e.$ Either way, $y_d \neq y_e.$

Thus every $d \in D$ is associated with a unique rational number (said differently, the map $D \to \mathbb{Q}$ defined by $d \mapsto y_d$ is [injective](wikipedia://en/45196)). Since $\mathbb{Q}$ is countable, the same must be true of $D.$ $\blacksquare$

:::

:::

::: {#o23 .proof cue=heading name="Proof of general case"}

### Proof of general case {#Proof_of_general_case}

Suppose that the domain of $f$ (a monotone real-valued function) is equal to a union of countably many closed and bounded intervals; say its domain is $\bigcup_{n} \left[a_n, b_n\right]$ (no requirements are placed on these closed and bounded intervals). It follows from the special case proved above that for every index $n,$ the [restriction](https://en.wikipedia.org/wiki/Restriction_of_a_map) $f\big\vert_{\left[a_n, b_n\right]} : \left[a_n, b_n\right] \to \mathbb{R}$ of $f$ to the interval $\left[a_n, b_n\right]$ has at most countably many discontinuities; denote this (countable) set of discontinuities by $D_n.$ If $f$ has a discontinuity at a point $x_0 \in \bigcup_{n} \left[a_n, b_n\right]$ in its domain then either $x_0$ is equal to an endpoint of one of these intervals (that is, $x_0 \in \left\{a_1, b_1, a_2, b_2, \ldots\right\}$) or else there exists some index $n$ such that $a_n < x_0 < b_n,$ in which case $x_0$ must be a point of discontinuity for $f\big\vert_{\left[a_n, b_n\right]}$ (that is, $x_0 \in D_n$). Thus the set $D$ of all points of at which $f$ is discontinuous is a subset of $\left\{a_1, b_1, a_2, b_2, \ldots\right\} \cup \bigcup_{n} D_n,$ which is a countable set (because it is a union of countably many countable sets) so that its subset $D$ must also be countable (because every subset of a countable set is countable).

In particular, because every interval (including open intervals and half open/closed intervals) of real numbers can be written as a countable union of closed and bounded intervals, it follows that any monotone real-valued function defined on an interval has at most countable many discontinuities.

To make this argument more concrete, suppose that the domain of $f$ is an interval $I$ that is not [closed](wikipedia://en/47279) and [bounded](wikipedia://en/48258) (and hence by [Heine–Borel theorem](wikipedia://en/59595) not [compact](https://en.wikipedia.org/wiki/Compact_set)). Then the interval can be written as a countable union of closed and bounded intervals $I_n$ with the property that any two consecutive intervals have an [endpoint](wikipedia://en/49172#Notations_for_intervals) in common: $I = \cup_{n=1}^\infty I_n.$ If $I = (a,b] \text{ with } a \geq -\infty$ then $I_1 = \left[\alpha_1, b\right],\ I_2 = \left[\alpha_2, \alpha_1\right], \ldots, I_n = \left[\alpha_n, \alpha_{n-1}\right], \ldots$ where $\left(\alpha_n\right)_{n=1}^{\infty}$ is a strictly decreasing [sequence](wikipedia://en/27838) such that $\alpha_n \rightarrow a.$ In a similar way if $I = [a,b), \text{ with } b \leq +\infty$ or if $I = (a,b) \text{ with } -\infty \leq a < b \leq \infty.$ In any interval $I_n,$ there are at most countable many points of discontinuity, and since a countable union of at most countable sets is at most countable, it follows that the set of all discontinuities is at most countable. $\blacksquare$

:::

## Jump functions {#Jump_functions}

**Examples.** Let $x$<sub>1</sub> \< $x$<sub>2</sub> \< $x$<sub>3</sub> \< ⋅⋅⋅ be a countable subset of the compact interval \[$a$,$b$\] and let μ<sub>1</sub>, μ<sub>2</sub>, μ<sub>3</sub>, ... be a positive sequence with finite sum. Set

$$f(x) = \sum_{n=1}^{\infty} \mu_n \chi_{[x_n,b]} (x)$$

where χ<sub>*A*</sub> denotes the [characteristic function](wikipedia://en/240790) of a compact interval $A$. Then $f$ is a non-decreasing function on \[$a$,$b$\], which is continuous except for jump discontinuities at $x$<sub>$n$</sub> for $n$ ≥ 1. In the case of finitely many jump discontinuities, $f$ is a **[step function](wikipedia://en/170939)**. The examples above are generalised step functions; they are very special cases of what are called jump functions or saltus-functions.[^n6][^n7]

More generally, the analysis of monotone functions has been studied by many mathematicians, starting from Abel, Jordan and Darboux. Following (Riesz Sz.-Nagy 1990), replacing a function by its negative if necessary, only the case of non-negative non-decreasing functions has to be considered. The domain \[$a$,$b$\] can be finite or have ∞ or −∞ as endpoints.

The main task is to construct monotone functions — generalising step functions — with discontinuities at a given denumerable set of points and with prescribed left and right discontinuities at each of these points. Let $x_{n}$ ($n$ ≥ 1) lie in ($a$, $b$) and take λ<sub>1</sub>, λ<sub>2</sub>, λ<sub>3</sub>, ... and μ<sub>1</sub>, μ<sub>2</sub>, μ<sub>3</sub>, ... non-negative with finite sum and with λ<sub>$n$</sub> + μ<sub>$n$</sub> > 0 for each $n$. Define

$f_n(x)=0\,\,$ for $\,\, x < x_n,\,\, f_n(x_n) = \lambda_n, \,\, f_n(x) = \lambda_n +\mu_n\,\,$ for $\,\, x > x_n.$

Then the **jump function**, or **saltus-function**, defined by

$$f(x)=\,\,\sum_{n=1}^\infty f_n(x) =\,\, \sum_{x_n\le x} \lambda_n + \sum_{x_n<x} \mu_n,$$

is non-decreasing on \[$a$, $b$\] and is continuous except for [jump discontinuities](https://en.wikipedia.org/wiki/Jump_discontinuity) at $x_{n}$ for $n$ ≥ 1.[^o43][^n8][^n9][^n10]

To prove this, note that sup |$f$<sub>$n$</sub>| = λ<sub>$n$</sub> + μ<sub>$n$</sub>, so that Σ $f$<sub>$n$</sub> converges uniformly to $f$. Passing to the limit, it follows that

$f(x_n)-f(x_n-0)=\lambda_n,\,\,\, f(x_n+0)-f(x_n)=\mu_n,\,\,\,$ and $\,\, f(x\pm 0)=f(x)$

if $x$ is not one of the $x$<sub>$n$</sub>'s.[^o43]

Conversely, by a differentiation theorem of [Lebesgue](wikipedia://en/49514), the jump function $f$ is uniquely determined by the properties:[^o31] (1) being non-decreasing and non-positive; (2) having given jump data at its points of discontinuity $x$<sub>$n$</sub>; (3) satisfying the boundary condition $f$($a$) = 0; and (4) having zero derivative [almost everywhere](wikipedia://en/21520).

::: {#o32 .proof cue=collapse name="Proof that a jump function has zero derivative almost everywhere."}

Property (4) can be checked following (Riesz Sz.-Nagy 1990), (Rubel 1963) and (Komornik 2016). Without loss of generality, it can be assumed that $f$ is a non-negative jump function defined on the compact \[$a$,$b$\], with discontinuities only in ($a$,$b$).

Note that an open set $U$ of ($a$,$b$) is canonically the disjoint union of at most countably many open intervals $I$<sub>$m$</sub>; that allows the total length to be computed ℓ($U$)= Σ ℓ($I$<sub>$m$</sub>). Recall that a null set $A$ is a subset such that, for any arbitrarily small ε' > 0, there is an open $U$ containing $A$ with ℓ($U$) \< ε'. A crucial property of length is that, if $U$ and $V$ are open in ($a$,$b$), then ℓ($U$) + ℓ($V$) = ℓ($U$ ∪ $V$) + ℓ($U$ ∩ $V$).[^n11] It implies immediately that the union of two null sets is null; and that a finite or countable set is null.[^o37][^o38]

::: {#o39 .statement kind=statement/proposition cue=inline-head name="Proposition 1"}

**Proposition 1.** For $c$ > 0 and a normalised non-negative jump function $f$, let $U$<sub>$c$</sub>($f$) be the set of points $x$ such that

$${f(t)-f(s)\over t -s} > c$$

for some $s$, $t$ with $s$ \< $x$ \< $t$. Then $U$<sub>$c$</sub>($f$) is open and has total length ℓ($U$<sub>$c$</sub>($f$)) ≤ 4 $c$<sup>−1</sup> ($f$($b$) – $f$($a$)).

Note that $U$<sub>$c$</sub>($f$) consists the points $x$ where the slope of $h$ is greater that $c$ near $x$. By definition $U$<sub>$c$</sub>($f$) is an open subset of ($a$, $b$), so can be written as a disjoint union of at most countably many open intervals $I$<sub>$k$</sub> = ($a$<sub>$k$</sub>, $b$<sub>$k$</sub>). Let $J$<sub>$k$</sub> be an interval with closure in $I$<sub>$k$</sub> and ℓ($J$<sub>$k$</sub>) = ℓ($I$<sub>$k$</sub>)/2. By compactness, there are finitely many open intervals of the form ($s$,$t$) covering the closure of $J$<sub>$k$</sub>. On the other hand, it is elementary that, if three fixed bounded open intervals have a common point of intersection, then their union contains one of the three intervals: indeed just take the supremum and infimum points to identify the endpoints. As a result, the finite cover can be taken as adjacent open intervals ($s$<sub>$k,1$</sub>,$t$<sub>$k,1$</sub>), ($s$<sub>$k,2$</sub>,$t$<sub>$k,2$</sub>), ... only intersecting at consecutive intervals.[^o40] Hence

$$\ell(J_k) \le \sum_m (t_{k,m} - s_{k,m}) \le \sum_m c^{-1}(f(t_{k,m})-f(s_{k,m})) \le 2 c^{-1}(f(b_k)-f(a_k)).$$

Finally sum both sides over $k$.[^o37][^o38]

:::

::: {#o41 .statement kind=statement/proposition cue=inline-head name="Proposition 2"}

**Proposition 2.** If $f$ is a jump function, then $f$ '($x$) = 0 almost everywhere.

To prove this, define

$$Df(x)= \limsup_{s,t\rightarrow x,\,\, s<x< t} {f(t)-f(s)\over t-s},$$

a variant of the [Dini derivative](wikipedia://en/2163404) of $f$. It will suffice to prove that for any fixed $c$ > 0, the Dini derivative satisfies $D$$f$($x$) ≤ $c$ [almost everywhere](wikipedia://en/44688), i.e. on a [null set](wikipedia://en/21520).

Choose ε > 0, arbitrarily small. Starting from the definition of the jump function $f$ = Σ $f$<sub>$n$</sub>, write $f$ = $g$ + $h$ with $g$ = Σ<sub>$n$≤$N$</sub> $f$<sub>$n$</sub> and $h$ = Σ<sub>$n$>$N$</sub> $f$<sub>$n$</sub> where $N$ ≥ 1. Thus $g$ is a step function having only finitely many discontinuities at $x$<sub>$n$</sub> for $n$ ≤ $N$ and $h$ is a non-negative jump function. It follows that $D$$f$ = $g$' +$D$$h$ = $D$$h$ except at the $N$ points of discontinuity of $g$. Choosing $N$ sufficiently large so that Σ<sub>$n$>$N$</sub> λ<sub>$n$</sub> + μ<sub>$n$</sub> \< ε, it follows that $h$ is a jump function such that $h$($b$) − $h$($a$) \< ε and $\operatorname{Dh}$ ≤ $c$ off an open set with length less than 4ε/$c$.

By construction $\operatorname{Df}$ ≤ $c$ off an open set with length less than 4ε/$c$. Now set ε' = 4ε/$c$ — then ε' and $c$ are arbitrarily small and $\operatorname{Df}$ ≤ $c$ off an open set of length less than ε'. Thus $\operatorname{Df}$ ≤ $c$ almost everywhere. Since $c$ could be taken arbitrarily small, $\operatorname{Df}$ and hence also $f$ ' must vanish almost everywhere.[^o37][^o38]

As explained in (Riesz Sz.-Nagy 1990), every non-decreasing non-negative function $F$ can be decomposed uniquely as a sum of a jump function $f$ and a continuous monotone function $g$: the jump function $f$ is constructed by using the jump data of the original monotone function $F$ and it is easy to check that $g$ = $F$ − $f$ is continuous and monotone.[^o43]

:::
