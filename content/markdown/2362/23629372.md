# Lemke's algorithm

::: {#o1 .subject cue=lead name="Lemke's algorithm"}

In [mathematical optimization](wikipedia://en/52033), **Lemke's algorithm** is a [procedure](wikipedia://en/775) for solving [linear complementarity problems](wikipedia://en/1470767), and more generally [mixed linear complementarity problems](wikipedia://en/23629444). It is named after [Carlton E. Lemke](wikipedia://en/48695353).

:::

Lemke's algorithm is of [pivoting](wikipedia://en/9811503) or [basis](wikipedia://en/244321)-[exchange](https://en.wikipedia.org/wiki/Exchange_algorithm) type. Similar algorithms can compute [Nash equilibria](wikipedia://en/45337#Nash_equilibria_in_a_payoff_matrix) for [two-person matrix and bimatrix games](wikipedia://en/1863612).
