# Exact algorithm

::: {#o1 .subject cue=lead name="Exact algorithm"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science) and [operations research](wikipedia://en/43476), **exact algorithms** are [algorithms](wikipedia://en/775) that always solve an optimization problem to optimality.

:::

Unless [P = NP](https://en.wikipedia.org/wiki/P_=_NP), an exact algorithm for an [NP-hard](wikipedia://en/54681) optimization problem cannot run in worst-case [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time). There has been extensive research on finding exact algorithms whose running time is exponential with a low base.[^o2] [^o3]
