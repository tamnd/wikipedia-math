# Strong measure zero set

::: {#o1 .subject cue=lead name="Strong measure zero set"}

In [mathematical analysis](wikipedia://en/48396), a **strong measure zero set**[^o3] is a subset *A* of the [real line](https://en.wikipedia.org/wiki/Real_line) with the following property:

:::

for every sequence (ε<sub>*n*</sub>) of positive reals there exists a sequence (*I<sub>n</sub>*) of [intervals](wikipedia://en/49172) such that |*I*<sub>*n*</sub>| \< ε<sub>*n*</sub> for all *n* and *A* is contained in the union of the *I*<sub>*n*</sub>.

(Here |*I*<sub>*n*</sub>| denotes the length of the interval *I*<sub>*n*</sub>.)

Every [countable set](wikipedia://en/6026) is a strong measure zero set, and so is every union of countably many strong measure zero sets. Every strong measure zero set has [Lebesgue measure](wikipedia://en/18198) 0. The [Cantor set](wikipedia://en/6172) is an example of an uncountable set of Lebesgue measure 0 which is not of strong measure zero.[^o2]

**[Borel's](wikipedia://en/356161) conjecture**[^o3] states that every strong measure zero set is countable. It is now known that this statement is [independent](wikipedia://en/1141208) of [ZFC](https://en.wikipedia.org/wiki/ZFC) (the Zermelo–Fraenkel axioms of set theory, which is the standard axiom system assumed in mathematics). This means that Borel's conjecture can neither be proven nor disproven in ZFC (assuming ZFC is [consistent](https://en.wikipedia.org/wiki/Consistent)). [Sierpiński](wikipedia://en/34122) proved in 1928 that the [continuum hypothesis](wikipedia://en/5705) (which is now also known to be independent of ZFC) implies the existence of uncountable strong measure zero sets.[^o4] In 1976 [Laver](wikipedia://en/22280145) used a method of [forcing](https://en.wikipedia.org/wiki/Forcing_%28set_theory%29) to construct a model of ZFC in which Borel's conjecture holds.[^o5] These two results together establish the independence of Borel's conjecture.

The following characterization of strong measure zero sets was proved in 1973:

A set *A* ⊆ **R** has strong measure zero if and only if *A* + *M* ≠ **R** for every [meagre set](wikipedia://en/226975) *M* ⊆ **R**.[^o6]

This result establishes a connection to the notion of **strongly meagre set**, defined as follows:

A set *M* ⊆ **R** is strongly meagre if and only if *A* + *M* ≠ **R** for every set *A* ⊆ **R** of Lebesgue measure zero.

The **dual Borel conjecture** states that every strongly meagre set is countable. This statement is also independent of ZFC.[^o7]
