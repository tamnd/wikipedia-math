# Strong set order

::: {#o1 .subject cue=lead name="Strong set order"}

In [order theory](wikipedia://en/361924), the **strong set order** $\leq_s$ is a [partial order](https://en.wikipedia.org/wiki/Partial_order) over the subsets of a [lattice](https://en.wikipedia.org/wiki/Lattice). It is widely used to study [monotone comparative statics](wikipedia://en/42583036) of [parametrized optimization problems](wikipedia://en/45302060) in [economic theory](https://en.wikipedia.org/wiki/Economic_theory) and [operations research](wikipedia://en/43476).[^o2]

:::

The strong set order was first defined and used by [Arthur F. Veinott](wikipedia://en/82736707) in his unpublished lecture notes.[^o3][^o4][^o5] It was later popularized by [Donald M. Topkis](https://en.wikipedia.org/wiki/Donald_M._Topkis), [Paul Milgrom](https://en.wikipedia.org/wiki/Paul_Milgrom) and [Chris Shannon](https://en.wikipedia.org/wiki/Chris_Shannon) via their work on [monotone comparative statics](wikipedia://en/42583036), in particular through [Topkis' Theorem](https://en.wikipedia.org/wiki/Topkis's_Theorem).

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a [lattice](wikipedia://en/469304) $(X, \leq)$, consider its [power set](wikipedia://en/23799) $\mathcal P(X)$. The **strong set order** $\leq_s$ is a [partial order](https://en.wikipedia.org/wiki/Partial_order) on $\mathcal P(X)$ given by:

$$A \leq_s B \iff \left\{ \begin{array}{ll} a \vee b \in B \\[0.1em] a \wedge b \in A \end{array} \ \ \ \ \ \forall a \in A, b \in B, \right.$$

where $a \vee b$ and $a \wedge b$ are respectively the [join and meet](wikipedia://en/3956618) of $a, b$.

:::

## Examples and non-examples {#Examples_and_non-examples}

### Real numbers {#Real_numbers}

Consider the real numbers $\mathbb R$ with the usual order $\geq$. Let $A = [\underline a, \overline a]$ and $B = [\underline b, \overline b]$. Then

$$A \leq_s B \iff \underline a \leq \underline b \ \text{ and } \ \overline a \leq \overline b.$$

More generally, for any $A, B \subseteq \mathbb R$, we have

$$A \leq_s B \iff \inf A \leq \inf B \ \text{ and } \ \sup A \leq \sup B.$$

### Euclidean space {#Euclidean_space}

Consider the [Euclidean space](wikipedia://en/9697) $\mathbb R^n$ with the usual pointwise order: $\mathbf x \leq \mathbf y \iff x_i \leq y_i \ \ \forall i \leq n$. For $n = 2$, let

$$A = [0,2] \times [0, 3],$$

$$B = [1,3] \times [1, 4].$$

Then :$A \leq_s B$. But now consider

$$B' = [-1, 3] \times [1,4];$$

Then $A \nleq_s B'$, since $(0, 0) \in A$, $(-1, 1) \in B'$ but

$$(0, 0) \wedge (-1, 1) = (-1, 0) \notin B'.$$

### Power set {#Power_set}

Consider the [power set](wikipedia://en/23799) of the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $\mathcal P(\mathbb N)$ under the [set-inclusion order](wikipedia://en/11728075): $A \leq B \iff A \subseteq B$. Let

$$A = \{\{1\}\},$$

$$B = \{\{1\}, \{2\}, \{1,2,3\}\}.$$

It it *not true* that $A \leq_s B$. Indeed, we have $\{1\} \in A$, $\{2\} \in B$, but

$$\{1\} \wedge \{2\} = \{1\} \cap \{2\} = \varnothing \notin A,$$

whence $A \nleq_s B$.

## Applications {#Applications}

::: {#o15 .statement kind=statement/theorem cue=named-heading name="Topkis' Theorem"}

### Topkis' Theorem {#Topkis'_Theorem}

The strong set order is widely used in [monotone comparative statics](wikipedia://en/42583036), in particular via [Topkis' Theorem](https://en.wikipedia.org/wiki/Topkis's_Theorem). Given a lattice $X$, a [poset](https://en.wikipedia.org/wiki/Poset) $\Theta$, a [constraint](wikipedia://en/4171950) [correspondence](wikipedia://en/12506030) $D : \Theta \rightrightarrows X$ and a function $f : X \times \Theta \to \mathbb R$, the theorem gives sufficient conditions for the correspondence

$$x^*(\theta) = \arg\max_{x \in D(\theta)} f(x, \theta)$$

the be increasing in the strong set order, that is, for the statement

$$\theta \geq \theta' \implies x^*(\theta) \geq_s x^*(\theta')$$

to hold.

:::

### Monotone selections {#Monotone_selections}

Increasigness in the strong set order can be used to obtain monotone [selections](wikipedia://en/1432664) from [correspondences](wikipedia://en/12506030). Indeed, if $X$ is a [poset](https://en.wikipedia.org/wiki/Poset) and $Y$ is a lattice, the correspondence $\Gamma : X \rightrightarrows Y$ is nonempty-valued and increasing in the strong set order, then a monotone selection $g$ from $\Gamma$ exists if any of the following hold:

- $\Gamma(x) \subseteq Y$ has a minimal element for every $x \in X$ (in particular, if $\Gamma$ is [complete-lattice](wikipedia://en/44777)-valued). One can thus take :$g : X \to Y$ by putting $g(x) = \min \Gamma(x)$. The same works if a maximal element is available.
- $Y$ is a [sublattice](wikipedia://en/469304#Sublattices) of a finite [product](wikipedia://en/24104095) of [chains](wikipedia://en/30330#Chains).[^o17] This covers, for example, $Y \subseteq \mathbb R^n$.
- $X$ is countable.[^o17]

::: {#o19 .statement kind=statement/theorem cue=named-heading name="Zhou's Fixed-Point Theorem for correspondences"}

### Zhou's Fixed-Point Theorem for correspondences {#Zhou's_Fixed-Point_Theorem_for_correspondences}

The strong set order can also be used for a generalization of [Tarski's fixed-point theorem](wikipedia://en/181417) to [correspondences](wikipedia://en/12506030) known as Zhou's fixed-point theorem:[^o20][^o21]

::: {#o22 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** let $X$ be a nonempty [complete lattice](wikipedia://en/44777) and $\Gamma : X \rightrightarrows X$ a nonempty-valued correspondence. If $\Gamma$ is increasing in the strong set order and $\Gamma(x)$ is a [subcomplete sublattice](wikipedia://en/44777#Complete_sublattices) for all $x \in X$, then $\Gamma$ has a fixed point. Moreover, the set $\text{Fix}(\Gamma)$ of such fixed points is a complete lattice.

:::

## Weak set order {#Weak_set_order}

The strong set order if often too restrictive for some applications, in particular because it assumes that the underlying space $X$ is a lattice.[^o24] A useful weaker ordering which can be used on the subsets of any [poset](https://en.wikipedia.org/wiki/Poset) $X$ is the weak set order $\leq_w$, defined by:[^o2]

$$A \leq_w B \iff \left\{ \begin{array}{ll} \forall a \in A \ \ \exists b \in B \ \text{ such that } a \leq b, \text{ and } \\[0.1em] \forall b \in B \ \ \exists a \in A \ \text{ such that } b \geq a. \end{array} \right.$$

This order can moreover be broken down into two weaker orders: the upper and lower weak set orders $\leq_{uw}, \leq_{lw}$, respectively defined by:

$$A \leq_{uw} B \iff \forall a \in A \ \ \exists b \in B \ \text{ such that } a \leq b,$$

$$A \leq_{lw} B \iff \forall b \in B \ \ \exists a \in A \ \text{ such that } b \leq a.$$

Clearly $A \leq_w B \iff A \leq_{uw} B \text{ and } A \leq_{lw} B$.
