# Cryptography standards

::: {#o1 .subject cue=lead name="Cryptography standards"}

There are a number of **[standards](https://en.wikipedia.org/wiki/Standardization) related to [cryptography](wikipedia://en/18934432)**. Standard algorithms and protocols provide a focus for study; standards for popular applications attract a large amount of [cryptanalysis](wikipedia://en/5715).

:::

## Encryption standards {#Encryption_standards}

- [Data Encryption Standard](wikipedia://en/7978) (DES, now obsolete)
- [Advanced Encryption Standard](wikipedia://en/1260) (AES)
- [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) the original public key algorithm
- [OpenPGP](https://en.wikipedia.org/wiki/OpenPGP)

## Hash standards {#Hash_standards}

- [MD5](wikipedia://en/18826) 128-bit (obsolete)
- [SHA-1](wikipedia://en/26672) 160-bit (obsolete)
- [SHA-2](wikipedia://en/1638777) available in 224, 256, 384, and 512-bit variants
- [HMAC](wikipedia://en/17112) keyed hash
- PBKDF2 [Key derivation function](wikipedia://en/449781) (RFC 2898)

## Digital signature standards {#Digital_signature_standards}

- Digital Signature Standard (DSS), based on the [Digital Signature Algorithm](wikipedia://en/59470) (DSA)
- [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29)
- [Elliptic Curve DSA](https://en.wikipedia.org/wiki/Elliptic_Curve_DSA)

## Public-key infrastructure (PKI) standards {#Public-key_infrastructure_(PKI)_standards}

- [X.509](https://en.wikipedia.org/wiki/X.509) Public Key Certificates

## Wireless Standards {#Wireless_Standards}

- [Wired Equivalent Privacy](wikipedia://en/422014) (WEP), severely flawed and superseded by WPA
- [Wi-Fi Protected Access](wikipedia://en/422017) (WPA) better than WEP, a 'pre-standard' partial version of 802.11i
- [802.11i](https://en.wikipedia.org/wiki/802.11i) a.k.a. WPA2, uses [AES](wikipedia://en/1260) and other improvements on WEP
- [A5/1](wikipedia://en/294149) and [A5/2](wikipedia://en/543816) cell phone encryption for [GSM](https://en.wikipedia.org/wiki/GSM)

## U.S. Government Federal Information Processing Standards (FIPS) {#U.S._Government_Federal_Information_Processing_Standards_(FIPS)}

- FIPS PUB 31 Guidelines for Automatic Data Processing Physical Security and Risk Management 1974
- FIPS PUB 46-3 Data Encryption Standard ([DES](wikipedia://en/7978)) 1999
- FIPS PUB 73 Guidelines for Security of Computer Applications 1980
- FIPS PUB 74 Guidelines for Implementing and Using the [NBS](https://en.wikipedia.org/wiki/National_Institute_of_Standards_and_Technology) [Data Encryption Standard](wikipedia://en/7978) 1981
- FIPS PUB 81 [DES](wikipedia://en/7978) Modes of Operation 1980
- FIPS PUB 102 Guideline for Computer Security Certification and Accreditation 1983
- FIPS PUB 112 Password Usage 1985, defines 10 factors to be considered in access control systems that are based on passwords
- FIPS PUB 113 Computer Data Authentication 1985, specifies a Data Authentication Algorithm (DAA) based on [DES](wikipedia://en/7978), adopted by the [Department of Treasury](https://en.wikipedia.org/wiki/U.S._Treasury_Department) and the banking community to protect electronic fund transfers.
- FIPS PUB 140-2 Security Requirements for Cryptographic Modules 2001, defines four increasing security levels
- FIPS PUB 171 Key Management Using [ANSI](https://en.wikipedia.org/wiki/American_National_Standards_Institute) X9.17 (ANSI X9.17-1985) 1992, based on [DES](wikipedia://en/7978)
- FIPS PUB 180-2 Secure Hash Standard (SHS) 2002 defines the [SHA](https://en.wikipedia.org/wiki/Secure_Hash_Algorithm_%28disambiguation%29) family
- FIPS PUB 181 Automated Password Generator (APG) 1993
- FIPS PUB 185 Escrowed Encryption Standard (EES) 1994, a [key escrow](wikipedia://en/17114) system that provides for decryption of telecommunications when lawfully authorized.
- FIPS PUB 186-2 Digital Signature Standard ([DSS](wikipedia://en/59470)) 2000
- FIPS PUB 190 Guideline for the Use of Advanced [Authentication](wikipedia://en/47967) Technology Alternatives 1994
- FIPS PUB 191 Guideline for the Analysis of [local area network](https://en.wikipedia.org/wiki/Local_area_network) Security 1994
- FIPS PUB 196 Entity [Authentication](wikipedia://en/47967) Using [Public Key Cryptography](https://en.wikipedia.org/wiki/Public_key_cryptography) 1997
- FIPS PUB 197 Advanced Encryption Standard ([AES](wikipedia://en/1260)) 2001
- FIPS PUB 198 The Keyed-Hash Message Authentication Code ([HMAC](wikipedia://en/17112)) 2002

## Internet Requests for Comments (RFCs) {#Internet_Requests_for_Comments_(RFCs)}

Below is a non-exhaustive overview of notable cryptography-related RFCs, grouped by topic.

**Transport Security**

- 8446 The Transport Layer Security (TLS) Protocol Version 1.3 Defines secure web communication (HTTPS), introduces modern cipher suites and removes legacy cryptography.8446
- 5246 The Transport Layer Security Protocol Version 1.2 Predecessor to TLS 1.3, still widely implemented.5246

**Public-Key Cryptography and Signatures**

- 8017 RSA Cryptography Specifications Defines RSA encryption and signature schemes such as RSA-OAEP and RSASSA-PSS.8017
- 6979 Specifies deterministic generation of the nonce in DSA/ECDSA to avoid catastrophic randomness failures.6979
- 7748 Defines modern elliptic curves X25519 and X448 for Diffie–Hellman key exchange.7748

**Symmetric Cryptography and MACs**

- 2104 Defines the HMAC construction, widely used with hash functions such as SHA-256.2104
- 5869 A widely used key derivation function used in protocols like TLS 1.3.5869
- 8439 Defines the ChaCha20 stream cipher and Poly1305 MAC AEAD construction used in TLS, SSH, and QUIC.8439

**Public-Key Infrastructure and Certificates**

- 5280 Defines the Internet profile for X.509 certificates, used by TLS certificate authorities.5280
- 6960 Defines a protocol for checking certificate revocation status.6960

**Secure Messaging and Data Formats**

- 5652 Defines the message format used for secure email (S/MIME).5652
- 4880 Specifies the OpenPGP encryption and signature format used in tools like GnuPG.4880

**Network Security (IPsec)**

- 4301 Defines the overall IPsec security architecture.4301
- 4303 Specifies encrypted IP packets for IPsec.4303
- 7296 Defines key exchange and authentication for IPsec VPNs.7296

- [EKMS](https://en.wikipedia.org/wiki/EKMS) [NSA](https://en.wikipedia.org/wiki/NSA)'s Electronic Key Management System

- [STU-III](https://en.wikipedia.org/wiki/STU-III) older secure telephone
- [TEMPEST](https://en.wikipedia.org/wiki/Tempest_%28codename%29) prevents compromising emanations
