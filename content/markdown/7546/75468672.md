# Quasi-polynomial growth

::: {#o1 .subject cue=lead name="Quasi-polynomial growth"}

In [theoretical computer science](wikipedia://en/323392), a [function](wikipedia://en/185427) $f(n)$ is said to exhibit **quasi-polynomial growth** when it has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) of the form

$$f(n)=2^{O\bigl((\log n)^c\bigr)}$$

for some constant $c$, as expressed using [big O notation](wikipedia://en/44578). That is, it is bounded by an [exponential function](wikipedia://en/9678) of a [polylogarithmic function](wikipedia://en/445957). This generalizes the [polynomials](wikipedia://en/23000) and the functions of polynomial growth, for which one can take $c=1$. A function with quasi-polynomial growth is also said to be **quasi-polynomially bounded**.

:::

Quasi-polynomial growth has been used in the [analysis of algorithms](wikipedia://en/2230) to describe certain algorithms whose [computational complexity](wikipedia://en/6511) is not polynomial, but is substantially smaller than [exponential](wikipedia://en/191933). In particular, algorithms whose [worst-case running times](https://en.wikipedia.org/wiki/Worst-case_analysis) exhibit quasi-polynomial growth are said to take [quasi-polynomial time](wikipedia://en/25269049). As well as [time complexity](wikipedia://en/405944), some algorithms require quasi-polynomial [space complexity](wikipedia://en/338946), use a quasi-polynomial number of parallel processors, can be expressed as algebraic formulas of quasi-polynomial size or have a quasi-polynomial [competitive ratio](https://en.wikipedia.org/wiki/Competitive_ratio). In some other cases, quasi-polynomial growth is used to model restrictions on the inputs to a problem that, when present, lead to good performance from algorithms on those inputs. It can also bound the size of the output for some problems; for instance, for the [shortest path problem](wikipedia://en/41985) with linearly varying edge weights, the number of distinct solutions can be quasipolynomial.

Beyond theoretical computer science, quasi-polynomial growth bounds have also been used in mathematics, for instance in partial results on the [Hirsch conjecture](wikipedia://en/10412371) for the diameter of polytopes in [polyhedral combinatorics](wikipedia://en/19696519), or relating the sizes of [cliques](wikipedia://en/524466) and [independent sets](wikipedia://en/524501) in certain classes of graphs. However, in polyhedral combinatorics and [enumerative combinatorics](wikipedia://en/3925533), a different meaning of the same word also is used, for the [quasi-polynomials](wikipedia://en/10609701), functions that generalize polynomials by having periodic coefficients.
