# Countably generated module

::: {#o1 .subject cue=lead name="Countably generated module"}

In [mathematics](wikipedia://en/18831), a [module](wikipedia://en/276410) over a (not necessarily [commutative](wikipedia://en/61346)) [ring](wikipedia://en/48404) is **countably generated** if it is [generated](wikipedia://en/50718738) as a module by a [countable](https://en.wikipedia.org/wiki/Countable) subset. The importance of the notion comes from [Kaplansky's theorem](wikipedia://en/62610482) (Kaplansky 1958), which states that a [projective module](wikipedia://en/364488) is a [direct sum](wikipedia://en/58899) of countably generated modules.

:::

More generally, a module over a possibly [non-commutative](https://en.wikipedia.org/wiki/Non-commutative_ring) ring is projective [if and only if](wikipedia://en/14922) (i) it is [flat](wikipedia://en/492616), (ii) it is a direct sum of countably generated modules and (iii) it is a [Mittag-Leffler module](https://en.wikipedia.org/wiki/Mittag-Leffler_module). (Bazzoni–Stovicek)
