# UTM theorem

::: {#o1 .subject cue=lead name="UTM theorem"}

In [computability theory](wikipedia://en/155414), the **UTM theorem**, or **[universal Turing machine](wikipedia://en/71435) theorem**, is a basic result about [Gödel numberings](wikipedia://en/207790) of the set of [computable functions](wikipedia://en/1139338). It affirms the existence of a computable **universal function**, which is capable of calculating any other computable function.[^n1] The universal function is an abstract version of the [universal Turing machine](wikipedia://en/71435), thus the name of the theorem.

:::

[Roger's equivalence theorem](https://en.wikipedia.org/wiki/Roger's_equivalence_theorem) provides a characterization of the Gödel numbering of the computable functions in terms of the [*s<sub>mn</sub>* theorem](wikipedia://en/2330936) and the UTM theorem.

::: {#o4 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

The theorem states that a [partial](wikipedia://en/23577) [computable function](wikipedia://en/1139338) *u* of two variables exists such that, for every computable function *f* of one variable, a number *e* exists such that $f(x) \simeq u(e,x)$ for all *x*. This means that, for each *x*, either *f*(*x*) and *u*(*e*,*x*) are both defined and are equal, or are both undefined.[^n2]

The theorem thus shows that, defining *φ*<sub>*e*</sub>(*x*) as *u*(*e*, *x*), the sequence *φ*<sub>1</sub>, *φ*<sub>2</sub>, ... is an enumeration ([numbering](wikipedia://en/2399097)) of the partial computable functions. In fact, *u* can be chosen so this is the [standard numbering](https://en.wikipedia.org/wiki/Admissible_numbering#Definition). The function $u$ in the statement of the theorem is called a universal function.

:::
