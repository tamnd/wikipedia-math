# Kakutani fixed-point theorem

::: {#o1 .subject cue=lead name="Kakutani fixed-point theorem"}

In [mathematical analysis](wikipedia://en/48396), the **Kakutani fixed-point theorem** is a [fixed-point theorem](wikipedia://en/1011848) for [set-valued functions](wikipedia://en/12506030). It provides [sufficient conditions](https://en.wikipedia.org/wiki/Sufficient_condition) for a set-valued function defined on a [convex](wikipedia://en/6292), [compact](https://en.wikipedia.org/wiki/Compact_set) subset of a [Euclidean space](wikipedia://en/9697) to have a [fixed point](wikipedia://en/449738), i.e. a point which is [mapped](wikipedia://en/516931) to a set containing it. The Kakutani fixed point theorem is a generalization of the [Brouwer fixed point theorem](https://en.wikipedia.org/wiki/Brouwer_fixed_point_theorem). The Brouwer fixed point theorem is a fundamental result in [topology](wikipedia://en/29954) which proves the existence of fixed points for [continuous functions](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) defined on compact, convex subsets of Euclidean spaces. Kakutani's theorem extends this to set-valued functions.

:::

The theorem was developed by [Shizuo Kakutani](wikipedia://en/2572542) in 1941,[^o2] and was used by [John Nash](https://en.wikipedia.org/wiki/John_Forbes_Nash,_Jr.) in his description of [Nash equilibria](wikipedia://en/45337).[^o19] It has subsequently found widespread application in [game theory](wikipedia://en/11924) and [economics](https://en.wikipedia.org/wiki/Economics).[^o3]

::: {#o5 .statement cue=heading name="Statement"}

## Statement {#Statement}

Kakutani's theorem states:[^o6]

*Let* *S* *be a [non-empty](wikipedia://en/9566), [compact](https://en.wikipedia.org/wiki/Compact_set) and [convex](wikipedia://en/6292) [subset](wikipedia://en/27631) of some [Euclidean space](wikipedia://en/9697)* **R**<sup>*n*</sup>.

*Let* *φ*: *S* → 2<sup>*S*</sup> *be a [set-valued function](wikipedia://en/12506030) on* *S* *with the following properties:*

- *φ* has *a [closed graph](https://en.wikipedia.org/wiki/Closed_graph);*
- *φ*(*x*) *is non-empty and convex for all* *x* ∈ *S*.

*Then* *φ* *has a [fixed point](wikipedia://en/449738).*

:::

::: {#o8 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

**Set-valued function**

A **set-valued function** *φ* from the set *X* to the set *Y* is some rule that associates one *or more* points in *Y* with each point in *X*. Formally it can be seen just as an ordinary [function](wikipedia://en/185427) from *X* to the [power set](wikipedia://en/23799) of *Y*, written as *φ*: *X* → 2<sup>*Y*</sup>, such that *φ*(*x*) is non-empty for every $x \in X$. Some prefer the term **correspondence**, which is used to refer to a function that for each input may return many outputs. Thus, each element of the domain corresponds to a subset of one or more elements of the range.

**Closed graph**

A set-valued function φ: *X* → 2<sup>*Y*</sup> is said to have a **closed graph** if the set {(*x*,*y*) | *y* ∈ *φ*(*x*)} is a [closed](wikipedia://en/47279) subset of *X* × *Y* in the [product topology](wikipedia://en/24910) i.e. for all sequences $\{x_n\}_{n\in \mathbb{N}}$ and $\{y_n\}_{n\in \mathbb{N}}$ such that $x_n\to x$, $y_{n}\to y$ and $y_{n}\in \phi(x_n)$ for all $n$, we have $y\in \phi(x)$.

**Fixed point**

Let φ: *X* → 2<sup>*X*</sup> be a set-valued function. Then *a* ∈ *X* is a **fixed point** of *φ* if *a* ∈ *φ*(*a*).

:::

## Examples {#Examples}

*Image: Kakutani.svg.* Fixed points for *φ*(x)=\[1−*x*/2, 1−*x*/4\]

### A function with infinitely many fixed points {#A_function_with_infinitely_many_fixed_points}

The function: $\varphi(x)= [1-x/2, ~1-x/4]$, shown on the figure at the right, satisfies all Kakutani's conditions, and indeed it has many fixed points: any point on the 45° line (dotted line in red) which intersects the graph of the function (shaded in grey) is a fixed point, so in fact there is an infinity of fixed points in this particular case. For example, *x* = 0.72 (dashed line in blue) is a fixed point since 0.72 ∈ \[1 − 0.72/2, 1 − 0.72/4\].

### A function with a unique fixed point {#A_function_with_a_unique_fixed_point}

The function:

$$\varphi(x)= \begin{cases} 3/4 & 0 \le x < 0.5 \\{} [0,1] & x = 0.5 \\ 1/4 & 0.5 < x \le 1 \end{cases}$$

satisfies all Kakutani's conditions, and indeed it has a fixed point: *x* = 0.5 is a fixed point, since *x* is contained in the interval \[0,1\].

### A function that does not satisfy convexity {#A_function_that_does_not_satisfy_convexity}

*Image: Kakutani non.svg.* A function without fixed points

The requirement that *φ*(*x*) be convex for all *x* is essential for the theorem to hold.

Consider the following function defined on \[0,1\]:

$$\varphi(x)= \begin{cases} 3/4 & 0 \le x < 0.5 \\ \{ 3/4, 1/4 \} & x = 0.5 \\ 1/4 & 0.5 < x \le 1 \end{cases}$$

The function has no fixed point. Though it satisfies all other requirements of Kakutani's theorem, its value fails to be convex at *x* = 0.5.

### A function that does not satisfy closed graph {#A_function_that_does_not_satisfy_closed_graph}

Consider the following function defined on \[0,1\]:

$$\varphi(x)= \begin{cases} 3/4 & 0 \le x < 0.5 \\ 1/4 & 0.5 \le x \le 1 \end{cases}$$

The function has no fixed point. Though it satisfies all other requirements of Kakutani's theorem, its graph is not closed; for example, consider the sequences *x<sub>n</sub>* = 0.5 - 1/*n*, *y<sub>n</sub>* = 3/4.

:::

## Alternative statement {#Alternative_statement}

Some sources, including Kakutani's original paper, use the concept of [upper hemicontinuity](wikipedia://en/2945778#Upper_hemicontinuity) while stating the theorem:

*Let* *S* *be a [non-empty](wikipedia://en/9566), [compact](https://en.wikipedia.org/wiki/Compact_set) and [convex](wikipedia://en/6292) [subset](wikipedia://en/27631) of some [Euclidean space](wikipedia://en/9697)* **R**<sup>*n*</sup>. *Let* *φ*: *S*→2<sup>*S*</sup> *be an [upper hemicontinuous](wikipedia://en/2945778#Upper_hemicontinuity) [set-valued function](wikipedia://en/12506030) on* *S* *with the property that* *φ*(*x*) *is non-empty, closed, and convex for all* *x* ∈ *S*. *Then* *φ* *has a [fixed point](wikipedia://en/449738).*

This statement of Kakutani's theorem is completely equivalent to the statement given at the beginning of this article.

We can show this by using the [closed graph theorem](wikipedia://en/497834) for set-valued functions,[^o41] which says that for a compact [Hausdorff](wikipedia://en/13637) range space *Y*, a set-valued function *φ*: *X*→2<sup>*Y*</sup> has a closed graph if and only if it is upper hemicontinuous and *φ*(*x*) is a closed set for all *x*. Since all [Euclidean spaces](wikipedia://en/9697) are Hausdorff (being [metric spaces](wikipedia://en/20018)) and *φ* is required to be closed-valued in the alternative statement of the Kakutani theorem, the Closed Graph Theorem implies that the two statements are equivalent.

## Applications {#Applications}

### Game theory {#Game_theory}

The Kakutani fixed point theorem can be used to prove the [minimax theorem](wikipedia://en/645602) in the theory of [zero-sum games](wikipedia://en/34417). This application was specifically discussed by Kakutani's original paper.[^o2]

Mathematician [John Nash](https://en.wikipedia.org/wiki/John_Forbes_Nash) used the Kakutani fixed point theorem to prove a major result in [game theory](wikipedia://en/11924).[^o19] Stated informally, the theorem implies the existence of a [Nash equilibrium](wikipedia://en/45337) in every finite game with mixed strategies for any finite number of players. This work later earned him a [Nobel Prize in Economics](https://en.wikipedia.org/wiki/Nobel_Prize_in_Economics). In this case:

- The base set *S* is the set of [tuples](wikipedia://en/132729) of [mixed strategies](https://en.wikipedia.org/wiki/Mixed_strategy) chosen by each player in a game. If each player has *k* possible actions, then each player's strategy is a *k*-tuple of probabilities summing up to 1, so each player's strategy space is the [standard simplex](https://en.wikipedia.org/wiki/Standard_simplex) in ***R***<sup>*k*</sup>*.* Then, *S* is the cartesian product of all these simplices. It is indeed a nonempty, compact and convex subset of ***R***<sup>*kn*</sup>*.*
- The function φ(*x*) associates with each tuple a new tuple where each player's strategy is her best response to other players' strategies in *x*. Since there may be a number of responses which are equally good, φ is set-valued rather than single-valued. For each *x*, φ(*x*) is nonempty since there is always at least one best response. It is convex, since a mixture of two best-responses for a player is still a best-response for the player. It can be proved that φ has a closed graph.
- Then the [Nash equilibrium](wikipedia://en/45337) of the game is defined as a fixed point of φ, i.e. a tuple of strategies where each player's strategy is a best response to the strategies of the other players. Kakutani's theorem ensures that this fixed point exists.

### General equilibrium {#General_equilibrium}

In [general equilibrium](https://en.wikipedia.org/wiki/General_equilibrium) theory in economics, Kakutani's theorem has been used to prove the existence of set of prices which simultaneously equate supply with demand in all markets of an economy.[^o21] The existence of such prices had been an open question in economics going back to at least [Walras](wikipedia://en/46769). The first proof of this result was constructed by [Lionel McKenzie](https://en.wikipedia.org/wiki/Lionel_McKenzie).[^o22]

In this case:

- The base set *S* is the set of [tuples](wikipedia://en/132729) of commodity prices.
- The function φ(*x*) is chosen so that its result differs from its arguments as long as the price-tuple *x* does not equate supply and demand everywhere. The challenge here is to construct φ so that it has this property while at the same time satisfying the conditions in Kakutani's theorem. If this can be done then φ has a fixed point according to the theorem. Given the way it was constructed, this fixed point must correspond to a price-tuple which equates supply with demand everywhere.

### Fair division {#Fair_division}

Kakutani's fixed-point theorem is used in proving the existence of cake allocations that are both [envy-free](https://en.wikipedia.org/wiki/Envy-free_cake-cutting) and [Pareto efficient](https://en.wikipedia.org/wiki/Pareto_efficient). This result is known as [Weller's theorem](https://en.wikipedia.org/wiki/Weller's_theorem).

:::

## Relation to Brouwer's fixed-point theorem {#Relation_to_Brouwer's_fixed-point_theorem}

Brouwer's fixed-point theorem is a special case of Kakutani fixed-point theorem. Conversely, Kakutani fixed-point theorem is an immediate generalization via the [approximate selection theorem](wikipedia://en/27035751):[^o26]

::: {#o27 .proof cue=math-proof}

By the approximate selection theorem, there exists a sequence of continuous $f_n: S \to S$ such that $\operatorname{graph}(f_n) \subset[\operatorname{graph}(\varphi)]_{1/n}$. By Brouwer fixed-point theorem, there exists a sequence $x_n$ such that $f_n(x_n) = x_n$, so $(x_n, x_n) \in [\operatorname{graph}(\varphi)]_{1/n}$.

Since $S$ is compact, we can take a convergent subsequence $x_n \to x$. Then $(x, x)\in \operatorname{graph}(\varphi)$ since it is a closed set.

:::

## Proof outline {#Proof_outline}

### *S* = \[0,1\] {#S_=_[0,1]}

The proof of Kakutani's theorem is simplest for set-valued functions defined over [closed intervals](wikipedia://en/49172) of the real line. Moreover, the proof of this case is instructive since its general strategy can be carried over to the higher-dimensional case as well.

Let φ: \[0,1\]→2<sup>\[0,1\]</sup> be a [set-valued function](wikipedia://en/12506030) on the closed interval \[0,1\] which satisfies the conditions of Kakutani's fixed-point theorem.

- **Create a sequence of subdivisions of \[0,1\] with adjacent points moving in opposite directions.**

Let (*a*<sub>*i*</sub>, *b*<sub>*i*</sub>, *p*<sub>*i*</sub>, *q*<sub>*i*</sub>) for *i* = 0, 1, ... be a [sequence](wikipedia://en/27838) with the following properties:

{|class="wikitable"

\|- |**\1.**||width="50%"|1 ≥ *b*<sub>i</sub> > *a*<sub>*i*</sub> ≥ 0 |**\2.**||width="40%"|(*b*<sub>*i*</sub> − *a*<sub>*i*</sub>) ≤ 2<sup>−*i*</sup> |- |**\3.**||*p*<sub>*i*</sub> ∈ φ(*a*<sub>*i*</sub>) |**\4.**||*q*<sub>*i*</sub> ∈ φ(*b*<sub>*i*</sub>) |- |**\5.**||*p*<sub>*i*</sub> ≥ *a*<sub>*i*</sub> |**\6.**||*q*<sub>*i*</sub> ≤ *b*<sub>*i*</sub> |}

Thus, the closed intervals \[*a*<sub>*i*</sub>, *b*<sub>*i*</sub>\] form a sequence of subintervals of \[0,1\]. Condition (2) tells us that these subintervals continue to become smaller while condition (3)–(6) tell us that the function φ shifts the left end of each subinterval to its right and shifts the right end of each subinterval to its left.

Such a sequence can be constructed as follows. Let *a*<sub>0</sub> = 0 and *b*<sub>0</sub> = 1. Let *p*<sub>0</sub> be any point in φ(0) and *q*<sub>0</sub> be any point in φ(1). Then, conditions (1)–(4) are immediately fulfilled. Moreover, since *p*<sub>0</sub> ∈ φ(0) ⊂ \[0,1\], it must be the case that *p*<sub>0</sub> ≥ 0 and hence condition (5) is fulfilled. Similarly condition (6) is fulfilled by *q*<sub>0</sub>.

Now suppose we have chosen *a*<sub>*k*</sub>, *b*<sub>*k*</sub>, *p*<sub>*k*</sub> and *q*<sub>*k*</sub> satisfying (1)–(6). Let,

*m* = (*a*<sub>*k*</sub>+*b*<sub>*k*</sub>)/2.

Then *m* ∈ \[0,1\] because \[0,1\] is [convex](wikipedia://en/6292).

If there is a *r* ∈ φ(*m*) such that *r* ≥ *m*, then we take,

*a*<sub>*k*+1</sub> = *m*

*b*<sub>*k*+1</sub> = *b*<sub>*k*</sub>

*p*<sub>*k*+1</sub> = *r*

*q*<sub>*k*+1</sub> = *q*<sub>*k*</sub>

Otherwise, since φ(*m*) is non-empty, there must be a *s* ∈ φ(*m*) such that *s* ≤ *m*. In this case let,

*a*<sub>*k*+1</sub> = *a*<sub>*k*</sub>

*b*<sub>*k*+1</sub> = *m*

*p*<sub>*k*+1</sub> = *p*<sub>*k*</sub>

*q*<sub>*k*+1</sub> = *s*.

It can be verified that *a*<sub>*k*+1</sub>, *b*<sub>*k*+1</sub>, *p*<sub>*k*+1</sub> and *q*<sub>*k*+1</sub> satisfy conditions (1)–(6).

- **Find a limiting point of the subdivisions.**

We have a pair of sequences of intervals, and we would like to show them to converge to a limiting point with the [Bolzano-Weierstrass theorem](https://en.wikipedia.org/wiki/Bolzano-Weierstrass_theorem). To do so, we construe these two interval sequences as a single sequence of points, (*a*<sub>*n*</sub>, *p*<sub>*n*</sub>, *b*<sub>*n*</sub>, *q*<sub>*n*</sub>). This lies in the [cartesian product](wikipedia://en/24104095) \[0,1\]×\[0,1\]×\[0,1\]×\[0,1\], which is a [compact set](https://en.wikipedia.org/wiki/Compact_set) by [Tychonoff's theorem](wikipedia://en/82739). Since our sequence (*a*<sub>*n*</sub>, *p*<sub>*n*</sub>, *b*<sub>*n*</sub>, *q*<sub>*n*</sub>) lies in a compact set, it must have a [convergent](wikipedia://en/285773) [subsequence](wikipedia://en/236098) by [Bolzano-Weierstrass](https://en.wikipedia.org/wiki/Bolzano-Weierstrass_theorem). Let's fix attention on such a subsequence and let its limit be (*a*\*, *p*\*,*b*\*,*q*\*). Since the graph of φ is closed it must be the case that *p*\* ∈ φ(*a*\*) and *q*\* ∈ φ(*b*\*). Moreover, by condition (5), *p*\* ≥ *a*\* and by condition (6), *q*\* ≤ *b*\*.

But since (*b*<sub>*i*</sub> − *a*<sub>*i*</sub>) ≤ 2<sup>−*i*</sup> by condition (2),

*b*\* − *a*\* = (lim *b*<sub>*n*</sub>) − (lim *a*<sub>*n*</sub>) = lim (*b*<sub>*n*</sub> − *a*<sub>*n*</sub>) = 0.

So, *b*\* equals *a*\*. Let *x* = *b*\* = *a*\*.

Then we have the situation that

φ(*x*) ∋ *q*\* ≤ *x* ≤ *p*\* ∈ φ(*x*).

- **Show that the limiting point is a fixed point.**

If *p*\* = *q*\* then *p*\* = *x* = *q*\*. Since *p*\* ∈ φ(*x*), *x* is a fixed point of φ.

Otherwise, we can write the following. Recall that we can parameterize a line between two points a and b by (1-t)a + tb. Using our finding above that q\<x\<p, we can create such a line between p and q as a function of x (notice the fractions below are on the unit interval). By a convenient writing of x, and since φ(*x*) is [convex](wikipedia://en/6292) and

$$x=\left(\frac{x-q^*}{p^*-q^*}\right)p^*+\left(1-\frac{x-q^*}{p^*-q^*}\right)q^*$$

it once again follows that *x* must belong to φ(*x*) since *p*\* and *q*\* do and hence *x* is a fixed point of φ.

### *S* is a *n*-simplex {#S_is_a_n-simplex}

In dimensions greater one, [*n*-simplices](wikipedia://en/39781) are the simplest objects on which Kakutani's theorem can be proved. Informally, a *n*-simplex is the higher-dimensional version of a triangle. Proving Kakutani's theorem for set-valued function defined on a simplex is not essentially different from proving it for intervals. The additional complexity in the higher-dimensional case exists in the first step of chopping up the domain into finer subpieces:

- Where we split intervals into two at the middle in the one-dimensional case, [barycentric subdivision](wikipedia://en/583651) is used to break up a simplex into smaller sub-simplices.
- While in the one-dimensional case we could use elementary arguments to pick one of the half-intervals in a way that its end-points were moved in opposite directions, in the case of simplices the [combinatorial](wikipedia://en/5170) result known as [Sperner's lemma](wikipedia://en/465067) is used to guarantee the existence of an appropriate subsimplex.

Once these changes have been made to the first step, the second and third steps of finding a limiting point and proving that it is a fixed point are almost unchanged from the one-dimensional case.

### Arbitrary *S* {#Arbitrary_S}

Kakutani's theorem for n-simplices can be used to prove the theorem for an arbitrary compact, convex *S*. Once again we employ the same technique of creating increasingly finer subdivisions. But instead of triangles with straight edges as in the case of n-simplices, we now use triangles with curved edges. In formal terms, we find a simplex which covers *S* and then move the problem from *S* to the simplex by using a [deformation retract](https://en.wikipedia.org/wiki/Deformation_retract). Then we can apply the already established result for n-simplices.

## Infinite-dimensional generalizations {#Infinite-dimensional_generalizations}

Kakutani's fixed-point theorem was extended to infinite-dimensional [locally convex topological vector spaces](wikipedia://en/518844) by [Irving Glicksberg](https://en.wikipedia.org/wiki/Irving_Glicksberg)[^o38] and [Ky Fan](https://en.wikipedia.org/wiki/Ky_Fan).[^o39] To state the theorem in this case, we need a few more definitions:

**Upper hemicontinuity**

A set-valued function φ: *X*→2<sup>*Y*</sup> is **[upper hemicontinuous](https://en.wikipedia.org/wiki/Upper_hemicontinuous)** if for every [open set](wikipedia://en/39358) *W* ⊂ *Y*, the set {*x*| φ(*x*) ⊂ *W*} is open in *X*.[^o40]

**Kakutani map**

Let *X* and *Y* be [topological vector spaces](wikipedia://en/45752) and φ: *X*→2<sup>*Y*</sup> be a set-valued function. If *Y* is convex, then φ is termed a **Kakutani map** if it is upper hemicontinuous and φ(*x*) is non-empty, compact and convex for all *x* ∈ *X*.[^o40]

Then the Kakutani–Glicksberg–Fan theorem can be stated as:[^o40]

*Let S be a [non-empty](wikipedia://en/9566), [compact](https://en.wikipedia.org/wiki/Compact_set) and [convex](wikipedia://en/6292) [subset](wikipedia://en/27631) of a [Hausdorff](wikipedia://en/13637) [locally convex topological vector space](wikipedia://en/518844). Let φ: S→2<sup>S</sup> be a Kakutani map. Then φ has a fixed point.*

The corresponding result for single-valued functions is the [Tychonoff fixed-point theorem](https://en.wikipedia.org/wiki/Tychonoff_fixed-point_theorem).

There is another version that the statement of the theorem becomes the same as that in the [Euclidean](wikipedia://en/9697) case:[^o41]

*Let S be a [non-empty](wikipedia://en/9566), [compact](https://en.wikipedia.org/wiki/Compact_set) and [convex](wikipedia://en/6292) [subset](wikipedia://en/27631) of a [locally convex](wikipedia://en/518844) [Hausdorff space](wikipedia://en/13637). Let φ: S→2<sup>S</sup> be a [set-valued function](wikipedia://en/12506030) on S which has a closed graph and the property that φ(x) is non-empty and convex for all x ∈ S. Then the set of [fixed points](wikipedia://en/449738) of φ is non-empty and compact.*

:::

In his game theory textbook,[^o43] [Ken Binmore](https://en.wikipedia.org/wiki/Ken_Binmore) recalls that Kakutani once asked him at a conference why so many economists had attended his talk.
