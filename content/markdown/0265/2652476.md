# Irreducible component

::: {#o1 .subject cue=lead name="Irreducible component"}

In [algebraic geometry](wikipedia://en/1997), an **irreducible algebraic set** or **irreducible variety** is an [algebraic set](https://en.wikipedia.org/wiki/Algebraic_set) that cannot be written as the [union](wikipedia://en/47949) of two [proper](https://en.wikipedia.org/wiki/Proper_subset) algebraic subsets. An **irreducible component** of an algebraic set is an algebraic subset that is irreducible and maximal (for [set inclusion](https://en.wikipedia.org/wiki/Set_inclusion)) for this property. For example, the set of solutions of the equation $xy = 0$ is not irreducible, and its irreducible components are the two lines of equations $x = 0$ and $y = 0$.

:::

It is a fundamental theorem of classical algebraic geometry that every algebraic set may be written in a unique way as a finite union of irreducible components.

These concepts can be reformulated in purely [topological](wikipedia://en/29954) terms, using the [Zariski topology](wikipedia://en/241744), for which the [closed sets](wikipedia://en/47279) are the algebraic subsets: A [topological space](wikipedia://en/30450) is *[irreducible](https://en.wikipedia.org/wiki/Irreducible_space)* if it is not the union of two proper closed subsets, and an *irreducible component* is a maximal subspace (necessarily closed) that is irreducible for the [induced topology](https://en.wikipedia.org/wiki/Induced_topology). Although these concepts may be considered for every topological space, this is rarely done outside algebraic geometry, since most common topological spaces are [Hausdorff spaces](wikipedia://en/13637), and, in a Hausdorff space, the irreducible components are the [singletons](wikipedia://en/381798).

## In topology {#In_topology}

A [topological space](wikipedia://en/30450) *X* is **reducible** if it can be written as a union $X = X_1 \cup X_2$ of two [closed](wikipedia://en/47279) proper subsets $X_1$, $X_2$ of $X.$ A topological space is **irreducible** (or **[hyperconnected](wikipedia://en/7556651)**) if it is not reducible. Equivalently, *X* is irreducible if all non empty [open](wikipedia://en/39358) subsets of *X* are [dense](wikipedia://en/23523594), or if any two nonempty open sets have nonempty [intersection](wikipedia://en/23476429).

A subset *F* of a topological space *X* is called irreducible or reducible, if *F* considered as a topological space via the [subspace topology](wikipedia://en/910926) has the corresponding property in the above sense. That is, $F$ is reducible if it can be written as a union $F = (G_1\cap F)\cup(G_2\cap F),$ where $G_1,G_2$ are closed subsets of $X$, neither of which contains $F.$

An **irreducible component** of a topological space is a [maximal](https://en.wikipedia.org/wiki/Maximal_element) irreducible subset. If a subset is irreducible, its [closure](wikipedia://en/42309) is also irreducible, so irreducible components are closed.

Every irreducible subset of a space *X* is contained in a (not necessarily unique) irreducible component of *X*.[^o3] Every point $x\in X$ is contained in some irreducible component of *X*.

### The empty topological space {#The_empty_topological_space}

The empty topological space vacuously satisfies the definition above for *irreducible* (since it has no proper subsets). However some authors,[^o5] especially those interested in applications to [algebraic topology](wikipedia://en/38801), explicitly exclude the empty set from being irreducible. This article will not follow that convention.

## In algebraic geometry {#In_algebraic_geometry}

Every [affine](wikipedia://en/320468) or [projective algebraic set](wikipedia://en/320469) is defined as the set of the zeros of an [ideal](wikipedia://en/25977) in a [polynomial ring](wikipedia://en/373065). An *irreducible algebraic set*, more commonly known as an [algebraic variety](wikipedia://en/248808), is an algebraic set that cannot be decomposed as the union of two smaller algebraic sets. [Lasker–Noether theorem](https://en.wikipedia.org/wiki/Lasker–Noether_theorem) implies that every algebraic set is the union of a finite number of uniquely defined algebraic sets, called its *irreducible components*. These notions of irreducibility and irreducible components are exactly the above defined ones, when the [Zariski topology](wikipedia://en/241744) is considered, since the algebraic sets are exactly the closed sets of this topology.

The [spectrum of a ring](wikipedia://en/37291) is a topological space whose points are the [prime ideals](wikipedia://en/24928) and the closed sets are the sets of all prime ideals that contain a fixed ideal. For this topology, a closed set is *irreducible* if it is the set of all prime ideals that contain some prime ideal, and the irreducible components correspond to [minimal prime ideals](wikipedia://en/16143832). The number of irreducible components is finite in the case of a [Noetherian ring](wikipedia://en/56129).

A [scheme](wikipedia://en/364754) is obtained by gluing together spectra of rings in the same way that a [manifold](wikipedia://en/2073470) is obtained by gluing together [charts](https://en.wikipedia.org/wiki/Chart_%28mathematics%29). So the definition of irreducibility and irreducible components extends immediately to schemes.

## Examples {#Examples}

In a [Hausdorff space](wikipedia://en/13637), the irreducible subsets and the irreducible components are the [singletons](wikipedia://en/381798). This is the case, in particular, for the [real numbers](wikipedia://en/20646438). In fact, if $X$ is a set of real numbers that is not a singleton, there are three real numbers such that $x \in X$, $y \in X$, and $x < a < y$. The set $X$ cannot be irreducible since $X=(X\cap ({-\infty}, a]) \cup (X\cap [a, \infty)).$

The notion of irreducible component is fundamental in [algebraic geometry](wikipedia://en/1997) and rarely considered outside this area of mathematics: consider the [algebraic subset](https://en.wikipedia.org/wiki/Algebraic_set) of the plane

$$X = \{(x, y) | xy = 0\}.$$

For the [Zariski topology](wikipedia://en/241744), its closed subsets are itself, the empty set, the singletons, and the two lines defined by $x = 0$ and $y = 0$. The set $X$ is thus reducible with these two lines as irreducible components.

The [spectrum](wikipedia://en/37291) of a [commutative ring](wikipedia://en/61346) is the set of the [prime ideals](wikipedia://en/24928) of the ring, endowed with the *Zariski topology*, for which a set of prime ideals is closed if and only if it is the set of all prime ideals that contain a fixed [ideal](wikipedia://en/25977). In this case an *irreducible subset* is the set of all prime ideals that contain a fixed prime ideal.
