# Triangular array

::: {#o1 .subject cue=lead name="Triangular array"}

*Image: BellNumberAnimated.gif.* The triangular array whose right-hand diagonal sequence consists of [Bell numbers](https://en.wikipedia.org/wiki/Bell_numbers)

In mathematics and computing, a **triangular array** of numbers, polynomials, or the like, is a doubly indexed sequence in which each row is only as long as the row's own index. That is, the *i*th row contains only *i* elements.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Notable particular examples include these:

- The [Bell triangle](wikipedia://en/40865450), whose numbers count the [partitions of a set](wikipedia://en/340240) in which a given element is the largest [singleton](wikipedia://en/381798)[^o4]
- [Catalan's triangle](wikipedia://en/35256461), which counts strings of matched parentheses[^o5]
- [Euler's triangle](https://en.wikipedia.org/wiki/Euler's_triangle), which counts permutations with a given number of ascents[^o6]
- [Floyd's triangle](wikipedia://en/14705292), whose entries are all of the integers in order[^o7]
- [Hosoya's triangle](wikipedia://en/17813366), based on the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number)[^o8]
- [Lozanić's triangle](wikipedia://en/4187401), used in the mathematics of chemical compounds[^o9]
- [Narayana triangle](https://en.wikipedia.org/wiki/Narayana_triangle), counting strings of balanced parentheses with a given number of distinct nestings[^o10]
- [Pascal's triangle](wikipedia://en/49497), whose entries are the [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficients)[^o11]
- Clark's triangle [^o12]

Triangular arrays of integers in which each row is symmetric and begins and ends with 1 are sometimes called **generalized Pascal triangles**; examples include Pascal's triangle, the Narayana numbers, and the triangle of Eulerian numbers.[^o13]

:::

::: {#o15 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

Triangular arrays may list mathematical values other than numbers; for instance the [Bell polynomials](wikipedia://en/572498) form a triangular array in which each array entry is a polynomial.[^o16]

Arrays in which the length of each row grows as a linear function of the row number (rather than being equal to the row number) have also been considered.[^o17]

:::

::: {#o19 .application cue=heading name="Applications"}

## Applications {#Applications}

[Romberg's method](wikipedia://en/640580) can be used to estimate the value of a [definite integral](https://en.wikipedia.org/wiki/Definite_integral) by completing the values in a triangle of numbers.[^o20]

The [Boustrophedon transform](wikipedia://en/3027085) uses a triangular array to transform one [integer sequence](wikipedia://en/51421) into another.[^o21]

In general, a triangular array is used to store any table indexed by two [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) where *j* ≤ *i*.

:::

## Indexing {#Indexing}

Storing a triangular array in a computer requires a mapping from the two-dimensional coordinates (*i*, *j*) to a linear [memory address](https://en.wikipedia.org/wiki/Memory_address). If two triangular arrays of equal size are to be stored (such as in [LU decomposition](wikipedia://en/6243993)), they can be combined into a standard [rectangular array](https://en.wikipedia.org/wiki/Array_%28data_structure%29). If there is only one array, or it must be easily appended to, the array may be stored where row *i* begins at the *i*th [triangular number](wikipedia://en/213915) *T<sub>i</sub>*. Just like a rectangular array, one multiplication is required to find the start of the row, but this multiplication is of two variables (`i*(i+1)/2`), so some optimizations such as using a [sequence of shifts and adds](wikipedia://en/57411#Usage_in_computers) are not available.
