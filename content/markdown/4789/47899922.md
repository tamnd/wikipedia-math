# Superadditive set function

::: {#o1 .subject cue=lead name="Superadditive set function"}

In mathematics, a **superadditive set function** is a [set function](wikipedia://en/25911217) whose value when applied to the [union](wikipedia://en/47949) of two [disjoint sets](wikipedia://en/39359) is greater than or equal to the sum of values of the function applied to each of the sets separately. This definition is analogous to the notion of [superadditivity](wikipedia://en/1464384) for real-valued functions. It is contrasted to [subadditive set function](wikipedia://en/37998626).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\Omega$ be a [set](wikipedia://en/26691) and $f \colon 2^{\Omega} \rightarrow \mathbb{R}$ be a [set function](wikipedia://en/25911217), where $2^\Omega$ denotes the [power set](wikipedia://en/23799#Representing_subsets_as_functions) of $\Omega$. The function *f* is *superadditive* if for any pair of disjoint subsets $S,T$ of $\Omega$, we have $f(S) + f(T) \leq f(S \cup T)$.[^o4]

:::
