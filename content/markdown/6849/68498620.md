# Conservativity

::: {#o1 .subject cue=lead name="Conservativity"}

In [formal semantics](wikipedia://en/31395652) **conservativity** is a proposed [linguistic universal](https://en.wikipedia.org/wiki/Linguistic_universal) which states that any [determiner](https://en.wikipedia.org/wiki/Determiner) $D$ must obey the equivalence $D(A,B) \leftrightarrow D(A, A\cap B)$. For instance, the [English](https://en.wikipedia.org/wiki/English_language) determiner "every" can be seen to be conservative by the [equivalence](wikipedia://en/169324) of the following two sentences, schematized in [generalized quantifier](wikipedia://en/7959499) notation to the right.[^o2][^o3][^o4]

:::

1. Every aardvark bites. $\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \rightsquigarrow every(A,B)$
1. Every aardvark is an aardvark that bites. $\ \ \rightsquigarrow every(A,A\cap B)$

Conceptually, conservativity can be understood as saying that the [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of $B$ which are not elements of $A$ are not relevant for evaluating the truth of the [determiner phrase](https://en.wikipedia.org/wiki/Determiner_phrase) as a whole. For instance, truth of the first sentence above does not depend on which biting non-aardvarks exist.[^o2][^o3][^o4]

Conservativity is significant to semantic theory because there are many logically possible determiners which are not attested as [denotations](https://en.wikipedia.org/wiki/Denotation) of natural language expressions. For instance, consider the imaginary determiner $shmore$ defined so that $shmore(A,B)$ is true iff $|A|>|B|$. If there are 50 biting aardvarks, 50 non-biting aardvarks, and millions of non-aardvark biters, $shmore(A,B)$ will be false but $shmore(A, A\cap B)$ will be true.[^o2][^o3][^o4]

Some potential counterexamples to conservativity have been observed, notably, the English expression "only". This expression has been argued to not be a determiner since it can stack with bona fide determiners and can combine with non-nominal constituents such as [verb phrases](https://en.wikipedia.org/wiki/Verb_phrase).[^o5]

1. Only some aardvarks bite.
1. This aardvark will only \[VP bite playfully.\]

Different analyses have treated conservativity as a constraint on the [lexicon](https://en.wikipedia.org/wiki/Lexicon), a structural constraint arising from the architecture of the [syntax-semantics interface](https://en.wikipedia.org/wiki/Syntax-semantics_interface), as well as constraint on [learnability](https://en.wikipedia.org/wiki/Language_acquisition).[^o6][^o7][^o8]
