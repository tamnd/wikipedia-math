# Optimization problem

Mathematical optimization

::: {#o1 .subject cue=lead name="Optimization problem"}

In [mathematics](wikipedia://en/18831), [engineering](https://en.wikipedia.org/wiki/Engineering), [computer science](https://en.wikipedia.org/wiki/Computer_science) and [economics](https://en.wikipedia.org/wiki/Economics), an **optimization problem** is the [problem](https://en.wikipedia.org/wiki/Computational_problem) of finding the *best* solution from all [feasible solutions](https://en.wikipedia.org/wiki/Feasible_solution).

:::

Optimization problems can be divided into two categories, depending on whether the [variables](wikipedia://en/3728109) are [continuous](https://en.wikipedia.org/wiki/Continuous_variable) or [discrete](https://en.wikipedia.org/wiki/Discrete_variable):

- An optimization problem with discrete variables is known as a *[discrete optimization](wikipedia://en/420567)*, in which an [object](wikipedia://en/19453961) such as an [integer](wikipedia://en/14563), [permutation](wikipedia://en/44027) or [graph](wikipedia://en/325806) must be found from a [countable set](wikipedia://en/6026).
- A problem with continuous variables is known as a *[continuous optimization](wikipedia://en/420577)*, in which an optimal value from a [continuous function](wikipedia://en/6122) must be found. They can include [constrained problems](wikipedia://en/4171950) and multimodal problems.

::: {#o3 .pointer-item cue=pointer name="Search space (mathematics)"}

## Search space {#Search_space}

In the context of an optimization problem, the **search space** refers to the set of all possible points or solutions that satisfy the problem's constraints, targets, or goals.[^o4] These points represent the feasible solutions that can be evaluated to find the optimal solution according to the objective function. The search space is often defined by the domain of the function being optimized, encompassing all valid inputs that meet the problem's requirements.[^o5]

The search space can vary significantly in size and complexity depending on the problem. For example, in a continuous optimization problem, the search space might be a multidimensional real-valued domain defined by bounds or constraints. In a discrete optimization problem, such as combinatorial optimization, the search space could consist of a finite set of permutations, combinations, or configurations.

In some contexts, the term *search space* may also refer to the optimization of the domain itself, such as determining the most appropriate set of variables or parameters to define the problem. Understanding and effectively navigating the search space is crucial for designing efficient algorithms, as it directly influences the computational complexity and the likelihood of finding an optimal solution.

## Continuous optimization problem {#Continuous_optimization_problem}

The *[standard form](wikipedia://en/515096)* of a [continuous](https://en.wikipedia.org/wiki/Continuity_%28mathematics%29) optimization problem is[^o8]

$$\begin{aligned} &\underset{x}{\operatorname{minimize}}& & f(x) \\ &\operatorname{subject\;to} & &g_i(x) \leq 0, \quad i = 1,\dots,m \\ &&&h_j(x) = 0, \quad j = 1, \dots,p \end{aligned}$$

where

- $f : \mathbb{R}^{n} \to \mathbb{R}$ is the *[objective function](https://en.wikipedia.org/wiki/Objective_function)* to be minimized over the $n$-variable vector $x$,
- $g_{i}(x) \le 0$ are called *inequality [constraints](wikipedia://en/7418540)*
- $h_{j}(x) = 0$ are called *equality constraints*, and
- $m \ge 0$ and $p \ge 0$.

If $m = p = 0$, the problem is an unconstrained optimization problem. By convention, the standard form defines a **minimization problem**. A **maximization problem** can be treated by [negating](wikipedia://en/228312) the objective function.

:::

## Combinatorial optimization problem {#Combinatorial_optimization_problem}

Formally, a [combinatorial optimization](wikipedia://en/420555) problem $A$ is a quadruple $(I, f, m, g)$, where

- $I$ is a [set](wikipedia://en/26691) of instances;
- given an instance $x \in I$, $f(x)$ is the set of feasible solutions;
- given an instance $x$ and a feasible solution $y$ of $x$, $m(x, y)$ denotes the [measure](wikipedia://en/19873) of $y$, which is usually a [positive](https://en.wikipedia.org/wiki/Positive_%28mathematics%29) [real](wikipedia://en/20646438).
- $g$ is the goal function, and is either $\min$ or $\max$.

The goal is then to find for some instance $x$ an *optimal solution*, that is, a feasible solution $y$ with

$$m(x, y) = g\left\{ m(x, y') : y' \in f(x) \right\}.$$

For each combinatorial optimization problem, there is a corresponding [decision problem](wikipedia://en/8336) that asks whether there is a feasible solution for some particular measure $m_{0}$. For example, if there is a [graph](wikipedia://en/325806) $G$ which contains vertices $u$ and $v$, an optimization problem might be "find a path from $u$ to $v$ that uses the fewest edges". This problem might have an answer of, say, 4. A corresponding decision problem would be "is there a path from $u$ to $v$ that uses 10 or fewer edges?" This problem can be answered with a simple 'yes' or 'no'.

In the field of [approximation algorithms](wikipedia://en/563105), algorithms are designed to find near-optimal solutions to hard problems. The usual decision version is then an inadequate definition of the problem since it only specifies acceptable solutions. Even though we could introduce suitable decision problems, the problem is more naturally characterized as an optimization problem.[^o10]
