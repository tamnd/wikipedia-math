# Dimensional operator

::: {#o1 .subject cue=lead name="Dimensional operator"}

In [mathematics](wikipedia://en/18831), specifically [set theory](wikipedia://en/27553), a **dimensional operator** on a set *E* is a function from the [subsets](https://en.wikipedia.org/wiki/Subsets) of *E* to the subsets of *E*.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If the [power set](wikipedia://en/23799) of *E* is denoted *P*(*E*) then a dimensional operator on *E* is a [map](wikipedia://en/516931)

$$d:P(E)\rightarrow P(E)\,$$

that satisfies the following properties for *S*,*T* ∈ *P*(*E*):

1. *S* ⊆ *d*(*S*);
1. *d*(*S*) = *d*(*d*(*S*)) (*d* is [idempotent](https://en.wikipedia.org/wiki/Idempotent));
1. if *S* ⊆ *T* then *d*(*S*) ⊆ *d*(*T*);
1. if Ω is the set of finite subsets of *S* then *d*(*S*) = ∪<sub>*A*∈Ω</sub>*d*(*A*);
1. if *x* ∈ *E* and *y* ∈ *d*(*S* ∪ {*x*}) \\ *d*(*S*), then *x* ∈ *d*(*S* ∪ {*y*}).

The final property is known as the exchange axiom.[^o4]

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

1. For any set *E* the identity map on *P*(*E*) is a dimensional operator.
1. The map which takes any subset *S* of *E* to *E* itself is a dimensional operator on *E*.

:::
