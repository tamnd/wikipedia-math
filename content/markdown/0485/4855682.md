# Junction tree algorithm

::: {#o1 .subject cue=lead name="Junction tree algorithm"}

*Image: Junction-tree-example.gif.* Example of a junction tree

The **junction tree algorithm** (also known as 'Clique Tree') is a method used in [machine learning](wikipedia://en/233488) to extract [marginalization](wikipedia://en/506077) in general [graphs](wikipedia://en/325806). In essence, it entails performing [belief propagation](wikipedia://en/800010) on a modified graph called a [junction tree](https://en.wikipedia.org/wiki/Junction_tree). The graph is called a tree because it branches into different sections of data; [nodes](wikipedia://en/638899) of variables are the branches.[^o2] The basic premise is to eliminate [cycles](wikipedia://en/168609) by clustering them into single nodes. Multiple extensive classes of queries can be compiled at the same time into larger structures of data.[^o2] There are different [algorithms](wikipedia://en/775) to meet specific needs and for what needs to be calculated. [Inference algorithms](https://en.wikipedia.org/wiki/Inference_network) gather new developments in the data and calculate it based on the new information provided.[^o3]

:::

## Junction tree algorithm {#Junction_tree_algorithm}

### Hugin algorithm {#Hugin_algorithm}

- If the graph is directed then [moralize](wikipedia://en/4855451) it to make it un-directed.
- Introduce the evidence.
- [Triangulate](wikipedia://en/744165) the graph to make it chordal.
- Construct a [junction tree](https://en.wikipedia.org/wiki/Junction_tree) from the triangulated graph (we will call the vertices of the junction tree "[supernodes](https://en.wikipedia.org/wiki/Supernode_%28circuit%29)").
- Propagate the probabilities along the junction tree (via [belief propagation](wikipedia://en/800010))

Note that this last step is inefficient for graphs of large [treewidth](wikipedia://en/3987086). Computing the messages to pass between supernodes involves doing exact marginalization over the variables in both supernodes. Performing this algorithm for a graph with treewidth k will thus have at least one computation which takes time exponential in k. It is a [message passing](wikipedia://en/800010) algorithm.[^o6] The Hugin algorithm takes fewer [computations](wikipedia://en/5926) to find a solution compared to Shafer-Shenoy.

### Shafer-Shenoy algorithm {#Shafer-Shenoy_algorithm}

- Computed recursively[^o6]
- Multiple recursions of the Shafer-Shenoy algorithm results in Hugin algorithm[^o8]
- Found by the [message passing](https://en.wikipedia.org/wiki/Message_passing_in_computer_clusters) equation[^o8]
- [Separator](wikipedia://en/1499165) potentials are not stored[^o9]

The Shafer-Shenoy [algorithm](wikipedia://en/775) is the [sum product](https://en.wikipedia.org/wiki/Sum-product_algorithm) of a junction tree.[^o10] It is used because it runs programs and queries more efficiently than the Hugin algorithm. The algorithm makes calculations for conditionals for [belief functions](https://en.wikipedia.org/wiki/Belief_functions) possible.[^o11] [Joint distributions](https://en.wikipedia.org/wiki/Joint_distributions) are needed to make local computations happen.[^o11]

### Underlying theory {#Underlying_theory}

*Image: Hmm temporal bayesian net.svg.* Example of a Dynamic Bayesian network

The first step concerns only [Bayesian networks](https://en.wikipedia.org/wiki/Bayesian_networks), and is a procedure to turn a directed graph into an [undirected](https://en.wikipedia.org/wiki/Undirected) one. We do this because it allows for the universal applicability of the algorithm, regardless of direction.

The second step is setting variables to their observed value. This is usually needed when we want to calculate conditional probabilities, so we fix the value of the [random variables](wikipedia://en/25685) we condition on. Those variables are also said to be clamped to their particular value.

*Image: Chordal-graph.svg.* Example of a chordal graph

The third step is to ensure that graphs are made [chordal](wikipedia://en/744165) if they aren't already chordal. This is the first essential step of the algorithm. It makes use of the following theorem:[^o13]

::: {#o14 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** For an [undirected](wikipedia://en/325806) graph, G, the following properties are equivalent:

- Graph G is triangulated.
- The clique graph of G has a junction tree.
- There is an elimination ordering for G that does not lead to any added edges.

Thus, by [triangulating](wikipedia://en/1440970) a graph, we make sure that the corresponding junction tree exists. A usual way to do this, is to decide an elimination order for its nodes, and then run the [Variable elimination](https://en.wikipedia.org/wiki/Variable_elimination) algorithm. The [variable elimination](https://en.wikipedia.org/wiki/Variable_elimination) algorithm states that the algorithm must be run each time there is a different query.[^o2] This will result to adding more edges to the initial graph, in such a way that the output will be a [chordal graph](wikipedia://en/744165). All chordal graphs have a junction tree.[^o8] The next step is to construct the [junction tree](https://en.wikipedia.org/wiki/Junction_tree). To do so, we use the graph from the previous step, and form its corresponding [clique graph](https://en.wikipedia.org/wiki/Clique_graph).[^o15] Now the next theorem gives us a way to find a junction tree:[^o8]

:::

::: {#o16 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem:** Given a triangulated graph, weight the edges of the clique graph by their cardinality, |A∩B|, of the intersection of the adjacent cliques A and B. Then any maximum-weight spanning tree of the clique graph is a junction tree.

So, to construct a junction tree we just have to extract a maximum weight spanning tree out of the clique graph. This can be efficiently done by, for example, modifying [Kruskal's algorithm](wikipedia://en/53776). The last step is to apply [belief propagation](wikipedia://en/800010) to the obtained junction tree.[^o17]

**Usage:** A junction tree graph is used to visualize the probabilities of the problem. The tree can become a binary tree to form the actual building of the tree.[^o18] A specific use could be found in [auto encoders](https://en.wikipedia.org/wiki/Autoencoder), which combine the graph and a passing network on a large scale automatically.[^o19]

:::

### Inference Algorithms {#Inference_Algorithms}

*Image: Cutset-4.svg.* Cutset conditioning

**Loopy belief propagation:** A different method of interpreting complex graphs. The [loopy belief propagation](https://en.wikipedia.org/wiki/Loopy_belief_propagation) is used when an approximate solution is needed instead of the [exact solution](https://en.wikipedia.org/wiki/Exact_solutions).[^o21] It is an [approximate inference](https://en.wikipedia.org/wiki/Approximate_inference).[^o6]

**Cutset conditioning:** Used with smaller sets of variables. [Cutset](https://en.wikipedia.org/wiki/Cutset) conditioning allows for simpler graphs that are easier to read but are not [exact](https://en.wikipedia.org/wiki/Exact_solutions).[^o6]
