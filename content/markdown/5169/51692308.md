# Geometric class field theory

::: {#o1 .subject cue=lead name="Geometric class field theory"}

In [mathematics](wikipedia://en/18831), **geometric class field theory** is an extension of [class field theory](wikipedia://en/242695) to higher-dimensional geometrical objects: much the same way as class field theory describes the [abelianization](https://en.wikipedia.org/wiki/Abelianization) of the [Galois group](wikipedia://en/12673) of a [local](wikipedia://en/145375) or [global field](wikipedia://en/288358), geometric class field theory describes the abelianized [fundamental group](wikipedia://en/11004) of higher dimensional [schemes](wikipedia://en/364754) in terms of data related to [algebraic cycles](wikipedia://en/9520954).

:::
