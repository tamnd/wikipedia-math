# Covering problems

::: {#o1 .subject cue=lead name="Covering problems"}

In [combinatorics](wikipedia://en/5170) and [computer science](https://en.wikipedia.org/wiki/Computer_science), **covering problems** are computational problems that ask whether a certain combinatorial structure 'covers' another, or how large the structure has to be to do that. Covering problems are [minimization problems](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) and usually [integer linear programs](https://en.wikipedia.org/wiki/Integer_linear_programs), whose [dual problems](https://en.wikipedia.org/wiki/Dual_problem) are called [packing problems](wikipedia://en/213003).

:::

The most prominent examples of covering problems are the [set cover problem](wikipedia://en/870399), which is equivalent to the [hitting set problem](https://en.wikipedia.org/wiki/Hitting_set), and its special cases, the [vertex cover problem](https://en.wikipedia.org/wiki/Vertex_cover_problem) and the [edge cover problem](https://en.wikipedia.org/wiki/Edge_cover_problem).

Covering problems allow the covering primitives to overlap; the process of covering something with non-overlapping primitives is called [decomposition](https://en.wikipedia.org/wiki/Decomposition_%28disambiguation%29).

## General linear programming formulation {#General_linear_programming_formulation}

In the context of [linear programming](wikipedia://en/43730), one can think of any minimization linear program as a covering problem if the coefficients in the constraint [matrix](wikipedia://en/20556859), the objective function, and right-hand side are nonnegative.[^o3] More precisely, consider the following general [integer linear program](https://en.wikipedia.org/wiki/Integer_linear_program):

| minimize | $\sum_{i=1}^n c_i x_i$ |
|---|---|
| subject to | $\sum_{i=1}^n a_{ji} x_i \geq b_j \text{ for }j=1,\dots,m$ |
|  | $x_i \in \left\{0, 1, 2, \ldots\right\}\text{ for }i=1,\dots,n$. |

Such an integer linear program is called a **covering problem** if $a_{ji}, b_j, c_i \geq 0$ for all $i=1,\dots,n$ and $j=1,\dots,m$.

**Intuition:** Assume having $n$ types of object and each object of type $i$ has an associated cost of $c_i$. The number $x_i$ indicates how many objects of type $i$ we buy. If the constraints $A\mathbf{x}\geq \mathbf{b}$ are satisfied, it is said that *$\mathbf{x}$ is a covering* (the structures that are covered depend on the combinatorial context). Finally, an optimal solution to the above integer linear program is a covering of minimal cost.

## Kinds of covering problems {#Kinds_of_covering_problems}

There are various kinds of covering problems in [graph theory](wikipedia://en/12401), [computational geometry](wikipedia://en/176927) and more; see . Other stochastic related versions of the problem can be found.[^o5]

*Image: Covering problem of Rado.gif.* The [covering problem of Rado](wikipedia://en/21261359), where a series of squares with parallel edges needs to cover an area of 1. For any set meeting these conditions, a subset of these squares is selected (indicated by the red coloring) in which no two squares overlap, and the total area is maximized. The goal is to make an arrangement of squares so that the total area of the optimal subset is *minimized*. The examples each have maximal areas of 1/4, but there are some which have slightly lower. [^o6] [^o7]

*Image: DiscCoveringExample.svg.* The [disk covering problem](wikipedia://en/9451796), which asks what the smallest real number $r(n)$ is such that $n$ disks of radius $r(n)$ can be arranged in such a way as to cover the unit disk.

### Covering in Petri nets {#Covering_in_Petri_nets}

For [Petri nets](wikipedia://en/225192), the covering problem is defined as the question if for a given marking, there exists a run of the net, such that some larger (or equal) marking can be reached. *Larger* means here that all components are at least as large as the ones of the given marking and at least one is properly larger.

### Rainbow covering {#Rainbow_covering}

In some covering problems, the covering should satisfy some additional requirements. In particular, in the **rainbow covering** problem, each of the original objects has a "color", and it is required that the covering contains exactly one (or at most one) object of each color. Rainbow covering was studied e.g. for covering points by [intervals](wikipedia://en/49172):[^o10]

- There is a set *J* of *n* colored intervals on the [real line](https://en.wikipedia.org/wiki/Real_line), and a set *P* of points on the real line.
- A [subset](wikipedia://en/27631) *Q* of *J* is called a *rainbow set* if it contains at most a single interval of each color.
- A set of intervals *J* is called a *covering* of *P* if each point in *P* is contained in at least one interval of *Q*.
- The *Rainbow covering problem* is the problem of finding a rainbow set *Q* that is a covering of *P*.

The problem is [NP-hard](wikipedia://en/54681) (by reduction from [linear SAT](https://en.wikipedia.org/wiki/Linear_SAT)).

### Conflict-free covering {#Conflict-free_covering}

A more general notion is **conflict-free covering**.[^o12] In this problem:

- There is a set *O* of *m* objects, and a conflict-graph *G<sub>O</sub>* on *O*.
- A subset *Q* of *O* is called *conflict-free* if it is an [independent set](wikipedia://en/524501) in *G<sub>O</sub>*, that is, no two objects in *Q* are connected by an edge in *G<sub>O</sub>*.
- A rainbow set is a conflict-free set in the special case in which *G<sub>O</sub>* is made of disjoint cliques, where each clique represents a color.

*Conflict-free set cover* is the problem of finding a conflict-free subset of *O* that is a covering of *P*. Banik, Panolan, Raman, Sahlot and Saurabh[^o13] [prove](wikipedia://en/82285) the following for the special case in which the conflict-graph has bounded [arboricity](wikipedia://en/2476311):

- If the geometric cover problem is [fixed-parameter](https://en.wikipedia.org/wiki/Fixed-parameter_algorithm) tractable (FPT), then the conflict-free geometric cover problem is FPT.
- If the geometric cover problem admits an r-approximation algorithm, then the conflict-free geometric cover problem admits a similar approximation algorithm in FPT time.
