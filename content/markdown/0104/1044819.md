# MD2 (hash function)

::: {#o3 .subject cue=lead name="MD2"}

The **MD2 Message-Digest Algorithm** is an obsolete [cryptographic hash function](wikipedia://en/439526) developed by [Ronald Rivest](https://en.wikipedia.org/wiki/Ronald_Rivest) in 1989.[^o15] The algorithm is optimized for [8-bit](https://en.wikipedia.org/wiki/8-bit) computers. MD2 is specified in [IETF RFC](https://en.wikipedia.org/wiki/Request_for_Comments) 1319.[^o12] The "MD" in MD2 stands for "Message Digest".

:::

Even though MD2 is not yet fully compromised, the IETF retired MD2 to "historic" status in 2011, citing "signs of weakness". It is deprecated in favor of [SHA-256](wikipedia://en/1638777) and other strong hashing algorithms.[^o4]

Nevertheless, , it remained in use in [public key infrastructures](wikipedia://en/194112) as part of [certificates](https://en.wikipedia.org/wiki/Certificate_%28cryptography%29) generated with MD2 and [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29).

## Description {#Description}

The 128-bit hash value of any message is formed by padding it to a multiple of the block length (128 bits or 16 [bytes](https://en.wikipedia.org/wiki/Byte)) and adding a 16-byte [checksum](https://en.wikipedia.org/wiki/Checksum) to it. For the actual calculation, a 48-byte auxiliary block and a 256-byte [S-table](https://en.wikipedia.org/wiki/S-table) are used. The constants were generated by shuffling the integers 0 through 255 using a variant of [Durstenfeld's algorithm](https://en.wikipedia.org/wiki/Fisher–Yates_shuffle#The_modern_algorithm) with a [pseudorandom number generator](wikipedia://en/45524) based on decimal digits of [$\pi$ (pi)](wikipedia://en/23601)[^o12][^o6] (see [nothing up my sleeve number](https://en.wikipedia.org/wiki/Nothing_up_my_sleeve_number)). The algorithm runs through a loop where it permutes each byte in the auxiliary block 18 times for every 16 input bytes processed. Once all of the blocks of the (lengthened) message have been processed, the first partial block of the auxiliary block becomes the hash value of the message.

## MD2 hashes {#MD2_hashes}

The 128-bit (16-byte) MD2 hashes (also termed *message digests*) are typically represented as 32-digit [hexadecimal](wikipedia://en/13263) numbers. The following demonstrates a 43-byte [ASCII](https://en.wikipedia.org/wiki/ASCII) input and the corresponding MD2 hash:

MD2("The quick brown fox jumps over the lazy #87CEEBog") = 03d85a0d629d2c442e987525319fc471

As the result of the [avalanche effect](wikipedia://en/769439) in MD2, even a small change in the input message will (with overwhelming probability) result in a completely different hash. For example, changing the letter d to c in the message results in:

MD2("The quick brown fox jumps over the lazy #87CEEBog") = 6b890c9292668cdbbfda00a4ebf31f05

The hash of the zero-length string is:

MD2("") = 8350e5a3e24c153df2275c9f80692773

## Security {#Security}

Rogier and Chauvaud presented in 1995[^o18] collisions of MD2's [compression function](wikipedia://en/3851622), although they were unable to extend the attack to the full MD2. The described collisions was published in 1997.[^o17]

In 2004, MD2 was shown to be vulnerable to a [preimage attack](wikipedia://en/969477) with [time complexity](wikipedia://en/405944) equivalent to 2<sup>104</sup> applications of the compression function.[^o14] The author concludes, "MD2 can no longer be considered a secure one-way hash function".

In 2008, MD2 has further improvements on a [preimage attack](wikipedia://en/969477) with [time complexity](wikipedia://en/405944) of 2<sup>73</sup> compression function evaluations and memory requirements of 2<sup>73</sup> message blocks.[^o16]

In 2009, MD2 was shown to be vulnerable to a [collision attack](wikipedia://en/969624) with [time complexity](wikipedia://en/405944) of 2<sup>\63.3</sup> compression function evaluations and memory requirements of 2<sup>52</sup> hash values. This is slightly better than the [birthday attack](wikipedia://en/189369) which is expected to take 2<sup>\65.5</sup> compression function evaluations.[^o13]

In 2009, security updates were issued disabling MD2 in [OpenSSL](wikipedia://en/438819), [GnuTLS](wikipedia://en/949758), and [Network Security Services](wikipedia://en/5137674).[^o9]
