# Projection-valued measure

::: {#o1 .subject cue=lead name="Projection-valued measure"}

In [mathematics](wikipedia://en/18831), particularly in [functional analysis](wikipedia://en/11180), a **projection-valued measure**, or **spectral measure**, is a function defined on certain subsets of a fixed set and whose values are [self-adjoint](https://en.wikipedia.org/wiki/Self-adjoint) [projections](wikipedia://en/3909097) on a fixed [Hilbert space](wikipedia://en/20598932).[^n1] A projection-valued measure (PVM) is formally similar to a [real-valued](https://en.wikipedia.org/wiki/Real-valued) [measure](wikipedia://en/19873), except that its values are self-adjoint projections rather than real numbers. As in the case of ordinary measures, it is possible to [integrate](https://en.wikipedia.org/wiki/Integration_%28mathematics%29) [complex-valued functions](https://en.wikipedia.org/wiki/Complex-valued_function) with respect to a PVM; the result of such an integration is a [linear operator](https://en.wikipedia.org/wiki/Linear_operator) on the given Hilbert space.

:::

Projection-valued measures are used to express results in [spectral theory](wikipedia://en/506713), such as the important [spectral theorem](wikipedia://en/123495#Spectral_subspaces_and_projection-valued_measures) for [self-adjoint operators](wikipedia://en/187408#Formulation_in_the_physics_literature), in which case the PVM is sometimes referred to as the [spectral measure](wikipedia://en/16990545#Spectral_measure). The [Borel functional calculus](wikipedia://en/876294) for self-adjoint operators is constructed using integrals with respect to PVMs. In [quantum mechanics](wikipedia://en/25202), PVMs are the mathematical description of [projective measurements](https://en.wikipedia.org/wiki/Quantum_measurement). They are generalized by [positive operator valued measures](wikipedia://en/3793084) (POVMs) in the same sense that a [mixed state](https://en.wikipedia.org/wiki/Mixed_state_%28physics%29) or [density matrix](wikipedia://en/62844) generalizes the notion of a [pure state](https://en.wikipedia.org/wiki/Pure_state).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $H$ denote a [separable](wikipedia://en/27855) [complex](wikipedia://en/5826) [Hilbert space](wikipedia://en/20598932) and $(X, M)$ a [measurable space](wikipedia://en/43333) consisting of a set $X$ and a [Borel σ-algebra](wikipedia://en/43327) $M$ on $X$. A **projection-valued measure** $\pi$ is a map from $M$ to the set of [bounded self-adjoint operators](wikipedia://en/187408#Bounded_self-adjoint_operators) on $H$ satisfying the following properties:[^n2][^n3]

- $\pi(E)$ is an [orthogonal projection](wikipedia://en/519182#Orthogonal_projections) for all $E \in M.$
- $\pi(\emptyset) = 0$ and $\pi(X) = I$, where $\emptyset$ is the [empty set](wikipedia://en/9566) and $I$ the [identity operator](https://en.wikipedia.org/wiki/Identity_operator).
- If $E_1, E_2, E_3,\dotsc$ in $M$ are disjoint, then for all $v \in H$,

$$\pi\left(\bigcup_{j=1}^{\infty} E_j \right)v = \sum_{j=1}^{\infty} \pi(E_j) v.$$

- $\pi(E_1 \cap E_2)= \pi(E_1)\pi(E_2)$ for all $E_1, E_2 \in M.$

The fourth property is a consequence of the first and third property.[^n4] The second and fourth property show that if $E_1$ and $E_2$ are disjoint, i.e., $E_1 \cap E_2 = \emptyset$, the images $\pi(E_1)$ and $\pi(E_2)$ are [orthogonal](https://en.wikipedia.org/wiki/Orthogonal) to each other.

Let $V_E = \operatorname{im}(\pi(E))$ and its [orthogonal complement](wikipedia://en/1058833) $V^\perp_E=\ker(\pi(E))$ denote the [image](wikipedia://en/579311) and [kernel](wikipedia://en/1072915), respectively, of $\pi(E)$. If $V_E$ is a closed subspace of $H$ then $H$ can be wrtitten as the *orthogonal decomposition* $H=V_E \oplus V^\perp_E$ and $\pi(E)=I_E$ is the unique identity operator on $V_E$ satisfying all four properties.[^n5][^n6]

For every $\xi,\eta\in H$ and $E\in M$ the projection-valued measure forms a [complex-valued measure](wikipedia://en/3057532) on $H$ defined as

$$\mu_{\xi,\eta}(E) := \langle \pi(E)\xi \mid \eta \rangle$$

with [total variation](wikipedia://en/683561) at most $\|\xi\|\|\eta\|$.[^n7] It reduces to a real-valued [measure](wikipedia://en/19873) when

$$\mu_{\xi}(E) := \langle \pi(E)\xi \mid \xi \rangle$$

and a [probability measure](wikipedia://en/45437) when $\xi$ is a [unit vector](wikipedia://en/167053).

::: {#o11 .example cue=inline-head name="Example"}

**Example** Let $(X, M, \mu)$ be a [$\sigma$-finite measure space](wikipedia://en/45270#Important_classes_of_measure_spaces) and, for all $E \in M$, let

$$\pi(E) : L^2(X) \to L^2 (X)$$

be defined as

$$\psi \mapsto \pi(E)\psi=1_E \psi,$$

i.e., as multiplication by the [indicator function](wikipedia://en/240790) $1_E$ on [*L*<sup>2</sup>(*X*)](wikipedia://en/45194). Then $\pi(E)=1_E$ defines a projection-valued measure.[^n7] For example, if $X = \mathbb{R}$, $E = (0,1)$, and $\varphi,\psi \in L^2(\mathbb{R})$ there is then the associated complex measure $\mu_{\varphi,\psi}$ which takes a measurable function $f: \mathbb{R} \to \mathbb{R}$ and gives the integral

$$\int_E f\,d\mu_{\varphi,\psi} = \int_0^1 f(x)\psi(x)\overline{\varphi}(x)\,dx$$

:::

## Extensions of projection-valued measures {#Extensions_of_projection-valued_measures}

If $\pi$ is a projection-valued measure on a measurable space (*X*, *M*), then the map

$$\chi_E \mapsto \pi(E)$$

extends to a linear map on the vector space of [step functions](wikipedia://en/170939) on *X*. In fact, it is easy to check that this map is a [ring homomorphism](wikipedia://en/26411). This map extends in a canonical way to all bounded complex-valued [measurable functions](wikipedia://en/44055) on *X*, and we have the following.

::: {#o14 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

For any bounded Borel function $f$ on $X$, there exists a unique [bounded operator](wikipedia://en/455961) $T : H \to H$ such that [^o15][^n8]

$\langle T \xi \mid \xi \rangle = \int_X f(\lambda) \,d\mu_{\xi}(\lambda), \quad \forall \xi \in H.$ where $\mu_{\xi}$ is a finite [Borel measure](wikipedia://en/4322) given by

$\mu_{\xi}(E) := \langle \pi(E)\xi \mid \xi \rangle, \quad \forall E \in M.$ Hence, $(X,M,\mu)$ is a [finite measure space](https://en.wikipedia.org/wiki/Finite_measure_space).

:::

The theorem is also correct for unbounded measurable functions $f$ but then $T$ will be an unbounded linear operator on the Hilbert space $H$.

::: {#o18 .statement kind=statement/theorem cue=named-heading name="Spectral theorem"}

### Spectral theorem {#Spectral_theorem}

Let $H$ be a [separable](wikipedia://en/27855) [complex](wikipedia://en/5826) [Hilbert space](wikipedia://en/20598932), $A:H\to H$ be a bounded [self-adjoint operator](wikipedia://en/187408) and $\sigma(A)$ the [spectrum](wikipedia://en/206137) of $A$. Then the [spectral theorem](wikipedia://en/123495) says that there exists a unique projection-valued measure $\pi^A$, defined on a [Borel subset](wikipedia://en/43327) $E \subset \sigma(A)$, such that

$$A =\int_{\sigma(A)} \lambda \, d\pi^A(\lambda),$$

and $\pi^{A}(E)$ is called the *spectral projection* of $A$.[^n3][^n9] The integral extends to an unbounded function $\lambda$ when the spectrum of $A$ is unbounded.[^n10]

The spectral theorem allows us to define the [Borel functional calculus](wikipedia://en/876294) for any Borel measurable function $g:\mathbb{R}\to\mathbb{C}$ by integrating with respect to the projection-valued measure $\pi^{A}$:

$$g(A) :=\int_\mathbb{R} g(\lambda) \, d\pi^{A}(\lambda).$$

A similar construction holds for [normal operators](wikipedia://en/190167) and measurable functions $g:\mathbb{C}\to\mathbb{C}$.

:::

### Direct integrals {#Direct_integrals}

First we provide a general example of projection-valued measure based on [direct integrals](wikipedia://en/1256105). Suppose (*X*, *M*, μ) is a measure space and let {*H*<sub>*x*</sub>}<sub>*x* ∈ *X*</sub> be a μ-measurable family of separable Hilbert spaces. For every *E* ∈ *M*, let $\pi$(*E*) be the operator of multiplication by 1<sub>*E*</sub> on the Hilbert space

$$\int_X^\oplus H_x \ d \mu(x).$$

Then $\pi$ is a projection-valued measure on (*X*, *M*).

Suppose $\pi$, ρ are projection-valued measures on (*X*, *M*) with values in the projections of *H*, *K*. $\pi$, ρ are **unitarily equivalent** [if and only if](wikipedia://en/14922) there is a unitary operator *U*:*H* → *K* such that

$$\pi(E) = U^* \rho(E) U \quad$$

for every *E* ∈ *M*.

::: {#o23 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem**. If (*X*, *M*) is a [standard Borel space](https://en.wikipedia.org/wiki/Borel_algebra#Standard_Borel_spaces_and_Kuratowski_theorems), then for every projection-valued measure $\pi$ on (*X*, *M*) taking values in the projections of a *separable* Hilbert space, there is a Borel measure μ and a μ-measurable family of Hilbert spaces {*H*<sub>*x*</sub>}<sub>*x* ∈ *X*</sub>, such that $\pi$ is unitarily equivalent to multiplication by 1<sub>*E*</sub> on the Hilbert space

$$\int_X^\oplus H_x \ d \mu(x).$$

The measure class of μ and the measure equivalence class of the multiplicity function *x* → dim *H*<sub>*x*</sub> completely characterize the projection-valued measure up to unitary equivalence.

A projection-valued measure $\pi$ is *homogeneous of multiplicity* *n* if and only if the multiplicity function has constant value *n*. Clearly,

:::

::: {#o24 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem**. Any projection-valued measure $\pi$ taking values in the projections of a separable Hilbert space is an orthogonal direct sum of homogeneous projection-valued measures:

$$\pi = \bigoplus_{1 \leq n \leq \omega} (\pi \mid H_n)$$

where

$$H_n = \int_{X_n}^\oplus H_x \ d (\mu \mid X_n) (x)$$

and

$$X_n = \{x \in X: \dim H_x = n\}.$$

:::

## Application in quantum mechanics {#Application_in_quantum_mechanics}

In quantum mechanics, given a projection-valued measure of a measurable space $X$ to the space of continuous endomorphisms upon a Hilbert space $H$,

- the [projective space](wikipedia://en/796760) $\mathbf{P}(H)$ of the Hilbert space $H$ is interpreted as the set of possible ([normalizable](https://en.wikipedia.org/wiki/Probability_amplitude#Normalization)) states $\varphi$ of a quantum system,[^n11]
- the measurable space $X$ is the value space for some quantum property of the system (an "observable"),
- the projection-valued measure $\pi$ expresses the probability that the [observable](wikipedia://en/294248) takes on various values.

A common choice for $X$ is the real line, but it may also be

- $\mathbb{R}^3$ (for position or momentum in three dimensions ),
- a discrete set (for angular momentum, energy of a bound state, etc.),
- the 2-point set "true" and "false" for the truth-value of an arbitrary proposition about $\varphi$.

Let $E$ be a measurable subset of $X$ and $\varphi$ a normalized [vector quantum state](wikipedia://en/30876419) in $H$, so that its Hilbert norm is unitary, $\|\varphi\|=1$. The probability that the observable takes its value in $E$, given the system in state $\varphi$, is

$$P_\pi(\varphi)(E) = \langle \varphi\mid\pi(E)(\varphi)\rangle = \langle \varphi\mid\pi(E)\mid\varphi\rangle.$$

We can parse this in two ways. First, for each fixed $E$, the projection $\pi(E)$ is a [self-adjoint operator](wikipedia://en/187408) on $H$ whose 1-eigenspace are the states $\varphi$ for which the value of the observable always lies in $E$, and whose 0-eigenspace are the states $\varphi$ for which the value of the observable never lies in $E$.

Second, for each fixed normalized vector state $\varphi$, the association

$$P_\pi(\varphi) : E \mapsto \langle\varphi\mid\pi(E)\varphi\rangle$$

is a probability measure on $X$ making the values of the observable into a random variable.

A measurement that can be performed by a projection-valued measure $\pi$ is called a **projective measurement**.

If $X$ is the real number line, there exists, associated to $\pi$, a self-adjoint operator $A$ defined on $H$ by

$$A(\varphi) = \int_{\mathbb{R}} \lambda \,d\pi(\lambda)(\varphi),$$

which reduces to

$$A(\varphi) = \sum_i \lambda_i \pi({\lambda_i})(\varphi)$$

if the support of $\pi$ is a discrete subset of $X$.

The above operator $A$ is called the observable associated with the spectral measure.

::: {#o28 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

The idea of a projection-valued measure is generalized by the [positive operator-valued measure](https://en.wikipedia.org/wiki/Positive_operator-valued_measure) (POVM), where the need for the orthogonality implied by projection operators is replaced by the idea of a set of operators that are a non-orthogonal "partition of unity", i.e. a set of [positive semi-definite](wikipedia://en/454936) [Hermitian operators](https://en.wikipedia.org/wiki/Hermitian_operators) that sum to the identity. This generalization is motivated by applications to [quantum information theory](https://en.wikipedia.org/wiki/Quantum_information_theory).

:::
