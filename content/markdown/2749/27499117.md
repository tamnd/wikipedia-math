# Mondrian (software)

::: {#o1 .subject cue=lead name="Mondrian"}

**Mondrian** is a general-purpose statistical data-visualization system, for [interactive data visualization](https://en.wikipedia.org/wiki/Interactive_data_visualization).

:::

All plots in Mondrian are fully linked, and offer various interactions and queries. Any case selected in a plot in Mondrian is highlighted in all other plots. Currently implemented plots comprise Mosaic Plot, Scatterplots and SPLOM, Maps, Barcharts, Histograms, Missing Value Plot, Parallel Coordinates/Boxplots and Boxplots y by x.[^o3] Mondrian works with data in standard tab-delimited or comma-separated ASCII files and can load data from [R](wikipedia://en/376707) workspaces. There is basic support for working directly on data in databases. Mondrian links to R and offers statistical procedures like interactive [density estimation](wikipedia://en/554671), [scatterplot smoothers](https://en.wikipedia.org/wiki/Scatterplot_smoother), [multidimensional scaling](wikipedia://en/398786) (MDS) and [principal component analysis](wikipedia://en/76340) (PCA).

## Overview {#Overview}

Starting in 1997, Mondrian was first developed with a focus on visualization techniques for [categorical data](wikipedia://en/821165) and enhanced selection techniques. Over the years, a complete suite of visualizations for univariate and multivariate data measured on any scale were added. The link to R offers well tested statistical procedures, which integrate seamlessly into the interactive graphics. Today, even geographical data is supported with highly interactive maps.

## Mondrian details {#Mondrian_details}

Last stable and beta versions, help and documentations are available on the developer web site, Martin Theus

### Supported data sources {#Supported_data_sources}

Mondrian works on plain text files with tab-separated columns with variable header, as exported from [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel) as ".txt". If the Rserve link and R are present, Mondrian also reads data directly from R workspace files (.RData files).

### Visualizations {#Visualizations}

- 1-d: [Barchart](https://en.wikipedia.org/wiki/Barchart), [Spineplot](https://en.wikipedia.org/wiki/Spineplot), [Histogram](wikipedia://en/13266), [Spinogram](https://en.wikipedia.org/wiki/Spinogram), [Boxplot](https://en.wikipedia.org/wiki/Boxplot)
- 2-d: [Scatterplot](https://en.wikipedia.org/wiki/Scatterplot), [Boxplot y by x](https://en.wikipedia.org/wiki/Boxplot_y_by_x)
- High-D:
  - Multivariate continuous: [Scatterplot matrix](https://en.wikipedia.org/wiki/Scatterplot_matrix), [Parallel coordinates](wikipedia://en/1254148)
  - Multivariate categorical: [Mosaic plot](wikipedia://en/42637526) (see also [Treemapping](https://en.wikipedia.org/wiki/Treemapping))
- Geographical: [Map](https://en.wikipedia.org/wiki/Map)
- Special: [missing value plot](https://en.wikipedia.org/wiki/Missing_value_plot)

### Interaction techniques {#Interaction_techniques}

Mondrian supports Query, Select, and Modify.
