# Well-colored graph

::: {#o1 .subject cue=lead name="Well-colored graph"}

*Image: Complex tripartite graph octahedron.svg.* The graph of an [octahedron](wikipedia://en/80177635) is complete multipartite ($K_{2,2,2}$) and well-colored.

In [graph theory](wikipedia://en/12401), a subfield of mathematics, a **well-colored graph** is an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) for which [greedy coloring](wikipedia://en/21051195) uses the same number of colors regardless of the order in which colors are chosen for its vertices. That is, for these graphs, the [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) (minimum number of colors) and [Grundy number](wikipedia://en/5224898) (maximum number of greedily-chosen colors) are equal.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

The well-colored graphs include the [complete graphs](wikipedia://en/85816) and odd-length [cycle graphs](wikipedia://en/878962) (the graphs that form the exceptional cases to [Brooks' theorem](wikipedia://en/21042117)) as well as the [complete bipartite graphs](wikipedia://en/525320) and [complete multipartite graphs](https://en.wikipedia.org/wiki/Complete_multipartite_graph).

The simplest example of a graph that is not well-colored is a four-vertex path. Coloring the vertices in path order uses two colors, the optimum for this graph. However, coloring the ends of the path first (using the same color for each end) causes the greedy coloring algorithm to use three colors for this graph. Because there exists a non-optimal vertex ordering, the path is not well-colored.

:::

## Complexity {#Complexity}

A graph is well-colored if and only if does not have two vertex orderings for which the greedy coloring algorithm produces different numbers of colors. Therefore, recognizing non-well-colored graphs can be performed within the complexity class [NP](wikipedia://en/21562). On the other hand, a graph $G$ has Grundy number $k$ or more if and only if the graph obtained from $G$ by adding a $(k-1)$-vertex clique is not well-colored. Therefore, by a reduction from the Grundy number problem, it is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) to test whether these two orderings exist. It follows that it is co-NP-complete to test whether a given graph is well-colored.

## Related properties {#Related_properties}

A graph is [hereditarily](wikipedia://en/13552465) well-colored if every [induced subgraph](wikipedia://en/1655188) is well-colored. The hereditarily well-colored graphs are exactly the [cographs](wikipedia://en/1175666), the graphs that do not have a four-vertex path as an induced subgraph.
