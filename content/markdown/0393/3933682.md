# EViews

::: {#o2 .subject cue=lead name="EViews"}

**EViews** is a [statistical package](https://en.wikipedia.org/wiki/Statistical_package) for [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) and MacOS, used mainly for time-series oriented [econometric analysis](wikipedia://en/10390).[^o3] It is developed by Quantitative Micro Software (QMS), now a part of [IHS](https://en.wikipedia.org/wiki/IHS_Inc.). Version 1.0 was released in March 1994, and replaced MicroTSP.[^o4] The [TSP](https://en.wikipedia.org/wiki/TSP_%28econometrics_software%29) software and programming language had been originally developed by [Robert Hall](https://en.wikipedia.org/wiki/Robert_Hall_%28economist%29) in 1965. The current version of EViews is 14, released in June 2024.

:::

## Features {#Features}

EViews can be used for general statistical analysis and econometric analyses, such as cross-section and panel data analysis and [time series](wikipedia://en/406624) estimation and forecasting.[^o6]

EViews combines [spreadsheet](https://en.wikipedia.org/wiki/Spreadsheet) and relational database technology with the traditional tasks found in statistical software, and uses a Windows [GUI](https://en.wikipedia.org/wiki/Graphical_user_interface). This is combined with a [programming language](wikipedia://en/23015) which displays limited [object orientation](https://en.wikipedia.org/wiki/Object-oriented_programming).

EViews allows access to 3rd party time series data from multiple providers including:[^o7] Thomson Reuters Datastream, Moody's Economy.com, Macrobond Financial,[^o8] Haver Analytics,[^o9] and CEIC.

## Data formats {#Data_formats}

EViews relies heavily on a proprietary and undocumented file format for data storage. However, for input and output it supports numerous formats, including [databank format](https://en.wikipedia.org/wiki/Databank_format), [Excel formats](https://en.wikipedia.org/wiki/Microsoft_Excel), [PSPP](wikipedia://en/16653967)/[SPSS](wikipedia://en/179088), [DAP](wikipedia://en/16671308)/[SAS](https://en.wikipedia.org/wiki/SAS_System), [Stata](wikipedia://en/1809002), [RATS](https://en.wikipedia.org/wiki/RATS_%28statistical_package%29), and TSP. EViews can access [ODBC](https://en.wikipedia.org/wiki/ODBC) databases. EViews file formats can be partially opened by [gretl](wikipedia://en/1166251).

## Stationarity of data {#Stationarity_of_data}

EViews helps researchers detect unit roots in their data series. Multiple [unit root tests](wikipedia://en/2473482) are available in the research software, including [Dickey–Fuller](wikipedia://en/2473516), [Phillips–Perron](wikipedia://en/24590400), [Kwiatkowski–Phillips–Schmidt–Shin](wikipedia://en/23453383) and [Elliott, Rothenberg and Stock Point-Optimal](wikipedia://en/37048590) tests.

## Estimation {#Estimation}

EViews helps researchers and professionals to estimate [linear equations](wikipedia://en/17570) and [systems of linear equations](wikipedia://en/113087) models of [time series](wikipedia://en/406624) and [panel data](wikipedia://en/2499813) with various methods. Eviews allows the user to assess econometric results easily.[^o13]
