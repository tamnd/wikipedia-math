# List of statistical software

::: {#o1 .subject cue=lead name="List of statistical software"}

The following is a list of [statistical software](https://en.wikipedia.org/wiki/Statistical_software).

:::

## Open-source {#Open-source}

*Image: Gretl screenshot.png.* [gretl](wikipedia://en/1166251) is an example of an [open-source](https://en.wikipedia.org/wiki/Open-source_license) statistical package

::: {#o3 .entry cue=list-entry name="ADaMSoft"}

- [ADaMSoft](https://en.wikipedia.org/wiki/ADaMSoft) – a generalized statistical software with [data mining](wikipedia://en/42253) algorithms and methods for data management

:::

::: {#o4 .entry cue=list-entry name="ADMB"}

- [ADMB](wikipedia://en/20527175) – a software suite for non-linear statistical modeling based on [C++](https://en.wikipedia.org/wiki/C++) which uses [automatic differentiation](wikipedia://en/734787)

:::

::: {#o5 .entry cue=list-entry name="Chronux"}

- [Chronux](wikipedia://en/19480072) – for neurobiological time series data

:::

::: {#o6 .entry cue=list-entry name="DAP"}

- [DAP](wikipedia://en/16671308) – free replacement for SAS

:::

::: {#o7 .entry cue=list-entry name="Environment for DeveLoping KDD-Applications Supported by Index-Structures"}

- [Environment for DeveLoping KDD-Applications Supported by Index-Structures](https://en.wikipedia.org/wiki/Environment_for_DeveLoping_KDD-Applications_Supported_by_Index-Structures) (ELKI) a [software framework](https://en.wikipedia.org/wiki/Software_framework) for developing [data mining](wikipedia://en/42253) algorithms in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29)

:::

::: {#o8 .entry cue=list-entry name="Epi Info"}

- [Epi Info](wikipedia://en/6244450) – [statistical software](https://en.wikipedia.org/wiki/List_of_statistical_packages) for [epidemiology](wikipedia://en/66997) developed by [Centers for Disease Control and Prevention](https://en.wikipedia.org/wiki/Centers_for_Disease_Control_and_Prevention) (CDC). Apache 2 licensed[^o9]

- [Fityk](https://en.wikipedia.org/wiki/Fityk) – nonlinear regression software (GUI and command line)

- [GNU Octave](wikipedia://en/48707) – programming language very similar to MATLAB with statistical features

::: {#o12 .entry cue=list-entry name="Gretl"}

- [gretl](wikipedia://en/1166251) – gnu regression, econometrics and time-series library

- [intrinsic Noise Analyzer](https://en.wikipedia.org/wiki/Intrinsic_Noise_Analyzer) (iNA) – For analyzing intrinsic fluctuations in biochemical systems

:::

::: {#o14 .entry cue=list-entry name="Jamovi"}

- [jamovi](wikipedia://en/70595459) – A free [GUI](https://en.wikipedia.org/wiki/GUI) and library for R

:::

::: {#o15 .entry cue=list-entry name="JASP"}

- [JASP](https://en.wikipedia.org/wiki/JASP) – A free software alternative to IBM [SPSS](wikipedia://en/179088) Statistics with additional option for Bayesian methods

:::

::: {#o16 .entry cue=list-entry name="JMulTi"}

- [JMulTi](wikipedia://en/6237309) – For [econometric analysis](https://en.wikipedia.org/wiki/Econometric_analysis), specialised in univariate and multivariate [time series](wikipedia://en/406624) analysis

::: {#o17 .entry cue=list-entry name="Just another Gibbs sampler"}

- [Just another Gibbs sampler](wikipedia://en/21845564) (JAGS) – a program for analyzing Bayesian hierarchical models using [Markov chain Monte Carlo](wikipedia://en/236801) developed by Martyn Plummer. It is similar to WinBUGS

:::

::: {#o18 .entry cue=list-entry name="KNIME"}

- [KNIME](https://en.wikipedia.org/wiki/KNIME) – An open source analytics platform built with [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) and [Eclipse](https://en.wikipedia.org/wiki/Eclipse_%28software%29) using modular data pipeline workflows

:::

::: {#o19 .entry cue=list-entry name="LabPlot"}

- [LabPlot](https://en.wikipedia.org/wiki/LabPlot) – A [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source_software), [cross-platform](https://en.wikipedia.org/wiki/Cross-platform) computer program for interactive [scientific plotting](wikipedia://en/19774918), [curve fitting](wikipedia://en/555425), [nonlinear regression](wikipedia://en/1045012), [data processing](https://en.wikipedia.org/wiki/Data_processing) and [data analysis](wikipedia://en/2720954)

:::

::: {#o20 .entry cue=list-entry name="LIBSVM"}

- [LIBSVM](wikipedia://en/40008429) – C++ support vector machine libraries

:::

::: {#o21 .entry cue=list-entry name="Mlpack"}

- [mlpack](https://en.wikipedia.org/wiki/Mlpack) – open-source library for machine learning, exploits C++ language features to provide maximum performance and flexibility while providing a simple and consistent [application programming interface](https://en.wikipedia.org/wiki/Application_programming_interface) (API)

:::

- [R](wikipedia://en/376707) – [free](https://en.wikipedia.org/wiki/Free_software) implementation of the [S (programming language)](wikipedia://en/919313)

:::

  - [Programming with Big Data in R](wikipedia://en/39775648) (pbdR) – a series of R packages enhanced by [SPMD](https://en.wikipedia.org/wiki/SPMD) parallelism for [big data](wikipedia://en/27051151) analysis
  - [R Commander](https://en.wikipedia.org/wiki/R_Commander) – GUI interface for R
  - [Rattle GUI](https://en.wikipedia.org/wiki/Rattle_GUI) – GUI interface for R
  - [Revolution Analytics](wikipedia://en/32415602) – production-grade software for the enterprise big data analytics
  - [RStudio](wikipedia://en/36691501) – GUI interface and development environment for R

::: {#o34 .entry cue=list-entry name="ROOT"}

- [ROOT](https://en.wikipedia.org/wiki/ROOT) – an open-source C++ system for data storage, processing and analysis, developed by CERN and used to find the [Higgs boson](https://en.wikipedia.org/wiki/Higgs_boson)

:::

::: {#o35 .entry cue=list-entry name="Salstat"}

- [Salstat](https://en.wikipedia.org/wiki/Salstat) – menu-driven statistics software

:::

::: {#o37 .entry cue=list-entry name="SciPy"}

- [SciPy](https://en.wikipedia.org/wiki/SciPy) – [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) library for scientific computing that contains the *stats* sub-package which is partly based on the venerable *\|STAT* (a.k.a. *PipeStat*, formerly *UNIX|STAT*) software

:::

  - [scikit-learn](https://en.wikipedia.org/wiki/Scikit-learn) – extends SciPy with a host of machine learning models (classification, clustering, regression, etc.)

::: {#o38 .entry cue=list-entry name="Shogun (toolbox)"}

- [Shogun (toolbox)](https://en.wikipedia.org/wiki/Shogun_%28toolbox%29) – [open-source](https://en.wikipedia.org/wiki/Open-source_license), large-scale machine learning toolbox that provides several SVM (Support Vector Machine) implementations (like libSVM, SVMlight) under a common framework and interfaces to Octave, MATLAB, Python, R

:::

::: {#o39 .entry cue=list-entry name="Simfit"}

:::

::: {#o41 .entry cue=list-entry name="SOFA Statistics"}

- [SOFA Statistics](wikipedia://en/23699874) – desktop GUI program focused on ease of use, learn as you go, and beautiful output

:::

::: {#o42 .entry cue=list-entry name="Stan (software)"}

- [Stan (software)](wikipedia://en/42243853) – open-source package for obtaining Bayesian inference using the No-U-Turn sampler, a variant of [Hamiltonian Monte Carlo](wikipedia://en/32164063). It is somewhat like BUGS, but with a different language for expressing models and a different sampler for sampling from their posteriors

:::

::: {#o43 .entry cue=list-entry name="Statistical Lab"}

- [Statistical Lab](wikipedia://en/2513143) – [R](https://en.wikipedia.org/wiki/R_programming_language)-based and focusing on educational purposes

- [TOPCAT (software)](https://en.wikipedia.org/wiki/TOPCAT_%28software%29) – interactive graphical analysis and manipulation package for astronomers that understands [FITS](https://en.wikipedia.org/wiki/FITS), VOTable and [CDF](https://en.wikipedia.org/wiki/Common_Data_Format) formats.

:::

::: {#o45 .entry cue=list-entry name="Torch (machine learning)"}

- [Torch (machine learning)](https://en.wikipedia.org/wiki/Torch_%28machine_learning%29) – a [deep learning](https://en.wikipedia.org/wiki/Deep_learning) software library written in [Lua (programming language)](https://en.wikipedia.org/wiki/Lua_%28programming_language%29)
