# Tisserand

::: {#o1 .subject cue=lead name="Tisserand"}

**Tisserand** is a French occupational surname meaning "weaver". Notable people with the surname include:

:::

- [Félix Tisserand](https://en.wikipedia.org/wiki/Félix_Tisserand) (1845–1896), French astronomer
- [Marcel Tisserand](https://en.wikipedia.org/wiki/Marcel_Tisserand) (b. 1993), Congolese footballer
