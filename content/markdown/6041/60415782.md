# Generalized Cohen–Macaulay ring

::: {#o1 .subject cue=lead name="Generalized Cohen–Macaulay ring"}

In [algebra](wikipedia://en/18716923), a **generalized Cohen–Macaulay ring** is a commutative Noetherian [local ring](wikipedia://en/153391) $(A, \mathfrak{m})$ of [Krull dimension](wikipedia://en/56079) *d* > 0 that satisfies any of the following equivalent conditions:[^o2][^o3]

:::

- For each integer $i = 0, \dots, d - 1$, the length of the *i*-th [local cohomology](wikipedia://en/3212091) of *A* is finite:

$$\operatorname{length}_A(\operatorname{H}^i_{\mathfrak{m}}(A)) < \infty.$$

- $\sup_Q (\operatorname{length}_A(A/Q) - e(Q)) < \infty$ where the sup is over all [parameter ideals](https://en.wikipedia.org/wiki/Parameter_ideal) $Q$ and $e(Q)$ is the [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_of_a_module) of $Q$.
- There is an $\mathfrak{m}$-[primary ideal](wikipedia://en/3021435) $Q$ such that for each system of parameters $x_1, \dots, x_d$ in $Q$, $(x_1, \dots, x_{d-1}) : x_d = (x_1, \dots, x_{d-1}) : Q.$
- For each prime ideal $\mathfrak{p}$ of $\widehat{A}$ that is not $\mathfrak{m} \widehat{A}$, $\dim \widehat{A}_{\mathfrak{p}} + \dim \widehat{A}/\mathfrak{p} = d$ and $\widehat{A}_{\mathfrak{p}}$ is [Cohen–Macaulay](wikipedia://en/497407).

The last condition implies that the localization $A_\mathfrak{p}$ is Cohen–Macaulay for each prime ideal $\mathfrak{p} \ne \mathfrak{m}$.

A standard example is the local ring at the vertex of an affine cone over a smooth [projective variety](wikipedia://en/320469). Historically, the notion grew up out of the study of a [Buchsbaum ring](wikipedia://en/34961349), a Noetherian local ring *A* in which $\operatorname{length}_A(A/Q) - e(Q)$ is constant for $\mathfrak{m}$-primary ideals $Q$; see the introduction of.[^o4]
