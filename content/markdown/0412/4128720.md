# Cyclic module

::: {#o1 .subject cue=lead name="Cyclic module"}

In [mathematics](wikipedia://en/18831), more specifically in [ring theory](wikipedia://en/250424), a **cyclic module** or **monogenous module**[^o2] is a [module over a ring](wikipedia://en/276410) that is generated by one element. The concept is a generalization of the notion of a [cyclic group](wikipedia://en/52327), that is, an [Abelian group](wikipedia://en/2974) (i.e. **Z**-module) that is generated by one element.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A left *R*-module *M* is called **cyclic** if *M* can be generated by a single element i.e. *M* = (*x*) = *Rx* = {*rx* | *r* ∈ *R*} for some *x* in *M*. Similarly, a right *R*-module *N* is cyclic if *N* = *yR* for some *y* ∈ *N*.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- 2**Z** as a **Z**-module is a cyclic module.
- In fact, every [cyclic group](wikipedia://en/52327) is a cyclic **Z**-module.
- Every [simple](wikipedia://en/29430) *R*-module *M* is a cyclic module since the [submodule](https://en.wikipedia.org/wiki/Submodule) generated by any non-zero element *x* of *M* is necessarily the whole module *M*. In general, a module is simple if and only if it is nonzero and is generated by each of its nonzero elements.[^o7]
- If the ring *R* is considered as a left module over itself, then its cyclic submodules are exactly its left [principal ideals](wikipedia://en/145126) as a ring. The same holds for *R* as a right *R*-module, [mutatis mutandis](wikipedia://en/742665).
- If *R* is *F*\[*x*\], the [ring of polynomials](https://en.wikipedia.org/wiki/Ring_of_polynomials) over a [field](wikipedia://en/10603) *F*, and *V* is an *R*-module which is also a [finite-dimensional](https://en.wikipedia.org/wiki/Dimension_%28linear_algebra%29) [vector space](wikipedia://en/32370) over *F*, then the [Jordan blocks](https://en.wikipedia.org/wiki/Jordan_block) of *x* acting on *V* are cyclic submodules. (The Jordan blocks are all [isomorphic](wikipedia://en/14828) to *F*\[*x*\] / (*x* − *λ*)<sup>*n*</sup>; there may also be other cyclic submodules with different [annihilators](wikipedia://en/328684); see below.)

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Given a cyclic *R*-module *M* that is generated by *x*, there exists a canonical isomorphism between *M* and *R* / Ann<sub>*R*</sub> *x*, where Ann<sub>*R*</sub> *x* denotes the [annihilator](wikipedia://en/328684) of *x* in *R*.

:::
