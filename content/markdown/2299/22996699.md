# Multidimensional parity-check code

::: {#o1 .subject cue=lead name="Multidimensional parity-check code"}

A **multidimensional parity-check code (MDPC)** is a type of [error-correcting code](https://en.wikipedia.org/wiki/Error-correcting_code) that generalizes two-dimensional [parity checks](https://en.wikipedia.org/wiki/Parity_check) to higher dimensions. It was developed as an extension of simple parity check methods used in [magnetic recording systems](https://en.wikipedia.org/wiki/Magnetic_tape) and [radiation-hardened](https://en.wikipedia.org/wiki/Radiation_hardening) [memory designs](https://en.wikipedia.org/wiki/Memory_architecture).[^o2]

:::

## Overview {#Overview}

In an MDPC code, information bits are organized into an $N$-dimensional structure, where each [bit](https://en.wikipedia.org/wiki/Bit) is protected by $N$ [parity bits](wikipedia://en/194467). Each parity bit is calculated along a different dimensional axis. The code can be characterized by its *dimension vector* $r = [r_1, r_2, \cdots, r_n ]$, where $r_i$ defines the size of the block or multi-block in the $i$th dimension. The code length $c$ can be expressed as

$$c = \prod_{n=1}^{N} r_n$$

while the number of information bits $d$ is given by

$d = \prod_{n=1}^{N} (r_n - 1)$.[^o4]

### Reduced generator matrices {#Reduced_generator_matrices}

*Reduced generator matrices* eliminate redundant [parity bits](https://en.wikipedia.org/wiki/Parity_bits) while maintaining error correction capabilities. This modification increases the code rate without significantly degrading performance. The code rate $R$ for a reduced MDPC is given by

$$R = \frac{d}{c} = \frac{\prod_{n=1}^{N} (r_n - 1)}{\prod_{n=1}^{N} r_n}.$$

The reduced generator matrix can be created using systematic construction methods, resulting in more efficient encoding processes compared to traditional parity check codes.

The following [pseudocode](https://en.wikipedia.org/wiki/Pseudocode) shows how to generate a reduced generator matrix:[^o7]

**function** function\_name **is** *// Initialize G with identity matrix augmented with ones column* G ← \[I\_{r<sub>1</sub>-1} | 1\_{(r<sub>1</sub>-1)×1}\] **for** n ← 2 to N **do** *// Update G with Kronecker product* G ← I\_{r\_n-1} ⊗ G *// Calculate product of previous dimensions* x ← Π<sub>i=1</sub><sup>n-1</sup>(r<sub>i</sub> - 1) *// Create temporary matrix with ones column and identity* G\_tmp ← 1\_{(r\_n-1)×1} ⊗ I\_x *// Augment G with temporary matrix* G ← \[G | G\_tmp\] **return** G **end function**

### Decoding algorithms {#Decoding_algorithms}

Decoding in MDPC systems typically employs an [iterative algorithm](https://en.wikipedia.org/wiki/Iterative_algorithm) based on *Failed Dimension Markers (FDM)*, which indicate the number of parity check failures associated with each information bit. The FDM-based decoding process works by identifying bits with the highest probability of error and iteratively attempting corrections until either all errors are resolved or a maximum iteration limit is reached.[^o7]

## Applications {#Applications}

MDPC codes have applications in scenarios where short block lengths are required, such as [real-time communications](https://en.wikipedia.org/wiki/Real-time_communication) systems and [memory protection](https://en.wikipedia.org/wiki/Memory_protection) schemes. They offer several advantages over other [error-correcting codes](https://en.wikipedia.org/wiki/Error-correcting_codes), including positive code gain at low [signal-to-noise ratios](wikipedia://en/41706) and simpler implementation complexity compared to LDPC codes. The level of error protection can be adjusted by modifying the number of dimensions or the size of each dimension, allowing for flexibility in design trade-offs between code rate and error correction capability.[^o10]
