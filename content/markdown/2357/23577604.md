# Pregaussian class

::: {#o1 .subject cue=lead name="Pregaussian class"}

In [probability theory](wikipedia://en/23542), a **pregaussian class** or **pregaussian set** of functions is a set of functions, [square integrable](https://en.wikipedia.org/wiki/Square_integrable) with respect to some [probability measure](wikipedia://en/45437), such that there exists a certain [Gaussian process](wikipedia://en/302944), indexed by this set, satisfying the conditions below.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a [probability space](wikipedia://en/43325) (*S*, Σ, *P*), denote by $L^2_P(S)$ a [set](wikipedia://en/27553) of square integrable with respect to *P* functions $f:S\to R$, that is

$$\int f^2 \, dP<\infty$$

Consider a set $\mathcal{F}\subset L^2_P(S)$. There exists a [Gaussian process](wikipedia://en/302944) $G_P$, indexed by $\mathcal{F}$, with mean 0 and covariance

$$\operatorname{Cov} (G_P(f),G_P(g))= E G_P(f)G_P(g)=\int fg\, dP-\int f\,dP \int g\,dP\text{ for }f,g\in\mathcal{F}$$

Such a process exists because the given covariance is positive definite. This covariance defines a semi-inner product as well as a [pseudometric](wikipedia://en/68503) on $L^2_P(S)$ given by

$$\varrho_P(f,g)=(E(G_P(f)-G_P(g))^2)^{1/2}$$

::: {#o4 .definition cue=inline-head name="Definition"}

**Definition** A class $\mathcal{F}\subset L^2_P(S)$ is called **pregaussian** if for each $\omega\in S,$ the function $f\mapsto G_P(f)(\omega)$ on $\mathcal{F}$ is bounded, $\varrho_P$-uniformly continuous, and prelinear.

:::

:::

## Brownian bridge {#Brownian_bridge}

The $G_P$ process is a generalization of the [brownian bridge](wikipedia://en/1843777). Consider $S=[0,1],$ with *P* being the [uniform measure](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29). In this case, the $G_P$ process indexed by the [indicator functions](wikipedia://en/240790) $I_{[0,x]}$, for $x\in [0,1],$ is in fact the standard [brownian bridge](wikipedia://en/1843777) *B*(*x*). This set of the indicator functions is pregaussian, moreover, it is the [Donsker class](https://en.wikipedia.org/wiki/Donsker_class).
