# Zimmert set

::: {#o1 .subject cue=lead name="Zimmert set"}

In mathematics, a **Zimmert set** is a set of positive integers associated with the structure of quotients of [hyperbolic three-space](https://en.wikipedia.org/wiki/Hyperbolic_3-space) by a [Bianchi group](wikipedia://en/3238478).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Fix an integer *d* and let *D* be the discriminant of the imaginary [quadratic field](wikipedia://en/454781) **Q**(√-*d*). The *Zimmert set* *Z*(*d*) is the set of positive integers *n* such that 4*n*<sup>2</sup> \< -D-3 and n ≠ 2; *D* is a [quadratic non-residue](https://en.wikipedia.org/wiki/Quadratic_non-residue) of all odd primes in *d*; *n* is odd if *D* is not congruent to 5 modulo 8. The cardinality of *Z*(*d*) may be denoted by *z*(*d*).

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Property"}

## Property {#Property}

For all but a finite number of *d* we have *z*(*d*) > 1: indeed this is true for all *d* > 10<sup>476</sup>.[^o6]

:::

::: {#o8 .application cue=heading name="Application"}

## Application {#Application}

Let Γ<sub>*d*</sub> denote the Bianchi group PSL(2,*O*<sub>*d*</sub>), where *O*<sub>*d*</sub> is the [ring of integers](wikipedia://en/460613) of. As a subgroup of PSL(2,**C**), there is an action of Γ<sub>*d*</sub> on hyperbolic 3-space *H*<sub>3</sub>, with a [fundamental domain](wikipedia://en/469365). It is a theorem that there are only finitely many values of *d* for which Γ<sub>*d*</sub> can contain an [arithmetic subgroup](wikipedia://en/630741) *G* for which the quotient *H*<sub>3</sub>/*G* is a [link complement](https://en.wikipedia.org/wiki/Link_complement). Zimmert sets are used to obtain results in this direction: *z*(*d*) is a lower bound for the rank of the largest [free](wikipedia://en/59735) [quotient](wikipedia://en/11526) of Γ<sub>*d*</sub>[^o9] and so the result above implies that almost all Bianchi groups have non-[cyclic](wikipedia://en/52327) free quotients.[^o6]

:::
