# Ecological regression

::: {#o1 .subject cue=lead name="Ecological regression"}

**Ecological regression** is a statistical technique which runs regression on aggregates, often used in [political science](https://en.wikipedia.org/wiki/Political_science) and [history](https://en.wikipedia.org/wiki/History) to estimate group [voting behavior](https://en.wikipedia.org/wiki/Voting_behavior) from [aggregate data](wikipedia://en/6937928).[^o2]

:::

For example, in a hypothetical election in the [United States](https://en.wikipedia.org/wiki/United_States), if counties have a known Democratic vote (in percentage) D, and a known percentage of Catholics, C, then running a [linear regression](wikipedia://en/48758386) of dependent variable D against independent variable C will give D = a + bC. If the regression gives D = .22 + .45C for example, then the estimated Catholic vote (C = 1) is 67% Democratic and the non-Catholic vote (C = 0) is 22% Democratic. The technique has been often used in [litigation](https://en.wikipedia.org/wiki/Litigation) brought under the [Voting Rights Act](https://en.wikipedia.org/wiki/Voting_Rights_Act) of 1965 to see how blacks and whites voted.[^o3]
