# Devex algorithm

::: {#o1 .subject cue=lead name="Devex algorithm"}

In applied mathematics, the **devex algorithm** is a pivot rule for the [simplex method](https://en.wikipedia.org/wiki/Simplex_method) developed by Paula M. J. Harris.[^o2] It identifies the steepest-edge approximately in its search for the optimal solution.[^o3]

:::
