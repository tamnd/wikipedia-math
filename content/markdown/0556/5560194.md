# Dual object

::: {#o1 .subject cue=lead name="Dual object"}

In [category theory](wikipedia://en/5869), a branch of [mathematics](wikipedia://en/18831), a **dual object** is an analogue of a [dual vector space](https://en.wikipedia.org/wiki/Dual_vector_space) from [linear algebra](wikipedia://en/18422) for [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) in arbitrary [monoidal categories](wikipedia://en/330604). It is only a partial generalization, based upon the categorical properties of [duality](wikipedia://en/609737) for [finite-dimensional](wikipedia://en/38267) [vector spaces](wikipedia://en/32370). An object admitting a dual is called a **dualizable object**. In this formalism, infinite-dimensional vector spaces are not dualizable, since the dual vector space *V*<sup>∗</sup> doesn't satisfy the axioms.[^o2] Often, an object is dualizable only when it satisfies some finiteness or [compactness](wikipedia://en/6042) property.[^o3]

:::

A [category](wikipedia://en/53759) in which each object has a dual is called **autonomous** or **rigid**. The category of finite-dimensional vector spaces with the standard [tensor product](wikipedia://en/30844) is rigid, while the [category of all vector spaces](https://en.wikipedia.org/wiki/Category_of_vector_spaces) is not.

## Motivation {#Motivation}

Let *V* be a finite-dimensional vector space over some [field](wikipedia://en/10603) *K*. The standard notion of a [dual vector space](https://en.wikipedia.org/wiki/Dual_vector_space) *V*<sup>∗</sup> has the following property: for any *K*-vector spaces *U* and *W* there is an [adjunction](wikipedia://en/53991) Hom<sub>*K*</sub>(*U* ⊗ *V*,*W*) = Hom<sub>*K*</sub>(*U*, *V*<sup>∗</sup> ⊗ *W*), and this characterizes *V*<sup>∗</sup> up to a unique [isomorphism](wikipedia://en/14828). This expression makes sense in any category with an appropriate replacement for the [tensor product](wikipedia://en/30844) of vector spaces. For any [monoidal category](wikipedia://en/330604) (*C*, ⊗) one may attempt to define a dual of an object *V* to be an object *V*<sup>∗</sup> ∈ *C* with a [natural isomorphism](https://en.wikipedia.org/wiki/Natural_isomorphism) of [bifunctors](https://en.wikipedia.org/wiki/Bifunctor)

Hom<sub>*C*</sub>((–)<sub>1</sub> ⊗ *V*, (–)<sub>2</sub>) → Hom<sub>*C*</sub>((–)<sub>1</sub>, *V*<sup>∗</sup> ⊗ (–)<sub>2</sub>)

For a well-behaved notion of duality, this map should be not only natural in the sense of category theory, but also respect the monoidal structure in some way.[^o2] An actual definition of a dual object is thus more complicated.

In a [closed monoidal category](wikipedia://en/1396924) *C*, i.e. a monoidal category with an [internal Hom](https://en.wikipedia.org/wiki/Internal_Hom) functor, an alternative approach is to simulate the standard definition of a dual vector space as a space of [functionals](wikipedia://en/1374948). For an object *V* ∈ *C* define *V*<sup>∗</sup> to be $\underline{\mathrm{Hom}}_C(V, \mathbb{1}_C)$, where 1<sub>*C*</sub> is the monoidal identity. In some cases, this object will be a dual object to *V* in a sense above, but in general it leads to a different theory.

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

Consider an object $X$ in a [monoidal category](wikipedia://en/330604) $(\mathbf{C},\otimes, I, \alpha, \lambda, \rho)$. The object $X^*$ is called a **left dual** of $X$ if there exist two morphisms

$\eta:I\to X\otimes X^*$, called the **coevaluation**, and $\varepsilon:X^*\otimes X\to I$, called the **evaluation**,

The object $X$ is called the **right dual** of $X^*$. This definition is due to (Dold Puppe 1980).

Left duals are canonically isomorphic when they exist, as are right duals. When *C* is [braided](wikipedia://en/1470466) (or [symmetric](wikipedia://en/3865249)), every left dual is also a right dual, and vice versa.

If we consider a monoidal category as a [bicategory](https://en.wikipedia.org/wiki/Bicategory) with one object, a dual pair is exactly an [adjoint pair](https://en.wikipedia.org/wiki/Adjoint_pair).

## Examples {#Examples}

- Consider a monoidal category (Vect<sub>*K*</sub>, ⊗<sub>*K*</sub>) of vector spaces over a field *K* with the standard tensor product. A space *V* is dualizable if and only if it is finite-dimensional, and in this case the dual object *V*<sup>∗</sup> coincides with the standard notion of a [dual vector space](https://en.wikipedia.org/wiki/Dual_vector_space).
- Consider a monoidal category (Mod<sub>*R*</sub>, ⊗<sub>*R*</sub>) of [modules](wikipedia://en/276410) over a [commutative ring](wikipedia://en/61346) *R* with the standard [tensor product](wikipedia://en/2993836). A module *M* is dualizable if and only if it is a [finitely generated](wikipedia://en/326430) [projective module](wikipedia://en/364488). In that case the dual object *M*<sup>∗</sup> is also given by the module of [homomorphisms](wikipedia://en/474118) Hom<sub>*R*</sub>(*M*, *R*).[^o11]
- Consider a [homotopy category](wikipedia://en/2040756) of [pointed](wikipedia://en/1236666) [spectra](wikipedia://en/1033697) Ho(Sp) with the [smash product](wikipedia://en/698010) as the monoidal structure. If *M* is a [compact](wikipedia://en/6042) [neighborhood retract](https://en.wikipedia.org/wiki/Deformation_retract) in $\mathbb{R}^n$ (for example, a compact smooth [manifold](wikipedia://en/2073470)), then the corresponding pointed spectrum Σ<sup>∞</sup>(*M*<sup>\+</sup>) is dualizable. This is a consequence of [Spanier–Whitehead duality](wikipedia://en/3108602), which implies in particular [Poincaré duality](wikipedia://en/540732) for compact manifolds.[^o2]
- The category $\mathrm{End}(\mathbf{C})$ of [endofunctors](https://en.wikipedia.org/wiki/Endofunctor) of a category $\mathbf{C}$ is a monoidal category under composition of [functors](wikipedia://en/10987). A functor $F$ is a left dual of a functor $G$ if and only if $F$ is left adjoint to $G$.[^o12]

:::

## Categories with duals {#Categories_with_duals}

A monoidal category where every object has a left (respectively right) dual is sometimes called a **left** (respectively right) **autonomous** category. [Algebraic geometers](wikipedia://en/1997) call it a **left** (respectively right) **[rigid category](wikipedia://en/25383437)**. A monoidal category where every object has both a left and a right dual is called an **[autonomous category](https://en.wikipedia.org/wiki/Autonomous_category)**. An autonomous category that is also [symmetric](wikipedia://en/3865249) is called a **[compact closed category](wikipedia://en/5557623)**.

## Traces {#Traces}

Any endomorphism *f* of a dualizable object admits a [trace](wikipedia://en/62338906), which is a certain endomorphism of the monoidal unit of *C*. This notion includes, as very special cases, the [trace in linear algebra](wikipedia://en/43270) and the [Euler characteristic](wikipedia://en/148420) of a [chain complex](wikipedia://en/138404).
