# Birkhoff's theorem (equational logic)

::: {#o1 .subject cue=lead name="Birkhoff's theorem"}

In [logic](wikipedia://en/46426065), **Birkhoff's theorem** in [equational logic](wikipedia://en/33522862) states that an equality t = u is a [semantic consequence](https://en.wikipedia.org/wiki/Semantic_consequence) of a set of [equalities](wikipedia://en/90446) E, if and only if t = u can be proven from the set of equalities.[^o2] It is named after [Garrett Birkhoff](wikipedia://en/1180916).

:::
