# Increasing process

::: {#o1 .subject cue=lead name="Increasing process"}

An **increasing process** is a [stochastic process](wikipedia://en/47895)...

:::

$$(X_t)_{t \in M}$$

...where the [random variables](wikipedia://en/25685) $X_t$ which make up the process are increasing [almost surely](wikipedia://en/351908) and [adapted](wikipedia://en/6583420):

$$0=X_0 \leq X_{t_1} \leq \cdots .$$

A **continuous increasing process** is such a process where the set $M$ is continuous.

Consider a stochastic process $(\mathrm{X}_t)$ satisfying $X_t \leq X_s$ a.s. for all $t \leq s$ My question is: Does there exist a modification $\breve{X}$ of ,$X$ which almost surely has increasing sample paths $t \mapsto \breve{X}_t(\omega)$?[^o2]
