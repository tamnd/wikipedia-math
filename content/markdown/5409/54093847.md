# Delsarte–Goethals code

::: {#o1 .subject cue=lead name="Delsarte–Goethals code"}

The **Delsarte–Goethals code** is a type of [error-correcting code](https://en.wikipedia.org/wiki/Error-correcting_code).

:::

## History {#History}

The concept was introduced by mathematicians Philippe Delsarte and J.-M. Goethals in their published paper.[^o3][^o4]

A new proof of the properties of the Delsarte–Goethals code was published in 1970.[^o5]

## Function {#Function}

The Delsarte–Goethals code DG(*m*,*r*) for even *m* ≥ 4 and 0 ≤ *r* ≤ *m*/2 − 1 is a binary, [non-linear code](https://en.wikipedia.org/wiki/Non-linear_code) of length $2^{m}$, size $2^{r(m-1)+2m}$ and [minimum distance](wikipedia://en/1134659#The_distance_d) $2^{m-1} - 2^{m/2-1+r}$

The code sits between the [Kerdock code](https://en.wikipedia.org/wiki/Kerdock_code) and the second-order [Reed–Muller codes](wikipedia://en/2032752). More precisely, we have

$$K(m) \subseteq DG(m,r) \subseteq RM(2,m)$$

When *r* = 0, we have DG(*m*,*r*) = *K*(*m*) and when *r* = *m*/2 − 1 we have DG(*m*,*r*) = RM(2,*m*).

For *r* = *m*/2 − 1 the Delsarte–Goethals code has strength 7 and is therefore an [orthogonal array](wikipedia://en/17887653) OA($2^{3m-1}, 2^m, \mathbb{Z}_2, 7)$.[^o7][^o8]
