# Class logic

::: {#o1 .subject cue=lead name="Class logic"}

**Class logic** is a [logic](wikipedia://en/46426065) in its broad sense, whose objects are called classes. In a narrower sense, one speaks of a class logic only if [classes](wikipedia://en/20696) are described by a property of their elements. This class logic is thus a generalization of [set theory](wikipedia://en/27553), which allows only a limited consideration of classes.

:::

## Class logic in the strict sense {#Class_logic_in_the_strict_sense}

The first class logic in the strict sense was created by [Giuseppe Peano](wikipedia://en/13043) in 1889 as the basis for his arithmetic ([Peano Axioms](https://en.wikipedia.org/wiki/Peano_Axioms)). He introduced the class term, which formally correctly describes classes through a property of their elements. Today the class term is denoted in the form {x|A(x)}, where A(x) is an arbitrary statement, which all class members x meet. Peano axiomatized the class term for the first time and used it fully. [Gottlob Frege](wikipedia://en/48416) also tried establishing the arithmetic logic with class terms in 1893; [Bertrand Russell](wikipedia://en/4163) discovered a conflict in it in 1902 which became known as [Russell's paradox](wikipedia://en/46095). As a result, it became generally known that you can not safely use class terms.

To solve the problem, Russell developed his [type theory](wikipedia://en/40282) from 1903 to 1908, which allowed only a restricted use of class terms. Among mathematicians, Russell's type theory was superseded by an alternative axiomatization of set theory initiated by [Ernst Zermelo](wikipedia://en/178655). This axiomatization is not a class logic in the narrower sense, because in its present form (Zermelo-Fraenkel or NBG) it does not axiomatize the class term, but uses it only in practice as a useful notation. [Willard Van Orman Quine](wikipedia://en/33833) described a set theory [New Foundations](wikipedia://en/945957) (NF) in 1937, based on a theory of types which was intended as an alternative to Zermelo-Fraenkel. In 1940 Quine advanced NF to Mathematical Logic (ML). Since the [antinomy](wikipedia://en/3175) of [Burali-Forti](https://en.wikipedia.org/wiki/Burali-Forti) was derived in the first version of ML,[^o3] Quine clarified ML, retaining the widespread use of classes, and took up a proposal by Hao Wang[^o4] introducing in 1963 in his theory of {x|A(x)} as a virtual class, so that classes are although not yet full-fledged terms, but sub-terms in defined contexts.[^o5]

After Quine, [Arnold Oberschelp](wikipedia://en/62923277) developed the first fully functional modern axiomatic class logic starting in 1974. It is a consistent extension of [predicate logic](https://en.wikipedia.org/wiki/Predicate_logic) and allows the unrestricted use of class terms (such as Peano).[^o6] It uses all classes that produce antinomies of [naive set theory](wikipedia://en/4944) as a term. This is possible because the theory assumes no existence axioms for classes. It presupposes in particular any number of axioms, but can also take those and syntactically correct to formulate in the traditionally simple design with class terms. For example, the Oberschelp set theory developed the [Zermelo–Fraenkel set theory](wikipedia://en/152214) within the framework of class logic.[^o7] Three principles guarantee that cumbersome ZF formulas are translatable into convenient classes formulas; guarantee a class logical increase in the ZF language they form without quantities axioms together with the axioms of predicate logic an axiom system for a simple logic of general class.[^o8]

The principle of abstraction (*Abstraktionsprinzip*) states that classes describe their elements via a logical property:

$$\forall y\colon (y \in \{x\mid A(x)\} \iff A(y))$$

The principle of extensionality (*Extensionalitätsprinzip* ) describes the equality of classes by matching their elements and eliminates the [axiom of extensionality](wikipedia://en/52376) in ZF:

$$A=B \iff\forall x\colon (x\in A \iff x\in B)$$

The [principle of comprehension](https://en.wikipedia.org/wiki/Principle_of_comprehension) (*Komprehensionsprinzip*) determines the existence of a class as an element:

$$\{x\mid A(x)\}\in B\iff \exists y\colon (y=\{x\mid A(x)\}\land y\in B)$$
