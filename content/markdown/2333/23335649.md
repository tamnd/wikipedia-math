# Canonical map

For the canonical map of an algebraic variety into projective space, see Canonical bundle#Canonical maps.

::: {#o1 .subject cue=lead name="Canonical map"}

In [mathematics](wikipedia://en/18831), a **canonical map**, also called a **natural map**, is a [map](wikipedia://en/516931) or [morphism](wikipedia://en/27716891) between objects that arises naturally from the definition or the construction of the objects. Often, it is a map which preserves the widest amount of structure. A choice of a canonical map sometimes depends on a convention (e.g., a sign convention).

:::

A closely related notion is that of a **structure map** or **structure morphism**: the map or morphism that comes with the given structure on the object. These are also sometimes called canonical maps.

A [canonical isomorphism](https://en.wikipedia.org/wiki/Canonical_isomorphism) is a canonical map that is also an [isomorphism](wikipedia://en/14828) (that is, [invertible](wikipedia://en/14907)). In some contexts, it might be necessary to address an issue of *choices* of canonical maps or canonical isomorphisms; for a typical example, see [prestack](wikipedia://en/39547490#Definition).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- If $N$ is a [normal subgroup](wikipedia://en/21918) of a [group](wikipedia://en/19447) $G$, then there is a canonical [surjective](https://en.wikipedia.org/wiki/Surjective) [group homomorphism](wikipedia://en/12396) from $G$ to the [quotient group](wikipedia://en/11526) $G / N$, that sends an element $g$ to the [coset](wikipedia://en/98759) determined by $g$.
- If $I$ is an [ideal](wikipedia://en/25977) of a [ring](wikipedia://en/48404) $R$, then there is a canonical surjective [ring homomorphism](wikipedia://en/26411) from $R$ onto the [quotient ring](wikipedia://en/184635) $R / I$ that sends an element $r$ to its coset $I + r$.
- If $S$ is a multiplicative set in commutative ring $R$, then there is a canonical ring homomorphism from $R$ to the [localization](wikipedia://en/252216) $S^{-1}R$ that sends element $r$ to $r/1$ in the localization.
- If $R_{f}$ is the localization of commutative ring $R$ by $S = \{1, f, f^{2}, f^{3}, ...\}$, and $R_{p}$ is the localization of $R$ by $S = R \backslash p$, where $p$ is a prime ideal such that $f \notin p$, there is a canonical ring homomorphism $\alpha : R_{f} \to R_{p}$ mapping $a/f^{n}$ as an element of $R_{f}$ to $a/f^{n}$ as an element of $R_{p}$. If φ is the canonical map $R \to R_{p}$ and ψ is the canonical map $R \to R_{f}$, then α is the unique map such that $\varphi = \alpha \circ \psi$.
- If $V$ is a finite-dimenstional [vector space](wikipedia://en/32370), then there is a canonical map from $V$ to the second [dual space](wikipedia://en/7988) of $V$, that sends a vector $v$ to the [linear functional](wikipedia://en/214137) $f_{v}$ defined by $f_{v}(\lambda) = \lambda(v)$.
- If $f: R \to S$ is a homomorphism between [commutative rings](wikipedia://en/61346), then $S$ can be viewed as an [algebra](https://en.wikipedia.org/wiki/Algebra_over_a_ring) over $R$. The ring homomorphism $f$ is then called the structure map (for the algebra structure). The corresponding map on the [prime spectra](https://en.wikipedia.org/wiki/Prime_spectrum) $f^{*}: \operatorname{Spec}(S) \to \operatorname{Spec}(R)$ is also called the structure map. More generally, a [scheme](wikipedia://en/364754) *X* over a scheme *S* is one equipped with a structure [morphism](wikipedia://en/7482797) $X \to S$; for a scheme over a field *k* (e.g., a [variety](wikipedia://en/248808)), this is a morphism $X \to \operatorname{Spec}(k)$.
- If $E$ is a [vector bundle](wikipedia://en/276524) over a [topological space](wikipedia://en/30450) $X$, then the projection map from $E$ to $X$ is the structure map.
- In [topology](wikipedia://en/29954), a canonical map is a function $f$ mapping a set $X \to X / R$ ($X \bmod R$), where $R$ is an equivalence relation on $X$, that takes each $x$ in $X$ to the [equivalence class](wikipedia://en/9260) $[x] \bmod R$.[^o4]
