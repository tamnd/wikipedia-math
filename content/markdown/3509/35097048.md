# Moment closure

::: {#o1 .subject cue=lead name="Moment closure"}

In [probability theory](wikipedia://en/23542), **moment closure** is an approximation method used to estimate [moments](wikipedia://en/368684) of a [stochastic process](wikipedia://en/47895).[^o2]

:::

## Introduction {#Introduction}

Typically, [differential equations](https://en.wikipedia.org/wiki/Differential_equations) describing the *i-*th moment will depend on the *(i + 1)*-st moment. To use moment closure, a level is chosen past which all [cumulants](wikipedia://en/359684) are set to zero. This leaves a resulting closed system of equations which can be solved for the moments.[^o2] The approximation is particularly useful in models with a very large [state space](https://en.wikipedia.org/wiki/State_space), such as stochastic [population models](wikipedia://en/11397469).[^o2]

## History {#History}

The moment closure approximation was first used by Goodman[^o5] and Whittle[^o6][^o7] who set all third and higher-order cumulants to be zero, approximating the population distribution with a [normal distribution](wikipedia://en/21462).[^o2]

In 2006, Singh and Hespanha proposed a closure which approximates the population distribution as a [log-normal distribution](wikipedia://en/102476) to describe biochemical reactions.[^o8]

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

The approximation has been used successfully to model the spread of the [Africanized bee](https://en.wikipedia.org/wiki/Africanized_bee) in the Americas,[^o11] [nematode infection](https://en.wikipedia.org/wiki/Nematode_infection) in [ruminants](https://en.wikipedia.org/wiki/Ruminant).[^o12] and [quantum tunneling](https://en.wikipedia.org/wiki/Quantum_tunneling) in [ionization](https://en.wikipedia.org/wiki/Ionization) experiments.[^o13]

:::
