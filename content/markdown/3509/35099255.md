# Fenchel–Moreau theorem

*Image: Upper semi.svg.* A function that is not [lower semi-continuous](https://en.wikipedia.org/wiki/Lower_semi-continuous). By the Fenchel-Moreau theorem, this function is not equal to its [biconjugate](https://en.wikipedia.org/wiki/Biconjugate).

::: {#o1 .subject cue=lead name="Fenchel–Moreau theorem"}

In [convex analysis](wikipedia://en/3237201), the **Fenchel–Moreau theorem** (named after [Werner Fenchel](wikipedia://en/4784468) and [Jean Jacques Moreau](https://en.wikipedia.org/wiki/Jean_Jacques_Moreau)) or **Fenchel biconjugation theorem** (or just **biconjugation theorem**) is a [theorem](wikipedia://en/30977) which gives [necessary and sufficient conditions](https://en.wikipedia.org/wiki/Necessary_and_sufficient_conditions) for a function to be equal to its [biconjugate](https://en.wikipedia.org/wiki/Biconjugate). This is in contrast to the general property that for any function $f^{**} \leq f$.[^o2][^o3] This can be seen as a generalization of the [bipolar theorem](wikipedia://en/35128576).[^o2] It is used in [duality theory](wikipedia://en/3372717) to prove [strong duality](wikipedia://en/34390810) (via the [perturbation function](wikipedia://en/33430345)).

:::

::: {#o5 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $(X,\tau)$ be a [Hausdorff](wikipedia://en/13637) [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space), for any [extended real](https://en.wikipedia.org/wiki/Extended_real) valued function $f: X \to \mathbb{R} \cup \{\pm \infty\}$ it follows that $f = f^{**}$ if and only if one of the following is true

1. $f$ is a [proper](wikipedia://en/630360), [lower semi-continuous](https://en.wikipedia.org/wiki/Lower_semi-continuous), and [convex function](wikipedia://en/245568),
1. $f \equiv +\infty$, or
1. $f \equiv -\infty$.[^o2][^o6][^o7]

:::
