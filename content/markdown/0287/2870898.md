# Cocycle

::: {#o1 .subject cue=lead name="Cocycle"}

In [mathematics](wikipedia://en/18831) a **cocycle** is a closed [cochain](https://en.wikipedia.org/wiki/Cochain_%28algebraic_topology%29). Cocycles are used in [algebraic topology](wikipedia://en/38801) to express obstructions (for example, to integrating a [differential equation](wikipedia://en/1424309) on a [closed manifold](wikipedia://en/669475)). They are likewise used in [group cohomology](wikipedia://en/248635). In [autonomous](wikipedia://en/312398) [dynamical systems](wikipedia://en/9087), cocycles are used to describe particular kinds of map, as in [Oseledets theorem](wikipedia://en/2537958).[^o2]

:::

## Definition {#Definition}

::: {#o6 .pointer-item cue=pointer name="Cocycle (algebraic topology)"}

### Algebraic Topology {#Algebraic_Topology}

Let *X* be a [CW complex](wikipedia://en/353022) and $C^n(X)$ be the singular [cochains](wikipedia://en/138404) with coboundary map $d^n: C^{n-1}(X) \to C^n(X)$. Then elements of $\text{ker }d$ are **cocycles**. Elements of $\text{im } d$ are **coboundaries**. If $\varphi$ is a cocycle, then $d \circ \varphi = \varphi \circ \partial =0$, which means cocycles vanish on boundaries. [^o7]
