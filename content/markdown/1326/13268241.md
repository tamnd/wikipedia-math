# Simple magic cube

*Image: Simple magic cube.svg.* An example of a 3 × 3 × 3 simple magic cube.

::: {#o1 .subject cue=lead name="Simple magic cube"}

A **simple magic cube** is the lowest of six basic [classes of magic cubes](wikipedia://en/1369521). These classes are based on extra features required.

:::

The simple magic cube requires only the basic features a cube requires to be magic. Namely, all lines parallel to the faces, and all 4 [space diagonals](wikipedia://en/1337505) sum correctly.[^o2] i.e. all "1-agonals" and all "3-agonals" sum to

$$S = \frac{m(m^3+1)}{2}.$$

No planar diagonals (2-agonals) are required to sum correctly, so there are probably no [magic squares](wikipedia://en/52202) in the cube.
