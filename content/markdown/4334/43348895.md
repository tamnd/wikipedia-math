# Knapsack cryptosystems

::: {#o1 .subject cue=lead name="Knapsack cryptosystems"}

**Knapsack cryptosystems** are [cryptosystems](wikipedia://en/506383) whose security is based on the hardness of solving the [knapsack problem](wikipedia://en/16974). They remain quite unpopular because simple versions of these algorithms have been broken for several decades.[^o2] However, that type of cryptosystem is a good candidate for [post-quantum cryptography](wikipedia://en/26605226).

:::

The most famous knapsack cryptosystem is the [Merkle-Hellman Public Key Cryptosystem](wikipedia://en/59652), one of the first [public key cryptosystems](https://en.wikipedia.org/wiki/Public_key_cryptography), published the same year as the [RSA cryptosystem](wikipedia://en/25385). However, this system has been broken by several attacks: one from [Shamir](wikipedia://en/57314),[^n1] one by Adleman,[^n2] and the *low density attack*.

However, there exist modern knapsack cryptosystems that are considered secure so far: among them is Nasako-Murakami 2006.[^n3]

Knapsack cryptosystems, when not subject to classical cryptoanalysis, are believed to be difficult even for quantum computers. That is not the case for systems that rely on [factoring](wikipedia://en/15491) large integers, like [RSA](https://en.wikipedia.org/wiki/RSA_%28cryptosystem%29), or computing [discrete logarithms](https://en.wikipedia.org/wiki/Discrete_logarithms), like [ECDSA](https://en.wikipedia.org/wiki/ECDSA), problems solved in [polynomial time](wikipedia://en/405944) with [Shor's algorithm](wikipedia://en/42674).[^o6]
