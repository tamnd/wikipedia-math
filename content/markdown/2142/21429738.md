# Concentration dimension

::: {#o1 .subject cue=lead name="Concentration dimension"}

In [mathematics](wikipedia://en/18831) — specifically, in [probability theory](wikipedia://en/23542) — the **concentration dimension** of a [Banach space](wikipedia://en/3989)-valued [random variable](wikipedia://en/25685) is a numerical measure of how "spread out" the random variable is compared to the [norm](wikipedia://en/990534) on the space.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let (*B*, || ||) be a Banach space and let *X* be a [Gaussian random variable](https://en.wikipedia.org/wiki/Gaussian_distribution) taking values in *B*. That is, for every linear functional *ℓ* in the [dual space](wikipedia://en/7988) *B*<sup>∗</sup>, the real-valued random variable ⟨*ℓ*, *X*⟩ has a [normal distribution](wikipedia://en/21462). Define

$$\sigma(X) = \sup \left\{ \left. \sqrt{\operatorname{E} [\langle \ell, X \rangle^{2}]} \,\right|\, \ell \in B^{\ast}, \| \ell \| \leq 1 \right\}.$$

Then the **concentration dimension** *d*(*X*) of *X* is defined by

$$d(X) = \frac{\operatorname{E} [\| X \|^{2}]}{\sigma(X)^{2}}.$$

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *B* is *n*-dimensional [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup> with its usual [Euclidean norm](wikipedia://en/53932), and *X* is a standard Gaussian random variable, then *σ*(*X*) = 1 and E\[||*X*||<sup>2</sup>\] = *n*, so *d*(*X*) = *n*.
- If *B* is **R**<sup>*n*</sup> with the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm), then *σ*(*X*) = 1 but E\[||*X*||<sup>2</sup>\] (and hence *d*(*X*)) is of the order of log(*n*).

:::
