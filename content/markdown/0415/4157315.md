# Pentagrammic antiprism

::: {#o1 .subject cue=lead name="Pentagrammic antiprism"}

Prism star polyhedron stat table

*Image: Pentagrammic antiprism.stl.* 3D model of a (uniform) pentagrammic antiprism

In [geometry](wikipedia://en/18973446), the **pentagrammic antiprism** is one in an infinite set of nonconvex [antiprisms](https://en.wikipedia.org/wiki/Antiprisms) formed by triangle sides and two regular [star polygon](wikipedia://en/313303) caps, in this case two [pentagrams](wikipedia://en/197544).

:::

It has 12 faces, 20 edges and 10 vertices. This polyhedron is identified with the indexed name U<sub>79</sub> as a [uniform polyhedron](wikipedia://en/2537223).[^o2]

Note that the pentagram face has an ambiguous interior because it is self-intersecting. The central pentagon region can be considered interior or exterior depending on how interior is defined. One definition of interior is the set of points that have a ray that crosses the boundary an odd number of times to escape the perimeter.

In either case, it is best to show the pentagram boundary line to distinguish it from a concave decagon.
