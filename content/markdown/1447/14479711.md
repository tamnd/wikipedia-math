# Self-concordant function

::: {#o1 .subject cue=lead name="Self-concordant function"}

A **self-concordant function** is a function satisfying a certain [differential inequality](https://en.wikipedia.org/wiki/Differential_inequality), which makes it particularly easy for [optimization](wikipedia://en/1126536) using [Newton's method](wikipedia://en/22145)[^o2] A **self-concordant barrier** is a particular self-concordant function, that is also a [barrier function](wikipedia://en/3382647) for a particular convex set. Self-concordant barriers are important ingredients in [interior point methods](https://en.wikipedia.org/wiki/Interior_point_method) for optimization.

:::

## Self-concordant functions {#Self-concordant_functions}

### Multivariate self-concordant function {#Multivariate_self-concordant_function}

Here is the general definition of a self-concordant function.[^o5]

Let *C* be a convex nonempty [open set](wikipedia://en/39358) in R*<sup>n</sup>*. Let *f* be a function that is three-times continuously differentiable defined on *C*. We say that **f is self-concordant on *C*** if it satisfies the following properties:

\1. *Barrier property*: on any sequence of points in *C* that converges to a boundary point of *C*, *f* converges to ∞.

\2. *Differential inequality*: for every point **x** in *C*, and any direction **h** in R<sup>*n*</sup>, let *g*<sub>h</sub> be the function *f* restricted to the direction **h**, that is: *g*<sub>h</sub>(*t*) = *f*(**x**+t\***h**). Then the one-dimensional function *g*<sub>h</sub> should satisfy the following differential inequality:

> $$|g_h'''(x)| \leq 2 g_h''(x)^{3/2}.$$

Equivalently:[^o6]

> $$\left. \frac{d}{d\alpha} \nabla^2 f(x + \alpha y) \right|_{\alpha = 0} \preceq 2 \sqrt{y^T \nabla^2 f(x)\,y} \, \nabla^2 f(x)$$

### Univariate self-concordant function {#Univariate_self-concordant_function}

A [function](wikipedia://en/185427) $f:\mathbb{R} \rightarrow \mathbb{R}$ is self-concordant on $\mathbb{R}$ if:

$$|f'''(x)| \leq 2 f''(x)^{3/2}$$

Equivalently: if wherever $f''(x) > 0$ it satisfies:

$$\left| \frac{d}{dx} \frac{1}{\sqrt{f''(x)}} \right| \leq 1$$

and satisfies $f'''(x) = 0$ elsewhere.

::: {#o9 .example cue=heading name="Examples"}

### Examples {#Examples}

- Linear and convex quadratic functions are self-concordant, since their third derivative is zero.
- Any function $f(x) = -\log(-g(x))-\log x$ where $g(x)$ is defined and convex for all $x > 0$ and verifies $| g'''(x) | \leq 3g''(x)/x$, is self concordant on its domain which is $\{ x \mid x > 0, g(x) < 0 \}$. Some examples are
  - $g(x) = -x^p$ for $0 < p \leq 1$
  - $$g(x) = -\log x$$
  - $g(x) = x^p$ for $-1 \leq p \leq 0$
  - $$g(x) = (ax+b)^2 / x$$
  - for any function $g$ satisfying the conditions, the function $g(x) + a x^2 + bx + c$ with $a \geq 0$ also satisfies the conditions.

Some functions that are not self-concordant:

- $$f(x) = e^x$$
- $$f(x) = \frac{1}{x^p}, x >0, p >0$$
- $$f(x) = |x^p|, p > 2$$

:::

## Self-concordant barriers {#Self-concordant_barriers}

Here is the general definition of a self-concordant barrier (SCB).[^o5]

Let *C* be a convex closed set in R*<sup>n</sup>* with a non-empty interior. Let *f* be a function from interior(*C*) to R. Let *M*>0 be a real parameter. We say that ***f* is a *M*-self-concordant barrier for *C*** if it satisfies the following:

\1. *f* is a self-concordant function on interior(*C*).

\2. For every point **x** in interior(*C*), and any direction **h** in R<sup>*n*</sup>, let *g*<sub>h</sub> be the function *f* restricted to the direction **h**, that is: *g*<sub>h</sub>(*t*) = *f*(**x**+t\***h**). Then the one-dimensional function *g*<sub>h</sub> should satisfy the following differential inequality:

> $$|g_h'(x)| \leq M^{1/2}\cdot g_h''(x)^{1/2}.$$

### Constructing SCBs {#Constructing_SCBs}

Due to the importance of SCBs in interior-point methods, it is important to know how to construct SCBs for various domains.

In theory, it can be proved that *every* closed convex domain in R<sup>n</sup> has a self-concordant barrier with parameter O(*n*). But this “universal barrier” is given by some multivariate integrals, and it is too complicated for actual computations. Hence, the main goal is to construct SCBs that are efficiently computable.[^o12]

SCBs can be constructed from some *basic SCBs*, that are combined to produce SCBs for more complex domains, using several *combination rules*.

### Basic SCBs {#Basic_SCBs}

Every constant is a self-concordant barrier for all R*<sup>n</sup>*, with parameter M=0. It is the only self-concordant barrier for the entire space, and the only self-concordant barrier with *M* \< 1.[^o5] \[Note that linear and quadratic functions are self-concordant functions, but they are *not* self concordant barriers\].

For the positive half-line $\mathbb R_+$($x > 0$), $f(x) = -\ln x$ is a self-concordant barrier with parameter $M = 1$. This can be proved directly from the definition.

### Substitution rule {#Substitution_rule}

Let *G* be a closed convex domain in *R<sup>n</sup>*, and *g* an *M*-SCB for *G*. Let *x* = *Ay*+*b* be an affine mapping from R<sup>k</sup> to R<sup>n</sup> with its image intersecting the interior of *G*. Let *H* be the inverse image of *G* under the mapping: *H* = {*y* in R<sup>*k*</sup> | *Ay+b* in *G*}. Let *h* be the composite function *h*(*y*) := g(*Ay*+*b*). Then, *h* is an *M*-SCB for *H*.[^o5]

For example, take *n*=1, *G* the positive half-line, and $g(x) = -\ln x$. For any *k*, let *a* be a *k*-element vector and *b* a scalar. Let *H* = {*y* in R<sup>k</sup> | *a*<sup>T</sup>*y+b* ≥ 0} = a *k*-dimensional half-space. By the substitution rule, $h(y) = -\ln (a^T y+b)$ is a 1-SCB for *H*. A more common format is *H* = {*x* in R<sup>*k*</sup> | *a<sup>T</sup>x* ≤ b}, for which the SCB is $h(y) = -\ln (b - a^T y)$.

The substitution rule can be extended from affine mappings to a certain class of "appropriate" mappings,[^o5] and to quadratic mappings.[^o5]

### Cartesian product rule {#Cartesian_product_rule}

For all *i* in 1,...,*m*, let *G<sub>i</sub>* be a closed convex domains in *R<sup>ni</sup>*, and let *g<sub>i</sub>* be an *M*<sub>i</sub>-SCB for *G<sub>i</sub>*. Let *G* be the [cartesian product](wikipedia://en/24104095) of all *G<sub>i</sub>*. Let *g(x*<sub>1</sub>*,...,x<sub>m</sub>)* := sum*<sub>i</sub> g<sub>i</sub>*(*x<sub>i</sub>*). Then, *g* is a SCB for *G*, with parameter sum*<sub>i</sub> M<sub>i</sub>*.[^o5]

For example, take all *G<sub>i</sub>* to be the positive half-line, so that *G* is the positive orthant $\mathbb R_+^m$. Let $g(x) = -\sum_{i=1}^m \ln x_i$ is an *m*-SCB for *G.*

We can now apply the substitution rule. We get that, for the polytope defined by the linear inequalities *a<sub>j</sub>*<sup>T</sup>*x* ≤ *b<sub>j</sub>* for *j* in 1,...,*m*, if it satisfies [Slater's condition](wikipedia://en/33295435), then $f(x) = -\sum_{i=1}^m \ln (b_j-a_j^T x)$ is an *m*-SCB. The linear functions $b_j-a_j^T x$ can be replaced by [quadratic functions](wikipedia://en/187240).

### Intersection rule {#Intersection_rule}

Let *G*<sub>1</sub>,...,*G<sub>m</sub>* be closed convex domains in *R<sup>n</sup>*. For each *i* in 1,...,*m*, let *g<sub>i</sub>* be an *M*<sub>i</sub>-SCB for *G<sub>i</sub>*, and *r<sub>i</sub>* a real number. Let *G* be the intersection of all *G<sub>i</sub>*, and suppose its interior is nonempty. Let *g* := sum*<sub>i</sub> r<sub>i</sub>\*g<sub>i</sub>*. Then, *g* is a SCB for *G*, with parameter sum*<sub>i</sub> r<sub>i</sub>\*M<sub>i</sub>*.[^o5]

Therefore, if *G* is defined by a list of constraints, we can find a SCB for each constraint separately, and then simply sum them to get a SCB for *G*.

For example, suppose the domain is defined by *m* linear constraints of the form *a<sub>j</sub><sup>T</sup>x* ≤ *b<sub>j</sub>*, for *j* in 1,...,*m*. Then we can use the Intersection rule to construct the *m*-SCB $f(x) = -\sum_{i=1}^m \ln (b_j-a_j^T x)$ (the same one that we previously computed using the Cartesian [product rule](wikipedia://en/248988)).

### SCBs for epigraphs {#SCBs_for_epigraphs}

The [epigraph](wikipedia://en/5744061) of a function *f*(*x*) is the area above the graph of the function, that is, $\{ (x,t) \in \mathbb{R}^2: t\geq f(x) \}$. The epigraph of *f* is a [convex set](wikipedia://en/6292) [if and only if](wikipedia://en/14922) *f* is a [convex function](wikipedia://en/245568). The following theorems present some functions *f* for which the epigraph has an SCB.

Let *g*(*t*) be a 3-times continuously differentiable [concave function](wikipedia://en/263321) on *t*>0, such that $t\cdot | g'''(t)| / |g''(t)|$ is bounded by a constant (denoted 3\**b*) for all *t*>0. Let *G* be the 2-dimensional convex domain: $G=\text{closure}(\{ (x,t) \in \mathbb{R}^2: t>0, x \leq g(t) \}).$Then, the function *f*(*x*,*t*) = -ln(f(t)-x) - max\[1,b<sup>2</sup>\]\*ln(t) is a self-concordant barrier for *G*, with parameter (1+max\[1,b<sup>2</sup>\]).[^o5]

Examples:

- Let *g*(*t*) = *t*<sup>1/*p*</sup>, for some *p*≥1, and *b*=(2*p*-1)/(3*p*). Then $G_1=\{ (x,t) \in \mathbb{R}^2: (x_+)^p \leq t \}$ has a 2-SCB. Similarly, $G_2=\{ (x,t) \in \mathbb{R}^2: ([-x]_+)^p \leq t \}$ has a 2-SCB. Using the Intersection rule, we get that $G = G_1\cap G_2= \{ (x,t) \in \mathbb{R}^2: |x|^p \leq t \}$ has a 4-SCB.
- Let *g*(*t*)=ln(*t*) and *b*=2/3. Then $G=\{ (x,t) \in \mathbb{R}^2: e^x \leq t \}$ has a 2-SCB.

We can now construct a SCB for the problem of minimizing the *p*-norm: $\min_x \sum_{j=1}^n |v_j - x^T u_j|^p$, where *v<sub>j</sub>* are constant scalars, *u<sub>j</sub>* are constant vectors, and *p*>0 is a constant. We first convert it into minimization of a linear objective: $\min_x \sum_{j=1}^n t_j$, with the constraints: $t_j \geq |v_j - x^T u_j|^p$for all *j* in \[*m*\]. For each constraint, we have a 4-SCB by the affine substitution rule. Using the Intersection rule, we get a (4*n*)-SCB for the entire feasible domain.

Similarly, let *g* be a 3-times continuously differentiable convex function on the ray *x*>0, such that: $x\cdot |g'''(x)| / |g''(x)| \leq 3 b$ for all *x*>0. Let *G* be the 2-dimensional convex domain: closure({ (*t,x*) in R<sup>2</sup>: x>0, *t* ≥ *g*(*x*) }). Then, the function *f*(*x*,*t*) = -ln(t-f(x)) - max\[1,b<sup>2</sup>\]\*ln(x) is a self-concordant barrier for G, with parameter (1+max\[1,b<sup>2</sup>\]).[^o5]

Examples:

- Let *g*(*x*) = *x*<sup>−*p*</sup>, for some *p*>0, and b=(2+*p*)/3. Then $G_1=\{ (x,t) \in \mathbb{R}^2: x^{-p} \leq t, x\geq 0 \}$ has a 2-SCB.
- Let *g*(*x*)=*x* ln(*x*) and *b*=1/3. Then $G=\{ (x,t) \in \mathbb{R}^2: x\ln x \leq t, x\geq 0 \}$ has a 2-SCB.

### SCBs for cones {#SCBs_for_cones}

- For the [second order cone](wikipedia://en/7500026) $\{ (x,y) \in \mathbb R^{n-1} \times \mathbb R \mid \| x \| \leq y \}$, the function $f(x,y) = -\log(y^2 - x^T x)$ is a self-concordant barrier.
- For the cone of [positive semidefinite](https://en.wikipedia.org/wiki/Positive_semidefinite_matrices) of m\*m symmetric matrices, the function $f(A) = - \log \det A$ is a self-concordant barrier.
- For the quadratic region defined by $\phi(x) > 0$ where $\phi(x) = \alpha +\langle a, x \rangle - \frac{1}{2} \langle Ax, x \rangle$ where $A = A^T \geq 0$ is a [positive semi-definite](https://en.wikipedia.org/wiki/Positive_semidefinite_matrix) [symmetric matrix](wikipedia://en/126474), the logarithmic barrier $f(x) = -\log \phi(x)$ is self-concordant with $M = 2$
- For the [exponential cone](https://en.wikipedia.org/wiki/Exponential_cone) $\{ (x,y,z) \in \mathbb R^3 \mid ye^{x/y} \leq z, y > 0 \}$, the function $f(x,y,z) = -\log (y \log(z/y) - x) - \log z - \log y$ is a self-concordant barrier.
- For the [power cone](wikipedia://en/75439302) $\{ (x_1,x_2,y) \in \mathbb R_+^2 \times \mathbb R \mid |y| \leq x_1^{\alpha} x_2^{1-\alpha} \}$, the function $f(x_1,x_2,y) = -\log(x_1^{2\alpha} x_2^{2(1-\alpha)} - y^2) - \log x_1 - \log x_2$ is a self-concordant barrier.

## History {#History}

As mentioned in the "Bibliography Comments"[^o20] of their 1994 book,[^o30] self-concordant functions were introduced in 1988 by [Yurii Nesterov](wikipedia://en/42967707)[^o21][^o22] and further developed with [Arkadi Nemirovski](https://en.wikipedia.org/wiki/Arkadi_Nemirovski).[^o23] As explained in[^o24] their basic observation was that the Newton method is affine invariant, in the sense that if for a function $f(x)$ we have Newton steps $x_{k+1} = x_k - [f''(x_k)]^{-1}f'(x_k)$ then for a function $\phi(y) = f(Ay)$ where $A$ is a non-degenerate linear transformation, starting from $y_0 = A^{-1} x_0$ we have the Newton steps $y_k = A^{-1} x_k$ which can be shown recursively

$$y_{k+1} = y_k - [\phi''(y_k)]^{-1} \phi'(y_k) = y_k - [A^T f''(A y_k) A]^{-1} A^T f'(A y_k) = A^{-1} x_k - A^{-1}[f''(x_k)]^{-1} f'(x_k) = A^{-1} x_{k+1}.$$

However, the standard analysis of the Newton method supposes that the Hessian of $f$ is [Lipschitz continuous](wikipedia://en/51731), that is $\|f''(x) - f''(y)\| \leq M\| x-y \|$ for some constant $M$. If we suppose that $f$ is 3 times continuously differentiable, then this is equivalent to

$| \langle f'''(x)[u]v, v \rangle | \leq M \|u\| \|v\|^2$for all $u,v \in \mathbb{R}^n$

where $f'''(x)[u] = \lim_{\alpha \to 0} \alpha^{-1} [f''(x + \alpha u) - f''(x)]$ . Then the left hand side of the above inequality is invariant under the [affine transformation](wikipedia://en/38449) $f(x) \to \phi(y) = f(A y), u \to A^{-1} u, v \to A^{-1} v$, however the right hand side is not.

The authors note that the right hand side can be made also invariant if we replace the Euclidean metric by the scalar product defined by the Hessian of $f$ defined as $\| w \|_{f''(x)} = \langle f''(x)w, w \rangle^{1/2}$ for $w \in \mathbb R^n$. They then arrive at the definition of a self concordant function as

$$| \langle f'''(x)[u]u, u \rangle | \leq M \langle f''(x) u, u \rangle^{3/2}.$$

::: {#o26 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Linear combination {#Linear_combination}

If $f_1$ and $f_2$ are self-concordant with constants $M_1$ and $M_2$ and $\alpha,\beta>0$, then $\alpha f_1 + \beta f_2$ is self-concordant with constant $\max(\alpha^{-1/2} M_1, \beta^{-1/2} M_2)$.

### Affine transformation {#Affine_transformation}

If $f$ is self-concordant with constant $M$ and $Ax + b$ is an affine transformation of $\mathbb R^n$, then $\phi(x) = f(Ax+b)$ is also self-concordant with parameter $M$.

### Convex conjugate {#Convex_conjugate}

If $f$ is self-concordant, then its [convex conjugate](wikipedia://en/1001490) $f^*$ is also self-concordant.[^o30][^o31]

### Non-singular Hessian {#Non-singular_Hessian}

If $f$ is self-concordant and the domain of $f$ contains no straight line (infinite in both directions), then $f''$ is non-singular.

Conversely, if for some $x$ in the domain of $f$ and $u \in \mathbb R^n, u \neq 0$ we have $\langle f''(x) u, u \rangle = 0$, then $\langle f''(x + \alpha u) u, u \rangle = 0$ for all $\alpha$ for which $x + \alpha u$ is in the domain of $f$ and then $f(x + \alpha u)$ is linear and cannot have a maximum so all of $x + \alpha u, \alpha \in \mathbb R$ is in the domain of $f$. We note also that $f$ cannot have a minimum inside its domain.

:::

## Applications {#Applications}

Among other things, self-concordant functions are useful in the analysis of [Newton's method](wikipedia://en/22145). Self-concordant *barrier functions* are used to develop the [barrier functions](wikipedia://en/3382647) used in [interior point methods](https://en.wikipedia.org/wiki/Interior_point_method) for convex and nonlinear optimization. The usual analysis of the Newton method would not work for barrier functions as their second derivative cannot be Lipschitz continuous, otherwise they would be bounded on any compact subset of $\mathbb R^n$.

Self-concordant barrier functions

- are a class of functions that can be used as barriers in constrained optimization methods
- can be minimized using the Newton algorithm with provable convergence properties analogous to the usual case (but these results are somewhat more difficult to derive)
- to have both of the above, the usual constant bound on the third derivative of the function (required to get the usual convergence results for the Newton method) is replaced by a bound relative to the Hessian

### Minimizing a self-concordant function {#Minimizing_a_self-concordant_function}

A self-concordant function may be minimized with a modified Newton method where we have a bound on the number of steps required for convergence. We suppose here that $f$ is a *standard* self-concordant function, that is it is self-concordant with parameter $M = 2$.

We define the *Newton decrement* $\lambda_f(x)$ of $f$ at $x$ as the size of the Newton step $[f''(x)]^{-1} f'(x)$ in the local norm defined by the Hessian of $f$ at $x$

$$\lambda_f(x) = \langle f''(x) [f''(x)]^{-1} f'(x), [f''(x)]^{-1} f'(x) \rangle^{1/2} = \langle [f''(x)]^{-1} f'(x), f'(x) \rangle^{1/2}$$

Then for $x$ in the domain of $f$, if $\lambda_f(x) < 1$ then it is possible to prove that the Newton iterate

$$x_+ = x - [f''(x)]^{-1}f'(x)$$

will be also in the domain of $f$. This is because, based on the self-concordance of $f$, it is possible to give some finite bounds on the value of $f(x_+)$. We further have

$$\lambda_f(x_+) \leq \Bigg( \frac{\lambda_f(x)}{1-\lambda_f(x)} \Bigg)^2$$

Then if we have

$$\lambda_f(x) < \bar\lambda = \frac{3-\sqrt 5}{2}$$

then it is also guaranteed that $\lambda_f(x_+) < \lambda_f(x)$, so that we can continue to use the Newton method until convergence. Note that for $\lambda_f(x_+) < \beta$ for some $\beta \in (0, \bar\lambda)$ we have quadratic convergence of $\lambda_f$ to 0 as $\lambda_f(x_+) \leq (1-\beta)^{-2} \lambda_f(x)^2$. This then gives quadratic convergence of $f(x_k)$ to $f(x^*)$ and of $x$ to $x^*$, where $x^* = \arg\min f(x)$, by the following theorem. If $\lambda_f(x) < 1$ then

$$\omega(\lambda_f(x)) \leq f(x)-f(x^*) \leq \omega_*(\lambda_f(x))$$

$$\omega'(\lambda_f(x)) \leq \| x-x^* \|_x \leq \omega_*'(\lambda_f(x))$$

with the following definitions

$$\omega(t) = t - \log(1+t)$$

$$\omega_*(t) = -t-\log(1-t)$$

$$\| u \|_x = \langle f''(x) u, u \rangle^{1/2}$$

If we start the Newton method from some $x_0$ with $\lambda_f(x_0) \geq \bar\lambda$ then we have to start by using a *damped Newton method* defined by

$$x_{k+1} = x_k - \frac{1}{1+\lambda_f(x_k)}[f''(x_k)]^{-1}f'(x_k)$$

For this it can be shown that $f(x_{k+1}) \leq f(x_k) - \omega(\lambda_f(x_k))$ with $\omega$ as defined previously. Note that $\omega(t)$ is an increasing function for $t > 0$ so that $\omega(t) \geq \omega(\bar\lambda)$ for any $t \geq \bar\lambda$, so the value of $f$ is guaranteed to decrease by a certain amount in each iteration, which also proves that $x_{k+1}$ is in the domain of $f$.

:::
