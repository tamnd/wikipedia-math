# Monotone class theorem

::: {#o1 .subject cue=lead name="Monotone class theorem"}

In [measure theory](wikipedia://en/19873) and [probability](wikipedia://en/23542), the **monotone class theorem** connects monotone classes and [\-algebras](https://en.wikipedia.org/wiki/Sigma-algebra). The theorem says that the smallest monotone class containing an [algebra of sets](wikipedia://en/1018676) $G$ is precisely the smallest [\-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) containing $G.$ It is used as a type of [transfinite induction](wikipedia://en/30461) to prove many other theorems, such as [Fubini's theorem](wikipedia://en/255245).

:::

## Definition of a monotone class {#Definition_of_a_monotone_class}

A **monotone class** is a [family](wikipedia://en/723043) (i.e. class) $M$ of sets that is [closed](wikipedia://en/293802) under countable monotone unions and also under countable monotone intersections. Explicitly, this means $M$ has the following properties:

1. if $A_1, A_2, \ldots \in M$ and $A_1 \subseteq A_2 \subseteq \cdots$ then ${\textstyle\bigcup\limits_{i = 1}^\infty} A_i \in M,$ and
1. if $B_1, B_2, \ldots \in M$ and $B_1 \supseteq B_2 \supseteq \cdots$ then ${\textstyle\bigcap\limits_{i = 1}^\infty} B_i \in M.$

::: {#o4 .statement kind=statement/theorem cue=named-heading name="Monotone class theorem for sets"}

## Monotone class theorem for sets {#Monotone_class_theorem_for_sets}

::: {#o5 .statement kind=statement/theorem cue=math-theorem name="Monotone class theorem for sets"}

**Monotone class theorem for sets.**

Let $G$ be an [algebra of sets](wikipedia://en/1018676) and define $M(G)$ to be the smallest monotone class containing $G.$ Then $M(G)$ is precisely the [\-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) generated by $G$; that is $\sigma(G) = M(G).$

:::

:::

## Monotone class theorem for functions {#Monotone_class_theorem_for_functions}

::: {#o8 .statement kind=statement/theorem cue=math-theorem name="Monotone class theorem for functions"}

**Monotone class theorem for functions.**

Let $\mathcal{A}$ be a [$\pi$-system](https://en.wikipedia.org/wiki/Pi_system) that contains $\Omega\,$ and let $\mathcal{H}$ be a collection of functions from $\Omega$ to $\mathbb{R}$ with the following properties:

If $A \in \mathcal{A}$ then $\mathbf{1}_A \in \mathcal{H}$ where $\mathbf{1}_A$ denotes the [indicator function](wikipedia://en/240790) of $A.$

If $f, g \in \mathcal{H}$ and $c \in \mathbb{R}$ then $f + g$ and $c f \in \mathcal{H}.$

If $f_n \in \mathcal{H}$ is a sequence of non-negative functions that increase to a bounded function $f$ then $f \in \mathcal{H}.$

Then $\mathcal{H}$ contains all bounded functions that are measurable with respect to $\sigma(\mathcal{A}),$ which is the -algebra generated by $\mathcal{A}.$

:::

::: {#o10 .proof cue=heading name="Proof"}

### Proof {#Proof}

The following argument originates in [Rick Durrett](wikipedia://en/14717141)'s Probability: Theory and Examples.[^o11]

::: {#o12 .proof cue=math-proof}

The assumption $\Omega\, \in \mathcal{A},$ (2), and (3) imply that $\mathcal{G} = \left\{A : \mathbf{1}_{A} \in \mathcal{H}\right\}$ is a -system. By (1) and the [$\pi$− theorem](wikipedia://en/2549191), $\sigma(\mathcal{A}) \subseteq \mathcal{G}.$ Statement (2) implies that $\mathcal{H}$ contains all simple functions, and then (3) implies that $\mathcal{H}$ contains all bounded functions measurable with respect to $\sigma(\mathcal{A}).$

:::

:::

:::

## Results and applications {#Results_and_applications}

As a corollary, if $G$ is a [ring of sets](wikipedia://en/2686481), then the smallest monotone class containing it coincides with the [\-ring](wikipedia://en/6928351) of $G.$

By invoking this theorem, one can use monotone classes to help verify that a certain collection of subsets is a [\-algebra](https://en.wikipedia.org/wiki/Sigma-algebra).

The monotone class theorem for functions can be a powerful tool that allows statements about particularly simple classes of functions to be generalized to arbitrary bounded and measurable functions.
