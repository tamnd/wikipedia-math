# Positively separated sets

::: {#o1 .subject cue=lead name="Positively separated sets"}

In [mathematics](wikipedia://en/18831), two [non-empty](https://en.wikipedia.org/wiki/Non-empty) [subsets](wikipedia://en/27631) *A* and *B* of a given [metric space](wikipedia://en/20018) (*X*, *d*) are said to be **positively separated** if the [infimum](https://en.wikipedia.org/wiki/Infimum)

:::

$$\inf_{a \in A, b \in B} d(a, b) > 0.$$

(Some authors also specify that *A* and *B* should be [disjoint sets](wikipedia://en/39359); however, this adds nothing to the definition, since if *A* and *B* have some common point *p*, then *d*(*p*, *p*) = 0, and so the infimum above is clearly 0 in that case.)

For example, on the real line with the usual distance, the [open intervals](https://en.wikipedia.org/wiki/Open_interval) (0, 2) and (3, 4) are positively separated, while (3, 4) and (4, 5) are not. In two dimensions, the graph of *y* = 1/*x* for *x* > 0 and the *x*-axis are not positively separated.
