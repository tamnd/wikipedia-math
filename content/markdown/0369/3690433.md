# Empirical process

::: {#o1 .subject cue=lead name="Empirical process"}

In [probability theory](wikipedia://en/23542), an **empirical process** is a [stochastic process](wikipedia://en/47895) that characterizes the deviation of the [empirical distribution function](wikipedia://en/2690455) from its expectation. In [mean field theory](https://en.wikipedia.org/wiki/Mean_field_theory), limit theorems (as the number of objects becomes large) are considered and generalise the [central limit theorem](wikipedia://en/39406) for [empirical measures](wikipedia://en/5647670). Applications of the theory of empirical processes arise in [non-parametric statistics](https://en.wikipedia.org/wiki/Non-parametric_statistics).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For *X*<sub>1</sub>, *X*<sub>2</sub>, ... *X*<sub>*n*</sub> [independent and identically-distributed random variables](https://en.wikipedia.org/wiki/Independent_and_identically-distributed_random_variables) with values in $\mathbb{R}$ and [cumulative distribution function](wikipedia://en/5793) *F*(*x*), the empirical distribution function is defined as

$$F_n(x)=\frac{1}{n}\sum_{i=1}^n I_{(-\infty,x]}(X_i),$$

where I<sub>*C*</sub> is the [indicator function](wikipedia://en/240790) of the set *C*.

For every (fixed) *x*, *F*<sub>*n*</sub>(*x*) is a sequence of random variables which converge to *F*(*x*) [almost surely](wikipedia://en/351908) by the strong [law of large numbers](wikipedia://en/157055). That is, *F*<sub>*n*</sub> converges to *F* [pointwise](wikipedia://en/340198). Glivenko and Cantelli strengthened this result by proving [uniform convergence](wikipedia://en/50652) of *F*<sub>*n*</sub> to *F* by the [Glivenko–Cantelli theorem](wikipedia://en/3828409).[^o5]

A centered and scaled version of the empirical measure is the [signed measure](wikipedia://en/2985811)

$$G_n(A)=\sqrt{n}(P_n(A)-P(A))$$

It induces a map on measurable functions *f* given by

$$f\mapsto G_n f=\sqrt{n}(P_n-P)f=\sqrt{n}\left(\frac{1}{n}\sum_{i=1}^n f(X_i)-\mathbb{E}f\right)$$

By the [central limit theorem](wikipedia://en/39406), $G_n(A)$ [converges in distribution](https://en.wikipedia.org/wiki/Converges_in_distribution) to a [normal](wikipedia://en/21462) random variable *N*(0, *P*(*A*)(1 − *P*(*A*))) for fixed measurable set *A*. Similarly, for a fixed function *f*, $G_nf$ converges in distribution to a normal random variable $N(0,\mathbb{E}(f-\mathbb{E}f)^2)$, provided that $\mathbb{E}f$ and $\mathbb{E}f^2$ exist.

::: {#o6 .definition cue=inline-head name="Definition"}

**Definition**

$\bigl(G_n(c)\bigr)_{c\in\mathcal{C}}$ is called an *empirical process* indexed by $\mathcal{C}$, a collection of measurable subsets of *S*.

$\bigl(G_nf\bigr)_{f\in\mathcal{F}}$ is called an *empirical process* indexed by $\mathcal{F}$, a collection of measurable functions from *S* to $\mathbb{R}$.

A significant result in the area of empirical processes is [Donsker's theorem](wikipedia://en/3828419). It has led to a study of [Donsker classes](https://en.wikipedia.org/wiki/Donsker_classes): sets of functions with the useful property that empirical processes indexed by these classes [converge weakly](wikipedia://en/50723) to a certain [Gaussian process](wikipedia://en/302944). While it can be shown that Donsker classes are [Glivenko–Cantelli classes](https://en.wikipedia.org/wiki/Glivenko–Cantelli_class), the converse is not true in general.

:::

:::

::: {#o8 .example cue=heading name="Example"}

## Example {#Example}

As an example, consider [empirical distribution functions](wikipedia://en/2690455). For real-valued [iid](https://en.wikipedia.org/wiki/Iid) random variables *X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*n*</sub> they are given by

$$F_n(x)=P_n((-\infty,x])=P_nI_{(-\infty,x]}.$$

In this case, empirical processes are indexed by a class $\mathcal{C}=\{(-\infty,x]:x\in\mathbb{R}\}.$ It has been shown that $\mathcal{C}$ is a Donsker class, in particular,

$\sqrt{n}(F_n(x)-F(x))$ converges [weakly](https://en.wikipedia.org/wiki/Weak_convergence_of_measures) in $\ell^\infty(\mathbb{R})$ to a [Brownian bridge](wikipedia://en/1843777) *B*(*F*(*x*)) .

:::
