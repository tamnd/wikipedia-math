# Lusin's separation theorem

::: {#o1 .subject cue=lead name="Lusin's separation theorem"}

In [descriptive set theory](wikipedia://en/396619) and [mathematical logic](wikipedia://en/19636), **Lusin's separation theorem** states that if *A* and *B* are disjoint [analytic subsets](wikipedia://en/634261) of [Polish space](wikipedia://en/396622), then there is a [Borel set](wikipedia://en/43327) *C* in the space such that *A* ⊆ *C* and *B* ∩ *C* = ∅.[^o2] It is named after [Nikolai Luzin](wikipedia://en/576228), who proved it in 1927.[^o3]

:::

The theorem can be generalized to show that for each sequence (*A*<sub>*n*</sub>) of disjoint analytic sets there is a sequence (*B*<sub>*n*</sub>) of disjoint Borel sets such that *A*<sub>*n*</sub> ⊆ *B*<sub>*n*</sub> for each *n*.[^o2]

An immediate consequence is **Suslin's theorem**, which states that if a set and its complement are both analytic, then the set is Borel.
