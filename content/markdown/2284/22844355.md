# Erdős–Rado theorem

::: {#o1 .subject cue=lead name="Erdős–Rado theorem"}

*Image: Paul\_Erdős.jpg.* Paul Erdős at a student seminar in Budapest (fall 1992)

In [partition calculus](https://en.wikipedia.org/wiki/Partition_calculus), part of [combinatorial set theory](https://en.wikipedia.org/wiki/Combinatorial_set_theory), a branch of mathematics, the **Erdős–Rado theorem** is a basic result extending [Ramsey's theorem](wikipedia://en/184898) to [uncountable sets](wikipedia://en/32248). It is named after [Paul Erdős](wikipedia://en/601284) and [Richard Rado](wikipedia://en/614984).[^n1] It is sometimes also attributed to [Đuro Kurepa](wikipedia://en/3130558) who proved it under the additional assumption of the [generalised continuum hypothesis](https://en.wikipedia.org/wiki/Generalised_continuum_hypothesis),[^n2] and hence the result is sometimes also referred to as the **Erdős–Rado–Kurepa theorem**.

:::

::: {#o5 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

If *r* ≥ 0 is finite and *κ* is an [infinite cardinal](https://en.wikipedia.org/wiki/Infinite_cardinal), then

$$\exp_r(\kappa)^+\longrightarrow(\kappa^+)^{r+1}_\kappa$$

where exp<sub>0</sub>(κ) = *κ* and inductively exp<sub>*r*+1</sub>(κ)=2<sup>exp<sub>*r*</sub>(κ)</sup>. This is sharp in the sense that exp<sub>*r*</sub>(κ)<sup>\+</sup> cannot be replaced by exp<sub>*r*</sub>(κ) on the left hand side.

The above partition symbol describes the following statement. If *f* is a coloring of the *r+1*-element subsets of a set of cardinality exp<sub>*r*</sub>(κ)<sup>\+</sup>, in *κ* many colors, then there is a homogeneous set of cardinality *κ<sup>\+</sup>* (a set, all whose *r+1*-element subsets get the same *f*-value).
