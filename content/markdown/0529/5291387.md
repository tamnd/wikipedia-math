# Koszul–Tate resolution

::: {#o1 .subject cue=lead name="Koszul–Tate resolution"}

In mathematics, a **Koszul–Tate resolution** or **Koszul–Tate complex** of the [quotient ring](wikipedia://en/184635) *R*/*M* is a [projective resolution](https://en.wikipedia.org/wiki/Projective_resolution) of it as an *R*-module which also has a structure of a [dg-algebra](https://en.wikipedia.org/wiki/Dg-algebra) over *R*, where *R* is a [commutative ring](wikipedia://en/61346) and *M* ⊂ *R* is an [ideal](wikipedia://en/25977). They were introduced by (txt) as a generalization of the [Koszul resolution](wikipedia://en/519992) for the quotient *R*/(*x*<sub>1</sub>, ...., *x*<sub>n</sub>) of *R* by a [regular sequence](wikipedia://en/505119) of elements. (txt, 439–569) used the Koszul–Tate resolution to calculate [BRST cohomology](https://en.wikipedia.org/wiki/BRST_cohomology). The [differential](wikipedia://en/138404#Formal_definition) of this complex is called the **Koszul–Tate derivation** or **Koszul–Tate differential**.

:::

## Construction {#Construction}

First suppose for simplicity that all rings contain the [rational numbers](wikipedia://en/19727024) *Q*. Assume we have a [graded](wikipedia://en/103094) [supercommutative ring](https://en.wikipedia.org/wiki/Supercommutative_ring) *X*, so that

*ab* = (−1)<sup>deg(*a*)deg (*b*)</sup>*ba*,

with a differential *d*, with

*d*(*ab*) = *d*(*a*)*b* + (−1)<sup>deg(*a*)</sup>*ad*(*b*)),

and *x* ∈ *X* is a homogeneous cycle (*dx* = 0). Then we can form a new ring

*Y* = *X*\[T\]

of [polynomials](wikipedia://en/23000) in a variable *T*, where the differential is extended to *T* by

*dT*=*x*.

(The [polynomial ring](wikipedia://en/373065) is understood in the super sense, so if *T* has odd degree then *T*<sup>2</sup> = 0.) The result of adding the element *T* is to kill off the element of the homology of *X* represented by *x*, and *Y* is still a [supercommutative ring](wikipedia://en/859686) with derivation.

A Koszul–Tate resolution of *R*/*M* can be constructed as follows. We start with the commutative ring *R* (graded so that all elements have degree 0). Then add new variables as above of degree 1 to kill off all elements of the ideal *M* in the homology. Then keep on adding more and more new variables (possibly an infinite number) to kill off all homology of positive degree. We end up with a supercommutative graded ring with derivation *d* whose homology is just *R*/*M*.

If we are not working over a [field](wikipedia://en/10603) of characteristic 0, the construction above still works, but it is usually neater to use the following variation of it. Instead of using polynomial rings *X*\[*T*\], one can use a "polynomial ring with divided powers" *X*〈*T*〉, which has a basis of elements

*T*<sup>(*i*)</sup> for *i* ≥ 0,

where

*T*<sup>(*i*)</sup>*T*<sup>(*j*)</sup> = ((*i* + *j*)!/*i*!*j*!)*T*<sup>(*i*+*j*)</sup>.

Over a field of characteristic 0,

*T*<sup>(*i*)</sup> is just *T*<sup>*i*</sup>/*i*!.
