# Antoine's necklace

::: {#o1 .subject cue=lead name="Antoine's necklace"}

In [mathematics](wikipedia://en/18831), **Antoine's necklace** is a topological embedding of the [Cantor set](wikipedia://en/6172) in 3-dimensional [Euclidean space](wikipedia://en/9697), whose complement is not [simply connected](https://en.wikipedia.org/wiki/Simply_connected). It also serves as a counterexample to the claim that all [Cantor spaces](wikipedia://en/352376) are ambiently homeomorphic to each other. It was discovered by ().[^o3]

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

Antoine's necklace is constructed iteratively like so: Begin with a [solid torus](wikipedia://en/1251473) *A*<sup>0</sup> (iteration 0). Next, construct a "necklace" of smaller, linked tori that lie inside *A*<sup>0</sup>. This necklace is *A*<sup>1</sup> (iteration 1). Each torus composing *A*<sup>1</sup> can be replaced with another smaller necklace as was done for *A*<sup>0</sup>. Doing this yields *A*<sup>2</sup> (iteration 2).

This process can be repeated a countably infinite number of times to create an *A*<sup>*n*</sup> for all *n*. Antoine's necklace *A* is defined as the intersection of all the iterations.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Since the solid tori are chosen to become arbitrarily small as the iteration number increases, the connected components of *A* must be single points. It is then easy to verify that *A* is [closed](wikipedia://en/293802), [dense-in-itself](wikipedia://en/8327127), and [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected), having the [cardinality of the continuum](wikipedia://en/1574901). This is sufficient to conclude that as an abstract metric space *A* is homeomorphic to the Cantor set.

However, as a subset of Euclidean space *A* is not ambiently homeomorphic to the standard Cantor set *C*, embedded in **R**<sup>3</sup> on a [line segment](wikipedia://en/22634860). That is, there is no bi-continuous map from **R**<sup>3</sup> → **R**<sup>3</sup> that carries *C* onto *A*. To show this, suppose there was such a map *h* : **R**<sup>3</sup> → **R**<sup>3</sup>, and consider a loop *k* that is interlocked with the necklace. *k* cannot be continuously shrunk to a point without touching *A* because two loops cannot be continuously unlinked. Now consider any loop *j* disjoint from *C*. *j* can be shrunk to a point without touching *C* because we can simply move it through the gap intervals. However, the loop *g* = *h*<sup>−1</sup>(*k*) is a loop that *cannot* be shrunk to a point without touching *C*, which contradicts the previous statement. Therefore, *h* cannot exist.

In fact, there is no homeomorphism of **R**<sup>3</sup> sending *A* to a set of [Hausdorff dimension](wikipedia://en/14294) \< 1, since the complement of such a set must be simply-connected.

Antoine's necklace was used by (txt) to construct **Antoine's horned sphere** (similar to but not the same as [Alexander's horned sphere](https://en.wikipedia.org/wiki/Alexander's_horned_sphere)).[^o9] This construction can be used to show the existence of uncountably many embeddings of a disk or sphere into three-dimensional space, all inequivalent in terms of [ambient isotopy](wikipedia://en/7404467).[^o10]

:::
