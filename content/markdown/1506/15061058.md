# Bernoulli sampling

::: {#o1 .subject cue=lead name="Bernoulli sampling"}

In the theory of finite population sampling, **Bernoulli sampling** is a sampling process where each element of the [population](wikipedia://en/27585) is subjected to an [independent](https://en.wikipedia.org/wiki/Statistical_independence) [Bernoulli trial](wikipedia://en/102653) which determines whether the element becomes part of the sample. An essential property of Bernoulli sampling is that all elements of the population have equal probability of being included in the sample.[^o2]

:::

Bernoulli sampling is therefore a special case of [Poisson sampling](wikipedia://en/15060881). In [Poisson sampling](wikipedia://en/15060881) each element of the population may have a different probability of being included in the sample. In Bernoulli sampling, the probability is equal for all the elements.

Because each element of the population is considered separately for the sample, the sample size is not fixed but rather follows a [binomial distribution](wikipedia://en/3876).

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

The most basic Bernoulli method generates *n* random variates to extract a sample from a population of *n* items. Suppose you want to extract a given percentage *pct* of the population. The algorithm can be described as follows:[^o5]

for each item in the set generate a random non-negative integer R if (R mod 100) \< pct then select item

*Image: Scaled binomial distribution.png.* Scaled f(k, n, 0.2) for four values of n.

A percentage of 20%, say, is usually expressed as a probability *p*=0.2. In that case, random variates are generated in the [unit interval](wikipedia://en/49324). After running the algorithm, a sample of size *k* will have been selected. One would expect to have $k \approx n \cdot p$, which is more and more likely as *n* grows. In fact, It is possible to calculate the probability of obtaining a sample size of *k* by the [Binomial distribution](wikipedia://en/3876):

$$f(k,n,p) = \binom{n}{k}p^k(1-p)^{n-k}$$

**On the left** this function is shown for four values of $n$ and $p=0.2$. In order to compare the values for different values of $n$, the $k$'s in abscissa are scaled from $\left[0, n\right]$ to the unit interval, while the value of the function, in ordinate, is multiplied by the inverse, so that the area under the graph maintains the same value —that area is related to the corresponding [cumulative distribution function](wikipedia://en/5793). The values are shown in [logarithmic scale](wikipedia://en/164055).

*Image: Confidence of bernoulli sampling.png.* Values of *n* such that a Bernoulli sample size is within error in 95% of cases.

**On the right** the minimum values of $n$ that satisfy given error bounds with 95% probability. Given an error, the set of $k$'s within bounds can be described as follows:

$$K_{n, p} = \left\{ k \in \mathbb{N}: \left\vert \frac k n - p \right\vert < \mathrm{error} \right\}$$

The probability to end up within $K$ is given again by the binomial distribution as:

$$\sum_{k \in K} f(k, n, p).$$

The picture shows the lowest values of $n$ such that the sum is at least 0.95. For $p = 0.0$ and $p = 1.00$ the algorithm delivers exact results for all $n$'s. The $p$'s in between are obtained by [bisection](wikipedia://en/646651). Note that, if $100 \cdot p$ is an integer percentage, $\mathrm{error} = 0.005$, guarantees that $100 \cdot k/n = 100 \cdot p$. Values as high as $n = 38400$ can be required for such an exact match.
