# Hidden shift problem

::: {#o1 .subject cue=lead name="Hidden shift problem"}

In [quantum computing](wikipedia://en/25220), the **hidden shift problem** is a type of [oracle](wikipedia://en/22431)-based problem. Various versions of this problem have [quantum algorithms](https://en.wikipedia.org/wiki/Quantum_algorithm) which can run much more quickly than known non-quantum methods for the same problem. In its general form, it is equivalent to the [hidden subgroup problem](wikipedia://en/3728000) for the [dihedral group](wikipedia://en/100267).[^o2] It is a major [open problem](wikipedia://en/1333335) to understand how well quantum algorithms can perform for this task, as it can be applied to break [lattice-based cryptography](wikipedia://en/18657553).[^o3][^o4]

:::

## Problem statement {#Problem_statement}

The hidden shift problem states: Given an [oracle](wikipedia://en/22431) $O$ that encodes two functions $f$ and $g$, there is an $n$-bit string $s$ for which $g(x) = f(x + s)$ for all $x$. Find $s$.[^o6]

Functions such as the [Legendre symbol](wikipedia://en/18567) and [bent functions](wikipedia://en/24465207) satisfy these constraints.[^o7]

::: {#o9 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

With a quantum algorithm that is defined as $|s\rangle = H^{\otimes n} O_{f} H^{\otimes n} O_{\hat{g}} H^{\otimes n}|0^{n}\rangle$, where $H$ is the [Hadamard gate](https://en.wikipedia.org/wiki/Hadamard_gate) and $\hat{g}$ is the [Fourier transform](wikipedia://en/52247) of $g$, certain instantiations of this problem can be solved in a polynomial number of queries to $O$ while taking exponential queries with a classical algorithm.

:::
