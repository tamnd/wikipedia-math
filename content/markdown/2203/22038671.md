# Least-upper-bound property

::: {#o1 .subject cue=lead name="Least-upper-bound property"}

*Image: Illustration of supremum.svg.* Every non-empty subset $M$ of the real numbers $\mathbb{R}$ which is bounded from above has a least upper bound.

In [mathematics](wikipedia://en/18831), the **least-upper-bound property** (sometimes called **completeness**, **supremum property** or **l.u.b. property**)[^o2] is a fundamental property of the [real numbers](wikipedia://en/20646438). More generally, a [partially ordered set](wikipedia://en/23572) $X$ has the least-upper-bound property if every non-empty [subset](wikipedia://en/26691) of $X$ with an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) has a [*least* upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) (supremum) in $X$. Not every (partially) ordered set has the least upper bound property. For example, the set $\mathbb{Q}$ of all [rational numbers](wikipedia://en/19727024) with its natural order does *not* have the least upper bound property.

:::

The least-upper-bound property is one form of the [completeness axiom](wikipedia://en/29322627) for the real numbers, and is sometimes referred to as **Dedekind completeness**.[^o3] It can be used to prove many of the fundamental results of [real analysis](wikipedia://en/26478), such as the [intermediate value theorem](wikipedia://en/14884), the [Bolzano–Weierstrass theorem](wikipedia://en/31211), the [extreme value theorem](wikipedia://en/276881), and the [Heine–Borel theorem](wikipedia://en/59595). It is usually taken as an axiom in synthetic [constructions of the real numbers](wikipedia://en/296666), and it is also intimately related to the construction of the real numbers using [Dedekind cuts](wikipedia://en/45569).

In [order theory](wikipedia://en/361924), this property can be generalized to a notion of [completeness](wikipedia://en/549445) for any [partially ordered set](wikipedia://en/23572). A [linearly ordered set](https://en.wikipedia.org/wiki/Linearly_ordered_set) that is [dense](wikipedia://en/6320997) and has the least upper bound property is called a [linear continuum](wikipedia://en/17368856).

## Statement of the property {#Statement_of_the_property}

### Statement for real numbers {#Statement_for_real_numbers}

Let $S$ be a non-empty set of [real numbers](wikipedia://en/20646438).

- A real number $x$ is called an **[upper bound](https://en.wikipedia.org/wiki/Upper_bound)** for $S$ if $x \ge s$ for all $s \in S$.
- A real number $x$ is the **least upper bound** (or **[supremum](https://en.wikipedia.org/wiki/Supremum)**) for $S$ if $x$ is an upper bound for $S$ and $x \le y$ for every upper bound $y$ of $S$.

The **least-upper-bound property** states that any non-empty set of real numbers that has an upper bound must have a least upper bound in *real numbers*.

### Generalization to ordered sets {#Generalization_to_ordered_sets}

*Image: Dedekind cut at square root of two.svg.* *Red:* the set $\left\{ x \in \mathbf{Q} : x^2 \le 2 \right\}$. *Blue:* the set of its upper bounds in $\mathbf{Q}$.

More generally, one may define upper bound and least upper bound for any [subset](wikipedia://en/27631) of a [partially ordered set](wikipedia://en/23572) $X$, with “real number” replaced by “element of $X$”. In this case, we say that $X$ has the least-upper-bound property if every non-empty subset of $X$ with an upper bound has a least upper bound in $X$.

For example, the set $\mathbf{Q}$ of [rational numbers](wikipedia://en/19727024) does not have the least-upper-bound property under the usual order. For instance, the set

$$\left\{ x \in \mathbf{Q} : x^2 \le 2 \right\} = \mathbf{Q} \cap \left(-\sqrt{2}, \sqrt{2}\right)$$

has an upper bound in $\mathbf{Q}$, but does not have a least upper bound in $\mathbf{Q}$ (since the square root of two is [irrational](wikipedia://en/20647689)). The [construction of the real numbers](wikipedia://en/296666) using [Dedekind cuts](wikipedia://en/45569) takes advantage of this failure by defining the irrational numbers as the least upper bounds of certain subsets of the rationals.

## Proof {#Proof}

### Logical status {#Logical_status}

For the real numbers, the least-upper-bound property is equivalent to other forms of the [completeness axiom](https://en.wikipedia.org/wiki/Completeness_axiom), such as the convergence of [Cauchy sequences](wikipedia://en/6085) or the [nested intervals theorem](https://en.wikipedia.org/wiki/Nested_intervals_theorem). The logical status of the property depends on the [construction of the real numbers](wikipedia://en/296666) used: in a [synthetic approach](wikipedia://en/296666#Synthetic_approach), the property is usually taken as an [axiom](wikipedia://en/928); in other approaches, the property must be proved as a [theorem](wikipedia://en/30977), either directly from the construction or as a consequence of some other form of completeness.

::: {#o11 .proof cue=heading name="Proof using Cauchy sequences"}

### Proof using Cauchy sequences {#Proof_using_Cauchy_sequences}

The least-upper-bound property can be proved from the [Archimedean property](wikipedia://en/264158) together with the assumption that every Cauchy sequence of real numbers converges.[^o12] Let $S$ be a [nonempty](https://en.wikipedia.org/wiki/Nonempty) set of real numbers. If $S$ has exactly one element, then its only element is a least upper bound. So consider $S$ with more than one element, and suppose that $S$ has an upper bound $B_{1}$. Since $S$ is nonempty and has more than one element, there exists a real number $A_{1}$ that is not an upper bound for $S$. Define sequences $A_{1}, A_{2}, A_{3}, ...$ and $B_{1}, B_{2}, B_{3}, ...$ recursively as follows:

1. Check whether $(A_{n} + B_{n}) \text{⁄} 2$ is an upper bound for $S$.
1. If it is, let $A_{n+1} = A_{n}$ and let $B_{n+1} = (A_{n} + B_{n}) \text{⁄} 2$.
1. Otherwise there must be an element $s$ in $S$ so that $s>(A_{n} + B_{n}) \text{⁄} 2$. Let $A_{n+1} = s$ and let $B_{n+1} = B_{n}$.

Then $A_{1} \le A_{2} \le A_{3} \le \cdots \le B_{3} \le B_{2} \le B_{1}$. Now $|A_{n} - B_{n}| \to 0$ as $n \to \infty$, by the Archimedean property. It follows that both sequences are Cauchy and have the same limit $L$, which must be the least upper bound for $S$.

:::

## Applications {#Applications}

The least-upper-bound property of $\mathbf{R}$ can be used to prove many of the main foundational theorems in [real analysis](wikipedia://en/26478).

::: {#o16 .statement kind=statement/theorem cue=named-heading name="Intermediate value theorem"}

### Intermediate value theorem {#Intermediate_value_theorem}

Let $f\,: [a, b] \to \mathbf{R}$ be a [continuous function](wikipedia://en/6122), and suppose that $f\,(a) < 0$ and $f\,(b) > 0$. In this case, the [intermediate value theorem](wikipedia://en/14884) states that $f$ must have a [root](https://en.wikipedia.org/wiki/Root_of_a_function) in the interval $[a, b]$. This theorem can be proved by considering the set

$$S \,=\, \{s \in [a, b] \,:\, f\,(x) < 0\text{ for }\text{ all } x \le s\}.$$

That is, $S$ is the initial segment of $[a, b]$ that takes negative values under $f$. Then $b$ is an upper bound for $S$, and the least upper bound must be a root of $f$.

:::

::: {#o18 .statement kind=statement/theorem cue=named-heading name="Bolzano–Weierstrass theorem"}

### Bolzano–Weierstrass theorem {#Bolzano–Weierstrass_theorem}

The [Bolzano–Weierstrass theorem](wikipedia://en/31211) for $\mathbf{R}$ states that every [sequence](wikipedia://en/27838) $x_{n}$ of real numbers in a closed interval $[a, b]$ must have a convergent [subsequence](wikipedia://en/236098). This theorem can be proved by considering the set

$$S \,=\, \{s \in [a, b] \,:\, s \le x_{n}\text{ for } \operatorname{infinitely} \operatorname{many} n\}$$

Clearly, $a\in S$, and $S$ is not empty. In addition, $b$ is an upper bound for $S$, so $S$ has a least upper bound $c$. Then $c$ must be a [limit point](https://en.wikipedia.org/wiki/Limit_point) of the sequence $x_{n}$, and it follows that $x_{n}$ has a subsequence that converges to $c$.

:::

::: {#o20 .statement kind=statement/theorem cue=named-heading name="Extreme value theorem"}

### Extreme value theorem {#Extreme_value_theorem}

Let $f\,: [a, b] \to \mathbf{R}$ be a [continuous function](wikipedia://en/6122) and let $M = \sup f\,([a, b])$, where $M = \infty$ if $f\,([a, b])$ has no upper bound. The [extreme value theorem](wikipedia://en/276881) states that $M$ is finite and $f\,(c) = M$ for some $c \in [a, b]$. This can be proved by considering the set

$$S \,=\, \{s \in [a, b] \,:\, \sup f\,([s, b]) = M\}.$$

By definition of $M$, $a \in S$, and by its own definition, $S$ is bounded by $b$. If $c$ is the least upper bound of $S$, then it follows from continuity that $f\,(c) = M$.

:::

::: {#o22 .statement kind=statement/theorem cue=named-heading name="Heine–Borel theorem"}

### Heine–Borel theorem {#Heine–Borel_theorem}

Let $[a, b]$ be a closed interval in $\mathbf{R}$, and let $\{U_{\alpha}\}$ be a collection of [open sets](wikipedia://en/39358) that [covers](wikipedia://en/317552) $[a, b]$. Then the [Heine–Borel theorem](wikipedia://en/59595) states that some finite subcollection of $\{U_{\alpha}\}$ covers $[a, b]$ as well. This statement can be proved by considering the set

$$S \,=\, \{s \in [a, b] \,:\, [a, s] \operatorname{can}\text{ be } \operatorname{covered}\text{ by } \operatorname{finitely} \operatorname{many} U_{\alpha}\}.$$

The set $S$ obviously contains $a$, and is bounded by $b$ by construction. By the least-upper-bound property, $S$ has a least upper bound $c \in [a, b]$. Hence, $c$ is itself an element of some open set $U_{\alpha}$, and it follows for $c < b$ that $[a, c + \delta]$ can be covered by finitely many $U_{\alpha}$ for some sufficiently small $\delta > 0$. This proves that $c + \delta \in S$ and $c$ is not an upper bound for $S$. Consequently, $c = b$.

:::

:::

## History {#History}

The importance of the least-upper-bound property was first recognized by [Bernard Bolzano](wikipedia://en/302185) in his 1817 paper *Rein analytischer Beweis des Lehrsatzes dass zwischen je zwey Werthen, die ein entgegengesetztes Resultat gewähren, wenigstens eine reelle Wurzel der Gleichung liege*.[^o24]
