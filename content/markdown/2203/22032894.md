# Semicomputable function

::: {#o1 .subject cue=lead name="Semicomputable function"}

In [computability theory](https://en.wikipedia.org/wiki/Recursion_theory), a **semicomputable function** is a [partial function](wikipedia://en/23577) $f : \mathbb{Q} \rightarrow \mathbb{R}$ that can be approximated either from above or from below by a [computable function](wikipedia://en/1139338).

:::

More precisely a [partial function](wikipedia://en/23577) $f : \mathbb{Q} \rightarrow \mathbb{R}$ is **upper semicomputable**, meaning it can be approximated from above, if there exists a [computable function](wikipedia://en/1139338) $\phi(x,k) : \mathbb{Q} \times \mathbb{N} \rightarrow \mathbb{Q}$, where $x$ is the desired parameter for $f(x)$ and $k$ is the level of approximation, such that:

- $$\lim_{k \rightarrow \infty} \phi(x,k) = f(x)$$
- $$\forall k \in \mathbb{N} : \phi(x,k+1) \leq \phi(x,k)$$

Completely analogous a [partial function](wikipedia://en/23577) $f : \mathbb{Q} \rightarrow \mathbb{R}$ is **lower semicomputable** if and only if $-f(x)$ is upper semicomputable or equivalently if there exists a [computable function](wikipedia://en/1139338) $\phi(x,k)$ such that:

- $$\lim_{k \rightarrow \infty} \phi(x,k) = f(x)$$
- $$\forall k \in \mathbb{N} : \phi(x,k+1) \geq \phi(x,k)$$

If a [partial function](wikipedia://en/23577) is both upper and lower **semicomputable** it is called computable.
