# Surrogate data

::: {#o1 .subject cue=lead name="Surrogate data"}

**Surrogate data**, sometimes known as **analogous data**,[^o3] usually refers to [time series](wikipedia://en/406624) data that is produced using well-defined (linear) models like [ARMA](https://en.wikipedia.org/wiki/Autoregressive–moving-average_model) processes that reproduce various statistical properties like the [autocorrelation](wikipedia://en/2724) structure of a measured data set.[^o2] The resulting surrogate data can then for example be used for testing for non-linear structure in the empirical data; this is called [surrogate data testing](wikipedia://en/34590269).

:::

Surrogate or analogous data also refers to data used to supplement available data from which a [mathematical model](wikipedia://en/20590) is built. Under this definition, it may be generated (i.e., [synthetic data](wikipedia://en/25270778)) or transformed from another source.[^o3]

::: {#o5 .application cue=heading name="Uses"}

## Uses {#Uses}

Surrogate data is used in environmental and laboratory settings, when study data from one source is used in estimation of characteristics of another source.[^o6] For example, it has been used to model population trends in animal species.[^o7] It can also be used to model biodiversity, as it would be difficult to gather actual data on all species in a given area.[^o8]

Surrogate data may be used in forecasting. Data from similar series may be pooled to improve forecast accuracy.[^o9] Use of surrogate data may enable a model to account for patterns not seen in historical data.[^o10]

Another use of surrogate data is to test models for non-linearity. The term [surrogate data testing](wikipedia://en/34590269) refers to algorithms used to analyze models in this way.[^o11] These tests typically involve generating data, whereas surrogate data in general can be produced or gathered in many ways.[^o3]

:::

::: {#o13 .definition kind=definition/construction cue=heading name="Methods"}

## Methods {#Methods}

One method of surrogate data is to find a source with similar conditions or parameters, and use those data in modeling.[^o7] Another method is to focus on patterns of the underlying system, and to search for a similar pattern in related data sources (for example, patterns in other related species or environmental areas).[^o8]

Rather than using existing data from a separate source, surrogate data may be generated through statistical processes,[^o2] which may involve random data generation[^o3] using constraints of the model or system.[^o11]

:::
