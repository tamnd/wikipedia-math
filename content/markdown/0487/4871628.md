# P2-irreducible manifold

::: {#o1 .subject cue=lead name="P2-irreducible manifold"}

In [mathematics](wikipedia://en/18831), a **P<sup>2</sup>-irreducible manifold** is a [3-manifold](wikipedia://en/1018257) that is [irreducible](https://en.wikipedia.org/wiki/Irreducible_manifold) and contains no [2-sided](wikipedia://en/4785316) $\mathbb RP^2$ ([real projective plane](wikipedia://en/411325)). An [orientable manifold](https://en.wikipedia.org/wiki/Orientable_manifold) is P<sup>2</sup>-irreducible if and only if it is irreducible.[^o2] Every non-orientable P<sup>2</sup>-irreducible manifold is a [Haken manifold](wikipedia://en/236567).[^o3]

:::
