# HHL algorithm

::: {#o1 .subject cue=lead name="HHL algorithm"}

The **Harrow–Hassidim–Lloyd** (**HHL**) **algorithm** is a [quantum algorithm](https://en.wikipedia.org/wiki/Quantum_algorithm) for obtaining certain limited information about the solution to a [system of linear equations](wikipedia://en/113087), introduced by [Aram Harrow](https://en.wikipedia.org/wiki/Aram_Harrow), Avinatan Hassidim, and [Seth Lloyd](https://en.wikipedia.org/wiki/Seth_Lloyd). Specifically, the algorithm estimates quadratic functions of the solution vector to a given system.[^o2]

:::

The algorithm is one of the main fundamental algorithms expected to provide a speedup over their classical counterparts, along with [Shor's factoring algorithm](https://en.wikipedia.org/wiki/Shor's_Algorithm) and [Grover's search algorithm](wikipedia://en/58498). Assuming the system is [sparse](wikipedia://en/341015),[^o3] has a low [condition number](wikipedia://en/6934) $\kappa$, and that the user is only interested in certain information about solution vector and not the entire vector itself, the algorithm has a runtime of $O(\log(N)\kappa^2)$, where $N$ is the number of variables. This offers an exponential speedup over the fastest classical algorithm, which runs in $O(N\kappa)$ (or $O(N\sqrt{\kappa})$ for positive semidefinite matrices).

An implementation of the HHL algorithm was first demonstrated in 2013 by three independent publications, consisting of simple systems on specially designed devices.[^o4][^o5][^o6] The first demonstration of a general-purpose version of the algorithm appeared in 2018.[^o7]

## Overview {#Overview}

Given an $N \times N$ [Hermitian matrix](wikipedia://en/189682) $A$ and unit vector $\vec b\in\mathbb{R}^N$, the HHL algorithms prepares the quantum state $|x\rangle$ whose amplitudes are the entries of the solution $\vec x\in\mathbb{R}^N$ to the linear system $A\vec x=\vec b$. The algorithm cannot efficiently output the solution *x* itself, but allows one to efficiently estimate $\vec{x}^{T}M\vec{x}$ for a Hermitian matrix $M$.

The algorithm first prepares the quantum state $|b\rangle$ whose amplitudes are equal to the entries of $\vec b$. Using [Hamiltonian simulation](wikipedia://en/60663582), the unitary operator $e^{iAt}$ is applied to $|b\rangle$ for a superposition of different times *t*. The algorithm then uses [quantum phase estimation](https://en.wikipedia.org/wiki/Quantum_phase_estimation) to decompose $|b\rangle$ in the eigenbasis of $A$ and find the corresponding eigenvalues $\lambda_j$. The state of the system after this step is approximately

$$\sum_{j \mathop =1}^N \beta_j|u_j\rangle|\lambda_j\rangle,$$

where $u_j$ are the eigenvectors of *A* and $\beta_j$ is the *j*-th coefficient of *b* in the eigenbasis of *A*.

We would then like to apply the linear map taking $|\lambda_j\rangle$ to $C\lambda^{-1}_j|\lambda_j\rangle$ for some constant *C*. This map is not unitary and must be implemented using a quantum measurement with a nonzero probability of failure. After it succeeds, we have uncomputed the $|\lambda_j\rangle$ register and have a state proportional to

$$\sum_{i \mathop =1}^N \beta_i\lambda^{-1}_j|u_j\rangle=A^{-1}|b\rangle=|x\rangle.$$

By performing the quantum measurement corresponding to *M*, we get an estimate of $\vec{x}^{T}M\vec{x}$. One could use [quantum tomography](https://en.wikipedia.org/wiki/Quantum_tomography) to retrieve all components of *x*, but this would require repeating the algorithm roughly *N* times.

## Detailed description {#Detailed_description}

### Assumptions and initialization {#Assumptions_and_initialization}

The algorithm requires the following assumptions to hold:

1. The algorithm requires *A* to be [Hermitian](wikipedia://en/189682) so that it can be exponentiated into a [unitary operator](wikipedia://en/225999). If *A* is not Hermitian, one can define a Hermitian matrix $\mathbf{C} = \begin{bmatrix} 0 & A \\ A^\dagger & 0 \end{bmatrix}$ and solve $Cy=\begin{bmatrix} b \\ 0 \end{bmatrix}$ to obtain $y = \begin{bmatrix} 0 \\ x \end{bmatrix}$.
1. The algorithm requires an efficient procedure to prepare $|b\rangle$. It is assumed that either $|b\rangle$ has already been prepared or there exists some *B* which takes some quantum state $|\mathrm{initial}\rangle$ to $|b\rangle$ efficiently. Any error in the preparation of $|b\rangle$ is ignored.
1. The algorithm assumes that the state $| \psi_0 \rangle$ can be prepared efficiently, where $| \psi_0 \rangle := \sqrt{2/T} \sum_{\tau \mathop =0}^{T-1} \sin\pi\left(\tfrac{\tau+\tfrac{1}{2}}{T}\right) |\tau\rangle$ for some large *T*. The coefficients of $| \psi_0 \rangle$ are chosen to minimize a certain quadratic loss function which induces error in the $U_\mathrm{invert}$ subroutine described below.
1. The algorithm assumes that the unitary operator $e^{iAt}$ can be applied efficiently. This is possible using [Hamiltonian simulation](wikipedia://en/60663582) if *A* is *s*-sparse and efficiently row computable, meaning it has at most *s* nonzero entries per row which can be computed in time O(*s*) given a row index. One can then apply $e^{iAt}$ in time $O(\log(N)s^2t)$.

### $U_{\operatorname{invert}}$ subroutine {#subroutine}

The key subroutine to the algorithm, denoted $U_\mathrm{invert}$, is defined as follows using [phase estimation](https://en.wikipedia.org/wiki/Phase_estimation):

1. Prepare $|\psi_0\rangle^C$ on register *C*
1. Apply the conditional Hamiltonian evolution (sum)
1. Apply the Fourier transform to the register *C*. Denote the resulting basis states with $|k\rangle$ for *k* = 0, ..., *T* − 1. Define $\lambda_k:=2\pi k/t_0$.
1. Adjoin a three-dimensional register *S* in the state

$$|h(\lambda_k)\rangle^S := \sqrt{1-f(\lambda_k)^2 - g(\lambda_k)^2} |\mathrm{nothing} \rangle^S + f(\lambda_k)| \mathrm{well} \rangle^S+g (\lambda_k) | \mathrm{ill} \rangle^S,$$

1. Reverse steps 1–3, uncomputing any garbage produced along the way.

The phase estimation procedure in steps 1-3 estimates the eigenvalues of *A* up to error $\epsilon$.

The ancilla register in step 4 is needed to construct a state with inverted eigenvalues corresponding to the diagonalized inverse of *A*. The states 'nothing', 'well' and 'ill' are used to direct the loop body; 'nothing' indicates that the matrix inversion has not yet taken place, 'well' indicates that it has and the loop should halt, and 'ill' indicates that part of $|b\rangle$ is in the ill-conditioned subspace of *A* and the algorithm cannot produce the desired inversion. Producing a state proportional to the inverse of *A* requires 'well' to be measured, after which the overall state collapses to the desired output.

### Main loop {#Main_loop}

The main loop follows [amplitude amplification](https://en.wikipedia.org/wiki/Amplitude_amplification): starting with $U_\mathrm{invert}B|\mathrm{initial}\rangle$, repeatedly apply

$$U_\mathrm{invert}B (I-2|\mathrm{initial}\rangle\langle\mathrm{initial}|) B^\dagger U^\dagger_\mathrm{invert} (I-2|\mathrm{well}\rangle\langle \mathrm{well}|).$$

After each iteration, $S$ is measured and will produce a value of 'nothing', 'well', or 'ill.' The loop is repeated until 'well' is measured, which occurs with some probability $p$. Using amplitude amplification achieves a given error using $O(1/\sqrt{p})$ queries, as opposed to $1/p$ using naive repetition.

After successfully measuring 'well' on $S$ the system will be in a state proportional to

$$\sum_{i \mathop =1}^N \beta_i \lambda^{-1}_j |u_j\rangle = A^{-1} |b \rangle = | x\rangle.$$

The quantum measurement corresponding to M then gives an estimate of $\vec{x}^{T}M\vec{x}$.

## Analysis {#Analysis}

### Classical efficiency {#Classical_efficiency}

The best classical algorithm which produces the actual solution vector $\vec{x}$ is [Gaussian elimination](wikipedia://en/13035), which runs in $O(N^3)$ time.

If *A* is *s*-sparse and positive semi-definite, then the [Conjugate Gradient method](https://en.wikipedia.org/wiki/Conjugate_Gradient_method) can be used to find the solution vector $\vec{x}$, which can be found in $O(Ns\kappa)$ time by minimizing the quadratic function $\lVert A\vec{x} -\vec{b} \rVert^2$.

When only a summary statistic of the solution vector $\vec{x}$ is needed, as is the case for the HHL algorithm, a classical computer can find an estimate of $\vec{x}^\dagger M \vec{x}$ in $O(N\sqrt{\kappa})$.

### Quantum efficiency {#Quantum_efficiency}

The runtime of the algorithm originally proposed by Harrow et al. was shown to be $O(\kappa^2\log N/\varepsilon)$, where $\varepsilon>0$ is the error parameter and $\kappa$ is the [condition number](wikipedia://en/6934) of $A$. This was subsequently improved to $O(\kappa \log^3\kappa \log N /\varepsilon^3)$ by Andris Ambainis[^o16] and to $O(\kappa \log N /\varepsilon)$ for large condition number cases by Peniel Tsemo et al,[^o17] and a quantum algorithm with runtime polynomial in $\log(1/\varepsilon)$ was developed by Childs et al.[^o18] Since the HHL algorithm maintains its logarithmic scaling in $N$ only for sparse or low rank matrices, Wossnig et al.[^o19] extended the HHL algorithm based on a quantum singular value estimation technique and provided a linear system algorithm for dense matrices which runs in $O(\sqrt N \log N \kappa^2)$ time compared to the $O(N \log N \kappa^2)$ of the standard HHL algorithm.

### Optimality {#Optimality}

The performance of the matrix inversion algorithm depends on the [condition number](wikipedia://en/6934) $\kappa$ of *A*, which is the ratio of the largest and smallest eigenvalues. As $\kappa$ increases *A* becomes closer to non-invertible, so the solution vector becomes less stable and the performance of gradient descent methods decreases. The HHL algorithm assumes that all [singular values](https://en.wikipedia.org/wiki/Singular_values) of $A$ lie in $[1/\kappa, 1]$, in which case the runtime is proportional to $\kappa^2$, improving the speedup further when $\kappa$ is $\mathrm{poly}(\log(N))$.[^o2]

A quantum algorithm for linear systems with poly-logarithmic runtime in $\kappa$ would imply that [BQP](wikipedia://en/4080) is equal to [PSPACE](wikipedia://en/39351), which is believed to be false.[^o2]

### Error analysis {#Error_analysis}

The dominant source of error is the application of $e^{iAt}$ using Hamiltonian simulation. If $A$ is s-sparse this can be done with error bounded by some constant $\varepsilon$, which will result in an additive error in the output state $|x\rangle$.

The phase estimation step errs by $O(1/t_0)$ in estimating $\lambda$, which results in a relative error of $O((\lambda t_0)^{-1})$ in $1/\lambda$. If $\lambda \ge 1/\kappa$, taking $t_0=O(\kappa\varepsilon)$ induces a final error of $\varepsilon$. This requires the overall runtime to be increased proportional to $O(1/\varepsilon)$ in order to minimize error.

## Experimental realization {#Experimental_realization}

While a general-purpose quantum computer does not yet exist, one can still try to execute a proof of concept implementation of the HHL algorithm. This remained a challenge for years, until three groups independently did so in 2013.

On February 5, 2013, a group led by [Stefanie Barz](https://en.wikipedia.org/wiki/Stefanie_Barz) reported an implementation of the HHL algorithm on a photonic quantum computer. The implementation used two consecutive entangling gates on the same pair of polarization-encoded qubits. Two separately controlled NOT gates were realized where the successful operation of the first was heralded by a measurement of two ancillary photons. Experimental measurements of the fidelity in the obtained output state ranged from 64.7% to 98.1% due to the influence of higher-order emissions from spontaneous parametric down-conversion.[^o5]

On February 8, 2013, Pan et al. reported a proof-of-concept experimental demonstration of the quantum algorithm using a 4-qubit NMR quantum computer. The implementation was tested using linear systems of 2 variables. Across three experiments, the solution vector was obtained with over 96% fidelity.[^o6]

On February 18, 2013, Cai et al. reported an experimental demonstration solving 2-by-2 linear systems. The quantum circuit was optimized and compiled into a linear optical network with four photonic qubits and four controlled logic gates, which were used to coherently implement the subroutines of the HHL algorithm. For various input vectors, the realization gave solutions with fidelities ranging from 0.825 to 0.993.[^o23]

Another experimental demonstration using NMR for solving an 8\*8 system was reported by Wen et al.[^o24] in 2018 using the algorithm developed by Subaşı et al.[^o25]

## Proposed applications {#Proposed_applications}

Several concrete applications of the HHL algorithm have been proposed, which analyze the algorithm's input assumptions and output guarantees for particular problems.

**Electromagnetic scattering**

Clader et al. gave a version of the HHL algorithm which allows a [preconditioner](wikipedia://en/5165246) to be included, which can be used improve the dependence on the [condition number](wikipedia://en/6934). The algorithm was applied to solving for the [radar cross-section](https://en.wikipedia.org/wiki/Radar_cross-section) of a complex shape, which was one of the first examples of an application of the HHL algorithm to a concrete problem.[^o27]

**Solving linear differential equations**

Berry proposed an algorithm for solving linear, time-dependent [initial value problems](wikipedia://en/498383) using the HHL algorithm.[^o28]

**Solving nonlinear differential equations**

Two groups proposed[^o29] efficient algorithms for numerically integrating dissipative nonlinear [ordinary differential equations](wikipedia://en/32742753). Liu et al.[^o30] utilized [Carleman linearization](wikipedia://en/62503788) for second order equations and Lloyd et al.[^o31] used a mean field linearization method inspired by the [nonlinear Schrödinger equation](wikipedia://en/1422748) for general order nonlinearities. The resulting linear equations are solved using quantum algorithms for linear differential equations.

**Finite element method**

The [finite element method](wikipedia://en/18233581) approximates linear [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations) using large systems of linear equations. Montanaro and Pallister demonstrate that the HHL algorithm can achieve a polynomial quantum speedup for the resulting linear systems. Exponential speedups are not expected for problems in a fixed dimension or for which the solution meets certain smoothness conditions, such as certain high-order problems in many-body dynamics, or some problems in [computational finance](wikipedia://en/2910837).[^o32]

**Least-squares fitting**

Wiebe et al. gave a quantum algorithm to determine the quality of a [least-squares fit](https://en.wikipedia.org/wiki/Least-squares_fit). The optimal coefficients cannot be calculated directly from the output of the quantum algorithm, but the algorithm still outputs the optimal least-squares error.[^o33]

**Machine learning**

Many [quantum machine learning](https://en.wikipedia.org/wiki/Quantum_machine_learning) algorithms have been developed, a large number of which use the HHL algorithm as a subroutine. The runtime of certain classical algorithms is often polynomial in the size and dimension of a dataset, while the HHL algorithm can give an exponential speedup in some cases. However, a line work initiated by [Ewin Tang](https://en.wikipedia.org/wiki/Ewin_Tang) has found that for most quantum machine learning algorithms, there are classical algorithms giving the same exponential speedups with similar input assumptions.

**Finance**

Proposals for using HHL in finance include solving [partial differential equations](wikipedia://en/52564) for the [Black–Scholes equation](wikipedia://en/17656561) and determining [portfolio optimization](https://en.wikipedia.org/wiki/Portfolio_optimization) via a [Markowitz solution](https://en.wikipedia.org/wiki/Markowitz_model).[^o34]

**Quantum chemistry**

The linearized [coupled cluster](https://en.wikipedia.org/wiki/Coupled_cluster) method in quantum chemistry can be recast as a system of linear equations. In 2023, Baskaran et al. proposed the use of HHL algorithm to solve the resulting linear systems.[^o35] The number of state register qubits in the quantum algorithm is the logarithm of the number of excitations, offering an exponential reduction in the number of required qubits when compared to using the [variational quantum eigensolver](https://en.wikipedia.org/wiki/Variational_quantum_eigensolver) or [quantum phase estimation](wikipedia://en/28615265).

## Implementation difficulties {#Implementation_difficulties}

Recognizing the importance of the HHL algorithm in the field of *quantum machine learning*, Scott Aaronson[^o37] analyzes the caveats and factors that could limit the actual quantum advantage of the algorithm.

1. the solution vector, $|b\rangle$, has to be *efficiently* prepared in the quantum state. If the vector is not close to uniform, the state preparation is likely to be costly, and if it takes $O(n^c)$ steps the exponential advantage of HHL would vanish.
1. the QPE phases calls for the generation of the unitary $e^{i A t}$, and its controlled application. The efficiency of this step depends on the $A$ matrix being sparse and 'well conditioned' (low $\kappa$). Otherwise, the application of $e^{i A t}$ would grow as $O(n^c)$ and once again, the algorithm's quantum advantage would vanish.
1. lastly, the vector, $|x\rangle$, is not readily accessible. The HHL algorithm enables learning a 'summary' of the vector, namely the result of measuring the expectation of an operator $\langle x|M|x\rangle$. If actual values of $\vec{x}$ are needed, then HHL would need to be repeated $O(n)$ times, killing the exponential speed-up. However, three ways of avoiding getting the actual values have been proposed: first, if only some properties of the solution are needed;[^o38] second, if the results are needed only to feed downstream matrix operations; third, if only a sample of the solution is needed.[^o39]
