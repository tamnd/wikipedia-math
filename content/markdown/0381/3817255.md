# Tree spanner

*Image: Tree spanner 2.svg.* The lowest $k$ tree spanner for the graph $G$ is $k=3/2$ because of the necessarily longer path between the red vertices, which is $3/2$ times as long as the shortest distance between them in $G$

::: {#o1 .subject cue=lead name="Tree spanner"}

A **tree *k*-spanner** (or simply ***k*-spanner**) of a [graph](wikipedia://en/325806) $G$ is a [spanning subtree](https://en.wikipedia.org/wiki/Spanning_tree_%28mathematics%29) $T$ of $G$ in which the distance between every pair of vertices is at most $k$ times their [distance](wikipedia://en/1020021) in $G$.

:::

## Known Results {#Known_Results}

There are several papers written on the subject of tree spanners. One of these was entitled *Tree Spanners*[^o3] written by mathematicians Leizhen Cai and [Derek Corneil](https://en.wikipedia.org/wiki/Derek_Corneil), which explored theoretical and algorithmic problems associated with tree spanners. Some of the conclusions from that paper are listed below. $n$ is always the number of vertices of the graph, and $m$ is its number of edges.

1. A tree 1-spanner, if it exists, is a [minimum spanning tree](wikipedia://en/41795) and can be found in $\mathcal{O}(m \log \beta (m,n))$ time (in terms of complexity) for a weighted graph, where $\beta(m,n) = \min\left\{i\mid \log^{i} n \leq m/n\right\}$. Furthermore, every tree 1-spanner admissible weighted graph contains a unique minimum spanning tree.
1. A tree 2-spanner can be constructed in $\mathcal{O}(m+n)$ time, and the tree $t$-spanner problem is [NP-complete](wikipedia://en/23385892) for any fixed integer $t > 3$.
1. The complexity for finding a minimum tree spanner in a digraph is $\mathcal{O}((m+n)\cdot\alpha(m+n,n))$, where $\alpha(m+n,n)$ is a functional inverse of the [Ackermann function](wikipedia://en/2925)
1. The minimum 1-spanner of a weighted graph can be found in $\mathcal{O}(mn+n^2\log(n))$ time.
1. For any fixed rational number $t > 1$, it is NP-complete to determine whether a weighted graph contains a tree t-spanner, even if all edge weights are positive integers.
1. A tree spanner (or a minimum tree spanner) of a digraph can be found in linear time.
1. A digraph contains at most one tree spanner.
1. The quasi-tree spanner of a weighted digraph can be found in $\mathcal{O}(m \log \beta(m,n))$ time.
