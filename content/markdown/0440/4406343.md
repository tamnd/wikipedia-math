# Chronology of computation of pi

::: {#o1 .subject cue=lead name="Chronology of computation of pi"}

The table below is a brief chronology of computed numerical values of, or bounds on, the mathematical constant [$\pi$](wikipedia://en/23601). For more detailed explanations for some of these calculations, see [Approximations of $\pi$](https://en.wikipedia.org/wiki/Approximations_of_π).

:::

*Image: PiComputationHistory.svg.* Graph showing how the record precision of numerical approximations to pi measured in decimal places (depicted on a logarithmic scale), evolved in human history. The time before 1400 is compressed.
