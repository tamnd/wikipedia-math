# L-infinity

::: {#o1 .subject cue=lead name="L-infinity"}

In [mathematics](wikipedia://en/18831), $\ell^\infty$, the (real or complex) [vector space](wikipedia://en/32370) of bounded sequences with the [supremum](https://en.wikipedia.org/wiki/Supremum) norm, and $L^\infty = L^\infty(X,\Sigma,\mu)$, the vector space of [essentially bounded](https://en.wikipedia.org/wiki/Essentially_bounded) measurable functions with the [essential supremum](https://en.wikipedia.org/wiki/Essential_supremum) norm, are two closely related [Banach spaces](wikipedia://en/3989). In fact the former is a special case of the latter. As a Banach space they are, respectively, the continuous dual of the Banach spaces $\ell_1$ of absolutely summable sequences, and $L^1 = L^1(X,\Sigma, \mu)$ of absolutely integrable measurable functions (if the measure space fulfills the conditions of being localizable and therefore semifinite).[^o2] Pointwise multiplication gives them the structure of a [Banach algebra](wikipedia://en/4665), and in fact they are the standard examples of abelian [Von Neumann algebras](wikipedia://en/294185).

:::

## Sequence space {#Sequence_space}

The vector space $\ell^\infty$ is a [sequence space](wikipedia://en/1701075) whose elements are the [bounded sequences](https://en.wikipedia.org/wiki/Bounded_sequence). The vector space operations, addition and scalar multiplication, are applied coordinate by coordinate. With respect to the norm

$$\|x\|_\infty = \sup_n |x_n|$$

$\ell^\infty$ is a standard example of a [Banach space](wikipedia://en/3989). In fact, $\ell^\infty$ can be considered as the [$\ell^p$ space](wikipedia://en/1701075#.E2.84.93p_spaces) with the largest $p$.

This space is the [strong dual space](wikipedia://en/63951372) of $\ell^1$: indeed, every $x \in \ell^\infty$ defines a continuous functional on the space $\ell^1$ of absolutely summable sequences by component-wise multiplication and summing:

$$\begin{aligned} \ell^\infty &\to ({\ell^1})' \end{aligned}$$

via

$$\begin{aligned} x &\mapsto \left(y \mapsto \sum_{i = 1}^\infty x_iy_i \right) \end{aligned}$$

By evaluating on $(0,\ldots,0,1,0,\ldots)$ we see that every continuous linear functional on $\ell^1$ arises in this way. i.e.

$$({\ell^1})' = \ell^\infty$$

However, not every continuous linear functional on $\ell^\infty$ arises from an absolutely summable series in $\ell^1,$ and hence $\ell^\infty$ is not a [reflexive Banach space](https://en.wikipedia.org/wiki/Reflexive_Banach_space).

## Function space {#Function_space}

$L^\infty$ is a [function space](wikipedia://en/340630). Its elements are the *essentially bounded measurable functions*.[^o6]

More precisely, $L^\infty$ is defined based on an underlying [measure space](wikipedia://en/45270), $(S, \Sigma, \mu).$ Start with the set of all measurable functions from $S$ to $\mathbb{R}$ which are **essentially bounded**, that is, bounded except on a set of measure zero. Two such functions are identified if they are equal almost everywhere. Denote the resulting set by $L^{\infty}(S, \mu).$

For a function $f$ in this set, its [essential supremum](https://en.wikipedia.org/wiki/Essential_supremum) serves as an appropriate norm:

$$\|f\|_\infty \equiv \inf \{C \geq 0 : |f(x)| \leq C \text{ for almost every } x\}.$$

This norm is the [uniform norm](wikipedia://en/349755). It is an [$L^p$ norm](wikipedia://en/45194) for $p=\infty.$

The sequence space is a special case of the function space: $\ell^\infty = L^\infty(\mathbb{N})$ where the natural numbers are equipped with the counting measure.

:::

## Applications {#Applications}

One application of $\ell^\infty$ and $L^\infty$ is in [economics](https://en.wikipedia.org/wiki/Economics), particularly in the study of economies with infinitely many commodities.[^o9] In simple economic models, it is common to assume that there is only a finite number of different commodities, e.g. houses, fruits, cars, etc., so every bundle can be represented by a finite vector, and the [consumption set](https://en.wikipedia.org/wiki/Consumption_set) is a vector space with a finite dimension. But in reality, the number of different commodities may be infinite. For example, a "house" is not a single commodity type since the value of a house depends on its location. So the number of different commodities is the number of different locations, which may be considered infinite. In this case, the consumption set is naturally represented by $L^\infty.$
