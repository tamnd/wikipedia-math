# Rational set

::: {#o1 .subject cue=lead name="Rational set"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), more precisely in [automata theory](wikipedia://en/103356), a **rational set** of a [monoid](wikipedia://en/19652) is an element of the minimal class of subsets of this monoid that contains all finite subsets and is closed under [union](https://en.wikipedia.org/wiki/Set_union), product and [Kleene star](wikipedia://en/16750). Rational sets are useful in [automata theory](wikipedia://en/103356), [formal languages](wikipedia://en/10939) and [algebra](wikipedia://en/18716923).

:::

A rational set generalizes the notion of [rational (or regular) language](wikipedia://en/25723) (understood as defined by [regular expressions](wikipedia://en/25717)) to monoids that are not necessarily [free](wikipedia://en/523166).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(N,\cdot)$ be a [monoid](wikipedia://en/19652) with identity element $e$. The set $\mathrm{RAT}(N)$ of rational subsets of $N$ is the smallest set that contains every [finite set](wikipedia://en/11742) and is closed under

- [union](https://en.wikipedia.org/wiki/Set_union): if $A,B\in \mathrm{RAT}(N)$ then $A\cup B\in \mathrm{RAT}(N)$
- product: if $A,B\in \mathrm{RAT}(N)$ then $A\cdot B=\{a\cdot b\mid a\in A,b\in B\}\in\mathrm{RAT}(N)$
- [Kleene star](wikipedia://en/16750): if $A\in \mathrm{RAT}(N)$ then $A^*=\bigcup_{i=0}^\infty A^i \in\mathrm{RAT}(N)$ where $A^0=\{e\}$ is the singleton containing the [identity element](wikipedia://en/14962), and where $A^{n+1}=A^n \cdot A$.

This means that any rational subset of $N$ can be obtained by taking a finite number of finite subsets of $N$ and applying the union, product and Kleene star operations a finite number of times.

In general a rational subset of a monoid is not a submonoid.

:::

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

Let $A$ be an [alphabet](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29), the set $A^*$ of [words](https://en.wikipedia.org/wiki/Word_%28formal_language_theory%29) over $A$ is a monoid. The rational subset of $A^*$ are precisely the [regular languages](wikipedia://en/25723). Indeed, the regular languages may be defined by a finite [regular expression](wikipedia://en/25717).

The rational subsets of $\mathbb N$ are the ultimately periodic sets of integers. More generally, the rational subsets of $\mathbb N^k$ are the [semilinear sets](wikipedia://en/2628576).[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

[McKnight's theorem](https://en.wikipedia.org/wiki/McKnight's_theorem) states that if $N$ is [finitely generated](https://en.wikipedia.org/wiki/Finitely_generated_monoid) then its [recognizable subset](https://en.wikipedia.org/wiki/Recognizable_set) are rational sets. This is not true in general, since the whole $N$ is always recognizable but it is not rational if $N$ is infinitely generated.

Rational sets are closed under homomorphism: given $N$ and $M$ two monoids and $\phi:N\rightarrow M$ a monoid homomorphism, if $S\in\mathrm{RAT}(N)$ then $\phi(S)=\{\phi(x)\mid x\in S\}\in\mathrm{RAT}(M)$.

$\mathrm{RAT}(N)$ is not closed under [complement](wikipedia://en/23476429) as the following example shows.[^o9] Let $N=\{a\}^*\times\{b,c\}^*$, the sets $R=(a,b)^*(1,c)^* = \{(a^n,b^nc^m)\mid n,m\in\mathbb N\}$ and $S=(1,b)^*(a,c)^*=\{(a^n,b^mc^n)\mid n,m\in\mathbb N\}$ are rational but $R\cap S=\{(a^n,b^nc^n)\mid n\in\mathbb N\}$ is not because its projection to the second element $\{b^nc^n\mid n\in\mathbb N\}$ is not rational.

The intersection of a rational subset and of a recognizable subset is rational.

For [finite groups](wikipedia://en/323707) the following result of A. Anissimov and A. W. Seifert is well known: a [subgroup](wikipedia://en/28011) *H* of a [finitely generated group](wikipedia://en/963042) *G* is recognizable if and only if *H* has [finite index](https://en.wikipedia.org/wiki/Finite_index) in *G*. In contrast, *H* is rational if and only if *H* is finitely generated.[^o10]

:::

::: {#o12 .pointer-item cue=pointer name="Rational function (monoid)"}

## Rational relations and rational functions {#Rational_relations_and_rational_functions}

A [binary relation](wikipedia://en/3931) between monoids *M* and *N* is a **rational relation** if the graph of the relation, regarded as a subset of *M*×*N* is a rational set in the product monoid. A function from *M* to *N* is a **rational function** if the graph of the function is a rational set.[^o13]

:::
