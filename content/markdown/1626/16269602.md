# Abstract additive Schwarz method

::: {#o1 .subject cue=lead name="Abstract additive Schwarz method"}

In [mathematics](wikipedia://en/18831), the **abstract additive Schwarz method**, named after [Hermann Schwarz](wikipedia://en/3165834), is an abstract version of the [additive Schwarz method](wikipedia://en/400296) for [boundary value problems](wikipedia://en/436779) on [partial differential equations](wikipedia://en/52564), formulated only in terms of [linear algebra](wikipedia://en/18422) without reference to domains, subdomains, etc. Many if not all [domain decomposition methods](wikipedia://en/16230272) can be cast as abstract additive Schwarz method, which is often the first and most convenient approach to their analysis.[^o2]

:::
