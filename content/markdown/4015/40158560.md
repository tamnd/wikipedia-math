# Chebyshev integral

::: {#o1 .subject cue=lead name="Chebyshev integral"}

In mathematics, the **Chebyshev integral**, named after [Pafnuty Chebyshev](wikipedia://en/149568), is

:::

$$\int x^p (1-x)^q \, dx = B (x; 1+p, 1+q),$$

where $B (x; a, b)$ is an [incomplete beta function](https://en.wikipedia.org/wiki/Incomplete_beta_function).
