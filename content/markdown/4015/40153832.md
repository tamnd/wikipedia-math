# Inclusion (Boolean algebra)

::: {#o1 .subject cue=lead name="Inclusion"}

In [Boolean algebra](wikipedia://en/3959), the **inclusion relation** $a\le b$ is defined as $ab'=0$ and is the Boolean analogue to the [subset](wikipedia://en/27631) relation in [set theory](wikipedia://en/27553). Inclusion is a [partial order](https://en.wikipedia.org/wiki/Partial_order).

:::

The inclusion relation $a<b$ can be expressed in many ways:

- $$a < b$$
- $$ab' = 0$$
- $$a' + b = 1$$
- $$b' < a'$$
- $$a+b = b$$
- $$ab = a$$

The inclusion relation has a natural interpretation in various Boolean algebras: in the subset algebra, the [subset](wikipedia://en/27631) relation; in arithmetic Boolean algebra, [divisibility](wikipedia://en/49492); in the [algebra of propositions](wikipedia://en/1557634#An_algebra_of_propositions.2C_the_propositional_calculus), [material implication](wikipedia://en/658808); in the two-element algebra, the set { (0,0), (0,1), (1,1) }.

Some useful properties of the inclusion relation are:

- $$a \le a+b$$
- $$ab \le a$$

The inclusion relation may be used to define **Boolean intervals** such that $a\le x\le b$. A Boolean algebra whose carrier set is restricted to the elements in an interval is itself a Boolean algebra.
