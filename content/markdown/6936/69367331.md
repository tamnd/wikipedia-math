# Forrester's paradox

::: {#o1 .subject cue=lead name="Forrester's paradox"}

**Forrester's paradox**, also known as the **paradox of gentle murder**, is a [paradox](wikipedia://en/24390) of [deontic logic](wikipedia://en/1343980) attributed to [James Forrester](https://en.wikipedia.org/wiki/James_Forrester_%28philosopher%29).[^o2][^o3][^o4] It is a version of the [Good Samaritan paradox](https://en.wikipedia.org/wiki/Good_Samaritan_paradox).

:::

Forrester's argument is that, starting from the statements that:

- it is obligatory (under the law) that Smith not murder Jones, and
- it is obligatory that, if Smith murders Jones, Smith murder Jones gently,

it logically follows that:

- if Smith murders Jones, it is obligatory, that Smith murder Jones gently.

However, if it were actually the case that Smith murdered Jones, it can then be deduced that:

- it is obligatory, that Smith murder Jones,

which contradicts the first statement, leading to a [logical fallacy](https://en.wikipedia.org/wiki/Logical_fallacy).[^o5]

A number of arguments have been advanced that Forrester's paradox is invalid, for example that it is the result of a confusion of scope,[^o2][^o6] or a misuse of deduction rules.[^o7]
