# Mostow–Palais theorem

::: {#o1 .subject cue=lead name="Mostow–Palais theorem"}

In mathematics, the **Mostow–Palais theorem** is an equivariant version of the [Whitney embedding theorem](wikipedia://en/477578). It states that if a [manifold](wikipedia://en/2073470) is [acted on](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) by a [compact](wikipedia://en/750326) [Lie group](wikipedia://en/17945) with finitely many orbit types, then it can be embedded into some finite-dimensional orthogonal representation.
