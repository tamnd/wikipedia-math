# BPL (complexity)

::: {#o1 .subject cue=lead name="BPL"}

In [computational complexity theory](wikipedia://en/7543), **BPL** (Bounded-error Probabilistic Logarithmic-space),[^o2] sometimes called **BPLP** (Bounded-error Probabilistic Logarithmic-space Polynomial-time),[^o3] is the [complexity class](wikipedia://en/502426) of problems solvable in [logarithmic space](https://en.wikipedia.org/wiki/Logarithmic_space) and [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) with [probabilistic Turing machines](wikipedia://en/197812) with [two-sided error](https://en.wikipedia.org/wiki/Two-sided_error). It is named in analogy with **[BPP](https://en.wikipedia.org/wiki/Bounded-error_probabilistic_polynomial)**, which is similar but has no logarithmic space restriction.

:::

## Error model {#Error_model}

The probabilistic Turing machines in the definition of **BPL** may only accept or reject incorrectly less than 1/3 of the time; this is called *two-sided error*. The constant 1/3 is arbitrary; any *x* with 0 ≤ *x* \< 1/2 would suffice. This error can be made 2<sup>−*p*(*x*)</sup> times smaller for any polynomial *p*(*x*) without using more than polynomial time or logarithmic space by running the algorithm repeatedly.

## Related classes {#Related_classes}

Since two-sided error is more general than one-sided error, **[RL](wikipedia://en/1176581)** and its [complement](wikipedia://en/1929955) **co-RL** are contained in **BPL**. **BPL** is also contained in **[PL](wikipedia://en/48561286)**, which is similar except that the error bound is 1/2, instead of a constant less than 1/2; like the class **[PP](wikipedia://en/659322)**, the class **PL** is less practical because it may require a large number of rounds to reduce the error probability to a small constant.

(Nisan 1994) showed the weak [derandomization](https://en.wikipedia.org/wiki/Derandomization) result that **BPL** is contained in **[SC](wikipedia://en/18449916)**.[^o7] SC is the class of problems solvable in polynomial time and polylogarithmic space on a deterministic Turing machine; in other words, this result shows that, given *polylogarithmic* space, a deterministic machine can simulate *logarithmic* space probabilistic algorithms.

**BPL** is contained in **[NC](wikipedia://en/22073)** and in **[L/poly](wikipedia://en/7192559)**. Saks and Zhou showed that **BPL** is contained in **DSPACE**(log<sup>3/2</sup> n),[^o8] and in 2021 Hoza improved this to show **BPL** is contained in **DSPACE** $(\log^{3/2}(n)/\sqrt{\log \log n})$.[^o9]
