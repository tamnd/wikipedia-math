# Order unit

::: {#o1 .subject cue=lead name="Order unit"}

An **order unit** is an element of an [ordered vector space](wikipedia://en/8099221) which can be used to bound all elements from above.[^o2] In this way (as seen in the first example below) the order unit generalizes the unit element in the reals.

:::

According to [H. H. Schaefer](https://en.wikipedia.org/wiki/H._H._Schaefer), "most of the ordered vector spaces occurring in analysis do not have order units."[^n1]

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

For the ordering cone $K \subseteq X$ in the [vector space](wikipedia://en/32370) $X$, the element $e \in K$ is an order unit (more precisely a $K$-order unit) if for every $x \in X$ there exists a $\lambda_x > 0$ such that $\lambda_x e - x \in K$ (that is, $x \leq_K \lambda_x e$).[^o6]

::: {#o8 .definition cue=heading name="Equivalent definition"}

### Equivalent definition {#Equivalent_definition}

The order units of an ordering cone $K \subseteq X$ are those elements in the [algebraic interior](wikipedia://en/30823252) of $K;$ that is, given by $\operatorname{core}(K).$[^o6]

:::

:::

::: {#o10 .example cue=heading name="Examples"}

## Examples {#Examples}

Let $X = \mathbb{R}$ be the real numbers and $K = \mathbb{R}_+ = \{x \in \mathbb{R} : x \geq 0\},$ then the unit element $1$ is an order unit.

Let $X = \mathbb{R}^n$ and $K = \mathbb{R}^n_+ = \left\{ x_i \in \mathbb{R} : \text{ for all } i = 1, \ldots, n : x_i \geq 0 \right\},$ then the unit element $\vec{1} = (1, \ldots, 1)$ is an order unit.

Each interior point of the positive cone of an [ordered topological vector space](wikipedia://en/63988132) is an order unit.[^n1]

:::

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Each order unit of an ordered TVS is interior to the positive cone for the order topology.[^n1]

If $(X, \leq)$ is a preordered vector space over the reals with order unit $u,$ then the map $p(x) := \inf \{ t \in \mathbb{R} : x \leq t u \}$ is a [sublinear functional](https://en.wikipedia.org/wiki/Sublinear_functional).[^n2]

:::

## Order unit norm {#Order_unit_norm}

Suppose $(X, \leq)$ is an ordered vector space over the reals with order unit $u$ whose order is [Archimedean](wikipedia://en/63989376) and let $U = [-u, u].$ Then the [Minkowski functional](wikipedia://en/3510908) $p_U$ of $U,$ defined by $p_{U}(x) := \inf \{ r > 0 : x \in r [-u, u] \},$ is a norm called the **order unit norm**. It satisfies $p_U(u) = 1$ and the closed unit ball determined by $p_U$ is equal to $[-u, u];$ that is, $[-u, u] = \left\{ x \in X : p_U(x) \leq 1 \right\}.$[^n2]
