# Height zeta function

::: {#o1 .subject cue=lead name="Height zeta function"}

In mathematics, the **height zeta function** of an [algebraic variety](wikipedia://en/248808) or more generally a subset of a variety encodes the distribution of points of given [height](wikipedia://en/3141855).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If *S* is a set with height function *H*, such that there are only finitely many elements of bounded height, define a *counting function*

$$N(S,H,B) = \#\{ x \in S : H(x) \le B \} .$$

and a *zeta function*

$$Z(S,H;s) = \sum_{x \in S} H(x)^{-s} .$$

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If *Z* has [abscissa of convergence](https://en.wikipedia.org/wiki/Abscissa_of_convergence) β and there is a constant *c* such that *N* has rate of growth

$$N \sim c B^a (\log B)^{t-1}$$

then a version of the [Wiener–Ikehara theorem](wikipedia://en/6832988) holds: *Z* has a *t*-fold pole at *s* = β with residue *c*.*a*.Γ(*t*).

The abscissa of convergence has similar formal properties to the [Nevanlinna invariant](wikipedia://en/35799819) and it is conjectured that they are essentially the same. More precisely, Batyrev–Manin conjectured the following.[^o6] Let *X* be a projective variety over a number field *K* with ample divisor *D* giving rise to an embedding and height function *H*, and let *U* denote a Zariski-open subset of *X*. Let *α* = *α*(*D*) be the Nevanlinna invariant of *D* and β the abscissa of convergence of *Z*(*U*, *H*; *s*). Then for every *ε* > 0 there is a *U* such that *β* \< *α* + *ε*: in the opposite direction, if *α* > 0 then *α* = *β* for all sufficiently large fields *K* and sufficiently small *U*.

:::
