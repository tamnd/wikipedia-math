# Probabilistic number theory

::: {#o1 .subject cue=lead name="Probabilistic number theory"}

In [mathematics](wikipedia://en/18831), **Probabilistic number theory** is a subfield of [number theory](wikipedia://en/21527), which explicitly uses [probability](wikipedia://en/22934) to answer questions about the [integers](wikipedia://en/14563) and [integer-valued functions](wikipedia://en/39818965). One basic idea underlying it is that different [prime numbers](wikipedia://en/23666) are, in some serious sense, like [independent random variables](https://en.wikipedia.org/wiki/Independent_random_variables). This however is not an idea that has a unique useful formal expression.

:::

The founders of the theory were [Paul Erdős](wikipedia://en/601284), [Aurel Wintner](https://en.wikipedia.org/wiki/Aurel_Wintner) and [Mark Kac](wikipedia://en/1062425) during the 1930s, one of the periods of investigation in [analytic number theory](wikipedia://en/251513). Foundational results include the [Erdős–Wintner theorem](wikipedia://en/82671951), the [Erdős–Kac theorem](wikipedia://en/6046005) on [additive functions](wikipedia://en/87372) and the [DDT theorem](https://en.wikipedia.org/wiki/DDT_theorem).
