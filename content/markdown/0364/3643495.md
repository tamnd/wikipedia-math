# Doubly periodic function

::: {#o1 .subject cue=lead name="Doubly periodic function"}

In [mathematics](wikipedia://en/18831), a **doubly periodic function** is a [function](wikipedia://en/185427) defined on the [complex plane](wikipedia://en/217628) and having two "periods", which are [complex numbers](wikipedia://en/5826) $u$ and $v$ that are [linearly independent](wikipedia://en/101863) as [vectors](wikipedia://en/32533) over the [field](wikipedia://en/10603) of [real numbers](wikipedia://en/20646438). That $u$ and $v$ are periods of a function $f$ means that

:::

$$f(z + u) = f(z + v) = f(z)\,$$

for all values of the complex number $z$.[^o2][^o3]

The doubly periodic function is thus a two-dimensional extension of the simpler [singly periodic function](wikipedia://en/76848), which repeats itself in a single dimension. Familiar examples of functions with a single period on the real number line include the [trigonometric functions](wikipedia://en/30367) like [cosine](https://en.wikipedia.org/wiki/Cosine) and [sine](https://en.wikipedia.org/wiki/Sine), In the [complex plane](wikipedia://en/217628) the [exponential function](wikipedia://en/9678) $e^z$ is a singly periodic function, with period $2 \pi i$.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

As an arbitrary mapping from pairs of reals (or complex numbers) to reals, a doubly periodic function can be constructed with little effort. For example, assume that the periods are $1$ and $i$, so that the repeating [lattice](wikipedia://en/19635706) is the set of unit squares with vertices at the [Gaussian integers](wikipedia://en/48628). Values in the prototype square (i.e. $x + iy$ where $0 \leq x < 1$ and $0 \leq y < 1$) can be assigned rather arbitrarily and then 'copied' to adjacent squares. This function will then be necessarily doubly periodic.

If the vectors $1$ and $i$ in this example are replaced by linearly independent vectors $u$ and $v$, the prototype square becomes a prototype parallelogram that still [tiles the plane](wikipedia://en/321671). The "origin" of the lattice of parallelograms does not have to be the point $0$: the lattice can start from any point. In other words, we can think of the plane and its associated functional values as remaining fixed, and mentally translate the lattice to gain insight into the function's characteristics.

:::

## Use of complex analysis {#Use_of_complex_analysis}

If a doubly periodic function is also a [*complex function*](wikipedia://en/5759) that satisfies the [Cauchy–Riemann equations](wikipedia://en/7583) and provides an analytic function away from some set of isolated [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) – in other words, a [meromorphic function](wikipedia://en/80857) – then a lot of information about such a function can be obtained by applying some basic theorems from complex analysis.

- A non-constant meromorphic doubly periodic function cannot be bounded on the prototype parallelogram. For if it were it would be bounded everywhere, and therefore constant by [Liouville's theorem](wikipedia://en/312293).
- Since the function is meromorphic, it has no essential singularities and its poles are isolated. Therefore a translated lattice that does not pass through any pole can be constructed. The [contour integral](wikipedia://en/21245414) around any parallelogram in the lattice must vanish, because the values assumed by the doubly periodic function along the two pairs of parallel sides are identical, and the two pairs of sides are traversed in opposite directions as we move around the contour. Therefore, by the [residue theorem](wikipedia://en/73390), the function cannot have a single simple pole inside each parallelogram – it must have at least two simple poles within each parallelogram (Jacobian case), or it must have at least one pole of order greater than one (Weierstrassian case).
- A similar argument can be applied to the function $g = 1 / f$ where $f$ is meromorphic and doubly periodic. Under this inversion the [zeroes](wikipedia://en/264210) of $f$ become the [poles](wikipedia://en/81560) of $g$, and *vice versa*. So the meromorphic doubly periodic function $f$ cannot have one simple zero lying within each parallelogram on the lattice—it must have at least two simple zeroes, or it must have at least one zero of multiplicity greater than one. It follows that $f$ cannot attain any value just once, since $f$ minus that value would itself be a meromorphic doubly periodic function with just one zero.
