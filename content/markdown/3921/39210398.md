# Subpaving

::: {#o1 .subject cue=lead name="Subpaving"}

In [mathematics](wikipedia://en/18831), a **subpaving** is a set of nonoverlapping [boxes](wikipedia://en/1688550) of **R⁺**. A [subset](wikipedia://en/27631) *X* of **Rⁿ** can be approximated by two subpavings *X⁻* and *X⁺* such that *X⁻* ⊂ *X* ⊂ *X⁺*.

:::

In **R¹** the boxes are line segments, in **R²** rectangles and in **Rⁿ** hyperrectangles. A **R²** subpaving can be also a "[non-regular tiling](wikipedia://en/321671) by rectangles", when it has no holes.

*Image: Rectangular-covering.png.* Bracketing of the hatched set *X* between two subpavings. Red boxes: inner subpaving. Red and yellow: outer subpaving. The [difference](wikipedia://en/54347#Relative_complement), outer minus inner, is a [boundary](wikipedia://en/72824) approximation.

Boxes present the advantage of being very easily manipulated by computers, as they form the heart of [interval analysis](wikipedia://en/2176160). Many interval algorithms naturally provide solutions that are regular subpavings.[^o2]

In [computation](wikipedia://en/5926), a well-known application of subpaving in **R²** is the [Quadtree data structure](https://en.wikipedia.org/wiki/Quadtree). In [image tracing](https://en.wikipedia.org/wiki/Image_tracing) context and other applications is important to see *X⁻* as [topological interior](wikipedia://en/55610), as illustrated.

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

The three figures on the right below show an approximation of the set *X* = {(*x*<sub>1</sub>, *x*<sub>2</sub>) ∈ **R**<sup>2</sup> | *x*${}^{2}_{1}$ + *x*${}^{2}_{2}$ + sin(*x*<sub>1</sub> + *x*<sub>2</sub>) ∈ \[4,9\]} with different accuracies. The set *X⁻* corresponds to red boxes and the set *X⁺* contains all red and yellow boxes.

*Image: Wiki subpaving1.png.* Subpavings which bracket a set with a low resolution

*Image: Wiki subpaving2.png.* Subpavings which bracket the same set with a moderate resolution

*Image: Wiki subpaving3.png.* Subpavings which bracket the set with a high resolution

Combined with [interval-based methods](wikipedia://en/2176160), subpavings are used to approximate the solution set of non-linear problems such as [set inversion problems](wikipedia://en/39157279).[^o5] Subpavings can also be used to prove that a set defined by nonlinear [inequalities](wikipedia://en/89489) is [path connected](https://en.wikipedia.org/wiki/Path_connected),[^o6] to provide [topological](wikipedia://en/29954) properties of such sets,[^o7] to solve [piano-mover's problems](https://en.wikipedia.org/wiki/Motion_planning)[^o8] or to implement set computation.[^o9]
