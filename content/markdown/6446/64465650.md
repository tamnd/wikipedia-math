# SOS-convexity

::: {#o1 .subject cue=lead name="SOS-convexity"}

A [multivariate polynomial](https://en.wikipedia.org/wiki/Multivariate_polynomial) is **SOS-convex** (or **sum of squares convex**) if its [Hessian matrix](wikipedia://en/412108) **H** can be factored as **H**(*x*) = *S*<sup>T</sup>(*x*)*S*(*x*) where *S* is a matrix (possibly rectangular) which entries are polynomials in *x*.[^o2] In other words, the Hessian matrix is a [SOS matrix polynomial](wikipedia://en/17001761#Matrix_SOS).

:::

An equivalent definition is that the form defined as *g*(*x*,*y*) = *y*<sup>T</sup>**H**(*x*)*y* is a [sum of squares of forms](wikipedia://en/17001761).[^o3]

## Connection with convexity {#Connection_with_convexity}

If a polynomial is SOS-convex, then it is also convex. Since establishing whether a polynomial is SOS-convex amounts to solving a [semidefinite programming](wikipedia://en/4993539) problem, SOS-convexity can be used as a proxy to establishing if a polynomial is convex. In contrast, deciding if a generic quartic polynomial of degree four (or higher even degree) is convex is a NP-hard problem.[^o5]

The first counterexample of a polynomial which is convex but not SOS-convex was constructed by [Amir Ali Ahmadi](https://en.wikipedia.org/wiki/Amir_Ali_Ahmadi) and [Pablo Parrilo](https://en.wikipedia.org/wiki/Pablo_Parrilo) in 2009.[^o6] The polynomial is a homogeneous polynomial that is sum-of-squares and given by:[^o6]

$$p(x)= 32 x_{1}^{8}+118 x_{1}^{6} x_{2}^{2}+40 x_{1}^{6} x_{3}^{2}+25 x_{1}^{4} x_{2}^{4} -43 x_{1}^{4} x_{2}^{2} x_{3}^{2}-35 x_{1}^{4} x_{3}^{4}+3 x_{1}^{2} x_{2}^{4} x_{3}^{2} -16 x_{1}^{2} x_{2}^{2} x_{3}^{4}+24 x_{1}^{2} x_{3}^{6}+16 x_{2}^{8} +44 x_{2}^{6} x_{3}^{2}+70 x_{2}^{4} x_{3}^{4}+60 x_{2}^{2} x_{3}^{6}+30 x_{3}^{8}$$

In the same year, Grigoriy Blekherman proved in a [non-constructive](https://en.wikipedia.org/wiki/Non-constructive) manner that there exist convex forms that is not representable as sum of squares.[^o7] An explicit example of a convex form (with degree 4 and 272 variables) that is not a sum of squares was claimed by James Saunderson in 2021.[^o8]

## Connection with non-negativity and sum-of-squares {#Connection_with_non-negativity_and_sum-of-squares}

In 2013 [Amir Ali Ahmadi](https://en.wikipedia.org/wiki/Amir_Ali_Ahmadi) and [Pablo Parrilo](https://en.wikipedia.org/wiki/Pablo_Parrilo) showed that every convex homogeneous polynomial in *n* variables and degree 2*d* is SOS-convex if and only if either (a) *n* = 2 or (b) 2*d* = 2 or (c) *n* = 3 and 2*d* = 4.[^o10] Impressively, the same relation is valid for non-negative homogeneous polynomial in *n* variables and degree 2*d* that can be represented as sum of squares polynomials (See [Hilbert's seventeenth problem](wikipedia://en/2336214)).
