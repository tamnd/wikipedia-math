# Spectral layout

::: {#o1 .subject cue=lead name="Spectral layout"}

*Image: Spectral graph drawing of small world graph.svg.* Spectral layout drawing of random [small-world network](wikipedia://en/1457254).

*Image: Spring graph drawing of small world graph.svg.* For comparison, the same graph plotted as [spring graph drawing](wikipedia://en/710331).

**Spectral layout** is a class of [algorithm](wikipedia://en/775) for [drawing graphs](wikipedia://en/325813). The layout uses the [eigenvectors](https://en.wikipedia.org/wiki/Eigenvectors) of a matrix, such as the [Laplace matrix](https://en.wikipedia.org/wiki/Laplace_matrix) of the graph, as [Cartesian coordinates](https://en.wikipedia.org/wiki/Cartesian_coordinate) of the graph's vertices.

:::

The idea of the layout is to compute the two largest (or smallest) eigenvalues and corresponding eigenvectors of the Laplacian matrix of the graph and then use those for actually placing the nodes. Usually nodes are placed in the 2 dimensional plane. An embedding into more dimensions can be found by using more eigenvectors. In the 2-dimensional case, for a given node which corresponds to the row/column $i$ in the (symmetric) Laplacian matrix $L$ of the graph, the $x$ and $y$-coordinates are the $i$-th entries of the first and second eigenvectors of $L$, respectively.
