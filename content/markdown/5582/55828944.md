# Bellman's lost-in-a-forest problem

::: {#o1 .subject cue=lead name="Bellman's lost-in-a-forest problem"}

::: {#o2 .problem cue=unsolved}

What is the optimal path to take when lost in a forest?

:::

*Image: Bellman\_lost\_in\_a\_forest\_problem.svg.* }

**Bellman's lost-in-a-forest problem** is an unsolved minimization problem in [geometry](wikipedia://en/18973446), originating in 1955 by the American applied mathematician [Richard E. Bellman](https://en.wikipedia.org/wiki/Richard_E._Bellman).[^o3] The problem is often stated as follows: *"A hiker is lost in a forest whose shape and dimensions are precisely known to him. What is the best path for him to follow to escape from the forest?"*[^o4] It is usually assumed that the hiker does not know the starting point or direction he is facing. The best path is taken to be the one that minimizes the worst-case distance to travel before reaching the edge of the forest. Other variations of the problem have been studied.

:::

Although non-contrived real-world applications are not apparent, the problem falls into a class of geometric optimization problems, including search strategies that are of practical importance. A bigger motivation for study has been the connection to [Moser's worm problem](wikipedia://en/30774748). It was included in a list of 12 problems described by the mathematician [Scott W. Williams](wikipedia://en/10709770) as "million buck problems" because he believed that the techniques involved in their resolution will be worth at least a million dollars to mathematics.[^o5]

## Known cases {#Known_cases}

Although it is not known how to find an optimal solution for an arbitrary shape, the optimal solution is known for some special shapes and special classes of shapes:

- If the forest contains a 60° rhombus whose long diagonal is a [diameter](wikipedia://en/68283333) of the forest, then the optimal escape path length is the diameter, and walking in a straight line for this distance will provide an optimal escape. This case includes, for instance, a circular forest.[^o4]
- The optimal escape path for a semicircular forest, or more generally a forest in the shape of a [circular sector](wikipedia://en/1967249) with angle at least 60°, is also the diameter of the forest, as is the optimal escape path for a [regular polygon](wikipedia://en/333306) with more than three sides.[^o4]
- The optimal escape path for an infinite strip of width $w$ is a V-shaped path formed from four straight line segments and two shallow circular arcs, of length approximately $2.2783w$. This same path is also optimal for rectangles of height $w$ whose diameter is greater than or equal to the length of this path. For rectangles with a shorter diameter, the optimal escape path length is the diameter. A rectangle whose diameter equals the length of the escape path for a strip of the same height provides an example of a shape with two very different optimal escape paths, the path for the strip and a single line segment of the same length as the diameter.[^o4]
