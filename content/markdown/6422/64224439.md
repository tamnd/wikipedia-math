# Negative definiteness

::: {#o1 .subject cue=lead name="Negative definiteness"}

In [mathematics](wikipedia://en/18831), **negative definiteness** is a property of any object to which a [bilinear form](wikipedia://en/449477) may be naturally associated, which is [negative-definite](https://en.wikipedia.org/wiki/Negative-definite_bilinear_form). See, in particular:

:::

- [Negative-definite bilinear form](https://en.wikipedia.org/wiki/Negative-definite_bilinear_form)
- [Negative-definite quadratic form](https://en.wikipedia.org/wiki/Negative-definite_quadratic_form)
- [Negative-definite matrix](https://en.wikipedia.org/wiki/Negative-definite_matrix)
- [Negative-definite function](https://en.wikipedia.org/wiki/Negative-definite_function)
