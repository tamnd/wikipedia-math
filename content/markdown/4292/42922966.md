# Coins in a fountain

::: {#o1 .subject cue=lead name="Coins in a fountain"}

**Coins in a fountain** is a problem in [combinatorial](wikipedia://en/5170) [mathematics](wikipedia://en/18831) involving a [generating function](wikipedia://en/160993). In this problem, a *fountain* is an arrangement of non-overlapping coins, modeled as [unit circles](wikipedia://en/27072071), into horizontal rows in the plane. Consecutive coins in the bottom row are [tangent](wikipedia://en/19349153) to each other, and each coin in a higher row is tangent to two coins in the row immediately below it. Above the bottom row, consecutive coins are not required to touch. The problem asks for the number of different fountains of $n$ coins with $k$ coins in the bottom row.[^o2]

:::
