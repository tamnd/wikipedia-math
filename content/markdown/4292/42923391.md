# Kleene's algorithm

::: {#o1 .subject cue=lead name="Kleene's algorithm"}

In [theoretical computer science](wikipedia://en/323392), in particular in [formal language theory](https://en.wikipedia.org/wiki/Formal_language_theory), **Kleene's algorithm** transforms a given [nondeterministic finite automaton](wikipedia://en/653406) (NFA) into a [regular expression](wikipedia://en/25717). Together with other conversion algorithms, it establishes the equivalence of several description formats for [regular languages](wikipedia://en/25723). Alternative presentations of the same method include the "elimination method" attributed to [Brzozowski](wikipedia://en/23616030) and [McCluskey](https://en.wikipedia.org/wiki/Edward_J._McCluskey), the algorithm of [McNaughton](wikipedia://en/55774434) and [Yamada](https://en.wikipedia.org/wiki/Hisao_Yamada),[^o2] and the use of [Arden's lemma](https://en.wikipedia.org/wiki/Arden's_lemma).

:::

## Algorithm description {#Algorithm_description}

According to Gross and Yellen (2004),[^o4] the algorithm can be traced back to [Kleene](https://en.wikipedia.org/wiki/Kleene) (1956).[^o5] A presentation of the algorithm in the case of [deterministic finite automata](https://en.wikipedia.org/wiki/Deterministic_finite_automata) (DFAs) is given in Hopcroft and Ullman (1979).[^o6] The presentation of the algorithm for NFAs below follows Gross and Yellen (2004).[^o4]

Given a [nondeterministic finite automaton](wikipedia://en/653406#Formal_definition) *M* = (*Q*, Σ, δ, *q*<sub>0</sub>, *F*), with *Q* = { *q*<sub>0</sub>,...,*q*<sub>*n*</sub> } its set of [states](wikipedia://en/653406#Formal_definition), the algorithm computes

the sets *R*${}^{k}_{ij}$ of all strings that take *M* from state *q*<sub>*i*</sub> to *q*<sub>*j*</sub> without going through any state numbered higher than *k*.

Here, "going through a state" means entering *and* leaving it, so both *i* and *j* may be higher than *k*, but no intermediate state may. Each set *R*${}^{k}_{ij}$ is represented by a regular expression; the algorithm computes them step by step for *k* = -1, 0, ..., *n*. Since there is no state numbered higher than *n*, the regular expression *R*${}^{n}_{0j}$ represents the set of all strings that take *M* from its [start state](wikipedia://en/653406#Formal_definition) *q*<sub>0</sub> to *q*<sub>*j*</sub>. If *F* = { *q*<sub>1</sub>,...,*q*<sub>*f*</sub> } is the set of [accept states](wikipedia://en/653406#Formal_definition), the [regular expression](wikipedia://en/25717#Formal_definition) *R*${}^{n}_{01}$ | ... | *R*${}^{n}_{0f}$ represents the language [accepted](wikipedia://en/653406#Formal_definition) by *M*.

The initial regular expressions, for *k* = -1, are computed as follows for *i*≠*j*:

*R*${}^{-1}_{ij}$ = *a*<sub>1</sub> | ... | *a*<sub>*m*</sub> where *q*<sub>*j*</sub> ∈ δ(*q*<sub>*i*</sub>,*a*<sub>1</sub>), ..., *q*<sub>*j*</sub> ∈ δ(*q*<sub>*i*</sub>,*a*<sub>*m*</sub>)

and as follows for *i*=*j*:

*R*${}^{-1}_{ii}$ = *a*<sub>1</sub> | ... | *a*<sub>*m*</sub> | ε where *q*<sub>*i*</sub> ∈ δ(*q*<sub>*i*</sub>,*a*<sub>1</sub>), ..., *q*<sub>*i*</sub> ∈ δ(*q*<sub>*i*</sub>,*a*<sub>*m*</sub>)

In other words, *R*${}^{-1}_{ij}$ mentions all letters that label a transition from *i* to *j*, and we also include ε in the case where *i*=*j*.

After that, in each step the expressions *R*${}^{k}_{ij}$ are computed from the previous ones by

*R*${}^{k}_{ij}$ = *R*${}^{k-1}_{ik}$ (*R*${}^{k-1}_{kk}$)<sup>\*</sup> *R*${}^{k-1}_{kj}$ | *R*${}^{k-1}_{ij}$

Another way to understand the operation of the algorithm is as an "elimination method", where the states from 0 to *n* are successively removed: when state *k* is removed, the regular expression *R*${}^{k-1}_{ij}$, which describes the words that label a path from state *i*>*k* to state *j*>*k*, is rewritten into *R*${}^{k}_{ij}$ so as to take into account the possibility of going via the "eliminated" state *k*.

By induction on *k*, it can be shown that the length[^o7] of each expression *R*${}^{k}_{ij}$ is at most $\tfrac{1}{3}$(4<sup>*k*+1</sup>(6*s*+7) - 4) symbols, where *s* denotes the number of characters in Σ. Therefore, the length of the regular expression representing the language accepted by *M* is at most $\tfrac{1}{3}$(4<sup>*n*+1</sup>(6*s*+7)*f* - *f* - 3) symbols, where *f* denotes the number of final states. This exponential blowup is inevitable, because there exist families of DFAs for which any equivalent regular expression must be of exponential size.[^o8]

In practice, the size of the regular expression obtained by running the algorithm can be very different depending on the order in which the states are considered by the procedure, i.e., the order in which they are numbered from 0 to *n*.

- the set of states *Q* = { *q*<sub>0</sub>, *q*<sub>1</sub>, *q*<sub>2</sub> },
- the input alphabet Σ = { *a*, *b* },
- the transition function δ with δ(*q*<sub>0</sub>,*a*)=*q*<sub>0</sub>, δ(*q*<sub>0</sub>,*b*)=*q*<sub>1</sub>, δ(*q*<sub>1</sub>,*a*)=*q*<sub>2</sub>, δ(*q*<sub>1</sub>,*b*)=*q*<sub>1</sub>, δ(*q*<sub>2</sub>,*a*)=*q*<sub>1</sub>, and δ(*q*<sub>2</sub>,*b*)=*q*<sub>1</sub>,
