# Morse–Kelley set theory

::: {#o1 .subject cue=lead name="Morse–Kelley set theory"}

In the [foundations of mathematics](wikipedia://en/169358), **Morse–Kelley set theory** (**MK**), **Kelley–Morse set theory** (**KM**), **Morse–Tarski set theory** (**MT**), **Quine–Morse set theory** (**QM**) or the **system of Quine and Morse** is a [first-order](wikipedia://en/10983) [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory) that is closely related to [von Neumann–Bernays–Gödel set theory](wikipedia://en/528491) (NBG). While von Neumann–Bernays–Gödel set theory restricts the [bound variables](https://en.wikipedia.org/wiki/Bound_variable) in the schematic formula appearing in the [axiom schema](wikipedia://en/764613) of [class comprehension](https://en.wikipedia.org/wiki/Axiom_schema_of_Class_Comprehension) to range over sets alone, Morse–Kelley set theory allows these bound variables to range over [proper classes](https://en.wikipedia.org/wiki/Proper_class) as well as sets, as first suggested by [Quine](https://en.wikipedia.org/wiki/W.V.O._Quine) in 1940 for his system [ML](wikipedia://en/945957).

:::

Morse–Kelley set theory is named after mathematicians [John L. Kelley](https://en.wikipedia.org/wiki/John_L._Kelley) and [Anthony Morse](https://en.wikipedia.org/wiki/Anthony_Morse) and was first set out by (Wang 1949)[^o3] and later in an appendix to Kelley's textbook *General Topology* (1955), a graduate level introduction to [topology](wikipedia://en/29954).[^n1] Kelley said the system in his book was a variant of the systems due to [Thoralf Skolem](wikipedia://en/453765) and Morse. Morse's own version appeared later in his book *A Theory of Sets* (1965).

While von Neumann–Bernays–Gödel set theory is a [conservative extension](wikipedia://en/1840214) of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC, the canonical set theory) in the sense that a statement in the language of ZFC is provable in NBG if and only if it is provable in ZFC, Morse–Kelley set theory is a [proper extension](https://en.wikipedia.org/wiki/Proper_extension) of ZFC (assuming ZFC is consistent). Unlike von Neumann–Bernays–Gödel set theory, where the axiom schema of class comprehension can be replaced with finitely many of its instances, Morse–Kelley set theory cannot be finitely axiomatized.

## MK axioms and ontology {#MK_axioms_and_ontology}

[NBG](wikipedia://en/528491) and MK share a common [ontology](https://en.wikipedia.org/wiki/Ontology). The [universe of discourse](wikipedia://en/229180#Universe_of_discourse) consists of [classes](https://en.wikipedia.org/wiki/Proper_class). Classes that are members of other classes are called [sets](wikipedia://en/26691). A class that is not a set is a [proper class](https://en.wikipedia.org/wiki/Proper_class). The primitive [atomic sentences](wikipedia://en/943457) involve membership or equality.

With the exception of class comprehension, the following axioms are the same as those for [NBG](wikipedia://en/528491), inessential details aside. The symbolic versions of the axioms employ the following notational devices:

- The upper case letters other than *M*, appearing in Extensionality, Class Comprehension, and Foundation, denote variables ranging over classes. A lower case letter denotes a variable that cannot be a [proper class](https://en.wikipedia.org/wiki/Proper_class), because it appears to the left of an ∈. As MK is a one-sorted theory, this notational convention is only [mnemonic](https://en.wikipedia.org/wiki/Mnemonic).
- The [monadic](wikipedia://en/161006) [predicate](https://en.wikipedia.org/wiki/Predicate_%28mathematical_logic%29) $Mx,$ whose intended reading is "the class *x* is a set", abbreviates $\exists W(x \in W).$
- The [empty set](wikipedia://en/9566) $\varnothing$ is defined by $\forall x (x \not \in \varnothing).$
- The class *V*, the [universal class](wikipedia://en/296838) having all possible sets as members, is defined by $\forall x (Mx \to x \in V).$ *V* is also the [von Neumann universe](wikipedia://en/445980).

**[Extensionality](wikipedia://en/52376):** Classes having the same members are the same class.

$$\forall X \, \forall Y \, ( \forall z \, (z \in X \leftrightarrow z \in Y) \rightarrow X = Y).$$

A set and a class having the same extension are identical. Hence MK is not a two-sorted theory, appearances to the contrary notwithstanding.

**[Foundation](https://en.wikipedia.org/wiki/Axiom_of_foundation):** Each nonempty class *A* is [disjoint](wikipedia://en/39359) from at least one of its members.

$$\forall A [A \not = \varnothing \rightarrow \exists b (b \in A \land \forall c (c \in b \rightarrow c \not\in A))].$$

**Class Comprehension:** Let φ(*x*) be any formula in the language of MK in which *x* is a [free variable](https://en.wikipedia.org/wiki/Free_variable) and *Y* is not free. φ(*x*) may contain parameters that are either sets or proper classes. More consequentially, the quantified variables in φ(*x*) may range over all classes and not just over all sets; *this is the only way MK differs from [NBG](wikipedia://en/528491)*. Then there exists a **class** $Y=\{x \mid \phi(x)\}$ whose members are exactly those **sets** *x* such that $\phi(x)$ comes out true. Formally, if *Y* is not free in φ:

$$\forall W_1 ... W_n \exists Y \forall x [x \in Y \leftrightarrow (\phi(x, W_1, ... W_n) \land Mx)].$$

**[Pairing](wikipedia://en/52385):** For any sets *x* and *y*, there exists a set $z=\{x,y\}$ whose members are exactly *x* and *y*.

$$\forall x \, \forall y \, [ (Mx \land My) \rightarrow \exists z \, (Mz \land \forall s \, [ s \in z \leftrightarrow (s = x \, \lor \, s = y)])].$$

Pairing licenses the unordered pair in terms of which the [ordered pair](wikipedia://en/22362), $\langle x,y \rangle$, may be defined in the usual way, as $\ \{\{x\},\{x,y\}\}$. With ordered pairs in hand, Class Comprehension enables defining [relations](wikipedia://en/22517558) and [functions](https://en.wikipedia.org/wiki/Function_%28set_theory%29) on sets as sets of ordered pairs, making possible the next axiom:

**[Limitation of Size](wikipedia://en/5322450):** *C* is a [proper class](https://en.wikipedia.org/wiki/Proper_class) if and only if *[V](wikipedia://en/445980)* can be [mapped one-to-one](https://en.wikipedia.org/wiki/One-to-one_mapping) into *C*.

$$\begin{array}{l} \forall C [\lnot MC \leftrightarrow \exists F ( \forall x [Mx \rightarrow \exists s (s \in C \land \langle x, s \rangle \in F)] \land \\ \qquad \forall x \forall y \forall s [(\langle x, s \rangle \in F \land \langle y, s \rangle \in F) \rightarrow x = y])]. \end{array}$$

The formal version of this axiom resembles the [axiom schema of replacement](wikipedia://en/52387), and embodies the class function *F*. The next section explains how Limitation of Size is stronger than the usual forms of the [axiom of choice](wikipedia://en/840).

**[Power set](wikipedia://en/52552):** Let *p* be a class whose members are all possible [subsets](wikipedia://en/27631) of the set *a*. Then *p* is a set.

$$\forall a \, \forall p \, [(Ma \land \forall x \, [x \in p \leftrightarrow \forall y \, (y \in x \rightarrow y \in a)]) \rightarrow Mp].$$

**[Union](wikipedia://en/52553):** Let $s=\bigcup a$ be the sum class of the set *a*, namely the [union](wikipedia://en/47949) of all members of *a*. Then *s* is a set.

$$\forall a \, \forall s \, [(Ma \land \forall x \, [x \in s \leftrightarrow \exists y \, (x \in y \land y \in a)]) \rightarrow Ms].$$

**[Infinity](wikipedia://en/246449):** There exists an inductive set *y*, meaning that (i) the [empty set](wikipedia://en/9566) is a member of *y*; (ii) if *x* is a member of *y*, then so is $x \cup \{x\}.$.

$$\exists y[My \land \varnothing \in y \land \forall z(z \in y \rightarrow \exists x [x \in y \land \forall w (w \in x \leftrightarrow [w = z \lor w \in z])] )].$$

Note that *p* and *s* in Power Set and Union are universally, not existentially, quantified, as Class Comprehension suffices to establish the existence of *p* and *s*. Power Set and Union only serve to establish that *p* and *s* cannot be proper classes.

The above axioms are shared with other set theories as follows:

- [ZFC](wikipedia://en/152214) and [NBG](wikipedia://en/528491): Pairing, Power Set, Union, Infinity;
- [NBG](wikipedia://en/528491) (and ZFC, if quantified variables were restricted to sets): Extensionality, Foundation;
- [NBG](wikipedia://en/528491): Limitation of Size.

:::

## Discussion {#Discussion}

Monk (1980) and Rubin (1967) are set theory texts built around MK; Rubin's [ontology](https://en.wikipedia.org/wiki/Ontology) includes [urelements](wikipedia://en/643648). These authors and Mendelson (1997: 287) submit that MK does what is expected of a set theory while being less cumbersome than [ZFC](wikipedia://en/152214) and [NBG](wikipedia://en/528491).

MK is strictly stronger than ZFC and its [conservative extension](wikipedia://en/1840214) NBG, the other well-known set theory with [proper classes](https://en.wikipedia.org/wiki/Proper_class). In fact, NBG—and hence ZFC—can be proved consistent in MK. That means that if MK's axioms hold, one can define a *True* predicate and show that all the ZFC and NBG axioms are true—hence every other statement formulated in ZFC or NBG is true, because truth is preserved by logic. MK's strength stems from its axiom schema of Class Comprehension being [impredicative](wikipedia://en/1930406), meaning that φ(*x*) may contain quantified variables ranging over classes. The quantified variables in NBG's axiom schema of Class Comprehension are restricted to sets; hence Class Comprehension in NBG must be [predicative](wikipedia://en/1930406). (Separation with respect to sets is still impredicative in NBG, because the quantifiers in φ(*x*) may range over all sets.) The NBG axiom schema of Class Comprehension can be replaced with finitely many of its instances; this is not possible in MK. MK is consistent relative to ZFC augmented by an axiom asserting the existence of strongly [inaccessible cardinals](wikipedia://en/248076).

The only advantage of the [axiom of limitation of size](wikipedia://en/5322450) is that it implies the [axiom of global choice](wikipedia://en/5322320). Limitation of Size does not appear in Rubin (1967), Monk (1980), or Mendelson (1997). Instead, these authors invoke a usual form of the local [axiom of choice](wikipedia://en/840), and an "axiom of replacement,"[^o8] asserting that if the [domain](wikipedia://en/50263) of a class function is a set, its [range](wikipedia://en/275991) is also a set. Replacement can prove everything that Limitation of Size proves, except prove some form of the [axiom of choice](wikipedia://en/840).

[Limitation of Size](wikipedia://en/5322450) plus [*I* being a set](wikipedia://en/246449) (hence the universe is nonempty) renders provable the sethood of the empty set; hence no need for an [axiom of empty set](wikipedia://en/52534). Such an axiom could be added, of course, and minor perturbations of the above axioms would necessitate this addition. The set *I* is not identified with the [limit ordinal](wikipedia://en/373137) $\omega,$ as *I* could be a set larger than $\omega.$ In this case, the existence of $\omega$ would follow from either form of Limitation of Size.

The class of [von Neumann ordinals](https://en.wikipedia.org/wiki/Von_Neumann_ordinal) can be [well-ordered](wikipedia://en/33456). It cannot be a set (under pain of paradox); hence that class is a proper class, and all proper classes have the same size as *V*. Hence *V* too can be well-ordered.

MK can be confused with second-order ZFC, that is, ZFC with [second-order logic](wikipedia://en/341428) (representing second-order objects in set rather than predicate language) as its background logic. The language of second-order ZFC is similar to that of MK (although a set and a class having the same extension can no longer be identified), and their [syntactical](wikipedia://en/26860) resources for practical proof are almost identical (and are identical if MK includes the strong form of Limitation of Size). But the [semantics](wikipedia://en/29107) of second-order ZFC are quite different from those of MK. For example, if MK is consistent then it has a countable first-order model, while second-order ZFC has no countable models.

### Model theory {#Model_theory}

ZFC, NBG, and MK each have models describable in terms of *V*, the [von Neumann universe of sets](https://en.wikipedia.org/wiki/Von_Neumann_universe_of_sets) in [ZFC](wikipedia://en/152214). Let the [inaccessible cardinal](wikipedia://en/248076) *κ* be a member of *V*. Also let Def(*X*) denote the Δ<sub>0</sub> definable [subsets](wikipedia://en/27631) of *X* (see [constructible universe](wikipedia://en/343335)). Then:

- *V*<sub>*κ*</sub> is model of [ZFC](wikipedia://en/152214);
- Def(*V*<sub>*κ*</sub>) is a model of Mendelson's version of [NBG](wikipedia://en/528491), which excludes global choice, replacing limitation of size by replacement and ordinary choice;
- *V*<sub>*κ*+1</sub>, the [power set](wikipedia://en/23799) of *V*<sub>*κ*</sub>, is a model of MK.

### History {#History}

MK was first set out in (Wang 1949)[^o3] and popularized in an appendix to [J. L. Kelley](https://en.wikipedia.org/wiki/J._L._Kelley)'s (1955) *General Topology*, using the axioms given in the next section. The system of Anthony Morse's (1965) *A Theory of Sets* is equivalent to Kelley's, but formulated in an idiosyncratic formal language rather than, as is done here, in standard [first-order logic](wikipedia://en/10983). The first set theory to include [impredicative](https://en.wikipedia.org/wiki/Impredicative) class comprehension was [Quine's](https://en.wikipedia.org/wiki/W._V._Quine) [ML](wikipedia://en/945957), that built on [New Foundations](wikipedia://en/945957) rather than on [ZFC](wikipedia://en/152214).[^o12] [Impredicative](https://en.wikipedia.org/wiki/Impredicative) class comprehension was also proposed in [Mostowski](https://en.wikipedia.org/wiki/Mostowski) (1951) and [Lewis](https://en.wikipedia.org/wiki/David_Kellogg_Lewis) (1991).

## The axioms in Kelley's *General Topology* {#The_axioms_in_Kelley's_General_Topology}

The axioms and definitions in this section are, but for a few inessential details, taken from the Appendix to Kelley (1955). The explanatory remarks below are not his. The Appendix states 181 theorems and definitions, and warrants careful reading as an abbreviated exposition of axiomatic set theory by a working mathematician of the first rank. Kelley introduced his axioms gradually, as needed to develop the topics listed after each instance of *Develop* below.

Notations appearing below and now well-known are not defined. Peculiarities of Kelley's notation include:

- He did *not* distinguish variables ranging over classes from those ranging over sets;
- *domain f* and *range f* denote the domain and range of the function *f*; this peculiarity has been carefully respected below;
- His primitive logical language includes [class abstracts](https://en.wikipedia.org/wiki/Set_builder_notation) of the form $\ \{x : A(x)\},$ "the class of all sets *x* satisfying *A*(*x*)."

::: {#o15 .definition cue=math-theorem name="Definition"}

**Definition.**

*x* is a *set* (and hence not a [proper class](https://en.wikipedia.org/wiki/Proper_class)) if, for some *y*, $x \in y$. **Classification (schema):** An axiom results if in

For each $\beta$, $\beta \in \{\alpha:A\}$ if and only if $\beta$ is a set and $B,$ 'α' and 'β' are replaced by variables, ' *A* ' by a formula Æ, and ' *B* ' by the formula obtained from Æ by replacing each occurrence of the variable that replaced α by the variable that replaced β provided that the variable that replaced β does not appear bound in *A*.

*Develop*: Boolean [algebra of sets](wikipedia://en/961805). Existence of the [null class](wikipedia://en/9566) and of the universal class *V*.

:::

If the scope of all quantified variables in the above axioms is restricted to sets, all axioms except **III** and the schema **IV** are ZFC axioms. **IV** is provable in ZFC. Hence the Kelley treatment of **MK** makes very clear that all that distinguishes **MK** from ZFC are variables ranging over [proper classes](https://en.wikipedia.org/wiki/Proper_class) as well as sets, and the Classification schema.

:::
