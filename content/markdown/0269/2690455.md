# Empirical distribution function

::: {#o1 .subject cue=lead name="Empirical distribution function"}

In [statistics](wikipedia://en/26685), an **empirical distribution function** ( an **empirical cumulative distribution function**, **eCDF**) is the [distribution function](wikipedia://en/5793) associated with the [empirical measure](wikipedia://en/5647670) of a [sample](wikipedia://en/160361).[^o2] This [cumulative distribution function](wikipedia://en/5793) is a [step function](wikipedia://en/170939) that jumps up by $1/n$ at each of the $n$ data points. Its value at any specified value of the measured variable is the fraction of observations of the measured variable that are less than or equal to the specified value.

:::

The empirical distribution function is an [estimate](wikipedia://en/10043) of the cumulative distribution function that generated the points in the sample. It converges with probability 1 to that underlying distribution, according to the [Glivenko–Cantelli theorem](wikipedia://en/3828409). A number of results exist to quantify the rate of [convergence](wikipedia://en/50723#Convergence_in_distribution) of the empirical distribution function to the underlying cumulative distribution function. A simple empirical estimate is the [frequency distribution](https://en.wikipedia.org/wiki/Frequency_distribution).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(X_{1}, \ldots, X_{n})$ be [independent, identically distributed](https://en.wikipedia.org/wiki/Iid) real random variables with the common [cumulative distribution function](wikipedia://en/5793) $F(t)$. Then the **empirical distribution function** is defined as[^o5]

$$\widehat F_n(t) = \frac{\text{number of elements in the sample} \leq t}{n} = \frac{1}{n} \sum_{i=1}^n \mathbf{1}_{X_i \le t},$$

where $\mathbf{1}_{A}$ is the [indicator](wikipedia://en/240790) of [event](wikipedia://en/22961) $A$. For a fixed $t$, the indicator $\mathbf{1}_{X_i \le t}$ is a [Bernoulli random variable](wikipedia://en/199189) with parameter $p = F(t)$; hence $n \widehat F_n(t)$ is a [binomial random variable](wikipedia://en/3876) with [mean](https://en.wikipedia.org/wiki/Mean) $nF(t)$ and [variance](wikipedia://en/32344) $nF(t)(1 - F(t))$. This implies that $\widehat F_n(t)$ is an [unbiased](wikipedia://en/8450479) estimator for $F(t)$.

In some textbooks, the empirical distribution function is defined as[^o6][^o7]

$$\widehat F_n(t) = \frac{1}{n+1} \sum_{i=1}^n \mathbf{1}_{X_i \le t}$$

However, since the ratio $(n + 1)/n$ approaches 1 as $n$ goes to infinity, the asymptotic properties of the two definitions are the same.

:::

## Asymptotic properties {#Asymptotic_properties}

By the [strong law of large numbers](https://en.wikipedia.org/wiki/Strong_law_of_large_numbers), the estimator $\widehat{F}_n(t)$ converges to $F(t)$ as $n\,\to\,\infty$ [almost surely](https://en.wikipedia.org/wiki/Almost_sure_convergence), for every value of $t$:[^o5]

$$\widehat F_n(t)\ \xrightarrow{\text{a.s.}}\ F(t);$$

thus the estimator $\widehat{F}_n(t)$ is [consistent](wikipedia://en/1497569). This expression asserts the pointwise convergence of the empirical distribution function to the true cumulative distribution function. There is a stronger result, called the [Glivenko–Cantelli theorem](wikipedia://en/3828409), which states that the convergence in fact happens uniformly over $t$:[^o9]

$$\left\|\widehat F_n-F\right\|_\infty \equiv \sup_{t\in\mathbb{R}} \left|\widehat F_n(t)-F(t)\right| \xrightarrow{}\ 0.$$

The sup-norm in this expression is called the [Kolmogorov–Smirnov statistic](wikipedia://en/16714) for testing the goodness-of-fit between the empirical distribution $\widehat{F}_n(t)$ and the assumed true cumulative distribution function $F$. Other [norm functions](wikipedia://en/990534) may be reasonably used here instead of the sup-norm. For example, the [L<sup>2</sup>-norm](https://en.wikipedia.org/wiki/Lp_norm) gives rise to the [Cramér–von Mises statistic](wikipedia://en/5509769).

The asymptotic distribution can be further characterized in several different ways. First, the [central limit theorem](wikipedia://en/39406) states that *pointwise*, $\widehat{F}_n(t)$ has asymptotically normal distribution with the standard $\sqrt{n}$ rate of convergence:[^o5]

$$\sqrt{n}\big(\widehat F_n(t) - F(t)\big)\ \ \xrightarrow{d}\ \ \mathcal{N}\Big( 0, F(t)\big(1-F(t)\big) \Big).$$

This result is extended by the [Donsker’s theorem](https://en.wikipedia.org/wiki/Donsker’s_theorem), which asserts that the *[empirical process](wikipedia://en/3690433)* $\sqrt{n}(\widehat{F}_n - F)$, viewed as a function indexed by $t\in\mathbb{R}$, [converges in distribution](https://en.wikipedia.org/wiki/Convergence_in_distribution) in the [Skorokhod space](https://en.wikipedia.org/wiki/Skorokhod_space) $D[-\infty, +\infty]$ to the mean-zero [Gaussian process](wikipedia://en/302944) $G_F = B \circ F$, where $B$ is the standard [Brownian bridge](wikipedia://en/1843777).[^o9] The covariance structure of this Gaussian process is

$$\operatorname{E}[\,G_F(t_1)G_F(t_2)\,] = F(t_1\wedge t_2) - F(t_1)F(t_2).$$

The uniform rate of convergence in Donsker’s theorem can be quantified by the result known as the [Hungarian embedding](https://en.wikipedia.org/wiki/Hungarian_embedding):[^o10]

$$\limsup_{n\to\infty} \frac{\sqrt{n}}{\ln^2 n} \left\| \sqrt{n}(\widehat F_n-F) - G_{F,n}\right\|_\infty < \infty, \quad \text{a.s.}$$

Alternatively, the rate of convergence of $\sqrt{n}(\widehat{F}_n-F)$ can also be quantified in terms of the asymptotic behavior of the sup-norm of this expression. Number of results exist in this venue, for example the [Dvoretzky–Kiefer–Wolfowitz inequality](wikipedia://en/8140616) provides bound on the tail probabilities of $\sqrt{n} \left\|\widehat{F}_n - F\right\|_\infty$:[^o10]

$$\Pr\!\Big( \sqrt{n}\|\widehat{F}_n-F\|_\infty > z \Big) \leq 2e^{-2z^2}.$$

In fact, Kolmogorov has shown that if the cumulative distribution function $F$ is continuous, then the expression $\sqrt{n} \left\|\widehat{F}_n - F\right\|_\infty$ converges in distribution to $\left\|B\right\|_\infty$, which has the [Kolmogorov distribution](https://en.wikipedia.org/wiki/Kolmogorov_distribution) that does not depend on the form of $F$.

Another result, which follows from the [law of the iterated logarithm](wikipedia://en/496558), is that [^o10]

$$\limsup_{n\to\infty} \sqrt{\frac{n}{2 \ln \ln n}} \left\|\widehat{F}_n - F\right\|_\infty \leq \frac{1}{2}, \quad \text{a.s.}$$

and

$$\liminf_{n\to\infty} \sqrt{2n\ln\ln n} \left\|\widehat{F}_n - F\right\|_\infty = \frac{\pi}{2}, \quad \text{a.s.}$$

As per [Dvoretzky–Kiefer–Wolfowitz inequality](wikipedia://en/8140616) the interval that contains the true CDF, $F(x)$, with probability $1-\alpha$ is specified as

$$F_n(x){-}\varepsilon \le F(x) \le F_n(x){+} \varepsilon \; \text{ where } \varepsilon = \sqrt{\frac{\ln{\frac{2}{\alpha}}}{2n}}.$$

As per the above bounds, we can plot the Empirical CDF, CDF and confidence intervals for different distributions by using any one of the statistical implementations.

## Statistical implementation {#Statistical_implementation}

A non-exhaustive list of software implementations of Empirical Distribution function includes:

- In [R software](https://www.rdocumentation.org/packages/stats/versions/3.6.1/topics/ecdf), we compute an empirical cumulative distribution function, with several methods for plotting, printing and computing with such an “ecdf” object.
- In [GNU Octave](https://gnu-octave.github.io/statistics/cdfplot.html) or [MATLAB](https://www.mathworks.com/help/stats/cdfplot.html) we can use Empirical cumulative distribution function (cdf) plot
- [jmp from SAS](https://www.jmp.com/support/help/14-2/cdf-plot.shtml), the CDF plot creates a plot of the empirical cumulative distribution function.
- [Minitab](https://blog.minitab.com/blog/data-analysis-and-quality-improvement-and-stuff/the-empirical-cdf-part-2-software-vs-etch-a-sketch), create an Empirical CDF
- [Mathwave](http://www.mathwave.com/articles/distribution-fitting-graphs.html), we can fit probability distribution to our data
- [Dataplot](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/ecdfplot.htm), we can plot Empirical CDF plot
- [Scipy](https://scipy.github.io/devdocs/reference/generated/scipy.stats.ecdf.html), we can use scipy.stats.ecdf
- [Statsmodels](https://www.statsmodels.org/dev/generated/statsmodels.distributions.empirical_distribution.ECDF.html#statsmodels.distributions.empirical_distribution.ECDF), we can use statsmodels.distributions.empirical\_distribution.ECDF
- [Matplotlib](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.ecdf.html), using the matplotlib.pyplot.ecdf function (new in version 3.8.0)[^o13]
- [Seaborn](https://seaborn.pydata.org/generated/seaborn.ecdfplot.html), using the seaborn.ecdfplot function
- [Plotly](https://plotly.com/python/ecdf-plots/), using the plotly.express.ecdf function
- [Excel](https://www.statisticshowto.com/empirical-distribution-function/), we can plot Empirical CDF plot
- [ArviZ](https://en.wikipedia.org/wiki/ArviZ), using the [az.plot\_dist](https://python.arviz.org/projects/plots/en/latest/gallery/plot_dist_ecdf.html) function
