# Lilliefors test

::: {#o1 .subject cue=lead name="Lilliefors test"}

**Lilliefors test** is a [normality test](wikipedia://en/8617378) based on the [Kolmogorov–Smirnov test](wikipedia://en/16714). It is used to test the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis) that data come from a [normally distributed](wikipedia://en/21462) population, when the null hypothesis does not specify *which* normal distribution; i.e., it does not specify the [expected value](wikipedia://en/9653) and [variance](wikipedia://en/32344) of the distribution.[^o2] It is named after [Hubert Lilliefors](wikipedia://en/17048217), professor of statistics at [George Washington University](https://en.wikipedia.org/wiki/George_Washington_University).

:::

A variant of the test can be used to test the null hypothesis that data come from an exponentially distributed population, when the null hypothesis does not specify which [exponential distribution](wikipedia://en/45906).[^o3]

## The test {#The_test}

The test proceeds as follows:[^o2]

1. First estimate the population mean and population variance based on the data.
1. Then find the maximum discrepancy between the [empirical distribution function](wikipedia://en/2690455) and the [cumulative distribution function](wikipedia://en/5793) (CDF) of the normal distribution with the estimated mean and estimated variance. Just as in the Kolmogorov–Smirnov test, this will be the test statistic.
1. Finally, assess whether the maximum discrepancy is large enough to be [statistically significant](wikipedia://en/160995), thus requiring rejection of the null hypothesis. This is where this test becomes more complicated than the Kolmogorov–Smirnov test. Since the hypothesised CDF has been moved closer to the data by estimation based on those data, the maximum discrepancy has been made smaller than it would have been if the null hypothesis had singled out just one normal distribution. Thus the "null distribution" of the test statistic, i.e. its [probability distribution](wikipedia://en/23543) assuming the null hypothesis is true, is [stochastically smaller](https://en.wikipedia.org/wiki/Stochastic_order) than the Kolmogorov–Smirnov distribution. This is the **Lilliefors distribution**. To date, tables for this distribution have been computed only by [Monte Carlo methods](wikipedia://en/56098).

In 1986 a corrected table of critical values for the test was published.[^o5]
