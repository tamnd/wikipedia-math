# Singular distribution

::: {#o1 .subject cue=lead name="Singular distribution"}

A **singular distribution** or **singular continuous distribution** is a [probability distribution](wikipedia://en/23543) concentrated on a [set of Lebesgue measure zero](wikipedia://en/21520), for which the probability of each point in that set is zero.[^o2]

:::

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Such distributions are not [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) with respect to [Lebesgue measure](wikipedia://en/18198).

A singular distribution is not a [discrete probability distribution](https://en.wikipedia.org/wiki/Discrete_probability_distribution) because each discrete point has a zero probability. On the other hand, neither does it have a [probability density function](wikipedia://en/43487), since the [Lebesgue integral](wikipedia://en/26064288) of any such function would be zero.

In general, distributions can be described as a discrete distribution (with a probability mass function), an absolutely continuous distribution (with a probability density), a singular distribution (with neither), or can be decomposed into a mixture of these.[^o2]

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

An example is the [Cantor distribution](wikipedia://en/387941); its cumulative distribution function is a [devil's staircase](wikipedia://en/320819). Another is the [Minkowski's question-mark distribution](wikipedia://en/1475109#Probability_distribution). Less curious examples appear in higher dimensions. For example, the upper and lower [Fréchet–Hoeffding bounds](https://en.wikipedia.org/wiki/Copula_%28probability_theory%29#Fréchet–Hoeffding_copula_bounds) are singular distributions in two dimensions.

:::
