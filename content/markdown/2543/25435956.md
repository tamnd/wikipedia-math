# Szymanski's conjecture

*Image: Szymanski routing.svg.* Routing a permutation of the doubly-directed [cube graph](https://en.wikipedia.org/wiki/Cube_graph)

::: {#o1 .problem cue=unsolved}

Can every [permutation](wikipedia://en/44027) on the $n$-dimensional doubly [directed](wikipedia://en/19721986) [hypercube graph](wikipedia://en/6706815) be routed with edge-disjoint [paths](wikipedia://en/638889)?

:::

::: {#o2 .subject cue=lead name="Szymanski's conjecture"}

In mathematics, **Szymanski's conjecture**, named after Ted H. Szymanski,[^o3] states that every [permutation](wikipedia://en/44027) on the $n$-dimensional doubly [directed](wikipedia://en/19721986) [hypercube graph](wikipedia://en/6706815) can be routed with edge-disjoint [paths](wikipedia://en/638889). That is, if the permutation $\sigma$ matches each vertex $v$ to another vertex $\sigma(v)$, then for each $v$ there exists a path in the hypercube graph from $v$ to $\sigma(v)$ such that no two paths for two different vertices $u$ and $v$ use the same edge in the same direction.

:::

## Known results {#Known_results}

Through computer experiments it has been verified that the conjecture is true for $n \leq 4$.[^o5] Although the conjecture remains open for $n \geq 5$, in this case there exist permutations that require the use of paths that are not [shortest paths](https://en.wikipedia.org/wiki/Shortest_path) in order to be routed.[^o6]

## Partial results {#Partial_results}

While the full conjecture remains open, several partial results have been established. Most notably, it has been proven that the hypercube is 2-rearrangeable, meaning that any permutation can be partitioned into two partial permutations, each of which can be routed by edge-disjoint paths.[^o8] This result has applications in [time-sharing](https://en.wikipedia.org/wiki/Time-sharing) approaches and optical networks with multiple wavelengths, where virtual doubling of edges can be achieved without physically adding connections. The 2-rearrangeability result also provides a 2-approximation algorithm for the maximum disjoint paths problem on the hypercube, which has applications in [admission control](https://en.wikipedia.org/wiki/Admission_control) for high-speed networks.

A related result shows that when source and target vertices are separated by at least two levels in the hypercube (in terms of [Hamming weight](wikipedia://en/1127884)), there exist two edge-disjoint collections of vertex-disjoint paths connecting them.[^o9] More generally, it has been conjectured that if source and target vertices are separated by $r$ levels, then $r$ such edge-disjoint collections should exist.[^o9]

### 2-1 routing requests {#2-1_routing_requests}

The study of 2-1 routing requests (where each vertex can be used at most twice as a source but only once as a target) is important for understanding Szymanski's conjecture. Any counterexample to the conjecture would necessarily produce two non-routable 2-1 routing requests when decomposed using the "cross first strategy".[^o11] However, the existence of non-routable 2-1 routing requests in a dimension does not immediately provide a counterexample to Szymanski's conjecture for that dimension.

In $H_3$, there exist exactly two 2-1 routing requests that cannot be routed and are non-equivalent by automorphism.[^o5] One of these, denoted $g_3$, can be extended to any dimension $n \geq 3$ to produce a non-routable 2-1 routing request $g_n$ in $H_n$.[^o5] Computer searches have identified approximately a dozen non-routable 2-1 routing requests in $H_4$, though not all can be extended to higher dimensions.[^o11]

## Motivation {#Motivation}

The conjecture is closely related to the [circuit-switched](https://en.wikipedia.org/wiki/Circuit_switching) routing capability of networks, which is used to support simultaneous communications across multiprocessor parallel and telecommunication systems. In circuit-switched routing, a dedicated path is established for each source-destination pair, and data is pipelined through the path. If the hypercube is rearrangeable (meaning Szymanski's conjecture is true), it would guarantee that any permutation routing request can be satisfied with edge-disjoint paths, allowing parallel data transfer between every source-destination pair.[^o8]

The conjecture also has connections to [property testing](wikipedia://en/20506304), particularly in the context of testing [monotonicity](wikipedia://en/48260) of Boolean functions over the hypercube domain.[^o9] Understanding hypercube routing properties has implications for developing efficient algorithms for monotonicity testing and related problems in theoretical computer science.
