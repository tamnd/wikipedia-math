# Double turnstile

::: {#o1 .subject cue=lead name="Double turnstile"}

In [logic](wikipedia://en/46426065), the [symbol](wikipedia://en/24028642) ⊨, ⊧ or $\models$ is called the **double turnstile**. It is often read as "[entails](wikipedia://en/37531624)", "[models](wikipedia://en/19858)", "is a **[semantic](https://en.wikipedia.org/wiki/Semantic)** **consequence** of" or "is stronger than".[^o2] It is closely related to the [turnstile](wikipedia://en/7954712) symbol $\vdash$, which has a single bar across the middle, and which denotes *[syntactic](https://en.wikipedia.org/wiki/Syntactic)* consequence (in contrast to *semantic*).

:::

## Meaning {#Meaning}

The double turnstile is a binary relation. It has several different meanings in different contexts:

- To show [semantic consequence](wikipedia://en/37531624#Semantic_consequence), with a set of sentences on the left and a single sentence on the right, to denote that if every sentence on the left is true, the sentence on the right must be true, e.g. $\Gamma \vDash \varphi$. This usage is closely related to the single-barred [turnstile](wikipedia://en/7954712) symbol which denotes [syntactic consequence](wikipedia://en/37531624#Syntactic_consequence).
- To show [satisfaction](wikipedia://en/23401166), with a model (or truth-structure) on the left and a set of sentences on the right, to denote that the structure is a model for (or satisfies) the set of sentences, e.g. $\mathcal{A} \models \Gamma$. This is typically done [inductively](wikipedia://en/1063436) along with restricting the range of a *variable assignment*, a function mapping each variable symbol to a value in $\mathcal{A}$ it might hold.[^o4]
  - In this context, the semantic consequence in the previous list can be stated as "For a given model $\mathcal{A}$, if $\mathcal{A} \models \Gamma$ then $\mathcal{A} \vDash \varphi$".
- To denote a [tautology](wikipedia://en/4495335), $\vDash \varphi$. which is to say that the expression $\varphi$ is a semantic consequence of the empty set.
- You can also use this symbol as follows: ⊭ to denote the statement 'does not entail'.
- There is an unrelated usage in combinatorics where for a non-negative integer $n$ the statement $\lambda \vDash n$ means $\lambda$ is a [composition](wikipedia://en/550741) of $n$.

## Typography {#Typography}

In [TeX](https://en.wikipedia.org/wiki/TeX), the turnstile symbols ⊨ and $\models$ are obtained from the commands `\vDash` and `\models` respectively.

In Unicode it is encoded at 22A8 , and the opposite of it is 22AD .

In [LaTeX](https://en.wikipedia.org/wiki/LaTeX) there is the [turnstile package](http://www.ctan.org/tex-archive/macros/latex/contrib/turnstile), which issues this sign in many ways, including the double turnstile, and is capable of putting labels below or above it, in the correct places. The article [A Tool for Logicians](http://www.tug.org/pracjourn/2007-3/buchsbaum) is a tutorial on using this package.
