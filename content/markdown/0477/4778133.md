# Elementary number

::: {#o1 .subject cue=lead name="Elementary number"}

An **elementary number** is one formalization of the concept of a [closed-form number](https://en.wikipedia.org/wiki/Closed-form_number). Roughly speaking, it is a complex number that can be specified using algebraic operations, [exponentiation](wikipedia://en/99491), and [logarithms](wikipedia://en/17860).

:::

Several different kinds of elementary numbers appear in the literature.

An elementary number of [Joseph Fels Ritt](https://en.wikipedia.org/wiki/Joseph_Fels_Ritt) is built from an integer by applying finitely many $\mathbb{Q}$-algebraic operations (i.e. $\mathbb{Q}$-algebraic functions), exponential functions, and/or logarithm functions.[^o2] The set of these numbers is the smallest subfield of $\mathbb{C}$ that is algebraically closed and closed under $\exp$ and $\ln$.[^o3] An elementary number is a constant $\mathbb{Q}$-elementary function.[^o4]

An exponential-logarithmic number of Timothy Y. Chow is built from an integer by applying finitely many field operations (i.e. rational functions) over $\mathbb{Q}$, exponential functions, and/or logarithm functions. The set of these numbers is the intersection of all subfields of $\mathbb{C}$ that are closed under exp and ln. It is closed under the field operations, $\exp$ and $\ln$.[^o5]

An elementary number of Daniel Richardson is a solution of a special kind of system of exponential polynomial equations.[^o6]

Chow's numbers can be presented explicitly, i.e. by applying rational, exponential and logarithmic functions, whereas Ritt's and Richardson's sets also allow implicit presentation, i.e. solutions of $\mathbb{Q}$-algebraic equations respectively special exponential-logarithmic polynomial systems.
