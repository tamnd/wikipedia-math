# Graded category

::: {#o1 .subject cue=lead name="Graded category"}

In [mathematics](wikipedia://en/18831), if $\mathcal{A}$ is a [category](wikipedia://en/53759), then a **$\mathcal{A}$-graded category** is a category $\mathcal{C}$ together with a [functor](wikipedia://en/10987) $F\colon\mathcal{C} \rightarrow \mathcal{A}$.

:::

[Monoids](wikipedia://en/19652) and [groups](wikipedia://en/19447) can be thought of as categories with a single [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29). A monoid-graded or group-graded category is therefore one in which to each [morphism](wikipedia://en/27716891) is attached an element of a given monoid (resp. group), its grade. This must be compatible with composition, in the sense that compositions have the product grade.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

There are various different definitions of a graded category, up to the most abstract one given above. A more concrete definition of a graded [abelian category](wikipedia://en/45063) is as follows:[^o4]

Let $\mathcal{C}$ be an abelian category and $G$ a monoid. Let $\mathcal{S} = \{ S_g : g \in G \}$ be a set of functors from $\mathcal{C}$ to itself. If

- $S_1$ is the [identity functor](https://en.wikipedia.org/wiki/Identity_functor) on $\mathcal{C}$,
- $S_g S_h = S_{gh}$ for all $g,h \in G$ and
- $S_g$ is a [full and faithful functor](https://en.wikipedia.org/wiki/Full_and_faithful_functor) for every $g\in G$

we say that $(\mathcal{C},\mathcal{S})$ is a $G$-graded category.

:::
