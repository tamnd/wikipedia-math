# Wijsman convergence

::: {#o1 .subject cue=lead name="Wijsman convergence"}

**Wijsman convergence** is a variation of [Hausdorff convergence](https://en.wikipedia.org/wiki/Hausdorff_convergence) suitable for work with [unbounded sets](https://en.wikipedia.org/wiki/Unbounded_set). Intuitively, Wijsman convergence is to convergence in the [Hausdorff metric](https://en.wikipedia.org/wiki/Hausdorff_metric) as [pointwise convergence](wikipedia://en/340198) is to [uniform convergence](wikipedia://en/50652).

:::

## History {#History}

The convergence was defined by [Robert Wijsman](https://en.wikipedia.org/wiki/Robert_Wijsman).[^o3] The same definition was used earlier by [Zdeněk Frolík](wikipedia://en/37391956).[^o4] Yet earlier, Hausdorff in his book *[Grundzüge der Mengenlehre](wikipedia://en/2561202)* defined so called *closed limits*; for [proper metric spaces](https://en.wikipedia.org/wiki/Proper_metric_space) it is the same as Wijsman convergence.

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let (*X*, *d*) be a metric space and let Cl(*X*) denote the collection of all *d*-closed subsets of *X*. For a point *x* ∈ *X* and a set *A* ∈ Cl(*X*), set

$$d(x, A) = \inf_{a \in A} d(x, a).$$

A sequence (or [net](wikipedia://en/22170)) of sets *A*<sub>*i*</sub> ∈ Cl(*X*) is said to be **Wijsman convergent** to *A* ∈ Cl(*X*) if, for each *x* ∈ *X*,

$$d(x, A_{i}) \to d(x, A).$$

Wijsman convergence induces a [topology](wikipedia://en/29954) on Cl(*X*), known as the **Wijsman topology**.

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The Wijsman topology depends very strongly on the metric *d*. Even if two metrics are uniformly equivalent, they may generate different Wijsman topologies.
- **Beer's theorem**: if (*X*, *d*) is a [complete](https://en.wikipedia.org/wiki/Complete_space), [separable](wikipedia://en/27855) metric space, then Cl(*X*) with the Wijsman topology is a [Polish space](wikipedia://en/396622), i.e. it is separable and metrizable with a complete metric.
- Cl(*X*) with the Wijsman topology is always a [Tychonoff space](wikipedia://en/30554). Moreover, one has the **Levi-Lechicki theorem**: (*X*, *d*) is separable [if and only if](wikipedia://en/14922) Cl(*X*) is either metrizable, [first-countable](wikipedia://en/904940) or [second-countable](wikipedia://en/901459).
- If the pointwise convergence of Wijsman convergence is replaced by uniform convergence (uniformly in *x*), then one obtains Hausdorff convergence, where the Hausdorff metric is given by

$$d_{\mathrm{H}} (A, B) = \sup_{x \in X} \big| d(x, A) - d(x, B) \big|.$$

The Hausdorff and Wijsman topologies on Cl(*X*) coincide if and only if (*X*, *d*) is a [totally bounded space](wikipedia://en/1528346).

:::
