# Mumble (software)

::: {#o4 .subject cue=lead name="Mumble"}

**Mumble** is a [voice over IP](https://en.wikipedia.org/wiki/Voice_over_IP) (VoIP) application primarily designed for use by [gamers](https://en.wikipedia.org/wiki/Gamer) and is similar to programs such as [TeamSpeak](https://en.wikipedia.org/wiki/TeamSpeak).[^o5]

:::

Mumble uses a [client–server](https://en.wikipedia.org/wiki/Client–server) architecture which allows users to talk to each other via the same server.[^o6] It has a very simple administrative interface and features high sound quality and low [latency](https://en.wikipedia.org/wiki/Latency_%28audio%29). All communication is encrypted.[^o7]

Mumble is [free and open-source software](https://en.wikipedia.org/wiki/Free_and_open-source_software), is [cross-platform](https://en.wikipedia.org/wiki/Cross-platform), and is released under the terms of the [BSD-3-Clause](https://en.wikipedia.org/wiki/BSD_licenses) license.[^o3]

## Channel hierarchy {#Channel_hierarchy}

A Mumble server (called **Murmur**) has a root channel and a hierarchical [tree](https://en.wikipedia.org/wiki/Tree_structure) of channels beneath it. Users can temporarily connect channels to create larger virtual channels. This is useful during larger events where a small group of users may be chatting in a channel, but are linked to a common channel with other users to hear announcements. It also matches team-based [first-person shooter](https://en.wikipedia.org/wiki/First-person_shooter) (FPS) games. Each channel has an associated set of groups and [access control lists](https://en.wikipedia.org/wiki/Access_control_list) which control user permissions. The system supports many usage scenarios, at the cost of added configuration complexity.[^o9]

## Sound quality {#Sound_quality}

Mumble uses the low-[latency](https://en.wikipedia.org/wiki/Latency_%28engineering%29) audio codec [Opus](https://en.wikipedia.org/wiki/Opus_%28audio_format%29) as of version 1.2.4,[^o11] the codec that succeeds the previous defaults [Speex](https://en.wikipedia.org/wiki/Speex) and [CELT](https://en.wikipedia.org/wiki/CELT). This and the rest of Mumble's design allow for low-latency communication, meaning a shorter delay between when something is said on one end and when it's heard on the other. Mumble also incorporates [echo cancellation](https://en.wikipedia.org/wiki/Echo_cancellation) to reduce echo when using speakers or poor quality sound hardware.

## Security and privacy {#Security_and_privacy}

Mumble connects to a server via a [TLS](wikipedia://en/187813) control channel, with the audio traveling via UDP encrypted with [AES](wikipedia://en/1260) in [OCB mode](wikipedia://en/2233546).[^o13] As of 1.2.9 Mumble now prefers [ECDHE](https://en.wikipedia.org/wiki/Elliptic_curve_Diffie–Hellman) + [AES-GCM](wikipedia://en/5897139) cipher suites if possible, providing Perfect Forward Secrecy.[^o14] While password authentication for users is supported, since 1.2.0 it is typically eschewed in favor of strong authentication in the form of public key certificates.[^o15]

## Overlay {#Overlay}

There is an integrated overlay for use in fullscreen applications.[^o7] The overlay shows who is talking and what linked channel they are in. As of version 1.0, users could upload avatars to represent themselves in the overlay, creating a more personalized experience. As of version 1.2, the overlay works with most [Direct3D](https://en.wikipedia.org/wiki/Direct3D) 9/10 and [OpenGL](https://en.wikipedia.org/wiki/OpenGL) applications on Windows and has [OpenGL](https://en.wikipedia.org/wiki/OpenGL) support for Linux and Mac OS X.[^o17] Support for DirectX 11 applications was later added.

## Positional audio {#Positional_audio}

For certain games, Mumble modifies the audio to position other players' voices according to their relative position in the game.[^o7] This not only includes giving a sense of direction, but also of distance.

To realize this, Mumble sends each player's in-game position to players in the same game with every audio packet. Mumble can gather the information needed to do this in two ways: it either reads the needed information directly out of the memory of the game or the games provide it themselves via the so-called link plugin interface.

The link plugin provides games with a way to expose the information needed for positional audio themselves by including a small piece of source code provided by the Mumble project.[^o19] Several high-profile games have implemented this functionality including many of [Valve](https://en.wikipedia.org/wiki/Valve_Corporation)'s [Source Engine](https://en.wikipedia.org/wiki/Source_%28game_engine%29) based games (*[Team Fortress 2](https://en.wikipedia.org/wiki/Team_Fortress_2)*, *[Day of Defeat: Source](https://en.wikipedia.org/wiki/Day_of_Defeat:_Source)*, *[Counter-Strike: Source](https://en.wikipedia.org/wiki/Counter-Strike:_Source)*, *[Half-Life 2: Deathmatch](https://en.wikipedia.org/wiki/Half-Life_2:_Deathmatch)*)[^o20][^o21] and *[Guild Wars 2](https://en.wikipedia.org/wiki/Guild_Wars_2)*.[^o22][^o23]

## Mobile apps {#Mobile_apps}

Third-party mobile apps are available for Mumble, such as Mumble for iOS, Plumble for Android (F-Droid, Google Play, Note: Discontinued in 2016), and Mumla (F-Droid, Google Play).

## Server integration {#Server_integration}

Mumble fits into existing technological and social structures. As such, the server is fully remote controllable over [ZeroC Ice](https://en.wikipedia.org/wiki/Internet_Communications_Engine).[^o26] User channels as well as virtual server instances can be manipulated. The project provides a number of sample scripts illustrating the abilities of the interface[^o27] as well as prefabricated scripts offering features like authenticating users using an existing [phpBB](https://en.wikipedia.org/wiki/PhpBB) or [Simple Machines Forum](https://en.wikipedia.org/wiki/Simple_Machines_Forum) [database](https://en.wikipedia.org/wiki/Database).[^o28] The murmur server uses port 64738 [TCP](https://en.wikipedia.org/wiki/Transmission_Control_Protocol) and [UDP](https://en.wikipedia.org/wiki/User_Datagram_Protocol) by default. The port number refers to the address of the reset function on a [Commodore 64](https://en.wikipedia.org/wiki/Commodore_64).

An alternative minimalist implementation of the mumble-server (Murmur) is called uMurmur.[^o29] It is intended for installation on [embedded devices](https://en.wikipedia.org/wiki/Embedded_devices) with limited resources, such as, for example, [residential gateways](https://en.wikipedia.org/wiki/Residential_gateway) running [OpenWrt](https://en.wikipedia.org/wiki/OpenWrt).[^o30]

## Server hosting {#Server_hosting}

Like many other VoIP clients, Mumble servers can be both rented or hosted locally. Hosting a Mumble server locally requires downloading Murmur (included as an option in the Mumble installer) and launching it. Configuring the server is achieved via editing the configuration file. The configuration file holds information for the server's name, user authentication, audio quality restrictions, and port.

Administering the server from within requires a user to be given administrator rights, or can also be done by logging into the SuperUser account. Administrators within the server can add or edit rooms, manage users, and view the server's information.
