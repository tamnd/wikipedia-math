# Berezin transform

::: {#o1 .subject cue=lead name="Berezin transform"}

In [mathematics](wikipedia://en/18831) — specifically, in [complex analysis](wikipedia://en/5759) — the **Berezin transform** is an [integral operator](wikipedia://en/2649421) acting on functions defined on the [open](wikipedia://en/39358) [unit disk](wikipedia://en/252738) *D* of the [complex plane](wikipedia://en/217628) **C**. Formally, for a function *ƒ* : *D* → **C**, the **Berezin transform** of *ƒ* is a new function *Bƒ* : *D* → **C** defined at a point *z* ∈ *D* by

:::

$$(B f)(z) = \int_D \frac{(1 - |z|^2)^2}{| 1 - z \bar{w} |^4} f(w) \, \mathrm{d}A (w),$$

where $\overline{w}$ denotes the [complex conjugate](wikipedia://en/173918) of *w* and $\mathrm{d}A$ is the area measure. It is named after [Felix Alexandrovich Berezin](https://en.wikipedia.org/wiki/Felix_Alexandrovich_Berezin).
