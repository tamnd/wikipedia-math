# Lehmer's totient problem

::: {#o1 .subject cue=lead name="Lehmer's totient problem"}

::: {#o2 .problem cue=unsolved}

Can the totient function of a composite number $n$ divide $n-1$?

:::

In mathematics, **Lehmer's totient problem** asks whether there is any [composite number](wikipedia://en/82289) $n$ such that [Euler's totient function](wikipedia://en/53452) $\varphi(n)$ divides $n - 1$. This is an unsolved problem.

:::

It is known that $\varphi(n) = n - 1$ if and only if $n$ is prime. So for every [prime number](wikipedia://en/23666) $n$, we have $\varphi(n) = n - 1$ and thus in particular $\varphi(n)$ divides $n - 1$. [D. H. Lehmer](https://en.wikipedia.org/wiki/D._H._Lehmer) asked in 1932 whether there exist composite numbers with this property.[^o5]

## History {#History}

- Lehmer showed that if any composite solution *$n$* exists, it must be odd, [square-free](wikipedia://en/29525), and divisible by at least seven [distinct primes](wikipedia://en/57197043) (i.e. $\omega(n) \ge 7$). Such a number must also be a [Carmichael number](wikipedia://en/7723).
- In 1980, Cohen and Hagis proved that, for any solution *$n$* to the problem, $n > 10^{20}$ and $\omega(n) \ge 14$.[^o8]
- In 1988, Hagis showed that if 3 divides any solution *$n$*, then $n > 10^{1937042}$ and $\omega(n) \ge 298848$.[^o6] This was subsequently improved by Burcsi, Czirbusz, and Farkas, who showed that if 3 divides any solution *$n$*, then $n > 10^{360000000}$ and $\omega(n) \ge 40000000$.[^o9]
- A 2011 result of Luca and Pomerance states that the number of solutions to the problem less than $X$ is at most $X^{1/2} / (\log X)^{1/2 + o(1)}$.[^o7]
- In 2019 Burek and Żmija proved that any solution *$n$* satisfies $n < 2^{2^{\omega(n)}} - 2^{2^{\omega(n)-1}}$.[^o13]
