# Aronszajn line

::: {#o1 .subject cue=lead name="Aronszajn line"}

In mathematical [set theory](wikipedia://en/27553), an **Aronszajn line** (named after [Nachman Aronszajn](wikipedia://en/13496987)) is a [linear ordering](wikipedia://en/30330) of cardinality $\aleph_1$ which contains no subset [order-isomorphic](wikipedia://en/23916899) to

:::

- $\omega_1$ with the usual ordering
- the reverse of $\omega_1$
- an [uncountable](wikipedia://en/32248) subset of the [Real numbers](wikipedia://en/20646438) with the usual ordering.

Unlike [Suslin lines](wikipedia://en/228668), the existence of Aronszajn lines is provable using the standard axioms of set theory. A linear ordering is an Aronszajn line if and only if it is the lexicographical ordering of some [Aronszajn tree](wikipedia://en/12774077).[^o2]
