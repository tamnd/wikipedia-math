# Schreier domain

::: {#o1 .subject cue=lead name="Schreier domain"}

In [abstract algebra](wikipedia://en/19616384), a **Schreier domain**, named after [Otto Schreier](wikipedia://en/4355201), is an [integrally closed domain](wikipedia://en/21420209) where every nonzero element is **primal**; *i.e.*, whenever *x* divides *yz*, *x* can be written as *x* = *x*<sub>1</sub> *x*<sub>2</sub> so that *x*<sub>1</sub> divides *y* and *x*<sub>2</sub> divides *z*. An [integral domain](wikipedia://en/15462) is said to be **pre-Schreier** if every nonzero element is primal. A [GCD domain](wikipedia://en/2932361) is an example of a Schreier domain. The term "Schreier domain" was introduced by [P. M. Cohn](https://en.wikipedia.org/wiki/P._M._Cohn) in 1960s. The term "pre-Schreier domain" is due to Muhammad Zafrullah.

:::

In general, an [irreducible element](wikipedia://en/60693) is primal if and only if it is a [prime element](wikipedia://en/60692). Consequently, in a pre-Schreier domain, every irreducible is prime. In particular, an [atomic](wikipedia://en/9599592) pre-Schreier domain is a [unique factorization domain](wikipedia://en/60546); this generalizes the fact that an atomic GCD domain is a UFD.
