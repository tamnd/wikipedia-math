# List of axiomatic systems in logic

::: {#o1 .subject cue=lead name="List of axiomatic systems in logic"}

This article contains a list of sample [Hilbert-style](wikipedia://en/8529655) [deductive systems](https://en.wikipedia.org/wiki/Deductive_system) for [propositional logics](wikipedia://en/18154).

:::

## Classical propositional calculus systems {#Classical_propositional_calculus_systems}

[Classical](wikipedia://en/55868) propositional calculus is the standard propositional logic. Its intended semantics is [bivalent](https://en.wikipedia.org/wiki/Bivalent_logic) and its main property is that it is [strongly complete](wikipedia://en/31271451), otherwise said that whenever a formula semantically follows from a set of premises, it also follows from that set syntactically. Many different equivalent complete axiom systems have been formulated. They differ in the choice of basic [connectives](wikipedia://en/18153) used, which in all cases have to be [functionally complete](https://en.wikipedia.org/wiki/Functionally_complete) (i.e. able to express by composition all *n*-ary [truth tables](https://en.wikipedia.org/wiki/Truth_tables)), and in the exact complete choice of axioms over the chosen basis of connectives.

### Implication and negation {#Implication_and_negation}

The formulations here use implication and negation $\{\to,\neg\}$ as functionally complete set of basic connectives. Every logic system requires at least one non-nullary [rule of inference](wikipedia://en/252311). Classical propositional calculus typically uses the rule of [modus ponens](wikipedia://en/18900):

$$\frac{A,A\to B}{B}.$$

We assume this rule is included in all systems below unless stated otherwise.

[Frege](wikipedia://en/48416)'s axiom system:[^o4]

$$A\to(B\to A)$$

$$(A\to(B\to C))\to((A\to B)\to(A\to C))$$

$$(A \to (B \to C)) \to (B \to (A \to C))$$

$$(A\to B)\to(\neg B\to\neg A)$$

$$\neg\neg A\to A$$

$$A\to\neg\neg A$$

[Hilbert](wikipedia://en/8302)'s axiom system:[^o4]

$$A\to(B\to A)$$

$$(A\to(B\to C))\to(B\to(A\to C))$$

$$(B\to C)\to((A\to B)\to(A\to C))$$

$$A\to(\neg A\to B)$$

$$(A\to B)\to((\neg A\to B)\to B)$$

[Łukasiewicz](wikipedia://en/305064)'s axiom systems:[^o4]

- First:

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$(\neg A\to A)\to A$$

$$A\to(\neg A\to B)$$

- Second:

$$((A\to B)\to C)\to(\neg A\to C)$$

$$((A\to B)\to C)\to(B\to C)$$

$$(\neg A\to C)\to((B\to C)\to((A\to B)\to C))$$

- Third:

$$A\to(B\to A)$$

$$(A\to(B\to C))\to((A\to B)\to(A\to C))$$

$$(\neg A\to\neg B)\to(B\to A)$$

[Arai](https://en.wikipedia.org/wiki/Yoshinari_Arai)'s axiom system:[^o5]

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$A\to(\neg A\to B)$$

$$(\neg A\to B)\to((B\to A)\to A)$$

Łukasiewicz and [Tarski](wikipedia://en/59920)'s axiom system:[^o6]

$$[(A\to(B\to A))\to([(\neg C\to(D\to\neg E))\to[(C\to(D\to F))\to((E\to D)\to(E\to F))]]\to G)]\to(H\to G)$$

[Meredith](wikipedia://en/2595472)'s axiom system:

$$((((A\to B)\to(\neg C\to\neg D))\to C)\to E)\to((E\to A)\to(D\to A))$$

[Mendelson](wikipedia://en/27776666)'s axiom system:[^o7]

$$A\to(B\to A)$$

$$(A\to(B\to C))\to((A\to B)\to(A\to C))$$

$$(\neg A\to\neg B)\to((\neg A\to B)\to A)$$

[Russell](wikipedia://en/4163)'s axiom system:[^o4]

$$A\to(B\to A)$$

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$(A\to(B\to C))\to(B\to(A\to C))$$

$$\neg\neg A\to A$$

$$(A\to\neg A)\to\neg A$$

$$(A\to\neg B)\to(B\to\neg A)$$

[Sobociński](https://en.wikipedia.org/wiki/Bolesław_Sobociński)'s axiom systems:[^o4]

- First:

$$\neg A\to(A\to B)$$

$$A\to(B\to(C\to A))$$

$$(\neg A\to C)\to((B\to C)\to((A\to B)\to C))$$

- Second:

$$(A\to B)\to(\neg B\to(A\to C))$$

$$A\to(B\to(C\to A))$$

$$(\neg A\to B)\to((A\to B)\to B)$$

### Implication and falsum {#Implication_and_falsum}

Instead of negation, classical logic can also be formulated using the functionally complete set $\{\to,\bot\}$ of connectives.

Tarski–[Bernays](wikipedia://en/2556580)–[Wajsberg](https://en.wikipedia.org/wiki/Mordechaj_Wajsberg) axiom system:

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$A\to(B\to A)$$

$((A\to B)\to A)\to A$.[^o9]

$$\bot\to A$$

[Church](wikipedia://en/49731)'s axiom system:

$$A\to(B\to A)$$

$$(A\to(B\to C))\to((A\to B)\to(A\to C))$$

$$((A\to\bot)\to\bot)\to A$$

Meredith's axiom systems:

- First:[^o10][^o11][^o12]

$$((((A\to B)\to(C\to\bot))\to D)\to E)\to((E\to A)\to(C\to A))$$

- Second:[^o10]

$$((A\to B)\to((\bot\to C)\to D))\to((D\to A)\to(E\to(F\to A)))$$

### Negation and disjunction {#Negation_and_disjunction}

Instead of implication, classical logic can also be formulated using the functionally complete set $\{\neg,\lor\}$ of connectives. These formulations use the following rule of inference;

$$\frac{A, \neg A\lor B}{B}.$$

Russell–Bernays axiom system:

$$\neg (\neg B\lor C)\lor (\neg (A\lor B)\lor (A\lor C))$$

$$\neg (A\lor B)\lor (B\lor A)$$

$$\neg A\lor (B\lor A)$$

$$\neg (A\lor A)\lor A$$

Meredith's axiom systems:[^o14]

- First:

$$\neg (\neg (\neg A\lor B)\lor (C\lor (D\lor E)))\lor (\neg (\neg D\lor A)\lor (C\lor (E\lor A)))$$

- Second:

$$\neg (\neg (\neg A\lor B)\lor (C\lor (D\lor E)))\lor (\neg (\neg E\lor D)\lor (C\lor (A\lor D)))$$

- Third:

$$\neg (\neg (\neg A\lor B)\lor (C\lor (D\lor E)))\lor (\neg (\neg C\lor A)\lor (E\lor (D\lor A)))$$

Dually, classical propositional logic can be defined using only conjunction and negation.

### Conjunction and negation {#Conjunction_and_negation}

Rosser J. Barkley created a system based on conjunction and negation $\{\wedge, \neg\}$, with the modus ponens as inference rule. In his book,[^o16] he used the implication to present his axiom schemes. "$C\rightarrow D$" is an abbreviation for "$\neg(C\wedge \neg D)$":

- $$A\rightarrow A\wedge A$$
- $$A\wedge B\rightarrow A$$
- $$\left(A\rightarrow B\right)\rightarrow\left(\neg\left(B\wedge C\right)\rightarrow\neg\left(C\wedge A\right)\right)$$

If we don't use the abbreviation, we get the axiom schemes in the following form:

- $$\neg(A\wedge \neg(A\wedge A))$$
- $$\neg((A\wedge B)\wedge \neg A)$$
- $$\neg\left(\neg\left(A\wedge\neg B\right)\wedge\neg\neg\left(\neg\left(B\wedge C\right)\wedge\neg\neg\left(C\wedge A\right)\right)\right)$$

Also, modus ponens becomes:

- $$\frac{A, \neg\left(A\wedge \neg B\right)}{B}$$

### Sheffer's stroke {#Sheffer's_stroke}

Because [Sheffer's stroke](https://en.wikipedia.org/wiki/Sheffer's_stroke) (also known as NAND operator) is [functionally complete](https://en.wikipedia.org/wiki/Functionally_complete), it can be used to create an entire formulation of propositional calculus. NAND formulations use a rule of inference called [Nicod](wikipedia://en/2078853)'s modus ponens:

$$\frac{A, A\mid(B\mid C)}{C}.$$

Nicod's axiom system:[^o10]

$$(A\mid(B\mid C))\mid[(E\mid(E\mid E))\mid((D\mid B)\mid[(A\mid D)\mid(A\mid D)])]$$

Łukasiewicz's axiom systems:[^o10]

- First:

$$(A\mid(B\mid C))\mid[(D\mid(D\mid D))\mid((D\mid B)\mid[(A\mid D)\mid(A\mid D)])]$$

- Second:

$$(A\mid(B\mid C))\mid[(A\mid(C\mid A))\mid((D\mid B)\mid[(A\mid D)\mid(A\mid D)])]$$

Wajsberg's axiom system:[^o10]

$$(A\mid(B\mid C))\mid[((D\mid C)\mid[(A\mid D)\mid(A\mid D)])\mid(A\mid(A\mid B))]$$

[Argonne](https://en.wikipedia.org/wiki/Argonne_National_Laboratory) axiom systems:[^o10]

- First:

$$(A\mid(B\mid C))\mid[(A\mid(B\mid C))\mid((D\mid C)\mid[(C\mid D)\mid(A\mid D)])]$$

- Second:

$(A\mid(B\mid C))\mid[([(B\mid D)\mid(A\mid D)]\mid(D\mid B))\mid((C\mid B)\mid A)]$[^o18]

Computer analysis by Argonne has revealed over 60 additional single axiom systems that can be used to formulate NAND propositional calculus.[^o12]

## Implicational propositional calculus {#Implicational_propositional_calculus}

The [implicational propositional calculus](wikipedia://en/5795043) is the fragment of the classical propositional calculus which only admits the implication connective. It is not [functionally complete](https://en.wikipedia.org/wiki/Functionally_complete) (because it lacks the ability to express falsity and negation) but it is however [syntactically complete](wikipedia://en/31271451). The implicational calculi below use modus ponens as an inference rule.

Bernays–Tarski axiom system:[^o20]

$$A\to(B\to A)$$

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$((A\to B)\to A)\to A$$

Łukasiewicz and Tarski's axiom systems:

- First:[^o20]

$$[(A\to(B\to A))\to[([((C\to D)\to E)\to F]\to[(D\to F)\to(C\to F)])\to G]]\to G$$

- Second:[^o20]

$$[(A\to B)\to((C\to D)\to E)]\to([F\to((C\to D)\to E)]\to[(A\to F)\to(D\to E)])$$

- Third:

$$((A\to B)\to(C\to D))\to(E\to((D\to A)\to(C\to A)))$$

- Fourth:

$$((A\to B)\to(C\to D))\to((D\to A)\to(E\to(C\to A)))$$

Łukasiewicz's axiom system:[^o21][^o20]

$$((A\to B)\to C)\to((C\to A)\to(D\to A))$$

## Intuitionistic and intermediate logics {#Intuitionistic_and_intermediate_logics}

[Intuitionistic logic](wikipedia://en/169262) is a subsystem of classical logic. It is commonly formulated with $\{\to,\land,\lor,\bot\}$ as the set of (functionally complete) basic connectives. It is not syntactically complete since it lacks [excluded middle](https://en.wikipedia.org/wiki/Excluded_middle) A∨¬A or [Peirce's law](wikipedia://en/47261948) ((A→B)→A)→A which can be added without making the logic inconsistent. It has modus ponens as inference rule, and the following axioms:

$$A\to(B\to A)$$

$$(A\to(B\to C))\to((A\to B)\to(A\to C))$$

$$(A\land B)\to A$$

$$(A\land B)\to B$$

$$A\to(B\to(A\land B))$$

$$A\to(A\lor B)$$

$$B\to(A\lor B)$$

$$(A\to C)\to((B\to C)\to((A\lor B)\to C))$$

$$\bot\to A$$

Alternatively, intuitionistic logic may be axiomatized using $\{\to,\land,\lor,\neg\}$ as the set of basic connectives, replacing the last axiom with

$$(A\to\neg A)\to\neg A$$

$$\neg A\to(A\to B)$$

[Intermediate logics](https://en.wikipedia.org/wiki/Intermediate_logics) are in between intuitionistic logic and classical logic. Here are a few intermediate logics:

- Jankov logic (KC) is an extension of intuitionistic logic, which can be axiomatized by the intuitionistic axiom system plus the axiom[^o23]

$$\neg A\lor\neg\neg A.$$

- Gödel–Dummett logic (LC) can be axiomatized over intuitionistic logic by adding the axiom[^o23]

$$(A\to B)\lor(B\to A).$$

## Positive implicational calculus {#Positive_implicational_calculus}

The positive implicational calculus is the implicational fragment of intuitionistic logic. The calculi below use modus ponens as an inference rule.

Łukasiewicz's axiom system:

$$A\to(B\to A)$$

$$(A\to(B\to C))\to((A\to B)\to(A\to C))$$

Meredith's axiom systems:

- First:

$$E\to((A\to B)\to(((D\to A)\to(B\to C))\to(A\to C)))$$

- Second:

$$A\to(B\to A)$$

$$(A\to B)\to((A\to(B\to C))\to(A\to C))$$

- Third:

$((A\to B)\to C)\to(D\to((B\to(C\to E))\to(B\to E)))$[^o25]

Hilbert's axiom systems:

- First:

$$(A\to(A\to B))\to(A\to B)$$

$$(B\to C)\to((A\to B)\to(A\to C))$$

$$(A\to(B\to C))\to(B\to(A\to C))$$

$$A\to(B\to A)$$

- Second:

$$(A\to(A\to B))\to(A\to B)$$

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$A\to(B\to A)$$

- Third:

$$A\to A$$

$$(A\to B)\to((B\to C)\to(A\to C))$$

$$(B\to C)\to((A\to B)\to(A\to C))$$

$$(A\to(A\to B))\to(A\to B)$$

## Positive propositional calculus {#Positive_propositional_calculus}

Positive propositional calculus is the fragment of intuitionistic logic using only the (non functionally complete) connectives $\{\to,\land,\lor\}$. It can be axiomatized by any of the above-mentioned calculi for positive implicational calculus together with the axioms

$$(A\land B)\to A$$

$$(A\land B)\to B$$

$$A\to(B\to(A\land B))$$

$$A\to(A\lor B)$$

$$B\to(A\lor B)$$

$$(A\to C)\to((B\to C)\to((A\lor B)\to C))$$

Optionally, we may also include the connective $\leftrightarrow$ and the axioms

$$(A\leftrightarrow B)\to(A\to B)$$

$$(A\leftrightarrow B)\to(B\to A)$$

$$(A\to B)\to((B\to A)\to(A\leftrightarrow B))$$

[Johansson](wikipedia://en/26269027)'s [minimal logic](wikipedia://en/26267678) can be axiomatized by any of the axiom systems for positive propositional calculus and expanding its language with the nullary connective $\bot$, with no additional axiom schemas. Alternatively, it can also be axiomatized in the language $\{\to,\land,\lor,\neg\}$ by expanding the positive propositional calculus with the axiom

$$(A\to\neg B)\to(B\to\neg A)$$

or the pair of axioms

$$(A\to B)\to(\neg B\to\neg A)$$

$$A\to\neg\neg A$$

Intuitionistic logic in language with negation can be axiomatized over the positive calculus by the pair of axioms

$$(A\to\neg B)\to(B\to\neg A)$$

$$\neg A\to(A\to B)$$

or the pair of axioms[^o28]

$$(A\to\neg A)\to\neg A$$

$$\neg A\to(A\to B)$$

Classical logic in the language $\{\to,\land,\lor,\neg\}$ can be obtained from the positive propositional calculus by adding the axiom

$$(\neg A\to\neg B)\to(B\to A)$$

or the pair of axioms

$$(A\to\neg B)\to(B\to\neg A)$$

$$\neg\neg A\to A$$

Fitch calculus takes any of the axiom systems for positive propositional calculus and adds the axioms[^o28]

$$\neg A\to(A\to B)$$

$$A\leftrightarrow\neg\neg A$$

$$\neg(A\lor B)\leftrightarrow(\neg A\land\neg B)$$

$$\neg(A\land B)\leftrightarrow(\neg A\lor\neg B)$$

Note that the first and third axioms are also valid in intuitionistic logic.

:::

## Equivalential calculus {#Equivalential_calculus}

Equivalential calculus is the subsystem of classical propositional calculus that only allows the (functionally incomplete) [equivalence](https://en.wikipedia.org/wiki/Biconditional) connective, denoted here as $\equiv$. The rule of inference used in these systems is as follows:

$$\frac{A,A\equiv B}{B}.$$

Iséki's axiom system:[^o31]

$$((A\equiv C)\equiv(B\equiv A))\equiv(C\equiv B)$$

$$(A\equiv(B\equiv C))\equiv((A\equiv B)\equiv C)$$

Iséki–Arai axiom system:[^o32]

$$A\equiv A$$

$$(A\equiv B)\equiv(B\equiv A)$$

$$(A\equiv B)\equiv((B\equiv C)\equiv(A\equiv C))$$

Arai's axiom systems;

- First:

$$(A\equiv(B\equiv C))\equiv((A\equiv B)\equiv C)$$

$$((A\equiv C)\equiv(B\equiv A))\equiv(C\equiv B)$$

- Second:

$$(A\equiv B)\equiv(B\equiv A)$$

$$((A\equiv C)\equiv(B\equiv A))\equiv(C\equiv B)$$

Łukasiewicz's axiom systems:[^o33]

- First:

$$(A\equiv B)\equiv((C\equiv B)\equiv(A\equiv C))$$

- Second:

$$(A\equiv B)\equiv((A\equiv C)\equiv(C\equiv B))$$

- Third:

$$(A\equiv B)\equiv((C\equiv A)\equiv(B\equiv C))$$

Meredith's axiom systems:[^o33]

- First:

$$((A\equiv B)\equiv C)\equiv(B\equiv(C\equiv A))$$

- Second:

$$A\equiv((B\equiv(A\equiv C))\equiv(C\equiv B))$$

- Third:

$$(A\equiv(B\equiv C))\equiv(C\equiv(A\equiv B))$$

- Fourth:

$$(A\equiv B)\equiv(C\equiv((B\equiv C)\equiv A))$$

- Fifth:

$$(A\equiv B)\equiv(C\equiv((C\equiv B)\equiv A))$$

- Sixth:

$$((A\equiv(B\equiv C))\equiv C)\equiv(B\equiv A)$$

- Seventh:

$$((A\equiv(B\equiv C))\equiv B)\equiv(C\equiv A)$$

[Kalman](https://en.wikipedia.org/wiki/John_Arnold_Kalman)'s axiom system:[^o33]

$$A\equiv((B\equiv(C\equiv A))\equiv(C\equiv B))$$

[Winker](https://en.wikipedia.org/wiki/S._Winker)'s axiom systems:[^o33]

- First:

$$A\equiv((B\equiv C)\equiv((A\equiv C)\equiv B))$$

- Second:

$$A\equiv((B\equiv C)\equiv((C\equiv A)\equiv B))$$

XCB axiom system:[^o33]

$$A\equiv(((A\equiv B)\equiv(C\equiv B))\equiv C)$$
