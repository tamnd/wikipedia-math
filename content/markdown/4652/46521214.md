# Supertransitive class

::: {#o1 .subject cue=lead name="Supertransitive class"}

In [set theory](wikipedia://en/27553), a **supertransitive class** is a [transitive class](wikipedia://en/2462396)[^o2] which includes as a subset the [power set](wikipedia://en/23799) of each of its [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29).

:::

Formally, let *A* be a transitive class. Then *A* is supertransitive if and only if

$(\forall x)(x\in A \to \mathcal{P}(x) \subseteq A).$[^o3]

Here *P*(*x*) denotes the power set of *x*.[^o4]

## References {#References}

[^o2]: Any element of a transitive set must also be its subset. See Definition 7.1 of Zaring W.M., G. Takeuti. (1971). "Introduction to axiomatic set theory". Springer-Verlag. isbn:0387900241
[^o3]: See Definition 9.8 of Zaring W.M., G. Takeuti. (1971). "Introduction to axiomatic set theory". Springer-Verlag. isbn:0387900241
[^o4]: *P*(*x*) must be a set by [axiom of power set](wikipedia://en/52552), since each element *x* of a class *A* must be a set (Theorem 4.6 in Takeuti's text above).
