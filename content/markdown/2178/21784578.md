# Cluster-weighted modeling

::: {#o1 .subject cue=lead name="Cluster-weighted modeling"}

In [data mining](wikipedia://en/42253), **cluster-weighted modeling (CWM)** is an algorithm-based approach to non-linear prediction of outputs ([dependent variables](wikipedia://en/437701)) from inputs ([independent variables](wikipedia://en/437701)) based on [density estimation](wikipedia://en/554671) using a set of models (clusters) that are each notionally appropriate in a sub-region of the input space. The overall approach works in jointly input-output space and an initial version was proposed by [Neil Gershenfeld](https://en.wikipedia.org/wiki/Neil_Gershenfeld).[^o2][^o3]

:::

## Basic form of model {#Basic_form_of_model}

The procedure for cluster-weighted modeling of an input-output problem can be outlined as follows.[^o3] In order to construct predicted values for an output variable *y* from an input variable *x*, the modeling and calibration procedure arrives at a [joint probability density function](wikipedia://en/879637), *p*(*y*,*x*). Here the "variables" might be uni-variate, multivariate or time-series. For convenience, any model parameters are not indicated in the notation here and several different treatments of these are possible, including setting them to fixed values as a step in the calibration or treating them using a [Bayesian analysis](https://en.wikipedia.org/wiki/Bayesian_analysis). The required predicted values are obtained by constructing the [conditional probability density](wikipedia://en/504458) *p*(*y*|*x*) from which the prediction using the [conditional expected value](https://en.wikipedia.org/wiki/Conditional_expected_value) can be obtained, with the [conditional variance](wikipedia://en/11391180) providing an indication of uncertainty.

The important step of the modeling is that *p*(*y*|*x*) is assumed to take the following form, as a [mixture model](wikipedia://en/871681):

$$p(y,x)=\sum_{j=1}^n w_jp_j(y,x),$$

where *n* is the number of clusters and {*w<sub>j</sub>*} are weights that sum to one. The functions *p<sub>j</sub>*(*y*,*x*) are joint probability density functions that relate to each of the *n* clusters. These functions are modeled using a decomposition into a conditional and a [marginal density](wikipedia://en/506077):

$$p_j(y,x)=p_j(y|x)p_j(x),$$

where:

- *p<sub>j</sub>*(*y*|*x*) is a model for predicting *y* given *x*, and given that the input-output pair should be associated with cluster *j* on the basis of the value of *x*. This model might be a [regression model](wikipedia://en/826997) in the simplest cases.
- *p<sub>j</sub>*(*x*) is formally a density for values of *x*, given that the input-output pair should be associated with cluster *j*. The relative sizes of these functions between the clusters determines whether a particular value of *x* is associated with any given cluster-center. This density might be a [Gaussian function](wikipedia://en/245552) centered at a parameter representing the cluster-center.

In the same way as for [regression analysis](wikipedia://en/826997), it will be important to consider preliminary [data transformations](https://en.wikipedia.org/wiki/Data_transformation) as part of the overall modeling strategy if the core components of the model are to be simple regression models for the cluster-wise condition densities, and [normal distributions](wikipedia://en/21462) for the cluster-weighting densities *p<sub>j</sub>*(*x*).

## General versions {#General_versions}

The basic CWM algorithm gives a single output cluster for each input cluster. However, CWM can be extended to multiple clusters which are still associated with the same input cluster.[^o6] Each cluster in CWM is localized to a Gaussian input region, and this contains its own trainable local model.[^o7] It is recognized as a versatile inference algorithm which provides simplicity, generality, and flexibility; even when a feedforward layered network might be preferred, it is sometimes used as a "second opinion" on the nature of the training problem.[^o8]

The original form proposed by Gershenfeld describes two innovations:

- Enabling CWM to work with continuous streams of data
- Addressing the problem of local minima encountered by the CWM parameter adjustment process[^o8]

CWM can be used to classify media in printer applications, using at least two parameters to generate an output that has a joint dependency on the input parameters.[^o9]
