# Lag windowing

::: {#o1 .subject cue=lead name="Lag windowing"}

**Lag windowing** is a technique that consists of [windowing](wikipedia://en/244097) the [autocorrelation](wikipedia://en/2724) coefficients prior to estimating [linear prediction](wikipedia://en/18572) coefficients (LPC). The windowing in the autocorrelation domain has the same effect as a convolution (smoothing) in the [power spectral domain](https://en.wikipedia.org/wiki/Power_spectrum) and helps in stabilizing the result of the [Levinson-Durbin](https://en.wikipedia.org/wiki/Levinson-Durbin) algorithm. The window function is typically a [Gaussian function](wikipedia://en/245552).

:::
