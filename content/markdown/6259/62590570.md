# Claw finding problem

::: {#o1 .subject cue=lead name="Claw finding problem"}

The **claw finding problem** is a classical problem in [complexity theory](wikipedia://en/7543), with several applications in [cryptography](wikipedia://en/18934432). In short, given two functions *f*, *g*, viewed as [oracles](wikipedia://en/451286), the problem is to find *x* and *y* such as *f*(*x*) = *g*(*y*). The pair (*x*, *y*) is then called a *claw*. Some problems, especially in cryptography, are best solved when viewed as a claw finding problem, hence any algorithmic improvement to solving the claw finding problem provides a better attack on cryptographic primitives such as [hash functions](https://en.wikipedia.org/wiki/Hash_function).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $A, B, C$ be finite sets, and $f: A \to C$, $g: B \to C$ two functions. A pair $(x,y) \in A \times B$ is called a *claw* if $f(x) = g(y)$. The claw finding problem is defined as to find such a claw, given that one exists.

If we view $f, g$ as random functions, we expect a claw to exist iff $|A| \cdot |B| \geq |C|$. More accurately, there are exactly $|A| \cdot |B|$ pairs of the form $(x,y)$ with $x \in A, y \in B$; the probability that such a pair is a claw is $1/|C|$. So if $|A| \cdot |B| \geq |C|$, the [expected number](https://en.wikipedia.org/wiki/Expected_number) of claws is at least 1.

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

If classical computers are used, the best algorithm is similar to a [Meet-in-the-middle attack](wikipedia://en/423418), first described by [Diffie](wikipedia://en/427776) and [Hellman](wikipedia://en/422387).[^o6] The algorithm works as follows: assume $|A| \leq |B|$. For every $x \in A$, save the pair $(f(x),x)$ in a [hash table](wikipedia://en/13833) indexed by $f(x)$. Then, for every $y \in B$, look up the table at $g(y)$. If such an index exists, we found a claw. This approach takes time $O(|A| + |B|)$ and memory $O(|A|)$.

If [quantum computers](https://en.wikipedia.org/wiki/Quantum_computer) are used, Seiichiro Tani showed that a claw can be found in complexity

$\sqrt[3]{|A|\cdot|B|}$ if $|A|\le|B|<|A|^2$ and

$\sqrt{|B|}$ if $|B|\ge|A|^2$.[^o7]

Shengyu Zhang showed that asymptotically these algorithms are the most efficient possible.[^o8]

:::

::: {#o10 .application cue=heading name="Applications"}

## Applications {#Applications}

As noted, most applications of the claw finding problem appear in [cryptography](wikipedia://en/18934432). Examples include:

- [Collision](wikipedia://en/969624) finding on cryptographic [hash functions](https://en.wikipedia.org/wiki/Hash_function).
- [Meet-in-the-middle attacks](wikipedia://en/423418): using this technique, *k* bits of round keys can be found in time roughly 2<sup>k/2+1</sup>. Here *f* is encrypting halfway through and *g* is decrypting halfway through. This is why [Triple DES](wikipedia://en/48375) applies [DES](wikipedia://en/7978) three times and not just two.

:::
