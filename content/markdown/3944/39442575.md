# SecureDrop

::: {#o2 .subject cue=lead name="SecureDrop"}

**SecureDrop** is a [free software](https://en.wikipedia.org/wiki/Free_software) platform for [secure communication](https://en.wikipedia.org/wiki/Secure_communication) between [journalists](https://en.wikipedia.org/wiki/Journalist) and [sources](https://en.wikipedia.org/wiki/Source_%28journalism%29) ([whistleblowers](https://en.wikipedia.org/wiki/Whistleblower)).[^o3] It was originally designed and developed by [Aaron Swartz](https://en.wikipedia.org/wiki/Aaron_Swartz) and [Kevin Poulsen](https://en.wikipedia.org/wiki/Kevin_Poulsen) under the name *[DeadDrop](https://en.wikipedia.org/wiki/Dead_drop)*.[^o4][^o5] [James Dolan](https://en.wikipedia.org/wiki/James_Dolan_%28computer_security_expert%29) also co-created the software.[^o6]

:::

## History {#History}

After Aaron Swartz's death, the first instance of the platform was launched under the name *Strongbox* by staff at *[The New Yorker](https://en.wikipedia.org/wiki/The_New_Yorker)* on 15 May 2013.[^o8] The [Freedom of the Press Foundation](https://en.wikipedia.org/wiki/Freedom_of_the_Press_Foundation) took over development of DeadDrop under the name *SecureDrop*, and has since assisted with its installation at several news organizations, including [ProPublica](https://en.wikipedia.org/wiki/ProPublica), *[The Guardian](https://en.wikipedia.org/wiki/The_Guardian)*, *[The Intercept](https://en.wikipedia.org/wiki/The_Intercept)*, and *[The Washington Post](https://en.wikipedia.org/wiki/The_Washington_Post)*.[^o9][^o10][^o11]

## Security {#Security}

SecureDrop uses the anonymity network [Tor](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29) to facilitate communication between [whistleblowers](https://en.wikipedia.org/wiki/Whistleblowers), journalists, and news organizations. SecureDrop sites are therefore only accessible as [onion services](https://en.wikipedia.org/wiki/Tor_%28anonymity_network%29#Onion_services) in the Tor network. After a user visits a SecureDrop website, they are given a randomly generated code name.[^o8] This code name is used to send information to a particular author or editor via uploading. [Investigative journalists](https://en.wikipedia.org/wiki/Investigative_journalist) can contact the whistleblower via SecureDrop messaging. Therefore, the whistleblower must take note of their random code name.[^o4]

The system utilizes private, segregated [servers](https://en.wikipedia.org/wiki/Server_%28computing%29) that are in the possession of the news organization. Journalists use two [USB flash drives](https://en.wikipedia.org/wiki/USB_flash_drive) and two personal computers to access SecureDrop data.[^o4][^o8] The first personal computer accesses SecureDrop via the Tor network, and the journalist uses the first flash drive to download [encrypted](https://en.wikipedia.org/wiki/Encrypted) data from the SecureDrop server. The second personal computer does not connect to the Internet, and is wiped during each reboot.[^o4][^o8] The second flash drive contains a [decryption](https://en.wikipedia.org/wiki/Decryption) code. The first and second flash drives are inserted into the second personal computer, and the material becomes available to the journalist. The personal computer is shut down after each use.[^o4]

Freedom of the Press Foundation has stated it will have the SecureDrop code and security environment audited by an independent third party before every major version release and then publish the results.[^o13] The first audit was conducted by security researchers at the [University of Washington](https://en.wikipedia.org/wiki/University_of_Washington) and [Bruce Schneier](wikipedia://en/36732).[^o14] The second audit was conducted by [Cure53](https://en.wikipedia.org/wiki/Cure53), a German security firm.[^o13]

SecureDrop suggests sources disabling [JavaScript](https://en.wikipedia.org/wiki/JavaScript) to protect anonymity.[^o15]
