# Trusted Data Format

::: {#o1 .subject cue=lead name="Trusted Data Format"}

The **Trusted Data Format** (**TDF**) is a data object encoding specification for the purposes of enabling data tagging and cryptographic security features.[^o3] These features include [assertion](https://en.wikipedia.org/wiki/Logical_assertion) of data properties or tags, [cryptographic binding](wikipedia://en/627040) and [data encryption](wikipedia://en/10294). The TDF is freely available with no restrictions and requires no use of proprietary or patented technology and is thus open for anyone to use.

:::

## Overview {#Overview}

The TDF Specification is based on a **Trusted Data Object** (**TDO**) which can be grouped together into a **Trusted Data Collection** (**TDC**).[^o5] Each TDO consists of a data payload which can be associated with an unlimited number of metadata objects. The TDO supports the cryptographic binding of the metadata objects to the payload data object.[^o5] In addition, both data and metadata objects can be associated with a block of encryption information which is used by any TDF consumer to decrypt the associated data or metadata if it had been encrypted.[^o5] A TDC allows for additional metadata objects to apply to a set of TDOs.

::: {#o7 .definition kind=definition/construction cue=heading name="Implementations"}

## Implementations {#Implementations}

The [United States Intelligence Community](https://en.wikipedia.org/wiki/United_States_Intelligence_Community) maintains the IC-TDF, which includes government-specific tagging requirements on top of the core TDF capabilities mentioned above, in an XML Data Encoding Specification.

The [United States Department of Defense](https://en.wikipedia.org/wiki/United_States_Department_of_Defense) uses TDF to implement the [Department of Defense Discovery Metadata Specification](https://en.wikipedia.org/wiki/Department_of_Defense_Discovery_Metadata_Specification) (DDMS).

:::
