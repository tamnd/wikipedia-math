# Slowly varying function

::: {#o1 .subject cue=lead name="Slowly varying function"}

In [real analysis](wikipedia://en/26478), a branch of [mathematics](wikipedia://en/18831), a **slowly varying function** is a [function of a real variable](wikipedia://en/1268958) whose behaviour at [infinity](wikipedia://en/20110824#Real_analysis) is in some sense similar to the behaviour of a function converging at infinity. Similarly, a **regularly varying function** is a function of a real variable whose behaviour at infinity is similar to the behaviour of a [power law](wikipedia://en/24522) function (like a [polynomial](wikipedia://en/23000)) near infinity. These classes of functions were both introduced by [Jovan Karamata](wikipedia://en/3130497),[^o2][^o3] and have found several important applications, for example in [probability theory](wikipedia://en/23542) and [extreme value theory](wikipedia://en/50732).

:::

## Basic definitions {#Basic_definitions}

(Definition 1). A [measurable function](wikipedia://en/44055) $L : (0, +\infty) \to (0, +\infty)$ is called *slowly varying* (at infinity) if for all $a > 0$,

$$\lim_{x \to \infty} \frac{L(ax)}{L(x)}=1.$$

(Definition 2). Let $L : (0, +\infty) \to (0, +\infty)$. Then $L$ is a regularly varying function if and only if $\forall a > 0, g_L(a) = \lim_{x \to \infty} \frac{L(ax)}{L(x)} \in \mathbb{R}^{+}$. In particular, the [limit](wikipedia://en/285759) must be finite.

These definitions are due to [Jovan Karamata](wikipedia://en/3130497).[^o2][^o3]

::: {#o6 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

Regularly varying functions have some important properties:[^o2] a partial list of them is reported below. More extensive analyses of the properties characterizing regular variation are presented in the monograph by (Bingham Goldie Teugels 1987).

### Uniformity of the limiting behaviour {#Uniformity_of_the_limiting_behaviour}

(Theorem 1). The limit in (definitions 1) and (2) is [uniform](wikipedia://en/50652) if $a$ is restricted to a compact [interval](wikipedia://en/49172).

::: {#o10 .statement kind=statement/theorem cue=named-heading name="Karamata's characterization theorem"}

### Karamata's characterization theorem {#Karamata's_characterization_theorem}

(Theorem 2). Every regularly varying function $f : (0, +\infty) \to (0, +\infty)$ is of the form

$$f(x)=x^\beta L(x)$$

where

- $\beta$ is a [real number](wikipedia://en/20646438),
- $L$ is a slowly varying function.

**Note**. This implies that the function $g(a)$ in (definition 2) has necessarily to be of the following form

$$g(a)=a^\rho$$

where the real number $\rho$ is called the *index of regular variation*.

:::

::: {#o12 .statement kind=statement/theorem cue=named-heading name="Karamata representation theorem"}

### Karamata representation theorem {#Karamata_representation_theorem}

(Theorem 3). A function $L$ is slowly varying if and only if there exists $B > 0$ such that for all $x \ge B$ the function can be written in the form

$$L(x) = \exp \left( \eta(x) + \int_B^x \frac{\varepsilon(t)}{t} \,dt \right)$$

where

- $\eta(x)$ is a [bounded](wikipedia://en/311509) [measurable function](wikipedia://en/44055) of a real variable converging to a finite number as $x$ goes to infinity
- $\varepsilon(x)$ is a bounded measurable function of a real variable converging to zero as $x$ goes to infinity.

:::

:::

::: {#o14 .example cue=heading name="Examples"}

## Examples {#Examples}

- If $L$ is a measurable function and has a limit

$$\lim_{x \to \infty} L(x) = b \in (0,\infty),$$

then $L$ is a slowly varying function.

- For any $\beta \in \mathbf{R}$, the function $L(x) = \log^{\beta}x$ is slowly varying.
- The function $L(x) = x$ is not slowly varying, nor is $L(x) = x^{\beta}$ for any real $\beta \ne 0$. However, these functions are regularly varying.

:::
