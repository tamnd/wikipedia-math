# List of unsolved problems in computer science

::: {#o1 .subject cue=lead name="List of unsolved problems in computer science"}

This article is a [list of notable unsolved problems](https://en.wikipedia.org/wiki/Lists_of_unsolved_problems) in [computer science](https://en.wikipedia.org/wiki/Computer_science). A problem in computer science is considered unsolved when no solution is known or when experts in the field disagree about proposed solutions.

:::

## Computational complexity {#Computational_complexity}

::: {#o3 .entry cue=list-entry name="P versus NP problem"}

- [P versus NP problem](wikipedia://en/6115) – The P vs NP problem is a major unsolved question in computer science that asks whether every problem whose solution can be quickly verified by a computer (NP) can also be quickly solved by a computer (P). This question has profound implications for fields such as cryptography, algorithm design, and computational theory.[^o4]

## Polynomial versus nondeterministic-polynomial time for specific algorithmic problems {#Polynomial_versus_nondeterministic-polynomial_time_for_specific_algorithmic_problems}

::: {#o21 .entry cue=list-entry name="shortest vector"}

- Can the [shortest vector](wikipedia://en/18661117#Shortest_vector_problem_%28SVP%29) of a lattice be computed in polynomial time on a classical or quantum computer?

:::

::: {#o22 .entry cue=list-entry name="Graph isomorphism problem"}

- Can the [graph isomorphism problem](wikipedia://en/1950766) be solved in polynomial time on a classical computer?

:::

The graph isomorphism problem involves determining whether two finite graphs are isomorphic, meaning there is a one-to-one correspondence between their vertices and edges that preserves adjacency. While the problem is known to be in NP, it is not known whether it is NP-complete or solvable in polynomial time. This uncertainty places it in a unique complexity class, making it a significant open problem in computer science.[^o23]

::: {#o24 .entry cue=list-entry name="Graph canonization"}

## Other algorithmic problems {#Other_algorithmic_problems}

::: {#o38 .entry cue=list-entry name="dynamic optimality conjecture"}

- The [dynamic optimality conjecture](https://en.wikipedia.org/wiki/Splay_tree#Dynamic_optimality_conjecture): Do splay trees have a bounded competitive ratio?

:::

::: {#o39 .entry cue=list-entry name="depth-first search tree"}

- Can a [depth-first search tree](wikipedia://en/30247317) be constructed in [NC](wikipedia://en/22073)?

:::

::: {#o40 .entry cue=list-entry name="Fast Fourier transform"}

- Can the [fast Fourier transform](wikipedia://en/11512) be computed in $o(n \log n)$ time?

:::

::: {#o41 .entry cue=list-entry name="algorithm for multiplication"}

- What is the fastest [algorithm for multiplication](https://en.wikipedia.org/wiki/Multiplication_algorithms#Computational_complexity_of_multiplication) of two *n*-digit numbers?

:::

::: {#o42 .entry cue=list-entry name="Shellsort"}

- What is the lowest possible average-case time complexity of [Shellsort](https://en.wikipedia.org/wiki/Shellsort) with a deterministic fixed gap sequence?

:::

::: {#o43 .entry cue=list-entry name="3SUM"}

- Can [3SUM](wikipedia://en/506330) be solved in strongly sub-quadratic time, that is, in time $O(n^{2-\epsilon})$ for some $\epsilon > 0$?

:::

::: {#o44 .entry cue=list-entry name="Edit distance"}

- Can the [edit distance](wikipedia://en/406427) between two strings of length $n$ be computed in strongly sub-quadratic time? (This is only possible if the strong [exponential time hypothesis](wikipedia://en/26434552) is false.)

:::

::: {#o45 .entry cue=list-entry name="X + Y sorting"}

- Can [X + Y sorting](wikipedia://en/43934137) be done in $o(n^{2} \log n)$ time?

:::

::: {#o46 .entry cue=list-entry name="fastest algorithm for matrix multiplication"}

- What is the [fastest algorithm for matrix multiplication](wikipedia://en/24107400)?

:::

::: {#o47 .entry cue=list-entry name="all-pairs shortest paths"}

- Can [all-pairs shortest paths](wikipedia://en/41985#All-pairs_shortest_paths) be computed in strongly sub-cubic time, that is, in time $O(V^{3-\epsilon})$ for some $\epsilon > 0$?

:::

::: {#o48 .entry cue=list-entry name="Schwartz–Zippel lemma"}

- Can the [Schwartz–Zippel lemma](wikipedia://en/2789076) for [polynomial identity testing](https://en.wikipedia.org/wiki/Polynomial_identity_testing) be [derandomized](wikipedia://en/495383#Derandomization)?

:::

::: {#o49 .entry cue=list-entry name="linear programming"}

- Does [linear programming](wikipedia://en/43730#Open_problems_and_recent_work) admit a [strongly-polynomial time](https://en.wikipedia.org/wiki/Strongly-polynomial_time) algorithm? (This is problem #9 in [Smale's list](wikipedia://en/8294746) of problems.)

:::

::: {#o50 .entry cue=list-entry name="Envy-free cake-cutting"}

- How many queries are required for [envy-free cake-cutting](https://en.wikipedia.org/wiki/Envy-free_cake-cutting)?

:::

::: {#o51 .entry cue=list-entry name="Minimum spanning tree problem"}

- What is the algorithmic complexity of the [minimum spanning tree problem](https://en.wikipedia.org/wiki/Minimum_spanning_tree_problem)? Equivalently, what is the [decision tree](wikipedia://en/41795#Decision_trees) complexity of the MST problem? The optimal algorithm to compute MSTs is [known](wikipedia://en/41795#Optimal_algorithm), but it relies on decision trees, so its complexity is unknown.

:::

::: {#o52 .entry cue=list-entry name="Gilbert–Pollak conjecture"}

- [Gilbert–Pollak conjecture](wikipedia://en/72307852): Is the [Steiner ratio](https://en.wikipedia.org/wiki/Steiner_ratio) of the [Euclidean plane](wikipedia://en/15575410) equal to $2/\sqrt{3}$?

:::

## Other problems {#Other_problems}

::: {#o56 .entry cue=list-entry name="multiplicative-exponential linear logic"}

::: {#o58 .entry cue=list-entry name="Černý conjecture"}

- [Černý conjecture](wikipedia://en/13667880#Length): If a [deterministic finite automaton](wikipedia://en/653404) with $n$ states has a [synchronizing word](wikipedia://en/13667880), must it have one of length at most $(n - 1)^2$?

:::

::: {#o59 .entry cue=list-entry name="Generalized star-height problem"}

- [Generalized star-height problem](wikipedia://en/669942): Can all [regular languages](wikipedia://en/25723) be expressed using generalized regular expressions with a limited nesting depth of [Kleene stars](wikipedia://en/16750)?

:::

::: {#o60 .entry cue=list-entry name="Separating words problem"}

- [Separating words problem](wikipedia://en/48936369): How many states are needed in a [deterministic finite automaton](wikipedia://en/653404) that behaves differently on two given [strings](wikipedia://en/27701) of length $n$?

:::

::: {#o61 .entry cue=list-entry name="Turing completeness"}

- What is the [Turing completeness](wikipedia://en/30621) status of all unique [elementary cellular automata](wikipedia://en/22928014)?

:::

::: {#o62 .entry cue=list-entry name="Variable-length code"}

- Determine whether the length of the minimal uncompletable word of $M$ is polynomial in $l(M)$, or even in $sl(M)$. It is known that $M$ is a [variable-length code](https://en.wikipedia.org/wiki/Variable-length_code) if for all $u_1,...,u_n,v_1,...,v_m \in M$, $u_1...u_n = v_1...v_m$ implies $n = m$ and $u_i = v_i$ for all $0 < i \leq n$. In such cases, we do not yet know if a polynomial bound exists. This is a possible weakening of the Restivo conjecture (already disproven in general, though upper bounds remain unknown).

:::

- Determine all positive integers $n$ such that the concatenation of $n$ and $n^2$ in base $b$ uses at most $k$ distinct characters, for fixed $b$ and $k$.
