# Vertical line test

::: {#o1 .subject cue=lead name="Vertical line test"}

*Image: Graphs of the vertical line test.svg.* The vertical line test, shown graphically. The [abscissa](https://en.wikipedia.org/wiki/Abscissa) shows the [domain of the (to be tested) function](wikipedia://en/50263).

In mathematics, the **vertical line test** is a visual way to determine if a [curve](https://en.wikipedia.org/wiki/Curve_%28mathematics%29) is a [graph of a function](wikipedia://en/87352) or not. A [function](wikipedia://en/185427) can only have one output, *y*, for each unique input, *x*. If a vertical line intersects a curve on an *xy*-plane more than once then for one value of *x* the curve has more than one value of *y*, and so, the curve does not represent a function. If all vertical lines intersect a curve at most once then the curve represents a function.[^o2]

:::

By failing the vertical line test, a curve that does not represent a function may be described more broadly as a [multivalued function](wikipedia://en/222367), where its multiple values are each the intersections with the vertical line. An example is the equation $y^2 = x$, which gives $y = \pm\sqrt{x}$ when solved for $y$. Here, the $\pm$ symbol yields two distinct output values, failing the vertical line test on the domain right of the Y-axis.
