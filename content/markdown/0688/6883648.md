# Ostrowski

::: {#o1 .subject cue=lead name="Ostrowski"}

**Ostrowski** (; feminine: **Ostrowska**) is a [Polish surname](https://en.wikipedia.org/wiki/Polish_surname). It is a [toponymic surname](https://en.wikipedia.org/wiki/Toponymic_surname) derived from any of places named [Ostrów](https://en.wikipedia.org/wiki/Ostrów_%28disambiguation%29), [Ostrowo](https://en.wikipedia.org/wiki/Ostrowo_%28disambiguation%29), [Ostrowsko](https://en.wikipedia.org/wiki/Ostrowsko_%28disambiguation%29)[^o2][^o3][^o4] It is related to several surnames in other languages.

:::
