# General elephant

::: {#o1 .subject cue=lead name="General elephant"}

In [algebraic geometry](wikipedia://en/1997), ***general elephant*** is an idiosyncratic name for a general element of the anticanonical system of a variety, introduced by [Miles Reid](wikipedia://en/5863755).[^o2] For 3-folds the **general elephant problem** (or conjecture) asks whether general elephants have at most [du Val singularities](https://en.wikipedia.org/wiki/Du_Val_singularities); this has been proved in several cases.[^o3][^o4]

:::
