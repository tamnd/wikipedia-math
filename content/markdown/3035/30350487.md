# Auslander algebra

::: {#o1 .subject cue=lead name="Auslander algebra"}

In [mathematics](wikipedia://en/18831), the **Auslander algebra** of an [algebra](wikipedia://en/2112) *A* is the [endomorphism ring](wikipedia://en/59623) of the sum of the [indecomposable modules](wikipedia://en/810549) of *A*. It was introduced by (txt).

:::

An [Artin algebra](wikipedia://en/29353834) Γ is called an **Auslander algebra** if [gl dim](https://en.wikipedia.org/wiki/Gl_dim) Γ ≤ 2 and if 0 → Γ → *I* → *J* → *K* → 0 is a minimal [injective resolution](https://en.wikipedia.org/wiki/Injective_resolution) of Γ then *I* and *J* are [projective](wikipedia://en/364488) Γ-modules.
