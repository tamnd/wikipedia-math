# Genetic map function

::: {#o1 .subject cue=lead name="Genetic map function"}

In [genetics](https://en.wikipedia.org/wiki/Genetics), **mapping functions** are used to model the relationship between [map](https://en.wikipedia.org/wiki/Gene_mapping) distances (measured in map units or [centimorgans](https://en.wikipedia.org/wiki/Centimorgan)) and [recombination](https://en.wikipedia.org/wiki/Genetic_recombination) frequencies, particularly as these measurements relate to regions encompassed between [genetic markers](https://en.wikipedia.org/wiki/Genetic_marker). One utility of this approach is that it allows one to obtain values for distances in genetic mapping units directly from recombination fractions, as map distances cannot typically be obtained from empirical experiments.[^o2]

:::

The simplest mapping function is the **Morgan Mapping Function**, eponymously devised by [Thomas Hunt Morgan](https://en.wikipedia.org/wiki/Thomas_Hunt_Morgan). Other well-known mapping functions include the **Haldane Mapping Function** introduced by [J. B. S. Haldane](https://en.wikipedia.org/wiki/J._B._S._Haldane) in 1919,[^o3] and the **Kosambi Mapping Function** introduced by [Damodar Dharmananda Kosambi](https://en.wikipedia.org/wiki/Damodar_Dharmananda_Kosambi) in 1944.[^o4][^o5] Few mapping functions are used in practice other than Haldane and Kosambi.[^o11] The main difference between them is in how [crossover interference](https://en.wikipedia.org/wiki/Crossover_interference) is incorporated.[^o6]

## Morgan Mapping Function {#Morgan_Mapping_Function}

Where *d* is the distance in map units, the Morgan Mapping Function states that the recombination frequency *r* can be expressed as $\ r=d$ . This assumes that one crossover occurs, at most, in an interval between two loci, and that the probability of the occurrence of this crossover is proportional to the map length of the interval.

Where *d* is the distance in map units, the recombination frequency *r* can be expressed as:

$$\ r = \frac{1}{2} [1-(1-2d)] = d$$

The equation only holds when $\frac{1}{2} \geq d \geq 0$ as, otherwise, recombination frequency would exceed 50%. Therefore, the function cannot approximate recombination frequencies beyond short distances.[^o5]

## Haldane Mapping Function {#Haldane_Mapping_Function}

### Overview {#Overview}

Two properties of the Haldane Mapping Function is that it limits recombination frequency up to, but not beyond 50%, and that it represents a linear relationship between the frequency of recombination and map distance up to recombination frequencies of 10%.[^o10] It also assumes that crossovers occur at random positions and that they do so independent of one another. This assumption therefore also assumes no [crossover interference](https://en.wikipedia.org/wiki/Crossover_interference) takes place;[^o11] but using this assumption allows Haldane to model the mapping function using a [Poisson distribution](wikipedia://en/23009144).[^o5]

::: {#o13 .definition cue=heading name="Definitions"}

### Definitions {#Definitions}

- *r* = recombination frequency
- *d* = mean number of crossovers on a chromosomal interval
- *2d* = mean number of crossovers for a tetrad
- *e<sup>\-2d</sup>* = probability of no genetic exchange in a chromosomal interval

:::

::: {#o15 .statement cue=named-heading name="Formula"}

### Formula {#Formula}

$$\ r = \frac{1}{2} (1-e^{-2d})$$

:::

### Inverse {#Inverse}

$$\ d = -\frac{1}{2} \ln (1-2r)$$

## Kosambi Mapping Function {#Kosambi_Mapping_Function}

### Overview {#Overview}

The Kosambi mapping function was introduced to account for the impact played by [crossover interference](https://en.wikipedia.org/wiki/Crossover_interference) on recombination frequency. It introduces a parameter C, representing the [coefficient of coincidence](https://en.wikipedia.org/wiki/Coefficient_of_coincidence), and sets it equal to 2r. For loci which are strongly [linked](wikipedia://en/681230), interference is strong; otherwise, interference decreases towards zero.[^o11] Interference declines according to the linear function i = 1 - 2r.[^o19]

::: {#o21 .statement cue=named-heading name="Formula"}

### Formula {#Formula}

$$\ r = \frac{1}{2}\tanh(2d) = \frac{1}{2}\frac{e^{4d}-1}{e^{4d}+1}$$

:::

### Inverse {#Inverse}

$$\ d = \frac{1}{2} \tanh^{-1} (2r) = \frac{1}{4}\ln(\frac{1+2r}{1-2r})$$

## Comparison and application {#Comparison_and_application}

Below 10% recombination frequency, there is little mathematical difference between different mapping functions and the relationship between map distance and recombination frequency is linear (that is, 1 map unit = 1% recombination frequency).[^o19] When genome-wide SNP sampling and mapping data is present, the difference between the functions is negligible outside of regions of high recombination, such as recombination hotspots or ends of chromosomes.[^o6]

While many mapping functions now exist,[^o24][^o25][^o26] in practice functions other than Haldane and Kosambi are rarely used.[^o11] More specifically, the Haldane function is preferred when distance between markers is relatively small, whereas the Kosambi function is preferred when distances between markers is larger and crossovers need to be accounted for.[^o27]
