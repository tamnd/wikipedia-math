# Glossary of general topology

::: {#o1 .subject cue=lead name="Glossary of general topology"}

This is a glossary of some terms used in the branch of [mathematics](wikipedia://en/18831) known as [topology](wikipedia://en/29954). Although there is no absolute distinction between different areas of topology, the focus here is on [general topology](wikipedia://en/178649). The following definitions are also fundamental to [algebraic topology](wikipedia://en/38801), [differential topology](wikipedia://en/8562) and [geometric topology](wikipedia://en/621732). For a list of terms specific to algebraic topology, see [Glossary of algebraic topology](wikipedia://en/48781047).

:::

All spaces in this glossary are assumed to be [topological spaces](wikipedia://en/30450) unless stated otherwise.

## A {#A}

::: {#o3 .entry cue=glossary-term name="Absolutely closed"}

**Absolutely closed**

See *H-closed*

:::

::: {#o4 .entry cue=glossary-term name="Accessible"}

**Accessible**

See **[$T_1$](wikipedia://en/148721)**.

:::

::: {#o5 .entry cue=glossary-term name="Accumulation point"}

**Accumulation point**

See [limit point](https://en.wikipedia.org/wiki/Limit_point).

:::

::: {#o6 .entry cue=glossary-term name="Alexandroff compactification"}

**[Alexandroff compactification](https://en.wikipedia.org/wiki/Alexandroff_compactification)**

:::

::: {#o7 .entry cue=glossary-term name="Alexandrov topology"}

**[Alexandrov topology](wikipedia://en/542198)**

The topology of a space *X* is an [Alexandrov topology](wikipedia://en/542198) (or is **finitely generated**) if arbitrary intersections of open sets in *X* are open, or equivalently, if arbitrary unions of closed sets are closed, or, again equivalently, if the open sets are the [upper sets](https://en.wikipedia.org/wiki/Upper_set) of a [poset](https://en.wikipedia.org/wiki/Poset).[^o8]

:::

::: {#o9 .entry cue=glossary-term name="Almost discrete"}

**Almost discrete**

A space is almost discrete if every open set is closed (hence clopen). The almost discrete spaces are precisely the finitely generated zero-dimensional spaces.

:::

::: {#o10 .entry cue=glossary-term name="α-closed, α-open"}

**α-closed, α-open**

A subset *A* of a topological space *X* is α-open if $A \subseteq \operatorname{Int}_X \left( \operatorname{Cl}_X \left( \operatorname{Int}_X A \right) \right)$, and the complement of such a set is α-closed.[^n1]

:::

::: {#o12 .entry cue=glossary-term name="Approach space"}

**[Approach space](https://en.wikipedia.org/wiki/Approach_space)**

An [approach space](https://en.wikipedia.org/wiki/Approach_space) is a generalization of metric space based on point-to-set distances, instead of point-to-point.

:::

## B {#B}

::: {#o14 .entry cue=glossary-term name="Baire space"}

**Baire space**

This has two distinct common meanings:

1. A space is a **Baire space** if the intersection of any [countable](https://en.wikipedia.org/wiki/Countable) collection of dense open sets is dense; see [Baire space](wikipedia://en/200550).
1. **Baire space** is the set of all functions from the natural numbers to the natural numbers, with the topology of pointwise convergence; see [Baire space (set theory)](wikipedia://en/2078245).

:::

::: {#o15 .entry cue=glossary-term name="Base"}

**[Base](wikipedia://en/59220)**

A collection *B* of open sets is a [base](wikipedia://en/59220) (or **basis**) for a topology $\tau$ if every open set in $\tau$ is a union of sets in $B$. The topology $\tau$ is the smallest topology on $X$ containing $B$ and is said to be generated by $B$.

:::

::: {#o16 .entry cue=glossary-term name="Basis"}

**[Basis](https://en.wikipedia.org/wiki/Basis_%28topology%29)**

See **[Base](wikipedia://en/59220)**.

:::

::: {#o17 .entry cue=glossary-term name="β-open"}

**β-open**

See *Semi-preopen*.

:::

::: {#o18 .entry cue=glossary-term name="b-open, b-closed"}

**b-open, b-closed**

A subset $A$ of a topological space $X$ is b-open if $A \subseteq \operatorname{Int}_X \left( \operatorname{Cl}_X A \right) \cup \operatorname{Cl}_X \left( \operatorname{Int}_X A \right)$. The complement of a b-open set is b-closed.[^n1]

:::

::: {#o20 .entry cue=glossary-term name="Borel algebra"}

**[Borel algebra](https://en.wikipedia.org/wiki/Borel_algebra)**

The [Borel algebra](https://en.wikipedia.org/wiki/Borel_algebra) on a topological space $(X,\tau)$ is the smallest [$\sigma$-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) containing all the open sets. It is obtained by taking intersection of all $\sigma$-algebras on $X$ containing $\tau$.

:::

::: {#o21 .entry cue=glossary-term name="Borel set"}

**Borel set**

A Borel set is an element of a Borel algebra.

:::

::: {#o22 .entry cue=glossary-term name="Boundary"}

**[Boundary](wikipedia://en/72824)**

The [boundary](wikipedia://en/72824) (or **frontier**) of a set is the set's closure minus its interior. Equivalently, the boundary of a set is the intersection of its closure with the closure of its complement. Boundary of a set $A$ is denoted by $\partial A$ or $bd$ $A$.

:::

::: {#o23 .entry cue=glossary-term name="Bounded"}

**[Bounded](wikipedia://en/48258)**

A set in a metric space is [bounded](wikipedia://en/48258) if it has [finite](wikipedia://en/11742) diameter. Equivalently, a set is bounded if it is contained in some open ball of finite radius. A [function](wikipedia://en/185427) taking values in a metric space is [bounded](wikipedia://en/311509) if its [image](https://en.wikipedia.org/wiki/Image_%28functions%29) is a bounded set.

:::

## C {#C}

::: {#o25 .entry cue=glossary-term name="Category of topological spaces"}

**[Category of topological spaces](wikipedia://en/435051)**

The [category](wikipedia://en/5869) **[Top](wikipedia://en/435051)** has [topological spaces](wikipedia://en/30450) as [objects](https://en.wikipedia.org/wiki/Object_%28category_theory%29) and [continuous maps](https://en.wikipedia.org/wiki/Continuous_map) as [morphisms](wikipedia://en/27716891).

:::

::: {#o26 .entry cue=glossary-term name="Cauchy sequence"}

**[Cauchy sequence](wikipedia://en/6085)**

A [sequence](wikipedia://en/27838) {*x*<sub>*n*</sub>} in a metric space (*M*, *d*) is a [Cauchy sequence](wikipedia://en/6085) if, for every [positive](https://en.wikipedia.org/wiki/Positive_number) [real number](wikipedia://en/20646438) *r*, there is an [integer](wikipedia://en/14563) *N* such that for all integers *m*, *n* > *N*, we have *d*(*x*<sub>*m*</sub>, *x*<sub>*n*</sub>) \< *r*.

:::

::: {#o27 .entry cue=glossary-term name="Clopen set"}

**[Clopen set](wikipedia://en/233398)**

A set is [clopen](wikipedia://en/233398) if it is both open and closed.

:::

::: {#o28 .entry cue=glossary-term name="Closed ball"}

**Closed ball**

If (*M*, *d*) is a [metric space](wikipedia://en/20018), a closed ball is a set of the form *D*(*x*; *r*) := {*y* in *M* : *d*(*x*, *y*) ≤ *r*}, where *x* is in *M* and *r* is a [positive](https://en.wikipedia.org/wiki/Positive_number) [real number](wikipedia://en/20646438), the **radius** of the ball. A closed ball of radius *r* is a **closed *r*-ball**. Every closed ball is a closed set in the topology induced on *M* by *d*. Note that the closed ball *D*(*x*; *r*) might not be equal to the [closure](wikipedia://en/42309) of the open ball *B*(*x*; *r*).

:::

::: {#o29 .entry cue=glossary-term name="Closed set"}

**[Closed set](wikipedia://en/47279)**

A set is [closed](wikipedia://en/47279) if its complement is a member of the topology.

:::

::: {#o30 .entry cue=glossary-term name="Closed function"}

**[Closed function](https://en.wikipedia.org/wiki/Closed_function)**

A function from one space to another is closed if the [image](wikipedia://en/579311) of every closed set is closed.

:::

::: {#o31 .entry cue=glossary-term name="Closure"}

**[Closure](wikipedia://en/42309)**

The [closure](wikipedia://en/42309) of a set is the smallest closed set containing the original set. It is equal to the intersection of all closed sets which contain it. An element of the closure of a set *S* is a **point of closure** of *S*.

:::

::: {#o32 .entry cue=glossary-term name="Closure operator"}

**Closure operator**

See **[Kuratowski closure axioms](wikipedia://en/331597)**.

:::

::: {#o33 .entry cue=glossary-term name="Coarser topology"}

**[Coarser topology](https://en.wikipedia.org/wiki/Coarser_topology)**

If *X* is a set, and if *T*<sub>1</sub> and *T*<sub>2</sub> are topologies on *X*, then *T*<sub>1</sub> is [coarser](https://en.wikipedia.org/wiki/Coarser_topology) (or **smaller**, **weaker**) than *T*<sub>2</sub> if *T*<sub>1</sub> is contained in *T*<sub>2</sub>. Beware, some authors, especially [analysts](wikipedia://en/48396), use the term **stronger**.

:::

::: {#o34 .entry cue=glossary-term name="Comeagre"}

**Comeagre**

A subset *A* of a space *X* is **comeagre** (**comeager**) if its [complement](wikipedia://en/54347) *X*\\*A* is [meagre](wikipedia://en/226975). Also called **residual**.

:::

::: {#o35 .entry cue=glossary-term name="Compact"}

**[Compact](wikipedia://en/6042)**

A space is [compact](wikipedia://en/6042) if every open cover has a [finite](wikipedia://en/11742) subcover. Every compact space is Lindelöf and paracompact. Therefore, every compact [Hausdorff space](wikipedia://en/13637) is normal. See also **quasicompact**.

:::

::: {#o36 .entry cue=glossary-term name="Compact-open topology"}

**[Compact-open topology](wikipedia://en/726335)**

The [compact-open topology](wikipedia://en/726335) on the set *C*(*X*, *Y*) of all continuous maps between two spaces *X* and *Y* is defined as follows: given a compact subset *K* of *X* and an open subset *U* of *Y*, let *V*(*K*, *U*) denote the set of all maps *f* in *C*(*X*, *Y*) such that *f*(*K*) is contained in *U*. Then the collection of all such *V*(*K*, *U*) is a subbase for the compact-open topology.

:::

::: {#o37 .entry cue=glossary-term name="Complete"}

**[Complete](https://en.wikipedia.org/wiki/Complete_space)**

A metric space is [complete](https://en.wikipedia.org/wiki/Complete_space) if every Cauchy sequence converges.

:::

::: {#o38 .entry cue=glossary-term name="Completely metrizable/completely metrisable"}

**Completely metrizable/completely metrisable**

See **[complete space](https://en.wikipedia.org/wiki/Complete_space)**.

:::

::: {#o39 .entry cue=glossary-term name="Completely normal"}

**Completely normal**

A space is completely normal if any two separated sets have [disjoint](wikipedia://en/39359) neighbourhoods.

:::

::: {#o40 .entry cue=glossary-term name="Completely normal Hausdorff"}

**Completely normal Hausdorff**

A completely normal Hausdorff space (or [**T<sub>5</sub>** space](https://en.wikipedia.org/wiki/T5_space)) is a completely normal T<sub>1</sub> space. (A completely normal space is Hausdorff [if and only if](wikipedia://en/14922) it is T<sub>1</sub>, so the terminology is [consistent](https://en.wikipedia.org/wiki/Consistent).) Every completely normal Hausdorff space is normal Hausdorff.

:::

::: {#o41 .entry cue=glossary-term name="Completely regular"}

**[Completely regular](https://en.wikipedia.org/wiki/Completely_regular_space)**

A space is [completely regular](https://en.wikipedia.org/wiki/Completely_regular_space) if, whenever *C* is a closed set and *x* is a point not in *C*, then *C* and {*x*} are functionally separated.

:::

::: {#o42 .entry cue=glossary-term name="Completely T3"}

**[Completely T<sub>3</sub>](https://en.wikipedia.org/wiki/Completely_T3_space)**

See **[Tychonoff](wikipedia://en/30554)**.

:::

::: {#o43 .entry cue=glossary-term name="Component"}

**Component**

See **[Connected component](wikipedia://en/6233)**/**Path-connected component**.

:::

::: {#o44 .entry cue=glossary-term name="Connected"}

**[Connected](https://en.wikipedia.org/wiki/Connected_%28topology%29)**

A space is [connected](https://en.wikipedia.org/wiki/Connected_%28topology%29) if it is not the union of a pair of [disjoint](wikipedia://en/39359) nonempty open sets. Equivalently, a space is connected if the only clopen sets are the whole space and the empty set.

:::

::: {#o45 .entry cue=glossary-term name="Connected component"}

**[Connected component](wikipedia://en/6233)**

A [connected component](wikipedia://en/6233) of a space is a maximal nonempty connected subspace. Each connected component is closed, and the set of connected components of a space is a [partition](wikipedia://en/340240) of that space.

:::

::: {#o46 .entry cue=glossary-term name="Continuous"}

**[Continuous](https://en.wikipedia.org/wiki/Continuity_%28topology%29)**

A function from one space to another is [continuous](https://en.wikipedia.org/wiki/Continuity_%28topology%29) if the [preimage](https://en.wikipedia.org/wiki/Preimage) of every open set is open.

:::

::: {#o47 .entry cue=glossary-term name="Continuum"}

**[Continuum](wikipedia://en/24758520)**

A space is called a continuum if it a compact, connected Hausdorff space.

:::

::: {#o48 .entry cue=glossary-term name="Contractible"}

**[Contractible](wikipedia://en/1752414)**

A space *X* is contractible if the [identity map](wikipedia://en/15069) on *X* is homotopic to a constant map. Every contractible space is simply connected.

:::

::: {#o49 .entry cue=glossary-term name="Coproduct topology"}

**[Coproduct topology](https://en.wikipedia.org/wiki/Coproduct_topology)**

If {*X*<sub>*i*</sub>} is a collection of spaces and *X* is the (set-theoretic) [disjoint union](wikipedia://en/188946) of {*X*<sub>*i*</sub>}, then the coproduct topology (or **disjoint union topology**, **topological sum** of the *X*<sub>*i*</sub>) on *X* is the finest topology for which all the injection maps are continuous.

:::

::: {#o50 .entry cue=glossary-term name="Core-compact space"}

**[Core-compact space](wikipedia://en/72645041)**

:::

::: {#o51 .entry cue=glossary-term name="Cosmic space"}

**[Cosmic space](wikipedia://en/19859862)**

A [continuous](wikipedia://en/6122) [image](wikipedia://en/579311) of some [separable](wikipedia://en/27855) [metric space](wikipedia://en/20018).[^o52]

:::

::: {#o53 .entry cue=glossary-term name="Countable chain condition"}

**[Countable chain condition](wikipedia://en/1550771)**

A space *X* satisfies the countable chain condition if every family of non-empty, pairswise disjoint open sets is countable.

:::

::: {#o54 .entry cue=glossary-term name="Countably compact"}

**[Countably compact](https://en.wikipedia.org/wiki/Countably_compact)**

A space is countably compact if every [countable](https://en.wikipedia.org/wiki/Countable) open cover has a [finite](wikipedia://en/11742) subcover. Every countably compact space is pseudocompact and weakly countably compact.

:::

::: {#o55 .entry cue=glossary-term name="Countably locally finite"}

**Countably locally finite**

A collection of subsets of a space *X* is **countably locally finite** (or **σ-locally finite**) if it is the union of a [countable](https://en.wikipedia.org/wiki/Countable) collection of locally finite collections of subsets of *X*.

:::

::: {#o56 .entry cue=glossary-term name="Cover"}

**[Cover](wikipedia://en/317552)**

A collection of subsets of a space is a cover (or **covering**) of that space if the union of the collection is the whole space.

:::

::: {#o57 .entry cue=glossary-term name="Covering"}

**Covering**

See **Cover**.

:::

::: {#o58 .entry cue=glossary-term name="Cut point"}

**Cut point**

If *X* is a connected space with more than one point, then a point *x* of *X* is a cut point if the subspace *X* − {*x*} is disconnected.

:::

## D {#D}

::: {#o60 .entry cue=glossary-term name="δ-cluster point, δ-closed, δ-open"}

**δ-cluster point, δ-closed, δ-open**

A point *x* of a topological space *X* is a δ-cluster point of a subset *A* if $A \cap \operatorname{Int}_X\left( \operatorname{Cl}_X(U) \right) \neq \emptyset$ for every open neighborhood *U* of *x* in *X*. The subset *A* is δ-closed if it is equal to the set of its δ-cluster points, and δ-open if its complement is δ-closed.[^n2]

:::

::: {#o62 .entry cue=glossary-term name="Dense set"}

**[Dense set](wikipedia://en/23523594)**

A set is dense if it has nonempty intersection with every nonempty open set. Equivalently, a set is dense if its closure is the whole space.

:::

::: {#o63 .entry cue=glossary-term name="Dense-in-itself set"}

**[Dense-in-itself](wikipedia://en/8327127) set**

A set is dense-in-itself if it has no [isolated point](wikipedia://en/390557).

:::

::: {#o64 .entry cue=glossary-term name="Density"}

**Density**

the minimal cardinality of a dense subset of a topological space. A set of density ℵ<sub>0</sub> is a [separable space](wikipedia://en/27855).[^o65]

:::

::: {#o66 .entry cue=glossary-term name="Derived set"}

**Derived set**

If *X* is a space and *S* is a subset of *X*, the derived set of *S* in *X* is the set of limit points of *S* in *X*.

:::

::: {#o67 .entry cue=glossary-term name="Developable space"}

**Developable space**

A topological space with a [development](wikipedia://en/8017307).[^o165]

:::

::: {#o68 .entry cue=glossary-term name="Development"}

**[Development](wikipedia://en/8017307)**

A [countable](wikipedia://en/6026) collection of [open covers](https://en.wikipedia.org/wiki/Open_cover) of a topological space, such that for any closed set *C* and any point *p* in its complement there exists a cover in the collection such that every neighbourhood of *p* in the cover is [disjoint](wikipedia://en/39359) from *C*.[^o165]

:::

::: {#o69 .entry cue=glossary-term name="Diameter"}

**Diameter**

If (*M*, *d*) is a metric space and *S* is a subset of *M*, the diameter of *S* is the [supremum](https://en.wikipedia.org/wiki/Supremum) of the distances *d*(*x*, *y*), where *x* and *y* range over *S*.

:::

::: {#o70 .entry cue=glossary-term name="Discrete metric"}

**Discrete metric**

The discrete metric on a set *X* is the function *d* : *X* × *X* → **[R](wikipedia://en/20646438)** such that for all *x*, *y* in *X*, *d*(*x*, *x*) = 0 and *d*(*x*, *y*) = 1 if *x* ≠ *y*. The discrete metric induces the discrete topology on *X*.

:::

::: {#o71 .entry cue=glossary-term name="Discrete space"}

**[Discrete space](wikipedia://en/56061)**

A space *X* is [discrete](wikipedia://en/56061) if every subset of *X* is open. We say that *X* carries the **discrete topology**.[^o72]

:::

::: {#o73 .entry cue=glossary-term name="Discrete topology"}

**[Discrete topology](https://en.wikipedia.org/wiki/Discrete_topology)**

See **[discrete space](wikipedia://en/56061)**.

:::

::: {#o74 .entry cue=glossary-term name="Disjoint union topology"}

**Disjoint union topology**

See **Coproduct topology**.

:::

::: {#o75 .entry cue=glossary-term name="Dispersion point"}

**[Dispersion point](wikipedia://en/7588072)**

If *X* is a connected space with more than one point, then a point *x* of *X* is a dispersion point if the subspace *X* − {*x*} is hereditarily disconnected (its only connected components are the one-point sets).

:::

::: {#o76 .entry cue=glossary-term name="Distance"}

**Distance**

See **[metric space](wikipedia://en/20018)**.

## E {#E}

::: {#o81 .entry cue=glossary-term name="Entourage"}

**[Entourage](https://en.wikipedia.org/wiki/Entourage_%28topology%29)**

See **[Uniform space](wikipedia://en/32339)**.

:::

::: {#o82 .entry cue=glossary-term name="Exterior"}

**Exterior**

The exterior of a set is the interior of its complement.

:::

::: {#o83 .entry cue=glossary-term name="Eilenberg–Wojdysławski theorem"}

**Eilenberg–Wojdysławski theorem**

The [Eilenberg–Wojdysławski theorem](https://en.wikipedia.org/wiki/Eilenberg–Wojdysławski_theorem) says every bounded metric space can be embedded into a Banach space as a closed subset of the convex hull of the image.

:::

## F {#F}

::: {#o85 .entry cue=glossary-term name="Fσ set"}

**[*F*<sub>σ</sub> set](https://en.wikipedia.org/wiki/F-sigma_set)**

An [*F*<sub>σ</sub> set](https://en.wikipedia.org/wiki/F-sigma_set) is a [countable](https://en.wikipedia.org/wiki/Countable) union of closed sets.[^o101]

:::

::: {#o86 .entry cue=glossary-term name="Filter"}

**[Filter](wikipedia://en/12646549)**

See also: [Filters in topology](wikipedia://en/47516955). A filter on a space *X* is a nonempty family *F* of subsets of *X* such that the following conditions hold:

1. The [empty set](wikipedia://en/9566) is not in *F*.
1. The intersection of any [finite](wikipedia://en/11742) number of elements of *F* is again in *F*.
1. If *A* is in *F* and if *B* contains *A*, then *B* is in *F*.

:::

::: {#o87 .entry cue=glossary-term name="Final topology"}

**[Final topology](wikipedia://en/1819736)**

On a set *X* with respect to a family of functions into $X$, is the [finest topology](https://en.wikipedia.org/wiki/Finest_topology) on *X* which makes those functions [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29).[^o88]

:::

::: {#o89 .entry cue=glossary-term name="Fine topology (potential theory)"}

**[Fine topology (potential theory)](wikipedia://en/5170051)**

On [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$, the coarsest topology making all [subharmonic functions](wikipedia://en/3237359) (equivalently all superharmonic functions) continuous.[^o90]

:::

::: {#o91 .entry cue=glossary-term name="Finer topology"}

**[Finer topology](https://en.wikipedia.org/wiki/Finer_topology)**

If *X* is a set, and if *T*<sub>1</sub> and *T*<sub>2</sub> are topologies on *X*, then *T*<sub>2</sub> is [finer](https://en.wikipedia.org/wiki/Finer_topology) (or **larger**, **stronger**) than *T*<sub>1</sub> if *T*<sub>2</sub> contains *T*<sub>1</sub>. Beware, some authors, especially [analysts](wikipedia://en/48396), use the term **weaker**.

:::

::: {#o92 .entry cue=glossary-term name="Finitely generated"}

**Finitely generated**

See **[Alexandrov topology](wikipedia://en/542198)**.

:::

::: {#o93 .entry cue=glossary-term name="First category"}

**[First category](https://en.wikipedia.org/wiki/First_category)**

See **[Meagre](wikipedia://en/226975)**.

:::

::: {#o94 .entry cue=glossary-term name="First-countable"}

**[First-countable](wikipedia://en/904940)**

A space is [first-countable](wikipedia://en/904940) if every point has a [countable](https://en.wikipedia.org/wiki/Countable) local base.

:::

::: {#o95 .entry cue=glossary-term name="Fréchet"}

**Fréchet**

See **[T<sub>1</sub>](wikipedia://en/148721)**.

:::

::: {#o96 .entry cue=glossary-term name="Frontier"}

**Frontier**

See **[Boundary](wikipedia://en/72824)**.

:::

::: {#o97 .entry cue=glossary-term name="Full set"}

**Full set**

A [compact](wikipedia://en/6042) subset *K* of the [complex plane](wikipedia://en/217628) is called **full** if its [complement](wikipedia://en/54347) is connected. For example, the [closed unit disk](https://en.wikipedia.org/wiki/Closed_unit_disk) is full, while the [unit circle](wikipedia://en/27072071) is not.

:::

::: {#o98 .entry cue=glossary-term name="Functionally separated"}

**Functionally separated**

Two sets *A* and *B* in a space *X* are functionally separated if there is a continuous map *f*: *X* → \[0, 1\] such that *f*(*A*) = 0 and *f*(*B*) = 1.

:::

## G {#G}

::: {#o100 .entry cue=glossary-term name="Gδ set"}

## H {#H}

::: {#o106 .entry cue=glossary-term name="Hausdorff"}

**[Hausdorff](wikipedia://en/13637)**

A [Hausdorff space](wikipedia://en/13637) (or **[T<sub>2</sub>](https://en.wikipedia.org/wiki/T2_space) space**) is one in which every two distinct points have [disjoint](wikipedia://en/39359) neighbourhoods. Every Hausdorff space is T<sub>1</sub>.

:::

::: {#o107 .entry cue=glossary-term name="H-closed"}

**[H-closed](wikipedia://en/34157704)**

A space is H-closed, or **Hausdorff closed** or **absolutely closed**, if it is closed in every Hausdorff space containing it.

:::

::: {#o108 .entry cue=glossary-term name="Hemicompact"}

**[Hemicompact](wikipedia://en/5076058)**

A space is hemicompact, if there is a sequence of compact subsets so that every compact subset is contained in one of them.

:::

::: {#o109 .entry cue=glossary-term name="Hereditarily P"}

**Hereditarily *P**

A space is hereditarily *P* for some property *P* if every subspace is also *P*.

:::

::: {#o110 .entry cue=glossary-term name="Hereditary"}

**[Hereditary](wikipedia://en/13552465)**

A property of spaces is said to be hereditary if whenever a space has that property, then so does every subspace of it.[^o111] For example, second-countability is a hereditary property.

:::

::: {#o112 .entry cue=glossary-term name="Homeomorphism"}

**[Homeomorphism](wikipedia://en/13660)**

If *X* and *Y* are spaces, a [homeomorphism](wikipedia://en/13660) from *X* to *Y* is a [bijective](wikipedia://en/3942) function *f* : *X* → *Y* such that *f* and *f*<sup>−1</sup> are continuous. The spaces *X* and *Y* are then said to be **homeomorphic**. From the standpoint of topology, homeomorphic spaces are identical.

:::

::: {#o113 .entry cue=glossary-term name="Homogeneous"}

**[Homogeneous](wikipedia://en/363325)**

A space *X* is [homogeneous](wikipedia://en/363325) if, for every *x* and *y* in *X*, there is a homeomorphism *f* : *X* → *X* such that *f*(*x*) = *y*. Intuitively, the space looks the same at every point. Every [topological group](wikipedia://en/42315) is homogeneous.

:::

::: {#o114 .entry cue=glossary-term name="Homotopic maps"}

**[Homotopic maps](https://en.wikipedia.org/wiki/Homotopic)**

Two continuous maps *f*, *g* : *X* → *Y* are [homotopic](https://en.wikipedia.org/wiki/Homotopic) (in *Y*) if there is a continuous map *H* : *X* × \[0, 1\] → *Y* such that *H*(*x*, 0) = *f*(*x*) and *H*(*x*, 1) = *g*(*x*) for all *x* in *X*. Here, *X* × \[0, 1\] is given the product topology. The function *H* is called a **homotopy** (in *Y*) between *f* and *g*.

:::

::: {#o115 .entry cue=glossary-term name="Homotopy"}

**Homotopy**

See **[Homotopic maps](https://en.wikipedia.org/wiki/Homotopic)**.

:::

::: {#o116 .entry cue=glossary-term name="Hyperconnected"}

**[Hyperconnected](wikipedia://en/7556651)**

A space is hyperconnected if no two non-empty open sets are disjoint[^o189] Every hyperconnected space is connected.[^o189]

Every isometry is [injective](wikipedia://en/45196), although not every isometry is [surjective](https://en.wikipedia.org/wiki/Surjection).

::: {#o131 .entry cue=glossary-term name="Kuratowski closure axioms"}

**[Kuratowski closure axioms](wikipedia://en/331597)**

The [Kuratowski closure axioms](wikipedia://en/331597) is a set of [axioms](wikipedia://en/928) satisfied by the function which takes each subset of *X* to its closure:

1. *[Isotonicity](https://en.wikipedia.org/wiki/Isotone_function)*: Every set is contained in its closure.
1. *[Idempotence](https://en.wikipedia.org/wiki/Idempotent_function)*: The closure of the closure of a set is equal to the closure of that set.
1. *Preservation of binary unions*: The closure of the union of two sets is the union of their closures.
1. *Preservation of nullary unions*: The closure of the empty set is empty.

If *c* is a function from the [power set](wikipedia://en/23799) of *X* to itself, then *c* is a **closure operator** if it satisfies the Kuratowski closure axioms. The Kuratowski closure axioms can then be used to define a topology on *X* by declaring the closed sets to be the [fixed points](wikipedia://en/449738) of this operator, i.e. a set *A* is closed [if and only if](wikipedia://en/14922) *c*(*A*) = *A*.

## M {#M}

**[Meagre](wikipedia://en/226975)**

If *X* is a space and *A* is a subset of *X*, then *A* is meagre in *X* (or of **first category** in *X*) if it is the [countable](https://en.wikipedia.org/wiki/Countable) union of nowhere dense sets. If *A* is not meagre in *X*, *A* is of **second category** in *X*.[^o156]

**[Metacompact](wikipedia://en/5074872)**

A space is metacompact if every open cover has a point finite open refinement.

**Metric**

::: {#o159 .entry cue=glossary-term name="Metric invariant"}

**Metric invariant**

A metric invariant is a property which is preserved under isometric isomorphism.

:::

::: {#o160 .entry cue=glossary-term name="Metric map"}

**[Metric map](wikipedia://en/469760)**

If *X* and *Y* are metric spaces with metrics *d*<sub>*X*</sub> and *d*<sub>*Y*</sub> respectively, then a [metric map](wikipedia://en/469760) is a function *f* from *X* to *Y*, such that for any points *x* and *y* in *X*, *d*<sub>*Y*</sub>(*f*(*x*), *f*(*y*)) ≤ *d*<sub>*X*</sub>(*x*, *y*). A metric map is [strictly metric](wikipedia://en/469760) if the above inequality is strict for all *x* and *y* in *X*.

:::

::: {#o161 .entry cue=glossary-term name="Metric space"}

**[Metric space](wikipedia://en/20018)**

A [metric space](wikipedia://en/20018) (*M*, *d*) is a set *M* equipped with a function *d* : *M* × *M* → **[R](wikipedia://en/20646438)** satisfying the following axioms for all *x*, *y*, and *z* in *M*:

1. *d*(*x*, *y*) ≥ 0
1. *d*(*x*, *x*) = 0
1. if *d*(*x*, *y*) = 0 then *x* = *y* (*identity of indiscernibles*)
1. *d*(*x*, *y*) = *d*(*y*, *x*) (*symmetry*)
1. *d*(*x*, *z*) ≤ *d*(*x*, *y*) + *d*(*y*, *z*) (*[triangle inequality](wikipedia://en/53941)*)

:::

The function *d* is a **metric** on *M*, and *d*(*x*, *y*) is the **distance** between *x* and *y*. The collection of all open balls of *M* is a base for a topology on *M*; this is the topology on *M* induced by *d*. Every metric space is Hausdorff and paracompact (and hence normal and Tychonoff). Every metric space is first-countable.

::: {#o162 .entry cue=glossary-term name="Metrizable/Metrisable"}

**[Metrizable](https://en.wikipedia.org/wiki/Metrizable)**/**Metrisable**

A space is [metrizable](https://en.wikipedia.org/wiki/Metrizable) if it is homeomorphic to a metric space. Every metrizable space is Hausdorff and paracompact (and hence normal and Tychonoff). Every metrizable space is first-countable.

:::

::: {#o163 .entry cue=glossary-term name="Monolith"}

**Monolith**

Every non-empty ultra-connected compact space *X* has a largest proper open subset; this subset is called a **monolith**.

:::

::: {#o164 .entry cue=glossary-term name="Moore space"}

**[Moore space](wikipedia://en/8016525)**

A [Moore space](wikipedia://en/8016525) is a [developable](https://en.wikipedia.org/wiki/Developable_space) [regular Hausdorff space](https://en.wikipedia.org/wiki/Regular_Hausdorff_space).[^o165]

## P {#P}

::: {#o184 .entry cue=glossary-term name="Paracompact"}

**[Paracompact](wikipedia://en/48631)**

A space is [paracompact](wikipedia://en/48631) if every open cover has a locally finite open refinement. Paracompact implies metacompact.[^o185] Paracompact Hausdorff spaces are normal.[^o186]

:::

::: {#o187 .entry cue=glossary-term name="Partition of unity"}

**[Partition of unity](wikipedia://en/48636)**

A partition of unity of a space *X* is a set of continuous functions from *X* to \[0, 1\] such that any point has a neighbourhood where all but a [finite](wikipedia://en/11742) number of the functions are identically zero, and the sum of all the functions on the entire space is identically 1.

:::

::: {#o188 .entry cue=glossary-term name="Path"}

**[Path](wikipedia://en/1189553)**

A [path](wikipedia://en/1189553) in a space *X* is a continuous map *f* from the closed unit [interval](wikipedia://en/49172) \[0, 1\] into *X*. The point *f*(0) is the initial point of *f*; the point *f*(1) is the terminal point of *f*.[^o189]

:::

::: {#o190 .entry cue=glossary-term name="Path-connected"}

**[Path-connected](https://en.wikipedia.org/wiki/Path-connected_space)**

A space *X* is [path-connected](https://en.wikipedia.org/wiki/Path-connected_space) if, for every two points *x*, *y* in *X*, there is a path *f* from *x* to *y*, i.e., a path with initial point *f*(0) = *x* and terminal point *f*(1) = *y*. Every path-connected space is connected.[^o189]

:::

::: {#o191 .entry cue=glossary-term name="Path-connected component"}

**Path-connected component**

A path-connected component of a space is a maximal nonempty path-connected subspace. The set of path-connected components of a space is a [partition](wikipedia://en/340240) of that space, which is [finer](wikipedia://en/340240) than the partition into connected components.[^o189] The set of path-connected components of a space *X* is denoted [π<sub>0</sub>(*X*)](https://en.wikipedia.org/wiki/Homotopy_groups).

**π-base**

A collection *B* of nonempty open sets is a π-base for a topology τ if every nonempty open set in τ includes a set from *B*.[^o195]

::: {#o196 .entry cue=glossary-term name="Point"}

**Point**

A point is an element of a topological space. More generally, a point is an element of any set with an underlying topological structure; e.g. an element of a metric space or a topological group is also a "point".

:::

::: {#o197 .entry cue=glossary-term name="Point of closure"}

**Point of closure**

See **[Closure](wikipedia://en/42309)**.

:::

::: {#o198 .entry cue=glossary-term name="Polish"}

**[Polish](wikipedia://en/396622)**

A space is Polish if it is separable and completely metrizable, i.e. if it is homeomorphic to a separable and complete metric space.

:::

::: {#o199 .entry cue=glossary-term name="Polyadic"}

**[Polyadic](wikipedia://en/45398062)**

A space is polyadic if it is the continuous image of the power of a [one-point compactification](https://en.wikipedia.org/wiki/One-point_compactification) of a locally compact, non-compact Hausdorff space.

:::

::: {#o200 .entry cue=glossary-term name="Polytopological space"}

**[Polytopological space](wikipedia://en/62153058)**

A polytopological space is a [set](wikipedia://en/26691) $X$ together with a [family](wikipedia://en/723043) $\{\tau_i\}_{i\in I}$ of [topologies](wikipedia://en/30450#Definition_via_open_sets) on $X$ that is [linearly ordered](wikipedia://en/30330) by the [inclusion relation](wikipedia://en/27631) where $I$ is an arbitrary [index set](wikipedia://en/393055).

:::

::: {#o201 .entry cue=glossary-term name="P-point"}

**P-point**

A point of a topological space is a P-point if its [filter of neighbourhoods](wikipedia://en/1714290) is closed under countable intersections.

:::

::: {#o202 .entry cue=glossary-term name="Pre-compact"}

**Pre-compact**

See **[Relatively compact](https://en.wikipedia.org/wiki/Relatively_compact)**.

:::

::: {#o203 .entry cue=glossary-term}

**Pre-open set**

A subset *A* of a topological space *X* is preopen if $A \subseteq \operatorname{Int}_X \left( \operatorname{Cl}_X A \right)$.[^n2]

:::

::: {#o205 .entry cue=glossary-term name="Prodiscrete topology"}

**Prodiscrete topology**

The prodiscrete topology on a product *A*<sup>*G*</sup> is the product topology when each factor *A* is given the discrete topology.[^o206]

:::

::: {#o207 .entry cue=glossary-term name="Product topology"}

**[Product topology](wikipedia://en/24910)**

If $\left(X_i\right)$ is a collection of spaces and *X* is the (set-theoretic) [Cartesian product](wikipedia://en/24104095) of $\left(X_i\right),$ then the [product topology](wikipedia://en/24910) on *X* is the coarsest topology for which all the projection maps are continuous.

:::

::: {#o208 .entry cue=glossary-term name="Proper function/mapping"}

**Proper function/mapping**

A continuous function *f* from a space *X* to a space *Y* is proper if $f^{-1}(C)$ is a compact set in *X* for any compact subspace *C* of *Y*.

:::

::: {#o209 .entry cue=glossary-term name="Proximity space"}

**[Proximity space](wikipedia://en/1536920)**

A proximity space (*X*, **d**) is a set *X* equipped with a [binary relation](wikipedia://en/3931) **d** between subsets of *X* satisfying the following properties:

:::

For all subsets *A*, *B* and *C* of *X*,

1. *A* **d** *B* implies *B* **d** *A*
1. *A* **d** *B* implies *A* is non-empty
1. If *A* and *B* have non-empty intersection, then *A* **d** *B*
1. *A* **d** (*B* $\cup$ *C*) [if and only if](wikipedia://en/14922) (*A* **d** *B* or *A* **d** *C*)
1. If, for all subsets *E* of *X*, we have (*A* **d** *E* or *B* **d** *E*), then we must have *A* **d** (*X* − *B*)

::: {#o210 .entry cue=glossary-term name="Pseudocompact"}

**[Pseudocompact](https://en.wikipedia.org/wiki/Pseudocompact)**

A space is pseudocompact if every [real-valued](wikipedia://en/20646438) continuous function on the space is bounded.

:::

::: {#o211 .entry cue=glossary-term name="Pseudometric"}

**Pseudometric**

See **Pseudometric space**.

:::

::: {#o212 .entry cue=glossary-term name="Pseudometric space"}

**[Pseudometric space](wikipedia://en/68503)**

A pseudometric space (*M*, *d*) is a set *M* equipped with a [real](wikipedia://en/20646438)-valued function $d : M \times M \to \mathbb{R}$ satisfying all the conditions of a metric space, except possibly the identity of indiscernibles. That is, points in a pseudometric space may be "infinitely close" without being identical. The function *d* is a **pseudometric** on *M*. Every metric is a pseudometric.

:::

::: {#o213 .entry cue=glossary-term name="Punctured neighbourhood/Punctured neighborhood"}

**Punctured neighbourhood**/**Punctured neighborhood**

A punctured neighbourhood of a point *x* is a neighbourhood of *x*, [minus](https://en.wikipedia.org/wiki/Set_subtraction) {*x*}. For instance, the [interval](wikipedia://en/49172) (−1, 1) = {*y* : −1 \< *y* \< 1} is a neighbourhood of *x* = 0 in the [real line](https://en.wikipedia.org/wiki/Real_line), so the set $(-1, 0) \cup (0, 1) = (-1, 1) - \{ 0 \}$ is a punctured neighbourhood of 0.

:::

## Q {#Q}

::: {#o215 .entry cue=glossary-term name="Quasicompact"}

**Quasicompact**

See **[compact](wikipedia://en/6042)**. Some authors define "compact" to include the [Hausdorff](wikipedia://en/13637) separation axiom, and they use the term **quasicompact** to mean what we call in this glossary simply "compact" (without the Hausdorff axiom). This convention is most commonly found in French, and branches of mathematics heavily influenced by the French.

:::

::: {#o216 .entry cue=glossary-term name="Quotient map"}

**[Quotient map](https://en.wikipedia.org/wiki/Quotient_map_%28topology%29)**

If *X* and *Y* are spaces, and if *f* is a [surjection](https://en.wikipedia.org/wiki/Surjection) from *X* to *Y*, then *f* is a quotient map (or **identification map**) if, for every subset *U* of *Y*, *U* is open in *Y* [if and only if](wikipedia://en/14922) *f*<sup>\-1</sup>(*U*) is open in *X*. In other words, *Y* has the *f*-strong topology. Equivalently, $f$ is a quotient map if and only if it is the transfinite composition of maps $X\rightarrow X/Z$, where $Z\subset X$ is a subset. Note that this does not imply that *f* is an open function.

:::

::: {#o217 .entry cue=glossary-term name="Quotient space"}

**[Quotient space](wikipedia://en/237213)**

If *X* is a space, *Y* is a set, and *f* : *X* → *Y* is any [surjective](https://en.wikipedia.org/wiki/Surjection) function, then the [Quotient topology](https://en.wikipedia.org/wiki/Quotient_topology) on *Y* induced by *f* is the finest topology for which *f* is continuous. The space *X* is a quotient space or **identification space**. By definition, *f* is a quotient map. The most common example of this is to consider an [equivalence relation](wikipedia://en/9259) on *X*, with *Y* the set of [equivalence classes](wikipedia://en/9260) and *f* the natural projection map. This construction is dual to the construction of the subspace topology.

:::

## R {#R}

::: {#o219 .entry cue=glossary-term name="Refinement"}

**Refinement**

A cover *K* is a [refinement](https://en.wikipedia.org/wiki/Refinement_%28topology%29) of a cover *L* if every member of *K* is a subset of some member of *L*.

:::

::: {#o220 .entry cue=glossary-term name="Regular"}

**[Regular](wikipedia://en/53058)**

A space is [regular](wikipedia://en/53058) if, whenever *C* is a closed set and *x* is a point not in *C*, then *C* and *x* have [disjoint](wikipedia://en/39359) neighbourhoods.

:::

::: {#o221 .entry cue=glossary-term name="Regular Hausdorff"}

**[Regular Hausdorff](https://en.wikipedia.org/wiki/T3_space)**

A space is [regular Hausdorff](https://en.wikipedia.org/wiki/T3_space) (or **T<sub>3</sub>**) if it is a regular T<sub>0</sub> space. (A regular space is Hausdorff [if and only if](wikipedia://en/14922) it is T<sub>0</sub>, so the terminology is consistent.)

:::

::: {#o222 .entry cue=glossary-term}

**[Regular open](wikipedia://en/47306)**

A subset of a space *X* is regular open if it equals the interior of its closure; dually, a regular closed set is equal to the closure of its interior.[^o223] An example of a non-regular open set is the set *U* = 0,1 ∪ 1,2 in **R** with its normal topology, since 1 is in the interior of the closure of *U*, but not in *U*. The regular open subsets of a space form a [complete Boolean algebra](wikipedia://en/1839944).[^o223]

:::

::: {#o224 .entry cue=glossary-term name="Relatively compact"}

**[Relatively compact](https://en.wikipedia.org/wiki/Relatively_compact)**

A subset *Y* of a space *X* is [relatively compact](https://en.wikipedia.org/wiki/Relatively_compact) in *X* if the closure of *Y* in *X* is compact.

:::

::: {#o225 .entry cue=glossary-term name="Residual"}

**Residual**

If *X* is a space and *A* is a subset of *X*, then *A* is residual in *X* if the complement of *A* is meagre in *X*. Also called **comeagre** or **comeager**.

:::

::: {#o226 .entry cue=glossary-term name="Resolvable"}

**Resolvable**

A [topological space](wikipedia://en/30450) is called [resolvable](wikipedia://en/5705219) if it is expressible as the union of two [disjoint](wikipedia://en/39359) [dense subsets](https://en.wikipedia.org/wiki/Dense_subset).

:::

::: {#o227 .entry cue=glossary-term name="Rim-compact"}

**Rim-compact**

A space is rim-compact if it has a base of open sets whose boundaries are compact.

:::

## S {#S}

::: {#o229 .entry cue=glossary-term name="S-space"}

**S-space**

An *S-space* is a [hereditarily](wikipedia://en/13552465#In_topology) [separable space](wikipedia://en/27855) which is not hereditarily [Lindelöf](wikipedia://en/310480).[^o135]

:::

::: {#o230 .entry cue=glossary-term name="Scattered"}

**[Scattered](wikipedia://en/40260318)**

A space *X* is [scattered](wikipedia://en/40260318) if every nonempty subset *A* of *X* contains a point isolated in *A*.

:::

::: {#o231 .entry cue=glossary-term name="Scott"}

**[Scott](wikipedia://en/743106)**

The [Scott topology](https://en.wikipedia.org/wiki/Scott_topology) on a [poset](https://en.wikipedia.org/wiki/Poset) is that in which the open sets are those [Upper sets](https://en.wikipedia.org/wiki/Upper_set) inaccessible by directed joins.[^o232]

:::

::: {#o233 .entry cue=glossary-term name="Second category"}

**Second category**

See **Meagre**.

:::

::: {#o234 .entry cue=glossary-term name="Second-countable"}

**[Second-countable](wikipedia://en/901459)**

A space is [second-countable](wikipedia://en/901459) or **perfectly separable** if it has a [countable](https://en.wikipedia.org/wiki/Countable) base for its topology.[^o101] Every second-countable space is first-countable, separable, and Lindelöf.

:::

::: {#o235 .entry cue=glossary-term name="Semilocally simply connected"}

**[Semilocally simply connected](https://en.wikipedia.org/wiki/Semilocally_simply_connected)**

A space *X* is [semilocally simply connected](https://en.wikipedia.org/wiki/Semilocally_simply_connected) if, for every point *x* in *X*, there is a neighbourhood *U* of *x* such that every loop at *x* in *U* is homotopic in *X* to the constant loop *x*. Every simply connected space and every locally simply connected space is semilocally simply connected. (Compare with locally simply connected; here, the homotopy is allowed to live in *X*, whereas in the definition of locally simply connected, the homotopy must live in *U*.)

:::

::: {#o236 .entry cue=glossary-term name="Semi-open"}

**Semi-open**

A subset *A* of a topological space *X* is called semi-open if $A \subseteq \operatorname{Cl}_X \left( \operatorname{Int}_X A \right)$.[^n3]

:::

::: {#o238 .entry cue=glossary-term name="Semi-preopen"}

**Semi-preopen**

A subset *A* of a topological space *X* is called semi-preopen if $A \subseteq \operatorname{Cl}_X \left( \operatorname{Int}_X \left( \operatorname{Cl}_X A \right) \right)$[^n1]

:::

::: {#o240 .entry cue=glossary-term name="Semiregular"}

**[Semiregular](wikipedia://en/1885104)**

A space is semiregular if the regular open sets form a base.

:::

::: {#o241 .entry cue=glossary-term name="Separable"}

**[Separable](https://en.wikipedia.org/wiki/Separable_%28topology%29)**

A space is [separable](https://en.wikipedia.org/wiki/Separable_%28topology%29) if it has a [countable](https://en.wikipedia.org/wiki/Countable) dense subset.[^o101][^o156]

:::

::: {#o242 .entry cue=glossary-term name="Separated"}

**[Separated](wikipedia://en/148911)**

Two sets *A* and *B* are [separated](wikipedia://en/148911) if each is [disjoint](wikipedia://en/39359) from the other's closure.

:::

::: {#o243 .entry cue=glossary-term name="Sequentially compact"}

**[Sequentially compact](https://en.wikipedia.org/wiki/Sequentially_compact)**

A space is sequentially compact if every [sequence](wikipedia://en/27838) has a convergent subsequence. Every sequentially compact space is countably compact, and every first-countable, countably compact space is sequentially compact.

:::

**[Short map](https://en.wikipedia.org/wiki/Short_map)**

See **[metric map](wikipedia://en/469760)**

**[Sierpiński space](wikipedia://en/387651)**

:::

::: {#o246 .entry cue=glossary-term name="Simply connected"}

**[Simply connected](wikipedia://en/523879)**

A space is [simply connected](wikipedia://en/523879) if it is path-connected and every loop is homotopic to a constant map.

:::

::: {#o247 .entry cue=glossary-term name="Smaller topology"}

**Smaller topology**

See **[Coarser topology](https://en.wikipedia.org/wiki/Coarser_topology)**.

:::

::: {#o248 .entry cue=glossary-term name="Sober"}

**[Sober](wikipedia://en/602490)**

In a [sober space](wikipedia://en/602490), every [irreducible](wikipedia://en/7556651) closed subset is the [closure](wikipedia://en/42309) of exactly one point: that is, has a unique [generic point](wikipedia://en/3043978).[^o249]

:::

::: {#o250 .entry cue=glossary-term name="Star"}

**Star**

The star of a point in a given [cover](wikipedia://en/317552) of a [topological space](wikipedia://en/30450) is the union of all the sets in the cover that contain the point. See **[star refinement](wikipedia://en/982000)**.

:::

::: {#o251 .entry cue=glossary-term name="f-Strong topology"}

**$f$-Strong topology**

Let $f\colon X\rightarrow Y$ be a map of topological spaces. We say that $Y$ has the $f$-strong topology if, for every subset $U\subset Y$, one has that $U$ is open in $Y$ if and only if $f^{-1}(U)$ is open in $X$

:::

::: {#o252 .entry cue=glossary-term name="Stronger topology"}

**Stronger topology**

See **[Finer topology](https://en.wikipedia.org/wiki/Finer_topology)**. Beware, some authors, especially [analysts](wikipedia://en/48396), use the term **weaker topology**.

:::

::: {#o253 .entry cue=glossary-term name="Subbase"}

**[Subbase](wikipedia://en/395395)**

A collection of open sets is a [subbase](wikipedia://en/395395) (or **subbasis**) for a topology if every non-empty proper open set in the topology is the union of a [finite](wikipedia://en/11742) intersection of sets in the subbase. If $\mathcal B$ is *any* collection of subsets of a set *X*, the topology on *X* generated by $\mathcal B$ is the smallest topology containing $\mathcal B;$ this topology consists of the empty set, *X* and all unions of finite intersections of elements of $\mathcal B.$ Thus $\mathcal B$ is a subbase for the topology it generates.

:::

::: {#o254 .entry cue=glossary-term name="Subbasis"}

**[Subbasis](wikipedia://en/395395)**

See **[Subbase](wikipedia://en/395395)**.

:::

::: {#o255 .entry cue=glossary-term name="Subcover"}

**Subcover**

A cover *K* is a subcover (or **subcovering**) of a cover *L* if every member of *K* is a member of *L*.

:::

::: {#o256 .entry cue=glossary-term name="Subcovering"}

**Subcovering**

See **Subcover**.

:::

::: {#o257 .entry cue=glossary-term name="Submaximal space"}

**[Submaximal space](https://en.wikipedia.org/wiki/Submaximal_space)**

A [topological space](wikipedia://en/30450) is said to be submaximal if every subset of it is locally closed, that is, every subset is the intersection of an [open set](wikipedia://en/39358) and a [closed set](wikipedia://en/47279).

:::

Here are some facts about submaximality as a property of topological spaces:

- Every [door space](wikipedia://en/5075606) is submaximal.
- Every submaximal space is *weakly submaximal* viz every finite set is locally closed.
- Every submaximal space is [irresolvable](https://en.wikipedia.org/wiki/Irresolvable_space).[^o258]

::: {#o259 .entry cue=glossary-term name="Subspace"}

**Subspace**

If *T* is a topology on a space *X*, and if *A* is a subset of *X*, then the [subspace topology](wikipedia://en/910926) on *A* induced by *T* consists of all intersections of open sets in *T* with *A*. This construction is dual to the construction of the quotient topology.

## T {#T}

::: {#o262 .entry cue=glossary-term name="T0"}

**[T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space)**

A space is [T<sub>0</sub>](https://en.wikipedia.org/wiki/T0_space) (or **Kolmogorov**) if for every pair of distinct points *x* and *y* in the space, either there is an open set containing *x* but not *y*, or there is an open set containing *y* but not *x*.

:::

::: {#o263 .entry cue=glossary-term name="T1"}

**[T<sub>1</sub>](wikipedia://en/148721)**

A space is [T<sub>1</sub>](wikipedia://en/148721) (or **Fréchet** or **accessible**) if for every pair of distinct points *x* and *y* in the space, there is an open set containing *x* but not *y*. (Compare with T<sub>0</sub>; here, we are allowed to specify which point will be contained in the open set.) Equivalently, a space is T<sub>1</sub> if all its [singletons](wikipedia://en/381798) are closed. Every T<sub>1</sub> space is T<sub>0</sub>.

::: {#o270 .entry cue=glossary-term name="θ-cluster point, θ-closed, θ-open"}

**θ-cluster point, θ-closed, θ-open**

A point *x* of a topological space *X* is a θ-cluster point of a subset *A* if $A \cap \operatorname{Cl}_X(U) \neq \emptyset$ for every open neighborhood *U* of *x* in *X*. The subset *A* is θ-closed if it is equal to the set of its θ-cluster points, and θ-open if its complement is θ-closed.[^n3]

::: {#o272 .entry cue=glossary-term name="Topological invariant"}

**[Topological invariant](https://en.wikipedia.org/wiki/Topological_invariant)**

A topological invariant is a property which is preserved under homeomorphism. For example, compactness and connectedness are topological properties, whereas boundedness and completeness are not. [Algebraic topology](wikipedia://en/38801) is the study of topologically invariant [abstract algebra](wikipedia://en/19616384) constructions on topological spaces.

:::

::: {#o273 .entry cue=glossary-term name="Topological space"}

**[Topological space](wikipedia://en/30450)**

A [topological space](wikipedia://en/30450) (*X*, *T*) is a set *X* equipped with a collection *T* of subsets of *X* satisfying the following [axioms](wikipedia://en/928):

:::

1. The empty set and *X* are in *T*.
1. The union of any collection of sets in *T* is also in *T*.
1. The intersection of any pair of sets in *T* is also in *T*.

The collection *T* is a **topology** on *X*.

**Topologically complete**

[Completely metrizable spaces](wikipedia://en/7975189) (i. e. topological spaces homeomorphic to complete metric spaces) are often called *topologically complete*; sometimes the term is also used for [Čech-complete spaces](https://en.wikipedia.org/wiki/Čech-complete_space) or [completely uniformizable spaces](wikipedia://en/27351720).

**Topology**

::: {#o277 .entry cue=glossary-term name="Totally bounded"}

**Totally bounded**

A metric space *M* is totally bounded if, for every *r* > 0, there exist a [finite](wikipedia://en/11742) cover of *M* by open balls of radius *r*. A metric space is compact if and only if it is complete and totally bounded.

:::

::: {#o278 .entry cue=glossary-term name="Totally disconnected"}

**Totally disconnected**

A space is totally disconnected if it has no connected subset with more than one point.

:::

::: {#o279 .entry cue=glossary-term name="Trivial topology"}

**[Trivial topology](wikipedia://en/382447)**

The [trivial topology](wikipedia://en/382447) (or **indiscrete topology**) on a set *X* consists of precisely the empty set and the entire space *X*.

:::

::: {#o280 .entry cue=glossary-term name="Tychonoff"}

**[Tychonoff](wikipedia://en/30554)**

A [Tychonoff space](wikipedia://en/30554) (or **completely regular Hausdorff** space, **completely T<sub>3</sub>** space, **T<sub>\3.5</sub>** space) is a completely regular T<sub>0</sub> space. (A completely regular space is Hausdorff [if and only if](wikipedia://en/14922) it is T<sub>0</sub>, so the terminology is consistent.) Every Tychonoff space is regular Hausdorff.

## U {#U}

::: {#o282 .entry cue=glossary-term name="Ultra-connected"}

**Ultra-connected**

A space is ultra-connected if no two non-empty closed sets are disjoint.[^o189] Every ultra-connected space is path-connected.

:::

::: {#o283 .entry cue=glossary-term name="Ultrametric"}

**[Ultrametric](wikipedia://en/333996)**

A metric is an ultrametric if it satisfies the following stronger version of the [triangle inequality](wikipedia://en/53941): for all *x*, *y*, *z* in *M*, *d*(*x*, *z*) ≤ max(*d*(*x*, *y*), *d*(*y*, *z*)).

:::

::: {#o284 .entry cue=glossary-term name="Uniform isomorphism"}

**[Uniform isomorphism](wikipedia://en/1344480)**

If *X* and *Y* are [uniform spaces](wikipedia://en/32339), a uniform isomorphism from *X* to *Y* is a bijective function *f* : *X* → *Y* such that *f* and *f*<sup>−1</sup> are [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous). The spaces are then said to be uniformly isomorphic and share the same [uniform properties](https://en.wikipedia.org/wiki/Uniform_properties).

:::

::: {#o285 .entry cue=glossary-term name="Uniformizable/Uniformisable"}

**[Uniformizable](https://en.wikipedia.org/wiki/Uniformizable)/Uniformisable**

A space is uniformizable if it is homeomorphic to a uniform space.

:::

::: {#o286 .entry cue=glossary-term name="Uniform space"}

**[Uniform space](wikipedia://en/32339)**

A [uniform space](wikipedia://en/32339) is a set *X* equipped with a nonempty collection Φ of subsets of the [Cartesian product](wikipedia://en/24104095) *X* × *X* satisfying the following [axioms](wikipedia://en/928):

:::

1. if *U* is in Φ, then *U* contains { (*x*, *x*) | *x* in *X* }.
1. if *U* is in Φ, then { (*y*, *x*) | (*x*, *y*) in *U* } is also in Φ
1. if *U* is in Φ and *V* is a subset of *X* × *X* which contains *U*, then *V* is in Φ
1. if *U* and *V* are in Φ, then *U* ∩ *V* is in Φ
1. if *U* is in Φ, then there exists *V* in Φ such that, whenever (*x*, *y*) and (*y*, *z*) are in *V*, then (*x*, *z*) is in *U*.

The elements of Φ are called **entourages**, and Φ itself is called a **uniform structure** on *X*. The uniform structure induces a topology on *X* where the basic neighborhoods of *x* are sets of the form {*y* : (*x*,*y*)∈*U*} for *U*∈Φ.

See **[Uniform space](wikipedia://en/32339)**.

## W {#W}

::: {#o291 .entry cue=glossary-term name="Weak topology"}

**[Weak topology](wikipedia://en/33662)**

The [weak topology](wikipedia://en/33662) on a set, with respect to a collection of functions from that set into topological spaces, is the coarsest topology on the set which makes all the functions continuous.

:::

::: {#o292 .entry cue=glossary-term name="Weaker topology"}

**Weaker topology**

See **[Coarser topology](https://en.wikipedia.org/wiki/Coarser_topology)**. Beware, some authors, especially [analysts](wikipedia://en/48396), use the term **stronger topology**.

:::

::: {#o293 .entry cue=glossary-term name="Weakly countably compact"}

**Weakly countably compact**

A space is weakly countably compact (or **limit point compact**) if every [infinite](wikipedia://en/20110824) subset has a limit point.

:::

::: {#o294 .entry cue=glossary-term name="Weakly hereditary"}

**Weakly hereditary**

A property of spaces is said to be weakly hereditary if whenever a space has that property, then so does every closed subspace of it. For example, compactness and the Lindelöf property are both weakly hereditary properties, although neither is hereditary.

:::

::: {#o295 .entry cue=glossary-term name="Weight"}

**Weight**

The [weight of a space](https://en.wikipedia.org/wiki/Weight_of_a_space) *X* is the smallest [cardinal number](wikipedia://en/6173) κ such that *X* has a base of cardinal κ. (Note that such a cardinal number exists, because the entire topology forms a base, and because the class of cardinal numbers is [well-ordered](https://en.wikipedia.org/wiki/Well_order).)

:::

::: {#o296 .entry cue=glossary-term name="Well-connected"}

**Well-connected**

See **Ultra-connected**. (Some authors use this term strictly for ultra-connected compact spaces.)

:::

## Z {#Z}

::: {#o298 .entry cue=glossary-term name="Zero-dimensional"}

**Zero-dimensional**

A space is [zero-dimensional](https://en.wikipedia.org/wiki/Zero-dimensional) if it has a base of clopen sets.[^o299]

:::
