# Transfer function

::: {#o1 .subject cue=lead name="Transfer function"}

In [engineering](https://en.wikipedia.org/wiki/Engineering), a **transfer function** (also known as **system function**[^o2] or **network function**) of a system, sub-system, or component is a [mathematical function](wikipedia://en/185427) that [models](wikipedia://en/20590) the system's output for each possible input.[^o3][^o4][^o5] It is widely used in [electronic engineering](https://en.wikipedia.org/wiki/Electronic_engineering) tools like [circuit simulators](https://en.wikipedia.org/wiki/Electronic_circuit_simulation) and [control systems](https://en.wikipedia.org/wiki/Control_system) and in [chemical reaction engineering](https://en.wikipedia.org/wiki/Chemical_reaction_engineering) for the study and modeling of the [residence time distribution](https://en.wikipedia.org/wiki/Residence_time) and stability of a [reactor](https://en.wikipedia.org/wiki/Chemical_reactor).[^o6] In simple cases, this function can be represented as a two-dimensional [graph](https://en.wikipedia.org/wiki/Graph_%28function%29) of an independent [scalar](wikipedia://en/3588331) input versus the dependent scalar output (known as a **transfer curve** or **characteristic curve**). Transfer functions for components are used to design and analyze systems assembled from components, particularly using the [block diagram](https://en.wikipedia.org/wiki/Block_diagram) technique, in electronics and [control theory](wikipedia://en/7039).

:::

Dimensions and units of the transfer function model the output response of the device for a range of possible inputs. The transfer function of a [two-port](https://en.wikipedia.org/wiki/Two-port) electronic circuit, such as an [amplifier](https://en.wikipedia.org/wiki/Amplifier), might be a two-dimensional graph of the scalar voltage at the output as a function of the scalar voltage applied to the input; the transfer function of an electromechanical [actuator](https://en.wikipedia.org/wiki/Actuator) might be the mechanical displacement of the movable arm as a function of electric current applied to the device; the transfer function of a [photodetector](https://en.wikipedia.org/wiki/Photodetector) might be the output voltage as a function of the [luminous intensity](https://en.wikipedia.org/wiki/Luminous_intensity) of incident light of a given [wavelength](wikipedia://en/33125).

The term *transfer function* is also used in the [frequency domain](wikipedia://en/370346) analysis of systems using transform methods, such as the [Laplace transform](wikipedia://en/18610); it is the [amplitude](https://en.wikipedia.org/wiki/Amplitude) of the output as a function of the [frequency](wikipedia://en/10779) of the input signal. The transfer function of an [electronic filter](https://en.wikipedia.org/wiki/Electronic_filter) is the amplitude at the output as a function of the frequency of a constant amplitude [sine wave](wikipedia://en/324749) applied to the input. For optical imaging devices, the [optical transfer function](wikipedia://en/4079673) is the [Fourier transform](wikipedia://en/52247) of the [point spread function](wikipedia://en/865348) (a function of [spatial frequency](https://en.wikipedia.org/wiki/Spatial_frequency)).

## Linear time-invariant systems {#Linear_time-invariant_systems}

Transfer functions are commonly used in the analysis of systems such as [single-input single-output](https://en.wikipedia.org/wiki/Single-input_single-output) [filters](https://en.wikipedia.org/wiki/Filter_%28signal_processing%29) in [signal processing](wikipedia://en/29324), [communication theory](wikipedia://en/248810), and [control theory](wikipedia://en/7039). The term is often used exclusively to refer to [linear time-invariant](https://en.wikipedia.org/wiki/Linear_time-invariant) (LTI) systems. Most real systems have [non-linear](https://en.wikipedia.org/wiki/Non-linear) input–output characteristics, but many systems operated within nominal parameters (not over-driven) have behavior close enough to linear that [LTI system theory](https://en.wikipedia.org/wiki/LTI_system_theory) is an acceptable representation of their input–output behavior.

### Continuous-time {#Continuous-time}

Descriptions are given in terms of a [complex variable](https://en.wikipedia.org/wiki/Complex_variable), $s = \sigma + j \cdot \omega$. In many applications it is sufficient to set $\sigma=0$ (thus $s = j \cdot \omega$), which reduces the [Laplace transforms](wikipedia://en/18610) with complex arguments to [Fourier transforms](wikipedia://en/52247) with the real argument ω. This is common in applications primarily interested in the LTI system's steady-state response (often the case in [signal processing](wikipedia://en/29324) and [communication theory](wikipedia://en/248810)), not the fleeting turn-on and turn-off [transient response](https://en.wikipedia.org/wiki/Transient_response) or stability issues.

For [continuous-time](https://en.wikipedia.org/wiki/Continuous-time) input signal $x(t)$ and output $y(t)$, dividing the Laplace transform of the output, $Y(s) = \mathcal{L}\left\{y(t)\right\}$, by the Laplace transform of the input, $X(s) = \mathcal{L}\left\{x(t)\right\}$, yields the system's transfer function $H(s)$:

$$H(s) = \frac{Y(s)}{X(s)} = \frac{ \mathcal{L}\left\{y(t)\right\} }{ \mathcal{L}\left\{x(t)\right\} }$$

which can be rearranged as:

$$Y(s) = H(s)\;X(s) \, .$$

### Discrete-time {#Discrete-time}

[Discrete-time](https://en.wikipedia.org/wiki/Discrete-time) signals may be notated as arrays indexed by an [integer](wikipedia://en/14563) $n$ (e.g. $x[n]$ for input and $y[n]$ for output). Instead of using the Laplace transform (which is better for continuous-time signals), discrete-time signals are dealt with using the [z-transform](wikipedia://en/171589) (notated with a corresponding capital letter, like $X(z)$ and $Y(z)$), so a discrete-time system's transfer function can be written as:

$$H(z) = \frac{Y(z)}{X(z)} = \frac{\mathcal{Z}\{y[n]\}}{\mathcal{Z}\{x[n]\}}.$$

### Direct derivation from differential equations {#Direct_derivation_from_differential_equations}

A [linear differential equation](wikipedia://en/379868) with constant coefficients

$$L[u] = \frac{d^nu}{dt^n} + a_1\frac{d^{n-1}u}{dt^{n-1}} + \dotsb + a_{n-1}\frac{du}{dt} + a_nu = r(t)$$

where *u* and *r* are suitably smooth functions of *t*, has *L* as the operator defined on the relevant function space that transforms *u* into *r*. That kind of equation can be used to constrain the output function *u* in terms of the *forcing* function *r*. The transfer function can be used to define an operator $F[r] = u$ that serves as a right inverse of *L*, meaning that $L[F[r]] = r$.

Solutions of the homogeneous [constant-coefficient differential equation](wikipedia://en/379868#Homogeneous_equations_with_constant_coefficients) $L[u] = 0$ can be found by trying $u = e^{\lambda t}$. That substitution yields the [characteristic polynomial](wikipedia://en/31050469)

$$p_L(\lambda) = \lambda^n + a_1\lambda^{n-1} + \dotsb + a_{n-1}\lambda + a_n\,$$

The inhomogeneous case can be easily solved if the input function *r* is also of the form $r(t) = e^{s t}$. By substituting $u = H(s)e^{s t}$, $L[H(s) e^{s t}] = e^{s t}$ if we define

$$H(s) = \frac{1}{p_L(s)} \qquad\text{wherever }\quad p_L(s) \neq 0.$$

Other definitions of the transfer function are used, for example $1/p_L(ik) .$[^o11]

### Gain, transient behavior and stability {#Gain,_transient_behavior_and_stability}

A general sinusoidal input to a system of frequency $\omega_0 / (2\pi)$ may be written $\exp( j \omega_0 t )$. The response of a system to a sinusoidal input beginning at time $t=0$ will consist of the sum of the steady-state response and a transient response. The steady-state response is the output of the system in the limit of infinite time, and the transient response is the difference between the response and the steady-state response; it corresponds to the homogeneous solution of the [differential equation](wikipedia://en/1424309). The transfer function for an LTI system may be written as the product:

$$H(s)=\prod_{i=1}^N \frac{1}{s-s_{P_i}}$$

where *s<sub>P<sub>i</sub></sub>* are the *N* roots of the characteristic polynomial and will be the [poles](https://en.wikipedia.org/wiki/Pole_%28complex_analysis%29) of the transfer function. In a transfer function with a single pole $H(s)=\frac{1}{s-s_P}$ where $s_P = \sigma_P+j \omega_P$, the Laplace transform of a general sinusoid of unit amplitude will be $\frac{1}{s-j\omega_0}$. The Laplace transform of the output will be $\frac{H (s)}{s-j \omega_0}$, and the temporal output will be the inverse Laplace transform of that function:

$$g(t)=\frac{e^{j\,\omega_0\,t}-e^{(\sigma_P+j\,\omega_P)t}}{-\sigma_P+j (\omega_0-\omega_P)}$$

The second term in the numerator is the transient response, and in the limit of infinite time it will diverge to infinity if *σ<sub>P</sub>* is positive. For a system to be stable, its transfer function must have no poles whose real parts are positive. If the transfer function is strictly stable, the real parts of all poles will be negative and the transient behavior will tend to zero in the limit of infinite time. The steady-state output will be:

$$g(\infty)=\frac{e^{j\, \omega_0\,t}}{-\sigma_P+j (\omega_0-\omega_P)}$$

The [frequency response](wikipedia://en/302033) (or "gain") *G* of the system is defined as the absolute value of the ratio of the output amplitude to the steady-state input amplitude:

$$G(\omega_i)=\left|\frac{1}{-\sigma_P+j (\omega_0-\omega_P)}\right|=\frac{1}{\sqrt{\sigma_P^2+(\omega_P-\omega_0)^2}},$$

which is the absolute value of the transfer function $H(s)$ evaluated at $j\omega_i$. This result is valid for any number of transfer-function poles.

### Steady state behavior for sinusoidal excitation {#Steady_state_behavior_for_sinusoidal_excitation}

The steady state behavior of a linear system

$$\sum_{i=0}^n a_i y^{(i)} + \sum_{j=0}^m b_j u^{(j)} = 0$$

for sinusoidal excitation $u(t) = \sin(\omega t)$ can be expressed in terms of its transfer function

$$g(s) = \frac{b_m s^m + ... + b_0}{a_n s^n + ... + a_0},$$

evaluated at $s = j \omega$, i.e. with real part $\sigma = 0$:

$$y(t) = |g(j \omega)| \sin(\omega t + \arg(g(j \omega))).$$

To show this, use the ansatz function

$$y(t) = c e^{j \omega t},$$

plug it into the above given differential equation, solve for $c$, and note that $c = g(j \omega)$.

From the complex identity $z = |z| e^{j \arg(z)}$, the argument follows.

## Signal processing {#Signal_processing}

If $x(t)$ is the input to a general [linear time-invariant system](https://en.wikipedia.org/wiki/LTI_system_theory), and $y(t)$ is the output, and the [bilateral Laplace transform](https://en.wikipedia.org/wiki/Bilateral_Laplace_transform) of $x(t)$ and $y(t)$ is

$$\begin{aligned} X(s) &= \mathcal{L}\left \{ x(t) \right \} \ \stackrel{\mathrm{def}}{=}\ \int_{-\infty}^{\infty} x(t) e^{-st}\, dt, \\ Y(s) &= \mathcal{L}\left \{ y(t) \right \} \ \stackrel{\mathrm{def}}{=}\ \int_{-\infty}^{\infty} y(t) e^{-st}\, dt. \end{aligned}$$

The output is related to the input by the transfer function $H(s)$ as

$$Y(s) = H(s) X(s)$$

and the transfer function itself is

$$H(s) = \frac{Y(s)} {X(s)}.$$

If a [complex](wikipedia://en/5826) [harmonic](https://en.wikipedia.org/wiki/Harmonic) [signal](https://en.wikipedia.org/wiki/Signal_%28information_theory%29) with a [sinusoidal](https://en.wikipedia.org/wiki/Sinusoidal) component with [amplitude](https://en.wikipedia.org/wiki/Amplitude) $|X|$, [angular frequency](https://en.wikipedia.org/wiki/Angular_frequency) $\omega$ and [phase](https://en.wikipedia.org/wiki/Phase_%28waves%29) $\arg(X)$, where arg is the [argument](wikipedia://en/14699765)

$$x(t) = Xe^{j\omega t} = |X|e^{j(\omega t + \arg(X))}$$

where $X = |X|e^{j\arg(X)}$

is input to a [linear](https://en.wikipedia.org/wiki/Linear) time-invariant system, the corresponding component in the output is:

$$\begin{aligned} y(t) &= Ye^{j\omega t} = |Y|e^{j(\omega t + \arg(Y))}, \\ Y &= |Y|e^{j\arg(Y)}. \end{aligned}$$

In a linear time-invariant system, the input frequency $\omega$ has not changed; only the amplitude and phase angle of the sinusoid have been changed by the system. The [frequency response](wikipedia://en/302033) $H(j \omega)$ describes this change for every frequency $\omega$ in terms of gain

$$G(\omega) = \frac{|Y|}{|X|} = |H(j \omega)|$$

and phase shift

$$\phi(\omega) = \arg(Y) - \arg(X) = \arg( H(j \omega)).$$

The [phase delay](https://en.wikipedia.org/wiki/Phase_delay) (the frequency-dependent amount of delay introduced to the sinusoid by the transfer function) is

$$\tau_{\phi}(\omega) = -\frac{\phi(\omega)}{\omega}.$$

The [group delay](https://en.wikipedia.org/wiki/Group_delay) (the frequency-dependent amount of delay introduced to the envelope of the sinusoid by the transfer function) is found by computing the derivative of the phase shift with respect to angular frequency $\omega$,

$$\tau_{g}(\omega) = -\frac{d\phi(\omega)}{d\omega}.$$

The transfer function can also be shown using the [Fourier transform](wikipedia://en/52247), a special case of [bilateral Laplace transform](https://en.wikipedia.org/wiki/Bilateral_Laplace_transform) where $s = j \omega$.

### Common transfer-function families {#Common_transfer-function_families}

Although any LTI system can be described by some transfer function, "families" of special transfer functions are commonly used:

- [Butterworth filter](https://en.wikipedia.org/wiki/Butterworth_filter) – maximally flat in passband and stopband for the given order
- [Chebyshev filter (Type I)](https://en.wikipedia.org/wiki/Chebyshev_filter) – maximally flat in stopband, sharper cutoff than a Butterworth filter of the same order
- Chebyshev filter (Type II) – maximally flat in passband, sharper cutoff than a Butterworth filter of the same order
- [Bessel filter](https://en.wikipedia.org/wiki/Bessel_filter) – maximally constant [group delay](https://en.wikipedia.org/wiki/Group_delay) for a given order
- [Elliptic filter](https://en.wikipedia.org/wiki/Elliptic_filter) – sharpest cutoff (narrowest transition between passband and stopband) for the given order
- [Optimum "L" filter](https://en.wikipedia.org/wiki/Optimum_"L"_filter)
- [Gaussian filter](https://en.wikipedia.org/wiki/Gaussian_filter) – minimum group delay; gives no overshoot to a step function
- [Raised-cosine filter](https://en.wikipedia.org/wiki/Raised-cosine_filter)

## Control engineering {#Control_engineering}

In [control engineering](https://en.wikipedia.org/wiki/Control_engineering) and [control theory](wikipedia://en/7039), the transfer function is derived with the [Laplace transform](wikipedia://en/18610). The transfer function was the primary tool used in classical control engineering. A [transfer matrix](wikipedia://en/48259106) can be obtained for any linear system to analyze its dynamics and other properties; each element of a transfer matrix is a transfer function relating a particular input variable to an output variable. A representation bridging [state space](wikipedia://en/548156) and transfer function methods was proposed by [Howard H. Rosenbrock](https://en.wikipedia.org/wiki/Howard_Harry_Rosenbrock), and is known as the [Rosenbrock system matrix](wikipedia://en/43654412).

## Imaging {#Imaging}

In [imaging](https://en.wikipedia.org/wiki/Imaging), transfer functions are used to describe the relationship between the scene light, the image signal and the displayed light.

## Non-linear systems {#Non-linear_systems}

Transfer functions do not exist for many [non-linear systems](wikipedia://en/3359147), such as [relaxation oscillators](wikipedia://en/195967);[^o19] however, [describing functions](wikipedia://en/3877767) can sometimes be used to approximate such nonlinear time-invariant systems.
