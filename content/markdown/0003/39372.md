# Prototile

::: {#o1 .subject cue=lead name="Prototile"}

*Image: Penrose Tiling (Rhombi).svg.* This form of the [aperiodic](wikipedia://en/868145) [Penrose tiling](wikipedia://en/26611936) has two prototiles, a thick [rhombus](wikipedia://en/183884) (shown blue in the figure) and a thin rhombus (green).

In [mathematics](wikipedia://en/18831), a **prototile** is one of the shapes of a tile in a [tessellation](wikipedia://en/321671).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A tessellation of the plane or of any other space is a cover of the space by [closed](wikipedia://en/47279) shapes, called tiles, that have [disjoint](wikipedia://en/39359) [interiors](wikipedia://en/55610). Some of the tiles may be [congruent](wikipedia://en/39330) to one or more others. If $S$ is the set of tiles in a tessellation, a set $R$ of shapes is called a set of prototiles if no two shapes in $R$ are congruent to each other, and every tile in $S$ is congruent to one of the shapes in $R$.[^o5]

It is possible to choose many different sets of prototiles for a tiling: translating or rotating any one of the prototiles produces another valid set of prototiles. However, every set of prototiles has the same [cardinality](wikipedia://en/6174), so the number of prototiles is well defined. A tessellation is said to be *monohedral* if it has exactly one prototile.

:::

## Aperiodicity {#Aperiodicity}

*Image: Smith aperiodic monotiling.svg.* A tiling that does not repeat and uses only one shape, discovered by [David Smith](https://en.wikipedia.org/wiki/David_Smith_%28hobbyist%29)

A set of prototiles is said to be aperiodic if every tiling with those prototiles is an [aperiodic tiling](wikipedia://en/868145). In March 2023, four researchers, [Chaim Goodman-Strauss](wikipedia://en/56181508), [David Smith](https://en.wikipedia.org/wiki/David_Smith_%28hobbyist%29), Joseph Samuel Myers and Craig S. Kaplan, announced the discovery of an aperiodic monohedral prototile (monotile) and a proof that the tile discovered by David Smith is an aperiodic monotile, i.e. a solution to a longstanding open [einstein problem](wikipedia://en/43542926).[^o7][^o8]

In higher dimensions, the problem had been solved earlier: the [Schmitt-Conway-Danzer tile](https://en.wikipedia.org/wiki/Schmitt-Conway-Danzer_tile) is the prototile of a monohedral aperiodic tiling of three-dimensional [Euclidean space](wikipedia://en/9697), and cannot tile space periodically.
