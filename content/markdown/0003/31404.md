# Tietze extension theorem

::: {#o1 .subject cue=lead name="Tietze extension theorem"}

*Image: Urysohn.jpeg.* Pavel Urysohn

In [topology](wikipedia://en/29954), the **[Tietze](wikipedia://en/1368572) extension theorem** (also known as the **Tietze–[Urysohn](wikipedia://en/23770)–[Brouwer](wikipedia://en/172896) extension theorem** or **Urysohn-Brouwer lemma**) states that any [real-valued](wikipedia://en/22284647), [continuous function](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) on a [closed subset](https://en.wikipedia.org/wiki/Closed_subset) of a [normal](wikipedia://en/48629) [topological space](wikipedia://en/30450) can be extended to the entire space, preserving boundedness if necessary.

:::

::: {#o4 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

If $X$ is a [normal space](wikipedia://en/48629) and

$$f : A \to \mathbb{R}$$

is a [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) map from a [closed subset](https://en.wikipedia.org/wiki/Closed_subset) $A$ of $X$ into the [real numbers](wikipedia://en/20646438) $\mathbb{R}$ carrying the [standard topology](wikipedia://en/1482085), then there exists a [continuous extension](https://en.wikipedia.org/wiki/Continuous_extension) of $f$ to $X;$ that is, there exists a map

$$F : X \to \mathbb{R}$$

continuous on all of $X$ with $F(a) = f(a)$ for all $a \in A.$ Moreover, $F$ may be chosen such that

$$\sup \{|f(a)| : a \in A\} ~=~ \sup \{|F(x)| : x \in X\},$$

that is, if $f$ is bounded then $F$ may be chosen to be bounded (with the same bound as $f$).

:::

::: {#o6 .proof cue=heading name="Proof"}

## Proof {#Proof}

We prove the theorem in the case where $f$ is bounded.

The function $F$ is constructed iteratively. Firstly, we define

$$\begin{aligned} c_0 &= \sup \{|f(a)|:a\in A\}\\ E_0 &= \{a\in A:f(a)\geq c_0/3\}\\ F_0 &=\{a\in A:f(a)\leq -c_0/3\}. \end{aligned}$$

Observe that $E_0$ and $F_0$ are [closed](wikipedia://en/47279) and [disjoint](wikipedia://en/39359) subsets of $A$. By taking a linear combination of the function obtained from the proof of [Urysohn's lemma](wikipedia://en/49253), there exists a [continuous function](wikipedia://en/6122) $g_0:X\to \mathbb{R}$ such that

$$\begin{aligned} g_0 &= \frac{c_0}{3}\text{ on }E_0\\ g_0 &= -\frac{c_0}{3}\text{ on }F_0 \end{aligned}$$

and furthermore

$$-\frac{c_0}{3}\leq g_0 \leq \frac{c_0}{3}$$

on $X$. In particular, it follows that

$$\begin{aligned} |g_0| &\leq \frac{c_0}{3}\\ |f-g_0| &\leq \frac{2c_0}{3} \end{aligned}$$

on $A$. We now use [induction](wikipedia://en/18881) to construct a sequence of continuous functions $(g_n)_{n=0}^\infty$ such that

$$\begin{aligned} |g_n|&\leq \frac{2^nc_0}{3^{n+1}}\\ |f-g_0-...-g_{n}|&\leq \frac{2^{n+1}c_0}{3^{n+1}}. \end{aligned}$$

We've shown that this holds for $n=0$ and assume that $g_0,...,g_{n-1}$ have been constructed. Define

$$c_{n-1} = \sup\{|f(a)-g_0(a)-...-g_{n-1}(a)|:a\in A\}$$

and repeat the above argument replacing $c_0$ with $c_{n-1}$ and replacing $f$ with $f-g_0-...-g_{n-1}$. Then we find that there exists a continuous function $g_n:X\to \mathbb{R}$ such that

$$\begin{aligned} |g_n|&\leq \frac{c_{n-1}}{3}\\ |f-g_0-...-g_n|&\leq \frac{2c_{n-1}}{3}. \end{aligned}$$

By the inductive hypothesis, $c_{n-1}\leq 2^nc_0/3^n$ hence we obtain the required identities and the induction is complete. Now, we define a continuous function $F_n:X\to \mathbb{R}$ as

$$F_n = g_0+...+g_n.$$

Given $n\geq m$,

$$\begin{aligned} |F_n - F_m| &= |g_{m+1}+...+g_n|\\ &\leq \left(\left(\frac{2}{3}\right)^{m+1}+...+\left(\frac{2}{3}\right)^{n}\right)\frac{c_0}{3}\\ &\leq \left(\frac{2}{3}\right)^{m+1}c_0. \end{aligned}$$

Therefore, the sequence $(F_n)_{n=0}^\infty$ is [Cauchy](wikipedia://en/6085). Since the [space](wikipedia://en/20018) of continuous functions on $X$ together with the [sup norm](wikipedia://en/349755) is a [complete metric space](wikipedia://en/7832), it follows that there exists a continuous function $F:X\to \mathbb{R}$ such that $F_n$ [converges uniformly](wikipedia://en/50652) to $F$. Since

$$|f-F_n|\leq \frac{2^{n+1}c_0}{3^{n+1}}$$

on $A$, it follows that $F=f$ on $A$. Finally, we observe that

$$|F_n|\leq \sum_{n=0}^\infty |g_n|\leq c_0$$

hence $F$ is bounded and has the same bound as $f$. $\square$

:::

## History {#History}

[L. E. J. Brouwer](wikipedia://en/172896) and [Henri Lebesgue](wikipedia://en/49514) proved a special case of the theorem, when $X$ is a finite-dimensional real [vector space](wikipedia://en/32370). [Heinrich Tietze](wikipedia://en/1368572) extended it to all [metric spaces](wikipedia://en/20018), and [Pavel Urysohn](https://en.wikipedia.org/wiki/Pavel_Samuilovich_Urysohn) proved the theorem as stated here, for normal topological spaces.[^o2][^o8]

## Equivalent statements {#Equivalent_statements}

This theorem is equivalent to [Urysohn's lemma](wikipedia://en/49253) (which is also equivalent to the normality of the space) and is widely applicable, since all [metric spaces](wikipedia://en/20018) and all [compact](wikipedia://en/6042) [Hausdorff spaces](wikipedia://en/13637) are normal. It can be generalized by replacing $\mathbb{R}$ with $\mathbb{R}^J$ for some indexing set $J,$ any retract of $\mathbb{R}^J,$ or any normal [absolute retract](https://en.wikipedia.org/wiki/Deformation_retract#Retract) whatsoever.

::: {#o11 .statement kind=statement/generalization cue=heading name="Variations"}

## Variations {#Variations}

If $X$ is a metric space, $A$ a non-empty subset of $X$ and $f : A \to \mathbb{R}$ is a [Lipschitz continuous](https://en.wikipedia.org/wiki/Lipschitz_continuous) function with Lipschitz constant $K,$ then $f$ can be extended to a Lipschitz continuous function $F : X \to \mathbb{R}$ with same constant $K.$ This theorem is also valid for [Hölder continuous functions](wikipedia://en/4005892), that is, if $f : A \to \mathbb{R}$ is Hölder continuous function with constant less than or equal to $1,$ then $f$ can be extended to a Hölder continuous function $F : X \to \mathbb{R}$ with the same constant.[^o12]

Another variant (in fact, generalization) of Tietze's theorem is due to H.Tong and Z. Ercan:[^o13] Let $A$ be a closed subset of a normal topological space $X.$ If $f : X \to \mathbb{R}$ is an [upper semicontinuous](https://en.wikipedia.org/wiki/Upper_semicontinuous) function, $g : X \to \mathbb{R}$ a [lower semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous) function, and $h : A \to \mathbb{R}$ a continuous function such that $f(x) \leq g(x)$ for each $x \in X$ and $f(a) \leq h(a) \leq g(a)$ for each $a \in A$, then there is a continuous extension $H : X \to \mathbb{R}$ of $h$ such that $f(x) \leq H(x) \leq g(x)$ for each $x \in X.$ This theorem is also valid with some additional hypothesis if $\mathbb{R}$ is replaced by a general locally solid [Riesz space](wikipedia://en/8099018).[^o13]

Dugundji (1951) extends the theorem as follows: If $X$ is a metric space, $Y$ is a [locally convex topological vector space](wikipedia://en/518844), $A$ is a closed subset of $X$ and $f:A\to Y$ is continuous, then it could be extended to a continuous function $\tilde f$ defined on all of $X$. Moreover, the extension could be chosen such that $\tilde f(X)\subseteq \text{conv} f(A)$

:::
