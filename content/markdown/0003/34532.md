# List of zeta functions

::: {#o1 .subject cue=lead name="List of zeta functions"}

In [mathematics](wikipedia://en/18831), a **[zeta](https://en.wikipedia.org/wiki/Zeta) function** is (usually) a [function](wikipedia://en/185427) analogous to the original example, the [Riemann zeta function](wikipedia://en/25809)

:::

$$\zeta(s) = \sum_{n=1}^\infty \frac 1 {n^s}.$$

Zeta functions include:

- [Airy zeta function](wikipedia://en/26762899), related to the zeros of the [Airy function](wikipedia://en/406896)

:::

- [Arakawa–Kaneko zeta function](wikipedia://en/43708138)

- [Zeta function of an incidence algebra](wikipedia://en/166980#Special_elements), a function that maps every interval of a poset to the constant value 1.
