# Unary numeral system

::: {#o1 .subject cue=lead name="Unary numeral system"}

The **unary numeral system** is the simplest numeral system to represent [natural numbers](wikipedia://en/21474):[^o2] to represent a number *N*, a symbol representing 1 is repeated *N* times.[^o3]

:::

In the unary system, the number [0](wikipedia://en/34513) (zero) is represented by the [empty string](wikipedia://en/835827), that is, the absence of a symbol. Numbers 1, 2, 3, 4, 5, 6, ... are represented in unary as 1, 11, 111, 1111, 11111, 111111, ...[^o4]

Unary is a [bijective numeral system](wikipedia://en/2260933). However, although it has sometimes been described as "base 1",[^o5] it differs in some important ways from [positional notations](wikipedia://en/437052), in which the value of a digit depends on its position within a number. For instance, the unary form of a number can be exponentially longer than its representation in other bases.[^o6]

The use of [tally marks](wikipedia://en/47962742) in counting is an application of the unary numeral system. For example, using the tally mark **$|$** (𝍷), the number 3 is represented as **$|$$|$$|$**. In [East Asian](https://en.wikipedia.org/wiki/East_Asia) cultures, the number 3 is represented as 三, a character drawn with three strokes.[^o7] (One and two are represented similarly.) In China and Japan, the character 正, drawn with 5 strokes, is sometimes used to represent 5 as a tally.[^o8][^o9]

Unary numbers should be distinguished from [repunits](wikipedia://en/215056), which are also written as sequences of ones but have their usual [decimal](wikipedia://en/8214) numerical interpretation.

## Operations {#Operations}

[Addition](wikipedia://en/61338) and [subtraction](wikipedia://en/74141) are particularly simple in the unary system, as they involve little more than [string concatenation](https://en.wikipedia.org/wiki/String_concatenation).[^o11] The [Hamming weight](wikipedia://en/1127884) or population count operation that counts the number of nonzero bits in a sequence of binary values may also be interpreted as a conversion from unary to [binary numbers](wikipedia://en/238686).[^o12] However, [multiplication](wikipedia://en/20845) is more cumbersome and has often been used as a test case for the design of [Turing machines](wikipedia://en/30403).[^o13][^o14][^o15]

## Complexity {#Complexity}

Compared to standard [positional numeral systems](wikipedia://en/437052), the unary system is inconvenient and hence is not used in practice for large calculations. It occurs in some [decision problem](wikipedia://en/8336) descriptions in [theoretical computer science](wikipedia://en/30402) (e.g. some [P-complete](wikipedia://en/54683) problems), where it is used to "artificially" decrease the run-time or space requirements of a problem. For instance, the problem of [integer factorization](wikipedia://en/15491) is suspected to require more than a polynomial function of the length of the input as run-time if the input is given in [binary](https://en.wikipedia.org/wiki/Binary_numeral_system), but it only needs linear runtime if the input is presented in unary.[^o17] However, this is potentially misleading. Using a unary input is slower for any given number, not faster; the distinction is that a binary (or larger base) input is proportional to the base 2 (or larger base) logarithm of the number while unary input is proportional to the number itself. Therefore, while the run-time and space requirement in unary looks better as function of the input size, it does not represent a more efficient solution.[^o18]

In [computational complexity theory](wikipedia://en/7543), unary numbering is used to distinguish [strongly NP-complete](https://en.wikipedia.org/wiki/Strongly_NP-complete) problems from problems that are [NP-complete](https://en.wikipedia.org/wiki/NP-complete) but not strongly NP-complete. A problem in which the input includes some numerical parameters is strongly NP-complete if it remains NP-complete even when the size of the input is made artificially larger by representing the parameters in unary. For such a problem, there exist hard instances for which all parameter values are at most polynomially large.[^o19]

## Applications {#Applications}

In addition to the application in tally marks, unary numbering is used as part of some data compression algorithms such as [Golomb coding](wikipedia://en/147230).[^o22] It also forms the basis for the [Peano axioms](wikipedia://en/25005) for formalizing arithmetic within [mathematical logic](wikipedia://en/19636).[^o23] A form of unary notation called [Church encoding](wikipedia://en/2989409) is used to represent numbers within [lambda calculus](wikipedia://en/18203).[^o24]

Some [email](https://en.wikipedia.org/wiki/Email) [spam filters](https://en.wikipedia.org/wiki/Spam_filter) tag messages with a number of [asterisks](https://en.wikipedia.org/wiki/Asterisk) in an [e-mail header](https://en.wikipedia.org/wiki/E-mail_header) such as *X-Spam-Bar* or *X-SPAM-LEVEL*. The larger the number, the more likely the email is considered spam. Using a unary representation instead of a decimal number lets the user search for messages with a given rating or higher. For example, searching for **\*\*\*\*** yield messages with a rating of at least 4.[^o25]
