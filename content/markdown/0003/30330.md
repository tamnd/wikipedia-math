# Total order

::: {#o1 .subject cue=lead name="Total order"}

In [mathematics](wikipedia://en/18831), a **total order** or **linear order** is a [partial order](https://en.wikipedia.org/wiki/Partial_order) in which any two elements are comparable. That is, a total order is a [binary relation](wikipedia://en/3931) $\leq$ on some [set](wikipedia://en/26691) $X$, which satisfies the following for all $a, b$ and $c$ in $X$:

:::

1. $a \leq a$ ([reflexive](wikipedia://en/200458)).
1. If $a \leq b$ and $b \leq c$ then $a \leq c$ ([transitive](wikipedia://en/200463)).
1. If $a \leq b$ and $b \leq a$ then $a = b$ ([antisymmetric](wikipedia://en/1176)).
1. $a \leq b$ or $b \leq a$ ([strongly connected](wikipedia://en/57495962), formerly called totality).

Requirements 1. to 3. just make up the definition of a partial order. Reflexivity (1.) already follows from strong connectedness (4.), but is required explicitly by many authors nevertheless, to indicate the kinship to partial orders.[^n1] Total orders are sometimes also called **simple**,[^n2] **connex**,[^n3] or **full orders**.[^n4]

A set equipped with a total order is a **totally ordered set**;[^n5] the terms **simply ordered set**,[^n2] **linearly ordered set**,[^n3][^n5] **toset**[^o10] and **loset**[^o11][^o12] are also used. The term *chain* is sometimes defined as a synonym of *totally ordered set*,[^n5] but generally refers to a totally ordered subset of a given partially ordered set.

An extension of a given partial order to a total order is called a [linear extension](wikipedia://en/11726298) of that partial order.

::: {#o15 .pointer-item cue=pointer name="Strict total order"}

## Strict and non-strict total orders {#Strict_and_non-strict_total_orders}

For delimitation purposes, a total order as defined above is sometimes called *non-strict* order. For each (non-strict) total order $\leq$ there is an associated relation $<$, called the *strict total order* associated with $\leq$ that can be defined in two equivalent ways:

- $a < b$ if $a \leq b$ and $a \neq b$ ([reflexive reduction](https://en.wikipedia.org/wiki/Reflexive_reduction)).
- $a < b$ if not $b \leq a$ (i.e., $<$ is the [complement](wikipedia://en/3931#Complement) of the [converse](wikipedia://en/3941020) of $\leq$).

Conversely, the [reflexive closure](wikipedia://en/22603618) of a strict total order $<$ is a (non-strict) total order.

Thus, a **strict total order** on a set $X$ is a [strict partial order](https://en.wikipedia.org/wiki/Strict_partial_order) on $X$ in which any two distinct elements are comparable. That is, a strict total order is a [binary relation](wikipedia://en/3931) $<$ on some [set](wikipedia://en/26691) $X$, which satisfies the following for all $a, b$ and $c$ in $X$:

1. Not $a < a$ ([irreflexive](https://en.wikipedia.org/wiki/Irreflexive_relation)).
1. If $a < b$ then not $b < a$ ([asymmetric](wikipedia://en/1229368)).
1. If $a < b$ and $b < c$ then $a < c$ ([transitive](wikipedia://en/200463)).
1. If $a \neq b$, then $a < b$ or $b < a$ ([connected](wikipedia://en/57495962)).

Asymmetry follows from transitivity and irreflexivity;Let $a < b$, assume for contradiction that also $b < a$. Then $a < a$ by transitivity, which contradicts irreflexivity. moreover, irreflexivity follows from asymmetry.If $a < a$, then not $a < a$ by asymmetry.

:::

## Examples {#Examples}

- Any [subset](wikipedia://en/27631) of a totally ordered set $X$ is totally ordered for the restriction of the order on $X$.
- The unique order on the empty set, $\emptyset$, is a total order.
- Any set of [ordinal numbers](wikipedia://en/26547932) (more strongly, these are [well-orders](wikipedia://en/33456)).
- If $X$ is any set and $f$ an [injective function](wikipedia://en/45196) from $X$ to a totally ordered set then $f$ induces a total ordering on $X$ by setting $x_{1} \le x_{2}$ if and only if $f(x_{1}) \le f(x_{2})$.
- The [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order) on the [Cartesian product](wikipedia://en/24104095) of a family of totally ordered sets, [indexed](wikipedia://en/393055) by a [well ordered set](wikipedia://en/33456), is itself a total order.
- The set of [real numbers](https://en.wikipedia.org/wiki/Real_numbers) ordered by the usual "less than or equal to" (≤) or "greater than or equal to" (≥) relations is totally ordered. Hence each subset of the real numbers is totally ordered, such as the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), [integers](https://en.wikipedia.org/wiki/Integers), and [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers). Each of these can be shown to be the unique (up to an [order isomorphism](wikipedia://en/23916899)) "initial example" of a totally ordered set with a certain property, (here, a total order $A$ is *initial* for a property, if, whenever $B$ has the property, there is an order isomorphism from $A$ to a subset of $B$):[^o18]
  - The natural numbers form an initial non-empty totally ordered set with no [upper bound](https://en.wikipedia.org/wiki/Upper_bound).
  - The integers form an initial non-empty totally ordered set with neither an upper nor a [lower bound](https://en.wikipedia.org/wiki/Lower_bound).
  - The rational numbers form an initial totally ordered set which is [dense](wikipedia://en/23523594) in the real numbers. Moreover, the reflexive reduction \< is a [dense order](wikipedia://en/6320997) on the rational numbers.
  - The real numbers form an initial unbounded totally ordered set that is [connected](wikipedia://en/87141) in the [order topology](wikipedia://en/213650) (defined below).
- [Ordered fields](wikipedia://en/22430) are totally ordered by definition. They include the rational numbers and the real numbers. Every ordered field contains an ordered subfield that is isomorphic to the rational numbers. Any *[Dedekind-complete](https://en.wikipedia.org/wiki/Dedekind-complete)* ordered field is isomorphic to the real numbers.
- The letters of the alphabet ordered by the standard [dictionary order](https://en.wikipedia.org/wiki/Alphabetical_order), e.g., $A < B < C$ etc., is a strict total order.

:::

## Chains {#Chains}

The term **chain** is sometimes defined as a synonym for a totally ordered set, but it is generally used for referring to a [subset](wikipedia://en/27631) of a [partially ordered set](wikipedia://en/23572) that is totally ordered for the induced order.[^n1][^o22] Typically, the partially ordered set is a set of subsets of a given set that is ordered by inclusion, and the term is used for stating properties of the set of the chains. This high number of nested levels of sets explains the usefulness of the term.

A common example of the use of *chain* for referring to totally ordered subsets is [Zorn's lemma](wikipedia://en/51442) which asserts that, if every chain in a partially ordered set $X$ has an upper bound in $X$, then $X$ contains at least one maximal element.[^o23] Zorn's lemma is commonly used with $X$ being a set of subsets; in this case, the upper bound is obtained by proving that the union of the elements of a chain in $X$ is in $X$. This is the way that is generally used to prove that a [vector space](wikipedia://en/32370) has [Hamel bases](https://en.wikipedia.org/wiki/Hamel_bases) and that a [ring](wikipedia://en/48404) has [maximal ideals](wikipedia://en/48164).

In some contexts, the chains that are considered are order isomorphic to the natural numbers with their usual order or its [opposite order](wikipedia://en/3941020). In this case, a chain can be identified with a [monotone sequence](https://en.wikipedia.org/wiki/Monotone_sequence), and is called an **ascending chain** or a **descending chain**, depending whether the sequence is increasing or decreasing.[^o24]

A partially ordered set has the [descending chain condition](https://en.wikipedia.org/wiki/Descending_chain_condition) if every descending chain eventually stabilizes.[^o25] For example, an order is [well founded](https://en.wikipedia.org/wiki/Well-founded_order) if it has the descending chain condition. Similarly, the [ascending chain condition](wikipedia://en/3189) means that every ascending chain eventually stabilizes. For example, a [Noetherian ring](wikipedia://en/56129) is a ring whose [ideals](wikipedia://en/25977) satisfy the ascending chain condition.

In other contexts, only chains that are [finite sets](wikipedia://en/11742) are considered. In this case, one talks of a *finite chain*, often shortened as a *chain*. In this case, the **length** of a chain is the number of inequalities (or set inclusions) between consecutive elements of the chain; that is, the number minus one of elements in the chain.[^o26] Thus a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) is a chain of length zero, and an [ordered pair](wikipedia://en/22362) is a chain of length one. The [dimension](https://en.wikipedia.org/wiki/Dimension_theory) of a space is often defined or characterized as the maximal length of chains of subspaces. For example, the [dimension of a vector space](https://en.wikipedia.org/wiki/Dimension_of_a_vector_space) is the maximal length of chains of [linear subspaces](wikipedia://en/56357), and the [Krull dimension](wikipedia://en/56079) of a [commutative ring](wikipedia://en/61346) is the maximal length of chains of [prime ideals](wikipedia://en/24928).

"Chain" may also be used for some totally ordered subsets of [structures](wikipedia://en/1809181) that are not partially ordered sets. An example is given by [regular chains](wikipedia://en/18814716) of polynomials. Another example is the use of "chain" as a synonym for a [walk](https://en.wikipedia.org/wiki/Walk_%28graph_theory%29) in a [graph](wikipedia://en/325806).

:::

## Further concepts {#Further_concepts}

### Lattice theory {#Lattice_theory}

One may define a totally ordered set as a particular kind of [lattice](wikipedia://en/469304), namely one in which we have

$\{a\vee b, a\wedge b\} = \{a, b\}$ for all *a*, *b*.

We then write *a* ≤ *b* [if and only if](wikipedia://en/14922) $a = a\wedge b$. Hence a totally ordered set is a [distributive lattice](wikipedia://en/310883).

::: {#o30 .pointer-item cue=pointer name="Finite total order"}

### Finite total orders {#Finite_total_orders}

A simple [counting](wikipedia://en/275768) argument will verify that any non-empty finite totally ordered set (and hence any non-empty subset thereof) has a least element. Thus every finite total order is in fact a [well order](https://en.wikipedia.org/wiki/Well_order). Either by direct proof or by observing that every well order is [order isomorphic](https://en.wikipedia.org/wiki/Order_isomorphic) to an [ordinal](wikipedia://en/26547932) one may show that every finite total order is [order isomorphic](https://en.wikipedia.org/wiki/Order_isomorphic) to an [initial segment](https://en.wikipedia.org/wiki/Initial_segment) of the natural numbers ordered by \<. In other words, a total order on a set with *k* elements induces a bijection with the first *k* natural numbers. Hence it is common to index finite total orders or well orders with [order type](wikipedia://en/4499021) ω by natural numbers in a fashion which respects the ordering (either starting with zero or with one).

:::

### Category theory {#Category_theory}

Totally ordered sets form a [full subcategory](wikipedia://en/310959) of the [category](wikipedia://en/53759) of [partially ordered sets](wikipedia://en/23572), with the [morphisms](wikipedia://en/27716891) being maps which respect the orders, i.e. maps *f* such that if *a* ≤ *b* then *f*(*a*) ≤ *f*(*b*).

A [bijective](wikipedia://en/3942) [map](wikipedia://en/516931) between two totally ordered sets that respects the two orders is an [isomorphism](wikipedia://en/14828) in this category.

### Order topology {#Order_topology}

For any totally ordered set $X$ we can define the *[open intervals](wikipedia://en/49172)*

- $$(a, b) = \{x\mid a < x\text{ and } x < b\},$$
- $$(-\infty, b) = \{x\mid x < b\},$$
- $(a, \infty) = \{x\mid a < x\}$, and
- $$(-\infty, \infty) = X.$$

We can use these open intervals to define a [topology](wikipedia://en/29954) on any ordered set, the [order topology](wikipedia://en/213650).

When more than one order is being used on a set one talks about the order topology induced by a particular order. For instance if **N** is the natural numbers, \< is less than and > greater than we might refer to the order topology on **N** induced by \< and the order topology on **N** induced by > (in this case they happen to be identical but will not in general).

The order topology induced by a total order may be shown to be hereditarily [normal](wikipedia://en/48629).

::: {#o34 .pointer-item cue=pointer name="Complete total order"}

### Completeness {#Completeness}

A totally ordered set is said to be **[complete](wikipedia://en/549445)** if every nonempty subset that has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound), has a [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound). For example, the set of [real numbers](wikipedia://en/20646438) **R** is complete but the set of [rational numbers](wikipedia://en/19727024) **Q** is not. In other words, the various concepts of [completeness](wikipedia://en/549445) (not to be confused with being "total") do not carry over to [restrictions](wikipedia://en/3931). For example, over the [real numbers](wikipedia://en/20646438) a property of the relation ≤ is that every [non-empty](wikipedia://en/9566) subset *S* of **R** with an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) in **R** has a [least upper bound](https://en.wikipedia.org/wiki/Supremum) (also called supremum) in **R**. However, for the rational numbers this supremum is not necessarily rational, so the same property does not hold on the restriction of the relation ≤ to the rational numbers.

There are a number of results relating properties of the order topology to the completeness of X:

- If the order topology on *X* is connected, *X* is complete.
- *X* is connected under the order topology if and only if it is complete and there is no *gap* in *X* (a gap is two points *a* and *b* in *X* with *a* \< *b* such that no *c* satisfies *a* \< *c* \< *b*.)
- *X* is complete if and only if every bounded set that is closed in the order topology is compact.

A totally ordered set (with its order topology) which is a [complete lattice](wikipedia://en/44777) is [compact](wikipedia://en/6042). Examples are the closed intervals of real numbers, e.g. the [unit interval](wikipedia://en/49324) \[0,1\], and the [affinely extended real number system](https://en.wikipedia.org/wiki/Affinely_extended_real_number_system) (extended real number line). There are order-preserving [homeomorphisms](wikipedia://en/13660) between these examples.

:::

### Sums of orders {#Sums_of_orders}

For any two disjoint total orders $(A_1,\le_1)$ and $(A_2,\le_2)$, there is a natural order $\le_+$ on the set $A_1\cup A_2$, which is called the sum of the two orders or sometimes just $A_1+A_2$:

For $x,y\in A_1\cup A_2$, $x\le_+ y$ holds if and only if one of the following holds:

1. $x,y\in A_1$ and $x\le_1 y$
1. $x,y\in A_2$ and $x\le_2 y$
1. $x\in A_1$ and $y\in A_2$

Intuitively, this means that the elements of the second set are added on top of the elements of the first set.

More generally, if $(I,\le)$ is a totally ordered index set, and for each $i\in I$ the structure $(A_i,\le_i)$ is a linear order, where the sets $A_i$ are pairwise disjoint, then the natural total order on $\bigcup_i A_i$ is defined by

For $x,y\in \bigcup_{i\in I} A_i$, $x\le y$ holds if:

1. Either there is some $i\in I$ with $x\le_i y$
1. or there are some $i<j$ in $I$ with $x\in A_i$, $y\in A_j$

### Decidability {#Decidability}

The [first-order](wikipedia://en/10983) theory of total orders is [decidable](wikipedia://en/913118), i.e. there is an algorithm for deciding which first-order statements hold for all total orders. Using interpretability in [S2S](wikipedia://en/72252525), the [monadic second-order](wikipedia://en/14650395) theory of [countable](wikipedia://en/6026) total orders is also decidable.[^o37]

## Orders on the Cartesian product of totally ordered sets {#Orders_on_the_Cartesian_product_of_totally_ordered_sets}

There are several ways to take two totally ordered sets and extend to an order on the [Cartesian product](wikipedia://en/24104095), though the resulting order may only be [partial](https://en.wikipedia.org/wiki/Partial_order). Here are three of these possible orders, listed such that each order is stronger than the next:

- [Lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order): (*a*,*b*) ≤ (*c*,*d*) if and only if *a* \< *c* or (*a* = *c* and *b* ≤ *d*). This is a total order.
- (*a*,*b*) ≤ (*c*,*d*) if and only if *a* ≤ *c* and *b* ≤ *d* (the [product order](wikipedia://en/1956306)). This is a partial order.
- (*a*,*b*) ≤ (*c*,*d*) if and only if (*a* \< *c* and *b* \< *d*) or (*a* = *c* and *b* = *d*) (the reflexive closure of the [direct product](wikipedia://en/8887#Direct_product_of_binary_relations) of the corresponding strict total orders). This is also a partial order.

Each of these orders extends the next in the sense that if we have *x* ≤ *y* in the product order, this relation also holds in the lexicographic order, and so on. All three can similarly be defined for the Cartesian product of more than two sets.

Applied to the [vector space](wikipedia://en/32370) **R**<sup>*n*</sup>, each of these make it an [ordered vector space](wikipedia://en/8099221).

See also [examples of partially ordered sets](wikipedia://en/23572#Examples).

A real function of *n* real variables defined on a subset of **R**<sup>*n*</sup> [defines a strict weak order and a corresponding total preorder](https://en.wikipedia.org/wiki/Strict_weak_ordering#Function) on that subset.

## Related structures {#Related_structures}

A binary relation that is antisymmetric, transitive, and reflexive (but not necessarily total) is a [partial order](https://en.wikipedia.org/wiki/Partial_order).

A [group](wikipedia://en/19447) with a compatible total order is a [totally ordered group](https://en.wikipedia.org/wiki/Totally_ordered_group).

There are only a few nontrivial structures that are (interdefinable as) reducts of a total order. Forgetting the orientation results in a [betweenness relation](https://en.wikipedia.org/wiki/Betweenness_relation). Forgetting the location of the ends results in a [cyclic order](wikipedia://en/434673). Forgetting both data results use of [point-pair separation](wikipedia://en/68571139) to distinguish, on a circle, the two intervals determined by a point-pair.[^o40]
