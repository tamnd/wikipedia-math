# Uncountable set

::: {#o1 .subject cue=lead name="Uncountable set"}

In [mathematics](wikipedia://en/18831), an **uncountable set**, informally, is an [infinite set](wikipedia://en/142679) that contains too many [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) to be [countable](wikipedia://en/6026). The uncountability of a set is closely related to its [cardinal number](wikipedia://en/6173): a set is uncountable if its cardinal number is larger than [aleph-null](wikipedia://en/293961), the cardinality of the [natural numbers](wikipedia://en/21474).

:::

Examples of uncountable sets include the set $\mathbb{R}$ of all [real numbers](wikipedia://en/20646438) and the set of all subsets of the natural numbers.

::: {#o3 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

There are many equivalent characterizations of uncountability. A set $X$ is uncountable if and only if any of the following conditions hold:

- There is no [injective function](wikipedia://en/45196) (hence no [bijection](wikipedia://en/3942)) from $X$ to the set of natural numbers.
- $X$ is nonempty and for every ω-[sequence](wikipedia://en/27838) of elements of $X$, there exists at least one element of X not included in it. That is, $X$ is nonempty and there is no [surjective function](wikipedia://en/27873) from the natural numbers to $X$.
- The [cardinality](wikipedia://en/6174) of $X$ is neither finite nor equal to $\aleph_0$ ([aleph-null](wikipedia://en/293961)).
- The set $X$ has cardinality strictly greater than $\aleph_0$.

The first three of these characterizations can be proved equivalent in [Zermelo–Fraenkel set theory](wikipedia://en/152214) without the [axiom of choice](wikipedia://en/840), but the equivalence of the third and fourth cannot be proved without additional choice principles.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If an uncountable set $X$ is a subset of set $Y$, then $Y$ is uncountable.

:::

## Examples {#Examples}

The best known example of an uncountable set is the set $\mathbb{R}$ of all [real numbers](wikipedia://en/20646438); [Cantor's diagonal argument](wikipedia://en/51426) shows that this set is uncountable. The diagonalization proof technique can also be used to show that several other sets are uncountable, such as the set of all infinite [sequences](wikipedia://en/27838) of [natural numbers](wikipedia://en/21474) $\mathbb{N}$ (see: ), and the [set of all subsets](https://en.wikipedia.org/wiki/Powerset) of the set of natural numbers. The cardinality of $\mathbb{R}$ is often called the [cardinality of the continuum](wikipedia://en/1574901), and denoted by $\mathfrak{c}$, or $2^{\aleph_0}$[^o8], or $\beth_1$ ([beth-one](wikipedia://en/1574901)).

The [Cantor set](wikipedia://en/6172) is an uncountable [subset](wikipedia://en/27631) of $\mathbb{R}$. The Cantor set is a [fractal](wikipedia://en/10913) and has [Hausdorff dimension](wikipedia://en/14294) greater than zero but less than one ($\mathbb{R}$ has dimension one). This is an example of the following fact: any subset of $\mathbb{R}$ of Hausdorff dimension strictly greater than zero must be uncountable.

Another example of an uncountable set is the set of all [functions](wikipedia://en/185427) from $\mathbb{R}$ to $\mathbb{R}$. This set is even "more uncountable" than $\mathbb{R}$ in the sense that the cardinality of this set is $\beth_2$ ([beth two](https://en.wikipedia.org/wiki/Beth_two)), which is larger than $\beth_1$.

A more abstract example of an uncountable set is the set of all countable [ordinal numbers](wikipedia://en/26547932), denoted by Ω or ω<sub>1</sub>.[^o9] The cardinality of Ω is denoted $\aleph_1$ ([aleph-one](wikipedia://en/293961)). It can be shown, using the [axiom of choice](wikipedia://en/840), that $\aleph_1$ is the *smallest* uncountable cardinal number. Thus either $\beth_1$, the cardinality of the reals, is equal to $\aleph_1$ or it is strictly larger. [Georg Cantor](wikipedia://en/12216) was the first to propose the question of whether $\beth_1$ is equal to $\aleph_1$. In 1900, [David Hilbert](wikipedia://en/8302) posed this question as the first of his [23 problems](wikipedia://en/154584). The statement that $\aleph_1 = \beth_1$ is now called the [continuum hypothesis](wikipedia://en/5705), and is known to be independent of the [Zermelo–Fraenkel axioms](https://en.wikipedia.org/wiki/Zermelo–Fraenkel_axioms) for [set theory](wikipedia://en/27553) (including the [axiom of choice](wikipedia://en/840)).

:::

::: {#o11 .statement kind=statement/axiom cue=named-heading name="Without the axiom of choice"}

## Without the axiom of choice {#Without_the_axiom_of_choice}

Without the [axiom of choice](wikipedia://en/840), there might exist cardinalities [incomparable](wikipedia://en/3834818) to $\aleph_0$ (namely, the cardinalities of [Dedekind-finite](https://en.wikipedia.org/wiki/Dedekind-finite) infinite sets). Sets of these cardinalities satisfy the first three characterizations above, but not the fourth characterization. Since these sets are not larger than the natural numbers in the sense of cardinality, some may not want to call them uncountable.

If the axiom of choice holds, the following conditions on a cardinal $\kappa$ are equivalent:

- $$\kappa \nleq \aleph_0;$$
- $\kappa > \aleph_0;$ and
- $\kappa \geq \aleph_1$, where $\aleph_1 = |\omega_1 |$ and $\omega_1$ is the least [initial ordinal](https://en.wikipedia.org/wiki/Initial_ordinal) greater than $\omega.$

However, these may all be different if the axiom of choice fails. So it is not obvious which one is the appropriate generalization of "uncountability" when the axiom fails. It may be best to avoid using the word in this case and specify which of these one means.
