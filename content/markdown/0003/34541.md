# Zero-based numbering

::: {#o1 .subject cue=lead name="Zero-based numbering"}

**Zero-based numbering** is a way of [numbering](https://en.wikipedia.org/wiki/Numbering) in which the initial element of a [sequence](wikipedia://en/27838) is assigned the [index](wikipedia://en/23624339) 0, rather than the index 1 as is typical in everyday non-mathematical or non-programming circumstances. Under zero-based numbering, the initial element is sometimes termed the *[zeroth](wikipedia://en/34513)* element,[^o2] rather than the *first* element; *zeroth* is a [coined](https://en.wikipedia.org/wiki/Word_coinage) word for the [ordinal number](https://en.wikipedia.org/wiki/Ordinal_number_%28linguistics%29) zero. In some cases, an object or value that does not (originally) belong to a given sequence, but which could be naturally placed before its initial element, may be termed the zeroth element. There is no wide agreement regarding the correctness of using zero as an ordinal (nor regarding the use of the term *zeroth*), as it creates ambiguity for all subsequent elements of the sequence when lacking context.

:::

Numbering sequences starting at 0 is quite common in mathematics notation,Use in Mathematics in particular in [combinatorics](wikipedia://en/5170), though programming languages for mathematics usually index from 1.[^o3][^o4][^o5] In [computer science](https://en.wikipedia.org/wiki/Computer_science), [array](https://en.wikipedia.org/wiki/Array_data_structure) indices usually start at 0 in modern programming languages, so computer programmers might use *zeroth* in situations where others might use *first*, and so forth. In some mathematical contexts, zero-based numbering can be used without confusion, when ordinal forms have well established meaning with an obvious candidate to come before *first*; for instance, a *zeroth derivative* of a function is the function itself, obtained by [differentiating](wikipedia://en/7921) zero times. Such usage corresponds to naming an element not properly belonging to the sequence but preceding it: the zeroth derivative is not really a derivative at all. However, just as the *first derivative* precedes the *second derivative*, so also does the *zeroth derivative* (or the original function itself) precede the *first derivative*.

## Computer programming {#Computer_programming}

### Origin {#Origin}

[Martin Richards](https://en.wikipedia.org/wiki/Martin_Richards_%28computer_scientist%29), creator of the [BCPL](https://en.wikipedia.org/wiki/BCPL) language (a precursor of [C](https://en.wikipedia.org/wiki/C_%28programming_language%29)), designed arrays initiating at 0 as the natural position to start accessing the array contents in the language, since the value of a [pointer](https://en.wikipedia.org/wiki/Pointer_%28computer_programming%29) *p* used as an address accesses the position *p* + 0 in memory.[^o8][^o9] BCPL was first compiled for the [IBM&nbsp;7094](https://en.wikipedia.org/wiki/IBM&nbsp;7094); the language introduced no [run-time](https://en.wikipedia.org/wiki/Run_time_%28program_lifecycle_phase%29) [indirection lookups](https://en.wikipedia.org/wiki/Indirection_lookup), so the indirection optimization provided by these arrays was done at compile time.[^o9] The optimization was nevertheless important.[^o9][^o10]

In 1982 [Edsger W. Dijkstra](https://en.wikipedia.org/wiki/Edsger_W._Dijkstra) in his pertinent note *Why numbering should start at zero*[^o15] argued that arrays subscripts should start at zero as that's the most [natural number](wikipedia://en/21474). Discussing possible designs of array ranges by enclosing them in a chained inequality, combining sharp and standard inequalities to four possibilities, demonstrating that to his conviction zero-based arrays are best represented by non-overlapping index ranges, which start at zero, alluding to [open, half-open and closed intervals](wikipedia://en/49172#Definitions) as with the real numbers. Dijkstra's criteria for preferring this convention are in detail that it represents empty sequences in a more natural way (*a* ≤ *i* \< *a* ?) than closed "intervals" (*a* ≤ *i* ≤ (*a* − 1) ?), and that with half-open "intervals" of naturals, the length of a sub-sequence equals the upper minus the lower bound (*a* ≤ *i* \< *b* gives (*b* − *a*) possible values for *i*, with *a*, *b*, *i* all integers).

### Usage in programming languages {#Usage_in_programming_languages}

This usage follows from design choices embedded in many influential [programming languages](wikipedia://en/23015), including [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29), and [Lisp](https://en.wikipedia.org/wiki/Lisp_%28programming_language%29). In these three, sequence types (C arrays, Java arrays and lists, and Lisp lists and vectors) are indexed beginning with the zero subscript. Particularly in C, where arrays are closely tied to [pointer](https://en.wikipedia.org/wiki/Pointer_%28computer_programming%29) arithmetic, this makes for a simpler implementation: the subscript refers to an offset from the starting position of an array, so the first element has an offset of zero.

Referencing memory by an address and an offset is represented directly in [computer hardware](https://en.wikipedia.org/wiki/Computer_hardware) on virtually all computer architectures, so this design detail in C makes compilation easier, at the cost of some human factors. In this context using "zeroth" as an ordinal is not strictly correct, but a widespread habit in this profession. Some programming languages, such as [Fortran](https://en.wikipedia.org/wiki/Fortran) or [COBOL](https://en.wikipedia.org/wiki/COBOL), have array subscripts starting with one, because they were meant as [high-level programming languages](https://en.wikipedia.org/wiki/High-level_programming_language), and as such they had to have a correspondence to the usual [ordinal numbers](https://en.wikipedia.org/wiki/Ordinal_number_%28linguistics%29) which predate the [invention of the zero](wikipedia://en/34513) by a long time. And some programming languages, e.g., [Ada](https://en.wikipedia.org/wiki/Ada_%28programming_language%29), [ALGOL 60](https://en.wikipedia.org/wiki/ALGOL_60), [PL/I](https://en.wikipedia.org/wiki/PL/I), allow an arbitrary lower bound for each index.

[Pascal](https://en.wikipedia.org/wiki/Pascal_%28programming_language%29) allows the range of an array to be of any ordinal type (including enumerated types) and Ada allows any discrete subtype. [APL](https://en.wikipedia.org/wiki/APL_%28programming_language%29) allows setting the index origin to 0 or 1 during runtime programmatically.[^o12][^o13] Some more recent languages, such as [Lua](https://en.wikipedia.org/wiki/Lua) and [Visual Basic](https://en.wikipedia.org/wiki/Visual_Basic), have adopted the same convention for the same reason.

Zero is the lowest unsigned integer value, one of the most fundamental types in programming and hardware design. In computer science, [zero](https://en.wikipedia.org/wiki/0_%28number%29) is thus often used as the base case for many kinds of numerical [recursion](wikipedia://en/25407). Proofs and other sorts of mathematical reasoning in computer science often begin with zero. For these reasons, in computer science it is not unusual to number from zero rather than one.

If an array is used to represent a cycle, it is convenient to obtain the index with a [modulo function](https://en.wikipedia.org/wiki/Modulo_operator), which can result in zero.

### Numerical properties {#Numerical_properties}

With zero-based numbering, a range can be expressed as the half-open [interval](wikipedia://en/49172), $[0, n)$, as opposed to the closed interval, $[1, n]$. Empty ranges, which often occur in algorithms, are tricky to express with a closed interval without resorting to obtuse conventions like $[1, 0]$. Because of this property, zero-based indexing potentially reduces [off-by-one](https://en.wikipedia.org/wiki/Off-by-one_error) and [fencepost errors](https://en.wikipedia.org/wiki/Fencepost_error).[^o15] On the other hand, the repeat count $n$ is calculated in advance, making the use of counting from 0 to $n - 1$ (inclusive) less intuitive. Some authors prefer one-based indexing, as it corresponds more closely to how entities are indexed in other contexts.[^o16]

Another property of this convention is in the use of [modular arithmetic](wikipedia://en/20087) as implemented in modern computers. Usually, the [modulo function](https://en.wikipedia.org/wiki/Modulo_operation) maps any integer modulo $N$ to one of the numbers $0, 1, 2, ..., N - 1$, where $N \ge 1$. Because of this, many formulas in algorithms (such as that for calculating hash table indices) can be elegantly expressed in code using the modulo operation when array indices start at zero.

Pointer operations can also be expressed more elegantly on a zero-based index due to the underlying address/offset logic mentioned above. To illustrate, suppose $a$ is the [memory address](https://en.wikipedia.org/wiki/Memory_address) of the first element of an array, and $i$ is the index of the desired element. To compute the address of the desired element, if the index numbers count from 1, the desired address is computed by this expression:

$$a + s \times (i-1),$$

where $s$ is the size of each element. In contrast, if the index numbers count from 0, the expression becomes

$$a + s \times i.$$

This simpler expression is more efficient to compute at [run time](https://en.wikipedia.org/wiki/Run_time_%28program_lifecycle_phase%29).

However, a language wishing to index arrays from 1 could adopt the convention that every array address is represented by $a' = a - s$; that is, rather than using the address of the first array element, such a language would use the address of a fictitious element located immediately before the first actual element. The indexing expression for a 1-based index would then be

$$a' + s \times i.$$

Hence, the efficiency benefit at run time of zero-based indexing is not inherent, but is an artifact of the decision to represent an array with the address of its first element rather than the address of the fictitious zeroth element. However, the address of that fictitious element could very well be the address of some other item in memory not related to the array.

Superficially, the fictitious element doesn't scale well to multidimensional arrays. Indexing multidimensional arrays from zero makes a naive (contiguous) conversion to a linear address space (systematically varying one index after the other) look simpler than when indexing from one. For instance, when mapping the three-dimensional array $A[P][N][M]$ to a linear array $L[M\cdot N\cdot P]$, both with $M \cdot N \cdot P$ elements, the index $r$ in the linear array to access a specific element with $L[r] = A[z][y][x]$ in zero-based indexing, i.e. $[0 \le x < P]$, $[0 \le y < N]$, $[0 \le z < M]$, and $[0 \le r < M \cdot N \cdot P]$, is calculated by

$$r = z \cdot M \cdot N + y \cdot M + x.$$

Organizing all arrays with 1-based indices ($[1 \le x' \le P]$, $[1 \le y' \le N]$, $[1 \le z' \le M]$, $[1 \le r' \le M \cdot N \cdot P]$), and assuming an analogous arrangement of the elements, gives

$$r' = (z'-1) \cdot M \cdot N + (y'-1) \cdot M + (x'-0)$$

to access the same element, which arguably looks more complicated. Of course, $r' = r + 1,$ since $[z = z' - 1],$ $[y = y' - 1],$ and $[x = x' - 1].$ A simple and everyday-life example is [positional notation](wikipedia://en/437052), which the invention of the zero made possible. In positional notation, tens, hundreds, thousands and all other digits start with zero, only units start at one.[^o17]

This situation can lead to some confusion in terminology. In a zero-based indexing scheme, the first element is "element number zero"; likewise, the twelfth element is "element number eleven". Therefore, an analogy from the ordinal numbers to the quantity of objects numbered appears; the highest index of $n$ objects will be $n - 1$, and it refers to the $n$th element. For this reason, the first element is sometimes referred to as the [zeroth](https://en.wikipedia.org/wiki/Array_data_structure) element, in an attempt to avoid confusion.

## Science {#Science}

In [mathematics](wikipedia://en/18831), many sequences of numbers or of [polynomials](https://en.wikipedia.org/wiki/Polynomials) are indexed by nonnegative integers, for example, the [Bernoulli numbers](https://en.wikipedia.org/wiki/Bernoulli_numbers) and the [Bell numbers](https://en.wikipedia.org/wiki/Bell_numbers).

In both [mechanics](https://en.wikipedia.org/wiki/Mechanics) and [statistics](wikipedia://en/26685), the zeroth [moment](wikipedia://en/368684) is defined, representing total mass in the case of physical [density](https://en.wikipedia.org/wiki/Density), or total probability, i.e. one, for a [probability distribution](wikipedia://en/23543).

The *[zeroth law of thermodynamics](wikipedia://en/262861)* was formulated after the first, second, and third laws, but considered more fundamental, thus its name.

In biology, an organism is said to have zero-order intentionality if it shows "no intention of anything at all". This would include a situation where the organism's genetically predetermined phenotype results in a fitness benefit to itself, because it did not "intend" to express its genes.[^o19] In the similar sense, a computer may be considered from this perspective a zero-order intentional entity, as it does not "intend" to express the code of the programs it runs.[^o20]

In biological or medical experiments, the first day of an experiment is often numbered as day 0.[^o21]

Patient zero (or [index case](wikipedia://en/6064646)) is the initial [patient](https://en.wikipedia.org/wiki/Patient) in the [population sample](https://en.wikipedia.org/wiki/Sample_%28statistics%29) of an [epidemiological](wikipedia://en/66997) investigation.

## Other fields {#Other_fields}

A familiar use of zero-based numbering for people of most cultures is age: a baby is zero years old for the first year of their life, and one year old at their first birthday a year later. By contrast, many types of [East Asian age reckoning](https://en.wikipedia.org/wiki/East_Asian_age_reckoning) are one-based, assigning a newborn baby an age of one.[^o23]

In *[The Remaining Signs of Past Centuries](https://en.wikipedia.org/wiki/The_Remaining_Signs_of_Past_Centuries)*,[^o24] [Al-Biruni](https://en.wikipedia.org/wiki/Al-Biruni) numbered the years of the [Metonic cycle](https://en.wikipedia.org/wiki/Metonic_cycle) from 0 to 18.

The [year zero](https://en.wikipedia.org/wiki/Year_zero) does not exist in the widely used [Gregorian calendar](https://en.wikipedia.org/wiki/Gregorian_calendar) or in its predecessor, the [Julian calendar](https://en.wikipedia.org/wiki/Julian_calendar). Under those systems, the year [1&nbsp;BC](https://en.wikipedia.org/wiki/1&nbsp;BC) is followed by [AD 1](https://en.wikipedia.org/wiki/1_AD). However, there is a year zero in [astronomical year numbering](https://en.wikipedia.org/wiki/Astronomical_year_numbering) (where it coincides with the Julian year 1 BC) and in [ISO 8601:2004](https://en.wikipedia.org/wiki/ISO_8601) (where it coincides with the Gregorian year 1 BC), as well as in all [Buddhist](https://en.wikipedia.org/wiki/Buddhist_calendar) and [Hindu calendars](https://en.wikipedia.org/wiki/Hindu_calendar).

In many countries, the [ground floor](https://en.wikipedia.org/wiki/Storey#European_scheme_2) in buildings is considered as floor number 0 rather than as the "1st floor", the naming convention usually found in the United States of America. This makes a consistent set with underground floors marked with negative numbers.

While the ordinal of 0 mostly finds use in communities directly connected to mathematics, physics, and computer science, there are also instances in classical music. The composer [Anton Bruckner](https://en.wikipedia.org/wiki/Anton_Bruckner) regarded his early *Symphony in D minor* to be unworthy of including in the canon of his works, and he wrote gilt nicht ("doesn't count") on the score and a circle with a crossbar, intending it to mean "invalid". But posthumously, this work came to be known as [*Symphony No. 0 in D minor*](https://en.wikipedia.org/wiki/Symphony_No._0_%28Bruckner%29), even though it was actually written after [*Symphony No. 1 in C minor*](https://en.wikipedia.org/wiki/Symphony_No._1_%28Bruckner%29). There is an even earlier *Symphony in F minor* of Bruckner's, which is sometimes called [*No. 00*](https://en.wikipedia.org/wiki/Symphony_No._00_%28Bruckner%29). The Russian composer [Alfred Schnittke](https://en.wikipedia.org/wiki/Alfred_Schnittke) also wrote a [Symphony No. 0](https://en.wikipedia.org/wiki/Symphony_No._0_%28Schnittke%29).

In some universities, including Oxford and Cambridge, "week 0" or occasionally "noughth week" refers to the week before the first week of lectures in a term. In Australia, some universities refer to this as "O week", which serves as a pun on "[orientation week](https://en.wikipedia.org/wiki/Orientation_week)". As a parallel, the introductory weeks at university educations in [Sweden](https://en.wikipedia.org/wiki/Sweden) are generally called nollning (zeroing).

The [United States Air Force](https://en.wikipedia.org/wiki/United_States_Air_Force) starts basic training each Wednesday, and the first week (of eight) is considered to begin with the following Sunday. The four days before that Sunday are often referred to as "zero week".

[24-hour clocks](https://en.wikipedia.org/wiki/24-hour_clock) and the international standard [ISO&nbsp;8601](https://en.wikipedia.org/wiki/ISO&nbsp;8601) use 0 to denote the first (zeroth) hour of the day, consistent with using the 0 to denote the first (zeroth) minute of the hour and the first (zeroth) second of the minute. Also, the [12-hour clocks](https://en.wikipedia.org/wiki/12-hour_clock) used in [Japan](https://en.wikipedia.org/wiki/Date_and_time_notation_in_Japan) use 0 to denote the hour immediately after midnight and noon in contrast to 12 used elsewhere, in order to avoid confusion [whether 12 a.m. and 12 p.m. represent noon or midnight](https://en.wikipedia.org/wiki/12-hour_clock#Confusion_at_noon_and_midnight).

[Robert Crumb](https://en.wikipedia.org/wiki/Robert_Crumb)'s drawings for the first issue of *[Zap Comix](https://en.wikipedia.org/wiki/Zap_Comix)* were stolen, so he drew a whole new issue, which was published as issue 1. Later he re-inked his photocopies of the stolen artwork and published it as issue 0.

The [Brussels ring](https://en.wikipedia.org/wiki/Brussels_ring) road in Belgium is numbered R0. It was built after the ring road around [Antwerp](https://en.wikipedia.org/wiki/Antwerp), but Brussels (being the capital city) was deemed deserving of a more basic number. Similarly the (unfinished) orbital motorway around [Budapest](https://en.wikipedia.org/wiki/Budapest) in Hungary is called [M0](https://en.wikipedia.org/wiki/M0_motorway).

Zero is sometimes used [in street addresses](https://en.wikipedia.org/wiki/House_numbering), especially in schemes where even numbers are one side of the street and odd numbers on the other. A case in point is [Christ Church](https://en.wikipedia.org/wiki/Christ_Church_%28Cambridge,_Massachusetts%29) on [Harvard Square](https://en.wikipedia.org/wiki/Harvard_Square), whose address is 0 Garden Street.

Formerly in [Formula One](https://en.wikipedia.org/wiki/Formula_One), when a defending world champion did not compete in the following season, the number 1 was not assigned to any driver, but one driver of the world champion team would carry the number 0, and the other, number 2. This did happen both in 1993 and 1994 with [Damon Hill](https://en.wikipedia.org/wiki/Damon_Hill) carrying the number 0 in both seasons, as defending champion [Nigel Mansell](https://en.wikipedia.org/wiki/Nigel_Mansell) quit after 1992, and defending champion [Alain Prost](https://en.wikipedia.org/wiki/Alain_Prost) quit after 1993. However, in 2014 the series moved to drivers carrying career-long personalised numbers, instead of team-allocated numbers, other than the defending champion still having the option to carry number 1. Therefore 0 is no longer used in this scenario. It is not clear if it is available as a driver's chosen number, or whether they must be between 2 and 99, but it has not been used to date under this system.

Some team sports allow 0 to be chosen as a player's [uniform number](https://en.wikipedia.org/wiki/Uniform_number) (in addition to the typical range of 1-99). The NFL voted to allow this from 2023 onwards.

A chronological prequel of a series may be numbered as 0, such as *[Ring&nbsp;0: Birthday](https://en.wikipedia.org/wiki/Ring&nbsp;0:_Birthday)* or *[Zork Zero](https://en.wikipedia.org/wiki/Zork_Zero)*.

The [Swiss Federal Railways](https://en.wikipedia.org/wiki/Swiss_Federal_Railways) number certain classes of rolling stock from zero, for example, [Re 460](https://en.wikipedia.org/wiki/SBB-CFF-FFS_Re_460) 000 to 118.

In the realm of fiction, [Isaac Asimov](https://en.wikipedia.org/wiki/Isaac_Asimov) eventually added a Zeroth Law to his [Three Laws of Robotics](https://en.wikipedia.org/wiki/Three_Laws_of_Robotics), essentially making them four laws.

A standard [roulette](https://en.wikipedia.org/wiki/Roulette) wheel contains the number 0 as well as 1-36. It appears in green, so is classed as neither a "red" nor "black" number for betting purposes. The card game [Uno](https://en.wikipedia.org/wiki/Uno_%28card_game%29) has number cards running from 0 to 9 along with special cards, within each coloured suit.

The [Four Essential Freedoms of Free Software](https://en.wikipedia.org/wiki/Free_software#Definition) are numbered starting from zero. This is for historical reasons: the list originally had only three freedoms, and when the fourth was added it was placed in the zeroth position as it was considered more basic.
