# Quantifier rank

::: {#o1 .subject cue=lead name="Quantifier rank"}

In [mathematical logic](wikipedia://en/19636), the **quantifier rank** of a [formula](https://en.wikipedia.org/wiki/Formula_%28mathematical_logic%29) is the depth of nesting of its [quantifiers](wikipedia://en/43507260). It plays an essential role in [model theory](wikipedia://en/19858).

:::

The quantifier rank is a property of the formula itself (i.e. the expression in a language). Thus two [logically equivalent](wikipedia://en/169324) formulae can have different quantifier ranks, when they express the same thing in different ways.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

### In first-order logic {#In_first-order_logic}

Let $\varphi$ be a [first-order](wikipedia://en/10983) formula. The quantifier rank of $\varphi$, written $\operatorname{qr}(\varphi)$, is defined as:

- $\operatorname{qr}(\varphi) = 0$, if $\varphi$ is atomic.
- $$\operatorname{qr}(\varphi_1 \land \varphi_2) = \operatorname{qr}(\varphi_1 \lor \varphi_2) = \max(\operatorname{qr}(\varphi_1), \operatorname{qr}(\varphi_2)).$$
- $$\operatorname{qr}(\lnot \varphi) = \operatorname{qr}(\varphi).$$
- $$\operatorname{qr}(\exists_x \varphi) = \operatorname{qr}(\varphi) + 1.$$
- $$\operatorname{qr}(\forall_x \varphi) = \operatorname{qr}(\varphi) + 1.$$

**Remarks**

- We write $\operatorname{FO}[n]$ for the set of all [first-order formulas](https://en.wikipedia.org/wiki/First-order_formula) $\varphi$ with $\operatorname{qr}(\varphi) \le n$.
- Relational $\operatorname{FO}[n]$ (without function symbols) is always of finite size, i.e. contains a finite number of formulas.
- In [prenex normal form](wikipedia://en/421068), the quantifier rank of $\varphi$ is exactly the number of quantifiers appearing in $\varphi$.

### In higher-order logic {#In_higher-order_logic}

For [fixed-point logic](wikipedia://en/50026488), with a least fixed-point operator $\operatorname{LFP}$: $\operatorname{qr}([\operatorname{LFP}_\phi]y) = 1 + \operatorname{qr}( \phi )$.

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

- A sentence of quantifier rank 2:

$$\forall x\exists y R(x, y)$$

- A formula of quantifier rank 1:

$$\forall x R(y, x) \wedge \exists x R(x, y)$$

- A formula of quantifier rank 0:

$$R(x, y) \wedge x \neq y$$

- A sentence in [prenex normal form](wikipedia://en/421068) of quantifier rank 3:

$$\forall x \exists y \exists z ((x \neq y \wedge x R y) \wedge (x \neq z \wedge z R x))$$

- A sentence, equivalent to the previous, although of quantifier rank 2:

$$\forall x (\exists y (x \neq y \wedge x R y)) \wedge \exists z (x \neq z \wedge z R x ))$$

:::
