# Half-logistic distribution

::: {#o1 .subject cue=lead name="Half-logistic distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **half-logistic distribution** is a continuous [probability distribution](wikipedia://en/23543)—the distribution of the absolute value of a [random variable](wikipedia://en/25685) following the [logistic distribution](wikipedia://en/542666). That is, for

:::

$$X = |Y| \!$$

where *Y* is a logistic random variable, *X* is a half-logistic random variable.

## Specification {#Specification}

### Cumulative distribution function {#Cumulative_distribution_function}

The [cumulative distribution function](wikipedia://en/5793) (cdf) of the half-logistic distribution is intimately related to the cdf of the logistic distribution. Formally, if *F*(*k*) is the cdf for the logistic distribution, then *G*(*k*) = 2*F*(*k*) − 1 is the cdf of a half-logistic distribution. Specifically,

$$G(k) = \frac{1-e^{-k}}{1+e^{-k}} \text{ for } k\geq 0. \!$$

### Probability density function {#Probability_density_function}

Similarly, the [probability density function](wikipedia://en/43487) (pdf) of the half-logistic distribution is *g*(*k*) = 2*f*(*k*) if *f*(*k*) is the pdf of the logistic distribution. Explicitly,

$$g(k) = \frac{2 e^{-k}}{(1+e^{-k})^2} \text{ for } k\geq 0. \!$$
