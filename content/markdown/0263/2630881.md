# Lightface analytic game

::: {#o1 .subject cue=lead name="Lightface analytic game"}

In [descriptive set theory](wikipedia://en/396619), a **lightface analytic game** is an infinite two-player game of perfect information whose payoff set is a [lightface](https://en.wikipedia.org/wiki/Lightface) [analytic](wikipedia://en/634261) (**Σ${}^{1}$${}_{1}$**) subset of [Baire space](wikipedia://en/200550). The determinacy of all lightface analytic games is equivalent, over [ZFC](https://en.wikipedia.org/wiki/ZFC), to the existence of [0${}^{\#}$](wikipedia://en/248085), a result known as the **Martin–Harrington theorem**.

:::

## Background {#Background}

### Infinite games {#Infinite_games}

The games studied here are [Gale-Stewart games](https://en.wikipedia.org/wiki/Gale-Stewart_game). Two players, conventionally called Player I and Player II, alternate choosing natural numbers, with Player I going first:

Player I chooses *a*${}_{0}$, Player II chooses *a*${}_{1}$, Player I chooses *a*${}_{2}$, ...

After infinitely many rounds, the two players have together produced an infinite sequence (*a*${}_{0}$, *a*${}_{1}$, *a*${}_{2}$, ...) in [Baire space](wikipedia://en/2078245) *ω*${}^{\omega}$ — the set of all infinite sequences of natural numbers equipped with the product of the discrete topology. A payoff set *A* ⊆ *ω*${}^{\omega}$ is fixed in advance; Player I wins if the resulting sequence belongs to *A*, and Player II wins otherwise.

A **strategy** for Player I is a function σ that maps each finite sequence of even length (representing the moves played so far) to a natural number (Player I's next move). A strategy for Player II is defined analogously for sequences of odd length. A strategy is a **winning strategy** if following it guarantees a win regardless of the opponent's play. A game is **[determined](https://en.wikipedia.org/wiki/Determined_game)** if one of the two players has a winning strategy.

### The determinacy hierarchy {#The_determinacy_hierarchy}

Not all infinite games are determined: using the [axiom of choice](wikipedia://en/840) one can construct an undetermined game.[^o5] However, determinacy holds for payoff sets of low descriptive complexity. The classical results form a hierarchy:

::: {#o6 .table cue=table}

| Complexity of payoff set | Determinacy | Reference |
|---|---|---|
| [Open](wikipedia://en/39358) / [closed](wikipedia://en/47279) | Provable in [ZFC](https://en.wikipedia.org/wiki/ZFC) | [Gale–Stewart theorem](https://en.wikipedia.org/wiki/Gale–Stewart_theorem) (1953) |
| [Borel](wikipedia://en/43327) | Provable in ZFC | [Martin](wikipedia://en/15483838) (1975) |
| Lightface Σ${}^{1}$${}_{1}$ (lightface analytic) | Equivalent to existence of 0${}^{\#}$ | Martin–Harrington (1978) |
| Σ${}^{1}$${}_{1}$ (analytic, boldface) | Follows from a [measurable cardinal](wikipedia://en/248102) | Martin (1970) |
| All [projective](https://en.wikipedia.org/wiki/Projective_set) sets | Follows from infinitely many [Woodin cardinals](wikipedia://en/248105) | Martin–Steel, Woodin (1985–88) |

:::

## Lightface versus boldface {#Lightface_versus_boldface}

The [lightface/boldface distinction](wikipedia://en/634233#Lightface_and_boldface_hierarchies) is central to this subject. A set *A* ⊆ *ω*${}^{\omega}$ is **boldface** analytic (**Σ${}^{1}$${}_{1}$**) if it is the projection of a closed set in a product space, equivalently if there exists a tree *T* on *ω* × *ω* such that *A* is the set of first coordinates of infinite branches through *T*. The **lightface** version adds an effectivity constraint: *A* is lightface analytic (**Σ${}^{1}$${}_{1}$**) if *T* can be taken to be a [computable](wikipedia://en/332264) (recursive) subset of (*ω* × *ω*)${}^{<\omega}$.[^o11]

Equivalently, a set is lightface analytic if it is [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable) relative to no oracle — it can be described without any real-number parameters. Boldface analytic sets may require real-number parameters; the lightface class is strictly smaller.

This distinction has a direct consequence for determinacy: boldface analytic determinacy follows from the existence of a [measurable cardinal](wikipedia://en/248102), a relatively strong large-cardinal assumption. Lightface analytic determinacy requires only the weaker assumption that [0${}^{\#}$](wikipedia://en/248085) exists. Conversely, [Leo Harrington](wikipedia://en/5693354) showed that lightface analytic determinacy cannot be proved in ZFC alone, and in fact implies the existence of 0${}^{\#}$.

::: {#o13 .statement kind=statement/theorem cue=named-heading name="The Martin–Harrington theorem"}

## The Martin–Harrington theorem {#The_Martin–Harrington_theorem}

The central result of the subject is: **Theorem** (Martin–Harrington, 1978). The following are equivalent over ZFC:

All lightface analytic games are determined.

[0${}^{\#}$](wikipedia://en/248085) exists.

### Forward direction: 0${}^{\#}$ implies determinacy {#Forward_direction:_0_implies_determinacy}

[Donald A. Martin](wikipedia://en/2270985) proved that if 0${}^{\#}$ exists then all lightface analytic games are determined.[^o15] The key tool is the sequence of [Silver indiscernibles](https://en.wikipedia.org/wiki/Silver_indiscernibles) encoded by 0${}^{\#}$. These indiscernibles provide a uniform way to build winning strategies for lightface analytic games: the computable tree defining the payoff set can be analyzed using the indiscernibles, and the resulting structure allows one to determine which player wins and to explicitly construct a winning strategy.

### Reverse direction: determinacy implies 0${}^{\#}$ {#Reverse_direction:_determinacy_implies_0}

[Leo Harrington](wikipedia://en/5693354) proved the converse in 1978: if all lightface analytic games are determined, then 0${}^{\#}$ exists.[^o17] This direction is considerably harder. Harrington's proof uses the theory of [admissible sets](wikipedia://en/5138993) and [admissible ordinals](wikipedia://en/4635859) (in particular, [Barwise compactness](https://en.wikipedia.org/wiki/Barwise_compactness)) to show that determinacy of a certain lightface analytic game forces the existence of a model of set theory with a non-trivial [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* : *L* → *L*, which is equivalent to the existence of 0${}^{\#}$. A later forcing-free proof of this direction was given by Sami (1999).[^o18]

:::

## 0${}^{\#}$ and the constructible universe {#0_and_the_constructible_universe}

[0${}^{\#}$](wikipedia://en/248085) (zero sharp) is a real number — formally a subset of *ω* — that encodes the complete first-order theory of [Gödel's constructible universe *L*](wikipedia://en/343335) with respect to its [Silver indiscernibles](https://en.wikipedia.org/wiki/Silver_indiscernibles). The Silver indiscernibles are a [club](wikipedia://en/1251559) class of ordinals that are indistinguishable from one another by any first-order formula of set theory with parameters from lower in the indiscernible sequence.

The existence of 0${}^{\#}$ is independent of ZFC. If 0${}^{\#}$ exists then *L* ≠ *V* (the constructible universe is a proper inner model of the true universe), and every uncountable cardinal of *V* is a [measurable cardinal](wikipedia://en/248102) in *L*\[0${}^{\#}$\]. The existence of a measurable cardinal implies that 0${}^{\#}$ exists, but not conversely; 0${}^{\#}$ is a strictly weaker assumption.

## Relativization {#Relativization}

The theorem relativizes to arbitrary reals. For any real *x*, **Π${}^{1}$${}_{1}$(*x*)** determinacy — determinacy of all games whose payoff set is lightface co-analytic relative to *x* as an oracle — is equivalent to the existence of **x${}^{\#}$**, the sharp for the inner model *L*\[*x*\].[^o21] The original Martin–Harrington theorem is the special case *x* = ∅.
