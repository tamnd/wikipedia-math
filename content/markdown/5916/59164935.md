# Tidyverse

::: {#o1 .subject cue=lead name="Tidyverse"}

The **tidyverse** is a collection of [open source](https://en.wikipedia.org/wiki/Open-source_software) [packages](https://en.wikipedia.org/wiki/R_packages) for the [R programming language](wikipedia://en/376707) introduced by [Hadley Wickham](wikipedia://en/41916270)[^o5] and his team that "share an underlying design philosophy, grammar, and data structures" of [tidy data](https://en.wikipedia.org/wiki/Tidy_data).[^o6] Characteristic features of tidyverse packages include extensive use of non-standard evaluation and encouraging [piping](https://en.wikipedia.org/wiki/Pipeline_%28software%29).[^o7][^o8][^o9]

:::

As of November 2018, the tidyverse package and some of its individual packages comprise 5 out of the top 10 most downloaded R packages.[^o10] The tidyverse is the subject of multiple books and papers.[^o11][^o12][^o13][^o14] In 2019, the ecosystem has been published in the *[Journal of Open Source Software](https://en.wikipedia.org/wiki/Journal_of_Open_Source_Software)*.[^o15]

Its syntax has been referred to as "supremely readable",[^o16] and some[^o17] have argued that tidyverse is an effective way to introduce complete beginners to programming, as pedagogically it allows students to quickly begin doing data processing tasks.[^o18][^o17] Moreover, some practitioners have pointed out that data processing tasks are intuitively easier to [chain](https://en.wikipedia.org/wiki/Method_chaining) together with tidyverse compared to Python's equivalent data processing package, [pandas](https://en.wikipedia.org/wiki/Pandas_%28software%29).[^o19] Critics of the tidyverse have argued it promotes tools that are harder to teach and learn than their built-in, base R equivalents and are too dissimilar to some programming languages.[^o20][^o21]

There is an active R community around the tidyverse. For example, there is the [TidyTuesday](wikipedia://en/79503166) social data project organised by the Data Science Learning Community (DSLC),[^o22] where varied real-world datasets are released each week for the community to participate, share, practice, and make learning to work with data easier.[^o23]

The tidyverse principles more generally encourage and help ensure that a universe of streamlined packages, in principle, will help alleviate dependency issues and compatibility with current and future features.[^o24] An example of such a tidyverse principled approach is the pharmaverse, which is a collection of R packages for clinical reporting usage in the [pharmaceutical industry](https://en.wikipedia.org/wiki/Pharmaceutical_industry).[^o25]

## Packages {#Packages}

The core tidyverse packages, which provide functionality to model, transform, and visualize data, include:[^o27]

- tidyr – help transform data specifically into [tidy data](https://en.wikipedia.org/wiki/Tidy_data), a table where each row is a single observation. The value of each observation is given in a column of the table. Variables describing the observation are included as additional columns.
- [ggplot2](wikipedia://en/32380922) – for data visualization
- [dplyr](https://en.wikipedia.org/wiki/Dplyr) – for wrangling and transforming data
- readr – help read in common delimited, text files with data
- purrr - a [functional programming](https://en.wikipedia.org/wiki/Functional_programming) toolkit
- tibble – a modern implementation of the built-in data frame data structure
- stringr – helps to manipulate string data types
- forcats helps to manipulate category data types

Additional packages assist the core collection.[^o28] Other packages based on the tidy data principles are regularly developed, such as tidytext[^o29] for text analysis, tidymodels[^o30] for machine learning, or tidyquant[^o31] for financial operations.
