# Ingleton's inequality

::: {#o1 .subject cue=lead name="Ingleton's inequality"}

In [mathematics](wikipedia://en/18831), **Ingleton's inequality** is an [inequality](wikipedia://en/89489) that is satisfied by the [rank function](wikipedia://en/37123010) of any [representable matroid](https://en.wikipedia.org/wiki/Representable_matroid). In this sense it is a necessary condition for representability of a [matroid](wikipedia://en/244321) over a [finite field](wikipedia://en/11615). For a matroid *M* and its rank function *ρ*, Ingleton's inequality states that for any subsets *X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub> and *X*<sub>4</sub> in the [support](wikipedia://en/381013) of *M*, the inequality

:::

*ρ*(*X*<sub>1</sub>) + *ρ*(*X*<sub>2</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>2</sub>∪*X*<sub>3</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>2</sub>∪*X*<sub>4</sub>) + *ρ*(*X*<sub>3</sub>∪*X*<sub>4</sub>) ≤ *ρ*(*X*<sub>1</sub>∪*X*<sub>2</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>3</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>4</sub>) + *ρ*(*X*<sub>2</sub>∪*X*<sub>3</sub>) + *ρ*(*X*<sub>2</sub>∪*X*<sub>4</sub>)

is satisfied.

[Aubrey William Ingleton](wikipedia://en/43130429), an English mathematician, wrote an important paper in 1969[^o2] in which he surveyed the representability problem in matroids. Although the article is mainly expository, in this paper Ingleton stated and [proved](wikipedia://en/82285) Ingleton's inequality, which has found interesting applications in [information theory](wikipedia://en/14773), [matroid theory](wikipedia://en/244321), and [network coding](https://en.wikipedia.org/wiki/Network_coding).[^o3]

::: {#o5 .statement cue=named-heading name="Importance of inequality"}

## Importance of inequality {#Importance_of_inequality}

There are interesting connections between matroids, the [entropy region](wikipedia://en/17519721) and [group theory](wikipedia://en/41890). Some of those connections are revealed by Ingleton's Inequality.

Perhaps, the more interesting application of Ingleton's inequality concerns the computation of [network coding](https://en.wikipedia.org/wiki/Network_coding) capacities. [Linear coding solutions](wikipedia://en/3084295) are constrained by the inequality and it has an important consequence:

The region of achievable rates using [linear network coding](wikipedia://en/3084295) could be, in some cases, strictly smaller than the region of achievable rates using general network coding.[^o6][^o7][^o8]

## Proof {#Proof}

::: {#o12 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** (Ingleton's inequality):[^o13] Let *M* be a [representable matroid](https://en.wikipedia.org/wiki/Linear_matroid) with rank function *ρ* and let *X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub> and *X*<sub>4</sub> be subsets of the support set of *M*, denoted by the symbol *E*(*M*). Then:

*ρ*(*X*<sub>1</sub>)+*ρ*(*X*<sub>2</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>2</sub>∪*X*<sub>3</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>2</sub>∪*X*<sub>4</sub>) + *ρ*(*X*<sub>3</sub>∪*X*<sub>4</sub>) ≤ *ρ*(*X*<sub>1</sub>∪*X*<sub>2</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>3</sub>) + *ρ*(*X*<sub>1</sub>∪*X*<sub>4</sub>) + *ρ*(*X*<sub>2</sub>∪*X*<sub>3</sub>) + *ρ*(*X*<sub>2</sub>∪*X*<sub>4</sub>).

To prove the inequality we have to show the following result:

:::

::: {#o14 .statement kind=statement/proposition cue=inline-head name="Proposition"}

**Proposition**: Let *V*<sub>1</sub>,*V*<sub>2</sub>, *V*<sub>3</sub> and *V*<sub>4</sub> be [subspaces](wikipedia://en/56357) of a [vector space](wikipedia://en/32370) *V*, then

1. dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) ≥ dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) − dim(*V*<sub>1</sub>+*V*<sub>3</sub>) − dim(*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>)
1. dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) ≥ dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) + dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>) − dim(*V*<sub>1</sub>∩*V*<sub>2</sub>)
1. dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) ≥ dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) + dim(*V*<sub>4</sub>) − dim(*V*<sub>1</sub>+*V*<sub>3</sub>) − dim(*V*<sub>2</sub>+*V*<sub>3</sub>) − dim(*V*<sub>1</sub>+*V*<sub>4</sub>) − dim(*V*<sub>2</sub>+*V*<sub>4</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>4</sub>)
1. dim(*V*<sub>1</sub>) + dim(*V*<sub>2</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>4</sub>) + dim(*V*<sub>3</sub>+*V*<sub>4</sub>) ≤ dim(*V*<sub>1</sub>+*V*<sub>2</sub>) + dim(*V*<sub>1</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>4</sub>) + dim(*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>2</sub>+*V*<sub>4</sub>)

Where *V<sub>i</sub>*+*V<sub>j</sub>* represent the [direct sum](wikipedia://en/2084687) of the two subspaces.

:::

::: {#o15 .proof cue=inline-head name="Proof (proposition)"}

**Proof (proposition)**: We will use frequently the standard vector space identity: dim(*U*) + dim(*W*) = dim(*U*+*W*) + dim(*U*∩*W*).

\1. It is clear that (*V*<sub>1</sub>∩*V*<sub>2</sub>) + *V*<sub>3</sub> ⊆ (*V*<sub>1</sub>+ *V*<sub>3</sub>) ∩ (*V*<sub>2</sub>+*V*<sub>3</sub>), then

| dim((*V*<sub>1</sub>∩*V*<sub>2</sub>)+*V*<sub>3</sub>) | ≤ | dim((*V*<sub>1</sub>+*V*<sub>2</sub>)∩(*V*<sub>2</sub>+*V*<sub>3</sub>)), | hence |
|---|---|---|---|
| dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) | \= | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) − dim((*V*<sub>1</sub>∩*V*<sub>2</sub>)+*V*<sub>3</sub>) |
|---|---|---|
|  | ≥ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) − dim((*V*<sub>1</sub>+*V*<sub>3</sub>)∩(*V*<sub>2</sub>+*V*<sub>3</sub>)) |
|  | \= | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) – {dim(*V*<sub>1</sub>+*V*<sub>3</sub>) + dim(*V*<sub>2</sub>+*V*<sub>3</sub>) – dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>)} |
|  | \= | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) – dim(*V*<sub>1</sub>+*V*<sub>3</sub>) − dim(*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) |

\2. It is clear that (*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) + (*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>) ⊆ (*V*<sub>1</sub>∩*V*<sub>2</sub>), then

| dim{(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>)+(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>)} | ≤ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>), | hence |
|---|---|---|---|
| dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) | \= | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) + dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>) − dim{(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) + (*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>)} |
|---|---|---|
|  | ≥ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) + dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>) − dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) |

\3. From (1) and (2) we have:

| dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) | ≥ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>) + dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>4</sub>) − dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) |
|---|---|---|
|  | ≥ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) − dim(*V*<sub>1</sub>+*V*<sub>3</sub>) − dim(*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>4</sub>) − dim(*V*<sub>1</sub>+*V*<sub>4</sub>) − dim(*V*<sub>2</sub>+*V*<sub>4</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>4</sub>) − dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) |
|  | \= | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>3</sub>) + dim(*V*<sub>4</sub>) − dim(*V*<sub>1</sub>+*V*<sub>3</sub>) − dim(*V*<sub>2</sub>+*V*<sub>3</sub>) − dim(*V*<sub>1</sub>+*V*<sub>4</sub>) − dim(*V*<sub>2</sub>+*V*<sub>4</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) |

\4. From (3) we have

| dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>4</sub>) | ≤ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) − dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) − dim(*V*<sub>3</sub>) − dim(*V*<sub>4</sub>) + dim(*V*<sub>1</sub>+*V*<sub>3</sub>)+ dim(*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>4</sub>) + dim(*V*<sub>2</sub>+*V*<sub>4</sub>) |
|---|---|---|

If we add (dim(*V*<sub>1</sub>)+dim(*V*<sub>2</sub>)+dim(*V*<sub>3</sub>+*V*<sub>4</sub>)) at both sides of the last inequality, we get

| dim(*V*<sub>1</sub>) + dim(*V*<sub>2</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>2</sub>+*V*<sub>4</sub>) + dim(*V*<sub>3</sub>+*V*<sub>4</sub>) | ≤ | dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) − dim(*V*<sub>1</sub>∩*V*<sub>2</sub>) + dim(*V*<sub>1</sub>+dim(*V*<sub>2</sub>) + dim(*V*<sub>3</sub>+*V*<sub>4</sub>) − dim(*V*<sub>3</sub>) − dim(*V*<sub>4</sub>) + dim(*V*<sub>1</sub>+*V*<sub>3</sub>) + dim(*V*<sub>2</sub>+*V*<sub>3</sub>) + dim(*V*<sub>1</sub>+*V*<sub>4</sub>) + dim(*V*<sub>2</sub>+*V*<sub>4</sub>) |
|---|---|---|

Since the inequality dim(*V*<sub>1</sub>∩*V*<sub>2</sub>∩*V*<sub>3</sub>∩*V*<sub>4</sub>) ≤ dim(*V*<sub>3</sub>∩*V*<sub>4</sub>) holds, we have finished the proof.♣

:::

::: {#o16 .proof cue=inline-head name="Proof (Ingleton's inequality)"}

**Proof (Ingleton's inequality)**: Suppose that *M* is a representable matroid and let *A* = \[*v*<sub>1</sub> *v*<sub>2</sub> … *v*<sub>*n*</sub>\] be a [matrix](wikipedia://en/20556859) such that *M* = *M*(*A*). For *X*, *Y* ⊆ E(*M*) = {1,2, …, *n*}, define *U* = \<{*V<sub>i</sub>* : *i* ∈ *X* }>, as the [span](wikipedia://en/56353) of the vectors in *V<sub>i</sub>*, and we define *W* = \<{*V<sub>j</sub>* : *j* ∈ *Y* }> accordingly.

If we suppose that *U* = \<{*u*<sub>1</sub>, *u*<sub>2</sub>, … ,*u*<sub>*m*</sub>}> and *W* = \<{*w*<sub>1</sub>, *w*<sub>2</sub>, … ,*w*<sub>*r*</sub>}> then clearly we have \<{*u*<sub>1</sub>, *u*<sub>2</sub>, …, *u*<sub>*m*</sub>, *w*<sub>1</sub>, *w*<sub>2</sub>, …, *w*<sub>*r*</sub>}> = *U* + *W*.

Hence: *r*(*X*∪*Y*) = dim \<{*v<sub>i</sub>* : *i* ∈ *X* } ∪ {*v<sub>j</sub>* : *j* ∈ *Y* }> = dim(*V* + *W* ).

Finally, if we define *V<sub>i</sub>* = {*v<sub>r</sub>* : *r* ∈ *X<sub>i</sub>* } for *i* = 1,2,3,4, then by last inequality and the item (4) of the above proposition, we get the result.

:::
