# Average crossing number

::: {#o1 .subject cue=lead name="Average crossing number"}

In the [mathematical](wikipedia://en/18831) subject of [knot theory](wikipedia://en/153008), the **average crossing number** of a [knot](wikipedia://en/366808) is the result of averaging over all directions the [number of crossings](wikipedia://en/18298598) in a knot diagram of the knot obtained by projection onto the plane orthogonal to the direction. The average crossing number is often seen in the context of [physical knot theory](https://en.wikipedia.org/wiki/Physical_knot_theory).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

More precisely, if *K* is a smooth knot, then for almost every [unit vector](wikipedia://en/167053) *v* giving the direction, orthogonal projection onto the plane perpendicular to *v* gives a [knot diagram](https://en.wikipedia.org/wiki/Knot_diagram), and we can compute the crossing number, denoted *n*(*v*). The average crossing number is then defined as the [integral](wikipedia://en/15532) over the [unit sphere](wikipedia://en/27033090):[^n1]

$$\frac{1}{4\pi}\int_{S^2} n(v) \, dA$$

where *dA* is the area form on the [2-sphere](https://en.wikipedia.org/wiki/2-sphere). The integral makes sense because the set of directions where projection doesn't give a knot diagram is a set of [measure zero](https://en.wikipedia.org/wiki/Measure_zero) and *n*(*v*) is [locally constant](https://en.wikipedia.org/wiki/Locally_constant) when defined.

:::

## Alternative formulation {#Alternative_formulation}

A less intuitive but computationally useful definition is an integral similar to the [Gauss linking integral](https://en.wikipedia.org/wiki/Gauss_linking_integral).

A derivation analogous to the derivation of the linking integral will be given. Let *K* be a knot, parameterized by

$$f: S^1 \rightarrow \mathbb R^3.$$

Then define the map from the [torus](wikipedia://en/74800) to the 2-sphere

$$g: S^1 \times S^1 \rightarrow S^2$$

by

$$g(s, t) = \frac{f(s) - f(t)}{|f(s) - f(t)|}.$$

(Technically, one needs to avoid the diagonal: points where *s* = *t*.) We want to count the number of times a point (direction) is covered by *g*. This will count, for a generic direction, the number of crossings in a knot diagram given by projecting along that direction. Using the [degree of the map](https://en.wikipedia.org/wiki/Degree_of_a_map), as in the linking integral, would count the number of crossings with *sign*, giving the [writhe](wikipedia://en/968591). Use *g* to pull back the [area form](https://en.wikipedia.org/wiki/Area_form) on *S*<sup>2</sup> to the torus *T*<sup>2</sup> = *S*<sup>1</sup> × *S*<sup>1</sup>. Instead of integrating this form, integrate the absolute value of it, to avoid the sign issue. The resulting integral is[^n2]

$$\frac{1}{4\pi}\int_{T^2} \frac{|(f'(s) \times f'(t)) \cdot (f(s) - f(t))|}{|(f(s) -f(t))|^3} \, ds\, dt.$$
