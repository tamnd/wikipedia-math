# Cross Gramian

::: {#o1 .subject cue=lead name="Cross Gramian"}

In [control theory](wikipedia://en/7039), the **cross Gramian** ($W_X$, also referred to by $W_{CO}$) is a [Gramian](https://en.wikipedia.org/wiki/Gramian) matrix used to determine how [controllable](wikipedia://en/100638) and [observable](wikipedia://en/871280) a linear system is.[^o2][^o3]

:::

For the stable [time-invariant](https://en.wikipedia.org/wiki/Time-invariant_system) linear system

$$\dot{x} = A x + B u \,$$

$$y = C x \,$$

the cross Gramian is defined as:

$$W_X := \int_0^\infty e^{At} BC e^{At} dt \,$$

and thus also given by the solution to the [Sylvester equation](wikipedia://en/10105237):

$$A W_X + W_X A = -BC \,$$

This means the cross Gramian is not strictly a [Gramian matrix](https://en.wikipedia.org/wiki/Gramian_matrix), since it is generally neither positive semi-definite nor symmetric.

The triple $(A,B,C)$ is [controllable](wikipedia://en/100638) and [observable](wikipedia://en/871280), and hence minimal, if and only if the matrix $W_X$ is [nonsingular](wikipedia://en/253260#Singularities), (i.e. $W_X$ has full rank, for any $t > 0$).

If the associated system $(A,B,C)$ is furthermore symmetric, such that there exists a transformation $J$ with

$$AJ = JA^T \,$$

$$B = JC^T \,$$

then the [absolute value](wikipedia://en/991) of the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of the cross Gramian equal [Hankel singular values](wikipedia://en/12540984):[^o4]

$$|\lambda(W_X)| = \sqrt{\lambda(W_C W_O)}. \,$$

Thus the direct truncation of the [Eigendecomposition](https://en.wikipedia.org/wiki/Eigendecomposition) of the cross Gramian allows [model order reduction](wikipedia://en/42908722) (see <http://modelreduction.org>) without a balancing procedure as opposed to [balanced truncation](https://en.wikipedia.org/wiki/Balanced_truncation).

The cross Gramian has also applications in [decentralized control](https://en.wikipedia.org/wiki/Decentralized_control), [sensitivity analysis](wikipedia://en/620083), and the [inverse scattering transform](wikipedia://en/4916481).[^o5][^o6]
