# Frugal number

::: {#o1 .subject cue=lead name="Frugal number"}

In [number theory](wikipedia://en/21527), a **frugal number** is a [natural number](wikipedia://en/21474) in a given [number base](https://en.wikipedia.org/wiki/Number_base) that has more [digits](wikipedia://en/280582) than the number of digits in its [prime factorization](https://en.wikipedia.org/wiki/Prime_factorization) in the given number base (including exponents).[^o2] For example, in [base 10](https://en.wikipedia.org/wiki/Base_10), 125 = 5<sup>3</sup>, 128 = 2<sup>7</sup>, 243 = 3<sup>5</sup>, and 256 = 2<sup>8</sup> are frugal numbers . The first frugal number which is not a [prime power](wikipedia://en/1630483) is 1029 = 3 × 7<sup>3</sup>. In [base 2](https://en.wikipedia.org/wiki/Base_2), thirty-two is a frugal number, since 32 = 2<sup>5</sup> is written in base 2 as 100000 = 10<sup>101</sup>.

:::

The term **economical number** has been used for a frugal number, but also for a number which is either frugal or [equidigital](wikipedia://en/10396838).

## Mathematical definition {#Mathematical_definition}

Let $b > 1$ be a number base, and let $K_b(n) = \lfloor \log_b{n} \rfloor + 1$ be the number of digits in a natural number $n$ for base $b$. A natural number $n$ has the prime factorisation

$$n = \prod_{\stackrel{p \,\mid\, n}{p\text{ prime}}} p^{v_p(n)}$$

where $v_p(n)$ is the [*p*-adic valuation](wikipedia://en/16047618) of $n$, and $n$ is an **frugal number** in base $b$ if

$$K_b(n) > \sum_{{\stackrel{p \,\mid\, n}{p\text{ prime}}}} K_b(p) + \sum_{{\stackrel{p^2 \,\mid\, n}{p\text{ prime}}}} K_b(v_p(n)).$$
