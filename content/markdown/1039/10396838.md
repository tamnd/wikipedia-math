# Equidigital number

*Image: Composite number Cuisenaire rods 10.svg.* Demonstration, with [Cuisenaire rods](https://en.wikipedia.org/wiki/Cuisenaire_rods), that the [composite number](wikipedia://en/82289) 10 is equidigital: 10 has two digits, and 2 × 5 has two digits (1 is excluded)

::: {#o1 .subject cue=lead name="Equidigital number"}

In [number theory](wikipedia://en/21527), an **equidigital number** is a [natural number](wikipedia://en/21474) in a given [number base](wikipedia://en/701207) that has the same number of digits as the number of digits in its [prime factorization](https://en.wikipedia.org/wiki/Prime_factorization) in the given number base, including [exponents](wikipedia://en/99491) but excluding exponents equal to 1.[^o2] For example, in [base 10](https://en.wikipedia.org/wiki/Base_10), 1, 2, 3, 5, 7, and 10 (2 × 5) are equidigital numbers . All [prime numbers](wikipedia://en/23666) are equidigital numbers in any base.

:::

A number that is either equidigital or [frugal](wikipedia://en/10396863) is said to be *economical*.

## Mathematical definition {#Mathematical_definition}

Let $b > 1$ be the number base, and let $K_b(n) = \lfloor \log_{b}{n} \rfloor + 1$ be the number of digits in a natural number $n$ for base $b$. A natural number $n$ has the prime factorisation

$$n = \prod_{\stackrel{p \,\mid\, n}{p\text{ prime}}} p^{v_p(n)}$$

where $v_p(n)$ is the [*p*-adic valuation](wikipedia://en/16047618) of $n$, and $n$ is an **equidigital number** in base $b$ if

$$K_b(n) = \sum_{{\stackrel{p \,\mid\, n}{p\text{ prime}}}} K_b(p) + \sum_{{\stackrel{p^2 \,\mid\, n}{p\text{ prime}}}} K_b(v_p(n)).$$

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every [prime number](wikipedia://en/23666) is equidigital. This also [proves](wikipedia://en/82285) that there are infinitely many equidigital numbers.

:::
