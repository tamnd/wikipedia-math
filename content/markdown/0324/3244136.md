# Effective descriptive set theory

::: {#o1 .subject cue=lead name="Effective descriptive set theory"}

**Effective descriptive set theory** is the branch of [descriptive set theory](wikipedia://en/396619) dealing with [sets](wikipedia://en/26691) of [reals](wikipedia://en/20646438) having [lightface](https://en.wikipedia.org/wiki/Lightface) definitions; that is, definitions that do not require an arbitrary real [parameter](wikipedia://en/25065) (Moschovakis 1980). Thus effective descriptive set theory combines descriptive set theory with [recursion theory](https://en.wikipedia.org/wiki/Recursion_theory).

:::

::: {#o3 .definition kind=definition/construction cue=heading name="Constructions"}

## Constructions {#Constructions}

### Effective Polish space {#Effective_Polish_space}

An **effective Polish space** is a [complete](wikipedia://en/7832) [separable](wikipedia://en/27855) [metric space](wikipedia://en/20018) that has a [computable presentation](https://en.wikipedia.org/wiki/Computable_presentation). Such spaces are studied in both effective descriptive set theory and in [constructive analysis](wikipedia://en/239851). In particular, standard examples of Polish spaces such as the [real line](https://en.wikipedia.org/wiki/Real_line), the [Cantor set](wikipedia://en/6172) and the [Baire space](wikipedia://en/2078245) are all effective Polish spaces.

### Arithmetical hierarchy {#Arithmetical_hierarchy}

The [arithmetical hierarchy](wikipedia://en/186475), arithmetic hierarchy or [Kleene](wikipedia://en/28805)–[Mostowski](wikipedia://en/1029314) hierarchy classifies certain [sets](wikipedia://en/26691) based on the complexity of formulas that define them. Any set that receives a classification is called "arithmetical".

More formally, the arithmetical hierarchy assigns classifications to the formulas in the language of [first-order arithmetic](wikipedia://en/25005). The classifications are denoted $\Sigma^0_n$ and $\Pi^0_n$ for natural numbers *n* (including 0). The Greek letters here are [lightface](https://en.wikipedia.org/wiki/Lightface) symbols, which indicates that the formulas do not contain set parameters.

If a formula $\phi$ is [logically equivalent](https://en.wikipedia.org/wiki/Logically_equivalent) to a formula with only [bounded quantifiers](wikipedia://en/5824808) then $\phi$ is assigned the classifications $\Sigma^0_0$ and $\Pi^0_0$.

The classifications $\Sigma^0_n$ and $\Pi^0_n$ are defined inductively for every natural number *n* using the following rules:

- If $\phi$ is logically equivalent to a formula of the form $\exists n_1 \exists n_2\cdots \exists n_k \psi$, where $\psi$ is $\Pi^0_n$, then $\phi$ is assigned the classification $\Sigma^0_{n+1}$.
- If $\phi$ is logically equivalent to a formula of the form $\forall n_1 \forall n_2\cdots \forall n_k \psi$, where $\psi$ is $\Sigma^0_n$, then $\phi$ is assigned the classification $\Pi^0_{n+1}$.

:::
