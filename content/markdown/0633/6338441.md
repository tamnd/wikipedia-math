# CryptMT

::: {#o1 .subject cue=lead name="CryptMT"}

In [cryptography](wikipedia://en/18934432), **CryptMT** is a [stream cipher](wikipedia://en/49007) [algorithm](wikipedia://en/775) which internally uses the [Mersenne twister](https://en.wikipedia.org/wiki/Mersenne_twister). It was developed by [Makoto Matsumoto](wikipedia://en/73756160), [Mariko Hagita](https://en.wikipedia.org/wiki/Mariko_Hagita), [Takuji Nishimura](https://en.wikipedia.org/wiki/Takuji_Nishimura) and [Mutsuo Saito](https://en.wikipedia.org/wiki/Mutsuo_Saito) and is [patented](https://en.wikipedia.org/wiki/Patent). It was one of the final Phase 3 candidates[^o2] in the [eSTREAM](wikipedia://en/2287686) project of the [eCRYPT](wikipedia://en/1635837) network but was not selected because [the non-linear filter](wikipedia://en/49007#Filter_generator) component was not as well-understood in terms of its security.[^o3]

:::

In that submission to [eSTREAM](wikipedia://en/2287686), the authors also included another cipher named **Fubuki**, which also uses the Mersenne twister.
