# Achterbahn (stream cipher)

::: {#o1 .subject cue=lead name="Achterbahn"}

In [cryptography](wikipedia://en/18934432), **Achterbahn** is a synchronous [stream cipher](wikipedia://en/49007) [algorithm](wikipedia://en/775) submitted to the [eSTREAM](wikipedia://en/2287686) Project of the [eCRYPT](wikipedia://en/1635837) network.

:::

In the final specification the cipher is called **ACHTERBAHN-128/80**, because it supports the key lengths of 80 bits and 128 bits, respectively.[^o2] Achterbahn was developed by Berndt Gammel, Rainer Göttfert and Oliver Kniffler.

*Achterbahn* means *rollercoaster* (in German), though a literal translation of the term would be *eight-track*, which indicates that the cipher can encrypt eight bit streams in parallel.

The parameters of the cipher are given in the following table:

::: {#o3 .table cue=table}

|  | ACHTERBAHN-80 | ACHTERBAHN-128 |
|---|---|---|
| Max. key length | 80 bit | 128 bit |
| Max. IV length | 80 bit | 128 bit |
| Max. frame length | 2<sup>44</sup> | 2<sup>44</sup> |
| Internal state | 297 bit | 351 bit |

:::

ACHTERBAHN-128 is downward compatible and can produce the same keystream as ACHTERBAHN-80 if so desired. The keystream generator of ACHTERBAHN-128/80 is based on the design principle of the nonlinear combination generator, however it deploys primitive nonlinear feedback shift registers ([NLFSR](https://en.wikipedia.org/wiki/NLFSR)) instead of linear ones ([LFSR](https://en.wikipedia.org/wiki/LFSR)).

## Security {#Security}

There are no known cryptanalytic attacks against ACHTERBAHN-128/80 for the tabulated parameters that are faster than [brute force attack](https://en.wikipedia.org/wiki/Brute_force_attack). Recent analysis showed that attacks are possible if larger frame ([packet](https://en.wikipedia.org/wiki/Packet_%28information_technology%29)) lengths are used in a communication protocol.[^o5][^o6][^o7] The cipher's authors recommend a maximum frame length of 2<sup>44</sup> bits.[^o8] This value does however not imply practical limitations.

## Performance {#Performance}

The ACHTERBAHN-128/80 stream cipher is optimized for hardware applications with restricted resources, such as limited gate count and power consumption. An implementation of ACHTERBAHN-80 has a design size of only 2188 gate equivalents (Nand-GE) in a standard [CMOS](https://en.wikipedia.org/wiki/CMOS) technology and delivers a throughput of up to 400 Megabit/s. This makes it suitable for RFID tags. A high-speed implementation with a throughput of 8 Gigabit/s has a design size of 8651 Nand-GE.[^o10]
