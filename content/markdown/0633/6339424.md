# ABC (stream cipher)

::: {#o1 .subject cue=lead name="ABC"}

In [cryptography](wikipedia://en/18934432), **ABC** is a [stream cypher](wikipedia://en/49007) [algorithm](wikipedia://en/775) developed by [Vladimir Anashin](https://en.wikipedia.org/wiki/Vladimir_Anashin), [Andrey Bogdanov](https://en.wikipedia.org/wiki/Andrei_Bogdanov_%28cryptographer%29), [Ilya Kizhvatov](https://en.wikipedia.org/wiki/Ilya_Kizhvatov), and [Sandeep Kumar](https://en.wikipedia.org/wiki/Sandeep_Kumar_%28cryptographer%29).[^o2] It has been submitted to the [eSTREAM](wikipedia://en/2287686) Project of the [eCRYPT](wikipedia://en/1635837) network.

:::

It takes a 128-bit key and a 128-bit [IV](wikipedia://en/105971).[^o2]

The claimed security level of $2^{128}$ bits has been reduced to $2^{88}$.[^o3]
