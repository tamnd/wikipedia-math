# WG (cipher)

::: {#o1 .subject cue=lead name="WG"}

In [cryptography](wikipedia://en/18934432), **WG** is a [stream cypher](wikipedia://en/49007) [algorithm](wikipedia://en/775) developed by [Guang Gong](https://en.wikipedia.org/wiki/Guang_Gong) and [Yassir Nawaz](https://en.wikipedia.org/wiki/Yassir_Nawaz). It has been submitted to the [eSTREAM](wikipedia://en/2287686) Project of the [eCRYPT](wikipedia://en/1635837) network.[^o2]

:::
