# NLS (cipher)

::: {#o1 .subject cue=lead name="NLS"}

In [cryptography](wikipedia://en/18934432), **NLS** is a [stream cipher](wikipedia://en/49007) [algorithm](wikipedia://en/775) designed by [Gregory Rose](wikipedia://en/17464335), [Philip Hawkes](https://en.wikipedia.org/wiki/Philip_Hawkes), [Michael Paddon](https://en.wikipedia.org/wiki/Michael_Paddon), and [Miriam Wiggers de Vries](https://en.wikipedia.org/wiki/Miriam_Wiggers_de_Vries). It has been submitted to the [eSTREAM](wikipedia://en/2287686) Project of the [eCRYPT](wikipedia://en/1635837) network.[^o2]

:::
