# Polar Bear (cipher)

::: {#o1 .subject cue=lead name="Polar Bear"}

In [cryptography](wikipedia://en/18934432), **Polar Bear** is a [stream cypher](wikipedia://en/49007) [algorithm](wikipedia://en/775) designed by [Johan Håstad](https://en.wikipedia.org/wiki/Johan_Håstad) and Mats Näslund. It has been submitted to the [eSTREAM](wikipedia://en/2287686) Project of the [eCRYPT](wikipedia://en/1635837) network.

:::
