# SSS (cipher)

::: {#o1 .subject cue=lead name="SSS"}

In [cryptography](wikipedia://en/18934432), **SSS** is a [stream cypher](wikipedia://en/49007) [algorithm](wikipedia://en/775) developed by [Gregory Rose](wikipedia://en/17464335), [Philip Hawkes](https://en.wikipedia.org/wiki/Philip_Hawkes), [Michael Paddon](https://en.wikipedia.org/wiki/Michael_Paddon), and [Miriam Wiggers de Vries](https://en.wikipedia.org/wiki/Miriam_Wiggers_de_Vries).[^o2] It includes a [message authentication code](wikipedia://en/567523) feature. It has been submitted to the [eSTREAM](wikipedia://en/2287686) Project of the [eCRYPT](wikipedia://en/1635837) network. It has not selected for focus nor for consideration during Phase 2; it has been 'archived'.

:::
