# The State of The USA

::: {#o1 .subject cue=lead name="The State of The USA"}

**The State of the USA** is a non-profit group that seeks to present non-partisan data on key national indicators of the United States.[^o2][^o3][^o4][^o5]

:::

The group works with the [United States National Academy of Sciences](https://en.wikipedia.org/wiki/United_States_National_Academy_of_Sciences) in creating a federally mandated Key National Indicator System (KNIS).[^o2][^o6][^o7]
