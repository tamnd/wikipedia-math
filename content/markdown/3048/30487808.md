# Multivariate stable distribution

::: {#o1 .subject cue=lead name="Multivariate stable distribution"}

The **multivariate stable distribution** is a multivariate [probability distribution](wikipedia://en/23543) that is a multivariate generalisation of the univariate [stable distribution](wikipedia://en/1117869). The multivariate stable distribution defines linear relations between [stable distribution](wikipedia://en/1117869) marginals. In the same way as for the univariate case, the distribution is defined in terms of its [characteristic function](wikipedia://en/3229401).

:::

The multivariate stable distribution can also be thought as an extension of the [multivariate normal distribution](wikipedia://en/50347). It has parameter, *α*, which is defined over the range 0 \< *α* ≤ 2, and where the case *α* = 2 is equivalent to the multivariate normal distribution. It has an additional skew parameter that allows for non-symmetric distributions, where the [multivariate normal distribution](wikipedia://en/50347) is symmetric.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathbb{S}$ be the Euclidean unit sphere in $\mathbb R^d$, that is, $\mathbb{S} = \{u \in \mathbb R^d\colon|u| = 1\}$. A [random vector](https://en.wikipedia.org/wiki/Random_vector) $X$ has a multivariate stable distribution—denoted as $X \sim S(\alpha, \Lambda, \delta)$—, if the joint characteristic function of $X$ is[^o4]

$$\operatorname{E} \exp(i u^T X) = \exp \left\{-\int \limits_{\mathbb S}\left\{|u^Ts|^\alpha + i \nu (u^Ts, \alpha) \right\} \, \Lambda(ds) + i u^T\delta\right\},$$

where 0 \< *α* \< 2, and for $y\in\mathbb R$

$$\nu(y,\alpha) =\begin{cases} -\operatorname{sign}(y) \tan(\pi \alpha / 2)|y|^\alpha & \alpha \ne 1, \\ (2/\pi)y \ln |y| & \alpha=1. \end{cases}$$

This is essentially the result of Feldheim,[^o5] that any stable random vector can be characterized by a spectral measure $\Lambda$ (a finite measure on $\mathbb S$) and a shift vector $\delta \in \mathbb R^d$.

:::

## Parametrization using projections {#Parametrization_using_projections}

Another way to describe a stable random vector is in terms of projections. For any vector $u$ the projection $u^TX$ is univariate $\alpha$-stable with some skewness $\beta(u)$, scale $\gamma(u)$, and some shift $\delta(u)$. The notation $X \sim S(\alpha,\beta,\gamma,\delta)$ is used if *X* is stable with $u^TX \sim s(\alpha,\beta(u),\gamma(u),\delta(u))$ for every $u \in \mathbb R^d$. This is called the projection parametrization.

The spectral measure determines the projection parameter functions by:

$$\gamma(u) = \Bigl( \int_{\mathbb{S}} |u^Ts|^\alpha \, \Lambda(ds) \Bigr)^{1/\alpha}$$

$$\beta(u) = \gamma(u)^{-\alpha} \int_{\mathbb{S}}|u^Ts|^\alpha \operatorname{sign}(u^Ts) \, \Lambda(ds)$$

$$\delta(u)=\begin{cases}u^T \delta & \alpha \ne 1\\u^T \delta -\int_{\mathbb{S}}\frac{\pi}{2} u^Ts \ln|u^Ts| \, \Lambda(ds)&\alpha=1\end{cases}$$

## Special cases {#Special_cases}

There are special cases where the multivariate [characteristic function](wikipedia://en/3229401) takes a simpler form. Define the characteristic function of a stable marginal as

$$\omega(y|\alpha,\beta) = \begin{cases}|y|^\alpha\left[1-i \beta(\tan \frac{\pi\alpha}{2})\operatorname{sign}(y)\right]& \alpha \ne 1\\ |y|\left[1+i \beta \tfrac{2}{\pi} \operatorname{sign}(y)\ln |y|\right] & \alpha = 1\end{cases}$$

### Isotropic multivariate stable distribution {#Isotropic_multivariate_stable_distribution}

Here the characteristic function is $E \exp(i u^T X)=\exp\{-\gamma_0^\alpha|u|^\alpha+i u^T \delta)\}$. The spectral measure is a scalar multiple of the uniform distribution on the sphere, leading to radial/isotropic symmetry.[^o10] For the Gaussian case $\alpha=2$ this corresponds to independent components, but this is not the case when $\alpha<2$. Isotropy is a special case of ellipticity (see the next paragraph)—just take $\Sigma$ to be a multiple of the identity matrix.

### Elliptically contoured multivariate stable distribution {#Elliptically_contoured_multivariate_stable_distribution}

The [elliptically contoured](wikipedia://en/27014075) multivariate stable distribution is a special symmetric case of the multivariate stable distribution. *X* is *α*-stable and elliptically contoured iff it has joint [characteristic function](wikipedia://en/3229401) $E \exp(i u^T X)=\exp\{-(u^T\Sigma u)^{\alpha/2}+i u^T \delta)\}$ for some shift vector $\delta \in \mathbb{R}^d$ (equal to the mean when it exists) and some positive semidefinite matrix $\Sigma$ (akin to a correlation matrix, although the usual definition of correlation fails to be meaningful). Note the relation to the characteristic function of the [multivariate normal distribution](wikipedia://en/50347): $E \exp(i u^T X)=\exp\{-(u^T\Sigma u)+i u^T \delta)\}$, obtained when *α* = 2.

### Independent components {#Independent_components}

The marginals are independent with $X_j \sim S(\alpha, \beta_j, \gamma_j, \delta_j)$ iff the characteristic function is

$$E \exp(i u^T X) = \exp\left\{-\sum_{j=1}^m \omega(u_j|\alpha,\beta_j)\gamma_j^\alpha +i u^T \delta\right\}.$$

Observe that when *α* = 2 this reduces again to the multivariate normal; note that the i.i.d. case and the isotropic case do not coincide when *α* \< 2. Independent components is a special case of a discrete spectral measure (see next paragraph), with the spectral measure supported by the standard unit vectors.

### Discrete {#Discrete}

If the spectral measure is discrete with mass $\lambda_j$ at $s_j \in \mathbb{S}$, $j=1,\ldots,m$, the characteristic function is

$$E \exp(i u^T X)= \exp\left\{-\sum_{j=1}^m \omega(u^Ts_j|\alpha,1)\lambda_j^\alpha +i u^T \delta\right\}.$$

:::

## Linear properties {#Linear_properties}

If $X \sim S(\alpha, \beta(\cdot), \gamma(\cdot), \delta(\cdot))$ is *d*-dimensional $\alpha$-stable, *A* is an *m* × *d* matrix, and $b \in \mathbb{R}^m,$ then *AX + b* is *m*-dimensional $\alpha$-stable with scale function $\gamma \circ A^T$, skewness function $\beta \circ A^T$, and location function $\delta \circ A^T + b^T$.

## Inference in the independent-component model {#Inference_in_the_independent-component_model}

Bickson and Guestrin have shown how to compute inference in closed form in a linear model (or equivalently a [factor analysis](wikipedia://en/253492) model), involving independent-component models.[^o16]

More specifically, let $X_i \sim S(\alpha, \beta_{x_i}, \gamma_{x_i}, \delta_{x_i})$ $(i=1,\ldots,n)$ be a family of i.i.d. unobserved univariates drawn from a [stable distribution](wikipedia://en/1117869). Given a known linear relation matrix *A* of size $n \times n$, the observations $Y_i = \sum_{i=1}^n A_{ij}X_j$ are assumed to be distributed as a convolution of the hidden factors $X_i$, hence $Y_i = S(\alpha, \beta_{y_i}, \gamma_{y_i}, \delta_{y_i})$. The inference task is to compute the most likely $X_i$, given the linear relation matrix *A* and the observations $Y_i$. This task can be computed in closed form in O(*n*<sup>3</sup>).

An application for this construction is [multiuser detection](https://en.wikipedia.org/wiki/Multiuser_detection) with stable, non-Gaussian noise.
