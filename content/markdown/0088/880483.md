# Self number

::: {#o1 .subject cue=lead name="Self number"}

In [number theory](wikipedia://en/21527), a **self number** in a given [number base](https://en.wikipedia.org/wiki/Number_base) $b$ is a [natural number](wikipedia://en/21474) that cannot be written as the sum of any other natural number $n$ and the individual digits of $n$. 20 is a self number (in base 10), because no such combination can be found (all $n < 15$ give a result less than 20; all other $n$ give a result greater than 20). 21 is not, because it can be written as 15 + 1 + 5 using *n* = 15. These numbers were first described in 1959 by the [Indian](https://en.wikipedia.org/wiki/India) [mathematician](wikipedia://en/18902) [D. R. Kaprekar](https://en.wikipedia.org/wiki/D._R._Kaprekar).

:::

::: {#o4 .definition cue=heading name="Definition and properties"}

## Definition and properties {#Definition_and_properties}

Let $n$ be a natural number. We define the $b$-**self function** $F_b : \mathbb{N} \rightarrow \mathbb{N}$ for base $b > 1$ to be the following:

$$F_{b}(n) = n + \sum_{i=0}^{k - 1} d_i.$$

where $k = \lfloor \log_{b}{n} \rfloor + 1$ is the number of digits in the number in base $b$, and

$$d_i = \frac{n \bmod{b^{i+1}} - n \bmod b^i}{b^i}$$

is the value of each digit of the number. A natural number $n$ is a $b$-**self number** if the [preimage](wikipedia://en/14907#Preimages) of $n$ for $F_b$ is the [empty set](wikipedia://en/9566).

In general, for even bases, all [odd](https://en.wikipedia.org/wiki/Even_and_odd_numbers) numbers below the base number are self numbers, since any number below such an odd number would have to also be a 1-digit number which when added to its digit would result in an even number. For odd bases, all odd numbers are self numbers.[^o5]

The set of self numbers in a given base $b$ is infinite and has a positive [asymptotic density](https://en.wikipedia.org/wiki/Asymptotic_density): when $b$ is odd, this density is 1/2.[^o6]

:::

## Self primes {#Self_primes}
