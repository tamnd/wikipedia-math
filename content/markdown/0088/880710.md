# Maximum modulus principle

::: {#o1 .subject cue=lead name="Maximum modulus principle"}

*Image: Maximum modulus principle.png.* A plot of the modulus of $\cos(z)$ (in red) for $z$ in the [unit disk](wikipedia://en/252738) centered at the origin (shown in blue). As predicted by the theorem, the maximum of the modulus cannot be inside of the disk (so the highest value on the red surface is somewhere along its edge).

In [mathematics](wikipedia://en/18831), the **maximum modulus principle** in [complex analysis](wikipedia://en/5759) states that if $f$ is a [holomorphic function](wikipedia://en/14110), then the [modulus](wikipedia://en/991) $|f|$ cannot exhibit a strict [maximum](https://en.wikipedia.org/wiki/Maximum) that is strictly within the [domain](wikipedia://en/50263) of $f$.

:::

In other words, either $f$ is locally a [constant function](wikipedia://en/320861), or, for any point $z_0$ inside the domain of $f$ there exist other points arbitrarily close to $z_0$ at which $|f|$ takes larger values.

::: {#o3 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

Let $f$ be a holomorphic function on some [bounded](wikipedia://en/48258) and [connected](https://en.wikipedia.org/wiki/Connected_set) [open](wikipedia://en/39358) [subset](wikipedia://en/27631) $D$ of the [complex plane](wikipedia://en/217628) $\mathbb{C}$ and taking complex values. If $z_0$ is a point in $D$ such that

$$|f(z_0)|\ge |f(z)|$$

for all $z$ in some [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of $z_0$, then $f$ is constant on $D$.

This statement can be viewed as a special case of the [open mapping theorem](wikipedia://en/17395232), which states that a nonconstant holomorphic function maps open sets to open sets: If $|f|$ attains a local maximum at $z$, then the image of a sufficiently small open neighborhood of $z$ cannot be open, so $f$ is constant.

### Related statement {#Related_statement}

Suppose that $D$ is a bounded nonempty connected open subset of $\mathbb{C}$. Let $\overline{D}$ be the closure of $D$. Suppose that $f \colon \overline{D} \to \mathbb{C}$ is a continuous function that is holomorphic on $D$. Then $|f(z)|$ attains a maximum at some point of the boundary of $D$.

This follows from the first version as follows. Since $\overline{D}$ is [compact](wikipedia://en/6042) and nonempty, the continuous function $|f(z)|$ attains a maximum at some point $z_0$ of $\overline{D}$. If $z_0$ is not on the boundary, then the maximum modulus principle implies that $f$ is constant, so $|f(z)|$ also attains the same maximum at any point of the boundary.

::: {#o6 .statement cue=named-heading name="Minimum modulus principle"}

### Minimum modulus principle {#Minimum_modulus_principle}

For a holomorphic function $f$ on a connected open set $D$ of $\mathbb{C}$, if $z_0$ is a point in $D$ such that

$$0 < |f(z_0)| \le |f(z)|$$

for all $z$ in some [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of $z_0$, then $f$ is constant on $D$.

Proof: Apply the maximum modulus principle to $1/f$.

:::

:::

## Sketches of proofs {#Sketches_of_proofs}

::: {#o9 .statement cue=named-heading name="Using the maximum principle for harmonic functions"}

### Using the maximum principle for harmonic functions {#Using_the_maximum_principle_for_harmonic_functions}

One can use the equality

$$\log f(z) = \ln |f(z)| + i\arg f(z)$$

for complex [natural logarithms](wikipedia://en/21476) to deduce that $\ln |f (z) |$ is a [harmonic function](wikipedia://en/55762). Since $z_0$ is a local maximum for this function also, it follows from the [maximum principle](wikipedia://en/1436104) that $| f (z) |$ is constant. Then, using the [Cauchy–Riemann equations](wikipedia://en/7583) we show that $f'(z)$ = 0, and thus that $f(z)$ is constant as well. Similar reasoning shows that $| f (z) |$ can only have a local minimum (which necessarily has value 0) at an isolated zero of $f(z)$.

:::

::: {#o11 .statement kind=statement/theorem cue=named-heading name="Using Gauss's mean value theorem"}

### Using Gauss's mean value theorem {#Using_Gauss's_mean_value_theorem}

Another proof works by using [Gauss's mean value theorem](wikipedia://en/72827#Consequences) to "force" all points within overlapping open disks to assume the same value as the maximum. The disks are laid such that their centers form a polygonal path from the value where $f(z)$ is maximized to any other point in the domain, while being totally contained within the domain. Thus the existence of a maximum value implies that all the values in the domain are the same, thus $f(z)$ is constant.

:::

::: {#o13 .statement cue=named-heading name="Using Cauchy's Integral Formula"}

### Using Cauchy's Integral Formula {#Using_Cauchy's_Integral_Formula}

Source:[^o14]

As $D$ is open, there exists $\overline{B}(a,r)$ (a closed ball centered at $a \in D$ with radius $r>0$) such that $\overline{B}(a,r) \subset D$. We then define the boundary of the closed ball with positive orientation as $\gamma(t)=a+re^{it}, t \in [0,2\pi]$. Invoking Cauchy's integral formula, we obtain

$$0 \leq \int_{0}^{2\pi} |f(a)|-| f(a+re^{it})| \,dt \leq 0$$

For all $t \in [0,2\pi]$, $| f(a) |-| f(a+re^{it}) | \geq 0$, so $| f(a)|=| f(a+re^{it}) |$. This also holds for all balls of radius less than $r$ centered at $a$. Therefore, $f(z)=f(a)$ for all $z \in \overline{B}(a,r)$.

Now consider the constant function $g(z)=f(a)$ for all $z \in D$. Then one can construct a sequence of distinct points located in $\overline{B}(a,r)$ where the holomorphic function $g-f$ vanishes. As $\overline{B}(a,r)$ is closed, the sequence converges to some point in $\overline{B}(a,r) \in D$. This means $f-g$ vanishes everywhere in $D$ which implies $f(z)=f(a)$ for all $z \in D$.

:::

## Physical interpretation {#Physical_interpretation}

A physical interpretation of this principle comes from the [heat equation](wikipedia://en/166415). That is, since $\log | f(z) |$ is harmonic, it is thus the steady state of a heat flow on the region $D$. Suppose a strict maximum was attained on the interior of $D$, the heat at this maximum would be dispersing to the points around it, which would contradict the assumption that this represents the steady state of a system.

::: {#o17 .application cue=heading name="Applications"}

## Applications {#Applications}

The maximum modulus principle has many uses in complex analysis, and may be used to prove the following:

- The [fundamental theorem of algebra](wikipedia://en/51414).
- [Schwarz's lemma](https://en.wikipedia.org/wiki/Schwarz's_lemma), a result which in turn has many generalisations and applications in complex analysis.
- The [Phragmén–Lindelöf principle](wikipedia://en/1377241), an extension to unbounded domains.
- The [Borel–Carathéodory theorem](wikipedia://en/1793258), which bounds an analytic function in terms of its real part.
- The [Hadamard three-lines theorem](wikipedia://en/30418364), a result about the behaviour of bounded holomorphic functions on a line between two other parallel lines in the complex plane.

:::
