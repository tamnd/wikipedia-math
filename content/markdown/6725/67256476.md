# MacMahon Squares

*Image: MacMahon Squares solution.png.* A particular solution; this illustrates the B<sub>20,0,0</sub> constraint which forces a single color along the perimeter, while also maximizing the largest contiguous single-color area within the perimeter

::: {#o1 .subject cue=lead name="MacMahon Squares"}

**MacMahon Squares** are an [edge-matching puzzle](wikipedia://en/12740519) first published by [Percy MacMahon](https://en.wikipedia.org/wiki/Percy_Alexander_MacMahon) in 1921,[^o2] using 24 unique [squares](wikipedia://en/659939) with 3-color patterns; each of the four edges is assigned a single color. The complete set of 24 squares are organized next to each other by matching edge [colors](https://en.wikipedia.org/wiki/Color) to create a 4 by 6 [grid](https://en.wikipedia.org/wiki/Grid_graph). Such [tessellation](wikipedia://en/321671) puzzles have multiple variants, which are determined by restrictions on how to arrange the 24 squares. This game has also been commercialized in numerous physical forms, by various companies.

:::

## The game {#The_game}

*Image: MacMahon squares.svg.* All 24 MacMahon Squares, redrawn from Fig. 26 of *New Mathematical Pastimes* (MacMahon, 1921)

MacMahon squares was first published in [Percy Alexander MacMahon](https://en.wikipedia.org/wiki/Percy_Alexander_MacMahon)'s 1921 treatise *New Mathematical Pastimes*.[^o2] The original version consisted of one copy of each of the 24 different squares that can be made by coloring the edges of a square with one of three colors. (Here "different" means [up to](wikipedia://en/44787) rotations.) The goal is to arrange the squares into a 4 by 6 grid so that when two squares share an edge, the common edge is the same color in both squares.

In 1964, a [supercomputer](https://en.wikipedia.org/wiki/Supercomputer) was used to produce 12,261 solutions to the basic version of the MacMahon Squares puzzle, with a runtime of about 40 hours.[^o4]

### Theory {#Theory}

The MacMahon Squares game is an example of an edge-matching puzzle. The family of such problems is [NP-complete](wikipedia://en/23385892). The first part of *New Mathematical Diversions* describes these games in general, starting with linear forms ([dominoes](https://en.wikipedia.org/wiki/Domino)), then progressing in detail with similar games using tiles shaped as equilateral triangles, squares, right isoceles triangles, cubes, and hexagons.[^o2]

There are a total of 24 distinct squares for 3 colors. For an arbitrary number of colors $n$, the number of unique squares can be found by the expression $\frac{n}{4}\cdot(n+1)\cdot(n^2-n+2)$.[^o2][^o7]

For other shapes with $n$ colors, MacMahon determined the number of unique patterns are:

- Triangle: $\frac{n}{3}\cdot(n^2+2)$
- Pentagon: $\frac{n}{5}\cdot(n^4+4)$
- Hexagon: $\frac{n}{6}\cdot(n+1)\cdot(n^4-n^3+n^2+2)$
- Heptagon: $\frac{n}{7}\cdot(n^6+6)$

For example, given a triangle with three sides, each of which is assigned one of four possible colors, there are 56 unique patterns.

### Variants {#Variants}

#### Contact system {#Contact_system}

In his book, [MacMahon](https://en.wikipedia.org/wiki/Percy_Alexander_MacMahon) suggested the ability to define which borders can contact one another, based on their colors. This is by some permutation of the 3 colors, described by C<sub>a,b,c</sub>.[^o2] Here, a, b, and c represent the shift in colors to which the first, second, and third colors can be matched to. A '1' it is matched to itself, and a '2' signifies that it must be matched with a different color.

For example, C<sub>1,1,1</sub> represents 1 to 1, 2 to 2, and 3 to 3, as each of these matchings are represented by the number 1. Alternatively, C<sub>1,2</sub> represents 1 to 1 and 2 to 3 as the 1 to 1 matching is represented by the number 1, and the matching between 2 and 3 is represented by 2. More colors can be described in a similar way. For example, a coloring of C<sub>1,2,2,2</sub> represents 1 to 1, 2 to 3, 4 to 5, and 6 to 7.

From here we can see that the only possible numbers to describe the pairings by are 1 and 2, since a 3 or above merely skips over a color that would be used the same otherwise because colorings are relative.[^o2]

#### Boundaries {#Boundaries}

Another way to change the puzzle is to restrict which colors squared make up the border colors. In the classic MacMahon squares puzzle, there are a total of 20 places on the border.[^o2] The number of each color that can be present on these 20 places can be described by B<sub>a,b,c</sub>[^o2] where a, b, and c are the number of each color of the border pieces.

For example, B<sub>20,0,0</sub> represents 20 of the first color and none of the rest since the first color already constitutes all available border spaces. Alternatively, B<sub>10,10,0</sub> represents 10 of the first color and 10 of the next. More colors can be described in a similar way. For example, a boundary of B<sub>22,16,8,2</sub> represents 22 of the first, 16 of the second, 8 of the next, and 2 of the last colors to populate the border colors.

From here we can see that the only possible numbers to describe the number of each color composing the boundary are even numbers, since this would imply an odd number of another color, which would violate the [parity](wikipedia://en/143135) of the total number of triangles.[^o2]

## Analogous puzzles {#Analogous_puzzles}

MacMahon Squares, along with variations on the idea, was commercialized as Multimatch.

Another puzzle with similar properties is MacMahon's Cubes, which are a set of 30 cubes, with sides colored one of 6 different colors. Unlike the MacMahon Squares puzzle, we do not include all 2,226 possible cubes, but only the cubes containing exactly 6 distinct colors and 1 of each of the 6 colors.[^o7]

MacMahon Squares have served as a baseline for numerous other puzzles. Some of these include the Nelson Puzzle,[^o13] the [Wang Tile](wikipedia://en/65798), and [TetraVex](https://en.wikipedia.org/wiki/TetraVex).

The commercial board game *[Trioker](https://en.wikipedia.org/wiki/Trioker)*, patented in 1969 by Marc Odier, uses triangular tiles first proposed by MacMahon in 1921.
