# Engset formula

::: {#o1 .subject cue=lead name="Engset formula"}

In [queueing theory](wikipedia://en/50578), the **Engset formula** is used to determine the blocking probability of an M/M/c/c/N queue (in [Kendall's notation](wikipedia://en/7345405)).

:::

The formula is named after its developer, [T. O. Engset](wikipedia://en/162454).

## Example application {#Example_application}

Consider a fleet of $c$ vehicles and $N$ operators. Operators enter the system randomly to request the use of a vehicle. If no vehicles are available, a requesting operator is "blocked" (i.e., the operator leaves without a vehicle). The owner of the fleet would like to pick $c$ small so as to minimize costs, but large enough to ensure that the blocking probability is tolerable.

::: {#o4 .statement cue=named-heading name="Formula"}

## Formula {#Formula}

Let

- $c > 0$ be the (integer) number of servers.
- $N > c$ be the (integer) number of sources of traffic;
- $\lambda > 0$ be the idle source arrival rate (i.e., the rate at which a free source initiates requests);
- $h > 0$ be the average holding time (i.e., the average time it takes for a server to handle a request);

Then, the [probability](wikipedia://en/22934) of blocking is given by[^o5]

$$P=\frac{\binom{N-1}{c}\left(\lambda h\right)^{c}}{\sum_{i=0}^{c}\binom{N-1}{i}\left(\lambda h\right)^{i}}.$$

By rearranging terms, one can rewrite the above formula as[^o6]

$$P = \frac{1}{ {}_2 F_1(1,-c;N-c;-1/(\lambda h) ) }$$

where ${}_2 F_1$ is the Gaussian [hypergeometric function](wikipedia://en/2055223).

::: {#o8 .definition kind=definition/construction cue=heading name="Computation"}

### Computation {#Computation}

There are several recursions[^o9] that can be used to compute $P$ in a numerically stable manner.

Alternatively, any numerical package that supports the [hypergeometric function](wikipedia://en/2055223) can be used. Some examples are given below.

**[Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) with [SciPy](https://en.wikipedia.org/wiki/SciPy)**

```python
from scipy.special import hyp2f1
P = 1.0 / hyp2f1(1, -c, N - c, -1.0 / (Lambda * h))
```

**[MATLAB](wikipedia://en/20412) with the [Symbolic Math Toolbox](http://www.mathworks.com/products/symbolic/)**

```matlab
P = 1 / hypergeom([1, -c], N - c, -1 / (Lambda * h))
```

## Unknown source arrival rate {#Unknown_source_arrival_rate}

In practice, it is often the case that the source arrival rate $\lambda$ is unknown (or hard to estimate) while $\alpha > 0$, the [offered traffic](wikipedia://en/10283) per-source, is known. In this case, one can substitute the relationship

$$\lambda h=\frac{\alpha}{1-\alpha(1-P)}$$

between the source arrival rate and blocking probability into the Engset formula to arrive at the fixed point equation

$$P = f(P)$$

where

$$f(P) = \frac{1}{ {}_2 F_1(1,-c;N-c;1-P-1/\alpha) }.$$

::: {#o12 .definition kind=definition/construction cue=heading name="Computation"}

### Computation {#Computation}

While the above removes the unknown $\lambda$ from the formula, it introduces an additional point of complexity: we can no longer compute the blocking probability directly, and must use an [iterative method](wikipedia://en/15237) instead. While a [fixed-point iteration](wikipedia://en/7344320) is tempting, it has been shown that such an iteration is sometimes [divergent](wikipedia://en/285773) when applied to $f$.[^o6] Alternatively, it is possible to use one of [bisection](wikipedia://en/152547) or [Newton's method](wikipedia://en/22145), for which an [open source implementation](https://github.com/parsiad/fast-engset/releases) is available.

:::
