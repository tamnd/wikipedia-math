# HP-10B

::: {#o2 .subject cue=lead name="HP-10B"}

The **HP-10B** (F1636A) is a student [business calculator](wikipedia://en/28598560) introduced in 1987. The model of this calculator proved to compete well with the higher end [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_Notation) [HP-12C](wikipedia://en/952015).

:::

Two versions of the 10B were produced, the first version came with orange lettering around the keys and used an 1LU7 [HP Saturn](https://en.wikipedia.org/wiki/HP_Saturn) processor, the later model (in 2000) with teal-green labels.[^o3] The functionality of the two versions appears to be identical.

The successor **HP 10BII** (F1902A), which was introduced in 2001, has both cosmetic and architectural changes from its predecessor. It uses a different CPU based on the [Hitachi H8](https://en.wikipedia.org/wiki/Hitachi_H8)[^o4] architecture. The calculator's firmware is not a perfect replica of the overall HP10B functionality. For instance, the keyboard layout is different, with two separate shift keys, and the available numbered-storage registers is reduced from 15 to 10. Early production runs were of poor quality; newer calculators have apparently solved this shortcoming.

The 10BII was released in two cosmetic variants. The first in 2001, branded as "10BII", had a golden bezel and mauve statistical shift button and key labels. The second in 2007, branded as "10bII", had a silver bezel and blue statistical shift button and key labels. As with the cosmetic variants of the original 10B, these two variants also appear to have identical functionality.

In 2011, the 10bII was replaced by the **HP 10bII+** (NW239AA) model 1 (codenamed "Bluestar"[^o5]) with expanded capabilities. This model offers two modes of input logic, [chain input](https://en.wikipedia.org/wiki/Chain_input) which evaluates operators strictly in the order in which they are entered, and algebraic input which observes [PEMDAS](https://en.wikipedia.org/wiki/PEMDAS) operator precedence. Chain input is backwards compatible with the previous models of the series. It added new financial functions such as bonds, break-even, and deprecation functions. Several additional scientific functions were also added, such as trigonometric and hyperbolic functions, their inverses, and several additional statistical regression models. The 10bII+ uses a flashable [Atmel AT91SAM7L128](https://en.wikipedia.org/wiki/Atmel_AT91SAM7L128)[^o6][^o7][^o8][^o9][^o10] processor with [ARM7TDMI](https://en.wikipedia.org/wiki/ARM7TDMI) core.[^o11]

In 2015, the internal hardware of the HP 10bII+ changed to use an [Atmel ATSAM4LC2CA](https://en.wikipedia.org/wiki/Atmel_ATSAM4LC2CA) processor with [ARM Cortex-M4](https://en.wikipedia.org/wiki/ARM_Cortex-M4) core.[^o12] The part number and physical appearance of model 2 didn't change except for a "Rev 2" plate on the bottom side.[^o12] The serial numbers of the new model start with "PHA".[^o12] The 2×3-pin flash port now uses the USB protocol instead of a TTL serial protocol.[^o12]

None of the five models supports [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_Notation).
