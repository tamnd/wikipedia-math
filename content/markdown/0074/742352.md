# Derivative test

::: {#o1 .subject cue=lead name="Derivative test"}

*Image: 1derteszt.png.* A graph illustrating the derivative test

In [calculus](wikipedia://en/5176), a **derivative test** uses the [derivatives](wikipedia://en/7921) of a [function](wikipedia://en/185427) to locate the [critical points](wikipedia://en/1951424) of a function and determine whether each point is a [local maximum](https://en.wikipedia.org/wiki/Local_maximum), a [local minimum](https://en.wikipedia.org/wiki/Local_minimum), or a [saddle point](wikipedia://en/640249). Derivative tests can also give information about the [concavity](wikipedia://en/263321) of a function.

:::

The usefulness of derivatives to find [extrema](https://en.wikipedia.org/wiki/Maxima_and_minima) is proved mathematically by [Fermat's theorem of stationary points](https://en.wikipedia.org/wiki/Fermat's_theorem_%28stationary_points%29).

## First-derivative test {#First-derivative_test}

The first-derivative test examines a function's [monotonic](wikipedia://en/48260) properties (where the function is increasing or decreasing), focusing on a particular point in its [domain](wikipedia://en/50263). If the function "switches" from increasing to decreasing at the point, then the function will achieve a highest value at that point. Similarly, if the function "switches" from decreasing to increasing at the point, then it will achieve a least value at that point. If the function fails to "switch" and remains increasing or remains decreasing, then no highest or least value is achieved.

One can examine a function's monotonicity without calculus. However, calculus is usually helpful because there are [sufficient conditions](https://en.wikipedia.org/wiki/Necessary_and_sufficient_conditions) that guarantee the monotonicity properties above, and these conditions apply to the vast majority of functions one would encounter.

### Precise statement of monotonicity properties {#Precise_statement_of_monotonicity_properties}

Stated precisely, suppose that *f* is a [real](wikipedia://en/20646438)-valued function defined on some [open interval](https://en.wikipedia.org/wiki/Open_interval) containing the point *x* and suppose further that *f* is [continuous](wikipedia://en/6122) at *x*.

- If there exists a positive number *r* > 0 such that *f* is weakly increasing on *x* − *r*, *x* and weakly decreasing on *x*, *x* + *r*, then *f* has a local maximum at *x*.
- If there exists a positive number *r* > 0 such that *f* is strictly increasing on *x* − *r*, *x* and strictly increasing on *x*, *x* + *r*, then *f* is strictly increasing on *x* − *r*, *x* + *r* and does not have a local maximum or minimum at *x*.

Note that in the first case, *f* is not required to be strictly increasing or strictly decreasing to the left or right of *x*, while in the last case, *f* is required to be strictly increasing or strictly decreasing. The reason is that in the definition of local maximum and minimum, the inequality is not required to be strict: e.g. every value of a [constant function](wikipedia://en/320861) is considered both a local maximum and a local minimum.

### Precise statement of first-derivative test {#Precise_statement_of_first-derivative_test}

The first-derivative test depends on the "increasing–decreasing test", which is itself ultimately a consequence of the [mean value theorem](wikipedia://en/19662). It is a direct consequence of the way the [derivative](wikipedia://en/7921) is defined and its connection to decrease and increase of a function locally, combined with the previous section.

Suppose *f* is a real-valued function of a real variable defined on some [interval](wikipedia://en/49172) containing the critical point *a*. Further suppose that *f* is continuous at *a* and [differentiable](wikipedia://en/330206) on some open interval containing *a*, except possibly at *a* itself.

- If there exists a positive number *r* > 0 such that for every *x* in (*a* − *r*, *a*) we have *f*(*x*) ≥ 0, and for every *x* in (*a*, *a* + *r*) we have *f*(*x*) ≤ 0, then *f* has a local maximum at *a*.
- If there exists a positive number *r* > 0 such that for every *x* in (*a* − *r*, *a*) we have *f*(*x*) ≤ 0, and for every *x* in (*a*, *a* + *r*) we have *f*(*x*) ≥ 0, then *f* has a local minimum at *a*.
- If there exists a positive number *r* > 0 such that for every *x* in (*a* − *r*, *a*) ∪ (*a*, *a* + *r*) we have *f*(*x*) > 0, then *f* is strictly increasing at *a* and has neither a local maximum nor a local minimum there.
- If none of the above conditions hold, then the test fails. (Such a condition is not [vacuous](wikipedia://en/51672); there are functions that satisfy none of the first three conditions, e.g. *f*(*x*) = *x*<sup>2</sup> sin(1/*x*)).

Again, corresponding to the comments in the section on monotonicity properties, note that in the first two cases, the inequality is not required to be strict, while in the third, strict inequality is required.

::: {#o6 .application cue=heading name="Applications"}

### Applications {#Applications}

The first-derivative test is helpful in solving [optimization problems](wikipedia://en/1126536) in physics, economics, and engineering. In conjunction with the [extreme value theorem](wikipedia://en/276881), it can be used to find the absolute maximum and minimum of a real-valued function defined on a [closed](https://en.wikipedia.org/wiki/Closed_interval) and [bounded](wikipedia://en/48258) interval. In conjunction with other information such as concavity, inflection points, and [asymptotes](wikipedia://en/3107), it can be used to sketch the [graph](wikipedia://en/87352) of a function.

:::

## Second-derivative test (single variable) {#Second-derivative_test_(single_variable)}

After establishing the [critical points](wikipedia://en/1951424) of a function, the *second-derivative test* uses the value of the [second derivative](wikipedia://en/3224219) at those points to determine whether such points are a local [maximum](https://en.wikipedia.org/wiki/Maxima_and_minima) or a local minimum.[^o8] If the function *f* is twice-differentiable at a critical point *x* (i.e. a point where *f*(*x*) = 0), then:

- If $f''(x) < 0$, then $f$ has a local maximum at $x$.
- If $f''(x) > 0$, then $f$ has a local minimum at $x$.
- If $f''(x) = 0$, the test is inconclusive.

In the last case, [Taylor's theorem](wikipedia://en/51714#Taylor's_theorem_in_one_real_variable) may sometimes be used to determine the behavior of *f* near *x* using [higher derivatives](https://en.wikipedia.org/wiki/Higher_derivative).

::: {#o10 .proof cue=heading name="Proof of the second-derivative test"}

### Proof of the second-derivative test {#Proof_of_the_second-derivative_test}

Suppose we have $f''(x) > 0$ (the proof for $f''(x) < 0$ is analogous). By assumption, $f'(x) = 0$. Then

$$0 < f''(x) = \lim_{h \to 0} \frac{f'(x + h) - f'(x)}{h} = \lim_{h \to 0} \frac{f'(x + h)}{h}.$$

Thus, for *h* sufficiently small we get

$$\frac{f'(x + h)}{h} > 0,$$

which means that $f'(x + h) < 0$ if $h < 0$ (intuitively, *f* is decreasing as it approaches $x$ from the left), and that $f'(x + h) > 0$ if $h > 0$ (intuitively, *f* is increasing as we go right from *x*). Now, by the [first-derivative test](https://en.wikipedia.org/wiki/First-derivative_test), $f$ has a local minimum at $x$.

:::

### Concavity test {#Concavity_test}

A related but distinct use of second derivatives is to determine whether a function is [concave up](wikipedia://en/263321) or concave down at a point. It does not, however, provide information about [inflection points](https://en.wikipedia.org/wiki/Inflection_points). Specifically, a twice-differentiable function *f* is concave up if $f''(x) > 0$ and concave down if $f''(x) < 0$. Note that if $f(x) = x^4$, then $x = 0$ has zero second derivative, yet is not an inflection point, so the second derivative alone does not give enough information to determine whether a given point is an inflection point.

::: {#o13 .pointer-item cue=pointer name="Higher order derivative test"}

### Higher-order derivative test {#Higher-order_derivative_test}

The *higher-order derivative test* or *general derivative test* is able to determine whether a function's critical points are maxima, minima, or points of inflection for a wider variety of functions than the second-order derivative test. As shown below, the second-derivative test is mathematically identical to the special case of *n* = 1 in the higher-order derivative test.

Let *f* be a real-valued, sufficiently differentiable function on an interval $I \subseteq \mathbb{R}$, let $c \in I$, and let $n \ge 1$ be a [natural number](wikipedia://en/21474). Also let all the derivatives of *f* at *c* be zero up to and including the *n*-th derivative, but with the (*n* + 1)th derivative being non-zero:

$$f'(c) = \cdots =f^{(n)}(c) = 0\quad \text{and}\quad f^{(n+1)}(c) \ne 0.$$

There are four possibilities, the first two cases where *c* is an extremum, the second two where *c* is a (local) saddle point:

- If *(n+1)* is [even](wikipedia://en/143135) and $f^{(n+1)}(c) < 0$, then *c* is a local maximum.
- If *(n+1)* is even and $f^{(n+1)}(c) > 0$, then *c* is a local minimum.
- If *(n+1)* is [odd](wikipedia://en/143135) and $f^{(n+1)}(c) < 0$, then *c* is a strictly decreasing point of inflection.
- If *(n+1)* is odd and $f^{(n+1)}(c) > 0$, then *c* is a strictly increasing point of inflection.

Since *(n+1)* must be either odd or even, this analytical test classifies any stationary point of *f*, so long as a nonzero derivative shows up eventually, where $f^{(n+1)}(c) \ne 0.$ is the first non-zero derivative.

:::

::: {#o15 .example cue=heading name="Example"}

### Example {#Example}

Say we want to perform the general derivative test on the function $f(x) = x^6 + 5$ at the point $x = 0$. To do this, we calculate the derivatives of the function and then evaluate them at the point of interest until the result is nonzero.

1. $f'(x) = 6x^5$, $f'(0) = 0;$
1. $f''(x) = 30x^4$, $f''(0) = 0;$
1. $f^{(3)}(x) = 120x^3$, $f^{(3)}(0) = 0;$
1. $f^{(4)}(x) = 360x^2$, $f^{(4)}(0) = 0;$
1. $f^{(5)}(x) = 720x$, $f^{(5)}(0) = 0;$
1. $f^{(6)}(x) = 720$, $f^{(6)}(0) = 720.$

As shown above, at the point $x = 0$, the function $x^6 + 5$ has all of its derivatives at 0 equal to 0, except for the 6th derivative, which is positive. Thus *n* = 5, and by the test, there is a local minimum at 0.

:::

## Multivariable case {#Multivariable_case}

For a function of more than one variable, the second-derivative test generalizes to a test based on the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of the function's [Hessian matrix](wikipedia://en/412108) at the critical point. In particular, assuming that all second-order partial derivatives of *f* are continuous on a [neighbourhood](wikipedia://en/1529485) of a critical point *x*, then if the eigenvalues of the Hessian at *x* are all positive, then *x* is a local minimum. If the eigenvalues are all negative, then *x* is a local maximum, and if some are positive and some negative, then the point is a [saddle point](wikipedia://en/640249). If the Hessian matrix is [singular](wikipedia://en/245528), then the second-derivative test is inconclusive.
