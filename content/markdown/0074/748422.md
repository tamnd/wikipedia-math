# Nontotient

::: {#o1 .subject cue=lead name="Nontotient"}

In [number theory](wikipedia://en/21527), a **nontotient** is a positive integer *n* which is not a [totient number](https://en.wikipedia.org/wiki/Totient_number): it is not in the [image](wikipedia://en/579311) of [Euler's totient function](wikipedia://en/53452) φ, that is, the equation φ(*x*) = *n* has no solution *x*. In other words, *n* is a nontotient if there is no integer *x* that has exactly *n* [coprimes](https://en.wikipedia.org/wiki/Coprime) below it. All odd numbers are nontotients, except [1](https://en.wikipedia.org/wiki/1_%28number%29), since it has the solutions *x* = 1 and *x* = 2. The first few even nontotients are this sequence:

[Carmichael's conjecture](wikipedia://en/19103379) is that there are no *1*s in this sequence.

An even nontotient may be one more than a [prime number](wikipedia://en/23666), but never one less, since all numbers below a prime number are, by definition, coprime to it. To put it algebraically, for p prime: φ(*p*) = *p* − 1. Also, a [pronic number](wikipedia://en/652733) *n*(*n* − 1) is certainly not a nontotient if *n* is prime since φ(*p*<sup>2</sup>) = *p*(*p* − 1).

If a natural number *n* is a totient, *n* · 2<sup>*k*</sup> is a totient for all natural numbers *k*.

There are infinitely many even nontotient numbers: indeed, there are infinitely many distinct primes *p* (such as 78557 and 271129, see [Sierpinski number](https://en.wikipedia.org/wiki/Sierpinski_number)) such that all numbers of the form 2<sup>*a*</sup>*p* are nontotient, and every odd number has an even multiple which is a nontotient.
