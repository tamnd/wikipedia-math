# Generalized game

::: {#o1 .subject cue=lead name="Generalized game"}

In [computational complexity theory](wikipedia://en/7543), a **generalized game** is a game or puzzle that has been generalized so that it can be played on a board or grid of any size. For example, generalized [chess](https://en.wikipedia.org/wiki/Chess) is the game of [chess](https://en.wikipedia.org/wiki/Chess) played on an $n\times n$ board, with $2n$ pieces on each side. Generalized [Sudoku](wikipedia://en/1365807) includes Sudokus constructed on an $n\times n$ grid.

:::

Complexity theory studies the [asymptotic](https://en.wikipedia.org/wiki/Asymptotic) difficulty of problems, so generalizations of games are needed, as games on a fixed size of board are finite problems.

For many generalized games which last for a number of moves polynomial in the size of the board, the problem of determining if there is a win for the first player in a given position is [PSPACE-complete](wikipedia://en/54685). Generalized [hex](wikipedia://en/36703) and [reversi](https://en.wikipedia.org/wiki/Reversi) are PSPACE-complete.[^o2][^o3]

For many generalized games which may last for a number of moves exponential in the size of the board, the problem of determining if there is a win for the first player in a given position is [EXPTIME-complete](https://en.wikipedia.org/wiki/EXPTIME-complete). Generalized [chess](https://en.wikipedia.org/wiki/Chess), [go](https://en.wikipedia.org/wiki/Go_%28board_game%29) (with Japanese ko rules), [Quixo](https://en.wikipedia.org/wiki/Quixo),[^o4] and [checkers](https://en.wikipedia.org/wiki/Checkers) are EXPTIME-complete.[^o5][^o6][^o7]
