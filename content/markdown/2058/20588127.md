# SPSS Modeler

::: {#o2 .subject cue=lead name="SPSS Modeler"}

**IBM SPSS Modeler** is a [data mining](wikipedia://en/42253) and [text analytics](https://en.wikipedia.org/wiki/Text_analytics) software application from [IBM](https://en.wikipedia.org/wiki/IBM). It is used to build [predictive models](wikipedia://en/2538775) and conduct other analytic tasks. It has a visual interface which allows users to leverage statistical and data mining algorithms without programming.

:::

One of its main aims from the outset was to eliminate needless complexity in data transformations, and make complex predictive models very easy to use.

The first version incorporated decision trees (ID3), and neural networks (backprop), which could both be trained without underlying knowledge of how those techniques worked.

IBM SPSS Modeler was originally named Clementine by its creators, Integral Solutions Limited. This name continued for a while after SPSS's acquisition of the product. [SPSS](https://en.wikipedia.org/wiki/SPSS_Inc.) later changed the name to SPSS Clementine, and then later to PASW Modeler.[^o3] Following IBM's 2009 acquisition of SPSS, the product was renamed IBM SPSS Modeler, its current name. SPSS Modeler supports a wide range of analytical techniques[^o6], including classification, clustering, forecasting, and text mining, and is commonly used in business analytics, research, and decision-support systems.

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

SPSS Modeler has been used in these and other industries:

- [Customer analytics](https://en.wikipedia.org/wiki/Customer_analytics)[^o6] and [Customer relationship management](https://en.wikipedia.org/wiki/Customer_relationship_management) (CRM)
- [Fraud detection](https://en.wikipedia.org/wiki/Fraud_detection) and prevention[^o7]
- Optimizing insurance claims
- [Risk management](https://en.wikipedia.org/wiki/Risk_management)
- Manufacturing quality improvement
- Healthcare quality improvement[^o8]
- [Forecasting](wikipedia://en/246074) demand or sales
- Law enforcement[^o9] and border security
- Education[^o10]
- Telecommunications[^o11]
- Entertainment: e.g., predicting movie box office receipts[^o12][^o13]

:::

## Editions {#Editions}

IBM sells the version of SPSS Modeler 18.2.1 in two separate bundles of features. These two bundles are called "editions" by IBM:

- **SPSS Modeler Professional:** used for structured data, such as databases, mainframe data systems, flat files or [BI](wikipedia://en/168387) systems
- **SPSS Modeler Premium:** Includes all the features of Modeler Professional, with the addition of:

– [Text analytics](https://en.wikipedia.org/wiki/Text_analytics)

Both editions are available in desktop and server configurations.

In addition to the traditional IBM SPSS Modeler desktop installations, IBM now offers the SPSS Modeler interface as an option in the Watson Studio product line which includes Watson Studio (cloud), Watson Studio Local, and Watson Studio Desktop.

## Product history {#Product_history}

Early versions of the software were called Clementine and were Unix-based. The first version was released on Jun 9th 1994, after Beta testing at 6 customer sites. Clementine was originally developed by a UK company named Integral Solutions Limited (ISL),[^o16] in Collaboration with [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) researchers at the [University of Sussex](https://en.wikipedia.org/wiki/University_of_Sussex). The original Clementine was implemented in [Poplog](https://en.wikipedia.org/wiki/Poplog), which ISL marketed for that University.

Clementine mainly used the Poplog languages, [Pop-11](https://en.wikipedia.org/wiki/Pop-11), with some parts written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) for speed (such as the neural network engine), along with additional tools provided as part of [Solaris](https://en.wikipedia.org/wiki/Oracle_Solaris), [VMS](https://en.wikipedia.org/wiki/OpenVMS) and various versions of [Unix](https://en.wikipedia.org/wiki/Unix). The tool quickly garnered the attention of the data mining community (at that time in its infancy).

In order to reach a larger market, ISL then Ported Poplog to [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) using the NutCracker package, later named [MKS Toolkit](https://en.wikipedia.org/wiki/MKS_Toolkit) to provide the Unix graphical facilities. Original in many respects, Clementine was the first data mining tool to use an icon based [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) rather than requiring users to write in a [programming language](wikipedia://en/23015), though that option remained available for expert users.

In 1998 ISL was acquired by [SPSS Inc.](https://en.wikipedia.org/wiki/SPSS_Inc.), who saw the potential for extended development as a commercial data mining tool. In early 2000, the software was developed into a [client–server model](https://en.wikipedia.org/wiki/Client–server_model) architecture, and shortly afterward, the client front-end interface component was rewritten fully and replaced with a new [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) front-end, which allowed deeper integration with the other tools provided by SPSS.

SPSS Clementine version 7.0: The client front-end runs under Windows. The server back-end [Unix](https://en.wikipedia.org/wiki/Unix) variants ([SunOS](https://en.wikipedia.org/wiki/SunOS), [HP-UX](https://en.wikipedia.org/wiki/HP-UX), [AIX](https://en.wikipedia.org/wiki/AIX)), [Linux](https://en.wikipedia.org/wiki/Linux), and [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows). The [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) is written in Java.

IBM SPSS Modeler 14.0 was the first release of Modeler by IBM.

IBM SPSS Modeler 15, released in June 2012, introduced significant new functions for *social network analysis* and *entity analytics*.
