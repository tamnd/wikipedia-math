# Binary decision

::: {#o1 .subject cue=lead name="Binary decision"}

A **binary decision** is a choice between two alternatives, for instance between taking some specific action or not taking it.[^o2]

:::

Binary decisions are basic to many fields. Examples include:

- [Truth values](wikipedia://en/161711) in [mathematical logic](wikipedia://en/19636), and the corresponding [Boolean data type](https://en.wikipedia.org/wiki/Boolean_data_type) in [computer science](https://en.wikipedia.org/wiki/Computer_science), representing a value which may be chosen to be either true or false.[^o3]
- [Conditional statements](https://en.wikipedia.org/wiki/Conditional_%28computer_programming%29) (if-then or if-then-else) in computer science, binary decisions about which piece of code to execute next.[^o4]
- [Decision trees](wikipedia://en/232602) and [binary decision diagrams](wikipedia://en/576855), representations for sequences of binary decisions.[^o5]
- [Binary choice](https://en.wikipedia.org/wiki/Binary_choice), a [statistical model](wikipedia://en/27576) for the outcome of a binary decision.[^o6]

## Binary decision diagrams {#Binary_decision_diagrams}

A [binary decision diagram](wikipedia://en/576855) (BDD) is a way to visually represent a [boolean function](wikipedia://en/753349). One application of BDDs is in CAD software and digital circuit analysis where they are an efficient way to represent and manipulate boolean functions.[^o8]

*Image: BDD simple.svg.* Reduced Ordered Binary Decision Diagram for the boolean function $f$

The value of a boolean function can be determined by following a path in its BDD down to a terminal, making a binary decision at each node where a solid line is followed if the value of the variable at the node is true and a dotted line if it is false. A BDD is said to be 'ordered' if the order of the variables tested is fixed. A BDD is said to be 'reduced' if the two following conditions are true:

- Each successor of each node is distinct.
- There are no two distinct nodes of the same variable with the same successors.[^o9][^o10]

BDDs that are ordered and reduced can be called Reduced Ordered Binary Decision Diagrams (ROBDD). An example of a ROBDD is the figure to the right, which represents the function $f(x_1,x_2,x_3)=\bar{x}_1\bar{x}_2\bar{x}_3+x_1x_2+x_2x_3$. The order of the variables along any path is always $x_1$, $x_2$, then $x_3$, all nodes have distinct successors, and there are no two nodes of the same variable and the same successors.

## Conditional statements {#Conditional_statements}

In computer science, [conditional statements](https://en.wikipedia.org/wiki/Conditional_%28computer_programming%29) are used to make binary decisions.[^o12] A program can perform different computations or actions depending on whether a certain boolean value evaluates to true or false.

The [if-then-else](https://en.wikipedia.org/wiki/If-then-else) construct is a [control flow statement](https://en.wikipedia.org/wiki/Control_flow_statement) which runs one of two code blocks depending on the value of a [boolean expression](wikipedia://en/3126968), and its structure looks like this:

```
if condition then
    code block 1
else
    code block 2
end
```

*Image: IF-THEN-ELSE-END flowchart.png.* Flowchart illustrating the use of `else if`

The conditional expression is `condition`, and if it is true, then `code block 1` is executed, otherwise `code block 2` is executed. It is also possible to combine multiple conditions with the else-if construct:

```
if condition 1 then
    code block 1
else if condition 2 then
    code block 2
else
    code block 3
end
```

This can be represented by the flow diagram on the right. If one condition is found to be true, then the rest are skipped, so only one of the three [code blocks](https://en.wikipedia.org/wiki/Block_%28programming%29) above can be executed.

A [while loop](https://en.wikipedia.org/wiki/While_loop) is a control flow statement which executes a code block repeatedly until its boolean expression becomes false, making a decision on whether to continue repeating before each loop. This is similar to the if-then construct, but it can executing a code block multiple times.
