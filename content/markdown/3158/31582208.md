# Banach algebra cohomology

::: {#o1 .subject cue=lead name="Banach algebra cohomology"}

In [mathematics](wikipedia://en/18831), **Banach algebra cohomology** of a [Banach algebra](wikipedia://en/4665) with coefficients in a bimodule is a [cohomology](wikipedia://en/194060) theory defined in a similar way to [Hochschild cohomology](https://en.wikipedia.org/wiki/Hochschild_cohomology) of an [abstract algebra](wikipedia://en/19616384), except that one takes the topology into account so that all cochains and so on are continuous.[^o2][^o3]

:::
