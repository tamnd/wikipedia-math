# Centered set

::: {#o1 .subject cue=lead name="Centered set"}

In [mathematics](wikipedia://en/18831), in the area of order theory, an **upwards centered set** *S* is a [subset](wikipedia://en/27631) of a [partially ordered set](wikipedia://en/23572), *P*, such that any finite subset of *S* has an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) in *P*. Similarly, any finite subset of a **downwards centered set** has a lower bound. An upwards centered set can also be called a **consistent set**. Any [directed set](wikipedia://en/9165) is necessarily centered, and any centered set is a [linked set](wikipedia://en/32926234).

:::

A subset *B* of a partial order is said to be **σ-centered** if it is a [countable](https://en.wikipedia.org/wiki/Countable) [union](wikipedia://en/47949) of centered sets.
