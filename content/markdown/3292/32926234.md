# Linked set

::: {#o1 .subject cue=lead name="Linked set"}

In [mathematics](wikipedia://en/18831), an **upwards linked set** *A* is a [subset](wikipedia://en/27631) of a [partially ordered set](wikipedia://en/23572), *P*, in which any two of elements *A* have a common [upper bound](https://en.wikipedia.org/wiki/Upper_bound) in *P*. Similarly, every pair of elements of a **downwards linked set** has a lower bound. Every [centered set](wikipedia://en/32926187) is linked, which includes, in particular, every [directed set](wikipedia://en/9165).

:::
