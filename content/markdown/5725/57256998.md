# Gekko (optimization software)

::: {#o2 .subject cue=lead name="Gekko"}

The **GEKKO** Python package[^o3] solves large-scale mixed-integer and differential algebraic equations with nonlinear programming solvers ([IPOPT](https://en.wikipedia.org/wiki/IPOPT), [APOPT](https://en.wikipedia.org/wiki/APOPT), BPOPT, [SNOPT](https://en.wikipedia.org/wiki/SNOPT), [MINOS](https://en.wikipedia.org/wiki/MINOS_%28optimization_software%29)). Modes of operation include machine learning, data reconciliation, real-time optimization, dynamic simulation, and nonlinear [model predictive control](wikipedia://en/1100516). In addition, the package solves [Linear programming](wikipedia://en/43730) (LP), [Quadratic programming](wikipedia://en/40324) (QP), [Quadratically constrained quadratic program](wikipedia://en/9519121) (QCQP), [Nonlinear programming](wikipedia://en/679709) (NLP), [Mixed integer programming](https://en.wikipedia.org/wiki/Mixed_integer_programming) (MIP), and [Mixed integer linear programming](https://en.wikipedia.org/wiki/Mixed_integer_linear_programming) (MILP). GEKKO is available in Python and installed with pip from PyPI of the Python Software Foundation.

:::

```python
pip install gekko
```

GEKKO works on all platforms and with Python 2.7 and 3+. By default, the problem is sent to a public server where the solution is computed and returned to Python. There are Windows, MacOS, Linux, and ARM (Raspberry Pi) processor options to solve without an Internet connection. GEKKO is an extension of the [APMonitor Optimization Suite](https://en.wikipedia.org/wiki/APMonitor) but has integrated the modeling and solution visualization directly within Python. A mathematical model is expressed in terms of variables and equations such as the Hock & Schittkowski Benchmark Problem #71[^o4] used to test the performance of [nonlinear programming](wikipedia://en/679709) solvers. This particular optimization problem has an objective function $\min_{x\in\mathbb R}\; x_1 x_4 (x_1+x_2+x_3)+x_3$ and subject to the inequality constraint $x_1 x_2 x_3 x_4 \ge 25$ and equality constraint ${x_1}^2 + {x_2}^2 + {x_3}^2 + {x_4}^2=40$. The four variables must be between a lower bound of 1 and an upper bound of 5. The initial guess values are $x_1 = 1, x_2=5, x_3=5, x_4=1$. This optimization problem is solved with GEKKO as shown below.

```python
from gekko import GEKKO

m = GEKKO()  # Initialize gekko
# Initialize variables
x1 = m.Var(value=1, lb=1, ub=5)
x2 = m.Var(value=5, lb=1, ub=5)
x3 = m.Var(value=5, lb=1, ub=5)
x4 = m.Var(value=1, lb=1, ub=5)
# Equations
m.Equation(x1 * x2 * x3 * x4 >= 25)
m.Equation(x1 ** 2 + x2 ** 2 + x3 ** 2 + x4 ** 2 == 40)
m.Minimize(x1 * x4 * (x1 + x2 + x3) + x3)
m.solve(disp=False)  # Solve
print("x1: " + str(x1.value))
print("x2: " + str(x2.value))
print("x3: " + str(x3.value))
print("x4: " + str(x4.value))
print("Objective: " + str(m.options.objfcnval))
```

## Applications of GEKKO {#Applications_of_GEKKO}

Applications include [cogeneration (power and heat)](https://en.wikipedia.org/wiki/Cogeneration),[^o7] [drilling automation](https://en.wikipedia.org/wiki/Oil_well),[^o8] severe slugging control,[^o9] solar thermal energy production,[^o10] [solid oxide fuel cells](https://en.wikipedia.org/wiki/Solid_oxide_fuel_cell),[^o11][^o12] flow assurance,[^o13] [Enhanced oil recovery](https://en.wikipedia.org/wiki/Enhanced_oil_recovery),[^o14] [Essential oil](https://en.wikipedia.org/wiki/Essential_oil) extraction,[^o15] and [Unmanned Aerial Vehicles (UAVs)](https://en.wikipedia.org/wiki/Unmanned_aerial_vehicle).[^o16] There are many other references to APMonitor and GEKKO as a sample of the types of applications that can be solved. GEKKO is developed from the National Science Foundation (NSF) research grant #1547110 [^o17][^o18][^o19][^o20] and is detailed in a Special Issue collection on combined scheduling and control.[^o21] Other notable mentions of GEKKO are the listing in the Decision Tree for Optimization Software,[^o22] added support for [APOPT](https://en.wikipedia.org/wiki/APOPT) and BPOPT solvers,[^o23] projects reports of the online Dynamic Optimization course from international participants.[^o24] GEKKO is a topic in online forums where users are solving optimization and optimal control problems.[^o25][^o26] GEKKO is used for advanced control in the Temperature Control Lab (TCLab)[^o27] for process control education at 20 universities.[^o28][^o29][^o30][^o31]

### Machine learning {#Machine_learning}

*Image: Artificial Neural Network Example.png.* Artificial Neural Network

One application of [machine learning](wikipedia://en/233488) is to perform regression from training data to build a correlation. In this example, [deep learning](https://en.wikipedia.org/wiki/Deep_learning) generates a model from training data that is generated with the function $1-\cos(x)$. An [artificial neural network](https://en.wikipedia.org/wiki/Artificial_neural_network) with three layers is used for this example. The first layer is linear, the second layer has a hyperbolic tangent activation function, and the third layer is linear. The program produces parameter weights that minimize the sum of squared errors between the measured data points and the neural network predictions at those points. GEKKO uses gradient-based optimizers to determine the optimal weight values instead of standard methods such as [backpropagation](https://en.wikipedia.org/wiki/Backpropagation). The gradients are determined by automatic differentiation, similar to other popular packages. The problem is solved as a constrained optimization problem and is converged when the solver satisfies [Karush–Kuhn–Tucker conditions](wikipedia://en/2397362). Using a gradient-based optimizer allows additional constraints that may be imposed with domain knowledge of the data or system.

```numpy
from gekko import brain
import numpy as np

b = brain.Brain()
b.input_layer(1)
b.layer(linear=3)
b.layer(tanh=3)
b.layer(linear=3)
b.output_layer(1)
x = np.linspace(-np.pi, 3 * np.pi, 20)
y = 1 - np.cos(x)
b.learn(x, y)
```

The neural network model is tested across the range of training data as well as for extrapolation to demonstrate poor predictions outside of the training data. Predictions outside the training data set are improved with hybrid machine learning that uses fundamental principles (if available) to impose a structure that is valid over a wider range of conditions. In the example above, the hyperbolic tangent activation function (hidden layer 2) could be replaced with a sine or cosine function to improve extrapolation. The final part of the script displays the neural network model, the original function, and the sampled data points used for fitting.

```numpy
import matplotlib.pyplot as plt

xp = np.linspace(-2 * np.pi, 4 * np.pi, 100)
yp = b.think(xp)

plt.figure()
plt.plot(x, y, "bo")
plt.plot(xp, yp[0], "r-")
plt.show()
```

### Optimal control {#Optimal_control}

*Image: Optimal Control Luus.png.* Optimal control problem benchmark (Luus) with an integral objective, inequality, and differential constraint.

[Optimal control](wikipedia://en/362565) is the use of [mathematical optimization](wikipedia://en/52033) to obtain a policy that is constrained by differential $\left(\frac{d\,x_1}{d\,t}=u\right)$, equality $\left(x_1(0) = 1\right)$, or inequality $\left(-1 \le u(t) \le 1\right)$ equations and minimizes an objective/reward function $\left(\min_u \frac{1}{2} \int_0^2 x_1^2(t) \, dt\right)$. The basic optimal control is solved with GEKKO by integrating the objective and transcribing the differential equation into algebraic form with orthogonal collocation on finite elements.

```numpy
from gekko import GEKKO
import numpy as np
import matplotlib.pyplot as plt

m = GEKKO()  # initialize gekko
nt = 101
m.time = np.linspace(0, 2, nt)
# Variables
x1 = m.Var(value=1)
x2 = m.Var(value=0)
u = m.Var(value=0, lb=-1, ub=1)
p = np.zeros(nt)  # mark final time point
p[-1] = 1.0
final = m.Param(value=p)
# Equations
m.Equation(x1.dt() == u)
m.Equation(x2.dt() == 0.5 * x1 ** 2)
m.Minimize(x2 * final)
m.options.IMODE = 6  # optimal control mode
m.solve()  # solve
plt.figure(1)  # plot results
plt.plot(m.time, x1.value, "k-", label=r"$x_1$")
plt.plot(m.time, x2.value, "b-", label=r"$x_2$")
plt.plot(m.time, u.value, "r--", label=r"$u$")
plt.legend(loc="best")
plt.xlabel("Time")
plt.ylabel("Value")
plt.show()
```
