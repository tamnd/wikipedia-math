# Projection plane

::: {#o1 .subject cue=lead name="Projection plane"}

A **projection plane**, or **plane of projection**, is a type of view in which graphical projections from an object intersect.[^o2] Projection planes are used often in [descriptive geometry](wikipedia://en/484891) and graphical representation. A [picture plane](wikipedia://en/937408) in [perspective drawing](https://en.wikipedia.org/wiki/Perspective_drawing) is a type of projection plane.

:::

With perspective drawing, the **lines of sight**, or **projection lines**, between an object and a picture plane return to a [vanishing point](https://en.wikipedia.org/wiki/Vanishing_point) and are not parallel. With [parallel projection](wikipedia://en/2503009) the lines of sight from the object to the projection plane are parallel.
