# Higraph

::: {#o1 .subject cue=lead name="Higraph"}

A **higraph** is a diagramming object that formalizes relations into a visual structure. It was developed by [David Harel](https://en.wikipedia.org/wiki/David_Harel) in 1988. Higraphs extend [mathematical graphs](wikipedia://en/325806) by including notions of depth and [orthogonality](wikipedia://en/102221). In particular, [nodes](https://en.wikipedia.org/wiki/Node_%28graph_theory%29) in a higraph can contain other nodes inside them, creating a hierarchy. The idea was initially developed for applications to [databases](https://en.wikipedia.org/wiki/Databases), [knowledge representation](https://en.wikipedia.org/wiki/Knowledge_representation), and the behavioral specification of complex [concurrent systems](https://en.wikipedia.org/wiki/Concurrent_systems) using the higraph-based language of statecharts.

:::

Higraphs are widely used in industrial applications like [UML](https://en.wikipedia.org/wiki/Unified_Modeling_Language). Recently they have been used by [philosophers](https://en.wikipedia.org/wiki/Philosophers) to formally study the use of [diagrams](https://en.wikipedia.org/wiki/Diagrams) in [mathematical proofs](wikipedia://en/82285) and reasoning.
