# Appert topology

::: {#o1 .subject cue=lead name="Appert topology"}

In [general topology](wikipedia://en/178649), a branch of mathematics, the **Appert topology**, named for (txt), is a [topology](wikipedia://en/30450) on the set *X* = {1, 2, 3, ...} of [positive integers](wikipedia://en/21474).[^o3] In the Appert topology, the open sets are those that do not contain 1, and those that asymptotically contain almost every positive integer. The space *X* with the Appert topology is called the **Appert space**.[^o3]

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

For a subset *S* of *X*, let N(*n*,*S*) denote the number of elements of *S* which are less than or equal to *n*:

$$\mathrm{N}(n,S) = \#\{ m \in S : m \le n \} .$$

*S* is defined to be open in the Appert topology if either it does not contain 1 or if it has [asymptotic density](https://en.wikipedia.org/wiki/Asymptotic_density) equal to 1, i.e., it satisfies

$$\lim_{n \to \infty} \frac{\text{N}(n,S)}{n} = 1.$$

The empty set is open because it does not contain 1, and the whole set *X* is open since $\text{N}(n,X)/n=1$ for all *n*.

:::

## Related topologies {#Related_topologies}

The Appert topology is closely related to the [Fort space](wikipedia://en/10105571) topology that arises from giving the set of integers greater than one the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology), and then taking the point 1 as the point at infinity in a [one point compactification](https://en.wikipedia.org/wiki/One_point_compactification) of the space.[^o3] The Appert topology is finer than the Fort space topology, as any cofinite subset of *X* has asymptotic density equal to 1.

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The closed subsets *S* of *X* are those that either contain 1 or that have zero asymptotic density, namely $\lim_{n\to\infty} \mathrm{N}(n,S)/n = 0$.
- Every point of *X* has a [local basis](https://en.wikipedia.org/wiki/Local_basis) of [clopen sets](https://en.wikipedia.org/wiki/Clopen_sets), i.e., *X* is a [zero-dimensional space](wikipedia://en/517682).[^o3] *Proof*: Every open neighborhood of 1 is also closed. For any $x\ne 1$, $\{x\}$ is both closed and open.
- *X* is [Hausdorff](wikipedia://en/13637) and [perfectly normal](https://en.wikipedia.org/wiki/Perfectly_normal_space) (T<sub>6</sub>). *Proof*: *X* is T<sub>1</sub>. Given any two disjoint closed sets *A* and *B*, at least one of them, say *A*, does not contain 1. *A* is then clopen and *A* and its complement are disjoint respective neighborhoods of *A* and *B*, which shows that *X* is normal and Hausdorff. Finally, any subset, in particular any closed subset, in a countable T<sub>1</sub> space is a G<sub>δ</sub>, so *X* is perfectly normal.
- *X* is countable, but not [first countable](https://en.wikipedia.org/wiki/First_countable),[^o3] and hence not [second countable](https://en.wikipedia.org/wiki/Second_countable) and not [metrizable](https://en.wikipedia.org/wiki/Metrizable).
- A subset of *X* is [compact](wikipedia://en/6042) if and only if it is finite. In particular, *X* is not [locally compact](wikipedia://en/48632), since there is no compact neighborhood of 1.
- *X* is not [countably compact](https://en.wikipedia.org/wiki/Countably_compact).[^o3] *Proof:* The infinite set $\{2^n:n\ge 1\}$ has zero asymptotic density, hence is closed in *X*. Each of its points is isolated. Since *X* contains an infinite closed discrete subset, it is not [limit point compact](wikipedia://en/9861462), and therefore it is not countably compact.

:::
