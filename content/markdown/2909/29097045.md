# Probable error

::: {#o1 .subject cue=lead name="Probable error"}

In [statistics](wikipedia://en/26685), **probable error** defines the [half-range](https://en.wikipedia.org/wiki/Half-range) of an interval about a [central point](https://en.wikipedia.org/wiki/Central_tendency) for the distribution, such that half of the values from the distribution will lie within the interval and half outside.[^o2] Thus for a [symmetric distribution](https://en.wikipedia.org/wiki/Symmetric_distribution) it is equivalent to half the [interquartile range](wikipedia://en/14812), or the [median absolute deviation](wikipedia://en/10050999). One such use of the term *probable error* in this sense is as the name for the [scale parameter](wikipedia://en/769503) of the [Cauchy distribution](wikipedia://en/7003), which does not have a standard deviation.

:::

The probable error can also be expressed as a multiple of the standard deviation σ,[^o2][^o3] which requires that at least the second [statistical moment](https://en.wikipedia.org/wiki/Statistical_moment) of the distribution should exist, whereas the other definition does not. For a [normal distribution](wikipedia://en/21462) this is $\gamma = 0.6745 \times \sigma$ (see [details](wikipedia://en/10050999#Relation_to_standard_deviation)).
