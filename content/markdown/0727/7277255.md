# Continuous embedding

::: {#o1 .subject cue=lead name="Continuous embedding"}

In [mathematics](wikipedia://en/18831), one [normed vector space](wikipedia://en/21538) is said to be **continuously embedded** in another normed vector space if the [inclusion function](https://en.wikipedia.org/wiki/Inclusion_function) between them is [continuous](wikipedia://en/6122). In some sense, the two norms are "almost equivalent", even though they are not both defined on the same space. Several of the [Sobolev embedding theorems](wikipedia://en/4665038) are continuous embedding theorems.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* and *Y* be two normed vector spaces, with norms ||·||<sub>*X*</sub> and ||·||<sub>*Y*</sub> respectively, such that *X* ⊆ *Y*. If the [inclusion map (identity function)](wikipedia://en/15069)

$$i : X \hookrightarrow Y : x \mapsto x$$

is continuous, i.e. if there exists a constant *C* > 0 such that

$$\| x \|_Y \leq C \| x \|_X$$

for every *x* in *X*, then *X* is said to be **continuously embedded** in *Y*. Some authors use the hooked arrow "↪" to denote a continuous embedding, i.e. "*X* ↪ *Y*" means "*X* and *Y* are normed spaces with *X* continuously embedded in *Y*". This is a consistent use of notation from the point of view of the [category of topological vector spaces](wikipedia://en/15089522), in which the [morphisms](wikipedia://en/27716891) ("arrows") are the [continuous linear maps](https://en.wikipedia.org/wiki/Continuous_linear_map).

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- A finite-dimensional example of a continuous embedding is given by a natural embedding of the [real line](https://en.wikipedia.org/wiki/Real_line) *X* = **R** into the plane *Y* = **R**<sup>2</sup>, where both spaces are given the Euclidean norm:

$$i : \mathbf{R} \to \mathbf{R}^2 : x \mapsto (x, 0)$$

In this case, ||*x*||<sub>*X*</sub> = ||*x*||<sub>*Y*</sub> for every real number *X*. Clearly, the optimal choice of constant *C* is *C* = 1.

- An infinite-dimensional example of a continuous embedding is given by the [Rellich–Kondrachov theorem](wikipedia://en/7907151): let Ω ⊆ **R**<sup>*n*</sup> be an [open](wikipedia://en/39358), [bounded](wikipedia://en/48258), [Lipschitz domain](wikipedia://en/7820612), and let 1 ≤ *p* \< *n*. Set

$$p^{*} = \frac{n p}{n - p}.$$

Then the Sobolev space *W*<sup>1,*p*</sup>(Ω; **R**) is continuously embedded in the [*L*<sup>*p*</sup> space](wikipedia://en/45194) *L*<sup>*p*<sup>∗</sup></sup>(Ω; **R**). In fact, for 1 ≤ *q* \< *p*<sup>∗</sup>, this embedding is [compact](https://en.wikipedia.org/wiki/Compactly_embedded). The optimal constant *C* will depend upon the geometry of the domain Ω.

- Infinite-dimensional spaces also offer examples of *discontinuous* embeddings. For example, consider

$$X = Y = C^0 ([0, 1]; \mathbf{R}),$$

the space of continuous real-valued functions defined on the unit interval, but equip *X* with the *L*<sup>1</sup> norm and *Y* with the [supremum norm](https://en.wikipedia.org/wiki/Supremum_norm). For *n* ∈ **N**, let *f*<sub>*n*</sub> be the [continuous](wikipedia://en/6122), [piecewise linear function](wikipedia://en/444224) given by

$$f_n (x) = \begin{cases} - n^2 x + n , & 0 \leq x \leq \tfrac 1 n; \\ 0, & \text{otherwise.} \end{cases}$$

Then, for every *n*, ||*f*<sub>*n*</sub>||<sub>*Y*</sub> = ||*f*<sub>*n*</sub>||<sub>∞</sub> = *n*, but

$$\| f_n \|_{L^1} = \int_0^1 | f_n (x) | \, \mathrm{d} x = \frac1{2}.$$

Hence, no constant *C* can be found such that ||*f*<sub>*n*</sub>||<sub>*Y*</sub> ≤ *C*||*f*<sub>*n*</sub>||<sub>*X*</sub>, and so the embedding of *X* into *Y* is discontinuous.

:::
