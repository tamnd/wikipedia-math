# Boundary value problem

*Image: Boundary value problem-en.svg.* Shows a region where a [differential equation](wikipedia://en/1424309) is valid and the associated boundary values

::: {#o1 .subject cue=lead name="Boundary value problem"}

In the study of [differential equations](wikipedia://en/1424309), a **boundary-value problem** is a [differential equation](wikipedia://en/1424309) subjected to constraints called **boundary conditions**.[^o2] A solution to a boundary value problem is a solution to the differential equation which also satisfies the boundary conditions.

:::

Boundary value problems arise in several branches of physics as any physical differential equation will have them. Problems involving the [wave equation](wikipedia://en/33691), such as the determination of [normal modes](wikipedia://en/478195), are often stated as boundary value problems. A large class of important boundary value problems are the [Sturm–Liouville problems](wikipedia://en/490990). The analysis of these problems, in the linear case, involves the [eigenfunctions](wikipedia://en/228601) of a [differential operator](wikipedia://en/263886).

To be useful in applications, a boundary value problem should be [well posed](wikipedia://en/176673). This means that given the input to the problem there exists a unique solution, which depends continuously on the input. Much theoretical work in the field of [partial differential equations](wikipedia://en/52564) is devoted to proving that boundary value problems arising from scientific and engineering applications are in fact well-posed.

Among the earliest boundary value problems to be studied is the [Dirichlet problem](wikipedia://en/571109), of finding the [harmonic functions](wikipedia://en/55762) (solutions to [Laplace's equation](wikipedia://en/36941)); the solution was given by the [Dirichlet's principle](wikipedia://en/1240011).

## Explanation {#Explanation}

Boundary value problems are similar to [initial value problems](wikipedia://en/498383). A boundary value problem has conditions specified at the extremes ("boundaries") of the independent variable in the equation whereas an initial value problem has all of the conditions specified at the same value of the independent variable (and that value is at the lower boundary of the domain, thus the term "initial" value). A **boundary value** is a data value that corresponds to a minimum or maximum input, internal, or output value specified for a system or component.[^o4]

For example, if the independent variable is time over the domain \[0,1\], a boundary value problem would specify values for $y(t)$ at both $t=0$ and $t=1$, whereas an initial value problem would specify a value of $y(t)$ and $y'(t)$ at time $t=0$.

Finding the temperature at all points of an iron bar with one end kept at [absolute zero](https://en.wikipedia.org/wiki/Absolute_zero) and the other end at the freezing point of water would be a boundary value problem.

If the problem is dependent on both space and time, one could specify the value of the problem at a given point for all time or at a given time for all space.

Concretely, an example of a boundary value problem (in one spatial dimension) is

$$y''(x)+y(x)=0$$

to be solved for the unknown function $y(x)$ with the boundary conditions

$$y(0)=0, \ y(\pi/2)=2.$$

Without the boundary conditions, the general solution to this equation is

$$y(x) = A \sin(x) + B \cos(x).$$

From the boundary condition $y(0)=0$ one obtains

$$0 = A \cdot 0 + B \cdot 1$$

which implies that $B=0.$ From the boundary condition $y(\pi/2)=2$ one finds

$$2 = A \cdot 1$$

and so $A=2.$ One sees that imposing boundary conditions allowed one to determine a unique solution, which in this case is

$$y(x)=2\sin(x).$$

## Types of boundary value problems {#Types_of_boundary_value_problems}

The 3 standard classes[^o7] of conditions are Dirichlet, Neumann and Cauchy[^o6] or Robin,[^o7] with also mixed,[^o8] boundary as infinity.[^o9]

Summary of boundary conditions for the unknown function, $y$, constants $c_0$ and $c_1$ specified by the boundary conditions, and known scalar functions $f$ and $g$ specified by the boundary conditions.

::: {#o10 .table cue=table}

| Name | Form on 1st part of boundary | Form on 2nd part of boundary |
|---|---|---|
| [Dirichlet](wikipedia://en/423504) | $y=f$ |  |
| [Neumann](wikipedia://en/735443) | ${\partial y \over \partial n}=f$ |  |
| [Robin](wikipedia://en/9945920) | $c_0 y + c_1 {\partial y \over \partial n}=f$ |  |
| [Cauchy](wikipedia://en/1725025) | both $y=f$ and ${\partial y \over \partial n}=g$ |  |
| [Mixed](wikipedia://en/2784886) | $y=f$ | $c_0 y + c_1 {\partial y \over \partial n}=g$ |

:::

### Boundary value conditions {#Boundary_value_conditions}

*Image: Bounday value problem for a rod.PNG.* Finding a function to describe the temperature of this idealised 2D rod is a boundary value problem with [Dirichlet boundary conditions](wikipedia://en/423504). Any solution function will both solve the [heat equation](wikipedia://en/166415), and fulfill the boundary conditions of a temperature of 0 K on the left boundary and a temperature of 273.15 K on the right boundary.

A type 1 boundary condition, [Dirichlet boundary condition](wikipedia://en/423504),[^o17] specifies the value of the function itself. For example, if one end of an iron rod is held at absolute zero, then the value of the problem would be known at that point in space.

A type 2 boundary condition, [Neumann boundary condition](wikipedia://en/735443),[^o17] specifies the value of the [normal derivative](https://en.wikipedia.org/wiki/Normal_derivative) of the function. For example, if there is a heater at one end of an iron rod, then energy would be added at a constant rate but the actual temperature would not be known.

A type 3 boundary condition is the Robin condition.[^o17]

If the boundary has the form of a curve or surface that gives a value to the normal derivative and the variable itself then it is a [Cauchy boundary condition](wikipedia://en/1725025).

A type 0 boundary condition has no physical boundary.[^o17]

### Differential operators {#Differential_operators}

Aside from the boundary condition, boundary value problems are also classified according to the type of differential operator involved. For an [elliptic operator](wikipedia://en/550137), one discusses [elliptic boundary value problems](wikipedia://en/10468961). For a [hyperbolic operator](https://en.wikipedia.org/wiki/Hyperbolic_operator), one discusses [hyperbolic boundary value problems](https://en.wikipedia.org/wiki/Hyperbolic_boundary_value_problems). These categories are further subdivided into [linear](wikipedia://en/379868) and various nonlinear types.

## Applications {#Applications}

### Electromagnetic potential {#Electromagnetic_potential}

In [electrostatics](https://en.wikipedia.org/wiki/Electrostatics), a common problem is to find a function which describes the [electric potential](wikipedia://en/59615) of a given region. If the region does not contain charge, the potential must be a solution to [Laplace's equation](wikipedia://en/36941) (a so-called [harmonic function](wikipedia://en/55762)). The boundary conditions in this case are the [Interface conditions for electromagnetic fields](wikipedia://en/7822233). If there is no [current density](https://en.wikipedia.org/wiki/Current_density) in the region, it is also possible to define a [magnetic scalar potential](wikipedia://en/2395496) using a similar procedure.
