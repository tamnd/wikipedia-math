# Cyclic order

*Image: Months circle svg.svg.* The months are a cyclic order.

::: {#o1 .subject cue=lead name="Cyclic order"}

In [mathematics](wikipedia://en/18831), a **cyclic order** is a way to arrange a set of objects in a [circle](wikipedia://en/6220). Unlike most structures in [order theory](wikipedia://en/361924), a cyclic order is not modeled as a [binary relation](wikipedia://en/3931), such as "$a < b$". One does not say that east is "more clockwise" than west. Instead, a cyclic order is defined as a [ternary relation](wikipedia://en/3784565) $[a, b, c]$, meaning "after $a$, one reaches $b$ before $c$". For example, \[June, October, February\], but not \[June, February, October\], cf. picture. A ternary relation is called a cyclic order if it is cyclic, asymmetric, transitive, and connected. Dropping the "connected" requirement results in a [partial cyclic order](wikipedia://en/32131629).

:::

A [set](wikipedia://en/26691) with a cyclic order is called a **cyclically ordered set** or simply a **cycle**. Some familiar cycles are discrete, having only a [finite number](wikipedia://en/11742) of [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29): there are seven [days of the week](https://en.wikipedia.org/wiki/Days_of_the_week), four [cardinal directions](https://en.wikipedia.org/wiki/Cardinal_direction), twelve notes in the [chromatic scale](https://en.wikipedia.org/wiki/Chromatic_scale), and three plays in [rock-paper-scissors](https://en.wikipedia.org/wiki/Rock-paper-scissors). In a finite cycle, each element has a "next element" and a "previous element". There are also cyclic orders with infinitely many elements, such as the oriented [unit circle](wikipedia://en/27072071) in the plane.

Cyclic orders are closely related to the more familiar [linear orders](https://en.wikipedia.org/wiki/Linear_order), which arrange objects in a [line](wikipedia://en/946975). Any linear order can be bent into a circle, and any cyclic order can be cut at a point, resulting in a line. These operations, along with the related constructions of intervals and covering maps, mean that questions about cyclic orders can often be transformed into questions about linear orders. Cycles have more symmetries than linear orders, and they often naturally occur as residues of linear structures, as in the [finite cyclic groups](https://en.wikipedia.org/wiki/Finite_cyclic_group) or the [real projective line](wikipedia://en/46379102).

## Finite cycles {#Finite_cycles}

*Image: Orientovaná kružnice.svg.* A 5-element cycle

A cyclic order on a set $X$ with $n$ elements is like an arrangement of $X$ on a clock face, for an $n$-hour clock. Each element $x$ in $X$ has a "next element" and a "previous element", and taking either successors or predecessors cycles exactly once through the elements as $x(1), x(2), ..., x(n)$.

There are a few equivalent ways to state this definition. A cyclic order on $X$ is the same as a [permutation](wikipedia://en/44027) that makes all of $X$ into a single [cycle](wikipedia://en/2221032), which is a special type of permutation - [a circular permutation](wikipedia://en/44027#Circular_permutations). Alternatively, a cycle with $n$ elements is also a $\mathbf{Z}_{n}$-[torsor](https://en.wikipedia.org/wiki/Torsor): a set with a free transitive [action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) by a [finite cyclic group](https://en.wikipedia.org/wiki/Finite_cyclic_group).[^n1] Another formulation is to make $X$ into the standard [directed cycle graph](https://en.wikipedia.org/wiki/Directed_cycle_graph) on $n$ vertices, by some matching of elements to vertices.

It can be instinctive to use cyclic orders for [symmetric functions](wikipedia://en/22510359), for example as in

$$xy + yz + zx$$

where writing the final [monomial](wikipedia://en/357416) as $xz$ would distract from the pattern.

A substantial use of cyclic orders is in the determination of the [conjugacy classes](wikipedia://en/49176) of [free groups](wikipedia://en/59735). Two elements $g$ and $h$ of the free group $F$ on a set $Y$ are conjugate if and only if, when they are written as products of elements $y$ and $y^{-1}$ with $y$ in $Y$, and then those products are put in cyclic order, the cyclic orders are equivalent under the [rewriting](wikipedia://en/415847) rules that allow one to remove or add adjacent $y$ and $y^{-1}$.

A cyclic order on a set $X$ can be determined by a linear order on $X$, but not in a unique way. Choosing a linear order is equivalent to choosing a first element, so there are exactly $n$ linear orders that induce a given cyclic order. Since there are $n!$ possible linear orders (as in [permutations](wikipedia://en/44027)), there are $(n - 1)!$ possible cyclic orders (as in [circular permutations](wikipedia://en/44027#Circular_permutations)).

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

An [infinite set](wikipedia://en/142679) can also be ordered cyclically. Important examples of infinite cycles include the [unit circle](wikipedia://en/27072071), $S^{1}$, and the [rational numbers](wikipedia://en/19727024), $\mathbf{Q}$. The basic idea is the same: we arrange elements of the set around a circle. However, in the infinite case we cannot rely upon an immediate successor relation, because points may not have successors. For example, given a point on the unit circle, there is no "next point". Nor can we rely upon a binary relation to determine which of two points comes "first". Traveling clockwise on a circle, neither east or west comes first, but each follows the other.

Instead, we use a ternary relation denoting that elements $a$, $b$, $c$ occur after each other (not necessarily immediately) as we go around the circle. For example, in clockwise order, \[east, south, west\]. By [currying](wikipedia://en/6600) the arguments of the ternary relation $[a, b, c]$, one can think of a cyclic order as a one-parameter family of binary order relations, called *cuts*, or as a two-parameter family of subsets of $K$, called *intervals*.

### The ternary relation {#The_ternary_relation}

The general definition is as follows: a cyclic order on a set $X$ is a relation $C \subset X^{3}$, written $[a, b, c]$, that satisfies the following axioms:

1. Cyclicity: If $[a, b, c]$ then $[b, c, a]$
1. Asymmetry: If $[a, b, c]$ then not $[c, b, a]$
1. Transitivity: If $[a, b, c]$ and $[a, c, d]$ then $[a, b, d]$
1. Connectedness: If $a$, $b$, and $c$ are distinct, then either $[a, b, c]$ or $[c, b, a]$

The axioms are named by analogy with the [asymmetry](wikipedia://en/1229368), [transitivity](wikipedia://en/200463), and [connectedness](wikipedia://en/57495962) axioms for a binary relation, which together define a [strict linear order](https://en.wikipedia.org/wiki/Strict_linear_order). (txt) considered other possible lists of axioms, including one list that was meant to emphasize the similarity between a cyclic order and a [betweenness relation](https://en.wikipedia.org/wiki/Betweenness_relation). A ternary relation that satisfies the first three axioms, but not necessarily the axiom of totality, is a [partial cyclic order](wikipedia://en/32131629).

### Rolling and cuts {#Rolling_and_cuts}

Given a linear order $<$ on a set $X$, the cyclic order on $X$ induced by $<$ is defined as follows:[^o9]

$[a, b, c]$ if and only if $a < b < c$ or $b < c < a$ or $c < a < b$

Two linear orders induce the same cyclic order if they can be transformed into each other by a cyclic rearrangement, as in [cutting a deck of cards](https://en.wikipedia.org/wiki/Cut_%28cards%29).[^n2] One may define a cyclic order relation as a ternary relation that is induced by a strict linear order as above.[^n3]

Cutting a single point out of a cyclic order leaves a linear order behind. More precisely, given a cyclically ordered set $(K,[\cdot,\cdot,\cdot])$, each element $a\in K$ defines a natural linear order $<_a$ on the remainder of the set, $K\setminus\{a\}$, by the following rule:[^o12]

Moreover, $<_a$ can be extended by adjoining $a$ as a least element; the resulting linear order on $K$ is called the principal cut with least element $a$. Likewise, adjoining $a$ as a greatest element results in a cut $<^a$.[^n4]

### Intervals {#Intervals}

Given two elements $a\ne b\in K$, the [open interval](https://en.wikipedia.org/wiki/Open_interval) from $a$ to $b$, written $(a,b)$, is the set of all $x\in K$ such that $[a,x,b]$. The system of open intervals completely defines the cyclic order and can be used as an alternate definition of a cyclic order relation.[^n5]

An interval $(a,b)$ has a natural linear order given by $<_a$. One can define half-closed and closed intervals $[a,b)$, $(a,b]$, and $[a,b]$ by adjoining $a$ as a [least element](https://en.wikipedia.org/wiki/Least_element) and/or $b$ as a [greatest element](https://en.wikipedia.org/wiki/Greatest_element).[^n6] As a special case, the open interval $(a,a)$ is defined as the cut $K\setminus a$.

More generally, a proper subset $S$ of $K$ is called [convex](wikipedia://en/6292) if it contains an interval between every pair of points: for $a\ne b\in S$, either $(a,b)$ or $(b,a)$ must also be in $S$.[^n7] A convex set is linearly ordered by the cut $<_x$ for any $x$ not in the set; this ordering is independent of the choice of $x$.

### Automorphisms {#Automorphisms}

As a circle has a [clockwise](https://en.wikipedia.org/wiki/Clockwise) order and a counterclockwise order, any set with a cyclic order has two **senses**. A [bijection](wikipedia://en/3942) of the set that preserves the order is called an **ordered correspondence**. If the sense is maintained as before, it is a **direct correspondence**, otherwise it is called an **opposite correspondence**.[^n8] Coxeter uses a [separation relation](wikipedia://en/68571139) to describe cyclic order, and this relation is strong enough to distinguish the two senses of cyclic order. The [automorphisms](wikipedia://en/1160) of a cyclically ordered set may be identified with C<sub>2</sub>, the two-element group, of direct and opposite correspondences.

:::

## Monotone functions {#Monotone_functions}

The "cyclic order = arranging in a circle" idea works because any [subset](wikipedia://en/27631) of a cycle is itself a cycle. In order to use this idea to impose cyclic orders on sets that are not actually subsets of the unit circle in the plane, it is necessary to consider [functions](wikipedia://en/185427) between sets.

A function between two cyclically ordered sets, $f : X \to Y$, is called a *[monotonic function](wikipedia://en/48260)* or a *[homomorphism](wikipedia://en/27716891)* if it pulls back the ordering on $Y$: whenever $[f(a), f(b), f(c)]$, one has $[a, b, c]$. Equivalently, $f$ is monotone if whenever $[a, b, c]$ and $f(a), f(b)$, and $f(c)$ are all distinct, then $[f(a), f(b), f(c)]$. A typical example of a monotone function is the following function on the cycle with 6 elements:

$$f(0) = f(1) = 4,$$

$$f(2) = f(3) = 0,$$

$$f(4) = f(5) = 1.$$

A function is called an *[embedding](wikipedia://en/52119)* if it is both monotone and [injective](wikipedia://en/45196). Equivalently, an embedding is a function that pushes forward the ordering on $X$: whenever $[a, b, c]$, one has $[f(a), f(b), f(c)]$. As an important example, if $X$ is a subset of a cyclically ordered set $Y$, and $X$ is given its natural ordering, then the [inclusion map](wikipedia://en/492516) $i : X \to Y$ is an embedding.

Generally, an injective function $f$ from an unordered set $X$ to a cycle $Y$ induces a unique cyclic order on $X$ that makes $f$ an embedding.

### Functions on finite sets {#Functions_on_finite_sets}

A cyclic order on a finite set $X$ can be determined by an injection into the unit circle, $X \to S^{1}$. There are many possible functions that induce the same cyclic order—in fact, infinitely many. In order to quantify this redundancy, it takes a more complex combinatorial object than a simple number. Examining the [configuration space](wikipedia://en/54981574) of all such maps leads to the definition of an $(n - 1)$-dimensional [polytope](wikipedia://en/23471) known as a [cyclohedron](wikipedia://en/31649951). Cyclohedra were first applied to the study of [knot invariants](wikipedia://en/166898);[^n9] they have more recently been applied to the experimental detection of [periodically expressed](https://en.wikipedia.org/wiki/Periodically_expressed_gene) [genes](https://en.wikipedia.org/wiki/Gene) in the study of [biological clocks](https://en.wikipedia.org/wiki/Circadian_rhythm).[^n10]

The category of homomorphisms of the standard finite cycles is called the [cyclic category](wikipedia://en/31787272); it may be used to construct [Alain Connes](wikipedia://en/340)' [cyclic homology](wikipedia://en/1460172).

One may define a degree of a function between cycles, analogous to the [degree of a continuous mapping](wikipedia://en/3094450). For example, the natural map from the [circle of fifths](https://en.wikipedia.org/wiki/Circle_of_fifths) to the [chromatic circle](https://en.wikipedia.org/wiki/Chromatic_circle) is a map of degree 7. One may also define a [rotation number](wikipedia://en/3928569).

### Completion {#Completion}

- A cut with both a least element and a greatest element is called a *jump*. For example, every cut of a finite cycle $Z_{n}$ is a jump. A cycle with no jumps is called *[dense](wikipedia://en/6320997)*.[^n11][^n12]
- A cut with neither a least element nor a greatest element is called a *gap*. For example, the rational numbers $\mathbf{Q}$ have a gap at every irrational number. They also have a gap at infinity, i.e. the usual ordering. A cycle with no gaps is called *[complete](wikipedia://en/549445)*.[^n13][^n12]
- A cut with exactly one endpoint is called a *principal* or *Dedekind* cut. For example, every cut of the circle $S^{1}$ is a principal cut. A cycle where every cut is principal, being both dense and complete, is called *continuous*.[^n14][^n12]

*Image: CyclicOrderingOfCuts.svg.* $[<_{1}, <_{2}, <_{3}]$ and $[x, y, z]$

The set of all cuts is cyclically ordered by the following relation: $[<_{1}, <_{2}, <_{3}]$ if and only if there exist $x, y, z$ such that:[^n15]

$$x <_{1} y <_{1} z,$$

$x <_{1}$$y <_{2} z <_{2} x$, and

$x <_{1} y <_{1}$$z <_{3} x <_{3} y$.

A certain subset of this cycle of cuts is the [Dedekind completion](https://en.wikipedia.org/wiki/Dedekind_completion) of the original cycle.

## Further constructions {#Further_constructions}

### Unrolling and covers {#Unrolling_and_covers}

Starting from a cyclically ordered set $K$, one may form a linear order by unrolling it along an infinite line. This captures the intuitive notion of keeping track of how many times one goes around the circle. Formally, one defines a linear order on the [Cartesian product](wikipedia://en/24104095) $\mathbf{Z} \times K$, where $\mathbf{Z}$ is the set of [integers](wikipedia://en/14563), by fixing an element $a$ and requiring that for all $i$:[^o34]

If $[a, x, y]$, then $a_{i} < x_{i} < y_{i} < a_{i+1}$.

For example, the months 1 , 5 , 9 , and 1 occur in that order.

This ordering of $\mathbf{Z} \times K$ is called the [universal cover](https://en.wikipedia.org/wiki/Universal_cover) of $K$. Its [order type](wikipedia://en/4499021) is independent of the choice of $a$, but the notation is not, since the integer coordinate "rolls over" at $a$. For example, although the cyclic order of [pitch classes](https://en.wikipedia.org/wiki/Pitch_class) is compatible with the A-to-G alphabetical order, C is chosen to be the first note in each octave, so in [note-octave](https://en.wikipedia.org/wiki/Note-octave) notation, B<sub>3</sub> is followed by C<sub>4</sub>.

The inverse construction starts with a linearly ordered set and coils it up into a cyclically ordered set. Given a linearly ordered set $L$ and an order-preserving [bijection](wikipedia://en/3942) $T : L \to L$ with unbounded orbits, the [orbit space](https://en.wikipedia.org/wiki/Orbit_space) $L / T$ is cyclically ordered by the requirement:[^n5]

If $a < b < c < T(a)$, then $[[a], [b], [c]]$.

In particular, one can recover $K$ by defining $T(x_{i}) = x_{i+1}$ on $\mathbf{Z} \times K$.

There are also $n$-fold coverings for finite $n$; in this case, one cyclically ordered set covers another cyclically ordered set. For example, the [24-hour clock](https://en.wikipedia.org/wiki/24-hour_clock) is a double cover of the [12-hour clock](https://en.wikipedia.org/wiki/12-hour_clock). In geometry, the [pencil](https://en.wikipedia.org/wiki/Pencil_%28mathematics%29) of [rays](https://en.wikipedia.org/wiki/Ray_%28mathematics%29) emanating from a point in the oriented plane is a double cover of the pencil of unoriented [lines](wikipedia://en/946975) passing through the same point.[^o36] These covering maps can be characterized by lifting them to the universal cover.[^n5]

### Products and retracts {#Products_and_retracts}

*Image: CyclicLinearProductLabels.svg.*

Given a cyclically ordered set $(K, [ ])$ and a linearly ordered set $(L, <)$, the (total) lexicographic product is a cyclic order on the [product set](wikipedia://en/24104095) $K \times L$, defined by $[(a, x), (b, y), (c, z)]$ if one of the following holds:[^n16]

- $$[a, b, c]$$
- $a = b \ne c$ and $x < y$
- $b = c \ne a$ and $y < z$
- $c = a \ne b$ and $z < x$
- $a = b = c$ and $[x, y, z]$

The lexicographic product $K \times L$ globally looks like $K$ and locally looks like $L$; it can be thought of as $K$ copies of $L$. This construction is sometimes used to characterize cyclically ordered groups.[^n17]

One can also glue together different linearly ordered sets to form a circularly ordered set. For example, given two linearly ordered sets $L_{1}$ and $L_{2}$, one may form a circle by joining them together at positive and negative infinity. A circular order on the disjoint union $L_{1} \cup L_{2} \cup \{-\infty, \infty$} is defined by $\infty < L_{1} < -\infty < L_{2} < \infty$, where the induced ordering on $L_{1}$ is the opposite of its original ordering. For example, the set of all [longitudes](https://en.wikipedia.org/wiki/Longitude) is circularly ordered by joining all points west and all points east, along with the [prime meridian](https://en.wikipedia.org/wiki/Prime_meridian) and the [180th meridian](https://en.wikipedia.org/wiki/180th_meridian). (Kuhlmann Marshall Osiak 2011) use this construction while characterizing the spaces of orderings and [real places](https://en.wikipedia.org/wiki/Real_place) of double [formal Laurent series](https://en.wikipedia.org/wiki/Formal_Laurent_series) over a [real closed field](wikipedia://en/1066093).[^n18]

## Topology {#Topology}

The open intervals form a [base](wikipedia://en/59220) for a natural [topology](wikipedia://en/30450), the cyclic [order topology](wikipedia://en/213650). The [open sets](wikipedia://en/39358) in this topology are exactly those sets which are open in *every* compatible linear order.[^n19] To illustrate the difference, in the set \[0, 1), the subset \[0, 1/2) is a neighborhood of 0 in the linear order but not in the cyclic order.

Interesting examples of cyclically ordered spaces include the conformal boundary of a [simply connected](https://en.wikipedia.org/wiki/Simply_connected) [Lorentz surface](wikipedia://en/31742143)[^n20] and the [leaf space](https://en.wikipedia.org/wiki/Leaf_space) of a lifted [essential lamination](https://en.wikipedia.org/wiki/Essential_lamination) of certain 3-manifolds.[^n21] [Discrete dynamical systems](https://en.wikipedia.org/wiki/Discrete_dynamical_system) on cyclically ordered spaces have also been studied.[^n22]

The interval topology forgets the original orientation of the cyclic order. This orientation can be restored by enriching the intervals with their induced linear orders; then one has a set covered with an atlas of linear orders that are compatible where they overlap. In other words, a cyclically ordered set can be thought of as a locally linearly ordered space: an object like a [manifold](wikipedia://en/2073470), but with order relations instead of coordinate charts. This viewpoint makes it easier to be precise about such concepts as covering maps. The generalization to a locally partially ordered space is studied in (Roll 1993); see also *[Directed topology](https://en.wikipedia.org/wiki/Directed_topology)*.

## Related structures {#Related_structures}

### Groups {#Groups}

A [cyclically ordered group](wikipedia://en/32131620) is a set with both a [group structure](wikipedia://en/19447) and a cyclic order, such that left and right multiplication both preserve the cyclic order. Cyclically ordered groups were first studied in depth by [Ladislav Rieger](wikipedia://en/31627584) in 1947.[^n23] They are a generalization of [cyclic groups](wikipedia://en/52327): the [infinite cyclic group](https://en.wikipedia.org/wiki/Infinite_cyclic_group) $\mathbf{Z}$ and the [finite cyclic groups](https://en.wikipedia.org/wiki/Finite_cyclic_group) $\mathbf{Z}/n$. Since a linear order induces a cyclic order, cyclically ordered groups are also a generalization of [linearly ordered groups](wikipedia://en/349014): the [rational numbers](wikipedia://en/19727024) $\mathbf{Q}$, the real numbers $\mathbf{R}$, and so on. Some of the most important cyclically ordered groups fall into neither previous category: the [circle group](wikipedia://en/508177) $\mathbf{T}$ and its subgroups, such as the [subgroup of rational points](wikipedia://en/29508075).

Every cyclically ordered group can be expressed as a quotient $L / Z$, where $L$ is a linearly ordered group and $Z$ is a cyclic cofinal subgroup of $L$. Every cyclically ordered group can also be expressed as a subgroup of a product $\mathbf{T} \times L$, where $L$ is a linearly ordered group. If a cyclically ordered group is Archimedean or compact, it can be embedded in $\mathbf{T}$ itself.[^n24]

### Modified axioms {#Modified_axioms}

A [partial cyclic order](wikipedia://en/32131629) is a ternary relation that generalizes a (total) cyclic order in the same way that a [partial order](https://en.wikipedia.org/wiki/Partial_order) generalizes a [total order](wikipedia://en/30330). It is cyclic, asymmetric, and transitive, but it need not be total. An [order variety](https://en.wikipedia.org/wiki/Order_variety) is a partial cyclic order that satisfies an additional *spreading* axiom.[^o55] Replacing the asymmetry axiom with a complementary version results in the definition of a *co-cyclic order*. Appropriately total co-cyclic orders are related to cyclic orders in the same way that $\le$ is related to $<$.

A cyclic order obeys a relatively strong 4-point transitivity axiom. One structure that weakens this axiom is a [CC system](wikipedia://en/31866635): a ternary relation that is cyclic, asymmetric, and total, but generally not transitive. Instead, a CC system must obey a 5-point transitivity axiom and a new *interiority* axiom, which constrains the 4-point configurations that violate cyclic transitivity.[^n25]

A cyclic order is required to be symmetric under cyclic permutation, $[a, b, c] \Rightarrow [b, c, a]$, and asymmetric under reversal: $[a, b, c] \Rightarrow \neg[c, b, a]$. A ternary relation that is *asymmetric* under cyclic permutation and *symmetric* under reversal, together with appropriate versions of the transitivity and totality axioms, is called a [betweenness relation](https://en.wikipedia.org/wiki/Betweenness_relation). A [quaternary relation](wikipedia://en/22517558) called [point-pair separation](wikipedia://en/68571139#Unoriented_circle) distinguishes the two intervals that a point-pair determines on a circle. The relationship between a circular order and a point-pair separation is analogous to the relationship between a linear order and a betweenness relation.[^n26]

:::

## Symmetries and model theory {#Symmetries_and_model_theory}

(Evans Macpherson Ivanov 1997) provide a model-theoretic description of the covering maps of cycles.

(txt) studies groups of automorphisms of cycles with various [transitivity](https://en.wikipedia.org/wiki/Transitive_action) properties. (Giraudet Holland 2002) characterize cycles whose full automorphism groups act [freely and transitively](https://en.wikipedia.org/wiki/Free_transitive_action). (Campero-Arena Truss 2009) characterize [countable](wikipedia://en/6026) [colored](https://en.wikipedia.org/wiki/Colored_set) cycles whose automorphism groups act transitively. (Truss 2009) studies the automorphism group of the unique (up to isomorphism) countable dense cycle.

(Kulpeshov Macpherson 2005) study [minimality](https://en.wikipedia.org/wiki/Minimality) conditions on circularly ordered [structures](wikipedia://en/4055928), i.e. models of first-order languages that include a cyclic order relation. These conditions are analogues of [o-minimality](wikipedia://en/30865852) and [weak o-minimality](wikipedia://en/7859407) for the case of linearly ordered structures. (txt) continues with some characterizations of [ω-categorical](wikipedia://en/26628083) structures.[^n27]

## Cognition {#Cognition}

[Hans Freudenthal](https://en.wikipedia.org/wiki/Hans_Freudenthal) has emphasized the role of cyclic orders in cognitive development, as a contrast to [Jean Piaget](https://en.wikipedia.org/wiki/Jean_Piaget) who addresses only linear orders. Some experiments have been performed to investigate the mental representations of cyclically ordered sets, such as the months of the year.

## Notes on usage {#Notes_on_usage}

cyclic orderThe relation may be called a *cyclic order* (Huntington 1916, 630), a *circular order* (Huntington 1916, 630), a *cyclic ordering* (Kok 1973, 6), or a *circular ordering* (Mosher 1996, 109). Some authors call such an ordering a *total cyclic order* (Isli Cohn 1998, 643), a *complete cyclic order* (Novák 1982, 462), a *linear cyclic order* (Novák 1984, 323), or an *l-cyclic order* or ℓ-*cyclic order* (Černák 2001, 32), to distinguish from the broader class of [partial cyclic orders](wikipedia://en/32131629), which they call simply *cyclic orders*. Finally, some authors may take *cyclic order* to mean an unoriented quaternary [separation relation](wikipedia://en/68571139) (Bowditch 1998, 155).

cycleA set with a cyclic order may be called a *cycle* (Novák 1982, 462) or a *circle* (Giraudet Holland 2002, 1). The above variations also appear in adjective form: *cyclically ordered set* (*cyklicky uspořádané množiny*, (Čech 1936, 23)), *circularly ordered set*, *total cyclically ordered set*, *complete cyclically ordered set*, *linearly cyclically ordered set*, *l-cyclically ordered set*, ℓ-*cyclically ordered set*. All authors agree that a cycle is totally ordered.

ternary relationThere are a few different symbols in use for a cyclic relation. (Huntington 1916, 630) uses concatenation: $ABC$. (Čech 1936, 23) and (Novák 1982, 462) use ordered triples and the set membership symbol: $(a, b, c) \in C$. (Megiddo 1976, 274) uses concatenation and set membership: $abc \in C$, understanding $abc$ as a cyclically ordered triple. The literature on groups, such as (Świerczkowski 1959a, 162) and (Černák Jakubík 1987, 157), tend to use square brackets: $[a, b, c]$. (Giraudet Holland 2002, 1) use round parentheses: $(a, b, c)$, reserving square brackets for a betweenness relation. (Campero-Arena Truss 2009, 1) use a function-style notation: $R(a, b, c)$. Rieger (1947), cited after (Pecinová 2008, 82)) uses a "less-than" symbol as a delimiter: $< x, y, z <$. Some authors use infix notation: $a < b < c$, with the understanding that this does not carry the usual meaning of $a < b$ and $b < c$ for some binary relation \< (Černy 1978, 262). (Weinstein 1996, 81) emphasizes the cyclic nature by repeating an element: $p \hookrightarrow r \hookrightarrow q \hookrightarrow p$.

embedding(Novák 1984, 332) calls an embedding an "isomorphic embedding".

rollIn this case, (Giraudet Holland 2002, 2) write that $K$ is $L$ "rolled up".

orbit spaceThe map *T* is called *archimedean* by (Bowditch 2004, 33), *coterminal* by (Campero-Arena Truss 2009, 582), and a *translation* by (McMullen 2009, 10).

universal cover(McMullen 2009, 10) calls $\mathbf{Z} \times K$ the "universal cover" of $K$. (Giraudet Holland 2002, 3) write that $K$ is $\mathbf{Z} \times K$ "coiled". (Freudenthal Bauer 1974, 10) call $\mathbf{Z} \times K$ the "∞-times covering" of $K$. Often this construction is written as the anti-lexicographic order on $K \times \mathbf{Z}$.
