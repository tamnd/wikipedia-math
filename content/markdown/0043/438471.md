# Branching factor

*Image: Red-black tree example.svg.* A [red–black tree](wikipedia://en/26397) with branching factor 2

::: {#o1 .subject cue=lead name="Branching factor"}

In [computing](https://en.wikipedia.org/wiki/Computing), [tree data structures](https://en.wikipedia.org/wiki/Tree_data_structure), and [game theory](wikipedia://en/11924), the **branching factor** is the number of [children](https://en.wikipedia.org/wiki/Child_node) at each [node](https://en.wikipedia.org/wiki/Node_%28computer_science%29), the [outdegree](https://en.wikipedia.org/wiki/Outdegree). If this value is not uniform, an *average branching factor* can be calculated.

:::

For example, in [chess](https://en.wikipedia.org/wiki/Chess), if a "node" is considered to be a legal position, the average branching factor has been said to be about 35,[^o6][^o2] and a statistical analysis of over 2.5 million games revealed an average of 31.[^o3] This means that, on average, a player has about 31 to 35 legal moves at their disposal at each turn. By comparison, the average branching factor for the game [Go](https://en.wikipedia.org/wiki/Go_%28game%29) is 250.[^o6]

Higher branching factors make algorithms that follow every branch at every node, such as exhaustive [brute force searches](https://en.wikipedia.org/wiki/Brute-force_search), computationally more expensive due to the [exponentially increasing](wikipedia://en/191933) number of nodes, leading to [combinatorial explosion](wikipedia://en/7835738).

For example, if the branching factor is 10, then there will be 10 nodes one level down from the current position, 10<sup>2</sup> (or 100) nodes two levels down, 10<sup>3</sup> (or 1,000) nodes three levels down, and so on. The higher the branching factor, the faster this "explosion" occurs. The branching factor can be cut down by a [pruning algorithm](https://en.wikipedia.org/wiki/Pruning_%28algorithm%29).

The average branching factor can be quickly calculated as the number of non-root nodes (the size of the tree, minus one; or the number of edges) divided by the number of non-leaf nodes (the number of nodes with children).
