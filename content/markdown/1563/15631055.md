# Undecidable problem

::: {#o1 .subject cue=lead name="Undecidable problem"}

In [computability theory](wikipedia://en/155414) and [computational complexity theory](wikipedia://en/7543), an **undecidable problem** is a [decision problem](wikipedia://en/8336) for which it is [proved](wikipedia://en/82285) to be impossible to construct an [algorithm](wikipedia://en/775) that always leads to a correct yes-or-no answer. The [halting problem](wikipedia://en/21391870) is an example: it can be proven that there is no algorithm that correctly determines whether an arbitrary program eventually halts when run.[^o2]

:::

## Background {#Background}

A decision problem is a question which, for every input in some infinite set of inputs, requires a "yes" or "no" answer.[^o4] Those inputs can be numbers (for example, the decision problem "is the input a [prime number](wikipedia://en/23666)?") or values of some other kind, such as [strings](wikipedia://en/27701) of a [formal language](wikipedia://en/10939).

The formal representation of a decision problem is a subset of the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers). For decision problems on natural numbers, the set consists of those numbers that the decision problem answers "yes" to. For example, the decision problem "is the input even?" is formalized as the set of even numbers. A decision problem whose input consists of strings or more complex values is formalized as the set of numbers that, via a specific [Gödel numbering](wikipedia://en/207790), correspond to inputs that satisfy the decision problem's criteria.

A decision problem *A* is called decidable or effectively solvable if the formalized set of *A* is a [recursive set](https://en.wikipedia.org/wiki/Recursive_set). Otherwise, *A* is called undecidable. A problem is called partially decidable, semi-decidable, solvable, or provable if *A* is a [recursively enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set).[^o5]

## Example: the halting problem in computability theory {#Example:_the_halting_problem_in_computability_theory}

In [computability theory](wikipedia://en/155414), the [halting problem](wikipedia://en/21391870) is a [decision problem](wikipedia://en/8336) which can be stated as follows:

Given the description of an arbitrary [program](https://en.wikipedia.org/wiki/Computer_program) and a finite input, decide whether the program finishes running or will run forever.

[Alan Turing](wikipedia://en/1208) proved in 1936 that a general [algorithm](wikipedia://en/775) running on a [Turing machine](wikipedia://en/30403) that solves the halting problem for *all* possible program-input pairs necessarily cannot exist. Hence, the halting problem is *undecidable* for Turing machines.

## Relationship with Gödel's incompleteness theorem {#Relationship_with_Gödel's_incompleteness_theorem}

The concepts raised by [Gödel's incompleteness theorems](https://en.wikipedia.org/wiki/Gödel's_incompleteness_theorem) are very similar to those raised by the halting problem, and the proofs are quite similar. In fact, a weaker form of the First Incompleteness Theorem is an easy consequence of the undecidability of the halting problem. This weaker form differs from the standard statement of the incompleteness theorem by asserting that an effective [axiomatization](https://en.wikipedia.org/wiki/Axiomatization) of the natural numbers that is both complete and [sound](wikipedia://en/26819) is impossible. The "sound" part is the weakening: it means that we require the axiomatic system in question to prove only *true* statements about natural numbers. Since soundness implies [consistency](https://en.wikipedia.org/wiki/Consistency_proof), this weaker form can be seen as a [corollary](wikipedia://en/168865) of the strong form. It is important to observe that the statement of the standard form of Gödel's First Incompleteness Theorem is completely unconcerned with the truth value of a statement, but only concerns the issue of whether it is possible to find it through a [mathematical proof](wikipedia://en/82285).

The weaker form of the theorem can be proved from the undecidability of the halting problem as follows.[^o9] Assume that we have a sound (and hence consistent) and complete effective [axiomatization](https://en.wikipedia.org/wiki/Axiomatization) of all true [first-order logic](wikipedia://en/10983) statements about [natural numbers](wikipedia://en/21474). Then we can build an algorithm that enumerates all these statements. This means that there is an algorithm *N*(*n*) that, given a natural number *n*, computes a true first-order logic statement about natural numbers, and that for all true statements, there is at least one *n* such that *N*(*n*) yields that statement. Now suppose we want to decide if the algorithm with representation *a* halts on input *i*. We know that this statement can be expressed with a first-order logic statement, say *H*(*a*, *i*). Since the axiomatization is complete it follows that either there is an *n* such that *N*(*n*) = *H*(*a*, *i*) or there is an *n* such that *N*(*n*) = ¬ *H*(*a*, *i*). So if we [iterate](https://en.wikipedia.org/wiki/Iterate) over all *n* until we either find *H*(*a*, *i*) or its negation, we will always halt, and furthermore, the answer it gives us will be true (by soundness). This means that this gives us an algorithm to decide the halting problem. Since we know that there cannot be such an algorithm, it follows that the assumption that there is a sound and complete effective axiomatization of all true first-order logic statements about natural numbers must be false.

:::

## Examples of undecidable problems {#Examples_of_undecidable_problems}

Undecidable problems can be related to different topics, such as [logic](wikipedia://en/46426065), [abstract machines](wikipedia://en/60492) or [topology](wikipedia://en/29954). Since there are [uncountably](wikipedia://en/32248) many undecidable problems,[^o11] any list, even one of [infinite length](https://en.wikipedia.org/wiki/Countably_infinite), is necessarily incomplete.

## Examples of undecidable statements {#Examples_of_undecidable_statements}

There are two distinct senses of the word "undecidable" in contemporary use. The first of these is the sense used in relation to Gödel's theorems, that of a statement being neither provable nor refutable in a specified [deductive system](https://en.wikipedia.org/wiki/Deductive_system). The second sense is used in relation to [computability theory](wikipedia://en/155414) and applies not to statements but to [decision problems](wikipedia://en/8336), which are countably infinite sets of questions each requiring a yes or no answer. Such a problem is said to be undecidable if there is no [computable function](wikipedia://en/1139338) that correctly answers every question in the problem set. The connection between these two is that if a decision problem is undecidable (in the recursion theoretical sense) then there is no consistent, effective [formal system](wikipedia://en/396102) which proves for every question *A* in the problem either "the answer to *A* is yes" or "the answer to *A* is no".

Because of the two meanings of the word undecidable, the term [independent](wikipedia://en/1141208) is sometimes used instead of undecidable for the "neither provable nor refutable" sense. The usage of "independent" is also ambiguous, however. It can mean just "not provable", leaving open whether an independent statement might be refuted.

Undecidability of a statement in a particular deductive system does not, in and of itself, address the question of whether the [truth value](wikipedia://en/161711) of the statement is well-defined, or whether it can be determined by other means. Undecidability only implies that the particular deductive system being considered does not prove the truth or falsity of the statement. Whether there exist so-called "absolutely undecidable" statements, whose truth value can never be known or is ill-specified, is a controversial point among various [philosophical schools](wikipedia://en/46439).

One of the first problems suspected to be undecidable, in the second sense of the term, was the [word problem for groups](wikipedia://en/33563), first posed by [Max Dehn](wikipedia://en/570602) in 1911, which asks if there is a finitely presented [group](wikipedia://en/19447) for which no algorithm exists to determine whether two words are equivalent. This was shown to be the case in 1955 by [Sergei Novikov](wikipedia://en/628515).[^o13]

The combined work of Gödel and [Paul Cohen](https://en.wikipedia.org/wiki/Paul_Cohen_%28mathematician%29) has given two concrete examples of undecidable statements (in the first sense of the term): The [continuum hypothesis](wikipedia://en/5705) can neither be proved nor refuted in [ZFC](https://en.wikipedia.org/wiki/ZFC) (the standard axiomatization of [set theory](wikipedia://en/27553)), and the [axiom of choice](wikipedia://en/840) can neither be proved nor refuted in [ZF](wikipedia://en/152214) (which is all the ZFC axioms *except* the axiom of choice). These results do not require the incompleteness theorem. Gödel proved in 1940 that neither of these statements could be disproved in ZF or ZFC set theory. In the 1960s, Cohen proved that neither is provable from ZF, and the continuum hypothesis cannot be proven from ZFC.

[Hilbert's Tenth Problem](wikipedia://en/101851), posed in 1900 as a challenge to the next century of mathematicians, was proved undecidable by [Yuri Matiyasevich](wikipedia://en/2627712) in 1970. Hilbert's challenge sought an algorithm which finds all solutions of a [Diophantine equation](wikipedia://en/9109). A Diophantine equation is a more general case of [Fermat's Last Theorem](wikipedia://en/19021953); we seek [integer roots](https://en.wikipedia.org/wiki/Integer_number) of a [polynomial](wikipedia://en/23000) in any number of variables with integer coefficients. Since we have only one equation but *n* variables, infinitely many solutions exist (and are easy to find) in the [complex plane](wikipedia://en/217628); however, the problem becomes impossible if solutions are constrained to integer values of the variables. Matiyasevich showed this problem to be unsolvable by mapping a Diophantine equation to a [recursively enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set) and invoking Gödel's Incompleteness Theorem.[^o14]

In 1936, [Alan Turing](wikipedia://en/1208) proved that the [halting problem](wikipedia://en/21391870)—the question of whether or not a [Turing machine](wikipedia://en/30403) halts on a given program—is undecidable, in the second sense of the term. This result was later generalized by [Rice's theorem](wikipedia://en/25852).

In 1973, [Saharon Shelah](wikipedia://en/331211) showed the [Whitehead problem](wikipedia://en/212619) in [group theory](wikipedia://en/41890) is undecidable, in the first sense of the term, in standard set theory.[^o15]

In 1977, Paris and Harrington proved that the [Paris-Harrington principle](https://en.wikipedia.org/wiki/Paris-Harrington_theorem), a version of the [Ramsey theorem](https://en.wikipedia.org/wiki/Ramsey_theorem), is undecidable in the axiomatization of arithmetic given by the [Peano axioms](wikipedia://en/25005) but can be proven to be true in the larger system of [second-order arithmetic](wikipedia://en/3542454).

[Kruskal's tree theorem](wikipedia://en/3606300), which has applications in computer science, is also undecidable from the Peano axioms but provable in set theory. In fact Kruskal's tree theorem (or its finite form) is undecidable in a much stronger system codifying the principles acceptable on basis of a philosophy of mathematics called predicativism.

[Goodstein's theorem](wikipedia://en/150062) is a statement about the [Ramsey theory](wikipedia://en/157175) of the natural numbers that Kirby and Paris showed is undecidable in Peano arithmetic.

[Gregory Chaitin](wikipedia://en/12308) produced undecidable statements in [algorithmic information theory](https://en.wikipedia.org/wiki/Algorithmic_information_theory) and proved another incompleteness theorem in that setting. Chaitin's theorem states that for any theory that can represent enough arithmetic, there is an upper bound *c* such that no specific number can be proven in that theory to have [Kolmogorov complexity](wikipedia://en/1635) greater than *c*. While Gödel's theorem is related to the [liar paradox](wikipedia://en/17967), Chaitin's result is related to [Berry's paradox](https://en.wikipedia.org/wiki/Berry's_paradox).

In 2007, researchers Kurtz and Simon, building on earlier work by [J.H. Conway](wikipedia://en/15807) in the 1970s, proved that a natural generalization of the [Collatz problem](https://en.wikipedia.org/wiki/Collatz_problem) is undecidable.[^o16]

In 2019, Ben-David and colleagues constructed an example of a learning model (named EMX), and showed a family of functions whose learnability in EMX is undecidable in standard set theory.[^o17][^o18]
