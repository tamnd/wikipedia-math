# Amenable Banach algebra

::: {#o1 .subject cue=lead name="Amenable Banach algebra"}

In mathematics, specifically in [functional analysis](wikipedia://en/11180), a [Banach algebra](wikipedia://en/4665), *A*, is **amenable** if all [bounded](https://en.wikipedia.org/wiki/Bounded_linear_map) [derivations](wikipedia://en/1816587) from *A* into [dual](wikipedia://en/44902322) [Banach *A*-bimodules](https://en.wikipedia.org/wiki/Banach_module) are [inner](wikipedia://en/17944#Derivations) (that is of the form $a\mapsto a.x-x.a$ for some $x$ in the dual module).

:::

An equivalent characterization is that *A* is amenable if and only if it has a [virtual diagonal](https://en.wikipedia.org/wiki/Virtual_diagonal).

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *A* is a [group algebra](wikipedia://en/381010) $L^1(G)$ for some [locally compact group](wikipedia://en/1651204) *G* then *A* is amenable if and only if *G* is [amenable](wikipedia://en/657430).
- If *A* is a [C\*-algebra](wikipedia://en/7184) then *A* is amenable if and only if it is [nuclear](wikipedia://en/25351068).
- If *A* is a [uniform algebra](wikipedia://en/4536974) on a [compact](wikipedia://en/6042) [Hausdorff space](wikipedia://en/13637) then *A* is amenable if and only if it is trivial (i.e. the algebra *C(X)* of all [continuous](wikipedia://en/6122) [complex](wikipedia://en/5826) [functions](wikipedia://en/185427) on *X*).
- If *A* is amenable and there is a continuous algebra homomorphism $\theta$ from *A* to another Banach algebra, then the closure of $\overline{\theta(A)}$ is amenable.

:::
