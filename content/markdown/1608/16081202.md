# String graph

::: {#o1 .subject cue=lead name="String graph"}

In [graph theory](wikipedia://en/12401), a **string graph** is an [intersection graph](wikipedia://en/7726759) of [curves in the plane](wikipedia://en/971691); each curve is called a "string". Given a [graph](wikipedia://en/325806) $G$, $G$ is a string graph [if and only if](wikipedia://en/14922) there exists a set of curves, or strings, such that the graph having a [vertex](wikipedia://en/638899) for each curve and an edge for each intersecting pair of curves is [isomorphic](wikipedia://en/247577) to $G$.

:::

## Background {#Background}

(txt) described a concept similar to string graphs as they applied to genetic structures. In that context, he also posed the specific case of intersecting intervals on a line, namely the now-classical family of [interval graphs](wikipedia://en/363423).[^n1] Later, (Sinden 1966) specified the same idea to [electrical networks](wikipedia://en/9559) and printed circuits.[^n2] The mathematical study of string graphs began with the paper (Ehrlich Even Tarjan 1976) and through a collaboration between Sinden and [Ronald Graham](wikipedia://en/240694), where the characterization of string graphs eventually came to be posed as an open question at the 5th Hungarian Colloquium on Combinatorics in 1976.[^o8] However, the recognition of string graphs was eventually proven to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete), implying that no simple characterization is likely to exist.[^n3]

## Related graph classes {#Related_graph_classes}

*Image: Planar string graph.svg.* Representation of a [planar graph](wikipedia://en/24314) as a string graph.

Every [planar graph](wikipedia://en/24314) is a string graph:[^o11] one may form a string graph representation of an arbitrary plane-embedded graph by drawing a string for each vertex that loops around the vertex and around the midpoint of each adjacent edge, as shown in the figure. For any edge $uv$ of the graph, the strings for $u$ and $v$ cross each other twice near the midpoint of $uv$, and there are no other crossings, so the pairs of strings that cross represent exactly the adjacent pairs of vertices of the original planar graph. Alternatively, by the [circle packing theorem](wikipedia://en/16648043), any planar graph may be represented as a collection of circles, any two of which cross if and only if the corresponding vertices are adjacent; these circles (with a starting and ending point chosen to turn them into open curves) provide a string graph representation of the given planar graph. (Chalopin Gonçalves Ochem 2007) proved that every planar graph has a string representation in which each pair of strings has at most one crossing point, unlike the representations described above. [Scheinerman's conjecture](wikipedia://en/3125930), now proven, is the even stronger statement that every planar graph may be represented by the intersection graph of straight line segments, a very special case of strings.

*Image: Subdivided K5.svg.* A subdivision of *K*<sub>5</sub> that is not a string graph.

If every edge of a given graph $G$ is [subdivided](https://en.wikipedia.org/wiki/Subdivision_%28graph_theory%29), the resulting graph is a string graph if and only if $G$ is planar. In particular, the subdivision of the [complete graph](wikipedia://en/85816) $K_5$ shown in the illustration is not a string graph, because $K_5$ is not planar.[^o11]

Every [circle graph](wikipedia://en/1399873), as an intersection graph of line segments (the chords of a circle), is also a string graph. Every [chordal graph](wikipedia://en/744165) may be represented as a string graph: chordal graphs are intersection graphs of subtrees of trees, and one may form a string representation of a chordal graph by forming a planar embedding of the corresponding tree and replacing each subtree by a string that traces around the subtree's edges.[^n4]

The [complement graph](wikipedia://en/1175649) of every [comparability graph](wikipedia://en/6978672) (also known as the [cocomparability graph](https://en.wikipedia.org/wiki/Cocomparability_graph)) is also a string graph.[^o14]

## Computational complexity {#Computational_complexity}

(Kratochvíl 1991b) showed string graph recognition to be [NP-hard](https://en.wikipedia.org/wiki/NP-hard), but was not able to show that it could be solved in [NP](wikipedia://en/21562).[^n5] One barrier to solving the problem in NP is that, for some string graphs, all systems of curves that realize the graph have an exponential number of crossings, so an explicit realization cannot be used as a polynomial-size witness for the graph being a string graph.[^n6] Instead, subsequent research in this area focused on compressed descriptions of realizations in terms of the sequences of crossings on each string, described using the theory of [formal languages](wikipedia://en/10939). After intermediate results by (Schaefer Štefankovič 2001) and (Pach Tóth 2002), (Schaefer Sedgwick Štefankovič 2003) completed the proof that the problem is in NP, and therefore is [NP-complete](https://en.wikipedia.org/wiki/NP-complete).[^n3]

(Ehrlich Even Tarjan 1976) showed that testing whether a string graph is $k$-colorable is NP-complete, for every $k\ge 3$, and even when restricted to graphs with a given string representation consisting of straight line segments.[^n7] 3-colorings of string graphs, when they exist, can be found in the subexponential time bound $2^{O(n^{2/3}\log n)}$, but a similarly fast time for more colors is unlikely, under standard complexity-theoretic assumptions: an algorithm for 4-coloring in time $2^{o(n)}$ would contradict the [exponential time hypothesis](wikipedia://en/26434552).[^n8]

## Other results {#Other_results}

The smallest graph that is not a string graph has 12 vertices.[^n9]

(Kratochvíl 1991a) observed that [induced minors](wikipedia://en/353042#Induced_minors) of string graphs are also string graphs. Induced minors are obtained from a given graph by contracting edges and deleting vertices; unlike the more general form of graph minor they do not allow deleting edges. For graph minors, the [Robertson–Seymour theorem](wikipedia://en/351769) states that any graph property closed under minors has finitely many [minimal forbidden minors](wikipedia://en/13547826). However, this does not hold for induced minors, and Kratochvíl found an infinite family of minimal forbidden induced minors for string graphs.[^n10]

Analogously to the [planar separator theorem](wikipedia://en/18978005), every $m$-edge string graph can be partitioned into two subsets, each a constant fraction the size of the whole graph, by the removal of $O(m^{3/4}\log^{1/2}m)$ vertices. It follows that the [biclique-free](https://en.wikipedia.org/wiki/Biclique-free_graph) string graphs, string graphs containing no $K_{t,t}$ subgraph for some constant $t$, have $O(n)$ edges and more strongly have [polynomial expansion](wikipedia://en/47843724).[^o30]
