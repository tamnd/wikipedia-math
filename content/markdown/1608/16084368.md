# Nonrecursive ordinal

::: {#o1 .subject cue=lead name="Nonrecursive ordinal"}

In mathematics, particularly [set theory](wikipedia://en/27553), **non-recursive ordinals** are [large countable ordinals](wikipedia://en/4376814) greater than all the [recursive ordinals](https://en.wikipedia.org/wiki/Recursive_ordinal), and therefore can not be expressed using [recursive ordinal notations](wikipedia://en/6108552).

:::

::: {#o3 .pointer-item cue=pointer name="Church–Kleene ordinal"}

## The Church–Kleene ordinal and variants {#The_Church–Kleene_ordinal_and_variants}

The smallest non-recursive ordinal is the **Church–Kleene ordinal**, $\omega_1^{\mathsf{CK}}$, named after [Alonzo Church](wikipedia://en/49731) and [S. C. Kleene](https://en.wikipedia.org/wiki/S._C._Kleene); its [order type](wikipedia://en/4499021) is the set of all [recursive ordinals](https://en.wikipedia.org/wiki/Recursive_ordinal). Since the successor of a recursive ordinal is recursive, the Church–Kleene ordinal is a [limit ordinal](wikipedia://en/373137). It is also the smallest ordinal that is not [hyperarithmetical](wikipedia://en/12383591), and the smallest [admissible ordinal](wikipedia://en/4635859) after $\omega$ (an ordinal $\alpha$ is called admissible if $L_\alpha \models \mathsf{KP}$.) The $\omega_1^{\mathsf{CK}}$-recursive subsets of $\omega$ are exactly the $\Delta^1_1$ subsets of $\omega$.[^o4]

The notation $\omega_1^{\mathsf{CK}}$ is in reference to $\omega_1$, the [first uncountable ordinal](wikipedia://en/20860540), which is the set of all countable ordinals, analogously to how the Church–Kleene ordinal is the set of all recursive ordinals. Some old sources use $\omega_1$ to denote the Church–Kleene ordinal.[^o5]

For a set $x\subseteq\mathbb N$, a set is $x$-computable if it is computable from a [Turing machine](wikipedia://en/30403) with an [oracle](wikipedia://en/22431) that queries $x$. The relativized Church–Kleene ordinal $\omega_1^x$ is the [supremum](wikipedia://en/39382) of the order types of $x$-computable relations. The Friedman–Jensen–Sacks theorem states that for every countable admissible ordinal $\alpha$, there exists a set $x$ such that $\alpha=\omega_1^x$.[^o6]

$\omega_\omega^{\mathsf{CK}}$, first defined by [Stephen G. Simpson](https://en.wikipedia.org/wiki/Stephen_G._Simpson) is an extension of the Church–Kleene ordinal. This is the smallest limit of admissible ordinals, yet this ordinal is not admissible. Alternatively, this is the smallest $\alpha$ such that $L_\alpha \cap \mathsf{P}(\omega)$ is a model of [$\Pi^1_1$-comprehension](wikipedia://en/3542454).[^o7]

:::

## Recursively \[X\] ordinals {#Recursively_[X]_ordinals}

The $\alpha$th admissible ordinal is sometimes denoted by $\tau_\alpha$.[^o9][^o10]

Recursively \[X\] ordinals, where \[X\] typically represents a [large cardinal](wikipedia://en/383644) property, are kinds of nonrecursive ordinals.[^o11] Rathjen has called these ordinals the "recursively large counterparts" of X,[^o12] however the use of "recursively large" here is not to be confused with the notion of an ordinal being recursive.

An ordinal $\alpha$ is called *recursively inaccessible* if it is admissible and a limit of admissibles. Alternatively, $\alpha$ is recursively inaccessible iff $\alpha$ is the $\alpha$th admissible ordinal,[^o10] or iff $L_\alpha \models \mathsf{KPi}$, an extension of [Kripke–Platek set theory](wikipedia://en/1124695) stating that each set is contained in a model of Kripke–Platek set theory. Under the condition that $L_\alpha\vDash\textrm{V=HC}$ ("every set is [hereditarily countable](wikipedia://en/13552465)"), $\alpha$ is recursively inaccessible iff $L_\alpha \cap \mathsf{P}(\omega)$ is a model of [$\Delta^1_2$-comprehension](wikipedia://en/3542454).[^o13]

An ordinal $\alpha$ is called *recursively hyperinaccessible* if it is recursively inaccessible and a limit of recursively inaccessibles, or where $\alpha$ is the $\alpha$th recursively inaccessible. Like "hyper-inaccessible cardinal", different authors conflict on this terminology.

An ordinal $\alpha$ is called *recursively Mahlo* if it is admissible and for any $\alpha$-recursive function $f : \alpha \rightarrow \alpha$ there is an admissible $\beta < \alpha$ such that $\left\{f(\gamma)\mid\gamma\in\beta\right\}\subseteq\beta$ (that is, $\beta$ is closed under $f$).[^o5] Mirroring the [Mahloness hierarchy](wikipedia://en/248081), $\alpha$ is *recursively $\gamma$-Mahlo* for an ordinal $\gamma$ if it is admissible and for any $\alpha$-recursive function $f : \alpha \rightarrow \alpha$ there is an admissible ordinal $\beta < \alpha$ such that $\beta$ is closed under $f$, and $\beta$ is recursively $\delta$-Mahlo for all $\delta<\gamma$.[^o11]

An ordinal $\alpha$ is called *recursively weakly compact* if it is $\Pi_3$-reflecting, or equivalently,[^o5] 2-admissible. These ordinals have strong recursive Mahloness properties, if α is $\Pi_3$-reflecting then $\alpha$ is recursively $\alpha$-Mahlo.[^o11]

## Weakenings of stable ordinals {#Weakenings_of_stable_ordinals}

An ordinal $\alpha$ is stable if $L_\alpha$ is a $\Sigma_1$-[elementary-substructure](https://en.wikipedia.org/wiki/Elementary_substructure) of $L$, denoted $L_\alpha\preceq_1 L$.[^o15] These are some of the largest named nonrecursive ordinals appearing in a model-theoretic context, for instance greater than $\min\{\alpha: L_\alpha \models T\}$ for any computably axiomatizable theory $T$.[^o16]<sup>Proposition 0.7</sup>. There are various weakenings of stable ordinals:[^o7]

- A countable ordinal $\alpha$ is called $(+1)$-stable [iff](wikipedia://en/14922) $L_\alpha \preceq_1 L_{\alpha+1}$.
  - The smallest $(+1)$-stable ordinal is much larger than the smallest recursively weakly compact ordinal: it has been shown that the smallest $(+1)$-stable ordinal is $\Pi_n$-reflecting for all finite $n$.[^o5]
  - In general, a countable ordinal $\alpha$ is called $(+\beta)$-stable iff $L_\alpha \preceq_1 L_{\alpha+\beta}$.
- A countable ordinal $\alpha$ is called $(^+)$-stable iff $L_\alpha \preceq_1 L_{\alpha^+}$, where $\alpha^+$ is the smallest admissible ordinal $> \alpha$. The smallest $(^+)$-stable ordinal is again much larger than the smallest $(+1)$-stable or the smallest $(+\beta)$-stable for any constant $\beta$.
- A countable ordinal $\alpha$ is called $(^{++})$-stable iff $L_\alpha \preceq_1 L_{\alpha^{++}}$, where $\alpha^+$ and $\alpha^{++}$ are the two smallest admissible ordinals $> \alpha$. The smallest $(^{++})$-stable ordinal is larger than the smallest $\Sigma^1_1$-reflecting.
- A countable ordinal $\alpha$ is called inaccessibly-stable iff $L_\alpha \preceq_1 L_{\beta}$, where $\beta$ is the smallest recursively inaccessible ordinal $> \alpha$. The smallest inaccessibly-stable ordinal is larger than the smallest $(^{++})$-stable.
- A countable ordinal $\alpha$ is called Mahlo-stable iff $L_\alpha \preceq_1 L_{\beta}$, where $\beta$ is the smallest recursively Mahlo ordinal $> \alpha$. The smallest Mahlo-stable ordinal is larger than the smallest inaccessibly-stable.
- A countable ordinal $\alpha$ is called doubly $(+1)$-stable iff $L_\alpha \preceq_1 L_{\beta} \preceq_1 L_{\beta+1}$. The smallest doubly $(+1)$-stable ordinal is larger than the smallest Mahlo-stable.

## Larger nonrecursive ordinals {#Larger_nonrecursive_ordinals}

Even larger nonrecursive ordinals include:[^o7]

- The least ordinal $\alpha$ such that $L_\alpha \preceq_1 L_\beta$ where $\beta$ is the smallest nonprojectible ordinal.
- An ordinal $\alpha$ is nonprojectible if $\alpha$ is a limit of *$\alpha$*-stable ordinals, or; if the set $X = \left\{ \beta < \alpha \mid L_\beta \preceq_1 L_\alpha\right\}$ is unbounded in *$\alpha$*.
- The ordinal of ramified analysis, often written as $\beta_0$. This is the smallest $\beta$ such that $L_\beta \cap \mathsf{P}(\omega)$ is a model of [second-order comprehension](wikipedia://en/3542454), or $L_\beta \models \mathsf{ZFC^{-}}$, which is $\mathsf{ZFC}$ without the [axiom of power set](wikipedia://en/52552).
- The least ordinal $\alpha$ such that $L_\alpha \models \mathsf{KP} + \text{'}\omega_1\text{ exists'}$. This ordinal has been characterized by Toshiyasu Arai.[^o18]
- The least ordinal $\alpha$ such that $L_\alpha \models \mathsf{ZFC^{-}} + \text{'}\omega_1\text{ exists'}$.
- The least stable ordinal.
