# Feferman–Schütte ordinal

::: {#o1 .subject cue=lead name="Feferman–Schütte ordinal"}

In mathematics, the **Feferman–Schütte ordinal** (**Γ<sub>0</sub>**) is a [large countable ordinal](wikipedia://en/4376814). It is the [proof-theoretic ordinal](https://en.wikipedia.org/wiki/Proof-theoretic_ordinal) of several mathematical theories, such as [arithmetical transfinite recursion](https://en.wikipedia.org/wiki/Arithmetical_transfinite_recursion). It is named after [Solomon Feferman](wikipedia://en/355401) and [Kurt Schütte](wikipedia://en/16184365), the former of whom suggested the name Γ<sub>0</sub>.[^o2]

:::

There is no standard notation for ordinals beyond the Feferman–Schütte ordinal. There are several ways of representing the Feferman–Schütte ordinal, some of which use [ordinal collapsing functions](wikipedia://en/16968563): $\psi(\Omega^\Omega)$, $\theta(\Omega)$, or $\varphi(1,0,0)$.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Feferman–Schütte ordinal can be defined as the smallest ordinal that cannot be obtained by starting with 0 and using the operations of [ordinal addition](https://en.wikipedia.org/wiki/Ordinal_addition) and the binary [Veblen functions](wikipedia://en/16124925) *φ*<sub>*α*</sub>(*β*) = *φ*(*α*,*β*). That is, it is the smallest *α* such that *φ*<sub>*α*</sub>(0) = *α*.

$$\Gamma_0 = \sup \{ 0, \, 1=\varphi (0,0), \, \varepsilon_0=\varphi (\varphi (0,0), 0), \, \varphi (\varphi (\varphi (0,0), 0), 0), \, \varphi (\varphi (\varphi (\varphi (0,0), 0), 0), 0), \ldots \}.$$

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

This ordinal is sometimes said to be the first impredicative ordinal,[^o7][^o8] though this is controversial, partly because there is no generally accepted precise definition of "[predicative](https://en.wikipedia.org/wiki/Predicativity)". Sometimes an ordinal is said to be predicative if it is less than Γ<sub>0</sub>.

Any recursive path ordering whose function symbols are well-founded with order type less than that of Γ<sub>0</sub> itself has order type less than Γ<sub>0</sub>.[^o9]

:::
