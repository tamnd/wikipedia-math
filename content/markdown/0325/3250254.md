# Firefly (key exchange protocol)

::: {#o1 .subject cue=lead name="Firefly"}

**Firefly** is a U.S. [National Security Agency](wikipedia://en/21939) [public-key](wikipedia://en/24222) [key exchange](wikipedia://en/578092) protocol, used in [EKMS](https://en.wikipedia.org/wiki/EKMS), the [STU-III](https://en.wikipedia.org/wiki/STU-III) secure telephone, and several other U.S. cryptographic systems.

:::
