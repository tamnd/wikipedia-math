# Pseudorandom generator theorem

::: {#o1 .subject cue=lead name="Pseudorandom generator theorem"}

In [computational complexity theory](wikipedia://en/7543) and [cryptography](wikipedia://en/18934432), the existence of [pseudorandom generators](wikipedia://en/1812809) is related to the existence of [one-way functions](wikipedia://en/363890) through a number of theorems, collectively referred to as the **pseudorandom generator theorem**.

:::

## Introduction {#Introduction}

### Pseudorandomness {#Pseudorandomness}

A distribution is considered [pseudorandom](https://en.wikipedia.org/wiki/Pseudorandom) if no efficient computation can distinguish it from the true [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29) by a non-[negligible](wikipedia://en/8426019) [advantage](wikipedia://en/4636092). Formally, a family of distributions *D<sub>n</sub>* is *pseudorandom* if for any polynomial size circuit *C*, and any *ε* inversely polynomial in *n*

\|Prob<sub>*x*∈*U*</sub>\[*C*(*x*)=1\] − Prob<sub>*x*∈*D*</sub>\[*C*(*x*)=1\] | ≤ *ε*.

### Pseudorandom generators {#Pseudorandom_generators}

A function *G<sub>l</sub>*: {0,1}<sup>*l*</sup> → {0,1}<sup>*m*</sup>, where *l* \< *m* is a pseudorandom generator if:

- *G<sub>l</sub>* can be computed in time polynomial in *l*
- *G<sub>l</sub>*(*x*) is pseudorandom, when *x* is uniformly random.

### One additional pseudorandom bit implies polynomially more pseudorandom bits {#One_additional_pseudorandom_bit_implies_polynomially_more_pseudorandom_bits}

It can be shown that if there is a pseudorandom generator *G<sub>l</sub>*: {0,1}<sup>*l*</sup> → {0,1}<sup>*l*+1</sup>, *i.e.* a generator that adds *only one* pseudorandom bit, then for any *m* = *poly*(*l*), there is a pseudorandom generator *G'<sub>l</sub>*: {0,1}<sup>*l*</sup> → {0,1}<sup>*m*</sup>.

The idea of the proof is as follows: first *s* bits from uniform distribution *U<sub>l</sub>* are picked and used as the seed to the first instance of *G<sub>l</sub>*, which is known to be a pseudorandom generator. Next, the output of the first instance of *G<sub>l</sub>* is divided into two parts: first *l* bits are fed into the second instance of *G<sub>l</sub>* as a seed, while the last bit becomes the first bit of the output. Repeating this process for *m* times yields an output of *m* pseudorandom bits.

It can be shown that such *G'<sub>l</sub>*, that consists of *m* instances of *G<sub>l</sub>*, is indeed a pseudorandom generator by using a [hybrid approach](https://en.wikipedia.org/wiki/Hybrid_approach) and [proof by contradiction](https://en.wikipedia.org/wiki/Proof_by_contradiction) as follows:

Consider *m+1* intermediate distributions *H<sub>i</sub>: 0 ≤ i ≤ m*, where first *i* bits are chosen from the uniform distribution, and last *m − i* bits are chosen from the output of *G'<sub>l</sub>*. Thus, *H<sub>0</sub>* is the full output of *G'<sub>l</sub>* and *H<sub>m</sub>* is a true uniform distribution *U<sub>m</sub>*. Therefore, distributions *H<sub>i</sub>* and *H<sub>i+1</sub>* will be different in only one bit (bit number *i*+1).

Now, assume that *G'<sub>l</sub>* is not a pseudorandom distribution; that is, there exists some circuit *C* that can distinguish between *G'<sub>l</sub>* and *U<sub>m</sub>* with an advantage *ε* = 1/*poly*(*l*). In other words, this circuit can distinguish between *H<sub>0</sub>* and *H<sub>m</sub>*. Therefore, there exists such *i* that the circuit *C* can distinguish between *H<sub>i</sub>* and *H<sub>i+1</sub>* by at least *ε / m*. Note, that since *m* are polynomial in *l*, then *ε / m* is also polynomial in *l* and is still a non-negligible advantage.

Now, assume we are given *l+1* bits that are either output of *G<sub>l</sub>* or a drawn from uniform distribution. Let's reuse the approach of building large pseudorandom generators out of instances of *G<sub>l</sub>* and construct a string of pseudorandom bits of length *m−i−1* in the same way the *G'<sub>l</sub>* was constructed above using the first *l* given bits as the seed. Then, let's create a string consisting of *i* bits drawn from uniform, concatenated with the last one of the given bits, followed by the created *m−i−1* bits. The resulting output is either *H<sub>i</sub>* or *H<sub>i+1</sub>*, since the *i+1* bit is either drawn from uniform or from *G<sub>l</sub>*. Since by assumption we can distinguish between *H<sub>i</sub>* and *H<sub>i+1</sub>* with *non-negligible* advantage, then we can distinguish between *U* and *G<sub>l</sub>*, which implies that *G<sub>l</sub>* is not a pseudorandom generator, which is a contradiction to the hypothesis. Q.E.D.

Now, let's illustrate that if exists, the circuit for distinguishing between *G<sub>l</sub>* and *U<sub>l+1</sub>* does not have to toss random coins. As we showed above, if exists a circuit *C* for distinguishing between *G'<sub>l</sub>* and *U<sub>m</sub>*, where *m* = *poly*(*l*), then exists a circuit *C'* for distinguishing between *G<sub>l</sub>* and *U<sub>l+1</sub>* that uses *i* random bits. For this circuit *C'*: | Prob<sub>*u, s*</sub> \[*C'*(*u<sub>1</sub>,...,u<sub>i</sub>,G<sub>l</sub>*(*s*)) = 1 \] − Prob<sub>*u, y*</sub> \[*C'*(*u<sub>1</sub>,>,...,u<sub>i</sub>,y*) = 1\] | ≥ *ε / m*,

where *u* is a string of *i* uniformly random bits, *s* is a string of *l* uniformly random bits, and *y* is a string of *l*+1 uniformly random bits.

Then,

Prob<sub>*u*</sub>\[ | Prob<sub>*s*</sub> \[*C'*(*u<sub>1</sub>,...,u<sub>i</sub>,G<sub>l</sub>*(*s*)) = 1\] - Prob<sub>*y*</sub> \[*C'*(*u<sub>1</sub>,...,u<sub>i</sub>,y*) = 1\] | \] ≥ *ε / m*;

Which means, there exists some fixed string *u* of *i* bits that can be used as an "advice" to circuit *C'* for distinguishing between *G<sub>l</sub>* and *U<sub>l+1</sub>*.

## Existence of pseudorandom generators {#Existence_of_pseudorandom_generators}

The existence of pseudorandom generators is related to the existence of [one-way functions](wikipedia://en/363890) and [hard-core predicates](wikipedia://en/1182871). Formally, pseudorandom generators exist [if and only if](wikipedia://en/14922) one-way functions exist, or

PRG ↔ OWF

::: {#o8 .definition cue=heading name="Definitions"}

### Definitions {#Definitions}

#### One-way functions {#One-way_functions}

Intuitively [one-way functions](wikipedia://en/363890) are functions that are easy to compute and hard to invert. In other words, the complexity (or circuit size) of the function is much smaller than that of its inverse. Formally: A function ƒ: {0,1}<sup>*n*</sup> → {0,1}<sup>*n*</sup> is (*S*,*ε*) *one-way* if for any circuit *C* of size ≤ *S*,

Prob\[ƒ(*C*(ƒ(*x*))) = ƒ(*x*)\] ≤ *ε*.

Moreover, ƒ is a *one-way function* if

- ƒ can be computed in polynomial time
- ƒ is (*poly*(*n*), 1/*poly*(*n*)) one-way

#### Hard-core predicate {#Hard-core_predicate}

Function *B*: {0,1}<sup>*n*</sup> → {0,1} is a [hard-core predicate](wikipedia://en/1182871) for function ƒ if

- *B* can be computed in polynomial time
- for any polynomial size circuit *C* and any non-negligible *ε* = 1/*poly*(*n*), Prob*<sub>x~U</sub>*\[*C*(ƒ(*x*)) = *B*(*x*)\] ≤ 1/2+*ε*

In other words, it is hard to predict *B*(*x*) from function ƒ(*x*).

:::

::: {#o12 .proof cue=heading name="Proof"}

### Proof {#Proof}

*Here an outline of the proof is given. Please see references for detailed proofs.*

#### PRG → OWF {#PRG_→_OWF}

Consider a pseudorandom generator *G<sub>l</sub>*: {0,1}<sup>*l*</sup> → {0,1}<sup>*2l*</sup>. Let's create the following one-way function ƒ: {0,1}<sup>*n*</sup> → {0,1}<sup>*n*</sup> that uses the first half of the output of *G<sub>l</sub>* as its output. Formally,

ƒ(*x*,*y*) → *G<sub>l</sub>*(*x*)

A key observation that justifies such selection, is that the size of the pre-image universe is 2<sup>*n*</sup> and is a negligible fraction of the [image](wikipedia://en/579311) of the function of size 2<sup>*2n*</sup>.

To prove that ƒ is indeed a one-way function let's construct an argument by contradiction. Assume there exists a circuit *C* that inverts ƒ with advantage *ε*:

Prob\[ƒ(*C*(ƒ(*x*,*y*))) = ƒ(*x*,*y*)\] > *ε*

Then we can create the following algorithm that will distinguish *G<sub>l</sub>* from uniform, which contradicts the hypothesis. The algorithm would take an input of *2n* bits *z* and compute (*x*,*y*) = *C*(*z*). If *G<sub>l</sub>*(*x*) = *z* the algorithm would accept, otherwise it rejects.

Now, if *z* is drawn from uniform distribution, the probability that the above algorithm accepts is ≤ 1/2<sup>*l*</sup>, since the size of the pre-image is 1/2<sup>*l*</sup> of the size of the image. However, if *z* was drawn from the output of *G<sub>l</sub>* then the probability of acceptance is > *ε* by assumption of the existence of circuit *C*. Therefore, the advantage that circuit *C* has in distinguishing between the uniform *U* and output of *G<sub>l</sub>* is > *ε* − 1/2<sup>*l*</sup>, which is non-negligible and thus contradicts our assumption of *G<sub>l</sub>* being a pseudorandom generator. Q.E.D.

#### OWF → PRG {#OWF_→_PRG}

For this case we prove a *weaker* version of the theorem:

One-way [permutation](wikipedia://en/44027) → pseudorandom generator

A one-way permutation is a one-way function that is also a permutation of the input bits. A pseudorandom generator can be constructed from one-way permutation ƒ as follows:

*G<sub>l</sub>*: {0,1}<sup>*l*</sup>→{0,1}<sup>*l*+1</sup> = ƒ(*x*).*B*(*x*), where *B* is hard-core predicate of ƒ and "." is a concatenation operator. Note, that by the theorem proven above, it is only needed to show the existence of a generator that adds just one pseudorandom bit.

##### Hard-core predicate → PRG {#Hard-core_predicate_→_PRG}

First, let's show that if *B* is a hard-core predicate for ƒ then *G<sub>l</sub>* is indeed pseudorandom. Again, we'll use an argument by contradiction.

Assume that *G<sub>l</sub>* is not a pseudorandom generator; that is, there exists circuit *C* of polynomial size that distinguishes *G<sub>l</sub>*(*x*) =ƒ(*x*).*B*(*x*) from *U<sub>l+1</sub>* with advantage ≥*ε*, where *ε* is non-negligible. Note, that since ƒ(*x*) is a permutation, then if *x* is drawn from uniform distribution, then so if ƒ(*x*). Therefore, *U<sub>l+1</sub>* is equivalent to ƒ(*x*).*b*, where *b* is a bit drawn independently from a uniform distribution. Formally,

Prob<sub>*x~U*</sub>\[*C*(*G*(*x*))=1\] − Prob<sub>*x~U,b~U*</sub>\[*C*(*x.b*)=1\] ≥ *ε*

Let's construct the following algorithm *C**:***

\1. Given z=f(x) guess bit b 2. Run C on z.b 3. IF C(z.b)=1 4. output b 5. ELSE 6. output 1-b

Given the output of ƒ the algorithm first guesses bit *b* by tossing a random coin, *i.e.* Prob\[*b*=0\] = Prob\[*b*=1\] = 0.5. Then, algorithm (circuit) *C* is run on *f(x).b* and if the result is 1 then *b* is outputted, otherwise the inverse of *b* is returned.

Then probability of *C**guessing*****B*(*x*) correctly is:***

Prob<sub>*x~U*</sub>\[*C**(*****z*)=*B*(*x*)\] =***

Prob\[*b*=*B*(*x*) ∧ *C*(*z.b*)=1\] + Prob\[*b*≠*B*(*x*) ∧ *C*(*z.b*)=0\] =

Prob\[*b*=*B*(*x*)\]⋅Prob\[*C*(*z.b*)=1 | *b*=*B*(*x*)\] + Prob\[*b*≠*B*(*x*)\]⋅Prob\[*C*(*z.b*)=0 | *b*≠*B*(*x*)\] =

1/2⋅Prob\[*C*(*z.b*)=1 | *b*=*B*(*x*)\] + 1/2⋅Prob\[*C*(*z.b*)=0 | *b*≠*B*(*x*)\] =

(1−1/2)⋅Prob\[*C*(*z.b*)=1 | *b*=*B*(*x*)\] + 1/2⋅(1−Prob\[*C*(*z.b*)=1 | *b*≠*B*(*x*)\]) =

1/2+Prob<sub>*z.b~G(x)*</sub>\[*C*(*z.b*)=1\] − 1/2⋅(Prob\[*C*(*z.b*)=1 | *b*=*B*(*x*)\]+Prob\[*C*(*z.b*)=1 | *b*≠*B*(*x*)\]) =

1/2+Prob<sub>*z.b~G(x)*</sub>\[*C*(*z.b*)=1\] − Prob<sub>*z.b~U*</sub>\[*C*(*z.b*)=1\] ≥ 1/2+*ε*

This implies that circuit *C**can predict*****B*(*x*) with probability more than 1/2 +*ε*, which means that*B*cannot be a hard-core predicate for ƒ and the hypothesis is contradicted. Q.E.D.***

##### OWP → hard-core predicate {#OWP_→_hard-core_predicate}

The outline of the proof is as follows:

If ƒ{0,1}<sup>*n*</sup>→{0,1}<sup>*n*</sup> is a one-way permutation, then so is ƒ'{0,1}<sup>*2n*</sup>→{0,1}<sup>*2n*</sup>, where ƒ'(*x*,*y*)=ƒ(*x*).*y* by definition. Then *B*(*x*,*y*)=*x*⋅*y* is a hard-core predicate for ƒ', where *⋅* is a vector [dot product](wikipedia://en/157093). To prove that it is indeed hard-core let's assume otherwise, and show a contradiction with the hypothesis of ƒ being one-way. If *B* is not a hard-core predicate, then there exists a circuit *C* that predicts it, so

Prob<sub>*x,y*</sub>\[*C*(ƒ(*x*),*y*)=*x*⋅*y*\] ≥ 1/2+*ε*. That fact can be used to recover *x* by cleverly constructing permutations *y* that *isolate* bits in *x*. In fact, for a constant fraction of *x*, there exists a [polynomial time](wikipedia://en/405944) algorithm that lists *O*(1/*ε*<sup>2</sup>) candidates that include all valid *x*. Thus, an algorithm can invert ƒ(*x*) in polynomial time for a non-negligible fraction of *x*, which contradicts the hypothesis.

:::
