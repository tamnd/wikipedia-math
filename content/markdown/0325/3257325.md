# Double descent

::: {#o1 .subject cue=lead name="Double descent"}

*Image: Double descent in a two-layer neural network (Figure 3a from Rocks et al. 2022).png.* An example of the double descent phenomenon in a two-layer [neural network](wikipedia://en/21523): as the ratio of parameters to data points increases, the test error first falls, then rises, then falls again.[^o2] The vertical line marks the "interpolation threshold" boundary between the underparametrized region (more data points than parameters) and the overparameterized region (more parameters than data points).

**Double descent** in [statistics](wikipedia://en/26685) and [machine learning](wikipedia://en/233488) is the phenomenon where a model's error rate on the [test set](https://en.wikipedia.org/wiki/Test_set) initially decreases with the number of parameters, then peaks, then decreases again.[^o3] This phenomenon has been considered surprising, as it contradicts assumptions about [overfitting](wikipedia://en/173332) in classical machine learning.[^o4]

:::

The increase usually occurs near the interpolation threshold, where the number of parameters is the same as the number of training data points (the model is *just* large enough to fit the training data). Or, more precisely, it is the maximum number of samples on which the model/training procedure achieves approximately on average 0 training error.[^o5]

## History {#History}

Early observations of what would later be called double descent in specific models date back to 1989.[^o7][^o8]

The term "double descent" was coined by Belkin et al.[^o9] in 2019,[^o4] when the phenomenon gained popularity as a broader concept exhibited by many models.[^o10][^o11] The latter development was prompted by a perceived contradiction between the conventional wisdom that too many parameters in the model result in a significant overfitting error (an extrapolation of the [bias–variance tradeoff](wikipedia://en/40678189)),[^o12] and the empirical observations in the 2010s that some modern machine learning techniques tend to perform better with larger models.[^o9][^o13]

## Theoretical models {#Theoretical_models}

Double descent occurs in [linear regression](wikipedia://en/48758386) with [isotropic](wikipedia://en/14865) [Gaussian covariates](wikipedia://en/302944#Covariance_functions) and isotropic Gaussian noise.[^o15]

A model of double descent at the [thermodynamic limit](wikipedia://en/2262550) has been analyzed using the [replica trick](wikipedia://en/3885155), and the result has been confirmed numerically.[^o16]

A number of works[^o17][^o18] have suggested that double descent can be explained using the concept of [effective dimension](wikipedia://en/10978612): While a network may have a large number of parameters, in practice only a subset of those parameters are relevant for generalization performance, as measured by the local [Hessian](wikipedia://en/412108) curvature. This explanation is formalized through [PAC](https://en.wikipedia.org/wiki/Probably_approximately_correct_learning)-Bayes compression-based generalization bounds,[^o19] which show that less complex models are expected to generalize better under a [Solomonoff prior](wikipedia://en/402688).
