# Model synthesis

::: {#o1 .subject cue=lead name="Model synthesis"}

**Model synthesis** (also **wave function collapse** or **'wfc'**) is a family of [constraint-solving](https://en.wikipedia.org/wiki/Constraint_solving) [algorithms](wikipedia://en/775) commonly used in [procedural generation](https://en.wikipedia.org/wiki/Procedural_generation), especially in the [video game industry](https://en.wikipedia.org/wiki/Video_game_industry).

*Image: Wave function collapse texture example.png.* An example texture created using WFC.

*Image: Wave function collapse texture example (source).png.* The source bitmap used to generate the above image.

:::

Some video games known to have utilized variants of the algorithm include *[Bad North](https://en.wikipedia.org/wiki/Bad_North)*, *[Townscaper](https://en.wikipedia.org/wiki/Townscaper)*, and *[Caves of Qud](https://en.wikipedia.org/wiki/Caves_of_Qud)*.

The first example of this type of algorithm was described by Paul Merrell, who termed it 'model synthesis' first in his 2007 i3D paper [^o2] and also presented at the 2008 [SIGGRAPH conference](https://en.wikipedia.org/wiki/SIGGRAPH_conference) and his 2009 PhD thesis.[^o3] The name '[wave function collapse](wikipedia://en/71138)' later became the popular name for a variant of that algorithm, after an implementation by Maxim Gumin was published in 2016 on a [GitHub](https://en.wikipedia.org/wiki/GitHub) [repository](https://en.wikipedia.org/wiki/Repository_%28version_control%29) with that name.[^o4] Gumin's implementation significantly popularised this style of algorithm, with it becoming widely adopted and adapted by technical artists and game developers over the following years.[^o4]

There were a number of inspirations to Gumin's implementation, including Merrell's PhD dissertation, and [convolutional neural network](https://en.wikipedia.org/wiki/Convolutional_neural_network) style transfer.[^o5][^o6] The popular name for the algorithm, 'wave function collapse', is from an analogy drawn between the algorithm's method and the concept of [superposition](wikipedia://en/1201321) and observation in [quantum mechanics](wikipedia://en/25202).[^o7][^o8] Some innovations present in Gumin's implementation included the usage of overlapping patterns, allowing a single image to be used as an input to the algorithm.[^o9]

Some have speculated that the reason Gumin's implementation proved more popular than Merrell's, may have been due to the 'model synthesis' implementation's lower accessibility, its 3D focus, or perhaps the general public's computing constraints at the time.[^o10]

One of the differences between Merrell & Gumin's implementation and 'wave function collapse' lies in the decision of which cell to 'collapse' next. Merrell's implementation uses a scanline approach, whereas Gumin's always selects as next cell the one with the lowest entropy.[^o11]

## Description {#Description}

The WFC or 'model synthesis' algorithm has some variants.[^o7] Gumin and Merrell's implementations are described below, and other variants are noted:

### Gumin's implementation {#Gumin's_implementation}

1. The input bitmap is read, and the patterns present within the bitmap are counted.
1. An array is created with the dimensions of the output desired.
1. Each cell of the array is initialized in an 'unobserved' state
1. The following steps are repeated:
   1. The cell with the lowest number of possible output states is located
   1. 'Collapse' this cell into one of its possible states according to the rules
   1. Check that all cells are still valid and follow the rules
1. Once all cells are 'collapsed' into a definite state, return the output. If the output is illegal, discard it, and repeat the process until legal.

### Merrell's implementation {#Merrell's_implementation}

Merrell's earlier implementation is substantially the same as Gumin's with some minor differences.

(1) In Merrell's version, there is no requirement to select the cell with the lowest number of possible output states for collapse. Instead, a scanline approach is adopted. According to Merrell, this results in a lower [failure rate](wikipedia://en/1336960) of the model without any negative effect on quality.[^o11] Some commentators have noted however that the scanline approach to 'collapse' tends to result in directional artifacts.[^o15]

(2) Merrell's approach performs the algorithm in chunks, rather than all-at-once. This approach greatly reduces the failure rate for many large complex models; especially in a 3D space.[^o11]

## Developments {#Developments}

In April 2023 Shaad Alaka and Rafael Bidarra of [Delft University](https://en.wikipedia.org/wiki/Delft_University) proposed 'Hierarchical Semantic wave function collapse'. Essentially, the algorithm is modified to work beyond simple, unstructured sets of tiles. Prior to their work, all WFC algorithm variants operated on a flat set of tile choices per cell.[^o17]

Their generalised approach organizes tile-sets into a hierarchy, consisting of abstract nodes called 'meta-tiles', and terminating nodes called 'leaf tiles'.[^o18] For example, on the first pass, WFC might make a certain tile a meta-tile of 'castle' type; which on a second pass will be collapsed into other tiles based on a rule, e.g. a 'wall' or 'grass' tile.
