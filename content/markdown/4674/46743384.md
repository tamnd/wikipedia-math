# Peerio

::: {#o1 .subject cue=lead name="Peerio"}

**Peerio** was a [cross-platform](https://en.wikipedia.org/wiki/Cross-platform) [end-to-end encrypted](wikipedia://en/1065362) application that provided secure messaging, file sharing, and cloud file storage. Peerio was available as an application for [iOS](https://en.wikipedia.org/wiki/IOS), [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29), [macOS](https://en.wikipedia.org/wiki/MacOS), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), and [Linux](https://en.wikipedia.org/wiki/Linux). Peerio (Legacy) was originally released on 14 January 2015,[^o3][^o4] and was replaced by Peerio 2 on 15 June 2017.[^o5] The app is discontinued.[^o6]

:::

Messages and user files stored on the Peerio cloud were protected by end-to-end encryption, meaning the data was encrypted in a way that could not be read by third parties, such as Peerio itself or its service providers. Security was provided by a single permanent key-password, which in Peerio was called an "Account Key".[^o7]

The company, Peerio Technologies Inc., was founded in 2014 by Vincent Drouin. The intent behind Peerio was to provide a security program that is easier to use than the [PGP](wikipedia://en/23080) standard.[^o8]

Peerio was acquired by [WorkJam](https://en.wikipedia.org/wiki/WorkJam_%28software_company%29), a digital workplace solutions provider, on January 13, 2019.[^o9][^o10]

## Features {#Features}

Peerio allowed users to share encrypted messages and files in direct messages or groups that Peerio called "rooms".[^o12]

Peerio "rooms" were offered as a team-oriented group chat, allowing administrative functionality to add and remove other users from the group chat.[^o13]

Peerio allows users to store encrypted files online, offering limited cloud storage for free with optional paid upgrades.[^o12]

Peerio messages and files [persist](https://en.wikipedia.org/wiki/Persistent_data_structure) between logins and hardware, differing from [ephemeral](https://en.wikipedia.org/wiki/Ephemeral_data_structure) encrypted messaging apps which do not retain message or file history between logins or different devices.

Peerio supported application based [multi-factor authentication](https://en.wikipedia.org/wiki/Multi-factor_authentication).[^o12]

Peerio allowed users to share animated GIFs.[^o14]

## Security {#Security}

### End-to-End Encryption {#End-to-End_Encryption}

Peerio utilized end-to-end encryption and it was applied by default to all message and file data. End-to-end encryption is intended to encrypt data in a way that only the sender and intended recipients are able to decrypt, and thus read, the data.

Taken from Peerio's privacy policy:

"Peerio utilizes the [NaCl](https://en.wikipedia.org/wiki/NaCl_%28software%29) (pronounced "salt") cryptographic framework, which itself uses the following cryptographic primitives:

- *[X25519](https://en.wikipedia.org/wiki/X25519)* for public key agreement over elliptic curves.
- *[ed25519](https://en.wikipedia.org/wiki/Ed25519)* for public key signatures.
- *XSalsa20* for encryption and confidentiality.
- *[Poly1305](wikipedia://en/2017690)* for ensuring the integrity of encrypted data.

Additionally, Peerio uses *[scrypt](https://en.wikipedia.org/wiki/Scrypt)* for memory-hard key derivation and *[BLAKE2s](https://en.wikipedia.org/wiki/BLAKE2s)* is used for various hashing operations.

For in-transit encryption, Peerio Services used [Transport Layer Security](wikipedia://en/187813) (TLS) with best-practice cipher suite configuration, including support for [perfect forward secrecy](https://en.wikipedia.org/wiki/Perfect_Forward_Secrecy) (PFS). You can view a detailed and up-to-date independent review of Peerio's TLS configuration on SSL Labs."[^o17][^o18]

### Code Audits {#Code_Audits}

Prior to Peerio's initial release, the software was [audited](https://en.wikipedia.org/wiki/Software_audit_review) by the German security firm [Cure53](https://en.wikipedia.org/wiki/Cure53), which found only non-security related bugs, all of which were fixed prior to the applications release.[^o4]

According to Peerio's website, the application was also audited in March 2017 by Cure53.[^o13]

### Open Source {#Open_Source}

Peerio was partly [open source](https://en.wikipedia.org/wiki/Open-source_software) and published code publicly on [GitHub](https://en.wikipedia.org/wiki/GitHub)[^o21]

### Bug Bounty {#Bug_Bounty}

Peerio offered a [bug bounty](https://en.wikipedia.org/wiki/Bug_bounty_program), offering cash rewards for anyone who reports security vulnerabilities.[^o23]

## Peerio (Legacy) {#Peerio_(Legacy)}

The first iteration of Peerio, **Peerio (Legacy)**, was developed by [Nadim Kobeissi](https://en.wikipedia.org/wiki/Nadim_Kobeissi) and Florencia Herra-Vega and was released on 14 January 2015[^o3][^o4] and was closed on 8 January 2018.[^o14]

Peerio (Legacy) was a free application, available for [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29), [iOS](https://en.wikipedia.org/wiki/IOS), [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), [Linux](https://en.wikipedia.org/wiki/Linux), and as a [Google Chrome extension](https://en.wikipedia.org/wiki/Google_Chrome_extension).[^o25][^o26] It offered end-to-end encryption, which is enabled by default. The encryption used the miniLock open-source security standard, which was also developed by Kobeissi.[^o27]

On 15 June 2017, Peerio 2 was launched as the successor to Peerio (Legacy). According to the company's blog, Peerio 2 is purported to be a "radical overhaul" of the original application's core technology.[^o5] Claimed benefits in comparison to Peerio (Legacy) include increased speed, support for larger file transfers (up to 7000GB), and a re-designed user interface. Peerio also stated an added focus towards businesses looking for encrypted team collaboration software.[^o13]
