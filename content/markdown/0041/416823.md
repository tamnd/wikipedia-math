# Square triangular number

*Image: square\_triangular\_number\_36.svg.* Square triangular number 36 depicted as a triangular number and as a square number.

::: {#o1 .subject cue=lead name="Square triangular number"}

In [mathematics](wikipedia://en/18831), a **square triangular number** (or **triangular square number**) is a number which is both a [triangular number](wikipedia://en/213915) and a [square number](wikipedia://en/213919), in other words, the sum of all integers from $1$ to $n$ has a square root that is an integer. ## Solution as a Pell equation {#Solution_as_a_Pell_equation}

Define the *triangular root* of a triangular number $N=\tfrac{n(n+1)}{2}$ to be $n$. In the form of the quadratic equation, $n^2 + n - 2N = 0$. From the quadratic formula,

Therefore, $N$ is triangular ($n$ is an integer) [if and only if](wikipedia://en/14922) $8N+1$ is square. Consequently, a square number $M^2$ is also triangular if and only if $8M^2+1$ is square, that is, there are numbers $x$ and $y$ such that $x^2-8y^2=1$. This is an instance of the [Pell equation](https://en.wikipedia.org/wiki/Pell_equation) $x^2-ny^2=1$ with $n=8$. All Pell equations have the trivial solution $x=1,y=0$ for any $n$; this is called the zeroth solution, and indexed as $(x_0,y_0)=(1,0)$. ## Other characterizations {#Other_characterizations}

All square triangular numbers have the form $b^2c^2$, where $\tfrac{b}{c}$ is a [convergent](https://en.wikipedia.org/wiki/Convergent_%28continued_fraction%29) to the [continued fraction expansion](wikipedia://en/46802) of $\sqrt2$, the [square root of 2](wikipedia://en/341682).[^o11]

A. V. Sylwester gave a short proof that there are infinitely many square triangular numbers: If the $n$th triangular number $\tfrac{n(n+1)}{2}$ is square, then so is the larger $4n(n+1)$th triangular number, since:

The left hand side of this equation is in the form of a triangular number, and as the product of three squares, the right hand side is square.[^o12]

The [generating function](wikipedia://en/160993) for the square triangular numbers is:[^o13]

$$\frac{1+z}{(1-z)\left(z^2 - 34z + 1\right)} = 1 + 36z + 1225 z^2 + \cdots$$
