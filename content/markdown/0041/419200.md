# Schrödinger picture

::: {#o1 .subject cue=lead name="Schrödinger picture"}

In [physics](wikipedia://en/22939), the **Schrödinger picture** or **Schrödinger representation** is a [formulation](https://en.wikipedia.org/wiki/Dynamical_pictures) of [quantum mechanics](wikipedia://en/25202) in which the [state vectors](https://en.wikipedia.org/wiki/Quantum_state_vector) evolve in time, but the operators (observables and others) are mostly constant with respect to time (an exception is the Hamiltonian which may change if the potential $V$ changes).[^o2][^o3] This differs from the [Heisenberg picture](wikipedia://en/306706) which keeps the states constant while the observables evolve in time, and from the [interaction picture](wikipedia://en/901382) in which both the states and the observables evolve in time. The Schrödinger and Heisenberg pictures are related as [active and passive transformations](wikipedia://en/366436) and [commutation relations](https://en.wikipedia.org/wiki/Commutation_relation) between operators are preserved in the passage between the two pictures.

:::

In the [Schrödinger](https://en.wikipedia.org/wiki/Schrödinger) picture, the state of a system evolves with time. The evolution for a closed quantum system is brought about by a [unitary operator](https://en.wikipedia.org/wiki/Unitarity_%28physics%29), the [time evolution operator](wikipedia://en/937739). For time evolution from a state vector $|\psi(t_0)\rangle$ at time $t$<sub>0</sub> to a state vector $|\psi(t)\rangle$ at time $t$, the time-evolution operator is commonly written $U(t, t_0)$, and one has

$$|\psi(t)\rangle = U(t, t_0) |\psi(t_0)\rangle.$$

In the case where the [Hamiltonian](wikipedia://en/14381) $H$ of the system does not vary with time, the time-evolution operator has the form

$$U(t, t_0) = e^{-iH\cdot (t-t_0)/\hbar},$$

where the exponent is evaluated via its [Taylor series](wikipedia://en/30448).

The Schrödinger picture is useful when dealing with a time-independent Hamiltonian $H$; that is, $\partial_t H=0$.

## Background {#Background}

In elementary quantum mechanics, the [state](wikipedia://en/30876419) of a quantum-mechanical system is represented by a complex-valued [wavefunction](https://en.wikipedia.org/wiki/Wavefunction) $\psi(x, t)$. More abstractly, the state may be represented as a state vector, or [*ket*](wikipedia://en/4542), $| \psi \rangle$. This ket is an element of a *[Hilbert space](wikipedia://en/20598932)*, a vector space containing all possible states of the system. A quantum-mechanical [operator](https://en.wikipedia.org/wiki/Operator_%28physics%29#Operators_in_quantum_mechanics) is a function which takes a ket $| \psi \rangle$ and returns some other ket $| \psi' \rangle$.

The differences between the Schrödinger and Heisenberg pictures of quantum mechanics revolve around how to deal with systems that evolve in time: the time-dependent nature of the system *must* be carried by some combination of the state vectors and the operators. For example, a [quantum harmonic oscillator](wikipedia://en/50719) may be in a state $| \psi \rangle$ for which the [expectation value](wikipedia://en/11371560) of the momentum, $\langle \psi | \hat{p} | \psi \rangle$, oscillates sinusoidally in time. One can then ask whether this sinusoidal oscillation should be reflected in the state vector $| \psi \rangle$, the momentum operator $\hat{p}$, or both. All three of these choices are valid; the first gives the Schrödinger picture, the second the Heisenberg picture, and the third the interaction picture.

## The time evolution operator {#The_time_evolution_operator}

::: {#o7 .definition cue=heading name="Definition"}

### Definition {#Definition}

The time-evolution operator *U*(*t*, *t*<sub>0</sub>) is defined as the operator which acts on the ket at time *t*<sub>0</sub> to produce the ket at some other time *t*:

$$| \psi(t) \rangle = U(t,t_0) | \psi(t_0) \rangle.$$

For [bras](https://en.wikipedia.org/wiki/Bra-ket_notation),

$$\langle \psi(t) | = \langle \psi(t_0) |U^{\dagger}(t,t_0).$$

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

**Unitarity**

The time evolution operator must be [unitary](wikipedia://en/225999). For the [norm](wikipedia://en/990534) of the state ket must not change with time. That is,

$$\langle \psi(t)| \psi(t) \rangle = \langle \psi(t_0)|U^{\dagger}(t,t_0)U(t,t_0)| \psi(t_0) \rangle = \langle \psi(t_0) | \psi(t_0) \rangle.$$

Therefore,

$$U^{\dagger}(t,t_0)U(t,t_0)=I.$$

**Identity**

When *t* = *t*<sub>0</sub>, *U* is the [identity operator](https://en.wikipedia.org/wiki/Identity_operator), since

$$| \psi(t_0) \rangle = U(t_0,t_0) | \psi(t_0) \rangle.$$

**Closure**

Time evolution from *t*<sub>0</sub> to *t* may be viewed as a two-step time evolution, first from *t*<sub>0</sub> to an intermediate time *t*<sub>1</sub>, and then from *t*<sub>1</sub> to the final time *t*. Therefore,

$$U(t, t_0) = U(t, t_1) U(t_1, t_0).$$

:::

### Differential equation for time evolution operator {#Differential_equation_for_time_evolution_operator}

We drop the *t*<sub>0</sub> index in the time evolution operator with the convention that $t_{0} = 0$ and write it as *U*(*t*). The [Schrödinger equation](wikipedia://en/59874) is

$$i \hbar \frac{\partial}{\partial t} |\psi(t)\rangle = H |\psi(t)\rangle,$$

where *H* is the [Hamiltonian](wikipedia://en/14381). Now using the time-evolution operator *U* to write $|\psi(t)\rangle = U(t) |\psi(0)\rangle$,

$$i \hbar {\partial \over \partial t} U(t) | \psi (0) \rangle = H U(t)| \psi (0)\rangle.$$

Since $|\psi(0)\rangle$ is a constant ket (the state ket at $t = 0$), and since the above equation is true for any constant ket in the Hilbert space, the time evolution operator must obey the equation

$$i \hbar \frac{\partial}{\partial t} U(t) = H U(t).$$

If the Hamiltonian is independent of time, the solution to the above equation is[^o11]

$$U(t) = e^{-iHt / \hbar}.$$

Since *H* is an operator, this exponential expression is to be evaluated via its [Taylor series](wikipedia://en/30448):

$$e^{-iHt / \hbar} = 1 - \frac{iHt}{\hbar} - \frac{1}{2} \left(\frac{Ht}{\hbar}\right)^2 + \cdots .$$

Therefore,

$$| \psi(t) \rangle = e^{-iHt / \hbar} | \psi(0) \rangle.$$

Note that $|\psi(0)\rangle$ is an arbitrary ket. However, if the initial ket is an [eigenstate](https://en.wikipedia.org/wiki/Eigenstate) of the Hamiltonian, with eigenvalue *E*:

$$| \psi(t) \rangle = e^{-iEt / \hbar} | \psi(0) \rangle.$$

The eigenstates of the Hamiltonian are *stationary states*: they only pick up an overall phase factor as they evolve with time.

If the Hamiltonian is dependent on time, but the Hamiltonians at different times commute, then the time evolution operator can be written as

$$U(t) = \exp\left({-\frac{i}{\hbar} \int_0^t H(t')\, dt'}\right),$$

If the Hamiltonian is dependent on time, but the Hamiltonians at different times do not commute, then the time evolution operator can be written as

$$U(t) = \mathrm{T}\exp\left({-\frac{i}{\hbar} \int_0^t H(t')\, dt'}\right),$$

where T is [time-ordering](https://en.wikipedia.org/wiki/Time-ordering) operator, which is sometimes known as the [Dyson series](wikipedia://en/1409609), after [Freeman Dyson](wikipedia://en/11397).

The alternative to the Schrödinger picture is to switch to a rotating reference frame, which is itself being rotated by the propagator. Since the undulatory rotation is now being assumed by the reference frame itself, an undisturbed state function appears to be truly static. This is the [Heisenberg picture](wikipedia://en/306706).
