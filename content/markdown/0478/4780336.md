# Generalized Wiener process

::: {#o1 .subject cue=lead name="Generalized Wiener process"}

In [statistics](wikipedia://en/26685), a **generalized Wiener process**[^o2] (named after [Norbert Wiener](wikipedia://en/63185)) is a [continuous time](https://en.wikipedia.org/wiki/Continuous_time) [random walk with drift](https://en.wikipedia.org/wiki/Random_walk_with_drift) and [random](https://en.wikipedia.org/wiki/Random) jumps at every point in time. Formally:

:::

$$a(x,t) dt + b(x,t) \eta \sqrt{dt}$$

where a and b are [deterministic](https://en.wikipedia.org/wiki/Deterministic) functions, t is a [continuous](wikipedia://en/6122) index for time, x is a set of [exogenous](https://en.wikipedia.org/wiki/Exogenous) variables that may change with time, dt is a [differential](wikipedia://en/23997203) in time, and η is a [random](https://en.wikipedia.org/wiki/Random) draw from a [standard normal distribution](https://en.wikipedia.org/wiki/Standard_normal_distribution) at each instant.
