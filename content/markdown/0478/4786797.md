# Pointwise

::: {#o1 .subject cue=lead name="Pointwise"}

In [mathematics](wikipedia://en/18831), the qualifier **pointwise** is used to indicate that a certain property is defined by considering each value $f(x)$ of some [function](wikipedia://en/185427) $f.$ An important class of pointwise concepts are the *pointwise operations*, that is, operations defined on functions by applying the operations to function values separately for each point in the [domain](wikipedia://en/50263) of definition. Important [relations](https://en.wikipedia.org/wiki/Theory_of_relations) can also be defined pointwise.

:::

### Formal definition {#Formal_definition}

A binary operation $o: Y \times Y \to Y$ on a set $Y$ can be lifted pointwise to an operation $O: (X\to Y) \times (X\to Y) \to (X\to Y)$ on the set $X \to Y$ of all functions from $X$ to $Y$ as follows: Given two functions $f_{1}: X \to Y$ and $f_{2}: X \to Y$, define the function $O(f_{1}, f_{2}): X \to Y$ by

Commonly, *o* and *O* are denoted by the same symbol. A similar definition is used for unary operations *o*, and for operations of other [arity](wikipedia://en/42301).

### Properties {#Properties}

Pointwise operations inherit such properties as [associativity](https://en.wikipedia.org/wiki/Associativity), [commutativity](https://en.wikipedia.org/wiki/Commutativity) and [distributivity](https://en.wikipedia.org/wiki/Distributivity) from corresponding operations on the [codomain](wikipedia://en/50264). If $A$ is some [algebraic structure](wikipedia://en/106364), the set of all functions $X$ to the [carrier set](https://en.wikipedia.org/wiki/Carrier_set) of $A$ can be turned into an algebraic structure of the same type in an analogous way.

## Componentwise operations {#Componentwise_operations}

Componentwise operations are usually defined on vectors, where vectors are elements of the set $K^n$ for some [natural number](wikipedia://en/21474) $n$ and some [field](wikipedia://en/10603) $K$. If we denote the $i$-th component of any vector $v$ as $v_i$, then componentwise addition is $(u+v)_i = u_i+v_i$.

Componentwise operations can be defined on matrices. Matrix addition, where $(A + B)_{ij} = A_{ij} + B_{ij}$ is a componentwise operation while [matrix multiplication](wikipedia://en/125280) is not.

A [tuple](wikipedia://en/132729#Tuples_as_functions) can be regarded as a function, and a vector is a tuple. Therefore, any vector $v$ corresponds to the function $f:n\to K$ such that $f(i)=v_i$, and any componentwise operation on vectors is the pointwise operation on functions corresponding to those vectors.

:::

## Pointwise relations {#Pointwise_relations}

In [order theory](wikipedia://en/361924) it is common to define a pointwise [partial order](https://en.wikipedia.org/wiki/Partial_order) on functions. With *A*, *B* [posets](https://en.wikipedia.org/wiki/Partially_ordered_sets), the set of functions *A* → *B* can be ordered by defining *f* ≤ *g* if $(\forall x \in A) f(x) \le g(x)$. Pointwise orders also inherit some properties of the underlying posets. For instance if A and B are [continuous lattices](https://en.wikipedia.org/wiki/Continuous_lattice), then so is the set of functions *A* → *B* with pointwise order.[^o13] Using the pointwise order on functions one can concisely define other important notions, for instance:[^o14]

- A *[closure operator](wikipedia://en/483120)* *c* on a poset *P* is a [monotone](wikipedia://en/48260) and [idempotent](https://en.wikipedia.org/wiki/Idempotent) self-map on *P* (i.e. a [projection operator](https://en.wikipedia.org/wiki/Projection_%28order%29)) with the additional property that id<sub>*A*</sub> ≤ *c*, where id is the [identity function](wikipedia://en/15069).
- Similarly, a projection operator *k* is called a *[kernel operator](https://en.wikipedia.org/wiki/Kernel_operator)* if and only if *k* ≤ id<sub>*A*</sub>.

An example of an [infinitary](https://en.wikipedia.org/wiki/Infinitary) pointwise relation is [pointwise convergence](wikipedia://en/340198) of functions—a [sequence](wikipedia://en/27838) of functions

$$(f_n)_{n=1}^\infty$$

with

$$f_n:X \longrightarrow Y$$

[converges](wikipedia://en/285773) pointwise to a function $f$ if for each $x$ in $X$

$$\lim_{n \to \infty} f_n(x) = f(x).$$
