# GapP

::: {#o1 .subject cue=lead name="GapP"}

**GapP** is a [counting complexity class](https://en.wikipedia.org/wiki/Counting_complexity_class), consisting of all of the functions *f* such that there exists a [polynomial-time](https://en.wikipedia.org/wiki/Polynomial-time) [non-deterministic Turing machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine) *M* where, for any input *x*, the value *f(x)* is equal to the number of accepting paths of *M* minus the number of rejecting paths of *M*. GapP is exactly the closure of [\#P](https://en.wikipedia.org/wiki/Sharp-P) under subtraction. It also has all the other closure properties of #P, such as addition, multiplication, and binomial coefficients.

:::

The counting class [AWPP](https://en.wikipedia.org/wiki/Almost_Wide_Probabilistic_Polynomial-Time) is defined in terms of GapP functions.
