# Limit ordinal

*Image: Omega-exp-omega-normal-dark svg.svg.* Representation of the ordinal numbers up to ω<sup>ω</sup>. Each turn of the spiral represents one power of ω. Limit ordinals are those that are non-zero and have no predecessor, such as ω or ω<sup>2</sup>

::: {#o1 .subject cue=lead name="Limit ordinal"}

In [set theory](wikipedia://en/27553), a **limit ordinal** is an [ordinal number](wikipedia://en/26547932) that is neither zero nor a [successor ordinal](wikipedia://en/375256). Alternatively, an ordinal λ is a limit ordinal if there is an ordinal less than λ, and whenever β is an ordinal less than λ, then there exists an ordinal γ such that β \< γ \< λ. Every ordinal number is either zero, a successor ordinal, or a limit ordinal.

:::

For example, the smallest limit ordinal is [ω](https://en.wikipedia.org/wiki/Ω_%28ordinal_number%29), the smallest ordinal greater than every [natural number](wikipedia://en/21474). This is a limit ordinal because for any smaller ordinal (i.e., for any natural number) *n* we can find another natural number larger than it (e.g. *n*+1), but still less than ω. The next-smallest limit ordinal is ω+ω. This will be discussed further in the article.

Using the [von Neumann definition of ordinals](https://en.wikipedia.org/wiki/Von_Neumann_definition_of_ordinals), every ordinal is the [well-ordered set](https://en.wikipedia.org/wiki/Well-ordered_set) of all smaller ordinals. The union of a nonempty set of ordinals that has no [greatest element](https://en.wikipedia.org/wiki/Greatest_element) is then always a limit ordinal. Using [von Neumann cardinal assignment](https://en.wikipedia.org/wiki/Von_Neumann_cardinal_assignment), every infinite [cardinal number](wikipedia://en/6173) is also a limit ordinal.

::: {#o3 .definition cue=heading name="Alternative definitions"}

## Alternative definitions {#Alternative_definitions}

Various other ways to define limit ordinals are:

- It is equal to the [supremum](https://en.wikipedia.org/wiki/Supremum) of all the ordinals below it, but is not zero. (Compare with a successor ordinal: the set of ordinals below it has a maximum, so the supremum is this maximum, the previous ordinal.)
- It is not zero and has no maximum element.
- It can be written in the form ωα for α > 0. That is, in the [Cantor normal form](wikipedia://en/2139226#Cantor_normal_form) there is no finite number as last term, and the ordinal is nonzero.
- It is a limit point of the class of ordinal numbers, with respect to the [order topology](wikipedia://en/213650). (The other ordinals are [isolated points](wikipedia://en/390557).)

Some contention exists on whether or not 0 should be classified as a limit ordinal, as it does not have an immediate predecessor; some textbooks include 0 in the class of limit ordinals[^o4] while others exclude it.[^o5]

:::

## Examples {#Examples}

Because the [class](wikipedia://en/20696) of ordinal numbers is [well-ordered](wikipedia://en/33456), there is a smallest infinite limit ordinal; denoted by ω (omega). The ordinal ω is also the smallest infinite ordinal (disregarding *limit*), as it is the [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) of the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers). Hence ω represents the [order type](wikipedia://en/4499021) of the natural numbers. The next limit ordinal above the first is ω + ω = ω·2, which generalizes to ω·*n* for any natural number *n*. Taking the [union](wikipedia://en/47949) (the [supremum](https://en.wikipedia.org/wiki/Supremum) operation on any [set](wikipedia://en/26691) of ordinals) of all the ω·n, we get ω·ω = ω<sup>2</sup>, which generalizes to ω<sup>*n*</sup> for any natural number *n*. This process can be further iterated as follows to produce:

$$\omega^3, \omega^4, \ldots, \omega^\omega, \omega^{\omega^\omega}, \ldots, \varepsilon_0 = \omega^{\omega^{\omega^{~\cdot^{~\cdot^{~\cdot}}}}}, \ldots$$

In general, all of these recursive definitions via multiplication, exponentiation, repeated exponentiation, etc. yield limit ordinals. All of the ordinals discussed so far are still [countable](https://en.wikipedia.org/wiki/Countable) ordinals. However, there is no [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable) scheme for [systematically naming](wikipedia://en/6108552) all ordinals less than the [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Church–Kleene_ordinal), which is a countable ordinal.

Beyond the countable, the [first uncountable ordinal](wikipedia://en/20860540) is usually denoted ω<sub>1</sub>. It is also a limit ordinal.

Continuing, one can obtain the following (all of which are now increasing in cardinality):

$$\omega_2, \omega_3, \ldots, \omega_\omega, \omega_{\omega + 1}, \ldots, \omega_{\omega_\omega},\ldots$$

In general, we always get a limit ordinal when taking the union of a nonempty set of ordinals that has no [maximum](https://en.wikipedia.org/wiki/Maximum) element.

The ordinals of the form ω²α, for α > 0, are limits of limits, etc.

:::

## Properties {#Properties}

The classes of successor ordinals and limit ordinals (of various [cofinalities](wikipedia://en/6693)) as well as zero exhaust the entire class of ordinals, so these cases are often used in proofs by [transfinite induction](wikipedia://en/30461) or definitions by [transfinite recursion](https://en.wikipedia.org/wiki/Transfinite_recursion). Limit ordinals represent a sort of "turning point" in such procedures, in which one must use limiting operations such as taking the union over all preceding ordinals. In principle, one could do anything at limit ordinals, but taking the union is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) in the order topology and this is usually desirable.

If we use the [von Neumann cardinal assignment](https://en.wikipedia.org/wiki/Von_Neumann_cardinal_assignment), every infinite [cardinal number](wikipedia://en/6173) is also a limit ordinal (and this is a fitting observation, as *cardinal* derives from the Latin *cardo* meaning *hinge* or *turning point*): the proof of this fact is done by simply showing that every infinite successor ordinal is [equinumerous](https://en.wikipedia.org/wiki/Equinumerous) to a limit ordinal via the [Hotel Infinity](wikipedia://en/37797) argument.

Cardinal numbers have their own notion of successorship and limit (everything getting upgraded to a higher level).

:::

## Indecomposable ordinals {#Indecomposable_ordinals}

**Additively indecomposable**

A limit ordinal α is called additively indecomposable if it cannot be expressed as the sum of β \< α ordinals less than α. These numbers are any ordinal of the form $\omega^\beta$ for β an ordinal. The smallest is written $\gamma_0$, the second is written $\gamma_1$, etc.[^o11]

**Multiplicatively indecomposable**

A limit ordinal α is called multiplicatively indecomposable if it cannot be expressed as the product of β \< α ordinals less than α. These numbers are any ordinal of the form $\omega^{\omega^\beta}$ for β an ordinal. The smallest is written $\delta_0$, the second is written $\delta_1$, etc.[^o11]

**Exponentially indecomposable and beyond**

The term "exponentially indecomposable" does not refer to ordinals not expressible as the exponential product *(?)* of β \< α ordinals less than α, but rather the [epsilon numbers](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), "tetrationally indecomposable" refers to the zeta numbers, "pentationally indecomposable" refers to the eta numbers, etc.[^o11]
