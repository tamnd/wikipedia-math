# Law of trichotomy

::: {#o1 .subject cue=lead name="Law of trichotomy"}

In [mathematics](wikipedia://en/18831), the **law of trichotomy** states that every [real number](wikipedia://en/20646438) is either positive, negative, or zero.[^o2]

:::

More generally, a [binary relation](wikipedia://en/3931) *R* on a [set](wikipedia://en/26691) *X* is **trichotomous** if for all *x* and *y* in *X*, exactly one of *xRy*, *yRx* and *x*=*y* holds. Writing *R* as \<, this is stated in formal logic as:

$$\forall x \in X \, \forall y \in X \, ( [ x < y \, \land \, \lnot(y < x) \, \land \, \lnot(x = y) ] \, \lor \, [ \lnot(x < y) \, \land \, y < x \, \land \, \lnot(x = y) ] \, \lor \, [ \lnot(x < y) \, \land \, \lnot(y < x) \, \land \, x = y ] ) \,.$$

With this definition, the law of trichotomy states that \< is a trichotomous relation on the set of real numbers. In other words, if *x* and *y* are real numbers, then exactly one of the following must be true: *x*\<*y*, *x*=*y*, *y*\<*x*.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A relation is trichotomous if, and only if, it is [asymmetric](wikipedia://en/1229368) and [connected](wikipedia://en/57495962).
- If a trichotomous relation is also transitive, then it is a [strict total order](wikipedia://en/30330#Strict_total_order); this is a special case of a [strict weak order](https://en.wikipedia.org/wiki/Strict_weak_order).[^o5][^o6]

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- On the set *X* = {*a*,*b*,*c*}, the relation *R* = { (*a*,*b*), (*a*,*c*), (*b*,*c*) } is transitive and trichotomous, and hence a strict [total order](wikipedia://en/30330).
- On the same set, the cyclic relation *R* = { (*a*,*b*), (*b*,*c*), (*c*,*a*) } is trichotomous, but not transitive; it is even [antitransitive](https://en.wikipedia.org/wiki/Antitransitive).

:::

## Trichotomy on numbers {#Trichotomy_on_numbers}

A law of trichotomy on some set *X* of numbers usually expresses that some tacitly given ordering relation on *X* is a trichotomous one. An example is the law "For arbitrary real numbers *x* and *y*, exactly one of *x* \< *y*, *y* \< *x*, or *x* = *y* applies". (Some authors fix *y* to be zero, relying on the real number's [linearly ordered group](wikipedia://en/349014) structure for addition.

In classical logic, this **axiom of trichotomy** holds for ordinary comparisons between real numbers and therefore also for comparisons between [integers](wikipedia://en/14563) and between [rational numbers](wikipedia://en/19727024). The law does not hold in general in [intuitionistic logic](wikipedia://en/169262).

In [Zermelo–Fraenkel set theory](wikipedia://en/152214) and [Bernays set theory](wikipedia://en/528491), the law of trichotomy holds for the [cardinal numbers](wikipedia://en/6173) of well-orderable sets, but not necessarily for all cardinal numbers. If the axiom of choice holds, then trichotomy holds between arbitrary cardinal numbers (because they are [all well-orderable](wikipedia://en/33458) in that case).[^o10]
