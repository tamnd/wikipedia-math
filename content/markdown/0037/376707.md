# R (programming language)

::: {#o6 .subject cue=lead name="R"}

**R** is a [programming language](wikipedia://en/23015) for [statistical computing](https://en.wikipedia.org/wiki/Statistical_computing) and [data visualization](wikipedia://en/3461736). It has been widely adopted in the fields of [data mining](wikipedia://en/42253), [bioinformatics](wikipedia://en/4214), [data analysis](wikipedia://en/2720954), and [data science](wikipedia://en/35458904).[^o7]

:::

The core R language is extended by a large number of [software packages](wikipedia://en/65740838), which contain [reusable code](https://en.wikipedia.org/wiki/Reusability), documentation, and sample data. Some of the most popular R packages are in the [tidyverse](wikipedia://en/59164935) collection, which enhances functionality for visualizing, transforming, and modelling data, as well as improves the ease of programming (according to the authors and users).[^o8]

R is [free and open-source software](https://en.wikipedia.org/wiki/Free_and_open-source_software) distributed under the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License).[^o9][^o10] The language is implemented primarily in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), [Fortran](https://en.wikipedia.org/wiki/Fortran), and [R itself](https://en.wikipedia.org/wiki/Self-hosting_%28compilers%29). [Precompiled](https://en.wikipedia.org/wiki/Preprocessor) [executables](https://en.wikipedia.org/wiki/Executable) are available for the major [operating systems](https://en.wikipedia.org/wiki/Operating_system) (including [Linux](https://en.wikipedia.org/wiki/Linux), [MacOS](https://en.wikipedia.org/wiki/MacOS), and [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows)).

Its core is an [interpreted language](https://en.wikipedia.org/wiki/Interpreted_language) with a native [command line interface](https://en.wikipedia.org/wiki/Command_line_interface). In addition, multiple [third-party](https://en.wikipedia.org/wiki/Third-party_software_component) applications are available as [graphical user interfaces](https://en.wikipedia.org/wiki/Graphical_user_interface); such applications include [RStudio](wikipedia://en/36691501) (an [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment)), [Jupyter](https://en.wikipedia.org/wiki/Jupyter) (a [notebook interface](https://en.wikipedia.org/wiki/Notebook_interface)), as well as [Termux](https://en.wikipedia.org/wiki/Termux) and [Google Colab](https://en.wikipedia.org/wiki/Google_Colab) for mobile devices.[^o11]

## History {#History}

R was started by professors [Ross Ihaka](wikipedia://en/19954367) and [Robert Gentleman](https://en.wikipedia.org/wiki/Robert_Gentleman_%28statistician%29) as a programming language to teach introductory statistics at the [University of Auckland](https://en.wikipedia.org/wiki/University_of_Auckland).[^o13] The language was inspired by the [S programming language](wikipedia://en/919313), with most S programs able to run unaltered in R.[^o14] The language was also inspired by [Scheme's](https://en.wikipedia.org/wiki/Scheme_%28programming_language%29) [lexical scoping](https://en.wikipedia.org/wiki/Lexical_scoping), allowing for [local variables](https://en.wikipedia.org/wiki/Local_variable).[^o15]

The name of the language, R, comes from being both an S language successor and the shared first letter of the authors, Ross and Robert.[^o16] In August 1993, Ihaka and Gentleman posted a [binary](https://en.wikipedia.org/wiki/Binary_file) file of R on StatLib — a data archive website.[^o17] At the same time, they announced the posting on the *s-news* mailing list.[^o18] On 5 December 1997, R became a [GNU project](https://en.wikipedia.org/wiki/GNU_project) when version 0.60 was released.[^o19] On 29 February 2000, the 1.0 version was released.[^o20]

## Packages {#Packages}

*Image: Ggplot2 PlantGrowth violin plot.svg.* A [violin plot](wikipedia://en/17164795) created with the R package [ggplot2](wikipedia://en/32380922) for data visualization

[R packages](wikipedia://en/65740838) are collections of functions, documentation, and data that expand R.[^o23] For example, packages can add reporting features (using packages such as [R Markdown](wikipedia://en/36691501#Reproducible_analyses_with_R_Markdown_vignettes), Quarto,[^o24] [knitr](https://en.wikipedia.org/wiki/Knitr), and [Sweave](wikipedia://en/16749071)) and support for various statistical techniques (such as [linear](https://en.wikipedia.org/wiki/Linear), [generalized linear](wikipedia://en/747122) and [nonlinear](wikipedia://en/146103) modeling, classical [statistical tests](https://en.wikipedia.org/wiki/Statistical_hypothesis_testing), [spatial](wikipedia://en/3190431) analysis, [time-series analysis](https://en.wikipedia.org/wiki/Time-series_analysis), and [clustering](wikipedia://en/669675)). Ease of package installation and use have contributed to the language's adoption in [data science](wikipedia://en/35458904).[^o25]

Immediately available when starting R after installation, base packages provide the fundamental and necessary syntax and commands for programming, computing, graphics production, [basic arithmetic](wikipedia://en/1567386), and statistical functionality.[^o26]

An example is the MASS package, which bundles functions and datasets to support the textbook *Modern Applied Statistics with S* by Venables and Ripley.

Installing a package occurs only once. For example, to install the MASS package:[^o27]

```rout
> install.packages("MASS")
```

To load the functions, data, and documentation of a package, one calls the `library()` function. To load the MASS collection, one can execute the following code:

```rout
> # The package name can be enclosed in quotes
> library("MASS")

> # But the package name can also be used without quotes
> library(MASS)
```

The [Comprehensive R Archive Network](wikipedia://en/65740838#Comprehensive_R_Archive_Network_%28CRAN%29) (CRAN) was founded in 1997 by Kurt Hornik and [Friedrich Leisch](https://en.wikipedia.org/wiki/Friedrich_Leisch) to host R's [source code](https://en.wikipedia.org/wiki/Source_code), executable files, documentation, and user-created packages.[^o28] CRAN's name and scope mimic the [Comprehensive TeX Archive Network](https://en.wikipedia.org/wiki/Comprehensive_TeX_Archive_Network) (CTAN) and the [Comprehensive Perl Archive Network](https://en.wikipedia.org/wiki/Comprehensive_Perl_Archive_Network) (CPAN).[^o28] CRAN originally had only three [mirror sites](https://en.wikipedia.org/wiki/Mirror_site) and twelve contributed packages.[^o29] , it has 90 mirrors[^o30] and 22,390 contributed packages.[^o31] Packages are also available in [repositories](https://en.wikipedia.org/wiki/Repository_%28version_control%29) such as R-Forge, Omegahat, and [GitHub](https://en.wikipedia.org/wiki/GitHub).[^o32][^o33][^o34]

To provide guidance on the CRAN web site, its [Task Views](https://cran.r-project.org/web/views/) area lists packages that are relevant for specific topics; sample topics include [causal inference](wikipedia://en/37103476), [finance](https://en.wikipedia.org/wiki/Finance), [genetics](https://en.wikipedia.org/wiki/Genetics), [high-performance computing](https://en.wikipedia.org/wiki/High-performance_computing), [machine learning](wikipedia://en/233488), [medical imaging](https://en.wikipedia.org/wiki/Medical_imaging), [meta-analysis](wikipedia://en/62329), [social sciences](https://en.wikipedia.org/wiki/Social_science), and [spatial statistics](wikipedia://en/9467349).

The [Bioconductor](https://en.wikipedia.org/wiki/Bioconductor) project provides packages for [genomic](https://en.wikipedia.org/wiki/Genomics) data analysis, [complementary DNA](https://en.wikipedia.org/wiki/Complementary_DNA), [microarray](https://en.wikipedia.org/wiki/Microarray), and [high-throughput sequencing](https://en.wikipedia.org/wiki/High-throughput_sequencing) methods.

### Basic syntax {#Basic_syntax}

The following examples illustrate the basic [syntax of the language](https://en.wikipedia.org/wiki/Programming_language_syntax) and use of the command-line interface.

In R, the generally preferred [assignment operator](https://en.wikipedia.org/wiki/Assignment_%28computer_science%29) is an arrow made from two characters `<-`, although `=` can be used in some cases.[^o42]

```rout
> x <- 1:6 # Create a numeric vector in the current environment
> y <- x^2 # Similarly, create a vector based on the values in x.
> y        # Print the vector’s contents.
[1]  1  4  9 16 25 36

> z <- x + y # Create a new vector that is the sum of x and y
> z # Return the contents of z to the current environment.
[1]  2  6 12 20 30 42

> z_matrix <- matrix(z, nrow = 3) # Create a new matrix that transforms the
                                  # vector z into a 3x2 matrix object
> z_matrix 
     [,1] [,2]
[1,]    2   20
[2,]    6   30
[3,]   12   42

> 2 * t(z_matrix) - 2 # Transpose the matrix; multiply every element by 2;
                      # subtract 2 from each element in the matrix; and
                      # then return the results to the terminal.
     [,1] [,2] [,3]
[1,]    2   10   22
[2,]   38   58   82

# Create a new dataframe object that contains the data from a transposed
# z_matrix, with row names 'A' and 'B'
> new_df <- data.frame(t(z_matrix), row.names = c("A", "B")) 
> names(new_df) <- c("X", "Y", "Z") # Set the column names of the new_df dataframe as X, Y, and Z.
> new_df                            # Print the current results.
   X  Y  Z
A  2  6 12
B 20 30 42

> new_df$Z # Output the Z column
[1] 12 42

> new_df$Z == new_df['Z'] && new_df[3] == new_df$Z # The dataframe column Z can be accessed using the syntax $Z, ['Z'], or [3], and the values are the same. 
[1] TRUE

> attributes(new_df) # Print information about attributes of the new_df dataframe
$names
[1] "X" "Y" "Z"

$row.names
[1] "A" "B"

$class
[1] "data.frame"

> attributes(new_df)$row.names <- c("one", "two") # Access and then change the row.names attribute; this can also be done using the rownames() function
> new_df
     X  Y  Z
one  2  6 12
two 20 30 42
```

### Structure of a function {#Structure_of_a_function}

R can create [functions](https://en.wikipedia.org/wiki/Function_%28computer_programming%29) that add new functionality and enable code reuse.[^o44] [Objects](https://en.wikipedia.org/wiki/Object_%28computer_science%29) created within the body of the function (which are enclosed by curly brackets) remain [accessible only](https://en.wikipedia.org/wiki/Local_variable) from within the function, and any [data type](https://en.wikipedia.org/wiki/Data_type) may be returned. In R, almost all functions and all [user-defined functions](https://en.wikipedia.org/wiki/User-defined_function) are [closures](https://en.wikipedia.org/wiki/Closure_%28computer_programming%29).[^o45]

The following is an example of creating a function to perform an arithmetic calculation:

```r
# The function's input parameters are x and y.
# The function, named f, returns a linear combination of x and y.
f <- function(x, y) {
  z <- 3 * x + 4 * y

  # An explicit return() statement is optional--it could be replaced with simply `z` in this case.
  return(z)
}

# As an alternative, the last statement executed in a function is returned implicitly.
f <- function(x, y) 3 * x + 4 * y
```

The following is some output from using the function defined above:

```rout
> f(1, 2) #  3 * 1 + 4 * 2 = 3 + 8
[1] 11

> f(c(1, 2, 3), c(5, 3, 4)) # Element-wise calculation
[1] 23 18 25

> f(1:3, 4) # Equivalent to f(c(1, 2, 3), c(4, 4, 4))
[1] 19 22 25
```

It is possible to define functions to be used as [infix operators](wikipedia://en/199014) by using the special syntax `` `%name%` ``, where "name" is the function variable name:

```rout
> `%sumx2y2%` <- function(e1, e2) {e1 ^ 2 + e2 ^ 2}
> 1:3 %sumx2y2% -(1:3)
[1]  2  8 18 
```

Since R version 4.1.0, functions can be written in a short notation (inspired by the [lambda calculus](wikipedia://en/18203)), which is useful for passing anonymous functions to higher-order functions:[^o46]

```rout
> sapply(1:5, \(i) i^2)    # here \(i) is the same as function(i) 
[1]  1  4  9 16 25
```

### Native pipe operator {#Native_pipe_operator}

In R version 4.1.0, a native [pipe operator](https://en.wikipedia.org/wiki/Pipeline_%28computing%29), `|>`, was introduced.[^o48] This operator allows users to chain functions together, rather than using nested function calls.

```rout
> nrow(subset(mtcars, cyl == 4)) # Nested without the pipe character
[1] 11

> mtcars |> subset(cyl == 4) |> nrow() # Using the pipe character
[1] 11
```

An alternative to nested functions is the use of intermediate objects, rather than the pipe operator:

```rout
> mtcars_subset_rows <- subset(mtcars, cyl == 4)
> num_mtcars_subset <- nrow(mtcars_subset_rows)
> print(num_mtcars_subset)
[1] 11
```

While the pipe operator can produce code that is easier to read, influential R programmers like [Hadley Wickham](wikipedia://en/41916270) suggest to chain together at most 10-15 lines of code using this operator and saving them into objects having meaningful names to avoid [code obfuscation](https://en.wikipedia.org/wiki/Code_obfuscating).[^o49]

### Object-oriented programming {#Object-oriented_programming}

The R language has native support for [object-oriented programming](https://en.wikipedia.org/wiki/Object-oriented_programming). There are two native [frameworks](https://en.wikipedia.org/wiki/Application_framework), the so-called S3 and S4 systems. The former, being more informal, supports single dispatch on the first argument, and objects are assigned to a class simply by setting a "class" attribute in each object. The latter is a system like the [Common Lisp Object System (CLOS)](https://en.wikipedia.org/wiki/CLOS), with formal classes (also derived from [S](wikipedia://en/919313#S4)) and generic methods, which supports [multiple dispatch](https://en.wikipedia.org/wiki/Multiple_dispatch) and [multiple inheritance](https://en.wikipedia.org/wiki/Multiple_inheritance)[^o51]

In the example below, `summary()` is a [generic function](https://en.wikipedia.org/wiki/Generic_function) that dispatches to different methods depending on whether its [argument](wikipedia://en/32842052) is a numeric [vector](wikipedia://en/23218956) or a *factor*:

```rout
> data <- c("a", "b", "c", "a", NA)
> summary(data)
   Length     Class      Mode 
        5 character character 
> summary(as.factor(data))
   a    b    c NA's 
   2    1    1    1 
```

### Modeling and plotting {#Modeling_and_plotting}

*Image: Plots from lm example.svg.* Diagnostic plots for the model from the example code in the "Modeling and plotting" section (q.v. the `plot.lm()` function). Mathematical notation is allowed in labels, as shown in the lower left plot.

The R language has built-in support for [data modeling](https://en.wikipedia.org/wiki/Data_modeling) and graphics. The following example shows how R can generate and plot a [linear model](wikipedia://en/17904) with residuals.

```r
# Create x and y values
x <- 1:6
y <- x^2

# Linear regression model: y = A + B * x
model <- lm(y ~ x)

# Display an in-depth summary of the model
summary(model)

# Create a 2-by-2 layout for figures
par(mfrow = c(2, 2))

# Output diagnostic plots of the model
plot(model)
```

### Mandelbrot set {#Mandelbrot_set}

*Image: Mandelbrot Creation Animation.gif.* A Mandelbrot set as visualized in R. (Note: The colours in this image differ from the output of the sample code in the "Mandelbrot set" section.)

This example of a [Mandelbrot set](wikipedia://en/19562) highlights the use of [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers). It models the first 20 [iterations](wikipedia://en/68833) of the [equation](wikipedia://en/9284) `z = z<sup>2</sup> + c`, where `c` represents different [complex constants](wikipedia://en/5826).

To run this sample code, it is necessary to first install the package that provides the `write.gif()` function:

```r
install.packages("caTools")
```

The sample code is as follows:

```r
library(caTools)

jet.colors <-
    colorRampPalette(
        c("green", "pink", "#007FFF", "cyan", "#7FFF7F",
          "white", "#FF7F00", "red", "#7F0000"))

dx <- 1500 # define width
dy <- 1400 # define height

C  <-
    complex(
            real = rep(seq(-2.2, 1.0, length.out = dx), each = dy),
            imag = rep(seq(-1.2, 1.2, length.out = dy), times = dx)
            )

# reshape as matrix of complex numbers
C <- matrix(C, dy, dx)

# initialize output 3D array
X <- array(0, c(dy, dx, 20))

Z <- 0

# loop with 20 iterations
for (k in 1:20) {

  # the central difference equation
  Z <- Z^2 + C

  # capture the results
  X[, , k] <- exp(-abs(Z))
}

write.gif(
    X,
    "Mandelbrot.gif",
    col = jet.colors,
    delay = 100)
```

## Version names {#Version_names}

*Image: CD of R 1 0 0.png.* A CD of R Version 1.0.0, autographed by the core team of R, photographed in Quebec City in 2019

All R version releases from 2.14.0 onward have [codenames](https://en.wikipedia.org/wiki/Code_name) that make reference to *[Peanuts](https://en.wikipedia.org/wiki/Peanuts)* comics and films.[^o55][^o56][^o57]

In 2018, core R developer [Peter Dalgaard](wikipedia://en/65741765) presented a history of R releases since 1997.[^o58] Some notable early releases before the named releases include the following:

- Version 1.0.0, released on 29 February 2000, a [leap day](https://en.wikipedia.org/wiki/Leap_days)
- Version 2.0.0, released on 4 October 2004, "which at least had a nice ring to it"[^o58]

The idea of naming R version releases was inspired by the naming system for [Debian](https://en.wikipedia.org/wiki/Debian_version_history) and [Ubuntu](https://en.wikipedia.org/wiki/Ubuntu_version_history) versions. Dalgaard noted an additional reason for the use of Peanuts references in R codenames—the humorous observation that "everyone in statistics is a [P-nut](wikipedia://en/554994)."[^o58]

## Implementations {#Implementations}

The main R implementation is written primarily in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), [Fortran](https://en.wikipedia.org/wiki/Fortran), and [R itself](https://en.wikipedia.org/wiki/Self-hosting_%28compilers%29). Other implementations include the following:

- [pretty quick R](http://www.pqr-project.org) (pqR), by [Radford M. Neal](https://en.wikipedia.org/wiki/Radford_M._Neal), which attempts to improve [memory management](https://en.wikipedia.org/wiki/Memory_management).
- [Renjin](https://en.wikipedia.org/wiki/Renjin) for the [Java Virtual Machine](https://en.wikipedia.org/wiki/Java_virtual_machine).
- [CXXR](https://www.cs.kent.ac.uk/projects/cxxr) and Riposte[^o65] written in [C++](https://en.wikipedia.org/wiki/C++).
- [Oracle's](https://en.wikipedia.org/wiki/Oracle_Corporation) [FastR](https://github.com/oracle/fastr) built on [GraalVM](https://www.graalvm.org/).
- [TIBCO](https://en.wikipedia.org/wiki/TIBCO_Software) Enterprise Runtime for R (TERR) to integrate with [Spotfire](https://en.wikipedia.org/wiki/Spotfire).[^o66] (The company also sold [S-Plus](wikipedia://en/3830007), a discontinued implementation of the S language.)

Microsoft R Open (MRO) was an R implementation. As of 30 June 2021, Microsoft began to phase out MRO in favor of the CRAN distribution.[^o67]

## Commercial support {#Commercial_support}

Although R is an [open-source](https://en.wikipedia.org/wiki/Open-source) project, some companies provide commercial support:

- [Oracle](https://en.wikipedia.org/wiki/Oracle_Corporation) provides commercial support for its [Big Data Appliance](https://en.wikipedia.org/wiki/Oracle_Big_Data_Appliance), which integrates R into its other products.
- [IBM](https://en.wikipedia.org/wiki/IBM) provides commercial support for execution of R within [Hadoop](https://en.wikipedia.org/wiki/Hadoop).
