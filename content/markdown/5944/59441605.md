# Box's M test

::: {#o1 .subject cue=lead name="Box's M test"}

**Box's *M* test** is a multivariate statistical test used to check the equality of multiple [variance-covariance matrices](https://en.wikipedia.org/wiki/Variance-covariance_matrix).[^o2] The test is commonly used to test the assumption of [homogeneity](https://en.wikipedia.org/wiki/Homogeneity) of variances and covariances in [MANOVA](https://en.wikipedia.org/wiki/MANOVA) and [linear discriminant analysis](wikipedia://en/1470657). It is named after [George E. P. Box](wikipedia://en/2741338), who first discussed the test in 1949. The test uses a [chi-squared](wikipedia://en/113424) approximation.

:::

Box's *M* test is susceptible to errors if the data does not meet model assumptions or if the sample size is too large or small.[^o3] Box's *M* test is especially prone to error if the data does not meet the assumption of [multivariate normality](https://en.wikipedia.org/wiki/Multivariate_normal).[^o4]
