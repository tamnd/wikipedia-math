# Clique cover

*Image: Clique cover.svg.* A graph with a **minimum clique cover** colored

::: {#o1 .subject cue=lead name="Clique cover"}

In [graph theory](wikipedia://en/12401), a **clique cover** or **partition into cliques** of a given [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is a collection of [cliques](wikipedia://en/524466) that cover the whole graph. Generally, this means all vertices must be covered, and the term [clique edge cover](https://en.wikipedia.org/wiki/Clique_edge_cover) is used when all edges must be covered. A **minimum clique cover** is a clique cover that uses as few cliques as possible. The minimum $k$ for which a clique cover exists is called the **clique cover number** of the given graph.

:::

## Relation to coloring {#Relation_to_coloring}

A clique cover of a graph $G$ may be seen as a [graph coloring](wikipedia://en/426743) of the [complement graph](wikipedia://en/1175649) of $G$, the graph on the same vertex set that has edges between non-adjacent vertices of $G$. Like clique covers, graph colorings are partitions of the set of vertices, but into subsets with no adjacencies ([independent sets](wikipedia://en/524501)) rather than cliques. A subset of vertices is a clique in $G$ if and only if it is an independent set in the complement of $G$, so a partition of the vertices of $G$ is a clique cover of $G$ if and only if it is a coloring of the complement of $G$.

## Computational complexity {#Computational_complexity}

The **clique cover problem** in [computational complexity theory](wikipedia://en/7543) is the [algorithmic](wikipedia://en/775) problem of finding a minimum clique cover, or (rephrased as a [decision problem](wikipedia://en/8336)) finding a clique cover whose number of cliques is below a given threshold. Finding a minimum clique cover is [NP-hard](https://en.wikipedia.org/wiki/NP-hard), and its [decision version](wikipedia://en/8336) is [NP-complete](https://en.wikipedia.org/wiki/NP-complete). It was one of [Richard Karp's original 21 problems](wikipedia://en/2012564) shown NP-complete in his 1972 paper "Reducibility Among Combinatorial Problems".[^o4]

The equivalence between clique covers and coloring is a [reduction](wikipedia://en/848067) that can be used to prove the NP-completeness of the clique cover problem from the known NP-completeness of graph coloring.[^o5]

## In special classes of graphs {#In_special_classes_of_graphs}

[Perfect graphs](wikipedia://en/670531) are defined as graphs in which, for every [induced subgraph](wikipedia://en/1655188), the chromatic number (minimum number of colors in a coloring) equals the size of the [maximum clique](https://en.wikipedia.org/wiki/Maximum_clique). According to the [weak perfect graph theorem](wikipedia://en/670602), the complement of a perfect graph is also perfect. Therefore, the perfect graphs are also the graphs in which, for every induced subgraph, the clique cover number equals the size of the [maximum independent set](https://en.wikipedia.org/wiki/Maximum_independent_set). It is possible to compute the clique cover number in perfect graphs in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).

Another class of graphs in which the minimum clique cover can be found in polynomial time are the [triangle-free graphs](wikipedia://en/7667996). In these graphs, every clique cover consists of a [matching](wikipedia://en/581797) (a set of disjoint pairs of adjacent vertices) together with [singleton sets](https://en.wikipedia.org/wiki/Singleton_set) for the remaining unmatched vertices. The number of cliques equals the number of vertices minus the number of matched pairs. Therefore, in triangle-free graphs, the minimum clique cover can be found by using an algorithm for [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching).

The optimum partition into cliques can also be found in polynomial time for graphs of bounded [clique-width](wikipedia://en/16795502).[^o7] These include, among other graphs, the [cographs](wikipedia://en/1175666) and [distance-hereditary graphs](wikipedia://en/17315337), which are also classes of perfect graphs.

The clique cover problem remains NP-complete on some other special classes of graphs, including the [cubic](wikipedia://en/980508) [planar graphs](wikipedia://en/24314)[^o11] and [unit disk graphs](wikipedia://en/3686677).[^o8]

## Approximation {#Approximation}

The same [hardness of approximation](wikipedia://en/20677277) results that are known for graph coloring also applies to clique cover. Therefore, unless [P = NP](https://en.wikipedia.org/wiki/P_=_NP), there can be no [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) [approximation algorithm](wikipedia://en/563105) for any $\varepsilon > 0$ that, on $n$-vertex graphs, achieves an [approximation ratio](https://en.wikipedia.org/wiki/Approximation_ratio) better than $n^{1 - \varepsilon}$.[^o10]

In graphs where every vertex has [at most three neighbors](wikipedia://en/1374448), the clique cover remains NP-hard, and there is a constant $\rho > 1$ such that it is NP-hard to approximate with [approximation ratio](https://en.wikipedia.org/wiki/Approximation_ratio) $\rho$ or better. Nevertheless, in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) it is possible to find an approximation with a ratio of 5/4. That is, this approximation algorithm finds a clique cover whose number of cliques is no more than 5/4 times the optimum.[^o11]

[Baker's technique](https://en.wikipedia.org/wiki/Baker's_technique) can be used to provide a [polynomial-time approximation scheme](wikipedia://en/666431) for the problem on planar graphs.[^o12]

## Related problems {#Related_problems}

The related [clique edge cover](https://en.wikipedia.org/wiki/Clique_edge_cover) problem concerns partitioning the edges of a graph, rather than the vertices, into subgraphs induced by cliques. It is also NP-complete.[^o14]
