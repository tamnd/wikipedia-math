# Parry–Daniels map

::: {#o1 .subject cue=lead name="Parry–Daniels map"}

In [mathematics](wikipedia://en/18831), the **Parry–Daniels map** is a [function](wikipedia://en/185427) studied in the context of [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems). Typical questions concern the existence of an [invariant](wikipedia://en/7635201) or [ergodic measure](https://en.wikipedia.org/wiki/Ergodic_%28adjective%29) for the map.[^o2]

:::

It is named after the [English](https://en.wikipedia.org/wiki/England) [mathematician](wikipedia://en/18902) [Bill Parry](wikipedia://en/7618438)[^o3] and the [British](https://en.wikipedia.org/wiki/UK) [statistician](wikipedia://en/48661) [Henry Daniels](https://en.wikipedia.org/wiki/Henry_Daniels_%28statistician%29),[^o4] who independently studied the map in papers published in 1962.

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given an [integer](wikipedia://en/14563) *n* ≥ 1, let Σ denote the *n*-[dimensional](wikipedia://en/8398) [simplex](wikipedia://en/39781) in **R**<sup>*n*+1</sup> given by

$$\Sigma := \{ x = (x_0, x_1, \dots, x_n) \in \mathbb{R}^{n + 1} | 0 \leq x_i \leq 1 \mbox{ for each } i \mbox{ and } x_0 + x_1 + \dots + x_n = 1 \}.$$

Let *π* be a [permutation](wikipedia://en/44027) such that

$$x_{\pi(0)} \leq x_{\pi (1)} \leq \dots \leq x_{\pi (n)}.$$

Then the **Parry–Daniels map**

$$T_{\pi} : \Sigma \to \Sigma$$

is defined by

$$T_\pi (x_0, x_1, \dots, x_n) := \left( \frac{x_{\pi (0)}}{x_{\pi (n)}} , \frac{x_{\pi (1)} - x_{\pi (0)}}{x_{\pi (n)}}, \dots, \frac{x_{\pi (n)} - x_{\pi (n - 1)}}{x_{\pi (n)}} \right).$$

:::
