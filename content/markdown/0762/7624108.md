# Standard linear solid model

::: {#o1 .subject cue=lead name="Standard linear solid model"}

The **standard linear solid (SLS)**, also known as the **Zener model** after [Clarence Zener](https://en.wikipedia.org/wiki/Clarence_Zener),[^o2] is a method of modeling the behavior of a [viscoelastic](wikipedia://en/711288) material using a [linear combination](wikipedia://en/55632) of springs and dashpots to represent elastic and viscous components, respectively. Often, the simpler [Maxwell model](https://en.wikipedia.org/wiki/Maxwell_material) and the [Kelvin–Voigt model](wikipedia://en/2061865) are used. These models often prove insufficient, however; the Maxwell model does not describe creep or recovery, and the Kelvin–Voigt model does not describe [stress relaxation](wikipedia://en/5202789). SLS is the simplest model that predicts both phenomena.

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Materials undergoing strain are often modeled with mechanical components, such as [springs](https://en.wikipedia.org/wiki/Spring_%28device%29#Physics) (restorative force component) and [dashpots](https://en.wikipedia.org/wiki/Dashpots) (damping component).

Connecting a spring and damper in series yields a model of a [Maxwell material](https://en.wikipedia.org/wiki/Maxwell_material) while connecting a spring and damper in parallel yields a model of a [Kelvin–Voigt material](wikipedia://en/2061865).[^o5] In contrast to the Maxwell and Kelvin–Voigt models, the SLS is slightly more complex, involving elements both in series and in parallel. Springs, which represent the elastic component of a viscoelastic material, obey [Hooke's law](https://en.wikipedia.org/wiki/Hooke's_law):

$$\sigma_{s} = E \varepsilon$$

where σ is the applied stress, E is the [Young's modulus](https://en.wikipedia.org/wiki/Young's_modulus) of the material, and ε is the strain. The spring represents the elastic component of the model's response.[^o5]

Dashpots represent the viscous component of a viscoelastic material. In these elements, the applied stress varies with the time rate of change of the strain:

$$\sigma_D = \eta \frac {d\varepsilon} {dt}$$

where η is [viscosity](wikipedia://en/18963754) of the dashpot component.

:::

## Solving the model {#Solving_the_model}

In order to model this system, the following physical relations must be realized:

For parallel components: $\sigma_{tot} = \sigma_1 + \sigma_2$, and $\varepsilon_{tot} = \varepsilon_1 = \varepsilon_2$.[^o5]

For series components: $\sigma_{tot} = \sigma_1 = \sigma_2$, and $\varepsilon_{tot} = \varepsilon_1 + \varepsilon_2$.[^o5]

### Maxwell representation {#Maxwell_representation}

*Image: SLS.svg.* Standard Linear Solid model, Maxwell representation

This model consists of two systems in parallel. The first, referred to as the Maxwell arm, contains a spring ($E = E_2$) and dashpot (viscosity $\eta$) in series.[^o5] The other system contains only a spring ($E = E_1$).

These relationships help relate the various stresses and strains in the overall system and the Maxwell arm:

**$\sigma_{tot} = \sigma_{m} + \sigma_{S_1}$**

**$\varepsilon_{tot} = \varepsilon_{m} = \varepsilon_{S_1}$**

**$\sigma_{m} = \sigma_{D} = \sigma_{S_2}$**

**$\varepsilon_{m} = \varepsilon_{D} + \varepsilon_{S_2}$**

where the subscripts $m$, $D$, $S_1$ and $S_2$ refer to Maxwell, dashpot, spring one and spring two, respectively.

Using these relationships, their time derivatives, and the above stress-strain relationships for the spring and dashpot elements, the system can be modeled as follows:

$\frac {d\varepsilon(t)} {dt} = \frac { \frac {E_2} {\eta} \left ( \frac {\eta} {E_2}\frac {d\sigma(t)} {dt} + \sigma(t) - E_1 \varepsilon(t) \right )}{E_1 + E_2}$ [^o8]

The equation can also be expressed as:

$$\sigma(t) + \frac {\eta} {E_2} \frac{d\sigma(t)}{dt} = E_1 \varepsilon(t) + \frac {\eta (E_1 + E_2)} {E_2} \frac{d\varepsilon(t)}{dt}$$

or, in dot notation:

$$\sigma + \frac {\eta} {E_2} \dot {\sigma} = E_1 \varepsilon + \frac {\eta (E_1 + E_2)} {E_2} \dot {\varepsilon}$$

The [relaxation time](https://en.wikipedia.org/wiki/Relaxation_time), $\tau$, is different for each material and is equal to

$$\tau = \frac {\eta} {E_2}$$

### Kelvin-Voigt representation {#Kelvin-Voigt_representation}

*Image: SLS2.svg.* Standard Linear Solid model, Kelvin representation

This model consists of two systems in series. The first, referred to as the Kelvin arm, contains a spring ($E = E_2$) and dashpot (viscosity $\eta$) in parallel. The other system contains only a spring ($E = E_1$).

These relationships help relate the various stresses and strains in the overall system and the Kelvin arm:

**$\sigma_{tot} = \sigma_{k} = \sigma_{S_1}$**

**$\varepsilon_{tot} = \varepsilon_{k} + \varepsilon_{S_1}$**

**$\sigma_{k} = \sigma_{D} + \sigma_{S_2}$**

**$\varepsilon_{k} = \varepsilon_{D} = \varepsilon_{S_2}$**

where the subscripts $k$, $D$, $S_1$, and $S_2$ refer to Kelvin, dashpot, spring one, and spring two, respectively.

Using these relationships, their time derivatives, and the above stress-strain relationships for the spring and dashpot elements, the system can be modeled as follows:

$$\sigma(t) + \frac{\eta}{E_1+E_2}\frac{d\sigma(t)}{dt} = \frac{E_1E_2}{E_1+E_2}\varepsilon(t) + \frac{E_1\eta}{E_1+E_2} \frac{d\varepsilon(t)}{dt}$$

or, in dot notation:

$$\sigma + \frac{\eta}{E_1+E_2} \dot \sigma = \frac{E_1E_2}{E_1+E_2}\varepsilon + \frac{E_1\eta}{E_1+E_2} \dot \varepsilon$$

The [retardation time](https://en.wikipedia.org/wiki/Retardation_time), $\bar{\tau}$, is different for each material and is equal to

$$\bar{\tau} = \frac {\eta} {E_2}$$

## Model characteristics {#Model_characteristics}

*Image: Comparison three four element models.svg.* Comparison of creep and stress relaxation for three and four element models

The standard linear solid model combines aspects of the Maxwell and Kelvin–Voigt models to accurately describe the overall behavior of a system under a given set of loading conditions. The behavior of a material applied to an instantaneous stress is shown as having an instantaneous component of the response. Instantaneous release of a stress also results in a discontinuous decrease in strain, as is expected. The shape of the time-dependent strain curve is true to the type of equation that characterizes the behavior of the model over time, depending upon how the model is loaded.

Although this model can be used to accurately predict the general shape of the strain curve, as well as behavior for long time and instantaneous loads, the model lacks the ability to accurately model material systems numerically.

The fluid model equivalent to the standard linear solid model includes a dashpot in series with the Kelvin–Voigt model and is called the Jeffreys model.[^o11]
