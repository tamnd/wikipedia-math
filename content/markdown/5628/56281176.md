# Pfaffian orientation

*Image: Pfaffian orientation revised.svg.* Left: The 3 cycles of the graph, shown red, along with a matching of the remaining graph after removing the cycle. The cycles are "even" because they have an even number of edges, and are "central" because a [perfect matching](wikipedia://en/44031) is able to be created with the remaining graph (cycle 3 leaves no vertices, automatically filling this criterion). Right: A Pfaffian Orientation of the graph on the left, where the edges of the 3 cycles from the right have an odd number going in each direction around the cycle. The red and blue arrows are clockwise and counter-clockwise respectively for all cycles, and the black arrow is counter-clockwise relative to cycle 1 and clockwise relative to cycle 2.

::: {#o1 .subject cue=lead name="Pfaffian orientation"}

In [graph theory](wikipedia://en/12401), a **Pfaffian orientation** of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) assigns a direction to each edge, so that certain cycles (the "even central cycles") have an odd number of edges in each direction. When a graph has a Pfaffian orientation, the orientation can be used to count the [perfect matchings](wikipedia://en/44031) of the graph. This is the main idea behind the [FKT algorithm](wikipedia://en/30159370) for counting perfect matchings in [planar graphs](wikipedia://en/24314), which always have Pfaffian orientations. More generally, every graph that does not have the [utility graph](https://en.wikipedia.org/wiki/Utility_graph) $K_{3,3}$ as a [graph minor](wikipedia://en/353042) has a Pfaffian orientation, but $K_{3,3}$ does not, nor do infinitely many other minimal non-Pfaffian graphs.

:::

## Definitions {#Definitions}

A **Pfaffian orientation** of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is an [orientation](wikipedia://en/36619818) in which every even central cycle is oddly oriented. The terms of this definition have the following meanings:

- An orientation assigns a direction to each edge of the graph.
- A [cycle](wikipedia://en/168609) $C$ is called even if it contains an even number of edges.
- A cycle $C$ is central if the subgraph of $G$ formed by removing all the vertices of $C$ has a [perfect matching](wikipedia://en/44031); central cycles are also sometimes called alternating circuits.
- Cycle $C$ is oddly oriented if each of the two orientations of $C$ is consistent with an odd number of edges in the orientation.

:::

## Application to counting matchings {#Application_to_counting_matchings}

Pfaffian orientations have been studied in connection with the [FKT algorithm](wikipedia://en/30159370) for counting the number of perfect matchings in a given graph. In this algorithm, the orientations of the edges are used to assign the values $\pm 1$ to the variables in the [Tutte matrix](wikipedia://en/18305460) of the graph. Then, the [Pfaffian](wikipedia://en/530060) of this matrix (the [square root](wikipedia://en/29208) of its [determinant](wikipedia://en/8468)) gives the number of perfect matchings. Each perfect matching contributes $\pm 1$ to the Pfaffian regardless of which orientation is used; the choice of a Pfaffian orientation ensures that these contributions all have the same sign as each other, so that none of them cancel. This result stands in contrast to the much higher computational complexity of counting matchings in arbitrary graphs.

## Pfaffian graphs {#Pfaffian_graphs}

A graph is said to be Pfaffian if it has a Pfaffian orientation. Every [planar graph](wikipedia://en/24314) is Pfaffian. An orientation in which each face of a planar graph has an odd number of clockwise-oriented edges is automatically Pfaffian. Such an orientation can be found by starting with an arbitrary orientation of a [spanning tree](wikipedia://en/455770) of the graph. The remaining edges, not in this tree, form a spanning tree of the [dual graph](wikipedia://en/2536864), and their orientations can be chosen according to a bottom-up traversal of the dual spanning tree in order to ensure that each face of the original graph has an odd number of clockwise edges.

More generally, every $K_{3,3}$-minor-free graph has a Pfaffian orientation. These are the graphs that do not have the [utility graph](https://en.wikipedia.org/wiki/Utility_graph) $K_{3,3}$ (which is not Pfaffian) as a [graph minor](wikipedia://en/353042). By [Wagner's theorem](wikipedia://en/3126130), the $K_{3,3}$-minor-free graphs are formed by gluing together copies of planar graphs and the [complete graph](wikipedia://en/85816) $K_5$ along shared edges. The same gluing structure can be used to obtain a Pfaffian orientation for these graphs.

Along with $K_{3,3}$, there are infinitely many minimal non-Pfaffian graphs. For [bipartite graphs](wikipedia://en/244431), it is possible to determine whether a Pfaffian orientation exists, and if so find one, in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).
