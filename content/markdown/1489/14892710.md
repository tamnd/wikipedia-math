# Product type

::: {#o1 .subject cue=lead name="Product type"}

In [programming languages](wikipedia://en/23015) and [type theory](wikipedia://en/40282), a **product** of *types* is another, compounded, type in a structure. The "operands" of the product are [types](https://en.wikipedia.org/wiki/Data_type), and the structure of a product type is determined by the fixed order of the operands in the product. An instance of a product type retains the fixed order, but otherwise may contain all possible instances of its [primitive data types](https://en.wikipedia.org/wiki/Primitive_data_type). The expression of an instance of a product type will be a [tuple](wikipedia://en/132729), and is called a "tuple type" of expression. A product of types is a [direct product](wikipedia://en/8887) of two or more types.

:::

If there are only two component types, it can be called a "pair type". For example, if two component types $A$ and $B$ are the set of all possible values of that type, the product type written $A \times B$ contains elements that are pairs $(a, b)$, where $a$ and $b$ are instances of $A$ and $B$ respectively. The pair type is a special case of the [dependent pair type](wikipedia://en/1949487#Dependent_pair_type), where the type $B$ may depend on the instance picked from $A$.

In many languages, product types take the form of a [record](https://en.wikipedia.org/wiki/Record_%28computer_science%29) type, for which the components of a tuple can be accessed by [label](https://en.wikipedia.org/wiki/Identifier). In languages that have [algebraic data types](https://en.wikipedia.org/wiki/Algebraic_data_type), as in most [functional programming](https://en.wikipedia.org/wiki/Functional_programming) languages, algebraic data types with one constructor are [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to a product type.

In the [Curry–Howard correspondence](wikipedia://en/254299), product types are associated with [logical conjunction](wikipedia://en/18152) (AND) in [logic](https://en.wikipedia.org/wiki/Formal_logic).

The notion directly extends to the product of an arbitrary finite number of types (an $n$-ary product type), and in this case, it characterizes the expressions that behave as tuples of expressions of the corresponding types. A degenerate form of product type is the [unit type](wikipedia://en/3646268): it is the [product of no types](wikipedia://en/181289).

In [call-by-value](wikipedia://en/2977119#Call_by_value) programming languages, a product type can be interpreted as a set of pairs whose first component is a [value](https://en.wikipedia.org/wiki/Value_%28computer_science%29) in the first type and whose second component is a value in the second type. In short, it is a [cartesian product](wikipedia://en/24104095) and it corresponds to a [product](wikipedia://en/237868) in the category of types.

Most [functional programming](https://en.wikipedia.org/wiki/Functional_programming) languages have a [primitive notion](wikipedia://en/23706) of product type. For instance, the product $T_1 \times T_2 \times ... \times T_n$ is written `T<sub>1</sub> * T<sub>2</sub> * ... * T<sub>n</sub>` in [ML](https://en.wikipedia.org/wiki/ML_%28programming_language%29) and `(T<sub>1</sub>, T<sub>2</sub>, ..., T<sub>n</sub>)` in [Haskell](https://en.wikipedia.org/wiki/Haskell_%28programming_language%29). In both these languages, tuples are written `(v<sub>1</sub>, v<sub>2</sub>, ..., v<sub>n</sub>)` and the components of a tuple are extracted by [pattern-matching](https://en.wikipedia.org/wiki/Pattern-matching). Additionally, many functional programming languages provide more general [algebraic data types](https://en.wikipedia.org/wiki/Algebraic_data_type), which extend both product and [sum types](https://en.wikipedia.org/wiki/Sum_type). Product types are the [dual](https://en.wikipedia.org/wiki/Dual_%28mathematics%29) of sum types.

## Product types in programming languages {#Product_types_in_programming_languages}

- [C++](https://en.wikipedia.org/wiki/C++) defines the class `std::tuple` (expressed `tuple<Ts...>` using [variadic templates](https://en.wikipedia.org/wiki/Variadic_template)),[^o3] and for the specific case of two elements defines `std::pair` (expressed `pair<T, U>`).[^o4] `std::tuple` can be empty (`tuple<>`).
- [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29)/[.NET Framework](https://en.wikipedia.org/wiki/.NET_Framework) defines the class `System.Tuple`. There are specific instantiations for 1 to 8 elements. For the specific case of two elements (a pair), it uses `Tuple<T1, T2>`.[^o5] In order to create a tuple with nine or more components, the final parameter `TRest` of `Tuple<T1, T2, T3, T4, T5, T6, T7, TRest>` is supplied as another tuple.[^o6] For iterating over collections like dictionary types, the class `System.Collections.Generic.KeyValuePair` (expressed `KeyValuePair<TKey, TValue>`) is provided.[^o7]
- [Go](https://en.wikipedia.org/wiki/Go_%28programming_language%29) does not have a tuple type, but can express multiple return values in a function as a sort of tuple.[^o8]
- [Haskell](https://en.wikipedia.org/wiki/Haskell) has a data type `Data.Tuple`.[^o9]
- [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) does not have a general tuple type, but [JavaFX](https://en.wikipedia.org/wiki/JavaFX) has a type `javafx.util.Pair` (expressed `Pair<K, V>`).[^o10] For iterating over associative containers such as `java.util.Map`, a pair in the map is expressed as `Map.Entry<K, V>`.[^o11]
- [Kotlin](https://en.wikipedia.org/wiki/Kotlin_%28programming_language%29) does not have a general tuple type, but has classes `kotlin.Pair` (expressed `Pair<A, B>`)[^o12] and `kotlin.Triple` (expressed `Triple<A, B, C>`).[^o13]
- [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) has a `tuple` collection which can be annotated as `typing.Tuple` (expressed `Tuple[T<sub>1</sub>, T<sub>2</sub>, ..., T<sub>N</sub>]`).[^o14]
- [Rust](https://en.wikipedia.org/wiki/Rust_%28programming_language%29) defines the primitive tuple type, expressed as `(T<sub>1</sub>, T<sub>2</sub>, ..., T<sub>N</sub>)`, and a pair is just `(T, U)`.[^o15]
- [Scala](wikipedia://en/3254510) defines the class `scala.Tuple`,[^o16] which supports between 2 and 22 objects as `scala.Tuple2` (expressed as `Tuple2[A, B]`)[^o17] to `scala.Tuple22` (expressed as `Tuple22[A, B, ..., V]`).[^o18]
- [Swift](https://en.wikipedia.org/wiki/Swift_%28programming_language%29) expresses tuples as `(T<sub>1</sub>, T<sub>2</sub>, ..., T<sub>N</sub>)`.[^o19]
