# Dense submodule

::: {#o1 .subject cue=lead name="Dense submodule"}

In [abstract algebra](wikipedia://en/19616384), specifically in [module theory](https://en.wikipedia.org/wiki/Module_theory), a **dense submodule** of a [module](wikipedia://en/276410) is a refinement of the notion of an [essential submodule](https://en.wikipedia.org/wiki/Essential_submodule). If *N* is a dense submodule of *M*, it may alternatively be said that "*N* ⊆ *M* is a **rational extension**". Dense submodules are connected with rings of quotients in [noncommutative](wikipedia://en/24062516) ring theory. Most of the results appearing here were first established in (Johnson 1951), (Utumi 1956) and (Findlay Lambek 1958).

:::

It should be noticed that this terminology is different from the notion of a [dense subset](https://en.wikipedia.org/wiki/Dense_subset) in [general topology](wikipedia://en/178649). No topology is needed to define a dense submodule, and a dense submodule may or may not be topologically dense in a [module with topology](wikipedia://en/1616141).

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

This article modifies [exposition](https://en.wikipedia.org/wiki/Exposition_%28literary_technique%29) appearing in (Storrer 1972) and (Lam 1999, 272). Let *R* be a ring, and *M* be a right *R*-module with submodule *N*. For an element *y* of *M*, define

$$y^{-1}N = \{r\in R \mid yr\in N \}.$$

Note that the expression *y*<sup>−1</sup> is only formal since it is not meaningful to speak of the module element *y* being [invertible](https://en.wikipedia.org/wiki/Invertible), but the notation helps to suggest that *y*⋅(*y*<sup>−1</sup>*N*) ⊆ *N*. The set *y* <sup>−1</sup>*N* is always a right [ideal](wikipedia://en/25977) of *R*.

A submodule *N* of *M* is said to be a **dense submodule** if, for all *x* and *y* in *M* with *x* ≠ 0, there exists an *r* in *R* such that *xr* ≠ 0 and *yr* is in *N*. In other words, using the introduced notation,

$$x(y^{-1}N) \neq \{0\}.$$

In this case, the relationship is denoted by

$$N\subseteq_d M.$$

Another equivalent definition is [homological](wikipedia://en/139410) in nature: *N* is dense in *M* if and only if

$$\mathrm{Hom}_R (M/N,E(M)) = \{0\},$$

where *E*(*M*) is the [injective hull](wikipedia://en/665821) of *M*.

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- It can be shown that *N* is an essential submodule of *M* if and only if for all *y* ≠ 0 in *M*, the set *y*⋅(*y* <sup>−1</sup>*N*) ≠ {0}. Clearly then, every dense submodule is an essential submodule.
- If *M* is a [nonsingular module](https://en.wikipedia.org/wiki/Nonsingular_module), then *N* is dense in *M* if and only if it is essential in *M*.
- A ring is a right [nonsingular ring](https://en.wikipedia.org/wiki/Nonsingular_ring) if and only if its essential right ideals are all dense right ideals.
- If *N* and *N'* are dense submodules of *M*, then so is *N* ∩ *N'*.
- If *N* is dense and *N* ⊆ *K* ⊆ *M*, then *K* is also dense.
- If *B* is a dense right ideal in *R*, then so is *y*<sup>−1</sup>*B* for any *y* in *R*.

:::

::: {#o12 .example cue=heading name="Examples"}

## Examples {#Examples}

- If *x* is a non-zerodivisor in the [center](wikipedia://en/53796787) of *R*, then *xR* is a dense right ideal of *R*.
- If *I* is a two-sided ideal of *R*, *I* is dense as a right ideal if and only if the *left* [annihilator](wikipedia://en/328684) of *I* is zero, that is, $\ell\cdot \mathrm{Ann}(I)=\{0\}\,$. In particular in [commutative rings](wikipedia://en/61346), the dense ideals are precisely the ideals which are [faithful modules](https://en.wikipedia.org/wiki/Faithful_module).

:::

::: {#o14 .application cue=heading name="Applications"}

## Applications {#Applications}

### Rational hull of a module {#Rational_hull_of_a_module}

Every right *R*-module *M* has a maximal essential extension *E*(*M*) which is its [injective hull](wikipedia://en/665821). The analogous construction using a maximal dense extension results in the **rational hull** *Ẽ*(*M*) which is a submodule of *E*(*M*). When a module has no proper rational extension, so that *Ẽ*(*M*) = *M*, the module is said to be **rationally complete**. If *R* is right nonsingular, then of course *Ẽ*(*M*) = *E*(*M*).

The rational hull is readily identified within the injective hull. Let *S*=End<sub>*R*</sub>(*E*(*M*)) be the [endomorphism ring](wikipedia://en/59623) of the injective hull. Then an element *x* of the injective hull is in the rational hull if and only if *x* is sent to zero by all maps in *S* which are zero on *M*. In symbols,

$$\tilde{E}(M) = \{x\in E(M) \mid \forall f\in S, f(M)=0 \implies f(x)=0\}\,$$

In general, there may be maps in *S* which are zero on *M* and yet are nonzero for some *x* not in *M*, and such an *x* would not be in the rational hull.

::: {#o17 .pointer-item cue=pointer name="Maximal ring of quotients"}

### Maximal right ring of quotients {#Maximal_right_ring_of_quotients}

The maximal right ring of quotients can be described in two ways in connection with dense right ideals of *R*.

- In one method, *Ẽ*(*R*) is shown to be module-[isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to a certain endomorphism ring, and the ring structure is taken across this isomorphism to imbue *Ẽ*(*R*) with a ring structure, that of the maximal right ring of quotients. (Lam 1999, 366)
- In a second method, the maximal right ring of quotients is identified with a set of [equivalence classes](wikipedia://en/9260) of homomorphisms from dense right ideals of *R* into *R*. The equivalence relation says that two functions are equivalent if they agree on a dense right ideal of *R*. (Lam 1999, 370)
