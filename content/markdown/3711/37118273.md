# Octic reciprocity

::: {#o1 .subject cue=lead name="Octic reciprocity"}

In [number theory](wikipedia://en/21527), **octic reciprocity** is a [reciprocity law](wikipedia://en/247622) relating the residues of 8th powers [modulo](wikipedia://en/20087) [primes](wikipedia://en/23666), analogous to the [law of quadratic reciprocity](https://en.wikipedia.org/wiki/Law_of_quadratic_reciprocity), [cubic reciprocity](wikipedia://en/6299003), and [quartic reciprocity](wikipedia://en/20131133).

:::

There is a [rational reciprocity law](wikipedia://en/33669897) for 8th powers, due to Williams. Define the symbol $\left(\frac xp\right)_k$ to be +1 if *x* is a *k*-th power modulo the prime *p* and -1 otherwise. Let *p* and *q* be distinct primes congruent to 1 modulo 8, such that $\left(\frac pq\right)_4 = \left(\frac qp\right)_4 = +1 .$ Let *p* = *a*<sup>2</sup> + *b*<sup>2</sup> = *c*<sup>2</sup> + 2*d*<sup>2</sup> and *q* = *A*<sup>2</sup> + *B*<sup>2</sup> = *C*<sup>2</sup> + 2*D*<sup>2</sup>, with *aA* odd. Then

$$\left(\frac pq\right)_8 \left(\frac qp\right)_8 = \left(\frac{aB-bA}q\right)_4 \left(\frac{cD-dC}q\right)_2 \ .$$
