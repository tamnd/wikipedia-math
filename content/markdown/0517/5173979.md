# Computable ordinal

::: {#o1 .subject cue=lead name="Computable ordinal"}

In [mathematics](wikipedia://en/18831), specifically [computability](wikipedia://en/155414) and [set theory](wikipedia://en/27553), a **computable** (or **recursive**) ordinal is an [ordinal number](wikipedia://en/26547932) that can be represented as a [computable](wikipedia://en/332264) [well-ordering](wikipedia://en/33456) of [natural numbers](wikipedia://en/21474).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

An ordinal $\alpha$ is computable if there exists a [computable](wikipedia://en/332264) [well-ordering](wikipedia://en/33456) $\prec$ of a computable [subset](wikipedia://en/27631) $S$ of the natural numbers having the [order type](wikipedia://en/4499021) $\alpha$. This means that given any $x \in \mathbb{N}$ it is [decidable](wikipedia://en/23290990) whether $x \in S$, and given any $x, y \in S$ it is decidable whether $x \prec y$. Alternatively, this condition can be characterized with a single [Turing machine](wikipedia://en/30403) that decides whether $x \in S \land y \in S \land x \preceq y$ for any $x, y \in \mathbb{N}$.[^n1]

Another equivalent definition states that $\alpha$ is computable if it either is finite or is the order type of a computable well-ordering of all natural numbers.[^n2] This equivalence holds because, if $S$ is infinite and computable, then one can compute a [bijection](wikipedia://en/3942) $f:\mathbb{N}\to S$ by letting $f(n)$ be the $n$th element of $S$ in the usual ordering of the natural numbers; the search always halts because $S$ is infinite. If $\langle S,\prec\rangle$ is a computable well-ordering with order type $\alpha$, then defining $x \prec_f y$ iff $f(x) \prec f(y)$ gives a computable well-ordering $\langle \mathbb{N},\prec_f\rangle$ with the same order type.

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

All computable ordinals are by definition [countable](https://en.wikipedia.org/wiki/Countable). Conversely, for many countable ordinals, the "natural" witnesses for countability are also witnesses for computability. For example, the natural ordering $<$ of all natural numbers has order type [$\omega$](https://en.wikipedia.org/wiki/Omega_%28ordinal%29). Since there exists a [Turing machine](wikipedia://en/30403) that decides $x < y$, this means that $\omega$ is a computable ordinal.

As another example, the following is the "canonical" construction of a well-ordering $\prec$ of all natural numbers with order type $\omega + \omega$:

$$\begin{matrix} 0 & 2 & 4 & 6 & 8 & \dots & 1 & 3 & 5 & 7 & 9 & \dots \end{matrix}$$

An algorithm that decides $x \prec y$ can be as follows: Return true if $x$ is even and $y$ is odd, false if $x$ is odd and $y$ is even, and otherwise return $x < y$. Therefore $\omega + \omega$ is also computable. In fact, with similar constructions, it can be shown that the [successor](wikipedia://en/375256) of a computable ordinal and the [sum, product, and power](wikipedia://en/2139226) of a pair of computable ordinals are all computable.

The [set](wikipedia://en/26691) of all computable ordinals is [closed](wikipedia://en/293802) downwards, i.e., if $\alpha$ is computable and $\beta < \alpha$, then $\beta$ is computable too.[^n2] This is because any well-ordering $\langle S, \prec \rangle$ with order type $\alpha$ has an initial segment $\langle S', \prec \rangle$ with order type $\beta$, where $S' = \{ x \in S \mid x \prec x_\beta\}$ (for some fixed $x_\beta \in S$) is a computable subset of $S$ if $\prec$ is computable.

:::

## Church–Kleene ordinal {#Church–Kleene_ordinal}

The [supremum](https://en.wikipedia.org/wiki/Supremum) of all computable ordinals is called the [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Nonrecursive_ordinals), the first nonrecursive ordinal, and denoted by $\omega_1^{\mathsf{CK}}$.[^n3] The Church–Kleene ordinal is a [limit ordinal](wikipedia://en/373137). An ordinal is computable if and only if it is smaller than $\omega_1^{\mathsf{CK}}$.[^o11] Since there are only countably many computable binary relations, there are also only [countably](wikipedia://en/6026) many computable ordinals. Thus, $\omega_1^{\mathsf{CK}}$ is countable.

The computable ordinals are exactly the ordinals that have an [ordinal notation](wikipedia://en/6108552) in [Kleene's $\mathcal{O}$](wikipedia://en/16105044).[^n4]
