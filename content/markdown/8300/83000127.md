# Method of types

::: {#o1 .subject cue=lead name="Method of types"}

The **method of types** is a tool in [information theory](https://en.wikipedia.org/wiki/Information_Theory) and [large deviation theory](wikipedia://en/3772909) to analyze events from the perspective of the [empirical distribution](wikipedia://en/5647670).[^o2][^o3] It classifies events as [typical](wikipedia://en/248717) when the empirical distribution closely matches the true distribution.

:::

It has been used to prove results in [hypothesis testing](wikipedia://en/60531312), [channel coding](wikipedia://en/4237207),[^o3][^o4] and [universal source coding](wikipedia://en/2522009),[^o2][^o5] and it is used to prove [Sanov's theorem](wikipedia://en/31587409) in the finite support setting.[^o6][^o7] It is often used to simplify complex probability expressions into more natural expressions involving the [Kullback–Leibler divergence](wikipedia://en/1115052). The topic is considered a traditional method in information theory,[^o8][^o9] is usually covered in introductory courses on information theory,[^o4][^o5][^o10][^o11][^o12] and textbooks.[^o2][^o9][^o15][^o13]

It was popularized by [Imre Csiszár](wikipedia://en/13008077),[^o14] with the first formal treatment given in the book *Information Theory: Coding Theorems for Discrete Memoryless Systems*.[^o9][^o15]. Csiszár claimed that the technique was originally motivated by the large deviation bound described in Hoeffding's seminal paper on multinomial hypothesis testing.[^o16][^o3]

## Motivating example {#Motivating_example}

Given $n$ samples from $P$, a Bernoulli distribution with probability of success $p$, there are $2^n$ possible outcomes. We can group outcomes by the number of successful events, since every collection of $r$ successes has the same probability, $p^r(1-p)^{n-r}$, and there are $\binom{n}{r}$ such events. This can be summarized by considering the empirical distribution $P_r = \left(1 - \frac{r}{n}, \frac{r}{n}\right)$ and the type class $T(P_r) = \left\{X^n: \sum_{i=1}^n \mathbf{1}\{X_i = 1\} = r\right\}$. With some analysis, one finds that

$$\begin{aligned} \mathbb{P}\left[X^n\right] = p^r (1-p)^{n-r} \approx 2^{-n [H(P_r) + D(P_r\|P)]},\\ \mathbb{P}[T(P_r)] = \binom{n}{r} p^r(1-p)^{n-r} \approx 2^{-n D(P_r\|P)}, \end{aligned}$$

where $H(P_r), D(P_r\|P)$ denote the Shannon entropy and relative entropy. These approximations are most accurate when $n$ is taken to be large. A more accruate bound would be

$$(n+1)^{-2} 2^{-n D(P_r\|P)} \leq \mathbb{P}[T(P_r)] \leq 2^{-n D(P_r\|P)}.$$

For example, if we wanted to get a rough estimate of the probability of seeing $r=400$ heads in 1000 tosses of a fair coin, we could compute

$$\begin{aligned} D(P_r\|P) &= 0.6 \log \frac{0.6}{0.5} + 0.4 \log \frac{0.4}{0.5}\\ &\approx 0.02905 \end{aligned}$$

which gives us the (loose) approximation

$$2^{-1000 * 0.02905} \approx 1.799 * 10^{-9},$$

while the true value is

$$\binom{1000}{400}2^{-1000} \approx 4.6339 * 10^{-11}.$$

The figure below plots the exact probability and the upper and lower bounds.

The method of types generalizes the above example to multivariate distributions.

## Mathematical formulation {#Mathematical_formulation}

Let $\mathcal{X}$ be an alphabet with a finite number of elements. We start with a sequence of [i.i.d.](wikipedia://en/30876902) [random variables](wikipedia://en/25685) following a finite support distribution $Q$, $X^n = (X_1, \dots, X_n) \sim Q$, where $X_i\in \mathcal{X}$. For this sequence, let $N(k|X^n) = \sum_{i=1}^n \mathbf{1}\{X_i = k\}$ denote the number of occurrences of the symbol $k$ in the sequence $X^n$.

Denote the [empirical distribution](wikipedia://en/5647670) of the samples with $P_{X^n}$, so that $P_{X^n}[k] = \frac{N(k|X^n)}{n}$. The sets of sequences having empirical distribution $Q$, are called the type classes $T(Q) = \{X^n \in \mathcal{X}^n: P_{X^n} = Q\}$. To describe the set of all empirical distributions possible from $n$ samples, we use the symbol $\mathcal{P}_n$, which is a subset of the $d-1$ dimensional [probability simplex](wikipedia://en/39781) $\mathcal{P}$.

The method of types is built on top of the following results:[^o2]

- $$|\mathcal{P}_n| \leq (n+1)^{|\mathcal{X}|}$$
- $$Q[X^n] = 2^{-n \left[H(P_{X^n}) + D(P_{X^n}\|Q)\right]}$$
- $$\frac{1}{ (n+1)^{ |\mathcal{X}| } } 2^{n H(Q)} \leq |T(Q)| \leq 2^{n H(Q)}$$
- $$\frac{ 1 }{ (n+1)^{|\mathcal{X}| } } 2^{-nD(P\|Q)} \leq Q[T(P)] \leq 2^{-n D(P\|Q)}$$

Here $H(P)$ denotes the [Shannon entropy](wikipedia://en/15445), and $D(P\|Q)$ denotes the [Kullback–Leibler divergence](wikipedia://en/1115052). The last equation is derived from the previous ones by noticing that every element of $T(P)$ has the same probability when the samples are taken i.i.d.

These bounds are tight in terms of the error exponent,[^o19] but may give a loose bound in terms of $|\mathcal{X}|$ and the sub-exponential terms in $n$.[^o20]

::: {#o22 .application cue=heading name="Applications"}

## Applications {#Applications}

The method of types is used for [hypothesis testing](https://en.wikipedia.org/wiki/Hypothesis_testing) problems, when the underlying distributions have finite support[^o23][^o3][^o24], because it provides a tight bound on the error exponent. It was also used to prove some initial conditional limit theorems[^o25], which are special cases of the general class of limit theorems. The bound on the size of a type class can be used to prove tight bounds on the exact value on [binomial coefficients](wikipedia://en/4668#Bounds_and_asymptotic_formulas)[^o2]. It is also used to prove the [principle of maximum entropy](wikipedia://en/201718).[^o26]

:::
