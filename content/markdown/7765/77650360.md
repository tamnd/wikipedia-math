# Neural differential equation

::: {#o1 .subject cue=lead name="Neural differential equation"}

**Neural differential equations** are a class of models in [machine learning](wikipedia://en/233488) that combine [neural networks](https://en.wikipedia.org/wiki/Neural_networks) with the mathematical framework of [differential equations](https://en.wikipedia.org/wiki/Differential_equations).[^o2] These models provide an alternative approach to neural network design, particularly for systems that evolve over time or through continuous transformations.

:::

The most common type, a **neural ordinary differential equation (neural ODE)**, defines the evolution of a system's state using an [ordinary differential equation](wikipedia://en/32742753) whose dynamics are governed by a neural network:

$$\frac{\mathrm{d} \mathbf{h}(t)}{\mathrm{d} t}=f_\theta(\mathbf{h}(t), t).$$

In this formulation, the neural network parameters *θ* determine how the state changes at each point in time.[^o2] This approach contrasts with conventional [neural networks](https://en.wikipedia.org/wiki/Neural_networks), where information flows through discrete layers indexed by [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers). Neural ODEs instead use continuous layers indexed by [positive real numbers](wikipedia://en/47172571), where the function $h: \mathbb{R}_{\ge 0} \to \mathbb{R}$ represents the network's state at any given layer depth *t*.

Neural ODEs can be understood as [continuous-time](https://en.wikipedia.org/wiki/Continuous-time) [control systems](https://en.wikipedia.org/wiki/Control_system), where their ability to [interpolate](wikipedia://en/14569) data can be interpreted in terms of [controllability](wikipedia://en/100638).[^o3] They have found applications in [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis), generative modeling, and the study of complex [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems).

## Connection with residual neural networks {#Connection_with_residual_neural_networks}

Neural ODEs can be interpreted as a [residual neural network](wikipedia://en/55867424) with a continuum of layers rather than a discrete number of layers.[^o2] Applying the [Euler method](wikipedia://en/3011098) with a unit time step to a neural ODE yields the forward propagation equation of a residual neural network:

$$\mathbf{h}_{\ell+1} = f_{\theta}(\mathbf{h}_{\ell}, \ell) + \mathbf{h}_{\ell},$$

with ℓ being the ℓ-th layer of this residual neural network. While the forward propagation of a residual neural network is done by applying a sequence of transformations starting at the input layer, the forward propagation computation of a neural ODE is done by solving a differential equation. More precisely, the output $\mathbf{h}_{\text{out}}$ associated to the input $\mathbf{h}_{\text{in}}$ of the neural ODE is obtained by solving the [initial value problem](wikipedia://en/498383)

$$\frac{\mathrm{d} \mathbf{h}(t)}{\mathrm{d} t}=f_\theta(\mathbf{h}(t), t), \quad \mathbf{h}(0)=\mathbf{h}_{\text{in}},$$

and assigning the value $\mathbf{h}(T)$ to $\mathbf{h}_{\text{out}}$.

## Universal differential equations {#Universal_differential_equations}

In physics-informed contexts where additional information is known, neural ODEs can be combined with an existing first-principles model to build a physics-informed neural network model called universal differential equations (UDE).[^o6][^o7][^o8][^o9] For instance, an UDE version of the [Lotka-Volterra model](https://en.wikipedia.org/wiki/Lotka-Volterra_model) can be written as[^o10]

$$\begin{aligned} \frac{dx}{dt} &= \alpha x - \beta x y + f_{\theta}(x(t),y(t)), \\ \frac{dy}{dt} &= - \gamma y + \delta x y + g_{\theta}(x(t),y(t)), \end{aligned}$$

where the terms $f_{\theta}$ and $g_{\theta}$ are correction terms parametrized by neural networks.
