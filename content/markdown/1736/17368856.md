# Linear continuum

::: {#o1 .subject cue=lead name="Linear continuum"}

In the [mathematical](wikipedia://en/18831) field of [order theory](wikipedia://en/361924), a **continuum** or **linear continuum** is a generalization of the [real line](https://en.wikipedia.org/wiki/Real_line).

:::

Formally, a linear continuum is a [linearly ordered set](https://en.wikipedia.org/wiki/Linearly_ordered_set) *S* of more than one element that is [densely ordered](wikipedia://en/6320997), i.e., between any two distinct elements there is another (and hence infinitely many others), and [conditionally complete](wikipedia://en/549445), i.e., which "lacks gaps" in the sense that every [nonempty](wikipedia://en/9566) [subset](wikipedia://en/27631) with an [upper bound](https://en.wikipedia.org/wiki/Upper_bound) has a [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) in the set. More symbolically:

*S* has the [least upper bound property](https://en.wikipedia.org/wiki/Least_upper_bound_property), and For each *x* in *S* and each *y* in *S* with *x* \< *y*, there exists *z* in *S* such that *x* \< *z* \< *y*

A [set](wikipedia://en/26691) has the least upper bound property, if every nonempty subset of the set that is bounded above has a least upper bound in the set. Linear continua are particularly important in the field of [topology](wikipedia://en/29954) where they can be used to verify whether an [ordered set](wikipedia://en/30330) given the [order topology](wikipedia://en/213650) is [connected](wikipedia://en/6233) or not.[^o2]

Unlike the standard real line, a linear continuum may be bounded on either side: for example, any (real) [closed interval](https://en.wikipedia.org/wiki/Closed_interval) is a linear continuum.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- The ordered set of [real numbers](wikipedia://en/20646438), **R**, with its usual [order](wikipedia://en/30330) is a linear continuum, and is the archetypal example. Property b) is trivial, and property a) is simply a reformulation of the [completeness axiom](https://en.wikipedia.org/wiki/Completeness_axiom).

Examples in addition to the real numbers:

- sets which are [order-isomorphic](wikipedia://en/23916899) to the set of real numbers, for example a real [open interval](https://en.wikipedia.org/wiki/Open_interval), and the same with half-open gaps (note that these are not gaps in the above-mentioned sense)
- the [affinely extended real number system](https://en.wikipedia.org/wiki/Affinely_extended_real_number_system) and order-isomorphic sets, for example the [unit interval](wikipedia://en/49324)
- the set of real numbers with only +∞ or only −∞ added, and order-isomorphic sets, for example a [half-open interval](https://en.wikipedia.org/wiki/Half-open_interval)
- the [long line](wikipedia://en/338403)
- The set *I* × *I* (where × denotes the [Cartesian product](wikipedia://en/24104095) and *I* = \[0, 1\]) in the [lexicographic order](wikipedia://en/567667) is a linear continuum. Property b) is trivial. To check property a), we define a map, π<sub>1</sub> : *I* × *I* → *I* by

*π*<sub>1</sub> (*x*, *y*) = *x*

This map is known as the [projection map](https://en.wikipedia.org/wiki/Projection_map). The projection map is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) (with respect to the [product topology](wikipedia://en/24910) on *I* × *I*) and is [surjective](https://en.wikipedia.org/wiki/Surjective). Let *A* be a nonempty subset of *I* × *I* which is bounded above. Consider *π*<sub>1</sub>(*A*). Since *A* is bounded above, *π*<sub>1</sub>(*A*) must also be bounded above. Since, *π*<sub>1</sub>(*A*) is a subset of *I*, it must have a least upper bound (since *I* has the least upper bound property). Therefore, we may let *b* be the least upper bound of *π*<sub>1</sub>(*A*). If *b* belongs to *π*<sub>1</sub>(*A*), then *b* × *I* will intersect *A* at say *b* × *c* for some *c* ∈ *I*. Notice that since *b* × *I* has the same [order type](wikipedia://en/4499021) of *I*, the set (*b* × *I*) ∩ *A* will indeed have a least upper bound *b* × *c**, which is the desired least upper bound for*****A*.***

If *b* does not belong to *π*<sub>1</sub>(*A*), then *b* × 0 is the least upper bound of *A*, for if *d* \< *b*, and *d* × *e* is an upper bound of *A*, then *d* would be a smaller upper bound of *π*<sub>1</sub>(*A*) than *b*, contradicting the unique property of *b*.

:::

## Non-examples {#Non-examples}

- The ordered set **Q** of [rational numbers](wikipedia://en/19727024) is not a linear continuum. Even though property b) is satisfied, property a) is not. Consider the subset

*A* = {*x* ∈ **Q** | *x* \< $\sqrt{2}$}

of the set of rational numbers. Even though this set is bounded above by any rational number greater than $\sqrt{2}$ (for instance 3), it has no [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) in the rational numbers.[^o7] (Specifically, for any rational upper bound *r* > $\sqrt{2}$, *r*/2 + 1/*r* is a closer rational upper bound; details at Methods of computing square roots.)

- The ordered set of non-negative [integers](wikipedia://en/14563) with its usual order is not a linear continuum. Property a) is satisfied (let *A* be a subset of the set of non-negative integers that is bounded above. Then *A* is [finite](wikipedia://en/11742) so it has a maximum, and this maximum is the desired least upper bound of *A*). On the other hand, property b) is not. Indeed, 5 is a non-negative integer and so is 6, but there exists no non-negative integer that lies strictly between them.
- The ordered set *A* of nonzero real numbers

*A* = (−∞, 0) ∪ (0, +∞)

is not a linear continuum. Property b) is trivially satisfied. However, if *B* is the set of negative real numbers:

*B* = (−∞, 0)

then *B* is a subset of *A* which is bounded above (by any element of *A* greater than 0; for instance 1), but has no least upper bound in *A*. Notice that 0 is not a bound for *B* since 0 is not an element of *A*.

- Let **Z**<sub>−</sub> denote the set of negative integers and let *A* = (0, 5) ∪ (5, +∞). Let

*S* = **Z**<sub>−</sub> ∪ *A*.

Then *S* satisfies neither property a) nor property b). The proof is similar to the previous examples.

:::

## Topological properties {#Topological_properties}

Even though linear continua are important in the study of [ordered sets](wikipedia://en/30330), they do have applications in the mathematical field of [topology](wikipedia://en/29954). In fact, we will prove that an ordered set in the [order topology](wikipedia://en/213650) is [connected](wikipedia://en/6233) if and only if it is a linear continuum. We will prove one implication, and leave the other one as an exercise. (Munkres explains the second part of the proof in [^o9])

::: {#o10 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem**

Let *X* be an ordered set in the order topology. If *X* is connected, then *X* is a linear continuum.

*Proof:*

Suppose that *x* and *y* are elements of *X* with *x* \< *y*. If there exists no *z* in *X* such that *x* \< *z* \< *y*, consider the sets:

*A* = (−∞, *y*)

*B* = (*x*, +∞)

These sets are [disjoint](wikipedia://en/39359) (If *a* is in *A*, *a* \< *y* so that if *a* is in *B*, *a* > *x* and *a* \< *y* which is impossible by hypothesis), [nonempty](https://en.wikipedia.org/wiki/Nonempty) (*x* is in *A* and *y* is in *B*) and [open](wikipedia://en/39358) (in the order topology), and their [union](wikipedia://en/47949) is *X*. This contradicts the connectedness of *X*.

Now we prove the least upper bound property. If *C* is a subset of *X* that is bounded above and has no least upper bound, let *D* be the union of all [open rays](wikipedia://en/213650) of the form (*b*, +∞) where b is an upper bound for *C*. Then *D* is open (since it is the union of open sets), and [closed](wikipedia://en/47279) (if *a* is not in *D*, then *a* \< *b* for all upper bounds *b* of *C* so that we may choose *q* > *a* such that *q* is in *C* (if no such *q* exists, *a* is the least upper bound of *C*), then an [open interval](wikipedia://en/213650) containing *a* may be chosen that doesn't intersect *D*). Since *D* is nonempty (there is more than one upper bound of *D* for if there was exactly one upper bound *s*, *s* would be the least upper bound. Then if *b*<sub>1</sub> and *b*<sub>2</sub> are two upper bounds of *D* with *b*<sub>1</sub> \< *b*<sub>2</sub>, *b*<sub>2</sub> will belong to *D*), *D* and its complement together form a [separation](wikipedia://en/148911) on *X*. This contradicts the connectedness of *X*.

:::

::: {#o12 .statement kind=statement/theorem cue=named-heading name="Applications of the theorem"}

### Applications of the theorem {#Applications_of_the_theorem}

1. Since the ordered set *A* = (−∞, 0) U (0,+∞) is not a linear continuum, it is disconnected.
1. By applying the theorem just proved, the fact that **R** is connected follows. In fact any [interval](wikipedia://en/49172) (or ray) in **R** is also connected.
1. The set of integers is not a linear continuum and therefore cannot be connected.
1. In fact, if an ordered set in the order topology is a linear continuum, it must be connected. Since any interval in this set is also a linear continuum, it follows that this space is [locally connected](wikipedia://en/6959754) since it has a [basis](https://en.wikipedia.org/wiki/Basis_%28topology%29) consisting entirely of connected sets.
1. For an example of a [topological space](wikipedia://en/30450) that is a linear continuum, see [long line](wikipedia://en/338403).

:::
