# Casio fx-7000G

::: {#o1 .subject cue=lead name="Casio fx-7000G"}

*Image: Vintage Casio Scientific Graphing Pocket Calculator, Model fx-7000GA, Made in Japan, 1990 (8721201872).jpg.* The successor FX-7000 GA was released in 1990.[^o3]

The **Casio FX-7000G** is a [calculator](wikipedia://en/7593) which is widely known as being the world's first [graphing calculator](wikipedia://en/335004) available to the public. It was introduced to the public and later manufactured between 1985 and c. 1989.[^o18] Notable features are its ability to graph functions,[^o8] and that it is [programmable](https://en.wikipedia.org/wiki/Programmable_calculator). The calculator offers 82 scientific functions and is capable of manual computation for basic [arithmetic](wikipedia://en/3118) problems.[^o15]

:::

## Features {#Features}

### Mathematical {#Mathematical}

The calculator can compute basic arithmetic functions with a precision up to 13 digits.[^o18] Many functions integrated into the calculator include arithmetic and algebraic computations such as:

- [square roots](https://en.wikipedia.org/wiki/Square_roots)
- [reciprocals](wikipedia://en/229940)
- [exponential functions](https://en.wikipedia.org/wiki/Exponential_functions)
- [factorials](https://en.wikipedia.org/wiki/Factorials)
- [logarithms](https://en.wikipedia.org/wiki/Logarithms)
- [trig functions](https://en.wikipedia.org/wiki/Trig_functions)[^o15]

Other specialized functions also implemented into the calculator include [hyperbolic](https://en.wikipedia.org/wiki/Hyperbolic_function) and [statistical](https://en.wikipedia.org/wiki/Statistical) functions, [binary](wikipedia://en/238686)/[octal](wikipedia://en/22330)/[hexadecimal](wikipedia://en/13263)/[sexagesimal](wikipedia://en/135316) conversions and graph plotting.[^o6]

### Programming {#Programming}

Like many [Casio](https://en.wikipedia.org/wiki/Casio) calculators, the FX-7000G includes a [programming](https://en.wikipedia.org/wiki/Mathematical_programming) mode,[^o8] in addition to its display and graphing mode. It holds 422 bytes of programming memory,[^o9] less than half a kilobyte. The calculator uses a [tokenized](https://en.wikipedia.org/wiki/Lexical_analysis#Tokenization) programming language (similar to the earlier FX-602P) which is well suited to writing more complex programs, as memory efficiency is a priority. Tokenization is performed by using characters and symbols in place of long lines of code to minimize the amount of memory being used. The User Manual programming catalog is written in these symbols,[^o10] allowing for lengthier programs to be written with less effort and less memory. One example is a program which estimates a [definite integral](https://en.wikipedia.org/wiki/Definite_integral) through the use of [Simpson's Rule](https://en.wikipedia.org/wiki/Simpson's_Rule); this can be found within the user manual for reference.[^o10]

The calculator has 26 numeric memories as standard. Additional memories can be created by reducing the number of bytes available for programs. Using this facility allows a total of 78 memories maximum.

### Graphing {#Graphing}

The calculator has a built in graphing feature which is unique to its model. The calculator can display either built-in graphs that are already programmed or display a user defined graph.[^o12] The user also has the option to rewrite any of the previously programmed graphs.[^o12]

Statistical graphs can also be generated: bar graphs, line graphs, normal distribution curves, regression lines.[^o9]

## Display and exterior {#Display_and_exterior}

### Display {#Display}

The FX-7000G incorporates an [LCD](https://en.wikipedia.org/wiki/LCD) [Dot Matrix](https://en.wikipedia.org/wiki/Dot_Matrix) design via the display window. When set into character mode the calculator can display up to sixteen characters on each of its eight display lines.[^o15] This sixteen character by eight line display is screened on the 96 × 64 dot matrix.[^o15] The LCD is not capable of colour or grey scale display.

### Exterior {#Exterior}

A black casing surrounds the calculator along with a metal panel implemented on the rear; a large plastic screen protects the LCD window as well. Keys are labeled and printed on orange, green, blue, red, and black malleable buttons.[^o18]

### Measurements {#Measurements}

The calculator's dimensions (width, height, depth) are \83.5 x. It has an approximate mass of \155.5 g including batteries. [^o18]

### Power {#Power}

The Casio Fx-7000G needs a 9.0 volt [DC current](https://en.wikipedia.org/wiki/Direct_current) [lithium battery](https://en.wikipedia.org/wiki/Lithium_battery) supply provided by 3 [CR2032](https://en.wikipedia.org/wiki/CR2032_battery) type cells. The calculator does not accept an [AC adapter](https://en.wikipedia.org/wiki/AC_adapter) and only uses batteries. The average battery life is around 120 hours which is shorter in length compared to similar models.[^o18]
