# Conformally flat manifold

::: {#o1 .subject cue=lead name="Conformally flat manifold"}

*Image: Conformal map.svg.* The upper manifold is flat. The lower one is not, but it is conformal to the first one

A ([pseudo](wikipedia://en/287555)-)[Riemannian manifold](wikipedia://en/144652) is **conformally flat** if each point has a neighborhood that can be mapped to [flat space](wikipedia://en/12756616) by a [conformal transformation](https://en.wikipedia.org/wiki/Conformal_transformation).

:::

In practice, the [metric tensor](wikipedia://en/195795) $g$ of the manifold $M$ has to be conformal to the flat metric tensor $\eta$, i.e., the [geodesics](wikipedia://en/91096) maintain in all points of $M$ the angles by moving from one to the other, as well as keeping the null geodesics unchanged,[^o2] that means there exists a function $\lambda(x)$ such that $g(x) = \lambda^2(x)\, \eta$, where $\lambda(x)$ is known as the [conformal factor](wikipedia://en/295907#Conformal_manifolds) and $x$ is a point on the manifold.

More formally, let $(M,g)$ be a pseudo-Riemannian manifold. Then $(M,g)$ is conformally flat if for each point $x$ in $M$, there exists a neighborhood $U$ of $x$ and a [smooth function](https://en.wikipedia.org/wiki/Smooth_function) $f$ defined on $U$ such that $(U,e^{2f} g)$ is [flat](wikipedia://en/12756616) (i.e. the [curvature](wikipedia://en/130526) of $e^{2f} g$ vanishes on $U$). The function $f$ need not be defined on all of $M$.

Some authors use the definition of **locally conformally flat** when referred to just some point $x$ on $M$ and reserve the definition of *conformally flat* for the case in which the relation is valid for all $x$ on $M$.

## Examples {#Examples}

- Every manifold with [constant](wikipedia://en/3638803) [sectional curvature](wikipedia://en/285618) is conformally flat.
- Every 2-dimensional pseudo-Riemannian manifold is conformally flat.[^o2]
  - The [line element](wikipedia://en/855138) of the two dimensional spherical coordinates, like the one used in the [geographic coordinate system](https://en.wikipedia.org/wiki/Geographic_coordinate_system), $ds^2 = d\theta^2 + \sin^2 \theta \, d\phi^2$,[^o5] has metric tensor $\textstyle g_{ik} = \left[ \begin{smallmatrix} 1 & 0 \\ 0 & \sin^2 \theta \end{smallmatrix} \right]$ and is not flat but with the [stereographic projection](wikipedia://en/143431) can be mapped to a flat space using the conformal factor $\textstyle \frac{2}{1+r^2}$, where $r$ is the distance from the origin of the flat space,[^o6] obtaining $\textstyle ds^2 = d\theta^2 + \sin^2 \theta \, d\phi^2 \, = \frac{4}{(1+r^2)^2}(dx^2 +dy^2)$.
- A 3-dimensional pseudo-Riemannian manifold is conformally flat if and only if the [Cotton tensor](wikipedia://en/1074140) vanishes.
- An *n*-dimensional pseudo-Riemannian manifold for *n* ≥ 4 is conformally flat if and only if the [Weyl tensor](wikipedia://en/1026848) vanishes.
- Every [compact](wikipedia://en/6042), [simply connected](https://en.wikipedia.org/wiki/Simply_connected), conformally Euclidean Riemannian manifold is conformally equivalent to the [round sphere](wikipedia://en/39782).[^o7]
  - The [stereographic projection](wikipedia://en/143431) provides a coordinate system for the sphere in which conformal flatness is explicit, as the metric is proportional to the flat one.
- In [general relativity](wikipedia://en/12024), conformally flat manifolds are often used, for instance, in describing the [Friedmann–Lemaître–Robertson–Walker metric](wikipedia://en/343031).[^o8] However, this is not always possible, as in the case of the [Kerr metric](wikipedia://en/456715), which does not admit any conformally flat slices.[^o9]

An example of conformally flat metric can be obtained by transforming the [Kruskal–Szekeres coordinates](wikipedia://en/2089093) for the [Schwarzschild metric](wikipedia://en/264606), which have line element $\textstyle ds^2 = \left(1-{2GM}/{r} \right) dv \, du$ with metric tensor $\textstyle g_{ik} = \left[ \begin{smallmatrix} 0 & 1-{2GM}/{r} \\ 1-{2GM}/{r} & 0 \end{smallmatrix} \right]$ and so is not flat. But with the transformations $t = (v + u)/2$ and $x = (v - u)/2$ becomes $\textstyle ds^2 = \left(1-{2GM}/{r} \right) (dt^2 - dx^2)$ with metric tensor $\textstyle g_{ik} = \left[ \begin{smallmatrix} 1-{2GM}/{r} & 0 \\ 0 & -1+{2GM}/{r} \end{smallmatrix} \right]$, which is the flat metric times the conformal factor $\textstyle 1-{2GM}/{r}$.[^o10]
