# Tietze transformations

::: {#o1 .subject cue=lead name="Tietze transformations"}

In [group theory](wikipedia://en/41890), **Tietze transformations** are used to transform a given [presentation of a group](wikipedia://en/99494) into another, often simpler presentation of the same [group](wikipedia://en/19447). These transformations are named after [Heinrich Tietze](wikipedia://en/1368572) who introduced them in a paper in 1908.[^o2]

:::

A presentation is in terms of *generators* and *relations*; formally speaking the presentation is a pair of a set of named generators, and a set of words in the [free group](wikipedia://en/59735) on the generators that are taken to be the relations. Tietze transformations are built up of elementary steps, each of which individually rather evidently takes the presentation to a presentation of an [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) group. These elementary steps may operate on generators or relations, and are of four kinds.

## Adding a relation {#Adding_a_relation}

If a relation can be derived from the existing relations then it may be added to the presentation without changing the group. Let G=〈 x | x<sup>3</sup>=1 〉 be a finite presentation for the cyclic group of order 3. Multiplying x<sup>3</sup>=1 on both sides by x<sup>3</sup> we get x<sup>6</sup> = x<sup>3</sup> = 1 so x<sup>6</sup> = 1 is derivable from x<sup>3</sup>=1. Hence G=〈 x | x<sup>3</sup>=1, x<sup>6</sup>=1 〉 is another presentation for the same group.

## Removing a relation {#Removing_a_relation}

If a relation in a presentation can be derived from the other relations then it can be removed from the presentation without affecting the group. In *G* = 〈 *x* | *x*<sup>3</sup> = 1, *x*<sup>6</sup> = 1 〉 the relation *x*<sup>6</sup> = 1 can be derived from *x*<sup>3</sup> = 1 so it can be safely removed. Note, however, that if *x*<sup>3</sup> = 1 is removed from the presentation the group *G* = 〈 *x* | *x*<sup>6</sup> = 1 〉 defines the cyclic group of order 6 and does not define the same group. Care must be taken to show that any relations that are removed are consequences of the other relations.

## Adding a generator {#Adding_a_generator}

Given a presentation it is possible to add a new generator that is expressed as a word in the original generators. Starting with *G* = 〈 *x* | *x*<sup>3</sup> = 1 〉 and letting *y* = *x*<sup>2</sup> the new presentation *G* = 〈 *x*,*y* | *x*<sup>3</sup> = 1, *y* = *x*<sup>2</sup> 〉 defines the same group.

## Removing a generator {#Removing_a_generator}

If a relation can be formed where one of the generators is a word in the other generators then that generator may be removed. In order to do this it is necessary to replace all occurrences of the removed generator with its equivalent word. The presentation for the [elementary abelian group](wikipedia://en/4843202) of order 4, G=〈 x,y,z | x = yz, y<sup>2</sup>=1, z<sup>2</sup>=1, x=x<sup>−1</sup> 〉 can be replaced by *G* = 〈 *y*,*z* | *y*<sup>2</sup> = 1, *z*<sup>2</sup> = 1, (*yz*) = (*yz*)<sup>−1</sup> 〉 by removing *x*.

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

Let *G* = 〈 *x*,*y* | *x*<sup>3</sup> = 1, *y*<sup>2</sup> = 1, (*xy*)<sup>2</sup> = 1 〉 be a presentation for the [symmetric group](wikipedia://en/28901) of degree three. The generator *x* corresponds to the permutation (1,2,3) and *y* to (2,3). Through Tietze transformations this presentation can be converted to *G* = 〈 *y*, *z* | (*zy*)<sup>3</sup> = 1, *y*<sup>2</sup> = 1, *z*<sup>2</sup> = 1 〉, where z corresponds to (1,2).

| *G* = 〈 *x*,*y* \| *x*<sup>3</sup> = 1, *y*<sup>2</sup> = 1, (*xy*)<sup>2</sup> = 1 〉 | (start) |
|---|---|
| *G* = 〈 *x*,*y*,*z*\| *x*<sup>3</sup> = 1, *y*<sup>2</sup> = 1, (*xy*)<sup>2</sup> = 1, *z* = *xy* 〉 | rule 3 — Add the generator *z* |
| *G* = 〈 *x*,*y*,*z* \| *x*<sup>3</sup> = 1, *y*<sup>2</sup> = 1, (*xy*)<sup>2</sup> = 1, *x* = *zy* 〉 | rules 1 and 2 — Add *x* = *z*y<sup>−1</sup> = *zy* and remove *z* = *xy* |
| *G* = 〈 *y*,*z* \| (*zy*)<sup>3</sup> = 1, *y*<sup>2</sup> = 1, *z*<sup>2</sup> = 1 〉 | rule 4 - Remove the generator x |

:::

::: {#o10 .statement kind=statement/theorem cue=named-heading name="Tietze's Theorem"}

## Tietze's Theorem {#Tietze's_Theorem}

Tietze's theorem states that any two finite presentations of the same group can be obtained from one another by a finite sequence of Tietze transformations.

:::
