# Affine hull

::: {#o1 .subject cue=lead name="Affine hull"}

In [mathematics](wikipedia://en/18831), the **affine hull** or **affine span** of a [set](wikipedia://en/26691) $S$ in [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n$ is the smallest [affine set](https://en.wikipedia.org/wiki/Affine_set) containing $S$,[^o2] or equivalently, the [intersection](wikipedia://en/23476429) of all affine sets containing $S$. Here, an *affine set* may be defined as the [translation](wikipedia://en/204682) of a [vector subspace](https://en.wikipedia.org/wiki/Vector_subspace).

:::

The affine hull of $S$ is what $\operatorname{span} S$ would be if the origin was moved to $S$.

The affine hull aff($S$) of $S$ is the set of all [affine combinations](wikipedia://en/298835) of elements of $S$, that is,

$$\operatorname{aff} (S)=\left\{\sum_{i=1}^k \alpha_i x_i \, \Bigg | \, k>0, \, x_i\in S, \, \alpha_i\in \mathbb{R}, \, \sum_{i=1}^k \alpha_i=1 \right\}.$$

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- The affine hull of the [empty set](wikipedia://en/9566) is the empty set.
- The affine hull of a [singleton](https://en.wikipedia.org/wiki/Singleton_%28set_theory%29) (a set made of one single element) is the singleton itself.
- The affine hull of a set of two different points is the [line](wikipedia://en/946975) through them.
- The affine hull of a set of three points not on one line is the [plane](https://en.wikipedia.org/wiki/Plane_%28geometry%29) going through them.
- The affine hull of a set of four points not in a plane in $\mathbb{R}^3$ is the entire space $\mathbb{R}^3$.

:::

## Properties {#Properties}

For any subsets $S, T \subseteq X$

- $$\operatorname{aff}(\operatorname{aff} S) = \operatorname{aff} S \subset \operatorname{span} S = \operatorname{span} \operatorname{aff} S.$$
- $\operatorname{aff} S$ is a [closed set](wikipedia://en/47279) if $X$ is finite dimensional.
- $$\operatorname{aff}(S + T)=\operatorname{aff} S + \operatorname{aff} T.$$
- $$S\subset \operatorname{aff} S.$$
- If $0 \in \operatorname{aff} S$ then $\operatorname{aff} S = \operatorname{span} S$.
- If $s_0 \in \operatorname{aff} S$ then $\operatorname{aff}(S) - s_0 = \operatorname{span}(S - s_0)= \operatorname{span}(S - S)$ is a linear subspace of $X$.
- $\operatorname{aff}(S - S) = \operatorname{span}(S - S)$ if $S\ne\varnothing$.
  - So, $\operatorname{aff}(S - S)$ is always a vector subspace of $X$ if $S\ne\varnothing$.
- If $S$ is [convex](wikipedia://en/6292) then $\operatorname{aff}(S - S) = \displaystyle\bigcup_{\lambda > 0} \lambda (S - S)$
- For every $s_0 \in \operatorname{aff} S$, $\operatorname{aff} S = s_0 + \operatorname{span}(S - s_0) = s_0 + \operatorname{span}(S - S) = S + \operatorname{span}(S - S) = s_0 + \operatorname{cone}(S - S)$ where $\operatorname{cone}(S - S)$ is the smallest [cone](wikipedia://en/3558266) containing $S - S$ (here, a set $C \subseteq X$ is a **cone** if $r c \in C$ for all $c \in C$ and all non-negative $r \geq 0$).
  - Hence $\operatorname{cone}(S - S)= \operatorname{span}(S - S)$ is always a linear subspace of $X$ parallel to $\operatorname{aff} S$ if $S\ne\varnothing$.
  - Note: $\operatorname{aff} S = s_0 + \operatorname{span}(S - s_0)$ says that if we translate $S$ so that it contains the origin, take its span, and translate it back, we get $\operatorname{aff} S$. Moreover, $\operatorname{aff} S$ or $s_0 + \operatorname{span}(S - s_0)$ is what $\operatorname{span} S$ would be if the origin was at $s_0$.

:::

## Related sets {#Related_sets}

- If instead of an affine combination one uses a [convex combination](wikipedia://en/794534), that is, one requires in the formula above that all $\alpha_i$ be non-negative, one obtains the [convex hull](wikipedia://en/40634) of $S$, which cannot be larger than the affine hull of $S$, as more restrictions are involved.
- The notion of [conical combination](wikipedia://en/19634578) gives rise to the notion of the [conical hull](https://en.wikipedia.org/wiki/Conical_hull) $\operatorname{cone} S$.
- If however one puts no restrictions at all on the numbers $\alpha_i$, instead of an affine combination one has a [linear combination](wikipedia://en/55632), and the resulting set is the [linear span](wikipedia://en/56353) $\operatorname{span} S$ of $S$, which contains the affine hull of $S$.
