# Cruzer Enterprise

::: {#o1 .subject cue=lead name="Cruzer Enterprise"}

The [SanDisk](https://en.wikipedia.org/wiki/SanDisk) **Cruzer Enterprise**[^o2] was an [encrypted](wikipedia://en/10294) [USB flash drive](https://en.wikipedia.org/wiki/USB_flash_drive). This [secure USB drive](https://en.wikipedia.org/wiki/Secure_USB_drive) imposed a mandatory access control on all files, storing them in a hardware-encrypted, password-protected [partition](https://en.wikipedia.org/wiki/Disk_partitioning). The Cruzer Enterprise was designed to protect information on company-issued [USB](https://en.wikipedia.org/wiki/USB) [flash drives](https://en.wikipedia.org/wiki/Flash_drives).

:::

Central Management and Control (CMC) server software centrally managed the drive, enabling password administration, data backup, and termination if the drive is lost or stolen.[^o3] It was released around 2008.[^o4][^o5] The Cruzer Enterprise supported [Microsoft](https://en.wikipedia.org/wiki/Microsoft) [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000) SP4, [Windows XP](https://en.wikipedia.org/wiki/Windows_XP) SP1, [Windows Server 2003](https://en.wikipedia.org/wiki/Windows_Server_2003), [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista),[^o6] and [Apple](https://en.wikipedia.org/wiki/Apple_Inc.) [OS X](https://en.wikipedia.org/wiki/Mac_OS_X) 10.4 and 10.5.[^o7] It was discontinued in November 2010.[^o8]

The SanDisk Cruzer Enterprise competed with other secure USB drives, including [IronKey](https://en.wikipedia.org/wiki/IronKey), [Kingston](https://en.wikipedia.org/wiki/Kingston_Technology), and [Verbatim](https://en.wikipedia.org/wiki/Verbatim_Corporation), and also [disk encryption software](https://en.wikipedia.org/wiki/Disk_encryption_software) such as [FreeOTFE](wikipedia://en/4954583) and [TrueCrypt](wikipedia://en/905962).

Cruzer Enterprise FIPS Edition also offered features of the Cruzer Enterprise, including:

- Mandatory password-protection and hardware-based 256-bit AES [encryption](wikipedia://en/10294) for all files stored on the drive.
- Encryption keys never leave the drive, so they are safe from hacking attempts aimed at the host PC.
- [Plug & Play](https://en.wikipedia.org/wiki/Plug_&_Play) functionality on any PC
- Premium performance, with read speed of 24 megabytes (MB) per second and write speed of 20 MB/sec1.
- Complete lifecycle management through SanDisk's CMC (Central Management & Control) server software. CMC provides password recovery and renewal through the network, remote termination of lost drives, central back-up and restore, and central usage tracking. This means data is not lost when a drive is lost, and IT administrators can provision a replacement flash drive with user files stored on the network.
