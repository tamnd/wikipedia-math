# Tsallis statistics

::: {#o1 .subject cue=lead name="Tsallis statistics"}

The term **Tsallis statistics** usually refers to the collection of mathematical functions and associated probability distributions that were originated by [Constantino Tsallis](https://en.wikipedia.org/wiki/Constantino_Tsallis). Using that collection, it is possible to derive [Tsallis distributions](wikipedia://en/22342404) from the optimization of the [Tsallis entropic form](https://en.wikipedia.org/wiki/Tsallis_entropy). A continuous real parameter *q* can be used to adjust the distributions, so that distributions which have properties intermediate to that of [Gaussian](wikipedia://en/21462) and [Lévy distributions](wikipedia://en/1346871) can be created. The parameter *q* represents the degree of non-[extensivity](https://en.wikipedia.org/wiki/Extensivity) of the distribution. Tsallis statistics are useful for characterising complex, [anomalous diffusion](https://en.wikipedia.org/wiki/Anomalous_diffusion).

:::

## Tsallis functions {#Tsallis_functions}

The *q*-deformed exponential and logarithmic functions were first introduced in Tsallis statistics in 1994.[^o3] However, the *q*-logarithm is the [Box–Cox transformation](https://en.wikipedia.org/wiki/Box–Cox_transformation) for $q=1-\lambda$, proposed by [George Box](https://en.wikipedia.org/wiki/George_Box) and [David Cox](wikipedia://en/1990771) in 1964.[^o4]

### *q*-exponential {#q-exponential}

The *q*-exponential is a deformation of the [exponential function](wikipedia://en/9678) using the real parameter *q*.[^o6]

$$e_q(x) = \begin{cases} \exp(x) & \text{if }q=1, \\[6pt] [1+(1-q)x]^{1/(1-q)} & \text{if }q \ne 1 \text{ and } 1+(1-q)x >0, \\[6pt] 0^{1/(1-q)} & \text{if }q \ne 1\text{ and }1+(1-q)x \le 0, \\[6pt] \end{cases}$$

Note that the *q*-exponential in Tsallis statistics is different from a version used [elsewhere](wikipedia://en/4120642).

### *q*-logarithm {#q-logarithm}

The *q*-logarithm is the inverse of *q*-exponential and a deformation of the [logarithm](wikipedia://en/17860) using the real parameter *q*.[^o6]

$$\ln_q(x) = \begin{cases} \ln(x) & \text{if }x> 0 \text{ and }q=1\\[8pt] \dfrac{x^{1-q} - 1}{1-q} & \text{if }x> 0 \text{ and }q\ne 1\\[8pt] \text{Undefined } & \text{if }x\le 0\\[8pt] \end{cases}$$

### Inverses {#Inverses}

These functions have the property that

$$\begin{cases} e_q( \ln_q(x)) = x & (x>0)\\ \ln_q( e_q(x) ) = x & (0<e_q(x)<\infty)\\ \end{cases}$$

### Analysis {#Analysis}

The $q\to 1$ limits of the above expression can be understood by considering $\left(1+\frac{x}{N}\right)^N \approx {\rm e}^x$ for the exponential function and $N\left(x^{\frac{1}{N}}-1\right)\approx \log(x)$ for the logarithm, in the limit $N = \frac{1}{1-q}\to \infty$.
