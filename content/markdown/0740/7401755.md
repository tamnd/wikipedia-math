# AC (complexity)

::: {#o1 .subject cue=lead name="AC"}

In [circuit complexity](wikipedia://en/7641969), **AC** is a [complexity class](wikipedia://en/502426) hierarchy. Each class, **AC<sup>i</sup>**, consists of the [languages](wikipedia://en/10939) recognized by [Boolean circuits](wikipedia://en/7087423) with depth $O(\log^i n)$ and a [polynomial number](wikipedia://en/23000) of [unlimited fan-in](https://en.wikipedia.org/wiki/Fanin) [AND](https://en.wikipedia.org/wiki/AND_gate) and [OR gates](https://en.wikipedia.org/wiki/OR_gate).

:::

The name "AC" was chosen by analogy to [NC](wikipedia://en/22073), with the "A" in the name standing for "alternating" and referring both to the alternation between the AND and OR gates in the circuits and to [alternating Turing machines](https://en.wikipedia.org/wiki/Alternating_Turing_machine).[^n1]

The smallest AC class is [AC<sup>0</sup>](wikipedia://en/7400698), consisting of constant-depth unlimited fan-in circuits.

The total hierarchy of AC classes is defined as

> $$\mbox{AC} = \bigcup_{i \geq 0} \mbox{AC}^i$$

## Relation to NC {#Relation_to_NC}

The AC classes are related to [NC](wikipedia://en/22073), [ACC](https://en.wikipedia.org/wiki/ACC_%28complexity%29), and [TC](wikipedia://en/26200497) classes. For each *i*, we have[^o4]

$$\mathsf{NC}^i \subseteq \mathsf{AC}^i \subseteq \mathsf{ACC}^{i} \subseteq \mathsf{TC}^{i} \subseteq \mathsf{NC}^{i+1}.$$

As an immediate consequence of this, we have that NC = AC = ACC = TC.[^n2]

We have $\mathsf{NC}^0 \subsetneq \mathsf{AC}^0 \subsetneq \mathsf{ACC}^{0}$. Specifically, PARITY is in $\mathsf{ACC}^0$ but not in $\mathsf{AC}^0$.[^n3] And since NC requires bounded fan-in, any function of type $\{0, 1\}^n \to \{0, 1\}$ whose output depends on more than $O(1)$ inputs is beyond $\mathsf{NC}^0$. In particular, the unbounded fan-in OR is beyond $\mathsf{NC}^0$.

In detail, define $f_n: \{0, 1\}^n \to \{0, 1\}$ by $f_n(x_1, \dots, x_n) = \sum_i x_i \mod 2$. Then it requires $\Omega(2^{\frac{n^{1 / d}}{16}})$ gates to be computed by a $\mathsf{AC}^0$ circuit with depth $\leq d$.[^n4]

::: {#o9 .statement kind=statement/generalization cue=heading name="Variations"}

## Variations {#Variations}

The power of the AC classes can be affected by adding additional gates. If we add gates which calculate the [modulo operation](https://en.wikipedia.org/wiki/Modulo_operation) for some modulus *m*, we have the classes [ACC<sup>i</sup>\[m](https://en.wikipedia.org/wiki/ACC_%28complexity%29)\].[^n2]

:::
