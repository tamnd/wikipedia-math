# Prime form

::: {#o1 .subject cue=lead name="Prime form"}

In [algebraic geometry](wikipedia://en/1997), the Schottky–Klein **prime form** *E*(*x*,*y*) of a [compact](wikipedia://en/6042) [Riemann surface](wikipedia://en/173181) *X* depends on two elements *x* and *y* of *X*, and vanishes if and only if *x* = *y*. The prime form *E* is not quite a holomorphic function on *X* × *X*, but is a section of a holomorphic line bundle over this space. Prime forms were introduced by [Friedrich Schottky](wikipedia://en/5872505) and [Felix Klein](wikipedia://en/41887).

:::

Prime forms can be used to construct meromorphic functions on *X* with given poles and zeros. If Σ*n*<sub>*i*</sub>*a*<sub>*i*</sub> is a divisor linearly equivalent to 0, then Π*E*(*x*,*a*<sub>*i*</sub>)<sup>*n*<sub>*i*</sub></sup> is a meromorphic function with given poles and zeros.
