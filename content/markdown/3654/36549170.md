# Schizophrenic number

::: {#o1 .subject cue=lead name="Schizophrenic number"}

A **schizophrenic number** or **mock rational number** is an [irrational number](wikipedia://en/20647689) which displays certain characteristics of [rational numbers](wikipedia://en/19727024). It is one of the numerous [mathematical curiosities](wikipedia://en/740817).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

*[The Universal Book of Mathematics](https://en.wikipedia.org/wiki/The_Universal_Book_of_Mathematics)* defines "schizophrenic number" as:

The sequence of numbers generated by the recurrence relation *f*(*n*) = 10 *f*(*n* − 1) + *n* described above is:

0, 1, 12, 123, 1234, 12345, 123456, 1234567, 12345678, 123456789, 1234567900, ... .

*f*(49) = 1234567901234567901234567901234567901234567901229

The [integer parts](https://en.wikipedia.org/wiki/Integer_part) of their square roots,

1, 3, 11, 35, 111, 351, 1111, 3513, 11111, 35136, 111111, 351364, 1111111, ... ,

alternate between numbers with irregular digits and numbers with repeating digits, in a similar way to the alternations appearing within the [decimal part](https://en.wikipedia.org/wiki/Decimal_part) of each square root.

:::

## Characteristics {#Characteristics}

The *schizophrenic number* shown above is the special case of a more general phenomenon that appears in the [$b$-ary](wikipedia://en/701207) expansions of square roots of the solutions of the recurrence $f_b(n)=b f_b(n-1)+n$, for all $b\geq2$, with initial value $f(0) = 0$ taken at odd positive integers $n$. The case $b=10$ and $n=49$ corresponds to the example above.

Indeed, Tóth showed that these irrational numbers present *schizophrenic patterns* within their $b$-ary expansion,[^o6] composed of blocks that begin with a non-repeating digit block followed by a repeating digit block. When put together in base $b$, these blocks form the *schizophrenic* pattern. For instance, in [base 8](https://en.wikipedia.org/wiki/Base_8), the number $\sqrt{f_8(49)}$ begins:

```
1111111111111111111111111.1111111111111111111111 0600
444444444444444444444444444444444444444444444 02144
333333333333333333333333333333333333333333 175124422
666666666666666666666666666666666666666 ....
```

The pattern is due to the [Taylor expansion](https://en.wikipedia.org/wiki/Taylor_expansion) of the square root of the recurrence's solution taken at odd positive integers. The various digit contributions of the Taylor expansion yield the non-repeating and repeating digit blocks that form the schizophrenic pattern.

## Other properties {#Other_properties}

In some cases, instead of repeating digit sequences, we find repeating *digit patterns*. For instance, the number $\sqrt{f_3(49)}$:

```
1111111111111111111111111.1111111111111111111111111111111 01200 
202020202020202020202020202020202020202020 11010102 
00120012000012001200120012001200120012 0010
21120020211210002112100021121000211210 ...
```

shows repeating digit patterns in base $3$.

Numbers that are *schizophrenic* in base $b$ are also *schizophrenic* in base $b^m$, up to a certain limit (see Tóth). An example is $\sqrt{f_3(49)}$ above, which is still schizophrenic in base $9$:

```
1444444444444.4444444444 350
666666666666666666666 4112
0505050505050505050 337506
75307530753075307 40552382 ...
```
