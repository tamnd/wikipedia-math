# Dormand–Prince method

::: {#o1 .subject cue=lead name="Dormand–Prince method"}

In [numerical analysis](wikipedia://en/21506), the **Dormand–Prince** (**RKDP**) **method** or **DOPRI method**, is an embedded method for solving [ordinary differential equations](https://en.wikipedia.org/wiki/Ordinary_differential_equations) (ODE).[^o2] The method is a member of the [Runge–Kutta](https://en.wikipedia.org/wiki/Runge–Kutta) family of ODE solvers. More specifically, it uses six function evaluations to calculate fourth- and fifth-order accurate solutions. The difference between these solutions is then taken to be the error of the (fourth-order) solution. This error estimate is very convenient for adaptive stepsize integration algorithms. Other similar integration methods are [Fehlberg](wikipedia://en/8401893) (RKF) and [Cash–Karp](https://en.wikipedia.org/wiki/Cash–Karp) (RKCK).

:::

The Dormand–Prince method has seven stages, but it uses only six function evaluations per step because it has the "First Same As Last" (FSAL) property: the last stage is evaluated at the same point as the first stage of the next step. Dormand and Prince chose the coefficients of their method to minimize the error of the fifth-order solution. This is the main difference with the Fehlberg method, which was constructed so that the fourth-order solution has a small error. For this reason, the Dormand–Prince method is more suitable when the higher-order solution is used to continue the integration, a practice known as *local extrapolation*.[^o3][^o4]

## Applications {#Applications}

Dormand–Prince is the default method in the `ode45` solver for [MATLAB](wikipedia://en/20412)[^o8] and [GNU Octave](wikipedia://en/48707)[^o9] and is the default choice for the [Simulink](https://en.wikipedia.org/wiki/Simulink)'s model explorer solver. It is an option in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29)'s SciPy ODE integration library[^o10] and in [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29)'s ODE solvers library.[^o11] Implementations for the languages [Fortran](https://en.wikipedia.org/wiki/Fortran),[^o12] [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29),[^o13] [C++](https://en.wikipedia.org/wiki/C++),[^o14] and [Rust](https://en.wikipedia.org/wiki/Rust_%28programming_language%29)[^o15] are also available.
