# Logit-normal distribution

::: {#o1 .subject cue=lead name="Logit-normal distribution"}

In [probability theory](wikipedia://en/23542), a **logit-normal distribution** is a [probability distribution](wikipedia://en/23543) of a [random variable](wikipedia://en/25685) whose [logit](wikipedia://en/172068) has a [normal distribution](wikipedia://en/21462). If *Y* is a random variable with a normal distribution, and *t* is the standard [logistic function](wikipedia://en/84563), then *X* = *t*(*Y*) has a logit-normal distribution; likewise, if *X* is logit-normally distributed, then *Y* = [logit](wikipedia://en/172068)(*X*)= log (*X*/(1-*X*)) is normally distributed. It is also known as the **logistic normal distribution**,[^o2] which often refers to a multinomial logit version (e.g.[^o3][^o4][^o5]).

:::

A variable might be modeled as logit-normal if it is a proportion, which is bounded by zero and one, and where values of zero and one never occur.

::: {#o7 .statement kind=statement/fact cue=heading name="Characterization"}

## Characterization {#Characterization}

### Probability density function {#Probability_density_function}

The [probability density function](wikipedia://en/43487) (PDF) of a logit-normal distribution, for 0 \< *x* \< 1, is:

$$f_X(x;\mu,\sigma) = \frac{1}{\sigma\sqrt{2 \pi}}\,\frac{1}{x (1-x)}\, e^{-\frac{(\operatorname{logit}(x) - \mu)^2}{2\sigma^2}}$$

where *μ* and *σ* are the [mean](https://en.wikipedia.org/wiki/Mean) and [standard deviation](wikipedia://en/27590) of the variable’s [logit](wikipedia://en/172068) (by definition, the variable’s logit is normally distributed).

The density obtained by changing the sign of *μ* is symmetrical, in that it is equal to f(1-x;-*μ*,*σ*), shifting the mode to the other side of 0.5 (the midpoint of the (0,1) interval).

### Moments {#Moments}

The moments of the logit-normal distribution have no analytic solution. The moments can be estimated by [numerical integration](wikipedia://en/170089), however numerical integration can be prohibitive when the values of $\mu, \sigma^2$are such that the density function diverges to infinity at the end points zero and one. An alternative is to use the observation that the logit-normal is a transformation of a normal random variable. This allows us to approximate the $n$-th moment via the following quasi Monte Carlo estimate $E[X^n] \approx \frac{1}{K-1} \sum_{i=1}^{K-1} \left( P\left(\Phi^{-1}_{\mu,\sigma^2}(i/K)\right) \right)^n,$

where $P$ is the standard logistic function, and $\Phi^{-1}_{\mu,\sigma^2}$ is the inverse cumulative distribution function of a normal distribution with mean and variance $\mu, \sigma^2$. When $n=1$, this corresponds to the mean.

### Mode or modes {#Mode_or_modes}

When the derivative of the density equals 0 then the location of the mode x satisfies the following equation:

$$\operatorname{logit}(x) = \sigma^2(2x-1)+\mu .$$

For some values of the parameters there are two solutions, i.e. the distribution is [bimodal](https://en.wikipedia.org/wiki/Bimodal).

:::

## Multivariate generalization {#Multivariate_generalization}

The **logistic normal distribution** is a generalization of the logit–normal distribution to D-dimensional probability vectors by taking a logistic transformation of a multivariate normal distribution.[^o12][^o13][^o14]

### Probability density function {#Probability_density_function}

The [probability density function](wikipedia://en/43487) is:

$$f_X( \mathbf{x}; \boldsymbol{\mu} , \boldsymbol{\Sigma} ) = \frac{1}{ (2 \pi)^{D-1} |\boldsymbol{\Sigma} |^\frac{1}{2} } \, \frac{1}{ \prod\limits_{i=1}^D x_i } \, e^{- \frac{1}{2} \left\{ \log \left( \frac{ \mathbf{x}_{-D} }{ x_D } \right) - \boldsymbol{\mu} \right\}^\top \boldsymbol{\Sigma}^{-1} \left\{ \log \left( \frac{ \mathbf{x}_{-D} }{ x_D } \right) - \boldsymbol{\mu} \right\} } \quad , \quad \mathbf{x} \in \mathcal{S}^D \;\; ,$$

where $\mathbf{x}_{-D}$ denotes a vector of the first (D-1) components of $\mathbf{x}$ and $\mathcal{S}^D$ denotes the [simplex](wikipedia://en/39781#Probability) of D-dimensional probability vectors. This follows from applying the **additive logistic transformation** to map a [multivariate normal](wikipedia://en/50347) random variable $\mathbf{y} \sim \mathcal{N} \left( \boldsymbol{\mu} , \boldsymbol{\Sigma} \right) \; , \; \mathbf{y} \in \mathbb{R}^{D-1}$ to the simplex:

$$\mathbf{x} = \left[ \frac{ e^{ y_1 } }{ 1 + \sum_{i=1}^{D-1} e^{ y_i } } , \dots , \frac{ e^{ y_{D-1} } }{ 1 + \sum_{i=1}^{D-1} e^{ y_i } } , \frac{ 1 }{ 1 + \sum_{i=1}^{D-1} e^{ y_i } } \right]^\top$$

*Image: Gaussian and Logistic Normal pdfs.pdf.* Gaussian density functions and corresponding logistic normal density functions after logistic transformation.

The unique inverse mapping is given by:

$$\mathbf{y} = \left[ \log \left( \frac{ x_1 }{ x_D } \right) , \dots , \log \left( \frac{ x_{D-1} }{ x_D } \right) \right]^\top.$$

This is the case of a vector **x** which components sum up to one. In the case of **x** with sigmoidal elements, that is, when

$$\mathbf{y} = \left[ \log \left( \frac{ x_1 }{ 1-x_1 } \right) , \dots , \log \left( \frac{ x_D }{ 1-x_D } \right) \right]^\top$$

we have

$$f_X( \mathbf{x}; \boldsymbol{\mu} , \boldsymbol{\Sigma} ) = \frac{1}{ (2 \pi)^{D-1} |\boldsymbol{\Sigma} |^\frac{1}{2} } \, \frac{1}{ \prod\limits_{i=1}^D \left(x_i(1-x_i)\right) } \, e^{- \frac{1}{2} \left\{ \log \left( \frac{ \mathbf{x} }{ 1-\mathbf{x} } \right) - \boldsymbol{\mu} \right\}^\top \boldsymbol{\Sigma}^{-1} \left\{ \log \left( \frac{ \mathbf{x}}{ 1-\mathbf{x} } \right) - \boldsymbol{\mu} \right\} }$$

where the log and the division in the argument are taken element-wise. This is because the Jacobian matrix of the transformation is diagonal with elements $\frac{ 1 }{ x_i(1-x_i)}$.

### Use in statistical analysis {#Use_in_statistical_analysis}

The logistic normal distribution is a more flexible alternative to the [Dirichlet distribution](wikipedia://en/1117833) in that it can capture correlations between components of probability vectors. It also has the potential to simplify statistical analyses of [compositional data](wikipedia://en/500654) by allowing one to answer questions about log-ratios of the components of the data vectors. One is often interested in ratios rather than absolute component values.

The probability simplex is a bounded space, making standard techniques that are typically applied to vectors in $\mathbb{R}^n$ less meaningful. Statistician [John Aitchison](wikipedia://en/4900381) described the problem of spurious negative correlations when applying such methods directly to simplicial vectors.[^o13] However, mapping compositional data in $\mathcal{S}^D$ through the inverse of the additive logistic transformation yields real-valued data in $\mathbb{R}^{D-1}$. Standard techniques can be applied to this representation of the data. This approach justifies use of the logistic normal distribution, which can thus be regarded as the "Gaussian of the simplex".

### Relationship with the Dirichlet distribution {#Relationship_with_the_Dirichlet_distribution}

*Image: Logistic Normal approximation to Dirichlet distribution.pdf.* Logistic normal approximation to Dirichlet distribution

The [Dirichlet](wikipedia://en/1117833) and logistic normal distributions are never exactly equal for any choice of parameters. However, Aitchison described a method for approximating a Dirichlet with a logistic normal such that their [Kullback–Leibler divergence](wikipedia://en/1115052) (KL) is minimized:

$$K(p,q) = \int_{\mathcal{S}^D} p \left( \mathbf{x} \mid \boldsymbol{\alpha} \right) \log \left( \frac{ p \left( \mathbf{x} \mid \boldsymbol{\alpha} \right) }{ q \left( \mathbf{x} \mid \boldsymbol{\mu} , \boldsymbol{\Sigma} \right) } \right) \, d \mathbf{x}$$

This is minimized by:

$$\boldsymbol{\mu}^* = \mathbf{E}_p \left[ \log \left( \frac{ \mathbf{x}_{-D} }{ x_D } \right) \right] \quad , \quad \boldsymbol{\Sigma}^* = \textbf{Var}_p \left[ \log \left( \frac{ \mathbf{x}_{-D} }{ x_D } \right) \right]$$

Using moment properties of the Dirichlet distribution, the solution can be written in terms of the [digamma](wikipedia://en/406935) $\psi$ and [trigamma](wikipedia://en/2036750) $\psi'$ functions:

$$\mu_i^* = \psi \left( \alpha_i \right) - \psi \left( \alpha_D \right) \quad , \quad i = 1 , \ldots , D-1$$

$$\Sigma_{ii}^* = \psi' \left( \alpha_i \right) + \psi' \left( \alpha_D \right) \quad , \quad i = 1 , \ldots , D-1$$

$$\Sigma_{ij}^* = \psi' \left( \alpha_D \right) \quad , \quad i \neq j$$

This approximation is particularly accurate for large $\boldsymbol{\alpha}$. In fact, one can show that for $\alpha_i \rightarrow \infty , i = 1 , \ldots , D$, we have that $p \left( \mathbf{x} \mid \boldsymbol{\alpha} \right) \rightarrow q \left( \mathbf{x} \mid \boldsymbol{\mu}^* , \boldsymbol{\Sigma}^* \right)$.
