# Orbital stability

::: {#o1 .subject cue=lead name="Orbital stability"}

In [mathematical physics](wikipedia://en/173416) and the theory of [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations), the [solitary wave](wikipedia://en/51654) solution of the form $u(x,t)=e^{-i\omega t}\phi(x)$ is said to be **orbitally stable** if any solution with the [initial data](wikipedia://en/1186804) sufficiently close to $\phi(x)$ forever remains in a given small [neighborhood](wikipedia://en/1529485) of the trajectory of $e^{-i\omega t}\phi(x).$

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Formal definition is as follows.[^o4] Consider the [dynamical system](wikipedia://en/9087)

$$i\frac{du}{dt}=A(u), \qquad u(t)\in X, \quad t\in\mathbb{R},$$

with $X$ a [Banach space](wikipedia://en/3989) over $\mathbb{C}$, and $A : X \to X$. We assume that the system is [$\mathrm{U}(1)$-invariant](https://en.wikipedia.org/wiki/Unitary_invariance), so that $A(e^{is}u) = e^{is}A(u)$ for any $u\in X$ and any $s\in\mathbb{R}$.

Assume that $\omega \phi=A(\phi)$, so that $u(t)=e^{-i\omega t}\phi$ is a solution to the dynamical system. We call such solution a [solitary wave](wikipedia://en/51654).

We say that the solitary wave $e^{-i\omega t}\phi$ is orbitally stable if for any $\epsilon > 0$ there is $\delta > 0$ such that for any $v_0\in X$ with $\Vert \phi-v_0\Vert_X < \delta$ there is a solution $v(t)$ defined for all $t\ge 0$ such that $v(0) = v_0$, and such that this solution satisfies

$$\sup_{t\ge 0} \inf_{s\in\mathbb{R}} \Vert v(t) - e^{is} \phi \Vert_X < \epsilon.$$

:::

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

According to [^o7] ,[^o8] the solitary wave solution $e^{-i\omega t}\phi_\omega(x)$ to the [nonlinear Schrödinger equation](wikipedia://en/1422748)

$$i\frac{\partial}{\partial t} u = -\frac{\partial^2}{\partial x^2} u+g\!\left(|u|^2\right)u, \qquad u(x,t)\in\mathbb{C},\quad x\in\mathbb{R},\quad t\in\mathbb{R},$$

where $g$ is a smooth [real-valued function](wikipedia://en/22284647), is **orbitally stable** if the [Vakhitov&ndash;Kolokolov stability criterion](https://en.wikipedia.org/wiki/Vakhitov&ndash;Kolokolov_stability_criterion) is satisfied:

$$\frac{d}{d\omega}Q(\phi_\omega) < 0,$$

where

$$Q(u) = \frac{1}{2} \int_{\mathbb{R}} |u(x,t)|^2 \, dx$$

is the [charge](wikipedia://en/9804) of the solution $u(x,t)$, which is conserved in time (at least if the solution $u(x,t)$ is sufficiently smooth).

It was also shown,[^o9][^o10] that if $\frac{d}{d\omega}Q(\omega) < 0$ at a particular value of $\omega$, then the solitary wave $e^{-i\omega t}\phi_\omega(x)$ is [Lyapunov stable](wikipedia://en/363360), with the [Lyapunov function](wikipedia://en/352267) given by $L(u) = E(u) - \omega Q(u) + \Gamma(Q(u)-Q(\phi_\omega))^2$, where $E(u) = \frac{1}{2} \int_{\mathbb{R}} \left(\left|\frac{\partial u}{\partial x}\right|^2 + G\!\left(|u|^2\right)\right) dx$ is the [energy](https://en.wikipedia.org/wiki/Energy) of a solution $u(x,t)$, with $G(y) = \int_0^y g(z)\,dz$ the [antiderivative](wikipedia://en/2823) of $g$, as long as the constant $\Gamma>0$ is chosen sufficiently large.
