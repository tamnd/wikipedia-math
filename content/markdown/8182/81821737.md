# Packing coloring

::: {#o1 .subject cue=lead name="Packing coloring"}

In [graph theory](wikipedia://en/12401), a **packing coloring** (also called a **broadcast coloring**) is a type of [graph coloring](wikipedia://en/426743) where vertices are assigned colors (represented by positive integers) such that the distance between any two vertices with the same color $i$ is greater than $i$. The **packing chromatic number** (or **broadcast chromatic number**) $\chi_\rho(G)$ (or $\chi_b(G)$) of a graph $G$ is the minimum number of colors needed for a packing coloring.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **packing coloring** of a graph $G = (V,E)$ is a function $\pi : V \to \{1,2,\ldots,k\}$ such that if $\pi(u) = \pi(v)$, then the distance $d(u,v) > \pi(u)$. The minimum $k$ for which such a coloring exists is the **packing chromatic number** $\chi_\rho(G)$.[^o2]

Equivalently, a packing coloring is a partition $\mathcal{P}_\pi = \{V_1, V_2, \ldots, V_k\}$ of the vertex set where each $V_i$ is an $i$-packing (vertices at pairwise distance more than $i$).[^o2]

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Basic properties"}

## Basic properties {#Basic_properties}

For any graph $G$ with $n$ vertices:

- $\omega(G) \leq \chi(G) \leq \chi_\rho(G)$, where $\omega(G)$ is the [clique number](https://en.wikipedia.org/wiki/Clique_number) and $\chi(G)$ is the [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number)[^o2]
- $\chi_\rho(G) \leq \alpha_0(G) + 1$, where $\alpha_0(G)$ is the [vertex cover](wikipedia://en/562782) number, with equality if and only if $G$ has diameter two[^o2]
- $\chi_\rho(G) \leq n - \alpha(G) + 1$, where $\alpha(G)$ is the [independence number](https://en.wikipedia.org/wiki/Independence_number)[^o7]
- If $\chi_\rho(G) = \chi(G)$, then $\omega(G) = \chi(G)$[^o7]

:::

## Complexity {#Complexity}

Determining whether $\chi_\rho(G) \leq 3$ can be solved in polynomial time, while determining whether $\chi_\rho(G) \leq 4$ is [NP-hard](https://en.wikipedia.org/wiki/NP-hard), even for [planar graphs](wikipedia://en/24314).[^o2]

The problem remains NP-hard for [diameter](wikipedia://en/2979341) 2 graphs, since computing the vertex cover number is NP-hard for such graphs.[^o2]

The problem is NP-complete for trees,[^o7] resolving a long-standing open question. However, it can be solved in polynomial time for graphs of bounded [treewidth](wikipedia://en/3987086) and bounded diameter.[^o7]

## Specific graph families {#Specific_graph_families}

For [path graphs](wikipedia://en/4587190) $P_n$:

- $\chi_\rho(P_n) = 2$ for $2 \leq n \leq 3$
- $\chi_\rho(P_n) = 3$ for $n \geq 4$

For [cycle graphs](wikipedia://en/878962) $C_n$ with $n \geq 3$:

- $\chi_\rho(C_n) = 3$ if $n$ is $3$ or a multiple of $4$
- $\chi_\rho(C_n) = 4$ otherwise

For [trees](wikipedia://en/48560) $T$ of order $n$:[^o2]

- $\chi_\rho(T) \leq (n+7)/4$ for all trees except $P_4$ and two specific $8$-vertex trees
- The [star graph](https://en.wikipedia.org/wiki/Star_graph) $K_{1,n-1}$ has $\chi_\rho(K_{1,n-1}) = 2$
- Trees of [diameter](wikipedia://en/2979341) $3$ have $\chi_\rho(T) = 3$
- The bound $(n+7)/4$ is sharp and achieved by specific tree constructions

For the [hypercube graph](wikipedia://en/6706815) $Q_k$[^o2][^o10]

- $\chi_\rho(Q_k) \sim \frac{1}{2} \cdot O(1/k) \cdot 2^k$ asymptotically
- With $k = 1, 2, 3, 4$...:

$\chi_\rho(Q_k) = 2, 3, 5, 7, 15, 25, 49, 95$...

For [complete graphs](wikipedia://en/85816) $K_n$:

- $$\chi_\rho(K_n) = n$$
- $\chi_\rho(S(K_n)) = n + 1$ for $n \geq 3$

For [bipartite graphs](wikipedia://en/244431) $G$ of diameter $3$:

$$\alpha_0(G) \leq \chi_\rho(G) \leq \alpha_0(G) + 1$$

For [complete multipartite graphs](https://en.wikipedia.org/wiki/Complete_multipartite_graph) and [wheel graphs](wikipedia://en/1655876) $G$:

$$\chi_\rho(G) = \alpha_0(G) + 1$$

For the $r \times c$ [grid graph](https://en.wikipedia.org/wiki/Grid_graph) $G_{r,c}$:[^o2][^o11]

- $\chi_\rho(G_{2,c}) = 5$ for $c \geq 6$
- $\chi_\rho(G_{3,c}) = 7$ for $c \geq 12$
- $\chi_\rho(G_{4,c}) = 8$ for $c \geq 10$
- $\chi_\rho(G_{5,c}) = 9$ for $c \geq 10$
- $\chi_\rho(G_{r,c}) \leq 23$ for any finite grid
- For $r = c = 1, 2, 3, 4$... (the [square grid graphs](wikipedia://en/2874853)):

$\chi_\rho(G_{r,c}) = 1, 3, 4, 5, 7, 8, 9, 9, 10, 11$...

The infinite [square grid](wikipedia://en/2874853) $G_{\infty,\infty}$ has:[^o11]

$$\chi_\rho(G_{\infty,\infty}) = 15$$

The infinite [hexagonal lattice](wikipedia://en/2868762) $H$ has:[^o7]

$$\chi_\rho(H) = 7$$

The infinite [triangular lattice](https://en.wikipedia.org/wiki/Triangular_lattice) has infinite packing chromatic number.[^o7]

For the [subdivision graph](https://en.wikipedia.org/wiki/Subdivision_graph) $S(G)$ of a graph $G$, obtained by subdividing every edge once:[^o13]

- For [connected graphs](https://en.wikipedia.org/wiki/Connected_graph) $G$ with at least 3 vertices:

$$\omega(G) + 1 \leq \chi_\rho(S(G)) \leq \chi_\rho(G) + 1$$

- For connected bipartite graphs with at least two edges:

$$\chi_\rho(S(G)) = 3$$

### Graph products {#Graph_products}

For [Cartesian products](wikipedia://en/2856852) $G \square H$ of connected graphs $G$ and $H$ with at least two vertices:[^o13]

$$\chi_\rho(G \square H) \geq (\chi_\rho(G) + 1)|H| - \text{diam}(G \square H)(|H| - 1) - 1$$

For the Cartesian product with complete graphs:[^o13]

$$\chi_\rho(G \square K_n) \geq n\chi_\rho(G) - (n-1)\text{diam}(G)$$

::: {#o15 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

A connected graph $G$ has $\chi_\rho(G) = 2$ if and only if $G$ is a star.

A graph has $\chi_\rho(G) = 3$ if and only if it can be formed by taking a bipartite multigraph, subdividing every edge exactly once, adding leaves to some vertices, and performing a single $T$-add operation to some vertices.[^o2]

:::

::: {#o17 .application cue=heading name="Applications"}

## Applications {#Applications}

Packing colorings model frequency assignment problems in broadcasting, where radio stations must be assigned frequencies such that stations with the same frequency are sufficiently far apart to avoid interference. The distance requirement increases with the power of the broadcast signal.[^o2]

:::

## Related concepts {#Related_concepts}

- **Dominating broadcast**: A function $b : V \to \{0,1,\ldots\}$ where $b(u) \leq e(u)$ (eccentricity) and every vertex with $b(v) = 0$ has a neighbor $u$ with $b(u) > 0$ and $d(u,v) \leq b(u)$
- **Broadcast independence**: A broadcast where $b(u), b(v) > 0$ implies $d(u,v) > b(u)$
- **$S$-packing coloring** (or **$(s_1,s_2,\ldots,s_k)$-coloring**): For a non-decreasing sequence $S = (s_1, s_2, \ldots)$ of positive integers, vertices in color class $i$ must be at distance greater than $s_i$ apart. The standard packing coloring corresponds to $S = (1, 2, 3, \ldots)$. The $S$-packing chromatic number $\chi_S(G)$ is the minimum number of colors needed.[^o2][^o7]
