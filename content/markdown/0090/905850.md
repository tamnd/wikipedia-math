# Supermodular function

::: {#o1 .subject cue=lead name="Supermodular function"}

In mathematics, a **supermodular function** is a function on a [lattice](wikipedia://en/469304) that, informally, has the property of being characterized by "increasing differences." Seen from the point of [set functions](wikipedia://en/25911217), this can also be viewed as a relationship of "increasing returns", where adding more elements to a subset increases its valuation. In [economics](https://en.wikipedia.org/wiki/Economics), supermodular functions are often used as a formal expression of complementarity in preferences among goods. Supermodular functions are studied and have applications in [game theory](wikipedia://en/11924), [economics](https://en.wikipedia.org/wiki/Economics), [lattice theory](wikipedia://en/469304), [combinatorial optimization](wikipedia://en/420555), and [machine learning](wikipedia://en/233488).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(X, \preceq)$ be a [lattice](wikipedia://en/469304). A real-valued function $f: X \rightarrow \mathbb{R}$ is called **supermodular** if $f(x \vee y) + f(x \wedge y) \geq f(x) + f(y)$

for all $x, y \in X$.[^o4]

If the inequality is strict, then $f$ is **strictly supermodular** on $X$. If $-f$ is (strictly) supermodular then *f* is called (**strictly) submodular**. A function that is both submodular and supermodular is called **modular**. This corresponds to the inequality being changed to an equality.

We can also define supermodular functions where the underlying lattice is the vector space $\mathbb{R}^n$. Then the function $f : \mathbb{R}^n \to \mathbb{R}$ is **supermodular** if

$$f(x \uparrow y) + f(x \downarrow y) \geq f(x) + f(y)$$

for all $x$, $y \in \mathbb{R}^{n}$, where $x \uparrow y$ denotes the componentwise maximum and $x \downarrow y$ the componentwise minimum of $x$ and $y$.

If *f* is twice continuously differentiable, then supermodularity is equivalent to the condition[^o5]

$$\frac{\partial ^2 f}{\partial z_i\, \partial z_j} \geq 0 \mbox{ for all } i \neq j.$$

:::

## Supermodularity in economics and game theory {#Supermodularity_in_economics_and_game_theory}

The concept of supermodularity is used in the social sciences to analyze how one [agent's](https://en.wikipedia.org/wiki/Agent_%28economics%29) decision affects the incentives of others.

Consider a [symmetric game](https://en.wikipedia.org/wiki/Symmetric_game) with a smooth payoff function $\,f$ defined over actions $\,z_i$ of two or more players $i \in {1,2,\dots,N}$. Suppose the action space is continuous; for simplicity, suppose each action is chosen from an interval: $z_i \in [a,b]$. In this context, supermodularity of $\,f$ implies that an increase in player $\,i$'s choice $\,z_i$ increases the marginal payoff $df/dz_j$ of action $\,z_j$ for all other players $\,j$. That is, if any player $\,i$ chooses a higher $\,z_i$, all other players $\,j$ have an incentive to raise their choices $\,z_j$ too. Following the terminology of Bulow, [Geanakoplos](https://en.wikipedia.org/wiki/John_Geanakoplos), and [Klemperer](https://en.wikipedia.org/wiki/Paul_Klemperer) (1985), economists call this situation [strategic complementarity](wikipedia://en/12645144), because players' strategies are complements to each other.[^o7] This is the basic property underlying examples of [multiple equilibria](https://en.wikipedia.org/wiki/General_equilibrium#Uniqueness) in [coordination games](https://en.wikipedia.org/wiki/Coordination_game).[^o8]

The opposite case of supermodularity of $\,f$, called submodularity, corresponds to the situation of [strategic substitutability](wikipedia://en/12645144). An increase in $\,z_i$ lowers the marginal payoff to all other player's choices $\,z_j$, so strategies are substitutes. That is, if $\,i$ chooses a higher $\,z_i$, other players have an incentive to pick a *lower* $\,z_j$.

For example, Bulow et al. consider the interactions of many [imperfectly competitive](https://en.wikipedia.org/wiki/Imperfect_competition) firms. When an increase in output by one firm raises the marginal revenues of the other firms, production decisions are strategic complements. When an increase in output by one firm lowers the marginal revenues of the other firms, production decisions are strategic substitutes.

A supermodular [utility function](https://en.wikipedia.org/wiki/Utility_function) is often related to [complementary goods](https://en.wikipedia.org/wiki/Complementary_goods). However, this view is disputed.[^o9]

## Supermodular set functions {#Supermodular_set_functions}

Supermodularity can also be defined for [set functions](wikipedia://en/25911217), which are functions defined over subsets of a larger set. Many properties of [submodular set functions](wikipedia://en/33273315) can be rephrased to apply to supermodular set functions.

Intuitively, a supermodular function over a set of subsets demonstrates "increasing returns". This means that if each subset is assigned a real number that corresponds to its value, the value of a subset will always be less than the value of a larger subset which contains it. Alternatively, this means that as we add elements to a set, we increase its value.

::: {#o12 .definition cue=heading name="Definition"}

### Definition {#Definition}

Let $S$ be a finite set. A set function $f: 2^S \to \mathbb{R}$ is **supermodular** if it satisfies the following (equivalent) conditions:[^o13]

1. $f(A)+f(B) \leq f(A \cap B) + f(A \cup B)$ for all $A, B \subseteq S$.
1. $f(A \cup \{v\}) - f(A) \leq f(B \cup \{v\}) - f(B)$ for all $A \subset B \subset V$, where $v \notin B$.

A set function $f$ is submodular if $-f$ is supermodular, and modular if it is both supermodular and submodular.

:::

### Additional Facts {#Additional_Facts}

- If $f$ is modular and $g$ is submodular, then $f-g$ is a supermodular function.
- A non-negative supermodular function is also a superadditive function.
