# SimFiT

::: {#o2 .subject cue=lead name="SimFiT"}

**Simfit** is a free [open-source](https://en.wikipedia.org/wiki/Open-source_software) [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) package for simulation, curve fitting, statistics, and [plotting](https://simfit.uk/simfit.html), using a library of models or user-defined mathematical [equations](https://simfit.uk/user_defined_models.html). Simfit has been developed by Bill Bardsley of the [University of Manchester](https://en.wikipedia.org/wiki/University_of_Manchester).[^o5] Although it is written for Windows, it can easily be installed and used on Linux machines via [WINE](https://en.wikipedia.org/wiki/Wine_%28software%29).[^o3]

:::

Simfit is developed using [Silverfrost Limited's](http://www.silverfrost.com) [FTN95](https://en.wikipedia.org/wiki/Silverfrost_FTN95) Fortran Compiler and is currently featured on their website as a [showcased application](http://www.silverfrost.com/37/ftn95/ftn95_showcase.aspx). The graphical functionality in Simfit has been released as a Fortran library called [Simdem](https://simfit.uk/simdem.html) which allows the programmer to produce charts and graphs with just a few lines of Fortran. A version of Simdem is shipped with the Windows version of the NAG Fortran Builder.[^o6]

A Spanish-language version of Simfit is maintained by a team in [Salamanca](https://en.wikipedia.org/wiki/Salamanca).

At Version 8.1.1 a simplified version of simfit called sv\_simfit designed for first-time users is bundled with the main simfit package.
