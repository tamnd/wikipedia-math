# Kurosh problem

::: {#o1 .subject cue=lead name="Kurosh problem"}

In [mathematics](wikipedia://en/18831), the **Kurosh problem** is one general problem, and several more special questions, in [ring theory](wikipedia://en/250424). The general problem is known to have a negative solution, since one of the special cases has been shown to have [counterexamples](wikipedia://en/143151). These matters were brought up by [Aleksandr Gennadievich Kurosh](https://en.wikipedia.org/wiki/Aleksandr_Gennadievich_Kurosh) as analogues of the [Burnside problem](wikipedia://en/151452) in [group theory](wikipedia://en/41890).

:::

Kurosh asked whether there can be a finitely-generated infinite-dimensional [algebraic algebra](https://en.wikipedia.org/wiki/Algebraic_algebra) (the problem being to show this cannot happen). A special case is whether or not every [nil algebra](https://en.wikipedia.org/wiki/Nil_algebra) is [locally nilpotent](wikipedia://en/3100179). For [PI-algebras](https://en.wikipedia.org/wiki/PI-algebra) the Kurosh problem has a positive solution.

[Golod](https://en.wikipedia.org/wiki/Evgeny_Golod) showed a counterexample to that case, as an application of the [Golod–Shafarevich theorem](wikipedia://en/8845470).

The Kurosh problem on [group algebras](wikipedia://en/349223) concerns the [augmentation ideal](wikipedia://en/2224774) *I*. If *I* is a [nil ideal](wikipedia://en/3100140), is the group algebra locally nilpotent?

There is an important problem which is often referred as the Kurosh's problem on [division rings](wikipedia://en/9067). The problem asks whether there exists an algebraic (over the [center](wikipedia://en/53796787)) division ring which is not locally finite. This problem has not been solved until now.
