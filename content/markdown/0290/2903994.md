# Upper and lower sets

::: {#o1 .subject cue=lead name="Upper and lower sets"}

*Image: Upset\_210div.svg.* A [Hasse diagram](wikipedia://en/338199) of the [divisors](wikipedia://en/49492) of $210$, ordered by the relation *is divisor of*, with the upper set $\uparrow 2$ colored green. The white sets form the lower set $\downarrow 105.$

In [mathematics](wikipedia://en/18831), an **upper set** $S$ of a [partially ordered set](wikipedia://en/23572) $X$ is a subset such that if *s* is in *S* and if *x* in *X* is larger than *s*, then *x* is in *S*. A **lower set** is defined similarly as being a subset *S* of *X* with the property that any element *x* of *X* that precedes an element of *S* is necessarily also an element of *S*.

:::

Upper sets and lower sets are also known by many other names. An upper set may also be called an **upward closed set**, an **up-set**, an *isotone set*, or an *order filter*, while a lower set may also be called a **downward closed set**, **down-set**, *decreasing set*, *semi-ideal*, or *order ideal*.[^n1][^o3] However, the terms "order ideal" and "order filter" are also used for a more restrictive notion.[^o9]

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(X, \leq)$ be a [preordered set](https://en.wikipedia.org/wiki/Preordered_set) (the same as a partially ordered set except the requirement $x \le y, \, y \le x$ implying $x = y$ is dropped).

An upper set in $X$ (also called an upward closed set, up set, increasing set, or an isotone set)[^n1] is a subset $U$ that is "closed under going up", in the following sense: for all $u$ in $U$ and $x$ in $X$, if $u \le x$, then $x$ is in $U$.

The [dual](wikipedia://en/600618) notion is a lower set (also called a downward closed set, down set, decreasing set, or a semi-ideal), which is a subset $L$ that is "closed under going down": for all $l$ in $L$ and all $x$ in $X$, if $x \leq l$, then $x$ is in $L.$

The term order ideal is sometimes used as a synonym for a lower set.[^o7][^o3][^o8] However, an [ideal](wikipedia://en/530559) is also commonly defined specifically as a lower set which is [upward directed](wikipedia://en/9165).[^o9][^o10] Dually, a [filter](wikipedia://en/19719) is an upper set that is directed downward (that is, every finite subset has a lower bound).

For a [well-ordered set](https://en.wikipedia.org/wiki/Well-ordered_set), a lower set is usually called an *[initial segment](https://en.wikipedia.org/wiki/Initial_segment)*.

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The following properties are stated in terms of upper sets; the corresponding dual properties for lower sets also hold.

- Every preordered set is an upper set of itself.
- The [intersection](wikipedia://en/23476429) and the [union](wikipedia://en/47949) of any family of upper sets is again an upper set.
- The [complement](wikipedia://en/54347) of an upper set is a lower set, and vice versa.
- Given a partially ordered set $(X, \leq),$ the family of upper sets of $X$ ordered with the [inclusion](https://en.wikipedia.org/wiki/Inclusion_%28set_theory%29) relation is a [complete lattice](wikipedia://en/44777), the **upper set lattice**.
- Every upper set $Y$ of a finite partially ordered set $X$ is equal to the smallest upper set containing all [minimal elements](https://en.wikipedia.org/wiki/Minimal_element) of $Y.$
- For partial orders satisfying the [descending chain condition](https://en.wikipedia.org/wiki/Descending_chain_condition), [antichains](wikipedia://en/348973) and upper sets are in one-to-one correspondence via the following [bijections](https://en.wikipedia.org/wiki/Bijections): map each antichain to its upper closure (see below); conversely, map each upper set to the set of its minimal elements. This correspondence does not hold for more general partial orders; for example the sets of [real numbers](wikipedia://en/20646438) $\{ x \in \mathbb{R}: x > 0 \}$ and $\{ x \in \mathbb{R}: x > 1 \}$ are both mapped to the empty antichain.

:::

::: {#o14 .example cue=heading name="Examples"}

## Examples {#Examples}

Upper sets and lower sets appear in various fields of mathematics.

- In the totally ordered set of the [real numbers](wikipedia://en/20646438) $(\mathbb{R},\le)$, lower sets include "left rays" like $(-\infty,3]$ and $(-\infty,5)$, as well as the empty set $\emptyset$ and the whole set. Upper sets include "right rays" like $(3,\infty)$ and $[5,\infty)$.
- In real analysis, a [real number](wikipedia://en/20646438) is often defined as a [Dedekind cut](wikipedia://en/45569). By definition, this is a nonempty proper lower subset of $\mathbb{Q}$ with no maximal element.
- Let $X$ be a topological space and $x$ a point in it. Let $F$ be the set of all (not-necessarily-open) neighborhoods of $x$. Then $F$ is an upper set in the [power set](wikipedia://en/23799) of $X$ ordered by inclusion, since any set containing a neighborhood of the point is a neighborhood of that point.
- Any [filter on a set](wikipedia://en/12646549) $X$ is an upper set in the power set of $X$ ordered by inclusion. The previous example of the [neighbourhood filter](https://en.wikipedia.org/wiki/Neighbourhood_filter) of a point in a topological space is an instance of this.
- [Abstract simplicial complex](wikipedia://en/723105) - a set-family that is downwards-closed with respect to the containment relation.

:::

## Upper closure and lower closure {#Upper_closure_and_lower_closure}

Given an element $x$ of a preordered set $(X, \leq),$ the **upper closure** or **upward closure** of $x$ is defined by

$$\uparrow\! x = \{ u \in X : x \leq u\}$$

while the **lower closure** or **downward closure** of $x$ by

$\downarrow\! x = \{l \in X : l \leq x\}.$[^o17]

Upper and lower sets of the form $\uparrow\! x$ and $\downarrow\! x$ are called **principal**. The upper closure of an element is the same thing as the [principal filter](https://en.wikipedia.org/wiki/Principal_filter) generated by that element, since it is also directed downward.

More generally, given a subset $A \subset X,$ the upper closure and lower closure of $A$ are defined as $\uparrow\! A = \bigcup_{a \in A} \uparrow\!a$ and $\downarrow\! A = \bigcup_{a \in A} \downarrow\!a$;[^o17] they are, respectively, the smallest upper set and lower set containing $A$. The upper and lower closures, when viewed as functions from the power set of $X$ to itself, are examples of [Kuratowski closure operators](https://en.wikipedia.org/wiki/Kuratowski_closure_operator). As a result, the upper closure of a set is equal to the intersection of all upper sets containing it, and similarly for lower sets.

In [category theory](wikipedia://en/5869), a poset can be (and often is) viewed as a category by writing a morphism $x \to y$ if and only if $x \le y$. Then the lower closure $\downarrow x$ corresponds to the [slice category](https://en.wikipedia.org/wiki/Slice_category) over $x$, while the upper closure that under $x$.[^o18]

Let $X$ be a poset. Then we have[^o19]

$$\eta : X \hookrightarrow \mathfrak{P}(X)$$

where $\mathfrak{P}(X)$ is the power set of $X$ and $\eta(x) = {\downarrow\! x}$ is the lower closure of $x$. The map $\eta$ is an embedding in the sense it is injective and monotone:

$x \le y \Longleftrightarrow {\downarrow\! x} \subseteq {\downarrow\! y}.$[^o20]

Thus, the above construction can be used to replace a given ordering by set inclusion and also yields advantages such as that a least upper bound always exists (possibly outside the image of $\eta$); namely, a union. For example, this trick can be used to reduce a proof of [Zorn's lemma](wikipedia://en/51442) to the case of posets of sets.[^o21]

As Paul Taylor points out, the above $\eta$ is an analog of an embedding in the [Yoneda lemma](wikipedia://en/34359) in category theory.[^o22][^o23]

The image of $\eta$ lies in the set of all lower sets in $X$. But, more specifically, it lies in the set of all *directed* lower sets (ideals), denoted by $I(X)$ and called the [ideal completion](https://en.wikipedia.org/wiki/Ideal_completion) of $X$.[^o24] Then $\eta : X \hookrightarrow I(X)$ satisfies the universal property that makes $I$ a [free functor](https://en.wikipedia.org/wiki/Free_functor) in the sense: it is left adjoint to the forgetful functor from the category of [dcpos](https://en.wikipedia.org/wiki/Dcpo_%28order_theory%29) to the category of posets.[^o25]

:::

## Scott topology {#Scott_topology}

A function between posets is said to be [Scott-continuous](https://en.wikipedia.org/wiki/Scott-continuous) if it is monotone (it preserves $\le$) and preserves directed sups.[^o27] Then a poset $X$ carries a topology where a subset $U$ is open if and only if the characteristic function on $U$ is Scott-continuous. This topology is called the [Scott topology](https://en.wikipedia.org/wiki/Scott_topology). Explicitly, an open set in this topology is exactly an upper set such that if $\textstyle \sup_i x_i \in U$ for a directed set $x_i$, then $x_i$ is in $U$ for some $i$.[^o28] The intuition here is that a sup corresponds to the best approximation and so if the best approximation is available in the set, some finite approximation is already in that set.

The Scott topology appears prominently in [domain theory](wikipedia://en/325077), a branch of order theory with a strong connection to computer science. Like the Zariski topology used in algebraic geometry, the Scott topology is an important example of a non-[Hausdorff topological space](https://en.wikipedia.org/wiki/Hausdorff_topological_space).

::: {#o30 .statement kind=statement/theorem cue=named-heading name="Birkhoff's theorem"}

## Birkhoff's theorem {#Birkhoff's_theorem}

The set of all lower sets of a given poset $P$ may be ordered by inclusion. The resulting poset, denoted $J(P)$, is a [lattice](https://en.wikipedia.org/wiki/Lattice_%28order_theory%29) (meaning that every subset of $J(P)$ has a least upper bound and a greatest lower bound), and indeed a [distributive lattice](wikipedia://en/310883) (meaning that the two operations of least upper bound and greatest lower bound distribute over one another). [Birkhoff's representation theorem](wikipedia://en/20489385) asserts that every finite distributive lattice arises (up to isomorphism) in this way as the lattice of lower sets of a unique finite poset.

:::

## Related notions {#Related_notions}

- [Cofinal set](https://en.wikipedia.org/wiki/Cofinal_set) – a subset $U$ of a partially ordered set $(X, \leq)$ that contains for every element $x \in X,$ some element $y$ such that $x \leq y.$
