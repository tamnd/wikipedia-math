# Semifield

::: {#o1 .subject cue=lead name="Semifield"}

In [mathematics](wikipedia://en/18831), a **semifield** is an [algebraic structure](wikipedia://en/106364) with two [binary operations](wikipedia://en/3948), addition and multiplication, which is similar to a [field](wikipedia://en/10603), but with some axioms relaxed.

:::

## Overview {#Overview}

The term semifield has two conflicting meanings, both of which include fields as a special case.

- In [projective geometry](wikipedia://en/243849) and [finite geometry](wikipedia://en/267061) ([MSC](wikipedia://en/3008091) 51A, 51E, 12K10), a **semifield** is a [nonassociative division ring](wikipedia://en/26549625#Not_necessarily_associative_division_algebras) with multiplicative identity element.[^o9] More precisely, it is a [nonassociative ring](https://en.wikipedia.org/wiki/Nonassociative_algebra) whose nonzero elements form a [loop](https://en.wikipedia.org/wiki/Loop_%28algebra%29) under multiplication. In other words, a semifield is a set *S* with two operations + (addition) and · (multiplication), such that
  - (*S*,+) is an [abelian group](wikipedia://en/2974),
  - multiplication is [distributive](wikipedia://en/103118) on both the left and right,
  - there exists a multiplicative [identity element](wikipedia://en/14962), and
  - [division](wikipedia://en/53696) is always possible: for every *a* and every nonzero *b* in *S*, there exist unique *x* and *y* in *S* for which *b*·*x* = *a* and *y*·*b* = *a*.

Note in particular that the multiplication is not assumed to be [commutative](wikipedia://en/294390) or [associative](wikipedia://en/1335). A semifield that is associative is a [division ring](wikipedia://en/9067), and one that is both associative and commutative is a [field](wikipedia://en/10603). A semifield by this definition is a special case of a [quasifield](wikipedia://en/4029839). If *S* is finite, the last axiom in the definition above can be replaced with the assumption that there are no [zero divisors](wikipedia://en/51441), so that *a*⋅*b* = 0 implies that *a* = 0 or *b* = 0.[^o8] Note that due to the lack of associativity, the last axiom is *not* equivalent to the assumption that every nonzero element has a multiplicative inverse, as is usually found in definitions of fields and division rings.

- In [ring theory](wikipedia://en/250424), [combinatorics](wikipedia://en/5170), [functional analysis](wikipedia://en/11180), and [theoretical computer science](wikipedia://en/323392) ([MSC](wikipedia://en/3008091) 16Y60), a **semifield** is a [semiring](wikipedia://en/371468) (*S*,+,·) in which all nonzero elements have a multiplicative inverse.[^o10][^o11] These objects are also called **proper semifields**. A variation of this definition arises if *S* contains an absorbing zero that is different from the multiplicative unit *e*, it is required that the non-zero elements be invertible, and *a*·0 = 0·*a* = 0. Since multiplication is [associative](https://en.wikipedia.org/wiki/Associative), the (non-zero) elements of a semifield form a [group](wikipedia://en/19447). However, the pair (*S*,+) is only a [semigroup](wikipedia://en/27799), i.e. additive inverse need not exist, or, colloquially, 'there is no subtraction'. Sometimes, it is not assumed that the multiplication is associative.

## Primitivity of semifields {#Primitivity_of_semifields}

A semifield D is called right (resp. left) primitive if it has an element w such that the set of nonzero elements of D\* is equal to the set of all right (resp. left) principal powers of w.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

We only give examples of semifields in the second sense, i.e. additive semigroups with distributive multiplication. Moreover, addition is commutative and multiplication is associative in our examples.

- [Positive](wikipedia://en/7951270) [rational numbers](https://en.wikipedia.org/wiki/Rational_numbers) with the usual addition and multiplication form a commutative semifield.

This can be extended by an absorbing 0.

- [Positive real numbers](wikipedia://en/47172571) with the usual addition and multiplication form a commutative semifield.

This can be extended by an absorbing 0, forming the [probability semiring](https://en.wikipedia.org/wiki/Probability_semiring), which is isomorphic to the [log semiring](wikipedia://en/37563991).

- [Rational functions](wikipedia://en/361210) of the form *f* /*g*, where *f* and *g* are [polynomials](wikipedia://en/23000) over a subfield of real numbers in one variable with positive coefficients, form a commutative semifield.

This can be extended to include 0.

- The [real numbers](https://en.wikipedia.org/wiki/Real_numbers) **R** can be viewed a semifield where the sum of two elements is defined to be their maximum and the product to be their ordinary sum; this semifield is more compactly denoted (**R**, max, +). Similarly (**R**, min, +) is a semifield. These are called the [tropical semiring](wikipedia://en/3892336).

This can be extended by −∞ (an absorbing 0); this is the limit ([tropicalization](https://en.wikipedia.org/wiki/Tropicalization)) of the [log semiring](wikipedia://en/37563991) as the base goes to infinity.

- Generalizing the previous example, if (*A*,·,≤) is a [lattice-ordered group](https://en.wikipedia.org/wiki/Lattice_ordered_group) then (*A*,+,·) is an additively [idempotent](https://en.wikipedia.org/wiki/Idempotent) semifield with the semifield sum defined to be the [supremum](https://en.wikipedia.org/wiki/Supremum) of two elements. Conversely, any additively idempotent semifield (*A*,+,·) defines a lattice-ordered group (*A*,·,≤), where *a*≤*b* if and only if *a* + *b* = *b*.
- The Boolean semifield **B** = {0, 1} with addition defined by [logical or](https://en.wikipedia.org/wiki/Logical_or), and multiplication defined by [logical and](https://en.wikipedia.org/wiki/Logical_and).
