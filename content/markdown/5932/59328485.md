# Cyclic and separating vector

::: {#o1 .subject cue=lead name="Cyclic and separating vector"}

In [mathematics](wikipedia://en/18831), the notion of a **cyclic and separating vector** is important in the theory of [von Neumann algebras](wikipedia://en/294185),[^o2][^o3] and, in particular, in [Tomita–Takesaki theory](wikipedia://en/2898625). A related notion is that of a vector that is [cyclic](wikipedia://en/58713633) for a given operator. The existence of cyclic vectors is guaranteed by the [Gelfand–Naimark–Segal (GNS) construction](wikipedia://en/297446).

:::

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Given a [Hilbert space](wikipedia://en/20598932) *H* and a linear space *A* of [bounded linear operators](https://en.wikipedia.org/wiki/Bounded_linear_operator) in *H*, an element Ω of *H* is said to be *cyclic* for *A* if the linear space *A*Ω = {*a*Ω: *a* ∈ *A*} is norm-dense in *H*. The element Ω is said to be *separating* if *a*Ω = 0 for *a* in *A* implies that *a* = 0. Note that:

- Any element Ω of *H* defines a [semi-norm](https://en.wikipedia.org/wiki/Semi-norm) *p* on *A*, with *p*(*a*) = ||*a*Ω||. The statement that "Ω is separating" is then equivalent to the statement that *p* is actually a [norm](wikipedia://en/990534).
- If Ω is cyclic for *A*, then it is separating for the commutant *A′* of *A* in *B*(*H*), which is the [von Neumann algebra](wikipedia://en/294185) consisting of all [bounded operators](wikipedia://en/455961) in *H* that commute with all elements of *A*, where *A* is a subset of *B*(*H*). In particular, if *a* belongs to the commutant *A′* and satisfies *a*Ω = 0 for some Ω, then for all *b* in *A*, we have that 0 = *ba*Ω = *ab*Ω. Because the subspace *b*Ω for *b* in *A* is dense in the Hilbert space *H*, this implies that *a* vanishes on a dense subspace of *H*. By continuity, this implies that *a* vanishes everywhere. Hence, Ω is separating for *A′*.

The following, stronger result holds if *A* is a [\*-algebra](wikipedia://en/293426) (an algebra that is closed under [adjoints](wikipedia://en/667175)) and unital (i.e., contains the identity operator **1**). For a proof, see Proposition 5 of Part I, Chapter 1 of *von Neumann algebras*.[^o3]

::: {#o6 .statement kind=statement/proposition cue=inline-head name="Proposition"}

***Proposition*** If *A* is a [\*-algebra](wikipedia://en/293426) of [bounded linear operators](https://en.wikipedia.org/wiki/Bounded_linear_operator) on *H* and **1** belongs to *A*, then Ω is cyclic for *A* if and only if it is separating for the commutant *A′*.

A special case occurs when *A* is a [von Neumann algebra](wikipedia://en/294185), in which case a vector Ω that is cyclic and separating for *A* is also cyclic and separating for the commutant *A′*.

:::

:::

## Positive linear functionals {#Positive_linear_functionals}

A [positive linear functional](wikipedia://en/454930) *ω* on a [\*-algebra](wikipedia://en/293426) *A* is said to be *faithful* if, for any [positive element](wikipedia://en/68445647) *a* in *A*, *ω*(*a*) = 0 implies that *a* = 0.

Every element Ω of the Hilbert space *H* defines a [positive linear functional](wikipedia://en/454930) *ω*<sub>Ω</sub> on a [\*-algebra](wikipedia://en/293426) *A* of [bounded linear operators](https://en.wikipedia.org/wiki/Bounded_linear_operator) on *H* via the inner product *ω*<sub>Ω</sub>(*a*) = (*a*Ω,Ω), for all *a* in *A*. If *ω*<sub>Ω</sub> is defined in this way and *A* is a [C\*-algebra](wikipedia://en/7184), then *ω*<sub>Ω</sub> is faithful if and only if the vector Ω is separating for *A*. Note that a [von Neumann algebra](wikipedia://en/294185) is a special case of a [C\*-algebra](wikipedia://en/7184).

::: {#o8 .statement kind=statement/proposition cue=inline-head name="Proposition"}

***Proposition*** Let *φ* and *ψ* be elements of *H* that are cyclic for *A*. Assume that *ω*<sub>*φ*</sub> = *ω*<sub>*ψ*</sub>. Then there exists an [isometry](wikipedia://en/254777) *U* in the commutant *A′* such that *φ* = *Uψ*.

:::
