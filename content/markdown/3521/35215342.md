# Gram's theorem

::: {#o1 .subject cue=lead name="Gram's theorem"}

In [mathematics](wikipedia://en/18831), **Gram's theorem** states that an [algebraic set](https://en.wikipedia.org/wiki/Algebraic_set) in a [finite-dimensional vector space](https://en.wikipedia.org/wiki/Finite-dimensional_vector_space) invariant under some [linear group](wikipedia://en/3983656) can be defined by [absolute invariants](https://en.wikipedia.org/wiki/Absolute_invariant). (, p. 31). It is named after [J. P. Gram](wikipedia://en/851232), who published it in 1874.

:::
