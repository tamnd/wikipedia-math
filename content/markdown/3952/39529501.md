# Centered dodecahedral number

::: {#o2 .subject cue=lead name="Centered dodecahedral number"}

In [mathematics](wikipedia://en/18831), a **centered dodecahedral number** is a [centered](https://en.wikipedia.org/wiki/Centered_number) [figurate number](wikipedia://en/325260) that represents a [dodecahedron](wikipedia://en/8407). The centered dodecahedral number for a specific *n* is given by

:::

$$(2n+1)\left(5n^2+5n+1\right)$$

The first such numbers are: [1](wikipedia://en/77591639), [33](https://en.wikipedia.org/wiki/33_%28number%29), [155](https://en.wikipedia.org/wiki/155_%28number%29), 427, 909, 1661, 2743, 4215, 6137, 8569, … .

## Congruence Relations {#Congruence_Relations}

- $$CDC(n) \equiv 1 \pmod{2}$$
- $$CDC(n) \equiv 1-n \pmod{3}$$
- $$CDC(n) \equiv 2n+1 \pmod{3,5,6,10}$$
