# Centered polyhedral number

::: {#o1 .subject cue=lead name="Centered polyhedral number"}

In [mathematics](wikipedia://en/18831), the **centered polyhedral numbers** are a class of [figurate numbers](wikipedia://en/325260), each formed by a central dot, surrounded by [polyhedral](wikipedia://en/23470) layers with a constant number of edges. The length of the edges increases by one in each additional layer.

:::
