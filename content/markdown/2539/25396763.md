# Zorich's theorem

::: {#o1 .subject cue=lead name="Zorich's theorem"}

In [mathematical analysis](wikipedia://en/48396), **Zorich's theorem** was proved by [Vladimir A. Zorich](wikipedia://en/48551031) in 1967.[^o2] The result was conjectured by [M. A. Lavrentev](https://en.wikipedia.org/wiki/Mikhail_Alekseevich_Lavrentev) in 1938.[^o3]

:::

::: {#o5 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

Every locally [homeomorphic](wikipedia://en/13660) [quasiregular mapping](wikipedia://en/34304924) $f : R^{n} \rightarrow R^{n}$ for $n \geq 3$, is a homeomorphism of $R^{n}$.[^o6]

The fact that there is no such result for $n = 2$ is easily shown using the [exponential function](wikipedia://en/9678).[^n1]

:::
