# Perfect Dark (P2P)

::: {#o5 .subject cue=lead name="Perfect Dark"}

**Perfect Dark** is a [peer-to-peer](https://en.wikipedia.org/wiki/Peer-to-peer) [file-sharing](https://en.wikipedia.org/wiki/File-sharing) (P2P) application from Japan designed for use with [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows). It was launched in 2006. Its [author](https://en.wikipedia.org/wiki/Software_developer) is known by the [pseudonym](https://en.wikipedia.org/wiki/Pseudonym) *Kaichō*. Perfect Dark was developed with the intention for it to be the successor to both [Winny](https://en.wikipedia.org/wiki/Winny) and [Share](https://en.wikipedia.org/wiki/Share_%28P2P%29) software.[^o6] While Japan's Association for Copyright of Computer Software reported that in January 2014, the number of nodes connected on Perfect Dark (24000) was less than on [Share](https://en.wikipedia.org/wiki/Share_%28P2P%29) (44000), but more than on [Winny](https://en.wikipedia.org/wiki/Winny) (12000),[^o7] Netagent in 2018 reported [Winny](https://en.wikipedia.org/wiki/Winny) being the largest with 50 000 nodes followed by Perfect Dark with 30 000 nodes followed by Share with 10 000.[^o8] Netagent asserts that the number of nodes on Perfect Dark have fallen since 2015 while the numbers of [Winny](https://en.wikipedia.org/wiki/Winny) hold steady. Netagent reports that users of Perfect Dark are most likely to share books/manga.

:::

As of version 1.02 (2008), code-named "Stand Alone Complex", there is support for the program to run in English, an option that can be selected when the program is installed.

## Overview {#Overview}

Perfect Dark is still being actively developed. The author does not ask that the program's users at this point become dedicated "users" of the software. Instead, the author asks them to participate in the [test phase](https://en.wikipedia.org/wiki/Software_release_life_cycle). Through this test phase, the author hopes for [bug](https://en.wikipedia.org/wiki/Software_bug) reports and discussion that will help shape Perfect Dark into a better program.

### DKT+DHT+DU {#DKT+DHT+DU}

The author implements an architecture called *DKT+DHT+DU* in the design of the network. These three parts compose the entire network.

- "DKT" stands for Distributed Keyword Table.
- "DHT" for [Distributed Hash Table](https://en.wikipedia.org/wiki/Distributed_Hash_Table).
- "DU" for [distributed](https://en.wikipedia.org/wiki/Distributed_data_store) Unity.

"DKT" is mainly for providing effective file searching while "DHT" and "DU" is used for effective file sharing and enhancing anonymity.

### Network bandwidth requirement {#Network_bandwidth_requirement}

Perfect Dark has higher [bandwidth](https://en.wikipedia.org/wiki/Bandwidth_%28computing%29) and [hard drive](https://en.wikipedia.org/wiki/Hard_disk_drive) space requirements than its predecessors [Winny](https://en.wikipedia.org/wiki/Winny) and [Share](https://en.wikipedia.org/wiki/Share_%28P2P%29). The minimum [upload](https://en.wikipedia.org/wiki/Upload) speed is 100 kbit/s.

Perfect Dark requires more network [bandwidth](https://en.wikipedia.org/wiki/Bandwidth_%28computing%29) and hard disk space than Winny or Share, forcing a fairer load on all users. If a user does not have Perfect Dark configured with the proper settings or if the user is unable to support the settings, download rates will be restricted and priority will be given to other users. This is intended to increase the retention rate of the Perfect Dark network.

### Disk space requirement {#Disk_space_requirement}

It requires to share at minimum 40 GB of hard drive space, for its "Unity" folder (a huge [distributed hash table](https://en.wikipedia.org/wiki/Distributed_hash_table) used as a [distributed data store](https://en.wikipedia.org/wiki/Distributed_data_store)).

### File system requirement {#File_system_requirement}

Perfect Dark requires [NTFS](https://en.wikipedia.org/wiki/NTFS) file system instead of [FAT32](https://en.wikipedia.org/wiki/FAT32), because FAT32 is limited to a file size of 4 GB, while Perfect Dark can download files up to the size of 32 GB.

## Features {#Features}

### Distributed datastore {#Distributed_datastore}

Like other Japanese sharing software, Perfect Dark has its own proprietary P2P network called "Unity".

One of the biggest characteristics of Perfect Dark is its powerful search capability. By using [distributed hash tables](https://en.wikipedia.org/wiki/Distributed_hash_table), search performance is greatly improved compared to [Winny](https://en.wikipedia.org/wiki/Winny) or [Share](https://en.wikipedia.org/wiki/Share_%28P2P%29), making it unnecessary to rely on the construction of [node](https://en.wikipedia.org/wiki/Node_%28networking%29) clusters. This frees users from inputting or switching cluster keywords and also enables users to search for files of different genres at the same time. This is in contrast to Winny and Share, where cluster keywords, such as "DVDISO" or "アニメ"/"anime" are used to specify what types of files the user is searching for. These keywords segregate the network and introduce delays when the user changes to them.

### File search: tree search {#File_search:_tree_search}

The concept of "[tree search](https://en.wikipedia.org/wiki/Tree_search)" brings about strong search ability. In addition, the flexible use of AND, OR and NOT [boolean operators](https://en.wikipedia.org/wiki/Boolean_operator_%28Boolean_algebra%29) helps filtering out undesirable results.

### Text flow {#Text_flow}

Perfect Dark includes an original feature named "flow": a window where text lines written by users [scroll](https://en.wikipedia.org/wiki/Scrolling) vertically. Each user can write one little message (few lines and columns), and it will be displayed to the other peers using the flow feature.

### Automated update {#Automated_update}

Since version 1.02 Perfect Dark has an option to automatically update itself through its own (Unity) network.

### Messages boards {#Messages_boards}

Perfect Dark has a simple [message board](https://en.wikipedia.org/wiki/Message_board) feature. The boards are distributed into Unity network. The design is rudimentary. To get boards, these must be searched with the file search feature, with (for example) the Japanese keyword ボード (board).

## Security {#Security}

The overall structure of the Perfect Dark network broadly resembles recent versions of [HyphaNet](wikipedia://en/10997), only with a heavier use of [distributed hash tables](https://en.wikipedia.org/wiki/Distributed_hash_tables).

The anonymity relies on a [mixnet](wikipedia://en/6200269) where traffic is forwarded according to certain probability, as well as the deniability of the [distributed data storage](https://en.wikipedia.org/wiki/Distributed_data_store) ("Unity") which is stored and transferred in encrypted blocks while the [keys](wikipedia://en/53039) are distributed separately.

Perfect Dark uses [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) (2048-bit) and [AES](wikipedia://en/1260) (128-bit) to [encrypt](https://en.wikipedia.org/wiki/Encrypt) data transmitted between peers. Exchanged keys are cached for efficiency.

Published files and boards (including automatic updates from the author, where enabled) are usually signed with 160-bit [ECDSA](https://en.wikipedia.org/wiki/ECDSA) signatures. Automatic updates of the software are additionally protected with a 2048-bit RSA signature.

The author believes that initially, a layer of obscurity due to the closed-source nature of the program will frustrate attempted attacks on its anonymity, as well as deter "free riders" and junk files degrading the network. However, the author has stated that it may become open-source in the future should an acceptable solution to these problems be found.

The Japanese security firm NetAgent is claiming (2010) that they have created software capable of deciphering encrypted information such as the [IP address](https://en.wikipedia.org/wiki/IP_address) of the original computer uploading a file as well as the file name and other details of Perfect Dark.[^o21][^o22]

## Legal issues {#Legal_issues}

- A Perfect Dark user was arrested for the first time on 27 January 2010. The user had been uploading and sharing an episode of the Japanese animated TV series *[Fullmetal Alchemist: Brotherhood](https://en.wikipedia.org/wiki/Fullmetal_Alchemist:_Brotherhood)* with Perfect Dark and was charged with breach of copyright law.[^o24]
- On 10 June 2010, a second user, a 43-year-old man, was arrested on the suspicion of uploading roughly one thousand [copyrighted](https://en.wikipedia.org/wiki/Copyright) files including the *[Big Windup!](https://en.wikipedia.org/wiki/Big_Windup!)* anime series.[^o25]
- On 8 October 2010, a 42-year-old woman was arrested for uploading the *[Mitsudomoe](https://en.wikipedia.org/wiki/Mitsudomoe_%28manga%29)* anime television series.[^o26]
