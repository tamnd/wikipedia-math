# Cryptographic splitting

::: {#o1 .subject cue=lead name="Cryptographic splitting"}

**Cryptographic splitting**, also known as cryptographic bit splitting or cryptographic data splitting, is a technique for securing data over a [computer network](https://en.wikipedia.org/wiki/Computer_network). The technique involves encrypting data, splitting the encrypted data into smaller data units, distributing those smaller units to different storage locations, and then further encrypting the data at its new location.[^o2] With this process, the data is protected from security breaches, because even if an intruder is able to retrieve and decrypt one data unit, the information would be useless unless it can be combined with decrypted data units from the other locations.

:::

## History {#History}

The technology was filed for patent consideration in June 2003, and the patent was granted in June 2008.[^o2]

## Technology {#Technology}

Cryptographic splitting utilizes a combination of different algorithms to provide the data protection. A block of data is first encrypted using the [AES-256](https://en.wikipedia.org/wiki/AES-256) government encryption standard. The encrypted bits are then split into different shares and then each share is [hashed](wikipedia://en/439526) using the [National Security Agency](wikipedia://en/21939)'s [SHA-256](https://en.wikipedia.org/wiki/SHA-256) algorithm.[^o5]

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

One application of cryptographic splitting is to provide security for [cloud computing](https://en.wikipedia.org/wiki/Cloud_computing). The encrypted data subsets can be stored on different clouds, with the information required to restore the data being held on a [private cloud](https://en.wikipedia.org/wiki/Private_cloud) for additional security.[^o8] Security vendor Security First Corp uses this technology for its Secure Parser Extended (SPx) product line.

In 2009, technology services company [Unisys](https://en.wikipedia.org/wiki/Unisys) gave a presentation about using cryptographic splitting with [storage area networks](https://en.wikipedia.org/wiki/Storage_area_networks). By splitting the data into different parts of the storage area network, this technique provided [data redundancy](https://en.wikipedia.org/wiki/Data_redundancy) in addition to security.[^o5]

Computer giant [IBM](https://en.wikipedia.org/wiki/IBM) has written about using the technology as part of its Cloud Data Encryption Services (ICDES).[^o9]

The technology has also been written about in the context of more effectively using sensitive corporate information, by entrusting different individuals within a company (trustees) with different parts of the information.[^o10]
