# Maxwell's theorem

::: {#o1 .subject cue=lead name="Maxwell's theorem"}

In [probability theory](wikipedia://en/23542), **Maxwell's theorem** (known also as **Herschel-Maxwell's theorem** and **Herschel-Maxwell's derivation**) states that if the [probability distribution](wikipedia://en/23543) of a random vector in $\mathbb{R}^n$ is unchanged by rotations, and if the components are independent, then the components are identically distributed and normally distributed.

:::

## Equivalent statements {#Equivalent_statements}

If the probability distribution of a [vector](wikipedia://en/32370)-valued [random variable](wikipedia://en/25685) *X* = ( *X*<sub>1</sub>, ..., *X*<sub>*n*</sub> )<sup>*T*</sup> is the same as the distribution of *GX* for every *n*×*n* [orthogonal matrix](wikipedia://en/105620) *G* and the components are [independent](https://en.wikipedia.org/wiki/Statistical_independence), then the components *X*<sub>1</sub>, ..., *X*<sub>*n*</sub> are [normally distributed](wikipedia://en/21462) with [expected value](wikipedia://en/9653) 0 and all have the same [variance](wikipedia://en/32344). This theorem is one of many [characterizations](wikipedia://en/780886) of the normal distribution.

The only rotationally invariant probability distributions on **R**<sup>*n*</sup> that have independent components are [multivariate normal distributions](wikipedia://en/50347) with [expected value](wikipedia://en/9653) **0** and [variance](wikipedia://en/32344) *σ*<sup>2</sup>*I*<sub>*n*</sub>, (where *I*<sub>*n*</sub> = the *n*×*n* identity matrix), for some positive number *σ*<sup>2</sup>.

## History {#History}

[John Herschel](https://en.wikipedia.org/wiki/John_Herschel) proved the theorem in 1850.[^o4][^o5] Ten years later, [James Clerk Maxwell](wikipedia://en/28989696) proved the theorem in Proposition IV of his 1860 paper.[^o6][^o7]

::: {#o9 .proof cue=heading name="Proof"}

## Proof {#Proof}

We only need to prove the theorem for the 2-dimensional case, since we can then generalize the theorem to n-dimensions by sequentially applying the theorem for 2-dimensions to each pair of coordinates.

Since rotating by 90 degrees preserves the [joint distribution](https://en.wikipedia.org/wiki/Joint_distribution), $X_1$ and $X_2$ have the same [probability measure](wikipedia://en/45437): let it be $\mu$. If $\mu$ is a [Dirac delta distribution](https://en.wikipedia.org/wiki/Dirac_delta_distribution) at zero, then it is, in particular, a degenerate gaussian distribution. Let us now assume that $\mu$ is not a Dirac delta distribution at zero.

By [Lebesgue's decomposition theorem](wikipedia://en/4316238), we can decompose $\mu$ into a sum of a [regular measure](wikipedia://en/3390453) and an [atomic measure](https://en.wikipedia.org/wiki/Atomic_measure): $\mu = \mu_r + \mu_s$. We need to show that $\mu_s = 0$; we proceed by [contradiction](https://en.wikipedia.org/wiki/Proof_by_contradiction). Suppose $\mu_s$ contains an atomic part, then there exists some $x\in \mathbb{R}$ such that $\mu_s(\{x\}) > 0$. By independence of $X_1, X_2$, the conditional variable $X_2 | \{X_1 = x\}$ is distributed the same way as $X_2$. Suppose $x=0$, then since we assumed $\mu$ is not concentrated at zero, $Pr(X_2 \neq 0) > 0$, and so the double ray $\{(x_1, x_2): x_1 = 0, x_2 \neq 0\}$ has nonzero probability. Now, by the rotational symmetry of $\mu \times \mu$, any rotation of the double ray also has the same nonzero probability, and since any two rotations are disjoint, their union has infinite probability, which is a contradiction.

Let $\mu$ have probability density function $\rho$; the problem reduces to solving the functional equation

$$\rho(x)\rho(y) = \rho(x \cos \theta + y \sin\theta)\rho(x \sin \theta - y \cos\theta).$$
