# Universal set

::: {#o1 .subject cue=lead name="Universal set"}

In [set theory](wikipedia://en/27553), a **universal set** is a set that contains all of the objects in the theory, including itself.[^n1] In set theory as usually formulated, it can be [proven](wikipedia://en/82285) in multiple ways that a universal set does not exist. However, some non-standard variants of set theory include a universal set.

:::

## Reasons for nonexistence {#Reasons_for_nonexistence}

Many set theories do not allow for the existence of a universal set. There are several different arguments for its non-existence, based on different choices of [axioms](wikipedia://en/928) for set theory.

::: {#o5 .statement cue=named-heading name="Russell's paradox"}

### Russell's paradox {#Russell's_paradox}

[Russell's paradox](wikipedia://en/46095) concerns the impossibility of a set of sets, whose members are all sets that do not contain themselves. If such a set could exist, it could neither contain itself (because its members all do not contain themselves) nor avoid containing itself (because if it did, it should be included as one of its members).[^n2] This paradox prevents the existence of a universal set in set theories that include either [Zermelo](https://en.wikipedia.org/wiki/Zermelo)'s [axiom of restricted comprehension](https://en.wikipedia.org/wiki/Axiom_of_comprehension), or the [axiom of regularity](wikipedia://en/2113) and [axiom of pairing](wikipedia://en/52385).

#### Regularity and pairing {#Regularity_and_pairing}

In [Zermelo–Fraenkel set theory](wikipedia://en/152214), the [axiom of regularity](wikipedia://en/2113) and [axiom of pairing](wikipedia://en/52385) prevent any set from containing itself. For any set $A$, the set $\{A\}$ (constructed using pairing) necessarily contains an element disjoint from $\{A\}$, by regularity. Because its only element is $A$, it must be the case that $A$ is disjoint from $\{A\}$, and therefore that $A$ does not contain itself. Because a universal set would necessarily contain itself, it cannot exist under these axioms.[^n3]

#### Comprehension {#Comprehension}

Russell's paradox prevents the existence of a universal set in set theories that include [Zermelo](https://en.wikipedia.org/wiki/Zermelo)'s [axiom of restricted comprehension](https://en.wikipedia.org/wiki/Axiom_of_comprehension). This axiom states that, for any formula $\varphi(x)$ and any set $A$, there exists a set

$$\{x \in A \mid \varphi(x)\}$$

that contains exactly those elements $x$ of $A$ that satisfy $\varphi$.[^n2]

If this axiom could be applied to a universal set $A$, with $\varphi(x)$ defined as the predicate $x\notin x$, it would state the existence of Russell's paradoxical set, giving a contradiction. It was this contradiction that led the axiom of comprehension to be stated in its restricted form, where it asserts the existence of a subset of a given set rather than the existence of a set of all sets that satisfy a given formula.[^n2]

When the axiom of restricted comprehension is applied to an arbitrary set $A$, with the predicate $\varphi(x)\equiv x\notin x$, it produces the subset of elements of $A$ that do not contain themselves. It cannot be a member of $A$, because if it were it would be included as a member of itself, by its definition, contradicting the fact that it cannot contain itself. In this way, it is possible to construct a witness to the non-universality of $A$, even in versions of set theory that allow sets to contain themselves. This indeed holds even with [predicative comprehension](wikipedia://en/17773501) and over [intuitionistic logic](wikipedia://en/169262).

:::

::: {#o13 .statement kind=statement/theorem cue=named-heading name="Cantor's theorem"}

### Cantor's theorem {#Cantor's_theorem}

Another difficulty with the idea of a universal set concerns the [power set](wikipedia://en/23799) of the set of all sets. Because this power set is a set of sets, it would necessarily be a subset of the set of all sets, provided that both exist. However, this conflicts with Cantor's theorem that the power set of any set (whether infinite or not) always has strictly higher [cardinality](wikipedia://en/6174) than the set itself.

:::

## Theories of universality {#Theories_of_universality}

The difficulties associated with a universal set can be avoided either by using a variant of set theory in which the axiom of comprehension is restricted in some way, or by using a universal object that is not considered to be a set.

### Restricted comprehension {#Restricted_comprehension}

There are set theories known to be [consistent](https://en.wikipedia.org/wiki/Consistent) (if the usual set theory is consistent) in which the universal set $V$ does exist (and $V \in V$ is true). In these theories, Zermelo's [axiom of comprehension](https://en.wikipedia.org/wiki/Axiom_of_comprehension) does not hold in general, and the axiom of comprehension of [naive set theory](wikipedia://en/4944) is restricted in a different way. A set theory containing a universal set is necessarily a [non-well-founded set theory](wikipedia://en/1091767). The most widely studied set theory with a universal set is [Willard Van Orman Quine](wikipedia://en/33833)'s [New Foundations](wikipedia://en/945957). [Alonzo Church](wikipedia://en/49731) and [Arnold Oberschelp](wikipedia://en/62923277) also published work on such set theories. Church speculated that his theory might be extended in a manner consistent with Quine's,[^o16] but this is not possible for Oberschelp's, since in it the singleton function is provably a set,[^n4] which leads immediately to paradox in New Foundations.[^n5]

Another example is [positive set theory](wikipedia://en/1023857), where the axiom of comprehension is restricted to hold only for the [positive formulas](https://en.wikipedia.org/wiki/Positive_formula) (formulas that do not contain negations). Such set theories are motivated by notions of closure in topology.

### Universal objects that are not sets {#Universal_objects_that_are_not_sets}

The idea of a universal set seems intuitively desirable in the [Zermelo–Fraenkel set theory](wikipedia://en/152214), particularly because most versions of this theory do allow the use of quantifiers over all sets (see [universal quantifier](https://en.wikipedia.org/wiki/Universal_quantifier)). One way of allowing an object that behaves similarly to a universal set, without creating paradoxes, is to describe $V$ and similar large collections as [proper classes](wikipedia://en/20696) rather than as sets. Russell's paradox does not apply in these theories because the axiom of comprehension operates on sets, not on classes.

The [category of sets](wikipedia://en/26829) can also be considered to be a universal object that is, again, not itself a set. It has all sets as elements, and also includes arrows for all functions from one set to another. Again, it does not contain itself, because it is not itself a set.
