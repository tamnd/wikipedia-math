# Self-adjoint element

::: {#o1 .subject cue=lead name="Self-adjoint element"}

In [mathematics](wikipedia://en/18831), an [element](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of a [\*-algebra](wikipedia://en/293426) is called **self-adjoint** if it is the same as its [adjoint](https://en.wikipedia.org/wiki/Adjoint_operator) (i.e. $a = a^*$).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{A}$ be a \*-algebra. An element $a \in \mathcal{A}$ is called self-adjoint if $a = a^*$.[^n1]

The [set](wikipedia://en/26691) of self-adjoint elements is referred to as $\mathcal{A}_{sa}$.

A [subset](wikipedia://en/27631) $\mathcal{B} \subseteq \mathcal{A}$ that is [closed](wikipedia://en/47279) under the [involution](wikipedia://en/293450) \*, i.e. $\mathcal{B} = \mathcal{B}^*$, is called self-adjoint.[^n2]

A special case of particular importance is the case where $\mathcal{A}$ is a [complete normed \*-algebra](wikipedia://en/4665#Banach_*-algebras), that satisfies the C\*-identity ($\left\| a^*a \right\| = \left\| a \right\|^2 \ \forall a \in \mathcal{A}$), which is called a [C\*-algebra](wikipedia://en/7184).

Especially in the older literature on \*-algebras and C\*-algebras, such elements are often called hermitian.[^n1] Because of that the notations $\mathcal{A}_h$, $\mathcal{A}_H$ or $H(\mathcal{A})$ for the set of self-adjoint elements are also sometimes used, even in the more recent literature.

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- Each [positive element](wikipedia://en/68445647) of a C\*-algebra is self-adjoint.[^n3]
- For each element $a$ of a \*-algebra, the elements $aa^*$ and $a^*a$ are self-adjoint, since \* is an [involutive antiautomorphism](wikipedia://en/706374#Involutions).[^n4]
- For each element $a$ of a \*-algebra, the [real and imaginary parts](https://en.wikipedia.org/wiki/Real_and_imaginary_parts) $\operatorname{Re}(a) = \frac{1}{2} (a+a^*)$ and $\operatorname{Im}(a) = \frac{1}{2 \mathrm{i} } (a-a^*)$ are self-adjoint, where $\mathrm{i}$ denotes the [imaginary unit](wikipedia://en/52358).[^n1]
- If $a \in \mathcal{A}_N$ is a [normal element](wikipedia://en/21454688) of a C\*-algebra $\mathcal{A}$, then for every [real-valued function](wikipedia://en/22284647) $f$, which is [continuous](wikipedia://en/6122) on the [spectrum](wikipedia://en/4665#Spectral_theory) of $a$, the [continuous functional calculus](wikipedia://en/784808) defines a self-adjoint element $f(a)$.[^n5]

:::

## Criteria {#Criteria}

Let $\mathcal{A}$ be a \*-algebra. Then:

- Let $a \in \mathcal{A}$, then $a^*a$ is self-adjoint, since $(a^*a)^* = a^*(a^*)^* = a^*a$. A similarly calculation yields that $aa^*$ is also self-adjoint.[^n6]
- Let $a = a_1 a_2$ be the [product](wikipedia://en/24977) of two self-adjoint elements $a_1,a_2 \in \mathcal{A}_{sa}$. Then $a$ is self-adjoint if $a_1$ and $a_2$ [commutate](wikipedia://en/294390), since $(a_1 a_2)^* = a_2^* a_1^* = a_2 a_1$ always holds.[^n1]
- If $\mathcal{A}$ is a C\*-algebra, then a normal element $a \in \mathcal{A}_N$ is self-adjoint if and only if its spectrum is real, i.e. $\sigma(a) \subseteq \mathbb{R}$.[^n5]

::: {#o18 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### In \*-algebras {#In_*-algebras}

Let $\mathcal{A}$ be a \*-algebra. Then:

- Each element $a \in \mathcal{A}$ can be uniquely decomposed into real and imaginary parts, i.e. there are uniquely determined elements $a_1,a_2 \in \mathcal{A}_{sa}$, so that $a = a_1 + \mathrm{i} a_2$ holds. Where $a_1 = \frac{1}{2} (a + a^*)$ and $a_2 = \frac{1}{2 \mathrm{i}} (a - a^*)$.[^n1]
- The set of self-adjoint elements $\mathcal{A}_{sa}$ is a [real](wikipedia://en/20646438) [linear subspace](wikipedia://en/56357) of $\mathcal{A}$. From the previous property, it follows that $\mathcal{A}$ is the [direct sum](wikipedia://en/2084687) of two real linear subspaces, i.e. $\mathcal{A} = \mathcal{A}_{sa} \oplus \mathrm{i} \mathcal{A}_{sa}$.[^n7]
- If $a \in \mathcal{A}_{sa}$ is self-adjoint, then $a$ is normal.[^n1]
- The \*-algebra $\mathcal{A}$ is called a hermitian \*-algebra if every self-adjoint element $a \in \mathcal{A}_{sa}$ has a real spectrum $\sigma(a) \subseteq \mathbb{R}$.[^n8]

### In C\*-algebras {#In_C*-algebras}

Let $\mathcal{A}$ be a C\*-algebra and $a \in \mathcal{A}_{sa}$. Then:

- For the spectrum $\left\| a \right\| \in \sigma(a)$ or $-\left\| a \right\| \in \sigma(a)$ holds, since $\sigma(a)$ is real and $r(a) = \left\| a \right\|$ holds for the [spectral radius](wikipedia://en/4665#Spectral_theory), because $a$ is normal.[^n9]
- According to the continuous functional calculus, there exist uniquely determined positive elements $a_+,a_- \in \mathcal{A}_+$, such that $a = a_+ - a_-$ with $a_+ a_- = a_- a_+ = 0$. For the norm, $\left\| a \right\| = \max(\left\|a_+\right\|,\left\|a_-\right\|)$ holds.[^n10] The elements $a_+$ and $a_-$ are also referred to as the [positive and negative parts](wikipedia://en/3344921). In addition, $|a| = a_+ + a_-$ holds for the absolute value defined for every element $|a| = (a^* a)^\frac{1}{2}$.[^n11]
- For every $a \in \mathcal{A}_+$ and odd $n \in \mathbb{N}$, there exists a uniquely determined $b \in \mathcal{A}_+$ that satisfies $b^n = a$, i.e. a unique $n$[\-th root](wikipedia://en/235029), as can be shown with the continuous functional calculus.[^n12]

:::
