# Counting process

::: {#o1 .subject cue=lead name="Counting process"}

A **counting process** is a [stochastic process](wikipedia://en/47895) $\{N(t), t\geq0\}$ with values that are non-negative, integer, and non-decreasing:

:::

1. $$N(t)\geq0.$$
1. $N(t)$ is an integer.
1. If $s\leq t$ then $N(s)\leq N(t).$

If $s<t$, then $N(t)-N(s)$ is the number of events occurred during the interval $(s,t].$ Examples of counting processes include [Poisson processes](https://en.wikipedia.org/wiki/Poisson_process) and [Renewal processes](wikipedia://en/1945387).

Counting processes deal with the number of occurrences of something over time. An example of a counting process is the number of job arrivals to a queue over time.

If a process has the [Markov property](wikipedia://en/306422), it is said to be a Markov counting process.
