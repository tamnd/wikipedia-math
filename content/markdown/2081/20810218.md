# Item bank

::: {#o1 .subject cue=lead name="Item bank"}

An **item bank** or **question bank** is a repository of [test items](https://en.wikipedia.org/wiki/Test_item) that belong to a testing program, as well as all information pertaining to those items. In most applications of testing and [assessment](https://en.wikipedia.org/wiki/Educational_assessment), the items are of [multiple choice](https://en.wikipedia.org/wiki/Multiple_choice) format, but any format can be used. Items are pulled from the bank and assigned to test forms for publication either as a paper-and-pencil test or some form of [e-assessment](https://en.wikipedia.org/wiki/E-assessment).

:::

## Types of information {#Types_of_information}

An item bank will not only include the text of each item, but also extensive information regarding test development and [psychometric](wikipedia://en/24982) characteristics of the items. Examples of such information include:[^o3]

- Item [author](https://en.wikipedia.org/wiki/Author)
- Date written
- Item status (e.g., new, pilot, active, retired)
- Angoff ratings
- Correct answer
- Item format
- [Classical test theory](wikipedia://en/419859) statistics
- [Item response theory](wikipedia://en/420159) statistics
- Linkage to test blueprint
- Item history (e.g., usage date(s) and reviews)
- User-defined fields

## Item banking software {#Item_banking_software}

Because an item bank is essentially a simple [database](https://en.wikipedia.org/wiki/Database), it can be stored in database software or even a spreadsheet such as [Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel). However, there are several dozen commercially available [software](https://en.wikipedia.org/wiki/Software) programs specifically designed for item banking. The advantages that these provide are related to [assessment](https://en.wikipedia.org/wiki/Educational_assessment). For example, items are presented on the [computer](https://en.wikipedia.org/wiki/Computer) screen as they would appear to a test examinee, and item response theory parameters can be translated into [item response functions](https://en.wikipedia.org/wiki/Item_response_function) or [information functions](https://en.wikipedia.org/wiki/Item_information_function). Additionally, there are functionalities for publication, such as formatting a set of items to be printed as a paper-and-pencil test.

Some item banks also have test administration functionalities, such as being able to deliver [e-assessment](https://en.wikipedia.org/wiki/E-assessment) or process ["bubble"](https://en.wikipedia.org/wiki/Bubble_sheet) answer sheets.

## Examples {#Examples}

In India the popular question bank is [Oswaal](https://en.wikipedia.org/wiki/Oswaal_Books) Question Bank which covers all Indian board and competitive exam such as [CBSE](https://en.wikipedia.org/wiki/Central_Board_of_Secondary_Education), [CISCE](https://en.wikipedia.org/wiki/Council_for_the_Indian_School_Certificate_Examinations), [Pre-university course](https://en.wikipedia.org/wiki/Pre-university_course)- State board and [JEE](https://en.wikipedia.org/wiki/Joint_Entrance_Examination), [NEET](https://en.wikipedia.org/wiki/National_Eligibility_cum_Entrance_Test_%28Undergraduate%29), [CLAT](https://en.wikipedia.org/wiki/Common_Law_Admission_Test) and [CUET](https://en.wikipedia.org/wiki/Common_University_Entrance_Test).
