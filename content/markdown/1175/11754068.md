# Knödel number

::: {#o1 .subject cue=lead name="Knödel number"}

In [number theory](wikipedia://en/21527), an *n*-**Knödel number** for a given [positive integer](https://en.wikipedia.org/wiki/Positive_integer) *n* is a [composite number](wikipedia://en/82289) *m* with the property that each *i* \< *m* [coprime](https://en.wikipedia.org/wiki/Coprime) to *m* satisfies $i^{m - n} \equiv 1 \pmod{m}$.[^o2] The concept is named after [Walter Knödel](wikipedia://en/41885639).

:::

The [set](wikipedia://en/26691) of all *n*-Knödel numbers is denoted *K*<sub>*n*</sub>.[^o2] The [special case](wikipedia://en/31308010) *K*<sub>1</sub> is the [Carmichael numbers](wikipedia://en/7723).[^o2] There are infinitely many *n*-Knödel numbers for a given *n*.

Due to [Euler's theorem](wikipedia://en/69566) every composite number *m* is an *n*-Knödel number for $n = m-\varphi(m)$ where $\varphi$ is [Euler's totient function](wikipedia://en/53452).
