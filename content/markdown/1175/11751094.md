# Binary constraint

::: {#o1 .subject cue=lead name="Binary constraint"}

A **binary constraint**, in [mathematical optimization](wikipedia://en/52033), is a constraint that involves exactly two [variables](wikipedia://en/3728109).

:::

For example, consider the [*n*-queens problem](https://en.wikipedia.org/wiki/N-queens_problem), where the goal is to place *n* [chess queens](https://en.wikipedia.org/wiki/Queen_%28chess%29) on an *n*-by-*n* chessboard such that none of the queens can attack each other (horizontally, vertically, or diagonally). The formal set of constraints are therefore "Queen 1 can't attack Queen 2", "Queen 1 can't attack Queen 3", and so on between all pairs of queens. Each constraint in this problem is binary, in that it only considers the placement of two individual queens.[^o2]

[Linear programs](https://en.wikipedia.org/wiki/Linear_program) in which all constraints are binary can be solved in [strongly polynomial time](https://en.wikipedia.org/wiki/Strongly_polynomial_time), a result that is not known to be true for more general linear programs.[^o3]
