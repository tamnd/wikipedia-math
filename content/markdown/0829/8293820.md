# Sequentially compact space

::: {#o1 .subject cue=lead name="Sequentially compact space"}

In [mathematics](wikipedia://en/18831), a [topological space](wikipedia://en/30450) $X$ is **sequentially compact** if every [sequence](wikipedia://en/27838) of points in $X$ has a [convergent](wikipedia://en/285773#Topological_spaces) [subsequence](wikipedia://en/236098) converging to a point in $X$.

:::

Every [metric space](wikipedia://en/20018) is naturally a topological space, and for metric spaces, the notions of [compactness](wikipedia://en/6042) and sequential compactness are equivalent (using the [axiom of countable choice](wikipedia://en/421086)). However, there exist sequentially compact topological spaces that are not compact, and compact topological spaces that are not sequentially compact.

## Examples and properties {#Examples_and_properties}

The space of all [real numbers](wikipedia://en/20646438) with the [standard topology](https://en.wikipedia.org/wiki/Standard_topology) is not sequentially compact; the sequence $(s_n)$ given by $s_n = n$ for all [natural numbers](wikipedia://en/21474) *$n$* is a sequence that has no convergent subsequence.

On a [first countable space](https://en.wikipedia.org/wiki/First_countable_space), a sequence $x_n$ has a convergent subsequence if and only if

$$\bigcap_n \overline{ \{ x_m \mid m \ge n \} }$$

is nonempty. Indeed, a limit of a convergent subsequence is necessarily in the above intersection (this direction holds for any topological space). Conversely, if $x$ is in the above intersection, then let $x \in \cdots \subset U_2 \subset U_1$ be a countable [neighborhood base](https://en.wikipedia.org/wiki/Neighborhood_base) at $x$. Then, inductively, choose integers $n_i > 0$ such that $n_i$ is a least integer with the property (1) $n_i > n_{i-1}$ and (2) $x_{n_i} \in U_i$, which is possible since $\mathbb N$ is a [well-ordered set](https://en.wikipedia.org/wiki/Well-ordered_set). Then $x_{n_j} \to x$.

A point in the above intersection is called a [cluster point](https://en.wikipedia.org/wiki/Cluster_point). Thus, for first countable spaces, the definition of a sequentially compact space is the same as saying that each sequence in the space has a cluster point.

If a space is a [metric space](wikipedia://en/20018), then it is sequentially compact if and only if it is [compact](wikipedia://en/6042) (cf. Heine–Borel theorem).[^o3] Here is how to see this, using only the [countable Choice](https://en.wikipedia.org/wiki/Countable_Choice). We have to show "sequentially compact" implies "compact". First, we note $X$ is totally bounded, meaning for each $\epsilon > 0$, there is a finite cover of $X$ consisting of open balls $B(x, \epsilon)$ of radius $\epsilon$. Indeed, if it fails for some $\epsilon$, by countable Choice, choose a sequence $x_n$ such that

$$x_n \not\in B(x_1, \epsilon) \cup \cdots \cup B(x_{n-1}, \epsilon).$$

This sequence $x_n$ has no convergent subsequence, a contradiction. It follows that $X$ has a countable base. Hence, it is enough to show $X$ is countably compact; i.e., each descending sequence $E_1 \supset E_2 \supset \cdots$ of nonempty closed subsets has nonempty intersection. But this is clear since

$$\emptyset \ne \cap_n \overline{\{ x_m \mid m \ge n \}} \subset \cap_n E_n$$

for some sequence $x_n$ with $x_n \in E_n$. $\square$

The [first uncountable ordinal](wikipedia://en/20860540) with the [order topology](wikipedia://en/213650) is an example of a sequentially compact topological space that is not compact. The [topological product](wikipedia://en/24910) of $2^{\aleph_0}=\mathfrak c$ copies of the [closed unit interval](https://en.wikipedia.org/wiki/Closed_unit_interval) is an example of a compact space that is not sequentially compact.[^o4]

## Related notions {#Related_notions}

A topological space *$X$* is said to be [limit point compact](wikipedia://en/9861462) if every infinite subset of *$X$* has a [limit point](https://en.wikipedia.org/wiki/Limit_point) in *$X$*, and [countably compact](wikipedia://en/8293816) if every countable [open cover](https://en.wikipedia.org/wiki/Open_cover) has a finite subcover. In a [metric space](wikipedia://en/20018), the notions of sequential compactness, limit point compactness, countable compactness and [compactness](wikipedia://en/6042) are all equivalent (if one assumes the [axiom of choice](wikipedia://en/840)).

In a [sequential (Hausdorff) space](wikipedia://en/4668395) sequential compactness is equivalent to countable compactness.[^o6]

There is also a notion of a one-point sequential compactification—the idea is that the non convergent sequences should all converge to the extra point.[^o7]
