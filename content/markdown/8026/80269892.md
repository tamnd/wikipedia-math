# Ruijsenaars–Schneider model

::: {#o1 .subject cue=lead name="Ruijsenaars–Schneider model"}

**Ruijsenaars–Schneider models** (short **RS models**) are [relativistic](wikipedia://en/30001) generalizations of [Calogero–Moser–Sutherland models](wikipedia://en/80269878) (short CMS models), which are closely connected with [relativistic field theories](https://en.wikipedia.org/wiki/Relativistic_field_theory) like the [Sine-Gordon model](wikipedia://en/306645). RS models are named after Simon N. M. Ruijsenaars and Harald Schneider. Both of them introduced the [classical](https://en.wikipedia.org/wiki/Classical_physics) models in 1986 and Ruijsenaars introduced the [quantum](https://en.wikipedia.org/wiki/Quantum) models in 1987.[^o2]

:::

## Description {#Description}

For $N$ particles on the real line $\mathbb{R}$, the Hamiltonian of the RS model is given by:[^o4]

$$H =mc^2\sum_{i=1}^N\cosh\left(\frac{p_i}{mc}\right)\prod_{\stackrel{1\leq j\leq N}{j\neq i}}f(x_i-x_j).$$

Different [potentials](wikipedia://en/23703) lead to different RS models, which the four types most often considered being:

- Type I/rational:

$$f(x)^2 =1+\left(\frac{g}{mcx}\right)^2.$$

- Type II/hyperbolic:

$$f(x)^2 =1+\frac{\sin\left(\frac{ag}{mc}\right)^2}{\sinh(ax)^2}.$$

- Type III/trigonometric:

$$f(x)^2 =1+\frac{\sinh\left(\frac{ag}{mc}\right)^2}{\sin(ax)^2}.$$

- Type IV/elliptic:[^o5]

$$f(x)^2 =a+b\wp(x;\omega_1,\omega_2).$$
