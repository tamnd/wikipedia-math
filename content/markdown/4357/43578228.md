# Decidability of first-order theories of the real numbers

::: {#o1 .subject cue=lead name="Decidability of first-order theories of the real numbers"}

In [mathematical logic](wikipedia://en/19636), a first-order language of the [real numbers](https://en.wikipedia.org/wiki/Real_numbers) is the set of all [well-formed sentences](https://en.wikipedia.org/wiki/Well_formed_formula) of [first-order logic](wikipedia://en/10983) that involve [universal](https://en.wikipedia.org/wiki/Universal_quantifier) and [existential quantifiers](https://en.wikipedia.org/wiki/Existential_quantifier) and logical combinations of equalities and inequalities of expressions over real variables. The corresponding first-order [theory](wikipedia://en/3512103) is the set of sentences that are actually true of the real numbers. There are several different such theories, with different expressive power, depending on the primitive operations that are allowed to be used in the expression. A fundamental question in the study of these theories is whether they are [decidable](wikipedia://en/913118): that is, whether there is an [algorithm](wikipedia://en/775) that can take a sentence as input and produce as output an answer "yes" or "no" to the question of whether the sentence is true in the theory.

:::

The theory of [real closed fields](https://en.wikipedia.org/wiki/Real_closed_fields) is the theory in which the primitive operations are multiplication and addition; this implies that, in this theory, the only numbers that can be defined are the real [algebraic numbers](wikipedia://en/1158). As proven by [Tarski](wikipedia://en/59920), this theory is decidable; see [Tarski–Seidenberg theorem](wikipedia://en/19389633) and [Quantifier elimination](wikipedia://en/2150441). Current implementations of decision procedures for the theory of real closed fields are often based on quantifier elimination by [cylindrical algebraic decomposition](wikipedia://en/12218154).

Tarski's decidable algorithm was implemented on electronic computers in the 1950s. Its runtime is too slow for it to reach any interesting results.[^o2]

[Tarski's exponential function problem](wikipedia://en/16073214) concerns the extension of this theory to another primitive operation, the [exponential function](wikipedia://en/9678). It is an open problem whether this theory is decidable, but if [Schanuel's conjecture](wikipedia://en/2031353) holds then the decidability of this theory would follow.[^o3] In contrast, the extension of the theory of real closed fields with the [sine function](https://en.wikipedia.org/wiki/Sine_function) is undecidable since this allows encoding of the undecidable theory of integers (see [Richardson's theorem](wikipedia://en/13463844)).

Still, one can handle the undecidable case with functions such as sine by using algorithms that do not necessarily terminate always. In particular, one can design algorithms that are only required to terminate for input formulas that are [robust](https://en.wikipedia.org/wiki/Robustness), that is, formulas whose satisfiability does not change if the formula is slightly perturbed.[^o5] Alternatively, it is also possible to use purely heuristic approaches.[^o6]
