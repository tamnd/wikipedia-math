# RStudio

::: {#o5 .subject cue=lead name="RStudio"}

**RStudio IDE** (or **RStudio**) is an [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) for [R](wikipedia://en/376707), a [programming language](wikipedia://en/23015) for [statistical computing](https://en.wikipedia.org/wiki/Statistical_computing) and graphics. It is available in two formats: RStudio Desktop, a regular [desktop application](https://en.wikipedia.org/wiki/Desktop_application), and RStudio Server, which runs on a remote server and allows accessing RStudio using a [web browser](https://en.wikipedia.org/wiki/Web_browser). The RStudio IDE is a product of [Posit PBC](https://en.wikipedia.org/wiki/Posit_PBC) (formerly RStudio PBC, formerly RStudio Inc.).

:::

## Reproducible analyses with vignettes {#Reproducible_analyses_with_vignettes}

A strength of RStudio is its support for reproducible analyses[^o7] with R Markdown vignettes. These allow users to mix text with code in [R](wikipedia://en/376707), [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), shell scripts, [SQL](wikipedia://en/29004), [Stan](wikipedia://en/42243853), [JavaScript](https://en.wikipedia.org/wiki/JavaScript), [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), [C++](https://en.wikipedia.org/wiki/C++), [Fortran](https://en.wikipedia.org/wiki/Fortran), and others,[^o8] similar to [Jupyter Notebooks](wikipedia://en/57313979#Jupyter_Notebook). R Markdown can be used to create dynamic reports that are automatically updated when new data become available. These reports can also be exported in various formats, including [HTML](https://en.wikipedia.org/wiki/HTML), [PDF](https://en.wikipedia.org/wiki/PDF), [Microsoft Word](https://en.wikipedia.org/wiki/Microsoft_Word), and [LaTeX](https://en.wikipedia.org/wiki/LaTeX), with templates specific to the requirements of many scientific journals.[^o9]

R Markdown vignettes and Jupyter notebooks make the data analysis completely reproducible. R Markdown vignettes have been included as appendices with tutorials on [Wikiversity](https://en.wikipedia.org/wiki/Wikiversity).[^o10]

In 2022, Posit announced an R Markdown-like publishing system called [Quarto](https://en.wikipedia.org/wiki/Quarto_%28software%29). In addition to combining results of R, code and results using [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), Observable JavaScript, and [Jupyter](wikipedia://en/57313979) notebooks can also be used in Quarto documents. Compared to the file extension `.Rmd` that R Markdown has, Quarto documents have the file extension `.qmd`.[^o11]

One difference between R Markdown files and Quarto documents is defining options in code chunks. In R Markdown, they would be inline within the curly brackets.

\`\`\`{r chunk\_name, echo=FALSE, warning=FALSE} print(42) \`\`\`

In contrast, Quarto documents define the chunk options below the curly brackets, prefixed using a [pound character](https://en.wikipedia.org/wiki/Number_sign) and [vertical pipe](wikipedia://en/641073) (or "hash-pipe").

\`\`\`{r} #| label: chunk\_name #| echo: false #| warning: false print(42) \`\`\`

## Licensing model {#Licensing_model}

The RStudio [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) (IDE) is available with the [GNU Affero General Public License](https://en.wikipedia.org/wiki/GNU_Affero_General_Public_License) version 3. The AGPL v3 is an open source license that guarantees the freedom to share the code.

RStudio Desktop and RStudio Server are both available in [free](https://en.wikipedia.org/wiki/Gratis_versus_libre) and fee-based (commercial) editions. OS support depends on the format/edition of the IDE. Prepackaged distributions of RStudio Desktop are available for [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), and [Linux](https://en.wikipedia.org/wiki/Linux). RStudio Server and Server Pro run on [Debian](https://en.wikipedia.org/wiki/Debian), [Ubuntu](https://en.wikipedia.org/wiki/Ubuntu_%28operating_system%29), [Red Hat Linux](https://en.wikipedia.org/wiki/Red_Hat_Linux), [CentOS](https://en.wikipedia.org/wiki/CentOS), [openSUSE](https://en.wikipedia.org/wiki/OpenSUSE) and [SLES](https://en.wikipedia.org/wiki/SUSE_Linux_Enterprise_Server).[^o13]

## Overview and history {#Overview_and_history}

The RStudio IDE was partly written in the [C++](https://en.wikipedia.org/wiki/C++) programming language and uses the [Qt framework](https://en.wikipedia.org/wiki/Qt_%28software%29) for its [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface).[^o15] Since 2022.12.0+353 version, it switched to the [Electron](https://en.wikipedia.org/wiki/Electron_%28software_framework%29) framework.[^o16] The bigger percentage of the code is written in Java. JavaScript is also used.[^o17]

Work on the RStudio IDE started around December 2010,[^o18] and the first public [beta version](https://en.wikipedia.org/wiki/Beta_version) (v0.92) was officially announced in February 2011.[^o19] [Version 1.0](https://en.wikipedia.org/wiki/Software_versioning#Version_1.0_as_a_milestone) was released on 1 November 2016.[^o20] Version 1.1 was released on 9 October 2017.[^o21]

## Addins {#Addins}

The RStudio IDE provides a mechanism for executing R functions interactively from within the IDE through the `Addins` menu.[^o24] This enables packages to include [graphical user interfaces](https://en.wikipedia.org/wiki/Graphical_user_interface) (GUIs) for increased accessibility. Popular [R](wikipedia://en/376707) packages that use this feature include:

- bookdown – a [knitr](https://en.wikipedia.org/wiki/Knitr) extension to create books
- colourpicker – a graphical tool to pick colours for plots
- [datasets.load](https://en.wikipedia.org/wiki/Datasets.load) – a graphical tool to search and load datasets
- googleAuthR – Authenticate with Google APIs

:::

## Development {#Development}

The RStudio IDE is developed by Posit, PBC, a [public-benefit corporation](https://en.wikipedia.org/wiki/Benefit_corporation)[^o26] founded by [J. J. Allaire](https://en.wikipedia.org/wiki/Joseph_J._Allaire),[^o27] creator of the programming language [ColdFusion](https://en.wikipedia.org/wiki/ColdFusion_Markup_Language). Posit has no formal connection to the R Foundation, a [not-for-profit](https://en.wikipedia.org/wiki/Not-for-profit) organization located in [Vienna](wikipedia://en/55866), [Austria](https://en.wikipedia.org/wiki/Austria),[^o28] which is responsible for overseeing development of the [R](wikipedia://en/376707) environment for statistical computing. Posit was formerly known as RStudio Inc. In July 2022, it announced that it changed its name to Posit, to signify its broadening exploration towards other programming languages such as [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29).[^o29]
