# Hitting time

::: {#o1 .subject cue=lead name="Hitting time"}

*Image: HittingTimes1.png.* The Hitting times and stopping times of three samples of Brownian motion.

In the study of [stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes) in [mathematics](wikipedia://en/18831), a **hitting time** (or **first hit time**) is the first time at which a given process "hits" a given [subset](wikipedia://en/27631) of the [state space](https://en.wikipedia.org/wiki/State_space). **Exit times** and **return times** are also examples of hitting times.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $T$ be an ordered [index set](wikipedia://en/393055) such as the [natural numbers](wikipedia://en/21474), $\mathbb{N},$ the non-negative [real numbers](wikipedia://en/20646438), $[0, +\infty)$, or a subset of these; elements $t \in T$ can be thought of as "times". Given a [probability space](wikipedia://en/43325) $(\Omega, \Sigma, \Pr)$ and a [measurable state space](wikipedia://en/43333) $S$, let $X :\Omega \times T \to S$ be a [stochastic process](wikipedia://en/47895), and let $A$ be a [measurable subset](https://en.wikipedia.org/wiki/Measurable_set) of the state space $S$. Then the **first hit time** $\tau_A : \Omega \to [0, +\infty]$ is the [random variable](wikipedia://en/25685) defined by

$$\tau_A (\omega) := \inf \{ t \in T \mid X_t (\omega) \in A \}.$$

The **first exit time** (from $A$) is defined to be the first hit time for $S \backslash A$, the [complement](wikipedia://en/54347) of $A$ in $S$. Confusingly, this is also often denoted by $\tau_{A}$.[^o4]

The **first return time** is defined to be the first hit time for the [singleton](wikipedia://en/381798) set $\{X_{0}(\omega)\},$ which is usually a given deterministic element of the state space, such as the origin of the coordinate system.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any [stopping time](wikipedia://en/1202193) is a hitting time for a properly chosen process and target set. This follows from the converse of the [Début theorem](wikipedia://en/7059985#Début_theorem) (Fischer, 2013).
- Let $B$ denote standard [Brownian motion](wikipedia://en/149984) on the [real line](https://en.wikipedia.org/wiki/Real_line) $\mathbb{R}$ starting at the origin. Then the hitting time $\tau_{A}$ satisfies the measurability requirements to be a stopping time for every Borel measurable set $A\subseteq\mathbb{R}.$
- For $B$ as above, let $\tau_{r}$ ($r > 0$) denote the first exit time for the interval $(-r, r)$, i.e. the first hit time for $(-\infty,-r]\cup [r, +\infty).$ Then the [expected value](wikipedia://en/9653) and [variance](wikipedia://en/32344) of $\tau_{r}$ satisfy

$$\begin{aligned} \operatorname{E} \left[ \tau_r \right] &= r^2, \\ \operatorname{Var} \left[ \tau_r \right] &= \tfrac{2}{3} r^4. \end{aligned}$$

- For $B$ as above, the time of hitting a single point (different from the starting point 0) has the [Lévy distribution](wikipedia://en/1346871).
- The [narrow escape problem](wikipedia://en/26641574) considers the time it takes for a confined particle, undergoing Brownian motion, to escape through a small opening.

:::

::: {#o8 .statement kind=statement/theorem cue=named-heading name="Début theorem"}

## Début theorem {#Début_theorem}

The hitting time of a set $F$ is also known as the *début* of $F$. The Début theorem says that the hitting time of a measurable set $F$, for a [progressively measurable process](wikipedia://en/6583544) with respect to a right continuous and complete filtration, is a stopping time. Progressively measurable processes include, in particular, all right and left-continuous [adapted processes](wikipedia://en/6583420). The proof that the début is measurable is rather involved and involves properties of [analytic sets](wikipedia://en/634261). The theorem requires the underlying probability space to be [complete](wikipedia://en/44775) or, at least, universally complete.

The *converse of the Début theorem* states that every [stopping time](wikipedia://en/1202193) defined with respect to a [filtration](wikipedia://en/57854817) over a real-valued time index can be represented by a hitting time. In particular, for essentially any such stopping time there exists an adapted, non-increasing process with càdlàg (RCLL) paths that takes the values 0 and 1 only, such that the hitting time of the set $\{0\}$ by this process is the considered stopping time. The proof is very simple.[^o9]

:::

## Markov chains {#Markov_chains}

If a [Markov chain](wikipedia://en/60876) is irreducible and positive-recurrent, then the stationary distribution is unique and given by

$$\begin{aligned} \pi(i)=\frac{1}{\operatorname{E} \left[ \tau_i \right]} \end{aligned}$$

where $\tau_{i}$ is the hitting time for a state $i$. [^o11]

This can be viewed as a special case of [Kac's lemma](wikipedia://en/63490326).
