# Matrix pencil

::: {#o1 .subject cue=lead name="Matrix pencil"}

In [linear algebra](wikipedia://en/18422), a **matrix pencil** is a [matrix](wikipedia://en/20556859)-valued function defined on a [field](wikipedia://en/10603) $K$, usually the [real](https://en.wikipedia.org/wiki/Real_numbers) or [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $K$ be a field (typically, $K \in \{ \mathbb R, \mathbb C \}$; the definition can be generalized to [rngs](https://en.wikipedia.org/wiki/Rng_%28mathematics%29), i.e. non-unital rings), and let $n > 0$ be a positive integer. Then any matrix-valued function

$$P \colon K \to \mathrm{Mat}(K, n \times n)$$

(where $\mathrm{Mat}(K, n \times n)$ denotes the $K$-algebra of $n\times n$ matrices over $K$) is called a **matrix pencil.**

### Polynomial matrix pencils {#Polynomial_matrix_pencils}

An important special case arises when $P$ is [polynomial](https://en.wikipedia.org/wiki/Polynomial_function): let $\ell \ge 0$ be a non-negative integer, and let $A_0, A_1, \dots, A_\ell$ be $n\times n$ matrices (i. e. $A_i \in \mathrm{Mat}(K, n \times n)$ for all $i = 0, \dots, \ell$). Then the **polynomial matrix pencil** (often simply a **matrix pencil**) defined by $A_0, \dots, A_\ell$ is the matrix-valued function $L \colon K \to \mathrm{Mat}(K, n \times n)$ defined by

$$L(\lambda) = \sum_{i=0}^\ell \lambda^i A_i.$$

The *degree* of this matrix pencil is defined as the largest integer $0 \le k \le \ell$ such that $A_k \ne 0$, the $n \times n$ [zero matrix](wikipedia://en/1168888) over $K$.

### Linear matrix pencils {#Linear_matrix_pencils}

A particular case is a linear matrix pencil $L(\lambda) = A - \lambda B$ (where $B \ne 0$).[^o6] We denote it briefly with the notation $(A, B)$, and note that using the more general notation, $A_0 = A$ and $A_1 = -B$ (not $B$).

:::

## Generalized eigenvalues of matrix pencils {#Generalized_eigenvalues_of_matrix_pencils}

For a matrix pencil $P$, any $k \in K$ such that $\det P(k) = 0_K$ is called a **generalized eigenvalue** (often simply **eigenvalue**) of $P$, and the set of generalized eigenvalues of $P$ is called its **spectrum** and is denoted by

$$\sigma(P) = \{ k \in K : \det P(k) = 0_K \}.$$

For a polynomial matrix pencil, we write $\sigma(A_0, \dots, A_\ell)$; for the linear pencil $(A, B)$, we write as $\sigma(A, B)$ (not $\sigma(A, -B)$).

The generalized eigenvalues of the linear matrix pencil $(A, I)$ are precisely the matrix [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of $A$. The general linear pencil $(A, B)$ is said to have one or more eigenvalues *at infinity* if $B$ has one or more 0 eigenvalues.

A pencil is called **regular** if there is at least one $k \in K$ such that $\det P(k) \ne 0_K$, i. e. if $\sigma(P) \ne K$; otherwise it is called **singular.**

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

Matrix pencils play an important role in [numerical linear algebra](wikipedia://en/7330660). The problem of finding the generalized eigenvalues of a pencil is called the [generalized eigenvalue problem](https://en.wikipedia.org/wiki/Generalized_eigenvalue_problem). The most popular [algorithm](wikipedia://en/775) for this task is the [QZ algorithm](https://en.wikipedia.org/wiki/QZ_algorithm), an implicit version of the [QR algorithm](wikipedia://en/594072) for solving the eigenvalue problem $Ax = \lambda Bx$ without inverting the matrix $B$ (which is impossible when $B$ is singular, or numerically unstable when it is [ill-conditioned](wikipedia://en/6934)).

:::

## Pencils generated by commuting matrices {#Pencils_generated_by_commuting_matrices}

If $AB = BA$, then the pencil generated by $A$ and $B$:[^o11]

1. consists only of matrices [similar](https://en.wikipedia.org/wiki/Similar_matrices) to a [diagonal matrix](wikipedia://en/174080), or
1. has no matrices in it similar to a diagonal matrix, or
1. has exactly one matrix in it similar to a diagonal matrix.
