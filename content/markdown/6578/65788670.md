# Laminar set family

*Image: Laminar set.svg.* All hyperedges here are either [disjoint](wikipedia://en/39359) or related by containment. Edge 1 contains edge 4, and edges 3 and 5 contain each other. The set of hyperedges therefore forms a **laminar set family**.

::: {#o1 .subject cue=lead name="Laminar set family"}

In [combinatorics](wikipedia://en/5170), a **laminar set family** is a [set family](wikipedia://en/723043) in which each pair of sets are either [disjoint](wikipedia://en/39359) or related by containment.[^o2][^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, a set family $\mathcal{F} = \{S_1, S_2, \ldots\}$ is called **laminar** if for every $i, j$, the intersection $S_i \cap S_j$ is either empty, or equals $S_i$, or equals $S_j$.

:::

## Construction and Properties {#Construction_and_Properties}

Let $E$ be a ground-set of elements. A laminar set-family on $E$ can be constructed by recursively [partitioning](wikipedia://en/340240) $E$ into parts and sub-parts. The [singleton](wikipedia://en/381798) family ${E}$ is laminar. If we partition $E$ into some $k$ pairwise-disjoint parts $E_1, \ldots, E_k$, then ${E, E_1, \ldots, E_k}$ is laminar too. If we now partition, say $E_1$ into $E_{11}, E_{12}, \ldots, E_{1j}$, then adding these sub-parts yields another laminar family, and so on. Hence, a laminar set-family can be seen as a hierarchical partitioning of the ground-set into categories and sub-categories.

A fundamental property of laminar set families is that they can be represented as a rooted tree where each node corresponds to a set in the family, and a set $S_i$ is an ancestor of $S_j$ if and only if $S_i \supset S_j$. This tree representation makes laminar families particularly useful in algorithm design, as many problems can be solved efficiently using dynamic programming on the tree structure.

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

### Hypergraphs {#Hypergraphs}

The notion of laminarity can be applied to [hypergraphs](wikipedia://en/232535) to define "laminar hypergraphs" as those whose set of hyperedges forms a laminar set family.[^o10]

### Planar Graph Decomposition {#Planar_Graph_Decomposition}

Laminar families of separators play a crucial role in decomposing [planar graphs](wikipedia://en/24314). A **k-separator** (or k-cutset) in a k-connected graph is a subset of k vertices whose deletion disconnects the remaining graph. For planar graphs, the separators of small size often naturally form laminar families, which enables efficient algorithmic solutions.

Eppstein and Reed[^o12] showed that for a 3-connected planar graph $G$, a [maximal set](https://en.wikipedia.org/wiki/Maximal_set) of laminar 3-separators can be found in linear time. This is non-trivial because some planar graphs like wheel graphs can have $\Theta(n^2)$ 3-separators and $\Theta(n^4)$ non-laminar pairs of 3-separators, making it inefficient to enumerate all separators and then select a laminar subset.

Their algorithm works by transforming the problem: 3-separators in the original graph $G$ correspond to certain 6-cycles in the barycentric subdivision $\text{BCS}(G)$. The algorithm identifies "frames" (wheel-like structures containing many mutually non-laminar cycles) and handles them separately to avoid quadratic blow-up in complexity. This decomposition has important applications in finding disjoint paths in graphs and computing tree decompositions of bounded adhesion.

Beginning with the work of Wagner,[^o13] decompositions of graphs by laminar sets of small cutsets have been an important tool in graph structure theory. Wagner showed that every $K_5$-minor-free graph can be decomposed by a laminar system of cutsets of size at most three into pieces that are either planar or the eight-vertex [Wagner graph](wikipedia://en/17598450). Many similar decomposition theorems are now known, and tree decompositions and [treewidth](wikipedia://en/3987086) are also defined by laminar cutsets.
