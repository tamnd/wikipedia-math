# Identity function

*Image: Function-x.svg.* [Graph](wikipedia://en/87352) of the identity function on the [real numbers](wikipedia://en/20646438)

::: {#o1 .subject cue=lead name="Identity function"}

In [mathematics](wikipedia://en/18831), an **identity function**, also called an **identity relation**, **identity map** or **identity transformation**, is a [function](wikipedia://en/185427) that always returns the value that was used as its [argument](wikipedia://en/32842052), unchanged. That is, when $f$ is the identity function, the [equality](wikipedia://en/90446) $f(x)=x$ is true for all values of $x$ to which $f$ can be applied.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Formally, if $X$ is a [set](wikipedia://en/26691), the identity function $f$ on $X$ is defined to be a function with $X$ as its [domain](wikipedia://en/50263) and [codomain](wikipedia://en/50264), satisfying $f(x)=x$ for all elements $x$ in $X$.[^o4]

In other words, the function value $f(x)$ in the codomain $X$ is always the same as the input element $x$ in the domain $X$. The identity function on $X$ is clearly an [injective function](wikipedia://en/45196) as well as a [surjective function](wikipedia://en/27873) (its codomain is also its [range](https://en.wikipedia.org/wiki/Range_%28function%29)), so it is [bijective](wikipedia://en/3942).[^o5]

The identity function $f$ on $X$ is often denoted by $\mathrm{id}_X$.

In [set theory](wikipedia://en/27553), where a function is defined as a particular kind of [binary relation](wikipedia://en/3931), the identity function is given by the [identity relation](https://en.wikipedia.org/wiki/Identity_relation), or *diagonal* of $X$.[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Algebraic properties"}

## Algebraic properties {#Algebraic_properties}

If $f:X\rightarrow Y$ is any function, then $f\circ\mathrm{id}_X=f=\mathrm{id}_Y\circ f$, where "$\circ$" denotes [function composition](wikipedia://en/195947).[^o9] In particular, $\mathrm{id}_X$ is the [identity element](wikipedia://en/14962) of the [monoid](wikipedia://en/19652) of all functions from $X$ to $X$ (under function composition).

Since the identity element of a monoid is [unique](https://en.wikipedia.org/wiki/Unique_%28mathematics%29),[^o10] one can alternately define the identity function on $M$ to be this identity element. Such a definition generalizes to the concept of an [identity morphism](https://en.wikipedia.org/wiki/Identity_morphism) in [category theory](wikipedia://en/5869), where the [endomorphisms](wikipedia://en/9569) of $M$ need not be functions.

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The identity function is a [linear operator](wikipedia://en/18102) when applied to [vector spaces](wikipedia://en/32370).[^o13]
- In an $n$-[dimensional](wikipedia://en/38267) [vector space](wikipedia://en/32370) the identity function is represented by the [identity matrix](wikipedia://en/59718) $I_n$, regardless of the [basis](wikipedia://en/18420) chosen for the space.[^o14]
- The identity function on the positive [integers](wikipedia://en/14563) is a [completely multiplicative function](wikipedia://en/1055940) (essentially multiplication by 1), considered in [number theory](wikipedia://en/21527).[^o15]
- In a [metric space](wikipedia://en/20018) the identity function is trivially an [isometry](wikipedia://en/254777). An object without any [symmetry](wikipedia://en/53741) has as its [symmetry group](wikipedia://en/28186) the [trivial group](wikipedia://en/193059) containing only this isometry (symmetry type $\mathrm{C}_1$).[^o16]
- In a [topological space](wikipedia://en/30450), the identity function is always [continuous](wikipedia://en/6122#Continuous_functions_between_topological_spaces).[^o17]
- The identity function is [idempotent](wikipedia://en/14972).[^o18]
- Every map from a [set of a single element](wikipedia://en/381798) to itself is necessarily the identity map.

:::
