# Linear prediction

::: {#o1 .subject cue=lead name="Linear prediction"}

**Linear prediction** is a mathematical operation where future values of a [discrete-time](wikipedia://en/40240263) [signal](wikipedia://en/29324) are estimated as a [linear function](https://en.wikipedia.org/wiki/Linear_transformation) of previous samples.

:::

In [digital signal processing](https://en.wikipedia.org/wiki/Digital_signal_processing), linear prediction is often called [linear predictive coding](https://en.wikipedia.org/wiki/Linear_predictive_coding) (LPC) and can thus be viewed as a subset of [filter theory](https://en.wikipedia.org/wiki/Filter_theory). In [system analysis](https://en.wikipedia.org/wiki/System_analysis), a subfield of [mathematics](wikipedia://en/18831), linear prediction can be viewed as a part of [mathematical modelling](wikipedia://en/20590) or [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29).

## The prediction model {#The_prediction_model}

The most common representation is

$$\widehat{x}(n) = \sum_{i=1}^p a_i x(n-i)\,$$

where $\widehat{x}(n)$ is the predicted signal value, $x(n-i)$ the previous observed values, with $p \leq n$, and $a_i$ the predictor coefficients. The error generated by this estimate is

$$e(n) = x(n) - \widehat{x}(n)\,$$

where $x(n)$ is the true signal value.

These equations are valid for all types of (one-dimensional) linear prediction. The differences are found in the way the predictor coefficients $a_i$ are chosen.

For multi-dimensional signals the error metric is often defined as

$$e(n) = \|x(n) - \widehat{x}(n)\|\,$$

where $\|\cdot\|$ is a suitable chosen vector [norm](wikipedia://en/990534). Predictions such as $\widehat{x}(n)$ are routinely used within [Kalman filters](wikipedia://en/180855) and smoothers to estimate current and past signal values, respectively, from noisy measurements.

### Estimating the parameters {#Estimating_the_parameters}

The most common choice in optimization of parameters $a_i$ is the [root mean square](wikipedia://en/66819) criterion which is also called the [autocorrelation](wikipedia://en/2724) criterion. In this method we minimize the expected value of the squared error $E[e^2(n)]$, which yields the equation

$$\sum_{i=1}^p a_i R(j-i) = R(j),$$

for 1 ≤ *j* ≤ *p*, where *R* is the [autocorrelation](wikipedia://en/2724) of signal *x*<sub>*n*</sub>, defined as

$$\ R(i) = E\{x(n)x(n-i)\}\,,$$

and *E* is the [expected value](wikipedia://en/9653). In the multi-dimensional case this corresponds to minimizing the [L<sub>2</sub> norm](wikipedia://en/45194).

The above equations are called the [normal equations](https://en.wikipedia.org/wiki/Normal_equations) or [Yule-Walker equations](wikipedia://en/1434444#Yule–Walker_equations). In matrix form the equations can be equivalently written as

$$\mathbf{R A} = \mathbf{r}$$

where the autocorrelation matrix $\mathbf{R}$ is a symmetric, $p \times p$ [Toeplitz matrix](wikipedia://en/151569) with elements $r_{ij} = R(i-j), 0 \leq i, j<p$, the vector $\mathbf{r}$ is the autocorrelation vector $r_j = R(j), 0<j \leq p$, and $\mathbf{A} = [a_1, a_2, \,\cdots\, , a_{p-1}, a_p]$, the parameter vector.

Another, more general, approach is to minimize the sum of squares of the errors defined in the form

$$e(n) = x(n) - \widehat{x}(n) = x(n) - \sum_{i=1}^p a_i x(n-i) = - \sum_{i=0}^p a_i x(n-i)$$

where the optimisation problem searching over all $a_i$ must now be constrained with $a_0=-1$.

On the other hand, if the mean square prediction error is constrained to be unity and the prediction error equation is included on top of the normal equations, the augmented set of equations is obtained as

$$\ \mathbf{R A} = [1, 0, ... , 0]^{\mathrm{T}}$$

where the index $i$ ranges from 0 to $p$, and $\mathbf{R}$ is a $(p+1)\times(p+1)$ matrix.

Specification of the parameters of the linear predictor is a wide topic and a large number of other approaches have been proposed. In fact, the autocorrelation method is the most common and it is used, for example, for [speech coding](https://en.wikipedia.org/wiki/Speech_coding) in the [GSM](https://en.wikipedia.org/wiki/Global_System_for_Mobile_Communications) standard.

Solution of the matrix equation $\mathbf{R A} = \mathbf{r}$ is computationally a relatively expensive process. The [Gaussian elimination](wikipedia://en/13035) for matrix inversion is probably the oldest solution but this approach does not efficiently use the symmetry of $\mathbf{R}$. A faster algorithm is the [Levinson recursion](wikipedia://en/219847) proposed by [Norman Levinson](wikipedia://en/1090122) in 1947, which recursively calculates the solution, running in $O(n^{2})$ time (vs $O(n^{3})$ for Gaussian elimination).[^o4] In particular, the autocorrelation equations above may be more efficiently solved by the Durbin algorithm.[^o5]

In 1986, Philippe Delsarte and Y.V. Genin proposed an improvement to this algorithm called the split Levinson recursion, which requires about half the number of multiplications and divisions.[^o6] It uses a special symmetrical property of parameter vectors on subsequent recursion levels. That is, calculations for the optimal predictor containing $p$ terms make use of similar calculations for the optimal predictor containing $p-1$ terms.

Another way of identifying model parameters is to iteratively calculate state estimates using [Kalman filters](wikipedia://en/180855) and obtaining [maximum likelihood](wikipedia://en/140806) estimates within [expectation–maximization algorithms](wikipedia://en/470752).

For equally-spaced values, a polynomial interpolation is a [linear combination of the known values.](wikipedia://en/203565#Linear_combination_of_the_given_values) If the discrete time signal is estimated to obey a polynomial of degree $p-1,$ then the predictor coefficients $a_i$ are given by the corresponding row of the [triangle of binomial transform coefficients.](wikipedia://en/49497#The_Triangle_of_Binomial_Transform_Coefficients_is_like_Pascal's_Triangle.) This estimate might be suitable for a slowly varying signal with low noise. The predictions for the first few values of $p$ are

$$\begin{array}{lcl} p=1 & : & \widehat{x}(n) = 1x(n-1)\\ p=2 & : & \widehat{x}(n) = 2x(n-1) - 1x(n-2) \\ p=3 & : & \widehat{x}(n) = 3x(n-1) - 3x(n-2) + 1x(n-3)\\ p=4 & : & \widehat{x}(n) = 4x(n-1) - 6x(n-2) + 4x(n-3) - 1x(n-4)\\ \end{array}$$
