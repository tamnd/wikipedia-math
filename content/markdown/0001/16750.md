# Kleene star

::: {#o1 .subject cue=lead name="Kleene star"}

In [formal language theory](https://en.wikipedia.org/wiki/Formal_language_theory), the **Kleene star** (or **Kleene operator** or **Kleene closure**) refers to two related [unary operations](wikipedia://en/161006), that can be applied either to an [alphabet](wikipedia://en/4292269) of [symbols](wikipedia://en/24028642) or to a [formal language](wikipedia://en/10939), a set of strings (finite sequences of symbols).

:::

The Kleene star operator on an alphabet $V$ generates the set $V*$ of all finite-length strings over $V$, that is, finite sequences whose elements belong to $V$; in mathematics, it is more commonly known as the [free monoid](wikipedia://en/523166) construction. The Kleene star operator on a language $L$ generates another language $L*$, the set of all strings that can be obtained as a [concatenation](wikipedia://en/64474) of zero or more members of $L$. In both cases, repetitions are allowed.

The Kleene star operators are named after American mathematician [Stephen Cole Kleene](wikipedia://en/28805), who first introduced and widely used it to characterize [automata](wikipedia://en/103356) for [regular expressions](wikipedia://en/25717).

## Of an alphabet {#Of_an_alphabet}

Given an alphabet $V$, define

$V^{0}=\{\varepsilon\}$ (the set consists only of the empty string),

$$V^{1}=V,$$

and define recursively the set

$V^{i+1}=\{wv: w\in V^{i} \text{ and } v\in V \}$ for each $i>0,$

where $wv$ denotes the string obtained by appending the single character $v$ to the end of $w$. Here, *$V^i$* can be understood to be the set of all strings of length exactly $i$, with characters from $V$.

The definition of Kleene star on $V$ is[^o11]

$$V^*=\bigcup_{i \ge 0 }V^i = V^0 \cup V^1 \cup V^2 \cup V^3 \cup V^4 \cup \cdots.$$

## Of a language {#Of_a_language}

Given a language $L$ (any finite or infinite set of strings), define

$L^{0}=\{\varepsilon\}$ (the language consisting only of the empty string),

$$L^{1}=L,$$

and define recursively the set

$L^{i+1}=\{wv: w\in L^{i} \text{ and } v\in L \}$ for each $i>0,$

where $wv$ denotes the string obtained by concatenating $w$ and $v$. Here, *$L^i$* can be understood to be the set of all strings that can be obtained by concatenating exactly $i$ strings from $L$, allowing repetitions.

The definition of Kleene star on $L$ is[^o4]

$$L^*=\bigcup_{i \ge 0 }L^i = L^0 \cup L^1 \cup L^2 \cup L^3 \cup L^4 \cup \cdots.$$

::: {#o6 .pointer-item cue=pointer name="Kleene plus"}

## Kleene plus {#Kleene_plus}

In some [formal language](wikipedia://en/10939) studies, (e.g. [AFL theory](wikipedia://en/11148549)) a variation on the Kleene star operation called the *Kleene plus* is used. The Kleene plus omits the $V^{0}$ or $L^0$ term in the above unions. In other words, the Kleene plus on $V$ is

$$V^+=\bigcup_{i \geq 1} V^i = V^1 \cup V^2 \cup V^3 \cup \cdots,$$

or

$$V^+ = V^*V.$$

:::

## Examples {#Examples}

Example of Kleene star applied to a set of strings:

{"ab","c"}<sup>\*</sup> = { ε, "ab", "c", "abab", "abc", "cab", "cc", "ababab", "ababc", "abcab", "abcc", "cabab", "cabc", "ccab", "ccc", ...}.

Example of Kleene star applied to a set of strings without the [prefix property](https://en.wikipedia.org/wiki/Prefix_property):

{"a","ab","b"}<sup>\*</sup> = { ε, "a", "ab", "b", "aa", "aab", "aba", "abab", "abb", "ba", "bab", "bb", ...}; In this example, the string "aab" can be obtained in two different ways. The [Sardinas-Patterson algorithm](https://en.wikipedia.org/wiki/Sardinas-Patterson_algorithm) can be used to check for a given *V* whether any member of *V*<sup>\*</sup> can be obtained in more than one way.

Example of Kleene and Kleene plus applied to a set of characters (following the [C programming language](https://en.wikipedia.org/wiki/C_programming_language) convention where a character is denoted by single quotes and a string is denoted by double quotes):

{'a', 'b', 'c'}<sup>\*</sup> = { ε, "a", "b", "c", "aa", "ab", "ac", "ba", "bb", "bc", "ca", "cb", "cc", "aaa", "aab", ...}.

{'a', 'b', 'c'}<sup>\+</sup> = { "a", "b", "c", "aa", "ab", "ac", "ba", "bb", "bc", "ca", "cb", "cc", "aaa", "aab", ...}.

:::

## Properties {#Properties}

- If $V$ is any [finite](wikipedia://en/11742) or [countably infinite set](https://en.wikipedia.org/wiki/Countably_infinite_set) of characters, then *$V^*$* is a countably infinite set.[^o11] As a result, each [formal language](wikipedia://en/10939) over a finite or countably infinite alphabet $\Sigma$ is countable, since it is a subset of the countably infinite set $\Sigma^{*}$.
- $(L^{*})^{*}=L^{*}$, which means that the Kleene star operator is an [idempotent](https://en.wikipedia.org/wiki/Idempotent) [unary operator](https://en.wikipedia.org/wiki/Unary_operator), as $(L^{*})^{i}=L^{*}$ for every $i\geq 1$.
- $V^{*}=\{\varepsilon\}$, if $V$ is the [empty set](wikipedia://en/9566) ∅. For the version of the Kleene star operator on languages, $L^{*}=\{\varepsilon\}$ when $L$ is either the [empty set](wikipedia://en/9566) ∅ or the singleton set $\{\varepsilon\}$.

:::

::: {#o13 .statement kind=statement/generalization cue=heading name="Generalization"}

## Generalization {#Generalization}

[Strings](wikipedia://en/27701) form a [monoid](wikipedia://en/19652) with concatenation as the binary operation and ε the identity element. In addition to strings, the Kleene star is defined for any monoid. More precisely, let (*M*, ⋅) be a monoid, and *S* ⊆ *M*. Then *S*<sup>\*</sup> is the smallest submonoid of *M* containing *S*; that is, *S*<sup>\*</sup> contains the neutral element of *M*, the set *S*, and is such that if *x*,*y* ∈ *S*<sup>\*</sup>, then *x*⋅*y* ∈ *S*<sup>\*</sup>.

Furthermore, the Kleene star is generalized by including the \*-operation (and the union) in the [algebraic structure](wikipedia://en/106364) itself by the notion of [complete star semiring](https://en.wikipedia.org/wiki/Complete_star_semiring).[^o14]

:::
