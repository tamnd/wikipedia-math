# Identity element

::: {#o1 .subject cue=lead name="Identity element"}

In [mathematics](wikipedia://en/18831), an **identity element** or **neutral element** of a [binary operation](wikipedia://en/3948) is an element that leaves unchanged every element when the operation is applied.[^o2][^o3] For example, 0 is an identity element of the [addition](wikipedia://en/61338) of [real numbers](wikipedia://en/20646438). This concept is used in [algebraic structures](wikipedia://en/106364) such as [groups](wikipedia://en/19447) and [rings](wikipedia://en/48404). The term *identity element* is often shortened to *identity* (as in the case of *additive identity* for 0 and *multiplicative identity* for 1)[^o4] when there is no possibility of confusion, but the identity implicitly depends on the binary operation it is associated with.

:::

::: {#o6 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Let $(S,\,\ast)$ be a set $S$ equipped with a [binary operation](wikipedia://en/3948) ∗. Then an element $e$ of $S$ is called a left identity element if $e \ast s = s$ for all $s$ in $S$, and a right identity element if $s \ast e = s$ for all $s$ in $S$.[^o7] If $e$ is both a left identity and a right identity, then it is called a **two-sided identity**, or simply an **identity**.[^o8][^o9][^o10][^o11][^o12]

An identity with respect to addition is called an [additive identity](wikipedia://en/4178225) (often denoted as 0) and an identity with respect to multiplication is called a **multiplicative identity** (often denoted as 1).[^o4] These need not be ordinary addition and multiplication—as the underlying operation could be rather arbitrary. In the case of a [group](wikipedia://en/19447) for example, the identity element is sometimes simply denoted by the symbol $e$. The distinction between additive and multiplicative identity is used most often for sets that support both binary operations, such as [rings](wikipedia://en/48404), [integral domains](wikipedia://en/15462), and [fields](wikipedia://en/10603). The multiplicative identity is often called **unity** in the latter context (a ring with unity).[^o13][^o14][^o15] This should not be confused with a [unit](wikipedia://en/289666) in ring theory, which is any element having a [multiplicative inverse](wikipedia://en/229940). By its own definition, unity itself is necessarily a unit.[^o16][^o17] The symbol $e$ was chosen because it is the first letter in *Einheit*, the German for "unit" or "unity."[^o18]

## Properties {#Properties}

In the example *S* = {*e,f*} with the equalities given, *S* is a [semigroup](wikipedia://en/27799). It demonstrates the possibility for $(S,\,\ast)$ to have several left identities. In fact, every element can be a left identity. In a similar manner, there can be several right identities. But if there is both a right identity and a left identity, then they must be equal, resulting in a single two-sided identity.

To see this, note that if $l$ is a left identity and $r$ is a right identity, then $l = l \ast r = r$. In particular, there can never be more than one two-sided identity: if there were two, say $e$ and $f$, then $e \ast f$ would have to be equal to both $e$ and $f$.

It is also quite possible for $(S,\,\ast)$ to have *no* identity element,[^o48] such as the case of even integers under the multiplication operation.[^o4] Another common example is the [cross product](wikipedia://en/157092) of [vectors](wikipedia://en/32533), where the absence of an identity element is related to the fact that the [direction](wikipedia://en/54516626) of any nonzero cross product is always [orthogonal](https://en.wikipedia.org/wiki/Orthogonal) to any element multiplied. That is, it is not possible to obtain a non-zero vector in the same direction as the original. Yet another example of structure without identity element involves the additive [semigroup](wikipedia://en/27799) of [positive](https://en.wikipedia.org/wiki/Positive_number) [natural numbers](wikipedia://en/21474).
