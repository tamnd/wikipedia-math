# Mandelbrot set

*Image: Mandel zoom 00 mandelbrot set.jpg.* The Mandelbrot set plotted on the [complex plane](wikipedia://en/217628) within a continuously colored environment

::: {#o1 .subject cue=lead name="Mandelbrot set"}

The **Mandelbrot set** ()[^o2] is a two-dimensional [set](wikipedia://en/26691). It is defined in the [complex plane](wikipedia://en/217628) as the [complex numbers](wikipedia://en/5826) $c$ for which the function $f_c(z)=z^2+c$ does not [diverge](wikipedia://en/5493795) to infinity when [iterated](wikipedia://en/68833) starting at $z=0$. In other words, it is the set of $c$ for which the sequence $f_c(0)$, $f_c(f_c(0))$, and so on, remains bounded in [absolute value](wikipedia://en/991).[^o4]

:::

This set was first defined and drawn by [Robert W. Brooks](wikipedia://en/34336906) and Peter Matelski in 1978, as part of a study of [Kleinian groups](wikipedia://en/1362652).[^o18] Afterwards, in 1980, [Benoit Mandelbrot](wikipedia://en/3999) obtained high-quality visualizations of the set while working at [IBM](https://en.wikipedia.org/wiki/IBM)'s [Thomas J. Watson Research Center](https://en.wikipedia.org/wiki/Thomas_J._Watson_Research_Center) in [Yorktown Heights, New York](https://en.wikipedia.org/wiki/Yorktown_Heights,_New_York).[^o5]

*Image: Mandelbrot sequence new.gif.* Zooming into the Mandelbrot set's "Seahorse Valley" with high iteration count

Images of the Mandelbrot set exhibit an infinitely complicated [boundary](wikipedia://en/72824) that reveals progressively ever-finer [recursive](wikipedia://en/25407) detail at increasing magnifications;[^o6][^o7] mathematically, the boundary of the Mandelbrot set is a [fractal curve](wikipedia://en/4972605).[^o8] The "style" of this recursive detail depends on the region of the set boundary being examined.[^o9] Images of the Mandelbrot set are created by determining whether the sequence $f_c(0), f_c(f_c(0)),f_c(f_c(f_c(0))),\dotsc$ [goes to infinity](wikipedia://en/27838#Bounded) for each sampled [complex number](wikipedia://en/5826) c.[^o10] The [real](https://en.wikipedia.org/wiki/Real_numbers) and [imaginary parts](wikipedia://en/14554) of $c$ are mapped as [image coordinates](https://en.wikipedia.org/wiki/Image_coordinate) on the [complex plane](wikipedia://en/217628) and colored based on the point at which the sequence $|f_c(0)|, |f_c(f_c(0))|,\dotsc$ crosses an arbitrary threshold.[^o10] If $c$ is held constant and the initial value of $z$ is varied instead, the corresponding [Julia set](wikipedia://en/56434) for the point $c$ is obtained.[^o11]

The Mandelbrot set is well-known,[^o12] even outside mathematics,[^o13] for how it exhibits complex fractal structures when visualized and magnified, despite having a relatively simple definition, and is commonly cited as an example of [mathematical beauty](wikipedia://en/18974136).[^o14][^o15][^o16]

## History {#History}

*Image: Mandel.png.* The first published picture of the Mandelbrot set, by [Robert W. Brooks](wikipedia://en/34336906) and Peter Matelski in 1978

The Mandelbrot set has its origin in [complex dynamics](wikipedia://en/650518), a field first investigated by the [French mathematicians](https://en.wikipedia.org/wiki/French_mathematicians) [Pierre Fatou](wikipedia://en/629100) and [Gaston Julia](wikipedia://en/249107) at the beginning of the 20th century. The fractal was first defined and drawn in 1978 by [Robert W. Brooks](wikipedia://en/34336906) and Peter Matelski as part of a study of [Kleinian groups](wikipedia://en/1362652).[^o18] On 1 March 1980, at [IBM](https://en.wikipedia.org/wiki/IBM)'s [Thomas J. Watson Research Center](https://en.wikipedia.org/wiki/Thomas_J._Watson_Research_Center) in [Yorktown Heights, New York](https://en.wikipedia.org/wiki/Yorktown_Heights,_New_York), [Benoit Mandelbrot](wikipedia://en/3999) first visualized the set.[^o19]

Mandelbrot studied the [parameter space](wikipedia://en/2882813) of [quadratic polynomials](https://en.wikipedia.org/wiki/Quadratic_polynomial) in an article that appeared in 1980.[^o20] The mathematical study of the Mandelbrot set really began with work by the mathematicians [Adrien Douady](wikipedia://en/1604604) and [John H. Hubbard](wikipedia://en/6674772) (1985),[^o21] who established many of its fundamental properties and named the set in honor of Mandelbrot for his influential work in [fractal geometry](https://en.wikipedia.org/wiki/Fractal_geometry).

The mathematicians [Heinz-Otto Peitgen](wikipedia://en/1562451) and [Peter Richter](https://en.wikipedia.org/wiki/Peter_Richter) became well known for promoting the set with photographs, books (1986),[^o22] and an internationally touring exhibit of the German [Goethe-Institut](https://en.wikipedia.org/wiki/Goethe-Institut) (1985).[^o23][^o24]

The cover article of the August 1985 *[Scientific American](https://en.wikipedia.org/wiki/Scientific_American)* introduced the [algorithm](wikipedia://en/775) for computing the Mandelbrot set. The cover was created by Peitgen, Richter and [Saupe](https://en.wikipedia.org/wiki/Dietmar_Saupe) at the [University of Bremen](https://en.wikipedia.org/wiki/University_of_Bremen).[^o25] The Mandelbrot set became prominent in the mid-1980s as a [computer-graphics demo](https://en.wikipedia.org/wiki/Demo_%28computer_programming%29), when [personal computers](https://en.wikipedia.org/wiki/Personal_computer) became powerful enough to plot and display the set in high resolution.[^o26]

The work of Douady and Hubbard occurred during an increase in interest in [complex dynamics](wikipedia://en/650518) and [abstract mathematics](https://en.wikipedia.org/wiki/Abstract_mathematics),[^o27] and the topological and geometric study of the Mandelbrot set remains a key topic in the field of complex dynamics.[^o28]

## Formal definition {#Formal_definition}

*Image: Mandelbrot-with-xy-grid.png.* The set's location on the complex plane

The Mandelbrot set is the [uncountable set](wikipedia://en/32248) of values of *c* in the [complex plane](wikipedia://en/217628) for which the [orbit](wikipedia://en/252250) of the [critical point](wikipedia://en/11735693#Critical_points) $z = 0$ under [iteration](wikipedia://en/1448702) of the [quadratic map](https://en.wikipedia.org/wiki/Quadratic_map)

$z \mapsto z^2 + c$ [^o31]

remains [bounded](https://en.wikipedia.org/wiki/Bounded_sequence).[^o32] Thus, a [complex number](wikipedia://en/5826) *c* is a member of the Mandelbrot set if, when starting with $z_0 = 0$ and applying the iteration repeatedly, the [absolute value](wikipedia://en/991) of $z_n$ remains bounded for all $n \in \mathbb{Z}^+$.

For example, for *c* = 1, the [sequence](wikipedia://en/27838) is 0, 1, 2, 5, 26, ..., which tends to [infinity](wikipedia://en/20110824), so 1 is not an element of the Mandelbrot set. On the other hand, for $c=-1$, the sequence is 0, −1, 0, −1, 0, ..., which is bounded, so −1 does belong to the set.

The Mandelbrot set can also be defined as the [connectedness locus](https://en.wikipedia.org/wiki/Connectedness_locus) of the family of [quadratic](wikipedia://en/25175) [polynomials](wikipedia://en/23000) $f(z) = z^2 + c$, the subset of the space of parameters $c$ for which the [Julia set](wikipedia://en/56434) of the corresponding polynomial forms a [connected set](https://en.wikipedia.org/wiki/Connected_set).[^o33] In the same way, the [boundary](wikipedia://en/72824) of the Mandelbrot set can be defined as the [bifurcation locus](wikipedia://en/5164765) of this quadratic family, the subset of parameters near which the dynamic behavior of the polynomial (when it is [iterated](wikipedia://en/1448702) repeatedly) changes drastically.

:::

## Basic properties {#Basic_properties}

The Mandelbrot set is a [compact set](https://en.wikipedia.org/wiki/Compact_set), since it is [closed](wikipedia://en/47279) and contained in the [closed disk](https://en.wikipedia.org/wiki/Closed_disk) of radius 2 centred on [zero](wikipedia://en/1313432). A point $c$ belongs to the Mandelbrot set if and only if $|z_n|\leq 2$ for all $n\geq 0$. In other words, the [absolute value](wikipedia://en/991) of $z_n$ must remain at or below 2 for $c$ to be in the Mandelbrot set, $M$, and if that absolute value exceeds 2, the sequence will escape to infinity. Since $c=z_1$, it follows that $|c|\leq 2$, establishing that $c$ will always be in the closed disk of radius 2 around the origin.[^o36]

*Image: Verhulst-Mandelbrot-Bifurcation.jpg.* Correspondence between the Mandelbrot set and the [bifurcation diagram](wikipedia://en/79173) of the [quadratic map](wikipedia://en/11735693)

*Image: Logistic Map Bifurcations Underneath Mandelbrot Set.gif.* With $z_{n}$ iterates plotted on the vertical axis, the Mandelbrot set can be seen to bifurcate at the period-2<sup>k</sup> components.

The [intersection](wikipedia://en/23476429) of $M$ with the real axis is the interval $\left[-2,\frac{1}{4}\right]$. The parameters along this interval can be put in [one-to-one correspondence](https://en.wikipedia.org/wiki/One-to-one_correspondence) with those of the real [logistic family](wikipedia://en/18137),

$$x_{n+1} = r x_n(1-x_n),\quad r\in[1,4].$$

The correspondence is given by

$$r = 1+\sqrt{1- 4 c}, \quad c = \frac{r}{2}\left(1-\frac{r}{2}\right), \quad z_n = r\left(\frac{1}{2} - x_n\right).$$

This gives a correspondence between the entire [parameter space](wikipedia://en/2882813) of the logistic family and that of the Mandelbrot set.[^o37]

Douady and Hubbard showed that the Mandelbrot set is [connected](wikipedia://en/6233). They constructed an explicit [conformal isomorphism](wikipedia://en/14110) between the complement of the Mandelbrot set and the complement of the [closed unit disk](https://en.wikipedia.org/wiki/Closed_unit_disk). Mandelbrot had originally conjectured that the Mandelbrot set is [disconnected](https://en.wikipedia.org/wiki/Disconnected_%28topology%29). This conjecture was based on computer pictures generated by programs that are unable to detect the thin filaments connecting different parts of $M$. Upon further experiments, he revised his conjecture, deciding that $M$ should be connected. A [topological](wikipedia://en/29954) proof of the connectedness was discovered in 2001 by [Jeremy Kahn](wikipedia://en/48625747).[^o38]

*Image: Wakes near the period 1 continent in the Mandelbrot set.png.* External rays of wakes near the period 1 continent in the Mandelbrot set

The dynamical formula for the [uniformisation](wikipedia://en/288270) of the complement of the Mandelbrot set, arising from Douady and Hubbard's proof of the connectedness of $M$, gives rise to [external rays](wikipedia://en/4804435) of the Mandelbrot set. These rays can be used to study the Mandelbrot set in combinatorial terms and form the backbone of the [Yoccoz parapuzzle](wikipedia://en/589307#Mathematical_work).[^o39]

The [boundary](wikipedia://en/72824) of the Mandelbrot set is the [bifurcation locus](wikipedia://en/5164765) of the family of quadratic polynomials. In other words, the boundary of the Mandelbrot set is the set of all parameters $c$ for which the dynamics of the quadratic map $z_n=z_{n-1}^2+c$ exhibits sensitive dependence on $c,$ i.e. changes abruptly under arbitrarily small changes of $c.$ It can be constructed as the limit set of a sequence of [plane algebraic curves](https://en.wikipedia.org/wiki/Algebraic_curves), the *Mandelbrot curves*, of the general type known as [polynomial lemniscates](wikipedia://en/5222945). The Mandelbrot curves are defined by setting $p_0=z,\ p_{n+1}=p_n^2+z$, and then interpreting the set of points $|p_n(z)| = 2$ in the complex plane as a curve in the real [Cartesian plane](wikipedia://en/7706) of degree $2^{n+1}$in *x* and *y*.[^o40] Each curve $n > 0$ is the mapping of an initial circle of radius 2 under $p_n$. These algebraic curves appear in images of the Mandelbrot set computed using the "escape time algorithm" mentioned below.

## Other properties {#Other_properties}

### Main cardioid and period bulbs {#Main_cardioid_and_period_bulbs}

*Image: Mandelbrot Set – Periodicities coloured.png.* Periods of hyperbolic components

The *main [cardioid](wikipedia://en/642101)* is the period 1 continent.[^o43] It is the region of parameters $c$ for which the map $f_c(z) = z^2 + c$ has an [attracting fixed point](https://en.wikipedia.org/wiki/Periodic_points_of_complex_quadratic_mappings).[^o44] The set comprises all parameters of the form $c(\mu) := \frac\mu2\left(1-\frac\mu2\right)$ where $\mu$ lies within the [open unit disk](https://en.wikipedia.org/wiki/Open_unit_disk).[^o45]

Attached to the left of the main cardioid at the point $c=-3/4$, the *period-2 bulb* is visible.[^o45] This region consists of values of $c$ for which $f_c$ has an [attracting cycle of period 2](https://en.wikipedia.org/wiki/Periodic_points_of_complex_quadratic_mappings). It is the filled circle of radius 1/4 centered around −1.[^o45]

*Image: Animated cycle.gif.* Attracting cycle in 2/5-bulb plotted over [Julia set](wikipedia://en/56434) (animation)

More generally, for every positive integer $q>2$, there are $\phi(q)$ circular bulbs tangent to the main cardioid called *period-q bulbs* (where $\phi$ denotes the [Euler phi function](wikipedia://en/53452)), which consist of parameters $c$ for which $f_c$ has an attracting cycle of period $q$. More specifically, for each primitive $q$th root of unity $r=e^{2\pi i\frac{p}{q}}$ (where $0<\frac{p}{q}<1$), there is one period-q bulb called the $\frac{p}{q}$ bulb, which is tangent to the main cardioid at the parameter $c_{\frac{p}{q}} := c(r) = \frac{r}2\left(1-\frac{r}2\right),$ and which contains parameters with $q$-cycles having combinatorial rotation number $\frac{p}{q}$.[^o46] The $q$ periodic [Fatou components](wikipedia://en/10422205) containing the attracting cycle meet at the *$\alpha$-fixed point*. If these are labelled counterclockwise as $U_0,\dots,U_{q-1}$, then component $U_j$ is mapped by $f_c$ to the component $U_{j+p\,(\operatorname{mod} q)}$.[^o45]

*Image: Juliacycles1.png.* Attracting cycles and [Julia sets](wikipedia://en/56434) for parameters in the 1/2, 3/7, 2/5, 1/3, 1/4, and 1/5 bulbs

### Hyperbolic components {#Hyperbolic_components}

Bulbs that are interior components of the Mandelbrot set in which the maps $f_c$ have an attracting periodic cycle are called *hyperbolic components*.[^o48]

It is conjectured that these are the *only* [interior regions](wikipedia://en/55610) of $M$ and that they are [dense](wikipedia://en/23523594) in $M$. This problem, known as *density of hyperbolicity*, is one of the most important open problems in [complex dynamics](wikipedia://en/650518).[^o49] Hypothetical non-hyperbolic components of the Mandelbrot set are often referred to as "queer" or ghost components.[^o50][^o51] For real quadratic polynomials, this question was proved in the 1990s independently by Lyubich and by Graczyk and Świątek. (Note that hyperbolic components intersecting the real axis correspond exactly to periodic windows in the [Feigenbaum diagram](wikipedia://en/79173). So this result states that such windows exist near every parameter in the diagram.)

Not every hyperbolic component can be reached by a sequence of direct bifurcations from the main cardioid of the Mandelbrot set. Such a component can be reached by a sequence of direct bifurcations from the main cardioid of a little Mandelbrot copy (see below).

*Image: Centers8.png.* Centers of 983 hyperbolic components of the Mandelbrot set

Each of the hyperbolic components has a *center*, which is a point *c* such that the inner Fatou domain for $f_c(z)$ has a super-attracting cycle—that is, that the attraction is infinite. This means that the cycle contains the critical point 0, so that 0 is iterated back to itself after some iterations. Therefore, $f_c^n(0) = 0$ for some *n*. If we call this polynomial $Q^{n}(c)$ (letting it depend on *c* instead of *z*), we have that $Q^{n+1}(c) = Q^{n}(c)^{2} + c$ and that the degree of $Q^{n}(c)$ is $2^{n-1}$. Therefore, constructing the centers of the hyperbolic components is possible by successively solving the equations $Q^{n}(c) = 0, n = 1, 2, 3, ...$. The number of new centers produced in each step is given by Sloane's .

### Local connectivity {#Local_connectivity}

It is conjectured that the Mandelbrot set is [locally connected](https://en.wikipedia.org/wiki/Locally_connected). This conjecture is known as *MLC* (for *Mandelbrot locally connected*). By the work of [Adrien Douady](wikipedia://en/1604604) and [John H. Hubbard](wikipedia://en/6674772), this conjecture would result in a simple abstract "pinched disk" model of the Mandelbrot set. In particular, it would imply the important *hyperbolicity conjecture* mentioned above.[^o54]

The work of [Jean-Christophe Yoccoz](wikipedia://en/589307) established local connectivity of the Mandelbrot set at all finitely [renormalizable](wikipedia://en/291453) parameters; that is, roughly speaking those contained only in finitely many small Mandelbrot copies.[^o55] Since then, local connectivity has been proved at many other points of $M$, but the full conjecture is still open.

:::

### Self-similarity {#Self-similarity}

*Image: Self-Similarity-Zoom.gif.* [Self-similarity](wikipedia://en/28782) in the Mandelbrot set shown by zooming in on a round feature while panning in the negative-*x* direction. The display center pans left from the fifth to the seventh round feature (−1.4002, 0) to (−1.4011, 0) while the view magnifies by a factor of 21.78 to approximate the square of the [Feigenbaum ratio](wikipedia://en/79150).

The Mandelbrot set is [self-similar](https://en.wikipedia.org/wiki/Self-similar) under magnification in the neighborhoods of the [Misiurewicz points](wikipedia://en/9612488). It is also conjectured to be self-similar around generalized [Feigenbaum points](https://en.wikipedia.org/wiki/Feigenbaum_point) (e.g., −1.401155 or −0.1528 + 1.0397*i*), in the sense of converging to a limit set.[^o57][^o58] The Mandelbrot set in general is quasi-self-similar, as small slightly different versions of itself can be found at arbitrarily small scales. These copies of the Mandelbrot set are all slightly different, mostly because of the thin threads connecting them to the main body of the set.[^o59]

### Further results {#Further_results}

The [Hausdorff dimension](wikipedia://en/14294) of the [boundary](wikipedia://en/72824) of the Mandelbrot set equals 2 as determined by a result of [Mitsuhiro Shishikura](wikipedia://en/4403736).[^o65] The fact that this is greater by a whole integer than its topological dimension, which is 1, reflects the extreme [fractal](wikipedia://en/10913) nature of the Mandelbrot set boundary. Roughly speaking, Shishikura's result states that the Mandelbrot set boundary is so "wiggly" that it locally [fills space](wikipedia://en/352398) as efficiently as a two-dimensional planar region. Curves with Hausdorff dimension 2, despite being (topologically) 1-dimensional, are oftentimes capable of having nonzero area (more formally, a nonzero planar [Lebesgue measure](wikipedia://en/18198)). Whether this is the case for the Mandelbrot set boundary is an unsolved problem.

It has been shown that the generalized Mandelbrot set in higher-dimensional [hypercomplex number](wikipedia://en/51438) spaces (i.e. when the power $\alpha$ of the iterated variable $z$ tends to infinity) is convergent to the unit ($\alpha$−1)-sphere.[^o61]

In the [Blum–Shub–Smale](https://en.wikipedia.org/wiki/Blum–Shub–Smale_machine) model of [real computation](wikipedia://en/397247), the Mandelbrot set is not computable, but its complement is [computably enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable_set). Many simple objects (e.g., the graph of exponentiation) are also not computable in the BSS model. At present, it is unknown whether the Mandelbrot set is computable in models of real computation based on [computable analysis](wikipedia://en/21535996), which correspond more closely to the intuitive notion of "plotting the set by a computer". Hertling has shown that the Mandelbrot set is computable in this model if the hyperbolicity conjecture is true.[^o62]

### Relationship with Julia sets {#Relationship_with_Julia_sets}

*Image: Julia Mandelbrot Relationship.png.* A mosaic made by matching Julia sets to their values of c on the complex plane. The Mandelbrot set is a map of connected Julia sets.

As a consequence of the definition of the Mandelbrot set, there is a close correspondence between the [geometry](wikipedia://en/18973446) of the Mandelbrot set at a given point and the structure of the corresponding [Julia set](wikipedia://en/56434). For instance, a value of c belongs to the Mandelbrot set if and only if the corresponding Julia set is connected. Thus, the Mandelbrot set may be seen as a map of the connected Julia sets.[^o64]

This principle is exploited in virtually all deep results on the Mandelbrot set. For example, Shishikura proved that, for a dense set of parameters in the boundary of the Mandelbrot set, the Julia set has [Hausdorff dimension](wikipedia://en/14294) two, and then transfers this information to the parameter plane.[^o65] Similarly, Yoccoz first proved the local connectivity of Julia sets, before establishing it for the Mandelbrot set at the corresponding parameters.[^o55]

## Geometry {#Geometry}

For every rational number $\tfrac{p}{q}$, where *p* and *q* are [coprime](https://en.wikipedia.org/wiki/Coprime), a hyperbolic component of period *q* bifurcates from the main cardioid at a point on the edge of the cardioid corresponding to an [internal angle](https://en.wikipedia.org/wiki/Internal_angle) of $\tfrac{2\pi p}{q}$.[^o67] The part of the Mandelbrot set connected to the main cardioid at this bifurcation point is called the ***p*/*q*-limb**. Computer experiments suggest that the [diameter](wikipedia://en/8007) of the limb tends to zero like $\tfrac{1}{q^2}$. The best current estimate known is the Yoccoz-inequality, which states that the size tends to zero like $\tfrac{1}{q}$.

A period-*q* limb will have $q-1$ "antennae" at the top of its limb. The period of a given bulb is determined by counting these antennas. The numerator of the rotation number, *p*, is found by numbering each antenna counterclockwise from the limb from 1 to $q-1$ and finding which antenna is the shortest.[^o67]

### Pi in the Mandelbrot set {#Pi_in_the_Mandelbrot_set}

There are intriguing experiments in the Mandelbrot set that lead to the occurrence of the number $\pi$. For a parameter $c = -\tfrac{3}{4}+ i\varepsilon$ with $\varepsilon>0$, verifying that $c$ is not in the Mandelbrot set means iterating the sequence $z \mapsto z^2 + c$ starting with $z=0$, until the sequence leaves the disk around $0$ of any radius $R>2$. This is motivated by the (still open) question whether the vertical line at real part $-3/4$ intersects the Mandelbrot set at points away from the real line. It turns out that the necessary number of iterations, multiplied by $\varepsilon$, converges to pi. For example, for *$\varepsilon$* = 0.0000001, and $R=2$, the number of iterations is 31415928 and the product is 3.1415928.[^o69] This experiment was performed independently by many people in the early 1990s, if not before; for instance by David Boll.

Analogous observations have also been made at the parameters $c=-5/4$ and $c=1/4$ (with a necessary modification in the latter case). In 2001, Aaron Klebanoff published a (non-conceptual) proof for this phenomenon at $c=1/4$[^o70]

In 2023, Paul Siewert developed, in his Bachelor thesis, a conceptual proof also for the value $c=1/4$, explaining why the number pi occurs (geometrically as half the circumference of the unit circle).[^o71]

In 2025, the three high school students Thies Brockmöller, Oscar Scherz, and Nedim Srkalovic extended the theory and the conceptual proof to all the infinitely many bifurcation points in the Mandelbrot set.[^o72]

### Fibonacci sequence in the Mandelbrot set {#Fibonacci_sequence_in_the_Mandelbrot_set}

The Mandelbrot Set features a fundamental cardioid shape adorned with numerous bulbs directly attached to it.[^o74] Understanding the arrangement of these bulbs requires a detailed examination of the Mandelbrot Set's boundary. As one zooms into specific portions with a geometric perspective, precise deducible information about the location within the boundary and the corresponding dynamical behavior for parameters drawn from associated bulbs emerges.[^o75]

The iteration of the quadratic polynomial $f_c(z) = z^2 + c$, where $c$ is a parameter drawn from one of the bulbs attached to the main cardioid within the Mandelbrot Set, gives rise to maps featuring attracting cycles of a specified period $q$ and a rotation number $p/q$. In this context, the attracting cycle of exhibits rotational motion around a central fixed point, completing an average of $p/q$ revolutions at each iteration.[^o75][^o76]

The bulbs within the Mandelbrot Set are distinguishable by both their attracting cycles and the geometric features of their structure. Each bulb is characterized by an antenna attached to it, emanating from a junction point and displaying a certain number of spokes indicative of its period. For instance, the $2/5$ bulb is identified by its attracting cycle with a rotation number of $2/5$. Its distinctive antenna-like structure comprises a junction point from which five spokes emanate. Among these spokes, called the principal spoke is directly attached to the $2/5$ bulb, and the 'smallest' non-principal spoke is positioned approximately $2/5$ of a turn counterclockwise from the principal spoke, providing a distinctive identification as a $2/5$-bulb.[^o77] This raises the question: how does one discern which among these spokes is the 'smallest'?[^o74][^o77] In the theory of [external rays](wikipedia://en/4804435) developed by [Douady](wikipedia://en/1604604) and [Hubbard](wikipedia://en/6674772),[^o78] there are precisely two external rays landing at the root point of a satellite hyperbolic component of the Mandelbrot Set. Each of these rays possesses an external angle that undergoes doubling under the angle doubling map $\theta\mapsto$ $2\theta$. According to this theorem, when two rays land at the same point, no other rays between them can intersect. Thus, the 'size' of this region is measured by determining the length of the arc between the two angles.[^o75]

If the root point of the main cardioid is the cusp at $c=1/4$, then the main cardioid is the $0/1$-bulb. The root point of any other bulb is just the point where this bulb is attached to the main cardioid. This prompts the inquiry: which is the largest bulb between the root points of the $0/1$ and $1/2$-bulbs? It is clearly the $1/3$-bulb. And note that $1/3$ is obtained from the previous two fractions by [Farey addition](wikipedia://en/1421466), i.e., adding the numerators and adding the denominators

$\frac{0}{1}$ $\oplus$ $\frac{1}{2}$$=$$\frac{1}{3}$

Similarly, the largest bulb between the $1/3$ and $1/2$-bulbs is the $2/5$-bulb, again given by Farey addition.

$\frac{1}{3}$ $\oplus$ $\frac{1}{2}$$=$$\frac{2}{5}$

The largest bulb between the $2/5$ and $1/2$-bulb is the $3/7$-bulb, while the largest bulb between the $2/5$ and $1/3$-bulbs is the $3/8$-bulb, and so on.[^o75][^o79] The arrangement of bulbs within the Mandelbrot set follows a remarkable pattern governed by the [Farey tree](https://en.wikipedia.org/wiki/Farey_tree), a structure encompassing all rationals between $0$ and $1$. This ordering positions the bulbs along the boundary of the main cardioid precisely according to the [rational numbers](wikipedia://en/19727024) in the [unit interval](wikipedia://en/49324).[^o77]

*Image: Fibonacci sequence within the Mandelbrot set.png.* Fibonacci sequence within the Mandelbrot set

Starting with the $1/3$ bulb at the top and progressing towards the $1/2$ circle, the sequence unfolds systematically: the largest bulb between $1/2$ and $1/3$ is $2/5$, between $1/3$ and $2/5$ is $3/8$, and so forth.[^o80] Intriguingly, the denominators of the periods of circular bulbs at sequential scales in the Mandelbrot Set conform to the [Fibonacci number sequence](wikipedia://en/10918), the sequence that is made by adding the previous two terms – 1, 2, 3, 5, 8, 13, 21...[^o81][^o82]

The Fibonacci sequence manifests in the number of spiral arms at a unique spot on the Mandelbrot set, mirrored both at the top and bottom. This distinctive location demands the highest number of iterations of for a detailed fractal visual, with intricate details repeating as one zooms in.[^o83]

## Generalizations {#Generalizations}

*Image: Quaternion Julia x=-0,75 y=-0,14.jpg.* A 4D Julia set may be projected or cross-sectioned into 3D, and because of this a 4D Mandelbrot is also possible.

### Multibrot sets {#Multibrot_sets}

[Multibrot sets](wikipedia://en/19509478) are bounded sets found in the [complex plane](wikipedia://en/217628) for members of the general monic univariate [polynomial](wikipedia://en/23000) family of recursions

$z \mapsto z^d + c$.[^o96]

For an [integer](wikipedia://en/14563) *d*, these sets are connectedness loci for the Julia sets built from the same formula. The full cubic connectedness locus has also been studied; here one considers the two-parameter recursion $z \mapsto z^3 + 3kz + c$, whose two [critical points](wikipedia://en/1951424) are the [complex square roots](https://en.wikipedia.org/wiki/Complex_square_root) of the parameter *k*. A parameter is in the cubic connectedness locus if both critical points are stable.[^o97] For general families of [holomorphic functions](wikipedia://en/14110), the *boundary* of the Mandelbrot set generalizes to the [bifurcation locus](wikipedia://en/5164765).

The [Multibrot set](wikipedia://en/19509478) is obtained by varying the value of the exponent *d*. The article has a video that shows the development from *d* = 0 to 7, at which point there are 6 i.e. $(d-1)$ lobes around the [perimeter](wikipedia://en/23636). In general, when *d* is a positive integer, the central region in each of these sets is always an [epicycloid](wikipedia://en/713354) of $(d-1)$ cusps. A similar development with negative integral exponents results in $(1-d)$ clefts on the inside of a ring, where the main central region of the set is a [hypocycloid](wikipedia://en/592735) of $(1-d)$ cusps.

### Higher dimensions {#Higher_dimensions}

There is no perfect extension of the Mandelbrot set into 3D, because there is no 3D analogue of the complex numbers for it to iterate on. There is an extension of the complex numbers into 4 dimensions, the [quaternions](wikipedia://en/51440), that creates a perfect extension of the Mandelbrot set and the Julia sets into 4 dimensions.[^o99] These can then be either [cross-sectioned](wikipedia://en/1337370) or [projected](https://en.wikipedia.org/wiki/Projection_mapping) into a 3D structure. The quaternion (4-dimensional) Mandelbrot set is simply a [solid of revolution](wikipedia://en/329400) of the 2-dimensional Mandelbrot set (in the j-k plane), and is therefore uninteresting to look at.[^o99] Taking a 3-dimensional cross section at $d = 0\ (q = a + bi +cj + dk)$ results in a solid of revolution of the 2-dimensional Mandelbrot set around the real axis.

### Other non-analytic mappings {#Other_non-analytic_mappings}

*Image: Mandelbar fractal from XaoS.PNG.* Image of the [Tricorn / Mandelbar fractal](https://en.wikipedia.org/wiki/Tricorn_%28mathematics%29)

The **[tricorn](https://en.wikipedia.org/wiki/Tricorn_%28mathematics%29) fractal**, also called the **Mandelbar set**, is the connectedness locus of the [anti-holomorphic](wikipedia://en/464178) family $z \mapsto \bar{z}^2 + c$.[^o101][^o102] It was encountered by [Milnor](wikipedia://en/61632) in his study of parameter slices of real [cubic polynomials](wikipedia://en/243709). It is not locally connected.[^o101] This property is inherited by the connectedness locus of real cubic polynomials.

Another non-analytic generalization is the [Burning Ship fractal](https://en.wikipedia.org/wiki/Burning_Ship_fractal), which is obtained by iterating the following:

$$z \mapsto (|\Re \left(z\right)|+i|\Im \left(z\right)|)^2 + c.$$

## Computer drawings {#Computer_drawings}

There exist a multitude of various algorithms for plotting the Mandelbrot set via a computing device. Here, the naïve[^o104] "escape time algorithm" will be shown, since it is the most popular[^o105] and one of the simplest algorithms.[^o106] In the escape time algorithm, a repeating calculation is performed for each *x*, *y* point in the plot area and based on the behavior of that calculation, a color is chosen for that pixel.[^o107][^o108]

The *x* and *y* locations of each point are used as starting values in a repeating, or iterating calculation (described in detail below). The result of each iteration is used as the starting values for the next. The values are checked during each iteration to see whether they have reached a critical "escape" condition, or "bailout". If that condition is reached, the calculation is stopped, the pixel is drawn, and the next *x*, *y* point is examined.

The color of each point represents how quickly the values reached the escape point. Often black is used to show values that fail to escape before the iteration limit, and gradually brighter colors are used for points that escape. This gives a visual representation of how many cycles were required before reaching the escape condition.

To render such an image, the region of the complex plane we are considering is subdivided into a certain number of [pixels](https://en.wikipedia.org/wiki/Pixel). To color any such pixel, let $c$ be the midpoint of that pixel. Iterate the critical point 0 under $f_c$, checking at each step whether the orbit point has a radius larger than 2. When this is the case, $c$ does not belong to the Mandelbrot set, and color the pixel according to the number of iterations used to find out. Otherwise, keep iterating up to a fixed number of steps, after which we decide that our parameter is "probably" in the Mandelbrot set, or at least very close to it, and color the pixel black.

In [pseudocode](https://en.wikipedia.org/wiki/Pseudocode), this algorithm would look as follows. The algorithm does not use complex numbers and manually simulates complex-number operations using two real numbers, for those who do not have a [complex data type](https://en.wikipedia.org/wiki/Complex_data_type). The program may be simplified if the programming language includes complex-data-type operations.

**for each** pixel (Px, Py) on the screen **do** x0 := scaled x coordinate of pixel (scaled to lie in the Mandelbrot X scale (-2.00, 0.47)) y0 := scaled y coordinate of pixel (scaled to lie in the Mandelbrot Y scale (-1.12, 1.12)) x := 0.0 y := 0.0 iteration := 0 max\_iteration := 1000 **while** (x^2 + y^2 ≤ 2^2 AND iteration \< max\_iteration) **do** xtemp := x^2 - y^2 + x0 y := 2\*x\*y + y0 x := xtemp iteration := iteration + 1

color := palette\[iteration\] plot(Px, Py, color)

Here, relating the pseudocode to $c$, $z$ and $f_c$:

- $$z = x + iy$$
- $$z^2 = x^2 +i2xy - y^2$$
- $$c = x_0 + i y_0$$

and so, as can be seen in the pseudocode in the computation of *x* and *y*:

- $x = \mathop{\mathrm{Re}} \left(z^2+c \right) = x^2-y^2 + x_0$ and $y = \mathop{\mathrm{Im}} \left(z^2+c \right) = 2xy + y_0$.

To get colorful images of the set, the assignment of a color to each value of the number of executed iterations can be made using one of a variety of functions (linear, exponential, etc.).

### Python code {#Python_code}

Here is the code implementing the above algorithm in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29):[^o110]

```numpy
import numpy as np
import matplotlib.pyplot as plt

# Setting parameters (these values can be changed)
x_domain, y_domain = np.linspace(-2, 2, 500), np.linspace(-2, 2, 500)
bound = 2
max_iterations = 50  # any positive integer value
colormap = "nipy_spectral"  # set to any matplotlib valid colormap

func = lambda z, p, c: z**p + c

# Computing 2D array to represent the Mandelbrot set
iteration_array = []
for y in y_domain:
    row = []
    for x in x_domain:
        z = 0
        p = 2
        c = complex(x, y)
        for iteration_number in range(max_iterations):
            if abs(z) >= bound:
                row.append(iteration_number)
                break
            else:
                try:
                    z = func(z, p, c)
                except (ValueError, ZeroDivisionError):
                    z = c
        else:
            row.append(0)

    iteration_array.append(row)

# Plotting the data
ax = plt.axes()
ax.set_aspect("equal")
graph = ax.pcolormesh(x_domain, y_domain, iteration_array, cmap=colormap)
plt.colorbar(graph)
plt.xlabel("Real-Axis")
plt.ylabel("Imaginary-Axis")
plt.show()
```

*Image: Multibrot set of power 5.png.* An image of a 2-dimensional multibrot-set represented by the equation $z=z^5+c$

The value of `power` variable can be modified to generate an image of equivalent [multibrot set](wikipedia://en/19509478) ($z = z^{\text{power}}+c$). For example, setting `p = 2` produces the associated image.
