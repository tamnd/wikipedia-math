# Filter (mathematics)

::: {#o1 .subject cue=lead name="Filter"}

*Image: Filter vs ultrafilter.svg.* The power set lattice of the set $\{1, 2, 3, 4\}$, with [upper set](https://en.wikipedia.org/wiki/Upper_set) $\uparrow\{1, 4\}$ colored dark green. This upper set is a filter, and even a principal filter. It is not an ultrafilter, because including also the light green elements extends it to the larger nontrivial filter $\uparrow\{1\}$. Since the latter cannot be extended further, $\uparrow\{1\}$ is an ultrafilter.

In [mathematics](wikipedia://en/18831), a **filter** or **order filter** is a special [subset](wikipedia://en/27631) of a [partially ordered set](wikipedia://en/23572) (poset), describing "large" or "eventual" elements. Filters appear in [order](wikipedia://en/361924) and [lattice theory](https://en.wikipedia.org/wiki/Lattice_theory), but also [topology](wikipedia://en/29954), whence they originate. The notion [dual](wikipedia://en/600618) to a filter is an [order ideal](wikipedia://en/530559).

:::

Special cases of filters include [ultrafilters](wikipedia://en/31911), which are filters that cannot be enlarged, and describe nonconstructive techniques in [mathematical logic](wikipedia://en/19636).

[Filters on sets](wikipedia://en/12646549) were introduced by [Henri Cartan](wikipedia://en/362536) in 1937. [Nicolas Bourbaki](wikipedia://en/167394), in their book *[Topologie Générale](https://en.wikipedia.org/wiki/Topologie_Générale)*, popularized filters as an alternative to [E. H. Moore](wikipedia://en/1532860) and [Herman L. Smith](wikipedia://en/29651449)'s 1922 notion of a [net](https://en.wikipedia.org/wiki/Net_%28topology%29); order filters generalize this notion from the specific case of a [power set](wikipedia://en/23799) under [inclusion](https://en.wikipedia.org/wiki/Inclusion_%28set_theory%29) to arbitrary [partially ordered sets](wikipedia://en/23572). Nevertheless, the [theory of power-set filters](wikipedia://en/12646549) retains interest in its own right, in part for substantial [applications in topology](wikipedia://en/47516955).

## Motivation {#Motivation}

Fix a [partially ordered set (poset)](wikipedia://en/23572) $P$. Intuitively, a filter $F$ is a subset of $P$ whose members are elements large enough to satisfy some criterion.[^n1] For instance, if $x \in P$, then the set of elements above $x$ is a filter, called the principal filter at $x$. (If $x$ and $y$ are [incomparable](wikipedia://en/3834818) elements of $P$, then neither the principal filter at $x$ nor $y$ is contained in the other.)

Similarly, a filter on a set $S$ contains those subsets that are sufficiently large to contain some given thing. For example, if $S$ is the [real line](https://en.wikipedia.org/wiki/Real_line) and $x \in S$, then the family of sets including $x$ in their [interior](wikipedia://en/55610) is a filter, called the neighborhood filter at $x$. The thing in this case is slightly larger than $x$, but it still does not contain any other specific point of the line.

The above considerations motivate the upward closure requirement in the [definition below](wikipedia://en/19719#Definition): "large enough" objects can always be made larger.

To understand the other two conditions, reverse the roles and instead consider $F$ as a "locating scheme" to find $x$. In this interpretation, one searches in some space $X$, and expects $F$ to describe those subsets of $X$ that contain the goal. The goal must be located somewhere; thus the [empty set](wikipedia://en/9566) $\emptyset$ can never be in $F$. And if two subsets both contain the goal, then should "zoom in" to their common region.

An ultrafilter describes a "perfect locating scheme" where each scheme component gives new information (either "look here" or "look elsewhere"). [Compactness](https://en.wikipedia.org/wiki/Compactness#Ordered_Spaces) is the property that "every search is fruitful," or, to put it another way, "every locating scheme ends in a search result."

A common use for a filter is to define properties that are satisfied by "generic" elements of some topological space.[^o4] This application generalizes the "locating scheme" to find points that might be hard to write down explicitly.

## Definition {#Definition}

A subset $F$ of a partially ordered set $(P, \le)$ is a **filter** or **dual ideal** if the following are satisfied:[^o12]

**[Downward directedness](wikipedia://en/9165)**

Every finite subset of $F$ has a lower bound in $F$. In other words, $F$ is non-empty and for every $x, y \in F$ there is some $z \in F$ such that $z \le x$ and $z \le y$.

**[Upward closure](https://en.wikipedia.org/wiki/Upper_set)**

For every $x \in F$ and $p \in P$, the condition $x \le p$ implies $p \in F$. If, additionally, $F \ne P$, then $F$ is said to be a **proper filter**. Authors in [set theory](wikipedia://en/27553) and [mathematical logic](wikipedia://en/19636) often require all filters to be proper;[^n2] this article will *eschew* that convention. An [ultrafilter](wikipedia://en/31911) is a proper filter contained in no other proper filter except itself.

### Filter bases {#Filter_bases}

A subset $S$ of $F$ is a **base** or **basis** for $F$ if the [upwards closure](https://en.wikipedia.org/wiki/Upwards_closure) of $S$ (i.e., the smallest upwards-closed set containing $S$) is equal to $F$. Since every filter is upwards-closed, every filter is a base for itself.

Moreover, if $B \subseteq P$ is downward directed, then $B$ generates an upper set $F$ that is a filter (for which $B$ is a base). Such sets are called **prefilters**, as well as the aforementioned **filter base/basis**, and $F$ is said to be **generated** or **spanned** by $B$. A prefilter is proper if and only if it generates a proper filter.

Given $p \in P$, the set $\{x : p \le x\}$ is the smallest filter containing $p$, and sometimes written $\uparrow p$. Such a filter is called a **principal filter**; $p$ is said to be the **principal element** of $F$, or generate $F$.

#### Refinement {#Refinement}

Suppose $B$ and $C$ are two prefilters on $P$, and, for each $c \in C$, there is a $b \in B$, such that $b \le c$. Then we say that $B$ is **finer** than (or **refines**) $C$; likewise, $C$ is **coarser** than (or **coarsens**) $B$. Refinement is a [preorder](wikipedia://en/23582) on the set of prefilters. In fact, if $C$ also refines $B$, then $B$ and $C$ are called **equivalent**, for they generate the same filter. Thus passage from prefilter to filter is an instance of passing from a preordering to associated partial ordering.

## Special cases {#Special_cases}

Historically, filters generalized to [order-theoretic lattices](wikipedia://en/469304) before arbitrary partial orders. In the case of lattices, downward direction can be written as closure under finite [meets](https://en.wikipedia.org/wiki/Meet_%28mathematics%29): for all $x, y \in F$, one has $x \land y \in F$.[^o12]

### Linear filters {#Linear_filters}

A linear (ultra)filter is an (ultra)filter on the [lattice](wikipedia://en/469304) of [vector subspaces](https://en.wikipedia.org/wiki/Vector_subspace) of a given [vector space](wikipedia://en/32370), ordered by inclusion. Explicitly, a linear filter on a vector space $X$ is a family $B$ of vector subspaces of $X$ such that if $A, B \in B$ and $C$ is a vector subspace of $X$ that contains $A$, then $A \cap B \in B$ and $C \in B$.[^n3]

A linear filter is proper if it does not contain $\{0\}$.[^n3]

### Filters on a set; subbases {#Filters_on_a_set;_subbases}

Given a set $S$, the [power set](wikipedia://en/23799) $P(S)$ is [partially ordered](wikipedia://en/23572) by [set inclusion](https://en.wikipedia.org/wiki/Set_inclusion); filters on this poset are often just called "filters on $S$," in an [abuse of terminology](https://en.wikipedia.org/wiki/Abuse_of_terminology). For such posets, downward direction and upward closure reduce to:[^n2]

**Closure under finite intersections**

If $A, B \in F$, then so too is $A \cap B \in F$.

**Isotony**

[^n4] If $A \in F$ and $A \subseteq B \subseteq S$, then $B \in F$.

A **proper**[^o19] or **non-degenerate[^n5]** filter is one that does not contain $\emptyset$, and these three conditions (including non-degeneracy) are [Henri Cartan](wikipedia://en/362536)'s original definition of a filter.[^n6][^n7] It is common, though not universal, to require filters on sets to be proper (whatever one's stance on poset filters); we shall again eschew this convention.

Prefilters on a set are proper if and only if they do not contain $\emptyset$ either.

For every subset $T$ of $P(S)$, there is a smallest filter $F$ containing $T$. As with prefilters, $T$ is said to generate or span $F$; a base for $F$ is the set $U$ of all finite intersections of $T$. The set $T$ is said to be a **filter subbase** when $F$ (and thus $U$) is proper.

Proper filters on sets have the [finite intersection property](wikipedia://en/365026).

If $S=\varnothing$, then $S$ admits only the improper filter $\{\varnothing\}$.

#### Free filters {#Free_filters}

A filter is said to be a **free filter** if the intersection of its members is empty. A proper principal filter is not free.

Since the intersection of any finite number of members of a filter is also a member, no proper filter on a finite set is free, and indeed is the principal filter generated by the common intersection of all of its members. But a nonprincipal filter on an infinite set is not necessarily free: a filter is free if and only if it includes the [Fréchet filter](wikipedia://en/1586291) (see ).

## Examples {#Examples}

See the image at the top of this article for a simple example of filters on the finite poset $P(\{1, 2, 3, 4\})$.

Partially order $R \to R$, the space of real-valued functions on $R$, by pointwise comparison. Then the set of functions "large at infinity,"

$$\left\{f:\lim_{x\to\pm\infty}{f(x)}=\infty\right\}\text{,}$$

is a filter on $R \to R$. One can generalize this construction quite far by [compactifying](wikipedia://en/6617) the domain and [completing](https://en.wikipedia.org/wiki/Completion_%28order_theory%29) the codomain: if $X$ is a set with distinguished subset $S$ and $Y$ is a poset with distinguished element $m$, then $\{f : f\,|_{S} \ge m\}$ is a filter in $X \to Y$.

The set $\{\{k : k \ge N\} : N \in N\}$ is a filter in $P(N)$. More generally, if $D$ is any [directed set](wikipedia://en/9165), then

$$\{\{k:k\geq N\}:N\in D\}$$

is a filter in $P(D)$, called the tail filter. Likewise any [net](https://en.wikipedia.org/wiki/Net_%28topology%29) $\{x_{\alpha}\}_{\alpha\in\mathrm{A}}$ generates the eventuality filter $\{\{x_{\beta} : \alpha \le \beta\} : \alpha \in \mathrm{A}\}$. A tail filter is the eventuality filter for $x_{\alpha} = \alpha$.

The [Fréchet filter](wikipedia://en/1586291) on an infinite set $X$ is

$$\{A:X\setminus A\text{ finite}\}\text{.}$$

If $(X, \mu)$ is a [measure space](wikipedia://en/45270), then the collection $\{A : \mu(X \setminus A) = 0\}$ is a filter. If $\mu(X) = \infty$, then $\{A : \mu(X \setminus A) < \infty\}$ is also a filter; the Fréchet filter is the case where $\mu$ is [counting measure](wikipedia://en/191786).

Given an [ordinal](wikipedia://en/26547932) $a$ with uncountable [cofinality](wikipedia://en/6693#Cofinality_of_ordinals_and_other_well-ordered_sets), a subset of $a$ is called a [club](wikipedia://en/1251559) if it is closed in the [order topology](wikipedia://en/213650) of $a$ but has net-theoretic limit $a$. The clubs of $a$, and their supersets, form a filter: the [club filter](wikipedia://en/1679210), $\text{♣}(a)$.

The previous construction generalizes as follows: any club $C$ is also a collection of dense subsets (in the [ordinal topology](https://en.wikipedia.org/wiki/Ordinal_topology)) of $a$, and $\text{♣}(a)$ meets each element of $C$. Replacing $C$ with an arbitrary collection $C\text{̃}$ of [dense sets](https://en.wikipedia.org/wiki/Dense_set_%28order%29), there "typically" exists a filter meeting each element of $C\text{̃}$, called a [generic filter](wikipedia://en/2213247). For countable $C\text{̃}$, the [Rasiowa–Sikorski lemma](wikipedia://en/30864999) implies that such a filter must exist; for "small" [uncountable](wikipedia://en/32248) $C\text{̃}$, the existence of such a filter can be [forced](wikipedia://en/152205) through [Martin's axiom](wikipedia://en/1550783).

Let $P$ denote the set of [partial orders](https://en.wikipedia.org/wiki/Partial_Order) of [limited cardinality](wikipedia://en/296838), [modulo](wikipedia://en/1352566) [isomorphism](https://en.wikipedia.org/wiki/Isomorphism_%28algebra%29). Partially order $P$ by:

$A \le B$ if there exists a strictly increasing $f : A \to B$.

Then the subset of [non-atomic](wikipedia://en/998824) partial orders forms a filter. Likewise, if $I$ is the set of [injective modules](wikipedia://en/473775) over some given [commutative ring](wikipedia://en/61346), of limited cardinality, modulo isomorphism, then a partial order on $I$ is:

$A \le B$ if there exists an [injective](wikipedia://en/45196) [linear map](wikipedia://en/474118) $f : A \to B$.[^o26]

Given any infinite cardinal $\kappa$, the modules in $I$ that cannot be generated by fewer than $\kappa$ elements form a filter.

Every [uniform structure](https://en.wikipedia.org/wiki/Uniform_structure) on a set $X$ is a filter on $X \times X$.

:::

## Relationship to ideals {#Relationship_to_ideals}

The [dual notion](wikipedia://en/609737) to a filter — that is, the concept obtained by reversing all $\le$ and exchanging $\land$ with $\lor$ — is an order ideal. Because of this duality, any question of filters can be mechanically translated to a question about ideals and vice versa; in particular, a **prime** or **maximal** filter is a filter whose corresponding ideal is (respectively) prime or maximal.

A filter is an ultrafilter if and only if the corresponding ideal is minimal.

## In model theory {#In_model_theory}

For every filter $F$ on a set $S$, the set function defined by

$$m(A) = \begin{cases} 1 & \text{if }A \in F \\ 0 & \text{if }S \smallsetminus A \in F \\ \text{is undefined} & \text{otherwise} \end{cases}$$

is finitely additive — a "[measure](wikipedia://en/19873)," if that term is construed rather loosely. Moreover, the measures so constructed are defined everywhere if $F$ is an [ultrafilter](wikipedia://en/31911). Therefore, the statement

$$\left\{\,x \in S : \varphi(x)\,\right\} \in F$$

can be considered somewhat analogous to the statement that $\varphi$ holds "almost everywhere." That interpretation of membership in a filter is used (for motivation, not actual proofs) in the theory of [ultraproducts](wikipedia://en/273642) in [model theory](wikipedia://en/19858), a branch of [mathematical logic](wikipedia://en/19636).

## In topology {#In_topology}

In [general topology](wikipedia://en/178649) and analysis, filters are used to define convergence in a manner similar to the role of [sequences](wikipedia://en/27838) in a [metric space](wikipedia://en/20018). They unify the concept of a [limit](wikipedia://en/26551602) across the wide variety of arbitrary [topological spaces](wikipedia://en/30450).

To understand the need for filters, begin with the equivalent concept of a [net](wikipedia://en/22170). A [sequence](wikipedia://en/27838) is usually indexed by the [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) $N$, which are a [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set). Nets generalize the notion of a sequence by replacing $N$ with an arbitrary [directed set](wikipedia://en/9165). In certain categories of topological spaces, such as [first-countable spaces](wikipedia://en/904940), sequences characterize most topological properties, but this is not true in general. However, nets — as well as filters — always do characterize those topological properties.

Filters do not involve any set external to the topological space $X$, whereas sequences and nets rely on other directed sets. For this reason, the collection of all filters on $X$ is always a [set](wikipedia://en/26691), whereas the collection of all $X$-valued nets is a [proper class](https://en.wikipedia.org/wiki/Proper_class).

### Neighborhood bases {#Neighborhood_bases}

Any point $x$ in the topological space $X$ defines a [neighborhood filter or system](wikipedia://en/1714290) $N_{x}$: namely, the family of all sets containing $x$ in their [interior](wikipedia://en/55610). A set $N$ of neighborhoods of $x$ is a [neighborhood base](https://en.wikipedia.org/wiki/Neighbourhood_base) at $x$ if $N$ generates $N_{x}$. Equivalently, $S \subseteq X$ is a neighborhood of $x$ if and only if there exists $N \in N$ such that $N \subseteq S$.

#### Convergent filters and cluster points {#Convergent_filters_and_cluster_points}

A prefilter $B$ [converges](https://en.wikipedia.org/wiki/Convergent_prefilter) to a point $x$, written $B \to x$, if and only if $B$ generates a filter $F$ that contains the neighborhood filter $N_{x}$ — explicitly, for every neighborhood $U$ of $x$, there is some $V \in B$ such that $V \subseteq U$. Less explicitly, $B \to x$ if and only if $B$ refines $N_{x}$, and any neighborhood base at $x$ can replace $N_{x}$ in this condition. Clearly, every [neighborhood base](https://en.wikipedia.org/wiki/Neighbourhood_base) at $x$ converges to $x$.

A filter $F$ (which generates itself) converges to $x$ if $N_{x} \subseteq F$. The above can also be reversed to characterize the neighborhood filter $N_{x}$: $N_{x}$ is the finest filter coarser than each filter converging to $x$.

If $B \to x$, then $x$ is called a [limit](https://en.wikipedia.org/wiki/Limit_of_a_filter) (point) of $B$. The prefilter $B$ is said to cluster at $x$ (or have $x$ as a [cluster point](https://en.wikipedia.org/wiki/Cluster_point_of_a_filter)) if and only if each element of $B$ has non-empty intersection with each neighborhood of $x$. Every limit point is a cluster point but the converse is not true in general. However, every cluster point of an ultrafilter is a limit point.
