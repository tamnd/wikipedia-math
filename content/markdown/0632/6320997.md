# Dense order

::: {#o1 .subject cue=lead name="Dense order"}

In [mathematics](wikipedia://en/18831), a [partial order](https://en.wikipedia.org/wiki/Partial_order) or [total order](wikipedia://en/30330) \< on a [set](wikipedia://en/26691) $X$ is said to be **dense** if, for all $x$ and $y$ in $X$ for which $x < y$, there is a $z$ in $X$ such that $x < z < y$. That is, for any two elements, one less than the other, there is another element between them. For total orders this can be simplified to "for any two distinct elements, there is another element between them", since all elements of a total order are [comparable](wikipedia://en/3834818).

:::

Equivalently, a partial order is dense precisely if its [covering relation](wikipedia://en/14835049) is empty.

::: {#o3 .example cue=heading name="Example"}

## Example {#Example}

The [rational numbers](wikipedia://en/19727024) as a linearly ordered set are a densely ordered set in this sense, as are the [algebraic numbers](wikipedia://en/1158), the [real numbers](wikipedia://en/20646438), the [dyadic rationals](wikipedia://en/56263) and the [decimal fractions](https://en.wikipedia.org/wiki/Decimal_fraction). In fact, every [Archimedean](wikipedia://en/264158) ordered [ring extension](wikipedia://en/24873145#Ring_extensions) of the [integers](https://en.wikipedia.org/wiki/Integers) $\mathbb{Z}[x]$ is a densely ordered set.

::: {#o4 .proof cue=math-proof name="Proof"}

**Proof.**

For the element $x\in\mathbb{Z}[x]$, due to the Archimedean property, if $x > 0$, there exists a largest integer $n < x$ with $n < x < n + 1$, and if $x < 0$, $-x > 0$, and there exists a largest integer $m = -n - 1 < -x$ with $-n - 1 < -x < -n$. As a result, $0 < x - n < 1$. For any two elements $y, z\in\mathbb{Z}[x]$ with $z < y$, $0 < (x - n)(y - z) < y - z$ and $z < (x - n)(y - z) + z < y$. Therefore $\mathbb{Z}[x]$ is dense.

:::

On the other hand, the linear ordering on the [integers](wikipedia://en/14563) is not dense.

:::

## Uniqueness for total dense orders without endpoints {#Uniqueness_for_total_dense_orders_without_endpoints}

[Georg Cantor](wikipedia://en/12216) proved that every two non-empty dense totally ordered [countable sets](wikipedia://en/6026) without lower or upper bounds are [order-isomorphic](wikipedia://en/23916899).[^o6] This makes the theory of dense linear orders without bounds an example of an ω-[categorical theory](wikipedia://en/1096396) where ω is the smallest [limit ordinal](wikipedia://en/373137). For example, there exists an order-isomorphism between the [rational numbers](wikipedia://en/19727024) and other densely ordered countable sets including the [dyadic rationals](wikipedia://en/56263) and the [algebraic numbers](wikipedia://en/1158). The proofs of these results use the [back-and-forth method](wikipedia://en/2033586).[^o7]

[Minkowski's question mark function](https://en.wikipedia.org/wiki/Minkowski's_question_mark_function) can be used to determine the order isomorphisms between the [quadratic algebraic numbers](wikipedia://en/305331) and the [rational numbers](wikipedia://en/19727024), and between the rationals and the [dyadic rationals](wikipedia://en/56263).

::: {#o9 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

Any [binary relation](wikipedia://en/3931) *R* is said to be *dense* if, for all *R*-related *x* and *y*, there is a *z* such that *x* and *z* and also *z* and *y* are *R*-related. Formally:

$\forall x\ \forall y\ xRy\Rightarrow (\exists z\ xRz \land zRy).$ Alternatively, in terms of [composition](wikipedia://en/7472170) of *R* with itself, the dense condition may be expressed as *R* ⊆ (*R* ; *R*).[^o10]

[Sufficient conditions](https://en.wikipedia.org/wiki/Sufficient_condition) for a binary relation *R* on a set *X* to be dense are:

- *R* is [reflexive](wikipedia://en/200458);
- *R* is [coreflexive](https://en.wikipedia.org/wiki/Coreflexive_relation);
- *R* is [quasireflexive](https://en.wikipedia.org/wiki/Quasireflexive_relation);
- *R* is left or right [Euclidean](wikipedia://en/11613832); or
- *R* is [symmetric](wikipedia://en/200459) and [semi-connex](https://en.wikipedia.org/wiki/Semi-connex_relation) and *X* has at least 3 elements.

None of them are [necessary](https://en.wikipedia.org/wiki/Necessary_condition). For instance, there is a relation R that is not reflexive but dense. A [non-empty](https://en.wikipedia.org/wiki/Empty_relation) and dense relation cannot be [antitransitive](https://en.wikipedia.org/wiki/Antitransitive).

A strict partial order \< is a dense order [if and only if](wikipedia://en/14922) \< is a dense relation. A dense relation that is also [transitive](wikipedia://en/200463) is said to be [idempotent](wikipedia://en/42719930).

:::
