# Fast-growing hierarchy

::: {#o1 .subject cue=lead name="Fast-growing hierarchy"}

In [computability theory](wikipedia://en/155414), [computational complexity theory](wikipedia://en/7543) and [proof theory](wikipedia://en/183478), a **fast-growing hierarchy** (also called an **extended [Grzegorczyk hierarchy](wikipedia://en/14334415)**, or a **Schwichtenberg–Wainer hierarchy**)[^n1] is an [ordinal](wikipedia://en/26547932)-indexed family of rapidly increasing functions *f*<sub>α</sub>: **N** → **N** (where **N** is the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers) {0, 1, ...}, and α ranges up to some large countable ordinal). A primary example is the **Wainer hierarchy**, or **Löb–Wainer hierarchy**, which is an extension to all α \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29). Such hierarchies provide a natural way to classify [computable functions](wikipedia://en/1139338) according to rate-of-growth and [computational complexity](wikipedia://en/7543).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let μ be a [large countable ordinal](wikipedia://en/4376814) such that to every [limit ordinal](wikipedia://en/373137) α \< μ there is assigned a [fundamental sequence](https://en.wikipedia.org/wiki/Fundamental_sequence_%28ordinals%29) (a strictly increasing sequence of ordinals whose supremum is α). A **fast-growing hierarchy** of functions *f*<sub>α</sub>: **N** → **N**, for α \< μ, is then defined as follows:

- $$f_0(n) = n + 1,$$
- $$f_{\alpha+1}(n) = f_\alpha^n(n)$$
- $f_\alpha(n) = f_{\alpha[n]}(n)$ if α is a limit ordinal.

Here *f*<sub>α</sub><sup>*n*</sup>(*n*) = *f*<sub>α</sub>(*f*<sub>α</sub>(...(*f*<sub>α</sub>(*n*))...)) denotes the *n*<sup>th</sup> [iterate](wikipedia://en/1448702) of *f*<sub>α</sub> applied to *n*, and α\[*n*\] denotes the *n*<sup>th</sup> element of the fundamental sequence assigned to the limit ordinal α. (An alternative definition takes the number of iterations to be *n*+1, rather than *n*, in the second line above.)

*First functions of the fast-growing hierarchy*

::: {#o5 .table cue=table name="First functions of the fast-growing hierarchy"}

| Level | Formula | Mathematical function |
|---|---|---|
| $f_{0}(n)$ | $n + 1$ | [Addition](wikipedia://en/61338) |
| $f_{1}(n)$ | $f_{0}^{n}(n){=n+}\underbrace{ 1+1 \cdots+1 }_{n\text{ times +1}} = n + n = 2n$ | [Multiplication](wikipedia://en/20845) |
| $f_{2}(n)$ | $f_{1}^{n}(n) = n \cdot \underbrace{ 2 \cdot \ldots \cdot 2 }_{n \text{ times } \cdot 2} = 2^{n} n$ | [Exponentiation](wikipedia://en/99491) |
| $f_{3}(n)$ | $f_{2}^{n}(n) \ge 2^{n}n \cdot ((2^{n}n) \uparrow\uparrow (n-1)) \ge 2 \uparrow\uparrow n$ | [Tetration](wikipedia://en/482379) |
| $f_{m}(n)$ | $f_{m-1}^{n}(n) \ge f_{m-1}(n) \uparrow^{m-1} n \ge 2 \uparrow^{m-1}n$ |  |

:::

The initial part of this hierarchy, comprising the functions *f*<sub>α</sub> with *finite* index (i.e., α \< ω), is often called the **Grzegorczyk hierarchy** because of its close relationship to the [Grzegorczyk hierarchy](wikipedia://en/14334415); note, however, that the former is here an indexed family of functions *f*<sub>*n*</sub>, whereas the latter is an indexed family of *sets* of functions $\mathcal{E}^n$. (See [Points of interest](wikipedia://en/24947285#Points_of_interest) below.)

Generalizing the above definition even further, a **fast iteration hierarchy** is obtained by taking *f*<sub>0</sub> to be any non-decreasing function *g*: **N** → **N**.

For limit ordinals not greater than [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), there is a straightforward natural definition of the fundamental sequences (see the **Wainer hierarchy** below), but beyond [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29) the definition is more complicated. However, this is possible well beyond the Feferman–Schütte ordinal, [Γ<sub>0</sub>](wikipedia://en/16084455), up to at least the [Bachmann–Howard ordinal](wikipedia://en/12732453). Using [Buchholz psi functions](https://en.wikipedia.org/wiki/Buchholz_psi_function) one can extend this definition to the ordinal of transfinitely iterated $\Pi^1_1$-comprehension (see [Analytical hierarchy](wikipedia://en/634233)).

A fully specified extension beyond the [computable ordinals](wikipedia://en/5173979) is thought to be unlikely; e.g., Prӧmel and others note that in such an attempt "there would even arise problems in [ordinal notation](wikipedia://en/6108552)".[^n2]

:::

## The Wainer hierarchy {#The_Wainer_hierarchy}

The **Wainer hierarchy** is the particular fast-growing hierarchy of functions *f*<sub>α</sub> (α ≤ [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29)) obtained by defining the fundamental sequences as follows:[^n3][^n4]

For limit ordinals λ \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), written in [Cantor normal form](https://en.wikipedia.org/wiki/Cantor_normal_form),

- if λ = ω<sup>α<sub>1</sub></sup> + ... + ω<sup>α<sub>k−1</sub></sup> + ω<sup>α<sub>k</sub></sup> for α<sub>1</sub> ≥ ... ≥ α<sub>k−1</sub> ≥ α<sub>k</sub>, then λ\[*n*\] = ω<sup>α<sub>1</sub></sup> + ... + ω<sup>α<sub>k−1</sub></sup> + ω<sup>α<sub>k</sub></sup>\[*n*\],
- if λ = ω<sup>α+1</sup>, then λ\[*n*\] = ω<sup>α</sup>*n*,
- if λ = ω<sup>α</sup> for a limit ordinal α, then λ\[*n*\] = ω<sup>α\[*n*\]</sup>,

and

- if λ = ε<sub>0</sub>, take λ\[0\] = 0 and λ\[*n* + 1\] = ω<sup>λ\[*n*\]</sup>[^n3]; alternatively, take the same sequence except starting with λ\[0\] = 1.[^n4] For *n* > 0, the alternative version has one additional ω in the resulting exponential tower, i.e. λ\[*n*\] = ω<sup>ω<sup>⋰<sup>ω</sup></sup></sup> with *n* appearances of ω.

Some authors use slightly different definitions (e.g., ω<sup>α+1</sup>\[*n*\] = ω<sup>α</sup>(*n+1*), instead of ω<sup>α</sup>*n*), and some define this hierarchy only for α \< ε<sub>0</sub> (thus excluding *f*<sub>ε<sub>0</sub></sub> from the hierarchy).

To continue beyond ε<sub>0</sub> the [fundamental sequences for the Veblen hierarchy](wikipedia://en/16124925#Fundamental_sequences_for_the_Veblen_hierarchy) can be used.

## Points of interest {#Points_of_interest}

Following are some relevant points of interest about fast-growing hierarchies:

- Every *f*<sub>α</sub> is a [total function](https://en.wikipedia.org/wiki/Total_function). If the fundamental sequences are computable (e.g., as in the Wainer hierarchy), then every *f*<sub>α</sub> is a total [computable function](wikipedia://en/1139338).
- In the Wainer hierarchy, *f*<sub>α</sub> is dominated by *f*<sub>β</sub> if α \< β. (For any two functions *f*, *g*: **N** → **N**, *f* is said to **dominate** *g* if *f*(*n*) > *g*(*n*) for all sufficiently large *n*.) The same property holds in any fast-growing hierarchy with fundamental sequences satisfying the so-called [Bachmann property](https://en.wikipedia.org/wiki/Bachmann_property). (This property holds for most natural well orderings.)
- In the Grzegorczyk hierarchy, every [primitive recursive function](wikipedia://en/24829) is dominated by some *f*<sub>α</sub> with α \< ω. Hence, in the Wainer hierarchy, every primitive recursive function is dominated by *f*<sub>ω</sub>, which is a variant of the [Ackermann function](wikipedia://en/2925).
- For *n* ≥ 3, the set $\mathcal{E}^n$ in the [Grzegorczyk hierarchy](wikipedia://en/14334415) is composed of just those total multi-argument functions which, for sufficiently large arguments, are computable within time bounded by some fixed iterate *f*<sub>*n*-1</sub><sup>*k*</sup> evaluated at the maximum argument.
- In the Wainer hierarchy, every *f*<sub>α</sub> with α \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29) is computable and provably total in [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic).
- Every computable function that is provably total in Peano arithmetic is dominated by some *f*<sub>α</sub> with α \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29) in the Wainer hierarchy. Hence *f*<sub>ε<sub>0</sub></sub> in the Wainer hierarchy is not provably total in Peano arithmetic.
- The [Goodstein function](wikipedia://en/150062#Sequence_length_as_a_function_of_the_starting_value) has approximately the same growth rate (*i.e.* each is dominated by some fixed iterate of the other) as *f*<sub>ε<sub>0</sub></sub> in the Wainer hierarchy, dominating every *f*<sub>α</sub> for which α \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), and hence is not provably total in Peano Arithmetic.
- In the Wainer hierarchy, if α \< β \< [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29), then *f*<sub>β</sub> dominates every computable function within time and space bounded by some fixed iterate *f*<sub>α</sub><sup>*k*</sup>.
- [Friedman's TREE function](wikipedia://en/3606300#TREE_function) dominates *f*<sub>[Γ<sub>0</sub>](wikipedia://en/16084455)</sub> in a fast-growing hierarchy.[^n3]
- The Wainer hierarchy of functions *f*<sub>α</sub> and the [Hardy hierarchy](wikipedia://en/25264191) of functions *h*<sub>α</sub> are related by *f*<sub>α</sub> = *h*<sub>ω<sup>α</sup></sub> for all α \< ε<sub>0</sub>. The Hardy hierarchy "catches up" to the Wainer hierarchy at α = ε<sub>0</sub>, such that *f*<sub>ε<sub>0</sub></sub> and *h*<sub>ε<sub>0</sub></sub> have the same growth rate, in the sense that *f*<sub>ε<sub>0</sub></sub>(*n*-1) ≤ *h*<sub>ε<sub>0</sub></sub>(*n*) ≤ *f*<sub>ε<sub>0</sub></sub>(*n*+1) for all *n* ≥ 1.[^n3]
- The *[slow-growing hierarchy](wikipedia://en/25264092)* of functions *g*<sub>α</sub> attains the same growth rate as the function *f*<sub>ε<sub>0</sub></sub> in the Wainer hierarchy when α is the [Bachmann–Howard ordinal](wikipedia://en/12732453).[^n5][^n6] Furthermore, the slow-growing hierarchy *g*<sub>α</sub> attains the same growth rate as *f*<sub>α</sub> (in a particular fast-growing hierarchy) when α is the ordinal of the theory *ID*<sub>\<ω</sub> of arbitrary finite iterations of an inductive definition.[^n5][^n7]

## Functions in fast-growing hierarchies {#Functions_in_fast-growing_hierarchies}

The functions at finite levels (α \< ω) of any fast-growing hierarchy coincide with those of the Grzegorczyk hierarchy: (using [hyperoperation](wikipedia://en/33731923))

- *f*<sub>0</sub>(*n*) = *n* + 1 = 2\[1\]*n* − 1
- *f*<sub>1</sub>(*n*) = *f*<sub>0</sub><sup>*n*</sup>(*n*) = *n* + *n* = 2*n* = 2\[2\]*n*
- *f*<sub>2</sub>(*n*) = *f*<sub>1</sub><sup>*n*</sup>(*n*) = 2<sup>*n*</sup> · *n* > 2<sup>*n*</sup> = 2\[3\]*n* for *n* ≥ 2
- *f*<sub>*k*+1</sub>(*n*) = *f*<sub>*k*</sub><sup>*n*</sup>(*n*) > (2\[*k* + 1\])<sup>*n*</sup> *n* ≥ 2\[*k* + 2\]*n* for *n* ≥ 2, *k* \< ω.

Beyond the finite levels are the functions of the Wainer hierarchy (ω ≤ α ≤ ε<sub>0</sub>):

- *f*<sub>ω</sub>(*n*) = *f*<sub>*n*</sub>(*n*) > 2\[*n* + 1\]*n* > 2\[*n*\](*n* + 3) − 3 = *A*(*n*, *n*) for *n* ≥ 4, where *A* is the [Ackermann function](wikipedia://en/2925) (of which *f*<sub>ω</sub> is a unary version).
- *f*<sub>ω+1</sub>(*n*) = *f*<sub>ω</sub><sup>*n*</sup>(*n*) ≥ f<sub>*n*\[*n* + 2\]*n*</sub>(*n*) for all *n* > 0, where *n*\[*n* + 2\]*n* is the *n*<sup>th</sup> [Ackermann number](wikipedia://en/2925#Ackermann_numbers).
- *f*<sub>ω+1</sub>(64) = *f*<sub>ω</sub><sup>64</sup>(64) > [Graham's number](wikipedia://en/234232#Definition) (= *g*<sub>64</sub> in the sequence defined by *g*<sub>0</sub> = 4, *g*<sub>*k*+1</sub> = 3\[*g*<sub>*k*</sub> + 2\]3). This follows by noting *f*<sub>ω</sub>(*n*) > 2\[*n* + 1\]*n* > 3\[*n*\]3 + 2, and hence *f*<sub>ω</sub>(*g*<sub>*k*</sub> + 2) > *g*<sub>*k*+1</sub> + 2.
- *f*<sub>ε<sub>0</sub></sub>(*n*) is the first function in the Wainer hierarchy that dominates the [Goodstein function](https://en.wikipedia.org/wiki/Goodstein_function).
