# Huber loss

::: {#o1 .subject cue=lead name="Huber loss"}

In [statistics](wikipedia://en/26685), the **Huber loss** is a [loss function](wikipedia://en/442137) used in [robust regression](wikipedia://en/2713327), that is less sensitive to [outliers](wikipedia://en/160951) in data than the [squared error loss](https://en.wikipedia.org/wiki/Squared_error_loss). A variant for classification is also sometimes used.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

*Image: Huber loss.svg.* Huber loss (green, $\delta=1$) and squared error loss (blue) as a function of $y - f(x)$

The Huber loss function describes the penalty incurred by an [estimation procedure](wikipedia://en/10043) $f$. [Huber](https://en.wikipedia.org/wiki/Peter_J._Huber) (1964) defines the loss function piecewise by[^o4]

$$L_\delta (a) = \begin{cases} \frac{1}{2}{a^2} & \text{for } |a| \le \delta, \\[4pt] \delta \cdot \left(|a| - \frac{1}{2}\delta\right), & \text{otherwise.} \end{cases}$$

This function is quadratic for small values of $a$, and linear for large values, with equal values and slopes of the different sections at the two points where $|a| = \delta$. The variable $a$ often refers to the residuals, that is to the difference between the observed and predicted values $a = y - f(x)$, so the former can be expanded to[^o5]

$$L_\delta(y, f(x)) = \begin{cases} \frac{1}{2} {\left(y - f(x)\right)}^2 & \text{for } \left|y - f(x)\right| \le \delta, \\[4pt] \delta\ \cdot \left(\left|y - f(x)\right| - \frac{1}{2}\delta\right), & \text{otherwise.} \end{cases}$$

The Huber loss is the [convolution](wikipedia://en/7519) of the [absolute value](wikipedia://en/991) function with the [rectangular function](wikipedia://en/1261615), scaled and translated. Thus it "smoothens out" the former's corner at the origin.

*Image: Comparison of loss functions.png.* Comparison of Huber loss with other loss functions used for robust regression.

:::

## Motivation {#Motivation}

Two very commonly used loss functions are the [squared loss](wikipedia://en/201816), $L(a) = a^2$, and the [absolute loss](https://en.wikipedia.org/wiki/Absolute_deviation), $L(a)=|a|$. The squared loss function results in an [arithmetic mean](wikipedia://en/612)-[unbiased estimator](https://en.wikipedia.org/wiki/Unbiased_estimator), and the absolute-value loss function results in a [median](wikipedia://en/18837)-unbiased estimator (in the one-dimensional case, and a [geometric median](wikipedia://en/10324687)-unbiased estimator for the multi-dimensional case). The squared loss has the disadvantage that it has the tendency to be dominated by outliers—when summing over a set of $a$'s (as in $\sum_{i=1}^n L(a_i)$), the sample mean is influenced too much by a few particularly large $a$-values when the distribution is heavy tailed: in terms of [estimation theory](wikipedia://en/1565926), the asymptotic relative efficiency of the mean is poor for heavy-tailed distributions.[^o7]

As defined above, the Huber loss function is [strongly convex](wikipedia://en/245568#Strongly_convex_functions) in a uniform neighborhood of its minimum $a=0$; at the boundary of this uniform neighborhood, the Huber loss function has a differentiable extension to an affine function at points $a=-\delta$ and $a = \delta$. These properties allow it to combine much of the sensitivity of the mean-unbiased, minimum-variance estimator of the mean (using the quadratic loss function) and the robustness of the median-unbiased estimator (using the absolute value function).

## Pseudo-Huber loss function {#Pseudo-Huber_loss_function}

The **Pseudo-Huber loss function** can be used as a [smooth](wikipedia://en/1408000) approximation of the Huber loss function. It combines the best properties of **L2** [squared loss](wikipedia://en/201816) and **L1** [absolute loss](https://en.wikipedia.org/wiki/Absolute_deviation) by being strongly convex when close to the target/minimum and less steep for extreme values. The scale at which the Pseudo-Huber loss function transitions from **L2** loss for values close to the minimum to **L1** loss for extreme values and the steepness at extreme values can be controlled by the $\delta$ value. The **Pseudo-Huber loss function** ensures that derivatives are continuous for all degrees. It is defined as[^o9][^o10]

$$L_\delta (a) = \delta^2\left(\sqrt{1+(a/\delta)^2}-1\right).$$

As such, this function approximates $a^2/2$ for small values of $a$, and approximates a straight line with slope $\delta$ for large values of $a$.

While the above is the most common form, other smooth approximations of the Huber loss function also exist.[^o11]

## Variant for classification {#Variant_for_classification}

For [classification](wikipedia://en/1579244) purposes, a variant of the Huber loss called *modified Huber* is sometimes used. Given a prediction $f(x)$ (a real-valued classifier score) and a true [binary](wikipedia://en/205393) class label $y \in \{+1, -1\}$, the modified Huber loss is defined as[^o13]

$$L(y, f(x)) = \begin{cases} \max(0, 1 - y \, f(x))^2 & \text{for }\, \, y \, f(x) > -1, \\[4pt] -4y \, f(x) & \text{otherwise.} \end{cases}$$

The term $\max(0, 1 - y \, f(x))$ is the [hinge loss](wikipedia://en/33100241) used by [support vector machines](wikipedia://en/65309); the [quadratically smoothed hinge loss](wikipedia://en/33100241#Optimization) is a generalization of $L$.[^o13]

## Applications {#Applications}

The Huber loss function is used in [robust statistics](wikipedia://en/2885691), [M-estimation](wikipedia://en/4225388) and [additive modelling](wikipedia://en/20964272).[^o16]
