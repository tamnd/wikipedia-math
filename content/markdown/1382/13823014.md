# Krener's theorem

::: {#o1 .subject cue=lead name="Krener's theorem"}

In mathematics, **Krener's theorem** is a result attributed to [Arthur J. Krener](https://en.wikipedia.org/wiki/Arthur_J._Krener) in geometric [control theory](wikipedia://en/7039) about the topological properties of [attainable sets](https://en.wikipedia.org/wiki/Attainable_set) of finite-dimensional control systems. It states that any attainable set of a [bracket-generating](https://en.wikipedia.org/wiki/Bracket-generating) system has nonempty interior or, equivalently, that any attainable set has nonempty interior in the topology of the corresponding [orbit](https://en.wikipedia.org/wiki/Orbit_%28control_theory%29). Heuristically, Krener's theorem prohibits attainable sets from being [hairy](wikipedia://en/485168).

:::

::: {#o3 .statement cue=heading name="Theorem"}

## Theorem {#Theorem}

Let ${\ }\dot q=f(q,u)$ be a smooth control system, where ${\ q}$ belongs to a finite-dimensional manifold $\ M$ and $\ u$ belongs to a control set $\ U$. Consider the family of vector fields ${\mathcal F}=\{f(\cdot,u)\mid u\in U\}$.

Let $\ \mathrm{Lie}\,\mathcal{F}$ be the [Lie algebra](wikipedia://en/17944) generated by ${\mathcal F}$ with respect to the [Lie bracket of vector fields](wikipedia://en/10282799). Given $\ q\in M$, if the vector space $\ \mathrm{Lie}_q\,\mathcal{F}=\{g(q)\mid g\in \mathrm{Lie}\,\mathcal{F}\}$ is equal to $\ T_q M$, then $\ q$ belongs to the closure of the interior of the attainable set from $\ q$.

:::

## Remarks and consequences {#Remarks_and_consequences}

Even if $\mathrm{Lie}_q\,\mathcal{F}$ is different from $\ T_q M$, the attainable set from $\ q$ has nonempty interior in the orbit topology, as it follows from Krener's theorem applied to the control system restricted to the orbit through $\ q$.

When all the vector fields in $\ \mathcal{F}$ are analytic, $\ \mathrm{Lie}_q\,\mathcal{F}=T_q M$ **if and only if** $\ q$ belongs to the closure of the interior of the attainable set from $\ q$. This is a consequence of Krener's theorem and of the [orbit theorem](https://en.wikipedia.org/wiki/Orbit_%28control_theory%29#Orbit_theorem_%28Nagano-Sussmann%29).

As a corollary of Krener's theorem one can prove that if the system is bracket-generating and if the attainable set from $\ q\in M$ is dense in $\ M$, then the attainable set from $\ q$ is actually equal to $\ M$.
