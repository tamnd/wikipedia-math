# Local diffeomorphism

::: {#o1 .subject cue=lead name="Local diffeomorphism"}

In [mathematics](wikipedia://en/18831), more specifically [differential topology](wikipedia://en/8562), a **local diffeomorphism** is intuitively a [map](wikipedia://en/185427) between [smooth manifolds](https://en.wikipedia.org/wiki/Smooth_manifold) that preserves the local [differentiable structure](https://en.wikipedia.org/wiki/Differentiable_structure). The formal definition of a local diffeomorphism is given below.

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let $X$ and $Y$ be [differentiable manifolds](wikipedia://en/2119219). A [function](wikipedia://en/185427) $f:X \to Y$ is a **local diffeomorphism** if, for each point $x \in X$, there exists an [open set](wikipedia://en/39358) $U$ containing $x$ such that the [image](wikipedia://en/579311) $f(U)$ is open in $Y$ and

$$f\vert_U : U \to f(U)$$

is a [diffeomorphism](wikipedia://en/8564).

A local diffeomorphism is a special case of an [immersion](wikipedia://en/6993953) $f : X \to Y$. In this case, for each $x \in X$, there exists an open set $U$ containing $x$ such that the image $f(U)$ is an [embedded submanifold](wikipedia://en/525095#Embedded_submanifolds), and $f|_U:U \to f(U)$ is a diffeomorphism. Here $X$ and $f(U)$ have the same dimension, which may be less than the dimension of $Y$.[^o4]

::: {#o6 .statement kind=statement/fact cue=heading name="Characterizations"}

### Characterizations {#Characterizations}

A map is a local diffeomorphism if and only if it is a smooth [immersion](wikipedia://en/6993953) (smooth local embedding) and an [open map](https://en.wikipedia.org/wiki/Open_map).

The [inverse function theorem](wikipedia://en/287229) implies that a smooth map $f:X \to Y$ is a local diffeomorphism if and only if the [derivative](wikipedia://en/1558510) $D f_x : T_x X \to T_{f(x)} Y$ is a [linear isomorphism](https://en.wikipedia.org/wiki/Linear_isomorphism) for all points $x \in X$. This implies that $X$ and $Y$ have the same dimension.[^o7]

It follows that a map $f : X \to Y$ between two manifolds of equal dimension ($\operatorname{dim} X = \operatorname{dim} Y$) is a local diffeomorphism if and only if it is a smooth [immersion](wikipedia://en/6993953) (smooth local embedding), or equivalently, if and only if it is a smooth [submersion](wikipedia://en/356413). This is because, for any $x \in X$, both $T_xX$ and $T_{f(x)}Y$ have the same dimension, thus $Df_x$ is a linear isomorphism if and only if it is injective, or equivalently, if and only if it is surjective.[^o8]

Here is an alternative argument for the case of an immersion: every smooth immersion is a [locally injective function](https://en.wikipedia.org/wiki/Locally_injective_function), while [invariance of domain](wikipedia://en/210731) guarantees that any continuous injective function between manifolds of equal dimensions is necessarily an open map.

:::

:::

## Discussion {#Discussion}

All manifolds of the same dimension are "locally diffeomorphic," in the following sense: if $X$ and $Y$ have the same dimension, and $x \in X$ and $y\in Y$, then there exist open neighbourhoods $U$ of $x$ and $V$ of $y$ and a diffeomorphism $f:U \to V$. However, this map $f$ need not extend to a smooth map defined on all of $X$, let alone extend to a local diffeomorphism. Thus the existence of a local diffeomorphism $f:X \to Y$ is a stronger condition than "to be locally diffeomorphic." Indeed, although locally defined diffeomorphisms preserve differentiable structure locally, one must be able to "patch up" these (local) diffeomorphisms to ensure that the domain is the entire smooth manifold.

For example, one can impose two different [differentiable structures](https://en.wikipedia.org/wiki/Differentiable_structure) on $\mathbb{R}^4$ that each make $\mathbb{R}^4$ into a differentiable manifold, but both structures are not locally diffeomorphic (see [Exotic $\mathbb{R}^4$](wikipedia://en/2180637)).

As another example, there can be no local diffeomorphism from the [2-sphere](wikipedia://en/27859) to [Euclidean 2-space](wikipedia://en/9697), although they do indeed have the same local differentiable structure. This is because all local diffeomorphisms are [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29), the continuous image of a [compact space](wikipedia://en/6042) is compact, and the 2-sphere is compact whereas Euclidean 2-space is not.

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

If a local diffeomorphism between two manifolds exists then their dimensions must be equal. Every local diffeomorphism is also a [local homeomorphism](wikipedia://en/248582) and therefore a [locally injective](https://en.wikipedia.org/wiki/Locally_injective_function) [open map](https://en.wikipedia.org/wiki/Open_map). A local diffeomorphism has constant [rank](wikipedia://en/7880215) of $n.$

:::

::: {#o13 .example cue=heading name="Examples"}

## Examples {#Examples}

- A [diffeomorphism](wikipedia://en/8564) is a [bijective](https://en.wikipedia.org/wiki/Bijective) local diffeomorphism.
- A [smooth](wikipedia://en/1408000#Smooth_functions_on_and_between_manifolds) [covering map](https://en.wikipedia.org/wiki/Covering_map) is a local diffeomorphism such that every point in the target has a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) that is evenly covered by the map.

:::
