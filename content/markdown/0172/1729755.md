# Bi-directional delay line

::: {#o1 .subject cue=lead name="Bi-directional delay line"}

In [mathematics](wikipedia://en/18831), a **bi-directional delay line** is a [numerical analysis](wikipedia://en/21506) technique used in [computer simulation](https://en.wikipedia.org/wiki/Computer_simulation) for solving [ordinary differential equations](wikipedia://en/32742753) by converting them to [hyperbolic equations](https://en.wikipedia.org/wiki/Hyperbolic_equation). In this way an explicit solution scheme is obtained with highly robust numerical properties. It was introduced by Auslander in 1968.

:::

It originates from simulation of [hydraulic pipelines](https://en.wikipedia.org/wiki/Hydraulic_pipeline) where [wave propagation](https://en.wikipedia.org/wiki/Wave_propagation) was studied. It was then found that it could be used as an efficient numerical technique for numerically insulating different parts of a simulation model in each times step. It is used in the [HOPSAN](https://en.wikipedia.org/wiki/HOPSAN) simulation package (Krus *et al.* 1990).

It is also known as the *[Transmission Line Modelling](https://en.wikipedia.org/wiki/Transmission-line_matrix_method)* (TLM) from an independent development by Johns and O'Brian 1980. This is also extended to partial differential equations.
