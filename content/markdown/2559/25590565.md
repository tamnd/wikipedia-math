# ♯SAT

::: {#o1 .subject cue=lead name="♯SAT"}

In [computer science](https://en.wikipedia.org/wiki/Computer_science), the **Sharp Satisfiability Problem** (sometimes called **Sharp-SAT**, **\#SAT** or **model counting**) is the problem of counting the number of [interpretations](wikipedia://en/14511671) that [satisfy](wikipedia://en/23401166) a given [Boolean](https://en.wikipedia.org/wiki/Boolean_logic) [formula](https://en.wikipedia.org/wiki/Formula_%28mathematical_logic%29), introduced by Valiant in 1979.[^o2] In other words, it asks in how many ways the variables of a given Boolean formula can be consistently replaced by the values TRUE or FALSE in such a way that the formula [evaluates to TRUE](wikipedia://en/21304742). For example, the formula $a\lor \neg b$ is satisfiable by three distinct Boolean value assignments of the variables, namely, for any of the assignments ($a$ = TRUE, $b$ = FALSE), ($a$ = FALSE, $b$ = FALSE), and ($a$ = TRUE, $b$ = TRUE), we have $a\lor \neg b = \textsf{TRUE}.$

:::

\#SAT is different from [Boolean satisfiability problem](wikipedia://en/4715) (SAT), which asks if there exists *a solution* to a Boolean formula. Instead, #SAT asks to enumerate *all* *the solutions* to a Boolean formula. #SAT is harder than SAT in the sense that, once the total number of solutions to a Boolean formula is known, SAT can be decided in constant time. However, the converse is not true, because knowing a Boolean formula has *a solution* does not help us to count *all the solutions*, as there are an exponential number of possibilities.

\#SAT is a well-known example of the class of [counting problems](https://en.wikipedia.org/wiki/Counting_problem_%28complexity%29), known as [\#P-complete](https://en.wikipedia.org/wiki/Sharp-P-complete) (read as sharp P complete). In other words, every instance of a problem in the complexity class [\#P](wikipedia://en/27924) can be reduced to an instance of the #SAT problem. This is an important result because many difficult counting problems arise in [Enumerative Combinatorics](wikipedia://en/3925533), [Statistical physics](https://en.wikipedia.org/wiki/Statistical_physics), Network Reliability, and [Artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) without any known formula. If a problem is shown to be hard, then it provides a [complexity theoretic](wikipedia://en/7543) explanation for the lack of nice looking formulas.[^o3]

## \#P-Completeness {##P-Completeness}

\#SAT is [\#P-complete](wikipedia://en/27925). To prove this, first note that #SAT is obviously in #P.

Next, we prove that #SAT is #P-hard. Take any problem #A in #P. We know that A can be solved using a [Non-deterministic Turing Machine](https://en.wikipedia.org/wiki/Non-deterministic_Turing_machine) M. On the other hand, from the proof for [Cook-Levin Theorem](https://en.wikipedia.org/wiki/Cook-Levin_theorem), we know that we can reduce M to a boolean formula F. Now, each valid assignment of F corresponds to a unique acceptable path in M, and vice versa. However, each acceptable path taken by M represents a solution to A. In other words, there is a bijection between the valid assignments of F and the solutions to A. So, the reduction used in the proof for Cook-Levin Theorem is parsimonious. This implies that #SAT is #P-hard.

## Intractable special cases {#Intractable_special_cases}

Counting solutions is intractable (#P-complete) in many special cases for which satisfiability is tractable (in P), as well as when satisfiability is intractable (NP-complete). This includes the following.

### \#3SAT {##3SAT}

This is the counting version of [3SAT](https://en.wikipedia.org/wiki/3SAT). One can show that any formula in SAT [can be rewritten](https://en.wikipedia.org/wiki/3SAT) as a formula in 3-[CNF](wikipedia://en/73342) form preserving the number of satisfying assignments. Hence, #SAT and #3SAT are counting equivalent and #3SAT is #P-complete as well.

### \#2SAT {##2SAT}

Even though [2SAT](https://en.wikipedia.org/wiki/2SAT) (deciding whether a 2CNF formula has a solution) is polynomial, counting the number of solutions is [\#P](wikipedia://en/27924)-complete.[^o8] The #P-completeness already in the monotone case, i.e., when there are no [negations](wikipedia://en/161019) (#MONOTONE-2-CNF).

It is known that, assuming that [NP](https://en.wikipedia.org/wiki/NP_%28class%29) is different from [RP](https://en.wikipedia.org/wiki/RP_%28class%29), #MONOTONE-2-CNF also cannot be [approximated](wikipedia://en/563105) by a fully [polynomial-time approximation scheme](wikipedia://en/666431) (FPRAS), even assuming that each variable occurs in at most 6 clauses, but that a fully polynomial-time approximation scheme (FPTAS) exists when each variable occurs in at most 5 clauses:[^o9] this follows from analogous results on the problem [♯IS](https://en.wikipedia.org/wiki/♯IS) of counting the number of [independent sets](wikipedia://en/524501) in [graphs](wikipedia://en/325806).

### \#Horn-SAT {##Horn-SAT}

Similarly, even though [Horn-satisfiability](wikipedia://en/1227519) is polynomial, counting the number of solutions is #P-complete. This result follows from a general dichotomy characterizing which SAT-like problems are #P-complete.[^o11]

### Planar #3SAT {#Planar_#3SAT}

This is the counting version of [Planar 3SAT](https://en.wikipedia.org/wiki/Planar_3SAT). The hardness reduction from 3SAT to Planar 3SAT given by Lichtenstein[^o13] is parsimonious. This implies that Planar #3SAT is #P-complete.

### Planar Monotone Rectilinear #3SAT {#Planar_Monotone_Rectilinear_#3SAT}

This is the counting version of Planar Monotone Rectilinear 3SAT.[^o15] The NP-hardness reduction given by de Berg & Khosravi[^o15] is parsimonious. Therefore, this problem is #P-complete as well.

### \#DNF {##DNF}

For [disjunctive normal form](wikipedia://en/73341) (DNF) formulas, counting the solutions is also #P-complete, even when all clauses have size 2 and there are no [negations](wikipedia://en/161019): this is because, by [De Morgan's laws](wikipedia://en/64669), counting the number of solutions of a DNF amounts to counting the number of solutions of the negation of a [conjunctive normal form](wikipedia://en/73342) (CNF) formula. Intractability even holds in the case known as #PP2DNF, where the variables are partitioned into two sets, with each clause containing one variable from each set.[^o17]

By contrast, it is possible to tractably approximate the number of solutions of a disjunctive normal form formula using the [Karp-Luby algorithm](https://en.wikipedia.org/wiki/Karp-Luby_algorithm), which is an FPRAS for this problem.[^o18]

## Tractable special cases {#Tractable_special_cases}

### Affine constraint satisfaction problems {#Affine_constraint_satisfaction_problems}

The variant of SAT corresponding to affine relations in the sense of [Schaefer's dichotomy theorem](wikipedia://en/4638322), i.e., where clauses amount to equations modulo 2 with the [XOR](wikipedia://en/105979) operator, is the only SAT variant for which the #SAT problem can be solved in polynomial time.[^o21]

### Bounded treewidth {#Bounded_treewidth}

If the instances to SAT are restricted using [graph](wikipedia://en/557931) parameters, the #SAT problem can become tractable. For instance, #SAT on SAT instances whose [treewidth](wikipedia://en/3987086) is bounded by a constant can be performed in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).[^o23] Here, the treewidth can be the primal treewidth, dual treewidth, or incidence treewidth of the [hypergraph](wikipedia://en/232535) associated to the SAT formula, whose vertices are the variables and where each clause is represented as a hyperedge.

### Restricted circuit and diagram classes {#Restricted_circuit_and_diagram_classes}

Model counting is tractable (solvable in polynomial time) for (ordered) [BDDs](wikipedia://en/576855) and for some circuit formalisms studied in [knowledge compilation](https://en.wikipedia.org/wiki/Knowledge_compilation), such as [d-DNNFs](https://en.wikipedia.org/wiki/D-DNNF).

## Generalizations {#Generalizations}

Weighted model counting (WMC) generalizes #SAT by computing a linear combination of the models instead of just counting the models. In the literal-weighted variant of WMC, each literal gets assigned a weight, such that $\text{WMC}(\phi; w) = \sum_{M \models \phi} \prod_{l \in M} w(l)$.

WMC is used for probabilistic inference, as probabilistic queries over discrete random variables such as in [Bayesian networks](wikipedia://en/203996) can be reduced to WMC.[^o27]

Algebraic model counting further generalizes #SAT and WMC over arbitrary commutative [semirings](https://en.wikipedia.org/wiki/Semirings).[^o28]
