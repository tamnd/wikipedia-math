# Multiple rule-based problems

::: {#o1 .subject cue=lead name="Multiple rule-based problems"}

**Multiple rule-based problems** are [problems](wikipedia://en/256700) containing various conflicting rules and restrictions.[^o2] Such problems typically have an "[optimal](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29)" solution, found by striking a balance between the various restrictions, without directly defying any of the aforementioned restrictions.

:::

Solutions to such problems can either require complex, non-linear [thinking](https://en.wikipedia.org/wiki/Thought) processes, or can instead require mathematics-based solutions in which an optimal solution is found by setting the various restrictions as equations, and finding an appropriate maximum value when all equations are added. These problems may thus require more working information as compared to causal relationship [problem solving](wikipedia://en/1467948) or single rule-based problem solving. The multiple rule-based problem solving is more likely to increase [cognitive](https://en.wikipedia.org/wiki/Cognition) load than are the other two types of problem solving.
