# L/poly

::: {#o1 .subject cue=lead name="L/poly"}

In [computational complexity theory](wikipedia://en/7543), **L/poly** is the [complexity class](wikipedia://en/502426) of [logarithmic space](https://en.wikipedia.org/wiki/Logarithmic_space) machines with a polynomial amount of [advice](wikipedia://en/665843). L/poly is a [non-uniform](wikipedia://en/7641969) logarithmic space class, analogous to the non-uniform polynomial time class [P/poly](wikipedia://en/2052415).[^o2]

:::

Formally, for a [formal language](wikipedia://en/10939) $L$ to belong to L/poly, there must exist an advice function $f$ that maps an integer $n$ to a string of length polynomial in $n$, and a [Turing machine](wikipedia://en/30403) M with two read-only input tapes and one read-write tape of size logarithmic in the input size, such that an input $x$ of length $n$ belongs to $L$ if and only if machine M accepts the input $x, f(n)$.[^o3] Alternatively and more simply, $L$ is in L/poly if and only if it can be recognized by [branching programs](https://en.wikipedia.org/wiki/Branching_program) of polynomial size.[^o4] One direction of the proof that these two models of computation are equivalent in power is the observation that, if a branching program of polynomial size exists, it can be specified by the advice function and simulated by the Turing machine. In the other direction, a Turing machine with logarithmic writable space and a polynomial advice tape may be simulated by a branching program the states of which represent the combination of the configuration of the writable tape and the position of the Turing machine heads on the other two tapes.

In 1979, Aleliunas et al. showed that [symmetric logspace](wikipedia://en/1174919) is contained in L/poly.[^o5] However, this result was superseded by [Omer Reingold](https://en.wikipedia.org/wiki/Omer_Reingold)'s result that SL collapses to uniform logspace.[^o6]

[BPL](wikipedia://en/18449708) is contained in L/poly, which is a variant of [Adleman's theorem](wikipedia://en/2052415#Adleman's_theorem).[^o7]
