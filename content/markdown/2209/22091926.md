# Weierstrass–Erdmann condition

::: {#o1 .subject cue=lead name="Weierstrass–Erdmann condition"}

The **Weierstrass–Erdmann condition** is a mathematical result from the [calculus of variations](wikipedia://en/171882), which specifies sufficient conditions for broken [extremals](https://en.wikipedia.org/wiki/Extremals) (that is, an extremal which is constrained to be smooth except at a finite number of "corners").[^o2]

:::

## Conditions {#Conditions}

The Weierstrass-Erdmann corner conditions stipulate that a broken extremal $y(x)$ of a [functional](wikipedia://en/1374948) $J=\int\limits_a^b f(x,y,y')\,dx$ satisfies the following two continuity relations at each corner $c\in[a,b]$:

$\left.\frac{\partial f}{\partial y'}\right|_{x=c-0}=\left.\frac{\partial f}{\partial y'}\right|_{x=c+0}$; $\left.\left(f-y'\frac{\partial f}{\partial y'}\right)\right|_{x=c-0}=\left.\left(f-y'\frac{\partial f}{\partial y'}\right)\right|_{x=c+0}$.

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

The condition allows one to prove that a corner exists along a given extremal. As a result, there are many applications to [differential geometry](wikipedia://en/8625). In calculations of the [Weierstrass excess function](https://en.wikipedia.org/wiki/Weierstrass_excess_function), it is often helpful to find where corners exist along the curves. Similarly, the condition allows for one to find a minimizing curve for a given integral.

:::
