# Monogenic function

::: {#o1 .subject cue=lead name="Monogenic function"}

A monogenic[^o2][^o3] function is a [complex function](https://en.wikipedia.org/wiki/Complex_function) with a single finite [derivative](https://en.wikipedia.org/wiki/Complex_derivative). More precisely, a function $f(z)$ defined on $A \subseteq \mathbb{C}$ is called monogenic at $\zeta \in A$, if $f'(\zeta)$ exists and is finite, with:

$$f'(\zeta) = \lim_{z\to\zeta}\frac{f(z) - f(\zeta)}{z - \zeta}$$

:::

Alternatively, it can be defined as the above [limit](wikipedia://en/285759) having the same value for all paths. Functions can either have a single derivative (monogenic) or infinitely many derivatives (polygenic), with no intermediate cases.[^o3] Furthermore, a function $f(x)$ which is monogenic $\forall \zeta \in B$, is said to be monogenic on $B$, and if $B$ is a [domain](wikipedia://en/16796643) of $\mathbb{C}$, then it is [analytic](wikipedia://en/61478) as well (The notion of domains can also be generalized [^o2] in a manner such that functions which are monogenic over non-connected subsets of $\mathbb{C}$, can show a weakened form of analyticity)

The term monogenic was coined by [Cauchy](wikipedia://en/1842).[^o4]
