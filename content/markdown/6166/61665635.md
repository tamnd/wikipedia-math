# Character module

::: {#o1 .subject cue=lead name="Character module"}

In mathematics, especially in the area of [abstract algebra](wikipedia://en/19616384), every [module](wikipedia://en/276410) has an associated **character module**. Using the associated character module it is possible to investigate the properties of the original module. One of the main results discovered by [Joachim Lambek](wikipedia://en/1250498) shows that a module is [flat](wikipedia://en/492616) [if and only if](wikipedia://en/14922) the associated character module is [injective](wikipedia://en/473775).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

The [group](wikipedia://en/19447) $(\mathbb{Q}/\mathbb{Z}, +)$, the group of rational numbers modulo $1$, can be considered as a $\mathbb{Z}$-module in the natural way. Let $M$ be an additive group which is also considered as a $\mathbb{Z}$-module. Then the group

$$M^* = \operatorname{Hom}_\mathbb{Z} (M, \mathbb{Q} / \mathbb{Z})$$

of $\mathbb{Z}$-[homomorphisms](wikipedia://en/474118) from $M$ to $\mathbb{Q} / \mathbb{Z}$ is called the *character group associated to $M$*. The elements in this group are called *characters*. If $M$ is a left $R$-module over a ring $R$, then the [character group](wikipedia://en/1384568) $M^*$ is a right $R$-module and called the *character module associated to* $M$. The module action in the character module for $f \in \operatorname{Hom}_\mathbb{Z} (M, \mathbb{Q} / \mathbb{Z})$ and $r \in R$ is defined by $(f r)(m) = f(rm)$ for all $m \in M$.[^o5] The character module can also be defined in the same way for right $R$-modules. In the literature also the notations $M', M^0$ and $M^+$ are used for character modules.[^o6][^o7]

Let $M,N$ be left $R$-modules and $f \colon M \to N$ an $R$-homomorphism. Then the mapping $f^* \colon N^* \to M^*$ defined by $f^* (h) = h \circ f$ for all $h \in N^*$ is a right $R$-homomorphism. Character module formation is a contravariant [functor](wikipedia://en/10987) from the [category](wikipedia://en/11231812) of left $R$-modules to the category of right $R$-modules.[^o6]

:::

## Motivation {#Motivation}

The abelian group $\mathbb{Q} / \mathbb{Z}$ is [divisible](wikipedia://en/472147) and therefore an [injective](wikipedia://en/473775) $\mathbb{Z}$-module. Furthermore it has the following important property: Let $G$ be an [abelian group](wikipedia://en/2974) and $g \in G$ nonzero. Then there exists a [group homomorphism](wikipedia://en/12396) $f \colon G \to \mathbb{Q} / \mathbb{Z}$ with $f(g) \neq 0$. This says that $\mathbb{Q} / \mathbb{Z}$ is a [cogenerator](https://en.wikipedia.org/wiki/Injective_cogenerator). With these properties one can show the main theorem of the theory of character modules:[^o6]

> **Theorem (Lambek)**[^o2]**:** A left module $M$ over a ring $R$ is [flat](wikipedia://en/492616) if and only if the character module $M^*$ is an [injective](wikipedia://en/473775) right $R$-module.

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $M$ be a left module over a ring $R$ and $M^*$ the associated character module.

- The module $M$ is flat if and only if $M^*$ is injective (Lambek's Theorem[^o7]).[^o2]
- If $M$ is free, then $M^*$ is an injective right $R$-module and $M^*$ is a direct product of copies of the right $R$-modules $R^*$.[^o5]
- For every right $R$-module $N$ there is a free module $M$ such that $N$ is isomorphic to a submodule of $M^*$. With the previous property this module $M^*$ is injective, hence every right $R$-module is isomorphic to a submodule of an injective module. (Baer's Theorem)[^o11]
- A left $R$-module $N$ is injective if and only if there exists a free $M$ such that $N$ is isomorphic to a direct summand of $M^*$.[^o11]
- The module $M$ is injective if and only if it is a direct summand of a character module of a [free module](wikipedia://en/326454).[^o5]
- If $N$ is a submodule of $M$, then $(M/N)^*$ is isomorphic to the submodule of $M^*$ which consists of all elements which annihilate $N$.[^o5]
- Character module formation is a contravariant [exact functor](wikipedia://en/453945), i.e. it preserves exact sequences.[^o6]
- Let $N$ be a right $R$-module. Then the modules $\operatorname{Hom}_R (N, M^*)$ and $(N \otimes_R M)^*$ are isomorphic as $\mathbb{Z}$-modules.[^o7]

:::
