# Frege system

::: {#o1 .subject cue=lead name="Frege system"}

In [proof complexity](wikipedia://en/2801284), a **Frege system** is a [propositional proof system](wikipedia://en/29696524) whose proofs are [sequences](wikipedia://en/27838) of [formulas](wikipedia://en/1557634) derived using a finite set of [sound](wikipedia://en/26819) and implicationally complete [inference rules](https://en.wikipedia.org/wiki/Inference_rules).[^o2] Frege systems (more often known as [Hilbert systems](wikipedia://en/8529655) in general [proof theory](wikipedia://en/183478)) are named after [Gottlob Frege](wikipedia://en/48416).

:::

The name "Frege system" was first defined[^o3] by Stephen Cook and Robert Reckhow,[^o4][^o5] and was intended to capture the properties of the most common propositional proof systems.[^o3]

::: {#o7 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Cook and Reckhow[^o4][^o5] gave the first[^o3] formal definition of a Frege system, to which the one below, based on Krajicek,[^o2] is equivalent.

Let *K* be a finite [functionally complete](wikipedia://en/5279259) set of Boolean connectives, and consider [propositional formulas](wikipedia://en/1557634) built from variables *p*<sub>0</sub>, *p*<sub>1</sub>, *p*<sub>2</sub>, ... using *K*-connectives. A Frege rule is an inference rule of the form

$$r=\frac{B_1,\dots,B_n}B,$$

where *B*<sub>1</sub>, ..., *B<sub>n</sub>*, *B* are formulas. If *R* is a finite set of Frege rules, then *F* = (*K*,*R*) defines a derivation system in the following way. If *X* is a set of formulas, and *A* is a formula, then an *F*-derivation of *A* from axioms *X* is a sequence of formulas *A*<sub>1</sub>, ..., *A<sub>m</sub>* such that *A<sub>m</sub>* = *A*, and every *A<sub>k</sub>* is a member of *X*, or it is derived from some of the formulas *A<sub>i</sub>*, *i* \< *k*, by a [substitution](wikipedia://en/5438948) instance of a rule from *R*. An *F*-proof of a formula *A* is an *F*-derivation of *A* from the empty set of axioms (X=∅). *F* is called a Frege system if

- *F* is sound: every *F*-provable formula is a tautology.
- *F* is implicationally complete: for every formula *A* and a set of formulas *X*, if *X* entails *A*, then there is an *F*-derivation of *A* from *X*.

The length (number of lines) in a proof *A*<sub>1</sub>, ..., *A<sub>m</sub>* is *m*. The size of the proof is the total number of symbols.

A derivation system *F* as above is refutationally complete, if for every inconsistent set of formulas *X*, there is an *F*-derivation of a fixed contradiction from *X*.

:::

::: {#o9 .example cue=heading name="Examples"}

## Examples {#Examples}

- Frege's propositional calculus is not a Frege system, since it used axioms instead of axiom schemes, although it can be modified to be a Frege system.[^o5]
- There are many examples of sound Frege rules on the [Propositional calculus](https://en.wikipedia.org/wiki/Propositional_calculus) page.
- [Resolution](wikipedia://en/2724082) is not a Frege system because it only operates on [clauses](wikipedia://en/4638484), not on formulas built in an arbitrary way by a functionally complete set of connectives. Moreover, it is not implicationally complete, i.e. we cannot conclude $A \lor B$ from $A$. However, adding the *weakening* rule: $\frac{A}{A \lor B}$ makes it implicationally complete . Resolution is also refutationally complete.

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Reckhow's 1979 theorem[^o5] states that all Frege systems are [p-equivalent](wikipedia://en/29696524#Relation_with_computational_complexity_theory).
- [Natural deduction](wikipedia://en/51072) and [sequent calculus](wikipedia://en/252329) (Gentzen system with cut) are also p-equivalent to Frege systems.
- There are polynomial-size Frege proofs of the [pigeonhole principle](wikipedia://en/54217).[^o12]
- Frege systems are considered to be fairly strong systems. Unlike, say, resolution, there are no known superlinear lower bounds on the number of lines in Frege proofs, and the best known lower bounds on the size of the proofs are quadratic.
- The minimal number of rounds in the *prover-adversary* game needed to prove a tautology $\phi$ is proportional to the logarithm of the minimal number of steps in a Frege proof of $\phi$.

:::

## Extended Frege system {#Extended_Frege_system}

Cook and Reckhow also defined an extension of a Frege system, called *extended Frege*,[^o5] which takes a Frege system *F* and adds an extra derivation rule which allows one to derive a formula $p \leftrightarrow D$, where $\leftrightarrow$ abbreviates its definition in the language of the particular *F* and the atom $p$ does not occur in previously derived formulas including axioms and in the formula $D$.

The purpose of the new derivation rule is to introduce 'names' or shortcuts for arbitrary formulas. It allows one to interpret proofs in Extended Frege as Frege proofs operating with [circuits](wikipedia://en/7087423) instead of formulas.

[Cook's correspondence](https://en.wikipedia.org/wiki/Bounded_arithmetic#Correspondence_to_propositional_proof_systems) allows one to interpret Extended Frege as a nonuniform equivalent of Cook's theory PV and Buss's theory $S^1_2$ formalizing feasible (polynomial-time) reasoning.
