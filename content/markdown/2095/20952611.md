# Čech-to-derived functor spectral sequence

::: {#o1 .subject cue=lead name="Čech-to-derived functor spectral sequence"}

In [algebraic topology](wikipedia://en/38801), a branch of [mathematics](wikipedia://en/18831), the **Čech-to-derived functor spectral sequence** is a [spectral sequence](wikipedia://en/803894) that relates [Čech cohomology](wikipedia://en/856614) of a [sheaf](wikipedia://en/245466) and [sheaf cohomology](wikipedia://en/1055357).[^n1]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{F}$ be a sheaf on a topological space *X*. Choose an open cover $\mathfrak{U}$ of *X*. That is, $\mathfrak{U}$ is a set of open subsets of *X* which together cover *X*. Let $\mathcal{H}^q(X, \mathcal{F})$ denote the presheaf which takes an open set *U* to the *q*th cohomology of $\mathcal{F}$ on *U*, that is, to $H^q(U, \mathcal{F})$. For any presheaf $\mathcal{G}$, let $\check{H}^p(\mathfrak{U}, \mathcal{G})$ denote the *p*th Čech cohomology of $\mathcal{G}$ with respect to the cover $\mathfrak{U}$. Then the Čech-to-derived functor spectral sequence is:[^n2]

$$E^{p,q}_2 = \check{H}^p(\mathfrak{U}, \mathcal{H}^q(X, \mathcal{F})) \Rightarrow H^{p+q}(X, \mathcal{F}).$$

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $\mathfrak{U}$ consists of only two open sets, then this spectral sequence degenerates to the [Mayer–Vietoris sequence](wikipedia://en/378677). See [Spectral sequence#Long exact sequences](wikipedia://en/803894#Long_exact_sequences).

If for all finite intersections of a covering the cohomology vanishes, the *E*<sub>*2*</sub>-term degenerates and the edge morphisms yield an isomorphism of Čech cohomology for this covering to sheaf cohomology. This provides a method of computing sheaf cohomology using Čech cohomology. For instance, this happens if $\mathcal{F}$ is a quasi-coherent sheaf on a [scheme](wikipedia://en/364754) and each element of $\mathfrak{U}$ is an open affine subscheme such that all finite intersections are again affine (e.g. if the scheme is [separated](https://en.wikipedia.org/wiki/Separated_scheme)). This can be used to compute the cohomology of line bundles on projective space.[^n3]

:::
