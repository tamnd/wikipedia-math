# List of genetic algorithm applications

::: {#o1 .subject cue=lead name="List of genetic algorithm applications"}

This is a list of **[genetic algorithm](https://en.wikipedia.org/wiki/Genetic_algorithm) (GA) applications**.

:::

## Natural Sciences, Mathematics and Computer Science {#Natural_Sciences,_Mathematics_and_Computer_Science}

- Bayesian inference links to particle methods in Bayesian statistics and hidden Markov chain models[^o3][^o4]

::: {#o5 .entry cue=list-entry name="Artificial creativity"}

- [Artificial creativity](https://en.wikipedia.org/wiki/Computational_creativity)

:::

- Chemical kinetics ( and [solid](http://repositories.cdlib.org/postprints/1154) phases)

::: {#o6 .entry cue=list-entry name="Bound state"}

- Calculation of [bound states](wikipedia://en/696912) and [local-density approximations](https://en.wikipedia.org/wiki/Local-density_approximation)

:::

::: {#o7 .entry cue=list-entry name="Code-breaking"}

- [Code-breaking](https://en.wikipedia.org/wiki/Code-breaking), using the GA to search large solution spaces of [ciphers](wikipedia://en/5244) for the one correct decryption.[^o8]

:::

::: {#o9 .entry cue=list-entry name="Approximate computing"}

- Computer architecture: using GA to find out weak links in [approximate computing](https://en.wikipedia.org/wiki/Approximate_computing) such as [lookahead](https://en.wikipedia.org/wiki/Combinatorial_search#Lookahead).

:::

::: {#o10 .entry cue=list-entry name="buckyballs"}

- Configuration applications, particularly physics applications of optimal molecule configurations for particular systems like C<sub>60</sub> ([buckyballs](wikipedia://en/10628))

:::

::: {#o11 .entry cue=list-entry name="Facial composite"}

- Construction of [facial composites](https://en.wikipedia.org/wiki/Facial_composite) of suspects by [eyewitnesses](https://en.wikipedia.org/wiki/Witness) in forensic science.[^o12]

:::

- Data Center/Server Farm.[^o13]

::: {#o14 .entry cue=list-entry name="Distributed computer network"}

- [Distributed computer network](https://en.wikipedia.org/wiki/Distributed_computer_network) [topologies](https://en.wikipedia.org/wiki/Topologies)

:::

::: {#o15 .entry cue=list-entry name="Evolvable hardware"}

- Electronic circuit design, known as [evolvable hardware](https://en.wikipedia.org/wiki/Evolvable_hardware)

:::

::: {#o16 .entry cue=list-entry name="Evolutionary image processing"}

- [Evolutionary image processing](https://en.wikipedia.org/wiki/Evolutionary_image_processing)

:::

::: {#o17 .entry cue=list-entry name="Feature selection"}

- [Feature selection](wikipedia://en/1179950) for [Machine Learning](wikipedia://en/233488)[^o18]

:::

- Feynman-Kac models [^o19][^o20][^o21]

::: {#o22 .entry cue=list-entry name="Distributed system"}

- File allocation for a [distributed system](https://en.wikipedia.org/wiki/Distributed_system)

:::

- Filtering and signal processing [^o23][^o24]
- Finding hardware bugs.[^o25][^o26]

::: {#o27 .entry cue=list-entry name="Game theory"}

- [Game theory](wikipedia://en/11924) equilibrium resolution

:::

::: {#o28 .entry cue=list-entry name="Genetic Algorithm for Rule Set Production"}

- [Genetic Algorithm for Rule Set Production](https://en.wikipedia.org/wiki/Genetic_Algorithm_for_Rule_Set_Production)

:::

::: {#o29 .entry cue=list-entry name="Scheduling applications"}

- [Scheduling applications](wikipedia://en/13957150), including [job-shop scheduling](https://en.wikipedia.org/wiki/Job_Shop_Scheduling) and scheduling in [printed circuit board](https://en.wikipedia.org/wiki/Printed_circuit_board) assembly.[^o30] The objective being to schedule jobs in a [sequence-dependent](https://en.wikipedia.org/wiki/Sequence-dependent_setup) or non-sequence-dependent setup environment in order to maximize the volume of production while minimizing penalties such as tardiness. Satellite communication scheduling for the NASA Deep Space Network was shown to benefit from genetic algorithms.[^o31]

:::

::: {#o32 .entry cue=list-entry name="Learning robot behavior"}

- [Learning robot behavior](https://en.wikipedia.org/wiki/Robot_learning) using genetic algorithms

:::

- Image processing: Dense pixel matching[^o33]
- Learning fuzzy rule base using genetic algorithms
- Molecular structure optimization (chemistry)

::: {#o34 .entry cue=list-entry name="Wavelet"}

- Optimisation of data compression systems, for example using [wavelets](wikipedia://en/50903).

:::

::: {#o35 .entry cue=list-entry name="Power electronics"}

- [Power electronics](https://en.wikipedia.org/wiki/Power_electronics) design.[^o36]

:::

::: {#o37 .entry cue=list-entry name="Traveling salesman problem"}

- [Traveling salesman problem](https://en.wikipedia.org/wiki/Traveling_salesman_problem) and its applications[^o30]

:::

- Stopping propagations, i.e. deciding how to cut edges in a graph so that some infectious condition (e.g. a disease, fire, computer virus, etc.) stops its spread. A bi-level genetic algorithm (i.e. a genetic algorithm where the fitness of each individual is calculated by running another genetic algorithm) was used due to the Σ<sup>P</sup><sub>2</sub>-completeness of the problem.[^o38]

::: {#o39 .entry cue=list-entry name="Symbolic regression"}

- [Symbolic regression](wikipedia://en/42922637)[^o40]

:::
