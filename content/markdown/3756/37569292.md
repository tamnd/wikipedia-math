# Monad (homological algebra)

::: {#o1 .subject cue=lead name="Monad"}

In [homological algebra](wikipedia://en/139410), a **monad** is a 3-term [complex](wikipedia://en/138404)

:::

*A* → *B* → *C*

of objects in some [abelian category](wikipedia://en/45063) whose middle term *B* is [projective](wikipedia://en/3017382), whose first map *A* → *B* is [injective](wikipedia://en/45196), and whose second map *B* → *C* is [surjective](wikipedia://en/27873). Equivalently, a monad is a projective object together with a 3-step [filtration](wikipedia://en/726014) *B* ⊃ ker(*B* → *C*) ⊃ im(*A* → *B*). In practice *A*, *B*, and *C* are often [vector bundles](wikipedia://en/276524) over some space, and there are several minor extra conditions that some authors add to the definition. Monads were introduced by Horrocks.[^o2]
