# Inverse distribution

::: {#o1 .subject cue=lead name="Inverse distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), an **inverse distribution** is the distribution of the [reciprocal](wikipedia://en/229940) of a random variable. Inverse distributions arise in particular in the [Bayesian](wikipedia://en/49571) context of [prior distributions](https://en.wikipedia.org/wiki/Prior_distribution) and [posterior distributions](https://en.wikipedia.org/wiki/Posterior_distribution) for [scale parameters](wikipedia://en/769503). In the [algebra of random variables](wikipedia://en/1217120), inverse distributions are special cases of the class of [ratio distributions](wikipedia://en/9519371), in which the numerator random variable has a [degenerate distribution](wikipedia://en/101843).

:::

## Relation to original distribution {#Relation_to_original_distribution}

In general, given the [probability distribution](wikipedia://en/23543) of a random variable *X* with strictly positive support, it is possible to find the distribution of the reciprocal, *Y* = 1 / X. If the distribution of *X* is [continuous](https://en.wikipedia.org/wiki/Continuous_probability_distribution) with [density function](wikipedia://en/43487) *f*(*x*) and [cumulative distribution function](wikipedia://en/5793) *F*(*x*), then the cumulative distribution function, *G*(*y*), of the reciprocal is found by noting that

$$G(y) = \Pr(Y \leq y) = \Pr\left(X \geq \frac{1}{y}\right) = 1-\Pr\left(X<\frac{1}{y}\right) = 1 - F\left( \frac{ 1 }{ y } \right).$$

Then the density function of *Y* is found as the derivative of the cumulative distribution function:

$$g(y) = \frac{ 1 }{ y^2 } f\left( \frac{ 1 }{ y } \right) .$$

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### Reciprocal distribution {#Reciprocal_distribution}

The [reciprocal distribution](wikipedia://en/39127799) has a density function of the form[^o6]

$$f(x) \propto x^{-1} \quad \text{ for } 0<a<x<b,$$

where $\propto \!\,$ means ["is proportional to"](wikipedia://en/81863). It follows that the inverse distribution in this case is of the form

$$g(y) \propto y^{-1} \quad \text{ for } 0\le b^{-1}<y< a^{-1},$$

which is again a reciprocal distribution.

::: {#o8 .pointer-item cue=pointer name="Inverse uniform distribution"}

### Inverse uniform distribution {#Inverse_uniform_distribution}

If the original random variable *X* is [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on the interval (*a*,*b*), where *a*>0, then the reciprocal variable *Y* = 1 / *X* has the reciprocal distribution which takes values in the range (*b*<sup>−1</sup> ,*a*<sup>−1</sup>), and the probability density function in this range is

$$g( y ) = y^{-2} \frac{ 1 }{ b-a } ,$$

and is zero elsewhere.

The cumulative distribution function of the reciprocal, within the same range, is

$$G( y ) = \frac{ b - y^{-1} }{ b - a } .$$

For example, if *X* is uniformly distributed on the interval (0,1), then *Y* = 1 / *X* has density $g( y ) = y^{-2}$ and cumulative distribution function $G( y ) = { 1 - y^{-1} }$ when $y > 1 .$

:::

### Inverse *t* distribution {#Inverse_t_distribution}

Let *X* be a [*t* distributed](wikipedia://en/105375) random variate with *k* [degrees of freedom](wikipedia://en/176622). Then its density function is

$$f( x ) = \frac{ 1 }{ \sqrt{ k \pi } } \frac{ \Gamma\left( \frac{ k + 1 }{ 2 } \right) }{ \Gamma\left( \frac{ k }{ 2 } \right) } \frac{ 1 }{ \left( 1 + \frac{ x^2 }{ k } \right)^{ \frac{ 1 + k }{ 2 } } } .$$

The density of *Y* = 1 / *X* is

$$g( y ) = \frac{ 1 }{ \sqrt{ k \pi } } \frac{ \Gamma\left( \frac{ k + 1 }{ 2 } \right) }{ \Gamma\left( \frac{ k }{ 2 } \right) } \frac{ 1 }{ y^2 \left( 1 + \frac{ 1 }{ y^2 k } \right)^{ \frac{ 1 + k }{ 2 } } } .$$

With *k* = 1, the distributions of *X* and 1 / *X* are identical (*X* is then [Cauchy distributed](wikipedia://en/7003) (0,1)). If *k* > 1 then the distribution of 1 / *X* is [bimodal](https://en.wikipedia.org/wiki/Bimodal).

::: {#o11 .pointer-item cue=pointer name="Reciprocal normal distribution"}

### Reciprocal normal distribution {#Reciprocal_normal_distribution}

If variable $X$ follows a [normal distribution](wikipedia://en/21462) $\mathcal{N}(\mu,\sigma^2)$, then the inverse or reciprocal $Y=\frac{1}{X}$ follows a reciprocal normal distribution:[^o12]

$$f(y) = \frac{1}{\sqrt{2\pi} \sigma y^2} e^{-\frac{1}{2}\left(\frac{1/y-\mu}{\sigma}\right)^2} .$$

*Image: Graph of inverse of the normal distribution.png.* Graph of the density of the inverse of the standard normal distribution

If variable *X* follows a [standard normal distribution](https://en.wikipedia.org/wiki/Standard_normal_distribution) $\mathcal{N}(0, 1)$, then *Y* = 1/*X* follows a *reciprocal standard normal distribution*, [heavy-tailed](wikipedia://en/8092200) and [bimodal](https://en.wikipedia.org/wiki/Bimodal_distribution),[^o12] with modes at $\pm\tfrac{1}{\sqrt{2}}$ and density

$$f(y)=\frac{e^{-\frac{1}{2y^2}}}{\sqrt{2\pi}y^2}$$

and the first and higher-order moments do not exist.[^o12] For such inverse distributions and for [ratio distributions](wikipedia://en/9519371), there can still be defined probabilities for intervals, which can be computed either by [Monte Carlo simulation](https://en.wikipedia.org/wiki/Monte_Carlo_simulation) or, in some cases, by using the Geary–Hinkley transformation.[^o13]

However, in the more general case of a shifted reciprocal function $1/(p-B)$, for $B=N(\mu,\sigma)$ following a general normal distribution, then mean and variance statistics do exist in a [principal value](wikipedia://en/408225) sense, if the difference between the pole $p$ and the mean $\mu$ is real valued. The mean of this transformed random variable (*reciprocal shifted normal distribution*) is then indeed the scaled [Dawson's function](https://en.wikipedia.org/wiki/Dawson's_function):[^o14]

$$\frac{\sqrt{2}}{\sigma} F \left(\frac{p-\mu}{\sqrt{2}\sigma}\right).$$

In contrast, if the shift $p-\mu$ is purely complex, the mean exists and is a scaled [Faddeeva function](wikipedia://en/16381196), whose exact expression depends on the sign of the imaginary part, $\operatorname{Im}(p-\mu)$. In both cases, the variance is a simple function of the mean.[^o15] Therefore, the variance has to be considered in a principal value sense if $p-\mu$ is real, while it exists if the imaginary part of $p-\mu$ is non-zero. Note that these means and variances are exact, as they do not recur to linearisation of the ratio. The exact covariance of two ratios with a pair of different poles $p_1$ and $p_2$ is similarly available.[^o16] The case of the inverse of a [complex normal variable](https://en.wikipedia.org/wiki/Complex_normal_variable) $B$, shifted or not, exhibits different characteristics.[^o14]

:::

### Inverse exponential distribution {#Inverse_exponential_distribution}

If $X$ is an exponentially distributed random variable with rate parameter $\lambda$, then $Y=1/X$ has the following cumulative distribution function: $F_Y(y) = e^{-\lambda/y}$for $y> 0$. Note that the expected value of this random variable does not exist. The reciprocal exponential distribution finds use in the analysis of fading wireless communication systems.

### Inverse Cauchy distribution {#Inverse_Cauchy_distribution}

If *X* is a [Cauchy distributed](wikipedia://en/7003) (*μ*, *σ*) random variable, then 1 / X is a Cauchy ( *μ* / *C*, *σ* / *C* ) random variable where *C* = *μ*<sup>2</sup> + *σ*<sup>2</sup>.

### Inverse F distribution {#Inverse_F_distribution}

If *X* is an [*F*(*ν*<sub>1</sub>, *ν*<sub>2</sub> ) distributed](https://en.wikipedia.org/wiki/F_distribution) random variable then 1 / *X* is an *F*(*ν*<sub>2</sub>, *ν*<sub>1</sub> ) random variable.

### Reciprocal of binomial distribution {#Reciprocal_of_binomial_distribution}

If $X$ is distributed according to a Binomial distribution with $n$ number of trials and a probability of success $p$ then no closed form for the reciprocal distribution is known. However, we can calculate the mean of this distribution.

$$E\left[\frac{1}{(1+X)}\right] = \frac{1}{p(n+1)}\left( 1 - (1-p)^{n+1} \right)$$

An asymptotic approximation for the non-central moments of the reciprocal distribution is known.[^o21]

$$E[ ( 1 + X )^a ] = O( ( np )^{ -a } ) + o( n^{ -a } )$$

where O() and o() are the big and little [o order functions](wikipedia://en/44578) and $a$ is a real number.

### Reciprocal of triangular distribution {#Reciprocal_of_triangular_distribution}

For a [triangular distribution](wikipedia://en/663496) with lower limit *a*, upper limit *b* and mode *c*, where *a* \< *b* and *a* ≤ *c* ≤ *b*, the mean of the reciprocal is given by

$$\mu = \frac{2 \left( \frac{ a\, \mathrm{ln} \left(\frac{a}{c}\right) }{a-c} + \frac{ b\, \mathrm{ln}\left(\frac{c}{b}\right) }{b-c} \right)}{a-b}$$

and the variance by

$$\sigma^2 = \frac{2 \left( \frac{ \mathrm{ln} \left(\frac{c}{a}\right) }{a-c} + \frac{ \mathrm{ln} \left(\frac{b}{c}\right) }{b-c} \right)}{a-b} - \mu^2.$$

Both moments of the reciprocal are only defined when the triangle does not cross zero, i.e. when *a*, *b*, and *c* are either all positive or all negative.
