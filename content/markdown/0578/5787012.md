# Lerche–Newberger sum rule

::: {#o1 .subject cue=lead name="Lerche–Newberger sum rule"}

In [mathematics](wikipedia://en/18831), the **Lerche–Newberger sum rule**, or **Newberger sum rule**, discovered by B. S. Newberger in 1982,[^o2][^o3][^o4] finds the sum of certain [infinite series](https://en.wikipedia.org/wiki/Infinite_series) involving [Bessel functions](wikipedia://en/4700) $J_\alpha$ [of the first kind](wikipedia://en/4700#Bessel_functions_of_the_first_kind). It states that if $\mu$ is any non-integer [complex number](wikipedia://en/5826), $\gamma \in (0,1]$, and $\Re(\alpha+\beta)>-1$, then

:::

$$\sum_{n=-\infty}^\infty\frac{(-1)^n J_{\alpha - \gamma n}(z)J_{\beta + \gamma n}(z)}{n+\mu}=\frac{\pi}{\sin \mu \pi}J_{\alpha + \gamma \mu}(z)J_{\beta - \gamma \mu}(z).$$

Newberger's formula generalizes a formula of this type proven by Lerche in 1966. Lerche's formula has $\gamma=1$; both extend a standard rule for the summation of Bessel functions, and are useful in [plasma](https://en.wikipedia.org/wiki/Plasma_%28physics%29) physics.[^o5][^o6][^o7][^o8]
