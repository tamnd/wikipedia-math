# Postnikov square

::: {#o1 .subject cue=lead name="Postnikov square"}

In [algebraic topology](wikipedia://en/38801), a **Postnikov square** is a certain [cohomology operation](wikipedia://en/1226719) from a first [cohomology](wikipedia://en/194060) [group](wikipedia://en/19447) *H*<sup>1</sup> to a third cohomology group *H*<sup>3</sup>, introduced by (txt). (Eilenberg 1952) described a generalization taking classes in *H*<sup>*t*</sup> to *H*<sup>2*t*+1</sup>.

:::
