# Bareiss algorithm

::: {#o1 .subject cue=lead name="Bareiss algorithm"}

In mathematics, the **Bareiss algorithm**, named after [Erwin Bareiss](https://en.wikipedia.org/wiki/Erwin_Bareiss), is an [algorithm](wikipedia://en/775) to calculate the [determinant](wikipedia://en/8468) or the [echelon form](https://en.wikipedia.org/wiki/Echelon_form) of a [matrix](wikipedia://en/20556859) with [integer](wikipedia://en/14563) entries using only integer arithmetic; any [divisions](wikipedia://en/53696) that are performed are guaranteed to be exact (there is no [remainder](wikipedia://en/502897)). The method can also be used to compute the determinant of matrices with (approximated) [real](wikipedia://en/20646438) entries, avoiding the introduction of any round-off errors beyond those already present in the input.

:::

## Overview {#Overview}

The definition of the [determinant](wikipedia://en/8468) of a matrix involves only the operations of multiplication, addition and subtraction. Therefore the determinant of a matrix is an integer whenever all the entries are integers. However, actual computation of the determinant using the definition or [Leibniz formula](wikipedia://en/5361510) is impractical, as it requires O(*n!*) operations. [Gaussian elimination](wikipedia://en/13035#Computing_determinants) has O(*n*<sup>3</sup>) complexity, but introduces division, which results in round-off errors when implemented using floating point numbers.

[Round-off errors](wikipedia://en/432450) can be avoided if all the numbers are kept as integer fractions instead of floating point. But then the size of each element grows in size exponentially with the number of rows.[^o3]

Bareiss brings up a question of performing an integer-preserving elimination while keeping the magnitudes of the intermediate coefficients reasonably small. Two algorithms are suggested:[^o4][^o5]

1. Division-free algorithm — performs matrix reduction to triangular form without any division operation.
1. Fraction-free algorithm — uses division to keep the intermediate entries smaller, but due to the [Sylvester's Identity](wikipedia://en/61109403) the transformation is still integer-preserving (the division has zero remainder).

For completeness Bareiss also suggests fraction-producing multiplication-free elimination methods.[^o4]

## Algorithm {#Algorithm}

The program structure of this algorithm is a simple triple-loop, as in the standard Gaussian elimination. However in this case the matrix is modified so that each $M$<sub>$k,k$</sub> entry contains the leading principal [minor](wikipedia://en/262107) \[$M$\]<sub>$k,k$</sub>. Algorithm correctness is easily shown by induction on $k$.[^o8]

blue

- Input: $M$ — an $n$-square matrix assuming its leading principal minors \[$M$\]<sub>$k,k$</sub> are all non-zero.
- Let *M*<sub>0,0</sub> = 1 (Note: *M*<sub>0,0</sub> is a special variable)
- For $k$ from 1 to $n$−1:
  - For $i$ from $k$+1 to $n$:
    - For $j$ from $k$+1 to $n$:
      - Set $M_{i,j} = \frac{M_{i,j} M_{k,k} - M_{i,k} M_{k,j}}{M_{k-1,k-1}}$
    - Set *M*<sub>i,k</sub> = 0
- Output: The matrix is modified [in-place](https://en.wikipedia.org/wiki/In-place_algorithm), each $M$<sub>$k,k$</sub> entry contains the leading minor \[$M$\]<sub>$k,k$</sub>, entry $M_{n,n}$ contains the determinant of the original $M$.

If the assumption about principal minors turns out to be false, e.g. if $M$<sub>$k$−1,$k$−1</sub> = 0 and some $M$<sub>$i$,$k$−1</sub> ≠ 0 ($i$ = $k$,...,$n$) then we can exchange the $k$−1-th row with the $i$-th row and change the sign of the final answer.

:::

## Analysis {#Analysis}

During execution of the Bareiss algorithm, every integer that is computed is the determinant of a submatrix of the input matrix. This allows, using the [Hadamard inequality](https://en.wikipedia.org/wiki/Hadamard_inequality), to bound the size of these integers. Otherwise, the Bareiss algorithm may be viewed as a variant of [Gaussian elimination](wikipedia://en/13035) and needs roughly the same number of arithmetic operations.

It follows that, for an *n* × *n* matrix of maximum (absolute) value 2<sup>*L*</sup> for each entry, the Bareiss algorithm runs in [O(*n*<sup>3</sup>)](wikipedia://en/44578) elementary operations with an O(*n*<sup>*n*/2</sup> 2<sup>*nL*</sup>) bound on the absolute value of intermediate values needed. Its [computational complexity](wikipedia://en/6511) is thus O(*n*<sup>5</sup>*L*<sup>2</sup> (log(*n*)<sup>2</sup> + *L*<sup>2</sup>)) when using elementary arithmetic or O(*n*<sup>4</sup>*L* (log(*n*) + *L*) log(log(*n*) + *L*))) by using [fast multiplication](https://en.wikipedia.org/wiki/Fast_multiplication).

## Usage {#Usage}

The Bareiss algorithm is not commonly used for integer matrices, because [multi-modular arithmetic](https://en.wikipedia.org/wiki/Multi-modular_arithmetic) allows a complexity similar to that of the Bareiss algorithm with fast multiplication, and is much simpler to implement.

On the other hand, the Bareiss algorithm may be used with entries in any [integral domain](wikipedia://en/15462) equipped with an exact-division algorithm, and, in particular, for matrices of polynomials.
