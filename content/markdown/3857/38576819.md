# Flow-equivalent server method

::: {#o1 .subject cue=lead name="Flow-equivalent server method"}

In [queueing theory](wikipedia://en/50578), a discipline within the mathematical theory of probability, the **flow-equivalent server method** (also known as **flow-equivalent aggregation technique**,[^o2] **Norton's theorem for queueing networks** or the **Chandy–Herzog–Woo method**[^o3]) is a [divide-and-conquer method](https://en.wikipedia.org/wiki/Divide-and-conquer_method) to solve [product form queueing networks](https://en.wikipedia.org/wiki/Product_form_queueing_network) inspired by [Norton's theorem](https://en.wikipedia.org/wiki/Norton's_theorem) for electrical circuits.[^o4] The network is successively split into two, one portion is reconfigured to a closed network and evaluated.

:::

Marie's algorithm is a similar method where analysis of the sub-network are performed with state-dependent [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) arrivals.[^o5][^o6]
