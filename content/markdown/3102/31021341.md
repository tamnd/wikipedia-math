# Bootstrap error-adjusted single-sample technique

::: {#o1 .subject cue=lead name="Bootstrap error-adjusted single-sample technique"}

In [statistics](wikipedia://en/26685), the **bootstrap error-adjusted single-sample technique** (**BEST** or **the BEAST**) is a [non-parametric](https://en.wikipedia.org/wiki/Non-parametric_statistics) method that is intended to allow an assessment to be made of the validity of a single sample. It is based on estimating a [probability distribution](wikipedia://en/23543) representing what can be expected from valid samples.[^o2] This is done use a statistical method called [bootstrapping](wikipedia://en/6885770), applied to previous samples that are known to be valid.

:::

## Methodology {#Methodology}

BEST provides advantages over other methods such as the [Mahalanobis metric](wikipedia://en/799760), because it does not assume that for all spectral groups have equal [covariances](wikipedia://en/157059) or that each group is drawn for a [normally distributed population](wikipedia://en/21462).[^o4] A quantitative approach involves BEST along with a nonparametric [cluster analysis](wikipedia://en/669675) algorithm. Multidimensional standard deviations (MDSs) between clusters and spectral data points are calculated, where BEST considers each frequency to be taken from a separate dimension.[^o5]

BEST is based on a population, P, relative to some hyperspace, R, that represents the universe of possible samples. P<sup>\*</sup> is the realized values of P based on a calibration set, T. T is used to find all possible variation in P. P<sup>\*</sup> is bound by parameters C and B. C is the expectation value of P, written E(P), and B is a bootstrapping distribution called the [Monte Carlo](wikipedia://en/56098) approximation. The [standard deviation](wikipedia://en/27590) can be found using this technique. The values of B projected into hyperspace give rise to X. The hyperline from C to X gives rise to the skew adjusted standard deviation which is calculated in both directions of the hyperline.[^o6]

::: {#o8 .application cue=heading name="Application"}

## Application {#Application}

BEST is used in detection of sample tampering in pharmaceutical products. Valid (unaltered) samples are defined as those that fall inside the cluster of training-set points when the BEST is trained with unaltered product samples. False (tampered) samples are those that fall outside of the same cluster.[^o2]

Methods such as [ICP-AES](https://en.wikipedia.org/wiki/ICP-AES) require capsules to be emptied for analysis. A [nondestructive](https://en.wikipedia.org/wiki/Nondestructive_testing) method is valuable. A method such as NIRA can be coupled to the BEST method in the following ways.[^o2]

- Detect any tampered product by determining that it is not similar to the previously analyzed unaltered product.
- Quantitatively identify the contaminant from a library of known adulterants in that product.
- Provide quantitative indication of the amount of contaminant present.

:::
