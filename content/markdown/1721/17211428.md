# Global analytic function

::: {#o1 .subject cue=lead name="Global analytic function"}

In the [mathematical](wikipedia://en/18831) field of [complex analysis](wikipedia://en/5759), a **global analytic function** (or **complete analytic function**) is a generalization of the notion of an [analytic function](wikipedia://en/61478) which allows for functions to have multiple [branches](https://en.wikipedia.org/wiki/Branch_cut). Global analytic functions arise naturally in considering the possible [analytic continuations](wikipedia://en/80842) of an analytic function, since analytic continuations may have a non-trivial [monodromy](wikipedia://en/251250). They are one foundation for the theory of [Riemann surfaces](wikipedia://en/173181).

:::

The definition of a global analytic function goes back to [Karl Weierstrass](wikipedia://en/93459).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The following definition may be found in (Ahlfors 1979). An analytic function in an [open set](wikipedia://en/39358) *U* is called a function element. Two function elements (*f*<sub>1</sub>, *U*<sub>1</sub>) and (*f*<sub>2</sub>, *U*<sub>2</sub>) are said to be [analytic continuations](wikipedia://en/80842) of one another if *U*<sub>1</sub> ∩ *U*<sub>2</sub> ≠ ∅ and *f*<sub>1</sub> = *f*<sub>2</sub> on this intersection. A chain of analytic continuations is a finite sequence of function elements (*f*<sub>1</sub>, *U*<sub>1</sub>), …, (*f*<sub>*n*</sub>,*U*<sub>*n*</sub>) such that each consecutive pair are analytic continuations of one another; i.e., (*f*<sub>*i*+1</sub>, *U*<sub>*i*+1</sub>) is an analytic continuation of (*f*<sub>*i*</sub>, *U*<sub>*i*</sub>) for *i* = 1, 2, …, *n* − 1.

A global analytic function is a family **f** of function elements such that, for any (*f*,*U*) and (*g*,*V*) belonging to **f**, there is a chain of analytic continuations in **f** beginning at (*f*,*U*) and finishing at (*g*,*V*).

A complete global analytic function is a global analytic function **f** which contains every analytic continuation of each of its elements.

### Sheaf-theoretic definition {#Sheaf-theoretic_definition}

Using ideas from [sheaf theory](https://en.wikipedia.org/wiki/Sheaf_theory), the definition can be streamlined. In these terms, a complete global analytic function is a [path-connected](wikipedia://en/6233#Path_connectedness) sheaf of germs of analytic functions which is *maximal* in the sense that it is not contained (as an [etale space](https://en.wikipedia.org/wiki/Etale_space)) within any other path connected sheaf of germs of analytic functions.
