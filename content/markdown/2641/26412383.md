# GraphCrunch

::: {#o1 .subject cue=lead name="GraphCrunch"}

**GraphCrunch** is a comprehensive, parallelizable, and easily extendible [open source](https://en.wikipedia.org/wiki/Open-source_software) software tool for analyzing and modeling large [biological networks](https://en.wikipedia.org/wiki/Network_biology) (or [graphs](wikipedia://en/325806)); it compares real-world networks against a series of [random graph models](wikipedia://en/358477) with respect to a multitude of local and global network properties.[^o2]

:::

## Motivation {#Motivation}

Recent technological advances in experimental biology have yielded large amounts of biological network data. Many other real-world phenomena have also been described in terms of large networks (also called graphs), such as various types of social and technological networks. Thus, understanding these complex phenomena has become an important scientific problem that has led to intensive research in network modeling and analyses.

An important step towards understanding biological networks is finding an adequate network model. Evaluating the fit of a model network to the data is a formidable challenge, since network comparisons are computationally infeasible and thus have to rely on heuristics, or "network properties." GraphCrunch automates the process of generating random networks drawn from a series of random graph models and evaluating the fit of the network models to a real-world network with respect to a variety of global and local network properties.

## Features {#Features}

GraphCrunch performs the following tasks: 1) computes user specified global and local properties of an input real-world network, 2) creates a user specified number of random networks belonging to user specified random graph models, 3) compares how closely each model network reproduces a range of global and local properties (specified in point 1 above) of the real-world network, and 4) produces the statistics of network property similarities between the data and the model networks.

## Network models supported by GraphCrunch {#Network_models_supported_by_GraphCrunch}

GraphCrunch currently supports five different types of random graph models:

1. [Erdös-Rényi random graphs](wikipedia://en/10477221);
1. random graphs with the same degree distribution as the data;
1. [Barabási-Albert preferential-attachment scale-free networks](wikipedia://en/8286726);
1. *n*-dimensional [geometric random graphs](wikipedia://en/12106740) (for all positive integers *n*); and
1. stickiness model networks.

## Network properties supported by GraphCrunch {#Network_properties_supported_by_GraphCrunch}

GraphCrunch currently supports seven global and local network properties:

1. [degree distribution](wikipedia://en/2129782);
1. [clustering coefficient](wikipedia://en/1457636);
1. clustering spectrum;
1. [average diameter](https://en.wikipedia.org/wiki/Average_path_length);
1. spectrum of shortest path lengths;
1. [relative graphlet frequency distance](https://en.wikipedia.org/wiki/Graphlets#Relative_graphlet_frequency_distance); and
1. [graphlet degree distribution agreement](https://en.wikipedia.org/wiki/Graphlets#Graphlet_degree_distribution_agreement).

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

GraphCrunch has been used to find an optimal network model for protein-protein interaction networks,[^o9][^o10] as well as for protein structure networks.[^o10][^o11]
