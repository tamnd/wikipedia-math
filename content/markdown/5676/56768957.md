# Abundance conjecture

::: {#o1 .subject cue=lead name="Abundance conjecture"}

In algebraic geometry, the **abundance conjecture** is a conjecture in [birational geometry](wikipedia://en/382733), more precisely in the [minimal model program](wikipedia://en/15148924), stating that for every [projective variety](wikipedia://en/320469) $X$ with [Kawamata log terminal singularities](https://en.wikipedia.org/wiki/Kawamata_log_terminal_singularity) over a field $k$ if the [canonical bundle](wikipedia://en/734893) $K_X$ is [nef](wikipedia://en/3404309), then $K_X$ is [semi-ample](wikipedia://en/1186896), i.e. $mK_X$ is base-point free for some $m>0$. In particular, if abundance holds, then one is able to define a model $X\rightarrow Y=\mathrm{Proj}\bigoplus_{l\geqslant 0} H^0(X, lK_X).$

:::

Important cases of the abundance conjecture have been proven by [Caucher Birkar](wikipedia://en/36465461).[^o2]
