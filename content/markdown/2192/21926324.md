# Self-similarity matrix

::: {#o1 .subject cue=lead name="Self-similarity matrix"}

In [data analysis](wikipedia://en/2720954), the **self-similarity matrix** is a graphical representation of [similar](wikipedia://en/1004743) sequences in a data series.

:::

Similarity can be explained by different measures, like spatial distance ([distance matrix](wikipedia://en/831350)), [correlation](wikipedia://en/157057), or comparison of local [histograms](wikipedia://en/13266) or [spectral properties](https://en.wikipedia.org/wiki/Spectral_properties) (e.g. IXEGRAM[^o2]). A similarity plot can be the starting point for [dot plots](wikipedia://en/8634376) or [recurrence plots](https://en.wikipedia.org/wiki/Recurrence_plots).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

To construct a self-similarity matrix, one first transforms a data series into an ordered sequence of [feature vectors](https://en.wikipedia.org/wiki/Feature_vector) $V = (v_1, v_2, \ldots, v_n)$, where each vector $v_i$ describes the relevant features of a data series in a given local interval. Then the self-similarity matrix is formed by computing the similarity of pairs of feature vectors

$$S(j,k) = s(v_j, v_k) \quad j,k \in (1,\ldots,n)$$

where $s(v_j, v_k)$ is a function measuring the similarity of the two vectors, for instance, the [inner product](https://en.wikipedia.org/wiki/Inner_product) $s(v_j, v_k) = v_j \cdot v_k$. Then similar segments of feature vectors will show up as path of high similarity along diagonals of the matrix.[^o5] Similarity plots are used for action recognition that is invariant to point of view [^o6] and for audio segmentation using [spectral clustering](wikipedia://en/13651683) of the self-similarity matrix.[^o7]

:::
