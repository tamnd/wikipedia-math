# Rainbow-independent set

*Image: Rainbow independent set.svg.* Each selected (hollow circle) vertex is of a different color, and no edges connect any of them. The set of selected vertices is therefore **rainbow-independent** in the given graph.

::: {#o1 .subject cue=lead name="Rainbow-independent set"}

In [graph theory](wikipedia://en/12401), a **rainbow-independent set** (**ISR**) is an [independent set](wikipedia://en/524501) in a [graph](wikipedia://en/325806), in which each [vertex](wikipedia://en/638899) has a different [color](wikipedia://en/426743).

:::

Formally, let $G = (V, E)$ be a graph, and suppose vertex set $V$ is [partitioned](wikipedia://en/11973947) into $m$ subsets $V_{1}, \ldots, V_{m}$, called "colors". A set $U$ of vertices is called a rainbow-independent set if it satisfies both the following conditions:[^o2]

- It is an **independent set** – every two vertices in $U$ are not adjacent (there is no edge between them);
- It is a **rainbow set** – $U$ contains at most a single vertex from each color $V_{i}$.

Other terms used in the literature are **independent set of representatives**,[^o3] **independent transversal**,[^o4] and **independent system of representatives**.[^o5]

As an example application, consider a faculty with $m$ departments, where some faculty members dislike each other. The dean wants to construct a committee with $m$ members, one member per department, but without any pair of members who dislike each other. This problem can be presented as finding an ISR in a graph in which the nodes are the faculty members, the edges describe the "dislike" relations, and the subsets $V_{1}, \ldots, V_{m}$ are the departments.[^o4]

::: {#o7 .statement kind=statement/generalization cue=heading name="Variants"}

## Variants {#Variants}

It is assumed for convenience that the sets $V_{1}, \ldots, V_{m}$ are pairwise-disjoint. In general the sets may intersect, but this case can be easily reduced to the case of [disjoint sets](wikipedia://en/39359): for every vertex $x$, form a copy of $x$ for each $i$ such that $V_{i}$ contains $x$. In the resulting graph, connect all copies of $x$ to each other. In the new graph, the $V_{i}$ are disjoint, and each ISR corresponds to an ISR in the original graph.[^o5]

ISR generalizes the concept of a *[system of distinct representatives](https://en.wikipedia.org/wiki/System_of_distinct_representatives)* (SDR, also known as **transversal**). Every transversal is an ISR where in the underlying graph, all and only copies of the same vertex from different sets are connected.

:::

## Existence of rainbow-independent sets {#Existence_of_rainbow-independent_sets}

There are various sufficient conditions for the existence of an ISR.

### Condition based on vertex degree {#Condition_based_on_vertex_degree}

Intuitively, when the departments $V_{i}$ are larger, and there is less conflict between faculty members, an ISR should be more likely to exist. The "less conflict" condition is represented by the [vertex degree](https://en.wikipedia.org/wiki/Vertex_degree) of the graph. This is formalized by the following theorem:[^o10]

> If the degree of every vertex in $G$ is at most $d$, and the size of each color-set is at least $2d$, then $G$ has an ISR.

The $2d$ is best possible: there are graph with vertex degree $k$ and colors of size $2d - 1$ without an ISR.[^o11] But there is a more precise version in which the bound depends both on $d$ and on $m$.[^o12]

### Condition based on dominating sets {#Condition_based_on_dominating_sets}

Below, given a subset $S$ of colors (a subset of $\{V_{1}, ..., V_{m}\}$), we denote by $U_{S}$ the union of all subsets in $S$ (all vertices whose color is one of the colors in $S$), and by $G_{S}$ the subgraph of $G$ induced by $U_{S}$.[^o14] The following theorem describes the structure of graphs that have no ISR but are *edge-minimal*, in the sense that whenever any edge is removed from them, the remaining graph has an ISR.

> If $G$ has no ISR, but for every edge $e$ in $E$, $G-e$ has an ISR, then for every edge $e = (x, y)$ in $E$, there exists a subset $S$ of the colors $\{V_{1}, \ldots, V_{m}\},$ and a set $Z$ of edges of $G_{S}$, such that:
>
> The vertices $x$ and $y$ are both in $U_{S}$;
>
> The edge $e = (x, y)$ is in $Z$;
>
> The set of vertices adjacent to $Z$ [*dominates*](wikipedia://en/1747972) $G_{S}$;
>
> $$\lvert Z\rvert \le \lvert S\rvert - 1;$$
>
> $Z$ is a [matching](wikipedia://en/581797) – no two edges of it are adjacent to the same vertex.

### Hall-type condition {#Hall-type_condition}

Below, given a subset $S$ of colors (a subset of $\{V_{1}, \ldots, V_{m}\}$), an independent set $I_{S}$ of $G_{S}$ is called **special for $S$** if for every independent subset $J$ of vertices of $G_{S}$ of size at most $\lvert S\rvert - 1$, there exists some $v$ in $I_{S}$ such that $J \cup \{v\}$ is also independent. Figuratively, $I_{S}$ is a team of "neutral members" for the set $S$ of departments, that can augment any sufficiently small set of non-conflicting members, to create a larger such set. The following theorem is analogous to [Hall's marriage theorem](wikipedia://en/186969):[^o17]

> If, for every subset S of colors, the graph $G_{S}$ contains an independent set $I_{S}$ that is special for $S$, then $G$ has an ISR. *Proof idea*. The theorem is proved using [Sperner's lemma](wikipedia://en/465067).[^o4] The standard simplex with $m$ endpoints is assigned a triangulation with some special properties. Each endpoint $i$ of the simplex is associated with the color-set $V_{i}$, each face $\{i_{1}, \ldots, i_{k}\}$ of the simplex is associated with a set $S = \{V_{i1}, \ldots, V_{ik}\}$ of colors. Each point $x$ of the triangulation is labeled with a vertex $g(x)$ of $G$ such that: (a) For each point $x$ on a face $S$, $g(x)$ is an element of $I_{S}$ – the special independent set of $S$. (b) If points $x$ and $y$ are adjacent in the [1-skeleton](https://en.wikipedia.org/wiki/1-skeleton) of the triangulation, then $g(x)$ and $g(y)$ are not adjacent in $G$. By Sperner's lemma, there exists a sub-simplex in which, for each point $x$, $g(x)$ belongs to a different color-set; the set of these $g(x)$ is an ISR.

The above theorem implies Hall's marriage condition. To see this, it is useful to state the theorem for the special case in which $G$ is the [line graph](wikipedia://en/675231) of some other graph $H$; this means that every vertex of $G$ is an edge of $H$, and every independent set of $G$ is a matching in $H$. The vertex-coloring of $G$ corresponds to an edge-coloring of $H$, and a rainbow-independent-set in $G$ corresponds to a rainbow-matching in $H$. A matching $I_{S}$ in $H_{S}$ is special for $S$, if for every matching $J$ in $H_{S}$ of size at most $\lvert S\rvert - 1$, there is an edge $e$ in $I_{S}$ such that $J \cup \{e\}$ is still a matching in $H_{S}$.

> Let $H$ be a graph with an edge-coloring. If, for every subset $S$ of colors, the graph $H_{S}$ contains a matching $M_{S}$ that is special for $S$, then $H$ has a rainbow-matching.

Let $H = (X + Y, E)$ be a bipartite graph satisfying Hall's condition. For each vertex $i$ of $X$, assign a unique color $V_{i}$ to all edges of $H$ adjacent to $i$. For every subset $S$ of colors, Hall's condition implies that $S$ has at least $\lvert S\rvert$ neighbors in $Y$, and therefore there are at least $\lvert S\rvert$ edges of $H$ adjacent to distinct vertices of $Y$. Let $I_{S}$ be a set of $\lvert S\rvert$ such edges. For any matching $J$ of size at most $\lvert S\rvert - 1$ in $H$, some element $e$ of $I_{S}$ has a different endpoint in $Y$ than all elements of $J$, and thus $J \cup \{e\}$ is also a matching, so $I_{S}$ is special for $S$. The above theorem implies that $H$ has a rainbow matching $M_{R}$. By definition of the colors, $M_{R}$ is a perfect matching in $H$.

Another corollary of the above theorem is the following condition, which involves both vertex degree and cycle length:[^o4]

> If the [degree of every vertex](wikipedia://en/1374448) in $G$ is at most 2, and the length of each cycle of $G$ is divisible by 3, and the size of each color-set is at least 3, then $G$ has an ISR. *Proof.* For every subset $S$ of colors, the graph $G_{S}$ contains at least $3\lvert S\rvert$ vertices, and it is a union of cycles of length divisible by 3 and paths. Let $I_{S}$ be an independent set in $G_{S}$ containing every third vertex in each cycle and each path. So $\lvert I_{S}\rvert$ contains at least $\tfrac{3\lvert S\rvert}{3} = \lvert S\rvert$ vertices. Let $J$ be an independent set in $G_{S}$ of size at most $\lvert S\rvert - 1$. Since the distance between each two vertices of $I_{S}$ is at least 3, every vertex of $J$ is adjacent to at most one vertex of $I_{S}$. Therefore, there is at least one vertex of $I_{S}$ which is not adjacent to any vertex of $J$. Therefore $I_{S}$ is special for $S$. By the previous theorem, $G$ has an ISR.

### Condition based on homological connectivity {#Condition_based_on_homological_connectivity}

One family of conditions is based on the [homological connectivity](wikipedia://en/64688677) of the [independence complex](wikipedia://en/64659151) of subgraphs. To state the conditions, the following notation is used:

- $\operatorname{Ind}(G)$ denotes the [independence complex](wikipedia://en/64659151) of a graph $G$ (that is, the [abstract simplicial complex](wikipedia://en/723105) whose faces are the independent sets in $G$).
- $\eta_{H}(X)$ denotes the [homological connectivity](wikipedia://en/64688677) of a simplicial complex $X$ (i.e., the largest integer $k$ such that the first $k$ homology groups of $X$ are trivial), plus 2.
- $[m]$ is the set of indices of colors, $\{1, \ldots, n\}.$ For any subset $J$ of $[m]$, $V_{J}$ is the union of colors $V_{J}$ for $J$ in $J$.
- $G[V_{J}]$ is the subgraph of $G$ induced by the vertices in $V_{J}$.

The following condition is implicit in [^o17] and proved explicitly in.[^o18]

> If, for all subsets $J$ of $[m]$:
>
> $\eta_H(\text{Ind}(G[V_J])) \geq |J|$ then the partition $V_{1}, \ldots, V_{m}$ admits an ISR.

As an example,[^o5] suppose $G$ is a [bipartite graph](wikipedia://en/244431), and its parts are exactly $V_{1}$ and $V_{2}$. In this case $[m] = \{1,2\}$ so there are four options for $J$:

- $J = \{\}:$ then $G[J] = \{\}$ and $\operatorname{Ind}(G[J]) = \{\}$ and the connectivity is infinite, so the condition holds trivially.
- $J = \{1\}:$ then $G[J]$ is a graph with vertices $V_{1}$ and no edges. Here all vertex sets are independent, so $\operatorname{Ind}(G[J])$ is the power set of $V_{1}$, i.e., it has a single $n$-simplex (and all its subsets). It is known that a single simplex is $k$-connected for all integers $k$, since all its reduced homology groups are trivial (see [simplicial homology](wikipedia://en/1060236)). Hence the condition holds.
- $J = \{2\}:$ this case is analogous to the previous one.
- $J = \{1,2\}:$ then $G[J] = G$, and $\operatorname{Ind}(G)$ contains two simplices $V_{1}$ and $V_{2}$ (and all their subsets). The condition $\eta_{H}(\operatorname{Ind}(G)) \ge 2$ is equivalent to the condition that the homological connectivity of $\operatorname{Ind}(G)$ is at least 0, which is equivalent to the condition that $\tilde{H_0}(\text{Ind}(G))$ is the [trivial group](wikipedia://en/193059). This holds if-and-only-if the complex $\operatorname{Ind}(G)$ contains a connection between its two simplices $V_{1}$ and $V_{2}$. Such a connection is equivalent to an independent set in which one vertex is from $V_{1}$ and one is from $V_{2}$. Thus, in this case, the condition of the theorem is not only sufficient but also necessary.

### Other conditions {#Other_conditions}

Every properly coloured [triangle-free graph](wikipedia://en/7667996) of [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) $x$ contains a rainbow-independent set of size at least $\tfrac{x}{2}$.[^o20]

Several authors have studied conditions for existence of large rainbow-independent sets in various classes of graphs.[^o2][^o21]

## Computation {#Computation}

The *ISR decision problem* is the problem of deciding whether a given graph $G = (V, E)$ and a given partition of $V$ into $m$ colors admits a rainbow-independent set. This problem is [NP-complete](wikipedia://en/23385892). The proof is by reduction from the [3-dimensional matching](wikipedia://en/22261908) problem (3DM).[^o5] The input to 3DM is a tripartite hypergraph $(X + Y + Z, F)$, where $X$, $Y$, $Z$ are vertex-sets of size $m$, and $F$ is a set of triplets, each of which contains a single vertex of each of $X$, $Y$, $Z$. An input to 3DM can be converted into an input to ISR as follows:

- For each edge $(x,y,z)$ in $F$, there is a vertex $v_{x,y,z}$ in $V$;
- For each vertex $z$ in $Z$, let $V_{z} = \{v_{x,y,z} | x \in X, y \in Y\}.$
- For each $x$, $y_{1}$, $y_{2}$, $z_{1}$, $z_{2}$, there is an edge $(v_{x, y_{1}, z_{1}}, v_{x, y_{2}, z_{2}})$ in $E$;
- For each $x_{1}$, $x_{2}$, $y$, $z_{1}$, $z_{2}$, there is an edge $(v_{x_{1}, y, z_{1}}, v_{x_{2}, y, z_{2}})$ in $E$;

In the resulting graph $G = (V, E)$, an ISR corresponds to a set of triplets $(x,y,z)$ such that:

- Each triplet has a different $z$ value (since each triplet belongs to a different color-set $V_{z}$);
- Each triplet has a different $x$ value and a different $y$ value (since the vertices are independent).

Therefore, the resulting graph admits an ISR if and only if the original hypergraph admits a 3DM.

An alternative proof is by reduction from [SAT](wikipedia://en/4715).[^o4]

:::

## Related concepts {#Related_concepts}

If $G$ is the [line graph](wikipedia://en/675231) of some other graph $H$, then the independent sets in $G$ are the [matchings](wikipedia://en/581797) in $H$. Hence, a rainbow-independent set in $G$ is a *[rainbow matching](wikipedia://en/42366612)* in $H$. See also [matching in hypergraphs](wikipedia://en/63030703).

Another related concept is a *rainbow cycle*, which is a [cycle](wikipedia://en/168609) in which each vertex has a different color.[^o25]

When an ISR exists, a natural question is whether there exist other ISRs, such that the entire set of vertices is partitioned into disjoint ISRs (assuming the number of vertices in each color is the same). Such a partition is called *[strong coloring](wikipedia://en/690775)*.

Using the faculty metaphor:[^o4]

- A *[system of distinct representatives](https://en.wikipedia.org/wiki/System_of_distinct_representatives)* is a committee of distinct members, with or without conflicts.
- An *[independent set](wikipedia://en/524501)* is a committee with no conflict.
- An *independent transversal* is a committee with no conflict, with exactly one member from each department.
- A *[graph coloring](wikipedia://en/426743)* is a partitioning of the faculty members into committees with no conflict.
- A *[strong coloring](wikipedia://en/690775)* is a partitioning of the faculty members into committees with no conflict and with exactly one member from each department. Thus this problem is sometimes called the *happy dean problem*.

A *rainbow clique* or a *colorful clique* is a [clique](wikipedia://en/524466) in which every vertex has a different color.[^o18] Every clique in a graph corresponds to an independent set in its [complement graph](wikipedia://en/1175649). Therefore, every rainbow clique in a graph corresponds to a rainbow-independent set in its complement graph.
