# Mesh analysis

::: {#o1 .subject cue=lead name="Mesh analysis"}

*Image: Mesh Analysis Example1 TeX.svg.* Figure 1: Essential meshes of the planar circuit labeled 1, 2, and 3. R<sub>1</sub>, R<sub>2</sub>, R<sub>3</sub>, 1/sC, and sL represent the [impedance](https://en.wikipedia.org/wiki/Electrical_impedance) of the [resistors](https://en.wikipedia.org/wiki/Resistor), [capacitor](https://en.wikipedia.org/wiki/Capacitor), and [inductor](https://en.wikipedia.org/wiki/Inductor) values in the [s-domain](https://en.wikipedia.org/wiki/S-domain). V<sub>s</sub> and I<sub>s</sub> are the values of the [voltage source](https://en.wikipedia.org/wiki/Voltage_source) and [current source](https://en.wikipedia.org/wiki/Current_source), respectively.

**Mesh analysis** (or the **mesh current method**) is a [circuit analysis](https://en.wikipedia.org/wiki/Circuit_analysis) method for [planar circuits](wikipedia://en/24314); planar circuits are circuits that can be drawn on a [plane surface](wikipedia://en/19469852) with no [wires](https://en.wikipedia.org/wiki/Wire) crossing each other. A more general technique, called **loop analysis** (with the corresponding network variables called **loop currents**) can be applied to any circuit, planar or not.

:::

Mesh analysis and loop analysis both make systematic use of [Kirchhoff's voltage law](https://en.wikipedia.org/wiki/Kirchhoff's_circuit_laws) (KVL) to arrive at a set of equations guaranteed to be solvable if the circuit has a solution.[^o2] Similarly, [nodal analysis](wikipedia://en/2329101) is a systematic application of Kirchhoff's current law (KCL). Mesh analysis is usually easier to use when the circuit is planar, compared to loop analysis.[^o3]

## Mesh currents and essential meshes {#Mesh_currents_and_essential_meshes}

*Image: Mesh Analysis Example2 TeX.svg.* Figure 2: Circuit with mesh currents labeled as I<sub>1</sub>, I<sub>2</sub>, and I<sub>3</sub>. The arrows show the direction of the mesh current.

Mesh analysis works by arbitrarily assigning mesh currents in the essential meshes (also referred to as independent meshes). An essential mesh is a loop in the circuit that does not contain any other loop. Figure 1 labels the essential meshes with one, two, and three.[^o5]

A mesh current is a current that loops around the essential mesh and the equations are solved in terms of them. A mesh current may not correspond to any physically flowing current, but the physical currents are easily found from them.[^o3] It is usual practice to have all the mesh currents loop in the same direction. This helps prevent errors when writing out the equations. The convention is to have all the mesh currents looping in a [clockwise](https://en.wikipedia.org/wiki/Clockwise) direction.[^o5] Figure 2 shows the same circuit from Figure 1 with the mesh currents labeled.

Solving for mesh currents instead of directly applying [Kirchhoff's current law](https://en.wikipedia.org/wiki/Kirchhoff's_circuit_laws#Kirchhoff's_current_law_%28KCL%29) and [Kirchhoff's voltage law](https://en.wikipedia.org/wiki/Kirchhoff's_circuit_laws#Kirchhoff's_voltage_law_%28KVL%29) can greatly reduce the amount of calculation required. This is because there are fewer mesh currents than there are physical branch currents. In figure 2 for example, there are six branch currents but only three mesh currents.

## Setting up the equations {#Setting_up_the_equations}

Each mesh produces one equation. These equations are the sum of the [voltage drops](https://en.wikipedia.org/wiki/Voltage_drop) in a complete loop of the mesh current.[^o5] For problems more general than those including [current](https://en.wikipedia.org/wiki/Current_source) and [voltage sources](https://en.wikipedia.org/wiki/Voltage_source), the [voltage drops](https://en.wikipedia.org/wiki/Voltage_drop) will be the [impedance](https://en.wikipedia.org/wiki/Electrical_impedance) of the [electronic component](https://en.wikipedia.org/wiki/Electronic_component) multiplied by the mesh current in that loop.[^o7]

If a [voltage source](https://en.wikipedia.org/wiki/Voltage_source) is present within the mesh loop, the [voltage](https://en.wikipedia.org/wiki/Voltage) at the source is either added or subtracted depending on if it is a [voltage drop](https://en.wikipedia.org/wiki/Voltage_drop) or a voltage rise in the direction of the mesh current. For a [current source](https://en.wikipedia.org/wiki/Current_source) that is not contained between two meshes (for example, the current source in essential mesh 1 in the circuit above), the mesh current will take the positive or negative value of the [current source](https://en.wikipedia.org/wiki/Current_source) depending on if the mesh current is in the same or opposite direction of the [current source](https://en.wikipedia.org/wiki/Current_source).[^o5] The following is the same circuit from above with the equations needed to solve for all the currents in the circuit.

$$\begin{cases} \text{Mesh 1: } I_1 = I_s\\ \text{Mesh 2: } -V_s + R_1(I_2-I_1) + \frac{1}{s C}(I_2-I_3)=0\\ \text{Mesh 3: } \frac{1}{s C}(I_3-I_2) + R_2(I_3-I_1) + sLI_3=0\\ \end{cases} \,$$

Once the equations are found, the [system of linear equations](wikipedia://en/113087) can be solved by using any technique to solve [linear equations](wikipedia://en/17570).

## Special cases {#Special_cases}

There are two special cases in mesh current: currents containing a supermesh and currents containing [dependent sources](https://en.wikipedia.org/wiki/Dependent_source).

### Supermesh {#Supermesh}

*Image: Mesh Analysis Example3 TeX.svg.* Figure 3: Circuit with a supermesh. Supermesh occurs because the current source is in between the essential meshes.

A supermesh occurs when a [current source](https://en.wikipedia.org/wiki/Current_source) is contained between two essential meshes. The circuit is first treated as if the [current source](https://en.wikipedia.org/wiki/Current_source) is not there. This leads to one equation that incorporates two mesh currents. Once this equation is formed, an equation is needed that relates the two mesh currents with the [current source](https://en.wikipedia.org/wiki/Current_source). This will be an equation where the [current source](https://en.wikipedia.org/wiki/Current_source) is equal to one of the mesh currents minus the other. The following is a simple example of dealing with a supermesh.[^o3]

$$\begin{cases} \text{Mesh 1, 2: } -V_s + R_1I_1 + R_2I_2 = 0\\ \text{Current source: } I_s = I_2 - I_1 \end{cases} \,$$

### Dependent sources {#Dependent_sources}

*Image: Mesh Analysis Example4 TeX.svg.* Figure 4: Circuit with dependent source. I<sub>x</sub> is the current upon which the dependent source depends.

A dependent source is a [current source](https://en.wikipedia.org/wiki/Current_source) or [voltage source](https://en.wikipedia.org/wiki/Voltage_source) that depends on the [voltage](https://en.wikipedia.org/wiki/Voltage) or [current](https://en.wikipedia.org/wiki/Electric_current) of another [element](https://en.wikipedia.org/wiki/Electronic_component) in the circuit. When a dependent source is contained within an essential mesh, the dependent source should be treated like an independent source. After the mesh equation is formed, a dependent source equation is needed. This equation is generally called a constraint equation. This is an equation that relates the dependent source's variable to the [voltage](https://en.wikipedia.org/wiki/Voltage) or [current](https://en.wikipedia.org/wiki/Electric_current) that the source depends on in the circuit. The following is a simple example of a dependent source.[^o3]

$$\begin{cases} \text{Mesh 1: } -V_s + R_1I_1 + R_3(I_1 - I_2) = 0\\ \text{Mesh 2: } R_2I_2 + 3I_x + R_3(I_2 - I_1) = 0\\ \text{Dependent variable: } I_x = I_1 - I_2 \end{cases} \,$$
