# Homogeneous relation

::: {#o1 .subject cue=lead name="Homogeneous relation"}

In [mathematics](wikipedia://en/18831), a **homogeneous relation** (also called **endorelation**) on a set *X* is a [binary relation](wikipedia://en/3931) between *X* and itself, i.e. it is a subset of the [Cartesian product](wikipedia://en/24104095) $X \times X$.[^o2][^o3][^o4] This is commonly phrased as "a relation on *X*"[^o5] or "a (binary) relation over *X*".[^o6][^o7] An example of a homogeneous relation is the relation of [kinship](https://en.wikipedia.org/wiki/Kinship), where the relation is between people.

:::

Common types of endorelations include [orders](wikipedia://en/19074048), [graphs](wikipedia://en/325806), and [equivalences](wikipedia://en/9259). Specialized studies of [order theory](wikipedia://en/361924) and [graph theory](wikipedia://en/12401) have developed understanding of endorelations. Terminology particular for graph theory is used for description, with an ordinary (undirected) graph presumed to correspond to a [symmetric relation](wikipedia://en/200459), and a general endorelation corresponding to a [directed graph](wikipedia://en/19721986). An endorelation *R* corresponds to a [logical matrix](wikipedia://en/4109196) of 0s and 1s, where the expression *xRy* (*x* is *R*-related to *y*) corresponds to an edge between *x* and *y* in the graph, and to a 1 in the [square matrix](wikipedia://en/166022) of *R*. It is called an [adjacency matrix](wikipedia://en/244463) in graph terminology.

## Particular homogeneous relations {#Particular_homogeneous_relations}

Some particular homogeneous relations over a set *X* (with arbitrary elements $x_{1}$, $x_{2}$) are:

**Empty relation**

$E = \emptyset$; that is, $x_{1}Ex_{2}$ holds never;

**Universal relation**

$U = X \times X$; that is, $x_{1}Ux_{2}$ holds always;

**Identity relation (see also *[Identity function](wikipedia://en/15069)*)**

$I = \{(x, x) | x \in X$}; that is, $x_{1}Ix_{2}$ holds if and only if $x_{1} = x_{2}$.

## Properties {#Properties}

Some important properties that a homogeneous relation $R$ over a set $X$ may have are:

**[Reflexive](wikipedia://en/200458)**

for all $x \in X$, $xRx$. For example, ≥ is a reflexive relation but > is not.

**[Irreflexive](https://en.wikipedia.org/wiki/Irreflexive_relation) (or strict)**

for all $x \in X$, not $xRx$. For example, > is an irreflexive relation, but ≥ is not.

**[Coreflexive](https://en.wikipedia.org/wiki/Coreflexive_relation)**

for all $x, y \in X$, if $xRy$ then $x = y$.[^o14] For example, the relation over the integers in which each odd number is related to itself is a coreflexive relation. The equality relation is the only example of a both reflexive and coreflexive relation, and any coreflexive relation is a subset of the identity relation.

**[Left quasi-reflexive](https://en.wikipedia.org/wiki/Left_quasi-reflexive)**

for all $x, y \in X$, if $xRy$ then $xRx$.

**[Right quasi-reflexive](https://en.wikipedia.org/wiki/Right_quasi-reflexive)**

for all $x, y \in X$, if $xRy$ then $yRy$.

**[Quasi-reflexive](https://en.wikipedia.org/wiki/Quasi-reflexive_relation)**

for all $x, y \in X$, if $xRy$ then $xRx$ and $yRy$. A relation is quasi-reflexive if, and only if, it is both left and right quasi-reflexive.

The previous 6 alternatives are far from being exhaustive; e.g., the binary relation $xRy$ defined by $y = x^{2}$ is neither irreflexive, nor coreflexive, nor reflexive, since it contains the pair $(0, 0)$, and $(2, 4)$, but not $(2, 2)$, respectively. The latter two facts also rule out (any kind of) quasi-reflexivity.

**[Symmetric](wikipedia://en/200459)**

for all $x, y \in X$, if $xRy$ then $yRx$. For example, "is a blood relative of" is a symmetric relation, because $x$ is a blood relative of $y$ if and only if $y$ is a blood relative of $x$.

**[Antisymmetric](wikipedia://en/1176)**

for all $x, y \in X$, if $xRy$ and $yRx$ then $x = y$. For example, ≥ is an antisymmetric relation; so is >, but [vacuously](wikipedia://en/51672) (the condition in the definition is always false).[^o15]

**[Asymmetric](wikipedia://en/1229368)**

for all $x, y \in X$, if $xRy$ then not $yRx$. A relation is asymmetric if and only if it is both antisymmetric and irreflexive.[^o16] For example, > is an asymmetric relation, but ≥ is not.

Again, the previous 3 alternatives are far from being exhaustive; as an example over the natural numbers, the relation $xRy$ defined by $x > 2$ is neither symmetric nor antisymmetric, let alone asymmetric.

**[Transitive](wikipedia://en/200463)**

for all $x, y, z \in X$, if $xRy$ and $yRz$ then $xRz$. A transitive relation is irreflexive if and only if it is asymmetric.[^o17] For example, "is ancestor of" is a transitive relation, while "is parent of" is not.

**[Antitransitive](https://en.wikipedia.org/wiki/Antitransitive)**

for all $x, y, z \in X$, if $xRy$ and $yRz$ then never $xRz$.

**[Co-transitive](https://en.wikipedia.org/wiki/Co-transitivity)**

if the complement of *R* is transitive. That is, for all $x, y, z \in X$, if $xRz$, then $xRy$ or $yRz$. This is used in [pseudo-orders](wikipedia://en/17543768) in constructive mathematics.

**[Quasitransitive](wikipedia://en/6770393)**

for all $x, y, z \in X$, if $xRy$ and $yRz$ but neither $yRx$ nor $zRy$, then $xRz$ but not $zRx$.

**[Transitivity of incomparability](https://en.wikipedia.org/wiki/Transitivity_of_incomparability)**

for all $x, y, z \in X$, if $x$ and $y$ are incomparable with respect to $R$ and if the same is true of $y$ and $z$, then $x$ and $z$ are also incomparable with respect to $R$. This is used in [weak orderings](wikipedia://en/828131).

Again, the previous 5 alternatives are not exhaustive. For example, the relation $xRy$ if ($y = 0$ or $y = x+1$) satisfies none of these properties. On the other hand, the empty relation trivially satisfies all of them.

**[Dense](https://en.wikipedia.org/wiki/Dense_relation)**

for all $x, y \in X$ such that $xRy$, there exists some $z \in X$ such that $xRz$ and $zRy$. This is used in [dense orders](wikipedia://en/6320997).

**[Connected](wikipedia://en/57495962)**

for all $x, y \in X$, if $x \ne y$ then $xRy$ or $yRx$. This property is sometimes called "total", which is distinct from the definitions of "left/right-total" given below.

**[Strongly connected](wikipedia://en/57495962)**

for all $x, y \in X$, $xRy$ or $yRx$. This property, too, is sometimes called "total", which is distinct from the definitions of "left/right-total" given below.

**[Trichotomous](https://en.wikipedia.org/wiki/Trichotomy_%28mathematics%29)**

for all $x, y \in X$, exactly one of $xRy$, $yRx$ or $x = y$ holds. For example, > is a trichotomous relation on the real numbers, while the relation "divides" over the natural numbers is not.[^o18]

**[Right Euclidean](wikipedia://en/11613832) (or just Euclidean)**

for all $x, y, z \in X$, if $xRy$ and $xRz$ then $yRz$. For example, = is a Euclidean relation because if $x = y$ and $x = z$ then $y = z$.

**Left Euclidean**

for all $x, y, z \in X$, if $yRx$ and $zRx$ then $yRz$.

**[Well-founded](wikipedia://en/319712)**

every nonempty subset $S$ of $X$ contains a [minimal element](wikipedia://en/303398) with respect to $R$. Well-foundedness implies the [descending chain condition](https://en.wikipedia.org/wiki/Descending_chain_condition) (that is, no infinite chain $... x_{n}R...Rx_{3}Rx_{2}Rx_{1}$ can exist). If the [axiom of dependent choice](wikipedia://en/441950) is assumed, both conditions are equivalent.[^o19][^o20]

Moreover, all properties of binary relations in general also may apply to homogeneous relations:

**Set-like**

for all $x \in X$, the [class](wikipedia://en/20696) of all $y$ such that $yRx$ is a set. (This makes sense only if relations over proper classes are allowed.)

**Left-unique**

for all $x, z \in X$ and all $y \in Y$, if $xRy$ and $zRy$ then $x = z$.

**Univalent**

for all $x \in X$ and all $y, z \in Y$, if $xRy$ and $xRz$ then $y = z$.[^o21]

**[Total](wikipedia://en/1482218) (also called left-total)**

for all $x \in X$ there exists a $y \in Y$ such that $xRy$. This property is different from the definition of *connected* (also called *total* by some authors).

**Surjective (also called right-total)**

for all $y \in Y$, there exists an $x \in X$ such that *xRy*.

A [preorder](wikipedia://en/23582) is a relation that is reflexive and transitive. A [total preorder](wikipedia://en/828131#Total_preorders), also called linear preorder or weak order, is a relation that is reflexive, transitive, and connected.

A [partial order](wikipedia://en/23572#Formal_definition), also called order, is a relation that is reflexive, antisymmetric, and transitive. A [strict partial order](wikipedia://en/23572#Correspondence_of_strict_and_non-strict_partial_order_relations), also called strict order, is a relation that is irreflexive, antisymmetric, and transitive. A [total order](wikipedia://en/30330), also called linear order, simple order, or chain, is a relation that is reflexive, antisymmetric, transitive and connected.[^o22] A [strict total order](wikipedia://en/30330#Strict_total_order), also called strict linear order, strict simple order, or strict chain, is a relation that is irreflexive, antisymmetric, transitive and connected.

A [partial equivalence relation](wikipedia://en/3450320) is a relation that is symmetric and transitive. An [equivalence relation](wikipedia://en/9259) is a relation that is reflexive, symmetric, and transitive. It is also a relation that is symmetric, transitive, and total, since these properties imply reflexivity.

A univalent relation may also be called a [partial function](wikipedia://en/23577). A (total) [function](wikipedia://en/185427) is a partial function that is left-total. An [injective function](wikipedia://en/45196) (or partial function) is one whose inverse is univalent. A [surjective function](wikipedia://en/27873) is one that is right-total.

## Operations {#Operations}

If *R* is a homogeneous relation over a set *X* then each of the following is a homogeneous relation over *X*:

**[Reflexive closure](wikipedia://en/22603618), *R*<sup>\=</sup>**

Defined as $R^{=} = \{(x, x) | x \in X\} \cup R$ or the smallest reflexive relation over *X* containing *R*. This can be proven to be equal to the [intersection](wikipedia://en/23476429) of all reflexive relations containing *R*.

**Reflexive reduction, *R*<sup>≠</sup>**

Defined as $R^{\ne} = R \backslash \{(x, x) | x \in X$} or the largest [irreflexive](https://en.wikipedia.org/wiki/Irreflexive) relation over *X* contained in *R*.

**[Transitive closure](wikipedia://en/292239), *R*<sup>\+</sup>**

Defined as the smallest transitive relation over *X* containing *R*. This can be seen to be equal to the intersection of all transitive relations containing *R*.

**Reflexive transitive closure, *R*\**

Defined as $R* = (R^{+})^{=}$, the smallest [preorder](wikipedia://en/23582) containing *R*.

**[Reflexive transitive symmetric closure](https://en.wikipedia.org/wiki/Reflexive_transitive_symmetric_closure), *R*<sup>≡</sup>**

Defined as the smallest [equivalence relation](wikipedia://en/9259) over *X* containing *R*.

All operations defined in *Binary relation* also apply to homogeneous relations.

## Enumeration {#Enumeration}

The set of all homogeneous relations $\mathcal{B}(X)$ over a set *X* is the set $2^{X\times X}$, which is a [Boolean algebra](wikipedia://en/3959) augmented with the [involution](wikipedia://en/293450) of mapping of a relation to its [converse relation](wikipedia://en/3941020). Considering [composition of relations](wikipedia://en/7472170) as a [binary operation](wikipedia://en/3948) on $\mathcal{B}(X)$, it forms a [monoid with involution](https://en.wikipedia.org/wiki/Monoid_with_involution) where the identity element is the identity relation.[^o28]

The number of distinct homogeneous relations over an *n*-element set is $2^{n^{2}}$ :

Notes:

- The number of irreflexive relations is the same as that of reflexive relations.
- The number of [strict partial orders](wikipedia://en/23572#Correspondence_of_strict_and_non-strict_partial_order_relations) (irreflexive transitive relations) is the same as that of partial orders.
- The number of strict weak orders is the same as that of total preorders.
- The total orders are the partial orders that are also total preorders. The number of preorders that are neither a partial order nor a total preorder is, therefore, the number of preorders, minus the number of partial orders, minus the number of total preorders, plus the number of total orders: 0, 0, 0, 3, and 85, respectively.
- The number of equivalence relations is the number of [partitions](wikipedia://en/340240), which is the [Bell number](wikipedia://en/201022).

The homogeneous relations can be grouped into pairs (relation, [complement](wikipedia://en/3931#Complement)), except that for $n = 0$ the relation is its own complement. The non-symmetric ones can be grouped into [quadruples](https://en.wikipedia.org/wiki/4-tuple) (relation, complement, inverse, inverse complement).

## Generalizations {#Generalizations}

- A [binary relation](wikipedia://en/3931) in general need not be homogeneous, it is defined to be a subset *R* ⊆ *X* × *Y* for arbitrary sets *X* and *Y*.
- A [finitary relation](wikipedia://en/19509) is a subset *R* ⊆ *X*<sub>1</sub> × ... × *X*<sub>*n*</sub> for some [natural number](wikipedia://en/21474) *n* and arbitrary sets *X*<sub>1</sub>, ..., *X*<sub>*n*</sub>, it is also called an *n*-ary relation.
