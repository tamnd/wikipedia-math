# AES-GCM-SIV

::: {#o1 .subject cue=lead name="AES-GCM-SIV"}

**AES-GCM-SIV** is a [mode of operation](wikipedia://en/160202) for the [Advanced Encryption Standard](wikipedia://en/1260) which provides similar (but slightly worse[^o2]) performance to [Galois/Counter Mode](wikipedia://en/5897139) as well as misuse resistance in the event of the reuse of a [cryptographic nonce](wikipedia://en/6988390). The construction is defined in RFC 8452.[^o3]

:::

## About {#About}

AES-GCM-SIV is designed to preserve both privacy and integrity even if nonces are repeated. To accomplish this, encryption is a function of a nonce, the plaintext message, and optional additional associated data (AAD). In the event a nonce is misused (i.e., used more than once), nothing is revealed except in the case that the same message is encrypted multiple times with the same nonce. When that happens, an attacker is able to observe repeat encryptions, since encryption is a deterministic function of the nonce and message. However, beyond that, no additional information is revealed to the attacker. For this reason, AES-GCM-SIV is an ideal choice in cases that unique nonces cannot be guaranteed, such as multiple servers or network devices encrypting messages under the same key without coordination.

Note, however, that unlike AES-GCM, AES-GCM-SIV cannot be used as a streaming cipher, as it needs to hold the entire message to be encrypted as well as the associated data in memory before encryption/decryption can commence.

## Operation {#Operation}

Like Galois/Counter Mode, AES-GCM-SIV combines the well-known [counter mode](https://en.wikipedia.org/wiki/Block_cipher_modes_of_operation#Counter_%28CTR%29) of encryption with the Galois mode of authentication. The key feature is the use of a synthetic [initialization vector](wikipedia://en/105971) (SIV) which is computed with [Galois field](https://en.wikipedia.org/wiki/Galois_field) multiplication using a construction called POLYVAL (a [little-endian](https://en.wikipedia.org/wiki/Endianness) variant of Galois/Counter Mode's GHASH). POLYVAL is run over the combination of nonce, plaintext, and additional data, so that the IV is different for each combination.

POLYVAL is defined over GF(2<sup>128</sup>) by the polynomial:

$$x^{128} + x^{127} + x^{126} + x^{121} + 1$$

Note that GHASH is defined over the "reverse" polynomial:

$$x^{128} + x^7 + x^2 + x + 1$$

This change provides efficiency benefits on little-endian architectures.[^o6]
