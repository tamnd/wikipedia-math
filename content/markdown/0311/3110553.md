# Statgraphics

::: {#o2 .subject cue=lead name="Statgraphics"}

**Statgraphics** is a [statistics package](https://en.wikipedia.org/wiki/List_of_statistical_packages) that performs and explains basic and advanced [statistical](https://en.wikipedia.org/wiki/Statistical) functions.

:::

## History {#History}

The software was created in 1980 by Dr. Neil W. Polhemus while on the Princeton University School of Engineering and Applied Science faculty as a teaching tool for his statistics students. It was made available to the public in 1982, becoming an early example of data science software designed for use on the PC.

## Software {#Software}

*Image: Shaded trellis plot with contours - September 2023.png.* Trellis plot

The flagship version of Statgraphics is Statgraphics Centurion, a Windows desktop application with capabilities for regression analysis, ANOVA, multivariate statistics, Design of Experiments, statistical process control, life data analysis, machine learning, and data visualization. The data analysis procedures include [descriptive statistics](wikipedia://en/8187), [hypothesis testing](https://en.wikipedia.org/wiki/Hypothesis_testing), [regression analysis](wikipedia://en/826997), [analysis of variance](wikipedia://en/634), [survival analysis](wikipedia://en/419259), [time series analysis](https://en.wikipedia.org/wiki/Time_series_analysis) and forecasting, [sample size determination](wikipedia://en/1776839), multivariate methods, machine learning and [Monte Carlo techniques](wikipedia://en/56098). The SPC menu includes many procedures for [quality assessment](https://en.wikipedia.org/wiki/Quality_assurance), [capability analysis](https://en.wikipedia.org/wiki/Capability_analysis), [control charts](wikipedia://en/435754), [measurement systems analysis](https://en.wikipedia.org/wiki/Measurement_systems_analysis), and acceptance sampling. The program also features a DOE Wizard that creates and analyzes statistically designed experiments.

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

*Image: Control Chart with Zones.png.* Control chart with zones

Statgraphics is frequently used for [Six Sigma](wikipedia://en/222448) process improvement.[^o7] The program has also been used in various health and nutrition-related studies.[^o8][^o9][^o10] The software is heavily used in manufacturing chemicals, pharmaceuticals, medical devices, automobiles, food and consumer goods. It is also widely used in mining,[^o11] environmental studies,[^o12][^o13] and basic R&D.[^o14]

:::

## Distribution {#Distribution}

Statgraphics is distributed by Statgraphics Technologies, Inc., a privately held company based in [The Plains, Virginia](https://en.wikipedia.org/wiki/The_Plains,_Virginia).
