# Majorization

::: {#o1 .subject cue=lead name="Majorization"}

In [mathematics](wikipedia://en/18831), **majorization** is a [preorder](wikipedia://en/23582) on [vectors](wikipedia://en/32370) of [real numbers](https://en.wikipedia.org/wiki/Real_numbers). For two such vectors, $\mathbf{x},\ \mathbf{y} \in \mathbb{R}^n$, we say that $\mathbf{x}$ **weakly majorizes** (or dominates) $\mathbf{y}$ **from below**, commonly denoted $\mathbf{x} \succ_w \mathbf{y},$ when

:::

$\sum_{i=1}^k x_i^{\downarrow} \geq \sum_{i=1}^k y_i^{\downarrow}$ for all $k=1,\,\dots,\,n$,

where $x_i^{\downarrow}$ denotes the $i$<sup>th</sup> largest entry of $\mathbf{x}$. If $\mathbf{x}, \mathbf{y}$ further satisfy $\sum_{i=1}^n x_i = \sum_{i=1}^n y_i$, we say that $\mathbf{x}$ **majorizes** (or dominates) $\mathbf{y}$, commonly denoted $\mathbf{x} \succ \mathbf{y}$.

Both weak majorization and majorization are [partial orders](wikipedia://en/23572) for vectors whose entries are non-decreasing, but only a [preorder](wikipedia://en/23582) for general vectors, since majorization is agnostic to the ordering of the entries in vectors, e.g., the statement $(1,2)\prec (0,3)$ is simply equivalent to $(2,1)\prec (3,0)$.

Specifically, $\mathbf{x} \succ \mathbf{y} \wedge \mathbf{y} \succ \mathbf{x}$ if and only if $\mathbf{x}, \mathbf{y}$ are permutations of each other. Similarly for $\succ_w$.

Majorizing also sometimes refers to entrywise ordering, e.g. the [real-valued function](wikipedia://en/22284647) *f* majorizes the real-valued function *g* when $f(x) \geq g(x)$ for all $x$ in the domain, or other technical definitions, such as majorizing measures in [probability theory](wikipedia://en/23542).[^o2]

## Equivalent conditions {#Equivalent_conditions}

### Geometric definition {#Geometric_definition}

*Image: 2D Majorization Example.png.* Figure 1. 2D majorization example

For $\mathbf{x},\ \mathbf{y} \in \mathbb{R}^n,$ we have $\mathbf{x} \prec \mathbf{y}$ if and only if $\mathbf{x}$ is in the [convex hull](wikipedia://en/40634) of all vectors obtained by permuting the coordinates of $\mathbf{y}$. This is equivalent to saying that $\mathbf{x} = \mathbf{D}\mathbf{y}$ for some [doubly stochastic matrix](wikipedia://en/2906180) $\mathbf{D}$.[^o5] In particular, $\mathbf{x}$ can be written as a [convex combination](wikipedia://en/794534) of $n$ permutations of $\mathbf{y}$.[^o6] In other words, $\mathbf{x}$ is in the [permutahedron](wikipedia://en/12745947) of $\mathbf{y}$.

Figure 1 displays the convex hull in 2D for the vector $\mathbf{y}=(3,\,1)$. Notice that the center of the convex hull, which is an interval in this case, is the vector $\mathbf{x}=(2,\,2)$. This is the "smallest" vector satisfying $\mathbf{x} \prec \mathbf{y}$ for this given vector $\mathbf{y}$. Figure 2 shows the convex hull in 3D. The center of the convex hull, which is a 2D polygon in this case, is the "smallest" vector $\mathbf{x}$ satisfying $\mathbf{x} \prec \mathbf{y}$ for this given vector $\mathbf{y}$.

### Other definitions {#Other_definitions}

Each of the following statements is true if and only if $\mathbf{x}\succ \mathbf{y}$.

- From $\mathbf{x}$ we can produce $\mathbf{y}$ by a finite sequence of "Robin Hood operations" where we replace two elements $x_i$ and $x_j < x_i$ with $x_i-\varepsilon$ and $x_j+\varepsilon$, respectively, for some $\varepsilon \in (0, x_i-x_j)$.[^o5]
- For every convex function $h:\mathbb{R}\to \mathbb{R}$, $\sum_{i=1}^d h(x_i) \geq \sum_{i=1}^d h(y_i)$.[^o5]
  - In fact, a special case suffices: $\sum_i{x_i}=\sum_i{y_i}$ and, for every $t$, $\sum_{i=1}^d \max(0,x_i-t) \geq\sum_{i=1}^d \max(0,y_i-t)$.[^o8]
- For every $t \in \mathbb{R}$, $\sum_{j=1}^d |x_j-t| \geq \sum_{j=1}^d |y_j-t|$.[^o9]
- *Image: Three vector majorization relations.svg.* Three vectors and their concave curves, illustrating $x \succ z, y \succ z, \neg(x \succ y), \neg(y \succ x)$. Each vector $\mathbf{x}$ can be plotted as a concave curve by connecting $(0,0), (1, x_1^{\downarrow}), (2, x_1^{\downarrow}+x_2^{\downarrow}), \dots, (n, x_1^{\downarrow}+x_2^{\downarrow} + \dots +x_n^{\downarrow})$. Then $\mathbf{x}\succ \mathbf{y}$ is equivalent to the curve of $\mathbf{x}$ being higher than that of $\mathbf{y}$.

## Examples {#Examples}

Among non-negative vectors with three components, $(1, 0, 0)$ and permutations of it majorize all other vectors $(p_1, p_2, p_3)$ such that $p_1 + p_2 + p_3 = 1$. For example, $(1, 0, 0) \succ (1/2, 0, 1/2)$. Similarly, $(1/3, 1/3, 1/3)$ is majorized by all other such vectors, so $(1/2, 0, 1/2) \succ (1/3, 1/3, 1/3)$.

This behavior extends to general-length [probability vectors](wikipedia://en/217133): the singleton vector majorizes all other probability vectors, and the uniform distribution is majorized by all probability vectors.

:::

## Schur convexity {#Schur_convexity}

A function $f:\mathbb{R}^n \to \mathbb{R}$ is said to be [Schur convex](wikipedia://en/3897244) when $\mathbf{x} \succ \mathbf{y}$ implies $f(\mathbf{x}) \geq f(\mathbf{y})$. Hence, Schur-convex functions translate the ordering of vectors to a standard ordering in $\mathbb{R}$. Similarly, $f(\mathbf{x})$ is **Schur concave** when $\mathbf{x} \succ \mathbf{y}$ implies $f(\mathbf{x}) \leq f(\mathbf{y}).$

An example of a Schur-convex function is the max function, $\max(\mathbf{x})=x_{1}^{\downarrow}$. Schur convex functions are necessarily symmetric that the entries of it argument can be switched without modifying the value of the function. Therefore, linear functions, which are convex, are not Schur-convex unless they are symmetric. If a function is symmetric and convex, then it is Schur-convex.

## Generalizations {#Generalizations}

Majorization can be generalized to the [Lorenz ordering](wikipedia://en/18135), a partial order on [distribution functions](wikipedia://en/5793). For example, a [wealth distribution](https://en.wikipedia.org/wiki/Income_distribution) is Lorenz-greater than another if its [Lorenz curve](wikipedia://en/18135) lies below the other. As such, a Lorenz-greater wealth distribution has a higher [Gini coefficient](wikipedia://en/12883), and has more [income disparity](https://en.wikipedia.org/wiki/Income_inequality).[^o15]

The majorization preorder can be naturally extended to [density matrices](wikipedia://en/62844) in the context of [quantum information](wikipedia://en/25274).[^o9][^o16] In particular, $\rho\succ\rho'$ exactly when $\mathrm{spec}[\rho]\succ\mathrm{spec}[\rho']$ (where $\mathrm{spec}$ denotes the state's [spectrum](wikipedia://en/206136)).

Similarly, one can say a [Hermitian operator](https://en.wikipedia.org/wiki/Hermitian_operator), $\mathbf{H}$, majorizes another, $\mathbf{M}$, if the set of eigenvalues of $\mathbf{H}$ majorizes that of $\mathbf{M}$.
