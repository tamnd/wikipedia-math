# CIPHERUNICORN-E

::: {#o1 .subject cue=lead name="CIPHERUNICORN-E"}

In [cryptography](wikipedia://en/18934432), **CIPHERUNICORN-E** is a [block cipher](wikipedia://en/4594) created by [NEC](https://en.wikipedia.org/wiki/NEC) in 1998. It was among the cryptographic techniques recommended for Japanese government use by [CRYPTREC](wikipedia://en/549159) in 2003. However, it has been dropped to "candidate" level by the CRYPTREC revision of 2013.

:::

The algorithm has a 16-round modified [Feistel network](wikipedia://en/352709) structure, with an additional key-dependent mixing function after every 2 rounds. The [block size](wikipedia://en/294065) is 64 bits, and the [key size](wikipedia://en/5749) 128 bits. The round function is fairly complicated, split into two nearly parallel computations.

The first part (called the *main stream* by the designers) consists of [XORs](https://en.wikipedia.org/wiki/XOR) and [S-box](https://en.wikipedia.org/wiki/Substitution_box) lookups, with a few choices influenced by the second part. This second function (called *temporary key generation*) uses more XORs and two operations which are equivalent to [modular multiplications](wikipedia://en/20087). Subkeys are added at various stages of both parts of the round function. There are 4 S-boxes in all, each with 8-bit inputs and outputs.

In 2000, NEC used the same high-level structure, with more elaborate components, to design the [CIPHERUNICORN-A](wikipedia://en/9036507) cipher.

CIPHERUNICORN-E's [key schedule](wikipedia://en/609603) uses a nested Feistel network, based on some of the same building blocks as the cipher itself.

The complexity of CIPHERUNICORN-E's round function has made it difficult to analyze. Some limited analysis has been done on simplified variants, showing that they are likely resistant to both [differential](wikipedia://en/8536) and [linear cryptanalysis](wikipedia://en/59469).
