# System U

::: {#o1 .subject cue=lead name="System U"}

In [mathematical logic](wikipedia://en/19636), **System U** and **System U<sup>−</sup>** are [pure type systems](wikipedia://en/17870536), i.e. special forms of a [typed lambda calculus](wikipedia://en/366208) with an arbitrary number of [sorts](wikipedia://en/4055928#Many-sorted_structures), axioms and rules (or dependencies between the sorts).

:::

System U was proved inconsistent by [Jean-Yves Girard](wikipedia://en/579673) in 1972[^o2] (and the question of consistency of System U<sup>−</sup> was formulated). This result led to the realization that [Martin-Löf](wikipedia://en/1925764)'s original [1971 type theory](wikipedia://en/345023#Martin-Löf_type_theories) was inconsistent, as it allowed the same "type in type" behaviour that Girard's paradox exploits.

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

System U is defined[^o5] as a pure type system with

- three [sorts](wikipedia://en/8169758) $\{\ast, \square, \triangle\}$;
- two axioms $\{\ast:\square, \square:\triangle\}$; and
- five rules $\{(\ast,\ast), (\square,\ast), (\square,\square), (\triangle,\ast), (\triangle,\square)\}$.

System U<sup>−</sup> is defined the same with the exception of the $(\triangle, \ast)$ rule.

The sorts $\ast$ and $\square$ are conventionally called “type” and “[kind](wikipedia://en/20627460)”, respectively; the sort $\triangle$ doesn't have a specific name. The two axioms describe the containment of types in kinds ($\ast:\square$) and kinds in $\triangle$ ($\square:\triangle$). Intuitively, the sorts describe a hierarchy in the *nature* of the terms.

1. All values have a *type*, such as a base type (*e.g.* $b : \mathrm{Bool}$ is read as “$b$ is a boolean”) or a (dependent) function type (*e.g.* $f : \mathrm{Nat} \to \mathrm{Bool}$ is read as “$f$ is a function from natural numbers to booleans”).
1. $\ast$ is the sort of all such types ($t : \ast$ is read as “$t$ is a type”). From $\ast$ we can build more terms, such as $\ast \to \ast$ which is the *kind* of unary type-level operators (*e.g.* $\mathrm{List} : \ast \to \ast$ is read as “$\mathrm{List}$ is a function from types to types”, that is, a polymorphic type). The rules restrict how we can form new kinds.
1. $\square$ is the sort of all such kinds ($k : \square$ is read as “$k$ is a kind”). Similarly we can build related terms, according to what the rules allow.
1. $\triangle$ is the sort of all such terms.

The rules govern the dependencies between the sorts: $(\ast,\ast)$ says that values may depend on values ([functions](https://en.wikipedia.org/wiki/First-class_function)), $(\square,\ast)$ allows values to depend on types ([polymorphism](https://en.wikipedia.org/wiki/Parametric_polymorphism)), $(\square,\square)$ allows types to depend on types ([type operators](wikipedia://en/24047271)), and so on.

:::

::: {#o7 .statement cue=named-heading name="Girard's paradox"}

## Girard's paradox {#Girard's_paradox}

The definitions of System U and U<sup>−</sup> allow the assignment of [polymorphic](https://en.wikipedia.org/wiki/Parametric_polymorphism) [kinds](wikipedia://en/20627460) to *generic constructors* in analogy to polymorphic types of terms in classical polymorphic lambda calculi, such as [System F](wikipedia://en/767637). An example of such a generic constructor might bep. 353 (where *k* denotes a kind variable)

$$\lambda k^\square \lambda\alpha^{k \to k} \lambda\beta^k\!. \alpha (\alpha \beta) \;:\; \Pi k : \square.((k \to k) \to k \to k).$$

This mechanism is sufficient to construct a term with the type $(\forall p:\ast, p)$ (equivalent to the type $\bot$), which implies that every type is [inhabited](https://en.wikipedia.org/wiki/Type_inhabitation). By the [Curry–Howard correspondence](wikipedia://en/254299), this is equivalent to all logical propositions being provable, which makes the system inconsistent.

Girard's paradox is the [type-theoretic](wikipedia://en/40282) analogue of the [Burali-Forti paradox](wikipedia://en/51653) in [set theory](wikipedia://en/4944).[^o8]
