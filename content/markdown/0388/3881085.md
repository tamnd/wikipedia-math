# SSLeay

::: {#o2 .subject cue=lead name="SSLeay"}

**SSLeay** is an open-source [SSL](https://en.wikipedia.org/wiki/Secure_Sockets_Layer) implementation. It was developed by Eric Andrew Young[^o3] and Tim J. Hudson as an SSL 3.0 implementation using [RC2](wikipedia://en/632592) and [RC4](wikipedia://en/25831) encryption.[^o4] The recommended pronunciation is to say each letter, S-S-L-E-A-Y; the "eay" comes from the initials of author Eric A. Young.[^o5] SSLeay also included an implementation of [DES](wikipedia://en/7978) from earlier work by Eric Young which was believed to be the first open-source implementation of DES. Development of SSLeay unofficially mostly ended, and volunteers forked the project under the [OpenSSL](wikipedia://en/438819) banner around December 1998, when Hudson and Young both began working for [RSA Security](wikipedia://en/301240) in Australia.

:::

## SSLeay {#SSLeay}

SSLeay was developed by Eric A. Young, starting in 1995. Windows support was added by Tim J. Hudson. Patches to open source applications to support SSL using SSLeay were produced by Tim Hudson. Development by Young and Hudson ceased in 1998. The SSLeay library and codebase is licensed under its own SSLeay License, a form of [free software license](https://en.wikipedia.org/wiki/Free_software_license).[^o4][^o5][^o7] The SSLeay License is a BSD-style [open-source license](https://en.wikipedia.org/wiki/Open-source_license), almost identical to a four-clause [BSD license](https://en.wikipedia.org/wiki/BSD_license).[^o8]

SSLeay supports [X.509v](https://en.wikipedia.org/wiki/X.509)3 certificates and [PKCS](wikipedia://en/616418)#10 certificate requests.[^o9] It supports SSL2 and SSL3.[^o10] Also supported is [TLSv](wikipedia://en/187813)1.[^o11]

The first secure FTP implementation was created under BSD using SSLeay by Tim Hudson.[^o3]

The first open source Certifying Authority implementation was created with CGI scripts using SSLeay by Clifford Heath.

## Forks {#Forks}

[OpenSSL](wikipedia://en/438819) is a fork and successor project to SSLeay and has a similar interface to it.[^o5][^o13] After Young and Hudson joined RSA Corporation, volunteers forked SSLeay and continued development as OpenSSL.[^o4]

[BSAFE SSL-C](https://en.wikipedia.org/wiki/BSAFE_SSL-C) is a fork of SSLeay developed by Eric A. Young and Tim J. Hudson for RSA Corporation.[^o4][^o14]
