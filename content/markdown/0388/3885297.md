# Comprehension (logic)

::: {#o1 .subject cue=lead name="Comprehension"}

In [logic](wikipedia://en/46426065), the **comprehension**[^o2] of an object is the totality of [intensions](wikipedia://en/14570), that is, attributes, characters, marks, properties, or qualities, that the object possesses, or else the totality of intensions that are [pertinent](wikipedia://en/442688) to the context of a given discussion. This is the correct technical term for the whole collection of intensions of an object, but it is common in less technical usage to see 'intension' used for both the composite and the primitive ideas.

:::
