# Exact C\*-algebra

::: {#o1 .subject cue=lead name="Exact C*-algebra"}

In mathematics, an **exact C\*-algebra** is a [C\*-algebra](wikipedia://en/7184) that preserves [exact sequences](wikipedia://en/138215) under the [minimum tensor product](https://en.wikipedia.org/wiki/Minimum_tensor_product).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [C\*-algebra](wikipedia://en/7184) *E* is exact if, for any [short exact sequence](https://en.wikipedia.org/wiki/Short_exact_sequence),

$$0 \;\to\; A \;\xrightarrow{{} \atop f}\; B \;\xrightarrow{g}\; C \;\to\; 0$$

the sequence

$$0\;\to\; A \otimes_\min E\;\xrightarrow{{} \atop {f\otimes \operatorname{id}}}\; B\otimes_\min E \;\xrightarrow{{} \atop {g\otimes \operatorname{id}}}\; C\otimes_\min E \;\to\; 0,$$

where ⊗<sub>min</sub> denotes the minimum [tensor product](wikipedia://en/30844), is also exact.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Every [nuclear C\*-algebra](wikipedia://en/25351068) is exact.
- Every sub-C\*-algebra and every quotient of an exact C\*-algebra is exact. An extension of exact C\*-algebras is not exact in general.
- It follows that every sub-C\*-algebra of a [nuclear C\*-algebra](wikipedia://en/25351068) is exact.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

Exact C\*-algebras have the following equivalent characterizations:

- A C\*-algebra *A* is exact if and only if *A* is nuclearly embeddable into *B*(*H*), the C\*-algebra of all bounded operators on a Hilbert space *H*.
- A C\*-algebra is exact if and only if every separable sub-C\*-algebra is exact.
- A separable C\*-algebra *A* is exact if and only if it is isomorphic to a subalgebra of the [Cuntz algebra](wikipedia://en/4463325) $\mathcal{O}_2$.

:::
