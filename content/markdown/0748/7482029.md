# Completely distributive lattice

::: {#o1 .subject cue=lead name="Completely distributive lattice"}

In the mathematical area of [order theory](wikipedia://en/361924), a **completely distributive lattice** is a [complete lattice](wikipedia://en/44777) in which arbitrary [joins](https://en.wikipedia.org/wiki/Join_%28lattice_theory%29) [distribute](wikipedia://en/616019) over arbitrary [meets](https://en.wikipedia.org/wiki/Meet_%28lattice_theory%29).

:::

Formally, a complete lattice *L* is said to be **completely distributive** if, for any doubly indexed family {*x*<sub>*j*,*k*</sub> | *j* in *J*, *k* in *K*<sub>*j*</sub>} of *L*, we have

$$\bigwedge_{j\in J}\bigvee_{k\in K_j} x_{j,k} = \bigvee_{f\in F}\bigwedge_{j\in J} x_{j,f(j)}$$

where *F* is the set of [choice functions](wikipedia://en/1432664) *f* choosing for each index *j* of *J* some index *f*(*j*) in *K*<sub>*j*</sub>.[^o2]

Complete distributivity is a self-dual property, i.e. [dualizing](wikipedia://en/600618) the above statement yields the same class of complete lattices.[^o2]

## Alternative characterizations {#Alternative_characterizations}

Various different characterizations exist. For example, the following is an equivalent law that avoids the use of choice functions. For any set *S* of sets, we define the set *S*<sup>\#</sup> to be the set of all subsets *X* of the complete lattice that have non-empty intersection with all members of *S*. We then can define complete distributivity via the statement

$$\begin{aligned}\bigwedge \{ \bigvee Y \mid Y\in S\} = \bigvee\{ \bigwedge Z \mid Z\in S^\# \}\end{aligned}$$

The operator ( )<sup>\#</sup> might be called the **crosscut operator**. This version of complete distributivity only implies the original notion when admitting the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice).

## Properties {#Properties}

In addition, it is known that the following statements are equivalent for any complete lattice *L*:[^o6]

- *L* is completely distributive.
- *L* can be embedded into a direct product of chains \[0,1\] by an [order embedding](wikipedia://en/762203) that preserves arbitrary meets and joins.
- Both *L* and its dual order *L*<sup>op</sup> are [distributive](wikipedia://en/310883) [continuous posets](wikipedia://en/71369165).[^o7]

Direct products of \[0,1\], i.e. sets of all functions from some set *X* to \[0,1\] ordered [pointwise](https://en.wikipedia.org/wiki/Pointwise_order), are also called *cubes*.

:::

## Free completely distributive lattices {#Free_completely_distributive_lattices}

Every [poset](wikipedia://en/23572) *C* can be [completed](wikipedia://en/44777#Completion) in a completely distributive lattice.

A completely distributive lattice *L* is called the **free completely distributive lattice over a poset *C*** if and only if there is an [order embedding](wikipedia://en/762203) $\phi:C\rightarrow L$ such that for every completely distributive lattice *M* and [monotonic function](wikipedia://en/48260) $f:C\rightarrow M$, there is a unique [complete homomorphism](wikipedia://en/44777#Morphisms_of_complete_lattices) $f^*_\phi:L\rightarrow M$ satisfying $f=f^*_\phi\circ\phi$. For every poset *C*, the free completely distributive lattice over a poset *C* exists and is unique up to isomorphism.[^o9]

This is an instance of the concept of [free object](wikipedia://en/333835). Since a set *X* can be considered as a poset with the discrete order, the above result guarantees the existence of the free completely distributive lattice over the set *X*.

::: {#o11 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [unit interval](wikipedia://en/49324) \[0,1\], ordered in the natural way, is a completely distributive lattice.[^o12]
  - More generally, any [complete chain](wikipedia://en/30330#Completeness) is a completely distributive lattice.[^o13]
- The [power set](wikipedia://en/23799) lattice $(\mathcal{P}(X),\subseteq)$ for any set *X* is a completely distributive lattice.[^o2]
- For every poset *C*, there is a *free completely distributive lattice over C*.[^o9] See the section on [Free completely distributive lattices](wikipedia://en/7482029#Free_completely_distributive_lattices) above.

:::
