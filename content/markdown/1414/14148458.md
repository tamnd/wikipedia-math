# Paper key

::: {#o1 .subject cue=lead name="Paper key"}

A **paper key** is a [machine-readable](https://en.wikipedia.org/wiki/Machine-readable_medium) print of a [cryptographic](https://en.wikipedia.org/wiki/Cryptographic) key. The printed key can be used to decrypt data, e.g. archives or [backup](https://en.wikipedia.org/wiki/Backup) data. A paper key can be the result of an [offline private key protocol](wikipedia://en/14242021). The offline private key can also function as a token in [two-factor authentication](https://en.wikipedia.org/wiki/Two-factor_authentication).

:::

The idea is that a digital key to decrypt and recover sensitive or personal data should have long-term durability and not be stored on any computer or network. The length of secure cryptographic keys restricts memorization, so the secret key takes the form of a 2D [barcode](https://en.wikipedia.org/wiki/Barcode), a machine-readable print. Early implementations of a paper key by the company Safeberg use a [Data Matrix](https://en.wikipedia.org/wiki/Data_Matrix) [barcode](https://en.wikipedia.org/wiki/Barcode)[^o2][^o3] or human-readable [base 16](https://en.wikipedia.org/wiki/Base_16) digits.[^o4]

The user stores the printed key in a secure location. To avoid abuse, the key can only be used in combination with a ‘normal’ password.

The user can extract the key by creating a [digital photo](https://en.wikipedia.org/wiki/Digital_photo) or scan of their paper key and feeding it to cryptographic software that extracts the key to decrypt the data.
