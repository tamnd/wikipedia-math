# Gretl

::: {#o1 .subject cue=lead name="Gretl"}

**gretl** is [computer software](https://en.wikipedia.org/wiki/Computer_software), an [open-source](https://en.wikipedia.org/wiki/Open-source_software) [statistical package](https://en.wikipedia.org/wiki/Statistical_package), mainly for [econometrics](wikipedia://en/10390). The name is an acronym for [*G*nu](https://en.wikipedia.org/wiki/GNU_General_Public_License) [*R*egression](wikipedia://en/826997), *E*conometrics and [*T*ime-series](wikipedia://en/406624) *L*ibrary.

:::

It has both a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) (GUI) and a [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface). It is written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29), uses [GTK+](https://en.wikipedia.org/wiki/GTK+) as [widget toolkit](https://en.wikipedia.org/wiki/Widget_toolkit) for creating its GUI, and calls [gnuplot](https://en.wikipedia.org/wiki/Gnuplot) for generating graphs. The native scripting language of gretl is known as hansl (see below); it can also be used together with [TRAMO/SEATS](https://en.wikipedia.org/wiki/TRAMO), [R](wikipedia://en/376707), [Stata](wikipedia://en/1809002), [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [Octave](wikipedia://en/48707), [Ox](https://en.wikipedia.org/wiki/Ox_%28programming_language%29) and [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29).

It includes natively all the basic statistical techniques employed in contemporary Econometrics and Time-Series Analysis. Additional estimators and tests are available via user-contributed *function packages*, which are written in hansl.[^o3] Output from gretl can be exported as [LaTeX](https://en.wikipedia.org/wiki/LaTeX) files.

gretl is available in English, Albanian, Basque, Bulgarian, Catalan, Chinese, Czech, French, Galician, German, Greek, Italian, Polish, European and Brazilian Portuguese, Romanian, Russian, Spanish, Turkish and Ukrainian. Gretl has been reviewed several times in the *[Journal of Applied Econometrics](wikipedia://en/14274642)*,[^o4][^o5][^o6] and later in the *[Australian Economic Review](https://en.wikipedia.org/wiki/Australian_Economic_Review)*.[^o7]

A review also appeared in the *[Journal of Statistical Software](wikipedia://en/2179145)*[^o8] in 2008. Since then, the journal has published several articles in which gretl is used to implement various statistical techniques.

## Supported data formats {#Supported_data_formats}

gretl offers its own fully documented, [XML](https://en.wikipedia.org/wiki/XML)-based data format.

It can also import [ASCII](https://en.wikipedia.org/wiki/ASCII), [CSV](https://en.wikipedia.org/wiki/CSV_%28file_format%29), [databank](https://en.wikipedia.org/wiki/Databank_format), [EViews](wikipedia://en/3933682), [Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [Gnumeric](https://en.wikipedia.org/wiki/Gnumeric), [GNU Octave](wikipedia://en/48707), [JMulTi](wikipedia://en/6237309), [OpenDocument](https://en.wikipedia.org/wiki/OpenDocument) spreadsheets, [PcGive](https://en.wikipedia.org/wiki/PcGive), [RATS 4](https://en.wikipedia.org/wiki/Regression_Analysis_of_Time_Series), [SAS](wikipedia://en/990677) xport, [SPSS](wikipedia://en/179088), and [Stata](wikipedia://en/1809002) files. Since version 2020c, the [GeoJSON](https://en.wikipedia.org/wiki/GeoJSON) and [Shapefile](https://en.wikipedia.org/wiki/Shapefile) formats are also supported, for thematic map creation.

It can export to [Stata](wikipedia://en/1809002), [GNU Octave](wikipedia://en/48707), [R](wikipedia://en/376707), [CSV](https://en.wikipedia.org/wiki/CSV_%28file_format%29), [JMulTi](wikipedia://en/6237309), and [PcGive](https://en.wikipedia.org/wiki/PcGive) file formats.

## hansl {#hansl}

Gretl has its own [scripting language](https://en.wikipedia.org/wiki/Scripting_language), called *hansl* (which is a [recursive acronym](https://en.wikipedia.org/wiki/Recursive_acronym) for Hansl's A Neat Scripting Language).

Hansl is a Turing-complete, interpreted programming language, featuring loops, conditionals, user-defined functions and complex data structures.[^o11] It can be considered a [domain-specific language](https://en.wikipedia.org/wiki/Domain-specific_language) for econometrics.[^o12] Like other scientifically oriented programming languages, such as [MATLAB](wikipedia://en/20412) and [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), matrices are supported natively as a primitive variable type.

A simple example of hansl:

matrix A = {1, 2 ; 3, 4} matrix B = [inv](wikipedia://en/217122)(A) matrix C = A\*B

print A B C

loop i=-3..3 [printf](https://en.wikipedia.org/wiki/Printf) "[Phi](https://en.wikipedia.org/wiki/Phi)(%d) = %7.3f\\n", i, [cdf](wikipedia://en/5793)(N, i) endloop

Running the above code produces

```
A (2 x 2)

  1   2
  3   4

B (2 x 2)

    -2      1
   1.5   -0.5

C (2 x 2)

      1.0000       0.0000
  8.8818e-16       1.0000

Phi(-3) =   0.001
Phi(-2) =   0.023
Phi(-1) =   0.159
Phi( 0) =   0.500
Phi( 1) =   0.841
Phi( 2) =   0.977
Phi( 3) =   0.999
```

## Random Number Generation {#Random_Number_Generation}

Random Number Generation (RNG) in *gretl* has been examined and tested in Yalta & Schreiber (2012).[^o14] The authors conclude "Our results show that the RNG related procedures in *gretl* are implemented soundly and perform well in the three crush test suites of the TestU01".

## Gretl as a teaching tool {#Gretl_as_a_teaching_tool}

Due to its libre nature and the breadth of econometric techniques it contains, gretl is widely used for teaching econometrics, from the undergraduate level onwards. Datasets in gretl format are available for several popular textbooks.

The following is a list of textbooks that use gretl as their software of choice:

- Dougherty, Christopher *Introduction to Econometrics* (Oxford University Press)
- Kufel, Tadeusz *Ekonometria* (Wydawnictwo Naukowe PWN); in Polish (Russian version also available)
- Kivedal, Bjørnar *Applied Statistics and Econometrics* (Springer)
- Bismans, Francis J. and Damette, Olivier *Dynamic Econometrics. Models and Applications* (Springer)

In addition, a free supplement[^o16] to Hill, Griffiths and Lim *Principles of Econometrics* (Wiley) is available.
