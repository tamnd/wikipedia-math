# Coanalytic set

::: {#o1 .subject cue=lead name="Coanalytic set"}

In [descriptive set theory](wikipedia://en/396619), a **coanalytic set** is a [set](wikipedia://en/26691) (typically a subset of a [Polish space](wikipedia://en/396622)) that is the [complement](wikipedia://en/54347) of an [analytic set](wikipedia://en/634261).[^n1] In the [projective hierarchy](wikipedia://en/1236542), coanalytic sets correspond to $\mathbf{\Pi}^1_1$ sets.

:::
