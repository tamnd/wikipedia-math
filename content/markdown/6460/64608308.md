# Strejc method

::: {#o1 .subject cue=lead name="Strejc method"}

The **Strejc system identification method** allows the estimate of the [transfer function](wikipedia://en/31146) of a non-periodic, [black box](https://en.wikipedia.org/wiki/Black_box)-type system based on its [step response](wikipedia://en/545863) and is widely used in all branches of industrial and mechanical engineering.

:::

It allows specifically to estimate the order *n* of the studied system, its time constant and its delay.

To use the Strejc method, it is necessary to apply a step signal to the system and record its t<sub>u</sub> and t<sub>g</sub> parameters by observing the inflection point of the response curve. These parameters are then compared with the ones in the numeric table to estimate what order approximates better the system's behaviour and then find the time constant t with the second column (using the appropriate order).
