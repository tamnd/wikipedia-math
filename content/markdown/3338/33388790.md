# Burkill integral

::: {#o1 .subject cue=lead name="Burkill integral"}

In mathematics, the **Burkill integral** is an integral introduced by (txt) for calculating areas. It is a special case of the [Kolmogorov integral](wikipedia://en/33389039).

:::
