# List of formal systems

::: {#o1 .subject cue=lead name="List of formal systems"}

This is a list of [formal systems](wikipedia://en/396102), also known as logical calculi.

:::

## Mathematical {#Mathematical}

::: {#o3 .entry cue=list-entry name="Functional calculus"}

- [Functional calculus](wikipedia://en/965348), a way to apply various types of functions to operators

:::

::: {#o4 .entry cue=list-entry name="Matrix calculus"}

- [Matrix calculus](wikipedia://en/1765852), a specialized notation for multivariable calculus over spaces of matrices

:::

::: {#o5 .entry cue=list-entry name="Umbral calculus"}

- [Umbral calculus](wikipedia://en/214124), the combinatorics of certain operations on polynomials

:::

::: {#o6 .entry cue=list-entry name="Vector calculus"}

- [Vector calculus](wikipedia://en/32640) (also called vector analysis), comprising specialized notations for multivariable analysis of vectors in an inner-product space

:::

### Logical {#Logical}

::: {#o8 .entry cue=list-entry name="Predicate calculus"}

- [Predicate calculus](https://en.wikipedia.org/wiki/Predicate_calculus), specifies the rules of inference governing the logic of predicates

:::

::: {#o9 .entry cue=list-entry name="Propositional calculus"}

- [Propositional calculus](https://en.wikipedia.org/wiki/Propositional_calculus), specifies the rules of inference governing the logic of propositions

:::

### In [theoretical computer science](wikipedia://en/323392) ([Formal language](wikipedia://en/10939)) {#In_theoretical_computer_science_(Formal_language)}

::: {#o11 .entry cue=list-entry name="Modal μ-calculus"}

- [Modal μ-calculus](wikipedia://en/6158953), a common temporal logic used by formal verification methods such as model checking

:::

::: {#o12 .entry cue=list-entry name="Lambda calculus"}

- [Lambda calculus](wikipedia://en/18203), a formulation of the theory of reflexive functions that has deep connections to computational theory

:::

  - [Kappa calculus](wikipedia://en/33498023), a reformulation of the first-order fragment of typed lambda calculus
  - Rho calculus, introduced as a general means to uniformly integrate rewriting into lambda calculus

::: {#o13 .entry cue=list-entry name="Process calculus"}

- [Process calculus](wikipedia://en/853240), a set of approaches to formulating formal models of concurrent systems

:::

  - [Ambient calculus](https://en.wikipedia.org/wiki/Ambient_calculus), a family of models for concurrent systems based on the concept of agent mobility
  - [Join calculus](https://en.wikipedia.org/wiki/Join_calculus), a theoretical model for the design of distributed programming languages
  - [π-calculus](wikipedia://en/420373), a formulation of the theory of concurrent, communicating processes, that was invented by [Robin Milner](https://en.wikipedia.org/wiki/Robin_Milner)

::: {#o14 .entry cue=list-entry name="Relational calculus"}

- [Relational calculus](https://en.wikipedia.org/wiki/Relational_calculus), a calculus for the relational data model

:::

  - [Domain relational calculus](https://en.wikipedia.org/wiki/Domain_relational_calculus)
  - [Tuple calculus](https://en.wikipedia.org/wiki/Tuple_calculus), inspired the SQL language

::: {#o15 .entry cue=list-entry name="Refinement calculus"}

- [Refinement calculus](https://en.wikipedia.org/wiki/Refinement_calculus), a way of refining models of programs into efficient programs

:::
