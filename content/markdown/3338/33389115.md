# Hellinger integral

::: {#o1 .subject cue=lead name="Hellinger integral"}

In mathematics, the **Hellinger integral** is an integral introduced by (txt) that is a special case of the [Kolmogorov integral](wikipedia://en/33389039). It is used to define the [Hellinger distance](wikipedia://en/13035709) in probability theory.

:::
