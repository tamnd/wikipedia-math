# Zeta function (operator)

::: {#o1 .subject cue=lead name="Zeta function"}

The **[zeta function](https://en.wikipedia.org/wiki/Zeta_function_%28disambiguation%29) of a mathematical [operator](wikipedia://en/22213)** $\mathcal O$ is a function defined as

:::

$$\zeta_{\mathcal O}(s) = \operatorname{tr} \; \mathcal O^{-s}$$

for those values of *s* where this expression exists, and as an [analytic continuation](wikipedia://en/80842) of this function for other values of *s*. Here "tr" denotes a functional [trace](wikipedia://en/43270).

The zeta function may also be expressible as a **spectral zeta function**[^o2] in terms of the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalues) $\lambda_i$ of the operator $\mathcal O$ by

$$\zeta_{\mathcal O}(s) = \sum_{i} \lambda_i^{-s}.$$

It is used in giving a rigorous definition to the [functional determinant](wikipedia://en/2703380) of an operator, which is given by

$$\det \mathcal O := e^{-\zeta'_{\mathcal O}(0)} \;.$$

The [Minakshisundaram–Pleijel zeta function](wikipedia://en/4744575) is an example, when the operator is the [Laplacian](wikipedia://en/15659323) of a compact [Riemannian manifold](wikipedia://en/144652).

One of the most important motivations for [Arakelov theory](wikipedia://en/16364229) is the zeta functions for operators with the method of [heat kernels](wikipedia://en/3904336) generalized algebro-geometrically.[^o3]
