# Dickman function

::: {#o1 .subject cue=lead name="Dickman function"}

*Image: Mplwp Dickman function log.svg.* The Dickman–de Bruijn function *ρ*(*u*) plotted on a logarithmic scale. The horizontal axis is the argument *u*, and the vertical axis is the value of the function. The graph nearly makes a downward line on the logarithmic scale, demonstrating that the logarithm of the function is [quasilinear](https://en.wikipedia.org/wiki/Linearithmic_function).

In [analytic number theory](wikipedia://en/251513), the **Dickman function** or **Dickman–de Bruijn function** *ρ* is a [special function](https://en.wikipedia.org/wiki/Special_function) used to estimate the proportion of [smooth numbers](wikipedia://en/1035039) up to a given bound. It was first studied by actuary Karl Dickman, who defined it in his only mathematical publication.[^o2] It was later studied by the Dutch mathematician [Nicolaas Govert de Bruijn](wikipedia://en/3166399).[^o3][^o4]

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Dickman–de Bruijn function $\rho(u)$ is a [continuous function](wikipedia://en/6122) that satisfies the [delay differential equation](wikipedia://en/3941333)

$$u\rho'(u) + \rho(u-1) = 0\,$$

with initial conditions $\rho(u) = 1$ for 0 ≤ *u* ≤ 1.

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Dickman proved that, when $a$ is fixed, we have

$$\Psi(x, x^{1/a})\sim x\rho(a)\,$$

where $\Psi(x,y)$ is the number of *y*-[smooth](wikipedia://en/1035039) (or *y*-[friable](https://en.wikipedia.org/wiki/Friable_number)) integers below *x*. Equivalently, the number of $B$-smooth numbers less than $N$ is about

$$\Psi(N,B) \approx N \rho\left(\frac{\log N}{\log B}\right).$$

Ramaswami later gave a rigorous proof that for fixed *a*, $\Psi(x,x^{1/a})$ was asymptotic to $x \rho(a)$, with the [error bound](https://en.wikipedia.org/wiki/Error_bound)

$$\Psi(x,x^{1/a})=x\rho(a)+O(x/\log x)$$

in [big O notation](wikipedia://en/44578).[^o9]

Knuth gives a proof for a narrowed bound:

$$\Psi(x,x^{1/a})=x\rho(a)+(1-\gamma)\rho(a-1)(x/\log x)+O(x/{(\log x)}^2)$$

where γ is [Euler's constant](wikipedia://en/148594).[^o20]

:::

::: {#o11 .application cue=heading name="Applications"}

## Applications {#Applications}

*Image: Dickman\_prob\_factor\_size.svg.* The Dickman–de Bruijn used to calculate the probability that the largest and 2nd largest factor of x is less than x^a

The main purpose of the Dickman–de Bruijn function is to estimate the frequency of smooth numbers at a given size. This can be used to optimize various number-theoretical algorithms such as [P–1 factoring](https://en.wikipedia.org/wiki/Pollard_P-1#How_to_choose_B?) and can be useful of its own right.[^o20]

It can be shown that[^o12]

$$\Psi(x,y)=xu^{O(-u)}$$

which is related to the estimate $\rho(u)\approx u^{-u}$ below.

The [Golomb–Dickman constant](wikipedia://en/12676307) has an alternate definition in terms of the Dickman–de Bruijn function.

:::

## Estimation {#Estimation}

A first approximation might be $\rho(u)\approx u^{-u}.\,$ A better estimate is[^o18]

$$\rho(u)\sim \frac 1 {\xi\sqrt{2\pi u}} \cdot \exp(-u\xi+\operatorname{Ei}(\xi))$$

where Ei is the [exponential integral](wikipedia://en/648614) and *ξ* is the positive root of

$$e^\xi-1=u\xi.\,$$

A simple upper bound is $\rho(x)\le1/x!.$

::: {#o16 .definition kind=definition/construction cue=heading name="Computation"}

## Computation {#Computation}

For each interval \[*n* − 1, *n*\] with *n* an [integer](wikipedia://en/14563), there is an [analytic function](wikipedia://en/61478) $\rho_n$ such that $\rho_n(u)=\rho(u)$. For 0 ≤ *u* ≤ 1, $\rho(u) = 1$. For 1 ≤ *u* ≤ 2, $\rho(u) = 1-\log u$. For 2 ≤ *u* ≤ 3,

$$\rho(u) = 1-(1-\log(u-1))\log(u) + \operatorname{Li}_2(1 - u) + \frac{\pi^2}{12}.$$

with Li<sub>2</sub> the [dilogarithm](wikipedia://en/482471#Dilogarithm). Other $\rho_n$ can be calculated using infinite series.[^o17]

An alternate method is computing lower and upper bounds with the [trapezoidal rule](wikipedia://en/573452);[^o18] a mesh of progressively finer sizes allows for arbitrary accuracy. For high precision calculations (hundreds of digits), a recursive series expansion about the midpoints of the intervals is superior.[^o19] Values for *u* ≤ 7 can be usefully computed via [numerical integration](wikipedia://en/170089) in ordinary double-precision floating-point.[^o20]

:::

::: {#o22 .statement kind=statement/generalization cue=heading name="Extension"}

## Extension {#Extension}

Friedlander defines a two-dimensional analog $\sigma(u,v)$ of $\rho(u)$.[^o23] This function is used to estimate a function $\Psi(x,y,z)$ similar to de Bruijn's, but counting the number of *y*-smooth integers with at most one prime factor greater than *z*. Then

$$\Psi(x,x^{1/a},x^{1/b})\sim x\sigma(b,a).\,$$

This class of numbers may be encountered in the two-stage variant of P-1 factoring. However, Kruppa's estimate of the probability of finding a factor by P-1 does not make use of this result.[^o20]

:::
