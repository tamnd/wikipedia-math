# Spouge's approximation

::: {#o1 .subject cue=lead name="Spouge's approximation"}

In mathematics, **Spouge's approximation** is a formula for computing an approximation of the [gamma function](wikipedia://en/12316). It was named after John L. Spouge, who defined the formula in a 1994 paper.[^o2] The formula is a modification of [Stirling's approximation](wikipedia://en/151783), and has the form

:::

$$\Gamma(z+1) = (z+a)^{z+\frac12} e^{-z-a} \left( c_0 + \sum_{k=1}^{a-1} \frac{c_k}{z+k} + \varepsilon_a(z) \right)$$

where *a* is an arbitrary positive integer and the coefficients are given by

$$\begin{aligned} c_0 &= \sqrt{2 \pi}\\ c_k &= \frac{(-1)^{k-1}}{(k-1)!} (-k+a)^{k-\frac12} e^{-k+a} \qquad k\in\{1,2,\dots, a-1\}. \end{aligned}$$

Spouge has proved that, if Re(*z*) > 0 and *a* > 2, the relative error in discarding *ε*<sub>*a*</sub>(*z*) is bounded by

$$a^{-\frac12} (2 \pi)^{-a-\frac12}.$$

The formula is similar[^o3] to the [Lanczos approximation](wikipedia://en/1982776), but has some distinct features[^o4]. Whereas the Lanczos formula exhibits faster convergence [^o5], Spouge's coefficients are much easier to calculate and the error can be set arbitrarily low. The formula is therefore feasible for [arbitrary-precision](wikipedia://en/600892)[^o6] evaluation of the gamma function [^o7]. However, special care must be taken to use sufficient precision when computing the sum due to the large size of the coefficients *c<sub>k</sub>*, as well as their alternating sign. For example, for *a* = 49, one must compute the sum using about 65 decimal digits of precision in order to obtain the promised 40 decimal digits of accuracy.

Spouge's approximation for the scalar Gamma function, along with the Lanczos and Stirling approximations, generalizes to the matrix Gamma function [^o8].
