# Hanani–Tutte theorem

::: {#o1 .subject cue=lead name="Hanani–Tutte theorem"}

In [topological graph theory](wikipedia://en/1631772), the **Hanani–Tutte theorem** is a result on the [parity](wikipedia://en/143135) of [edge crossings](wikipedia://en/18298594) in a [graph drawing](wikipedia://en/325813). It states that every drawing in the plane of a [non-planar graph](wikipedia://en/24314) contains a pair of independent edges (not both sharing an endpoint) that cross each other an odd number of times. Equivalently, it can be phrased as a planarity criterion: a graph is planar if and only if it has a drawing in which every pair of independent edges crosses evenly (or not at all).[^o2]

:::

## History {#History}

The result is named after [Haim Hanani](wikipedia://en/37650460), who proved in 1934 that every drawing of the two [minimal non-planar graphs](wikipedia://en/54493) *K*<sub>5</sub> and *K*<sub>3,3</sub> has a pair of edges with an odd number of crossings,[^o4] and after [W. T. Tutte](wikipedia://en/52021), who stated the full theorem explicitly in 1970.[^o5] A parallel development of similar ideas in [algebraic topology](wikipedia://en/38801) has been credited to [Egbert van Kampen](wikipedia://en/8156533), [Arnold S. Shapiro](https://en.wikipedia.org/wiki/Arnold_S._Shapiro), and [Wu Wenjun](https://en.wikipedia.org/wiki/Wu_Wenjun).[^o6][^o7][^o8][^o9][^o10][^o11]

::: {#o13 .application cue=heading name="Applications"}

## Applications {#Applications}

One consequence of the theorem is that testing whether a graph is planar may be formulated as solving a [system of linear equations](wikipedia://en/113087) over the [finite field of order two](wikipedia://en/11137263). These equations may be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), but the resulting [algorithms](wikipedia://en/775) are less efficient than other known planarity tests.[^o2]

:::

::: {#o15 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

For other surfaces *S* than the plane, a graph can be drawn on *S* without crossings if and only if it can be drawn in such a way that all pairs of edges cross an even number of times; this is known as the weak Hanani–Tutte theorem for *S*. The strong Hanani–Tutte theorem states that a graph can be drawn without crossings on *S* if and only if it can be drawn in such a way that all independent pairs of edges cross an even number of times, without regard for the number of crossings between edges that share an endpoint;[^o16] this strong version does not hold for all surfaces,[^o17] but it is known to hold for the plane, the [projective plane](wikipedia://en/24350) and the [torus](wikipedia://en/74800).[^o18]

The same approach, in which one shows that pairs of edges with an even number of crossings can be disregarded or eliminated in some type of graph drawing and uses this fact to set up a system of linear equations describing the existence of a drawing, has been applied to several other graph drawing problems, including [upward planar drawings](wikipedia://en/40148474),[^o19] drawings minimizing the number of uncrossed edges,[^o20][^o21] and [clustered planarity](wikipedia://en/44034633).[^o22]

:::
