# Wholeness axiom

::: {#o1 .subject cue=lead name="Wholeness axiom"}

In mathematics, the **wholeness axiom** is a strong axiom of set theory introduced by [Paul Corazza](https://en.wikipedia.org/wiki/Paul_Corazza) in 2000.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

The wholeness axiom states roughly that there is an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding) *j* from the [Von Neumann universe](wikipedia://en/445980) *V* to itself. This has to be stated carefully to avoid [Kunen's inconsistency theorem](wikipedia://en/25426123) stating (roughly) that no such embedding exists.

More specifically, as Samuel Gomes da Silva states, "the inconsistency is avoided by omitting from the schema all instances of the Replacement Axiom for *j*-formulas".[^o5] Thus, the wholeness axiom differs from [Reinhardt cardinals](wikipedia://en/4687321) (another way of providing elementary embeddings from *V* to itself) by allowing the [axiom of choice](wikipedia://en/840) and instead modifying the [axiom of replacement](https://en.wikipedia.org/wiki/Axiom_of_replacement). However, (Holmes Forster Libert 2012) write that Corrazza's theory should be "naturally viewed as a version of [Zermelo set theory](wikipedia://en/322623) rather than [ZFC](https://en.wikipedia.org/wiki/ZFC)".[^o7]

If the wholeness axiom is consistent, then it is also consistent to add to the wholeness axiom the assertion that all sets are [hereditarily ordinal definable](wikipedia://en/14566906).[^o9] The consistency of stratified versions of the wholeness axiom, introduced by (Hamkins 2001),[^o9] was studied by (Apter 2012).[^o11]

:::
