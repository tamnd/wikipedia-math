# Element of a set

::: {#o1 .subject cue=lead name="Element of a set"}

In [mathematics](wikipedia://en/18831), an **element** (or **member**) **of a [set](wikipedia://en/26691)** is any one of the [distinct](wikipedia://en/90446) [objects](wikipedia://en/19453961) that belong to that set. For example, given a set called $A$ containing the first four positive [integers](wikipedia://en/14563) ($A = \{1, 2, 3, 4\}$), one could say that "3 is an element of $A$", expressed notationally as $3 \in A$.

:::

## Sets {#Sets}

Writing $A = \{1, 2, 3, 4\}$ means that the elements of the set $A$ are the numbers 1, 2, 3 and 4. Sets of elements of $A$, for example $\{1, 2\}$, are [subsets](wikipedia://en/27631) of $A$.

Sets can themselves be elements. For example, consider the set $B = \{1, 2, \{3, 4\}\}$. The elements of $B$ are *not* 1, 2, 3, and 4. Rather, there are only three elements of $B$, namely the numbers 1 and 2, and the set $\{3, 4\}$.

The elements of a set can be anything. For example the elements of the set $C = \{\mathrm{\color{Red}red}, \mathrm{12}, B\}$ are the color red, the number 12, and the set $B$.

In logic, a set can be defined in terms of the membership of its elements as $(x \in y) \leftrightarrow \forall x[P_x = y]: x \in \mathfrak D y$. This basically means that there is a general [predication](wikipedia://en/285109) of x called membership that is equivalent to the statement ‘x is a member of y if and only if, for all objects x, the general predication of x is identical to y, where x is a member of the [domain](wikipedia://en/50263) of y.’ The expression x ∈ 𝔇y makes this definition well-defined by ensuring that x is a bound variable in its predication of membership in y.

In this case, the domain of Px, which is the set containing all dependent logical values x that satisfy the stated conditions for membership in y, is called the Universe (U) of y. The range of Px, which is the set of all possible dependent set variables y resulting from satisfaction of the conditions of membership for x, is the [power set](wikipedia://en/23799) of U such that the [binary relation](wikipedia://en/3931) of the membership of x in y is any subset of the [cartesian product](wikipedia://en/24104095) U × 𝒫(U) (the Cartesian Product of set U with the Power Set of U).

## Notation and terminology {#Notation_and_terminology}

The [binary relation](wikipedia://en/3931) "is an element of", also called **set membership**, is denoted by the symbol "∈". Writing

$$x \in A$$

means that "*x* is an element of *A*".[^o5] Equivalent expressions are "*x* is a member of *A*", "*x* belongs to *A*", "*x* is in *A*" and "*x* lies in *A*". The expressions "*A* includes *x*" and "*A* contains *x*" are also used to mean set membership, although some authors use them to mean instead "*x* is a [subset](wikipedia://en/27631) of *A*".[^o6] Logician [George Boolos](wikipedia://en/340621) strongly urged that "contains" be used for membership only, and "includes" for the subset relation only.[^o7]

For the relation ∈ , the [converse relation](wikipedia://en/3941020) ∈<sup>T</sup> may be written

$$A \ni x$$

meaning "*A* contains or includes *x*".

The [negation](wikipedia://en/161019) of set membership is denoted by the symbol "∉". Writing

$$x \notin A$$

means that "*x* is not an element of *A*".

The symbol ∈ was first used by [Giuseppe Peano](wikipedia://en/13043), in his 1889 work [Arithmetices principia, nova methodo exposita](wikipedia://en/51988929).[^o8] Here he wrote on page X:

> Signum ∈ significat est. Ita $a \in b$ legitur a est quoddam b; …

which means

> The symbol ∈ means *is*. So $a \in b$ is read as a *is a certain* b; …

The symbol itself is a stylized lowercase Greek letter [epsilon](https://en.wikipedia.org/wiki/Epsilon) ("ϵ"), the first letter of the word grc, which means "is".[^o8]

## Examples {#Examples}

Using the sets defined above, namely *A* = {1, 2, 3, 4}, *B* = {1, 2, {3, 4}} and *C* = {red, 12, *B*}, the following statements are true:

- $$2 \in A$$
- $$5 \notin A$$
- $$\{3, 4\} \in B$$
- $$3 \notin B$$
- $$4 \notin B$$
- $$\operatorname{yellow} \notin C$$

:::

## Cardinality of sets {#Cardinality_of_sets}

The number of elements in a particular set is a property known as [cardinality](wikipedia://en/6174); informally, this is the size of a set.[^o12] In the above examples, the cardinality of the set *A* is 4, while the cardinality of set *B* and set *C* are both 3. An infinite set is a set with an infinite number of elements, while a [finite set](wikipedia://en/11742) is a set with a finite number of elements. The above examples are examples of finite sets. An example of an infinite set is the set of positive integers $\{1, 2, 3, 4, ...\}$.

## Formal relation {#Formal_relation}

As a [relation](wikipedia://en/22517558), set membership must have a domain and a range. Conventionally the domain is called the [universe](wikipedia://en/296838) denoted *U*. The range is the set of [subsets](wikipedia://en/27631) of *U* called the [power set](wikipedia://en/23799) of *U* and denoted P(*U*). Thus the relation $\in$ is a subset of $U \times P(U)$. The converse relation $\ni$ is a subset of $P(U) \times U$.
