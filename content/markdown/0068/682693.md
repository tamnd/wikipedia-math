# Cohomotopy set

::: {#o1 .subject cue=lead name="Cohomotopy set"}

In [mathematics](wikipedia://en/18831), particularly [algebraic topology](wikipedia://en/38801), **cohomotopy sets** are particular [contravariant functors](wikipedia://en/5869) from the [category](wikipedia://en/53759) of [pointed topological spaces](wikipedia://en/1236666) and basepoint-preserving [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) maps to the category of [sets](wikipedia://en/26691) and [functions](wikipedia://en/185427). They are [dual](wikipedia://en/609737) to the [homotopy groups](https://en.wikipedia.org/wiki/Homotopy_groups), but less studied.

:::

## Overview {#Overview}

The *p*-th cohomotopy set of a pointed [topological space](wikipedia://en/30450) *X* is defined by

$$\pi^p(X) = [X,S^p]$$

the set of pointed [homotopy](wikipedia://en/212250) classes of continuous mappings from $X$ to the *p*-[sphere](https://en.wikipedia.org/wiki/Hypersphere) $S^p$.

For *p* = 1 this set has an [abelian group](wikipedia://en/2974) structure, and is called the **Bruschlinsky group**. Provided $X$ is a [CW-complex](https://en.wikipedia.org/wiki/CW-complex), it is [isomorphic](wikipedia://en/12397) to the first [cohomology](wikipedia://en/194060) group $H^1(X)$, since the [circle](wikipedia://en/6220) $S^1$ is an [Eilenberg–MacLane space](wikipedia://en/1073230) of type $K(\mathbb{Z},1)$.

A theorem of [Heinz Hopf](wikipedia://en/543082) states that if $X$ is a [CW-complex](https://en.wikipedia.org/wiki/CW-complex) of dimension at most *p*, then $[X,S^p]$ is in [bijection](wikipedia://en/3942) with the *p*-th cohomology group $H^p(X)$.

The set $[X,S^p]$ also has a natural [group](wikipedia://en/19447) structure if $X$ is a [suspension](wikipedia://en/1251702) $\Sigma Y$, such as a sphere $S^q$ for $q \ge 1$.

If *X* is not homotopy equivalent to a CW-complex, then $H^1(X)$ might not be isomorphic to $[X,S^1]$. A counterexample is given by the [Warsaw circle](https://en.wikipedia.org/wiki/Warsaw_circle), whose first cohomology group vanishes, but admits a map to $S^1$ which is not homotopic to a constant map.[^o4]

## Properties {#Properties}

Some basic facts about cohomotopy sets, some more obvious than others:

- $\pi^p(S^q) = \pi_q(S^p)$ for all *p* and *q*.
- For $q= p + 1$ and $p > 2$, the group $\pi^p(S^q)$ is equal to $\mathbb{Z}_2$. (To prove this result, [Lev Pontryagin](wikipedia://en/582075) developed the concept of framed [cobordism](wikipedia://en/391832).)
- If $f,g\colon X \to S^p$ has $\|f(x) - g(x)\| < 2$ for all *x*, then $[f] = [g]$, and the homotopy is smooth if *f* and *g* are.
- For $X$ a [compact](wikipedia://en/6042) [smooth manifold](https://en.wikipedia.org/wiki/Smooth_manifold), $\pi^p(X)$ is isomorphic to the set of homotopy classes of [smooth](https://en.wikipedia.org/wiki/Smooth_function) maps $X \to S^p$; in this case, every continuous map can be uniformly approximated by a smooth map and any homotopic smooth maps will be smoothly homotopic.
- If $X$ is an $m$-[manifold](wikipedia://en/2073470), then $\pi^p(X)=0$ for $p > m$.
- If $X$ is an $m$-[manifold with boundary](wikipedia://en/2073470#Manifold_with_boundary), the set $\pi^p(X,\partial X)$ is [canonically](https://en.wikipedia.org/wiki/Natural_isomorphism) in bijection with the set of cobordism classes of [codimension](wikipedia://en/525149)-*p* framed submanifolds of the [interior](wikipedia://en/55610) $X \setminus \partial X$.
- The [stable cohomotopy group](https://en.wikipedia.org/wiki/Stable_cohomotopy_group) of $X$ is the [colimit](https://en.wikipedia.org/wiki/Colimit)

$$\pi^p_s(X) = \varinjlim_k{[\Sigma^k X, S^{p+k}]}$$

which is an abelian group.

:::

## History {#History}

Cohomotopy sets were introduced by [Karol Borsuk](https://en.wikipedia.org/wiki/Karol_Borsuk) in 1936.[^o8] A systematic examination was given by [Edwin Spanier](https://en.wikipedia.org/wiki/Edwin_Spanier) in 1949.[^o9] The stable cohomotopy groups were defined by [Franklin P. Peterson](wikipedia://en/40839653) in 1956.[^o10]
