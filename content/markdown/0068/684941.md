# TI-15 Explorer

::: {#o1 .subject cue=lead name="TI-15 Explorer"}

**TI-15 Explorer** is a [calculator](wikipedia://en/7593) designed by [Texas Instruments](https://en.wikipedia.org/wiki/Texas_Instruments), intended for use in classes from grades 3–6.[^o2] It is the successor to the [TI-12 Math Explorer](https://en.wikipedia.org/wiki/TI-12_Math_Explorer). For younger students, TI recommends the use of the [TI-108](https://en.wikipedia.org/wiki/TI-108). For older students, TI recommends the use of the [TI-73 Explorer](https://en.wikipedia.org/wiki/TI-73_Explorer).

:::

Features include a 2-line pixel display (as opposed to the [7-segment display](https://en.wikipedia.org/wiki/7-segment_display) of several other calculators) and a quiz-like "[problem-solving](wikipedia://en/1567386)" mode with 3 difficulty levels.[^o3] It also supports limited [scientific capabilities](wikipedia://en/439711), such as parentheses, fixed decimal, fractions, [pi](wikipedia://en/23601), and exponents.
