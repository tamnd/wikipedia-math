# Listing number

::: {#o1 .subject cue=lead name="Listing number"}

In mathematics, a **Listing number** of a [topological space](wikipedia://en/30450) is one of several [topological invariants](https://en.wikipedia.org/wiki/Topological_invariant) introduced by the 19th-century mathematician [Johann Benedict Listing](wikipedia://en/1525914) and later given this name by [Charles Sanders Peirce](wikipedia://en/6117). Unlike the later invariants given by [Bernhard Riemann](wikipedia://en/41980), the Listing numbers do not form a complete set of invariants: two different two-dimensional [manifolds](wikipedia://en/2073470) may have the same Listing numbers as each other.[^o2]

:::

There are four Listing numbers associated with a space.[^o3] The smallest Listing number counts the number of connected components of a space, and is thus equivalent to the zeroth [Betti number](wikipedia://en/346262).[^o4]
