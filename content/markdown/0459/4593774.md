# Edge connectivity

::: {#o1 .subject cue=lead name="Edge connectivity"}

In [graph theory](wikipedia://en/12401), a connected [graph](wikipedia://en/325806) is **$k$-edge-connected** if it remains [connected](wikipedia://en/1614492) whenever fewer than $k$ edges are removed.

:::

The **edge-connectivity** of a graph is the largest $k$ for which the graph is $k$-edge-connected.

Edge connectivity and the [enumeration](wikipedia://en/9982439) of $k$-edge-connected graphs was studied by [Camille Jordan](wikipedia://en/355931) in 1869.[^o2]

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

*Image: 2-edge connected graph.svg.* A 2-edge-connected graph

Let $G = (V, E)$ be an arbitrary graph. If the [subgraph](wikipedia://en/325802#Subgraphs) $G' = (V, E \setminus X)$ is connected for all $X \subseteq E$ where $|X| < k$, then *G* is said to be *k*-edge-connected. The edge connectivity of $G$ is the maximum value *k* such that *G* is *k*-edge-connected. The smallest set *X* whose removal disconnects *G* is a [minimum cut](wikipedia://en/3562453) in *G*.

The edge connectivity version of [Menger's theorem](wikipedia://en/1155738) provides an alternative and equivalent characterization, in terms of edge-disjoint paths in the graph. If and only if every two [vertices](wikipedia://en/638899) of *G* form the endpoints of *k* paths, no two of which share an edge with each other, then *G* is *k*-edge-connected. In one direction this is easy: if a system of paths like this exists, then every set *X* of fewer than *k* edges is disjoint from at least one of the paths, and the pair of vertices remains connected to each other even after *X* is deleted. In the other direction, the existence of a system of paths for each pair of vertices in a graph that cannot be disconnected by the removal of few edges can be proven using the [max-flow min-cut theorem](wikipedia://en/78130) from the theory of [network flows](wikipedia://en/645676).

:::

## Related concepts {#Related_concepts}

Minimum [vertex degree](wikipedia://en/1374448) gives a trivial upper bound on edge-connectivity. That is, if a graph $G = (V, E)$ is *k*-edge-connected then it is necessary that *k* ≤ δ(*G*), where δ(*G*) is the minimum degree of any vertex *v* ∈ *V*. Deleting all edges incident to a vertex *v* would disconnect *v* from the graph.

Edge connectivity is the dual concept to [girth](wikipedia://en/12013), the length of the shortest cycle in a graph, in the sense that the girth of a [planar graph](wikipedia://en/24314) is the edge connectivity of its [dual graph](wikipedia://en/2536864), and vice versa. These concepts are unified in [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory) by the [girth of a matroid](wikipedia://en/47482411), the size of the smallest dependent set in the matroid. For a [graphic matroid](wikipedia://en/745714), the matroid girth equals the girth of the underlying graph, while for a co-graphic matroid it equals the edge connectivity.[^o6]

The 2-edge-connected graphs can also be characterized by the absence of [bridges](wikipedia://en/1305071), by the existence of an [ear decomposition](wikipedia://en/32183016), or by [Robbins' theorem](wikipedia://en/36633800) according to which these are exactly the graphs that have a [strong orientation](wikipedia://en/16678715).[^o7]

By a corollary of the [Nash-Williams theorem](wikipedia://en/60654680), the edge-connectivity of a graph provides bounds on how many edge-disjoint spanning trees can be found within the graph.

## Computational aspects {#Computational_aspects}

There is a polynomial-time algorithm to determine the largest *k* for which a graph *G* is *k*-edge-connected. A simple algorithm would, for every pair *(u,v)*, determine the [maximum flow](wikipedia://en/403165) from *u* to *v* with the capacity of all edges in *G* set to 1 for both directions. A graph is *k*-edge-connected if and only if the maximum flow from *u* to *v* is at least *k* for any pair *(u,v)*, so *k* is the least *u-v*-flow among all *(u,v)*.

If *n* is the number of vertices in the graph, this simple algorithm would perform $O(n^2)$ iterations of the Maximum flow problem, which can be solved in $O(n^3)$ time. Hence the complexity of the simple algorithm described above is $O(n^5)$ in total.

An improved algorithm will solve the maximum flow problem for every pair *(u,v)* where *u* is arbitrarily fixed while *v* varies over all vertices. This reduces the complexity to $O(n^4)$ and is sound since, if a [cut](wikipedia://en/2180494) of capacity less than *k* exists, it is bound to separate *u* from some other vertex. It can be further improved by an algorithm of [Gabow](wikipedia://en/68166303) that runs in worst case $O(n^3)$ time. [^o9]

The Karger–Stein variant of [Karger's algorithm](https://en.wikipedia.org/wiki/Karger's_algorithm) provides a faster [randomized algorithm](wikipedia://en/495383) for determining the connectivity, with expected runtime $O(n^2\log^3 n)$.[^o10]

A related problem: finding the minimum *k*-edge-connected spanning subgraph of *G* (that is: select as few as possible edges in *G* that your selection is *k*-edge-connected) is NP-hard for $k\geq 2$.[^o11]
