# Grey box model

::: {#o1 .subject cue=lead name="Grey box model"}

In [mathematics](wikipedia://en/18831), [statistics](wikipedia://en/26685), and [computational modelling](https://en.wikipedia.org/wiki/Computational_modelling), a **grey box model**[^o2][^o3][^o4][^o5] combines a partial theoretical structure with data to complete the model. The theoretical structure may vary from information on the smoothness of results, to models that need only parameter values from data or existing literature.[^o6] Thus, almost all models are grey box models as opposed to [black box](https://en.wikipedia.org/wiki/Black_box) where no model form is assumed or [white box](https://en.wikipedia.org/wiki/White_box_%28software_engineering%29) models that are purely theoretical. Some models assume a special form such as a [linear regression](wikipedia://en/48758386)[^o7][^o8] or [neural network](https://en.wikipedia.org/wiki/Neural_network).[^o9][^o10] These have special analysis methods. In particular [linear regression](wikipedia://en/48758386) techniques[^o11] are much more efficient than most non-linear techniques.[^o12][^o13] The model can be [deterministic](https://en.wikipedia.org/wiki/Deterministic) or [stochastic](wikipedia://en/292222) (i.e. containing random components) depending on its planned use.

:::

## Model form {#Model_form}

The general case is a [non-linear model](https://en.wikipedia.org/wiki/Non-linear_system) with a partial theoretical structure and some unknown parts derived from data. Models with unlike theoretical structures need to be evaluated individually,[^o2][^o15][^o16] possibly using [simulated annealing](wikipedia://en/172244) or [genetic algorithms](https://en.wikipedia.org/wiki/Genetic_algorithms).

Within a particular model structure, [parameters](wikipedia://en/552466)[^o16][^o17] or variable parameter relations[^o6][^o18] may need to be found. For a particular structure it is arbitrarily assumed that the data consists of sets of feed vectors **f**, product vectors **p**, and operating condition vectors **c**.[^o6] Typically **c** will contain values extracted from **f**, as well as other values. In many cases a model can be converted to a function of the form:[^o6][^o19][^o20]

**m(f,p,q)**

where the vector function **m** gives the errors between the data **p**, and the model predictions. The vector **q** gives some variable parameters that are the model's unknown parts.

The parameters **q** vary with the operating conditions **c** in a manner to be determined.[^o6][^o19] This relation can be specified as **q** = **Ac** where **A** is a matrix of unknown coefficients, and **c** as in [linear regression](wikipedia://en/48758386)[^o7][^o8] includes a [constant term](wikipedia://en/79861) and possibly transformed values of the original operating conditions to obtain non-linear relations[^o21][^o22] between the original operating conditions and **q**. It is then a matter of selecting which terms in **A** are non-zero and assigning their values. The model completion becomes an [optimization](wikipedia://en/52033) problem to determine the non-zero values in **A** that minimizes the error terms **m(f,p,Ac)** over the data.[^o2][^o18][^o23][^o24][^o25]

## Model completion {#Model_completion}

Once a selection of non-zero values is made, the remaining coefficients in **A** can be determined by minimizing ***m*(*f*,*p*,*Ac*)** over the data with respect to the nonzero values in **A**, typically by [non-linear least squares](wikipedia://en/15652764). Selection of the nonzero terms can be done by optimization methods such as [simulated annealing](wikipedia://en/172244) and [evolutionary algorithms](https://en.wikipedia.org/wiki/Evolutionary_algorithms). Also the [non-linear least squares](wikipedia://en/15652764) can provide accuracy estimates[^o12][^o17] for the elements of **A** that can be used to determine if they are significantly different from zero, thus providing a method of [term selection](wikipedia://en/3664073).[^o27][^o28]

It is sometimes possible to calculate values of **q** for each data set, directly or by [non-linear least squares](wikipedia://en/15652764). Then the more efficient [linear regression](wikipedia://en/48758386) can be used to predict **q** using **c** thus selecting the non-zero values in **A** and estimating their values. Once the non-zero values are located [non-linear least squares](wikipedia://en/15652764) can be used on the original model **m(f,p,Ac)** to refine these values .[^o18][^o23][^o24]

A third method is [model inversion](https://en.wikipedia.org/wiki/Model_inversion),[^o6][^o19][^o20] which converts the non-linear **m**(**f**,**p**,**Ac**) into an approximate linear form in the elements of **A**, that can be examined using efficient term selection[^o27][^o28] and evaluation of the linear regression.[^o11] For the simple case of a single **q** value (**q** = **a**<sup>T</sup>**c**) and an estimate **q\*** of **q**. Putting d**q** = **a**<sup>T</sup>**c** − **q\*** gives

**m(f,p,a**<sup>T</sup>**c) = m(f,p,q\* +**d**q) ≈ m(f,p.q\*) +**d**q m’(f,p,q\*) = m(f,p.q\*) + (a**<sup>T</sup>**c − q\*) m’(f,p,q\*)**

so that **a**<sup>T</sup> is now in a linear position with all other terms known, and thus can be analyzed by [linear regression](wikipedia://en/48758386) techniques. For more than one parameter the method extends in a direct manner.[^o6][^o20][^o19] After checking that the model has been improved this process can be repeated until convergence. This approach has the advantages that it does not need the parameters **q** to be able to be determined from an individual data set and the linear regression is on the original error terms[^o6]

## Model validation {#Model_validation}

Where sufficient data is available, division of the data into a separate model construction set and one or two [evaluation sets](wikipedia://en/416612) is recommended. This can be repeated using multiple selections of the construction set and the [resulting models averaged](wikipedia://en/1307911) or used to evaluate prediction differences.

A statistical test such as [chi-squared](wikipedia://en/113424) on the residuals is not particularly useful.[^o30] The chi squared test requires known standard deviations which are seldom available, and failed tests give no indication of how to improve the model.[^o12] There are a range of methods to compare both nested and non nested models. These include comparison of model predictions with repeated data.

An attempt to predict the residuals **m(, )** with the operating conditions **c** using linear regression will show if the residuals can be predicted.[^o23][^o24] Residuals that cannot be predicted offer little prospect of improving the model using the current operating conditions.[^o6] Terms that do predict the residuals are prospective terms to incorporate into the model to improve its performance.[^o23]

The model inversion technique above can be used as a method of determining whether a model can be improved. In this case selection of nonzero terms is not so important and [linear prediction](wikipedia://en/18572) can be done using the significant [eigenvectors](https://en.wikipedia.org/wiki/Eigenvectors) of the [regression matrix](wikipedia://en/949189). The values in **A** determined in this manner need to be substituted into the nonlinear model to assess improvements in the model errors. The absence of a significant improvement indicates the available data is not able to improve the current model form using the defined parameters.[^o6] Extra parameters can be inserted into the model to make this test more comprehensive.
