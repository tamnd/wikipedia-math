# GNOME Calculator

::: {#o2 .subject cue=lead name="GNOME Calculator"}

**GNOME Calculator**, formerly known as **gcalctool**, is the [software calculator](wikipedia://en/17056775) integrated with the [GNOME desktop environment](https://en.wikipedia.org/wiki/GNOME). It is programmed in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) and [Vala](https://en.wikipedia.org/wiki/Vala_%28programming_language%29) and part of the [GNOME Core Applications](https://en.wikipedia.org/wiki/GNOME_Core_Applications).

:::

## Mathematics {#Mathematics}

GNOME Calculator uses the [MPFR](https://en.wikipedia.org/wiki/MPFR) library for extended precision arithmetic. It can support complex number arithmetic, perform factorization of integers, and define new functions by composition.

## Views {#Views}

While most functionality can be accessed by typing the function name into the input, Calculator provides different views for convenience.

- *Basic* – interface for basic arithmetic, resembling a [desk calculator](https://en.wikipedia.org/wiki/Desk_calculator).
- *Advanced* – an interface with scientific functions, and support for custom variables. New functions can be defined by function composition.
- *Financial* – financial calculation and [currency conversion](https://en.wikipedia.org/wiki/Currency_converter).
- *Programming* – a view with [bit manipulation](https://en.wikipedia.org/wiki/Bitwise_operators) operators and [radix](wikipedia://en/701207) conversion.
- *Keyboard* – most of the space is taken up by the output, with no on-screen buttons. Supports currency and [unit conversion](https://en.wikipedia.org/wiki/Unit_converter).
- *Conversion* – A view for performing conversions between units.

## Notation {#Notation}

The GNOME calculator uses the common [infix notation](wikipedia://en/199014) for [binary functions](wikipedia://en/3943), such as the four basic arithmetic operations. Unlike many other calculators, it uses [prefix notation](https://en.wikipedia.org/wiki/Prefix_notation), not [postfix notation](https://en.wikipedia.org/wiki/Postfix_notation) for [unary functions](wikipedia://en/1514907). So to calculate e.g. the [sine](https://en.wikipedia.org/wiki/Sine) of [one](https://en.wikipedia.org/wiki/One), the user must push the keys sin, not 1, as on many other calculators.

The decimal separator on the [number pad](https://en.wikipedia.org/wiki/Numeric_keypad) is based on the general keyboard layout since version 3.12.3.[^o7] Due to different styles of formatting decimal positions across the world, Calculator interprets both commas and periods as decimal separators. Consequently, using k-ary functions requires using a semicolon to separate the arguments.
