# ALGLIB

::: {#o1 .subject cue=lead name="ALGLIB"}

**ALGLIB** is a [cross-platform](https://en.wikipedia.org/wiki/Cross-platform) [open source](https://en.wikipedia.org/wiki/Open-source_software) [numerical analysis](wikipedia://en/21506) and [data processing](https://en.wikipedia.org/wiki/Data_processing) [library](https://en.wikipedia.org/wiki/Library_%28computing%29). It can be used from several programming languages ([C++](https://en.wikipedia.org/wiki/C++), [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29), [VB.NET](https://en.wikipedia.org/wiki/VB.NET), [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), [Delphi](https://en.wikipedia.org/wiki/Delphi_%28programming_language%29), [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29)).

:::

ALGLIB started in 1999 and has a long history of steady development with 3 releases per year. It is used by several open-source projects, commercial libraries, and applications (e.g. [TOL project](https://en.wikipedia.org/wiki/Tree_of_Life_Web_Project), [Math.NET Numerics](https://en.wikipedia.org/wiki/Math.NET_Numerics),[^o3][^o4] [SpaceClaim](https://en.wikipedia.org/wiki/SpaceClaim)[^o5]).

## Features {#Features}

Distinctive features of the library are:

- Support for several programming languages with identical APIs (C++, C#, FreePascal/Delphi, VB.NET, Python, and Java)
- Self-contained code with no mandatory external dependencies and easy installation
- Portability (it was tested under x86/x86-64/ARM, [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) and [Linux](https://en.wikipedia.org/wiki/Linux))
- Two independent backends (pure C# implementation, native C implementation) with automatically generated APIs (C++, C#, ...)
- Same functionality of commercial and GPL versions, with enhancements for speed and parallelism provided in the commercial version

The most actively developed parts of ALGLIB are:

- Mixed-integer optimization, with support for analytic and derivative-free MINLP problems.
- Continuous optimization, with LP, QP, QCQP, SOCP (and other conic problem types) and NLP solvers, derivative-free global solvers and multiobjective optimization algorithms.
- Linear algebra, offering a comprehensive set of both dense and sparse linear solvers and factorizations
- Interpolation, featuring standard algorithms like polynomials and 1D/2D splines, as well as several unique large-scale interpolation/fitting algorithms. These include penalized 1D/2D splines, fast thin plate splines and fast polyharmonic splines, all scalable to hundreds of thousands of points.
- Least squares solvers, including linear/nonlinear unconstrained and constrained least squares and curve fitting solvers
- [Data analysis](wikipedia://en/2720954), with various algorithms being implemented

The other functions in the library include:

- [Fast Fourier transforms](wikipedia://en/11512)
- [Numerical integration](wikipedia://en/170089)
- [Ordinary differential equations](wikipedia://en/32742753)
- [Special functions](wikipedia://en/23709110)
- [Statistics](wikipedia://en/26685) ([descriptive statistics](wikipedia://en/8187), [hypothesis testing](https://en.wikipedia.org/wiki/Hypothesis_testing))
- Multiple precision versions of [linear algebra](wikipedia://en/18422), [interpolation](wikipedia://en/14569) and optimization algorithms (using [MPFR](https://en.wikipedia.org/wiki/MPFR) for floating point computations)
