# Component analysis (statistics)

::: {#o1 .subject cue=lead name="Component analysis"}

**Component analysis** is the analysis of two or more [independent variables](https://en.wikipedia.org/wiki/Independent_variable) which comprise a [treatment modality](https://en.wikipedia.org/wiki/Treatment_modality).[^o2][^o3][^o4] It is also known as a dismantling study.[^o5]

:::

The chief purpose of the component analysis is to identify the component which is efficacious in changing behavior, if a singular component exists.[^o3]

Eliminating ineffective or less effective components may help with improving social validity, reducing aversive elements, improving generalization and maintenance, as well as administrative efficacy.

It is also a required skill for the [BCBA](https://en.wikipedia.org/wiki/Licensed_behavior_analyst).[^o6]
