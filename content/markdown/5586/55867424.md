# Residual neural network

*Image: ResBlock.png.* A residual block in a deep residual network. Here, the residual connection skips two layers.

::: {#o1 .subject cue=lead name="Residual neural network"}

A **residual neural network** (also referred to as a **residual network** or **ResNet**)[^o2] is a [deep learning](https://en.wikipedia.org/wiki/Deep_learning) architecture in which the layers learn residual functions with reference to the layer inputs. It was developed in 2015 for [image recognition](https://en.wikipedia.org/wiki/Image_recognition), and won the [ImageNet](https://en.wikipedia.org/wiki/ImageNet) Large Scale Visual Recognition Challenge ([ILSVRC](https://image-net.org/challenges/LSVRC/)) of that year.[^o3][^o4]

:::

As a point of terminology, "residual connection" refers to the specific architectural motif of $x \mapsto f(x) + x$, where $f$ is an arbitrary neural network module. The motif had been used previously (see [§History](wikipedia://en/55867424#History) for details). However, the publication of ResNet made it widely popular for [feedforward networks](https://en.wikipedia.org/wiki/Feedforward_neural_network), appearing in neural networks that are seemingly unrelated to ResNet.

The residual connection stabilizes the training and convergence of deep neural networks with hundreds of layers, and is a common motif in deep neural networks, such as [transformer](https://en.wikipedia.org/wiki/Transformer_%28deep_learning_architecture%29) models (e.g., [BERT](https://en.wikipedia.org/wiki/BERT_%28language_model%29), and [GPT](https://en.wikipedia.org/wiki/Generative_pre-trained_transformer) models such as [ChatGPT](https://en.wikipedia.org/wiki/ChatGPT)), the [AlphaGo Zero](https://en.wikipedia.org/wiki/AlphaGo_Zero) system, the [AlphaStar](https://en.wikipedia.org/wiki/AlphaStar_%28software%29) system, and the [AlphaFold](https://en.wikipedia.org/wiki/AlphaFold) system.

## Mathematics {#Mathematics}

### Residual connection {#Residual_connection}

In a multilayer neural network model, consider a (non-residual) subnetwork with a certain number of stacked layers (e.g., 2 or 3). Let $H(x; \alpha)$ denote the subnetwork, where $x$ is the input and $\alpha$ is the set of parameters. Suppose $H^*$ is the desired optimal output of this subnetwork. Residual learning simply adds $x$ directly to the output, such that the optimal learned output now becomes $H^* - x$, which is interpreted as a "residual" with respect to $x$.

The operation of "adding $x$" is implemented via a "skip connection" that performs an identity mapping to connect the input of the subnetwork with its output. This connection is referred to as a "residual connection" in later work.

Let $F(x; \alpha) = H(x; a) + x$. The function $F$ is often represented by matrix multiplication interlaced with [activation functions](https://en.wikipedia.org/wiki/Activation_function) and normalization operations (e.g., [batch normalization](https://en.wikipedia.org/wiki/Batch_normalization) or [layer normalization](https://en.wikipedia.org/wiki/Normalization_%28machine_learning%29#Layer_normalization)). As a whole, one of these subnetworks is referred to as a "residual block".[^o2] A deep residual network is constructed by simply stacking these blocks.

[Long short-term memory](https://en.wikipedia.org/wiki/Long_short-term_memory) (LSTM) has a memory mechanism that serves as a residual connection.[^o7] In an LSTM without a forget [gate](https://en.wikipedia.org/wiki/Gating_mechanism), an input $x_t$ is processed by a function $F$ and added to a memory cell $c_t$, resulting in $c_{t+1} = c_t + F(x_t)$. An LSTM with a forget gate essentially functions as a [highway network](https://en.wikipedia.org/wiki/Highway_network).

To stabilize the [variance](wikipedia://en/32344) of the layers' inputs, it is recommended to replace the residual connections $x + f(x)$ with $x/L + f(x)$, where $L$ is the total number of residual layers.[^o8]

### Projection connection {#Projection_connection}

If the function $F$ is of type $F: \mathbb{R}^n \to \mathbb{R}^m$ where $n \neq m$, then $F(x) + x$ is undefined. To handle this special case, a projection connection is used:

$$y = F(x) + P(x)$$

where $P$ is typically a linear projection, defined by $P(x) = Mx$ where $M$ is a $m \times n$ matrix. The matrix is trained via [backpropagation](https://en.wikipedia.org/wiki/Backpropagation), as is any other parameter of the model.

### Signal propagation {#Signal_propagation}

The introduction of identity mappings facilitates signal propagation in both forward and backward paths.[^o11]

#### Forward propagation {#Forward_propagation}

If the output of the $\ell$-th residual block is the input to the $(\ell+1)$-th residual block (assuming no activation function between blocks), then the $(\ell+1)$-th input is:

$$x_{\ell+1} = F(x_{\ell}) + x_{\ell}$$

Applying this formulation recursively, e.g.:

$$\begin{aligned} x_{\ell+2} & = F(x_{\ell+1}) + x_{\ell+1} \\ & = F(x_{\ell+1}) + F(x_{\ell}) + x_{\ell} \end{aligned}$$

yields the general relationship:

$$x_{L} = x_{\ell} + \sum_{i=\ell}^{L-1} F(x_{i})$$

where $L$ is the index of a residual block and $\ell$ is the index of some earlier block. This formulation suggests that there is always a signal that is directly sent from a shallower block $\ell$ to a deeper block $L$.

#### Backward propagation {#Backward_propagation}

The residual learning formulation provides the added benefit of mitigating the [vanishing gradient problem](https://en.wikipedia.org/wiki/Vanishing_gradient_problem) to some extent. However, it is crucial to acknowledge that the vanishing gradient issue is not the root cause of the degradation problem, which is tackled through the use of normalization. To observe the effect of residual blocks on backpropagation, consider the partial derivative of a [loss function](wikipedia://en/44578554) $\mathcal{E}$ with respect to some residual block input $x_{\ell}$. Using the equation above from forward propagation for a later residual block $L>\ell$:[^o11]

$$\begin{aligned} \frac{\partial \mathcal{E} }{\partial x_{\ell} } & = \frac{\partial \mathcal{E} }{\partial x_{L} }\frac{\partial x_{L} }{\partial x_{\ell} } \\ & = \frac{\partial \mathcal{E} }{\partial x_{L} } \left( 1 + \frac{\partial }{\partial x_{\ell} } \sum_{i=\ell}^{L-1} F(x_{i}) \right) \\ & = \frac{\partial \mathcal{E} }{\partial x_{L} } + \frac{\partial \mathcal{E} }{\partial x_{L} } \frac{\partial }{\partial x_{\ell} } \sum_{i=\ell}^{L-1} F(x_{i}) \end{aligned}$$

This formulation suggests that the gradient computation of a shallower layer, $\frac{\partial \mathcal{E} }{\partial x_{\ell} }$, always has a later term $\frac{\partial \mathcal{E} }{\partial x_{L} }$ that is directly added. Even if the gradients of the $F(x_{i})$ terms are small, the total gradient $\frac{\partial \mathcal{E} }{\partial x_{\ell} }$ resists vanishing due to the added term $\frac{\partial \mathcal{E} }{\partial x_{L} }$.

## Variants of residual blocks {#Variants_of_residual_blocks}

*Image: ResBlockVariants.png.* Two variants of convolutional Residual Blocks.[^o2] **Left**: a *basic block* that has two 3x3 convolutional layers. **Right**: a *bottleneck block* that has a 1x1 convolutional layer for dimension reduction, a 3x3 convolutional layer, and another 1x1 convolutional layer for dimension restoration.

### Basic block {#Basic_block}

A *basic block* is the simplest building block studied in the original ResNet.[^o2] This block consists of two sequential 3x3 [convolutional](https://en.wikipedia.org/wiki/Convolutional_neural_network) layers and a residual connection. The input and output dimensions of both layers are equal.

*Image: ResNet\_block.svg.* Block diagram of ResNet (2015). It shows a ResNet block with and without the 1x1 convolution. The 1x1 convolution (with stride) can be used to change the shape of the array, which is necessary for residual connection through an upsampling/downsampling layer.

### Bottleneck block {#Bottleneck_block}

A *bottleneck block*[^o2] consists of three sequential convolutional layers and a residual connection. The first layer in this block is a 1×1 convolution for dimension reduction (e.g., to 1/2 of the input dimension); the second layer performs a 3×3 convolution; the last layer is another 1×1 convolution for dimension restoration. The models of ResNet-50, ResNet-101, and ResNet-152 are all based on bottleneck blocks.[^o2]

### Pre-activation block {#Pre-activation_block}

The *pre-activation residual block*[^o11] applies activation functions before applying the residual function $F$. Formally, the computation of a pre-activation residual block can be written as:

$$x_{\ell+1} = F(\phi(x_{\ell})) + x_{\ell}$$

where $\phi$ can be any activation (e.g. [ReLU](https://en.wikipedia.org/wiki/ReLU)) or normalization (e.g. [LayerNorm](https://en.wikipedia.org/wiki/LayerNorm)) operation. This design reduces the number of non-identity mappings between residual blocks, and allows an identity mapping directly from the input to the output. This design was used to train models with 200 to over 1000 layers, and was found to consistently outperform variants where the residual path is not an identity function. The pre-activation ResNet with 200 layers took 3 weeks to train for [ImageNet](https://en.wikipedia.org/wiki/ImageNet) on 8 [GPUs](https://en.wikipedia.org/wiki/Graphics_processing_unit) in 2016.[^o11]

Since [GPT-2](https://en.wikipedia.org/wiki/GPT-2), [transformer](https://en.wikipedia.org/wiki/Transformer_%28deep_learning_architecture%29) blocks have been mostly implemented as pre-activation blocks. This is often referred to as "pre-normalization" in the literature of transformer models.[^o18]

*Image: Resnet-18\_architecture.svg.* The original Resnet-18 architecture. Up to 152 layers were trained in the original publication (as "ResNet-152").[^o50]

## Applications {#Applications}

Originally, ResNet was designed for [computer vision](https://en.wikipedia.org/wiki/Computer_vision).[^o2][^o50][^o21]

*Image: Transformer, full architecture.png.* The Transformer architecture includes residual connections.

All transformer architectures include residual connections. Indeed, very deep transformers cannot be trained without them.[^o22]

The original ResNet paper made no claim on being inspired by biological systems. However, later research has related ResNet to biologically-plausible algorithms.[^o23][^o24]

A study published in [*Science*](https://en.wikipedia.org/wiki/Science_%28journal%29) in 2023[^o25] disclosed the complete [connectome](https://en.wikipedia.org/wiki/Connectome) of an insect brain (specifically that of a fruit fly larva). This study discovered "multilayer shortcuts" that resemble the skip connections in artificial neural networks, including ResNets.

:::

## History {#History}

### Previous work {#Previous_work}

Residual connections were noticed in [neuroanatomy](https://en.wikipedia.org/wiki/Neuroanatomy), such as [Lorente de No](https://en.wikipedia.org/wiki/Rafael_Lorente_de_Nó) (1938).[^o28] [McCulloch](https://en.wikipedia.org/wiki/Warren_Sturgis_McCulloch) and [Pitts](wikipedia://en/302949) (1943) proposed artificial neural networks and considered those with residual connections.[^o29]

In 1961, [Frank Rosenblatt](https://en.wikipedia.org/wiki/Frank_Rosenblatt) described a three-layer [multilayer perceptron](https://en.wikipedia.org/wiki/Multilayer_perceptron) (MLP) model with skip connections.[^o30] The model was referred to as a "cross-coupled system", and the skip connections were forms of cross-coupled connections.

During the late 1980s, "skip-layer" connections were sometimes used in neural networks. Examples include:[^o31][^o32] Lang and Witbrock (1988)[^o33] trained a fully connected feedforward network where each layer skip-connects to all subsequent layers, like the later DenseNet (2016). In this work, the residual connection was the form $x \mapsto F(x) + P(x)$, where $P$ is a randomly-initialized projection connection. They termed it a "short-cut connection". An early neural language model used residual connections and named them "direct connections".[^o34]

*Image: LSTM\_3.svg.* The long short-term memory (LSTM) cell can process data sequentially and keep its hidden state through time. The cell state $c_t$ can function as a generalized residual connection.

### Degradation problem {#Degradation_problem}

[Sepp Hochreiter](https://en.wikipedia.org/wiki/Sepp_Hochreiter) discovered the [vanishing gradient problem](https://en.wikipedia.org/wiki/Vanishing_gradient_problem) in 1991[^o36] and argued that it explained why the then-prevalent forms of [recurrent neural networks](wikipedia://en/1706303) did not work for long sequences. He and [Schmidhuber](https://en.wikipedia.org/wiki/Jürgen_Schmidhuber) later designed the LSTM architecture to solve this problem,[^o7][^o37] which has a "cell state" $c_t$ that can function as a generalized residual connection. The [highway network](https://en.wikipedia.org/wiki/Highway_network) (2015)[^o38][^o39] applied the idea of an LSTM [unfolded in time](wikipedia://en/1706303) to [feedforward neural networks](https://en.wikipedia.org/wiki/Feedforward_neural_network), resulting in the highway network. ResNet is equivalent to an open-gated highway network.

*Image: Recurrent\_neural\_network\_unfold.svg.* Standard (left) and unfolded (right) basic recurrent neural network

During the early days of deep learning, there were attempts to train increasingly deep models. Notable examples included the [AlexNet](https://en.wikipedia.org/wiki/AlexNet) (2012), which had 8 layers, and the [VGG-19](https://en.wikipedia.org/wiki/VGGNet) (2014), which had 19 layers.[^o40] However, stacking too many layers led to a steep reduction in [training](wikipedia://en/1514392) accuracy,[^o41] known as the "degradation" problem.[^o2] In theory, adding additional layers to deepen a network should not result in a higher training [loss](wikipedia://en/44578554), but this is what happened with [VGGNet](https://en.wikipedia.org/wiki/VGGNet).[^o2] If the extra layers can be set as [identity mappings](https://en.wikipedia.org/wiki/Identity_mapping), however, then the deeper network would represent the same function as its shallower counterpart. There is some evidence that the optimizer is not able to approach identity mappings for the parameterized layers, and the benefit of residual connections was to allow identity mappings by default.[^o11]

In 2014, the state of the art was training deep neural networks with 20 to 30 layers.[^o40] The research team for ResNet attempted to train deeper ones by empirically testing various methods for training deeper networks, until they came upon the ResNet architecture.[^o42]

::: {#o44 .pointer-item cue=pointer name="Squeeze-and-Excitation Network"}

### Subsequent work {#Subsequent_work}

**Wide Residual Network** (2016) found that using more channels and fewer layers than the original ResNet improves performance and GPU-computational efficiency, and that a block with two 3×3 convolutions is superior to other configurations of convolution blocks.[^o45]

**DenseNet** (2016)[^o46] connects the output of each layer to the input to each subsequent layer:

$$x_{\ell+1} = F(x_1, x_2, \dots, x_{\ell-1}, x_{\ell})$$

**Stochastic depth**[^o47] is a [regularization](wikipedia://en/2009061) method that randomly drops a subset of layers and lets the signal propagate through the identity skip connections. Also known as *DropPath*, this regularizes training for deep models, such as [vision transformers](https://en.wikipedia.org/wiki/Vision_transformer).[^o48]

*Image: ResNext\_block.svg.* ResNeXt block diagram

**ResNeXt** (2017) combines the [Inception module](https://en.wikipedia.org/wiki/Inception_%28deep_learning_architecture%29) with ResNet.[^o49][^o50]

**Squeeze-and-Excitation Networks** (2018) added squeeze-and-excitation (SE) modules to ResNet.[^o51] An SE module is applied after a convolution, and takes a tensor of shape $\mathbb{R}^{H \times W \times C}$ (height, width, channels) as input. Each channel is averaged, resulting in a vector of shape $\mathbb{R}^C$. This is then passed through a [multilayer perceptron](https://en.wikipedia.org/wiki/Multilayer_perceptron) (with an architecture such as *linear-ReLU-linear-sigmoid*) before it is multiplied with the original tensor. It won the [ILSVRC](https://en.wikipedia.org/wiki/ILSVRC) in 2017.[^o52]

:::
