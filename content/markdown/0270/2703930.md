# Schwinger parametrization

::: {#o1 .subject cue=lead name="Schwinger parametrization"}

**Schwinger parametrization** is a technique for evaluating [loop integrals](wikipedia://en/2703676) which arise from [Feynman diagrams](wikipedia://en/11617) with one or more loops. It is named after [Julian Schwinger](wikipedia://en/269980),[^o2] who introduced the method in 1951 for [quantum electrodynamics](wikipedia://en/25268).[^o3]

:::

## Description {#Description}

Using the observation that

$$\frac{1}{A^n}=\frac{1}{(n-1)!}\int^\infty_0 du \, u^{n-1}e^{-uA},$$

one may simplify the integral:

$$\int \frac{dp}{A(p)^n}=\frac{1}{\Gamma(n)}\int dp \int^\infty_0 du \, u^{n-1}e^{-uA(p)}=\frac{1}{\Gamma(n)}\int^\infty_0 du \, u^{n-1} \int dp \, e^{-uA(p)},$$

for $\mathrm{Re}(n)>0$.

### Alternative parametrization {#Alternative_parametrization}

Another version of Schwinger parametrization is:

$$\frac{i}{A+i\epsilon}=\int^\infty_0 du \, e^{iu(A+i\epsilon)},$$

which is convergent as long as $\epsilon >0$ and $A \in \mathbb R$.[^o6] It is easy to generalize this identity to n denominators.
