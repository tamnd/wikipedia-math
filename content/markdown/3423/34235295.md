# Tautological consequence

::: {#o1 .subject cue=lead name="Tautological consequence"}

In [propositional logic](wikipedia://en/18154), **tautological consequence** is a strict form of [logical consequence](wikipedia://en/37531624)[^o2] in which the [tautologousness](wikipedia://en/4495335) of a [proposition](wikipedia://en/81094) is preserved from one line of a proof to the next. Not all logical consequences are tautological consequences. A [proposition](wikipedia://en/81094) $Q$ is said to be a tautological consequence of one or more other propositions ($P_1$, $P_2$, ..., $P_n$) in a [proof](wikipedia://en/1197184) with respect to some [logical system](https://en.wikipedia.org/wiki/Logical_system) if one is [validly](wikipedia://en/21304742) able to introduce the proposition onto a line of the proof within the [rules](wikipedia://en/252311) of the system; and in all cases when each of ($P_1$, $P_2$, ..., $P_n$) are true, the proposition $Q$ also is true.

:::

Another way to express this preservation of tautologousness is by using [truth tables](wikipedia://en/25512250). A proposition $Q$ is said to be a tautological consequence of one or more other propositions ($P_1$, $P_2$, ..., $P_n$) if and only if in every row of a joint truth table that assigns "T" to all propositions ($P_1$, $P_2$, ..., $P_n$) the truth table also assigns "T" to $Q$.

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

$a$ = "Socrates is a man." $b$ = "All men are mortal." $c$ = "Socrates is mortal."

$$a$$

$$b$$

$${\therefore c}$$

The conclusion of this argument is a logical consequence of the premises because it is impossible for all the premises to be true while the conclusion false.

*Joint Truth Table for *a* ∧ *b* and *c*

::: {#o5 .table cue=table name="Joint Truth Table for a ∧ b and c"}

| *a* | *b* | *c* | *a* ∧ *b* | *c* |
|---|---|---|---|---|
| T | T | T | T | T |
| T | T | F | T | F |
| T | F | T | F | T |
| T | F | F | F | F |
| F | T | T | F | T |
| F | T | F | F | F |
| F | F | T | F | T |
| F | F | F | F | F |

:::

Reviewing the truth table, it turns out the conclusion of the argument is *not* a tautological consequence of the premise. Not every row that assigns T to the premise also assigns T to the conclusion. In particular, it is the second row that assigns T to *a* ∧ *b*, but does not assign T to *c*.

:::

## Denotation and properties {#Denotation_and_properties}

Tautological consequence can also be defined as $P_1$ ∧ $P_2$ ∧ ... ∧ $P_n$ → $Q$ is a substitution instance of a tautology, with the same effect.[^o7]

It follows from the definition that if a proposition *p* is a contradiction then *p* tautologically implies every proposition, because there is no truth valuation that causes *p* to be true and so the definition of tautological implication is trivially satisfied. Similarly, if *p* is a tautology then *p* is tautologically implied by every proposition.
