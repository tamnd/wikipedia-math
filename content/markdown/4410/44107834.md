# Signal magnitude area

::: {#o1 .subject cue=lead name="Signal magnitude area"}

In [mathematics](wikipedia://en/18831), the **signal magnitude area** (abbreviated **SMA** or **sma**) is a [statistical](wikipedia://en/26685) measure of the [magnitude](wikipedia://en/577301) of a varying quantity.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The SMA value of a set of values (or a [continuous-time](https://en.wikipedia.org/wiki/Continuous-time) [waveform](https://en.wikipedia.org/wiki/Waveform)) is the [normalized](wikipedia://en/2978513) [integral](wikipedia://en/15532) of the original values. [^o4][^o5]

In the case of a set of *n* values $\{x_1,x_2,\dots,x_n\}$ matching a time length *T*, the SMA

$$x_\text{sma} = \sum_{i=1}^n x_i$$

In the continuous domain, we have for example, with a 3-axis signal with an offset correction *a* for each axis, the following equation:[^o6]

$$f_\text{sma}= {1 \over T} \int_0^T |x(t)-a_x|+|y(t)-a_y|+|z(t)-a_z| \, dt$$

:::
