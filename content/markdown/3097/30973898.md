# Lambda-connectedness

::: {#o1 .subject cue=lead name="Lambda-connectedness"}

In [applied mathematics](wikipedia://en/24295969), **lambda-connectedness** (or **λ-connectedness**) deals with partial connectivity for a [discrete space](wikipedia://en/56061).

:::

Assume that a function on a discrete space (usually a [graph](wikipedia://en/325806)) is given. A degree of connectivity (connectedness) will be defined to measure the connectedness of the space with respect to the function. It was invented to create a new method for image [segmentation](https://en.wikipedia.org/wiki/Segmentation_%28image_processing%29). The method has expanded to handle other problems related to uncertainty for incomplete information analysis. [^o2][^o3]

For a [digital image](https://en.wikipedia.org/wiki/Digital_image) and a certain value of $\lambda$, two pixels are called $\lambda$-connected if there is a path linking those two pixels and the connectedness of this path is at least $\lambda$. $\lambda$-connectedness is an [equivalence relation](wikipedia://en/9259).[^o4]

## Background {#Background}

Connectedness is a basic measure in many areas of mathematical science and social sciences. In graph theory, two vertices are said to be connected if there is a path between them. In [topology](wikipedia://en/29954), two points are connected if there is a [continuous function](wikipedia://en/6122) that could move from one point to another continuously. In management science, for example, in an institution, two individuals are connected if one person is under the supervision of the other. Such connected relations only describe either full connection or no connection. lambda-connectedness is introduced to measure incomplete or fuzzy relations between two vertices, points, human beings, etc.

In fact, partial relations have been studied in other aspects. [Random graph](wikipedia://en/358477) theory allows one to assign a [probability](wikipedia://en/22934) to each edge of a graph. This method assumes, in most cases, each edge has the same probability. On the other hand, [Bayesian networks](https://en.wikipedia.org/wiki/Bayesian_networks) are often used for inference and analysis when relationships between each pair of states/events, denoted by vertices, are known. These relationships are usually represented by conditional probabilities among these vertices and are usually obtained from outside of the system.

$\lambda$-connectedness is based on graph theory; however, graph theory only deals with vertices and edges with or without weights. In order to define a partial, incomplete, or fuzzy connectedness, one needs to assign a function on the vertex in the graph. Such a function is called a potential function. It can be used to represent the intensity of an image, the surface of a *XY*-domain, or the utility function of a management or economic network.

## Basic concepts {#Basic_concepts}

A generalized definition of $\lambda$-connectedness can be described as follows: a simple system $\langle G,\rho\rangle$, where $\rho$ is called a potential function of $G$. If $\langle G,\rho\rangle$ is an image, then $G$ is a 2D or 2D grid space and $\rho$ is an intensity function. For a color image, one can use $f=(\text{red},\text{green},\text{blue})$ to represent $\rho$.

Neighbor connectivity will be first defined on a pair of adjacent points. Then one can define the general connectedness for any two points.

Assume $\alpha_\rho(x,y)$ is used to measure the neighbor-connectivity of x,y where x and y are adjacent. In graph *G* = (*V*, *E*), a finite sequence $x_1,x_2,\ldots,x_n$ is called a path, if $(x_i,x_{i+1})\in E$.

The path-connectivity $\beta$ of a path $\pi=\pi(x_1,x_n)=\{x_1,x_2,...,x_n\}$ is defined as

$$\beta_\rho(\pi(x_1,x_n)) = \min \{ \alpha_{\rho}(x_i,x_{i+1}) | i=1,\ldots,n-1 \}$$

Finally, the degree of connectedness (connectivity) of two vertices x,y with respect to $\rho$ is defined as

$$C_\rho(x,y) = \max \{ \beta(\pi(x,y)) | \pi \text { is a (simple) path}. \}$$

For a given $\lambda \in [0,1]$, point $p=(x,\rho(x))$ and $q=(y,\rho(y))$ are said to be $\lambda$-connected if $C_{\rho}(x,y)\ge \lambda$.

$\lambda$-connectedness is a equivalence relation. It can be used in image segmentation.

## Relations to Image Segmentation {#Relations_to_Image_Segmentation}

The lambda-connected segmentation is a region-growing segmentation method in general. It can also be made for split-and-merge segmentation.[^o8] Its [time complexity](wikipedia://en/405944) also reaches the optimum at $O(n log n )$ where $n$ is the number of pixels in the image.[^o9]

The lambda-connectedness has close relationships to [Data Science](wikipedia://en/35458904) that can be found in the Book entitled Mathematical Problems in Data Science.[^o10]

## New Developments {#New_Developments}

Researchers applied related techniques to smooth 3D [data processing](https://en.wikipedia.org/wiki/Data_processing) and transportation network management recently.[^o12][^o13]
