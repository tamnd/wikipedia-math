# Ahlfors finiteness theorem

::: {#o1 .subject cue=lead name="Ahlfors finiteness theorem"}

In the mathematical theory of [Kleinian groups](wikipedia://en/1362652), the **Ahlfors finiteness theorem** describes the quotient of the domain of discontinuity by a finitely generated Kleinian group. The theorem was proved by [Lars Ahlfors](wikipedia://en/61636),[^o2][^o3] apart from a gap that was filled by Greenberg.[^o4]

:::

The Ahlfors finiteness theorem states that if Γ is a finitely-generated Kleinian group with region of discontinuity Ω, then Ω/Γ has a finite number of components, each of which is a compact [Riemann surface](wikipedia://en/173181) with a finite number of points removed.

::: {#o6 .statement cue=named-heading name="Bers area inequality"}

## Bers area inequality {#Bers_area_inequality}

The **Bers area inequality** is a quantitative refinement of the Ahlfors finiteness theorem proved by Lipman Bers.[^o7] It states that if Γ is a non-elementary finitely-generated Kleinian group with *N* generators and with region of discontinuity Ω, then

Area(Ω/Γ) ≤ 4π(*N* − 1)

with equality only for [Schottky groups](wikipedia://en/5871034). (The area is given by the Poincaré metric in each component.) Moreover, if Ω<sub>1</sub> is an invariant component then

Area(Ω/Γ) ≤ 2Area(Ω<sub>1</sub>/Γ)

with equality only for [Fuchsian groups](wikipedia://en/471365) of the first kind (so in particular there can be at most two invariant components).

:::
