# Engel identity

::: {#o1 .subject cue=lead name="Engel identity"}

The **Engel identity**, named after [Friedrich Engel](wikipedia://en/5686283), is a mathematical equation that is satisfied by all elements of a [Lie ring](https://en.wikipedia.org/wiki/Lie_ring), in the case of an Engel Lie ring, or by all the elements of a [group](wikipedia://en/19447), in the case of an [Engel group](wikipedia://en/17228297). The Engel identity is the defining condition of an [Engel group](wikipedia://en/17228297).

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

A [Lie ring](https://en.wikipedia.org/wiki/Lie_ring) $L$ is defined as a [nonassociative ring](https://en.wikipedia.org/wiki/Nonassociative_ring) with multiplication that is [anticommutative](https://en.wikipedia.org/wiki/Anticommutative) and satisfies the [Jacobi identity](wikipedia://en/294370) with respect to the [Lie bracket](wikipedia://en/7193) $[x,y]$, defined for all elements $x,y$ in the ring $L$. The Lie ring $L$ is defined to be an n-Engel Lie ring if and only if

- for all $x, y$ in $L$, the n-Engel identity

$[x,[x, \ldots, [x,[x,y]]\ldots]] = 0$ (n copies of $x$), is satisfied.[^o4]

In the case of a [group](wikipedia://en/19447) $G$, in the preceding definition, use the definition \[*x*,*y*\] = *x*<sup>−1</sup> • *y*<sup>−1</sup> • *x* • *y* and replace $0$ by $1$, where $1$ is the identity element of the group $G$.[^o5]

:::
