# Telegraph process

::: {#o1 .subject cue=lead name="Telegraph process"}

In [probability theory](wikipedia://en/23542), the **telegraph process** is a [memoryless](wikipedia://en/772441) continuous-time [stochastic process](wikipedia://en/47895) that shows two distinct values. It models [burst noise](https://en.wikipedia.org/wiki/Burst_noise) (also called popcorn noise or random telegraph signal). If the two possible values that a [random variable](wikipedia://en/25685) can take are *$c_1$* and *$c_2$*, then the process can be described by the following [master equations](wikipedia://en/840106):

:::

$$\partial_t P(c_1, t|x, t_0)=-\lambda_1 P(c_1, t|x, t_0)+\lambda_2 P(c_2, t|x, t_0)$$

and

$$\partial_t P(c_2, t|x, t_0)=\lambda_1 P(c_1, t|x, t_0)-\lambda_2 P(c_2, t|x, t_0).$$

where $\lambda_1$ is the transition rate for going from state $c_1$ to state $c_2$ and $\lambda_2$ is the transition rate for going from going from state $c_2$ to state $c_1$. The process is also known under the names **Kac process** (after mathematician [Mark Kac](wikipedia://en/1062425)),[^o2] and **dichotomous random process**.[^o3]

## Solution {#Solution}

The master equation is compactly written in a matrix form by introducing a vector $\mathbf{P}=[P(c_1, t|x, t_0),P(c_2, t|x, t_0)]$,

$$\frac{d\mathbf P}{dt}=W\mathbf P$$

where

$$W=\begin{pmatrix} -\lambda_1 & \lambda_2 \\ \lambda_1 & -\lambda_2 \end{pmatrix}$$

is the [transition rate matrix](https://en.wikipedia.org/wiki/Transition_rate_matrix). The formal solution is constructed from the initial condition $\mathbf{P}(0)$ (that defines that at $t=t_0$, the state is $x$) by

$$\mathbf{P}(t) = e^{Wt}\mathbf{P}(0).$$

It can be shown that[^o5]

$$e^{Wt}= I+ W\frac{(1-e^{-2\lambda t})}{2\lambda}$$

where $I$ is the identity matrix and $\lambda=(\lambda_1+\lambda_2)/2$ is the average transition rate. As $t\rightarrow \infty$, the solution approaches a stationary distribution $\mathbf{P}(t\rightarrow \infty)=\mathbf{P}_s$ given by

$$\mathbf{P}_s= \frac{1}{2\lambda}\begin{pmatrix} \lambda_2 \\ \lambda_1 \end{pmatrix}$$

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Knowledge of an initial state [decays exponentially](wikipedia://en/330320). Therefore, for a time $t\gg (2\lambda)^{-1}$, the process will reach the following stationary values, denoted by subscript *s*:

Mean:

$$\langle X \rangle_s = \frac {c_1\lambda_2+c_2\lambda_1}{\lambda_1+\lambda_2}.$$

Variance:

$$\operatorname{var} \{ X \}_s = \frac {(c_1-c_2)^2\lambda_1\lambda_2}{(\lambda_1+\lambda_2)^2}.$$

One can also calculate a [correlation function](wikipedia://en/59500109):

$$\langle X(t),X(u)\rangle_s = e^{-2\lambda |t-u|}\operatorname{var} \{ X \}_s.$$

:::

## Application {#Application}

This random process finds wide application in model building:

- In [physics](wikipedia://en/22939), [spin systems](wikipedia://en/19593829) and [fluorescence](https://en.wikipedia.org/wiki/Fluorescence) [intermittency](https://en.wikipedia.org/wiki/Fluorescence_intermittency) show dichotomous properties. But especially in [single molecule experiments](https://en.wikipedia.org/wiki/Single_molecule_experiment) [probability distributions](wikipedia://en/23543) featuring [algebraic tails](https://en.wikipedia.org/wiki/Algebraic_tail) are used instead of the [exponential distribution](wikipedia://en/45906) implied in all formulas above.
- In [finance](https://en.wikipedia.org/wiki/Finance) for describing [share](https://en.wikipedia.org/wiki/Share_capital) prices[^o2]
- In [biology](https://en.wikipedia.org/wiki/Biology) for describing [transcription factor](https://en.wikipedia.org/wiki/Transcription_factor) binding and unbinding.
