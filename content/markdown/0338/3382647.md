# Barrier function

::: {#o1 .subject cue=lead name="Barrier function"}

In constrained [optimization](wikipedia://en/52033), a field of [mathematics](wikipedia://en/18831), a **barrier function** is a [continuous function](wikipedia://en/6122) whose value increases to infinity as its argument approaches the boundary of the [feasible region](https://en.wikipedia.org/wiki/Candidate_solution) of an optimization problem.[^o2][^o3] Such functions are used to replace inequality [constraints](wikipedia://en/7418540) by a penalizing term in the objective function that is easier to handle. A barrier function is also called an **interior penalty function**, as it is a penalty function that forces the solution to remain within the interior of the feasible region.

:::

The two most common types of barrier functions are [inverse barrier functions](https://en.wikipedia.org/wiki/Inverse_barrier_function) and [logarithmic](wikipedia://en/17860) barrier functions. Resumption of interest in logarithmic barrier functions was motivated by their connection with primal-dual [interior point methods](https://en.wikipedia.org/wiki/Interior_point_method).

## Motivation {#Motivation}

Consider the following constrained optimization problem:

minimize $f(x)$

subject to $x \le b$

where $b$ is some constant. If one wishes to remove the inequality constraint, the problem can be reformulated as

minimize $f(x) + c(x)$,

where $c(x) = \infty$ if $x > b$, and zero otherwise.

This problem is equivalent to the first. It gets rid of the inequality, but introduces the issue that the penalty function $c$, and therefore the objective function $f(x) + c(x)$, is [discontinuous](https://en.wikipedia.org/wiki/Discontinuous_function), preventing the use of [calculus](wikipedia://en/5176) to solve it.

A barrier function, now, is a continuous approximation $g$ to $c$ that tends to infinity as $x$ approaches $b$ from below. Using such a function, a new optimization problem is formulated, viz.

minimize $f(x) + \mu\,g(x)$

where $\mu > 0$ is a free parameter. This problem is not equivalent to the original, but as $\mu$ approaches zero, it becomes an ever-better approximation.[^o5]

## Logarithmic barrier function {#Logarithmic_barrier_function}

For logarithmic barrier functions, $g(x,b)$ is defined as $-\!\log(b-x)$ when $x < b$ and $\infty$ otherwise (in one dimension; see below for a definition in higher dimensions). This essentially relies on the fact that $\log t$ tends to negative infinity as $t$ tends to 0.

This introduces a gradient to the function being optimized which favors less extreme values of $x$ (in this case, values lower than $b$), while having relatively low impact on the function away from these extremes.

Logarithmic barrier functions may be favored over less computationally expensive [inverse barrier functions](https://en.wikipedia.org/wiki/Inverse_barrier_functions) depending on the function being optimized.

### Higher dimensions {#Higher_dimensions}

Extending to higher dimensions is simple, provided each dimension is independent. For each variable $x_i$ which should be limited to be strictly lower than $b_i$, add $-\!\log(b_i - x_i)$.

::: {#o9 .definition cue=heading name="Formal definition"}

### Formal definition {#Formal_definition}

Minimize $\mathbf c^Tx$ subject to $\mathbf a_i^T x \le b_i, i = 1,\ldots,m$

Assume strictly feasible: $\{\mathbf x \mid A x < b\}\ne\emptyset$

Define **logarithmic barrier** $g(x) = \begin{cases} \sum_{i=1}^m -\!\log(b_i - a_i^Tx) & \text{for } Ax<b \\ +\infty & \text{otherwise} \end{cases}$

:::
