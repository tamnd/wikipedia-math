# Message authentication

::: {#o1 .subject cue=lead name="Message authentication"}

In [information security](wikipedia://en/15036), **message authentication** or **data origin authentication** is a property that a message has not been modified while in transit ([data integrity](https://en.wikipedia.org/wiki/Data_integrity)) and that the receiving party can verify the source of the message.[^o2]

:::

## Description {#Description}

Message authentication or data origin authentication is an [information security](wikipedia://en/15036) property that indicates that a message has not been modified while in transit ([data integrity](https://en.wikipedia.org/wiki/Data_integrity)) and that the receiving party can verify the source of the message.[^o2] Message [authentication](wikipedia://en/47967) does not necessarily include the property of [non-repudiation](wikipedia://en/52491).[^o4][^o5]

## Techniques {#Techniques}

Message authentication is typically achieved by using [message authentication codes](wikipedia://en/567523) (MACs), [authenticated encryption](wikipedia://en/2244296) (AE), or [digital signatures](wikipedia://en/59644).[^o4] The message authentication code, also known as digital authenticator, is used as an integrity check based on a secret key shared by two parties to authenticate information transmitted between them.[^o7] It is based on using a [cryptographic hash](wikipedia://en/439526) or [symmetric encryption algorithm](wikipedia://en/53042).[^o8] The authentication key is only shared by exactly two parties (e.g. communicating devices), and the authentication will fail in the existence of a third party possessing the key since the [algorithm](wikipedia://en/775) will no longer be able to detect [forgeries](https://en.wikipedia.org/wiki/Forgery) (i.e. to be able to validate the unique source of the message).[^o9] In addition, the key must also be randomly generated to avoid its recovery through brute-force searches and related-key attacks designed to identify it from the messages transiting the medium.[^o9]

Some cryptographers distinguish between "message authentication without secrecy" systems – which allow the intended receiver to verify the source of the message, but they don't bother hiding the plaintext contents of the message – from [authenticated encryption](wikipedia://en/2244296) systems.[^o10] Some cryptographers have researched [subliminal channel](wikipedia://en/23723266) systems that send messages that appear to use a "message authentication without secrecy" system, but in fact also transmit a secret message.

## Related concepts {#Related_concepts}

Data origin authentication and non-repudiation have been also studied in the framework of quantum cryptography.[^o12][^o13]
