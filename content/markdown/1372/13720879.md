# Trendalyzer

::: {#o2 .subject cue=lead name="Trendalyzer"}

**Trendalyzer** is an [information visualization](https://en.wikipedia.org/wiki/Information_visualization) software program for [animation](https://en.wikipedia.org/wiki/Animation) of [statistics](wikipedia://en/26685) that was initially developed by [Hans Rosling](https://en.wikipedia.org/wiki/Hans_Rosling)'s [Gapminder Foundation](https://en.wikipedia.org/wiki/Gapminder_Foundation) in Sweden. In March 2007, it was acquired by [Google Inc.](https://en.wikipedia.org/wiki/Google_Inc.)[^o3] The current beta version is a [Flash](https://en.wikipedia.org/wiki/Adobe_Flash) application that is preloaded with statistical and historical data about the development of the countries of the world.

:::

The [information visualization](https://en.wikipedia.org/wiki/Information_visualization) technique used by Trendalyzer is an interactive [bubble chart](https://en.wikipedia.org/wiki/Bubble_chart). By default it shows five variables: Two numeric variables on the X and Y axes, bubble size and colour, and a time variable that may be manipulated with a slider. The software uses [brushing and linking](wikipedia://en/20349155) techniques for displaying the numeric value of a highlighted country.

Components of the Trendalyzer software, particularly the Flash-based Motion Chart gadget, have become available for public use as part of the Google Visualizations API (see <https://code.google.com/apis/visualization/documentation/gadgetgallery.html> ).
