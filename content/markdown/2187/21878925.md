# Stiffness matrix

::: {#o1 .subject cue=lead name="Stiffness matrix"}

In the [finite element method](wikipedia://en/18233581) for the numerical solution of elliptic [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations), the **stiffness matrix** is a [matrix](wikipedia://en/20556859) that represents the [system of linear equations](wikipedia://en/113087) that must be solved in order to ascertain an approximate solution to the differential equation.

:::

## The stiffness matrix for the Poisson problem {#The_stiffness_matrix_for_the_Poisson_problem}

For simplicity, we will first consider the [Poisson problem](https://en.wikipedia.org/wiki/Poisson_problem)

$$-\nabla^2 u = f$$

on some domain $\Omega$, subject to the boundary condition $u = 0$ on the boundary of $\Omega$. To discretize this equation by the [finite element method](wikipedia://en/18233581), one chooses a set of *[basis functions](wikipedia://en/50909)* $\{\varphi_{1}, \ldots, \varphi_{n}\}$ defined on $\Omega$ which also vanish on the boundary. One then approximates

$$u \approx u^h = u_1\varphi_1+\cdots+u_n\varphi_n.$$

The coefficients $u_{1}, u_{2}, \ldots, u_{n}$ are determined so that the error in the approximation is orthogonal to each basis function $\varphi_{i}$:

$$\int_{\Omega} \varphi_i\cdot f \, dx = -\int_{\Omega} \varphi_i\nabla^2u^h \, dx = -\sum_j\left(\int_{\Omega} \varphi_i\nabla^2\varphi_j\,dx\right)\, u_j = \sum_j\left(\int_{\Omega} \nabla\varphi_i\cdot\nabla\varphi_j\, dx\right)u_j.$$

as a consequence of the homogenous [Dirichlet boundary conditions](wikipedia://en/423504). The **stiffness matrix** is the $n$-element [square matrix](wikipedia://en/166022) $\mathbf{A}$ defined by

$$\mathbf A_{ij} = \int_{\Omega} \nabla\varphi_i\cdot\nabla\varphi_j\, dx.$$

By defining the *load vector* $\mathbf{F}$ with components $\mathbf F_i = \int_\Omega\varphi_i f\,dx,$ the coefficients $u_{i}$ are determined by the linear system $\mathbf{Au} = \mathbf{F}$. The stiffness matrix is [symmetric](wikipedia://en/126474), i.e. $\mathbf{A}_{ij} = \mathbf{A}_{ji}$, so all its [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) are real. Moreover, it is a strictly [positive-definite matrix](https://en.wikipedia.org/wiki/Positive-definite_matrix), so that the system $\mathbf{Au} = \mathbf{F}$ always has a unique solution. (For other problems, these nice properties will be lost.)

Note that the stiffness matrix will be different depending on the computational grid used for the domain and what type of finite element is used. For example, the stiffness matrix when piecewise quadratic finite elements are used will have more degrees of freedom than piecewise linear elements.

## The stiffness matrix for other problems {#The_stiffness_matrix_for_other_problems}

Determining the stiffness matrix for other PDEs follows essentially the same procedure, but it can be complicated by the choice of boundary conditions. As a more complex example, consider the [elliptic equation](wikipedia://en/10225)

$$-\sum_{k,l}\frac{\partial}{\partial x_k}\left(a^{kl}\frac{\partial u}{\partial x_l}\right)= f$$

where $\mathbf A(x) = a^{kl}(x)$ is a positive-definite matrix defined for each point $x$ in the domain. We impose the [Robin boundary condition](wikipedia://en/9945920)

$$-\sum_{k,l}\nu_k a^{kl}\frac{\partial u}{\partial x_l} = c(u-g),$$

where $\nu_{k}$ is the component of the unit outward [normal vector](https://en.wikipedia.org/wiki/Normal_vector) $\nu$ in the $k$-th direction. The system to be solved is

$$\sum_j\left(\sum_{k,l}\int_\Omega a^{kl}\frac{\partial\varphi_i}{\partial x_k}\frac{\partial\varphi_j}{\partial x_l}dx+\int_{\partial\Omega}c\varphi_i\varphi_j\, ds\right)u_j = \int_\Omega\varphi_i f\, dx+\int_{\partial\Omega}c\varphi_i g\, ds,$$

as can be shown using an analogue of [Green's identity](https://en.wikipedia.org/wiki/Green's_identity). The coefficients $u_{i}$ are still found by solving a system of linear equations, but the matrix representing the system is markedly different from that for the ordinary Poisson problem.

In general, to each scalar [elliptic operator](wikipedia://en/550137) $L$ of order $2k$, there is associated a [bilinear form](wikipedia://en/449477) $B$ on the [Sobolev space](wikipedia://en/611964) $H^{k}$, so that the [weak formulation](wikipedia://en/3368981) of the equation $Lu = f$ is

$$B[u,v] = (f,v)$$

for all functions $v$ in $H^{k}$. Then the stiffness matrix for this problem is

$$\mathbf A_{ij} = B[\varphi_j,\varphi_i].$$

## Practical assembly of the stiffness matrix {#Practical_assembly_of_the_stiffness_matrix}

In order to implement the finite element method on a computer, one must first choose a set of basis functions and then compute the integrals defining the stiffness matrix. Usually, the domain $\Omega$ is [discretized](https://en.wikipedia.org/wiki/Discretized) by some form of [mesh generation](wikipedia://en/3050716), wherein it is divided into non-overlapping [triangles](https://en.wikipedia.org/wiki/Triangle_mesh) or [quadrilaterals](wikipedia://en/37667343), which are generally referred to as elements. The basis functions are then chosen to be [polynomials](wikipedia://en/23000) of some order within each element, and continuous across element boundaries. The simplest choices are [piecewise linear](wikipedia://en/444224) for triangular elements and piecewise bilinear for rectangular elements.

The **element stiffness matrix** $\mathbf{A}^{[k]}$ for element $T_{k}$ is the matrix

$$\mathbf A^{[k]}_{ij} = \int_{T_k}\nabla\varphi_i\cdot\nabla\varphi_j\, dx.$$

The element stiffness matrix is zero for most values of $i$ and $j$, for which the corresponding basis functions are zero within $T_{k}$. The full stiffness matrix $\mathbf{A}$ is the sum of the element stiffness matrices. In particular, for basis functions that are only supported locally, the stiffness matrix is [sparse](wikipedia://en/341015).

For many standard choices of basis functions, i.e. piecewise linear basis functions on triangles, there are simple formulas for the element stiffness matrices. For example, for piecewise linear elements, consider a triangle with vertices $(x_{1}, y_{1})$, $(x_{2}, y_{2})$, $(x_{3}, y_{3})$, and define the 2×3 matrix

$$\mathbf D = \left[\begin{matrix}x_3 - x_2 & x_1 - x_3 & x_2 - x_1 \\ y_3 - y_2 & y_1 - y_3 & y_2 - y_1\end{matrix}\right].$$

Then the element stiffness matrix is

$$\mathbf A^{[k]} = \frac{\mathbf D^\mathsf{T} \mathbf D}{4\operatorname{area}(T)}.$$

When the differential equation is more complicated, say by having an inhomogeneous diffusion coefficient, the integral defining the element stiffness matrix can be evaluated by [Gaussian quadrature](wikipedia://en/50579).

The [condition number](wikipedia://en/6934) of the stiffness matrix depends strongly on the quality of the numerical grid. In particular, triangles with small angles in the finite element mesh induce large eigenvalues of the stiffness matrix, degrading the solution quality.
