# Representable functor

::: {#o1 .subject cue=lead name="Representable functor"}

In [mathematics](wikipedia://en/18831), particularly [category theory](wikipedia://en/5869), a **representable functor** is a certain [functor](wikipedia://en/10987) from an arbitrary [category](wikipedia://en/53759) into the [category of sets](wikipedia://en/26829). Such functors give representations of an abstract category in terms of known structures (i.e. [sets](wikipedia://en/26691) and [functions](wikipedia://en/185427)) allowing one to utilize, as much as possible, knowledge about the category of sets in other settings.

:::

From another point of view, representable functors for a category *C* are the functors *given* with *C*. Their theory is a vast generalisation of [upper sets](https://en.wikipedia.org/wiki/Upper_set) in [posets](https://en.wikipedia.org/wiki/Poset), and [Yoneda's representability](wikipedia://en/34359) theorem generalizes [Cayley's theorem](wikipedia://en/105967) in [group theory](wikipedia://en/41890).

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\mathcal{C}$ be a [locally small category](https://en.wikipedia.org/wiki/Locally_small_category) and let $\mathbf{Set}$ be the [category of sets](wikipedia://en/26829). For each object $A$ of $\mathcal{C}$ let $\operatorname{Hom}(A,-)$ be the [hom functor](wikipedia://en/2741037) that maps object $X$ to the set $\operatorname{Hom}(A,X)$.

A [functor](wikipedia://en/10987) $F:\mathcal{C}\rightarrow\mathbf{Set}$ is said to be **representable** if it is [naturally isomorphic](https://en.wikipedia.org/wiki/Naturally_isomorphic) to $\operatorname{Hom}(A,-)$ for some object $A$ of $\mathcal{C}$. A **representation** of $F$ is a pair $(A,\Phi)$ where

$$\Phi:\operatorname{Hom}(A,-)\rightarrow F$$

is a natural isomorphism.

A [contravariant functor](https://en.wikipedia.org/wiki/Contravariant_functor) $G$ from $\mathcal{C}$ to $\mathbf{Set}$ is the same thing as a functor $G:\mathcal{C}^{\text{op}}\rightarrow\mathbf{Set}$ and is commonly called a [presheaf](wikipedia://en/4840944). A presheaf is representable when it is naturally isomorphic to the contravariant hom-functor $\operatorname{Hom}(-,A)$ for some object $A$ of $\mathcal{C}$.

:::

## Universal elements {#Universal_elements}

According to [Yoneda's lemma](https://en.wikipedia.org/wiki/Yoneda's_lemma), natural transformations from Hom(*A*,–) to *F* are in one-to-one correspondence with the elements of *F*(*A*). Given a natural transformation Φ : Hom(*A*,–) → *F* the corresponding element *u* ∈ *F*(*A*) is given by

$$u = \Phi_A(\mathrm{id}_A).\,$$

Conversely, given any element *u* ∈ *F*(*A*) we may define a natural transformation Φ : Hom(*A*,–) → *F* via

$$\Phi_X(f) = (Ff)(u)\,$$

where *f* is an element of Hom(*A*,*X*). In order to get a representation of *F* we want to know when the natural transformation induced by *u* is an isomorphism. This leads to the following definition:

A **universal element** of a functor *F* : **C** → **Set** is a pair (*A*,*u*) consisting of an object *A* of **C** and an element *u* ∈ *F*(*A*) such that for every pair (*X*,*v*) consisting of an object *X* of **C** and an element *v* ∈ *F*(*X*) there exists a unique morphism *f* : *A* → *X* such that (*Ff*)(*u*) = *v*.

A universal element may be viewed as a [universal morphism](https://en.wikipedia.org/wiki/Universal_morphism) from the one-point set {•} to the functor *F* or as an [initial object](https://en.wikipedia.org/wiki/Initial_object) in the [category of elements](wikipedia://en/4877413) of *F*.

The natural transformation induced by an element *u* ∈ *F*(*A*) is an isomorphism if and only if (*A*,*u*) is a universal element of *F*. We therefore conclude that representations of *F* are in one-to-one correspondence with universal elements of *F*. For this reason, it is common to refer to universal elements (*A*,*u*) as representations.

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

- Consider the contravariant functor *P* : **Set** → **Set** which maps each set to its [power set](wikipedia://en/23799) and each function to its [inverse image](https://en.wikipedia.org/wiki/Inverse_image) map. To represent this functor we need a pair (*A*,*u*) where *A* is a set and *u* is a subset of *A*, i.e. an element of *P*(*A*), such that for all sets *X*, the hom-set Hom(*X*,*A*) is isomorphic to *P*(*X*) via Φ<sub>*X*</sub>(*f*) = (*Pf*)*u* = *f*<sup>−1</sup>(*u*). Take *A* = {0,1} and *u* = {1}. Given a subset *S* ⊆ *X* the corresponding function from *X* to *A* is the [characteristic function](wikipedia://en/240790) of *S*.
- [Forgetful functors](wikipedia://en/844783) to **Set** are very often representable. In particular, a forgetful functor is represented by (*A*, *u*) whenever *A* is a [free object](wikipedia://en/333835) over a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) with generator *u*.
  - The forgetful functor **Grp** → **Set** on the [category of groups](wikipedia://en/800092) is represented by (**Z**, 1).
  - The forgetful functor **Ring** → **Set** on the [category of rings](wikipedia://en/15300181) is represented by (**Z**\[*x*\], *x*), the [polynomial ring](wikipedia://en/373065) in one [variable](wikipedia://en/3728109) with [integer](wikipedia://en/14563) [coefficients](wikipedia://en/51203).
  - The forgetful functor *A*-**Mod** → **Set** on the [category of modules](wikipedia://en/11231812) over a ring *A* is represented by (*A*, 1).
  - The forgetful functor **Top** → **Set** on the [category of topological spaces](wikipedia://en/435051) is represented by any singleton topological space with its unique element.
- A [group](wikipedia://en/19447) *G* can be considered a category (even a [groupoid](wikipedia://en/12543)) with one object which we denote by •. A functor from *G* to **Set** then corresponds to a [*G*-set](https://en.wikipedia.org/wiki/G-set). The unique hom-functor Hom(•,–) from *G* to **Set** corresponds to the canonical *G*-set *G* with the action of left multiplication. Standard arguments from group theory show that a functor from *G* to **Set** is representable if and only if the corresponding *G*-set is simply transitive (i.e. a [*G*-torsor](https://en.wikipedia.org/wiki/Torsor) or [heap](wikipedia://en/6386360)). Choosing a representation amounts to choosing an identity for the heap.
- Let *R* be a commutative ring with identity, and let **R**-**Mod** be the category of *R*-modules. If *M* and *N* are unitary modules over *R*, there is a covariant functor *B*: **R**-**Mod** → **Set** which assigns to each *R*-module *P* the set of *R*-bilinear maps *M* × *N* → *P* and to each *R*-module homomorphism *f* : *P* → *Q* the function *B*(*f*) : *B*(*P*) → *B*(*Q*) which sends each bilinear map *g* : *M* × *N* → *P* to the bilinear map *f*∘*g* : *M* × *N*→*Q*. The functor *B* is represented by the *R*-module *M* ⊗<sub>*R*</sub> *N*.[^o7]
- The [functor represented by a scheme](wikipedia://en/45399927) *A* can sometimes describe families of geometric objects*.* For example, [vector bundles](wikipedia://en/276524) of rank *k* over a given algebraic variety or scheme *X* correspond to algebraic morphisms $X\to A$ where *A* is the [Grassmannian](wikipedia://en/373810) of *k*-planes in a high-dimensional space. Also certain types of subschemes are represented by [Hilbert schemes](wikipedia://en/6612581).
- Let *C* be the category of [CW-complexes](https://en.wikipedia.org/wiki/CW-complex) with morphisms given by homotopy classes of continuous functions. For each natural number *n* there is a contravariant functor *H*<sup>*n*</sup> : *C* → **Ab** which assigns each CW-complex its *n*<sup>th</sup> [cohomology group](https://en.wikipedia.org/wiki/Cohomology_group) (with integer coefficients). Composing this with the [forgetful functor](wikipedia://en/844783) we have a contravariant functor from *C* to **Set**. [Brown's representability theorem](wikipedia://en/1073746) in algebraic topology says that this functor is represented by a CW-complex *K*(**Z**,*n*) called an [Eilenberg–MacLane space](wikipedia://en/1073230).

:::

## Analogy: Representable functionals {#Analogy:_Representable_functionals}

Consider a linear functional on a complex [Hilbert space](wikipedia://en/20598932) *H*, i.e. a linear function $F: H\to\mathbb C$. The [Riesz representation theorem](wikipedia://en/26452) states that if *F* is continuous, then there exists a unique element $a\in H$ which represents *F* in the sense that *F* is equal to the inner product functional $\langle a, -\rangle$, that is $F(v) = \langle a,v\rangle$ for $v\in H$.

For example, the continuous linear functionals on the [square-integrable function space](wikipedia://en/28680558) $H = L^2(\mathbb R)$ are all representable in the form $\textstyle F(v) = \langle a,v\rangle = \int_{\mathbb R} a(x)v(x)\,dx$ for a unique function $a(x)\in H$. The theory of [distributions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) considers more general continuous functionals on the space of test functions $C=C^\infty_c(\mathbb R)$. Such a distribution functional is not necessarily representable by a function, but it may be considered intuitively as a generalized function. For instance, the [Dirac delta function](wikipedia://en/37021) is the distribution defined by $F(v) = v(0)$ for each test function $v(x)\in C$, and may be thought of as "represented" by an infinitely tall and thin bump function near $x=0$.

Thus, a function $a(x)$ may be determined not by its values, but by its effect on other functions via the inner product. Analogously, an object *A* in a category may be characterized not by its internal features, but by its [functor of points](wikipedia://en/45399927), i.e. its relation to other objects via morphisms. Just as non-representable functionals are described by distributions, non-representable functors may be described by more complicated structures such as [stacks](wikipedia://en/13185596).

## Properties {#Properties}

### Uniqueness {#Uniqueness}

Representations of functors are unique up to a unique isomorphism. That is, if (*A*<sub>1</sub>,Φ<sub>1</sub>) and (*A*<sub>2</sub>,Φ<sub>2</sub>) represent the same functor, then there exists a unique isomorphism φ : *A*<sub>1</sub> → *A*<sub>2</sub> such that

$$\Phi_1^{-1}\circ\Phi_2 = \mathrm{Hom}(\varphi,-)$$

as natural isomorphisms from Hom(*A*<sub>2</sub>,–) to Hom(*A*<sub>1</sub>,–). This fact follows easily from [Yoneda's lemma](https://en.wikipedia.org/wiki/Yoneda's_lemma).

Stated in terms of universal elements: if (*A*<sub>1</sub>,*u*<sub>1</sub>) and (*A*<sub>2</sub>,*u*<sub>2</sub>) represent the same functor, then there exists a unique isomorphism φ : *A*<sub>1</sub> → *A*<sub>2</sub> such that

$$(F\varphi)u_1 = u_2.$$

### Preservation of limits {#Preservation_of_limits}

Representable functors are naturally isomorphic to Hom functors and therefore share their properties. In particular, (covariant) representable functors [preserve all limits](wikipedia://en/39248#Preservation_of_limits). It follows that any functor which fails to preserve some limit is not representable.

Contravariant representable functors take colimits to limits.

### Left adjoint {#Left_adjoint}

Any functor *K* : *C* → **Set** with a [left adjoint](https://en.wikipedia.org/wiki/Left_adjoint) *F* : **Set** → *C* is represented by (*FX*, η<sub>*X*</sub>(•)) where *X* = {•} is a [singleton set](https://en.wikipedia.org/wiki/Singleton_set) and η is the unit of the adjunction.

Conversely, if *K* is represented by a pair (*A*, *u*) and all small [copowers](https://en.wikipedia.org/wiki/Copower) of *A* exist in *C* then *K* has a left adjoint *F* which sends each set *I* to the *I*th copower of *A*.

Therefore, if *C* is a category with all small copowers, a functor *K* : *C* → **Set** is representable if and only if it has a left adjoint.

:::

## Relation to universal morphisms and adjoints {#Relation_to_universal_morphisms_and_adjoints}

The categorical notions of [universal morphisms](https://en.wikipedia.org/wiki/Universal_morphism) and [adjoint functors](https://en.wikipedia.org/wiki/Adjoint_functor) can both be expressed using representable functors.

Let *G* : *D* → *C* be a functor and let *X* be an object of *C*. Then (*A*,φ) is a universal morphism from *X* to *G* [if and only if](wikipedia://en/14922) (*A*,φ) is a representation of the functor Hom<sub>*C*</sub>(*X*,*G*–) from *D* to **Set**. It follows that *G* has a left-adjoint *F* if and only if Hom<sub>*C*</sub>(*X*,*G*–) is representable for all *X* in *C*. The natural isomorphism Φ<sub>*X*</sub> : Hom<sub>*D*</sub>(*FX*,–) → Hom<sub>*C*</sub>(*X*,*G*–) yields the adjointness; that is

$$\Phi_{X,Y}\colon \mathrm{Hom}_{\mathcal D}(FX,Y) \to \mathrm{Hom}_{\mathcal C}(X,GY)$$

is a bijection for all *X* and *Y*.

The dual statements are also true. Let *F* : *C* → *D* be a functor and let *Y* be an object of *D*. Then (*A*,φ) is a universal morphism from *F* to *Y* if and only if (*A*,φ) is a representation of the functor Hom<sub>*D*</sub>(*F*–,*Y*) from *C* to **Set**. It follows that *F* has a right-adjoint *G* if and only if Hom<sub>*D*</sub>(*F*–,*Y*) is representable for all *Y* in *D*.[^o15]
