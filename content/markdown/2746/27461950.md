# Invariant extended Kalman filter

::: {#o1 .subject cue=lead name="Invariant extended Kalman filter"}

The **invariant extended Kalman filter (IEKF)** (not to be confused with the iterated extended Kalman filter) was first introduced as a version of the [extended Kalman filter](wikipedia://en/18436459) (EKF) for nonlinear systems possessing symmetries (or *[invariances](https://en.wikipedia.org/wiki/Invariance_%28mathematics%29)*),[^o2] then generalized and recast as an adaptation to [Lie groups](wikipedia://en/17945) of the [linear Kalman filtering theory](wikipedia://en/180855).[^o3][^o4] Instead of using a linear correction term based on a linear output error, the IEKF uses a geometrically adapted correction term based on an invariant output error; in the same way the [gain](https://en.wikipedia.org/wiki/Kalman_gain) matrix is not updated from a linear state error, but from an invariant state error. The main benefit is that the gain and covariance equations have reduced dependence on the estimated value of the state. In some cases they converge to constant values on a much bigger set of trajectories than is the case for the EKF, which results in a better convergence of the estimation.

:::

## Filter derivation {#Filter_derivation}

### Discrete-time framework {#Discrete-time_framework}

Consider a system whose [state](https://en.wikipedia.org/wiki/State_space) is encoded at time step $n$ by an element $x_n$ of a [Lie group](wikipedia://en/17945) $G$ and dynamics has the following shape:[^o7]

$$x_n = \phi_n(x_{n-1}) \cdot u_n$$

where $\phi_n$ is a [group automorphism](https://en.wikipedia.org/wiki/Group_automorphism) of $G$, $\cdot$ is the group operation and $u_n$ an element of $G$. The system is supposed to be observed through a measurement $y_n$ having the following shape:

$$y_n = x_n * b_n$$

where $b_n$ belongs to a vector space $\mathcal{Y}$ endowed with a [left action](wikipedia://en/12781) of the elements of $G$ denoted again by $*$ (which cannot create confusion with the group operation as the second member of the operation is an element of $\mathcal{Y}$, not $G$). Alternatively, the same theory applies to a measurement defined by a [right action](wikipedia://en/12781):

$$y_n = b_n * x_n$$

### Filter equations {#Filter_equations}

The invariant extended Kalman filter is an observer $\hat{x}_n$ defined by the following equations if the measurement function is a left action:

$$\hat{x}_{n|n-1} = \phi_n(\hat{x}_{n-1|n-1}) \cdot u_n$$

$$\hat{x}_{n|n} = \hat{x}_{n|n-1} \cdot \exp(K_n (\hat{x}_{n|n-1}^{-1} * y_n-b_n))$$

where $\exp()$ is the [exponential map](wikipedia://en/44612290) of $G$ and $K_n$ is a gain matrix to be tuned through a [Riccati equation](wikipedia://en/304999).

If measurement function is a right action then the update state is defined as:

$$\hat{x}_{n|n} = \exp(K_n (y_n * \hat{x}_{n|n-1}^{-1}-b_n)) \cdot \hat{x}_{n|n-1}$$

### Continuous-time framework {#Continuous-time_framework}

The discrete-time framework above was first introduced for continuous-time dynamics of the shape:

$$\frac{d}{dt} x_t = f_t(x_t),$$

where the [vector field](wikipedia://en/62641) $f_t$ verifies at any time $t$ the relation:[^o3]

$$\forall a,b \in G, f_t(a \cdot b) = f_t(a) b + a f_t(b) - a f(Id)b$$

where the identity element of the group is denoted by $Id$ and is used the short-hand notation $g u = L_g(u)$ (resp. $u g = R_g(u)$) for the left translation $L_g: TG_x \rightarrow TG_{gx}$ (resp. the right translation $R_g: TG_x \rightarrow TG_{xg}$) where $TG_x$ denotes the [tangent space](wikipedia://en/30807) to $G$ at $x$. It leads to more involved computations than the discrete-time framework, but properties are similar.

## Main properties {#Main_properties}

The main benefit of invariant extended Kalman filtering is the behavior of the invariant error variable, whose definition depends on the type of measurement. For left actions we define a left-invariant error variable as:

$$e^L_{n|n-1} = \hat{x}_{n|n-1}^{-1} x_n,$$

$$e^L_{n|n} = \hat{x}_{n|n}^{-1} x_n,$$

while for right actions we define a right-invariant error variable as:

$$e^R_{n|n-1} = x_n \hat{x}_{n|n-1}^{-1},$$

$$e^R_{n|n} = x_n \hat{x}_{n|n}^{-1},$$

Indeed, replacing $x_n$, $\hat{x}_{n|n-1}$, $\hat{x}_{n|n}$ by their values we obtain for left actions, after some algebra:

$$e^L_{n|n-1} = u_n^{-1} \cdot \phi_n(e^L_{n-1|n-1}) \cdot u_n,$$

$$e^L_{n|n} = \exp(-K_n(e^L_{n|n-1} * b_n-b_n)) \cdot e^L_{n|n-1},$$

and for right actions:

$$e^R_{n|n-1} = \phi_n(e^R_{n-1|n-1}),$$

$$e^R_{n|n} = e^R_{n|n-1} \exp(-K_n(b_n * e^R_{n|n-1}-b_n)),$$

We see the estimated value of the state is not involved in the equation followed by the error variable, a property of [linear Kalman filtering](https://en.wikipedia.org/wiki/Kalman_filtering) the classical [extended Kalman filter](wikipedia://en/18436459) does not share, but the similarity with the linear case actually goes much further. Let $\xi_{n|n-1}, \xi_{n|n}$ be a linear version of the error variable defined by the identity:

$$e_{n|n-1} = \exp(\xi_{n|n-1}),$$

$$e_{n|n} = \exp(\xi_{n|n}).$$

Then, with $F_n$ defined by the [Taylor expansion](https://en.wikipedia.org/wiki/Taylor_expansion) $\xi_{n|n} = F_n \xi_{n|n-1} + \circ(||\xi_{n|n-1}||)$ we actually have:[^o3]

$$\xi_{n|n} = F_n\xi_{n|n-1}.$$

In other words, there are no higher-order terms: the dynamics is linear for the error variable $\xi_{n|n}, \xi_{n|n-1}$. This result and error dynamics independence are at the core of theoretical properties and practical performance of IEKF.[^o3]

## Relation to symmetry-preserving observers {#Relation_to_symmetry-preserving_observers}

Most physical systems possess natural symmetries (or invariance), i.e. there exist transformations (e.g. rotations, translations, scalings) that leave the system unchanged. From mathematical and engineering viewpoint, it makes sense that a filter well-designed for the considered system should preserve the same invariance properties. The idea for the IEKF is a modification of the EKF equations to take advantage of the symmetries of the system.

::: {#o13 .definition cue=heading name="Definition"}

### Definition {#Definition}

Consider the system

$$\dot{x}{=}f(x,u)+M(x) w$$

$$y {=}h(x,u) +N(x)v$$

where $w,v$ are independent [white Gaussian noises](https://en.wikipedia.org/wiki/White_Gaussian_noise). Consider $G$ a [Lie group](wikipedia://en/17945) with identity $e$, and (local) [transformation groups](https://en.wikipedia.org/wiki/Transformation_group) $\varphi_g, \psi_g, \rho_g$ ($g \in G$) such that $(X,U,Y)=(\varphi_g(x),\psi_g(u),\rho_g(y))$. The previous system with noise is said to be *[invariant](wikipedia://en/1126638)* if it is left unchanged by the action the transformations groups $\varphi_g, \psi_g, \rho_g$; that is, if

$$\dot X{=}f(X,U)+M(X) w.$$

$$Y{=}h(X,U) +N(X)v$$

:::

### Filter equations and main result {#Filter_equations_and_main_result}

Since it is a [symmetry-preserving filter](wikipedia://en/27428429), the general form of an IEKF reads[^o15]

$$\dot{\hat x}=f(\hat x,u) +W(\hat x)L\Bigl(I(\hat x,u),E(\hat x,u,y)\Bigr)E(\hat x,u,y)$$

where

- $E(\hat x,u,y)$ is an invariant output error, which is different from the usual output error $\hat y-y$
- $W(\hat x)=\bigl(w_1(\hat x),..,w_n(\hat x)\bigr)$ is an invariant frame
- $I(\hat x,u)$ is an invariant vector
- $L(I,E)$ is a freely chosen gain matrix.

To analyze the error convergence, an invariant state error $\eta(\hat x,x)$ is defined, which is different from the standard output error $\hat x-x$, since the standard output error usually does not preserve the symmetries of the system.

Given the considered system and associated transformation group, there exists a constructive method to determine $E(\hat x,u,y),W(\hat x),I(\hat x,u),\eta(\hat x,x)$, based on the [moving frame](wikipedia://en/439082) method.

Similarly to the EKF, the gain matrix $L(I,E)$ is determined from the equations[^o18]

$$L{=}PC^T\bigl(N(e)N^T(e)\bigr)^{-1},$$

$$\dot P{=}AP+PA^T+M(e)M^T(e)-PC^T\bigl(N(e)N^T(e)\bigr)^{-1}CP,$$

where the matrices $A,C$ depend here only on the known invariant vector $I(\hat x,u)$, rather than on $(\hat x,u)$ as in the standard EKF. This much simpler dependence and its consequences are the main interests of the IEKF. Indeed, the matrices $A,C$ are then constant on a much bigger set of trajectories (so-called *permanent trajectories*) than equilibrium points as it is the case for the EKF. Near such trajectories, we are back to the "true", i.e. linear, Kalman filter where convergence is guaranteed. Informally, this means the IEKF converges in general at least around any slowly varying permanent trajectory, rather than just around any slowly varying equilibrium point for the EKF.

## Application examples {#Application_examples}

### Attitude and heading reference systems {#Attitude_and_heading_reference_systems}

Invariant extended Kalman filters are for instance used in [attitude and heading reference systems](https://en.wikipedia.org/wiki/Attitude_and_Heading_Reference_Systems). In such systems the orientation, velocity and/or position of a moving rigid body, e.g. an aircraft, are estimated from different embedded sensors, such as inertial sensors, magnetometers, GPS or sonars. The use of an IEKF naturally leads[^o18] to consider the [quaternion](wikipedia://en/51440) error $\hat qq^{-1}$, which is often used as an *ad hoc* trick to preserve the constraints of the [quaternion group](wikipedia://en/153130). The benefits of the IEKF compared to the EKF are experimentally shown for a large set of trajectories.[^o19]

### Inertial navigation {#Inertial_navigation}

A major application of the Invariant extended Kalman filter is [inertial navigation](https://en.wikipedia.org/wiki/Inertial_navigation), which fits the framework after embedding of the state (consisting of [attitude matrix](https://en.wikipedia.org/wiki/Attitude_matrix) $R$, velocity vector $v$ and position vector $x$) into the Lie group $SE_2(3)$[^o22] defined by the group operation:

$$(R_1, v_1, x_1) \cdot (R_2, v_2, x_2) = (R_1 R_2, x_1 + R_1 x_2, v_1 + R_1 v_2)$$

### Simultaneous localization and mapping {#Simultaneous_localization_and_mapping}

The problem of [simultaneous localization and mapping](https://en.wikipedia.org/wiki/Simultaneous_localization_and_mapping) also fits the framework of invariant extended Kalman filtering after embedding of the state (consisting of attitude matrix $R$, position vector $x$ and a sequence of static feature points $p^1, \dots, p^K$) into the Lie group $SE_{K+1}(3)$ (or $SE_{K+1}(2)$ for planar systems)[^o22] defined by the group operation:

$$(R_1, x_1, p_1^1, \dots, p_1^K) \cdot (R_2, x_2, p_2^2, \dots, p_2^K) = (R_1 R_2, x_1 + R_1 x_2, p_1^1 + R_1 p_2^1, \dots, p_1^K + R_1 p_2^K)$$

The main benefit of the Invariant extended Kalman filter in this case is solving the problem of false observability.[^o22]
