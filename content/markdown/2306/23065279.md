# Robinson–Foulds metric

::: {#o1 .subject cue=lead name="Robinson–Foulds metric"}

The **Robinson–Foulds** or **symmetric difference metric**, often abbreviated as the **RF distance**, is a simple way to calculate the distance between [phylogenetic trees](https://en.wikipedia.org/wiki/Phylogenetic_trees).[^o2]

:::

It is defined as ($A$ + $B$) where $A$ is the number of partitions of data implied by the first tree but not the second tree and $B$ is the number of partitions of data implied by the second tree but not the first tree (although some software implementations divide the RF metric by 2[^o3] and others scale the RF distance to have a maximum value of 1). The partitions are calculated for each tree by removing each branch. Thus, the number of eligible partitions for each tree is equal to the number of branches in that tree.

RF distances have been criticized as biased,[^o4] but they represent a relatively intuitive measure of the distances between phylogenetic trees and therefore remain widely used (the original 1981 paper describing Robinson-Foulds distances[^o2] was cited more than 2700 times by 2023 based on [Google Scholar](https://en.wikipedia.org/wiki/Google_Scholar)). Nevertheless, the biases inherent to the RF distances suggest that researches should consider using "Generalized" Robinson–Foulds metrics[^o14] that may have better theoretical and practical performance and avoid the biases and misleading attributes of the original metric.

## Explanation {#Explanation}

Given two unrooted trees of nodes and a set of labels (i.e., [taxa](https://en.wikipedia.org/wiki/Taxa)) for each node (which could be empty, but only nodes with degree greater than or equal to three can be labeled by an empty set) the Robinson–Foulds metric finds the number of $\alpha$ and $\alpha^{-1}$ operations to convert one into the other. The number of operations defines their distance. Rooted trees can be examined by attaching a dummy leaf to the root node.[^o13]

The authors define two trees to be the same if they are isomorphic and the isomorphism preserves the labeling. The construction of the proof is based on a function called $\alpha$, which contracts an edge (combining the nodes, creating a union of their sets). Conversely, $\alpha^{-1}$ expands an edge (decontraction), where the set can be split in any fashion.

The $\alpha$ function removes all edges from $T_1$ that are not in $T_2$, creating $T_1 \wedge T_2$, and then $\alpha^{-1}$ is used to add the edges only discovered in $T_2$ to the tree $T_1 \wedge T_2$ to build $T_2$. The number of operations in each of these procedures is equivalent to the number of edges in $T_1$ that are not in $T_2$ plus the number of edges in $T_2$ that are not in $T_1$. The sum of the operations is equivalent to a transformation from $T_1$ to $T_2$, or vice versa.

## Properties {#Properties}

The RF distance corresponds to an equivalent similarity metric that reflects the resolution of the strict consensus of two trees, first used to compare trees in 1980.[^o8]

In their 1981 paper[^o2] Robinson and Foulds proved that the distance is in fact a [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29).

### Algorithms for computing the metric {#Algorithms_for_computing_the_metric}

In 1985 Day gave an algorithm based on perfect hashing that computes this distance that has only a linear complexity in the number of nodes in the trees. A [randomized algorithm](wikipedia://en/495383) that uses hash tables that are not necessarily perfect has been shown to approximate the Robinson-Foulds distance with a bounded error in sublinear time.

### Specific applications {#Specific_applications}

In [phylogenetics](https://en.wikipedia.org/wiki/Phylogenetics), the metric is often used to compute a distance between two trees. The treedist program in the [PHYLIP](https://en.wikipedia.org/wiki/PHYLIP) suite offers this function, as does the [RAxML\_standard](https://cme.h-its.org/exelixis/web/software/raxml/index.html) package, the [DendroPy](https://dendropy.org/) Python library (under the name "symmetric difference metric"), and R packages [TreeDist](https://CRAN.R-project.org/package=TreeDist) (`RobinsonFoulds()` function) and [phangorn](https://CRAN.R-project.org/package=phangorn) (`treedist()` function). For comparing groups of trees, the fastest implementations include HashRF and MrsRF.

The Robinson–Foulds metric has also been [used in quantitative comparative linguistics](https://en.wikipedia.org/wiki/Quantitative_comparative_linguistics#Metrics) to compute distances between trees that represent how languages are related to each other.

:::

## Strengths and weaknesses {#Strengths_and_weaknesses}

The RF metric remains widely used because the idea of using the number of splits that differ between a pair of trees is a relatively intuitive way to assess the differences among trees for many systematists. This is the primary strength of the RF distance and the reason for its continued use in phylogenetics. Of course, the number of splits that differ between a pair of trees depends on the number of taxa in the trees so one might argue that this unit is not meaningful. However, it is straightforward to normalize RF distances so they range between zero and one.

However, the RF metric also suffers a number of theoretical and practical shortcomings:[^o12][^o13]

- Relative to other metrics, lacks sensitivity, and is thus imprecise; it can take two fewer distinct values than there are taxa in a tree.[^o12][^o13]
- It is rapidly saturated; very similar trees can be allocated the maximum distance value.[^o12]
- Its value can be counterintuitive. One example is that moving a tip and its neighbour to a particular point on a tree generates a *lower* difference value than if just one of the two tips were moved to the same place.[^o12]
- Its range of values can depend on tree shape: trees that contain many uneven partitions will command relatively lower distances, on average, than trees with many even partitions.[^o12]
- It performs more poorly than many alternative measures in practical settings, based on simulated trees.[^o13]

Another issue to consider when using RF distances is that differences in one clade may be trivial (perhaps if the clade resolves three species within a genus differently) or may be fundamental (if the clade is deep in the tree and defines two fundamental subgroups, such as mammals and birds). However, this issue is not a problem with RF distances per se, it is a more general criticism of tree distances. Regardless of the behaviour of any specific tree distance a practicing evolutionary biologist might view some tree rearrangements as "important" and other rearrangements as "trivial". Tree distances are tools; they are most useful in the context of other information about the organisms in the trees.

These issues can be addressed by using less conservative metrics. "Generalized RF distances" recognize similarity between similar, but non-identical, splits; the original Robinson Foulds distance doesn't care how similar two groupings are, if they aren't identical they are discarded.[^o14]

The best-performing generalized Robinson-Foulds distances have a basis in [information theory](wikipedia://en/14773), and measure the distance between trees in terms of the quantity of information that the trees' splits hold in common (measured in bits).[^o13] The Clustering [Information Distance](wikipedia://en/41129889) (implemented in R package [TreeDist](https://CRAN.R-project.org/package=TreeDist)) is recommended as the most suitable alternative to the Robinson-Foulds distance.[^o13]

An alternative approach to tree distance calculation is to use [Quartet distance](https://en.wikipedia.org/wiki/Quartet_distance), rather than splits, as the basis for tree comparison.[^o12]
