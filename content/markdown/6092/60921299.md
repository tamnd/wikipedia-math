# Hasse–Schmidt derivation

::: {#o1 .subject cue=lead name="Hasse–Schmidt derivation"}

In mathematics, a **Hasse–Schmidt derivation** is an extension of the notion of a [derivation](wikipedia://en/897658). The concept was introduced by (Schmidt Hasse 1937).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a (not necessarily commutative nor associative) [ring](wikipedia://en/48404) *B* and a *B*-[algebra](https://en.wikipedia.org/wiki/Algebra_over_a_ring) *A*, a Hasse–Schmidt derivation is a map of *B*-algebras

$$D: A \to A[\![t]\!]$$

taking values in the ring of [formal power series](wikipedia://en/60012) with coefficients in *A*. This definition is found in several places, such as (Gatto Salehyan 2016, §3.4), which also contains the following example: for *A* being the ring of infinitely [differentiable functions](wikipedia://en/330206) (defined on, say, **R**<sup>*n*</sup>) and *B*=**R**, the map

$$f \mapsto \exp\left(t \frac d {dx}\right) f(x) = f + t \frac {df}{dx} + \frac {t^2}2 \frac {d^2 f}{dx^2} + \cdots$$

is a Hasse–Schmidt derivation, as follows from applying the [Leibniz rule](wikipedia://en/248988) iteratedly.

:::

## Equivalent characterizations {#Equivalent_characterizations}

(Hazewinkel 2012) shows that a Hasse–Schmidt derivation is equivalent to an action of the [bialgebra](wikipedia://en/310887)

$$\operatorname{NSymm} = \mathbf Z \langle Z_1, Z_2, \ldots \rangle$$

of [noncommutative symmetric functions](wikipedia://en/42432800) in countably many variables *Z*<sub>1</sub>, *Z*<sub>2</sub>, ...: the part $D_i : A \to A$ of *D* which picks the coefficient of $t^i$ is the action of the indeterminate *Z*<sub>*i*</sub>.

::: {#o9 .application cue=heading name="Applications"}

## Applications {#Applications}

Hasse–Schmidt derivations on the [exterior algebra](wikipedia://en/221537) $A = \bigwedge M$ of some *B*-module *M* have been studied by (Gatto Salehyan 2016, §4). Basic properties of derivations in this context lead to a conceptual proof of the [Cayley–Hamilton theorem](wikipedia://en/173547). See also (Gatto Scherbak 2015).

:::
