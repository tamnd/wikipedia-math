# Graph sandwich problem

::: {#o1 .subject cue=lead name="Graph sandwich problem"}

In [graph theory](wikipedia://en/12401) and [computer science](https://en.wikipedia.org/wiki/Computer_science), the **graph sandwich problem** is a problem of finding a graph that belongs to a particular family of graphs and is "sandwiched" between two other graphs, one of which must be a subgraph and the other of which must be a supergraph of the desired graph.

:::

Graph sandwich problems generalize the problem of testing whether a given graph belongs to a family of graphs, and have attracted attention because of their applications and as a natural generalization of recognition problems.[^o2]

## Problem statement {#Problem_statement}

More precisely, given a vertex set *V*, a mandatory edge set *E*<sup>1</sup>, and a (potentially) larger edge set *E*<sup>2</sup>, a graph *G* = (*V*, *E*) is called a *sandwich* graph for the pair *G*<sup>1</sup> = (*V*, *E*<sup>1</sup>), *G*<sup>2</sup> = (*V*, *E*<sup>2</sup>) if *E*<sup>1</sup> ⊆ *E* ⊆ *E*<sup>2</sup>. The *graph sandwich problem* for property Π is defined as follows:[^o4][^o5]

**Graph Sandwich Problem** for Property **Π**:

**Instance:** Vertex set *V* and edge sets *E*<sup>1</sup> ⊆ *E*<sup>2</sup> ⊆ *V* × *V*.

**Question:** Is there a graph *G* = (*V*, *E*) such that *E*<sup>1</sup> ⊆ *E* ⊆ *E*<sup>2</sup> and *G* satisfies property Π ?

The *recognition problem* for a class of graphs (those satisfying a property Π) is equivalent to the particular graph sandwich problem where *E*<sup>1</sup> = *E*<sup>2</sup>, that is, the optional edge set is empty.

## Computational complexity {#Computational_complexity}

The graph sandwich problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) when Π is the property of being a [chordal graph](wikipedia://en/744165), [comparability graph](wikipedia://en/6978672), [permutation graph](wikipedia://en/17625375), [chordal bipartite graph](wikipedia://en/44355462), or [chain graph](https://en.wikipedia.org/wiki/Chain_graph).[^o4][^o7] It can be solved in polynomial time for [split graphs](wikipedia://en/9928681),[^o4][^o8] [threshold graphs](wikipedia://en/11503485),[^o4][^o8] and graphs in which every five vertices contain at most one four-vertex [induced path](wikipedia://en/7714430).[^o9] The complexity status has also been settled for the *H*-free graph sandwich problems for each of the four-vertex graphs *H*.[^o10]
