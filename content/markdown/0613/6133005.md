# Generator matrix

::: {#o1 .subject cue=lead name="Generator matrix"}

In [coding theory](wikipedia://en/321869), a **generator matrix** is a [matrix](wikipedia://en/20556859) whose rows form a [basis](wikipedia://en/18420) for a [linear code](wikipedia://en/1866743). The codewords are all of the [linear combinations](wikipedia://en/55632) of the rows of this matrix, that is, the linear code is the [row space](https://en.wikipedia.org/wiki/Row_space) of its generator matrix.

:::

::: {#o3 .definition kind=definition/notation cue=heading name="Terminology"}

## Terminology {#Terminology}

If **G** is a matrix, it generates the codewords of a linear code *C* by

$$w=sG$$

where **w** is a codeword of the linear code *C*, and **s** is any input vector. Both **w** and **s** are assumed to be row vectors.[^o4] A generator matrix for a linear $[n, k, d]_q$-code has format $k \times n$, where *n* is the length of a codeword, *k* is the number of information bits (the dimension of *C* as a vector subspace), *d* is the minimum distance of the code, and *q* is size of the [finite field](wikipedia://en/11615), that is, the number of symbols in the alphabet (thus, *q* = 2 indicates a [binary code](https://en.wikipedia.org/wiki/Binary_code), etc.). The number of [redundant bits](https://en.wikipedia.org/wiki/Redundancy_%28information_theory%29) is denoted by $r = n - k$.

The *standard* form for a generator matrix is,[^o5]

$$G = \begin{bmatrix} I_k | P \end{bmatrix},$$

where $I_k$ is the $k \times k$ [identity matrix](wikipedia://en/59718) and P is a $k \times (n-k)$ matrix. When the generator matrix is in standard form, the code *C* is [systematic](https://en.wikipedia.org/wiki/Systematic_code) in its first *k* coordinate positions.[^o6]

A generator matrix can be used to construct the [parity check matrix](https://en.wikipedia.org/wiki/Parity_check_matrix) for a code (and vice versa). If the generator matrix *G* is in standard form, $G = \begin{bmatrix} I_k | P \end{bmatrix}$, then the parity check matrix for *C* is[^o7]

$$H = \begin{bmatrix} -P^{\top} | I_{n-k} \end{bmatrix},$$

where $P^{\top}$ is the [transpose](wikipedia://en/173844) of the matrix $P$. This is a consequence of the fact that a parity check matrix of $C$ is a generator matrix of the [dual code](wikipedia://en/1864548) $C^{\perp}$.

G is a $k \times n$ matrix, while H is a $(n-k) \times n$ matrix.

:::

## Equivalent codes {#Equivalent_codes}

Codes *C*<sub>1</sub> and *C*<sub>2</sub> are *equivalent* (denoted *C*<sub>1</sub> ~ *C*<sub>2</sub>) if one code can be obtained from the other via the following two transformations:[^o9]

1. arbitrarily permute the components, and
1. independently scale by a non-zero element any components.

Equivalent codes have the same minimum distance.

The generator matrices of equivalent codes can be obtained from one another via the following [elementary operations](wikipedia://en/5897031#Operations):[^o10]

1. permute rows
1. scale rows by a nonzero scalar
1. add rows to other rows
1. permute columns, and
1. scale columns by a nonzero scalar.

Thus, we can perform [Gaussian elimination](wikipedia://en/13035) on *G*. Indeed, this allows us to assume that the generator matrix is in the standard form. More precisely, for any matrix *G* we can find an [invertible matrix](wikipedia://en/217122) *U* such that $UG = \begin{bmatrix} I_k | P \end{bmatrix}$, where *G* and $\begin{bmatrix} I_k | P \end{bmatrix}$ generate equivalent codes.
