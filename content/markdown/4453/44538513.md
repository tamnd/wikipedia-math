# (a, b)-decomposition

::: {#o1 .subject cue=lead name="(a, b)-decomposition"}

In [graph theory](wikipedia://en/12401), the **(*a*, *b*)-decomposition** of an undirected [graph](wikipedia://en/12401) is a partition of its edges into *a* + 1 sets, each one of them inducing a forest, except one which induces a graph with maximum degree *b*. If this graph is also a forest, then we call this a **F(*a*, *b*)-decomposition**.

:::

A graph with [arboricity](wikipedia://en/2476311) *a* is (*a*, 0)-decomposable. Every (*a*, *0*)-decomposition or (*a*, *1*)-decomposition is a F(*a*, *0*)-decomposition or a F(*a*, *1*)-decomposition respectively.

## Graph classes {#Graph_classes}

- Every [planar graph](wikipedia://en/24314) is F(2, 4)-decomposable.[^o3]
- Every [planar graph](wikipedia://en/24314) $G$ with [girth](wikipedia://en/12013) at least $g$ is
  - F(2, 0)-decomposable if $g \ge 4$.[^o4]
  - (1, 4)-decomposable if $g \ge 5$.[^o5]
  - F(1, 2)-decomposable if $g \ge 6$.[^o6]
  - F(1, 1)-decomposable if $g \ge 8$,[^o7] or if every cycle of $G$ is either a triangle or a cycle with at least 8 edges not belonging to a triangle.[^o8]
  - (1, 5)-decomposable if $G$ has no 4-cycles.[^o9]
- Every [outerplanar graph](wikipedia://en/352343) is F(2, 0)-decomposable[^o4] and (1, 3)-decomposable.[^o10]
