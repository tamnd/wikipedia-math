# Join (graph theory)

*Image: Join operation on graphs C4 and K4.svg.* Join operation on graphs [$C_{4}$](wikipedia://en/878962) (blue) and [$K_{4}$](wikipedia://en/85816) (red).

::: {#o1 .subject cue=lead name="Join"}

In [graph theory](wikipedia://en/12401), the **join** operation is a [graph operation](wikipedia://en/9938244) that combines two graphs by connecting every vertex of one graph to every vertex of the other.[^o2][^o3][^o4] The join of two graphs $G_1$ and $G_2$ is denoted $G_1 + G_2$,[^o2][^o3] $G_1\vee G_2$,[^o4] or $G_1 \nabla G_2$.

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $G_1 = (V_1, E_1)$ and $G_2 = (V_2, E_2)$ be two [disjoint graphs](wikipedia://en/325802#Disjoint_union). The **join** $G_1 + G_2$ is a graph with:[^o2][^o3][^o4]

- Vertex set: $V(G_1 + G_2) = V_1 \cup V_2$
- Edge set: $E(G_1 + G_2) = E_1 \cup E_2 \cup \{uv \mid u \in V_1, v \in V_2\}$

In other words, the join contains all vertices and edges from both original graphs, plus new edges connecting every vertex in $G_1$ to every vertex in $G_2$.

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

Several well-known graph families can be constructed using the join operation.

**[Complete bipartite graph](wikipedia://en/525320)**

$K_{m,n} = \overline{K}_m + \overline{K}_n$ (join of two [independent sets](wikipedia://en/524501)).

**[Wheel graph](wikipedia://en/1655876)**

$W_n = C_n + K_1$ (join of a [cycle graph](wikipedia://en/878962) and a single vertex).[^o9]

**[Star graph](wikipedia://en/19310129)**

$S_{n+1} = \overline{K}_n + K_1$ (join of a $n$ vertex [empty graph](wikipedia://en/1520758) and a single vertex).[^o9]

**[Fan graph](wikipedia://en/81762753)**

$F_{m,n} = P_n + \overline{K}_m$ (join of a [path graph](wikipedia://en/4587190) with an empty graph).[^o9]

**[Complete graph](wikipedia://en/85816)**

$K_n = K_m + K_{n-m}$ (join of two complete graphs whose orders sum to $n$).

**[Cograph](wikipedia://en/1175666)**

Cographs are formed by repeated join and [disjoint union](wikipedia://en/9938459) operations starting from single vertices.

**[Windmill graph](wikipedia://en/24373456)**

$D_n^{(m)} = mK_{n-1} + K_1$ (join of \$m\$ copies of the complete graph on $n-1$ vertices with a single vertex).[^o9]

:::

## Properties {#Properties}

::: {#o13 .statement kind=statement/fact cue=heading name="Basic properties"}

### Basic properties {#Basic_properties}

The join operation is [commutative](https://en.wikipedia.org/wiki/Commutative) for unlabeled graphs: $G_1 + G_2 \cong G_2 + G_1$.

If $G_1$ has $p_1$ vertices and $q_1$ edges, and $G_2$ has $p_2$ vertices and $q_2$ edges, then $G_1 + G_2$ has $p_1 + p_2$ vertices and $q_1 + q_2 + p_1 p_2$ edges. If $p_1>0$ and $p_2>0$ then $G_1 + G_2$ is [connected](wikipedia://en/1614492) ($K_{p_1,p_2}$ is a subgraph).[^o14]

:::

### Chromatic number {#Chromatic_number}

The [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) of the join satisfies:

$$\chi(G_1 + G_2) = \chi(G_1) + \chi(G_2).$$

*Image: Sulanke Earth-Moon map.svg.* The join of a 5-cycle and a 6-clique and its representation as an [Earth–Moon map](wikipedia://en/72683786)

This property holds because vertices from $G_1$ and $G_2$ must use different colors (as they are all adjacent to each other), and within each original graph, the minimum coloring is preserved. It was used in a 1974 construction by Thom Sulanke related to the [Earth–Moon problem](wikipedia://en/72683786) of coloring graphs of [thickness](wikipedia://en/43082178) two. Sulanke observed that the join $C_5+K_6$ is a thickness-two graph requiring nine colors, still the largest number of colors known to be needed for this problem.[^o16]

$G_1 + G_2$ is [color critical](wikipedia://en/680672) if and only if $G_1$ and $G_2$ are both color critical.[^o14]
