# Lang's theorem

::: {#o1 .subject cue=lead name="Lang's theorem"}

In [algebraic geometry](wikipedia://en/1997), **Lang's theorem**, introduced by [Serge Lang](wikipedia://en/872991), states: if *G* is a connected smooth [algebraic group](wikipedia://en/247924) over a [finite field](wikipedia://en/11615) $\mathbf{F}_q$, then, writing $\sigma: G \to G, \, x \mapsto x^q$ for the Frobenius, the [morphism of varieties](https://en.wikipedia.org/wiki/Morphism_of_varieties)

:::

$$G \to G, \, x \mapsto x^{-1} \sigma(x)$$

is surjective. Note that the [kernel](wikipedia://en/45240) of this map (i.e., $G = G(\overline{\mathbf{F}_q}) \to G(\overline{\mathbf{F}_q})$) is precisely $G(\mathbf{F}_q)$.

The theorem implies that $H^1(\mathbf{F}_q, G) = H_{\mathrm{\acute{e}t}}^1(\operatorname{Spec}\mathbf{F}_q, G)$ vanishes,[^o2] and, consequently, any [*G*-bundle](wikipedia://en/41910974) on $\operatorname{Spec} \mathbf{F}_q$ is isomorphic to the trivial one. Also, the theorem plays a basic role in the theory of [finite groups of Lie type](https://en.wikipedia.org/wiki/Finite_groups_of_Lie_type).

It is not necessary that *G* is affine. Thus, the theorem also applies to [abelian varieties](wikipedia://en/247152) (e.g., [elliptic curves](wikipedia://en/10225).) In fact, this application was Lang's initial motivation. If *G* is affine, the Frobenius $\sigma$ may be replaced by any surjective map with finitely many fixed points (see below for the precise statement.)

The proof (given below) actually goes through for any $\sigma$ that induces a [nilpotent operator](wikipedia://en/671772) on the Lie algebra of *G*.[^o3]

::: {#o5 .statement kind=statement/theorem cue=named-heading name="The Lang–Steinberg theorem"}

## The Lang–Steinberg theorem {#The_Lang–Steinberg_theorem}

(txt) gave a useful improvement to the theorem.

Suppose that *F* is an endomorphism of an algebraic group *G*. The **Lang map** is the map from *G* to *G* taking *g* to *g*<sup>−1</sup>*F*(*g*).

The **Lang–Steinberg theorem** states[^o7] that if *F* is surjective and has a finite number of fixed points, and *G* is a connected affine algebraic group over an [algebraically closed field](wikipedia://en/1018), then the Lang map is surjective.

:::

## Proof of Lang's theorem {#Proof_of_Lang's_theorem}

Define:

$$f_a: G \to G, \quad f_a(x) = x^{-1}a\sigma(x).$$

Then, by identifying the [tangent space](wikipedia://en/30807) at *a* with the tangent space at the [identity element](wikipedia://en/14962), we have:

$$(d f_a)_e = d(h \circ (x \mapsto (x^{-1}, a, \sigma(x))))_e = dh_{(e, a, e)} \circ (-1, 0, d\sigma_e) = -1 + d \sigma_e$$

where $h(x, y, z) = xyz$. It follows $(d f_a)_e$ is bijective since the differential of the Frobenius $\sigma$ vanishes. Since $f_a(bx) = f_{f_a(b)}(x)$, we also see that $(df_a)_b$ is bijective for any *b*.[^o10] Let *X* be the closure of the image of $f_1$. The [smooth points](https://en.wikipedia.org/wiki/Smooth_point) of *X* form an open dense subset; thus, there is some *b* in *G* such that $f_1(b)$ is a smooth point of *X*. Since the tangent space to *X* at $f_1(b)$ and the tangent space to *G* at *b* have the same dimension, it follows that *X* and *G* have the same dimension, since *G* is smooth. Since *G* is connected, the image of $f_1$ then contains an open dense subset *U* of *G*. Now, given an arbitrary element *a* in *G*, by the same reasoning, the image of $f_a$ contains an open dense subset *V* of *G*. The intersection $U \cap V$ is then nonempty but then this implies *a* is in the image of $f_1$.

:::
