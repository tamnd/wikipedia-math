# Vague set

::: {#o1 .subject cue=lead name="Vague set"}

In [mathematics](wikipedia://en/18831), **vague sets** are an extension of [fuzzy sets](wikipedia://en/56601).

:::

In a fuzzy set, each object is assigned a single [value](wikipedia://en/4095147) in the [interval](wikipedia://en/49172) \[0,1\] reflecting its *grade of [membership](https://en.wikipedia.org/wiki/Element_%28mathematics%29)*. This [single value](https://en.wikipedia.org/wiki/Single-valued_function) does not allow a separation of [evidence](wikipedia://en/82285) for membership and evidence against membership.

Gau et al.[^o2] proposed the notion of vague sets, where each object is characterized by two different membership [functions](wikipedia://en/185427): a true membership function and a false membership function. This kind of reasoning is also called interval membership, as opposed to point membership in the context of fuzzy sets.

## Mathematical definition {#Mathematical_definition}

A vague set $V$ is characterized by

- its true membership function $t_v(x)$
- its false membership function $f_v(x)$
- with $0 \le t_v(x)+f_v(x) \le 1$

The *grade of membership* for *x* is not a crisp value anymore, but can be located in $[t_v(x), 1-f_v(x)]$. This interval can be interpreted as an extension to the fuzzy membership function. The vague set degenerates to a fuzzy set, if $1-f_v(x)=t_v(x)$ for all *x*. The *uncertainty* of *x* is the difference between the upper and lower bounds of the membership interval; it can be computed as $(1-f_v(x))-t_v(x)$.
