# Partition function (mathematics)

::: {#o1 .subject cue=lead name="Partition function"}

The **partition function** or **configuration integral**, as used in [probability theory](wikipedia://en/23542), [information theory](wikipedia://en/14773) and [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems), is a generalization of the definition of a [partition function in statistical mechanics](https://en.wikipedia.org/wiki/Partition_function_in_statistical_mechanics). It is a special case of a [normalizing constant](wikipedia://en/398189) in probability theory, for the [Boltzmann distribution](wikipedia://en/4107). The partition function occurs in many problems of probability theory because, in situations where there is a natural symmetry, its associated [probability measure](wikipedia://en/45437), the [Gibbs measure](wikipedia://en/3085914), has the [Markov property](wikipedia://en/306422). This means that the partition function occurs not only in physical systems with translation symmetry, but also in such varied settings as neural networks (the [Hopfield network](wikipedia://en/1170097)), and applications such as [genomics](https://en.wikipedia.org/wiki/Genomics), [corpus linguistics](https://en.wikipedia.org/wiki/Corpus_linguistics) and [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence), which employ [Markov networks](https://en.wikipedia.org/wiki/Markov_network), and [Markov logic networks](wikipedia://en/3670357). The Gibbs measure is also the unique measure that has the property of maximizing the [entropy](https://en.wikipedia.org/wiki/Entropy_%28general_concept%29) for a fixed expectation value of the energy; this underlies the appearance of the partition function in [maximum entropy methods](https://en.wikipedia.org/wiki/Maximum_entropy_method) and the algorithms derived therefrom.

:::

The partition function ties together many different concepts, and thus offers a general framework in which many different kinds of quantities may be calculated. In particular, it shows how to calculate [expectation values](https://en.wikipedia.org/wiki/Expectation_value) and [Green's functions](wikipedia://en/311001), forming a bridge to [Fredholm theory](wikipedia://en/4355120). It also provides a natural setting for the [information geometry](wikipedia://en/487312) approach to information theory, where the [Fisher information metric](wikipedia://en/488687) can be understood to be a [correlation function](wikipedia://en/59500109) derived from the partition function; it happens to define a [Riemannian manifold](wikipedia://en/144652).

When the setting for random variables is on [complex projective space](wikipedia://en/762977) or [projective Hilbert space](wikipedia://en/796760), geometrized with the [Fubini–Study metric](wikipedia://en/2574486), the theory of [quantum mechanics](wikipedia://en/25202) and more generally [quantum field theory](wikipedia://en/25267) results. In these theories, the partition function is heavily exploited in the [path integral formulation](https://en.wikipedia.org/wiki/Path_integral_formulation), with great success, leading to many formulas nearly identical to those reviewed here. However, because the underlying measure space is complex-valued, as opposed to the real-valued [simplex](wikipedia://en/39781) of probability theory, an extra factor of *i* appears in many formulas. Tracking this factor is troublesome, and is not done here. This article focuses primarily on classical probability theory, where the sum of probabilities total to one.

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a set of [random variables](wikipedia://en/25685) $X_i$ taking on values $x_i$, and some sort of [potential function](wikipedia://en/461654) or [Hamiltonian](https://en.wikipedia.org/wiki/Hamiltonian_function) $H(x_1,x_2,\dots)$, the partition function is defined as

$$Z(\beta) = \sum_{x_i} \exp \left(-\beta H(x_1,x_2,\dots) \right)$$

The function *H* is understood to be a real-valued function on the space of states $\{X_1,X_2,\dots\}$, while $\beta$ is a real-valued free parameter (conventionally, the [inverse temperature](https://en.wikipedia.org/wiki/Inverse_temperature)). The sum over the $x_i$ is understood to be a sum over all possible values that each of the random variables $X_i$ may take. Thus, the sum is to be replaced by an [integral](wikipedia://en/15532) when the $X_i$ are continuous, rather than discrete. Thus, one writes

$$Z(\beta) = \int \exp \left(-\beta H(x_1,x_2,\dots) \right) \, dx_1 \, dx_2 \cdots$$

for the case of continuously-varying $X_i$.

When *H* is an [observable](wikipedia://en/294248), such as a finite-dimensional [matrix](wikipedia://en/20556859) or an infinite-dimensional [Hilbert space](wikipedia://en/20598932) [operator](wikipedia://en/22213) or element of a [C-star algebra](https://en.wikipedia.org/wiki/C-star_algebra), it is common to express the summation as a [trace](wikipedia://en/43270), so that

$$Z(\beta) = \operatorname{tr}\left(\exp\left(-\beta H\right)\right)$$

When *H* is infinite-dimensional, then, for the above notation to be valid, the argument must be [trace class](wikipedia://en/192266), that is, of a form such that the summation exists and is bounded.

The number of variables $X_i$ need not be [countable](https://en.wikipedia.org/wiki/Countable), in which case the sums are to be replaced by [functional integrals](https://en.wikipedia.org/wiki/Functional_integral). Although there are many notations for functional integrals, a common one would be

$$Z = \int \mathcal{D} \varphi \exp \left(- \beta H[\varphi] \right)$$

Such is the case for the [partition function in quantum field theory](https://en.wikipedia.org/wiki/Partition_function_in_quantum_field_theory).

A common, useful modification to the partition function is to introduce auxiliary functions. This allows, for example, the partition function to be used as a [generating function](wikipedia://en/160993) for [correlation functions](wikipedia://en/59500109). This is discussed in greater detail below.

:::

## The parameter *β* {#The_parameter_β}

The role or meaning of the parameter $\beta$ can be understood in a variety of different ways. In classical thermodynamics, it is an [inverse temperature](https://en.wikipedia.org/wiki/Inverse_temperature). More generally, one would say that it is the variable that is [conjugate](wikipedia://en/3177451) to some (arbitrary) function $H$ of the random variables $X$. The word *conjugate* here is used in the sense of conjugate [generalized coordinates](wikipedia://en/473514) in [Lagrangian mechanics](wikipedia://en/23371726), thus, properly $\beta$ is a [Lagrange multiplier](wikipedia://en/159974). It is not uncommonly called the [generalized force](https://en.wikipedia.org/wiki/Generalized_force). All of these concepts have in common the idea that one value is meant to be kept fixed, as others, interconnected in some complicated way, are allowed to vary. In the current case, the value to be kept fixed is the [expectation value](https://en.wikipedia.org/wiki/Expectation_value) of $H$, even as many different [probability distributions](wikipedia://en/23543) can give rise to exactly this same (fixed) value.

For the general case, one considers a set of functions $\{H_k(x_1,\dots)\}$ that each depend on the random variables $X_i$. These functions are chosen because one wants to hold their expectation values constant, for one reason or another. To constrain the expectation values in this way, one applies the method of [Lagrange multipliers](wikipedia://en/159974). In the general case, [maximum entropy methods](https://en.wikipedia.org/wiki/Maximum_entropy_method) illustrate the manner in which this is done.

Some specific examples are in order. In basic thermodynamics problems, when using the [canonical ensemble](wikipedia://en/1137672), the use of just one parameter $\beta$ reflects the fact that there is only one expectation value that must be held constant: the [free energy](https://en.wikipedia.org/wiki/Thermodynamic_free_energy) (due to [conservation of energy](wikipedia://en/67088)). For chemistry problems involving chemical reactions, the [grand canonical ensemble](wikipedia://en/1129074) provides the appropriate foundation, and there are two Lagrange multipliers. One is to hold the energy constant, and another, the [fugacity](https://en.wikipedia.org/wiki/Fugacity), is to hold the particle count constant (as chemical reactions involve the recombination of a fixed number of atoms).

For the general case, one has

$$Z(\beta) = \sum_{x_i} \exp \left(-\sum_k\beta_k H_k(x_i) \right)$$

with $\beta = (\beta_1, \beta_2, \dots)$ a point in a space.

For a collection of observables $H_k$, one would write

$$Z(\beta) = \operatorname{tr}\left[\,\exp \left(-\sum_k\beta_k H_k\right)\right]$$

As before, it is presumed that the argument of $\operatorname{tr}$ is [trace class](wikipedia://en/192266).

The corresponding [Gibbs measure](wikipedia://en/3085914) then provides a probability distribution such that the expectation value of each $H_k$ is a fixed value. More precisely, one has

$$\frac{\partial}{\partial \beta_k} \left(- \log Z \right) = \langle H_k\rangle = \mathrm{E}\left[H_k\right]$$

with the angle brackets $\langle H_k \rangle$ denoting the expected value of $H_k$, and $\operatorname{E}[\,\cdot\,]$ being a common alternative notation. A precise definition of this expectation value is given below.

Although the value of $\beta$ is commonly taken to be real, it need not be, in general; this is discussed in the section Normalization below. The values of $\beta$ can be understood to be the coordinates of points in a space; this space is in fact a [manifold](wikipedia://en/2073470), as sketched below. The study of these spaces as manifolds constitutes the field of [information geometry](wikipedia://en/487312).

::: {#o6 .statement kind=statement/fact cue=heading name="Symmetry"}

## Symmetry {#Symmetry}

The potential function itself commonly takes the form of a sum:

$$H(x_1,x_2,\dots) = \sum_s V(s)\,$$

where the sum over *s* is a sum over some subset of the [power set](wikipedia://en/23799) *P*(*X*) of the set $X = \lbrace x_1,x_2,\dots \rbrace$. For example, in [statistical mechanics](wikipedia://en/28481), such as the [Ising model](wikipedia://en/292744), the sum is over pairs of nearest neighbors. In probability theory, such as [Markov networks](https://en.wikipedia.org/wiki/Markov_networks), the sum might be over the [cliques](wikipedia://en/524466) of a graph; so, for the Ising model and other [lattice models](wikipedia://en/291472), the maximal cliques are edges.

The fact that the potential function can be written as a sum usually reflects the fact that it is invariant under the [action](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) of a [group symmetry](wikipedia://en/19447), such as [translational invariance](https://en.wikipedia.org/wiki/Translational_invariance). Such symmetries can be discrete or continuous; they materialize in the [correlation functions](wikipedia://en/59500109) for the random variables (discussed below). Thus a symmetry in the Hamiltonian becomes a symmetry of the correlation function (and vice versa).

This symmetry has a critically important interpretation in probability theory: it implies that the [Gibbs measure](wikipedia://en/3085914) has the [Markov property](wikipedia://en/306422); that is, it is independent of the random variables in a certain way, or, equivalently, the measure is identical on the [equivalence classes](wikipedia://en/9260) of the symmetry. This leads to the widespread appearance of the partition function in problems with the Markov property, such as [Hopfield networks](wikipedia://en/1170097).

:::

## As a measure {#As_a_measure}

The value of the expression

$$\exp \left(-\beta H(x_1,x_2,\dots) \right)$$

can be interpreted as a likelihood that a specific [configuration](wikipedia://en/473596) of values $(x_1,x_2,\dots)$ occurs in the system. Thus, given a specific configuration $(x_1,x_2,\dots)$,

$$P(x_1,x_2,\dots) = \frac{1}{Z(\beta)} \exp \left(-\beta H(x_1,x_2,\dots) \right)$$

is the [probability](wikipedia://en/43487) of the configuration $(x_1,x_2,\dots)$ occurring in the system, which is now properly normalized so that $0\le P(x_1,x_2,\dots)\le 1$, and such that the sum over all configurations totals to one. As such, the partition function can be understood to provide a [measure](wikipedia://en/19873) (a [probability measure](wikipedia://en/45437)) on the [probability space](wikipedia://en/43325); formally, it is called the [Gibbs measure](wikipedia://en/3085914). It generalizes the narrower concepts of the [grand canonical ensemble](wikipedia://en/1129074) and [canonical ensemble](wikipedia://en/1137672) in statistical mechanics.

There exists at least one configuration $(x_1,x_2,\dots)$ for which the probability is maximized; this configuration is conventionally called the [ground state](https://en.wikipedia.org/wiki/Ground_state). If the configuration is unique, the ground state is said to be **non-degenerate**, and the system is said to be [ergodic](https://en.wikipedia.org/wiki/Ergodic); otherwise the ground state is **degenerate**. The ground state may or may not commute with the generators of the symmetry; if commutes, it is said to be an [invariant measure](wikipedia://en/7635201). When it does not commute, the symmetry is said to be [spontaneously broken](https://en.wikipedia.org/wiki/Spontaneously_broken).

Conditions under which a ground state exists and is unique are given by the [Karush–Kuhn–Tucker conditions](wikipedia://en/2397362); these conditions are commonly used to justify the use of the Gibbs measure in maximum-entropy problems.

## Normalization {#Normalization}

The values taken by $\beta$ depend on the [mathematical space](https://en.wikipedia.org/wiki/Mathematical_space) over which the random field varies. Thus, real-valued random fields take values on a [simplex](wikipedia://en/39781): this is the geometrical way of saying that the sum of probabilities must total to one. For quantum mechanics, the random variables range over [complex projective space](wikipedia://en/762977) (or complex-valued [projective Hilbert space](wikipedia://en/796760)), where the random variables are interpreted as [probability amplitudes](https://en.wikipedia.org/wiki/Probability_amplitude). The emphasis here is on the word *projective*, as the amplitudes are still normalized to one. The normalization for the potential function is the [Jacobian](wikipedia://en/195351) for the appropriate mathematical space: it is 1 for ordinary probabilities, and *i* for Hilbert space; thus, in [quantum field theory](wikipedia://en/25267), one sees $it H$ in the exponential, rather than $\beta H$. The partition function is very heavily exploited in the [path integral formulation](https://en.wikipedia.org/wiki/Path_integral_formulation) of quantum field theory, to great effect. The theory there is very nearly identical to that presented here, aside from this difference, and the fact that it is usually formulated on four-dimensional space-time, rather than in a general way.

## Expectation values {#Expectation_values}

The partition function is commonly used as a [probability-generating function](https://en.wikipedia.org/wiki/Probability-generating_function) for [expectation values](https://en.wikipedia.org/wiki/Expectation_value) of various functions of the random variables. So, for example, taking $\beta$ as an adjustable parameter, then the derivative of $\log(Z(\beta))$ with respect to $\beta$

$$\operatorname{E}[H] = \langle H \rangle = -\frac {\partial \log(Z(\beta))} {\partial \beta}$$

gives the average (expectation value) of *H*. In physics, this would be called the average [energy](https://en.wikipedia.org/wiki/Energy) of the system.

Given the definition of the probability measure above, the expectation value of any function *f* of the random variables *X* may now be written as expected: so, for discrete-valued *X*, one writes

$$\begin{aligned} \langle f\rangle & = \sum_{x_i} f(x_1,x_2,\dots) P(x_1,x_2,\dots) \\ & = \frac{1}{Z(\beta)} \sum_{x_i} f(x_1,x_2,\dots) \exp \left(-\beta H(x_1,x_2,\dots) \right) \end{aligned}$$

The above notation makes sense for a finite number of discrete random variables. In more general settings, the summations should be replaced with integrals over a [probability space](wikipedia://en/43325).

Thus, for example, the [entropy](https://en.wikipedia.org/wiki/Entropy_%28general_concept%29) is given by

$$\begin{aligned} S & = -k_\text{B} \langle\ln P\rangle \\[1ex] & = -k_\text{B} \sum_{x_i} P(x_1, x_2, \dots) \ln P(x_1,x_2,\dots) \\ & = k_\text{B} \left(\beta \langle H\rangle + \log Z(\beta)\right) \end{aligned}$$

The Gibbs measure is the unique statistical distribution that maximizes the entropy for a fixed expectation value of the energy; this underlies its use in [maximum entropy methods](https://en.wikipedia.org/wiki/Maximum_entropy_method).

## Information geometry {#Information_geometry}

The points $\beta$ can be understood to form a space, and specifically, a [manifold](wikipedia://en/2073470). Thus, it is reasonable to ask about the structure of this manifold; this is the task of [information geometry](wikipedia://en/487312).

Multiple derivatives with regard to the Lagrange multipliers gives rise to a positive semi-definite [covariance matrix](wikipedia://en/191752)

$$g_{ij}(\beta) = \frac{\partial^2}{\partial \beta^i\partial \beta^j} \left(-\log Z(\beta)\right) = \langle \left(H_i-\langle H_i\rangle\right)\left( H_j-\langle H_j\rangle\right)\rangle$$

This matrix is positive semi-definite, and may be interpreted as a [metric tensor](wikipedia://en/195795), specifically, a [Riemannian metric](https://en.wikipedia.org/wiki/Riemannian_metric). Equipping the space of Lagrange multipliers with a metric in this way turns it into a [Riemannian manifold](wikipedia://en/144652).[^o11] The study of such manifolds is referred to as [information geometry](wikipedia://en/487312); the metric above is the [Fisher information metric](wikipedia://en/488687). Here, $\beta$ serves as a coordinate on the manifold. It is interesting to compare the above definition to the simpler [Fisher information](wikipedia://en/598971), from which it is inspired.

That the above defines the Fisher information metric can be readily seen by explicitly substituting for the expectation value:

$$\begin{aligned} g_{ij}(\beta) & = \left\langle \left(H_i - \left\langle H_i \right\rangle\right) \left( H_j - \left\langle H_j \right\rangle\right) \right\rangle \\ & = \sum_{x} P(x) \left(H_i - \left\langle H_i \right\rangle\right) \left( H_j - \left\langle H_j \right\rangle\right) \\ & = \sum_{x} P(x) \left(H_i + \frac{\partial\log Z}{\partial \beta_i}\right) \left(H_j + \frac{\partial\log Z}{\partial \beta_j}\right) \\ & = \sum_{x} P(x) \frac{\partial \log P(x)}{\partial \beta^i} \frac{\partial \log P(x)}{\partial \beta^j} \\ \end{aligned}$$

where we've written $P(x)$ for $P(x_1,x_2,\dots)$ and the summation is understood to be over all values of all random variables $X_k$. For continuous-valued random variables, the summations are replaced by integrals, of course.

Curiously, the [Fisher information metric](wikipedia://en/488687) can also be understood as the flat-space [Euclidean metric](https://en.wikipedia.org/wiki/Euclidean_metric), after appropriate change of variables, as described in the main article on it. When the $\beta$ are complex-valued, the resulting metric is the [Fubini–Study metric](wikipedia://en/2574486). When written in terms of [mixed states](https://en.wikipedia.org/wiki/Mixed_state_%28physics%29), instead of [pure states](https://en.wikipedia.org/wiki/Pure_state), it is known as the [Bures metric](wikipedia://en/20086937).

## Correlation functions {#Correlation_functions}

By introducing artificial auxiliary functions $J_k$ into the partition function, it can then be used to obtain the expectation value of the random variables. Thus, for example, by writing

$$\begin{aligned} Z(\beta,J) & = Z(\beta,J_1,J_2,\dots) \\ & = \sum_{x_i} \exp \left(-\beta H(x_1,x_2,\dots) + \sum_n J_n x_n \right) \end{aligned}$$

one then has

$$\operatorname{E}[x_k] = \langle x_k \rangle = \left. \frac{\partial}{\partial J_k} \log Z(\beta,J)\right|_{J=0}$$

as the expectation value of $x_k$. In the [path integral formulation](https://en.wikipedia.org/wiki/Path_integral_formulation) of [quantum field theory](wikipedia://en/25267), these auxiliary functions are commonly referred to as [source fields](https://en.wikipedia.org/wiki/Source_field).

Multiple differentiations lead to the [connected correlation functions](wikipedia://en/19660624) of the random variables. Thus the correlation function $C(x_j,x_k)$ between variables $x_j$ and $x_k$ is given by:

$$C(x_j,x_k) = \left. \frac{\partial}{\partial J_j} \frac{\partial}{\partial J_k} \log Z(\beta,J)\right|_{J=0}$$

## Gaussian integrals {#Gaussian_integrals}

For the case where *H* can be written as a [quadratic form](wikipedia://en/251478) involving a [differential operator](wikipedia://en/263886), that is, as

$$H = \frac{1}{2} \sum_n x_n D x_n$$

then partition function can be understood to be a sum or [integral](wikipedia://en/567580) over Gaussians. The correlation function $C(x_j,x_k)$ can be understood to be the [Green's function](wikipedia://en/311001) for the differential operator (and generally giving rise to [Fredholm theory](wikipedia://en/4355120)). In the quantum field theory setting, such functions are referred to as [propagators](wikipedia://en/698759); higher order correlators are called n-point functions; working with them defines the [effective action](https://en.wikipedia.org/wiki/Effective_action) of a theory.

When the random variables are anti-commuting [Grassmann numbers](wikipedia://en/3117887), then the partition function can be expressed as a determinant of the operator *D*. This is done by writing it as a [Berezin integral](wikipedia://en/20041308) (also called Grassmann integral).

## General properties {#General_properties}

Partition functions are used to discuss [critical scaling](https://en.wikipedia.org/wiki/Critical_scaling), [universality](wikipedia://en/1752072) and are subject to the [renormalization group](wikipedia://en/291462).
