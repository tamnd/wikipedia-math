# Markovian arrival process

::: {#o1 .subject cue=lead name="Markovian arrival process"}

In [queueing theory](wikipedia://en/50578), a discipline within the mathematical [theory of probability](wikipedia://en/23542), a **Markovian arrival process** (**MAP** or **MArP**[^o2]) is a mathematical model for the time between job arrivals to a system. The simplest such process is a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) where the time between each arrival is [exponentially distributed](wikipedia://en/45906).[^o3][^o4]

:::

The processes were first suggested by [Marcel F. Neuts](wikipedia://en/73888681) in 1979.[^o3][^o5]

::: {#o7 .definition cue=heading name="Definition"}

## Definition {#Definition}

A Markov arrival process is defined by two matrices, *D*<sub>0</sub> and *D*<sub>1</sub> where elements of *D*<sub>0</sub> represent hidden transitions and elements of *D*<sub>1</sub> observable transitions. The [block matrix](wikipedia://en/457464) *Q* below is a [transition rate matrix](https://en.wikipedia.org/wiki/Transition_rate_matrix) for a [continuous-time Markov chain](wikipedia://en/1125342).[^o8]

$$Q=\left[\begin{matrix} D_{0}&D_{1}&0&0&\dots\\ 0&D_{0}&D_{1}&0&\dots\\ 0&0&D_{0}&D_{1}&\dots\\ \vdots & \vdots & \ddots & \ddots & \ddots \end{matrix}\right]\; .$$

The simplest example is a Poisson process where *D*<sub>0</sub> = −*λ* and *D*<sub>1</sub> = *λ* where there is only one possible transition, it is observable, and occurs at rate *λ*. For *Q* to be a valid transition rate matrix, the following restrictions apply to the *D*<sub>*i*</sub>

$$\begin{aligned} 0\leq [D_{1}]_{i,j}&<\infty \\ 0\leq [D_{0}]_{i,j}&<\infty \quad i\neq j \\ \, [D_{0}]_{i,i}&<0 \\ (D_{0}+D_{1})\boldsymbol{1} &= \boldsymbol{0} \end{aligned}$$

:::

::: {#o10 .statement kind=statement/generalization cue=heading name="Special cases"}

## Special cases {#Special_cases}

### Phase-type renewal process {#Phase-type_renewal_process}

The **phase-type renewal process** is a Markov arrival process with [phase-type distributed](wikipedia://en/3513151) sojourn between arrivals. For example, if an arrival process has an interarrival time distribution PH$(\boldsymbol{\alpha},S)$ with an exit vector denoted $\boldsymbol{S}^{0}=-S\boldsymbol{1}$, the arrival process has generator matrix,

$$Q=\left[\begin{matrix} S&\boldsymbol{S}^{0}\boldsymbol{\alpha}&0&0&\dots\\ 0&S&\boldsymbol{S}^{0}\boldsymbol{\alpha}&0&\dots\\ 0&0&S&\boldsymbol{S}^{0}\boldsymbol{\alpha}&\dots\\ \vdots&\vdots&\ddots&\ddots&\ddots\\ \end{matrix}\right]$$

:::

::: {#o13 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

### Batch Markov arrival process {#Batch_Markov_arrival_process}

The **batch Markovian arrival process** (*BMAP*) is a generalisation of the Markovian arrival process by allowing more than one arrival at a time.[^o15][^o16] The homogeneous case has rate matrix,

$$Q=\left[\begin{matrix} D_{0}&D_{1}&D_{2}&D_{3}&\dots\\ 0&D_{0}&D_{1}&D_{2}&\dots\\ 0&0&D_{0}&D_{1}&\dots\\ \vdots & \vdots & \ddots & \ddots & \ddots \end{matrix}\right]\; .$$

An arrival of size $k$ occurs every time a transition occurs in the sub-matrix $D_{k}$. Sub-matrices $D_{k}$ have elements of $\lambda_{i,j}$, the rate of a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process), such that,

$$0\leq [D_{k}]_{i,j}<\infty\;\;\;\; 1\leq k$$

$$0\leq [D_{0}]_{i,j}<\infty\;\;\;\; i\neq j$$

$$[D_{0}]_{i,i}<0\;$$

and

$$\sum^{\infty}_{k=0}D_{k}\boldsymbol{1}=\boldsymbol{0}$$

::: {#o18 .pointer-item cue=pointer name="Markov-modulated Poisson process"}

### Markov-modulated Poisson process {#Markov-modulated_Poisson_process}

The **Markov-modulated Poisson process** or **MMPP** where *m* Poisson processes are switched between by an underlying [continuous-time Markov chain](wikipedia://en/1125342).[^o19] If each of the *m* Poisson processes has rate *λ*<sub>*i*</sub> and the modulating continuous-time Markov has *m* × *m* transition rate matrix *R*, then the MAP representation is

$$\begin{aligned} D_{1} &= \operatorname{diag}\{\lambda_{1},\dots,\lambda_{m}\}\\ D_{0} &=R-D_1. \end{aligned}$$

:::

:::

## Fitting {#Fitting}

A MAP can be fitted using an [expectation–maximization algorithm](wikipedia://en/470752).[^o21]
