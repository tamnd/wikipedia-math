# Diagnostic odds ratio

*Image: Log-DiagnosticOddsRatio.svg.* log(Diagnostic Odds Ratio) for varying sensitivity and specificity

::: {#o1 .subject cue=lead name="Diagnostic odds ratio"}

In [medical testing](wikipedia://en/12439068) with [binary classification](wikipedia://en/205393), the **diagnostic odds ratio** (**DOR**) is a [measure of the effectiveness](wikipedia://en/43218024) of a [diagnostic test](https://en.wikipedia.org/wiki/Diagnostic_test).[^o2] It is defined as the ratio of [positive likelihood ratio](https://en.wikipedia.org/wiki/Positive_likelihood_ratio) to [negative likelihood ratio](https://en.wikipedia.org/wiki/Negative_likelihood_ratio). There is also a [multiclass](https://en.wikipedia.org/wiki/Multi-class_classification) version of the diagnostic odds ratio.[^o3]

:::

The rationale for the diagnostic odds ratio is that it is a single indicator of test performance (like [accuracy](https://en.wikipedia.org/wiki/Accuracy#Accuracy_and_precision_in_binary_classification) and [Youden's J statistic](wikipedia://en/14092544)) but which is independent of [prevalence](wikipedia://en/126688) (unlike accuracy) and is presented as an [odds ratio](wikipedia://en/406880), which has theoretical advantages (e.g. [Bayes' law](https://en.wikipedia.org/wiki/Bayes'_law) is written a product of ratios).

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The diagnostic odds ratio is defined mathematically as:

$\text{Diagnostic odds ratio, DOR} = \frac{TP/FN}{FP/TN} = \frac{TP/FP}{FN/TN} = \frac{TP \cdot TN}{FP \cdot FN}$[^o6][^o7]

where $TP$, $FN$, $FP$ and $TN$ are the number of true positives, false negatives, false positives and true negatives respectively.[^o2]

### Confidence interval {#Confidence_interval}

As with the [odds ratio](wikipedia://en/406880), the [logarithm](wikipedia://en/21476) of the diagnostic odds ratio is approximately [normally distributed](wikipedia://en/21462). The [standard error](https://en.wikipedia.org/wiki/Standard_error_%28statistics%29) of the log diagnostic odds ratio is approximately:

$$\mathrm{SE}\left(\ln{\text{DOR}}\right) = \sqrt{\frac{1}{TP}+\frac{1}{FN}+\frac{1}{FP}+\frac{1}{TN}}$$

From this an approximate 95% [confidence interval](wikipedia://en/280911) can be calculated for the log diagnostic odds ratio:

$$\ln{\text{DOR}} \pm 1.96 \times \mathrm{SE}\left(\ln{\text{DOR}}\right)$$

[Exponentiation](wikipedia://en/9678) of the approximate confidence interval for the log diagnostic odds ratio gives the approximate confidence interval for the diagnostic odds ratio.[^o2]

:::

## Interpretation {#Interpretation}

The diagnostic odds ratio ranges from zero to infinity, although for useful tests it is greater than one, and higher diagnostic odds ratios are indicative of better test performance.[^o2] Diagnostic odds ratios less than one indicate that the test can be improved by simply inverting the outcome of the test – the test is in the wrong direction, while a diagnostic odds ratio of exactly one means that the test is equally likely to predict a positive outcome whatever the true condition – the test gives no information.

## Relation to other measures of diagnostic test accuracy {#Relation_to_other_measures_of_diagnostic_test_accuracy}

The diagnostic odds ratio may be expressed in terms of the [sensitivity and specificity](wikipedia://en/5599330) of the test:[^o2]

$$\text{DOR} = \frac{\text{sensitivity}\times\text{specificity}}{\left(1-\text{sensitivity}\right)\times\left(1-\text{specificity}\right)}$$

It may also be expressed in terms of the [positive predictive value](https://en.wikipedia.org/wiki/Positive_predictive_value) (PPV) and [negative predictive value](https://en.wikipedia.org/wiki/Negative_predictive_value) (NPV):[^o2]

$$\text{DOR} = \frac{\text{PPV}\times\text{NPV}}{\left(1-\text{PPV}\right)\times\left(1-\text{NPV}\right)}$$

It is also related to the [likelihood ratios](wikipedia://en/935451), $LR+$ and $LR-$:[^o2]

$$\text{DOR} = \frac{LR+}{LR-}$$

::: {#o12 .application cue=heading name="Uses"}

## Uses {#Uses}

The log diagnostic odds ratio is sometimes used in meta-analyses of diagnostic test accuracy studies due to its simplicity (being approximately normally distributed).[^o13]

Traditional [meta-analytic](wikipedia://en/62329) techniques such as [inverse-variance weighting](wikipedia://en/30440719) can be used to combine log diagnostic odds ratios computed from a number of data sources to produce an overall diagnostic odds ratio for the test in question.

The log diagnostic odds ratio can also be used to study the [trade-off](https://en.wikipedia.org/wiki/Trade-off) between sensitivity and specificity[^o20][^o14] by expressing the log diagnostic odds ratio in terms of the [logit](wikipedia://en/172068) of the true positive rate (sensitivity) and false positive rate (1 − specificity), and by additionally constructing a measure, $S$:

$$D = \log{\text{DOR}} = \log{\left[\frac{TPR}{(1-TPR)}\times\frac{(1-FPR)}{FPR}\right]} = \operatorname{logit}(TPR) - \operatorname{logit}(FPR)$$

$$S = \operatorname{logit}(TPR) + \operatorname{logit}(FPR)$$

It is then possible to fit a straight line, $D = a + bS$. If b ≠ 0 then there is a trend in diagnostic performance with threshold beyond the simple trade-off of sensitivity and specificity. The value a can be used to plot a summary [ROC](wikipedia://en/922505) (SROC) curve.[^o20][^o14]

:::

## Example {#Example}

Consider a test with the following 2×2 [confusion matrix](wikipedia://en/847558):

::: {#o17 .table cue=table}

|  | Positive | Negative |
|---|---|---|
| Positive | 26 | 3 |
| Negative | 12 | 48 |

:::

We calculate the diagnostic odds ratio as:

$$\text{DOR} = \frac{TP/FP}{FN/TN} = \frac{26/12}{3/48} = 34.666\ldots \approx 35$$

This diagnostic odds ratio is greater than one, so we know that the test is discriminating correctly. We compute the confidence interval for the diagnostic odds ratio of this test as \[9, 134\].

:::

## Criticisms {#Criticisms}

The diagnostic odds ratio is undefined when the number of false negatives *or* false positives is zero – if both false negatives *and* false positives are zero, then the test is perfect, but if only one is, this ratio does not give a usable measure. The typical response to such a scenario is to add 0.5 to all cells in the [contingency table](wikipedia://en/935515),[^o2][^o19] although this should not be seen as a correction as it introduces a bias to results.[^o20] It is suggested that the adjustment is made to all contingency tables, even if there are no cells with zero entries.[^o20]

Another solution is to consider $1 -\frac{2}{DOR+1} = \frac{DOR-1}{DOR+1} = \frac{TP \cdot TN - FP \cdot FN}{TP \cdot TN + FP \cdot FN}$. This metric is well defined if the test is not constant (all positive or all negative), it ranks the tests in the same order as the diagnostic odds ratio, it is between -1 and 1 and it is positive for tests that are better than chance.[^o3]
