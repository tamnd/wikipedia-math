# Permutation automaton

::: {#o1 .subject cue=lead name="Permutation automaton"}

In [automata theory](wikipedia://en/103356), a **permutation automaton**, or **pure-group automaton**, is a [deterministic finite automaton](wikipedia://en/653404) such that each input symbol [permutes](wikipedia://en/44027) the set of states.[^o2][^o3]

:::

Formally, a deterministic finite automaton $A$ may be defined by the tuple (*Q*, Σ, δ, *q*<sub>*0*</sub>, *F*), where *Q* is the set of states of the automaton, Σ is the set of input symbols, δ is the [transition function](https://en.wikipedia.org/wiki/Transition_map) that takes a state *q* and an input symbol *x* to a new state δ(*q*,*x*), *q*<sub>*0*</sub> is the initial state of the automaton, and *F* is the set of accepting states (also: final states) of the automaton. $A$ is a permutation automaton if and only if, for every two distinct states $q_{i}$ and $q_{j}$ in *Q* and every input symbol $x$ in Σ, δ(*q<sub>i</sub>*,*x*) ≠ δ(*q<sub>j</sub>*,*x*).

A [formal language](wikipedia://en/10939) is **p-regular** (also: a **pure-group language**) if it is accepted by a permutation automaton. For example, the set of strings of even length forms a p-regular language: it may be accepted by a permutation automaton with two states in which every transition replaces one state by the other.

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

The pure-group languages were the first interesting family of [regular languages](https://en.wikipedia.org/wiki/Regular_languages) for which the [star height problem](wikipedia://en/27647) was proved to be [computable](https://en.wikipedia.org/wiki/Computable).[^o2][^o6]

Another mathematical problem on regular languages is the *separating words problem*, which asks for the size of a smallest deterministic finite automaton that distinguishes between two given words of length at most *n* – by accepting one word and rejecting the other. The known upper bound in the general case is $O(n^{2/5}(\log n)^{3/5})$.[^o7] The problem was later studied for the restriction to permutation automata. In this case, the known upper bound changes to $O(n^{1/2})$.[^o8]
