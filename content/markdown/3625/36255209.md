# Bauerian extension

::: {#o1 .subject cue=lead name="Bauerian extension"}

In [mathematics](wikipedia://en/18831), in the field of [algebraic number theory](wikipedia://en/174705), a **Bauerian extension** is a [field extension](wikipedia://en/11634) of an [algebraic number field](wikipedia://en/28730822) which is characterized by the [prime ideals](wikipedia://en/24928) with [inertial degree](https://en.wikipedia.org/wiki/Inertial_degree) one in the extension.

:::

For a finite [degree](wikipedia://en/4382697) extension *L*/*K* of an algebraic number field *K* we define *P*(*L*/*K*) to be the set of primes **p** of *K* which have a factor **P** with inertial degree one (that is, the [residue field](wikipedia://en/10789680) of **P** has the same order as the residue field of **p**).

**Bauer's theorem** states that if *M*/*K* is a finite degree [Galois extension](wikipedia://en/457064), then *P*(*M*/*K*) ⊇ *P*(*L*/*K*) if and only if *M* ⊆ *L*. In particular, finite degree Galois extensions *N* of *K* are characterised by set of prime ideals which split completely in *N*.

An extension *F*/*K* is *Bauerian* if it obeys Bauer's theorem: that is, for every finite extension *L* of *K*, we have *P*(*F*/*K*) ⊇ *P*(*L*/*K*) if and only if *L* contains a subfield *K*-isomorphic to *F*.

All field extensions of degree at most 4 over **Q** are Bauerian.[^o2] An example of a non-Bauerian extension is the Galois extension of **Q** by the roots of 2*x*<sup>5</sup> − 32*x* + 1, which has Galois group *S*<sub>5</sub>.[^o3]
