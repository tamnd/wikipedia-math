# LaplacesDemon

::: {#o1 .subject cue=lead name="LaplacesDemon"}

**LaplacesDemon** is an [open-source](https://en.wikipedia.org/wiki/Open-source_software) [statistical package](https://en.wikipedia.org/wiki/Statistical_package) that is intended to provide a complete environment for [Bayesian inference](wikipedia://en/49571). LaplacesDemon has been used in numerous fields.[^o3][^o4][^o5] The user writes their own model specification function and selects a numerical approximation algorithm to update their Bayesian model. Some numerical approximation families of algorithms include [Laplace's method](wikipedia://en/642006) (Laplace approximation), [numerical integration](wikipedia://en/170089) (iterative quadrature), [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC), and [variational Bayesian methods](wikipedia://en/1208480).

:::

The base package, LaplacesDemon, is written entirely in the [R programming language](https://en.wikipedia.org/wiki/R_programming_language), and is largely self-contained, though it does require the parallel package for high performance computing via parallelism. [Big data](wikipedia://en/27051151) is also supported.[^o6] An extension package called LaplacesDemonCpp is in development to provide [C++](https://en.wikipedia.org/wiki/C++) functionality.[^o7]

The software was named after the concept of [Laplace's demon](https://en.wikipedia.org/wiki/Laplace's_demon), which refers to a hypothetical being capable of predicting the universe. [Pierre-Simon Laplace](wikipedia://en/344783) alluded to this hypothetical being in the introduction to his Philosophical Essay on Probabilities.[^o8]
