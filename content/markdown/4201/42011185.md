# Quotient type

::: {#o1 .subject cue=lead name="Quotient type"}

In the field of [type theory](wikipedia://en/40282) in [computer science](https://en.wikipedia.org/wiki/Computer_science), a **quotient type** is a [data type](https://en.wikipedia.org/wiki/Data_type) that respects a user-defined [equality](wikipedia://en/90446) relation. A quotient type defines an [equivalence relation](wikipedia://en/9259) $\equiv$ on elements of the type — for example, we might say that two values of the type `Point` are equivalent if they have the same respective x- and y-coordinates; formally `p1 == p2` if `p1.x == p2.x && p1.y == p2.y`. In type theories that allow quotient types, an additional requirement is made that all operations must respect the equivalence between elements. For example, if `f` is a function on values of type `Point`, it must be the case that for two `Point`s `p1` and `p2`, if `p1 == p2` then `f(p1) == f(p2)`.

:::

Quotient types are part of a general class of types known as [algebraic data types](https://en.wikipedia.org/wiki/Algebraic_data_type). In the early 1980s, quotient types were defined and implemented as part of the [Nuprl](wikipedia://en/45609427) [proof assistant](wikipedia://en/1258607), in work led by [Robert L. Constable](https://en.wikipedia.org/wiki/Robert_L._Constable) and others.[^o2][^o3] Quotient types have been studied in the context of [Martin-Löf type theory](https://en.wikipedia.org/wiki/Martin-Löf_type_theory),[^o4] [dependent type theory](https://en.wikipedia.org/wiki/Dependent_type_theory),[^o5] [higher-order logic](wikipedia://en/562883),[^o6] and [homotopy type theory](wikipedia://en/33974223).[^o7]

::: {#o9 .definition cue=heading name="Definition"}

## Definition {#Definition}

To define a quotient type, one typically provides a [data type](https://en.wikipedia.org/wiki/Data_type) together with an [equivalence relation](wikipedia://en/9259) on that type, for example, `Point // ==`, where `==` is a user-defined equality relation. The elements of the quotient type are [equivalence classes](wikipedia://en/9260) of elements of the original type.[^o4]

Quotient types can be used to define [modular arithmetic](wikipedia://en/20087). For example, if `Integer` is a data type of integers, $\equiv_2$ can be defined by saying that $x \equiv_2 y$ if the difference $x - y$ is even. We then form the type of integers modulo 2:[^o2]

`Integer //` $\equiv_2$

The operations on integers, `+`, `-` can be proven to be well-defined on the new quotient type.

:::

## Variations {#Variations}

In type theories that lack quotient types, [setoids](wikipedia://en/769434) (sets explicitly equipped with an equivalence relation) are often used instead of quotient types. However, unlike with setoids, many type theories may require a [formal proof](wikipedia://en/1197184) that any functions defined on quotient types are [well-defined](wikipedia://en/9259#well-definedness_under_an_equivalence_relation).[^o12]

:::

::: {#o14 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Quotient types are part of a general class of types known as [algebraic data types](https://en.wikipedia.org/wiki/Algebraic_data_type). Just as [product types](wikipedia://en/14892710) and [sum types](https://en.wikipedia.org/wiki/Sum_type) are analogous to the cartesian product and disjoint union of abstract algebraic structures, quotient types reflect the concept of set-theoretic [quotients](https://en.wikipedia.org/wiki/Quotient_set), sets whose elements are partitioned into [equivalence classes](wikipedia://en/9260) by a given equivalence relation on the set. Algebraic structures whose [underlying set](https://en.wikipedia.org/wiki/Underlying_set) is a quotient are also termed quotients. Examples of such quotient structures include quotient [sets](https://en.wikipedia.org/wiki/Quotient_set), [groups](wikipedia://en/11526), [rings](wikipedia://en/184635), [categories](wikipedia://en/4004632) and, in topology, [quotient spaces](wikipedia://en/237213).[^o4]
