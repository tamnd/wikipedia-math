# SOFA Statistics

::: {#o2 .subject cue=lead name="SOFA Statistics"}

**SOFA Statistics** is an [open-source](https://en.wikipedia.org/wiki/Open-source_software) [statistical package](https://en.wikipedia.org/wiki/Statistical_package). The name stands for *Statistics Open For All*.

:::

It has a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface) and can connect directly to [MySQL](https://en.wikipedia.org/wiki/MySQL), [PostgreSQL](https://en.wikipedia.org/wiki/PostgreSQL), [SQLite](https://en.wikipedia.org/wiki/SQLite), [MS Access](https://en.wikipedia.org/wiki/MS_Access) (map), and [Microsoft SQL Server](https://en.wikipedia.org/wiki/Microsoft_SQL_Server). Data can also be imported from [CSV](https://en.wikipedia.org/wiki/Comma-separated_values) and [Tab-Separated](https://en.wikipedia.org/wiki/Tab-separated_values) files or spreadsheets ([Microsoft Excel](https://en.wikipedia.org/wiki/Microsoft_Excel), [OpenOffice.org Calc](https://en.wikipedia.org/wiki/OpenOffice.org_Calc), [Gumeric](https://en.wikipedia.org/wiki/Gnumeric), [Google Docs](https://en.wikipedia.org/wiki/Google_Docs)). The main statistical tests available are [Independent and Paired t-tests](https://en.wikipedia.org/wiki/T_test), [Wilcoxon signed ranks](wikipedia://en/1954987), [Mann–Whitney U](https://en.wikipedia.org/wiki/Mann–Whitney_U), [Pearson's chi squared](wikipedia://en/226676), [Kruskal Wallis H](https://en.wikipedia.org/wiki/Kruskal–Wallis_one-way_analysis_of_variance), [one-way ANOVA](wikipedia://en/634), [Spearman's R](wikipedia://en/235623), and [Pearson's R](https://en.wikipedia.org/wiki/Pearson_product-moment_correlation_coefficient). Nested tables can be produced with row and column percentages, totals, [standard deviation](wikipedia://en/27590), [mean](wikipedia://en/612), [median](wikipedia://en/18837), [lower and upper quartiles](wikipedia://en/25170), and sum.

Installation packages are available for several [operating systems](https://en.wikipedia.org/wiki/Operating_system) such as [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [Ubuntu](https://en.wikipedia.org/wiki/Ubuntu_%28operating_system%29), [Arch Linux](https://en.wikipedia.org/wiki/Arch_Linux), [Linux Mint](https://en.wikipedia.org/wiki/Linux_Mint). On [macOS](https://en.wikipedia.org/wiki/MacOS), SOFA only runs on older versions the OS with [Leopard](https://en.wikipedia.org/wiki/Mac_OS_X_Leopard) being the minimum version.

SOFA Statistics is written in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), and the [widget toolkit](https://en.wikipedia.org/wiki/Widget_toolkit) used is [WxPython](https://en.wikipedia.org/wiki/WxPython). The statistical analyses are based on functions available through the [SciPy](https://en.wikipedia.org/wiki/Scipy) stats module.[^o3]

## Statistics features - workflows {#Statistics_features_-_workflows}

Users are guided through the selection of the appropriate basic statistical methods and assignment of the basic statistical on the table column of the data that should be analyzed. The features available within SOFA for statistical analysis are limited compared to those found in Open Source [R Statistics Software](https://en.wikipedia.org/wiki/R_%28language%29), which contains a large [repository of statistics packages](wikipedia://en/65740838).

## Evaluating Accuracy {#Evaluating_Accuracy}

One paper compared the results of frequencies, means, correlations and regression from a number of free to use menu driven statistical packages, including SOFA, and found all of the packages produced about the same results.[^o6]
