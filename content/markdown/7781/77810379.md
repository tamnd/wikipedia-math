# WRPN Calculator

::: {#o1 .subject cue=lead name="WRPN Calculator"}

**WRPN** (or **Windows Reverse Polish Notation**) is an [open-source](https://en.wikipedia.org/wiki/Open-source_software) scientific [software calculator](wikipedia://en/17056775), simulating the Hewlett-Packard Voyager series' [HP-16C](https://en.wikipedia.org/wiki/HP-16C) "Computer Scientist" [programmable calculator](https://en.wikipedia.org/wiki/Programmable_calculator).

:::

## History {#History}

On April 3, 1995, Emmet P. Gray,[^o4] an American [programmer](https://en.wikipedia.org/wiki/Programmer), at the time civilian employee at the [US Army](https://en.wikipedia.org/wiki/US_Army), now [adjunct professor](https://en.wikipedia.org/wiki/Adjunct_professor) at the [Texas A&M University](https://en.wikipedia.org/wiki/Texas_A&M_University),[^o5] released *WRPN* 1.0 ([16-bit](https://en.wikipedia.org/wiki/16-bit_computing)), a [public domain](https://en.wikipedia.org/wiki/Public_domain) [open-source software](https://en.wikipedia.org/wiki/Open-source_software) written in [Borland C++](https://en.wikipedia.org/wiki/Borland_C++) 4.0 for early versions of [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows).[^o6][^o7][^o8][^o9]

As of September 2024 the project is still in active development, and the latest *WRPN* 7.1.1 was released on August 26, 2024, for modern operating systems with [Java](https://en.wikipedia.org/wiki/Java_Runtime_Environment) installed, and as a mobile application for [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29). Source code is available in [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29), [VB.NET](https://en.wikipedia.org/wiki/Visual_Basic_%28.NET%29), [ASP.NET](https://en.wikipedia.org/wiki/ASP.NET) and [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29).[^o10]

## Features {#Features}

*WRPN* simulates almost all of the functions of HP-16C:

- RPN ([Reverse Polish notation](wikipedia://en/26513)) input support
- Floating point, Decimal, Hexadecimal, Octal and Binary modes
- Word sizes from 1–64 bits per word
- Signed math
- [Logical operators](https://en.wikipedia.org/wiki/Logical_operators)
- [Bitwise operators](https://en.wikipedia.org/wiki/Bitwise_operators)
- 32 storage registers
- 4 position stack
- 203 lines of program memory

## JRPN {#JRPN}

In 2019 Bill Foote, an American software engineer and ex-Lead of the [Sun Microsystems](https://en.wikipedia.org/wiki/Sun_Microsystems)' standardization of interactive technologies for [Blu-ray](https://en.wikipedia.org/wiki/Blu-ray) and other TV platforms,[^o13] created the *JRPN* (*[JOVIAL](https://en.wikipedia.org/wiki/JOVIAL) Reverse Polish Notation Calculators*), an open-source HP-16C simulator, [forked](https://en.wikipedia.org/wiki/Fork_%28software_development%29) from *WRPN* 6.0.2 in Java, but with all of the text set to be rendered from [vector fonts](https://en.wikipedia.org/wiki/Vector_font) (instead of the [bitmap font](https://en.wikipedia.org/wiki/Bitmap_font) used in *WRPN*), and licensed it under the free [Apache License](https://en.wikipedia.org/wiki/Apache_License).[^o14]

During the [COVID-19 pandemic](https://en.wikipedia.org/wiki/COVID-19_pandemic) Foote fully rewrote *JRPN* code in [Flutter](https://en.wikipedia.org/wiki/Flutter_%28software%29) and licensed it under [GPLv3](https://en.wikipedia.org/wiki/GPLv3).[^o15] *JRPN* is available now in two variants, 15C and 16C (simulating [HP-15C](https://en.wikipedia.org/wiki/HP-15C) and HP-16C accordingly), for Android, Linux, Mac OS, Windows and as a [web application](https://en.wikipedia.org/wiki/Web_application).[^o16]

Also there is another RPN calculator of the same name, developed by William Giel as freeware proprietary software. It has been last released in 1999.[^o17]
