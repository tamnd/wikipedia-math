# Monotonically normal space

::: {#o1 .subject cue=lead name="Monotonically normal space"}

In mathematics, specifically in the field of [topology](wikipedia://en/29954), a **monotonically normal space** is a particular kind of [normal space](wikipedia://en/48629), defined in terms of a monotone normality operator. It satisfies some interesting properties; for example metric spaces and linearly ordered spaces are monotonically normal, and every monotonically normal space is [hereditarily normal](https://en.wikipedia.org/wiki/Hereditarily_normal_space).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [topological space](wikipedia://en/30450) $X$ is called **monotonically normal** if it satisfies any of the following equivalent definitions:[^o4][^o5][^o6][^o7]

### Definition 1 {#Definition_1}

The space $X$ is [T<sub>1</sub>](wikipedia://en/148721) and there is a function $G$ that assigns to each ordered pair $(A,B)$ of disjoint closed sets in $X$ an open set $G(A,B)$ such that:

(i) $A\subseteq G(A,B)\subseteq \overline{G(A,B)}\subseteq X\setminus B$;

(ii) $G(A,B)\subseteq G(A',B')$ whenever $A\subseteq A'$ and $B'\subseteq B$.

Condition (i) says $X$ is a normal space, as witnessed by the function $G$. Condition (ii) says that $G(A,B)$ varies in a monotone fashion, hence the terminology *monotonically normal*. The operator $G$ is called a **monotone normality operator**.

One can always choose $G$ to satisfy the property

$$G(A,B)\cap G(B,A)=\emptyset,$$

by replacing each $G(A,B)$ by $G(A,B)\setminus\overline{G(B,A)}$.

### Definition 2 {#Definition_2}

The space $X$ is T<sub>1</sub> and there is a function $G$ that assigns to each ordered pair $(A,B)$ of [separated sets](wikipedia://en/148911) in $X$ (that is, such that $A\cap\overline{B}=B\cap\overline{A}=\emptyset$) an open set $G(A,B)$ satisfying the same conditions (i) and (ii) of Definition 1.

### Definition 3 {#Definition_3}

The space $X$ is T<sub>1</sub> and there is a function $\mu$ that assigns to each pair $(x,U)$ with $U$ open in $X$ and $x\in U$ an open set $\mu(x,U)$ such that:

(i) $x\in\mu(x,U)$;

(ii) if $\mu(x,U)\cap\mu(y,V)\ne\emptyset$, then $x\in V$ or $y\in U$.

Such a function $\mu$ automatically satisfies

$$x\in\mu(x,U)\subseteq\overline{\mu(x,U)}\subseteq U.$$

(*Reason*: Suppose $y\in X\setminus U$. Since $X$ is T<sub>1</sub>, there is an open neighborhood $V$ of $y$ such that $x\notin V$. By condition (ii), $\mu(x,U)\cap\mu(y,V)=\emptyset$, that is, $\mu(y,V)$ is a neighborhood of $y$ disjoint from $\mu(x,U)$. So $y\notin\overline{\mu(x,U)}$.)[^o11]

### Definition 4 {#Definition_4}

Let $\mathcal{B}$ be a [base](wikipedia://en/59220) for the [topology](https://en.wikipedia.org/wiki/Topology_%28structure%29) of $X$. The space $X$ is T<sub>1</sub> and there is a function $\mu$ that assigns to each pair $(x,U)$ with $U\in\mathcal{B}$ and $x\in U$ an open set $\mu(x,U)$ satisfying the same conditions (i) and (ii) of Definition 3.

### Definition 5 {#Definition_5}

The space $X$ is T<sub>1</sub> and there is a function $\mu$ that assigns to each pair $(x,U)$ with $U$ open in $X$ and $x\in U$ an open set $\mu(x,U)$ such that:

(i) $x\in\mu(x,U)$;

(ii) if $U$ and $V$ are open and $x\in U\subseteq V$, then $\mu(x,U)\subseteq\mu(x,V)$;

(iii) if $x$ and $y$ are distinct points, then $\mu(x,X\setminus\{y\})\cap\mu(y,X\setminus\{x\})=\emptyset$.

Such a function $\mu$ automatically satisfies all conditions of Definition 3.

:::

::: {#o15 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [metrizable space](wikipedia://en/19738) is monotonically normal.[^o7]
- Every [linearly ordered topological space](wikipedia://en/213650) (LOTS) is monotonically normal.[^o16][^o7] This is assuming the [Axiom of Choice](https://en.wikipedia.org/wiki/Axiom_of_Choice), as without it there are examples of LOTS that are not even normal.[^o17]
- The [Sorgenfrey line](https://en.wikipedia.org/wiki/Sorgenfrey_line) is monotonically normal.[^o7] This follows from Definition 4 by taking as a base for the topology all intervals of the form $[a,b)$ and for $x\in[a,b)$ by letting $\mu(x,[a,b))=[x,b)$. Alternatively, the Sorgenfrey line is monotonically normal because it can be embedded as a subspace of a LOTS, namely the [double arrow space](https://en.wikipedia.org/wiki/Double_arrow_space).
- Any [generalised metric](wikipedia://en/13403260) is monotonically normal.

:::

::: {#o19 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Monotone normality is a [hereditary property](wikipedia://en/13552465): Every subspace of a monotonically normal space is monotonically normal.
- Every monotonically normal space is [completely normal Hausdorff](https://en.wikipedia.org/wiki/Completely_normal_Hausdorff_space) (or T<sub>5</sub>).
- Every monotonically normal space is [hereditarily collectionwise normal](https://en.wikipedia.org/wiki/Hereditarily_collectionwise_normal).[^o20]
- The image of a monotonically normal space under a continuous [closed map](https://en.wikipedia.org/wiki/Closed_map) is monotonically normal.[^o21]
- A compact Hausdorff space $X$ is the continuous image of a compact linearly ordered space if and only if $X$ is monotonically normal.[^o22][^o6]

:::
