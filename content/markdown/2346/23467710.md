# Exponential map (discrete dynamical systems)

::: {#o1 .subject cue=lead name="Exponential map"}

*Image: Exponential Parameter Space Detail PSP Rays.png.* Parameter plane of the complex exponential family f(z)=exp(z)+c with 8 [external ( parameter) rays](wikipedia://en/4804435)

In the theory of [dynamical systems](wikipedia://en/9087), the **exponential map** can be used as the [evolution function](https://en.wikipedia.org/wiki/Dynamical_system_%28definition%29) of [the discrete nonlinear dynamical system](wikipedia://en/146806).[^o2]

:::

## Family {#Family}

The family of [exponential functions](wikipedia://en/9678) is called the **exponential family**.

## Forms {#Forms}

There are many **forms** of these maps,[^o5] many of which are equivalent under a coordinate transformation. For example two of the most common ones are:

- $$E_c : z \to e^z + c$$
- $$E_\lambda : z \to \lambda e^z$$

The second one can be mapped to the first using the fact that $\lambda e^z = e^{z+\ln(\lambda)}$, so $E_\lambda : z \to e^z + \ln(\lambda)$ is the same under the transformation $z=z+\ln(\lambda)$. The only difference is that, due to multi-valued properties of exponentiation, there may be a few select cases that can only be found in one version. Similar arguments can be made for many other formulas.
