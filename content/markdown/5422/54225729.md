# Moschovakis coding lemma

::: {#o1 .subject cue=lead name="Moschovakis coding lemma"}

The **Moschovakis coding lemma** is a [lemma](wikipedia://en/18634) from descriptive [set theory](wikipedia://en/27553) involving sets of [real numbers](wikipedia://en/20646438) under the [axiom of determinacy](wikipedia://en/1002300) (the principle — incompatible with [choice](wikipedia://en/840) — that every two-player integer game is determined). The lemma was developed and named after the mathematician [Yiannis N. Moschovakis](wikipedia://en/2291002).

:::

The lemma may be expressed generally as follows:

Let $\Gamma$ be a non-selfdual [pointclass](wikipedia://en/9304834) closed under [real quantification](wikipedia://en/43507260#Range_of_quantification) and $\land$, and $\prec$ a $\Gamma$-well-founded relation on $\omega^{\omega}$ of rank $\theta \in \operatorname{ON}$. Let $R \subseteq \operatorname{dom}(\prec) \times \omega^{\omega}$ be such that $(\forall x\in\operatorname{dom}(\prec))(\exists y)(x R y)$. Then there is a $\Gamma$-set $A \subseteq \operatorname{dom}(\prec) \times \omega^{\omega}$ which is a [choice set](https://en.wikipedia.org/wiki/Choice_set) for R, that is:

1. $$(\forall\alpha<\theta)(\exists x\in\operatorname{dom}(\prec),y)(x_{\prec}=\alpha \land x A y).$$
1. $$(\forall x,y)(x A y \to x R y).$$

A proof runs as follows: suppose for contradiction $\theta$ is a minimal counterexample, and fix $\prec$, $R$, and a good universal set $U \subseteq (\omega^{\omega})^{3}$ for the $\Gamma$-subsets of $(\omega^{\omega})^{2}$. Easily, $\theta$ must be a limit ordinal. For $\delta < \theta$, we say $u \in \omega^{\omega}$ codes a $\delta$-choice set provided the property (1) holds for $\alpha \le \delta$ using $A = U u$ and property (2) holds for $A = U u$ where we replace $x \in \operatorname{dom}(\prec)$ with $x \in \operatorname{dom}(\prec) \land x \prec [\le\delta]$. By minimality of $\theta$, for all $\delta < \theta$, there are $\delta$-choice sets.

Now, play a game where players I, II select points $u,v \in \omega^{\omega}$ and II wins when $u$ coding a $\delta_{1}$-choice set for some $\delta_{1} < \theta$ implies $v$ codes a $\delta_{2}$-choice set for some $\delta_{2} > \delta_{1}$. A winning strategy for I defines a $\Sigma^{1}_{1}$ set $B$ of reals encoding $\delta$-choice sets for arbitrarily large $\delta < \theta$. Define then

$$x A y \leftrightarrow (\exists w\in B)U(w,x,y),$$

which easily works. On the other hand, suppose $\tau$ is a winning strategy for II. From the [S theorem](wikipedia://en/2330936), let $s:(\omega^{\omega})^{2} \to \omega^{\omega}$ be continuous such that for all $\epsilon$, $x$, $t$, and $w$,

$$U(s(\epsilon,x),t,w) \leftrightarrow (\exists y,z)(y \prec x \land U(\epsilon,y,z) \land U(z,t,w)).$$

By the recursion theorem, there exists $\epsilon_{0}$ such that $U(\epsilon_{0},x,z) \leftrightarrow z = \tau(s(\epsilon_{0},x))$. A straightforward induction on $x_{\prec}$ for $x \in \operatorname{dom}(\prec)$ shows that

$$(\forall x\in\operatorname{dom}(\prec))(\exists!z)U(\epsilon_{0},x,z),$$

and

$$(\forall x\in\operatorname{dom}(\prec),z)(U(\epsilon_{0},x,z) \to z \operatorname{encodes} a \operatorname{choice} \operatorname{set}\text{ of } \operatorname{ordinal} \ge x_{\prec}).$$

So let

$x A y \leftrightarrow (\exists z\in\operatorname{dom}(\prec),w)(U(\epsilon_{0},z,w) \land U(w,x,y))$.[^o2][^o3][^o4]
