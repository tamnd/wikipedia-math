# Herbrand interpretation

::: {#o1 .subject cue=lead name="Herbrand interpretation"}

In [mathematical logic](wikipedia://en/19636), a **Herbrand interpretation** is an [interpretation](wikipedia://en/14511671) in which all [constants](wikipedia://en/4089175) and function symbols are assigned very simple meanings.[^o2] Specifically, every constant is interpreted as itself, and every function symbol is interpreted as the application [function](wikipedia://en/185427) on [terms](wikipedia://en/24885593). The interpretation also defines [predicate](https://en.wikipedia.org/wiki/Predicate_%28mathematical_logic%29) symbols as denoting a subset of the relevant [Herbrand base](https://en.wikipedia.org/wiki/Herbrand_base), effectively specifying which [ground atoms](https://en.wikipedia.org/wiki/Ground_atom) are true in the interpretation. This allows the symbols in a set of clauses to be interpreted in a purely [syntactic](wikipedia://en/26860) way, separated from any real instantiation.

:::

The importance of Herbrand interpretations is that, if there exists an interpretation that [satisfies](https://en.wikipedia.org/wiki/Satisfiable) a given set of [clauses](wikipedia://en/4638484) *S* then there is a Herbrand interpretation that satisfies the clauses. Moreover, [Herbrand's theorem](wikipedia://en/2518328) states that if *S* is unsatisfiable then there is a finite unsatisfiable set of ground instances from the [Herbrand universe](https://en.wikipedia.org/wiki/Herbrand_universe) defined by *S*. Since this set is finite, its unsatisfiability can be verified in finite time. However, there may be an infinite number of such sets to check.

Herbrand interpretations are named after [Jacques Herbrand](wikipedia://en/159901).
