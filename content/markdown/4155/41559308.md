# Sampling in order

::: {#o1 .subject cue=lead name="Sampling in order"}

In [statistics](wikipedia://en/26685), some [Monte Carlo methods](wikipedia://en/56098) require independent observations in a sample to be drawn from a one-dimensional distribution in [sorted order](wikipedia://en/28442). In other words, all *n* [order statistics](wikipedia://en/160986) are needed from the *n* observations in a sample. The naive method performs a sort and takes *O*(*n* log *n*) time. There are also *O*(*n*) algorithms which are better suited for large *n*. The special case of drawing *n* sorted observations from the [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on \[0,1\] is equivalent to drawing from the uniform distribution on an *n*-dimensional [simplex](wikipedia://en/39781); this task is a part of [sequential importance resampling](https://en.wikipedia.org/wiki/Sequential_importance_resampling).

:::
