# Decomposable measure

::: {#o1 .subject cue=lead name="Decomposable measure"}

In mathematics, a **decomposable measure**[^n1] (also known as a **strictly localizable measure**) is a [measure](wikipedia://en/19873) that is a [disjoint union](wikipedia://en/188946) of [finite measures](wikipedia://en/4316185). This is a generalization of [σ-finite measures](wikipedia://en/4316174), which are the same as those that are a disjoint union of *[countably many](https://en.wikipedia.org/wiki/Countably_many)* finite measures. There are several theorems in [measure theory](https://en.wikipedia.org/wiki/Measure_theory) such as the [Radon–Nikodym theorem](wikipedia://en/338746) that are not true for arbitrary measures but are true for σ-finite measures. Several such theorems remain true for the more general class of decomposable measures. This extra generality is not used much as most decomposable measures that occur in practice are σ-finite.

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- [Counting measure](wikipedia://en/191786) on an uncountable measure space with all subsets measurable is a decomposable measure that is not σ-finite. [Fubini's theorem and Tonelli's theorem](wikipedia://en/255245) hold for σ-finite measures but can fail for this measure.
- Counting measure on an uncountable measure space with not all subsets measurable is generally not a decomposable measure.
- The one-point space of measure infinity is not decomposable.

:::
