# List of undecidable problems

::: {#o1 .subject cue=lead name="List of undecidable problems"}

In [computability theory](wikipedia://en/155414), an [undecidable problem](wikipedia://en/15631055) is a [decision problem](wikipedia://en/8336) for which an [effective method](wikipedia://en/12979890) (algorithm) to derive the correct answer does not exist. More formally, an undecidable problem is a problem whose language is not a [recursive set](https://en.wikipedia.org/wiki/Recursive_set); see the article [Decidable language](https://en.wikipedia.org/wiki/Decidable_language). There are [uncountably](wikipedia://en/32248) many undecidable problems, so the list below is necessarily incomplete. Though undecidable languages are not recursive languages, they may be [subsets](wikipedia://en/27631) of [Turing](wikipedia://en/1208) recognizable languages: i.e., such undecidable languages may be recursively enumerable.

:::

Many, if not most, undecidable problems in mathematics can be posed as [word problems](wikipedia://en/3852079): determining when two distinct strings of symbols (encoding some mathematical concept or object) represent the same object or not.

For undecidability in axiomatic mathematics, see [List of statements undecidable in ZFC](https://en.wikipedia.org/wiki/List_of_statements_undecidable_in_ZFC).

## Problems about abstract machines {#Problems_about_abstract_machines}

::: {#o3 .entry cue=list-entry name="Halting problem"}

- The [halting problem](wikipedia://en/21391870) (determining whether a [Turing machine](wikipedia://en/30403) halts on a given input) and the [mortality problem](https://en.wikipedia.org/wiki/Mortality_%28computability_theory%29) (determining whether it halts for every starting configuration).

:::

::: {#o4 .entry cue=list-entry name="busy beaver champion"}

- Determining whether a Turing machine is a [busy beaver champion](wikipedia://en/67911#Non-computability) (i.e., is the longest-running among halting Turing machines with the same number of states and symbols).

:::

::: {#o5 .entry cue=list-entry name="Rice's theorem"}

- [Rice's theorem](wikipedia://en/25852) states that for all nontrivial properties of partial functions, it is undecidable whether a given machine computes a partial function with that property.

:::

::: {#o6 .entry cue=list-entry name="Register machine"}

- The halting problem for a [register machine](wikipedia://en/505218): a finite-state automaton with no inputs and two counters that can be incremented, decremented, and tested for zero.

:::

::: {#o7 .entry cue=list-entry name="Pushdown automaton"}

- Universality of a nondeterministic [pushdown automaton](wikipedia://en/24510): determining whether all words are accepted.

:::

::: {#o8 .entry cue=list-entry name="Conway's Game of Life"}

- [Conway's Game of Life](wikipedia://en/37035#Undecidability) on whether, given an initial pattern and another pattern, the latter pattern can ever appear from the initial one.

:::

::: {#o9 .entry cue=list-entry name="Rule 110"}

- [Rule 110](wikipedia://en/491028) - most questions involving "can property X appear later" are undecidable.

:::

## Problems in formal logic and grammars {#Problems_in_formal_logic_and_grammars}

::: {#o11 .entry cue=list-entry name="Entscheidungsproblem"}

- Hilbert's [Entscheidungsproblem](wikipedia://en/9672).

:::

::: {#o12 .entry cue=list-entry name="Type inference"}

- [Type inference](wikipedia://en/279690) and [type checking](https://en.wikipedia.org/wiki/Type_checking) for the [second-order lambda calculus](https://en.wikipedia.org/wiki/Second-order_lambda_calculus) (or equivalent).[^o13]

:::

::: {#o14 .entry cue=list-entry name="Logic of graphs"}

- Determining whether a first-order sentence in the [logic of graphs](wikipedia://en/47857242) can be realized by a finite undirected graph.[^o15]

:::

::: {#o16 .entry cue=list-entry name="Trakhtenbrot's theorem"}

- [Trakhtenbrot's theorem](wikipedia://en/4232656) - Finite satisfiability is undecidable.

:::

::: {#o17 .entry cue=list-entry name="Horn clause"}

- Satisfiability of first order [Horn clauses](wikipedia://en/333824).

:::

::: {#o18 .entry cue=list-entry name="λ-calculus"}

- Determining whether a [λ-calculus](wikipedia://en/18203#Undecidability_of_equivalence) formula has a normal form.

:::

::: {#o19 .entry cue=list-entry name="Post correspondence problem"}

- The [Post correspondence problem](wikipedia://en/64685): whether a [tag system](https://en.wikipedia.org/wiki/Tag_system) halts. There are [many variants](wikipedia://en/64685#Variants) thereof.

:::

::: {#o20 .entry cue=list-entry name="Context-free grammar"}

- Determining if a [context-free grammar](wikipedia://en/6759) generates all possible strings, or if it is [ambiguous](wikipedia://en/647729).

:::

- Given two context-free grammars, determining whether they generate the same set of strings, or whether one generates a subset of the strings generated by the other, or whether there is any string at all that both generate.

::: {#o21 .entry cue=list-entry name="the page section"}

- Some other problems about CFG are also undecidable. See [the page section](wikipedia://en/6759#Language_equality) for details.

:::

::: {#o22 .entry cue=list-entry name="Emptiness problem"}

- The [emptiness problem](wikipedia://en/57342784): determining whether a language is empty given some representation of it, such as a [finite-state automaton](https://en.wikipedia.org/wiki/Finite-state_automaton). It is undecidable for [context-sensitive grammars](wikipedia://en/6211).

:::

## Problems about matrices {#Problems_about_matrices}

::: {#o24 .entry cue=list-entry name="Mortal matrix problem"}

- The [mortal matrix problem](https://en.wikipedia.org/wiki/Mortal_matrix_problem).

:::

::: {#o25 .entry cue=list-entry name="free"}

- Determining whether a finite set of upper triangular 3 × 3 matrices with nonnegative integer entries generates a [free](wikipedia://en/333835) [semigroup](wikipedia://en/27799).[^o26]

:::

::: {#o27 .entry cue=list-entry name="subsemigroups"}

- Determining whether two finitely generated [subsemigroups](https://en.wikipedia.org/wiki/Subsemigroup) of [integer matrices](https://en.wikipedia.org/wiki/Integer_matrices) have a common element.[^o28]

:::

::: {#o29 .entry cue=list-entry name="Joint spectral radius"}

- Given a finite set of n×n matrices $A_1, \dots, A_m$, their [joint spectral radius](https://en.wikipedia.org/wiki/Joint_spectral_radius) is defined as $\limsup_{N \to \infty} \max_{i_1, \dots, i_N \in 1:m}\|A_{i_1}\cdots, A_{i_N}\|^{1/N}$. For a set of 2 matrices with rational entries, the problem of deciding whether their joint spectral radius is $\leq 1$ is undecidable.[^o30]

:::

## Problems in topology {#Problems_in_topology}

::: {#o36 .entry cue=list-entry name="Simplicial complex"}

- Determining whether two finite [simplicial complexes](wikipedia://en/252686) are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic).

:::

::: {#o37 .entry cue=list-entry name="Simplicial complex"}

- Determining whether a finite [simplicial complex](wikipedia://en/252686) is (homeomorphic to) a [manifold](wikipedia://en/2073470).

:::

::: {#o38 .entry cue=list-entry name="Fundamental group"}

- Determining whether the [fundamental group](wikipedia://en/11004) of a finite simplicial complex is trivial.

:::

::: {#o39 .entry cue=list-entry name="Simply connected"}

- Determining whether two non-[simply connected](https://en.wikipedia.org/wiki/Simply_connected) [5-manifolds](wikipedia://en/7763362) are homeomorphic, or if a 5-manifold is homeomorphic to **S**<sup>5</sup>.[^o40]

:::

## Problems in number theory {#Problems_in_number_theory}

::: {#o42 .entry cue=list-entry name="Hilbert's tenth problem"}

- [Hilbert's tenth problem](wikipedia://en/101851): the problem of deciding whether a Diophantine equation (multivariable polynomial equation) has a solution in integers.

:::

## Problems in analysis {#Problems_in_analysis}

::: {#o44 .entry cue=list-entry name="Richardson's theorem"}

- For functions in certain classes, the problem of determining: whether two functions are equal, known as the zero-equivalence problem (see [Richardson's theorem](wikipedia://en/13463844));[^o45] the zeroes of a function; whether the indefinite integral of a function is also in the class.[^o47] Of course, some subclasses of these problems are decidable. For example, there is an effective decision procedure for the elementary integration of any function which belongs to a field of transcendental elementary functions, the [Risch algorithm](wikipedia://en/289450).

:::

::: {#o46 .entry cue=list-entry name="MRDP theorem"}

- "The problem of deciding whether the definite contour multiple integral of an elementary meromorphic function is zero over an everywhere real analytic manifold on which it is analytic", a consequence of the [MRDP theorem](https://en.wikipedia.org/wiki/Matiyasevich's_theorem) resolving [Hilbert's tenth problem](wikipedia://en/101851).[^o47]

:::

::: {#o48 .entry cue=list-entry name="Ordinary differential equation"}

- Determining the domain of a solution to an [ordinary differential equation](wikipedia://en/32742753) of the form

:::

$$\frac{dx}{dt} = p(t, x),~x(t_0)=x_0,$$

where *x* is a [vector](wikipedia://en/23218956) in **R**<sup>n</sup>, *p*(*t*, *x*) is a vector of [polynomials](wikipedia://en/23000) in *t* and *x*, and *(t<sub>0</sub>, x<sub>0</sub>)* belongs to **R**<sup>n+1</sup>.[^o49]

## Problems in physics {#Problems_in_physics}

::: {#o51 .entry cue=list-entry name="spectral gap"}

- Determining whether a quantum mechanical system has a [spectral gap](https://en.wikipedia.org/wiki/Spectral_gap_%28physics%29).[^o52][^o53]

:::

::: {#o54 .entry cue=list-entry name="ray tracing"}

- In the [ray tracing](https://en.wikipedia.org/wiki/Ray_tracing_%28graphics%29) problem for a 3-dimensional system of reflective or refractive objects, determining if a ray beginning at a given position and direction eventually reaches a certain point.[^o55]

:::

- Determining if a particle path of an ideal fluid on a three dimensional domain eventually reaches a certain region in space.[^o56][^o57]

## Other problems {#Other_problems}

::: {#o59 .entry cue=list-entry name="Wang tile"}

- The problem of determining if a given set of [Wang tiles](wikipedia://en/65798) can tile the plane.

:::

::: {#o60 .entry cue=list-entry name="Polyominoes"}

- The problem of determining if a given set of [polyominoes](https://en.wikipedia.org/wiki/Polyominoes) can tile the plane.[^o61]

:::

::: {#o62 .entry cue=list-entry name="Kolmogorov complexity"}

- The problem of determining the [Kolmogorov complexity](wikipedia://en/1635) of a string.

:::

- Determining whether a given initial point with rational coordinates is periodic, or whether it lies in the basin of attraction of a given open set, in a piecewise-linear iterated map in two dimensions, or in a piecewise-linear flow in three dimensions.[^o63]
- Finding the capacity of an information-stable finite state machine channel.[^o64]

::: {#o65 .entry cue=list-entry name="Network coding"}

- In [network coding](https://en.wikipedia.org/wiki/Network_coding), determining whether a network is solvable.[^o66][^o67]

:::

::: {#o68 .entry cue=list-entry name="Magic: The Gathering"}

- Determining whether a player has a winning strategy in a game of *[Magic: The Gathering](https://en.wikipedia.org/wiki/Magic:_The_Gathering)*.[^o69]

:::

::: {#o70 .entry cue=list-entry name="Partially observable Markov decision process"}

- Planning in a [partially observable Markov decision process](wikipedia://en/3063552).

:::

::: {#o71 .entry cue=list-entry name="Air travel"}

- Planning [air travel](https://en.wikipedia.org/wiki/Air_travel) from one destination to another, when [fares](https://en.wikipedia.org/wiki/Fare) are taken into account.[^o72]

:::
