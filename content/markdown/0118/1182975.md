# Dual basis in a field extension

::: {#o1 .subject cue=lead name="Dual basis in a field extension"}

In [mathematics](wikipedia://en/18831), the [linear algebra](wikipedia://en/18422) concept of [dual basis](wikipedia://en/1182982) can be applied in the context of a [finite](https://en.wikipedia.org/wiki/Finite_extension) [field extension](wikipedia://en/11634) *L*/*K*, by using the [field trace](wikipedia://en/457105). This requires the property that the field trace *Tr*<sub>*L*/*K*</sub> provides a [non-degenerate](https://en.wikipedia.org/wiki/Non-degenerate) [quadratic form](wikipedia://en/251478) over *K*. This is true if *L* is [separable](wikipedia://en/363340) over *K*; it is always true if *K* is a [perfect field](wikipedia://en/505088), including when *K* is [finite](wikipedia://en/11615) or of [characteristic](wikipedia://en/1066621) zero.

:::

A **dual basis** is not a specific [basis](wikipedia://en/18420) like the [polynomial basis](https://en.wikipedia.org/wiki/Polynomial_basis) or the [normal basis](wikipedia://en/1028589); rather for any given basis, it is another associated basis which is useful for computations.

We say that two bases of a finite field $L=\text{GF}(p^n)$ over $K = \text{GF}(p)=\mathbb{Z}/p\mathbb{Z}$,

$$B_1 = \{\alpha_0, \alpha_1, \ldots, \alpha_{n-1}\}, \qquad B_2 = \{\beta_0, \beta_1, \ldots, \beta_{n-1}\},$$

are **dual** to each other provided

$$\operatorname{Tr}(\alpha_i\cdot \beta_j) = \begin{cases} 1 & \text{if }\ i = j \\ 0 & \text{if }\ i\neq j. \end{cases}$$

Here the [trace](wikipedia://en/457105) of a value in GF(*p*<sup>*m*</sup>) can be calculated as follows:

$$\operatorname{Tr}(\gamma ) = \sum_{i=0}^{n-1} \gamma^{p^i}$$

Using a dual basis can provide a way to easily communicate between devices that use different bases, rather than having to explicitly convert between bases using the [change of bases](wikipedia://en/1179451) formula. Furthermore, if a dual basis is implemented then conversion from an element in the original basis to the dual basis can be accomplished with multiplication by the multiplicative identity (usually 1).
