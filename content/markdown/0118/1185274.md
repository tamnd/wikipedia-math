# Friend-to-friend

::: {#o1 .subject cue=lead name="Friend-to-friend"}

A **friend-to-friend** (**F2F**) **computer network** is a type of [peer-to-peer network](https://en.wikipedia.org/wiki/Peer-to-peer_network) in which users only make direct connections with people they know. [Passwords](https://en.wikipedia.org/wiki/Passwords) or [digital signatures](https://en.wikipedia.org/wiki/Digital_signatures) can be used for [authentication](wikipedia://en/47967).

:::

Unlike other kinds of [private P2P](https://en.wikipedia.org/wiki/Private_P2P), users in a friend-to-friend network cannot find out who else is participating beyond their own circle of friends, so F2F networks can grow in size without compromising their users' anonymity. [Retroshare](https://en.wikipedia.org/wiki/Retroshare), [WASTE](https://en.wikipedia.org/wiki/WASTE), [GNUnet](wikipedia://en/293685), [Freenet](https://en.wikipedia.org/wiki/Freenet) and [OneSwarm](https://en.wikipedia.org/wiki/OneSwarm) are examples of software that can be used to build F2F networks, though RetroShare is the only one of these configured for friend-to-friend operation by default.

Many F2F networks support indirect [anonymous](https://en.wikipedia.org/wiki/Anonymity) or [pseudonymous](https://en.wikipedia.org/wiki/Pseudonym) communication between users who do not know or trust one another. For example, a [node](https://en.wikipedia.org/wiki/Node_%28networking%29) in a friend-to-friend [overlay](https://en.wikipedia.org/wiki/Overlay_network) can automatically forward a file (or a request for a file) anonymously between two friends, without telling either of them the other's name or [IP address](https://en.wikipedia.org/wiki/IP_address). These friends can in turn automatically forward the same file (or request) to their own friends, and so on.

[Dan Bricklin](https://en.wikipedia.org/wiki/Dan_Bricklin) coined the term "friend-to-friend network" in 2000.[^o2]

## Potential applications of F2F {#Potential_applications_of_F2F}

- The Bouillon project uses a friend-to-friend network to assign trust ratings to messages.[^o4]
