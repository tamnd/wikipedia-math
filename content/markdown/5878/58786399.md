# Distance set

::: {#o1 .subject cue=lead name="Distance set"}

In [geometry](wikipedia://en/18973446), the **distance set** of a collection of points is the [set](wikipedia://en/26691) of [distances](wikipedia://en/39378) between distinct pairs of points. Thus, it can be seen as the generalization of a [difference set](https://en.wikipedia.org/wiki/Minkowski_difference), the set of distances (and their negations) in collections of numbers.

:::

Several problems and results in geometry concern distance sets, usually based on the principle that a large collection of points must have a large distance set (for varying definitions of "large"):

- [Falconer's conjecture](wikipedia://en/38368203) is the statement that, for a collection of points in $d$-dimensional space that has [Hausdorff dimension](wikipedia://en/14294) larger than $d/2$, the corresponding distance set has nonzero [Lebesgue measure](wikipedia://en/18198). Although partial results are known, the conjecture remains unproven.
- The [Erdős–Ulam problem](wikipedia://en/52483865) asks whether it is possible to have a [dense set](wikipedia://en/23523594) in the [Euclidean plane](wikipedia://en/15575410) whose distance set consists only of [rational numbers](wikipedia://en/19727024). Again, it remains unsolved.
- [Fermat's theorem on sums of two squares](wikipedia://en/1850216) characterizes the numbers in the distance set of the two-dimensional [integer lattice](wikipedia://en/3333402): they are the square roots of integers whose prime factorization does not contain an odd number of copies of any prime congruent to 3 mod 4. Analogously, [Legendre's three-square theorem](wikipedia://en/40708124) characterizes the distance set of the three-dimensional integer lattice, and [Lagrange's four-square theorem](wikipedia://en/326395) characterizes the distance set of integer lattices in four and higher dimensions as being the square roots of integers without any additional constraints. In lattices of five or more dimensions, every subset of the lattice with nonzero [upper density](wikipedia://en/1819983) has a distance set containing the squares of an infinite [arithmetic progression](wikipedia://en/168389).
- According to the [Erdős–Anning theorem](wikipedia://en/12600251), every infinite set of points in the Euclidean plane that does not lie on one line has a non-integer in its distance set.
- Square grids of points have distance sets of sublinear size, in contrast to points in [general position](wikipedia://en/383736) whose distance set is quadratic in size. However, according to the 2015 solution of the [Erdős distinct distances problem](wikipedia://en/30193394) by [Larry Guth](wikipedia://en/31875947) and [Nets Katz](https://en.wikipedia.org/wiki/Nets_Katz), the distance set of any finite collection of points in the Euclidean plane is only slightly sublinear, nearly as large as the given collection. In particular, only a finite collection of points can have a finite distance set.
- A [Golomb ruler](wikipedia://en/48211) is a finite set of points on a line such that no two pairs of points have the same distance. [Sophie Piccard](wikipedia://en/48027009) claimed that no two Golomb rulers have the same distance sets. The claim is incorrect, but there is only one counterexample, a pair of six-point Golomb rulers with a shared distance set.
- The [equilateral dimension](wikipedia://en/28417424) of a [metric space](wikipedia://en/20018) is the largest size of a collection of points whose distance set has only a single element. [Kusner's conjecture](https://en.wikipedia.org/wiki/Kusner's_conjecture) states that the equilateral dimension of a $d$-dimensional space with the [Manhattan distance](https://en.wikipedia.org/wiki/Manhattan_distance) is exactly $2d$, but this remains unproven.
- A **2-distance set** is a set of points for which the set of distinct mutual distances has cardinality exactly 2. An example of a 2-distance set is the set of vertices of the regular [octahedron](wikipedia://en/80177635). There are various results about 2-distance sets, including a classification of all 2-distance sets in dimension 4. Every 2-distance set is an [isosceles set](wikipedia://en/57831158), a set in which all triangles are isosceles. As a partial converse, every isosceles set that cannot be decomposed into two perpendicular subspaces is a 2-distance set.
- The [Universal chord theorem](wikipedia://en/52167339) states that for any [real function](https://en.wikipedia.org/wiki/Real_function), the distance set of the [level sets](wikipedia://en/559622) of the function is closed under division by integers.

Distance sets have also been used as a [shape descriptor](wikipedia://en/16576796) in [computer vision](https://en.wikipedia.org/wiki/Computer_vision).
