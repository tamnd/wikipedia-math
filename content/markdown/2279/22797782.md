# Weak inverse

::: {#o1 .subject cue=lead name="Weak inverse"}

In [mathematics](wikipedia://en/18831), the term **weak inverse** is used with several meanings.

:::

## Theory of semigroups {#Theory_of_semigroups}

In the theory of [semigroups](wikipedia://en/27799), a weak inverse of an element *x* in a semigroup (*S*, •) is an element *y* such that *y* • *x* • *y* = *y*. If every element has a weak inverse, the semigroup is called an [*E*-inversive or *E*-dense semigroup](wikipedia://en/43721974). An *E*-inversive semigroup may equivalently be defined by requiring that for every element *x* ∈ *S*, there exists *y* ∈ *S* such that *x* • *y* and *y* • *x* are [idempotents](https://en.wikipedia.org/wiki/Idempotent).[^o3]

An element *x* of *S* for which there is an element *y* of *S* such that *x* • *y* • *x* = *x* is called regular. A [regular semigroup](wikipedia://en/6797677) is a semigroup in which every element is regular. This is a stronger notion than weak inverse. Every regular semigroup is *E*-inversive, but not vice versa.[^o3]

If every element *x* in *S* has a unique inverse *y* in *S* in the sense that *x* • *y* • *x* = *x* and *y* • *x* • *y* = *y* then *S* is called an [inverse semigroup](wikipedia://en/1757814).

## Category theory {#Category_theory}

In [category theory](wikipedia://en/5869), a weak inverse of an [object](https://en.wikipedia.org/wiki/Object_%28category_theory%29) *A* in a [monoidal category](wikipedia://en/330604) *C* with monoidal product ⊗ and unit object $I$ is an object *B* such that both $A \otimes B$ and $B \otimes A$ are [isomorphic](wikipedia://en/14828) to the unit object $I$ of *C*. A monoidal category in which every [morphism](wikipedia://en/27716891) is invertible and every object has a weak inverse is called a [2-group](wikipedia://en/21368493).
