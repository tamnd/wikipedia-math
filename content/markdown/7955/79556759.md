# Small object argument

::: {#o1 .subject cue=lead name="Small object argument"}

In mathematics, especially in [category theory](wikipedia://en/5869), Quillen’s **small object argument**, when applicable, constructs a factorization of a morphism in a functorial way. In practice, it can be used to show some class of morphisms constitutes a [weak factorization system](https://en.wikipedia.org/wiki/Weak_factorization_system) in the theory of [model categories](wikipedia://en/2895304).

:::

The argument was introduced by [Quillen](wikipedia://en/435519) to construct a model structure on the category of (reasonable) topological spaces.[^o2] The original argument was later refined by Garner.[^o3]

::: {#o5 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $C$ be a category that has all small colimits. We say an object $x$ in it is [compact](wikipedia://en/57633087) with respect to an ordinal $\omega$ if $\operatorname{Hom}(x, -)$ commutes with an $\omega$-filtered colimit. In practice, we fix $\omega$ and simply say an object is compact if it is so with respect to that fixed $\omega$.

If $F$ is a class of morphisms, we write $l(F)$ for the class of morphisms that satisfy the [left lifting property](https://en.wikipedia.org/wiki/Left_lifting_property) with respect to $F$. Similarly, we write $r(F)$ for the right lifting property. Then

::: {#o6 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

[^o7][^o8] Let $F$ be a class of morphisms in $C$. If the source (domain) of each morphism in $F$ is compact, then each morphism $f$ in $C$ admits a functorial factorization $f = p \circ i$ where $i, p$ are in $l(r(F)), r(F)$.

:::

:::

## Example: presheaf {#Example:_presheaf}

Here is a simple example of how the argument works in the case of the category $C$ of presheaves on some small category.[^o10]

Let $I$ denote the set of monomorphisms of the form $K \to L$, $L$ a quotient of a representable presheaf. Then $l(r(I))$ can be shown to be equal to the class of monomorphisms. Then the small object argument says: each presheaf morphism $f$ can be factored as $f = p \circ i$ where $i$ is a [monomorphism](wikipedia://en/59538) and $p$ in $r(I) = r(l(r(I))$; i.e., $p$ is a morphism having the right lifting property with respect to monomorphisms.
