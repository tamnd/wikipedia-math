# Pseudocomplement

::: {#o1 .subject cue=lead name="Pseudocomplement"}

In [mathematics](wikipedia://en/18831), particularly in [order theory](wikipedia://en/361924), a **pseudocomplement** is one generalization of the notion of [complement](wikipedia://en/753521). In a [lattice](wikipedia://en/469304) *L* with [bottom element](https://en.wikipedia.org/wiki/Bottom_element) 0, an element *x* ∈ *L* is said to have a *pseudocomplement* if there exists a [greatest element](https://en.wikipedia.org/wiki/Greatest_element) $x^*\in L$ with the property that $x\wedge x^*=0$. More formally, $x^* = \max\{y\in L\mid x\wedge y = 0 \}$. The lattice *L* itself is called a **pseudocomplemented lattice** if every element of *L* is pseudocomplemented. Every pseudocomplemented lattice is necessarily [bounded](wikipedia://en/48258#Boundedness_in_order_theory), i.e. it has a 1 as well. Since the pseudocomplement is unique by definition (if it exists), a pseudocomplemented lattice can be endowed with a unary operation \* mapping every element to its pseudocomplement; this structure is sometimes called a ***p*-algebra**.[^o2][^o3] However this latter term may have other meanings in other areas of mathematics.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

In a *p*-algebra *L*, for all $x, y \in L:$[^o2][^o3]

- The map $x \mapsto x^*$ is [antitone](https://en.wikipedia.org/wiki/Antitone). In particular, $0^* = 1$ and $1^* = 0$.
- The map $x \mapsto x^{**}$ is a [closure](wikipedia://en/483120#Closure_operators_on_partially_ordered_sets).
- $$x^* = x^{***}.$$
- $$(x\vee y)^* = x^* \wedge y^*.$$
- $$(x\wedge y)^{**} = x^{**} \wedge y^{**}.$$
- $$x\wedge(x\wedge y)^* = x\wedge y^*.$$

The set $S(L) \stackrel{\mathrm def}{=} \{ x^* \mid x\in L \}$ is called the **skeleton** of *L*. *S*(*L*) is a $\wedge$-[subsemilattice](https://en.wikipedia.org/wiki/Subsemilattice) of *L* and together with $x\cup y = (x\vee y)^{**} = (x^*\wedge y^*)^*$ forms a [Boolean algebra](wikipedia://en/3959) (the complement in this algebra is $^*$).[^o2][^o3] In general, *S*(*L*) is not a [sublattice](https://en.wikipedia.org/wiki/Sublattice) of *L*.[^o3] In a [distributive](wikipedia://en/310883) *p*-algebra, *S*(*L*) is the set of [complemented](wikipedia://en/753521) elements of *L*.[^o2]

Every element *x* with the property $x^* = 0$ (or equivalently, $x^{**} = 1$) is called **dense**. Every element of the form $x\vee x^*$ is dense. *D*(*L*), the set of all the dense elements in *L* is a [filter](wikipedia://en/19719) of *L*.[^o2][^o3] A distributive *p*-algebra is Boolean if and only if $D(L) = \{1\}$.[^o2]

Pseudocomplemented lattices form a [variety](wikipedia://en/1021753); indeed, so do pseudocomplemented semilattices.[^o6]

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every finite [distributive lattice](wikipedia://en/310883) is pseudocomplemented.[^o2]
- Every [Stone algebra](wikipedia://en/32022697) is pseudocomplemented. In fact, a Stone algebra can be defined as a pseudocomplemented distributive lattice *L* in which any of the following equivalent statements hold for all $x, y \in L:$[^o2]
  - *S*(*L*) is a sublattice of *L*;
  - $$(x\wedge y)^* = x^*\vee y^*;$$
  - $$(x\vee y)^{**} = x^{**}\vee y^{**};$$
  - $$x^* \vee x^{**} = 1.$$
- Every [Heyting algebra](wikipedia://en/309343) is pseudocomplemented.[^o2]
- If *X* is a [topological space](wikipedia://en/30450), the (open set) [topology](wikipedia://en/29954) on *X* is a pseudocomplemented (and distributive) lattice with the meet and join being the usual union and intersection of open sets. The pseudocomplement of an open set *A* is the [interior](wikipedia://en/55610) of the [set complement](https://en.wikipedia.org/wiki/Set_complement) of *A*. Furthermore, the dense elements of this lattice are exactly the [dense open subsets](wikipedia://en/23523594) in the topological sense.[^o3]

:::

::: {#o10 .pointer-item cue=pointer name="Brouwerian lattice"}

## Relative pseudocomplement {#Relative_pseudocomplement}

A **relative pseudocomplement** of *a* with respect to *b* is a maximal element *c* such that $a\wedge c\le b$. This [binary operation](wikipedia://en/3948) is denoted $a\to b$. A lattice with a relative pseudocomplement for each pair of elements is called an **implicative lattice**, or **Brouwerian lattice**. In general, an implicative lattice may not have a minimal element. If such a minimal element exists, then each pseudocomplement $a^*$ could be defined using relative pseudocomplement as $a\to 0$.[^o11]
