# Group-based cryptography

::: {#o1 .subject cue=lead name="Group-based cryptography"}

**Group-based cryptography** is a use of [groups](wikipedia://en/19447) to construct [cryptographic primitives](wikipedia://en/4928985). A group is a very general algebraic object and most cryptographic schemes use groups in some way. In particular [Diffie–Hellman key exchange](wikipedia://en/7903) uses finite [cyclic groups](wikipedia://en/52327). So the term *group-based cryptography* refers mostly to [cryptographic protocols](wikipedia://en/591994) that use infinite [non-abelian groups](wikipedia://en/4791400) such as a [braid group](wikipedia://en/550138).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

- Shpilrain–Zapata public-key protocols
- Magyarik–Wagner public key protocol
- [Anshel–Anshel–Goldfeld key exchange](wikipedia://en/24708948)
- Ko–Lee et al. key exchange protocol
