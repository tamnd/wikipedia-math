# Coimage

::: {#o1 .subject cue=lead name="Coimage"}

In [algebra](wikipedia://en/19616384), the **coimage** of a [homomorphism](wikipedia://en/13564)

:::

$$f : A \rightarrow B$$

is the [quotient](wikipedia://en/11526)

$$\text{coim} f = A/\ker(f)$$

of the [domain](wikipedia://en/50263) by the [kernel](wikipedia://en/45240). The coimage is [canonically isomorphic](https://en.wikipedia.org/wiki/Natural_isomorphism) to the [image](wikipedia://en/579311) by the [first isomorphism theorem](https://en.wikipedia.org/wiki/Isomorphism_theorem), when that theorem applies.

More generally, in [category theory](wikipedia://en/5869), the **coimage** of a [morphism](wikipedia://en/27716891) is the dual notion of the [image of a morphism](wikipedia://en/342899). If $f : X \rightarrow Y$, then a coimage of $f$ (if it exists) is an [epimorphism](wikipedia://en/59539) $c : X \rightarrow C$ such that

1. there is a map $f_c : C \rightarrow Y$ with $f =f_c \circ c$,
1. for any epimorphism $z : X \rightarrow Z$ for which there is a map $f_z : Z \rightarrow Y$ with $f =f_z \circ z$, there is a unique map $h : Z \rightarrow C$ such that both $c =h \circ z$ and $f_z =f_c \circ h$
