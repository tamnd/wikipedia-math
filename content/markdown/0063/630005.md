# Dirichlet function

::: {#o1 .subject cue=lead name="Dirichlet function"}

In [mathematics](wikipedia://en/18831), the **Dirichlet function**[^o3] is the [indicator function](wikipedia://en/240790) $\mathbf{1}_\mathbb{Q}$ of the set of [rational numbers](wikipedia://en/19727024) $\mathbb{Q}$ over the set of [real numbers](wikipedia://en/20646438) $\mathbb{R}$, i.e. $\mathbf{1}_\mathbb{Q}(x) = 1$ for a real number $x$ if $x$ is a rational number and $\mathbf{1}_\mathbb{Q}(x) = 0$ if $x$ is not a rational number (i.e. is an [irrational number](wikipedia://en/20647689)).

$$\mathbf 1_\mathbb{Q}(x) = \begin{cases} 1 & x \in \mathbb{Q} \\ 0 & x \notin \mathbb{Q} \end{cases}$$

:::

It is named after the mathematician [Peter Gustav Lejeune Dirichlet](wikipedia://en/240002).[^o4] It is an example of a [pathological function](wikipedia://en/372742) which provides counterexamples to many situations.

## Topological properties {#Topological_properties}

::: {#o6 .proof cue=math-proof}

The Dirichlet function is [nowhere continuous](wikipedia://en/333677). We can prove this by reference to the definition of a [continuous function](wikipedia://en/6122) to show that it violates the continuity properties at both rational and irrational arguments: \*If $y$ is rational, then $f(y) = 1$. To show the function is not continuous at $y$, we need to find an $\varepsilon$ such that no matter how small we choose $\delta$, there will be points $z$ within $\delta$ of $y$ such that $f(z)$ is not within $\varepsilon$ of $f(y) = 1$. In fact, $\tfrac{1}{2}$ is such an $\varepsilon$. Because the [irrational numbers](wikipedia://en/20647689) are [dense](wikipedia://en/23523594) in the reals, no matter what $\delta$ we choose we can always find an irrational $z$ within $\delta$ of $y$, and $f(z) = 0$ is at least $\tfrac{1}{2}$ away from 1. If $y$ is irrational, then $f(y) = 0$. Again, we can take $\varepsilon = \tfrac{1}{2}$, and this time, because the rational numbers are dense in the reals, we can pick $z$ to be a rational number as close to $y$ as is required. Again, $f(z) = 1$ is more than $\tfrac{1}{2}$ away from $f(y) = 0$. Its restrictions to the set of rational numbers and to the set of irrational numbers are [constants](wikipedia://en/320861) and therefore continuous. The Dirichlet function is an archetypal example of the [Blumberg theorem](wikipedia://en/63849351).; The Dirichlet function can be constructed as the double pointwise limit of a sequence of continuous functions, as follows: $\forall x \in \mathbb{R}, \quad \mathbf{1}_{\mathbb{Q}}(x) = \lim_{k \to \infty} \left(\lim_{j\to\infty}\left(\cos(k!\pi x)\right)^{2j}\right)$ for integer $j$ and $k$. This shows that the Dirichlet function is a [Baire class](wikipedia://en/3575729) 2 function. It cannot be a Baire class 1 function because a Baire class 1 function can only be discontinuous on a [meagre set](wikipedia://en/226975).[^o7]

:::

## Periodicity {#Periodicity}

For any real number $x$ and any positive rational number $T$, $\mathbf{1}_\mathbb{Q}(x + T) = \mathbf{1}_\mathbb{Q}(x)$. The Dirichlet function is therefore an example of a real [periodic function](wikipedia://en/76848) which is not [constant](wikipedia://en/320861) but whose set of periods, the set of rational numbers, is a [dense subset](wikipedia://en/23523594) of $\mathbb{R}$.

## Integration properties {#Integration_properties}

::: {#o10 .proof cue=math-proof}

The Dirichlet function is not [Riemann-integrable](wikipedia://en/26390) on any segment of $\mathbb{R}$ despite being bounded because the set of its discontinuity points is not [negligible](wikipedia://en/195132) (for the [Lebesgue measure](wikipedia://en/18198)).; The Dirichlet function has both an upper [Darboux integral](wikipedia://en/872314) (namely, $b-a$) and a lower Darboux integral (0) over any bounded interval $[a,b]$ — but they are not equal if $a < b$, so the Dirichlet function is not Darboux-integrable (and therefore not Riemann-integrable) over any nondegenerate interval.; The Dirichlet function provides a counterexample showing that the [monotone convergence theorem](wikipedia://en/146263) is not true in the context of the Riemann integral. Using an [enumeration](wikipedia://en/212115) of the rational numbers between 0 and 1, we define the function $f_{n}$ (for all nonnegative integer $n$) as the indicator function of the set of the first $n$ terms of this sequence of rational numbers. The increasing sequence of functions $f_{n}$ (which are nonnegative, Riemann-integrable with a vanishing integral) pointwise converges to the Dirichlet function which is not Riemann-integrable.; The Dirichlet function is [Lebesgue-integrable](wikipedia://en/26064288) on $\mathbb{R}$ and its integral over $\mathbb{R}$ is zero because it is zero except on the set of rational numbers which is negligible (for the Lebesgue measure).

:::
