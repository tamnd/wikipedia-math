# Vertex (graph theory)

::: {#o1 .subject cue=lead name="Vertex"}

*Image: 6n-graf.svg.* A graph with 6 vertices and 7 edges where the vertex number 6 on the far-left is a leaf vertex or a pendant vertex

In [discrete mathematics](wikipedia://en/8492), and more specifically in [graph theory](wikipedia://en/12401), a **vertex** (plural **vertices**) or **node** is the fundamental unit of which graphs are formed: an [undirected graph](wikipedia://en/325806#Graph) consists of a set of vertices and a set of [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) (unordered pairs of vertices), while a [directed graph](wikipedia://en/19721986) consists of a set of vertices and a set of arcs (ordered pairs of vertices). In a diagram of a graph, a vertex is usually represented by a circle with a label, and an edge is represented by a line or arrow extending from one vertex to another.

:::

From the point of view of graph theory, vertices are treated as featureless and indivisible [objects](wikipedia://en/19453961), although they may have additional structure depending on the application from which the graph arises; for instance, a [semantic network](https://en.wikipedia.org/wiki/Semantic_network) is a graph in which the vertices represent concepts or classes of objects.

The two vertices forming an edge are said to be the endpoints of this edge, and the edge is said to be incident to the vertices. A vertex *w* is said to be adjacent to another vertex *v* if the graph contains an edge (*v*,*w*). The [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28graph_theory%29) of a vertex *v* is an [induced subgraph](wikipedia://en/1655188) of the graph, formed by all vertices adjacent to *v*.

::: {#o3 .pointer-item cue=pointer name="Leaf vertex"}

## Types of vertices {#Types_of_vertices}

*Image: Small Network.png.* Example network with 8 vertices (of which one is isolated) and 10 edges.

The [degree](wikipedia://en/1374448) of a vertex, denoted 𝛿(v) in a graph is the number of edges incident to it. An **isolated vertex** is a vertex with degree zero; that is, a vertex that is not an endpoint of any edge (the example image illustrates one isolated vertex).[^o4] A **leaf vertex** (also **pendant vertex**) is a vertex with degree one. In a directed graph, one can distinguish the outdegree (number of outgoing edges), denoted 𝛿<sup>\+</sup>(v), from the indegree (number of incoming edges), denoted 𝛿<sup>−</sup>(v); a **source vertex** is a vertex with indegree zero, while a **sink vertex** is a vertex with outdegree zero. A [simplicial vertex](wikipedia://en/79562353) is one whose [closed neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28graph_theory%29) forms a [clique](wikipedia://en/524466): every two neighbors are adjacent. A [universal vertex](wikipedia://en/51352780) is a vertex that is adjacent to every other vertex in the graph.

A [cut vertex](https://en.wikipedia.org/wiki/Cut_vertex) is a vertex the removal of which would disconnect the remaining graph; a [vertex separator](wikipedia://en/1499165) is a collection of vertices the removal of which would disconnect the remaining graph into small pieces. A [k-vertex-connected graph](https://en.wikipedia.org/wiki/K-vertex-connected_graph) is a graph in which removing fewer than *k* vertices always leaves the remaining graph connected. An [independent set](wikipedia://en/524501) is a set of vertices no two of which are adjacent, and a [vertex cover](wikipedia://en/562782) is a set of vertices that includes at least one endpoint of each edge in the graph. The [vertex space](https://en.wikipedia.org/wiki/Vertex_space) of a graph is a vector space having a set of basis vectors corresponding with the graph's vertices.

A graph is [vertex-transitive](wikipedia://en/581175) if it has symmetries that map any vertex to any other vertex. In the context of [graph enumeration](wikipedia://en/9982439) and [graph isomorphism](wikipedia://en/247577) it is important to distinguish between **labeled vertices** and **unlabeled vertices**. A labeled vertex is a vertex that is associated with extra information that enables it to be distinguished from other labeled vertices; two graphs can be considered isomorphic only if the correspondence between their vertices pairs up vertices with equal labels. An unlabeled vertex is one that can be substituted for any other vertex based only on its [adjacencies](https://en.wikipedia.org/wiki/Adjacency_%28graph_theory%29) in the graph and not based on any additional information.

Vertices in graphs are analogous to, but not the same as, [vertices of polyhedra](wikipedia://en/11308417): the [skeleton](https://en.wikipedia.org/wiki/Skeleton_%28topology%29) of a polyhedron forms a graph, the vertices of which are the vertices of the polyhedron, but polyhedron vertices have additional structure (their geometric location) that is not assumed to be present in graph theory. The [vertex figure](wikipedia://en/1005719) of a vertex in a polyhedron is analogous to the neighborhood of a vertex in a graph.
