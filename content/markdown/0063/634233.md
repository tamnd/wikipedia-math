# Analytical hierarchy

::: {#o1 .subject cue=lead name="Analytical hierarchy"}

In [mathematical logic](wikipedia://en/19636) and [descriptive set theory](wikipedia://en/396619), the **analytical hierarchy** is an extension of the [arithmetical hierarchy](wikipedia://en/186475). The analytical hierarchy of formulas includes formulas in the language of [second-order arithmetic](wikipedia://en/3542454), which can have quantifiers over both the set of [natural numbers](https://en.wikipedia.org/wiki/Natural_numbers), $\mathbb{N}$, and over functions from $\mathbb{N}$ to $\mathbb{N}$. The analytical hierarchy of sets classifies sets by the formulas that can be used to define them; it is the [lightface](https://en.wikipedia.org/wiki/Lightface) version of the [projective hierarchy](wikipedia://en/1236542).

:::

::: {#o3 .statement cue=named-heading name="The analytical hierarchy of formulas"}

## The analytical hierarchy of formulas {#The_analytical_hierarchy_of_formulas}

The notation $\Sigma^1_0 = \Pi^1_0 = \Delta^1_0$ indicates the class of formulas in the language of [second-order arithmetic](wikipedia://en/3542454) with number quantifiers but no set quantifiers. This language does not contain set parameters. The Greek letters here are [lightface](https://en.wikipedia.org/wiki/Lightface) symbols, indicating the language choice. Each corresponding [boldface](https://en.wikipedia.org/wiki/Boldface_%28mathematics%29) symbol denotes the corresponding class of formulas in the extended language with a parameter for each [real](wikipedia://en/352376); see [projective hierarchy](wikipedia://en/1236542) for details.

A formula in the language of second-order arithmetic is defined to be $\Sigma^1_{n+1}$ if it is [logically equivalent](wikipedia://en/169324) to a formula of the form $\exists X_1\cdots \exists X_k \psi$ where $\psi$ is $\Pi^1_{n}$. A formula is defined to be $\Pi^1_{n+1}$ if it is logically equivalent to a formula of the form $\forall X_1\cdots \forall X_k \psi$ where $\psi$ is $\Sigma^1_{n}$. This inductive definition defines the classes $\Sigma^1_n$ and $\Pi^1_n$ for every natural number $n$.

[Kuratowski](https://en.wikipedia.org/wiki/Kuratowski) and [Tarski](wikipedia://en/59920) showed in 1931 that every formula in the language of second-order arithmetic has a [prenex normal form](wikipedia://en/421068),[^o4] and therefore is $\Sigma^1_n$ or $\Pi^1_n$ for some $n$. Because meaningless quantifiers can be added to any formula, once a formula is given the classification $\Sigma^1_n$ or $\Pi^1_n$ for some $n$ it will be given the classifications $\Sigma^1_m$ and $\Pi^1_m$ for all $m$ greater than $n$.

:::

## The analytical hierarchy of sets of natural numbers {#The_analytical_hierarchy_of_sets_of_natural_numbers}

A set of natural numbers is assigned the classification $\Sigma^1_n$ if it is definable by a $\Sigma^1_n$ formula (with one free number variable and no free set variables). The set is assigned the classification $\Pi^1_n$ if it is definable by a $\Pi^1_n$ formula. If the set is both $\Sigma^1_n$ and $\Pi^1_n$ then it is given the additional classification $\Delta^1_n$.

The $\Delta^1_1$ sets are called **hyperarithmetical**. An alternate classification of these sets by way of iterated computable functionals is provided by the [hyperarithmetical theory](wikipedia://en/12383591).

## The analytical hierarchy on subsets of Cantor and Baire space {#The_analytical_hierarchy_on_subsets_of_Cantor_and_Baire_space}

The analytical hierarchy can be defined on any [effective Polish space](wikipedia://en/24662110); the definition is particularly simple for Cantor and Baire space because they fit with the language of ordinary second-order arithmetic. [Cantor space](wikipedia://en/352376) is the set of all infinite sequences of 0s and 1s; [Baire space](wikipedia://en/2078245) is the set of all infinite sequences of natural numbers. These are both [Polish spaces](wikipedia://en/396622).

The ordinary axiomatization of [second-order arithmetic](wikipedia://en/3542454) uses a set-based language in which the set quantifiers can naturally be viewed as quantifying over Cantor space. A subset of Cantor space is assigned the classification $\Sigma^1_n$ if it is definable by a $\Sigma^1_n$ formula (with one free set variable and no free number variables). The set is assigned the classification $\Pi^1_n$ if it is definable by a $\Pi^1_n$ formula. If the set is both $\Sigma^1_n$ and $\Pi^1_n$ then it is given the additional classification $\Delta^1_n$.

A subset of Baire space has a corresponding subset of Cantor space under the map that takes each function from $\omega$ to $\omega$ to the characteristic function of its graph. A subset of Baire space is given the classification $\Sigma^1_n$, $\Pi^1_n$, or $\Delta^1_n$ if and only if the corresponding subset of Cantor space has the same classification. An equivalent definition of the analytical hierarchy on Baire space is given by defining the analytical hierarchy of formulas using a functional version of second-order arithmetic; then the analytical hierarchy on subsets of Cantor space can be defined from the hierarchy on Baire space. This alternate definition gives exactly the same classifications as the first definition.

Because Cantor space is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to any finite Cartesian power of itself, and Baire space is homeomorphic to any finite Cartesian power of itself, the analytical hierarchy applies equally well to finite Cartesian powers of one of these spaces. A similar extension is possible for countable powers and to products of powers of Cantor space and powers of Baire space.

## Extensions {#Extensions}

As is the case with the [arithmetical hierarchy](wikipedia://en/186475), a relativized version of the analytical hierarchy can be defined. The language is extended to add a constant set symbol *A*. A formula in the extended language is inductively defined to be $\Sigma^{1,A}_n$ or $\Pi^{1,A}_n$ using the same inductive definition as above. Given a set $Y$, a set is defined to be $\Sigma^{1,Y}_n$ if it is definable by a $\Sigma^{1,A}_n$ formula in which the symbol $A$ is interpreted as $Y$; similar definitions for $\Pi^{1,Y}_n$ and $\Delta^{1,Y}_n$ apply. The sets that are $\Sigma^{1,Y}_n$ or $\Pi^{1,Y}_n$, for any parameter *Y*, are classified in the [projective hierarchy](wikipedia://en/1236542), and often denoted by boldface Greek letters to indicate the use of parameters.[^o9]

:::

## Examples {#Examples}

- For a relation $\prec$ on $\mathbb N^2$, the statement "$\prec$ is a [well-order](wikipedia://en/33456) on $\mathbb N$" is $\Pi_1^1$. (Not to be confused with the general case for [well-founded](https://en.wikipedia.org/wiki/Well-founded) relations on sets, see [Lévy hierarchy](wikipedia://en/25129404))
- The set of all natural numbers that are indices of computable [ordinals](https://en.wikipedia.org/wiki/Ordinal_%28mathematics%29) is a $\Pi^1_1$ set that is not $\Sigma^1_1$.
  - These sets are exactly the [$\omega_1^{CK}$-recursively-enumerable](wikipedia://en/12008116) subsets of $\omega$. \[Bar75, p. 168\]
- A function $f:\mathbb N\to\mathbb N$ is definable by [Herbrand](wikipedia://en/159901)'s 1931 formalism of systems of equations if and only if $f$ is hyperarithmetical.[^o12]
- The set of continuous functions $f:[0,1]\to\mathbb [0,1]$ that have the [mean value property](wikipedia://en/19662) is no lower than $\Delta_2^1$ on the hierarchy.[^o13]
- The set of elements of Cantor space that are the characteristic functions of well orderings of $\omega$ is a $\Pi^1_1$ set that is not $\Sigma^1_1$. In fact, this set is not $\Sigma^{1,Y}_1$ for any element $Y$ of Baire space.
- If the [axiom of constructibility](wikipedia://en/696472) holds then there is a subset of the product of the Baire space with itself that is $\Delta^1_2$ and is the graph of a [well ordering](https://en.wikipedia.org/wiki/Well_ordering) of Baire space. If the axiom holds then there is also a $\Delta^1_2$ well ordering of Cantor space.

:::

## Properties {#Properties}

For each $n$ we have the following strict containments:

$$\Pi^1_n \subset \Sigma^1_{n+1},$$

$$\Pi^1_n \subset \Pi^1_{n+1},$$

$$\Sigma^1_n \subset \Pi^1_{n+1},$$

$$\Sigma^1_n \subset \Sigma^1_{n+1}.$$

A set that is in $\Sigma^1_n$ for some *n* is said to be **analytical**. Care is required to distinguish this usage from the term [analytic set](wikipedia://en/634261), which has a different meaning, namely $\boldsymbol\Sigma_1^1$.[^o16]

:::
