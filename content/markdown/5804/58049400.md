# SM3 (hash function)

::: {#o2 .subject cue=lead name="SM3"}

**ShangMi 3** (**SM3**) is a [cryptographic hash function](wikipedia://en/439526), standardised for use in commercial cryptography in China.[^o3] It was published by the [State Cryptography Administration](https://en.wikipedia.org/wiki/State_Cryptography_Administration) (国家密码管理局) on 2010-12-17[^o4][^o5] as "".[^o4]

:::

SM3 is used for implementing [digital signatures](https://en.wikipedia.org/wiki/Digital_signatures), [message authentication codes](https://en.wikipedia.org/wiki/Message_authentication_codes), and [pseudorandom number generators](https://en.wikipedia.org/wiki/Pseudorandom_number_generators).[^o6] The algorithm is public[^o7][^o8] and is considered similar to [SHA-256](https://en.wikipedia.org/wiki/SHA-256) in security and efficiency.[^o9] SM3 can be used with [Transport Layer Security](wikipedia://en/187813)[^o10] although it is not enabled by default.

## Definitive standards {#Definitive_standards}

SM3 is defined in each of:

- GM/T 0004-2012: SM3 cryptographic hash algorithm[^o4]
- GB/T 32905-2016: Information security techniques—SM3 cryptographic hash algorithm[^o15]
- ISO/IEC 10118-3:2018—IT Security techniques—Hash-functions—Part 3: Dedicated hash-functions
- IETF RFC draft-sca-cfrg-sm3-02[^o6]
