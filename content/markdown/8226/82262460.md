# Greatest common multiple

::: {#o1 .subject cue=lead name="Greatest common multiple"}

The **greatest common multiple** is a term mistakenly used to refer to:[^o2]

:::

- [Least common denominator](https://en.wikipedia.org/wiki/Least_common_denominator), the lowest common multiple of the denominators of a set of fractions
- [Greatest common divisor](wikipedia://en/12354), the largest positive integer that divides each of the integers
