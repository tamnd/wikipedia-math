# Goursat tetrahedron

::: {#o1 .subject cue=lead name="Goursat tetrahedron"}

*Image: Coxeter-Dynkin 3-space groups.png.* For Euclidean 3-space, there are 3 simple and related Goursat tetrahedra, represented by \[4,3,4\], \[4,3<sup>1,1</sup>\], and \[3<sup>\[4\]</sup>\]. They can be seen inside as points on and within a cube, {4,3}.

In [geometry](wikipedia://en/18973446), a **Goursat tetrahedron** is a [tetrahedral](wikipedia://en/30606) [fundamental domain](wikipedia://en/469365) of a [Wythoff construction](wikipedia://en/2950777). Each tetrahedral face represents a reflection hyperplane on 3-dimensional surfaces: the [3-sphere](wikipedia://en/39792), Euclidean 3-space, and hyperbolic 3-space. [Coxeter](https://en.wikipedia.org/wiki/Coxeter) named them after [Édouard Goursat](wikipedia://en/1674255) who first looked into these domains. It is an extension of the theory of [Schwarz triangles](wikipedia://en/2069325) for Wythoff constructions on the sphere.

:::

## Graphical representation {#Graphical_representation}

A **Goursat tetrahedron** can be represented graphically by a tetrahedral graph, which is in a dual configuration of the fundamental domain tetrahedron. In the graph, each node represents a face (mirror) of the Goursat tetrahedron. Each edge is labeled by a rational value corresponding to the reflection order, being π/[dihedral angle](wikipedia://en/338046).

*Image: General Goursat tetrahedron.png.*

A 4-node [Coxeter-Dynkin diagram](https://en.wikipedia.org/wiki/Coxeter-Dynkin_diagram) represents this tetrahedral graph with order-2 edges hidden. If many edges are order 2, the [Coxeter group](wikipedia://en/297004) can be represented by a [bracket notation](wikipedia://en/32088502).

Existence requires each of the 3-node subgraphs of this graph, (p q r), (p u s), (q t u), and (r s t), must correspond to a [Schwarz triangle](wikipedia://en/2069325).

An extended symmetry of the Goursat tetrahedron is a [semidirect product](wikipedia://en/48246) of the [Coxeter group](wikipedia://en/297004) symmetry and the [fundamental domain](wikipedia://en/469365) symmetry (the Goursat tetrahedron in these cases). [Coxeter notation](wikipedia://en/32088502) supports this symmetry as double-brackets like \[Y\[X\]\] means full Coxeter group symmetry \[X\], with **Y** as a symmetry of the Goursat tetrahedron. If **Y** is a pure reflective symmetry, the group will represent another Coxeter group of mirrors. If there is only one simple doubling symmetry, **Y** can be implicit like \[\[X\]\] with either reflectional or rotational symmetry depending on the context.

The extended symmetry of each Goursat tetrahedron is also given below. The highest possible symmetry is that of the regular [tetrahedron](wikipedia://en/30606) as \[3,3\], and this occurs in the prismatic point group \[2,2,2\] or \[2<sup>\[3,3\]</sup>\] and the paracompact hyperbolic group \[3<sup>\[3,3\]</sup>\].

See [Tetrahedron#Isometries of irregular tetrahedra](wikipedia://en/30606#Isometries_of_irregular_tetrahedra) for 7 lower symmetry isometries of the tetrahedron.

## Whole number solutions {#Whole_number_solutions}

The following sections show all of the whole number Goursat tetrahedral solutions on the 3-sphere, Euclidean 3-space, and hyperbolic 3-space. The extended symmetry of each tetrahedron is also given.

The colored tetrahedal diagrams below are [vertex figures](wikipedia://en/1005719) for [omnitruncated](wikipedia://en/7083690) polytopes and honeycombs from each symmetry family. The edge labels represent polygonal face orders, which is double the Coxeter graph branch order. The [dihedral angle](wikipedia://en/338046) of an edge labeled *2n* is π/*n*. Yellow edges labeled 4 come from right angle (unconnected) mirror nodes in the Coxeter diagram.
