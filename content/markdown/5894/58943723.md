# Clique game

::: {#o1 .subject cue=lead name="Clique game"}

The **clique game** is a [positional game](wikipedia://en/25981951) where two players alternately pick edges, trying to occupy a complete [clique](wikipedia://en/524466) of a given size.

:::

The game is parameterized by two integers *n* > *k*. The game-board is the set of all edges of a [complete graph](wikipedia://en/85816) on *n* vertices. The winning-sets are all the cliques on *k* vertices. There are several variants of this game:

- In the [strong positional variant](wikipedia://en/58908272) of the game, the first player who holds a *k*-clique wins. If no one wins, the game is a draw.
- In the [Maker-Breaker variant](https://en.wikipedia.org/wiki/Maker-Breaker_game), the first player (Maker) wins if he manages to hold a *k*-clique, otherwise the second player (Breaker) wins. There are no draws.
- In the [Avoider-Enforcer variant](wikipedia://en/58939052), the first player (Avoider) wins if he manages *not* to hold a *k*-clique. Otherwise, the second player (Enforcer) wins. There are no draws. A special case of this variant is [Sim](https://en.wikipedia.org/wiki/Sim_%28pencil_game%29).

The clique game (in its strong-positional variant) was first presented by [Paul Erdős](wikipedia://en/601284) and [John Selfridge](wikipedia://en/995084), who attributed it to Simmons.[^o2] They called it the **Ramsey game**, since it is closely related to [Ramsey's theorem](wikipedia://en/184898) (see below).

## Winning conditions {#Winning_conditions}

[Ramsey's theorem](wikipedia://en/184898) implies that, whenever we color a graph with 2 colors, there is at least one monochromatic clique. Moreover, for every integer *k*, there exists an integer *R(k,k)* such that, in every graph with $n \geq R_2(k,k)$ vertices, any 2-coloring contains a monochromatic clique of size at least *k*. This means that, if $n \geq R_2(k,k)$, the clique game can never end in a draw. a [Strategy-stealing argument](wikipedia://en/709783) implies that the first player can always force at least a draw; therefore, if $n \geq R_2(k,k)$, Maker wins. By substituting known bounds for the Ramsey number we get that Maker wins whenever $k \leq {\log_2 n\over 2}$.

On the other hand, the Erdos-Selfridge theorem[^o2] implies that Breaker wins whenever $k \geq {2 \log_2 n}$.

[Beck](https://en.wikipedia.org/wiki/József_Beck) improved these bounds as follows:[^o4]

- Maker wins whenever $k \leq 2 \log_2 n - 2\log_2\log_2 n + 2\log_2 e - 10/3 + o(1)$;
- Breaker wins whenever $k \geq 2 \log_2 n - 2\log_2\log_2 n + 2\log_2 e - 1 + o(1)$.

## Ramsey game on higher-order hypergraphs {#Ramsey_game_on_higher-order_hypergraphs}

Instead of playing on complete graphs, the clique game can also be played on complete hypergraphs of higher orders. For example, in the clique game on triplets, the game-board is the set of triplets of integers 1,...,*n* (so its size is ${n \choose 3}$ ), and winning-sets are all sets of triplets of *k* integers (so the size of any winning-set in it is ${k \choose 3}$).

By [Ramsey's theorem](wikipedia://en/184898) on triples, if $n \geq R_3(k,k)$, Maker wins. The currently known upper bound on $R_3(k,k)$ is very large, $2^{k^2/6} < R_3(k,k) < 2^{2^{4k-10}}$. In contrast, [Beck](https://en.wikipedia.org/wiki/József_Beck)[^o6] proves that $2^{k^2/6} < R^*_3(k,k) < k^4 2^{k^3/6}$, where $R^*_3(k,k)$ is the smallest integer such that Maker has a winning strategy. In particular, if $k^4 2^{k^3/6} < n$ then the game is Maker's win.
