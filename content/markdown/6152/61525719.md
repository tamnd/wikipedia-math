# Control (optimal control theory)

::: {#o1 .subject cue=lead name="Control"}

In [optimal control theory](https://en.wikipedia.org/wiki/Optimal_control_theory), a **control** is a variable chosen by the controller or [agent](https://en.wikipedia.org/wiki/Agent_%28economics%29) to manipulate [state variables](https://en.wikipedia.org/wiki/State_variables), similar to an actual [control valve](https://en.wikipedia.org/wiki/Control_valve). Unlike the state variable, it does not have a predetermined [equation of motion](https://en.wikipedia.org/wiki/Equation_of_motion).[^o2] The goal of optimal control theory is to find some [sequence](wikipedia://en/27838) of controls (within an admissible set) to achieve an optimal path for the state variables (with respect to a [loss function](wikipedia://en/442137)).

:::

A control given as a function of time only is referred to as an *[open-loop control](https://en.wikipedia.org/wiki/Open-loop_control)*. In contrast, a control that gives optimal solution during some remainder period as a function of the state variable at the beginning of the period is called a *[closed-loop control](https://en.wikipedia.org/wiki/Closed-loop_control)*.[^o3]
