# Stochastic multicriteria acceptability analysis

::: {#o1 .subject cue=lead name="Stochastic multicriteria acceptability analysis"}

**Stochastic multicriteria acceptability analysis** (**SMAA**) is a [multiple-criteria decision analysis](wikipedia://en/1050551) method for problems with missing or incomplete information.

:::

## Description {#Description}

This means that criteria and preference information can be uncertain, inaccurate or partially missing. Incomplete information is represented in SMAA using suitable probability distributions. The method is based on stochastic simulation by drawing random values for criteria measurements and weights from their corresponding distributions.[^o3]

SMAA can handle mixed [cardinal](https://en.wikipedia.org/wiki/Cardinal_numbers) and [ordinal](https://en.wikipedia.org/wiki/Ordinal_numbers) information. Ordinal information is treated by a special joint distribution that preserves the ordinal information.[^o4]

A survey on different variants and applications of SMAA can be found in this article.[^o5]

Open source implementations of SMAA can be found at the website SMAA.fi.[^o6]
