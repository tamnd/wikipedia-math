# Essential monomorphism

::: {#o1 .subject cue=lead name="Essential monomorphism"}

In [mathematics](wikipedia://en/18831), specifically [category theory](wikipedia://en/5869), an **essential monomorphism** is a [monomorphism](wikipedia://en/59538) *i* in an [abelian category](wikipedia://en/45063) *C* such that for a morphism *f* in *C*, the composition $fi$ is a monomorphism only when *f* is a monomorphism.[^o2] Essential monomorphisms in a [category of modules](wikipedia://en/11231812) are those whose image is an [essential submodule](https://en.wikipedia.org/wiki/Essential_submodule) of the [codomain](wikipedia://en/50264). An injective hull of an object *A* is an essential monomorphism from *A* to an [injective object](wikipedia://en/473779).[^o2]

:::
