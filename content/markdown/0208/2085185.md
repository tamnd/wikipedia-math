# Artin's conjecture on primitive roots

::: {#o1 .subject cue=lead name="Artin's conjecture on primitive roots"}

In [number theory](wikipedia://en/21527), **Artin's conjecture on primitive roots** states that a given [integer](wikipedia://en/14563) *a* that is neither a [square number](wikipedia://en/213919) nor −1 is a [primitive root](wikipedia://en/186864) modulo infinitely many [primes](wikipedia://en/23666) *p*. The [conjecture](wikipedia://en/6138) also ascribes an [asymptotic density](https://en.wikipedia.org/wiki/Asymptotic_density) to these primes. This conjectural density equals Artin's constant or a [rational](wikipedia://en/19727024) multiple thereof.

:::

The conjecture was made by [Emil Artin](wikipedia://en/245351) to [Helmut Hasse](wikipedia://en/727118) on September 27, 1927, according to the latter's diary. The conjecture is still unresolved as of 2026. In fact, there is no single value of *a* for which Artin's conjecture is proved.

::: {#o3 .definition cue=heading name="Formulation"}

## Formulation {#Formulation}

Let *a* be an integer that is not a square number and not −1. Write *a* = *a*<sub>0</sub>*b*<sup>2</sup> with *a*<sub>0</sub> [square-free](wikipedia://en/29525). Denote by *S*(*a*) the set of prime numbers *p* such that *a* is a primitive root modulo *p*. Then the conjecture states

1. *S*(*a*) has a positive asymptotic density inside the set of primes. In particular, *S*(*a*) is infinite.
1. Under the conditions that *a* is not a [perfect power](wikipedia://en/4023591) and *a*<sub>0</sub> is not [congruent](wikipedia://en/20087) to 1 modulo 4 , this density is independent of *a* and equals **Artin's constant**, which can be expressed as an infinite product

$C_{\mathrm{Artin}}=\prod_{p\ \mathrm{prime}} \left(1-\frac{1}{p(p-1)}\right) = 0.3739558136\ldots$ .

The positive integers satisfying these conditions are:

2, 3, 6, 7, 10, 11, 12, 14, 15, 18, 19, 22, 23, 24, 26, 28, 30, 31, 34, 35, 38, 39, 40, 42, 43, 44, 46, 47, 48, 50, 51, 54, 55, 56, 58, 59, 60, 62, 63, …

The negative integers satisfying these conditions are:

2, 4, 5, 6, 9, 10, 13, 14, 16, 17, 18, 20, 21, 22, 24, 25, 26, 29, 30, 33, 34, 36, 37, 38, 40, 41, 42, 45, 46, 49, 50, 52, 53, 54, 56, 57, 58, 61, 62, …

Similar conjectural product formulas[^o4][^o5][^o6] exist for the density when *a* does not satisfy the above conditions. In these cases, the conjectural density is always a rational multiple of *C*<sub>Artin</sub>.

If *a* is either [square number](wikipedia://en/213919) or −1, then this density is 0.

If *a* is not a perfect power but *a*<sub>0</sub> is congruent to 1 modulo 4, then this density is $C_\text{Artin}\left(1-\prod_{p|a_0, p\ \text{prime}}\frac{1}{1+p-p^2}\right)$.

If *a* is a perfect power, let *r* be the largest number such that *a* is an *r*th power, then this density is:

$C_\text{Artin}\prod_{p|r, p\ \text{prime}}\frac{p^2-2p}{p^2-p-1}$ if *a*<sub>0</sub> is not congruent to 1 modulo 4;

$C_\text{Artin}\prod_{p|r, p\ \text{prime}}\frac{p^2-2p}{p^2-p-1}\left(1-\prod_{p|a_0, p\ \text{prime}}\frac{1}{1+p-p^2}\prod_{p|\gcd(a_0,r), p\ \text{prime}}\frac{p^2-p-1}{p-2}\right)$ if *a*<sub>0</sub> is congruent to 1 modulo 4.

For $n=1,2,3,\cdots$, the conjectural densities given by the formula are *C*<sub>Artin</sub> times

0, 1, 1, 0, $\tfrac{20}{19}$, 1, 1, $\tfrac{3}{5}$, 0, 1, 1, 1, $\tfrac{156}{155}$, 1, 1, 0, $\tfrac{272}{271}$, 1, 1, $\tfrac{20}{19}$, $\tfrac{204}{205}$, 1, 1, 1, 0, 1, $\tfrac{3}{5}$, 1, $\tfrac{812}{811}$, 1, 1, $\tfrac{15}{19}$, $\tfrac{544}{545}$, 1, 1, 0, $\tfrac{1332}{1331}$, 1, 1, 1, $\tfrac{1640}{1639}$, 1, 1, 1, $\tfrac{20}{19}$, ... ( for the numerators, for the denominators)

For $n=-1,-2,-3,\cdots$, the conjectural densities given by the formula are *C*<sub>Artin</sub> times

0, 1, $\tfrac{6}{5}$, 1, 1, 1, $\tfrac{42}{41}$, $\tfrac{3}{5}$, 1, 1, $\tfrac{110}{109}$, $\tfrac{6}{5}$, 1, 1, $\tfrac{94}{95}$, 1, 1, 1, $\tfrac{342}{341}$, 1, 1, 1, $\tfrac{506}{505}$, 1, 1, 1, $\tfrac{6}{5}$, $\tfrac{42}{41}$, 1, 1, $\tfrac{930}{929}$, $\tfrac{15}{19}$, 1, 1, $\tfrac{778}{779}$, 1, 1, 1, $\tfrac{774}{775}$, 1, 1, 1, $\tfrac{1806}{1805}$, $\tfrac{110}{109}$, 1, ... ( for the numerators, for the denominators)

:::

## Examples {#Examples}

For example, take *a* = 2. The conjecture is that the set of primes *p* for which 2 is a primitive root has the density *C*<sub>Artin</sub>. The set of such primes is

*S*(2) = {3, 5, 11, 13, 19, 29, 37, 53, 59, 61, 67, 83, 101, 107, 131, 139, 149, 163, 173, 179, 181, 197, 211, 227, 269, 293, 317, 347, 349, 373, 379, 389, 419, 421, 443, 461, 467, 491, ...}.

It has 38 elements smaller than 500 and there are 95 primes smaller than 500. The ratio (which conjecturally tends to *C*<sub>Artin</sub>) is 38/95 = 2/5 = 0.4.

For *a* = 4 = 2<sup>2</sup>, which is a square number, the density is 0, and for *a* = 8 = 2<sup>3</sup>, which is a power of 2, the conjectured density is $\frac{3}{5}C$, and for *a* = 5, which is congruent to 1 mod 4, the conjectured density is $\frac{20}{19}C$.

:::

## Partial results {#Partial_results}

In 1967, [Christopher Hooley](wikipedia://en/5380265) published a [conditional proof](wikipedia://en/6562) for the conjecture, assuming certain cases of the [generalized Riemann hypothesis](wikipedia://en/152567).[^o10]

Without the generalized Riemann hypothesis, there is no single value of *a* for which Artin's conjecture is proved. However, [D. R. Heath-Brown](wikipedia://en/2984550) proved in 1986 (Corollary 1) that at least one of 2, 3, or 5 is a primitive root modulo infinitely many primes *p*.[^o11] He also proved (Corollary 2) that there are at most two primes for which Artin's conjecture fails.

## Abelian varieties {#Abelian_varieties}

Unconditionally, the infinite part of Artin's primitive root conjecture for general abelian varieties was proved in:

C. Virdol, Artin's conjecture for abelian varieties, Kyoto Journal of Mathematics, 2016.

Moreover, unconditionally, the strong form of Artin's primitive root conjecture for general CM elliptic curves was proved in:

C. Virdol, On Artin's conjecture for CM elliptic curves, Kyoto Journal of Mathematics, 2020.

Conditionally, under the Generalized Riemann Hypothesis, Gupta and Murty proved Artin's primitive root conjecture for elliptic curves with complex multiplication, for primes splitting in the relevant imaginary quadratic field.[^o13]
