# Probabilistic latent semantic analysis

::: {#o1 .subject cue=lead name="Probabilistic latent semantic analysis"}

**Probabilistic latent semantic analysis** (**PLSA**), also known as **probabilistic latent semantic indexing** (**PLSI**, especially in information retrieval circles) is a [statistical technique](https://en.wikipedia.org/wiki/Statistical_technique) for the analysis of two-mode and co-occurrence data. In effect, one can derive a low-dimensional representation of the observed variables in terms of their affinity to certain hidden variables, just as in [latent semantic analysis](wikipedia://en/689427), from which PLSA evolved.

:::

Compared to standard [latent semantic analysis](wikipedia://en/689427) which stems from [linear algebra](wikipedia://en/18422) and downsizes the occurrence tables (usually via a [singular value decomposition](wikipedia://en/142207)), probabilistic latent semantic analysis is based on a mixture decomposition derived from a [latent class model](wikipedia://en/4094720).

## Model {#Model}

*Image: Plsi 1.svg.* [Plate notation](wikipedia://en/15882673) representing the PLSA model ("asymmetric" formulation). $d$ is the document index variable, $c$ is a word's topic drawn from the document's topic distribution, $P(c|d)$, and $w$ is a word drawn from the word distribution of this word's topic, $P(w|c)$ . The $d$ and $w$ are [observable variables](https://en.wikipedia.org/wiki/Observable_variable), the topic $c$ is a [latent variable](https://en.wikipedia.org/wiki/Latent_variable).

Considering observations in the form of co-occurrences $(w,d)$ of words and documents, PLSA models the probability of each co-occurrence as a mixture of conditionally independent [multinomial distributions](wikipedia://en/1045553):

$$P(w,d) = \sum_c P(d) P(c|d) P(w|c) = P(d) \sum_c P(c|d) P(w|c)$$

with $c$ being the words' topic. Note that the number of topics is a hyperparameter that must be chosen in advance and is not estimated from the data. The first formulation is the *symmetric* formulation, where $w$ and $d$ are both generated from the latent class $c$ in similar ways (using the conditional probabilities $P(d|c)$ and $P(w|c)$), whereas the second formulation is the *asymmetric* formulation, where, for each document $d$, a latent class is chosen conditionally to the document according to $P(c|d)$, and a word is then generated from that class according to $P(w|c)$. Although we have used words and documents in this example, the co-occurrence of any couple of discrete variables may be modelled in exactly the same way.

So, the number of parameters is equal to $cd + wc$. The number of parameters grows linearly with the number of documents. In addition, although PLSA is a generative model of the documents in the collection it is estimated on, it is not a generative model of new documents.

Their parameters are learned using the [EM algorithm](https://en.wikipedia.org/wiki/EM_algorithm).

::: {#o4 .application cue=heading name="Application"}

## Application {#Application}

PLSA may be used in a discriminative setting, via [Fisher kernels](wikipedia://en/6855527).[^o5]

PLSA has applications in [information retrieval](https://en.wikipedia.org/wiki/Information_retrieval) and [filtering](https://en.wikipedia.org/wiki/Information_filtering), [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing), [machine learning](wikipedia://en/233488) from text, [bioinformatics](wikipedia://en/4214),[^o6] and related areas.

It is reported that the [aspect model](https://en.wikipedia.org/wiki/Aspect_model) used in the probabilistic latent semantic analysis has severe [overfitting](wikipedia://en/173332) problems.[^o7]

:::

## Extensions {#Extensions}

- Hierarchical extensions:
  - Asymmetric: MASHA ("Multinomial ASymmetric Hierarchical Analysis")[^o10]
  - Symmetric: HPLSA ("Hierarchical Probabilistic Latent Semantic Analysis")[^o11]
- Generative models: The following models have been developed to address an often-criticized shortcoming of PLSA, namely that it is not a proper generative model for new documents.
  - [Latent Dirichlet allocation](wikipedia://en/4605351) – adds a [Dirichlet](wikipedia://en/1117833) prior on the per-document topic distribution
- Higher-order data: Although this is rarely discussed in the scientific literature, PLSA extends naturally to higher order data (three modes and higher), i.e. it can model co-occurrences over three or more variables. In the symmetric formulation above, this is done simply by adding conditional probability distributions for these additional variables. This is the probabilistic analogue to non-negative tensor factorisation.

:::

## History {#History}

This is an example of a [latent class model](wikipedia://en/4094720) (see references therein), and it is related[^o13][^o14] to [non-negative matrix factorization](wikipedia://en/3681279). The present terminology was coined in 1999 by Thomas Hofmann.[^o15]
