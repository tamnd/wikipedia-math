# Skorokhod's embedding theorem

::: {#o1 .subject cue=lead name="Skorokhod's embedding theorem"}

In [mathematics](wikipedia://en/18831) and [probability theory](wikipedia://en/23542), **Skorokhod's embedding theorem** is either or both of two [theorems](wikipedia://en/30977) that allow one to regard any suitable collection of [random variables](wikipedia://en/25685) as a [Wiener process](wikipedia://en/149984) ([Brownian motion](wikipedia://en/4436)) evaluated at a collection of [stopping times](wikipedia://en/1202193). Both results are named for the [Ukrainian](https://en.wikipedia.org/wiki/Ukraine) [mathematician](wikipedia://en/18902) [A. V. Skorokhod](https://en.wikipedia.org/wiki/Anatoliy_Skorokhod).

:::

::: {#o3 .statement kind=statement/theorem cue=named-heading name="Skorokhod's first embedding theorem"}

## Skorokhod's first embedding theorem {#Skorokhod's_first_embedding_theorem}

Let *X* be a [real](wikipedia://en/20646438)-valued random variable with [expected value](wikipedia://en/9653) 0 and finite [variance](wikipedia://en/32344); let *W* denote a canonical real-valued Wiener process. Then there is a stopping time (with respect to the natural [filtration](https://en.wikipedia.org/wiki/Filtration_%28abstract_algebra%29) of *W*), *τ*, such that *W*<sub>*τ*</sub> has the same distribution as *X*,

$$\operatorname{E}[\tau] = \operatorname{E}[X^2]$$

and

$$\operatorname{E}[\tau^2] \leq 4 \operatorname{E}[X^4].$$

:::

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Skorokhod's second embedding theorem"}

## Skorokhod's second embedding theorem {#Skorokhod's_second_embedding_theorem}

Let *X*<sub>1</sub>, *X*<sub>2</sub>, ... be a sequence of [independent and identically distributed random variables](wikipedia://en/30876902), each with expected value 0 and finite variance, and let

$$S_n = X_1 + \cdots + X_n.$$

Then there is a sequence of stopping times *τ*<sub>1</sub> ≤ *τ*<sub>2</sub> ≤ ... such that the $W_{\tau_{n}}$ have the same joint distributions as the partial sums *S*<sub>*n*</sub> and *τ*<sub>1</sub>, *τ*<sub>2</sub> − *τ*<sub>1</sub>, *τ*<sub>3</sub> − *τ*<sub>2</sub>, ... are independent and identically distributed random variables satisfying

$$\operatorname{E}[\tau_n - \tau_{n - 1}] = \operatorname{E}[X_1^2]$$

and

$$\operatorname{E}[(\tau_{n} - \tau_{n - 1})^2] \le 4 \operatorname{E}[X_1^4].$$

:::
