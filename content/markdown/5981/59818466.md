# Frequent pattern discovery

::: {#o1 .subject cue=lead name="Frequent pattern discovery"}

**Frequent pattern discovery** (or **FP discovery**, **FP mining**, or **Frequent itemset mining**) is part of [knowledge discovery in databases](https://en.wikipedia.org/wiki/Knowledge_discovery_in_databases), [Massive Online Analysis](https://en.wikipedia.org/wiki/Massive_Online_Analysis), and [data mining](wikipedia://en/42253); it describes the task of finding the most frequent and relevant [patterns](https://en.wikipedia.org/wiki/Pattern) in large datasets.[^o2][^o3] The concept was first introduced for mining transaction databases.[^o6] Frequent patterns are defined as subsets (itemsets, subsequences, or substructures) that appear in a data set with frequency no less than a user-specified or auto-determined threshold.[^o3][^o4]

:::

## Techniques {#Techniques}

Techniques for FP mining include:

- [market basket analysis](https://en.wikipedia.org/wiki/Market_basket_analysis)[^o6]
- [cross-marketing](https://en.wikipedia.org/wiki/Cross-marketing)
- catalog design
- [clustering](wikipedia://en/669675)
- [classification](wikipedia://en/232426)
- [recommendation systems](https://en.wikipedia.org/wiki/Recommendation_systems)[^o2]

For the most part, FP discovery can be done using [association rule learning](wikipedia://en/577053) with particular algorithms [Eclat](wikipedia://en/577053#Eclat_algorithm), [FP-growth](https://en.wikipedia.org/wiki/FP-growth) and the [Apriori algorithm](https://en.wikipedia.org/wiki/Apriori_algorithm).

Other strategies include:

- [Frequent subtree mining](https://en.wikipedia.org/wiki/Frequent_subtree_mining)
- [Structure mining](https://en.wikipedia.org/wiki/Structure_mining)
- [Sequential pattern mining](https://en.wikipedia.org/wiki/Sequential_pattern_mining)

and respective specific techniques.

Implementations exist for various [machine learning](wikipedia://en/233488) systems or modules like MLlib for [Apache Spark](https://en.wikipedia.org/wiki/Apache_Spark).[^o7]
