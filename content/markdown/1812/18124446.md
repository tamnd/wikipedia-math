# Volumetric mesh

::: {#o1 .subject cue=lead name="Volumetric mesh"}

In [3D computer graphics](https://en.wikipedia.org/wiki/3D_computer_graphics) and [modeling](https://en.wikipedia.org/wiki/3D_modeling), a **volumetric mesh** is a [polyhedral](https://en.wikipedia.org/wiki/Polyhedral) representation of the interior region of an object. It is unlike [polygon meshes](https://en.wikipedia.org/wiki/Polygon_mesh), which represent only the [surface](https://en.wikipedia.org/wiki/Computer_representation_of_surfaces) as polygons.

:::

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

One application of volumetric meshes is in [finite element analysis](https://en.wikipedia.org/wiki/Finite_element_analysis), which may use regular or irregular volumetric meshes to compute internal stresses and forces in an object throughout the entire volume of the object. [^o4]

Volume meshes may also be used for [portal rendering](https://en.wikipedia.org/wiki/Portal_rendering).

:::
