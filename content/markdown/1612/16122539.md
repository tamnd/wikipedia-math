# Self-reference puzzle

::: {#o1 .subject cue=lead name="Self-reference puzzle"}

types A **self-reference puzzle** is a type of [logical](wikipedia://en/46426065) [puzzle](https://en.wikipedia.org/wiki/Puzzle) where the question in the puzzle refers to the attributes of the puzzle itself.[^o2] A common example is that a "fill in the blanks" style sentence is given, but what is filled in the blanks can contribute to the sentence itself. An example is "There are \_\_\_\_\_ e's in this sentence.", for which a solution is "eight" (since including the "eight", there are 8 e's in the sentence).

:::
