# Sacks property

::: {#o1 .subject cue=lead name="Sacks property"}

In mathematical set theory, the **Sacks property** holds between two [models](wikipedia://en/19858) of [Zermelo–Fraenkel set theory](wikipedia://en/152214) if they are not "too dissimilar" in the following sense.

:::

For $M$ and $N$ transitive models of set theory, $N$ is said to have the Sacks property over $M$ if and only if for every function $g\in M$ mapping $\omega$ to $\omega\setminus\{0\}$ such that $g$ diverges to infinity, and every function $f\in N$ mapping $\omega$ to $\omega$ there is a [tree](wikipedia://en/704160) $T\in M$ such that for every $n$ the $n^{th}$ level of $T$ has cardinality at most $g(n)$ and $f$ is a branch of $T$.[^o2]

The Sacks property is used to control the value of certain [cardinal invariants](https://en.wikipedia.org/wiki/Cardinal_invariant) in [forcing](https://en.wikipedia.org/wiki/Forcing_%28set_theory%29) arguments. It is named for [Gerald Enoch Sacks](wikipedia://en/3050504).

A [forcing notion](wikipedia://en/152205) is said to have the Sacks property if and only if the forcing extension has the Sacks property over the ground model. Examples include [Sacks forcing](wikipedia://en/15550368#Sacks_forcing) and [Silver forcing](wikipedia://en/15550368#Silver_forcing).

[Shelah](wikipedia://en/331211) proved that when proper forcings with the Sacks property are [iterated](wikipedia://en/43053125) using countable supports, the resulting forcing notion will have the Sacks property as well.[^o3][^o4]

The Sacks property is equivalent to the conjunction of the [Laver property](wikipedia://en/45136432) and the ${}^\omega\omega$-bounding property.
