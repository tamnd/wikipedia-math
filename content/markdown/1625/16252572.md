# Balancing domain decomposition method

::: {#o1 .subject cue=lead name="Balancing domain decomposition method"}

In [numerical analysis](wikipedia://en/21506), the **balancing domain decomposition method (BDD)** is an [iterative method](wikipedia://en/15237) to find the solution of a [symmetric](wikipedia://en/126474) [positive definite](https://en.wikipedia.org/wiki/Positive_definite_matrix) system of [linear](wikipedia://en/17570) [algebraic equations](wikipedia://en/404001) arising from the [finite element method](wikipedia://en/18233581).[^o2] In each iteration, it combines the solution of local problems on non-overlapping subdomains with a coarse problem created from the subdomain [nullspaces](https://en.wikipedia.org/wiki/Null_space). BDD requires only solution of subdomain problems rather than access to the matrices of those problems, so it is applicable to situations where only the solution operators are available, such as in [oil reservoir](https://en.wikipedia.org/wiki/Oil_reservoir) [simulation](https://en.wikipedia.org/wiki/Simulation) by [mixed finite elements](https://en.wikipedia.org/wiki/Mixed_finite_elements).[^o3] In its original formulation, BDD performs well only for 2nd order problems, such [elasticity](https://en.wikipedia.org/wiki/Elasticity_%28physics%29) in 2D and 3D. For 4th order problems, such as [plate bending](https://en.wikipedia.org/wiki/Plate_bending), it needs to be modified by adding to the coarse problem special basis functions that enforce continuity of the solution at subdomain corners,[^o4] which makes it however more expensive. The [BDDC](wikipedia://en/16229578) method uses the same corner basis functions as,[^o4] but in an additive rather than multiplicative fashion.[^o5] The dual counterpart to BDD is [FETI](https://en.wikipedia.org/wiki/FETI), which enforces the equality of the solution between the subdomain by Lagrange multipliers. The base versions of BDD and FETI are not mathematically equivalent, though a special version of FETI designed to be robust for hard problems [^o6] has the same [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) and thus essentially the same performance as BDD.[^o7][^o8]

:::

The operator of the system solved by BDD is the same as obtained by eliminating the unknowns in the interiors of the subdomain, thus reducing the problem to the [Schur complement](wikipedia://en/372620) on the subdomain interface. Since the BDD preconditioner involves the solution of [Neumann problems](https://en.wikipedia.org/wiki/Neumann_problem) on all subdomain, it is a member of the [Neumann–Neumann class of methods](wikipedia://en/16252918), so named because they solve a Neumann problem on both sides of the interface between subdomains.

In the simplest case, the [coarse space](https://en.wikipedia.org/wiki/Coarse_problem) of BDD consists of functions constant on each subdomain and averaged on the interfaces. More generally, on each subdomain, the coarse space needs to only contain the [nullspace](https://en.wikipedia.org/wiki/Nullspace) of the problem as a subspace.
