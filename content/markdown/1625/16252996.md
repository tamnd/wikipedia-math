# Neumann–Dirichlet method

::: {#o1 .subject cue=lead name="Neumann–Dirichlet method"}

In mathematics, the **Neumann–Dirichlet method** is a [domain decomposition](https://en.wikipedia.org/wiki/Domain_decomposition) [preconditioner](wikipedia://en/5165246) which involves solving [Neumann](https://en.wikipedia.org/wiki/Neumann_problem) [boundary value problem](wikipedia://en/436779) on one subdomain and [Dirichlet](wikipedia://en/571109) [boundary value problem](wikipedia://en/436779) on another, adjacent across the interface between the subdomains.[^o2] On a problem with many subdomains organized in a rectangular mesh, the subdomains are assigned Neumann or Dirichlet problems in a checkerboard fashion.

:::
