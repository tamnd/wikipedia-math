# Champernowne distribution

::: {#o1 .subject cue=lead name="Champernowne distribution"}

In [statistics](wikipedia://en/26685), the **Champernowne distribution** is a symmetric, [continuous probability distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution), describing [random variables](wikipedia://en/25685) that take both positive and negative values. It is a generalization of the [logistic distribution](wikipedia://en/542666) that was introduced by [D. G. Champernowne](wikipedia://en/1994574).[^o2][^o3][^o4] Champernowne developed the distribution to describe the logarithm of income.[^o3]

:::

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Champernowne distribution has a [probability density function](wikipedia://en/43487) given by

$$f(y;\alpha, \lambda, y_0 ) = \frac{n}{\cosh[\alpha(y - y_0)] + \lambda}, \qquad -\infty < y < \infty,$$

where $\alpha, \lambda, y_0$ are positive parameters, and *n* is the normalizing constant, which depends on the parameters. The density may be rewritten as

$$f(y) = \frac{n}{\tfrac 1 2 e^{\alpha(y-y_0)} + \lambda + \tfrac 12 e^{-\alpha(y-y_0)}},$$

using the fact that $\cosh x = \tfrac 1 2 (e^x + e^{-x}).$

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

The density *f*(*y*) defines a symmetric distribution with median *y*<sub>0</sub>, which has tails somewhat heavier than a normal distribution.

:::

::: {#o10 .statement kind=statement/generalization cue=heading name="Special cases"}

### Special cases {#Special_cases}

In the special case $\lambda = 0$ ($\alpha = \tfrac \pi 2, y_0 = 0$) it is the [hyperbolic secant distribution](wikipedia://en/2026043).

In the special case $\lambda=1$ it is the [Burr Type XII](wikipedia://en/12618582) density.

When $y_0 = 0, \alpha=1, \lambda=1$,

$$f(y) = \frac{1}{e^y + 2 + e^{-y}} = \frac{e^y}{(1+e^y)^2},$$

which is the density of the standard [logistic distribution](wikipedia://en/542666).

:::

:::

## Distribution of income {#Distribution_of_income}

If the distribution of *Y*, the logarithm of income, has a Champernowne distribution, then the density function of the income *X* = exp(*Y*) is[^o2]

$$f(x) = \frac{n}{x [1/2(x/x_0)^{-\alpha} + \lambda + a/2(x/x_0)^\alpha ]}, \qquad x > 0,$$

where *x*<sub>0</sub> = exp(*y*<sub>0</sub>) is the median income. If λ = 1, this distribution is often called the [Fisk distribution](https://en.wikipedia.org/wiki/Fisk_distribution),[^o12] which has density

$$f(x) = \frac{\alpha x^{\alpha - 1}}{x_0^\alpha [1 + (x/x_0)^\alpha]^2}, \qquad x > 0.$$
