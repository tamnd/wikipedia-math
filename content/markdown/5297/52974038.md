# Γ-space

::: {#o1 .subject cue=lead name="Γ-space"}

In [mathematics](wikipedia://en/18831), a **$\gamma$-space** (gamma space) is a [topological space](wikipedia://en/30450) that satisfies a certain basic [selection principle](wikipedia://en/50398478). An infinite cover of a topological space is an $\omega$-cover if every finite subset of this space is contained in some member of the cover, and the whole space is not a member the cover. A cover of a topological space is a $\gamma$-cover if every point of this space belongs to all but finitely many members of this cover. A **$\gamma$-space** is a space in which every open $\omega$-cover contains a $\gamma$-cover.

:::

## History {#History}

Gerlits and Nagy introduced the notion of γ-spaces.[^o3] They listed some topological properties and enumerated them by Greek letters. The above property was the third one on this list, and therefore it is called the γ-property.

## Characterizations {#Characterizations}

### Combinatorial characterization {#Combinatorial_characterization}

Let $[\mathbb{N}]^\infty$ be the set of all infinite subsets of the set of [natural numbers](wikipedia://en/21474). A set $A\subset [\mathbb{N}]^\infty$ is centered if the intersection of finitely many elements of $A$ is infinite. Every set $a\in[\mathbb{N}]^\infty$ we identify with its increasing enumeration, and thus the set $a$ we can treat as a member of the [Baire space](wikipedia://en/200550) $\mathbb{N}^\mathbb{N}$. Therefore, $[\mathbb{N}]^\infty$ is a topological space as a subspace of the Baire space $\mathbb{N}^\mathbb{N}$. A [zero-dimensional](wikipedia://en/517682) [separable](wikipedia://en/27855) [metric space](wikipedia://en/20018) is a γ-space [if and only if](wikipedia://en/14922) every continuous image of that space into the space $[\mathbb{N}]^\infty$ that is centered has a [pseudointersection](wikipedia://en/43743012).[^o7]

### Topological game characterization {#Topological_game_characterization}

Let $X$ be a topological space. The $\gamma$-has a pseudo intersection if there is a set game played on $X$ is a game with two players [Alice and Bob](wikipedia://en/679079).

**1st round**: Alice chooses an open $\omega$-cover $\mathcal{U}_1$ of $X$. Bob chooses a set $U_1\in \mathcal{U}_1$.

**2nd round**: Alice chooses an open $\omega$-cover $\mathcal{U}_2$ of $X$. Bob chooses a set $U_2\in \mathcal{U}_2$.

**etc.**

If $\{U_n:n\in\mathbb{N}\}$ is a $\gamma$-cover of the space $X$, then Bob wins the game. Otherwise, Alice wins.

A player has a winning strategy if he knows how to play in order to win the game (formally, a winning strategy is a function).

A topological space is a $\gamma$-space iff Alice has no winning strategy in the $\gamma$-game played on this space.[^o3]

:::

## Properties {#Properties}

- A [topological space](wikipedia://en/30450) is a γ-space if and only if it satisfies $\text{S}_1(\Omega,\Gamma)$ [selection principle](wikipedia://en/50398478).[^o3]
- Every [Lindelöf space](wikipedia://en/310480) of cardinality less than the [pseudointersection](wikipedia://en/43743012) number $\mathfrak{p}$ is a $\gamma$-space.
- Every $\gamma$-space is a [Rothberger space](wikipedia://en/52820644),[^o11] and thus it has [strong measure zero](wikipedia://en/45200516).
- Let $X$ be a [Tychonoff space](wikipedia://en/30554), and $C(X)$ be the space of continuous functions $f\colon X\to\mathbb{R}$ with [pointwise convergence](wikipedia://en/340198) topology. The space $X$ is a $\gamma$-space if and only if $C(X)$ is [Fréchet–Urysohn](wikipedia://en/28480560) if and only if $C(X)$ is [strong Fréchet–Urysohn](wikipedia://en/28480560).[^o3]
- Let $A$ be a $\binom{\mathbf{\Omega}}{\mathbf{\Gamma}}$ subset of the [real line](wikipedia://en/287188), and $M$ be a [meager](wikipedia://en/226975) subset of the real line. Then the set $A+M=\{a+x:a\in A, x\in M\}$ is meager.[^o12]

:::
