# NSMB (mathematics)

::: {#o1 .subject cue=lead name="NSMB"}

**NSMB** is a computer system for solving [Navier–Stokes equations](wikipedia://en/48395) using the [finite volume method](wikipedia://en/345017). It supports meshes built of several blocks (multi-blocks) and supports [parallelisation](https://en.wikipedia.org/wiki/Parallel_computing). The name stands for "Navier–Stokes multi-block". It was developed by a consortium of European scientific institutions and companies, between 1992 and 2003.[^o2][^o3]

:::
