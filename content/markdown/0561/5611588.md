# Ramsey RESET test

::: {#o1 .subject cue=lead name="Ramsey RESET test"}

In [statistics](wikipedia://en/26685), the **Ramsey Regression Equation Specification Error Test (RESET) test** is a general [specification](wikipedia://en/11249626) test for the [linear regression](wikipedia://en/48758386) model. More specifically, it tests whether non-linear combinations of the explanatory variables help to explain the [response variable](https://en.wikipedia.org/wiki/Response_variable). The intuition behind the test is that if non-linear combinations of the [explanatory variables](https://en.wikipedia.org/wiki/Explanatory_variable) have any power in explaining the response variable, the model is misspecified in the sense that the data generating process might be better approximated by a [polynomial](wikipedia://en/23000) or another non-linear functional form.

:::

The test was developed by [James B. Ramsey](https://en.wikipedia.org/wiki/James_B._Ramsey) as part of his Ph.D. thesis at the [University of Wisconsin–Madison](https://en.wikipedia.org/wiki/University_of_Wisconsin–Madison) in 1968, and later published in the *[Journal of the Royal Statistical Society](wikipedia://en/13327143)* in 1969.[^o2][^o3]

## Technical summary {#Technical_summary}

Consider the model

$$\hat{y}=E\{y\mid x\}=\beta x.$$

The Ramsey test then tests whether $(\beta x)^2, (\beta x)^3, \ldots ,(\beta x)^k$ has any power in explaining $y$. This is executed by estimating the following [linear regression](wikipedia://en/48758386)

$$y=\beta x + \gamma_1\hat{y}^2+ \cdots +\gamma_{k-1}\hat{y}^k+\varepsilon,$$

and then testing, by a means of an [F-test](wikipedia://en/318976) whether $\gamma_1~$ through $~\gamma_{k-1}$ are zero. If the null-hypothesis that all $\gamma~$ coefficients are zero is rejected, then the model suffers from misspecification.
