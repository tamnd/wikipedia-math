# CryptoGraf

Products

::: {#o2 .subject cue=lead name="CryptoGraf"}

**CryptoGraf** is a secure messaging application for [smartphones](https://en.wikipedia.org/wiki/Smartphones) running [Symbian OS](https://en.wikipedia.org/wiki/Symbian_OS) and [Windows Mobile](https://en.wikipedia.org/wiki/Windows_Mobile). It allows the user to compose and send [SMS](https://en.wikipedia.org/wiki/SMS) and [MMS](https://en.wikipedia.org/wiki/Multimedia_Messaging_Service) messages that are [encrypted](https://en.wikipedia.org/wiki/Encrypted) and [digitally signed](wikipedia://en/59644) using methods that are based on the [S/MIME](https://en.wikipedia.org/wiki/S/MIME) standard. Secure e-mail messaging is not supported.

:::

The [cryptographic algorithms](wikipedia://en/5244) supported by CryptoGraf include [AES](wikipedia://en/1260), [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) and [SHA-256](https://en.wikipedia.org/wiki/SHA-256).

RSA [public keys](https://en.wikipedia.org/wiki/Public_key) of other users are stored in a "Crypto Contacts" list <http://cryptograf.com/cryptomanual.php> (2009-01-03). <https://web.archive.org/web/20090103081038/http://cryptograf.com/cryptomanual.php>. The user sends an encrypted SMS or MMS to a recipient listed in Crypto Contacts. Keys must be exchanged before messages can be sent. The way a Crypto Contact is received determines the [trust level](http://cryptograf.com/cryptomanual.php#heading14) (2009-01-03). <https://web.archive.org/web/20090103081038/http://cryptograf.com/cryptomanual.php#heading14> assigned to the key:

- High trust for Crypto Contacts received by [Bluetooth](https://en.wikipedia.org/wiki/Bluetooth).
- Medium trust for Crypto Contacts received via High trust contacts.
- Low trust for Crypto Contacts received by [SMS](https://en.wikipedia.org/wiki/SMS) or [MMS](https://en.wikipedia.org/wiki/Multimedia_Messaging_Service).

The Crypto Contacts list is based on a trust model similar to the [Web of trust](wikipedia://en/296356) known from [PGP](wikipedia://en/23080). Crypto Contacts are compatible with [X.509](https://en.wikipedia.org/wiki/X.509) [digital certificates](https://en.wikipedia.org/wiki/Digital_certificate) and contain RSA (1024/2048 bit) public keys. Messages are [encrypted](https://en.wikipedia.org/wiki/Encrypted) using [AES-256 bit](wikipedia://en/1260) and [digitally signed](wikipedia://en/59644) using [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) (1024/2048 bit) with [SHA-256](https://en.wikipedia.org/wiki/SHA-256). CryptoGraf is integrated with standard messaging application in both Symbian and Windows Mobile and stores messages in the default Inbox, Sent and other folders.
