# Sazonov's theorem

::: {#o1 .subject cue=lead name="Sazonov's theorem"}

In [mathematics](wikipedia://en/18831), **Sazonov's theorem**, named after [Vyacheslav Vasilievich Sazonov](https://en.wikipedia.org/wiki/Vyacheslav_Vasilievich_Sazonov) (Вячесла́в Васи́льевич Сазо́нов), is a [theorem](wikipedia://en/30977) in [functional analysis](wikipedia://en/11180).

:::

It states that a [bounded linear operator](wikipedia://en/455961) between two [Hilbert spaces](wikipedia://en/20598932) is [*γ*-radonifying](https://en.wikipedia.org/wiki/&gamma;-radonifying) if it is a [Hilbert–Schmidt operator](wikipedia://en/976673). The result is also important in the study of [stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes) and the [Malliavin calculus](wikipedia://en/837875), since results concerning [probability measures](wikipedia://en/45437) on infinite-dimensional spaces are of central importance in these fields. Sazonov's theorem also has a converse: if the map is not Hilbert–Schmidt, then it is not *γ*-radonifying.

::: {#o3 .statement cue=heading name="Statement of the theorem"}

## Statement of the theorem {#Statement_of_the_theorem}

Let *G* and *H* be two Hilbert spaces and let *T* : *G* → *H* be a [bounded operator](wikipedia://en/455961) from *G* to *H*. Recall that *T* is said to be ***γ*-radonifying** if the [push forward](wikipedia://en/9412979) of the [canonical Gaussian cylinder set measure](wikipedia://en/6571387#Cylinder_set_measures_on_Hilbert_spaces) on *G* is a *bona fide* [measure](wikipedia://en/19873) on *H*. Recall also that *T* is said to be a **[Hilbert–Schmidt operator](wikipedia://en/976673)** if there is an [orthonormal basis](wikipedia://en/195063) { *e*<sub>*i*</sub> : *i* ∈ *I* } of *G* such that

$$\sum_{i \in I} \| T(e_i) \|_H^2 < + \infty.$$

Then **Sazonov's theorem** is that *T* is *γ*-radonifying if it is a Hilbert–Schmidt operator.

The proof uses [Prokhorov's theorem](wikipedia://en/6553549).

:::

## Remarks {#Remarks}

The canonical Gaussian [cylinder set measure](wikipedia://en/6571387) on an infinite-dimensional Hilbert space can never be a *bona fide* measure; equivalently, the [identity function](wikipedia://en/15069) on such a space cannot be *γ*-radonifying.
