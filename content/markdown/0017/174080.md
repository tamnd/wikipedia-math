# Diagonal matrix

::: {#o1 .subject cue=lead name="Diagonal matrix"}

In [linear algebra](wikipedia://en/18422), a **diagonal matrix** is a [matrix](wikipedia://en/20556859) in which the entries outside the [main diagonal](wikipedia://en/194990) are all zero; the term usually refers to [square matrices](https://en.wikipedia.org/wiki/Square_matrices). Elements of the main diagonal can either be zero or nonzero. An example of a 2×2 diagonal matrix is $\left[\begin{smallmatrix} 3 & 0 \\ 0 & 2 \end{smallmatrix}\right]$, while an example of a 3×3 diagonal matrix is$\left[\begin{smallmatrix} 6 & 0 & 0 \\ 0 & 5 & 0 \\ 0 & 0 & 4 \end{smallmatrix}\right]$. An [identity matrix](wikipedia://en/59718) of any size, or any multiple of it is a diagonal matrix called a *scalar matrix*, for example, $\left[\begin{smallmatrix} 0.5 & 0 \\ 0 & 0.5 \end{smallmatrix}\right]$. In [geometry](wikipedia://en/18973446), a diagonal matrix may be used as a *[scaling matrix](https://en.wikipedia.org/wiki/Scaling_matrix)*, since matrix multiplication with it results in changing scale (size) and possibly also [shape](wikipedia://en/169191); only a scalar matrix results in uniform change in scale.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

As stated above, a diagonal matrix is a matrix in which all off-diagonal entries are zero. That is, the matrix $\mathbf{D} = (d_{i,j})$ with $n$ columns and $n$ rows is diagonal if

$$\forall i,j \in \{1, 2, \ldots, n\}, i \ne j \implies d_{i,j} = 0.$$

However, the main diagonal entries are unrestricted.

The term *diagonal matrix* may sometimes refer to a **rectangular diagonal matrix**, which is an $m$-by-$n$ matrix with all the entries not of the form $d_{i,i}$ being zero. For example:

$$\begin{bmatrix} 1 & 0 & 0\\ 0 & 4 & 0\\ 0 & 0 & -3\\ 0 & 0 & 0\\ \end{bmatrix} \quad \text{or} \quad \begin{bmatrix} 1 & 0 & 0 & 0 & 0\\ 0 & 4 & 0& 0 & 0\\ 0 & 0 & -3& 0 & 0 \end{bmatrix}$$

More often, however, *diagonal matrix* refers to square matrices, which can be specified explicitly as a **square diagonal matrix**. A square diagonal matrix is a [symmetric matrix](wikipedia://en/126474), so this can also be called a **symmetric diagonal matrix**.

The following matrix is square diagonal matrix:

$$\begin{bmatrix} 1 & 0 & 0\\ 0 & 4 & 0\\ 0 & 0 & -2 \end{bmatrix}$$

If the entries are [real numbers](https://en.wikipedia.org/wiki/Real_numbers) or [complex numbers](https://en.wikipedia.org/wiki/Complex_numbers), then it is a [normal matrix](wikipedia://en/170366) as well.

In the remainder of this article we will consider only square diagonal matrices, and refer to them simply as "diagonal matrices".

:::

## Vector-to-matrix diag operator {#Vector-to-matrix_diag_operator}

A diagonal matrix $\mathbf{D}$ can be constructed from a vector $\mathbf{a} = \begin{bmatrix}a_1 & \dots & a_n\end{bmatrix}^\textsf{T}$ using the $\operatorname{diag}$ operator:

$$\mathbf{D} = \operatorname{diag}(a_1, \dots, a_n).$$

This may be written more compactly as $\mathbf{D} = \operatorname{diag}(\mathbf{a})$.

The same operator is also used to represent [block diagonal matrices](wikipedia://en/457464#Block_diagonal_matrices) as $\mathbf{A} = \operatorname{diag}(\mathbf A_1, \dots, \mathbf A_n)$ where each argument $\mathbf{A}_{i}$ is a matrix.

The $\operatorname{diag}$ operator may be written as

$$\operatorname{diag}(\mathbf{a}) = \left(\mathbf{a} \mathbf{1}^\textsf{T}\right) \circ \mathbf{I},$$

where $\circ$ represents the [Hadamard product](wikipedia://en/34260496), and $\mathbf{1}$ is a constant vector with elements 1.

## Matrix-to-vector diag operator {#Matrix-to-vector_diag_operator}

The inverse matrix-to-vector $\operatorname{diag}$ operator is sometimes denoted by the identically named $\operatorname{diag}(\mathbf{D}) = \begin{bmatrix}a_1 & \dots & a_n\end{bmatrix}^\textsf{T},$ where the argument is now a matrix, and the result is a vector of its diagonal entries.

The following property holds:

$$\operatorname{diag}(\mathbf{A}\mathbf{B}) = \sum_j \left(\mathbf{A} \circ \mathbf{B}^\textsf{T}\right)_{ij} = \left( \mathbf{A} \circ \mathbf{B}^\textsf{T} \right) \mathbf{1}.$$

## Scalar matrix {#Scalar_matrix}

A diagonal matrix with equal diagonal entries is a **scalar matrix**; that is, a scalar multiple $\lambda$ of the [identity matrix](wikipedia://en/59718) $\mathbf{I}$. Its effect on a [vector](wikipedia://en/23218956) is [scalar multiplication](wikipedia://en/244373) by $\lambda$. For example, a 3×3 scalar matrix has the form:

$$\begin{bmatrix} \lambda & 0 & 0 \\ 0 & \lambda & 0 \\ 0 & 0 & \lambda \end{bmatrix} \equiv \lambda \boldsymbol{I}_3$$

The scalar matrices are the [center](https://en.wikipedia.org/wiki/Center_of_an_algebra) of the algebra of matrices: that is, they are precisely the matrices that [commute](https://en.wikipedia.org/wiki/Commute_%28mathematics%29) with all other square matrices of the same size. By contrast, over a [field](wikipedia://en/10603) (like the real numbers), a diagonal matrix with all diagonal elements distinct only commutes with diagonal matrices (its [centralizer](https://en.wikipedia.org/wiki/Centralizer) is the set of diagonal matrices). That is because if a diagonal matrix $\mathbf{D} = \operatorname{diag}(a_1, \dots, a_n)$ has $a_i \neq a_j,$ then given a matrix $\mathbf{M}$ with $m_{ij} \neq 0,$ the $(i, j)$ term of the products are: $(\mathbf{DM})_{ij} = a_im_{ij}$ and $(\mathbf{MD})_{ij} = m_{ij}a_j,$ and $a_jm_{ij} \neq m_{ij}a_i$ (since one can divide by $m_{ij}$), so they do not commute unless the off-diagonal terms are zero. Diagonal matrices where the diagonal entries are not all equal or all distinct have centralizers intermediate between the whole space and only diagonal matrices.[^o8]

For an abstract vector space $V$ (rather than the concrete vector space $K^{n}$), the analog of scalar matrices are **scalar transformations**. This is true more generally for a [module](https://en.wikipedia.org/wiki/Module_%28ring_theory%29) $M$ over a [ring](https://en.wikipedia.org/wiki/Ring_%28algebra%29) $R$, with the [endomorphism algebra](https://en.wikipedia.org/wiki/Endomorphism_algebra) $\operatorname{End}(M)$ (algebra of linear operators on $M$) replacing the algebra of matrices. Formally, scalar multiplication is a linear map, inducing a map $R \to \operatorname{End}(M),$ (from a scalar $\lambda$ to its corresponding scalar transformation, multiplication by $\lambda$) exhibiting $\operatorname{End}(M)$ as a $R$-[algebra](https://en.wikipedia.org/wiki/Algebra_%28ring_theory%29). For vector spaces, the scalar transforms are exactly the [center](https://en.wikipedia.org/wiki/Center_of_a_ring) of the endomorphism algebra, and, similarly, scalar invertible transforms are the center of the [general linear group](wikipedia://en/113564) $\operatorname{GL}(V)$. The former is more generally true [free modules](wikipedia://en/326454) $M \cong R^n,$ for which the endomorphism algebra is isomorphic to a matrix algebra.

:::

## Vector operations {#Vector_operations}

Multiplying a vector by a diagonal matrix multiplies each of the terms by the corresponding diagonal entry. Given a diagonal matrix $\mathbf{D} = \operatorname{diag}(a_1, \dots, a_n)$ and a vector $\mathbf{v} = \begin{bmatrix} x_1 & \dotsm & x_n \end{bmatrix}^\textsf{T}$, the product is:

$$\mathbf{D}\mathbf{v} = \operatorname{diag}(a_1, \dots, a_n)\begin{bmatrix}x_1 \\ \vdots \\ x_n\end{bmatrix} = \begin{bmatrix} a_1 \\ & \ddots \\ & & a_n \end{bmatrix} \begin{bmatrix}x_1 \\ \vdots \\ x_n\end{bmatrix} = \begin{bmatrix}a_1 x_1 \\ \vdots \\ a_n x_n\end{bmatrix}.$$

This can be expressed more compactly by using a vector instead of a diagonal matrix, $\mathbf{d} = \begin{bmatrix} a_1 & \dotsm & a_n \end{bmatrix}^\textsf{T}$, and taking the [Hadamard product](wikipedia://en/34260496) of the vectors (entrywise product), denoted $\mathbf{d} \circ \mathbf{v}$:

$$\mathbf{D}\mathbf{v} = \mathbf{d} \circ \mathbf{v} = \begin{bmatrix} a_1 \\ \vdots \\ a_n \end{bmatrix} \circ \begin{bmatrix} x_1 \\ \vdots \\ x_n \end{bmatrix} = \begin{bmatrix} a_1 x_1 \\ \vdots \\ a_n x_n \end{bmatrix}.$$

This is mathematically equivalent, but avoids storing all the zero terms of this [sparse matrix](wikipedia://en/341015). This product is thus used in [machine learning](wikipedia://en/233488), such as computing products of derivatives in [backpropagation](https://en.wikipedia.org/wiki/Backpropagation) or multiplying IDF weights in [TF-IDF](https://en.wikipedia.org/wiki/TF-IDF),[^o10] since some [BLAS](https://en.wikipedia.org/wiki/BLAS) frameworks, which multiply matrices efficiently, do not include Hadamard product capability directly.[^o11]

## Matrix operations {#Matrix_operations}

The operations of matrix addition and [matrix multiplication](wikipedia://en/125280) are especially simple for diagonal matrices. Write $\operatorname{diag}(a_{1}, ..., a_{n})$ for a diagonal matrix whose diagonal entries starting in the upper left corner are $a_{1}, ..., a_{n}$. Then, for [addition](wikipedia://en/125276), we have

$$\operatorname{diag}(a_1,\, \ldots,\, a_n) + \operatorname{diag}(b_1,\, \ldots,\, b_n) = \operatorname{diag}(a_1 + b_1,\, \ldots,\, a_n + b_n)$$

and for [matrix multiplication](wikipedia://en/125280),

$$\operatorname{diag}(a_1,\, \ldots,\, a_n) \operatorname{diag}(b_1,\, \ldots,\, b_n) = \operatorname{diag}(a_1 b_1,\, \ldots,\, a_n b_n).$$

The diagonal matrix $\operatorname{diag}(a_{1}, ..., a_{n})$ is [invertible](wikipedia://en/217122) [if and only if](wikipedia://en/14922) the entries $a_{1}, ..., a_{n}$ are all nonzero. In this case, we have

$$\operatorname{diag}(a_1,\, \ldots,\, a_n)^{-1} = \operatorname{diag}(a_1^{-1},\, \ldots,\, a_n^{-1}).$$

In particular, the diagonal matrices form a [subring](wikipedia://en/24873145) of the ring of all $n$-by-$n$ matrices.

Multiplying an $n$-by-$n$ matrix $\mathbf{A}$ from the *left* with $\operatorname{diag}(a_{1}, ..., a_{n})$ amounts to multiplying the $i$-th *row* of $\mathbf{A}$ by $a_{i}$ for all $i$; multiplying the matrix $\mathbf{A}$ from the *right* with $\operatorname{diag}(a_{1}, ..., a_{n})$ amounts to multiplying the $i$-th *column* of $\mathbf{A}$ by $a_{i}$ for all $i$.

## Operator matrix in eigenbasis {#Operator_matrix_in_eigenbasis}

As explained in [determining coefficients of operator matrix](wikipedia://en/692458#Finding_the_matrix_of_a_transformation), there is a special basis, $\mathbf{e}_{1}, ..., \mathbf{e}_{n}$, for which the matrix $\mathbf{A}$ takes the diagonal form. Hence, in the defining equation $\mathbf{Ae}_j = \sum_i a_{i,j} \mathbf e_i$, all coefficients $a_{i, j}$ with $i \ne j$ are zero, leaving only one term per sum. The surviving diagonal elements, $a_{i, j}$, are known as **eigenvalues** and designated with $\lambda_{i}$ in the equation, which reduces to $\mathbf{Ae}_i = \lambda_i \mathbf e_i.$ The resulting equation is known as **eigenvalue equation**[^o14] and used to derive the [characteristic polynomial](wikipedia://en/218268) and, further, [eigenvalues and eigenvectors](wikipedia://en/2161429).

In other words, the [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of $\operatorname{diag}(\lambda_{1}, ..., \lambda_{n})$ are $\lambda_{1}, ..., \lambda_{n}$ with associated [eigenvectors](https://en.wikipedia.org/wiki/Eigenvectors) of $\mathbf{e}_{1}, ..., \mathbf{e}_{n}$.

::: {#o16 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The [determinant](wikipedia://en/8468) of $\operatorname{diag}(a_{1}, ..., a_{n})$ is the product $a_{1}\cdots a_{n}$.
- The [adjugate](https://en.wikipedia.org/wiki/Adjugate) of a diagonal matrix is again diagonal.
- Where all matrices are square,
  - A matrix is diagonal if and only if it is triangular and [normal](wikipedia://en/170366).
  - A matrix is diagonal if and only if it is both [upper-](wikipedia://en/374222) and [lower-triangular](wikipedia://en/374222).
  - A diagonal matrix is [symmetric](wikipedia://en/126474).
- The [identity matrix](wikipedia://en/59718) $\mathbf{I}_{n}$ and [zero matrix](wikipedia://en/1168888) are diagonal.
- A 1×1 matrix is always diagonal.
- The square of a 2×2 matrix with zero [trace](wikipedia://en/43270) is always diagonal.
- The inverse of a diagonal matrix is obtained by taking the reciprocals of the elements on the diagonal

:::

## Applications {#Applications}

Diagonal matrices occur in many areas of linear algebra. Because of the simple description of the matrix operation and eigenvalues/eigenvectors given above, it is typically desirable to represent a given matrix or [linear map](https://en.wikipedia.org/wiki/Linear_operator) by a diagonal matrix.

In fact, a given $n$-by-$n$ matrix $\mathbf{A}$ is [similar](https://en.wikipedia.org/wiki/Similar_matrix) to a diagonal matrix (meaning that there is a matrix $\mathbf{X}$ such that $\mathbf{X}^{-1}\mathbf{AX}$ is diagonal) if and only if it has $n$ [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) eigenvectors. Such matrices are said to be [diagonalizable](wikipedia://en/246325).

Over the [field](wikipedia://en/10603) of [real](wikipedia://en/20646438) or [complex](wikipedia://en/5826) numbers, more is true. The [spectral theorem](wikipedia://en/123495) says that every [normal matrix](wikipedia://en/170366) is [unitarily similar](wikipedia://en/341149) to a diagonal matrix (if $\mathbf{AA}^{\ast} = \mathbf{A}^{\ast}\mathbf{A}$ then there exists a [unitary matrix](wikipedia://en/129222) $\mathbf{U}$ such that $\mathbf{UAU}^{\ast}$ is diagonal). Furthermore, the [singular value decomposition](wikipedia://en/142207) implies that for any matrix $\mathbf{A}$, there exist unitary matrices $\mathbf{U}$ and $\mathbf{V}$ such that $\mathbf{U}^{\ast}\mathbf{AV}$ is diagonal with positive entries.

:::

## Operator theory {#Operator_theory}

In [operator theory](wikipedia://en/712675), particularly the study of [PDEs](https://en.wikipedia.org/wiki/PDEs), operators are particularly easy to understand and PDEs easy to solve if the operator is diagonal with respect to the basis with which one is working; this corresponds to a [separable partial differential equation](wikipedia://en/6885778). Therefore, a key technique to understanding operators is a change of coordinates—in the language of operators, an [integral transform](wikipedia://en/430912)—which changes the basis to an [eigenbasis](https://en.wikipedia.org/wiki/Eigenbasis) of [eigenfunctions](wikipedia://en/228601): which makes the equation separable. An important example of this is the [Fourier transform](wikipedia://en/52247), which diagonalizes constant coefficient differentiation operators (or more generally translation invariant operators), such as the Laplacian operator, say, in the [heat equation](wikipedia://en/166415).

Especially easy are [multiplication operators](wikipedia://en/976642), which are defined as multiplication by (the values of) a fixed function–the values of the function at each point correspond to the diagonal entries of a matrix.
