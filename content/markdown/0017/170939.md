# Step function

::: {#o1 .subject cue=lead name="Step function"}

In mathematics, a [function](wikipedia://en/185427) on the [real numbers](wikipedia://en/20646438) is called a **step function** if it can be written as a [finite](wikipedia://en/11742) [linear combination](wikipedia://en/55632) of [indicator functions](wikipedia://en/240790) of [intervals](wikipedia://en/49172). Informally speaking, a step function is a [piecewise](https://en.wikipedia.org/wiki/Piecewise) [constant function](wikipedia://en/320861) having only finitely many pieces.

*Image: StepFunctionExample.png.* An example of step functions (the red graph). In this function, each constant subfunction with a function value *α<sub>i</sub>* (*i* = 0, 1, 2, ...) is defined by an interval *A<sub>i</sub>* and intervals are distinguished by points *x<sub>j</sub>* (*j* = 1, 2, ...). This particular step function is [right-continuous](wikipedia://en/6122#Directional_and_semi-continuity).

:::

## Definition and first consequences {#Definition_and_first_consequences}

A function $f\colon \mathbb{R} \rightarrow \mathbb{R}$ is called a **step function** if it can be written as

$f(x) = \sum\limits_{i=0}^n \alpha_i \chi_{A_i}(x)$, for all real numbers $x$

where $n\ge 0$, $\alpha_i$ are real numbers, $A_i$ are intervals, and $\chi_{A_{i}}$ is the [indicator function](wikipedia://en/240790) of $A_{i}$:

$$\chi_{A_{i}}(x) = \begin{cases} 1 & \text{if } x \in A_{i} \\ 0 & \text{if } x \notin A_{i} \\ \end{cases}$$

In this definition, the intervals $A_i$ can be assumed to have the following two properties:

1. The intervals are [pairwise disjoint](wikipedia://en/39359): $A_i \cap A_j = \emptyset$ for $i \neq j$
1. The [union](wikipedia://en/47949) of the intervals is the entire real line: $\bigcup_{i=0}^n A_i = \mathbb R.$

Indeed, if that is not the case to start with, a different set of intervals can be picked for which these assumptions hold. For example, the step function

$$f = 4 \chi_{[-5, 1)} + 3 \chi_{(0, 6)}$$

can be written as

$$f = 0\chi_{(-\infty, -5)} +4 \chi_{[-5, 0]} +7 \chi_{(0, 1)} + 3 \chi_{[1, 6)}+0\chi_{[6, \infty)}.$$

### Variations in the definition {#Variations_in_the_definition}

Sometimes, the intervals are required to be right-open[^o4] or allowed to be singleton.[^o5] The condition that the collection of intervals must be finite is often dropped, especially in school mathematics,[^o6][^o7][^o8] though it must still be [locally finite](wikipedia://en/11611098), resulting in the definition of piecewise constant functions.

## Examples {#Examples}

*Image: Dirac distribution CDF.svg.* The [Heaviside step function](wikipedia://en/87299) is an often-used step function.

- A [constant function](wikipedia://en/320861) is a trivial example of a step function. Then there is only one interval, $A_0=\mathbb R.$
- The [sign function](wikipedia://en/505449) $\operatorname{sgn}(x)$, which is −1 for negative numbers and +1 for positive numbers, and is the simplest non-constant step function.
- The [Heaviside function](wikipedia://en/87299) $H(x)$, which is 0 for negative numbers and 1 for positive numbers, is equivalent to the sign function, up to a shift and scale of range ($H = (\operatorname{sgn} + 1)/2$). It is the mathematical concept behind some test [signals](https://en.wikipedia.org/wiki/Signal_%28electronics%29), such as those used to determine the [step response](wikipedia://en/545863) of a [dynamical system](https://en.wikipedia.org/wiki/Dynamical_system_%28definition%29).

*Image: Rectangular function.svg.* The [rectangular function](wikipedia://en/1261615), the next simplest step function.

- The [rectangular function](wikipedia://en/1261615), the normalized [boxcar function](wikipedia://en/1454542), is used to model a unit pulse.

::: {#o12 .example kind=example/counterexample cue=heading name="Non-examples"}

### Non-examples {#Non-examples}

- The [integer part](https://en.wikipedia.org/wiki/Integer_part) function is not a step function according to the definition of this article, since it has an infinite number of intervals. However, some authors also define step functions with an infinite number of intervals.[^o13]

## Properties {#Properties}

- The sum and product of two step functions is again a step function. The product of a step function with a number is also a step function. As such, the step functions form an [algebra](wikipedia://en/191788) over the real numbers.
- A step function takes only a finite number of values. If the intervals $A_i,$ for $i=0, 1, \dots, n$ in the above definition of the step function are disjoint and their union is the real line, then $f(x)=\alpha_i$ for all $x\in A_i.$
- The [definite integral](https://en.wikipedia.org/wiki/Definite_integral) of a step function is a [piecewise linear function](wikipedia://en/444224).
- The [Lebesgue integral](wikipedia://en/26064288) of a step function $\textstyle f = \sum_{i=0}^n \alpha_i \chi_{A_i}$ is $\textstyle \int f\,dx = \sum_{i=0}^n \alpha_i \ell(A_i),$ where $\ell(A)$ is the length of the interval $A$, and it is assumed here that all intervals $A_i$ have finite length. In fact, this equality (viewed as a definition) can be the first step in constructing the Lebesgue integral.[^o16]
- A [discrete random variable](https://en.wikipedia.org/wiki/Discrete_random_variable) is sometimes defined as a [random variable](wikipedia://en/25685) whose [cumulative distribution function](wikipedia://en/5793) is piecewise constant.[^o17] In this case, it is locally a step function (globally, it may have an infinite number of steps). Usually however, any random variable with only countably many possible values is called a discrete random variable, in this case their cumulative distribution function is not necessarily locally a step function, as infinitely many intervals can accumulate in a finite region.

:::
