# Fast multipole method

::: {#o1 .subject cue=lead name="Fast multipole method"}

The **fast multipole method** (**FMM**) is a [numerical](wikipedia://en/21506) technique that was developed to speed up the calculation of long-ranged forces in the [*n*-body problem](wikipedia://en/23859945). It does this by expanding the system [Green's function](https://en.wikipedia.org/wiki/Green's_function_%28many-body_theory%29) using a [multipole expansion](wikipedia://en/1425534), which allows one to group sources that lie close together and treat them as if they were a single source.[^o2]

:::

The FMM has also been applied in accelerating the [iterative solver](https://en.wikipedia.org/wiki/Iterative_solver) in the [method of moments](wikipedia://en/68572267) (MoM) as applied to [computational electromagnetics](wikipedia://en/3849994) problems,[^o3] and in particular in [computational bioelectromagnetism](https://en.wikipedia.org/wiki/Charge_based_boundary_element_fast_multipole_method). The FMM was first introduced in this manner by [Leslie Greengard](wikipedia://en/30091589) and [Vladimir Rokhlin Jr.](https://en.wikipedia.org/wiki/Vladimir_Rokhlin_Jr.)[^o4] and is based on the [multipole expansion](wikipedia://en/1425534) of the vector [Helmholtz equation](wikipedia://en/1156215). By treating the interactions between far-away basis functions using the FMM, the corresponding matrix elements do not need to be explicitly stored, resulting in a significant reduction in required memory. If the FMM is then applied in a hierarchical manner, it can improve the complexity of matrix-vector products in an iterative solver from $\mathcal{O}(N^2)$ to $\mathcal{O}(N)$ in finite arithmetic, i.e., given a tolerance $\varepsilon$, the matrix-vector product is guaranteed to be within a tolerance $\varepsilon.$ The dependence of the complexity on the tolerance $\varepsilon$ is $\mathcal{O}(\log(1/\varepsilon))$, i.e., the complexity of FMM is $\mathcal{O}(N\log(1/\varepsilon))$. This has expanded the area of applicability of the MOM to far greater problems than were previously possible.

The FMM, introduced by Rokhlin Jr. and Greengard has been said to be one of the top ten [algorithms](wikipedia://en/775) of the 20th century.[^o5] The FMM algorithm reduces the complexity of matrix-vector multiplication involving a certain type of dense matrix which can arise out of many physical systems.

The FMM has also been applied for efficiently treating the Coulomb interaction in the [Hartree–Fock method](wikipedia://en/475393) and [density functional theory](wikipedia://en/209874) calculations in [quantum chemistry](https://en.wikipedia.org/wiki/Quantum_chemistry).[^o6][^o7]

## Sketch of the algorithm {#Sketch_of_the_algorithm}

*Image: Fast Multipoles - Local Expansion.svg.* Fast multipole method – interpolation of a pole at *x* = 3 with an order-5 Chebyshev polynomial

In its simplest form, the fast multipole method seeks to evaluate the following function:

$$f(y) = \sum_{\alpha=1}^N \frac{\phi_\alpha}{y - x_\alpha},$$

where $x_\alpha \in [-1, 1]$ are a set of poles, and $\phi_\alpha\in\mathbb C$ are the corresponding pole weights on a set of points $\{y_1, \ldots, y_M\}$ with $y_\beta \in [-1, 1]$. This is the one-dimensional form of the problem, but the algorithm can be easily generalized to multiple dimensions and kernels other than $(y - x)^{-1}$.

Naively, evaluating $f(y)$ on $M$ points requires $\mathcal O(MN)$ operations. The crucial observation behind the fast multipole method is that if the distance between $y$ and $x$ is large enough, then $(y - x)^{-1}$ is well-approximated by a [polynomial](wikipedia://en/23000). Specifically, let $-1 < t_1 < \ldots < t_p < 1$ be the [Chebyshev nodes](wikipedia://en/647470) of order $p \ge 2,$ and let $u_1(y), \ldots, u_p(y)$ be the corresponding [Lagrange basis polynomials](wikipedia://en/217523). One can show that the interpolating polynomial

$$\frac{1}{y-x} = \sum_{i=1}^p \frac{1}{t_i - x} u_i(y) + \epsilon_p(y)$$

converges quickly with polynomial order, $|\epsilon_{p(y)}| < 5^{-p}$, provided that the pole is far enough away from the region of interpolation, $|x| \ge 3$ and $|y| < 1$. This is known as the "local expansion".

The speed-up of the fast multipole method derives from this interpolation: provided that all the poles are "far away", we evaluate the sum only on the Chebyshev nodes at a cost of $\mathcal O(N p)$, and then interpolate it onto all the desired points at a cost of $\mathcal O(M p)$:

$$\sum_{\alpha=1}^N \frac{\phi_\alpha}{y_\beta - x_\alpha} = \sum_{i=1}^p u_i(y_\beta) \sum_{\alpha=1}^N \frac{1}{t_i - x_\alpha} \phi_\alpha.$$

Since $p = -\log_5 \epsilon$, where $\epsilon$ is the numerical tolerance, the total cost is $\mathcal O\big((M + N) \log(1/\epsilon)\big)$.

To ensure that the poles are indeed well-separated, one recursively subdivides the unit interval such that only $\mathcal O(p)$ poles end up in each interval. One then uses the explicit formula within each interval and interpolation for all intervals that are well-separated. This does not spoil the scaling, since one needs at most $\log(1/\epsilon)$ levels within the given tolerance.

### Free software {#Free_software}

- [Puma-EM](https://sourceforge.net/projects/puma-em/) A high performance, parallelized, open source Method of Moments / Multilevel Fast Multipole Method electromagnetics code.
- [KIFMM3d](http://www.harperlangston.com/kifmm3d/documentation/index.html) The Kernel-Independent Fast Multipole 3d Method (kifmm3d) is a new FMM implementation which does not require the explicit multipole expansions of the underlying kernel, and it is based on kernel evaluations.
- [PVFMM](https://github.com/dmalhotra/pvfmm) An optimized parallel implementation of KIFMM for computing potentials from particle and volume sources.
- [FastBEM](http://www.yijunliu.com/Software) Free fast multipole boundary element programs for solving 2D/3D potential, elasticity, stokes flow and acoustic problems.
- [FastFieldSolvers](http://www.fastfieldsolvers.com) maintains the distribution of the tools, called FastHenry and FastCap, developed at M.I.T. for the solution of Maxwell equations and extraction of circuit parasites (inductance and capacitance) using the FMM.
- [ExaFMM](https://github.com/exafmm/exafmm) ExaFMM is a CPU/GPU capable 3D FMM code for Laplace/Helmholtz kernels that focuses on parallel scalability.
- [ScalFMM](http://scalfmm-public.gforge.inria.fr/doc/) (2017-05-02). <https://web.archive.org/web/20170502145137/http://scalfmm-public.gforge.inria.fr/doc/> ScalFMM is a C++ software library developed at [Inria](https://en.wikipedia.org/wiki/Inria) Bordeaux with high emphasis on genericity and parallelization (using [OpenMP](https://en.wikipedia.org/wiki/OpenMP)/[MPI](https://en.wikipedia.org/wiki/Message_Passing_Interface)).
- [DASHMM](https://jacksondebuhr.github.io/dashmm/) DASHMM is a C++ Software library developed at Indiana University using Asynchronous Multi-Tasking HPX-5 [runtime system](https://en.wikipedia.org/wiki/Runtime_system). It provides a unified execution on shared and distributed memory computers and provides 3D Laplace, Yukawa, and Helmholtz kernels.
- [RECFMM](https://zhang416.github.io/recfmm/) Adaptive FMM with dynamic parallelism on multicores.
- [FMM3D](https://fmm3d.readthedocs.io/en/latest/) A library for efficient 3D N-body interaction computation on multicore machines.
