# MDS matrix

::: {#o1 .subject cue=lead name="MDS matrix"}

An **MDS matrix** (**maximum distance separable**) is a [matrix](wikipedia://en/20556859) representing a function with certain [diffusion](https://en.wikipedia.org/wiki/Diffusion_%28cryptography%29) properties that have useful applications in [cryptography](wikipedia://en/18934432). Technically, an $m \times n$ matrix $A$ over a [finite field](wikipedia://en/11615) $K$ is an MDS matrix if it is the [transformation matrix](wikipedia://en/692458) of a [linear transformation](https://en.wikipedia.org/wiki/Linear_transformation) $f(x) = Ax$ from $K^n$ to $K^m$ such that no two different $(m + n)$-tuples of the form $(x, f(x))$ coincide in $n$ or more components. Equivalently, the set of all $(m + n)$-tuples $(x, f(x))$ is an [MDS code](https://en.wikipedia.org/wiki/Maximum_distance_separable_code), i.e., a [linear code](wikipedia://en/1866743) that reaches the [Singleton bound](wikipedia://en/1874173).

:::

Let $\tilde A = \begin{pmatrix} \mathrm{I}_n \\ \hline \mathrm{A} \end{pmatrix}$ be the matrix obtained by joining the [identity matrix](wikipedia://en/59718) $\mathrm{I}_n$ to $A$. Then a necessary and sufficient condition for a matrix $A$ to be MDS is that every possible $n \times n$ [submatrix](https://en.wikipedia.org/wiki/Submatrix) obtained by removing $m$ rows from $\tilde A$ is [non-singular](https://en.wikipedia.org/wiki/Non-singular_matrix). This is also equivalent to the following: all the sub-determinants of the matrix $A$ are non-zero. Then a binary matrix $A$ (namely over the field with two elements) is never MDS unless it has only one row or only one column with all components $1$.

[Reed–Solomon codes](https://en.wikipedia.org/wiki/Reed–Solomon_code) have the MDS property and are frequently used to obtain the MDS matrices used in cryptographic algorithms.

[Serge Vaudenay](https://en.wikipedia.org/wiki/Serge_Vaudenay) suggested using MDS matrices in [cryptographic primitives](wikipedia://en/4928985) to produce what he called *multipermutations*, not-necessarily linear functions with this same property.[^o2] These functions have what he called *perfect diffusion*: changing $t$ of the inputs changes at least $m - t + 1$ of the outputs. He showed how to exploit imperfect diffusion to [cryptanalyze](wikipedia://en/5715) functions that are not multipermutations.

MDS matrices are used for diffusion in such [block ciphers](wikipedia://en/4594) as [AES](wikipedia://en/1260), [SHARK](wikipedia://en/619666), [Square](wikipedia://en/613945), [Twofish](wikipedia://en/26508356), [Anubis](wikipedia://en/3432526), [KHAZAD](wikipedia://en/615967), [Manta](https://en.wikipedia.org/wiki/Manta_%28cipher%29), [Hierocrypt](wikipedia://en/8439595), [Kalyna](wikipedia://en/52949872), [Camellia](wikipedia://en/532475) and [HADESMiMC](https://en.wikipedia.org/wiki/HADESMiMC), and in the [stream cipher](wikipedia://en/49007) [MUGI](https://en.wikipedia.org/wiki/MUGI) and the [cryptographic hash function](wikipedia://en/439526) [Whirlpool](https://en.wikipedia.org/wiki/Whirlpool_%28cryptography%29), [Poseidon](https://en.wikipedia.org/wiki/Poseidon_%28cryptography%29).
