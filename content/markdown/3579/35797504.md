# Pseudo-canonical variety

::: {#o1 .subject cue=lead name="Pseudo-canonical variety"}

In mathematics, a **pseudo-canonical variety** is an [algebraic variety](wikipedia://en/248808) of "general type".

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Formally, a variety *X* is pseudo-canonical if the [canonical class](https://en.wikipedia.org/wiki/Canonical_class) is pseudo-ample.

:::

::: {#o5 .statement cue=heading name="Results"}

## Results {#Results}

For a [non-singular](https://en.wikipedia.org/wiki/Non-singular_variety) [projective variety](wikipedia://en/320469), a result of [Kodaira](wikipedia://en/646326) states that this is equivalent to a divisor in the class being the sum of an [ample divisor](https://en.wikipedia.org/wiki/Ample_divisor) and an [effective divisor](https://en.wikipedia.org/wiki/Effective_divisor).

:::
