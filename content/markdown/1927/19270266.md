# Spark (mathematics)

::: {#o1 .subject cue=lead name="Spark"}

In [mathematics](wikipedia://en/18831), more specifically in [linear algebra](wikipedia://en/18422), the **spark** of a $m \times n$ [matrix](wikipedia://en/20556859) $A$ is the smallest integer $k$ such that there exists a set of $k$ columns in $A$ which are [linearly dependent](wikipedia://en/101863). If all the columns are linearly independent, $\mathrm{spark}(A)$ is usually defined to be 1 more than the number of rows. The concept of matrix spark finds applications in [error-correction codes](wikipedia://en/4237207), [compressive sensing](https://en.wikipedia.org/wiki/Compressive_sensing), and [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory), and provides a simple criterion for maximal sparsity of solutions to a [system of linear equations](wikipedia://en/113087).

:::

The spark of a matrix is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) to compute.

Equivalently, the spark of a matrix $A$ is the size of its smallest *circuit* $C$ (a subset of column indices such that $A_C x = 0$ has a nonzero solution, but every subset of it does not[^o20]).

If all the columns are linearly independent, $\mathrm{spark}(A)$ is usually defined to be $m+1$ (if $A$ has *m* rows).[^o6][^o7]

By contrast, the [rank](wikipedia://en/26561) of a matrix is the largest number $k$ such that some set of $k$ columns of $A$ is linearly independent.[^o19]

## Example {#Example}

Consider the following matrix $A$.

$$A= \begin{bmatrix} 1 & 2 & 0 & 1 \\ 1 & 2 & 0 & 2 \\ 1 & 2 & 0 & 3 \\ 1 & 0 & -3 & 4 \end{bmatrix}$$

The spark of this matrix equals 3 because:

- There is no set of 1 column of $A$ which are linearly dependent.
- There is no set of 2 columns of $A$ which are linearly dependent.
- But there is a set of 3 columns of $A$ which are linearly dependent. The first three columns are linearly dependent because $\begin{pmatrix}1\\1\\1\\1\end{pmatrix} - \frac{1}{2}\begin{pmatrix}2\\2\\2\\0\end{pmatrix} + \frac{1}{3}\begin{pmatrix}0\\0\\0\\-3\end{pmatrix} = \begin{pmatrix}0\\0\\0\\0\end{pmatrix}$.

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $n\geq m$, the following simple properties hold for the spark of a $m \times n$ matrix $A$:

- $\mathrm{spark}(A) = m+1 \Rightarrow \mathrm{rank}(A) = m$ (If the spark equals $m+1$, then the matrix has full rank.)
- $\mathrm{spark}(A) = 1$ if and only if the matrix has a zero column.
- $\mathrm{spark}(A) \le \mathrm{rank}(A) + 1$.[^o19]

:::

::: {#o13 .statement cue=named-heading name="Criterion for uniqueness of sparse solutions"}

## Criterion for uniqueness of sparse solutions {#Criterion_for_uniqueness_of_sparse_solutions}

The spark yields a simple criterion for uniqueness of sparse solutions of [linear equation systems](wikipedia://en/113087).[^o14] Given a linear equation system $A\mathbf{x}=\mathbf{b}$. If this system has a solution $\mathbf{x}$ that satisfies $\|\mathbf{x}\|_{0} < \frac{\mathrm{spark}(A)}{2}$, then this solution is the [sparsest](wikipedia://en/341015) possible solution. Here $\|\mathbf{x}\|_{0}$ denotes the number of nonzero entries of the vector $\mathbf{x}$.

:::

## Lower bound in terms of dictionary coherence {#Lower_bound_in_terms_of_dictionary_coherence}

If the columns of the matrix $A$ are normalized to unit [norm](wikipedia://en/990534), we can lower bound its spark in terms of its dictionary coherence:[^o16][^o6]

$$\mathrm{spark}(A) \ge 1+\frac{1}{\mu(A)}.$$

Here, the dictionary coherence $\mu(A)$ is defined as the maximum correlation between any two columns:

$$\mu(A)=\max_{m \neq n} |\langle a_m,a_n \rangle| = \max_{m\neq n}\frac{|a_m^{\intercal} a_n|}{||a_m||_2||a_n||_2}.$$

::: {#o18 .application cue=heading name="Applications"}

## Applications {#Applications}

The minimum distance of a [linear code](wikipedia://en/1866743) equals the spark of its [parity-check matrix](wikipedia://en/10557570).

The concept of the spark is also of use in the theory of [compressive sensing](https://en.wikipedia.org/wiki/Compressive_sensing), where requirements on the spark of the measurement matrix are used to ensure stability and consistency of various estimation techniques.[^o19] It is also known in [matroid theory](https://en.wikipedia.org/wiki/Matroid_theory) as the [girth](wikipedia://en/47482411) of the vector matroid associated with the columns of the matrix. The spark of a matrix is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) to compute.[^o20]
