# Population reconstruction

::: {#o1 .subject cue=lead name="Population reconstruction"}

**Population reconstruction** is a method used by [historical demographers](wikipedia://en/10817881). Using records, such as [church registries](https://en.wikipedia.org/wiki/Church_registry), the size and composition of families living in a given region in a given past time is determined. This allows the identification and analysis of patterns of family formation, fertility, mortality, and migration, and of consequent trends such as population growth.

:::
