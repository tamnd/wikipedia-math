# Cochrane–Orcutt estimation

::: {#o1 .subject cue=lead name="Cochrane–Orcutt estimation"}

**Cochrane–Orcutt estimation** is a procedure in [econometrics](wikipedia://en/10390), which adjusts a [linear model](wikipedia://en/17904) for [serial correlation](https://en.wikipedia.org/wiki/Serial_correlation) in the [error term](wikipedia://en/4229275). Developed in the 1940s, it is named after [statisticians](wikipedia://en/48661) [Donald Cochrane](https://en.wikipedia.org/wiki/Donald_Cochrane_%28economist%29) and [Guy Orcutt](https://en.wikipedia.org/wiki/Guy_Orcutt).[^o2]

:::

## Theory {#Theory}

Consider the model

$$y_t = \alpha + X_t \beta+\varepsilon_t,\,$$

where $y_{t}$ is the value of the [dependent variable](https://en.wikipedia.org/wiki/Dependent_variable) of interest at time *t*, $\beta$ is a column [vector](https://en.wikipedia.org/wiki/Vector_%28geometry%29) of coefficients to be estimated, $X_{t}$ is a row vector of [explanatory variables](https://en.wikipedia.org/wiki/Explanatory_variable) at time *t*, and $\varepsilon_t$ is the [error term](wikipedia://en/4229275) at time *t*.

If it is found, for instance via the [Durbin–Watson statistic](wikipedia://en/4864529), that the error term is [serially correlated](https://en.wikipedia.org/wiki/Serial_correlation) over time, then standard [statistical inference](wikipedia://en/27577) as normally applied to [regressions](wikipedia://en/1651906) is invalid because [standard errors](wikipedia://en/552520) are estimated with [bias](wikipedia://en/184099). To avoid this problem, the residuals must be modeled. If the process generating the residuals is found to be a [stationary](wikipedia://en/329898) first-order [autoregressive structure](wikipedia://en/1434444),[^o4] $\varepsilon_t =\rho \varepsilon_{t-1}+e_t,\ |\rho| <1$, with the errors {$e_t$} being [white noise](wikipedia://en/46182), then the Cochrane–Orcutt procedure can be used to transform the model by taking a quasi-difference:

$$y_t - \rho y_{t-1} = \alpha(1-\rho)+(X_t - \rho X_{t-1})\beta + e_t. \,$$

In this specification the error terms are white noise, so statistical inference is valid. Then the sum of squared residuals (the sum of squared estimates of $e_t^2$) is minimized with respect to $(\alpha,\beta)$, conditional on $\rho$.

### Inefficiency {#Inefficiency}

The transformation suggested by Cochrane and Orcutt disregards the first observation of a time series, causing a loss of [efficiency](wikipedia://en/27250866) that can be substantial in small samples.[^o6] A superior transformation, which retains the first observation with a weight of $\sqrt{(1-\rho^{2})}$ was first suggested by [Prais and Winsten](wikipedia://en/29526098),[^o7] and later independently by Kadiyala.[^o8]

## Estimating the autoregressive parameter {#Estimating_the_autoregressive_parameter}

If $\rho$ is not known, then it is estimated by first regressing the untransformed model and obtaining the residuals {$\hat{\varepsilon}_t$}, and regressing $\hat{\varepsilon}_t$ on $\hat{\varepsilon}_{t-1}$, leading to an estimate of $\rho$ and making the transformed regression sketched above feasible. (Note that one data point, the first, is lost in this regression.) This procedure of autoregressing estimated residuals can be done once and the resulting value of $\rho$ can be used in the transformed *y* regression, or the residuals of the residuals autoregression can themselves be autoregressed in consecutive steps until no substantial change in the estimated value of $\rho$ is observed.

The iterative Cochrane–Orcutt procedure might converge to a local but not [global minimum](https://en.wikipedia.org/wiki/Maxima_and_minima) of the residual sum of squares.[^o10][^o11][^o12] This problem disappears when using the [Prais–Winsten transformation](wikipedia://en/29526098) instead, which keeps the initial observation.[^o13]
