# Error term

::: {#o1 .subject cue=lead name="Error term"}

In [mathematics](wikipedia://en/18831) and [statistics](wikipedia://en/26685), an **error term** is an [additive](wikipedia://en/61338) type of [error](wikipedia://en/41118#Science_and_engineering). In [writing](https://en.wikipedia.org/wiki/Writing), an **error term** is an instance of faulty language or grammar. Common examples include:

:::

- [errors and residuals in statistics](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics), e.g. in [linear regression](wikipedia://en/48758386)
- the error term in [numerical integration](wikipedia://en/170089)
