# Project Jupyter

::: {#o2 .subject cue=lead name="Project Jupyter"}

**Project Jupyter** (pronounced "Jupiter") is a project to develop [open-source software](https://en.wikipedia.org/wiki/Open-source_software), [open standards](https://en.wikipedia.org/wiki/Open_standard), and services for [interactive computing](https://en.wikipedia.org/wiki/Interactive_computing) across multiple [programming languages](wikipedia://en/23015).

:::

It was spun off from [IPython](https://en.wikipedia.org/wiki/IPython) in 2014 by its Seven Founding Members: [Fernando Pérez](https://en.wikipedia.org/wiki/Fernando_Pérez_%28software_developer%29), Brian Granger, Damian Avila, Kyle Kelley, Matthias Bussonnier, Min Ragan-Kelley, and Thomas Kluyver.[^o3] Project Jupyter's name is a reference to the three core programming languages supported by Jupyter, which are [Julia](https://en.wikipedia.org/wiki/Julia_%28programming_language%29), [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29) and [R](wikipedia://en/376707). Its name and logo are an [homage](https://en.wikipedia.org/wiki/Homage_%28arts%29) to [Galileo](wikipedia://en/29688374)'s discovery of the [moons of Jupiter](https://en.wikipedia.org/wiki/Moons_of_Jupiter), as documented in notebooks attributed to Galileo.

Jupyter is financially sponsored by the Jupyter Foundation.[^o4]

## History {#History}

*Image: Galileo Galilei (1564 - 1642) - Serenissimo Principe - manuscript with observations of Jupiter and four of its moons, 1610.png.* A manuscript (incorrectly) ascribed to [Galileo Galilei](wikipedia://en/29688374)'s observations of Jupiter (⊛) and four of its moons (✱), which inspired the Jupyter logo

The first version of Notebooks for IPython was released in 2011 by a team including Fernando Pérez, Brian Granger, and Min Ragan-Kelley.[^o6] In 2014, Pérez announced a spin-off project from IPython called Project Jupyter.[^o7] IPython continues to exist as a Python [shell](https://en.wikipedia.org/wiki/Command-line_interface) and a kernel for Jupyter, while the [notebook](https://en.wikipedia.org/wiki/Notebook_interface) and other [language-agnostic](https://en.wikipedia.org/wiki/Language-agnostic) parts of IPython moved under the Jupyter name.[^o8][^o9] Jupyter supports execution environments (called "kernels") in several dozen languages, including Julia, R, [Haskell](https://en.wikipedia.org/wiki/Haskell), [Ruby](https://en.wikipedia.org/wiki/Ruby_%28programming_language%29), and Python (via the IPython kernel).

In 2015, about 200,000 Jupyter notebooks were available on [GitHub](https://en.wikipedia.org/wiki/GitHub). By 2018, about 2.5 million were available.[^o10] In January 2021, nearly 10 million were available, including notebooks about the [first observation of gravitational waves](https://en.wikipedia.org/wiki/First_observation_of_gravitational_waves)[^o11] and about the 2019 discovery of a [supermassive black hole](https://en.wikipedia.org/wiki/Supermassive_black_hole).[^o19]

Major [cloud computing](https://en.wikipedia.org/wiki/Cloud_computing) providers have adopted the Jupyter Notebook or derivative tools as a frontend interface for cloud users. Examples include [Amazon SageMaker](https://en.wikipedia.org/wiki/Amazon_SageMaker) Notebooks,[^o12] [Google](https://en.wikipedia.org/wiki/Google)'s Colab,[^o13][^o14] and [Microsoft](https://en.wikipedia.org/wiki/Microsoft)'s Azure Notebook.[^o15]

[Visual Studio Code](https://en.wikipedia.org/wiki/Visual_Studio_Code) supports local development of Jupyter notebooks. As of July 2022, the Jupyter extension for VS Code has been downloaded over 40 million times, making it the second-most popular extension in the VS Code Marketplace.[^o16]

Members of the Project Jupyter steering committee — [Fernando Pérez](https://en.wikipedia.org/wiki/Fernando_Pérez_%28software_developer%29), [Brian E. Granger](https://en.wikipedia.org/wiki/Brian_E._Granger), [Min Ragan-Kelley](https://en.wikipedia.org/wiki/Min_Ragan-Kelley_%28software_developer%29), Paul Ivanov, Thomas Kluyver, Jason Grout, Matthias Bussonnier, Damián Avila, Steven Silvester, Jonathan Frederic, [Kyle Kelley](https://en.wikipedia.org/wiki/Kyle_Kelley_%28software_developer%29), Jessica Hamrick, Carol Willing, [Sylvain Corlay](https://en.wikipedia.org/wiki/Sylvain_Corlay), and Peter Parente — received the 2017 [ACM Software System Award](https://en.wikipedia.org/wiki/ACM_Software_System_Award), an annual award that honors people or an organization "for developing a software system that has had a lasting influence, reflected in contributions to concepts, in commercial acceptance, or both".[^o17]

*[The Atlantic](https://en.wikipedia.org/wiki/The_Atlantic)* published an article entitled "The Scientific Paper Is Obsolete" in 2018, discussing the role of Jupyter Notebook and the [Mathematica](wikipedia://en/49024) notebook in the future of scientific publishing.[^o25] Economist [Paul Romer](https://en.wikipedia.org/wiki/Paul_Romer), in response, published a blog post in which he reflected on his experiences using Mathematica and Jupyter for research, concluding in part that Jupyter "does a better job of delivering what [Theodore Gray](https://en.wikipedia.org/wiki/Theodore_Gray) had in mind when he designed the Mathematica notebook."[^o18]

In 2021, *[Nature](https://en.wikipedia.org/wiki/Nature_%28journal%29)* named Jupyter as one of ten computing projects that transformed science.[^o19]

## Jupyter Notebook {#Jupyter_Notebook}

Jupyter Notebook can colloquially refer to two different concepts, either the user-facing application to edit code and text, or the underlying file format which is interoperable across many implementations.

::: {#o24 .application cue=heading name="Applications"}

### Applications {#Applications}

Jupyter Notebook (formerly IPython Notebook) is a [web-based interactive](https://en.wikipedia.org/wiki/Web_application) computational environment for creating [notebook](https://en.wikipedia.org/wiki/Notebook_interface) documents. Jupyter Notebook is built using several [open-source](https://en.wikipedia.org/wiki/Open-source_software) libraries, including [IPython](https://en.wikipedia.org/wiki/IPython), [ZeroMQ](https://en.wikipedia.org/wiki/ZeroMQ), [Tornado](https://en.wikipedia.org/wiki/Tornado_%28web_server%29), [jQuery](https://en.wikipedia.org/wiki/JQuery), [Bootstrap](https://en.wikipedia.org/wiki/Bootstrap_%28front-end_framework%29), and [MathJax](https://en.wikipedia.org/wiki/MathJax). A Jupyter Notebook application is a browser-based [REPL](https://en.wikipedia.org/wiki/Read–eval–print_loop) containing an ordered list of input/output cells which can contain code, text (using GitHub Flavored [Markdown](https://en.wikipedia.org/wiki/Markdown)), mathematics, [plots](wikipedia://en/19774918) and [rich media](https://en.wikipedia.org/wiki/Interactive_media).

Jupyter Notebook is similar to the notebook interface of other programs such as [Maple](https://en.wikipedia.org/wiki/Maple_%28software%29), [Mathematica](wikipedia://en/49024), and [SageMath](https://en.wikipedia.org/wiki/SageMath), a computational interface style that originated with Mathematica in the 1980s. Jupyter interest overtook the popularity of the Mathematica notebook interface in early 2018.[^o25]

JupyterLab is a newer user interface for Project Jupyter, offering a flexible user interface and more features than the classic notebook UI. The first stable release was announced on February 20, 2018.[^o26][^o27] In 2015, a joint \$6 million grant from [The Leona M. and Harry B. Helmsley Charitable Trust](https://en.wikipedia.org/wiki/The_Leona_M._and_Harry_B._Helmsley_Charitable_Trust), [The Gordon and Betty Moore Foundation](https://en.wikipedia.org/wiki/Gordon_and_Betty_Moore_Foundation), and [The Alfred P. Sloan Foundation](https://en.wikipedia.org/wiki/Alfred_P._Sloan_Foundation) funded work that led to expanded capabilities of the core Jupyter tools, as well as to the creation of JupyterLab.[^o28]

GitHub announced in November 2022 that JupyterLab would be available in its online Coding platform called Codespace.[^o29]

In August 2023, Jupyter AI, a Jupyter extension, was released. This extension incorporates [generative AI](https://en.wikipedia.org/wiki/Generative_AI) into Jupyter notebooks, enabling users to explain and generate code, rectify errors, summarize content, inquire about their local files, and generate complete notebooks based on natural language prompts.[^o30]

JupyterHub is a multi-user server for Jupyter Notebooks. It is designed to support many users by spawning, managing, and proxying many singular Jupyter Notebook servers.[^o31]

:::

::: {#o33 .pointer-item cue=pointer name=".ipynb"}

### Documents {#Documents}

A Jupyter Notebook document is a [JSON](https://en.wikipedia.org/wiki/JSON) file, following a versioned schema, usually ending with the ".ipynb" extension. The main parts of the Jupyter Notebooks are: Metadata, Notebook format and list of cells. Metadata is a data Dictionary of definitions to set up and display the notebook. Notebook Format is a version number of the software. List of cells are different types of Cells for Markdown (display), Code (to execute), and output of the code type cells.[^o34]

While JSON is the most common format, it is possible to forgo some features (like storing images and metadata), and save notebooks as markdown documents using extensions like Jupytext.[^o35] Jupytext is often used in conjunction with version control to make diffing and merging of notebooks simpler.
