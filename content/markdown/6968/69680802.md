# Recursive largest first algorithm

::: {#o1 .subject cue=lead name="Recursive largest first algorithm"}

The **Recursive Largest First** (**RLF**) algorithm is a [heuristic](https://en.wikipedia.org/wiki/Heuristic) for the [NP-hard](https://en.wikipedia.org/wiki/NP-hard) [graph coloring problem](https://en.wikipedia.org/wiki/Graph_coloring_problem). It was originally proposed by Frank Leighton in 1979.[^o2]

:::

The RLF algorithm assigns colors to a graph’s vertices by constructing each color class one at a time. It does this by identifying a [maximal independent set](wikipedia://en/1793590) of vertices in the graph, assigning these to the same color, and then removing these vertices from the graph. These actions are repeated on the remaining subgraph until no vertices remain.

To form high-quality solutions (solutions using few colors), the RLF algorithm uses specialized heuristic rules to try to identify "good quality" independent sets. These heuristics make the RLF algorithm exact for [bipartite](wikipedia://en/244431), [cycle](wikipedia://en/878962), and [wheel graphs](wikipedia://en/1655876).[^o3] In general, however, the algorithm is approximate and may well return solutions that use more colors than the graph’s [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number).

## Description {#Description}

The algorithm can be described by the following three steps. At the end of this process, $\mathcal{S}$ gives a partition of the vertices representing a feasible $|\mathcal{S}|$-colouring of the graph $G$.

1. Let $\mathcal{S}=\emptyset$ be an empty solution. Also, let $G=(V,E)$ be the graph we wish to color, comprising a vertex set $V$ and an edge set $E$.
1. Identify a [maximal independent set](wikipedia://en/1793590) $S\subseteq V$. To do this:
   1. The first vertex added to $S$ should be the vertex in $G$ that has the largest number of neighbors.
   1. Subsequent vertices added to $S$ should be chosen as those that (a) are not currently adjacent to any vertex in $S$, and (b) have a maximal number of neighbors that are adjacent to vertices in $S$. Ties in condition (b) can be broken by selecting the vertex with the minimum number of neighbors not in $S$. Vertices are added to $S$ in this way until it is impossible to add further vertices.
1. Now set $\mathcal{S}=\mathcal{S}\cup \{S\}$ and remove the vertices of $S$ from $G$. If $G$ still contains vertices, then return to Step 2; otherwise end.

1. Vertex $g$ (color 1)
1. Vertex $a$, $c$, and then $e$ (color 2)

## Performance {#Performance}

Let $n$ be the number of vertices in the graph and let $m$ be the number of edges. Using [big O notation](wikipedia://en/44578), in his original publication Leighton states the complexity of RLF to be $\mathcal{O}(n^3)$; however, this can be improved upon. Much of the expense of this algorithm is due to Step 2, where vertex selection is made according to the heuristic rules stated above. Indeed, each time a vertex is selected for addition to the independent set $S$, information regarding the neighbors needs to be recalculated for each uncolored vertex. These calculations can be performed in $\mathcal{O}(m)$ time, meaning that the overall complexity of RLF is $\mathcal{O}(mn)$.[^o3]

If the heuristics of Step 2 are replaced with random selection, then the complexity of this algorithm reduces to $\mathcal{O}(n+m)$; however, the resultant algorithm will usually return lower quality solutions compared to those of RLF.[^o3] It will also now be inexact for [bipartite](wikipedia://en/244431), [cycle](wikipedia://en/878962), and [wheel graphs](wikipedia://en/1655876).

In an empirical comparison by Lewis in 2021, RLF was shown to produce significantly better vertex colorings than alternative heuristics such as the $\mathcal{O}(n+m)$ [greedy algorithm](wikipedia://en/21051195) and the $\mathcal{O}((n + m) \lg n)$ [DSatur](wikipedia://en/59742671) algorithm on [random graphs](wikipedia://en/358477). However, runtimes with RLF were also seen to be higher than these alternatives due to its higher overall complexity.[^o3]
