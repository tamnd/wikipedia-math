# Artstein's theorem

::: {#o1 .subject cue=lead name="Artstein's theorem"}

**Artstein's theorem** states that a [nonlinear dynamical system](wikipedia://en/146103#Nonlinear_differential_equations) in the control-affine form

:::

$$\dot{\mathbf{x}} = \mathbf{f(x)} + \sum_{i=1}^m \mathbf{g}_i(\mathbf{x})u_i$$

has a differentiable [control-Lyapunov function](wikipedia://en/6172616) if and only if it admits a regular stabilizing feedback *u*(*x*), that is a [locally Lipschitz](https://en.wikipedia.org/wiki/Locally_Lipschitz) function on **R**<sup>n</sup>\\{0}.[^o2]

The original 1983 proof by [Zvi Artstein](https://en.wikipedia.org/wiki/Zvi_Artstein) proceeds by a nonconstructive argument. In 1989 [Eduardo D. Sontag](https://en.wikipedia.org/wiki/Eduardo_D._Sontag) provided a constructive version of this theorem explicitly exhibiting the feedback.[^o3][^o4]
