# Constructive nonstandard analysis

::: {#o1 .subject cue=lead name="Constructive nonstandard analysis"}

In mathematics, **constructive nonstandard analysis** is a version of [Abraham Robinson](wikipedia://en/46024)'s [nonstandard analysis](wikipedia://en/21708), developed by [Moerdijk](wikipedia://en/25499812) (1995), Palmgren (1998), Ruokolainen (2004). Ruokolainen wrote:

:::

The possibility of [constructivization](https://en.wikipedia.org/wiki/Constructive_mathematics) of nonstandard analysis was studied by Palmgren (1997, 1998, 2001). The model of constructive nonstandard analysis studied there is an extension of Moerdijk’s (1995) model for constructive nonstandard arithmetic.
