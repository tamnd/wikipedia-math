# Partially ordered space

::: {#o1 .subject cue=lead name="Partially ordered space"}

In mathematics, a **partially ordered space**[^o2] (or **pospace**) is a [topological space](wikipedia://en/30450) $X$ equipped with a closed [partial order](https://en.wikipedia.org/wiki/Partial_order) $\leq$, i.e. a partial order whose graph $\{(x, y) \in X^2 \mid x \leq y\}$ is a closed subset of $X^2$.

:::

From pospaces, one can define **dimaps**, i.e. [continuous maps](https://en.wikipedia.org/wiki/Continuous_map) between pospaces which preserve the order relation.

## Equivalences {#Equivalences}

For a topological space $X$ equipped with a partial order $\leq$, the following are equivalent:

- $X$ is a partially ordered space.
- For all $x,y\in X$ with $x \not\leq y$, there are open sets $U,V\subset X$ with $x\in U, y\in V$ and $u \not\leq v$ for all $u\in U, v\in V$.
- For all $x,y\in X$ with $x \not\leq y$, there are disjoint neighbourhoods $U$ of $x$ and $V$ of $y$ such that $U$ is an [upper set](https://en.wikipedia.org/wiki/Upper_set) and $V$ is a lower set.

The [order topology](wikipedia://en/213650) is a special case of this definition, since a [total order](wikipedia://en/30330) is also a partial order.

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every pospace is a [Hausdorff space](wikipedia://en/13637). If we take equality $=$ as the partial order, this definition becomes the definition of a Hausdorff space.

Since the graph is closed, if $\left( x_{\alpha} \right)_{\alpha \in A}$ and $\left( y_{\alpha} \right)_{\alpha \in A}$ are [nets](wikipedia://en/22170) converging to *x* and *y*, respectively, such that $x_{\alpha} \leq y_{\alpha}$ for all $\alpha$, then $x \leq y$.

:::
