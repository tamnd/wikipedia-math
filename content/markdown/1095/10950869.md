# Orthonormal function system

::: {#o1 .subject cue=lead name="Orthonormal function system"}

An **orthonormal function system (ONS)** is an [orthonormal](https://en.wikipedia.org/wiki/Orthonormal) [basis](wikipedia://en/18420) in a [vector space](wikipedia://en/32370) of [functions](wikipedia://en/185427).[^o2]

:::
