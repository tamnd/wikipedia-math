# Silver's dichotomy

::: {#o1 .subject cue=lead name="Silver's dichotomy"}

In [descriptive set theory](wikipedia://en/396619), a branch of [mathematics](wikipedia://en/18831), **Silver's dichotomy** (also known as **Silver's theorem**)[^o2] is a statement about [equivalence relations](wikipedia://en/9260), named after [Jack Silver](wikipedia://en/21626512).[^o3][^o4]

:::

## Statement and history {#Statement_and_history}

A relation is said to be [coanalytic](wikipedia://en/4214995) if its complement is an [analytic](wikipedia://en/634261) set. Silver's dichotomy is a statement about the equivalence classes of a coanalytic equivalence relation, stating any coanalytic equivalence relation either has [countably](https://en.wikipedia.org/wiki/Countable) many equivalence classes, or else there is a [perfect set](wikipedia://en/5075551) of reals that are each incomparable to each other.[^o6] In the latter case, there must be continuum many equivalence classes of the relation.[^o3]

The first published proof of Silver's dichotomy was by Jack Silver, appearing in 1980 in order to answer a question posed by [Harvey Friedman](wikipedia://en/3038108).[^o7] One application of Silver's dichotomy appearing in recursive set theory is since equality restricted to a set $X$ is coanalytic, there is no Borel equivalence relation $R$ such that $(=\upharpoonright\aleph_0)\leq_B R\leq_B (=\upharpoonright 2^{\aleph_0})$, where $\leq_B$ denotes [Borel equivalence relation](https://en.wikipedia.org/wiki/Borel-reducibility). Some later results motivated by Silver's dichotomy founded a new field known as invariant descriptive set theory, which studies definable equivalence relations. Silver's dichotomy also admits several weaker recursive versions, which have been compared in strength with subsystems of second-order arithmetic from [reverse mathematics](wikipedia://en/326365),[^o3] while Silver's dichotomy itself is provably equivalent to $\Pi_1^1\mathsf{-CA}_0$ over $\mathsf{RCA}_0$.[^o2]
