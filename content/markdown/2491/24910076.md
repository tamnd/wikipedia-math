# Bernstein set

::: {#o1 .subject cue=lead name="Bernstein set"}

In mathematics, a **Bernstein set** is a subset of the [real line](https://en.wikipedia.org/wiki/Real_line) that meets every uncountable [closed subset](https://en.wikipedia.org/wiki/Closed_subset) of the real line but that contains none of them.[^o2]

:::

A Bernstein set [partitions the real line](wikipedia://en/340240) into two pieces in a peculiar way: every [measurable](wikipedia://en/18198) set of positive measure meets both the Bernstein set and its [complement](wikipedia://en/54347), as does every set with the [property of Baire](wikipedia://en/2213768) that is not a [meagre set](wikipedia://en/226975).[^o3]
