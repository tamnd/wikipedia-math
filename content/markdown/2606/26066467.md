# Kish grid

::: {#o1 .subject cue=lead name="Kish grid"}

The **Kish grid** or **Kish selection grid** is a method for selecting members within a [household](https://en.wikipedia.org/wiki/Household) to be [interviewed](https://en.wikipedia.org/wiki/Interview). It uses a pre-assigned table of random numbers to find the person to be interviewed. It was developed by statistician [Leslie Kish](wikipedia://en/4307591) in 1949.[^o2]

:::

It is a technique widely used in [survey research](https://en.wikipedia.org/wiki/Survey_research).[^o3]
