# Hasse–Arf theorem

::: {#o1 .subject cue=lead name="Hasse–Arf theorem"}

In [mathematics](wikipedia://en/18831), specifically in [local class field theory](wikipedia://en/669532), the **Hasse–Arf theorem** is a result concerning jumps of the [upper numbering](https://en.wikipedia.org/wiki/Upper_numbering) filtration of the [Galois group](wikipedia://en/12673) of a finite [Galois extension](wikipedia://en/457064). A special case of it when the residue fields are finite was originally proved by [Helmut Hasse](wikipedia://en/727118),[^o2][^o3] and the general result was proved by [Cahit Arf](https://en.wikipedia.org/wiki/Cahit_Arf).[^o4][^o14]

:::

::: {#o6 .statement cue=heading name="Statement"}

## Statement {#Statement}

::: {#o8 .pointer-item cue=pointer name="Higher ramification groups"}

### Higher ramification groups {#Higher_ramification_groups}

The theorem deals with the upper numbered higher ramification groups of a finite [abelian extension](wikipedia://en/174448) $L/K$. So assume $L/K$ is a finite Galois extension, and that $v_K$ is a [discrete normalised valuation](https://en.wikipedia.org/wiki/Discrete_valuation) of *K*, whose [residue field](wikipedia://en/10789680) has characteristic *p* > 0, and which admits a unique extension to *L*, say *w*. Denote by $v_L$ the associated normalised valuation *ew* of *L* and let $\scriptstyle{\mathcal{O}}$ be the [valuation ring](wikipedia://en/966856) of *L* under $v_L$. Let $L/K$ have [Galois group](wikipedia://en/12673) *G* and define the *s*-th ramification group of $L/K$ for any real *s* ≥ −1 by

$$G_s(L/K)=\{\sigma\in G\,:\,v_L(\sigma a-a)\geq s+1 \text{ for all }a\in\mathcal{O}\}.$$

So, for example, *G*<sub>−1</sub> is the Galois group *G*. To pass to the upper numbering one has to define the function *ψ*<sub>*L*/*K*</sub> which in turn is the inverse of the function *η*<sub>*L*/*K*</sub> defined by

$$\eta_{L/K}(s)=\int_0^s \frac{dx}{|G_0:G_x|}.$$

The upper numbering of the [ramification groups](wikipedia://en/501614) is then defined by *G*<sup>*t*</sup>(*L*/*K*) = *G*<sub>*s*</sub>(*L*/*K*) where *s* = *ψ*<sub>*L*/*K*</sub>(*t*).

These higher ramification groups *G*<sup>*t*</sup>(*L*/*K*) are defined for any real *t* ≥ −1, but since *v*<sub>*L*</sub> is a discrete valuation, the groups will change in discrete jumps and not continuously. Thus we say that *t* is a jump of the filtration {*G*<sup>*t*</sup>(*L*/*K*) : *t* ≥ −1} if *G*<sup>*t*</sup>(*L*/*K*) ≠ *G*<sup>*u*</sup>(*L*/*K*) for any *u* > *t*. The Hasse–Arf theorem tells us the arithmetic nature of these jumps.

:::

::: {#o10 .statement cue=heading name="Statement of the theorem"}

### Statement of the theorem {#Statement_of_the_theorem}

With the above set up of an abelian extension *L*/*K*, the theorem states that the jumps of the filtration {*G*<sup>*t*</sup>(*L*/*K*) : *t* ≥ −1} are all [rational integers](wikipedia://en/14563).[^o14][^o11]

:::

:::

::: {#o13 .example cue=heading name="Example"}

## Example {#Example}

Suppose *G* is cyclic of order $p^n$, $p$ residue characteristic and $G(i)$ be the subgroup of $G$ of order $p^{n-i}$. The theorem says that there exist positive integers $i_0, i_1, ..., i_{n-1}$ such that

$$G_0 = \cdots = G_{i_0} = G = G^0 = \cdots = G^{i_0}$$

$$G_{i_0 + 1} = \cdots = G_{i_0 + p i_1} = G(1) = G^{i_0 + 1} = \cdots = G^{i_0 + i_1}$$

$$G_{i_0 + p i_1 + 1} = \cdots = G_{i_0 + p i_1 + p^2 i_2} = G(2) = G^{i_0 + i_1 + 1}$$

...

$G_{i_0 + p i_1 + \cdots + p^{n-1}i_{n-1} + 1} = 1 = G^{i_0 + \cdots + i_{n-1} + 1}.$[^o14]

:::

## Non-abelian extensions {#Non-abelian_extensions}

For non-abelian extensions the jumps in the upper filtration need not be at integers. [Jean-Pierre Serre](wikipedia://en/205483) gave an example of a totally ramified extension with Galois group the [quaternion](wikipedia://en/51440) group $Q_8$ of order 8 with

- $$G_0 = Q_8$$
- $$G_1 = Q_8$$
- $$G_2 = \mathbb{Z}/2\mathbb{Z}$$
- $$G_3 = \mathbb{Z}/2\mathbb{Z}$$
- $$G_4 = 1$$

The upper numbering then satisfies

- $G^n = Q_8$ for $n \leq 1$
- $G^n = \mathbb{Z}/2\mathbb{Z}$ for $1 < n\leq 3/2$
- $G^n = 1$ for $3/2 < n$

so has a jump at the non-integral value $n=3/2$.
