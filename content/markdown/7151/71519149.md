# Metric lattice

::: {#o1 .subject cue=lead name="Metric lattice"}

*Image: Metric lattice cube135.svg.* Example valuation function on the cube lattice which makes it a metric lattice.

In the mathematical [study of order](wikipedia://en/361924), a **metric lattice** $L$ is a [lattice](wikipedia://en/469304) that admits a positive **valuation**: a function $v \in L \to R$ satisfying, for any $a, b \in L$,[^o2]

$$v(a)+v(b)=v(a\wedge b)+v(a\vee b)$$

and

$${a>b}\Rightarrow v(a)>v(b)\text{.}$$

:::

## Relation to other notions {#Relation_to_other_notions}

*Image: N5 abcde.svg.* A lattice containing [N5](wikipedia://en/1089311#Examples) (depicted) cannot be a metric one, since *v*(*d*)+*v*(*c*) = *v*(*e*)+*v*(*a*) = *v*(*b*)+*v*(*c*) implies *v*(*d*) = *v*(*b*), contradicting *v*(*d*) \< *v*(*b*).

A [Boolean algebra](wikipedia://en/54476844) is a metric lattice; any [finitely-additive measure](wikipedia://en/9999200) on its [Stone dual](wikipedia://en/604111) gives a valuation.[^o4]

Every metric lattice is a [modular lattice](wikipedia://en/1089311),[^o2] c.f. lower picture. It is also a [metric space](wikipedia://en/20018), with distance function given by[^o7]

$$d(x,y)=v(x\vee y)-v(x\wedge y)\text{.}$$

With that metric, the [join and meet](wikipedia://en/3956618) are [uniformly continuous](https://en.wikipedia.org/wiki/Uniformly_continuous) [contractions](wikipedia://en/6239),[^o4] and so extend to the metric [completion (metric space)](https://en.wikipedia.org/wiki/Completion_%28metric_space%29). That lattice is usually not the [Dedekind-MacNeille completion](https://en.wikipedia.org/wiki/Dedekind-MacNeille_completion), but it is [conditionally complete](https://en.wikipedia.org/wiki/Conditionally_complete_lattice).[^o4]

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

In the study of [fuzzy logic](wikipedia://en/49180) and [interval arithmetic](wikipedia://en/2176160), the space of [uniform distributions](wikipedia://en/1699223) is a metric lattice.[^o7] Metric lattices are also key to von Neumann's construction of the [continuous projective geometry](wikipedia://en/32590824).[^o4] A function satisfies the one-dimensional [wave equation](wikipedia://en/33691) if and only if it is a valuation for the lattice of spacetime coordinates with the natural partial order. A similar result should apply to any [partial differential equation](wikipedia://en/52564) solvable by the [method of characteristics](wikipedia://en/751933), but key features of the theory are lacking.[^o4]

:::
