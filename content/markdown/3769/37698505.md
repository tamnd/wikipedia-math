# Surjunctive group

::: {#o1 .subject cue=lead name="Surjunctive group"}

::: {#o2 .problem cue=unsolved}

Is every group surjunctive?

:::

In mathematics, a **surjunctive group** is a [group](wikipedia://en/19447) such that every [injective](wikipedia://en/45196) [cellular automaton](wikipedia://en/54342) with the group elements as its cells is also [surjective](wikipedia://en/27873). Surjunctive groups were introduced by (Gottschalk 1973). It is unknown whether every group is surjunctive.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [cellular automaton](wikipedia://en/54342) consists of a regular system of cells, each containing a symbol from a finite [alphabet](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29), together with a uniform rule called a *transition function* for updating all cells simultaneously based on the values of neighboring cells. Most commonly the cells are arranged in the form of a line or a higher-dimensional [integer grid](wikipedia://en/3333402), but other arrangements of cells are also possible. What is required of the cells is that they form a structure in which every cell "looks the same as" every other cell: there is a [symmetry](wikipedia://en/53741) of both the arrangement of cells and the rule set that takes any cell to any other cell. Mathematically, this can be formalized by the notion of a [group](wikipedia://en/19447), a set of elements together with an associative and invertible binary operation. The elements of the group can be used as the cells of an automaton, with symmetries generated by the group operation. For instance, a one-dimensional line of cells can be described in this way as the additive group of the [integers](wikipedia://en/14563), and the higher-dimensional integer grids can be described as the [free abelian groups](wikipedia://en/247296).

The collection of all possible states of a cellular automaton over a group can be described as the functions that map each group element to one of the symbols in the alphabet. As a finite set, the alphabet has a [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology), and the collection of states can be given the [product topology](wikipedia://en/24910) (called a [prodiscrete topology](https://en.wikipedia.org/wiki/Prodiscrete_topology) because it is the product of discrete topologies). To be the transition function of a cellular automaton, a function from states to states must be a [continuous function](wikipedia://en/6122) for this topology, and must also be [equivariant](https://en.wikipedia.org/wiki/Equivariant) with the group action, meaning that shifting the cells prior to applying the transition function produces the same result as applying the function and then shifting the cells. For such functions, the [Curtis–Hedlund–Lyndon theorem](wikipedia://en/18903091) ensures that the value of the transition function at each group element depends on the previous state of only a finite set of neighboring elements.

A state transition function is a [surjective function](wikipedia://en/27873) when every state has a predecessor (there can be no [Garden of Eden](wikipedia://en/1144206)). It is an [injective function](wikipedia://en/45196) when no two states have the same successor. A surjunctive group is a group with the property that, when its elements are used as the cells of cellular automata, every injective transition function of a cellular automaton is also surjective. Equivalently, summarizing the definitions above, a group $G$ is surjunctive if, for every finite set $S$, every continuous equivariant injective function $f:S^G \to S^G$ is also surjective.[^o6] The implication from injectivity to surjectivity is a form of the [Garden of Eden theorem](wikipedia://en/1144206), and the cellular automata defined from injective and surjective transition functions are [reversible](wikipedia://en/30766907).

:::

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of surjunctive groups include all locally [residually finite groups](wikipedia://en/5780875),[^o9] all [free groups](wikipedia://en/59735),[^o9] all subgroups of surjunctive groups,[^o10] all abelian groups,[^o9] all [sofic groups](wikipedia://en/37690209),[^o11] and every locally surjunctive group.[^o10]

When he introduced surjunctive groups in 1973, Gottschalk observed that there were no known examples of non-surjunctive groups. As of 2014, it is still unknown whether every group is surjunctive.[^n1]
