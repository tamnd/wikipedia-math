# Random indexing

::: {#o1 .subject cue=lead name="Random indexing"}

**Random indexing** is a [dimensionality reduction](wikipedia://en/579867) method and computational framework for [distributional semantics](https://en.wikipedia.org/wiki/Distributional_semantics), based on the insight that very-high-dimensional [vector space model](wikipedia://en/20948989) implementations are impractical, that models need not grow in dimensionality when new items (e.g. new terminology) are encountered, and that a high-dimensional model can be projected into a space of lower dimensionality without compromising L2 distance metrics if the resulting dimensions are chosen appropriately.

:::

This is the original point of the [random projection](wikipedia://en/43932548) approach to dimension reduction first formulated as the [Johnson–Lindenstrauss lemma](wikipedia://en/14855952), and [locality-sensitive hashing](https://en.wikipedia.org/wiki/Locality-sensitive_hashing) has some of the same starting points. Random indexing, as used in representation of language, originates from the work of [Pentti Kanerva](https://en.wikipedia.org/wiki/Pentti_Kanerva)[^o2][^o3][^o4][^o5][^o6] on [sparse distributed memory](https://en.wikipedia.org/wiki/Sparse_distributed_memory), and can be described as an incremental formulation of a random projection.[^o7]

It can be also verified that random indexing is a random projection technique for the construction of Euclidean spaces—i.e. L2 normed vector spaces.[^o8] In Euclidean spaces, random projections are elucidated using the Johnson–Lindenstrauss lemma.[^o9]

The TopSig technique[^o10] extends the random indexing model to produce [bit vectors](https://en.wikipedia.org/wiki/Bit_vector) for comparison with the [Hamming distance](wikipedia://en/41227) similarity function. It is used for improving the performance of [information retrieval](https://en.wikipedia.org/wiki/Information_retrieval) and [document clustering](https://en.wikipedia.org/wiki/Document_clustering). In a similar line of research, Random Manhattan Integer Indexing (RMII)[^o11] is proposed for improving the performance of the methods that employ the [Manhattan distance](https://en.wikipedia.org/wiki/Manhattan_distance) between text units. Many random indexing methods primarily generate similarity from co-occurrence of items in a corpus. Reflexive Random Indexing (RRI)[^o12] generates similarity from co-occurrence and from shared occurrence with other items.
