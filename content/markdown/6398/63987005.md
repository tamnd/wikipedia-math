# Topological homomorphism

::: {#o1 .subject cue=lead name="Topological homomorphism"}

In [functional analysis](wikipedia://en/11180), a **topological homomorphism** or simply **homomorphism** (if no confusion will arise) is the analog of [homomorphisms](wikipedia://en/13564) for the category of [topological vector spaces](wikipedia://en/45752) (TVSs). This concept is of considerable importance in functional analysis and the famous [open mapping theorem](wikipedia://en/17395276) gives a sufficient condition for a continuous linear map between [Fréchet spaces](wikipedia://en/233801) to be a topological homomorphism.

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A **topological homomorphism** or simply **homomorphism** (if no confusion will arise) is a [continuous](https://en.wikipedia.org/wiki/Continuous_map) [linear map](wikipedia://en/18102) $u : X \to Y$ between [topological vector spaces](wikipedia://en/45752) (TVSs) such that the induced map $u : X \to \operatorname{Im} u$ is an [open mapping](https://en.wikipedia.org/wiki/Open_mapping) when $\operatorname{Im} u := u(X),$ which is the [image](wikipedia://en/579311) of $u,$ is given the [subspace topology](wikipedia://en/910926) induced by $Y.$[^n1] This concept is of considerable importance in functional analysis and the famous [open mapping theorem](wikipedia://en/17395276) gives a sufficient condition for a continuous linear map between [Fréchet spaces](wikipedia://en/233801) to be a topological homomorphism.

A **TVS embedding** or a **topological [monomorphism](wikipedia://en/59538)**[^n2] is an [injective](https://en.wikipedia.org/wiki/Injective_map) topological homomorphism. Equivalently, a TVS-embedding is a linear map that is also a [topological embedding](https://en.wikipedia.org/wiki/Topological_embedding).

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

Suppose that $u : X \to Y$ is a linear map between TVSs and note that $u$ can be decomposed into the composition of the following canonical linear maps:

$$X ~\overset{\pi}{\rightarrow}~ X / \operatorname{ker} u ~\overset{u_0}{\rightarrow}~ \operatorname{Im} u ~\overset{\operatorname{In}}{\rightarrow}~ Y$$

where $\pi : X \to X / \operatorname{ker} u$ is the canonical [quotient map](https://en.wikipedia.org/wiki/Quotient_map) and $\operatorname{In} : \operatorname{Im} u \to Y$ is the [inclusion map](wikipedia://en/492516).

The following are equivalent:

1. $u$ is a topological homomorphism
1. for every neighborhood base $\mathcal{U}$ of the origin in $X,$ $u\left( \mathcal{U} \right)$ is a neighborhood base of the origin in $Y$[^n1]
1. the induced map $u_0 : X / \operatorname{ker} u \to \operatorname{Im} u$ is an isomorphism of TVSs[^n1]

If in addition the range of $u$ is a finite-dimensional Hausdorff space then the following are equivalent:

1. $u$ is a topological homomorphism
1. $u$ is continuous[^n1]
1. $u$ is continuous at the origin[^n1]
1. $u^{-1}(0)$ is closed in $X$[^n1]

:::

## Sufficient conditions {#Sufficient_conditions}

::: {#o15 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n1].**

Let $u : X \to Y$ be a surjective continuous linear map from an [LF-space](wikipedia://en/2314852) $X$ into a TVS $Y.$ If $Y$ is also an [LF-space](wikipedia://en/2314852) or if $Y$ is a [Fréchet space](wikipedia://en/233801) then $u : X \to Y$ is a topological homomorphism.

:::

::: {#o17 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n3].**

Suppose $f : X \to Y$ be a continuous linear operator between two Hausdorff TVSs. If $M$ is a dense vector subspace of $X$ and if the restriction $f\big\vert_M : M \to Y$ to $M$ is a topological homomorphism then $f : X \to Y$ is also a topological homomorphism.[^n3]

So if $C$ and $D$ are Hausdorff completions of $X$ and $Y,$ respectively, and if $f : X \to Y$ is a topological homomorphism, then $f$'s unique continuous linear extension $F : C \to D$ is a topological homomorphism. (However, it is possible for $f : X \to Y$ to be surjective but for $F : C \to D$ to not be injective.)

:::

::: {#o20 .statement kind=statement/theorem cue=named-heading name="Open mapping theorem"}

### Open mapping theorem {#Open_mapping_theorem}

The [open mapping theorem](wikipedia://en/17395276), also known as [Banach](wikipedia://en/29646)'s homomorphism theorem, gives a sufficient condition for a continuous linear operator between complete metrizable TVSs to be a topological homomorphism.

::: {#o22 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n4].**

Let $u : X \to Y$ be a continuous linear map between two complete metrizable TVSs. If $\operatorname{Im} u,$ which is the range of $u,$ is a dense subset of $Y$ then either $\operatorname{Im} u$ is [meager](https://en.wikipedia.org/wiki/Meager_set) (that is, [of the first category](wikipedia://en/226975)) in $Y$ or else $u : X \to Y$ is a surjective topological homomorphism. In particular, $u : X \to Y$ is a topological homomorphism if and only if $\operatorname{Im} u$ is a closed subset of $Y.$

:::

::: {#o24 .statement kind=statement/corollary cue=math-theorem name="Corollary"}

**Corollary[^n4].**

Let $\sigma$ and $\tau$ be TVS topologies on a vector space $X$ such that each topology makes $X$ into a [complete metrizable TVSs](wikipedia://en/200440). If either $\sigma \subseteq \tau$ or $\tau \subseteq \sigma$ then $\sigma = \tau.$

:::

::: {#o26 .statement kind=statement/corollary cue=math-theorem name="Corollary"}

**Corollary[^n4].**

If $X$ is a [complete](wikipedia://en/53695856) [metrizable TVS](wikipedia://en/64278078), $M$ and $N$ are two closed vector subspaces of $X,$ and if $X$ is the algebraic direct sum of $M$ and $N$ (i.e. the direct sum in the category of vector spaces), then $X$ is the direct sum of $M$ and $N$ in the category of topological vector spaces.

:::

:::

::: {#o28 .example cue=heading name="Examples"}

## Examples {#Examples}

Every [continuous linear functional](https://en.wikipedia.org/wiki/Continuous_linear_functional) on a TVS is a topological homomorphism.[^n1]

Let $X$ be a $1$-dimensional TVS over the field $\mathbb{K}$ and let $x \in X$ be non-zero. Let $L : \mathbb{K} \to X$ be defined by $L(s) := s x.$ If $\mathbb{K}$ has it usual [Euclidean topology](wikipedia://en/1482085) and if $X$ is [Hausdorff](wikipedia://en/13637) then $L : \mathbb{K} \to X$ is a TVS-isomorphism.

:::
