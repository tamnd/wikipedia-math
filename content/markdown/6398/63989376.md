# Archimedean ordered vector space

::: {#o1 .subject cue=lead name="Archimedean ordered vector space"}

In mathematics, specifically in [order theory](wikipedia://en/361924), a [binary relation](wikipedia://en/3931) $\,\leq\,$ on a [vector space](wikipedia://en/32370) $X$ over the [real](wikipedia://en/20646438) or [complex numbers](wikipedia://en/5826) is called **Archimedean** if for all $x \in X,$ whenever there exists some $y \in X$ such that $n x \leq y$ for all positive integers $n,$ then necessarily $x \leq 0.$ An **Archimedean (pre)ordered vector space** is a (pre)[ordered vector space](wikipedia://en/8099221) whose order is Archimedean.[^n1] A pre[ordered vector space](wikipedia://en/8099221) $X$ is called **almost Archimedean** if for all $x \in X,$ whenever there exists a $y \in X$ such that $-n^{-1} y \leq x \leq n^{-1} y$ for all positive integers $n,$ then $x = 0.$[^n2]

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

A pre[ordered vector space](wikipedia://en/8099221) $(X, \leq)$ with an [order unit](wikipedia://en/38017102) $u$ is Archimedean preordered if and only if $n x \leq u$ for all non-negative integers $n$ implies $x \leq 0.$[^n3]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $X$ be an [ordered vector space](wikipedia://en/8099221) over the reals that is finite-dimensional. Then the order of $X$ is Archimedean if and only if the positive cone of $X$ is closed for the unique topology under which $X$ is a Hausdorff TVS (topological vector space).[^n4]

:::

## Order unit norm {#Order_unit_norm}

Suppose $(X, \leq)$ is an ordered vector space over the reals with an [order unit](wikipedia://en/38017102) $u$ whose order is Archimedean and let $U = [-u, u].$ Then the [Minkowski functional](wikipedia://en/3510908) $p_U$ of $U$ (defined by $p_{U}(x) := \inf\left\{ r > 0 : x \in r [-u, u] \right\}$) is a norm called the **order unit norm**. It satisfies $p_U(u) = 1$ and the closed unit ball determined by $p_U$ is equal to $[-u, u]$ (that is, $[-u, u] = \{ x\in X : p_U(x) \leq 1 \}.$[^n3]

::: {#o13 .example cue=heading name="Examples"}

### Examples {#Examples}

The space $l_{\infty}(S, \mathbb{R})$ of bounded real-valued maps on a set $S$ with the pointwise order is Archimedean ordered with an order unit $u := 1$ (that is, the function that is identically $1$ on $S$). The order unit norm on $l_{\infty}(S, \mathbb{R})$ is identical to the usual sup norm: $\|f\| := \sup_{} |f(S)|.$[^n3]

:::

::: {#o16 .example cue=heading name="Examples"}

## Examples {#Examples}

Every [order complete](wikipedia://en/63989777) [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) is Archimedean ordered.[^n5] A finite-dimensional vector lattice of dimension $n$ is Archimedean ordered if and only if it is isomorphic to $\mathbb{R}^n$ with its canonical order.[^n5] However, a totally ordered vector order of dimension $\,> 1$ can not be Archimedean ordered.[^n5] There exist ordered vector spaces that are almost Archimedean but not Archimedean.

The [Euclidean space](wikipedia://en/9697) $\mathbb{R}^2$ over the reals with the [lexicographic order](wikipedia://en/567667) is not Archimedean ordered since $r(0, 1) \leq (1, 1)$ for every $r > 0$ but $(0, 1) \neq (0, 0).$[^n3]

:::
