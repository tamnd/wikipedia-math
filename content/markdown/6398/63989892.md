# Order topology (functional analysis)

::: {#o1 .subject cue=lead name="Order topology"}

In mathematics, specifically in [order theory](wikipedia://en/361924) and [functional analysis](wikipedia://en/11180), the **order topology** of an [ordered vector space](wikipedia://en/8099221) $(X, \leq)$ is the finest [locally convex](https://en.wikipedia.org/wiki/Locally_convex) [topological vector space](wikipedia://en/45752) (TVS) [topology](wikipedia://en/29954) on $X$ for which every order interval is bounded, where an **order interval** in $X$ is a set of the form $[a, b] := \left\{ z \in X : a \leq z \text{ and } z \leq b \right\}$ where $a$ and $b$ belong to $X.$[^n1]

:::

The order topology is an important topology that is used frequently in the theory of [ordered topological vector spaces](wikipedia://en/63988132) because the topology stems directly from the algebraic and order theoretic properties of $(X, \leq),$ rather than from some topology that $X$ starts out having. This allows for establishing intimate connections between this topology and the algebraic and order theoretic properties of $(X, \leq).$ For many [ordered topological vector spaces](wikipedia://en/63988132) that occur in analysis, their topologies are identical to the order topology.[^n2]

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

The family of all locally convex topologies on $X$ for which every order interval is bounded is non-empty (since it contains the coarsest possible topology on $X$) and the order topology is the upper bound of this family.[^n1]

A subset of $X$ is a neighborhood of the origin in the order topology if and only if it is convex and absorbs every order interval in $X.$[^n1] A neighborhood of the origin in the order topology is necessarily an [absorbing set](wikipedia://en/1728179) because $[x, x] := \{ x \}$ for all $x \in X.$[^n1]

For every $a \geq 0,$ let $X_a = \bigcup_{n=1}^{\infty} n [-a, a]$ and endow $X_a$ with its order topology (which makes it into a normable space). The set of all $X_a$'s is directed under inclusion and if $X_a \subseteq X_b$ then the natural inclusion of $X_a$ into $X_b$ is continuous. If $X$ is a [regularly ordered](wikipedia://en/63990309) vector space over the reals and if $H$ is any subset of the positive cone $C$ of $X$ that is cofinal in $C$ (e.g. $H$ could be $C$), then $X$ with its order topology is the inductive limit of $\left\{ X_a : a \geq 0 \right\}$ (where the bonding maps are the natural inclusions).[^n3]

The lattice structure can compensate in part for any lack of an order unit:

::: {#o11 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n3].**

Let $X$ be a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) with a [regular order](https://en.wikipedia.org/wiki/Regular_order_%28mathematics%29) and let $C$ denote its positive cone. Then the order topology on $X$ is the finest locally convex topology on $X$ for which $C$ is a [normal cone](wikipedia://en/63990912); it is also the same as the [Mackey topology](wikipedia://en/1790627) induced on $X$ with respect to the [duality](wikipedia://en/63735167) $\left\langle X, X^{+} \right\rangle.$

:::

In particular, if $(X, \tau)$ is an ordered [Fréchet lattice](wikipedia://en/63990644) over the real numbers then $\tau$ is the ordered topology on $X$ if and only if the positive cone of $X$ is a normal cone in $(X, \tau).$[^n3]

If $X$ is a regularly ordered [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) then the ordered topology is the finest locally convex TVS topology on $X$ making $X$ into a [locally convex vector lattice](wikipedia://en/63990620). If in addition $X$ is order complete then $X$ with the order topology is a [barreled space](https://en.wikipedia.org/wiki/Barreled_space) and every band decomposition of $X$ is a topological direct sum for this topology.[^n3] In particular, if the order of a vector lattice $X$ is regular then the order topology is generated by the family of all [lattice seminorms](https://en.wikipedia.org/wiki/Lattice_seminorm) on $X.$[^n3]

:::

## Properties {#Properties}

Throughout, $(X, \leq)$ will be an [ordered vector space](wikipedia://en/8099221) and $\tau_{\leq}$ will denote the order topology on $X.$

- The dual of $\left(X, \tau_{\leq}\right)$ is the [order bound dual](wikipedia://en/63989481) $X_b$ of $X.$[^n3]
- If $X_b$ separates points in $X$ (such as if $(X, \leq)$ is regular) then $\left(X, \tau_{\leq}\right)$ is a [bornological](https://en.wikipedia.org/wiki/Bornological) locally convex TVS.[^n3]
- Each [positive linear operator](wikipedia://en/64045357) between two ordered vector spaces is continuous for the respective order topologies.[^n3]
- Each [order unit](wikipedia://en/38017102) of an ordered TVS is interior to the positive cone for the order topology.[^n3]
- If the order of an ordered vector space $X$ is a [regular order](https://en.wikipedia.org/wiki/Regular_order_%28mathematics%29) and if each positive sequence of [type $\ell^1$](wikipedia://en/64133229) in $X$ is [order summable](wikipedia://en/64133229), then $X$ endowed with its order topology is a [barreled space](https://en.wikipedia.org/wiki/Barreled_space).[^n3]
- If the order of an ordered vector space $X$ is a [regular order](https://en.wikipedia.org/wiki/Regular_order_%28mathematics%29) and if for all $x \geq 0$ and $y \geq 0$ $[0, x] + [0, y] = [0, x + y]$ holds, then the positive cone of $X$ is a [normal cone](wikipedia://en/63990912) in $X$ when $X$ is endowed with the order topology.[^n3] In particular, the continuous dual space of $X$ with the order topology will be the [order dual](wikipedia://en/12259232) $X$<sup>\+</sup>.
- If $(X, \leq)$ is an [Archimedean ordered](https://en.wikipedia.org/wiki/Archimedean_order) vector space over the real numbers having an [order unit](wikipedia://en/38017102) and let $\tau_{\leq}$ denote the order topology on $X.$ Then $\left(X, \tau_{\leq}\right)$ is an [ordered TVS](https://en.wikipedia.org/wiki/Ordered_TVS) that is [normable](https://en.wikipedia.org/wiki/Normable), $\tau_{\leq}$ is the finest locally convex TVS topology on $X$ such that the positive cone is normal, and the following are equivalent:[^n3]

<!-- -->

1. $\left(X, \tau_{\leq}\right)$ is complete.
1. Each positive sequence of [type $\ell^1$](wikipedia://en/64133229) in $X$ is [order summable](wikipedia://en/64133229).

<!-- -->

- In particular, if $(X, \leq)$ is an [Archimedean ordered](https://en.wikipedia.org/wiki/Archimedean_order) vector space having an [order unit](wikipedia://en/38017102) then the order $\,\leq\,$ is a regular order and $X_b = X^+.$[^n3]
- If $X$ is a Banach space and an ordered vector space with an order unit then $X$'s topological is identical to the order topology if and only if the positive cone of $X$ is a [normal cone](wikipedia://en/63990912) in $X.$[^n3]
- A [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) homomorphism from $X$ into $Y$ is a [topological homomorphism](wikipedia://en/63987005) when $X$ and $Y$ are given their respective order topologies.[^n4]

:::

## Relation to subspaces, quotients, and products {#Relation_to_subspaces,_quotients,_and_products}

If $M$ is a [solid](wikipedia://en/63989659) vector subspace of a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) $X,$ then the order topology of $X / M$ is the quotient of the order topology on $X.$[^n4]

::: {#o30 .example cue=heading name="Examples"}

## Examples {#Examples}

The order topology of a finite product of ordered vector spaces (this product having its canonical order) is identical to the product topology of the [topological product](https://en.wikipedia.org/wiki/Topological_product) of the constituent ordered vector spaces (when each is given its order topology).[^n3]

:::
