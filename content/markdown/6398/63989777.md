# Order complete

::: {#o1 .subject cue=lead name="Order complete"}

In mathematics, specifically in [order theory](wikipedia://en/361924) and [functional analysis](wikipedia://en/11180), a subset $A$ of an [ordered vector space](wikipedia://en/8099221) is said to be **order complete** in $X$ if for every non-empty subset $S$ of $X$ that is order bounded in $A$ (meaning contained in an interval, which is a set of the form $[a, b] := \{ x \in X : a \leq x \text{ and } x \leq b \},$ for some $a, b \in A$), the [supremum](https://en.wikipedia.org/wiki/Supremum) $\sup S$ and the [infimum](https://en.wikipedia.org/wiki/Infimum) $\inf S$ both exist and are elements of $A.$ An ordered vector space is called **order complete**, **Dedekind complete**, a **complete vector lattice**, or a **complete Riesz space**, if it is order complete as a subset of itself,[^n1][^n2] in which case it is necessarily a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice). An ordered vector space is said to be **countably order complete** if each countable subset that is bounded above has a supremum.[^n1]

:::

Being an order complete vector space is an important property that is used frequently in the theory of [topological vector lattices](wikipedia://en/63989962).

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

The [order dual](wikipedia://en/12259232) of a [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) is an order complete vector lattice under its canonical ordering.[^n1]

If $X$ is a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) [topological vector lattice](wikipedia://en/63989962) then the strong dual $X^{\prime}_b$ is an order complete locally convex topological vector lattice under its canonical order.[^n3]

Every [reflexive](wikipedia://en/210091) [locally convex](https://en.wikipedia.org/wiki/Locally_convex) [topological vector lattice](wikipedia://en/63989962) is order complete and a complete TVS.[^n3]

:::

::: {#o11 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $X$ is an order complete [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) then for any subset $A \subseteq X,$ $X$ is the ordered direct sum of the band generated by $A$ and of the band $A^{\perp}$ of all elements that are disjoint from $A.$[^n1] For any subset $A$ of $X,$ the band generated by $A$ is $A^{\perp \perp}.$[^n1] If $x$ and $y$ are [lattice disjoint](wikipedia://en/64014128) then the band generated by $\{x\},$ contains $y$ and is lattice disjoint from the band generated by $\{y\},$ which contains $x.$[^n1]

:::
