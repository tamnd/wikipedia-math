# Topological vector lattice

::: {#o1 .subject cue=lead name="Topological vector lattice"}

In mathematics, specifically in [functional analysis](wikipedia://en/11180) and [order theory](wikipedia://en/361924), a **topological vector lattice** is a [Hausdorff](wikipedia://en/13637) [topological vector space](wikipedia://en/45752) (TVS) $X$ that has a [partial order](https://en.wikipedia.org/wiki/Partial_order) $\,\leq\,$ making it into [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) that possesses a neighborhood base at the origin consisting of [solid sets](wikipedia://en/63989659).[^n1] Ordered vector lattices have important applications in [spectral theory](wikipedia://en/506713).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $X$ is a vector lattice then by **the vector lattice operations** we mean the following maps:

1. the three maps $X$ to itself defined by $x \mapsto|x |$, $x \mapsto x^+$, $x \mapsto x^{-}$, and
1. the two maps from $X \times X$ into $X$ defined by $(x, y) \mapsto \sup_{} \{ x, y \}$ and$(x, y) \mapsto \inf_{} \{ x, y \}$.

If $X$ is a TVS over the reals and a vector lattice, then $X$ is locally solid if and only if (1) its positive cone is a [normal cone](wikipedia://en/63990912), and (2) the vector lattice operations are continuous.[^n1]

If $X$ is a vector lattice and an [ordered topological vector space](wikipedia://en/63988132) that is a [Fréchet space](wikipedia://en/233801) in which the positive cone is a [normal cone](wikipedia://en/63990912), then the lattice operations are continuous.[^n1]

If $X$ is a [topological vector space](wikipedia://en/45752) (TVS) and an [ordered vector space](wikipedia://en/8099221) then $X$ is called **locally solid** if $X$ possesses a neighborhood base at the origin consisting of [solid sets](wikipedia://en/63989659).[^n1] A **topological vector lattice** is a [Hausdorff](wikipedia://en/13637) TVS $X$ that has a [partial order](https://en.wikipedia.org/wiki/Partial_order) $\,\leq\,$ making it into [vector lattice](https://en.wikipedia.org/wiki/Vector_lattice) that is locally solid.[^n1]

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every topological vector lattice has a closed positive cone and is thus an [ordered topological vector space](wikipedia://en/63988132).[^n1] Let $\mathcal{B}$ denote the set of all bounded subsets of a topological vector lattice with positive cone $C$ and for any subset $S$, let $[S]_C := (S + C) \cap (S - C)$ be the [$C$-saturated](wikipedia://en/63990850) hull of $S$. Then the topological vector lattice's positive cone $C$ is a strict $\mathcal{B}$-cone,[^n1] where $C$ is a **strict $\mathcal{B}$-cone** means that $\left\{ [B]_C : B \in \mathcal{B} \right\}$ is a fundamental subfamily of $\mathcal{B}$ that is, every $B \in \mathcal{B}$ is contained as a subset of some element of $\left\{ [B]_C : B \in \mathcal{B} \right\}$).[^n2]

If a topological vector lattice $X$ is [order complete](wikipedia://en/63989777) then every band is closed in $X$.[^n1]

:::

::: {#o16 .example cue=heading name="Examples"}

## Examples {#Examples}

The [L<sup>p</sup> spaces](wikipedia://en/45194) ($1 \leq p \leq \infty$) are [Banach lattices](wikipedia://en/54391334) under their canonical orderings. These spaces are order complete for $p < \infty$.
