# Dini's surface

::: {#o1 .subject cue=lead name="Dini's surface"}

*Image: Mathematica dinis surface.png.* Dini's surface plotted with adjustable parameters by [Wolfram Mathematica](wikipedia://en/49024) program

*Image: Dini Surface.png.* Dini's Surface with constants a = 1, b = 0.5 and 0 ≤ u ≤ 4$\pi$ and 0\<v\<1.

In [geometry](wikipedia://en/18973446), **Dini's surface** is a [surface](wikipedia://en/4342970) with constant negative [curvature](wikipedia://en/60770) that can be created by twisting a [pseudosphere](wikipedia://en/60766).[^o2] It is named after [Ulisse Dini](https://en.wikipedia.org/wiki/Ulisse_Dini)[^o3] and described by the following [parametric equations](wikipedia://en/576108):[^o4]

:::

$$\begin{aligned} x&=a \cos u \sin v \\ y&=a \sin u \sin v \\ z&=a \left(\cos v +\ln \tan \frac{v}{2} \right) + bu \end{aligned}$$

*Image: Dini's Surface.svg.* Dini's surface with 0 ≤ *u* ≤ 4$\pi$ and 0.01 ≤ *v* ≤ 1 and constants *a* = 1.0 and *b* = 0.2.

Another description is a [generalized helicoid](https://en.wikipedia.org/wiki/Generalized_helicoid) constructed from the [tractrix](wikipedia://en/841685).[^o5]
