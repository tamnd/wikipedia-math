# Dualizing module

::: {#o1 .subject cue=lead name="Dualizing module"}

In [abstract algebra](wikipedia://en/19616384), a **dualizing module**, also called a **canonical module**, is a [module](wikipedia://en/276410) over a [commutative ring](wikipedia://en/61346) that is analogous to the [canonical bundle](wikipedia://en/734893) of a [smooth variety](https://en.wikipedia.org/wiki/Smooth_variety). It is used in [Grothendieck local duality](wikipedia://en/38470542).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A dualizing module for a [Noetherian ring](wikipedia://en/56129) *R* is a [finitely generated module](wikipedia://en/326430) *M* such that for any [maximal ideal](wikipedia://en/48164) *m*, the *R*/*m* [vector space](wikipedia://en/32370) Ext${}^{n}_{R}$(*R*/*m*,*M*) vanishes if *n* ≠ height(*m*) and is [1-dimensional](wikipedia://en/38267) if *n* = height(*m*).

A dualizing module need not be unique because the [tensor product](wikipedia://en/30844) of any dualizing module with a rank 1 [projective module](wikipedia://en/364488) is also a dualizing module. However this is the only way in which the dualizing module fails to be unique: given any two dualizing modules, one is isomorphic to the tensor product of the other with a rank 1 projective module. In particular if the ring is local the dualizing module is unique up to isomorphism.

A Noetherian ring does not necessarily have a dualizing module. Any ring with a dualizing module must be [Cohen–Macaulay](wikipedia://en/497407). Conversely if a Cohen–Macaulay ring is a quotient of a [Gorenstein ring](wikipedia://en/515613) then it has a dualizing module. In particular any complete local Cohen–Macaulay ring has a dualizing module. For rings without a dualizing module it is sometimes possible to use the [dualizing complex](https://en.wikipedia.org/wiki/Dualizing_complex) as a substitute.

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

If *R* is a Gorenstein ring, then *R* considered as a module over itself is a dualizing module.

If *R* is an [Artinian](wikipedia://en/489273) [local ring](wikipedia://en/153391) then the [Matlis module](https://en.wikipedia.org/wiki/Matlis_module) of *R* (the injective hull of the residue field) is the dualizing module.

The Artinian local ring *R* = *k*\[*x*,*y*\]/(*x*<sup>2</sup>,*y*<sup>2</sup>,*xy*) has a unique dualizing module, but it is not isomorphic to *R*.

The ring **Z**\[$\sqrt{-5}$\] has two non-isomorphic dualizing modules, corresponding to the two classes of invertible ideals.

The local ring *k*\[*x*,*y*\]/(*y*<sup>2</sup>,*xy*) is not Cohen–Macaulay so does not have a dualizing module.

:::
