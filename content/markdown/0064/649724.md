# Affine plane (incidence geometry)

::: {#o1 .subject cue=lead name="Affine plane"}

In [geometry](wikipedia://en/18973446), an **affine plane** is a system of points and lines that satisfy the following axioms:[^o2]

:::

- Any two distinct points lie on a unique line.
- Given any line and any point not on that line there is a unique line which contains the point and does not meet the given line. ([Playfair's axiom](wikipedia://en/33731592))
- There exist four points such that no three are collinear (points not on a single line).

In an affine plane, two lines are called *parallel* if they are equal or [disjoint](wikipedia://en/39359). Using this definition, Playfair's axiom above can be replaced by:[^o3]

- Given a point and a line, there is a unique line which contains the point and is parallel to the line.

Parallelism is an [equivalence relation](wikipedia://en/9259) on the lines of an affine plane.

Since no concepts other than those involving the relationship between points and lines are involved in the axioms, an affine plane is an object of study belonging to [incidence geometry](wikipedia://en/1576323). They are non-degenerate [linear spaces](wikipedia://en/13872825) satisfying Playfair's axiom.

The familiar [Euclidean plane](wikipedia://en/15575410) is an affine plane. There are many finite and infinite affine planes. As well as [affine planes](wikipedia://en/30764139) over fields (and [division rings](wikipedia://en/9067)), there are also many [non-Desarguesian planes](wikipedia://en/21092112), not derived from coordinates in a division ring, satisfying these axioms. The [Moulton plane](wikipedia://en/9787563) is an example of one of these.[^o4]

## Finite affine planes {#Finite_affine_planes}

*Image: Hesse configuration.svg.* Affine plane of order 3 9 points, 12 lines

If the number of points in an affine plane is finite, then if one line of the plane contains $n$ points then:

- each line contains $n$ points,
- each point is contained in $n + 1$ lines,
- there are $n^{2}$ points in all, and
- there is a total of $n^{2} + n$ lines.

The number $n$ is called the *order* of the affine plane.

All known finite affine planes have orders that are prime or [prime power](wikipedia://en/1630483) integers. The smallest affine plane (of order 2) is obtained by removing a line and the three points on that line from the [Fano plane](wikipedia://en/390404). A similar construction, starting from the projective plane of order 3, produces the affine plane of order 3 sometimes called the [Hesse configuration](wikipedia://en/35282956). An affine plane of order $n$ exists if and only if a [projective plane](wikipedia://en/24350#Finite_projective_planes) of order $n$ exists (however, the definition of order in these two cases is not the same). Thus, there is no affine plane of order 6 or order 10 since there are no projective planes of those orders. The [Bruck–Ryser–Chowla theorem](wikipedia://en/456781) provides further limitations on the order of a projective plane, and thus, the order of an affine plane.

The $n^{2} + n$ lines of an affine plane of order $n$ fall into $n + 1$ equivalence classes of $n$ lines apiece under the equivalence relation of parallelism. These classes are called *parallel classes* of lines. The lines in any parallel class form a partition the points of the affine plane. Each of the $n + 1$ lines that pass through a single point lies in a different parallel class.

The parallel class structure of an affine plane of order $n$ may be used to construct a set of $n - 1$ [mutually orthogonal latin squares](https://en.wikipedia.org/wiki/Mutually_orthogonal_latin_square). Only the incidence relations are needed for this construction.

## Relation with projective planes {#Relation_with_projective_planes}

An affine plane can be obtained from any [projective plane](wikipedia://en/24350) by removing a line and all the points on it, and conversely any affine plane can be used to construct a projective plane by adding a [line at infinity](wikipedia://en/403142), each of whose points is that [point at infinity](wikipedia://en/403139) where an equivalence class of parallel lines meets.

If the projective plane is [non-Desarguesian](wikipedia://en/21092112), the removal of different lines could result in non-isomorphic affine planes. For instance, there are exactly four projective planes of order nine, and seven affine planes of order nine.[^o7] There is only one affine plane corresponding to the [Desarguesian plane](https://en.wikipedia.org/wiki/Desarguesian_plane) of order nine since the [collineation group](wikipedia://en/4072976) of that projective plane acts [transitively](https://en.wikipedia.org/wiki/Transitive_%28group_action%29) on the lines of the plane. Each of the three non-Desarguesian planes of order nine have collineation groups having two orbits on the lines, producing two non-isomorphic affine planes of order nine, depending on which orbit the line to be removed is selected from.

## Affine translation planes {#Affine_translation_planes}

A line $l$ in a projective plane $\Pi$ is a **translation line** if the group of elations with axis $l$ [acts](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) [transitively](https://en.wikipedia.org/wiki/Transitive_property) on the points of the affine plane obtained by removing $l$ from the plane $\Pi$. A projective plane with a translation line is called a **translation plane** and the affine plane obtained by removing the translation line is called an **affine translation plane**. While in general it is often easier to work with projective planes, in this context the affine planes are preferred and several authors simply use the term translation plane to mean affine translation plane.[^o9]

An alternate view of affine translation planes can be obtained as follows: Let $V$ be a $2n$-dimensional [vector space](wikipedia://en/32370) over a [field](wikipedia://en/10603) $F$. A **spread** of $V$ is a set $S$ of $n$-dimensional subspaces of $V$ that partition the non-zero vectors of $V$. The members of $S$ are called the **components** of the spread and if $V_{i}$ and $V_{j}$ are distinct components then $V_{i} \oplus V_{j} = V$. Let $A$ be the [incidence structure](wikipedia://en/723125) whose points are the vectors of $V$ and whose lines are the cosets of components, that is, sets of the form $v + U$ where $v$ is a vector of $V$ and $U$ is a component of the spread $S$. Then:[^o10]

$A$ is an affine plane and the group of [translations](wikipedia://en/204682) $x \to x + w$ for a vector $w$ is an automorphism group acting regularly on the points of this plane.

## Generalization: $k$-nets {#Generalization:_-nets}

An incidence structure more general than a finite affine plane is a $k$-*net of order* $n$. This consists of $n^{2}$ points and $nk$ lines such that:

- Parallelism (as defined in affine planes) is an equivalence relation on the set of lines.
- Every line has exactly $n$ points, and every parallel class has $n$ lines (so each parallel class of lines partitions the point set).
- There are $k$ parallel classes of lines. Each point lies on exactly $k$ lines, one from each parallel class.

An $(n + 1)$-net of order $n$ is precisely an affine plane of order $n$.

A $k$-*net of order* $n$ is equivalent to a set of $k - 2$ mutually orthogonal Latin squares of order $n$.

### Example: translation nets {#Example:_translation_nets}

For an arbitrary field $F$, let $\Sigma$ be a set of $n$-dimensional subspaces of the vector space $F^{2n}$, any two of which intersect only in {0} (called a **partial spread**). The members of $\Sigma$, and their cosets in $F^{2n}$, form the lines of a **translation net** on the points of $F^{2n}$. If $\lvert \Sigma\rvert = k$ this is a $k$-net of order $\lvert F^{n}\rvert$. Starting with an affine [translation plane](wikipedia://en/2628762), any subset of the parallel classes will form a translation net.

Given a translation net, it is not always possible to add parallel classes to the net to form an affine plane. However, if $F$ is an infinite field, any partial spread $\Sigma$ with fewer than $\lvert F\rvert$ members can be extended and the translation net can be completed to an affine translation plane.[^o13]

## Geometric codes {#Geometric_codes}

Given the "line/point" [incidence matrix](wikipedia://en/420919) of any finite [incidence structure](wikipedia://en/723125), $M$, and any [field](wikipedia://en/10603), $F$ the [row space](wikipedia://en/97848) of $M$ over $F$ is a [linear code](wikipedia://en/1866743) that we can denote by $C = C_{F}(M)$. Another related code that contains information about the incidence structure is the **Hull** of $C$ which is defined as:[^o15]

$$\operatorname{Hull}(C) = C \cap C^{\perp},$$

where $C^{\perp}$ is the orthogonal code to $C$.

Not much can be said about these codes at this level of generality, but if the incidence structure has some "regularity" the codes produced this way can be analyzed and information about the codes and the incidence structures can be gleaned from each other. When the incidence structure is a finite affine plane, the codes belong to a class of codes known as *geometric codes*. How much information the code carries about the affine plane depends in part on the choice of field. If the [characteristic](https://en.wikipedia.org/wiki/Characteristic_%28field%29) of the field does not divide the order of the plane, the code generated is the full space and does not carry any information. On the other hand,[^o16]

- If $\pi$ is an affine plane of order $n$ and $F$ is a field of characteristic $p$, where $p$ divides $n$, then the minimum weight of the code $B = \operatorname{Hull}(C_{F}(\pi))^{\perp}$ is $n$ and all the minimum weight vectors are constant multiples of vectors whose entries are either zero or one.

Furthermore,[^o17]

- If $\pi$ is an affine plane of order $p$ and $F$ is a field of characteristic $p$, then $C = \operatorname{Hull}(C_{F}(\pi))^{\perp}$ and the minimum weight vectors are precisely the scalar multiples of the (incidence vectors of) lines of $\pi$.

When $\pi = \operatorname{AG}(2, q)$ the geometric code generated is the $q$-ary [Reed-Muller Code](https://en.wikipedia.org/wiki/Reed-Muller_Code).

## Affine spaces {#Affine_spaces}

[Affine spaces](wikipedia://en/298834) can be defined in an analogous manner to the construction of affine planes from projective planes. It is also possible to provide a system of axioms for the higher-dimensional affine spaces which does not refer to the corresponding [projective space](wikipedia://en/242135).[^o19]
