# Heterotic string theory

::: {#o1 .subject cue=lead name="Heterotic string theory"}

In [string theory](wikipedia://en/28305), a **heterotic string** is a closed string (or loop) which is a hybrid ('heterotic') of a [superstring](https://en.wikipedia.org/wiki/Superstring) and a [bosonic string](https://en.wikipedia.org/wiki/Bosonic_string). There are two kinds of heterotic superstring theories, the heterotic SO(32) and the heterotic E<sub>8</sub> × E<sub>8</sub>, abbreviated to **HO** and **HE**. Apart from that there exist seven more heterotic string theories which are not [supersymmetric](https://en.wikipedia.org/wiki/Supersymmetric) and hence are only of secondary importance in most applications.[^o2] Heterotic string theory was first developed in 1985 by [David Gross](https://en.wikipedia.org/wiki/David_Gross), [Jeffrey Harvey](https://en.wikipedia.org/wiki/Jeffrey_A._Harvey), [Emil Martinec](https://en.wikipedia.org/wiki/Emil_Martinec), and [Ryan Rohm](https://en.wikipedia.org/wiki/Ryan_Rohm)[^o3] (the so-called "Princeton string quartet"[^o4]), in one of the key papers that fueled the [first superstring revolution](https://en.wikipedia.org/wiki/First_superstring_revolution).

:::

## Overview {#Overview}

In [string theory](wikipedia://en/28305), the left-moving and the right-moving excitations of strings are completely decoupled for a closed string,[^o6] and it is possible to construct a string theory whose left-moving (counter-clockwise) excitations are treated as a bosonic string propagating in *D* = 26 dimensions, while the right-moving (clockwise) excitations are treated as a superstring in *D* = 10 dimensions.

The mismatched 16 dimensions must be compactified on an even, [self-dual lattice](https://en.wikipedia.org/wiki/Self-dual_lattice) (a [discrete subgroup](https://en.wikipedia.org/wiki/Discrete_subgroup) of a linear space). There are two possible even self-dual lattices in 16 dimensions, and it leads to two types of the heterotic string. They differ by the [gauge group](https://en.wikipedia.org/wiki/Gauge_group) in 10 dimensions. One gauge group is [SO(32)](https://en.wikipedia.org/wiki/Special_orthogonal_group) (the HO string) while the other is [E<sub>8</sub> × E<sub>8</sub>](wikipedia://en/647994) (the HE string).[^o7]

These two gauge groups also turned out to be the only two [anomaly](wikipedia://en/364731)-free gauge groups that can be coupled to the [*N* = 1 supergravity](https://en.wikipedia.org/wiki/Type_I_supergravity) in 10 dimensions. (Although not realized for quite some time, U(1)<sup>496</sup> and E<sub>8</sub> × U(1)<sup>248</sup> are anomalous.[^o8])

Every heterotic string must be a [closed string](https://en.wikipedia.org/wiki/Closed_string), not an [open string](https://en.wikipedia.org/wiki/String_%28physics%29); it is not possible to define any [boundary conditions](https://en.wikipedia.org/wiki/Boundary_conditions) that would relate the left-moving and the right-moving excitations because they have a different character.

## String duality {#String_duality}

[String duality](https://en.wikipedia.org/wiki/String_duality) is a class of symmetries in physics that link different string theories. In the 1990s, it was realized that the strong coupling limit of the HO theory is [type I string theory](https://en.wikipedia.org/wiki/Type_I_string_theory) — a theory that also contains [open strings](https://en.wikipedia.org/wiki/Open_string_%28physics%29); this relation is called [S-duality](https://en.wikipedia.org/wiki/S-duality). The HO and HE theories are also related by [T-duality](wikipedia://en/432615).

Because the various superstring theories were shown to be related by dualities, it was proposed that each type of string was a different limit of a single underlying theory called [M-theory](wikipedia://en/20406).
