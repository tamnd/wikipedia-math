# Vertical bar

::: {#o2 .subject cue=lead name="Vertical bar"}

The **vertical bar**, |, is a [glyph](https://en.wikipedia.org/wiki/Glyph) with various uses in [mathematics](wikipedia://en/18831), [computing](https://en.wikipedia.org/wiki/Computing), and [typography](https://en.wikipedia.org/wiki/Typography). It has many names, often related to particular meanings: [Sheffer stroke](wikipedia://en/29388) (in [logic](wikipedia://en/19636)), **pipe**, **bar**, **or** (literally, the word "or"), **vbar**, and others.[^o3]

:::

## Usage {#Usage}

::: {#o6 .pointer-item cue=pointer name="Double vertical bar"}

### Mathematics {#Mathematics}

The vertical bar is used as a [mathematical symbol](https://en.wikipedia.org/wiki/Table_of_mathematical_symbols) in numerous ways. If used as a pair of brackets, it suggests the notion of size. These are:

- [absolute value](wikipedia://en/991): $|x|$, read "the *absolute value* of *x*"[^o7]
- [cardinality](wikipedia://en/6174): $|S|$, read "the *cardinality* of the [set](wikipedia://en/26691) *S*" or "the *length* of a [string](wikipedia://en/27701) *S*"
- [determinant](wikipedia://en/8468): $|A|$, read "the *determinant* of the [matrix](wikipedia://en/20556859) *A*".[^o7] When the matrix entries are written out, the determinant is denoted by surrounding the matrix entries by vertical bars instead of the usual brackets or parentheses of the matrix, as in $\begin{vmatrix} a & b \\ c & d\end{vmatrix}$.
- [order](wikipedia://en/493527#Class_equation): $|G|$, read "the *order* of the [group](wikipedia://en/19447) *G*", or $|g|$, "the *order* of the element $g \in G$"

Likewise, the vertical bar is also used singly in many different ways:

- [conditional probability](wikipedia://en/24104134): $P(X|Y)$, read "the [probability](wikipedia://en/22934) of *X* *given* *Y*"
- [distance](wikipedia://en/39378): $P|ab$, denoting the shortest *distance* between point $P$ to line $ab$, so line $P|ab$ is perpendicular to line $ab$
- [divisibility](https://en.wikipedia.org/wiki/Divisibility): $a \mid b$, read "*a* *divides* *b*" or "*a* is a *factor* of *b*", though Unicode also provides special 'divides' and 'does not divide' symbols (2223 and 2224)[^o7]
- [function](wikipedia://en/185427) evaluation: $f(x)|_{x=4}$, read "*f* of *x*, evaluated at *x* equals 4" (see subscripts at Wikibooks)
- [restriction](wikipedia://en/1589032): $f|_{A}$, denoting the *restriction* of the function $f$, with a domain that is a superset of $A$, to just $A$
- [set-builder notation](wikipedia://en/220089): $\{x|x<2\}$, read "the set of *x* *such that* *x* is [less than](https://en.wikipedia.org/wiki/Less_than) two". Often, a [colon](https://en.wikipedia.org/wiki/Colon_%28punctuation%29) ':' is used instead of a vertical bar
- the [Sheffer stroke](wikipedia://en/29388) in [logic](wikipedia://en/46426065): $a|b$, read "*a* *nand* *b*"
- [subtraction](wikipedia://en/74141): $f(x) \vert _a ^b$, read "*f(x)* *from* *a* *to* *b*", denoting $f(b) - f(a)$. Used in the context of a definite integral with variable *x*.
- A vertical bar can be used to separate variables from fixed parameters in a function, for example $f(x|\mu,\sigma)$, or in the notation for [elliptic integrals](https://en.wikipedia.org/wiki/Elliptic_integrals).

The **double vertical bar**, $\|$, is also employed in mathematics.

- [Parallelism](wikipedia://en/664497): $AB \parallel CD$; reads "the line $AB$ *is parallel to* the line $CD$"
- [Norm](wikipedia://en/990534): $\|A\|$; reads "the *norm* (length, size, magnitude etc.) of the matrix $A$". The norm of a one-dimensional [vector](wikipedia://en/32370) is the absolute value and single bars are used.[^o8]
- **Propositional truncation** (a [type](wikipedia://en/40282) former that truncates a type down to a [mere proposition](https://en.wikipedia.org/wiki/Proposition_%28logic%29) in [homotopy type theory](wikipedia://en/33974223)): for any $a : A$ (read "term $a$ of type $A$") we have $|a| : \left\| A \right\|$[^o9] (here $|a|$ reads "*[image](wikipedia://en/579311)* of $a : A$ in $\left\| A \right\|$" and $|a| : \left\| A \right\|$ reads "*propositional truncation* of $A$")[^o10]
- [Integer complexity](wikipedia://en/47292238): $\|n\|$; reads "the complexity of the integer *n*".

In LaTeX [mathematical mode](https://en.wikipedia.org/wiki/TeX#math_mode), the ASCII vertical bar produces a vertical line, and `\|` creates a double vertical line (`a | b \| c` is set as $a | b \| c$). This has different spacing from `\mid` and `\parallel`, which are [relational operators](https://en.wikipedia.org/wiki/Relational_operator): `a \mid b \parallel c` is set as $a \mid b \parallel c$. See below about [LaTeX](https://en.wikipedia.org/wiki/LaTeX) in text mode.

:::

### Chemistry {#Chemistry}

In chemistry, the vertical line is used in [cell notation](https://en.wikipedia.org/wiki/Cell_notation) of [electrochemical cells](https://en.wikipedia.org/wiki/Electrochemical_cells).

Example,

Zn | Zn<sup>2+</sup> || Cu<sup>2+</sup> | Cu

Single vertical lines show components of the cell which do not mix, usually being in different phases. The double vertical line ( || ) is used to represent the [salt bridge](https://en.wikipedia.org/wiki/Salt_bridge), which is used to maintain electrical neutrality within the electrochemical cell.

### Physics {#Physics}

The vertical bar is used in [bra–ket notation](wikipedia://en/4542) in [quantum physics](https://en.wikipedia.org/wiki/Quantum_physics). Examples:

- $|\psi\rangle$: the quantum physical state $\psi$
- $\langle\psi|$: the [dual state](wikipedia://en/7988) corresponding to the state above
- $\langle\psi|\rho\rangle$: the [inner product](https://en.wikipedia.org/wiki/Inner_product) of states $\psi$ and $\rho$
- [Supergroups in physics](wikipedia://en/293756) are denoted *G*(*N*|*M*), which reads "*G*, *M* vertical bar *N*"; here *G* denotes any supergroup, *M* denotes the [bosonic dimensions](https://en.wikipedia.org/wiki/Bosonic_dimensions), and *N* denotes the [Grassmann dimensions](https://en.wikipedia.org/wiki/Grassmann_dimensions).[^o13]

### Computing {#Computing}

::: {#o16 .pointer-item cue=pointer name="Pipe (computing)"}

#### Pipe {#Pipe}

A [pipe](https://en.wikipedia.org/wiki/Pipe_%28Unix%29) is an [inter-process communication](https://en.wikipedia.org/wiki/Inter-process_communication) mechanism originating in [Unix](https://en.wikipedia.org/wiki/Unix), which directs the output (standard out and, optionally, standard error) of one process to the input (standard in) of another. In this way, a series of commands can be "piped" together, giving users the ability to quickly perform complex multi-stage processing from the [command line](https://en.wikipedia.org/wiki/Command-line_interface) or as part of a [Unix shell script](https://en.wikipedia.org/wiki/UNIX_shell_script) ("bash file"). In most [Unix shells](https://en.wikipedia.org/wiki/Unix_shell) (command interpreters), this is represented by the vertical bar character. For example:

[grep](https://en.wikipedia.org/wiki/Grep) -i 'blair' filename.log | [more](https://en.wikipedia.org/wiki/More_%28command%29#Unix)

where the output from the `grep` process (all lines containing 'blair') is piped to the `more` process (which allows a command line user to read through results one page at a time).

The same "pipe" feature has been adopted in other operating systems.

This usage has led to the character itself being called "pipe".

:::

#### Disjunction {#Disjunction}

In many programming languages, the vertical bar is used to designate the [logic operation *or*](wikipedia://en/7962), either [bitwise](wikipedia://en/264399) *or* or [logical](https://en.wikipedia.org/wiki/Boolean_data_type) *or*.

Specifically, in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) and other languages following [C syntax](https://en.wikipedia.org/wiki/C_syntax) conventions, such as [C++](https://en.wikipedia.org/wiki/C++), [Perl](https://en.wikipedia.org/wiki/Perl), [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) and [C#](https://en.wikipedia.org/wiki/C_Sharp_%28programming_language%29), `a | b` denotes a [bitwise *or*](wikipedia://en/264399#OR); whereas a double vertical bar `a || b` denotes a ([short-circuited](https://en.wikipedia.org/wiki/Minimal_evaluation)) [logical *or*](wikipedia://en/7962). Since the character was originally not available in all [code pages](https://en.wikipedia.org/wiki/Code_page) and keyboard layouts, [ANSI C](https://en.wikipedia.org/wiki/ANSI_C) can transcribe it in form of the [trigraph](https://en.wikipedia.org/wiki/C_trigraph) `??!`, which, outside string literals, is equivalent to the `|` character.

In [regular expression](wikipedia://en/25717) syntax, the vertical bar again indicates logical *or* ([alternation](https://en.wikipedia.org/wiki/Alternation_%28formal_language_theory%29)). For example: the Unix command `[[grep]] -E 'fu|bar'` matches lines containing 'fu' or 'bar'.

#### Concatenation {#Concatenation}

The double vertical bar operator "||" denotes [string](wikipedia://en/27701) [concatenation](wikipedia://en/64474) in [PL/I](https://en.wikipedia.org/wiki/PL/I), [REXX](https://en.wikipedia.org/wiki/Rexx), [ooRexx](https://en.wikipedia.org/wiki/Object_REXX), standard [ANSI SQL](https://en.wikipedia.org/wiki/ANSI_SQL), and theoretical computer science (particularly [cryptography](wikipedia://en/18934432)).

#### Delimiter {#Delimiter}

Although not as common as commas or tabs, the vertical bar can be used as a [delimiter](https://en.wikipedia.org/wiki/Delimiter) in a [flat file](https://en.wikipedia.org/wiki/Flat_file). Examples of a [pipe-delimited](https://en.wikipedia.org/wiki/Pipe_delimited) standard data format are [LEDES](https://en.wikipedia.org/wiki/LEDES) 1998B and [HL7](https://en.wikipedia.org/wiki/HL7). It is frequently used because vertical bars are typically uncommon in the data itself.

Similarly, the vertical bar may see use as a delimiter for [regular expression](wikipedia://en/25717) operations (e.g. in [sed](https://en.wikipedia.org/wiki/Sed)). This is useful when the regular expression contains instances of the more common forward slash (`/`) delimiter; using a vertical bar eliminates the need to escape all instances of the forward slash. However, this makes the bar unusable as the regular expression "alternative" operator.

#### Backus–Naur form {#Backus–Naur_form}

In [Backus–Naur form](https://en.wikipedia.org/wiki/Backus–Naur_form), an expression consists of sequences of symbols and/or sequences separated by '|', indicating a [choice](https://en.wikipedia.org/wiki/Alternation_%28formal_language_theory%29), the whole being a possible substitution for the symbol on the left. \<personal-name> ::= \<name> | \<initial>

#### Concurrency operator {#Concurrency_operator}

In calculi of communicating processes (like [pi-calculus](https://en.wikipedia.org/wiki/Pi-calculus)), the vertical bar is used to indicate that processes execute in parallel.

#### APL {#APL}

The pipe in [APL](https://en.wikipedia.org/wiki/APL_%28programming_language%29) is the modulo or *residue* function between two operands and the absolute value function next to one operand.

#### List comprehensions {#List_comprehensions}

The vertical bar is used for list comprehensions in some functional languages, e.g. [Haskell](https://en.wikipedia.org/wiki/Haskell_%28programming_language%29) and [Erlang](https://en.wikipedia.org/wiki/Erlang_%28programming_language%29). Compare set-builder notation.

#### Text markup {#Text_markup}

The vertical bar is used as a special character in [lightweight markup languages](https://en.wikipedia.org/wiki/Lightweight_markup_language), notably [MediaWiki](https://en.wikipedia.org/wiki/MediaWiki)'s [Wikitext](https://en.wikipedia.org/wiki/Wikitext) (in the templates and internal links).

In LaTeX text mode, the vertical bar produces an [em dash](https://en.wikipedia.org/wiki/Em_dash) (—). The `\textbar` command can be used to produce a vertical bar.

#### Closures {#Closures}

The vertical bar is used to denote closures certain languages such as [Ruby](https://en.wikipedia.org/wiki/Ruby_%28programming_language%29) and [Rust](https://en.wikipedia.org/wiki/Rust_%28programming_language%29).

### Phonetics and orthography {#Phonetics_and_orthography}

In the [Khoisan languages](https://en.wikipedia.org/wiki/Khoisan_languages) and the [International Phonetic Alphabet](https://en.wikipedia.org/wiki/International_Phonetic_Alphabet), the vertical bar is used to write the [dental click](https://en.wikipedia.org/wiki/Dental_click) (). A double vertical bar is used to write the [alveolar lateral click](https://en.wikipedia.org/wiki/Alveolar_lateral_click) (). Since these are technically letters, they have their own [Unicode](https://en.wikipedia.org/wiki/Unicode) code points in the [Latin Extended-B](https://en.wikipedia.org/wiki/Latin_Extended-B) range: 01C0 and 01C1.

Some [Northwest](https://en.wikipedia.org/wiki/Northwest_Caucasian_languages) and [Northeast Caucasian languages](https://en.wikipedia.org/wiki/Northeast_Caucasian_languages) written in the [Cyrillic script](https://en.wikipedia.org/wiki/Cyrillic_script) have a vertical bar called [palochka](https://en.wikipedia.org/wiki/Palochka) (палочка), indicating the preceding consonant is an [ejective](https://en.wikipedia.org/wiki/Ejective_consonant).

Longer single and double vertical bars are used to mark [prosodic](https://en.wikipedia.org/wiki/Prosody_%28linguistics%29) boundaries in the IPA.

### Literature {#Literature}

In medieval European manuscripts, a single vertical bar was a common variant of the [virgula](https://en.wikipedia.org/wiki/Slash_%28punctuation%29) [/](https://en.wikipedia.org/wiki//) used as a [comma](https://en.wikipedia.org/wiki/Comma),[^o28] or [caesura](https://en.wikipedia.org/wiki/Caesura) mark.[^o28]

In [Sanskrit](https://en.wikipedia.org/wiki/Sanskrit) and other [Indian languages](https://en.wikipedia.org/wiki/Languages_of_India), a single vertical mark,।, called a [danda](https://en.wikipedia.org/wiki/Danda), has a similar function as a period (full stop). Two bars,॥, (a 'double danda') is the equivalent of a [pilcrow](https://en.wikipedia.org/wiki/Pilcrow) in marking the end of a [stanza](https://en.wikipedia.org/wiki/Stanza), paragraph or section. The danda has its own Unicode code point, 0964; as does the double danda: 0965.

#### Poetry {#Poetry}

A double vertical bar || or ‖ is the standard *[caesura](https://en.wikipedia.org/wiki/Caesura) mark* in English [literary criticism](https://en.wikipedia.org/wiki/Literary_criticism) and analysis. It marks the strong break or [caesura](https://en.wikipedia.org/wiki/Caesura) common to many forms of [poetry](https://en.wikipedia.org/wiki/Poetry), particularly [Old English verse](https://en.wikipedia.org/wiki/Old_English_poetry). It is also traditionally used to mark the division between lines of verse printed as prose (the style preferred by [Oxford University Press](https://en.wikipedia.org/wiki/Oxford_University_Press)), though it is now often replaced by the [forward slash](https://en.wikipedia.org/wiki/Forward_slash).

#### Notation {#Notation}

In the [Geneva Bible](https://en.wikipedia.org/wiki/Geneva_Bible) and early printings of the [King James Version](https://en.wikipedia.org/wiki/King_James_Version), a double vertical bar is used to mark [margin notes](https://en.wikipedia.org/wiki/Marginalia) that contain an alternative translation from the original text. These margin notes always begin with the conjunction "or". In later printings of the King James Version, the double vertical bar is irregularly used to mark any comment in the margins.

A double vertical bar symbol may be used to call out a [footnote](https://en.wikipedia.org/wiki/Footnote). (The traditional order of these symbols in English is [\*](https://en.wikipedia.org/wiki/Asterisk), [†](https://en.wikipedia.org/wiki/Dagger_%28mark%29), [‡](https://en.wikipedia.org/wiki/Dagger_%28mark%29), [§](https://en.wikipedia.org/wiki/Section_sign), ‖, [¶](https://en.wikipedia.org/wiki/Pilcrow), so its use is very rare; in modern usage, numbers and letters are preferred for [endnotes and footnotes](https://en.wikipedia.org/wiki/Note_%28typography%29).[^o31])

#### Music scoring {#Music_scoring}

In music, when writing chord sheets, single vertical bars associated with a colon (|: A / / / :|) represents the beginning and end of a section (e.g. Intro, Interlude, Verse, Chorus) of music. Single bars can also represent the beginning and end of measures (|: A / / / | D / / / | E / / / :|). A double vertical bar associated with a colon can represent the repeat of a given section (||: A / / / :|| - play twice).

## Broken bar {#Broken_bar}

*Image: Dot printer ASCII0x7C+.png.* The code point 124 (7C [hexadecimal](wikipedia://en/13263)) is occupied by a broken bar in a [dot matrix printer](https://en.wikipedia.org/wiki/Dot_matrix_printer) of the late 1980s, which apparently lacks a solid vertical bar. See the full picture.

Many early video terminals and [dot-matrix printers](https://en.wikipedia.org/wiki/Dot-matrix_printers) rendered the vertical bar character as the [allograph](https://en.wikipedia.org/wiki/Allograph) **broken bar** ¦. This variant (briefly) replaced the continuous vertical bar in the 1967 version (only) of the [ASCII](https://en.wikipedia.org/wiki/ASCII) standard.

An initial draft for a 7-bit character set that was published by the X3.2 subcommittee for Coded Character Sets and Data Format on June 8, 1961, was the first to include the vertical bar in a standard set. The (unbroken) vertical bar was intended to be used as the representation for the [logical OR](https://en.wikipedia.org/wiki/Logical_OR) symbol.[^o35] A subsequent draft on May 12, 1966, places the vertical bar in column 7 alongside regional entry codepoints, and formed the basis for the original draft proposal used by the [International Standards Organisation](https://en.wikipedia.org/wiki/International_Standards_Organisation).[^o35] This draft received opposition from the [IBM](https://en.wikipedia.org/wiki/IBM) user group [SHARE](https://en.wikipedia.org/wiki/SHARE_%28computing%29), with its chairman, H. W. Nelson, writing a letter to the [American Standards Association](https://en.wikipedia.org/wiki/American_Standards_Association) titled "The Proposed revised American Standard Code for Information Interchange does NOT meet the needs of computer programmers!"; in this letter, he argues that no characters within the international subset designated at columns 2-5 of the character set would be able to adequately represent logical OR and [logical NOT](wikipedia://en/161019) in languages such as IBM's [PL/I](https://en.wikipedia.org/wiki/PL/I) universally on all platforms.[^o36] As a compromise, a requirement was introduced where the [exclamation mark](wikipedia://en/7712754) (!) and [circumflex](https://en.wikipedia.org/wiki/Circumflex) (^) would display as logical OR (|) and logical NOT (¬) respectively in use cases such as programming, while outside of these use cases they would represent their original typographic symbols:

The original vertical bar encoded at 0x7C in the original May 12, 1966 draft was then broken as ¦, so it could not be confused with the unbroken logical OR. In the 1967 revision of ASCII, along with the equivalent ISO 464 code published the same year, the code point was defined to be a broken vertical bar, and the exclamation mark character was allowed to be rendered as a solid vertical bar.[^o39][^o38] However, the 1977 revision (ANSI X.3-1977) undid the changes made in the 1967 revision, enforcing that the circumflex could no longer be stylised as a logical NOT symbol, the exclamation mark likewise no longer allowing stylisation as a vertical bar, and defining the code point originally set to the broken bar as a solid vertical bar instead;[^o39] the same changes were also reverted in ISO 646-1973 published four years prior.

Some variants of [EBCDIC](https://en.wikipedia.org/wiki/EBCDIC) included both versions of the character as different code points. The broad implementation of the [extended ASCII](https://en.wikipedia.org/wiki/Extended_ASCII) [ISO/IEC 8859](https://en.wikipedia.org/wiki/ISO/IEC_8859) series in the 1990s also made a distinction between the two forms. This was preserved in Unicode as a separate character at 00A6 (the term "parted rule" is used sometimes in Unicode documentation). Some fonts draw the characters the same (both are solid vertical bars, or both are broken vertical bars).[^o40]

The broken bar does not appear to have any clearly identified uses distinct from those of the vertical bar.[^o41] In non-computing use — for example in mathematics, physics and general typography — the broken bar is not an acceptable substitute for the vertical bar.[^o42] In some dictionaries, the broken bar is used to mark stress that may be either primary or secondary: covers the pronunciations and .[^o43]

:::
