# Computational Diffie–Hellman assumption

::: {#o1 .subject cue=lead name="Computational Diffie–Hellman assumption"}

The **computational Diffie–Hellman (CDH) assumption** is a [computational hardness assumption](wikipedia://en/6158383) about the [Diffie–Hellman problem](wikipedia://en/3237741).[^o2] The CDH assumption involves the problem of computing the [discrete logarithm](wikipedia://en/181334) in [cyclic groups](wikipedia://en/52327). The CDH problem illustrates the attack of an eavesdropper in the [Diffie–Hellman key exchange](wikipedia://en/7903)[^o3] protocol to obtain the exchanged secret key.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Consider a [cyclic group](wikipedia://en/52327) *G* of order *q*. The CDH assumption states that, given

$$(g,g^a,g^b) \,$$

for a randomly chosen generator *g* and random

$$a,b \in \{0, \ldots, q-1\},\,$$

it is [computationally intractable](https://en.wikipedia.org/wiki/Computationally_intractable) to compute the value

$$g^{ab}. \,$$

:::

## Relation to discrete logarithms {#Relation_to_discrete_logarithms}

The CDH assumption is strongly related to the [discrete logarithm assumption](https://en.wikipedia.org/wiki/Discrete_logarithm_assumption). If computing the [discrete logarithm](wikipedia://en/181334) (base *g* ) in *G* were easy, then the CDH problem could be solved easily:

Given

$$(g,g^a,g^b), \,$$

one could efficiently compute $g^{ab}$ in the following way:

- compute $a$ by taking the discrete log of $g^a$ to base $g$;
- compute $g^{ab}$ by exponentiation: $g^{ab} = (g^b)^a$;

Computing the [discrete logarithm](wikipedia://en/181334) is the only known method for solving the CDH problem. But there is no proof that it is, in fact, the only method. It is an open problem to determine whether the discrete log assumption is equivalent to the CDH assumption, though in certain special cases this can be shown to be the case.[^o7][^o8]

## Relation to decisional Diffie–Hellman assumption {#Relation_to_decisional_Diffie–Hellman_assumption}

The CDH assumption is a *weaker* assumption than the [decisional Diffie–Hellman assumption](wikipedia://en/1198015) (DDH assumption). If computing $g^{ab}$ from $(g,g^a,g^b)$ was easy (CDH problem), then one could solve the DDH problem trivially.

Many cryptographic schemes that are constructed from the CDH problem rely in fact on the hardness of the DDH problem. The [semantic security](wikipedia://en/960585) of the [Diffie–Hellman key exchange](wikipedia://en/7903) as well as the security of the [ElGamal encryption](wikipedia://en/59458) rely on the hardness of the DDH problem.

There are concrete constructions of groups where the stronger DDH assumption does not hold but the weaker CDH assumption still seems to be a reasonable hypothesis.[^o10]

::: {#o12 .statement kind=statement/generalization cue=heading name="Variations of the computational Diffie–Hellman assumption"}

## Variations of the computational Diffie–Hellman assumption {#Variations_of_the_computational_Diffie–Hellman_assumption}

The following variations of the CDH problem have been studied and proven to be equivalent to the CDH problem:[^o13]

- Square computational Diffie–Hellman problem (SCDH): On input $g, g^x$, compute $g^{x^{2}}$;[^o14]
- Inverse computational Diffie–Hellman problem (InvCDH): On input $g, g^x$, compute $g^{x^{-1}}$;[^o15]
- Divisible computation Diffie–Hellman problem (DCDH): On input $g, g^x, g^y$, compute $g^{y/x}$.

:::

## Variations of the computational Diffie–Hellman assumption in product groups {#Variations_of_the_computational_Diffie–Hellman_assumption_in_product_groups}

Let $G_1$ and $G_2$ be two [cyclic groups](wikipedia://en/52327).

- Co-computational Diffie–Hellman (co-CDH) problem: Given $g, g^a \in G_1$ and $h \in G_2$, compute $h^a \in G_2$.[^o17]
