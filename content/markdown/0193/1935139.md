# Q-matrix

::: {#o1 .subject cue=lead name="Q-matrix"}

In [mathematics](wikipedia://en/18831), a **Q-matrix** is a square [matrix](wikipedia://en/20556859) whose associated [linear complementarity problem](wikipedia://en/1470767) LCP(*M*,*q*) has a solution for every vector *q*.

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- *M* is a Q-matrix if there exists *d* > 0 such that LCP(*M*,0) and LCP(*M*,*d*) have a unique solution.[^o4][^o5]
- Any [P-matrix](wikipedia://en/7632450) is a Q-matrix. Conversely, if a matrix is a [Z-matrix](wikipedia://en/7838302) and a Q-matrix, then it is also a P-matrix.[^o6]

:::
