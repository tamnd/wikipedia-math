# FEA-M

::: {#o2 .subject cue=lead name="FEA-M"}

In [cryptography](wikipedia://en/18934432), **FEA-M (Fast Encryption Algorithm for Multimedia)** is a [block cipher](wikipedia://en/4594) developed in 2001 by X. Yi, C. H. Tan, C. K. Siew, and M. R. Syed.

:::

With the unusually large [block size](wikipedia://en/294065) of 4096 bits, all of FEA-M's calculations operate on 64×64 binary [matrices](wikipedia://en/20556859). Unlike most block ciphers, FEA-M does not use multiple rounds of encryption. Each block is encrypted using just two [multiplications](wikipedia://en/125280) and two [additions](wikipedia://en/125276). The data is encrypted using a pair of [session keys](wikipedia://en/63941) chosen for just that message. The [key](wikipedia://en/53039) is an invertible matrix used to encrypt the session keys, and the encrypted session keys must be sent along with the ciphertext. Since only invertible matrices can be used for the key, the effective [key size](wikipedia://en/5749) is about 4094.2 bits.

FEA-M is insecure; an attack found by [Youssef](https://en.wikipedia.org/wiki/Amr_Youssef) and [Tavares](wikipedia://en/9546396) (2003) recovers the secret key using only 1 [known plaintext](wikipedia://en/517019) and 2 [chosen plaintexts](wikipedia://en/63852).[^o3]
