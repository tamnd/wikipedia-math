# Orthogonalization

::: {#o1 .subject cue=lead name="Orthogonalization"}

In [linear algebra](wikipedia://en/18422), **orthogonalization** is the process of finding a [set](wikipedia://en/26691) of [orthogonal vectors](https://en.wikipedia.org/wiki/Orthogonal_vector) that [span](https://en.wikipedia.org/wiki/Span_%28linear_algebra%29) a particular [subspace](wikipedia://en/56357). Formally, starting with a [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) set of vectors {*v*<sub>1</sub>, ... , *v*<sub>*k*</sub>} in an [inner product space](wikipedia://en/14856) (most commonly the [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup>), orthogonalization results in a set of [orthogonal](wikipedia://en/102221) vectors {*u*<sub>1</sub>, ... , *u*<sub>*k*</sub>} that [generate](wikipedia://en/3171371) the same subspace as the vectors *v*<sub>1</sub>, ... , *v*<sub>*k*</sub>. Every vector in the new set is orthogonal to every other vector in the new set; and the new set and the old set have the same [linear span](wikipedia://en/56353).

:::

In addition, if we want the resulting vectors to all be [unit vectors](wikipedia://en/167053), then we [normalize](wikipedia://en/167053) each vector and the procedure is called **orthonormalization**.

Orthogonalization is also possible with respect to any [symmetric bilinear form](wikipedia://en/1803375) (not necessarily an inner product, not necessarily over [real numbers](wikipedia://en/20646438)), but standard algorithms may encounter [division by zero](wikipedia://en/185663) in this more general setting.

::: {#o3 .definition kind=definition/construction cue=heading name="Orthogonalization algorithms"}

## Orthogonalization algorithms {#Orthogonalization_algorithms}

Methods for performing orthogonalization include:

- [Gram–Schmidt process](wikipedia://en/82361), which uses [projection](wikipedia://en/519182)
- [Householder transformation](wikipedia://en/485424), which uses [reflection](wikipedia://en/295829)
- [Givens rotation](wikipedia://en/680237)
- Symmetric orthogonalization, which uses the [Singular value decomposition](wikipedia://en/142207)

When performing orthogonalization on a computer, the Householder transformation is usually preferred over the Gram–Schmidt process since it is more [numerically stable](wikipedia://en/233807), i.e. rounding errors tend to have less serious effects.

On the other hand, the Gram–Schmidt process produces the jth orthogonalized vector after the jth iteration, while orthogonalization using Householder reflections produces all the vectors only at the end. This makes only the Gram–Schmidt process applicable for [iterative methods](wikipedia://en/15237) like the [Arnoldi iteration](wikipedia://en/1134614).

The Givens rotation is more easily [parallelized](https://en.wikipedia.org/wiki/Parallel_computing) than Householder transformations.

Symmetric orthogonalization was formulated by [Per-Olov Löwdin](https://en.wikipedia.org/wiki/Per-Olov_Löwdin).[^o4]

:::

## Local orthogonalization {#Local_orthogonalization}

To compensate for the loss of useful signal in traditional noise attenuation approaches because of incorrect parameter selection or inadequacy of [denoising](https://en.wikipedia.org/wiki/Denoising) assumptions, a weighting operator can be applied on the initially denoised section for the retrieval of useful signal from the initial noise section. The new denoising process is referred to as the local orthogonalization of signal and noise.[^o6] It has a wide range of applications in many [signals processing](wikipedia://en/29324) and [seismic exploration](https://en.wikipedia.org/wiki/Seismic_exploration) fields.
