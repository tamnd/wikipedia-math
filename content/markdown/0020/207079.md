# Gamma distribution

::: {#o2 .subject cue=lead name="Gamma distribution"}

In [probability theory](wikipedia://en/23542) and [statistics](wikipedia://en/26685), the **gamma distribution** is a versatile two-[parameter](wikipedia://en/413291) family of continuous [probability distributions](wikipedia://en/23543).[^o3] The [exponential distribution](wikipedia://en/45906), [Erlang distribution](wikipedia://en/199028), and [chi-squared distribution](wikipedia://en/113424) are special cases of the gamma distribution.[^o4] There are two equivalent parameterizations in common use:

:::

1. With a [shape parameter](wikipedia://en/9210865) $\alpha$ and a [scale parameter](wikipedia://en/769503) $\theta$
1. With a shape parameter $\alpha$ and a [rate parameter](https://en.wikipedia.org/wiki/Rate_parameter) $\beta = 1/ \theta$

In each of these forms, both parameters are positive real numbers.

The distribution has important applications in various fields, including [econometrics](wikipedia://en/10390), [Bayesian statistics](wikipedia://en/404412), and life testing.[^o5] In econometrics, the (*α*, *θ*) parameterization is common for modeling waiting times, such as the time until death, where it often takes the form of an [Erlang distribution](wikipedia://en/199028) for integer *α* values. Bayesian statisticians prefer the (*α*,*β*) parameterization, utilizing the gamma distribution as a [conjugate prior](wikipedia://en/846412) for several inverse scale parameters, facilitating analytical tractability in posterior distribution computations.

The gamma distribution is the [maximum entropy probability distribution](wikipedia://en/1813193) (both with respect to a uniform base measure and a $1/x$ base measure) for a random variable $X$ for which $\mathbf{E}[X] = \alpha\theta = \alpha/\beta$ is fixed and greater than zero, and $\mathbf{E}[\ln X] = \psi(\alpha) + \ln \theta = \psi(\alpha) - \ln \beta$ is fixed ($\psi$ is the [digamma function](wikipedia://en/406935)).[^o6]

::: {#o8 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

The parameterization with $\alpha$ and $\theta$ appears to be more common in [econometrics](wikipedia://en/10390) and other applied fields, where the gamma distribution is frequently used to model waiting times. For instance, in [life testing](https://en.wikipedia.org/wiki/Accelerated_life_testing), the waiting time until death is a [random variable](wikipedia://en/25685) that is frequently modeled with a gamma distribution. See Hogg and Craig[^o9] for an explicit motivation.

The parameterization with $\alpha$ and $\beta$ is more common in [Bayesian statistics](wikipedia://en/404412),[^o10] where the gamma distribution is used as a [conjugate prior](wikipedia://en/846412) distribution for various types of inverse scale (rate) parameters, such as the $\lambda$ of an [exponential distribution](wikipedia://en/45906) or a [Poisson distribution](wikipedia://en/23009144)[^o11] – or for that matter, the $\beta$ of the gamma distribution itself. The closely related [inverse-gamma distribution](wikipedia://en/1653565) is used as a conjugate prior for scale parameters, such as the [variance](wikipedia://en/32344) of a [normal distribution](wikipedia://en/21462).

If $\alpha$ is a positive [integer](wikipedia://en/14563), then the distribution represents an [Erlang distribution](wikipedia://en/199028); i.e., the sum of $\alpha$ independent [exponentially distributed](https://en.wikipedia.org/wiki/Exponentially_distributed) [random variables](wikipedia://en/25685), each of which has a mean of $\theta$.

### Characterization using shape *α* and rate *β* {#Characterization_using_shape_α_and_rate_β}

The gamma distribution can be parameterized in terms of a [shape parameter](wikipedia://en/9210865) $\alpha$ and an inverse scale parameter $\beta = 1/\theta$, called a [rate parameter](https://en.wikipedia.org/wiki/Rate_parameter). A random variable $X$ that is gamma-distributed with shape $\alpha$ and rate $\beta$ is denoted

$$X \sim \Gamma(\alpha, \beta) \equiv \operatorname{Gamma}(\alpha,\beta)$$

The corresponding probability density function in the shape-rate parameterization is

$$\begin{aligned} f(x;\alpha,\beta) & = \frac{ x^{\alpha-1} e^{-\beta x} \beta^\alpha}{\Gamma(\alpha)} \quad \text{ for } x > 0 \quad \alpha, \beta > 0, \\[6pt] \end{aligned}$$

where $\Gamma(\alpha)$ is the [gamma function](wikipedia://en/12316). For all positive integers, $\Gamma(\alpha)=(\alpha-1)!$.

The [cumulative distribution function](wikipedia://en/5793) is the regularized gamma function:

$$F(x;\alpha,\beta) = \int_0^x f(u;\alpha,\beta)\,du= \frac{\gamma(\alpha, \beta x)}{\Gamma(\alpha)},$$

where $\gamma(\alpha, \beta x)$ is the lower [incomplete gamma function](wikipedia://en/456050).

If $\alpha$ is a positive [integer](wikipedia://en/14563) (i.e., the distribution is an [Erlang distribution](wikipedia://en/199028)), the cumulative distribution function has the following series expansion:[^o14]

$$\begin{aligned} F(x;\alpha,\beta) &= 1-\sum_{i=0}^{\alpha-1} \frac{\left(\beta x\right)^i}{i!} e^{-\beta x} \\[1ex] &= e^{-\beta x} \sum_{i=\alpha}^\infty \frac{\left(\beta x\right)^i}{i!}. \end{aligned}$$

### Characterization using shape *α* and scale *θ* {#Characterization_using_shape_α_and_scale_θ}

A random variable $X$ that is gamma-distributed with shape $\alpha$ and scale $\theta$ is denoted by

$$X \sim \Gamma(\alpha, \theta) \equiv \operatorname{Gamma}(\alpha, \theta)$$

*Image: Gamma-PDF-3D.png.* Illustration of the gamma PDF for parameter values over $\alpha$ and $x$ with $\theta$ set to $1, 2, 3, 4, 5,$ and $6$. One can see each $\theta$ layer by itself here <http://commons.wikimedia.org/wiki/File:Gamma-PDF-3D-by-k.png> as well as by $\alpha$ <http://commons.wikimedia.org/wiki/File:Gamma-PDF-3D-by-Theta.png> and $x$. <http://commons.wikimedia.org/wiki/File:Gamma-PDF-3D-by-x.png>.

The [probability density function](wikipedia://en/43487) using the shape-scale parametrization is

$$f(x;\alpha,\theta) = \frac{x^{\alpha-1}e^{-x/\theta}}{\theta^\alpha\Gamma(\alpha)} \quad \text{ for } x > 0 \text{ and } \alpha, \theta > 0.$$

Here $\Gamma(\alpha)$ is the [gamma function](wikipedia://en/12316) evaluated at $\alpha$.

The [cumulative distribution function](wikipedia://en/5793) is the regularized gamma function:

$$F(x;\alpha,\theta) = \int_0^x f(u;\alpha,\theta)\,du = \frac{\gamma{\left(\alpha, \frac{x}{\theta}\right)}}{\Gamma(\alpha)},$$

where $\gamma{\left(\alpha, \frac{x}{\theta}\right)}$ is the lower [incomplete gamma function](wikipedia://en/456050).

It can also be expressed as follows, if $\alpha$ is a positive [integer](wikipedia://en/14563) (i.e., the distribution is an [Erlang distribution](wikipedia://en/199028)):[^o14]

$$F(x;\alpha,\theta) = 1-\sum_{i=0}^{\alpha-1} \frac{1}{i!} \left(\frac{x}{\theta} \right)^i e^{-x/\theta} = e^{-x/\theta} \sum_{i=\alpha}^\infty \frac{1}{i!} \left( \frac{x}{\theta} \right)^i.$$

Both parametrizations are common because either can be more convenient depending on the situation.

:::

## Properties {#Properties}

### Mean and variance {#Mean_and_variance}

The mean of gamma distribution is given by the product of its shape and scale parameters:

$$\mu = \alpha\theta = \alpha/\beta$$

The variance is:

$$\sigma^2 = \alpha \theta^2 = \alpha/\beta^2$$

The square root of the inverse shape parameter gives the [coefficient of variation](wikipedia://en/1012687):

$$\sigma/\mu = \alpha^{-0.5} = 1/\sqrt{\alpha}$$

### Skewness {#Skewness}

The [skewness](wikipedia://en/28212) of the gamma distribution only depends on its shape parameter, $\alpha$, and it is equal to $2/\sqrt{\alpha}.$

### Higher moments {#Higher_moments}

The $r$-th [raw moment](https://en.wikipedia.org/wiki/Raw_moment) is given by:

$$\mathrm{E}[X^r] = \theta^r \frac{\Gamma(\alpha+r)}{\Gamma(\alpha)} = \theta^r \alpha^\overline{r}$$

with $\alpha^\overline{r}$ the [rising factorial](https://en.wikipedia.org/wiki/Rising_factorial).

### Cumulants {#Cumulants}

The $r$-th [cumulant](wikipedia://en/359684) is given by:

$$\kappa_r = \theta^r \alpha (r-1)! = \theta^r \alpha \Gamma(r).$$

### Median approximations and bounds {#Median_approximations_and_bounds}

*Image: Gamma distribution median bounds.png.* Bounds and asymptotic approximations to the median of the gamma distribution. The cyan-colored region indicates the large gap between published lower and upper bounds before 2021.

Unlike the mode and the mean, which have readily calculable formulas based on the parameters, the median does not have a closed-form equation. The median for this distribution is the value $\nu$ such that

$$\frac{1}{\Gamma(\alpha) \theta^\alpha} \int_0^{\nu} x^{\alpha - 1} e^{-x/\theta} dx = \frac{1}{2}.$$

A rigorous treatment of the problem of determining an asymptotic expansion and bounds for the median of the gamma distribution was handled first by Chen and Rubin, who proved that (for $\theta = 1$)

$$\alpha - \tfrac{1}{3} < \nu(\alpha) < \alpha,$$

where $\mu(\alpha) = \alpha$ is the mean and $\nu(\alpha)$ is the median of the $\text{Gamma}(\alpha,1)$ distribution.[^o22] For other values of the scale parameter, the mean scales to $\mu = \alpha\theta$, and the median bounds and approximations would be similarly scaled by $\theta$.

K. P. Choi found the first five terms in a [Laurent series](wikipedia://en/61213) asymptotic approximation of the median by comparing the median to [Ramanujan's $\theta$ function](wikipedia://en/2324377).[^o23] Berg and Pedersen found more terms:[^o24]

$$\begin{aligned} \nu(\alpha) = \alpha & - \frac{1}{3} + \frac{8}{405} \alpha^{-1} + \frac{184}{{25\,515}} \alpha^{-2} + \frac{2248}{{3\,444\,525}} \alpha^{-3} \\[1ex] & - \frac{19\,006\,408}{{15\,345\,358\,875}} \alpha^{-4} - \mathcal{O}{\left(\alpha^{-5}\right)} + \cdots \end{aligned}$$

*Image: Gamma distribution median Lyon bounds.png.* Two gamma distribution median asymptotes which were proved in 2023 to be bounds (upper solid red and lower dashed red), of the from $\nu(\alpha) \approx 2^{-1/\alpha}(A + \alpha)$, and an interpolation between them that makes an approximation (dotted red) that is exact at $\alpha = 1$ and has maximum relative error of about 0.6%. The cyan shaded region is the remaining gap between upper and lower bounds (or conjectured bounds), including these new bounds and the bounds in the previous figure.

*Image: Gamma distribution median loglog bounds.png.* [Log–log plot](wikipedia://en/1659215) of upper (solid) and lower (dashed) bounds to the median of a gamma distribution and the gaps between them. The green, yellow, and cyan regions represent the gap before the Lyon 2021 paper. The green and yellow narrow that gap with the lower bounds that Lyon proved. Lyon's bounds proved in 2023 further narrow the yellow. Mostly within the yellow, closed-form rational-function-interpolated conjectured bounds are plotted along with the numerically calculated median (dotted) value. Tighter interpolated bounds exist but are not plotted, as they would not be resolved at this scale.

Partial sums of these series are good approximations for high enough $\alpha$; they are not plotted in the figure, which is focused on the low-$\alpha$ region that is less well approximated.

Berg and Pedersen also proved many properties of the median, showing that it is a convex function of $\alpha$,[^o25] and that the asymptotic behavior near $\alpha = 0$ is $\nu(\alpha) \approx e^{-\gamma}2^{-1/\alpha}$ (where $\gamma$ is the [Euler–Mascheroni constant](https://en.wikipedia.org/wiki/Euler–Mascheroni_constant)), and that for all $\alpha > 0$ the median is bounded by $\alpha 2^{-1/\alpha} < \nu(\alpha) < k e^{-1/3k}$.[^o24]

A closer linear upper bound, for $\alpha \ge 1$ only, was provided in 2021 by Gaunt and Merkle,[^o26] relying on the Berg and Pedersen result that the slope of $\nu(\alpha)$ is everywhere less than 1:

$$\nu(\alpha) \le \alpha - 1 + \log2 ~~$$

for $\alpha \ge 1$ (with equality at $\alpha = 1$) which can be extended to a bound for all $\alpha > 0$ by taking the max with the chord shown in the figure, since the median was proved convex.[^o25]

An approximation to the median that is asymptotically accurate at high $\alpha$ and reasonable down to $\alpha = 0.5$ or a bit lower follows from the [Wilson–Hilferty transformation](https://en.wikipedia.org/wiki/Wilson–Hilferty_transformation):

$$\nu(\alpha) = \alpha \left( 1 - \frac{1}{9\alpha} \right)^3$$

which goes negative for $\alpha < 1/9$.

In 2021, Lyon proposed several approximations of the form $\nu(\alpha) \approx 2^{-1/\alpha}(A + B\alpha)$. He conjectured values of $A$ and $B$ for which this approximation is an asymptotically tight upper or lower bound for all $\alpha > 0$.[^o27] In particular, he proposed these closed-form bounds, which he proved in 2023:[^o28]

$$\nu_{L\infty}(\alpha) = 2^{-1/\alpha} \left(\log 2 - \tfrac{1}{3} + \alpha\right)$$

is a lower bound, asymptotically tight as $\alpha \to \infty$

$$\nu_U(\alpha) = 2^{-1/\alpha}(e^{-\gamma} + \alpha) \quad$$

is an upper bound, asymptotically tight as $\alpha \to 0$

Lyon also showed (informally in 2021, rigorously in 2023) two other lower bounds that are not [closed-form expressions](wikipedia://en/585143), including this one involving the [gamma function](wikipedia://en/12316), based on solving the integral expression substituting 1 for $e^{-x}$:

$$\nu(\alpha) > \left( \frac{2}{\Gamma(\alpha+1)} \right)^{-1/\alpha}$$

(approaching equality as $k \to 0$) and the tangent line at $\alpha = 1$ where the derivative was found to be $\nu^\prime(1) \approx 0.9680448$:

$$\nu(\alpha) \ge \nu(1) + (\alpha-1) \nu^\prime(1) \quad$$

(with equality at $k = 1$)

$$\nu(\alpha) \ge \log 2 + (\alpha-1) \left[\gamma - 2 \operatorname{Ei}(-\log 2) - \log \log 2\right]$$

where Ei is the [exponential integral](wikipedia://en/648614).[^o27][^o28]

Additionally, he showed that interpolations between bounds could provide excellent approximations or tighter bounds to the median, including an approximation that is exact at $\alpha = 1$ (where $\nu(1) = \log 2$) and has a maximum relative error less than 0.6%. Interpolated approximations and bounds are all of the form

$$\nu(\alpha) \approx \tilde{g}(\alpha)\nu_{L\infty}(\alpha) + (1 - \tilde{g}(\alpha)) \nu_U(\alpha)$$

where $\tilde{g}$ is an interpolating function running monotonially from 0 at low $\alpha$ to 1 at high $\alpha$, approximating an ideal, or exact, interpolator $g(\alpha)$:

$$g(\alpha) = \frac{\nu_U(\alpha) - \nu(\alpha)}{\nu_U(\alpha) - \nu_{L\infty}(\alpha)}$$

For the simplest interpolating function considered, a first-order rational function

$$\tilde{g}_1(\alpha) = \frac{\alpha}{b_0 + \alpha}$$

the tightest lower bound has

$$b_0 = \frac{\frac{8}{405} + e^{-\gamma} \log 2 - \frac{\log^2 2}{2}}{e^{-\gamma} - \log 2 + \frac{1}{3}} - \log 2 \approx 0.143472$$

and the tightest upper bound has

$$b_0 = \frac{e^{-\gamma} - \log 2 + \frac{1}{3}}{1 - \frac{e^{-\gamma} \pi^2}{12}} \approx 0.374654$$

The interpolated bounds are plotted (mostly inside the yellow region) in the [log–log plot](wikipedia://en/1659215) shown. Even tighter bounds are available using different interpolating functions, but not usually with closed-form parameters like these.[^o27]

### Summation {#Summation}

If $X_{i}$ has a $\operatorname{Gamma}(\alpha_{i}, \theta)$ distribution for $i = 1, 2, ..., N$ (i.e., all distributions have the same scale parameter $\theta$), then

$$\sum_{i=1}^N X_i \sim\mathrm{Gamma} \left( \sum_{i=1}^N \alpha_i, \theta \right)$$

provided all $X_{i}$ are [independent](https://en.wikipedia.org/wiki/Statistical_independence).

For the cases where the $X_{i}$ are [independent](https://en.wikipedia.org/wiki/Statistical_independence) but have different scale parameters, see Mathai[^o30] or Moschopoulos.[^o31]

The gamma distribution exhibits [infinite divisibility](wikipedia://en/13588803).

### Scaling {#Scaling}

If

$$X \sim \mathrm{Gamma}(\alpha, \theta),$$

then, for any $c > 0$,

$$cX \sim \mathrm{Gamma}(\alpha, c\,\theta),$$

by moment generating functions,

or equivalently, if

$$X \sim \mathrm{Gamma}\left( \alpha,\beta \right)$$

(shape-rate parameterization)

$$cX \sim \mathrm{Gamma}\left( \alpha, \frac \beta c \right),$$

Indeed, we know that if $X$ is an [exponential r.v.](wikipedia://en/45906) with rate $\beta$, then $cX$ is an exponential r.v. with rate $\beta/c$; the same thing is valid with Gamma variates (and this can be checked using the [moment-generating function](https://en.wikipedia.org/wiki/Moment-generating_function), see, e.g.,[these notes](http://www.stat.washington.edu/thompson/S341_10/Notes/week4.pdf), 10.4-(ii)): multiplication by a positive constant $c$ divides the rate (or, equivalently, multiplies the scale).

### Exponential family {#Exponential_family}

The gamma distribution is a two-parameter [exponential family](wikipedia://en/339174) with [natural parameters](https://en.wikipedia.org/wiki/Natural_parameters) $\alpha - 1$ and $-1/\theta$ (equivalently, $\alpha - 1$ and $-\beta$), and [natural statistics](https://en.wikipedia.org/wiki/Natural_statistics) $X$ and $\ln X$.

If the shape parameter $\alpha$ is held fixed, the resulting one-parameter family of distributions is a [natural exponential family](wikipedia://en/9413032).

### Logarithmic expectation and variance {#Logarithmic_expectation_and_variance}

One can show that

$$\operatorname{E}[\ln X] = \psi(\alpha) - \ln \beta$$

or equivalently,

$$\operatorname{E}[\ln X] = \psi(\alpha) + \ln \theta$$

where $\psi$ is the [digamma function](wikipedia://en/406935). Likewise,

$$\operatorname{var}[\ln X] = \psi^{(1)}(\alpha)$$

where $\psi^{(1)}$ is the [trigamma function](wikipedia://en/2036750).

This can be derived using the [exponential family](wikipedia://en/339174) formula for the [moment generating function of the sufficient statistic](wikipedia://en/339174#Moment_generating_function_of_the_sufficient_statistic), because one of the sufficient statistics of the gamma distribution is $\ln x$.

### Information entropy {#Information_entropy}

The [information entropy](https://en.wikipedia.org/wiki/Information_entropy) is

$$\begin{aligned} \operatorname{H}(X) & = \operatorname{E}[-\ln p(X)] \\[4pt] & = \operatorname{E}[-\alpha \ln \beta + \ln \Gamma(\alpha) - (\alpha-1)\ln X + \beta X] \\[4pt] & = \alpha - \ln \beta + \ln \Gamma(\alpha) + (1-\alpha)\psi(\alpha). \end{aligned}$$

In the $\alpha$, $\theta$ parameterization, the [information entropy](https://en.wikipedia.org/wiki/Information_entropy) is given by

$$\operatorname{H}(X) =\alpha + \ln \theta + \ln \Gamma(\alpha) + (1-\alpha)\psi(\alpha).$$

### Kullback–Leibler divergence {#Kullback–Leibler_divergence}

*Image: Gamma-KL-3D.png.* Illustration of the Kullback–Leibler (KL) divergence for two gamma PDFs. Here $\beta = \beta_{0} + 1$ which are set to $1, 2, 3, 4, 5,$ and $6$. The typical asymmetry for the KL divergence is clearly visible.

The [Kullback–Leibler divergence](wikipedia://en/1115052) (KL-divergence), of $\operatorname{Gamma}(\alpha_{p}, \beta_{p})$ ("true" distribution) from $\operatorname{Gamma}(\alpha_{q}, \beta_{q})$ ("approximating" distribution) is given by[^o37]

$$\begin{aligned} D_{\mathrm{KL}}(\alpha_p,\beta_p; \alpha_q, \beta_q) = {} & (\alpha_p-\alpha_q) \psi(\alpha_p) - \log\frac{\Gamma(\alpha_p)}{\Gamma(\alpha_q)} \\ & {} + \alpha_q \log\frac{\beta_p}{\beta_q} + \alpha_p\left(\frac{\beta_q}{\beta_p} - 1\right). \end{aligned}$$

Written using the $\alpha$, $\theta$ parameterization, the KL-divergence of $\operatorname{Gamma}(\alpha_{p}, \theta_{p})$ from $\operatorname{Gamma}(\alpha_{q}, \theta_{q})$ is given by

$$\begin{aligned} D_{\mathrm{KL}}(\alpha_p,\theta_p; \alpha_q, \theta_q) = {} & (\alpha_p-\alpha_q)\psi(\alpha_p) - \log\frac{\Gamma(\alpha_p)}{\Gamma(\alpha_q)} \\ & {} + \alpha_q \log\frac{\theta_q}{\theta_p} + \alpha_p \left(\frac{\theta_p}{\theta_q} - 1 \right). \end{aligned}$$

### Laplace transform {#Laplace_transform}

The [Laplace transform](wikipedia://en/18610) of the gamma PDF, which is related to the [moment-generating function](https://en.wikipedia.org/wiki/Moment-generating_function), is

$$F(s) = \operatorname E\left[ e^{-sX} \right] = \frac{1}{\left(1 + \theta s\right)^\alpha} = \left( \frac\beta{ \beta + s} \right)^\alpha$$

(where $X$ is a random variable distributed as $\operatorname{Gamma}(\alpha, \theta)$, or equivalently $\operatorname{Gamma}(\alpha, \beta)$).

### Full width at half maximum {#Full_width_at_half_maximum}

The [full width at half maximum](https://en.wikipedia.org/wiki/Full_width_at_half_maximum) of a unimodal probability distribution is the difference between the two values of the support that produce an output of half the function's maximum value when evaluated by the distribution's [probability density function](wikipedia://en/43487). For the gamma distribution with shape parameter $\alpha > 1$, the FWHM is[^o40]

$$\mathrm{FWHM}= (\alpha-1)\theta \left[ W_{0} \left(-\frac{2^{-1/(\alpha-1)}}{e}\right) - W_{-1} \left(-\frac{2^{-1/(\alpha-1)}}{e}\right) \right]$$

When $\alpha = 1$, the gamma distribution reduces to an [exponential distribution](wikipedia://en/45906), whose FWHM is

$$\mathrm{FWHM}=\theta \ln{2}$$

When $\alpha < 1$, the gamma distribution has no finite mode and therefore no well-defined FWHM.

## Related distributions {#Related_distributions}

### General {#General}

- Let $X_1, X_2, \ldots, X_n$ be $n$ independent and identically distributed random variables following an [exponential distribution](wikipedia://en/45906) with rate parameter *β*, then $\sum_i X_i \sim \operatorname{Gamma}(n,\beta)$ where *n* is the shape parameter and $\beta$ is the rate, and $\bar{X} = \frac{1}{n} \sum_i X_i \sim \operatorname{Gamma}(n, n\beta)$.
- If $X \sim \operatorname{Gamma}(1, \beta)$ (in the shape–rate parametrization), then $X$ has an [exponential distribution](wikipedia://en/45906) with rate parameter $\beta$. In the shape-scale parametrization, $X \sim \operatorname{Gamma}(1, \theta)$ has an exponential distribution with rate parameter $1/\theta$.
- If $X \sim \operatorname{Gamma}(\nu/2, 2)$ (in the shape–scale parametrization), then $X$ is identical to $\chi^{2}(\nu)$, the [chi-squared distribution](wikipedia://en/113424) with $\nu$ degrees of freedom. Conversely, if $Q \sim \chi^{2}(\nu)$ and $c$ is a positive constant, then $cQ \sim \operatorname{Gamma}(\nu/2, 2c)$.
- If $\theta = 1/\alpha$, one obtains the [Schulz-Zimm distribution](https://en.wikipedia.org/wiki/Schulz-Zimm_distribution), which is most prominently used to model polymer chain lengths.
- If $\alpha$ is an [integer](wikipedia://en/14563), the gamma distribution is an [Erlang distribution](wikipedia://en/199028) and is the probability distribution of the waiting time until the $\alpha$-th "arrival" in a one-dimensional [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) with intensity $1/\theta$. If

$$X \sim \Gamma(\alpha \in \mathbb{Z}, \theta), \qquad Y \sim \operatorname{Pois}\left(\frac x \theta \right),$$

then

$$\Pr(X > x) = \Pr(Y < \alpha).$$

- If $X$ has a [Maxwell–Boltzmann distribution](wikipedia://en/19830) with parameter $a$, then

$$X^2 \sim \Gamma{\left(\tfrac{3}{2}, 2a^2\right)}.$$

- If $X \sim \operatorname{Gamma}(\alpha, \theta)$, then $\exp X$ follows a log-gamma distribution.[^o43]
- If $X \sim \operatorname{Gamma}(\alpha, \theta)$, then $\log X$ follows an exponential-gamma (abbreviated exp-gamma) distribution.[^o44] It is sometimes incorrectly referred to as the log-gamma distribution.[^o45] Formulas for its mean and variance are in the section #Logarithmic expectation and variance.
- If $X \sim \operatorname{Gamma}(\alpha, \theta)$, then $\sqrt{X}$ follows a [generalized gamma distribution](wikipedia://en/24553589) with parameters $p = 2$, $d = 2\alpha$, and $a = \sqrt{\theta}$.
- More generally, if $X \sim \operatorname{Gamma}(\alpha,\theta)$, then $X^q$ for $q > 0$ follows a [generalized gamma distribution](wikipedia://en/24553589) with parameters $p = 1/q$, $d = \alpha/q$, and $a = \theta^q$.
- If $X \sim \operatorname{Gamma}(\alpha, \theta)$ with shape $\alpha$ and scale $\theta$, then $1/X \sim \operatorname{Inv}-\operatorname{Gamma}(\alpha, \theta^{-1})$ (see [Inverse-gamma distribution](wikipedia://en/1653565) for derivation).
- Parametrization 1: If $X_k \sim \Gamma(\alpha_k,\theta_k)\,$ are independent, then $\frac{\alpha_2\theta_2 X_1}{\alpha_1\theta_1 X_2} \sim \mathrm{F}(2\alpha_1, 2\alpha_2)$, or equivalently, $\frac{X_1}{X_2} \sim \beta'\left(\alpha_1, \alpha_2, 1, \frac{\theta_1}{\theta_2}\right)$
- Parametrization 2: If $X_k \sim \Gamma(\alpha_k,\beta_k)\,$ are independent, then $\frac{\alpha_2\beta_1 X_1}{\alpha_1\beta_2 X_2} \sim \mathrm{F}(2\alpha_1, 2\alpha_2)$, or equivalently, $\frac{X_1}{X_2} \sim \beta'\left(\alpha_1, \alpha_2, 1, \frac{\beta_2}{\beta_1}\right)$
- If $X \sim \operatorname{Gamma}(\alpha, \theta)$ and $Y \sim \operatorname{Gamma}(\beta, \theta)$ are independently distributed, then $X/(X + Y)$ has a [beta distribution](wikipedia://en/207074) with parameters $\alpha$ and $\beta$, and $X/(X + Y)$ is independent of $X + Y$, which is $\operatorname{Gamma}(\alpha + \beta, \theta)$-distributed.
- If $X_n \sim \text{Beta}(\alpha,n\beta)\,$ and $Y_n = nX_n$, then $Y_n$ converges in distribution to $\text{Gamma}(\alpha,\beta)$ defined under parametrization 2.
- If $X_{i} \sim \operatorname{Gamma}(\alpha_{i}, 1)$ are independently distributed, then the vector ($X_{1}/S, ..., X_{n}/S)$, where $S = X_{1} + ... + X_{n}$, follows a [Dirichlet distribution](wikipedia://en/1117833) with parameters $\alpha_{1}, ..., \alpha_{n}$.
- For large $\alpha$ the gamma distribution converges to [normal distribution](wikipedia://en/21462) with mean $\mu = \alpha\theta$ and variance $\sigma^{2} = \alpha\theta^{2}$.
- The gamma distribution is the [conjugate prior](wikipedia://en/846412) for the precision of the [normal distribution](wikipedia://en/21462) with known [mean](https://en.wikipedia.org/wiki/Mean).
- The [matrix gamma distribution](wikipedia://en/35397405) and the [Wishart distribution](wikipedia://en/364996) are multivariate generalizations of the gamma distribution (samples are positive-definite matrices rather than positive real numbers).
- The gamma distribution is a special case of the [generalized gamma distribution](wikipedia://en/24553589), the [generalized integer gamma distribution](wikipedia://en/33925165), and the [generalized inverse Gaussian distribution](wikipedia://en/2682998).
- Among the discrete distributions, the [negative binomial distribution](wikipedia://en/45177) is sometimes considered the discrete analog of the gamma distribution.
- [Tweedie distributions](wikipedia://en/15204099) – the gamma distribution is a member of the family of Tweedie [exponential dispersion models](wikipedia://en/15670753).
- For the shape-scale parameterization $x|\theta \sim \Gamma(\alpha,\theta)$, if the scale parameter $\theta \sim IG(b,1)$ where $IG$ denotes the [Inverse-gamma distribution](wikipedia://en/1653565), then the marginal distribution $x \sim \beta'(\alpha,b)$ where $\beta'$ denotes the [Beta prime distribution](wikipedia://en/3126406).

### Compound gamma {#Compound_gamma}

If the shape parameter of the gamma distribution is known, but the inverse-scale parameter is unknown, then a gamma distribution for the inverse scale forms a conjugate prior. The [compound distribution](https://en.wikipedia.org/wiki/Compound_distribution), which results from integrating out the inverse scale, has a closed-form solution known as the [compound gamma distribution](https://en.wikipedia.org/wiki/Compound_gamma_distribution).[^o47]

If, instead, the shape parameter is known but the mean is unknown, with the prior of the mean being given by another gamma distribution, then it results in [K-distribution](wikipedia://en/25283098).

## Statistical inference {#Statistical_inference}

### Parameter estimation {#Parameter_estimation}

#### Maximum likelihood estimation {#Maximum_likelihood_estimation}

The likelihood function for $N$ [iid](https://en.wikipedia.org/wiki/Iid) observations $(x_{1}, ..., x_{N})$ is

$$L(\alpha, \theta) = \prod_{i=1}^N f(x_i;\alpha,\theta)$$

from which we calculate the log-likelihood function

$$\ell(\alpha, \theta) = (\alpha - 1) \sum_{i=1}^N \ln x_i - \sum_{i=1}^N \frac{x_i} \theta - N\alpha\ln \theta - N\ln \Gamma(\alpha)$$

Finding the maximum with respect to $\theta$ by taking the derivative and setting it equal to zero yields the [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimator of the $\theta$ parameter, which equals the [sample mean](https://en.wikipedia.org/wiki/Sample_mean) $\bar{x}$ divided by the shape parameter $\alpha$:

$$\hat{\theta} = \frac{1}{\alpha N}\sum_{i=1}^N x_i = \frac{\bar{x}}{\alpha}$$

Substituting this into the log-likelihood function gives

$$\ell(\alpha) = (\alpha-1)\sum_{i=1}^N \ln x_i -N\alpha - N\alpha\ln \frac{\sum_i x_i}{\alpha N} - N\ln \Gamma(\alpha)$$

We need at least two samples: $N\ge2$, because for $N=1$, the function $\ell(\alpha)$ increases without bounds as $\alpha\to\infty$. For $\alpha>0$, it can be verified that $\ell(\alpha)$ is strictly [concave](wikipedia://en/263321), by using [inequality properties of the polygamma function](wikipedia://en/406932#Inequalities). Finding the maximum with respect to $\alpha$ by taking the derivative and setting it equal to zero yields

$$\begin{aligned} \ln \alpha - \psi(\alpha) &= \ln\left(\frac{1}{N}\sum_{i=1}^N x_i\right) - \frac 1 N \sum_{i=1}^N \ln x_i \\[1ex] &= \ln \bar{x} - \overline{\ln x} \end{aligned}$$

where $\psi$ is the [digamma function](wikipedia://en/406935) and $\overline{\ln x}$ is the sample mean of $\ln x$. There is no closed-form solution for $\alpha$. The function is numerically very well behaved, so if a numerical solution is desired, it can be found using, for example, [Newton's method](wikipedia://en/22145). An initial value of $k$ can be found either using the [method of moments](wikipedia://en/2175504), or using the approximation

$$\ln \alpha - \psi(\alpha) \approx \frac{1}{2\alpha}\left(1 + \frac{1}{6\alpha + 1} \right)$$

If we let

$$\begin{aligned} s &= \ln \left(\frac 1 N \sum_{i=1}^N x_i\right) - \frac 1 N \sum_{i=1}^N \ln x_i \\[1ex] &= \ln \bar{x} - \overline{\ln x} \end{aligned}$$

then $\alpha$ is approximately

$$k \approx \frac{3 - s + \sqrt{\left(s - 3\right)^2 + 24s}}{12s}$$

which is within 1.5% of the correct value.[^o51] An explicit form for the Newton–Raphson update of this initial guess is:[^o52]

$$\alpha \leftarrow \alpha - \frac{ \ln \alpha - \psi(k) - s }{ \frac 1 \alpha - \psi\prime(\alpha) }.$$

At the maximum-likelihood estimate $(\hat \alpha,\hat\theta)$, the expected values for $x$ and $\ln x$ agree with the empirical averages:

$$\begin{aligned} \hat \alpha\hat\theta &= \bar x &&\text{and} & \psi(\hat \alpha)+\ln \hat\theta &= \overline{\ln x}. \end{aligned}$$

##### Caveat for small shape parameter {#Caveat_for_small_shape_parameter}

For data, $(x_1,\ldots,x_N)$, that is represented in a [floating point](https://en.wikipedia.org/wiki/Floating_point) format that underflows to 0 for values smaller than $\varepsilon$, the logarithms that are needed for the maximum-likelihood estimate will cause failure if there are any underflows. If we assume the data was generated by a gamma distribution with cdf $F(x;\alpha,\theta)$, then the probability that there is at least one underflow is:

$$\Pr(\text{underflow}) = 1-(1-F(\varepsilon;\alpha,\theta))^N$$

This probability will approach 1 for small $\alpha$ and large $N$. For example, at $\alpha=10^{-2}$, $N=10^4$ and $\varepsilon=2.25\times10^{-308}$, $\Pr(\text{underflow})\approx 0.9998$. A workaround is to instead have the data in logarithmic format.

In order to test an implementation of a maximum-likelihood estimator that takes logarithmic data as input, it is useful to be able to generate non-underflowing logarithms of random gamma variates, when $\alpha<1$. Following the implementation in `scipy.stats.loggamma`, this can be done as follows:[^o85] sample $Y\sim\text{Gamma}(\alpha+1,\theta)$ and $U\sim\text{Uniform}$ independently. Then the required logarithmic sample is $Z=\ln(Y)+\ln(U)/\alpha$, so that $\exp(Z)\sim\text{Gamma}(k,\theta)$.

#### Closed-form estimators {#Closed-form_estimators}

There exist consistent closed-form estimators of $\alpha$ and $\theta$ that are derived from the likelihood of the [generalized gamma distribution](wikipedia://en/24553589).[^o55]

The estimate for the shape $\alpha$ is

$$\hat{\alpha} = \frac{N \sum\limits_{i=1}^N x_i}{N \sum\limits_{i=1}^N x_i \ln x_i - \sum\limits_{i=1}^N x_i \sum\limits_{i=1}^N \ln x_i}$$

and the estimate for the scale $\theta$ is

$$\hat{\theta} = \frac{1}{N^2} \left(N \sum_{i=1}^N x_i \ln x_i - \sum_{i=1}^N x_i \sum_{i=1}^N \ln x_i\right)$$

Using the sample mean of $x$, the sample mean of $\ln x$, and the sample mean of the product $x\cdot\ln x$ simplifies the expressions to:

$$\hat{\alpha} = \frac{\bar{x}}{\hat{\theta}}$$

$$\hat{\theta} = \overline{x\ln x} - \bar{x} \overline{\ln x}.$$

If the rate parameterization is used, the estimate of $\hat{\beta} = 1/\hat{\theta}$.

These estimators are not strictly maximum likelihood estimators, but are instead referred to as mixed type log-moment estimators. They have however similar efficiency as the maximum likelihood estimators.

Although these estimators are consistent, they have a small bias. A bias-corrected variant of the estimator for the scale $\theta$ is

$$\tilde{\theta} = \frac{N}{N - 1} \hat{\theta}$$

A bias correction for the shape parameter $\alpha$ is given as[^o56]

$$\tilde{\alpha} = \hat{\alpha} - \frac{1}{N} \left(3 \hat{\alpha} - \frac{2}{3} \left(\frac{\hat{\alpha}}{1 + \hat{\alpha}}\right) - \frac{4}{5} \frac{\hat{\alpha}}{(1 + \hat{\alpha})^2} \right)$$

#### Bayesian minimum mean squared error {#Bayesian_minimum_mean_squared_error}

With known $\alpha$ and unknown $\theta$, the posterior density function for theta (using the standard scale-invariant [prior](wikipedia://en/472877) for $\theta$) is

$$\Pr(\theta \mid \alpha, x_1, \dots, x_N) \propto \frac 1 \theta \prod_{i=1}^N f(x_i; \alpha, \theta)$$

Denoting

$$y \equiv \sum_{i=1}^Nx_i , \qquad \Pr(\theta \mid \alpha, x_1, \dots, x_N) = C(x_i) \theta^{-N \alpha-1} e^{-y/\theta}$$

where the $C$ (integration) constant does not depend on $\theta$. The form of the posterior density reveals that $1 / \theta$ is gamma-distributed with shape parameter $N\alpha + 2$ and rate parameter $y$. Integration with respect to $\theta$ can be carried out using a change of variables to find the integration constant

$$\begin{aligned} \int_0^\infty \theta^{-N\alpha - 1 + m} e^{-y/\theta}\, d\theta &= \int_0^\infty x^{N\alpha - 1 - m} e^{-xy} \, dx \\ &= y^{-(N\alpha - m)} \Gamma(N\alpha - m) \! \end{aligned}$$

The moments can be computed by taking the ratio ($m$ by $m = 0$)

$$\operatorname{E} [x^m] = \frac {\Gamma (N\alpha - m)} {\Gamma(N\alpha)} y^m$$

which shows that the mean ± standard deviation estimate of the posterior distribution for $\theta$ is

$$\frac y {N\alpha - 1} \pm \sqrt{\frac {y^2} {\left(N\alpha - 1\right)^2 (N\alpha - 2)}}.$$

### Bayesian inference {#Bayesian_inference}

#### Conjugate prior {#Conjugate_prior}

In [Bayesian inference](wikipedia://en/49571), the **gamma distribution** is the [conjugate prior](wikipedia://en/846412) to many likelihood distributions: the [Poisson](wikipedia://en/23009144), [exponential](wikipedia://en/45906), [normal](wikipedia://en/21462) (with known mean), [Pareto](wikipedia://en/53057), gamma with known shape $\sigma$, [inverse gamma](https://en.wikipedia.org/wiki/Inverse_gamma) with known shape parameter, and [Gompertz](wikipedia://en/20101246) with known scale parameter.

The gamma distribution's [conjugate prior](wikipedia://en/846412) is:[^o60]

$$p(\alpha,\theta \mid p, q, r, s) = \frac{1}{Z} \frac{p^{\alpha-1} e^{-\theta^{-1} q}}{\Gamma(\alpha)^r \theta^{\alpha s}},$$

where $Z$ is the normalizing constant with no closed-form solution. The posterior distribution can be found by updating the parameters as follows:

$$\begin{aligned} p' &= p\prod\nolimits_i x_i,\\ q' &= q + \sum\nolimits_i x_i,\\ r' &= r + n,\\ s' &= s + n, \end{aligned}$$

where $n$ is the number of observations, and $x_{i}$ is the $i$-th observation from the gamma distribution.

## Occurrence and applications {#Occurrence_and_applications}

Consider a sequence of events, with the waiting time for each event being an exponential distribution with rate $\beta$. Then the waiting time for the $n$-th event to occur is the gamma distribution with integer shape $\alpha = n$. This construction of the gamma distribution allows it to model a wide variety of phenomena where several sub-events, each taking time with exponential distribution, must happen in sequence for a major event to occur.[^o62] Examples include the waiting time of [cell-division events](https://en.wikipedia.org/wiki/Cell_division),[^o63] number of compensatory mutations for a given mutation,[^o64] waiting time until a repair is necessary for a hydraulic system,[^o65] and so on.

In biophysics, the dwell time between steps of a molecular motor like [ATP synthase](https://en.wikipedia.org/wiki/ATP_synthase) is nearly exponential at constant ATP concentration, revealing that each step of the motor takes a single ATP hydrolysis. If there were n ATP hydrolysis events, then it would be a gamma distribution with degree n.[^o66]

The gamma distribution has been used to model the size of [insurance claims](https://en.wikipedia.org/wiki/Insurance_policy)[^o67] and rainfalls.[^o68] This means that aggregate insurance claims and the amount of rainfall accumulated in a reservoir are modelled by a [gamma process](wikipedia://en/4183150) – much like the [exponential distribution](wikipedia://en/45906) generates a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process).

The gamma distribution is also used to model errors in multi-level [Poisson regression](wikipedia://en/2708102) models because a [mixture](wikipedia://en/708242) of [Poisson distributions](wikipedia://en/23009144) with gamma-distributed rates has a known closed form distribution, called [negative binomial](https://en.wikipedia.org/wiki/Negative_binomial).

In wireless communication, the gamma distribution is used to model the [multi-path fading](https://en.wikipedia.org/wiki/Multi-path_fading) of signal power; see also [Rayleigh distribution](wikipedia://en/262296) and [Rician distribution](https://en.wikipedia.org/wiki/Rician_distribution).

In [oncology](https://en.wikipedia.org/wiki/Oncology), the age distribution of [cancer](https://en.wikipedia.org/wiki/Cancer) [incidence](https://en.wikipedia.org/wiki/Disease_incidence) often follows the gamma distribution, wherein the shape and scale parameters predict, respectively, the number of [driver events](https://en.wikipedia.org/wiki/Carcinogenesis) and the time interval between them.[^o69][^o70]

In [neuroscience](https://en.wikipedia.org/wiki/Neuroscience), the gamma distribution is often used to describe the distribution of [inter-spike intervals](https://en.wikipedia.org/wiki/Temporal_coding).[^o71][^o72]

In [bacterial](https://en.wikipedia.org/wiki/Bacterial_genetics) [gene expression](https://en.wikipedia.org/wiki/Gene_expression) where protein production can occur in bursts, the copy number of a given protein often follows the gamma distribution, where the shape and scale parameters are, respectively, the mean number of bursts per cell cycle and the mean number of [protein molecules](https://en.wikipedia.org/wiki/Protein_molecule) produced per burst.[^o73]

In [genomics](https://en.wikipedia.org/wiki/Genomics), the gamma distribution was applied in [peak calling](https://en.wikipedia.org/wiki/Peak_calling) step (i.e., in recognition of signal) in [ChIP-chip](https://en.wikipedia.org/wiki/ChIP-chip)[^o74] and [ChIP-seq](https://en.wikipedia.org/wiki/ChIP-seq)[^o75] data analysis.

In Bayesian statistics, the gamma distribution is widely used as a [conjugate prior](wikipedia://en/846412). It is the conjugate prior for the [precision](wikipedia://en/24467258) (i.e. inverse of the variance) of a [normal distribution](wikipedia://en/21462). It is also the conjugate prior for the [exponential distribution](wikipedia://en/45906).

In [phylogenetics](https://en.wikipedia.org/wiki/Phylogenetics), the gamma distribution is the most commonly used approach to model among-sites rate variation[^o76] when [maximum likelihood](wikipedia://en/3986130#Maximum_likelihood), [Bayesian](wikipedia://en/7022979), or [distance matrix methods](wikipedia://en/12955880) are used to estimate phylogenetic trees. Phylogenetic analyzes that use the gamma distribution to model rate variation estimate a single parameter from the data because they limit consideration to distributions where $\alpha = \beta$. This parameterization means that the mean of this distribution is 1 and the variance is $1/\alpha$. Maximum likelihood and Bayesian methods typically use a discrete approximation to the continuous gamma distribution.[^o77][^o78]

## Random variate generation {#Random_variate_generation}

Given the scaling property above, it is enough to generate gamma variables with $\theta = 1$, as we can later convert to any value of $\beta$ with a simple division.

Suppose we wish to generate random variables from $\operatorname{Gamma}(n + \delta, 1)$, where n is a non-negative integer and $0 < \delta < 1$. Using the fact that a $\operatorname{Gamma}(1, 1)$ distribution is the same as an $\operatorname{Exp}(1)$ distribution, and noting the method of [generating exponential variables](wikipedia://en/45906#Random_variate_generation), we conclude that if $U$ is [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on (0, 1\], then $-\ln U$ is distributed $\operatorname{Gamma}(1, 1)$ (i.e. [inverse transform sampling](wikipedia://en/45705)). Now, using the "$\alpha$-addition" property of gamma distribution, we expand this result:

$$-\sum_{k=1}^n \ln U_k \sim \Gamma(n, 1)$$

where $U_{k}$ are all uniformly distributed on (0, 1\] and [independent](https://en.wikipedia.org/wiki/Statistical_independence). All that is left now is to generate a variable distributed as $\operatorname{Gamma}(\delta, 1)$ for $0 < \delta < 1$ and apply the "$\alpha$-addition" property once more. This is the most difficult part.

Random generation of gamma variates is discussed in detail by Devroye,[^o80] noting that none are uniformly fast for all shape parameters. For small values of the shape parameter, the algorithms are often not valid.[^o80] For arbitrary values of the shape parameter, one can apply the Ahrens and Dieter[^o81] modified acceptance-rejection method Algorithm GD (shape $\alpha \ge 1$), or transformation method[^o82] when $0 < \alpha < 1$. Also see Cheng and Feast Algorithm GKM 3[^o83] or Marsaglia's squeeze method.[^o84]

The following is a version of the Ahrens-Dieter [acceptance–rejection method](wikipedia://en/502022):[^o81]

1. Generate $U$, $V$ and $W$ as [iid](https://en.wikipedia.org/wiki/Iid) uniform (0, 1\] variates.
1. If $U\le\frac e {e+\delta}$ then $\xi=V^{1/\delta}$ and $\eta=W\xi^{\delta-1}$. Otherwise, $\xi=1-\ln V$ and $\eta=We^{-\xi}$.
1. If $\eta>\xi^{\delta-1}e^{-\xi}$ then go to step 1.
1. $\xi$ is distributed as $\Gamma(\delta, 1)$.

A summary of this is

$$\theta \left( \xi - \sum_{i=1}^{\lfloor \alpha \rfloor} \ln U_i \right) \sim \Gamma (\alpha, \theta)$$

where $\scriptstyle \lfloor \alpha \rfloor$ is the integer part of $\alpha$, $\xi$ is generated via the algorithm above with $\delta = \{\alpha\}$ (the fractional part of $\alpha$) and the $U_{k}$ are all independent.

While the above approach is technically correct, Devroye notes that it is linear in the value of $\alpha$ and generally is not a good choice. Instead, he recommends using either rejection-based or table-based methods, depending on context.[^o80]

For example, Marsaglia's simple transformation-rejection method relying on one normal variate $X$ and one uniform variate $U$:[^o85]

1. Set $d = a - \frac13$ and $c = \frac1{\sqrt{9d}}$.
1. Set $v=(1+cX)^3$.
1. If $v > 0$ and $\ln U < \frac{X^2}2 + d - dv + d\ln v$ return $dv$, else go back to step 2.

With $1 \le a = \alpha$ generates a gamma distributed random number in time that is approximately constant with $\alpha$. The acceptance rate does depend on $\alpha$, with an acceptance rate of 0.95, 0.98, and 0.99 for *α* = 1, 2, and 4. For $\alpha < 1$, one can use $\gamma_\alpha = \gamma_{1+\alpha} U^{1/\alpha}$ to boost $k$ to be usable with this method.

In [Matlab](https://en.wikipedia.org/wiki/Matlab) numbers can be generated using the function `gamrnd()`, which uses the *α*, *θ* representation.
