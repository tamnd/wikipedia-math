# Mixed tensor

::: {#o1 .subject cue=lead name="Mixed tensor"}

In [tensor analysis](https://en.wikipedia.org/wiki/Tensor_analysis), a **mixed tensor** is a [tensor](wikipedia://en/29965) which is neither strictly [covariant](wikipedia://en/202886) nor strictly [contravariant](wikipedia://en/202886); at least one of the indices of a mixed tensor will be a subscript (covariant) and at least one of the indices will be a superscript (contravariant).

:::

A mixed tensor of **type** or **valence** $\binom{M}{N}$, also written "type (*M*, *N*)", with both *M* > 0 and *N* > 0, is a tensor which has *M* contravariant indices and *N* covariant indices. Such a tensor can be defined as a [linear function](https://en.wikipedia.org/wiki/Linear_operator) which maps an (*M* + *N*)-tuple of *M* [one-forms](wikipedia://en/314692) and *N* [vectors](https://en.wikipedia.org/wiki/Vector_%28geometry%29) to a [scalar](wikipedia://en/3588331).

## Changing the tensor type {#Changing_the_tensor_type}

Consider the following octet of related tensors:

$$T_{\alpha \beta \gamma}, \ T_{\alpha \beta} {}^\gamma, \ T_\alpha {}^\beta {}_\gamma, \ T_\alpha {}^{\beta \gamma}, \ T^\alpha {}_{\beta \gamma}, \ T^\alpha {}_\beta {}^\gamma, \ T^{\alpha \beta} {}_\gamma, \ T^{\alpha \beta \gamma} .$$

The first one is covariant, the last one contravariant, and the remaining ones mixed. Notationally, these tensors differ from each other by the covariance/contravariance of their indices. A given contravariant index of a tensor can be lowered using the [metric tensor](wikipedia://en/195795) $g_{\mu\nu}$, and a given covariant index can be raised using the inverse metric tensor $g^{\mu\nu}$. Thus, $g_{\mu\nu}$ could be called the *index lowering operator* and $g^{\mu\nu}$ the *index raising operator*.

Generally, the covariant metric tensor, contracted with a tensor of type (*M*, *N*), yields a tensor of type (*M* − 1, *N* + 1), whereas its contravariant inverse, contracted with a tensor of type (*M*, *N*), yields a tensor of type (*M* + 1, *N* − 1).

::: {#o4 .example cue=heading name="Examples"}

### Examples {#Examples}

As an example, a mixed tensor of type (1, 2) can be obtained by raising an index of a covariant tensor of type (0, 3),

$$T_{\alpha \beta} {}^\lambda = T_{\alpha \beta \gamma} \, g^{\gamma \lambda} ,$$

where $T_{\alpha \beta} {}^\lambda$ is the same tensor as $T_{\alpha \beta} {}^\gamma$, because

$$T_{\alpha \beta} {}^\lambda \, \delta_\lambda {}^\gamma = T_{\alpha \beta} {}^\gamma,$$

with Kronecker $\delta$ acting here like an identity matrix.

Likewise,

$$T_\alpha {}^\lambda {}_\gamma = T_{\alpha \beta \gamma} \, g^{\beta \lambda},$$

$$T_\alpha {}^{\lambda \epsilon} = T_{\alpha \beta \gamma} \, g^{\beta \lambda} \, g^{\gamma \epsilon},$$

$$T^{\alpha \beta} {}_\gamma = g_{\gamma \lambda} \, T^{\alpha \beta \lambda},$$

$$T^\alpha {}_{\lambda \epsilon} = g_{\lambda \beta} \, g_{\epsilon \gamma} \, T^{\alpha \beta \gamma}.$$

Raising an index of the metric tensor is equivalent to contracting it with its inverse, yielding the [Kronecker delta](wikipedia://en/182890),

$$g^{\mu \lambda} \, g_{\lambda \nu} = g^\mu {}_\nu = \delta^\mu {}_\nu ,$$

so any mixed version of the metric tensor will be equal to the Kronecker delta, which will also be mixed.

:::
