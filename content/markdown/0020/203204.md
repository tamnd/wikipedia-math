# List of order structures in mathematics

::: {#o1 .subject cue=lead name="List of order structures in mathematics"}

In [mathematics](wikipedia://en/18831), and more specifically in [order theory](wikipedia://en/361924), several different types of [ordered set](https://en.wikipedia.org/wiki/Ordered_set) have been studied. They include:

:::

::: {#o2 .entry cue=list-entry name="Cyclic order"}

- [Cyclic orders](wikipedia://en/434673), orderings in which triples of elements are either clockwise or counterclockwise

:::

::: {#o3 .entry cue=list-entry name="Lattices"}

- [Lattices](wikipedia://en/469304), partial orders in which each pair of elements has a greatest lower bound and a least upper bound. Many different types of lattice have been studied; see [map of lattices](wikipedia://en/13463881) for a list.

:::

::: {#o4 .entry cue=list-entry name="Partially ordered set"}

- [Partially ordered sets](wikipedia://en/23572) (or *posets*), orderings in which some pairs are comparable and others might not be

:::

::: {#o5 .entry cue=list-entry name="Preorder"}

- [Preorders](wikipedia://en/23582), a generalization of partial orders allowing ties (represented as equivalences and distinct from incomparabilities)

:::

::: {#o6 .entry cue=list-entry name="Semiorder"}

- [Semiorders](wikipedia://en/28771796), partial orders determined by comparison of numerical values, in which values that are too close to each other are incomparable; a subfamily of partial orders with certain restrictions

:::

::: {#o7 .entry cue=list-entry name="Total order"}

- [Total orders](wikipedia://en/30330), orderings that specify, for every two distinct elements, which one is less than the other

:::

::: {#o8 .entry cue=list-entry name="Weak order"}

- [Weak orders](https://en.wikipedia.org/wiki/Weak_order), generalizations of total orders allowing ties (represented either as equivalences or, in strict weak orders, as transitive incomparabilities)

:::

::: {#o9 .entry cue=list-entry name="Well-order"}

- [Well-orders](wikipedia://en/33456), total orders in which every non-empty subset has a least element

:::

::: {#o10 .entry cue=list-entry name="Well-quasi-ordering"}

- [Well-quasi-orderings](wikipedia://en/739775), a class of preorders generalizing the well-orders

:::
