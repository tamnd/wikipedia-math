# Flooding algorithm

::: {#o1 .subject cue=lead name="Flooding algorithm"}

A **flooding algorithm** is an [algorithm](wikipedia://en/775) for distributing material to every part of a [graph](wikipedia://en/325806). The name derives from the concept of inundation by a [flood](https://en.wikipedia.org/wiki/Flood). Flooding algorithms are used in [computer networking](https://en.wikipedia.org/wiki/Flooding_%28computer_networking%29) and [graphics](wikipedia://en/11635). Flooding algorithms are also useful for solving many mathematical problems, including [maze](https://en.wikipedia.org/wiki/Maze) problems and many problems in [graph theory](wikipedia://en/12401).

:::

Different flooding algorithms can be applied for different problems, and run with different [time complexities](https://en.wikipedia.org/wiki/Time_complexities). For example, the [flood fill](wikipedia://en/11635) algorithm is a simple but relatively robust algorithm that works for intricate geometries and can determine which part of the (target) area that is [connected](wikipedia://en/325802#Connectivity) to a given (source) node in a multi-dimensional [array](https://en.wikipedia.org/wiki/Array_data_structure), and is trivially generalized to arbitrary graph structures. If there instead are several source nodes, there are no obstructions in the geometry represented in the multi-dimensional array, and one wishes to segment the area based on which of the source nodes the target nodes are closest to, while the flood fill algorithm can still be used, the [jump flooding algorithm](https://en.wikipedia.org/wiki/Jump_flooding_algorithm) is potentially much faster as it has a lower time complexity. Unlike the flood fill algorithm, however, the jump flooding algorithm cannot trivially be generalized to unstructured graphs.[^o2][^o3]
