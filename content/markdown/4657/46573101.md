# Nodal surface

::: {#o1 .subject cue=lead name="Nodal surface"}

In [algebraic geometry](wikipedia://en/1997), a **nodal surface** is a surface in a (usually [complex](wikipedia://en/762977)) [projective space](wikipedia://en/242135) whose only singularities are [nodes](wikipedia://en/981915#Nodes). A major problem about them is to find the maximum number of nodes of a nodal surface of given degree.

:::

The following table gives some known upper and lower bounds for the maximal number of nodes on a complex surface of given degree. In degree 7, 9, 11, and 13, the upper bound is given by (Varchenko 1983), which is better than the one by (Miyaoka 1984).

::: {#o4 .table cue=table}

| Degree | Lower bound | Surface achieving lower bound | Upper bound |
|---|---|---|---|
| 1 | 0 | Plane | 0 |
| 2 | 1 | [Conical surface](wikipedia://en/706244) | 1 |
| 3 | 4 | [Cayley's nodal cubic surface](wikipedia://en/5202189) | 4 |
| 4 | 16 | [Kummer surface](wikipedia://en/647758) | 16 |
| 5 | 31 | [Togliatti surface](wikipedia://en/20705037) | 31 (Beauville) |
| 6 | 65 | [Barth sextic](https://en.wikipedia.org/wiki/Barth_sextic) | 65 (Jaffe and Ruberman) |
| 7 | 99 | [Labs septic](wikipedia://en/46465164) | 104 |
| 8 | 168 | [Endraß surface](https://en.wikipedia.org/wiki/Endraß_surface) | 174 |
| 9 | 226 | Labs | 246 |
| 10 | 345 | [Barth decic](https://en.wikipedia.org/wiki/Barth_decic) | 360 |
| 11 | 425 | Chmutov | 480 |
| 12 | 600 | [Sarti surface](wikipedia://en/23341987) | 645 |
| 13 | 732 | Chmutov | 829 |
| *d* |  |  | $\tfrac49 d (d-1)^2$ (Miyaoka 1984) |
| *d* ≡ 0 (mod 3) | $\tbinom d2 \lfloor \tfrac d2 \rfloor + (\tfrac{d^2}3 - d + 1)\lfloor\tfrac{d-1}2\rfloor$ | Escudero |  |
| *d* ≡ ±1 (mod 6) | $(5d^3 - 14d^2 + 13d - 4)/12$ | Chmutov |  |
| *d* ≡ ±2 (mod 6) | $(5d^3 - 13d^2 + 16d - 8)/12$ | Chmutov |  |

:::
