# Luzin space

::: {#o1 .subject cue=lead name="Luzin space"}

In [mathematics](wikipedia://en/18831), a **Luzin space** (or **Lusin space**), named for [N. N. Luzin](wikipedia://en/576228), is an [uncountable](https://en.wikipedia.org/wiki/Uncountable) topological [T<sub>1</sub> space](wikipedia://en/148721) without [isolated points](wikipedia://en/390557) in which every [nowhere-dense](https://en.wikipedia.org/wiki/Nowhere-dense) subset is [countable](https://en.wikipedia.org/wiki/Countable). There are many minor variations of this definition in use: the T<sub>1</sub> condition can be replaced by [T<sub>2</sub> or T<sub>3</sub>](wikipedia://en/40117302#Main_definitions), and some authors allow a countable or even arbitrary number of isolated points.

:::

The existence of a Luzin space is independent of the axioms of [ZFC](https://en.wikipedia.org/wiki/ZFC). (Lusin 1914) showed that the [continuum hypothesis](wikipedia://en/5705) implies that a Luzin space exists. (Kunen 1977) showed that assuming [Martin's axiom](wikipedia://en/1550783) and the negation of the [continuum hypothesis](wikipedia://en/5705), there are no [Hausdorff](wikipedia://en/13637) Luzin spaces.

## In real analysis {#In_real_analysis}

In [real analysis](wikipedia://en/26478) and [descriptive set theory](wikipedia://en/396619), a **Luzin set** (or **Lusin set**), is defined as an uncountable subset $A$ of the [reals](https://en.wikipedia.org/wiki/Real_numbers) $\mathbb{R}$ such that every uncountable subset of $A$ is [nonmeager](https://en.wikipedia.org/wiki/Nonmeager) (that is, of the second Baire category) in $\mathbb{R}.$ Equivalently, $A$ is an uncountable subset of $\mathbb{R}$ that meets every [meager subset](https://en.wikipedia.org/wiki/Meager_subset) of $\mathbb{R}$ (i.e., first category set) in only countably many points. Equivalently, $A$ is an uncountable subset of $\mathbb{R}$ that meets every [nowhere dense](https://en.wikipedia.org/wiki/Nowhere_dense) subset of $\mathbb{R}$ (i.e., first category set) in only countably many points.

Luzin proved that, if the continuum hypothesis holds, then every nonmeager set in $\mathbb{R}$ has a Luzin [subset](wikipedia://en/27631). Obvious properties of a Luzin set are that it must be nonmeager (otherwise the set itself is an uncountable [meager subset](wikipedia://en/226975)) and of [measure zero](https://en.wikipedia.org/wiki/Measure_zero), because every set of positive measure contains a meager set that also has positive measure, and is therefore uncountable.

A **weakly Luzin set** is an uncountable subset of a real [vector space](wikipedia://en/32370) such that for any uncountable subset the set of directions between different elements of the subset is dense in the sphere of directions.

The [measure-category duality](https://en.wikipedia.org/wiki/Measure-category_duality) provides a [measure](wikipedia://en/19873) analogue of Luzin sets – sets of positive [outer measure](wikipedia://en/488605), every uncountable subset of which has positive outer measure. These sets are called [Sierpiński sets](wikipedia://en/43761184), after [Wacław Sierpiński](wikipedia://en/34122). Sierpiński sets are weakly Luzin sets but are not Luzin sets.

## Example of a Luzin set {#Example_of_a_Luzin_set}

Choose a collection of 2<sup>ℵ<sub>0</sub></sup> meager subsets of **R** such that every meager subset is contained in one of them. By the continuum hypothesis, it is possible to enumerate them as *S*<sub>*α*</sub> for countable ordinals *α*. For each countable ordinal *β* choose a real number *x*<sub>*β*</sub> that is not in any of the sets *S*<sub>*α*</sub> for *α*\<*β*, which is possible as the union of these sets is meager so is not the whole of **R**. Then the uncountable set *X* of all these real numbers *x*<sub>*β*</sub> has only a countable number of elements in each set *S*<sub>*α*</sub>, so is a Luzin set.

More complicated variations of this construction produce examples of Luzin sets that are [subgroups](wikipedia://en/28011), [subfields](wikipedia://en/11634) or [real-closed subfields](wikipedia://en/1066093) of the real numbers.
