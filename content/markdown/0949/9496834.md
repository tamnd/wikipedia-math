# Carry operator

::: {#o1 .subject cue=lead name="Carry operator"}

The **carry operator**, symbolized by the **¢** sign, is an abstraction of the operation of determining whether a portion of an [adder](https://en.wikipedia.org/wiki/Adder_%28electronics%29) network generates or propagates a [carry](wikipedia://en/1629687). It is defined as follows:

:::

$(G_1, P_1) \$ **¢** $(G_2, P_2) = (G_1 \lor G_2 P_1, P_2 P_1)$
