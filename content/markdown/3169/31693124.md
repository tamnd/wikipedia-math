# Non-uniform random variate generation

::: {#o1 .subject cue=lead name="Non-uniform random variate generation"}

**Non-uniform random variate generation** or **pseudo-random number sampling** is the [numerical](wikipedia://en/21506) practice of generating [pseudo-random numbers](https://en.wikipedia.org/wiki/Pseudo-random_number) (PRN) that follow a given [probability distribution](wikipedia://en/23543). Methods are typically based on the availability of a [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) [PRN generator](https://en.wikipedia.org/wiki/Pseudo-random_number_generator). Computational algorithms are then used to manipulate a single [random variate](https://en.wikipedia.org/wiki/Random_variate), *X*, or often several such variates, into a new random variate *Y* such that these values have the required distribution. The first methods were developed for [Monte-Carlo simulations](https://en.wikipedia.org/wiki/Monte-Carlo_method) in the [Manhattan Project](https://en.wikipedia.org/wiki/Manhattan_Project), published by [John von Neumann](wikipedia://en/15942) in the early 1950s.[^o2]

:::

## Finite discrete distributions {#Finite_discrete_distributions}

For a [discrete probability distribution](https://en.wikipedia.org/wiki/Discrete_probability_distribution) with a finite number *n* of indices at which the [probability mass function](wikipedia://en/154725) *f* takes non-zero values, the basic sampling algorithm is straightforward. The interval \[0, 1) is divided in *n* intervals \[0, *f*(1)), \[*f*(1), *f*(1) + *f*(2)), ... The width of interval *i* equals the probability *f*(*i*). One draws a uniformly distributed pseudo-random number *X*, and searches for the index *i* of the corresponding interval. The so determined *i* will have the distribution *f*(*i*).

Formalizing this idea becomes easier by using the cumulative distribution function

$$F(i)=\sum_{j=1}^i f(j).$$

It is convenient to set *F*(0) = 0. The *n* intervals are then simply \[*F*(0), *F*(1)), \[*F*(1), *F*(2)), ..., \[*F*(*n* − 1), *F*(*n*)). The main computational task is then to determine *i* for which *F*(*i* − 1) ≤ *X* \< *F*(*i*).

This can be done by different algorithms:

- [Linear search](https://en.wikipedia.org/wiki/Linear_search), computational time linear in *n*.
- [Binary search](wikipedia://en/4266), computational time goes with log *n*.
- [Indexed search](wikipedia://en/6157370),[^o4] also called the *cutpoint method*.[^o5]
- [Alias method](wikipedia://en/34201204), computational time is constant, using some pre-computed tables.
- There are other methods that cost constant time.[^o6]

## Continuous distributions {#Continuous_distributions}

Generic methods for generating [independent](https://en.wikipedia.org/wiki/Statistical_independence) samples:

- [Rejection sampling](wikipedia://en/502022) for arbitrary density functions
- [Inverse transform sampling](wikipedia://en/45705) for distributions whose [CDF](wikipedia://en/5793) is known
- [Ratio of uniforms](wikipedia://en/68493758), combining a change of variables and rejection sampling
- [Slice sampling](wikipedia://en/7149788)
- [Ziggurat algorithm](wikipedia://en/7093060), for monotonically decreasing density functions as well as symmetric unimodal distributions
- [Convolution random number generator](wikipedia://en/10728412), not a sampling method in itself: it describes the use of arithmetics on top of one or more existing sampling methods to generate more involved distributions.

Generic methods for generating [correlated](https://en.wikipedia.org/wiki/Correlated) samples (often necessary for unusually-shaped or high-dimensional distributions):

- [Markov chain Monte Carlo](wikipedia://en/236801), the general principle
- [Metropolis–Hastings algorithm](wikipedia://en/56107)
- [Gibbs sampling](wikipedia://en/509709)
- [Slice sampling](wikipedia://en/7149788)
- [Reversible-jump Markov chain Monte Carlo](wikipedia://en/6069215), when the number of dimensions is not fixed (e.g. when estimating a [mixture model](wikipedia://en/871681) and simultaneously estimating the number of mixture components)
- [Particle filters](wikipedia://en/1396948), when the observed data is connected in a [Markov chain](wikipedia://en/60876) and should be processed sequentially

For generating a [normal distribution](wikipedia://en/21462):

- [Box–Muller transform](wikipedia://en/60758)
- [Marsaglia polar method](wikipedia://en/11310655)

For generating a [Poisson distribution](wikipedia://en/23009144):

- See [Poisson distribution#Generating Poisson-distributed random variables](wikipedia://en/23009144#Generating_Poisson-distributed_random_variables)
