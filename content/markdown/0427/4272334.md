# Blancmange curve

::: {#o1 .subject cue=lead name="Blancmange curve"}

*Image: Blancmange.svg.* A plot of the blancmange curve.

In [mathematics](wikipedia://en/18831), the **blancmange curve** is a [self-affine](https://en.wikipedia.org/wiki/Self-affinity) [fractal curve](wikipedia://en/4972605) constructible by midpoint subdivision. It is also known as the **Takagi curve**, after [Teiji Takagi](wikipedia://en/174754) who described it in 1901, or as the **Takagi–Landsberg curve**, a generalization of the curve named after Takagi and [Georg Landsberg](wikipedia://en/38027078). The name *blancmange* comes from its resemblance to a [blancmange pudding](https://en.wikipedia.org/wiki/Blancmange). It is a special case of the more general [de Rham curve](wikipedia://en/4539673).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The blancmange function is defined on the [unit interval](wikipedia://en/49324) by

$$\operatorname{blanc}(x) = \sum_{n=0}^\infty {s(2^{n}x)\over 2^n},$$

where $s(x)$ is the [triangle wave](wikipedia://en/52151), defined by $s(x)=\min_{n\in{\mathbf Z}}|x-n|$, that is, $s(x)$ is the distance from *x* to the nearest [integer](wikipedia://en/14563).

The Takagi–Landsberg curve is a slight generalization, given by

$$T_w(x) = \sum_{n=0}^\infty w^n s(2^{n}x)$$

for a parameter $w$; thus the blancmange curve is the case $w=1/2$. The value $H=-\log_2 w$ is known as the [Hurst parameter](https://en.wikipedia.org/wiki/Hurst_parameter).

The function can be extended to all of the real line: applying the definition given above shows that the function repeats on each unit interval.

### Functional equation definition {#Functional_equation_definition}

The periodic version of the Takagi curve can also be defined as the *unique bounded solution $T=T_w:\mathbb{R}\to\mathbb{R}$ to the functional equation*

$$T(x) = s(x) + w T(2x).$$

Indeed, the blancmange function $T_w$ is certainly bounded, and solves the functional equation, since

$T_w(x) := \sum_{n=0}^\infty w^n s(2^{n}x)= s(x) + \sum_{n=1}^\infty w^n s(2^{n}x)$$= s(x) + w\sum_{n=0}^\infty w^n s(2^{n+1}x)= s(x) + wT_w(2x).$

Conversely, if $T:\mathbb{R}\to\mathbb{R}$ is a bounded solution of the functional equation, iterating the equality one has for any *N*

$$T(x) =\sum_{n=0}^N w^n s(2^n x) + w^{N+1} T(2^{N+1}x) =\sum_{n=0}^N w^n s(2^n x) + o(1), \text{ for } N\to\infty,$$

whence $T=T_w$. Incidentally, the above functional equations possesses infinitely many continuous, non-bounded solutions, e.g. $T_w(x)+ c |x|^{-\log_2 w }.$

## Properties {#Properties}

### Convergence and continuity {#Convergence_and_continuity}

The infinite sum defining $T_w(x)$ [converges absolutely](wikipedia://en/61532) for all $x.$ Since $0\le s(x) \le 1/2$ for all $x\in \mathbb{R},$

$$\sum_{n=0}^\infty |w^n s(2^n x)| \le \frac{1}{2} \sum_{n=0}^\infty |w|^n = \frac{1}{2} \cdot \frac{1}{1-|w|}$$

if $|w|<1.$ The Takagi curve of parameter $w$ is defined on the unit interval (or $\mathbb{R}$) if $|w|<1$. The Takagi function of parameter $w$ is [continuous](wikipedia://en/6122). The functions $T_{w,n}$ defined by the partial sums

$$T_{w,n}(x) = \sum_{k=0}^n w^k s(2^k x)$$

are continuous and [converge uniformly](wikipedia://en/50652) toward $T_w:$

$$\begin{aligned} \left|T_w(x) - T_{w,n}(x)\right| & = \left|\sum_{k=n+1}^\infty w^k s(2^k x)\right| \\ & = \left|w^{n+1} \sum_{k=0}^\infty w^k s(2^{k+n+1} x)\right| \\ &\le \frac{|w|^{n+1}}{2} \cdot \frac{1}{1-|w|} \end{aligned}$$

for all *x* when $|w| < 1.$ This bound decreases as $n\to\infty.$ By the [uniform limit theorem](wikipedia://en/29230765), $T_w$ is continuous if |*w*| \< 1.

### Subadditivity {#Subadditivity}

Since the absolute value is a [subadditive function](https://en.wikipedia.org/wiki/Subadditive_function) so is the function $s(x)=\min_{n\in{\mathbf Z}}|x-n|$, and its dilations $s(2^kx)$; since positive linear combinations and point-wise limits of subadditive functions are subadditive, the Takagi function is subadditive for any value of the parameter $w$.

### The special case of the parabola {#The_special_case_of_the_parabola}

For $w=1/4$, one obtains the [parabola](wikipedia://en/23231): the construction of the parabola by midpoint subdivision was described by [Archimedes](wikipedia://en/1844).

### Differentiability {#Differentiability}

For values of the parameter $0< w < 1/2,$ the Takagi function $T_w$ is differentiable in the classical sense at any $x\in\mathbb{R}$ which is not a [dyadic rational](wikipedia://en/56263). By derivation under the sign of series, for any non dyadic rational $x\in\mathbb{R},$ one finds

$$T_w^\prime(x) = \sum_{n=0}^\infty (2w)^n \,(2b_n-1)$$

where $(b_n)_{n\in\mathbb{N}}\in\{0,1\}^\mathbb{N}$ is the sequence of binary digits in the [base 2](https://en.wikipedia.org/wiki/Base_2) expansion of $x$:

$$x=\sum_{n=-k}^\infty b_n2^{-n-1}\;.$$

Equivalently, the bits in the binary expansion can be understood as a sequence of [square waves](wikipedia://en/314652), the [Haar wavelets](wikipedia://en/50905), scaled to width $2^{-n}.$ This follows, since the derivative of the triangle wave is just the square wave:

$$\frac{d}{dx}s(x)=\operatorname{sgn}( 1/2- (x \!\!\! \mod 1))$$

and so

$$T_w^\prime(x) = \sum_{n=0}^\infty (2w)^n \operatorname{sgn} (1/2-(2^nx \!\!\!\mod 1))$$

For the parameter $0< w < 1/2,$ the function $T_w$ is [Lipschitz](wikipedia://en/51731) of constant $1/(1-2w).$ In particular for the special value $w=1/4$ one finds, for any non dyadic rational $x\in[0,1]$ $T_{1/4}'(x) = 2 - 4x$, according with the mentioned $T_{1/4}(x) = 2x(1 - x).$

For $w=1/2$ the blancmange function $T_w$ it is of [bounded variation](wikipedia://en/330673) on no non-empty open set; it is not even locally Lipschitz, but it is quasi-Lipschitz, indeed, it admits the function $\omega(t):=t(|\log_2 t| +1/2)$ as a [modulus of continuity](wikipedia://en/964161).

### Fourier series expansion {#Fourier_series_expansion}

The Takagi–Landsberg function admits an absolutely convergent Fourier series expansion:

$$T_w(x) =\sum_{m=0}^\infty a_m\cos(2\pi m x)$$

with $a_0=1/4(1-w)$ and, for $m\ge 1$

$$a_m:=-\frac{2}{\pi^2m^2}(4w)^{\nu(m)},$$

where $2^{\nu(m)}$ is the maximum power of $2$ that divides $m$. Indeed, the above [triangle wave](wikipedia://en/52151) $s(x)$ has an absolutely convergent Fourier series expansion

$$s(x)=\frac{1}{4}-\frac{2}{\pi^2}\sum_{k=0}^\infty\frac{1}{(2k+1)^2}\cos\big(2\pi (2k+1)x\big).$$

By absolute convergence, one can reorder the corresponding double series for $T_w(x)$:

$$T_w(x):=\sum_{n=0}^\infty w^n s(2^nx)= \frac{1}{4}\sum_{n=0}^\infty w^n -\frac{2}{\pi^2}\sum_{n=0}^\infty\sum_{k=0}^\infty \frac{w^n}{ (2k+1)^2}\cos\big(2\pi 2^n(2k+1)x\big)\, :$$

putting $m=2^n(2k+1)$ yields the above Fourier series for $T_w(x).$

### Self similarity {#Self_similarity}

The recursive definition allows the [monoid](wikipedia://en/19652) of self-symmetries of the curve to be given. This monoid is given by two generators, *g* and *r*, which [act](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) on the curve (restricted to the unit interval) as

$$[g \cdot T_w](x) = T_w \left(g \cdot x\right)= T_w\left(\frac{x}{2}\right) = \frac{x}{2} + w T_w(x)$$

and

$$[r \cdot T_w](x) = T_w(r \cdot x) = T_w(1-x) = T_w(x).$$

A general element of the monoid then has the form $\gamma=g^{a_1} r g^{a_2} r \cdots r g^{a_n}$ for some integers $a_1, a_2, \cdots, a_n$ This [acts](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) on the curve as a [linear function](wikipedia://en/152111): $\gamma \cdot T_w = a + bx + cT_w$ for some constants *a*, *b* and *c*. Because the action is linear, it can be described in terms of a [vector space](wikipedia://en/32370), with the [vector space basis](https://en.wikipedia.org/wiki/Vector_space_basis):

$$1 \mapsto e_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}$$

$$x \mapsto e_2 = \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}$$

$$T_w \mapsto e_3 = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}$$

In this [representation](wikipedia://en/12695), the action of *g* and *r* are given by

$$g=\begin{bmatrix} 1 & 0 & 0 \\ 0 & \frac{1}{2} & \frac{1}{2} \\ 0 & 0 & w \end{bmatrix}$$

and

$$r=\begin{bmatrix} 1 & 1 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

That is, the action of a general element $\gamma$ maps the blancmange curve on the unit interval \[0,1\] to a sub-interval $[m/2^p, n/2^p]$ for some integers *m*, *n*, *p*. The mapping is given exactly by $[\gamma \cdot T_w](x) = a + bx + cT_w(x)$ where the values of *a*, *b* and *c* can be obtained directly by multiplying out the above matrices. That is:

$$\gamma=\begin{bmatrix} 1 & \frac{m}{2^p} & a \\ 0 & \frac{n-m}{2^p} & b \\ 0 & 0 & c \end{bmatrix}$$

Note that $p=a_1+a_2+\cdots +a_n$ is immediate.

The monoid generated by *g* and *r* is sometimes called the **dyadic monoid**; it is a sub-monoid of the [modular group](wikipedia://en/325019). When discussing the modular group, the more common notation for *g* and *r* is *T* and *S*, but that notation conflicts with the symbols used here.

The above three-dimensional representation is just one of many representations it can have; it shows that the blancmange curve is one possible realization of the action. That is, there are representations for any dimension, not just 3; some of these give the [de Rham curves](wikipedia://en/4539673).

:::

## Integrating the Blancmange curve {#Integrating_the_Blancmange_curve}

Given that the [integral](wikipedia://en/15532) of $\operatorname{blanc}(x)$ from 0 to 1 is 1/2, the identity $\operatorname{blanc}(x)= \operatorname{blanc}(2x)/2+s(x)$ allows the integral over any interval to be computed by the following relation. The computation is recursive with computing time on the order of log of the accuracy required. Defining

$$I(x) = \int_0^x\operatorname{blanc}(y)\,dy$$

one has that

$$I(x) =\begin{cases} I(2x)/4+x^2/2 & \text{if } 0 \leq x \leq 1/2 \\ 1/2-I(1-x) & \text{if } 1/2 \le x \le 1 \\ n/2+I(x-n) & \text{if } n \le x \le (n+1) \\ \end{cases}$$

The [definite integral](https://en.wikipedia.org/wiki/Definite_integral) is given by:

$$\int_a^b\operatorname{blanc}(y)\,dy = I(b) - I(a).$$

A more general expression can be obtained by defining

$$S(x)=\int_0^x s(y)dy = \begin{cases} x^2/ 2, & 0 \le x \le \frac{1}{2} \\ - x^2 / 2 +x - 1/4, & \frac{1}{2} \le x \le 1 \\ n/4 + S(x-n), & (n \le x \le n+1) \end{cases}$$

which, combined with the series representation, gives

$$I_w(x)= \int_0^x T_w(y) dy = \sum_{n=0}^\infty (w/2)^n S(2^n x)$$

Note that

$$I_w(1)=\frac{1}{4(1-w)}$$

This integral is also self-similar on the unit interval, under an action of the dyadic monoid described in the section *Self similarity*. Here, the representation is 4-dimensional, having the basis $\{e_1,e_2,e_3,e_4\}=\{1, x, x^2, I_w(x)\}$. The action of *g* on the unit interval is the [commuting diagram](https://en.wikipedia.org/wiki/Commuting_diagram)

$$[g\cdot I_w](x) = I_w\left(g \cdot x\right) = I_w\left(\frac{x}{2}\right) = \frac{x^2}{8} + \frac{w}{2}I_w(x).$$

From this, one can then immediately read off the [generators](wikipedia://en/99945) of the four-dimensional representation:

$$g=\begin{bmatrix} 1 & 0 & 0 & 0\\ 0 & \frac{1}{2} & 0 & 0 \\ 0 & 0 & \frac{1}{4} & \frac{1}{8} \\ 0 & 0 & 0 & \frac{w}{2} \end{bmatrix}$$

and

$$r=\begin{bmatrix} 1 & 1 & 1 & \frac{1}{4(1-w)} \\ 0 & -1 & -2 & 0 \\ 0 & 0 & 1 & 0 \\ 0 & 0 & 0 & -1 \end{bmatrix}$$

Repeated integrals transform under a 5,6,... dimensional representation.

## Relation to simplicial complexes {#Relation_to_simplicial_complexes}

Let

$$N=\binom{n_t}{t}+\binom{n_{t-1}}{t-1}+\ldots+\binom{n_j}{j},\quad n_t > n_{t-1} > \ldots > n_j \geq j\geq 1.$$

Define the Kruskal–Katona function

$$\kappa_t(N)={n_t \choose t+1} + {n_{t-1} \choose t} + \dots + {n_j \choose j+1}.$$

The [Kruskal–Katona theorem](wikipedia://en/1536947) states that this is the minimum number of (*t* − 1)-simplexes that are faces of a set of *N* *t*-simplexes.

As *t* and *N* approach infinity, $\kappa_t(N)-N$ (suitably normalized) approaches the blancmange curve.
