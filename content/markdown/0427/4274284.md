# Kazhdan

::: {#o1 .subject cue=lead name="Kazhdan"}

**Kazhdan**, also written as **Kajdan**, **Kazdan**, **Každan**, is a Jewish surname. Notable people with the surname include:

:::

- [Alexander Kazhdan](https://en.wikipedia.org/wiki/Alexander_Kazhdan) - historian, byzantinist
- [David Kazhdan](wikipedia://en/3052833) - mathematician.
- [Jerry Kazdan](wikipedia://en/12870493) - mathematician
