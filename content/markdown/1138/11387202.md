# 2-EXPTIME

::: {#o1 .subject cue=lead name="2-EXPTIME"}

In [computational complexity theory](wikipedia://en/7543), the [complexity class](wikipedia://en/502426) **2-EXPTIME** (sometimes called **2-EXP**, sometimes also written **2EXPTIME**) is the [set](wikipedia://en/26691) of all [decision problems](wikipedia://en/8336) solvable by a [deterministic Turing machine](https://en.wikipedia.org/wiki/Deterministic_Turing_machine) in [O](wikipedia://en/44578)(2<sup>2<sup>*p*(*n*)</sup></sup>) time, where *p*(*n*) is a [polynomial function](https://en.wikipedia.org/wiki/Polynomial_Function) of *n*.

:::

In terms of [DTIME](wikipedia://en/658538),

$$\mathsf{2\mbox{-}EXPTIME} = \bigcup_{k \in \mathbb{N} } \mathsf{ DTIME } \left( 2^{ 2^{n^k} } \right) .$$

## Comparison with other complexity classes {#Comparison_with_other_complexity_classes}

We know

[P](wikipedia://en/658550) ⊆ [NP](wikipedia://en/21562) ⊆ [PSPACE](wikipedia://en/39351) ⊆ [EXPTIME](wikipedia://en/54694) ⊆ [NEXPTIME](wikipedia://en/663657) ⊆ [EXPSPACE](wikipedia://en/54703) ⊆ **2-EXPTIME** ⊆ [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY).

2-EXPTIME can also be reformulated as the space class AEXPSPACE, the problems that can be solved by an [alternating Turing machine](https://en.wikipedia.org/wiki/Alternating_Turing_machine) in exponential space. This is one way to see that EXPSPACE ⊆ 2-EXPTIME, since an alternating Turing machine is at least as powerful as a deterministic Turing machine.[^o3]

2-EXPTIME is one class in a hierarchy of complexity classes with increasingly higher time bounds. The class 3-EXPTIME is defined similarly to 2-EXPTIME but with a triply exponential time bound $2^{2^{2^{n^k}}}$. This can be generalized to higher and higher time bounds.

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

Examples of algorithms that require at least double-exponential time include:

- Each decision procedure for [Presburger arithmetic](wikipedia://en/23756) provably requires at least doubly exponential time[^o6]
- Computing a [Gröbner basis](wikipedia://en/357328) over a field. In the worst case, a Gröbner basis may have a number of elements which is doubly exponential in the number of variables. On the other hand, the [worst-case complexity](https://en.wikipedia.org/wiki/Worst-case_complexity) of Gröbner basis algorithms is doubly exponential in the number of variables as well as in the entry size.[^o7]
- Finding a complete set of associative-commutative unifiers[^o8]
- [Quantifier elimination](wikipedia://en/2150441) on [real closed fields](wikipedia://en/1066093) takes doubly exponential time (see [Cylindrical algebraic decomposition](wikipedia://en/12218154)). Thus, deciding whether a first-order formula over the real numbers is in 2-EXPTIME. But it was shown to be EXPSPACE and was conjectured to be EXPSPACE-complete in 1986.[^o9]
- Calculating the [complement](wikipedia://en/54347) of a [regular expression](wikipedia://en/25717)[^o10]

:::

## 2-EXPTIME-complete problems {#2-EXPTIME-complete_problems}

### Logic {#Logic}

The satisfiability problem for CTL<sup>\+</sup> ([computation tree logic](wikipedia://en/840894)) is 2-EXPTIME-complete.[^o13] The satisfiability problem of ATL\* ([alternating-time temporal logic](https://en.wikipedia.org/wiki/Alternating-time_temporal_logic)) is 2-EXPTIME-complete.[^o14]

Implicational Relevance Logic is 2-EXPTIME-complete.[^o15]

The satisfiability problem for propositional dynamic logic with intersection (IPDL) is 2-EXPTIME-complete.[^o16]

### Planning {#Planning}

Generalizations of many fully observable games are EXPTIME-complete. These games can be viewed as particular instances of a class of transition systems defined in terms of a set of state variables and actions/events that change the values of the state variables, together with the question of whether a [winning strategy](https://en.wikipedia.org/wiki/Winning_strategy) exists. A generalization of this class of fully observable problems to [partially observable problems](https://en.wikipedia.org/wiki/Partially_observable_system) lifts the complexity from [EXPTIME](wikipedia://en/54694)-complete to 2-EXPTIME-complete.[^o18]

### Synthesis {#Synthesis}

LTL (linear temporal logic) synthesis (deciding whether a reactive module satisfying an LTL specification) is 2EXPTIME-complete.[^o20]
