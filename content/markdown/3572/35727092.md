# Better-quasi-ordering

::: {#o1 .subject cue=lead name="Better-quasi-ordering"}

In [order theory](wikipedia://en/361924) a **better-quasi-ordering** or **bqo** is a [quasi-ordering](https://en.wikipedia.org/wiki/Quasi-ordering) that does not admit a certain type of bad array. Every better-quasi-ordering is a [well-quasi-ordering](wikipedia://en/739775).

:::

## Motivation {#Motivation}

Though *well-quasi-ordering* is an appealing notion, many important infinitary operations do not preserve well-quasi-orderedness. An example due to [Richard Rado](wikipedia://en/614984) illustrates this.[^o14] In a 1965 paper [Crispin Nash-Williams](wikipedia://en/16550517) formulated the stronger notion of *better-quasi-ordering* in order to prove that the class of [trees](wikipedia://en/704160) of height [ω](wikipedia://en/26547932#Ordinals_extend_the_natural_numbers) is well-quasi-ordered under the *[topological minor](https://en.wikipedia.org/wiki/Topological_minor)* relation.[^o13] Since then, many [quasi-orderings](https://en.wikipedia.org/wiki/Quasi-ordering) have been proven to be well-quasi-orderings by proving them to be better-quasi-orderings. For instance, [Richard Laver](wikipedia://en/22280145) established [Laver's theorem](wikipedia://en/63406456) (previously a conjecture of [Roland Fraïssé](wikipedia://en/4234672)) by proving that the class of scattered [linear order](https://en.wikipedia.org/wiki/Linear_order) types is better-quasi-ordered.[^o11] More recently, Carlos Martinez-Ranero has proven that, under the [proper forcing axiom](wikipedia://en/6250799), the class of [Aronszajn lines](wikipedia://en/9211715) is better-quasi-ordered under the embeddability relation.[^o12]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

It is common in better-quasi-ordering theory to write ${_*}x$ for the sequence $x$ with the first term omitted. Write $[\omega]^{<\omega}$ for the set of finite, strictly increasing [sequences](wikipedia://en/27838) with terms in $\omega$, and define a relation $\triangleleft$ on $[\omega]^{<\omega}$ as follows: $s\triangleleft t$ if there is $u \in [\omega]^{<\omega}$ such that $s$ is a strict initial segment of $u$ and $t={}_*u$. The relation $\triangleleft$ is not [transitive](wikipedia://en/200463).

A *block* $B$ is an infinite subset of $[\omega]^{<\omega}$ that contains an initial segment of every infinite subset of $\bigcup B$. For a quasi-order $Q$, a *$Q$-pattern* is a function from some block $B$ into $Q$. A $Q$-pattern $f\colon B\to Q$ is said to be *bad* if $f(s)\not \le_Q f(t)$ for every pair $s,t\in B$ such that $s\triangleleft t$; otherwise $f$ is *good*. A quasi-ordering $Q$ is called a *better-quasi-ordering* if there is no bad $Q$-pattern.

In order to make this definition easier to work with, Nash-Williams defines a *barrier* to be a block whose elements are pairwise [incomparable](wikipedia://en/3834818) under the inclusion relation $\subset$. A *$Q$-array* is a $Q$-pattern whose domain is a barrier. By observing that every block contains a barrier, one sees that $Q$ is a better-quasi-ordering if and only if there is no bad $Q$-array.

:::

## Simpson's alternative definition {#Simpson's_alternative_definition}

Simpson introduced an alternative definition of *better-quasi-ordering* in terms of [Borel functions](https://en.wikipedia.org/wiki/Borel_function) $[\omega]^{\omega}\to Q$, where $[\omega]^{\omega}$, the set of infinite subsets of $\omega$, is given the usual [product topology](wikipedia://en/24910).[^o15]

Let *$Q$* be a quasi-ordering and endow $Q$ with the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology). A *$Q$-array* is a Borel function $[A]^{\omega}\to Q$ for some infinite subset $A$ of $\omega$. A $Q$-array $f$ is *bad* if $f(X)\not\le_Q f({_*}X)$ for every $X\in[A]^{\omega}$; $f$ is *good* otherwise. The quasi-ordering $Q$ is a *better-quasi-ordering* if there is no bad $Q$-array in this sense.

## Major theorems {#Major_theorems}

Many major results in better-quasi-ordering theory are consequences of the Minimal Bad Array Lemma, which appears in Simpson's paper[^o15] as follows. See also Laver's paper,[^o16] where the Minimal Bad Array Lemma was first stated as a result. The technique was present in Nash-Williams' original 1965 paper.

Suppose $(Q,\le_Q)$ is a [quasi-order](https://en.wikipedia.org/wiki/Quasi-order). A *partial ranking* $\le'$ of $Q$ is a [well-founded](https://en.wikipedia.org/wiki/Well-founded) [partial ordering](https://en.wikipedia.org/wiki/Partial_order) of $Q$ such that $q\le'r \to q \le_Q r$. For bad $Q$-arrays (in the sense of Simpson) $f\colon [A]^{\omega}\to Q$ and $g\colon [B]^{\omega}\to Q$, define:

$$g\le^* f \text{ if } B\subseteq A \text{ and } g(X)\le' f(X) \text{ for every } X\in[B]^{\omega}$$

$$g <^* f \text{ if } B\subseteq A \text{ and } g(X) <' f(X) \text{ for every } X\in[B]^{\omega}$$

We say a bad $Q$-array $g$ is *minimal bad* (with respect to the partial ranking $\le'$) if there is no bad $Q$-array $f$ such that $f <^* g$. The definitions of $\le^*$ and $<'$ depend on a partial ranking $\le'$ of $Q$. The relation $<^*$ is not the strict part of the relation $\le^*$.

::: {#o8 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** (Minimal Bad Array Lemma)**.** Let $Q$ be a [quasi-order](https://en.wikipedia.org/wiki/Quasi-order) equipped with a partial ranking and suppose $f$ is a bad $Q$-array. Then there is a minimal bad $Q$-array $g$ such that $g \le^* f$.

:::
