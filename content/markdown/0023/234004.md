# Aggregate pattern

::: {#o1 .subject cue=lead name="Aggregate pattern"}

An **Aggregate pattern** can refer to concepts in either statistics or computer programming. Both uses simplify complexity into smaller, simpler parts.

:::

## Statistics {#Statistics}

An aggregate pattern is an important statistical concept in many fields that rely on [statistics](wikipedia://en/26685) to predict the behavior of large groups, based on the tendencies of subgroups to consistently behave in a certain way. It is particularly useful in [sociology](https://en.wikipedia.org/wiki/Sociology), [economics](https://en.wikipedia.org/wiki/Economics), [psychology](https://en.wikipedia.org/wiki/Psychology), and [criminology](https://en.wikipedia.org/wiki/Criminology).

## Computer programming {#Computer_programming}

In *[Design Patterns](https://en.wikipedia.org/wiki/Design_Patterns)*, an aggregate is not a [design pattern](https://en.wikipedia.org/wiki/Software_design_pattern) but rather refers to an object such as a list, vector, or generator which provides an interface for creating [iterators](https://en.wikipedia.org/wiki/Iterator). The following example code is in [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29).

```python
def fibonacci(n: int):
    a, b = 0, 1
    count = 0
    while count < n:
        count += 1
        a, b = b, a + b
        yield a

for x in fibonacci(10):
    print(x)

def fibsum(n: int) -> int:
    total = 0
    for x in fibonacci(n):
        total += x
    return total

def fibsum_alt(n: int) -> int:
    """
    Alternate implementation. demonstration that Python's built-in function sum()
    works with arbitrary iterators.
    """
    return sum(fibonacci(n))

myNumbers = [1, 7, 4, 3, 22]

def average(g) -> float:
    return float(sum(g)) / len(g)  # In Python 3 the cast to float is no longer be necessary
```

Python hides essentially all of the details using the [iterator protocol](https://docs.python.org/3/library/stdtypes.html#iterator-types). Confusingly, *[Design Patterns](https://en.wikipedia.org/wiki/Design_Patterns)* uses "aggregate" to refer to the blank in the code `for x in ___:` which is unrelated to the term "aggregation".[^o4] Neither of these terms refer to the statistical aggregation of data such as the act of adding up the Fibonacci sequence or taking the average of a list of numbers.
