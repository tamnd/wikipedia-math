# Clopen set

::: {#o1 .subject cue=lead name="Clopen set"}

In [topology](wikipedia://en/29954), a **clopen set** (a [portmanteau](https://en.wikipedia.org/wiki/Portmanteau) of **closed-open set**) in a [topological space](wikipedia://en/30450) is a set which is both [open](wikipedia://en/39358) and [closed](wikipedia://en/47279). That this is possible may seem counterintuitive, as the common meanings of open and closed are antonyms, but their mathematical definitions are not [mutually exclusive](https://en.wikipedia.org/wiki/Mutually_exclusive). A set is closed if its [complement](wikipedia://en/54347) is open, which leaves the possibility of an open set whose complement is also open, making both sets both open and closed, and therefore clopen. As described by topologist [James Munkres](wikipedia://en/7615776), unlike a [door](https://en.wikipedia.org/wiki/Door), "a set can be open, or closed, or both, or neither!"[^n1] emphasizing that the meaning of "open"/"closed" for doors is unrelated to their meaning for sets (and so the open/closed door dichotomy does not transfer to open/closed sets). This contrast to doors gave the class of topological spaces known as "[door spaces](wikipedia://en/5075606)" their name.

:::

## Examples {#Examples}

In any topological space $X,$ the [empty set](wikipedia://en/9566) and the whole space $X$ are both clopen.[^o5][^o6]

Now consider the space $X$ which consists of the [union](wikipedia://en/47949) of the two open [intervals](wikipedia://en/49172) $(0, 1)$ and $(2, 3)$ of $\mathbb{R}.$ The [topology](wikipedia://en/30450) on $X$ is inherited as the [subspace topology](https://en.wikipedia.org/wiki/Topological_subspace) from the ordinary topology on the [real line](https://en.wikipedia.org/wiki/Real_line) $\mathbb{R}.$ In $X,$ the set $(0, 1)$ is clopen, as is the set $(2, 3).$ This is a quite typical example: whenever a space is made up of a finite number of [disjoint](wikipedia://en/39359) [connected components](wikipedia://en/6233) in this way, the components will be clopen.

Now let $X$ be an [infinite set](wikipedia://en/142679) under the [discrete metric](https://en.wikipedia.org/wiki/Discrete_metric) – that is, two points $p, q \in X$ have distance 1 if they're not the same point, and 0 otherwise. Under the resulting [metric space](wikipedia://en/20018), any [singleton set](https://en.wikipedia.org/wiki/Singleton_set) is open; hence any set, being the union of single points, is open. Since any set is open, the complement of any set is open too, and therefore any set is closed. So, all sets in this metric space are clopen.

As a less trivial example, consider the space $\mathbb{Q}$ of all [rational numbers](wikipedia://en/19727024) with their ordinary topology, and the set $A$ of all positive rational numbers whose [square](wikipedia://en/659942) is bigger than 2. Using the fact that $\sqrt 2$ is not in $\mathbb{Q},$ one can show quite easily that $A$ is a clopen subset of $\mathbb{Q}.$ ($A$ is not a clopen subset of the real line $\mathbb{R}$; it is neither open nor closed in $\mathbb{R}.$)

:::

## Properties {#Properties}

- A topological space $X$ is [connected](wikipedia://en/6233) if and only if the only clopen sets are the empty set and $X$ itself.
- A set is clopen if and only if its [boundary](wikipedia://en/72824) is empty.[^o9]
- Any clopen subset of a space $X$ is a union of (possibly infinitely many) connected components of $X$.
- If all [connected components](https://en.wikipedia.org/wiki/Connected_component_%28topology%29) of $X$ are open (for instance, if $X$ has only finitely many components, or if $X$ is [locally connected](https://en.wikipedia.org/wiki/Locally_connected)), then a set is clopen in $X$ if and only if it is a union of connected components.
- A topological space $X$ is [discrete](wikipedia://en/56061) if and only if all of its subsets are clopen.
- Using the union and [intersection](wikipedia://en/23476429) as operations, the clopen subsets of a given topological space $X$ form a [Boolean algebra](wikipedia://en/3959). Every Boolean algebra can be obtained in this way from a suitable topological space: see [Stone's representation theorem for Boolean algebras](wikipedia://en/604111).
