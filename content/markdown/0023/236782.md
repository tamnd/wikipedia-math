# Kaiser window

*Image: KaiserWindow.svg.* The Kaiser window for several values of its parameter

::: {#o1 .subject cue=lead name="Kaiser window"}

The **Kaiser window**, also known as the **Kaiser–Bessel window**, was developed by [James Kaiser](https://en.wikipedia.org/wiki/James_Kaiser) at [Bell Laboratories](https://en.wikipedia.org/wiki/Bell_Laboratories). It is a one-parameter family of [window functions](wikipedia://en/244097) used in [finite impulse response](https://en.wikipedia.org/wiki/Finite_impulse_response) [filter design](https://en.wikipedia.org/wiki/Filter_design) and [spectral analysis](https://en.wikipedia.org/wiki/Spectral_estimation). The Kaiser window approximates the [DPSS window](https://en.wikipedia.org/wiki/DPSS_window) which [maximizes the energy concentration in the main lobe](https://en.wikipedia.org/wiki/Spectral_concentration_problem)[^o2] but which is difficult to compute.[^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Kaiser window and its [Fourier transform](wikipedia://en/52247) are given by**:**

$w_0(x) \triangleq \left\{ \begin{array}{ccl} \tfrac{1}{L}\frac{I_0\left[\pi\alpha \sqrt{1 - \left(2x/L\right)^2}\right]}{I_0[\pi\alpha]},\quad &\left|x\right| \leq L/2\\ 0,\quad &\left|x\right| > L/2 \end{array}\right\} \quad \stackrel{\mathcal{F}}{\Longleftrightarrow}\quad \frac{\sin\bigg(\sqrt{(\pi L f)^2-(\pi \alpha)^2}\bigg)} {I_0(\pi \alpha)\cdot \sqrt{(\pi L f)^2-(\pi \alpha)^2}},$ [^o6]An equivalent formula is**:**[^o7]

$$\frac{\sinh\bigg(\sqrt{(\pi \alpha)^2 - (\pi L f)^2}\bigg)} {I_0(\pi \alpha)\cdot \sqrt{(\pi \alpha)^2 - (\pi L f)^2}}.$$

*Image: Kaiser-Window-Spectra.svg.* Fourier transforms of two Kaiser windows

where**:**

- $I_{0}$ is the zeroth-order [modified Bessel function](https://en.wikipedia.org/wiki/Modified_Bessel_function#Modified_Bessel_functions:_Iα,_Kα) of the first kind,
- $L$ is the window duration, and
- $\alpha$ is a non-negative [real number](wikipedia://en/20646438) that determines the shape of the window. In the frequency domain, it determines the trade-off between main-lobe width and side lobe level, which is a central decision in window design.
- Sometimes the Kaiser window is parametrized by $\beta$, where $\beta = \pi\alpha$.

For [digital signal processing](https://en.wikipedia.org/wiki/Digital_signal_processing), the function can be sampled symmetrically as**:**

$$w[n] = L\cdot w_0\left(\tfrac{L}{N} (n-N/2)\right) = \frac{I_0\left[\pi\alpha \sqrt{1 - \left(\frac{2n}{N}-1\right)^2}\right]}{I_0[\pi\alpha]},\quad 0 \leq n \leq N,$$

where the length of the window is $N+1,$ and N can be even or odd. (see [A list of window functions](wikipedia://en/244097#Examples_of_window_functions))

In the Fourier transform, the first null after the main lobe occurs at $f = \tfrac{\sqrt{1+\alpha^2}}{L},$ which is just $\sqrt{1+\alpha^2}$ in units of N ([DFT "bins"](https://en.wikipedia.org/wiki/Normalized_frequency_%28signal_processing%29)). As *α* increases, the main lobe increases in width, and the side lobes decrease in amplitude. $\alpha$ = 0 corresponds to a rectangular window. For large $\alpha,$ the shape of the Kaiser window (in both time and frequency domain) tends to a [Gaussian](wikipedia://en/245552) curve. The Kaiser window is nearly optimal in the sense of its peak's concentration around frequency $0.$[^o8]

:::

## Kaiser–Bessel-derived (KBD) window {#Kaiser–Bessel-derived_(KBD)_window}

*Image: Kbd-window.svg.*

A related window function is the **Kaiser–Bessel-derived (KBD)** window, which is designed to be suitable for use with the [modified discrete cosine transform](https://en.wikipedia.org/wiki/Modified_discrete_cosine_transform) (MDCT). The KBD window function is defined in terms of the Kaiser window of length *N*+1, by the formula**:**

$$d_n = \begin{cases} \sqrt{\frac{\sum_{i=0}^{n} w[i]} {\sum_{i=0}^N w[i]}} & \mbox{if } 0 \leq n < N \\ \sqrt{\frac{\sum_{i=0}^{2N-1-n} w[i]} {\sum_{i=0}^N w[i]}} & \mbox{if } N \leq n \leq 2N-1 \\ 0 & \mbox{otherwise}. \\ \end{cases}$$

This defines a window of length 2*N*, where by construction *d*<sub>*n*</sub> satisfies the Princen-Bradley condition for the MDCT (using the fact that $w_{N-n} = w_{n}$): $d_{n}^{2} + (d_{n+N})^{2} = 1$ (interpreting *n* and *n* + *N* [modulo](wikipedia://en/20087) 2*N*). The KBD window is also symmetric in the proper manner for the MDCT: *d*<sub>*n*</sub> = *d*<sub>2*N*−1−*n*</sub>.

::: {#o11 .application cue=heading name="Applications"}

### Applications {#Applications}

The KBD window is used in the [Advanced Audio Coding](https://en.wikipedia.org/wiki/Advanced_Audio_Coding) [digital audio](https://en.wikipedia.org/wiki/Digital_audio) format.

:::
