# Unsupervised learning

Paradigms

::: {#o1 .subject cue=lead name="Unsupervised learning"}

**Unsupervised learning** is a framework in [machine learning](wikipedia://en/233488) where, in contrast to [supervised learning](wikipedia://en/20926), algorithms learn patterns exclusively from unlabeled data.[^o2] Other frameworks in the spectrum of supervisions include [weak- or semi-supervision](https://en.wikipedia.org/wiki/Weak_supervision), where a small portion of the data is tagged, and [self-supervision](wikipedia://en/67902375). Some researchers consider self-supervised learning a form of unsupervised learning.[^o3]

:::

Conceptually, unsupervised learning divides into the aspects of data, training, algorithm, and downstream applications. Typically, the dataset is harvested cheaply "in the wild", such as massive [text corpus](https://en.wikipedia.org/wiki/Text_corpus) obtained by [web crawling](https://en.wikipedia.org/wiki/Web_crawler), with only minor filtering (such as [Common Crawl](https://en.wikipedia.org/wiki/Common_Crawl)). This compares favorably to supervised learning, where the dataset (such as the [ImageNet1000](https://en.wikipedia.org/wiki/ImageNet)) is typically constructed manually, which is much more expensive.

There are algorithms designed specifically for unsupervised learning, such as [clustering algorithms](wikipedia://en/669675) like [k-means](wikipedia://en/1860407), [dimensionality reduction](wikipedia://en/579867) techniques like [principal component analysis (PCA)](wikipedia://en/76340), [Boltzmann machine learning](wikipedia://en/1166059), and [autoencoders](https://en.wikipedia.org/wiki/Autoencoder). After the rise of deep learning, most large-scale unsupervised learning has been done by training general-purpose neural network architectures by [gradient descent](wikipedia://en/201489), adapted to performing unsupervised learning by designing an appropriate training procedure.

Sometimes a trained model can be used as-is, but more often they are modified for downstream applications. For example, the generative pretraining method trains a model to generate a textual dataset, before finetuning it for other applications, such as text classification.[^o4][^o5] As another example, autoencoders are trained to produce [good features](https://en.wikipedia.org/wiki/Feature_learning), which can then be used as a module for other models, such as in a [latent diffusion model](https://en.wikipedia.org/wiki/Latent_diffusion_model).

## Tasks {#Tasks}

*Image: Task-guidance.png.* Tendency for a task to employ supervised vs. unsupervised methods. Task names straddling circle boundaries is intentional. It shows that the classical division of imaginative tasks (left) employing unsupervised methods is blurred in today's learning schemes.

Tasks are often categorized as [discriminative](wikipedia://en/12155912) (recognition) or [generative](wikipedia://en/1222578) (imagination). Often but not always, discriminative tasks use supervised methods and generative tasks use unsupervised (see [Venn diagram](wikipedia://en/61701)); however, the separation is very hazy. For example, object recognition favors supervised learning but unsupervised learning can also cluster objects into groups. Furthermore, as progress marches onward, some tasks employ both methods, and some tasks swing from one to another. For example, image recognition started off as heavily supervised, but became hybrid by employing unsupervised pre-training, and then moved towards supervision again with the advent of [dropout](https://en.wikipedia.org/wiki/Dilution_%28neural_networks%29), [ReLU](https://en.wikipedia.org/wiki/Rectifier_%28neural_networks%29), and [adaptive learning rates](wikipedia://en/59969558).

A typical generative task is as follows. At each step, a datapoint is sampled from the dataset, and part of the data is removed, and the model must infer the removed part. This is particularly clear for the [denoising autoencoders](https://en.wikipedia.org/wiki/Autoencoder) and [BERT](https://en.wikipedia.org/wiki/BERT_%28language_model%29).

## Neural network architectures {#Neural_network_architectures}

### Training {#Training}

During the learning phase, an unsupervised network tries to mimic the data it is given and uses the error in its mimicked output to correct itself (i.e. correct its weights and biases). Sometimes the error is expressed as a low probability that the erroneous output occurs, or it might be expressed as an unstable high energy state in the network.

In contrast to supervised methods' dominant use of [backpropagation](https://en.wikipedia.org/wiki/Backpropagation), unsupervised learning also employs other methods including: Hopfield learning rule, Boltzmann learning rule, [Contrastive Divergence](https://en.wikipedia.org/wiki/Contrastive_Divergence), [Wake Sleep](https://en.wikipedia.org/wiki/Wake-sleep_algorithm), [Variational Inference](https://en.wikipedia.org/wiki/Variational_Inference), [Maximum Likelihood](https://en.wikipedia.org/wiki/Maximum_Likelihood), [Maximum A Posteriori](https://en.wikipedia.org/wiki/Maximum_A_Posteriori), [Gibbs Sampling](https://en.wikipedia.org/wiki/Gibbs_Sampling), and backpropagating reconstruction errors or hidden state reparameterizations. See the table below for more details.

### Energy {#Energy}

An energy function is a macroscopic measure of a network's activation state. In Boltzmann machines, it plays the role of the Cost function. This analogy with physics is inspired by Ludwig Boltzmann's analysis of a gas' macroscopic energy from the microscopic probabilities of particle motion $p \propto e^{-E/kT}$, where k is the Boltzmann constant and T is temperature. In the [RBM](https://en.wikipedia.org/wiki/Restricted_Boltzmann_machine) network the relation is $p = e^{-E} / Z$,[^o40] where $p$ and $E$ vary over every possible activation pattern and $\textstyle{Z = \sum_{\scriptscriptstyle{\text{All Patterns}}} e^{-E(\text{pattern})}}$. To be more precise, $p(a) = e^{-E(a)} / Z$, where $a$ is an activation pattern of all neurons (visible and hidden). Hence, some early neural networks bear the name Boltzmann Machine. Paul Smolensky calls $-E\,$ the *Harmony*. A network seeks low energy which is high Harmony.

### Specific networks {#Specific_networks}

Here, we highlight some characteristics of select networks. The details of each are given in the comparison table below.

::: {#o16 .entry cue=term name="Hopfield Network"}

**[Hopfield Network](https://en.wikipedia.org/wiki/Hopfield_Network)**

Ferromagnetism inspired Hopfield networks. A neuron corresponds to an iron domain with binary magnetic moments Up and Down, and neural connections correspond to the domain's influence on each other. Symmetric connections enable a global energy formulation. During inference the network updates each state using the standard activation step function. Symmetric weights and the right energy functions guarantees convergence to a stable activation pattern. Asymmetric weights are difficult to analyze. Hopfield nets are used as Content Addressable Memories (CAM).

:::

::: {#o17 .entry cue=term name="Boltzmann Machine"}

**[Boltzmann Machine](https://en.wikipedia.org/wiki/Boltzmann_Machine)**

These are stochastic Hopfield nets. Their state value is sampled from this [pdf](wikipedia://en/43487) as follows: suppose a binary neuron fires with the Bernoulli probability p(1) = 1/3 and rests with p(0) = 2/3. One samples from it by taking a *uniformly* distributed random number y, and plugging it into the inverted [cumulative distribution function](wikipedia://en/5793), which in this case is the step function thresholded at 2/3. The inverse function = { 0 if x \<= 2/3, 1 if x > 2/3 }.

:::

::: {#o18 .entry cue=term name="Sigmoid Belief Net"}

**Sigmoid Belief Net**

Introduced by Radford Neal in 1992, this network applies ideas from probabilistic graphical models to neural networks. A key difference is that nodes in graphical models have pre-assigned meanings, whereas Belief Net neurons' features are determined after training. The network is a sparsely connected directed acyclic graph composed of binary stochastic neurons. The learning rule comes from Maximum Likelihood on p(X): Δw<sub>ij</sub> $\propto$ s<sub>j</sub> \* (s<sub>i</sub> - p<sub>i</sub>), where p<sub>i</sub> = 1 / ( 1 + e<sup>weighted inputs into neuron i</sup> ). s<sub>j</sub>'s are activations from an unbiased sample of the posterior distribution and this is problematic due to the Explaining Away problem raised by Judea Perl. [Variational Bayesian methods](wikipedia://en/1208480) uses a surrogate posterior and blatantly disregard this complexity.

:::

::: {#o19 .entry cue=term name="Deep Belief Network"}

**[Deep Belief Network](https://en.wikipedia.org/wiki/Deep_Belief_Network)**

Introduced by Hinton, this network is a hybrid of RBM and Sigmoid Belief Network. The top 2 layers is an RBM and the second layer downwards form a sigmoid belief network. One trains it by the [stacked RBM](https://en.wikipedia.org/wiki/Stacked_Restricted_Boltzmann_Machine) method and then throw away the recognition weights below the top RBM. As of 2009, 3-4 layers seems to be the optimal depth.[^o41]

:::

::: {#o20 .entry cue=term name="Helmholtz machine"}

**[Helmholtz machine](https://en.wikipedia.org/wiki/Helmholtz_machine)**

These are early inspirations for the Variational Auto Encoders. Its 2 networks combined into one—forward weights operates recognition and backward weights implements imagination. It is perhaps the first network to do both. Helmholtz did not work in machine learning but he inspired the view of "statistical inference engine whose function is to infer probable causes of sensory input".[^o21] the stochastic binary neuron outputs a probability that its state is 0 or 1. The data input is normally not considered a layer, but in the Helmholtz machine generation mode, the data layer receives input from the middle layer and has separate weights for this purpose, so it is considered a layer. Hence this network has 3 layers.

:::

::: {#o22 .entry cue=term name="Variational autoencoder"}

**[Variational autoencoder](https://en.wikipedia.org/wiki/Variational_autoencoder)**

These are inspired by Helmholtz machines and combines probability network with neural networks. An Autoencoder is a 3-layer CAM network, where the middle layer is supposed to be some internal representation of input patterns. The encoder neural network is a probability distribution q<sub>φ</sub>(z given x) and the decoder network is p<sub>θ</sub>(x given z). The weights are named phi & theta rather than W and V as in Helmholtz—a cosmetic difference. These 2 networks here can be fully connected, or use another NN scheme.

:::

### Hebbian Learning, ART, SOM {#Hebbian_Learning,_ART,_SOM}

The classical example of unsupervised learning in the study of neural networks is [Donald Hebb](https://en.wikipedia.org/wiki/Donald_Hebb)'s principle, that is, neurons that fire together wire together.[^o37] In [Hebbian learning](https://en.wikipedia.org/wiki/Hebbian_learning), the connection is reinforced irrespective of an error, but is exclusively a function of the coincidence between action potentials between the two neurons.[^o38] A similar version that modifies synaptic weights takes into account the time between the action potentials ([spike-timing-dependent plasticity](https://en.wikipedia.org/wiki/Spike-timing-dependent_plasticity) or STDP). Hebbian Learning has been hypothesized to underlie a range of cognitive functions, such as [pattern recognition](wikipedia://en/126706) and experiential learning.

Among [neural network](https://en.wikipedia.org/wiki/Artificial_neural_network) models, the [self-organizing map](wikipedia://en/76996) (SOM) and [adaptive resonance theory](https://en.wikipedia.org/wiki/Adaptive_resonance_theory) (ART) are commonly used in unsupervised learning algorithms. The SOM is a topographic organization in which nearby locations in the map represent inputs with similar properties. The ART model allows the number of clusters to vary with problem size and lets the user control the degree of similarity between members of the same clusters by means of a user-defined constant called the vigilance parameter. ART networks are used for many pattern recognition tasks, such as [automatic target recognition](https://en.wikipedia.org/wiki/Automatic_target_recognition) and seismic signal processing.[^o39]

## Probabilistic methods {#Probabilistic_methods}

Two of the main methods used in unsupervised learning are [principal component](wikipedia://en/76340) and [cluster analysis](wikipedia://en/669675). Cluster analysis is used in unsupervised learning to group, or segment, datasets with shared attributes in order to extrapolate algorithmic relationships.[^o32] Cluster analysis is a branch of [machine learning](wikipedia://en/233488) that groups the data that has not been [labelled](https://en.wikipedia.org/wiki/Labeled_data), classified or categorized. Instead of responding to feedback, cluster analysis identifies commonalities in the data and reacts based on the presence or absence of such commonalities in each new piece of data. This approach helps detect anomalous data points that do not fit into either group.

A central application of unsupervised learning is in the field of [density estimation](wikipedia://en/554671) in [statistics](wikipedia://en/26685),[^o33] though unsupervised learning encompasses many other domains involving summarizing and explaining data features. It can be contrasted with supervised learning by saying that whereas supervised learning intends to infer a [conditional probability distribution](wikipedia://en/504458) conditioned on the label of input data; unsupervised learning intends to infer an [a priori probability](https://en.wikipedia.org/wiki/A_priori_probability) distribution .

### Approaches {#Approaches}

Some of the most common algorithms used in unsupervised learning include: (1) Clustering, (2) Anomaly detection, (3) Approaches for learning latent variable models. Each approach uses several methods as follows:

- [Clustering](https://en.wikipedia.org/wiki/Data_clustering) methods include: [hierarchical clustering](wikipedia://en/477573),[^o34] [k-means](https://en.wikipedia.org/wiki/K-means),[^o35] [mixture models](https://en.wikipedia.org/wiki/Mixture_models), [model-based clustering](wikipedia://en/76187094), [DBSCAN](https://en.wikipedia.org/wiki/DBSCAN), and [OPTICS algorithm](wikipedia://en/22509799)
- [Anomaly detection](wikipedia://en/8190902) methods include: [local outlier factor](wikipedia://en/27321681), and [isolation forest](wikipedia://en/61890679)
- Approaches for learning [latent variable models](wikipedia://en/4237572) such as [expectation–maximization algorithm](wikipedia://en/470752) (EM), [method of moments](wikipedia://en/2175504), and [blind signal separation](https://en.wikipedia.org/wiki/Blind_signal_separation) techniques (principal component analysis, [independent component analysis](wikipedia://en/598031), [non-negative matrix factorization](wikipedia://en/3681279), [singular value decomposition](wikipedia://en/142207))

### Method of moments {#Method_of_moments}

One of the statistical approaches for unsupervised learning is the [method of moments](wikipedia://en/2175504). In the method of moments, the unknown parameters (of interest) in the model are related to the moments of one or more random variables, and thus, these unknown parameters can be estimated given the moments. The moments are usually estimated from samples empirically. The basic moments are first and second order moments. For a random vector, the first order moment is the [mean](https://en.wikipedia.org/wiki/Mean) vector, and the second order moment is the [covariance matrix](wikipedia://en/191752) (when the mean is zero). Higher order moments are usually represented using [tensors](https://en.wikipedia.org/wiki/Tensors) which are the generalization of matrices to higher orders as multi-dimensional arrays.

In particular, the method of moments is shown to be effective in learning the parameters of [latent variable models](wikipedia://en/4237572). Latent variable models are statistical models where in addition to the observed variables, a set of latent variables also exists which is not observed. A highly practical example of latent variable models in machine learning is the [topic modeling](https://en.wikipedia.org/wiki/Topic_modeling) which is a statistical model for generating the words (observed variables) in the document based on the topic (latent variable) of the document. In the topic modeling, the words in the document are generated according to different statistical parameters when the topic of the document is changed. It is shown that method of moments (tensor decomposition techniques) consistently recover the parameters of a large class of latent variable models under some assumptions.[^o36]

The [Expectation–maximization algorithm](wikipedia://en/470752) (EM) is also one of the most practical methods for learning latent variable models. However, it can get stuck in local optima, and it is not guaranteed that the algorithm will converge to the true unknown parameters of the model. In contrast, for the method of moments, the global convergence is guaranteed under some conditions.
