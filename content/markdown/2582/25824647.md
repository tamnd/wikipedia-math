# Moise's theorem

::: {#o1 .subject cue=lead name="Moise's theorem"}

In [geometric topology](wikipedia://en/621732), a branch of mathematics, **Moise's theorem**, proved by [Edwin E. Moise](wikipedia://en/19236494) in (Moise 1952), states that any topological [3-manifold](wikipedia://en/1018257) has an essentially unique [piecewise-linear structure](https://en.wikipedia.org/wiki/Piecewise-linear_structure) and [smooth structure](wikipedia://en/1542238).

:::

The analogue of Moise's theorem in dimension 4 (and above) is false: there are topological [4-manifolds](wikipedia://en/1362795) with no piecewise linear structures like the [E8 manifold](wikipedia://en/6091657), and others with an infinite number of inequivalent ones. However, a restricted version holds with non-[compactness](wikipedia://en/6042), which is known as the [Quinn theorem](https://en.wikipedia.org/wiki/Quinn_theorem).
