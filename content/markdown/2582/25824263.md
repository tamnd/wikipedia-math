# Side-approximation theorem

::: {#o1 .subject cue=lead name="Side-approximation theorem"}

In geometric topology, the **side-approximation theorem** was proved by (Bing 1963). It implies that a 2-sphere in **R**<sup>3</sup> can be approximated by polyhedral 2-spheres.

:::
