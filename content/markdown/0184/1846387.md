# Password Safe

::: {#o4 .subject cue=lead name="Password Safe"}

**Password Safe** is a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source_software) [password manager](wikipedia://en/4696394) program originally written for [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows) but supporting a wide array of operating systems, with compatible clients available for [Linux](https://en.wikipedia.org/wiki/Linux), [FreeBSD](https://en.wikipedia.org/wiki/FreeBSD), [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29), [IOS](https://en.wikipedia.org/wiki/IOS), [BlackBerry](https://en.wikipedia.org/wiki/BlackBerry) and other operating systems.

:::

## History {#History}

The program was initiated by [Bruce Schneier](wikipedia://en/36732) at [Counterpane Systems](https://en.wikipedia.org/wiki/BT_Managed_Security_Solutions).[^o6] the program is maintained on [GitHub](https://en.wikipedia.org/wiki/GitHub) by a group of volunteers.[^o7][^o8]

## Design {#Design}

After filling in the master password the user has access to all account data entered and saved previously. The data can be organized by categories, searched, and sorted based on references which are easy for the user to remember.[^o10]

There are various key combinations and mouse clicks to copy parts of the stored data (password, email, username etc.), or use the autofill feature (for filling forms). The program can be set to minimize automatically after a period of idle time and clear the clipboard. It is possible to compare and synchronize (merge) two different password databases. The program can be set up to generate automatic backups.

Password Safe does not support database sharing, but the single-file database can be shared by any external sharing method (for example [Syncthing](https://en.wikipedia.org/wiki/Syncthing), [Dropbox](https://en.wikipedia.org/wiki/Dropbox_%28service%29) etc.). The password database is not stored online.

## Features {#Features}

*Note: All uncited information in this section is sourced from the official Help file included with the application*

### Password management {#Password_management}

Stored passwords can be sectioned into groups and subgroups in a [tree structure](https://en.wikipedia.org/wiki/Tree_structure).

Changes to entries can be tracked, including a history of previous passwords, the creation time, modification time, last access time, and expiration time of each password stored. Text notes can be entered with the password details.

### Import and export {#Import_and_export}

The password list can be exported to various [file formats](https://en.wikipedia.org/wiki/File_format) including [TXT](https://en.wikipedia.org/wiki/.txt), [XML](https://en.wikipedia.org/wiki/XML) and previous versions of Password Safe. Password Safe also supports importing these files.

Password Safe supports importing TXT and [CSV](https://en.wikipedia.org/wiki/Comma-separated_values) files which were exported from [KeePass](wikipedia://en/30858923) version 1.x (V1). KeePass version 2.x (V2) allows databases to be exported as a KeePass V1 database, which in turn can be imported to Password Safe.

Password Safe cannot directly import an XML file exported by KeePass V1 or V2, as the fields are too different. However, the Help file provides instructions for processing an exported XML file with one of multiple [XSLT](https://en.wikipedia.org/wiki/XSLT) files (included with Password Safe) which will produce a Password Safe compatible XML file that can then be imported.

### File encryption {#File_encryption}

Password Safe can encrypt any file using a key derived from a passphrase provided by the user through the [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface).

### Password generator {#Password_generator}

The software features a built-in [password generator](https://en.wikipedia.org/wiki/Random_password_generator) that generates random passwords. The user may also designate parameters for password generation (length, character set, etc.), creating a "Named Password Policy" by which different passwords can be created.

## Cryptography {#Cryptography}

The original Password Safe was built on Bruce Schneier's [Blowfish](wikipedia://en/3940) encryption algorithm. Rony Shapiro implemented [Twofish](wikipedia://en/26508356) encryption along with other improvements to the 3.xx series of Password Safe.[^o17] The keys are derived using an equivalent of [PBKDF2](wikipedia://en/1568244) with [SHA-256](https://en.wikipedia.org/wiki/SHA-256) and a configurable number of iterations, currently set at 2048.[^o18][^o19]

In a 2012 paper analysing various database formats of password storage programs for security vulnerabilities the researchers found that the format used by Password Safe (version 3 format) was the most resistant to various cryptographic attacks.[^o20]

## Reception {#Reception}

Reviewers have highlighted the program's simplicity as its best feature.[^o22]
