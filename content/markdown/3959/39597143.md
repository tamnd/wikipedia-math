# M/D/c queue

::: {#o1 .subject cue=lead name="M/D/c queue"}

In [queueing theory](wikipedia://en/50578), a discipline within the mathematical [theory of probability](wikipedia://en/23542), an **M/D/c queue** represents the queue length in a system having *c* servers, where arrivals are determined by a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) and job service times are fixed (deterministic). The model name is written in [Kendall's notation](wikipedia://en/7345405).[^o2] [Agner Krarup Erlang](wikipedia://en/2948) first published on this model in 1909, starting the subject of [queueing theory](wikipedia://en/50578).[^o3][^o4] The model is an extension of the [M/D/1 queue](wikipedia://en/37844292) which has only a single server.

:::

## Model definition {#Model_definition}

An M/D/*c* queue is a stochastic process whose [state space](https://en.wikipedia.org/wiki/State_space) is the set {0,1,2,3,...} where the value corresponds to the number of customers in the system, including any currently in service.

- Arrivals occur at rate λ according to a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process) and move the process from state *i* to *i* + 1.
- Service times are deterministic time *D* (serving at rate *μ* = 1/*D*).
- *c* servers serve customers from the front of the queue, according to a [first-come, first-served](https://en.wikipedia.org/wiki/First-come,_first-served) discipline. When the service is complete the customer leaves the queue and the number of customers in the system reduces by one.
- The buffer is of infinite size, so there is no limit on the number of customers it can contain.

## Waiting time distribution {#Waiting_time_distribution}

Erlang showed that when *ρ* = (*λ* *D*)/*c* \< 1, the waiting time distribution has distribution F(*y*) given by[^o7]

$$F(y) = \int_0^\infty F(x+y-D)\frac{\lambda^c x^{c-1}}{(c-1)!} e^{-\lambda x} \text{d} x, \quad y \geq 0 \quad c \in \mathbb N.$$

Crommelin showed that, writing *P*<sub>*n*</sub> for the stationary probability of a system with *n* or fewer customers, [^o8]

$$\mathbb P(W \leq x) = \sum_{n=0}^{c-1} P_n \sum_{k=1}^m \frac{(-\lambda(x-kD))^{(k+1)c-1-n}}{((K+1)c-1-n)!}e^{\lambda(x-kD)}, \quad mD \leq x <(m+1)D.$$
