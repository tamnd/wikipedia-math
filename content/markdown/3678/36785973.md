# Distribution (number theory)

::: {#o1 .subject cue=lead name="Distribution"}

In [algebra](wikipedia://en/18716923) and [number theory](wikipedia://en/21527), a **distribution** is a function on a system of finite sets into an [abelian group](wikipedia://en/2974) which is analogous to an integral: it is thus the algebraic analogue of a [distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) in the sense of [generalised function](https://en.wikipedia.org/wiki/Generalised_function).

:::

The original examples of distributions occur, unnamed, as functions φ on **Q**/**Z** satisfying[^o2]

$$\sum_{r=0}^{N-1} \phi\left(x + \frac r N\right) = \phi(Nx) \ .$$

Such distributions are called ordinary distributions.[^o3] They also occur in *p*-adic integration theory in [Iwasawa theory](wikipedia://en/396150).[^o4]

Let ... → *X*<sub>*n*+1</sub> → *X*<sub>*n*</sub> → ... be a [projective system](https://en.wikipedia.org/wiki/Projective_system) of finite sets with surjections, indexed by the natural numbers, and let *X* be their [projective limit](https://en.wikipedia.org/wiki/Projective_limit). We give each *X*<sub>*n*</sub> the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology), so that *X* is [compact](wikipedia://en/6042). Let φ = (φ<sub>*n*</sub>) be a family of functions on *X*<sub>*n*</sub> taking values in an abelian group *V* and compatible with the projective system:

$$w(m,n) \sum_{y \mapsto x} \phi(y) = \phi(x)$$

for some *weight function* *w*. The family φ is then a *distribution* on the projective system *X*.

A function *f* on *X* is "locally constant", or a "[step function](wikipedia://en/170939)" if it factors through some *X*<sub>*n*</sub>. We can define an integral of a step function against φ as

$$\int f \, d\phi = \sum_{x \in X_n} f(x) \phi_n(x) \ .$$

The definition extends to more general projective systems, such as those indexed by the positive integers ordered by divisibility. As an important special case consider the projective system **Z**/*n***Z** indexed by positive integers ordered by divisibility. We identify this with the system (1/*n*)**Z**/**Z** with limit **Q**/**Z**.

For *x* in *R* we let ⟨*x*⟩ denote the [fractional part](wikipedia://en/501532) of *x* normalised to 0 ≤ ⟨*x*⟩ \< 1, and let {*x*} denote the fractional part normalised to 0 \< {*x*} ≤ 1.

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

### Hurwitz zeta function {#Hurwitz_zeta_function}

The [multiplication theorem](wikipedia://en/8720712) for the [Hurwitz zeta function](wikipedia://en/406952)

$$\zeta(s,a) = \sum_{n=0}^\infty (n+a)^{-s}$$

gives a distribution relation

$$\sum_{p=0}^{q-1}\zeta(s,a+p/q)=q^s\,\zeta(s,qa) \ .$$

Hence for given *s*, the map $t \mapsto \zeta(s,\{t\})$ is a distribution on **Q**/**Z**.

### Bernoulli distribution {#Bernoulli_distribution}

Recall that the *[Bernoulli polynomials](wikipedia://en/228161)* *B*<sub>*n*</sub> are defined by

$$B_n(x) = \sum_{k=0}^n {n \choose n-k} b_k x^{n-k} \ ,$$

for *n* ≥ 0, where *b*<sub>*k*</sub> are the [Bernoulli numbers](wikipedia://en/4964), with [generating function](wikipedia://en/160993)

$$\frac{t e^{xt}}{e^t-1}= \sum_{n=0}^\infty B_n(x) \frac{t^n}{n!} \ .$$

They satisfy the *distribution relation*

$$B_k(x) = n^{k-1} \sum_{a=0}^{n-1} b_k\left({\frac{x+a}{n}}\right)\ .$$

Thus the map

$$\phi_n : \frac{1}{n}\mathbb{Z}/\mathbb{Z} \rightarrow \mathbb{Q}$$

defined by

$$\phi_n : x \mapsto n^{k-1} B_k(\langle x \rangle)$$

is a distribution.[^o9]

### Cyclotomic units {#Cyclotomic_units}

The [cyclotomic units](wikipedia://en/5991396) satisfy *distribution relations*. Let *a* be an element of **Q**/**Z** prime to *p* and let *g*<sub>*a*</sub> denote exp(2πi*a*)−1. Then for *a*≠ 0 we have[^o11]

$$\prod_{p b=a} g_b = g_a \ .$$

:::

## Universal distribution {#Universal_distribution}

One considers the distributions on *Z* with values in some abelian group *V* and seek the "universal" or most general distribution possible.

## Stickelberger distributions {#Stickelberger_distributions}

Let *h* be an ordinary distribution on **Q**/**Z** taking values in a field *F*. Let *G*(*N*) denote the multiplicative group of **Z**/*N***Z**, and for any function *f* on *G*(*N*) we extend *f* to a function on **Z**/*N***Z** by taking *f* to be zero off *G*(*N*). Define an element of the group algebra *F*\[*G*(*N*)\] by

$$g_N(r) = \frac{1}{|G(N)|} \sum_{a \in G(N)} h\left({\left\langle{\frac{ra}{N}}\right\rangle}\right) \sigma_a^{-1} \ .$$

The group algebras form a projective system with limit *X*. Then the functions *g*<sub>*N*</sub> form a distribution on **Q**/**Z** with values in *X*, the **Stickelberger distribution** associated with *h*.

## p-adic measures {#p-adic_measures}

Consider the special case when the value group *V* of a distribution φ on *X* takes values in a [local field](wikipedia://en/145375) *K*, finite over **Q**<sub>*p*</sub>, or more generally, in a finite-dimensional *p*-adic Banach space *W* over *K*, with valuation |·|. We call φ a **measure** if |φ| is bounded on compact open subsets of *X*.[^o15] Let *D* be the ring of integers of *K* and *L* a lattice in *W*, that is, a free *D*-submodule of *W* with *K*⊗*L* = *W*. Up to scaling a measure may be taken to have values in *L*.

### Hecke operators and measures {#Hecke_operators_and_measures}

Let *D* be a fixed [integer](wikipedia://en/14563) prime to *p* and consider **Z**<sub>*D*</sub>, the limit of the system **Z**/*p*<sup>*n*</sup>*D*. Consider any [eigenfunction](wikipedia://en/228601) of the [Hecke operator](wikipedia://en/521837) *T*<sup>*p*</sup> with eigenvalue *λ*<sub>*p*</sub> prime to *p*. We describe a procedure for deriving a measure of **Z**<sub>*D*</sub>.

Fix an integer *N* prime to *p* and to *D*. Let *F* be the *D*-module of all functions on rational numbers with denominator coprime to *N*. For any prime *l* not dividing *N* we define the *Hecke operator* *T*<sub>*l*</sub> by

$$(T_l f)\left(\frac a b\right) = f\left(\frac{la}{b}\right) + \sum_{k=0}^{l-1} f\left({\frac{a+kb}{lb}}\right) - \sum_{k=0}^{l-1} f\left(\frac k l \right) \ .$$

Let *f* be an eigenfunction for *T*<sub>*p*</sub> with eigenvalue λ<sub>*p*</sub> in *D*. The quadratic equation *X*<sup>2</sup> − λ<sub>*p*</sub>*X* + *p* = 0 has roots π<sub>1</sub>, π<sub>2</sub> with π<sub>1</sub> a unit and π<sub>2</sub> divisible by *p*. Define a sequence *a*<sub>0</sub> = 2, *a*<sub>1</sub> = π<sub>1</sub>+π<sub>2</sub> = *λ*<sub>*p*</sub> and

$$a_{k+2} = \lambda_p a_{k+1} - p a_k \ ,$$

so that

$$a_k = \pi_1^k + \pi_2^k \ .$$
