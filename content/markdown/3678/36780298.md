# Partition matroid

*Image: Partition matroid.svg.* For the [bipartite graph](wikipedia://en/244431) shown on the left, each vertex in the first column is assigned a unique color. Then, each edge is colored based on which colored vertex it is connected to. Each independent set in the [matroid](wikipedia://en/244321) on the right is allowed a maximum of 1 edge of each color. Thus, the matroid is a **partition matroid** with $|C_i| = 3$ and $d_i = 1$ for all $i$. The latter condition means this matroid is also a [transversal matroid](https://en.wikipedia.org/wiki/Transversal_matroid).

::: {#o1 .subject cue=lead name="Partition matroid"}

In mathematics, a **partition matroid** or **partitional matroid** is a [matroid](wikipedia://en/244321) that is a [direct sum](wikipedia://en/2084687) of [uniform matroids](wikipedia://en/27967069).[^o2] It is defined over a base set in which the elements are partitioned into different categories. For each category, there is a *capacity constraint* - a maximum number of allowed elements from this category. The independent sets of a partition matroid are exactly the sets in which, for each category, the number of elements from this category is at most the category capacity.

:::

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let $C_i$ be a collection of [disjoint sets](wikipedia://en/39359) ("categories"). Let $d_i$ be integers with $0\le d_i\le |C_i|$ ("capacities"). Define a subset $I\subseteq \bigcup_i C_i$ to be "independent" when, for every index $i$, $|I\cap C_i|\le d_i$. The sets satisfying this condition form the independent sets of a [matroid](wikipedia://en/244321), called a **partition matroid**.

The sets $C_i$ are called the **categories** or the **blocks** of the partition matroid.

A **basis** of the partition matroid is a set whose intersection with every block $C_i$ has size exactly $d_i$. A **circuit** of the matroid is a subset of a single block $C_i$ with size exactly $d_i+1$. The [**rank**](wikipedia://en/37123010) of the matroid is $\sum d_i$.[^o5]

Every [uniform matroid](wikipedia://en/27967069) $U{}^r_n$ is a partition matroid, with a single block $C_1$ of $n$ elements and with $d_1=r$. Every partition matroid is the direct sum of a collection of uniform matroids, one for each of its blocks.

In some publications, the notion of a partition matroid is defined more restrictively, with every $d_i=1$. The partitions that obey this more restrictive definition are the [transversal matroids](https://en.wikipedia.org/wiki/Transversal_matroid) of the family of disjoint sets given by their blocks.[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

As with the uniform matroids they are formed from, the [dual matroid](wikipedia://en/23515837) of a partition matroid is also a partition matroid, and every [minor](wikipedia://en/36749660) of a partition matroid is also a partition matroid. Direct sums of partition matroids are partition matroids as well.

:::

## Matching {#Matching}

A [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching) in a graph is a set of edges that is as large as possible subject to the condition that no two edges share an endpoint. In a [bipartite graph](wikipedia://en/244431) with bipartition $(U,V)$, the sets of edges satisfying the condition that no two edges share an endpoint in $U$ are the independent sets of a partition matroid with one block per vertex in $U$ and with each of the numbers $d_i$ equal to one. The sets of edges satisfying the condition that no two edges share an endpoint in $V$ are the independent sets of a second partition matroid. Therefore, the bipartite maximum matching problem can be represented as a [matroid intersection](wikipedia://en/23258067) of these two matroids.[^o10]

More generally the matchings of a graph may be represented as an intersection of two matroids if and only if every odd cycle in the graph is a triangle containing two or more degree-two vertices.[^o11]

## Clique complexes {#Clique_complexes}

A [clique complex](wikipedia://en/20751674) is a [family of sets](wikipedia://en/723043) of vertices of a graph $G$ that induce complete subgraphs of $G$. A clique complex forms a matroid if and only if $G$ is a [complete multipartite graph](https://en.wikipedia.org/wiki/Complete_multipartite_graph), and in this case the resulting matroid is a partition matroid. The clique complexes are exactly the set systems that can be formed as [intersections](wikipedia://en/23258067) of families of partition matroids for which every $d_i=1$.[^o13]

::: {#o15 .definition kind=definition/construction cue=heading name="Enumeration"}

## Enumeration {#Enumeration}

The number of distinct partition matroids that can be defined over a set of $n$ labeled elements, for $n=0,1,2,\dots$, is

1, 2, 5, 16, 62, 276, 1377, 7596, 45789, 298626, 2090910, ... .

The [exponential generating function](https://en.wikipedia.org/wiki/Exponential_generating_function) of this sequence is $f(x)=\exp(e^x(x-1)+2x+1)$.[^o16]

:::
