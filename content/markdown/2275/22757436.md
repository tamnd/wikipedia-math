# Trivial semigroup

::: {#o1 .subject cue=lead name="Trivial semigroup"}

In [mathematics](wikipedia://en/18831), a **trivial semigroup** (a **semigroup with one element**) is a [semigroup](wikipedia://en/27799) for which the [cardinality](wikipedia://en/6174) of the [underlying set](https://en.wikipedia.org/wiki/Underlying_set) is [one](https://en.wikipedia.org/wiki/One). The number of [distinct](https://en.wikipedia.org/wiki/Distinct_%28mathematics%29) [nonisomorphic](https://en.wikipedia.org/wiki/Isomorphic) semigroups with one element is one. If *S* = { *a* } is a semigroup with one element, then the [Cayley table](wikipedia://en/1802723) of *S* is

:::

{| class="wikitable"

\|- ! ! *a* |- | ***a*** | *a* |}

The only element in *S* is the [zero element](wikipedia://en/14206224) 0 of *S* and is also the [identity element](wikipedia://en/14962) 1 of *S*.[^o2] However not all semigroup theorists consider the unique element in a semigroup with one element as the zero element of the semigroup. They define zero elements only in semigroups having at least two elements.[^o3][^o4]

In spite of its extreme triviality, the semigroup with one element is important in many situations. It is the starting point for understanding the [structure](https://en.wikipedia.org/wiki/Structure) of semigroups. It serves as a [counterexample](wikipedia://en/143151) in illuminating many situations. For example, the semigroup with one element is the only semigroup in which 0 = 1, that is, the zero element and the identity element are equal. Further, if *S* is a semigroup with one element, the semigroup obtained by adjoining an identity element to *S* is isomorphic to the semigroup obtained by adjoining a zero element to *S*.

The semigroup with one element is also a [group](wikipedia://en/19447).

In the language of [category theory](wikipedia://en/5869), any semigroup with one element is a [terminal object](wikipedia://en/59405) in the category of semigroups.
