# Modulus (algebraic number theory)

::: {#o1 .subject cue=lead name="Modulus"}

In [mathematics](wikipedia://en/18831), in the field of [algebraic number theory](wikipedia://en/174705), a **modulus** (plural **moduli**) (or **cycle**,[^o2] or **extended ideal**[^o3]) is a formal product of [places](https://en.wikipedia.org/wiki/Place_%28mathematics%29) of a [global field](wikipedia://en/288358) (i.e. an [algebraic number field](wikipedia://en/28730822) or a [global function field](https://en.wikipedia.org/wiki/Global_function_field)). It is used to encode [ramification](wikipedia://en/384644) data for [abelian extensions](wikipedia://en/174448) of a global field.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *K* be a global field with [ring of integers](wikipedia://en/460613) *R*. A **modulus** is a formal product[^o6][^o7]

$$\mathbf{m} = \prod_{\mathbf{p}} \mathbf{p}^{\nu(\mathbf{p})},\,\,\nu(\mathbf{p})\geq0$$

where **p** runs over all [places](https://en.wikipedia.org/wiki/Place_%28mathematics%29) of *K*, [finite](https://en.wikipedia.org/wiki/Finite_place) or [infinite](https://en.wikipedia.org/wiki/Infinite_place), the exponents ν(**p**) are zero except for finitely many **p**. If *K* is a number field, ν(**p**) = 0 or 1 for real places and ν(**p**) = 0 for complex places. If *K* is a function field, ν(**p**) = 0 for all infinite places.

In the function field case, a modulus is the same thing as an [effective divisor](https://en.wikipedia.org/wiki/Effective_divisor),[^o8] and in the number field case, a modulus can be considered as special form of [Arakelov divisor](https://en.wikipedia.org/wiki/Arakelov_divisor).[^o9]

The notion of [congruence](wikipedia://en/20087) can be extended to the setting of moduli. If *a* and *b* are elements of *K*<sup>×</sup>, the definition of *a* ≡<sup>∗</sup>*b* (mod **p**<sup>ν</sup>) depends on what type of prime **p** is:[^o10][^o11]

- if it is finite, then

$$a\equiv^\ast\!b\,(\mathrm{mod}\,\mathbf{p}^\nu)\Leftrightarrow \mathrm{ord}_\mathbf{p}\left(\frac{a}{b}-1\right)\geq\nu$$

where ord<sub>**p**</sub> is the [normalized valuation](https://en.wikipedia.org/wiki/Normalized_valuation) associated to **p**;

- if it is a real place (of a number field) and ν = 1, then

$$a\equiv^\ast\!b\,(\mathrm{mod}\,\mathbf{p})\Leftrightarrow \frac{a}{b}>0$$

under the [real embedding](https://en.wikipedia.org/wiki/Real_embedding) associated to **p**.

- if it is any other infinite place, there is no condition.

Then, given a modulus **m**, *a* ≡<sup>∗</sup>*b* (mod **m**) if *a* ≡<sup>∗</sup>*b* (mod **p**<sup>ν(**p**)</sup>) for all **p** such that ν(**p**) > 0.

:::

## Ray class group {#Ray_class_group}

The **ray modulo m** is[^o13][^o14][^o15]

$$K_{\mathbf{m},1}=\left\{ a\in K^\times : a\equiv^\ast\!1\,(\mathrm{mod}\,\mathbf{m})\right\}.$$

A modulus **m** can be split into two parts, **m**<sub>f</sub> and **m**<sub>∞</sub>, the product over the finite and infinite places, respectively. Let *I*<sup>**m**</sup> to be one of the following:

- if *K* is a number field, the subgroup of the [group of fractional ideals](https://en.wikipedia.org/wiki/Group_of_fractional_ideals) generated by ideals coprime to **m**<sub>f</sub>;[^o16]
- if *K* is a function field of an [algebraic curve](wikipedia://en/253260) over *k*, the group of divisors, [rational](https://en.wikipedia.org/wiki/Rational_divisor) over *k*, with [support](https://en.wikipedia.org/wiki/Support_of_a_divisor) away from **m**.[^o17]

In both case, there is a [group homomorphism](wikipedia://en/12396) *i* : *K*<sub>**m**,1</sub> → *I*<sup>**m**</sup> obtained by sending *a* to the [principal ideal](wikipedia://en/145126) (resp. [divisor](https://en.wikipedia.org/wiki/Principal_divisor)) (*a*).

The **ray class group modulo m** is the quotient *C*<sub>**m**</sub> = *I*<sup>**m**</sup> / i(*K*<sub>**m**,1</sub>).[^o18][^o19] A coset of i(*K*<sub>**m**,1</sub>) is called a **ray class modulo m**.

[Erich Hecke](wikipedia://en/1233990)'s original definition of [Hecke characters](wikipedia://en/3149443) may be interpreted in terms of [characters](wikipedia://en/293418) of the ray class group with respect to some modulus **m**.[^o20]

::: {#o22 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

When *K* is a number field, the following properties hold.[^o23]

- When **m** = 1, the ray class group is just the [ideal class group](wikipedia://en/150907).
- The ray class group is finite. Its order is the **ray class number**.
- The ray class number is divisible by the [class number](https://en.wikipedia.org/wiki/Class_number_%28number_theory%29) of *K*.

:::
