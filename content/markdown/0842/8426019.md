# Negligible function

::: {#o1 .subject cue=lead name="Negligible function"}

In mathematics, a **negligible function** is a [function](wikipedia://en/185427) $\mu:\mathbb{N}\to\mathbb{R}$ such that for every positive [integer](wikipedia://en/14563) *c* there exists an integer *N*<sub>*c*</sub> such that for all *n* > *N*<sub>*c*</sub>,

:::

$$|\mu(n)|<\frac{1}{n^c}.$$

Equivalently, the following definition may be used. A function $\mu:\mathbb{N}\to\mathbb{R}$ is **negligible**, if for every [positive polynomial](wikipedia://en/28416554) poly(·) there exists an integer *N*<sub>poly</sub> > 0 such that for all *n* > *N*<sub>poly</sub>

$$|\mu(n)|<\frac 1 {\operatorname{poly}(n)}.$$

## History {#History}

The concept of *negligibility* can find its trace back to sound models of analysis. Though the concepts of "[continuity](wikipedia://en/6122)" and "[infinitesimal](wikipedia://en/160990)" became important in mathematics during [Newton](wikipedia://en/14627) and [Leibniz](https://en.wikipedia.org/wiki/Gottfried_Leibniz)'s time (1680s), they were not well-defined until the late 1810s. The first reasonably rigorous definition of *continuity* in [mathematical analysis](wikipedia://en/48396) was due to [Bernard Bolzano](wikipedia://en/302185), who wrote in 1817 the modern definition of continuity. Later [Cauchy](https://en.wikipedia.org/wiki/Augustin_Louis_Cauchy), [Weierstrass](wikipedia://en/93459) and [Heine](wikipedia://en/608289) also defined as follows (with all numbers in the [real number](wikipedia://en/20646438) domain $\mathbb{R}$):

**([Continuous function](wikipedia://en/6122))** A function $f:\mathbb{R}{\rightarrow}\mathbb{R}$ is *continuous* at $x=x_0$ if for every $\varepsilon>0$, there exists a positive number $\delta>0$ such that $|x-x_0|<\delta$ implies $|f(x)-f(x_0)|<\varepsilon.$

This classic definition of continuity can be transformed into the definition of negligibility in a few steps by changing parameters used in the definition. First, in the case $x_0=\infty$ with $f(x_0)=0$, we must define the concept of "*infinitesimal function*":

**([Infinitesimal](wikipedia://en/160990))** A continuous function $\mu:\mathbb{R}\to\mathbb{R}$ is *infinitesimal* (as $x$ goes to infinity) if for every $\varepsilon>0$ there exists $N_\varepsilon$ such that for all $x>N_\varepsilon$

$$|\mu(x)|<\varepsilon\,.$$

Next, in the discrete setting where the domain is restricted to natural numbers $n \in \mathbb{N}$, we replace $\varepsilon>0$ by the functions $1/n^c$ where $c>0$ or by $1/\operatorname{poly}(n)$ where $\operatorname{poly}(n)$ is a positive [polynomial](wikipedia://en/23000). This leads to the definitions of negligible functions given at the top of this article. Since the constants $\varepsilon>0$ can be expressed as $1/\operatorname{poly}(n)$ with a constant polynomial, this shows that infinitesimal functions (restricted to $\mathbb{N}$) are a superset of negligible functions.

## Use in cryptography {#Use_in_cryptography}

In complexity-based modern [cryptography](wikipedia://en/18934432), a security scheme is *[provably secure](wikipedia://en/1182348)* if the probability of security failure (e.g., inverting a [one-way function](wikipedia://en/363890), distinguishing [cryptographically strong pseudorandom bits](wikipedia://en/182249) from truly random bits) is **negligible** in terms of the input security parameter or cryptographic key length $n$. Hence comes the definition at the top of the page because key length $n$ must be a [natural number](wikipedia://en/21474).

Nevertheless, the general notion of negligibility doesn't require that the input parameter $n$ is strictly the key length. Indeed, $n$ can be any predetermined discrete system metric and corresponding mathematical analysis would illustrate some hidden analytical behaviors of the system.

The reciprocal-of-polynomial formulation is used for the same reason that [computational boundedness](wikipedia://en/39275268) is defined as polynomial running time: it has mathematical closure properties that make it tractable in the [asymptotic](https://en.wikipedia.org/wiki/Asymptotic_security) setting (see #Closure properties). For example, if an attack succeeds in violating a security condition only with negligible probability, and the attack is repeated a polynomial number of times, the success probability of the overall attack still remains negligible.

In practice one might want to have more [concrete](wikipedia://en/2288644) functions bounding the adversary's success probability and to choose the [security parameter](wikipedia://en/2290431) large enough that this probability is smaller than some threshold, say 2<sup>−128</sup>.

## Closure properties {#Closure_properties}

One of the reasons that negligible functions are used in foundations of [complexity-theoretic](wikipedia://en/7543) cryptography is that they obey closure properties.[^o5] Specifically,

1. If $f,g:\mathbb{N}\to\mathbb{R}$ are negligible, then the function $n\mapsto f(n)+g(n)$ is negligible.
1. If $f:\mathbb{N}\to\mathbb{R}$ is negligible and $p$ is any real polynomial, then the function $n\mapsto p(n)\cdot f(n)$ is negligible.

[Conversely](wikipedia://en/155941), if $f:\mathbb{N}\to\mathbb{R}$ is not negligible, then neither is $n\mapsto f(n)/p(n)$ for any real polynomial $p$.

## Examples {#Examples}

- $n \mapsto a^{-n}$ is negligible for any constant $a \geq 2$:
  - **Step**: This is an [exponential decay](wikipedia://en/330320) function where $a$ is a constant greater than or equal to 2. As $n \to \infty$, $a^{-n} \to 0$ very quickly, making it negligible.
- $f(n) = 3^{-\sqrt{n}}$ is negligible:
  - **Step**: This function has exponential decay with a base of 3, but the exponent grows slower than $n$ (only at $\sqrt{n}$). As $n \to \infty$, $3^{-\sqrt{n}} \to 0$, so it’s still negligible but decays slower than $3^{-n}$.
- $f(n) = n^{-\log n}$ is negligible:
  - **Step**: In this case, $n^{-\log n}$ represents a superpolynomial decay, with the exponent growing negatively due to $\log n$. Since the decay rate increases with $n$, the function goes to 0 faster than polynomial functions like $n^{-k}$ for any constant $k$, making it negligible.
- $f(n) = (\log n)^{-\log n}$ is negligible:
  - **Step**: This function decays as the [logarithm](wikipedia://en/17860) of $n$ raised to a negative exponent $-\log n$, which leads to a fast approach to 0 as $n \to \infty$. The decay here is faster than inverse logarithmic or polynomial rates, making it negligible.
- $f(n) = 2^{-c \log n}$ is not negligible, for positive $c$:
  - **Step**: We can rewrite this as $f(n) = n^{-c}$, which is a polynomial decay rather than an exponential one. Since $c$ is positive, $f(n) \to 0$ as $n \to \infty$, but it doesn’t decay as quickly as true exponential functions with respect to $n$, making it non-negligible.

Assuming $n > 0$ and a fixed real constant $a > 1$, we take the limit as $n \to \infty$:

**Negligible:**

- $f(n) = \frac{1}{a^{n/2}}$:
  - **Step**: This function decays exponentially with base $a$ raised to the power of $-\frac{n}{2}$. As $n \to \infty$, $a^{-\frac{n}{2}} \to 0$ quickly, making it negligible.
- $f(n) = \frac{1}{a^{\log{(n^k)}}}$ for $k \geq 1$:
  - **Step**: We can simplify $a^{-\log(n^k)}$ as $n^{-k \log a}$, which decays faster than any polynomial. As $n \to \infty$, the function approaches zero and is considered negligible for any $k \geq 1$ and $a > 1$.
- $f(n) = \frac{1}{a^{(\log n)^k}}$ for $k \geq 1$:
  - **Step**: The decay is determined by the base $a$ raised to the power of $-(\log n)^k$. Since $(\log n)^k$ grows with $n$, this function approaches zero faster than polynomial decay, making it negligible.
- $f(n) = \frac{1}{a^{\sqrt{n}}}$:
  - **Step**: Here, $f(n)$ decays exponentially with a base of $a$ raised to $-\sqrt{n}$. As $n \to \infty$, $f(n) \to 0$ quickly, so it’s considered negligible.
- $f(n) = \frac{1}{a^{n(\log n)}}$:
  - **Step**: With an exponential base and exponent $n(\log n)$, this function would approach zero very rapidly, suggesting negligibility.

**Non-negligible:**

- $f(n) = \frac{1}{n^{1/n}}$:
  - **Step**: Since $n^{1/n} \to 1$ as $n \to \infty$, this function decays very slowly, failing to approach zero quickly enough to be considered negligible.
