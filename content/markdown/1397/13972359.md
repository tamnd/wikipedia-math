# Separating set

::: {#o1 .subject cue=lead name="Separating set"}

In [mathematics](wikipedia://en/18831), a [set](wikipedia://en/26691) $S$ of [functions](wikipedia://en/185427) with [domain](wikipedia://en/50263) $D$ is called a **separating set** for $D$ and is said to **separate** the points of $D$ (or just to **separate points**) if for any two distinct elements $x$ and $y$ of $D,$ there exists a function $f \in S$ such that $f(x) \neq f(y).$[^o2]

:::

Separating sets can be used to formulate a version of the [Stone–Weierstrass theorem](wikipedia://en/28858) for real-valued functions on a [compact Hausdorff space](https://en.wikipedia.org/wiki/Compact_Hausdorff_space) $X,$ with the topology of [uniform convergence](wikipedia://en/50652). It states that any subalgebra of this space of functions is dense if and only if it separates points. This is the version of the theorem originally proved by [Marshall H. Stone](wikipedia://en/758331).[^o2]

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- The [singleton set](https://en.wikipedia.org/wiki/Singleton_set) consisting of the [identity function](wikipedia://en/15069) on $\mathbb{R}$ separates the points of $\mathbb{R}.$
- If $X$ is a [T1](wikipedia://en/148721) [normal topological space](https://en.wikipedia.org/wiki/Normal_topological_space), then [Urysohn's lemma](wikipedia://en/49253) states that the set $C(X)$ of [continuous functions](wikipedia://en/6122) on $X$ with [real](wikipedia://en/20646438) (or [complex](wikipedia://en/5826)) values separates points on $X.$
- If $X$ is a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) Hausdorff topological vector space over $\mathbb{R}$ or $\mathbb{C},$ then the [Hahn–Banach separation theorem](https://en.wikipedia.org/wiki/Hahn–Banach_separation_theorem) implies that [continuous linear functionals](https://en.wikipedia.org/wiki/Continuous_linear_functional) on $X$ separate points.

:::
