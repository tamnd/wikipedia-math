# Finite von Neumann algebra

::: {#o1 .subject cue=lead name="Finite von Neumann algebra"}

In [mathematics](wikipedia://en/18831), a **finite von Neumann algebra** is a [von Neumann algebra](wikipedia://en/294185) in which every [isometry](wikipedia://en/254777) is a [unitary](wikipedia://en/225999). In other words, for an operator *V* in a finite von Neumann algebra if $V^*V = I$, then $VV^* = I$. In terms of the [comparison theory of projections](wikipedia://en/294185#Comparison_theory_of_projections), the identity operator is not (Murray-von Neumann) equivalent to any proper subprojection in the von Neumann algebra.

:::

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $\mathcal{M}$ denote a finite von Neumann algebra with [center](wikipedia://en/342453) $\mathcal{Z}$. One of the fundamental characterizing properties of finite von Neumann algebras is the existence of a center-valued trace. A von Neumann algebra $\mathcal{M}$ is finite [if and only if](wikipedia://en/14922) there exists a [normal](wikipedia://en/294185#The_predual) positive bounded map $\tau : \mathcal{M} \to \mathcal{Z}$ with the properties:

- $$\tau(AB) = \tau(BA), A, B \in \mathcal{M},$$
- if $A \ge 0$ and $\tau(A) = 0$ then $A = 0$,
- $\tau(C) = C$ for $C \in \mathcal{Z}$,
- $\tau(CA) = C\tau(A)$ for $A \in \mathcal{M}$ and $C \in \mathcal{Z}$.

:::

## Examples {#Examples}

### Finite-dimensional von Neumann algebras {#Finite-dimensional_von_Neumann_algebras}

The finite-dimensional von Neumann algebras can be characterized using [Wedderburn](wikipedia://en/2969494)'s theory of [semisimple algebras](wikipedia://en/3876151). Let **C**<sup>*n* × *n*</sup> be the *n* × *n* matrices with complex entries. A **von Neumann algebra** **M** is a self adjoint subalgebra in **C**<sup>*n* × *n*</sup> such that **M** contains the identity operator *I* in **C**<sup>*n* × *n*</sup>.

Every such **M** as defined above is a [semisimple algebra](wikipedia://en/3876151), i.e. it contains no nilpotent ideals. Suppose *M* ≠ 0 lies in a [nilpotent ideal](wikipedia://en/6389159) of **M**. Since *M\** ∈ **M** by assumption, we have *M\*M*, a positive semidefinite matrix, lies in that nilpotent ideal. This implies (*M\*M*)<sup>*k*</sup> = 0 for some *k*. So *M\*M* = 0, i.e. *M* = 0.

The [center](wikipedia://en/342453) of a von Neumann algebra **M** will be denoted by *Z*(**M**). Since **M** is self-adjoint, *Z*(**M**) is itself a (commutative) von Neumann algebra. A von Neumann algebra **N** is called a **factor** if *Z*(**N**) is one-dimensional, that is, *Z*(**N**) consists of multiples of the identity *I*.

::: {#o7 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem** Every finite-dimensional von Neumann algebra **M** is a direct sum of *m* factors, where *m* is the dimension of *Z*(**M**).

:::

::: {#o8 .proof cue=inline-head name="Proof"}

**Proof:** By Wedderburn's theory of semisimple algebras, *Z*(**M**) contains a finite orthogonal set of idempotents (projections) {*P<sub>i</sub>*} such that *P<sub>i</sub>P<sub>j</sub>* = 0 for *i* ≠ *j*, Σ *P<sub>i</sub>* = *I*, and

$$Z(\mathbf M) = \bigoplus _i Z(\mathbf M) P_i$$

where each *Z*(**M***)P<sub>i</sub>* is a commutative simple algebra. Every complex simple algebras is isomorphic to the full matrix algebra **C**<sup>*k* × *k*</sup> for some *k*. But *Z*(**M***)P<sub>i</sub>* is commutative, therefore one-dimensional.

The projections *P<sub>i</sub>* "diagonalizes" **M** in a natural way. For *M* ∈ **M**, *M* can be uniquely decomposed into *M* = Σ *MP<sub>i</sub>*. Therefore,

$${\mathbf M} = \bigoplus_i {\mathbf M} P_i .$$

One can see that *Z*(**M***P<sub>i</sub>*) = *Z*(**M***)P<sub>i</sub>*. So *Z*(**M***P<sub>i</sub>*) is one-dimensional and each **M***P<sub>i</sub>* is a factor. This proves the claim.

For general von Neumann algebras, the direct sum is replaced by the [direct integral](wikipedia://en/1256105). The above is a special case of the [central decomposition of von Neumann algebras](wikipedia://en/1256105#Central_decomposition).

:::

### Abelian von Neumann algebras {#Abelian_von_Neumann_algebras}

Abelian von Neumann algebras are all isomorphic to a multiplication algebra $L^\infty(X)$ for some [measure space](wikipedia://en/45270) $(X,\mu)$. Since an abelian von Neumann algebra M is commutative, for any $V\in M$, $V^*V=VV^*$, so clearly any isometry is unitary.
