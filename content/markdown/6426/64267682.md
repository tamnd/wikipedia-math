# Bornivorous set

::: {#o1 .subject cue=lead name="Bornivorous set"}

In [functional analysis](wikipedia://en/11180), a subset of a real or complex vector space $X$ that has an associated [vector bornology](wikipedia://en/64304060) $\mathcal{B}$ is called **bornivorous** and a **bornivore** if it [absorbs](wikipedia://en/1728179) every element of $\mathcal{B}.$ If $X$ is a [topological vector space](wikipedia://en/45752) (TVS) then a subset $S$ of $X$ is **bornivorous** if it is bornivorous with respect to the [von-Neumann bornology of $X$](wikipedia://en/1804457).

:::

Bornivorous sets play an important role in the definitions of many classes of topological vector spaces, particularly [bornological spaces](wikipedia://en/1804457).

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

If $X$ is a TVS then a subset $S$ of $X$ is called **bornivorous**[^n1] and a **bornivore** if $S$ [absorbs](wikipedia://en/1728179) every [bounded subset](wikipedia://en/1789812) of $X.$

An [absorbing](wikipedia://en/1728179) disk in a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) space is bornivorous if and only if its [Minkowski functional](wikipedia://en/3510908) is locally bounded (i.e. maps bounded sets to bounded sets).[^n1]

### Infrabornivorous sets and infrabounded maps {#Infrabornivorous_sets_and_infrabounded_maps}

A linear map between two TVSs is called **infrabounded** if it maps [Banach disks](wikipedia://en/63622954) to bounded disks.[^n2]

A disk in $X$ is called **infrabornivorous** if it [absorbs](wikipedia://en/1728179) every [Banach disk](https://en.wikipedia.org/wiki/Banach_disk).[^n3]

An [absorbing](wikipedia://en/1728179) disk in a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) space is infrabornivorous if and only if its [Minkowski functional](wikipedia://en/3510908) is infrabounded.[^n1] A disk in a Hausdorff [locally convex](https://en.wikipedia.org/wiki/Locally_convex) space is infrabornivorous if and only if it absorbs all compact disks (that is, if it is "compactivorous").[^n1]

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every bornivorous and infrabornivorous subset of a TVS is [absorbing](wikipedia://en/1728179). In a [pseudometrizable TVS](https://en.wikipedia.org/wiki/Pseudometrizable_TVS), every bornivore is a neighborhood of the origin.[^n4]

Two TVS topologies on the same vector space have that same bounded subsets if and only if they have the same bornivores.[^n5]

Suppose $M$ is a vector subspace of finite codimension in a locally convex space $X$ and $B \subseteq M.$ If $B$ is a barrel (resp. bornivorous barrel, bornivorous disk) in $M$ then there exists a barrel (resp. bornivorous barrel, bornivorous disk) $C$ in $X$ such that $B = C \cap M.$[^n6]

:::

## Examples and sufficient conditions {#Examples_and_sufficient_conditions}

Every neighborhood of the origin in a TVS is bornivorous. The convex hull, closed convex hull, and [balanced hull](wikipedia://en/1734238) of a bornivorous set is again bornivorous. The preimage of a bornivore under a bounded linear map is a bornivore.[^n7]

If $X$ is a TVS in which every bounded subset is contained in a finite dimensional vector subspace, then every absorbing set is a bornivore.[^n5]

### Counter-examples {#Counter-examples}

Let $X$ be $\mathbb{R}^2$ as a vector space over the reals. If $S$ is the balanced hull of the closed line segment between $(-1, 1)$ and $(1, 1)$ then $S$ is not bornivorous but the convex hull of $S$ is bornivorous. If $T$ is the closed and "filled" triangle with vertices $(-1, -1), (-1, 1),$ and $(1, 1)$ then $T$ is a convex set that is not bornivorous but its balanced hull is bornivorous.
