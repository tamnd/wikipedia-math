# Bennett, Alpert and Goldstein's S

::: {#o1 .subject cue=lead name="Bennett, Alpert and Goldstein's S"}

**Bennett, Alpert & Goldstein’s *S*** is a [statistical](wikipedia://en/26685) measure of [inter-rater agreement](https://en.wikipedia.org/wiki/Inter-rater_agreement). It was created by Bennett *et al.* in 1954.[^o2]

:::

## Rationale for use {#Rationale_for_use}

Bennett *et al.* suggested adjusting [inter-rater reliability](wikipedia://en/7837393) to accommodate the [percentage](wikipedia://en/64493) of rater agreement that might be expected by chance was a better measure than simple agreement between raters.[^o4] They proposed an index which adjusted the [proportion](wikipedia://en/81863) of rater agreement based on the number of categories employed.

## [Mathematical formulation](https://en.wikipedia.org/wiki/Mathematical_formula) {#Mathematical_formulation}

The formula for *S* is

$$S = \frac{ Q P_a - 1 } { Q - 1 }$$

where *Q* is the number of categories and *P*<sub>a</sub> is the proportion of agreement between raters.

The [variance](wikipedia://en/32344) of *S* is

$$\operatorname{Var}(S) = \left( \frac { Q } { Q - 1 } \right)^2 \frac { P_a ( P_a - 1 ) } { n - 1 }$$

## Notes {#Notes}

This statistic is also known as Guilford’s *G*.[^o7] Guilford was the first person to use the approach extensively in the determination of inter-rater reliability.
