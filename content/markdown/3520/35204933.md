# Ring class field

::: {#o1 .subject cue=lead name="Ring class field"}

In [algebraic number theory](wikipedia://en/174705), a **ring class field** is the [abelian extension](wikipedia://en/174448) of an [algebraic number field](wikipedia://en/28730822) $K$ associated by [class field theory](wikipedia://en/242695) to the **ring class group** of some [order](wikipedia://en/1114171) $\mathcal{O}$ of the [ring of integers](wikipedia://en/460613) of $K$.[^n1]

:::

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

- Let $K$ be any number field. The ring class field for the maximal order $\mathcal{O}=\mathcal{O}_K$ is the [Hilbert class field](wikipedia://en/3021036) $H$.
- Let $K=\mathbb{Q}(\sqrt{-n})$.
  - The ring class field for the order $\mathcal{O}=\mathbb{Z}[\sqrt{-n}]$ is $L=K(a)$, where $a$ is an [algebraic integer](wikipedia://en/98981) with [minimal polynomial](wikipedia://en/9667106) over $\mathbb{Q}$ of [degree](wikipedia://en/5930652) $h(-4n)$, the [class number](wikipedia://en/150907) of an order with discriminant $-4n$. Moreover, if $p$ is an [odd](wikipedia://en/143135) [prime](wikipedia://en/23666) not dividing $n$, then $p$ [splits completely](wikipedia://en/1190816) in $L$ if and only if $p$ splits completely in $K$.
- If $\mathcal{O}$ is an order and $a$ is a proper [fractional *O*-ideal](wikipedia://en/460700); i.e.

$$\{x\in K^\times: xa\subset a\}=\mathcal{O},$$

write $j(a)$ for the [*j*-invariant](wikipedia://en/451988) of the associated [elliptic curve](wikipedia://en/10225). Then $K(j(a))$ is the ring class field of $\mathcal{O}$ and $j(a)$ is an algebraic integer.

:::
