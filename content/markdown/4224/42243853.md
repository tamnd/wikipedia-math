# Stan (software)

::: {#o2 .subject cue=lead name="Stan"}

**Stan** is a [probabilistic programming language](https://en.wikipedia.org/wiki/Probabilistic_programming_language) for [statistical inference](wikipedia://en/27577) written in [C++](https://en.wikipedia.org/wiki/C++).[^o3] The Stan language is used to specify a (Bayesian) [statistical model](wikipedia://en/27576) with an [imperative program](https://en.wikipedia.org/wiki/Imperative_programming) calculating the log [probability density function](wikipedia://en/43487).[^o3]

:::

Stan is licensed under the [New BSD License](https://en.wikipedia.org/wiki/BSD_licenses#3-clause_license_%28"Revised_BSD_License",_"New_BSD_License",_or_"Modified_BSD_License"%29). Stan is named in honour of [Stanislaw Ulam](https://en.wikipedia.org/wiki/Stanislaw_Ulam), pioneer of the [Monte Carlo method](wikipedia://en/56098).[^o3]

Stan was created by a development team consisting of 52 members[^o4] that includes [Andrew Gelman](wikipedia://en/25745941), Bob Carpenter, Daniel Lee, Ben Goodrich, and others.

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

A simple linear regression model can be described as $y_n = \alpha + \beta x_n + \epsilon_n$, where $\epsilon_n \sim \text{normal} (0, \sigma)$. This can also be expressed as $y_n \sim \text{normal}(\alpha + \beta X_n, \sigma)$. The latter form can be written in Stan as the following:

```stan
data {
  int<lower=0> N;
  vector[N] x;
  vector[N] y;
}
parameters {
  real alpha;
  real beta;
  real<lower=0> sigma;
}
model {
  y ~ normal(alpha + beta * x, sigma);
}
```

:::

## Interfaces {#Interfaces}

The Stan language itself can be accessed through several interfaces:

- CmdStan – a command-line executable for the [shell](https://en.wikipedia.org/wiki/Unix_Shell),
- CmdStanR and rstan – [R software](wikipedia://en/376707) libraries,
- CmdStanPy and PyStan – libraries for the [Python programming language](https://en.wikipedia.org/wiki/Python_programming_language),
- CmdStan.rb - library for the [Ruby programming language](https://en.wikipedia.org/wiki/Ruby_%28programming_language%29),
- MatlabStan – integration with the [MATLAB](wikipedia://en/20412) numerical computing environment,
- Stan.jl – integration with the [Julia programming language](https://en.wikipedia.org/wiki/Julia_programming_language),
- StataStan – integration with [Stata](wikipedia://en/1809002).
- Stan Playground - online at <https://stan-playground.flatironinstitute.org/>

In addition, higher-level interfaces are provided with packages using Stan as backend, primarily in the [R language](wikipedia://en/376707):[^o8]

- *rstanarm* provides a drop-in replacement for frequentist models provided by base R and *lme4* using the R formula syntax;
- *brms*[^o9] provides a wide array of linear and nonlinear models using the R formula syntax;
- *prophet* provides automated procedures for [time series](wikipedia://en/406624) [forecasting](wikipedia://en/246074).

::: {#o11 .definition kind=definition/construction cue=heading name="Algorithms"}

## Algorithms {#Algorithms}

Stan implements gradient-based [Markov chain Monte Carlo](wikipedia://en/236801) (MCMC) algorithms for Bayesian inference, stochastic, gradient-based [variational Bayesian methods](wikipedia://en/1208480) for approximate Bayesian inference, and gradient-based [optimization](https://en.wikipedia.org/wiki/Optimization_%28mathematics%29) for penalized maximum likelihood estimation.

- MCMC algorithms:
  - [Hamiltonian Monte Carlo](wikipedia://en/32164063) (HMC)
  - No-U-Turn sampler[^o3][^o12] (NUTS), a variant of HMC and Stan's default MCMC engine
- Variational inference algorithms:
  - Automatic Differentiation Variational Inference[^o13]
  - Pathfinder: Parallel quasi-Newton variational inference[^o14]
- Optimization algorithms:
  - [Limited-memory BFGS](https://en.wikipedia.org/wiki/Limited-memory_BFGS) (L-BFGS) (Stan's default optimization algorithm)
  - [Broyden–Fletcher–Goldfarb–Shanno algorithm](wikipedia://en/1926409) (BFGS)
  - [Laplace's approximation](wikipedia://en/71313889) for classical standard error estimates and approximate Bayesian posteriors

:::

## Automatic differentiation {#Automatic_differentiation}

Stan implements reverse-mode [automatic differentiation](wikipedia://en/734787) to calculate gradients of the model, which is required by HMC, NUTS, L-BFGS, BFGS, and variational inference.[^o3] The automatic differentiation within Stan can be used outside of the probabilistic programming language.

## Usage {#Usage}

Stan is used in fields including social science,[^o17] [pharmaceutical statistics](https://en.wikipedia.org/wiki/Pharmaceutical_statistics),[^o18] [market research](https://en.wikipedia.org/wiki/Market_research),[^o19] and [medical imaging](https://en.wikipedia.org/wiki/Medical_imaging).[^o20]
